# 数据库设计规则（PostgreSQL 14+）

**何时使用**：建表设计、DDL 编写、ORM 映射时。

**如何使用**：建表/SQL/ORM 规则读本文；DDL→Entity/Mapper/Service/Controller 全链路生成见 [project-structure/DDL_SCAFFOLD.md](../project-structure/DDL_SCAFFOLD.md)。

配合 [xxx_table.sql](xxx_table.sql) 模版使用。

## 建表

- 表名：小写+下划线，不用复数，命名 `业务名_表作用`（如 `job_config`）
- 字段：小写+下划线；布尔 `is_xxx boolean`
- 通用字段（顺序固定）：
  - `id bigint GENERATED BY DEFAULT AS IDENTITY`（应用层正常插入雪花ID；未提供时 DB 序列兜底；**禁止** `GENERATED ALWAYS AS IDENTITY`，会拒绝外部写入）
  - `created_at timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP`
  - `updated_at timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP`（**必须**配合表级触发器兜底）
  - `created_by bigint NOT NULL DEFAULT 0`
  - `updated_by bigint NOT NULL DEFAULT 0`
- 外键引用主键时类型一致（`bigint`）；其他字段按范围选 `int/smallint`
- 小数：`numeric(19,4)`，禁止 `float/double precision`；字符串：`varchar(n)`，n ≤ 5000
- 长文本/JSON 存储：优先 `text`；需要索引/查询时用 `jsonb`，禁止 `json`
- 索引命名：`uk_` 唯一索引，`idx_` 普通索引
- 单表行数预计 > 500 万行时提前规划分区（`PARTITION BY RANGE`）
- 字符集在数据库级统一设置（`ENCODING = 'UTF8'`），建表时无需重复声明

## 索引

- 唯一业务字段建唯一索引
- varchar 索引可使用前缀表达式索引（`substr(col, 1, 20)`）
- 组合索引：等号条件列前置，区分度高的放左边，`ORDER BY` 字段放最后
- 禁止左模糊、全模糊——需走搜索引擎
- 软删除场景下的唯一索引使用**部分索引**：`CREATE UNIQUE INDEX uk_xxx ON t (col) WHERE is_deleted = false`

## SQL

- 禁止 `SELECT *`，必须明确列名
- 参数用 `#{}`，禁止 `${}` 拼接（SQL 注入风险）
- 多表列名前加表别名（`t1/t2/t3`）
- 禁止外键约束、存储过程
- 更新操作必须有 WHERE 条件；数据订正先 SELECT 确认再 UPDATE/DELETE

## ORM（MyBatis-Plus）

- 禁止 `select *`；XML 必须有明确字段列表
- `type/status` 建枚举实现 `BaseEnum`
- 逻辑删除字段统一命名 `is_deleted`
