# 数据库建表规范

---

## 建表步骤

1. 确定表名（小写下划线，`业务名_表作用`，不用复数，如 `job_config`）
2. 字符集在数据库级统一设置（`ENCODING = 'UTF8'`），建表时无需重复声明
3. 添加通用字段（顺序固定）：

   ```sql
   id          bigint    GENERATED BY DEFAULT AS IDENTITY,  -- 应用层插入雪花ID，DB序列兜底
   -- 业务字段放这里 --
   created_at  timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP,
   updated_at  timestamp NOT NULL DEFAULT CURRENT_TIMESTAMP,  -- 配合步骤 7 的触发器
   created_by  bigint    NOT NULL DEFAULT 0,
   updated_by  bigint    NOT NULL DEFAULT 0,
   PRIMARY KEY (id)
   ```

   > `GENERATED BY DEFAULT AS IDENTITY`：应用层正常写入自有 ID；未提供时由 DB 序列兜底。**禁止** `GENERATED ALWAYS AS IDENTITY`（会拒绝外部写入）。

4. 定义业务字段，选择正确类型（见下表）
5. 添加索引：唯一业务字段用 `CREATE UNIQUE INDEX uk_xxx`，查询高频字段用 `CREATE INDEX idx_xxx`
6. 写表/列注释：`COMMENT ON TABLE ... IS '...'` / `COMMENT ON COLUMN ... IS '...'`
7. **为 `updated_at` 创建表级兜底触发器（必须，不可省略）**：

   ```sql
   -- 触发器函数每个库只需创建一次
   CREATE OR REPLACE FUNCTION set_updated_at()
   RETURNS TRIGGER LANGUAGE plpgsql AS $$
   BEGIN
     NEW.updated_at = CURRENT_TIMESTAMP;
     RETURN NEW;
   END;
   $$;

   -- 每张新表都需绑定
   CREATE TRIGGER trg_{表名}_updated_at
   BEFORE UPDATE ON {表名}
   FOR EACH ROW EXECUTE FUNCTION set_updated_at();
   ```

   > 触发器是**直连数据库操作**（如数据修复、脚本批处理）时 `updated_at` 自动刷新的最后一道防线，不可省略。

## 字段类型速查

| 场景 | 类型 | 说明 |
|------|------|------|
| 主键 | `bigint GENERATED BY DEFAULT AS IDENTITY` | 应用层插入雪花ID，`BY DEFAULT` 让 DB 序列兜底；禁止 int；禁止 `GENERATED ALWAYS AS IDENTITY` |
| 外键 | `bigint` | 禁止 int |
| 普通整数 | `int` / `smallint` | 按范围选，不滥用 bigint |
| 布尔 / 是否 | `boolean` | 列名 `is_xxx`，TRUE/FALSE |
| 金额 | `numeric(19,4)` | 禁止 float/double precision |
| 短字符串 | `varchar(n)` | n ≤ 5000 |
| 长文本 | `text` | 注释含「JSON」时对应 DTO |
| 时间 | `timestamp` | 存储 UTC，应用层处理时区 |
| JSON | `jsonb` | 需要索引/查询时用 jsonb，纯存储用 text |

### DDL 列 ↔ Java 字段类型映射（与 [`java-pojo`](../java-pojo/SKILL.md) PO-07 互锁）

Entity / DTO / VO 的字段类型一律用包装类型，**禁止基本类型**：

| DDL 列 | Java 字段（推荐） | ❌ 禁止 |
|---|---|---|
| `bigint` | `Long` | `long` |
| `int` / `smallint` | `Integer` | `int` / `short` |
| `boolean` | `Boolean` | `boolean` |
| `numeric(p,s)` | `BigDecimal`（金额必用） | `float` / `double` |
| `varchar(n)` / `text` | `String` | — |
| `timestamp` | `LocalDateTime` | `Date` / `long`（毫秒） |
| `jsonb` / `text(JSON)` | 具名 DTO（Javadoc `{@link}` 标注）| `String` / `Object` |

**为什么列已 `NOT NULL DEFAULT 0` 还要用包装类型**：新增列、外连接、聚合（`SUM/AVG`）、未投影列等场景仍可能返回 NULL；基本类型映射 NULL 时直接 NPE 或被默认值掩盖（业务真实 0 与"未取到"无法区分）。

## 索引规范

- 命名：`pk_` 主键，`uk_` 唯一索引，`idx_` 普通索引
- 组合索引：等号条件列前置，区分度高的放左边，`ORDER BY` 字段放最后
- varchar 索引可使用前缀表达式索引（`substr(col, 1, 20)`）
- **禁止**左模糊（`LIKE '%xxx'`）、全模糊——需走搜索引擎
- 唯一索引需考虑软删除场景：可用**部分索引**（`WHERE is_deleted = false`）

## 输入 / 输出示例

**输入需求**：职位配置表，记录职位名称、类型（全职/兼职）、薪资范围、状态

**输出 DDL**：

```sql
-- 1. 建表
CREATE TABLE job_config (
  id          bigint        GENERATED BY DEFAULT AS IDENTITY,      -- 应用层插入雪花ID，DB序列兜底
  name        varchar(100)  NOT NULL,
  type        smallint      NOT NULL,
  salary_min  numeric(19,4) NOT NULL DEFAULT 0,
  salary_max  numeric(19,4) NOT NULL DEFAULT 0,
  status      smallint      NOT NULL DEFAULT 1,
  created_at  timestamp     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at  timestamp     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  created_by  bigint        NOT NULL DEFAULT 0,
  updated_by  bigint        NOT NULL DEFAULT 0,
  PRIMARY KEY (id)
);

-- 2. 注释
COMMENT ON TABLE  job_config              IS '职位配置表';
COMMENT ON COLUMN job_config.id           IS '主键（雪花ID）';
COMMENT ON COLUMN job_config.name         IS '职位名称';
COMMENT ON COLUMN job_config.type         IS '职位类型：1-全职，2-兼职';
COMMENT ON COLUMN job_config.salary_min   IS '最低薪资';
COMMENT ON COLUMN job_config.salary_max   IS '最高薪资';
COMMENT ON COLUMN job_config.status       IS '状态：1-启用，0-禁用';
COMMENT ON COLUMN job_config.created_at   IS '创建时间';
COMMENT ON COLUMN job_config.updated_at   IS '更新时间';
COMMENT ON COLUMN job_config.created_by   IS '创建人 userId';
COMMENT ON COLUMN job_config.updated_by   IS '更新人 userId';

-- 3. 索引
CREATE INDEX idx_status ON job_config (status);

-- 4. updated_at 表级兜底触发器（必须，见建表步骤第 7 步）
CREATE OR REPLACE FUNCTION set_updated_at()
RETURNS TRIGGER LANGUAGE plpgsql AS $$
BEGIN
  NEW.updated_at = CURRENT_TIMESTAMP;
  RETURN NEW;
END;
$$;

CREATE TRIGGER trg_job_config_updated_at
BEFORE UPDATE ON job_config
FOR EACH ROW EXECUTE FUNCTION set_updated_at();
```

## 常见边界情况

| 情况 | 处理 |
|------|------|
| 字段名是 PostgreSQL 保留字（user/order/type） | DDL 加双引号 `"type"` |
| 需要唯一约束但允许软删除 | 使用**部分唯一索引**：`CREATE UNIQUE INDEX uk_name ON job_config (name) WHERE is_deleted = false` |
| 单表行数预计 > 500 万 | 提前规划分区方案（`PARTITION BY RANGE`），在 DDL 注释中说明 |
| 需要存 emoji / 多语言 | 数据库 `ENCODING = 'UTF8'`，`LC_COLLATE = 'en_US.UTF-8'`，建表无需额外设置 |
| updated_at 未自动更新 | 确认触发器函数 `set_updated_at()` 已创建，且 trigger 绑定到该表 |
