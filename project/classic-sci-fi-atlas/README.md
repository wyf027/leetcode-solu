# 公版科幻经典简中图册

这是一套可直接在浏览器中阅读的静态图册，收录 10 本公版科幻小说、2995 个原文分段及对应插图。

## 内容

- 《海底两万里》
- 《地心游记》
- 《从地球到月球》
- 《世界大战》
- 《时间机器》
- 《莫罗博士岛》
- 《火星公主》
- 《弗兰肯斯坦》
- 《平面国》
- 《化身博士》

每本书使用双页书本界面，支持章节导航、点击和拖拽翻页，以及插图放大查看。页面通过 Tailwind CSS CDN 加载样式，不需要前端构建步骤。

## 本地预览

在仓库根目录运行：

```bash
python3 -m http.server 8787 --directory project/classic-sci-fi-atlas
```

然后访问 `http://127.0.0.1:8787/`。

## 文件结构

- `index.html`：图册入口。
- `books/*.html`：10 本书的阅读页面。
- `assets/{slug}/segment-XXXX.png`：图片生成流程输出的原始 PNG 插图，未缩放或转码。

原图通过 Git LFS 管理。完整克隆本仓库时需要安装 Git LFS，并运行 `git lfs pull` 获取图片内容。

## 内容说明

原作均来自公版文本。当前简中内容覆盖源数据中的全部 2995 个分段，译文由机器辅助生成，仍可能存在专名差异或少量待人工校对的外文片段。
