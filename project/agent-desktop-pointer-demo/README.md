# 本机桌面光标控制台

仅在本机 `http://127.0.0.1:8766/` 提供操作页面。

需要 Node.js、`agent-desktop` 和 `cua-driver`，以及已授予的辅助功能与屏幕录制权限。

```sh
npm ci
npm start
```

计算器演示：先打开 macOS 计算器，再点击「连接计算器」。可移动光标、点击按键，或运行三个计算预设。

画图演示：点击「连接 Safari 画图」，等待 JS Paint 画布加载，再点击「绘制霸天虎」。程序会在专用 Safari 窗口中，通过 Cua Driver 的虚拟光标与后台输入依次操作矩形、油漆桶、多边形、直线、画刷、铅笔、椭圆、曲线、喷枪、橡皮，画出紫色面甲徽记。

每完成一种工具，控制台更新进度和窗口截图。「停止」会阻止后续动作；当前已发送的单次输入可能先完成。完成或中断后，重新连接可打开新的空白画布。

JS Paint 需要联网。绘制期间保留其默认工具栏布局，不切换画图页面或缩小 Safari 窗口；窗口地址或颜色校验不通过时会停止。服务重启后，请刷新控制台页面。
