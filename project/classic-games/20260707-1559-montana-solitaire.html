Mini Montana Solitaire

Moves: 0 Gaps: 4

Rules

Aces are removed to make four gaps. Move a card into a gap when it follows the card on the left by one rank and matches suit. A gap in the first column accepts any 2.

Build every row from 2 through K in a single suit. Select a card, then select a legal gap.

Pick a card that can slide into a highlighted gap.
