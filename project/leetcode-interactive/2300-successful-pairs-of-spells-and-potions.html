2300. 咒语和药水的成功对数

Successful Pairs of Spells and Potions

一条成功门槛，多种能量组合。先理解要统计什么，再探索如何高效地找出它们。

独立练习交互演示与题解默认折叠打开官方题目 ↗
01 / PROBLEM

题意

给定正整数数组 spells 和 potions，长度分别为 n、m。每个元素分别表示一个咒语或一瓶药水的强度。另给一个整数门槛 success。

当 spells[i] × potions[j] ≥ success 时，这对组合成功。返回长度为 n 的数组 pairs：第 i 项是能与第 i 个咒语成功配对的药水数量。

各个咒语独立统计，药水不会被消耗；相同强度的不同药水仍分别计数，答案顺序对应原始咒语顺序。

官方约束

  • n == spells.length，m == potions.length
  • 1 ≤ n, m ≤ 10⁵
  • 1 ≤ spells[i], potions[j] ≤ 10⁵
  • 1 ≤ success ≤ 10¹⁰
02 / EXAMPLES

官方示例

示例 1

输入：spells = [5,1,3]
      potions = [1,2,3,4,5]
      success = 7
输出：[4,0,3]

04 / SOLUTION LAB

准备好探索解法了吗？

展开后可查看逐步可视化、推导和四种语言实现。

INSIGHT

排序药水，寻找第一个成功位置

固定正数咒语 s，药水越强，乘积越大。把药水升序排列后，判定序列必定是“失败…失败，成功…成功”。找到第一个成功药水的下标 k，数量就是 m − k。

用半开区间 [lo, hi) 二分：初始 lo=0, hi=m。若 s × potions[mid] ≥ success，令 hi=mid；否则令 lo=mid+1。循环结束后 lo 即边界。

交互实验 · 成功边界探针

紫色探针展示本次比较；灰色为已排除的失败项，绿色为已确定的成功后缀。每次“下一步”执行一次边界更新或切换咒语。

演示限制：每个数组 1–12 个整数，逗号分隔；值 1–100000，success 1–10000000000。提交代码支持完整官方范围。



键盘：Tab 选择控件，Enter / 空格激活按钮；药水轨道获得焦点时可用左右方向键切换步骤。减少动态效果偏好下默认仅手动推进。




完整过程与正确性
  1. 仅对药水排序，保留咒语原有顺序。
  2. 依次选一个咒语，在整个药水数组上二分寻找第一个达标位置。
  3. 若中点达标，它和更右侧都达标；仍需检查左侧是否还有更早的成功位置。
  4. 若中点失败，它和更左侧都失败，因此从 mid+1 继续。
  5. 区间为空时记录 m-lo，处理下一个咒语。


不变式证明
循环开始时，[0,lo) 全部失败，[hi,m) 全部成功。初始两段均为空，不变式成立。中点成功时，单调性保证 [mid,m) 成功，设 hi=mid 保持不变式；中点失败时，[0,mid] 全失败，设 lo=mid+1 也保持不变式。
每次区间长度严格缩短，最终 lo=hi。此时左侧全失败、右侧全成功，所以 m-lo 恰是成功药水数。排序只改变药水位置，不改变元素及其出现次数，逐个处理咒语所得答案正确。


示例 1 的第一轮
咒语 5：[0,5) → 中点 2，乘积 15，收缩到 [0,2) → 中点 1，乘积 10，收缩到 [0,1) → 中点 0，乘积 5，移动到 [1,1)。因此边界为 1，得到 5−1=4。咒语 1、3 的边界分别为 5、2，得到 [4,0,3]。


边界与数值范围
  • 全部成功：边界 0；全部失败：边界 m；无需额外分支。
  • 重复药水均计数；等于门槛使用 ≥。
  • Java 要在乘法前转为 long，C++ 用 1LL 提升类型。最大乘积 10¹⁰ 超过 32 位整数。
  • JavaScript 的安全整数上限约为 9×10¹⁵，本题乘积可精确表示；Python 整数无需额外处理。


复杂度
排序 O(m log m)，n 次二分 O(n log m)，总时间 O(m log m+n log m)。结果数组 O(n)，二分本身 O(1)。下方代码均原地排序药水；额外排序空间取决于语言实现：C++ 通常 O(log m) 栈，Python 最坏 O(m)，Java / JavaScript 依赖运行时排序实现，不能统一宣称整体 O(1)。


替代方案
  • 直接枚举：O(nm) 时间、O(1) 额外工作空间，适合理解题意，小规模可用。
  • 排序 + 双指针：将咒语按强度排序并保留原下标。按咒语升序遍历，成功边界只会向左移动。时间 O(n log n+m log m+n+m)，需要恢复原顺序。
  • 值域计数：药水强度上限 U=10⁵，可建立频次后缀和。计算需求 ceil(success/s) 后直接查询；超过 U 时答案为 0。时间 O(n+m+U)，空间 O(U)。


常见错误
  • 把“至少”写成严格大于，漏掉恰好成功的组合。
  • 成功时直接返回 mid，没有找到最左侧边界。
  • 写成 lo=mid 可能不收敛；此处失败分支必须用 mid+1。
  • JavaScript 忘记数字排序比较器，默认按字符串顺序排序。
  • 先以 32 位类型相乘再转换，溢出已经发生。
  • 给药水去重，或排序咒语后不恢复答案顺序。


面试追问
可以除法转阈值吗？ 可以，用 (success+s−1)//s 求向上取整；定长整数仍要关注加法范围。直接乘法比较能避免舍入问题。
药水不变但持续收到咒语查询？ 排序一次，每次 O(log m) 查询；有限小值域时可用频次后缀和。
允许负数时呢？ 本题依赖咒语为正；负咒语会让乘积随药水强度递减，需要改变边界方向，零值也须单独讨论。

Java
import java.util.Arrays;

class Solution {
    public int[] successfulPairs(int[] spells, int[] potions, long success) {
        Arrays.sort(potions);
        int m = potions.length;
        int[] answer = new int[spells.length];
        for (int i = 0; i < spells.length; i++) {
            int lo = 0, hi = m;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if ((long) spells[i] * potions[mid] >= success) {
                    hi = mid;
                } else {
                    lo = mid + 1;
                }
            }
            answer[i] = m - lo;
        }
        return answer;
    }
}

/**

var successfulPairs = function(spells, potions, success) {
    potions.sort((a, b) => a - b);
    const m = potions.length;
    return spells.map(spell => {
        let lo = 0, hi = m;
        while (lo < hi) {
            const mid = lo + Math.floor((hi - lo) / 2);
            if (spell * potions[mid] >= success) hi = mid;
            else lo = mid + 1;
        }
        return m - lo;
    });
};


Python 3
from typing import List

class Solution:
    def successfulPairs(self, spells: List[int], potions: List[int],
                        success: int) -> List[int]:
        potions.sort()
        m = len(potions)
        answer = []
        for spell in spells:
            lo, hi = 0, m
            while lo < hi:
                mid = lo + (hi - lo) // 2
                if spell * potions[mid] >= success:
                    hi = mid
                else:
                    lo = mid + 1
            answer.append(m - lo)
        return answer


C++
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> successfulPairs(vector<int>& spells,
                                vector<int>& potions,
                                long long success) {
        sort(potions.begin(), potions.end());
        int m = static_cast<int>(potions.size());
        vector<int> answer;
        answer.reserve(spells.size());
        for (int spell : spells) {
            int lo = 0, hi = m;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (1LL * spell * potions[mid] >= success) hi = mid;
                else lo = mid + 1;
            }
            answer.push_back(m - lo);
        }
        return answer;
    }
};
