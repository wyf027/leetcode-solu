01 / Problem

题目转述

给定整数数组 banned、正整数 n 与预算 maxSum。从闭区间 [1, n] 中选择若干互不相同的整数，并同时满足：

  • 每个整数最多选择一次；
  • 选中的整数不能出现在 banned 中；
  • 所有选中整数之和不超过 maxSum。
目标：返回最多能选择多少个整数。只要求最大数量，不要求输出具体集合。
函数形式
maxCount(banned, n, maxSum) → integer
参数
  • banned: integer[]
  • n: integer
  • maxSum: long
02 / Examples

官方示例

示例 1
输入：banned = [1,4,6], n = 6, maxSum = 4
输出：1

例如只选择 3：它位于范围内、不在禁用数组中，且总和 3 ≤ 4。无法合法选择两个数。

示例 2
输入：banned = [4,3,5,6], n = 7, maxSum = 18
输出：3

可以选择 1、2、7，总和为 10；范围内其余整数均被禁用，所以最多选择三个。

Solution / Greedy intervals

排序去重 + 区间贪心 + 二分

将巨大整数范围压缩为禁用点之间的连续可选区间。每个区间只需要回答一个问题：当前预算最多能买下从区间左端开始的多少个数。

核心洞察

所有数字的“价值”都相同：选中一个数就让答案加一，而代价就是该数本身。若某个合法方案选了较大的 y 却漏掉较小且可选的 x，用 x 替换 y 不会减少数量，只会降低总和。因此最优方案一定可以按从小到大的顺序取数。

区间公式

禁用值排序去重后，相邻禁用点之间形成连续区间 [L,R]。从 L 起取 k 个数的代价为：

cost(L,k) = k × (2L + k − 1) / 2

完整过程

  1. 过滤范围外的禁用值，排序并去重；末尾加入哨兵 n+1。
  2. 用 prev 记录上一个禁用点，当前可选区间是 [prev+1, ban-1]。
  3. 在 0..区间长度 上二分最大的 k，使区间前 k 项之和不超过剩余预算。
  4. 累加 k 并扣除代价。若未能取完整个区间，后续数字更大，直接结束。

正确性

交换论证：对任意最大数量方案，只要存在“选大漏小”，就可用较小合法数替换较大数，数量不变且总和不增。重复交换后得到按升序取最小合法数的同规模方案。

区间二分：cost(L,k) 随 k 单调递增，二分找到预算允许的最大前缀长度。逐区间从小到大处理，恰好构造上述最小合法数前缀，所以返回全局最大数量。

边界处理

  • banned 可能重复，必须去重；
  • 空区间无需二分；哨兵 n+1 负责收尾；
  • 预算可能连最小合法数都买不起，此时答案增量为零；
  • 区间和可能远超 32 位，Java/C++ 使用 64 位，JavaScript 使用 BigInt。

复杂度

设去重后的禁用值数量为 m。排序耗时 O(m log m)；每个区间做至多 O(log n) 次二分，总时间 O(m log m + m log n)，额外空间 O(m)。

替代方案

也可以全局二分一个前缀上界 x，计算 1..x 去掉禁用值后的和，再补选下一个合法数；若预先保存禁用值前缀和，可把判定降到对禁用数组的二分。实现更绕，但适合追问“能否按前缀判定”。

面试追问

  • 若每个数的收益不同，交换论证为何失效？
  • 若有多次不同 maxSum 查询，如何复用排序和前缀信息？
  • 为什么取不满当前区间后可以立刻停止？

常见错误

错误后果修正
从 1 枚举到 nn=10⁹ 时超时按禁用点切连续区间
不对 banned 去重重复切分、可能移动错 prev排序后去重或使用集合
使用 32 位区间和乘法溢出导致二分方向错误先提升到 64 位 / BigInt
二分取任意 k 个公式与选择集合不匹配公式始终对应区间左端的前 k 个数

JavaScriptBigInt 区间和 
/**
 * @param {number[]} banned
 * @param {number} n
 * @param {number} maxSum
 * @return {number}
 */
var maxCount = function (banned, n, maxSum) {
  const blocked = [...new Set(banned.filter((x) => x >= 1 && x <= n))]
    .sort((a, b) => a - b);
  blocked.push(n + 1);

  let remaining = BigInt(maxSum);
  let answer = 0;
  let previous = 0;

  const rangeSum = (start, count) => {
    const a = BigInt(start);
    const k = BigInt(count);
    return k * (2n * a + k - 1n) / 2n;
  };

  for (const stop of blocked) {
    const start = previous + 1;
    const length = stop - start;
    let left = 0;
    let right = length;

    while (left < right) {
      const middle = Math.floor((left + right + 1) / 2);
      if (rangeSum(start, middle) <= remaining) left = middle;
      else right = middle - 1;
    }

    remaining -= rangeSum(start, left);
    answer += left;
    if (left < length) break;
    previous = stop;
  }

  return answer;
};
Javalong 区间和 
import java.util.Arrays;

class Solution {
    public int maxCount(int[] banned, int n, long maxSum) {
        Arrays.sort(banned);
        long remaining = maxSum;
        int answer = 0;
        int previous = 0;

        for (int i = 0; i <= banned.length; i++) {
            int stop = i == banned.length ? n + 1 : banned[i];
            if (stop < 1 || stop > n + 1 || stop == previous) continue;

            int start = previous + 1;
            int length = stop - start;
            int left = 0;
            int right = length;

            while (left < right) {
                int middle = left + (right - left + 1) / 2;
                if (rangeSum(start, middle) <= remaining) left = middle;
                else right = middle - 1;
            }

            remaining -= rangeSum(start, left);
            answer += left;
            if (left < length) break;
            previous = stop;
        }
        return answer;
    }

    private long rangeSum(long start, long count) {
        return count * (2 * start + count - 1) / 2;
    }
}

from typing import List


class Solution:
    def maxCount(self, banned: List[int], n: int, maxSum: int) -> int:
        blocked = sorted(set(x for x in banned if 1 <= x <= n))
        blocked.append(n + 1)
        remaining = maxSum
        answer = 0
        previous = 0

        def range_sum(start: int, count: int) -> int:
            return count * (2 * start + count - 1) // 2

        for stop in blocked:
            start = previous + 1
            length = stop - start
            left, right = 0, length

            while left < right:
                middle = (left + right + 1) // 2
                if range_sum(start, middle) <= remaining:
                    left = middle
                else:
                    right = middle - 1

            remaining -= range_sum(start, left)
            answer += left
            if left < length:
                break
            previous = stop

        return answer

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
 public:
  int maxCount(vector<int>& banned, int n, long long maxSum) {
    sort(banned.begin(), banned.end());
    banned.erase(unique(banned.begin(), banned.end()), banned.end());
    banned.push_back(n + 1);

    long long remaining = maxSum;
    int answer = 0;
    int previous = 0;

    for (const int stop : banned) {
      if (stop < 1 || stop > n + 1) continue;
      const int start = previous + 1;
      const int length = stop - start;
      int left = 0;
      int right = length;

      while (left < right) {
        const int middle = left + (right - left + 1) / 2;
        if (rangeSum(start, middle) <= remaining)
          left = middle;
        else
          right = middle - 1;
      }

      remaining -= rangeSum(start, left);
      answer += left;
      if (left < length) break;
      previous = stop;
    }
    return answer;
  }

 private:
  long long rangeSum(long long start, long long count) {
    return count * (2 * start + count - 1) / 2;
  }
};
