连续的子数组和

Continuous Subarray Sum

题目

给定整数数组 nums 和整数 k。判断是否存在一个连续子数组，它的长度至少为 2，并且元素和是 k 的倍数；存在则返回 true，否则返回 false。

这里“倍数”包含 0：只要存在整数 n 使 x = n × k，x 就是 k 的倍数。

输入：int[] nums, int k输出：booleanpaidOnly: false

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁹
  • 0 ≤ sum(nums[i]) ≤ 2³¹ − 1
  • 1 ≤ k ≤ 2³¹ − 1

官方示例

输入：nums = [23,2,4,6,7], k = 6
输出：true
解释：[2,4] 长度为 2，和为 6。
输入：nums = [23,2,6,4,7], k = 6
输出：true
解释：整个数组和为 42 = 7 × 6。
输入：nums = [23,2,6,4,7], k = 13
输出：false

首次出现位置

先自己推导，再查看题解

思考：两个前缀和具有什么关系时，它们之间的区间和能被 k 整除？长度至少为 2 如何编码？

题解：前缀和余数 + 最早位置

核心洞察

令 P[i] 表示下标 0 到 i 的前缀和。如果 P[i] 与更早的前缀 P[j] 除以 k 的余数相同，那么 P[i] − P[j] 可被 k 整除，对应子数组 j+1…i。为了满足长度至少为 2，需要 i − j ≥ 2。

关键初始化：把余数 0 的最早位置设为 −1。这样从下标 0 开始、长度至少为 2 且前缀和能被 k 整除的区间也能被统一发现。

完整过程

  1. 创建哈希表 first，存每个余数第一次出现的下标，并置 first[0] = -1。
  2. 从左到右累计前缀和，计算 remainder = prefix % k。
  3. 若余数已出现且当前下标与首次下标之差至少为 2，返回 true。
  4. 若余数第一次出现，记录当前位置；不要覆盖，以保留最长距离。
  5. 遍历结束仍未找到则返回 false。

正确性证明

充分性：算法返回 true 时，存在相同余数的两个前缀位置 j 与 i，且 i−j≥2。它们的差能被 k 整除，因此区间 j+1…i 是长度至少为 2 的好子数组。

必要性：若存在好子数组 l…r，其和能被 k 整除，则 P[r] 与 P[l−1] 对 k 同余。扫描到 r 时，该余数必已在不晚于 l−1 的位置记录，且距离至少为 2，所以算法一定返回 true。

边界情况

  • 数组少于 2 个元素时必为 false；官方范围仍允许长度为 1。
  • 连续两个 0 会命中，因为区间和 0 是 k 的倍数。
  • 大元素会使累计和增长；Java/C++ 使用 64 位累计值更稳妥。
  • k 按官方约束至少为 1，无需处理除以 0。

复杂度

时间 O(n)，额外空间 O(min(n, k))：最多记录遇到的不同余数。

替代方案

枚举所有起点并累加终点是 O(n²)，无法应对 10⁵。也可维护余数集合，但若不保存下标就无法验证长度约束；保存所有下标又浪费空间。

面试追问

  • 如果要求返回具体区间？命中时返回 [first[remainder]+1, i]。
  • 为什么只保留首次位置？它让与未来下标的距离最大，且足以判断存在性。
  • 如果数组允许负数？需将余数标准化为 ((sum % k) + k) % k。
  • 如果要求子数组长度至少为 m？把距离条件改成 i − j ≥ m。

常见错误

  • 遗漏 first[0] = -1，错过从数组开头起的答案。
  • 每次覆盖余数位置，可能把足够长的区间缩短。
  • 只判断余数重复，却未检查长度至少为 2。
  • 用 32 位前缀和，在其他约束变体中可能溢出。

完整代码

Java

class Solution {
    public boolean checkSubarraySum(int[] nums, int k) {
        Map<Integer, Integer> first = new HashMap<>();
        first.put(0, -1);
        long prefix = 0;

        for (int i = 0; i < nums.length; i++) {
            prefix += nums[i];
            int remainder = (int) (prefix % k);
            if (first.containsKey(remainder)) {
                if (i - first.get(remainder) >= 2) return true;
            } else {
                first.put(remainder, i);
            }
        }
        return false;
    }
}

var checkSubarraySum = function(nums, k) {
    const first = new Map([[0, -1]]);
    let prefix = 0;

    for (let i = 0; i < nums.length; i++) {
        prefix += nums[i];
        const remainder = prefix % k;
        if (first.has(remainder)) {
            if (i - first.get(remainder) >= 2) return true;
        } else {
            first.set(remainder, i);
        }
    }
    return false;
};

Python

from typing import List

class Solution:
    def checkSubarraySum(self, nums: List[int], k: int) -> bool:
        first = {0: -1}
        prefix = 0

        for i, value in enumerate(nums):
            prefix += value
            remainder = prefix % k
            if remainder in first:
                if i - first[remainder] >= 2:
                    return True
            else:
                first[remainder] = i
        return False

C++

class Solution {
public:
    bool checkSubarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> first{{0, -1}};
        long long prefix = 0;

        for (int i = 0; i < (int)nums.size(); ++i) {
            prefix += nums[i];
            int remainder = prefix % k;
            auto it = first.find(remainder);
            if (it != first.end()) {
                if (i - it->second >= 2) return true;
            } else {
                first[remainder] = i;
            }
        }
        return false;
    }
};
