绝对差值和

Minimum Absolute Sum Difference MEDIUM

只有一次改动机会，你会把它留给哪个位置？

题意 · 复制一个已有的值

给定两个等长的正整数数组 nums1 和 nums2。对每个下标 i 计算 |nums1[i] − nums2[i]|，再将这些绝对差相加。

你可以不操作，也可以把 nums1 中的一个元素替换成原 nums1 中已有的任意值。来源元素仍然保留，这不是交换。求操作后可能得到的最小绝对差值和，并对 1,000,000,007 取余。

约束

  • n == nums1.length == nums2.length
  • 1 ≤ n ≤ 100000
  • 1 ≤ nums1[i], nums2[i] ≤ 100000
  • 下标从 0 开始，|x| 在 x ≥ 0 时等于 x，否则等于 −x。

先独立思考

一个位置改变后，其他位置的差值会受影响吗？原差值最大的地方，一定最值得替换吗？下方题解及交互实验台默认折叠。

题解 · 最大化一次替换的收益

原总和记作 S。把位置 i 的原值换成 x，节省量为 |nums1[i] − nums2[i]| − |x − nums2[i]|。只允许一次操作，因此答案是 (S − 最大节省量) mod M。

完整过程

  1. 复制 nums1 并排序，原数组保持不动以保留配对关系。
  2. 遍历每个 i，将原差值 old 累加到 S。
  3. 以 nums2[i] 为目标，二分寻找第一个不小于它的元素下标 p，即 lower_bound。
  4. 检查 p 和 p−1（存在时），得到最近值对应的最小差值 near。
  5. 用 old−near 更新最大收益 best，最后返回 (S−best) mod M。

交互实验台 · 邻居定位与收益账本

橙色虚线：二分探针；青色实线：定位后的邻居候选。逐步观察区间如何收缩，再看这次替换能省多少。可视化限制为 20 项，提交算法支持完整约束。

青色条表示最大节省量占原始总和的比例。

正确性论证

最近邻性质：在排序数组中，目标右侧的第一个值是右侧最近值，目标左侧的最后一个值是左侧最近值。比这两个邻居更远的值不可能产生更小的绝对差。因此 p 与 p−1 足以找到每个位置的最优替换。

全局最优：任意合法操作只修改一项，其收益不会超过该位置的最优收益，也不会超过所有位置的最大收益 best。所以任何方案的总和至少是 S−best。产生 best 的候选确实来自原 nums1，可以实际执行该替换，达到 S−best，因此结果最优。best 初始化为 0 同时覆盖无需替换的情况。

边界与数值范围

  • p=0 时没有前驱；p=n 时没有右邻居。只访问存在的一侧。
  • 重复值无需去重；目标恰好存在时可把该项差值降至 0。
  • n=1 时可用值只有原值，不能改进；两个数组相等则直接得到 0。
  • 总和最多 9,999,900,000。Java 用 long，C++ 用 long long；JavaScript Number 的安全整数范围足够，Python 整数自动扩展。
  • 真实总和减去最大收益后再取模，避免负余数；不能对收益先取模再比较大小。

复杂度

排序 O(n log n)，每个位置二分 O(log n)，总时间 O(n log n)。排序副本需要 O(n) 额外空间，排序栈不改变总空间上界。

替代方案

枚举每个位置及所有替换值，时间 O(n²)，只适用于小规模。利用固定值域 U=100000，也可以建立存在标记，通过两次扫描预计算每个值的最近前驱与后继，实现 O(n+U) 时间、O(U) 空间；排序方案更通用。

常见错误

  • 直接排序原 nums1，破坏它与 nums2 的配对关系。
  • 只替换原差值最大的位置。用例 6 中，下标 0 原差最大却无法改进，下标 1 可以节省 50。
  • 只检查 lower_bound，遗漏更近的前驱。
  • 把所有位置的收益相加，实际做了多次替换。
  • JavaScript 的 sort() 未传数字比较器，造成字典序排序。

面试追问

允许至多 k 次呢？若可重复使用原数组中的值，每个位置收益独立，选最大的 k 个非负收益。若改为交换两个位置呢？两项代价相互关联，不能直接沿用单位置收益模型。如何输出替换操作？更新 best 时同时记录目标下标与候选值，并列时任选一个。

Java

import java.util.Arrays;

class Solution {
    public int minAbsoluteSumDiff(int[] nums1, int[] nums2) {
        int[] sorted = nums1.clone();
        Arrays.sort(sorted);
        int n = nums1.length, best = 0;
        long sum = 0;
        for (int i = 0; i < n; i++) {
            int target = nums2[i];
            int old = Math.abs(nums1[i] - target);
            sum += old;
            int l = 0, r = n;
            while (l < r) {
                int m = l + (r - l) / 2;
                if (sorted[m] < target) l = m + 1;
                else r = m;
            }
            int near = old;
            if (l < n) near = Math.min(near, Math.abs(sorted[l] - target));
            if (l > 0) near = Math.min(near, Math.abs(sorted[l - 1] - target));
            best = Math.max(best, old - near);
        }
        return (int)((sum - best) % 1_000_000_007L);
    }
}

from typing import List
from bisect import bisect_left

class Solution:
    def minAbsoluteSumDiff(self, nums1: List[int], nums2: List[int]) -> int:
        ordered = sorted(nums1)
        total = best = 0
        n = len(nums1)
        for a, target in zip(nums1, nums2):
            old = abs(a - target)
            total += old
            p = bisect_left(ordered, target)
            near = old
            if p < n:
                near = min(near, abs(ordered[p] - target))
            if p > 0:
                near = min(near, abs(ordered[p - 1] - target))
            best = max(best, old - near)
        return (total - best) % 1_000_000_007
