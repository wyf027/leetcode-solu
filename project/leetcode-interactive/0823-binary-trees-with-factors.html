823. 带因子的二叉树

Binary Trees With Factors

给定一组互不相同且都大于 1 的整数。用这些值构造二叉树，值可以重复使用；每个非叶结点必须恰好等于左右孩子值的乘积。请统计所有满足条件的有序二叉树。

你的任务

返回可构造的树总数

结果可能很大，最终对 109 + 7 取余。左右孩子交换后若结构或结点次序不同，应视为不同的树。

01 / Problem

读懂题目

数组 · 哈希表 · 动态规划 · 排序

题意转述

输入整数数组 arr。数组中的每个值都可以作为叶结点，也可以作为非叶结点；当一个结点有孩子时，它的值必须等于左孩子值与右孩子值之积。数组中的值可以在同一棵树或不同树中被反复使用。

统计根值属于 arr 的全部合法二叉树，并返回答案对 1,000,000,007 取余后的结果。

约束

  • 1 <= arr.length <= 1000
  • 2 <= arr[i] <= 109
  • arr 中的所有值互不相同
  • 函数签名：numFactoredBinaryTrees(arr)

完整题解

排序 + 动态规划 + 哈希表

从“固定一棵树的根”切入，把大问题拆成两个更小根值的树数量之积。

核心洞察

定义：dp[x] 表示“以值 x 为根”的合法二叉树数量。至少存在只含根结点的一棵树，所以初值为 1。

若 x = a × b，且 a、b 都在数组中，那么可以任取一棵以 a 为根的树作为左子树，再任取一棵以 b 为根的树作为右子树，因此这组有序因子对贡献 dp[a] × dp[b]。

把数组升序排序后，a 与 b 一定都小于 x（所有值均大于 1），处理 x 时两个子问题已求出。用哈希表即可常数时间查询互补因子 b = x / a 是否存在。

完整过程

建立计算顺序

升序排列 arr，创建映射 dp，答案 answer = 0。

保留叶结点方案

遍历当前根值 x，先设 ways = 1，表示单结点树。

枚举左因子

只枚举已经处理的值 a。若 x % a == 0，计算 b = x / a。

拼接左右子树

若 b 已在 dp，累加 dp[a] × dp[b] 并取模。

落账并汇总

保存 dp[x] = ways，再把它加入总答案。最后返回总答案。

为何不用乘 2

循环会分别枚举 a 与 b，自然覆盖 (a,b) 和 (b,a)；当二者相等时只出现一次，正合题意。

正确性证明

  1. 基础情形：对任意数组值 x，单独使用 x 都得到一棵合法叶结点树，故 dp[x] 的初始 1 正确。
  2. 完备性：考虑任意以 x 为根、且不是单结点的合法树。其左右孩子根值必为数组中的某个 a、b，满足 a × b = x。枚举到 a 时，算法会找到 b，并将这两棵子树的组合计入。
  3. 无重复：一棵非单结点树由根值 x、确定的有序孩子根值 (a,b)、确定的左右子树唯一决定。算法在对应的有序因子对中恰好计数一次。
  4. 归纳成立：因为所有因子都小于当前根值，升序处理 x 时 dp[a] 与 dp[b] 已正确。由乘法原理，本轮得到的 dp[x] 正确。对所有根求和即为全部合法树数。

复杂度与边界

O(n²)

时间：排序为 O(n log n)，双层枚举主导总耗时。

O(n)

空间：哈希表保存每个根值的计数。

mod 1e9+7

每次乘加都取模；JavaScript 实现使用 BigInt 避免精度损失。

  • 只有一个值：只能形成单结点树，返回 1。
  • 没有可用因子对：每个值只贡献单结点树，答案等于数组长度。
  • 平方因子：若 x = a²，有序对 (a,a) 只计一次，但贡献仍为 dp[a]²。
  • 左右不同：(a,b) 与 (b,a) 是不同结构，循环枚举会分别计入。

JavaLeetCode 提交格式
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numFactoredBinaryTrees(int[] arr) {
        final long MOD = 1_000_000_007L;
        Arrays.sort(arr);

        Map<Integer, Long> dp = new HashMap<>();
        long answer = 0L;

        for (int i = 0; i < arr.length; i++) {
            int root = arr[i];
            long ways = 1L;

            for (int j = 0; j < i; j++) {
                int left = arr[j];
                if (root % left != 0) {
                    continue;
                }

                int right = root / left;
                Long rightWays = dp.get(right);
                if (rightWays != null) {
                    ways = (ways + dp.get(left) * rightWays) % MOD;
                }
            }

            dp.put(root, ways);
            answer = (answer + ways) % MOD;
        }

        return (int) answer;
    }
}

/**
 * @param {number[]} arr
 * @return {number}

var numFactoredBinaryTrees = function(arr) {
    const MOD = 1000000007n;
    arr.sort((a, b) => a - b);

    const dp = new Map();
    let answer = 0n;

    for (let i = 0; i < arr.length; i++) {
        const root = arr[i];
        let ways = 1n;

        for (let j = 0; j < i; j++) {
            const left = arr[j];
            if (root % left !== 0) continue;

            const right = root / left;
            if (dp.has(right)) {
                ways = (ways + dp.get(left) * dp.get(right)) % MOD;
            }
        }

        dp.set(root, ways);
        answer = (answer + ways) % MOD;
    }

    return Number(answer);
};

from typing import List


class Solution:
    def numFactoredBinaryTrees(self, arr: List[int]) -> int:
        mod = 1_000_000_007
        arr.sort()

        dp = {}
        answer = 0

        for i, root in enumerate(arr):
            ways = 1

            for left in arr[:i]:
                if root % left != 0:
                    continue

                right = root // left

            dp[root] = ways
            answer = (answer + ways) % mod

        return answer
C++LeetCode 提交格式
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int numFactoredBinaryTrees(vector<int>& arr) {
        static constexpr long long MOD = 1'000'000'007LL;
        sort(arr.begin(), arr.end());

        unordered_map<int, long long> dp;
        long long answer = 0;

        for (int i = 0; i < static_cast<int>(arr.size()); ++i) {
            int root = arr[i];
            long long ways = 1;

            for (int j = 0; j < i; ++j) {
                int left = arr[j];
                if (root % left != 0) continue;

                int right = root / left;
                auto it = dp.find(right);
                if (it != dp.end()) {
                    ways = (ways + dp[left] * it->second) % MOD;
                }
            }

            dp[root] = ways;
            answer = (answer + ways) % MOD;
        }

        return static_cast<int>(answer);
    }
};

替代方案

递归记忆化搜索

也可以把“以 x 为根的树数”写成递归函数，并缓存结果。逻辑接近定义，但需要控制递归层数、重复枚举和取模；升序 DP 的依赖关系更直观。

只枚举到平方根

找到 a × b = x 后，若 a != b，手动乘 2；若相等则不乘。常数可能更小，但分支更容易写错，而且仍需确认两个因子都在集合中。

面试追问

为什么排序是必要的？

它建立了无环的依赖顺序：根的两个因子严格更小，因此读取到的子问题一定已经完成。

如果数组允许出现 1 会怎样？

x = 1 × x 会让状态依赖自身，并且值可以无限重复使用，可能产生无限多棵树；这也是题目要求所有值大于 1 的关键原因。

能否低于 O(n²)？

可以尝试枚举每个数的数学因子，但对最多 10⁹ 的值做开方枚举，复杂度未必更优。当前约束下 O(n²) 清晰且足够。

常见错误

漏掉单结点树：每个 dp[x] 必须从 1 开始。

左右次序重复或遗漏：全量枚举左因子时不要再手动乘 2。

太晚取模：乘法和累加都应及时取模；Java/C++ 中使用 64 位整数。

JavaScript 精度：两个模内数相乘可能超过安全整数范围，应使用 BigInt 完成计数。

用数组下标当值：arr[i] 可达 10⁹，应使用哈希表而非按值开大数组。
