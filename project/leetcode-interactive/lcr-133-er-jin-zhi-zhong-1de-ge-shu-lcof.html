位 1 的个数

统计一个无符号整数的二进制表示中，值为 1 的位数。

题意

给定一个非负整数 n，返回其二进制表示中 1 的个数（也称 popcount 或汉明重量）。

示例

输入：n = 11
二进制：1011
输出：3
输入：n = 128
二进制：10000000
输出：1

约束

  • 0 ≤ n ≤ 2³² - 1
  • 目标是按二进制位统计，不依赖十进制字符串。

分步交互

演示 Kernighan 算法：每一步清除最低位的 1。

当前二进制

1011

已找到 0 个 1，准备开始。

题解

默认收起；按需展开阅读完整推导。

核心洞察

表达式 n & (n - 1) 会把 n 最低位的那个 1 清零。因而循环次数恰好等于 1 的个数，比逐位扫描更贴合实际数据。

完整过程

  1. 将答案 count 置为 0。
  2. 当 n != 0 时，令 n = n & (n - 1)。
  3. 每清除一个 1，count 加 1。
  4. n 变为 0 时返回 count。

边界

  • n = 0：循环不会进入，答案为 0。
  • 最高位为 1：Java 需使用无符号右移时应注意符号扩展；本算法不需要右移。
  • JavaScript 位运算为 32 位有符号语义，使用 >>> 0 归一化。

复杂度

时间复杂度 O(k)，其中 k 是 1 的数量；空间复杂度 O(1)。

替代方案

可逐位检查 n & 1 后右移，固定 32 位时为 O(32)；部分语言还有内置位计数函数。面试中优先写出 Kernighan 算法并说明其原因。

追问

若要计算区间内每个数的位 1 个数，可用动态规划：bits[i] = bits[i >> 1] + (i & 1)。

常见错误

  • 把十进制字符串中的字符 1 数量当成答案。
  • JavaScript 忘记转为无符号 32 位，导致负数输入的交互演示失真。
  • 误写成 n & (n + 1)，这并不清除最低位的 1。

官方签名代码

// Java
public class Solution {
    public int hammingWeight(int n) {
        int count = 0;
        while (n != 0) {
            n &= (n - 1);
            count++;
        }
        return count;
    }
}
// JavaScript
var hammingWeight = function(n) {
  n >>>= 0;
  let count = 0;
  while (n !== 0) {
    n = (n & (n - 1)) >>> 0;
    count++;
  }
  return count;
};
# Python
class Solution:
    def hammingWeight(self, n: int) -> int:
        count = 0
        while n:
            n &= n - 1
            count += 1
        return count
// C++
class Solution {
public:
    int hammingWeight(uint32_t n) {
        int count = 0;
        while (n) {
            n &= n - 1;
            ++count;
        }
        return count;
    }
};
