订单的产品

Products With Three or More Orders in Two Consecutive Years

从订单记录中找出存在相邻两个自然年、且每年都至少下单三次的产品。先阅读数据与规则，再自行推导查询。

01 / 题意与数据契约

输入为 Orders 表。一行代表一笔订单，包含订单编号、产品编号、购买数量和购买日期。返回所有符合条件的 product_id，同一产品只出现一次，结果顺序不限。

字段类型含义
order_idint订单编号，主键
product_idint产品编号
quantityint该订单的商品数量
purchase_datedate购买日期

约束与语义

  • order_id 唯一；统计的是订单行数，不是购买数量之和。
  • “连续两年”指年份为 y 和 y + 1；不是任意两个有订单的年份，也不是滚动 24 个月。
  • 两个年份必须分别达到至少 3 笔，恰好 3 笔也符合；存在一对即可。
  • 公开题面未给出行数、字段数值范围或额外非空约束；这里不自行补造。

05 / 独立题解

准备好后再展开推导与代码。

按年达标，再寻找下一年

核心洞察

保留每个产品每个自然年的订单笔数就足够了。先得到“达标的产品—年份”集合，再判断同一产品的 y + 1 是否也在集合里。数量字段不参与计算。

完整过程

  1. 按 product_id, YEAR(purchase_date) 分组。
  2. 使用 HAVING COUNT(*) >= 3 留下达标年度。
  3. 达标集合自连接：产品相同，右侧年份等于左侧年份加 1。
  4. 只返回 DISTINCT product_id；三年或更多年达标可能产生多对年份。

正确性

可靠性：连接返回的每一对记录都来自达标集合，故两个年份各至少三笔；连接条件保证产品相同且年份相差一，因此返回的产品必定符合要求。

完整性：任何符合条件的产品都存在达标的 y 与 y + 1。分组和过滤会保留这两行，连接必然将它们匹配，因此该产品不会被遗漏。最终去重只删除重复结果，不删除产品本身。

边界与常见错误

  • 空表、仅一个达标年、年份断档：都不能形成匹配。
  • 两年订单总计六笔不充分：4 + 2 仍不符合。
  • 三年连续达标，只输出一次；不要遗漏 DISTINCT。
  • 必须按产品隔离，不能将两个产品的年份拼接。
  • 不能使用 SUM(quantity)，也不能将“至少三笔”写成等于三。
  • 如果采用 LAG，相邻记录不保证相邻年份，仍需判断差值等于 1。
  • 输入日期按数据库 DATE 语义处理；本地参考代码假定有效 YYYY-MM-DD。SQL 中空日期无法形成有效的相邻年匹配。

复杂度

令 N 为订单数，G 为不同的产品—年份组合数。哈希聚合和哈希连接的预期时间为 O(N + G)，中间空间 O(G)。SQL 的具体性能由执行计划决定：排序聚合可能为 O(N log N)，无有效连接策略时配对可能退化至 O(G²)。四语言参考采用哈希计数与下一年查找，预期 O(N + G) 时间、O(G) 空间，忽略输出顺序。

替代方案

将达标年份按产品分区、按年份排序，用 LAG 取上一个达标年，筛出差为 1 的行，再对产品去重。也可用 EXISTS 表达“下一年存在”。本题只需两年，自连接的条件最直接。

面试追问

  • 改为连续 K 年怎么办？先筛达标年，再按产品求连续年份段；可用“年份减行号”分组，段长至少 K。
  • 改为每年总购买量至少三件？改成 SUM(quantity)，但业务含义已改变。
  • 如何优化大量数据？先看执行计划，再评估产品与年份的生成列、索引或年度汇总；索引是否有益需按数据库与查询规模实测。
  • 如果订单拆成多条明细？先明确订单粒度，必要时用 COUNT(DISTINCT order_id)，不能直接沿用行数。

MySQL 8 · 可提交主解

WITH yearly AS (
    SELECT product_id, YEAR(purchase_date) AS yr
    FROM Orders
    GROUP BY product_id, YEAR(purchase_date)
    HAVING COUNT(*) >= 3
)
SELECT DISTINCT a.product_id
FROM yearly AS a
JOIN yearly AS b
  ON b.product_id = a.product_id
 AND b.yr = a.yr + 1;

Java · 本地语义参考（非本题提交接口）

import java.time.LocalDate;
import java.util.*;

class Solution {
    static class Order {
        final int orderId, productId, quantity;
        final LocalDate purchaseDate;
        Order(int orderId, int productId, int quantity, String date) {
            this.orderId = orderId;
            this.productId = productId;
            this.quantity = quantity;
            this.purchaseDate = LocalDate.parse(date);
        }
    }
    public static List<Integer> findValidProducts(List<Order> orders) {
        Map<Integer, Map<Integer, Integer>> counts = new HashMap<>();
        for (Order o : orders) {
            counts.computeIfAbsent(o.productId, k -> new HashMap<>())
                  .merge(o.purchaseDate.getYear(), 1, Integer::sum);
        }
        List<Integer> result = new ArrayList<>();
        for (var product : counts.entrySet()) {
            Map<Integer, Integer> years = product.getValue();
            for (var entry : years.entrySet()) {
                if (entry.getValue() >= 3 &&
                    years.getOrDefault(entry.getKey() + 1, 0) >= 3) {
                    result.add(product.getKey());
                    break;
                }
            }
        }
        return result;
    }
}

JavaScript · 本地语义参考（非本题提交接口）

// orders: [order_id, product_id, quantity, "YYYY-MM-DD"][]
// 返回唯一 product_id 数组；假定输入符合 Orders 表契约。
function findValidProducts(orders) {
  const counts = new Map();
  for (const [, product, , date] of orders) {
    const year = Number(date.slice(0, 4));
    if (!counts.has(product)) counts.set(product, new Map());
    const years = counts.get(product);
    years.set(year, (years.get(year) ?? 0) + 1);
  }
  const result = [];
  for (const [product, years] of counts) {
    for (const [year, count] of years) {
      if (count >= 3 && (years.get(year + 1) ?? 0) >= 3) {
        result.push(product);
        break;
      }
    }
  }
  return result;
}

Python · 本地语义参考（非 Pandas 提交接口）

from collections import Counter, defaultdict

def find_valid_products(orders):
    """orders: (order_id, product_id, quantity, YYYY-MM-DD) 序列。
    返回唯一 product_id 列表；输入应符合 Orders 表契约。
    """
    counts = defaultdict(Counter)
    for order_id, product_id, quantity, purchase_date in orders:
        year = int(purchase_date[:4])
        counts[product_id][year] += 1
    result = []
    for product, years in counts.items():
        if any(count >= 3 and years[year + 1] >= 3
               for year, count in list(years.items())):
            result.append(product)
    return result

C++17 · 本地语义参考（非本题提交接口）

#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

struct Order {
    int order_id, product_id, quantity;
    string purchase_date; // YYYY-MM-DD
};

vector<int> findValidProducts(const vector<Order>& orders) {
    unordered_map<int, unordered_map<int, int>> counts;
    for (const auto& o : orders) {
        ++counts[o.product_id][stoi(o.purchase_date.substr(0, 4))];
    }
    vector<int> result;
    for (const auto& [product, years] : counts) {
        for (const auto& [year, count] : years) {
            auto next = years.find(year + 1);
            if (count >= 3 && next != years.end() && next->second >= 3) {
                result.push_back(product);
                break;
            }
        }
    }
    return result;
}
