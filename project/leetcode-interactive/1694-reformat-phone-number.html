01 / Problem

题目说明

先规则，后策略

给定字符串 number，其中只含数字、空格和破折号。先移除所有空格与破折号；再从左到右每 3 个数字形成一块，直到只剩 4 个或更少的数字。最后的数字按下面规则分块，并用破折号连接全部块，返回格式化结果。

剩 2 位形成一个 2 位块
剩 3 位形成一个 3 位块
剩 4 位拆为两个 2 位块

最终不能出现长度为 1 的块，长度为 2 的块最多出现两个。

官方示例（完整参数形式）

示例 1 · 常规尾部

输入：number = "1-23-45 6"
输出："123-456"
说明：清洗为 "123456"，分成 123 与 456。

示例 2 · 四位尾部

输入：number = "123 4-567"
输出："123-45-67"
说明：清洗为 "1234567"，末 4 位拆成 45、67。

示例 3 · 两位尾部

输入：number = "123 4-5678"
输出："123-456-78"
说明：清洗为 "12345678"，末 2 位保留为 78。

约束

  • 2 <= number.length <= 100
  • number 只由数字、空格 ' ' 和破折号 '-' 组成。
  • number 中至少有 2 个数字。

04 / Solution

贪心分组题解

展开后可见

核心洞察

真正的决策点不是“当前能不能取 3 位”，而是“取完后会不会只剩 1 位”。因此只在剩余数字大于 4时不断取 3 位。循环结束只可能剩 2、3、4 位，分别按固定规则收尾。

完整过程

  1. 过滤空格与破折号，得到纯数字串。
  2. 维护指针 i；当 n - i > 4 时，加入长度为 3 的块并前进 3。
  3. 剩 4 位时加入两个 2 位块；否则将剩余的 2 或 3 位作为一块。
  4. 用 - 连接所有块。

为什么正确

循环阶段：每次取 3 位前剩余量大于 4，取后至少剩 2 位，所以不会制造最终的单字符块。

收尾阶段：循环结束时至多剩 4 位；输入保证至少两位数字，而循环始终留下至少两位，因此只需处理 2、3、4 三种情况。规则分别产生 2、3、2+2，都合法。

覆盖性：各块按原顺序、无重复无遗漏地覆盖清洗后的数字，连接结果正是所求格式。

边界与复杂度

  • 恰好 2 位：直接形成一个 2 位块。
  • 恰好 4 位：必须拆为 2 + 2，不能是 3 + 1。
  • 分隔符可连续、可位于首尾，过滤即可。
  • 时间复杂度 O(n)；构造纯数字串、块与答案需要 O(n) 额外空间。

替代方案

可先按 3 位切完整个字符串，再在最后一块只有 1 位时，把前一块末尾一位移给最后一块，形成两个 2 位块。它同样是 O(n)，但需要回退修改已有块；“剩余大于 4 才取 3 位”更直接地编码了约束。

面试追问与常见错误

  • 追问：若分组规则可配置？可把尾部合法拆分表参数化，再用贪心前缀或动态规划寻找合法划分。
  • 错误：无条件每 3 位分组，会把 4 位尾部变成 3 + 1。
  • 错误：只替换第一个空格或破折号；应过滤全部分隔符。
  • 错误：循环条件写成 >= 4，恰好 4 位时就会留下 1 位。

JavaStringBuilder
class Solution {
    public String reformatNumber(String number) {
        StringBuilder digits = new StringBuilder();
        for (char c : number.toCharArray()) {
            if (Character.isDigit(c)) {
                digits.append(c);
            }
        }

        StringBuilder answer = new StringBuilder();
        int i = 0;
        while (digits.length() - i > 4) {
            appendBlock(answer, digits.substring(i, i + 3));
            i += 3;
        }

        int remaining = digits.length() - i;
        if (remaining == 4) {
            appendBlock(answer, digits.substring(i, i + 2));
            appendBlock(answer, digits.substring(i + 2, i + 4));
        } else {
            appendBlock(answer, digits.substring(i));
        }
        return answer.toString();
    }

    private void appendBlock(StringBuilder answer, String block) {
        if (answer.length() > 0) answer.append('-');
        answer.append(block);
    }
}

/**

var reformatNumber = function(number) {
    const digits = number.replace(/[ -]/g, '');
    const blocks = [];
    let i = 0;

    while (digits.length - i > 4) {
        blocks.push(digits.slice(i, i + 3));
        i += 3;
    }

    const remaining = digits.length - i;
    if (remaining === 4) {
        blocks.push(digits.slice(i, i + 2));
        blocks.push(digits.slice(i + 2, i + 4));
    } else {
        blocks.push(digits.slice(i));
    }

    return blocks.join('-');
};

class Solution:
    def reformatNumber(self, number: str) -> str:
        digits = ''.join(ch for ch in number if ch.isdigit())
        blocks = []
        i = 0

        while len(digits) - i > 4:
            blocks.append(digits[i:i + 3])
            i += 3

        remaining = len(digits) - i
        if remaining == 4:
            blocks.append(digits[i:i + 2])
            blocks.append(digits[i + 2:i + 4])
        else:
            blocks.append(digits[i:])

        return '-'.join(blocks)
C++vector<string>
class Solution {
public:
    string reformatNumber(string number) {
        string digits;
        for (char c : number) {
            if (isdigit(static_cast<unsigned char>(c))) {
                digits.push_back(c);
            }
        }

        vector<string> blocks;
        int i = 0;
        while (static_cast<int>(digits.size()) - i > 4) {
            blocks.push_back(digits.substr(i, 3));
            i += 3;
        }

        int remaining = static_cast<int>(digits.size()) - i;
        if (remaining == 4) {
            blocks.push_back(digits.substr(i, 2));
            blocks.push_back(digits.substr(i + 2, 2));
        } else {
            blocks.push_back(digits.substr(i));
        }

        string answer;
        for (const string& block : blocks) {
            if (!answer.empty()) answer.push_back('-');
            answer += block;
        }
        return answer;
    }
};
