String Without AAA or BBB

题目

给定整数 a 和 b，返回任意字符串 s，使它的长度为 a + b，其中恰好有 a 个 'a' 和 b 个 'b'，并且既不含子串 "aaa"，也不含子串 "bbb"。

示例 1

输入：a = 1, b = 2
输出："abb"
解释："abb"、"bab" 和 "bba" 都是合法答案。

示例 2

输入：a = 4, b = 1
输出："aabaa"
约束
0 ≤ a, b ≤ 100
保证对给定的 a 和 b，至少存在一个合法答案。

完整题解

核心洞察

每次优先放剩余数量更多的字符，可以先消耗更容易堆积的一方；唯一的硬约束是：如果结果末尾已经是两个相同字符，本次必须选择另一个字符。题目保证有解，因此需要被强制选择的另一种字符一定可用。

完整过程

  1. 结果字符串初始为空。
  2. 若末尾是 aa，放 b；若末尾是 bb，放 a。
  3. 否则放剩余数量更多的字符；数量相同任选其一。
  4. 递减对应计数，直到两者都为零。

正确性证明

不产生禁用子串：算法每次添加字符前都会检查结果末尾。如果末尾已有两个 a，它不会再放 a；对 b 同理。因此任何一步都不会首次产生 aaa 或 bbb。

使用全部字符：每步恰好消耗一个仍有库存的字符。无三连风险时选择库存更多者；有风险时选择另一者。由于题目保证存在合法解，强制切换时不会陷入“另一者为零而当前字符又不能放”的状态。故循环最终恰好消耗全部 a+b 个字符，得到合法答案。

边界情况

  • 某个计数为 0：有解保证另一计数至多为 2。
  • 两者相等：任选一种开始。
  • 差距较大：规则自然形成 aab 或 bba 节奏。

复杂度

设 n = a + b。

时间复杂度 O(n)；除返回字符串外，额外空间为 O(1)（字符串构建器通常占 O(n) 输出空间）。

替代方案

可按较多字符每次取 2 个、较少字符取 1 个进行分组拼接。它同样线性，但分支和余数处理更繁琐；逐字符贪心更容易证明与泛化。

class Solution {
    public String strWithout3a3b(int a, int b) {
        StringBuilder ans = new StringBuilder(a + b);
        while (a > 0 || b > 0) {
            int n = ans.length();
            boolean mustB = n >= 2 && ans.charAt(n - 1) == 'a'
                    && ans.charAt(n - 2) == 'a';
            boolean mustA = n >= 2 && ans.charAt(n - 1) == 'b'
                    && ans.charAt(n - 2) == 'b';
            if (mustB || (!mustA && b > a)) {
                ans.append('b');
                b--;
            } else {
                ans.append('a');
                a--;
            }
        }
        return ans.toString();
    }
}

class Solution:
    def strWithout3a3b(self, a: int, b: int) -> str:
        ans = []
        while a > 0 or b > 0:
            must_b = len(ans) >= 2 and ans[-1] == ans[-2] == "a"
            must_a = len(ans) >= 2 and ans[-1] == ans[-2] == "b"
            if must_b or (not must_a and b > a):
                ans.append("b")
                b -= 1
            else:
                ans.append("a")
                a -= 1
        return "".join(ans)

                --b;

                --a;
            }
        }

面试追问

  • 若禁止连续 k 个相同字符，如何修改尾部检查？
  • 怎样在“保证有解”被移除后判断无解？
  • 若字符种类扩展到多种，能否用最大堆选择当前库存最多且不冲突的字符？

常见错误

  • 只选剩余较多者，却不检查尾部，产生三连。
  • 固定交替，遇到数量差距较大时无法用完库存。
  • 访问末尾两个字符前没有检查长度。
  • 误以为输出必须与示例完全一致；本题接受任意合法字符串。
