题解

一次扫描，只让“过去”与“现在”配对

核心不是寻找全局最小值与最大值本身，而是保证候选数来自不同数组。

01

只需数组两端

数组升序排列。若从某个数组选择一个数来拉大距离，最优选择一定可以落在该数组首元素或尾元素。

02

先算候选，再更新锚点

处理当前数组时，历史最小值与历史最大值只来自更早的数组，因此与当前端点组合天然满足“不同数组”。

完整过程

  1. 用第一个数组的首、尾元素初始化 minValue 与 maxValue。
  2. 从第二个数组开始，记当前首元素为 low，尾元素为 high。
  3. 计算两个合法候选：high - minValue 与 maxValue - low。
  4. 用候选更新答案后，再把当前数组端点并入历史范围。
  5. 扫描结束后返回答案。

不变量

进入第 i 轮时：

  • minValue 是数组 [0, i-1] 的最小首元素；
  • maxValue 是数组 [0, i-1] 的最大尾元素；
  • answer 已覆盖这些历史数组之间的最佳合法距离。

正确性证明

1
端点充分。

固定两个不同数组。从每个数组各选一个数时，绝对差最大值必由其中一个数组的最小值与另一个数组的最大值构成；内部元素不会产生更大距离。

2
每对数组都会被覆盖。

考虑最优答案来自数组 p 与 q，且 p < q。扫描到 q 时，数组 p 的端点已包含在历史最小/最大中，于是两个候选之一至少达到这对数组的最优距离。

3
候选始终合法。

候选计算发生在当前端点并入历史范围之前，所以候选的一端来自当前数组，另一端来自此前数组，绝不会从同一数组取两次。

4
结论。

算法既不会产生非法距离，又覆盖了最优数组对，因此最终答案就是题目所求最大距离。

边界情况

  • 仅两个单元素数组：算法仍在第二轮得到唯一合法距离。
  • 所有值相同：两个候选均为 0，答案正确保持 0。
  • 包含负数：有序性与减法方向保证候选非负，无需额外取绝对值。
  • 全局最小和全局最大在同一数组：先计算、后更新的顺序会避免非法配对。
  • 数组很多但总元素数受限：算法只读取每个数组两端。

复杂度

时间O(m)每个数组常数次操作
额外空间O(1)只维护三个标量

替代方案

可以收集每个数组的首尾端点后排序，再寻找来自不同数组的最远组合，但时间为 O(m log m)，还需额外空间。暴力枚举数组对为 O(m²)，无法通过 m = 10⁵。

四语言完整代码

均遵循官方函数签名；代码只读取每个数组的第一个与最后一个元素。

Java List<List<Integer>> 
class Solution {
    public int maxDistance(List<List<Integer>> arrays) {
        int minValue = arrays.get(0).get(0);
        List<Integer> first = arrays.get(0);
        int maxValue = first.get(first.size() - 1);
        int answer = 0;

        for (int i = 1; i < arrays.size(); i++) {
            List<Integer> current = arrays.get(i);
            int low = current.get(0);
            int high = current.get(current.size() - 1);

            answer = Math.max(answer, Math.max(high - minValue, maxValue - low));
            minValue = Math.min(minValue, low);
            maxValue = Math.max(maxValue, high);
        }
        return answer;
    }
}

        max_value = arrays[0][-1]

C++ vector<vector<int>> 
class Solution {
public:
    int maxDistance(vector<vector<int>>& arrays) {
        int minValue = arrays[0].front();
        int maxValue = arrays[0].back();
        int answer = 0;

        for (int i = 1; i < static_cast<int>(arrays.size()); ++i) {
            int low = arrays[i].front();
            int high = arrays[i].back();

            answer = max(answer, max(high - minValue, maxValue - low));
            minValue = min(minValue, low);
            maxValue = max(maxValue, high);
        }
        return answer;
    }
};

常见错误

  • 先更新历史最小/最大，再计算候选，可能让两个数来自当前同一数组。
  • 只计算 high - minValue，遗漏“历史最大减当前最小”的方向。
  • 遍历数组内所有元素，忽略了升序条件带来的端点性质。
  • 把全局最大减全局最小直接作为答案，未检查它们是否来自不同数组。

面试追问

  • 如果每个数组没有排序，应如何调整？可先线性寻找各数组的最小/最大，总时间仍为所有元素数之和。
  • 如果要求返回选中的数组下标和元素呢？为历史锚点与答案同步保存来源下标。
  • 为什么不需要绝对值？两个候选特意按“大减小”构造，结果天然非负。
  • 能否并行？可为分块维护最小/最大及块内答案，但合并时还要计算跨块候选。
