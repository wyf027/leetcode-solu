花园的最大总美丽值

Maximum Total Beauty of the Gardens

有限的花种，两种计分方式。你会怎样安排每一朵花？

独立思考 → 分步观察 → 题解官方题目 ↗

题意

给定长度为 n、下标从 0 开始的整数数组 flowers，第 i 个花园已有 flowers[i] 朵花。只能增种，不能移走已有的花；最多可以再种 newFlowers 朵，允许不全部用完。

花量达到或超过 target 的花园称为“完善花园”。另外给定两种分数系数 full 与 partial，请返回可获得的最大总美丽值。

总美丽值 = 完善花园数 × full + 不完善花园的最小花量 × partial

若所有花园都完善，第二项为 0。每个完善花园的得分与它超过 target 的花量无关。

约束

  • 1 ≤ flowers.length ≤ 10⁵
  • 1 ≤ flowers[i], target ≤ 10⁵
  • 1 ≤ newFlowers ≤ 10¹⁰
  • 1 ≤ full, partial ≤ 10⁵

官方示例

示例 1

flowers = [1,3,1,1]
newFlowers = 7
target = 6
full = 12
partial = 1

输出：14

可分别增加 [2,3,1,1] 朵，得到 [3,6,2,2]，共用 7 朵。1 个完善花园，剩余最低为 2，总分 1 × 12 + 2 × 1 = 14。

示例 2

flowers = [2,4,5,3]
newFlowers = 10
target = 5
full = 2
partial = 6

输出：30

可分别增加 [3,0,0,2] 朵，得到 [5,4,5,5]，只用 5 朵。3 个完善花园，剩余最低为 4，总分 3 × 2 + 4 × 6 = 30。全部完善反而只有 8 分。

先留一点思考空间

两个得分项会怎样相互影响？当预算充足时，是否一定要用完？准备好后，再展开推导与交互演示。

题解 · 固定完善数量，再抬高最低花量

核心洞察

把花量升序排列。若要增加固定数量的完善花园，优先完善原本花量最多的那些；它们组成后缀，剩余不完善花园组成前缀。这样可以用最少的完善成本，留下最多预算。

接着将不完善前缀中较低的花量一起“注水”抬高。最低花量最多只能到 target − 1，否则花园身份改变，partial 得分消失。

完整过程与公式


  1. 复制数组，将每个值截断到 target 后排序得到 a。截断仅用于计算，不代表移走实际的花。构造前缀和 pre[i] = a[0] + … + a[i−1]。
    2. 

  2. 设初始未完善数为 q，枚举剩余未完善数 m = q, q−1, …, 0。对应完善后缀为 a[m..n−1]，完善成本 spent 从 0 开始累加。
    3. 

  3. 如果 spent > newFlowers，当前及后续都不可行，可以结束。否则余量 rest = newFlowers − spent。
    4. 

  4. 若 m > 0，二分寻找最大的 j ∈ [1,m]，满足 a[j−1] × j − pre[j] ≤ rest。左边是把前 j 个花园抬到第 j 个花园高度的成本；这个成本随 j 单调不减。
    5. 

  5. 最低值可达到 level = min(target−1, floor((rest + pre[j]) / j))。未达下一台阶时，剩余预算均摊给前 j 个；整数取下整。若 m = 0，直接令 level = 0。
    6. 

  6. 更新答案 (n−m) × full + level × partial。若 m > 0，为下一轮追加 target − a[m−1] 的完善成本。


示例 2 的候选结果：m=3 → 26；m=2 → 28；m=1 → 30；m=0 → 8。足够的花并不意味着全部完善最优。






正确性论证
  1. 完善后缀的交换论证。若较小花园 x 完善而较大花园 y 不完善，可让 y 完善、让 x 达到原先 y 的最终花量。总增种量不增加，完善数量不变，剩余最小值不降低。重复交换得到完善后缀。
  2. 注水得到固定 m 的最优。要让最低花量达到 L，每个低于 L 的花园都必须补到 L，因此必要且充分成本为 Σ max(0,L−a[i])。前缀和二分定位可达到的最后一个台阶，再均摊预算，给出最大的整数 L，并用 target−1 保持不完善。
  3. 枚举完备。所有合法方案都有一个未完善数量 m。算法覆盖所有可行 m，并求出该 m 的最高得分，取最大即为全局最优。完善成本单调增加，预算不足后的剪枝不会漏解。


边界与复杂度
  • 全部原本完善：q=0，只计算 n × full。
  • target=1：约束下所有花园已经完善。
  • 只剩一座花园：比较完善得分与保留未完善的 partial 得分。
  • 预算非常大：仍要比较 m=1 与 m=0，允许剩余预算闲置。
  • 重复花量不影响二分；j=1 的成本总是 0。
  • 时间 O(n log n)：排序，加上每个 m 一次 O(log n) 二分。
  • 空间 O(n)：复制数组与前缀和。
  • 成本、前缀和与答案使用 64 位。JavaScript 所有整数中间量均在约 2 × 10¹⁰ 内，低于 2⁵³−1，可用 Number 精确表示。




替代方案与面试追问
也可直接二分最低花量 L，再通过二分找到低于 L 的前缀，用前缀和计算成本；时间为 O(n log target log n)，更直观但多一层搜索。
进一步优化：预计算注水台阶成本，利用 m 递减、rest 递减，维护只向左移动的台阶指针。排序后枚举可做到 O(n)，总体仍由 O(n log n) 排序主导。
追问：如何恢复具体种花方案？记录最优 m 与 level，将前缀补到 max(a[i], level)、后缀补到 target，并保留原始下标；不必分配剩余预算。
常见错误
  • 只看 full 和 partial 的大小，忽视 partial 乘的是最低花量。
  • 认为有足够预算就必须全部完善。
  • 把未完善最低值抬到 target，仍继续计算 partial。
  • m=0 时继续二分或除以 j，发生越界或除零。
  • 对 Java / C++ 先做 int 乘法再转 long，转换前已溢出。
  • 把排序截断当作真实减花操作；它只是等价计分表示。

JavaScript
/**
 * @param {number[]} flowers
 * @param {number} newFlowers
 * @param {number} target
 * @param {number} full
 * @param {number} partial
 * @return {number}
 */
var maximumBeauty = function(flowers, newFlowers, target, full, partial) {
    const a = flowers.map(x => Math.min(x, target)).sort((x, y) => x - y);
    const n = a.length, pre = Array(n + 1).fill(0);
    for (let i = 0; i < n; i++) pre[i + 1] = pre[i] + a[i];
    let m = n;
    while (m > 0 && a[m - 1] === target) m--;
    let spent = 0, ans = 0;
    for (; m >= 0; m--) {
        if (spent > newFlowers) break;
        const rest = newFlowers - spent;
        let level = 0;
        if (m > 0) {
            let lo = 1, hi = m;
            while (lo < hi) {
                const mid = Math.floor((lo + hi + 1) / 2);
                if (a[mid - 1] * mid - pre[mid] <= rest) lo = mid;
                else hi = mid - 1;
            }
            level = Math.min(target - 1, Math.floor((rest + pre[lo]) / lo));
        }
        ans = Math.max(ans, (n - m) * full + level * partial);
        if (m > 0) spent += target - a[m - 1];
    }
    return ans;
};

import java.util.Arrays;

class Solution {
    public long maximumBeauty(int[] flowers, long newFlowers,
                              int target, int full, int partial) {
        int n = flowers.length;
        int[] a = flowers.clone();
        for (int i = 0; i < n; i++) a[i] = Math.min(a[i], target);
        Arrays.sort(a);
        long[] pre = new long[n + 1];
        for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + a[i];
        int m = n;
        while (m > 0 && a[m - 1] == target) m--;
        long spent = 0, ans = 0;
        for (; m >= 0; m--) {
            if (spent > newFlowers) break;
            long rest = newFlowers - spent, level = 0;
            if (m > 0) {
                int lo = 1, hi = m;
                while (lo < hi) {
                    int mid = lo + (hi - lo + 1) / 2;
                    if ((long) a[mid - 1] * mid - pre[mid] <= rest) lo = mid;
                    else hi = mid - 1;
                }
                level = Math.min(target - 1L, (rest + pre[lo]) / lo);
            }
            ans = Math.max(ans, (long) (n - m) * full + level * partial);
            if (m > 0) spent += target - a[m - 1];
        }
        return ans;
    }
}

from typing import List

class Solution:
    def maximumBeauty(self, flowers: List[int], newFlowers: int,
                      target: int, full: int, partial: int) -> int:
        a = sorted(min(x, target) for x in flowers)
        n = len(a)
        pre = [0] * (n + 1)
        for i, x in enumerate(a):
            pre[i + 1] = pre[i] + x
        m = n
        while m > 0 and a[m - 1] == target:
            m -= 1
        spent = ans = 0
        for m in range(m, -1, -1):
            if spent > newFlowers:
                break
            rest = newFlowers - spent
            level = 0
            if m > 0:
                lo, hi = 1, m
                while lo < hi:
                    mid = (lo + hi + 1) // 2
                    if a[mid - 1] * mid - pre[mid] <= rest:
                        lo = mid
                    else:
                        hi = mid - 1
                level = min(target - 1, (rest + pre[lo]) // lo)
            ans = max(ans, (n - m) * full + level * partial)
            if m > 0:
                spent += target - a[m - 1]
        return ans


C++
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    long long maximumBeauty(vector<int>& flowers, long long newFlowers,
                            int target, int full, int partial) {
        vector<int> a = flowers;
        int n = a.size();
        for (int& x : a) x = min(x, target);
        sort(a.begin(), a.end());
        vector<long long> pre(n + 1, 0);
        for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + a[i];
        int m = n;
        while (m > 0 && a[m - 1] == target) --m;
        long long spent = 0, ans = 0;
        for (; m >= 0; --m) {
            if (spent > newFlowers) break;
            long long rest = newFlowers - spent, level = 0;
            if (m > 0) {
                int lo = 1, hi = m;
                while (lo < hi) {
                    int mid = lo + (hi - lo + 1) / 2;
                    if (1LL * a[mid - 1] * mid - pre[mid] <= rest) lo = mid;
                    else hi = mid - 1;
                }
                level = min(1LL * target - 1, (rest + pre[lo]) / lo);
            }
            ans = max(ans, 1LL * (n - m) * full + level * partial);
            if (m > 0) spent += target - a[m - 1];
        }
        return ans;
    }
};
