01 / THE TASK

题目与数据契约

给定销售明细表 Sales 和商品价格表 Product，返回每位有购买记录的用户的总消费额。结果包含 user_id 和 spending 两列：消费额从大到小排列；金额相同则按用户 ID 从小到大排列。

约束

  • Sales.sale_id 唯一，Product.product_id 唯一。
  • Sales.product_id 是指向 Product 的外键，每条销售记录都能找到商品。
  • 同一用户可以多次购买同一商品，各条销售记录都要计算。
  • 可获取题面没有另列行数、数量或价格的数值上下界；这里不补造范围。

04 / SOLUTION LAB

准备好再展开题解

账单推演、正确性说明与五份完整代码。

给明细补上价格，再按用户结账

核心洞察：数量在销售明细中，价格在商品表中。一次购买的消费额是 quantity × price；连接商品价格后，将属于同一用户的消费额相加。用户是聚合键，商品是查价键。

完整过程

  1. 通过 product_id 等值连接两表，每条销售记录得到唯一单价。
  2. 逐行计算 quantity × price。
  3. 按 user_id 分组求和，结果列命名为 spending。
  4. 按 spending DESC, user_id ASC 排列。

正确性

商品键唯一且外键有效，每条明细恰好连接一个单价，不丢失也不复制记录；乘积等于该笔消费。

处理前 k 条记录后，每位用户的累计值等于这 k 条记录中属于该用户的金额之和。初始空集合成立；加入下一笔只增加它所属用户的金额，性质保持。全部处理后便是每位用户的总消费。

SQL 的分组求和完成同样的归并。最后先比较消费额、再比较用户 ID，满足题目要求的两级排序。

边界与常见错误

  • 重复购买仍是不同明细，不可使用 SUM(DISTINCT ...) 去掉等额消费。
  • 按商品分组会得到商品销售额；本题要求用户消费额。
  • SUM(quantity) × SUM(price) 会错误地交叉放大金额，应逐行相乘后求和。
  • 不可漏掉金额相同时的用户 ID 升序。
  • 空销售表返回空结果；没有用户全集，不能补出零消费用户。
  • 若业务允许空值或缺失商品，须另定规则；题目外键关系下不需要额外兜底。

复杂度与数值范围

令 N 为销售行数，M 为商品行数，U 为有销售记录的用户数。哈希查价、哈希聚合与结果排序的期望时间为 O(M + N + U log U)，额外空间为 O(M + U)。SQL 的真实成本受索引、连接算法和聚合策略影响，上式不是对所有执行计划的保证。

本地代码假定输入满足表的唯一性和外键约束。Python 使用任意精度整数；JavaScript 使用 BigInt。Java / C++ 采用 64 位金额并检查溢出，超出范围需改用任意精度。SQL 的超大金额可在乘法前转换为足够精度的 DECIMAL，避免中间结果溢出。

替代方案

先按 (user_id, product_id) 汇总数量，再连接商品价格并按用户求和，也能得到相同结果。大量重复购买时可减少连接行数，但多一次聚合。本题直接连接后求和更简洁。本地逐笔遍历全部商品需要 O(NM)，哈希查价可避免这个开销。

面试追问

  • 商品涨价怎么办？题面只有一份单价。真实历史账单需要成交单价，或带有效期的价格表与成交时间。
  • 怎样列出没买过东西的用户？需要用户全集表，左连接消费汇总，再将空金额转为 0。
  • 数据变大怎样优化？查看执行计划，确认商品键索引、连接行数和聚合内存，再决定是否预聚合。

SELECT s.user_id, SUM(s.quantity * p.price) AS spending
FROM Sales AS s
JOIN Product AS p ON s.product_id = p.product_id
GROUP BY s.user_id
ORDER BY spending DESC, s.user_id ASC;

Java · 本地语义参考

import java.util.*;

public class Main {
    // Sales: [sale_id, product_id, user_id, quantity]
    // Product: [product_id, price]
    static List<long[]> productSalesAnalysis(long[][] sales, long[][] product) {
        Map<Long, Long> prices = new HashMap<>();
        for (long[] p : product) prices.put(p[0], p[1]);
        Map<Long, Long> totals = new HashMap<>();
        for (long[] s : sales) {
            long cost = Math.multiplyExact(s[3], prices.get(s[1]));
            long old = totals.getOrDefault(s[2], 0L);
            totals.put(s[2], Math.addExact(old, cost));
        }
        List<long[]> result = new ArrayList<>();
        totals.forEach((user, amount) -> result.add(new long[]{user, amount}));
        result.sort((a, b) -> {
            int byAmount = Long.compare(b[1], a[1]);
            return byAmount != 0 ? byAmount : Long.compare(a[0], b[0]);
        });
        return result;
    }
    public static void main(String[] args) {
        long[][] sales = {{1,1,101,10},{2,2,101,1},{3,3,102,3},
                          {4,3,102,2},{5,2,103,3}};
        long[][] product = {{1,10},{2,25},{3,15}};
        for (long[] row : productSalesAnalysis(sales, product))
            System.out.println(Arrays.toString(row));
    }
}

// 整数参数使用十进制字符串，避免 Number 精度损失。
// Sales: [sale_id, product_id, user_id, quantity]
// Product: [product_id, price]
function productSalesAnalysis(sales, product) {
  const prices = new Map(product.map(([id, price]) => [id, BigInt(price)]));
  const totals = new Map();
  for (const [, productId, userId, quantity] of sales) {
    const amount = BigInt(quantity) * prices.get(productId);
    totals.set(userId, (totals.get(userId) ?? 0n) + amount);
  }
  return [...totals].sort((a, b) => {
    if (a[1] !== b[1]) return a[1] > b[1] ? -1 : 1;
    const x = BigInt(a[0]), y = BigInt(b[0]);
    return x < y ? -1 : x > y ? 1 : 0;
  }).map(([userId, spending]) => ({
    user_id: userId, spending: spending.toString()
  }));
}

def product_sales_analysis(sales, product):
    # sales: [sale_id, product_id, user_id, quantity]
    # product: [product_id, price]
    prices = dict(product)
    totals = {}
    for _, product_id, user_id, quantity in sales:
        amount = quantity * prices[product_id]
        totals[user_id] = totals.get(user_id, 0) + amount
    return [
        {"user_id": user, "spending": amount}
        for user, amount in sorted(totals.items(), key=lambda row: (-row[1], row[0]))
    ]

C++ · 本地语义参考（C++17）

#include <algorithm>
#include <array>
#include <iostream>
#include <limits>
#include <stdexcept>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;
using i64 = long long;

// Sales: [sale_id, product_id, user_id, quantity]
// Product: [product_id, price]
vector<pair<i64, i64>> productSalesAnalysis(
    const vector<array<int, 4>>& sales,
    const vector<array<int, 2>>& product) {
    unordered_map<int, int> prices;
    for (const auto& p : product) prices[p[0]] = p[1];
    unordered_map<int, i64> totals;
    for (const auto& s : sales) {
        i64 cost = static_cast<i64>(s[3]) * prices.at(s[1]);
        i64 old = totals[s[2]];
        if ((cost > 0 && old > numeric_limits<i64>::max() - cost) ||
            (cost < 0 && old < numeric_limits<i64>::min() - cost))
            throw overflow_error("spending exceeds int64");
        totals[s[2]] = old + cost;
    }
    vector<pair<i64, i64>> result(totals.begin(), totals.end());
    sort(result.begin(), result.end(), [](const auto& a, const auto& b) {
        return a.second != b.second ? a.second > b.second : a.first < b.first;
    });
    return result;
}
int main() {
    vector<array<int, 4>> sales = {{1,1,101,10},{2,2,101,1},{3,3,102,3},
                                    {4,3,102,2},{5,2,103,3}};
    vector<array<int, 2>> product = {{1,10},{2,25},{3,15}};
    for (auto [user, spending] : productSalesAnalysis(sales, product))
        cout << user << " " << spending << '\n';
}
