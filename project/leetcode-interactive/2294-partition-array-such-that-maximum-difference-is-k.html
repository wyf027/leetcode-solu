划分数组使最大差为 K

Partition Array Such That Maximum Difference Is K

把所有元素分好组，让每组的数值跨度不超过限制。你能用最少几组完成？

官方题目 ↗

01 / 题目

给定整数数组 nums 和整数 k，把数组中的元素分配给一个或多个非空子序列。每个元素必须且只能分配一次，每个子序列都要满足 最大值 − 最小值 ≤ k。返回能做到的最少子序列数量。

子序列允许跳过元素，但要保持所选元素在原数组中的相对顺序；它不必是连续子数组。单个元素的最大差为 0。

参数与返回值

partitionArray(nums, k) → integer

nums：整数数组；k：允许的最大差；返回最少组数。

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁵
  • 0 ≤ k ≤ 10⁵

02 / 官方示例

示例 1

输入：nums = [3,6,1,2,5], k = 2
输出：2

可分成 [3,1,2] 和 [6,5]，最大差分别为 2 和 1。两组已经最少。

示例 2

输入：nums = [1,2,3], k = 1
输出：2

可以选 [1,2] 与 [3]，最大差为 1 和 0；[1] 与 [2,3] 也是最优划分。

示例 3

输入：nums = [2,2,4,5], k = 0
输出：3

可分成 [2,2]、[4]、[5]，每组最大差均为 0，最少需要三组。

04 / 准备好揭开思路了吗？

展开后可查看分组边界演示、正确性推导及四语言实现。

题解 / 最小值固定一扇宽度为 k 的窗

核心洞察

组是否合法只取决于最小值和最大值，与中间元素的排列无关。先将值升序排列：从尚未分组的最小值 start 出发，把所有不超过 start + k 的值放入同一组，再从下一个值开始。

排序只用来决定分组归属。把每组元素按原下标排列，就得到合法的原数组子序列，因此排序并未改变问题的可行划分。

完整过程

  1. 升序排序，令组数为 1，当前组最小值为第一个元素。
  2. 依次检查后续元素 x。若 x − start ≤ k，就加入当前组，start 不变。
  3. 若 x − start > k，则必须在此处开启新组：组数加一，start = x。
  4. 遍历结束返回组数。

示例 1 排序得到 [1,2,3,5,6]。以 1 为起点的窗口是 [1,3]，收下 1、2、3；5 超过 3，开启 [5,7]，收下 5、6。映射回原数组得到 [3,1,2] 和 [6,5]，答案为 2。

正确性：交换论证与剩余问题

令 m 是尚未分配的最小值。在任意最优划分中，含 m 的组不能包含大于 m+k 的值。把其他组中所有落在 [m,m+k] 内的元素移入含 m 的组：该组仍合法，其他组只删元素，最大差不会变大；空组可以删去，所以组数不会增加。按原下标恢复次序后，各组仍是子序列。

因此存在一个最优解，其第一组恰好包含整个 [m,m+k] 范围内的剩余元素，这正是贪心选择。删除第一组后，余下元素构成同样的问题，重复上述交换即可得到最优后缀。归纳可知所有贪心分组合起来具有最少组数。每组的实际最大差也始终不超过 k。

边界

  • n = 1：返回 1；空数组不在约束内。
  • k = 0：只有相同值可以同组，答案等于不同值个数。
  • 全局最大差 ≤ k：一组足够。
  • 差值恰好为 k 时仍可加入当前组。
  • 重复值逐个归组，不丢失元素。

复杂度与修改输入

排序耗时 O(n log n)，扫描 O(n)；扫描本身额外空间 O(1)。下面四份实现均直接排序并修改 nums。

完整排序辅助空间取决于库实现：Java 常见原始类型排序和 C++ sort 通常使用 O(log n) 栈空间；Python 排序最坏 O(n)；JavaScript 由引擎决定，常见实现为 O(n)。若先复制数组以保护输入，额外需要 O(n) 空间。

替代方案

  • 值域扫描：利用 nums[i] ≤ 10⁵，用布尔或计数数组记录出现过的值，升序扫描非空位置并使用同样的窗口分组。O(n+U) 时间、O(U) 空间，U 为值域大小；相同值不会增加组数。
  • 排序后动态规划：枚举最后一组的起点，满足 a[i]−a[j] ≤ k 时用 dp[j]+1 更新前缀答案。朴素做法 O(n²)，可用于理解，但在 n = 10⁵ 时不适合提交；本题交换性质让贪心更直接。

常见错误

  • 只比较相邻差：[1,3,5]、k=2 中相邻差都为 2，但整体跨度为 4。
  • 加入元素后更新 start：start 必须一直是本组最小值，只有新建组才更新。
  • 用 ≥ k 分组：应是 > k，等于上限仍合法。
  • 误认为必须切连续子数组：题目要求的是子序列。
  • JavaScript 省略数值比较器：默认 sort 按字符串排序，必须传入 (a,b) => a-b。

面试追问

  • 如何返回实际子序列？排序值与原下标的二元组，记录每个下标的组号，再按原数组次序向对应结果组追加。
  • 如果改成连续子数组？不能排序；保持原顺序维护当前段最小值和最大值，加入后超限就从该元素开新段。
  • 负数还适用吗？排序和差值逻辑不变；扩展到大整数时需要注意减法溢出。
  • k 变大答案会如何变化？答案单调不增，因为原先合法的分组在更大上限下仍合法。

Java

import java.util.Arrays;

class Solution {
    public int partitionArray(int[] nums, int k) {
        Arrays.sort(nums);
        int groups = 1, start = nums[0];
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] - start > k) {
                groups++;
                start = nums[i];
            }
        }
        return groups;
    }
}

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int partitionArray(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int groups = 1, start = nums[0];
        for (int i = 1; i < static_cast<int>(nums.size()); ++i) {
            if (nums[i] - start > k) {
                ++groups;
                start = nums[i];
            }
        }
        return groups;
    }
};
