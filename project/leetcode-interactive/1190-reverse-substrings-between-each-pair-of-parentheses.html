反转每对括号间的子串

一串字符被多层括号包住。每对括号都会让其中的内容改变方向——从最内层开始，最终还原出一个不含括号的新字符串。

中等 栈 字符串 括号序列
01 / Challenge

题目说明

给定字符串 s，其中只包含小写英文字母和括号。按照从内到外的层次，反转每一对匹配括号内部的字符串；返回最终结果，结果中不能保留任何括号。

函数签名

reverseParentheses(s: string): string

输入：字符串 s　·　返回：去掉括号后的最终字符串

约束

  • 1 <= s.length <= 2000
  • s 仅含小写英文字母和括号。
  • 所有括号都保证正确配对。

准备好看题解了吗？

先自己想一想：有没有办法不真的反转任何中间字符串？

核心洞察 · 括号是传送门

先用栈记录每对括号的两个下标。第二次扫描时，把一对括号看成连接两个端点的传送门：遇到括号就跳到它的配对位置，同时把移动方向反转。遇到字母则追加到答案。这样，每个字母会自然地按最终顺序被访问一次。

完整过程

  1. 从左到右扫描；左括号下标入栈，右括号与栈顶左括号建立双向配对。
  2. 令位置 i = 0、方向 dir = 1。
  3. 若当前位置是字母，将它加入答案。
  4. 若当前位置是括号，跳到配对括号，并令 dir = -dir。
  5. 每轮执行 i += dir；越界时结束。

正确性

进入一对括号时，跳到另一端并反向行走，恰好以相反顺序访问该括号内的内容；离开时再次跳转并恢复原方向。嵌套括号会重复同一规则，因此从内到外的每次反转都被遍历方向隐式表达。括号本身从不加入答案，所以得到的正是题目要求的最终字符串。

边界与复杂度

  • 无括号：始终向右，原样输出。
  • 只有一对或连续嵌套：跳转与方向翻转仍适用。
  • 时间复杂度：O(n)；每个位置至多访问一次。
  • 空间复杂度：O(n)；配对数组、栈与答案。

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String reverseParentheses(String s) {
        int n = s.length();
        int[] pair = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else if (s.charAt(i) == ')') {
                int left = stack.pop();
                pair[left] = i;
                pair[i] = left;
            }
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0, direction = 1; i >= 0 && i < n; i += direction) {
            char current = s.charAt(i);
            if (current == '(' || current == ')') {
                i = pair[i];
                direction = -direction;
            } else {
                answer.append(current);
            }
        }
        return answer.toString();
    }
}

class Solution:
    def reverseParentheses(self, s: str) -> str:
        pair = [-1] * len(s)
        stack = []

        for i, char in enumerate(s):
            if char == '(':
                stack.append(i)
            elif char == ')':
                left = stack.pop()
                pair[left] = i
                pair[i] = left

        answer = []
        i, direction = 0, 1
        while 0 <= i < len(s):
            if s[i] in '()':
                i = pair[i]
                direction = -direction
            else:
                answer.append(s[i])
            i += direction

        return ''.join(answer)
class Solution {
public:
    string reverseParentheses(string s) {
        int n = static_cast<int>(s.size());
        vector<int> pair(n, -1);
        stack<int> opened;

        for (int i = 0; i < n; ++i) {
            if (s[i] == '(') {
                opened.push(i);
            } else if (s[i] == ')') {
                int left = opened.top();
                opened.pop();
                pair[left] = i;
                pair[i] = left;
            }
        }

        string answer;
        for (int i = 0, direction = 1;
             i >= 0 && i < n;
             i += direction) {
            if (s[i] == '(' || s[i] == ')') {
                i = pair[i];
                direction = -direction;
            } else {
                answer.push_back(s[i]);
            }
        }
        return answer;
    }
};

替代方案

也可以用“字符串栈”：遇到左括号时保存当前结果并清空；遇到右括号时反转当前片段，再与栈顶前缀拼接。写法直观，但反复反转和拼接在某些语言中可能达到 O(n²)。括号传送门方案能稳定做到线性时间。

面试追问

  • 如果括号可能不合法，怎样在配对阶段报告错误？
  • 为什么改变方向后，每个下标仍只会访问一次？
  • 若输入是字符流而非完整字符串，线性跳转方案还能直接使用吗？

常见错误

  • 跳到配对括号后忘记反转方向。
  • 在跳转后额外移动两次，导致漏掉相邻字符。
  • 把括号本身追加到答案。
  • 用不可变字符串反复头插或拼接，退化为平方复杂度。

一句话记忆

先配对，再穿越：碰到括号就跳到另一端并掉头，碰到字母就收集。
