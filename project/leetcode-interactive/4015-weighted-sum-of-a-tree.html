4015. 树的加权和

先用层序遍历量出树高 h，再把每个节点的值乘上 h - depth + 1。越靠近根，剩余层数越多，权重也越大。

核心不变量

  1. 01 队列中的节点恰好处于同一深度。
  2. 02 每处理完一批节点，深度加一；最后的深度就是树高。
  3. 03 建 children 邻接表，因此 parent 数组的编号顺序不影响正确性。
  4. 04 使用 64 位整数：最大答案约为 1016。

等价公式

Σ nums[i] × (h - depth[i] + 1)。BFS 中可先累加 nums[i] × (1 - depth)，遍历结束再加 h × Σ nums[i]，无需保存每个深度。

题意与完整过程

给定以 0 为根的 parent 和节点值 nums。根的深度是 1；树高是最大深度。节点 i 的权重为 nums[i] × (h - depth[i] + 1)，求权重之和。

第 1 步：扫描 parent[1..n-1]，将每个节点挂到其父节点的 children 列表。

第 2 步：从根做 BFS。每轮队列长度固定，这批节点共享当前深度；入队它们的孩子。

第 3 步：BFS 结束获得 h。将每个节点的深度代入公式；或使用右侧等价公式在线累加。

边界、替代与追问

  • 单节点：h = depth = 1，答案就是 nums[0]。
  • 链：树高等于 n，根的系数最大；应避免递归 DFS 的栈溢出。
  • 编号乱序：例如 [-1,0,3,1] 仍是合法树，不能假设 parent[i] < i。
  • 替代方案：迭代 DFS 保存 (node, depth) 也可；BFS 更直接得到逐层树高。
  • 面试追问：若只问“按深度的加权值”，BFS 可边遍历边累计；若边会动态修改，需要维护树高和受影响子树的深度。

隐藏题解与常见错误

正确性：BFS 的第 d 轮只包含深度 d 的节点，遍历结束的轮数就是 h。因此每项都按定义乘以 h - d + 1；总和正是题目要求。

复杂度：建图与遍历各访问每个节点一次，时间 O(n)，邻接表和队列空间 O(n)。

常见错误：把根深度误设为 0；先按数组下标推深度；使用 int 导致溢出；递归遍历深链；把 parent 数组当作按拓扑顺序排列。
