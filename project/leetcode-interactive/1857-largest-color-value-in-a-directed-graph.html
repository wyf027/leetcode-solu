有向图中最大颜色值

Largest Color Value in a Directed Graph

沿箭头走出一条路径，观察哪一种颜色出现得最多。你的任务是找到全图的最大值。

01 / PROBLEM

题意与输入

图有 n 个节点，编号为 0 到 n − 1。字符串 colors 的第 i 个字符是节点 i 的颜色；edges[j] = [aⱼ, bⱼ] 表示一条从 aⱼ 指向 bⱼ 的有向边。

有效路径中，相邻节点必须由同方向的边连接。路径的颜色值等于这条路径中出现次数最多的颜色的节点数。返回所有有效路径的最大颜色值；只要图的任何位置存在有向环，就返回 −1。一个节点也可以单独构成路径。

largestPathValue(colors, edges) → integer

颜色值统计相同字母的次数，不要求这些节点在路径中连续。

官方约束

  • n == colors.length，m == edges.length
  • 1 ≤ n ≤ 10⁵，0 ≤ m ≤ 10⁵
  • colors 仅含小写英文字母。
  • 0 ≤ aⱼ, bⱼ < n

04 / SOLUTION

准备好再揭晓

包含逐步演示、证明与四语言实现。

核心洞察：每个终点保留 26 个答案

一条路径很长，并不代表某种颜色很多。为每个节点 v 保留 dp[v][c]：在所有以 v 结尾的路径里，颜色 c 最多出现几次。26 个分量可以来自不同路径，不能将它们相加解释成同一条路径。

先为每个节点自身的颜色置 1，其余置 0。对边 u → v，将每种颜色分别传递：

dp[v][c] = max(dp[v][c], dp[u][c] + (colors[v] == c ? 1 : 0))

只有处理完所有前驱，v 的结果才确定。因此用 Kahn 拓扑排序：每次取剩余入度为 0 的节点。若最后处理节点数不足 n，图中就有环。

INTERACTIVE / 入度与颜色一起流动

拓扑传播实验台

每步处理一个出队动作或一条边。边传播时先取逐色最大值，再减少入度；入度归零才进入队列。演示是教学状态回放，不代表执行验证。

节点文字：编号 / 颜色；绿色粗边框 = 当前节点，虚线边框 = 已处理。橙色边 = 本步传播。

就绪队列 / 统计

表中仅展示该场景出现的颜色，其余分量始终为 0。未出队节点的 DP 是暂存值。

每个终点的颜色计数

完整过程

  1. 建立邻接表并统计每个节点的入度，为每个节点建立 26 维计数，自身颜色置 1。
  2. 把所有入度为 0 的节点放入队列，包括孤立节点和不同连通分量的起点。
  3. 弹出 u，处理数加 1，用 u 的 26 维 DP 更新全局答案。
  4. 遍历 u 的每一条出边 u → v，对 26 种颜色做上述转移；v 的剩余入度减 1，减到 0 时入队。
  5. 队列耗尽后，若处理数等于 n，返回全局最大值；否则返回 −1。

在示例 1 中，颜色 a 的计数沿 0 → 2 → 3 → 4 依次为 1、2、2、3。节点 3 是 c，不增加 a 的次数；节点 4 是 a，才再加 1。

为什么正确

起点：单节点路径合法，初始化为自身颜色 1、其他颜色 0，覆盖所有路径的起始情况。

归纳：假设所有已出队节点的 DP 都正确。节点 v 出队时，所有前驱都已处理。以 v 结尾的路径要么只有 v，要么由某个前驱 u 的路径接上 v。每种颜色分别取所有前驱转移的最大值，恰好枚举了这两类可能，因此 v 的每个分量正确。

全局最大值：所有路径都有终点，路径颜色值又是各颜色频次的最大值，所以取所有终点、所有颜色的最大值就是所求。

判环：有向无环图总能在剩余子图中找到零入度节点，故会处理全部节点。若剩余节点都非零入度，沿前驱反复追溯必然重复节点，形成有向环。反之，环上的节点无法被全部移除。因此 processed < n 与存在环等价。

复杂度

时间：O(26(n + m))。每个节点检查 26 个分量，每条边进行 26 次转移。

空间：O(26n + n + m)。用于 DP、邻接表、入度与队列。字母表固定时可写作 O(n + m)。

边界与常见错误

  • 无边或单节点无环时答案为 1。
  • 自环、其他分量的环都必须返回 −1。
  • 汇合处取 max，不能把不同前驱相加。
  • 不能只保留每个节点的单个最大值，会丢失颜色信息。
  • 当前实现已在初始化计入自身，出队时不要再次加 1。
  • 重复边按边逐一计入和扣减入度即可。
  • JavaScript 用队头索引，避免反复 shift 的搬移开销。

替代方案与面试追问

  • DFS + 三色判环 + 记忆化：定义从 u 出发的每色最大计数，后序合并子节点。复杂度相同，但深度可能达到 10⁵，递归实现有栈溢出风险，Kahn 队列更稳妥。
  • 只计算一种颜色能否降空间？先得到完整拓扑序并判环，再对每个颜色单独做一维 DP。总时间仍为 O(26(n + m))，DP 工作空间可降到 O(n)。
  • 如何还原路径？为每个 (v,c) 保存令计数改进的前驱，记录取得最大值的终点和颜色，再沿该颜色的前驱链回溯。
  • 字母表扩大到 K 种怎么办？稠密表时间变为 O(K(n + m))、DP 空间 O(Kn)。可以先压缩实际出现的颜色；稀疏映射仍可能在最坏情况下变稠密。
  • 能不能枚举所有路径？即使无环，路径数量也可能指数增长；DP 只保留影响后续转移的每色最优计数。

import java.util.*;

class Solution {
    public int largestPathValue(String colors, int[][] edges) {
        int n = colors.length();
        List<List<Integer>> graph = new ArrayList<>(n);
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        int[] indegree = new int[n];
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            indegree[e[1]]++;
        }
        int[][] dp = new int[n][26];
        ArrayDeque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            dp[i][colors.charAt(i) - 'a'] = 1;
            if (indegree[i] == 0) queue.addLast(i);
        }
        int processed = 0, answer = 0;
        while (!queue.isEmpty()) {
            int u = queue.removeFirst();
            processed++;
            for (int c = 0; c < 26; c++)
                answer = Math.max(answer, dp[u][c]);
            for (int v : graph.get(u)) {
                int color = colors.charAt(v) - 'a';
                for (int c = 0; c < 26; c++) {
                    dp[v][c] = Math.max(dp[v][c],
                        dp[u][c] + (c == color ? 1 : 0));
                }
                if (--indegree[v] == 0) queue.addLast(v);
            }
        }
        return processed == n ? answer : -1;
    }
}

var largestPathValue = function(colors, edges) {
    const n = colors.length;
    const graph = Array.from({ length: n }, () => []);
    const indegree = new Int32Array(n);
    for (const [u, v] of edges) {
        graph[u].push(v);
        indegree[v]++;
    }
    const dp = Array.from({ length: n }, () => new Int32Array(26));
    const queue = [];
    for (let i = 0; i < n; i++) {
        dp[i][colors.charCodeAt(i) - 97] = 1;
        if (indegree[i] === 0) queue.push(i);
    }
    let head = 0, answer = 0;
    while (head < queue.length) {
        const u = queue[head++];
        for (let c = 0; c < 26; c++)
            answer = Math.max(answer, dp[u][c]);
        for (const v of graph[u]) {
            const color = colors.charCodeAt(v) - 97;
            for (let c = 0; c < 26; c++) {
                dp[v][c] = Math.max(dp[v][c],
                    dp[u][c] + (c === color ? 1 : 0));
            }
            if (--indegree[v] === 0) queue.push(v);
        }
    }
    return head === n ? answer : -1;
};

Python 3

from collections import deque
from typing import List

class Solution:
    def largestPathValue(self, colors: str, edges: List[List[int]]) -> int:
        n = len(colors)
        graph = [[] for _ in range(n)]
        indegree = [0] * n
        for u, v in edges:
            graph[u].append(v)
            indegree[v] += 1

        dp = [[0] * 26 for _ in range(n)]
        queue = deque()
        for i, color in enumerate(colors):
            dp[i][ord(color) - ord('a')] = 1
            if indegree[i] == 0:
                queue.append(i)

        processed = answer = 0
        while queue:
            u = queue.popleft()
            processed += 1
            answer = max(answer, max(dp[u]))
            for v in graph[u]:
                color = ord(colors[v]) - ord('a')
                for c in range(26):
                    dp[v][c] = max(dp[v][c], dp[u][c] + int(c == color))
                indegree[v] -= 1
                if indegree[v] == 0:
                    queue.append(v)

        return answer if processed == n else -1

#include <algorithm>
#include <array>
#include <queue>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int largestPathValue(string colors, vector<vector<int>>& edges) {
        int n = static_cast<int>(colors.size());
        vector<vector<int>> graph(n);
        vector<int> indegree(n, 0);
        for (const auto& e : edges) {
            graph[e[0]].push_back(e[1]);
            ++indegree[e[1]];
        }
        vector<array<int, 26>> dp(n);
        queue<int> q;
        for (int i = 0; i < n; ++i) {
            dp[i].fill(0);
            dp[i][colors[i] - 'a'] = 1;
            if (indegree[i] == 0) q.push(i);
        }
        int processed = 0, answer = 0;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            ++processed;
            for (int c = 0; c < 26; ++c)
                answer = max(answer, dp[u][c]);
            for (int v : graph[u]) {
                int color = colors[v] - 'a';
                for (int c = 0; c < 26; ++c)
                    dp[v][c] = max(dp[v][c], dp[u][c] + (c == color));
                if (--indegree[v] == 0) q.push(v);
            }
        }
        return processed == n ? answer : -1;
    }
};
