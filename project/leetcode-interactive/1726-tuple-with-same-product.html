Tuple with Same Product

核心目标

从互不相同的正整数中，统计所有满足 a × b = c × d 且四个元素互异的有序四元组。

O(n²)
时间
O(n²)
最坏空间

题意

官方参数：nums: integer[] → integer

给定一个由互不相同的正整数组成的数组 nums。返回有序元组 (a, b, c, d) 的数量：四个值都来自数组、彼此不同，并满足 a × b = c × d。

示例 1
输入：nums = [2,3,4,6]
输出：8
解释：2×6 = 3×4，共产生 8 种有序排列。
示例 2
输入：nums = [1,2,4,5,10]
输出：16
解释：1×10 = 2×5，2×10 = 4×5；
每组相等乘积贡献 8 个有序元组。

约束

1 ≤ nums.length ≤ 1000；1 ≤ nums[i] ≤ 10⁴；nums 中的元素互不相同。

Complete Solution

用乘积做桶，边扫描边计数

核心洞察

枚举每个下标对 i < j，把乘积 nums[i] × nums[j] 作为哈希表的键。若当前乘积此前出现了 k 次，当前数对能与此前每个数对组成一组等积数对，因此新增 k × 8 个有序元组。

为什么是 8？

对两对数 {a,b} 与 {c,d}：左右两对可交换（2 种），每一对内部也可交换（2 × 2 种），总计 2 × 2 × 2 = 8。

完整过程

  1. 创建哈希表 count，记录每个乘积已经由多少个无序数对产生；答案初始化为 0。
  2. 使用两层循环枚举所有 i < j，保证每个无序数对只出现一次。
  3. 计算乘积 p。若 count[p] = k，把 8k 加入答案。
  4. 将 count[p] 加一，让后续同乘积数对可以与当前数对配对。

正确性证明

完备性：任意合法元组对应两组乘积相同的无序数对。枚举到较晚那一对时，较早一对已被记录，算法会计入这组组合产生的 8 个排列。

唯一性：每个无序数对仅由 i < j 枚举一次；两对的组合只在第二对到达时计数一次。其 8 种排列互异，因此既不遗漏也不重复。

四元素互异：数组元素互不相同。若两个等积数对共享一个正数，约去该数后另一元素必须相同，两对便完全相同；不同数对不可能只共享一个元素。因此发生乘积碰撞的两对自然包含四个不同元素。

边界与复杂度

  • 少于 4 个元素或没有重复乘积时，答案为 0。
  • 所有值为正数，不涉及零导致的大量特殊碰撞。
  • 最大乘积为 10⁸，32 位有符号整数可容纳；答案上界也符合题目返回类型。
  • 共枚举 n(n−1)/2 个数对，时间复杂度 O(n²)。
  • 哈希表最坏存储 O(n²) 个不同乘积。

替代方案

可以先统计所有乘积频次，再对每个频次 f 计算 C(f,2) × 8。它同样是 O(n²)，但需要第二轮遍历哈希表。把所有数对按乘积排序后统计连续段也可行，时间会变为 O(n² log n)，通常不如哈希表直接。

完整代码

Java可提交
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int tupleSameProduct(int[] nums) {
        Map<Integer, Integer> count = new HashMap<>();
        int answer = 0;

        for (int i = 0; i < nums.length; i++) {
            for (int j = i + 1; j < nums.length; j++) {
                int product = nums[i] * nums[j];
                int seen = count.getOrDefault(product, 0);
                answer += seen * 8;
                count.put(product, seen + 1);
            }
        }
        return answer;
    }
}

from collections import defaultdict
from typing import List

class Solution:
    def tupleSameProduct(self, nums: List[int]) -> int:
        count = defaultdict(int)
        answer = 0

        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                product = nums[i] * nums[j]
                answer += count[product] * 8
                count[product] += 1

        return answer

#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int tupleSameProduct(vector<int>& nums) {
        unordered_map<int, int> count;
        int answer = 0;

        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            for (int j = i + 1; j < static_cast<int>(nums.size()); ++j) {
                int product = nums[i] * nums[j];
                answer += count[product] * 8;
                ++count[product];
            }
        }
        return answer;
    }
};

常见错误

  • 只给重复乘积加 8，没有乘以前面已出现的数对数 k。
  • 枚举 i != j，导致同一无序数对被扫描两次。
  • 最终忘记乘 8，返回的是“两对无序数对的组合数”。
  • 先递增频次再取值，产生额外的自配对。
  • 把题面的链式不等写法误解为只要求相邻元素不同；本题实际要求四个元素互异。
