任务定义

给定升序单链表的头节点 head，删除重复节点，使每个元素只出现一次，并返回仍然升序的链表。

与第 82 题不同：本题每组重复值要保留一个，不是整组删除。

样例 A

压掉一个 1
输入
head = [1,1,2]
输出
[1,2]
解释
第一组两个 1 只保留首个节点。

样例 B

两组压缩
输入
head = [1,1,2,3,3]
输出
[1,2,3]
解释
重复的 1 和 3 各留下一个。
约束：节点数在 [0, 300] 内，-100 ≤ Node.val ≤ 100，链表按升序排列。本题没有字符串参数；若其他题出现空格，本站统一以 ␠ 表示可见空格。

题解

核心洞察、完整过程与四语言代码默认隐藏。

核心洞察

升序把全局去重变成相邻比较

相同值必然连续。让 curr 指向每组要保留的第一个节点：若 curr.val == curr.next.val，直接让 curr.next 越过重复后继；否则 curr 才前进。删除重复节点时 curr 不动，因此能连续压掉三个、四个乃至更长的同值段。

不变量

curr 及其左侧链表已经去重；curr 是当前值唯一保留的代表节点。

完整过程

  1. 定位

    curr 从 head 开始；空链表直接返回。

  2. 比较

    只要 curr.next 存在，比较两个相邻值。

  3. 旁路

    相等时执行 curr.next = curr.next.next，curr 不动。

  4. 前进

    不等时 curr = curr.next；结束后返回 head。

边界

空链 / 单节点

循环条件不成立，原样返回。

边界

全部相同

curr 固定在首节点，连续旁路其余节点。

复杂度

O(n) / O(1)

每个节点最多访问一次，只改 next 指针。

替代方案

递归 / 重建

递归有 O(n) 栈；计数重建浪费升序与原地条件。

面试追问

  • • 为什么删除后不能立刻移动 curr？
  • • 如果链表无序，如何在 O(n) 时间内去重？
  • • 与第 82 题“整组删除”的不变量有何不同？

常见错误

  • • 相等时 curr 也前进，导致三连重复只删掉一个。
  • • 用值覆盖模拟删除，没有真正重接 next 指针。
  • • 误做成第 82 题，把整组重复值全部删除。
