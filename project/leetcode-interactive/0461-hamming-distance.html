汉明距离Hamming Distance

两个整数的汉明距离，是它们二进制表示中对应位不同的位置数量。给定整数 x 与 y，返回这个数量。

先观察每一位如何变化

题目速览

hammingDistance(x: integer, y: integer) → integer
示例 1 
输入：x = 1, y = 4
输出：2
解释：
1  → 0001
4  → 0100
       ↑ ↑  共 2 个不同位
示例 2 
输入：x = 3, y = 1
输出：1

约束：0 ≤ x, y ≤ 2³¹ − 1

核心洞察

先异或，再只遍历结果中的 1。

异或运算在两位相同时得到 0、不同时得到 1，所以 x ^ y 恰好是一张“差异地图”。随后反复使用 n & (n - 1) 清除最低位的 1，每清除一次，答案加一。

n = x ^ y　→　循环执行 n = n & (n - 1)　→　计数

完整过程

  1. 计算 n = x ^ y。此时 n 中每个 1 对应一个二进制不同位。
  2. 只要 n != 0，就执行 n &= n - 1，清除 n 最低位的 1。
  3. 每次清除都让计数器加一；当 n 归零，计数器就是汉明距离。

以 x = 1、y = 4 为例：0001 ^ 0100 = 0101。第一次清除后为 0100，第二次清除后为 0000，因此结果是 2。

正确性说明

引理：异或精确标记不同位

任意位置上，若 x 与 y 的位相同，异或为 0；若不同，异或为 1。因此异或结果中 1 的数量恰好等于汉明距离。

引理：每轮恰好删除一个 1

n - 1 会翻转最低位 1 及其右侧所有位；与原数按位与后，最低位 1 被清除，其余更高的 1 保持不变。

终止性

每轮都让 1 的数量严格减少 1。32 位整数最多有 32 个 1，所以循环必定终止。

结论

循环次数等于初始异或结果中 1 的数量；由第一个引理，这个次数正是 x 与 y 的汉明距离。

边界与复杂度

边界

  • x == y：异或为 0，直接返回 0。
  • x == 0 或 y == 0：结果等于另一数的置位数。
  • 最大输入 2³¹ - 1：有效低 31 位都是 1，仍在题目范围内。

复杂度

时间 O(k) 空间 O(1)

其中 k 是 x ^ y 中 1 的数量；在本题 32 位范围内，k ≤ 31。

替代方案

逐位右移

检查异或结果最低位，再无符号右移；写法直观但固定扫描所有有效位，时间为 O(w)，w 是位宽。

内建 bit count

Java 的 Integer.bitCount、Python 的 int.bit_count、C++20 的 std::popcount 都能简化代码，但面试中通常仍需解释底层含义。

四种语言完整代码

JavaLeetCode 可提交
class Solution {
    public int hammingDistance(int x, int y) {
        int differentBits = x ^ y;
        int distance = 0;

        while (differentBits != 0) {
            differentBits &= differentBits - 1;
            distance++;
        }

        return distance;
    }
}
JavaScriptLeetCode 可提交
/**
 * @param {number} x
 * @param {number} y
 * @return {number}
 */
var hammingDistance = function(x, y) {
    let differentBits = (x ^ y) >>> 0;
    let distance = 0;

    while (differentBits !== 0) {
        differentBits = (differentBits & (differentBits - 1)) >>> 0;
        distance++;
    }

    return distance;
};

C++LeetCode 可提交
class Solution {
public:
    int hammingDistance(int x, int y) {
        unsigned int differentBits =
            static_cast<unsigned int>(x ^ y);
        int distance = 0;

        while (differentBits != 0) {
            differentBits &= differentBits - 1;
            ++distance;
        }

        return distance;
    }
};

面试追问

如果输入是负数呢？

要先约定位宽并按补码处理。固定 32 位时应使用无符号视角或无符号右移，避免算术右移不断补 1。当前题目只给非负数。

如何处理一组整数？

若求总汉明距离，可按每一位统计 0 和 1 的个数；该位贡献为 zeros × ones，无需枚举所有数对。

常见错误

  • 把“二进制值的差”误当作“不同位置的数量”。
  • 直接比较十进制字符串，或忘记二进制表示需要按位对齐。
  • JavaScript 位运算按有符号 32 位执行，循环状态未用 >>> 0 归一化。
  • 写成 n & n - 1 时忽略可读性与运算优先级，建议明确加括号。
  • 把 n & -n（保留最低位 1）与 n & (n - 1)（清除最低位 1）混淆。
