统计放置房子的方式数

Count Number of Ways to Place Houses

一条街，两排地块。只限制同侧相邻，隔街相望的房子可以同时存在。

查看官方题目 ↗

01 / 题目

给定整数 n，街道每侧都有编号为 1 … n 的地块，共 2n 个。每块地可以空着，也可以放一所房子。计算所有合法放置方式：同一侧连续的两个地块不能同时有房子。两侧的同号地块互不限制；全部空着也算一种方式。

返回方式数对 1,000,000,007 取模的结果。参数：countHousePlacements(n: integer) → integer。

约束：1 ≤ n ≤ 10⁴。输入只有一个整数参数 n。

官方示例 1

输入：n = 1
输出：4

两块地的情况为：全空、仅上侧有房、仅下侧有房、两侧都有房，共 4 种。

官方示例 2

输入：n = 2
输出：9

用 0 表示空地、1 表示房子。完整排列如下，每对括号依次表示上侧、下侧：

(00, 00)  (00, 01)  (00, 10)
(01, 00)  (01, 01)  (01, 10)
(10, 00)  (10, 01)  (10, 10)

04 / 独立题解

核心洞察：先数一侧，再组合两侧

两侧没有交叉约束。若单侧有 f(n) 种合法方案，总数就是 f(n) × f(n)。同侧只关心最后一格是否有房子，可以按这个状态分类计数。

令 Eᵢ 为前 i 块地中末格为空的方案数，Hᵢ 为末格有房的方案数。新格为空时可以接在任何方案后；新格有房时只能接在末格为空的方案后。

E₀ = 1, H₀ = 0  // 空前缀是一种方案
Eᵢ = Eᵢ₋₁ + Hᵢ₋₁
Hᵢ = Eᵢ₋₁
f(i) = Eᵢ + Hᵢ
答案 = f(n)² mod 1,000,000,007

完整过程

  1. 从空前缀开始：empty = 1, house = 0。
  2. 重复 n 次，用旧状态计算 nextEmpty = (empty + house) % MOD，然后令 house = empty，empty = nextEmpty。
  3. 取单侧总数 side = (empty + house) % MOD。
  4. 返回 side * side % MOD，使用能精确承载乘积的整数类型。

以 n = 3 为例：(E,H) 从 (1,0) 依次变为 (1,1) → (2,1) → (3,2)。单侧共有 5 种，两侧共有 25 种。

正确性证明

基础：没有地块时只有一个空方案，初始化将其放入 E 类，以便第一块地可以空着或建房。

归纳：假设前 i−1 块地已被完整、无重复地划分为 E 与 H。追加空地不会产生相邻房子，因此两个旧类都恰好贡献一次到新 E；追加房子时前一格必须为空，因此只有旧 E 恰好贡献一次到新 H。任何新合法方案删除末格后都唯一回到对应旧方案，所以转移既无遗漏又无重复。

组合：任意上侧合法方案与任意下侧合法方案都能组成一条合法街道，且每条街道唯一对应这对方案。因此按乘法原理平方即为答案。逐步取模保持加法、乘法的同余关系。

边界与复杂度

  • n = 1 得到 4，允许隔街的两所房子同时存在。
  • 全空方案不能漏掉。n = 0 仅用作内部基础状态，不属于官方输入。
  • n = 10000 时每步取模，避免递推值无限增长。
  • 时间 O(n)，额外空间 O(1)。演示枚举用于讲解，不是提交算法。
  • Java 用 long、C++ 用 long long；模后两个数的乘积小于约 10¹⁸，能放进有符号 64 位整数。JavaScript 使用 BigInt，最后再转为 Number。

替代方案

单侧总数满足 f(i) = f(i−1) + f(i−2)，基础为 f(0)=1, f(1)=2，即斐波那契数 Fᵢ₊₂。可以用两个滚动变量直接递推。DP 数组便于回溯各步但需 O(n) 空间；矩阵快速幂或斐波那契倍增可把计算降为 O(log n)，本题规模无需它们。暴力枚举两侧需搜索最多 2²ⁿ 种配置，只适合小规模理解。

常见错误

  • 把两侧的同号房子判为冲突，错误增加题目没有的限制。
  • 忘记平方，只返回一侧的数量。
  • 先覆盖 empty 再计算 house，导致使用了新状态；应保存 nextEmpty。
  • 只在最后取模导致溢出；JavaScript 即使每步取模，Number 平方也可能超过安全整数范围。
  • 把 f(0) 设为 0，漏掉空前缀与全空方案。

面试追问

  • n 极大怎么办？用快速倍增计算 Fₙ₊₂，再平方取模。
  • 隔街也不允许同时建房？按一列的占用掩码建立状态，不能再独立平方。
  • 同侧房子间至少隔 k 块空地？在边界单独定义后，用 f(i)=f(i−1)+f(i−k−1)，或维护末尾连续空地数。
  • 两侧长度不同？分别计算 f(a)、f(b)，相乘取模。

Java

class Solution {
    public int countHousePlacements(int n) {
        final long MOD = 1_000_000_007L;
        long empty = 1, house = 0;
        for (int i = 0; i < n; i++) {
            long nextEmpty = (empty + house) % MOD;
            house = empty;
            empty = nextEmpty;
        }
        long side = (empty + house) % MOD;
        return (int) (side * side % MOD);
    }
}
