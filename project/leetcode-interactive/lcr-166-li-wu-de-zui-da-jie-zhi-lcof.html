珠宝的最高价值

从二维珠宝架左上角走到右下角，每次只能向右或向下，返回沿途可以取得的最高总价值。

二维矩阵只能向右 / 向下行列至多 200

题意与示例

珠宝架为二维矩阵 frame，从左上角开始，每次只能到右侧或下侧相邻格，到右下角停止。返回沿途拿到的最高总价值。 

frame = [[1,3,1],
         [1,5,1],
         [4,2,1]]
输出 = 12
路径：1 → 3 → 5 → 2 → 1

约束：0 < frame.length <= 200，0 < frame[0].length <= 200；价值为正数，空架可表示为 [[0]]。

题解：用一行 DP 合并上方与左方

核心洞察

到达格子 (i, j) 的最后一步只能来自上方 (i-1,j) 或左方 (i,j-1)，所以最优值只需比较两者。按行从左到右更新时，dp[j] 尚存上方的答案，dp[j-1] 已是本行左方答案。

完整过程

  1. 建立长度为列数的 DP 数组，初值全 0。
  2. 逐行、逐列扫描；边界格只继承唯一来源。
  3. 内部格更新为 max(dp[j], dp[j-1]) + frame[i][j]。

边界与复杂度

单格 [[0]] 返回 0；单行只能一直向右，单列只能一直向下。时间 O(mn)，一维滚动数组仅 O(n) 空间；若要还原路径，需额外记录来源。

替代方案、追问与常见错误

二维 DP 便于调试和回溯路径，但占 O(mn) 空间。追问：若允许障碍物，可将不可达格设为负无穷。常见错误：更新顺序从右到左，导致 dp[j-1] 不是当前行左方；或忘记首行、首列边界。

class Solution {
    public int jewelleryValue(int[][] frame) {
        int[] dp = new int[frame[0].length];
        for (int i = 0; i < frame.length; i++) {
            for (int j = 0; j < frame[0].length; j++) {
                if (i == 0 && j == 0) dp[j] = frame[i][j];
                else if (i == 0) dp[j] = dp[j - 1] + frame[i][j];
                else if (j == 0) dp[j] += frame[i][j];
                else dp[j] = Math.max(dp[j], dp[j - 1]) + frame[i][j];
            }
        }
        return dp[dp.length - 1];
    }
}
var jewelleryValue = function (frame) {
  const dp = Array(frame[0].length).fill(0);
  for (let i = 0; i < frame.length; i++) {
    for (let j = 0; j < frame[0].length; j++) {
      if (i === 0 && j === 0) dp[j] = frame[i][j];
      else if (i === 0) dp[j] = dp[j - 1] + frame[i][j];
      else if (j === 0) dp[j] += frame[i][j];
      else dp[j] = Math.max(dp[j], dp[j - 1]) + frame[i][j];
    }
  }
  return dp.at(-1);
};

        for i, row in enumerate(frame):
            for j, value in enumerate(row):
                if i == 0 and j == 0: dp[j] = value
                elif i == 0: dp[j] = dp[j - 1] + value
                elif j == 0: dp[j] += value
                else: dp[j] = max(dp[j], dp[j - 1]) + value
