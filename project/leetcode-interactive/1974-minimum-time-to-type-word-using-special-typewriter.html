键入单词的最少时间

Minimum Time to Type Word Using Special Typewriter

26 个字母，一个指针。转动与键入，都需要时间。

01 / 题目

小写字母 a 到 z 按顺序排成一个圆环，z 与 a 相邻。指针最初指向 a。每秒只能做一件事：顺时针移动一格、逆时针移动一格，或键入当前指向的字母。必须按顺序键入字符串 word，返回所需的最少秒数。

参数与返回值
minTimeToType(word: string) → integer

约束
1 ≤ word.length ≤ 100
word 只包含小写英文字母。

02 / 官方示例

示例 1

输入：word = "abc"
输出：5

键入 a 用 1 秒；顺时针到 b 并键入用 2 秒；顺时针到 c 并键入用 2 秒。

示例 2

输入：word = "bza"
输出：7

顺时针到 b 并键入用 2 秒；逆时针经 a 到 z 并键入用 3 秒；顺时针到 a 并键入用 2 秒。

输入：word = "zjpc"
输出：34

    05 / 独立题解

    准备好后，再展开思路与四语言实现。

    核心洞察：每段都取圆环上的最短路

    用 0–25 表示 a–z。当前位置为 p，下一个字符为 q，令 d = |q − p|。两条方向的路径长度为 d 和 26 − d，移动用时是 min(d, 26 − d)。键入还需 1 秒，之后指针停留在 q。

    完整过程

    1. 令 p = 0，总时间 ans = 0。
    2. 按 word 的字符顺序，将当前字符转换为 q。
    3. 计算 d，累加 min(d, 26 − d) + 1。
    4. 更新 p = q。全部处理完后返回 ans。

    以 bza 为例：a→b 移动 1 格再键入，累计 2；b→z 逆时针移动 2 格再键入，累计 5；z→a 移动 1 格再键入，累计 7。

    正确性

    在键入第 i 个字符之前，指针必须从上一个已键入字符（第一个字符之前是 a）到达目标字符。圆环上两条简单路径中，较短路径提供移动次数的下界；额外绕圈不可能更优。每个字符又必须单独花 1 秒键入。

    选择每段的较短路径即可达到该段下界。无论选择哪种方向，键入后都处在同一个目标字母，因而不会改变后续问题的起点。把各段下界相加既是全局下界，也能由算法实现，所以得到最少总时间。

    边界与复杂度

    • 重复字符的移动成本为 0，但键入仍花 1 秒。
    • a 与 z 相邻，跨边界只需 1 格。
    • 距离恰为 13 时，两种方向同样最优；回放默认选顺时针。
    • 长度为 1 也需计入初始 a 到目标的距离。空串不在官方输入范围。
    • 每段至多 13 次移动及 1 次键入，因此长度 100 时答案不超过 1400。

    设 n = word.length。提交算法时间复杂度 O(n)，额外空间 O(1)。页面为了逐秒回放保存状态，使用 O(n) 额外空间（字母表固定为 26）。

    替代方案

    可以逐格模拟两种方向，或在 26 个字母构成的环上用 BFS 求距离；均能得到同样的结果，但公式更直接。固定字母表下逐格模拟仍为 O(n)，只是常数更大，不需要引入动态规划。

    Java

    class Solution {
    public int minTimeToType(String word) {
        int prev = 0, total = 0;
        for (int i = 0; i < word.length(); i++) {
            int curr = word.charAt(i) - 'a';
            int d = Math.abs(curr - prev);
            total += Math.min(d, 26 - d) + 1;
            prev = curr;
        }
        return total;
    }
}

    常见错误

    • 仅累加字母下标差，忽略 z 与 a 的环形邻接。
    • 忘记键入的 1 秒，尤其漏算连续相同字符。
    • 每键入一个字母就把指针重置到 a，导致后续距离错误。
    • 使用 25 − d；圆环有 26 条相邻边，应为 26 − d。
    • 把移动与键入合并为同一秒；题目每秒只能执行一种操作。

    面试追问

    字母表扩大到 m 个符号？ 公式改为 min(d, m − d)，并建立符号到下标的映射。

    顺逆时针单步费用不同？ 分别计算两方向的步数乘对应费用；只要结束位置固定且没有历史依赖，每段仍能独立选择。

    圆盘上同一字符有多个位置？ 键入后的位置不再唯一，会影响后续成本，需要按可能位置维护动态规划状态。
