2617 · Minimum Number of Visited Cells in a Grid

网格图中最少访问的格子数

每个格子的数值决定你向右或向下能走多远。目标不是计算移动次数，而是计算从左上角到右下角最少访问多少个格子。

输入规模
m × n ≤ 10⁵
移动方向
仅向右 / 向下
返回值
最少格子数或 −1

01题目说明

给定一个下标从 0 开始的 m × n 整数矩阵 grid，初始位于左上角 (0, 0)。在格子 (i, j)，可以：

  • 向右到达同一行的 (i, k)，其中 j < k ≤ j + grid[i][j]；
  • 向下到达同一列的 (k, j)，其中 i < k ≤ i + grid[i][j]。

返回到达右下角 (m − 1, n − 1) 所需访问的最少格子数；无法到达时返回 −1。计数包含起点和终点，因此单格矩阵的答案是 1。

函数签名： minimumVisitedCells(grid)，参数为二维整数数组，返回整数。

 [4,2,3,1],

 [2,4,0,0]]

03约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 10⁵
  • 1 ≤ m × n ≤ 10⁵
  • 0 ≤ grid[i][j] < m × n
  • grid[m − 1][n − 1] == 0

05题解：动态规划 + 行列最小堆

核心洞察

按从上到下、从左到右的顺序扫描时，所有能到达当前格子 (i, j) 的前驱一定已经处理过。令 dist[i][j] 为到达该格子最少访问的格子数。每个前驱提供候选值 dist + 1，因此只需快速找到同一行、同一列中“仍覆盖当前坐标”的最小 dist。

为每一行维护一个最小堆，元素为 (dist, 最远列)；为每一列维护一个最小堆，元素为 (dist, 最远行)。堆顶若已过期就弹出，剩余堆顶就是该方向的最优前驱。

关键点：堆按 dist 排序，而“是否过期”通过覆盖终点判断。持续弹出过期堆顶后，留下的堆顶就是当前可用候选中的最小距离。

完整过程

  1. 建立 m 个行堆和 n 个列堆，起点距离设为 1。
  2. 扫描 (i, j) 时，从行堆弹出最远列小于 j 的堆顶；从列堆弹出最远行小于 i 的堆顶。
  3. 若不是起点，从两个有效堆顶的 dist 中取更小者再加 1；两个堆都没有候选则当前格不可达。
  4. 若当前格可达，把 (dist, j + grid[i][j]) 放入当前行堆，把 (dist, i + grid[i][j]) 放入当前列堆。
  5. 返回右下角距离；仍为无穷则返回 −1。

正确性证明

引理 1：处理 (i, j) 时，所有可能前驱都已处理。移动只向右或向下，前驱只能位于本行更小列或本列更小行，均早于当前格进入扫描。

引理 2：清除过期堆顶后，行堆与列堆的堆顶分别给出该方向可达当前格子的最小前驱距离。堆按距离排序；若最小距离元素过期便删除，重复后第一个未过期元素既有效又不大于堆中其他有效元素。

归纳：起点距离 1 正确。假设此前距离均正确，根据两个引理，当前格从两个方向取得全部有效前驱中的最小距离再加一；若没有前驱则不可达。因此当前状态正确，归纳至终点即得正确答案。

边界情况

  • 单格网格：起点即终点，返回 1。
  • 起点为 0：除单格外无法离开，返回 −1。
  • 不可达中间格：不进入任何堆，不能成为虚假前驱。
  • 跳跃越界：覆盖终点不必截断，扫描坐标本身不会越界。
  • 答案计数：距离从 1 开始，而不是从 0 开始。

复杂度

每个可达格子至多进入一个行堆和一个列堆，也至多各弹出一次。时间复杂度为 O(mn · log(mn))，更细可写为 O(mn(log m + log n))；空间复杂度为 O(mn)。

替代方案

  • BFS + 有序集合或并查集：跳过已访问坐标，使每个格子只扩展一次；复杂度同样优秀，但实现更长。
  • 单调栈 DP：利用候选间的支配关系压缩状态，复杂度优秀，但证明和实现更易出错。
  • 朴素 BFS：逐个枚举跳跃范围会反复扫描大量格子，最坏平方级，无法承受总格子数 10⁵。

06四语言完整代码

JavaPriorityQueue
import java.util.*;

class Solution {
    public int minimumVisitedCells(int[][] grid) {
        int m = grid.length, n = grid[0].length, inf = m * n + 1;
        PriorityQueue<int[]>[] rows = new PriorityQueue[m];
        PriorityQueue<int[]>[] cols = new PriorityQueue[n];
        Comparator<int[]> byDistance = Comparator.comparingInt(a -> a[0]);
        for (int i = 0; i < m; i++) rows[i] = new PriorityQueue<>(byDistance);
        for (int j = 0; j < n; j++) cols[j] = new PriorityQueue<>(byDistance);

        int answer = inf;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                while (!rows[i].isEmpty() && rows[i].peek()[1] < j) rows[i].poll();
                while (!cols[j].isEmpty() && cols[j].peek()[1] < i) cols[j].poll();
                int distance = (i == 0 && j == 0) ? 1 : inf;
                if (!rows[i].isEmpty()) distance = Math.min(distance, rows[i].peek()[0] + 1);
                if (!cols[j].isEmpty()) distance = Math.min(distance, cols[j].peek()[0] + 1);
                if (distance < inf) {
                    rows[i].offer(new int[]{distance, j + grid[i][j]});
                    cols[j].offer(new int[]{distance, i + grid[i][j]});
                }
                if (i == m - 1 && j == n - 1) answer = distance;
            }
        }
        return answer == inf ? -1 : answer;
    }
}
JavaScriptBinary Heap
/**
 * @param {number[][]} grid
 * @return {number}
 */
var minimumVisitedCells = function (grid) {
    const m = grid.length, n = grid[0].length, inf = m * n + 1;
    const rows = Array.from({ length: m }, () => []);
    const cols = Array.from({ length: n }, () => []);
    const push = (heap, item) => {
        heap.push(item);
        for (let i = heap.length - 1; i > 0;) {
            const p = (i - 1) >> 1;
            if (heap[p][0] <= heap[i][0]) break;
            [heap[p], heap[i]] = [heap[i], heap[p]];
            i = p;
        }
    };
    const pop = heap => {
        const last = heap.pop();
        if (!heap.length) return;
        heap[0] = last;
        for (let i = 0;;) {
            let smallest = i, left = i * 2 + 1, right = left + 1;
            if (left < heap.length && heap[left][0] < heap[smallest][0]) smallest = left;
            if (right < heap.length && heap[right][0] < heap[smallest][0]) smallest = right;
            if (smallest === i) break;
            [heap[i], heap[smallest]] = [heap[smallest], heap[i]];
            i = smallest;
        }
    };
    let answer = inf;
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            while (rows[i].length && rows[i][0][1] < j) pop(rows[i]);
            while (cols[j].length && cols[j][0][1] < i) pop(cols[j]);
            let distance = i === 0 && j === 0 ? 1 : inf;
            if (rows[i].length) distance = Math.min(distance, rows[i][0][0] + 1);
            if (cols[j].length) distance = Math.min(distance, cols[j][0][0] + 1);
            if (distance < inf) {
                push(rows[i], [distance, j + grid[i][j]]);
                push(cols[j], [distance, i + grid[i][j]]);
            }
            if (i === m - 1 && j === n - 1) answer = distance;
        }
    }
    return answer === inf ? -1 : answer;
};
Pythonheapq
from typing import List
from heapq import heappop, heappush


class Solution:
    def minimumVisitedCells(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        inf = m * n + 1
        rows = [[] for _ in range(m)]
        cols = [[] for _ in range(n)]
        answer = inf
        for i in range(m):
            for j in range(n):
                while rows[i] and rows[i][0][1] < j:
                    heappop(rows[i])
                while cols[j] and cols[j][0][1] < i:
                    heappop(cols[j])
                distance = 1 if i == 0 and j == 0 else inf
                if rows[i]:
                    distance = min(distance, rows[i][0][0] + 1)
                if cols[j]:
                    distance = min(distance, cols[j][0][0] + 1)
                if distance < inf:
                    heappush(rows[i], (distance, j + grid[i][j]))
                    heappush(cols[j], (distance, i + grid[i][j]))
                if i == m - 1 and j == n - 1:
                    answer = distance
        return -1 if answer == inf else answer
C++priority_queue
#include <vector>
#include <queue>
#include <functional>
using namespace std;

class Solution {
public:
    int minimumVisitedCells(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size(), inf = m * n + 1;
        using Entry = pair<int, int>;
        vector<priority_queue<Entry, vector<Entry>, greater<Entry>>> rows(m), cols(n);
        int answer = inf;
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                while (!rows[i].empty() && rows[i].top().second < j) rows[i].pop();
                while (!cols[j].empty() && cols[j].top().second < i) cols[j].pop();
                int distance = (i == 0 && j == 0) ? 1 : inf;
                if (!rows[i].empty()) distance = min(distance, rows[i].top().first + 1);
                if (!cols[j].empty()) distance = min(distance, cols[j].top().first + 1);
                if (distance < inf) {
                    rows[i].push({distance, j + grid[i][j]});
                    cols[j].push({distance, i + grid[i][j]});
                }
                if (i == m - 1 && j == n - 1) answer = distance;
            }
        }
        return answer == inf ? -1 : answer;
    }
};

07面试追问与常见错误

面试追问

  • 为什么只清理过期的堆顶就足够？
  • 能否用有序集合配合 BFS，使每个坐标只被枚举一次？
  • 若允许向左和向上移动，当前扫描 DP 为什么失效？
  • 怎样恢复一条实际的最短路径？
  • 如何只保存必要候选来降低空间？

常见错误

  • 把答案当作移动次数，忘记起点也计入。
  • 不可达格子仍被加入堆，污染后续状态。
  • 堆按覆盖终点而非距离排序。
  • 只删除一次过期堆顶，没有用 while。
  • 枚举所有跳跃目标，导致平方复杂度。
