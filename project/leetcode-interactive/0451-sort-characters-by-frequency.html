根据字符出现
频率排序

把一串字符送上“频率跑道”：出现越多的字符越先抵达终点。先读题、亲手推进计数过程，再决定是否展开完整解法。

中等 哈希表 桶排序 计数 字符串
Problem brief

题意与边界

返回结果不唯一：频率相同的字符组可以交换先后，但每一种字符必须连续成组。

给定字符串 s，统计每个字符出现的次数，并按频率从高到低重新排列所有字符。若有多个合法答案，返回任意一个即可。大小写字符彼此不同，例如 A 与 a 是两种字符。

示例 1

输入：s = "tree" 输出："eert"

e 出现 2 次，必须排在各出现 1 次的 r、t 之前；“eetr”同样有效。

示例 2

输入：s = "cccaaa" 输出："cccaaa"

c 与 a 均出现 3 次，“aaaccc”也有效；“cacaca”不合法，因为相同字符未连续成组。

示例 3

输入：s = "Aabb" 输出："bbAa"

b 出现 2 次；A 与 a 各 1 次。“bbaA”也有效，且大小写敏感。

约束

  • 1 <= s.length <= 5 × 105
  • s 只由大写英文字母、小写英文字母和数字组成。

Complete solution

桶排序：让频率成为下标

设字符串长度为 n，任一字符的频率只可能落在 1 到 n。于是无需比较字符，只需把字符放入对应频率的桶，再倒序读取桶。

核心洞察

哈希表回答“每个字符多少次”，桶数组回答“某个频率有哪些字符”。频率天然是有限整数区间。

完整过程

  1. 遍历 s，得到字符到频率的映射。
  2. 创建长度 n + 1 的桶；把字符放入 bucket[freq]。
  3. 从频率 n 到 1 倒序扫描，将桶中每个字符重复相应次数后追加到答案。

正确性说明

计数阶段记录了每个字符的准确出现次数。字符 c 只会进入下标为其频率 f(c) 的桶；倒序读取桶保证若 f(x) > f(y)，x 的整组副本一定先于 y 输出。每个字符恰好输出 f(c) 次，因此结果既是原字符串的重排，也满足频率非增。

复杂度

  • 时间：O(n)，计数、扫描桶和构造答案各为线性量级。
  • 空间：O(n + k)，k 为不同字符数；桶及输出占线性空间。

边界情况

  • 单字符或所有字符相同：直接形成一个桶。
  • 所有字符频率相同：任意字符组顺序都合法，但同类字符仍须相邻。
  • 大小写与数字分别计数；不要做大小写归一化。
  • 最大长度 5 × 105：避免反复字符串拼接造成二次复杂度。

替代方案

  • 对 k 个不同字符按频率排序：O(n + k log k)，代码通常更短。
  • 最大堆：O(n + k log k)，适合流式取出最高频字符。
  • 若字符集固定且很小，数组计数可替代哈希表。

面试追问

  • 若只需要前 k 个高频字符，如何用小顶堆降低额外开销？
  • 若输入是 Unicode 字素簇，按代码点计数为什么可能不符合用户感知？
  • 若要求同频时保持首次出现顺序，应记录什么额外信息？

常见错误

  • 只按字符频率逐个排序，却忘记让相同字符连续输出。
  • 把频率相同误判为必须按字典序；题目允许任意顺序。
  • 在循环中用不可变字符串反复追加，导致性能退化。
  • 把 A 和 a 合并计数。
Java
class Solution {
    public String frequencySort(String s) {
        int n = s.length();
        java.util.Map<Character, Integer> count = new java.util.HashMap<>();
        for (char c : s.toCharArray()) {
            count.put(c, count.getOrDefault(c, 0) + 1);
        }

        java.util.List<Character>[] buckets = new java.util.List[n + 1];
        for (java.util.Map.Entry<Character, Integer> entry : count.entrySet()) {
            int frequency = entry.getValue();
            if (buckets[frequency] == null) {
                buckets[frequency] = new java.util.ArrayList<>();
            }
            buckets[frequency].add(entry.getKey());
        }

        StringBuilder answer = new StringBuilder(n);
        for (int frequency = n; frequency >= 1; frequency--) {
            if (buckets[frequency] == null) continue;
            for (char c : buckets[frequency]) {
                for (int i = 0; i < frequency; i++) answer.append(c);
            }
        }
        return answer.toString();
    }
}

/**
 * @param {string} s
 * @return {string}

var frequencySort = function(s) {
    const count = new Map();
    for (const character of s) {
        count.set(character, (count.get(character) || 0) + 1);
    }

    const buckets = Array.from({ length: s.length + 1 }, () => []);
    for (const [character, frequency] of count) {
        buckets[frequency].push(character);
    }

    const answer = [];
    for (let frequency = s.length; frequency >= 1; frequency--) {
        for (const character of buckets[frequency]) {
            answer.push(character.repeat(frequency));
        }
    }
    return answer.join("");
};
Python 3
from collections import Counter
from typing import List


class Solution:
    def frequencySort(self, s: str) -> str:
        count = Counter(s)
        buckets: List[List[str]] = [[] for _ in range(len(s) + 1)]

        for character, frequency in count.items():
            buckets[frequency].append(character)

        answer: List[str] = []
        for frequency in range(len(s), 0, -1):
            for character in buckets[frequency]:
                answer.append(character * frequency)

        return "".join(answer)
C++
class Solution {
public:
    string frequencySort(string s) {
        unordered_map<char, int> count;
        for (char c : s) ++count[c];

        vector<vector<char>> buckets(s.size() + 1);
        for (const auto& [character, frequency] : count) {
            buckets[frequency].push_back(character);
        }

        string answer;
        answer.reserve(s.size());
        for (int frequency = static_cast<int>(s.size()); frequency >= 1; --frequency) {
            for (char character : buckets[frequency]) {
                answer.append(frequency, character);
            }
        }
        return answer;
    }
};
