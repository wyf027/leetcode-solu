最小跳跃次数

在下标 i 可以向前跳到 i + jump[i]，也可以跳到任意更小的下标。离开数组即成功；求最少跳跃次数。

输入
jump: 正整数数组
输出
离开数组的最少次数
限制
1 ≤ n ≤ 10⁶

题意与示例

从 0 出发。一次操作只能选择一个合法落点：向前跳 i + jump[i]，或向后跳任意 j < i。一旦向前跳到 n 或更大，立刻离开。

示例：jump = [2, 5, 1, 1, 1, 1]

0 → 2 → 3 → 4 → 5 → 出界，共 5 次。

BFS 的第一条出界路径必然最短。

BFS 波前演示

蓝色是已出队位置，绿色是本层新发现位置。向后边只在首次扩展到该范围时扫描。

交互步骤

  1. 1. 入队 0

    距离为 0，标记已访问。

  2. 2. 按层出队

    队列天然保证最少跳数。

  3. 3. 扩展邻居

    尝试前跳和未扫描的后跳范围。

  4. 4. 首次出界

    当前层数加一就是答案。

核心洞察

把每个数组下标视为图节点，所有允许跳跃都是边，问题是无权图最短路。直接枚举每个节点的所有后跳边会退化到 O(n²)。关键是维护 backScanned：所有下标小于它的节点已经作为某次“任意后跳”的目标加入过队列，不必再扫描。

完整过程

queue = [0], visited[0] = true, backScanned = 0
for each BFS layer:
  pop i
  forward = i + jump[i]
  if forward >= n: return distance + 1
  enqueue forward if unvisited
  for j from backScanned to i - 1:
    enqueue j if unvisited
  backScanned = max(backScanned, i)

每个下标最多入队一次；后跳循环中的每个 j 也只会被扫描一次。因此总时间 O(n)，空间 O(n)。

边界

  • 长度为 1 时，若 jump[0] ≥ 1，答案是 1。
  • 前跳越界无需入队，直接返回。
  • 必须先标记 visited 再入队，避免后跳产生重复节点。
  • backScanned 只向右移动，绝不回退。

替代方案与追问

朴素 BFS 易写但在递增下标反复枚举前缀时超时。也可使用并查集维护“下一个未访问下标”；本题的单调扫描更轻量。追问：若后跳范围改为有限窗口，可用双端队列或线段树按新边结构设计。

常见错误

  • 只跳到 i−1，漏掉题目允许的任意更小下标。
  • 每次都从 0 枚举后跳，导致 O(n²)。
  • 把“出界”当作一个需要入队的节点，造成距离多算。
  • 在出队而不是入队时标记访问，队列会膨胀。

import java.util.*;
class Solution {
    public int minJump(int[] jump) {
        int n = jump.length, backScanned = 0, steps = 0;
        boolean[] seen = new boolean[n];
        ArrayDeque<Integer> q = new ArrayDeque<>();
        q.offer(0); seen[0] = true;
        while (!q.isEmpty()) {
            for (int size = q.size(); size > 0; size--) {
                int i = q.poll(), forward = i + jump[i];
                if (forward >= n) return steps + 1;
                if (!seen[forward]) { seen[forward] = true; q.offer(forward); }
                for (int j = backScanned; j < i; j++) if (!seen[j]) { seen[j] = true; q.offer(j); }
                backScanned = Math.max(backScanned, i);
            }
            steps++;
        }
        return -1;
    }
}
var minJump = function (jump) {
  const n = jump.length, seen = Array(n).fill(false), queue = [0];
  let head = 0, backScanned = 0, steps = 0;
  seen[0] = true;
  while (head < queue.length) {
    const end = queue.length;
    while (head < end) {
      const i = queue[head++], forward = i + jump[i];
      if (forward >= n) return steps + 1;
      if (!seen[forward]) { seen[forward] = true; queue.push(forward); }
      for (let j = backScanned; j < i; j++) if (!seen[j]) { seen[j] = true; queue.push(j); }
      backScanned = Math.max(backScanned, i);
    }
    steps++;
  }
  return -1;
};
from collections import deque
from typing import List

class Solution:
    def minJump(self, jump: List[int]) -> int:
        n, back_scanned, steps = len(jump), 0, 0
        seen, q = [False] * n, deque([0])
        seen[0] = True
        while q:
            for _ in range(len(q)):
                i = q.popleft()
                forward = i + jump[i]
                if forward >= n:
                    return steps + 1
                if not seen[forward]:
                    seen[forward] = True
                    q.append(forward)
                for j in range(back_scanned, i):
                    if not seen[j]:
                        seen[j] = True
                        q.append(j)
                back_scanned = max(back_scanned, i)
            steps += 1
        return -1
