Maximum Number of Visible Points · 把二维视野压平为一条极角时间线，在环形边界上寻找最密集的一段连续窗口。

HARD 数组 几何 排序 滑动窗口 非付费题
Mission brief

题目任务

visiblePoints(points, angle, location)

给定二维整数坐标数组 points、视野宽度 angle（角度制）和固定观测位置 location = [posx, posy]。你不能移动，但可以向任意方向旋转。

若一个点相对观测位置的方向落在某个宽度为 angle 的闭区间视野内，它就可见。多个点可以重合；与你位置完全相同的点无论朝向如何都始终可见；点之间也不会互相遮挡。

目标：选择最佳朝向，返回同一时刻最多能看见多少个点。

观测规则

  1. 01正东方向记作 0°，逆时针为正。
  2. 02视野边界也算可见，因此差值判断使用 ≤ angle。
  3. 03同位置点没有方向，单独计数后加回答案。
Official cases

官方示例

Example 01
输入：points = [[2,1],[2,2],[3,3]],
      angle = 90,
      location = [1,1]
输出：3

三个点都能放入同一个 90° 视野；同一射线上的点不会彼此遮挡。

Example 02
输入：points = [[2,1],[2,2],[3,4],[1,1]],
      angle = 90,
      location = [1,1]
输出：4

位于 location 的点恒可见，其余三个点可被同一视野覆盖。

Example 03
输入：points = [[1,0],[2,1]],
      angle = 13,
      location = [1,1]
输出：1

两个方向相差 90°，13° 的视野一次只能容纳其中一个。

Complete solution

极角排序 + 环形滑动窗口

O(n log n)
CORE INSIGHT 01

二维几何可以降成一维区间

从 location 到普通点的距离不影响可见性，只需保留方向。用 atan2(dy, dx) 得到每个点的极角并统一到 [0°, 360°)。于是问题变成：在环形角度序列上，找一个宽度不超过 angle 的闭区间，使其中元素最多。

CORE INSIGHT 02

复制一圈，拆掉 0° / 360° 接缝

排序后，把每个角度再加 360° 追加到末尾。例如 [350°, 5°, 8°] 排序为 [5°, 8°, 350°]，扩展后会出现 [350°, 365°, 368°] 这一段，跨零度视野就变成普通连续区间。

CORE INSIGHT 03

同位置点先隔离

若点与 location 重合，向量是 (0,0)，没有有意义的极角，但它始终可见。将其数量记为 same，滑动窗口只处理其余点，最后返回 best + same。

完整过程

  1. 遍历 points，统计重合点，其余点计算极角。
  2. 升序排序角度数组 dirs。
  3. 构造 ext = dirs + (dirs + 360)。
  4. 固定左端 left，持续右移 right，只要 ext[right] - ext[left] ≤ angle。
  5. 用 right - left 更新最优值。右指针不回退，总扫描量为线性。
  6. 最优普通点数加上 same。

边界清单

  • angle = 0：相同方向上的多个点仍可同时看见。
  • 视野是闭区间：正好相差 angle 的两端都应计入。
  • 多个相同坐标或相同方向的点都要分别计数。
  • 窗口最多检查原数组的 n 个方向，避免扩展数组重复计数。
  • 浮点比较可加入很小的 EPS，吸收角度换算误差。
Why it works

正确性证明

1

极角等价

除重合点外，一个点是否落入某个视野只由它相对 location 的方向决定，因此以极角替代坐标不会改变任何朝向下的可见集合。

2

连续性

任意固定朝向的视野都是圆周上一个宽度为 angle 的闭弧；按极角排序后，弧内点必然构成环形序列中的连续段。

3

展开完备

为每个极角追加其 +360° 副本后，任何跨越 0° 的连续弧都在扩展数组中对应一个普通连续区间，因此不会遗漏最优朝向。

4

窗口最优

对每个左端，右指针停在第一个超出宽度的位置，所以 [left, right) 是以该左端开始的最大合法区间。枚举所有原始左端并取最大值，就得到所有可选视野中的最大普通点数。

5

重合点加回

重合点在任意朝向下都可见，且与普通点的选择互不冲突，因此把 same 加到普通点最优值上恰好得到最终答案。

Cost model

复杂度

Time
O(n log n)
排序主导；双指针扫描为 O(n)。
Space
O(n)
保存极角与复制后的展开数组。
Alternative

替代方案

每个角度作为边界后二分：排序并复制后，对每个左端用二分查找最后一个不超过 start + angle 的位置。逻辑直观，时间为 O(n log n)；但双指针利用右端单调性，将排序后的扫描降到 O(n)，常数也更小。

枚举朝向：任意连续角度不可取；最优闭区间总能平移到某个点贴住一侧边界，因此只需以已有极角为候选边界。不过直接对每个边界重新计数会退化到 O(n²)。

Interview follow-ups

面试追问

  • 为什么用 atan2？ 它同时利用 dx、dy 确定象限，也能处理竖直方向。
  • 怎样避免浮点角度？ 可用叉积比较方向，但排序与固定角宽判断会更复杂；本题用双精度足够实用。
  • 若 angle 可以等于 360°？ 可直接返回 points.length，或严格限制窗口最多 n 个普通点。
  • 若点带权重？ 把窗口内“数量”改为前缀和或双指针维护权重和。
Failure modes

常见错误

  • 忘记单独统计与 location 重合的点，把 atan2(0,0) 当成真实方向。
  • 只在 [0°,360°) 内滑窗，漏掉同时覆盖 359° 与 1° 的最佳视野。
  • 使用 < angle，错误排除恰好位于视野边界的点。
  • 复制数组后不限制窗口长度，极端情况下可能把同一个原始点计算两次。
  • JavaScript 忘记给 sort 提供数值比较器，导致按字符串顺序排序。

class Solution {
    public int visiblePoints(List<List<Integer>> points,
                             int angle,
                             List<Integer> location) {
        List<Double> directions = new ArrayList<>();
        int same = 0;
        int px = location.get(0);
        int py = location.get(1);

        for (List<Integer> point : points) {
            int dx = point.get(0) - px;
            int dy = point.get(1) - py;
            if (dx == 0 && dy == 0) {
                same++;
                continue;
            }
            double degree = Math.toDegrees(Math.atan2(dy, dx));
            if (degree < 0) degree += 360.0;
            directions.add(degree);
        }

        Collections.sort(directions);
        int n = directions.size();
        double[] extended = new double[n * 2];
        for (int i = 0; i < n; i++) {
            extended[i] = directions.get(i);
            extended[i + n] = directions.get(i) + 360.0;
        }

        final double EPS = 1e-10;
        int best = 0;
        int right = 0;
        for (int left = 0; left < n; left++) {
            if (right < left) right = left;
            while (right < left + n
                    && extended[right] - extended[left] <= angle + EPS) {
                right++;
            }
            best = Math.max(best, right - left);
        }
        return best + same;
    }
}

var visiblePoints = function(points, angle, location) {
    const directions = [];
    let same = 0;
    const [px, py] = location;

    for (const [x, y] of points) {
        const dx = x - px;
        const dy = y - py;
        if (dx === 0 && dy === 0) {
            same++;
            continue;
        }
        let degree = Math.atan2(dy, dx) * 180 / Math.PI;
        if (degree < 0) degree += 360;
        directions.push(degree);
    }

    directions.sort((a, b) => a - b);
    const n = directions.length;
    const extended = directions.concat(directions.map(value => value + 360));
    const EPS = 1e-10;
    let best = 0;
    let right = 0;

    for (let left = 0; left < n; left++) {
        if (right < left) right = left;
        while (right < left + n &&
               extended[right] - extended[left] <= angle + EPS) {
            right++;
        }
        best = Math.max(best, right - left);
    }
    return best + same;
};

class Solution {
public:
    int visiblePoints(vector<vector<int>>& points,
                      int angle,
                      vector<int>& location) {
        vector<double> directions;
        int same = 0;
        const int px = location[0];
        const int py = location[1];
        const double PI = acos(-1.0);

        for (const auto& point : points) {
            int dx = point[0] - px;
            int dy = point[1] - py;
            if (dx == 0 && dy == 0) {
                ++same;
                continue;
            }
            double degree = atan2(dy, dx) * 180.0 / PI;
            if (degree < 0) degree += 360.0;
            directions.push_back(degree);
        }

        sort(directions.begin(), directions.end());
        const int n = static_cast<int>(directions.size());
        vector<double> extended(2 * n);
        for (int i = 0; i < n; ++i) {
            extended[i] = directions[i];
            extended[i + n] = directions[i] + 360.0;
        }

        constexpr double EPS = 1e-10;
        int best = 0;
        int right = 0;
        for (int left = 0; left < n; ++left) {
            right = max(right, left);
            while (right < left + n &&
                   extended[right] - extended[left] <= angle + EPS) {
                ++right;
            }
            best = max(best, right - left);
        }
        return best + same;
    }
};
