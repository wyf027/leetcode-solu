让每一枚箭头，

从左上走到右下。顺着格子里的方向移动不花钱；若要改掉当前格子的方向，代价为 1。你需要找出让至少一条有效路径出现的最小总代价。

Problem

题意与规则

先理解移动规则，再尝试交互实验。完整算法被收在页面底部，不会在这里直接泄露。

给定一个 m × n 的整数网格 grid。每个格子里的数字是一枚方向标志：站在该格时，它告诉你下一步应该走向哪个相邻格。标志可能指向网格外。

你从 (0, 0) 出发。若一路遵循标志，最终到达 (m - 1, n - 1)，这条路径就是有效路径；它不必是最短路径。你可以把任意格子的标志修改一次，每修改一个格子花费 1。返回使网格中至少存在一条有效路径的最小花费。

1 →
向右：(i,j+1)
2 ←
向左：(i,j-1)
3 ↓
向下：(i+1,j)
4 ↑
向上：(i-1,j)

输入：grid = [[1,1,1,1],[2,2,2,2],
              [1,1,1,1],[2,2,2,2]]

沿每一行的箭头蛇形前进，需要在三处把行尾或行首箭头改为向下，总花费为 3。

输出：0

无需修改，按现有箭头就能从 (0,0) 到达 (2,2)。

示例 3

输入：grid = [[1,2],[4,3]]
输出：1

只需修改一个格子的方向即可建立有效路径。

示例 4 与 5

输入：grid = [[2,2,2],[2,2,2]]
输出：3

输入：grid = [[4]]
输出：0

单格网格的起点就是终点，即使箭头指向网格外，答案仍为 0。

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 100
  • 1 ≤ grid[i][j] ≤ 4

准备好对答案了吗？

下面包含核心洞察、证明、复杂度、完整代码与面试追问，默认保持收起。

0-1 BFS

把改箭头，变成边权

核心洞察：从每个格子向四个相邻格连边。若移动方向等于当前箭头，边权为 0；否则需要修改当前格子的箭头，边权为 1。题目就变成了只含 0/1 边权图上的单源最短路。

完整过程

  1. 令 dist[0][0] = 0，其余距离为无穷大；把起点放入双端队列。
  2. 从队首取出格子 (r,c)，尝试走向上、下、左、右四个合法相邻格。
  3. 若所选方向与 grid[r][c] 一致，本次边权是 0；否则边权是 1。
  4. 若得到更小距离就更新相邻格。边权 0 的格子放到队首，边权 1 的格子放到队尾，使更低代价优先处理。
  5. 队列耗尽后，dist[m-1][n-1] 就是答案。也可在目标以当前最短距离出队时提前结束。

正确性证明

引理 1：路径代价与修改次数相等

一条路径每离开一个格子时，沿原箭头走贡献 0，否则必须且只需修改当前格的箭头，贡献 1。因此图中路径边权之和恰好等于让这条路径有效所需的修改数。

引理 2：双端队列让更低代价优先

从当前最小距离顶点松弛时，0 权邻居与它同层并放到队首，1 权邻居属于下一层并放到队尾。因此尚未处理的更大距离不会越过更小距离。

结论

0-1 BFS 得到从起点到每个格子的最短边权和；结合引理 1，终点的最短边权和正是最小修改代价。

复杂度

时间：O(mn)。每个格子及至多四条出边被常数次处理。

空间：O(mn)，用于距离数组与双端队列。

边界情况

  • 1 × 1：起点即终点，返回 0。
  • 边界箭头指向网格外：忽略不存在的移动。
  • 原图已有有效路径：答案为 0。
  • 环不会导致死循环：仅在距离严格变小时入队。

import java.util.*;

class Solution {
    public int minCost(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        Deque<int[]> deque = new ArrayDeque<>();
        dist[0][0] = 0;
        deque.offerFirst(new int[]{0, 0, 0});

        while (!deque.isEmpty()) {
            int[] cur = deque.pollFirst();
            int r = cur[0], c = cur[1], d = cur[2];
            if (d != dist[r][c]) continue;
            for (int k = 0; k < 4; k++) {
                int nr = r + dirs[k][0], nc = c + dirs[k][1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int weight = grid[r][c] == k + 1 ? 0 : 1;
                int candidate = d + weight;
                if (candidate < dist[nr][nc]) {
                    dist[nr][nc] = candidate;
                    int[] next = {nr, nc, candidate};
                    if (weight == 0) deque.offerFirst(next);
                    else deque.offerLast(next);
                }
            }
        }
        return dist[m - 1][n - 1];
    }
}

var minCost = function(grid) {
    const m = grid.length, n = grid[0].length;
    const dirs = [[0, 1], [0, -1], [1, 0], [-1, 0]];
    const dist = Array.from({ length: m }, () => Array(n).fill(Infinity));
    const deque = [[0, 0, 0]];
    dist[0][0] = 0;

    while (deque.length) {
        const [r, c, d] = deque.shift();
        if (d !== dist[r][c]) continue;
        for (let k = 0; k < 4; k++) {
            const nr = r + dirs[k][0], nc = c + dirs[k][1];
            if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
            const weight = grid[r][c] === k + 1 ? 0 : 1;
            const candidate = d + weight;
            if (candidate < dist[nr][nc]) {
                dist[nr][nc] = candidate;
                const item = [nr, nc, candidate];
                if (weight === 0) deque.unshift(item);
                else deque.push(item);
            }
        }
    }
    return dist[m - 1][n - 1];
};
from collections import deque
from typing import List

class Solution:
    def minCost(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        directions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
        dist = [[float("inf")] * n for _ in range(m)]
        queue = deque([(0, 0, 0)])
        dist[0][0] = 0

        while queue:
            r, c, current = queue.popleft()
            if current != dist[r][c]:
                continue
            for index, (dr, dc) in enumerate(directions, start=1):
                nr, nc = r + dr, c + dc
                if not (0 <= nr < m and 0 <= nc < n):
                    continue
                weight = 0 if grid[r][c] == index else 1
                candidate = current + weight
                if candidate < dist[nr][nc]:
                    dist[nr][nc] = candidate
                    item = (nr, nc, candidate)
                    if weight == 0:
                        queue.appendleft(item)
                    else:
                        queue.append(item)
        return dist[m - 1][n - 1]

public:

替代方案

Dijkstra：边权仍为 0/1，用最小堆求最短路。正确且通用，复杂度 O(mn log(mn))，但没有利用边权只有两种的特点。

分层 BFS：每轮先沿所有 0 权边扩展，再用一次修改跨到下一层；直观但去重与层级维护更易出错。

常见错误

  • 把“不沿箭头”误算成修改目标格；实际修改当前格。
  • 对 0/1 权图直接使用普通 BFS。
  • 方向数组未按右、左、下、上排列。
  • 没有在更短距离出现时重新入队。
  • 用全局 visited 阻止更优松弛。
