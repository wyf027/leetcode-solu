跳跃游戏 V

Jump Game V

在有限距离内向更低的位置跳跃，但任何不够低的中间柱都会成为不可跨越的屏障。选择任意起点，求最多能访问的下标数。

Problem statement

题目描述

给定整数数组 arr 和整数 d。从下标 i 出发，一步可以向右跳到 i + x，或向左跳到 i - x，其中 1 ≤ x ≤ d，且落点必须仍在数组范围内。

从 i 跳到 j 还需同时满足：

  • 落点更低：arr[i] > arr[j]；
  • 途中没有达到或超过起点高度的柱子：对所有严格位于 i 与 j 之间的 k，均有 arr[i] > arr[k]。

可以任选一个下标作为起点。返回一次合法跳跃序列中最多可访问的下标数量（起点也计入）。任何时刻都不能跳出数组。

maxJumps(arr: integer[], d: integer) → integer
Official examples

示例 1

输入：maxJumps(arr = [6,4,14,6,8,13,9,7,10,6,12], d = 2)
输出：4
解释：可走 10 → 8 → 6 → 7（这里是下标）。

示例 2

输入：maxJumps(arr = [3,3,3,3,3], d = 3)
输出：1
解释：高度相同，无法跳到更低位置。

示例 3

输入：maxJumps(arr = [7,6,5,4,3,2,1], d = 1)
输出：7
解释：从下标 0 开始可依次访问全部下标。

输入：maxJumps(arr = [7,1,7,1,7,1], d = 2)
输出：2

示例 5

输出：1

  • 1 ≤ arr[i] ≤ 10⁵
  • 1 ≤ d ≤ arr.length

Dynamic programming

题解：有向无环图上的最长路

核心洞察

所有合法跳跃都从更高值走向更低值，因此关系图不可能出现环。令 dp[i] 表示“从下标 i 出发最多访问多少个位置”，则当前答案只依赖更低位置的答案。

dp[i] = 1 + max(dp[j])，j 为 i 的合法落点

没有合法落点时，最大值为空，故 dp[i] = 1。

屏障为何能直接 break

从 i 向某一侧逐格扫描。一旦遇到 arr[j] ≥ arr[i]，该位置本身不能落脚，并且它会挡住同方向更远的所有位置，因此应立即停止这一侧。仅仅 continue 会错误地“穿墙”。

扫描左右两侧时要分别停止。一侧遇到屏障，不影响另一侧。

完整过程

  1. 定义状态。dfs(i) 返回从 i 开始可访问的最大下标数。
  2. 向左扫描。最多查看 d 个位置；越界或遇到高度不低于起点时停止，否则用该落点的结果更新答案。
  3. 向右扫描。以相同规则独立处理。
  4. 记忆化。每个下标首次计算后缓存，后续直接复用。
  5. 枚举起点。对所有 i 求 dfs(i)，取最大值。

正确性证明

引理 1：每条合法边都指向严格更低的值，所以合法跳跃图无环。

引理 2：算法枚举了从 i 出发的全部且仅有的合法第一跳。逐格扫描会收集屏障前所有更低位置；首个不低于 arr[i] 的位置及其后方位置均不合法，因此停止不会漏解。

归纳：按高度从低到高考虑。最低位置只能得到 1。假设所有更低位置的 dp 已正确，则对 i 枚举每个合法首跳 j，取 1 + dp[j] 的最大值，恰为从 i 出发的最优路径。

结论：所有起点中的最大 dp[i] 即全局答案。

复杂度与边界

  • 时间复杂度：O(n · d)，每个状态最多向两侧各扫描 d 步。
  • 空间复杂度：O(n)，用于缓存和递归栈。
  • n = 1 时答案为 1。
  • 相等高度不能互跳，并且会阻挡更远位置。
  • d ≥ n 仍受数组边界和屏障规则限制。
  • 极端严格下降数组的递归深度可能达到 n。
class Solution {
    private int[] arr;
    private int d;
    private int[] memo;

    public int maxJumps(int[] arr, int d) {
        this.arr = arr;
        this.d = d;
        this.memo = new int[arr.length];

        int answer = 1;
        for (int i = 0; i < arr.length; i++) {
            answer = Math.max(answer, dfs(i));
        }
        return answer;
    }

    private int dfs(int i) {
        if (memo[i] != 0) return memo[i];

        int best = 1;
        for (int j = i - 1; j >= Math.max(0, i - d); j--) {
            if (arr[j] >= arr[i]) break;
            best = Math.max(best, 1 + dfs(j));
        }
        for (int j = i + 1; j <= Math.min(arr.length - 1, i + d); j++) {
            if (arr[j] >= arr[i]) break;
            best = Math.max(best, 1 + dfs(j));
        }

        memo[i] = best;
        return best;
    }
}

from typing import List


class Solution:
    def maxJumps(self, arr: List[int], d: int) -> int:
        n = len(arr)
        memo = [0] * n

        def dfs(i: int) -> int:
            if memo[i] != 0:
                return memo[i]

            best = 1
            for j in range(i - 1, max(-1, i - d - 1), -1):
                if arr[j] >= arr[i]:
                    break
                best = max(best, 1 + dfs(j))

            for j in range(i + 1, min(n, i + d + 1)):
                if arr[j] >= arr[i]:
                    break
                best = max(best, 1 + dfs(j))

            memo[i] = best
            return best

        return max(dfs(i) for i in range(n))
class Solution {
public:
    int maxJumps(vector<int>& arr, int d) {
        int n = static_cast<int>(arr.size());
        vector<int> memo(n, 0);

        function<int(int)> dfs = [&](int i) -> int {
            if (memo[i] != 0) return memo[i];

            int best = 1;
            for (int j = i - 1; j >= max(0, i - d); --j) {
                if (arr[j] >= arr[i]) break;
                best = max(best, 1 + dfs(j));
            }
            for (int j = i + 1; j <= min(n - 1, i + d); ++j) {
                if (arr[j] >= arr[i]) break;
                best = max(best, 1 + dfs(j));
            }

            return memo[i] = best;
        };

        int answer = 1;
        for (int i = 0; i < n; ++i) answer = max(answer, dfs(i));
        return answer;
    }

替代方案

按高度排序的迭代 DP：从低到高处理下标，状态转移相同，可避免递归栈；排序带来 O(n log n)，扫描仍为 O(n·d)。

单调栈优化：可借助单调栈连接相邻的更高/更低关系，进一步优化到接近 O(n)，但相等高度、距离限制和双向连边的细节更复杂，面试中更容易出错。

常见错误

  • 遇到 arr[j] ≥ arr[i] 时写成 continue，错误穿过屏障。
  • 允许相等高度作为落点。
  • 只从最大值所在位置开始；最优起点不一定是全局最高点。
  • 返回跳跃次数而非访问下标数，导致少算起点。
  • 左右扫描共用停止状态，使一侧屏障影响另一侧。

路径恢复扩展

计算 dp[i] 时同时记录使其取得最大值的下一个位置 next[i]。找到全局最佳起点后，沿 next 指针走到末尾，即可恢复一条最优路径。并列时可按下标或字典序制定稳定规则。
