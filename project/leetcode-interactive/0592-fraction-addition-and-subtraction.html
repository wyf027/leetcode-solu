Full Solution

逐项解析、累加并随时约分

把当前答案始终维护为一个最简分数；读入下一项后交叉相乘完成通分，再用最大公约数归一化。

核心洞察

无须先拆出整个表达式或寻找统一的全局分母。若当前累计值是 a/b，下一项是 c/d，则直接更新为：

(a × d + c × b) / (b × d)

随后立即除以分子、分母的最大公约数。这样每轮结束时，累计值都保持最简。

完整过程

  1. 令累计分数为 0/1。
  2. 从左到右读取可选正负号、分子、斜杠和分母。
  3. 用交叉相乘把累计值与当前项合并。
  4. 计算 gcd(|分子|, 分母)，同时除以它。
  5. 所有项处理完后，输出 分子/分母。

正确性证明

初始化正确：处理任何输入项之前，累计值 0/1 等于空前缀的和，且已是最简形式。
单步保持数值：假设累计值 a/b 等于前 k 项之和。下一项为 c/d 时，交叉相乘得到 (ad + cb)/(bd)，它与 a/b + c/d 完全等值，因此新累计值等于前 k+1 项之和。
约分保持数值且保证最简：分子、分母同除以它们的最大公约数不会改变分数值；除尽最大公约数后两者互质，因此结果为最简分数。分母由正分母相乘得到，始终为正。
终止结论：循环处理完所有项后，累计值等于完整表达式的值，并且是分母为正的最简分数，所以返回格式与题目要求一致。

边界情况

  • 首项可以带负号，也可以没有符号。
  • 中间结果或最终结果可能为零；gcd(0, d) = d，会自然归一成 0/1。
  • 结果为整数时，约分后的分母自然变为 1。
  • 始终让负号留在分子，分母保持正数。

复杂度

设表达式长度为 n，共有 m 个分数。扫描字符需要 O(n)；每项执行一次欧几里得算法，数值部分约为 O(log V)。总时间可写为 O(n + m log V)，额外空间为 O(1)（不计返回字符串）。

替代方案

  • 正则拆项：先用模式提取所有带符号分数，再逐项累加。代码短，但不同语言的正则细节和临时数组会增加复杂度。
  • 最小公倍数通分：用 lcm(b,d) 作为新分母，可让中间数字更小；不过即使直接用 b×d，每轮立即约分也已足够清晰。
  • 一次性全局通分：先求所有分母的最小公倍数再求和，能做但需要保存或二次扫描，没必要。

面试追问

  • 如果分子、分母可能超过 32 位，如何改成大整数实现？
  • 如果表达式允许空格、括号或乘除，解析器应如何扩展？
  • 为什么每轮约分可以降低溢出风险？能否改用 LCM 进一步降低？
  • 如何设计一个不可变的 Fraction 类型封装规范化规则？

常见错误

  • 只按 + 切分字符串，导致负号丢失。
  • 交叉相乘时写成 a×b + c×d，混淆了分子与对方分母。
  • 只在最后约分，使中间分子、分母不必要地增长。
  • 用带符号分子直接调用不接受负数的 GCD，或忘记取绝对值。
  • 结果为零时输出 0/d，或结果为整数时漏掉 /1。

Java · Solution.fractionAddition 
class Solution {
    public String fractionAddition(String expression) {
        long numerator = 0;
        long denominator = 1;
        int i = 0;

        while (i < expression.length()) {
            int sign = 1;
            char ch = expression.charAt(i);
            if (ch == '+' || ch == '-') {
                sign = ch == '-' ? -1 : 1;
                i++;
            }

            long currentNumerator = 0;
            while (i < expression.length() && Character.isDigit(expression.charAt(i))) {
                currentNumerator = currentNumerator * 10 + expression.charAt(i) - '0';
                i++;
            }
            i++; // skip '/'

            long currentDenominator = 0;
            while (i < expression.length() && Character.isDigit(expression.charAt(i))) {
                currentDenominator = currentDenominator * 10 + expression.charAt(i) - '0';
                i++;
            }
            currentNumerator *= sign;

            numerator = numerator * currentDenominator
                    + currentNumerator * denominator;
            denominator *= currentDenominator;

            long divisor = gcd(Math.abs(numerator), denominator);
            numerator /= divisor;
            denominator /= divisor;
        }

        return numerator + "/" + denominator;
    }

    private long gcd(long a, long b) {
        while (b != 0) {
            long remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }
}

/**
 * @param {string} expression
 * @return {string}

var fractionAddition = function(expression) {
    let numerator = 0;
    let denominator = 1;
    let i = 0;

    const gcd = (a, b) => {
        a = Math.abs(a);
        while (b !== 0) {
            [a, b] = [b, a % b];
        }
        return a;
    };

    while (i < expression.length) {
        let sign = 1;
        if (expression[i] === "+" || expression[i] === "-") {
            sign = expression[i] === "-" ? -1 : 1;
            i++;
        }

        let currentNumerator = 0;
        while (i < expression.length && expression[i] !== "/") {
            currentNumerator = currentNumerator * 10 + Number(expression[i]);
            i++;
        }
        i++; // skip '/'

        let currentDenominator = 0;
        while (i < expression.length && expression[i] >= "0" && expression[i] <= "9") {
            currentDenominator = currentDenominator * 10 + Number(expression[i]);
            i++;
        }
        currentNumerator *= sign;

        numerator = numerator * currentDenominator
            + currentNumerator * denominator;
        denominator *= currentDenominator;

        const divisor = gcd(numerator, denominator);
        numerator /= divisor;
        denominator /= divisor;
    }

    return `${numerator}/${denominator}`;
};

class Solution:
    def fractionAddition(self, expression: str) -> str:
        def gcd(a: int, b: int) -> int:
            a = abs(a)
            while b:
                a, b = b, a % b
            return a

        numerator, denominator = 0, 1
        i, n = 0, len(expression)

        while i < n:
            sign = 1
            if expression[i] in "+-":
                sign = -1 if expression[i] == "-" else 1
                i += 1

            current_numerator = 0
            while i < n and expression[i].isdigit():
                current_numerator = current_numerator * 10 + int(expression[i])
                i += 1
            i += 1  # skip '/'

            current_denominator = 0
            while i < n and expression[i].isdigit():
                current_denominator = current_denominator * 10 + int(expression[i])
                i += 1
            current_numerator *= sign

            numerator = (
                numerator * current_denominator
                + current_numerator * denominator
            )
            denominator *= current_denominator

            divisor = gcd(numerator, denominator)
            numerator //= divisor
            denominator //= divisor

        return f"{numerator}/{denominator}"

class Solution {

        long long numerator = 0;
        long long denominator = 1;
        int i = 0;

        while (i < static_cast<int>(expression.size())) {
            int sign = 1;
            if (expression[i] == '+' || expression[i] == '-') {
                sign = expression[i] == '-' ? -1 : 1;
                ++i;
            }

            long long currentNumerator = 0;
            while (i < static_cast<int>(expression.size())
                    && isdigit(expression[i])) {
                currentNumerator = currentNumerator * 10 + expression[i] - '0';
                ++i;
            }
            ++i; // skip '/'

            long long currentDenominator = 0;
            while (i < static_cast<int>(expression.size())
                    && isdigit(expression[i])) {
                currentDenominator = currentDenominator * 10 + expression[i] - '0';
                ++i;
            }
            currentNumerator *= sign;

                    + currentNumerator * denominator;
            denominator *= currentDenominator;

            long long divisor = std::gcd(llabs(numerator), denominator);
            numerator /= divisor;
            denominator /= divisor;
