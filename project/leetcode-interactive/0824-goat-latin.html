题目描述

转换规则

toGoatLatin(sentence)

给定字符串 sentence，其中的单词由单个空格分隔，每个单词只含大小写英文字母。请按照下列规则逐词转换，并返回由转换结果组成的完整句子。

1

元音开头

若首字母是 a/e/i/o/u（不区分大小写），保留原词，并在末尾添加 ma。

2

辅音开头

把首字母移动到词尾，再添加 ma。例如 goat 先变为 oatg。

3

位置后缀

按从 1 开始的单词序号，再追加相同数量的 a：第 1 个加一个，第 2 个加两个，以此类推。

示例 1

输入sentence = "I speak Goat Latin"
输出"Imaa peaksmaaa oatGmaaaa atinLmaaaaa"

示例 2

输入sentence = "The quick brown fox jumped over the lazy dog"
输出"heTmaa uickqmaaa rownbmaaaa oxfmaaaaa umpedjmaaaaaa overmaaaaaaa hetmaaaaaaaa azylmaaaaaaaaa ogdmaaaaaaaaaa"

约束

  • 1 <= sentence.length <= 150
  • sentence 仅由英文字母与空格组成。
  • sentence 没有前导或尾随空格。
  • 相邻单词之间恰好有一个空格。

Solution

一次扫描，逐词构造

时间 O(n) · 空间 O(n)

核心洞察

每个单词的变换只依赖两个信息：它的首字母，以及它在句子中的序号。单词之间互不影响，因此拆分后按顺序独立构造，最后用空格连接即可。

完整过程

  1. 按空格拆分 sentence。
  2. 若首字母为元音，保留单词；否则把首字母移到末尾。
  3. 追加 ma，再追加 i + 1 个 a。
  4. 把全部新单词用单个空格连接。

正确性说明

对任意第 i 个单词：算法先依据首字母类别执行题目规定的唯一一种前缀变换，随后添加 ma，再添加恰好 i + 1 个 a。所以生成词与规则完全一致。按原顺序连接所有生成词，得到的句子也与要求一致。

复杂度

设输入总字符数为 n。每个输入字符只参与常数次处理，输出构造耗时 O(n)；返回字符串及临时结果占用 O(n) 空间。

边界情况

  • 单字符元音，如 "A"。
  • 单字符辅音，如 "b"，移位后内容仍为 b。
  • 大小写元音都必须识别。
  • 只有一个单词时，位置后缀仍为一个 a。
  • 接近 150 字符的输入需要高效拼接。

替代方案

也可以逐字符扫描，在遇到空格时完成当前单词，从而避免显式的单词数组。不过输入上限很小，直接 split 更清晰，通常更适合面试表达。

class Solution {
    public String toGoatLatin(String sentence) {
        String vowels = "aeiouAEIOU";
        String[] words = sentence.split(" ");
        StringBuilder answer = new StringBuilder();

        for (int i = 0; i < words.length; i++) {
            String word = words[i];
            if (i > 0) {
                answer.append(' ');
            }

            if (vowels.indexOf(word.charAt(0)) >= 0) {
                answer.append(word);
            } else {
                answer.append(word.substring(1));
                answer.append(word.charAt(0));
            }

            answer.append("ma");
            answer.append("a".repeat(i + 1));
        }

        return answer.toString();
    }
}
/**
 * @param {string} sentence
 * @return {string}

var toGoatLatin = function(sentence) {
    const vowels = new Set(['a', 'e', 'i', 'o', 'u']);

    return sentence.split(' ').map((word, index) => {
        const startsWithVowel = vowels.has(word[0].toLowerCase());
        const base = startsWithVowel
            ? word
            : word.slice(1) + word[0];

        return base + 'ma' + 'a'.repeat(index + 1);
    }).join(' ');
};
class Solution:
    def toGoatLatin(self, sentence: str) -> str:
        vowels = set("aeiouAEIOU")
        converted = []

        for index, word in enumerate(sentence.split()):
            if word[0] in vowels:
                base = word
            else:
                base = word[1:] + word[0]

            converted.append(base + "ma" + "a" * (index + 1))

        return " ".join(converted)
class Solution {
public:
    string toGoatLatin(string sentence) {
        istringstream input(sentence);
        vector<string> converted;
        string word;
        int index = 1;

        auto isVowel = [](char ch) {
            const string vowels = "aeiouAEIOU";
            return vowels.find(ch) != string::npos;
        };

        while (input >> word) {
            if (!isVowel(word[0])) {
                word = word.substr(1) + word[0];
            }
            word += "ma" + string(index, 'a');
            converted.push_back(word);
            ++index;
        }

        string answer;
        for (int i = 0; i < static_cast<int>(converted.size()); ++i) {
            if (i > 0) answer += ' ';
            answer += converted[i];
        }
        return answer;
    }
};

面试追问

  • 如果分隔符可能是连续空白，解析逻辑应如何调整？
  • 怎样实现流式处理，避免先保存全部单词？
  • 如果“元音”扩展到 Unicode 字符，当前判断方式有什么局限？
  • 输出非常长时，为什么应避免在循环中反复创建大字符串？

常见错误

  • 只识别小写元音，漏掉 A/E/I/O/U。
  • 把从 0 开始的数组下标直接当作 a 的数量。
  • 辅音词先添加 ma，再错误地移动首字母。
  • 连接单词时多出前导、尾随或重复空格。
  • 在循环内使用低效的不可变字符串连续拼接。

速记

最后检查思路

判断元音时为什么要处理大小写？

题目允许大小写英文字母，因此 I、A 等大写元音也必须命中元音分支。

为什么位置使用 i + 1？

常见数组下标从 0 开始，但题目中的单词序号从 1 开始，所以第 i 个数组元素需要追加 i + 1 个 a。

单字符辅音能安全移动吗？

可以。去掉首字符后是空串，再把该字符接回去仍得到原字符，随后正常添加后缀。
