01 · Brief

题目说明

先理解输入与输出，题解仍保持收起。

给定一个 32 位整数 num，返回表示它的十六进制字符串。负整数按 32 位二进制补码解释。

结果中的字母必须为小写；除数字 0 本身外，不得出现前导零。

限制：不能调用直接把数字转换或格式化为十六进制字符串的内置方法。

约束

  • -231 ≤ num ≤ 231 - 1
示例 1 
输入：num = 26
输出："1a"
示例 2 
输入：num = -1
输出："ffffffff"

03 · Before the Reveal

三个观察线索

CLUE 01

为什么是 4 位？

一个十六进制位恰好覆盖 16 种状态，而 4 个二进制位也恰好有 16 种组合。

CLUE 02

负数为何不特殊分支？

一旦按 32 位补码观察，正数与负数都只是同一组比特；区别只在最高位。

CLUE 03

何时停止？

正数的高位归零即可停止；32 位负数最多也只会产生固定的 8 个十六进制字符。

Complete Walkthrough

位掩码 + 无符号右移

核心洞察

十六进制的基数是 16，即 2⁴。用 num & 15 取得最低 4 位，就得到当前十六进制位的数值 0..15；再右移 4 位继续处理。

对 Java、JavaScript 等存在有符号整数语义的语言，使用无符号右移或先固定到 32 位无符号值，便能让负数补码最终归零。

完整过程

  1. 若 num == 0，直接返回 "0"。
  2. 读取当前值最低 4 位，映射到字符表 0123456789abcdef。
  3. 因为先得到最低位，所以把字符添加到结果左端。
  4. 把当前值无符号右移 4 位；归零后返回结果。

正确性说明

循环不变量：每轮开始时，已经生成的字符串恰好等于原 32 位补码中已移除低位分组的十六进制表示，且顺序正确。

本轮掩码准确取得下一个低 4 位，并把对应字符放到现有结果左端，因此不变量继续成立。右移移除的正是这 4 位。循环结束时没有未处理的有效分组，所以结果完整；零由单独分支保证表示为 "0"。

边界与复杂度

  • 零：必须显式返回 "0"，否则循环不会执行。
  • 负数：按 32 位补码处理，最多得到 8 个字符。
  • 最小整数：-2³¹ 不需要取绝对值，避免溢出。
  • 时间：O(1)（32 位固定最多 8 轮）；若按位宽记为 O(w)。
  • 额外空间：O(1)（输出字符串不计；固定 8 位上限）。

替代方案

也可以反复对 16 取模并做整数除法，最后反转字符串；但负数仍需谨慎转换为 32 位无符号值。逐个二进制位扫描再每 4 位聚合可行，却更繁琐。直接调用 toString(16)、hex() 或格式化 API 不符合题目限制。

面试追问与常见错误

  • 若改成 64 位整数，循环上限与掩码类型如何调整？
  • 如何推广到任意 2ᵏ 进制？掩码应为 2ᵏ - 1。
  • 错误使用算术右移会让负数不断补 1，可能无法归零。
  • 忘记零的特判、字符顺序写反、输出大写字母，都是高频错误。
class Solution {
    public String toHex(int num) {
        if (num == 0) return "0";

        char[] digits = "0123456789abcdef".toCharArray();
        StringBuilder answer = new StringBuilder();

        while (num != 0) {
            answer.append(digits[num & 15]);
            num >>>= 4;
        }

        return answer.reverse().toString();
    }
}

var toHex = function(num) {
    if (num === 0) return "0";

    const digits = "0123456789abcdef";
    let answer = "";
    num = num >>> 0;

    while (num !== 0) {
        answer = digits[num & 15] + answer;
        num = num >>> 4;
    }

    return answer;
};

public:
    string toHex(int num) {

        unsigned int value = static_cast<unsigned int>(num);
        string answer;

        while (value != 0) {
            answer.push_back(digits[value & 15]);
            value >>= 4;
        }

        reverse(answer.begin(), answer.end());
