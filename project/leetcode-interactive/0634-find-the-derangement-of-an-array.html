01 · Problem

把限制说清楚

数组由 1 到 n 组成。一个排列若满足每个位置 i 上的数字都不等于 i，就称为错位排列。

给定整数 n，计算 [1, 2, …, n] 的错位排列数量。也就是说，对于结果排列 p，所有下标都必须满足 p[i] ≠ i（位置按 1 开始计数）。

由于答案可能很大，请返回答案对 1,000,000,007 取模后的结果。

示例 1

输入n = 3
输出2
说明有效排列为 [2,3,1]、[3,1,2]。

示例 2

输入n = 2
输出1
说明唯一有效排列是 [2,1]。

参数与约束

  • 函数：findDerangement(n)
  • n 为整数
  • 1 ≤ n ≤ 106
  • 返回值为错位排列数量对 109 + 7 取模后的整数
判断标准

数字 x 不能出现在第 x 个位置。只要有一个数字回到原位，整个排列就不合格。

04 · Full Solution

从一个人的选择，拆出两类子问题

核心不是枚举排列，而是观察“第 n 个人坐到哪里”后，剩余关系如何收缩。

核心洞察

设 D(n) 为 n 个人的错位排列数。第 n 个人不能坐座位 n，因此先从其余 n - 1 个座位中任选一个，记为 j。

两种互斥情形

  • j 恰好坐到座位 n：二人闭合，剩余贡献 D(n-2)。
  • j 不坐座位 n：收缩这条关系后，剩余贡献 D(n-1)。
D(n) = (n − 1) × [D(n − 1) + D(n − 2)]边界：D(0) = 1，D(1) = 0；每一步对 1,000,000,007 取模。

完整过程

  1. 用两个变量保存相邻状态：D(i-2) 与 D(i-1)。
  2. 从 i = 2 递推到 n。
  3. 按公式计算当前值并立即取模。
  4. 滚动更新两个变量，最终返回 D(n)。

边界与复杂度

  • n = 1：没有合法排列，返回 0。
  • D(0) = 1 是组合意义上的空排列，用于统一递推。
  • 时间复杂度 O(n)。
  • 额外空间复杂度 O(1)。

正确性证明

分类完整且互斥。

固定第 n 个人所选的错误座位 j 后，座位 j 对应的人要么坐到 n，要么不坐到 n；不存在第三种情况，也不会重复计数。

两类分别等价于更小问题。

第一类固定了 n 与 j 的相互占位，剩余 n−2 人必须构成错位排列，共 D(n−2) 种。第二类可移除第 n 个人并收缩相关座位映射，与 n−1 人的错位排列一一对应，共 D(n−1) 种。

乘上第一步选择。

j 有 n−1 种选择，且每个 j 下的计数相同，所以总数为 (n−1)[D(n−1)+D(n−2)]。从正确边界 D(0)、D(1) 出发归纳，递推得到的 D(n) 正确。

替代方案

容斥原理可得 D(n) = n! × Σ((-1)^k / k!)。它揭示了 D(n) 约等于 n! / e，但模运算下需要阶乘与逆元，代码更重；本题用线性递推更直接、空间也更小。

常见错误

  • 把 D(0) 写成 0，导致 D(2) 错误。
  • 乘法前使用 32 位整数，发生溢出。
  • 只在最后取模，中间数早已越界。
  • 误写为 D(n-1)+D(n-2)，漏掉 n−1 种座位选择。

面试追问

  • 如何用容斥原理推导闭式表达？
  • 为什么结果是最接近 n!/e 的整数？
  • 若某些人有多个禁坐座位，状态还能只依赖 n 吗？
  • 如何用矩阵快速幂处理结构变化后的递推？

实现提示

Java/C++ 用 64 位整数承接乘积。JavaScript 的本题乘积上界仍在安全整数范围内；Python 整数自动扩展。四种实现均保持相同状态定义，方便面试时迁移语言。

四语言完整代码

Java · LeetCode 提交O(n) / O(1)
class Solution {
    public int findDerangement(int n) {
        final long MOD = 1_000_000_007L;
        long prev2 = 1; // D(0)
        long prev1 = 0; // D(1)

        for (int i = 2; i <= n; i++) {
            long current = ((i - 1L) * (prev1 + prev2)) % MOD;
            prev2 = prev1;
            prev1 = current;
        }
        return (int) prev1;
    }
}

class Solution:

        mod = 1_000_000_007
        prev2 = 1  # D(0)

    int findDerangement(int n) {
        static constexpr long long MOD = 1'000'000'007LL;
        long long prev2 = 1; // D(0)
        long long prev1 = 0; // D(1)

        for (long long i = 2; i <= n; ++i) {

            prev2 = prev1;
