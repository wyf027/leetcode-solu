01 / Problem

把日期相同的订单
从表中辨认出来

表 Delivery 记录订单日期与顾客期望配送日期。若二者相同，该订单为“即时订单”；否则为“计划订单”。请计算即时订单占全部订单的百分比，并四舍五入到小数点后两位，结果列命名为 immediate_percentage。

表结构 · Delivery

官方元数据

customer_idINT · 顾客标识
order_dateDATE · 下单日期
customer_pref_delivery_dateDATE · 期望配送日期

约束与输出

  • delivery_id 的值唯一。
  • 每行表示一笔食物配送订单。
  • 下单日期不晚于顾客期望配送日期。
  • 输出恰好一行、一个百分比列，保留两位小数。

03 / Solution

准备好核对思路了吗？

题解、证明、代码与验证清单默认收起。

题解

MySQL

核心洞察

条件表达式 order_date = customer_pref_delivery_date 对每行给出真假。把“真”映射为 1、“假”映射为 0 后，平均值天然就是即时订单比例；再乘 100 并四舍五入到两位小数即可。

ROUND(AVG(order_date = customer_pref_delivery_date) * 100, 2)

完整过程

  1. 扫描 Delivery 的每一行。
  2. 比较下单日期和期望配送日期，得到 1 或 0。
  3. 对这些 1/0 求平均值，获得区间 [0, 1] 内的比例。
  4. 乘 100 转为百分比，使用 ROUND(..., 2) 保留两位小数，并设置要求的列别名。

正确性证明

设共有 n 笔订单，其中有 k 笔即时订单。对每笔订单定义指示值：即时为 1，计划为 0。所有指示值之和恰为 k，其平均值为 k / n。查询将该平均值乘 100，所以结果恰为即时订单占全部订单的百分比；最后的四舍五入只改变展示精度，不改变其统计含义。因此查询正确。

边界情况

  • 全部是即时订单：平均值为 1，结果为 100.00。
  • 全部是计划订单：平均值为 0，结果为 0.00。
  • 比例是循环小数：统一由 ROUND 处理到两位。
  • 若运行环境允许空表，AVG 会返回 NULL；题目通常提供至少一行。若业务上必须兜底，可外包 COALESCE(..., 0)。

复杂度

需要扫描全部 n 行，时间复杂度 O(n)；聚合只维护常数个状态，额外空间复杂度 O(1)。

替代方案

可使用 SUM(CASE WHEN ... THEN 1 ELSE 0 END) / COUNT(*)。它更跨数据库，但要注意小数除法与类型转换。MySQL 中直接对布尔表达式求平均更短，也与本题机制完全对应。

面试追问

  • 若要求按客户分组，应在哪里加入 GROUP BY customer_id？
  • PostgreSQL 不允许直接对布尔值求 AVG 时，怎样用 CASE 改写？
  • 若日期列可能为 NULL，应将未知订单排除还是算作非即时？业务口径会怎样影响分母？

常见错误

  • 只计算即时订单数量，忘记除以总订单数或乘 100。
  • 使用整数除法，导致非 100% 的比例被截断为 0。
  • 先把分子或中间比例过早取整，造成精度损失。
  • 列别名不是题目要求的 immediate_percentage。

实现代码

官方可提交语言：MySQL
SELECT
    ROUND(
        AVG(order_date = customer_pref_delivery_date) * 100,
        2
    ) AS immediate_percentage
FROM Delivery;
本地语义参考：数据库题无法以 Java 直接提交
import java.time.LocalDate;
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.List;

class Solution {
    record Delivery(int deliveryId, int customerId,
                    LocalDate orderDate,
                    LocalDate preferredDate) {}

    public static BigDecimal immediatePercentage(
            List<Delivery> deliveries) {
        if (deliveries.isEmpty()) {
            return new BigDecimal("0.00");
        }

        long immediate = deliveries.stream()
            .filter(d -> d.orderDate().equals(d.preferredDate()))
            .count();

        return BigDecimal.valueOf(immediate)
            .multiply(BigDecimal.valueOf(100))
            .divide(BigDecimal.valueOf(deliveries.size()),
                    2, RoundingMode.HALF_UP);
    }
}

/**
 * @param {Array<{order_date: string,
 *   customer_pref_delivery_date: string}>} deliveries
 * @return {string}
 */
function immediatePercentage(deliveries) {
  if (deliveries.length === 0) return "0.00";

  const immediate = deliveries.reduce(
    (count, row) =>
      count + Number(
        row.order_date === row.customer_pref_delivery_date
      ),
    0
  );

  return ((immediate * 100) / deliveries.length).toFixed(2);
}
本地语义参考：展示等价的 Python 数据处理
from decimal import Decimal, ROUND_HALF_UP
from typing import Iterable, TypedDict


class Delivery(TypedDict):
    order_date: str
    customer_pref_delivery_date: str


def immediate_percentage(
    deliveries: Iterable[Delivery],
) -> Decimal:
    rows = list(deliveries)
    if not rows:
        return Decimal("0.00")

    immediate = sum(
        row["order_date"]
        == row["customer_pref_delivery_date"]
        for row in rows
    )
    value = Decimal(immediate * 100) / Decimal(len(rows))
    return value.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
本地语义参考：数据库题无法以 C++ 直接提交
#include <cmath>
#include <string>
#include <vector>

struct Delivery {
    int deliveryId;
    int customerId;
    std::string orderDate;
    std::string preferredDate;
};

double immediatePercentage(
    const std::vector<Delivery>& deliveries
) {
    if (deliveries.empty()) return 0.0;

    int immediate = 0;
    for (const auto& row : deliveries) {
        if (row.orderDate == row.preferredDate) {
            ++immediate;
        }
    }

    const double raw = 100.0 * immediate / deliveries.size();
    return std::round(raw * 100.0) / 100.0;
}
