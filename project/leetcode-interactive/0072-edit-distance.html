Pattern brief

题意转述

给定两个只含小写英文字母的字符串 word1 与 word2，求把前者变成后者所需的最少操作数。一次操作可以插入、删除或替换一个字符；空字符串也属于合法输入。

官方样例 1

输入
word1 = "horse", word2 = "ros"
输出
3

官方样例 2

输入
word1 = "intention", word2 = "execution"
输出
5

官方约束：0 ≤ word1.length, word2.length ≤ 500。本页输入中的普通空格若出现，会用 ␠ 表示；空字符串用 "" 完整展示。

Sealed pattern notes

题解

默认隐藏。展开后查看洞察、完整过程、边界、复杂度与四语言代码。

核心洞察

直接思考完整字符串会产生大量重复分支。把问题缩小为“word1 前 i 个字符转成 word2 前 j 个字符”，最后一步只可能来自左、上或左上三个已知状态。

状态与转移

若末尾字符相同，dp[i][j] = dp[i-1][j-1]。否则取 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])，分别对应删除、插入、替换。

完整过程

  1. 建立 (m+1) × (n+1) 表格。
  2. 首列填 0..m，表示删除到空串。
  3. 首行填 0..n，表示从空串连续插入。
  4. 按行填其余格子，比较末尾字符并执行状态转移。
  5. 右下角即最小编辑距离。

边界与复杂度

  • 任一字符串为空，答案就是另一个字符串的长度。
  • 两个字符串相同，沿对角线复制，答案为 0。
  • 时间复杂度 O(mn)，二维表空间复杂度 O(mn)。

替代方案取舍

只求答案时可把空间压缩为 O(min(m,n))；但二维表更容易解释、回溯具体编辑序列，是面试首轮最稳妥的写法。暴力递归会重复计算，复杂度指数级。

常见错误

  • 忘记矩阵多出一行一列表示空前缀。
  • 把插入与删除的来源方向写反。
  • 字符相同时仍然额外加 1。
  • 循环从 0 开始导致访问负下标。

面试追问

  • 如何输出一条具体的最优编辑序列？
  • 如何把空间降到一维？
  • 若三种操作代价不同，转移式怎么改？
  • 如何扩展到允许交换相邻字符？
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        int[][] dp = new int[m + 1][n + 1];

        for (int i = 0; i <= m; i++) dp[i][0] = i;
        for (int j = 0; j <= n; j++) dp[0][j] = j;

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = 1 + Math.min(
                        dp[i - 1][j - 1],
                        Math.min(dp[i - 1][j], dp[i][j - 1])
                    );
                }
            }
        }
        return dp[m][n];
    }
}

  const n = word2.length;

    Array(n + 1).fill(0),
  );

  for (let i = 0; i <= m; i += 1) dp[i][0] = i;
  for (let j = 0; j <= n; j += 1) dp[0][j] = j;

      }
    }
  }
