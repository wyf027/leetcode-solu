矩阵中和能被 K
整除的路径

Paths in Matrix Whose Sum Is Divisible by K

只能向右或向下。从左上走到右下，哪些路线的数字总和恰好是 K 的倍数？

官方题目 ↗

01 / THE CHALLENGE

题目说明

给定整数矩阵 grid（m × n）和正整数 k，下标从 0 开始。从 (0, 0) 出发，每次只移动到右侧或下侧的相邻格，最终到达 (m − 1, n − 1)。路径和包含起点、终点及途中每个格子的值。

返回路径和可被 k 整除的不同路径条数，并对 1,000,000,007 取余。不同的走格顺序对应不同路径，即使数字相同也分别计数。

参数与返回值
numberOfPaths(grid: integer[][], k: integer) → integer

约束

  • m == grid.length，n == grid[i].length。
  • 1 ≤ m, n ≤ 5 × 10⁴。
  • 1 ≤ m × n ≤ 5 × 10⁴。
  • 0 ≤ grid[i][j] ≤ 100。
  • 1 ≤ k ≤ 50。

官方示例

示例 1

grid = [[5,2,4],[3,0,5],[0,7,2]]
k = 3

输出：2

两条合法路径的数字分别为 5 → 2 → 4 → 5 → 2（和为 18），以及 5 → 3 → 0 → 5 → 2（和为 15）。

示例 2

grid = [[0,0]]
k = 5

输出：1

仅有一条路径，路径和为 0；0 可以被 5 整除。

示例 3

grid = [[7,3,4,9],[2,3,6,2],[2,3,7,0]]
k = 1

输出：10

任何整数都能被 1 整除，因此全部 10 条路径都合法。

02 / REMAINDER ROUTING

把路径和，压缩成余数

核心洞察

我们不需要记住完整路径和，只需要知道它除以 k 的余数。若两条前缀路径到达同一格且余数相同，继续走任何相同后缀时，最终能否整除的结果也相同。因此可将它们合并为一个计数。

定义 dp[i][j][r]：到达格子 (i,j)，且包含该格后的路径和余数为 r 的路径数。

v = grid[i][j] % k
newR = (r + v) % k
dp[i][j][newR] += dp[i-1][j][r] + dp[i][j-1][r]
每次相加后对 MOD = 1_000_000_007 取余

越界来源视为 0；起点单独设置 dp[0][0][grid[0][0] % k] = 1。最终取右下格的余数 0 桶。

交互实验 · 余数桶接力

逐格处理 / 上方 + 左方 → 当前格

每次前进一步，完成一个格子的所有余数转移。蓝色实心为当前格，浅蓝为已处理格，虚线标出直接来源。桶中显示到达该格的路径数。此演示不代表测试或验证结果。

完整过程与滚动数组

  1. 准备 n 个长度为 k 的桶数组，全部置零。
  2. 按行从上到下、每行从左到右遍历。
  3. 处理当前格前，dp[j] 还是上一行同一列的桶；dp[j-1] 已是本行左格的桶。
  4. 新建全零 cur，对所有旧余数累加两个来源，再加当前值并取余，放入新桶。
  5. 用 cur 替换 dp[j]。返回 dp[n-1][0]。

示例 1 中，起点 5 的桶为 [0,0,1]。加入右侧的 2 后移入余数 1 桶；加入下侧的 3 后仍在余数 2 桶。不同来源在汇合格中累加。

为什么正确

基础：起点仅有一条只含自身的路径，其余数是起点值对 k 取余，初始化准确。

归纳：到达非起点格的路径，最后一步必然来自上方或左方，两类路径互斥且覆盖全部可能。假设来源桶准确，加入当前值后余数唯一变为 (r+v)%k；按该映射相加，不漏计也不重复。

结论：行优先顺序保证来源已处理；归纳到终点后，余数 0 桶恰是所求。计数模 MOD 的加法保持最终结果的同余关系。

复杂度与边界

时间 O(mnk)，辅助空间 O(nk)，每格枚举 k 个余数。新建的 cur 只额外占 O(k)，不累计保存旧行。若改为沿短边存储，可进一步写成 O(min(m,n)k) 空间，但需要调整访问方向。

  • 单格：该数字能整除 k 则答案 1，否则 0。
  • 单行或单列：只能走一条路线，判断全部数字之和即可。
  • k = 1：所有路径均合法；全零矩阵在任意 k 下也一样。
  • 起点和终点都要计入；取余数的 k 与计数模数 MOD 不可混用。
  • Java / C++ 两个已取模计数之和最大 2,000,000,012，小于有符号 32 位整数上限；JavaScript 也能精确表示。

替代方案

三维 DP：同样 O(mnk) 时间，使用 O(mnk) 空间，便于保留每个格子的桶以回看过程；上方演示使用这种表示。

记忆化搜索：以 (i,j,r) 为状态也可达到 O(mnk)，但递归深度可达 m+n−1，细长矩阵可能触发栈溢出。

枚举全部路径：路线数为组合数 C(m+n−2,m−1)，随规模快速增长，只适用于手工探索小矩阵。

常见错误

  • 只记录每格一个总路径数，丢失余数，后续无法判断哪些路径合法。
  • 在旧桶上原地加当前值，导致同一格的新状态又被读取。必须创建 cur。
  • 滚动数组从右向左更新，却仍使用 dp[j−1] 作为本行左格，读到了上一行。
  • 把起点设成余数 0 桶的 1，却没有再处理起点数字。
  • 仅在最后取计数模数，中间可能溢出。

面试追问

目标余数改为 t？返回终点的 t 桶。允许负数？将余数规范为 ((x % k) + k) % k。加入障碍格？该格桶清零，禁止转移穿过。还要输出一条路线？不能直接用取模计数是否非零判断可达性，真实正数可能模为零；另存布尔可达状态和前驱，再回溯。

Java

class Solution {
    public int numberOfPaths(int[][] grid, int k) {
        final int MOD = 1_000_000_007;
        int m = grid.length, n = grid[0].length;
        int[][] dp = new int[n][k];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int[] cur = new int[k];
                int v = grid[i][j] % k;
                if (i == 0 && j == 0) {
                    cur[v] = 1;
                } else {
                    for (int r = 0; r < k; r++) {
                        int ways = dp[j][r];
                        if (j > 0) {
                            ways = (ways + dp[j - 1][r]) % MOD;
                        }
                        cur[(r + v) % k] = ways;
                    }
                }
                dp[j] = cur;
            }
        }
        return dp[n - 1][0];
    }
}

/**

 * @param {number} k

var numberOfPaths = function(grid, k) {
    const MOD = 1_000_000_007;
    const m = grid.length, n = grid[0].length;
    const dp = Array.from({length: n}, () => Array(k).fill(0));
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            const cur = Array(k).fill(0);
            const v = grid[i][j] % k;
            if (i === 0 && j === 0) {
                cur[v] = 1;
            } else {
                for (let r = 0; r < k; r++) {
                    const left = j > 0 ? dp[j - 1][r] : 0;
                    cur[(r + v) % k] = (dp[j][r] + left) % MOD;
                }
            }
            dp[j] = cur;
        }
    }
    return dp[n - 1][0];
};

Python

from typing import List

class Solution:
    def numberOfPaths(self, grid: List[List[int]], k: int) -> int:
        MOD = 1_000_000_007
        m, n = len(grid), len(grid[0])
        dp = [[0] * k for _ in range(n)]
        for i in range(m):
            for j in range(n):
                cur = [0] * k
                v = grid[i][j] % k
                if i == 0 and j == 0:
                    cur[v] = 1
                else:
                    for r in range(k):
                        left = dp[j - 1][r] if j > 0 else 0
                        cur[(r + v) % k] = (dp[j][r] + left) % MOD
                dp[j] = cur
        return dp[n - 1][0]

C++

#include <vector>
using namespace std;

class Solution {
public:
    int numberOfPaths(vector<vector<int>>& grid, int k) {
        const int MOD = 1000000007;
        int m = grid.size(), n = grid[0].size();
        vector<vector<int>> dp(n, vector<int>(k, 0));
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                vector<int> cur(k, 0);
                int v = grid[i][j] % k;
                if (i == 0 && j == 0) {
                    cur[v] = 1;
                } else {
                    for (int r = 0; r < k; ++r) {
                        int left = j > 0 ? dp[j - 1][r] : 0;
                        cur[(r + v) % k] = (dp[j][r] + left) % MOD;
                    }
                }
                dp[j].swap(cur);
            }
        }
        return dp[n - 1][0];
    }
};

代码中直接赋值 cur[(r+v)%k] 是因为固定 v 时该映射是一一对应；来自上、左的计数已先相加。
