按位与为零的三元组

Triples with Bitwise AND Equal To Zero。先把三重枚举折叠成“二元按位与的频次”，再寻找与第三个数互补的掩码。

位运算数组哈希表 / 频次数组非付费题

题目

给定整数数组 nums，统计有序下标三元组 (i, j, k) 的数量。三个下标都可独立取遍 [0, nums.length)（允许相等），且必须满足 nums[i] & nums[j] & nums[k] == 0。

示例 1

输入：nums = [2,1,3]
输出：12
解释：共有 12 个有序下标三元组满足条件，
例如 (0,0,1)、(0,1,0)、(2,1,0)。

示例 2

输入：nums = [0,0,0]
输出：27

约束

  • 1 <= nums.length <= 1000
  • 0 <= nums[i] < 2^16

题解：统计二元 AND

核心洞察：把 nums[i] & nums[j] 的所有结果先计数。随后对每个 nums[k]，累加所有满足 mask & nums[k] == 0 的 pairCount[mask]。

完整过程

  1. 数值小于 2^16，因此二元 AND 的结果也只在 [0, 2^16) 内。
  2. 建立长度 65536 的频次数组。枚举全部有序对 (i,j)，令 pairCount[nums[i] & nums[j]]++。
  3. 枚举每个第三元素 x 与全部掩码 mask。若 (mask & x) == 0，将该掩码的二元对数量加入答案。

正确性证明

  1. 计数完整。第一阶段逐个枚举所有有序下标对，因此每个 (i,j) 恰好被放入其唯一的 AND 结果桶。
  2. 判定等价。对固定的 k，条件 (nums[i] & nums[j]) & nums[k] == 0 正好等价于其桶掩码与 nums[k] 相与为零。
  3. 无重无漏。第二阶段为每个 k 加入全部且仅有合格桶中的有序对；故每个合法 (i,j,k) 恰好计入一次，非法三元组不会计入。

边界与复杂度

  • 数组只有一个元素时，下标可以重复；算法仍会统计唯一的有序三元组。
  • 若元素全为 0，则所有 n^3 个三元组都合法。
  • 时间复杂度 O(n² + n·2^16)，空间复杂度 O(2^16)。

替代方案

可以用哈希表只遍历实际出现的 AND 结果；在结果很稀疏时更快，但最坏仍可能有很多键。也可使用子集和（SOS DP）预处理某掩码所有子集的频次，将第二阶段降至 O(16·2^16+n)，实现更复杂。

面试追问

  • 为什么是有序三元组，且下标允许重复？因为三个下标各自独立取值。
  • 怎样用补集理解判定？mask 必须是 16 位范围内 ~x 的子掩码。
  • 值域扩大到 30 位怎么办？优先用哈希表存实际 AND 结果，避免分配 2^30 数组。

常见错误

  • 把三元组误当成无序组合，或强制 i,j,k 互不相同。
  • 只统计不同 AND 值，忘记保存每个值对应的有序对频次。
  • JavaScript 用普通按位运算处理超过 32 位的值；本题值域在 16 位内，没有这个问题。

四语言完整代码

Java

官方签名
class Solution {
    public int countTriplets(int[] nums) {
        int[] pairCount = new int[1 << 16];
        for (int a : nums) {
            for (int b : nums) pairCount[a & b]++;
        }
        int answer = 0;
        for (int x : nums) {
            for (int mask = 0; mask < pairCount.length; mask++) {
                if ((mask & x) == 0) answer += pairCount[mask];
            }
        }
        return answer;
    }
}

Python 3

官方签名
from typing import List

class Solution:
    def countTriplets(self, nums: List[int]) -> int:
        pair_count = [0] * (1 << 16)
        for a in nums:
            for b in nums:
                pair_count[a & b] += 1

        answer = 0
        for x in nums:
            for mask, count in enumerate(pair_count):
                if mask & x == 0:
                    answer += count
        return answer

C++

官方签名
class Solution {
public:
    int countTriplets(vector<int>& nums) {
        vector<int> pairCount(1 << 16);
        for (int a : nums) {
            for (int b : nums) ++pairCount[a & b];
        }
        int answer = 0;
        for (int x : nums) {
            for (int mask = 0; mask < (1 << 16); ++mask) {
                if ((mask & x) == 0) answer += pairCount[mask];
            }
        }
        return answer;
    }
};
