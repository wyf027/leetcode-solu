Shortest Bridge

最短的桥

先认识两座岛，再观察水波如何一圈圈扩散。答案藏在相遇之前，而题解会留到你主动展开。

Problem

题意

给定一个 n × n 二元矩阵 grid：1 是陆地，0 是水域。上下左右相连的陆地组成岛屿，矩阵中恰好有两座岛。

你可以把若干个水格翻成陆地。返回连接两座岛所需翻转的最少水格数量。

函数形式： shortestBridge(grid: integer[][]): integer

Constraints

约束

  • n == grid.length == grid[i].length
  • 2 ≤ n ≤ 100
  • grid[i][j] 只能是 0 或 1
  • 矩阵中恰好有两座岛

Official examples

示例

输出：1

              [1,0,1,0,1],

输出：1

Solution

题解：整座岛作为 BFS 起点

核心洞察

任意一条桥都从第一座岛的某个格子出发。与其分别尝试每个格子，不如把第一座岛的全部格子同时放进队列，进行多源 BFS。BFS 每扩张一层，代表多翻转一个水格；第一次碰到第二座岛时，层数必然最小。

完整过程

  1. 扫描矩阵，找到任意一个陆地格。
  2. 用 DFS/BFS 标记它所属的整座岛，并把岛上所有格加入队列。
  3. 从整座岛同步向外做分层 BFS；未访问水格入队并标记。
  4. 若下一格是第二座岛的陆地，返回当前扩张层数。

为什么正确

引理 1：标记阶段恰好收集第一座岛，因为遍历只沿四方向经过相连的陆地。

引理 2：多源 BFS 的第 d 层包含所有距第一座岛最少经过 d 个水格可达的位置，这是 BFS 的逐层最短路性质。

结论：首次触及第二座岛时不存在使用更少水格的路径，否则它应在更早一层被发现，因此返回值就是最少翻转数。

复杂度

每个格子至多进入遍历常数次：时间 O(n²)，队列与访问标记空间 O(n²)。

边界情况

  • 两岛只隔一个水格，答案为 1
  • 岛屿贴近矩阵边缘
  • 一座岛包围另一座岛
  • 岛的形状细长、不规则

替代方案

可从每个岛格单独 BFS，但会重复搜索。也可做双向 BFS，理论上缩小前沿，却增加标记与距离管理复杂度；本题上单向多源 BFS 已是线性级。

面试追问

  • 为什么队列要初始化为整座岛？
  • 若有多座岛，如何求任意两岛最短桥？
  • 若翻转不同水格成本不同怎么办？

常见错误

  • 只把第一座岛的一个格子作为 BFS 起点，错过更近的边界。
  • 把碰到第二座岛的那一步也计作翻转；陆地本身无需翻转。
  • 水格入队时不立即标记，导致重复入队。
  • DFS 递归过深时忽略语言栈限制；可改用显式栈。

class Solution {
    private final int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
    public int shortestBridge(int[][] grid) {
        int n = grid.length;
        boolean[][] seen = new boolean[n][n];
        java.util.ArrayDeque<int[]> queue = new java.util.ArrayDeque<>();
        boolean found = false;
        for (int r = 0; r < n && !found; r++) {
            for (int c = 0; c < n; c++) if (grid[r][c] == 1) {
                mark(grid, r, c, seen, queue); found = true; break;
            }
        }
        int distance = 0;
        while (!queue.isEmpty()) {
            for (int size = queue.size(); size > 0; size--) {
                int[] cur = queue.remove();
                for (int[] d : dirs) {
                    int nr = cur[0] + d[0], nc = cur[1] + d[1];
                    if (nr < 0 || nr >= n || nc < 0 || nc >= n || seen[nr][nc]) continue;
                    if (grid[nr][nc] == 1) return distance;
                    seen[nr][nc] = true; queue.add(new int[]{nr, nc});
                }
            }
            distance++;
        }
        return -1;
    }
    private void mark(int[][] g, int r, int c, boolean[][] seen, java.util.ArrayDeque<int[]> q) {
        int n = g.length;
        if (r < 0 || r >= n || c < 0 || c >= n || seen[r][c] || g[r][c] == 0) return;
        seen[r][c] = true; q.add(new int[]{r, c});
        for (int[] d : dirs) mark(g, r + d[0], c + d[1], seen, q);
    }
}
var shortestBridge = function(grid) {
    const n = grid.length, seen = Array.from({length:n}, () => Array(n).fill(false));
    const q = [], dirs = [[1,0],[-1,0],[0,1],[0,-1]];
    const mark = (sr, sc) => {
        const stack = [[sr, sc]]; seen[sr][sc] = true;
        while (stack.length) {
            const [r,c] = stack.pop(); q.push([r,c]);
            for (const [dr,dc] of dirs) {
                const nr=r+dr, nc=c+dc;
                if (nr>=0 && nr<n && nc>=0 && nc<n && !seen[nr][nc] && grid[nr][nc]===1) {
                    seen[nr][nc]=true; stack.push([nr,nc]);
                }
            }
        }
    };
    outer: for (let r=0;r<n;r++) for (let c=0;c<n;c++) if (grid[r][c]===1) { mark(r,c); break outer; }
    let head=0, distance=0;
    while (head<q.length) {
        const end=q.length;
        while (head<end) {
            const [r,c]=q[head++];
            for (const [dr,dc] of dirs) {
                const nr=r+dr,nc=c+dc;
                if (nr<0||nr>=n||nc<0||nc>=n||seen[nr][nc]) continue;
                if (grid[nr][nc]===1) return distance;
                seen[nr][nc]=true; q.push([nr,nc]);
            }
        }
        distance++;
    }
    return -1;
};
from collections import deque
from typing import List

class Solution:
    def shortestBridge(self, grid: List[List[int]]) -> int:
        n = len(grid)
        seen = [[False] * n for _ in range(n)]
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))
        q = deque()
        def mark(sr: int, sc: int) -> None:
            stack = [(sr, sc)]
            seen[sr][sc] = True
            while stack:
                r, c = stack.pop()
                q.append((r, c))
                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < n and 0 <= nc < n and not seen[nr][nc] and grid[nr][nc] == 1:
                        seen[nr][nc] = True
                        stack.append((nr, nc))
        done = False
        for r in range(n):
            for c in range(n):
                if grid[r][c] == 1:
                    mark(r, c); done = True; break
            if done: break
        distance = 0
        while q:
            for _ in range(len(q)):
                r, c = q.popleft()
                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc
                    if not (0 <= nr < n and 0 <= nc < n) or seen[nr][nc]: continue
                    if grid[nr][nc] == 1: return distance
                    seen[nr][nc] = True
                    q.append((nr, nc))
            distance += 1
        return -1
