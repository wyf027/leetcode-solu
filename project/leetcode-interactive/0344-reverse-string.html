Problem

题目要求

编写函数 reverseString(s)，将字符数组 s 表示的字符串反转。

必须直接修改传入的数组，不创建另一份同等规模的字符数组；额外空间复杂度要求为 O(1)。函数不返回反转后的数组，评测器会读取修改后的参数 s。

示例 1

输入

s = ["h","e","l","l","o"]

输出（修改后的 s）

["o","l","l","e","h"]

示例 2

输入

s = ["H","a","n","n","a","h"]

输出（修改后的 s）

["h","a","n","n","a","H"]

函数参数形式

参数：s: character[]
返回：void
输出来源：修改后的参数 s

约束

  • 1 <= s.length <= 10^5
  • s[i] 是 ASCII 码表中的可打印字符。
  • 修改必须在输入数组内完成，额外空间为常数级。

Solution

双指针原地反转

核心洞察

反转后，原下标 i 的字符应移动到 n - 1 - i。因此用指针 left 和 right 分别从数组两端向中间移动，每轮交换两端字符。指针相遇或交错时，所有镜像位置都已处理完。

完整过程

  1. 初始化 left = 0，right = s.length - 1。
  2. 当 left < right 时，交换 s[left] 与 s[right]。
  3. 令 left++、right--，继续处理尚未确定的内部区间。
  4. 循环结束，不返回数组；修改已直接保存在 s 中。

循环不变式

每轮循环开始时，区间 [0, left) 和 (right, n-1] 已经位于最终反转位置；仅闭区间 [left, right] 尚待处理。

正确性证明

1

初始化

循环前两侧已处理区间为空，不变式自然成立。

2

保持

交换当前两端后，它们分别到达镜像位置；指针内移，不变式继续成立。

3

终止

当指针相遇或交错，未处理区间最多一个字符；全部位置均正确，数组已反转。

时间复杂度

O(n)

每个字符至多参与一次交换。

额外空间

O(1)

仅保存两个指针与一个临时字符。

交换次数

⌊n / 2⌋

恰好覆盖每一对镜像位置。

边界情况

  • 单字符：left == right，循环不执行，原数组就是答案。
  • 偶数长度：指针在中央两个字符交换后交错。
  • 奇数长度：中央字符无需移动，指针在该位置相遇。
  • 重复字符或回文：算法不依赖字符是否相同；即使结果看似不变，过程仍正确。
  • 最大规模：线性扫描可处理 10^5 个字符，且不分配等长数组。

四语言完整代码

均遵循官方签名，直接修改参数并返回 void / None。

Java
class Solution {
    public void reverseString(char[] s) {
        int left = 0;
        int right = s.length - 1;

        while (left < right) {
            char temp = s[left];
            s[left] = s[right];
            s[right] = temp;
            left++;
            right--;
        }
    }
}

from typing import List


class Solution:
    def reverseString(self, s: List[str]) -> None:
        left, right = 0, len(s) - 1

        while left < right:
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1

替代方案

  • 语言内置反转：代码简短，但面试中可能掩盖核心机制；仍需确认其是否原地以及空间开销。
  • 递归交换：也能按镜像位置处理，但调用栈占用 O(n)，不满足本题常数额外空间要求。
  • 新建反转数组：直观但需要 O(n) 额外空间，直接违反题目约束。

常见错误

  • 返回新字符串，却没有修改传入的字符数组。
  • 循环条件写成无边界控制，导致字符被交换两次而恢复原状。
  • 只移动一个指针，造成越界或死循环。
  • JavaScript 使用 s = s.reverse() 重新绑定局部变量，却忽略面试官要求展示原地机制。
  • 把 O(1) 误解为不能使用任何临时变量；单个临时字符仍是常数空间。

面试追问

如果输入是不可变字符串呢？

无法真正原地修改，通常需要转成可变字符结构，或构造新字符串，并诚实说明空间复杂度变化。

为什么条件是 left < right？

相等时只剩中央字符，它的镜像仍是自身；继续交换没有意义。

Unicode 会有什么不同？

本题限定可打印 ASCII。真实产品中需区分代码单元、码点与用户感知字符簇，简单反转可能拆开组合字符。

能否并行化？

镜像交换彼此独立，理论上可并行；但本题规模与内存访问特征下，线程调度成本通常得不偿失。
