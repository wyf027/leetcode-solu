和等于 k 的最长子数组长度

Maximum Size Subarray Sum Equals k。先读题并尝试独立推导；交互实验和完整题解分别放在后文。

难度：中等 连续子数组 返回长度
Problem

题目描述

给定一个整数数组 nums 和一个整数 k，找出元素和恰好等于 k 的最长连续子数组，并返回它的长度。如果不存在这样的连续子数组，返回 0。

示例 1
输入：nums = [1, -1, 5, -2, 3], k = 3
输出：4

连续子数组 [1, -1, 5, -2] 的和为 3，长度为 4，并且不存在更长的可行子数组。

示例 2
输入：nums = [-2, -1, 2, 1], k = 1
输出：2

连续子数组 [-1, 2] 的和为 1，长度为 2。

函数参数

maxSubArrayLen(nums: integer[], k: integer) -> integer
  • nums：待检查的整数数组。
  • k：目标子数组和。
  • 返回值：满足条件的最长连续子数组长度。

约束

  • 1 <= nums.length <= 2 × 10^5
  • -10^4 <= nums[i] <= 10^4
  • -10^9 <= k <= 10^9

Core Insight

核心洞察：把区间和改写成两个前缀和之差

令 P[i] 表示从 nums[0] 到 nums[i] 的元素和。区间 nums[j + 1 ... i] 的和为 P[i] - P[j]。要让它等于 k，只需在扫描到 i 时确认历史中是否出现过 P[i] - k。

P[i] - P[j] = k ⟺ P[j] = P[i] - k

为让长度 i - j 尽可能大，同一个前缀和值只保留它的最早索引。初始化 0 → -1，即可统一处理从索引 0 开始的可行子数组。

完整过程

  1. 建立映射 first，令 first[0] = -1，并把当前前缀和与答案都设为 0。
  2. 从左到右扫描数组，把当前元素累加到 prefix。
  3. 查询 prefix - k 是否存在；若存在于索引 j，就用 i - j 更新最长长度。
  4. 若 prefix 尚未出现，记录当前索引；若已出现则保留更早的位置。
  5. 扫描结束后返回最长长度；没有匹配时自然保持为 0。

为什么必须保留最早索引

对固定右端点 i 和固定目标前缀和 P[i] - k，候选长度是 i - j。同一个和值可能出现在多个 j；选择最小的 j 才能得到最大长度。因此不能无条件覆盖哈希表中的旧索引。

平均时间 O(n) 一次线性扫描
额外空间 O(n) 最早索引映射

正确性证明

不变式：处理索引 i 前，哈希表保存所有已见前缀和值的最早索引，best 是右端点不超过 i - 1 的最长可行子数组长度。

保持：处理 i 时，若 prefix - k 在索引 j 出现，则 P[i] - P[j] = k，所以 (j, i] 是可行区间。映射保存最早的 j，该右端点下不会有更长候选。更新答案后，仅在当前前缀和首次出现时写入，故不变式继续成立。

终止：所有右端点都被处理，每个右端点的最长候选都参与更新，因此最终 best 等于全局最长可行子数组长度。

边界情况

  • 从索引 0 开始：first[0] = -1 让长度计算仍为 i - (-1)。
  • 没有答案：best 从 0 开始并保持不变。
  • k = 0 或大量 0：重复前缀和必须保留第一次出现的位置。
  • 负数：算法不依赖区间和单调性，因此仍然有效。
  • 数值范围：实现中使用 64 位前缀和，避免跨语言迁移时发生整数溢出。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maxSubArrayLen(int[] nums, int k) {
        Map<Long, Integer> firstIndex = new HashMap<>();
        firstIndex.put(0L, -1);

        long prefix = 0L;
        int best = 0;

        for (int i = 0; i < nums.length; i++) {
            prefix += nums[i];
            long need = prefix - k;

            Integer left = firstIndex.get(need);
            if (left != null) {
                best = Math.max(best, i - left);
            }

            firstIndex.putIfAbsent(prefix, i);
        }

        return best;
    }
}

var maxSubArrayLen = function (nums, k) {
    const firstIndex = new Map();
    firstIndex.set(0, -1);

    let prefix = 0;
    let best = 0;

    for (let i = 0; i < nums.length; i += 1) {
        prefix += nums[i];
        const need = prefix - k;

        if (firstIndex.has(need)) {
            best = Math.max(best, i - firstIndex.get(need));
        }

        if (!firstIndex.has(prefix)) {
            firstIndex.set(prefix, i);
        }
    }

    return best;
};
from typing import List


class Solution:
    def maxSubArrayLen(self, nums: List[int], k: int) -> int:
        first_index = {0: -1}
        prefix = 0
        best = 0

        for i, value in enumerate(nums):
            prefix += value
            need = prefix - k

            if need in first_index:
                best = max(best, i - first_index[need])

            if prefix not in first_index:
                first_index[prefix] = i

        return best
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int maxSubArrayLen(vector<int>& nums, int k) {
        unordered_map<long long, int> firstIndex;
        firstIndex[0] = -1;

        long long prefix = 0;
        int best = 0;

        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            prefix += nums[i];
            const long long need = prefix - k;

            auto it = firstIndex.find(need);
            if (it != firstIndex.end()) {
                best = max(best, i - it->second);
            }

            if (firstIndex.find(prefix) == firstIndex.end()) {
                firstIndex[prefix] = i;
            }
        }

        return best;
    }
};

  • 如果要返回最长区间的左右端点，需要保存和更新哪些变量？
  • 如果改成统计和为 k 的子数组个数，哈希表中应保存什么？
  • 如果数据以流式方式到达，当前方法能否在线更新答案？内存如何增长？
  • 为什么哈希表平均是 O(1)，最坏情况又可能是多少？

常见错误

  • 忘记初始化 0 → -1，漏掉从索引 0 开始的答案。
  • 每次都覆盖前缀和的索引，丢失能够产生最长区间的最早位置。
  • 先写入当前前缀和再查询，在 k = 0 时干扰长度语义。
  • 看到“连续子数组”就套滑动窗口，忽略数组中允许出现负数。
  • 在数值范围扩大后仍使用过窄整数类型计算前缀和。
一句话记忆： 扫描到右端点时，用“当前前缀和减去 k”寻找最早的左侧前缀位置。
