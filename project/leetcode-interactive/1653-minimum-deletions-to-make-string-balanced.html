Problem

题目说明

函数：minimumDeletions(s) → integer

给定只由字符 'a' 和 'b' 组成的字符串 s。你可以删除其中任意数量的字符，使剩余字符串变得平衡。

平衡的定义：不存在下标对 (i, j)，满足 i < j、s[i] = 'b' 且 s[j] = 'a'。换句话说，结果必须形如若干个 a 后接若干个 b，两部分都可以为空。

请返回使 s 平衡所需的最少删除次数。

参数与约束

  • s：字符串，1 ≤ s.length ≤ 105
  • 每个 s[i] 只能是 'a' 或 'b'
  • 返回值：最少删除次数（整数）

Examples

官方示例

Example 01
输入s = "aababbab"
输出2

可删除下标 2、6 得到 aaabbb，或删除下标 3、6 得到 aabbbb，两种方案均删除 2 个字符。

Example 02
输入s = "bbaaaaabb"
输出2

删除最前面的两个 b 后得到 aaaaabb，最少需要删除 2 个字符。

Solution

一次扫描的动态规划

维护两个量：已经见过的 b 数量，以及让当前前缀平衡的最少删除次数。

核心洞察

从左向右扫描。如果当前字符是 b，它可以合法地留在末尾，只需累计 bCount。

如果当前字符是 a，它会与左侧保留下来的 b 冲突。此时只有两类完整选择：

deletions = min(deletions + 1, bCount)
  • deletions + 1：删除当前 a；
  • bCount：删除此前所有 b。

完整过程

  1. 令 bCount = 0、deletions = 0。
  2. 遍历字符串；遇到 b 就令 bCount++。
  3. 遇到 a 时，在“删当前 a”与“删前面全部 b”之间取较小代价。
  4. 遍历结束后，deletions 即全串最优答案。

正确性说明

不变式：处理完任意前缀后，deletions 等于让该前缀平衡的最少删除次数，bCount 等于该前缀原本包含的 b 数量。

遇到 b 时，把它接到平衡前缀末尾不会制造 ba 逆序，不变式保持。遇到 a 时，任何平衡方案要么删掉这个 a，要么必须删掉左侧所有与它冲突的 b；两类方案覆盖全部可能，取较小值就是最优。由归纳法，最终结果正确。

复杂度与边界

  • 时间复杂度：O(n)，每个字符只处理一次。
  • 空间复杂度：O(1)，只维护两个计数器。
  • 全为 a、全为 b 或本就形如 a*b*：答案为 0。
  • 长度为 1：不存在逆序对，答案为 0。
  • 交替字符串：每个 a 都会触发一次两方案比较。

替代方案

枚举分割点：把答案字符串看成左侧全 a、右侧全 b。对每个分割点，代价是左侧 b 数量加右侧 a 数量。前后缀计数可在 O(n) 时间、O(n) 或优化后的 O(1) 额外空间内完成。

单调栈视角：遇到 ba 冲突就消去一对并累计一次删除，也能得到答案，但状态含义不如动态规划直接。

面试追问与常见错误

  • 追问：为什么只比较两种选择？因为当前 a 若保留，左侧任何保留的 b 都会违规。
  • 追问：能否在线处理字符流？可以，两个状态都可增量更新。
  • 错误：见到 ba 就固定删除某一侧；局部贪心未比较累计代价。
  • 错误：更新 deletions 后又修改 bCount；删除选择是成本模型，不需要真的改写字符串。
  • 错误：把“平衡”误解成 a、b 数量相等。
JavaLeetCode 可提交
class Solution {
    public int minimumDeletions(String s) {
        int bCount = 0;
        int deletions = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == 'b') {
                bCount++;
            } else {
                deletions = Math.min(deletions + 1, bCount);
            }
        }

        return deletions;
    }
}

/**
 * @param {string} s

var minimumDeletions = function(s) {
    let bCount = 0;
    let deletions = 0;

    for (const char of s) {
        if (char === 'b') {
            bCount++;
        } else {
            deletions = Math.min(deletions + 1, bCount);
        }
    }

    return deletions;
};

class Solution {
public:
    int minimumDeletions(string s) {
        int bCount = 0;
        int deletions = 0;

        for (char c : s) {
            if (c == 'b') {
                ++bCount;
            } else {
                deletions = min(deletions + 1, bCount);
            }
        }

        return deletions;
    }
};
