环形闯关游戏

任选一个关卡开启。只有当前积分不小于关卡要求时才能挑战；通过后积分变成 score | challenge[i]，并开启它的两个邻居。求通关全部关卡所需的最小初始积分。

N ≤ 5×10⁴，challenge[i] ≤ 10¹⁴；必须使用 64 位整数。

题意与示例

已通关关卡始终形成环上的一个连续区间，下一步只能从区间的左邻居或右邻居继续。积分只会通过按位或增加，不会下降。

示例 1

challenge = [5, 4, 6, 2, 7]

输出：4

从关卡 3 开始：4|2=6，随后可依次通过 2、1、0、4。

示例 2

challenge = [12, 7, 11, 3, 9]

输出：8

从关卡 3 开始，积分依次吸收 3、11、9、7、12 的二进制位。

题解：按位贪心 + 单调归并环

核心洞察：只需考虑 OR 的子掩码

令 all 为所有 challenge 的按位或。最优初始积分不需要 all 之外的位；最高有效位无法删除，否则无法达到含该位的最大关卡。由高到低尝试删除 all 中的其余位，候选可行就永久删除，可得到数值最小的子掩码。

如何 O(n) 判断候选可行

线性扫描环，把“当前积分足以吞下”的连续片段合并成一个值；遇到要求大于当前积分时留下边界块并重新以初始候选开始。每次只要新块足以吞掉栈尾，就继续 OR 并弹出。最后首尾相邻，再从双端持续归并；全部合成不超过两个边界块，或首尾归并后能清空，即存在合法起点和扩张顺序。

复杂度与边界

每次可行性检查中，每个块最多入队、出队一次，O(n)。最多检查 47 个二进制位，整体 O(n log V)，空间 O(n)。n=1 时答案就是该关卡要求；所有要求相同时同样返回该值；全程使用 64 位整数，JavaScript 使用 BigInt。

替代方案、追问与常见错误

区间 DP 是 O(n²)；线段树模拟可行性常数更大。普通数值二分不成立：按位或导致可行性不按数值单调。常见错误是忽略首尾归并、把 10¹⁴ 放进 32 位、JavaScript 直接使用 Number 位运算，或错误地尝试删除最高有效位。
