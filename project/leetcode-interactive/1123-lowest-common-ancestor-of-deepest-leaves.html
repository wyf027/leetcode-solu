01 / Problem

先确定“最深”，再寻找“最近”

给定一棵二叉树的根节点 root，请返回所有最深叶节点的最近公共祖先。答案是一个节点，因此示例输出采用以该节点为根的子树的层序数组形式表示。

叶节点

没有任何子节点的节点。

深度

根节点深度为 0；子节点深度等于父节点深度加 1。

最近公共祖先

包含目标集合全部节点、且自身深度尽可能大的祖先节点。

示例 1

输入：root = [3,5,1,6,2,0,8,null,null,7,4]
输出：[2,7,4]

最深叶节点为 7 与 4，深度均为 3；它们的最近公共祖先是节点 2，返回以 2 为根的子树。

示例 2

输入：root = [1]
输出：[1]

根节点本身是唯一且最深的叶节点，也是自己的最近公共祖先。

示例 3

输入：root = [0,1,3,null,2]
输出：[2]

最深叶节点只有 2；单个节点的最近公共祖先就是它自己。

约束

  • 树中节点数在 [1, 1000] 范围内。
  • 0 <= Node.val <= 1000
  • 树中每个节点的值都互不相同。

04 / Solution Vault

准备好核对思路了吗？

完整题解与四种语言代码被独立收起，避免在阅读题目时提前泄露关键结论。

Solution / Postorder DP

一次后序遍历，同时得到深度与答案

核心洞察

对每个节点定义递归结果 (height, lca)：height 是该节点子树中最深叶节点到当前节点的层数；lca 是这批最深叶节点在该子树内的最近公共祖先。

  • 左高大于右高：全局最深叶只在左侧，沿用左候选。
  • 右高大于左高：沿用右候选。
  • 左右同高：两侧都含最深叶，当前节点就是新候选。

完整过程

  1. 空节点返回高度 0 与空候选。
  2. 后序递归求出左右子树结果。
  3. 比较左右高度，选择候选节点。
  4. 当前高度取较大子树高度再加 1。
  5. 根节点递归结果里的候选即为答案。

正确性说明

1

归纳定义成立：空树没有叶节点，高度为 0；叶节点的左右结果高度相同，因此候选为它自己、高度为 1。

2

不同高度：若一侧更高，当前子树的全部最深叶必然只在较高侧；根据归纳假设，该侧返回的候选就是这些叶节点的最近公共祖先。

3

相同高度：两侧都存在同等深度的最深叶。任何能同时覆盖两侧的节点不可能低于当前节点，所以当前节点恰是它们的最近公共祖先。

4

结论：由结构归纳，递归结果对每棵子树都正确，故根节点返回的候选就是全树最深叶节点的最近公共祖先。

边界情况

  • 只有一个节点：左右同高，返回根节点。
  • 树退化成链：最深叶唯一，答案为该叶节点。
  • 左右最深高度相同：答案可能正是根节点。
  • 节点值只用于标识，不参与比较。

复杂度

时间 O(n)递归栈 O(h)

每个节点只访问一次。最坏退化树中 h = n，平衡树中 h = log n。

替代方案

也可以先用 BFS 找到所有最深叶节点，并记录每个节点的父节点，再将最深层节点集合反复整体上移，直到只剩一个节点。该方案同样是 O(n)，但需要额外的父指针映射和集合，空间常数更大。

常见错误

  • 把“最深节点”误认为“任意最深叶节点”，只返回其中一个。
  • 高度定义不统一，空节点用 0 和 -1 混用。
  • 左右同高时错误沿用某一侧，而不是返回当前节点。
  • 第二遍再查 LCA，错失一次遍历完成的机会。

面试追问

为什么回传高度就足够，不需要保存所有最深叶？

父节点只需知道哪一侧包含更深的叶，或两侧是否并列；候选节点已经压缩了子树内部所有最深叶的公共祖先信息。

递归深度可能溢出时怎么办？

可用显式栈模拟后序遍历，并用映射保存每个节点的 (height, lca) 结果。

它与“包含所有最深节点的最小子树”有什么关系？

两题本质相同：最小子树的根，正是所有最深叶节点的最近公共祖先。

Java

官方签名 · 可提交
/** Definition for a binary tree node.
 * public class TreeNode {
 *     int val; TreeNode left; TreeNode right;
 * }
 */
class Solution {
    private static class Result {
        int height;
        TreeNode lca;
        Result(int height, TreeNode lca) {
            this.height = height;
            this.lca = lca;
        }
    }

    public TreeNode lcaDeepestLeaves(TreeNode root) {
        return dfs(root).lca;
    }

    private Result dfs(TreeNode node) {
        if (node == null) return new Result(0, null);
        Result left = dfs(node.left);
        Result right = dfs(node.right);
        if (left.height > right.height) {
            return new Result(left.height + 1, left.lca);
        }
        if (right.height > left.height) {
            return new Result(right.height + 1, right.lca);
        }
        return new Result(left.height + 1, node);
    }
}

JavaScript

/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *   this.val = (val === undefined ? 0 : val);
 *   this.left = (left === undefined ? null : left);
 *   this.right = (right === undefined ? null : right);
 * }
 * @param {TreeNode} root
 * @return {TreeNode}
 */
var lcaDeepestLeaves = function(root) {
    const dfs = (node) => {
        if (node === null) return [0, null];

        const [leftHeight, leftLca] = dfs(node.left);
        const [rightHeight, rightLca] = dfs(node.right);

        if (leftHeight > rightHeight) {
            return [leftHeight + 1, leftLca];
        }
        if (rightHeight > leftHeight) {
            return [rightHeight + 1, rightLca];
        }
        return [leftHeight + 1, node];
    };

    return dfs(root)[1];
};

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *   int val; TreeNode *left; TreeNode *right;
 * };
 */
class Solution {
    using Result = pair<int, TreeNode*>;

    Result dfs(TreeNode* node) {
        if (node == nullptr) return {0, nullptr};

        auto [leftHeight, leftLca] = dfs(node->left);
        auto [rightHeight, rightLca] = dfs(node->right);

        if (leftHeight > rightHeight) {
            return {leftHeight + 1, leftLca};
        }
        if (rightHeight > leftHeight) {
            return {rightHeight + 1, rightLca};
        }
        return {leftHeight + 1, node};
    }

public:
    TreeNode* lcaDeepestLeaves(TreeNode* root) {
        return dfs(root).second;
    }
};
