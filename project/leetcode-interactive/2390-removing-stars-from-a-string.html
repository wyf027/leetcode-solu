2390. 从字符串中移除星号

Removing Stars From a String

一颗星号，带走左侧最近的一个字母。哪些字符能留到最后？

01 / 题目

给定字符串 s。每次选择一个 *，同时删除它和它左侧最近的、尚未被删除的非星号字符。持续操作，直到没有星号，返回剩余字符串。输入保证每次移除都可进行，且最终结果唯一。

官方示例 1

输入：s = "leet**cod*e"
输出："lecoe"

从左到右删除：先移除 t 和第一颗星，再移除 e 和第二颗星，最后移除 d 和第三颗星。

leet**cod*e → lee*cod*e
→ lecod*e → lecoe

官方示例 2

输入：s = "erase*****"
输出：""

五颗星号依次消去五个字母，最终为空字符串。

约束

  • 1 ≤ s.length ≤ 10⁵。
  • s 只包含小写英文字母和 *。
  • 输入保证能够完成上述操作。

参数：s: string　返回：string　函数：removeStars(s)

04 / 独立题解

准备好解释你的方法了吗？展开后阅读推导和四语言实现。

核心洞察：只需操作保留序列的末尾

从左往右扫描时，当前星号左侧最近的存活字母，就是已经保留序列的最后一个字符。普通字母追加到末尾；星号使末尾字符退出。这正是栈的后进先出机制，星号本身不入栈。

完整过程

  1. 建立空字符栈。
  2. 逐字符读取 s：字母入栈；遇到星号弹出栈顶字母。
  3. 遍历结束后，把栈从底到顶连接成字符串。
s = "leet**cod*e"
i  字符  操作        栈（底 → 顶）
0   l    入栈        l
1   e    入栈        le
2   e    入栈        lee
3   t    入栈        leet
4   *    弹出 t      lee
5   *    弹出 e      le
6   c    入栈        lec
7   o    入栈        leco
8   d    入栈        lecod
9   *    弹出 d      leco
10  e    入栈        lecoe

正确性

不变式：处理完前 i 个字符后，栈内从底到顶恰好是该前缀中所有星号按从左到右顺序执行移除后的剩余字符。

初始前缀为空，栈也为空，不变式成立。读到字母，它不会触发删除，追加后仍成立；读到星号时，栈顶是前缀中最右侧存活字母，也就是题目要求的最近非星号字符，弹出它恰好执行一次合法操作。输入有效性保证此时栈非空。归纳可得，不变式一直成立。

结束时整个字符串已经处理，所有星号已移除，栈即一个合法的最终结果。结合题目给出的结果唯一性，它就是所求答案。

边界与复杂度

  • 没有星号：保留原字符串；全部抵消：返回空字符串。
  • 连续星号：逐个弹出，不会把另一颗星当作待删除字母。
  • 对任意前缀，字母数不少于星号数；因此合法输入不会弹出空栈。以星号开头的字符串不属于合法输入。
  • 令 n = s.length。每个字符最多入栈一次、出栈一次，最终拼接为 O(n)，总时间 O(n)，辅助空间最坏 O(n)。

Java

class Solution {
    public String removeStars(String s) {
        StringBuilder stack = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '*') {
                stack.setLength(stack.length() - 1);
            } else {
                stack.append(c);
            }
        }
        return stack.toString();
    }
}

JavaScript

/**
 * @param {string} s
 * @return {string}
 */
var removeStars = function(s) {
    const stack = [];
    for (const c of s) {
        if (c === '*') stack.pop();
        else stack.push(c);
    }
    return stack.join('');
};

Python

class Solution:
    def removeStars(self, s: str) -> str:
        stack = []
        for c in s:
            if c == '*':
                stack.pop()
            else:
                stack.append(c)
        return ''.join(stack)

C++

#include <string>
using namespace std;

class Solution {
public:
    string removeStars(string s) {
        string stack;
        for (char c : s) {
            if (c == '*') stack.pop_back();
            else stack.push_back(c);
        }
        return stack;
    }
};

替代方案

逆序扫描：遇到星号增加待删除计数，遇到字母时优先抵消计数，否则记录该字母；最后反转记录。时间 O(n)，保存输出仍需 O(n) 空间。

可变字符缓冲区也能用读、写指针模拟栈：普通字符写入 write 并递增，星号令 write 递减，最后截断。复用现有可变缓冲区时只需 O(1) 额外空间；从不可变字符串转换缓冲区仍需 O(n)。反复在字符串中间删除可能导致 O(n²) 搬移。

面试追问

  • 为什么不需要保存星号？ 它出现时即可执行一次删除，没有未来用途。
  • 能够流式处理吗？ 可以持续维护栈，但将来的星号仍可能删除已保留字符，不能提前不可撤回地输出它们。
  • 输入不再保证合法怎么办？ 遇到星号先检查栈空并按接口约定报错；不能默默忽略。
  • 需要删除最近两个字母时呢？ 每颗星弹出两次，并重新规定与校验合法性。

常见错误

  • 删除原字符串中星号前一个位置，而不是前一个仍存活的字母。
  • 把星号入栈，使连续星号相互抵消。
  • 最终反向弹栈输出，导致字符顺序颠倒。
  • 在循环里反复拼接或切片不可变字符串，隐藏了最坏 O(n²) 开销。
