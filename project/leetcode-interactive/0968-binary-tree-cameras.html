监控二叉树

Binary Tree Cameras · 用最少摄像头覆盖整棵树

HARD树后序 DFS贪心 / 树形 DP

任务

给定二叉树根节点 root。安装在某个节点上的摄像头能够监控该节点、它的父节点以及它的直接子节点。返回监控树中全部节点所需的最少摄像头数量。

示例 1

输入：root = [0,0,null,0,0]
输出：1
解释：在第二层节点放置一台摄像头即可覆盖全部节点。

示例 2

输入：root = [0,0,null,0,null,0,null,null,0]
输出：2
解释：至少需要两台摄像头；存在一种放置方式能覆盖全部节点。

约束

  • 树中节点数在 [1, 1000] 范围内。
  • Node.val == 0。

Solution

后序遍历 + 三态贪心

核心洞察

让每个节点向父节点报告三种状态：0 待覆盖、1 有摄像头、2 已被覆盖。空节点视为已覆盖，这样不会迫使叶节点安装摄像头。只有当某个孩子待覆盖时，当前节点才必须放摄像头；这是能同时覆盖孩子、自己和父节点的最划算位置。

完整过程

  1. 后序处理左、右子树。
  2. 任一孩子为 0：当前节点放摄像头，计数加一，返回 1。
  3. 否则，任一孩子为 1：当前节点已被孩子摄像头覆盖，返回 2。
  4. 两个孩子都为 2：当前节点暂时未覆盖，返回 0，把决策交给父节点。
  5. 遍历结束若根返回 0，再给根补一台摄像头。
局部最优为何成立：发现孩子待覆盖时，把摄像头放在父节点至少不比放在孩子上差，并额外覆盖父节点的父节点方向。

正确性说明

状态不变式：DFS 返回时，当前节点以下的所有节点均已被妥善处理；返回值精确描述当前节点对父节点的覆盖关系。

必要性：孩子返回待覆盖时，其子树内部已没有摄像头能覆盖它，因此当前节点必须安装摄像头。

最优性：该摄像头既完成必要覆盖，又能最大化向上覆盖范围。其余两种分支不放摄像头不会遗漏已确定的节点，也不会提前做冗余选择。根节点最后单独补齐，因此所有节点被覆盖，且摄像头数最少。

边界与复杂度

  • 单节点树：根最终待覆盖，补一台。
  • 空孩子：返回已覆盖，不影响叶节点判断。
  • 链状树与完全树：同一三态规则，无需特判。

时间：O(n)，每个节点访问一次。

空间：O(h) 递归栈；最坏 O(n)，平衡树为 O(log n)。

替代方案与面试追问

树形 DP

可为每个节点维护“放摄像头 / 被父覆盖 / 被孩子覆盖”等成本并做状态转移。表达更通用，但状态与无穷大边界更繁琐；三态贪心是该题结构下的精简形式。

追问

  • 若摄像头成本因节点而异，贪心是否仍成立？通常需要树形 DP。
  • 若摄像头可覆盖距离 2，状态应如何扩展？需记录向下未覆盖距离与向上覆盖能力。
  • 如何避免递归栈溢出？用显式栈模拟后序遍历并保存节点状态。

常见错误

  • 把空节点设为待覆盖，导致叶节点被迫安装摄像头。
  • 使用前序遍历，未获知孩子状态就做决定。
  • 忘记根节点可能在 DFS 后仍待覆盖。
  • 混淆“节点有摄像头”和“节点已被覆盖”。

class Solution {
    private int cameras = 0;
    // 0: 待覆盖, 1: 有摄像头, 2: 已覆盖
    public int minCameraCover(TreeNode root) {
        if (dfs(root) == 0) cameras++;
        return cameras;
    }
    private int dfs(TreeNode node) {
        if (node == null) return 2;
        int left = dfs(node.left), right = dfs(node.right);
        if (left == 0 || right == 0) { cameras++; return 1; }
        if (left == 1 || right == 1) return 2;
        return 0;
    }
}
