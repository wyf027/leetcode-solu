3913. 按频率对元音排序

只改动元音位置：频率高的元音在前；频率相同则保持它们在原串中首次出现的相对次序。

MediumO(n + 5 log 5)稳定的首次出现顺序

题意

给定仅含小写英文字母的 s。只重排 a/e/i/o/u：按出现次数降序排列；若次数相同，按各自第一次出现的位置排序。随后按原来的元音槽位依次写回。

示例 1
s = "leetcode"
e×3、o×1 → "leetcedo"
示例 2
s = "baeiou"
全部频率为 1，保留首次出现顺序 → "baeiou"

约束：1 ≤ s.length ≤ 10⁵，s 仅含小写英文字母。

题解：先确定顺序，再消费计数

  1. 扫描原串。记录每种出现元音的数量，且只在初次遇到时把它加入候选列表。
  2. 按频率降序稳定排序候选列表；稳定性自然保留同频元音的首次出现顺序。
  3. 再次扫描原串。遇到元音就从当前候选元音取一个写入；该元音剩余计数归零后移动候选指针。
复杂度
扫描两次为 O(n)；元音种类最多 5 个，排序为常数规模。额外空间 O(n) 用于可变输出。
边界
无元音、单个元音、同频元音、以及所有字符都是元音时都由同一流程覆盖。

替代方案与常见错误

也可收集全部元音并按“频率降序、首次位置升序”排序后一次写回。不要用字母序处理同频情况，也不要在写回时按原元音种类消耗计数。

面试追问

若元音集合扩大到 Unicode 字符，计数映射与首次位置比较不变；若要求不分配输出字符数组，很多语言的字符串不可变，仍需构建结果容器。
