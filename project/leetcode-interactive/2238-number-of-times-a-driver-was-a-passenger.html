01 / 题目

从行程记录中汇总角色

输入是一张名为 Rides 的表。每条记录描述一次行程，包含行程编号、驾驶该行程的人以及乘坐该行程的人。请为表中每个曾经担任司机的人返回一行：其 driver_id，以及他在全部记录中作为乘客出现的次数 cnt。从未当过乘客的司机也要列出，次数为 0。结果顺序不限。

输入表 Rides
字段类型含义
ride_idint唯一行程编号
driver_idint当前行程的司机编号
passenger_idint当前行程的乘客编号

约束与输入边界

  • ride_id 是具有唯一值的列（主键）。
  • 每条记录满足 driver_id != passenger_id。
  • 同一个司机或乘客编号可以在不同行程中多次出现。
  • 输出列为 driver_id、cnt，无需排序。
  • 可获得的题面未给出行数及整数范围上限；这里不自行添加数值约束。

04 / 题解

一份司机名单，一份乘客频次

核心洞察：输出哪些人由 driver_id 决定；每个人的次数由 passenger_id 决定。这是两个不同的统计维度。先得到去重的司机名单，再对乘客分组计数，最后以司机名单为左表关联频次。

完整过程

  1. 对司机列使用 DISTINCT，使每位司机只占一行。
  2. 对全部乘客按 passenger_id 分组，用 COUNT(*) 数真实行程。
  3. 按 driver_id = passenger_id 进行 LEFT JOIN，保留所有司机。
  4. 匹配到频次就返回该值；未匹配产生的 NULL 用 COALESCE(..., 0) 转成 0。

回填结果

为什么正确

司机去重集合恰好包含所有应输出的人，每人仅一次。扫描前 k 条行程后，频次表中每个编号的值等于其在这 k 条中的乘客出现次数：初始为 0；每读一行只把该行乘客的频次加 1，故不变式始终成立。扫描完全部行程后即得到真实次数。左连接对每个司机最多匹配一个已分组的频次行；有匹配时返回真实次数，无匹配时说明该司机从未出现于乘客列，返回 0。因此既无遗漏，也无重复计数。

边界与常见错误

  • 直接用原表自连接：司机有 a 条驾驶记录、b 条乘车记录时，连接可能产生 a × b 行。先去重司机或先聚合双方。
  • INNER JOIN 丢失零次司机：11 这样的司机必须保留，使用 LEFT JOIN。
  • 外连接后 COUNT(*)：未匹配也有一条占位行，会被数成 1。当前解法在连接前对真实行计数，因此此处 COUNT(*) 安全。
  • COUNT(DISTINCT passenger_id)：会把多次乘车合并为一次；应统计行程条数。
  • 只按乘客分组输出：会把仅当过乘客的人也列出来，且漏掉零次司机。
  • 空表返回空结果；重复的司机、乘客以及相同司机乘客组合的不同 ride_id 都按各自行程处理。

复杂度

令 n 为行程数，d 为不同司机数，p 为不同乘客数。本地哈希实现期望时间 O(n + d)，辅助空间 O(d + p)，输出空间 O(d)。SQL 若采用哈希聚合与哈希连接，通常可达到相同量级；若采用排序聚合，时间可能为 O(n log n)。实际执行成本取决于数据库的执行计划、索引和数据分布，不能仅由 SQL 文本保证线性时间。

替代方案

去重司机名单后直接 LEFT JOIN 原始 Rides，再按司机分组并 COUNT(r.passenger_id)，同样能保留 0。还可以对每个司机使用相关子查询 SELECT COUNT(*) FROM Rides WHERE passenger_id = d.driver_id：逻辑直观，无索引时可能反复全表扫描；乘客列索引可能改善查找，具体看执行计划。

面试追问

  • 想统计不同乘坐日期？需要日期字段，按人统计 DISTINCT 日期，不能复用行程次数含义。
  • 大量新增行程如何增量处理？维护司机集合及乘客计数；修改、删除、重复投递则需要相应冲销和幂等策略。
  • 有哪些索引候选？考虑 passenger_id 及 driver_id 上的索引，但聚合全表未必受益，需以后用执行计划确认。
  • 如果加入时间筛选？先明确司机名单覆盖所有历史还是仅目标时间段，再将筛选应用到正确的数据范围。

SQL · MySQL 8+

本题正式提交解法；输入为数据库表 Rides。

WITH drivers AS (
    SELECT DISTINCT driver_id FROM Rides
), passenger_counts AS (
    SELECT passenger_id, COUNT(*) AS cnt
    FROM Rides
    GROUP BY passenger_id
)
SELECT d.driver_id, COALESCE(p.cnt, 0) AS cnt
FROM drivers AS d
LEFT JOIN passenger_counts AS p
    ON d.driver_id = p.passenger_id;

Java

import java.util.*;

// 本地语义参考；输入每行是 [ride_id, driver_id, passenger_id]。
public class Solution {
    public static List<long[]> driverPassenger(int[][] rides) {
        Set<Integer> drivers = new LinkedHashSet<>();
        Map<Integer, Long> counts = new HashMap<>();
        for (int[] ride : rides) {
            drivers.add(ride[1]);
            counts.merge(ride[2], 1L, Long::sum);
        }
        List<long[]> result = new ArrayList<>();
        for (int driver : drivers) {
            result.add(new long[]{driver, counts.getOrDefault(driver, 0L)});
        }
        return result; // 每行 [driver_id, cnt]，顺序任意
    }
}

JavaScript

// 本地语义参考；输入每行是 [ride_id, driver_id, passenger_id]。
function driverPassenger(rides) {
    const drivers = new Set();
    const counts = new Map();
    for (const [, driver, passenger] of rides) {
        drivers.add(driver);
        counts.set(passenger, (counts.get(passenger) ?? 0) + 1);
    }
    return [...drivers].map(driver => ({
        driver_id: driver,
        cnt: counts.get(driver) ?? 0
    }));
}

Python

普通 Python 容器版本，仅作本地语义参考；不是 Pandas 提交版本。

from collections import Counter

# 本地语义参考；输入每行是 [ride_id, driver_id, passenger_id]。
def driver_passenger(rides: list[list[int]]) -> list[dict[str, int]]:
    drivers = {driver for _, driver, _ in rides}
    counts = Counter(passenger for _, _, passenger in rides)
    return [{"driver_id": driver, "cnt": counts[driver]}
            for driver in drivers]

本地语义参考，不是本数据库题的官方提交签名。

#include <array>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

// 本地语义参考；输入每行是 [ride_id, driver_id, passenger_id]。
vector<array<long long, 2>> driverPassenger(
    const vector<array<int, 3>>& rides) {
    unordered_set<int> drivers;
    unordered_map<int, long long> counts;
    for (const auto& ride : rides) {
        drivers.insert(ride[1]);
        ++counts[ride[2]];
    }
    vector<array<long long, 2>> result;
    for (int driver : drivers) {
        auto it = counts.find(driver);
        result.push_back({driver, it == counts.end() ? 0LL : it->second});
    }
    return result; // 每行 [driver_id, cnt]，顺序任意
}
