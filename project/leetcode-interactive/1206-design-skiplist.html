1206. 设计跳表

把多层有序链表想成城市的“快速路”：高层负责跨越长距离，底层保留全部数据。先读懂接口，再用交互演示观察一次定位与插入。

困难非付费题设计题

题目要求

不借助内置的有序集合，设计一个跳表。跳表由多层有序链表组成：最底层保存所有元素，上层保存部分索引节点，从而让搜索、插入和删除在平均情况下都能达到 O(log n)。

实现 Skiplist 类。跳表允许重复值；删除时，如果存在多个相同值，只需删除其中任意一个。

Skiplist()
初始化一个空跳表。
boolean search(int target)
判断 target 是否存在。
void add(int num)
插入 num，允许重复。
boolean erase(int num)
删除一个 num；成功返回 true，否则返回 false。

  • 对 search、add 和 erase 的调用总数不超过 5 × 104。

完整题解

核心洞察：每一层都是有序链表。搜索时只要“能向右就向右，否则下降一层”；插入和删除则先保存每层中目标位置的前驱节点，再统一修改指针。

数据结构与随机层高

每个节点保存一个值和若干条向右指针。头节点使用固定最大层数。插入新值时不断抛硬币：每次成功就多升一层，直到失败或达到最大层数。某个节点至少达到第 k 层的概率约为 1 / 2k，因此高层节点会指数减少。

完整过程

  1. 定位：从最高层头节点开始。如果右侧节点值小于目标就向右，否则下降一层。每下降一层，都把当前位置记入 update[level]。
  2. 搜索：到达第 0 层后检查下一个节点是否等于目标。
  3. 插入：随机生成新节点层高；在这些层上，让新节点接住前驱原来的后继，再让前驱指向新节点。使用严格小于进行定位，因此重复值会被插在已有相同值之前。
  4. 删除：如果第 0 层找不到目标，返回 false；否则仅当某一层的前驱确实指向同一个目标节点时才绕过它，从而只删除一个副本。

正确性

定位不变式：处理第 i 层时，当前位置是该层中值小于目标的最右节点。向右不会越过目标，下降又保留同一前缀位置，所以到第 0 层时，其后继就是第一个大于等于目标的节点。

插入：每层都把新节点接在正确前驱与后继之间，因此各层仍有序；第 0 层一定插入，所以元素确实存在。

删除：各层只绕过同一目标节点，其余相对顺序不变；第 0 层移除该节点，所以恰好删除一个副本。

复杂度

令 n 为元素数，最大层数为常数上限。

  • 搜索：平均 O(log n)，最坏 O(n)
  • 插入：平均 O(log n)，最坏 O(n)
  • 删除：平均 O(log n)，最坏 O(n)
  • 空间：期望 O(n)

边界情况

  • 空跳表搜索或删除
  • 插入 0 与 20000
  • 连续插入多个相同值
  • 删除头部或尾部值
  • 删除不存在的值
  • 随机层高触及上限

常见错误

  • 定位时使用 ≤，破坏重复值处理
  • 删除时只改第 0 层
  • 每层误删不同的重复节点
  • 新节点指针数组长度少一层
  • 随机层高没有最大限制

替代方案与追问

平衡树能给出严格 O(log n)，但实现更长；有序数组搜索快，却会让插入删除变成 O(n)。

追问：如何让随机结果可复现？如何动态调整最大层数？并发跳表为何常用无锁 CAS？概率 p 改变会怎样影响空间与查询常数？

import java.util.Random;

class Skiplist {
    private static final int MAX_LEVEL = 16;
    private final Node head = new Node(-1, MAX_LEVEL);
    private final Random random = new Random();

    private static class Node {
        int value;
        Node[] next;
        Node(int value, int level) {
            this.value = value;
            this.next = new Node[level];
        }
    }

    public Skiplist() {}

    public boolean search(int target) {
        Node cur = head;
        for (int level = MAX_LEVEL - 1; level >= 0; level--) {
            while (cur.next[level] != null
                    && cur.next[level].value < target) {
                cur = cur.next[level];
            }
        }
        cur = cur.next[0];
        return cur != null && cur.value == target;
    }

    public void add(int num) {
        Node[] update = new Node[MAX_LEVEL];
        Node cur = head;
        for (int level = MAX_LEVEL - 1; level >= 0; level--) {
            while (cur.next[level] != null
                    && cur.next[level].value < num) {
                cur = cur.next[level];
            }
            update[level] = cur;
        }

        int height = randomHeight();
        Node node = new Node(num, height);
        for (int level = 0; level < height; level++) {
            node.next[level] = update[level].next[level];
            update[level].next[level] = node;
        }
    }

    public boolean erase(int num) {
        Node[] update = new Node[MAX_LEVEL];
        Node cur = head;
        for (int level = MAX_LEVEL - 1; level >= 0; level--) {
            while (cur.next[level] != null
                    && cur.next[level].value < num) {
                cur = cur.next[level];
            }
            update[level] = cur;
        }
        Node target = update[0].next[0];
        if (target == null || target.value != num) return false;
        for (int level = 0; level < target.next.length; level++) {
            if (update[level].next[level] == target) {
                update[level].next[level] = target.next[level];
            }
        }
        return true;
    }

    private int randomHeight() {
        int height = 1;
        while (height < MAX_LEVEL && random.nextBoolean()) height++;
        return height;
    }
}

      cur = cur.next[level];
    }

import random
from typing import List, Optional


MAX_LEVEL = 16


class Node:
    def __init__(self, value: int, height: int):
        self.value = value
        self.next: List[Optional["Node"]] = [None] * height


class Skiplist:
    def __init__(self):
        self.head = Node(-1, MAX_LEVEL)

    def search(self, target: int) -> bool:
        cur = self.head
        for level in range(MAX_LEVEL - 1, -1, -1):
            while (cur.next[level] is not None and
                   cur.next[level].value < target):
                cur = cur.next[level]
        cur = cur.next[0]
        return cur is not None and cur.value == target

    def add(self, num: int) -> None:
        update = [self.head] * MAX_LEVEL
        cur = self.head
        for level in range(MAX_LEVEL - 1, -1, -1):
            while (cur.next[level] is not None and
                   cur.next[level].value < num):
                cur = cur.next[level]
            update[level] = cur

        height = 1
        while height < MAX_LEVEL and random.getrandbits(1):
            height += 1
        node = Node(num, height)
        for level in range(height):
            node.next[level] = update[level].next[level]
            update[level].next[level] = node

    def erase(self, num: int) -> bool:
        update = [self.head] * MAX_LEVEL
        cur = self.head
        for level in range(MAX_LEVEL - 1, -1, -1):
            while (cur.next[level] is not None and
                   cur.next[level].value < num):
                cur = cur.next[level]
            update[level] = cur

        target = update[0].next[0]
        if target is None or target.value != num:
            return False
        for level in range(len(target.next)):
            if update[level].next[level] is target:
                update[level].next[level] = target.next[level]
        return True
C++
#include <array>
#include <cstdlib>
#include <vector>
using namespace std;

class Skiplist {
    static constexpr int MAX_LEVEL = 16;

    struct Node {
        int value;
        vector<Node*> next;
        Node(int value, int height) : value(value), next(height, nullptr) {}
    };

    Node* head;

    int randomHeight() {
        int height = 1;
        while (height < MAX_LEVEL && (rand() & 1)) ++height;
        return height;
    }

public:
    Skiplist() : head(new Node(-1, MAX_LEVEL)) {}

    bool search(int target) {
        Node* cur = head;
        for (int level = MAX_LEVEL - 1; level >= 0; --level) {
            while (cur->next[level] != nullptr &&
                   cur->next[level]->value < target) {
                cur = cur->next[level];
            }
        }
        cur = cur->next[0];
        return cur != nullptr && cur->value == target;
    }

    void add(int num) {
        array<Node*, MAX_LEVEL> update{};
        Node* cur = head;
        for (int level = MAX_LEVEL - 1; level >= 0; --level) {
            while (cur->next[level] != nullptr &&
                   cur->next[level]->value < num) {
                cur = cur->next[level];
            }
            update[level] = cur;
        }
        int height = randomHeight();
        Node* node = new Node(num, height);
        for (int level = 0; level < height; ++level) {
            node->next[level] = update[level]->next[level];
            update[level]->next[level] = node;
        }
    }

    bool erase(int num) {
        array<Node*, MAX_LEVEL> update{};
        Node* cur = head;
        for (int level = MAX_LEVEL - 1; level >= 0; --level) {
            while (cur->next[level] != nullptr &&
                   cur->next[level]->value < num) {
                cur = cur->next[level];
            }
            update[level] = cur;
        }
        Node* target = update[0]->next[0];
        if (target == nullptr || target->value != num) return false;
        for (int level = 0; level < (int)target->next.size(); ++level) {
            if (update[level]->next[level] == target) {
                update[level]->next[level] = target->next[level];
            }
        }
        delete target;
        return true;
    }

    ~Skiplist() {
        Node* cur = head;
        while (cur != nullptr) {
            Node* next = cur->next[0];
            delete cur;
            cur = next;
        }
    }
};
