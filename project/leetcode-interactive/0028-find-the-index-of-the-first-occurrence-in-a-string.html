找出字符串中第一个匹配项的下标

KMP 像一把会记忆的校准尺：匹配失败时，主串指针 i 不回头，只让模式串指针 j 沿 LPS 刻度回弹。

mismatch protocol

j = lps[j - 1]

i → 继续向前，不重复比较

Brief

题意转述

给定两个字符串 haystack 和 needle，返回 needle 在 haystack 中第一次完整出现的起始下标；如果不存在，返回 -1。

官方样例 1

输入haystack = "sadbutsad", needle = "sad"
输出index = 0

"sad" 出现在下标 0 和 6，返回第一次出现的位置 0。

官方样例 2

输入haystack = "leetcode", needle = "leeto"
输出index = -1

模式串没有完整出现，因此返回 -1。

约束：1 ≤ haystack.length, needle.length ≤ 10⁴；两个字符串仅含小写英文字母。示例中的双引号属于字符串格式；本题输入不含空格，因此无需使用 ␠ 占位符。

KMP invariant

为什么不会漏掉更早的匹配？

当已匹配 needle[0..j-1] 却失配时，LPS 告诉我们这段已匹配文本的后缀中，最长有多少字符也等于 needle 的前缀。直接把 j 回退到该长度，保留所有仍可能参与最早匹配的信息，而 i 无需后退。

Core insight

核心洞察：LPS 复用已经比较过的结果

普通匹配失配后会把起点右移一格并重新比较；KMP 预先计算模式串的 LPS 数组。失配且 j > 0 时执行 j = lps[j - 1]，不移动 i；只有 j = 0 仍失配时才令 i++。一旦 j 等于 needle.length，起点就是 i - j。

Process

完整解题过程

  1. 1. 对 needle 构建 LPS：记录每个前缀的最长相等真前后缀长度。
  2. 2. i、j 从 0 开始比较 haystack[i] 与 needle[j]。
  3. 3. 相等则 i++、j++；j 到达 m 时返回 i - m。
  4. 4. 失配且 j > 0 时让 j 回退到 lps[j - 1]。
  5. 5. 失配且 j = 0 时只移动 i；扫描结束返回 -1。

Edge cases

边界情况

  • • needle 比 haystack 长：不可能完整匹配，返回 -1。
  • • 两串相同：首次匹配位置为 0。
  • • 只有一个字符：直接比较即可。
  • • 大量重复字符：最能体现 LPS 避免重复比较的价值。
  • • 当前约束保证 needle 非空；通用实现仍可对空 needle 返回 0。

Alternative

替代方案取舍

暴力枚举每个起点最容易现场写出，时间为 O((n-m+1)m)、空间 O(1)，本题 10⁴ 规模通常也能通过。Rabin–Karp 平均高效但需要处理哈希碰撞。若面试官追问线性字符串匹配，KMP 是最稳妥的主线答案。

Interview follow-ups

面试高频追问

LPS 为什么是“真”前缀？
不能把整个字符串同时当作前缀和后缀，否则失配时 j 不会缩短，循环无法前进。
i 为什么不会回退？
已比较文本的可复用后缀信息被编码在 j 的回退值里，回退 i 只会重复工作。
如何返回第一次出现？
i 单调从左到右，第一次 j == m 时得到的 i - m 必然是最小起点。

Common mistakes

常见错误

  • • 失配后写成 j = lps[j]，可能越界或无法缩短。
  • • 构建 LPS 时失配就直接把 i 加一，漏掉可继续回退的前缀。
  • • 匹配成功返回 i，而正确起点是 i - needle.length。
  • • j 回退时同时移动 i，破坏 KMP 的线性保证。
  • • 直接调用 indexOf / find，无法展示算法能力。

class Solution {
    public int strStr(String haystack, String needle) {
        if (needle.isEmpty()) return 0;
        int[] lps = buildLps(needle);
        int i = 0, j = 0;

        while (i < haystack.length()) {
            if (haystack.charAt(i) == needle.charAt(j)) {
                i++;
                j++;
                if (j == needle.length()) return i - j;
            } else if (j > 0) {
                j = lps[j - 1];
            } else {
                i++;
            }
        }
        return -1;
    }

    private int[] buildLps(String pattern) {
        int[] lps = new int[pattern.length()];
        for (int i = 1, len = 0; i < pattern.length();) {
            if (pattern.charAt(i) == pattern.charAt(len)) {
                lps[i++] = ++len;
            } else if (len > 0) {
                len = lps[len - 1];
            } else {
                lps[i++] = 0;
            }
        }
        return lps;
    }
}
