LEETCODE 1073 · ARRAY / MATH

负二进制数相加

不把长数组转成十进制：像竖式一样从右向左算，只是进位要除以 −2。

MEDIUMAdding Two Negabinary Numbers

题目

给定两个以 −2 为基数的二进制数组 arr1 与 arr2。数组元素均为 0 或 1，并按最高位到最低位排列。请返回它们的和，仍用相同形式表示且不含前导零。

arr = [1,1,0,1] ⇒ (−2)³ + (−2)² + (−2)⁰ = −3

函数形式

addNegabinary(arr1: integer[], arr2: integer[]) → integer[]

官方示例

示例 1
输入：arr1 = [1,1,1,1,1], arr2 = [1,0,1]
输出：[1,0,0,0,0]
解释：两数组分别表示 11 与 5，结果表示 16。
示例 2
输入：arr1 = [0], arr2 = [0]
输出：[0]
示例 3
输入：arr1 = [0], arr2 = [1]
输出：[1]

约束

  • 1 ≤ arr1.length, arr2.length ≤ 1000
  • arr1[i]、arr2[i] 只能是 0 或 1
  • 输入没有前导零（零本身表示为 [0]）

观察：−2 的偶次幂为正，奇次幂为负；位权正负交替。

负基数竖式实验台

演示示例 1。从最低位向左，每列令 sum = a + b + carry；结果位取 0 或 1，再把剩余量交给下一列。

当前列传向更高位的进位
准备开始：从最右侧的 (−2)⁰ 位处理。

键盘提示：控件获得焦点后按 Enter 或 Space；也可用方向键切换步骤。

准备好看题解了吗？

先尝试解释：为什么普通二进制的正进位，在这里可能变成负数？

题解：逐位归一化

核心洞察

任意整数 sum 都能写成 bit + (−2) × nextCarry，其中 bit ∈ {0,1}。因此令：

bit = sum & 1
nextCarry = (sum − bit) / (−2)

sum − bit 必为偶数，所以下一进位始终是整数。按位结果先逆序收集，最后去掉高位多余的 0 并翻转。

完整过程

  1. 两个指针分别指向数组末尾，初始化 carry = 0。
  2. 只要任一数组还有位或进位非零，就把当前两位与进位相加。
  3. 用 sum & 1 取得合法结果位。
  4. 按 (sum − bit) / −2 更新进位。
  5. 删除逆序结果末尾的冗余 0，再反转。

正确性说明

循环不变式：处理完低位 0..k−1 后，已写出的这些位与尚未处理的输入、位于 k 的 carry 共同表示原始两数之和。

第 k 列把当前总量精确分解为 bit + (−2)·nextCarry；因此写入 bit 后，所有未结算量被等价搬到下一位，不变式保持。循环终止时输入和进位均为空，结果完整；去掉前导零不改变数值。

边界与复杂度

  • 全零：清理后保留单个 0。
  • 数组长度不同：缺失位按 0 处理。
  • 末尾仍有进位：循环继续，直到归零。
  • 不转十进制，避免长度 1000 时溢出。

时间：O(max(m,n))；额外空间：O(max(m,n))（返回数组）。

四语言完整实现

class Solution {
    public int[] addNegabinary(int[] arr1, int[] arr2) {
        java.util.List<Integer> rev = new java.util.ArrayList<>();
        int i = arr1.length - 1, j = arr2.length - 1, carry = 0;
        while (i >= 0 || j >= 0 || carry != 0) {
            int sum = carry;
            if (i >= 0) sum += arr1[i--];
            if (j >= 0) sum += arr2[j--];
            int bit = sum & 1;
            rev.add(bit);
            carry = (sum - bit) / -2;
        }
        while (rev.size() > 1 && rev.get(rev.size() - 1) == 0) rev.remove(rev.size() - 1);
        int[] ans = new int[rev.size()];
        for (int k = 0; k < ans.length; k++) ans[k] = rev.get(ans.length - 1 - k);
        return ans;
    }
}

var addNegabinary = function(arr1, arr2) {
    const rev = [];
    let i = arr1.length - 1, j = arr2.length - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry !== 0) {
        let sum = carry;
        if (i >= 0) sum += arr1[i--];
        if (j >= 0) sum += arr2[j--];
        const bit = sum & 1;
        rev.push(bit);
        carry = (sum - bit) / -2;
    }
    while (rev.length > 1 && rev[rev.length - 1] === 0) rev.pop();
    return rev.reverse();
};

替代方案

也可以按四种余数情况手写规则，或先计算大整数再转回 −2 进制。前者分支多、容易漏掉负进位；后者依赖大整数且偏离本题考察的逐位思想。统一公式更短、更易证明。

面试追问

  • 如何推广到任意负基数 −k？需要把余数规范到 [0,k−1]。
  • 为什么 sum & 1 对负奇数仍得到 1？可改写成规范取模以便跨语言。
  • 能否原地复用较长输入数组以降低额外空间？可以，但会改变参数且代码更复杂。

常见错误

  • 沿用正二进制的 carry = sum / 2。
  • 忽略负数除法在不同语言里的取整语义。
  • 循环条件漏掉 carry != 0。
  • 删除所有 0，导致零的结果变成空数组。
  • 先转普通整数，引发溢出。
