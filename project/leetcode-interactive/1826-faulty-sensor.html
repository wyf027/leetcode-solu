有缺陷的传感器

Faulty Sensor · 两条记录，一次丢失，能否锁定故障来源？

先观察规则与样本；算法推导与四语言代码收在底部，按需展开。

01 / 实验规则

两只传感器同时记录同一组数据，输入为等长整数数组 sensor1、sensor2。至多一只发生故障：恰好漏掉一个值，后续读数向左移一格，再在末尾补入一个随机值。补入值保证不等于被漏掉的值。

能唯一确定时返回故障传感器编号 1 或 2；没有故障，或无法辨别是哪只故障，返回 -1。

参数与约束

  • badSensor(sensor1, sensor2) → integer
  • sensor1.length == sensor2.length
  • 1 ≤ sensor1.length ≤ 100
  • 1 ≤ sensor1[i], sensor2[i] ≤ 100
  • 输入保证符合至多一只传感器故障的模型。

02 / 官方示例

sensor1 = [2,3,4,5]
sensor2 = [2,1,3,4]
输出：1

第二组是正常数据；漏掉 1，末尾补 5，得到第一组。

sensor1 = [2,2,2,2,2]
sensor2 = [2,2,2,2,5]
输出：-1

任一组都可解释为另一组漏掉末项并补值后的结果。

sensor1 = [2,3,2,2,3,2]
sensor2 = [2,3,2,3,2,7]
输出：2

第一组正常；漏掉下标 3 的 2，末尾补 7，得到第二组。

05 / 独立题解

核心洞察、证明、边界与完整代码

核心洞察：同时保留两个候选

找到首个差异下标 k。若 Sensor 1 坏了，其当前项已经来自正常序列的下一项，因此应比较 sensor1[j] 与 sensor2[j+1]。假设 Sensor 2 坏了则反向比较。只找到一个匹配方向还不够，另一个方向也可能成立。

完整过程

  1. 扫描公共前缀。若 k == n，记录完全相同，返回 -1。
  2. 候选 1 的丢失值是 sensor2[k]，要求 sensor1[n-1] != sensor2[k]，且每个 j ∈ [k,n-2] 都满足 sensor1[j] == sensor2[j+1]。
  3. 候选 2 的丢失值是 sensor1[k]，要求 sensor2[n-1] != sensor1[k]，且每个 j ∈ [k,n-2] 都满足 sensor2[j] == sensor1[j+1]。
  4. 两个候选不同，返回唯一成立者的编号；相同则返回 -1。有效输入中，存在差异但两个候选都失败的情况不会发生。

正确性

若真正的删除点 d 早于首个差异 k，那么正常序列从 d 到 k 必然是相同值，否则差异会提前出现。把删除点移到 k 不改变删除后的序列，也不改变被删值。因此只检查 k 不会遗漏合法解释。

对每个候选，循环维护“所有已经检查的偏移对应项都相等”。公共前缀一致、删除后后缀对应、补值不同于丢失值，恰好构成一次合法故障，既必要又充分。两个方向覆盖所有可能，只有一个成立时便可唯一识别。

完全一致的数组不可能由这种故障产生：若删除后记录不变，删除点起的正常后缀必须全相等，末尾也必须补入同一个值，违反补值规则。

边界与复杂度

  • n = 1：相同则正常，不同则双向均可能，都返回 -1。
  • 只在末项不同：没有可比较的偏移后缀，双向均可解释。
  • 重复读数可能遮蔽丢失位置或造成歧义，不能提前判定。
  • 时间 O(n)，额外空间 O(1)，不修改输入。可视化储存步骤不计入提交算法。

替代方案

枚举两种故障方向及每个删除位置，再用下标检查记录，时间 O(n²)、辅助空间 O(1)。首个差异法省去了重复枚举，无需排序、哈希或复制数组。

常见错误

  • 跳过的是正常序列中的丢失项，不是故障数组的当前项。
  • 只比较一对值，或一个方向成功就返回。
  • j 扫到 n-1 导致 j+1 越界。
  • 把故障数组末尾补值也参与偏移匹配，或忘记补值不等于丢失值。

面试追问

没有有效输入保证？ 双候选失败时需额外报告模型不匹配。

连续丢失 t 项？ 已知 t 则检查偏移 t 并重定义补尾规则；未知 t 需要搜索更多偏移。

流式输入？ 用一项缓存维护偏移比较，保存首个差异处的丢失值，到末尾完成补值判断。

Java

class Solution {
    public int badSensor(int[] sensor1, int[] sensor2) {
        int n = sensor1.length, k = 0;
        while (k < n && sensor1[k] == sensor2[k]) k++;
        if (k == n) return -1;
        boolean bad1 = sensor1[n - 1] != sensor2[k];
        boolean bad2 = sensor2[n - 1] != sensor1[k];
        for (int j = k; j < n - 1; j++) {
            bad1 = bad1 && sensor1[j] == sensor2[j + 1];
            bad2 = bad2 && sensor2[j] == sensor1[j + 1];
        }
        return bad1 == bad2 ? -1 : (bad1 ? 1 : 2);
    }
}

from typing import List

class Solution:
    def badSensor(self, sensor1: List[int], sensor2: List[int]) -> int:
        n, k = len(sensor1), 0
        while k < n and sensor1[k] == sensor2[k]:
            k += 1
        if k == n:
            return -1
        bad1 = sensor1[n - 1] != sensor2[k]
        bad2 = sensor2[n - 1] != sensor1[k]
        for j in range(k, n - 1):
            bad1 = bad1 and sensor1[j] == sensor2[j + 1]
            bad2 = bad2 and sensor2[j] == sensor1[j + 1]
        return -1 if bad1 == bad2 else (1 if bad1 else 2)
