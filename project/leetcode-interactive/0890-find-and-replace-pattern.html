Find and Replace Pattern

中等数组哈希表字符串

题目

给定字符串数组 words 和字符串 pattern，返回所有与模式匹配的单词，顺序任意。

所谓匹配，是指可以把模式中的每个字母一致地替换成另一个字母，从而得到该单词；这种替换必须是双射：同一模式字母始终映射到同一字母，不同模式字母也不能映射到同一字母。

函数形式

findAndReplacePattern(words: string[], pattern: string): string[]

官方示例 1

输入：words = ["abc","deq","mee","aqq","dkd","ccc"], pattern = "abb"
输出：["mee","aqq"]
解释："mee" 可由 a→m、b→e 得到；"ccc" 会让 a、b 都映射到 c，不是双射。

官方示例 2

输入：words = ["a","b","c"], pattern = "a"
输出：["a","b","c"]

约束

  • 1 <= pattern.length <= 20
  • 1 <= words.length <= 50
  • words[i].length == pattern.length
  • pattern 与 words[i] 仅含小写英文字母。

反向映射冲突

输入：words=["aa"], pattern="ab" 期望输出：[] 实际输出：待补验证 状态：待补验证

题解：同时维护两个方向

核心洞察

“替换是双射”包含两个独立条件：pattern → word 保证同一模式字符不变心；word → pattern 保证两个模式字符不会挤到同一目标字符。任一方向冲突，当前单词立即失败。

完整过程

  1. 依次检查每个候选单词。
  2. 为它新建两张映射表。
  3. 同步扫描模式与单词：已有映射必须与当前字符一致；没有映射则同时登记两个方向。
  4. 扫描完成且无冲突，将单词加入答案。

正确性说明

若算法接受一个单词，则每次重复出现的模式字符都由正向表映射到同一字符，同时反向表保证不同模式字符的目标互不相同，因此映射是双射，单词必然匹配。反之，若单词确实匹配，其双射在每个位置都满足两张表的检查，算法不会拒绝它。因此算法返回且仅返回全部匹配单词。

边界与复杂度

  • 长度为 1：任意单字符单词都匹配。
  • 模式全相同：单词也必须全相同。
  • 所有字符不同：单词字符也必须两两不同。
  • 设单词数为 n、模式长度为 m，时间 O(nm)；每个候选词的额外空间 O(m)（小写字母下也可视为常数）。

替代方案

可把字符串规范化为“字符首次出现位置序列”，例如 abb → [0,1,1]、mee → [0,1,1]，比较单词与模式的规范形。它同样是 O(nm)，表达简洁；双向映射更直接展示冲突原因。

面试追问

  • 字符集扩大到 Unicode 时如何处理？使用哈希映射并按 Unicode code point 遍历。
  • 能否只用一张映射？不能，除非额外检查目标值唯一性。
  • 大量单词共享模式时如何优化？预先计算模式规范形，再逐词生成并比较规范形。

常见错误

  • 只检查正向映射，错误接受 pattern="ab", word="aa"。
  • 把映射表放在单词循环外，导致不同候选词相互污染。
  • 仅比较字符出现次数；频次相同并不一定具有相同位置结构。

完整代码

class Solution {
    public List<String> findAndReplacePattern(String[] words, String pattern) {
        List<String> answer = new ArrayList<>();
        for (String word : words) {
            Map<Character, Character> forward = new HashMap<>();
            Map<Character, Character> backward = new HashMap<>();
            boolean matches = true;
            for (int i = 0; i < pattern.length(); i++) {
                char p = pattern.charAt(i), w = word.charAt(i);
                if ((forward.containsKey(p) && forward.get(p) != w) ||
                    (backward.containsKey(w) && backward.get(w) != p)) {
                    matches = false; break;
                }
                forward.put(p, w); backward.put(w, p);
            }
            if (matches) answer.add(word);
        }
        return answer;
    }
}

var findAndReplacePattern = function(words, pattern) {
    return words.filter((word) => {
        const forward = new Map(), backward = new Map();
        for (let i = 0; i < pattern.length; i++) {
            const p = pattern[i], w = word[i];
            if ((forward.has(p) && forward.get(p) !== w) ||
                (backward.has(w) && backward.get(w) !== p)) return false;
            forward.set(p, w); backward.set(w, p);
        }
        return true;
    });
};
class Solution:
    def findAndReplacePattern(self, words: List[str], pattern: str) -> List[str]:
        def matches(word: str) -> bool:
            forward, backward = {}, {}
            for p, w in zip(pattern, word):
                if (p in forward and forward[p] != w) or \
                   (w in backward and backward[w] != p):
                    return False
                forward[p] = w
                backward[w] = p
            return True

        return [word for word in words if matches(word)]
