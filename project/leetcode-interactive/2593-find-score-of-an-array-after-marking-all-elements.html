2593Find Score of an Array After Marking All Elements非付费题

Problem

题目描述

给定一个由正整数组成的数组 nums，初始分数为 0。不断执行以下操作，直到所有元素都已标记：

  1. 选择数值最小的未标记元素；若数值相同，选择下标较小者。
  2. 把该元素的值加入分数。
  3. 标记该元素，以及存在的左、右相邻元素。

返回最终分数。

示例 1

输入：nums = [2,1,3,4,5,2]
输出：7
解释：依次选择 1、2、4，分数为 1 + 2 + 4 = 7。

示例 2

输入：nums = [2,3,5,1,3,2]
输出：5
解释：依次选择 1、下标 0 的 2、下标 5 的 2，
分数为 1 + 2 + 2 = 5。

Solution

准备好再看题解

先用上面的交互演示建立直觉，再展开完整算法、证明与四种语言实现。

Insight

核心洞察

规则总是按“数值优先、下标次之”选择未标记元素。先把每个元素表示成 (值, 下标) 并按这个顺序排序，就得到所有可能被选择的固定优先级。

依次扫描排序后的元素：已标记就跳过；否则把它加入答案，再标记它及左右邻居。无需每轮重新寻找最小值。

Complexity

复杂度

  • 排序 n 个元素：时间 O(n log n)。
  • 每个排序项只扫描一次：时间 O(n)。
  • 排序结果与标记数组：空间 O(n)。

Walkthrough

完整过程

  1. 生成所有 [nums[i], i]，按值升序、下标升序排列。
  2. 建立长度为 n 的标记数组，初始均为未标记；答案为 0。
  3. 按排序顺序访问每一对：若该下标已标记，直接跳过。
  4. 若未标记，将对应值累加到答案，并标记 i - 1、i、i + 1 中合法的下标。
  5. 扫描结束后，所有位置均已标记，返回答案。

示例 1：排序优先级从 (1,1) 开始，先选择下标 1，标记 0～2；随后排序中未标记的最小项是 (2,5)，标记 4～5；最后选择 (4,3)。总分 1 + 2 + 4 = 7。

Proof

正确性证明

引理：排序列表中第一个尚未标记的元素，正是当前规则要求选择的元素。因为列表先按值、再按下标升序排列，排在它之前的元素要么优先级更高但已标记，要么不存在。

保持：算法选择该元素后，累加其值，并准确标记它和合法相邻元素，与题目的一轮操作完全一致。

终止：每次选择至少标记当前元素。有限次后全部标记；由引理和保持性，每轮都与题目规则一致，因此累计分数正确。

Edges

边界情况

  • 只有一个元素：直接选择它。
  • 选择首尾元素：只标记存在的一侧邻居。
  • 大量相同值：必须让下标参与排序，保证最左优先。
  • 分数可能达到 1011：Java/C++ 使用 64 位整数。

Alternatives

替代方案

最小堆：把 (值, 下标) 全部入堆，每次弹出最小项并跳过已标记项，同样是 O(n log n)。它更贴近逐轮取最小值，但代码与常数更大。

反复线性查找：每轮扫描数组找最小未标记元素，最坏 O(n²)，无法应对 105。

Pitfalls

常见错误

  • 只按数值排序，未处理相同数值的下标优先级。
  • 遇到已标记元素仍然累加，或错误地再次扩散标记。
  • 标记邻居时数组越界。
  • 用 32 位整数保存总分导致溢出。

Interview

面试追问

  • 为什么一次排序足够？ 标记只会删除候选，不会改变剩余元素的相对优先级。
  • 如果要支持在线追加元素？ 可改用按值和下标排序的最小堆，并明确新元素的邻接关系。
  • 如果标记半径变成 k？ 直接逐点标记可能退化；可用并查集“跳到下一个未标记位置”优化区间标记。
  • 能否原地修改 nums 表示已标记？ 题目值域为正时可以使用特殊哨兵，但额外布尔数组更清晰，也不破坏输入。

Java
import java.util.Arrays;

class Solution {
    public long findScore(int[] nums) {
        int n = nums.length;
        int[][] order = new int[n][2];
        for (int i = 0; i < n; i++) {
            order[i][0] = nums[i];
            order[i][1] = i;
        }
        Arrays.sort(order, (a, b) ->
            a[0] != b[0] ? Integer.compare(a[0], b[0])
                          : Integer.compare(a[1], b[1]));

        boolean[] marked = new boolean[n];
        long score = 0;
        for (int[] item : order) {
            int i = item[1];
            if (marked[i]) continue;
            score += item[0];
            marked[i] = true;
            if (i > 0) marked[i - 1] = true;
            if (i + 1 < n) marked[i + 1] = true;
        }
        return score;
    }
}

var findScore = function(nums) {
    const order = nums.map((value, index) => [value, index]);
    order.sort((a, b) => a[0] - b[0] || a[1] - b[1]);

    const marked = Array(nums.length).fill(false);
    let score = 0;
    for (const [value, index] of order) {
        if (marked[index]) continue;
        score += value;
        marked[index] = true;
        if (index > 0) marked[index - 1] = true;
        if (index + 1 < nums.length) marked[index + 1] = true;
    }
    return score;
};
Python
from typing import List


class Solution:
    def findScore(self, nums: List[int]) -> int:
        order = sorted((value, index) for index, value in enumerate(nums))
        marked = [False] * len(nums)
        score = 0

        for value, index in order:
            if marked[index]:
                continue
            score += value
            for neighbor in (index - 1, index, index + 1):
                if 0 <= neighbor < len(nums):
                    marked[neighbor] = True

        return score
C++
#include <algorithm>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    long long findScore(vector<int>& nums) {
        vector<pair<int, int>> order;
        order.reserve(nums.size());
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            order.emplace_back(nums[i], i);
        }
        sort(order.begin(), order.end());

        vector<bool> marked(nums.size(), false);
        long long score = 0;
        for (auto [value, index] : order) {
            if (marked[index]) continue;
            score += value;
            marked[index] = true;
            if (index > 0) marked[index - 1] = true;
            if (index + 1 < static_cast<int>(nums.size())) {
                marked[index + 1] = true;
            }
        }
        return score;
    }
};
