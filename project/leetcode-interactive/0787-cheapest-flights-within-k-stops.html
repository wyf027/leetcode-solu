Cheapest Flights Within K Stops

在一张带价格的有向航班网中，寻找从出发城市到目的城市的最低费用，同时严格遵守中转站数量上限。先读题、观察限制，再决定怎样搜索这张图。

01 · Mission

任务简报

城市编号为 0 到 n - 1。每趟航班都有明确方向与价格；“最多 k 站中转”意味着整条路线最多搭乘 k + 1 段航班。

题意转述

给定 n 个城市，以及航班数组 flights。每个三元组 [fromᵢ, toᵢ, priceᵢ] 表示存在一趟从 fromᵢ 飞往 toᵢ、票价为 priceᵢ 的航班。

再给定出发城市 src、目的城市 dst 和允许的最大中转站数 k。请返回满足中转限制的最低总价；若不存在这样的路线，返回 -1。

findCheapestPrice(n, flights, src, dst, k) → integer

约束

  • 2 ≤ n ≤ 100
  • 0 ≤ flights.length ≤ n × (n - 1) / 2
  • flights[i].length == 3
  • 0 ≤ fromᵢ, toᵢ < n，且 fromᵢ != toᵢ
  • 1 ≤ priceᵢ ≤ 10⁴
  • 任意两个城市之间不存在重复航班，也不存在自环
  • 0 ≤ src, dst, k < n，且 src != dst

04 · Solution locker

准备好核对思路了吗？

题解与四种语言代码默认锁定。建议先回答：限制中转次数后，普通“最短价格”为什么不再是唯一需要记录的状态？

Unlocked

有边数限制的最短路

把“最多 k 个中转站”翻译成“最多使用 k + 1 条边”，再按航段数一层层扩展可达价格。

核心洞察

第 t 轮只允许最多使用 t 段航班。令 dist[v] 表示在当前航段预算内，从 src 到城市 v 的最低费用。每轮扫描全部航班，但更新必须读取上一轮的快照，不能读取本轮刚写入的新值。

完整过程

  1. 初始化。令 dist[src] = 0，其他城市费用为无穷大。此时允许 0 段航班。
  2. 扩展一段航班。一共执行 k + 1 轮。每轮先复制上一轮数组为 next。
  3. 松弛所有航班。对航班 u → v、票价 w，若上一轮可达 u，则尝试用 dist[u] + w 改善 next[v]。
  4. 提交本轮。扫描结束后令 dist = next。快照隔离保证一轮最多新增一段航班。
  5. 读取答案。最后若 dist[dst] 仍为无穷大，返回 -1；否则返回该费用。

边界检查

  • k = 0 时只运行 1 轮，仅允许直飞。
  • flights 为空时，目的地不可达。
  • 有环也没关系：轮数限制了最多使用的边数。
  • 同一轮保留上一轮已有答案，因此表达的是“至多”而非“恰好”。
TimeO((k+1)·E)
SpaceO(n)

正确性证明

循环不变式：完成第 t 轮后，dist[v] 等于从 src 到 v、最多使用 t 段航班的最低费用。

基础情形：t = 0 时，只有 src 可用 0 费用到达，其他城市不可达，初始化与不变式一致。

归纳步骤：假设第 t - 1 轮后不变式成立。任何最多使用 t 段航班到达 v 的最优路线，要么已经使用不超过 t - 1 段，要么最后一段是某条 u → v。前者由复制到 next[v] 保留；后者的前缀至多使用 t - 1 段，其最优费用由上一轮 dist[u] 给出，扫描该航班时会考虑 dist[u] + w。取所有可能中的最小值后，next[v] 正好是航段预算为 t 的最优费用。

终止：共执行 k + 1 轮，因此得到最多使用 k + 1 段航班、即最多经过 k 个中转站的最低费用。若仍不可达，返回 -1，故算法正确。

Implementations

四种语言完整代码

语言标签支持左右方向键切换。四份实现使用相同的上一轮快照机制。

import java.util.Arrays;

class Solution {
    public int findCheapestPrice(int n, int[][] flights,
                                 int src, int dst, int k) {
        final int INF = 1 << 29;
        int[] dist = new int[n];
        Arrays.fill(dist, INF);
        dist[src] = 0;

        for (int edges = 1; edges <= k + 1; edges++) {
            int[] next = dist.clone();
            for (int[] flight : flights) {
                int from = flight[0];
                int to = flight[1];
                int price = flight[2];
                if (dist[from] != INF) {
                    next[to] = Math.min(next[to], dist[from] + price);
                }
            }
            dist = next;
        }

        return dist[dst] == INF ? -1 : dist[dst];
    }
}

var findCheapestPrice = function(n, flights, src, dst, k) {
    const INF = Number.POSITIVE_INFINITY;
    let dist = new Array(n).fill(INF);
    dist[src] = 0;

    for (let edges = 1; edges <= k + 1; edges++) {
        const next = dist.slice();
        for (const [from, to, price] of flights) {
            if (dist[from] !== INF) {
                next[to] = Math.min(next[to], dist[from] + price);
            }
        }
        dist = next;
    }

    return dist[dst] === INF ? -1 : dist[dst];
};
from typing import List


class Solution:
    def findCheapestPrice(
        self,
        n: int,
        flights: List[List[int]],
        src: int,
        dst: int,
        k: int,
    ) -> int:
        inf = float("inf")
        dist = [inf] * n
        dist[src] = 0

        for _ in range(k + 1):
            next_dist = dist.copy()
            for from_city, to_city, price in flights:
                if dist[from_city] != inf:
                    next_dist[to_city] = min(
                        next_dist[to_city],
                        dist[from_city] + price,
                    )
            dist = next_dist

        return -1 if dist[dst] == inf else dist[dst]

class Solution {
public:
    int findCheapestPrice(int n, vector<vector<int>>& flights,
                          int src, int dst, int k) {

        vector<int> dist(n, INF);
        dist[src] = 0;

        for (int edges = 1; edges <= k + 1; ++edges) {
            vector<int> next = dist;
            for (const vector<int>& flight : flights) {
                int from = flight[0];
                int to = flight[1];
                int price = flight[2];
                if (dist[from] != INF) {
                    next[to] = min(next[to], dist[from] + price);
                }
            }
            dist.swap(next);
        }

        return dist[dst] == INF ? -1 : dist[dst];
    }

Debrief

替代方案与面试追问

这道题的重点不是死记一个模板，而是识别“费用 + 航段数”构成的受限最短路状态。

替代方案

  • 二维动态规划：dp[t][v] 显式记录最多使用 t 条边到达 v 的最低费用，逻辑最直观，但空间为 O(kn)。
  • 带状态的 Dijkstra：优先队列状态为“累计费用、城市、已用航段数”，可在稀疏图上提前结束；需要认真维护不同航段数下的最优状态。
  • 分层 BFS 松弛：按航段数逐层扩展，本质上仍需保留同层快照或正确的状态去重，避免跨层污染。

面试追问

  • 为什么普通 Dijkstra 只为每个城市记录一个最低费用可能出错？
  • 若要返回具体路线，应该额外保存什么状态？
  • 若存在负票价但没有负环，这个方案是否仍然成立？
  • 如何将空间从 O(kn) 优化到 O(n)？

常见错误

  • 把 k 个中转站误当成最多 k 段航班，少执行一轮。
  • 直接原地更新 dist，让同一轮连续使用多条航班，突破航段限制。
  • 只记录恰好使用本轮航段的答案，没有继承更少航段的最优值。
  • 没有判断起点是否可达就做加法，导致无穷大哨兵溢出。

追问参考

普通 Dijkstra 的单一 dist[city] 会丢失“更贵但用更少航段”的状态，而这种状态可能凭借剩余航段预算最终得到更便宜的完整路线。若要还原路线，可按轮次保存前驱，或使用二维状态 parent[edges][city]。
