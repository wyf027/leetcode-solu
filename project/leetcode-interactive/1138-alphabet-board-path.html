01 / Problem

把目标字符串走出来

这里先只建立规则，不展示解法。你可以随后用实验室观察任意合法目标的逐步移动。

题意

字母板为 ["abcde", "fghij", "klmno", "pqrst", "uvwxy", "z"]。初始位置是 (0, 0)，也就是字母 a。每次只能移动到板上真实存在的相邻方格。

请返回一串指令，使得依次执行后收集到的字符恰好等于参数 target，且移动次数最少。若有多条最短路径，可以返回任意一条。

五种指令

U上移
D下移
L左移
R右移
!收集

函数形式

alphabetBoardPath(target: string) → string

官方示例

示例 1
输入：target = "leet"
输出："DDR!UURRR!!DDD!"
示例 2
输入：target = "code"
输出："RR!DDRR!UUL!R!"

约束

1 <= target.length <= 100
target 只由小写英文字母组成。
只有标有字母的坐标真实存在。

核心洞察：曼哈顿最短路 + 安全移动顺序

每个字母的位置可以直接由字母序号计算：令 k = ch - 'a'，则 row = k / 5、col = k % 5（整数除法）。从当前格到目标格，横纵坐标分别相差多少，就至少需要多少次移动。

每段最少移动数 = |当前行 − 目标行| + |当前列 − 目标列|，到达后再追加一次 !。

普通 5×5 区域里，横向与纵向先走谁都可以；但 z 位于缺角棋盘的 (5,0)。统一采用 U → L → D → R 的顺序：离开最后一行时先向上，进入最后一行前先向左归零，就不会踏入不存在的格子。

完整过程

  1. 记录当前位置 (r, c)，初始为 (0, 0)。
  2. 遍历 target 的每个字符，计算目标坐标 (tr, tc)。
  3. 当 r > tr 时输出 U；当 c > tc 时输出 L。
  4. 再用 D 增大行号，用 R 增大列号，直到到达目标。
  5. 输出 ! 收集字符，把目标坐标作为下一段的起点。

正确性证明

1
路径合法。

若当前在 z，先执行所有 U，离开第 5 行后才可能向右；若目标是 z，先执行所有 L，保证列号归零后才向下进入第 5 行。因此不会进入最后一行的缺失位置。其余移动都发生在完整的前五行内。

2
字符顺序正确。

对每个目标字符，算法先移动到它的唯一坐标，再输出一次 !。所以收集的字符逐个等于 target，顺序也一致。

3
移动次数最少。

任意路径都必须消除行差和列差，至少需要对应的曼哈顿距离。算法恰好执行这些必要移动，没有绕路；每个字符所需的 ! 也不可省略。因此各段乃至整条路径都是最短的。

边界情况

  • 目标字符就是当前位置：不移动，直接输出 !。
  • 前往 z：必须先向左到第 0 列，再向下进入第 5 行。
  • 从 z 离开：必须先向上回到完整行，再进行向右移动。
  • 重复字符：每次都要独立输出 !。
  • 最大长度 100：结果长度仍然是线性规模。

复杂度

时间：O(n)额外空间：O(1)返回串：O(n)

棋盘尺寸固定，每两个字母间最多移动 9 步，因此每个字符只产生常数次操作。若把返回字符串占用也计入空间，则输出空间为 O(n)。

替代方案

显式特判 z

可以在去往 z 时强制横向优先，从 z 离开时强制纵向优先。逻辑直观，但分支更多；统一顺序更精炼。

BFS 最短路

把 26 个字母视为图节点，对每对字符执行 BFS 或预计算路径。它同样正确，也方便扩展到任意障碍棋盘，但本题坐标规律固定，BFS 会增加不必要的队列和访问状态。

坐标哈希表

预先保存字母到坐标的映射，可读性不错；不过字母序号已经能在常数时间直接推导坐标。

面试追问

  • 如果棋盘形状任意、存在多个空洞，统一顺序还成立吗？不一定，应改用 BFS。
  • 为什么返回任意最短路径使贪心可行？因为每个字符的落点唯一，各段端点固定，段间没有选择依赖。
  • 怎样在线处理流式输入？保留当前位置，每收到一个字符就生成该段路径并更新坐标。
  • 如何验证返回值？模拟每条指令，检查落点合法，并比较收集串与目标串及移动下界。

常见错误

最危险：固定先 D/R，再 U/L。 从右侧字母前往 z 时，可能先落到不存在的 (5,1..4)；从 z 出发时，也不能先向右。
  • 忘记当前位置相同仍需追加 !。
  • 把 ! 算成移动方向，或在到达之前输出。
  • 每处理一个字符后忘记更新当前坐标。
  • 为了规避 z 绕远路，得到合法但非最短的答案。

四语言完整代码

四份实现都采用相同的 U → L → D → R 安全顺序，并使用官方函数签名。

class Solution {
    public String alphabetBoardPath(String target) {
        StringBuilder path = new StringBuilder();
        int row = 0, col = 0;

        for (char ch : target.toCharArray()) {
            int index = ch - 'a';
            int targetRow = index / 5;
            int targetCol = index % 5;

            while (row > targetRow) { path.append('U'); row--; }
            while (col > targetCol) { path.append('L'); col--; }
            while (row < targetRow) { path.append('D'); row++; }
            while (col < targetCol) { path.append('R'); col++; }
            path.append('!');
        }
        return path.toString();
    }
}

var alphabetBoardPath = function(target) {
    const path = [];
    let row = 0;
    let col = 0;

    for (const ch of target) {
        const index = ch.charCodeAt(0) - 97;
        const targetRow = Math.floor(index / 5);
        const targetCol = index % 5;

        while (row > targetRow) { path.push('U'); row--; }
        while (col > targetCol) { path.push('L'); col--; }
        while (row < targetRow) { path.push('D'); row++; }
        while (col < targetCol) { path.push('R'); col++; }
        path.push('!');
    }
    return path.join('');
};
