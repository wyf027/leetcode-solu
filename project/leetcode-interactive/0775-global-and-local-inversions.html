全局倒置与局部倒置

Global and Local Inversions

数组 数学 非付费题

题目

给定长度为 n 的整数数组 nums。它恰好是 [0, n - 1] 中所有整数的一个排列。

全局倒置是满足 0 ≤ i < j < n 且 nums[i] > nums[j] 的不同下标对 (i, j)。局部倒置是满足 0 ≤ i < n - 1 且 nums[i] > nums[i + 1] 的下标 i。

如果全局倒置的数量与局部倒置的数量相等，返回 true；否则返回 false。

官方示例

示例 1

输入：nums = [1,0,2]
输出：true
解释：有 1 个全局倒置和 1 个局部倒置。

示例 2

输入：nums = [1,2,0]
输出：false
解释：有 2 个全局倒置和 1 个局部倒置。

约束

  • n == nums.length
  • 1 ≤ n ≤ 105
  • 0 ≤ nums[i] < n
  • nums 中的整数互不相同。
  • nums 是区间 [0, n - 1] 内所有整数的排列。

Solution

题解：把全局问题化为位置约束

O(n) 时间 · O(1) 空间

核心洞察

每个局部倒置本来就是一个全局倒置，所以“二者数量相等”等价于：不存在跨度至少为 2 的非局部倒置。

排列最初可视为恒等排列 [0,1,2,…]。如果每个数字离自己的原始位置最多一步，即对所有下标都满足 |nums[i] - i| ≤ 1，排列只可能由互不重叠的相邻交换组成；所有倒置自然都是局部倒置。反过来，某个数字离原位超过一步时，排列中必然出现至少一个非局部倒置。

完整过程

从左到右扫描每个下标 i。
计算当前位置数值与其原始位置的距离 |nums[i] - i|。
一旦距离大于 1，立即返回 false。
扫描结束仍未发现越界位移，返回 true。

正确性证明

充分性：假设所有 i 都满足 |nums[i] - i| ≤ 1。若存在跨度至少为 2 的倒置 (i, j)，即 j ≥ i + 2，则有 nums[i] ≤ i + 1 ≤ j - 1 ≤ nums[j]，与 nums[i] > nums[j] 矛盾。因此不存在非局部倒置；全局倒置全部是局部倒置，数量相等。

必要性：假设存在 |nums[i] - i| > 1。若 nums[i] ≥ i + 2，在比它小的值中，至少有一个会落在 i + 2 或更右侧，从而与 nums[i] 构成非局部倒置。若 nums[i] ≤ i - 2，对称地，至少有一个更大的值位于 i - 2 或更左侧，也会构成非局部倒置。因此二者数量不相等。

综上，算法返回 true 当且仅当全局倒置数等于局部倒置数。

边界情况

  • n = 1：没有任何倒置，返回 true。
  • 恒等排列：所有位移为 0，返回 true。
  • 只有若干互不重叠的相邻交换：位移都不超过 1，返回 true。
  • 任意元素跨越两个或更多位置：立即返回 false。

复杂度

  • 时间复杂度：O(n)，只扫描一次数组。
  • 空间复杂度：O(1)，只使用循环变量。
  • 支持提前结束：遇到首个越界位移便返回。

替代方案

  • 前缀最大值：对每个 i ≥ 2，检查 max(nums[0..i-2]) > nums[i]。若成立就找到了非局部倒置。仍是 O(n) 时间、O(1) 额外空间。
  • 归并排序计数：分别统计全局倒置与局部倒置，时间 O(n log n)、空间 O(n)。通用但没有利用“排列”这一强约束。
  • 双重循环：直接枚举所有下标对，时间 O(n²)，在 n = 105 时不可行。

面试追问

  1. 如果输入不保证是排列，位移条件是否仍然成立？不一定，证明依赖值域完整且无重复。
  2. 如何找出第一个非局部倒置而不只是返回布尔值？可维护隔一个位置之前的前缀最大值及其下标。
  3. 若要求统计全局倒置总数怎么办？使用归并排序、树状数组或线段树。
  4. 能否在线处理数据流？位移法需要知道下标与值域语义；若要通用地检测非局部倒置，可维护历史前缀最大值。

常见错误

  • 只比较全局和局部倒置的“是否存在”，而不是判断是否存在额外的非局部倒置。
  • 写成 nums[i] - i > 1，漏掉向右移动超过一步的较小元素；必须取绝对值。
  • 统计所有倒置导致 O(n²) 超时。
  • 忘记题目保证输入是排列，从而设计了不必要的哈希表或排序。

JavaLeetCode 提交格式
class Solution {
    public boolean isIdealPermutation(int[] nums) {
        for (int i = 0; i < nums.length; i++) {
            if (Math.abs(nums[i] - i) > 1) {
                return false;
            }
        }
        return true;
    }
}
