区间内查询数字的频率

Range Frequency Queries

一段固定数组，多次区间提问。你会怎样快速数出某个值出现了几次？

2080

01 / PROBLEM

题意与接口

设计一个数据结构，接收一个下标从 0 开始的整数数组。之后可以反复查询：在包含左右端点的连续区间内，指定数字一共出现多少次。这里的“频率”是出现次数，不是占比；数组在构造后不会修改。

  • RangeFreqQuery(int[] arr)：用完整数组 arr 构造实例。
  • int query(int left, int right, int value)：返回 arr[left...right] 中等于 value 的元素数量。
先独立思考：最多 100,000 次查询。你愿意为构造过程付出多少工作，来减少之后每次查询的工作？

约束

  • 1 ≤ arr.length ≤ 10⁵
  • 1 ≤ arr[i], value ≤ 10⁴
  • 0 ≤ left ≤ right < arr.length
  • query 最多调用 10⁵ 次。

读题边界

  • 区间 [left, right] 两端都计入。
  • left = right 是合法的单元素区间。
  • 目标数字可能从未出现在数组中。
  • 构造操作的输出占位符为 null。

04 / SOLUTION

准备好对照思路了吗？

展开后包含机制演示、推导与四语言实现。

只找这个值的下标，再切出一段

核心洞察：对同一个 value，所有出现位置天然有序。把每种值映射到它的下标列表，查询就变成“有多少个下标落在 [left,right] 中”。扫描原数组时按顺序追加下标，不需要额外排序。

设目标列表为 p。找到第一个 p[i] ≥ left 的列表位置 a，再找到第一个 p[i] > right 的列表位置 b。答案是 b − a，对应半开切片 p[a:b]。

完整过程与正确性

  1. 建表：从左到右遍历 arr，将下标 i 追加到 pos[arr[i]]。每个元素恰好存储一次。
  2. 选列表：取 pos[value]。不存在时直接返回 0。
  3. 左边界：在 [0,m) 二分寻找第一个不小于 left 的下标，得到 a。
  4. 右边界：在相同列表二分寻找第一个大于 right 的下标，得到 b。
  5. 计数：返回 b-a。这里减的是列表位置，不是原数组下标。

为什么二分和相减都正确？

建表保持原遍历顺序，所以每个位置列表严格递增，且恰好包含目标值的所有出现位置。对于下界搜索，循环不变式是：lo 之前的元素都小于阈值，hi 及其之后的元素都不小于阈值。若中点小于阈值，令 lo=mid+1；否则令 hi=mid。搜索范围严格缩小，结束时 lo=hi 就是第一个满足条件的位置，可能等于 m。

上界搜索将条件换成“是否大于 right”。因此 a 之前都不在区间内，b 开始都超过区间右端；由有序性，且仅有列表位置 [a,b) 满足 left ≤ p[j] ≤ right。每个位置对应一个目标元素，数量正是 b-a。

例如 33 的下标列表是 [1,7]。查询 [0,11] 得 a=0、b=2，答案为 2。若查询 [2,6]，a=b=1，答案为 0，尽管 33 在整个数组里存在。

边界与常见错误

  • 右端点要计入：使用 upper_bound(right)；整数场景也等价于 lower_bound(right+1)。本题 right 最大 99999，加一安全；通用整型上限场景应避免加一溢出。
  • 返回 b-a，不要再加 1。两个边界是半开列表区间。
  • 不要把 p[b]-p[a] 当成次数，更不能访问可能等于 m 的边界。
  • 缺失值、单元素、全部相同、区间没有命中均无需特殊二分分支；缺失值可提前返回。
  • 按出现位置存储，不能只记录每个值的全局总次数；全局频次无法恢复区间分布。
  • 不能用每次扫描整个区间来应对最坏的十万次查询；也不应在每次查询里重建索引。

复杂度

设数组长度为 n，目标值出现 m 次。使用哈希映射时，构造期望 O(n) 时间、O(n) 总空间；单次查询期望 O(log(m+1)) 时间（包含映射查找），额外空间 O(1)。q 次查询总计期望 O(n + q log(n+1))。这些哈希实现的查找界限依赖通常的平均 / 期望 O(1) 假设。

替代方案

  • 逐项扫描：不需要额外索引，单次 O(right-left+1)，适合少量小区间查询。
  • 每个值一份前缀频次数组：查询 O(1)，但 n×V 的空间与预处理代价太大，本题 V 可达 10⁴。
  • 按值域直接开位置列表：用 10001 个桶替代哈希表，构造 O(n+V)、空间 O(n+V)，查询不依赖哈希假设。
  • 带频次信息的树结构：可以应对修改或更广的查询类型，但静态精确值计数用有序位置列表更简单。

面试追问

  • 如果允许修改 arr[i]？必须从旧值的位置集合删除 i，再加入新值集合；可以使用支持排名的平衡树。普通有序数组插入删除是 O(n)，不能直接宣称更新 O(log n)。
  • 如果询问区间第 k 小，而非某值次数？索引目标发生变化，可讨论 Wavelet Tree 或持久化线段树。
  • 如果值域很小且内存充足？可以比较按值前缀计数与位置列表的空间、查询时间取舍。
  • 为什么无需排序？下标按 0 到 n−1 依次追加，每份列表已经严格递增。

Java

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class RangeFreqQuery {
    private final Map<Integer, List<Integer>> pos = new HashMap<>();

    public RangeFreqQuery(int[] arr) {
        for (int i = 0; i < arr.length; i++) {
            pos.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);
        }
    }

    public int query(int left, int right, int value) {
        List<Integer> p = pos.get(value);
        if (p == null) return 0;
        return lowerBound(p, right + 1) - lowerBound(p, left);
    }

    private int lowerBound(List<Integer> p, int target) {
        int lo = 0, hi = p.size();
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (p.get(mid) < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }
}

JavaScript

/** @param {number[]} arr */
var RangeFreqQuery = function(arr) {
    this.pos = new Map();
    for (let i = 0; i < arr.length; i++) {
        if (!this.pos.has(arr[i])) this.pos.set(arr[i], []);
        this.pos.get(arr[i]).push(i);
    }
};

function lowerBound(p, target) {
    let lo = 0, hi = p.length;
    while (lo < hi) {
        const mid = lo + Math.floor((hi - lo) / 2);
        if (p[mid] < target) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}

/**
 * @param {number} left
 * @param {number} right
 * @param {number} value
 * @return {number}
 */
RangeFreqQuery.prototype.query = function(left, right, value) {
    const p = this.pos.get(value);
    if (!p) return 0;
    return lowerBound(p, right + 1) - lowerBound(p, left);
};

Python 3

from bisect import bisect_left, bisect_right
from typing import List


class RangeFreqQuery:
    def __init__(self, arr: List[int]):
        self.pos = {}
        for i, value in enumerate(arr):
            self.pos.setdefault(value, []).append(i)

    def query(self, left: int, right: int, value: int) -> int:
        p = self.pos.get(value)
        if p is None:
            return 0
        return bisect_right(p, right) - bisect_left(p, left)

C++

#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class RangeFreqQuery {
    unordered_map<int, vector<int>> pos;

public:
    RangeFreqQuery(vector<int>& arr) {
        for (int i = 0; i < static_cast<int>(arr.size()); ++i) {
            pos[arr[i]].push_back(i);
        }
    }

    int query(int left, int right, int value) {
        auto it = pos.find(value);
        if (it == pos.end()) return 0;
        const auto& p = it->second;
        auto a = lower_bound(p.begin(), p.end(), left);
        auto b = upper_bound(p.begin(), p.end(), right);
        return static_cast<int>(b - a);
    }
};
