库存管理 III找出库存余量最少的 cnt 个商品

给定整数数组 stock，其中 stock[i] 表示第 i 个商品的库存余量。请返回库存余量最少的 cnt 个商品余量，返回顺序不限。

输入：stock, cnt 输出：number[] 顺序不限

约束

  • 0 <= cnt <= stock.length <= 10000
  • 0 <= stock[i] <= 10000
  • 结果只要求包含正确的多重集合，不要求排序。

题解：三路快速选择

核心洞察

题目只要求“最少的 cnt 个”而不要求有序，因此不必把全部库存排序。围绕一个参照值把当前区间分为 < pivot、== pivot、> pivot 三段；只继续处理目标下标所在的一段。重复值整段一次定位，避免全相等输入反复缩小一个位置。

完整过程

  1. cnt == 0 时直接返回空数组。
  2. 目标下标设为 cnt - 1，初始区间覆盖整个数组。
  3. 随机选择参照值，用三路切分得到相等区间 [lt, gt]。
  4. 目标在左侧就收缩右边界，在右侧就收缩左边界。
  5. 目标落入相等区间时，数组前 cnt 个就是合法答案。

边界与副作用

  • cnt = 0、cnt = stock.length。
  • 空数组只会与 cnt = 0 同时出现。
  • 全相等、重复边界值、库存 0 与 10000。
  • 快速选择会原地改写 stock；若调用方要保留输入，应先复制。
  • 答案顺序不限，验证时应比较排序后的多重集合。
期望 O(n)

随机参照值下，每轮只继续一侧；最坏情况为 O(n²)。

额外 O(1)

切分原地完成；返回数组所占空间不计入辅助空间。

结果 O(cnt)

返回数组包含恰好 cnt 个库存余量。

真正的替代方案

维护容量为 cnt 的大顶堆。扫描库存，堆超过容量时弹出最大值；最终堆内就是答案。 时间 O(n log cnt)、空间 O(cnt)，不改原数组，尤其适合数据流或 cnt 很小的场景。由于值域固定为 0..10000，还可用计数桶在 O(n + 10001) 时间内取够 cnt 个。

常见错误

  • 忘记先处理 cnt = 0，让目标下标变成 -1。
  • 把单个参照值位置当成重复值的完整边界。
  • 无意中要求输出升序，增加题目并不需要的工作。
  • 对返回顺序做精确比较，误判合法答案。
  • 调用者仍需原数组，却直接在其上切分。

面试追问

数据持续到达且只保留最小 cnt 个怎么办？

使用容量为 cnt 的大顶堆，单次更新 O(log cnt)，无需保存全部历史数据。

如果答案必须升序呢？

快速选择后只排序前 cnt 个，期望 O(n) + O(cnt log cnt)。

如果不允许改原数组呢？

复制后快速选择，或改用大顶堆；两者分别增加 O(n) 或 O(cnt) 空间。

如何稳定保留原下标？

把元素保存为 (value, index)，并为相同库存定义明确的下标次序。 

import java.util.Arrays;
import java.util.concurrent.ThreadLocalRandom;

class Solution {
    public int[] inventoryManagement(int[] stock, int cnt) {
        if (cnt == 0) {
            return new int[0];
        }
        int left = 0;
        int right = stock.length - 1;
        int target = cnt - 1;

        while (left <= right) {
            int pivot = stock[ThreadLocalRandom.current().nextInt(left, right + 1)];
            int lt = left;
            int i = left;
            int gt = right;
            while (i <= gt) {
                if (stock[i] < pivot) {
                    swap(stock, i++, lt++);
                } else if (stock[i] > pivot) {
                    swap(stock, i, gt--);
                } else {
                    i++;
                }
            }
            if (target < lt) {
                right = lt - 1;
            } else if (target > gt) {
                left = gt + 1;
            } else {
                break;
            }
        }
        return Arrays.copyOf(stock, cnt);
    }

    private void swap(int[] values, int a, int b) {
        int temp = values[a];
        values[a] = values[b];
        values[b] = temp;
    }
}

var inventoryManagement = function (stock, cnt) {
    if (cnt === 0) return [];

    const swap = (a, b) => {
        [stock[a], stock[b]] = [stock[b], stock[a]];
    };
    let left = 0;
    let right = stock.length - 1;
    const target = cnt - 1;

    while (left <= right) {
        const pivotIndex = left + Math.floor(Math.random() * (right - left + 1));
        const pivot = stock[pivotIndex];
        let lt = left;
        let i = left;
        let gt = right;
        while (i <= gt) {
            if (stock[i] < pivot) swap(i++, lt++);
            else if (stock[i] > pivot) swap(i, gt--);
            else i++;
        }
        if (target < lt) right = lt - 1;
        else if (target > gt) left = gt + 1;
        else break;
    }
    return stock.slice(0, cnt);
};
import random
from typing import List

class Solution:
    def inventoryManagement(self, stock: List[int], cnt: int) -> List[int]:
        if cnt == 0:
            return []

        left, right = 0, len(stock) - 1
        target = cnt - 1
        while left <= right:
            pivot = stock[random.randint(left, right)]
            lt, i, gt = left, left, right
            while i <= gt:
                if stock[i] < pivot:
                    stock[i], stock[lt] = stock[lt], stock[i]
                    i += 1
                    lt += 1
                elif stock[i] > pivot:
                    stock[i], stock[gt] = stock[gt], stock[i]
                    gt -= 1
                else:
                    i += 1
            if target < lt:
                right = lt - 1
            elif target > gt:
                left = gt + 1
            else:
                break
        return stock[:cnt]
#include <algorithm>
#include <random>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> inventoryManagement(vector<int>& stock, int cnt) {
        if (cnt == 0) {
            return {};
        }
        int left = 0;
        int right = static_cast<int>(stock.size()) - 1;
        int target = cnt - 1;
        static mt19937 rng(random_device{}());

        while (left <= right) {
            uniform_int_distribution<int> pick(left, right);
            int pivot = stock[pick(rng)];
            int lt = left;
            int i = left;
            int gt = right;
            while (i <= gt) {
                if (stock[i] < pivot) {
                    swap(stock[i++], stock[lt++]);
                } else if (stock[i] > pivot) {
                    swap(stock[i], stock[gt--]);
                } else {
                    ++i;
                }
            }
            if (target < lt) right = lt - 1;
            else if (target > gt) left = gt + 1;
            else break;
        }
        return vector<int>(stock.begin(), stock.begin() + cnt);
    }
};
