Problem brief

题目说明

给定一棵二叉树的根结点 root，树中每个结点的值只能是 0 或 1。请返回剪枝后的原树：凡是整棵子树中完全不含 1 的部分，都要被移除。

子树定义：某个结点自身，以及从该结点出发能够到达的全部后代结点。

函数签名

pruneTree(root: TreeNode) -> TreeNode

参数：二叉树根结点 root。返回：剪除无效子树后的根结点；整棵树被剪除时返回空。

约束

  • 树中结点数在 [1, 200] 内。
  • Node.val 只能为 0 或 1。

Solution / Postorder DFS

题解：让返回值代表“这棵子树是否值得保留”

核心洞察

一个结点能否删除，取决于它的左右子树处理完之后还剩什么。因此必须先处理孩子，再决定父亲——这正是后序遍历。当某结点值为 0，且剪枝后的左右孩子都为空时，以它为根的整棵子树不含 1，可以返回空。

一句话判定式

node.val == 0 && node.left == null && node.right == null 时删除当前结点；否则保留。

完整过程

  1. 空结点直接返回空，作为递归边界。
  2. 递归剪枝左子树，把返回结果重新接到 node.left。
  3. 递归剪枝右子树，把返回结果重新接到 node.right。
  4. 若当前值为 0 且两个孩子均为空，返回空；否则返回当前结点。

正确性说明

归纳基础：空子树不含 1，函数返回空；单个叶子中，0 被删、1 被保留，结论成立。

归纳步骤：假设左右子树递归后恰好保留所有含 1 的部分。若当前值为 1，当前子树必含 1，应保留；若当前值为 0，则只有至少一个处理后的孩子非空时，后代中才含 1。判定式恰好覆盖两种情况，所以返回结果正确。

O(n)时间：每个结点访问一次
O(h)递归栈：h 为树高
O(n)最坏栈空间：链状树

边界情况

  • 整棵树全为 0：根最终也返回空。
  • 只有根为 1：根直接保留。
  • 值为 0 的祖先下面藏着 1：祖先必须保留，用来维持连通路径。
  • 树退化成链：逻辑不变，但递归深度达到结点数。

常见错误

  • 看到值为 0 就立刻删除，忽略其后代可能含 1。
  • 递归完成后没有把返回值写回左右指针，导致剪枝未生效。
  • 只判断原始孩子是否为空，而不是判断“剪枝后”的孩子。
  • 忘记根本身也可能被删除。

替代方案

也可以写一个 DFS 返回布尔值“子树是否含 1”，同时在父结点处根据布尔值断开孩子。它与直接返回剪枝后根结点本质相同，但需要同时维护布尔结果和指针；直接让递归返回新根更紧凑。层序遍历不适合直接判断，因为删除父结点前仍需知道全部后代。

面试追问

  • 如果结点值不是 0/1，而是要保留满足谓词的结点，该如何抽象？
  • 如何改成不修改原树、返回一棵新树？空间复杂度怎样变化？
  • 若树很深导致栈溢出，如何用显式栈模拟后序遍历？

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode pruneTree(TreeNode root) {
        if (root == null) {
            return null;
        }

        root.left = pruneTree(root.left);
        root.right = pruneTree(root.right);

        if (root.val == 0 && root.left == null && root.right == null) {
            return null;
        }
        return root;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {TreeNode}
 */
var pruneTree = function(root) {
    if (root === null) {
        return null;
    }

    root.left = pruneTree(root.left);
    root.right = pruneTree(root.right);

    if (root.val === 0 && root.left === null && root.right === null) {
        return null;
    }
    return root;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def pruneTree(
        self,
        root: Optional[TreeNode]
    ) -> Optional[TreeNode]:
        if root is None:
            return None

        root.left = self.pruneTree(root.left)
        root.right = self.pruneTree(root.right)

        if root.val == 0 and root.left is None and root.right is None:
            return None
        return root
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* pruneTree(TreeNode* root) {
        if (root == nullptr) {
            return nullptr;
        }

        root->left = pruneTree(root->left);
        root->right = pruneTree(root->right);

        if (root->val == 0 &&
            root->left == nullptr &&
            root->right == nullptr) {
            return nullptr;
        }
        return root;
    }
};
