01 / Problem

题目要求

给定两个长度相同的整数数组。每当 nums1[i] > nums2[i]，就在位置 i 获得一个“优势”。返回 nums1 的任意一种排列，使优势总数最大。

示例 1

输入：nums1 = [2,7,11,15], nums2 = [1,10,4,11]
输出：[2,11,7,15]

四个位置均满足严格大于，优势为 4。

示例 2

输入：nums1 = [12,24,8,32], nums2 = [13,25,32,11]
输出：[24,32,8,12]

答案不唯一；任意达到最大优势的排列均可。

函数签名

advantageCount(nums1, nums2) → integer[]

约束

  • 1 ≤ nums1.length ≤ 10⁵
  • nums2.length == nums1.length
  • 0 ≤ nums1[i], nums2[i] ≤ 10⁹

包含证明、复杂度、四语言代码与面试追问。

核心洞察：能赢就刚好赢

把 nums1 排序。按 nums2 从大到小处理：若当前最大牌能击败对手，就出最大牌拿下这一分；否则连最大牌都赢不了，便用最小牌承受这次失败。

为什么从最大对手开始？

强牌是稀缺资源。先判断它能否拿下最难的一局，可以避免它被较弱对手过度消耗；无法取胜时，最小牌也不会损失未来任何本可取得的胜场。

完整过程

排序与索引
将 nums1 升序排列；将 nums2 的下标按对应值降序排列，保留原下标以便回填。
建立双指针
left 指向 nums1 最小值，right 指向最大值。
逐个挑战
若 nums1[right] > nums2[index]，把最大值放到该下标并右指针左移；否则把最小值放入并让左指针右移。
返回排列
所有位置填完后，答案天然保持 nums2 的原始下标顺序。

正确性说明（交换论证）

考虑尚未处理的最大对手 b。若当前最大牌 x 能赢 b，让 x 对阵 b 不会减少最优胜场：任何最优方案中，若另一张能赢的牌对阵 b，可与 x 交换；若 b 原本输掉，则让 x 取胜只会更好。若 x ≤ b，所有剩余牌都无法赢 b，因此用最小牌牺牲不会损失该局胜场，并保留更大的牌给更小对手。每步均存在同样最优的剩余安排，归纳可知算法达到最大优势。

复杂度

排序占 O(n log n) 时间，遍历为 O(n)；索引与答案数组占 O(n) 额外空间（不计排序实现自身开销）。

边界情况

单元素；大量重复值；全部可赢或全部不可赢；严格大于才算胜利，相等必须视为失败；数值可达 10⁹，但不涉及乘法溢出。

替代方案

可将 nums2 升序后，从小到大为每个对手挑 nums1 中最小的可胜元素；若用平衡树可达 O(n log n)，但实现与常数更复杂。也可按 nums1 从小到大用队列“发牌”，本质仍是相同贪心。

常见错误

直接对两个数组排序后返回，丢失 nums2 原下标；把 > 写成 >=；失败时浪费最大值；只统计胜场却没有构造排列。

面试追问

答案唯一吗？ 不唯一。 能否 O(n)？ 一般输入下需要确定相对次序，排序方案是主流；若值域很小，可用计数结构优化。 如何只求最大优势数？ 将两数组排序后用双指针统计可匹配的胜场即可。

四语言实现

import java.util.Arrays;

class Solution {
    public int[] advantageCount(int[] nums1, int[] nums2) {
        int n = nums1.length;
        Arrays.sort(nums1);
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (i, j) -> Integer.compare(nums2[j], nums2[i]));

        int[] answer = new int[n];
        int left = 0, right = n - 1;
        for (int index : order) {
            if (nums1[right] > nums2[index]) {
                answer[index] = nums1[right--];
            } else {
                answer[index] = nums1[left++];
            }
        }
        return answer;
    }
}

    nums1.sort((a, b) => a - b);
    const order = nums2.map((_, i) => i)
        .sort((i, j) => nums2[j] - nums2[i]);
    const answer = new Array(nums1.length);

        }
    }

from typing import List

class Solution:
    def advantageCount(self, nums1: List[int], nums2: List[int]) -> List[int]:
        nums1.sort()
        order = sorted(range(len(nums2)), key=lambda i: nums2[i], reverse=True)
        answer = [0] * len(nums1)
        left, right = 0, len(nums1) - 1

        for index in order:
            if nums1[right] > nums2[index]:
                answer[index] = nums1[right]
                right -= 1
            else:
                answer[index] = nums1[left]
                left += 1
        return answer

class Solution {

    vector<int> advantageCount(vector<int>& nums1, vector<int>& nums2) {

        sort(nums1.begin(), nums1.end());

        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int i, int j) {
            return nums2[i] > nums2[j];
        });

        int left = 0, right = n - 1;
        for (int index : order) {
            if (nums1[right] > nums2[index]) {
                answer[index] = nums1[right--];
            } else {
                answer[index] = nums1[left++];
            }
        }
        return answer;
    }
};
