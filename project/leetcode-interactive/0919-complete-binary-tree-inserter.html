题目

完全二叉树除最后一层外每层都填满，最后一层的节点从左向右连续排列。给定一棵非空完全二叉树，设计一个插入器，使每次加入新节点后仍保持完全性。

接口

  • CBTInserter(TreeNode root)：以给定根节点初始化。
  • int insert(int val)：插入值为 val 的节点，返回其父节点的值。
  • TreeNode get_root()：返回当前根节点。

官方示例（完整参数形式）

输入
["CBTInserter", "insert", "insert", "get_root"]
[[[1, 2]], [3], [4], []]

输出
[null, 1, 2, [1, 2, 3, 4]]

解释
初始树为 [1,2]；insert(3) 返回 1；insert(4) 返回 2；最终层序数组为 [1,2,3,4]。

约束

  • 初始节点数为 [1, 1000]。
  • 0 ≤ Node.val, val ≤ 5000。
  • root 是完全二叉树。
  • insert 与 get_root 合计最多调用 10⁴ 次。

题解：维护“尚未满员”的父节点队列

核心洞察

完全二叉树的下一个插入位置由层序顺序唯一确定。维护一个队列，里面只放缺少左孩子或右孩子的节点；队首永远是下一次插入的父节点。先填左孩子，再填右孩子；右孩子填完后，父节点出队，新节点入队。

完整过程

  1. 构造时广度优先遍历原树，把每个孩子不全的节点按层序加入候选队列。
  2. insert(val) 取队首 parent，创建新节点。
  3. 若左孩子为空则接到左侧；否则接到右侧并弹出已经满员的 parent。
  4. 新节点没有孩子，必定成为未来候选，因此入队；返回 parent.val。
  5. get_root() 直接返回保存的根。

正确性证明

不变式：每次操作前，队列恰好按层序保存所有未满节点。

初始化 BFS 逐层从左到右扫描，故不变式成立。插入时，队首是层序中最早的空位拥有者：先补左侧；若补右侧则该父节点满员并出队。新节点自身未满且在层序末尾，所以入队后顺序仍正确。由数学归纳法，每次插入都占据完全二叉树规定的下一个位置，树始终完全。

边界情况

  • 只有根节点：第一次插入成为左孩子，根仍留在队首。
  • 队首已有左孩子：新节点成为右孩子，随后父节点出队。
  • 值可为 0，不能把数值真假当作节点是否存在。
  • 最多 10⁴ 次调用，队列应避免 JavaScript 的频繁 shift()；用头指针即可。

复杂度

设初始化时节点数为 n：构造时间 O(n)，额外空间 O(n)；每次 insert 摊还/最坏时间 O(1)，get_root 为 O(1)。

替代方案

也可用完全二叉树的数组下标关系：新节点下标为当前节点数，父下标为 (i-1)/2。若维护所有节点的层序数组，插入也是 O(1)，但保存了所有节点；候选队列只强调仍可接孩子的节点，语义更直接。

面试追问

  • 如果初始树不保证完全，如何检测？—— BFS 中一旦见到空位置，之后不能再见非空节点。
  • 并发插入怎么办？—— 队首读取、挂接、出入队必须成为一个原子临界区。
  • 如何支持删除？—— 删除会改变层序尾部与候选集合，需要额外维护末节点及父子关系。

常见错误

  • 每次插入都重新 BFS，退化为 O(n)。
  • 填完左孩子就让父节点出队，导致右侧永久空缺。
  • 新节点忘记入队，后续无法继续扩展。
  • JavaScript 使用 shift() 导致数组整体搬移。

四语言完整代码

Java

class CBTInserter {
    private final TreeNode root;
    private final Queue<TreeNode> candidates = new ArrayDeque<>();

    public CBTInserter(TreeNode root) {
        this.root = root;
        Queue<TreeNode> bfs = new ArrayDeque<>();
        bfs.offer(root);
        while (!bfs.isEmpty()) {
            TreeNode node = bfs.poll();
            if (node.left == null || node.right == null) candidates.offer(node);
            if (node.left != null) bfs.offer(node.left);
            if (node.right != null) bfs.offer(node.right);
        }
    }

    public int insert(int val) {
        TreeNode parent = candidates.peek();
        TreeNode child = new TreeNode(val);
        if (parent.left == null) parent.left = child;
        else { parent.right = child; candidates.poll(); }
        candidates.offer(child);
        return parent.val;
    }

    public TreeNode get_root() { return root; }
}

JavaScript

var CBTInserter = function(root) {
    this.root = root;
    this.queue = [];
    this.head = 0;
    const bfs = [root];
    for (let i = 0; i < bfs.length; i++) {
        const node = bfs[i];
        if (node.left === null || node.right === null) this.queue.push(node);
        if (node.left !== null) bfs.push(node.left);
        if (node.right !== null) bfs.push(node.right);
    }
};

CBTInserter.prototype.insert = function(val) {
    const parent = this.queue[this.head];
    const child = new TreeNode(val);
    if (parent.left === null) parent.left = child;
    else { parent.right = child; this.head++; }
    this.queue.push(child);
    return parent.val;
};

CBTInserter.prototype.get_root = function() { return this.root; };

Python

from collections import deque

class CBTInserter:
    def __init__(self, root: Optional[TreeNode]):
        self.root = root
        self.candidates = deque()
        bfs = deque([root])
        while bfs:
            node = bfs.popleft()
            if node.left is None or node.right is None:
                self.candidates.append(node)
            if node.left is not None:
                bfs.append(node.left)
            if node.right is not None:
                bfs.append(node.right)

    def insert(self, val: int) -> int:
        parent = self.candidates[0]
        child = TreeNode(val)
        if parent.left is None:
            parent.left = child
        else:
            parent.right = child
            self.candidates.popleft()
        self.candidates.append(child)
        return parent.val

    def get_root(self) -> Optional[TreeNode]:
        return self.root

class CBTInserter {
    TreeNode* root;
    queue<TreeNode*> candidates;
public:
    CBTInserter(TreeNode* root) : root(root) {
        queue<TreeNode*> bfs;
        bfs.push(root);
        while (!bfs.empty()) {
            TreeNode* node = bfs.front(); bfs.pop();
            if (!node->left || !node->right) candidates.push(node);
            if (node->left) bfs.push(node->left);
            if (node->right) bfs.push(node->right);
        }
    }

    int insert(int val) {
        TreeNode* parent = candidates.front();
        TreeNode* child = new TreeNode(val);
        if (!parent->left) parent->left = child;
        else { parent->right = child; candidates.pop(); }
        candidates.push(child);
        return parent->val;
    }

    TreeNode* get_root() { return root; }
};
