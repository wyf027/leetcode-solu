绝对差不超过限制的最长连续子数组

Longest Continuous Subarray With Absolute Diff Less Than or Equal to Limit

The task

在变化的数据中，找到一段始终“相处融洽”的最长连续区间。

先读题、动手观察，再决定是否展开底部题解。

Problem

题目描述

连续子数组不能跳过元素；“任意两个元素”这一条件可由区间的最大值与最小值刻画。

给定整数数组 nums 和整数 limit，返回最长非空连续子数组的长度，使其中任意两个元素的绝对差都小于或等于 limit。

01
输入：nums = [8,2,4,7], limit = 4
输出：2

[2,4] 与 [4,7] 都满足条件，长度均为 2；包含 8 和 2 的区间差值为 6，超出限制。

02
输入：nums = [10,1,2,4,7,2], limit = 5
输出：4

最长区间是 [2,4,7,2]，其最大绝对差为 |2 − 7| = 5。

03
输入：nums = [4,2,2,2,4,4,2,2], limit = 0
输出：3

限制为 0 时，区间中的所有数必须相等；连续的三个 2 构成最长答案。

约束

  • 1 ≤ nums.length ≤ 105
  • 1 ≤ nums[i] ≤ 109
  • 0 ≤ limit ≤ 109

准备好核对思路了吗？

下面的完整题解默认收起。先在纸上写下你维护窗口最大值和最小值的方案，再展开对照。

Solution

滑动窗口 + 两个单调双端队列

01

只看两个极值

区间内任意两数的最大绝对差，恰好等于区间最大值减最小值。

02

右扩、左缩

右端加入新数；若极值差超限，持续右移左端，直到窗口重新合法。

03

队首就是答案

递减队列队首给最大值，递增队列队首给最小值；下标过期就从队首弹出。

完整过程

  1. 令 left = 0，准备一个递减队列 maxDeque 和一个递增队列 minDeque，两者都保存数组下标。
  2. 右端点 right 从左到右扫描。加入 nums[right] 前，弹掉各自队尾中不可能再成为极值的下标：最大队列弹掉不大于新值的元素，最小队列弹掉不小于新值的元素。
  3. 当 nums[maxDeque.front] - nums[minDeque.front] > limit，窗口非法。若某个队首等于 left，先将它弹出，然后递增 left；重复直到合法。
  4. 每轮用 right - left + 1 更新最长长度。

为什么正确

极值等价：一个区间中任意两元素的绝对差都不超过限制，当且仅当该区间的最大值减最小值不超过限制。

队列不变式：最大队列按值递减、最小队列按值递增，且只保留当前窗口下标。因此两个队首始终分别是当前窗口最大值和最小值。

窗口最优性：固定右端点时，收缩停止后的 left 是能使窗口合法的最左位置，所以此时得到以该右端点结尾的最长合法区间。遍历所有右端点并取最大值，即得到全局最优解。

边界情况

  • 数组只有一个元素时，答案恒为 1。
  • limit = 0 时，合法窗口只能包含相同值。
  • 重复值可以安全地从队尾替换为更新的下标，因为新下标存活时间更长。
  • 数值可达 109；本题差值仍在 32 位有符号整数范围内，但通用场景可使用更宽整数类型。

复杂度

时间 O(n)空间 O(n)

每个下标至多进入、离开每个队列各一次，因此总操作数是线性的。最坏情况下队列会保存整个窗口。

替代方案

有序多重集合

窗口增删均为 O(log n)，直接读取首尾获得极值；实现直观，总时间 O(n log n)。

两个堆

分别维护最大堆和最小堆，配合下标做延迟删除；可行，但状态更复杂。

暴力枚举

枚举起点并扩展终点，最坏 O(n²)，无法应对 105 的数据规模。

四语言完整代码

Java · ArrayDeque
class Solution {
    public int longestSubarray(int[] nums, int limit) {
        Deque<Integer> maxDeque = new ArrayDeque<>();
        Deque<Integer> minDeque = new ArrayDeque<>();
        int left = 0;
        int answer = 0;

        for (int right = 0; right < nums.length; right++) {
            while (!maxDeque.isEmpty()
                    && nums[maxDeque.peekLast()] <= nums[right]) {
                maxDeque.pollLast();
            }
            maxDeque.offerLast(right);

            while (!minDeque.isEmpty()
                    && nums[minDeque.peekLast()] >= nums[right]) {
                minDeque.pollLast();
            }
            minDeque.offerLast(right);

            while (nums[maxDeque.peekFirst()] - nums[minDeque.peekFirst()] > limit) {
                if (maxDeque.peekFirst() == left) maxDeque.pollFirst();
                if (minDeque.peekFirst() == left) minDeque.pollFirst();
                left++;
            }

            answer = Math.max(answer, right - left + 1);
        }
        return answer;
    }
}
JavaScript · 数组模拟双端队列
/**
 * @param {number[]} nums
 * @param {number} limit
 * @return {number}
 */
var longestSubarray = function(nums, limit) {
    const maxDeque = [];
    const minDeque = [];
    let maxHead = 0;
    let minHead = 0;
    let left = 0;
    let answer = 0;

    for (let right = 0; right < nums.length; right++) {
        while (maxDeque.length > maxHead &&
               nums[maxDeque[maxDeque.length - 1]] <= nums[right]) {
            maxDeque.pop();
        }
        maxDeque.push(right);

        while (minDeque.length > minHead &&
               nums[minDeque[minDeque.length - 1]] >= nums[right]) {
            minDeque.pop();
        }
        minDeque.push(right);

        while (nums[maxDeque[maxHead]] - nums[minDeque[minHead]] > limit) {
            if (maxDeque[maxHead] === left) maxHead++;
            if (minDeque[minHead] === left) minHead++;
            left++;
        }

        answer = Math.max(answer, right - left + 1);
    }
    return answer;
};
Python · collections.deque
from collections import deque
from typing import List


class Solution:
    def longestSubarray(self, nums: List[int], limit: int) -> int:
        max_deque = deque()
        min_deque = deque()
        left = 0
        answer = 0

        for right, value in enumerate(nums):
            while max_deque and nums[max_deque[-1]] <= value:
                max_deque.pop()
            max_deque.append(right)

            while min_deque and nums[min_deque[-1]] >= value:
                min_deque.pop()
            min_deque.append(right)

            while nums[max_deque[0]] - nums[min_deque[0]] > limit:
                if max_deque[0] == left:
                    max_deque.popleft()
                if min_deque[0] == left:
                    min_deque.popleft()
                left += 1

            answer = max(answer, right - left + 1)

        return answer
C++ · deque
class Solution {
public:
    int longestSubarray(vector<int>& nums, int limit) {
        deque<int> maxDeque;
        deque<int> minDeque;
        int left = 0;
        int answer = 0;

        for (int right = 0; right < static_cast<int>(nums.size()); ++right) {
            while (!maxDeque.empty() &&
                   nums[maxDeque.back()] <= nums[right]) {
                maxDeque.pop_back();
            }
            maxDeque.push_back(right);

            while (!minDeque.empty() &&
                   nums[minDeque.back()] >= nums[right]) {
                minDeque.pop_back();
            }
            minDeque.push_back(right);

            while (nums[maxDeque.front()] - nums[minDeque.front()] > limit) {
                if (maxDeque.front() == left) maxDeque.pop_front();
                if (minDeque.front() == left) minDeque.pop_front();
                ++left;
            }

            answer = max(answer, right - left + 1);
        }
        return answer;
    }
};

常见错误

  • 只比较相邻元素，而不是整个窗口的最大值和最小值。
  • 队列保存数值，导致无法判断队首是否已离开窗口。
  • 窗口非法时只收缩一次；正确做法是持续收缩直到重新合法。
  • 在更新答案前忘记先修复非法窗口。
