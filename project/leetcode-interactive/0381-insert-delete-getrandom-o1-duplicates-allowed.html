O(1) 时间插入、删除和获取随机元素 · 允许重复

设计一个支持重复数字的随机集合：插入一个值、删除该值的一次出现，并按元素出现次数对应的权重随机返回一个元素。三个操作都要求达到平均 O(1) 时间。

题号 381 非付费题 平均 O(1)

接口定义

  • RandomizedCollection()：初始化空集合。
  • boolean insert(int val)：始终插入 val；仅当插入前不存在该值时返回 true。
  • boolean remove(int val)：若存在则删除 一次出现并返回 true，否则返回 false。
  • int getRandom()：等概率抽取集合中的一个“位置”，因此某个值的返回概率与其出现次数成正比。

约束

  • −2³¹ ≤ val ≤ 2³¹ − 1
  • insert、remove、getRandom 的调用总数最多为 2 × 10⁵。
  • 调用 getRandom 时，集合中至少有一个元素。
  • 每个接口的目标为平均 O(1) 时间复杂度。

Core insight

核心洞察：动态数组 + 值到下标集合的映射

为什么随机抽取需要数组？

把多重集合的每次出现都放进连续数组。均匀随机生成 [0, size) 内的下标，就自然让重复值按出现次数获得权重。

为什么删除需要下标集合？

哈希映射记录每个值当前出现在哪些下标。删除时任取一个下标，用数组末尾元素覆盖该位置，再弹出末尾；同步修正两个值的下标集合。

完整过程

  1. 初始化：创建动态数组 values，以及映射 indices: value → set<index>。
  2. insert(val)：先判断下标集合是否为空，随后把数组当前长度登记为新下标，再把 val 追加到数组末尾。返回插入前是否不存在。
  3. remove(val)：若没有对应下标，返回 false。否则任取一个待删下标 removeIndex，读取末尾值与末尾下标。
  4. 末尾换位：把末尾值写到 removeIndex；从 val 的集合移除待删下标，在末尾值的集合中登记新位置并移除旧末尾位置，最后弹出数组末尾。
  5. 清理：若 val 的下标集合已空，可删除该映射项。
  6. getRandom()：均匀生成一个合法数组下标并返回对应元素。
顺序细节：当待删除值恰好也是末尾值时，下标集合会是同一个集合。按“移除待删下标 → 加入覆盖位置 → 移除旧末尾下标”的顺序更新，仍能覆盖 removeIndex == lastIndex 与重复值两种情况。

正确性证明

不变量 1：数组 values 中每个位置代表多重集合中的一次出现；对任意值 x，indices[x] 恰好包含数组中所有满足 values[i] = x 的下标。

插入保持不变量：新值只出现在追加后的末尾下标，同时该下标被加入对应集合，其他位置和映射不变。

删除保持不变量：待删位置被末尾值覆盖，映射中删除待删值的该位置，并把末尾值从旧末尾下标迁移到覆盖位置。弹出末尾后，数组中恰好少了一次 val，其余出现与映射一致。

随机性：数组长度为 n 时，每个下标被选中的概率都是 1/n。若值 x 出现 k 次，则返回它的概率为 k/n，正比于出现次数。

结论：三个操作均满足题目语义。

复杂度与边界

复杂度

  • insert：平均 O(1)
  • remove：平均 O(1)
  • getRandom：O(1)
  • 空间：O(n)

必须覆盖的边界

  • 首次插入与重复插入的返回值不同。
  • 删除不存在的值不改变结构。
  • 待删位置就是数组末尾。
  • 待删值与末尾值相同，且可能有多个副本。
  • 删除最后一次出现后清除空集合。
  • 整数可达 32 位有符号范围两端。

import java.util.*;

class RandomizedCollection {
    private final List<Integer> values;
    private final Map<Integer, Set<Integer>> indices;
    private final Random random;

    public RandomizedCollection() {
        values = new ArrayList<>();
        indices = new HashMap<>();
        random = new Random();
    }

    public boolean insert(int val) {
        boolean isNew = !indices.containsKey(val)
            || indices.get(val).isEmpty();
        indices.computeIfAbsent(val, key -> new HashSet<>())
               .add(values.size());
        values.add(val);
        return isNew;
    }

    public boolean remove(int val) {
        Set<Integer> positions = indices.get(val);
        if (positions == null || positions.isEmpty()) {
            return false;
        }

        int removeIndex = positions.iterator().next();
        int lastIndex = values.size() - 1;
        int lastValue = values.get(lastIndex);

        values.set(removeIndex, lastValue);
        positions.remove(removeIndex);
        indices.get(lastValue).add(removeIndex);
        indices.get(lastValue).remove(lastIndex);
        values.remove(lastIndex);

        if (positions.isEmpty()) {
            indices.remove(val);
        }
        return true;
    }

    public int getRandom() {
        return values.get(random.nextInt(values.size()));
    }
}
var RandomizedCollection = function() {
    this.values = [];
    this.indices = new Map();
};

RandomizedCollection.prototype.insert = function(val) {
    const isNew = !this.indices.has(val)
        || this.indices.get(val).size === 0;
    if (!this.indices.has(val)) {
        this.indices.set(val, new Set());
    }
    this.indices.get(val).add(this.values.length);
    this.values.push(val);
    return isNew;
};

RandomizedCollection.prototype.remove = function(val) {
    const positions = this.indices.get(val);
    if (!positions || positions.size === 0) {
        return false;
    }

    const removeIndex = positions.values().next().value;
    const lastIndex = this.values.length - 1;
    const lastValue = this.values[lastIndex];

    this.values[removeIndex] = lastValue;
    positions.delete(removeIndex);
    this.indices.get(lastValue).add(removeIndex);
    this.indices.get(lastValue).delete(lastIndex);
    this.values.pop();

    if (positions.size === 0) {
        this.indices.delete(val);
    }
    return true;
};

RandomizedCollection.prototype.getRandom = function() {
    const index = Math.floor(Math.random() * this.values.length);
    return this.values[index];
};
import random
from collections import defaultdict


class RandomizedCollection:
    def __init__(self):
        self.values = []
        self.indices = defaultdict(set)

    def insert(self, val: int) -> bool:
        is_new = len(self.indices[val]) == 0
        self.indices[val].add(len(self.values))
        self.values.append(val)
        return is_new

    def remove(self, val: int) -> bool:
        if not self.indices[val]:
            return False

        remove_index = self.indices[val].pop()
        last_index = len(self.values) - 1
        last_value = self.values[last_index]

        self.values[remove_index] = last_value
        self.indices[last_value].add(remove_index)
        self.indices[last_value].discard(last_index)
        self.values.pop()

        if not self.indices[val]:
            del self.indices[val]
        return True

    def getRandom(self) -> int:
        return random.choice(self.values)
#include <cstdlib>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

class RandomizedCollection {
private:
    vector<int> values;
    unordered_map<int, unordered_set<int>> indices;

public:
    RandomizedCollection() = default;

    bool insert(int val) {
        bool isNew = indices[val].empty();
        indices[val].insert(static_cast<int>(values.size()));
        values.push_back(val);
        return isNew;
    }

    bool remove(int val) {
        auto found = indices.find(val);
        if (found == indices.end() || found->second.empty()) {
            return false;
        }

        int removeIndex = *found->second.begin();
        int lastIndex = static_cast<int>(values.size()) - 1;
        int lastValue = values[lastIndex];

        values[removeIndex] = lastValue;
        found->second.erase(removeIndex);
        indices[lastValue].insert(removeIndex);
        indices[lastValue].erase(lastIndex);
        values.pop_back();

        if (found->second.empty()) {
            indices.erase(val);
        }
        return true;
    }

    int getRandom() {
        return values[rand() % values.size()];
    }
};

替代方案、追问与常见错误

替代方案

  • 计数哈希表：插入删除容易，但无法在不额外维护权重结构的情况下按出现次数 O(1) 随机抽取。
  • 平衡树 / Fenwick 树：可支持带权抽样及更多统计，但操作通常为 O(log n)，超出本题目标。
  • 链表：删除节点可快，但无法 O(1) 按均匀下标随机访问。

面试追问

  • 如果不同值有自定义权重而非按重复次数，该怎样抽样？
  • 如何保证可复现随机序列，便于测试？
  • 若要线程安全，锁的粒度如何设计？
  • 若支持随机删除一个元素，哪些结构可以直接复用？

常见错误

  • 只记录每个值的一个下标，遇到重复元素后丢失其余位置。
  • 删除数组中部时直接移动后续所有元素，退化为 O(n)。
  • 交换末尾元素后忘记同步末尾值的下标集合。
  • 错误处理 val == lastValue，导致集合留下失效下标。
  • insert 返回“插入是否成功”而不是“此前是否不存在”。
  • 按不同值均匀抽取，而不是按数组中的每次出现均匀抽取。
