Longest Increasing Path in a Matrix

题目说明

给定一个 m × n 的整数矩阵 matrix，返回矩阵中最长严格递增路径所包含的单元格数量。

每一步只能从当前单元格移动到上、下、左、右相邻的单元格，并且目标值必须严格大于当前值。不能走对角线、不能越界，也不能从一侧环绕到另一侧。

参数

matrix: integer[][]
一个非空的二维整数矩阵

返回值

integer
最长递增路径的单元格数量

官方示例

Example 01
输入：matrix = [[9,9,4],
                 [6,6,8],
                 [2,1,1]]
输出：4

一条最长路径为 [1, 2, 6, 9]。

Example 02
输入：matrix = [[3,4,5],
                 [3,2,6],
                 [2,2,1]]
输出：4

一条最长路径为 [3, 4, 5, 6]；不能从 3 对角移动到 5。

Example 03
输入：matrix = [[1]]
输出：1

单个单元格本身就是长度为 1 的路径。

约束

  • m == matrix.length
  • n == matrix[i].length
  • 1 <= m, n <= 200
  • 0 <= matrix[i][j] <= 231 - 1

完整题解

核心模型

有向无环图
小值格子 → 相邻大值格子

时间

O(mn)
每个格子和方向只处理常数次

空间

O(mn)
入度数组与拓扑队列

核心洞察

将每个格子视为一个顶点。若相邻格子的值更大，就从当前格子连一条有向边过去。因为沿边移动时数值严格增加，所以不可能沿若干条边回到原点；整个矩阵因此构成一个 DAG。

现在问题变成：DAG 中最长路径包含多少个顶点。先把入度为 0 的局部最小值全部入队，按拓扑排序一层一层处理。第一层能作为长度为 1 的路径终点；第二层能作为长度为 2 的路径终点；依此类推。最终处理的层数就是最长递增路径长度。

完整过程

  1. 为每个格子计算入度：四邻域中有多少个值比它小的格子。
  2. 把所有入度为 0 的格子加入队列；它们是所有递增路径可能的起点。
  3. 按层处理队列。每开始一层，答案加 1。
  4. 从当前格子走向所有更大的邻居，相当于删除这条有向边，并把邻居入度减 1。
  5. 某邻居入度降到 0 时，把它加入下一层队列。
  6. 队列为空时，返回累计层数。

正确性证明

  1. 图一定无环。 每条边都从较小值指向严格较大值。若存在有向环，沿环一周数值必须持续严格增加却又回到起点，矛盾。
  2. 拓扑层数等于以该格子结尾的最长路径长度。 第一层没有更小的前驱，最长路径长度为 1。假设前若干层成立；一个格子进入第 k 层，说明它所有前驱已被处理，并且至少有一个前驱处于第 k - 1 层，否则它会更早入队。因此它能且只能把最长路径扩展到长度 k。
  3. 算法返回全局最优值。 DAG 中每个格子最终都会被拓扑处理；由上一条，最后一层编号等于所有格子结尾路径长度的最大值，也就是矩阵的最长递增路径长度。

边界情况

  • 单格矩阵：唯一格子直接位于第一层，答案为 1。
  • 全部相等：相等值之间没有边，所有格子都在第一层，答案仍为 1。
  • 严格递减或蛇形矩阵：拓扑方向始终由小到大，与输入排列方向无关。
  • 最大整数：算法只比较大小，不做加减数值运算，不会因 2³¹ - 1 溢出。
  • 长链：迭代拓扑法没有递归深度风险。

复杂度

共有 mn 个格子，每个格子只检查四个方向的常数次边，因此时间复杂度为 O(mn)。入度数组与队列最多保存全部格子，空间复杂度为 O(mn)。

替代方案：记忆化 DFS

也可以令 dfs(r, c) 表示从格子 (r, c) 出发的最长递增路径，用记忆化避免重复搜索。它同样是 O(mn) 时间和 O(mn) 空间，写法更直接；但极端长链可能触发部分语言的递归栈限制。拓扑 BFS 是等价的迭代版本。

import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    private static final int[][] DIRS = {
        {1, 0}, {-1, 0}, {0, 1}, {0, -1}
    };

    public int longestIncreasingPath(int[][] matrix) {
        int rows = matrix.length;
        int cols = matrix[0].length;
        int[][] indegree = new int[rows][cols];

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                for (int[] dir : DIRS) {
                    int nr = r + dir[0];
                    int nc = c + dir[1];
                    if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                            && matrix[nr][nc] < matrix[r][c]) {
                        indegree[r][c]++;
                    }
                }
            }
        }

        Queue<int[]> queue = new ArrayDeque<>();
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (indegree[r][c] == 0) {
                    queue.offer(new int[]{r, c});
                }
            }
        }

        int layers = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();
            layers++;
            while (size-- > 0) {
                int[] cell = queue.poll();
                int r = cell[0];
                int c = cell[1];
                for (int[] dir : DIRS) {
                    int nr = r + dir[0];
                    int nc = c + dir[1];
                    if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                            && matrix[nr][nc] > matrix[r][c]
                            && --indegree[nr][nc] == 0) {
                        queue.offer(new int[]{nr, nc});
                    }
                }
            }
        }
        return layers;
    }
}

var longestIncreasingPath = function(matrix) {
    const rows = matrix.length;
    const cols = matrix[0].length;
    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    const indegree = Array.from({ length: rows }, () => Array(cols).fill(0));

    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            for (const [dr, dc] of dirs) {
                const nr = r + dr;
                const nc = c + dc;
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                        && matrix[nr][nc] < matrix[r][c]) {
                    indegree[r][c]++;
                }
            }
        }
    }

    const queue = [];
    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            if (indegree[r][c] === 0) queue.push([r, c]);
        }
    }

    let head = 0;
    let layers = 0;
    while (head < queue.length) {
        const layerEnd = queue.length;
        layers++;
        while (head < layerEnd) {
            const [r, c] = queue[head++];
            for (const [dr, dc] of dirs) {
                const nr = r + dr;
                const nc = c + dc;
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                        && matrix[nr][nc] > matrix[r][c]) {
                    indegree[nr][nc]--;
                    if (indegree[nr][nc] === 0) queue.push([nr, nc]);
                }
            }
        }
    }
    return layers;
};
from collections import deque
from typing import List


class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        rows, cols = len(matrix), len(matrix[0])
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
        indegree = [[0] * cols for _ in range(rows)]

        for r in range(rows):
            for c in range(cols):
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if (0 <= nr < rows and 0 <= nc < cols
                            and matrix[nr][nc] < matrix[r][c]):
                        indegree[r][c] += 1

        queue = deque(
            (r, c)
            for r in range(rows)
            for c in range(cols)
            if indegree[r][c] == 0
        )

        layers = 0
        while queue:
            layers += 1
            for _ in range(len(queue)):
                r, c = queue.popleft()
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if (0 <= nr < rows and 0 <= nc < cols
                            and matrix[nr][nc] > matrix[r][c]):
                        indegree[nr][nc] -= 1
                        if indegree[nr][nc] == 0:
                            queue.append((nr, nc))

        return layers
class Solution {
public:
    int longestIncreasingPath(vector<vector<int>>& matrix) {
        const int rows = matrix.size();
        const int cols = matrix[0].size();
        const int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        vector<vector<int>> indegree(rows, vector<int>(cols, 0));

        for (int r = 0; r < rows; ++r) {
            for (int c = 0; c < cols; ++c) {
                for (const auto& dir : dirs) {
                    int nr = r + dir[0];
                    int nc = c + dir[1];
                    if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                            && matrix[nr][nc] < matrix[r][c]) {
                        ++indegree[r][c];
                    }
                }
            }
        }

        queue<pair<int, int>> cells;
        for (int r = 0; r < rows; ++r) {
            for (int c = 0; c < cols; ++c) {
                if (indegree[r][c] == 0) cells.push({r, c});
            }
        }

        int layers = 0;
        while (!cells.empty()) {
            int size = cells.size();
            ++layers;
            while (size-- > 0) {
                auto [r, c] = cells.front();
                cells.pop();
                for (const auto& dir : dirs) {
                    int nr = r + dir[0];
                    int nc = c + dir[1];
                    if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                            && matrix[nr][nc] > matrix[r][c]
                            && --indegree[nr][nc] == 0) {
                        cells.push({nr, nc});
                    }
                }
            }
        }
        return layers;
    }
};

面试追问

  • 为什么严格递增能保证图中没有环？
  • 如何把拓扑层数与 DP 状态一一对应？
  • 若允许八个方向移动，只需改动哪里？
  • 若要求输出一条具体最长路径，需要额外记录什么？
  • 记忆化 DFS 与拓扑 BFS 在栈安全性上有什么差异？

常见错误

  • 把“严格大于”误写成“大于等于”，导致等值格子产生伪边。
  • 把路径长度当成边数，漏掉起始格子导致少算 1。
  • 处理队列时不固定本层大小，导致多个拓扑层混在一起。
  • 入度方向算反：本题入度来自值更小的邻居。
  • 忘记边界检查，或错误地加入对角线方向。
