一次可交换任意两个不同下标。目标只要求所有 0 位于数组末尾；非零元素之间不必保持原顺序。

Why it is minimum

只数“前缀里多余的 0”

  1. 设数组共有 z 个 0；最终的最后 z 个位置应当全为 0。
  2. 前缀 [0, n-z) 里的每个 0 都必须离开，至少需要一次交换。
  3. 后缀中恰好有同样多的非零数可与它们配对，所以每个错位 0 一次交换即可修正。
因此答案就是目标前缀中值为 0 的元素个数。

核心洞察与完整过程

先统计 0 的数量 z。最终后缀为 [n-z,n)，只扫描前缀；每发现一个 0，答案加一。无需真实交换，因为每个这样的 0 都能和后缀一个非零数配对。

边界与复杂度

没有 0、或 0 已全部在末尾时返回 0。时间 O(n)，额外空间 O(1)。

替代方案 / 面试追问

也可从后缀数非零元素，答案相同。若交换只能相邻进行，则不再能只计数量，需要累计移动距离。

常见错误

  • 误以为必须保持非零数相对顺序。
  • 把所有 0 的数量当成答案。
  • 扫描到整个数组，错误把已在正确后缀的 0 计入。
