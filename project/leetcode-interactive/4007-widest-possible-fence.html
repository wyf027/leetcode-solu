栅栏的最宽宽度

Widest Possible Fence · Array / Hash Table / Counting / Enumeration

Medium

题目

给定整数数组 planks，第 i 块木板高度为 planks[i]，每块宽度均为 1。

建造栅栏时，所有使用的木板必须等高。每块原木板可以直接使用，或者恰好与另一块不同的原木板合并；合并后的高度是两者之和。每块原木板最多用一次，且不必全部使用。

返回能够建造的栅栏的最大宽度。

示例

planks = [1,3,2,5,7,5,4,2,1]，答案为 4：两块高度 5 的原板，加上 1+4 与 3+2。

约束：1 ≤ planks.length ≤ 1000；1 ≤ planks[i] ≤ 10⁹。

思路与实现

核心洞察

固定最终高度 H。先保留所有高度恰为 H 的单板；其余可由互补高度 x 与 H-x 配对。计数表让每一对互补高度只处理一次，因此每块原板不会重复使用。枚举候选高度并取最大值。

完整过程

  1. 统计每个高度出现次数。
  2. 枚举一个可能的最终高度：原板高度与两块原板的和都可能成为候选。
  3. 先放所有等于该高度的单板；对 x < H-x 加上 min(cnt[x], cnt[H-x]) 对；若 H 为偶数，再加 cnt[H/2] / 2。

边界与复杂度

只有一种高度时，单板本身就是答案；同高两板只能两两配对。设不同高度数为 u，计数与枚举候选和的时间为 O(u²)，额外空间为 O(u²)（保存候选宽度）或 O(u)（逐个计算）。

替代方案、面试追问与常见错误

可直接枚举每一对原板的和，适合 n ≤ 1000。若高度范围很小，可改用数组计数。常见错误是把 x 与 H-x 处理两次，或把 H/2 的单板错误地当成可无限配对。

面试可追问：若允许拼接三块木板，应如何扩展状态；若只需一种指定高度，如何在线维护答案。
