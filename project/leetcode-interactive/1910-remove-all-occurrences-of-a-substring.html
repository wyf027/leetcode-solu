Remove All Occurrences of a Substring

删除一个字符串中所有出现的给定子字符串

移走一段字符之后，新相邻的字符会发生什么？

题目

给定 s 和 part，每次删除当前 s 中最靠左的一段连续子串 part，并连接两侧剩余字符。重复这一操作，直到 s 不再包含 part，返回剩余字符串。

参数形式：removeOccurrences(s: string, part: string) → string

约束

  • 1 ≤ s.length ≤ 1000
  • 1 ≤ part.length ≤ 1000
  • 两个字符串均只包含小写英文字母。

官方示例 1

s = "daabcbaabcbc", part = "abc"
输出："dab"
删除起始下标（从 0 开始）：2 → 4 → 3
daabcbaabcbc → dabaabcbc → dababc → dab

官方示例 2

s = "axxxxyyyyb", part = "xy"
输出："ab"
删除起始下标（从 0 开始）：4 → 3 → 2 → 1
axxxxyyyyb → axxxyyyb → axxyyb → axyb → ab

题解 · 字符栈的末端消除

核心洞察与完整过程

从左到右读 s，用栈保存处理好的前缀。每压入一个字符，只检查最后 m = part.length 个字符；如果与 part 相同，就弹出这 m 个字符。最后连接栈中字符。

  1. 空栈开始。
  2. 读取并压入一个字符。
  3. 栈长不少于 m 时，逐个比较后缀字符。
  4. 完整匹配则删除后缀；继续读取，直到输入结束。

交互 · 字符传送带

青色为刚读入的字符，黄色为即将删除的后缀。压入与删除分别占一步。修改后点“重置”应用。

输入 · 灰色为已读

字符栈 · 右侧是栈顶

正确性

不变式：每轮结束，栈是已读前缀按最左优先删除后的结果，且不含 part。初始空栈满足。追加字符后，新匹配必须以该字符结尾，所以只能是后缀；旧栈没有匹配，这个后缀就是当前最左匹配。删除后剩下的是旧栈的前缀，仍不含 part，故一轮不需要反复删除。后续输入可能在删除边界形成新匹配，之后的后缀比较会捕获它。由归纳法，读完后的栈就是答案。

边界

part 更长则不删除；完全相同则结果为空；m = 1 时逐个移除相同字符。重叠匹配必须遵守最左优先，例如 ababa 删除 aba 得到 ba。

复杂度

n 为 s 长度，m 为 part 长度。每次压栈最多比较 m 个字符，时间 O(nm)，辅助空间 O(n)。四份代码直接比较后缀字符。交互演示为支持回退保存快照，最坏 O(n²) 空间，与提交算法不同。

替代方案

反复查找最左匹配并切片删除，代码直观，但需要重复扫描、搬移字符。进阶可使用 KMP 前缀函数，并为栈中每个位置记录匹配长度；弹栈后恢复匹配状态，实现 O(n + m) 时间、O(n + m) 空间。

常见错误

  • 只替换一次：删除后可能产生新匹配。
  • 从右边任意删除：重叠时结果可能不同。
  • 栈长度不足时比较，导致越界。
  • 忽略后缀比较，误把普通栈算法写成 O(n)。

面试追问

如何线性化？KMP 删除后为什么必须恢复之前的匹配状态？如果允许空 part，语义应该如何定义？多个模式的删除优先级应如何规定？

四语言完整提交代码

Java

class Solution {
    public String removeOccurrences(String s, String part) {
        char[] stack = new char[s.length()];
        int top = 0, m = part.length();
        for (char c : s.toCharArray()) {
            stack[top++] = c;
            if (top < m) continue;
            int j = 0;
            while (j < m && stack[top - m + j] == part.charAt(j)) j++;
            if (j == m) top -= m;
        }
        return new String(stack, 0, top);
    }
}

JavaScript

/** @param {string} s
 * @param {string} part
 * @return {string} */
var removeOccurrences = function(s, part) {
    const stack = [], m = part.length;
    for (const c of s) {
        stack.push(c);
        if (stack.length < m) continue;
        let j = 0;
        while (j < m && stack[stack.length - m + j] === part[j]) j++;
        if (j === m) stack.length -= m;
    }
    return stack.join('');
};

Python

class Solution:
    def removeOccurrences(self, s: str, part: str) -> str:
        stack = []
        m = len(part)
        for c in s:
            stack.append(c)
            if len(stack) < m:
                continue
            j = 0
            while j < m and stack[len(stack) - m + j] == part[j]:
                j += 1
            if j == m:
                del stack[-m:]
        return ''.join(stack)

C++

#include <string>
using namespace std;
class Solution {
public:
    string removeOccurrences(string s, string part) {
        string stack;
        int m = part.size();
        for (char c : s) {
            stack.push_back(c);
            if (stack.size() < part.size()) continue;
            int j = 0;
            while (j < m && stack[stack.size() - m + j] == part[j]) ++j;
            if (j == m) stack.resize(stack.size() - m);
        }
        return stack;
    }
};
