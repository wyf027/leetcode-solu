增量偶权环查询

每条新边只需验证两个端点在已有连通块中的 异或势能，无需枚举任何环。

题意

初始是 n 个孤立点。按顺序考察 edges[i] = [u, v, w]（w 是 0 或 1）。只有在加入后 所有环的权重和均为偶数时，才真正加入该边；返回成功加入的数量。

示例 1：n = 3, edges = [[0,1,1],[1,2,1],[0,2,1]]，最后一条闭成权和 3 的奇环，答案为 2。

关键等价

把边权当作二进制位。一个环的权和为偶数，等价于环上边权的 XOR 为 0。对每个连通块维护 xorToRoot[x]：从 x 到根路径的 XOR。

已连通时可加 ⇔ xorToRoot[u] XOR xorToRoot[v] XOR w = 0

题解

默认收起，避免首屏直接展示解法和代码。

带 XOR 势能的并查集

  1. find(x) 路径压缩时，同步累计 x 到代表元的 XOR。
  2. 若 u、v 属于同一集合，新增边只会新产生若干环；全部满足偶权，当且仅当 xu XOR xv XOR w = 0。
  3. 若不连通，加入边不会产生环，必定可加。把一棵根挂到另一棵根，并设置两根之间的势能为 xu XOR xv XOR w。

复杂度：每次查询/合并均摊 O(α(n))，总时间 O((n + m) α(n))，空间 O(n)。

替代方案与常见错误

  • 逐次 DFS 找路径可做，但最坏会退化到 O(m(n+m))。
  • 不要把“权和偶数”误写成“边数偶数”；这里需要的是权值 XOR。
  • 路径压缩后必须更新势能，否则根已变化而 XOR 仍指向旧父节点。

面试追问

若权重改为任意整数并要求每个环的和模 k 为 0，只要把 XOR 势能替换成模 k 的加法势能即可。
