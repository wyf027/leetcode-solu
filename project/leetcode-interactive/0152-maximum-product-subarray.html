乘积最大子数组 符号翻转仪

负数会让最大值与最小值交换身份；同时保留两条状态轨道，才能捕捉下一次符号翻转后的最优答案。

任务边界

输入整数数组 nums，长度 1～2×10⁴、元素范围 -10～10；返回非空连续子数组的最大乘积。

Problem / 题意

连续子数组的乘积，需要记住两个极值

给定整数数组 nums，找出乘积最大的非空连续子数组，并返回该乘积。每一步既可以从当前元素重新开始，也可以把当前元素接到此前的最大或最小乘积之后。

官方示例 1
nums = [2,3,-2,4]

期望输出：6

官方示例 2
nums = [-2,0,-1]

期望输出：0

关键边界
nums = [-2,3,-4]

期望输出：24

核心洞察

最大值与最小值必须成对维护

乘以正数时大小关系不变，乘以负数时大小关系反转。因此上一轮最小乘积可能因负号翻身成为新最大值；每个位置都要同时比较“当前元素、旧最大值×当前元素、旧最小值×当前元素”。

完整过程

  1. 用首元素初始化 maxHere、minHere 与 answer。
  2. 保存上一轮两个极值，避免更新顺序污染。
  3. 用当前元素计算三种候选值。
  4. 更新局部最大、局部最小，再更新全局答案。

边界与复杂度

  • 单元素数组直接返回该元素，包括负数。
  • 零会切断乘积链，也可能成为当前最优答案。
  • 时间 O(n)，额外空间 O(1)。

替代方案取舍

可分别计算从左、从右的前缀乘积，并在遇零时重启，代码也能做到 O(n)；双状态 DP 更直接表达“负数交换极值”的因果关系。

常见错误

  • 只维护最大乘积，漏掉负负得正。
  • 先更新 maxHere，再用新值计算 minHere。
  • 把零一律忽略，错过答案为零或状态重启。
  • 把问题误写成允许跳跃的非连续子序列。

面试追问

为什么保存旧状态？两个新状态都依赖同一轮的旧极值。
负数出现时为何交换？乘负数会反转数轴上的大小关系。
如何返回具体区间？在“从当前元素重启”时同步记录起点。 
class Solution {
    public int maxProduct(int[] nums) {
        int maxHere = nums[0], minHere = nums[0], answer = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int previousMax = maxHere, previousMin = minHere;
            maxHere = Math.max(nums[i],
                Math.max(previousMax * nums[i], previousMin * nums[i]));
            minHere = Math.min(nums[i],
                Math.min(previousMax * nums[i], previousMin * nums[i]));
            answer = Math.max(answer, maxHere);
        }
        return answer;
    }
}
