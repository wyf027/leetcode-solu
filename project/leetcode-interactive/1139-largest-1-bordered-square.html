01 · 题目

要找的是面积，不是边长

题意转述

给定一个只包含 0 和 1 的二维网格 grid。请选出一个正方形子网格，使它的上、下、左、右四条边上的每个元素都是 1。

返回最大合法正方形包含的元素数量，也就是它的面积。内部不要求全为 1；如果不存在任何合法正方形，则返回 0。

注意：一个值为 1 的单元格本身就是边长为 1、面积为 1 的合法正方形。

约束

  • 1 <= grid.length <= 100
  • 1 <= grid[0].length <= 100
  • grid[i][j] 为 0 或 1

示例 1

输入
grid = [[1,1,1],[1,0,1],[1,1,1]]
输出
9
说明
整个 3 × 3 网格的四条边都是 1。

示例 2

输入
grid = [[1,1,0,0]]
输出
1
说明
可以选择一个值为 1 的单元格。

Solution · Directional DP

方向计数 + 枚举边长

把“检查一整条边”压缩成一次数组查询，再从较大的候选正方形开始尝试。

核心洞察完整过程正确性复杂度代码面试追问

核心洞察

若为每个候选逐格检查四边，会重复扫描大量元素。预处理两个表可将一次边界判断压缩为常数时间：

  • right[i][j]：从 (i,j) 向右连续为 1 的格子数。
  • down[i][j]：从 (i,j) 向下连续为 1 的格子数。

以 (i,j) 为左上角、边长为 k 时，四个读数都至少为 k，四条边才全部为 1：

right[i][j] ≥ k // 上边 down[i][j] ≥ k // 左边 right[i+k-1][j] ≥ k // 下边 down[i][j+k-1] ≥ k // 右边

完整过程

  1. 创建与网格同尺寸的 right 和 down，初值为 0。
  2. 从右下向左上遍历；遇到 1 时，用右侧和下方已完成的状态递推。
  3. 枚举每个位置作为左上角，候选最大边长由剩余行数与列数的较小值决定。
  4. 只尝试比当前最好答案更大的边长，并从大到小用四次表查询检查四边。
  5. 某个左上角找到合法边长后更新答案，并跳过其更小候选。
  6. 返回最大边长的平方。
遍历方向：当前位置依赖右邻格与下邻格，因此必须从右下向左上预处理。

正确性证明

  1. 方向表正确。 值为 0 时计数为 0；值为 1 时，当前计数等于 1 加对应相邻位置的计数。按右下到左上的顺序，依赖项已经正确，因此所有方向计数正确。
  2. 四边判断充要。 上、左、下、右四条边分别从左上、左上、左下、右上端点向右或向下延伸。四个方向计数均不少于边长，恰好等价于四条边全为 1。
  3. 不会遗漏最优解。 每个左上角及其所有可能超过当前答案的边长都被检查。任何更大的合法正方形都会在对应枚举中通过判断并更新答案。
  4. 返回面积正确。 循环结束后保存所有合法正方形中的最大边长，平方即元素数量；若不存在合法正方形，边长保持 0。

复杂度与边界

O(mn · min(m,n))最坏时间复杂度；O(mn) 预处理后枚举候选边长。
O(mn)两个方向计数表的额外空间。
  • 单行或单列：存在 1 时答案为 1，否则为 0。
  • 全为 0：计数表保持为 0，答案自然为 0。
  • 内部含 0：不影响合法性，只检查四边。
  • 矩形网格：候选边长同时受剩余行数与列数限制。

替代方案

行列前缀和

分别建立每行、每列前缀和，也能 O(1) 判断一条边是否全为 1。枚举复杂度不变，但区间下标更容易写错。

朴素逐边扫描

每个候选逐格检查四边，单次 O(k)，最坏达到 O(mn · min(m,n)²)，不适合本题上界。

JavaScript 
/**
 * @param {number[][]} grid
 * @return {number}
 */
var largest1BorderedSquare = function(grid) {
    const m = grid.length, n = grid[0].length;
    const right = Array.from({ length: m }, () => Array(n).fill(0));
    const down = Array.from({ length: m }, () => Array(n).fill(0));

    for (let i = m - 1; i >= 0; i--) {
        for (let j = n - 1; j >= 0; j--) {
            if (grid[i][j] === 1) {
                right[i][j] = 1 + (j + 1 < n ? right[i][j + 1] : 0);
                down[i][j] = 1 + (i + 1 < m ? down[i + 1][j] : 0);
            }
        }
    }

    let best = 0;
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            const limit = Math.min(m - i, n - j);
            for (let size = limit; size > best; size--) {
                const bottom = i + size - 1;
                const rightCol = j + size - 1;
                if (right[i][j] >= size && down[i][j] >= size &&
                    right[bottom][j] >= size && down[i][rightCol] >= size) {
                    best = size;
                    break;
                }
            }
        }
    }
    return best * best;
};

Python 
from typing import List


class Solution:
    def largest1BorderedSquare(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        right = [[0] * n for _ in range(m)]
        down = [[0] * n for _ in range(m)]

        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                if grid[i][j] == 1:
                    right[i][j] = 1 + (right[i][j + 1] if j + 1 < n else 0)
                    down[i][j] = 1 + (down[i + 1][j] if i + 1 < m else 0)

        best = 0
        for i in range(m):
            for j in range(n):
                limit = min(m - i, n - j)
                for size in range(limit, best, -1):
                    bottom = i + size - 1
                    right_col = j + size - 1
                    if (right[i][j] >= size and down[i][j] >= size and
                            right[bottom][j] >= size and
                            down[i][right_col] >= size):
                        best = size
                        break
        return best * best

class Solution {
public:
    int largest1BorderedSquare(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<vector<int>> right(m, vector<int>(n));
        vector<vector<int>> down(m, vector<int>(n));

        for (int i = m - 1; i >= 0; --i) {
            for (int j = n - 1; j >= 0; --j) {
                if (grid[i][j] == 1) {
                    right[i][j] = 1 + (j + 1 < n ? right[i][j + 1] : 0);
                    down[i][j] = 1 + (i + 1 < m ? down[i + 1][j] : 0);
                }
            }
        }

        int best = 0;
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                int limit = min(m - i, n - j);
                for (int size = limit; size > best; --size) {
                    int bottom = i + size - 1;
                    int rightCol = j + size - 1;
                    if (right[i][j] >= size && down[i][j] >= size &&
                        right[bottom][j] >= size && down[i][rightCol] >= size) {
                        best = size;
                        break;
                    }
                }
            }
        }
        return best * best;
    }
};

常见错误

  • 误把“边界全为 1”理解为“整个正方形全为 1”。
  • 返回边长而不是面积 best * best。
  • 用错误方向表检查右边或下边。
  • 预处理顺序错误，依赖状态尚未生成。
  • 下边或右边坐标忘记减 1。
