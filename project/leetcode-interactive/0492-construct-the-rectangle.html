03 / SOLUTION

准备核对你的思路？

题解包含推导、证明、复杂度、四种语言实现与面试扩展。展开前，建议先在制图台走到一次命中状态。

核心洞察

满足 L × W = area 且 L ≥ W 时，W 不会超过 √area。因数对越接近平方根，两边差越小。因此，从 ⌊√area⌋ 开始向下找，第一个能整除 area 的 W，就是最优宽度；随后令 L = area / W。

完整过程

  1. 令 W = ⌊√area⌋。
  2. 若 area % W ≠ 0，将 W 减 1 后继续。
  3. 首次满足整除时，计算 L = area / W。
  4. 返回 [L, W]。

正确性证明

算法只在 W 整除 area 时返回，所以 L = area / W 为整数且 L × W = area。由于搜索起点不超过平方根，得到的因数满足 W ≤ √area ≤ L。对固定乘积，当较小因数 W 增大并趋近平方根时，L - W = area / W - W 严格减小。算法按宽度从大到小搜索，首次找到的因数是所有不超过平方根的因数中最大的，因此对应边长差最小。

边界与复杂度

边界：area = 1 时直接命中 [1,1]；完全平方数会在起点命中；质数最终在 W = 1 命中。
时间：最坏 O(√area)。
空间：O(1)。

替代方案

也可以从 W = 1 枚举到 √area，每次遇到因数就更新答案。它同样是 O(√area) 时间、O(1) 空间，但需要保存最近一次命中的因数；从平方根向下搜索能在首次命中时立刻返回，表达更直接。

常见错误

  • 从 area 向下枚举，最坏退化为 O(area)。
  • 返回顺序写成 [W, L]，违反长在前的契约。
  • 用浮点除法判断整数，产生不必要的精度风险。
  • 只检查平方根，没有继续寻找更小的因数。

四语言完整实现

Java官方可提交签名
class Solution {
    public int[] constructRectangle(int area) {
        int width = (int) Math.sqrt(area);
        while (area % width != 0) {
            width--;
        }
        return new int[] {area / width, width};
    }
}
JavaScript官方可提交签名
/**
 * @param {number} area
 * @return {number[]}
 */
var constructRectangle = function(area) {
    let width = Math.floor(Math.sqrt(area));
    while (area % width !== 0) {
        width--;
    }
    return [area / width, width];
};
Python 3官方可提交签名
from math import isqrt
from typing import List

class Solution:
    def constructRectangle(self, area: int) -> List[int]:
        width = isqrt(area)
        while area % width != 0:
            width -= 1
        return [area // width, width]
C++官方可提交签名
class Solution {
public:
    vector<int> constructRectangle(int area) {
        int width = static_cast<int>(sqrt(area));
        while (area % width != 0) {
            --width;
        }
        return {area / width, width};
    }
};

面试追问

为什么从平方根开始？

每个较小因数都与一个较大因数成对；最接近平方根的因数对拥有最小边长差。

能否完全避免浮点数？

Python 可用 isqrt。其他语言也可实现整数平方根；本题上限仅 10⁷，标准平方根转换足够安全。

如果要求周长最小呢？

固定面积下，最接近正方形的整数因数对同样使 2(L + W) 最小，搜索策略不变。

如果允许实数边长呢？

最优解恒为正方形：L = W = √area；整数约束才引出了因数搜索。
