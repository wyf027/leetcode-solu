题意

顺时针旋转

给定长度为 n 的整数数组 nums。令 arrk 表示把 nums 顺时针旋转 k 个位置后得到的数组，并定义：

F(k) = 0 × arrk[0] + 1 × arrk[1] + … + (n − 1) × arrk[n − 1]

返回 F(0), F(1), …, F(n − 1) 中的最大值。测试数据保证答案可由 32 位整数表示。

示例 1

输入：nums = [4,3,2,6]
输出：26
解释：
F(0) = 0×4 + 1×3 + 2×2 + 3×6 = 25
F(1) = 0×6 + 1×4 + 2×3 + 3×2 = 16
F(2) = 0×2 + 1×6 + 2×4 + 3×3 = 23
F(3) = 0×3 + 1×2 + 2×6 + 3×4 = 26
最大值为 F(3) = 26。

示例 2

输入：nums = [100]
输出：0

约束

  • n == nums.length
  • 1 ≤ n ≤ 105
  • −100 ≤ nums[i] ≤ 100

SOLUTION

一次初值 + 一条递推式

核心洞察

若每次都把数组真的旋转并重新加权，n 次旋转各花 O(n)，总计会达到 O(n²)。真正有用的信息是相邻两个旋转函数值之间的差。

F(k) = F(k − 1) + S − n × nums[n − k]

其中 S 是原数组所有元素之和。顺时针旋转时，nums[n-k] 从最后一个权重位置移到索引 0：其权重一次减少 n−1；其余元素权重都增加 1。合并这些变化，就得到上式。

用示例快速代入

nums = [4,3,2,6]，S = 15，F(0) = 25

  • F(1) = 25 + 15 − 4×6 = 16
  • F(2) = 16 + 15 − 4×2 = 23
  • F(3) = 23 + 15 − 4×3 = 26

完整过程

同时计算 S 与 F(0)
一次遍历中累加 nums[i] 与 i × nums[i]。
枚举 k = 1 … n−1
用递推式从前一个函数值在 O(1) 时间得到当前值。
持续更新最大值
无需保存所有旋转数组或所有 F(k)。
返回答案
共线性扫描两轮量级，额外空间为常数。

正确性证明

引理：对每个 1 ≤ k < n，递推式都能从 F(k−1) 正确得到 F(k)。

从 arrk−1 顺时针旋转一格时，原本位于末尾的元素 x = nums[n−k] 移到索引 0，它的贡献变化为 −(n−1)x；其余元素索引都加 1，贡献总共增加 S−x。总变化为 S−x−(n−1)x = S−nx，故递推式成立。

结论：算法直接算出正确的 F(0)，再由引理依次得到全部 F(k)，并取其中最大值，因此返回值正确。

复杂度与边界

  • 时间：O(n)
  • 额外空间：O(1)
  • n = 1 时仅有 F(0) = 0。
  • 数组可包含负数，因此答案初值必须是 F(0)，不能武断设为 0。
  • 题目保证最终答案是 32 位整数；Java 中间计算使用 long、C++ 使用 long long 更稳妥。

四语言完整代码

Java
class Solution {
    public int maxRotateFunction(int[] nums) {
        int n = nums.length;
        long sum = 0;
        long current = 0;

        for (int i = 0; i < n; i++) {
            sum += nums[i];
            current += (long) i * nums[i];
        }

        long best = current;
        for (int k = 1; k < n; k++) {
            current = current + sum - (long) n * nums[n - k];
            best = Math.max(best, current);
        }
        return (int) best;
    }
}

Python 3
from typing import List


class Solution:
    def maxRotateFunction(self, nums: List[int]) -> int:
        n = len(nums)
        total = sum(nums)
        current = sum(i * value for i, value in enumerate(nums))
        best = current

        for k in range(1, n):
            current = current + total - n * nums[n - k]
            best = max(best, current)

        return best
C++
class Solution {
public:
    int maxRotateFunction(vector<int>& nums) {
        const int n = static_cast<int>(nums.size());
        long long sum = 0;
        long long current = 0;

        for (int i = 0; i < n; ++i) {
            sum += nums[i];
            current += 1LL * i * nums[i];
        }

        long long best = current;
        for (int k = 1; k < n; ++k) {
            current = current + sum - 1LL * n * nums[n - k];
            best = max(best, current);
        }
        return static_cast<int>(best);
    }
};

替代方案

暴力模拟：每次旋转后重新计算加权和，时间 O(n²)；仅适合帮助理解或作为小规模基准。

构造双倍数组：可更方便地表示所有旋转，但若每个窗口仍逐项加权，无法突破平方复杂度；本题并不需要额外数组。

  • 若权重不是连续的 0…n−1，还能否 O(1) 更新？
  • 如何用暴力实现对拍验证递推式？

常见错误

  • 把顺时针旋转的移出元素写成 nums[k]。
  • 漏掉乘数 n，写成 S−x。
  • 最大值初始化为 0，导致全负权重和场景出错。
  • 真实旋转数组，徒增时间或空间开销。
  • 循环写到 k ≤ n，重复计算 F(0)。
