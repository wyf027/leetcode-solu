新增的最少台阶数

Add Minimum Number of Rungs

从地面出发，每一步都有高度限制。怎样用尽可能少的新台阶抵达顶端？

先读题、观察间隔；需要推导时，再展开页底题解。

01 / 题目

严格递增的整数数组 rungs 记录梯子上已有台阶的高度。你从高度 0 的地面开始，每次只能向上走到与当前位置高度差不超过 dist 的下一台阶。允许在尚无台阶的任意正整数高度添加台阶。求到达最后一个已有台阶所需添加的最少台阶数。

参数与返回值

  • rungs: integer[]：已有台阶高度。
  • dist: integer：一次可跨越的最大高度差。
  • 返回 integer：最少新增数量。

约束

  • 1 ≤ rungs.length ≤ 10⁵
  • 1 ≤ rungs[i] ≤ 10⁹
  • 1 ≤ dist ≤ 10⁹
  • rungs 严格递增。

05 / 独立题解

准备好后，再看公式、证明与实现。

核心洞察：一段间隔是一道独立的小题

将地面视作高度 0 的虚拟台阶。对于一段高度差 gap = current − prev，插入 k 个台阶后，它被分为 k + 1 段。每段最多为 dist，因此至少需要 ceil(gap / dist) − 1 个新台阶。

每段最少新增 = floor((gap - 1) / dist)
总答案 = 所有原始相邻间隔（含地面到首阶）的贡献之和

整数高度下，两种写法等价。先减 1 再整除，恰好避免整倍数时把现有终点也当作新台阶。例如 gap = 6、dist = 3，只需新增高度 3，不应再新增终点 6。

完整过程

  1. 令 prev = 0、answer = 0。
  2. 从低到高遍历每个已有台阶 current。
  3. 将 floor((current − prev − 1) / dist) 累加到答案。
  4. 更新 prev = current；遍历结束返回答案。

示例 1 的间隔依次为 1、2、2、5，新增贡献为 0、0、0、2，总数为 2。可以在 7、9 放置新台阶；官方示例选用 7、8，同样最优。示例 3 中演示选择高度 2，官方选择高度 1，数量均为 1。

为什么一定最少？

下界：任意方案在 gap 内插入 k 阶，都必须满足 gap ≤ (k + 1) × dist，所以 k 不可能小于 ceil(gap / dist) − 1。

可达：取 k = floor((gap − 1) / dist)，在 prev + dist, prev + 2 × dist, …, prev + k × dist 放置新台阶。这些位置严格位于两端之间且都是整数。前 k 次攀爬长度均为 dist，最后剩余长度在 [1, dist] 内，故达到下界。

整体：每个原台阶间隔内部互不重叠，必须分别被跨越；一段内的新台阶不能填补另一段缺口。各段的下界相加是全局下界，各段构造合并后又可行，因此求和就是全局最优。

边界与复杂度

  • 首阶也要处理：起点是 0，不是 rungs[0]。
  • gap ≤ dist 时贡献为 0；gap 为 dist 整倍数时尤其要减 1。
  • 只有一个原台阶时仍使用相同公式。题目不允许空数组、重复高度、dist = 0。
  • 时间 O(n)，额外空间 O(1)，无需真的插入台阶，也无需排序。
  • 新增总数最多为 rungs[n−1] − n，不超过 999,999,999；本题范围内 Java / C++ 的 int 足够，JavaScript Number 可精确处理这些整数。

替代方案

逐个在当前可达的最高位置补阶也正确，但耗时 O(n + A)，其中 A 是新增总数；单段可需要近 10⁹ 次操作。除法把这一段重复过程一次算完。二分答案或动态规划在这里没有必要；可以直接对每段计算最少数量。

Java

class Solution {
    public int addRungs(int[] rungs, int dist) {
        int answer = 0;
        int prev = 0;
        for (int current : rungs) {
            answer += (current - prev - 1) / dist;
            prev = current;
        }
        return answer;
    }
}

常见错误

  • 写成 gap / dist：整倍数时多算 1。
  • 写成 floor(gap / dist) − 1：非整倍数时少算，甚至出现负数。
  • 从第二个台阶才开始：遗漏地面到首阶。
  • JavaScript 不取整、Python 使用 /：得到小数贡献。
  • 按新台阶逐个循环或真的修改数组：答案很大时无法及时完成。

面试追问

  • 如果还要输出新增位置？ 每段按 dist 向上放置直到终点之前；需要 O(A) 输出空间和时间，可用迭代器逐个产出。
  • 输入未排序怎么办？ 若扩展题意允许任意顺序，先排序并处理重复；会引入 O(n log n) 时间。
  • 如果某些高度禁止添加？ 等分构造不再保证可行，需依据合法位置集合重新分析。
  • 高度上限扩大怎么办？ Java / C++ 使用更宽整数；超过 JavaScript 安全整数范围时改用 BigInt，并全程保持整数运算。
