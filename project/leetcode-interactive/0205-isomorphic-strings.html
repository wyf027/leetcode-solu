205. 同构字符串 Easy

用两张“映射许可证”检查替换规则：既要保证同一个源字符始终去往同一个目标字符，也要保证没有两个源字符抢占同一个目标。

?题意

给定等长字符串 s 与 t，判断能否把 s 的每一种字符统一替换成某种字符，从而得到 t。替换必须保持字符顺序；不同源字符不能映射到同一目标字符；字符可以映射给自己。

官方样例 1

s = "egg"
t = "add"
输出：true

官方样例 2

s = "f11"
t = "b23"
输出：false

官方样例 3

s = "paper"
t = "title"
输出：true

约束：1 ≤ s.length ≤ 5 × 10⁴；t.length == s.length；两串由任意有效 ASCII 字符组成。字符串中的空格在本页写作 ␠，表示一个真实空格。

λ题解：两张方向相反的映射表

核心洞察

走到第 i 位时，检查 s[i] → t[i] 是否已被登记且一致；再检查反向 t[i] → s[i] 是否也一致。双向都通过，才不会发生“同一个源改去不同目标”或“两个源挤到同一目标”。

主线：哈希表双向约束。ASCII 条件下也可用两个长度 256 的数组，空间更小但表达力不如 Map 清楚。

完整过程

  1. 创建 forward 与 backward。
  2. 逐位读入 a = s[i]、b = t[i]。
  3. 若已有 forward[a] 且不等于 b，返回 false。
  4. 若已有 backward[b] 且不等于 a，返回 false。
  5. 登记两个方向；循环结束返回 true。

边界与复杂度

  • s = "a"、t = "a"：允许自映射。
  • s = "ab"、t = "aa"：反向映射冲突。
  • 长度不等：直接 false（虽然本题约束等长）。

时间：O(n)；空间：O(k)，k 为不同字符数，ASCII 下 k ≤ 128。

替代方案、追问与常见错误

替代：可比较“每个字符第一次出现的位置”序列，时间 O(n)、可省去两张表，但可读性更绕。
追问：若字符集扩大到 Unicode？仍用 Map；若需要输出替换字典？保留 forward 即可。
错误：只检查 forward，会漏掉 "ab" → "aa"；用 map.get() 的真假判断时，别把合法空值与不存在混淆。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isIsomorphic(String s, String t) {
        if (s.length() != t.length()) return false;
        Map<Character, Character> forward = new HashMap<>();
        Map<Character, Character> backward = new HashMap<>();
        for (int i = 0; i < s.length(); i++) {
            char a = s.charAt(i), b = t.charAt(i);
            if ((forward.containsKey(a) && forward.get(a) != b)
                    || (backward.containsKey(b) && backward.get(b) != a)) return false;
            forward.put(a, b); backward.put(b, a);
        }
        return true;
    }
}

class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        forward, backward = {}, {}
        for a, b in zip(s, t):
            if (a in forward and forward[a] != b) or (b in backward and backward[b] != a):

            forward[a] = b
            backward[b] = a
        return True
