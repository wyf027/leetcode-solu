Solution vault

准备好揭开完整思路了吗？

题解与代码默认收起。建议先在上方推进几步，再检查自己的推理。

核心洞察

对固定正整数 n，因数对越靠近 √n，两数之差越小。因此分别从 ⌊√(num+1)⌋、⌊√(num+2)⌋ 向下寻找第一个可整除的数，就能得到两个候选数各自最接近的因数对；最后比较绝对差。

边界处理

  • num 最小为 1：候选数 2 与 3 都能正常扫描到因数 1。
  • num 最大为 10⁹：平方根约 31623，整数运算安全落在 32 位有符号范围内。
  • 若两组因数差相同，返回任意一组都满足题意。

完整过程

  1. 令 n₁ = num + 1，n₂ = num + 2。
  2. 对每个 n，从 ⌊√n⌋ 开始递减 d；首次满足 n mod d = 0 时，记录 [d, n / d]。
  3. 分别得到 pair₁ 与 pair₂，计算每对因数的绝对差。
  4. 返回差更小的因数对；相等时任取一对。

正确性说明

引理：设 d ≤ √n 且 d 是 n 的因数，则对应因数为 n/d ≥ √n。在区间 (0, √n] 内，函数 n/d − d 随 d 增大而严格减小。因此，最大的、不超过 √n 的因数会产生 n 的最小因数差。

结论：向下扫描遇到的第一个因数正是该范围内最大的因数，所以辅助过程为每个候选数找到最接近的因数对。最终比较 n₁ 与 n₂ 的两组最优差，返回较小者，故返回值满足全局最优。

时间 O(√num)空间 O(1)

Solution.java官方可提交
class Solution {
    public int[] closestDivisors(int num) {
        int[] first = closestPair(num + 1);
        int[] second = closestPair(num + 2);
        return first[1] - first[0] <= second[1] - second[0]
                ? first : second;
    }

    private int[] closestPair(int value) {
        int divisor = (int) Math.sqrt(value);
        while (value % divisor != 0) {
            divisor--;
        }
        return new int[] { divisor, value / divisor };
    }
}

/**
 * @param {number} num

var closestDivisors = function(num) {
    const closestPair = (value) => {
        let divisor = Math.floor(Math.sqrt(value));
        while (value % divisor !== 0) {
            divisor--;
        }
        return [divisor, value / divisor];
    };

    const first = closestPair(num + 1);
    const second = closestPair(num + 2);
    return first[1] - first[0] <= second[1] - second[0]
        ? first
        : second;
};

from math import isqrt
from typing import List


class Solution:
    def closestDivisors(self, num: int) -> List[int]:
        def closest_pair(value: int) -> List[int]:
            divisor = isqrt(value)
            while value % divisor != 0:
                divisor -= 1
            return [divisor, value // divisor]

        first = closest_pair(num + 1)
        second = closest_pair(num + 2)
        if first[1] - first[0] <= second[1] - second[0]:
            return first
        return second
solution.cpp官方可提交
class Solution {
public:
    vector<int> closestDivisors(int num) {
        vector<int> first = closestPair(num + 1);
        vector<int> second = closestPair(num + 2);
        return first[1] - first[0] <= second[1] - second[0]
            ? first
            : second;
    }

private:
    vector<int> closestPair(int value) {
        int divisor = static_cast<int>(sqrt(value));
        while (value % divisor != 0) {
            --divisor;
        }
        return {divisor, value / divisor};
    }
};

替代方案

可以从 1 枚举到 √n，保存最后一组因数；也可以使用同一个下标同时检查 num+1 与 num+2。前者同样正确但更新次数更多；后者更短，却不如分别求解再比较直观。

面试追问

如果候选范围变为 num+1 到 num+k 怎么办？可对每个候选数求最近因数对后统一比较，复杂度 O(k√num)；当 k 很大时，再考虑筛法或批量分解。

常见错误

  • 只检查 num+1，遗漏 num+2 可能产生更小的因数差。
  • 从 1 向上找到第一个因数就停止；那通常是最远的一对。
  • 用浮点平方根直接当作因数，却没有继续检查整除性。
  • 比较两组答案时忘记取绝对差，或混淆因数的大小顺序。
