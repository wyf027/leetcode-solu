01 · Problem

登机规则

有 n 位乘客登上一架恰好有 n 个座位的飞机，每位乘客都有与自己编号相同的座位。第一位乘客丢失了机票，因此会从全部座位中等概率随机选择一个。

  • 1从第二位乘客开始，如果自己的座位仍空着，就直接坐到自己的座位。
  • 2如果自己的座位已经被占用，就从当前所有空座位中等概率随机选择一个。

任务：返回第 n 位乘客最终坐到自己座位的概率。

05 · Solution

真正重要的，只有两个座位

核心洞察当连锁冲突尚未结束时，空座集合里最关键的始终是座位 1 与座位 n。被迫随机选座的乘客一旦选中 1，后续每个人都能坐回自己的座位；一旦选中 n，第 n 位乘客就失败。其他选择只会把“被迫选择的人”转交给更后面的某位乘客。
P(n) = 1，n = 1
P(n) = 1/2，n ≥ 2

完整过程

  1. 第一位乘客从 n 个座位中等概率选择。选到座位 1，流程立刻进入成功结局；选到座位 n，流程立刻进入失败结局。
  2. 若第一位乘客选到中间座位 k（1 < k < n），第 2 到 k−1 位乘客照常就座，直到第 k 位发现自己的座位被占。
  3. 此时第 k 位从剩余空座中随机选择。状态与开局完全同构：座位 1、座位 n 仍空着，其余可选的中间座位只是继续传递冲突。
  4. 不断消去中间选择，过程最终必然先碰到座位 1 或座位 n。两者在每个同构状态中地位对称，因此先碰到它们的概率各为 1/2。

正确性证明

引理：在任意尚未终止的冲突状态中，座位 1 和座位 n 都空着，且当前被占座的乘客从包含这两个座位的空座集合中均匀选择。

证明：最初只有乘客 1 会随机选择。若选择中间座位 k，只有乘客 k 之后会遇到冲突；在此之前座位 1 与 n 均未被使用。每次再选中中间座位，完全相同的性质递归保持。

定理：当 n ≥ 2，第 n 位乘客坐到座位 n 的概率是 1/2。

证明：根据引理，流程仅在首次选中座位 1 或 n 时终止。对任意可能的冲突链，将终点 1 与 n 互换，可得到概率完全相同、结局相反的一条链；这是成功链与失败链的一一对应。因此两种结局等概率。n = 1 时唯一座位必然被本人选中。证毕。

边界与复杂度

  • n = 1：返回 1.0，不能套用 1/2。
  • n ≥ 2：直接返回 0.5，包括最大输入 10⁵。
  • 时间复杂度：O(1)。
  • 空间复杂度：O(1)。

替代方案：动态规划

可以写出 f(1)=1，并对 n≥2 分解第一位乘客的选择；中间座位会落回规模更小的同构问题。化简后仍得到 f(n)=1/2。它适合帮助发现规律，但实现数组或递归都是不必要的开销。

面试追问

为什么不能说“第一位乘客有一半概率坐对”就结束？

第一位乘客直接坐对的概率是 1/n，并不是 1/2。结论来自完整冲突链中座位 1 与座位 n 的终点对称性。

如果被占座的乘客不是均匀随机选空座呢？

对称性可能被破坏，答案不再保证为 1/2；需要根据具体权重建立状态转移。

如果有两位乘客同时丢票呢？

状态需要记录多个“特殊座位”与冲突源，简单的两终点对称不再直接成立，通常需要组合计数或状态 DP。

常见错误

漏掉 n = 1无条件返回 0.5，会让唯一的特殊边界出错。
真的模拟随机过程随机采样只能近似概率，还会引入误差；本题要求精确返回。
建立 O(n) DP虽然可能得到正确值，但忽略了终点对称性，空间和过程都多余。
