设计视频共享平台

Design Video Sharing Platform

一串数字就是一段视频。上传、删除、观看与互动，
让每个编号和每一次计数都遵守平台规则。

阅读题意 ↓进入操作实验室 ↓先观察行为，再展开底部题解

01 / THE CONTRACT

题意与接口

实现 VideoSharingPlatform。数字字符串的第 i 个字符对应第 i 分钟，从 0 开始。上传时分配当前未占用的最小非负整数编号；删除后可以复用。每个新视频的观看、赞、踩计数均从 0 开始。

完整接口（Java 形式）行为
VideoSharingPlatform()创建空平台。
int upload(String video)保存视频，返回分配的编号。
void remove(int videoId)存在则删除，否则忽略。
String watch(int videoId, int startMinute, int endMinute)存在则观看数加 1，并返回 startMinute 到 min(endMinute, 长度−1) 的闭区间内容；否则返回字符串 "-1"。
void like(int videoId)
void dislike(int videoId)		存在则对应计数加 1，否则忽略。
int[] getLikesAndDislikes(int videoId)返回 [赞数, 踩数]；不存在时返回 [-1]。
int getViews(int videoId)返回观看数；不存在时返回整数 -1。

约束

  • 1 ≤ video.length ≤ 10⁵，video 只包含数字；所有 upload 的视频长度之和不超过 10⁵。
  • 0 ≤ videoId ≤ 10⁵。
  • 0 ≤ startMinute < endMinute < 10⁵；对存在的视频，startMinute < video.length。
  • 所有 watch 调用的 endMinute − startMinute 之和不超过 10⁵。
  • 全部方法调用总数不超过 10⁵。

    04 / SOLUTION

    准备好再揭开实现

    核心洞察、正确性与四语言代码

    核心洞察：将空闲编号分成两类

    空闲编号包括已删除的旧编号和从未分配过的新编号。用 nextId 记录最小新编号，用最小堆 free 保存全部已删除编号。回收编号都小于 nextId，因此优先取堆顶；堆为空时使用 nextId++。哈希表保存有效视频及其三个计数。

    完整过程

    1. 初始化空哈希表、空堆和 nextId = 0。
    2. 上传：弹出回收堆最小编号，或分配 nextId++。创建新的记录，将统计清零。
    3. 删除：成功移除视频后才入堆。重复删除不能再次回收。
    4. 观看：找到记录后观看数加 1，截取闭区间。右开切片的终点为 min(endMinute + 1, 长度)。
    5. 赞、踩只更新对应计数；不存在则忽略。统计查询不改变平台状态。

    正确性

    维护不变式：[0, nextId) 内每个编号恰好处于有效视频表或回收堆之一，且堆中没有重复；nextId 及以上尚未分配。初始状态满足它。上传从堆移出编号并写入表，或写入 nextId 后递增游标；有效删除将编号从表移入堆，无效删除不动状态，因此不变式始终成立。堆非空时堆顶小于所有全新编号且是最小回收编号；堆空时 nextId 最小。因此每次分配的是全局最小可用编号。

    新记录的计数全部为 0，删除会移除整条记录。观看、赞和踩只对存在的视频修改指定计数，且每次恰好加 1；复用不会继承统计。截取区间与缺失返回值均按接口定义处理，所以全部操作正确。

    边界与常见错误

    • 重复删除不能重复入堆，否则同一个编号可能分配给两个有效视频。
    • 栈与普通队列不能保证最小编号优先；乱序删除后尤其明显。
    • 复用时必须重新初始化全部统计，不能只替换视频字符串。
    • watch 的 "-1" 是字符串；getViews 的 -1 是整数；赞踩查询缺失值是单元素数组 [-1]。
    • 0 次观看合法，不能用 views || -1 查询。
    • 截取终点包含在结果中；超长 endMinute 应截断。长度 1 的视频也可 watch(id,0,1)。
    • 题目没有用户身份或赞踩互斥约束，重复调用每次都计数。

    复杂度

    设 N 是历史分配编号数，L 是本次返回片段长度，S 是有效视频内容总长度。按哈希查找期望 O(1) 分析：upload / 有效 remove 的堆操作为 O(log(N+1))；无回收编号时分配为 O(1)。watch 为 O(L)，其余方法为期望 O(1)。如果语言复制上传字符串，upload 还需 O(|video|) 时间。平台空间 O(N+S)，返回片段另占 O(L)。哈希表的最坏碰撞复杂度不保证 O(1)；删除释放字符串的成本也取决于语言实现。

    替代方案

    有序集合也能维护回收编号，通常在 O(log N) 内完成插入和取最小值。可利用调用总数上界预先将 0…99999 全部入堆，但增加初始化时间与空间。每次从 0 扫描空位最容易写，却可能使 Q 次操作退化为 O(Q²)。

    面试追问

    • 并发如何保证唯一？编号分配与视频写入需要原子化，删除与回收也必须同步。
    • 旧链接不应指向新视频怎么办？增加代际版本或使用不复用的外部 ID，区别于本题规则。
    • 视频过长无法复制怎么办？使用分块存储与流式片段接口，这会改变字符串 API 的复杂度模型。
    • 如何支持撤赞？需要按用户记录互动状态，当前只有计数，不能完成用户去重。

    import java.util.*;

class VideoSharingPlatform {
    static class Video {
        String text;
        int views, likes, dislikes;
        Video(String text) { this.text = text; }
    }
    private final Map<Integer, Video> videos = new HashMap<>();
    private final PriorityQueue<Integer> free = new PriorityQueue<>();
    private int nextId;
    public VideoSharingPlatform() {}

    public int upload(String video) {
        int id = free.isEmpty() ? nextId++ : free.poll();
        videos.put(id, new Video(video));
        return id;
    }
    public void remove(int videoId) {
        if (videos.remove(videoId) != null) free.offer(videoId);
    }
    public String watch(int videoId, int startMinute, int endMinute) {
        Video v = videos.get(videoId);
        if (v == null) return "-1";
        v.views++;
        return v.text.substring(startMinute, Math.min(endMinute + 1, v.text.length()));
    }
    public void like(int videoId) {
        Video v = videos.get(videoId);
        if (v != null) v.likes++;
    }
    public void dislike(int videoId) {
        Video v = videos.get(videoId);
        if (v != null) v.dislikes++;
    }
    public int[] getLikesAndDislikes(int videoId) {
        Video v = videos.get(videoId);
        return v == null ? new int[]{-1} : new int[]{v.likes, v.dislikes};
    }
    public int getViews(int videoId) {
        Video v = videos.get(videoId);
        return v == null ? -1 : v.views;
    }
}

    JavaScript

    class VideoSharingPlatform {
  constructor() {
    this.videos = new Map();
    this.free = [];
    this.nextId = 0;
  }
  pushId(id) {
    const h = this.free;
    let i = h.length;
    h.push(id);
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (h[p] <= id) break;
      h[i] = h[p]; i = p;
    }
    h[i] = id;
  }
  popId() {
    const h = this.free, result = h[0], last = h.pop();
    if (h.length) {
      let i = 0;
      while (2 * i + 1 < h.length) {
        let c = 2 * i + 1;
        if (c + 1 < h.length && h[c + 1] < h[c]) c++;
        if (h[c] >= last) break;
        h[i] = h[c]; i = c;
      }
      h[i] = last;
    }
    return result;
  }
  upload(video) {
    const id = this.free.length ? this.popId() : this.nextId++;
    this.videos.set(id, {video, views: 0, likes: 0, dislikes: 0});
    return id;
  }
  remove(videoId) {
    if (this.videos.delete(videoId)) this.pushId(videoId);
  }
  watch(videoId, startMinute, endMinute) {
    const v = this.videos.get(videoId);
    if (!v) return "-1";
    v.views++;
    return v.video.slice(startMinute, Math.min(endMinute + 1, v.video.length));
  }
  like(videoId) {
    const v = this.videos.get(videoId);
    if (v) v.likes++;
  }
  dislike(videoId) {
    const v = this.videos.get(videoId);
    if (v) v.dislikes++;
  }
  getLikesAndDislikes(videoId) {
    const v = this.videos.get(videoId);
    return v ? [v.likes, v.dislikes] : [-1];
  }
  getViews(videoId) {
    const v = this.videos.get(videoId);
    return v ? v.views : -1;
  }
}

    Python

    import heapq
from typing import List

class VideoSharingPlatform:
    def __init__(self):
        self.videos = {}
        self.free = []
        self.next_id = 0

    def upload(self, video: str) -> int:
        if self.free:
            video_id = heapq.heappop(self.free)
        else:
            video_id = self.next_id
            self.next_id += 1
        # [content, views, likes, dislikes]
        self.videos[video_id] = [video, 0, 0, 0]
        return video_id

    def remove(self, videoId: int) -> None:
        if videoId in self.videos:
            del self.videos[videoId]
            heapq.heappush(self.free, videoId)

    def watch(self, videoId: int, startMinute: int, endMinute: int) -> str:
        v = self.videos.get(videoId)
        if v is None:
            return "-1"
        v[1] += 1
        return v[0][startMinute:min(endMinute + 1, len(v[0]))]

    def like(self, videoId: int) -> None:
        if videoId in self.videos:
            self.videos[videoId][2] += 1

    def dislike(self, videoId: int) -> None:
        if videoId in self.videos:
            self.videos[videoId][3] += 1

    def getLikesAndDislikes(self, videoId: int) -> List[int]:
        v = self.videos.get(videoId)
        return [-1] if v is None else [v[2], v[3]]

    def getViews(self, videoId: int) -> int:
        v = self.videos.get(videoId)
        return -1 if v is None else v[1]

    C++

    #include <algorithm>
#include <functional>
#include <queue>
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

class VideoSharingPlatform {
    struct Video {
        string text;
        int views = 0, likes = 0, dislikes = 0;
    };
    unordered_map<int, Video> videos;
    priority_queue<int, vector<int>, greater<int>> freeIds;
    int nextId = 0;
public:
    VideoSharingPlatform() {}
    int upload(string video) {
        int id;
        if (freeIds.empty()) id = nextId++;
        else { id = freeIds.top(); freeIds.pop(); }
        videos.emplace(id, Video{move(video), 0, 0, 0});
        return id;
    }
    void remove(int videoId) {
        if (videos.erase(videoId)) freeIds.push(videoId);
    }
    string watch(int videoId, int startMinute, int endMinute) {
        auto it = videos.find(videoId);
        if (it == videos.end()) return "-1";
        auto& v = it->second;
        ++v.views;
        int end = min(endMinute, static_cast<int>(v.text.size()) - 1);
        return v.text.substr(startMinute, end - startMinute + 1);
    }
    void like(int videoId) {
        auto it = videos.find(videoId);
        if (it != videos.end()) ++it->second.likes;
    }
    void dislike(int videoId) {
        auto it = videos.find(videoId);
        if (it != videos.end()) ++it->second.dislikes;
    }
    vector<int> getLikesAndDislikes(int videoId) {
        auto it = videos.find(videoId);
        if (it == videos.end()) return {-1};
        return {it->second.likes, it->second.dislikes};
    }
    int getViews(int videoId) {
        auto it = videos.find(videoId);
        return it == videos.end() ? -1 : it->second.views;
    }
};
