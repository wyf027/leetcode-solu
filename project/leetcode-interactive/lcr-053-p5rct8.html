LCR 053 · MEDIUM

二叉搜索树中的中序后继

给定二叉搜索树中的节点 p，找出中序遍历时紧随其后的节点；若不存在，返回 null。

题意

在一棵值互不相同的二叉搜索树中，求节点 p 的中序后继。中序遍历顺序为「左子树 → 根 → 右子树」。

示例

root = [5,3,6,2,4,null,null,1]
p = 4
输出 = 5
p = 6
输出 = null

约束

树满足二叉搜索树性质：左子树节点值小于根，右子树节点值大于根；节点值互不相同。

交互实验室

输入层序数组与 p。每一步利用 BST 的大小关系缩小范围，并维护目前最小的更大值。

载入示例后开始观察。

    内置用例

    已实现：页面交互与内置用例计算。待验证：四语言编译、随机对拍、HTML 校验和浏览器回归。

    快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

    核心洞察

    后继一定比 p.val 大。沿根到叶搜索：当前值大于 p.val 时，它可能是答案，记录它并向左继续寻找更小的候选；否则向右寻找更大的值。最终记录的候选就是最小的大值，也即中序后继。

    完整过程

    1. 令 cur = root，successor = null。
    2. 若 cur.val > p.val，当前节点可作候选；记录它，再向左走。
    3. 否则，当前节点及其左子树都不可能是后继，向右走。
    4. 走到空节点时返回 successor。

    边界与常见错误

    • p 是最大节点时没有后继，应返回 null。
    • 不能在遇到第一个大于 p 的节点后直接返回：其左子树可能有更小的候选。
    • 本题按节点值比较；题目保证 BST 值唯一。

    复杂度：时间 O(h)，空间 O(1)，其中 h 是树高。若严格按中序遍历，可用栈遍历，时间 O(n)、空间 O(h)；BST 性质使我们不必访问无关子树。

    可提交代码

    JavaScript

    var inorderSuccessor = function(root, p) {
  let cur = root, successor = null;
  while (cur) {
    if (cur.val > p.val) {
      successor = cur;
      cur = cur.left;
    } else cur = cur.right;
  }
  return successor;
};
