你能在你最喜欢的那天吃到你最喜欢的糖果吗？

Can You Eat Your Favorite Candy on Your Favorite Day? —— 把“某一天能吃多少颗”与“某类糖果占据哪些序号”放进同一条时间轴。

中等 数组 前缀和 非付费题

Problem

题目描述

给定从 0 开始编号的正整数数组 candiesCount，其中 candiesCount[i] 表示第 i 类糖果的数量。每个查询 [favoriteType, favoriteDay, dailyCap] 想知道：能否安排每天吃糖果的数量，使你在指定日期吃到指定类型，同时任何一天都不超过每日上限。

  1. 从第 0 天开始吃。
  2. 第 i - 1 类没有全部吃完前，不能吃第 i 类；同一天可以跨越多个相邻类型。
  3. 糖果全部吃完之前，每天至少吃 1 颗，且不超过该查询的 dailyCap。

对每个查询返回一个布尔值，最终组成与 queries 等长的数组。

函数签名
canEat(candiesCount, queries) → boolean[]

每个查询彼此独立，可以采用不同的每日进食计划。

约束

  • 1 ≤ candiesCount.length ≤ 10⁵

  • 1 ≤ queries.length ≤ 10⁵
  • queries[i].length == 3
  • 0 ≤ favoriteType < candiesCount.length
  • 0 ≤ favoriteDay ≤ 10⁹
  • 1 ≤ dailyCap ≤ 10⁹

Solution

前缀和 + 区间相交

核心洞察

把所有糖果严格按类型顺序排成一列，并从 1 开始编号。设 prefix[i] 是类型 0..i-1 的总数，那么类型 t 占据闭区间 [prefix[t] + 1, prefix[t + 1]]。

到了第 d 天，当天结束前累计至少吃 d + 1 颗，至多吃 (d + 1) × cap 颗。查询可行，当且仅当这两个闭区间有交集。

(d + 1) × cap > prefix[t]  &&  d + 1 ≤ prefix[t + 1]

完整过程

  1. 建立长度 n + 1 的前缀和，令 prefix[0] = 0。
  2. 对查询 [t,d,cap]，计算第 d 天可能触及的累计序号区间 [d+1,(d+1)cap]。
  3. 读取目标类型的序号区间 [prefix[t]+1,prefix[t+1]]。
  4. 判断区间是否相交，并写入答案。

正确性证明

必要性：到第 d 天至少吃过 d+1 颗，所以若 d+1 > prefix[t+1]，目标类型已经必然吃完。每天最多吃 cap 颗，所以若 (d+1)cap ≤ prefix[t]，还不可能越过所有更小类型。

充分性：若两个区间相交，取交集内某个累计数量 x。因为 d+1 ≤ x ≤ (d+1)cap，可把 x 颗分配到前 d+1 天，每天分到 1..cap 颗；又因为 x 落在类型 t 的序号区间，所以第 d 天可以吃到该类型。故判定充分且必要。

边界与数值安全

  • 日期从 0 开始，因此天数必须用 d + 1。
  • 左侧是严格条件：最多吃到 prefix[t] 时仍未进入类型 t。
  • 目标类型的末颗糖可以在当天吃到，所以右侧是 ≤。
  • (d+1)cap 可能接近 10¹⁸；Java/C++ 使用 64 位整数，JavaScript 使用 BigInt。

复杂度

设糖果类型数为 n、查询数为 m。建立前缀和需要 O(n)，每个查询 O(1)，总时间 O(n+m)；前缀和额外空间 O(n)，答案数组不计入额外空间。

替代方案与面试追问

  • 二分日期：可以求最早/最晚日期再比较，但每个查询做二分没有必要，区间条件可直接计算。
  • 追问：若每天的上限按日期变化，可对每日容量再做前缀和或数据结构查询。
  • 追问：若允许跳过不吃，则“最少累计”不再是 d+1，应改成新的下界。

常见错误

  • 把糖果序号和数组下标混用，漏掉 +1。
  • 把相交条件写成 (d+1)cap ≥ prefix[t]；等于时只吃完前一种，还没吃到目标类型。
  • 忘记每个查询独立，错误地让某个查询的进食方案影响下一个查询。
  • 在 Java/C++ 中先用 32 位整数相乘，再赋给 64 位变量，导致乘法已经溢出。
Java
class Solution {
    public boolean[] canEat(int[] candiesCount, int[][] queries) {
        int n = candiesCount.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + candiesCount[i];
        }

        boolean[] answer = new boolean[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int type = queries[i][0];
            long day = queries[i][1];
            long cap = queries[i][2];

            long minEaten = day + 1;
            long maxEaten = (day + 1) * cap;
            answer[i] = maxEaten > prefix[type]
                    && minEaten <= prefix[type + 1];
        }
        return answer;
    }
}

/**
 * @param {number[]} candiesCount
 * @param {number[][]} queries
 * @return {boolean[]}

var canEat = function(candiesCount, queries) {
    const prefix = new Array(candiesCount.length + 1).fill(0n);
    for (let i = 0; i < candiesCount.length; i++) {
        prefix[i + 1] = prefix[i] + BigInt(candiesCount[i]);
    }

    return queries.map(([type, day, cap]) => {
        const days = BigInt(day) + 1n;
        const minEaten = days;
        const maxEaten = days * BigInt(cap);
        return maxEaten > prefix[type]
            && minEaten <= prefix[type + 1];
    });
};
Python
from typing import List


class Solution:
    def canEat(
        self,
        candiesCount: List[int],
        queries: List[List[int]]
    ) -> List[bool]:
        prefix = [0]
        for count in candiesCount:
            prefix.append(prefix[-1] + count)

        answer = []
        for candy_type, day, cap in queries:
            min_eaten = day + 1
            max_eaten = (day + 1) * cap
            possible = (
                max_eaten > prefix[candy_type]
                and min_eaten <= prefix[candy_type + 1]
            )
            answer.append(possible)
        return answer
C++
class Solution {
public:
    vector<bool> canEat(
        vector<int>& candiesCount,
        vector<vector<int>>& queries
    ) {
        int n = candiesCount.size();
        vector<long long> prefix(n + 1, 0);
        for (int i = 0; i < n; ++i) {
            prefix[i + 1] = prefix[i] + candiesCount[i];
        }

        vector<bool> answer;
        answer.reserve(queries.size());
        for (const auto& query : queries) {
            int type = query[0];
            long long day = query[1];
            long long cap = query[2];
            long long minEaten = day + 1;
            long long maxEaten = (day + 1) * cap;

            answer.push_back(
                maxEaten > prefix[type]
                && minEaten <= prefix[type + 1]
            );
        }
        return answer;
    }
};
