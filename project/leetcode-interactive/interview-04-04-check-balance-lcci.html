Problem Brief

题意

给定二叉树根节点 root，判断它是否平衡。平衡的定义是：对树中任意节点，其左、右子树高度差的绝对值都不超过 1。

官方样例 1

root = [3,␠9,␠20,␠null,␠null,␠15,␠7]

输出

true

官方样例 2

root = [1,␠2,␠2,␠3,␠3,␠null,␠null,␠4,␠4]

输出

false

空树返回 true 任意节点高度差 ≤ 1 官方页面未单列数据范围

可见空格约定：输入代码中的 ␠ 表示一个普通空格，便于核对完整参数；null 表示缺失节点。

Sealed Height Notes

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码默认隐藏。

后序高度哨兵 DFS

核心洞察

高度天然依赖左右子树，因此使用后序遍历。递归函数同时承担两项职责：平衡时返回真实高度；失衡时返回 `-1`。这个哨兵会沿调用栈向上传播，避免再扫描同一棵子树。

完整过程

  1. 空节点高度为 0。
  2. 递归获取左子树高度；若为 `-1`，立即向上传播。
  3. 递归获取右子树高度；若为 `-1`，立即向上传播。
  4. 若左右高度差超过 1，返回 `-1`；否则返回较大高度加 1。

边界与复杂度

  • 空树和单节点树都平衡。
  • 平衡要求对每个节点成立，只检查根节点不够。
  • 时间 O(n)，每个节点最多访问一次。
  • 递归栈 O(h)；平衡树 O(log n)，最坏链状树 O(n)。

替代方案取舍

自顶向下做法会对每个节点重新计算两棵子树高度，退化到 O(n²)。也可以让递归返回 `{balanced, height}`，语义更显式；但整数 `-1` 哨兵状态更少、可直接短路，是面试中最推荐的写法。极深树可改为显式栈模拟后序遍历。

面试追问

  • 追问：如何避免递归栈溢出？用显式栈记录节点与“访问后回收”状态，模拟后序遍历。
  • 追问：为什么不能只比较根的左右高度？因为任意更深节点都可能单独失衡。
  • 追问：若要找出第一个失衡节点？让递归额外记录节点引用，或在首次返回 `-1` 时保存它。

常见错误

  • 只在根节点比较左右高度，遗漏子树内部的失衡节点。
  • 每个节点重复调用独立 `height()`，造成 O(n²) 最坏复杂度。
  • 把 `-1` 当成真实高度继续计算，破坏短路语义。
class Solution {
    public boolean isBalanced(TreeNode root) {
        return height(root) != -1;
    }

    private int height(TreeNode node) {
        if (node == null) return 0;
        int left = height(node.left);
        if (left == -1) return -1;
        int right = height(node.right);
        if (right == -1 || Math.abs(left - right) > 1) return -1;
        return Math.max(left, right) + 1;
    }
}
