快指针一次两步、慢指针一次一步，慢指针抵达后半区起点。把后半段原地反转后，两个指针从两端朝中间比较。

题意：判断单链表是否正读与反读一致

给定单链表的头节点 head，若它是回文链表返回 true，否则返回 false。

节点数范围为 [1, 10^5]，每个 Node.val 范围为 0..9。进阶要求：O(n) 时间与 O(1) 额外空间。

关键：偶数长度时慢指针正好落在后半段开头；奇数长度时会落在中心节点，反转从中心开始仍可正确比较。
官方样例 
head = [1,2,2,1]
output = true

head = [1,2]
output = false

本页主线使用“找中点 → 原地反转后半段 → 同步比较”，满足进阶的空间要求。

题解区域

默认收起。先观看链路折返，再展开指针不变量和代码。

核心洞察

fast 每轮走两步，slow 每轮走一步；当 fast 到尾部时 slow 已在中间。反转 slow 开始的后缀，使它按反序与原头部对齐。只要后缀尚未耗尽，就逐值比较。

  1. 快慢指针找到中点。
  2. 原地迭代反转后半段。
  3. head 和反转后的后缀同步前进，出现不等立即失败。

复杂度与边界

  • 每个节点常数次访问：时间 O(n)。
  • 只用若干指针：额外空间 O(1)。
  • 单节点天然为 true。
  • 奇数长度的中心节点会与自身比较一次，不影响结果。

替代方案取舍

把值复制到数组后双指针比较，代码短且更易读，但使用 O(n) 额外空间。栈也类似。需要满足 follow-up 时，原地反转是首选；生产代码若要求不修改链表，可在比较后再次反转恢复后缀。

常见错误与追问

错误：反转前断开链表导致丢失引用；只比较到 head 耗尽；把 fast 的循环条件写成只检查 fast；忘记保存 next 后再改指针。

追问：需要恢复原链表？把后缀再反转一次并接回。双向链表？直接两端收缩即可。

class Solution {
  public boolean isPalindrome(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; }
    ListNode prev = null;
    while (slow != null) { ListNode next = slow.next; slow.next = prev; prev = slow; slow = next; }
    while (prev != null) { if (head.val != prev.val) return false; head = head.next; prev = prev.next; }
    return true;
  }
}
