分割回文串

把字符串切成若干段，要求每一段都是回文。不同的切法，就是回溯树中的不同路径。

题意

给定一个字符串 s，将其分割成一些子串，使每个子串都是回文串，返回所有可能的分割方案。

示例

输入：s = "aab"

输出：[["a","a","b"],["aa","b"]]

约束

  • 1 <= s.length <= 16
  • s 仅由小写英文字母组成。

先问每个递归层一个问题：从当前位置开始，可以截取哪些“合法且回文”的前缀？题解默认隐藏。

核心洞察

枚举下一段的结束位置。若子串是回文，就把它加入路径并递归处理剩余后缀；恰好走到末尾时，当前路径是一种答案。

过程

  1. 从 start 枚举 end。
  2. 用双指针判断 s[start..end] 是否回文。
  3. 选择、递归、撤销选择，完整覆盖所有切法。

边界

单字符必是回文；整串本身可能是一种方案；路径加入答案时必须复制，不能直接保存会继续变化的引用。

复杂度

方案数量可能指数级。每次判回文 O(n)，可预处理回文表来减少重复判断。

替代方案

预先用 DP 计算每个区间是否回文，再回溯枚举路径；当字符串更长、重复判定较多时更合适。

常见错误

  • 递归返回时忘记移除最后选择的片段。
  • 把非回文子串也推进路径。
  • 答案中保存同一个可变 path 引用。

参考实现

Java

class Solution {
    public List<List<String>> partition(String s) {
        List<List<String>> ans = new ArrayList<>();
        backtrack(s, 0, new ArrayList<>(), ans); return ans;
    }
    private void backtrack(String s, int start, List<String> path, List<List<String>> ans) {
        if (start == s.length()) { ans.add(new ArrayList<>(path)); return; }
        for (int end = start; end < s.length(); end++) if (palindrome(s, start, end)) {
            path.add(s.substring(start, end + 1)); backtrack(s, end + 1, path, ans); path.remove(path.size() - 1);
        }
    }
    private boolean palindrome(String s, int l, int r) { while (l < r) if (s.charAt(l++) != s.charAt(r--)) return false; return true; }
}

JavaScript

var partition = function(s) {
  const ans = [], path = [];
  const isPalindrome = (l, r) => { while (l < r) if (s[l++] !== s[r--]) return false; return true; };
  const dfs = (start) => {
    if (start === s.length) return ans.push([...path]);
    for (let end = start; end < s.length; end++) if (isPalindrome(start, end)) {
      path.push(s.slice(start, end + 1)); dfs(end + 1); path.pop();
    }
  };
  dfs(0); return ans;
};

Python

class Solution:
    def partition(self, s: str) -> List[List[str]]:
        ans, path = [], []
        def dfs(start: int) -> None:
            if start == len(s):
                ans.append(path[:]); return
            for end in range(start, len(s)):
                part = s[start:end + 1]
                if part == part[::-1]:
                    path.append(part); dfs(end + 1); path.pop()
        dfs(0); return ans

C++

class Solution {
public:
    vector<vector<string>> partition(string s) {
        vector<vector<string>> ans; vector<string> path;
        function<void(int)> dfs = [&](int start) {
            if (start == s.size()) { ans.push_back(path); return; }
            for (int end = start; end < s.size(); ++end) if (isPal(s, start, end)) {
                path.push_back(s.substr(start, end - start + 1)); dfs(end + 1); path.pop_back();
            }
        }; dfs(0); return ans;
    }
    bool isPal(const string& s, int l, int r) { while (l < r) if (s[l++] != s[r--]) return false; return true; }
};
