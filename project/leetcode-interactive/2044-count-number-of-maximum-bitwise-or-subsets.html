01 / THE CHALLENGE

题目

给定整数数组 nums，选出一个非空子集，对其所有元素执行按位或。请统计：能达到所有子集中最大按位或值的不同非空子集有多少个。

子集通过删除原数组中的一些元素得到，也允许不删除。两个子集是否不同取决于所选元素下标，而不是元素值；选择不同位置上的相同数值，仍是不同子集。

按位或写作 |。某一位只要在任一参与数字中为 1，结果这一位就是 1，例如 2 | 1 = 3（10 | 01 = 11）。

参数与返回值

countMaxOrSubsets(nums: integer[]) → integer

返回子集数量，不是最大按位或值。

官方约束

  • 1 ≤ nums.length ≤ 16
  • 1 ≤ nums[i] ≤ 100000

04 / UNLOCK THE REASONING

准备好展开推导了吗？

逐步观察决策与位变化，再阅读证明和四语言实现。

核心洞察：先找目标，再数子集

按位或只会增加或保留 1 位，不会清除 1 位。全体元素的按位或 target = nums[0] | … | nums[n−1] 包含任意子集的所有 1 位，是子集按位或值的上界。选择全部元素就能达到这个上界。

用 dfs(i, current) 表示前 i 个下标已决定、当前按位或为 current，返回这个状态之后能够形成的有效完整子集数。

  1. 遍历数组，计算 target。
  2. 从 dfs(0, 0) 出发，跳过当前位置调用 dfs(i+1, current)，选取当前位置调用 dfs(i+1, current | nums[i])。
  3. 到达 i == n 的叶子时，若 current 等于 target，返回 1；否则返回 0。
  4. 两分支返回值相加，根节点返回的就是答案。

官方 nums[i] ≥ 1，所以 target > 0。空集的 OR 初始值为 0，不会被计入；下方代码利用了这一约束。

正确性证明

  1. 目标最大且可达。 子集 OR 的每个 1 位均来自原数组，因此它的 1 位是 target 的子集，数值不大于 target。全数组本身恰好得到 target。
  2. 递归状态准确。 初始空前缀的 OR 为 0；跳过保持 OR，选取则与 nums[i] 按位或。归纳可知每个节点都准确记录已选元素的 OR。
  3. 枚举无重无漏。 每个下标只有选取或跳过两种决策，每个子集唯一对应一条根到叶路径。相同数值的不同下标仍拥有不同路径。
  4. 计数准确。 只有 OR 等于 target 的叶子返回 1，其余返回 0。两分支选择互斥，求和不会重复；空集无法达到正数 target，最终得到所求非空子集数量。

复杂度与边界

  • 预处理 O(n)，递归树有 2ⁿ 个叶子、2ⁿ⁺¹−1 个节点；每个节点常数工作，总时间 O(2ⁿ)。
  • 只保存深度至多 n+1 的递归栈，辅助空间 O(n)。
  • 单元素答案为 1；全部元素相同时答案为 2ⁿ−1。
  • n ≤ 16，答案最大 65535。元素最多占 17 位，OR ≤ 131071，四语言的整数范围均足够。
  • 若允许全零数组，需记录是否选过元素，或在 target == 0 时扣除空集。

演示保存节点快照以便回退，有额外存储开销，因此限定 8 个元素；上述复杂度属于下方提交代码。

替代方案

  • 掩码枚举： 枚举 1 到 2ⁿ−1，每次遍历 n 位并计算 OR，时间 O(n·2ⁿ)，辅助空间 O(1)。
  • 计数 DP： 保存“OR 值 → 子集数量”，每个元素用新映射汇总跳过和选取。时间 O(n·K)、空间 O(K)，K 为出现的 OR 状态数。
  • 提前达标： 若 current == target，剩余 n−i 个下标任意选择，直接返回 2ⁿ⁻ⁱ。最坏仍为 O(2ⁿ)。
  • 后缀剪枝： 若 current 与所有剩余元素的 OR 仍不等于 target，该分支贡献 0。

四语言完整代码

统一使用跳过 / 选取递归与官方签名。Python 使用 Python 3。代码仅生成，尚未执行验证。

Java

class Solution {
    public int countMaxOrSubsets(int[] nums) {
        int target = 0;
        for (int x : nums) target |= x;
        return dfs(nums, 0, 0, target);
    }

    private int dfs(int[] nums, int i, int current, int target) {
        if (i == nums.length) return current == target ? 1 : 0;
        return dfs(nums, i + 1, current, target)
             + dfs(nums, i + 1, current | nums[i], target);
    }
}

/**

var countMaxOrSubsets = function(nums) {
    const target = nums.reduce((value, x) => value | x, 0);
    function dfs(i, current) {
        if (i === nums.length) return Number(current === target);
        return dfs(i + 1, current)
             + dfs(i + 1, current | nums[i]);
    }
    return dfs(0, 0);
};

from typing import List

class Solution:
    def countMaxOrSubsets(self, nums: List[int]) -> int:
        target = 0
        for x in nums:
            target |= x

        def dfs(i: int, current: int) -> int:
            if i == len(nums):
                return int(current == target)
            return dfs(i + 1, current) + dfs(i + 1, current | nums[i])

        return dfs(0, 0)

常见错误

  • 把 target 写成数组最大元素。例如 [1,2] 的 target 为 3。
  • 使用 Set 去重数值或子集内容，丢失不同下标的计数。
  • 把按位或 | 写成逻辑或 || 或 or。
  • 中途达标只加 1，忽略后续位置仍可自由选择。
  • 共用可变 OR 却不恢复，污染兄弟分支。按值传入 current 更简单。
  • 返回最大 OR 值，而不是达到它的子集数。

面试追问

  • 为何提前达标可以乘方计数？ 后续元素不可能引入 target 以外的 1 位，OR 不再变化；剩余下标每个都可独立选或不选。
  • n 更大怎么办？ OR 状态较少时采用计数 DP；根据新约束考虑大整数或取模。
  • DP 为什么用新映射？ 避免同一轮新状态再次选取同一个元素；相同 OR 的来源应累加次数。
  • 能否直接换成按位与？ 不能照搬目标分析，加入元素会清除 1 位，需要重新推导目标及初始值。
