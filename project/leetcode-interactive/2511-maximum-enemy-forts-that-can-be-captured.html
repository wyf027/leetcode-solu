2511EASY · 简单数组

最多可以摧毁的
敌人城堡数目

Maximum Enemy Forts That Can Be Captured

一条阵线，一次行军。选择出发城堡与落脚空地，让沿途摧毁的敌堡尽可能多。

官方题目 ↗

01 / 任务简报

给定下标从 0 开始、长度为 n 的整数数组 forts，每个位置有以下一种状态：

1 · 我方城堡 军队从这里出发。
−1 · 空地 军队必须在这里结束。
0 · 敌方城堡 途中经过时被摧毁。

选择我方城堡下标 i 和空地下标 j（0 ≤ i,j ≤ n−1），可以向左或向右移动。两个端点之间的每个位置都必须是敌堡：对所有 min(i,j) < k < max(i,j)，有 forts[k] = 0。求一次移动最多摧毁多少个敌堡；没有我方城堡或无法移动时返回 0。

约束与接口

  • 1 ≤ forts.length ≤ 1000
  • forts[i] 为整数，且 −1 ≤ forts[i] ≤ 1。
  • 参数：forts: integer[]；返回：integer；函数名：captureForts。

02 / 官方示例

示例 1

输入：forts = [1,0,0,-1,0,0,0,0,1]
输出：4

从下标 0 到 3，摧毁下标 1、2 的两个敌堡；从下标 8 到 3，摧毁下标 4、5、6、7 的四个敌堡。最大值为 4。

示例 2

输入：forts = [0,0,1,-1]
输出：0

可以从下标 2 移动到相邻的下标 3，但中间没有敌堡，因此答案为 0。

如果某次行军途中遇到我方城堡或空地，这次移动还符合要求吗？向左走和向右走会改变端点之间的条件吗？

04 / 题解 · 只看相邻的非零位置

核心洞察

合法路线的端点必须是一座我方城堡 1 和一块空地 −1，中间只能有 0。因此，这两个端点一定是数组中相邻的非零元素（忽略零后的相邻）。值不同即可配对，摧毁数为两个下标之差减一。

完整过程

  1. 令 prev = −1 表示还没有遇到非零位置，令 ans = 0。
  2. 从左向右扫描下标 i。若值为 0，继续扫描，不改变 prev。
  3. 若当前位置非零且存在 prev，检查两个位置的值是否不同。不同则用 i − prev − 1 更新最大值。
  4. 无论两个值是否相同，都将 prev 更新为 i。扫描结束返回 ans。

阵线扫描台

白色外框：当前扫描点；青色底：上一个非零点；黄色底：本步合法路线中的敌堡。路线方向始终是 1 → −1。

只接受整数 −1、0、1。长阵线可在自身区域横向滚动。

键盘：Tab 移动焦点，Enter / 空格激活按钮。启用减少动态效果时，自动播放每 2.5 秒推进一次，不使用移动动画。

示例 1 的关键节点

遇到下标 0，记录 prev = 0；在下标 3 遇到 −1，与 0 配对，得到 2；随后更新 prev = 3；在下标 8 遇到 1，与 3 配对，得到 4。虽然扫描向右，第二条真实行军路线是 8 → 3。

正确性证明

不变量：处理每个下标前，prev 是已经扫描的最后一个非零位置，ans 是此前所有合法端点对的最大间隔长度。遇到 0 时没有新端点，不变量保持。遇到非零位置时，它与 prev 之间全为 0；端点异号时路线合法，同号时路线不合法。更新最大值并记录当前端点后，不变量仍成立。

完备性：任意合法路线的端点之间不能有非零元素，所以必定会作为相邻非零位置被检查。算法检查的异号配对也必定合法。因此不会漏掉更优路线，也不会计入非法路线，最终最大值就是答案。

边界与复杂度

  • 单元素、全 0、没有 1 或没有 −1：没有有效配对，答案为 0。
  • 相邻的 1 和 −1：间隔长度为 0，合法移动也可能没有收益。
  • 两端同号：不能配对，但仍要更新 prev，因为不能跨过这个障碍。
  • 数组开头或结尾的零：缺少一侧合法端点，不能单独计数。
  • 算法时间 O(n)，额外空间 O(1)，不修改输入。页面演示保存状态并绘制阵线，不计入提交算法空间。

替代方案

可从每个 1 分别向两侧走，数连续的 0，直到第一个非零位置；只有停在 −1 时才更新答案。容易理解但会重复走过零段。在这道题上，每个零段最多从两侧被扫描，因此这种及时停止的实现总时间也可为 O(n)。另一种方案先保存所有非零下标，再比较相邻位置，时间 O(n)、空间 O(n)；在线记录 prev 可省去数组。

常见错误

  • 把 0 当空地：本题 0 是敌堡，−1 才是空地。
  • 只检查左端为 1 的路线：会漏掉向左行军。
  • 用 i − prev：多计一个端点，正确值应减一。
  • 同号时保留旧 prev：可能跨过非零障碍，制造非法路线。
  • 把所有合法路线的收益相加：题目只选择一次移动，应取最大值。

面试追问

  • 如何返回实际路线？更新最大值时同时保存两端下标，再将值为 1 的端点作为起点。
  • 如何流式处理？维护当前位置计数、前一个非零位置和值、最大值，无需保存完整数组。
  • 若敌堡有不同分值？维护相邻非零位置之间的分值总和，在合法端点处更新最大收益。

Java

class Solution {
    public int captureForts(int[] forts) {
        int prev = -1, ans = 0;
        for (int i = 0; i < forts.length; i++) {
            if (forts[i] == 0) continue;
            if (prev != -1 && forts[prev] != forts[i]) {
                ans = Math.max(ans, i - prev - 1);
            }
            prev = i;
        }
        return ans;
    }
}

/**
 * @param {number[]} forts
 * @return {number}
 */
var captureForts = function(forts) {
    let prev = -1, ans = 0;
    for (let i = 0; i < forts.length; i++) {
        if (forts[i] === 0) continue;
        if (prev !== -1 && forts[prev] !== forts[i]) {
            ans = Math.max(ans, i - prev - 1);
        }
        prev = i;
    }
    return ans;
};

Python 3

from typing import List

class Solution:
    def captureForts(self, forts: List[int]) -> int:
        prev, ans = -1, 0
        for i, value in enumerate(forts):
            if value == 0:
                continue
            if prev != -1 and forts[prev] != value:
                ans = max(ans, i - prev - 1)
            prev = i
        return ans

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int captureForts(vector<int>& forts) {
        int prev = -1, ans = 0;
        for (int i = 0; i < static_cast<int>(forts.size()); ++i) {
            if (forts[i] == 0) continue;
            if (prev != -1 && forts[prev] != forts[i]) {
                ans = max(ans, i - prev - 1);
            }
            prev = i;
        }
        return ans;
    }
};
