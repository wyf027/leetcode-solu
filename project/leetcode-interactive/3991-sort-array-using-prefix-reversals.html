3991. 使用前缀反转对数组进行排序

在排列图上做 BFS，第一次到达目标就是最少翻转次数。

n ≤ 8

题意

给定 nums（0..n-1 的一个排列）和允许长度集合 pre。一次操作选择 x ∈ pre，反转 nums 的前 x 项。求升序排列所需的最少操作数；不能到达则返回 -1。

示例 1

nums = [2, 0, 1]
pre = [2, 3]

输出：2

示例 2

nums = [1, 0, 2]
pre = [1, 3]

输出：-1

示例 3

nums = [0, 1]
pre = [2]

输出：0

约束：1 ≤ n ≤ 8；nums 是 0..n-1 的排列；pre 中长度互不相同且都在 1..n。

题解

默认收起，先动手观察再查看完整方案。

核心洞察

把每个排列看成图中的一个节点。对每个允许长度 x 反转一次前缀，就是一条等权边。目标是 [0,1,...,n-1]；BFS 按层扩展，所以首次弹出目标时层数恰为最少操作数。

完整过程

  1. 用逗号拼接的排列做状态键，避免重复入队。
  2. 队首取状态；若它已升序，返回步数。
  3. 枚举 pre，复制数组并反转前 x 项；未访问才入队。
  4. 队列耗尽仍未到目标，返回 -1。

边界与复杂度

x = 1 不改变状态，访问集会过滤；初始已排序直接返回 0。最多有 n! 个状态，时间 O(n! · |pre| · n)，空间 O(n! · n)。因 n ≤ 8 可行。

替代方案

可将排列编码为阶乘进制整数以减少哈希键开销，或做双向 BFS；但实现更复杂。面试中先清晰说明“无权最短路 → BFS”通常最稳妥。

面试追问

若 n 增大到 12？普通 BFS 的 n! 状态爆炸，应尝试双向 BFS、启发式搜索或利用允许反转集合的群结构；不能简单套贪心煎饼排序，因为这里允许的长度受限。

常见错误

  • 把允许长度当作索引，反转了前 x+1 项。
  • 未在入队时标记访问，导致同层重复状态暴涨。
  • 只做可达性 DFS，忘记 BFS 才保证最少步数。
  • 错误地认为任意包含 n 的集合都可排序。

from collections import deque
class Solution:
    def minOperations(self, nums, pre):
        start, goal=tuple(nums),tuple(range(len(nums)))
        q,dist=deque([start]),{start:0}
        while q:
            a=q.popleft()
            if a==goal:return dist[a]
            for x in pre:
                b=a[:x][::-1]+a[x:]
                if b not in dist:dist[b]=dist[a]+1;q.append(b)
        return -1
