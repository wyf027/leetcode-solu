最大数字范围的整数之和

对每个整数找出最大数字与最小数字，它们的差叫作“数字范围”。找出数组里的最大数字范围，并把所有达到这个范围的整数相加。

题意与约束

给定 nums。例如 5724 的数字范围为 7 - 2 = 5。返回数字范围等于全局最大值的全部整数之和。

  • 1 ≤ nums.length ≤ 100
  • 10 ≤ nums[i] ≤ 10⁵

示例：nums = [5724, 111, 350]，范围依次为 5, 0, 5，答案是 5724 + 350 = 6074。

交互实验室

只接受 10 到 100000 的正整数。

题解：一次扫描同时维护最佳范围与总和

令当前最大范围为 best、对应总和为 sum。扫描某个数 x 后得到范围 r：若 r > best，新的冠军出现，重置 sum = x；若 r = best，把 x 加入；否则忽略。无需第二次遍历。

完整过程
按位取 y % 10，维护 min/max。
边界
重复数字范围为 0；所有数都同范围时全部相加。
复杂度
O(n · log₁₀M) 时间，O(1) 额外空间。

替代方案：先保存每个范围再二次扫描，表达更直观但多占 O(n) 空间。面试追问：若允许负数，应忽略符号位并扫描绝对值。常见错误：新最大范围出现时忘记重置总和；把数值大小当成数字范围。 

class Solution { public int maxDigitRange(int[] nums) { int best=-1, sum=0; for(int x:nums){ int y=x, lo=10, hi=0; while(y>0){int d=y%10; lo=Math.min(lo,d); hi=Math.max(hi,d); y/=10;} int r=hi-lo; if(r>best){best=r;sum=x;} else if(r==best) sum+=x; } return sum; } }

class Solution:
    def maxDigitRange(self, nums: list[int]) -> int:
        best, ans = -1, 0
        for x in nums:
            y, lo, hi = x, 10, 0
            while y:
                d = y % 10; lo = min(lo, d); hi = max(hi, d); y //= 10
            r = hi - lo
            if r > best: best, ans = r, x
            elif r == best: ans += x
        return ans
