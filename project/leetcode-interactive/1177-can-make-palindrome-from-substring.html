Can Make Palindrome from Substring

构建回文串检测

每次取出一段子串：可以任意重排，再替换至多 k 个字符。你需要判断它最终能否变成回文串。

先别急着看题解

Problem

题目描述

给定字符串 s 与查询数组 queries。每个查询具有完整参数形式 queries[i] = [lefti, righti, ki]。

对第 i 次查询，可以先任意重排闭区间子串 s[lefti..righti]，再从中选择至多 ki 个位置，将每个位置替换成任意小写英文字母。若能得到回文串，则答案为 true，否则为 false。

返回布尔数组 answer，其中 answer[i] 对应第 i 个查询。每个查询彼此独立，不会修改原字符串；替换按字符位置逐个计数。

示例 1

输入：s = "abcda", queries = [[3,3,0],[1,2,0],[0,3,1],[0,3,2],[0,4,1]]
输出：[true,false,false,true,true]
解释：
[3,3,0] → "d" 本身就是回文串。
[1,2,0] → "bc" 无法在不替换字符时变为回文串。
[0,3,1] → "abcd" 只替换 1 个字符仍不够。
[0,3,2] → "abcd" 可经重排与 2 次替换变为 "abba"。
[0,4,1] → "abcda" 可变为 "abcba"。

示例 2

输入：s = "lyb", queries = [[0,1,0],[2,2,1]]
输出：[false,true]

约束

1 <= s.length <= 105
1 <= queries.length <= 105
0 <= lefti <= righti < s.length
0 <= ki <= s.length

s 仅由小写英文字母组成。

题解展开控制

Solution

前缀奇偶掩码

核心洞察

允许重排后，字符原来的位置不再重要，只需关心每种字母出现次数的奇偶性。偶数次的字符可以全部两两配对；奇数次的字符各会留下一个“单字符”。回文串最多允许一个单字符放在正中间。

若某段子串有 odd 种字母出现奇数次，每替换一个字符，最多能把两个落单字母配成一对，因此最少替换次数为 ⌊odd / 2⌋。判断式就是 odd / 2 <= k（整数除法）。

完整过程

  1. 为前缀建立 26 位整数掩码：第 j 位表示字母 'a' + j 在该前缀中出现次数的奇偶性。
  2. 扫描字符串。遇到字母 c 时，用异或切换对应位：prefix[i + 1] = prefix[i] XOR (1 << (c - 'a'))。
  3. 查询 [left, right, k] 的子串掩码为 prefix[right + 1] XOR prefix[left]。相同前缀部分被异或抵消。
  4. 对子串掩码统计二进制 1 的数量，得到 odd。
  5. 若 ⌊odd / 2⌋ <= k，记录 true；否则记录 false。

为什么正确

1
掩码准确表示奇偶性。 每次出现某字母就异或其位，恰好在偶与奇之间切换；两个前缀掩码异或后，只留下目标子串各字母的奇偶性。
2
替换下界。 有 odd 个奇数频次时，除中心字符外，其余落单字符都必须成对消除。一次替换最多同时修复两个奇数频次，所以至少需要 ⌊odd / 2⌋ 次。
3
下界可达到。 任取两个奇数频次字母，把其中一个落单字符替换成另一个字母，就能让这两种频次同时变偶。重复操作后，至多剩一个奇数频次，剩余字符可重排成回文串。

因此，查询可行当且仅当 ⌊odd / 2⌋ <= k，算法返回值正确。

复杂度

预处理 O(n)；每个查询做常数次位运算与位计数，为 O(1)。总时间 O(n + q)，额外空间 O(n)。

边界情况

  • 长度为 1：无需替换。
  • left = right：答案恒为真。
  • k = 0：必须已存在回文排列。
  • 查询互不影响，不能更新原串。

四种语言完整代码

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Boolean> canMakePaliQueries(String s, int[][] queries) {
        int n = s.length();
        int[] prefix = new int[n + 1];

        for (int i = 0; i < n; i++) {
            int bit = 1 << (s.charAt(i) - 'a');
            prefix[i + 1] = prefix[i] ^ bit;
        }

        List<Boolean> answer = new ArrayList<>(queries.length);
        for (int[] query : queries) {
            int left = query[0];
            int right = query[1];
            int k = query[2];
            int mask = prefix[right + 1] ^ prefix[left];
            int odd = Integer.bitCount(mask);
            answer.add(odd / 2 <= k);
        }
        return answer;
    }
}
/**
 * @param {string} s
 * @param {number[][]} queries
 * @return {boolean[]}
 */
var canMakePaliQueries = function(s, queries) {
    const prefix = new Int32Array(s.length + 1);

    for (let i = 0; i < s.length; i++) {
        const bit = 1 << (s.charCodeAt(i) - 97);
        prefix[i + 1] = prefix[i] ^ bit;
    }

    const bitCount = (value) => {
        let count = 0;
        let x = value >>> 0;
        while (x !== 0) {
            x &= x - 1;
            count++;
        }
        return count;
    };

    return queries.map(([left, right, k]) => {
        const mask = prefix[right + 1] ^ prefix[left];
        return Math.floor(bitCount(mask) / 2) <= k;
    });
};

替代方案

可以为 26 个字母分别建立计数前缀和。每次查询取 26 个差值并统计奇数频次，时间为 O(26)，空间为 O(26n)。它更直观，也容易扩展到更大的字符计数需求；本题只有 26 个小写字母，位掩码更紧凑。

面试追问

  • 如果字符串支持单点更新？ 可用 Fenwick 树或线段树维护异或掩码，使更新和查询都是 O(log n)。
  • 为什么答案不是 odd - 1？ 一次替换能同时改变两种字母频次的奇偶性，因此两个落单只需一次替换。
  • 字符集超过整数位数怎么办？ 使用多字整数、BitSet，或回到分字符前缀计数。
  • 能否直接检查原子串是否为回文？ 不能；题目允许重排，关注的是是否存在某种回文排列。

常见错误

  • 写成 odd <= k，忽略一次替换能处理两个奇数频次。
  • 区间掩码误写成 prefix[right] XOR prefix[left]，漏掉右端点。
  • 真的重排或修改每个子串，导致总体复杂度无法承受 105 次查询。
  • 在 JavaScript 中用普通右移统计负数位，造成无限符号扩展；应先用 >>> 0 转为无符号表示。
  • 误认为某次查询会改变后续查询使用的字符串。
