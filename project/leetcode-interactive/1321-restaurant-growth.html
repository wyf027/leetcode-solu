Restaurant Growth

老板想看的不是某一张小票，而是每天向前回望七天时，餐馆的营业额呈现怎样的变化。

The brief

题目要求

表 Customer 记录顾客的到店消费。请按自然日统计，以当前日期和之前 6 天组成连续 7 天窗口，输出窗口总消费 amount 与日均消费 average_amount。

Customer 表

字段类型含义
customer_idint顾客编号
namevarchar顾客姓名
visited_ondate到店日期
amountint本次消费金额

交付口径

只从第 7 个自然日开始输出。 同一天可以有多位顾客，要先汇总当天营业额，再进入七日窗口。

结果按 visited_on 升序排列；average_amount 四舍五入保留两位小数。

  • 主键(customer_id, visited_on) 唯一
  • 连续营业题目保证每天至少有一位顾客
  • 结果顺序按日期从早到晚输出

Solution

完整题解

核心洞察

1先把粒度降到“天”

原表是一位顾客一天一行，而窗口需要每日营业额。同一天的多笔消费必须先求和。

2再对日汇总做窗口

按日期排序，对当前行及前 6 行求和。每天至少有人到店，因此 7 行恰好对应连续 7 天。

3过滤未满七天的行

同步计算窗口内日数，仅保留计数为 7 的日期；最后将总额除以 7 并保留两位小数。

完整过程

  1. 按 visited_on 分组，计算每日总营业额。
  2. 按日期升序，对每日总额应用“当前行及前 6 行”的窗口。
  3. 同一窗口计算 COUNT(*)，排除前 6 行。
  4. 输出窗口总额和 ROUND(total / 7, 2)，按日期升序返回。

边界与复杂度

  • 少于 7 个营业日：结果为空。
  • 同日多位顾客：必须合并；示例 01-10 为 130 + 150 = 280。
  • 窗口平均是七天日均营业额，不是按顾客人数平均。
  • 设原记录数 N、天数 D，典型执行时间约 O(N + D log D)，日汇总中间结果 O(D)。

正确性说明

对任意输出日期 d，第一阶段把所有 visited_on = d 的消费相加，因此得到且只得到 d 当天总营业额。第二阶段按日期顺序取当前行和前 6 行；由于每天至少一条记录，日汇总没有日期缺口，这 7 行恰好是一段连续 7 天。窗口求和等于这 7 天的全部消费，除以 7 即题目要求的日均值。过滤窗口计数为 7 的行排除了全部不完整前缀，故输出既无遗漏也无多余。

官方可提交语言 · MySQL 8.0 窗口函数

WITH daily AS (
    SELECT visited_on, SUM(amount) AS daily_amount
    FROM Customer
    GROUP BY visited_on
),
rolling AS (
    SELECT
        visited_on,
        SUM(daily_amount) OVER (
            ORDER BY visited_on
            ROWS BETWEEN 6 PRECEDING AND CURRENT ROW
        ) AS amount,
        COUNT(*) OVER (
            ORDER BY visited_on
            ROWS BETWEEN 6 PRECEDING AND CURRENT ROW
        ) AS day_count
    FROM daily
)
SELECT
    visited_on,
    amount,
    ROUND(amount / 7, 2) AS average_amount
FROM rolling
WHERE day_count = 7
ORDER BY visited_on;

本地语义参考 · 输入为内存中的交易记录

import java.util.*;

public class RestaurantGrowth {
    public record Transaction(int customerId, String name,
                              String visitedOn, int amount) {}
    public record Result(String visitedOn, long amount,
                         double averageAmount) {}

    public static List<Result> calculate(List<Transaction> rows) {
        TreeMap<String, Long> daily = new TreeMap<>();
        for (Transaction row : rows) {
            daily.merge(row.visitedOn(), (long) row.amount(), Long::sum);
        }

        Deque<Long> window = new ArrayDeque<>();
        List<Result> answer = new ArrayList<>();
        long sum = 0;
        for (Map.Entry<String, Long> day : daily.entrySet()) {
            window.addLast(day.getValue());
            sum += day.getValue();
            if (window.size() > 7) sum -= window.removeFirst();
            if (window.size() == 7) {
                double average = Math.round(sum / 7.0 * 100.0) / 100.0;
                answer.add(new Result(day.getKey(), sum, average));
            }
        }
        return answer;
    }
}

本地语义参考 · 日期采用 YYYY-MM-DD，可按字符串排序

function restaurantGrowth(customer) {
  const daily = new Map();
  for (const row of customer) {
    daily.set(
      row.visited_on,
      (daily.get(row.visited_on) ?? 0) + row.amount
    );
  }

  const days = [...daily.entries()]
    .sort(([a], [b]) => a.localeCompare(b));
  const answer = [];
  let windowSum = 0;

  for (let right = 0; right < days.length; right += 1) {
    windowSum += days[right][1];
    if (right >= 7) windowSum -= days[right - 7][1];
    if (right >= 6) {
      answer.push({
        visited_on: days[right][0],
        amount: windowSum,
        average_amount: Number((windowSum / 7).toFixed(2)),
      });
    }
  }
  return answer;
}

本地语义参考 · 纯 Python 记录列表版本

from collections import defaultdict, deque
from decimal import Decimal, ROUND_HALF_UP

def restaurant_growth(customer: list[dict]) -> list[dict]:
    daily = defaultdict(int)
    for row in customer:
        daily[row["visited_on"]] += row["amount"]

    window = deque()
    window_sum = 0
    answer = []
    for visited_on in sorted(daily):
        amount = daily[visited_on]
        window.append(amount)
        window_sum += amount
        if len(window) > 7:
            window_sum -= window.popleft()
        if len(window) == 7:
            average = (Decimal(window_sum) / Decimal(7)).quantize(
                Decimal("0.01"), rounding=ROUND_HALF_UP
            )
            answer.append({
                "visited_on": visited_on,
                "amount": window_sum,
                "average_amount": average,
            })
    return answer

本地语义参考 · map 完成按日期聚合与排序

#include <cmath>
#include <deque>
#include <map>
#include <string>
#include <vector>
using namespace std;

struct Transaction {
    int customerId;
    string name;
    string visitedOn;
    int amount;
};
struct Result {
    string visitedOn;
    long long amount;
    double averageAmount;
};

vector<Result> restaurantGrowth(const vector<Transaction>& customer) {
    map<string, long long> daily;
    for (const auto& row : customer) daily[row.visitedOn] += row.amount;

    deque<long long> window;
    vector<Result> answer;
    long long sum = 0;
    for (const auto& [date, amount] : daily) {
        window.push_back(amount);
        sum += amount;
        if (window.size() > 7) {
            sum -= window.front();
            window.pop_front();
        }
        if (window.size() == 7) {
            double average =
                round(static_cast<double>(sum) / 7.0 * 100.0) / 100.0;
            answer.push_back({date, sum, average});
        }
    }
    return answer;
}

替代方案

日期范围自连接：先得到每日营业额，再让每个日期连接过去 6 天并聚合；直观但中间结果更大。

相关子查询：对每个日期重新扫描七日范围；写法直接，但大数据量下通常不如窗口函数高效。

不能直接在原表开 7 行窗口：一行代表一位顾客，不代表一天；同日多人会破坏“7 行等于 7 天”的前提。

常见错误

  • 未按日聚合，直接对顾客记录开窗口。
  • 用 AVG(amount) 得到每笔交易均值。
  • 保留前 6 个不完整窗口。
  • 除以顾客数，或忘记保留两位小数。
  • 误用 RANGE，使窗口语义受同值行影响。

面试追问

如果并非每天都有人到店呢？

“前 6 行”不再等于“前 6 个自然日”。可先用日历表补齐缺失日期为 0，再做 7 行窗口；或使用数据库支持的日期范围窗口。

为什么平均值固定除以 7？

题目定义完整七日周期；只有满 7 天的行才输出，因此分母恒为 7。

怎样支持任意窗口天数 k？

将窗口边界改为前 k−1 行，过滤计数为 k，并把总额除以 k。

如何优化超大表？

为日期建立合适索引或维护日汇总表，减少扫描与聚合成本；是否预聚合取决于查询频率和写入模式。
