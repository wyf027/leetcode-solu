FILE 01 · BRIEF

题意转述

给定一张固定为 9×9 的部分填写数独棋盘，只验证已填写的字符。每一行、每一列，以及九个 3×3 小宫内，数字 1 到 9 都不能重复。字符 "." 表示空格，不参与重复判断。

关键澄清：题目只问当前局面是否遵守规则，不要求证明它以后一定能被填成完整数独。

SOLUTION 01 · INSIGHT

核心洞察：一次扫描，三次查重

01 / ENCODE

把字符映射到 0…8

digit = board[r][c] - '1'，刚好对应 9 个布尔槽位。

02 / LOCATE

算出小宫编号

(r / 3) * 3 + c / 3 把二维宫坐标压成 0…8。

03 / REGISTER

查三本台账后登记

行、列或宫已有该数字就返回 false；否则同时标记为已出现。

面试记忆句

每个非点号单元格只问一件事：这个数字在“行 / 列 / 宫”三张身份证上是否都第一次出现？

SOLUTION 02 · PROCESS

完整解题过程

  1. 1

    建立三组 9×9 布尔表

    rows[r][d]、cols[c][d]、boxes[b][d] 分别记录数字 d 是否出现。

  2. 2

    按行优先扫描 81 格

    遇到 '.' 直接跳过；它不是数字，也不会占据任何台账。

  3. 3

    计算数字和宫下标

    数字下标为 ch - '1'；宫下标为 (r / 3) * 3 + c / 3。

  4. 4

    先查重，后统一登记

    任意一表为 true 就立即失败；三表都为 false 才把它们同时设为 true。

  5. 5

    完整扫描后返回 true

    所有已填数字均未冲突，当前棋盘就满足有效数独规则。

COMPLEXITY

O(1)

固定 9×9 时间

O(1)

固定 9×9 空间

若推广到 N×N 棋盘，扫描为 O(N²)，台账也为 O(N²)。

BOUNDARIES

  • • 全空棋盘有效：没有任何重复证据。
  • • 同一数字可出现在不同行、不同列、不同宫。
  • • 只在行或列不重复仍不够，必须检查 3×3 宫。
  • • 局面有效不等于一定可解，不做回溯搜索。

SOLUTION 03 · TRADE-OFF

替代方案与取舍

HashSet 字符串键

把 row-2-8、col-5-8、box-1-8 加入集合。代码直观，但会创建较多字符串对象。

位掩码

每行、列、宫用一个整数的 9 位记录，常数更小，但面试讲解和调试门槛更高。

三次独立扫描

分别查行、列、宫也正确；一次扫描的布尔台账更统一，也更容易早停。

SOLUTION 04 · INTERVIEW

面试高频追问

为什么宫编号公式成立？
整数除以 3 得到宫的行号和列号，再用 boxRow * 3 + boxCol 展平成 0…8。
为什么不需要回溯？
题目只验证当前填写是否冲突，不要求求解或证明可解性。
能压缩空间吗？
可以把每个 9 位布尔数组压为整数位掩码，但固定棋盘下两者渐进空间都是 O(1)。
如果尺寸变为 N² × N² 呢？
宫边长为 N，宫编号改为 (r / N) * N + c / N，整体扫描 O(N⁴)。

SOLUTION 05 · FAILURE MODES

常见错误

ERROR 01

把点号也登记

多个空格会被误判重复，必须先 continue。

ERROR 02

宫下标少乘 3

r / 3 + c / 3 会把不同宫混在一起。

ERROR 03

先登记再查重

当前数字会与自己冲突；应先检查三表，再统一标记。

ERROR 04

误做求解器

回溯求解超出题意，也会浪费面试时间。
