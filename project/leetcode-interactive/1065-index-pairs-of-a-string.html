字符串的索引对

在文本中寻找词典单词的每一次出现，并按起点、终点排序。先观察匹配过程，再选择是否展开完整题解。

EASY字符串字典树排序付费题

题目

给定字符串 text 和字符串数组 words。如果某个单词恰好等于 text[i..j]，就记录索引对 [i,j]（两端均包含）。返回全部索引对，先按 i 升序，再按 j 升序。

索引从 0 开始；匹配可以重叠。

函数签名

indexPairs(text, words) → integer[][]

text: string
words: string[]

官方示例（完整参数形式）

示例 1

输入：text = "thestoryofleetcodeandme",
      words = ["story","fleet","leetcode"]
输出：[[3,7],[9,13],[10,17]]

示例 2

输入：text = "ababa",
      words = ["aba","ab"]
输出：[[0,1],[0,2],[2,3],[2,4]]

约束

  • 1 ≤ text.length ≤ 100
  • 1 ≤ words.length ≤ 20
  • 1 ≤ words[i].length ≤ 50
  • 所有字符串仅包含小写英文字母。

完整题解

核心洞察

把所有单词放进字典树。对文本的每个起点 i，同时沿文本和树向右走；路径消失就停止，遇到单词结尾便加入 [i,j]。外层起点、内层终点均递增，答案天然有序。

完整过程

  1. 逐字插入每个单词，在末节点设置结束标记。
  2. 枚举每个文本起点，并把树指针重置到根。
  3. 从起点向右读字符；对应子节点不存在时立即停止此轮。
  4. 每到一个结束节点，就记录当前起点和终点。
  5. 直接返回收集结果，无需额外排序。

正确性

完备性：任何合法匹配对应的单词都已在树中，从其起点逐字读取必能到达带结束标记的终点，因此一定被记录。可靠性：只有走到结束节点才输出，此路径既是词典单词，也等于文本区间，所以输出均合法。两层索引递增保证顺序正确。

边界与复杂度

单字符、重叠匹配、前缀单词均由结束标记自然处理。设文本长度为 n，单词总字符数为 S，最长单词长度为 L：建树耗时和空间 O(S)，扫描 O(nL)，结果之外空间 O(S)。

替代方案

逐词查找更直观，但约为 O(n·words.length·L) 且需排序。规模很大时可用 Aho–Corasick 自动机，将多模式匹配推进到接近 O(S+n+答案数)。

面试追问

  • 为何不用排序？枚举次序已经是目标次序。
  • 怎样动态增删单词？插入路径，并维护经过计数和结束计数。
  • 词典特别大怎么办？压缩字典树、按首字母分组或使用 AC 自动机。

常见错误

  • 误把终点当开区间，输出 [i,j+1]。
  • 命中短词就停止，漏掉以它为前缀的长词。
  • 只找首次出现，漏掉重复和重叠匹配。

class Solution {
    static class Node { Node[] next = new Node[26]; boolean end; }
    public int[][] indexPairs(String text, String[] words) {
        Node root = new Node();
        for (String word : words) {
            Node p = root;
            for (char c : word.toCharArray()) {
                int k = c - 'a';
                if (p.next[k] == null) p.next[k] = new Node();
                p = p.next[k];
            }
            p.end = true;
        }
        java.util.List<int[]> ans = new java.util.ArrayList<>();
        for (int i = 0; i < text.length(); i++) {
            Node p = root;
            for (int j = i; j < text.length(); j++) {
                p = p.next[text.charAt(j) - 'a'];
                if (p == null) break;
                if (p.end) ans.add(new int[]{i, j});
            }
        }
        return ans.toArray(new int[ans.size()][]);
    }
}

from typing import List

class Solution:
    def indexPairs(self, text: str, words: List[str]) -> List[List[int]]:
        root, END = {}, "#"
        for word in words:
            node = root
            for ch in word:
                node = node.setdefault(ch, {})
            node[END] = True
        ans = []
        for i in range(len(text)):
            node = root
            for j in range(i, len(text)):
                if text[j] not in node:
                    break
                node = node[text[j]]
                if END in node:
                    ans.append([i, j])
        return ans
