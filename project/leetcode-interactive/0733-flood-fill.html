Problem 733 · Matrix traversal

图像渲染Flood Fill

从一个像素出发，把与它上下左右连通、且颜色相同的整片区域换成新颜色。

简单 EASY深度优先搜索 广度优先搜索数组矩阵

Problem

题目描述

识别与起点属于同一连通区域的像素，并完成一次颜色替换。

给定一个由 m × n 整数网格表示的图像 image，其中 image[i][j] 是像素颜色值；另给起点行 sr、起点列 sc 和目标颜色 color。

从 image[sr][sc] 开始，将起点以及所有通过上、下、左、右相连、且颜色等于起点原始颜色的像素改为 color。当没有更多符合条件的相邻像素时停止，并返回修改后的图像。

对角线不算相邻。即使某个像素颜色相同，只要无法沿四方向同色路径抵达，也不能被修改。

Solution

题解：只沿“原始颜色”扩张

把矩阵看成一张图：每个像素是节点，上下左右是边。本解采用广度优先搜索。

01 · SNAPSHOT

先保存起点原色

后续始终与 oldColor 比较，不要把已修改的起点值当作基准。

02 · GUARD

相同颜色直接返回

若 oldColor == color，改色无法充当访问标记，搜索可能重复进行。

03 · MARK EARLY

入队时立即改色

发现合格邻居时就改色并入队，同时完成 visited 标记，避免重复入队。

04 · FOUR WAYS

只检查四个方向

方向固定为上、下、左、右；对角线相同颜色不构成连通。

完整过程

  1. 读取 oldColor = image[sr][sc]；若它与 color 相同，直接返回。
  2. 将起点改成新颜色并放入队列，改色也标记它已被发现。
  3. 不断取出队首坐标，枚举它的四个相邻位置。
  4. 邻居未越界且仍为 oldColor 时，立即改色并入队。
  5. 队列为空时，返回已经修改的图像。

正确性说明

不会漏染：起点先被染色。对任意与起点四向连通的原色像素，沿一条同色路径归纳：当前一个像素被处理时，下一个像素一定因未越界且仍为原色而被染色入队。

不会误染：算法只从已抵达像素沿四方向扩张，并且只接纳值为 oldColor 的邻居，因此每个被修改像素都有一条原色四向路径回到起点。

必然终止：像素入队时立刻改色；新旧颜色不同时，它不会再次满足入队条件。矩阵有限，队列最终为空。

结论：被改色的集合恰好是起点所在的原色四连通分量。

复杂度

O(m × n)时间：最坏访问整张图，每个像素至多入队一次。
O(m × n)空间：队列最坏可容纳线性数量的像素。

边界情况

  • 新旧颜色相同：必须提前返回。
  • 单行、单列或单像素：统一的越界判断已覆盖。
  • 对角线同色：不属于四连通区域。
  • 起点被异色包围：只修改起点，队列随即清空。
  • 较大颜色值：小于 2^16，普通整数足够。

Implementations

四语言完整代码

四份实现均采用“入队即改色”的 BFS。

JavaQueue<int[]>
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int[][] floodFill(int[][] image, int sr, int sc, int color) {
        int oldColor = image[sr][sc];
        if (oldColor == color) return image;

        int rows = image.length;
        int cols = image[0].length;
        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        Queue<int[]> queue = new ArrayDeque<>();
        image[sr][sc] = color;
        queue.offer(new int[]{sr, sc});

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            for (int[] dir : dirs) {
                int nr = cur[0] + dir[0];
                int nc = cur[1] + dir[1];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                        && image[nr][nc] == oldColor) {
                    image[nr][nc] = color;
                    queue.offer(new int[]{nr, nc});
                }
            }
        }
        return image;
    }
}
JavaScript数组队列 + head
/**
 * @param {number[][]} image
 * @param {number} sr
 * @param {number} sc
 * @param {number} color
 * @return {number[][]}
 */
var floodFill = function(image, sr, sc, color) {
    const oldColor = image[sr][sc];
    if (oldColor === color) return image;

    const rows = image.length;
    const cols = image[0].length;
    const dirs = [[-1, 0], [1, 0], [0, -1], [0, 1]];
    const queue = [[sr, sc]];
    let head = 0;
    image[sr][sc] = color;

    while (head < queue.length) {
        const [row, col] = queue[head++];
        for (const [dr, dc] of dirs) {
            const nr = row + dr;
            const nc = col + dc;
            if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                    && image[nr][nc] === oldColor) {
                image[nr][nc] = color;
                queue.push([nr, nc]);
            }
        }
    }
    return image;
};
Pythoncollections.deque
from collections import deque
from typing import List


class Solution:
    def floodFill(
        self,
        image: List[List[int]],
        sr: int,
        sc: int,
        color: int
    ) -> List[List[int]]:
        old_color = image[sr][sc]
        if old_color == color:
            return image

        rows, cols = len(image), len(image[0])
        dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        queue = deque([(sr, sc)])
        image[sr][sc] = color

        while queue:
            row, col = queue.popleft()
            for dr, dc in dirs:
                nr, nc = row + dr, col + dc
                if (0 <= nr < rows and 0 <= nc < cols
                        and image[nr][nc] == old_color):
                    image[nr][nc] = color
                    queue.append((nr, nc))

        return image
C++std::queue
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> floodFill(
        vector<vector<int>>& image, int sr, int sc, int color
    ) {
        int oldColor = image[sr][sc];
        if (oldColor == color) return image;

        int rows = static_cast<int>(image.size());
        int cols = static_cast<int>(image[0].size());
        int dirs[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        queue<pair<int, int>> pending;
        image[sr][sc] = color;
        pending.push({sr, sc});

        while (!pending.empty()) {
            auto [row, col] = pending.front();
            pending.pop();
            for (const auto& dir : dirs) {
                int nr = row + dir[0];
                int nc = col + dir[1];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                        && image[nr][nc] == oldColor) {
                    image[nr][nc] = color;
                    pending.push({nr, nc});
                }
            }
        }
        return image;
    }
};

替代方案

递归 DFS

代码更短：遇到原色就改色，再递归四邻域。时间复杂度相同，但大连通块会增加调用栈深度。

显式栈 DFS

把 BFS 队列换成栈，避免递归栈风险。搜索顺序不同，最终渲染集合相同。

面试追问

为什么入队时改色？

它会立即标记已发现，阻止同一坐标被多个邻居重复入队。

允许八方向连通怎么办？

把方向数组扩充成八个方向即可，框架与复杂度不变。

不能修改输入矩阵怎么办？

复制结果矩阵或维护 visited 集合，额外使用 O(mn) 空间。

BFS 与 DFS 如何选择？

两者时间复杂度相同；BFS 避免深递归，递归 DFS 更简短。

常见错误

  • 改完起点后才读取原色，导致比较基准变成新颜色。
  • 漏掉新旧颜色相同的提前返回，造成重复访问。
  • 出队时才标记访问，让同一坐标多次入队。
  • 把对角线当成邻居，误染其他连通分量。
  • 先访问邻居再判断边界，引发数组越界。
  • JavaScript 反复使用 shift()；head 指针可避免线性移动。
