重新排列后的
最大子矩阵

Largest Submatrix With Rearrangements

一张只由 0 和 1 构成的矩阵，允许你把整列换到任意位置。目标很直观：重新排好后，找出面积最大的全 1 子矩阵。

移动的是整列

一列中的元素必须一起移动，不能单独重排某一行。先理解这个边界，再进入下方实验。

Problem

题目描述

给定大小为 m × n 的二进制矩阵 matrix。你可以任意重新排列矩阵的列。请返回在最优列排列下，元素全部为 1 的最大子矩阵面积。

参数与返回值：输入参数为 matrix: integer[][]，返回一个整数，表示可得到的最大面积。

示例 1

输入：matrix = [[0,0,1],[1,1,1],[1,0,1]]
输出：4

调整列顺序后，可以得到一个面积为 4 的全 1 子矩阵。

示例 2

输入：matrix = [[1,0,1,0,1]]
输出：3

唯一一行中有 3 个 1，可把它们排到相邻位置。

示例 3

输入：matrix = [[1,1,0],[1,0,1]]
输出：2

只能移动整列，因此不存在面积大于 2 的全 1 子矩阵。

示例 4

输入：matrix = [[0,0],[0,0]]
输出：0

矩阵中没有 1，所以最大面积为 0。

约束

  • m == matrix.length
  • n == matrix[i].length
  • 1 <= m × n <= 105
  • matrix[i][j] 只能是 0 或 1

Solution

准备好揭晓了吗？

题解被独立收起，实验不会自动展开答案。先在脑中回答：为什么每一行都值得被当作矩形的底边？

Deep Dive

题解：累计高度 + 每行排序

核心洞察

!

固定矩形底边后，问题就变成选高度

令 heights[j] 表示第 j 列在当前行向上连续出现 1 的数量。若把这些高度降序排列，那么选择前 k 列时，能保证的矩形高度就是第 k 个高度，面积为 k × heights[k - 1]。

完整过程

维护高度。逐行扫描。当前格为 1 时，对应高度加 1；为 0 时，高度归零。

复制并排序。对当前高度数组创建副本，按降序排列。排序表示：对于以当前行为底边的候选矩形，我们可以选择一个最有利的整列排列。

枚举宽度。降序数组下标为 i 时，前 i + 1 列的最低高度为 sorted[i]，候选面积是 sorted[i] × (i + 1)。

更新答案。对每一行、每一种宽度更新全局最大值，最终即为答案。

为什么正确

  1. 高度准确性：处理到第 r 行时，heights[j] 恰好记录列 j 中以第 r 行结尾的连续 1 数量。因此，任何以第 r 行为底边的全 1 矩形，其各列可用高度都由该数组完整描述。
  2. 排序最优性：固定宽度 k 后，最优选择必然是高度最大的 k 列；它们能共同达到的最大高度等于这 k 列中的最小值，即降序后的 sorted[k - 1]。
  3. 枚举完备性：算法枚举每个底边行与每个宽度，因而包含了任意最优矩形的底边和宽度。该候选的面积会被计算，答案不会小于最优值；所有计算出的候选又都能通过整列重排真实形成，所以答案不会超过最优值。两者相等。

边界情况

  • 全 0：所有高度始终为 0，答案为 0。
  • 单行：答案就是该行 1 的数量。
  • 单列：答案是最长连续 1 的长度。
  • 全 1：最终答案为 m × n。

常见错误

  • 直接在原高度数组上排序，破坏列与下一行的对应关系。
  • 把“整列重排”误解为每一行可独立重排元素。
  • 面积宽度误写成下标 i，正确是 i + 1。
  • 遇到 0 时忘记把累计高度清零。

复杂度

时间复杂度
O(m · n log n)

每一行更新高度需要 O(n)，排序需要 O(n log n)。

空间复杂度
O(n)

维护高度数组及其排序副本，不计排序实现的内部栈空间。

替代方案

由于高度最大不超过 m，可以在每一行用计数数组统计各高度的出现次数，再从高到低累计宽度，将排序优化为计数过程。这样时间可达 O(m · (n + m))，但实现更长；在约束 m × n ≤ 105 下，直接排序通常更清晰。

四语言完整实现

Java · 官方提交签名O(m · n log n)
import java.util.Arrays;

class Solution {
    public int largestSubmatrix(int[][] matrix) {
        int cols = matrix[0].length;
        int[] heights = new int[cols];
        int answer = 0;

        for (int[] row : matrix) {
            for (int col = 0; col < cols; col++) {
                heights[col] = row[col] == 0 ? 0 : heights[col] + 1;
            }

            int[] sorted = heights.clone();
            Arrays.sort(sorted);
            for (int i = 0; i < cols; i++) {
                int width = cols - i;
                answer = Math.max(answer, sorted[i] * width);
            }
        }
        return answer;
    }
}

/**
 * @param {number[][]} matrix
 * @return {number}
 */
var largestSubmatrix = function(matrix) {
    const cols = matrix[0].length;
    const heights = new Array(cols).fill(0);
    let answer = 0;

    for (const row of matrix) {
        for (let col = 0; col < cols; col++) {
            heights[col] = row[col] === 0 ? 0 : heights[col] + 1;
        }

        const sorted = [...heights].sort((a, b) => b - a);
        for (let i = 0; i < cols; i++) {
            answer = Math.max(answer, sorted[i] * (i + 1));
        }
    }
    return answer;
};
Python 3 · 官方提交签名O(m · n log n)
from typing import List

class Solution:
    def largestSubmatrix(self, matrix: List[List[int]]) -> int:
        cols = len(matrix[0])
        heights = [0] * cols
        answer = 0

        for row in matrix:
            for col in range(cols):
                heights[col] = heights[col] + 1 if row[col] == 1 else 0

            sorted_heights = sorted(heights, reverse=True)
            for index, height in enumerate(sorted_heights):
                answer = max(answer, height * (index + 1))

        return answer

class Solution {
public:
    int largestSubmatrix(vector<vector<int>>& matrix) {
        const int cols = matrix[0].size();
        vector<int> heights(cols, 0);
        int answer = 0;

        for (const auto& row : matrix) {
            for (int col = 0; col < cols; ++col) {
                heights[col] = row[col] == 0 ? 0 : heights[col] + 1;
            }

            vector<int> sorted = heights;
            sort(sorted.begin(), sorted.end(), greater<int>());
            for (int i = 0; i < cols; ++i) {
                answer = max(answer, sorted[i] * (i + 1));
            }
        }
        return answer;
    }
};

面试追问

为什么必须复制高度数组再排序？

原始 heights 的下标与真实列绑定，下一行更新时仍要沿用该对应关系。若原地排序，就无法知道下一行每个格子该累加到哪一列。

每一行排序，是否意味着列可以反复用不同顺序重排？

算法只是在评估“以某一行为底边”的最优候选。最终只需实现全局最优候选对应的那一次列排列，并不要求同一个结果矩阵同时满足所有行的评估顺序。

能否做到 O(m · n)？

可利用高度范围不超过 m 做计数统计；复杂度依维度关系而定。若将较小维度用于高度范围，还可进一步讨论转置和工程取舍。
