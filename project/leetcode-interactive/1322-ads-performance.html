广告效果Ads Performance

把广告事件汇总为点击率：只让“点击”和“浏览”进入分母，正确处理全是忽略事件的广告，再按表现稳定排序。

EASY付费题数据库聚合 · 条件计数 · 排序
Problem

题目转述

先理解指标，再展开题解

表 Ads 记录用户与广告的交互。每条记录由广告编号 ad_id、用户编号 user_id 和行为 action 组成；行为只能是 Clicked、Viewed 或 Ignored。

请为每个出现过的广告计算点击率 ctr，结果保留两位小数。输出先按点击率降序排列；点击率相同时，再按 ad_id 升序排列。

CTR = Clicked ÷ (Clicked + Viewed) × 100

关键定义：Ignored 不进入分子，也不进入分母。如果某个广告没有任何点击或浏览，其点击率定义为 0.00。

表结构与约束

列类型含义
ad_idINT广告编号
user_idINT用户编号
actionENUMClicked / Viewed / Ignored
  • (ad_id, user_id) 唯一标识一条广告—用户记录。
  • 每个广告至少在表中出现一次。
  • 数据库结果中的小数需按要求舍入到两位。

Core insight

一次分组，同时完成两个条件计数

按 ad_id 分组后，用两个 SUM(CASE ...) 分别得到点击数和有效曝光数（点击 + 浏览）。再用 NULLIF(分母, 0) 阻止除零，用 COALESCE(..., 0) 把该情况映射为题目定义的 0。

完整过程

  1. GROUP BY ad_id：把同一广告的事件放入一个分组。
  2. 条件计数：点击事件贡献给分子；点击或浏览事件贡献给分母；忽略事件都贡献 0。
  3. 安全相除：先把 0 分母变成 NULL，相除后再回填 0。
  4. 百分比与舍入：乘 100，并用 ROUND(..., 2) 保留两位小数。
  5. 稳定排序：ctr DESC, ad_id ASC。

边界情况

  • 只有 Ignored：分母为 0，CTR 为 0.00。
  • 只有 Clicked：CTR 为 100.00。
  • 只有 Viewed：CTR 为 0.00，但分母不为 0。
  • 多条记录产生循环小数：最后统一舍入两位。
  • CTR 相同：必须按 ad_id 升序决定次序。

正确性说明

1
分组完整。按 ad_id 分组，因此每个输出行恰好对应一个广告，且该广告的所有事件都在其分组中。
2
计数准确。第一个条件和只在行为为 Clicked 时加 1，所以等于点击数；第二个条件和只在 Clicked 或 Viewed 时加 1，所以等于题目定义的有效事件数。
3
比率符合定义。分母非零时，表达式正好计算 点击数 / 有效事件数 × 100；分母为零时，NULLIF 与 COALESCE 共同得到 0。
4
输出满足要求。ROUND 产生两位小数，最后的双关键字排序给出规定顺序。因此查询对每个广告都返回正确 CTR 和顺序。

复杂度

设记录数为 n、广告数为 k。聚合扫描约为 O(n)；结果排序为 O(k log k)。分组状态约需 O(k) 空间，具体由数据库执行计划决定。

替代方案

可先在子查询或 CTE 中算出 clicks 与 denominator，再在外层计算 CTR 和排序，可读性更强。也可用 AVG 配合过滤有效事件，但仍必须保留仅含 Ignored 的广告，连接和空值处理更复杂。

常见错误

  • 把 Ignored 计入分母。
  • 整数除法导致小数丢失。
  • 直接除以 0。
  • 先舍入比例再乘 100。
  • 遗漏并列时的 ad_id 排序。

提交说明：本题是数据库题，MySQL 是官方可提交主解。Java、JavaScript、Python、C++ 仅为本地语义参考，用数组模拟表数据与分组，不代表 LeetCode 本题可提交语言。

SELECT
    ad_id,
    ROUND(
        COALESCE(
            100.0 * SUM(CASE WHEN action = 'Clicked' THEN 1 ELSE 0 END)
            / NULLIF(
                SUM(CASE WHEN action IN ('Clicked', 'Viewed') THEN 1 ELSE 0 END),
                0
            ),
            0
        ),
        2
    ) AS ctr
FROM Ads
GROUP BY ad_id
ORDER BY ctr DESC, ad_id ASC;
import java.util.*;

class Solution {
    record AdEvent(int adId, int userId, String action) {}
    record Result(int adId, double ctr) {}

    public static List<Result> adsPerformance(List<AdEvent> rows) {
        Map<Integer, int[]> counts = new HashMap<>();
        for (AdEvent row : rows) {
            int[] count = counts.computeIfAbsent(row.adId(), id -> new int[2]);
            if (row.action().equals("Clicked")) {
                count[0]++; // clicks
                count[1]++; // clicked + viewed
            } else if (row.action().equals("Viewed")) {
                count[1]++;
            }
        }

        List<Result> answer = new ArrayList<>();
        for (Map.Entry<Integer, int[]> entry : counts.entrySet()) {
            int[] count = entry.getValue();
            double ctr = count[1] == 0 ? 0.0 : 100.0 * count[0] / count[1];
            ctr = Math.round(ctr * 100.0) / 100.0;
            answer.add(new Result(entry.getKey(), ctr));
        }
        answer.sort(Comparator.comparingDouble(Result::ctr).reversed()
                .thenComparingInt(Result::adId));
        return answer;
    }
}
function adsPerformance(rows) {
  const counts = new Map();

  for (const { ad_id, action } of rows) {
    if (!counts.has(ad_id)) counts.set(ad_id, { clicks: 0, valid: 0 });
    const count = counts.get(ad_id);
    if (action === "Clicked") {
      count.clicks += 1;
      count.valid += 1;
    } else if (action === "Viewed") {
      count.valid += 1;
    }
  }

  return [...counts.entries()]
    .map(([ad_id, { clicks, valid }]) => ({
      ad_id,
      ctr: valid === 0 ? 0 : Math.round((10000 * clicks) / valid) / 100,
    }))
    .sort((a, b) => b.ctr - a.ctr || a.ad_id - b.ad_id);
}
from collections import defaultdict
from typing import TypedDict

class AdEvent(TypedDict):
    ad_id: int
    user_id: int
    action: str

def ads_performance(rows: list[AdEvent]) -> list[dict[str, int | float]]:
    counts: dict[int, list[int]] = defaultdict(lambda: [0, 0])

    for row in rows:
        ad_id, action = row["ad_id"], row["action"]
        if action == "Clicked":
            counts[ad_id][0] += 1  # clicks
            counts[ad_id][1] += 1  # clicked + viewed
        elif action == "Viewed":
            counts[ad_id][1] += 1

    answer = []
    for ad_id, (clicks, valid) in counts.items():
        ctr = 0.0 if valid == 0 else round(100.0 * clicks / valid, 2)
        answer.append({"ad_id": ad_id, "ctr": ctr})

    return sorted(answer, key=lambda row: (-row["ctr"], row["ad_id"]))
#include <algorithm>
#include <cmath>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct AdEvent { int adId; int userId; string action; };
struct Result { int adId; double ctr; };

vector<Result> adsPerformance(const vector<AdEvent>& rows) {
    unordered_map<int, pair<int, int>> counts; // clicks, valid
    for (const auto& row : rows) {
        auto& [clicks, valid] = counts[row.adId];
        if (row.action == "Clicked") {
            ++clicks;
            ++valid;
        } else if (row.action == "Viewed") {
            ++valid;
        }
    }

    vector<Result> answer;
    for (const auto& [adId, count] : counts) {
        const auto [clicks, valid] = count;
        double ctr = valid == 0 ? 0.0 : 100.0 * clicks / valid;
        ctr = round(ctr * 100.0) / 100.0;
        answer.push_back({adId, ctr});
    }
    sort(answer.begin(), answer.end(), [](const Result& a, const Result& b) {
        if (a.ctr != b.ctr) return a.ctr > b.ctr;
        return a.adId < b.adId;
    });
    return answer;
}

面试追问

  • 为什么不用 COUNT(action = 'Clicked')？ 因为布尔表达式为假时仍是非 NULL，COUNT 可能把它计入；条件 SUM 更清晰。
  • 如果要按天统计？ 在分组键加入日期，并明确时区与日期截断规则。
  • 如果要求展示从未发生事件的广告？ 需要从广告主表出发 LEFT JOIN Ads，当前单表只能返回出现过的广告。
  • 如何避免浮点差异？ 数据库中可显式转 DECIMAL，并只在最终输出处 ROUND。
