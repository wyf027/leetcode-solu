Find Closest Number to Zero

在一组正负整数中寻找离原点最近的那个值。先理解选择规则，再亲手推进数轴实验。

01 / 题目与示例

输入长度为 n 的整数数组 nums，返回数组里与 0 距离最小的数字本身。如果距离最小的数字不止一个，返回其中数值最大的那个。

官方示例 1

输入：nums = [-4,-2,1,4,8]
输出：1

各元素到 0 的距离依次为 4、2、1、4、8。距离最小的是 1，因此返回 1。

官方示例 2

输入：nums = [2,-1,1]
输出：1

-1 与 1 到 0 的距离均为 1；两者中 1 更大，因此返回 1。

约束：1 ≤ n = nums.length ≤ 1000；-10⁵ ≤ nums[i] ≤ 10⁵。返回类型为整数，数组非空。

04 / 独立题解

先尝试描述你自己的选择规则，再展开推导与代码。

核心洞察：距离优先，数值次之

比较的是二元优先级 (|x|, -x)，取字典序最小者：先选绝对值更小的数，绝对值相同时选数值更大的数。无需排序，只需维护已扫描部分的最佳候选 best。

完整过程

  1. 将 best 初始化为 nums[0]，保证它确实来自输入数组。
  2. 从下标 1 开始扫描。如果 |x| < |best|，更新候选；如果距离相等且 x > best，也更新候选。
  3. 扫描结束返回 best。

以 nums = [2,-1,1] 为例：初始化为 2；-1 的距离为 1，小于 2，候选变成 -1；最后 1 的距离也为 1，但 1 大于 -1，最终返回 1。

为什么正确

循环不变量：处理完下标 i 后，best 是前缀 nums[0..i] 中距离最小且同距时数值最大的元素。

初始前缀只有一个元素，不变量成立。每轮新增 x，如果 x 按上述规则优于 best，就用 x 替换；否则保留已有最优值。因此新前缀仍满足不变量。遍历完成时前缀覆盖整个数组，best 即所求答案。

边界与复杂度

  • 单元素数组直接返回该元素。全负数也按绝对值比较，不能直接找最小整数。
  • 包含 0 时答案为 0，可提前返回；下面的代码保持统一扫描流程。
  • 同距异号时正数胜出，重复相同值无需更新；输入顺序不影响结果。
  • 时间 O(n)，额外空间 O(1)，不修改输入。交互页面为回放而重新计算前缀、绘制元素，其开销不等同于提交算法。
  • 官方数值范围内 Java/C++ 的整数绝对值安全；若扩大到最小有符号整数，必须先转更宽类型再取绝对值。

四语言完整提交代码

Java

class Solution {
    public int findClosestNumber(int[] nums) {
        int best = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];
            if (Math.abs(x) < Math.abs(best) ||
                (Math.abs(x) == Math.abs(best) && x > best)) {
                best = x;
            }
        }
        return best;
    }
}

C++

#include <vector>
#include <cstdlib>
using namespace std;

class Solution {
public:
    int findClosestNumber(vector<int>& nums) {
        int best = nums[0];
        for (int i = 1; i < static_cast<int>(nums.size()); ++i) {
            int x = nums[i];
            if (std::abs(x) < std::abs(best) ||
                (std::abs(x) == std::abs(best) && x > best)) {
                best = x;
            }
        }
        return best;
    }
};

替代方案

可以按“绝对值升序、原值降序”排序后取首项，但需要 O(n log n) 时间，且原地排序会改变输入。也可以先求最小绝对值 d，再判断数组中是否存在 d：存在则返回 d，否则返回 -d；两次线性扫描仍是 O(n) 时间、O(1) 额外空间。单次扫描直接保存候选更简洁。

常见错误

  • 把 best 初始化为 0：当数组不含 0 时，会留下不存在的答案。
  • 只在绝对值更小时更新：[-1,1] 会错误保留 -1。
  • 绝对值小于等于就更新：[1,-1] 会错误返回 -1。
  • 返回最小绝对值而非原值：[-3,-2] 应返回 -2，不是 2。
  • Python 使用 nums[1:] 进行遍历会创建切片，额外空间不再是 O(1)。

面试追问

  • 改为最接近任意目标 t？比较 |x-t|，同距时仍取较大值。
  • 输入是数据流？首个元素初始化，此后只维护 best，即可在线更新。
  • 数组已排序？可二分查找 0 的插入位置，比较左右相邻元素，时间 O(log n)。
  • 为什么不能一遇到正数就结束？未处理部分可能存在绝对值更小的负数或 0；只有距离为 0 才已达到全局下界。
