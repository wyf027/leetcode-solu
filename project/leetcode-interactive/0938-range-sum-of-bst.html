938. 二叉搜索树的范围和

Range Sum of BST · 树 / 深度优先搜索 / 二叉搜索树

先观察搜索如何借助 BST 的有序性，避开整片不可能命中的子树。

题目

给定二叉搜索树的根节点 root 和整数 low、high，返回所有节点值位于闭区间 [low, high] 中的节点值之和。

示例 1

输入：root = [10,5,15,3,7,null,18], low = 7, high = 15
输出：32
说明：7 + 10 + 15 = 32。

示例 2

输入：root = [10,5,15,3,7,13,18,1,null,6], low = 6, high = 10
输出：23
说明：6 + 7 + 10 = 23。

约束与签名

  • 节点数 1 ≤ n ≤ 2 × 10⁴
  • 1 ≤ Node.val ≤ 10⁵
  • 1 ≤ low ≤ high ≤ 10⁵
  • 所有节点值互不相同

rangeSumBST(root, low, high) → integer

题解：利用 BST 有序性剪枝

核心洞察：当前值太小时，左子树全部更小；当前值太大时，右子树全部更大。因此可以跳过整棵不可能命中的子树。

完整过程

  1. 空节点返回 0。
  2. node.val < low：舍弃左子树，只查右子树。
  3. node.val > high：舍弃右子树，只查左子树。
  4. 否则计入当前值，并递归左右子树。

正确性

若当前值小于 low，BST 左子树所有值更小，必不合法；大于 high 时右子树同理。当前值在区间内时，算法计入它并递归互不重叠的左右子树。因而每个合法节点恰好计入一次，所有被剪枝节点都不合法，返回值即所求范围和。

边界

  • low = high 时仍是闭区间。
  • 根在范围外时，只搜索可能命中的一侧。
  • 全部命中时访问整棵树；退化树递归深度可达 n。

复杂度

实际访问 k 个节点，时间 O(k)，最坏 O(n)；递归空间 O(h)，h 为树高。

替代方案

完整 DFS 不剪枝也正确但总访问 n 个节点；显式栈可避免深递归；中序遍历能按序处理并在超过 high 后停止。

面试追问

  • 大量不同区间查询时，如何维护子树和？
  • 若不是 BST，为什么剪枝失效？
  • 如何改写成迭代版本？

常见错误

  • 把闭区间写成严格不等式。
  • 把值太小时的剪枝方向写反。
  • 命中当前节点后只搜索一侧。
  • 忘记处理空节点。

四种语言完整代码

Java
class Solution {
  public int rangeSumBST(TreeNode root, int low, int high) {
    if (root == null) return 0;
    if (root.val < low) return rangeSumBST(root.right, low, high);
    if (root.val > high) return rangeSumBST(root.left, low, high);
    return root.val + rangeSumBST(root.left, low, high)
                    + rangeSumBST(root.right, low, high);
  }
}
JavaScript
var rangeSumBST = function(root, low, high) {
  if (root === null) return 0;
  if (root.val < low) return rangeSumBST(root.right, low, high);
  if (root.val > high) return rangeSumBST(root.left, low, high);
  return root.val
    + rangeSumBST(root.left, low, high)
    + rangeSumBST(root.right, low, high);
};

C++
class Solution {
public:
  int rangeSumBST(TreeNode* root, int low, int high) {
    if (root == nullptr) return 0;
    if (root->val < low)
      return rangeSumBST(root->right, low, high);
    if (root->val > high)
      return rangeSumBST(root->left, low, high);
    return root->val
      + rangeSumBST(root->left, low, high)
      + rangeSumBST(root->right, low, high);
  }
};
