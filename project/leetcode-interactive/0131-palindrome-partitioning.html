The cutting brief

题意转述

给定字符串 s，把它分割成若干连续子串，要求每一段都是回文串；返回全部可能的分割方案。顺序可以不同，但不能漏解或重复。

Material

1 <= s.length <= 16，且 s 只含小写英文字母。

Valid segment

长度为 1 的子串天然回文；更长子串需要首尾相同，内部也为回文。

Deliverable

返回所有完整覆盖原字符串的方案；每个字符恰好属于其中一段。

题解

核心洞察

每个方案由一连串“下一刀切在哪里”的选择构成。用 pal[i][j] 预处理子串是否回文后，回溯时可以 O(1) 判断当前候选，避免反复扫描同一段。

完整过程

  1. 按子串长度递增，填好回文表：首尾相等，且长度不超过 2 或内部已经回文。
  2. 令 start = 0，枚举 end；跳过非回文的 s[start..end]。
  3. 把合法子串加入路径，递归处理 end + 1。
  4. 到达字符串末尾时复制路径；返回后移除末段，尝试下一个结尾。

边界与不变量

  • 单字符一定能切，因此递归总能到达叶子。
  • path 中每一段都已经由回文表验证。
  • path 拼接后始终等于原串前缀 s[0..start)。
  • 保存答案必须复制路径，否则后续回退会修改已保存结果。

复杂度

预处理O(n²) 时间 / O(n²) 空间
枚举最坏 O(n · 2ⁿ)，输出本身即可达到该量级
递归栈O(n)，不计答案存储
候选判断每次 O(1)

替代方案取舍

  • 每次双指针判断：代码更短、额外空间 O(n)，但相同子串会被重复检查，适合先写出正确版本。
  • 中心扩展：也能预先收集回文区间，但与按起点枚举的回溯衔接不如二维表直接。
  • 位掩码枚举切口：直观但会检查大量无效方案，不是面试首选。

面试追问

  • 若只求最少切割次数，改成一维 DP：cuts[i] 表示前 i 个字符的最少切割。
  • 若结果太多，接口可以改成迭代器或通过回调流式产出，避免一次性占用内存。
  • 回文表能否降到 O(n) 空间？能，但会失去任意区间 O(1) 查询，需重新权衡。

常见错误

  • 递归传入 end 而不是 end + 1，导致重复或死循环。
  • 忘记在递归返回后 pop，使不同分支相互污染。
  • 把路径引用直接加入答案，没有创建副本。
  • 回文表填充顺序错误，在内部区间尚未计算时就读取它。

为什么推荐它

这个组合把“合法性查询”和“方案枚举”分离：DP 负责回答能不能切，回溯负责回答怎样列全。状态定义清楚、证明容易、四种语言都能稳定写出。 

class Solution {
    public List<List<String>> partition(String s) {
        int n = s.length();
        boolean[][] pal = new boolean[n][n];
        for (int i = n - 1; i >= 0; i--) {
            for (int j = i; j < n; j++) {
                pal[i][j] = s.charAt(i) == s.charAt(j)
                        && (j - i <= 2 || pal[i + 1][j - 1]);
            }
        }

        List<List<String>> answer = new ArrayList<>();
        dfs(0, s, pal, new ArrayList<>(), answer);
        return answer;
    }

    private void dfs(int start, String s, boolean[][] pal,
                     List<String> path, List<List<String>> answer) {
        if (start == s.length()) {
            answer.add(new ArrayList<>(path));
            return;
        }
        for (int end = start; end < s.length(); end++) {
            if (!pal[start][end]) continue;
            path.add(s.substring(start, end + 1));
            dfs(end + 1, s, pal, path, answer);
            path.remove(path.size() - 1);
        }
    }
}
var partition = function (s) {
  const n = s.length;
  const pal = Array.from({ length: n }, () => Array(n).fill(false));

  for (let i = n - 1; i >= 0; i--) {
    for (let j = i; j < n; j++) {
      pal[i][j] = s[i] === s[j] && (j - i <= 2 || pal[i + 1][j - 1]);
    }
  }

  const answer = [];
  const path = [];
  const dfs = (start) => {
    if (start === n) {
      answer.push([...path]);
      return;
    }
    for (let end = start; end < n; end++) {
      if (!pal[start][end]) continue;
      path.push(s.slice(start, end + 1));
      dfs(end + 1);
      path.pop();
    }
  };

  dfs(0);
  return answer;
};
class Solution:
    def partition(self, s: str) -> List[List[str]]:
        n = len(s)
        pal = [[False] * n for _ in range(n)]

        for i in range(n - 1, -1, -1):
            for j in range(i, n):
                pal[i][j] = s[i] == s[j] and (
                    j - i <= 2 or pal[i + 1][j - 1]
                )

        answer = []
        path = []

        def dfs(start: int) -> None:
            if start == n:
                answer.append(path.copy())
                return
            for end in range(start, n):
                if not pal[start][end]:
                    continue
                path.append(s[start:end + 1])
                dfs(end + 1)
                path.pop()

        dfs(0)
        return answer
class Solution {
public:
    vector<vector<string>> partition(string s) {
        int n = static_cast<int>(s.size());
        vector<vector<bool>> pal(n, vector<bool>(n, false));
        for (int i = n - 1; i >= 0; --i) {
            for (int j = i; j < n; ++j) {
                pal[i][j] = s[i] == s[j]
                    && (j - i <= 2 || pal[i + 1][j - 1]);
            }
        }
        dfs(0, s, pal);
        return answer;
    }

private:
    vector<vector<string>> answer;
    vector<string> path;

    void dfs(int start, const string& s,
             const vector<vector<bool>>& pal) {
        if (start == static_cast<int>(s.size())) {
            answer.push_back(path);
            return;
        }
        for (int end = start; end < static_cast<int>(s.size()); ++end) {
            if (!pal[start][end]) continue;
            path.push_back(s.substr(start, end - start + 1));
            dfs(end + 1, s, pal);
            path.pop_back();
        }
    }
};
