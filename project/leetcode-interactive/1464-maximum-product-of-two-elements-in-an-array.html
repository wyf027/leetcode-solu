数组中两元素的
最大乘积

从一组数字中选择两个不同位置，计算它们各自减一后的乘积，并让结果尽可能大。先读题、自己想，再进入交互实验。

01 / Problem

题目要求

给定整数数组 nums，请选择两个不同的下标 i 和 j。

返回表达式 (nums[i] - 1) * (nums[j] - 1) 能取得的最大值。

函数参数形式：maxProduct(nums)，其中 nums 是整数数组，返回值是整数。

官方示例

示例 1

输入：nums = [3,4,5,2]
输出：12
解释：选择 i = 1、j = 2，
(4 - 1) × (5 - 1) = 12。

示例 2

输入：nums = [1,5,4,5]
输出：16
解释：选择 i = 1、j = 3，
(5 - 1) × (5 - 1) = 16。

示例 3

输入：nums = [3,7]
输出：12

约束

  • 2 <= nums.length <= 500
  • 1 <= nums[i] <= 10³

04 / Full walkthrough

一次扫描，维护最大的两个数

核心洞察

由于所有 nums[i] >= 1，减一后的数仍非负；两个因子的乘积会随任一因子增大而不减。因此，最优答案一定来自数组中最大的两个元素（它们必须对应两个不同下标）。

完整过程

  1. 准备两个变量 max1 与 max2，分别表示扫描范围内的最大值、次大值。
  2. 依次读取元素 x。若 x > max1，原来的最大值退到第二席位，再让 x 成为新最大值。
  3. 否则，若 x > max2，只更新第二席位。这里用严格大于也能正确处理重复最大值：另一个相同值会进入 max2。
  4. 扫描结束后返回 (max1 - 1) * (max2 - 1)。

正确性证明

循环不变式：处理完前 k 个元素后，max1 和 max2 恰好是这 k 个元素中来自不同下标的最大值与次大值。

初始化：尚未处理元素时，两个席位为空；处理首个、第二个元素时，更新规则把它们正确放入对应席位。

保持：加入新元素 x 时共有三种情况：它超过最大值，则同时顺移两个席位；它只超过次大值，则替换次大值；它不超过次大值，则两席位不变。每种情况都保持不变式。

终止：所有元素处理后，两席位就是全数组最大的两个元素。对非负因子而言，选择它们减一后的乘积不小于任意其他不同下标的组合，所以返回值最优。

边界情况

  • 数组仅有两个元素：两者直接组成唯一选择。
  • 最大值重复：两个相同数来自不同下标，可以同时入选。
  • 包含 1：对应因子为 0，算法无需特殊判断。
  • 全部相等：最大值与次大值仍会由两个位置提供。

复杂度

只扫描数组一次，时间复杂度 O(n)；仅维护两个变量，额外空间复杂度 O(1)。

替代方案

  • 排序：升序排序后取末尾两个数，时间 O(n log n)，表达直观但做了多余工作。
  • 最大堆：弹出两个最大值，通常为 O(n) 建堆加弹出成本，空间和实现更重。
  • 暴力枚举：检查所有下标对，时间 O(n²)；适合说明定义，不是最优解。

常见错误

  • 先算 max1 * max2，忘记两个数都要减一。
  • 只记录一个最大值，或误用同一个下标两次。
  • 更新最大值时忘记把旧 max1 下放给 max2。
  • 用集合去重，导致两个相等但下标不同的最大值被错误合并。

面试追问

如果允许负数呢？

就不能只看最大的两个数；还需比较最小的两个数所形成的乘积，因为两个负因子相乘可能更大。

如果求前三大元素的某种组合呢？

可以维护固定大小的前三席位，或使用大小为 k 的最小堆；选择取决于 k 是否固定。

如何返回下标？

席位中同时保存值与原下标；移动席位时成对移动，最后返回两个记录的下标。

数据流无法回看怎么办？

该扫描方案天然支持流式输入，只需保留两个席位，不必保存完整数组。

四语言完整代码

class Solution {
    public int maxProduct(int[] nums) {
        int max1 = -1;
        int max2 = -1;

        for (int x : nums) {
            if (x > max1) {
                max2 = max1;
                max1 = x;
            } else if (x > max2) {
                max2 = x;
            }
        }

        return (max1 - 1) * (max2 - 1);
    }
}
