01 / Problem

任务说明

实现一个下标从 0 开始的链表。可以选择单链表或双链表，但不能直接使用语言内置的 LinkedList 容器。

  • MyLinkedList()初始化一个空链表对象。
  • int get(int index)返回下标为 index 的节点值；下标无效时返回 -1。
  • void addAtHead(int val)在当前第一个节点之前插入值为 val 的新节点，使其成为新的头节点。
  • void addAtTail(int val)把值为 val 的新节点追加到链表末尾。
  • void addAtIndex(int index, int val)在下标 index 的节点之前插入。若 index == size，追加到末尾；若 index > size，不做任何操作。
  • void deleteAtIndex(int index)仅当下标有效时，删除对应节点。

节点模型

单链表节点含 val 与 next；双链表节点再增加 prev，从而允许双向移动。

约束

  • 0 <= index, val <= 1000
  • 五种公开方法的调用总次数不超过 2000。
  • 不得使用内置 LinkedList 库。
官方示例 · 完整参数形式0-indexed
输入
["MyLinkedList", "addAtHead", "addAtTail", "addAtIndex", "get", "deleteAtIndex", "get"]
[[], [1], [3], [1, 2], [1], [1], [1]]

输出
[null, null, null, null, 2, null, 3]

解释
MyLinkedList myLinkedList = new MyLinkedList();
myLinkedList.addAtHead(1);       // 1
myLinkedList.addAtTail(3);       // 1 → 3
myLinkedList.addAtIndex(1, 2);   // 1 → 2 → 3
myLinkedList.get(1);             // 返回 2
myLinkedList.deleteAtIndex(1);   // 1 → 3
myLinkedList.get(1);             // 返回 3

    04 / Solution

    题解：双哨兵双向链表

    用不存业务值的 head 与 tail 包住所有真实节点，再用 size 记录长度。公开接口只负责校验与转发，真正的插入、删除都变成局部四指针操作。

    Core insight

    统一边界，比堆叠特判更可靠。

    空链表也始终满足 head.next == tail 与 tail.prev == head。因此头插、尾插、删除唯一节点都不需要独立分支。

    HEAD⇄A⇄B⇄TAIL

    完整过程

    1. 初始化不变量。 创建两个哨兵，让 head.next = tail、tail.prev = head，并令 size = 0。
    2. 按更近方向定位。 若目标下标靠近头部，从 head.next 向后走；否则从 tail.prev 向前走，最多移动约半条链。
    3. 统一插入。 找到插入位置右侧节点 succ 与其前驱 pred，把新节点接在二者之间，再增加 size。
    4. 统一删除。 找到目标节点 target，令它的前驱与后继互相连接，再减少 size。
    5. 复用公开接口。 addAtHead(val) 等价于 addAtIndex(0, val)；addAtTail(val) 等价于 addAtIndex(size, val)。

    正确性说明

    结构不变量

    每个真实节点的 next.prev 与 prev.next 都回到自身；头尾哨兵始终封住链表两端。初始化时显然成立。

    插入保持不变量

    新节点只替换 pred 与 succ 之间的一条相邻关系，并同时补齐四个方向的引用，因此链仍连续且双向一致。

    删除保持不变量

    删除时令 target.prev.next = target.next 且 target.next.prev = target.prev，目标节点被绕过，其余相邻关系不变。

    接口结果正确

    定位函数从已知端点移动精确步数，返回下标对应节点；无效下标在定位前被拒绝，所以 get、插入和删除符合题意。

    边界清单

    空链表访问 / 删除

    下标必然无效：get 返回 -1，删除不操作。

    index == size

    仅对插入有效，表示把节点放到尾哨兵之前。

    index > size

    插入必须被忽略，不能偷偷补空位或改成尾插。

    删除唯一节点

    删除后两哨兵重新互指，size 回到 0。

    复杂度

    get · O(min(i, n-i))

    从距离目标更近的一端开始定位；最坏仍为 O(n)。

    addAtHead / Tail · O(1)

    已知两端哨兵，不需要遍历。

    addAtIndex / delete · O(n)

    修改链接本身是 O(1)，主要成本来自定位。

    空间 · O(n)

    每个值使用一个节点，另有两个固定哨兵。

    四语言完整实现

    Java · LeetCode 可提交形式
    class MyLinkedList {
    private static class Node {
        int val;
        Node prev;
        Node next;

        Node(int val) {
            this.val = val;
        }
    }

    private final Node head;
    private final Node tail;
    private int size;

    public MyLinkedList() {
        head = new Node(0);
        tail = new Node(0);
        head.next = tail;
        tail.prev = head;
        size = 0;
    }

    public int get(int index) {
        if (index < 0 || index >= size) return -1;
        return nodeAt(index).val;
    }

    public void addAtHead(int val) {
        addAtIndex(0, val);
    }

    public void addAtTail(int val) {
        addAtIndex(size, val);
    }

    public void addAtIndex(int index, int val) {
        if (index < 0) index = 0;
        if (index > size) return;

        Node succ = (index == size) ? tail : nodeAt(index);
        Node pred = succ.prev;
        Node added = new Node(val);

        added.prev = pred;
        added.next = succ;
        pred.next = added;
        succ.prev = added;
        size++;
    }

    public void deleteAtIndex(int index) {
        if (index < 0 || index >= size) return;
        Node target = nodeAt(index);
        target.prev.next = target.next;
        target.next.prev = target.prev;
        size--;
    }

    private Node nodeAt(int index) {
        if (index < size / 2) {
            Node cur = head.next;
            for (int i = 0; i < index; i++) cur = cur.next;
            return cur;
        }
        Node cur = tail.prev;
        for (int i = size - 1; i > index; i--) cur = cur.prev;
        return cur;
    }
}

    Python 3 · LeetCode 可提交形式
    class Node:
    def __init__(self, val: int = 0):
        self.val = val
        self.prev = None
        self.next = None


class MyLinkedList:
    def __init__(self):
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head
        self.size = 0

    def get(self, index: int) -> int:
        if index < 0 or index >= self.size:
            return -1
        return self._node_at(index).val

    def addAtHead(self, val: int) -> None:
        self.addAtIndex(0, val)

    def addAtTail(self, val: int) -> None:
        self.addAtIndex(self.size, val)

    def addAtIndex(self, index: int, val: int) -> None:
        if index < 0:
            index = 0
        if index > self.size:
            return

        succ = self.tail if index == self.size else self._node_at(index)
        pred = succ.prev
        added = Node(val)

        added.prev = pred
        added.next = succ
        pred.next = added
        succ.prev = added
        self.size += 1

    def deleteAtIndex(self, index: int) -> None:
        if index < 0 or index >= self.size:
            return
        target = self._node_at(index)
        target.prev.next = target.next
        target.next.prev = target.prev
        self.size -= 1

    def _node_at(self, index: int) -> Node:
        if index < self.size // 2:
            cur = self.head.next
            for _ in range(index):
                cur = cur.next
            return cur

        cur = self.tail.prev
        for _ in range(self.size - 1, index, -1):
            cur = cur.prev
        return cur
    C++ · LeetCode 可提交形式
    class MyLinkedList {
private:
    struct Node {
        int val;
        Node* prev;
        Node* next;
        explicit Node(int value) : val(value), prev(nullptr), next(nullptr) {}
    };

    Node* head;
    Node* tail;
    int size;

    Node* nodeAt(int index) {
        if (index < size / 2) {
            Node* cur = head->next;
            for (int i = 0; i < index; ++i) cur = cur->next;
            return cur;
        }
        Node* cur = tail->prev;
        for (int i = size - 1; i > index; --i) cur = cur->prev;
        return cur;
    }

public:
    MyLinkedList() : head(new Node(0)), tail(new Node(0)), size(0) {
        head->next = tail;
        tail->prev = head;
    }

    ~MyLinkedList() {
        Node* cur = head;
        while (cur != nullptr) {
            Node* next = cur->next;
            delete cur;
            cur = next;
        }
    }

    int get(int index) {
        if (index < 0 || index >= size) return -1;
        return nodeAt(index)->val;
    }

    void addAtHead(int val) {
        addAtIndex(0, val);
    }

    void addAtTail(int val) {
        addAtIndex(size, val);
    }

    void addAtIndex(int index, int val) {
        if (index < 0) index = 0;
        if (index > size) return;

        Node* succ = (index == size) ? tail : nodeAt(index);
        Node* pred = succ->prev;
        Node* added = new Node(val);

        added->prev = pred;
        added->next = succ;
        pred->next = added;
        succ->prev = added;
        ++size;
    }

    void deleteAtIndex(int index) {
        if (index < 0 || index >= size) return;
        Node* target = nodeAt(index);
        target->prev->next = target->next;
        target->next->prev = target->prev;
        delete target;
        --size;
    }
};

    替代方案

    单链表 + 虚拟头节点

    每个节点少一个 prev，空间常数更小；但尾插仍需遍历（除非额外维护尾指针），删除时必须先找到前驱。

    动态数组

    随机访问快，但中间插入/删除需要整体搬移，且不符合本题练习“亲自实现链表”的核心目标。

    面试追问

    为什么需要 size？

    它让合法性判断为 O(1)，也让尾插位置与“从哪端开始找”变得明确。

    怎样做到严格 O(1) 随机访问？

    普通链表做不到。需要额外索引结构，但维护成本会上升，数据结构也不再是纯链表。

    并发环境会怎样？

    四次指针写入并非原子操作；需要锁、不可变结构或专门的无锁算法来避免观察到中间状态。

    如何检测链表损坏？

    遍历并检查相邻节点互指关系，同时核对实际节点数是否等于 size。

    常见错误： 先覆盖 pred.next 后才尝试从它读取原后继；忘记同时更新反向指针；把 index == size 判成无效；删除后忘记减少 size；在空链表或删除唯一节点时访问空引用。
