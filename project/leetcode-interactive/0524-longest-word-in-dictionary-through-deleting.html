Subsequence selection

通过删除字母匹配到字典里最长单词

在保留原字符相对顺序的前提下，从字符串 s 删除若干字符，找到字典中能够形成的最长单词；长度相同则选择字母序更小者。

Problem

题目说明

给定字符串 s 与字符串数组 dictionary。若一个字典单词可以通过删除 s 中的某些字符得到（不改变剩余字符的相对顺序），它就是候选答案。返回长度最大的候选；若有多个，返回字母序最小的一个；不存在时返回空字符串。

函数形式： findLongestWord(s, dictionary) → string

示例 1

输入：s = "abpcplea"
dictionary = ["ale","apple","monkey","plea"]
输出："apple"

示例 2

输入：s = "abpcplea"
dictionary = ["a","b","c"]
输出："a"

约束

  • 1 ≤ s.length ≤ 1000
  • 1 ≤ dictionary.length ≤ 1000
  • 1 ≤ dictionary[i].length ≤ 1000
  • s 与所有字典单词均只含小写英文字母。

Spoiler gate

先尝试描述：怎样判断一个单词是不是 s 的子序列？

Solution

双指针判定子序列

核心洞察

删除字符但保持顺序，等价于判断字典单词是否为 s 的子序列。用两个指针分别扫描 s 与候选词：字符相同则候选指针前进，无论是否相同，源指针都前进。候选指针到达末尾即匹配成功。

完整过程

  1. 令答案 best = ""。
  2. 逐个检查字典单词 word 是否为 s 的子序列。
  3. 匹配成功且 word 更长，或等长但字母序更小，则更新 best。
  4. 扫描结束后返回 best。

正确性证明

引理：双指针成功匹配候选词，当且仅当候选词是 s 的子序列。每次匹配都选取当前指针之后最早可用的相同字符，因此成功时得到严格递增的源串位置；若算法失败，则连最早可用位置的贪心选择也无法完成，任何更晚选择都不可能更优。

定理：算法返回题目要求的答案。算法检查每个字典单词，故不会遗漏合法候选；更新规则优先长度，再优先较小字母序，恰好实现题目定义的全序。因此最终 best 是唯一正确答案。

复杂度

设源串长度为 n，字典总字符数为 L，字典词数为 m。时间复杂度 O(mn + L)（每个候选最多扫描一次源串和自身），额外空间 O(1)，不计返回值。

边界

  • 没有候选时保持空字符串。
  • 候选比源串长时必然失败。
  • 重复字母必须按顺序逐个匹配。
  • 等长候选严格按字母序决胜。

替代方案

可以先按“长度降序、字母序升序”排序字典，找到第一个子序列后立即返回；代码直观，但引入 O(m log m) 排序与可能的额外空间。若同一个 s 要回答大量查询，可预处理每个位置之后各字符的下一出现位置，把单词判定降到与单词长度成正比。

面试追问

  • 如果字典有百万个词，如何用长度分桶、Trie 或下一位置表优化？
  • 如果字符集不止 26 个小写字母，预处理结构如何改变？
  • 为什么“出现次数足够”不能替代子序列判断？

常见错误

  • 把子序列误写成子串，只查连续出现。
  • 更新答案时只比较长度，漏掉字母序规则。
  • 对每个词排序字符，破坏原始相对顺序。
  • 比较 Java 字符串时误用 ==。

class Solution {
    public String findLongestWord(String s, List<String> dictionary) {
        String best = "";
        for (String word : dictionary) {
            if (isSubsequence(s, word)
                    && (word.length() > best.length()
                    || (word.length() == best.length()
                    && word.compareTo(best) < 0))) {
                best = word;
            }
        }
        return best;
    }

    private boolean isSubsequence(String source, String word) {
        int i = 0, j = 0;
        while (i < source.length() && j < word.length()) {
            if (source.charAt(i) == word.charAt(j)) j++;
            i++;
        }
        return j == word.length();
    }
}

var findLongestWord = function(s, dictionary) {
    let best = "";
    for (const word of dictionary) {
        let i = 0, j = 0;
        while (i < s.length && j < word.length) {
            if (s[i] === word[j]) j++;
            i++;
        }
        if (j === word.length &&
            (word.length > best.length ||
             (word.length === best.length && word < best))) {
            best = word;
        }
    }
    return best;
};
from typing import List

class Solution:
    def findLongestWord(self, s: str, dictionary: List[str]) -> str:
        best = ""
        for word in dictionary:
            j = 0
            for char in s:
                if j < len(word) and char == word[j]:
                    j += 1
            if j == len(word) and (
                len(word) > len(best)
                or (len(word) == len(best) and word < best)
            ):
                best = word
        return best
