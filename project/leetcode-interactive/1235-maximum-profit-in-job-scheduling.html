在时间冲突与收益之间做选择。先读题、操作时间轴，再决定是否展开完整题解。

HARD数组排序二分查找动态规划
Problem

题目

函数：jobScheduling(startTime, endTime, profit)

题意转述

有 n 份工作，第 i 份工作的执行区间为 [startTime[i], endTime[i])，完成后获得 profit[i]。请选择若干份互不重叠的工作，使总报酬最大，并返回这个最大值。

工作可以首尾衔接：若一份工作在时间 X 结束，另一份恰好在 X 开始，它们可以同时被选择。

输入与返回：三个等长整数数组 startTime、endTime、profit；返回一个整数，表示可获得的最大总报酬。

约束

  • 1 ≤ startTime.length = endTime.length = profit.length ≤ 5 × 10⁴
  • 1 ≤ startTime[i] < endTime[i] ≤ 10⁹
  • 1 ≤ profit[i] ≤ 10⁴

Solution

排序 + 动态规划 + 二分查找

把每个选择压缩成一个稳定的前缀状态，让冲突检查从线性扫描降为二分定位。

核心洞察

将工作按结束时间升序排列。令 dp[i] 表示只考虑排序后前 i 份工作时能获得的最大报酬。处理第 i 份工作时只有两个互斥选择：

dp[i] = max(dp[i - 1], dp[j] + profitᵢ)

其中 j 是结束时间不晚于当前开始时间的工作数量，也就是当前工作之前最近的兼容前缀。因为结束时间已有序，可以用二分查找找到 j。

完整过程

  1. 把三组数组合并成工作三元组 (start, end, profit)。
  2. 按 end 从小到大排序，并单独保存有序的结束时间数组。
  3. 建立长度为 n + 1 的 dp，令 dp[0] = 0。
  4. 枚举第 i 份工作；在前面的结束时间中二分查找最后一个 end ≤ startᵢ 的位置，换算成兼容前缀长度 j。
  5. 比较跳过当前工作的 dp[i - 1] 与接下当前工作的 dp[j] + profitᵢ。
  6. 最终返回 dp[n]。

正确性证明

状态覆盖全部合法解。

任意只使用前 i 份工作的最优方案，要么不包含第 i 份工作，要么包含它；两类方案互斥且完备。

跳过分支最优。

若不包含第 i 份工作，问题恰好退化为前 i - 1 份工作的最优解，即 dp[i - 1]。

接下分支最优。

若包含第 i 份工作，与它共存的其他工作必须都在兼容前缀 j 内；该前缀的最优收益为 dp[j]，因此此分支最优值是 dp[j] + profitᵢ。

归纳结论。

取两个完备分支的较大值即可得到 dp[i]。由 dp[0] = 0 逐步归纳，dp[n] 就是全部工作的最优报酬。

复杂度

时间：O(n log n)

空间：O(n)

排序和每份工作一次二分主导时间；工作数组、结束时间与 DP 数组占线性空间。

边界情况

  • 只有一份工作。
  • 所有工作互相冲突。
  • 所有工作都可首尾衔接。
  • 多个工作拥有相同开始或结束时间。
  • 选择一个高收益长工作优于许多短工作，或反之。

替代方案

按开始时间排序的后缀 DP

令 dp[i] 表示从第 i 份工作开始的最优收益，并二分寻找第一个开始时间不小于当前结束时间的工作。复杂度同样为 O(n log n)。

TreeMap / 有序映射

按时间维护“截至某时刻的最大收益”前沿，适合流式表达；实现细节更多，且仍需排序，面试中数组 DP 通常更清晰。

面试追问

  • 如果需要返回具体选择了哪些工作，如何记录并回溯决策？
  • 若工作端点闭区间、首尾相等也算冲突，二分边界应如何改变？
  • 如果每份工作还有冷却时间，如何修改兼容条件？
  • 当收益可能为负数时，状态初始化与答案是否需要变化？

常见错误

  • 二分查找使用 end < start，错误排除了允许的首尾相接。
  • 按开始时间排序，却把按结束时间定义的转移直接套用。
  • 把 j 的数组下标与 DP 的“前缀长度”混为一谈，产生偏一错误。
  • 用贪心只选择最早结束或单份收益最高的工作；带权区间调度不满足这些贪心条件。
  • 对每份工作向前线性扫描兼容项，最坏退化为 O(n²)。

import java.util.Arrays;

class Solution {
    public int jobScheduling(int[] startTime, int[] endTime, int[] profit) {
        int n = startTime.length;
        int[][] jobs = new int[n][3];
        for (int i = 0; i < n; i++) {
            jobs[i] = new int[]{startTime[i], endTime[i], profit[i]};
        }
        Arrays.sort(jobs, (a, b) -> Integer.compare(a[1], b[1]));

        int[] ends = new int[n];
        int[] dp = new int[n + 1];
        for (int i = 0; i < n; i++) ends[i] = jobs[i][1];

        for (int i = 1; i <= n; i++) {
            int[] job = jobs[i - 1];
            int compatibleCount = upperBound(ends, i - 1, job[0]);
            int take = dp[compatibleCount] + job[2];
            dp[i] = Math.max(dp[i - 1], take);
        }
        return dp[n];
    }

    private int upperBound(int[] values, int endExclusive, int target) {
        int left = 0, right = endExclusive;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (values[mid] <= target) left = mid + 1;
            else right = mid;
        }
        return left;
    }
}
/**
 * @param {number[]} startTime
 * @param {number[]} endTime
 * @param {number[]} profit
 * @return {number}
 */
var jobScheduling = function(startTime, endTime, profit) {
    const n = startTime.length;
    const jobs = startTime.map((start, i) => [start, endTime[i], profit[i]]);
    jobs.sort((a, b) => a[1] - b[1]);

    const ends = jobs.map(job => job[1]);
    const dp = new Array(n + 1).fill(0);

    const upperBound = (endExclusive, target) => {
        let left = 0;
        let right = endExclusive;
        while (left < right) {
            const mid = left + Math.floor((right - left) / 2);
            if (ends[mid] <= target) left = mid + 1;
            else right = mid;
        }
        return left;
    };

    for (let i = 1; i <= n; i++) {
        const [start, , value] = jobs[i - 1];
        const compatibleCount = upperBound(i - 1, start);
        const take = dp[compatibleCount] + value;
        dp[i] = Math.max(dp[i - 1], take);
    }
    return dp[n];
};
from bisect import bisect_right
from typing import List


class Solution:
    def jobScheduling(
        self,
        startTime: List[int],
        endTime: List[int],
        profit: List[int]
    ) -> int:
        jobs = sorted(zip(startTime, endTime, profit), key=lambda job: job[1])
        ends = [job[1] for job in jobs]
        dp = [0] * (len(jobs) + 1)

        for i, (start, _end, value) in enumerate(jobs, start=1):
            compatible_count = bisect_right(ends, start, 0, i - 1)
            take = dp[compatible_count] + value
            dp[i] = max(dp[i - 1], take)

        return dp[-1]
#include <algorithm>
#include <array>
#include <vector>
using namespace std;

class Solution {
public:
    int jobScheduling(vector<int>& startTime,
                      vector<int>& endTime,
                      vector<int>& profit) {
        int n = startTime.size();
        vector<array<int, 3>> jobs(n);
        for (int i = 0; i < n; ++i) {
            jobs[i] = {startTime[i], endTime[i], profit[i]};
        }
        sort(jobs.begin(), jobs.end(), [](const auto& a, const auto& b) {
            return a[1] < b[1];
        });

        vector<int> ends(n);
        vector<int> dp(n + 1, 0);
        for (int i = 0; i < n; ++i) ends[i] = jobs[i][1];

        for (int i = 1; i <= n; ++i) {
            const auto& job = jobs[i - 1];
            int compatibleCount = upper_bound(
                ends.begin(), ends.begin() + (i - 1), job[0]
            ) - ends.begin();
            int take = dp[compatibleCount] + job[2];
            dp[i] = max(dp[i - 1], take);
        }
        return dp[n];
    }
};
