SPACE CITY · BITMASK DP

LCP 53. 守护太空城

陨石会在指定时刻冲击指定舱室。开启单舱屏障耗能 2，开启相邻双舱联合屏障耗能 3；已开启屏障多维持一个时刻耗能 1。求守护所有冲击点的最小能量。

编号：LCP 53难度：困难轮廓状压 DP

题意与约束

数组 time[i] 与 position[i] 描述一次冲击。相同时间同一舱室只需保护一次。时间仅为 1 到 5，因此每个舱室的受攻击时刻可压成 5 位二进制掩码。

示例 1

time = [1, 2, 1]

position = [6, 3, 3]

输出 = 5

在时刻 1 开启 3、6 的单舱屏障各 2；时刻 2 维持 3 的屏障耗 1。

冲击次数

≤ 500

时间范围

1..5

状态设计

dp[i][mask]：已处理到舱室 i，且 i 与 i+1 之间在 mask 时刻使用联合屏障的最小成本。掩码把“向右延伸的联合屏障”交给下一列处理。

  1. 1. 预处理任意掩码开单舱/联合屏障的最小连续维持成本。
  2. 2. 枚举当前向右联合掩码 j。
  3. 3. 枚举前一舱留下的 pre，要求 pre & j = 0。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

题解：按舱室扫描的轮廓 DP

把每一个位置受到冲击的时刻压为 rain[position]。联合屏障横跨两个相邻舱室，因而扫描位置时只需记录它在 5 个时刻是否“向右延伸”。若上一舱和当前舱都在同一时刻使用联合屏障会重叠，所以二者掩码必须不相交。

预处理

single[mask]：选中时刻用单屏障的最小成本；连续时刻续费 1，否则新开 2。union[mask] 类似，新开为 3。

转移

令 free = full ^ j。枚举 pre 为 free 的子集；未被 pre 或 j 覆盖、且当前被陨石击中的时刻用单屏障补齐。

复杂度

位置最多 101、掩码至多 32。所有 j 与其补集子集的总枚举为 3^5，总时间 O(101 · 3⁵)，空间 O(101 · 2⁵)。

边界、替代方案与面试追问

最后一列不能再向右延伸，答案取 dp[maxPosition][0]。常见错误是允许 pre 与 j 重叠，或把续费成本算成再次开启。也可用 5 进制状态枚举每个时间的屏障类型，但状态数为 5⁵，表达更直观却更慢。

Java

import java.util.*;
class Solution {
  public int defendSpaceCity(int[] time, int[] position) {
    int n = 0, t = 0; for (int x : position) n = Math.max(n, x); for (int x : time) t = Math.max(t, x);
    int m = 1 << t, full = m - 1; int[] rain = new int[n + 1];
    for (int i = 0; i < time.length; i++) rain[position[i]] |= 1 << (time[i] - 1);
    int[] un = new int[m], single = new int[m];
    for (int x = 1; x < m; x++) { int low = x & -x, rest = x ^ low, prev = rest & -rest; boolean adjacent = low == (prev >> 1); un[x] = un[rest] + (adjacent ? 1 : 3); single[x] = single[rest] + (adjacent ? 1 : 2); }
    int[][] dp = new int[n + 1][m];
    for (int j = 0; j < m; j++) dp[0][j] = un[j] + single[(full ^ j) & rain[0]];
    for (int i = 1; i <= n; i++) { Arrays.fill(dp[i], 1 << 28); for (int j = 0; j < m; j++) { int free = full ^ j; for (int pre = free;; pre = (pre - 1) & free) { dp[i][j] = Math.min(dp[i][j], dp[i - 1][pre] + un[j] + single[(free ^ pre) & rain[i]]); if (pre == 0) break; } } }
    return dp[n][0];
  }
}

Python

from typing import List
class Solution:
    def defendSpaceCity(self, time: List[int], position: List[int]) -> int:
        n, t = max(position), max(time); m = 1 << t; full = m - 1
        rain = [0] * (n + 1)
        for x, p in zip(time, position): rain[p] |= 1 << (x - 1)
        un = [0] * m; single = [0] * m
        for x in range(1, m):
            low = x & -x; rest = x ^ low; prev = rest & -rest; adj = low == (prev >> 1)
            un[x] = un[rest] + (1 if adj else 3); single[x] = single[rest] + (1 if adj else 2)
        dp = [[10**9] * m for _ in range(n + 1)]
        for j in range(m): dp[0][j] = un[j] + single[(full ^ j) & rain[0]]
        for i in range(1, n + 1):
            for j in range(m):
                free = full ^ j; pre = free
                while True:
                    dp[i][j] = min(dp[i][j], dp[i - 1][pre] + un[j] + single[(free ^ pre) & rain[i]])
                    if pre == 0: break
                    pre = (pre - 1) & free
        return dp[n][0]

    vector<vector<int>> dp(n + 1, vector<int>(m, 1e9));

  }
