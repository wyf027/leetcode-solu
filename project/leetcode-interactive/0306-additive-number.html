累加数Additive Number

判断一串数字能否被切分成至少三个整数，并让每个后续整数都严格等于它前面两个整数之和。

仅含数字 禁止前导零 需规避整数溢出

Problem

题目描述

给定只包含数字 0–9 的字符串 num。如果其中的数字能按原顺序切分为一个有效的累加序列，返回 true；否则返回 false。

  • 序列至少包含 3 个数。
  • 从第 3 个数起，每个数都等于前两个数之和。
  • 除数字 0 本身外，任何数都不能以 0 开头；例如 1, 2, 03 与 1, 02, 3 均无效。
进阶：输入中的整数可能超出内置数值类型范围，算法需要避免溢出。

函数形式

isAdditiveNumber(num: string): boolean

输入为数字字符串，输出为布尔值。切分过程中不得改变字符顺序。

Examples

true
解释
1, 1, 2, 3, 5, 8；依次满足 1+1=2、1+2=3、2+3=5、3+5=8。

Full solution

枚举前两项，字符串模拟加法

核心洞察

一旦前两个数的边界确定，后续序列就不再有分支：下一项只能是二者之和。因此只需枚举前两项，然后一路向右验证。为彻底规避溢出，用十进制字符串完成加法。

完整过程

  1. 枚举第一项终点 i 与第二项终点 j，并保证至少留一个字符给第三项。
  2. 若某项长度大于 1 且首字符为 0，立即跳过对应切分。
  3. 字符串相加得到 sum，检查剩余串是否从当前位置以 sum 开始。
  4. 匹配则令 A ← B、B ← sum 继续；不匹配则尝试下一组初始切分。
  5. 恰好消费完整个字符串时返回 true；所有切分失败后返回 false。

正确性证明

  1. 枚举完备。 任意合法序列都有唯一的前两项边界；双层枚举会覆盖这组边界，合法前导零规则不会误删它。
  2. 验证可靠。 固定前两项后，累加规则唯一确定每个后续值。算法逐段计算并精确匹配，因此每次推进都保持“已消费前缀是合法累加序列”的不变式。
  3. 结论成立。 若算法返回真，不变式与完整消费保证得到至少三项的合法序列；若存在合法序列，其前两项会被枚举且所有后续匹配都会成功，算法必返回真。

边界与剪枝

  • "000" 合法，可切为 0, 0, 0；但 "01" 不能把 01 当作一个数。
  • 第二项终点不能到字符串末尾，必须为第三项留下至少一位。
  • 当前两项中较长者的位数已经超过剩余长度时，不可能再匹配，可提前终止该候选。
  • 字符串加法从右向左处理进位，不依赖语言内置整数上限。

复杂度

设字符串长度为 n。前两项边界有 O(n²) 种；每组候选最多线性扫描并完成总量为 O(n) 的数字处理，因此最坏时间复杂度为 O(n³)。字符串加法与临时结果需要 O(n) 额外空间。

替代方案

支持任意精度整数的语言可直接用 BigInteger 或 BigInt，代码更短，但会依赖语言特性。也可显式回溯构造序列，不过前两项确定后没有真正分支，通常比“枚举两项 + 顺推”更冗余。

面试追问

  • 为什么固定前两项后不需要继续回溯？
  • 怎样证明字符串加法没有遗漏最终进位？
  • 若长度上升到十万，哪些枚举与切片操作会成为瓶颈？
  • 能否只返回布尔值改为返回一组实际切分结果？

常见错误

  • 直接转成 long、Number 等固定精度类型，遇到大数溢出或失真。
  • 只禁止第一项前导零，却漏掉第二项和后续项。
  • 允许只切出两项，违反“至少三个数”。
  • 用全局查找代替从当前位置匹配，错误地跳过中间字符。

class Solution {
    public boolean isAdditiveNumber(String num) {
        int n = num.length();
        for (int i = 1; i <= n - 2; i++) {
            if (num.charAt(0) == '0' && i > 1) break;

            for (int j = i + 1; j <= n - 1; j++) {
                if (num.charAt(i) == '0' && j - i > 1) break;

                String a = num.substring(0, i);
                String b = num.substring(i, j);
                int pos = j;

                while (pos < n) {
                    String sum = addStrings(a, b);
                    if (!num.startsWith(sum, pos)) break;
                    pos += sum.length();
                    a = b;
                    b = sum;
                }

                if (pos == n) return true;
            }
        }
        return false;
    }

    private String addStrings(String a, String b) {
        StringBuilder reversed = new StringBuilder();
        int i = a.length() - 1;
        int j = b.length() - 1;
        int carry = 0;

        while (i >= 0 || j >= 0 || carry != 0) {
            int x = i >= 0 ? a.charAt(i--) - '0' : 0;
            int y = j >= 0 ? b.charAt(j--) - '0' : 0;
            int total = x + y + carry;
            reversed.append(total % 10);
            carry = total / 10;
        }
        return reversed.reverse().toString();
    }
}

function addStrings(a, b) {
    let i = a.length - 1;
    let j = b.length - 1;
    let carry = 0;
    const reversed = [];

    while (i >= 0 || j >= 0 || carry !== 0) {
        const x = i >= 0 ? a.charCodeAt(i--) - 48 : 0;
        const y = j >= 0 ? b.charCodeAt(j--) - 48 : 0;
        const total = x + y + carry;
        reversed.push(String(total % 10));
        carry = Math.floor(total / 10);
    }
    return reversed.reverse().join("");

class Solution:
    def isAdditiveNumber(self, num: str) -> bool:
        n = len(num)

        for i in range(1, n - 1):
            if num[0] == "0" and i > 1:
                break

            for j in range(i + 1, n):
                if num[i] == "0" and j - i > 1:
                    break

                a, b = num[:i], num[i:j]
                pos = j

                while pos < n:
                    total = self._add_strings(a, b)
                    if not num.startswith(total, pos):
                        break
                    pos += len(total)
                    a, b = b, total

                if pos == n:
                    return True

        return False

    def _add_strings(self, a: str, b: str) -> str:
        i, j, carry = len(a) - 1, len(b) - 1, 0
        reversed_digits = []

        while i >= 0 or j >= 0 or carry:
            x = ord(a[i]) - ord("0") if i >= 0 else 0
            y = ord(b[j]) - ord("0") if j >= 0 else 0
            total = x + y + carry
            reversed_digits.append(str(total % 10))
            carry = total // 10
            i -= 1
            j -= 1

        return "".join(reversed(reversed_digits))
#include <algorithm>

class Solution {
public:
    bool isAdditiveNumber(string num) {
        int n = static_cast<int>(num.size());

        for (int i = 1; i <= n - 2; ++i) {
            if (num[0] == '0' && i > 1) break;

            for (int j = i + 1; j <= n - 1; ++j) {
                if (num[i] == '0' && j - i > 1) break;

                string a = num.substr(0, i);
                string b = num.substr(i, j - i);
                int pos = j;

                while (pos < n) {
                    string sum = addStrings(a, b);
                    if (num.compare(pos, sum.size(), sum) != 0) break;
                    pos += static_cast<int>(sum.size());
                    a = b;
                    b = sum;
                }

                if (pos == n) return true;
            }
        }
        return false;
    }

private:
    string addStrings(const string& a, const string& b) {
        string reversed;
        int i = static_cast<int>(a.size()) - 1;
        int j = static_cast<int>(b.size()) - 1;
        int carry = 0;

        while (i >= 0 || j >= 0 || carry != 0) {
            int x = i >= 0 ? a[i--] - '0' : 0;
            int y = j >= 0 ? b[j--] - '0' : 0;
            int total = x + y + carry;
            reversed.push_back(char('0' + total % 10));
            carry = total / 10;
        }
        reverse(reversed.begin(), reversed.end());
        return reversed;
    }
};
