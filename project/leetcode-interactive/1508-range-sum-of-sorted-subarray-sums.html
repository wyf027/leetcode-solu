子数组和排序后的区间和

Range Sum of Sorted Subarray Sums

Problem

题目描述

数组双指针二分查找前缀和排序

给定由 n 个正整数组成的数组 nums。计算它的所有非空连续子数组之和，再将这些和按非递减顺序排列，得到长度为 n × (n + 1) / 2 的新数组。

返回新数组中第 left 项到第 right 项（从 1 开始编号，包含两端）的总和。答案可能很大，请对 109 + 7 取模。

官方示例

示例 1
输入：nums = [1,2,3,4], n = 4, left = 1, right = 5
输出：13
解释：全部子数组和排序后为
[1,2,3,3,4,5,6,7,9,10]，
第 1 到第 5 项之和为 1+2+3+3+4=13。
示例 2
输入：nums = [1,2,3,4], n = 4, left = 3, right = 4
输出：6
解释：排序后的数组仍为
[1,2,3,3,4,5,6,7,9,10]，
第 3 到第 4 项之和为 3+3=6。
示例 3
输入：nums = [1,2,3,4], n = 4, left = 1, right = 10
输出：50

约束

  • n == nums.length
  • 1 <= nums.length <= 103
  • 1 <= nums[i] <= 100
  • 1 <= left <= right <= n × (n + 1) / 2

Solution

枚举全部子数组和，再排序

核心洞察

最多只有 1000 × 1001 / 2 = 500,500 个连续子数组。直接保存所有和后排序，在本题约束内足够清晰且可行。

完整过程

  1. 创建空数组 sums。
  2. 固定子数组左端点 start，令滚动和 sum = 0。
  3. 右端点从 start 向右移动；每次加上当前元素，并把滚动和压入 sums。
  4. 对 sums 做数值升序排序。
  5. 累加下标 left - 1 到 right - 1 的元素，并持续取模。

关键不变量

sum = nums[start] + … + nums[end]

内层循环每前进一步只需加一个数，因此不必为每个区间重新求和。两层端点循环恰好枚举每个非空连续子数组一次。

正确性说明

引理 1：生成阶段不重不漏。任意非空连续子数组都由唯一的一对端点 (start, end) 决定，且双层循环遍历所有满足 0 ≤ start ≤ end < n 的端点对，所以每个子数组和恰好被加入一次。

引理 2：排序后位置正确。数值升序排序使 sums[k] 成为第 k+1 小的子数组和；相等的和是否交换位置不影响区间总和。

定理。算法累加 sums[left-1…right-1]，正好对应题目从 1 开始编号的第 left 到第 right 项。取模仅改变表示，不改变模意义下的答案。

复杂度

  • 令 m = n(n+1)/2。
  • 生成：O(n²)。
  • 排序：O(m log m)，即 O(n² log n)。
  • 空间：O(m)，即 O(n²)。

边界处理

  • n = 1 时只有一个子数组。
  • left = right 时只取一个排名位置。
  • left = 1, right = m 时累加全部子数组和。
  • Java / C++ 的累计值使用 64 位整数；JavaScript 的最大中间总和仍远低于安全整数上限。

四语言完整代码

import java.util.Arrays;

class Solution {
    public int rangeSum(int[] nums, int n, int left, int right) {
        final long MOD = 1_000_000_007L;
        int[] sums = new int[n * (n + 1) / 2];
        int index = 0;

        for (int start = 0; start < n; start++) {
            int sum = 0;
            for (int end = start; end < n; end++) {
                sum += nums[end];
                sums[index++] = sum;
            }
        }

        Arrays.sort(sums);
        long answer = 0;
        for (int i = left - 1; i < right; i++) {
            answer = (answer + sums[i]) % MOD;
        }
        return (int) answer;
    }
}

 * @return {number}

var rangeSum = function(nums, n, left, right) {
    const MOD = 1_000_000_007;
    const sums = [];

    for (let start = 0; start < n; start++) {
        let sum = 0;
        for (let end = start; end < n; end++) {
            sum += nums[end];
            sums.push(sum);
        }
    }

    sums.sort((a, b) => a - b);
    let answer = 0;
    for (let i = left - 1; i < right; i++) {
        answer = (answer + sums[i]) % MOD;
    }
    return answer;
};

替代方案

由于所有数均为正，可通过“二分答案 + 滑动窗口 + 前缀的前缀和”计算最小 k 个子数组和之和，再用 F(right) - F(left-1) 得到答案。它能把额外空间降到 O(n)，时间约为 O(n log S)，其中 S = sum(nums)，但实现和证明明显更复杂；当前约束下枚举排序更稳妥。

面试追问

  • 如果 n 扩大到 105，如何避免保存所有子数组和？
  • 正整数条件对滑动窗口为什么关键？存在负数时哪里失效？
  • 怎样在不排序全部元素的前提下求前 k 小之和？

常见错误

  • 忘记题目排名从 1 开始，导致循环起点写成 left 而不是 left - 1。
  • JavaScript 使用默认 sort()，得到字符串字典序；必须传入 (a, b) => a - b。
  • 内层循环换左端点时未把滚动和清零。
  • 累计很多项时用 32 位整数保存中间结果，可能溢出。
  • 只在最后才取模且没有使用足够宽的整数类型。
