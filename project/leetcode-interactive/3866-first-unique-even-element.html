找到第一个唯一偶数

先统计所有数的频次，再按原顺序寻找首个“偶数且只出现一次”的元素。顺序扫描保证答案就是下标最早的候选。

题意

给定整数数组 nums，返回数组中出现恰好一次且下标最早的偶数；若不存在，返回 -1。

示例：nums = [3, 4, 2, 5, 4, 6]，2 与 6 都唯一，但 2 更早，答案是 2。

约束

数组长度1 ≤ n ≤ 100
元素范围1 ≤ nums[i] ≤ 100

复杂度

时间 O(n) 空间 O(n)

核心洞察

“唯一”是全局属性，不能在第一次遇到数字时立即确定。先用哈希表统计，再用原数组顺序筛选，就同时满足唯一性和最早下标。

完整过程

  1. 遍历 nums，累加每个值的出现次数。
  2. 再次从左至右遍历：遇到偶数且频次为 1，立即返回。
  3. 扫描结束仍无候选则返回 -1。

边界与替代方案

全部奇数、偶数均重复、答案在末尾都覆盖。数值范围只有 1..100 时，可用固定长度计数数组替代哈希表；通用场景下哈希表更稳妥。

面试追问与常见错误

若要求“第一个偶数”可单遍返回；本题不能，因为之后可能出现相同值。另一个常见错误是先筛偶数再按数值排序，排序会破坏原下标顺序。
