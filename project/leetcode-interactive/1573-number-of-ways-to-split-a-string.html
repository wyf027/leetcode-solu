01 · 题目

切成三段，三段的 1 一样多

给定只由 0 和 1 组成的字符串 s，选择两个切口，将它分成按原顺序首尾拼接的三个非空字符串 s1、s2、s3。

统计满足三个子串中字符 1 的数量完全相同的切分方案。答案可能很大，返回它对 10⁹ + 7 取模后的结果。

约束

  • 3 ≤ s.length ≤ 10⁵
  • s[i] 只能是 '0' 或 '1'
示例 1
输入：s = "10101"
输出：4
解释："1|010|1"、"1|01|01"、
      "10|10|1"、"10|1|01"
示例 2
输入：s = "1001"
输出：0
示例 3
输入：s = "0000"
输出：3
解释："0|0|00"、"0|00|0"、"00|0|0"
示例 4
输入：s = "100100010100110"
输出：12

04 · 独立题解

准备好后再揭晓

包含核心洞察、证明、边界、复杂度、替代方案与四种语言实现。

从“枚举切口”到“数间隙”

设字符串中 1 的总数为 ones。目标不是逐对尝试两个切口，而是确定每个切口可以落在哪些连续的零间隙中。

1

先判可分性

若 ones 不能被 3 整除，每段不可能拥有同样多的 1，答案直接为 0。

2

定位四个关键 1

当每段应含 k = ones / 3 个 1 时，记录第 k、k+1、2k、2k+1 个 1 的位置。

3

独立选择两刀

两个合法切口数量分别等于两对关键 1 的位置差，总方案数是二者乘积。

完整过程

  1. 遍历 s，收集所有字符 '1' 的下标到数组 pos。
  2. 若 pos.length % 3 != 0，返回 0。
  3. 若没有任何 1，则三个子串都天然含 0 个 1。只需从 n - 1 个字符间隙中选两个不同切口，答案为 C(n-1, 2) = (n-1)(n-2)/2。
  4. 否则令 k = pos.length / 3。第一刀可放在 pos[k-1] 到 pos[k] 之间，选择数为 pos[k] - pos[k-1]。
  5. 第二刀可放在 pos[2k-1] 到 pos[2k] 之间，选择数为 pos[2k] - pos[2k-1]。
  6. 两刀选择互不干扰，乘起来并对 10⁹ + 7 取模。

为什么正确

定理

算法返回值恰好等于所有满足三段非空且 1 的数量相等的切分方案数。

证明

不可分情况：若 1 的总数不能被 3 整除，三个相等的整数之和不可能等于该总数，因此答案为 0。

全零情况：任意两个不同字符间隙都形成三个非空片段，且每段的 1 数量均为 0；从 n-1 个间隙中任选两个，既无遗漏也无重复。

含 1 情况：每段必须恰有 k 个 1。第一刀必须位于第 k 个 1 之后且第 k+1 个 1 之前；这个闭合的间隙范围内每个位置都合法，范围外都将使第一段的 1 数量不为 k。第二刀同理，必须位于第 2k 与第 2k+1 个 1 之间。两段合法间隙严格按序分离，所以任取一对切口都会得到唯一合法切分，任何合法切分也唯一对应这样一对选择。故乘积不重不漏。

边界情况

  • 全部为 0：必须单独使用组合数，不能访问不存在的 1 的位置。
  • 1 的数量不足 3 且非 0：不能整除 3，答案为 0。
  • 关键 1 相邻：位置差为 1，说明对应切口只有一种选法。
  • 长串：中间乘积可能超过 32 位整数；Java / C++ 使用 64 位类型，JavaScript 的最大乘积约 10¹⁰，仍低于安全整数上限。
  • 非空要求：切口只能在字符之间；上述关键 1 间隙与组合数都天然满足。

复杂度

时间复杂度 O(n)。下面实现保存全部 1 的位置，因此空间复杂度为 O(n)；也可只保存四个关键位置，将额外空间降为 O(1)。

替代方案

前缀计数：先求总数，再扫描每个候选切口。当左侧前缀含 k 个 1 时累计第一刀选择数；当前缀含 2k 个 1 时，把已累计的第一刀数量加入答案。它同样是 O(n) 时间和 O(1) 空间，但边界更新顺序更容易写错。

枚举两个切口：共有 O(n²) 对，不满足 n ≤ 10⁵。即使用前缀和把每次校验降为 O(1)，总体仍会超时。

四种语言完整代码

import java.util.ArrayList;
import java.util.List;

class Solution {
    public int numWays(String s) {
        final long MOD = 1_000_000_007L;
        List<Integer> positions = new ArrayList<>();

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '1') {
                positions.add(i);
            }
        }

        int ones = positions.size();
        if (ones % 3 != 0) {
            return 0;
        }
        if (ones == 0) {
            long gaps = s.length() - 1L;
            return (int) (gaps * (gaps - 1) / 2 % MOD);
        }

        int k = ones / 3;
        long firstChoices = positions.get(k) - positions.get(k - 1);
        long secondChoices = positions.get(2 * k) - positions.get(2 * k - 1);
        return (int) (firstChoices * secondChoices % MOD);
    }
}

    if (ones % 3 !== 0) return 0;

    if (ones === 0) {
        const gaps = s.length - 1;

    const firstChoices = positions[k] - positions[k - 1];
    const secondChoices = positions[2 * k] - positions[2 * k - 1];
    return (firstChoices * secondChoices) % MOD;
};

面试追问

  • 如何做到 O(1) 额外空间？第一次扫描求总 1 数，第二次扫描时只记录第 k、k+1、2k、2k+1 个 1 的位置。
  • 如果改成分成 m 段？总数需能被 m 整除；对相邻目标组之间的每个零间隙计算选择数，最终把 m-1 个选择数相乘。全零时为 C(n-1, m-1)。
  • 如果数组元素不是 0/1，而是任意整数并要求三段和相等？使用前缀和寻找总和的 1/3 与 2/3；需要谨慎处理负数、切口顺序和非空限制。

常见错误

  • 把间隙选择数写成“中间零的个数”，忘记还要加 1；直接用两个关键 1 的下标差最稳妥。
  • 遗漏全零特例，导致 k = 0 后访问负下标。
  • 组合数误写为 n(n-1)/2；实际可切位置只有 n-1 个。
  • Java / C++ 在乘法完成后才转 64 位，已经发生溢出；参与乘法的变量应先使用 long / long long。
  • 把两个切口放到字符串两端，从而产生空子串。
