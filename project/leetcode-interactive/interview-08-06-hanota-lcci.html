面试题 08.06 · 简单

汉诺塔问题三塔调度台

把递归当成一套可靠的调度协议：先清空最大盘上方的空间，再调度最大盘，最后把暂存塔整体接回目标塔。三根柱子的角色会轮换，但协议永远不变。

原地修改 A / B / C 最少移动 2ⁿ − 1 次 键盘 ← → / Space
01 / MISSION BRIEF

任务与规则

有三根柱子和 N 个不同大小的圆盘。初始时，所有圆盘都在 A，数组尾部代表柱顶；请借助 B，将圆盘全部移动到 C，并直接修改传入的三个列表。

01

单盘调度

一次只能移动一个圆盘。

02

只动柱顶

只能弹出列表末尾的柱顶圆盘。

03

小盘在上

任何时刻，大盘都不能压在小盘上。

示例 1

输入：A = [2, 1, 0], B = [], C = []

输出：C = [2, 1, 0]

示例 2

输入：A = [1, 0], B = [], C = []

输出：C = [1, 0]

记号说明：[] 表示空柱；本题没有字符串输入，因此无需把空格替换为可见符号 ␠。约束：A.length ≤ 14。

04 / DEBRIEF

递归协议拆解

核心洞察

要移动 n 个盘子，唯一安全的结构是：先把上方 n − 1 个盘子移到缓冲柱，再移动最大盘，最后把 n − 1 个盘子移到目标柱。子问题只更换三根柱子的角色。

完整过程

  1. move(n - 1, source, target, buffer)
  2. 把 source 柱顶弹出并压入 target
  3. move(n - 1, buffer, source, target)

边界与正确性

n = 0 时没有任务，直接返回。递归第一段保证最大盘上方为空；第二段合法移动最大盘；第三段依据同一不变量把小盘塔恢复到最大盘上方，因此始终合法。

复杂度

递推式 T(n) = 2T(n − 1) + 1，所以时间复杂度为 O(2ⁿ)，且恰好移动 2ⁿ − 1 次；递归栈深度为 O(n)。

替代方案

可以用奇偶性规律迭代生成合法移动，但代码更难解释、角色规则更容易写错。约束只有 14 个盘子，递归版最符合面试表达与可证明性。

常见错误

  • 误把数组首元素当作柱顶；本题柱顶在列表末尾。
  • 第二次递归仍沿用原缓冲柱，忘了交换角色。
  • 创建新数组返回，违反“原地修改”要求。

面试追问

  • 为什么最少必须移动 2ⁿ − 1 次？
  • 如果要输出每次移动而不是修改列表，接口如何设计？
  • 如何验证一串移动指令始终合法且最终到达 C？
