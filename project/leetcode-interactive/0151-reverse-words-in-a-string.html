反转字符串中的单词 单词轨道

跳过多余空格、提取每个完整单词，再从后向前用单个空格拼接；字符不反转，只改变单词顺序。

任务边界

输入字符串 s，长度 1～10⁴，至少含一个单词；输出无前后空格且单词间恰有一个空格。

Problem / 题意

反转的是单词顺序，不是字符

给定字符串 s，其中可能含前导、尾随和连续空格。先按空格提取非空单词，再逆序拼接，结果中只保留必要的单个分隔空格。 下方代码格式中的 ␠ 表示一个普通空格。

官方示例 1
s = "the␠sky␠is␠blue"

输出："blue␠is␠sky␠the"

官方示例 2
s = "␠␠hello␠world␠␠"

输出："world␠hello"

官方示例 3
s = "a␠good␠␠␠example"

输出："example␠good␠a"

核心洞察

先规整，再逆序拼接

多余空格不属于任何单词。先扫描并提取非空单词，就同时消除了首尾和连续空格；随后从末尾向前拼接，天然保证结果中只有单个分隔空格。

完整过程

  1. 跳过当前位置的连续空格。
  2. 记录单词起点，扫描到空格或字符串末尾。
  3. 保存完整单词，重复直到输入结束。
  4. 从后向前以单个空格连接单词。

边界与复杂度

  • 单个单词原样返回，不附加空格。
  • 输入可含任意数量的前导、尾随和连续空格。
  • 时间 O(n)，空间 O(n)。

替代方案取舍

内置 trim / split / reverse / join 最简洁；手写扫描更能展示边界处理。若字符数组可变，可原地规整空格、整体反转，再逐词反转，额外空间 O(1)。

常见错误

  • 直接按单个空格 split，保留了空字符串。
  • 反转了每个单词内部字符。
  • 拼接时留下首尾空格或重复空格。
  • 扫描到字符串末尾时漏掉最后一个单词。

面试追问

如何做到 O(1) 额外空间？在可变字符数组上三次反转。
为什么先规整空格？让后续反转不再处理空 token。
Unicode 空白怎么办？按题目只需识别普通空格字符。 
class Solution {
    public String reverseWords(String s) {
        List<String> words = new ArrayList<>();
        int i = 0, n = s.length();
        while (i < n) {
            while (i < n && s.charAt(i) == ' ') i++;
            int start = i;
            while (i < n && s.charAt(i) != ' ') i++;
            if (start < i) words.add(s.substring(start, i));
        }
        Collections.reverse(words);
        return String.join(" ", words);
    }
}
var reverseWords = function (s) {
  const words = [];
  let i = 0;
  while (i < s.length) {
    while (i < s.length && s[i] === " ") i++;
    const start = i;
    while (i < s.length && s[i] !== " ") i++;
    if (start < i) words.push(s.slice(start, i));
  }
  return words.reverse().join(" ");
};
