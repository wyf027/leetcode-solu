前五科的均分

把每位学生最亮眼的五次成绩留下，求它们的整数平均分。先观察成绩如何进入“只容纳前五名”的篮子，再决定是否展开题解。

EASY付费题High Five哈希表 · 排序 · 最小堆

题意

给定二维整数数组 items，每项 [id, score] 表示编号为 id 的学生获得一次 score 分。对每位学生选出最高的五个分数，计算整数平均值（舍去小数部分），返回 [id, average]，结果按学生编号升序排列。

函数签名

highFive(items: integer[][]): integer[][]

约束

  • 1 ≤ items.length ≤ 1000
  • items[i].length = 2
  • 1 ≤ id ≤ 1000；1 ≤ score ≤ 100
  • 每位学生至少有五条成绩。

官方示例形式

输入 1
items = [[1,91],[1,92],[2,93],[2,97],[1,60],
[2,77],[1,65],[1,87],[1,100],[2,100],[2,76]]
输出 1
[[1,87],[2,88]]

学生 1 前五分总和 435；学生 2 前五分总和 443，整数除以 5 得 87 与 88。

输入 2
items = [[1,100],[7,100],[1,100],[7,100],[1,100],
[7,100],[1,100],[7,100],[1,100],[7,100]]
输出 2
[[1,100],[7,100]]

题解 · 每人维护一个最小堆

核心洞察

无需完整排序所有成绩，只需始终保存当前最高的五个。最小堆的堆顶是这五个中最弱的一项；加入新成绩后若超过五项，弹出堆顶即可。

完整过程

  1. 哈希表将学生编号映射到最小堆。
  2. 遍历 items，压入分数；堆超过 5 时弹出最小值。
  3. 学生编号升序排列。
  4. 每个五元素堆求和并做整数除法。

正确性

不变式：处理任意输入前缀后，每位学生的堆含该前缀中最高的至多五分。加入分数后，若出现六项，删除其中最小值，剩余正是最高五项。因此遍历结束时堆内是全部成绩的最高五项，求和除以五即为答案。

边界与复杂度

相同分数可重复；平均值向下取整；恰好五项无需淘汰。设记录数为 n、学生数为 u，时间 O(n + u log u)，空间 O(u)（每堆最多五项）。

替代方案

按学生分组后降序排序再取前五项，直观但最坏 O(n log n)。分数仅在 1–100 时，也可用计数数组从 100 向下取五项。

面试追问

  • K 很大时如何选择堆、排序或快速选择？
  • 成绩作为持续数据流到达时如何在线更新？
  • 若需精确小数，返回类型和取整规则怎样改变？

常见错误

  • 取成最低五分，或最大堆弹出了最高分。
  • 忘记按学生编号升序输出。
  • 未显式处理整数除法。
  • 误把相同分数去重。

class Solution {
  public int[][] highFive(int[][] items) {
    Map<Integer, PriorityQueue<Integer>> m = new TreeMap<>();
    for (int[] x : items) {
      PriorityQueue<Integer> h = m.computeIfAbsent(x[0], k -> new PriorityQueue<>());
      h.offer(x[1]); if (h.size() > 5) h.poll();
    }
    int[][] ans = new int[m.size()][2]; int i = 0;
    for (var e : m.entrySet()) {
      int sum = 0; for (int s : e.getValue()) sum += s;
      ans[i++] = new int[]{e.getKey(), sum / 5};
    }
    return ans;
  }
}
var highFive = function(items) {
  const m = new Map();
  for (const [id, score] of items) {
    if (!m.has(id)) m.set(id, []);
    const a = m.get(id); a.push(score); a.sort((x, y) => y - x);
    if (a.length > 5) a.pop();
  }
  return [...m.keys()].sort((a,b) => a-b).map(id =>
    [id, Math.floor(m.get(id).reduce((a,b) => a+b, 0) / 5)]);
};
from typing import List
import heapq

class Solution:
    def highFive(self, items: List[List[int]]) -> List[List[int]]:
        heaps = {}
        for student, score in items:
            heap = heaps.setdefault(student, [])
            heapq.heappush(heap, score)
            if len(heap) > 5:
                heapq.heappop(heap)
        return [[student, sum(heaps[student]) // 5]
                for student in sorted(heaps)]
