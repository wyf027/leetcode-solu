道路的最大总重要性

Maximum Total Importance of Roads

给城市分配独一无二的数值，让整张路网的重要性之和尽可能大。
先读题、尝试分配，再展开下方推导。

01 / 题目

一个国家有 n 座城市，编号为 0 … n−1。二维数组 roads 中的每个 [aᵢ, bᵢ] 表示连接两座城市的一条双向道路。

将整数 1 … n 恰好各使用一次，分别分配给所有城市。每条道路的重要性是它两端城市所获数值的和。返回所有道路重要性总和的最大值；无需返回具体分配方案。

官方示例 1

n = 5
roads = [[0,1],[1,2],[2,3],[0,2],[1,3],[2,4]]
输出：43

按城市编号分配 [2,4,5,3,1]，六条道路分别贡献 6、9、8、7、7、6，总和为 43。

官方示例 2

n = 5
roads = [[0,3],[2,4],[1,3]]
输出：20

按城市编号分配 [4,3,2,5,1]，三条道路分别贡献 9、3、8，总和为 20。

约束

  • 2 ≤ n ≤ 5 × 10⁴
  • 1 ≤ roads.length ≤ 5 × 10⁴
  • roads[i].length = 2
  • 0 ≤ aᵢ, bᵢ ≤ n−1，且 aᵢ ≠ bᵢ
  • 没有重复道路。图不保证连通，允许存在孤立城市。

04 / 题解工作台

准备好后，展开原理、动态过程与四语言代码。

核心洞察：每座城市的数值会被重复计算几次？

城市 v 连接多少条道路，它的数值 w[v] 就在总和中出现多少次。这个连接数称为城市的度数 d[v]。

总重要性 = Σ道路(w[a] + w[b]) = Σ城市 d[v] × w[v]

因此只需让大的数值匹配大的度数。按度数升序排序，依次分配 1, 2, …, n，再累加乘积。城市的编号大小不参与决策。

完整过程

  1. 建立长度为 n 的全零度数数组。
  2. 遍历每条道路 [a,b]，令 d[a] 和 d[b] 各加一。
  3. 将度数数组升序排序。
  4. 对下标 i 累加 d[i] × (i+1)。

示例 1：原度数 [2,3,4,2,1]，排序后 [1,2,2,3,4]，答案为 1×1 + 2×2 + 2×3 + 3×4 + 4×5 = 43。只求最大和时，无需保留城市编号。

正确性 · 交换论证

若两座城市满足 dₐ < dᵦ，却被分配 x > y，则交换数值后，总和增加：

(dᵦ − dₐ)(x − y) > 0

因此最优分配不能存在这种逆序。不断消除逆序，必然得到度数与数值同向排列，且总和不会下降。按升序配对正是这样的分配，故它是全局最优；相同度数之间怎样交换都不影响结果。

边界与复杂度

  • 设道路数为 m，时间 O(m + n log n)，总额外空间 O(n)，已包含度数数组与排序的辅助空间上界。
  • 孤立城市度数为 0，仍参与 1…n 的分配，优先拿最小数值。
  • 不连通图仍统一排序；各连通分量共享同一组数值。
  • 同度数可任意排序，答案可能有多种最优方案。
  • 总和不超过 2mn ≤ 5×10⁹，32 位有符号整数不够。Java / C++ 在乘法前提升到 64 位；JavaScript Number 可精确覆盖此范围。

替代方案

  • 度数桶：简单图度数位于 0…n−1，统计每个度数出现次数，按桶依次分配数值，可达 O(n+m) 时间、O(n) 空间。
  • 堆：反复取最高度数分配最大值，时间 O(m+n log n)，本题直接排序更简单。
  • 全排列：枚举 n! 种方案，每种计算道路和，仅适合极小规模的思路参照。

常见错误

  • 按城市编号分配，或给低度数最大值：优化目标是度数与数值的乘积和。
  • 每条道路只给一端计数：双向道路的两个端点都贡献一次。
  • 把贡献和再除以二：每条道路本来就需要两个端点的和，无需去重。
  • 排序后使用下标 i 作为值：题目值域从 1 开始，应使用 i+1。
  • JavaScript 使用无比较器的 sort()：默认按字符串排序，应写 (a,b) => a-b。
  • Java / C++ 先用 int 相乘再存 long：溢出可能已发生，先提升类型。

四语言实现

以下均采用官方方法签名，可作为对应语言的提交代码；未编译、未运行。

Java

import java.util.Arrays;

class Solution {
    public long maximumImportance(int n, int[][] roads) {
        int[] degree = new int[n];
        for (int[] road : roads) {
            degree[road[0]]++;
            degree[road[1]]++;
        }
        Arrays.sort(degree);
        long answer = 0;
        for (int i = 0; i < n; i++) {
            answer += (long) degree[i] * (i + 1);
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number} n
 * @param {number[][]} roads
 * @return {number}
 */
var maximumImportance = function(n, roads) {
    const degree = Array(n).fill(0);
    for (const [a, b] of roads) {
        degree[a]++;
        degree[b]++;
    }
    degree.sort((a, b) => a - b);
    let answer = 0;
    for (let i = 0; i < n; i++) {
        answer += degree[i] * (i + 1);
    }
    return answer;
};

Python 3

from typing import List

class Solution:
    def maximumImportance(self, n: int, roads: List[List[int]]) -> int:
        degree = [0] * n
        for a, b in roads:
            degree[a] += 1
            degree[b] += 1
        degree.sort()
        return sum(value * d for value, d in enumerate(degree, 1))

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    long long maximumImportance(int n, vector<vector<int>>& roads) {
        vector<int> degree(n, 0);
        for (const auto& road : roads) {
            ++degree[road[0]];
            ++degree[road[1]];
        }
        sort(degree.begin(), degree.end());
        long long answer = 0;
        for (int i = 0; i < n; ++i) {
            answer += 1LL * degree[i] * (i + 1);
        }
        return answer;
    }
};

面试追问

  • 如何输出具体分配？排序 (度数,城市编号)，按排名赋值后写回原编号位置。
  • 能否不用比较排序？利用度数最多为 n−1 做计数桶；本题没有自环和重边。
  • 数值换成任意给定数组？将数值与度数分别升序排序后配对；交换论证仍成立。
  • 每条道路有一个权重？如果贡献是权重乘以两端数值之和，将普通度数换成每座城市相邻道路的权重和，再排序。
  • 如何求最小总重要性？度数与数值反向配对。
