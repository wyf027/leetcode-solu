Data Stream as Disjoint Intervals

困难 非会员题 设计 数据流 有序集合

Problem

题目说明

有一个由非负整数持续到达的数据流。请设计 SummaryRanges，在任意时刻把已经出现过的所有整数汇总成若干个互不重叠的闭区间，并按区间起点升序返回。

注意：重复加入同一个整数不会改变结果；区间只描述“哪些整数出现过”，不记录出现次数。

接口

  • SummaryRanges()：用空数据流初始化对象。
  • void addNum(int value)：把整数 value 加入数据流。
  • int[][] getIntervals()：返回当前所有不相交区间 [startᵢ, endᵢ]，按 startᵢ 升序排列。

Solution

有序区间映射：只合并相邻邻居

核心洞察

保持强不变量

始终让所有区间按起点有序、彼此不交，并且任意相邻区间之间至少缺一个整数。

新值只影响局部

插入 value 时，只有起点不大于它的最近左区间，以及起点大于它的最近右区间可能被连接。

四种结果

它可能已被覆盖、成为新区间、延伸一侧，或恰好把左右两个区间桥接成一个。

完整过程

  1. 定位左邻居。在按区间起点有序的映射中，找起点 ≤ value 的最后一个区间。若它的终点 ≥ value，说明该值已存在，直接返回。
  2. 尝试连接左侧。若左区间终点恰为 value - 1，把新区间起点扩展为左区间起点，并移除旧左区间。
  3. 尝试连接右侧。找起点不小于 value 的第一个区间。若其起点不超过当前新区间终点加一，将它并入并移除旧右区间。
  4. 写回结果。插入最终的 [start, end]。有序映射天然保持返回顺序；数组版本用二分找到局部位置后执行同样合并。

正确性证明

不丢失：旧区间若被删除，其覆盖范围会被完整并入新区间；新值也包含在 [start, end] 中。

不多纳入：只有与新值或当前新区间端点相邻/相交的区间才被合并，因此合并后的每个整数都来自旧区间或本次新值。

仍不相交：算法检查并吸收所有可能接触新区间的左右邻居；其余区间与新区间之间仍至少有一个缺失整数。

因此每次 addNum 后，不变量都成立；按归纳法，getIntervals 返回的正是数据流中所有已出现整数的唯一有序不相交区间表示。

复杂度

实现addNumgetIntervals空间
有序映射（Java / C++）O(log k)O(k)O(k)
有序数组（Python / JavaScript）定位 O(log k)，移动最坏 O(k)O(k)（复制结果）O(k)

其中 k 是当前不相交区间数量。单次插入只会移除常数个相邻区间；数组实现的瓶颈是元素移动。

边界清单

  • 空数据流调用 getIntervals() 应返回空数组。
  • 重复值或落在现有区间内部的值必须幂等。
  • 值只连接左边、只连接右边、同时桥接两边，都要单独覆盖。
  • 检查约束端点 0 与 10000，避免错误的下标假设。
  • 返回二维数组时避免泄露可变内部结构；示例实现均生成副本或值对象。

四语言完整代码

import java.util.Map;
import java.util.TreeMap;

class SummaryRanges {
    private final TreeMap<Integer, Integer> intervals;

    public SummaryRanges() {
        intervals = new TreeMap<>();
    }

    public void addNum(int value) {
        Map.Entry<Integer, Integer> left = intervals.floorEntry(value);

        if (left != null && left.getValue() >= value) {
            return;
        }

        int start = value;
        int end = value;

        if (left != null && left.getValue() + 1 == value) {
            start = left.getKey();
            end = Math.max(end, left.getValue());
            intervals.remove(left.getKey());
        }

        Map.Entry<Integer, Integer> right = intervals.ceilingEntry(value);
        if (right != null && right.getKey() <= end + 1) {
            end = Math.max(end, right.getValue());
            intervals.remove(right.getKey());
        }

        intervals.put(start, end);
    }

    public int[][] getIntervals() {
        int[][] answer = new int[intervals.size()][2];
        int index = 0;
        for (Map.Entry<Integer, Integer> entry : intervals.entrySet()) {
            answer[index][0] = entry.getKey();
            answer[index][1] = entry.getValue();
            index++;
        }
        return answer;
    }
}
var SummaryRanges = function() {
    this.intervals = [];
};

/**
 * @param {number} value
 * @return {void}
 */
SummaryRanges.prototype.addNum = function(value) {
    let left = 0;
    let right = this.intervals.length;

    // 找第一个 end >= value - 1 的区间。
    while (left < right) {
        const mid = left + Math.floor((right - left) / 2);
        if (this.intervals[mid][1] < value - 1) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    let index = left;
    let start = value;
    let end = value;

    while (
        index < this.intervals.length &&
        this.intervals[index][0] <= end + 1
    ) {
        start = Math.min(start, this.intervals[index][0]);
        end = Math.max(end, this.intervals[index][1]);
        this.intervals.splice(index, 1);
    }

    this.intervals.splice(index, 0, [start, end]);
};

/**
 * @return {number[][]}
 */
SummaryRanges.prototype.getIntervals = function() {
    return this.intervals.map(([start, end]) => [start, end]);
};
from bisect import bisect_left
from typing import List


class SummaryRanges:
    def __init__(self):
        self.intervals: List[List[int]] = []

    def addNum(self, value: int) -> None:
        # Python 列表按 [start, end] 字典序排列。
        index = bisect_left(self.intervals, [value])
        start = value
        end = value

        if index > 0 and self.intervals[index - 1][1] + 1 >= value:
            index -= 1
            start = self.intervals[index][0]
            end = max(end, self.intervals[index][1])

        scan = index
        while scan < len(self.intervals) and self.intervals[scan][0] <= end + 1:
            start = min(start, self.intervals[scan][0])
            end = max(end, self.intervals[scan][1])
            scan += 1

        self.intervals[index:scan] = [[start, end]]

    def getIntervals(self) -> List[List[int]]:
        return [interval[:] for interval in self.intervals]
#include <map>
#include <vector>
using namespace std;

class SummaryRanges {
private:
    map<int, int> intervals;

public:
    SummaryRanges() = default;

    void addNum(int value) {
        auto right = intervals.upper_bound(value);
        int start = value;
        int end = value;

        if (right != intervals.begin()) {
            auto left = prev(right);
            if (left->second >= value) {
                return;
            }
            if (left->second + 1 == value) {
                start = left->first;
                end = max(end, left->second);
                intervals.erase(left);
            }
        }

        right = intervals.lower_bound(value);
        if (right != intervals.end() && right->first <= end + 1) {
            end = max(end, right->second);
            intervals.erase(right);
        }

        intervals[start] = end;
    }

    vector<vector<int>> getIntervals() {
        vector<vector<int>> answer;
        answer.reserve(intervals.size());
        for (const auto& [start, end] : intervals) {
            answer.push_back({start, end});
        }
        return answer;
    }
};

替代方案

布尔数组 / 有序集合：记录每个已出现值，查询时再扫描并压缩连续段。约束上界只有 10⁴ 时简单可靠，但每次查询会扫描整个值域或全部元素。

并查集：可连接相邻值并维护连通块边界，但还需有序输出各块；设计与删除/去重细节更复杂，本题通常不如有序区间直观。

常见错误

  • 只合并左侧或右侧，漏掉桥接两个区间。
  • 把“相邻”写成“相交”，导致 [1,1] 与新值 2 未合并。
  • 重复插入时额外创建重叠区间。
  • 遍历映射时删除元素，造成迭代器失效。
  • 直接返回内部数组，使调用者可以破坏状态。

面试追问

如果值域固定且很小，怎么做更简单？

用布尔数组标记出现情况；查询时线性扫描，把连续的 true 压成区间。时间可预测，代码也短。

如果 getIntervals 极少，而 addNum 极多呢？

可以优先优化写入：用哈希集合记录值，在查询时排序并压缩。代价从写入转移到读取。

如何支持删除一个值？

删除可能缩短区间、删除整个区间，或把一个区间拆成两个；需要先定位覆盖它的区间，再按这四类情况更新。

并发调用时要注意什么？

区间合并是复合读写操作，需在同一临界区完成；读操作还要避免观察到删除旧区间但尚未插入新区间的中间状态。
