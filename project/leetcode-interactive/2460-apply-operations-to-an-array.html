01 / PROBLEM

任务与规则

给定从下标 0 开始、长度为 n 的非负整数数组 nums。按 i = 0, 1, …, n − 2 的顺序执行操作：若当前 nums[i] 与 nums[i + 1] 相等，将前者加倍，后者设为 0；不相等则保持不变。全部操作结束后，把 0 移到末尾，保持其他元素的相对顺序，返回得到的数组。

每次比较读取上一步更新后的数组。不能同时操作，也不能提前移动 0。

官方示例 1

输入：nums = [1,2,2,1,1,0]
输出：[1,4,2,0,0,0]

i = 0：跳过；i = 1：得到 [1,4,0,1,1,0]；i = 2：跳过；i = 3：得到 [1,4,0,2,0,0]；i = 4：比较 0 与 0，操作后不变。最后移动 0 得到输出。

官方示例 2

输入：nums = [0,1]
输出：[1,0]

0 与 1 不相等，不发生合并。最后将 0 移到末尾。

约束：2 ≤ nums.length ≤ 2000；0 ≤ nums[i] ≤ 1000，元素均为整数。
函数：applyOperations(nums: integer[]) → integer[]

04 / SOLUTION

准备好再展开

核心思路、正确性说明和四语言代码在这里。

核心洞察：分清两个阶段

先按题意完成相邻操作，再稳定地移动非零元素。合并阶段修改的是“当前位置和下一位置”；整理阶段使用读指针 r 与写指针 w，将读到的非零元素写入左侧连续区域。最后将剩余位置补 0。

完整过程

  1. 从 i = 0 到 n − 2 依次比较当前两个数；相等则左边乘 2，右边置 0。
  2. 设 w = 0，r 从 0 到 n − 1 扫描。若 nums[r] 非零，执行 nums[w] = nums[r]，再令 w 加 1。
  3. 扫描结束后，区间 [0,w) 已经是稳定的非零序列，将 [w,n) 全部设为 0。
  4. 返回原数组。演示中整理阶段的尾部可能暂时保留旧值；这些位置在最后一步统一清零。

示例 1 的合并结果为 [1,4,0,2,0,0]。整理时依次写入 1、4、2，w = 3，然后填充三个 0。

正确性

相邻操作不变式：第 i 步开始前，数组与题目执行完前 i 步后的状态一致。按规则只更新 i 和 i + 1，便得到执行完第 i 步的正确状态。因此 n − 1 步结束后，合并阶段正确。

整理不变式：处理下标 r 前，[0,w) 恰好存放原合并结果中 [0,r) 的所有非零元素，且顺序不变；同时 w ≤ r。读到 0 时跳过，读到非零数时写入 w 并递增，保持不变式。由于只写入当前或更早位置，不会破坏尚未读取的数据。扫描完成后补 0，得到题目要求的数组。

复杂度

时间 O(n)：相邻扫描、压缩、补零都至多遍历一次数组。
额外空间 O(1)：四份代码均原地修改输入。

边界

0 与 0 相等，但操作后仍为 0；长度 2 只比较一次；全零与无零都适用。新生成的非零数位于已处理位置，不会再被后续操作加倍，数值最多为 2000。

替代方案

合并后创建新数组，依次收集非零值，再补 0：时间 O(n)，额外空间 O(n)，更容易书写。也可将合并与非零写入结合在一趟扫描中，最后补零；仍为 O(n) 时间、O(1) 空间，但必须证明写入不会影响下一次比较。两阶段写法更直接。

常见错误

  • 先移 0 再合并：[2,0,2] 会被错误变成 [4,0,0]。
  • 对原数组同时比较：[2,2,2] 应得到 [4,2,0]，第二步必须看到被置 0 的元素。
  • 像 2048 一样反复合并：[2,2,2,2] 的结果是 [4,4,0,0]，不是 [8,0,0,0]。
  • 比较到 i = n − 1 导致越界；压缩后忘记将尾部旧值补 0。
  • 排序移零会改变非零元素顺序，不满足要求。

面试追问

为什么原地压缩安全？因为 w ≤ r，写入位置不会超过当前读取位置。
如果不允许修改输入？先复制 nums，再操作，额外空间为 O(n)。
交换相邻操作顺序可以吗？不可以，[2,2,2] 从左到右得到 [4,2,0]，从右到左会得到 [2,4,0]。
如何降低遍历次数？可以在处理完位置 i 后立即收集该位置的非零值，但需处理最后一个元素并保证尚未比较的右侧区域不被覆盖。

Java

class Solution {
    public int[] applyOperations(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n - 1; i++) {
            if (nums[i] == nums[i + 1]) {
                nums[i] *= 2;
                nums[i + 1] = 0;
            }
        }
        int w = 0;
        for (int r = 0; r < n; r++) {
            if (nums[r] != 0) nums[w++] = nums[r];
        }
        while (w < n) nums[w++] = 0;
        return nums;
    }
}

class Solution:
    def applyOperations(self, nums: List[int]) -> List[int]:
        n = len(nums)
        for i in range(n - 1):
            if nums[i] == nums[i + 1]:
                nums[i] *= 2
                nums[i + 1] = 0
        w = 0
        for r in range(n):
            if nums[r] != 0:
                nums[w] = nums[r]
                w += 1
        while w < n:
            nums[w] = 0
            w += 1
        return nums
