分割数组的最多方案数

Maximum Number of Ways to Partition an Array

一次修改，多个平衡切口。先理解问题，再展开推导。

官方题目 ↗

题意

给定从 0 开始编号的整数数组 nums 和整数 k。可以保持数组原样，也可以选择一个位置，将该元素替换成 k。操作完成后，统计有多少个切分位置 pivot，使左、右两段的元素和相等；返回这个数量的最大值。

切口满足 1 ≤ pivot < n，左段为 nums[0..pivot−1]，右段为 nums[pivot..n−1]。两段都必须非空；统计的是同一个最终数组的合法切口数，不是修改操作的数量。

约束

  • n == nums.length
  • 2 ≤ n ≤ 10⁵
  • −10⁵ ≤ nums[i], k ≤ 10⁵

官方示例

示例 1

nums = [2,-1,2], k = 3
输出：1

把 nums[0] 改成 3，得到 [3,−1 | 2]，pivot = 2 时两侧和均为 2。

示例 2

nums = [0,0,0], k = 1
输出：2

不修改即可在 pivot = 1、2 处切分，两边的和都是 0。

示例 3

nums = [22,4,-25,-20,-15,15,-16,7,19,-10,0,-13,-14], k = -33
输出：4

将 nums[2] 替换成 −33 是一个最优选择，此时存在 4 个合法切口。

独立题解
核心洞察：按修改位置划分切口
定义原数组切口差值 D[p] = 2 × prefix[p] − total，其中 prefix[p] 为前 p 个数之和。D[p] = 0 就代表平衡。把位置 i 改成 k，变化量为 δ = k − nums[i]。
  • p ≤ i：被改元素位于右段，新的差值为 D[p] − δ；因此需要 D[p] = δ。
  • p > i：被改元素位于左段，新的差值为 D[p] + δ；因此需要 D[p] = −δ。
用 left 统计 p ≤ i 的原差值频次，right 统计 p > i 的原差值频次。修改 i 的方案数就是 left[δ] + right[−δ]。注意 left/right 描述切口相对于 i 的位置。
完整过程
  1. 计算 total，并构造 n−1 个切口差值；全部计入 right，left 为空。
  2. 用 right[0] 初始化答案，保留“不修改”的情况。
  3. 从 i = 0 向右枚举。计算 δ，先查询两张频次表，更新最大值。
  4. 查询结束后，将切口 p = i+1（如果存在）的差值从 right 移到 left，为下一次枚举准备。
示例 1 中 D = [1,−1]。修改 i = 0 时 δ = 1，left 为空，right[−1] = 1，得到一个合法切口。随后把 D[1] = 1 移入 left。
正确性
不变量：查询位置 i 时，left 恰好包含所有 p ≤ i 的差值，right 恰好包含所有 p > i 的差值。初始 i = 0 时所有合法切口都在 right，不变量成立。每轮查询后仅移动 p = i+1，恰好得到下一轮分界，因此归纳成立。
两个集合互不相交且覆盖全部合法切口。根据变化量公式，在两个集合分别查询 δ 和 −δ，恰好数出该次修改后的全部平衡切口，无遗漏、无重复。算法枚举每个可改位置并纳入不修改的结果，取最大值即为最优答案。
边界与数值范围
  • n = 2 只有一个切口；禁止把 p = 0 或 p = n 计入。
  • k 等于原值时 δ = 0，两张表中零的频次之和仍是原方案数。
  • 全零数组可能不修改最优；负数也适用，不要求前缀和单调。
  • 和与差值可超过 32 位整数。Java 使用 long，C++ 使用 long long；Python 整数可扩展；本题量级远低于 JavaScript Number 的安全整数上限。
复杂度
使用哈希表，期望时间 O(n)，空间 O(n)。哈希表访问按平均 O(1) 分析；并非无条件最坏 O(n) 的保证。
替代方案
逐个修改并重新扫描所有切口，时间 O(n²)，适合理解小例子，不适合 n = 10⁵。也可以建立“差值 → 有序切口下标列表”，对每个 i 二分统计两侧匹配数量，时间 O(n log n)、空间 O(n)。
常见错误
  • 把 δ 与 −δ 的查询方向颠倒。
  • 查询之前移动切口，导致 p = i+1 被分到错误的一侧。
  • 只枚举修改，遗漏保持原数组。
  • 频次用集合代替，丢失重复差值对应的多个切口。
  • 用 32 位变量保存累计和，或用位运算处理 JavaScript 的大整数和。
面试追问
如何返回一个最优修改位置？更新答案时一并保存 i，不修改用 −1 表示。如何省掉 diff 数组？第二遍再次累计原前缀和即可计算待移动差值，哈希表空间仍为 O(n)。如果允许修改两个位置？切口会落入三段，影响量依赖两个位置，当前单次扫动公式无法直接复用。

JavaScript
/** @param {number[]} nums @param {number} k @return {number} */
var waysToPartition = function(nums, k) {
    const n = nums.length, total = nums.reduce((s, x) => s + x, 0);
    const left = new Map(), right = new Map(), diff = [];
    const get = (m, x) => m.get(x) || 0;
    let prefix = 0;
    for (let p = 1; p < n; p++) {
        prefix += nums[p - 1];
        const d = 2 * prefix - total;
        diff.push(d);
        right.set(d, get(right, d) + 1);
    }
    let answer = get(right, 0);
    for (let i = 0; i < n; i++) {
        const delta = k - nums[i];
        answer = Math.max(answer, get(left, delta) + get(right, -delta));
        if (i < n - 1) {
            const d = diff[i];
            right.set(d, get(right, d) - 1);
            left.set(d, get(left, d) + 1);
        }
    }
    return answer;
};
Java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int waysToPartition(int[] nums, int k) {
        int n = nums.length;
        long total = 0, prefix = 0;
        for (int x : nums) total += x;
        long[] diff = new long[n - 1];
        Map<Long, Integer> left = new HashMap<>(), right = new HashMap<>();
        for (int p = 1; p < n; p++) {
            prefix += nums[p - 1];
            long d = 2 * prefix - total;
            diff[p - 1] = d;
            right.merge(d, 1, Integer::sum);
        }
        int answer = right.getOrDefault(0L, 0);
        for (int i = 0; i < n; i++) {
            long delta = (long) k - nums[i];
            answer = Math.max(answer, left.getOrDefault(delta, 0)
                + right.getOrDefault(-delta, 0));
            if (i < n - 1) {
                long d = diff[i];
                right.merge(d, -1, Integer::sum);
                left.merge(d, 1, Integer::sum);
            }
        }
        return answer;
    }
}
Python
from typing import List
from collections import Counter

class Solution:
    def waysToPartition(self, nums: List[int], k: int) -> int:
        total = sum(nums)
        prefix = 0
        diff = []
        for x in nums[:-1]:
            prefix += x
            diff.append(2 * prefix - total)
        left, right = Counter(), Counter(diff)
        answer = right[0]
        for i, x in enumerate(nums):
            delta = k - x
            answer = max(answer, left[delta] + right[-delta])
            if i < len(nums) - 1:
                d = diff[i]
                right[d] -= 1
                left[d] += 1
        return answer
C++
#include <vector>
#include <unordered_map>
#include <algorithm>
using namespace std;

class Solution {
public:
    int waysToPartition(vector<int>& nums, int k) {
        int n = nums.size();
        long long total = 0, prefix = 0;
        for (int x : nums) total += x;
        vector<long long> diff(n - 1);
        unordered_map<long long, int> left, right;
        for (int p = 1; p < n; ++p) {
            prefix += nums[p - 1];
            long long d = 2 * prefix - total;
            diff[p - 1] = d;
            ++right[d];
        }
        int answer = right[0];
        for (int i = 0; i < n; ++i) {
            long long delta = (long long)k - nums[i];
            answer = max(answer, left[delta] + right[-delta]);
            if (i < n - 1) {
                --right[diff[i]];
                ++left[diff[i]];
            }
        }
        return answer;
    }
};
