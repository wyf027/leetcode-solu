相似字符串组

若两个字符串相等，或只需交换其中两个不同位置的字符就能相等，则它们相似。相似关系可传递；求给定字符串数组中的相似字符串组数。

题意

所有字符串长度相同，且互为字母异位词。把每个字符串看成一个节点：相似的两个字符串连边，问题等价于计算无向图的连通分量数。

示例

["tars","rats","arts","star"] → 2

["omv","ovm"] → 1

约束

1 ≤ strs.length ≤ 300；1 ≤ strs[i].length ≤ 300；每个字符串只由小写字母组成，且任意两项互为字母异位词。

核心洞察

“在同一组”是连通性问题，而不是只比较某一对字符串。枚举所有字符串对；两个字符串的不同字符位置数为 0 或 2 时相似。用并查集把相似的节点合并，最后集合根的个数就是答案。

完整过程

  1. 初始化 n 个互不相连的并查集节点与组数 n。
  2. 枚举 i<j 的字符串对，逐字符计数不同位置；超过 2 个即可提前结束。
  3. 差异为 0 或 2 时合并两个集合；只有在根不同的成功合并时，组数减 1。

边界

  • 完全相同的字符串差异数为 0，仍属于同一组。
  • 差异数为 1 不可能通过一次交换修复。
  • 不要只数直接相似对；并查集会处理传递关系。

复杂度

设 n 为字符串数、m 为字符串长度。比较为 O(n²m)，并查集合并近似 O(1)；空间 O(n)。

替代方案与追问

可将字符串作为图节点做 DFS/BFS，复杂度与构图相同但需额外邻接表。追问：当 n 很大而 m 较小时，可为每个字符串枚举一次交换得到的候选串，再哈希查找邻居，降低成对比较成本。

常见错误

  • 把差异数为 0 的重复字符串排除。
  • 只比较首尾字符，而未检查所有位置。
  • 合并已同根的节点时重复减少组数。

// Java
class Solution { public int numSimilarGroups(String[] strs) { int n=strs.length,ans=n; int[] p=new int[n]; for(int i=0;i<n;i++)p[i]=i; for(int i=0;i<n;i++)for(int j=0;j<i;j++)if(sim(strs[i],strs[j])){int a=find(p,i),b=find(p,j);if(a!=b){p[a]=b;ans--;}} return ans;} int find(int[] p,int x){return p[x]==x?x:(p[x]=find(p,p[x]));} boolean sim(String a,String b){int d=0;for(int i=0;i<a.length();i++)if(a.charAt(i)!=b.charAt(i)&&++d>2)return false;return d==0||d==2;} }
// JavaScript
var numSimilarGroups = function(strs) { const p=strs.map((_,i)=>i); const f=x=>p[x]===x?x:(p[x]=f(p[x])); let ans=strs.length; for(let i=0;i<strs.length;i++)for(let j=0;j<i;j++){let d=0;for(let k=0;k<strs[i].length;k++)if(strs[i][k]!==strs[j][k])d++;if((d===0||d===2)&&f(i)!==f(j)){p[f(i)]=f(j);ans--;}} return ans; };
# Python
class Solution:
    def numSimilarGroups(self, strs: list[str]) -> int:
        parent = list(range(len(strs)))
        def find(x):
            if parent[x] != x: parent[x] = find(parent[x])
            return parent[x]
        ans = len(strs)
        for i in range(len(strs)):
            for j in range(i):
                if sum(a != b for a,b in zip(strs[i],strs[j])) in (0,2) and find(i) != find(j): parent[find(i)] = find(j); ans -= 1
        return ans
