Nim Game

一堆石头、每次拿 1～3 块、拿到最后一块的人获胜。先别急着看公式：先在回合实验室里逐步观察，找出决定胜负的节奏。

Problem

题目描述

你和朋友轮流从桌上的一堆石头中取石头。你先手；每回合当前玩家必须取走 1 到 3 块石头，取走最后一块石头的人获胜。

给定石头总数 n，假设双方每一步都采用最优策略；如果你能够获胜，返回 true，否则返回 false。

函数参数： canWinNim(n: integer) → boolean

Core Insight

核心洞察：把必败局面交给对手

每回合只能取 1～3 块。若轮到你时剩下 4 块，无论你取多少，对手都能一次拿完剩余石头。因此，4 是最小的必败局面。

这个结构会周期性重复：当石头数是 4 的倍数时，你取走 x 块后，对手总能取走 4 − x 块，把总取石量补成 4；反之，若石头数不是 4 的倍数，你可以先取走余数，把 4 的倍数留给对手。

最终判定

n % 4 !== 0 时先手获胜；否则先手必败。

完整推导过程

01

建立小规模局面

当 n 为 1、2、3 时，先手可以一次取完；当 n 为 4 时，先手无论取 1、2、3，都会给对手留下可一次取完的局面。

02

识别配对策略

若对手面对 4 的倍数并取 x 块，你取 4 − x 块。两人的一组回合固定消耗 4 块。

03

推广到任意 n

若 n 不是 4 的倍数，先取 n % 4 块，把 4 的倍数留给对手；之后持续使用配对策略，最终由你拿走最后一块。

正确性证明

命题：当且仅当 n % 4 !== 0 时，先手存在必胜策略。

必要性：若 n 是 4 的倍数，先手只能取 x ∈ {1,2,3} 块。后手取 4 − x 块后，剩余数量仍是 4 的倍数。后手可重复此回应，并最终取走最后一块，所以先手无法保证获胜。

充分性：若 n 不是 4 的倍数，令 r = n % 4，则 r ∈ {1,2,3}。先手先取 r 块，使剩余数量成为 4 的倍数。此后对手每次取 x 块，先手都取 4 − x 块，合法且把 4 的倍数重新留给对手。有限次后先手取走最后一块，因此必胜。

必要性与充分性同时成立，算法正确。

边界情况

  • n = 1、2、3：直接取完，返回 true。
  • n = 4：最小必败局面，返回 false。
  • n = 2³¹ − 1：取模安全，不需要递归或数组。

复杂度

  • 时间复杂度：O(1)。
  • 空间复杂度：O(1)。
  • 只执行一次取模与比较。

替代方案

  • 动态规划可逐个计算胜负，但需 O(n) 时间。
  • 递归搜索能表达极小化极大，但会重复计算。
  • 本题的周期规律使数学解最简洁。

常见错误

  • 误以为偶数或奇数决定胜负，忽略每次最多取 3 块所形成的 4 周期。
  • 只验证 n ≤ 4 就直接外推，没有说明配对策略为何能持续。
  • 使用 O(n) 动态规划，在最大输入下浪费时间和空间。
  • 把“双方最优”误解成随机取石头，进而用概率模拟。

面试追问

  1. 若每次可取 1～k 块，必败局面是什么？答案会推广为 k + 1 的倍数。
  2. 若“拿到最后一块的人输”，边界和周期如何变化？需先重建最小局面的胜负表。
  3. 若允许取的数量是不连续集合，如何求解？可用状态 DP 或 Sprague-Grundy 思想。
  4. 多个石堆时为何需要异或？那将进入经典 Nim 和 Nim-sum。
