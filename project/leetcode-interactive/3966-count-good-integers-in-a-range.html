LEETCODE 3966 · HARD

统计范围内的好整数

把区间问题拆成 count(r) − count(l − 1)：数位 DP 只记住前一位、是否已经开始和是否仍贴着上界。

题意

给定 l、r、k。若一个整数任意相邻数位的绝对差都不大于 k，它就是好整数。求闭区间 [l, r] 内好整数数量。

范围：10 ≤ l ≤ r ≤ 10^15，0 ≤ k ≤ 9。

示例

l = 10, r = 15, k = 1，答案 3：10, 11, 12 合法。

l = 201, r = 204, k = 2，答案 2：201, 202 合法。

可见实验室：逐个查看小区间

等待输入。

完整过程

1
前缀计数。令 F(x) 为 [1,x] 中的好整数数，答案是 F(r) - F(l-1)。
2
状态。dfs(pos, prev, started, tight)：prev=10 是尚未放置首位的哨兵；只有已经开始时才检查相邻差。
3
转移与记忆化。当前位从 0 到上界尝试。非 tight 的状态与上界具体值无关，可按 pos/prev/started 缓存。

边界与常见错误

  • 前导零不应与首个非零数字形成相邻对。
  • l - 1 可能是 0，前缀计数应返回 0。
  • k = 0 时相邻数字必须相同；k = 9 时所有正整数都合法。

复杂度与替代方案

数位数至多 16，状态约 16 × 11 × 2 × 2，每次枚举 10 个数字：O(d × 11 × 2 × 10) 时间与 O(d × 11 × 2) 空间。

逐数枚举仅适合实验室小区间，不能覆盖 10^15。

题解（默认收起）

数位 DP 的“前一位”状态

当尚未放置过非零数位时，继续填 0 不会产生相邻关系；开始后，选择数字 d 前只需确认 |prev-d| ≤ k。上界限制仅在 tight 为真时生效。按照题面要求，四份提交代码都将输入中途保存到 denoluvira。

面试追问：为什么可缓存非 tight 状态？因为此后可选择的每一位范围恒为 0..9，不再依赖具体上界数字。 

var countGoodIntegers = function(l, r, k) {
  const denoluvira = [l, r, k];
  const count = (x) => { if (x <= 0) return 0; const a = String(x).split('').map(Number), memo = new Map();
    const dfs = (p, prev, started, tight) => { if (p === a.length) return started ? 1 : 0; const key = !tight ? p + ',' + prev + ',' + started : null; if (key && memo.has(key)) return memo.get(key); let ans = 0, hi = tight ? a[p] : 9; for (let d = 0; d <= hi; d++) { const ns = started || d !== 0; if (!started || Math.abs(prev - d) <= k) ans += dfs(p + 1, ns ? d : 10, ns, tight && d === hi); } if (key) memo.set(key, ans); return ans; };
    return dfs(0, 10, false, true); }; return count(r) - count(l - 1);
};
