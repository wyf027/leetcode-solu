LCR 039 · HARD

柱状图中最大的矩形

给定每根柱子的高度，找出能由连续柱子组成的最大矩形面积。一次扫描中，用单调递增栈确定每根柱子能向左右延伸的边界。

题意

数组 heights 表示柱状图中各柱的高度，柱宽均为 1。选择一段连续柱子，将其中最低高度作为矩形高，求最大面积。

示例

heights = [2, 1, 5, 6, 2, 3]
最大矩形 = 柱 5、6
面积 = 5 × 2 = 10

约束

0 ≤ heights.length ≤ 10⁵；0 ≤ heights[i] ≤ 10⁴。需要线性时间，不能枚举全部左右边界。

单调栈实验室

在末尾补一个高度为 0 的哨兵。每当当前柱更矮，就弹出栈顶，并在此刻结算该柱作为最低柱的最大宽度。

载入示例后开始观察。

    测试与验证

    此交互页已内置固定样例对拍；浏览器自动化、跨语言编译和完整随机验证延后执行。

    核心洞察

    栈中保存尚未确定右边界的柱子下标，且对应高度严格递增。处理位置 i 时，若 heights[i] 更低，栈顶柱的右边界就确定为 i - 1；弹栈后新的栈顶给出左侧第一个更矮柱，因此宽度为 i - left - 1。补入哨兵 0 可一次性结算剩余柱子。

    完整过程

    1. 复制高度数组并在末尾补 0，保证所有候选都会被弹出。
    2. 从左到右扫描；当栈为空或当前高度不低于栈顶高度时，压入当前下标。
    3. 否则持续弹栈：被弹出的高度是当前区间最低高度，新的栈顶是其左侧第一个更矮柱。
    4. 用 height × (i - left - 1) 更新答案，再处理当前柱。

    边界与常见错误

    • 空数组答案为 0；高度为 0 的柱也要正常入栈和结算。
    • 宽度不是 i - top，而是跨过被弹出柱后的 i - left - 1。
    • 末尾哨兵不可遗漏，否则递增序列的候选永远不会结算。

    复杂度：每个下标最多入栈、出栈各一次，时间 O(n)，额外空间 O(n)。

    可提交代码

    Java

    class Solution {
    public int largestRectangleArea(int[] heights) {
        int[] a = java.util.Arrays.copyOf(heights, heights.length + 1);
        java.util.Deque<Integer> stack = new java.util.ArrayDeque<>();
        int best = 0;
        for (int i = 0; i < a.length; i++) {
            while (!stack.isEmpty() && a[stack.peek()] > a[i]) {
                int h = a[stack.pop()];
                int left = stack.isEmpty() ? -1 : stack.peek();
                best = Math.max(best, h * (i - left - 1));
            }
            stack.push(i);
        }
        return best;
    }
}
