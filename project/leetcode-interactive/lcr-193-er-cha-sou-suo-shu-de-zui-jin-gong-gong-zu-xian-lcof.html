二叉搜索树的最近公共祖先

让 BST 的有序性替你排除整片子树：两目标同在一侧就继续下探，第一次夹住两者的节点就是最近公共祖先。

题意与官方样例

给定二叉搜索树 root 和其中两个不同节点 p、q，返回它们的最近公共祖先。祖先可以是节点本身；题目保证两节点都存在、节点值互不相同。

官方示例 1root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8
输出：6
官方示例 2root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 4
输出：2
官方说明
所有节点值唯一；p ≠ q，且 p、q 均存在于给定 BST 中。
可视化补充用例root = [6,2,8,0,4,7,9,null,null,3,5], p = 3, q = 5
输出：4，用于完整展示左转、右转与命中。

题解 · 第一个夹住目标区间的节点

核心洞察

令 low = min(p.val, q.val)、high = max(p.val, q.val)。若当前值小于 low，两个目标都在右子树；若大于 high，都在左子树；否则当前值位于区间内，正是两路径分叉处（或其中一个目标），必须返回。

完整过程

  1. 取两个目标值的 low / high，消除 p、q 参数顺序影响。
  2. 从 root 迭代检查：val < low 时右移。
  3. val > high 时左移。
  4. 否则返回当前节点，无须继续搜索。

边界与复杂度

每轮都严格向下一层移动，最多访问树高 h 个节点：时间 O(h)，迭代额外空间 O(1)。平衡树为 O(log n)，退化链最坏为 O(n)。

  • p 或 q 本身是祖先：它落在闭区间端点，直接返回。
  • p、q 分居当前节点两侧：当前节点首次夹住它们。
  • 不要用普通二叉树的全树后序搜索，BST 已提供方向。

替代方案

通用二叉树 LCA 用递归回传左右子树命中，时间 O(n)；它适用于无序树，但在这里忽略了 BST 不变量。

常见错误：忘记先取 min/max；把等于 p/q 的节点继续向下走；或只比较一个目标，导致“同侧”判断错误。

面试追问

若节点可能不存在，应先验证查找路径；若允许重复值，必须按节点引用而非单个值判断，并明确重复值落左/右的 BST 约定。递归版逻辑相同，但深链可能消耗调用栈。

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        int low = Math.min(p.val, q.val), high = Math.max(p.val, q.val);
        while (root != null) {
            if (root.val < low) root = root.right;
            else if (root.val > high) root = root.left;
            else return root;
        }
        return null;
    }
}
