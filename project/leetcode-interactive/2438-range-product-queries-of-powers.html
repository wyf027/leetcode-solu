2438. 二的幂数组中
查询范围内的乘积

Range Product Queries of Powers

先理解查询，再探索计算过程。题解与代码默认折叠。

01 / 题目

给定正整数 n，将它表示成若干个 2 的非负整数次幂的和，要求使用的项数最少。把这些项按非递减顺序排列，得到唯一的数组 powers，下标从 0 开始。

另给二维整数数组 queries。每个 queries[i] = [left_i, right_i] 表示一个包含两端的下标区间。计算该区间内所有 powers 元素的乘积，对 1,000,000,007 取余，按查询顺序返回答案数组。

读题提醒

区间指的是 powers 的下标；查询两端都参与乘法。返回数组长度等于查询数。

参数与返回值

productQueries(n: integer, queries: integer[][]) → integer[]

约束

  • 1 ≤ n ≤ 10⁹
  • 1 ≤ queries.length ≤ 10⁵
  • 0 ≤ left_i ≤ right_i < powers.length（官方约束中也写作 start_i, end_i）。

02 / 官方示例

示例 1

输入：n = 15,
queries = [[0,1],[2,2],[0,3]]
输出：[2,4,64]

powers = [1,2,4,8]，这已是最少项数。三次查询分别得到 1 × 2 = 2、4 和 1 × 2 × 4 × 8 = 64；取余后均不变。

示例 2

输入：n = 2,
queries = [[0,0]]
输出：[2]

powers = [2]，唯一查询取下标 0 的元素，结果为 2，取余后不变。

04 / 独立题解

准备好后展开核心思路、分步实验和四种语言实现。

核心洞察：乘法变成指数相加

若出现两个相同的 2ᵏ，可合并为一个 2ᵏ⁺¹，项数会减少。因此最少项数的表示不含重复幂，恰好对应 n 二进制中所有为 1 的位。按位从低到高读出指数数组 e，就有 powers[i] = 2^e[i]。

∏ powers[i] = 2^(∑ e[i])

prefix[0] = 0，prefix[i+1] = prefix[i] + e[i]。

查询 [l,r] 的指数和是 prefix[r+1] − prefix[l]。

最大位号只有 29，总指数和不超过 0+1+…+29 = 435。预先逐次翻倍，得到 pow2[s] = 2^s mod M；每个查询一次前缀差、一次查表即可。

完整过程

  1. 从第 0 位到第 29 位扫描 n，每遇到一个 1，把位号累加进指数前缀和。
  2. 令 S 为所有置位位号之和。建立长度 S+1 的表，首项 1，后项为前项乘 2 再模 M。
  3. 对每个 [l,r]，计算 s = prefix[r+1] − prefix[l]，返回 pow2[s]。

例如 n=15：e=[0,1,2,3]，prefix=[0,0,1,3,6]。查询 [0,3] 得到 s=6−0=6，答案 2⁶=64。

正确性证明

一、表示正确且最少。 任意重复幂都可合并，直到不存在重复幂；这种表示就是唯一的二进制展开。合并只会减少项数，所以它具有最少项数。低位到高位的扫描顺序也保证 powers 非递减。

二、区间指数准确。 prefix[t] 保存 e 的前 t 项之和，所以 prefix[r+1]−prefix[l] 恰好包含 l 到 r 的每个指数一次。

三、查表给出正确余数。 pow2[0]=1，递推 pow2[s]=(2·pow2[s−1]) mod M。归纳可知每项等于 2ˢ mod M。结合同底数幂相乘的指数加法，所有查询的查表结果即所需乘积余数。

复杂度与边界

令 B 为 n 的二进制位数，k 为置位数，S 为置位位号之和，q 为查询数。时间 O(B + S + q)，额外空间 O(k + S)，返回数组另占 O(q)。本题 B≤30、S≤435，因此在固定数值范围下是 O(q) 时间，辅助空间有固定上界。

  • n=1 时指数为 0，前缀可重复；pow2[0]=1 必须存在。
  • n 是 2 的幂时只有一个元素，合法查询只能为 [0,0]。
  • l=r 仍按 prefix[r+1]−prefix[l]，不可误用 prefix[r]。
  • 输入可能有 10⁵ 个查询，避免为每次查询复制区间。
  • JavaScript 只做小于 2M 的翻倍，处于精确整数范围；不直接计算巨大乘积。

替代方案

逐查询枚举乘积： powers 最多 30 项，时间 O(B+qk)，也很实用。但 JavaScript 的普通 Number 连乘再取模可能丢失精度，应使用 BigInt。

指数前缀和 + 快速幂： 不预计算表，每次用模快速幂，时间 O(B+q log(S+1))，适合指数范围很大的变体。

前缀积 + 模逆元： 可行，但需要逆元逻辑。本题只含 2 的幂，用指数前缀和更直接；取模后的前缀积不能做普通除法。

常见错误与面试追问

  • 把 powers 当成 [1,2,4,…] 全部幂；它只包含 n 的置位对应项。
  • 求的是元素乘积，不能直接返回指数和。
  • 用 2 ** s 再取余会溢出或不精确，应逐步模运算。
  • 用位移计算结果 1<<s，位宽和符号会破坏大指数结果。

如果模数不是质数？ 本解法没有除法，递推取模仍然成立。

如果数组会更新？ 固定索引上的指数更新可用树状数组维护区间和；若更新 n 导致置位数组长度和下标变化，需要重新考虑结构。

为什么不用 BigInt？ 当前方案每次只翻倍一个模内整数，Number 足够精确；若改成任意两个模内数相乘，就应考虑 BigInt。

Java

class Solution {
    public int[] productQueries(int n, int[][] queries) {
        final int MOD = 1_000_000_007;
        int[] prefix = new int[31];
        int k = 0;
        for (int b = 0; b < 30; b++) {
            if ((n & (1 << b)) != 0) {
                prefix[k + 1] = prefix[k] + b;
                k++;
            }
        }
        int[] pow2 = new int[prefix[k] + 1];
        pow2[0] = 1;
        for (int s = 1; s < pow2.length; s++) {
            pow2[s] = (int) (2L * pow2[s - 1] % MOD);
        }
        int[] answer = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int l = queries[i][0], r = queries[i][1];
            answer[i] = pow2[prefix[r + 1] - prefix[l]];
        }
        return answer;
    }
}

/**
 * @param {number} n
 * @param {number[][]} queries
 * @return {number[]}

var productQueries = function(n, queries) {
    const MOD = 1_000_000_007;
    const prefix = [0];
    for (let b = 0; b < 30; b++) {
        if ((n & (1 << b)) !== 0) {
            prefix.push(prefix[prefix.length - 1] + b);
        }
    }
    const total = prefix[prefix.length - 1];
    const pow2 = [1];
    for (let s = 1; s <= total; s++) {
        pow2.push(pow2[s - 1] * 2 % MOD);
    }
    return queries.map(([l, r]) =>
        pow2[prefix[r + 1] - prefix[l]]
    );
};

Python3

from typing import List

class Solution:
    def productQueries(self, n: int,
                       queries: List[List[int]]) -> List[int]:
        mod = 1_000_000_007
        prefix = [0]
        for b in range(n.bit_length()):
            if n & (1 << b):
                prefix.append(prefix[-1] + b)
        pow2 = [1]
        for _ in range(prefix[-1]):
            pow2.append(pow2[-1] * 2 % mod)
        return [pow2[prefix[r + 1] - prefix[l]]
                for l, r in queries]

C++

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> productQueries(int n,
                                vector<vector<int>>& queries) {
        const int MOD = 1000000007;
        vector<int> prefix{0};
        for (int b = 0; b < 30; ++b) {
            if (n & (1 << b)) {
                prefix.push_back(prefix.back() + b);
            }
        }
        vector<int> pow2(prefix.back() + 1, 1);
        for (int s = 1; s < (int)pow2.size(); ++s) {
            pow2[s] = 2LL * pow2[s - 1] % MOD;
        }
        vector<int> answer;
        answer.reserve(queries.size());
        for (const auto& query : queries) {
            answer.push_back(
                pow2[prefix[query[1] + 1] - prefix[query[0]]]
            );
        }
        return answer;
    }
};
