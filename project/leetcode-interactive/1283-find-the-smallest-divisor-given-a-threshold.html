01 · Problem

先读清楚规则

Find the Smallest Divisor Given a Threshold

给定整数数组 nums 和正整数 threshold。选择一个正整数 divisor，让数组中的每个元素除以它，并把每个除法结果向上取整后求和。

请返回使这个总和小于或等于 threshold 的所有除数中，最小的那个。题目保证答案存在。

sum(divisor) = Σ ceil(nums[i] / divisor) ≤ threshold

约束

  • 1 ≤ nums.length ≤ 5 × 10⁴
  • 1 ≤ nums[i] ≤ 10⁶
  • nums.length ≤ threshold ≤ 10⁶
示例 1
输入：nums = [1,2,5,9], threshold = 6
输出：5
解释：d=4 时总和为 7；d=5 时为 5。
示例 2
输入：nums = [2,3,5,7,11], threshold = 11
输出：3
示例 3
输入：nums = [19], threshold = 5
输出：4

04 · Solution

在答案上做二分

单调性是钥匙，左边界是目标
核心洞察：除数越大，逐项向上取整之和只会不变或减小。因此“是否满足阈值”在整数轴上呈现一段不可行、接一段可行的单调结构。

完整过程

  1. 确定搜索边界。最小候选是 1；最大候选取 max(nums)。此时每项都至多贡献 1，而 threshold ≥ nums.length，所以右端点必定可行。
  2. 检查中点。对每个 x 计算 ceil(x / mid)。整数运算可写成 (x + mid - 1) / mid 再向下取整。
  3. 保留答案。若总和不超过阈值，mid 可行，但可能还不是最小，令 high = mid；否则令 low = mid + 1。
  4. 区间收束。当 low == high 时，它既可行，又是所有可行除数的左边界，直接返回。

正确性证明

不变量：答案始终位于闭区间 [low, high]。

若 mid 可行，由单调性可知所有大于 mid 的值也可行；最小可行值可能等于 mid，故更新为 [low, mid]。若 mid 不可行，则所有不大于 mid 的值都不可行，答案只能在 [mid+1, high]。

每轮区间严格缩小且不变量保持。终止时只剩一个候选，它就是最小可行除数。

复杂度

时间：O(n log M)，其中 M = max(nums)。

空间：O(1)（忽略输入）。

边界与实现细节

  • threshold == nums.length 时，答案必为数组最大值。
  • 单个元素同样适用，无需特判。
  • 累加和在 Java/C++ 中宜用 long/long long，并可在超过阈值后提前停止。
  • 右边界必须是可行值；max(nums) 正好满足。

常见错误

  • 使用普通整除，忘记每一项都要向上取整。
  • 可行时写成 high = mid - 1，却仍用 low < high 的左边界模板。
  • 把右边界设成阈值；阈值与元素最大值没有这种大小关系。
  • 用浮点 ceil 增加不必要的精度依赖。

四语言完整代码

Java 
class Solution {
    public int smallestDivisor(int[] nums, int threshold) {
        int low = 1;
        int high = 0;
        for (int value : nums) {
            high = Math.max(high, value);
        }

        while (low < high) {
            int mid = low + (high - low) / 2;
            long sum = 0;
            for (int value : nums) {
                sum += (value + mid - 1L) / mid;
                if (sum > threshold) break;
            }

            if (sum <= threshold) {
                high = mid;
            } else {
                low = mid + 1;
            }
        }
        return low;
    }
}

var smallestDivisor = function(nums, threshold) {
    let low = 1;
    let high = Math.max(...nums);

    while (low < high) {
        const mid = low + Math.floor((high - low) / 2);
        let sum = 0;

        for (const value of nums) {

            if (sum > threshold) break;

        if (sum <= threshold) {
            high = mid;
        } else {
            low = mid + 1;
        }
    }
    return low;
};

替代方案

线性枚举：从 1 到 max(nums) 逐个试除数，首次可行即返回。逻辑直观，但最坏时间为 O(nM)，在 M = 10⁶ 时不可取。

按答案二分：不对数组下标二分，而是在所有可能的除数上寻找判定函数的第一个 true。
