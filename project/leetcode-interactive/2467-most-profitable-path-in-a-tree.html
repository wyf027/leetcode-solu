树上最大得分和路径

2467 · Most Profitable Path in a Tree

两个人，一棵树。哪条路能让 Alice 留下最多得分？

先理解门的开关与同步移动规则，再尝试选择一片叶子。题解在页面底部，默认收起。

01 / 题目与规则

给定以节点 0 为根的无向树，共 n 个节点，编号为 0…n−1。edges[i] = [aᵢ, bᵢ] 表示一条边。每个节点有一扇门，amount[i] 为偶数：负数是开门成本，正数是开门奖励，零表示无得分变化。

  • 时刻 0，Alice 从根节点 0 出发，Bob 从 bob 出发，两人立即处理各自起点的门。
  • 每秒各走一条边：Alice 沿树向下走到所选叶子，Bob 沿唯一的向上路径走到根。
  • 先到者独自承担费用或获得奖励；同时到达则各分一半，负数费用也平分；门一旦打开，后来者的得分变化为 0。
  • Alice 到叶子、Bob 到根后各自停止；一人停止不影响另一人继续。

返回 Alice 从根走到某个叶子的最大净得分。她必须到达叶子，即使所有可选路线的总得分都是负数。

mostProfitablePath(edges: integer[][], bob: integer, amount: integer[]) → integer

约束

  • 2 ≤ n ≤ 10⁵；edges.length = n − 1，每条边恰有两个端点。
  • 0 ≤ aᵢ, bᵢ < n，且 aᵢ ≠ bᵢ；输入保证是一棵有效的树。
  • 1 ≤ bob < n；amount.length = n。
  • −10⁴ ≤ amount[i] ≤ 10⁴，每个值均为偶数。

02 / 官方示例

示例 1

edges = [[0,1],[1,2],[1,3],[3,4]]
bob = 3
amount = [-2,4,2,-4,6]

输出：6

Alice 走 0 → 1 → 3 → 4：起点扣 2 分；在节点 1 与 Bob 同时到达，得到 4 / 2 = 2 分；节点 3 已被 Bob 打开，得 0 分；最后节点 4 得 6 分。累计 −2 + 2 + 0 + 6 = 6。

示例 2

edges = [[0,1]]
bob = 1
amount = [-7280,2350]

输出：−7280

Alice 走 0 → 1，Bob 走 1 → 0。起点各自开门，Alice 到节点 1 时门已开，因此她只有根节点的 −7280 分。

05 / 独立题解

准备好后展开：思路、证明、四语言完整实现。

核心洞察：把两人移动化为到达时间比较

树中两点之间只有一条简单路径，Bob 的路线完全确定。Alice 若经过节点 u，到达时刻一定是该节点相对根的深度 depth[u]，不依赖她最终选择哪个叶子。先记录 Bob 的时间 bt[u]，不在 Bob 路线上的节点设为无穷大，便能给每个节点一个固定的 Alice 收益。

gain(u) = amount[u]      当 depth[u] < bt[u]
          amount[u] / 2  当 depth[u] = bt[u]
          0              当 depth[u] > bt[u]

于是问题变成固定点权树上的“最大根到叶路径和”，无需搜索 Bob 的选择，也无需在不同 Alice 路径间共享可变门状态。

完整过程

  1. 用邻接表建树；从根开始迭代遍历，记录 parent、depth 和父节点先于子节点出现的 order。
  2. 从 bob 沿 parent 走到根，依次标记时间 0、1、2……。其余 bt 填 n；任意真实深度最多 n−1，所以 n 可代表无穷大。
  3. 依次处理 order：按时间关系计算 gain，令 score[u] = score[parent[u]] + gain(u)，根的父路径和为 0。
  4. 只有非根且度数为 1 的节点是叶子，在这些节点的 score 中取最大值。

正确性论证

到达时间正确：根到每个节点的路径唯一，Alice 每秒向下走一步，故到达时刻等于深度。Bob 沿父节点链每秒走一步，标记的时间正好是其实际到达时间，链外节点永不到达。

单点收益正确：若 Alice 先到，独享原始值；同时到，分得一半；后到，门已开而收益为 0。三种情况互斥且穷尽，所以 gain 与游戏规则一致。

路径累加正确：根的 score 是根收益。假设父节点 score 正确，子节点唯一的根路径就是父路径加该节点，因此递推得到的子节点 score 正确。按父先于子的顺序，归纳可得全部 score 正确。

最优性：Alice 的所有合法路线与根到叶路径一一对应。遍历枚举了每片叶子，且计算了每条路径的真实净得分，最大值恰是最优答案。

边界与复杂度

  • 根的度数即使为 1，也不能当作可停下的叶子；题目 n ≥ 2。
  • 负费用相遇也除以 2，且偶数保证除法结果是整数。
  • 答案可能为负，必须从负无穷或最小整数开始取最大值。
  • 链状树可深达 10⁵；下面四份实现都使用迭代遍历，避免递归调用栈限制。
  • Bob 到根后无需继续更新时间或反复开门；起点已在时刻 0 处理。
  • 时间 O(n)：建树、遍历、父链与累加均为线性；额外空间 O(n)。
  • 路径和绝对值不超过 10⁹，Java/C++ 的 32 位有符号整数及 JavaScript Number 均可准确保存。

替代方案

可以先将 Bob 路线上的点权按时间改成一半或零，再做一次最大根到叶和 DFS，仍是 O(n)；复制 amount 可以避免修改输入。也可从叶到根做树形 DP：best[u] = gain(u) + max(best[child])，叶子直接取 gain，不能把子节点最大值与 0 比较而允许提前停止。递归实现较短，但深链需要显式栈或可靠的栈空间支持。

常见错误

  • 让 Bob 在所有相邻分支搜索收益；他的路线只能向根。
  • 漏算 t = 0 的起点门，导致全部时间错位。
  • 把 Bob 未经过的节点时间设为 0；应设为无穷大或 n。
  • 只平分正奖励，忽略同时到达的负费用。
  • 把最大中间路径和当答案，或用全局开门集合跨候选路线模拟，污染其他路线。
  • 遍历无向邻接表时不排除父节点，造成重复访问。

面试追问

如何返回最优路线？记录得分最大的叶子，沿 parent 回溯到根再反转即可。为何不需要 Dijkstra？这里是树且每条边移动耗时相同，路径唯一。若边有不同耗时？仍可沿唯一树路径累加双方到达时间，再比较时间。若允许 Alice 等待？深度不再等于到达时间，固定点权的前提失效，需要重新建模。

Java · 可提交代码

import java.util.*;

class Solution {
    public int mostProfitablePath(int[][] edges, int bob, int[] amount) {
        int n = amount.length;
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
        }
        int[] parent = new int[n], depth = new int[n];
        int[] order = new int[n];
        parent[0] = -1;
        int size = 1;
        for (int i = 0; i < size; i++) {
            int u = order[i];
            for (int v : g.get(u)) {
                if (v == parent[u]) continue;
                parent[v] = u;
                depth[v] = depth[u] + 1;
                order[size++] = v;
            }
        }
        int[] bt = new int[n];
        Arrays.fill(bt, n);
        for (int u = bob, t = 0; u != -1; u = parent[u], t++) {
            bt[u] = t;
        }
        int[] score = new int[n];
        int ans = Integer.MIN_VALUE;
        for (int u : order) {
            int gain = depth[u] < bt[u] ? amount[u]
                     : depth[u] == bt[u] ? amount[u] / 2 : 0;
            score[u] = (u == 0 ? 0 : score[parent[u]]) + gain;
            if (u != 0 && g.get(u).size() == 1) {
                ans = Math.max(ans, score[u]);
            }
        }
        return ans;
    }
}

/**
 * @param {number[][]} edges
 * @param {number} bob
 * @param {number[]} amount
 * @return {number}

var mostProfitablePath = function(edges, bob, amount) {
    const n = amount.length;
    const g = Array.from({length: n}, () => []);
    for (const [a, b] of edges) {
        g[a].push(b);
        g[b].push(a);
    }
    const parent = Array(n).fill(-1);
    const depth = Array(n).fill(0);
    const order = [0];
    for (let i = 0; i < order.length; i++) {
        const u = order[i];
        for (const v of g[u]) {
            if (v === parent[u]) continue;
            parent[v] = u;
            depth[v] = depth[u] + 1;
            order.push(v);
        }
    }
    const bt = Array(n).fill(n);
    for (let u = bob, t = 0; u !== -1; u = parent[u], t++) {
        bt[u] = t;
    }
    const score = Array(n).fill(0);
    let ans = -Infinity;
    for (const u of order) {
        const gain = depth[u] < bt[u] ? amount[u]
                   : depth[u] === bt[u] ? amount[u] / 2 : 0;
        score[u] = (u === 0 ? 0 : score[parent[u]]) + gain;
        if (u !== 0 && g[u].length === 1) {
            ans = Math.max(ans, score[u]);
        }
    }
    return ans;
};

Python 3 · 可提交代码

from typing import List

class Solution:
    def mostProfitablePath(self, edges: List[List[int]],
                           bob: int, amount: List[int]) -> int:
        n = len(amount)
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a].append(b)
            g[b].append(a)
        parent = [-1] * n
        depth = [0] * n
        order = [0]
        i = 0
        while i < len(order):
            u = order[i]
            i += 1
            for v in g[u]:
                if v == parent[u]:
                    continue
                parent[v] = u
                depth[v] = depth[u] + 1
                order.append(v)
        bt = [n] * n
        u, t = bob, 0
        while u != -1:
            bt[u] = t
            u = parent[u]
            t += 1
        score = [0] * n
        ans = -10**18
        for u in order:
            if depth[u] < bt[u]:
                gain = amount[u]
            elif depth[u] == bt[u]:
                gain = amount[u] // 2
            else:
                gain = 0
            score[u] = (0 if u == 0 else score[parent[u]]) + gain
            if u != 0 and len(g[u]) == 1:
                ans = max(ans, score[u])
        return ans
