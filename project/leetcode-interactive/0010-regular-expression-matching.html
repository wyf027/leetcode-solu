题解

核心洞察、转移过程、边界、复杂度、追问、常见错误与四语言代码默认隐藏。

CORE INSIGHT

不要问字符，先问前缀

定义 dp[i][j]：s 的前 i 个字符，能否被 p 的前 j 个字符完整匹配。答案就是 dp[m][n]。

STAR HAS TWO RAILS

零次：dp[i][j - 2]

多次：firstMatch && dp[i - 1][j]

星号永远绑定前一个元素，所以“跳过”要一次退两列。

FULL WALKTHROUGH

完整解题过程

  1. 1. 定义状态：dp[i][j] 只描述两个前缀是否完整匹配。
  2. 2. 空串初始化：dp[0][0] = true；模式形如 x*y* 时可连续跳过两列。
  3. 3. 普通字符 / 点号：当前字符匹配，并且左上角状态为真，当前格才为真。
  4. 4. 星号：合并“出现零次”与“当前字符匹配后继续使用该星号”两条路径。
  5. 5. 收口：必须读取 dp[m][n]，因为题目要求整个字符串与整个模式完全匹配。

边界情况

  • 模式中的星号可令一整组出现零次。
  • 点号只匹配一个字符；只有 .* 才可覆盖任意长度。
  • 末尾多出的普通字符不能被忽略。
  • 初始化空行时只能处理以星号结尾的合法组。

复杂度

时间：O(mn)

空间：O(mn)

可滚动数组压到 O(n)，但二维表更方便面试解释与排错。

替代方案

自顶向下递归 + 记忆化同样是 O(mn)，代码更贴近“试两条路”的直觉；但递归状态、调用栈和空串边界更容易在白板上失控，因此主线推荐自底向上 DP。

class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length(), n = p.length();
        boolean[][] dp = new boolean[m + 1][n + 1];
        dp[0][0] = true;

        for (int j = 2; j <= n; j++) {
            if (p.charAt(j - 1) == '*') {
                dp[0][j] = dp[0][j - 2];
            }
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                char current = p.charAt(j - 1);
                if (current == '*') {
                    boolean matches = p.charAt(j - 2) == '.'
                        || p.charAt(j - 2) == s.charAt(i - 1);
                    dp[i][j] = dp[i][j - 2]
                        || (matches && dp[i - 1][j]);
                } else {
                    boolean matches = current == '.'
                        || current == s.charAt(i - 1);
                    dp[i][j] = matches && dp[i - 1][j - 1];
                }
            }
        }
        return dp[m][n];
    }
}

面试高频追问

为什么星号要看 j - 2？
它和前一个元素构成不可拆分的重复组；出现零次就是整组删除。
为什么多次分支仍停在 j？
当前星号组还可以继续消费下一个相同字符，因此模式指针不前进。
能否把空间压到 O(n)？
可以，但更新顺序更难解释；先写二维正确版，再按需求优化。

常见错误

  • 把 * 当成“任意字符串”，忘记它只修饰前一个元素。
  • 没有初始化 dp[0][j]，导致 a* 不能匹配空前缀。
  • 星号多次分支误写为 dp[i - 1][j - 2]。
  • 返回中间任意真格，而不是右下角 dp[m][n]。
