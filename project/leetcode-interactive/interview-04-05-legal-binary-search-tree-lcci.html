Problem Brief

题意

给定二叉树根节点 root，判断它是否为有效二叉搜索树。对任意节点，左子树所有值必须严格小于它，右子树所有值必须严格大于它，并且两棵子树也要满足同一规则。

官方样例 1

root = [2,␠1,␠3]

输出

true

官方样例 2

root = [5,␠1,␠4,␠null,␠null,␠3,␠6]

输出

false

1 ≤ 节点数 ≤ 10⁴ −2³¹ ≤ Node.val ≤ 2³¹ − 1 比较必须严格

可见空格约定：输入代码中的 ␠ 表示一个普通空格，便于核对完整参数；null 表示缺失节点。

Sealed Passport Notes

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码默认隐藏。

祖先上下界 DFS

核心洞察

节点是否合法由所有祖先共同决定，而不只是父节点。递归参数携带独占区间 `(lower, upper)`：左子树把当前值设为新上界，右子树把当前值设为新下界。

完整过程

  1. 根节点从 `(−∞, +∞)` 开始。
  2. 若 `value ≤ lower` 或 `value ≥ upper`，立即返回 false。
  3. 递归检查左子树 `(lower, value)`。
  4. 递归检查右子树 `(value, upper)`；两侧都通过才返回 true。

边界与复杂度

  • 相等值不允许，比较必须使用 `≤` / `≥` 拒绝。
  • 节点值覆盖 32 位整数边界；Java 用 long，其他语言使用无穷或宽类型。
  • 时间 O(n)，每个节点最多访问一次。
  • 递归栈 O(h)；平衡树 O(log n)，最坏链状树 O(n)。

替代方案取舍

中序遍历必须严格递增，也能做到 O(n)，并可写成显式栈以规避深递归；但上下界 DFS 更直接表达题目定义，也更容易解释“深层节点受祖先约束”的原因。汇总子树最小/最大值会带来更多状态，面试中通常不优先。

面试追问

  • 追问：如何避免递归栈溢出？改用显式栈保存节点及上下界。
  • 追问：允许重复值时怎么办？先明确重复值归属侧，再相应调整开闭区间。
  • 追问：中序法为什么正确？BST 的中序序列必须严格递增，反之亦然。

常见错误

  • 只比较 `node.left < node < node.right`，遗漏祖先的全局边界。
  • 使用 32 位哨兵，遇到 `−2³¹` 或 `2³¹−1` 时误判。
  • 把相等值放行，违反严格小于/大于的定义。
class Solution {
    public boolean isValidBST(TreeNode root) {
        return valid(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean valid(TreeNode node, long lower, long upper) {
        if (node == null) return true;
        if (node.val <= lower || node.val >= upper) return false;
        return valid(node.left, lower, node.val)
            && valid(node.right, node.val, upper);
    }
}

class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def valid(node, lower, upper):
            if node is None:
                return True
            if node.val <= lower or node.val >= upper:
                return False
            return valid(node.left, lower, node.val) and valid(
                node.right, node.val, upper

        return valid(root, float("-inf"), float("inf"))
