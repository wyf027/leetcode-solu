好子序列查询

每次单点更新后，判断是否能留下一个 非空且长度 < n 的子序列，使它的 GCD 恰为 p。

题意

给定 nums、p 与更新 queries[i] = [ind_i, val_i]。每次更新后，统计存在好子序列的轮数。只要一个数不被 p 整除，它绝不能放进 GCD 为 p 的子序列。

限制：2 ≤ n, q ≤ 5×10⁴，元素、p 与更新值不超过 5×10⁴。

更新演示

nums = [4, 8, 12, 16]，p = 2

准备执行第 1 次更新。

初始状态：尚未应用查询。

测试与验证

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

输入
nums = [4,8,12,16], p = 2, queries = [[0,3],[2,6]]
期望输出
1
实际输出
—
状态
待补

题解：只维护可入选的元素

令 b_i = nums[i]（当 b_i % p = 0 时保留，否则记为 0）。线段树维护这些值的 GCD 与可入选个数 cnt。如果 gcd(b) != p，没有答案；若 cnt < n，取所有可入选元素已经是严格更短的子序列；仅当 cnt = n 时，要排除至少一个位置。

对于最后一种情形，检查少量位置 i 的 gcd(nums[0..i-1], nums[i+1..n-1]) 是否为 p。若所有位置都“关键”，每个位置都需要一个不同质因子；在值上界 5×10⁴ 下不可能有 8 个这样的关键位置。因此最多试前 8 个位置。每个排除 GCD 由两次线段树区间查询得到。

复杂度：建树 O(n)，每次更新 O(log n)，额外至多 8 次 O(log n) 查询；空间 O(n)。

边界与替代方案

  • 没有 p 的倍数时线段树 GCD 为 0，直接否定。
  • 如果 cnt < n，非 p 倍数天然被排除，长度约束自动满足。
  • 暴力枚举子序列指数级；每次重做前后缀 GCD 为 O(nq)，均不适用。

面试追问 / 常见错误

  • 为什么能只看前 8 个？反证法：每个关键位置对应一个只缺它的不同质因子，8 个时会迫使某个元素含 7 个最小不同质因子的乘积，已超过上界。
  • 不能把非 p 倍数一起做 GCD；它们根本不可选。
  • 所有元素都可选且整体 GCD 为 p 仍不够：整数组长度为 n，必须能删除一个元素。
