数与其逆序数之间的质数和

先将 n 的数字逆序得到 r，再把两者夹出的闭区间中的质数全部相加。

题面示例：n = 13，r = 31，区间为 [13, 31]，答案为 132。

题意

给定整数 n。令 r 为将 n 十进制数字反转得到的整数（前导零自然消失）。返回 min(n, r) 到 max(n, r)（含端点）所有质数之和。

约束：1 ≤ n ≤ 1000。因此反转后的数也不超过 1000，直接筛到上界非常轻量。

准备展开 n = 13 对应的质数区间。

题解：逆序 + 埃氏筛

核心洞察：题目范围的端点最多为 1000。用整数运算反转 n，然后对 [low, high] 使用事先筛好的质数表累加即可。

完整过程

  1. 反复取 x % 10 并写入 r，得到逆序数。
  2. 令 low = min(n, r)、high = max(n, r)。
  3. 用埃氏筛标记 0 到 high 的质数；0、1 不是质数。
  4. 遍历闭区间，若表中为质数就加入答案。

边界

  • n = 10 反转为 1：1 不可计入。
  • 回文数使区间退化为一个数，例如 n = 8，答案为 0。
  • 端点本身若为质数，因区间闭合必须计入。

复杂度

设 H = max(n, r)。筛法为 O(H log log H) 时间和 O(H) 空间，随后区间求和为 O(H)；这里 H ≤ 1000。

替代方案

也可对区间每一个数试除到平方根，额外空间 O(1)。在本题小约束下同样可接受；若要多次查询，筛法更稳定。

面试追问

若 n 上界变成 109，不要整段建表；可先筛到 √high，再用分段筛处理 [low, high]。

常见错误

  • 把 1 当成质数。
  • 忽略 n 尾部零反转后消失。
  • 漏掉 low 或 high 端点。

class Solution {
    public int sumOfPrimesInRange(int n) {
        int r = 0, x = n;
        while (x > 0) { r = r * 10 + x % 10; x /= 10; }
        int high = Math.max(n, r), low = Math.min(n, r);
        boolean[] prime = new boolean[high + 1];
        java.util.Arrays.fill(prime, true);
        if (high >= 0) prime[0] = false;
        if (high >= 1) prime[1] = false;
        for (int p = 2; p * p <= high; p++) if (prime[p])
            for (int q = p * p; q <= high; q += p) prime[q] = false;
        int ans = 0;
        for (int v = low; v <= high; v++) if (prime[v]) ans += v;
        return ans;
    }
}

class Solution:
    def sumOfPrimesInRange(self, n: int) -> int:
        r, x = 0, n
        while x:
            r = r * 10 + x % 10
            x //= 10
        low, high = min(n, r), max(n, r)
        prime = [True] * (high + 1)
        prime[0] = prime[1] = False
        for p in range(2, int(high ** 0.5) + 1):
            if prime[p]:
                prime[p * p:high + 1:p] = [False] * len(prime[p * p:high + 1:p])
        return sum(v for v in range(low, high + 1) if prime[v])
