树的直径 Tree Diameter

在一棵无向树中，寻找任意两点之间最长简单路径所包含的边数。

题目

给定二维整数数组 edges。每个 edges[i] = [aᵢ, bᵢ] 表示节点 aᵢ 与 bᵢ 之间有一条无向边。所有边共同构成一棵节点编号为 0 到 n - 1 的树。

树的直径是树中任意两个节点之间最长简单路径的长度；路径长度按经过的边数计算。请返回该直径。

函数签名： treeDiameter(edges: int[][]): int

示例 1

输入：edges = [[0,1],[0,2]]
输出：2

解释：最长路径可取 1 → 0 → 2，共 2 条边。

示例 2

输入：edges = [[0,1],[1,2],[2,3],[1,4],[4,5]]
输出：4

解释：路径 3 → 2 → 1 → 4 → 5 含 4 条边。

约束

  • n = edges.length + 1
  • 1 ≤ n ≤ 10⁴
  • edges[i].length = 2
  • 0 ≤ aᵢ, bᵢ < n，且 aᵢ ≠ bᵢ
  • 输入保证是一棵连通、无环的无向树。

完整题解

核心洞察

在树上从任意节点 A 出发，离它最远的节点 B 一定可以作为某条直径的端点。再从 B 出发，能到达的最远距离就是整棵树的直径。树没有环且两点间路径唯一，因此 BFS 或 DFS 都能准确计算边数距离。

完整过程

  1. 由 edges 建立无向邻接表；节点数是 edges.length + 1。
  2. 从任意节点（例如 0）执行 BFS，记录最后得到的最远节点 B。
  3. 从 B 再执行一次 BFS，得到最远节点 C 以及距离 d。
  4. 返回 d。若树只有一个节点、没有边，两次搜索的最大距离都是 0。

正确性说明

引理：从树中任意节点开始，距离最远的节点必然是某条直径的端点。设一条直径端点为 X, Y，把起点到这条直径的唯一路径接入点记为 P。若搜索得到的最远节点不在某条最长路径端部，则沿其路径继续向外仍能增加距离，与“最远”矛盾；比较经过 P 的唯一路径，也可将直径的一个端点替换为该最远节点而不缩短直径。

定理：第一次 BFS 找到的 B 是某条直径端点。第二次 BFS 枚举了从 B 到所有节点的唯一距离，所得最远节点 C 与 B 的路径不能短于任何其他从 B 出发的路径；由于 B 属于一条直径，这一最大距离恰等于树的直径。因此算法返回值正确。

边界情况

  • 空边数组代表单节点树，答案为 0。
  • 链状树的直径为 n - 1。
  • 星状树在 n > 1 时直径为 2。
  • 节点编号并不表示遍历顺序，必须依据边构建邻接表。

复杂度

建图和两次 BFS 都是线性的。时间复杂度 O(n)，邻接表、队列和距离数组的空间复杂度 O(n)。

替代方案

也可做一次树形 DP：DFS 时为每个节点维护向下延伸的最长、次长链，两者之和更新全局直径。它同样是 O(n)，但递归深度在链状树上可达 O(n)；某些语言需要改成迭代写法或调整栈限制。还可通过逐层删除叶子找到树中心，再由中心到最远叶子的层数推导直径，但实现更绕。

完整代码

Java

import java.util.*;

class Solution {
    public int treeDiameter(int[][] edges) {
        int n = edges.length + 1;
        List<Integer>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : edges) {
            graph[edge[0]].add(edge[1]);
            graph[edge[1]].add(edge[0]);
        }
        int endpoint = bfs(0, graph)[0];
        return bfs(endpoint, graph)[1];
    }

    private int[] bfs(int start, List<Integer>[] graph) {
        int[] distance = new int[graph.length];
        Arrays.fill(distance, -1);
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(start);
        distance[start] = 0;
        int farthest = start;
        while (!queue.isEmpty()) {
            int node = queue.poll();
            if (distance[node] > distance[farthest]) farthest = node;
            for (int next : graph[node]) {
                if (distance[next] == -1) {
                    distance[next] = distance[node] + 1;
                    queue.offer(next);
                }
            }
        }
        return new int[] {farthest, distance[farthest]};
    }
}

/**
 * @param {number[][]} edges
 * @return {number}
 */
var treeDiameter = function(edges) {
    const n = edges.length + 1;
    const graph = Array.from({ length: n }, () => []);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
    }

    const bfs = (start) => {
        const distance = new Array(n).fill(-1);
        const queue = [start];
        distance[start] = 0;
        let head = 0;
        let farthest = start;
        while (head < queue.length) {
            const node = queue[head++];
            if (distance[node] > distance[farthest]) farthest = node;
            for (const next of graph[node]) {
                if (distance[next] === -1) {
                    distance[next] = distance[node] + 1;
                    queue.push(next);
                }
            }
        }
        return [farthest, distance[farthest]];
    };

    const [endpoint] = bfs(0);
    return bfs(endpoint)[1];
};

Python

from collections import deque
from typing import List, Tuple

class Solution:
    def treeDiameter(self, edges: List[List[int]]) -> int:
        n = len(edges) + 1
        graph = [[] for _ in range(n)]
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)

        def bfs(start: int) -> Tuple[int, int]:
            distance = [-1] * n
            distance[start] = 0
            queue = deque([start])
            farthest = start
            while queue:
                node = queue.popleft()
                if distance[node] > distance[farthest]:
                    farthest = node
                for nxt in graph[node]:
                    if distance[nxt] == -1:
                        distance[nxt] = distance[node] + 1
                        queue.append(nxt)
            return farthest, distance[farthest]

        endpoint, _ = bfs(0)
        return bfs(endpoint)[1]

C++

#include <vector>
#include <queue>
#include <utility>
using namespace std;

class Solution {
public:
    int treeDiameter(vector<vector<int>>& edges) {
        int n = static_cast<int>(edges.size()) + 1;
        vector<vector<int>> graph(n);
        for (const auto& edge : edges) {
            graph[edge[0]].push_back(edge[1]);
            graph[edge[1]].push_back(edge[0]);
        }
        int endpoint = bfs(0, graph).first;
        return bfs(endpoint, graph).second;
    }

private:
    pair<int, int> bfs(int start, const vector<vector<int>>& graph) {
        vector<int> distance(graph.size(), -1);
        queue<int> nodes;
        nodes.push(start);
        distance[start] = 0;
        int farthest = start;
        while (!nodes.empty()) {
            int node = nodes.front();
            nodes.pop();
            if (distance[node] > distance[farthest]) farthest = node;
            for (int next : graph[node]) {
                if (distance[next] == -1) {
                    distance[next] = distance[node] + 1;
                    nodes.push(next);
                }
            }
        }
        return {farthest, distance[farthest]};
    }
};

面试追问

  • 为什么不是从每个节点都搜索？ 利用树的唯一路径与直径端点性质，两次搜索已足够，把 O(n²) 降为 O(n)。
  • BFS 能换成 DFS 吗？ 可以，只要累计边数并找最远节点；迭代 DFS 可避免递归栈溢出。
  • 边有权重怎么办？ 树上仍可两次遍历，累计权重即可；若权重允许为负数，“任意点最远端”性质需要重新审视，通常使用树形 DP。
  • 如何恢复具体直径路径？ 第二次 BFS 保存父节点，从最远端 C 反向追溯到 B。

常见错误

  • 把直径理解为节点数量；本题返回的是边数。
  • 只做一次 BFS 并直接使用任意起点的最远距离。
  • 建无向图时漏掉反向边。
  • 使用 queue.shift() 实现 JavaScript 队列，导致大输入下反复移动数组；应使用头指针。
  • 忘记单节点树：edges = [] 时仍要创建节点 0，并返回 0。
