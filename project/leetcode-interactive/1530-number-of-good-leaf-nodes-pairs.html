好叶子节点对的数量

不急着看答案。先观察一棵树如何从叶子向上汇报“距离”，再让两个子树在最近公共祖先处完成配对。

树 深度优先搜索 二叉树 树形 DP
≤ 10

距离上限很小。每个节点只需携带有限长度的距离计数，不必枚举整棵树上的所有叶子对。

函数签名：countPairs(root, distance)
01 / PROBLEM

题目是什么？

先理解问题，再进入机制

给定二叉树根节点 root 和整数 distance。从树中选择两个不同的叶子节点；若它们之间最短路径所包含的边数不超过 distance，这两个叶子就构成一组“好叶子节点对”。返回这样的无序节点对数量。

路径长度按边计数。 一对叶子只计算一次，(a, b) 与 (b, a) 是同一对。

约束

  • 树中节点数为 [1, 2^10]
  • 1 ≤ Node.val ≤ 100
  • 1 ≤ distance ≤ 10

官方示例（完整参数）

示例 1
输入：root = [1,2,3,null,4], distance = 3
输出：1
解释：叶子 3 和 4 的最短路径长度为 3。
示例 2
输入：root = [1,2,3,4,5,6,7], distance = 3
输出：2
解释：[4,5]、[6,7] 的路径长度均为 2。
示例 3
输入：root = [7,1,4,6,null,5,3,null,null,null,null,null,2], distance = 3
输出：1
解释：唯一的好叶子节点对是 [2,5]。
示例 4 / 5
输入：root = [100], distance = 1
输出：0

输入：root = [1,1,1], distance = 2
输出：1

03 / SOLUTION

准备好，再揭开题解

先试着用一句话概括规律

一个节点真正需要从左右子树获得什么信息，才能判断跨过自己的两个叶子是否构成好节点对？

THE REVEAL

后序遍历 + 距离计数

核心洞察

每个节点只向父节点返回：其子树内叶子到自己的距离分布。左右分布合并时，若 leftDistance + rightDistance ≤ distance，对应的叶子组合都合法。

状态定义

count[d] 表示当前子树中，与当前节点相距 d 条边的叶子数。叶子节点返回 count[1] = 1 给自己的父节点。

完整过程

  1. 后序遍历：先递归得到左、右子树的距离数组。
  2. 枚举左距离 i 与右距离 j。若 i + j ≤ distance，答案增加 left[i] × right[j]。
  3. 把左右距离整体加一后交给父节点，即 current[d + 1] += left[d] + right[d]。
  4. 距离已经达到上限的叶子无需继续上传：再向上至少多一条边，不可能参与新的合法配对。

正确性说明

完备性：任意两个不同叶子都有唯一的最近公共祖先。后序遍历处理到该祖先时，这两个叶子分属左右子树，算法会检查它们的两段距离之和，因此每个好节点对一定被统计。

唯一性：这对叶子只会在其最近公共祖先处分居左右；在其他节点处不会再次以跨左右子树的形式出现，所以不会重复计数。

合法性：在祖先处两段路径相加正是两叶子的最短路径长度，算法仅在该和不超过 distance 时累加，因此计入的每一对都合法。

边界情况

  • 空树或只有一个叶子：答案为 0。
  • distance = 1：两个不同叶子不可能相距 1。
  • 重复节点值不影响计数；统计的是节点身份，不是值。
  • 倾斜树只有一个叶子，不产生节点对。

复杂度

设节点数为 n、距离上限为 D。每个节点最多枚举 D² 个距离组合：

时间：O(nD²)
空间：O(nD)（返回数组与递归栈；实现复用得当时辅助数组可更小）。

替代方案

也可从每个叶子做限深 DFS / BFS，再除以 2。实现直观，但会重复访问大量节点；叶子较多时通常劣于一次后序遍历。还可收集每棵子树的叶子距离列表，但计数数组更紧凑。

常见错误

  • 把叶子到自身记为 1，随后又多加一次，产生 off-by-one。
  • 使用 < 而不是 ≤。
  • 合并同一子树内部的叶子，导致重复计数。
  • 上传距离时没有截断，徒增空间和枚举量。

面试追问

如果是多叉树？

逐个合并子树距离分布：新子树先与累计分布配对，再并入累计分布。

如果边有权重？

数组下标改为路径权重，或使用稀疏映射保存可达距离；合并条件仍是两段距离之和不超过阈值。

能否做到 O(nD)？

可用前缀和优化左右距离组合：对每个左距离，查询右侧不超过 D-i 的累计数量。

为什么在最近公共祖先统计？

它恰好把两个叶子的最短路径分成互不重叠的左右两段，也是唯一不会漏计或重计的位置。

四种可提交实现

Java · LeetCode 提交格式
class Solution {
    private int answer;

    public int countPairs(TreeNode root, int distance) {
        answer = 0;
        dfs(root, distance);
        return answer;
    }

    private int[] dfs(TreeNode node, int limit) {
        int[] count = new int[limit + 1];
        if (node == null) return count;
        if (node.left == null && node.right == null) {
            count[1] = 1;
            return count;
        }

        int[] left = dfs(node.left, limit);
        int[] right = dfs(node.right, limit);
        for (int i = 1; i <= limit; i++) {
            for (int j = 1; i + j <= limit; j++) {
                answer += left[i] * right[j];
            }
        }
        for (int d = 1; d < limit; d++) {
            count[d + 1] = left[d] + right[d];
        }
        return count;
    }
}

        }

Python 3 · LeetCode 提交格式
class Solution:
    def countPairs(self, root: Optional[TreeNode], distance: int) -> int:
        answer = 0

        def dfs(node: Optional[TreeNode]) -> list[int]:
            nonlocal answer
            count = [0] * (distance + 1)
            if node is None:
                return count
            if node.left is None and node.right is None:
                count[1] = 1
                return count

            left = dfs(node.left)
            right = dfs(node.right)
            for i in range(1, distance + 1):
                for j in range(1, distance - i + 1):
                    answer += left[i] * right[j]
            for d in range(1, distance):
                count[d + 1] = left[d] + right[d]
            return count

        dfs(root)
        return answer

class Solution {
    int answer = 0;

    vector<int> dfs(TreeNode* node, int limit) {
        vector<int> count(limit + 1, 0);
        if (node == nullptr) return count;
        if (node->left == nullptr && node->right == nullptr) {
            count[1] = 1;
            return count;
        }

        vector<int> left = dfs(node->left, limit);
        vector<int> right = dfs(node->right, limit);
        for (int i = 1; i <= limit; ++i) {
            for (int j = 1; i + j <= limit; ++j) {
                answer += left[i] * right[j];
            }
        }
        for (int d = 1; d < limit; ++d) {
            count[d + 1] = left[d] + right[d];
        }
        return count;
    }

public:
    int countPairs(TreeNode* root, int distance) {
        answer = 0;
        dfs(root, distance);
        return answer;
    }
};
