MEDIUM数组哈希表计数贪心

题目

仓库中有一排条形码，第 i 个条形码的编号为 barcodes[i]。请重新排列数组，使任意两个相邻位置的编号都不相同。可以返回任意一种合法排列；题目保证答案存在。

函数形式： rearrangeBarcodes(barcodes: integer[]) → integer[]

示例 1

输入：barcodes = [1,1,1,2,2,2]
输出：[2,1,2,1,2,1]

示例 2

输入：barcodes = [1,1,1,1,2,2,3,3]
输出：[1,3,1,3,2,1,2,1]

输出不唯一；只要元素频次不变且相邻元素不同即可。

约束

  • 1 ≤ barcodes.length ≤ 10⁴
  • 1 ≤ barcodes[i] ≤ 10⁴
  • 保证至少存在一种合法排列

题解

核心洞察：先处理出现次数最多的编号，并依次占据 0, 2, 4, …；偶数位用完后再填 1, 3, 5, …。

完整过程

  1. 用哈希表统计每个编号的出现次数。
  2. 将“编号—次数”按次数从大到小排序。
  3. 从结果数组下标 0 开始，每放一个元素就将下标加 2。
  4. 当下标越过数组末端时，改从下标 1 开始，继续每次加 2。

为什么正确

  1. 频次保持：每个编号恰好按统计次数写入，因此结果与输入是同一多重集合。
  2. 高频编号被隔开：同一批次先进入相差 2 的槽位；最难安排的最大频次编号最先获得全部隔离位置。
  3. 跨区边界安全：题目保证有解，即最大频次不超过 ⌈n/2⌉。按频次降序填充时，偶数区末尾与奇数区开头不会迫使同一编号相邻。
  4. 综上，输出包含全部输入元素，并且任意相邻编号不同。

边界情况

  • 单元素数组直接返回自身。
  • 所有编号互不相同，任意顺序都合法。
  • 最大频次恰为 ⌈n/2⌉ 时，应优先占满偶数位。

复杂度

设数组长度为 n，不同编号数为 k。计数为 O(n)，排序为 O(k log k)，填充为 O(n)；额外空间为 O(k+n)（含输出）。

替代方案

也可以使用最大堆，每次取出频次最高且不同于上一次的编号，再把上一次暂存的编号放回堆。它更直观地维护“相邻不同”，时间为 O(n log k)，但实现与常数开销更大。

import java.util.*;

class Solution {
    public int[] rearrangeBarcodes(int[] barcodes) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int x : barcodes) count.merge(x, 1, Integer::sum);
        List<Map.Entry<Integer, Integer>> entries = new ArrayList<>(count.entrySet());
        entries.sort((a, b) -> Integer.compare(b.getValue(), a.getValue()));
        int[] ans = new int[barcodes.length];
        int index = 0;
        for (Map.Entry<Integer, Integer> entry : entries) {
            for (int c = entry.getValue(); c > 0; c--) {
                if (index >= ans.length) index = 1;
                ans[index] = entry.getKey();
                index += 2;
            }
        }
        return ans;
    }
}

var rearrangeBarcodes = function(barcodes) {
    const count = new Map();
    for (const x of barcodes) count.set(x, (count.get(x) || 0) + 1);
    const entries = [...count.entries()].sort((a, b) => b[1] - a[1]);
    const ans = new Array(barcodes.length);
    let index = 0;
    for (const [value, frequency] of entries) {
        for (let c = 0; c < frequency; c++) {
            if (index >= ans.length) index = 1;
            ans[index] = value;
            index += 2;
        }
    }
    return ans;
};
from collections import Counter
from typing import List

class Solution:
    def rearrangeBarcodes(self, barcodes: List[int]) -> List[int]:
        ordered = Counter(barcodes).most_common()
        ans = [0] * len(barcodes)
        index = 0
        for value, frequency in ordered:
            for _ in range(frequency):
                if index >= len(ans):
                    index = 1
                ans[index] = value
                index += 2
        return ans
#include <algorithm>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> rearrangeBarcodes(vector<int>& barcodes) {
        unordered_map<int, int> count;
        for (int x : barcodes) ++count[x];
        vector<pair<int, int>> entries;
        for (auto [value, frequency] : count) entries.push_back({frequency, value});
        sort(entries.rbegin(), entries.rend());
        vector<int> ans(barcodes.size());
        int index = 0;
        for (auto [frequency, value] : entries) {
            while (frequency--) {
                if (index >= static_cast<int>(ans.size())) index = 1;
                ans[index] = value;
                index += 2;
            }
        }
        return ans;
    }
};

面试追问

  • 如果题目不保证有解，如何判断？检查最大频次是否不超过 ⌈n/2⌉。
  • 若输入是流式数据怎么办？可维护频次结构，但完整重排仍需看到全部数据或接受在线约束。
  • 排序方案与最大堆方案如何权衡？前者代码短、常数低；后者更易推广到相邻距离大于 1 的变体。

常见错误

  • 先填奇偶位，却没有先处理最大频次编号。
  • 偶数位越界后直接取模，导致覆盖已有槽位；应明确切换到下标 1。
  • 验证时只比较某个固定输出；本题答案不唯一，应验证频次和相邻关系。
