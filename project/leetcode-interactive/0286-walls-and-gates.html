墙与门Walls and Gates

让一张只有墙、门与空房间的网格，标记出每个空房间到最近门的距离。无法到达门的房间保持原值。

数组 矩阵 广度优先搜索
Mission brief
  • 输入int[][] rooms
  • 输出原地修改，无返回值
  • 目标最近门的曼哈顿距离
  • 限制墙不可穿越
01 / Problem

先把地图读对

本题需要原地更新二维整数矩阵。

题意转述

给定一个 m × n 的网格 rooms，其中每个位置只会是以下三类值：

  • -1 表示墙或障碍，不能经过。
  • 0 表示门。
  • 2147483647（即 2³¹ - 1）表示尚未赋值的空房间，可视作无穷大。

请把每个空房间改为它到最近一扇门的最短距离。每一步只能向上、下、左、右移动；若某个空房间无法抵达任何门，则保留 2147483647。

函数返回类型是 void：答案写回传入的 rooms，不要另行返回矩阵。

约束

  • m == rooms.length
  • n == rooms[i].length
  • 1 ≤ m, n ≤ 250
  • rooms[i][j] 只可能是 -1、0 或 2³¹ - 1
  • 距离按四方向移动步数计算
  • 矩阵需原地修改

Solution unlocked

从所有门同时出发

多源 BFS

核心洞察

如果从每个空房间分别寻找最近的门，会反复走过同一区域。反过来，把所有门在时刻 0 一起放入队列，相当于让它们同时向外扩散。某个空房间第一次被抵达时，所走层数必然就是它到任意门的最短距离。

完整过程

  1. 扫描矩阵，把每一扇门的坐标加入同一个队列。
  2. 依次取出队首，检查上、下、左、右四个邻居。
  3. 只进入值仍为 2147483647 的空房间。
  4. 把它写成“当前格距离 + 1”，并入队等待继续扩散。
  5. 队列为空时结束；未被写入的空房间就是不可达房间。

正确性说明

不变式：队列中的位置都已经保存了其到最近门的最短距离。所有门的距离为 0，初始成立。按队列顺序处理距离为 d 的位置时，首次发现的空房间得到 d + 1；若存在更短路径，它应当从更小距离的上一层更早抵达，与“首次发现”矛盾。因此写入值正确。每个空房间最多入队一次，结束后所有可达房间均已被发现。

边界情况

  • 只有墙：队列为空，矩阵不变。
  • 只有门：答案仍为 [[0]]。
  • 没有门：全部空房间保留无穷大。
  • 墙围住的孤立区域不会被访问。
  • 多个门等距时，第一次抵达即可，无需区分来源门。
时间复杂度O(m × n)每个格子至多进入队列一次
空间复杂度O(m × n)最坏情况下队列容纳线性数量的坐标

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public void wallsAndGates(int[][] rooms) {
        if (rooms == null || rooms.length == 0 || rooms[0].length == 0) {
            return;
        }

        int rows = rooms.length;
        int cols = rooms[0].length;
        Deque<int[]> queue = new ArrayDeque<>();

        for (int row = 0; row < rows; row++) {
            for (int col = 0; col < cols; col++) {
                if (rooms[row][col] == 0) {
                    queue.offer(new int[] {row, col});
                }
            }
        }

        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!queue.isEmpty()) {
            int[] current = queue.poll();
            for (int[] direction : directions) {
                int nextRow = current[0] + direction[0];
                int nextCol = current[1] + direction[1];
                if (nextRow < 0 || nextRow >= rows
                        || nextCol < 0 || nextCol >= cols
                        || rooms[nextRow][nextCol] != Integer.MAX_VALUE) {
                    continue;
                }

                rooms[nextRow][nextCol] = rooms[current[0]][current[1]] + 1;
                queue.offer(new int[] {nextRow, nextCol});
            }
        }
    }
}

 * @param {number[][]} rooms
 * @return {void} Do not return anything, modify rooms in-place instead.
 */
var wallsAndGates = function(rooms) {
    if (rooms.length === 0 || rooms[0].length === 0) return;

    const rows = rooms.length;
    const cols = rooms[0].length;
    const queue = [];
    let head = 0;

    for (let row = 0; row < rows; row++) {
        for (let col = 0; col < cols; col++) {
            if (rooms[row][col] === 0) {
                queue.push([row, col]);
            }
        }
    }

    const EMPTY = 2147483647;
    const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];

    while (head < queue.length) {
        const [row, col] = queue[head++];
        for (const [rowDelta, colDelta] of directions) {
            const nextRow = row + rowDelta;
            const nextCol = col + colDelta;
            if (nextRow < 0 || nextRow >= rows
                    || nextCol < 0 || nextCol >= cols
                    || rooms[nextRow][nextCol] !== EMPTY) {
                continue;
            }

            rooms[nextRow][nextCol] = rooms[row][col] + 1;
            queue.push([nextRow, nextCol]);
        }
    }
};
from collections import deque
from typing import List


class Solution:
    def wallsAndGates(self, rooms: List[List[int]]) -> None:
        if not rooms or not rooms[0]:
            return

        rows, cols = len(rooms), len(rooms[0])
        queue = deque()

        for row in range(rows):
            for col in range(cols):
                if rooms[row][col] == 0:
                    queue.append((row, col))

        empty = 2**31 - 1
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

        while queue:
            row, col = queue.popleft()
            for row_delta, col_delta in directions:
                next_row = row + row_delta
                next_col = col + col_delta
                if not (0 <= next_row < rows and 0 <= next_col < cols):
                    continue
                if rooms[next_row][next_col] != empty:
                    continue

                rooms[next_row][next_col] = rooms[row][col] + 1
                queue.append((next_row, next_col))
#include <climits>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    void wallsAndGates(vector<vector<int>>& rooms) {
        if (rooms.empty() || rooms[0].empty()) return;

        const int rows = static_cast<int>(rooms.size());
        const int cols = static_cast<int>(rooms[0].size());
        queue<pair<int, int>> pending;

        for (int row = 0; row < rows; ++row) {
            for (int col = 0; col < cols; ++col) {
                if (rooms[row][col] == 0) {
                    pending.push({row, col});
                }
            }
        }

        const int directions[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!pending.empty()) {
            auto [row, col] = pending.front();
            pending.pop();

            for (const auto& direction : directions) {
                int nextRow = row + direction[0];
                int nextCol = col + direction[1];
                if (nextRow < 0 || nextRow >= rows
                        || nextCol < 0 || nextCol >= cols
                        || rooms[nextRow][nextCol] != INT_MAX) {
                    continue;
                }

                rooms[nextRow][nextCol] = rooms[row][col] + 1;
                pending.push({nextRow, nextCol});
            }
        }
    }
};
Trade-offs

替代方案与追问

替代方案

从每个空房间做 BFS：写法直观，但每次搜索都可能扫描整张地图，最坏可达 O((mn)²)。

从每扇门各自 BFS：可以维护最小值，但格子会被多个搜索重复访问；多源 BFS 把这些波前自然合并，只需一次遍历。

面试追问

  • 若不同地形有不同代价怎么办？改用多源 Dijkstra。
  • 若允许八方向移动？扩展方向数组，正确性结构不变。
  • 若门会动态增加？可从新增门继续传播，但门删除通常需要重算或维护更复杂的来源信息。
  • 能否不用额外 visited？可以；无穷大本身就是“未访问”标记。

常见错误

  • 只从一扇门开始，得到的不是全局最近距离。
  • 更新已经写过的格子，造成重复入队甚至覆盖更短答案。
  • 把墙也当成可通行位置。
  • 逐层计数时把当前层大小和不断增长的队列长度混用。
  • 返回新矩阵，而没有修改原参数。

为什么可直接写 当前值 + 1？

队列按非递减距离取出位置。所有距离为 0 的门最先进入，之后每个新房间都来自上一层，因此当前格保存的就是可靠的最短距离，无需额外维护层号。
