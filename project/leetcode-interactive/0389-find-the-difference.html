01 · 题目

问题定义

给定只由小写英文字母组成的字符串 s 和 t。字符串 t 由 s 随机重排后，再在任意位置添加一个字母得到。返回这个被添加的字母。

官方示例

示例 1

输入：s = "abcd", t = "abcde"

输出："e"

解释：e 是被添加的字母。

示例 2

输入：s = "", t = "y"

输出："y"

约束

  • 0 <= s.length <= 1000
  • t.length == s.length + 1
  • s 和 t 仅含小写英文字母

函数签名

findTheDifference(s, t) → character

03 · 深入理解

准备好揭晓机制了吗？

题解默认收起。建议先让消除机走完整个过程，再核对你的判断。

完整题解

用异或让成对字母归零

O(n) 时间 · O(1) 空间

核心洞察

异或具有三条关键性质：x ^ x = 0、x ^ 0 = x，并且满足交换律和结合律。把 s 与 t 的所有字符编码全部异或，不必关心字符顺序。

原有字母在两个字符串中各出现一次，最终两两抵消；只有新增字母出现奇数次，因此它的编码被保留下来。

完整过程

  1. 令累积值 answer = 0。
  2. 遍历 s，把每个字符编码异或进 answer。
  3. 遍历 t，继续执行相同操作。
  4. 将最终编码转换回字符并返回。
0 ^ a ^ b ^ c ^ d ^ a ^ b ^ c ^ d ^ e = e

正确性证明

设新增字符为 c。由于 t 包含 s 的全部字符且只额外包含一个 c，两个字符串合并后，除 c 外，每个字符都能按出现次数配成相同的两份。

由异或的交换律与结合律，可以把相同字符重新分组。每一对相同字符异或为 0，所有 0 不影响结果，最终只剩 0 ^ c = c。因此算法必然返回新增字符。

复杂度与边界

  • 时间：O(|s| + |t|)，即 O(n)。
  • 空间：O(1)，只使用一个累积变量。
  • 空串：当 s = "" 时，答案就是 t 的唯一字符。
  • 重复字符：不影响；相同字符的两份出现次数仍会抵消。
  • 字符范围：题目限定小写英文字符；四种实现均按官方约束处理。

替代方案

  • 频次数组：用长度 26 的数组先加后减，时间 O(n)、额外空间 O(1)，语义直观。
  • 字符编码求和：sum(t) - sum(s)，同样是 O(n) / O(1)，但在更宽泛的数据范围中要留意整数溢出。
  • 排序：排序后逐位比较，通常需要 O(n log n) 时间，并可能产生额外空间。

面试追问与常见错误

  • 追问：若新增多个字符怎么办？可改用频次数组；单个异或值无法恢复一般情况下的多个答案。
  • 追问：若字符不限于小写英文怎么办？哈希计数更通用。
  • 错误：逐位比较，忽略了 t 会被随机重排。
  • 错误：只用集合做差，无法正确处理重复字符。
  • 错误：在 JavaScript 中直接对单字符字符串使用位运算，必须先取字符编码。

四种语言完整代码

class Solution {
    public char findTheDifference(String s, String t) {
        char answer = 0;

        for (int i = 0; i < s.length(); i++) {
            answer ^= s.charAt(i);
        }
        for (int i = 0; i < t.length(); i++) {
            answer ^= t.charAt(i);
        }

        return answer;
    }
}
/**
 * @param {string} s
 * @param {string} t
 * @return {character}
 */
var findTheDifference = function(s, t) {
    let answer = 0;

    for (const char of s) {
        answer ^= char.charCodeAt(0);
    }
    for (const char of t) {
        answer ^= char.charCodeAt(0);
    }

    return String.fromCharCode(answer);
};
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:

            answer ^= ord(char)
        for char in t:
            answer ^= ord(char)

        return chr(answer)
