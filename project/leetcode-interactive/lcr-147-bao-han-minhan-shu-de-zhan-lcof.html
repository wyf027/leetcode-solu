最小栈

先像使用普通栈一样操作它：在任意时刻，都能立刻知道当前最小元素吗？

操作设计 常数时间查询 交互演示

题意

设计一个支持 push、pop、top 操作，并能在常数时间检索到最小元素的栈。

实现 MinStack 类：

  • MinStack() 初始化对象。
  • void push(int x) 将元素 x 推入栈中。
  • void pop() 删除栈顶元素。
  • int top() 获取栈顶元素。
  • int getMin() 检索栈中的最小元素。

示例

输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：[null,null,null,null,-3,null,0,-2]

解释：minStack.push(-2); minStack.push(0); minStack.push(-3);
minStack.getMin(); // 返回 -3
minStack.pop();
minStack.top();    // 返回 0
minStack.getMin(); // 返回 -2

约束

  • -2³¹ ≤ x ≤ 2³¹ - 1
  • pop、top 和 getMin 操作总是在非空栈上调用。
  • push、pop、top、getMin 最多调用 3 × 10⁴ 次。

如果每次调用 getMin 都扫描整个栈，最坏情况会怎样？尝试在每次入栈时多保存一点“截至此处”的信息。

输入一个整数，开始模拟。

数据栈

    最小值记录

      分步推演

      01

      入栈时

      把当前元素入数据栈，同时记下它与此前最小值之间更小的那个。

      02

      出栈时

      两份记录同步弹出，栈顶对应的最小值自然回到上一个状态。

      03

      查询时

      无需遍历；最小值记录栈顶就是此刻的答案。

      题解：双栈同步记录

      核心洞察

      最小值并不是一次性的结论，而是每个栈深度的状态。让辅助栈与数据栈等高，就能让每个位置拥有自己的最小值快照。

      过程

      Push：数据入栈；辅助栈压入 min(x, 辅助栈顶)。Pop：两栈一起弹出。Top：读取数据栈顶。GetMin：读取辅助栈顶。

      边界

      相等的最小值也必须记录两次；否则弹出其中一个后会错误地丢失仍在栈中的最小值。题目保证查询操作时栈非空。

      复杂度

      四个操作的时间复杂度均为 O(1)，额外空间为 O(n)。

      替代方案

      也可只在出现新最小值时压入辅助栈，并在弹出相等值时同步处理；但双栈等高的实现更直接，不易漏掉重复最小值。

      追问

      若要支持 O(1) 查询最大值？可再维护一份最大值记录，或把最小/最大状态组合进每个节点。

      常见错误

      只存严格更小的最小值、Pop 时没同步辅助栈、空栈时直接读取、把 getMin 写成遍历，都会破坏正确性或复杂度。

      Java 
      class MinStack {
    private final Deque<Integer> stack = new ArrayDeque<>();
    private final Deque<Integer> mins = new ArrayDeque<>();
    public MinStack() {}
    public void push(int x) { stack.push(x); mins.push(mins.isEmpty() ? x : Math.min(x, mins.peek())); }
    public void pop() { stack.pop(); mins.pop(); }
    public int top() { return stack.peek(); }
    public int getMin() { return mins.peek(); }
}

      class MinStack:
    def __init__(self): self.stack, self.mins = [], []
    def push(self, x: int) -> None:
        self.stack.append(x); self.mins.append(min(x, self.mins[-1]) if self.mins else x)
    def pop(self) -> None: self.stack.pop(); self.mins.pop()
    def top(self) -> int: return self.stack[-1]
    def getMin(self) -> int: return self.mins[-1]
