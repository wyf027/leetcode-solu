题意与样例

线性时间 · 常数空间

任务

给定整数数组 nums，除一个元素只出现一次外，其余每个元素都恰好出现三次。返回只出现一次的元素。

  • 1 ≤ nums.length ≤ 3 × 10⁴
  • −2³¹ ≤ nums[i] ≤ 2³¹ − 1
  • 输入保证唯一答案存在。

官方样例 1

输入：nums = [2,2,3,2]
期望输出：3

数字 2 的三张副本成组，孤本是 3。

官方样例 2

输入：nums = [0,1,0,1,0,1,99]
期望输出：99

0 与 1 都出现三次，剩下 99。

阅读提示

负数按 32 位补码参与位运算。页面完整展示从 b31 到 b0 的 32 个计数列。

本题没有字符串输入；若以后输入含空格，本系列统一用 ␠ 显示空格并解释。

题解

核心洞察、完整过程、边界、复杂度、替代方案与四语言代码默认封存。

Core insight

核心洞察：每一位独立计数

对任意二进制位，出现三次的数字会贡献 0 个或 3 个 1；位计数对 3 取模后，它们全部清零，只留下孤本。

answer[bit] = Σ ((num >>> bit) & 1) mod 3

Walkthrough

完整过程

  1. 依次枚举 32 个二进制位。
  2. 扫描所有数字，累加当前位上的 1。
  3. 若总数不能被 3 整除，就把答案的当前位置为 1。
  4. 32 位重建完毕后返回有符号整数。

Boundaries

边界处理

  • 数组只有一个元素时，32 位直接重建它。
  • 答案为 0 时，所有最终余数均为 0。
  • 负数必须保留第 31 位；Python 需转回有符号数。
  • −2³¹ 的符号位同样参与计数。

Complexity

复杂度

时间：O(32n) = O(n)

额外空间：O(1)

这是面试中最容易解释、最稳妥的推荐主线。

Trade-offs

替代方案取舍

  • 哈希表直观，但需要 O(n) 空间。
  • 排序需要 O(n log n) 时间。
  • ones / twos 状态机同为 O(n)/O(1)，更短但更难推导。

Interview follow-up

面试追问

  • 若其余数字出现 k 次？—— 每位计数对 k 取模。
  • 能否只遍历数组一次？—— 用两组位掩码构造三状态机。
  • 为何 32 次外循环仍是线性？—— 位宽是固定常数。

Common mistakes

常见错误

  • 误写成全部异或：相同数字出现三次不会被 XOR 消掉。
  • 只统计 31 位，遗漏负数的符号位。
  • Python 重建后未减去 2³²，负数会变成大正数。
  • JavaScript 用普通除法模拟移位，破坏 32 位语义。

class Solution {
    public int singleNumber(int[] nums) {
        int answer = 0;
        for (int bit = 0; bit < 32; bit++) {
            int count = 0;
            for (int num : nums) {
                count += (num >>> bit) & 1;
            }
            if (count % 3 != 0) {
                answer |= 1 << bit;
            }
        }
        return answer;
    }
}

class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        answer = 0
        for bit in range(32):
            count = sum((num >> bit) & 1 for num in nums)
            if count % 3:
                answer |= 1 << bit

        if answer >= 1 << 31:
            answer -= 1 << 32
        return answer
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        uint32_t answer = 0;
        for (int bit = 0; bit < 32; ++bit) {
            int count = 0;
            for (int num : nums) {
                count +=
                    (static_cast<uint32_t>(num) >> bit) & 1U;
            }
            if (count % 3 != 0) {
                answer |= 1U << bit;
            }
        }
        return static_cast<int32_t>(answer);
    }
};
