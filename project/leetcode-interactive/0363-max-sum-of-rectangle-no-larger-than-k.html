题目保证至少存在一个矩形，其数值和不超过 k。

函数形式： maxSumSubmatrix(matrix, k) → integer

约束

  • m == matrix.length
  • n == matrix[i].length
  • 1 ≤ m, n ≤ 100
  • -100 ≤ matrix[i][j] ≤ 100
  • -10⁵ ≤ k ≤ 10⁵

Solution

二维降维 + 有序前缀和

核心洞察

先枚举矩形在较短维度上的两条边界，把边界之间每一列（或每一行）的元素累加。此时，一个二维矩形就对应压缩数组中的一段连续子数组。

问题因此变为：在一维数组中，找和不超过 k 的最大连续子数组。

一维关键式

扫描到当前前缀和 S 时，若较早的前缀和是 P，区间和为 S − P。

要满足 S − P ≤ k，即 P ≥ S − k。为了让区间和最大，应从已见前缀中找“不小于 S − k 的最小值”，这正是有序集合的 ceiling / lower_bound。

完整过程

1

如果行数大于列数，先转置矩阵。转置不改变矩形和的集合，却能保证被枚举两次的维度更短。

2

枚举上边界 top。初始化长度为列数的 sums，再逐步下移 bottom，把新一行累加到 sums。

3

对每个压缩数组，用有序集合保存扫描过的前缀和；最初插入 0，以覆盖从索引 0 开始的区间。

4

对当前前缀和 S，查询集合中首个 ≥ S − k 的前缀 P，用 S − P 更新答案，再插入 S。

5

若答案等于 k 可立即返回，因为任何可行答案都不可能超过上限。

正确性证明

引理 1：压缩保持矩形和

固定上下边界后，令 sums[c] 为该行带在第 c 列的元素和。任意左右边界 l..r 的矩形和，恰好等于压缩数组子数组 sums[l..r] 的和；反之亦然。因此该行带内的二维候选与一维连续子数组一一对应。

引理 2：有序集合给出以当前位置结尾的最优可行区间

当前前缀为 S 时，可行旧前缀必须满足 P ≥ S − k。区间和 S − P 随 P 增大而减小，所以集合中满足条件的最小 P 产生以当前位置结尾的最大可行区间和。

定理：算法返回全局最优答案

算法枚举了较短维度上的所有边界对；由引理 1，每个矩形都会在且仅在对应行带的一维问题中出现。由引理 2，每个行带的一维扫描不会漏掉其最优可行区间。对所有行带取最大值，故得到所有和不超过 k 的矩形中的最大值。

复杂度

令 a = min(m,n)，b = max(m,n)。转置后枚举 O(a²) 个边界对；每次扫描 b 个数，每次有序集合操作为 O(log b)。

时间：O(a² · b · log b)
额外空间：O(b)（不计可选转置矩阵；计入转置为 O(mn)）。

边界处理

  • k 可能为负，答案不能初始化为 0。
  • 集合必须预先放入前缀和 0。
  • 元素有负数，不能使用滑动窗口。
  • 答案等于 k 时可以安全提前结束。
  • 重复前缀和只需在集合中保留一份，不影响可查询的数值集合。

替代方案

  • 暴力枚举四条边界 + 二维前缀和：每个矩形可 O(1) 求和，但矩形数为 O(m²n²)，在 100 × 100 上偏慢。
  • 压缩 + 枚举所有一维区间：无需有序集合，时间 O(a²b²)；适合尺寸很小或语言缺少有序集合时。
  • Kadane 剪枝：可以先求压缩数组的无约束最大子数组和；若它不超过 k，可直接用于当前行带，否则仍需有序集合。常数可能更好，但最坏复杂度不变。

面试追问

  1. 为什么应该平方较短的维度？请比较 m²n 与 n²m。
  2. 若所有元素均非负，可否改用滑动窗口？为什么含负数后失效？
  3. 如何恢复最优矩形的四个坐标？提示：有序集合同时保存前缀和及其索引。
  4. JavaScript / Python 标准库没有平衡树时，你会选择自写 Treap、离线坐标压缩 + 树状数组，还是退化为有序数组？各自的工程权衡是什么？
  5. 若只需要判断是否存在和恰好等于 k 的矩形，算法能怎样简化？

常见错误

  • 查询方向写反：需要的是第一个 P ≥ S − k，不是小于等于它的最大值。
  • 更新集合早于查询，可能错误地把空区间当候选。
  • 只枚举固定高度或宽度，漏掉部分矩形。
  • 忘记转置优化，导致在极端长方形矩阵上多一个数量级。
  • 把“最大和”误解为“面积最大”，或允许空矩形返回 0。

import java.util.TreeSet;

class Solution {
    public int maxSumSubmatrix(int[][] matrix, int k) {
        int rows = matrix.length;
        int cols = matrix[0].length;

        if (rows > cols) {
            int[][] transposed = new int[cols][rows];
            for (int r = 0; r < rows; r++) {
                for (int c = 0; c < cols; c++) {
                    transposed[c][r] = matrix[r][c];
                }
            }
            matrix = transposed;
            rows = matrix.length;
            cols = matrix[0].length;
        }

        int answer = Integer.MIN_VALUE;
        for (int top = 0; top < rows; top++) {
            int[] sums = new int[cols];
            for (int bottom = top; bottom < rows; bottom++) {
                for (int c = 0; c < cols; c++) {
                    sums[c] += matrix[bottom][c];
                }

                TreeSet<Integer> prefixes = new TreeSet<>();
                prefixes.add(0);
                int prefix = 0;
                for (int value : sums) {
                    prefix += value;
                    Integer previous = prefixes.ceiling(prefix - k);
                    if (previous != null) {
                        answer = Math.max(answer, prefix - previous);
                        if (answer == k) return k;
                    }
                    prefixes.add(prefix);
                }
            }
        }
        return answer;
    }
}

/**
 * @param {number[][]} matrix
 * @param {number} k
 * @return {number}
 */
var maxSumSubmatrix = function(matrix, k) {
    class Node {
        constructor(key, priority) {
            this.key = key;
            this.priority = priority;
            this.left = null;
            this.right = null;
        }
    }

    let seed = 0x9e3779b9;
    const nextPriority = () => {
        seed ^= seed << 13;
        seed ^= seed >>> 17;
        seed ^= seed << 5;
        return seed >>> 0;
    };

    const rotateRight = (root) => {
        const next = root.left;
        root.left = next.right;
        next.right = root;
        return next;
    };

    const rotateLeft = (root) => {
        const next = root.right;
        root.right = next.left;
        next.left = root;
        return next;
    };

    const insert = (root, key) => {
        if (root === null) return new Node(key, nextPriority());
        if (key === root.key) return root;
        if (key < root.key) {
            root.left = insert(root.left, key);
            if (root.left.priority < root.priority) root = rotateRight(root);
        } else {
            root.right = insert(root.right, key);
            if (root.right.priority < root.priority) root = rotateLeft(root);
        }
        return root;
    };

    const ceiling = (root, target) => {
        let answer = null;
        while (root !== null) {
            if (root.key >= target) {
                answer = root.key;
                root = root.left;
            } else {
                root = root.right;
            }
        }
        return answer;
    };

    let rows = matrix.length;
    let cols = matrix[0].length;
    if (rows > cols) {
        const transposed = Array.from({ length: cols }, () => Array(rows));
        for (let r = 0; r < rows; r++) {
            for (let c = 0; c < cols; c++) transposed[c][r] = matrix[r][c];
        }
        matrix = transposed;
        rows = matrix.length;
        cols = matrix[0].length;
    }

    let answer = -Infinity;
    for (let top = 0; top < rows; top++) {
        const sums = Array(cols).fill(0);
        for (let bottom = top; bottom < rows; bottom++) {
            for (let c = 0; c < cols; c++) sums[c] += matrix[bottom][c];

            let root = null;
            root = insert(root, 0);
            let prefix = 0;
            for (const value of sums) {
                prefix += value;
                const previous = ceiling(root, prefix - k);
                if (previous !== null) {
                    answer = Math.max(answer, prefix - previous);
                    if (answer === k) return k;
                }
                root = insert(root, prefix);
            }
        }
    }
    return answer;
};

Python

Python 3 · Treap
from typing import List, Optional


class Node:
    __slots__ = ("key", "priority", "left", "right")

    def __init__(self, key: int, priority: int) -> None:
        self.key = key
        self.priority = priority
        self.left: Optional["Node"] = None
        self.right: Optional["Node"] = None


class OrderedSet:
    def __init__(self) -> None:
        self.root: Optional[Node] = None
        self.seed = 0x9E3779B9

    def _next_priority(self) -> int:
        self.seed ^= (self.seed << 13) & 0xFFFFFFFF
        self.seed ^= self.seed >> 17
        self.seed ^= (self.seed << 5) & 0xFFFFFFFF
        self.seed &= 0xFFFFFFFF
        return self.seed

    @staticmethod
    def _rotate_right(root: Node) -> Node:
        next_root = root.left
        root.left = next_root.right
        next_root.right = root
        return next_root

    @staticmethod
    def _rotate_left(root: Node) -> Node:
        next_root = root.right
        root.right = next_root.left
        next_root.left = root
        return next_root

    def _insert(self, root: Optional[Node], key: int) -> Node:
        if root is None:
            return Node(key, self._next_priority())
        if key == root.key:
            return root
        if key < root.key:
            root.left = self._insert(root.left, key)
            if root.left.priority < root.priority:
                root = self._rotate_right(root)
        else:
            root.right = self._insert(root.right, key)
            if root.right.priority < root.priority:
                root = self._rotate_left(root)
        return root

    def add(self, key: int) -> None:
        self.root = self._insert(self.root, key)

    def ceiling(self, target: int) -> Optional[int]:
        root = self.root
        answer = None
        while root is not None:
            if root.key >= target:
                answer = root.key
                root = root.left
            else:
                root = root.right
        return answer


class Solution:
    def maxSumSubmatrix(self, matrix: List[List[int]], k: int) -> int:
        rows, cols = len(matrix), len(matrix[0])
        if rows > cols:
            matrix = [list(row) for row in zip(*matrix)]
            rows, cols = len(matrix), len(matrix[0])

        answer = float("-inf")
        for top in range(rows):
            sums = [0] * cols
            for bottom in range(top, rows):
                for col in range(cols):
                    sums[col] += matrix[bottom][col]

                prefixes = OrderedSet()
                prefixes.add(0)
                prefix = 0
                for value in sums:
                    prefix += value
                    previous = prefixes.ceiling(prefix - k)
                    if previous is not None:
                        answer = max(answer, prefix - previous)
                        if answer == k:
                            return k
                    prefixes.add(prefix)
        return int(answer)

C++17 · std::set
#include <algorithm>
#include <climits>
#include <set>
#include <vector>
using namespace std;

class Solution {
public:
    int maxSumSubmatrix(vector<vector<int>>& matrix, int k) {
        int rows = static_cast<int>(matrix.size());
        int cols = static_cast<int>(matrix[0].size());

        if (rows > cols) {
            vector<vector<int>> transposed(cols, vector<int>(rows));
            for (int r = 0; r < rows; ++r) {
                for (int c = 0; c < cols; ++c) {
                    transposed[c][r] = matrix[r][c];
                }
            }
            matrix.swap(transposed);
            rows = static_cast<int>(matrix.size());
            cols = static_cast<int>(matrix[0].size());
        }

        int answer = INT_MIN;
        for (int top = 0; top < rows; ++top) {
            vector<int> sums(cols, 0);
            for (int bottom = top; bottom < rows; ++bottom) {
                for (int c = 0; c < cols; ++c) {
                    sums[c] += matrix[bottom][c];
                }

                set<int> prefixes{0};
                int prefix = 0;
                for (int value : sums) {
                    prefix += value;
                    auto it = prefixes.lower_bound(prefix - k);
                    if (it != prefixes.end()) {
                        answer = max(answer, prefix - *it);
                        if (answer == k) return k;
                    }
                    prefixes.insert(prefix);
                }
            }
        }
        return answer;
    }
};
