User Activity for the Past 30 Days II

01 / Problem

题目要求

表 Activity 记录用户在不同会话中的活动。请统计截至 2019-07-27（含）的 30 天内，每位活跃用户拥有的会话数，再求这些用户的平均会话数，结果四舍五入保留两位小数。 一个会话只要在窗口内至少出现一条活动记录，就计入该用户一次。

Activity 表结构

user_id
INT，用户编号
session_id
INT，会话编号
activity_date
DATE，活动日期
activity_type
ENUM，活动类型

activity_type 只可能是 open_session、end_session、 scroll_down 或 send_message。

输出参数

仅输出一列：average_sessions_per_user
  • 日期区间两端都包含在内。
  • 只把区间内至少有一次活动的用户放入平均值分母。
  • 同一用户的同一会话有多条活动，也只算一个会话。
  • 若窗口内没有活跃用户，本页方案返回 0.00。

Answer unlocked

两层聚合：先用户，后全局

外层平均值的输入不是活动行，而是“每位活跃用户在窗口内的不同会话数”。

核心洞察

同一会话会产生多条活动，所以第一层必须按 user_id 分组并对 session_id 去重计数。得到每位用户的会话数后，第二层再求平均值。

完整过程

  1. 用闭区间筛出 2019-06-28 至 2019-07-27 的活动。
  2. 按用户分组，计算不同会话编号的数量。
  3. 对各用户的会话数求平均，并保留两位小数。
  4. 无活跃用户时以 0 替代空平均值。

正确性证明

  1. 筛选正确：闭区间条件恰好保留目标 30 天内的活动，窗口外记录均被排除。
  2. 计数正确：对每个用户执行不同会话计数；同一会话无论有多少活动只贡献 1，窗口内出现过的会话都会贡献 1。
  3. 平均正确：子查询每行一位活跃用户及其准确会话数，外层平均因此正是题目要求的每活跃用户平均会话数。

边界情况

  • 2019-06-28 与 2019-07-27 当天的记录都应计入。
  • 一个用户只有一个活动或一个会话时，仍是有效活跃用户。
  • 同一会话跨多天或包含重复活动，仍只计一次。
  • 窗口内无记录时，聚合平均值为空；用 IFNULL 返回 0。

复杂度

设表中共有 N 行、窗口内涉及 U 位用户。逻辑扫描为 O(N)；去重分组通常需要 O(N) 额外聚合空间（具体执行代价取决于数据库索引与执行计划）。外层只处理 U 行。

替代方案

可以用 CTE 代替派生表，语义完全相同。若能保证 session_id 在全表全局唯一，也可用“不同会话总数 ÷ 不同用户总数”； 两层聚合不依赖这一额外假设，更稳妥。

面试追问

  • 如果统计窗口由参数提供，怎样避免日期边界的 off-by-one？
  • 如果一个 session_id 可能被不同用户复用，为什么全局计数法会错？
  • 在大表上，应如何为日期筛选和分组设计复合索引？
  • 如果要求把零会话的注册用户也纳入平均值，需要连接哪张用户表？

常见错误

  • 把活动行数当成会话数，遗漏 DISTINCT。
  • 写成最近 30 天的动态当前日期，而不是题目给定的固定截止日。
  • 使用开区间，漏掉 2019-06-28 或 2019-07-27。
  • 先对所有行求平均，导致活动频繁的会话被重复加权。

主答案 · MySQL

官方提交方向：MySQL 查询。使用派生表先得到每位活跃用户的不同会话数。

SELECT ROUND(IFNULL(AVG(session_count), 0), 2)
       AS average_sessions_per_user
FROM (
    SELECT user_id,
           COUNT(DISTINCT session_id) AS session_count
    FROM Activity
    WHERE activity_date BETWEEN '2019-06-28' AND '2019-07-27'
    GROUP BY user_id
) AS per_user;

本地语义参考：输入为内存活动列表，返回两位小数的 BigDecimal；不是 LeetCode 数据库题提交代码。

import java.math.BigDecimal;
import java.math.RoundingMode;
import java.time.LocalDate;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

public class Solution {
    public static final class Activity {
        final int userId;
        final int sessionId;
        final LocalDate activityDate;
        final String activityType;

        public Activity(int userId, int sessionId, String date, String type) {
            this.userId = userId;
            this.sessionId = sessionId;
            this.activityDate = LocalDate.parse(date);
            this.activityType = type;
        }
    }

    public BigDecimal averageSessions(List<Activity> rows) {
        LocalDate start = LocalDate.of(2019, 6, 28);
        LocalDate end = LocalDate.of(2019, 7, 27);
        Map<Integer, Set<Integer>> sessionsByUser = new HashMap<>();

        for (Activity row : rows) {
            boolean inWindow = !row.activityDate.isBefore(start)
                    && !row.activityDate.isAfter(end);
            if (inWindow) {
                sessionsByUser
                        .computeIfAbsent(row.userId, ignored -> new HashSet<>())
                        .add(row.sessionId);
            }
        }

        if (sessionsByUser.isEmpty()) {
            return new BigDecimal("0.00");
        }

        long totalSessions = sessionsByUser.values().stream()
                .mapToLong(Set::size)
                .sum();
        return BigDecimal.valueOf(totalSessions)
                .divide(BigDecimal.valueOf(sessionsByUser.size()), 2, RoundingMode.HALF_UP);
    }
}

本地语义参考：活动日期采用 ISO 字符串，可安全进行字典序区间比较；不是 LeetCode 数据库题提交代码。

function averageSessions(activityRows) {
  const start = "2019-06-28";
  const end = "2019-07-27";
  const sessionsByUser = new Map();

  for (const row of activityRows) {
    if (row.activityDate < start || row.activityDate > end) continue;

    if (!sessionsByUser.has(row.userId)) {
      sessionsByUser.set(row.userId, new Set());
    }
    sessionsByUser.get(row.userId).add(row.sessionId);
  }

  if (sessionsByUser.size === 0) return 0.0;

  let totalSessions = 0;
  for (const sessions of sessionsByUser.values()) {
    totalSessions += sessions.size;
  }

  return Number((totalSessions / sessionsByUser.size).toFixed(2));
}

本地语义参考：字典把用户映射到会话集合，并以 Decimal 模拟数据库的两位小数舍入；不是 LeetCode 数据库题提交代码。

from collections import defaultdict
from decimal import Decimal, ROUND_HALF_UP
from typing import Iterable, NamedTuple


class Activity(NamedTuple):
    user_id: int
    session_id: int
    activity_date: str
    activity_type: str


def average_sessions(rows: Iterable[Activity]) -> Decimal:
    start = "2019-06-28"
    end = "2019-07-27"
    sessions_by_user: dict[int, set[int]] = defaultdict(set)

    for row in rows:
        if start <= row.activity_date <= end:
            sessions_by_user[row.user_id].add(row.session_id)

    if not sessions_by_user:
        return Decimal("0.00")

    total_sessions = sum(map(len, sessions_by_user.values()))
    average = Decimal(total_sessions) / Decimal(len(sessions_by_user))
    return average.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)

本地语义参考：使用哈希集合对每位用户的会话编号去重；不是 LeetCode 数据库题提交代码。

#include <cmath>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>

struct Activity {
    int userId;
    int sessionId;
    std::string activityDate;
    std::string activityType;
};

class Solution {
public:
    double averageSessions(const std::vector<Activity>& rows) {
        const std::string start = "2019-06-28";
        const std::string end = "2019-07-27";
        std::unordered_map<int, std::unordered_set<int>> sessionsByUser;

        for (const Activity& row : rows) {
            if (row.activityDate >= start && row.activityDate <= end) {
                sessionsByUser[row.userId].insert(row.sessionId);
            }
        }

        if (sessionsByUser.empty()) return 0.0;

        long long totalSessions = 0;
        for (const auto& entry : sessionsByUser) {
            totalSessions += static_cast<long long>(entry.second.size());
        }

        const double average = static_cast<double>(totalSessions)
                / static_cast<double>(sessionsByUser.size());
        return std::round(average * 100.0) / 100.0;
    }
};
