LCP 18. 早餐组合

主食数组与饮料数组各选一种，价格和不超过预算的组合有多少？把两侧排序后，右指针只会左移，左指针每次能批量确认一组组合。

题意

给定 staple、drinks 与 x，各选一个价格，统计满足 staple[i]+drinks[j] ≤ x 的组合数，返回模 1_000_000_007。

数组长度最多 10⁵，价格不超过 10⁵。

双指针

  1. 分别排序主食和饮料。
  2. 饮料指针从最贵开始；扫描每个主食时，若超预算就左移饮料指针。
  3. 指针停下时，所有 0…j 饮料都合法，加入 j+1。

题解与正确性

当当前主食 s 与最大尚未排除的饮料 d[j] 合法时，因饮料已排序，所有更便宜饮料也合法，恰有 j+1 个组合。若不合法，任何更贵饮料也不可能合法，因此安全地左移 j。两指针都只单调移动。

复杂度

排序 O(n log n+m log m)，扫描 O(n+m)。

边界

j 变为 -1 后可结束；答案使用 long。

常见错误

合法时加 j+1，不要误加 j。
