感染二叉树需要的总时间

Amount of Time for Binary Tree to Be Infected

MEDIUM免费题2385

一次感染从某个节点开始。每过一分钟，它会沿树枝扩散到相邻节点。试着观察：起点变化后，哪一个节点会最后被感染？

官方题目 ↗

01 / 题目

给定二叉树根节点 root 和整数 start，所有节点的值互不相同，且树中存在值为 start 的节点。第 0 分钟只有该节点感染。

此后每分钟，所有在上一分钟结束时仍未感染、且与已感染节点之间有一条边的节点，同时被感染。父节点与孩子节点都属于相邻节点。返回整棵树全部感染时经过的分钟数。

参数：amountOfTime(root: TreeNode, start: integer) → integer。示例中的 root 为层序序列，null 表示缺失的孩子，不是节点。

官方示例 1

root = [1,5,3,null,4,10,6,9,2]
start = 3
输出：4

第 0 分钟：3；第 1 分钟：1、10、6；第 2 分钟：5；第 3 分钟：4；第 4 分钟：9、2。此时全部感染。

官方示例 2

root = [1]
start = 1
输出：0

唯一节点在第 0 分钟就已感染，无需再等待一分钟。

约束

  • 节点数 n 满足 1 ≤ n ≤ 10⁵。
  • 每个节点的值满足 1 ≤ Node.val ≤ 10⁵。
  • 所有节点值互不相同。
  • 树中一定存在值为 start 的节点。

04 / 想好你的解法了吗？

先考虑如何向父节点传播，以及如何区分同一分钟与下一分钟。

题解 / 把树看成无向图，逐层扩散

核心洞察

树的指针向下，但感染可以向上。将每条父子边都记录为双向边后，每分钟的传播就对应从 start 出发的广度优先搜索（BFS）一层。节点的感染时间等于它与起点之间的最短路径边数，答案是这些距离的最大值。

完整过程

  1. 用显式栈遍历二叉树。创建以唯一节点值为键的邻接表；每遇到孩子，记录父 → 子、子 → 父两条邻接关系。
  2. 初始化队列只含 start，并立即加入已访问集合。分钟计数从 -1 开始。
  3. 每轮固定当前队列层的大小，只处理这一层；把所有未访问邻居标记并入队。新加入的节点留给下一轮处理。
  4. 每处理一层，分钟数加 1。初始层是第 0 分钟，队列耗尽后的计数就是答案。
示例 1：
分钟 0：{3}
分钟 1：{1,10,6}    3 同时连接父亲 1 与孩子 10、6
分钟 2：{5}         已感染节点不会再次入队
分钟 3：{4}
分钟 4：{9,2}       最后一层，答案 4

正确性说明

建图正确：每条树边被记录为两个方向，因此图中的邻接关系与题目允许的一分钟传播关系完全一致。

层次不变量：第 0 层仅含起点，恰好是第 0 分钟感染的节点。假设第 t 层包含所有首次在第 t 分钟感染的节点，扩展这些节点的未访问邻居时，恰好得到第 t+1 分钟的新感染节点：它们有长度 t+1 的路径，且若存在更短路径，则早已被之前的层访问。因此归纳成立。

终止与结果：每个节点只入队一次，且树连通，所以最终全部入队并被处理。最后一层的编号即最晚感染时间；此时全树已感染，任何更早时刻都还缺少最后一层节点。

边界与复杂度

  • 只有一个节点时只处理初始层，计数由 -1 变成 0。
  • 起点可以是根、叶子或内部节点；双向边统一处理。
  • 最长链可能有 10⁵ 个节点，四份实现都使用迭代遍历，避免递归调用栈溢出。
  • 树有 n−1 条边，建图和 BFS 各扫描 O(n) 个节点与邻接项。使用哈希表的通常平均复杂度：时间 O(n)，额外空间 O(n)。

替代方案

父指针表 + BFS：遍历时仅记录每个节点的父亲，之后从起点枚举左孩子、右孩子、父亲。时间、空间仍为 O(n)，避免复制全部孩子邻接信息。

树形 DP：一次后序遍历，传递子树高度与到起点的距离；若一侧包含起点，则用到当前节点的距离加上另一侧高度更新答案。也可做到 O(n)，但空子树高度和跨父节点距离更容易算错。递归版需留意长链栈深度，迭代后序可避免此问题。

常见错误

  • 只沿左右孩子传播，漏掉向父节点及兄弟子树传播。
  • 新入队节点在同一分钟继续扩散，导致把多分钟压成一分钟；必须固定层大小或层尾。
  • 记录节点数而不是边数，单节点返回 1；第 0 分钟不算等待。
  • 没有访问标记，在双向边之间来回传播；应在入队时标记。
  • JavaScript 使用反复 shift() 处理大数组，可能造成 O(n²) 搬移；用头指针。
  • 把层序数组当完全二叉树下标表，错误解释 null 后续位置。

面试追问

  • 多个初始感染源？全部放入第 0 层并标记，做多源 BFS；每个节点取到最近感染源的距离。
  • 每条边传播时间不同？非负权图使用 Dijkstra；本题仍是树时也可沿唯一路径累加边权。
  • 同一棵树要回答很多起点？先找直径两端 a、b，再保存到两端的距离；任意节点 v 的最远距离为 max(dist(a,v), dist(b,v))。预处理 O(n)，每次查询 O(1)。
  • 节点值不唯一？使用节点对象或索引作键，并让输入直接指定起点对象。

Java

ArrayDeque
import java.util.*;

// TreeNode 由平台提供，字段为 val、left、right。
class Solution {
    public int amountOfTime(TreeNode root, int start) {
        Map<Integer, List<Integer>> graph = new HashMap<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            graph.computeIfAbsent(node.val, k -> new ArrayList<>());
            for (TreeNode child : new TreeNode[]{node.left, node.right}) {
                if (child == null) continue;
                graph.get(node.val).add(child.val);
                graph.computeIfAbsent(child.val, k -> new ArrayList<>())
                     .add(node.val);
                stack.push(child);
            }
        }
        Queue<Integer> queue = new ArrayDeque<>();
        Set<Integer> seen = new HashSet<>();
        queue.add(start);
        seen.add(start);
        int minutes = -1;
        while (!queue.isEmpty()) {
            int size = queue.size();
            minutes++;
            for (int i = 0; i < size; i++) {
                int value = queue.remove();
                for (int next : graph.get(value)) {
                    if (seen.add(next)) queue.add(next);
                }
            }
        }
        return minutes;
    }
}

头指针队列
/**
 * TreeNode 由平台提供，字段为 val、left、right。
 * @param {TreeNode} root
 * @param {number} start
 * @return {number}
 */
var amountOfTime = function(root, start) {
    const graph = new Map();
    const stack = [root];
    while (stack.length) {
        const node = stack.pop();
        if (!graph.has(node.val)) graph.set(node.val, []);
        for (const child of [node.left, node.right]) {
            if (!child) continue;
            graph.get(node.val).push(child.val);
            if (!graph.has(child.val)) graph.set(child.val, []);
            graph.get(child.val).push(node.val);
            stack.push(child);
        }
    }
    const queue = [start];
    const seen = new Set([start]);
    let head = 0, minutes = -1;
    while (head < queue.length) {
        const end = queue.length;
        minutes++;
        while (head < end) {
            const value = queue[head++];
            for (const next of graph.get(value)) {
                if (seen.has(next)) continue;
                seen.add(next);
                queue.push(next);
            }
        }
    }
    return minutes;
};

Python 3

deque
from collections import defaultdict, deque
from typing import Optional

# TreeNode 由平台提供，字段为 val、left、right。
class Solution:
    def amountOfTime(self, root: Optional['TreeNode'], start: int) -> int:
        graph = defaultdict(list)
        stack = [root]
        while stack:
            node = stack.pop()
            for child in (node.left, node.right):
                if child is None:
                    continue
                graph[node.val].append(child.val)
                graph[child.val].append(node.val)
                stack.append(child)

        queue = deque([start])
        seen = {start}
        minutes = -1
        while queue:
            minutes += 1
            for _ in range(len(queue)):
                value = queue.popleft()
                for nxt in graph[value]:
                    if nxt not in seen:
                        seen.add(nxt)
                        queue.append(nxt)
        return minutes

#include <vector>
#include <queue>
#include <unordered_map>
#include <unordered_set>
using namespace std;

// TreeNode 由平台提供，字段为 val、left、right。
class Solution {
public:
    int amountOfTime(TreeNode* root, int start) {
        unordered_map<int, vector<int>> graph;
        vector<TreeNode*> stack = {root};
        while (!stack.empty()) {
            TreeNode* node = stack.back();
            stack.pop_back();
            graph[node->val];
            for (TreeNode* child : {node->left, node->right}) {
                if (!child) continue;
                graph[node->val].push_back(child->val);
                graph[child->val].push_back(node->val);
                stack.push_back(child);
            }
        }
        queue<int> q;
        unordered_set<int> seen = {start};
        q.push(start);
        int minutes = -1;
        while (!q.empty()) {
            int size = static_cast<int>(q.size());
            ++minutes;
            while (size--) {
                int value = q.front();
                q.pop();
                for (int next : graph[value]) {
                    if (seen.insert(next).second) q.push(next);
                }
            }
        }
        return minutes;
    }
};
