Valid Word Square

给定一个非空单词列表 words。把第 i 个单词看作第 i 行，判断它能否形成一个有效的单词方块。

有效的含义 对所有实际涉及的位置，按行读取与按列读取必须完全一致；也就是第 i 行第 j 个字符，应当和第 j 行第 i 个字符相同，而且两处都必须存在。
函数签名 validWordSquare(words) → boolean 单词长度可以不同

官方示例

以下输入采用完整参数形式。方块不要求每行等长，但转置位置不能缺失或不相等。

示例 1true
输入：words = ["abcd", "bnrt", "crmy", "dtye"]
输出：true

每一行也恰好是对应的列：例如第 2 行和第 2 列都是 "bnrt"。

示例 2true
输入：words = ["abcd", "bnrt", "crm", "dt"]
输出：true

虽然各行长度不同，所有存在的字符仍能与其转置位置一一对应。

示例 3false
输入：words = ["ball", "area", "read", "lady"]
输出：false

第 0 行第 2 个字符是 l，而第 2 行第 0 个字符是 r，两者不同。

Contract

约束

  • 1 ≤ words.length ≤ 500
  • 1 ≤ words[i].length ≤ 500
  • words[i] 仅由小写英文字母组成。

题解：逐字符验证转置位置

核心洞察

不需要真的构造每一列。遍历每个已存在字符 words[i][j]，直接检查转置位置 words[j][i]：先确认第 j 行存在，再确认该行长度大于 i，最后比较两个字符。

完整过程

  1. 从上到下枚举行下标 i。
  2. 枚举当前单词中的每个字符下标 j。
  3. 若 j ≥ words.length，转置所需的第 j 行不存在，返回 false。
  4. 若 i ≥ words[j].length，转置字符不存在，返回 false。
  5. 若两个字符不同，返回 false；全部检查结束则返回 true。

正确性

若算法返回 true：算法访问了输入中的每个字符，并为每个 (i, j) 验证转置字符存在且相等，因此任意一行按下标读到的字符，都与对应列相同，单词方块有效。

若单词方块有效：根据定义，每个已有坐标的转置坐标必然存在且字符相等，所以算法的三类失败条件都不会发生，最终一定返回 true。由此算法充要地判断有效性。

边界情况

  • 只有一个单词或一个字符时，仍按相同规则检查。
  • 行数可以多于某些单词长度；只要所有实际字符都有对称伙伴即可。
  • 很长的前置行可能要求一个不存在的后续行，应立即返回 false。
  • 对角线位置 i = j 与自身比较，天然相等，但仍需先确保坐标存在。

复杂度

设所有单词字符总数为 S。每个已有字符至多检查一次，因此时间复杂度为 O(S)；只使用循环下标，额外空间复杂度为 O(1)。

这里的 S = Σ words[i].length，比笼统写成最大边长的平方更精确。

替代方案

显式构造列：可以逐列拼接字符串，再与对应行比较，思路直观，但需要额外 O(S) 空间，并且处理不等长行时更容易越界。

仅检查半区：理论上可跳过已经比较过的对称位置，但边界判断更分散；本题上并不会改善渐进复杂度，直接扫描更稳妥。

面试追问

  • 如果输入是字符流、无法一次放入内存，怎样设计缓存与延迟判定？
  • 如果字符是 Unicode 码点而不是单字节字符，各语言的下标策略需要怎样变化？
  • 若要返回第一个冲突坐标，而不是布尔值，接口与测试应如何调整？
  • 怎样并行检查，同时仍稳定返回字典序最小的冲突位置？

常见错误

  • 只比较字符，却忘记先检查 j 是否超出单词列表。
  • 默认所有单词等长，用第一行长度作为所有循环边界。
  • 只检查 words[i][j] == words[j][i]，没有处理转置字符缺失。
  • 构造固定大小矩阵并用空字符填充，混淆“位置不存在”和“字符不相等”。

四语言完整代码

以下均保持官方方法语义：参数为字符串列表，返回布尔值。

JavaSolution.validWordSquare
import java.util.List;

class Solution {
    public boolean validWordSquare(List<String> words) {
        int rows = words.size();

        for (int i = 0; i < rows; i++) {
            String row = words.get(i);
            for (int j = 0; j < row.length(); j++) {
                if (j >= rows) {
                    return false;
                }

                String transposedRow = words.get(j);
                if (i >= transposedRow.length()
                        || row.charAt(j) != transposedRow.charAt(i)) {
                    return false;
                }
            }
        }

        return true;
    }
}

PythonSolution.validWordSquare
from typing import List


class Solution:
    def validWordSquare(self, words: List[str]) -> bool:
        rows = len(words)

        for i, row in enumerate(words):
            for j, char in enumerate(row):
                if j >= rows:
                    return False
                if i >= len(words[j]) or char != words[j][i]:
                    return False

        return True
