LEETCODE CUP / INVENTORY PEAK

最小展台数量

每天结束后展品会全部收回，因此不需要跨天保留展台。对每一种展品分别记录它在所有日期中的最大需求，再把这些峰值相加。

题意转述

展台可以复用，但同一天不能共用

每个字符串表示一天的展品：同一字符出现几次，就需要同时摆出几个该展品。第二天可把展台重新分配给任何展品，答案只受各字符的历史最高日需求影响。

示例

["acd", "bed", "accd"]

峰值

a:2, b:1, c:2, d:1, e:1

答案

7

核心不变量

maxCount[ch] 始终等于已处理日期中 ch 的最大出现次数。

一天结束后所有展台释放，所以不要把每天的总数相加；应按字符取最大值。

算法

两层线性扫描

  1. 建立长度 26 的 peak 数组，初始均为 0。
  2. 遍历每个日期，先用一个长度 26 的 count 统计当天字符频次。
  3. 对每个字母执行 peak[i] = max(peak[i], count[i])。
  4. 返回 peak 所有元素之和。

时间：O(总字符数 + 26 × 日期数)

空间：O(26) = O(1)

提交代码

四种语言，同一个不变量

Java

class Solution { public int minNumBooths(String[] demand) { int[] peak = new int[26]; for (String s : demand) { int[] count = new int[26]; for (char c : s.toCharArray()) count[c - 'a']++; for (int i = 0; i < 26; i++) peak[i] = Math.max(peak[i], count[i]); } int ans = 0; for (int x : peak) ans += x; return ans; } }

JavaScript

var minNumBooths = function (demand) { const peak = Array(26).fill(0); for (const s of demand) { const count = Array(26).fill(0); for (const ch of s) count[ch.charCodeAt(0) - 97]++; for (let i = 0; i < 26; i++) peak[i] = Math.max(peak[i], count[i]); } return peak.reduce((sum, x) => sum + x, 0); };

Python

class Solution:
    def minNumBooths(self, demand: List[str]) -> int:
        peak = [0] * 26
        for s in demand:
            count = [0] * 26
            for ch in s: count[ord(ch) - ord('a')] += 1
            for i in range(26): peak[i] = max(peak[i], count[i])
        return sum(peak)

C++

class Solution { public: int minNumBooths(vector<string>& demand) { vector<int> peak(26); for (const string& s : demand) { vector<int> count(26); for (char c : s) ++count[c - 'a']; for (int i = 0; i < 26; ++i) peak[i] = max(peak[i], count[i]); } return accumulate(peak.begin(), peak.end(), 0); } };
