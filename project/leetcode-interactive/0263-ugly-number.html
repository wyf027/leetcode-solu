263. 丑数

正丑数的所有质因子只能是 2、3、5。不断剥离这些因子，最终恰好归约到 1 才成立。

数学质因数分解循环O(1) 空间

题意

给定整数 n，若 n 是正数，且其所有质因子都属于 {2,3,5}，返回 true；否则返回 false。

官方样例 1

输入n = 6
输出true

6 = 2 × 3

官方样例 2

输入n = 1
输出true

没有质因子

官方样例 3

输入n = 14
输出false

含质因子 7

约束：-2³¹ ≤ n ≤ 2³¹ − 1。

交互：对 300 逐一剥离 2、3、5

只要能整除就持续相除。300 = 2² × 3 × 5²，最后能归约为 1。

题解：剥离允许的质因子

核心洞察

丑数的定义恰好给出全部可能质因子。因此不需要做完整质因数分解：依次把 2、3、5 能除的次数全部除掉，余数为 1 当且仅当没有别的质因子。

完整过程

  1. 若 n ≤ 0，直接返回 false。
  2. 依次对 p = 2、3、5：当 n % p == 0 时持续 n /= p。
  3. 判断最终 n 是否为 1。

边界与复杂度

n = 1：循环不改变它，返回 true。

n ≤ 0：不是正丑数。

含 7：剥离后会留下 7，返回 false。

复杂度：除法次数至多为 O(log n)，额外空间 O(1)。

替代方案

可以通过枚举 2ᵃ3ᵇ5ᶜ 判断，但需更多循环。直接剥离因子更简洁、通用。

常见错误：把 0 当作丑数；或每个因子只除一次，例如 8 需要连续除三次 2。

面试追问

若要找第 n 个丑数，不能逐个测试；应使用多指针动态规划生成有序序列（LeetCode 264）。

四语言可提交代码

class Solution {
  public boolean isUgly(int n) {
    if (n <= 0) return false;
    for (int factor : new int[] {2, 3, 5}) {
      while (n % factor == 0) n /= factor;
    }
    return n == 1;
  }
}
var isUgly = function(n) {
  if (n <= 0) return false;
  for (const factor of [2, 3, 5]) {
    while (n % factor === 0) n /= factor;
  }
  return n === 1;
};
