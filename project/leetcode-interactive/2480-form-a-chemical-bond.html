01 / 题意与数据契约

找出所有可成键元素对

输入为数据库表 Elements。题目把“可成键”定义为：一方属于 Metal，另一方属于 Nonmetal。返回全部符合定义的组合，列名依次为 metal、nonmetal，值均为元素符号；行顺序任意。这是题目的简化规则，不要求模拟真实化学反应。

05 / SOLUTION

准备好看看查询了吗？

展开后查看推导、SQL 与四语言参考。

题解：两个类别的全部组合

核心洞察

设金属集合为 M，非金属集合为 N。答案恰好是 M × N：每个金属与每个非金属配对。electrons 是背景字段，题目没有要求两边电子数相同，不能增加相等条件。

完整过程

  1. 把 Elements 作为两个角色读取，分别命名为 m 和 n。
  2. 限制 m.type = 'Metal'，n.type = 'Nonmetal'；Noble 不进入任一角色。
  3. 对两个角色做交叉连接，得到全部金属—非金属组合。
  4. 只投影 m.symbol 与 n.symbol，并命名为 metal、nonmetal。无需排序、聚合或去重。

官方示例中，先让 Na 依次对应 Cl、O、N；再对 Ca 和 La 做同样的事，总计 3 × 3 = 9 行。可视化采用这个顺序，题目示例采用另一种顺序，两者都符合要求。

官方可提交语言：SQL（MySQL）

SELECT m.symbol AS metal, n.symbol AS nonmetal
FROM Elements AS m
CROSS JOIN Elements AS n
WHERE m.type = 'Metal'
  AND n.type = 'Nonmetal';

正确性证明

可靠性：输出行经过两个类型条件，左侧必为金属、右侧必为非金属，因此每行符合成键定义。

完备性：任取合法元素对 (a,b)，a 在金属角色中、b 在非金属角色中；交叉连接一定产生 (a,b)，且它不会被过滤，所以不会漏解。

唯一性：symbol 是主键，每个元素在各自角色中只出现一次；每个有向角色组合只生成一次，因此无需 DISTINCT。

边界与复杂度

任意一侧为空时结果为空；空表、全 Noble 同理。电子数相等或不同均不改变配对规则。输出方向必须固定为 metal 在前、nonmetal 在后。

令总行数为 n、金属数为 m、非金属数为 k。先过滤再枚举需要 O(n + mk) 时间；结果自身占 O(mk) 空间。下方四语言参考保存分组列表，额外工作空间 O(n)，含结果共 O(n + mk)。SQL 的实际执行耗时与内存取决于优化器、索引和执行计划；上述是过滤后枚举的逻辑成本，不保证数据库一定采用该物理计划。

替代方案

可先用两个子查询各自过滤，再 CROSS JOIN；也可使用 INNER JOIN 并把两个类型条件写在 ON 中，语义相同。全表双重循环再判断也正确，但会考察 n² 对，Noble 很多时做了大量无用工作。DISTINCT、GROUP BY 和 UNION 都不是本题必需。

常见错误

  • 增加 m.electrons = n.electrons，会漏掉 Na–O 等合法组合。
  • 使用 type 不相等作为全部条件，会错误包含 Noble。
  • 两侧角色不固定，输出非金属在前或把方向相反的对算两次。
  • 按行号一一配对，只得到三行而非全部九行。
  • 把 SQL 的别名写成 symbol，忘记期望列名 metal、nonmetal。

面试追问

  • 只求对数？分别计数后相乘，不物化全部组合；注意计数乘积的数据类型容量。
  • 结果太大？输出本身有 mk 行；可讨论分页或流式消费，但完整输出量无法凭算法消除。
  • 若新规则要求电子数相等？那是另一道问题，在连接条件中追加相等判断，并考虑按 electrons 分组或索引。
  • type 上的索引一定更快吗？不一定，类别很少且选择性低，需要依据数据分布和执行计划判断。

Java · Java 8+ 本地参考

import java.util.ArrayList;
import java.util.List;

class Solution {
    static class Element {
        final String symbol, type;
        final int electrons;
        Element(String symbol, String type, int electrons) {
            this.symbol = symbol;
            this.type = type;
            this.electrons = electrons;
        }
    }
    static class Bond {
        final String metal, nonmetal;
        Bond(String metal, String nonmetal) {
            this.metal = metal;
            this.nonmetal = nonmetal;
        }
    }
    static List<Bond> formBond(List<Element> elements) {
        List<String> metals = new ArrayList<>();
        List<String> nonmetals = new ArrayList<>();
        for (Element e : elements) {
            if ("Metal".equals(e.type)) metals.add(e.symbol);
            if ("Nonmetal".equals(e.type)) nonmetals.add(e.symbol);
        }
        List<Bond> result = new ArrayList<>();
        for (String m : metals)
            for (String n : nonmetals)
                result.add(new Bond(m, n));
        return result;
    }
}

JavaScript · 本地参考

// elements: Array<{symbol: string, type: string, electrons: number}>
function formBond(elements) {
  const metals = elements.filter(e => e.type === 'Metal');
  const nonmetals = elements.filter(e => e.type === 'Nonmetal');
  const result = [];
  for (const m of metals) {
    for (const n of nonmetals) {
      result.push({ metal: m.symbol, nonmetal: n.symbol });
    }
  }
  return result;
}

def form_bond(elements):
    """elements: list of dicts with symbol, type, electrons."""
    metals = [e["symbol"] for e in elements if e["type"] == "Metal"]
    nonmetals = [e["symbol"] for e in elements if e["type"] == "Nonmetal"]
    return [
        {"metal": m, "nonmetal": n}
        for m in metals
        for n in nonmetals
    ]

C++ · C++11+ 本地参考

#include <string>
#include <vector>

struct Element {
    std::string symbol;
    std::string type;
    int electrons;
};
struct Bond {
    std::string metal;
    std::string nonmetal;
};
std::vector<Bond> formBond(const std::vector<Element>& elements) {
    std::vector<std::string> metals, nonmetals;
    for (const auto& e : elements) {
        if (e.type == "Metal") metals.push_back(e.symbol);
        if (e.type == "Nonmetal") nonmetals.push_back(e.symbol);
    }
    std::vector<Bond> result;
    for (const auto& m : metals)
        for (const auto& n : nonmetals)
            result.push_back({m, n});
    return result;
}
