Temporal query · 时间点快照

指定日期的产品价格

一张表只记录“什么时候改成了什么价”。你的任务，是还原一个指定日期结束时，所有出现过的产品各自处于什么价格。

题号 1164 非付费题 目标日期 2019-08-16

Snapshot brief

先想一想

价格修改可能发生在目标日之前、当天或之后；某些产品在目标日之前从未修改。怎样让每个产品恰好返回一行？

默认价格 = 10

Problem

题意与数据结构

数据表 Products 的每一行，表示某产品在某天将价格调整为一个新值。所有产品在第一次有效调价之前的初始价格均为 10。

Products 表

字段类型含义
product_idint产品编号
new_priceint调整后的新价格
change_datedate价格生效日期

要求

  • (product_id, change_date) 是主键，同一产品同一天最多一条记录。
  • 求每个出现过的产品在 2019-08-16 的价格。
  • 目标日之前没有调价记录的产品，价格为 10。
  • 结果包含 product_id 与 price，顺序任意。

Solution

题解：还原目标日快照

对每个产品只关心一个事实：不晚于目标日期的最后一次调价；若不存在，就回退到默认价格 10。

核心洞察与完整过程

  1. 先从整张 Products 表提取所有不同的 product_id，保证只有未来记录的产品也不会消失。
  2. 对当前产品，仅保留 change_date <= '2019-08-16' 的记录。
  3. 按 change_date DESC 排序并取第一条，它就是目标日期结束时生效的价格。
  4. 如果子查询没有返回价格，用 COALESCE(..., 10) 补为初始价格。
关键区别： 不能取“全表最新价格”，也不能只过滤日期后直接分组取任意价格；需要的是每个产品在截止日内日期最大的那条记录。

正确性证明

完备性：外层不同产品集合包含表中出现过的每个产品，因此每个产品都会输出一行。

有效记录：相关子查询只允许日期不晚于目标日的调价，因此未来事件不会影响快照。

最新性：有效记录按日期降序后取第一条，所选记录的日期最大；它正是目标日时仍生效的最后一次调价。

默认值：若没有有效记录，产品自始至目标日都未发生有效调价，故 COALESCE 返回初始价格 10。综上，查询对每个产品都返回且只返回正确价格。

边界情况

  • 产品只有目标日之后的调价：返回 10。
  • 调价恰好发生在目标日：该价格已经生效。
  • 目标日前有多次调价：只取日期最晚的一次。
  • 每个产品仅一条记录：按日期判断该值或默认值。
  • 输出顺序不固定：判题时应按集合语义比较。
无索引的朴素上界 时间 O(n²) 相关子查询可能为每个产品扫描记录
额外工作空间 O(d) d 为不同产品数；数据库执行计划可能不同

若存在 (product_id, change_date) 主键索引，数据库通常可以更高效地定位每个产品的截止日前最新记录；实际复杂度由优化器与执行计划决定。

完整代码

本题是数据库题，MySQL 是官方可提交语言。其余四种语言仅用于本地复现相同语义，不能提交到本题的 SQL 判题入口。

MySQL · 官方可提交相关子查询 + 默认值 
SELECT p.product_id,
       COALESCE(
           (
               SELECT p2.new_price
               FROM Products AS p2
               WHERE p2.product_id = p.product_id
                 AND p2.change_date <= '2019-08-16'
               ORDER BY p2.change_date DESC
               LIMIT 1
           ),
           10
       ) AS price
FROM (
    SELECT DISTINCT product_id
    FROM Products
) AS p;
Java · 本地语义参考非本题官方提交语言 
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

public class ProductPriceAtDate {
    public static class Change {
        final int productId;
        final int newPrice;
        final LocalDate changeDate;

        public Change(int productId, int newPrice, String changeDate) {
            this.productId = productId;
            this.newPrice = newPrice;
            this.changeDate = LocalDate.parse(changeDate);
        }
    }

    public static List<int[]> pricesAtDate(
            List<Change> changes,
            LocalDate targetDate) {
        Set<Integer> productIds = new LinkedHashSet<>();
        Map<Integer, Change> latest = new HashMap<>();

        for (Change change : changes) {
            productIds.add(change.productId);
            if (change.changeDate.isAfter(targetDate)) {
                continue;
            }

            Change current = latest.get(change.productId);
            if (current == null || change.changeDate.isAfter(current.changeDate)) {
                latest.put(change.productId, change);
            }
        }

        List<int[]> answer = new ArrayList<>();
        for (int productId : productIds) {
            Change change = latest.get(productId);
            answer.add(new int[] { productId, change == null ? 10 : change.newPrice });
        }
        return answer;
    }
}
JavaScript · 本地语义参考非本题官方提交语言 
/**
 * @param {{ product_id: number, new_price: number, change_date: string }[]} products
 * @param {string} targetDate - YYYY-MM-DD
 * @return {{ product_id: number, price: number }[]}
 */
function pricesAtDate(products, targetDate = "2019-08-16") {
  const productIds = new Set();
  const latest = new Map();

  for (const row of products) {
    productIds.add(row.product_id);
    if (row.change_date > targetDate) continue;

    const current = latest.get(row.product_id);
    if (!current || row.change_date > current.change_date) {
      latest.set(row.product_id, row);
    }
  }

  return [...productIds].map((productId) => ({
    product_id: productId,
    price: latest.get(productId)?.new_price ?? 10,
  }));
}
Python · 本地语义参考独立算法版本；官方另支持 Pandas 
from datetime import date
from typing import Dict, Iterable, List, TypedDict


class ProductRow(TypedDict):
    product_id: int
    new_price: int
    change_date: str


def prices_at_date(
    products: Iterable[ProductRow],
    target_date: str = "2019-08-16",
) -> List[Dict[str, int]]:
    target = date.fromisoformat(target_date)
    product_ids: Dict[int, None] = {}
    latest: Dict[int, tuple[date, int]] = {}

    for row in products:
        product_id = row["product_id"]
        product_ids.setdefault(product_id, None)
        changed_on = date.fromisoformat(row["change_date"])
        if changed_on > target:
            continue

        current = latest.get(product_id)
        if current is None or changed_on > current[0]:
            latest[product_id] = (changed_on, row["new_price"])

    return [
        {
            "product_id": product_id,
            "price": latest.get(product_id, (target, 10))[1],
        }
        for product_id in product_ids
    ]
C++ · 本地语义参考非本题官方提交语言 
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <utility>
#include <vector>

struct Change {
    int productId;
    int newPrice;
    std::string changeDate;  // YYYY-MM-DD
};

std::vector<std::pair<int, int>> pricesAtDate(
        const std::vector<Change>& changes,
        const std::string& targetDate = "2019-08-16") {
    std::vector<int> order;
    std::unordered_set<int> seen;
    std::unordered_map<int, Change> latest;

    for (const Change& change : changes) {
        if (seen.insert(change.productId).second) {
            order.push_back(change.productId);
        }
        if (change.changeDate > targetDate) {
            continue;
        }

        auto it = latest.find(change.productId);
        if (it == latest.end() || change.changeDate > it->second.changeDate) {
            latest[change.productId] = change;
        }
    }

    std::vector<std::pair<int, int>> answer;
    answer.reserve(order.size());
    for (int productId : order) {
        auto it = latest.find(productId);
        answer.emplace_back(productId, it == latest.end() ? 10 : it->second.newPrice);
    }
    return answer;
}

替代方案

窗口函数

先过滤截止日内记录，用 ROW_NUMBER() 为每个产品按日期降序编号，再与完整产品集合连接。表达清晰，适合支持窗口函数的数据库。

聚合后回表

先求每个产品截止日前的 MAX(change_date)，再回表取价格，并用外连接补默认值。兼容性好，但 SQL 更长。

条件聚合

某些数据库可配合排序键或专用聚合函数直接取“最大日期对应值”；可读性和可移植性依数据库方言而异。

常见错误

  • 使用 change_date < '2019-08-16'，错误排除目标日当天。
  • 先过滤日期，再从过滤结果提取产品，导致只有未来记录的产品消失。
  • GROUP BY product_id 后直接选择 new_price，价格不一定来自最大日期。
  • 把 MAX(new_price) 当成最新价格；价格大小与时间先后无关。
  • 使用内连接回表，遗漏应返回默认价格 10 的产品。
