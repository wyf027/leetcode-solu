设计内存分配器

一段内存，多次请求。为每个请求找到它的位置，也让释放回到正确的单元。

先读规则，再动手观察。完整思路与代码收在页面底部，按需展开。

01 / 任务说明

分配、标记、释放

创建长度为 n、下标从 0 开始的内存空间，初始全部空闲。每次分配必须占据一段连续的空闲单元，且选择符合长度要求的最左侧位置。同一个 mID 可以拥有多个不相邻的块。

  • Allocator(int n)：初始化长度为 n 的内存。
  • int allocate(int size, int mID)：把最左侧连续 size 个空闲单元分配给 mID，返回起始下标；找不到则返回 -1，内存不变。
  • int freeMemory(int mID)：释放所有属于 mID 的单元，返回释放的单元总数；不存在该 ID 时返回 0。

约束：1 ≤ n, size, mID ≤ 1000；allocate 与 freeMemory 合计最多调用 1000 次。size 可以大于 n。

    04 / 独立题解

    准备好后，再打开思路

    核心洞察：记录每个单元的归属

    用长度为 n 的数组 a 表示内存。a[i] = 0 表示空闲，正整数表示 mID。由于 mID 至少为 1，0 不会与合法 ID 冲突。n 与调用次数都不超过 1000，直接扫描足以满足此题规模。

    完整过程

    1. 构造时把数组全部置 0。
    2. allocate 从左向右扫描，用 run 记录以当前位置结尾的连续空闲长度。遇到空闲则加一，遇到占用则清零。
    3. 第一次出现 run = size 时，起点为 i − size + 1。将该闭区间全部写为 mID，立刻返回起点。
    4. 扫描结束仍未找到则返回 -1。搜索过程中不提前写入，所以失败不会留下部分占用。
    5. freeMemory 扫描整个数组，把所有等于 mID 的项置 0，并累计清除数量。

    关键例子：在 [1,0,3,0,0,0,0,0,0,0] 上申请 allocate(3,4)，下标 1 只有一个连续空位，下标 2 将 run 清零；扫描到下标 5 时 run 首次等于 3，得到起点 3，而不是把多个分散空位拼起来。

    正确性

    扫描不变式：处理下标 i 后，run 恰好等于以 i 结尾的连续空闲单元数。空闲时由前一段延伸，占用时连续段被截断，因此该不变式逐步成立。run 首次达到 size 时，区间 [i − size + 1, i] 全部空闲。所有候选区间长度相同，结束位置越早，起点越小；因此首次命中的区间就是最左侧合法区间。若始终未命中，则不存在足够长的连续空闲段。

    状态保持：成功分配只修改选中区间，其他归属不变；失败不修改数组。释放遍历每个单元且仅清除目标 ID，所以该 ID 在所有块中的单元都会被释放，计数也恰好是释放总数。配合初始全空状态，可归纳得出任意合法调用序列都保持正确内存状态。

    边界与常见错误

    • n = 1、请求恰好填满尾部或整个数组，都应正常处理；size > n 自动扫描失败。
    • 空闲总量足够不等于有连续空间；遇占用必须清零 run。
    • 不能把一个 ID 只对应到最后一次分配的块；释放要覆盖其所有单元。
    • 返回的是单元数量，不是块数量；重复释放同一 ID 应返回 0。
    • 起点是 i − size + 1；搜索中不能先占用再发现长度不足。
    • 不得移动已有分配来制造空位，这不是带内存压缩的分配器。

    复杂度

    构造时间 O(n)；allocate 搜索最多 n 次，成功写入最多 n 个单元，总时间 O(n)；freeMemory 时间 O(n)。持久数组空间 O(n)，每次操作额外空间 O(1)。q 次调用总时间 O(n + qn)。

    替代方案与取舍

    可维护按起点排序的空闲区间，分配时寻找第一个足够长的区间并拆分，释放时合并相邻区间；仍需记录每个 ID 的全部已分配区间，普通列表最坏仍为线性操作。更大规模可用维护前缀、后缀和最长空闲长度的线段树，支持 O(log n) 找到最左段与区间赋值；若 ID 有 k 个块，释放这些块需 O(k log n)。当前规模直接数组更容易实现。

    面试追问

    • 内存很大但调用稀疏？考虑有序区间结构，避免按 n 分配实体数组。
    • 如何处理碎片？合并相邻空闲段不会移动对象；真正压缩需要改变地址语义，本题不允许。
    • 若支持并发？搜索与写入必须作为一个原子操作；否则两个请求可能选中同一块。
    • 如何更快释放？额外维护 ID → 区间列表，换取存储和一致性维护成本。

    Java

    class Allocator {
    private final int[] a;

    public Allocator(int n) {
        a = new int[n];
    }

    public int allocate(int size, int mID) {
        int run = 0;
        for (int i = 0; i < a.length; i++) {
            run = a[i] == 0 ? run + 1 : 0;
            if (run == size) {
                int start = i - size + 1;
                for (int j = start; j <= i; j++) a[j] = mID;
                return start;
            }
        }
        return -1;
    }

    public int freeMemory(int mID) {
        int count = 0;
        for (int i = 0; i < a.length; i++) {
            if (a[i] == mID) {
                a[i] = 0;
                count++;
            }
        }
        return count;
    }
}

    Python 3

    class Allocator:
    def __init__(self, n: int):
        self.a = [0] * n

    def allocate(self, size: int, mID: int) -> int:
        run = 0
        for i, owner in enumerate(self.a):
            run = run + 1 if owner == 0 else 0
            if run == size:
                start = i - size + 1
                for j in range(start, i + 1):
                    self.a[j] = mID
                return start
        return -1

    def freeMemory(self, mID: int) -> int:
        count = 0
        for i, owner in enumerate(self.a):
            if owner == mID:
                self.a[i] = 0
                count += 1
        return count

                ++count;
            }
