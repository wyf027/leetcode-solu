同一组任意两点的树距离，累加到总答案

原树与当前同组节点

贡献轨迹

核心不变量

每一条原树边，恰好计算一次

固定某个组，删去一条边后，若一侧有 x 个该组节点、全组有 k 个，该边被 x(k-x) 条组内路径穿过。

贡献 = x × (k − x) × 路径长度

把所有边、所有组的贡献相加，就是所有组内点对距离的总和。

为什么是虚树

只压缩“无分叉的无关链”

  1. 一次 DFS 记录 tin、depth 与二进制跳表 LCA。
  2. 对每个组按 tin 排序，补入相邻点的 LCA。
  3. 用栈连出虚树。虚边 p → v 的长度为 depth[v] − depth[p]。
  4. 后序累计虚子树中的原组节点数 x，套用公式。

这样不需要为每个组扫描整棵树；虚树总节点数至多为该组节点数的两倍左右。

HIDDEN SOLUTION

先自己推导，再展开完整实现

查看题解与复杂度

预处理为 O(n log n)。设第 g 组出现次数为 k_g，则构建与后序计算总计约为 Σ k_g log k_g（LCA 额外对数因子取决于实现）。空间为 O(n log n)。

易错点：LCA 必须补入后再去重排序；虚树边长度不是 1；只给原始组节点计数，补入的 LCA 不增加组大小；使用 64 位答案。

using ll = long long;
// build tin, depth and up[][] once; lca(a,b) is standard binary lifting.
ll solve(int n, vector<vector<int>>& edges, vector<int>& group) {
  vector<vector<int>> byGroup; // group id -> original nodes (coordinate-compress ids)
  // ... DFS preprocessing and filling byGroup omitted only for brevity
  ll ans = 0;
  for (auto nodes : byGroup) {
    if (nodes.size() < 2) continue;
    sort(nodes.begin(), nodes.end(), [&](int a,int b){ return tin[a] < tin[b]; });
    int m = nodes.size(); vector<int> all = nodes;
    for (int i=1;i<m;i++) all.push_back(lca(nodes[i-1], nodes[i]));
    sort(all.begin(), all.end(), [&](int a,int b){ return tin[a] < tin[b]; });
    all.erase(unique(all.begin(),all.end()),all.end());
    vector<vector<pair<int,int>>> vt(all.size()); vector<int> st;
    for (int i=0;i<(int)all.size();i++) { while(!st.empty() && !isAncestor(all[st.back()],all[i])) st.pop_back(); if(!st.empty()) vt[st.back()].push_back({i,depth[all[i]]-depth[all[st.back()]]}); st.push_back(i); }
    unordered_set<int> original(nodes.begin(),nodes.end());
    function<int(int)> dfs = [&](int u) { int x=original.count(all[u]); for(auto [v,len]:vt[u]) { int y=dfs(v); ans += 1LL*y*(m-y)*len; x+=y; } return x; };
    dfs(0);
  } return ans;
}
// Same invariant in Java: use long for ans and 1L * x * (k - x) * len.
// 1) binary-lift LCA; 2) sort each group's nodes by tin; 3) append adjacent LCAs;
// 4) stack-build virtual edges; 5) postorder returns subtree original-node count.
long contribution(long x, long k, long len) { return x * (k - x) * len; }
// Keep only original group nodes in the count: added LCA vertices contribute zero.
# Python integers are unbounded; the virtual-tree postorder is identical.
def add_edge_contribution(x, k, length):
    return x * (k - x) * length
# Sort group vertices by tin, add lca(adjacent), deduplicate, then use a stack.
# In dfs_virtual(u), add child_count*(k-child_count)*virtual_edge_length.
// JavaScript: use BigInt for production-scale answers if inputs can exceed safe integers.
const contribution = (x, k, len) => BigInt(x) * BigInt(k - x) * BigInt(len);
