Problem brief

什么时候一个节点才真正安全？

给定一个含 n 个节点的有向图，节点编号为 0 到 n - 1。二维数组 graph 使用邻接表表示图：对每个 graph[i][j]，都有一条从节点 i 指向节点 graph[i][j] 的边。

终端节点没有任何出边；如果从某个节点出发的每一条可能路径最终都会到达终端节点（或另一个安全节点），那么它就是安全节点。

请返回图中所有安全节点，结果必须按升序排列。

Think first

“存在一条路能到终点”够吗？

不够。安全要求的是所有路径都不会无限停留在环中。先试着观察示例图，找出哪些节点无论怎么走都能结束。

示例 1

输入：graph = [[1,2],[2,3],[5],[0],[5],[],[]]
输出：[2,4,5,6]
解释：5、6 是终端节点；从 2、4、5、6 出发的
每条路径最终都会到达 5 或 6。

示例 2

输入：graph = [[1,2,3,4],[1,2],[3,4],[0,4],[]]
输出：[4]
解释：只有节点 4 是终端节点；其余节点都能走入环。

约束

  • n == graph.length，且 1 <= n <= 104
  • 0 <= graph[i].length <= n
  • 0 <= graph[i][j] <= n - 1
  • graph[i] 中的节点编号严格递增。
  • 图中可能包含自环。
  • 边数范围为 [1, 4 × 104]。

Complete solution

反向建图 + 拓扑消元

!

核心洞察：能走进环的节点不安全；直接找环外所有节点不够方便。换个方向，从出度为 0 的终端节点开始，把“已经确定安全”沿反图向前传播。最终能被消成出度 0 的节点恰好都是安全节点。

完整过程

01 · Reverse

建立反图

原边 u → v 在反图中记为 v → u，这样处理安全节点 v 时，就能找到所有依赖它的前驱 u。

02 · Degree

统计原图出度

outDegree[u] = graph[u].length。出度为 0 的节点天然是终端节点，也天然安全，先全部入队。

03 · Peel

逐层削减出度

每次弹出一个已安全节点 v，沿反图访问其前驱 u，将 outDegree[u] 减 1。

04 · Collect

收集归零节点

若某个前驱的出度降为 0，说明它的所有原始出边都已指向安全节点，因此它也安全并入队。最后按节点编号扫描即可自然得到升序答案。

正确性说明

  1. 入队节点一定安全。初始入队的是终端节点，显然安全。之后某节点只有在所有出边均被删除后才入队；被删除的边都指向已安全节点，所以从它出发的任意路径第一步都会进入安全节点，最终必然终止。

  2. 所有安全节点最终都会入队。任取一个安全节点，其可达子图不含环，否则沿环可无限行走，与安全定义矛盾。有限无环图中必有终端节点；从这些终端节点反向消元，会逐层删去该安全节点的所有出边，最终使它出度归零并入队。

  3. 结论。由前两点，算法不会加入不安全节点，也不会遗漏安全节点，因此最终出度为 0 的节点集合恰好等于全部最终安全节点。

复杂度

时间：O(V + E)

空间：O(V + E)

每个节点至多入队一次，每条边在建反图和削减出度时各被访问常数次；反图、出度数组与队列占线性空间。

边界情况

  • 单个终端节点：直接返回 [0]。
  • 纯有向环或自环：队列始终为空，返回空数组。
  • 链条通向终点：整条链都会反向入队。
  • 某节点一边通终点、一边通环：它仍不安全。
  • 多个互不连通分量：每个分量独立完成消元。

import java.util.*;

class Solution {
    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;
        List<List<Integer>> reverse = new ArrayList<>(n);
        int[] outDegree = new int[n];

        for (int i = 0; i < n; i++) {
            reverse.add(new ArrayList<>());
        }
        for (int from = 0; from < n; from++) {
            outDegree[from] = graph[from].length;
            for (int to : graph[from]) {
                reverse.get(to).add(from);
            }
        }

        Deque<Integer> queue = new ArrayDeque<>();
        for (int node = 0; node < n; node++) {
            if (outDegree[node] == 0) queue.offer(node);
        }

        while (!queue.isEmpty()) {
            int safe = queue.poll();
            for (int previous : reverse.get(safe)) {
                if (--outDegree[previous] == 0) {
                    queue.offer(previous);
                }
            }
        }

        List<Integer> answer = new ArrayList<>();
        for (int node = 0; node < n; node++) {
            if (outDegree[node] == 0) answer.add(node);
        }
        return answer;
    }
}

var eventualSafeNodes = function(graph) {
    const n = graph.length;
    const reverse = Array.from({ length: n }, () => []);
    const outDegree = new Array(n).fill(0);

    for (let from = 0; from < n; from++) {
        outDegree[from] = graph[from].length;
        for (const to of graph[from]) {
            reverse[to].push(from);
        }
    }

    const queue = [];
    for (let node = 0; node < n; node++) {
        if (outDegree[node] === 0) queue.push(node);
    }

    for (let head = 0; head < queue.length; head++) {
        const safe = queue[head];
        for (const previous of reverse[safe]) {
            outDegree[previous]--;
            if (outDegree[previous] === 0) {
                queue.push(previous);
            }
        }
    }

    const answer = [];
    for (let node = 0; node < n; node++) {
        if (outDegree[node] === 0) answer.push(node);
    }
    return answer;
};
from collections import deque
from typing import List

class Solution:
    def eventualSafeNodes(self, graph: List[List[int]]) -> List[int]:
        n = len(graph)
        reverse = [[] for _ in range(n)]
        out_degree = [len(neighbors) for neighbors in graph]

        for source, neighbors in enumerate(graph):
            for target in neighbors:
                reverse[target].append(source)

        queue = deque(
            node for node, degree in enumerate(out_degree)
            if degree == 0
        )

        while queue:
            safe = queue.popleft()
            for previous in reverse[safe]:
                out_degree[previous] -= 1
                if out_degree[previous] == 0:
                    queue.append(previous)

        return [
            node for node, degree in enumerate(out_degree)
            if degree == 0
        ]

替代方案：三色 DFS

用状态 0=未访问、1=当前递归栈、2=已确认安全。DFS 遇到状态 1 就发现环；只有所有后继都安全，当前节点才标记为 2。复杂度同为 O(V+E)，但递归深度可能达到 104，部分语言需留意栈限制。

常见错误

  • 只判断“能否到达某个终点”，忽略其他分支可能进环。
  • 在原图上从终点出发，却没有建立反向边。
  • 直接返回队列弹出顺序，导致答案不一定升序。
  • 把“访问过”与“已经确认安全”混成一个 DFS 状态。
