LeetCode 3883困难动态规划 · 前缀和

统计满足数位和数组的非递减数组数目

把每个候选整数当成一条有颜色的刻度：颜色是数位和，向右只能不回头。我们要数出颜色序列匹配时所有合法的单调路径。

题意

给定 digitSum。求长度相同的非递减数组 arr 的个数，要求每个元素在 0..5000，且 arr[i] 的十进制数位和恰好等于 digitSum[i]。答案对 1_000_000_007 取模。

示例 1　digitSum = [25, 1]　输出 6

数位和为 25 的 799、889、898、979、988、997 都能接上 1000（数位和为 1）。

示例 2　digitSum = [1]　输出 4，候选为 1、10、100、1000。

示例 3　digitSum = [2, 49, 23]　输出 0；范围内不存在数位和为 49 的数。

约束：1 ≤ digitSum.length ≤ 1000，0 ≤ digitSum[i] ≤ 50。本页中数组参数完整按 digitSum = [ … ] 展示；字符串中的空格会写作 ␠。

把题目变成“颜色过滤”

  1. 1. 预先计算每个 v ∈ [0,5000] 的数位和。
  2. 2. 第 i 层只保留颜色为 digitSum[i] 的刻度。
  3. 3. 从左到右累加上一层不大于当前刻度的方案数。

状态：dp[v] 是当前层以值 v 结尾的方案数。转移只需一条前缀和。

题解：逐层前缀和 DP

核心洞察

固定当前位置值 v 后，前一个值只能在 0..v。因此 dpNew[v] = prefix(dp)[v]，但仅当 sumDigits(v) = digitSum[i] 时保留；其他位置置零。首层的每个颜色匹配值各有一种选法。

完整过程

  1. 枚举 0..5000，得到 digit[v]。
  2. 用首个目标数位和初始化 dp。
  3. 对后续每一层从 0 到 5000 滚动维护上一层前缀和。
  4. 最后把全部 dp[v] 相加。

边界与复杂度

  • 数位和大于 31 时，在 0..5000 无候选，答案自然为零。
  • 0 的数位和是 0，必须纳入候选。
  • 时间：O(n · 5001)；空间：O(5001)。

替代方案与追问

也可按数位和收集候选列表，再对每层做双指针前缀和；本题值域很小，直接扫描更简单稳定。若上界增大到 109，需要数位 DP 预处理数位和分布与有序转移。

常见错误

不要把前缀和建立在本层 dpNew 上；它必须来自上一层。每次加法都要取模，且首层不能错误地要求前驱。
