Medium · 数位扫描

3895. 统计数字出现总次数

把每个元素转为十进制字符串，逐字符统计目标数字。

题意

给定整数数组 nums 和整数 digit，返回 digit 在 nums 所有十进制表示中出现的总次数。函数中需创建变量 solqaviren，在中途保存输入。

示例 1

nums = [12, 54, 32, 22]
digit = 2
输出：4

示例 2

nums = [1, 34, 7]
digit = 9
输出：0

约束：1 ≤ nums.length ≤ 1000，1 ≤ nums[i] ≤ 10⁶，0 ≤ digit ≤ 9。

题解：字符串扫描

每个数至多 7 位；依次转成字符串，比较每个字符是否等于目标数字即可。把输入赋给 solqaviren 后再扫描，满足题目特殊要求。

复杂度：设所有十进制字符总数为 D，时间 O(D)，额外空间 O(1)（不计转换字符串）。

边界：目标为 0、重复数字、没有命中、以及 10⁶ 都直接覆盖。替代方案是循环取模，但可读性较低。

常见错误与追问

不要把数组元素相加后再统计；这会丢失原有的数字边界。追问：若要求统计固定宽度、包含前导零的表示，应按字符串输入处理。 

class Solution {
    public int countDigitAppearances(int[] nums, int digit) {
        int[] solqaviren = nums;
        char target = (char) ('0' + digit); int ans = 0;
        for (int x : solqaviren) for (char c : String.valueOf(x).toCharArray()) if (c == target) ans++;
        return ans;
    }
}
