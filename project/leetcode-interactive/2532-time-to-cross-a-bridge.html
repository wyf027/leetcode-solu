过桥的时间

Time to Cross a Bridge

一座单行桥，两岸并行作业。遵循工人的通行规则，找到最后一个箱子抵达左岸的时刻。

规则模拟实验原生交互 · 离线可用快速生成 · 待补验证

01 / THE TASK

题目与规则

有 k 名工人，要将右侧旧仓库的 n 个箱子搬到左侧新仓库。所有工人最初在左岸。输入为 n, k, time，其中 time[i] = [rightᵢ, pickᵢ, leftᵢ, putᵢ]，工人编号从 0 开始。

每名工人的四阶段耗时，单位为分钟
阶段含义资源限制
rightᵢ左岸 → 右岸独占桥梁
pickᵢ取箱并回到右侧桥边工人之间可并行
leftᵢ带箱从右岸 → 左岸独占桥梁
putᵢ放箱并回到左侧桥边工人之间可并行
  1. 每次桥空闲，先考虑右岸已取好箱子的工人；右岸无人等待时，才考虑左岸。
  2. 同岸等待者中，rightᵢ + leftᵢ 更大的工人优先；若相等，编号更大的优先。取箱、放箱耗时不参与这项排名。
  3. 桥上同一时间只能有一人，过桥途中不会被抢占。
  4. 已经派出的工人足以取完余下箱子时，停止向右派人。

返回最后一个箱子到达桥左侧的时间，不必等最后一次放箱完成。全文统一使用分钟。

约束

  • 1 ≤ n, k ≤ 10⁴
  • time.length = k，每一行恰有 4 个整数。
  • 1 ≤ rightᵢ, pickᵢ, leftᵢ, putᵢ ≤ 1000

来源：随任务提供的官方元数据（2026-09-15）。官方题目 ↗

04 / SOLUTION

准备好对照你的思路了吗？

展开后包含推导、复杂度与四语言参考实现。

事件驱动模拟 + 四个优先队列

核心洞察

这不是自由选择工人的最短时间优化题，调度顺序已经由题意确定。用两个等待堆按“过桥总耗时、编号”降序选人，用两个作业堆按完成时刻升序释放工人。没有人能过桥时，直接跳到下一次作业完成事件。

队列保存什么堆顶含义
waitL / waitR等待中的工人编号过桥总耗时最大；并列取大编号
busyL(放箱结束时间, 编号)最早能重新在左岸排队的工人
busyR(取箱结束时间, 编号)最早能带箱回程的工人

完整过程

  1. 令时钟 cur = 0、未分配箱子数 remaining = n、送达数 delivered = 0。所有工人加入 waitL。
  2. 将 busyL、busyR 中所有完成时间 ≤ cur 的工人移入对应等待堆。必须全部释放，再选人。
  3. 若 waitR 非空，堆顶工人带箱返回，时钟增加 leftᵢ，送达数加一；若已送达 n 箱，立即返回时钟。否则把工人加入 busyL，结束时间为 cur + putᵢ。
  4. 否则若 remaining > 0 且 waitL 非空，派出堆顶工人，remaining 减一；时钟增加 rightᵢ，加入 busyR，结束时间为 cur + pickᵢ。
  5. 否则桥只能空闲。时钟跳至 busyR 最早完成时间，或（remaining > 0 时）busyL 最早完成时间，二者取小。已无待分配箱子时，左岸放箱事件不能促成新过桥，可跳过。
  6. 重复。过桥不可中断，期间结束的取放箱作业在下一轮统一释放。

示例 2 的事件路径

0 → 10   工人 1 向右，取箱到 20
10 → 11  工人 0 向右，取箱到 16
11 → 16  桥空闲
16 → 17  工人 0 带箱返回，放箱到 25（已到 1 箱）
17 → 20  桥空闲
20 → 30  工人 1 带箱返回，放箱到 40（已到 2 箱）
30 → 31  工人 0 向右，取箱到 36
31 → 36  桥空闲
36 → 37  工人 0 带箱返回（已到 3 箱，停止）

正确性

状态不变量：每轮选人前，每名工人恰在四个队列之一；等待堆包含当前已就绪的工人，作业堆只含未来才就绪的工人。每次过桥后记录其下一段取放箱结束事件，因此这个不变量持续成立。

调度一致：先释放全部到期事件，再优先 waitR；同岸堆按题目顺序选人，因而所选工人与真实规则一致。跨越整段过桥时间合法，因为桥上作业不可抢占。

跳时安全：仅在没有合法过桥者时跳时。在选定的下一次相关作业完成前，没有工人能开始新过桥，所以不会漏掉任何行动。每次向右派人即预留一箱，确保恰好派出 n 次；每次向左带回一箱，第 n 次回程结束正是所求时刻。

边界与复杂度

  • n < k：最多预留 n 箱，不让多余工人空跑。k = 1：中间各轮必须等待放箱，最后一轮不用。
  • 多个工人同时完成：先全部入等待堆，再比较效率；完成时刻相等的作业堆顺序不影响结果。
  • 效率排名仅比较两次过桥耗时，不比较 pick / put，也不优先高效率。
  • 初始化 k 次入堆，每箱产生常数次入堆、出堆和跨桥；时间 O((n + k) log(k + 1))，额外空间 O(k)。
  • 按约束，每箱两次过桥和两次取放作业合计不超过 4000 分钟，整段过程的事件时长总和不超过 4 × 10⁷，答案适合 32 位有符号整数。空堆用无穷哨兵，但不对哨兵做加法。

替代方案

可每次扫描全部工人寻找已就绪的候选者和下一个事件，额外空间仍为 O(k)，但选择和推进时间累计 O(nk)，最大输入不合适。逐分钟推进会依赖总时间上界，且仍要处理同刻释放。预先按效率排序能简化等待优先级，完成时间队列仍需单独维护。

常见错误

  • 返回最后一次 put 完成时间：把终点从“桥左侧”错改成“仓库”。
  • 在回程才减少待分配数：可能派出过多工人领取同一批箱子。
  • 只释放一个到期事件、用 < cur 而不是 ≤ cur：会漏掉同刻就绪者。
  • 拿未来才完成取箱的人阻塞目前可出发的左岸工人：右岸优先仅适用于当前已准备好的工人。
  • 过桥途中发现右岸有人就绪就中断过桥：违反桥梁不可抢占规则。

面试追问

  • 为什么需要两种排序？候选人按效率选，未来事件按完成时刻选，两个顺序独立。
  • 没有待分配箱子后为什么忽略 busyL 的跳时？左岸工人即使放箱结束也不再能出发，只需等右岸所有箱子回来。
  • 双向同时通行怎么办？需为两个方向分别记录桥的可用时间，现有单桥互斥与优先级推导不再直接成立。
  • 允许自主选人最小化时间呢？这是另一个调度优化问题，不能直接沿用本题固定的低效率优先规则。

Java

import java.util.*;

class Solution {
    public int findCrossingTime(int n, int k, int[][] time) {
        Comparator<Integer> rank = (a, b) -> {
            int d = Integer.compare(time[b][0] + time[b][2],
                                    time[a][0] + time[a][2]);
            return d != 0 ? d : Integer.compare(b, a);
        };
        PriorityQueue<Integer> waitL = new PriorityQueue<>(rank);
        PriorityQueue<Integer> waitR = new PriorityQueue<>(rank);
        Comparator<int[]> ready = Comparator.comparingInt(a -> a[0]);
        PriorityQueue<int[]> busyL = new PriorityQueue<>(ready);
        PriorityQueue<int[]> busyR = new PriorityQueue<>(ready);
        for (int i = 0; i < k; i++) waitL.offer(i);
        int cur = 0, remaining = n, delivered = 0;
        while (delivered < n) {
            while (!busyL.isEmpty() && busyL.peek()[0] <= cur)
                waitL.offer(busyL.poll()[1]);
            while (!busyR.isEmpty() && busyR.peek()[0] <= cur)
                waitR.offer(busyR.poll()[1]);
            if (!waitR.isEmpty()) {
                int i = waitR.poll();
                cur += time[i][2];
                if (++delivered == n) return cur;
                busyL.offer(new int[]{cur + time[i][3], i});
            } else if (remaining > 0 && !waitL.isEmpty()) {
                int i = waitL.poll();
                remaining--;
                cur += time[i][0];
                busyR.offer(new int[]{cur + time[i][1], i});
            } else {
                int next = Integer.MAX_VALUE;
                if (!busyR.isEmpty()) next = busyR.peek()[0];
                if (remaining > 0 && !busyL.isEmpty())
                    next = Math.min(next, busyL.peek()[0]);
                cur = next;
            }
        }
        return cur;
    }
}

JavaScript

包含二叉堆实现，无外部优先队列依赖。

class Heap {
    constructor(before) { this.a = []; this.before = before; }
    get size() { return this.a.length; }
    peek() { return this.a[0]; }
    push(x) {
        const a = this.a, before = this.before;
        let i = a.length;
        a.push(x);
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (!before(x, a[p])) break;
            a[i] = a[p];
            i = p;
        }
        a[i] = x;
    }
    pop() {
        const a = this.a, before = this.before;
        const top = a[0], x = a.pop();
        if (a.length) {
            let i = 0;
            while (i * 2 + 1 < a.length) {
                let c = i * 2 + 1;
                if (c + 1 < a.length && before(a[c + 1], a[c])) c++;
                if (!before(a[c], x)) break;
                a[i] = a[c];
                i = c;
            }
            a[i] = x;
        }
        return top;
    }
}

/** @param {number} n @param {number} k
 *  @param {number[][]} time @return {number} */
var findCrossingTime = function(n, k, time) {
    const rank = (a, b) => {
        const x = time[a][0] + time[a][2];
        const y = time[b][0] + time[b][2];
        return x !== y ? x > y : a > b;
    };
    const waitL = new Heap(rank), waitR = new Heap(rank);
    const ready = (a, b) => a[0] < b[0];
    const busyL = new Heap(ready), busyR = new Heap(ready);
    for (let i = 0; i < k; i++) waitL.push(i);
    let cur = 0, remaining = n, delivered = 0;
    while (delivered < n) {
        while (busyL.size && busyL.peek()[0] <= cur)
            waitL.push(busyL.pop()[1]);
        while (busyR.size && busyR.peek()[0] <= cur)
            waitR.push(busyR.pop()[1]);
        if (waitR.size) {
            const i = waitR.pop();
            cur += time[i][2];
            if (++delivered === n) return cur;
            busyL.push([cur + time[i][3], i]);
        } else if (remaining > 0 && waitL.size) {
            const i = waitL.pop();
            remaining--;
            cur += time[i][0];
            busyR.push([cur + time[i][1], i]);
        } else {
            cur = Math.min(
                busyR.size ? busyR.peek()[0] : Infinity,
                remaining > 0 && busyL.size ? busyL.peek()[0] : Infinity
            );
        }
    }
    return cur;
};

Python

from typing import List
from heapq import heappush, heappop

class Solution:
    def findCrossingTime(self, n: int, k: int,
                         time: List[List[int]]) -> int:
        def rank(i):
            return (-time[i][0] - time[i][2], -i)

        wait_l, wait_r, busy_l, busy_r = [], [], [], []
        for i in range(k):
            heappush(wait_l, rank(i))
        cur, remaining, delivered = 0, n, 0
        while delivered < n:
            while busy_l and busy_l[0][0] <= cur:
                _, i = heappop(busy_l)
                heappush(wait_l, rank(i))
            while busy_r and busy_r[0][0] <= cur:
                _, i = heappop(busy_r)
                heappush(wait_r, rank(i))
            if wait_r:
                i = -heappop(wait_r)[1]
                cur += time[i][2]
                delivered += 1
                if delivered == n:
                    return cur
                heappush(busy_l, (cur + time[i][3], i))
            elif remaining > 0 and wait_l:
                i = -heappop(wait_l)[1]
                remaining -= 1
                cur += time[i][0]
                heappush(busy_r, (cur + time[i][1], i))
            else:
                cur = min(
                    busy_r[0][0] if busy_r else float('inf'),
                    busy_l[0][0] if remaining > 0 and busy_l
                    else float('inf')
                )
        return cur

#include <vector>

using namespace std;

class Solution {
public:
    int findCrossingTime(int n, int k, vector<vector<int>>& time) {
        using P = pair<int, int>;
        priority_queue<P> waitL, waitR;
        priority_queue<P, vector<P>, greater<P>> busyL, busyR;
        auto rank = [&](int i) -> P {
            return {time[i][0] + time[i][2], i};
        };
        for (int i = 0; i < k; ++i) waitL.push(rank(i));
        int cur = 0, remaining = n, delivered = 0;
        while (delivered < n) {
            while (!busyL.empty() && busyL.top().first <= cur) {
                int i = busyL.top().second;
                busyL.pop();
                waitL.push(rank(i));
            }
            while (!busyR.empty() && busyR.top().first <= cur) {
                int i = busyR.top().second;
                busyR.pop();
                waitR.push(rank(i));
            }
            if (!waitR.empty()) {
                int i = waitR.top().second;
                waitR.pop();
                cur += time[i][2];
                if (++delivered == n) return cur;
                busyL.push({cur + time[i][3], i});
            } else if (remaining > 0 && !waitL.empty()) {
                int i = waitL.top().second;
                waitL.pop();
                --remaining;
                cur += time[i][0];
                busyR.push({cur + time[i][1], i});
            } else {
                int next = INT_MAX;
                if (!busyR.empty()) next = busyR.top().first;
                if (remaining > 0 && !busyL.empty())
                    next = min(next, busyL.top().first);
                cur = next;
            }
        }
        return cur;
    }
};
