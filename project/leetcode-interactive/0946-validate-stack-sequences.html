Validate Stack Sequences
MEDIUM数组栈模拟

题目

给定两个由互不相同整数构成的数组 pushed 与 popped。从空栈开始，元素必须按 pushed 的顺序入栈；判断是否能通过任意合法的入栈、出栈交错操作，得到完整的 popped 出栈顺序。

函数形式：validateStackSequences(pushed, popped) → boolean

约束

  • 1 ≤ pushed.length ≤ 1000
  • 0 ≤ pushed[i] ≤ 1000
  • pushed 中所有元素互不相同
  • popped.length == pushed.length
  • popped 是 pushed 的排列

示例 1

输入： pushed = [1,2,3,4,5], popped = [4,5,3,2,1] 输出： true 解释： 可依次 push 1、2、3、4，pop 4；再 push 5，然后依次 pop 5、3、2、1。

示例 2

输入： pushed = [1,2,3,4,5], popped = [4,3,5,1,2] 输出： false 解释： 当需要弹出 1 时，2 仍在它上方，因此 1 不可能先于 2 弹出。

Solution

题解：贪心模拟

核心洞察

按固定顺序逐个压入 pushed。每次压栈后，只要栈顶正好等于当前期待的 popped[j]，就立刻弹出并让 j 前进。这个弹出不会损失可行解：目标此刻就要求它出栈，拖延只会让后续元素盖住它。

完整过程

  1. 建立空栈，并令目标指针 j = 0。
  2. 遍历 pushed，把当前元素压栈。
  3. 当栈非空且栈顶等于 popped[j] 时，持续弹栈并递增 j。
  4. 遍历结束后，若 j == popped.length，说明目标序列完全匹配。

正确性说明

不变式：每轮外层循环结束时，已经弹出的元素恰好是 popped[0..j-1]，栈中保留的是已压入但尚未被目标要求弹出的元素，且相对次序合法。若栈顶等于下一目标，任何合法操作最终都必须先弹出它，因此立即弹出安全；若不相等，当前目标不能越过栈顶，只能继续压入。遍历结束时，全部目标被消费当且仅当序列可实现。

边界情况

  • 单元素序列：压入后立即弹出。
  • 完全同序：每个元素入栈后立即出栈。
  • 完全逆序：全部入栈后集中弹出。
  • 存在无法跨越的栈顶时，最终栈非空且目标指针无法到达末尾。

复杂度

每个元素最多入栈、出栈各一次，时间复杂度 O(n)，额外空间复杂度 O(n)。

替代方案

可以直接复用 pushed 数组前部模拟栈，将额外空间降到 O(1)，但会修改输入；递归或枚举所有 push/pop 组合会产生指数级分支，没有必要。

面试追问

  • 能否原地？ 用写指针把 pushed 当作栈即可。
  • 为什么要持续 while 弹出？ 一次压栈可能解锁多个连续目标。
  • 若元素允许重复？ 在给定操作顺序下同样可模拟，但“值”不再唯一标识某个元素，题意与证明需明确身份语义。

常见错误

  • 每次压栈后只弹一次，而不是持续匹配。
  • 访问 popped[j] 前未确认 j 未越界。
  • 只检查栈是否为空，却忽略目标指针是否完整消费。

class Solution {
    public boolean validateStackSequences(int[] pushed, int[] popped) {
        int[] stack = new int[pushed.length];
        int top = 0, j = 0;
        for (int value : pushed) {
            stack[top++] = value;
            while (top > 0 && j < popped.length && stack[top - 1] == popped[j]) {
                top--;
                j++;
            }
        }
        return j == popped.length;
    }
}
/**
 * @param {number[]} pushed
 * @param {number[]} popped
 * @return {boolean}
 */
var validateStackSequences = function(pushed, popped) {
    const stack = [];
    let j = 0;
    for (const value of pushed) {
        stack.push(value);
        while (stack.length && j < popped.length && stack.at(-1) === popped[j]) {
            stack.pop();
            j++;
        }
    }
    return j === popped.length;
};
from typing import List

class Solution:
    def validateStackSequences(
        self, pushed: List[int], popped: List[int]
    ) -> bool:
        stack = []
        j = 0
        for value in pushed:
            stack.append(value)
            while stack and j < len(popped) and stack[-1] == popped[j]:
                stack.pop()
                j += 1
        return j == len(popped)
class Solution {
public:
    bool validateStackSequences(vector<int>& pushed, vector<int>& popped) {
        vector<int> stack;
        int j = 0;
        for (int value : pushed) {
            stack.push_back(value);
            while (!stack.empty() && j < popped.size() && stack.back() == popped[j]) {
                stack.pop_back();
                ++j;
            }
        }
        return j == popped.size();
    }
};
