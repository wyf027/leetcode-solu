数据流的中位数

Find Median from Data Stream

设计一个持续接收整数的数据结构，并能随时给出当前所有数字的中位数。奇数个元素时返回排序后的中间值；偶数个元素时返回中间两个值的平均数。

Problem brief

题目说明

中位数是有序整数列表的中间值。若列表长度为偶数，中位数是中间两个值的算术平均数。例如，[2, 3, 4] 的中位数是 3，[2, 3] 的中位数是 2.5。

实现 MedianFinder 类：

  • MedianFinder()：初始化对象。
  • void addNum(int num)：把数据流中的整数 num 加入数据结构。
  • double findMedian()：返回目前所有元素的中位数，答案与真实值误差不超过 10^-5。

官方示例 1

输入
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]

输出
[null, null, null, 1.5, null, 2.0]

解释
MedianFinder medianFinder = new MedianFinder();
medianFinder.addNum(1);    // 当前数据：[1]
medianFinder.addNum(2);    // 当前数据：[1, 2]
medianFinder.findMedian(); // 返回 1.5，即 (1 + 2) / 2
medianFinder.addNum(3);    // 当前数据：[1, 2, 3]
medianFinder.findMedian(); // 返回 2.0

约束

  • -10^5 <= num <= 10^5
  • 调用 findMedian 前，数据结构中至少有一个元素。
  • addNum 与 findMedian 合计最多被调用 5 * 10^4 次。

Full solution

题解：两个堆维护动态分界线

核心洞察：无需维护完整有序序列，只需让较小的一半与较大的一半各自保留最靠近中位数的边界值。最大堆负责前者，最小堆负责后者。

完整过程

1
分成两半

用最大堆 lower 保存较小的一半，用最小堆 upper 保存较大的一半。

2
选择入口

新值不大于 lower 堆顶时放入左侧，否则放入右侧；左侧为空时先放左侧。

3
恢复平衡

保持 lower.size 等于 upper.size，或只比它多 1。失衡时移动一个堆顶。

4
读取答案

元素总数为奇数时答案是 lower 堆顶；为偶数时取两个堆顶的平均值。

正确性证明

顺序不变量

每次插入按左侧堆顶分流，重平衡只跨边界移动堆顶，因此始终有 max(lower) ≤ min(upper)。

规模不变量

重平衡后，两堆等大，或左堆恰好多一个元素，故中间位置一定落在两个堆顶之一或二者之间。

结论

奇数时左堆顶正是排序后的中间元素；偶数时两堆顶正是中间两个元素，所以返回值必为中位数。

复杂度与边界

复杂度
  • addNum：时间 O(log n)
  • findMedian：时间 O(1)
  • 空间：O(n)
边界处理
  • 第一个数直接进入左堆。
  • 重复值不影响不变量。
  • 负数按同一比较规则处理。
  • 计算平均值前使用更宽类型或先转浮点，避免整数相加溢出。

import java.util.Collections;
import java.util.PriorityQueue;

class MedianFinder {
    private final PriorityQueue<Integer> lower;
    private final PriorityQueue<Integer> upper;

    public MedianFinder() {
        lower = new PriorityQueue<>(Collections.reverseOrder());
        upper = new PriorityQueue<>();
    }

    public void addNum(int num) {
        if (lower.isEmpty() || num <= lower.peek()) {
            lower.offer(num);
        } else {
            upper.offer(num);
        }

        if (lower.size() > upper.size() + 1) {
            upper.offer(lower.poll());
        } else if (upper.size() > lower.size()) {
            lower.offer(upper.poll());
        }
    }

    public double findMedian() {
        if (lower.size() > upper.size()) {
            return lower.peek();
        }
        return ((long) lower.peek() + upper.peek()) / 2.0;
    }
}
class Heap {
    constructor(compare) {
        this.data = [];
        this.compare = compare;
    }

    size() { return this.data.length; }
    peek() { return this.data[0]; }

    push(value) {
        this.data.push(value);
        let i = this.data.length - 1;
        while (i > 0) {
            const parent = Math.floor((i - 1) / 2);
            if (!this.compare(this.data[i], this.data[parent])) break;
            [this.data[i], this.data[parent]] = [this.data[parent], this.data[i]];
            i = parent;
        }
    }

    pop() {
        const top = this.data[0];
        const last = this.data.pop();
        if (this.data.length > 0) {
            this.data[0] = last;
            let i = 0;
            while (true) {
                let best = i;
                const left = i * 2 + 1;
                const right = i * 2 + 2;
                if (left < this.data.length && this.compare(this.data[left], this.data[best])) best = left;
                if (right < this.data.length && this.compare(this.data[right], this.data[best])) best = right;
                if (best === i) break;
                [this.data[i], this.data[best]] = [this.data[best], this.data[i]];
                i = best;
            }
        }
        return top;
    }
}

var MedianFinder = function() {
    this.lower = new Heap((a, b) => a > b);
    this.upper = new Heap((a, b) => a < b);
};

MedianFinder.prototype.addNum = function(num) {
    if (this.lower.size() === 0 || num <= this.lower.peek()) {
        this.lower.push(num);
    } else {
        this.upper.push(num);
    }

    if (this.lower.size() > this.upper.size() + 1) {
        this.upper.push(this.lower.pop());
    } else if (this.upper.size() > this.lower.size()) {
        this.lower.push(this.upper.pop());
    }
};

MedianFinder.prototype.findMedian = function() {
    if (this.lower.size() > this.upper.size()) return this.lower.peek();
    return (this.lower.peek() + this.upper.peek()) / 2;
};
import heapq


class MedianFinder:
    def __init__(self):
        self.lower = []  # 取相反数模拟最大堆
        self.upper = []  # 最小堆

    def addNum(self, num: int) -> None:
        if not self.lower or num <= -self.lower[0]:
            heapq.heappush(self.lower, -num)
        else:
            heapq.heappush(self.upper, num)

        if len(self.lower) > len(self.upper) + 1:
            heapq.heappush(self.upper, -heapq.heappop(self.lower))
        elif len(self.upper) > len(self.lower):
            heapq.heappush(self.lower, -heapq.heappop(self.upper))

    def findMedian(self) -> float:
        if len(self.lower) > len(self.upper):
            return float(-self.lower[0])
        return (-self.lower[0] + self.upper[0]) / 2.0
#include <functional>
#include <queue>
#include <vector>
using namespace std;

class MedianFinder {
private:
    priority_queue<int> lower;
    priority_queue<int, vector<int>, greater<int>> upper;

public:
    MedianFinder() = default;

    void addNum(int num) {
        if (lower.empty() || num <= lower.top()) {
            lower.push(num);
        } else {
            upper.push(num);
        }

        if (lower.size() > upper.size() + 1) {
            upper.push(lower.top());
            lower.pop();
        } else if (upper.size() > lower.size()) {
            lower.push(upper.top());
            upper.pop();
        }
    }

    double findMedian() {
        if (lower.size() > upper.size()) {
            return lower.top();
        }
        return (static_cast<long long>(lower.top()) + upper.top()) / 2.0;
    }
};

替代方案与面试追问

替代方案
  • 有序数组：二分定位后插入仍需移动元素，单次插入 O(n)。
  • 平衡搜索树：若支持秩统计，可插入与查询均做到 O(log n)，实现更复杂。
  • 值域计数：若数值都在 [0,100]，用 101 个计数桶即可用常数级额外空间扫描中位数。
常见追问
  • 若 99% 的数在 [0,100]，可用桶处理主体，并为两端离群值维护额外计数结构。
  • 如何支持删除？可结合延迟删除哈希表与双堆，或使用有序多重集合。
  • 如何合并多台机器的数据流？可汇总可合并的分位数摘要，接受近似答案。

常见错误

  • 只平衡两个堆的大小，却没有保证左堆所有值不大于右堆所有值。
  • 允许右堆比左堆多一个，随后却始终从左堆读取奇数中位数。
  • 偶数时先做整数除法，导致 1.5 被截断成 1。
  • 在 Java 或 C++ 中直接把两个极端整数相加，存在溢出风险。
  • 每次查询都完整排序，忽略了数据流场景中频繁插入与查询的成本。
