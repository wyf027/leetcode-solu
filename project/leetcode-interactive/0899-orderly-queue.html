有序队列

Orderly Queue：一次局部的“取出再排尾”操作，在 k = 1 与 k > 1 时会形成完全不同的可达空间。

HARD

题目

给定字符串 s 和整数 k。每次从当前字符串的前 k 个字符中任选一个，将它移到字符串末尾。操作次数不限，返回所有可达字符串中字典序最小的一个。

函数：orderlyQueue(s: string, k: integer) → string

约束

  • 1 ≤ k ≤ s.length ≤ 1000
  • s 只由小写英文字母组成。

官方示例

示例 1 输入：s = "cba", k = 1 输出："acb" 解释："cba" → "bac" → "acb" 示例 2 输入：s = "baaca", k = 3 输出："aaabc" 解释："baaca" → "aacab" → "aaabc"

建议先在实验室比较 k=1 与 k=2。

题解：一道题，两种状态空间

核心洞察

k = 1：每次只能左旋一位，因此枚举所有循环旋转并取最小。
k ≥ 2：可构造任意相邻交换，所有排列可达，答案就是升序串。

完整过程

  1. 若 k=1，对每个切分点 i 构造 s[i..]+s[..i]，保留字典序最小值。
  2. 若 k>1，直接将全部字符升序排列。

机制与正确性

  1. k=1 的一步严格等于左旋一位，连续操作恰好遍历所有循环旋转；枚举全集取最小必然正确。
  2. 当 k≥2，要交换队首的相邻字符 a,b，先把第二个字符 b 放到末尾，再把 a 放到末尾。
  3. 再依次移动其余字符，就得到只交换 a,b 的结果；配合循环旋转，可交换任意相邻位置。
  4. 相邻交换能生成任意排列，因此升序排列可达；它又是所有排列中字典序最小者，所以答案正确。

边界与复杂度

  • 长度为 1 直接返回；重复字符不影响证明。
  • k=1：时间 O(n²)，额外空间 O(n)（不计临时分配）。
  • k≥2：排序时间 O(n log n)，空间依语言实现而定，通常 O(n)。

替代方案

k=1 可用 Booth 最小表示法把时间降到 O(n)；本题 n≤1000，枚举更简洁。

面试追问

  • 如何严格构造一次相邻交换？
  • 长度达到百万时如何优化最小旋转？
  • 若每次必须选择第 k 个字符，可达集合如何变化？

常见错误

  • 所有 k 都排序，忽略 k=1 只能旋转。
  • 漏掉原串或循环切分下标错一位。
  • 用 BFS 搜索阶乘级状态。
  • 只说可排序，却不给出相邻交换构造。

四语言完整代码

class Solution {
    public String orderlyQueue(String s, int k) {
        if (k > 1) {
            char[] a = s.toCharArray();
            java.util.Arrays.sort(a);
            return new String(a);
        }
        String best = s;
        for (int i = 1; i < s.length(); i++) {
            String r = s.substring(i) + s.substring(0, i);
            if (r.compareTo(best) < 0) best = r;
        }
        return best;
    }
}

var orderlyQueue = function(s, k) {
    if (k > 1) return [...s].sort().join('');
    let best = s;
    for (let i = 1; i < s.length; i++) {
        const r = s.slice(i) + s.slice(0, i);
        if (r < best) best = r;
    }
    return best;
};

        return min(s[i:] + s[:i] for i in range(len(s)))
class Solution {
public:
    string orderlyQueue(string s, int k) {
        if (k > 1) {
            sort(s.begin(), s.end());
            return s;
        }
        string best = s;
        for (int i = 1; i < (int)s.size(); ++i) {
            string r = s.substr(i) + s.substr(0, i);
            best = min(best, r);
        }
        return best;
    }
};
