01 / 题目

给定两个下标从 0 开始的整数数组 nums1、nums2，返回包含两个列表的 answer：

  • answer[0]：在 nums1 中出现、在 nums2 中没有出现的所有不同整数。
  • answer[1]：在 nums2 中出现、在 nums1 中没有出现的所有不同整数。

每个结果列表内不能有重复值；列表内的顺序任意，但左右两个列表的位置有固定含义。

示例 1

输入：nums1 = [1,2,3], nums2 = [2,4,6]
输出：[[1,3],[4,6]]

2 在两边都出现；1、3 仅在第一个数组，4、6 仅在第二个数组。

示例 2

输入：nums1 = [1,2,3,3], nums2 = [1,1,2,2]
输出：[[3],[]]

第一个数组中的两个 3 只保留一次；第二个数组没有独有数字，因此右侧结果为空。

约束

  • 1 ≤ nums1.length, nums2.length ≤ 1000
  • -1000 ≤ nums1[i], nums2[i] ≤ 1000

04 / 独立题解

准备好后再打开，包含推导与四语言代码。

核心洞察：先消除重复，再判断存在性

题目问的是一个值是否出现，不关心它出现几次。令 A = Set(nums1)、B = Set(nums2)，答案就是两个有方向的差集：[A ∖ B, B ∖ A]。不能把它们合并成一个无方向的对称差。

完整过程

  1. 遍历 nums1，把值放进集合 A。重复值不会形成新的记录。
  2. 同样构建集合 B。两个集合都建好后再查询，避免把尚未读到的值误认为不存在。
  3. 遍历 A：若 B 不包含当前值，放入 answer[0]。
  4. 遍历 B：若 A 不包含当前值，放入 answer[1]。
  5. 返回两个列表。无需排序，也无需修改原始数组。

示例 2：A = {1,2,3}，B = {1,2}。检查 A 时 1、2 被过滤，3 留下；检查 B 时两个值都被过滤。最终得到 [[3],[]]。

为什么正确

集合构建结束后，A、B 分别包含原数组中出现过的全部不同值。遍历 A 的任意前缀后，左结果恰好包含该前缀里不属于 B 的值：初始为空成立；每一步只在当前值不属于 B 时追加，因此不变式保持。遍历结束后，所有且仅有 nums1 独有的值被保留；集合遍历又保证每个值只处理一次，所以无重复。右结果同理。两个列表的顺序固定，满足题目定义。

边界与复杂度

完全相同得到两个空列表；完全无交集得到各自去重后的所有值；一边被另一边包含时只有对应一侧为空。负数、0、±1000 均可直接作为集合键。输入数组长度至少为 1，结果列表允许为空。

记原数组长度为 n、m，不同值数量为 u、v。哈希集合操作按平均 O(1) 计，时间为 O(n + m)，辅助空间为 O(u + v)，最坏可写为 O(n + m)；返回结果也至多 O(u + v)。极端哈希冲突可能使操作退化，以上是通常的平均复杂度。

替代方案

  • 排序 + 双指针：跳过相等与重复值，分别收集独有值。时间 O(n log n + m log m)，空间依排序实现及是否复制输入而定；适合数组已有序的情况。
  • 值域标记：本题可用两个长度为 2001 的布尔表，以 x + 1000 为下标。标记后扫描整个值域，时间 O(n + m + 2001)，空间 O(2001)，依赖已知取值范围。
  • 逐个线性查找：对方数组每次扫描 O(m) 或 O(n)，还需对答案去重；总时间 O(nm)，适合解释朴素思路，规模增大时不如集合。

常见错误

  • 直接遍历原数组收集独有值，却没有去重，导致重复输出。
  • 只计算 A ∖ B，遗漏右侧列表；或者交换左右结果。
  • 一边删除共有值一边查询被修改的集合，破坏原始存在性依据。
  • 把“不同”误解成频次相减；[1,1] 与 [1] 应返回 [[],[]]。
  • 为匹配示例强行排序。顺序任意，验证时应按集合比较各子列表。

面试追问

  • 需要按升序输出？收集后排序结果，额外 O(k log k)，k 为输出值数。
  • 若要求按首次出现顺序？可遍历原数组，用另一个集合记录已输出值；JS Set 的迭代本身保留插入顺序。
  • 若要保留重复次数差？改用频次表，按次数之差输出；这已是多重集合差。
  • 若输入已排序？双指针线性扫描并跳过重复，避免建立哈希集合。

可提交代码 · JavaScript

/**
 * @param {number[]} nums1
 * @param {number[]} nums2
 * @return {number[][]}
 */
var findDifference = function(nums1, nums2) {
    const a = new Set(nums1), b = new Set(nums2);
    return [
        [...a].filter(x => !b.has(x)),
        [...b].filter(x => !a.has(x))
    ];
};

可提交代码 · Java

import java.util.*;

class Solution {
    public List<List<Integer>> findDifference(int[] nums1, int[] nums2) {
        Set<Integer> a = new HashSet<>();
        Set<Integer> b = new HashSet<>();
        for (int x : nums1) a.add(x);
        for (int x : nums2) b.add(x);
        List<Integer> left = new ArrayList<>();
        List<Integer> right = new ArrayList<>();
        for (int x : a) if (!b.contains(x)) left.add(x);
        for (int x : b) if (!a.contains(x)) right.add(x);
        return Arrays.asList(left, right);
    }
}

from typing import List

class Solution:
    def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
        a, b = set(nums1), set(nums2)
        return [list(a - b), list(b - a)]

可提交代码 · C++

#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    vector<vector<int>> findDifference(vector<int>& nums1, vector<int>& nums2) {
        unordered_set<int> a(nums1.begin(), nums1.end());
        unordered_set<int> b(nums2.begin(), nums2.end());
        vector<vector<int>> answer(2);
        for (int x : a) if (!b.count(x)) answer[0].push_back(x);
        for (int x : b) if (!a.count(x)) answer[1].push_back(x);
        return answer;
    }
};
