MINIMUM COSTS USING THE TRAIN LINE

乘坐火车路线的
最少费用

两条平行线路，同一组车站。普通线转入快线需要额外付费：为了抵达每一个站点，你会怎样安排行程？

● 普通线　● 快线　 0 → 1 → … → n

01 / 问题与规则

每一站，都要一个最低票价

普通线和快线都经过编号为 0…n 的车站。你从 0 号站的普通线出发，向后续站点行进。

输入长度均为 n 的整数数组 regular、express，以及换乘费 expressCost。代码下标 j 表示从站 j 到站 j+1 的区间：普通线票价为 regular[j]，快线票价为 express[j]。

返回长度为 n 的数组，answer[j] 是从站 0 抵达站 j+1 的最低总费用，到达任意一条线都算抵达。各站答案可以采用不同的行程。

原题采用从 1 开始的区间与答案描述；下方代码统一采用从 0 开始的数组下标。

换乘规则

  • 普通 → 快线：每次支付 expressCost。
  • 快线 → 普通：免费。
  • 继续乘快线：不重复收取换乘费。
  • 离开快线后重新进入，需要再次付费。

约束

  • n = regular.length = express.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ regular[j], express[j] ≤ 10⁵
  • 1 ≤ expressCost ≤ 10⁵

04 / 题解与双轨实验室

保留两种到达方式，再走下一段

核心洞察

同一站的两名乘客，较贵的一位如果已经在快线上，下一段可能省下一笔入场费。因此不能只保存“到站的最低费用”。分别记录普通线到达费用 R 和快线到达费用 E，同站同线只保留最低值。

状态表示刚走完上一段、以对应线路抵达的费用；不把本站的换乘预先混入状态。起点定义 R₀=0、E₀=C，其中 C=expressCost。后者是已在站 0 付费进入快线的虚拟初始状态。

nextR = min(R, E) + regular[j]
nextE = min(E, R + C) + express[j]
answer[j] = min(nextR, nextE)

每段先算两个新值，再同时替换旧状态。到站后免费退出快线不会改变本站最小答案，而且后续转移已包含免费退出，所以不必额外更新本站的 R。

车站普通 R快线 E到站最少费用

完整过程 · 示例 1

  1. 起点：(R,E)=(0,8)。
  2. 第 1 段后：(1,13)，答案 1。
  3. 第 2 段后：(7,11)，答案 7。
  4. 第 3 段后：(16,14)，答案 14。站 2 保留的快线状态 11 带来了更低费用。
  5. 第 4 段后：(19,24)，答案 19。

输出 [1,7,14,19]。终点的最优路线不必在所有中间站都取得最低前缀费用。

正确性 · 归纳证明

初始普通状态为 0，进入快线付 C，初值正确。假设上站的两状态已为各自最低费用。

本段乘普通线，只可能从普通线继续或从快线免费退出；本段乘快线，只可能从快线继续或从普通线付 C 进入。这四种候选穷尽必要选择，各自取最小就得到正确的新状态。

站内多次来回换乘只会增加费用，可以删除。同站同线的未来费用相同，较贵的前缀无需保留。归纳可知全部状态正确；任一线路到站都算抵达，取两状态最小即为该站答案。

边界与复杂度

  • n=1：min(regular[0], C+express[0])。
  • 高入场费可能使普通线始终更优，也可能要连续多段快线才能划算。
  • 并列最优不影响结果；只求费用无需固定线路优先级。
  • 答案至多为普通线累计费用，最大可达 10¹⁰。Java 用 long，C++ 用 long long；JS Number 在本题范围内精确，Python int 足够。
  • 时间 O(n)；滚动状态额外空间 O(1)；计入返回数组为 O(n)。演示额外保存历史状态，使用 O(n) 空间。

替代方案与常见错误

  • 二维 DP 保存全部 R/E，O(n) 空间，便于回溯；只求费用时滚动变量足够。
  • 把换乘和行驶合成四种前进边，得到分层 DAG；拓扑最短路等价于本解。Dijkstra 可用，但堆和 O(n log n) 时间没有必要。
  • 逐段贪心选择便宜线路，会忽略换乘费和后续收益。
  • E 初始化为 0，会漏付首次进入快线的费用。
  • 先更新 R 再计算 E，会混用不同车站的状态。
  • 持续快线不应每段付 C；离开后再进入才重新收费。

面试追问

  • 如何恢复路线？ 给每站每种状态保存最优前驱，从指定终点较小的状态倒推。不同终点可能对应不同路线。
  • 各站换乘费不同？ 用出发站的 C 替代固定费用，快线初始值也采用站 0 的入场费。
  • 推广到 k 条线路？ 每站保存 k 个状态，通过换乘矩阵枚举前驱，一般为 O(nk²)。若可站内多次换乘，需先求站内最短换乘费用。
  • 只要求终点？ 省掉答案数组，最后返回 min(R,E)，总空间 O(1)。

四种语言 · 相同的两状态转移

均为 LeetCode 方法提交形式，代码仅生成，尚未执行或提交。先用旧状态计算两个新值，再替换变量。

Java

class Solution {
    public long[] minimumCosts(int[] regular, int[] express, int expressCost) {
        int n = regular.length;
        long[] answer = new long[n];
        long r = 0, e = expressCost;
        for (int i = 0; i < n; i++) {
            long nextR = Math.min(r, e) + regular[i];
            long nextE = Math.min(e, r + expressCost) + express[i];
            answer[i] = Math.min(nextR, nextE);
            r = nextR;
            e = nextE;
        }
        return answer;
    }
}

Python 3

from typing import List

class Solution:
    def minimumCosts(self, regular: List[int], express: List[int],
                     expressCost: int) -> List[int]:
        answer = []
        r, e = 0, expressCost
        for a, b in zip(regular, express):
            next_r = min(r, e) + a
            next_e = min(e, r + expressCost) + b
            answer.append(min(next_r, next_e))
            r, e = next_r, next_e
        return answer

class Solution {

    vector<long long> minimumCosts(vector<int>& regular,
                                   vector<int>& express, int expressCost) {
        vector<long long> answer(regular.size());
        long long r = 0, e = expressCost;

            r = nextR;
            e = nextE;

        return answer;
    }
