Continuous ranges

找到连续区间的开始和结束数字

给定一张记录唯一日志编号的表，把所有编号按升序划分为若干个最大连续区间，并输出每个区间的起点与终点。

SQL窗口函数连续分组
Problem

题目转述

表 Logs 中保存若干互不重复的整数日志编号。两个编号相差 1 时，它们属于同一段连续序列。请为每一段不能再向左右扩展的连续序列返回 start_id 和 end_id，结果按 start_id 升序排列。

这是数据库题。官方可提交答案是 SQL；页面后面的 Java、JavaScript、Python 与 C++ 仅用于在本地数组上表达同一语义。

Walkthrough

题解

核心洞察：连续段拥有相同的“位移”

按 log_id 排序并从 1 开始编号为 rn。在任意连续段内，log_id 每次加 1，rn 也每次加 1，因此 log_id − rn 始终不变。不同的最大连续段之间至少跳过一个整数，这个差值必然改变，于是它自然成为分组键。

完整过程

  1. 用 ROW_NUMBER() OVER (ORDER BY log_id) 给日志编号建立连续序号。
  2. 计算每一行的分组键 log_id - rn。
  3. 按分组键聚合；每组最小编号是 start_id，最大编号是 end_id。
  4. 按 start_id 升序返回。

官方提交语言：SQL（MySQL 8+）

MySQL · 可提交答案
WITH numbered AS (
    SELECT
        log_id,
        ROW_NUMBER() OVER (ORDER BY log_id) AS rn
    FROM Logs
)
SELECT
    MIN(log_id) AS start_id,
    MAX(log_id) AS end_id
FROM numbered
GROUP BY log_id - rn
ORDER BY start_id;

正确性证明

引理 1 · 同段同键

设连续段中的第一个编号为 a，其行号为 r。段内第 k 个编号为 a+k，行号为 r+k，两者之差恒为 a-r。

引理 2 · 异段异键

相邻两段之间至少缺少一个编号。进入下一段时，log_id 的增量大于行号的增量 1，所以差值严格增大，不可能与上一段相同。

分组恰好

由两个引理，按差值分组既不会拆开一段，也不会合并两段。因此每个 SQL 分组恰好对应一个最大连续区间。

端点正确

每组中的编号连续且完整，最小值就是起点，最大值就是终点。按起点排序后即得到题目要求的全部结果。

边界情况

  • 空表：窗口子查询与聚合都不产生行，返回空结果。
  • 只有一行：该行同时是起点和终点。
  • 全部连续：最终只产生一个区间。
  • 全部互不相邻：每个编号各自形成 [x, x]。
  • 编号可以不从 1 开始；差值法不依赖首值。

复杂度

设有 n 行。窗口排序通常耗时 O(n log n)，之后编号、分组与聚合为 O(n)；执行引擎可能使用 O(n) 级中间空间。若优化器能利用 log_id 上的有序索引，排序成本可能降低，但不应把这一点当作通用保证。

替代方案

也可以用 LAG(log_id) 判断当前编号是否紧接上一编号：遇到断点记 1，再对断点标记做累计和得到分组号。它更容易扩展到“允许间隔不超过 k”之类的题目，但需要两层窗口计算，代码通常更长。还可以分别找“没有前驱”的起点与“没有后继”的终点，再配对；这种写法更依赖数据库执行计划。

本题判题入口是数据库 SQL。下面四份代码接受整数数组并返回区间，仅用于理解、面试演示或本地复用，不能替代本题的 SQL 提交。
Java · 本地数组语义参考
import java.util.*;

class Solution {
    public int[][] findContinuousRanges(int[] logIds) {
        if (logIds == null || logIds.length == 0) {
            return new int[0][2];
        }

        int[] ids = Arrays.copyOf(logIds, logIds.length);
        Arrays.sort(ids);
        List<int[]> ranges = new ArrayList<>();
        int start = ids[0];
        int end = ids[0];

        for (int i = 1; i < ids.length; i++) {
            if (ids[i] == end) { // 本地输入若含重复值，忽略重复项
                continue;
            }
            if ((long) ids[i] == (long) end + 1) {
                end = ids[i];
            } else {
                ranges.add(new int[] {start, end});
                start = end = ids[i];
            }
        }
        ranges.add(new int[] {start, end});
        return ranges.toArray(new int[ranges.size()][]);
    }
}
JavaScript · 本地数组语义参考
function findContinuousRanges(logIds) {
  if (!Array.isArray(logIds) || logIds.length === 0) return [];

  const ids = [...logIds].sort((a, b) => a - b);
  const ranges = [];
  let start = ids[0];
  let end = ids[0];

  for (let i = 1; i < ids.length; i += 1) {
    if (ids[i] === end) continue; // 容忍本地数组中的重复值
    if (ids[i] === end + 1) {
      end = ids[i];
    } else {
      ranges.push([start, end]);
      start = ids[i];
      end = ids[i];
    }
  }

  ranges.push([start, end]);
  return ranges;
}
Python · 本地数组语义参考
from typing import List


class Solution:
    def find_continuous_ranges(self, log_ids: List[int]) -> List[List[int]]:
        if not log_ids:
            return []

        ids = sorted(log_ids)
        ranges: List[List[int]] = []
        start = end = ids[0]

        for value in ids[1:]:
            if value == end:  # 容忍本地数组中的重复值
                continue
            if value == end + 1:
                end = value
            else:
                ranges.append([start, end])
                start = end = value

        ranges.append([start, end])
        return ranges

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> findContinuousRanges(vector<int> logIds) {
        if (logIds.empty()) return {};

        sort(logIds.begin(), logIds.end());
        vector<vector<int>> ranges;
        int start = logIds[0];
        int end = logIds[0];

        for (size_t i = 1; i < logIds.size(); ++i) {
            if (logIds[i] == end) continue; // 容忍本地重复值
            if (static_cast<long long>(logIds[i]) ==
                static_cast<long long>(end) + 1) {
                end = logIds[i];
            } else {
                ranges.push_back({start, end});
                start = end = logIds[i];
            }
        }
        ranges.push_back({start, end});
        return ranges;
    }
};

面试追问

  • 如果允许重复编号？ SQL 中先 SELECT DISTINCT log_id，再计算行号；否则重复行会破坏差值不变量。
  • 如果连续的定义是相邻差不超过 k？ 使用 LAG 标记 log_id - prev_id > k 的断点，再累计求组号。
  • 如何按用户分别求区间？ 窗口函数增加 PARTITION BY user_id，最终也按用户和组号聚合。
  • 旧版 MySQL 没有窗口函数怎么办？ 可用“起点无前驱、终点无后继”的反连接思路，或会话变量；前者通常更清晰，后者更依赖执行顺序。

常见错误

  • 直接按 log_id 分组，导致每行都是一组。
  • 忘记在 ROW_NUMBER 中按 log_id 排序。
  • 只用 LAG 找到断点，却没有累计断点生成稳定组号。
  • 没有给输出别名 start_id、end_id，或漏掉最终排序。
  • 在允许重复的变体中未先去重。
