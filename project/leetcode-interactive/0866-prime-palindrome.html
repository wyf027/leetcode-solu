Full Solution

从回文结构反向缩小搜索空间

核心洞察除 11 外，所有偶数位回文数都能被 11 整除，因此不可能是质数。只需枚举“前半部分”，镜像生成奇数位回文，再做素性测试。

完整过程

  1. 从前半部分整数 root = 1 起递增枚举。
  2. 把 root 的字符串去掉末位后反转，拼回 root 尾部，生成奇数位回文。例如 123 → 12321。
  3. 若候选小于 n，直接继续；否则检查它是否为质数。
  4. 第一个不小于 n 且为质数的候选就是答案。
  5. 11 是唯一需要单独处理的偶数位回文质数；当 8 ≤ n ≤ 11 时直接返回 11。

正确性证明

  1. 候选完整：镜像每个 root 会按升序生成全部奇数位回文；特殊值 11 另行覆盖。
  2. 排除安全：偶数位回文均被 11 整除，除了 11 本身都不是质数，因此跳过它们不漏解。
  3. 判断正确：素性测试检查到 √x；若没有任何因子，则 x 为质数。
  4. 最小性：候选按数值递增，算法返回第一个满足 x ≥ n 且为质数的回文，故它必为最小答案。

边界与复杂度

  • n = 1：枚举会得到 2。
  • 8 ≤ n ≤ 11：必须保留特殊答案 11。
  • 质数检测先排除小于 2 和偶数，再只试除奇数。
  • 时间：设检查了 K 个回文、最大候选为 M，约为 O(K√M)。
  • 空间：O(log M)，来自短字符串镜像；额外工作空间可视为常数级。

常见错误

  • 从 n 开始逐个整数同时判断回文与质数，浪费大量搜索。
  • 镜像时把 root 的最后一位重复一次，生成了偶数位回文。
  • 忘记单独保留 11，导致输入 8、9、10、11 时返回错误。
  • 把 1 当作质数，或素性循环边界遗漏平方根。
  • 使用 d * d 时忽略大整数溢出；本题范围内 int 足够，但通用实现应留意。

替代方案与面试追问

逐数枚举

易写，但绝大多数整数连回文都不是，搜索冗余最大。

镜像构造（推荐）

只访问可能成为答案的回文，并利用偶数位回文的整除性质。

预生成 + 二分

多次查询时可预先生成并筛选所有答案，再用二分查找。

  • 追问 1：若有十万次查询，如何摊薄成本？答：预生成所有范围内回文质数并排序，单次查询二分。
  • 追问 2：如何加速素性测试？答：先用小质数筛除，或在更大范围使用确定性 Miller–Rabin。
  • 追问 3：为什么偶数位回文可被 11 整除？答：其奇数位数字和与偶数位数字和相等，交错和为 0，满足 11 的整除规则。

class Solution {
    public int primePalindrome(int n) {
        if (n >= 8 && n <= 11) return 11;

        for (int root = 1; root < 100000; root++) {
            String left = Integer.toString(root);
            StringBuilder palindrome = new StringBuilder(left);
            for (int i = left.length() - 2; i >= 0; i--) {
                palindrome.append(left.charAt(i));
            }
            int candidate = Integer.parseInt(palindrome.toString());
            if (candidate >= n && isPrime(candidate)) return candidate;
        }
        return -1;
    }

    private boolean isPrime(int x) {
        if (x < 2) return false;
        if (x % 2 == 0) return x == 2;
        for (int d = 3; d <= x / d; d += 2) {
            if (x % d == 0) return false;
        }
        return true;
    }
}

var primePalindrome = function(n) {
    if (n >= 8 && n <= 11) return 11;

    for (let root = 1; root < 100000; root++) {
        const left = String(root);
        const candidate = Number(
            left + left.slice(0, -1).split('').reverse().join('')
        );
        if (candidate >= n && isPrime(candidate)) return candidate;
    }
    return -1;
};

function isPrime(x) {
    if (x < 2) return false;
    if (x % 2 === 0) return x === 2;
    for (let d = 3; d <= Math.floor(x / d); d += 2) {
        if (x % d === 0) return false;
    }
    return true;
}
class Solution:
    def primePalindrome(self, n: int) -> int:
        if 8 <= n <= 11:
            return 11

        for root in range(1, 100000):
            left = str(root)
            candidate = int(left + left[-2::-1])
            if candidate >= n and self._is_prime(candidate):
                return candidate
        return -1

    def _is_prime(self, x: int) -> bool:
        if x < 2:
            return False
        if x % 2 == 0:
            return x == 2
        divisor = 3
        while divisor <= x // divisor:
            if x % divisor == 0:
                return False
            divisor += 2
        return True
