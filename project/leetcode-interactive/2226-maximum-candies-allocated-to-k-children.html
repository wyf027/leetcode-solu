每个小孩最多能
分到多少糖果

Maximum Candies Allocated to K Children

一堆可以拆开，两堆不能合并。怎样让每个孩子拿到同样多的糖果？

先理解分配规则，再展开题解探索。此页面可离线打开。

01 / 题目与规则

给定下标从 0 开始的整数数组 candies，其中 candies[i] 是第 i 堆的糖果数量；另给定孩子数 k。每堆可拆成若干子堆，但不同堆不能合并。每个孩子最多拿一堆，所有孩子获得的糖果数量必须相同，允许有剩余糖果或整堆不使用。返回每个孩子最多能获得的糖果数；连每人 1 颗都无法满足时返回 0。

官方示例 1

输入：candies = [5,8,6], k = 3
输出：5

将 8 拆成 5 与 3，将 6 拆成 5 与 1。加上原来的 5，三个孩子各取一堆 5，余下 3 与 1 不用；无法让三人各拿更多。

官方示例 2

输入：candies = [2,5], k = 11
输出：0

总共只有 7 颗，却有 11 个孩子，不能满足每人至少 1 颗，因此答案是 0。

参数与约束

  • 1 ≤ candies.length ≤ 10⁵
  • 1 ≤ candies[i] ≤ 10⁷
  • 1 ≤ k ≤ 10¹²
  • 接口：maximumCandies(candies, k) → integer

03 / 独立题解

准备好后，展开思路、演示与四语言代码。

从“分多少”变成“够不够”

核心洞察：尝试每人 x 颗（x ≥ 1）时，一堆 a 颗最多提供 ⌊a / x⌋ 份。因此可服务的孩子数是 f(x) = Σ⌊candies[i] / x⌋，只需判断是否达到 k。余数不能跨堆合并，所以不能用 ⌊Σcandies[i] / x⌋ 代替。

x 增大时，每一堆能提供的份数都不会增加；可行性形成“可行 → 不可行”的分界。对每人糖果数做二分，寻找最右侧的可行值。

  1. 令 lo = 0、hi = max(candies)。0 是无正数方案时的答案哨兵，不参与除法。
  2. 取上中位数 mid = lo + ⌊(hi − lo + 1) / 2⌋。
  3. 累计各堆的整数商。若份数至少为 k，令 lo = mid；否则令 hi = mid − 1。
  4. 重复直到 lo = hi，返回 lo。

正确性与边界

判定正确：每个孩子只能从一堆获取 x 颗，一堆 a 至多供给 ⌊a/x⌋ 人。各堆独立切分即可达到这些份数之和。总份数 ≥ k 时任选 k 份分配，反之不可能满足所有孩子。

单调性：对任意 y > x，有 ⌊a/y⌋ ≤ ⌊a/x⌋，逐堆相加仍成立。因此 x 不可行时，更大值都不可行。

循环不变量：最优答案始终在闭区间 [lo, hi] 中，lo 是已知可行值（包含 0 哨兵）。初始最大堆是上界。mid 可行时最优值不小于 mid；不可行时最优值小于 mid，两种更新都保留最优答案。上中位数在 lo < hi 时严格大于 lo，每次区间缩短。终止时唯一剩余值就是答案。

边界：总量小于 k 时返回 0；k = 1 时答案是最大堆；允许剩余、不需要整除。Java/C++ 的份数累计与 k 必须使用 64 位整数。总份数最大 10¹²，JavaScript Number 在此范围可精确表示整数；不要用位运算转换份数。

复杂度：令 n 为堆数、M 为最大堆，时间 O(n log(M + 1))，额外空间 O(1)。可行性累计一旦达到 k 即可提前结束。本页演示为回放保存每一轮状态，展示层空间不属于提交算法空间。

替代方案、追问与常见错误

替代方案：从 1 到 M 逐一尝试可以求解，但需要 O(nM) 时间。排序并不消除对候选值的判定，反而增加成本。可把二分上界收紧为 min(M, ⌊sum/k⌋)，需额外累计总量，量不足时可直接返回 0。

面试追问：若允许合并，答案变为 ⌊sum/k⌋；若要输出实际分配，对答案 x > 0 遍历各堆、领取至多 ⌊a/x⌋ 份，直到累计 k 份，可输出每堆贡献数量而无需生成 k 个对象；若 k 很大，显式列出每个孩子会有 O(k) 输出成本。

  • 把各堆余数拼起来，会违反不能合并的规则。
  • 把份数必须“等于 k”作为判定，会错过允许多余子堆的方案。
  • 用下中位数配合 lo = mid，可能在相邻边界时死循环。
  • 直接判定 x = 0 会导致除零；本模板从不对 0 取商。
  • 用 32 位整数存 k 或累计份数会溢出；JavaScript 使用 Math.max(...candies) 还可能超过参数数量限制，应循环求最大值。

Java

class Solution {
    public int maximumCandies(int[] candies, long k) {
        int lo = 0, hi = 0;
        for (int a : candies) hi = Math.max(hi, a);
        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;
            long count = 0;
            for (int a : candies) {
                count += a / mid;
                if (count >= k) break;
            }
            if (count >= k) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }
}

var maximumCandies = function(candies, k) {
    let lo = 0, hi = 0;
    for (const a of candies) hi = Math.max(hi, a);
    while (lo < hi) {
        const mid = lo + Math.floor((hi - lo + 1) / 2);
        let count = 0;
        for (const a of candies) {
            count += Math.floor(a / mid);
            if (count >= k) break;
        }
        if (count >= k) lo = mid;
        else hi = mid - 1;
    }
    return lo;
};
