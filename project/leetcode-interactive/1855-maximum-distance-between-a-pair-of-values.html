下标对中的最大距离

Maximum Distance Between a Pair of Values

在两条非递增数列之间，找到相隔最远的有效下标。

非付费题从 0 开始计数先思考，再展开
01 / PROBLEM

题意与约束

给定整数数组 nums1 和 nums2，两者都按非递增顺序排列，即相邻元素满足前一个大于或等于后一个。长度可以不同，下标均从 0 开始。

选择下标 i 和 j，同时满足以下条件时，下标对有效：

  • 0 ≤ i < nums1.length，0 ≤ j < nums2.length；
  • i ≤ j；
  • nums1[i] ≤ nums2[j]。

距离为 j − i。返回所有有效下标对的最大距离；若没有有效下标对，返回 0。

距离比较的是下标差，不是两个元素的数值差。相等的数值、相等的下标都允许。

官方约束

  • 1 ≤ nums1.length, nums2.length ≤ 10⁵
  • 1 ≤ nums1[i], nums2[j] ≤ 10⁵
  • 两个数组均非递增，允许重复值。

接口：maxDistance(nums1, nums2) → integer。题意与示例依据随任务提供的官方元数据转述。查看原题 ↗

准备好对照思路了吗？

双指针：沿着可行区域的边界向前

核心洞察

固定 i 时，nums2[j] 随着 j 右移只会变小。如果当前已经小于 nums1[i]，这一行后面的所有位置也必定失败，可以直接放弃当前 i。反过来，如果当前有效，就记录距离并右移 j，试着把跨度拉长。

每次先保证 j ≥ i：若 j < i，把 j 推到 i。两个指针始终只向右移动。

完整过程

  1. 令 i = 0、j = 0、best = 0。
  2. 只要两个下标均未越界，就继续循环。
  3. 若 j < i，令 j = i，下一轮重新检查边界。
  4. 否则若 nums1[i] ≤ nums2[j]，用 j − i 更新 best，然后执行 j++。
  5. 否则执行 i++，因为当前 i 已无法匹配 j 及其右侧位置。
  6. 循环结束后返回 best。

以示例 1 为例：(0,0) 有效，记录 0 后右移 j；(0,1) 与 (1,1) 都因数值不满足而下移 i。到 i=2 时先把 j 从 1 推到 2；随后依次访问 (2,2)、(2,3)、(2,4)，记录距离 0、1、2。j 越界后结束。

为什么正确

不变式：每次进入循环，best 是已访问有效下标对的最大距离；被跳过的下标对要么无效，要么不可能超过已记录距离。两个指针不回退。

  • 丢弃一行：若 nums1[i] > nums2[j]，对任意 k ≥ j，由 nums2 非递增可得 nums2[k] ≤ nums2[j] < nums1[i]。因此这一行尚未访问的部分全无效，i++ 安全。
  • 丢弃一列：若 (i,j) 有效，已记录 j−i。同一列中所有后续行 k > i 的距离 j−k 更小，即使有效也无法改进当前记录。之前被丢弃的行在这一列也已被排除，所以可以 j++。
  • 跳到对角线：若 j < i，所有列下标小于 i 的位置都违反 i ≤ j；直接把 j 设为 i 不会漏掉有效候选。

初始没有被丢弃的位置，不变式成立。每次移动都按上述规则安全排除候选；当任一数组耗尽，剩余位置都不可能提供更优有效对。因此返回 best 就是答案；没有有效对时，初值 0 保持不变。

边界与复杂度

相等时必须进入有效分支。长度不同不需要补齐数组；跳到 j=i 后必须先重新检查 j 是否越界。单元素、只有距离为 0 的有效对、完全无有效对，都可能返回 0，不能由返回值判断是否存在有效对。

令 m、n 为两数组长度。每轮推进至少一个指针，时间 O(m+n)，提交算法额外空间 O(1)。页面教学矩阵占 O(mn) 空间、步骤记录占 O(m+n)，它们不属于提交算法。

替代方案

逐行二分：对每个 i < min(m,n)，在 nums2 的 [i,n−1] 范围二分查找满足 nums2[j] ≥ nums1[i] 的最右位置。该谓词由真变假，复杂度 O(m log n)，额外空间 O(1)。二分时相等也要继续向右，若范围内没有有效元素，则跳过该行。

暴力枚举：检查所有 i ≤ j 的组合可直接对应定义，但最坏 O(mn)，不适合 10⁵ 级别输入。

常见错误

  • 只比较数值，忘记 i ≤ j，得到负距离或非法下标对。
  • 把 ≤ 写成 <，漏掉重复值或相等边界。
  • 数值不满足时右移 j：nums2 只会更小，应移动 i。
  • 每次移动 i 就让 j 从头开始，失去线性复杂度。
  • 用 nums2[j]−nums1[i] 当作距离；本题求 j−i。
  • 跳转 j=i 后立即读数组，未检查第二个数组是否耗尽。

面试追问

如何返回下标对？更新 best 时同时保存 (i,j)，并用单独的 found 标志处理“仅有距离 0”与“完全无有效对”的区别。

nums2 无序怎么办？上面的丢弃行证明失效；不能直接排序，因为题目距离依赖原始下标。可以考虑维护后缀最大值或离线数据结构，再重新证明查找条件。

这个版本是否必须要求 nums1 有序？这份按列排除的证明只依赖 nums2 非递增，以及固定列中行下标增大时距离缩小。因此它还能处理 nums1 无序的扩展情形；题目本身仍保证两数组非递增。

Java

class Solution {
    public int maxDistance(int[] nums1, int[] nums2) {
        int i = 0, j = 0, best = 0;
        while (i < nums1.length && j < nums2.length) {
            if (j < i) {
                j = i;
            } else if (nums1[i] <= nums2[j]) {
                best = Math.max(best, j - i);
                j++;
            } else {
                i++;
            }
        }
        return best;
    }
}
