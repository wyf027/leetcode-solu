平方数组的数目

把数字看成图上的节点：若两数之和是完全平方数，就在它们之间连边。你的任务，是数出访问所有节点且不重复排列的路径数量。

HARD数组数学回溯位掩码

题目

如果一个数组中每一对相邻元素之和都是完全平方数，则称它为平方数组。给定整数数组 nums，返回由其元素组成的、彼此不同的平方数组排列数量。只要两个排列在某个位置的值不同，它们就是不同排列。

函数签名

numSquarefulPerms(nums: integer[]) → integer

约束

  • 1 ≤ nums.length ≤ 12
  • 0 ≤ nums[i] ≤ 10⁹

官方示例

输入： nums = [1,17,8] 输出： 2 解释： [1,8,17] 和 [17,8,1] 是有效排列。
输入： nums = [2,2,2] 输出： 1

注意：相同数值交换位置不会产生新的值排列。

题解：排序 + 去重回溯

核心洞察

数组长度最多 12，允许枚举排列。排序后，同一层只尝试一份相同的值；同时用 used[i] 记录下标是否已进入路径。添加新数前，只需检查它与路径末尾之和是否为完全平方数。

完整过程

  1. 将 nums 升序排序，让重复值相邻。
  2. 从空路径开始深度优先搜索；每层枚举尚未使用的下标。
  3. 若 i > 0、nums[i] == nums[i-1] 且前一个副本在本层仍未使用，就跳过当前副本，防止重复排列。
  4. 若路径非空，检查 last + nums[i] 的整数平方根平方后是否仍等于该和；不成立则剪枝。
  5. 路径长度等于 n 时答案加一；撤销选择后继续寻找其他路径。

为什么正确

完备性：回溯在每个位置尝试所有尚未使用且满足平方邻接条件的不同数值，因此每个合法值排列都能沿其元素顺序被构造。合法性：每次追加元素都验证新产生的唯一相邻对，所以完整路径中的所有相邻和均为完全平方数。唯一性：排序后的同层去重规则只让相同值中最靠前的可用副本先被选择；交换相同值下标的重复路径因此不会被再次计数。

边界情况

  • 单元素数组：没有相邻对，答案为 1。
  • 全部元素相同：若两数之和为平方数则为 1，否则为 0（单元素除外）。
  • 包含 0：0 与 0 的和也是完全平方数。
  • 大数：和最大为 2×10⁹，Java 的 int 仍可容纳；实现中使用整数复核平方根。

复杂度

最坏枚举 n! 条路径，每次扩展做常数检查，时间复杂度 O(n·n!)（大量剪枝时更快）；排序 O(n log n)。递归路径、使用标记占 O(n)，不计排序栈。

替代方案

可构建合法邻接图，再做位掩码 DP：dp[mask][last] 统计以某下标结尾的路径。重复值仍需按层去重，复杂度约 O(n²·2ⁿ)，状态更稳定但代码更重。

面试追问

为什么不能在最终答案上除以重复元素阶乘？

搜索中的合法性与位置有关，粗暴相除虽然某些实现可能凑巧成立，却容易与搜索计数方式耦合。构造时去重更直接，也保证从未生成重复叶子。

如何避免浮点平方根误差？

先求整数化的平方根 r，再检查 r*r == sum；不要只比较浮点结果是否为整数。

如果 n 增大到 20 呢？

全排列基本不可行，应优先考虑值频次状态、图上的状态压缩 DP，或利用图结构继续剪枝。

常见错误

  • 把相同值的不同下标当作不同排列重复计数。
  • 用 Math.sqrt(sum) % 1 == 0 后不做整数乘法复核。
  • 去重条件写成“只要与前一个值相等就跳过”，从而误删需要使用多个副本的路径。
  • 回溯后忘记恢复 used 或移除路径末尾。

四语言完整实现

Java

import java.util.Arrays;

class Solution {
    private int[] nums;
    private boolean[] used;

    public int numSquarefulPerms(int[] nums) {
        Arrays.sort(nums);
        this.nums = nums;
        this.used = new boolean[nums.length];
        return dfs(0, 0);
    }

    private int dfs(int depth, int last) {
        if (depth == nums.length) return 1;
        int count = 0;
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
            if (depth > 0 && !isSquare(last + nums[i])) continue;
            used[i] = true;
            count += dfs(depth + 1, nums[i]);
            used[i] = false;
        }
        return count;
    }

    private boolean isSquare(int value) {
        int root = (int) Math.sqrt(value);
        return root * root == value;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number}
 */
var numSquarefulPerms = function(nums) {
  nums.sort((a, b) => a - b);
  const used = Array(nums.length).fill(false);

  const isSquare = (value) => {
    const root = Math.floor(Math.sqrt(value));
    return root * root === value;
  };

  const dfs = (depth, last) => {
    if (depth === nums.length) return 1;
    let count = 0;
    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;
      if (i > 0 && nums[i] === nums[i - 1] && !used[i - 1]) continue;
      if (depth > 0 && !isSquare(last + nums[i])) continue;
      used[i] = true;
      count += dfs(depth + 1, nums[i]);
      used[i] = false;
    }
    return count;
  };

  return dfs(0, 0);
};

Python 3

from typing import List
from math import isqrt

class Solution:
    def numSquarefulPerms(self, nums: List[int]) -> int:
        nums.sort()
        used = [False] * len(nums)

        def is_square(value: int) -> bool:
            root = isqrt(value)
            return root * root == value

        def dfs(depth: int, last: int) -> int:
            if depth == len(nums):
                return 1
            count = 0
            for i, value in enumerate(nums):
                if used[i]:
                    continue
                if i > 0 and value == nums[i - 1] and not used[i - 1]:
                    continue
                if depth > 0 and not is_square(last + value):
                    continue
                used[i] = True
                count += dfs(depth + 1, value)
                used[i] = False
            return count

        return dfs(0, 0)

C++

#include <algorithm>
#include <cmath>
#include <vector>
using namespace std;

class Solution {
    vector<int> nums;
    vector<bool> used;

    bool isSquare(int value) {
        int root = static_cast<int>(sqrt(value));
        return root * root == value;
    }

    int dfs(int depth, int last) {
        if (depth == static_cast<int>(nums.size())) return 1;
        int count = 0;
        for (int i = 0; i < static_cast<int>(nums.size()); i++) {
            if (used[i]) continue;
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
            if (depth > 0 && !isSquare(last + nums[i])) continue;
            used[i] = true;
            count += dfs(depth + 1, nums[i]);
            used[i] = false;
        }
        return count;
    }

public:
    int numSquarefulPerms(vector<int>& input) {
        nums = input;
        sort(nums.begin(), nums.end());
        used.assign(nums.size(), false);
        return dfs(0, 0);
    }
};
