计算数字频率得分

把十进制表示逐位扫描；每读到一位，就把这位数字直接加入答案。重复出现自然会重复累加。

时间 O(位数) · 空间 O(1)

题意

给定正整数 n。不同数字 d 的贡献是 d × freq(d)，其中 freq(d) 是它在 n 中出现的次数；返回所有贡献的和。

示例 1
n = 122
数字 1 贡献 1 × 1，数字 2 贡献 2 × 2，结果为 5。
示例 2
n = 101
数字 0 的贡献为 0，两个数字 1 贡献 1 + 1，结果为 2。

约束：1 ≤ n ≤ 10⁹。输入中不会有前导零。

题解：频率公式可以逐位拆开

对任意数字 d，它出现 freq(d) 次，会在答案中加入 d 共 freq(d) 次。因此 Σ d × freq(d) 恰好等于把 n 的每个十进制位直接相加。无需哈希表或计数数组。

完整过程

  1. 当 n > 0 时，取 digit = n % 10。
  2. 令 answer += digit。
  3. 令 n = floor(n / 10)，直到没有剩余位。

边界与复杂度

  • 数字 0 会被读取但不会改变和，符合 0 × freq(0) = 0。
  • n 至少为 1，因此循环至少执行一次。
  • 若 k 为位数，时间复杂度为 O(k)，额外空间为 O(1)。

替代方案、面试追问与常见错误

  • 替代方案：转为字符串后累加每个字符减去 '0'；更直观，但有字符串分配。
  • 追问：如果改为任意进制，只需把除数和取模从 10 改为对应进制。
  • 常见错误：先计频再漏乘数字；或错误地把“不同数字”理解为每个数字只计一次。

四语言可提交代码

class Solution {
    public int digitFrequencyScore(int n) {
        int score = 0;
        while (n > 0) {
            score += n % 10;
            n /= 10;
        }
        return score;
    }
}
