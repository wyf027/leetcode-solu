Counter

给一个起点，让同一个函数在每次调用时交出序列中的下一个整数。

函数设计 闭包语义 非付费题
先读题，再动手
01 / Problem

题目要求

准确转述

给定整数 n，返回一个 counter 函数。第一次调用 counter() 时返回 n；此后每次调用，都返回上一次结果加 1，依次得到 n、n + 1、n + 2……

官方提交入口为 createCounter(n)；测试器会按给定的 calls 序列反复调用返回的函数。

约束

  • -1000 ≤ n ≤ 1000
  • 0 ≤ calls.length ≤ 1000
  • calls[i] === "call"
示例 1
输入：
n = 10
["call","call","call"]

输出：[10,11,12]

解释：
counter() = 10  // 首次返回 n
counter() = 11  // 上次结果加 1
counter() = 12  // 再加 1
示例 2
输入：
n = -2
["call","call","call","call","call"]

输出：[-2,-1,0,1,2]

解释：
counter() 初始返回 -2，
之后每次调用递增 1。

03 / Solution

准备好看题解了吗？

先在上面的轨迹里观察多次调用的变化，再展开完整推导与实现。

一个变量，一段被保留的状态

→
核心洞察：返回的函数必须记住“下一次该返回什么”。把可变的 n 留在外层函数的词法环境里，内层函数每次先返回当前值，再将它加一。

完整过程

  1. createCounter(n) 接收初始整数。
  2. 创建并返回一个内部函数。
  3. 每次执行内部函数，后置递增表达式 n++ 先产出当前值，再更新保存的 n。
  4. 下一次调用继续读取更新后的同一个变量。

正确性

设内部函数已被调用 k 次。调用前保存值为 n + k：首次时 k = 0，显然成立。第 k + 1 次调用返回 n + k，随后保存值变为 n + k + 1，故归纳成立。因此每次返回的正是题目要求的序列项。

边界与复杂度

  • 零次调用：函数可以被创建而不执行，不产生输出。
  • 负数起点：递增规则不变，可自然跨过零。
  • 时间：每次调用 O(1)。
  • 空间：计数器本身额外占用 O(1)。

替代方案

也可声明独立变量 let count = n，再返回 () => count++，语义相同但多一个名字。若用调用次数乘加计算，则仍须保存调用次数，没有更简单。

面试追问

  • 前置递增 ++n 与后置递增 n++ 的返回值有何不同？
  • 两个分别创建的计数器会共享状态吗？为什么？
  • 如何扩展为支持 increment、decrement 和 reset？

常见错误

  • 直接返回数字，而不是返回函数。
  • 用 ++n，导致第一次返回 n + 1。
  • 把计数变量写在内部函数体内，导致每次调用都重新初始化。
  • 立即调用内部函数后返回结果，丢失可重复调用能力。
JavaScript官方可提交语言
/**
 * @param {number} n
 * @return {Function} counter
 */
var createCounter = function(n) {
  return function() {
    return n++;
  };
};
Java本地语义参考，非本题官方提交语言
import java.util.function.IntSupplier;

class Solution {
  public IntSupplier createCounter(int n) {
    final int[] value = {n};
    return () -> value[0]++;
  }
}
Python本地语义参考，非本题官方提交语言
from typing import Callable


def create_counter(n: int) -> Callable[[], int]:
    def counter() -> int:
        nonlocal n
        current = n
        n += 1
        return current

    return counter
C++本地语义参考，非本题官方提交语言
#include <functional>

class Solution {
public:
  std::function<int()> createCounter(int n) {
    return [n]() mutable { return n++; };
  }
};
