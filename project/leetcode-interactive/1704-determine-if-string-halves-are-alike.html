判断字符串的
两半是否相似

Determine if String Halves Are Alike — 先把问题放进可操作的实验台，再决定是否展开完整题解。

Problem brief

题目说明

给定一个长度为偶数的字符串 s，把它从中点拆成等长的前半段 a 与后半段 b。如果两半包含的元音字母数量相同，则称它们“相似”，返回 true；否则返回 false。

元音包括 a e i o u 及对应的大写字母；每次出现都要单独计数。

示例 1
输入：s = "book"
输出：true
解释：a = "bo"，b = "ok"；两边各有 1 个元音。
示例 2
输入：s = "textbook"
输出：false
解释：a = "text" 有 1 个元音，b = "book" 有 2 个元音。
Contract

函数与约束

halvesAreAlike(s: string): boolean
  • 2 ≤ s.length ≤ 1000
  • s.length 为偶数
  • s 仅由英文字母组成
  • 同时区分输入中的大、小写形式，但元音判断忽略大小写

Solution unlocked

一次扫描，用一个差值完成比较

把“分别计数后比较”压缩为一个平衡量：左边元音加一，右边元音减一。

O(n) time · O(1) space

核心洞察

字符串长度为偶数，中点天然划分左右两半。遍历每个字符时，如果它不是元音就忽略；如果是元音，则根据下标位于中点左侧还是右侧更新同一个差值 balance。

balance = vowels(a) − vowels(b)

扫描结束时，balance === 0 恰好表示两边元音数量相等。

完整过程

  1. 准备包含 10 个大小写元音的集合。
  2. 令 mid = s.length / 2、balance = 0。
  3. 从左到右扫描 s。
  4. 遇到元音且 i < mid 时加一，否则减一。
  5. 返回差值是否为零。

正确性证明

循环不变量：处理完下标 0…i 后，balance 等于已处理的前半段元音数减去已处理的后半段元音数。

初始化：尚未处理字符时，两侧计数均为 0，不变量成立。

保持：辅音不改变两侧计数；左半元音令差值加一，右半元音令差值减一，因此不变量保持。

终止：全部字符处理后，差值就是两半完整元音数之差。返回零当且仅当两半相似，所以算法正确。

边界与复杂度

  • 最短字符串长度为 2，依然能在中点拆分。
  • 两半都没有元音时，差值为 0，应返回 true。
  • 连续出现的同一元音必须逐个计数。
  • 大小写元音都需要识别。
  • 时间复杂度 O(n)，只扫描一次。
  • 元音集合大小固定，额外空间复杂度 O(1)。

替代方案

也可以切出两个子串，分别调用计数函数后比较，表达更直观，但会创建额外字符串；或用两个计数器分别记录左右半段，仍为 O(n)，只是状态多一个。差值法同时避免切片并让最终判断直接落在零值上。

面试追问

  • 若字符串长度可能为奇数？ 需要先约定中间字符归属或忽略规则。
  • 若比较任意字符类别？ 把元音判定替换为可注入的谓词即可。
  • 若输入是流？ 在不知道总长度时不能直接判断分界，可先获知长度或缓冲数据。
  • 能否提前返回？ 一般不能；后续字符仍可能抵消当前差值。

常见错误

只写小写元音，漏掉 AEIOU。

把元音是否出现当成布尔值，漏计重复字符。

中点写成错误的偏移，导致某个字符被漏掉或重复处理。

用排序、哈希统计所有字符，解决了比题目更大的问题。

Implementations

四种语言完整代码

Java
class Solution {
    public boolean halvesAreAlike(String s) {
        String vowels = "aeiouAEIOU";
        int balance = 0;
        int mid = s.length() / 2;

        for (int i = 0; i < s.length(); i++) {
            if (vowels.indexOf(s.charAt(i)) == -1) {
                continue;
            }
            balance += i < mid ? 1 : -1;
        }

        return balance == 0;
    }
}

class Solution {
public:
    bool halvesAreAlike(string s) {
        const string vowels = "aeiouAEIOU";
        const int mid = static_cast<int>(s.size()) / 2;
        int balance = 0;

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            if (vowels.find(s[i]) == string::npos) {
                continue;
            }
            balance += i < mid ? 1 : -1;
        }

        return balance == 0;
    }
