数字的补数Number Complement

在有限的二进制位宽里，观察每个比特如何从一个状态切换到另一个状态。先理解任务，再进入交互实验；完整解法会留在页面底部，默认不会提前展开。

难度 · 简单 参数 · num: integer 返回 · integer 非付费题

Problem

题目说明

整数的补数，是把它的二进制表示中的每个 0 改为 1，并把每个 1 改为 0 后得到的整数。给定整数 num，返回它的补数。

二进制表示不包含前导零。也就是说，只处理从最高有效位到最低位的这段有限位宽。

示例 1

5 → 2

输入：num = 5
输出：2
解释：5 的二进制表示为 101（没有前导零位），取反后为 010，因此结果是 2。

示例 2

1 → 0

输入：num = 1
输出：0
解释：1 的二进制表示为 1（没有前导零位），取反后为 0，因此结果是 0。

约束

  • 1 <= num < 231

Spoiler Gate

核心洞察、证明、复杂度与四种语言代码都在折叠区内。

Solution

有限位宽掩码 + 异或

关键不是直接使用无限延伸的按位取反，而是先锁定 num 的有效二进制位宽，再只翻转这段范围。

核心洞察

设 num 的有效位宽为 k。构造低 k 位全为 1 的掩码 mask = 2k - 1。掩码与 num 异或，恰好会翻转有效范围内的每一位。

answer = num XOR (2ᵏ − 1)

完整过程

  1. 从 mask = 1 开始，不断左移，直到 mask > num。
  2. 此时 mask 等于严格大于 num 的最小二次幂，也就是 2k。
  3. 用 mask - 1 得到低 k 位全为 1 的位宽掩码。
  4. 返回 (mask - 1) XOR num。

正确性证明

掩码 2k - 1 的低 k 位都是 1，高位都是 0。对任意有效位 i，num[i] XOR 1 会把 0 变 1、把 1 变 0；对所有更高位，0 XOR 0 = 0，不会引入前导位。因此结果恰好是题目定义的补数。

边界与复杂度

  • num = 1 时，位宽为 1，掩码为 1，答案为 0。
  • num 的有效位全为 1 时，异或结果自然为 0。
  • 输入上限小于 231；实现中用足够宽的临时整数，避免构造下一次幂时溢出。
  • 时间复杂度 O(log num)，空间复杂度 O(1)。

替代方案

可以从最低位开始扫描 num：每次读取最低位，翻转后写入答案的对应位置，再右移。这同样需要 O(log num) 时间，但状态变量更多。

也可以利用语言提供的最高位函数直接求位宽。注意不能裸用 ~num：固定宽度整数的高位也会被翻转，通常会得到负数或多余高位。

面试追问

  • 如果允许 num = 0，应如何定义有效位宽与答案？
  • 如何用最高有效位 API 把构造掩码降为常数次操作？
  • JavaScript 的按位运算为何会转成 32 位有符号整数？本题范围内为什么结果仍安全？
  • 若输入扩展到 64 位，临时掩码应选用什么类型？

常见错误

  • 直接返回 ~num，忘记屏蔽有效位之外的高位。
  • 把位宽误写成固定 31 位，错误地把前导零也纳入翻转。
  • 构造 2k 时仍使用可能溢出的有符号 32 位临时变量。
  • 误把逻辑非 ! 当成按位操作，或混淆 XOR 与 OR。

Implementations

四种语言完整代码

JavaLeetCode
class Solution {
    public int findComplement(int num) {
        long nextPowerOfTwo = 1;
        while (nextPowerOfTwo <= num) {
            nextPowerOfTwo <<= 1;
        }

        int mask = (int) (nextPowerOfTwo - 1);
        return mask ^ num;
    }
}

C++LeetCode
class Solution {
public:
    int findComplement(int num) {
        unsigned int nextPowerOfTwo = 1;
        const unsigned int value =
            static_cast<unsigned int>(num);

        while (nextPowerOfTwo <= value) {
            nextPowerOfTwo <<= 1;
        }

        const unsigned int mask = nextPowerOfTwo - 1;
        return static_cast<int>(mask ^ value);
    }
};
