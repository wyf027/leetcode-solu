找出井字棋的获胜者

把一串落子坐标还原成棋局结论：赢家、平局，还是仍待继续。先亲手回放，再决定是否揭开题解。

Problem

题目要求

玩家 A 与 B 在 3 × 3 棋盘上轮流落子。A 先手使用 X，B 使用 O。

给定二维整数数组 moves，其中 moves[i] = [rowᵢ, colᵢ] 表示第 i 步落在 grid[rowᵢ][colᵢ]。输入保证是一段符合井字棋规则的有效落子序列。

  • RULE 01

    A、B 依次将棋子放进空格；已有棋子的格子不会再次落子。

  • RULE 02

    任意一行、一列或一条对角线上出现 3 个相同的非空棋子，游戏立即结束。

  • RULE 03

    棋盘填满仍无人获胜则为平局；尚有空位且无人获胜则游戏未结束。

返回：有赢家时返回 "A" 或 "B"；棋盘填满返回 "Draw"；否则返回 "Pending"。

Examples

官方示例

示例 1 输出 "A"

moves = [[0,0],[2,0],[1,1],[2,1],[2,2]]

A 总是先手；最后一枚 X 补成主对角线，A 获胜。

示例 2 输出 "B"

moves = [[0,0],[1,1],[0,1],[0,2],[1,0],[2,0]]

B 的三枚 O 占据另一条对角线，因此 B 获胜。

示例 3 输出 "Draw"

moves = [[0,0],[1,1],[2,0],[1,0],[1,2],[2,1],[0,1],[0,2],[2,2]]

9 个格子全部填满，且没有三子连线，游戏平局。

Constraints

约束

  • 1 ≤ moves.length ≤ 9
  • moves[i].length == 2
  • 0 ≤ rowᵢ, colᵢ ≤ 2
  • moves 中没有重复坐标
  • moves 遵循井字棋规则
  • 棋盘初始为空，玩家 A 先行动

Solution

用 8 个计数器捕捉胜负

不必保存整个棋盘。每次落子只会影响一行、一列，以及最多两条对角线。

!

核心洞察

让 A 的每次落子贡献 +1，B 的每次落子贡献 -1。某条线的计数到达 +3，说明 A 占满该线；到达 -3，说明 B 占满该线。符号同时编码了玩家身份。

8 条获胜线如何编号

计数数组 score[0..7] 覆盖全部可能的连线。

0–2三行
3–5三列
6主对角线
7副对角线

完整过程

  1. 按时间顺序遍历 moves，偶数下标属于 A，奇数下标属于 B。
  2. 更新对应行与列；若 row == col 更新主对角线，若 row + col == 2 更新副对角线。
  3. 任一计数绝对值变为 3，就返回当前玩家。
  4. 遍历结束仍无赢家：走满 9 步返回 Draw，否则返回 Pending。

正确性证明

  1. 不变式：处理完任意前缀后，每个计数器等于该线上 A 棋子数减去 B 棋子数。
  2. 赢家判定：一条线仅有 3 格。有效棋局中计数为 +3 当且仅当三格全是 A；-3 同理对应 B。
  3. 终局分类：若不存在上述计数，便没有赢家。此时 9 步恰好填满棋盘，对应平局；少于 9 步则仍有空格，对应待定。

因此算法返回且只返回题目定义的正确状态。

边界与复杂度

  • 中心格同时属于一行、一列和两条对角线，四处都要更新。
  • 只走 1 步时必然是 Pending。
  • 第 9 步仍可能产生赢家，应先判胜再判平局。
  • 输入已保证有效，无须处理重复落子或终局后的额外移动。
时间复杂度O(m)，m = moves.length ≤ 9
额外空间O(1)，固定 8 个整数

替代方案

直接模拟棋盘：建立 3 × 3 字符矩阵，完成所有落子后检查每行、每列和对角线。它更直观，也方便扩展到展示棋盘；空间仍是常数，但代码略长。

位掩码：给 9 个格子分配 9 个二进制位，分别维护 A、B 的占用掩码，再与 8 个胜利掩码比较。适合追问位运算优化。

面试追问与常见错误

  • 追问：如何扩展到 n × n？保留行列计数，胜利阈值改为 n，对角线判定不变。
  • 追问：若输入不保证有效？需要额外检查坐标范围、重复占用、轮次及胜负后是否仍有落子。
  • 错误：只检查最后一步的行列却漏掉对角线。
  • 错误：看到 moves.length == 9 就先返回平局，漏掉最后一步获胜。
  • 错误：用同号累计 A 与 B，无法区分一条线是否被双方混合占用。

JavaSolution.tictactoe
class Solution {
    public String tictactoe(int[][] moves) {
        int[] score = new int[8];

        for (int i = 0; i < moves.length; i++) {
            int row = moves[i][0];
            int col = moves[i][1];
            int value = (i % 2 == 0) ? 1 : -1;

            score[row] += value;
            score[3 + col] += value;
            if (row == col) score[6] += value;
            if (row + col == 2) score[7] += value;

            for (int line : score) {
                if (Math.abs(line) == 3) {
                    return value == 1 ? "A" : "B";
                }
            }
        }
        return moves.length == 9 ? "Draw" : "Pending";
    }
}

    for (let i = 0; i < moves.length; i++) {

    return moves.length === 9 ? "Draw" : "Pending";
};

            score[row] += value
            score[3 + col] += value
            if row == col:
                score[6] += value
            if row + col == 2:
                score[7] += value
