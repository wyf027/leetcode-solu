LeetCode 1692

计算分配糖果的不同方式

Count Ways to Distribute Candies

困难动态规划会员题

有 n 颗互不相同的糖果，要把它们分到 k 个没有编号的袋子里，并保证每个袋子至少有一颗糖。两种分法只要存在某颗糖所在的组合不同，就视为不同。返回不同分法的数量；答案对 1,000,000,007 取模。

函数签名：waysToDistribute(n, k) → integer。糖果彼此可区分，袋子的排列顺序不产生新方案。

Problem statement

示例与约束

示例 1

输入：n = 3, k = 2
输出：3

若糖果为 1、2、3，三种无序分组是：{1}|{2,3}、{2}|{1,3}、{3}|{1,2}。

示例 2

输入：n = 4, k = 2
输出：7

每种非空二分法只计一次，交换两个袋子不会得到新方案。

示例 3

输入：n = 20, k = 5
输出：206085257

结果较大，因此需要按题目要求取模。

约束
  • 1 ≤ k ≤ n ≤ 1000
  • 所有糖果互不相同；每个袋子非空。

Complete solution

题解：第二类斯特林数

核心洞察

把 n 个不同元素划分成 k 个非空、无序集合，正是第二类斯特林数 S(n, k)。关注编号为 n 的最后一颗糖，它只有两种互斥去向：

  1. 进入已有袋子：前 n - 1 颗已经形成 k 袋，有 S(n-1,k) 种；最后一颗可选择其中任一袋，共 k · S(n-1,k) 种。
  2. 独自开启新袋：前 n - 1 颗必须恰好形成 k - 1 袋，共 S(n-1,k-1) 种。
状态转移： S(n,k) = k · S(n-1,k) + S(n-1,k-1)。

完整过程

  1. 定义 dp[j] 为处理当前数量糖果时，恰好分成 j 个非空袋子的方案数。
  2. 初始化 dp[0] = 1，表示零颗糖分进零个袋子有一种空划分。其他状态为零。
  3. 逐颗加入糖果。对袋子数 j 从大到小更新：dp[j] = j * dp[j] + dp[j-1]。
  4. 倒序非常关键：更新 dp[j] 时，dp[j] 和 dp[j-1] 都仍代表上一行。
  5. 每一步取模，最终返回 dp[k]。

正确性证明

命题：算法返回把 n 颗不同糖果分入 k 个非空无序袋子的方案数。

基础情形：dp[0] = 1 正确表示空集合的唯一空划分；正数颗糖分进零袋、或糖果数少于袋数时均为零。

归纳步骤：假设少一颗糖时所有状态正确。任取一个 (i,j) 的合法分法，考察第 i 颗糖：若其所在袋还有其他糖，移除它后仍有 j 袋，并且它可被放回任一袋，对应 j·S(i-1,j)；若它单独成袋，移除该袋后恰有 j-1 袋，对应 S(i-1,j-1)。两类互斥且覆盖所有分法，转移无重无漏。由数学归纳法，最终 dp[k] 正确。

边界情况

  • k = 1：所有糖果只能放在同一袋，答案为 1。
  • k = n：每袋恰好一颗糖；袋子无序，答案为 1。
  • k > n：无法保证每袋非空，数学上答案为 0；题目约束通常已排除。
  • 大结果必须在乘法和加法后及时取模。

复杂度

时间复杂度 O(nk)；使用一维滚动数组后，空间复杂度 O(k)。

四语言完整代码

class Solution {
    public int waysToDistribute(int n, int k) {
        final long MOD = 1_000_000_007L;
        long[] dp = new long[k + 1];
        dp[0] = 1;

        for (int candies = 1; candies <= n; candies++) {
            int upper = Math.min(candies, k);
            for (int bags = upper; bags >= 1; bags--) {
                dp[bags] = (bags * dp[bags] + dp[bags - 1]) % MOD;
            }
            dp[0] = 0;
        }
        return (int) dp[k];
    }
}

替代方案

  • 二维 DP：直接保存 dp[i][j]，更直观，时间仍为 O(nk)，空间为 O(nk)。
  • 记忆化搜索：严格照递推式递归并缓存状态，同样是 O(nk)，但有递归栈和函数调用开销。
  • 容斥：先把袋子临时编号，用满射计数后除以 k!；需要快速幂和模逆元，推导更重，不是本题最稳妥的面试实现。

面试追问

  1. 如果袋子有编号，答案与本题有什么关系？答：每个无序划分可排列为 k! 种，答案乘以 k!。
  2. 为什么一维 DP 必须倒序？答：正序会让 dp[j-1] 提前变成当前行，混用同一颗糖，破坏转移语义。
  3. 如果允许空袋怎么办？答：无编号空袋没有辨识度；若袋子有编号，则可转成每颗糖选择一个袋子的计数，并视是否要求每袋使用决定是否用容斥。

常见错误

  • 把袋子当作有序，额外乘入排列数量。
  • 忘记每袋非空，误写成 k^n。
  • 把转移系数写成 n 或 k-1；进入已有袋子时可选的是当前目标的 j 个袋子。
  • 滚动数组正序更新，导致读取已被覆盖的状态。
  • 在 Java/C++ 中用 32 位整数做乘法而溢出。
