题意要点

Inspector Notes / Solution

集合记住已经见过谁

核心洞察

目标是判断当前值是否出现过，这是哈希集合最擅长的存在性查询。集合首次插入成功就保留节点，再次命中时让前驱 next 跨过当前节点。

不变量

扫描到 current 前，seen 恰好包含已保留节点的值，去重链表也恰好保存这些值的首次出现。处理 current 后，该不变量继续成立。

完整过程

  1. 若 head 为空，直接返回 null。
  2. 把头节点值加入 seen，让 current 指向 head。
  3. 检查 current.next：若值已在 seen 中，让 current.next 跨过该节点。
  4. 若值未出现，加入 seen，并让 current 前进到该节点。
  5. 直到 current.next 为空，返回原 head。

边界

  • 空链表不创建集合查询，直接返回。
  • 单节点没有重复，保持原样。
  • 全部相同只留下头节点。
  • 全部唯一时 current 每轮都前进。
  • 删除重复节点时 current 不能前进，否则可能漏掉连续重复。

复杂度

O(n)时间：期望每个节点查询一次
O(n)空间：最坏保存全部不同值

替代方案

若不得使用临时缓冲区，可让外层指针固定一个节点，再用 runner 扫描其后所有节点并删除同值项。额外空间为 O(1)，但最坏时间为 O(n²)。排序后去重会破坏首次出现顺序，因此不适合本题。

常见错误

  • 删除重复节点后仍移动 current，导致连续重复漏删。
  • 保留最后一次出现，而题目要求保留第一次。
  • 误以为未排序链表的重复值一定相邻。
  • 把节点对象放入集合，而不是节点值。

面试追问

  1. 如何不用额外缓冲区完成？请写出 runner 双指针。
  2. HashSet 的 O(1) 查询为什么是期望复杂度而非严格最坏复杂度？
  3. 若值域固定为 0 到 20000，能否用位图替代 HashSet？代价是什么？
  4. 若要求保留最后一次出现，应怎样调整扫描方向或计数方式？

class Solution {
    public ListNode removeDuplicateNodes(ListNode head) {
        if (head == null) {
            return null;
        }

        Set<Integer> seen = new HashSet<>();
        seen.add(head.val);
        ListNode current = head;

        while (current.next != null) {
            if (seen.contains(current.next.val)) {
                current.next = current.next.next;
            } else {
                seen.add(current.next.val);
                current = current.next;
            }
        }
        return head;
    }
}
