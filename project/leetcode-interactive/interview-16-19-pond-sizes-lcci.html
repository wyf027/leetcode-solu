Core Insight

核心洞察：每片水域只入栈一次

1. 扫描起点

从左到右、从上到下扫描矩阵。只有遇到尚未访问的 0，才开启一次新的池塘勘测。

2. 八向洪泛

用栈扩张当前连通块，枚举 dr, dc ∈ {-1,0,1} 的八种非零位移；发现新水域时立刻标记，避免重复入栈。

3. 汇总排序

每完成一次洪泛，就记录该池塘格数。扫描结束后统一升序排序，即得到答案。

Full Process

完整过程

  1. 建立访问矩阵与答案数组

    访问矩阵防止同一水域被重复统计；答案数组保存每个池塘的大小。

  2. 找到一个尚未访问的水域格

    它一定属于一个此前未统计的池塘。先标记再压栈，计数器清零。

  3. 迭代弹栈并检查八邻域

    每弹出一个格子，池塘大小加一；合法、为 0 且未访问的邻居立即标记并入栈。

  4. 栈空即完成一个池塘

    记录计数，继续扫描剩余矩阵。所有水域最多只访问一次。

  5. 按升序整理结果

    池塘数量记作 k，最后排序成本为 O(k log k)。

Complexity

复杂度

时间复杂度
O(mn + k log k)：扫描与洪泛覆盖每格一次，最后排序 k 个池塘。
空间复杂度
O(mn)：访问矩阵和迭代栈在最坏情况下都可与矩阵同阶。

Boundaries

边界清单

  • 矩阵没有 0：返回空数组。
  • 矩阵全是 0：只有一个大小为 m × n 的池塘。
  • 只有对角线相连：仍然属于同一池塘。
  • 多个池塘大小相同：答案保留重复值。
  • 1000 × 1000 大矩阵：优先迭代写法，避免递归栈溢出。

Trade-offs

替代方案取舍

方案 优点 代价 / 风险 面试建议
迭代 DFS（主线） 逻辑直接；不依赖递归深度；栈中状态容易调试。 需显式维护栈。 约束达到 1000 × 1000 时最稳妥。
递归 DFS 代码最短，递归定义贴合连通块。 大池塘可能触发调用栈溢出。 先说明栈风险，再决定是否采用。
BFS 同样不会递归溢出；层序扩张直观。 需要队列与头指针。 完全可行，复杂度与迭代 DFS 等价。
并查集 适合动态连通或多轮查询。 本题一次静态扫描明显更复杂。 作为扩展讨论，不作为首选实现。

class Solution {
    public int[] pondSizes(int[][] land) {
        int rows = land.length;
        int cols = land[0].length;
        boolean[][] visited = new boolean[rows][cols];
        java.util.List<Integer> sizes = new java.util.ArrayList<>();
        int[] directions = {-1, 0, 1};

        for (int row = 0; row < rows; row++) {
            for (int col = 0; col < cols; col++) {
                if (land[row][col] != 0 || visited[row][col]) {
                    continue;
                }

                int size = 0;
                java.util.ArrayDeque<int[]> stack = new java.util.ArrayDeque<>();
                stack.push(new int[] {row, col});
                visited[row][col] = true;

                while (!stack.isEmpty()) {
                    int[] cell = stack.pop();
                    size++;

                    for (int dr : directions) {
                        for (int dc : directions) {
                            if (dr == 0 && dc == 0) continue;
                            int nextRow = cell[0] + dr;
                            int nextCol = cell[1] + dc;
                            if (nextRow < 0 || nextRow >= rows ||
                                nextCol < 0 || nextCol >= cols ||
                                visited[nextRow][nextCol] ||
                                land[nextRow][nextCol] != 0) {
                                continue;
                            }
                            visited[nextRow][nextCol] = true;
                            stack.push(new int[] {nextRow, nextCol});
                        }
                    }
                }
                sizes.add(size);
            }
        }

        java.util.Collections.sort(sizes);
        return sizes.stream().mapToInt(Integer::intValue).toArray();
    }
}

var pondSizes = function (land) {
  const rows = land.length;
  const cols = land[0].length;
  const visited = Array.from({ length: rows }, () => Array(cols).fill(false));
  const sizes = [];

  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < cols; col++) {
      if (land[row][col] !== 0 || visited[row][col]) continue;

      let size = 0;
      const stack = [[row, col]];
      visited[row][col] = true;

      while (stack.length > 0) {
        const [currentRow, currentCol] = stack.pop();
        size++;

        for (let dr = -1; dr <= 1; dr++) {
          for (let dc = -1; dc <= 1; dc++) {
            if (dr === 0 && dc === 0) continue;
            const nextRow = currentRow + dr;
            const nextCol = currentCol + dc;
            if (
              nextRow < 0 ||
              nextRow >= rows ||
              nextCol < 0 ||
              nextCol >= cols ||
              visited[nextRow][nextCol] ||
              land[nextRow][nextCol] !== 0
            ) {
              continue;
            }
            visited[nextRow][nextCol] = true;
            stack.push([nextRow, nextCol]);
          }
        }
      }
      sizes.push(size);
    }
  }

  return sizes.sort((a, b) => a - b);
};
from typing import List


class Solution:
    def pondSizes(self, land: List[List[int]]) -> List[int]:
        rows, cols = len(land), len(land[0])
        visited = [[False] * cols for _ in range(rows)]
        sizes = []

        for row in range(rows):
            for col in range(cols):
                if land[row][col] != 0 or visited[row][col]:
                    continue

                size = 0
                stack = [(row, col)]
                visited[row][col] = True

                while stack:
                    current_row, current_col = stack.pop()
                    size += 1

                    for dr in (-1, 0, 1):
                        for dc in (-1, 0, 1):
                            if dr == 0 and dc == 0:
                                continue
                            next_row = current_row + dr
                            next_col = current_col + dc
                            if (
                                0 <= next_row < rows
                                and 0 <= next_col < cols
                                and not visited[next_row][next_col]
                                and land[next_row][next_col] == 0
                            ):
                                visited[next_row][next_col] = True
                                stack.append((next_row, next_col))

                sizes.append(size)

        sizes.sort()
        return sizes
class Solution {
public:
    vector<int> pondSizes(vector<vector<int>>& land) {
        int rows = static_cast<int>(land.size());
        int cols = static_cast<int>(land[0].size());
        vector<vector<bool>> visited(rows, vector<bool>(cols, false));
        vector<int> sizes;

        for (int row = 0; row < rows; ++row) {
            for (int col = 0; col < cols; ++col) {
                if (land[row][col] != 0 || visited[row][col]) continue;

                int size = 0;
                vector<pair<int, int>> stack = {{row, col}};
                visited[row][col] = true;

                while (!stack.empty()) {
                    auto [currentRow, currentCol] = stack.back();
                    stack.pop_back();
                    ++size;

                    for (int dr = -1; dr <= 1; ++dr) {
                        for (int dc = -1; dc <= 1; ++dc) {
                            if (dr == 0 && dc == 0) continue;
                            int nextRow = currentRow + dr;
                            int nextCol = currentCol + dc;
                            if (nextRow < 0 || nextRow >= rows ||
                                nextCol < 0 || nextCol >= cols ||
                                visited[nextRow][nextCol] ||
                                land[nextRow][nextCol] != 0) {
                                continue;
                            }
                            visited[nextRow][nextCol] = true;
                            stack.push_back({nextRow, nextCol});
                        }
                    }
                }
                sizes.push_back(size);
            }
        }

        sort(sizes.begin(), sizes.end());
        return sizes;
    }
};

Interview Follow-ups

面试追问

  • 能否原地标记？ 若允许修改输入，可把访问过的 0 改为非零，省去 visited 矩阵。
  • 若只算四方向？ 把方向集合改成上、下、左、右即可，框架不变。
  • 若地形持续变化？ 静态洪泛不再合适，可讨论并查集或离线动态连通。
  • 若无需排序？ 可直接返回发现顺序，省去 O(k log k)。

Common Mistakes

常见错误

  • 只检查四个方向，漏掉对角线相连的水域。
  • 弹栈时才标记，导致同一水域被多个邻居重复压栈。
  • 把正数高度也纳入池塘，实际只有 0 是水域。
  • 忘记最终升序排序，或用 JavaScript 默认字典序排序。
  • 大矩阵直接递归，未考虑语言调用栈上限。
