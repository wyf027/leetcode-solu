统计农场中
肥沃金字塔的数目

Count Fertile Pyramids in a Land

一片农田，两种朝向。每一层都必须完整，每一种高度都算一种区域。

■ ■ ■ ■ ■ ■ ■ ■ ■

01 / PROBLEM

先认识这片农田

给定从 0 开始编号的 m × n 二进制矩阵 grid。1 表示肥沃，0 表示贫瘠；网格外一律视为贫瘠。请统计所有由肥沃格子组成的实心金字塔和倒金字塔，返回两者的总数。

正向：顶端在上，逐层向下展开

顶端 (r,c)、高度 h ≥ 2。第 k 层（0 ≤ k < h）占据第 r+k 行的 c-k … c+k 列。

倒向：顶端在下，逐层向上展开

顶端 (r,c)、高度 h ≥ 2。第 k 层占据第 r-k 行的 c-k … c+k 列。

每层宽度为 1、3、5、…，区域内部也必须全为 1。一个格子不计数；不同顶端、高度或朝向对应不同区域，区域之间可以重叠。

参数与约束

  • m == grid.length，n == grid[i].length。
  • 1 ≤ m,n ≤ 1000。
  • 1 ≤ m × n ≤ 10⁵。
  • grid[i][j] ∈ {0,1}，所有行长度相同。
  • 函数：countPyramids(grid)；返回整数。

用最大高度，一次计入所有较小金字塔

定义 H[r][c] 为某一朝向下，以 (r,c) 为顶端的最大肥沃金字塔高度。贫瘠格高度是 0；肥沃单格高度至少是 1，虽然它本身不计入答案。最大高度为 H 时，高度 2、3、…、H 均合法，所以这个顶端贡献 max(0,H−1) 个区域。

三个子金字塔把下一层填满

正向金字塔依赖下一行左、中、右三个顶端。三者能支持的最小高度，决定当前金字塔还能向下延伸多少层。使用三个子状态能自然排除“底部中间有洞”的情况。

grid[r][c] = 0 ⇒ H[r][c] = 0
grid[r][c] = 1 ⇒ H[r][c] = 1 + min(H[r+1][c−1], H[r+1][c], H[r+1][c+1])

边界外状态为 0。倒向把 r+1 换成 r−1。正向自底向上计算，倒向自顶向下计算。

完整过程

  1. 准备长度为 n 的 prev 数组，全 0 表示网格外一行。
  2. 自最后一行向上扫描。每行新建全 0 的 cur，肥沃格取 1 加三个相邻 prev 状态的最小值，边列只能取 1。
  3. 对每个肥沃格累加 cur[c]−1，行尾令 prev=cur。
  4. 重新清空 prev，自第一行向下扫描，计算倒金字塔并继续累加。
  5. 返回总数；不需要修改输入矩阵，也不需要逐个存储金字塔。

例如全 1 的三行五列：正向底行高度为 [1,1,1,1,1]，中间行为 [1,2,2,2,1]，顶行为 [1,2,3,2,1]，贡献为 0+3+4=7。倒向对称得到 7，总计 14。高度 3 的顶端贡献 2，包含高度 2 和高度 3 两种区域。

正确性证明

高度递推。对扫描顺序归纳。边界外或贫瘠格高度为 0，肥沃边界格高度为 1，基础成立。若三个子金字塔都至少高 t，则它们在距子顶端 k 层的区间并集是连续的 [c−1−k, c+1+k]，恰好覆盖当前金字塔第 k+1 层。加上当前肥沃格，可构成高度 t+1。

反过来，若当前存在高度 h≥2 的完整金字塔，其下一行左、中、右三个位置都包含一个高度 h−1 的子金字塔。因此 h 不可能超过三个子高度最小值加 1。结合充分性，递推给出的正是最大高度。倒向只改变行方向，证明相同。

计数不重不漏。固定顶端和朝向，合法高度恰好是 2 到 H，所以贡献 H−1。每个合法区域都有唯一的顶端、朝向和高度，高度至少为 2 时两种朝向对应的形状不同。遍历两种朝向的所有顶端恰好统计全部区域一次。

复杂度与边界

  • 时间 O(mn)：两次扫描，每格仅常数次计算。
  • 额外空间 O(n)：只保留相邻两行状态。教学演示为了回放保存各步矩阵，不代表提交代码的空间开销。
  • m=1 或 n<3 时不存在合法区域；全 0 为 0，单个 1 也为 0。
  • 边列无法横向扩展；中间的 0 会压低相关状态。两次扫描之间必须清空 prev。
  • 高度不超过 min(m,⌊(n+1)/2⌋)，且 n≤1000，所以每顶端每朝向贡献≤499，总数≤2×10⁵×499=99,800,000；Java/C++ 的 32 位 int 足够，JavaScript Number 也精确。

替代方案与取舍

可以先计算每行前缀和，再枚举顶端、方向和高度，每加一层用区间和判断是否全 1；一旦遇到贫瘠格便停止。时间最坏 O(mn·min(m,n))，适合理解定义，但在本题规模下优先选线性动态规划。完整二维 DP 同为 O(mn) 时间，空间 O(mn)，便于还原某个区域；仅计数时滚动数组更省空间。

常见错误

  • 只检查轮廓，忽略内部格子也必须肥沃。
  • 只取左、右子状态却不检查中间格：[[0,1,0],[1,0,1]] 会被误判。
  • 累加 H，把不计数的单格也统计进去；贫瘠格若直接加 H−1 还会产生负数。
  • 只数每个顶端的最大金字塔，漏掉较小高度。
  • 扫描方向与依赖相反，或原地更新 prev 导致同一行的新状态污染后续计算。

面试追问

  • 只求最大高度？把计数累加改为维护全局最大值；若要求必须是合法区域，最大值<2 时返回无合法区域。
  • 能只依赖两个对角状态吗？可以，但必须额外检查相邻行中心格为 1；三状态写法让这个条件包含在最小值中，证明更直观。
  • 要列出所有区域？为每个 H≥2 的顶端输出高度 2…H 的三元组，额外时间至少与输出数量成正比。
  • 频繁翻转地块后求答案？一个地块可能影响许多顶端，简单局部更新未必高效。需结合查询规模讨论重算或增量依赖传播。

四语言完整实现

沿用官方 countPyramids 签名。以下均为可提交算法实现，尚未执行验证；Python 使用 Python3。

JavaScript

/**
 * @param {number[][]} grid
 * @return {number}
 */
var countPyramids = function(grid) {
    const m = grid.length, n = grid[0].length;
    let answer = 0;
    for (const step of [-1, 1]) {
        let prev = Array(n).fill(0);
        for (let r = step === -1 ? m - 1 : 0;
             r >= 0 && r < m; r += step) {
            const cur = Array(n).fill(0);
            for (let c = 0; c < n; c++) {
                if (grid[r][c] === 0) continue;
                cur[c] = 1;
                if (c > 0 && c + 1 < n) {
                    cur[c] += Math.min(prev[c - 1], prev[c], prev[c + 1]);
                }
                answer += cur[c] - 1;
            }
            prev = cur;
        }
    }
    return answer;
};

Python

from typing import List

class Solution:
    def countPyramids(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        answer = 0
        for step in (-1, 1):
            prev = [0] * n
            rows = range(m - 1, -1, -1) if step == -1 else range(m)
            for r in rows:
                cur = [0] * n
                for c in range(n):
                    if grid[r][c] == 0:
                        continue
                    cur[c] = 1
                    if 0 < c < n - 1:
                        cur[c] += min(prev[c - 1], prev[c], prev[c + 1])
                    answer += cur[c] - 1
                prev = cur
        return answer

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int countPyramids(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int answer = 0;
        for (int step : {-1, 1}) {
            vector<int> prev(n, 0);
            for (int r = step == -1 ? m - 1 : 0;
                 r >= 0 && r < m; r += step) {
                vector<int> cur(n, 0);
                for (int c = 0; c < n; ++c) {
                    if (grid[r][c] == 0) continue;
                    cur[c] = 1;
                    if (c > 0 && c + 1 < n) {
                        cur[c] += min({prev[c - 1], prev[c], prev[c + 1]});
                    }
                    answer += cur[c] - 1;
                }
                prev.swap(cur);
            }
        }
        return answer;
    }
};
