Merge BSTs to Create Single BST

让相同的叶与根相接。最终留下的，能否是一棵严格有序的树？

01 / 题目 · 先独立思考

给定数组 trees，其中存放 n 棵不同二叉搜索树的根节点，下标从 0 开始。每棵树只有 1～3 个节点，最多一层孩子；所有根的值互不相同。

一次操作选择不同下标 i、j：若 trees[i] 的某个叶节点的值等于 trees[j] 的根值，就用整棵 trees[j] 替换该叶，并从数组中移除 trees[j]。

如果能恰好进行 n−1 次操作，形成一棵有效 BST，则返回其根节点，否则返回 null。叶节点没有孩子；严格 BST 要求每个节点的整个左子树都比它小，整个右子树都比它大。

canMerge(trees: list<TreeNode>) → TreeNode | null
示例使用层序数组表示树；null 表示空孩子；空树输出 [] 对应返回 null。

完整约束

  • n == trees.length，1 ≤ n ≤ 5 × 10⁴。
  • 每棵输入树的节点数在 [1,3] 内。
  • 输入节点可以有孩子，但不存在孙节点。
  • 任意两棵输入树的根值不同。
  • 输入树全部为有效 BST。
  • 1 ≤ TreeNode.val ≤ 5 × 10⁴。

02 / 官方示例

示例 1 · 可以合并

输入：trees = [[2,1],[3,2,5],[5,4]]
输出：[3,2,5,1,null,4]

先选 i=1、j=0，把根 2 的树接到叶 2 上，得到 trees = [[3,2,5,1],[5,4]]；再选 i=0、j=1 接入根 5 的树，得到 trees = [[3,2,5,1,null,4]]，是有效 BST。

示例 2 · 接上不代表有序

输入：trees = [[5,3,8],[3,2,6]]
输出：[]（返回 null）

唯一操作是 i=0、j=1，形成 [5,3,8,2,6]。6 在 5 的左子树中却大于 5，结果非法。

示例 3 · 无连接点

输入：trees = [[5,4],[3]]
输出：[]（返回 null）

没有叶值等于另一棵树的根值，无法执行操作。

唯一根 + 叶节点嫁接 + 全局区间

核心洞察

被吸收的树，其根值必然出现在另一棵树的叶节点中。最终根值不能出现在任何非根叶中：叶只能被等值根替换，值不会消失，若与最终根重值就违反严格 BST。因此不在叶值集合中的根必须恰好只有一个。根值互异又使每个叶的可嫁接目标至多一棵，无需枚举顺序。

完整过程

  1. 建立根值到节点的 roots 映射，收集各树左右孩子值为叶集合。单节点树的根不计入叶集合。
  2. 找不在叶集合中的根，不是恰好一个就返回 null。
  3. 从 roots 删除最终根。显式栈存储 (节点, 下界, 上界)，初始区间为 (−∞,+∞)。
  4. 弹出节点，要求下界 < 值 < 上界。若当前节点是叶且 roots 有同值根，删除该映射并把目标根的孩子接到当前节点。保留等值叶对象与替换根在结构和值上等价。
  5. 右孩子携带 (当前值, 上界)，左孩子携带 (下界, 当前值) 入栈。先压右再压左。
  6. 全部遍历结束且 roots 为空才返回根，否则说明有未使用的树。

正确性

根的必要性：没有同值叶的根不能被吸收，只能成为最终根；最终根又不能在其他叶中重现，因此候选必须唯一。

嫁接的确定性：根值唯一，任何未使用的根只能接入同值叶。在有效严格 BST 中不会有多个同值位置，故有效结果中的接法是强制的。删除根表条目保证每棵树最多消费一次。

区间不变量：每个栈帧保存全部祖先给出的限制交集。左转收紧上界、右转收紧下界，严格区间检查确保所有后代都满足 BST 的全局顺序。

充分性与完整性：返回时所有嫁接都合法，全部节点满足祖先区间，根表耗尽。除最终根外 n−1 个根恰好被消费，对应 n−1 次操作，覆盖全部树。任何失败分别违反唯一根、强制结构的全局顺序或全树覆盖条件，因此无法构造有效结果。

边界与常见错误

  • n=1 时无需操作；不要把单节点树根放入非根叶集合。
  • 吸收单节点树即使不增加孩子，也要删除根表条目。
  • 只比较父子会漏掉示例 2 中的 6 与祖先 5 冲突。
  • 存在唯一候选根仍可能有孤立环，必须检查剩余 roots。
  • 严格 BST 不允许重复值，等于上下界也必须失败。叶集合去重不等于消除了实际重复节点。
  • 必须在叶上嫁接，不可覆盖已有内部子树。
  • 最终树可能退化为 O(n) 高的链；四份实现均使用显式栈。
  • 实现会原地修改孩子引用，失败也可能已有部分修改。需要失败回滚时先复制输入或记录修改日志。

复杂度

总输入节点数 M ≤ 3n，每个根最多消费一次，每个接入节点最多遍历一次。哈希操作按期望 O(1) 计，时间 O(M+n)=O(n)，额外空间 O(n)，包含映射、集合和显式栈。哈希碰撞的极端最坏情况不包含在线性期望界中。

替代方案

先嫁接再用严格递增的中序遍历判定 BST 也可行，但构造阶段须控制重复消费和终止，并检查所有树已使用。递归区间 DFS 更短但有深链栈溢出风险。使用值域数组替代哈希可得到 O(n+V) 时间和空间，其中 V=50000。枚举操作顺序没有必要。

面试追问

  • 允许更深的输入树？遍历收集真正的非根叶，整体仍按总节点数分析。
  • 根值可重复？单值到单根的映射失效，不能直接使用此确定性证明。
  • 如何报告失败原因？记录候选根数量、超界节点及区间、未消费的根。
  • 能否排序全部节点再重建？不能，题目限制操作为等值叶与根的替换，不允许任意重排。

/**
 * TreeNode 由平台提供，含 val、left、right。
 * @param {TreeNode[]} trees
 * @return {TreeNode|null}
 */
var canMerge = function(trees) {
    const roots = new Map(), leaves = new Set();
    for (const t of trees) {
        roots.set(t.val, t);
        if (t.left) leaves.add(t.left.val);
        if (t.right) leaves.add(t.right.val);
    }
    const candidates = trees.filter(t => !leaves.has(t.val));
    if (candidates.length !== 1) return null;
    const root = candidates[0];
    roots.delete(root.val);
    const stack = [[root, -Infinity, Infinity]];
    while (stack.length) {
        const [node, low, high] = stack.pop();
        if (node.val <= low || node.val >= high) return null;
        if (!node.left && !node.right && roots.has(node.val)) {
            const other = roots.get(node.val);
            roots.delete(node.val);
            node.left = other.left;
            node.right = other.right;
        }
        if (node.right) stack.push([node.right, node.val, high]);
        if (node.left) stack.push([node.left, low, node.val]);
    }
    return roots.size === 0 ? root : null;
};

import java.util.*;

// TreeNode 由平台提供：int val; TreeNode left, right;
class Solution {
    private static class Frame {
        TreeNode node;
        long low, high;
        Frame(TreeNode node, long low, long high) {
            this.node = node;
            this.low = low;
            this.high = high;
        }
    }
    public TreeNode canMerge(List<TreeNode> trees) {
        Map<Integer, TreeNode> roots = new HashMap<>();
        Set<Integer> leaves = new HashSet<>();
        for (TreeNode t : trees) {
            roots.put(t.val, t);
            if (t.left != null) leaves.add(t.left.val);
            if (t.right != null) leaves.add(t.right.val);
        }
        TreeNode root = null;
        for (TreeNode t : trees) {
            if (!leaves.contains(t.val)) {
                if (root != null) return null;
                root = t;
            }
        }
        if (root == null) return null;
        roots.remove(root.val);
        Deque<Frame> stack = new ArrayDeque<>();
        stack.push(new Frame(root, Long.MIN_VALUE, Long.MAX_VALUE));
        while (!stack.isEmpty()) {
            Frame f = stack.pop();
            TreeNode node = f.node;
            if (node.val <= f.low || node.val >= f.high) return null;
            if (node.left == null && node.right == null) {
                TreeNode other = roots.remove(node.val);
                if (other != null) {
                    node.left = other.left;
                    node.right = other.right;
                }
            }
            if (node.right != null)
                stack.push(new Frame(node.right, node.val, f.high));
            if (node.left != null)
                stack.push(new Frame(node.left, f.low, node.val));
        }
        return roots.isEmpty() ? root : null;
    }
}

from typing import List, Optional

# TreeNode 由平台提供，含 val、left、right。
class Solution:
    def canMerge(self, trees: List[TreeNode]) -> Optional[TreeNode]:
        roots = {t.val: t for t in trees}
        leaves = set()
        for t in trees:
            if t.left:
                leaves.add(t.left.val)
            if t.right:
                leaves.add(t.right.val)
        candidates = [t for t in trees if t.val not in leaves]
        if len(candidates) != 1:
            return None
        root = candidates[0]
        del roots[root.val]
        stack = [(root, float('-inf'), float('inf'))]
        while stack:
            node, low, high = stack.pop()
            if not low < node.val < high:
                return None
            if not node.left and not node.right and node.val in roots:
                other = roots.pop(node.val)
                node.left, node.right = other.left, other.right
            if node.right:
                stack.append((node.right, node.val, high))
            if node.left:
                stack.append((node.left, low, node.val))
        return root if not roots else None

#include <vector>
#include <unordered_map>
#include <unordered_set>
#include <tuple>
#include <climits>
using namespace std;

// TreeNode 由平台提供：int val; TreeNode *left, *right;
class Solution {
public:
    TreeNode* canMerge(vector<TreeNode*>& trees) {
        unordered_map<int, TreeNode*> roots;
        unordered_set<int> leaves;
        for (TreeNode* t : trees) {
            roots[t->val] = t;
            if (t->left) leaves.insert(t->left->val);
            if (t->right) leaves.insert(t->right->val);
        }
        TreeNode* root = nullptr;
        for (TreeNode* t : trees) {
            if (!leaves.count(t->val)) {
                if (root) return nullptr;
                root = t;
            }
        }
        if (!root) return nullptr;
        roots.erase(root->val);
        vector<tuple<TreeNode*, long long, long long>> stack;
        stack.emplace_back(root, LLONG_MIN, LLONG_MAX);
        while (!stack.empty()) {
            auto [node, low, high] = stack.back();
            stack.pop_back();
            if (node->val <= low || node->val >= high) return nullptr;
            if (!node->left && !node->right) {
                auto it = roots.find(node->val);
                if (it != roots.end()) {
                    TreeNode* other = it->second;
                    roots.erase(it);
                    node->left = other->left;
                    node->right = other->right;
                }
            }
            if (node->right) stack.emplace_back(node->right, node->val, high);
            if (node->left) stack.emplace_back(node->left, low, node->val);
        }
        return roots.empty() ? root : nullptr;
    }
};
