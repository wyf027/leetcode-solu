LEETCODE 242 · EASY · COUNTING

有效的字母异位词

Valid Anagram：两串中每个字母的出现次数完全相同，顺序可以不同。使用固定 26 格频次数组在线抵消。

26 格计数一增一减O(n) 时间

题意

所有字符频率都要对账为零

给定两条只含小写英文字母的字符串 s 与 t。若 t 是 s 的字母异位词，返回 true，否则 false。

输入：s = "anagram"，t = "nagaram"

输出：true

字符串完整保留成对直引号；空格若出现会写作 ␠。

核心洞察

s 记账 +1，t 记账 −1

字符串长度不同立刻失败。否则扫 s 为每个字母加一，再扫 t 减一。所有余额归零恰好等价于两串具有相同的多重集合。

Unicode 追问：26 格数组只适用于小写英文；通用字符应改为哈希表，按 code point 而非 UTF-16 code unit 处理。

题解：频率抵消

长度相同后，用 count[c - 'a']++ 记录 s，再用 -- 抵消 t。检查数组每项为 0。固定字母表大小为 26，额外空间是 O(1)。

完整过程

  1. 若长度不同，返回 false。
  2. 扫描 s：对应计数加一。
  3. 扫描 t：对应计数减一。
  4. 任一余额非零则 false，否则 true。

复杂度与边界

时间 O(n)，英文字母数组空间 O(1)。空串不在本题约束内，但算法仍会返回 true；长度不同和重复次数不同应立刻区分。

替代方案

排序后比较也正确，代码短但要 O(n log n)。哈希表适配 Unicode，代价是 O(k) 额外空间。小写英文下计数数组最快。

常见错误 / 追问

忘记长度检查或只检查总字符数都不够；数组索引必须映射 a..z。追问 Unicode 时应使用 Map，不可假设 26 格。
