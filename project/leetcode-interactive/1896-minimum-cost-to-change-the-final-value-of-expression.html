1896. 反转表达式值的最少操作次数

Minimum Cost to Change the Final Value of Expression

从字符修改出发，探索布尔表达式的反转代价。

题意与规则

给定有效布尔表达式字符串 expression，返回使最终值从 0 变为 1 或从 1 变为 0 的最少操作次数。每次只能改一个字符：0 ↔ 1，或 & ↔ |。括号不能修改。

括号优先；& 与 | 优先级相同，同层从左向右计算。

参数：expression: string；返回：integer。

  • 1 ≤ expression.length ≤ 10⁵。
  • 只包含 0、1、&、|、(、)。
  • 表达式有效，括号全部匹配，无空括号。

官方题目 · 根据本地官方元数据转述。

官方示例

示例 1

输入：expression = "1&(0|1)"
输出：1

把括号里的 | 改成 &，得到 1&(0&1)，最终值变成 0。

示例 2

输入：expression = "(0&0)&(0&0&0)"
输出：3

改成 (0|1)|(0&0&0)：左组改两处，连接两组的运算符改一处，最终值变成 1。

示例 3

输入：expression = "(0|(1|0&1))"
输出：1

把内层开头的 1 改成 0，得到 (0|(0|0&1))，最终值变成 0。

先想一想

局部看起来容易修改的字符，是否总能影响整个表达式？准备好后，展开状态实验与完整解法。

题解 · 双目标代价与显式栈

核心洞察

对每段表达式保存 d[0]、d[1]：让它变成 0、1 的最少修改次数。数字 0 的状态为 [0,1]，数字 1 为 [1,0]。原值对应代价恰好为 0，另一个就是反转代价。

合并左右状态 A、B：枚举最终运算符 q∈{&,|} 和左右目标 x,y∈{0,1}，令 z=x q y，更新 D[z]=min(D[z],A[x]+B[y]+[q≠原运算符])。总共只有 8 个候选。

完整过程

  1. 数字入状态栈；左括号入运算符栈，作为归约屏障。
  2. 遇新运算符，先归约栈顶直到左括号或栈空，再压入新符号，保证同优先级左结合。
  3. 遇右括号，归约到对应左括号，然后弹出左括号。
  4. 扫描结束，归约所有剩余运算符。最终状态中非零的代价就是答案。

示例 1：0|1 合并为 [1,0]，再和左边数字 1 的 [1,0] 用 & 合并，得到 [1,0]，因此答案是 1。

正确性

对表达式结构归纳。数字的两个代价显然最优。假设左右状态最优，任何合法修改方案必然确定一个最终运算符与两个子表达式的最终值，属于枚举的 8 种情况之一。左右子串和运算符互不重叠，代价可相加，每个候选也能由对应的最优子方案实现。因此取最小值既不漏解，也不会低估最优代价。双栈按括号和左结合顺序归约，构造的结构符合题意，最终相反目标的代价即为所求。

边界与复杂度

单字符答案为 1；额外括号不增加修改代价。长运算链必须左结合；深括号采用显式栈避免递归溢出。每个字符进出栈至多一次，单次合并枚举 8 项，时间 O(n)，最坏辅助空间 O(n)。

替代方案

表达式树加后序动态规划也可行，但需存储树节点。递归下降需防止 10⁵ 层导致调用栈溢出。也可存“原值 + 反转代价”，但分类讨论更易出错。暴力枚举字符修改需要指数级时间。

常见错误

  • 沿用宿主语言 & 高于 | 的默认优先级。
  • 只考虑改数字，漏掉运算符修改。
  • 只存当前值，丢失改变子表达式的代价。
  • 忘记右操作数先出栈，或者越过左括号归约。
  • 允许修改括号，改变了题目范围。

面试追问

修改成本不同时怎么办？替换叶子成本与运算符替换成本。要返回具体修改位置？保存每个状态的最优候选并回溯。增加异或运算？扩展候选运算符和真值表，同时明确解析优先级。

Java

import java.util.ArrayDeque;
import java.util.Deque;
class Solution {
    private void reduce(Deque<int[]> v, Deque<Character> ops) {
        int[] b = v.pop(), a = v.pop();
        char op = ops.pop();
        int[] d = {1000000000, 1000000000};
        for (char q : new char[]{'&', '|'})
            for (int x = 0; x < 2; x++)
                for (int y = 0; y < 2; y++) {
                    int z = q == '&' ? (x & y) : (x | y);
                    d[z] = Math.min(d[z], a[x] + b[y] + (q == op ? 0 : 1));
                }
        v.push(d);
    }
    public int minOperationsToFlip(String expression) {
        Deque<int[]> v = new ArrayDeque<>();
        Deque<Character> ops = new ArrayDeque<>();
        for (char c : expression.toCharArray()) {
            if (c == '0' || c == '1')
                v.push(c == '0' ? new int[]{0, 1} : new int[]{1, 0});
            else if (c == '(') ops.push(c);
            else if (c == ')') {
                while (ops.peek() != '(') reduce(v, ops);
                ops.pop();
            } else {
                while (!ops.isEmpty() && ops.peek() != '(') reduce(v, ops);
                ops.push(c);
            }
        }
        while (!ops.isEmpty()) reduce(v, ops);
        int[] d = v.pop();
        return d[0] == 0 ? d[1] : d[0];
    }
}

JavaScript

var minOperationsToFlip = function(expression) {
    const v = [], ops = [];
    function reduce() {
        const b = v.pop(), a = v.pop(), op = ops.pop();
        const d = [Infinity, Infinity];
        for (const q of ['&', '|'])
            for (let x = 0; x < 2; x++)
                for (let y = 0; y < 2; y++) {
                    const z = q === '&' ? x & y : x | y;
                    d[z] = Math.min(d[z], a[x] + b[y] + Number(q !== op));
                }
        v.push(d);
    }
    for (const c of expression) {
        if (c === '0' || c === '1') v.push(c === '0' ? [0, 1] : [1, 0]);
        else if (c === '(') ops.push(c);
        else if (c === ')') {
            while (ops[ops.length - 1] !== '(') reduce();
            ops.pop();
        } else {
            while (ops.length && ops[ops.length - 1] !== '(') reduce();
            ops.push(c);
        }
    }
    while (ops.length) reduce();
    return v[0][0] === 0 ? v[0][1] : v[0][0];
};

Python

class Solution:
    def minOperationsToFlip(self, expression: str) -> int:
        v, ops = [], []
        def reduce():
            b, a, op = v.pop(), v.pop(), ops.pop()
            d = [float('inf'), float('inf')]
            for q in ('&', '|'):
                for x in range(2):
                    for y in range(2):
                        z = (x & y) if q == '&' else (x | y)
                        d[z] = min(d[z], a[x] + b[y] + (q != op))
            v.append(d)
        for c in expression:
            if c in '01':
                v.append([0, 1] if c == '0' else [1, 0])
            elif c == '(':
                ops.append(c)
            elif c == ')':
                while ops[-1] != '(':
                    reduce()
                ops.pop()
            else:
                while ops and ops[-1] != '(':
                    reduce()
                ops.append(c)
        while ops:
            reduce()
        return v[0][1] if v[0][0] == 0 else v[0][0]

C++

#include <array>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;
class Solution {
public:
    int minOperationsToFlip(string expression) {
        vector<array<int, 2>> v;
        vector<char> ops;
        auto reduce = [&]() {
            auto b = v.back(); v.pop_back();
            auto a = v.back(); v.pop_back();
            char op = ops.back(); ops.pop_back();
            array<int, 2> d{1000000000, 1000000000};
            for (char q : {'&', '|'})
                for (int x = 0; x < 2; ++x)
                    for (int y = 0; y < 2; ++y) {
                        int z = q == '&' ? (x & y) : (x | y);
                        d[z] = min(d[z], a[x] + b[y] + (q != op));
                    }
            v.push_back(d);
        };
        for (char c : expression) {
            if (c == '0' || c == '1')
                v.push_back(c == '0' ? array<int, 2>{0, 1} : array<int, 2>{1, 0});
            else if (c == '(') ops.push_back(c);
            else if (c == ')') {
                while (ops.back() != '(') reduce();
                ops.pop_back();
            } else {
                while (!ops.empty() && ops.back() != '(') reduce();
                ops.push_back(c);
            }
        }
        while (!ops.empty()) reduce();
        return v[0][0] == 0 ? v[0][1] : v[0][0];
    }
};
