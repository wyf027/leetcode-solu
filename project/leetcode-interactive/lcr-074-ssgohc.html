合并区间

排序后线性扫描：重叠即扩展当前区间，否则写入结果。

题意

给定若干区间，合并所有重叠区间并返回不重叠的结果。

示例

[[1,3],[2,6],[8,10],[15,18]] → [[1,6],[8,10],[15,18]]

约束

1 ≤ intervals.length ≤ 10⁴；端点在 ±10⁴ 范围。

分步交互

准备开始。

点击下一步观察排序和合并。

洞察与过程

先按左端点排序。维护结果最后一个区间：新左端点不大于其右端点便更新右端点最大值，否则新开区间。

边界与复杂度

单区间、相邻端点、嵌套区间。排序 O(n log n)，扫描 O(n)，结果外空间通常 O(n)。

替代与追问

若输入已排序可省排序；追问插入新区间、会议室数量与区间是否相交。

常见错误

  • 没有排序便直接扫描。
  • 把相邻/重叠的判定写反。
  • 更新时覆盖右端点而非取最大值。

四语言代码

Java

class Solution { public int[][] merge(int[][] a){Arrays.sort(a,(x,y)->x[0]-y[0]);List<int[]> r=new ArrayList<>();for(int[] x:a)if(r.isEmpty()||r.get(r.size()-1)[1]<x[0])r.add(x);else r.get(r.size()-1)[1]=Math.max(r.get(r.size()-1)[1],x[1]);return r.toArray(new int[0][]);} }

class Solution:
 def merge(self, a):
  a.sort(); r=[]
  for x in a:
   if not r or r[-1][1]<x[0]: r.append(x)

  return r
