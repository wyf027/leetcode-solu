最长回文子串

回文像一束从中心向两侧同时发射的雷达：左右字符相同就继续扩散，一旦不同就停止。枚举所有中心，保留覆盖范围最大的那束光。

MISSION 01

题意转述

给定一个只含英文字母和数字的字符串，返回其中最长的连续回文子串。回文从左往右与从右往左读完全相同；注意题目要的是 子串，字符必须连续，不是可以跳着选的子序列。

EXAMPLE A

"babad" → "bab"

"aba" 也正确。

EXAMPLE B

"cbbd" → "bb"

中心在两个 b 的缝隙。

约束：1 ≤ s.length ≤ 1000，字符串只包含英文字母与数字。

CORE INSIGHT

n 个字符中心 + n−1 个缝隙中心

奇

奇数长度：从 (i,i) 开始，例如 aba。

偶

偶数长度：从 (i,i+1) 开始，例如 abba。

两个分支必须都算；漏掉缝隙中心，是这题最常见的面试失误。

MISSION 02

完整解题过程

  1. 1

    枚举 i：每个位置都可能是回文正中心，也可能是偶数回文左中心。

  2. 2

    分别调用 expand(i,i) 与 expand(i,i+1)。

  3. 3

    向外扩展：只要 L、R 未越界且 s[L] == s[R]，就令 L--、R++。

  4. 4

    循环停止时指针已经多走一步，所以回文长度是 R-L-1。

  5. 5

    若长度刷新记录，统一计算 start=i-(len-1)/2 与 end=i+len/2。

INDEX FORMULA

一套公式兼容奇偶

odd: center i=5, len=3

start = 5 - (3-1)/2 = 4

end = 5 + 3/2 = 6

even: left-center i=1, len=2

start = 1 - (2-1)/2 = 1

end = 1 + 2/2 = 2

这里的除法是整数除法。奇偶不需要分支，是模板最值得记住的部分。

EDGE SCAN

边界情况

LENGTH 1

单字符

它本身就是答案；start/end 初始为 0 可自然覆盖。

ALL SAME

全部相同

如 aaaa，偶数与奇数扩展都会发生，最终覆盖整串。

NO PAIR

无更长回文

如 abc，任意单字符都正确；严格大于可稳定返回最先出现者。

BOUNDARY

中心靠近首尾

while 条件先检查下标，再访问字符，防止越界。

TIME

O(n²)

2n−1 个中心，每个最坏扩展 O(n)。

SPACE

O(1)

只维护边界与最佳区间，不建二维表。

TRADE-OFF

DP / Manacher

DP 同为 O(n²) 但空间 O(n²)；Manacher 可到 O(n)，模板更长且易写错。面试通常先交中心扩展。

class Solution {
    public String longestPalindrome(String s) {
        int start = 0, end = 0;

        for (int i = 0; i < s.length(); i++) {
            int odd = expand(s, i, i);
            int even = expand(s, i, i + 1);
            int len = Math.max(odd, even);

            if (len > end - start + 1) {
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }
        return s.substring(start, end + 1);
    }

    private int expand(String s, int left, int right) {
        while (left >= 0 && right < s.length()
                && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }
        return right - left - 1;
    }
}
var longestPalindrome = function (s) {
  let start = 0;
  let end = 0;

  function expand(left, right) {
    while (left >= 0 && right < s.length && s[left] === s[right]) {
      left--;
      right++;
    }
    return right - left - 1;
  }

  for (let i = 0; i < s.length; i++) {
    const len = Math.max(expand(i, i), expand(i, i + 1));
    if (len > end - start + 1) {
      start = i - Math.floor((len - 1) / 2);
      end = i + Math.floor(len / 2);
    }
  }
  return s.slice(start, end + 1);
};
class Solution:
    def longestPalindrome(self, s: str) -> str:
        start = end = 0

        def expand(left: int, right: int) -> int:
            while left >= 0 and right < len(s) and s[left] == s[right]:
                left -= 1
                right += 1
            return right - left - 1

        for i in range(len(s)):
            length = max(expand(i, i), expand(i, i + 1))
            if length > end - start + 1:
                start = i - (length - 1) // 2
                end = i + length // 2

        return s[start : end + 1]
class Solution {
public:
    string longestPalindrome(string s) {
        int start = 0, end = 0;

        for (int i = 0; i < s.size(); ++i) {
            int odd = expand(s, i, i);
            int even = expand(s, i, i + 1);
            int len = max(odd, even);

            if (len > end - start + 1) {
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }
        return s.substr(start, end - start + 1);
    }

private:
    int expand(const string& s, int left, int right) {
        while (left >= 0 && right < s.size() && s[left] == s[right]) {
            --left;
            ++right;
        }
        return right - left - 1;
    }
};

面试高频追问

为什么总共有 2n−1 个中心？

n 个字符位置形成奇数回文中心，相邻字符之间有 n−1 条缝形成偶数回文中心。

为什么停止后长度是 R−L−1？

while 退出时，L 与 R 已经分别越过合法回文边界一格；有效区间是 [L+1,R−1]，长度为 R−L−1。

如何做到 O(n)？

Manacher 算法利用当前最右回文与镜像位置复用半径，但实现复杂。若面试官追求最优再展开。

常见错误雷达

  • ❌ 只算 expand(i,i)：会漏掉 bb、abba 等所有偶数回文。
  • ❌ 返回 R−L+1：停止时已多扩一格，正确长度是 R−L−1。
  • ❌ 把子串当子序列：不能跳过中间字符，窗口必须连续。
  • ❌ 先访问再判界：循环条件必须先确认 left/right 在范围内。
  • ❌ 更新公式手写两套：奇偶分支越多越易错，统一用 len 公式。

60-SECOND RECAP

“我枚举每个位置 i，同时把 (i,i) 当奇数中心、(i,i+1) 当偶数中心。只要左右字符相同就继续扩展，退出时长度是 right-left-1。若刷新最大值，用 start=i-(len-1)/2、end=i+len/2 统一计算区间。时间 O(n²)，额外空间 O(1)。”
