Problem statement

把“重复”放进子序列

记 [s, n] 为将字符串 s 连续拼接 n 次得到的字符串。例如，["abc", 3] = "abcabcabc"。

如果从字符串 B 中删除若干字符（不改变其余字符的相对次序）后能得到字符串 A，就称 A 可以从 B 获得，也就是 A 是 B 的子序列。

给定字符串 s1、s2 和整数 n1、n2，令 str1 = [s1, n1]，str2 = [s2, n2]。求最大的整数 m，使得 [str2, m] 可以作为子序列从 str1 中获得。

返回值：一个整数 m。注意匹配可以跨越相邻的 s1 块，不要求落在同一块中。

约束

  • 1 ≤ s1.length, s2.length ≤ 100
  • s1 与 s2 仅含小写英文字母
  • 1 ≤ n1, n2 ≤ 106

Full solution

有限状态 + 循环跳跃

不构造最长可达一亿字符的 str1；只记录每读完一个 s1 块后的必要状态。

核心洞察

逐字符把 str1 与无限重复的 s2 做贪心子序列匹配。任何时刻，只需知道两件事：已经完整匹配了多少个 s2，以及下一次要匹配 s2 的哪个下标 cursor。

每读完一个完整 s1 块时，cursor 只有 |s2| 种取值。同一个 cursor 再次出现，意味着从这两个块边界出发，后续行为完全相同，中间形成可整体跳过的循环。

完整过程

  1. 令 cursor = 0、completed = 0，并记录初始状态 cursor 0 → (0 块, 0 个 s2)。
  2. 扫描一整个 s1：字符等于 s2[cursor] 时推进指针；走到 s2 末尾就把 completed 加一并将指针归零。
  3. 在块边界检查当前 cursor。若未见过，保存当前块数和 completed。
  4. 若见过相同 cursor，两次记录之差就是一个循环的块长与收益。用整数除法一次跳过尽可能多的完整循环。
  5. 直接扫描剩余不足一个循环的尾部块，最后返回 ⌊completed / n2⌋。

边界处理

  • 若 s2 中存在 s1 从未包含的字符，状态很快回到原处，循环收益为 0，答案自然为 0。
  • 匹配可以跨 s1 块，绝不能在每个块结束时重置 cursor。
  • n2 只在最终分组时使用；过程中统计的是完整 s2 的个数。
  • Java 与 C++ 用 64 位整数保存中间计数，避免乘法跳跃时溢出。

正确性证明

引理 1：顺序扫描 str1，每遇到当前所需的 s2[cursor] 就立刻匹配，会得到能作为子序列匹配的最多完整 s2 个数。因为更晚选择相同所需字符不会为后续匹配留下更多字符，交换到最早可选位置不会使结果变差。

引理 2：在两个 s1 块边界，若 cursor 相同，则从这两个边界起扫描任意相同数量的后续 s1 块，指针演化与新增完整 s2 数相同。后续转移只由当前 cursor 和固定字符串 s1、s2 决定。

定理：算法返回最大可行的 m。根据引理 1，未跳跃扫描得到最优的完整 s2 数；根据引理 2，循环跳跃与逐块扫描产生完全相同的状态和收益，因此不改变该最优计数。每个 str2 恰含 n2 个 s2，最终向下取整即为最大组数。

复杂度

设 L1 = |s1|、L2 = |s2|。循环出现前至多访问 L2 + 1 个块，跳跃后的尾部少于一个循环，故时间复杂度可写为 O(L1 · min(n1, 2L2 + 1))，常用简化为 O(L1 · L2)；哈希表最多保存 L2 个指针状态，空间复杂度为 O(L2)。

四语言完整代码

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int getMaxRepetitions(String s1, int n1, String s2, int n2) {
        int cursor = 0;
        long completed = 0;
        long block = 0;
        boolean cycleUsed = false;

        // cursor -> {已经扫描的 s1 块数, 已完成的 s2 数}
        Map<Integer, long[]> seen = new HashMap<>();
        seen.put(0, new long[]{0L, 0L});

        while (block < n1) {
            for (int i = 0; i < s1.length(); i++) {
                if (s1.charAt(i) == s2.charAt(cursor)) {
                    cursor++;
                    if (cursor == s2.length()) {
                        cursor = 0;
                        completed++;
                    }
                }
            }
            block++;

            if (!cycleUsed) {
                long[] previous = seen.get(cursor);
                if (previous == null) {
                    seen.put(cursor, new long[]{block, completed});
                } else {
                    long cycleBlocks = block - previous[0];
                    long cycleGain = completed - previous[1];
                    long repeat = (n1 - block) / cycleBlocks;
                    block += repeat * cycleBlocks;
                    completed += repeat * cycleGain;
                    cycleUsed = true;
                }
            }
        }

        return (int) (completed / n2);
    }
}

var getMaxRepetitions = function (s1, n1, s2, n2) {
    let cursor = 0;
    let completed = 0;
    let block = 0;
    let cycleUsed = false;

    // cursor -> [已经扫描的 s1 块数, 已完成的 s2 数]
    const seen = new Map();
    seen.set(0, [0, 0]);

    while (block < n1) {
        for (const char of s1) {
            if (char === s2[cursor]) {
                cursor++;
                if (cursor === s2.length) {
                    cursor = 0;
                    completed++;
                }
            }
        }
        block++;

        if (!cycleUsed) {
            if (!seen.has(cursor)) {
                seen.set(cursor, [block, completed]);
            } else {
                const [previousBlock, previousCompleted] = seen.get(cursor);
                const cycleBlocks = block - previousBlock;
                const cycleGain = completed - previousCompleted;
                const repeat = Math.floor((n1 - block) / cycleBlocks);
                block += repeat * cycleBlocks;
                completed += repeat * cycleGain;
                cycleUsed = true;
            }
        }
    }

    return Math.floor(completed / n2);
};

class Solution {
public:
    int getMaxRepetitions(string s1, int n1, string s2, int n2) {
        int cursor = 0;
        long long completed = 0;
        long long block = 0;
        bool cycleUsed = false;

        // cursor -> {已经扫描的 s1 块数, 已完成的 s2 数}
        unordered_map<int, pair<long long, long long>> seen;
        seen[0] = {0LL, 0LL};

        while (block < n1) {
            for (char c : s1) {
                if (c == s2[cursor]) {
                    ++cursor;
                    if (cursor == static_cast<int>(s2.size())) {
                        cursor = 0;
                        ++completed;
                    }
                }
            }
            ++block;

            if (!cycleUsed) {
                auto it = seen.find(cursor);
                if (it == seen.end()) {
                    seen[cursor] = {block, completed};
                } else {
                    long long cycleBlocks = block - it->second.first;
                    long long cycleGain = completed - it->second.second;
                    long long repeat = (n1 - block) / cycleBlocks;
                    block += repeat * cycleBlocks;
                    completed += repeat * cycleGain;
                    cycleUsed = true;
                }
            }
        }

        return static_cast<int>(completed / n2);
    }
};

替代方案

直接展开：扫描 n1 × |s1| 个字符，空间很省，但上界约一亿字符，无法利用周期。

块转移预处理：为每个 s2 起始指针预先计算扫描一个 s1 后的指针与收益，再做倍增跳跃。它适合多次查询，但单次题目实现更长。

二维动态规划：记录各块边界状态本质上仍会遇到重复状态；显式循环识别更直接。

面试追问

  • 为什么块边界只记录 cursor 就足够，累计数量不属于转移状态？
  • 如何把这个方案改成二进制倍增，以支持很多组不同的 n1？
  • 若字符不是单字节 ASCII，而是 Unicode 码点，各语言遍历方式要怎么改？
  • 循环收益可能为 0 时，为什么算法仍会结束？

常见错误

  • 把“可以删除字符”误读成连续子串匹配。
  • 按块分别计算答案，漏掉跨块形成的 s2。
  • 发现循环后从 n1 而非“剩余块数”计算可跳次数。
  • 循环跳跃后忘记继续处理不足一个循环的尾部。
  • 在匹配过程中就除以 n2，丢失尚可与后续合并的完整 s2。
