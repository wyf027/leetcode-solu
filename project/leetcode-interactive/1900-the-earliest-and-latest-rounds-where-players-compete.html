TOURNAMENT LAB / 1900 / HARD

最佳运动员的比拼回合

The Earliest and Latest Rounds Where Players Compete

两端配对，胜者重新排队。观察两位最强选手的相遇时刻。

01 · 题意

n 名运动员按初始位置编号为 1 到 n。每个回合，从前往后第 i 位与从后往前第 i 位比赛；人数为奇数时，中间选手轮空晋级。胜者按原始编号升序重新排队，进入下一轮。

firstPlayer 和 secondPlayer 是最强选手，在相遇之前必胜。其他对局的任一方都可能获胜，你可以选择结果。返回两位最强选手可能相遇的最早和最晚回合数，回合从 1 开始。

约束：2 ≤ n ≤ 28，1 ≤ firstPlayer < secondPlayer ≤ n。

05 · 独立题解

核心洞察：身份可以压缩成位置

把当前队列重新编号为 1…m。只记录两位强者的位置 a、b，不记录普通选手身份。对阵方式与相对顺序决定未来，因此 F(m,a,b) 足够表达子问题。

完整过程

  1. 如果 a+b=m+1，两人本轮已配对，返回 [1,1]。
  2. 从两端逐场处理。包含强者的对局必须让强者获胜，普通对局可选择任一端，轮空只选择中间一人。
  3. 维护计数对集合 (x,y)，分别代表当前已确定的胜者中，在 a 和 b 前面的人数，初始为 {(0,0)}。
  4. 每选一个胜者 w，就给计数增加 (w<a,w<b)。每场结束去重；不要保留完整胜者组合。a 自己也属于 b 前面的胜者。
  5. 下一轮位置为 x+1、y+1，人数为 ceil(m/2)。递归所有可达状态，最早取最小，最晚取最大，各加当前这一轮。用缓存避免重复计算。

四份代码采用同一转移。整数 32*x+y 编码计数对；n≤28 保证低位不会进位。Python 直接使用元组。

正确性

相同人数与强者位置具有相同配对结构，普通选手可以自由胜负，因此状态压缩不改变可能赛程。逐场选择覆盖所有合法胜者组合，也不会生成非法组合。合并相同计数对不会影响尚未处理对局的增量，因此集合最终恰好表示所有下一轮强者位置。

若本轮配对，答案显然是 [1,1]。否则下一轮人数严格减少。假设所有子状态答案正确，在所有合法下一轮中分别取最早的最小值和最晚的最大值，再加一，就覆盖且仅覆盖当前状态的极值。由人数归纳，算法正确。

边界与常见错误

  • n=2 立即相遇；奇数人数的中间选手必须晋级且只计一次。
  • 位置随晋级改变，不能一直用原始编号判断是否配对。
  • 胜者必须按原始顺序排列，不能按对局遍历顺序排列。
  • 强者相遇时直接终止，不要继续强行选胜者。
  • 最早与最晚可由不同赛程实现。

复杂度

每个 m 人状态处理 O(m) 场，每场最多 O(m²) 个计数对，耗时 O(m³)。每层至多 O(m²) 个位置状态，人数逐层减半，总时间保守上界 O(n⁵)，哈希操作按期望 O(1) 计。缓存以及递归链上保留的集合总空间 O(n²)，递归深度 O(log n)。

替代方案

可枚举普通对局胜负位掩码并模拟整个晋级队列，但每轮选择数为指数级。当前算法提前合并相同位置统计。进一步可利用镜像对称，将 (a,b) 与 (m+1-b,m+1-a) 归为同一状态，或推导位置范围公式优化转移。

面试追问

如何还原赛程？在集合转移保存前驱与胜者，并为极值保存所选子状态。若普通选手胜率各不相同，还能压缩吗？一般不能，身份会影响后续概率，需要更丰富状态。

Java

import java.util.*;
class Solution {
    private final Map<Integer, int[]> memo = new HashMap<>();
    public int[] earliestAndLatest(int n, int firstPlayer, int secondPlayer) {
        memo.clear();
        return dfs(n, firstPlayer, secondPlayer);
    }
    private int[] dfs(int m, int a, int b) {
        if (a + b == m + 1) return new int[]{1, 1};
        int key = m * 1024 + a * 32 + b;
        if (memo.containsKey(key)) return memo.get(key);
        Set<Integer> states = new HashSet<>();
        states.add(0);
        for (int l = 1, r = m; l <= r; l++, r--) {
            int[] choices;
            if (l == a || l == b) choices = new int[]{l};
            else if (r == a || r == b) choices = new int[]{r};
            else choices = l == r ? new int[]{l} : new int[]{l, r};
            Set<Integer> next = new HashSet<>();
            for (int s : states)
                for (int w : choices)
                    next.add((s / 32 + (w < a ? 1 : 0)) * 32
                             + s % 32 + (w < b ? 1 : 0));
            states = next;
        }
        int lo = Integer.MAX_VALUE, hi = 0;
        for (int s : states) {
            int[] sub = dfs((m + 1) / 2, s / 32 + 1, s % 32 + 1);
            lo = Math.min(lo, sub[0] + 1);
            hi = Math.max(hi, sub[1] + 1);
        }
        int[] ans = {lo, hi};
        memo.put(key, ans);
        return ans;
    }
}

var earliestAndLatest = function(n, firstPlayer, secondPlayer) {
    const memo = new Map();
    function dfs(m, a, b) {
        if (a + b === m + 1) return [1, 1];
        const key = `${m},${a},${b}`;
        if (memo.has(key)) return memo.get(key);
        let states = new Set([0]);
        for (let l = 1, r = m; l <= r; l++, r--) {
            const choices = l === a || l === b ? [l]
                : r === a || r === b ? [r]
                : l === r ? [l] : [l, r];
            const next = new Set();
            for (const s of states)
                for (const w of choices)
                    next.add((Math.floor(s / 32) + (w < a ? 1 : 0)) * 32
                             + s % 32 + (w < b ? 1 : 0));
            states = next;
        }
        let lo = Infinity, hi = 0;
        for (const s of states) {
            const sub = dfs(Math.ceil(m / 2), Math.floor(s / 32) + 1, s % 32 + 1);
            lo = Math.min(lo, sub[0] + 1);
            hi = Math.max(hi, sub[1] + 1);
        }
        const ans = [lo, hi];
        memo.set(key, ans);
        return ans;
    }
    return dfs(n, firstPlayer, secondPlayer);
};

Python

from functools import cache
from typing import List

class Solution:
    def earliestAndLatest(self, n: int, firstPlayer: int,
                          secondPlayer: int) -> List[int]:
        @cache
        def dfs(m, a, b):
            if a + b == m + 1:
                return (1, 1)
            states = {(0, 0)}
            for l in range(1, (m + 1) // 2 + 1):
                r = m + 1 - l
                if l in (a, b):
                    choices = [l]
                elif r in (a, b):
                    choices = [r]
                else:
                    choices = [l] if l == r else [l, r]
                states = {(x + (w < a), y + (w < b))
                          for x, y in states for w in choices}
            lo, hi = float('inf'), 0
            for x, y in states:
                early, late = dfs((m + 1) // 2, x + 1, y + 1)
                lo = min(lo, early + 1)
                hi = max(hi, late + 1)
            return (lo, hi)
        return list(dfs(n, firstPlayer, secondPlayer))

class Solution {
    unordered_map<int, vector<int>> memo;

        if (a + b == m + 1) return {1, 1};
        int key = m * 1024 + a * 32 + b;
        if (memo.count(key)) return memo[key];
        unordered_set<int> states{0};
        for (int l = 1, r = m; l <= r; ++l, --r) {
            vector<int> choices;
            if (l == a || l == b) choices = {l};
            else if (r == a || r == b) choices = {r};
            else if (l == r) choices = {l};
            else choices = {l, r};
            unordered_set<int> next;
            for (int s : states)
                for (int w : choices)
                    next.insert((s / 32 + (w < a)) * 32 + s % 32 + (w < b));
            states = move(next);
        }
        int lo = INT_MAX, hi = 0;
        for (int s : states) {
            auto sub = dfs((m + 1) / 2, s / 32 + 1, s % 32 + 1);
            lo = min(lo, sub[0] + 1);
            hi = max(hi, sub[1] + 1);
        }
        return memo[key] = {lo, hi};
    }

    vector<int> earliestAndLatest(int n, int firstPlayer, int secondPlayer) {
