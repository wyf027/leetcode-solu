题目要求

给定字符串 s，其中只含英文字母、数字与连字符 -。这些连字符把原字符串分成若干组；另给定整数 k。

请重新格式化密钥：除第一组外，每组都必须恰好包含 k 个字符；第一组可以少于 k 个，但只要结果非空，它至少包含一个字符。相邻组之间放置一个连字符，并把所有小写字母转为大写。

返回格式化后的密钥字符串。

示例 1

输入s = "5F3Z-2e-9-w", k = 4
输出"5F3Z-2E9W"
解释形成两个各含 4 个字符的分组；原有的多余连字符被移除。

示例 2

输入s = "2-5g-3-J", k = 2
输出"2-5G-3J"
解释第一组只有 1 个字符，其余每组都有 2 个字符。

约束

  • 1 ≤ s.length ≤ 105
  • s 仅由英文字母、数字和连字符 '-' 组成。
  • 1 ≤ k ≤ 104

完整题解

先规范化，再按首组长度切分

把“删除旧格式”和“建立新格式”拆成两个确定步骤，避免在原分隔符上做复杂判断。

核心洞察

1

旧连字符无效

先删除所有 - 并统一转成大写，得到只含有效字符的字符串 clean。

2

余数决定首组

若 n % k ≠ 0，余数就是首组长度；若整除，所有组都长 k。

3

其余等长切分

处理可选首组后，每次读取恰好 k 个字符，并在组之间加入一个连字符。

完整过程

  1. 遍历 s：跳过连字符，把其他字符的大写形式追加到 clean。
  2. 记有效字符数为 n，计算 first = n % k。
  3. 如果 first > 0，先把前 first 个字符作为第一组。
  4. 从当前位置起，每次追加一个连字符（结果非空时）和接下来的 k 个字符。
  5. 返回构造完成的字符串。

正确性证明

引理 1：规范化后的 clean 按原顺序恰好包含 s 中全部非连字符，且字母均为大写。因为第一次遍历只跳过连字符，其他字符按出现顺序追加并转为大写。

引理 2：构造出的第一组长度合法。若 n % k = r > 0，第一组长 r，满足 1 ≤ r < k；若余数为 0，则不创建短首组，第一组由后续循环产生且长度为 k。

引理 3：除可能较短的第一组外，其余每组都恰好包含 k 个字符。扣除余数个字符后，剩余字符数可被 k 整除，循环每次消费恰好 k 个。

定理：由引理 1，输出保留全部有效字符、正确大写且顺序不变；由引理 2 与 3，分组长度满足要求；构造时只在相邻组之间插入一个连字符。因此算法返回的正是所需格式。

复杂度

时间复杂度
O(n)
有效字符只被常数次处理。
空间复杂度
O(n)
规范化字符串与输出都与输入同阶。

边界情况

  • k = 1：每个有效字符独立成组。
  • 有效字符数小于 k：只有一个较短分组，不加连字符。
  • 有效字符数刚好被 k 整除：不要生成空的第一组。
  • 原字符串含连续或首尾连字符：它们都应被统一忽略。
  • 数字保持不变，只有小写英文字母需要转为大写。

替代方案

可以从右向左扫描原字符串：跳过连字符，每累计 k 个有效字符就插入分隔符，最后反转结果。

这种写法不必先计算首组长度，但反向构造与末尾多余连字符的处理更容易出现下标错误。两种方案的时间、空间复杂度同为 O(n)。

面试追问

  • 如何只用一次扫描从右向左完成？
  • 若输入来自字符流，不能一次性载入内存，该如何设计？
  • 若分组长度是一个循环序列而非常数 k，如何扩展？
  • 如何在 Unicode 字母规则下安全地大小写转换？

常见错误

  • 从左侧直接每 k 个字符分组，导致短组出现在末尾。
  • 整除时把 n % k = 0 当作长度为 0 的第一组。
  • 沿用原有连字符的位置，而不是完全重新格式化。
  • 结果开头或结尾多出一个连字符。
  • 只转换部分组的字母大小写。

class Solution {
    public String licenseKeyFormatting(String s, int k) {
        StringBuilder clean = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch != '-') {
                clean.append(Character.toUpperCase(ch));
            }
        }

        StringBuilder answer = new StringBuilder();
        int first = clean.length() % k;
        int index = 0;

        if (first > 0) {
            answer.append(clean, 0, first);
            index = first;
        }

        while (index < clean.length()) {
            if (answer.length() > 0) {
                answer.append('-');
            }
            answer.append(clean, index, index + k);
            index += k;
        }

        return answer.toString();
    }
}

var licenseKeyFormatting = function(s, k) {
    let clean = "";
    for (const ch of s) {
        if (ch !== "-") {
            clean += ch.toUpperCase();
        }
    }

    const groups = [];
    const first = clean.length % k;
    let index = 0;

    if (first > 0) {
        groups.push(clean.slice(0, first));
        index = first;
    }

    while (index < clean.length) {
        groups.push(clean.slice(index, index + k));
        index += k;
    }

    return groups.join("-");
};

public:
    string licenseKeyFormatting(string s, int k) {
        string clean;
        clean.reserve(s.size());

        for (char ch : s) {
            if (ch != '-') {
                clean.push_back(static_cast<char>(
                    toupper(static_cast<unsigned char>(ch))
                ));
            }
        }

        string answer;
        int first = static_cast<int>(clean.size()) % k;
        int index = 0;

        if (first > 0) {
            answer.append(clean, 0, first);
            index = first;
        }

        while (index < static_cast<int>(clean.size())) {
            if (!answer.empty()) {
                answer.push_back('-');
            }
            answer.append(clean, index, k);
            index += k;
        }

        return answer;
    }
