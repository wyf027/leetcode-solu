最少翻转操作数

Minimum Reverse Operations — 让唯一的 1 在固定长度的翻转中穿梭，找出它到达每个位置的最少步数。

HARD广度优先搜索并查集数组有序集合

Problem

题意与规则

非会员题

有一个长度为 n 的数组，除下标 p 处为 1 外，其余元素全是 0。每次可以选取一个长度恰好为 k 的连续子数组并将它翻转。

数组 banned 给出禁止位置：操作后，唯一的 1 不能落在这些下标上。

目标：返回长度为 n 的 answer。其中 answer[i] 是把 1 移到下标 i 的最少操作次数；无法到达时为 -1。

官方函数形式

minReverseOperations(n, p, banned, k) → int[]

参数速览

n数组长度
p唯一的 1 的初始下标
banned1 不可到达的下标集合
k每次必须翻转的子数组长度

Examples

官方示例

整段翻转

输入 n = 4, p = 0, banned = [1,2], k = 4
输出 [0,-1,-1,1]

翻转整个数组即可让 1 从 0 到 3；下标 1、2 被禁止。

路径被截断

输入 n = 5, p = 0, banned = [2,4], k = 3
输出 [0,-1,-1,-1,-1]

唯一可能的新位置 2 被禁止，因此无法继续移动。

长度为一

输入 n = 4, p = 2, banned = [0,1,3], k = 1
输出 [-1,-1,0,-1]

翻转长度 1 不改变位置，只有起点距离为 0。

Constraints

约束

✓1 ≤ n ≤ 10⁵

✓0 ≤ banned.length ≤ n - 1

✓1 ≤ k ≤ n
✓banned[i] ≠ p

Solution

准备好看题解了吗？

先用上面的轨道试着找规律。详细推导、证明与四种语言代码默认收起。

Core Insight

BFS + 按奇偶跳过已访问位置

① 一次翻转会到哪里？

当前位置为 x，翻转窗口左端点为 l。翻转后的位置是：

y = 2l + k - 1 - x

合法窗口满足 max(0, x-k+1) ≤ l ≤ min(x, n-k)。

② 候选形成等差序列

当 l 每次增加 1，y 每次增加 2。所以同一状态的所有目的地都具有相同奇偶性，并落在：

lo = |x-k+1|
hi = min(x+k-1, 2n-k-1-x)

③ 为什么要 BFS？

把每个下标看成图节点，每次合法翻转是一条无权边。BFS 第一次访问某节点时，层数就是从 p 到它的最短距离。

④ 如何做到近线性？

朴素枚举会重复扫描候选。用“后继并查集”维护每个奇偶链上尚未访问的最小下标；访问后把它链接到 +2 的后继，每个下标只取出一次。

完整过程

  1. 答案初始化为 -1，起点 p 设为 0 并进入 BFS 队列。
  2. 建立后继并查集 parent[i] = i；删除所有 banned 位置和起点，使它们不会再次被扫描。
  3. 弹出当前下标 x，计算同奇偶候选区间 [lo, hi]。
  4. 从 find(lo) 开始反复取出尚未访问的候选 y。写入 answer[y] = answer[x] + 1，入队，然后从并查集中删除 y。
  5. 当后继大于 hi 时结束本轮；队列耗尽后返回答案。

正确性证明

引理 1：对当前位置 x，公式给出的 lo, lo+2, …, hi 恰好包含所有一次合法翻转可能到达的位置。因为每个包含 x 的合法左端点 l 与 y=2l+k-1-x 一一对应。

引理 2：后继并查集只删除禁止、起点或已经访问的位置，因此区间扫描不会遗漏任何尚未访问的合法候选；已删除节点也无需再次松弛。

定理：BFS 按操作次数逐层扩展。由引理 1 和 2，每一层完整枚举所有新邻居，所以节点第一次被访问时的层数就是最少操作数；未访问节点不可达，保留 -1。

复杂度

时间：O((n + banned.length) α(n))，其中 α 是反阿克曼函数。

空间：O(n)，用于答案、队列和后继结构。

边界情况

  • k = 1：1 永远不动。
  • k = n：至多在 p 与 n-1-p 间切换。
  • 候选全被禁止或访问过：本轮不产生新节点。
  • banned 为空：流程无需特判。

Implementation

四种语言完整代码

均使用同一后继并查集思路
JavaLeetCode 提交代码
class Solution {
    private int find(int[] parent, int x) {
        int root = x;
        while (parent[root] != root) root = parent[root];
        while (parent[x] != x) {
            int next = parent[x];
            parent[x] = root;
            x = next;
        }
        return root;
    }

    public int[] minReverseOperations(int n, int p, int[] banned, int k) {
        int[] answer = new int[n];
        Arrays.fill(answer, -1);
        answer[p] = 0;

        int[] parent = new int[n + 2];
        for (int i = 0; i < parent.length; i++) parent[i] = i;
        for (int x : banned) parent[x] = find(parent, x + 2);
        parent[p] = find(parent, p + 2);

        ArrayDeque<Integer> queue = new ArrayDeque<>();
        queue.offer(p);
        while (!queue.isEmpty()) {
            int x = queue.poll();
            int lo = Math.abs(x - k + 1);
            int hi = Math.min(x + k - 1, 2 * n - k - 1 - x);
            int y = find(parent, lo);
            while (y <= hi) {
                answer[y] = answer[x] + 1;
                queue.offer(y);
                parent[y] = find(parent, y + 2);
                y = find(parent, y);
            }
        }
        return answer;
    }
}

/**
 * @param {number} n
 * @param {number} p
 * @param {number[]} banned
 * @param {number} k
 * @return {number[]}
 */
var minReverseOperations = function(n, p, banned, k) {
    const answer = Array(n).fill(-1);
    answer[p] = 0;

    const parent = Array.from({ length: n + 2 }, (_, i) => i);
    const find = x => {
        let root = x;
        while (parent[root] !== root) root = parent[root];
        while (parent[x] !== x) {
            const next = parent[x];
            parent[x] = root;
            x = next;
        }
        return root;
    };
    const erase = x => { parent[x] = find(x + 2); };

    for (const x of banned) erase(x);
    erase(p);

    const queue = Array(n);
    let head = 0, tail = 0;
    queue[tail++] = p;
    while (head < tail) {
        const x = queue[head++];
        const lo = Math.abs(x - k + 1);
        const hi = Math.min(x + k - 1, 2 * n - k - 1 - x);
        let y = find(lo);
        while (y <= hi) {
            answer[y] = answer[x] + 1;
            queue[tail++] = y;
            erase(y);
            y = find(y);
        }
    }
    return answer;
};

class Solution:
    def minReverseOperations(
        self, n: int, p: int, banned: List[int], k: int
    ) -> List[int]:
        answer = [-1] * n
        answer[p] = 0

        parent = list(range(n + 2))

        def find(x: int) -> int:
            root = x
            while parent[root] != root:
                root = parent[root]
            while parent[x] != x:
                nxt = parent[x]
                parent[x] = root
                x = nxt
            return root

        def erase(x: int) -> None:
            parent[x] = find(x + 2)

        for x in banned:
            erase(x)
        erase(p)

        queue = [p]
        head = 0
        while head < len(queue):
            x = queue[head]
            head += 1
            lo = abs(x - k + 1)
            hi = min(x + k - 1, 2 * n - k - 1 - x)
            y = find(lo)
            while y <= hi:
                answer[y] = answer[x] + 1
                queue.append(y)
                erase(y)
                y = find(y)

        return answer
C++LeetCode 提交代码
class Solution {
public:
    vector<int> minReverseOperations(
        int n, int p, vector<int>& banned, int k
    ) {
        vector<int> answer(n, -1), parent(n + 2);
        iota(parent.begin(), parent.end(), 0);

        auto find = [&](int x) {
            int root = x;
            while (parent[root] != root) root = parent[root];
            while (parent[x] != x) {
                int next = parent[x];
                parent[x] = root;
                x = next;
            }
            return root;
        };
        auto erase = [&](int x) { parent[x] = find(x + 2); };

        for (int x : banned) erase(x);
        erase(p);
        answer[p] = 0;

        queue<int> q;
        q.push(p);
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            int lo = abs(x - k + 1);
            int hi = min(x + k - 1, 2 * n - k - 1 - x);
            int y = find(lo);
            while (y <= hi) {
                answer[y] = answer[x] + 1;
                q.push(y);
                erase(y);
                y = find(y);
            }
        }
        return answer;
    }
};

Trade-offs

替代方案

方案时间空间评价
每次枚举所有窗口最坏 O(nk)O(n)直观，但会反复扫描，无法承受 10⁵。
两棵有序集合O(n log n)O(n)按奇偶保存未访问下标，编码清晰；Java/C++ 很方便。
后继并查集O(n α(n))O(n)每个下标只删除一次，四种语言都可稳定实现。

Interview

面试追问

为什么候选位置步长一定是 2？

窗口左端点增加 1 时，映射式中的 2l 增加 2，因此目的地下标保持同一奇偶性。

为什么删除已访问节点是安全的？

无权图 BFS 第一次到达节点就是最短距离，后续路径不会更短，无需再次处理它。

能否用普通并查集连通分量？

这里不是查询连通性，而是查询“下一个未删除位置”；并查集承担的是后继结构。

如果每次允许不同的 k 呢？

候选区间和奇偶性会随操作改变，单一后继链未必够用，需要重新审视邻居生成与去重结构。

Pitfalls

常见错误

  • 把窗口左端点的范围写成 [x-k+1, x] 后忘记与 [0, n-k] 取交集。
  • 按 +1 扫描候选，忽略所有合法目的地具有固定奇偶性。
  • 只在答案里标记 banned，却没有从后继结构删除，导致它进入 BFS。
  • 递归实现后继查找，在 Python 或 Java 中因链过深产生栈风险；这里使用迭代路径压缩。
  • 访问节点后没有立即删除，造成重复入队或重复扫描。
