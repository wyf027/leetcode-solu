最大网络秩

Maximal Network Rank

从任意两座城市出发，把所有直接连到它们的道路合在一起计数。真正需要留意的只有一件事：如果两座城市之间恰好有路，这条路会同时出现在两边的度数里，最终只能算一次。

Problem

题目描述

函数：maximalNetworkRank(n, roads)

有 n 座编号为 0 到 n - 1 的城市。每个 roads[i] = [aᵢ, bᵢ] 表示城市 aᵢ 与 bᵢ 之间有一条双向道路。

两座不同城市的网络秩，是直接连接到其中任意一座城市的道路总数。若一条道路正好连接这两座城市，它只能被计算一次。返回所有不同城市对中的最大网络秩。

示例 1

输入：n = 4,
roads = [[0,1],[0,3],[1,2],[1,3]]
输出：4

城市 0、1 共触及 4 条不同道路；道路 [0,1] 只算一次。

示例 2

输入：n = 5,
roads = [[0,1],[0,3],[1,2],
         [1,3],[2,3],[2,4]]
输出：5

与城市 1 或城市 2 直接相连的不同道路共有 5 条。

示例 3

输入：n = 8,
roads = [[0,1],[1,2],[2,3],
         [2,4],[5,6],[5,7]]
输出：5

城市 2、5 的网络秩为 5；整个图不必连通。

约束

  • 2 ≤ n ≤ 100
  • 0 ≤ roads.length ≤ n × (n - 1) / 2
  • roads[i].length == 2
  • 0 ≤ aᵢ, bᵢ ≤ n - 1，且 aᵢ ≠ bᵢ
  • 每对城市之间最多只有一条道路。

Solution

题解：度数之和，减去重复

核心洞察

城市 i 与 j 的网络秩等于 degree[i] + degree[j] - connected(i, j)。其中 connected(i, j) 在两城直连时为 1，否则为 0。

完整过程

  1. 扫描 roads，累计每座城市的度数。
  2. 同时用邻接矩阵记录任意两城是否直连。
  3. 枚举所有 i < j 的城市对。
  4. 计算度数和；若直连则减 1，并更新最大值。

为什么要减 1？

若 i 与 j 直连，这条道路既计入 degree[i]，也计入 degree[j]。网络秩数的是道路并集，因此重复出现的这唯一一条道路要减去一次。

边界情况

  • 没有道路：所有城市对的网络秩都是 0。
  • 只有两座城市且彼此直连：1 + 1 - 1 = 1。
  • 图可以不连通；仍需比较跨连通分量的城市对。
  • 完全图中任意城市对都直连，网络秩为 2n - 3。

复杂度

设道路数为 m。预处理道路耗时 O(m)，枚举城市对耗时 O(n²)，总时间为 O(m + n²)；邻接矩阵与度数数组共使用 O(n²) 空间。

Correctness

正确性证明

  1. 度数统计完整。 扫描每条道路 [a,b] 时分别给 a、b 的度数加一，因此 degree[x] 恰好等于所有直接连接城市 x 的道路数。
  2. 单个城市对的计算正确。 对城市 i,j，两者道路集合大小之和是 degree[i] + degree[j]。两集合的交集仅可能包含道路 [i,j]；直连时交集大小为 1，否则为 0。按容斥原理，公式恰好得到道路并集大小，即网络秩。
  3. 最大值正确。 双重循环枚举所有且仅所有满足 i < j 的不同城市对，并取其网络秩最大值，所以最终结果就是整个网络的最大网络秩。

class Solution {
    public int maximalNetworkRank(int n, int[][] roads) {
        int[] degree = new int[n];
        boolean[][] connected = new boolean[n][n];

        for (int[] road : roads) {
            int a = road[0];
            int b = road[1];
            degree[a]++;
            degree[b]++;
            connected[a][b] = true;
            connected[b][a] = true;
        }

        int answer = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int rank = degree[i] + degree[j];
                if (connected[i][j]) {
                    rank--;
                }
                answer = Math.max(answer, rank);
            }
        }
        return answer;
    }
}

var maximalNetworkRank = function(n, roads) {
    const degree = new Array(n).fill(0);
    const connected = Array.from(
        { length: n },
        () => new Array(n).fill(false)
    );

    for (const [a, b] of roads) {
        degree[a]++;
        degree[b]++;
        connected[a][b] = true;
        connected[b][a] = true;
    }

    let answer = 0;
    for (let i = 0; i < n; i++) {
        for (let j = i + 1; j < n; j++) {
            const rank = degree[i] + degree[j]
                - (connected[i][j] ? 1 : 0);
            answer = Math.max(answer, rank);
        }
    }
    return answer;
};
class Solution:
    def maximalNetworkRank(
        self, n: int, roads: List[List[int]]
    ) -> int:
        degree = [0] * n
        connected = [[False] * n for _ in range(n)]

        for a, b in roads:
            degree[a] += 1
            degree[b] += 1
            connected[a][b] = True
            connected[b][a] = True

        answer = 0
        for i in range(n):
            for j in range(i + 1, n):
                rank = degree[i] + degree[j]
                if connected[i][j]:
                    rank -= 1
                answer = max(answer, rank)

        return answer

Alternatives

替代方案

可以把每座城市的邻居存进哈希集合，再用 neighbors[i].has(j) 判断直连。时间复杂度仍为 O(m + n²)，额外空间降为 O(m + n)，但集合常数更大。由于 n ≤ 100，邻接矩阵更直接。

Interview

面试追问

  • 若 n 极大而图很稀疏，邻接矩阵是否合适？
  • 能否利用度数排序减少实际比较次数，并证明剪枝安全？

Pitfalls

常见错误

忘记扣重

直接返回两城度数之和，会让它们之间的道路被算两次。

重复枚举

从 j = 0 开始会比较自己并重复城市对；应从 i + 1 开始。

只看连通城市对

最大值可能来自不直连的两座高出度城市，不能只遍历已有道路。

误用最短路

题目只统计直接相连的道路，与两城之间是否可达、距离多少无关。
