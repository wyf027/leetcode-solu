重新格式化部门表

Reformat Department Table — 把逐月记录整理成每个部门一行、十二个月各一列的宽表。

Problem

题意

给定表 Department(id, revenue, month)。每条记录表示某个部门在某个月的收入，联合主键为 (id, month)。请返回一张重新格式化的表：每个部门只占一行，除 id 外依次包含 Jan_Revenue 到 Dec_Revenue 十二列；没有记录的月份应为 null。结果行顺序不限。

表结构与约束

列名类型说明
idint部门编号
revenueint该月收入
monthvarcharJan…Dec 之一

(id, month) 是联合主键；month 只取 Jan、Feb、Mar、Apr、May、Jun、Jul、Aug、Sep、Oct、Nov、Dec。

输入：Department = [
  [1, 8000, "Jan"],
  [2, 9000, "Jan"],
  [3, 10000, "Feb"],
  [1, 7000, "Feb"],
  [1, 6000, "Mar"]
]

输出：[
  [1, 8000, 7000, 6000, null, null, null,
      null, null, null, null, null, null],
  [2, 9000, null, null, null, null, null,
      null, null, null, null, null, null],
  [3, null, 10000, null, null, null, null,
      null, null, null, null, null, null]
]

列顺序：id, Jan_Revenue, Feb_Revenue, ...,
        Dec_Revenue

示例中 Apr 至 Dec 均无记录，因此相应单元格为 null；结果共 13 列。

Solution

条件聚合：一次分组生成十二个月份列

核心洞察

输出的每一行对应一个 id，因此按部门分组；输出的每个月份列只接收该月份的 revenue，因此在聚合函数中写条件。联合主键保证同一部门同一月份至多一条记录。

完整过程

  1. 以 id 为分组键，把同一部门的记录放进一组。
  2. 对每个月分别计算条件表达式：月份匹配时返回 revenue，不匹配时返回 NULL。
  3. 用 SUM 聚合各条件表达式。某月有记录时得到该收入；没有记录时，该组全是 NULL，结果仍为 NULL。
  4. 为十二个表达式依次命名 Jan_Revenue 至 Dec_Revenue。

正确性说明

任取部门 d 与月份 m。分组确保只考察 id = d 的记录；条件表达式又只保留 month = m 的收入。若该记录存在，主键约束保证它唯一，聚合值就是该收入；若不存在，所有候选值均为 NULL，聚合结果为 NULL。因此每个部门的每个月份列都与定义一致，十二列同时成立。

边界情况

  • 某部门只有一个月的数据：其余十一个月份列均为 NULL。
  • 不同部门拥有不同月份：条件只在各自的 id 分组内生效，不会串行。
  • 收入为 0：会保留为 0，不应误写成 NULL。
  • 输入行顺序任意：分组结果不依赖输入顺序。

复杂度

设输入记录数为 n，月份数固定为 12。查询扫描并聚合记录，时间复杂度可写为 O(n)（把 12 视为常数）；分组聚合所需额外空间与不同部门数 k 有关，可记为 O(k)。数据库实际执行代价还取决于执行计划、索引和内存策略。

替代方案

可以把 SUM(IF(...)) 换成 MAX(CASE WHEN ... THEN revenue END)，在联合主键保证唯一时语义同样成立。部分数据库还提供 PIVOT 语法，但可移植性较弱。若月份集合动态变化，需要动态 SQL；本题月份固定，显式十二列更直接。

面试追问

  • 如果取消联合主键，同月出现多条记录，应该求和、取最大值还是先去重？必须先确认业务定义。
  • 为什么 ELSE 0 不合适？因为它无法区分“缺少记录”和“收入确实为 0”。
  • 如何支持动态月份？由数据库元数据生成列清单与条件表达式，并通过受控动态 SQL 执行。

常见错误

  • 遗漏月份列，或别名大小写/拼写不符合要求。
  • 写了条件表达式却忘记 GROUP BY id。
  • 用 0 填补缺失月份，改变了题目要求的 null 语义。
  • 把多个月份条件写进同一列，导致列间数据混淆。

官方可提交语言：MySQL

SELECT id,
       SUM(IF(month = 'Jan', revenue, NULL)) AS Jan_Revenue,
       SUM(IF(month = 'Feb', revenue, NULL)) AS Feb_Revenue,
       SUM(IF(month = 'Mar', revenue, NULL)) AS Mar_Revenue,
       SUM(IF(month = 'Apr', revenue, NULL)) AS Apr_Revenue,
       SUM(IF(month = 'May', revenue, NULL)) AS May_Revenue,
       SUM(IF(month = 'Jun', revenue, NULL)) AS Jun_Revenue,
       SUM(IF(month = 'Jul', revenue, NULL)) AS Jul_Revenue,
       SUM(IF(month = 'Aug', revenue, NULL)) AS Aug_Revenue,
       SUM(IF(month = 'Sep', revenue, NULL)) AS Sep_Revenue,
       SUM(IF(month = 'Oct', revenue, NULL)) AS Oct_Revenue,
       SUM(IF(month = 'Nov', revenue, NULL)) AS Nov_Revenue,
       SUM(IF(month = 'Dec', revenue, NULL)) AS Dec_Revenue
FROM Department
GROUP BY id;

import java.util.*;

public class DepartmentPivot {
    public record Input(int id, int revenue, String month) {}
    public record Output(int id, List<Integer> revenues) {}

    private static final List<String> MONTHS = List.of(
        "Jan", "Feb", "Mar", "Apr", "May", "Jun",
        "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"
    );

    public static List<Output> reformat(List<Input> rows) {
        Map<String, Integer> index = new HashMap<>();
        for (int i = 0; i < MONTHS.size(); i++) index.put(MONTHS.get(i), i);

        Map<Integer, Integer[]> grouped = new TreeMap<>();
        for (Input row : rows) {
            Integer[] values = grouped.computeIfAbsent(row.id(), k -> new Integer[12]);
            values[index.get(row.month())] = row.revenue();
        }

        List<Output> answer = new ArrayList<>();
        for (Map.Entry<Integer, Integer[]> entry : grouped.entrySet()) {
            answer.add(new Output(entry.getKey(), Arrays.asList(entry.getValue())));
        }
        return answer;
    }
}
function reformatDepartment(rows) {
  const months = [
    "Jan", "Feb", "Mar", "Apr", "May", "Jun",
    "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"
  ];
  const index = new Map(months.map((month, i) => [month, i]));
  const grouped = new Map();

  for (const { id, revenue, month } of rows) {
    if (!grouped.has(id)) grouped.set(id, Array(12).fill(null));
    grouped.get(id)[index.get(month)] = revenue;
  }

  return [...grouped.entries()]
    .sort((a, b) => a[0] - b[0])
    .map(([id, revenues]) => ({ id, revenues }));
}
from typing import Iterable, Optional

MONTHS = (
    "Jan", "Feb", "Mar", "Apr", "May", "Jun",
    "Jul", "Aug", "Sep", "Oct", "Nov", "Dec",
)

def reformat_department(
    rows: Iterable[tuple[int, int, str]],
) -> list[tuple[int, list[Optional[int]]]]:
    month_index = {month: i for i, month in enumerate(MONTHS)}
    grouped: dict[int, list[Optional[int]]] = {}

    for department_id, revenue, month in rows:
        values = grouped.setdefault(department_id, [None] * 12)
        values[month_index[month]] = revenue

    return [(department_id, grouped[department_id])
            for department_id in sorted(grouped)]

struct Output {
    int id;
    std::array<std::optional<int>, 12> revenues;
};

std::vector<Output> reformatDepartment(
    const std::vector<std::tuple<int, int, std::string>>& rows) {
    const std::array<std::string, 12> months = {
        "Jan", "Feb", "Mar", "Apr", "May", "Jun",
        "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"
    };
    std::unordered_map<std::string, int> index;
    for (int i = 0; i < 12; ++i) index[months[i]] = i;

    std::map<int, std::array<std::optional<int>, 12>> grouped;
    for (const auto& [id, revenue, month] : rows) {
        grouped[id][index.at(month)] = revenue;
    }

    std::vector<Output> answer;
    for (const auto& [id, revenues] : grouped) answer.push_back({id, revenues});
    return answer;
}
