猜猜这个单词

你只有有限次提问机会。每次猜测只会返回“同位置同字符”的数量——如何让每个回答都尽可能多地缩小候选集合？

先体验，再看答案下方实验台展示一次完整的候选集收缩。题解默认折叠，不会在首屏泄露核心策略。
01 · Problem

题目说明

这是交互题：你的代码不返回秘密词，而是通过评测器提供的 Master.guess 完成猜测。

给定一个由不同字符串组成的数组 words，每个单词恰好由 6 个小写英文字母组成，其中一个是秘密单词。你可以调用 Master.guess(word)：参数必须来自 words，返回猜测词与秘密词在相同位置上字符相等的数量；若参数不在列表中则返回 -1。

每个测试用例给出最多可调用次数 allowedGuesses。你需要在不超过该限制的前提下，至少一次把秘密词本身传给 Master.guess。测试数据保证存在合理的非暴力策略。

合法猜测长度为 6，且必须来自 words。
反馈含义仅统计字符和值都位于同一位置的匹配。
成功条件在 allowedGuesses 次内猜中秘密词。

约束

  • 1 <= words.length <= 100
  • words[i].length == 6
  • words[i] 仅由小写英文字母组成
  • words 中所有字符串互不相同
  • secret 一定存在于 words
  • 10 <= allowedGuesses <= 30

极小化最坏反馈组

核心洞察

一次猜测之后，只能根据返回的匹配数保留与该猜测具有相同匹配数的候选。于是应选择一个词，使它把当前候选集合按 0～6 个匹配划分后，最大的桶尽可能小。

对每个可猜单词 g，统计候选秘密词与它的匹配数分布。令最大桶大小为它的“最坏代价”，选择代价最小的词询问 Master。这就是这里的 minimax：我们最小化最坏情况下仍需处理的候选数量。

pick g = arg ming∈words maxk∈[0,6] |{ w∈candidates : match(g,w)=k }|

完整过程

  1. 预计算匹配数
    计算任意两个单词在相同位置上相等的字符数，避免循环内反复比较。
  2. 评估所有猜测
    针对每个仍可选择的词，把当前候选按匹配数 0～6 分桶，记录最大桶。
  3. 执行最稳健的猜测
    选择最大桶最小的单词调用 master.guess；若返回 6，立即结束。
  4. 过滤候选
    只保留与猜测词匹配数等于反馈值的词，因为秘密词必然满足这条一致性条件。
  5. 重复
    在候选集合上继续，直到猜中或达到允许次数。官方数据保证合理策略可完成。

正确性说明

不变式：秘密词始终在候选集合中

初始时候选集合为全部 words，题目保证秘密词在其中。某轮猜测 g 得到反馈 r，而 r 正是 match(g, secret)。过滤时仅删除 match(g, w) != r 的词，因此秘密词不会被删除。不变式由归纳法成立。

终止时结果正确

算法仅在 Master 返回 6 时停止。两个长度均为 6 的单词有 6 个同位置匹配，当且仅当它们完全相同，所以本轮猜测必为秘密词。

选择规则的意义

minimax 选择在所有可能反馈中最大剩余组最小的猜测；因此就“一步后的最坏候选数”而言，没有其他被评估的猜测能提供更好的保证。它是稳健启发式，不声称对整棵决策树全局最优。

复杂度与边界

设单词数为 n，单词长度固定为 6。预计算匹配矩阵需 O(n² · 6) 时间与 O(n²) 空间。每轮评估所有猜测与当前候选需 O(n²) 时间；最多进行 allowedGuesses 轮。若不预计算，空间可降为 O(n)，但会重复字符比较。

边界包括：只剩一个候选时直接猜；反馈为 0 时保留与猜测没有同位置匹配的词；猜测必须来自原列表；一旦反馈为 6 必须返回，避免浪费调用次数。

替代方案

随机猜候选

实现简单，期望表现可能尚可，但最坏情况不可控，容易在调用上限内失败。

零匹配启发式

选择与其他词零匹配数量较少的词，是经典轻量方案，但利用的反馈分布不如完整 minimax。

信息熵最大化

最小化期望剩余数量，平均表现可能更好；minimax 更强调最坏情况保证。

完整决策树搜索

可能找到全局更优策略，但状态空间很大，对本题 n≤100 没有必要。

/**
 * interface Master { int guess(String word); }
 */
class Solution {
    public void findSecretWord(String[] words, Master master) {
        int n = words.length;
        int[][] same = new int[n][n];
        for (int i = 0; i < n; i++)
            for (int j = i; j < n; j++)
                same[i][j] = same[j][i] = match(words[i], words[j]);

        java.util.List<Integer> candidates = new java.util.ArrayList<>();
        for (int i = 0; i < n; i++) candidates.add(i);

        while (!candidates.isEmpty()) {
            int guess = choose(same, candidates, n);
            int score = master.guess(words[guess]);
            if (score == 6) return;
            java.util.List<Integer> next = new java.util.ArrayList<>();
            for (int x : candidates)
                if (same[guess][x] == score) next.add(x);
            candidates = next;
        }
    }

    private int choose(int[][] same, java.util.List<Integer> cand, int n) {
        int best = 0, bestWorst = Integer.MAX_VALUE;
        for (int g = 0; g < n; g++) {
            int[] buckets = new int[7];
            int worst = 0;
            for (int x : cand) worst = Math.max(worst, ++buckets[same[g][x]]);
            if (worst < bestWorst) { bestWorst = worst; best = g; }
        }
        return best;
    }

    private int match(String a, String b) {
        int count = 0;
        for (int i = 0; i < 6; i++) if (a.charAt(i) == b.charAt(i)) count++;
        return count;
    }
}

 * @param {string[]} words
 * @param {Master} master

var findSecretWord = function(words, master) {
    const n = words.length;
    const match = (a, b) => {
        let count = 0;
        for (let i = 0; i < 6; i++) count += a[i] === b[i] ? 1 : 0;
        return count;
    };
    const same = Array.from({ length: n }, () => Array(n).fill(0));
    for (let i = 0; i < n; i++) {
        for (let j = i; j < n; j++) {
            same[i][j] = same[j][i] = match(words[i], words[j]);
        }
    }

    let candidates = Array.from({ length: n }, (_, i) => i);
    while (candidates.length) {
        let best = 0, bestWorst = Infinity;
        for (let g = 0; g < n; g++) {
            const buckets = Array(7).fill(0);
            let worst = 0;
            for (const x of candidates) worst = Math.max(worst, ++buckets[same[g][x]]);
            if (worst < bestWorst) { bestWorst = worst; best = g; }
        }
        const score = master.guess(words[best]);
        if (score === 6) return;
        candidates = candidates.filter(x => same[best][x] === score);
    }
};
class Solution:
    def findSecretWord(self, words: List[str], master: 'Master') -> None:
        n = len(words)

        def match(a: str, b: str) -> int:
            return sum(x == y for x, y in zip(a, b))

        same = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(i, n):
                same[i][j] = same[j][i] = match(words[i], words[j])

        candidates = list(range(n))
        while candidates:
            best, best_worst = 0, float('inf')
            for guess in range(n):
                buckets = [0] * 7
                worst = 0
                for candidate in candidates:
                    score = same[guess][candidate]
                    buckets[score] += 1
                    worst = max(worst, buckets[score])
                if worst < best_worst:
                    best, best_worst = guess, worst

            score = master.guess(words[best])
            if score == 6:
                return
            candidates = [x for x in candidates if same[best][x] == score]
/**
 * class Master { public: int guess(string word); };
 */
class Solution {
    int match(const string& a, const string& b) {
        int count = 0;
        for (int i = 0; i < 6; ++i) count += a[i] == b[i];
        return count;
    }
public:
    void findSecretWord(vector<string>& words, Master& master) {
        int n = words.size();
        vector<vector<int>> same(n, vector<int>(n));
        for (int i = 0; i < n; ++i)
            for (int j = i; j < n; ++j)
                same[i][j] = same[j][i] = match(words[i], words[j]);

        vector<int> candidates(n);
        iota(candidates.begin(), candidates.end(), 0);
        while (!candidates.empty()) {
            int best = 0, bestWorst = INT_MAX;
            for (int g = 0; g < n; ++g) {
                int buckets[7] = {};
                int worst = 0;
                for (int x : candidates)
                    worst = max(worst, ++buckets[same[g][x]]);
                if (worst < bestWorst) bestWorst = worst, best = g;
            }
            int score = master.guess(words[best]);
            if (score == 6) return;
            vector<int> next;
            for (int x : candidates)
                if (same[best][x] == score) next.push_back(x);
            candidates.swap(next);
        }
    }
};

面试追问

为什么猜测范围可用全部 words？

非候选词仍可能把当前候选切得更均匀，提供更好的信息。它不会被当作秘密词，只被当作探针。

minimax 与最大熵有何区别？

前者优化最坏分支，后者优化平均信息增益；面对硬调用上限时，前者更稳健。

如何降低计算量？

预计算匹配矩阵，并在候选很少时仅评估候选词；也可先用轻量启发式筛选探针。

词长不是 6 怎么办？

把 6 改为统一的长度 L，桶数改为 L+1，其他逻辑不变。

常见错误

  • 把“相同字符数”误写成无视位置的字符集合交集。
  • 用不在 words 中的字符串调用 Master，得到 -1。
  • 过滤方向写反；必须保留与本轮猜测匹配数恰好等于反馈的候选。
  • 只从当前候选中选择探针，虽然通常可行，但可能错过更均衡的划分。
  • 收到 6 后仍继续调用，浪费有限次数。
  • 声称 minimax 一定在任意输入的 10 次内成功；本题依赖官方测试数据的可解性保证。
