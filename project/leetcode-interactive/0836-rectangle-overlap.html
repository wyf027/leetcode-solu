矩形重叠

把二维问题拆成两个一维区间：只有 x 轴和 y 轴上的交集长度都严格大于 0，两个轴对齐矩形才真正重叠。

难度：简单Rectangle Overlap非付费题返回值：boolean

Problem

题目描述

一个与坐标轴平行的矩形表示为 [x1, y1, x2, y2]：(x1, y1) 是左下角，(x2, y2) 是右上角。给定 rec1 和 rec2，判断它们的交集面积是否为正。

关键定义
只在边或顶点上接触时，交集面积为 0，因此不算重叠。

约束

  • rec1.length == 4，rec2.length == 4
  • -10⁹ ≤ rec1[i], rec2[i] ≤ 10⁹
  • 两个数组都表示面积非零的有效矩形，即 x1 < x2 且 y1 < y2
示例 1
输入：rec1 = [0,0,2,2], rec2 = [1,1,3,3]
输出：true
示例 2
输入：rec1 = [0,0,1,1], rec2 = [1,0,2,1]
输出：false
示例 3
输入：rec1 = [0,0,1,1], rec2 = [2,2,3,3]
输出：false

Full solution

二维重叠 = 两个一维正交集

核心洞察

两个矩形在 x 轴上的公共长度是 min(r1, r2) - max(l1, l2)，在 y 轴同理。两者都严格大于 0，交集面积才为正。

min(rec1[2], rec2[2]) > max(rec1[0], rec2[0])
min(rec1[3], rec2[3]) > max(rec1[1], rec2[1])

完整过程

  1. 取两矩形左边界的较大值和右边界的较小值。
  2. 若右界不严格大于左界，x 方向没有正长度交集，直接返回 false。
  3. 对上下边界做完全相同的判断。
  4. 两个方向都通过，返回 true。

正确性证明

  1. 轴对齐矩形的交集若存在，仍是轴对齐矩形，其 x 范围等于两个 x 区间的交集，y 范围同理。
  2. 一维区间交集具有正长度，当且仅当较小右端点严格大于较大左端点。
  3. 交集面积是公共宽度与公共高度的乘积；两者均为正时乘积为正，任一不为正时面积不为正。因此算法返回值与题目定义等价。

边界情况

  • 边接触：公共宽度或高度为 0，必须返回 false。
  • 角接触：两个方向至少有一个公共长度为 0，返回 false。
  • 包含关系：一个矩形完全在另一个内部，两个公共长度都为正，返回 true。
  • 负坐标、大坐标不影响比较法；无需计算面积，也避免不必要的乘法溢出风险。

复杂度

只做常数次比较：时间复杂度 O(1)，额外空间复杂度 O(1)。

替代方案

也可以列出“不重叠”的四种分离情形：一个矩形完全位于另一个的左、右、上或下，再对它们取反。逻辑等价，但正向的区间交集公式通常更对称。

面试追问

  • 若旋转矩形不再与坐标轴平行，应如何用分离轴定理判断？
  • 若边接触也算重叠，应把哪两个严格不等号改成非严格不等号？
  • 如何计算交集面积？先把公共宽高截断到 0，再相乘。

常见错误

  • 使用 >=，把边接触误判为重叠。
  • 只判断一个矩形的顶点是否落在另一个内部，漏掉十字交叉等情形。
  • 直接相乘再判断面积，容易掩盖边界语义，也可能在其他整数类型下溢出。

四种语言完整实现

Java
class Solution {
    public boolean isRectangleOverlap(int[] rec1, int[] rec2) {
        boolean overlapX = Math.min(rec1[2], rec2[2])
                > Math.max(rec1[0], rec2[0]);
        boolean overlapY = Math.min(rec1[3], rec2[3])
                > Math.max(rec1[1], rec2[1]);
        return overlapX && overlapY;
    }
}

from typing import List

class Solution:
    def isRectangleOverlap(
        self, rec1: List[int], rec2: List[int]
    ) -> bool:
        overlap_x = min(rec1[2], rec2[2]) > max(rec1[0], rec2[0])
        overlap_y = min(rec1[3], rec2[3]) > max(rec1[1], rec2[1])
        return overlap_x and overlap_y
