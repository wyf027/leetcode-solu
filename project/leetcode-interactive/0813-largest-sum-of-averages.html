把一串数字切成至多 k 个连续小组。每一刀都会改变计分方式——你能找到让各组平均值之和最大的切法吗？

Problem

题目说明

给定整数数组 nums 和整数 k，把数组划分成至多 k 个非空、连续的子数组。一次划分的分数，等于所有子数组平均值的总和。

划分必须恰好使用 nums 中的每一个整数。返回所有合法划分能得到的最大分数；答案与真实值的误差不超过 10−6 即可。

函数形式： largestSumOfAverages(nums, k) → double
示例 01 
输入：nums = [9,1,2,3,9], k = 3
输出：20.00000
解释：[9] | [1,2,3] | [9]
      9 + 2 + 9 = 20

例如切成 [9,1] | [2] | [3,9] 只得到 5 + 2 + 6 = 13。

示例 02 
输入：nums = [1,2,3,4,5,6,7], k = 4
输出：20.50000

一种最优划分是 [1,2,3,4] | [5] | [6] | [7]。

  • 1 ≤ nums.length ≤ 100
  • 1 ≤ nums[i] ≤ 10⁴
  • 1 ≤ k ≤ nums.length

Solution

动态规划：枚举最后一刀

把“完整划分”拆成“前面的最优划分 + 最后一组”，再用前缀和 O(1) 求任意连续段的平均值。

核心洞察

令 dp[g][i] 表示前 i 个数恰好分成 g 组时的最大分数。最后一组若从下标 j 开始，那么前 j 个数必须恰好组成 g−1 组。

状态转移

dp[g][i] = max(dp[g−1][j] + avg(j, i−1))，其中 g−1 ≤ j < i。借助前缀和，avg(j, i−1) = (pre[i]−pre[j])/(i−j)。

初始化与答案

dp[1][i] = pre[i]/i。题目数组元素均为正数，多切出一个非空组不会降低分数，因此“至多 k 组”的最优解一定可以取到恰好 k 组，答案为 dp[k][n]。

完整过程

  1. 构造长度为 n+1 的前缀和。
  2. 填好一组时的全部前缀答案。
  3. 依次枚举组数 g、前缀长度 i 与最后切分点 j。
  4. 用每个候选值更新当前状态，最终返回 dp[k][n]。

正确性证明

引理： 对任意 g ≥ 2 和 i ≥ g，转移式得到的 dp[g][i] 等于前 i 个数恰分 g 组的最大分数。

证明： 任取一种合法最优划分，设最后一组从 j 开始。它前面的部分是前 j 个数的 g−1 组划分；若该部分不是最优的，用 dp[g−1][j] 替换即可得到更高总分，与原划分最优矛盾。因此该划分的分数必为转移枚举的某个候选值。反过来，转移中的每个 j 都把一个合法的 g−1 组划分与非空末组拼接，得到合法的 g 组划分。取所有候选最大值，既不会漏掉最优解，也不会产生非法解。

定理： 初始化正确描述一组情形；结合引理按组数归纳，dp[k][n] 即所求最大分数。

复杂度

三层枚举组数、前缀终点与切分点，时间复杂度 O(k·n²)；二维实现空间复杂度 O(k·n)。若只保留相邻两层，可降到 O(n) 空间。

边界情况

  • k = 1：答案就是整个数组的平均值。
  • k = n：每个元素单独一组，答案是元素总和。
  • 使用浮点类型保存前缀和、平均值和 DP 状态。
  • 只有 i ≥ g 的状态合法。

替代方案

自顶向下记忆化搜索同样自然：状态为起点和剩余组数，枚举第一组终点。它与二维 DP 的渐进复杂度相同。迭代写法没有递归栈，状态访问顺序也更直观。

常见错误

  • 把子数组误当成可跳跃选取的子序列。
  • 切分点从 0 开始，导致前面组数不够或末组为空。
  • 整数除法截断平均值。
  • 把 dp[g][i] 的“前 i 个”误写成“下标 i”。

四语言完整代码

class Solution {
    public double largestSumOfAverages(int[] nums, int k) {
        int n = nums.length;
        double[] prefix = new double[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        double[][] dp = new double[k + 1][n + 1];
        for (int i = 1; i <= n; i++) {
            dp[1][i] = prefix[i] / i;
        }

        for (int groups = 2; groups <= k; groups++) {
            for (int i = groups; i <= n; i++) {
                for (int j = groups - 1; j < i; j++) {
                    double lastAverage = (prefix[i] - prefix[j]) / (i - j);
                    dp[groups][i] = Math.max(
                        dp[groups][i],
                        dp[groups - 1][j] + lastAverage
                    );
                }
            }
        }
        return dp[k][n];
    }
}

面试追问

为什么“至多 k 组”可以按“恰好 k 组”求？
因为题目保证每个数为正。把一个长度至少为 2 的组拆为两个非空组后，得到两个正平均值之和；它严格大于原来位于二者之间的加权平均值。因此只要还能拆，增加组数就会提升分数。
能否把空间降到 O(n)？
可以。第 g 层只依赖第 g−1 层，保留 prev 与 curr 两个一维数组即可。每轮结束交换数组，并清理下一轮将写入的合法区间。
如果 nums 允许负数呢？
“恰好 k 组一定最优”不再成立，应计算每个组数 1…k 的答案并取最大值；无效状态也不能用 0 初始化，应使用负无穷。
为什么不使用贪心选择最大元素单独成组？
一次切分同时决定左右两边的连续区间，局部看似有利的单点可能迫使其他元素形成很差的组。动态规划枚举最后一刀，才能覆盖所有连续划分并保留全局最优子结构。
