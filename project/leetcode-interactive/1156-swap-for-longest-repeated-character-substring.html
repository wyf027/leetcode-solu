单字符重复子串的最大长度

Swap For Longest Repeated Character Substring

题目

给定仅含小写英文字母的字符串 text。你可以交换其中任意两个字符至多一次，也可以不交换。求经过操作后，能够出现的最长“所有字符都相同”的连续子串长度。

函数形式：int maxRepOpt1(String text)（语言不同类型写法相应变化），返回一个整数。

官方示例

输入：text = "ababa"
输出：3

输入：text = "aaabaaa"
输出：6

输入：text = "aaabbaaa"
输出：4

输入：text = "aaaaa"
输出：5

输入：text = "abcdef"
输出：1

约束

  • 1 <= text.length <= 20000
  • text 只包含小写英文字母。
  • 交换必须作用于原字符串中的两个位置，不能凭空增加字符。
先观察：一个不同字符隔开的两个同字母块，能否借一次交换连起来？总库存又会怎样限制答案？

题解

核心洞察

先统计每种字符在全串中的总数。随后对每个目标字符维护一个窗口，使窗口内“非目标字符”最多为 1。窗口长度表示通过至多一次交换可以覆盖的区间，但结果仍不能超过该字符在全串中的库存，因此候选值是 min(窗口长度, 总库存)。

完整过程

  1. 用长度 26 的数组统计字符总数。
  2. 对每个出现过的字符分别做一次双指针扫描。
  3. 右端进入非目标字符时累计 bad；若 bad > 1，移动左端直到恢复合法。
  4. 用 min(right-left+1, count[target]) 更新答案。

正确性

合法性：窗口至多含一个异字符。若存在窗口外的目标字符，可交换进来；若不存在，库存上限会将长度截断，所以候选一定可实现。

完备性：任一最优答案在交换前对应的区间中至多只有被换出的一个异字符。扫描其目标字符时，滑动窗口一定会覆盖这个区间，因而不会遗漏最优解。两者合并可知算法返回恰好是最优值。

边界情况

  • 长度为 1：答案为 1。
  • 全部相同：库存限制答案为字符串长度。
  • 全部不同：任何目标字符库存为 1。
  • 两个同字符块之间超过一个异字符：一次交换无法完整连接。

复杂度

固定扫描 26 个字符，时间复杂度 O(26n)=O(n)，额外空间 O(26)=O(1)。

替代方案

可先进行运行长度编码：检查单个字符块能否从别处补一个字符，并检查两个相同字符块之间是否恰好隔一个字符。这也是线性时间，但相邻块索引与库存裁剪更容易写错。

四语言完整代码

class Solution {
    public int maxRepOpt1(String text) {
        int[] total = new int[26];
        for (char c : text.toCharArray()) total[c - 'a']++;
        int ans = 0;
        for (char target = 'a'; target <= 'z'; target++) {
            int left = 0, bad = 0;
            for (int right = 0; right < text.length(); right++) {
                if (text.charAt(right) != target) bad++;
                while (bad > 1) {
                    if (text.charAt(left++) != target) bad--;
                }
                ans = Math.max(ans, Math.min(right - left + 1, total[target - 'a']));
            }
        }
        return ans;
    }
}

面试追问

如果允许最多交换 k 次呢？

可把窗口条件推广为“非目标字符不超过 k”，候选仍受目标字符总库存约束；若交换规则变化为任意替换，则库存约束也会改变。

为什么不是简单取最长字符块再加一？

因为形如 aaabaaa 的两个块只隔一个字符，可以通过一次交换合并，答案可能远大于单块长度加一。

常见错误

  • 忘记用总库存裁剪，给 aaaaa 算出 6。
  • 允许窗口中出现两个异字符，相当于做了两次操作。
  • 只看相邻单块，漏掉“同字符块 + 一个缺口 + 同字符块”。
  • 把一次交换误解成必须交换；题目允许不操作。
