2341. 数组能形成多少数对

Maximum Number of Pairs in Array

两个相同的数字可以一起离场。不断重复后，会留下什么？

打开 LeetCode 原题 ↗

题目说明

给定下标从 0 开始的整数数组 nums。每次选取两个值相等的元素，把它们同时移除，记为一个数对。重复操作，直到再也找不到相等的两个元素。

返回长度为 2 的整数数组 answer = [数对数量, 剩余元素数量]。元素可以来自任意位置，不要求相邻；每个元素只能使用一次。

参数与返回值

numberOfPairs(nums: integer[]) → integer[]

约束

  • 1 ≤ nums.length ≤ 100
  • 0 ≤ nums[i] ≤ 100

官方示例 1

输入：nums = [1,3,2,1,3,2,2]
输出：[3,1]

先移除两个 1，得到 [3,2,3,2,2]；再移除两个 3，得到 [2,2,2]；最后移除两个 2，剩下 [2]。共 3 对，剩 1 个。

官方示例 2

输入：nums = [1,1]
输出：[1,0]

两个 1 组成一对，数组清空。

官方示例 3

输入：nums = [0]
输出：[0,1]

只有一个 0，无法组成数对。

先想一想：移除顺序会影响最终数对数量吗？

题解 · 相同数字的等候位

核心洞察

每种数值独立配对。如果一个数出现 c 次，最多组成 ⌊c / 2⌋ 对，剩下 c % 2 个。遍历时甚至无需保存完整频次：只需记住每个值是否有一个尚未配对的元素。

完整过程

  1. 建立长度为 101 的布尔数组 waiting，初始全为 false；数对计数 pairs = 0。
  2. 读到数字 x：若 waiting[x] 为 false，让它等待；若为 true，就和等候元素组成一对，数对数加一。
  3. 每次都翻转 waiting[x]，表示这个等候位在“空 / 有人”之间切换。
  4. 遍历结束，已用元素数为 2 × pairs，返回 [pairs, nums.length - 2 × pairs]。

正确性证明

循环不变式：处理任意前缀后，每种值 x 的等候位恰好等于其前缀出现次数的奇偶性，数对数等于各值前缀频次整除 2 的总和。

开始时频次全为 0，不变式成立。读入 x 时，若原频次为偶数，则新增一个未配对元素；若原频次为奇数，则新元素与唯一等候元素配成一对。翻转等候位后不变式继续成立，其他值不受影响。

终止时，每种值至多剩一个元素，不能再配对；且每种值已形成其理论上限 ⌊c / 2⌋ 对。因此总数对数最大，未配对元素数由 n − 2 × pairs 得出。

边界与复杂度

  • 单个元素返回 [0,1]；全不同返回 [0,n]；同值偶数次全部配完，奇数次剩一个。
  • 0 是合法值，必须使用等候状态，而不能用“数值是否为真”判断存在性；100 需要索引 100，因此数组长度为 101。
  • 时间 O(n + U)，空间 O(U)，其中 U = 101。题目值域固定时可写为时间 O(n)、额外空间 O(1)。可视化为了支持回退会重新推演前缀，与提交代码的空间开销不同。

替代方案

频次数组：先统计，再累加 count[x] / 2 的向下取整与余数，时间 O(n + U)、空间 O(U)，更便于解释。排序后相邻扫描也能完成，时间 O(n log n)，但排序可能修改输入。值域不受限时，可用哈希集合保存等待值，期望时间 O(n)、空间 O(k)。

常见错误

  • 把数对数理解为所有相同元素的组合数 c(c−1)/2：元素不能被重复使用。
  • 返回 pairs 而忘记剩余元素，或误写为 n − pairs。
  • 配对后没有清空等候位，导致同一个元素被反复配对。
  • 仅比较原数组中相邻元素，漏掉相隔较远的相同元素。

面试追问

  • 改成每 k 个相同值一组？对频次取商和余数，或保留模 k 的状态。
  • 需要输出具体原始下标？等候位保存下标，第二次遇到时输出两者并清空。
  • 流式输入怎么办？保留等候状态与 pairs，随着输入持续更新；再维护已读总数即可计算剩余量。
  • 为什么贪心立即配对不会吃亏？相同值之间可互换，且不同值不能组成数对，提前消耗两个相同值不会影响任何其他值。

Java

class Solution {
    public int[] numberOfPairs(int[] nums) {
        boolean[] waiting = new boolean[101];
        int pairs = 0;
        for (int x : nums) {
            if (waiting[x]) pairs++;
            waiting[x] = !waiting[x];
        }
        return new int[]{pairs, nums.length - 2 * pairs};
    }
}

Python 3

from typing import List

class Solution:
    def numberOfPairs(self, nums: List[int]) -> List[int]:
        waiting = [False] * 101
        pairs = 0
        for x in nums:
            if waiting[x]:
                pairs += 1
            waiting[x] = not waiting[x]
        return [pairs, len(nums) - 2 * pairs]
