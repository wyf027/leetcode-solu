子树反转和 II

选中一个节点会反转整棵子树；但任何两个被选节点的树上距离必须至少为 k。

题意（付费题，基于官方可见元数据与公开题面核验）

树以 0 为根。对任意选中的节点 u，其子树全部数值乘以 −1。选中节点两两的最短路径距离必须 ≥ k；求操作后全树节点值之和的最大可能值。

约束：2 ≤ n ≤ 5×10⁴，−4×10⁴ ≤ nums[i] ≤ 4×10⁴，1 ≤ k ≤ 50。结果必须使用 64 位整数。

输入摘要 输出 一个最优选择
edges=[[0,1],[0,2],[0,3],[1,4],[1,5]]
nums=[1,0,-10,3,4,5], k=2 		23 反转节点 2 的子树
edges=[[0,1],[0,2]
nums=[1,-5,-6], k=3 		10 反转根 0

交互：距离约束的选择

在样例 [1,-5,-6] 上切换 k，比较可选节点集合。

分步可视化：合并孩子子树

状态中的距离只需保留到 k：k 代表“最近的反转已至少 k 条边远”。

核心 DP

状态

dp[u][sign][d]：已从祖先收到的翻转奇偶为 sign，且 u 到其子树内最近反转节点的距离为 d（截断到 k）时的最大和。

不反转 u

把所有孩子按最近距离合并。两个不同孩子的最近反转距离经 u 相加必须 ≥ k；用后缀最大值把一次合并降为 O(k)。

反转 u

u 的值变号，孩子收到的 sign 翻转；每个孩子的最近反转必须距离 u 至少 k，因此孩子侧距离必须 ≥ k−1。

每个节点维护 2×(k+1) 个状态；迭代后序遍历，总时间 O(nk)，空间 O(nk)。

题解默认收起；可用 Enter 或空格展开。

题解：最小距离状态 + 子树翻转奇偶

完整过程

  1. 从 0 建根，并迭代取得后序，避免 5×10⁴ 深度递归栈溢出。
  2. 对每个节点、两种祖先翻转奇偶，各自合并孩子的“最近选点距离”。
  3. 合并时若已有最近距离 m、新孩子距离 c，必须有 m+c ≥ k。维护后缀最大值即可在 O(k) 完成一个孩子的合并。
  4. 额外尝试选 u：距离状态重置为 0，所有孩子切换奇偶并要求子状态距离 ≥ k−1。

边界、替代与追问

k=1 时相邻节点也能同时选；k 大于两叶距离时，根和不同分支之间会竞争。朴素枚举选点是指数级；两两检查距离的 O(nk²) 合并也可推导，但本题 k≤50，使用后缀最大值可达到 O(nk)。

常见错误

II 版限制的是任意两选点的树上距离，不能只检查祖先—后代；不要用 int 存结果；选中 u 后，孩子收到的翻转奇偶必须取反。
