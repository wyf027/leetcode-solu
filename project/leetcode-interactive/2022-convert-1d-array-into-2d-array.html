01 · 题目

给定下标从 0 开始的一维整数数组 original 和整数 m、n，使用全部元素构造一个 m 行、n 列的二维数组。原数组前 n 个元素组成第一行，接着的 n 个元素组成第二行，依此类推。不能丢弃、添加或重排元素；无法构造时返回空二维数组 []。

约束

  • 1 ≤ original.length ≤ 5 × 10⁴
  • 1 ≤ original[i] ≤ 10⁵
  • 1 ≤ m, n ≤ 4 × 10⁴

官方示例（含中文题面第 4 例）

输入：original = [1,2,3,4], m = 2, n = 2
输出：[[1,2],[3,4]]

第一组 [1,2] 为第一行，第二组 [3,4] 为第二行。

输入：original = [1,2,3], m = 1, n = 3
输出：[[1,2,3]]

全部三个元素构成唯一的一行。

输入：original = [1,2], m = 1, n = 1
输出：[]

两个元素无法全部放入一个位置。

输入：original = [3], m = 1, n = 2
输出：[]

一个元素无法填满两个位置。

04 · 独立题解
先尝试自己解释：什么情况下可以完成排列？如何确定每个元素的位置？





核心洞察
容量必须恰好等于元素数量：m × n = original.length。一行占据连续的 n 个位置，所以第 i 个元素对应行 ⌊i / n⌋、列 i % n。


完整过程
  1. 先判断容量。数量不同立即返回 []，避免无意义分配。
  2. 创建 m 个独立的行数组，每行 n 列。
  3. 遍历 i = 0 到 L − 1，将 original[i] 放进 ans[⌊i/n⌋][i%n]。
  4. 返回 ans。以 [1,2,3,4,5,6]、m=2、n=3 为例：下标 0、1、2 落在第 0 行，下标 3、4、5 落在第 1 行。


正确性
必要性：目标有 m×n 个位置，每个原元素必须使用一次，故元素数量必须与位置数相等。充分性：数量相等时，任意 i∈[0,mn) 都唯一写作 i=rn+c，其中 0≤r<m、0≤c<n。商和余数因此把每个原下标映射到唯一有效格子，且覆盖所有格子。遍历每一步都保持“前 i 个元素已按行优先顺序正确放入”的不变式；终止时全部元素均正确放置，满足题意。


边界与复杂度
m=1 时只有一行；n=1 时每个元素单独成行；重复值不影响位置映射。过多和过少都返回 []，不能补零或截断。官方约束不包含空数组。令 L=original.length：成功时耗时 O(L)，返回数组占 O(L)，除返回数组外额外空间 O(1)；失败时耗时、空间均 O(1)。这里的四份实现均不修改 original。


替代方案
按行切片：第 r 行取 original[r*n : (r+1)*n]，更贴近题面；复制总量仍是 L，复杂度不变。也可用双重循环并维护原数组下标，避免除法取模。无需排序、搜索或动态规划。


常见错误
  • 用 m 作为除数或分组大小；每行长度是 n。
  • 用同一个行数组填满所有行，造成引用共享；每行必须独立创建。
  • 先分配矩阵再检查容量；不匹配输入可能申请大量无用内存。
  • 把空二维数组写成 [[]]；后者有一行，并非空数组。


面试追问
  • 能零拷贝吗？一般二维数组需复制或组织新行；支持视图的库可以共享底层内存，但修改会相互影响。
  • 如果输入是流？每 n 个值收成一行，结束时仍需确认总数恰好为 mn。
  • 若扩大尺寸范围？Java/C++ 的乘法应使用宽整数。当前最大乘积 1.6×10⁹ 未超有符号 32 位范围，下面仍使用宽整数比较。


Java
class Solution {
    public int[][] construct2DArray(int[] original, int m, int n) {
        if ((long) m * n != original.length) return new int[0][0];
        int[][] ans = new int[m][n];
        for (int i = 0; i < original.length; i++) {
            ans[i / n][i % n] = original[i];
        }
        return ans;
    }
}


JavaScript
/**
 * @param {number[]} original
 * @param {number} m
 * @param {number} n
 * @return {number[][]}
 */
var construct2DArray = function(original, m, n) {
    if (m * n !== original.length) return [];
    const ans = Array.from({length: m}, () => Array(n));
    for (let i = 0; i < original.length; i++) {
        ans[Math.floor(i / n)][i % n] = original[i];
    }
    return ans;
};


Python 3
from typing import List

class Solution:
    def construct2DArray(self, original: List[int], m: int, n: int) -> List[List[int]]:
        if m * n != len(original):
            return []
        ans = [[0] * n for _ in range(m)]
        for i, value in enumerate(original):
            ans[i // n][i % n] = value
        return ans


C++
#include <vector>
using std::vector;

class Solution {
public:
    vector<vector<int>> construct2DArray(vector<int>& original, int m, int n) {
        if (1LL * m * n != static_cast<long long>(original.size())) return {};
        vector<vector<int>> ans(m, vector<int>(n));
        for (int i = 0; i < static_cast<int>(original.size()); ++i) {
            ans[i / n][i % n] = original[i];
        }
        return ans;
    }
};
