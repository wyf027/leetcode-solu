883. 三维形体投影面积

把一座由单位立方体搭成的微型城市，从上、前、侧三个方向看。你看到的三片“影子”，合起来有多大？

Projection Area of 3D Shapes函数：projectionArea(grid)返回：integer
Problem

题目描述

先理解空间关系，再打开题解。

给定一个 n × n 网格 grid，grid[i][j] = v 表示在格子 (i, j) 上竖直叠放了 v 个与坐标轴对齐的单位立方体。

分别把整个三维形体投影到 xy、yz 和 zx 平面——也就是从顶部、前方与侧面观察它的影子。返回三个投影面积之和。

约束

  • n == grid.length == grid[i].length
  • 1 <= n <= 50
  • 0 <= grid[i][j] <= 50
输入： grid = [[1,2],[3,4]] 输出： 17 解释： 三个轴对齐平面上的投影面积总和为 17。
输入： grid = [[2]] 输出： 5
输入： grid = [[1,0],[0,2]] 输出： 8

Solution unlocked

把三个方向，变成三种计数

空间题的关键不在“搭出”立方体，而在识别每个观察方向究竟保留了二维网格中的什么信息。

核心洞察

答案 = 非零格子数 + 各行最大值之和 + 各列最大值之和
  • 俯视：每个非零格子贡献 1。
  • 正视：每一行只有最高塔决定轮廓。
  • 侧视：每一列只有最高塔决定轮廓。

完整过程

  1. 初始化 top = front = side = 0。
  2. 逐个访问 grid[i][j]；值大于 0 时，俯视面积加 1。
  3. 对每一行取最大值，累加到正视面积。
  4. 对每一列取最大值，累加到侧视面积。
  5. 返回三部分之和。

正确性说明

俯视投影：格子上只要存在至少一个立方体，投影就恰好覆盖一个单位方格，因此非零格子数等于俯视面积。

正视投影：固定一行后，该观察线上所有塔彼此遮挡；投影在竖直方向覆盖的单位格数恰好等于该行最大高度。对所有行求和得到正视面积。

侧视投影：同理，固定一列时投影高度等于该列最大值，对所有列求和得到侧视面积。

三个投影分别位于不同平面，题目要求它们的面积之和，所以把三部分相加即得到正确答案。

复杂度与边界

时间复杂度：O(n²)，每个网格元素只做常数次处理。

空间复杂度：O(1) 额外空间（不计输入）。

  • 全零网格：三个投影都为 0。
  • 单格塔高 h：h = 0 时为 0；否则总面积为 1 + 2h。
  • 不需要构造真实立方体，也不需要对高度逐层扫描。

替代方案

可以分别用三次遍历计算三部分，或者预先保存行/列最大值数组。它们同样是 O(n²)，但一次双层遍历可同时完成，常数与代码长度更优。

四种语言完整代码

JavaO(n²) · O(1)
class Solution {
    public int projectionArea(int[][] grid) {
        int n = grid.length;
        int top = 0, front = 0, side = 0;

        for (int i = 0; i < n; i++) {
            int rowMax = 0;
            int colMax = 0;
            for (int j = 0; j < n; j++) {
                if (grid[i][j] > 0) {
                    top++;
                }
                rowMax = Math.max(rowMax, grid[i][j]);
                colMax = Math.max(colMax, grid[j][i]);
            }
            front += rowMax;
            side += colMax;
        }
        return top + front + side;
    }
}

常见错误

  • 把俯视面积写成所有高度之和；俯视只关心格子是否非零。
  • 正视、侧视使用行和列的“总和”；遮挡关系要求取最大值。
  • 行列下标混淆，导致两个方向重复计算。
  • 按高度逐层模拟，虽然可能正确，却把复杂度不必要地放大到 O(n²h)。

面试追问

  • 如果网格不是正方形？ 分别遍历 m 行与 n 列，思路不变。
  • 如果问表面积？ 必须计算外露面，并扣除相邻立方体贴合的面，不能沿用投影公式。
  • 能否流式处理？ 行最大值可立即累加；列最大值需保留一个长度为列数的数组，空间为 O(n)。
  • 为什么不能把三维体积作为中间量？ 投影由轮廓决定，体积相同的形体可能具有不同投影。
