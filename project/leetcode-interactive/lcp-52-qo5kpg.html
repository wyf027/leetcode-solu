LCP 52 · 二叉搜索树染色

反过来处理操作：第一次覆盖某个节点值的操作，就是它最终颜色。并查集会把已确定的有序位置直接跳过。

节点 ≤ 10⁵操作 ≤ 10⁵O((n + q) log n)

题意

给定节点值互不重复的二叉搜索树。初始全蓝；ops[i] = [type, x, y] 把值在闭区间 [x, y] 的节点染成蓝色（type = 0）或红色（type = 1）。返回最终红色节点数。题目保证每次 x、y 都是树中节点值。

root = [1,null,2,null,3,null,4,null,5]
ops = [[1,2,4],[1,1,3],[0,3,5]]
最终红色为值 1、2，答案 2。

BST 的关键贡献

中序遍历后，节点值严格递增。每个染色操作不再是“树形范围”，而是排序数组上的一段连续下标。

逆序染色实验室

从最后一条操作向前走；已确定的位置会由 DSU 直接跳过。

准备从最后一次操作开始。

尚未执行

每个值只会被第一次（逆序意义下）命中的操作写入一次。

核心洞察

  1. 中序遍历得到升序数组 vals；二分找每次区间的左右下标。
  2. 正序会反复覆盖。改为逆序后，一个还没决定颜色的节点首次被覆盖的操作，恰好就是最终操作。
  3. DSU 的 find(i) 表示“从 i 起第一个未处理位置”。处理 i 后令其父亲指向 find(i+1)，下次会跳过它。
  4. 只有逆序首次覆盖且 type=1 时，答案加一。

完整过程

将所有节点压为有序位置 0…n−1。每条逆序操作用 lowerBound 找到 x 的位置，以 y 的位置为终点；从 DSU 找到的首个未处理位置开始，直到超过终点。每个位置至多被访问一次。

边界与替代方案

区间端点一定在树内，避免了“端点不在 vals”歧义。线段树区间赋值也可做，复杂度 O(q log n)，但本题只要最终红色总数，逆序 DSU 更轻量。

常见错误 / 面试追问

不要按树结构逐节点查询；不要在正序里用 DSU（颜色会被覆盖）。若要求每一步红色数，需懒标记线段树维护区间和。
