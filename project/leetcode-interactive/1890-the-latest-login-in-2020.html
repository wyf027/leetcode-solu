时间有边界。你能为每位用户，找到属于这一年的最后一条记录吗？

01 / 任务与数据

给定登录记录表 Logins，找出每位在 2020 年至少登录过一次的用户，以及该用户在 2020 年内最晚的登录时间。没有在这一年登录的用户不出现在结果中。

Logins 表结构
列名类型含义
user_idint用户编号
time_stampdatetime登录时间

返回形式与约束

  • 输出两列：user_id、last_stamp；每位符合条件的用户仅一行。
  • 结果顺序不限；数据原始顺序没有保证。
  • 联合主键为 (user_id, time_stamp)，该组合唯一。
  • 每条记录表示一位用户的一次登录；官方未给出额外的行数上限或数值范围。

04 / 独立题解与交互推演

核心洞察：先限定年份，再取每组的最晚时间

目标是“2020 年内的最大值”，而不是“所有年份的最大值恰好落在 2020”。先用左闭右开的区间筛选，再按用户分组，最后对时间取 MAX。

  1. 保留 2020-01-01 00:00:00 ≤ time_stamp < 2021-01-01 00:00:00。
  2. 用 GROUP BY user_id 将合格记录归入用户。
  3. 用 MAX(time_stamp) AS last_stamp 输出组内最晚时间。

正确性

过滤条件恰好覆盖 2020 全年，所以后续分组不可能混入其他年份。每位在 2020 年登录过的用户至少留下一行，因此必然产生一个组；没有合格记录的用户没有组。组内的最大时间就是这位用户在这一年的最后登录时间，每组输出一行，故结果既完整又无多余用户。

对交互中的逐行版本，可使用不变式：处理前 k 行后，每个时间槽保存这些行中该用户所有合格时间的最大值。无效年份不改变状态，合格行通过取较大值保持不变式；处理全部行后即得到目标结果。

边界与常见错误

  • 2020 年第一秒必须包含，2021 年第一秒必须排除；左闭右开也覆盖数据库支持的小数秒，不必猜测年末的最大精度。
  • 空表、完全没有 2020 年记录：返回空结果表，仍有指定列名。
  • 先对全表求最大值再筛年份会漏掉在 2020 和 2021 都登录过的用户，例如用户 6。
  • 仅按用户分组却直接选择非聚合的时间列，无法保证得到最晚时间；遗漏别名 last_stamp 会导致输出列名不符。
  • 联合主键允许同一用户有多个时间，也允许不同用户同一时刻登录。记录乱序不影响最大值。

复杂度与替代方案

设总行数为 n，筛选后为 m 行，涉及 u 位用户。一次扫描配合哈希聚合的典型时间为 O(n)，聚合额外空间 O(u)。这些是实现模型的估计；SQL 的实际成本取决于索引、优化器及聚合策略，排序聚合可能需要 O(m log m)。四份本地参考采用哈希表，期望时间 O(n)、空间 O(u)，返回结果也占 O(u)。

YEAR(time_stamp) = 2020 在 MySQL 中也能表达筛选，但列上的函数通常不如直接范围条件容易利用普通时间索引。先筛选后使用 ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY time_stamp DESC)，取序号 1 也可；仅取最大时间时，聚合更直接。

面试追问

  • 还要返回最后一次登录的设备？用窗口函数选择整行，或先聚合后连接原表；扩展数据若有并列时间，需要明确决胜规则。
  • 数据量很大怎么办？结合查询计划评估以 time_stamp 开头的索引及覆盖 user_id 的可能收益；收益取决于 2020 年数据占比，不能仅凭 SQL 文本断言。
  • 如果按业务时区划年？先定义业务时区，再将年度边界换算到存储时间基准。本题 datetime 未给出时区转换要求。
  • 需要包括全年未登录用户？需要独立的用户全集，再左连接年度聚合结果；仅靠 Logins 无法获知从未登录的用户。

MySQL · 官方可提交

SELECT user_id, MAX(time_stamp) AS last_stamp
FROM Logins
WHERE time_stamp >= '2020-01-01 00:00:00'
  AND time_stamp <  '2021-01-01 00:00:00'
GROUP BY user_id;

Java · 本地语义参考

import java.util.*;

public class Solution {
    public static class Login {
        final int userId;
        final String timeStamp;
        public Login(int userId, String timeStamp) {
            this.userId = userId;
            this.timeStamp = timeStamp;
        }
    }
    public static Map<Integer, String> latestLogin(List<Login> logins) {
        Map<Integer, String> result = new HashMap<>();
        for (Login row : logins) {
            String t = row.timeStamp;
            if (t.compareTo("2020-01-01 00:00:00") >= 0 &&
                t.compareTo("2021-01-01 00:00:00") < 0) {
                result.merge(row.userId, t,
                    (a, b) -> a.compareTo(b) >= 0 ? a : b);
            }
        }
        return result; // user_id -> last_stamp
    }
}

JavaScript · 本地语义参考

// Input: [{user_id: number, time_stamp: string}]
// Output: [{user_id: number, last_stamp: string}]
function latestLogin(logins) {
  const latest = new Map();
  for (const {user_id, time_stamp: t} of logins) {
    if (t >= "2020-01-01 00:00:00" && t < "2021-01-01 00:00:00") {
      if (!latest.has(user_id) || t > latest.get(user_id)) {
        latest.set(user_id, t);
      }
    }
  }
  return Array.from(latest, ([user_id, last_stamp]) => ({user_id, last_stamp}));
}

Python · 本地语义参考（非 Pandas 提交）

def latest_login(logins):
    # Input: list of dicts with user_id and time_stamp.
    latest = {}
    for row in logins:
        user_id, t = row["user_id"], row["time_stamp"]
        if "2020-01-01 00:00:00" <= t < "2021-01-01 00:00:00":
            if user_id not in latest or t > latest[user_id]:
                latest[user_id] = t
    return [{"user_id": user_id, "last_stamp": t}
            for user_id, t in latest.items()]

C++ · 本地语义参考

#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

struct Login { int user_id; string time_stamp; };
struct Result { int user_id; string last_stamp; };

class Solution {
public:
    vector<Result> latestLogin(const vector<Login>& logins) {
        unordered_map<int, string> latest;
        for (const auto& row : logins) {
            const string& t = row.time_stamp;
            if (t >= "2020-01-01 00:00:00" && t < "2021-01-01 00:00:00") {
                auto it = latest.find(row.user_id);
                if (it == latest.end() || t > it->second)
                    latest[row.user_id] = t;
            }
        }
        vector<Result> result;
        for (const auto& entry : latest)
            result.push_back({entry.first, entry.second});
        return result;
    }
};
