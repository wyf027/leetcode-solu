832. 翻转图像Flipping an Image

给定一个 n × n 的二进制矩阵，先把每一行水平翻转，再将每个像素取反，返回最终图像。

简单 数组 双指针 矩阵 位运算

Official signature

flipAndInvertImage(image: integer[][]): integer[][]
  • 参数image
  • 返回翻转并取反后的矩阵
  • 规模1 ≤ n ≤ 20

01 · Problem

任务说明

矩阵中的每个元素都是一个二进制像素：0 或 1。

两个连续操作

水平翻转
将每一行逆序。例如，[1, 1, 0] 会变为 [0, 1, 1]。
图像反转
把所有 0 替换成 1，并把所有 1 替换成 0。

约束

  • n == image.length
  • n == image[i].length
  • 1 ≤ n ≤ 20
  • image[i][j] 只能是 0 或 1

05 · Solution

准备好再揭晓题解

建议先用上方实验室完成至少一轮推演，再对照核心洞察与代码。

Revealed

双指针：交换与取反合并

对每一行使用左右指针，把“翻转后应该来到当前位置的值”直接取反并写入，从而在一次遍历中完成两种操作。

O(n²) / O(1)

核心洞察

一行中位置 left 的最终值来自原位置 right，并且还要取反；二进制取反可以写成 value ^ 1。

完整过程

  1. 逐行处理矩阵。
  2. 令左右指针分别指向行首、行尾。
  3. 交换两端来源，同时对写入值异或 1。
  4. 两指针向中间移动，直到相遇或交错。

正确性说明

循环不变式：每轮处理之前，区间外的像素都已经等于“原行水平翻转后再取反”的目标值，区间内尚未处理。

本轮把原右端的取反值写入左端、把原左端的取反值写入右端，恰好得到两个目标位置的正确结果，因此不变式继续成立。若左右指针相遇，该中心像素的位置经翻转不变，只需取反一次。当指针交错时，整行全部正确；逐行处理后，整个矩阵正确。

时间复杂度 O(n²)矩阵共有 n² 个像素，每个像素只处理一次。
额外空间 O(1)直接在输入矩阵上修改，只使用常数个变量。

四语言完整代码

class Solution {
    public int[][] flipAndInvertImage(int[][] image) {
        for (int[] row : image) {
            int left = 0;
            int right = row.length - 1;

            while (left <= right) {
                int invertedLeft = row[right] ^ 1;
                int invertedRight = row[left] ^ 1;
                row[left] = invertedLeft;
                row[right] = invertedRight;
                left++;
                right--;
            }
        }
        return image;
    }
}

from typing import List


class Solution:
    def flipAndInvertImage(
        self, image: List[List[int]]
    ) -> List[List[int]]:
        for row in image:
            left, right = 0, len(row) - 1

            while left <= right:
                row[left], row[right] = (
                    row[right] ^ 1,
                    row[left] ^ 1,
                )
                left += 1
                right -= 1

        return image
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> flipAndInvertImage(
        vector<vector<int>>& image
    ) {
        for (vector<int>& row : image) {
            int left = 0;
            int right = static_cast<int>(row.size()) - 1;

            while (left <= right) {
                int invertedLeft = row[right] ^ 1;
                int invertedRight = row[left] ^ 1;
                row[left] = invertedLeft;
                row[right] = invertedRight;
                ++left;
                --right;
            }
        }
        return image;
    }
};

边界情况

  • n = 1：中心元素只需取反一次。
  • 奇数行宽：左右指针最终相遇于中心。
  • 全 0 / 全 1：翻转不改变排列，但仍要逐位取反。
  • 回文行：即使翻转后相同，也不能跳过取反。

替代方案

  • 先调用行反转，再遍历全部元素取反：同为 O(n²)，但执行两趟。
  • 构造新矩阵，令 ans[i][j] = image[i][n-1-j] ^ 1：更直观，但需 O(n²) 额外空间。

面试追问

  • 如果不能修改输入，如何调整空间复杂度？
  • 为何异或 1 能完成二进制取反？
  • 矩阵不是方阵时，算法是否仍然成立？
  • 能否只在对称位相等时修改，以减少写操作？

常见错误

  • 循环条件写成 left < right，漏掉奇数长度的中心元素。
  • 直接覆盖左端后再读取它，导致右端拿到被修改的值。
  • 只翻转顺序，忘记执行 0/1 取反。
  • 额外创建整张结果图，却误报空间复杂度为 O(1)。
