3844. 最长的准回文子字符串

把“允许删一次”装进中心扩展：第一次不匹配时，分别尝试跳过左端或右端。

题意

给定小写字符串 s。若一个非空子串删除恰好一个字符后成为回文，它就是准回文串。返回最长长度。

示例

s = "abca"，删除 c 后为 "aba"，答案是 4。

s = "zzabba"，可取 "zabba"，答案为 5。

约束

2 ≤ s.length ≤ 2500，且仅含小写英文字母。必须避免枚举所有子串再逐个线性验证的 O(n³)。

交互：从中心向两侧扩展

核心洞察

枚举奇、偶两类中心。指针相等就继续外扩；遇到第一次不相等，删除左端或删除右端二选一，再继续扩展。之后若仍不等，该分支无解。一个原本就是回文的长度至少为 2 的窗口，也可以删掉中间字符后保持回文。

完整过程

  1. 枚举 (i,i) 和 (i,i+1)。
  2. 匹配则同步收缩/扩张。
  3. 首次失配递归（或迭代）尝试跳左、跳右。

边界

长度 2 只有相同字符才可删一位成为回文；首次失配可能在任一端；全回文窗口可删除一个中心字符。

复杂度

每个中心最多形成两个一次删除分支，每次线性扩展。时间 O(n²)，额外空间 O(1)（递归深度最多 1）。

替代方案、面试追问与常见错误

  • DP 可记录区间是否至多删除一次，空间 O(n²)，但不如中心扩展直观。
  • 追问：若允许删除 k 次，可把状态扩展为 (left, right, remaining)，需额外控制复杂度。
  • 常见错误：失配时只跳过一侧；把“子串”误写成“子序列”；忘记偶数中心。
