Problem Brief

题意

给定一个元素互不相同、按升序排列的整数数组，创建一棵高度最小的二叉搜索树。

官方样例

输入 nums = [-10,␠-3,␠0,␠5,␠9]
一个可能的输出 [0,␠-3,␠9,␠-10,␠null,␠5]

Construction Contract

  • 中序遍历必须还原原数组。
  • 每个节点左右子树的规模尽量接近。
  • 空数组返回空树；答案不唯一。
  • 官方页面未单列数组长度与数值范围。

可见空格：代码中的 ␠ 表示普通空格，便于完整核对参数；null 表示该层序位置没有节点。

Sealed Blueprint

题解

核心洞察、完整过程、边界、复杂度、替代方案、追问、错误与四语言代码默认隐藏。

核心洞察

高度最小意味着根的左右子树规模必须尽量接近。有序数组的中点正好把区间分成大小至多相差 1 的两段，同时左段全小于根、右段全大于根。

完整过程

  1. 函数接收闭区间 [left, right]。
  2. left > right 时返回 null。
  3. 选上中点，创建根节点。
  4. 左右区间递归挂到根的左右指针。

边界与复杂度

  • 空数组：返回空树。
  • 单元素：该元素就是根。
  • 偶数长度：上中点或下中点都能得到最小高度。
  • 时间 O(n)；递归栈 O(log n)，输出树占 O(n)。

替代方案

可以按中点顺序把值逐个插入普通 BST，但每次插入还要从根查找位置，最坏会多出遍历成本；直接递归连接节点更简洁。

面试追问

  • 如何证明中点分割达到理论最小高度？
  • 若输入是有序链表，如何避免随机访问？
  • 如何改成显式栈的迭代构造？

常见错误

  • 区间边界混用，导致漏元素或死递归。
  • 用数组切片，产生额外 O(n log n) 拷贝。
  • 误以为官方层序输出是唯一答案。
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    private TreeNode build(int[] nums, int left, int right) {
        if (left > right) return null;
        int mid = left + (right - left + 1) / 2;
        TreeNode root = new TreeNode(nums[mid]);
        root.left = build(nums, left, mid - 1);
        root.right = build(nums, mid + 1, right);
        return root;
    }
}

    const mid = left + Math.floor((right - left + 1) / 2);

    root.left = build(left, mid - 1);
    root.right = build(mid + 1, right);
    return root;
  }
  return build(0, nums.length - 1);
};

        int mid = left + (right - left + 1) / 2;

        root->left = build(nums, left, mid - 1);
        root->right = build(nums, mid + 1, right);
