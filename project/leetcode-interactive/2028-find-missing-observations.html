找出缺失的观测数据

2028 / Find Missing Observations

不完整的骰子记录，完整的平均值。补回丢失的数据。

题意

六面骰子共投掷 m + n 次，每次结果为 1 至 6。数组 rolls 保存了其中 m 次观测，另外 n 次丢失。已知全部结果的精确平均值 mean，请返回长度为 n 的整数数组，使补全后的平均值恰好等于 mean。

存在多个答案时返回任意一个；不可能补全时返回 []。不要求恢复原始顺序。平均值是总和除以数量，mean 为整数。

参数：missingRolls(rolls, mean, n) → 整数数组

  • m == rolls.length
  • 1 ≤ n, m ≤ 10⁵
  • 1 ≤ rolls[i], mean ≤ 6
官方题目

官方示例

示例 1

rolls = [3,2,4,3], mean = 4, n = 2
输出：[6,6]

总和为 24，共 6 次，平均值为 4。

示例 2

rolls = [1,5,6], mean = 3, n = 4
输出：[2,3,2,2]

总和为 21，共 7 次，平均值为 3。

示例 3

rolls = [1,2,3,4], mean = 6, n = 4
输出：[]

不论缺失值如何取，平均值都达不到 6。

示例 4 · 官方中文元数据

rolls = [1], mean = 3, n = 1
输出：[5]

(1 + 5) / 2 = 3。

题解 · 缺失总和的分配

核心洞察与完整过程

  1. 目标总和为 mean × (m + n)，减去 sum(rolls)，得到缺失总和 S。
  2. 若 S < n 或 S > 6n，则无解。
  3. 求 q = ⌊S / n⌋、r = S mod n。
  4. 填入 n 个 q，给前 r 个位置各加 1，即可完成。

查看目标、区间和每一步的点数分配。演示限制 n ≤ 60，代码支持完整约束。

这是算法演示，不是测试结果。开启减少动态效果时，播放间隔为 2.5 秒。


正确性
必要性：n 个合法点数的和必在 [n, 6n]，越界必然无解。
合法性：区间内 q ≥ 1 且 q ≤ 6。若 r > 0，则 q 不可能等于 6，否则 S > 6n。因此所有 q 或 q + 1 都在 1..6。
充分性：n 个数的总和为 nq + r = S，加上已知总和等于 mean × (m + n)，故平均值正确。
边界与复杂度
S = n 时全为 1；S = 6n 时全为 6；r = 0 时所有点数相同；n = 1 时结果唯一。总和过大或过小都要返回 []。
时间 O(m + n)，无解时 O(m)。输出空间 O(n)，额外辅助空间 O(1)。最大目标总和 1200000，Java/C++ int 足够。
替代方案
先填 n 个 1，再把 S − n 逐个分配，每个位置最多增加 5。复杂度相同，结果更偏向两端。回溯和动态规划没有必要。
常见错误
  • 把目标总和写成 mean × n，遗漏 m。
  • 只检查上界，忘记每个骰子至少为 1。
  • 使用四舍五入代替向下取整，破坏总和。
  • 要求输出和示例逐项一致，忽略多解。
面试追问
范围改为 [L,U]：先判断 nL ≤ S ≤ nU，再均匀分配，或从 L 开始填充。
字典序最小：当前取 max(1, 剩余和 − 6 × 后续数量)，把尽可能多的点数留给后面。
平均值是有理数：使用分子和分母计算目标总和，先判整除，避免浮点误差。

Java
class Solution {
    public int[] missingRolls(int[] rolls, int mean, int n) {
        int s = mean * (rolls.length + n);
        for (int x : rolls) s -= x;
        if (s < n || s > 6 * n) return new int[0];
        int q = s / n, r = s % n;
        int[] ans = new int[n];
        for (int i = 0; i < n; i++) ans[i] = q + (i < r ? 1 : 0);
        return ans;
    }
}

var missingRolls = function(rolls, mean, n) {
    const s = mean * (rolls.length + n) - rolls.reduce((a, b) => a + b, 0);
    if (s < n || s > 6 * n) return [];
    const q = Math.floor(s / n), r = s % n;
    return Array.from({length: n}, (_, i) => q + (i < r ? 1 : 0));
};
Python 3
from typing import List

class Solution:
    def missingRolls(self, rolls: List[int], mean: int, n: int) -> List[int]:
        s = mean * (len(rolls) + n) - sum(rolls)
        if s < n or s > 6 * n:
            return []
        q, r = divmod(s, n)
        return [q + (1 if i < r else 0) for i in range(n)]

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> missingRolls(vector<int>& rolls, int mean, int n) {
        int s = mean * (static_cast<int>(rolls.size()) + n);
        for (int x : rolls) s -= x;
        if (s < n || s > 6 * n) return {};
        int q = s / n, r = s % n;
        vector<int> ans(n, q);
        for (int i = 0; i < r; ++i) ++ans[i];
        return ans;
    }
};
