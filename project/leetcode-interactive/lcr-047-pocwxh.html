二叉树剪枝

给你一棵仅含 0 和 1 的二叉树。删除所有不包含 1 的子树，返回剪枝后的根节点。

核心思路：先处理孩子，再决定自己

  1. 1递归剪枝左、右子树，得到已经处理好的孩子节点。
  2. 2若当前节点值为 0，且两个孩子都为空，则当前整棵子树没有 1，返回空。
  3. 3否则保留当前节点。每个节点恰好访问一次，时间复杂度 O(n)，递归栈最坏 O(h)。
为什么是后序？ 父节点能否保留取决于“剪完之后”的左右子树；必须先知道孩子是否仍含 1。

约束与边界

  • • 节点值只可能为 0 或 1。
  • • 空树仍返回空树。
  • • 一个值为 0 的祖先，只要后代有 1，也必须保留。
  • • 原地复用保留下来的节点，无需额外建树。

示例与交互步骤

演示器使用层序数组，还原题目中的二叉树。

示例

输入 [1,null,0,0,1]：右侧的 0 节点因后代存在 1 而保留；其左孩子 0 被删除。输出为 [1,null,0,null,1]。

如何使用

输入有效 JSON 数组后点击“执行剪枝”。红色节点表示原树中的 0，蓝绿色节点表示剪枝后保留的节点；下方会按后序展示决策。

完整过程

对任一节点，先递归得到剪枝后的左、右孩子。此时若节点自身为 0 且两个孩子为空，说明以它为根的子树没有 1，向父节点返回空；其余情形返回当前节点。根节点返回空时，答案就是空树。

边界

空节点直接返回；单个 0 返回空；单个 1 保留。

替代方案

可先收集所有含 1 的根到叶路径再重建树，但需要额外结构，且不如原地后序简洁。

面试追问

若值不限于 0/1，可将条件推广为“子树是否含目标值”。

常见错误

先序时过早删除值为 0 的祖先，会误删其后代的 1；还要把递归返回值重新赋回 left、right，否则剪枝结果不会连回原树。
