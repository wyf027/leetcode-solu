Transmission brief

题意

数字字符串按 1 → A、2 → B，一直到 26 → Z 解码。返回完整字符串的合法解码方案数；如果无法完整解码，返回 0。

  • 1 ≤ s.length ≤ 100
  • s 只包含数字，且可能以 0 开头
  • 答案保证在 32 位整数范围内

输入代码里的 ␠ 表示可见空格，确保参数名、等号和值完整呈现；字符串保留成对直引号。

Core insight

只看最后一段来自哪里

设 dp[i] 为前 i 个字符的解码数。若第 i 个字符能单独解码，就加 dp[i-1]；若最后两个字符是 10–26，就再加 dp[i-2]。 状态只依赖前两项，因此可压缩为两个变量。

Complete process

从空前缀向右扫描

  1. 1. 初始化 prev2 = 1，表示空前缀。
  2. 2. prev1 取决于首字符是否为 0。
  3. 3. 从第二个字符起分别检查单码、双码。
  4. 4. 令 current 等于两条有效线路的贡献之和。
  5. 5. 左移两个滚动变量，最终返回 prev1。

Boundaries

0 是规则核心

  • "0"、"06"：0 种。
  • "10"、"20"：只能成对，1 种。
  • "30"：单码 0 无效，双码 30 也无效。
  • "101"：只能分为 10|1。

Complexity

线性时间，常数空间

时间
O(n)
额外空间
O(1)

替代方案取舍

记忆化搜索同样是 O(n)，更贴近“选 1 位或 2 位”的递归定义，但有递归栈；完整 DP 数组便于打印路径，却多用 O(n) 空间。面试主线优先滚动 DP。

面试追问

  • 如果加入通配符 *，转移如何计数？
  • 如何恢复一条具体解码路径？
  • 为什么 dp[0] 必须是 1？

常见错误

  • 把 0 当作可独立映射的字符。
  • 用 1–26 判断两位数，误收 "06"。
  • 遇到一个无效前缀就提前返回，忽略后续状态语义。
class Solution {
    public int numDecodings(String s) {
        int prev2 = 1;
        int prev1 = s.charAt(0) == '0' ? 0 : 1;

        for (int i = 2; i <= s.length(); i++) {
            int current = 0;
            if (s.charAt(i - 1) != '0') {
                current += prev1;
            }
            int pair = (s.charAt(i - 2) - '0') * 10
                    + (s.charAt(i - 1) - '0');
            if (pair >= 10 && pair <= 26) {
                current += prev2;
            }
            prev2 = prev1;
            prev1 = current;
        }
        return prev1;
    }
}

var numDecodings = function (s) {
    let prev2 = 1;
    let prev1 = s[0] === "0" ? 0 : 1;

    for (let i = 2; i <= s.length; i++) {
        let current = 0;
        if (s[i - 1] !== "0") current += prev1;

        const pair = Number(s.slice(i - 2, i));
        if (pair >= 10 && pair <= 26) current += prev2;

        prev2 = prev1;
        prev1 = current;
    }
    return prev1;
};
