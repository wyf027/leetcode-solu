跨越数组边界的最大子数组

K 次串联后最大子数组之和

不需要真的铺开十万份数组。先看清最优子数组如何跨过“接缝”，再用两次扫描和一个公式收束答案。

题目

给定整数数组 arr 和整数 k，把 arr 连续重复 k 次形成新数组。返回新数组的最大子数组和。允许选择长度为 0 的子数组，因此答案至少为 0；最终结果对 10⁹ + 7 取模。

函数形式： kConcatenationMaxSum(arr, k) → integer
示例 1
输入：arr = [1,2], k = 3
输出：9
解释：串联数组为 [1,2,1,2,1,2]，全部选择得到 9。
示例 2
输入：arr = [1,-2,1], k = 5
输出：2
解释：最优选择可跨过一次接缝，例如末尾 1 与下一份开头 1。
示例 3
输入：arr = [-1,-2], k = 7
输出：0
解释：所有非空子数组和均为负，选择空子数组。
约束
1 ≤ arr.length ≤ 10⁵
1 ≤ k ≤ 10⁵
−10⁴ ≤ arr[i] ≤ 10⁴

完整题解

先独立思考，再按需展开。题解包含推导、证明、边界与四种语言实现。

题解：只扫描两份，压缩中间副本

核心洞察

任意跨越多份数组的连续子数组，都由“第一份的后缀 + 若干完整副本 + 最后一份的前缀”组成。若单份数组总和 S ≤ 0，加入完整副本不会更优；若 S > 0，最优解会尽量收入中间的 k−2 份。

扫描上限

k=1 扫一份；k>1 扫两份，捕捉所有接缝形态。

→
中间收益

若 S>0，再加上 (k−2)×S；否则不加。

→
最后取模

先比较真实大小，最终答案再对 10⁹+7 取模。

完整过程

  1. 计算单份数组元素总和 S。
  2. 用允许空子数组的 Kadane 算法扫描 min(k, 2) 份：每步令 current = max(0, current + x)，并更新 best。
  3. 当 k > 2 且 S > 0 时，将中间 k−2 份完整数组的正收益加入：best += (k−2) × S。
  4. 返回 best mod (10⁹+7)。
等价公式： k=1 时答案为 Kadane(arr)；k>1 时答案为 Kadane(arr+arr) + max(0,(k−2)×sum(arr))。

正确性证明

引理 1：k=1 时，Kadane 算法维护“以当前位置结尾的最大非负连续和”，其历史最大值就是允许为空的最大子数组和。

引理 2：跨越至少一个接缝的候选，由起始副本后缀、结束副本前缀以及二者之间的完整副本组成。前后边界的所有组合都能在两份连续数组中出现，因此两份 Kadane 已找出最佳边界贡献。

引理 3：中间每个完整副本贡献均为 S。S>0 时全部加入最优，S≤0 时加入任何一个都不会改善答案。

结论：算法同时覆盖单份内部候选与所有跨接缝候选，并按 S 的符号最优处理完整中间副本，所以得到全局最优。

边界与复杂度

  • 全负：current 每次归零，返回 0。
  • k=1：不能套用中间副本公式，只扫描一份。
  • S=0：多加完整副本不改变和，两份扫描已足够。
  • 大数：Java/C++ 用 64 位整数；JavaScript 的上界仍在安全整数范围内。
  • 取模：必须在完成最大值判断后取模，不能用取模后的值比较大小。

时间：O(n)，最多访问 2n 个元素。
额外空间：O(1)，无需真的构造串联数组。

替代方案

也可以分别计算最大前缀和、最大后缀和、单份 Kadane 与总和，然后比较 singleBest 和 suffix + prefix + max(0,(k−2)×S)。它同样是 O(n)/O(1)，数学结构更直观；扫描两份的写法通常更短，也更不易遗漏 k=2。

面试追问

  • 如果不允许空子数组，如何修改 Kadane 初始化与全负数组处理？
  • 为什么两份扫描足以表达所有跨边界的“前缀 + 后缀”组合？
  • 若要求返回最大子数组的左右端点，如何用压缩表示跨越大量副本的位置？
  • 如果每份数组不同，还能否保留 O(n) 思路？可以考虑用区间四元组做合并。

常见错误

  • 真的创建长度为 n×k 的数组，导致时间或内存超限。
  • 所有情况下都加 (k−2)×S，忽略 S 为负数。
  • 忘记允许空子数组，导致全负输入返回负数。
  • 对中间计算过早取模，再拿取模值参与最大值比较。
  • 使用 32 位整数保存总和与乘积。

class Solution {
    public int kConcatenationMaxSum(int[] arr, int k) {
        final long MOD = 1_000_000_007L;
        long total = 0;
        for (int value : arr) total += value;

        long current = 0;
        long best = 0;
        int copies = Math.min(k, 2);
        for (int copy = 0; copy < copies; copy++) {
            for (int value : arr) {
                current = Math.max(0L, current + value);
                best = Math.max(best, current);
            }
        }

        if (k > 2 && total > 0) {
            best += (long) (k - 2) * total;
        }
        return (int) (best % MOD);
    }
}
