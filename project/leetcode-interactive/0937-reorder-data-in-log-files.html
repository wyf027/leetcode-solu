937. 重新排列日志文件

Reorder Data in Log Files

MEDIUM把混杂的日志整理成可预测、稳定的顺序

题目

给定字符串数组 logs，每条日志由单个空格分隔，首个单词是标识符。其余部分若全为小写字母则为字母日志，若全为数字则为数字日志。请让字母日志排在数字日志之前；字母日志先按内容字典序排列，内容相同时按标识符排列；数字日志保持原相对顺序。返回最终数组。

函数签名： reorderLogFiles(logs: string[]): string[]

约束

  • 1 <= logs.length <= 100
  • 3 <= logs[i].length <= 100
  • 每条日志的单词由单个空格分隔。
  • 每条日志都含标识符，且标识符后至少有一个单词。

示例 1

输入： logs = ["dig1 8 1 5 1", "let1 art can", "dig2 3 6", "let2 own kit dig", "let3 art zero"]
输出： ["let1 art can", "let3 art zero", "let2 own kit dig", "dig1 8 1 5 1", "dig2 3 6"]

字母内容依次为 art can、art zero、own kit dig；数字日志保留先后关系。

示例 2

输入： logs = ["a1 9 2 3 1", "g1 act car", "zo4 4 7", "ab1 off key dog", "a8 act zoo"]
输出： ["g1 act car", "a8 act zoo", "ab1 off key dog", "a1 9 2 3 1", "zo4 4 7"]

完整题解

准备好后再展开，不影响先独立思考。

核心洞察

切分日志时只切第一个空格，得到 identifier 与完整 content。内容首字符是数字即可识别数字日志。分离两类日志后，只排序字母日志，再把数字日志原样追加；这样“稳定”不依赖排序实现。

完整过程

  1. 从左到右扫描日志，定位首个空格。
  2. 若内容首字符是数字，将整条日志追加到数字列表。
  3. 否则保存整条字母日志，并在比较时使用内容与标识符。
  4. 字母日志按 (content, identifier) 升序排序。
  5. 返回“字母日志 + 数字日志”。

正确性证明

分类正确：题目保证标识符后的所有词同属一种类型，因此检查内容首字符足以判型。字母顺序正确：比较器先比较完整内容，只有相同才比较标识符，恰好实现题目规则。数字顺序正确：数字日志按扫描顺序追加且从未排序，所以相对顺序不变。最后拼接使每个字母日志都位于每个数字日志之前。故算法返回所要求的唯一顺序。

边界情况

  • 全部是字母日志或全部是数字日志。
  • 多个字母日志内容完全相同。
  • 内容含多个单词，不能按所有空格拆后丢失结构。
  • 单条日志与最短合法内容。

复杂度

设日志数为 n，单条最大长度为 m。分类为 O(nm)，排序至多 O(n log n) 次字符串比较，每次最坏 O(m)，总时间 O(nm log n)；额外空间 O(n)（不计字符串视图/语言实现的切片开销）。

替代方案

可以对整个数组使用自定义比较器：字母对数字固定在前，两个数字返回相等以依赖稳定排序。它更短，但正确性依赖语言排序稳定性，且比较过程中重复解析日志。显式分组更容易论证，也跨语言一致。

面试追问

  • 如果数字日志也要排序，比较键应该如何定义？
  • 日志数量极大、内存不足时，如何做外部排序？
  • 若内容允许 Unicode 或混合字符，分类规则如何调整？

常见错误

  • 把标识符也纳入字母日志的第一排序键。
  • 数字日志参与排序，破坏原相对顺序。
  • 仅比较内容第一个单词，而非全部内容。
  • 用减法或数值转换判断整段内容，造成错误与不必要开销。

class Solution {
    public String[] reorderLogFiles(String[] logs) {
        List<String> letters = new ArrayList<>();
        List<String> digits = new ArrayList<>();
        for (String log : logs) {
            int space = log.indexOf(' ');
            if (Character.isDigit(log.charAt(space + 1))) digits.add(log);
            else letters.add(log);
        }
        letters.sort((a, b) -> {
            int sa = a.indexOf(' '), sb = b.indexOf(' ');
            String ca = a.substring(sa + 1), cb = b.substring(sb + 1);
            int byContent = ca.compareTo(cb);
            return byContent != 0 ? byContent : a.substring(0, sa).compareTo(b.substring(0, sb));
        });
        letters.addAll(digits);
        return letters.toArray(new String[0]);
    }
}
/** @param {string[]} logs @return {string[]} */
var reorderLogFiles = function(logs) {
  const letters = [], digits = [];
  for (const log of logs) {
    const space = log.indexOf(' ');
    (/\d/.test(log[space + 1]) ? digits : letters).push(log);
  }
  letters.sort((a, b) => {
    const ia = a.indexOf(' '), ib = b.indexOf(' ');
    const contentOrder = a.slice(ia + 1).localeCompare(b.slice(ib + 1));
    return contentOrder || a.slice(0, ia).localeCompare(b.slice(0, ib));
  });
  return letters.concat(digits);
};
from typing import List

class Solution:
    def reorderLogFiles(self, logs: List[str]) -> List[str]:
        letters, digits = [], []
        for log in logs:
            identifier, content = log.split(" ", 1)
            if content[0].isdigit():
                digits.append(log)
            else:
                letters.append((content, identifier, log))
        letters.sort(key=lambda item: (item[0], item[1]))
        return [item[2] for item in letters] + digits
class Solution {
public:
    vector<string> reorderLogFiles(vector<string>& logs) {
        vector<string> letters, digits;
        for (const string& log : logs) {
            size_t p = log.find(' ');
            (isdigit(static_cast<unsigned char>(log[p + 1])) ? digits : letters).push_back(log);
        }
        sort(letters.begin(), letters.end(), [](const string& a, const string& b) {
            size_t pa = a.find(' '), pb = b.find(' ');
            string ca = a.substr(pa + 1), cb = b.substr(pb + 1);
            if (ca != cb) return ca < cb;
            return a.substr(0, pa) < b.substr(0, pb);
        });
        letters.insert(letters.end(), digits.begin(), digits.end());
        return letters;
    }
};
