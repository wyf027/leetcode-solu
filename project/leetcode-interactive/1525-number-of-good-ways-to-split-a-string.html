1525. 字符串的好分割数目Number of Good Ways to Split a String

MEDIUM字符串哈希表前缀统计非付费题

先理解“好分割”的定义，再用交互实验观察分割线两侧的字符变化。完整思路默认收起，留给你独立推导的空间。

Problem

题目描述

给定一个仅由小写英文字母组成的字符串 s。在某个相邻字符之间切一刀，得到两个非空字符串 p 与 q，且 p + q = s。如果两部分所含的不同字符数量相同，这次分割就是“好分割”。返回所有好分割的数量。

注意：分割位置只能位于字符之间，因此长度为 n 的字符串共有 n - 1 个候选位置；左右两部分都不能为空。
示例 1
输入：s = "aacaba"
输出：2
解释：("aac", "aba") 与 ("aaca", "ba") 两侧不同字符数均相等。
示例 2
输入：s = "abcd"
输出：1
解释：好分割为 ("ab", "cd")。
示例 3
输入：s = "aaaaa"
输出：4
解释：所有 4 个分割位置都是好分割。
示例 4
输入：s = "acbadbaada"
输出：2
  • 1 ≤ s.length ≤ 10⁵
  • s 只包含小写英文字母
  • 函数：numSplits(s)
  • 返回：integer

Editorial

一次扫描，维护两侧字符种类

核心洞察

先统计整个字符串各字符的出现次数，把它看成右侧。随后从左向右逐个移动字符：该字符第一次进入左侧时，左侧种类数加一；它在右侧的剩余次数减为零时，右侧种类数减一。每移动一个字符，就恰好对应一个候选分割位置。

仅需比较两个整数，无需反复构造子串或集合。

完整过程

  1. 统计 s 中每个字符的总频次，令右侧不同字符数为频次数组中的非零项数。
  2. 左侧频次数组初始全零，左侧不同字符数为 0，答案为 0。
  3. 让下标 i 从 0 扫描到 n - 2，确保右侧始终非空。
  4. 把 s[i] 从右侧移到左侧，同步更新左右不同字符数。
  5. 若两个不同字符数相等，将答案加一；扫描结束后返回答案。

正确性证明

循环不变量：处理完下标 i 后，左侧频次精确描述 s[0..i]，右侧频次精确描述 s[i+1..n-1]，两个计数分别等于对应部分的不同字符数。

初始化：扫描前左侧为空，右侧为整个字符串，不变量成立。保持：每轮仅把当前字符的一次出现从右侧转移到左侧；首次进入左侧与最后一次离开右侧时才改变种类数，因此不变量继续成立。终止：循环枚举了全部且仅有的 n - 1 个合法非空分割。每个位置在两计数相等时被计数一次，所以最终答案恰为好分割数量。

复杂度

时间：O(n)
空间：O(1)

字符集固定为 26 个小写字母；若用通用哈希表，可记作 O(k)。

边界情况

  • 长度 1：没有合法分割，返回 0。
  • 全为同一字符：长度大于 1 时每刀都好。
  • 所有字符互异：只有可能在两侧长度相等处满足。

常见错误

  • 扫描到末字符，造成右侧为空。
  • 每次见到字符都增加种类数，而非只在频次从 0 变 1 时增加。
  • 右侧减频次后未在归零时减少种类数。

替代方案

可以预处理两个长度为 n 的数组：prefix[i] 表示前缀不同字符数，suffix[i] 表示后缀不同字符数，再比较 prefix[i] == suffix[i+1]。同样是 O(n) 时间，但需要 O(n) 额外空间；双频次数组的扫描更节省空间。

四语言完整代码

class Solution {
    public int numSplits(String s) {
        int[] left = new int[26];
        int[] right = new int[26];
        int leftKinds = 0, rightKinds = 0, answer = 0;

        for (char c : s.toCharArray()) {
            int index = c - 'a';
            if (right[index]++ == 0) rightKinds++;
        }

        for (int i = 0; i < s.length() - 1; i++) {
            int index = s.charAt(i) - 'a';
            if (left[index]++ == 0) leftKinds++;
            if (--right[index] == 0) rightKinds--;
            if (leftKinds == rightKinds) answer++;
        }
        return answer;
    }
}

 * @param {string} s

var numSplits = function(s) {
    const left = new Array(26).fill(0);
    const right = new Array(26).fill(0);
    let leftKinds = 0;
    let rightKinds = 0;
    let answer = 0;

    for (const char of s) {
        const index = char.charCodeAt(0) - 97;
        if (right[index]++ === 0) rightKinds++;
    }

    for (let i = 0; i < s.length - 1; i++) {
        const index = s.charCodeAt(i) - 97;
        if (left[index]++ === 0) leftKinds++;
        if (--right[index] === 0) rightKinds--;
        if (leftKinds === rightKinds) answer++;
    }
    return answer;
};
class Solution:
    def numSplits(self, s: str) -> int:
        left = [0] * 26
        right = [0] * 26
        left_kinds = 0
        right_kinds = 0
        answer = 0

        for char in s:
            index = ord(char) - ord('a')
            if right[index] == 0:
                right_kinds += 1
            right[index] += 1

        for i in range(len(s) - 1):
            index = ord(s[i]) - ord('a')
            if left[index] == 0:
                left_kinds += 1
            left[index] += 1
            right[index] -= 1
            if right[index] == 0:
                right_kinds -= 1
            if left_kinds == right_kinds:
                answer += 1

        return answer
class Solution {
public:
    int numSplits(string s) {
        array<int, 26> left{};
        array<int, 26> right{};
        int leftKinds = 0, rightKinds = 0, answer = 0;

        for (char c : s) {
            int index = c - 'a';
            if (right[index]++ == 0) ++rightKinds;
        }

        for (int i = 0; i < static_cast<int>(s.size()) - 1; ++i) {
            int index = s[i] - 'a';
            if (left[index]++ == 0) ++leftKinds;
            if (--right[index] == 0) --rightKinds;
            if (leftKinds == rightKinds) ++answer;
        }
        return answer;
    }
};

面试追问

如果字符集不再限定为 26 个小写字母呢？

将定长数组替换成 Map / HashMap。算法结构不变，空间复杂度变为 O(k)，其中 k 是不同字符总数。

能否先用两个 Set 预处理每个位置？

可以分别生成前缀、后缀不同字符数数组，但不要为每个位置复制整个 Set，否则最坏会退化为 O(n²) 空间或时间。

如果需要返回所有好分割的位置？

在计数相等时记录 i（或按题意记录分割后的右侧起点 i + 1），替代只累加 answer 即可。
