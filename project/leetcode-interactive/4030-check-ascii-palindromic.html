4030. 判断 ASCII 值回文

给定字符串 s：逐字符取 ASCII 值，判断得到的整数序列是否首尾对称。

交互实验台

输入任意 ASCII 字符串，按“运行检查”查看双指针比较过程。

非 ASCII 字符会被拒绝，空串视为回文。

等待运行。

洞察

ASCII 是字符到整数的固定映射。映射一一对应，所以比较字符本身和比较其 ASCII 值在此题等价；用双指针无需额外数组。

不变量：每次比较通过后，区间外已确认镜像相等。

复杂度与边界

时间 O(n)，额外空间 O(1)。

  • 长度 0 或 1：直接为真。
  • 奇数长度：中间字符无需比较。
  • 大小写、空格、标点都按原始 ASCII 值区分。

完整过程

  1. 令 left = 0、right = s.length - 1。
  2. 当 left < right，比较 s.charCodeAt(left) 与 s.charCodeAt(right)。
  3. 不同立即返回 false；相同则两端向中间收缩。
  4. 循环结束仍未发现不同，返回 true。
替代方案：先转 ASCII 数组再反转比较，表达直观但耗费 O(n) 空间。
常见错误：把题意误读为忽略大小写/标点，或使用 Unicode 码点却未限定输入范围。

双指针只比较仍可能影响答案的最外层一对 ASCII 值；一旦不等即可提前结束。

参考代码

Java 
class Solution {
  public boolean isAsciiPalindromic(String s) {
    for (int l = 0, r = s.length() - 1; l < r; l++, r--)
      if ((int) s.charAt(l) != (int) s.charAt(r)) return false;
    return true;
  }
}
JavaScript 
function isAsciiPalindromic(s) {
  for (let l = 0, r = s.length - 1; l < r; l++, r--)
    if (s.charCodeAt(l) !== s.charCodeAt(r)) return false;
  return true;
}
Python 
class Solution:
    def isAsciiPalindromic(self, s: str) -> bool:
        left, right = 0, len(s) - 1
        while left < right:
            if ord(s[left]) != ord(s[right]): return False
            left, right = left + 1, right - 1
        return True
C++ 
class Solution {
 public:
  bool isAsciiPalindromic(const string& s) {
    for (int l = 0, r = (int)s.size() - 1; l < r; ++l, --r)
      if ((unsigned char)s[l] != (unsigned char)s[r]) return false;
    return true;
  }
};

测试区域

快速生成模式：UI、算法对拍、四语言编译和交互验收待补

  • "abcba" → true：对称。
  • "abca" → false：98 ≠ 99。
  • "A"、"" → true：无需比较。
  • "Aa" → false：65 ≠ 97。

追问

若输入允许 Unicode，如何按“字符”而不是 UTF-16 code unit 比较？可先用 Array.from(s) 按码点展开，但复杂度与题目约束要重新说明。
