01 / Problem

题意与边界

给定整数数组 nums。任取一个连续子数组，将其中元素相加后取绝对值。请返回所有连续子数组中最大的和的绝对值。

子数组可以为空；空子数组的和为 0。因此答案至少为 0。

maxAbsoluteSum(nums: integer[]) → integer

约束

  • 1 ≤ nums.length ≤ 105
  • −104 ≤ nums[i] ≤ 104
  • 只考虑连续片段，不可跳过中间元素。
示例 1
输入：nums = [1,-3,2,3,-4]
输出：5
解释：子数组 [2,3] 的和为 5，绝对值为 5。
示例 2
输入：nums = [2,-5,1,-4,3,-2]
输出：8
解释：子数组 [-5,1,-4] 的和为 -8，绝对值为 8。

03 / Solution

准备好验证你的猜想了吗？

完整思路、证明、复杂度与四种语言代码都在这里。

核心洞察：最大前缀与最小前缀的距离

令 prefix[i] 表示前 i 个数之和，且 prefix[0] = 0。任意子数组 nums[l..r] 的和等于 prefix[r+1] − prefix[l]。

max |prefix[j] − prefix[i]| = max(prefix) − min(prefix)

因此无需枚举子数组。扫描过程中维护见过的最小、最大前缀和，最终二者之差就是答案。把初始前缀 0 纳入统计，也自然覆盖空子数组和从下标 0 开始的子数组。

完整过程

  1. 初始化 prefix = 0，并令 minPrefix = maxPrefix = 0。
  2. 依次把每个数加到 prefix，同步更新最小和最大前缀。
  3. 扫描结束后返回 maxPrefix − minPrefix。

正确性证明

任意连续子数组和都可写成两个前缀和之差，所以其绝对值不会超过所有前缀中的最大值与最小值之差。

反过来，取达到全局最大和全局最小的两个前缀。按它们在数组中的先后顺序相减，对应某个合法连续子数组；无论谁在前，绝对值都恰为 maxPrefix − minPrefix。因此该值既是上界又能取得，算法正确。

边界与复杂度

  • 全为正数：最大跨度是总和与 0 的距离。
  • 全为负数：最小前缀不断下降，答案是总和的绝对值。
  • 全为 0：最高、最低前缀均为 0，答案为 0。
  • 时间复杂度 O(n)；额外空间复杂度 O(1)。

替代方案与面试追问

  • 双 Kadane：分别求最大子数组和、最小子数组和，再取 max(maxSum, −minSum)；同样是 O(n)。
  • 如何返回区间？记录最小/最大前缀出现的下标，再按先后顺序还原区间。
  • 流式输入？此方法只维护三个累计量，可在线处理，无需保存整个数组。

常见错误

  • 只求最大子数组和，会漏掉绝对值更大的负和子数组。
  • 未把初始前缀 0 纳入最值，可能漏掉从数组开头开始的最优片段。
  • 枚举所有起点和终点会达到 O(n²)，无法通过 10⁵ 的数据规模。
  • 在通用大数场景要注意溢出；本题约束下 32 位有符号整数足够，但使用更宽类型更稳妥。
Implementations

四语言完整代码

Java

class Solution {
    public int maxAbsoluteSum(int[] nums) {
        int prefix = 0;
        int minPrefix = 0;
        int maxPrefix = 0;

        for (int num : nums) {
            prefix += num;
            minPrefix = Math.min(minPrefix, prefix);
            maxPrefix = Math.max(maxPrefix, prefix);
        }
        return maxPrefix - minPrefix;
    }
}
