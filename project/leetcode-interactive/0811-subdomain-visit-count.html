811. 子域名访问计数

Subdomain Visit Count

一条域名访问记录不只属于完整域名：访问更深层的地址时，其所有父域名也会被隐式访问。你的任务是汇总每个出现过的域名后缀及其总访问次数。

难度
Medium
输入
string[]
输出
List<string>
顺序
任意

01 · Problem

题意与示例

计数配对域名采用 "访问次数 域名" 的格式。对数组中的每条记录，需要让完整域名及其逐级父域名都获得相同的增量，最后返回所有域名及累计次数。

函数形式

subdomainVisits(cpdomains: string[]): string[]。例如访问 discuss.leetcode.com 时，会同时访问 leetcode.com 与 com。

示例 1

单条记录
输入：cpdomains = ["9001 discuss.leetcode.com"]
输出：["9001 leetcode.com", "9001 discuss.leetcode.com", "9001 com"]

完整域名与两个父域名都被隐式访问 9001 次。

示例 2

合并计数
输入：cpdomains = ["900 google.mail.com", "50 yahoo.com", "1 intel.mail.com", "5 wiki.org"]
输出：["901 mail.com", "50 yahoo.com", "900 google.mail.com", "5 wiki.org", "5 org", "1 intel.mail.com", "951 com"]

mail.com 累计 900 + 1 = 901；com 累计 900 + 50 + 1 = 951；org 为 5。答案顺序可以不同。

约束

  • 1 ≤ cpdomains.length ≤ 100
  • 1 ≤ cpdomains[i].length ≤ 100
  • 每项格式为 "rep d1.d2.d3" 或 "rep d1.d2"
  • 1 ≤ rep ≤ 10⁴
  • d1、d2、d3 均只含小写英文字母
  • 返回结果的排列顺序不作要求

04 · Editorial

完整题解

默认收起，准备好后再展开。

核心洞察 01

父域名就是后缀

对 a.b.com，完整域名及父域名恰好是从每个标签起点截取的后缀。

核心洞察 02

哈希表负责合流

不同输入可能产生相同后缀。用“域名 → 累计次数”的映射做加法即可。

核心洞察 03

输出顺序无关

遍历哈希表，将每组键值拼成 "count domain"，不需要排序。

完整过程

  1. 拆分次数与域名

    找到第一个空格，左侧转为整数，右侧为完整域名。

  2. 枚举所有后缀

    先处理完整域名；随后从每个点号之后开始，依次得到更高层父域名。

  3. 累加访问次数

    对每个后缀执行 count[suffix] += visits。

  4. 格式化答案

    把哈希表中的每项转换成 "次数 域名"。

正确性证明

引理：对任意输入域名，算法枚举的后缀集合正好等于该域名本身及其全部父域名。

理由：完整域名从位置 0 开始；每个父域名都从某个点号后的首字符开始，算法逐一扫描这些位置，既不会遗漏，也不会产生非父域名字符串。

定理：最终哈希表中每个域名的值等于它的总访问次数。

证明：根据引理，每条输入记录会且只会向其隐式访问的每个域名增加一次该记录的访问量。哈希表加法把所有相关记录的贡献求和，因此得到总访问次数。格式化只改变表示，不改变键和值，故输出正确。

复杂度

时间
O(S)

S 为全部输入字符总量；题目至多三层域名。

空间
O(U)

U 为不同域名后缀的总字符规模。

边界情况

只有两层

如 yahoo.com，只产生自身与 com。

父域名也单独出现

其直接访问量与子域名贡献必须累加。

多种顶级域名

com 与 org 分属不同键，不会混合。

class Solution {
    public List<String> subdomainVisits(String[] cpdomains) {
        Map<String, Integer> counts = new HashMap<>();

        for (String item : cpdomains) {
            int space = item.indexOf(' ');
            int visits = Integer.parseInt(item.substring(0, space));
            String domain = item.substring(space + 1);

            counts.put(domain, counts.getOrDefault(domain, 0) + visits);
            for (int i = 0; i < domain.length(); i++) {
                if (domain.charAt(i) == '.') {
                    String suffix = domain.substring(i + 1);
                    counts.put(suffix, counts.getOrDefault(suffix, 0) + visits);
                }
            }
        }

        List<String> answer = new ArrayList<>();
        for (Map.Entry<String, Integer> entry : counts.entrySet()) {
            answer.add(entry.getValue() + " " + entry.getKey());
        }
        return answer;
    }
}

/**
 * @param {string[]} cpdomains
 * @return {string[]}

var subdomainVisits = function(cpdomains) {
    const counts = new Map();

    for (const item of cpdomains) {
        const space = item.indexOf(' ');
        const visits = Number(item.slice(0, space));
        const domain = item.slice(space + 1);

        const suffixes = [domain];
        for (let i = 0; i < domain.length; i++) {
            if (domain[i] === '.') {
                suffixes.push(domain.slice(i + 1));
            }
        }

        for (const suffix of suffixes) {
            counts.set(suffix, (counts.get(suffix) || 0) + visits);
        }
    }

    const answer = [];
    for (const [domain, visits] of counts) {
        answer.push(`${visits} ${domain}`);
    }
    return answer;
};
Python 3 · official signature
from typing import List
from collections import defaultdict


class Solution:
    def subdomainVisits(self, cpdomains: List[str]) -> List[str]:
        counts = defaultdict(int)

        for item in cpdomains:
            visits_text, domain = item.split(" ", 1)
            visits = int(visits_text)

            counts[domain] += visits
            for index, char in enumerate(domain):
                if char == ".":
                    counts[domain[index + 1:]] += visits

        return [
            f"{visits} {domain}"
            for domain, visits in counts.items()
        ]
C++ · official signature
class Solution {
public:
    vector<string> subdomainVisits(vector<string>& cpdomains) {
        unordered_map<string, int> counts;

        for (const string& item : cpdomains) {
            int space = item.find(' ');
            int visits = stoi(item.substr(0, space));
            string domain = item.substr(space + 1);

            counts[domain] += visits;
            for (int i = 0; i < static_cast<int>(domain.size()); ++i) {
                if (domain[i] == '.') {
                    counts[domain.substr(i + 1)] += visits;
                }
            }
        }

        vector<string> answer;
        answer.reserve(counts.size());
        for (const auto& [domain, visits] : counts) {
            answer.push_back(to_string(visits) + " " + domain);
        }
        return answer;
    }
};

替代方案

split + join

先按点号拆成标签，再从每个下标向后拼接。直观但会创建更多临时数组和字符串。

反向 Trie

若需要持续流式写入、按层级查询或展示域名树，可反向存储标签；对本题则明显过度设计。

面试追问

  • 如果域名层级不设上限？

    算法仍适用；复杂度按所有生成后缀的字符总量描述更严谨。

  • 如果访问次数可能超过 32 位？

    Java/C++ 改用 64 位整数；JavaScript 在超出安全整数时用 BigInt。

  • 如果必须稳定排序？

    格式化前对键排序，或按次数与域名组成比较器。

常见错误

覆盖而不是累加

相同后缀可能由多条记录贡献，必须读取旧值后再加。

漏掉完整域名

只处理点号后的字符串会遗漏原始域名本身。

只生成直接父域名

三级域名需要继续上溯到顶级域名，不能只截一次。

错误比较答案顺序

题目允许任意顺序；测试时应比较集合或排序后的数组。
