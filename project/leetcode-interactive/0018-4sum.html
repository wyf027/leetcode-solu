题解

核心洞察、完整过程、边界、复杂度、追问、错误清单和四语言代码默认隐藏。

CORE INSIGHT

4Sum = 固定两数 + 有序 Two Sum

排序让“调大/调小总和”与“跳过重复值”同时成立。枚举 i 和 j 后，剩余区间用左右指针找目标差：和偏小移动左指针，和偏大移动右指针；命中后记录并同时跳过左右重复值。外层两级也必须各自去重。

sort → choose i → choose j → two pointers → emit → deduplicate

30-SECOND PITCH

“我把数组排序，固定前两个数，再在剩余区间做 Two Sum。四层索引天然互异；四个层级都按相邻值去重。求和先提升到 long，避免 10⁹ 级输入溢出。整体 O(n³)。”

完整解题过程

  1. 1. 排序数组；若长度小于 4，直接返回空列表。
  2. 2. 枚举第一轨 i，与前一值相同则跳过。
  3. 3. 枚举第二轨 j，同样只保留第一个相同值。
  4. 4. 令 left=j+1、right=n-1，使用 64 位计算四数和。
  5. 5. 比目标小就 left++，比目标大就 right--。
  6. 6. 命中时保存四元组，两端内收并跳过重复值。

边界与复杂度

  • 不足四个元素：无合法四元组。
  • 全是重复值：外层与内层去重共同保证只输出一次。
  • 极大整数：Java/C++ 使用 long / long long；JS Number 在本约束内仍精确。
  • 时间：排序 O(n log n)，主体 O(n³)。
  • 额外空间：忽略排序栈与输出为 O(1)；结果空间依赖答案数。

替代方案

哈希表可以枚举两两之和，但处理下标互异与结果去重更复杂，空间可达 O(n²)。通用 K-Sum 递归更易扩展，但 4Sum 面试中直接两层循环 + 双指针更透明。

面试高频追问

  • 为什么命中后要同时移动左右指针？
  • 四处去重分别解决什么重复？
  • 能否用剪枝优化最小/最大可能和？
  • 如何抽象为通用 K-Sum？
  • 为什么 Java 转 long 必须发生在加法之前？

常见错误

  • 只给结果套 Set，却不跳过重复枚举。
  • 命中后只移动一个指针，导致重复或死循环。
  • (long)(a+b+c+d) 转换太晚，32 位已溢出。
  • j 的去重条件写成 j>0，误跳过新 i 下的合法值。
  • 忘记排序就使用双指针方向。

class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        List<List<Integer>> answer = new ArrayList<>();
        Arrays.sort(nums);
        int n = nums.length;

        for (int i = 0; i < n - 3; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            for (int j = i + 1; j < n - 2; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;

                int left = j + 1;
                int right = n - 1;
                while (left < right) {
                    long sum = (long) nums[i] + nums[j]
                             + nums[left] + nums[right];
                    if (sum < target) {
                        left++;
                    } else if (sum > target) {
                        right--;
                    } else {
                        answer.add(Arrays.asList(
                            nums[i], nums[j], nums[left], nums[right]
                        ));
                        int leftValue = nums[left];
                        int rightValue = nums[right];
                        while (left < right && nums[left] == leftValue) left++;
                        while (left < right && nums[right] == rightValue) right--;
                    }
                }
            }
        }
        return answer;
    }
}

public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> answer;
        int n = static_cast<int>(nums.size());

        for (int i = 0; i < n - 3; ++i) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            for (int j = i + 1; j < n - 2; ++j) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;

                int left = j + 1;
                int right = n - 1;
                while (left < right) {
                    long long sum = static_cast<long long>(nums[i])
                                  + nums[j] + nums[left] + nums[right];
                    if (sum < target) {
                        ++left;
                    } else if (sum > target) {
                        --right;
                    } else {
                        answer.push_back({
                            nums[i], nums[j], nums[left], nums[right]
                        });
                        int leftValue = nums[left];
                        int rightValue = nums[right];
                        while (left < right && nums[left] == leftValue) ++left;
                        while (left < right && nums[right] == rightValue) --right;
                    }
                }
            }
        }
        return answer;
    }
};
