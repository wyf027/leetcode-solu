LEETCODE 3847 · MEDIUM

计算比赛分数差

Find the Score Difference in a Game

模拟状态机O(n)

题意

两名玩家中，玩家 1 初始主动。第 i 场依序：分数为奇数先交换角色；每第 6 场（下标 5、11、17…）再交换；主动玩家获得该场分数。返回 玩家1总分 − 玩家2总分。

示例 1
nums = [1,2,3]
输出 0

示例 2
nums = [2,4,2,1,2,1]
输出 4

约束：1 ≤ nums.length ≤ 1000，1 ≤ nums[i] ≤ 1000。

交互分步可视化

数组使用方括号；每场严格执行“奇数交换 → 第六场交换 → 计分”。

题解

维护 firstActive。两种交换连续发生，因而可以逐次翻转；同场双翻转自然抵消。交换完成后，分数进入当前主动方。

完整过程

  1. 玩家1主动、两人总分为 0。
  2. 奇数则翻转角色。
  3. 若 (i + 1) % 6 == 0 再翻转。
  4. 给主动方加分，最后返回差值。

边界与复杂度

单元素、全偶数、第六场双交换以及负分差。时间 O(n)，额外空间 O(1)。

替代方案

可只维护带符号的答案：玩家1主动时加分，玩家2主动时减分。

面试追问

每第 k 场交换时，替换模数 6 为 k；更多玩家时维护当前编号。

常见错误

第六场误用下标 6；先计分再换人；漏掉同场双交换；误以为两次交换只发生一次。
