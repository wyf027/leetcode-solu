替换一个数字后的最大差值

给定整数 num，选定一个数字并把它的所有出现位置统一映射为另一个数字。最大值和最小值可以采用不同映射，求二者之差。

恰好选择一次映射 允许映射为自身 允许前导 0
↓先读规则，再亲手推演

Problem

题意与边界

对一次映射 d1 → d2，需要把十进制表示中所有 d1 同时替换成 d2。可以把数字映射为自身，因此即便结果不变，也满足“恰好一次”。求所有合法映射能得到的最大值减最小值。

  • 求最大值与最小值时，可以分别选择不同的 d1 和 d2。
  • 替换结果可带前导零；作为整数解释时，前导零不影响数值。
  • 参数形式：minMaxDifference(num: int) -> int。
  • 约束：1 <= num <= 108。

Example 01

重复数字同时变化

输入：num = 11891
输出：99009

最大值：1 → 9，得到 99899
最小值：1 → 0，得到 00890，即 890
差值：99899 - 890 = 99009

Example 02

两个方向选择不同数字

输入：num = 90
输出：99

最大值：0 → 9，得到 99
最小值：9 → 0，得到 00，即 0
差值：99 - 0 = 99

Solution

一次从左到右的贪心

核心洞察

最大值：从左往右找到第一个不是 9 的数字，把它的所有出现位置替换成 9。最小值：从左往右找到第一个不是 0 的数字，把它的所有出现位置替换成 0。

完整过程

  1. 把 num 转成字符串。
  2. 分别定位最大路径的首个非 9 数字和最小路径的首个非 0 数字。
  3. 对每条路径执行全局替换并转回整数。
  4. 返回 maximum - minimum。

正确性说明

比较两个等长十进制串时，最先不同的位置决定大小。若要求最大值，首个非 9 位置能提升，就应将其变为可取的最大数字 9；改动任何更靠右的数字都无法抵消该位置的优势。同一源数字的其他位置也被改成 9，只会继续增大结果。

最小值同理：首个非 0 位置必须尽可能降为 0；更靠右的映射不能得到更小结果。同源数字的其余位置变为 0 只会继续减小结果。因此两条贪心路径分别最优，差值也最大。

边界与复杂度

  • 全是 9：最大路径可把 9 映射为自身，数值不变。
  • 单个数字：规则不变，例如 7 可得到最大 9、最小 0。
  • 最小结果含前导零：转成整数后自然消失。
  • 时间复杂度 O(d)，空间复杂度 O(d)；d 为位数。

替代方案

可以枚举源数字与目标数字的 100 种组合，分别求极值，时间为 O(100d)。在本题范围内也能通过，但没有利用十进制高位优先的结构，代码更长。

面试追问

  • 若禁止前导零，最小值策略如何变化？
  • 若只能替换一个位置，而不是一种数字，如何选择？
  • 若允许进行至多 k 次映射，状态如何表示？

常见错误

  • 只替换第一次出现的源数字，忘记必须替换全部出现位置。
  • 最小值把首位改成 1；本题明确允许前导零，所以应改成 0。
  • 最大路径直接把所有数字改成 9；一次映射只能选择一种源数字。
  • 强迫最大值与最小值使用同一映射。

Implementations

四种语言完整代码

Java 
class Solution {
    public int minMaxDifference(int num) {
        String s = String.valueOf(num);
        char maxFrom = '9';
        for (char c : s.toCharArray()) {
            if (c != '9') {
                maxFrom = c;
                break;
            }
        }

        char minFrom = '0';
        for (char c : s.toCharArray()) {
            if (c != '0') {
                minFrom = c;
                break;
            }
        }

        int maximum = Integer.parseInt(s.replace(maxFrom, '9'));
        int minimum = Integer.parseInt(s.replace(minFrom, '0'));
        return maximum - minimum;
    }
}

/**

var minMaxDifference = function(num) {
    const s = String(num);
    const maxFrom = [...s].find((digit) => digit !== '9') ?? '9';
    const minFrom = [...s].find((digit) => digit !== '0') ?? '0';
    const maximum = Number(s.split(maxFrom).join('9'));
    const minimum = Number(s.split(minFrom).join('0'));
    return maximum - minimum;
};

C++ 
class Solution {
public:
    int minMaxDifference(int num) {
        string s = to_string(num);
        char maxFrom = '9';
        char minFrom = '0';

        for (char c : s) {
            if (c != '9') {
                maxFrom = c;
                break;
            }
        }
        for (char c : s) {
            if (c != '0') {
                minFrom = c;
                break;
            }
        }

        string maximum = s;
        string minimum = s;
        for (char& c : maximum) {
            if (c == maxFrom) c = '9';
        }
        for (char& c : minimum) {
            if (c == minFrom) c = '0';
        }
        return stoi(maximum) - stoi(minimum);
    }
};
