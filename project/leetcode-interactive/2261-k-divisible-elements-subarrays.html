含最多 K 个可整除元素的子数组

K Divisible Elements Subarrays

位置不同，内容就一定不同吗？先理解计数对象，再动手解决。

官方题目 ↗

题意

给定整数数组 nums 和整数 k、p，返回不同的、非空连续子数组的数量，且每个子数组中能被 p 整除的元素个数不超过 k。

“不同”比较的是长度与逐项元素值。相同内容在不同位置出现，只计一次。统计的是可整除的元素个数，不是子数组之和。

约束

  • 1 ≤ nums.length ≤ 200
  • 1 ≤ nums[i], p ≤ 200
  • 1 ≤ k ≤ nums.length

进阶：能否做到 O(n²) 时间？

示例 1

nums = [2,3,3,2,2], k = 2, p = 2
输出：11

下标 0、3、4 上的 2 可以被整除。合法的不同序列为：

[2]、[2,3]、[2,3,3]、[2,3,3,2]、[3]、[3,3]、[3,3,2]、[3,3,2,2]、[3,2]、[3,2,2]、[2,2]。

[2] 与 [3] 各自只计一次；整个数组含 3 个可整除元素，不能计入。

示例 2

nums = [1,2,3,4], k = 4, p = 1
输出：10

每个元素都可被 1 整除，任意子数组长度均不超过 4，因此全部合法。元素互异，全部子数组内容也不同，共 4 + 3 + 2 + 1 = 10 个。

先想一想

若同一个值在数组中出现三次，它对应多少个不同的长度为 1 的子数组？如果已经超过整除个数限制，继续向右延伸会重新合法吗？

题解 · 每条值路径只算一次

核心洞察

枚举起点并向右扩展。用计数器记录可整除元素数，超过 k 时停止当前起点。用字典树保存值序列：从根开始，依次按元素值走边，同一序列总会到达同一节点。每创建一个非根节点，就发现一个新的合法子数组。

完整过程

  1. 建立空根节点，答案初始化为 0。
  2. 对每个起点 i，从根出发并把整除计数清零。
  3. 右端点 j 向右移动，若 nums[j] % p == 0，计数加 1。
  4. 若计数大于 k，立即结束该起点，且不要插入这个元素。
  5. 否则沿值 nums[j] 的边前进；没有该边就创建节点并将答案加 1。

交互实验 · 整除额度与路径登记

每步扩展一个右端点。橙色底边表示可整除，青色框表示当前区间；路径登记簿列出从根到节点的完整值路径，新路径才增加计数。

路径登记簿（根节点不计入答案）

为什么正确

合法性：只在整除计数不超过 k 时插入节点，每个节点代表一个实际出现的合法非空子数组。

完整性：任意合法子数组 [i,j] 的所有前缀都合法，因此从起点 i 扩展时不会在到达 j 前停止，其值路径必然插入树中。超限后继续扩展，计数只增不减，提前停止不会漏解。

唯一性：根到节点的边值序列唯一；相同内容复用相同路径，不同长度或不同元素的序列到达不同节点。因此非根节点与合法不同子数组一一对应，创建节点的总数就是答案。

复杂度

令 n 为长度、V = 201 为子节点数组长度。最多扩展 n(n+1)/2 次；每次访问边 O(1)，每次新建节点初始化 O(V)。总时间 O(Vn²)，空间 O(Vn²)。本题值域固定为 1…200，V 是常数，故均为 O(n²)。四份代码均使用固定值域数组，避免哈希碰撞及平均复杂度假设，但会分配较多空槽。

边界

  • n = 1：唯一单元素子数组合法，因为 k ≥ 1。
  • p = 1：所有元素可整除，合法区间长度最多 k。
  • 没有元素可整除：所有区间合法，仍需按内容去重。
  • 所有元素相等：相同长度的序列只计一次。
  • k = n：过滤条件不起作用，不能省略内容去重。

替代方案

枚举 + 字符串集合最直接，需明确分隔符；构造与哈希整个序列使最坏时间达到 O(n³)，存储字符量也可能 O(n³)。稀疏 Map 字典树能节省空槽，使用哈希表时通常为期望 O(n²)。滚动哈希可做到期望 O(n²) 时间，但必须处理碰撞，双哈希也不是严格无碰撞证明。

常见错误

  • 把“最多 k”写成“恰好 k”，或在等于 k 时提前停止。
  • 直接用滑动窗口累计区间个数：它统计位置，无法按内容去重。
  • 每换一个起点就新建根：这样无法跨起点复用序列。
  • 先插入再判断超限：会把非法子数组计入答案。
  • 把空根也计数，或者只统计叶子：内部节点同样代表子数组。
  • 数字直接拼接无分隔符：[1,23] 和 [12,3] 会混淆。

面试追问

值域很大怎么办？把每个节点的数组改为 Map，或先坐标压缩；整除判断仍用原值。只想统计区间数量呢？可以用滑动窗口，不再需要字典树。必须严格 O(n²) 吗？本题固定值域数组提供确定性的常数时间边访问。为什么不需要结束标记？所有插入路径的非空前缀都是合法子数组，每个新节点本身就是一个完整计数对象。

Java
class Solution {
    static class Node {
        Node[] next = new Node[201];
    }

    public int countDistinct(int[] nums, int k, int p) {
        Node root = new Node();
        int answer = 0;
        for (int i = 0; i < nums.length; i++) {
            Node node = root;
            int count = 0;
            for (int j = i; j < nums.length; j++) {
                int x = nums[j];
                if (x % p == 0) count++;
                if (count > k) break;
                if (node.next[x] == null) {
                    node.next[x] = new Node();
                    answer++;
                }
                node = node.next[x];
            }
        }
        return answer;
    }
}

C++
#include <array>
#include <vector>
using namespace std;

class Solution {
public:
    int countDistinct(vector<int>& nums, int k, int p) {
        // Index 0 is the root; child index 0 means no edge.
        vector<array<int, 201>> trie(1, array<int, 201>{});
        int answer = 0;
        for (int i = 0; i < (int)nums.size(); ++i) {
            int node = 0, count = 0;
            for (int j = i; j < (int)nums.size(); ++j) {
                int x = nums[j];
                if (x % p == 0) ++count;
                if (count > k) break;
                if (trie[node][x] == 0) {
                    int child = (int)trie.size();
                    trie[node][x] = child;
                    trie.push_back(array<int, 201>{});
                    ++answer;
                }
                node = trie[node][x];
            }
        }
        return answer;
    }
};
