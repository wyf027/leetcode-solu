Distance to a Cycle in Undirected Graph

一张连通的无向图，一个环。对每个顶点，找出走到环上最少需要经过多少条边。

01 / PROBLEM

题目与输入约定

输入整数 n 和边数组 edges。顶点编号为 0…n−1；每条 [u,v] 表示 u 与 v 双向相连。图连通且恰有一个环。返回长度为 n 的整数数组，第 i 项表示顶点 i 到任意环上顶点的最短距离。距离是路径上的边数，环上顶点的答案为 0。

distanceToCycle(n: integer, edges: integer[][]) → integer[]

约束

  • 3 ≤ n ≤ 10⁵，edges.length = n。
  • edges[i].length = 2，端点取值在 [0,n−1] 内，且两端点不同。
  • 任意两点间至多一条边；图连通，恰好包含一个环。

题解：剥离叶子，再从环出发

唯一环之外是挂在环上的树枝。反复删除度为 1 的顶点，最后留下的就是环。把所有环上顶点作为距离 0 的源点，一起进行 BFS。

完整过程

  1. 建立双向邻接表和度数数组，将所有度为 1 的顶点入队。
  2. 弹出叶子，将其度数设为 0 表示删除；只对仍存在的邻居减度，邻居恰好降到 1 时入队。原邻接表保持完整。
  3. 队列耗尽后，度数大于 0 的顶点就是环。将它们的距离设为 0，并加入新的 BFS 队列；其余距离初始化为 −1。
  4. 在原图上扩散。未访问邻居的距离等于当前距离加 1；赋值后立即入队。最后按顶点编号返回数组。

正确性证明
环不会被删掉。 每个环点都有两个环内邻居，只要环存在，它的剩余度数至少为 2。以此归纳，环上顶点不会进入叶子队列。
环外点都会被删除。 因为只有一个环，其余部分是附着的树。若树枝尚未清空，距离环最远的一层必有可删除的叶子。因此剥离终止时所有环外顶点都已消失。结合上一点，剩余顶点恰为环。
BFS 的距离是最短距离。 环上所有点以 0 同时入队。BFS 按距离非递减顺序扩展，从距离 d 的点首次发现的邻居存在长度 d+1 的到环路径。若存在更短路径，该点应在更早一层被发现，矛盾。图连通，故每点最终都能得到正确距离。
复杂度
每点最多在剥离和 BFS 中各入队一次，每条边被扫描常数次。时间与空间都是 O(n+m)；本题 m=n，均化为 O(n)。队列采用迭代实现，避免 10⁵ 长链导致递归栈溢出。
边界情况
  • 纯环：初始叶子队列为空，所有点直接成为 BFS 源点，答案全为 0。
  • 多条树枝：环上所有顶点同时出发，才能正确覆盖每个分支。
  • 编号与结构无关：0 可能在环外，不能固定选择 0 当源点。
  • 剥离轮数不等于到环距离：不平衡树中的叶子可处于不同深度。

Java
import java.util.*;

class Solution {
    public int[] distanceToCycle(int n, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        int[] degree = new int[n];
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
            degree[e[0]]++;
            degree[e[1]]++;
        }
        Deque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < n; i++)
            if (degree[i] == 1) queue.offer(i);
        while (!queue.isEmpty()) {
            int u = queue.poll();
            degree[u] = 0;
            for (int v : graph.get(u)) {
                if (degree[v] > 0 && --degree[v] == 1)
                    queue.offer(v);
            }
        }
        int[] distance = new int[n];
        Arrays.fill(distance, -1);
        for (int i = 0; i < n; i++) {
            if (degree[i] > 0) {
                distance[i] = 0;
                queue.offer(i);
            }
        }
        while (!queue.isEmpty()) {
            int u = queue.poll();
            for (int v : graph.get(u)) {
                if (distance[v] == -1) {
                    distance[v] = distance[u] + 1;
                    queue.offer(v);
                }
            }
        }
        return distance;
    }
}

Python
from collections import deque
from typing import List

class Solution:
    def distanceToCycle(self, n: int, edges: List[List[int]]) -> List[int]:
        graph = [[] for _ in range(n)]
        degree = [0] * n
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
            degree[u] += 1
            degree[v] += 1

        queue = deque(u for u in range(n) if degree[u] == 1)
        while queue:
            u = queue.popleft()
            degree[u] = 0
            for v in graph[u]:
                if degree[v] > 0:
                    degree[v] -= 1
                    if degree[v] == 1:
                        queue.append(v)

        distance = [-1] * n
        for u in range(n):
            if degree[u] > 0:
                distance[u] = 0
                queue.append(u)
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                if distance[v] == -1:
                    distance[v] = distance[u] + 1
                    queue.append(v)
        return distance


C++
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    vector<int> distanceToCycle(int n, vector<vector<int>>& edges) {
        vector<vector<int>> graph(n);
        vector<int> degree(n, 0);
        for (const auto& e : edges) {
            graph[e[0]].push_back(e[1]);
            graph[e[1]].push_back(e[0]);
            ++degree[e[0]];
            ++degree[e[1]];
        }
        queue<int> q;
        for (int u = 0; u < n; ++u)
            if (degree[u] == 1) q.push(u);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            degree[u] = 0;
            for (int v : graph[u]) {
                if (degree[v] > 0 && --degree[v] == 1)
                    q.push(v);
            }
        }
        vector<int> distance(n, -1);
        for (int u = 0; u < n; ++u) {
            if (degree[u] > 0) {
                distance[u] = 0;
                q.push(u);
            }
        }
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (int v : graph[u]) {
                if (distance[v] == -1) {
                    distance[v] = distance[u] + 1;
                    q.push(v);
                }
            }
        }
        return distance;
    }
};




替代方案与常见错误
替代方案
DFS 用访问状态、父节点和当前路径识别唯一环，再执行多源 BFS，时间与空间仍为 O(n)。无向图中必须跳过父边，长链要注意调用栈。也可以在剥离时记录每个顶点指向环方向的唯一存活邻居，再逆序恢复距离，省去第二次图遍历。
常见错误
  • 只从一个环点开始 BFS：计算的是到该点的距离，而不是到环的距离。
  • 删除邻接表中的树边后直接 BFS：原图连接被破坏，无法再走回树枝。只更新 degree 即可。
  • 把初始度数大于 1 的点都当作环：链的中间节点也可能度为 2，必须持续剥离。
  • 在 BFS 出队时才标记距离：可能重复入队；应在首次发现时赋值。
  • JavaScript 使用 shift()、Python 使用 list.pop(0)：队列搬移可能退化，分别用头索引、deque。
  • 将 2-core 直接推广为任意图的环点集合：多环图的桥接路径也可能留在 2-core。
面试追问
多个环怎么办？ 可用桥算法识别所有非桥边，其端点属于某个环；从这些点多源 BFS。两个环之间的桥接路径不能直接算作环。无环连通块的返回值需另行约定。
非负带权图怎么办？ 环的识别过程不变，将 BFS 换为多源 Dijkstra，距离按边权累加。
如何恢复最近环点与路径？ 环源点记录自身编号，BFS 发现邻居时传播源编号并保存前驱；若要稳定处理等距情况，需规定平局规则。
为什么线性？ 两阶段中每点各入队至多一次，邻接表总长度是 2m，因此只扫描 O(n+m) 项。
