2535. 数组元素和与
数字和的绝对差

Difference Between Element Sum and Digit Sum of an Array

同一组数，用两种方式计数。先读懂「元素」与「数位」的区别，再尝试计算它们之间的距离。

阅读题目 ↓进入交互实验 ↓LeetCode 原题 ↗

01 / 题目

给定正整数数组 nums。把所有数组元素直接相加，得到元素和；把每个元素十进制表示中的每一位数字相加，得到数字和。重复出现的数字需要重复计入。返回这两个总和的绝对差，即 |元素和 − 数字和|。

参数：nums（整数数组） · 返回：整数 · 函数：differenceOfSum(nums)

官方示例 1

输入：nums = [1,15,6,3]
输出：9

元素和：1 + 15 + 6 + 3 = 25。
数字和：1 + 1 + 5 + 6 + 3 = 16。
绝对差：|25 − 16| = 9。

官方示例 2

输入：nums = [1,2,3,4]
输出：0

元素和：1 + 2 + 3 + 4 = 10。
数字和：1 + 2 + 3 + 4 = 10。
绝对差：|10 − 10| = 0。

约束
  • 1 ≤ nums.length ≤ 2000
  • 1 ≤ nums[i] ≤ 2000

04 / 独立题解

先尝试自己的思路，再展开完整分析和代码。

核心洞察：完整数值与数位贡献分开累计

一次遍历维护 E 和 D。对于每个元素 x，先把完整的 x 加入 E，再用临时变量 y 拆分数位：y % 10 取得个位，整数除以 10 去掉个位。直到 y 变成 0。最后返回 abs(E − D)，原数组无需修改。

完整过程

  1. 初始化 E = 0，D = 0。
  2. 读到 1：E = 1，取出数位 1 后 D = 1。
  3. 读到 15：E = 16；先取 5，D = 6；剩余 1，再取 1，D = 7。
  4. 读到 6：E = 22，D = 13。
  5. 读到 3：E = 25，D = 16。
  6. 返回 |25 − 16| = 9。数位处理顺序不会影响加法结果。

正确性

内层循环不变式：已提取数位之和，加上 y 中剩余数位之和，等于当前元素的全部数位之和。每次取余提取最低位，整除仅删除该位，因此不漏计、不重复；当 y = 0 时，该元素的全部数位都已计入 D。

外层循环不变式：处理前 k 个元素后，E 是它们的元素和，D 是它们的数字和。初始 k = 0 时成立；加入下一个完整元素及其全部数位后仍成立。遍历结束即得到题目定义的两个总和，取绝对差就是所求答案。

边界与复杂度

  • 所有元素均为一位数时，两种总和相等，答案为 0。
  • 中间或末尾的 0 也属于数位；它贡献 0，不影响正确性。
  • 重复数位必须重复相加，不能使用集合去重。
  • 输入只含正整数，不需要处理负号；空数组不属于官方输入。
  • 元素和最大为 2000 × 2000 = 4,000,000，四份实现的数值类型均能容纳。

令 n 为数组长度，M 为最大元素，十进制位数 L = ⌊log₁₀ M⌋ + 1。时间 O(nL)，额外空间 O(1)。本题 M ≤ 2000，最多 4 位，时间也可写为 O(n)。交互演示保存步骤快照的空间开销不属于提交算法。

替代方案与面试追问

字符串拆分：把每个数转为字符串，再把字符转回数字累加。更直观，时间同为 O(nL)，逐个转换时需要 O(L) 临时空间；无需把整个数组拼接成字符串。

能否省略绝对值？可以。设 x 的各位为 dᵢ，则 x − digitSum(x) = Σ dᵢ(10ⁱ − 1) ≥ 0，因此 E ≥ D。保留 abs 更直接对应题意。

答案有什么性质？每个 10ⁱ − 1 都是 9 的倍数，所以结果一定是 9 的倍数。这只是必要性质，不能代替完整验证。

输入改成超长整数？应改用字符串读取和大整数累计，不能先用可能溢出的普通数值解析。

常见错误

  • 只计算每个元素的个位，漏掉其他数位。
  • 先把 x 除到 0，再将 x 加入元素和，导致丢失原值。
  • JavaScript 使用 y / 10 却没有 Math.floor，会得到小数。
  • Python 使用 / 而非 //，不能正确执行整数数位拆分。
  • 把重复数字去重，或者把“数字和”误解为不同元素之和。

四语言提交代码

Java

class Solution {
    public int differenceOfSum(int[] nums) {
        int elementSum = 0, digitSum = 0;
        for (int x : nums) {
            elementSum += x;
            for (int y = x; y > 0; y /= 10) {
                digitSum += y % 10;
            }
        }
        return Math.abs(elementSum - digitSum);
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number}
 */
var differenceOfSum = function(nums) {
    let elementSum = 0, digitSum = 0;
    for (const x of nums) {
        elementSum += x;
        for (let y = x; y > 0; y = Math.floor(y / 10)) {
            digitSum += y % 10;
        }
    }
    return Math.abs(elementSum - digitSum);
};

Python 3

from typing import List

class Solution:
    def differenceOfSum(self, nums: List[int]) -> int:
        element_sum = 0
        digit_sum = 0
        for x in nums:
            element_sum += x
            y = x
            while y > 0:
                digit_sum += y % 10
                y //= 10
        return abs(element_sum - digit_sum)
