LeetCode 2444 / Count Subarrays With Fixed Bounds

统计定界子数组的数目

连续的一段数字，恰好触及两个边界。先理解什么样的区间符合要求，再试着把它们全部数出来。

01 / PROBLEM

题目与约束

给定整数数组 nums，以及整数 minK 和 maxK。统计所有非空、连续子数组中，最小值恰好为 minK 且最大值恰好为 maxK 的子数组数量，并返回这个数量。不同起止位置分别计数，即使内容相同。

  • 2 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i], minK, maxK ≤ 10⁶

官方约束没有额外列出 minK ≤ maxK；若 minK > maxK，没有符合定义的子数组。

打开官方题目 ↗

示例 1

nums = [1,3,5,2,7,5]
minK = 1
maxK = 5

输出：2

符合要求的是 [1,3,5] 和 [1,3,5,2]，它们的最小值是 1，最大值是 5。

示例 2

nums = [1,1,1,1]
minK = 1
maxK = 1

输出：10

所有非空连续子数组都符合条件，共 4 + 3 + 2 + 1 = 10 个。

04 / INSIGHT

固定右端点，数合法左端点

一个区间合法，当且仅当：每个数都在 [minK,maxK] 内，并且两个边界值都至少出现一次。扫描右端点 r，只需记住三个最近位置：

  • bad：最近一次越界的位置，初值 −1。
  • lo：最近一次出现 minK 的位置，初值 −1。
  • hi：最近一次出现 maxK 的位置，初值 −1。

起点 l 必须在越界点之后，并位于两个边界最近位置之前或其上：bad < l ≤ min(lo,hi)。

本轮贡献 = max(0, min(lo, hi) − bad)

固定右端点 r 的所有合法区间，正好对应上述范围内的每一个起点。

完整过程

  1. 令三个位置为 −1，答案为 0。
  2. 从左到右读入 nums[r]，若它越界则令 bad = r。
  3. 分别判断它是否等于 minK、maxK，并更新 lo、hi；两个判断必须独立。
  4. 计算本轮贡献，累加到答案，直到所有右端点处理完毕。

06 / REASONING

为什么不会漏数或重复？

循环不变式

处理完 r 后，bad、lo、hi 分别是前缀 nums[0..r] 中对应事件的最近位置，或未出现时的 −1。每轮只在当前元素触发事件时更新，因此不变式保持成立。

必要性与充分性

若 [l,r] 合法，不能包含最近越界点，所以 l > bad；它必须同时包含两个边界值，所以 l ≤ lo 且 l ≤ hi。反过来，满足这些不等式时，区间内没有越界值，又包含 minK 与 maxK，因此最小值和最大值恰好等于目标。

可选整数起点是 [bad+1, min(lo,hi)]，长度为 max(0,min(lo,hi)−bad)。每个子数组只有一个右端点，按右端点累加会恰好计数一次。

示例 1 的贡献序列

六个右端点依次贡献 0, 0, 1, 1, 0, 0。扫描到 7 时 bad = 4；最后的 5 虽然更新 hi，但 lo = 0 仍在 bad 之前，无法组成合法区间。

边界与数值范围

  • minK = maxK：同一元素要同时更新 lo、hi，连续匹配段长度为 m 时贡献总计 m(m+1)/2。
  • 某个边界没有出现，或者只在最近越界点之前出现：公式经 max(0,…) 截断为 0。
  • minK > maxK：不可能满足定义。此时每个元素都会被判为越界，公式自然返回 0。
  • 最大答案是 100000×100001/2 = 5000050000。Java 用 long，C++ 用 long long；Python 整数足够，JavaScript Number 在此范围内精确。

复杂度

时间 O(n)，每个元素处理一次；算法额外空间 O(1)。扫描台为回放保存状态与记录，属于教学界面的额外开销。

替代方案

朴素法固定左端点并向右扩展，维护区间最小值与最大值，时间 O(n²)、额外空间 O(1)，不适用于上限规模。也可用容斥：令 F(a,b) 为所有元素落在 [a,b] 中的子数组数量，答案为 F(minK,maxK) − F(minK+1,maxK) − F(minK,maxK−1) + F(minK+1,maxK−1)。F 可通过连续合法段长度单次扫描求出；空范围记 0。这是 O(n) 时间、O(1) 空间的多次扫描方案。

常见错误

  • 只检查所有值在范围内，却没保证两个边界都出现。
  • 使用 max(lo,hi)，导致遗漏一个边界的区间也被计入。
  • 把贡献写成 min(lo,hi)−bad+1；起点下界是 bad+1，本身已抵消 +1。
  • 用 else if 更新两个边界，使 minK = maxK 时只能更新一个位置。
  • 不截断负贡献；或用 32 位整数保存累计结果。

面试追问

  • 能流式处理吗？可以，仅保留三个最近位置、当前下标和累计答案。
  • 为什么不必重置 lo、hi？越界后的 bad 会自动排除它们在旧段中的位置。
  • 要输出所有区间呢？对每个 r 枚举合法起点范围，时间为 O(n+答案数量)，最坏输出本身是 O(n²)。
  • 若边界频繁变化？当前三个位置针对固定边界；查询更换边界时需要重新计算，不能直接复用状态。

07 / IMPLEMENTATIONS

四种语言 · 官方签名

Java

class Solution {
    public long countSubarrays(int[] nums, int minK, int maxK) {
        int bad = -1, lo = -1, hi = -1;
        long answer = 0;
        for (int r = 0; r < nums.length; r++) {
            int x = nums[r];
            if (x < minK || x > maxK) bad = r;
            if (x == minK) lo = r;
            if (x == maxK) hi = r;
            answer += Math.max(0, Math.min(lo, hi) - bad);
        }
        return answer;
    }
}
