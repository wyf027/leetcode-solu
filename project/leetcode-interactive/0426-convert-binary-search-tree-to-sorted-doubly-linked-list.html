Problem

题意转述

给定一棵二叉搜索树 root，将它原地改造成一个按节点值升序排列的循环双向链表。不得创建新的节点；需要复用每个节点原有的两个指针。

L

转换后，节点的 left 指向前驱，right 指向后继。

↻

返回最小节点作为表头。表头的前驱是最大节点，最大节点的后继又回到表头，因此链表首尾闭合。

函数参数： treeToDoublyList(root: TreeNode) → ListNode。官方元数据将返回类型记为 ListNode，实际提交环境复用题目给出的 Node 类型。

Contract

01树中节点数位于 [0, 2000]。
02-1000 ≤ Node.val ≤ 1000。
03所有节点值互不相同，输入满足二叉搜索树性质。
04空树返回 null；非空结果必须是循环链表。

注意：返回结果不能用普通的“遍历到 null”方式检查，因为链表会回到表头。

Solution

中序遍历时就地接线

核心洞察：二叉搜索树的中序遍历天然按值递增。遍历到当前节点 cur 时，只要记住上一个访问节点 prev，就能立刻建立 prev.right = cur 与 cur.left = prev。第一次访问的节点是表头，最后访问的节点是表尾。
  1. 若 root 为空，直接返回 null。
  2. 用 head 保存第一次访问的节点，用 prev 保存最近访问的节点。
  3. 递归处理左子树；随后访问当前节点。若 prev 已存在，就把它和当前节点双向连接，否则将当前节点记为 head。
  4. 更新 prev = cur，再递归处理原来的右子树。
  5. 遍历结束后，prev 是最大节点。连接 head.left = prev 与 prev.right = head，完成闭环。
时间复杂度O(n)每个节点恰好访问一次。
额外空间O(h)递归栈深度等于树高；最坏为 O(n)。

Proof

正确性说明

遍历不变量：在访问当前节点前，所有已经访问的节点构成一个按值递增、尚未闭环的双向链表；head 指向其中最小节点，prev 指向最大节点。

  • 中序遍历保证当前节点值大于全部已访问节点，因此它正是 prev 的后继。
  • 双向赋值后，新链表仍有序，且当前节点成为新的尾部，不变量继续成立。
  • 遍历全部节点后，链表含且仅含原树全部节点，并按升序排列。
  • 最后只连接头尾，不改变中间顺序；于是得到满足要求的循环双向链表。

Edges

边界情况

  • 空树：没有头尾节点，必须在闭环赋值前返回。
  • 单节点：它同时是头和尾，最终左右指针都指向自己。
  • 退化树：递归深度可能达到节点数；若担心栈溢出，可改用显式栈。
  • 多次调用：把 head、prev 作为成员字段时，每次入口都应重置。

/*
// Definition for a Node.
class Node {
    public int val;
    public Node left;
    public Node right;
    public Node() {}
    public Node(int val) { this.val = val; }
    public Node(int val, Node left, Node right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
};

class Solution {
    private Node head;
    private Node prev;

    public Node treeToDoublyList(Node root) {
        if (root == null) {
            return null;
        }

        head = null;
        prev = null;
        inorder(root);

        head.left = prev;
        prev.right = head;
        return head;
    }

    private void inorder(Node node) {
        if (node == null) {
            return;
        }

        inorder(node.left);
        if (prev == null) {
            head = node;
        } else {
            prev.right = node;
            node.left = prev;
        }
        prev = node;
        inorder(node.right);
    }
}

Alternatives

替代方案

  • 显式栈中序遍历：同样为 O(n) 时间和 O(h) 空间，可避免系统递归栈过深；接线逻辑完全相同。
  • 先收集再连接：把节点按中序放入数组，再统一连接。思路直观，但额外空间为 O(n)，没有利用“边遍历边连接”的性质。
  • Morris 中序遍历：理论上可做到 O(1) 额外空间，但临时线索会与最终指针改造相互影响，实现和证明更易出错，面试中需谨慎说明。

Pitfalls

常见错误

  • 只连接相邻节点，却忘记连接最终的头和尾。
  • 仅设置 prev.right，遗漏反向的 cur.left。
  • 空树时仍访问 head.left，造成空指针错误。
  • 返回原根节点而不是最小节点 head。
  • 把循环链表当普通链表遍历，导致测试代码无限循环。

Interview

面试追问

如何避免递归栈溢出？

改用显式栈模拟中序遍历；每弹出一个节点就按同样方式与前驱双向连接。

如何验证“循环”而不死循环？

先统计原树节点数 n，再从 head 沿 right 恰好走 n 步，检查序列升序且第 n 步回到 head；反向同理。

为什么第一次访问的节点一定是表头？

BST 的中序遍历首先到达全树最左节点，它是全树最小值，因此应作为排序链表的头。

如果节点值允许重复怎么办？

结构转换仍可进行，但“有序”应改为非递减；BST 对重复值放置规则必须明确，算法本身不依赖严格唯一性。
