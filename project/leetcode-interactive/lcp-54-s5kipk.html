夺回据点 点双连通要塞图

“剩余据点始终连通”把图论直觉带到点双连通分量。缩点后的圆方树是一棵树：只需在叶子分量预先破局，但可以留一个叶子最后免费收尾。

题意

初始可付费夺回若干据点；以后每一步可免费夺回一个与已夺回集合相邻的据点。任何一步后，所有尚未夺回的据点必须仍连通。求最小初始资源。

输入

cost = [1,2,3,4,5,6]roads = [[0,1],[0,2],[1,3],[2,3],[1,2],[2,4],[2,5]]

期望输出

6

解释

三个叶子点双的最低成本为 1、5、6；保留最大 6 作为最终收尾，付 1+5。

输入字段完整展示：cost = [...]、roads = [...]。若有空格，页面会以 ␠ 表示；本题输入没有字符串营地名。

关键结论

  • Tarjan 把原图分为点双连通分量。
  • 分量和割点构成一棵圆方树。
  • 每个叶子分量必须选一个非割点作为起点。
  • 最后一个叶子可不付费：答案为叶子候选和减去最大候选。

核心洞察

在点双分量内删除任何一个点都不会使其余点分裂，因此只要从一个非割点进入，就能合法地逐步夺回该分量。把每个点双分量作为方点、割点作为圆点后得到树；树的叶方点是必须付费“开门”的位置。只需开除一个之外的全部叶方点，因为最后一个可由已夺回部分反向收尾。

Tarjan 与贪心流程

  1. DFS 维护 dfn、low 和点栈。
  2. 树边 u → v 回溯时若 low[v] ≥ dfn[u]，弹栈得到一个点双分量。
  3. 统计每个原点属于多少点双分量；次数大于 1 的是割点。
  4. 若只有一个点双，付所有顶点成本最小值。
  5. 否则，对每个恰含一个割点的叶点双，取其中非割点的最小成本；答案是候选总和减最大候选。

边界

  • 单个据点直接付它的成本。
  • 整张图本身点双连通时只需要一个最小成本点。
  • 桥边也会形成含两个端点的点双；叶桥的非割点端可作为候选。
  • cost 达到 109，和必须用 64 位整数。

复杂度与替代方案

Tarjan 每个顶点、边常数次访问，时间 O(n+m)，空间 O(n+m)。暴力枚举初始集合是指数级；只找割点却不恢复点双结构，无法得到每个叶子区域的最小非割点成本。

面试追问与常见错误

追问：若道路增删，需要动态图连通性结构而非一次 Tarjan。常见错误：把边双当点双、叶子分量直接取所有点的最小值（割点不能先拿）、忘记减去最大叶候选、以及用 int 累加答案。

class Solution:
    def minimumCost(self, cost: List[int], roads: List[List[int]]) -> int:
        n = len(cost)
        if n == 1: return cost[0]
        g = [[] for _ in range(n)]
        for a,b in roads: g[a].append(b); g[b].append(a)
        dfn=[0]*n; low=[0]*n; st=[]; bcc=[]; timer=0
        def dfs(u, p):
            nonlocal timer
            timer += 1; dfn[u] = low[u] = timer; st.append(u)
            for v in g[u]:
                if v == p: continue
                if not dfn[v]:
                    dfs(v,u); low[u] = min(low[u],low[v])
                    if low[v] >= dfn[u]:
                        cur=[]
                        while True:
                            x=st.pop(); cur.append(x)
                            if x == v: break
                        cur.append(u); bcc.append(cur)
                else: low[u] = min(low[u],dfn[v])
        dfs(0,-1)
        if len(bcc) == 1: return min(cost)
        cnt=[0]*n
        for c in bcc:
            for x in c: cnt[x]+=1
        vals=[min(cost[x] for x in c if cnt[x]==1) for c in bcc if sum(cnt[x]>1 for x in c)==1]
        return sum(vals)-max(vals)
