Problem brief

题意转述

给定数组 lists，其中每个元素都是一条按升序排列的链表。把全部节点合并成一条升序链表并返回。

关键约束：0 <= k <= 10⁴，单链长度不超过 500，总节点数 N <= 10⁴，节点值在 [-10⁴, 10⁴]。
可见字符：若字符串含空格，统一用 ␠ 标出；本题输入为链表数组，不含字符串空格。

Core insight

只比较 k 个当前头节点

每条链表已经有序，因此一条链表中尚未合并的最小值一定是它的当前头节点。

把所有非空头节点放入小根堆。每次弹出全局最小节点接到结果尾部；若该节点还有后继，只把后继补入堆。

堆中每条链表至多一个节点，规模不超过 k；原节点直接重连，无需复制节点值。

Invariant

循环不变量

  • 结果链表始终有序，尾节点是已处理节点中的最大值。
  • 堆中保存每条未耗尽链表的最小未处理节点。
  • 堆顶必是所有未处理节点中的全局最小值。

Process

完整过程

  1. 创建哑节点、尾指针和小根堆。
  2. 将每条非空链表的头节点入堆。
  3. 弹出堆顶，接到结果尾部并移动尾指针。
  4. 若弹出节点有后继，把后继入堆。
  5. 堆空时返回 dummy.next。

Edges

边界情况

  • lists = []：堆始终为空，返回空链表。
  • lists = [[]]：跳过空头节点。
  • 重复值：任意相同值先出堆都不影响升序结果。
  • 只有一条链表：仍正确，堆规模始终为 1。

Complexity

复杂度

设总节点数为 N，链表数为 k。

时间：O(N log k)

辅助空间：O(k)

结果链表复用原节点，不把输出节点计入额外空间。

替代方案

两两顺序合并最坏会退化到 O(Nk)。分治合并同样是 O(N log k)，常数可能更小，也容易复用第 21 题；小根堆更直接体现“从 k 个车头选最小”的在线过程，是本页主线。

面试高频追问

  • 为什么堆大小是 k？每条链只贡献一个当前头节点。
  • 能否原地合并？可以，改变原节点的 next 指针即可。
  • Java 比较器会溢出吗？用 Integer.compare，不要直接相减。

常见错误

  • 把空链表头节点放入堆，触发空指针。
  • 弹出节点后忘记把它的后继补入堆。
  • 只保存节点值，丢失后继链关系。
  • 复杂度写成 O(N log N)，忽略堆规模只有 k。

import java.util.PriorityQueue;

class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        PriorityQueue<ListNode> heap = new PriorityQueue<>(
            (a, b) -> Integer.compare(a.val, b.val)
        );

        for (ListNode head : lists) {
            if (head != null) {
                heap.offer(head);
            }
        }

        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;

        while (!heap.isEmpty()) {
            ListNode node = heap.poll();
            tail.next = node;
            tail = node;

            if (node.next != null) {
                heap.offer(node.next);
            }
        }

        return dummy.next;
    }
}
class MinHeap {
    constructor() {
        this.data = [];
    }

    push(node) {
        this.data.push(node);
        let index = this.data.length - 1;
        while (index > 0) {
            const parent = Math.floor((index - 1) / 2);
            if (this.data[parent].val <= this.data[index].val) break;
            [this.data[parent], this.data[index]] = [
                this.data[index],
                this.data[parent],
            ];
            index = parent;
        }
    }

    pop() {
        const root = this.data[0];
        const last = this.data.pop();
        if (this.data.length > 0) {
            this.data[0] = last;
            let index = 0;
            while (true) {
                let smallest = index;
                const left = index * 2 + 1;
                const right = left + 1;
                if (left < this.data.length && this.data[left].val < this.data[smallest].val) smallest = left;
                if (right < this.data.length && this.data[right].val < this.data[smallest].val) smallest = right;
                if (smallest === index) break;
                [this.data[index], this.data[smallest]] = [
                    this.data[smallest],
                    this.data[index],
                ];
                index = smallest;
            }
        }
        return root;
    }

    get size() {
        return this.data.length;
    }
}

var mergeKLists = function (lists) {
    const heap = new MinHeap();
    for (const head of lists) {
        if (head !== null) heap.push(head);
    }

    const dummy = new ListNode(0);
    let tail = dummy;
    while (heap.size > 0) {
        const node = heap.pop();
        tail.next = node;
        tail = node;
        if (node.next !== null) heap.push(node.next);
    }
    return dummy.next;
};
import heapq
from typing import List, Optional


class Solution:
    def mergeKLists(
        self, lists: List[Optional[ListNode]]
    ) -> Optional[ListNode]:
        heap = []
        for list_index, node in enumerate(lists):
            if node is not None:
                heapq.heappush(heap, (node.val, list_index, node))

        dummy = ListNode(0)
        tail = dummy

        while heap:
            _, list_index, node = heapq.heappop(heap)
            tail.next = node
            tail = node

            if node.next is not None:
                heapq.heappush(
                    heap, (node.next.val, list_index, node.next)
                )

        return dummy.next
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    ListNode* mergeKLists(vector<ListNode*>& lists) {
        auto compare = [](ListNode* a, ListNode* b) {
            return a->val > b->val;
        };
        priority_queue<
            ListNode*,
            vector<ListNode*>,
            decltype(compare)
        > heap(compare);

        for (ListNode* head : lists) {
            if (head != nullptr) heap.push(head);
        }

        ListNode dummy(0);
        ListNode* tail = &dummy;
        while (!heap.empty()) {
            ListNode* node = heap.top();
            heap.pop();
            tail->next = node;
            tail = node;
            if (node->next != nullptr) heap.push(node->next);
        }
        return dummy.next;
    }
};
