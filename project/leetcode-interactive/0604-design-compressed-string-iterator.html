Problem

题目转述

给定一个压缩字符串，其中每一段都由一个英文字母和紧随其后的正整数构成；整数表示该字母在原字符串中连续出现的次数。请实现 StringIterator，按需迭代原字符串，而不是一次性展开全部内容。

  • StringIterator(string compressedString)：用压缩字符串初始化迭代器。
  • char next()：若仍有字符，返回原字符串中的下一个字符；若已经耗尽，返回空格字符 ' '。
  • boolean hasNext()：仍有未返回字符时为 true，否则为 false。

接口签名

StringIterator(compressedString) char next() boolean hasNext()

压缩段可能包含多位计数，例如 a12。计数上界很大，因此“先完整解压再迭代”会浪费内存。

Official example

官方示例（完整参数形式）

输入操作：
["StringIterator", "next", "next", "next", "next", "next", "next", "hasNext", "next", "hasNext"]

输入参数：
[["L1e2t1C1o1d1e1"], [], [], [], [], [], [], [], [], []]

输出：
[null, "L", "e", "e", "t", "C", "o", true, "d", true]

构造器只建立状态；连续六次 next() 得到 L、e、e、t、C、o。此时仍剩 d1e1，所以 hasNext() 为 true；再取出 d 后仍有一个 e，最后一次 hasNext() 仍为 true。

Constraints

约束与格式

1 ≤ compressedString.length ≤ 1000 压缩输入本身长度有限。
[a-zA-Z0-9] 输入由大小写英文字母和数字组成。
1 ≤ count ≤ 10⁹ 每个字母后的出现次数是正整数。
letter + positive integer 每段严格由字母开头，后接一位或多位计数。

Solution

题解：保留一段，按需消费

核心洞察

迭代器从来不需要同时持有完整解压结果。只要保存四个状态：压缩字符串、下一个未解析位置、当前字母、当前段剩余次数。当前段归零时才解析下一段；每次 next() 只消费一次计数。

完整过程

  1. 构造时保留 compressedString，令扫描位置为 0、剩余次数为 0。
  2. 调用 hasNext() 时，若当前段仍有剩余次数，直接返回 true。
  3. 否则从扫描位置读取一个字母，再连续读取其后的所有数字，按 count = count × 10 + digit 组合多位计数。
  4. 若压缩串已没有下一段，hasNext() 返回 false；否则新段装载完成，返回 true。
  5. next() 先借助 hasNext() 确保当前段存在，然后将剩余次数减一并返回当前字母；若已耗尽则返回空格。

正确性说明

引理 1 · 段解析正确

扫描器先读取段首字母，再读取直至下一个非数字位置；十进制累积式恰好得到该字母的完整次数，扫描位置恰好停在下一段开头。

引理 2 · 每次只消费一个

每次成功的 next() 返回当前字母并将其剩余次数减一，因此既不会漏掉当前段字符，也不会重复消费同一次数。

结论 · 顺序完全一致

由引理 1，各段按压缩串顺序装载；由引理 2，每段返回准确次数。故所有返回字符与原字符串顺序、数量均一致，耗尽后正确返回空格。

复杂度

时间：摊还 O(1) / 调用

解析新段时需读取该计数的若干位，单次最坏为 O(d)；但每个压缩字符只被扫描一次，所以连续调用的摊还成本为 O(1)。产生 k 个字符的总成本为 O(|compressedString| + k)。

空间：O(1)

除保存输入字符串外，仅维护索引、当前字母和剩余计数，不构造解压数组。

边界情况

  • 计数可能有多位，例如 a100，不能只读一个数字。
  • 多次连续调用 hasNext() 不得跳过字符或重复装载段。
  • 最后一个字符被取走后，下一次 hasNext() 必须为 false。
  • 耗尽后反复调用 next() 都应返回空格字符。
  • 计数可达 10⁹，语言中的计数类型与累积过程要避免溢出。
  • 大小写字母不同，必须按原字符返回。

四语言完整代码

class StringIterator {
    private final String compressed;
    private int index;
    private char current;
    private long remaining;

    public StringIterator(String compressedString) {
        compressed = compressedString;
        index = 0;
        current = ' ';
        remaining = 0;
    }

    public char next() {
        if (!hasNext()) {
            return ' ';
        }
        remaining--;
        return current;
    }

    public boolean hasNext() {
        if (remaining > 0) {
            return true;
        }
        if (index >= compressed.length()) {
            return false;
        }

        current = compressed.charAt(index++);
        long count = 0;
        while (index < compressed.length()
                && Character.isDigit(compressed.charAt(index))) {
            count = count * 10 + (compressed.charAt(index) - '0');
            index++;
        }
        remaining = count;
        return true;
    }
}

 * @return {boolean}
 */
StringIterator.prototype.hasNext = function () {
    if (this.remaining > 0) {
        return true;
    }
    if (this.index >= this.compressed.length) {
        return false;
    }

    this.current = this.compressed[this.index++];
    let count = 0;
    while (this.index < this.compressed.length
            && /[0-9]/.test(this.compressed[this.index])) {
        count = count * 10 + Number(this.compressed[this.index]);
        this.index++;
    }
    this.remaining = count;
    return true;
};
class StringIterator:
    def __init__(self, compressedString: str):
        self.compressed = compressedString
        self.index = 0
        self.current = " "
        self.remaining = 0

    def next(self) -> str:
        if not self.hasNext():
            return " "
        self.remaining -= 1
        return self.current

    def hasNext(self) -> bool:
        if self.remaining > 0:
            return True
        if self.index >= len(self.compressed):
            return False

        self.current = self.compressed[self.index]
        self.index += 1

        count = 0
        while (self.index < len(self.compressed)
               and self.compressed[self.index].isdigit()):
            count = count * 10 + int(self.compressed[self.index])
            self.index += 1

        self.remaining = count
        return True

private:
    string compressed;
    int index = 0;
    char current = ' ';
    long long remaining = 0;

public:
    StringIterator(string compressedString)
        : compressed(std::move(compressedString)) {}

    char next() {
        if (!hasNext()) {
            return ' ';
        }
        --remaining;
        return current;
    }

    bool hasNext() {
        if (remaining > 0) {
            return true;
        }
        if (index >= static_cast<int>(compressed.size())) {
            return false;
        }

            count = count * 10 + (compressed[index] - '0');
            ++index;
        }
        remaining = count;
        return true;

替代方案

  • 构造时解析为 (字符, 次数) 数组：实现直观，后续访问也清晰；但需要 O(段数) 额外空间，本题并不必要。
  • 完整解压：写法最简单，却可能尝试分配 10⁹ 级别字符，违背按需迭代的设计目标，应避免。
  • 生成器 / yield：在支持生成器的语言中表达自然，但在线评测要求固定类接口，仍需包装 next 与 hasNext 语义。

常见错误

  • 把计数当成单个数字，导致 a12 被错误解析为两段或只返回一次。
  • hasNext() 每调用一次都装载新段，从而跳过尚未消费完的当前段。
  • 在 next() 返回字符前错误地装载下一段，造成边界处顺序错乱。
  • 耗尽时返回空字符串、null 或异常，而不是题目指定的空格字符。
  • 预先构造完整字符串，计数很大时导致内存耗尽。
