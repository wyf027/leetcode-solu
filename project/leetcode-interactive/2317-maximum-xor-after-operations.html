2317. 操作后的最大异或和

Maximum XOR After Operations

一次更新会如何改变一个数的二进制位？先观察操作前后的变化，再尝试解释所有元素的异或结果。

数组位运算数学官方题目 ↗

01 / 题目

你可以做什么？

给定下标从 0 开始的整数数组 nums。每次选一个合法下标 i 和任意非负整数 x，只更新这个位置：

nums[i] = nums[i] AND (nums[i] XOR x)

其中 AND 是按位与，XOR 是按位异或。允许进行任意次操作，也允许一次都不做。返回操作后所有数组元素按位异或能得到的最大值；这里的“异或和”不是普通加法。

参数：nums: integer[]　返回：integer　函数：maximumXOR(nums)

  • 1 ≤ nums.length ≤ 105
  • 0 ≤ nums[i] ≤ 108

官方示例 1

输入：nums = [3,2,4,6]
输出：7

选 i = 3, x = 4：6 AND (6 XOR 4) = 2。数组变成 [3,2,4,2]，异或结果为 7，这是最大值。

官方示例 2

输入：nums = [1,2,3,9,2]
输出：11

不执行操作，1 XOR 2 XOR 3 XOR 9 XOR 2 = 11，已达到最大值。

04 / 独立题解

准备好解释你的观察了吗？

答案是所有元素的按位或

核心洞察：a AND (a XOR x) = a AND (NOT x)。操作能清除任意已有的 1，却无法把 0 变成 1。每一位独立，异或结果在某位为 1，当且仅当该列的 1 的个数为奇数。

完整过程

  1. 令 ans = 0。
  2. 遍历数组，对每个值执行 ans |= value，收集曾经出现过的所有 1 位。
  3. 返回 ans。无需真的修改数组或寻找每一步操作。

以 [3,2,4,6] 为例：累计 OR 为 0 → 3 → 3 → 7 → 7。它描述所有可能保留的位。真正执行操作时，二进制第 2 位有两个 1，可以清掉 6 的这一位，让该列的数量变为奇数，即得到官方的 [3,2,4,2]。

正确性：上界与可达性

上界：原数组某位全为 0 时，任何操作都不能产生该位的 1，所以最终异或值只能使用原数组按位或中存在的位。对于非负整数，这样的结果不超过原数组的按位或。

可达：逐位考虑。如果某列 1 的个数为奇数，不做操作；如果是正偶数，选一个在该位为 1 的元素，令 x = 1 << b 清掉这一位。数量变为奇数，且其他位不受影响；若数量为 0，则保持 0。最终所有曾出现过的位都在异或结果中为 1，恰好达到按位或这个上界。因此算法正确。

边界与复杂度

  • 全为 0：答案为 0；单个元素：保持原值最优。
  • 相同元素出现偶数次：原始 XOR 可能为 0，但允许清位后可得到非零结果。
  • 允许零次操作，因此原始 XOR 已最优时不必更新。
  • 时间 O(n)，额外空间 O(1)，不修改输入。
  • 题目数值小于 2^27，结果不超过 2^27 - 1。JavaScript 的 32 位有符号位运算在本题范围内安全；扩大数值范围时应改用 BigInt。

替代方案

显式逐位统计并构造操作需要 O(nB) 时间（本题 B ≤ 27），适合演示或要求返回操作序列时使用。也可为每一位只保留一个拥有者，把其他同位的 1 清掉，得到同样结果。只求最大值时一次 OR 扫描即可，不需要排序、动态规划或字典树。

常见错误

  • 直接 XOR 全数组：忽略了允许的操作，例如 [8,8]。
  • 误认为可以任意置位：外层 AND 会阻止新位出现。
  • 返回最大元素：不同元素的位可以贡献到同一个结果中，如 [1,2,4] 的答案为 7。
  • 把问题当成两数最大异或：这里是全数组，并且允许清位。
  • 代码使用 ans ^= value：提交代码应累计 OR，而不是原始 XOR。

面试追问

如果要求操作序列？按正偶数列清一位即可，每位至多一次，总共至多 27 次；也能先确定每个元素要清除的掩码，合并对同一元素的操作。

若只允许一次操作呢？不一定能达到 OR。例如 [1,1,2,2] 需要分别改变两个元素才能得到 3，一次操作最多得到 2。

可以用 JavaScript 的无限位整数吗？可以，改用 BigInt 并用 0n 初始化，但必须统一整数类型，不能把 Number 与 BigInt 混合做位运算。

四种语言 · 官方提交签名

Java

class Solution {
    public int maximumXOR(int[] nums) {
        int ans = 0;
        for (int value : nums) {
            ans |= value;
        }
        return ans;
    }
}

    return ans;
};
