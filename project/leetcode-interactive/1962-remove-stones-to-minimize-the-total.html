移除石子使总数最小

Remove Stones to Minimize the Total

一次移走一堆的一半。有限的操作，怎样让留下的石子尽可能少？

阅读题目·待验证用例·前往题解入口

01 / PROBLEM

题目与规则

给定从下标 0 开始的整数数组 piles 和整数 k。piles[i] 是第 i 堆的石子数。每次选择一堆，移除该堆当前石子数除以 2 后向下取整的数量。同一堆可以反复选择。执行恰好 k 次操作后，返回可能达到的最小剩余总数。

例如 5 颗移走 ⌊5 / 2⌋ = 2 颗，留下 3 颗；1 颗时移走 0 颗，这仍算一次操作。

官方示例 1

输入：piles = [5,4,9], k = 2
输出：12

选择下标 2：[5,4,9] → [5,4,5]；再选择下标 0：[5,4,5] → [3,4,5]。剩余总数为 12。

官方示例 2

输入：piles = [4,3,6,7], k = 3
输出：12

依次选择下标 2、3、0：[4,3,6,7] → [4,3,3,7] → [4,3,3,4] → [2,3,3,4]。剩余总数为 12。

约束

  • 1 ≤ piles.length ≤ 10⁵
  • 1 ≤ piles[i] ≤ 10⁴
  • 1 ≤ k ≤ 10⁵

03 / THINK FIRST

准备好再展开

下面包含策略、交互演示、证明和四种语言实现。

题解：每次从当前最大堆移除

一堆有 x 颗时，本次收益是 ⌊x/2⌋，留下 ⌈x/2⌉ = x - ⌊x/2⌋。石堆越大，可移除数量越多；重复操作同一堆时，其后续收益只会下降。因此每次取当前最大堆，用最大堆数据结构维护即可。

完整过程

  1. 计算初始总数，将所有堆加入最大堆。
  2. 取堆顶 x，计算移除数 removed = floor(x / 2)。
  3. 总数减去 removed，并将 x - removed 放回堆中。
  4. 重复恰好 k 次，返回总数。若最大值已是 1，剩余操作收益全为 0，可直接返回。

示例 1：总数 18；取 9，移除 4，留下 5，总数 14；再取一个 5，移除 2，留下 3，总数 12。示例 2 也可先取 7，再取 6，再取 4，移除量依次为 3、3、2，最终总数 12；最优操作顺序不一定唯一。

正确性：合并递减的收益序列

把每堆独立操作时的移除数列出来，例如 9 的收益为 4,2,1,1,0,…。每条序列非递增；对某堆操作 t 次，恰好取该序列的前 t 项。目标等价于从这些序列中取总共 k 项且各自为前缀，使收益总和最大。

当前每条序列只暴露它尚未取出的第一项。任一隐藏项都不大于该序列当前暴露项，所以所有尚未取出的收益中，最大项一定可在暴露项中选到。取走最大的暴露项，再暴露该序列下一项，仍保持这个性质。如此连续 k 次，就是按非增序选择 k 个最大可用收益，同时满足前缀条件，因此总移除量最大，剩余总数最小。因为 ⌊x/2⌋ 随 x 单调不减，选择最大石堆必然取得最大暴露收益。并列时任选一个都成立。

边界与复杂度

  • 奇数向上取整后保留：5 留下 3，不能留下 2。
  • 所有石堆至少留下 1 颗；全为 1 时，再多操作都不会改变结果。
  • 总和最大为 10⁹，Java/C++ 的 32 位有符号 int 足够，JavaScript Number 可精确表示。
  • 设 n 为堆数：统一上界为 O((n+k) log(n+1)) 时间、O(n) 辅助空间。Java 逐项入堆花费 O(n log(n+1))；其余三份代码使用线性建堆，得到更紧的 O(n+k log(n+1)) 时间界。
  • 演示为了保存上一步使用状态快照；提交代码不保存历史，空间界不包含演示。

替代方案

每次线性扫描最大值实现简单，但需要 O(kn) 时间。每轮重新排序需要 O(kn log(n+1)) 时间。利用本题数值上限 M = 10⁴，可以用计数桶记录每个大小的堆数，维护只向下移动的最大非空位置，单次操作把一堆移到 ⌈x/2⌉ 的桶：总时间 O(n+M+k)，空间 O(M)。堆方案对更大的值域更通用。

常见错误

  • 把“移除一半向下取整”写成“剩下一半向下取整”。
  • 只对初始数组排序一次，之后不维护最大值；第一次操作后顺序会改变。
  • 误认为每堆只能选择一次，或使用最小堆却没有反转优先级。
  • 修改堆顶后忘记恢复堆性质；这里堆顶只会变小，向下调整就足够。
  • 提前停止却没有说明剩余操作等价于零收益操作。

面试追问

  • 相邻大小的堆收益一样怎么办？例如 4 和 5 都移除 2，任选均可，最大堆取较大者也合法。
  • k 特别大怎么办？最大值到 1 后直接结束；每堆变到 1 至多需要 ⌈log₂ M⌉ 次有效操作。
  • 若移除收益不再随重复操作递减？上述证明不再成立，可能需要动态规划等全局方法，不能直接沿用贪心。
  • 只关心数量，是否需要保留下标？提交解法不需要；演示保留下标只是为了跟踪同一堆。

四种语言实现

均采用官方函数签名；JavaScript 使用原生数组最大堆，无第三方优先队列依赖。代码仅生成，待补验证。

Java

import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public int minStoneSum(int[] piles, int k) {
        PriorityQueue<Integer> heap =
            new PriorityQueue<>(Collections.reverseOrder());
        int total = 0;
        for (int x : piles) {
            heap.offer(x);
            total += x;
        }
        while (k-- > 0 && heap.peek() > 1) {
            int x = heap.poll();
            int removed = x / 2;
            total -= removed;
            heap.offer(x - removed);
        }
        return total;
    }
}

JavaScript

/**
 * @param {number[]} piles
 * @param {number} k
 * @return {number}
 */
var minStoneSum = function(piles, k) {
    const heap = piles.slice();
    const n = heap.length;
    let total = heap.reduce((a, b) => a + b, 0);
    function down(i) {
        while (2 * i + 1 < n) {
            let child = 2 * i + 1;
            if (child + 1 < n &&
                heap[child + 1] > heap[child]) child++;
            if (heap[i] >= heap[child]) break;
            [heap[i], heap[child]] = [heap[child], heap[i]];
            i = child;
        }
    }
    for (let i = Math.floor(n / 2) - 1; i >= 0; i--) {
        down(i);
    }
    while (k-- > 0 && heap[0] > 1) {
        const removed = Math.floor(heap[0] / 2);
        total -= removed;
        heap[0] -= removed;
        down(0);
    }
    return total;
};

Python

from typing import List
import heapq

class Solution:
    def minStoneSum(self, piles: List[int], k: int) -> int:
        heap = [-x for x in piles]
        heapq.heapify(heap)
        total = sum(piles)
        for _ in range(k):
            x = -heap[0]
            if x == 1:
                break
            removed = x // 2
            total -= removed
            heapq.heapreplace(heap, -(x - removed))
        return total
