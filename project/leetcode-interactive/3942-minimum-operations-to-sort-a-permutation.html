3942. 排序排列的最少操作数

只允许「整段反转」与「左旋一位」。它们并不能生成任意排列：可达状态恰好是一圈的正向或反向排列。

打开力扣题目

题意

给定 nums，它是 0…n-1 的一个排列。每次可反转整个数组，或把第一个元素移到末尾。求把它变成递增序列所需的最少次数；不可能则返回 -1。

输入 输出 一条最短过程
nums = [0, 2, 1] 2 左旋 → 反转
nums = [1, 0, 2] 2 反转 → 左旋
nums = [2, 0, 1, 3] -1 既非正向环也非反向环

约束：1 ≤ nums.length ≤ 105，且每个值都在 0…n-1 中且不重复。

先观察可达形状

  1. 左旋只改变环的起点，不改变相邻方向。
  2. 反转把环的方向翻转。
  3. 所以每个位置的下一个数只能始终是 (x+1) mod n 或始终是 (x-1+n) mod n。

核心洞察与完整过程

先检查正向：令 c = nums[0]，每个位置必须满足 nums[i] = (c+i) mod n。可直接左旋 (n-c) mod n 次；也可利用 R·Lc·R = L-c，代价是 c+2。两者取较小值。

再检查反向：每个位置必须满足 nums[i] = (c-i+n) mod n。此时有两条只用一次反转的路：先左旋 (c+1) mod n 次再反转，或先反转后左旋 (n-1-c) mod n 次，取较小值。

边界、复杂度与替代方案

  • n = 1 已经有序，答案为 0。
  • 正向判定优先返回；它与反向在 n=1 的重叠不影响答案。
  • 两轮线性扫描：时间 O(n)，额外空间 O(1)。
  • 替代方案是 BFS 枚举操作，但状态数随 n! 增长，不适用于约束。

面试追问

若允许右旋一位，操作距离如何变化？右旋等价于 n-1 次左旋，因此可把正向环上的距离改成双向最短距离。若只能反转任意子段，生成的群变大，当前环形判定不再成立。

常见错误

  • 把反向情况只写成一次反转，漏掉旋转位置。
  • 负数取模没有补 n。
  • 把反转后的目标误认为 [0,1,…]，而不是 [n-1,…,0]。

class Solution {
    public int minOperations(int[] nums) {
        int n = nums.length, c = nums[0];
        boolean forward = true, backward = true;
        for (int i = 0; i < n; i++) {
            if (nums[i] != (c + i) % n) forward = false;
            if (nums[i] != (c - i + n) % n) backward = false;
        }
        if (forward) return Math.min((n - c) % n, c + 2);
        if (!backward) return -1;
        int a = (c + 1) % n + 1;
        int b = (n - 1 - c + n) % n + 1;
        return Math.min(a, b);
    }
}
