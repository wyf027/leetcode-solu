LeetCode 944 · Column Scan

删列造序

Delete Columns to Make Sorted

EASY数组字符串

题目

给定由 n 个等长小写字母字符串组成的数组 strs。将每个字符串放成一行，检查每一列是否从上到下按字典序非严格递增。删除所有不满足条件的列，返回删除列数。

示例 1
输入：strs = ["cba","daf","ghi"]
输出：1
解释：列 1 的 b → a 出现下降。

示例 2
输入：strs = ["a","b"]
输出：0
解释：唯一一列 a → b 已有序。

示例 3
输入：strs = ["zyx","wvu","tsr"]
输出：3
解释：三列均不是升序。

参数与约束

minDeletionSize(strs: string[]) → integer
  • n == strs.length
  • 1 ≤ n ≤ 100
  • 1 ≤ strs[i].length ≤ 1000
  • 字符串等长，只含小写英文字母

判断的是每一列内部的字符顺序；无需真的删除字符。

Solution

逐列寻找第一次下降

核心洞察

列与列互不影响。对列 c，若存在相邻两行满足 strs[r-1][c] > strs[r][c]，该列就非法，只需计数一次并转到下一列。

完整过程

  1. 答案初始化为 0。
  2. 从左到右枚举每列。
  3. 从第二行开始，与上一行的同列字符比较。
  4. 首次发现下降时答案加一并跳出内层循环；最后返回答案。

正确性

算法计数的列包含相邻下降，因此必不满足非严格递增，必须删除。未计数的列中每对相邻字符都满足前者不大于后者，由传递性可知整列有序，无需删除。因此算法恰好计数全部且仅全部非法列。

边界与复杂度

单行没有相邻比较，答案为 0；相等字符合法；发现一个下降后无需继续。设行数为 n、列数为 m，时间 O(nm)，额外空间 O(1)。

替代方案

可转置网格或为每列构造字符串再检查，但会产生额外空间；对每列排序再比较则还有不必要的排序开销。直接扫描更优。

面试追问

若要求删除最少列使字符串数组整体有序（955 题），列之间会相互影响，需要维护哪些相邻行已经确定有序；本题各列独立。

常见错误

  • 把非严格递增误写为严格递增。
  • 比较横向字符而非同列字符。
  • 同一非法列对多个下降重复计数。
  • 实际构造删除后的网格。

四语言完整代码

class Solution {
    public int minDeletionSize(String[] strs) {
        int ans = 0;
        for (int c = 0; c < strs[0].length(); c++) {
            for (int r = 1; r < strs.length; r++) {
                if (strs[r - 1].charAt(c) > strs[r].charAt(c)) {
                    ans++;
                    break;
                }
            }
        }
        return ans;
    }
}
