01 / THE CHALLENGE

题目与规则

给定一个 n × n 网格，左上角为 (0,0)，右下角为 (n−1,n−1)。机器人从 startPos = [start_row, start_col] 出发。行号从上向下递增，列号从左向右递增。

另给定长度为 m、下标从 0 开始的字符串 s。字符 L、R、U、D 分别表示向左、右、上、下移动一格。对每个下标 i，机器人都从同一个起点重新出发，依次执行后缀 s[i…m−1]。

如果下一条指令会让机器人离开网格，则立即停止，这条失败指令不计数；如果所有剩余指令都已执行，也停止。返回长度为 m 的整数数组 answer，answer[i] 表示从指令 i 开始时成功执行的指令数。

每个后缀是一次独立出发，不沿用前一次旅程的终点。

约束

  • m == s.length，1 ≤ n, m ≤ 500。
  • startPos.length == 2。
  • 0 ≤ start_row, start_col < n。
  • s 只包含 L、R、U、D。

官方示例

示例 1

n = 3
startPos = [0,1]
s = "RRDDLU"
输出 = [1,5,4,3,1,0]

从 i=0 开始只能执行一个 R；i=1、2、3 的后缀可全部走完，分别执行 5、4、3 条，终点为 (1,1)、(1,0)、(0,0)。i=4 只能走 L；i=5 的 U 立即越界。

示例 2

n = 2
startPos = [1,1]
s = "LURD"
输出 = [4,1,0,0]

LURD 能全部走完；URD 只成功执行 U；以 R、D 开始都会立即越界。

示例 3

n = 1
startPos = [0,0]
s = "LRUD"
输出 = [0,0,0,0]

网格只有一个格子，任意方向的第一步都会越界。

04 / SOLUTION

想清楚后，再看实现

核心思路、正确性证明与四种语言代码默认收起。

核心洞察：独立模拟每个后缀

只需用两个整数记录当前位置，不必创建网格。所有后缀的长度之和至多为 500×501/2 = 125250，直接枚举并模拟即可。

完整过程

  1. 创建长度 m、初值全为 0 的 answer。
  2. 枚举 i，每次把 r、c 重置为 startPos 的两个分量。
  3. 从 j=i 开始逐条执行：L 令 c 减一，R 令 c 加一，U 令 r 减一，D 令 r 加一。
  4. 若新坐标不满足 0 ≤ r,c < n，立即结束该后缀，失败指令不计数。
  5. 新坐标合法时，将 answer[i] 加一。枚举结束后返回 answer。

示例 1，i=1：从 (0,1) 出发，R → (0,2)，D → (1,2)，D → (2,2)，L → (2,1)，U → (1,1)。五次合法移动，得到 answer[1]=5。

正确性

固定任意 i。初始位置为 startPos，成功指令数为 0，计数正确。假设某次循环前，坐标与已成功执行指令后的实际位置相同，计数也一致。本轮根据方向计算下一坐标：若合法，就恰好多完成一条指令，更新位置与计数后该性质仍成立；若越界，根据题意必须立刻停止，保留的计数就是可执行的最大前缀长度。如果循环正常结束，则整个后缀均已成功执行，计数同样正确。每个 i 都独立复位，因此数组中所有元素均正确。

边界与复杂度

时间复杂度 O(m²)；返回数组占 O(m)，除返回数组外辅助空间 O(1)。不分配网格，因此没有 n² 的空间开销。n=1 时全部为 0；第一步越界计 0；到达边缘仍合法；最后一条成功指令也必须计数。

替代方案：前缀位移 + 范围极值 + 二分

若 m 很大，可建立行、列位移前缀数组。对起始下标 i 和候选长度 k，查询前缀下标区间 [i+1,i+k] 的行列最小值与最大值，减去前缀下标 i 的位移并加上起点坐标，判断所有中途位置是否都在网格内。合法性对 k 单调，故可二分最大长度。稀疏表让区间极值查询为 O(1)，总时间与空间均为 O(m log m)；k=0 直接合法。本题规模下直接模拟更简洁。

常见错误

  • 忘记对每个后缀复位坐标，导致一次旅程接上另一次。
  • 在越界判断前增加计数，误算失败指令。
  • 把 U 写成行号加一，或把行列颠倒。
  • 到达边界就停止，而不是下一步越界才停止。
  • 只判断终点是否合法，忽略中途已越界后又返回的情形。

面试追问

能直接从 answer[i+1] 推出 answer[i] 吗？ 通常不能；进入相同后续指令时的位置不同，剩余边界空间也不同。

改成长方形网格？ 行和列分别使用各自上限，模拟过程不变。

有障碍物呢？ 直接模拟时增加目标格是否被阻挡的判断；单纯前缀位移极值不能识别路径上的障碍物。

class Solution {
    public int[] executeInstructions(int n, int[] startPos, String s) {
        int m = s.length();
        int[] answer = new int[m];
        for (int i = 0; i < m; i++) {
            int r = startPos[0], c = startPos[1];
            for (int j = i; j < m; j++) {
                switch (s.charAt(j)) {
                    case 'L': c--; break;
                    case 'R': c++; break;
                    case 'U': r--; break;
                    case 'D': r++; break;
                }
                if (r < 0 || r >= n || c < 0 || c >= n) break;
                answer[i]++;
            }
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number} n
 * @param {number[]} startPos
 * @param {string} s
 * @return {number[]}
 */
var executeInstructions = function(n, startPos, s) {
    const answer = Array(s.length).fill(0);
    const delta = {L: [0, -1], R: [0, 1], U: [-1, 0], D: [1, 0]};
    for (let i = 0; i < s.length; i++) {
        let [r, c] = startPos;
        for (let j = i; j < s.length; j++) {
            const [dr, dc] = delta[s[j]];
            r += dr;
            c += dc;
            if (r < 0 || r >= n || c < 0 || c >= n) break;
            answer[i]++;
        }
    }
    return answer;
};

from typing import List

class Solution:
    def executeInstructions(self, n: int, startPos: List[int], s: str) -> List[int]:
        answer = [0] * len(s)
        delta = {"L": (0, -1), "R": (0, 1), "U": (-1, 0), "D": (1, 0)}
        for i in range(len(s)):
            r, c = startPos
            for j in range(i, len(s)):
                dr, dc = delta[s[j]]
                r += dr
                c += dc
                if not (0 <= r < n and 0 <= c < n):
                    break
                answer[i] += 1
        return answer

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> executeInstructions(int n, vector<int>& startPos, string s) {
        int m = static_cast<int>(s.size());
        vector<int> answer(m, 0);
        for (int i = 0; i < m; ++i) {
            int r = startPos[0], c = startPos[1];
            for (int j = i; j < m; ++j) {
                switch (s[j]) {
                    case 'L': --c; break;
                    case 'R': ++c; break;
                    case 'U': --r; break;
                    case 'D': ++r; break;
                }
                if (r < 0 || r >= n || c < 0 || c >= n) break;
                ++answer[i];
            }
        }
        return answer;
    }
};
