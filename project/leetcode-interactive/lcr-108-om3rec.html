LCR 108 · HARD · BFS

单词接龙

每一步只能改变一个字符，并且中间单词必须在字典中。求从起始单词到目标单词的最短转换序列长度。

体验 BFS

题意

给定 beginWord、endWord 与字典 wordList。每次替换一个字母，返回最短路径包含的单词数；若无法到达则返回 0。

约束

  • • 所有单词长度相同且仅含小写字母。
  • • 1 ≤ wordList.length ≤ 5000。
  • • 目标单词必须在字典中才可能到达。

示例

hit → cog

hit→hot→dot→dog→cog：5

cog 不在字典

返回 0

same → same

起点即终点：1

分步交互：广度优先搜索

用默认字典观察队列按层扩展；首次发现目标时层数就是最短长度。

核心洞察

把每个合法单词视为节点，只差一个字符的单词之间有边。BFS 按距离分层访问，因此第一次到达 endWord 一定是最短路径。

完整过程

  1. 1. 将字典放入哈希集合，先检查目标是否存在。
  2. 2. 队列从 beginWord 出发，记录层数。
  3. 3. 对每一位置依次尝试 a 到 z；存在于集合则入队并立即删除。
  4. 4. 找到目标即返回层数；队列耗尽则返回 0。

边界

目标不在字典、起点等于目标、重复单词、以及已经访问的单词都需处理。删除已访问单词可防止重复入队。

复杂度与替代方案

设 N 为字典大小、L 为词长，时间 O(N·L·26)，空间 O(N)。双向 BFS 可从两端同时扩展，通常更快；预处理通配模式也可减少邻居生成。

追问与常见错误

追问：如何返回具体路径？记录每个单词的前驱再回溯。错误：在出队而非入队时才标记访问，会造成同一词多次进入队列。

  q, d=deque([b]), 1
  while q:
   for _ in range(len(q)):
