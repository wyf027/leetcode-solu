网格图中最小异或路径

从左上只向右或向下走到右下。路径代价不是和，而是沿途每个格子的按位异或；保留“可达异或值集合”，终点最小下标就是答案。

数值范围是 0…1023，因此每格最多记录 1024 种状态；网格总格数最多 1000。

题意速览

给定 grid，每条有效路径包含起点和终点。返回所有路径异或值中的最小值。

grid = [[1,2],[3,4]]

右→下：1 ^ 2 ^ 4 = 7
下→右：1 ^ 3 ^ 4 = 6

所以最小值为 6。

交互：沿路径累积 XOR

样例 [[1,2],[3,4]]。点击前进，观察每一步新增的可达异或值；也可自动演示。

停在起点：唯一状态为 1。

为什么不能贪心？

XOR 没有“走到当前最小就一定最好”的单调性。不同前缀 XOR 到达同一格后，未来会与相同后缀异或，必须并存记录。

  1. 状态：dp[i][j][x] 表示能以 XOR x 到达 (i,j)。
  2. 从上方或左方的每个可达 x 转移。
  3. 新状态为 x ^ grid[i][j]。
  4. 终点从小到大找第一个可达值。
复杂度：时间 O(m·n·1024)，空间 O(m·n·1024)；可用滚动数组降空间。

测试与验证

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

输入：grid = [[1, 2], [3, 4]]
期望输出：6
实际输出：待补
状态：待补
输入：grid = [[2, 7, 5]]
期望输出：0
实际输出：待补
状态：待补

题解：状态集合动态规划

令 dp[i][j][x] 为布尔值。起点只有 dp[0][0][grid[0][0]]。对于每个格子，枚举上、左两个前驱的可达 XOR，再与当前格值异或。由于格值不超过 1023，所有 XOR 也在 0…1023。

边界与替代方案

  • 单行/单列只有一条路径，转移自然适用。
  • 不能只存每格最小 XOR：XOR 的未来效果依赖具体位模式。
  • 若追求更低空间，可只保留上一行和当前行的状态集合。

面试追问

若值域变大，可改用每格 HashSet；若要恢复一条达到最小值的路径，在状态外保存前驱选择。

常见错误

  • 遗漏起点或终点的格值。
  • 把 XOR 当成可贪心累计的最小值。
  • 循环范围写成 1023，漏掉状态 1023。
