安排电影院座位

Cinema Seat Allocation

一排，三个候选块

每组 4 人，必须选择 2–5、4–7 或 6–9。边座 1 与 10 不会影响任何家庭。

Problem

题目

函数：maxNumberOfFamilies

电影院有 n 排座位，每排固定 10 个，编号为 1 到 10。reservedSeats[i] = [rowᵢ, seatᵢ] 表示对应座位已被预订。

每个四人小组必须坐在同一排，并完整占用以下三种座位块之一：2–5、4–7、6–9。座位块内不能出现已预订座位，且一个座位最多分配给一个小组。请返回最多可安排的四人小组数。

示例 1

输入：n = 3,
reservedSeats = [[1,2],[1,3],[1,8],
                 [2,6],[3,1],[3,10]]
输出：4

最优方案可安排 4 个小组。

示例 2

输入：n = 2,
reservedSeats = [[2,1],[1,8],[2,6]]
输出：2

示例 3

输入：n = 4,
reservedSeats = [[4,3],[1,4],[4,6],[1,7]]
输出：4

约束

  • 1 ≤ n ≤ 10⁹
  • 1 ≤ reservedSeats.length ≤ min(10n, 10⁴)
  • reservedSeats[i] = [rowᵢ, seatᵢ]
  • 1 ≤ rowᵢ ≤ n
  • 1 ≤ seatᵢ ≤ 10
  • 所有预订座位互不相同。

Solution

题解：只处理受影响的排

O(m) 时间 · O(m) 空间

核心洞察

n 可达 10⁹，不能逐排扫描；但预订数 m 最多 10⁴。没有出现在预订列表中的排必然能同时放下左右两组，所以先贡献 2 × (n − 受影响排数)。

对于受影响的每一排，只需关心座位 2–9。用一个整数的 10 个二进制位记录占用情况，再检查三段掩码：

左 2–5中 4–7右 6–9

局部最优规则：若左、右都空，放 2 组；否则三个候选块中任意一个为空，就放 1 组；都不空则放 0 组。

完整过程

  1. 用哈希表把每个出现预订的排映射到位掩码。
  2. 座位 1 和 10 不属于任何候选块，可以不写入掩码；保留它们所在的排也不影响正确性。
  3. 先为所有未受影响的排累计两组。
  4. 逐个检查受影响排：优先判断互不重叠的左块和右块能否同时使用。
  5. 若不能放两组，再判断左、中、右是否至少有一块可用。

为什么不能只数可用块？

中间块 4–7 会同时与左右块重叠。三个块都可用时，真实最优值是 2，而不是 3；所以必须按“左右同时，否则任选一个”的结构判断。

正确性证明

  1. 未出现预订的排：座位 2–5 与 6–9 均空闲且互不重叠，所以恰好可安排 2 组；一排只有 10 座，不可能安排第 3 个四人组。
  2. 受影响排可放 2 组的条件：任意两种候选块中，只有左块 2–5 与右块 6–9 不重叠。因此能安排 2 组当且仅当左右块都可用。
  3. 其余情况：若左右不能同时使用，一排至多放 1 组。只要左、中、右至少一个可用，算法就放 1 组；若都不可用则只能放 0 组。
  4. 全局最优：各排座位互不共享，逐排最优值可以直接相加，因此算法得到整个电影院的最大组数。

复杂度

  • 时间：O(m)，其中 m 为预订座位数。
  • 空间：O(r)，r 为出现预订的排数，且 r ≤ m。

边界

  • 只有座位 1 或 10 被订：该排仍能安排两组。
  • n 很大但预订很少：不能遍历全部 n 排。
  • 中间块可用而左右各自被阻断：仍可安排一组。
  • 结果最大为 2n；n ≤ 10⁹ 时 32 位有符号整数仍可容纳。

替代方案

可以用布尔数组记录每个受影响排的 10 个座位，逻辑直观，但每排需要额外容器；位掩码更紧凑。也可以把预订按行排序后扫描，省去哈希表，但复杂度变为 O(m log m)。

面试追问

  • 若每排座位数和家庭规模可变，如何生成并选择候选区间？
  • 若候选块带不同收益，问题会如何转化为加权区间选择？
  • 如何在流式输入下按排聚合，并限制内存占用？

常见错误

  • 遍历 1 到 n，导致 n = 10⁹ 时超时。
  • 把三个可用块直接计数，忽略中间块与左右块重叠。
  • 位编号偏移错误；应统一使用 1 << seat 或明确的 0 基索引。
  • 只在看见座位 2–9 的预订时才把该排加入哈希表，却又用哈希表大小计算“完整空排”，从而把仅预订 1/10 的排重复计数。下方实现会记录所有出现过的排，避免这个陷阱。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maxNumberOfFamilies(int n, int[][] reservedSeats) {
        Map<Integer, Integer> rows = new HashMap<>();
        for (int[] seat : reservedSeats) {
            int row = seat[0], col = seat[1];
            int mask = rows.getOrDefault(row, 0);
            rows.put(row, mask | (1 << col));
        }

        int left = mask(2, 5);
        int middle = mask(4, 7);
        int right = mask(6, 9);
        int answer = 2 * (n - rows.size());

        for (int occupied : rows.values()) {
            boolean leftFree = (occupied & left) == 0;
            boolean middleFree = (occupied & middle) == 0;
            boolean rightFree = (occupied & right) == 0;
            if (leftFree && rightFree) answer += 2;
            else if (leftFree || middleFree || rightFree) answer++;
        }
        return answer;
    }

    private int mask(int from, int to) {
        int result = 0;
        for (int seat = from; seat <= to; seat++) result |= 1 << seat;
        return result;
    }
}

    for (const [row, seat] of reservedSeats) {

using namespace std;

class Solution {
public:
    int maxNumberOfFamilies(int n, vector<vector<int>>& reservedSeats) {
        unordered_map<int, int> rows;
        for (const auto& seat : reservedSeats) {
            rows[seat[0]] |= 1 << seat[1];
        }

        auto rangeMask = [](int from, int to) {
            int mask = 0;
            for (int seat = from; seat <= to; ++seat) mask |= 1 << seat;
            return mask;
        };
        const int left = rangeMask(2, 5);
        const int middle = rangeMask(4, 7);
        const int right = rangeMask(6, 9);
        int answer = 2 * (n - static_cast<int>(rows.size()));

        for (const auto& [row, occupied] : rows) {
            bool leftFree = (occupied & left) == 0;
            bool middleFree = (occupied & middle) == 0;
            bool rightFree = (occupied & right) == 0;
            if (leftFree && rightFree) answer += 2;
            else if (leftFree || middleFree || rightFree) ++answer;
        }
        return answer;
    }
