LeetCode 1328 · Break a Palindrome

破坏
回文串

只改一个字符：既要打破镜像般的对称，又要让新字符串在字典序中尽可能靠前。

先别急着看答案。 先读题并在字符替换实验室里逐步观察；完整题解被折叠在页面下方。

Problem

题目要求

给定一个只含小写英文字母的回文字符串 palindrome。你必须恰好替换其中一个字符，使得到的字符串不再是回文串，并且在所有可行结果中字典序最小。

若不存在这样的替换，返回空字符串 ""。

字典序：两个等长字符串第一次出现不同字符的位置，字符更小的字符串字典序更小。例如 "abcc" < "abcd"，因为第一个差异在末位，'c' < 'd'。

函数形式

breakPalindrome(palindrome: string): string

约束

  • 1 <= palindrome.length <= 1000
  • palindrome 仅由小写英文字母组成
  • 输入保证是回文串

Official examples

官方示例

打破六字符回文

Example 01
输入
palindrome = "abccba"
输出
"aaccba"
解释
可行替换很多，而 "aaccba" 是其中字典序最小的结果。

无法破坏单字符回文

Example 02
输入
palindrome = "a"
输出
""
解释
替换唯一字符后，长度仍为 1，结果必然还是回文串。

Solution

贪心：优先改动最靠左的位置

核心洞察

扫描字符串的前一半，找到第一个不是 'a' 的字符并改成 'a'。如果前一半全是 'a'，就把最后一个字符改成 'b'。长度为 1 时直接返回空串。

完整过程

  1. 排除无解：若长度为 1，任何单字符字符串都是回文串，返回空串。
  2. 只扫前半：依次检查下标 0 到 n / 2 - 1。中间字符不参与扫描，因为只改中心仍保持回文。
  3. 制造最早差异：遇到首个非 'a' 字符，就把它降到最小字符 'a' 并立即返回。
  4. 兜底增大末位：若前半全为 'a'，无法再降低前部，只能把最后一位从 'a' 改为 'b'。

为什么正确？

可行性：修改前半中的一个字符而不修改其镜像位置，必然破坏回文；兜底时首位是 'a'，末位改成 'b' 后两端不同。

最小性：字典序由最早差异决定。若能降低字符，越靠左影响越优先，所以应改最左侧的非 'a' 字符；目标字符取最小的 'a'。若前半无法降低，则保持最长前缀不变，并在最靠后的末位做幅度最小的增加，即 'a' → 'b'。

边界与复杂度

  • 长度 1：无解，返回 ""。
  • 奇数长度：跳过中心字符；改中心不会破坏对称。
  • 全为 a：修改末位为 'b'，例如 "aaa" → "aab"。
  • 时间复杂度：O(n)，最多扫描一半字符。
  • 空间复杂度：算法辅助空间 O(1)；不可变字符串语言构造字符数组需 O(n)。

替代方案与面试追问

  • 暴力枚举：尝试每个位置的 25 个替换并筛选最小非回文，约为 O(26n²)，不必要。
  • 追问：为何不扫后半？相同幅度的修改发生得越靠左，字典序影响越大；前半提供更优的下降位置。
  • 追问：输入若不保证回文？本题契约保证输入为回文；若取消保证，应先明确是否仍需恰好替换一次，并重新分析候选。
  • 追问：字符集变化？把 'a' 与 'b' 替换成有序字符集中的最小、次小字符即可。

常见错误

  • 扫描到 i <= n / 2，误改奇数长度字符串的中心字符。
  • 前半全是 'a' 时修改靠前字符为 'b'；应改最后一位，才能保留更小的前缀。
  • 忘记“恰好替换一个字符”，直接返回原串。
  • 长度为 1 时返回某个单字符；它仍然是回文串。

class Solution {
    public String breakPalindrome(String palindrome) {
        int n = palindrome.length();
        if (n == 1) {
            return "";
        }

        char[] chars = palindrome.toCharArray();
        for (int i = 0; i < n / 2; i++) {
            if (chars[i] != 'a') {
                chars[i] = 'a';
                return new String(chars);
            }
        }

        chars[n - 1] = 'b';
        return new String(chars);
    }
}

var breakPalindrome = function (palindrome) {
    const n = palindrome.length;
    if (n === 1) {
        return "";
    }

    const chars = palindrome.split("");
    for (let i = 0; i < Math.floor(n / 2); i++) {
        if (chars[i] !== "a") {
            chars[i] = "a";
            return chars.join("");
        }
    }

    chars[n - 1] = "b";
    return chars.join("");
};
