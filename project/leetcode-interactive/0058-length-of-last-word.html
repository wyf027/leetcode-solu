题意

给定只包含英文字母与空格的字符串 s。单词是由连续非空格字符组成的最大子串；返回最后一个单词的长度。输入保证至少包含一个单词。

    题解

    核心洞察

    答案只由字符串末端决定。把指针放在最右侧，先越过所有尾随空格；到达最后一个单词的末尾后，再向左计数，直到遇到空格或越过字符串左边界。无需切分整条字符串。

    完整过程

    1. A令 i = s.length - 1。
    2. B当 s[i] 是空格时持续左移。
    3. C当 s[i] 不是空格时累加长度并左移。
    4. D遇到边界后返回计数值。

    边界情况

    • 只有一个字符：直接计数为 1。
    • 尾部有多个空格：全部跳过后才开始计数。
    • 单词从索引 0 开始：指针最终变成 -1。
    • 前导空格不影响答案。

    复杂度

    TIME
    O(n) 最坏；通常只扫描尾部空格与最后一个单词。
    SPACE
    O(1) 额外空间。

    替代方案取舍

    trim + split 更短，却会构造新字符串与单词数组；正向扫描并持续重置计数同样是 O(1) 空间，但无法在只关心尾部时提前结束。面试中优先展示反向扫描。

    面试追问

    如果“空白”还包括制表符怎么办？

    把字符判断抽象为语言对应的空白判断函数；本题约束只包含普通空格，提交代码应按题意精确实现。

    能否一次循环完成？

    可以用状态或根据计数是否为零分支，但两段循环更直接地表达“先定位、再计数”，可读性更好。

    为什么无需额外处理空字符串？

    约束保证字符串长度至少为 1 且至少包含一个单词；若扩展到通用 API，可在开头加入防御性返回。

    常见错误

    • 没有先跳过尾随空格，导致结果为 0。
    • 循环中先访问 s[i] 再检查 i >= 0，产生越界。
    • 把连续多个空格误认为只有一个分隔符。
    • 用 split(" ") 时忽略空元素和额外空间开销。

    class Solution {
    public int lengthOfLastWord(String s) {
        int i = s.length() - 1;
        while (i >= 0 && s.charAt(i) == ' ') {
            i--;
        }

        int length = 0;
        while (i >= 0 && s.charAt(i) != ' ') {
            length++;
            i--;
        }
        return length;
    }
}
