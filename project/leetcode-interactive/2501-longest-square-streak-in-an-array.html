2501 · 数组中最长的方波

Longest Square Streak in an Array

挑出一些数，重新排序后，让相邻的数满足平方关系。最长能接成多长？

打开 LeetCode 原题 ↗

01题目与规则

给定整数数组 nums，选择一个子序列。把选出的元素按升序排列后，如果长度至少为 2，且从第二个元素起，每个数都等于前一个数的平方，就称它为一个“方波”。返回所有方波中的最大长度；不存在时返回 -1。

子序列由原数组删除任意元素得到，保留其余元素的原始相对顺序。本题在选出子序列后允许排序，所以判定平方关系时不要求数值在原数组中递增。

参数：nums: integer[]；返回：integer。这里的“方波”指平方链，不是交替升降的波形。

  • 2 ≤ nums.length ≤ 10⁵
  • 2 ≤ nums[i] ≤ 10⁵

02官方示例

示例 1

输入：nums = [4,3,6,16,8,2]
输出：3

按原顺序选出 [4,16,2]，排序为 [2,4,16]，其中 4 = 2²，16 = 4²。不存在长度为 4 的方波，因此答案为 3。

示例 2

输入：nums = [2,3,5,6,7]
输出：-1

任何选择都无法组成至少包含两个元素的平方链，因此返回 -1。

05独立题解

核心洞察 · 下一站只有一个

对任意数 x，下一个元素只能是 x²。所有数都至少为 2，因此平方会严格增大，同一个值不可能在一条合法链中重复使用。用集合存储所有不同的值即可，原始顺序和出现次数都不影响答案。

完整过程

  1. 将 nums 放入哈希集合 values。
  2. 枚举集合中的每个值作为起点，令当前值 x 等于起点，链长为 0。
  3. 只要集合含 x，就把链长加 1，然后令 x = x²。
  4. 首次找不到 x 时停止这条链，更新最大长度。
  5. 最大长度至少为 2 时返回它，否则返回 -1。

例如从 2 出发，依次查找 2、4、16、256。前三项存在、256 缺失，就得到长度 3。无须枚举子序列，也无须做开方判断。

为什么正确

合法性：内层循环只接受集合里存在的数，并且后一个数由前一个数平方得到。由于 x ≥ 2，各值严格增大且互不相同；可以在原数组中为每个值选一个位置，再按位置排列得到子序列，其排序结果正是这条链。长度至少为 2 时必然合法。

完整性：任取最优方波，其排序后的最小值一定会被枚举为起点。从这个值开始，后续值由平方唯一确定，循环会找齐该方波的所有元素，并且可能继续延长。因此枚举所得最大值不会小于最优长度。

结论与终止：所有候选链均合法，且最优链一定被覆盖，所以最大长度就是答案。平方严格递增，集合有限，因此循环终止；只有长度 1 的候选时正确返回 -1。

边界与数值安全

  • [2,2] 没有长度为 2 的方波；重复数不增加链长。
  • [16,2] 缺少 4，不能把 16 当作 2 的直接后继。
  • 最小起点 2 的最长链为 2 → 4 → 16 → 256 → 65536，再平方超过 10⁵，故本题链长至多 5。
  • 乘法只发生在当前值仍属于集合时，当前值至多 10⁵，所以计算出的平方至多 10¹⁰。Java/C++ 使用 64 位整数；JavaScript 的安全整数范围足够；Python 整数支持任意精度。
  • 若扩展题目允许 0 或 1，平方不再严格增长，需要单独计数处理，否则本写法会死循环；它们不在本题约束内。

复杂度

设 n 为数组长度，u 为不同值个数，M 为最大值，L 为最长平方链长。哈希查询平均 O(1)，总期望时间 O(n + uL)，空间 O(u)。因为 L = O(1 + log log M)，也可写成 O(n + u log log M)（忽略小值常数）。本题 L ≤ 5，因而在固定约束下是期望 O(n) 时间、O(n) 空间。这里的期望界依赖哈希表的通常性能。

替代方案

排序加动态规划：升序处理不同值 x，如果整数平方根 r 满足 r² = x 且 r 已出现，则 dp[x] = dp[r] + 1，否则为 1。时间 O(n log n)，空间 O(n)。也可用值域布尔数组替代哈希集合，空间 O(M)，查询具有确定的常数时间。

面试追问

  • 如何返回实际链？保存最佳起点和长度，最后连续平方还原；若要原始子序列，记录各值的原下标并按下标排序。
  • 能否避免枚举链中间节点？只从没有平方根前驱的数出发，但要精确检查整数平方根；本题最多 5 层，直接枚举更简洁。
  • 范围大到平方溢出怎么办？在乘法前判断 x > M / x 则结束，或采用适当的大整数。

常见错误

  • 把原数组顺序当成平方链顺序，错误套用递增子序列。
  • 用重复出现次数累加长度，或把普通倍数当平方。
  • 只有一个元素时返回 1，忘记至少需要两个元素。
  • Java/C++ 先用 32 位乘法再转换为 64 位，导致转换前已经溢出。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int longestSquareStreak(int[] nums) {
        Set<Long> values = new HashSet<>();
        for (int num : nums) values.add((long) num);
        int best = 0;
        for (long start : values) {
            long x = start;
            int length = 0;
            while (values.contains(x)) {
                length++;
                x *= x;
            }
            best = Math.max(best, length);
        }
        return best >= 2 ? best : -1;
    }
}

C++

#include <algorithm>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    int longestSquareStreak(vector<int>& nums) {
        unordered_set<long long> values(nums.begin(), nums.end());
        int best = 0;
        for (long long start : values) {
            long long x = start;
            int length = 0;
            while (values.count(x)) {
                ++length;
                x *= x;
            }
            best = max(best, length);
        }
        return best >= 2 ? best : -1;
    }
};
