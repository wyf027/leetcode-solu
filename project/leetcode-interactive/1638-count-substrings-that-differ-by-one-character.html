统计只差一个字符的子串数目

两个字符串，许多对齐方式，一个精准条件：所选的两个连续片段必须等长，并且恰好只有一个位置的字符不同。

01 / Problem

先把“恰好一个”说清楚

给定两个字符串 s 和 t。从两者中各选一个非空、连续且长度相同的子串；如果对应位置中恰好有一个字符不同，那么这一对子串计入答案。

返回所有满足条件的子串对数量。即使字符内容相同，只要它们来自不同的起止位置，也按不同选择分别计数。

子串是字符串中一段连续字符。条件是“恰好一个不同”，完全相同或有至少两个位置不同都不计数。

函数与约束

countSubstrings(s, t) → integer

  • 1 ≤ s.length, t.length ≤ 100
  • s 和 t 只含小写英文字母
  • 子串必须非空，并保持原字符串中的连续顺序

示例 1

输入：s = "aba", t = "baba"
输出：6
解释：共有 6 对等长子串恰好相差一个字符。

示例 2

输入：s = "ab", t = "bb"
输出：3
解释：("a", "b") 按 t 中的两个位置计两次，("ab", "bb") 再计一次。

示例 3

输入：s = "a", t = "a"
输出：0

示例 4

输入：s = "abe", t = "bbc"
输出：10

准备好揭开机制了吗？

Solution Unlocked

以唯一错位为中心计数

核心洞察

每一对合法子串都存在一个唯一不同的位置。反过来，先固定字符串中的一对不同字符 s[i] != t[j]，再计算它左侧能连续相等多少个字符、右侧能连续相等多少个字符，就可以一次性数出所有以这对字符为唯一差异的子串。

贡献 = (left + 1) × (right + 1)
左端点可选 left + 1 种，右端点可选 right + 1 种。

完整过程

  1. 建立 left：left[i][j] 表示 s[i] 与 t[j] 之前，沿左上方向连续相等的字符数。
  2. 建立 right：right[i][j] 表示从 s[i] 与 t[j] 开始，沿右下方向连续相等的字符数。
  3. 枚举每对位置 (i, j)。若字符相同则跳过；若不同，把 (left[i][j] + 1) × (right[i+1][j+1] + 1) 加入答案。

正确性证明

完备性：任取一对合法子串，它恰好有一个不同位置 (i,j)。该位置左边的字符全部对应相等，其数量不超过 left[i][j]；右边同理不超过 right[i+1][j+1]。因此它一定会在枚举这个中心时被计入。

唯一性：每一对合法子串只有一个不同位置，所以只会归属一个中心。固定中心后，左右延伸长度唯一确定子串的两个端点，不同的选择产生不同的子串位置对。因此既不遗漏也不重复。

边界情况

  • 两个串完全相同仍可能有答案，但相同位置本身不能作为差异中心；例如不同偏移的字符可能不同。
  • 长度为 1 时，只需判断每对字符是否不同。
  • 差异中心在字符串边缘时，一侧延伸为 0，公式仍然成立。
  • 重复字符对应不同下标，必须分别计数。

复杂度

令 n = s.length、m = t.length。时间复杂度为 O(nm)，空间复杂度为 O(nm)。空间可以用按对角线扫描的状态压到 O(1) 额外空间，但实现更不直观。

替代方案

可以枚举两个子串的起点，然后同步向右扩展并维护不同字符数；遇到第一个差异时计数，遇到第二个差异时停止。这一方案时间 O(nm·min(n,m))、空间 O(1)，更容易想到，但没有利用两侧连续相等的信息。

一眼记住

  • 1唯一差异决定归属中心
  • 2向左统计连续相等
  • 3向右统计连续相等
  • 4两个选择数相乘
JavaO(nm)
class Solution {
    public int countSubstrings(String s, String t) {
        int n = s.length(), m = t.length();
        int[][] left = new int[n + 1][m + 1];
        int[][] right = new int[n + 1][m + 1];

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (s.charAt(i) == t.charAt(j)) {
                    left[i + 1][j + 1] = left[i][j] + 1;
                }
            }
        }
        for (int i = n - 1; i >= 0; i--) {
            for (int j = m - 1; j >= 0; j--) {
                if (s.charAt(i) == t.charAt(j)) {
                    right[i][j] = right[i + 1][j + 1] + 1;
                }
            }
        }

        int answer = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (s.charAt(i) != t.charAt(j)) {
                    answer += (left[i][j] + 1) * (right[i + 1][j + 1] + 1);
                }
            }
        }
        return answer;
    }
}

var countSubstrings = function(s, t) {
    const n = s.length;
    const m = t.length;
    const left = Array.from({ length: n + 1 }, () => Array(m + 1).fill(0));
    const right = Array.from({ length: n + 1 }, () => Array(m + 1).fill(0));

    for (let i = 0; i < n; i++) {
        for (let j = 0; j < m; j++) {
            if (s[i] === t[j]) left[i + 1][j + 1] = left[i][j] + 1;
        }
    }
    for (let i = n - 1; i >= 0; i--) {
        for (let j = m - 1; j >= 0; j--) {
            if (s[i] === t[j]) right[i][j] = right[i + 1][j + 1] + 1;
        }
    }

    let answer = 0;
    for (let i = 0; i < n; i++) {
        for (let j = 0; j < m; j++) {
            if (s[i] !== t[j]) {
                answer += (left[i][j] + 1) * (right[i + 1][j + 1] + 1);
            }
        }
    }
    return answer;
};

class Solution:
    def countSubstrings(self, s: str, t: str) -> int:
        n, m = len(s), len(t)
        left = [[0] * (m + 1) for _ in range(n + 1)]
        right = [[0] * (m + 1) for _ in range(n + 1)]

        for i in range(n):
            for j in range(m):
                if s[i] == t[j]:
                    left[i + 1][j + 1] = left[i][j] + 1

        for i in range(n - 1, -1, -1):
            for j in range(m - 1, -1, -1):
                if s[i] == t[j]:
                    right[i][j] = right[i + 1][j + 1] + 1

        answer = 0
        for i in range(n):
            for j in range(m):
                if s[i] != t[j]:
                    answer += (left[i][j] + 1) * (right[i + 1][j + 1] + 1)
        return answer

class Solution {
public:
    int countSubstrings(string s, string t) {
        int n = s.size(), m = t.size();
        vector<vector<int>> left(n + 1, vector<int>(m + 1));
        vector<vector<int>> right(n + 1, vector<int>(m + 1));

        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                if (s[i] == t[j]) left[i + 1][j + 1] = left[i][j] + 1;
            }
        }
        for (int i = n - 1; i >= 0; --i) {
            for (int j = m - 1; j >= 0; --j) {
                if (s[i] == t[j]) right[i][j] = right[i + 1][j + 1] + 1;
            }
        }

        int answer = 0;
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                if (s[i] != t[j]) {
                    answer += (left[i][j] + 1) * (right[i + 1][j + 1] + 1);
                }
            }
        }
        return answer;
    }
};

面试追问

能否优化空间？

可以。沿每条对角线扫描，维护“上一个差异位置”和“上上个差异位置”，当前端点的新增合法子串数由两个差异位置之差决定，可做到 O(1) 额外空间。

若改成“最多一个不同”呢？

在本题答案上，再加所有完全相同子串对；或在对角线滑动窗口中允许窗口内差异数不超过 1。

若改成恰好 k 个不同？

逐条对角线使用滑动窗口或记录差异位置。对每个右端点，利用第 k 个与第 k+1 个最近差异的位置确定合法左端点区间。

常见错误

×把内容相同的子串去重；本题按位置选择计数。
×把“恰好一个”写成“至多一个”，误计完全相同子串。
×只计算最大延伸一次；左右端点有多种组合，必须相乘。
×left 与 right 下标错一位，把差异中心也纳入相等段。
