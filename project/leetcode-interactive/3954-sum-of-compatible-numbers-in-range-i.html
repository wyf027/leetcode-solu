区间内的兼容数字之和 I

Sum of Compatible Numbers in Range I · 位运算 / 枚举

Easy

题意

给定整数 n 与 k。正整数 x 是兼容数字，当且仅当 abs(n - x) ≤ k 且 (n & x) == 0。返回所有兼容 x 的总和。

按位与为 0 表示二进制表示中，n 与 x 没有任何同为 1 的位。

示例

n = 2, k = 3。候选区间是 [1,5]；其中 1,4,5 分别与二进制 10 没有重叠的 1 位，答案 1+4+5=10。

约束：1 ≤ n ≤ 100，1 ≤ k ≤ 100。

题解

核心洞察

绝对差条件先把搜索范围缩小为 [max(1,n-k), n+k]。由于 k ≤ 100，直接枚举区间内每个候选，再用一次常数时间的按位与检查即可。

完整过程

  1. 令 left=max(1,n-k)、right=n+k。
  2. 遍历 x=left..right。
  3. 当 (n & x)==0 时，将 x 加入答案。

边界与复杂度

下界必须截到 1，因为 0 不是正整数。时间为 O(k)（最多 2k+1 次检查），额外空间 O(1)。

替代方案、面试追问与常见错误

当范围很大或有多次查询时，可用数位 DP 或预处理位掩码；本题限制下枚举更直接。常见错误是遗漏右端点、枚举 0，或把逻辑与 (n | x) 混淆。
