3893. 最大重叠区间团队规模

选择一名“核心员工”。团队中的每一段时间都要和他的闭区间相交；不要求所有成员在同一时刻同时在线。目标是找出能作为核心的员工中，覆盖成员数最多的那一个。

演示已就绪。可用左右方向键切换核心员工。

题意

输入startTime、endTime，第 i 人的区间为 [startTime[i], endTime[i]]。互动两个闭区间有公共时间点；端点相触也算重叠。有效团队存在至少一名成员，能与团队内其余每一位成员互动。范围1 ≤ n ≤ 105，时间值可到 109。

示例：startTime = [1, 2, 3]，endTime = [4, 5, 6]。选择 [1, 4] 作核心，三人都能进入团队，答案为 3。

先辨清一个陷阱

这不是“某一时刻最多有几段重叠”。例如 [3, 8] 同时分别和 [4, 5]、[6, 7] 重叠，三人有效；但后两段彼此没有公共点。

所以固定某段 [s, e] 后，只需统计满足 start ≤ e 且 end ≥ s 的段数。

题解：两份排序端点 + 二分

核心洞察

对核心 [s,e]，不相交的段恰好落在两侧：end < s 或 start > e。因此相交数是：

count = upperBound(starts, e) − lowerBound(ends, s)

左式先数所有开始不晚于 e 的段，再扣掉结束早于 s 的段。两份端点数组预排序一次，每个核心两次二分。

完整过程

  1. 复制并排序所有开始端点 starts 和结束端点 ends。
  2. 枚举原数组的每个 [s,e]。
  3. 二分得到 starts 中 ≤ e 的数量。
  4. 二分得到 ends 中 < s 的数量。
  5. 取差值最大者。

边界与复杂度

  • 闭区间：[1,2] 与 [2,3] 有交点 2，不能写成严格不等式。
  • 单个员工答案就是 1。
  • 排序 O(n log n)，枚举与二分 O(n log n)，额外空间 O(n)。

替代方案与追问

扫描线求的是“同一时刻重叠的最大数量”，不适用于本题的核心员工定义。追问动态增删时，可用坐标压缩搭配平衡树维护端点计数。

常见错误

  • 误把答案当成最大同时在线人数。
  • lowerBound(starts,e) 会漏掉 start=e 的相触区间。
  • 对每个区间暴力扫描，最坏为 O(n²)。
