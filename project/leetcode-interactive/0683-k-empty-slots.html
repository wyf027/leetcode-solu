K 个关闭的灯泡

K Empty Slots

每天只亮一盏灯。你要捕捉最早的那个瞬间：两端已经亮起，而它们之间恰好还有 k 盏灯保持关闭。

Problem

题意与输入输出

一排共有 n 盏灯，位置编号为 1..n，开始时全部关闭。接下来连续 n 天，每天恰好打开一盏灯，并且打开后不会再次关闭。

给定排列 bulbs：bulbs[i] = x 表示在第 i + 1 天打开位置 x 的灯。再给定整数 k，返回最早的天数，使得某两盏已打开的灯之间恰好隔着 k 个位置，且这些中间位置上的灯在当天全部关闭。

若直到最后一天都不存在这样的两盏灯，返回 -1。

返回的是天数，不是灯的位置。 两端位置之差必须为 k + 1。

官方函数形式

kEmptySlots(bulbs: integer[], k: integer) → integer

关键约束

  • n == bulbs.length
  • 1 ≤ n ≤ 2 × 10⁴
  • 1 ≤ bulbs[i] ≤ n
  • bulbs 是 1..n 的排列
  • 0 ≤ k ≤ 2 × 10⁴

输出2

Solution

把“每天亮哪里”翻转为“每个位置哪天亮”

核心洞察

原数组按时间排列，不便直接判断连续位置。先构造 days：days[p - 1] 表示位置 p 在第几天点亮。例如 bulbs=[1,3,2] 会得到 days=[1,3,2]。

对任意相距 k + 1 的位置 left 与 right，两端同时亮起的最早日期是：

candidate = max(days[left], days[right])

当天中间灯仍全关，当且仅当每个 i ∈ (left, right) 都满足：

days[i] > candidate

也就是中间每盏灯都比两端更晚点亮。答案是所有合法窗口的最小 candidate。

完整过程 · 线性滑动窗口

反转坐标。

遍历 bulbs，令 days[bulbs[day]-1] = day+1。

建立固定跨度。

先令 left=0、right=k+1。只有这个距离的两端才会夹着恰好 k 个位置。

从左向右检查内部。

若某个内部位置 i 的点亮日早于左端，或不晚于右端，那么当前窗口不可能成立，直接把 i 作为新左端。

右端哨兵确认合法。

扫描到 i == right 才触发条件，说明此前没有内部位置破坏窗口；记录 max(days[left], days[right])。

继续跳转。

更新为 left=i、right=i+k+1，直到右端越界。每个位置只被常数次检查。

正确性证明

引理 1：窗口 [left,right] 合法，当且仅当所有内部灯的点亮日都严格大于两端点亮日的最大值。因为在两端都亮起的最早一天，内部灯只有点亮日更晚才仍关闭。

引理 2：若内部位置 i 破坏当前窗口，则把 left 跳到 i 不会漏掉答案。任何旧 left 与不超过当前 right 的候选右端，要么跨度不为 k+1，要么仍含有这个过早点亮的破坏位置。

定理：算法会检查每个可能成立的固定跨度窗口；由引理 1 只记录合法窗口，由引理 2 跳转不漏合法窗口。对记录日期取最小值，故返回最早合法天数；没有记录时返回 -1。

边界与复杂度

  • k = 0：寻找最早同时亮起的相邻灯，算法仍成立。
  • k + 1 ≥ n：不存在两个相距足够远的端点，直接返回 -1。
  • 严格不等号：内部灯必须在候选日之后点亮；同一天并不存在两灯同时被打开，但判断仍应写成严格晚于。
  • 时间：O(n)；空间：O(n)，用于 days。

替代方案

  • 有序集合，O(n log n)：按天插入当天点亮的位置，只需检查它在集合中的前驱、后继距离是否为 k+1。思路直观，但 JavaScript/Python 标准库缺少直接可用的平衡树。
  • 树状数组 / 线段树，O(n log n)：维护亮灯数量或区间最值，可查询端点间是否没有亮灯。结构更通用，代码更重。
  • 单调队列，O(n)：在 days 上维护长度 k 的内部区间最小值，再与两端比较。也是线性，但固定窗口边界更容易写错。

Implementation

JavaO(n) / O(n)
class Solution {
    public int kEmptySlots(int[] bulbs, int k) {
        int n = bulbs.length;
        if (k + 1 >= n) return -1;

        int[] days = new int[n];
        for (int day = 0; day < n; day++) {
            days[bulbs[day] - 1] = day + 1;
        }

        int answer = Integer.MAX_VALUE;
        int left = 0;
        int right = k + 1;

        for (int i = left + 1; right < n; i++) {
            if (days[i] < days[left] ||
                days[i] <= days[right]) {
                if (i == right) {
                    answer = Math.min(
                        answer,
                        Math.max(days[left], days[right])
                    );
                }
                left = i;
                right = i + k + 1;
            }
        }

        return answer == Integer.MAX_VALUE ? -1 : answer;
    }
}

from typing import List


class Solution:
    def kEmptySlots(self, bulbs: List[int], k: int) -> int:
        n = len(bulbs)
        if k + 1 >= n:
            return -1

        days = [0] * n
        for day, position in enumerate(bulbs, start=1):
            days[position - 1] = day

        answer = float("inf")
        left = 0
        right = k + 1

        while right < n:
            for i in range(left + 1, right + 1):
                if days[i] < days[left] or days[i] <= days[right]:
                    if i == right:
                        answer = min(
                            answer,
                            max(days[left], days[right]),
                        )
                    left = i
                    right = i + k + 1
                    break

        return -1 if answer == float("inf") else int(answer)

面试追问

  1. 如果每天可能打开多盏灯，严格不等式和候选日定义需要怎样修改？
  2. 如果有动态查询，要求每次开灯后都报告所有合法间距，应该选有序集合还是线段树？
  3. 能否用有序集合做到 O(n log n) 且 O(n) 空间？前驱和后继分别检查什么？
  4. 为什么窗口失效时可以直接把破坏位置设为新左端？请证明不会漏解。

常见错误

  • 把 bulbs 当成按位置排列的状态，而忘了它是按天给出的事件序列。
  • 用端点距离 k；正确距离是 k + 1。
  • 只比较内部灯与某一个端点；必须晚于两端，即晚于两者最大点亮日。
  • 找到第一个按位置的合法窗口就返回；题目要的是最早天数，仍需取最小候选日。
  • 在 k 太大时访问越界，或把无解时的无穷大直接返回。
