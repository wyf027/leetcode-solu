Super Ugly Number

数组 数学 动态规划

一组给定的质数，定义了一套只属于它们的数字谱系。找到这个谱系中的第 n 个成员。

Problem

题目描述

超级丑数是一个正整数，它的所有质因数都包含在给定的质数数组 primes 中。给定整数 n 和整数数组 primes，返回第 n 个超级丑数。

数字 1 不含质因数，因此始终是第一个超级丑数。题目保证答案落在 32 位有符号整数范围内。

Example 01

输入：n = 12, primes = [2,7,13,19]
输出：32
解释：前 12 个超级丑数为
[1,2,4,7,8,13,14,16,19,26,28,32]。

Example 02

输入：n = 1, primes = [2,3,5]
输出：1
解释：1 没有质因数，所以它满足条件。

约束

1 <= n <= 105
1 <= primes.length <= 100
2 <= primes[i] <= 1000
primes[i] 均为质数
primes 中元素互不相同，并按严格递增顺序排列

Full Solution

多指针动态规划

核心洞察

对每个质数 primes[j]，把它依次乘上已经生成的超级丑数，就得到一条递增候选流。用指针 index[j] 指向这条流中尚未采用的最小候选：primes[j] * ugly[index[j]]。所有流的队首最小值，就是序列的下一项。

去重关键：当多个候选值同时等于本轮最小值时，必须推进所有对应指针；只推进一个会让相同数字在下一轮再次出现。

完整过程

  1. 创建长度为 n 的数组 ugly，令 ugly[0] = 1。
  2. 为每个质数维护一个初始为 0 的指针。
  3. 重复计算每条轨道的当前乘积，取其中最小值写入下一位置。
  4. 遍历所有质数，把候选等于该最小值的指针全部加一。
  5. 生成到第 n 项后返回 ugly[n - 1]。

正确性证明

引理 1：每条轨道的候选是该质数能产生的最小未输出值。
已确认数组递增，而指针只在对应乘积已被输出时前进。因此指针之前的乘积都已处理，指针所在乘积是该轨道最小的未处理值。
引理 2：所有轨道候选的最小值是全局下一个超级丑数。
任意大于 1 的超级丑数都能写成某个给定质数乘以另一个超级丑数，所以它必属于至少一条轨道。由引理 1，各轨道更小的值都已输出，队首最小值不可能越过任何合法值。
引理 3：序列没有重复项。
写入最小值后，所有产生该值的轨道指针都会前进，所以下一轮没有轨道仍停留在该值。
结论。
由初始化 ugly[0] = 1，结合引理 2 的递增完备性与引理 3 的唯一性，算法依次生成全部超级丑数，因此返回值正是第 n 个超级丑数。

复杂度

时间：O(n × k)，其中 k = primes.length。
空间：O(n + k)。

边界

n = 1 直接得到 1；只有一个质数时序列是它的幂。乘法应使用更宽的中间类型，避免候选值在比较前溢出。

替代方案：最小堆归并

可把每条轨道的当前候选放入最小堆，每次弹出最小值，再推进对应轨道，并跳过重复值。时间复杂度可降为 O(n log k)，空间为 O(n + k)；但堆节点、去重与轨道索引的实现更复杂。当 k ≤ 100 时，多指针扫描通常足够直接。

class Solution {
    public int nthSuperUglyNumber(int n, int[] primes) {
        int[] ugly = new int[n];
        int[] index = new int[primes.length];
        ugly[0] = 1;

        for (int i = 1; i < n; i++) {
            long next = Long.MAX_VALUE;
            for (int j = 0; j < primes.length; j++) {
                long candidate = (long) primes[j] * ugly[index[j]];
                next = Math.min(next, candidate);
            }

            ugly[i] = (int) next;
            for (int j = 0; j < primes.length; j++) {
                long candidate = (long) primes[j] * ugly[index[j]];
                if (candidate == next) {
                    index[j]++;
                }
            }
        }
        return ugly[n - 1];
    }
}

var nthSuperUglyNumber = function(n, primes) {
    const ugly = new Array(n).fill(1);
    const index = new Array(primes.length).fill(0);

    for (let i = 1; i < n; i++) {
        let next = Number.POSITIVE_INFINITY;
        for (let j = 0; j < primes.length; j++) {
            next = Math.min(next, primes[j] * ugly[index[j]]);
        }

        ugly[i] = next;
        for (let j = 0; j < primes.length; j++) {
            if (primes[j] * ugly[index[j]] === next) {
                index[j]++;
            }
        }
    }
    return ugly[n - 1];
};
from typing import List


class Solution:
    def nthSuperUglyNumber(self, n: int, primes: List[int]) -> int:
        ugly = [1] * n
        index = [0] * len(primes)

        for i in range(1, n):
            next_value = min(
                prime * ugly[index[j]]
                for j, prime in enumerate(primes)
            )
            ugly[i] = next_value

            for j, prime in enumerate(primes):
                if prime * ugly[index[j]] == next_value:
                    index[j] += 1

        return ugly[n - 1]
class Solution {
public:
    int nthSuperUglyNumber(int n, vector<int>& primes) {
        vector<int> ugly(n, 1);
        vector<int> index(primes.size(), 0);

        for (int i = 1; i < n; ++i) {
            long long next = LLONG_MAX;
            for (int j = 0; j < static_cast<int>(primes.size()); ++j) {
                long long candidate = 1LL * primes[j] * ugly[index[j]];
                next = min(next, candidate);
            }

            ugly[i] = static_cast<int>(next);
            for (int j = 0; j < static_cast<int>(primes.size()); ++j) {
                long long candidate = 1LL * primes[j] * ugly[index[j]];
                if (candidate == next) {
                    ++index[j];
                }
            }
        }
        return ugly[n - 1];
    }
};

常见错误

  • 把 1 漏掉，导致整体下标错一位。
  • 候选相等时只移动一个指针，产生重复项。
  • 使用 32 位整数直接做乘法，比较前已经溢出。
  • 把“质因数来自 primes”误解为数字只能由互不重复的质数相乘。

面试追问

  • 如果 primes.length 很大，如何改成堆归并？
  • 为什么同时推进所有命中最小值的指针就能去重？
  • 如何将算法改成流式生成器，按需返回下一项？
  • 若答案不再保证 32 位，应如何处理大整数与溢出？
