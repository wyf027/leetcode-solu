压缩字符串 II

String Compression II

删除至多 k 个字符，让行程长度编码尽可能短。真正的难点不是“删谁”，而是一次删除能否跨过边界、让两段相同字符合并。

先别急着看题解：先在下面的决策轨道中观察，删除一个分隔字符怎样把两个字符段接到一起。

Problem

题目要求

行程长度编码把连续相同字符组成的一段写成“字符 + 次数”。当一段只有 1 个字符时，不写数字 1。例如 aabccc 会被编码为 a2bc3。

给定只含小写英文字母的字符串 s 和整数 k，允许从 s 中删除至多 k 个字符。返回删除后字符串的行程长度编码的最小可能长度。

示例 1

输入：s = "aaabcccd", k = 2 输出：4 解释：删除 'b' 和 'd'，得到 "aaaccc"，编码为 "a3c3"。

示例 2

输入：s = "aabbaa", k = 2 输出：2 解释：删除两个 'b'，得到 "aaaa"，编码为 "a4"。

示例 3

输入：s = "aaaaaaaaaaa", k = 0 输出：3 解释：不能删除，编码为 "a11"。

函数签名

getLengthOfOptimalCompression(s, k) → integer

约束

  • 1 ≤ s.length ≤ 100
  • 0 ≤ k ≤ s.length
  • s 仅包含小写英文字母

Solution

准备好后再揭开动态规划

包含推导、证明、复杂度、四语言代码和面试追问。

Dynamic programming

枚举下一段：删掉中间异类字符

核心洞察

令 dp[i][d] 表示：处理后缀 s[i..]、还可以删除至多 d 个字符时，能够得到的最短编码长度。

在位置 i，有两类选择：

  1. 删除 s[i]：若 d > 0，转移到 dp[i+1][d-1]。
  2. 保留 s[i]，让它成为下一段：向右枚举段尾 j。区间中与 s[i] 相同的字符共 same 个，不同的共 deleted 个。删掉这些不同字符后，相同字符会合成一段，代价为 encodedLength(same) + dp[j+1][d-deleted]。
为何不需要记录上一段字符和长度？ 因为每次转移直接枚举并完整确定“下一段”覆盖到哪里，段的编码代价当场结算；后缀从 j+1 开始成为独立子问题。

完整过程

1
初始化。 空后缀的编码长度为 0；其余状态先设为无穷大。
2
倒序枚举 i。 这样所有 dp[j+1][*] 都已算好。
3
尝试删除首字符。 若仍有预算，用 dp[i+1][d-1] 更新。
4
尝试构造第一段。 从 j=i 向右扫，更新 same 与 deleted；预算不够时停止扩展。
5
返回 dp[0][k]。 它覆盖原串，并允许使用不超过全部预算的删除。

正确性证明

引理：对任意状态 (i,d)，转移枚举了一个最优方案第一步的所有可能形式。

证明：任意可行方案要么删除 s[i]，对应第一类转移；要么保留它。若保留，则它在最终字符串中属于第一段。设原串中参与该段的最右字符位置为 j，那么 [i,j] 内所有不同于 s[i] 的字符都必须被删除，所有保留下来的同字符合成一段，这恰好由第二类转移枚举。第一段之后的最优代价由相应后缀状态给出。

定理：dp[0][k] 等于题目要求的最短编码长度。

证明：按 i 从后往前归纳。空后缀显然正确。依据引理，状态的所有可行第一步均被枚举；每个后继状态按归纳假设已是最优。取这些方案的最小值，得到当前状态最优值。因此起始状态也是全局最优。

复杂度

状态数为 O(nk)，每个状态最多向右枚举 n 个位置，因此时间 O(n²k)；二维表空间 O(nk)。

边界

  • k ≥ n 时答案为 0。
  • 单字符段只贡献 1。
  • 计数位数只在 2、10、100 时增加。
  • 预算表示“至多删除”，无需强制用完。

Java

Solution.javaO(n²k)
import java.util.Arrays;

class Solution {
    public int getLengthOfOptimalCompression(String s, int k) {
        int n = s.length();
        int inf = 1_000_000;
        int[][] dp = new int[n + 1][k + 1];
        for (int i = 0; i < n; i++) {
            Arrays.fill(dp[i], inf);
        }
        Arrays.fill(dp[n], 0);

        for (int i = n - 1; i >= 0; i--) {
            for (int d = 0; d <= k; d++) {
                if (d > 0) {
                    dp[i][d] = dp[i + 1][d - 1];
                }

                int same = 0;
                int deleted = 0;
                for (int j = i; j < n; j++) {
                    if (s.charAt(j) == s.charAt(i)) {
                        same++;
                    } else {
                        deleted++;
                    }
                    if (deleted > d) break;
                    dp[i][d] = Math.min(
                        dp[i][d],
                        encodedLength(same) + dp[j + 1][d - deleted]
                    );
                }
            }
        }
        return dp[0][k];
    }

    private int encodedLength(int count) {
        if (count == 1) return 1;
        if (count < 10) return 2;
        if (count < 100) return 3;
        return 4;
    }
}

JavaScript

solution.jsO(n²k)
/**
 * @param {string} s
 * @param {number} k
 * @return {number}
 */
var getLengthOfOptimalCompression = function(s, k) {
    const n = s.length;
    const INF = 1_000_000;
    const dp = Array.from(
        { length: n + 1 },
        () => Array(k + 1).fill(INF)
    );
    dp[n].fill(0);

    const encodedLength = (count) => {
        if (count === 1) return 1;
        if (count < 10) return 2;
        if (count < 100) return 3;
        return 4;
    };

    for (let i = n - 1; i >= 0; i--) {
        for (let d = 0; d <= k; d++) {
            if (d > 0) dp[i][d] = dp[i + 1][d - 1];

            let same = 0;
            let deleted = 0;
            for (let j = i; j < n; j++) {
                if (s[j] === s[i]) same++;
                else deleted++;
                if (deleted > d) break;

                dp[i][d] = Math.min(
                    dp[i][d],
                    encodedLength(same) + dp[j + 1][d - deleted]
                );
            }
        }
    }
    return dp[0][k];
};

solution.pyO(n²k)
class Solution:
    def getLengthOfOptimalCompression(self, s: str, k: int) -> int:
        n = len(s)
        inf = 10**6
        dp = [[inf] * (k + 1) for _ in range(n + 1)]
        dp[n] = [0] * (k + 1)

        def encoded_length(count: int) -> int:
            if count == 1:
                return 1
            if count < 10:
                return 2
            if count < 100:
                return 3
            return 4

        for i in range(n - 1, -1, -1):
            for d in range(k + 1):
                if d > 0:
                    dp[i][d] = dp[i + 1][d - 1]

                same = 0
                deleted = 0
                for j in range(i, n):
                    if s[j] == s[i]:
                        same += 1
                    else:
                        deleted += 1
                    if deleted > d:
                        break

                    dp[i][d] = min(
                        dp[i][d],
                        encoded_length(same) + dp[j + 1][d - deleted],
                    )

        return dp[0][k]

C++

solution.cppO(n²k)
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int getLengthOfOptimalCompression(string s, int k) {
        int n = static_cast<int>(s.size());
        const int INF = 1'000'000;
        vector<vector<int>> dp(n + 1, vector<int>(k + 1, INF));
        fill(dp[n].begin(), dp[n].end(), 0);

        for (int i = n - 1; i >= 0; --i) {
            for (int d = 0; d <= k; ++d) {
                if (d > 0) dp[i][d] = dp[i + 1][d - 1];

                int same = 0;
                int deleted = 0;
                for (int j = i; j < n; ++j) {
                    if (s[j] == s[i]) ++same;
                    else ++deleted;
                    if (deleted > d) break;

                    dp[i][d] = min(
                        dp[i][d],
                        encodedLength(same) + dp[j + 1][d - deleted]
                    );
                }
            }
        }
        return dp[0][k];
    }

private:
    int encodedLength(int count) {
        if (count == 1) return 1;
        if (count < 10) return 2;
        if (count < 100) return 3;
        return 4;
    }
};

替代方案

另一种常见 DP 会把状态写成 (index, remainingK, previousChar, previousCount)，逐字符决定删或留，并只在计数跨过 1、9、99 时增加长度。它同样正确，但状态更复杂，记忆化键更大；本页的“枚举下一段”写法更紧凑。

常见错误

  • 误以为每增加一个相同字符，编码长度都加 1。
  • 只删除整段，漏掉删除中间字符后合并两段。
  • 单字符错误编码成 a1。
  • 把“至多 k 个”写成“必须恰好 k 个”。
  • 忘记 100 的计数需要 3 位数字。

面试追问

  1. 为什么区间里的异类字符必须全部删除？ 因为这一转移正把所有保留的 s[i] 合为同一个连续段；任何异类字符被保留都会截断该段。
  2. 能把空间降到 O(k) 吗？ 不能直接滚动两行，因为转移会访问任意 j+1 行，而不只是 i+1。
  3. 若字符串长度远大于 100 呢？ 编码长度函数应推广为 1 + digits(count)；门槛继续出现在 1000、10000 等十的幂。
  4. 怎样恢复具体删除方案？ 为每个 DP 状态额外记录取得最小值的选择，再从 (0,k) 顺着选择回溯。
