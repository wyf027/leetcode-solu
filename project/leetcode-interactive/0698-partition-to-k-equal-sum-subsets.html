划分为 k 个相等的子集

把一组数字完整放入若干个“等容量容器”。每个数字只能使用一次，每个容器都必须非空，并且最终总和完全相同。

MEDIUM
题目

先理解目标，再决定怎么搜索

给定整数数组 nums 和正整数 k，判断能否把数组中的全部元素划分为 k 个非空子集，使每个子集的元素总和都相等。

函数签名

canPartitionKSubsets(nums, k) → boolean

约束

  • 1 ≤ k ≤ nums.length ≤ 16
  • 1 ≤ nums[i] ≤ 104
  • 每个元素值的出现频率在 [1, 4] 范围内

输出：true

完整题解

降序分桶回溯 + 对称剪枝

核心洞察

若总和为 S，每组只能以 target = S / k 为目标。将数字降序后逐个放入 k 个桶，能让“不可能容纳”的冲突更早出现；而当前和相同的桶在这一层完全对称，只需尝试其中一个。

完整过程

  1. 求数组总和。若不能被 k 整除，直接返回 false。
  2. 令每桶目标和为 target；降序排列。若最大值超过目标，直接失败。
  3. 从最大元素开始，枚举将它放进哪个桶；只有放入后不超过 target 才继续。
  4. 递归放下一个元素；失败时撤销本次放置。
  5. 同一层跳过当前和相同的桶；若尝试一个空桶仍失败，不再尝试其余空桶。
  6. 全部元素放完即成功。

剪枝为什么有效

  • 降序：大数约束更强，先放更容易提前失败。
  • 容量：正整数条件下，桶和超过目标后不可能再下降。
  • 同和桶去重：桶没有身份；当前和相同意味着交换桶标签不会产生新划分。
  • 空桶终止：若放入一个空桶后找不到解，换到另一个空桶只是在重命名。

正确性证明

不变量：递归深度 i 时，前 i 个数字各被放入且仅放入一个桶；任何桶的当前和都不超过 target。
完备性：对当前数字，算法枚举所有不超容量的桶。被跳过的同和桶或空桶只与已尝试桶标签不同，不会删掉本质不同的划分。因此若合法划分存在，其对应放置路径会被搜索到。
成功的充分性：全部元素放完时，所有桶和均不超过 target；同时它们总和等于 k × target，故每个桶都恰好等于 target。因元素均为正数且 target > 0，每桶非空。
结论：算法返回 true 当且仅当数组能够划分为 k 个等和非空子集。

复杂度

时间：最坏为 O(kn)，因为每个元素最多尝试进入 k 个桶；排序另需 O(n log n)。剪枝通常会大幅缩小搜索树，但不改变最坏上界。

空间：O(n + k)，包括递归栈与桶数组；不计排序实现可能使用的额外空间。

边界情况

  • S % k != 0：目标和不是整数。
  • 最大元素大于 target：该元素无桶可放。
  • k = 1：整个数组自然是一组。
  • k = nums.length：只有所有元素相等时才成立。
  • 大量重复值：同和桶剪枝尤其重要。

四语言完整代码

import java.util.Arrays;

class Solution {
    public boolean canPartitionKSubsets(int[] nums, int k) {
        int total = 0;
        for (int num : nums) total += num;
        if (total % k != 0) return false;

        int target = total / k;
        Arrays.sort(nums);
        if (nums[nums.length - 1] > target) return false;

        int[] buckets = new int[k];
        return dfs(nums, nums.length - 1, buckets, target);
    }

    private boolean dfs(int[] nums, int index, int[] buckets, int target) {
        if (index < 0) return true;
        int value = nums[index];

        for (int i = 0; i < buckets.length; i++) {
            boolean sameStateSeen = false;
            for (int j = 0; j < i; j++) {
                if (buckets[j] == buckets[i]) {
                    sameStateSeen = true;
                    break;
                }
            }
            if (sameStateSeen || buckets[i] + value > target) continue;

            buckets[i] += value;
            if (dfs(nums, index - 1, buckets, target)) return true;
            buckets[i] -= value;

            if (buckets[i] == 0) break;
        }
        return false;
    }
}
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {boolean}

var canPartitionKSubsets = function(nums, k) {
    const total = nums.reduce((sum, value) => sum + value, 0);
    if (total % k !== 0) return false;

    const target = total / k;
    nums.sort((a, b) => b - a);
    if (nums[0] > target) return false;

    const buckets = new Array(k).fill(0);

    function dfs(index) {
        if (index === nums.length) return true;
        const value = nums[index];
        const seenSums = new Set();

        for (let i = 0; i < k; i++) {
            if (seenSums.has(buckets[i])) continue;
            seenSums.add(buckets[i]);
            if (buckets[i] + value > target) continue;

            buckets[i] += value;
            if (dfs(index + 1)) return true;
            buckets[i] -= value;

            if (buckets[i] === 0) break;
        }
        return false;
    }

    return dfs(0);
};
from typing import List


class Solution:
    def canPartitionKSubsets(self, nums: List[int], k: int) -> bool:
        total = sum(nums)
        if total % k != 0:
            return False

        target = total // k
        nums.sort(reverse=True)
        if nums[0] > target:
            return False

        buckets = [0] * k

        def dfs(index: int) -> bool:
            if index == len(nums):
                return True

            value = nums[index]
            seen_sums = set()
            for i in range(k):
                if buckets[i] in seen_sums:
                    continue
                seen_sums.add(buckets[i])
                if buckets[i] + value > target:
                    continue

                buckets[i] += value
                if dfs(index + 1):
                    return True
                buckets[i] -= value

                if buckets[i] == 0:
                    break
            return False

        return dfs(0)

class Solution {
public:
    bool canPartitionKSubsets(vector<int>& nums, int k) {
        int total = accumulate(nums.begin(), nums.end(), 0);
        if (total % k != 0) return false;

        int target = total / k;
        sort(nums.begin(), nums.end(), greater<int>());
        if (nums[0] > target) return false;

        vector<int> buckets(k, 0);
        return dfs(nums, 0, buckets, target);
    }

private:
    bool dfs(const vector<int>& nums, int index,
             vector<int>& buckets, int target) {
        if (index == static_cast<int>(nums.size())) return true;
        int value = nums[index];
        unordered_set<int> seenSums;

        for (int i = 0; i < static_cast<int>(buckets.size()); i++) {
            if (seenSums.count(buckets[i])) continue;
            seenSums.insert(buckets[i]);

            buckets[i] += value;
            if (dfs(nums, index + 1, buckets, target)) return true;
            buckets[i] -= value;

            if (buckets[i] == 0) break;
        }
        return false;
    }

替代方案：状态压缩 DP

用位掩码 mask 表示已使用元素，记录当前未填满桶的和 dp[mask]。尝试加入一个未使用元素，只要不超过 target，新状态记录为 (dp[mask] + nums[i]) % target。

复杂度为 O(n × 2n) 时间和 O(2n) 空间。由于 n ≤ 16，它是稳定且很有竞争力的方案，但分桶回溯更直观，也便于讲清剪枝。

常见错误

  • 只判断总和能否被 k 整除，误以为这已充分。
  • 不降序，导致大量无效分支拖到很深才失败。
  • 忘记回溯时撤销桶和。
  • 对相同当前和的桶重复搜索。
  • 把“元素值重复”误当成“元素可复用”。

面试追问

为什么可以只检查“所有元素都放完”，而不用逐桶检查等于 target？

每桶始终不超过 target，而所有桶总和固定为 k × target。如果存在一个桶小于 target，就必须有另一个桶大于 target 才能补足总和，与不变量矛盾。

为什么同一层只尝试一个空桶？

所有空桶的状态完全相同。把当前数字放进空桶 A 或空桶 B，只是交换桶标签；后续可行性没有区别。

如果 nums 中允许负数，这个剪枝还能直接使用吗？

不能。出现负数后，当前桶和即使超过 target，后续仍可能被负数拉回；“超过容量立即剪枝”和成功条件都需要重新设计。

回溯和状态压缩 DP 怎么选？

希望代码直观、输入分布下剪枝有效时选回溯；希望获得与数值分布关系较小的稳定上界，且 n 较小时，可选 O(n × 2^n) 的状态压缩 DP。
