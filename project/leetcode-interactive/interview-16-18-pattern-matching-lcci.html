题解

默认封存，展开后显示完整推导与代码。

核心洞察

固定 a 的长度后，总长度方程会唯一决定 b 的长度；不能整除的候选直接淘汰。对可行长度对，沿 pattern 切割 value，首次遇到字母时登记字模，后续只做一致性比较。

若 pattern 以 b 开头，就交换 a / b，使首字符总是 a，从而保证 countA ≥ 1，统一枚举主线。

完整过程

  1. 空 pattern 只匹配空 value。
  2. 必要时交换 a / b，并统计出现次数。
  3. 枚举 lenA 从 0 到 |value| / countA。
  4. 用总长度方程计算 lenB，不能整除就跳过。
  5. 逐槽位切片、登记或比对，最后排除 a 与 b 相同。

边界与复杂度

  • 替换串允许为空，必须包含长度 0。
  • pattern 为空时先返回，避免除零。
  • 只有一种字母时，不强行构造另一种字模。
  • 两种字母都出现时，两份字模必须不同。

设 n = |pattern|、m = |value|。至多枚举 m + 1 个长度，每次扫描 pattern 并比较最多 m 个字符：时间 O(m(n + m))，额外空间 O(m)（保存切片）。

替代方案与取舍

双长度暴力：重复枚举本可由方程确定的维度，复杂度更高。

正则表达式：捕获组可表达重复，但空串、a≠b 与跨语言语义容易出错。

推荐：长度方程 + 单维枚举，边界清楚，最适合面试证明。

面试追问

  • 若 pattern 扩展到三种字符，长度方程还剩几个自由变量？
  • 如何避免 substring 复制，降低额外内存？
  • 若要求返回所有合法映射，怎样去重？
  • 为什么样例 4 合法，而 a、b 相同仍非法？

常见错误

  • 遗漏 lenA = 0 或 lenB = 0。
  • 空 pattern 时除以 countA。
  • 只验证总长度，没有验证重复切片一致。
  • 忘记排除 a === b。
  • 切片游标最终没有恰好到达 value 末尾。
