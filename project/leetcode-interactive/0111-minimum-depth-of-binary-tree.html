01 / Briefing

任务说明

给定一棵二叉树的根节点 root，返回它的最小深度。最小深度是从根节点到最近叶子节点的最短路径上，节点的数量。

目标

沿合法的父子连接走到某个叶子，统计路径上的节点数；在所有根到叶子的路径中取最小值。空树的最小深度为 0。

什么才是叶子？

叶子节点必须同时满足 left == null 与 right == null。只有一侧为空的节点不是叶子，不能把“走向空指针”算作完成路径。

02 / Official examples

官方样例

数组采用层序序列化，null 表示该位置没有节点。

样例一

输入 root = [3,9,20,null,null,15,7]
输出 2

根节点 3 的左孩子 9 已经是叶子，最近叶子位于第 2 层。

样例二

输入 root = [2,null,3,null,4,null,5,null,6]
输出 5

这棵树只有一条向右延伸的路径，节点 6 是第 5 层的唯一叶子。

05 / Rescue protocol

题解：BFS 首叶命中

面试主线选择层序遍历。BFS 天然按深度从小到大访问节点，因此第一次遇到叶子时，不可能还有更浅的叶子尚未检查。

Complete process

完整过程

  1. 如果 root == null，直接返回 0。
  2. 根节点入队，并把当前深度初始化为 1。
  3. 记录当前队列长度 levelSize，只处理这一层的节点。
  4. 每弹出一个节点，先判断它是否左右孩子都为空；若是，立即返回当前深度。
  5. 把存在的左右孩子入队；一层处理完后深度加一，继续下一层。

Edges & trade-offs

边界、复杂度与替代方案

关键边界

  • 空树返回 0。
  • 单节点既是根也是叶子，返回 1。
  • 只有一个孩子时，必须沿真实孩子继续，空侧不是到叶子的路径。
  • 节点数可达 10^5，递归 DFS 可能遭遇调用栈风险。

为什么推荐 BFS

BFS 在命中最近叶子时可以提前结束，语义直接、证明简洁，也避免深链递归栈溢出。若最近叶子很浅，它只访问树的前几层。

方案 时间 额外空间 取舍
BFS（推荐） O(n) 最坏 O(w)，w 为最大层宽 可提前退出；宽树队列可能较大。
递归 DFS O(n) O(h) 调用栈 代码短，但必须特殊处理单孩子，深链有栈风险。

Interview follow-up

面试追问与常见错误

常见追问

  • 如何输出通往最近叶子的完整路径？——给入队节点保存父指针，命中后回溯。
  • 若要找所有最浅叶子？——记录首个叶子所在层，完成该层扫描后停止。
  • 为什么第一次遇到叶子一定最浅？——队列保证所有深度 d 的节点先于深度 d+1 出队。

常见错误

  • 把“任一孩子为空”误判为叶子。
  • 递归写成 1 + min(leftDepth, rightDepth)，导致空孩子的 0 被错误选中。
  • JavaScript 使用反复 shift()，使队列操作发生数组整体搬移；应使用头指针。
  • 深度自增时机错位，返回边数而不是节点数。

四份实现均采用层序 BFS，并在第一片叶子出队时返回当前深度。 

class Solution {
    public int minDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int depth = 1;

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                if (node.left == null && node.right == null) {
                    return depth;
                }
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            depth++;
        }

        return depth;
    }
}
var minDepth = function (root) {
    if (root === null) {
        return 0;
    }

    const queue = [root];
    let head = 0;
    let depth = 1;

    while (head < queue.length) {
        const levelEnd = queue.length;
        while (head < levelEnd) {
            const node = queue[head++];
            if (node.left === null && node.right === null) {
                return depth;
            }
            if (node.left !== null) {
                queue.push(node.left);
            }
            if (node.right !== null) {
                queue.push(node.right);
            }
        }
        depth++;
    }

    return depth;
};
from collections import deque
from typing import Optional


class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0

        queue = deque([root])
        depth = 1

        while queue:
            for _ in range(len(queue)):
                node = queue.popleft()
                if node.left is None and node.right is None:
                    return depth
                if node.left is not None:
                    queue.append(node.left)
                if node.right is not None:
                    queue.append(node.right)
            depth += 1

        return depth
