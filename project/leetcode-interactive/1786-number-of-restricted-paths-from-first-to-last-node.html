从第一个节点出发到最后一个节点的受限路径数

01 · 题目说明

只沿“更接近终点”的边前进

给定节点编号为 1 到 n 的加权无向连通图。边 [u, v, weight] 表示 u、v 之间有一条指定权重的边。

distanceToLastNode(x) 是节点 x 到节点 n 的最短距离。一条从 1 到 n 的路径只有在相邻每一步的该距离都严格减小时，才是受限路径。请返回受限路径总数，并对 10⁹ + 7 取余。

distance(z₀) > distance(z₁) > … > distance(zₖ)

约束

  • 1 ≤ n ≤ 2 × 10⁴
  • n − 1 ≤ edges.length ≤ 4 × 10⁴
  • edges[i].length = 3
  • 1 ≤ uᵢ, vᵢ ≤ n
  • uᵢ ≠ vᵢ
  • 1 ≤ weightᵢ ≤ 10⁵
  • 任意两点至多一条边
  • 图连通

03 · 完整题解

反向最短路 + 距离序 DP

先得到每个点到 n 的最短距离，再只沿距离严格下降的方向累计路径数。

核心洞察完整过程正确性复杂度四语言代码测试与验证

核心洞察

① 从终点出发在无向图中，从 n 跑最短路，恰好同时得到每个节点的 distanceToLastNode。
② 严格下降即无环把每条边从较大距离指向较小距离。沿边距离必降，因此不可能回到旧节点，结构是 DAG。
③ 按距离递增计数令 dp[u] 为 u 到 n 的受限路径数。较小距离节点先算好，较大距离节点直接求和。

完整过程

  1. 建立无向邻接表，保存邻点和边权。
  2. 以节点 n 为源点运行 Dijkstra，得到数组 dist。
  3. 按 dist 从小到大排列所有节点；初始化 dp[n] = 1，表示终点到自身有一条空后缀路径。
  4. 依次处理节点 u。对每个邻点 v，只有 dist[v] < dist[u] 时才能从 u 走向 v，于是执行 dp[u] += dp[v]。
  5. 每次加法对 10⁹ + 7 取余，最终返回 dp[1]。

示例 1 的距离为 d(5)=0, d(3)=1, d(2)=2, d(1)=4, d(4)=6。因此 dp[5]=1、dp[3]=1、dp[2]=2、dp[1]=3。

正确性证明

引理 1：保留的有向边与受限路径的单步条件完全一致。

对无向边 {u,v}，若 dist[u] > dist[v]，受限路径允许 u→v；反向不满足严格下降。距离相等时两个方向都不允许。因此定向后保留的边恰好是全部合法单步。

引理 2：定向后的图无环。

沿每条有向边，dist 都严格减小。若存在环，绕环一周后同一节点的 dist 会严格小于自身，产生矛盾，所以该图是 DAG。

引理 3：DP 正确计算每个节点的受限路径数。

按 dist 递增处理 u 时，所有可去邻点 v 都满足 dist[v] < dist[u]，其 dp[v] 已经计算。任意从 u 出发的受限路径都唯一选择一条首边 u→v，余下部分共有 dp[v] 种；不同首边对应集合互斥，所以求和得到且只得到 dp[u]。

定理

由引理 1，受限路径与定向图中从 1 到 n 的路径一一对应；由引理 2、3，DP 完整且不重复地计数这些路径，因此返回的 dp[1] 正确。

边界情况

  • n = 1：dp[n] = 1，起点已是终点。
  • 距离相等：相等不是严格下降，该边不能用于任一方向。
  • 多条最短路：Dijkstra 只需最短距离值，不需要记录具体最短路径。
  • 大答案：路径数在每次累加时取模；距离使用 64 位整数更稳妥。
  • 陈旧堆项：Dijkstra 弹出距离大于当前 dist 的条目时跳过。

复杂度

时间复杂度O((n + m) log n)Dijkstra 为主；节点排序为 O(n log n)，DP 扫边 O(m)。
空间复杂度O(n + m)邻接表、距离、堆、排序数组与 DP。

替代方案

得到 dist 后，可以从节点 1 使用记忆化 DFS：只递归到更小距离的邻点。它同样是 O(n+m) 的计数阶段，但最坏递归深度可达 n；在递归栈限制严格的语言中，迭代式距离序 DP 更可靠。也可以在 Dijkstra 每次“最终确定”节点时同步做 DP，但实现细节更容易写错，分成两个清晰阶段更适合面试表达。

面试追问

  • 为什么从 n 跑 Dijkstra？无向图中 x 到 n 与 n 到 x 距离相同，一次单源最短路即可覆盖全部节点。
  • 为什么不能按节点编号做 DP？合法依赖由 dist 决定，与编号没有单调关系。
  • 若存在负权怎么办？Dijkstra 不再适用；还需先判断负环及最短距离是否有定义，再选择相应最短路算法。
  • 若规则改为非严格下降？等距边可能形成环，不能直接视为 DAG，需要处理等距强连通结构或重新定义计数语义。

常见错误

  • 从节点 1 求最短路，得到的并不是题目定义的“到 n 的最短距离”。
  • 把 > 写成 >=，错误纳入等距边。
  • 按 dist 递减计算 dp，导致依赖项尚未准备好。
  • 只统计最短路径；受限路径本身不要求总权重最短，只要求每一步的 dist 严格下降。
  • 用 32 位整数保存 Java/C++ 的候选距离或未及时对路径数取模。

import java.util.*;

class Solution {
    private static final int MOD = 1_000_000_007;

    public int countRestrictedPaths(int n, int[][] edges) {
        List<int[]>[] graph = new ArrayList[n + 1];
        for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }

        long[] dist = new long[n + 1];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[n] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, n});
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1];
            if (d != dist[u]) continue;
            for (int[] next : graph[u]) {
                int v = next[0], w = next[1];
                if (d + w < dist[v]) {
                    dist[v] = d + w;
                    pq.offer(new long[]{dist[v], v});
                }
            }
        }

        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i + 1;
        Arrays.sort(order, Comparator.comparingLong(u -> dist[u]));
        long[] dp = new long[n + 1];
        dp[n] = 1;
        for (int u : order) {
            for (int[] next : graph[u]) {
                int v = next[0];
                if (dist[v] < dist[u]) dp[u] = (dp[u] + dp[v]) % MOD;
            }
        }
        return (int) dp[1];
    }
}

var countRestrictedPaths = function(n, edges) {
    const MOD = 1_000_000_007;
    const graph = Array.from({ length: n + 1 }, () => []);
    for (const [u, v, w] of edges) {
        graph[u].push([v, w]);
        graph[v].push([u, w]);
    }

    class MinHeap {
        constructor() { this.data = []; }
        get size() { return this.data.length; }
        push(item) {
            const a = this.data;
            a.push(item);
            let i = a.length - 1;
            while (i > 0) {
                const p = (i - 1) >> 1;
                if (a[p][0] <= a[i][0]) break;
                [a[p], a[i]] = [a[i], a[p]];
                i = p;
            }
        }
        pop() {
            const a = this.data;
            const root = a[0];
            const last = a.pop();
            if (a.length) {
                a[0] = last;
                let i = 0;
                while (true) {
                    let smallest = i;
                    const l = i * 2 + 1, r = l + 1;
                    if (l < a.length && a[l][0] < a[smallest][0]) smallest = l;
                    if (r < a.length && a[r][0] < a[smallest][0]) smallest = r;
                    if (smallest === i) break;
                    [a[i], a[smallest]] = [a[smallest], a[i]];
                    i = smallest;
                }
            }
            return root;
        }
    }

    const dist = Array(n + 1).fill(Infinity);
    dist[n] = 0;
    const heap = new MinHeap();
    heap.push([0, n]);
    while (heap.size) {
        const [d, u] = heap.pop();
        if (d !== dist[u]) continue;
        for (const [v, w] of graph[u]) {
            if (d + w < dist[v]) {
                dist[v] = d + w;
                heap.push([dist[v], v]);
            }
        }
    }

    const order = Array.from({ length: n }, (_, i) => i + 1);
    order.sort((a, b) => dist[a] - dist[b]);
    const dp = Array(n + 1).fill(0);
    dp[n] = 1;
    for (const u of order) {
        for (const [v] of graph[u]) {
            if (dist[v] < dist[u]) dp[u] = (dp[u] + dp[v]) % MOD;
        }
    }
    return dp[1];
};
from typing import List
import heapq


class Solution:
    def countRestrictedPaths(self, n: int, edges: List[List[int]]) -> int:
        MOD = 1_000_000_007
        graph = [[] for _ in range(n + 1)]
        for u, v, w in edges:
            graph[u].append((v, w))
            graph[v].append((u, w))

        dist = [float("inf")] * (n + 1)
        dist[n] = 0
        heap = [(0, n)]
        while heap:
            d, u = heapq.heappop(heap)
            if d != dist[u]:
                continue
            for v, w in graph[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(heap, (nd, v))

        order = sorted(range(1, n + 1), key=lambda u: dist[u])
        dp = [0] * (n + 1)
        dp[n] = 1
        for u in order:
            for v, _ in graph[u]:
                if dist[v] < dist[u]:
                    dp[u] = (dp[u] + dp[v]) % MOD
        return dp[1]
class Solution {
public:
    int countRestrictedPaths(int n, vector<vector<int>>& edges) {
        const int MOD = 1'000'000'007;
        vector<vector<pair<int, int>>> graph(n + 1);
        for (const auto& e : edges) {
            graph[e[0]].push_back({e[1], e[2]});
            graph[e[1]].push_back({e[0], e[2]});
        }

        const long long INF = numeric_limits<long long>::max();
        vector<long long> dist(n + 1, INF);
        priority_queue<pair<long long, int>,
                       vector<pair<long long, int>>,
                       greater<pair<long long, int>>> pq;
        dist[n] = 0;
        pq.push({0, n});
        while (!pq.empty()) {
            auto [d, u] = pq.top();
            pq.pop();
            if (d != dist[u]) continue;
            for (auto [v, w] : graph[u]) {
                if (d + w < dist[v]) {
                    dist[v] = d + w;
                    pq.push({dist[v], v});
                }
            }
        }

        vector<int> order(n);
        iota(order.begin(), order.end(), 1);
        sort(order.begin(), order.end(), [&](int a, int b) {
            return dist[a] < dist[b];
        });
        vector<long long> dp(n + 1, 0);
        dp[n] = 1;
        for (int u : order) {
            for (auto [v, _] : graph[u]) {
                if (dist[v] < dist[u]) dp[u] = (dp[u] + dp[v]) % MOD;
            }
        }
        return static_cast<int>(dp[1]);
    }
};
