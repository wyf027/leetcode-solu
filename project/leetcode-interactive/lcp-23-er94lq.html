CARD MAGIC · SIMULATION

LCP 23. 魔术排列

初始牌为 1 到 N。每轮先把当前偶数位置（从 1 开始计数）的牌保持相对顺序放到奇数位置牌之前，再取走前 k 张。判断是否存在某个固定 k，使取走顺序恰好等于 target。

LCP 23中等分块模拟

题意

特殊洗牌将 [1,2,3,4,5] 变为 [2,4,1,3,5]。若当前余牌数大于 k，取走前 k 张并在余牌上重复洗牌；余牌数不大于 k 时全部取走。target 是 1..N 的一个排列。

示例

target = [2, 4, 3, 1, 5]

输出 = true

取 k = 2：首轮取 [2,4]，余牌洗后为 [3,1,5]，再取 [3,1]，最后取 [5]。

关键观察

第一轮洗牌后，和 target 的最长公共前缀长度被唯一确定为 k。之后每一轮的匹配长度必须恰好仍为 k（最后一块可不足 k），否则不存在统一的 k。

题解：第一块决定 k

从 [1..N] 开始，在尚未取走的后缀上执行洗牌。记录该轮洗牌结果与 target 对应后缀的最长公共前缀长度 match。第一轮的 match 就是唯一候选 k；以后每轮必须匹配满 k 张，除非已到最后不足 k 张。任何一轮 match 为 0 或小于 k 都失败。

洗牌

对当前后缀依次写入原下标 1、3、5…，再写入 0、2、4…；这正是 1-based 偶数位置在前。

复杂度

每张牌在若干轮中参与洗牌；直接模拟的上界 O(N²)，N≤5000 可通过，额外空间 O(N)。

常见错误

把 0-based 偶数下标放前；每轮重新猜 k；或忘记最终不足 k 的剩余牌应整体取走。

替代方案与面试追问

可用双端队列写洗牌以避免数组搬移，但核心判断不变。追问：若每轮 k 可变化，则首块不再锁定全局 k，需要另行搜索或 DP。

四语言可提交代码

Java

import java.util.*;
class Solution {
  public boolean isMagic(int[] target) {
    int n = target.length, first = -1, idx = 0; int[] cards = new int[n];
    for (int i = 0; i < n; i++) cards[i] = i + 1;
    while (idx < n) {
      int[] old = cards.clone(); int p = idx;
      for (int j = idx + 1; j < n; j += 2) cards[p++] = old[j];
      for (int j = idx; j < n; j += 2) cards[p++] = old[j];
      int q = idx; while (q < n && cards[q] == target[q]) q++;
      int match = q - idx;
      if (match == n - idx) return true;
      if (first < 0) first = match;
      if (match == 0 || match < first) return false;
      idx += match;
    }
    return true;
  }
}

from typing import List
class Solution:
    def isMagic(self, target: List[int]) -> bool:
        n = len(target); cards = list(range(1, n + 1)); first = -1; idx = 0
        while idx < n:
            old = cards[:]
            cards[idx:] = old[idx + 1:n:2] + old[idx:n:2]
            q = idx
            while q < n and cards[q] == target[q]: q += 1
            match = q - idx
            if match == n - idx: return True
            if first < 0: first = match
            if match == 0 or match < first: return False
            idx += match
        return True
