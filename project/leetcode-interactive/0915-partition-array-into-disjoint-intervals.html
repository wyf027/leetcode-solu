分割数组

Partition Array into Disjoint Intervals

MEDIUM连续子数组贪心一次遍历

题目

给定整数数组 nums，把它切成两个非空、连续的子数组 left 与 right。要求 left 中的每个数都不大于 right 中的每个数，并让 left 尽可能短。返回 left 的长度。输入保证至少存在一种合法切法。

返回形式：partitionDisjoint(nums: integer[]): integer

官方示例

输入：nums = [5,0,3,8,6] 输出：3 解释：left = [5,0,3]，right = [8,6]
输入：nums = [1,1,1,0,6,12] 输出：4 解释：left = [1,1,1,0]，right = [6,12]

约束与目标

  • 2 <= nums.length <= 105
  • 0 <= nums[i] <= 106
  • 保证至少存在一个合法答案。

Greedy invariant

核心洞察

维护三个量：当前左区间终点 boundary、左区间最大值 leftMax，以及扫描到当前位置的全局最大值 scanMax。当新元素小于 leftMax 时，它不能留在右区间——否则左侧的 leftMax 会大于它。因此必须把边界扩到当前位置，并把扩张前扫描到的最大值升级为新的 leftMax。

完整过程

  1. 令边界为 0，两个最大值都等于 nums[0]。
  2. 从下标 1 开始扫描，持续更新 scanMax。
  3. 若 nums[i] < leftMax，将边界扩到 i，并令 leftMax = scanMax。
  4. 扫描结束，返回 boundary + 1。

为什么正确

每次出现小于 leftMax 的元素时，任何早于当前位置的切口都违法，所以扩张是必要的。扩张后，leftMax 取新左区间真实最大值。最后一次扩张之后再无元素小于它，因此所有右侧元素都至少为 leftMax。每次只在必要时扩张，所得左区间自然最短。

复杂度

时间 O(n)，额外空间 O(1)。

边界情况

  • 数组本身递增或相等：答案可以是 1。
  • 低值在靠后位置出现：边界可能多次扩张。
  • 左右允许相等，判断必须是 <，不是 <=。

替代方案

预处理后缀最小值，再从左向右维护前缀最大值，找到第一个 prefixMax[i] <= suffixMin[i+1] 的位置。思路直接，但需要 O(n) 额外空间。

完整代码

class Solution {
    public int partitionDisjoint(int[] nums) {
        int boundary = 0;
        int leftMax = nums[0], scanMax = nums[0];
        for (int i = 1; i < nums.length; i++) {
            scanMax = Math.max(scanMax, nums[i]);
            if (nums[i] < leftMax) {
                boundary = i;
                leftMax = scanMax;
            }
        }
        return boundary + 1;
    }
}

面试追问

  • 如何用后缀最小值实现？空间能否降到常数？
  • 为什么更新 leftMax 时必须使用 scanMax？
  • 若题目不保证存在答案，接口应如何设计？

常见错误

  • 只和前一个元素比较，忽略整个左区间最大值。
  • 扩张边界后把 leftMax 设成当前元素。
  • 返回边界下标，而不是左区间长度。
