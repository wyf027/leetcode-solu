数组大小减半

把相同数字装进同一个“货箱”，再决定最少搬走几类货箱，才能清空至少一半库存。

中等 数组 哈希表 排序 贪心 非付费题
≥ 50%
目标：删除 ≥ n / 2
代价：选择的数字种类数

Problem

任务说明

先理解目标，再进入频次实验室。

题意转述

给定整数数组 arr。你可以选择一个整数集合，并删除数组中这些整数的全部出现。请返回集合的最小大小，使删除的元素数量至少达到原数组的一半。

约束

  • 2 ≤ arr.length ≤ 10⁵
  • arr.length 为偶数
  • 1 ≤ arr[i] ≤ 10⁵

官方参数形式

函数minSetSize(arr)
参数arr: integer[]
返回integer
目标数量arr.length / 2

示例 1

输入：arr = [3,3,3,3,5,5,5,2,2,7] 输出：2

选择集合 {3,7} 后，剩余 [5,5,5,2,2]，长度恰好为 5。也可选择 {3,5}、{3,2} 或 {5,2}；而 {2,7} 只能删除 3 个元素，不满足要求。

示例 2

输入：arr = [7,7,7,7,7,7] 输出：1

只需选择集合 {7}，即可删除全部 6 个元素，因此最小集合大小为 1。

Solution

频次排序 + 贪心

集合中选择的是“数字种类”，一种数字一旦被选中，其所有出现都会被删除。因此，每次选择出现次数最多的尚未选数字，可以用最少的选择次数最快达到删除目标。

01

统计

用哈希表把数组压缩为“数字 → 出现次数”。

02

排序

只保留频次数组，并按从大到小排列。

03

累加

从最大频次开始累加，首次达到 n / 2 时返回已选种类数。

正确性：交换论证

设某个最优方案选择了 k 种数字，但其中包含频次较小的 a，却没有包含频次更大的 b。用 b 替换 a 后，选择的种类数仍为 k，删除数量不会减少，方案仍然可行。反复交换后，可得到由前 k 个最大频次组成的最优方案。因此，从大到小取频次，第一次达到一半时使用的种类数就是最小值。

时间复杂度

设不同数字个数为 m。计数为 O(n)，排序为 O(m log m)，总计 O(n + m log m)，最坏为 O(n log n)。

空间复杂度

哈希表和频次数组都至多保存 m 项，因此为 O(m)。

边界情况

  • 所有元素相同：选择 1 种即可删除至少一半。
  • 所有元素都不同：每个频次均为 1，需要选择恰好 n / 2 种。
  • 某个最高频数字刚好出现 n / 2 次：答案为 1。
  • 累计删除量超过 n / 2 也满足“至少一半”，不要求恰好相等。

替代方案

  • 最大堆：把所有频次入堆，每次弹出最大值。时间 O(n + m log m)，适合流式理解，但实现更重。
  • 桶计数：频次最大不超过 n，可用 bucket[f] 记录有多少数字出现 f 次，再从 n 向下扫描，达到 O(n) 时间、O(n) 空间。

常见错误

  • 按数字值大小排序，而不是按出现频次排序。
  • 误把目标写成“剩余一半”，循环条件应判断累计删除量是否达到 n / 2。
  • 只删除某个数字的一次出现；题目要求删除该数字的所有出现。
  • 达到目标后没有立即返回，导致答案偏大。

面试追问

  • 如果不能排序，如何用频次桶做到 O(n)？
  • 如果目标从一半改成任意比例 p，算法哪里需要变化？
  • 如果数组以数据流到达、内存受限，如何近似统计高频项？
  • 若删除每种数字有不同成本，原贪心为何失效？可以如何建模？

import java.util.ArrayList;
import java.util.Collections;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int minSetSize(int[] arr) {
        Map<Integer, Integer> frequency = new HashMap<>();
        for (int value : arr) {
            frequency.put(value, frequency.getOrDefault(value, 0) + 1);
        }

        List<Integer> counts = new ArrayList<>(frequency.values());
        counts.sort(Collections.reverseOrder());

        int removed = 0;
        int selected = 0;
        int target = arr.length / 2;

        for (int count : counts) {
            removed += count;
            selected++;
            if (removed >= target) {
                return selected;
            }
        }
        return selected;
    }
}

var minSetSize = function(arr) {
    const frequency = new Map();
    for (const value of arr) {
        frequency.set(value, (frequency.get(value) || 0) + 1);
    }

    const counts = [...frequency.values()].sort((a, b) => b - a);
    const target = arr.length / 2;
    let removed = 0;

    for (let i = 0; i < counts.length; i++) {
        removed += counts[i];
        if (removed >= target) {
            return i + 1;
        }
    }
    return counts.length;
};
from collections import Counter
from typing import List


class Solution:
    def minSetSize(self, arr: List[int]) -> int:
        counts = sorted(Counter(arr).values(), reverse=True)
        target = len(arr) // 2
        removed = 0

        for selected, count in enumerate(counts, start=1):
            removed += count
            if removed >= target:
                return selected

        return len(counts)
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int minSetSize(vector<int>& arr) {
        unordered_map<int, int> frequency;
        for (int value : arr) {
            ++frequency[value];
        }

        vector<int> counts;
        counts.reserve(frequency.size());
        for (const auto& entry : frequency) {
            counts.push_back(entry.second);
        }
        sort(counts.rbegin(), counts.rend());

        int removed = 0;
        int selected = 0;
        const int target = static_cast<int>(arr.size()) / 2;

        for (int count : counts) {
            removed += count;
            ++selected;
            if (removed >= target) {
                return selected;
            }
        }
        return selected;
    }
};
