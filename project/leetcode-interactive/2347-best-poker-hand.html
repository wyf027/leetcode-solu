最好的扑克手牌

Best Poker Hand

五张牌，四种牌型。先观察手牌，再亲手走过一次判断过程。

01 / 题目与规则

官方题目 ↗

给定整数数组 ranks 和字符数组 suits。第 i 张牌的点数和花色分别是 ranks[i]、suits[i]。从这 5 张牌中，选择能够组成的最高等级牌型，返回对应字符串，大小写必须完全一致。

  1. Flush：5 张牌的花色全部相同。
  2. Three of a Kind：可以选出 3 张点数相同的牌。
  3. Pair：可以选出 2 张点数相同的牌。
  4. High Card：以上均不成立时的高牌。

上述列表按等级从高到低排列。本题仅使用这四种类型，不采用完整扑克规则中的顺子、四条等额外名称。

约束

  • ranks.length == suits.length == 5
  • 1 <= ranks[i] <= 13
  • 'a' <= suits[i] <= 'd'
  • 任意两张牌的点数与花色不能同时相同。

02 / 官方示例

示例 1 · 同花

ranks = [13,2,3,1,9]
suits = ["a","a","a","a","a"]
输出："Flush"

五张牌都属于花色 a，因此组成同花。

示例 2 · 三条

ranks = [4,4,2,4,4]
suits = ["d","a","a","b","c"]
输出："Three of a Kind"

第 1、2、4 张牌点数均为 4，可以组成三条。虽然也能组成对子，但三条等级更高；四张 4 中还可以选择其他三张。

示例 3 · 对子

ranks = [10,10,2,12,9]
suits = ["a","b","c","a","d"]
输出："Pair"

前两张牌的点数相同，且无法组成同花或三条，所以选择对子。

05 / 独立题解

准备好后再展开：从计数不变量到四语言实现。

核心洞察：花色是否统一，点数最多出现几次

所有牌型只取决于两个事实：五张牌是否同花，以及同一点数的最大出现次数 m。先检查最高等级的同花；否则，m ≥ 3 为三条，m ≥ 2 为对子，剩下是高牌。无需排序，也无需枚举选牌组合。

完整过程

  1. 逐张比较花色与 suits[0]，维护 flush；一旦出现不同花色，它就保持 false。
  2. 如果始终一致，返回 "Flush"。
  3. 创建长度为 14 的计数数组，索引 0 不使用。读取点数 r 时执行 ++count[r]，同时维护最大次数 m。
  4. 计数完成后，按 m ≥ 3、m ≥ 2 的顺序返回对应牌型；均不满足则返回 "High Card"。

以示例 2 为例：花色 d、a 不同，排除同花；点数 4 的计数依次为 1、2、3、4，点数 2 为 1。最终最大次数 4 ≥ 3，可以选出三张 4，返回三条。

正确性说明

  • 花色不变量：读取前 k 张牌后，flush 为 true 当且仅当这 k 张牌都与第一张花色相同。因此全部读取后能准确识别同花，它已是最高等级。
  • 计数不变量：每读取一张牌，仅将其点数槽加一，所以 count[r] 始终等于已读牌中点数 r 的数量，m 是所有槽的最大值。
  • 分类完备：非同花时，m ≥ 3 当且仅当可选三张同点数牌；否则 m ≥ 2 当且仅当可选对子；否则所有点数只出现一次，只剩高牌。按等级判断保证返回最好的一类。

边界与常见错误

  • 四张同点数仍可选三张，因此应使用 ≥ 3，不能只判断 == 3。
  • 三条可能同时包含对子，不能一看到两张相同就直接返回 Pair。
  • 两对返回 Pair；三条加对子返回 Three of a Kind。本题没有 Two Pair 或 Full House。
  • 点数可以是 13，数组要有 14 格；A 在这里用数值 1 表示，不需要特殊大小比较。
  • 合法输入无完全相同的牌，因此五张同花时点数也各不相同；不应构造违反约束的同花加三条用例。
  • 不用识别顺子，不返回最大的点数；注意输出字符串空格与大小写。

复杂度

本题固定 5 张牌、13 种点数，时间和额外空间均为 O(1)。若将牌数推广为 n、点数域大小为 R，数组初始化与扫描共 O(n + R) 时间，O(R) 额外空间；R 固定时扫描时间为 O(n)。

替代方案

可用哈希表统计点数，适合点数域很大或不连续的推广题；本题固定小范围数组更直接。也可排序点数后统计相邻段长度，但需要 O(n log n) 时间，并可能改动输入。枚举三张、两张组合能做，但重复比较更多。

面试追问

  • 能一趟处理吗？可以同时更新同花标记与点数计数，最后按优先级分类。
  • 什么时候能提前返回三条？只有已确定不可能同花时；更简单的写法是先完成花色检查。
  • 若新增完整扑克规则呢？需要更多特征，例如点数连续性、不同点数数量与频次分布，并重新明确牌型优先级；本题实现不能直接当作完整扑克判定器。

Java

class Solution {
    public String bestHand(int[] ranks, char[] suits) {
        boolean flush = true;
        for (char suit : suits) {
            if (suit != suits[0]) flush = false;
        }
        if (flush) return "Flush";
        int[] count = new int[14];
        int max = 0;
        for (int rank : ranks) {
            max = Math.max(max, ++count[rank]);
        }
        if (max >= 3) return "Three of a Kind";
        if (max >= 2) return "Pair";
        return "High Card";
    }
}

Python 3

from typing import List

class Solution:
    def bestHand(self, ranks: List[int], suits: List[str]) -> str:
        if all(suit == suits[0] for suit in suits):
            return "Flush"
        count = [0] * 14
        maximum = 0
        for rank in ranks:
            count[rank] += 1
            maximum = max(maximum, count[rank])
        if maximum >= 3:
            return "Three of a Kind"
        if maximum >= 2:
            return "Pair"
        return "High Card"
