回文子数组求和

给定正整数数组 nums，从所有连续、非空且正反相同的子数组中，返回元素和的最大值。单个元素也天然是回文。

为什么不是最长回文？

比较的是元素和，不是长度；不过元素全为正，因此同一中心处越向外扩的回文和一定越大。

推荐主线

Manacher 在线性时间找每个中心的最大奇/偶回文半径；前缀和把最大半径直接换成区间和。

题意、示例与约束

示例

nums = [1, 2, 3, 2, 1, 5, 6]

最大回文子数组为 [1, 2, 3, 2, 1]，输出 9。

nums = [1, 2, 3, 4, 5] 时没有长度大于 1 的回文，输出 5。

约束

1 ≤ nums.length ≤ 10⁵

1 ≤ nums[i] ≤ 10⁹

答案须用 64 位整数保存。数组成员可以是任意正整数，回文比较的是值而非字符。

可视化实验室：最大半径 + 前缀和

输入逗号分隔的正整数。实验室用中心扩展展示一个中心的最远回文（便于观察）；正式算法用 Manacher 将所有中心总耗时降为 O(n)。

题解（默认收起）

首屏先理解题目；需要时再展开完整推导与代码。

核心洞察：所有值为正，所以固定一个回文中心时，最大的可扩半径对应的回文包含其所有更小回文，和也必然最大。Manacher 给出每个奇中心 d1[i] 与偶中心 d2[i] 的最大半径；利用 prefix[r] - prefix[l] 只需 O(1) 计算该候选和。

完整过程

  1. 建立 pre[0..n]，其中 pre[i+1] = pre[i] + nums[i]。
  2. 用 Manacher 的奇回文扫描得到 d1：d1[i] 表示以 i 为中心、含中心的半径。
  3. 用偶回文扫描得到 d2：d2[i] 表示中心在 i−1 和 i 之间的半径。
  4. 奇中心的最大区间为 [i-d1[i]+1, i+d1[i]-1]；偶中心为 [i-d2[i], i+d2[i]-1]。各自通过前缀和更新答案。

边界

长度 1（答案就是该值）；全不相同（取最大单点）；全相同（整个数组）；大值求和要使用 long / long long / BigInt。

复杂度

两次 Manacher 和一次枚举：O(n) 时间，O(n) 额外空间。中心扩展会退化到 O(n²)。

替代方案、面试追问、常见错误

替代：哈希 + 二分半径可做但实现和常数更大；DP 会超时。追问：若允许负数，最大半径不一定最大和，需要在每个中心的嵌套回文中做区间最优查询。常见错误：把偶回文中心也当作元素下标；奇半径端点少/多减 1；用 int 保存前缀和；只找最长回文。
