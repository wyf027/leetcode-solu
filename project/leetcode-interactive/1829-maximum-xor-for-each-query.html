每个查询的最大异或值

Maximum XOR for Each Query

一轮选择，一个删尾操作。先自己拨动二进制位，再探索每次查询之间的联系。

官方题目 ↗

01 / 题目

给定按非递减顺序排列的非负整数数组 nums 和整数 maximumBit。一共进行 n = nums.length 轮查询：每轮选择满足 0 ≤ k < 2^maximumBit 的整数，使当前数组所有元素与 k 的异或结果最大，然后删除当前数组的最后一个元素。

返回每轮所选的 k，按查询发生顺序组成数组 answer。注意：返回的不是最大异或结果本身。

约束

  • nums.length == n，1 ≤ n ≤ 10^5
  • 1 ≤ maximumBit ≤ 20
  • 0 ≤ nums[i] < 2^maximumBit
  • nums 已按升序排列，允许重复值。

输出：[0,3,2,3]

05 / 独立题解

准备好后展开，查看思路推导与四种语言实现。

核心洞察：在有限位宽内补齐每一位

令 b = maximumBit，当前数组异或为 x。所有数都只有低 b 位可能为 1，因此最终异或结果最多为 mask = (1 << b) - 1，也就是 b 个 1。逐位选择与 x 相反的位，即 k = x ^ mask，恰好让结果达到 mask。

删尾也无需重算：因为 a ^ a = 0，把离开的元素再次异或进 x，就移除了它的贡献。

完整过程

  1. 遍历数组，求所有元素的异或 x；计算低 b 位全为 1 的 mask。
  2. 从数组尾下标 j = n − 1 向前走。
  3. 先把 x ^ mask 写入当前查询的答案。
  4. 再执行 x ^= nums[j]，模拟删除尾元素。
  5. 重复 n 轮，返回答案；原始数组不需要修改。

正确性证明

最优性：每个合法输入和 k 均小于 2^b，异或后的高位为 0，故结果不超过 mask。所选 k = x ^ mask 仍在合法区间，且 x ^ k = x ^ x ^ mask = mask，达到上界，因此最优。

循环不变量：每轮开始时，x 是当前剩余前缀的异或值。初始化对整个数组异或，命题成立。记录本轮最优 k 后，再异或当前尾元素，依据结合律、交换律与自消性，x 正好成为下一轮前缀的异或值，命题保持。循环处理全部 n 个前缀，因此返回顺序正确且所有答案最优。

边界与复杂度

单元素仍需先答题再删尾；全零时每轮答案为 mask；重复值会抵消；b = 20 时移位与异或均安全地落在 JavaScript 有符号 32 位整数范围内。已排序条件不参与算法，因此无需排序。

时间复杂度 O(n)；除输出数组外辅助空间 O(1)，计入答案为 O(n)。

Java

class Solution {
    public int[] getMaximumXor(int[] nums, int maximumBit) {
        int x = 0;
        for (int v : nums) x ^= v;
        int mask = (1 << maximumBit) - 1;
        int n = nums.length;
        int[] answer = new int[n];
        for (int i = 0; i < n; i++) {
            answer[i] = x ^ mask;
            x ^= nums[n - 1 - i];
        }
        return answer;
    }
}

Python 3

from typing import List

class Solution:
    def getMaximumXor(self, nums: List[int], maximumBit: int) -> List[int]:
        x = 0
        for v in nums:
            x ^= v
        mask = (1 << maximumBit) - 1
        answer = []
        for v in reversed(nums):
            answer.append(x ^ mask)
            x ^= v
        return answer

C++

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> getMaximumXor(vector<int>& nums, int maximumBit) {
        int x = 0;
        for (int v : nums) x ^= v;
        int mask = (1 << maximumBit) - 1;
        int n = static_cast<int>(nums.size());
        vector<int> answer(n);
        for (int i = 0; i < n; ++i) {
            answer[i] = x ^ mask;
            x ^= nums[n - 1 - i];
        }
        return answer;
    }
};

替代方案

正向扫描维护前缀异或 p，将 p ^ mask 写入 answer[n - 1 - i]，同样 O(n) 时间、O(1) 额外空间，还能省去初始完整异或的一遍扫描。保存整个前缀异或数组也可行，但会多占 O(n) 空间。枚举所有 k 每轮需要 O(2^b)，没有必要。

常见错误

  • 返回 mask，而非题目要求的 k。
  • 先删除元素再求答案，漏掉完整数组那一轮。
  • 直接使用 ~x，把位宽以外的位也翻转；应使用 x ^ mask 或 (~x) & mask。
  • 按从短到长的前缀顺序输出，未倒序放置答案。
  • 将 2 ^ b 当作乘方；在这些语言中它表示异或。

面试追问

最优 k 唯一吗？唯一。结果必须为 mask，每一位的 k 都被 x 唯一确定。

输入不再有序呢？本方法依然成立，只要仍按数组尾部删除。

改成区间查询呢？静态数组可用前缀异或获得区间 x，再异或 mask；如果还支持点更新，可维护异或树状数组或线段树。

位宽超过 31 呢？JavaScript 需使用 BigInt 的移位和异或，其他语言也应选择足够宽的整数类型，并重新检查移位边界。
