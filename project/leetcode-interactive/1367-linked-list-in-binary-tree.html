二叉树中的链表

一条线性的链表，能否完整藏在树的某条连续向下路径里？先读懂匹配规则，再亲手观察搜索过程。

树深度优先搜索链表二叉树
Problem

题目说明

函数：isSubPath(head, root)

给定一棵以 root 为根的二叉树，以及一个以 head 为首节点的链表。判断树中是否存在一条从任意节点开始、沿父子关系持续向下的路径，使路径上的节点值依次与链表的全部节点值相同。

连续很重要：每匹配一个链表节点，只能移动到当前树节点的左孩子或右孩子；不能跳过树节点，也不能改变方向向上。

约束

  • 二叉树节点数在 [1, 2500] 范围内。
  • 链表节点数在 [1, 100] 范围内。
  • 链表与二叉树中每个节点都满足 1 <= Node.val <= 100。

Solution

双层 DFS：枚举起点 + 向下匹配

核心洞察

问题同时包含两个搜索维度：路径可以从树中任意节点开始；一旦选定起点，后续每一步只能进入左孩子或右孩子。因此用外层 DFS 枚举起点，用内层 DFS 校验从当前节点出发是否能匹配链表剩余部分。

状态定义

match(listNode, treeNode) 表示：链表从 listNode 开始的后缀，能否与树从 treeNode 开始的某条向下路径完全对应。

完整过程

  1. 外层函数访问当前树节点，把它当作一个候选起点，调用内层匹配。
  2. 内层先判断链表是否已经走完；若是，说明全部值均已匹配，返回 true。
  3. 若树节点为空，或当前两个节点的值不同，当前分支立即返回 false。
  4. 当前值相同后，链表前进一步，树选择左孩子或右孩子；任一方向成功即可。
  5. 若当前起点失败，外层继续在左子树和右子树中寻找新的起点。

正确性证明

引理：match(p, t) 返回真，当且仅当存在一条从 t 开始的向下路径，其值序列等于从 p 开始的链表后缀。证明可对链表剩余长度归纳：剩余长度为 0 时直接成立；否则首值必须相等，随后合法路径的下一点必为左或右孩子，递归的“或”恰好覆盖全部可能。

定理：外层 DFS 访问二叉树的每个节点，并以每个节点调用上述完备且可靠的 match。所以只要任一合法起点存在就会返回真；若返回真，也必由引理对应一条合法向下路径。算法正确。

时间复杂度O(n · min(m, h))

最坏情况下，对树的每个节点尝试最多 min(m, h) 层匹配；常写作 O(nm)。

空间复杂度O(h + m)

递归栈来自枚举树的高度与匹配深度；最坏树高可达 n。

边界情况

  • 链表只有一个节点：只需树中出现相同值。
  • 树退化成链：匹配过程仍然成立。
  • 值大量重复：会触发更多候选尝试，是朴素 DFS 的最坏场景。
  • 匹配到链表末尾时，应优先返回真，即使树节点此刻为空。

替代方案：KMP + 树 DFS

把链表值当作模式串，构建前缀函数。在遍历树路径时维护当前已匹配长度，失配后利用前缀函数回退。它能将时间优化到 O(n + m)，但实现与证明更复杂；在本题规模下，双层 DFS 更直观。

Implementation

四语言完整代码

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 * }
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    public boolean isSubPath(ListNode head, TreeNode root) {
        if (root == null) return false;
        return match(head, root)
            || isSubPath(head, root.left)
            || isSubPath(head, root.right);
    }

    private boolean match(ListNode list, TreeNode tree) {
        if (list == null) return true;
        if (tree == null || list.val != tree.val) return false;
        return match(list.next, tree.left)
            || match(list.next, tree.right);
    }
}
/**
 * @param {ListNode} head
 * @param {TreeNode} root
 * @return {boolean}
 */
var isSubPath = function(head, root) {
    const match = (list, tree) => {
        if (list === null) return true;
        if (tree === null || list.val !== tree.val) return false;
        return match(list.next, tree.left)
            || match(list.next, tree.right);
    };

    if (root === null) return false;
    return match(head, root)
        || isSubPath(head, root.left)
        || isSubPath(head, root.right);
};
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def isSubPath(self, head: Optional[ListNode],
                  root: Optional[TreeNode]) -> bool:
        def match(node: Optional[ListNode],
                  tree: Optional[TreeNode]) -> bool:
            if node is None:
                return True
            if tree is None or node.val != tree.val:
                return False
            return (match(node.next, tree.left)
                    or match(node.next, tree.right))

        if root is None:
            return False
        return (match(head, root)
                or self.isSubPath(head, root.left)
                or self.isSubPath(head, root.right))
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 * };
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class Solution {
    bool match(ListNode* list, TreeNode* tree) {
        if (list == nullptr) return true;
        if (tree == nullptr || list->val != tree->val) return false;
        return match(list->next, tree->left)
            || match(list->next, tree->right);
    }

public:
    bool isSubPath(ListNode* head, TreeNode* root) {
        if (root == nullptr) return false;
        return match(head, root)
            || isSubPath(head, root->left)
            || isSubPath(head, root->right);
    }
};

Deep dive

面试追问与常见错误

为什么不能只从根节点开始匹配？

题目允许路径从树中任意节点开始。只检查根节点会漏掉所有位于子树内部的合法起点，所以需要外层遍历。

为什么链表为空的判断要放在树为空之前？

当最后一个链表节点刚刚匹配成功后，下一次递归中的链表已经为空，此时完整匹配已经完成；即使对应树孩子为空，也应返回真。

常见错误有哪些？

把“向下路径”误写成只能走左边或只能走右边；匹配中途重新从链表头开始；失配时在内层跨节点寻找；以及漏掉当前节点作为候选起点。

如何应对大量重复值造成的退化？

可采用 KMP 前缀函数，把当前根到节点的值序列视为文本流，在树 DFS 中维护模式匹配长度，从而避免反复从链表头比较。
