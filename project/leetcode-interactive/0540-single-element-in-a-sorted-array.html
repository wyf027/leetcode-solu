单一元素

一对一对的元素排着整齐队伍，只有一个数打乱了配对节奏。先观察规律，再决定是否揭开二分答案。

MEDIUM数组二分查找O(log n)非付费题

题目描述

给定一个只包含整数的非递减有序数组 nums。除了某个元素只出现一次外，其余每个元素都恰好出现两次。返回这个唯一只出现一次的元素。

函数形式：singleNonDuplicate(nums: integer[]) → integer
要求时间复杂度为 O(log n)，额外空间为 O(1)。
官方示例 1输入：nums = [1,1,2,3,3,4,4,8,8] 输出：2
官方示例 2输入：nums = [3,3,7,7,10,11,11] 输出：10

约束与观察

  • 1 ≤ nums.length ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁵
  • 数组有序；仅一个值出现一次，其他值均出现两次。
  • 合法输入的长度必为奇数。

线性异或能找到答案，但不能满足题目刻意要求的 O(log n) 时间。下面的交互区会展示“配对索引规律”如何缩小搜索区间。

完整解析

从索引奇偶性找到断点

核心洞察：唯一元素之前，每一对从偶数索引开始；唯一元素之后，配对整体错位，改为从奇数索引开始。这个规律在答案处发生一次单调转折，因此可以二分。

  1. 维护闭区间。令 left = 0、right = n - 1，答案始终在其中。
  2. 把中点对齐到偶数索引。计算中点后，若它是奇数就减一。于是只需比较 nums[mid] 和 nums[mid + 1]。
  3. 完整配对则越过。若二者相等，说明到 mid + 1 为止仍保持正常配对，唯一元素必在右边，令 left = mid + 2。
  4. 配对破裂则保留左侧。若二者不等，唯一元素在 mid 或更左，令 right = mid。
  5. 边界相遇。循环结束时 left == right，该位置就是唯一元素。

正确性说明

不变量：每轮开始时，唯一元素位于闭区间 [left, right]。

将 mid 调为偶数后：若 nums[mid] == nums[mid+1]，这两个位置组成正常的一对，且其左侧包含偶数个已配对元素，因此可安全删除到 mid+1；否则正常配对已在 mid 之前或此处中断，答案必在 [left, mid]。两种更新都保留不变量并严格缩短区间。最终区间只剩一个位置，它必为答案。

复杂度与边界

时间O(log n)每轮约减半
空间O(1)仅常数变量
  • 长度为 1：循环不进入，直接返回首元素。
  • 答案在开头或结尾：闭区间更新仍然有效。
  • mid 为偶数且 left < right，所以访问 mid + 1 安全。

四种语言实现

Java · 官方可提交
class Solution {
    public int singleNonDuplicate(int[] nums) {
        int left = 0, right = nums.length - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if ((mid & 1) == 1) mid--;
            if (nums[mid] == nums[mid + 1]) {
                left = mid + 2;
            } else {
                right = mid;
            }
        }
        return nums[left];
    }
}

var singleNonDuplicate = function(nums) {
    let left = 0;
    let right = nums.length - 1;
    while (left < right) {
        let mid = left + Math.floor((right - left) / 2);
        if (mid % 2 === 1) mid--;
        if (nums[mid] === nums[mid + 1]) {
            left = mid + 2;
        } else {
            right = mid;
        }
    }
    return nums[left];
};

from typing import List

class Solution:
    def singleNonDuplicate(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        while left < right:
            mid = left + (right - left) // 2
            if mid % 2 == 1:
                mid -= 1
            if nums[mid] == nums[mid + 1]:
                left = mid + 2
            else:
                right = mid
        return nums[left]

public:
    int singleNonDuplicate(vector<int>& nums) {
        int left = 0, right = static_cast<int>(nums.size()) - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;

替代方案

全数组异或

利用 x ^ x = 0，实现简单、空间 O(1)，但时间为 O(n)，不符合本题目标。

相邻线性扫描

每次跨两格检查一对，直观但最坏 O(n)。哈希计数还会额外使用 O(n) 空间。

面试追问

  • 若每个普通元素出现三次，索引规律该如何重建？
  • 若数组无序，能否同时保持 O(log n) 时间与 O(1) 空间？为什么？
  • 能否用 mid ^ 1 找到配对索引？如何证明？
  • 若有多个单一元素，当前单调性是否仍成立？

常见错误

  • 直接比较 mid - 1 和 mid + 1，却没处理数组边界。
  • 中点未对齐偶数索引，导致“正常配对”的判断方向反转。
  • 配对完整时只写 left = mid + 1，未跳过整对，可能破坏边界奇偶结构。
  • 使用 while (left <= right) 后无条件访问 mid + 1，造成越界。
  • 宣称异或是 O(log n)；它必须读取全部元素，实际为 O(n)。
