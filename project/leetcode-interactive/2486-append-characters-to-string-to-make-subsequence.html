01 / 题目与示例

给定仅含小写英文字母的字符串 s 和 t。你可以在 s 的末尾追加字符，返回使 t 成为新字符串子序列所需的最少追加数量。子序列允许跳过字符，但保留字符的相对顺序；它不要求连续。

参数：appendCharacters(s: string, t: string) → integer

示例 1

输入：s = "coaching", t = "coding"
输出：4

追加 "ding" 后得到 "coachingding"，可以依次选出 "coding"。追加 3 个字符无法做到。

示例 2

输入：s = "abcde", t = "a"
输出：0

"a" 已经是原字符串的子序列，无需追加。

示例 3

输入：s = "z", t = "abcde"
输出：5

追加 "abcde" 得到 "zabcde"；追加 4 个字符无法满足要求。

约束

  • 1 ≤ s.length, t.length ≤ 105
  • s 和 t 仅含小写英文字母。

04 / 独立题解

准备好后再展开思路与四语言代码。

核心洞察：保留最长可匹配前缀

追加的位置都在原串之后，因此原串能贡献的只能是 t 的一个前缀。设这个最长前缀长度为 j，剩余后缀 t[j:] 必须在末尾补上，答案是 t.length - j。

完整过程

  1. 令 j = 0，表示尚未匹配任何目标字符。
  2. 从左到右扫描 s。当 s[i] == t[j] 时，令 j++；否则只跳过当前原串字符。
  3. 若 j == t.length，目标已完全匹配，可以提前结束。
  4. 返回 t.length - j，不必真的构造追加后的字符串。

示例 1 中，c 和 o 使 j 从 0 变为 2；之后等待 d，原串剩余的 aching 都不能推进目标。虽然其中有 i、n、g，它们也不能越过尚未匹配的 d。最后补上 ding，答案为 4。

正确性证明

不变式：扫描完 s 的前 i 个字符后，j 是可以在这些字符中匹配出的最长目标前缀长度。初始空前缀显然满足。若新字符等于 t[j]，可以将前缀扩展一位，一个新字符最多贡献一位，因此 j+1 最优；若不相等，新字符无法扩展当前最长前缀，j 保持最优。不变式由归纳成立。

最少性：任何最终匹配中，来自原串的部分都位于追加部分之前，故它对应目标前缀，长度最多为 j，至少还需追加 |t|-j 个字符。直接追加后缀 t[j:] 达到这个下界，所以答案最优。

边界与复杂度

  • 目标已为子序列：j 到达目标长度，答案 0，必须避免继续访问 t[j]。
  • 首字符始终无法匹配：j 为 0，整个目标都要追加。
  • 重复字符：每次比较最多消费一个目标字符，不能重复使用原串的同一位置。
  • 空串不在题目输入范围内；四份实现也能处理空串这一自然扩展。
  • 设 n = |s|，m = |t|。时间 O(n)，额外空间 O(1)；无需扫描或创建完整的目标后缀。可视化为回退保留历史，其空间开销不属于提交算法。

替代方案

动态规划可计算每个原串前缀能否匹配各目标前缀，耗时 O(nm)、滚动空间 O(m)，本题无需如此处理。若同一 s 有大量目标查询，可预处理字符位置列表，再用二分查找下一个位置；预处理 O(n)，每个目标约 O(m log n)，额外空间 O(n)。

常见错误

  • 把子序列当子串，要求匹配连续。
  • 统计字符频次或排序，丢失顺序信息。
  • 用最长公共子序列长度直接做减法。例 s="bc", t="abc" 的 LCS 长度是 2，但只能在末尾添加，答案是 3。
  • 不匹配时同时移动目标指针，漏掉必须补上的字符。
  • 返回原串剩余长度，而不是目标剩余长度。

面试追问

  • 为什么尽早匹配？尽早占用相同字符给后续目标留下最多可用位置，不会减少后续可行匹配。
  • 如何返回追加内容？返回 t[j:]，构造它需要 O(m-j) 时间和输出空间。
  • 允许任意位置插入呢？此时可以保留任意公共子序列，最少插入数量变为 m - LCS(s,t)。
  • s 是数据流呢？只保存目标和指针 j，逐字符消费 s，不需要回看原串。

Java

class Solution {
    public int appendCharacters(String s, String t) {
        int j = 0;
        for (int i = 0; i < s.length() && j < t.length(); i++) {
            if (s.charAt(i) == t.charAt(j)) j++;
        }
        return t.length() - j;
    }
}

    }

};

Python 3

class Solution:
    def appendCharacters(self, s: str, t: str) -> int:
        j = 0
        for char in s:
            if j == len(t):
                break
            if char == t[j]:
                j += 1
        return len(t) - j

C++

#include <string>
using namespace std;

class Solution {
public:
    int appendCharacters(string s, string t) {
        int j = 0;
        for (int i = 0; i < (int)s.size() && j < (int)t.size(); ++i) {
            if (s[i] == t[j]) ++j;
        }
        return (int)t.size() - j;
    }
};
