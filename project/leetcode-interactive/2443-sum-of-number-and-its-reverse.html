反转之后的数字和

Sum of Number and Its Reverse

数字读过来、倒过去，再相加。一个目标值，是否藏着这样的数字搭档？

官方题目 ↗

01 / 题目

给定非负整数 num，判断是否存在非负整数 k，使 k + reverse(k) = num。存在时返回 true，否则返回 false。reverse(k) 将十进制数位顺序反转，并按整数解释结果；因此反转产生的前导零不影响数值。

参数：num: integer　返回：boolean

约束：0 ≤ num ≤ 10⁵

02 / 官方示例

示例 1

输入：num = 443
输出：true

172 + 271 = 443，存在符合条件的数字。

示例 2

输入：num = 63
输出：false

没有非负整数与其反转数之和等于 63。

示例 3

输入：num = 181
输出：true

140 + 041 = 181，其中 041 的数值为 41。

05 / 题解 · 有界枚举与数位反转

核心洞察

反转数非负，所以任何可行的 k 都满足 0 ≤ k ≤ num。目标上限只有 100000，逐个检查这个闭区间即可，无需构造复杂的数位搜索。

  1. 从 k = 0 开始枚举，保留原始候选值。
  2. 用副本 x = k 取末位：digit = x % 10。
  3. 将末位接到结果右边：rev = rev * 10 + digit，然后令 x = floor(x / 10)，直到 x 为零。
  4. 若 k + rev == num，立即返回 true；所有候选都失败后返回 false。

正确性证明

反转不变式：每轮结束时，rev 恰好由已经从 k 末尾取出的数位按取出顺序组成；x 保存尚未处理的高位。乘十再加末位维持此不变式。循环结束时所有数位处理完毕，rev 即反转后的整数；k = 0 时 rev 初始为 0，也正确。

可靠性：只在 k + rev 等于目标时返回 true，返回时一定有合法见证。

完备性：任意合法见证 k 均位于 [0, num]，枚举必然访问它。因此枚举完仍未命中时，不存在解，返回 false 正确。内层每次去掉一位，外层至多 num + 1 次，算法必然结束。

边界与复杂度

  • num = 0：必须枚举零；0 + 0 = 0。
  • 末尾零：140 反转为数位 041，按整数取 41；不能把它当作 410。
  • 奇数也可能有解：181 = 140 + 41，不能仅按奇偶排除。
  • 上界 100000 无解：一至四位 k 的和不超过 19998；五位 k 的首尾数位之和若令个位为零，只可能为 10，产生进位 1，但万位又要求首尾之和加进位等于 10，迫使该列进位为零。十位产生的进位会经百位（2 倍中位数加 1 必须为 10）形成矛盾；唯一六位候选 100000 的和为 100001。
  • 令 N = num，每个候选至多 O(log(N + 1) + 1) 位。时间为 O((N + 1)(log(N + 1) + 1))，通常简写为 O(N log N)；四份算术实现的额外空间为 O(1)。可视化数位轨迹额外保存 O(log(N + 1) + 1) 行，不属于提交代码。
  • 此约束下使用 32 位整数足够，JavaScript 的整数运算也在安全精度范围内。

替代方案与面试追问

字符串反转：把 k 转为字符串、倒序、转回整数，逻辑直接，但每轮额外需要 O(log N) 空间。不要使用会保留字符串类型的反转结果参与加法。

更大约束：可从加法两端的数位约束及进位状态构造数位搜索；要处理位数不同和前导零，复杂度与证明更繁琐。本题无需使用。

追问：多次查询怎么办？在固定上界内预枚举 k，把不超过上界的 k + reverse(k) 标记在布尔数组中，预处理 O(M log M)，每次查询 O(1)，额外空间 O(M)。求所有见证时不要提前返回；若只要最小见证，递增枚举第一次命中即可。

常见错误

  • 从 1 开始或用 k < num，遗漏零边界。
  • 直接消耗 k 做除法，导致比较时原候选丢失；应使用副本 x。
  • 每个候选没有重新将 rev 置零。
  • 反转时忘记乘 10，或者在 JavaScript 中使用普通除法却不取整。
  • 假设候选之和单调，错误地用二分搜索：例如 19 + 91 = 110，而 20 + 2 = 22，反而下降。

四语言完整提交代码

Java

class Solution {
    public boolean sumOfNumberAndReverse(int num) {
        for (int k = 0; k <= num; k++) {
            int x = k, rev = 0;
            while (x > 0) {
                rev = rev * 10 + x % 10;
                x /= 10;
            }
            if (k + rev == num) return true;
        }
        return false;
    }
}
