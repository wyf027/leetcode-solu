行和列中一和零的差值

Difference Between Ones and Zeros in Row and Column

同一格子，连接一整行和一整列。请根据这两条线中 1 与 0 的数量，为每个位置计算一个差值。

先阅读题目并自行思考；算法演示和四语言实现收纳在页面底部。

01 / PROBLEM

题目与约束

给定下标从 0 开始的 m × n 二进制矩阵 grid。返回同样大小的矩阵 diff。对于位置 (i, j)，分别统计第 i 行、第 j 列中 1 和 0 的数量，然后按以下定义计算：

diff[i][j] = onesRow[i] + onesCol[j]
           - zerosRow[i] - zerosCol[j]

其中 onesRow[i]、zerosRow[i] 是第 i 行的 1、0 数量；onesCol[j]、zerosCol[j] 是第 j 列的 1、0 数量。行与列分别计数，交叉格同时属于两者。

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 10⁵
  • 1 ≤ m × n ≤ 10⁵
  • grid[i][j] 只能是 0 或 1。

参数：grid: integer[][] · 返回：integer[][] · 官方方法名：onesMinusZeros

02 / EXAMPLES

官方示例

示例 1 · 混合矩阵

输入：grid = [[0,1,1],[1,0,1],[0,0,1]]
输出：[[0,0,4],[0,0,4],[-2,-2,2]]

例如位置 (0, 2)：第 0 行有 2 个 1、1 个 0；第 2 列有 3 个 1、0 个 0，所以差值是 2 + 3 − 1 − 0 = 4。位置 (2, 0) 得到 1 + 1 − 2 − 2 = −2。

示例 2 · 全部为 1

输入：grid = [[1,1,1],[1,1,1]]
输出：[[5,5,5],[5,5,5]]

每一行有 3 个 1，每一列有 2 个 1，没有 0，因此所有位置的差值都是 3 + 2 − 0 − 0 = 5。

04 / SOLUTION

展开后查看行列计数实验、推导与可提交代码。

题解 · 两次遍历，复用行列统计

核心洞察

一行共有 n 格，因此零的个数是 n − onesRow[i]；一列共有 m 格，因此零的个数是 m − onesCol[j]。只需要记录每一行和每一列的 1 的数量。

diff[i][j]
= onesRow[i] + onesCol[j] − (n − onesRow[i]) − (m − onesCol[j])
= 2 × (onesRow[i] + onesCol[j]) − m − n

完整过程

  1. 分配长度为 m 的行计数数组 row、长度为 n 的列计数数组 col，初始均为 0。
  2. 第一次按行扫描 grid；读到 grid[i][j]，分别加到 row[i] 和 col[j]。
  3. 全部统计完成后，再遍历每个位置，用 2 * (row[i] + col[j]) - m - n 填入结果。
  4. 返回新的差值矩阵，不修改输入。

行列交叉计数实验

先统计 → 再合成

第一阶段逐格向行、列计数器各投一票；第二阶段突出当前行与列，把两份计数合成输出。交叉点计入两次是题目定义。

演示限制为 1～6 行、1～6 列且每行等长，只接受数字 0 或 1；四语言算法支持完整题目规模。

Tab 切换控件，Enter / 空格激活按钮；减少动态效果偏好下自动播放改为较慢节奏，无过渡动画。

绿色边框：当前行；橙色边框：当前列；深绿格：本步位置（同时标注坐标）。此处是算法演示，非测试执行记录。

正确性证明

统计不变式：第一次遍历任意前缀后，row[i] 等于该前缀中第 i 行的 1 的总数，col[j] 等于其中第 j 列的 1 的总数。初始前缀为空时都为 0；每读一格，将它的值加到对应行、列，所以不变式保持。遍历结束时，两个数组就是完整的行列 1 计数。

结果等价：二进制矩阵的每行恰有 n 格、每列恰有 m 格，所以零计数分别为 n − row[i] 与 m − col[j]。代回题目定义，得到实现使用的表达式。第二遍为每个位置写入这个值，因此整个返回矩阵正确。

边界与复杂度

  • 单格输入：[[1]] → [[2]]，[[0]] → [[-2]]。不要去除行列交叉点的重复贡献。
  • 全 1 时输出为 m + n，全 0 时输出为 −(m + n)；负数是有效结果。
  • 单行、单列、非方阵都用同一公式。行长度是 n，列长度是 m。
  • 时间复杂度 O(mn)：两次完整遍历；显式输出 mn 个值也需要 Ω(mn) 时间。
  • 辅助空间 O(m + n)；返回矩阵占 O(mn)，计入返回值后的总额外空间为 O(mn + m + n)。
  • 保守范围为 [−(m+n), m+n]，在给定约束下 32 位有符号整数足够。

替代方案

  • 逐格重数：每个输出位置扫描其行列，时间 O(mn(m+n))，辅助空间 O(1)，但重复工作多。
  • 直接统计差值：把 1 视为 +1、0 视为 −1，累计行差和列差，最终输出两者之和。时间、空间同主方案。
  • 复用输入：先完成所有行列统计，再覆盖 grid。可省独立结果矩阵，但会修改输入；不可一边统计一边覆盖。

常见错误

  • 为交叉格“去重”：行和列是分别统计的，交叉格应贡献两次。
  • 把 n − row[i] 写成 m − row[i]：方阵样例可能掩盖这一问题。
  • 计数尚未完成就计算结果：后面的格子仍可能改变当前行列总数。
  • JavaScript 用 Array(m).fill(Array(n).fill(0)) 创建结果：各行共享同一数组；用 Array.from 创建独立行。

面试追问

翻转一个格子会怎样？若从 0 变为 1，该行及该列的差值分别增加 2，因此这行或这列的输出增加 2，交叉位置增加 4；反向翻转符号相反。维护行列统计可在 O(1) 时间更新计数和查询一个位置；重新输出全部矩阵仍需 O(mn)。

能只用一个 O(m+n) 大小的数据结构返回吗？可以用行列差值隐式表达，但本题要求实体二维数组，不能以隐式表示替代返回契约。

四语言实现

以下使用官方方法名与参数形式。均为完整提交实现；快速生成模式下尚未编译或运行。

Java

class Solution {
    public int[][] onesMinusZeros(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] row = new int[m], col = new int[n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                row[i] += grid[i][j];
                col[j] += grid[i][j];
            }
        }
        int[][] diff = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                diff[i][j] = 2 * (row[i] + col[j]) - m - n;
            }
        }
        return diff;
    }
}

JavaScript

/**
 * @param {number[][]} grid
 * @return {number[][]}
 */
var onesMinusZeros = function(grid) {
    const m = grid.length, n = grid[0].length;
    const row = Array(m).fill(0), col = Array(n).fill(0);
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            row[i] += grid[i][j];
            col[j] += grid[i][j];
        }
    }
    return Array.from({ length: m }, (_, i) =>
        Array.from({ length: n }, (_, j) =>
            2 * (row[i] + col[j]) - m - n
        )
    );
};

Python 3

from typing import List

class Solution:
    def onesMinusZeros(self, grid: List[List[int]]) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        row, col = [0] * m, [0] * n
        for i in range(m):
            for j in range(n):
                row[i] += grid[i][j]
                col[j] += grid[i][j]
        return [
            [2 * (row[i] + col[j]) - m - n for j in range(n)]
            for i in range(m)
        ]
