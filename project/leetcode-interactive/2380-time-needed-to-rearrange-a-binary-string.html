二进制字符串重新安排
顺序需要的时间

Time Needed to Rearrange a Binary String

一秒，一次同步交换。先观察每个 1 如何向左移动，再寻找规律。

01 / 理解规则

同一秒，所有 01 一起变成 10

给定只含 0 和 1 的字符串 s。每一秒，找出这一秒开始时所有相邻的 01，同时交换为 10；不断重复，直到字符串里不再存在 01。返回总共经过的秒数，类型为整数。

“同时”是关键：这一秒交换后新形成的 01，只能等下一秒再交换。比如 001 → 010 → 100 需要两秒。

官方示例 1

输入：s = "0110101"
输出：4

每秒结束时依次为 1011010、1101100、1110100、1111000。第 4 秒后停止。

官方示例 2

输入：s = "11100"
输出：0

初始字符串已经没有 01，无需执行交换。

约束：1 ≤ s.length ≤ 1000；每个 s[i] 都是 '0' 或 '1'。进阶：能否用 O(n) 时间求解？

用两个整数，代替逐秒交换


核心洞察
从左往右扫描。zeros 统计已经遇到的零，time 表示已扫描前缀稳定所需的时间。一个 1 必须越过它前面的所有零，但也可能被前面的 1 阻挡。


读到 0：zeros += 1。
读到 1 且 zeros > 0：time = max(time + 1, zeros)。
前面没有零的 1 不需要移动，跳过。最终返回 time。


完整扫描过程：s = "0110101"


索引字符zerostime原因


0010记录一个零
1111max(0 + 1, 1)
2112max(1 + 1, 1)，跟随前一个 1
3022记录第二个零
4123max(2 + 1, 2)
5033记录第三个零
6134max(3 + 1, 3)




为什么公式正确？


  1. 顺序不变：交换只发生在 0 和 1 之间，所有 1 的相对次序保持不变。右侧追加字符不会影响前缀中已有 1 的左移过程。
  2. 路程下界：当前 1 左侧有 z 个零，必须左移 z 次，每秒最多移动一格，所以完成时间至少为 z。
  3. 排队下界：若前一个需要移动的 1 在第 t 秒归位，当前 1 的最终位置紧随它。该位置在第 t 秒开始时仍被占据，当前 1 最早第 t + 1 秒归位。若没有前一个移动的 1，令 t = 0；因为 z ≥ 1，这个额外下界不影响结果。
  4. 下界可达：考虑当前 1 的第 j 次左移。若前一个 1 左侧有 p 个零，则当前 1 可先穿过两者之间的 z − p 个零；之后的第 j 次左移，只需等待自身第 j − 1 次移动和前一个 1 对应的第 j − (z − p) 次移动各结束一秒。同步交换在这两个条件一满足就发生，不存在其他阻挡。沿移动次数归纳，其最后一步完成时间恰好为 max(z, t + 1)。没有前一个移动的 1 时，可连续移动 z 秒。
  5. 扫描不变式：全零前缀的 time = 0。追加 0 不改变已有 1 的完成时间；追加无需移动的 1 也不改变时间；其余 1 按上述公式更新，且完成时间严格晚于前一个移动的 1。因此扫描结束时，time 就是整个字符串停止变化的时间。




边界与复杂度
  • 单字符、全零、全一以及形如 111000 的字符串：返回 0。
  • 前导 1 不参与移动，尾随 0 不增加答案。
  • 0001 需要 3 秒；0111 也需要 3 秒，分别体现路程与排队。
  • 时间 O(n)：每个字符只处理一次。
  • 额外空间 O(1)：仅两个计数器；不修改输入。


替代方案：忠实模拟
每轮读取旧字符串，复制为新数组，把旧字符串里全部 01 改成 10；无交换时停止。也可以原地扫描，但交换后必须跨过这两个位置，避免同一秒再次移动同一个字符。
最多 O(n) 轮，每轮 O(n)，时间 O(n²)，只保留当前轮时额外空间 O(n)。实验台用此方案记录历史，因此历史空间最坏 O(n²)，用于回退观察，不是提交解法。




常见错误
  • 把所有逆序的 0、1 对数当成秒数：它是交换总次数，多次交换可以并行。
  • 只返回零的个数：0111 只有一个零，却需要 3 秒。
  • 遗漏 zeros > 0：会把开头无需移动的 1 也计时。
  • 见到 0 就把 time 清零：前面 1 的排队信息必须保留。
  • 模拟时使用本轮刚改过的结果继续交换：把同步更新误写成连续更新。


面试追问
  • 能流式处理吗？能。只需保留 zeros 和 time，无须存储完整字符串。
  • 最多需要几秒？长度 n 的答案不超过 n − 1；0…01…1 且两类字符都存在时可达到 n − 1。
  • 交换总次数如何计算？每遇到一个 1，累加此前零的数量；这是另一种计数，不是本题时间。
  • 想输出每秒字符串呢？需要模拟或重建状态，输出本身最坏已有 O(n²) 个字符。

Java
class Solution {
    public int secondsToRemoveOccurrences(String s) {
        int zeros = 0, time = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '0') {
                zeros++;
            } else if (zeros > 0) {
                time = Math.max(time + 1, zeros);
            }
        }
        return time;
    }
}
