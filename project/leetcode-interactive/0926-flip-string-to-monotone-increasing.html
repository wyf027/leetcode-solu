926. 将字符串翻转到单调递增

Flip String to Monotone Increasing · 用一次线性扫描理解“已经看到的 1”和“当前最少翻转”。

Problem

题目

若一个二进制字符串由若干个 0（可以没有）后接若干个 1（也可以没有）组成，就称它单调递增。给定二进制字符串 s，每次可以把任意一位从 0 翻成 1，或从 1 翻成 0。返回使 s 单调递增所需的最少翻转次数。

示例 1 输入：s = "00110" 输出：1 解释：翻转最后一位，得到 "00111"。
示例 2 输入：s = "010110" 输出：2 解释：可得到 "011111"，也可得到 "000111"。
示例 3 输入：s = "00011000" 输出：2 解释：可翻转两个 1，得到 "00000000"。

约束

  • 1 <= s.length <= 105
  • s[i] 只能是 '0' 或 '1'

Solution

贪心动态规划：保留前缀最优解

核心洞察

从左向右处理。维护 ones：前缀中原本出现的 1 的数量；维护 flips：把当前前缀变成单调递增的最少翻转数。

遇到 1 不会破坏单调性，只增加 ones。遇到 0 时有两种选择：把当前 0 翻成 1，代价为 flips + 1；或者把此前所有 1 翻成 0，代价为 ones。取二者较小值。

状态转移

若 c == '1': ones += 1
若 c == '0': flips = min(flips + 1, ones)

这实际上是压缩到两个变量的一维动态规划。

完整过程

  1. 初始化 ones = 0、flips = 0。
  2. 依次读取字符串中的每个字符。
  3. 字符为 1 时累计 ones。
  4. 字符为 0 时比较“翻当前 0”和“翻之前全部 1”的代价。
  5. 扫描结束后，flips 即整个字符串的最优答案。

正确性证明

用归纳法。处理空前缀时，flips = 0 显然最优。假设处理前 i 个字符后 flips 是该前缀的最少翻转数。第 i+1 位若为 1，把它接在任意单调前缀末尾仍单调，最优值不变；若为 0，任何合法结果只能属于两类：将当前 0 翻为 1（最优代价 flips + 1），或保留当前 0，此时它之前不能留下 1，必须翻转前缀中全部 ones 个 1。转移取两类的较小值，覆盖所有可能且各自代价最优。因此归纳成立，最终答案正确。

复杂度

时间 O(n)；额外空间 O(1)。

边界

全 0、全 1、单字符已单调，答案均为 0；交替串由同一转移自然处理；长度 105 只需一次扫描。

替代方案：枚举分界线

枚举 0/1 分界位置，统计左侧需要翻成 0 的 1 和右侧需要翻成 1 的 0。借助前缀和也能做到 O(n) 时间，但要使用 O(n) 空间；滚动统计可以压到 O(1)，本质与当前方法相通。

面试追问

  • 如何输出一种翻转后的具体字符串？记录最佳分界点，再重建结果。
  • 若 0→1 与 1→0 的成本不同？把两类操作替换成加权成本。
  • 为何局部取最小不会后悔？因为状态保存的是每个前缀的全局最优，而非只看相邻字符。

常见错误

  • 见到 10 就直接翻一位，忽略后续整体代价。
  • 更新 0 时只做 flips++，漏掉“翻掉之前全部 1”。
  • 误把单调递增理解为必须同时包含 0 和 1。
  • 建立完整 DP 数组，造成不必要的空间占用。

四种语言完整代码

Java

class Solution {
    public int minFlipsMonoIncr(String s) {
        int ones = 0;
        int flips = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '1') {
                ones++;
            } else {
                flips = Math.min(flips + 1, ones);
            }
        }
        return flips;
    }
}
