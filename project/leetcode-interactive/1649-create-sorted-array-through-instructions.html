Create Sorted Array through Instructions — 每次插入都在“严格更小”和“严格更大”之间选择较低代价。

HARD树状数组有序集合分治非付费题

Problem

题意

给定整数数组 instructions，从左到右把每个值插入一个初始为空的有序容器 nums。插入 instructions[i] 时，代价等于当前容器中严格小于它的元素数量与严格大于它的元素数量的较小值。

返回完成全部插入的总代价，并对 10^9 + 7 取余。与当前值相等的元素不会计入任意一侧。

函数签名： createSortedArray(instructions: integer[]) → integer

输入instructions = [1,5,6,2]
输出1

示例 2

输入instructions = [1,2,3,6,5,4]
输出3

示例 3

输入instructions = [1,3,3,3,2,4,2,1,2]
输出4

各步代价为 0、0、0、0、1、0、1、0、2；重复值均被排除在严格比较之外。

约束

  • 1 <= instructions.length <= 10^5
  • 1 <= instructions[i] <= 10^5

Solution

核心洞察：动态前缀频次

1

把值当作下标

值域最多为 105，可以让树状数组的第 x 位记录值 x 出现的次数。

2

两次前缀查询

query(x - 1) 是严格小于；i - query(x) 是严格大于。

3

先查询，再更新

本次元素不能参与自己的代价统计；算完代价后才执行 add(x, 1)。

Algorithm

完整过程

  1. 建立大小覆盖最大指令值的树状数组 bit，初始频次全为 0。
  2. 从左到右处理第 i 个值 x；此时恰好已有 i 个元素被插入。
  3. 查询 less = query(x - 1)，得到已插入元素中严格小于 x 的数量。
  4. 查询 lessOrEqual = query(x)，于是 greater = i - lessOrEqual。
  5. 把 min(less, greater) 加到答案，并对模数取余；随后执行 add(x, 1)。
cost(x) = min(query(x − 1), i − query(x))

Correctness

正确性证明

引理 1：树状数组维护准确频次

每处理一个值 x，算法仅在计算完本次代价后给位置 x 加 1。因此处理第 i 个元素前，树状数组恰好记录前 i 个指令值的出现次数。

引理 2：两侧数量计算准确

由引理 1，query(x − 1) 汇总值域 [1, x − 1]，正是严格小于 x 的数量；query(x) 汇总所有小于等于 x 的元素，所以 i − query(x) 正是严格大于 x 的数量。

定理：算法返回总最小代价

由引理 2，每一步取两侧准确数量的较小值，等于题目定义的该次插入代价。算法逐步累加所有插入代价，因此最终结果就是总最小代价；取模不改变所要求的模意义结果。

Complexity & Edges

复杂度与边界

复杂度

设 n 为数组长度、U 为最大值。每个元素执行常数次树状数组操作，时间 O(n log U)；树状数组占用 O(U) 空间。

重复值

严格小于查询到 x−1，严格大于从总数中减去 query(x)，所以等于 x 的元素自然不计入两边。

单调序列

严格递增时右侧数量恒为 0；严格递减时左侧数量恒为 0，总代价均为 0。

取模时机

每轮累加后立刻取模。JavaScript 使用 Number 仍安全，但持续取模也让四种实现保持一致。

Code

四种语言完整实现

JavaFenwick Tree
class Solution {
    private int[] bit;

    private void add(int index, int delta) {
        while (index < bit.length) {
            bit[index] += delta;
            index += index & -index;
        }
    }

    private int query(int index) {
        int sum = 0;
        while (index > 0) {
            sum += bit[index];
            index -= index & -index;
        }
        return sum;
    }

    public int createSortedArray(int[] instructions) {
        final int MOD = 1_000_000_007;
        int maxValue = 0;
        for (int x : instructions) maxValue = Math.max(maxValue, x);
        bit = new int[maxValue + 1];
        long answer = 0;

        for (int i = 0; i < instructions.length; i++) {
            int x = instructions[i];
            int less = query(x - 1);
            int greater = i - query(x);
            answer = (answer + Math.min(less, greater)) % MOD;
            add(x, 1);
        }
        return (int) answer;
    }
}

from typing import List


class Solution:
    def createSortedArray(self, instructions: List[int]) -> int:
        MOD = 10**9 + 7
        max_value = max(instructions)
        bit = [0] * (max_value + 1)

        def add(index: int, delta: int) -> None:
            while index < len(bit):
                bit[index] += delta
                index += index & -index

        def query(index: int) -> int:
            total = 0
            while index > 0:
                total += bit[index]
                index -= index & -index
            return total

        answer = 0
        for i, x in enumerate(instructions):
            less = query(x - 1)
            greater = i - query(x)
            answer = (answer + min(less, greater)) % MOD
            add(x, 1)

        return answer

class Solution {
public:
    int createSortedArray(vector<int>& instructions) {
        static constexpr int MOD = 1'000'000'007;
        int maxValue = *max_element(instructions.begin(), instructions.end());
        vector<int> bit(maxValue + 1);

        auto add = [&](int index, int delta) {
            while (index < static_cast<int>(bit.size())) {
                bit[index] += delta;
                index += index & -index;
            }
        };

        auto query = [&](int index) {
            int sum = 0;
            while (index > 0) {
                sum += bit[index];
                index -= index & -index;
            }
            return sum;
        };

        long long answer = 0;
        for (int i = 0; i < static_cast<int>(instructions.size()); ++i) {
            int x = instructions[i];
            int less = query(x - 1);
            int greater = i - query(x);
            answer = (answer + min(less, greater)) % MOD;
            add(x, 1);
        }
        return static_cast<int>(answer);
    }
};

Trade-offs

替代方案与面试追问

线段树

同样能完成点更新与区间计数，复杂度也是 O(n log U)，但代码更长、常数通常更大；若题目增加复杂区间操作则更有优势。

带秩平衡树

若值域未知或很大，可用支持 order statistics 的平衡树；必须正确处理重复值。标准 Java/JavaScript 容器并不直接提供该能力。

坐标压缩

如果 instructions[i] 的范围不再受限，先排序去重映射到 1…m，再使用树状数组，时间仍为 O(n log n)。

为何不能直接二分插入？

二分只能 O(log n) 找位置，但数组插入仍需 O(n) 搬移；总时间最坏 O(n²)，无法承受 105 规模。

常见错误

  • 用 query(x) 作为严格小于，错误地把重复值算进去。
  • 用 i - query(x - 1) 作为严格大于，同样会把等于 x 的值算进去。
  • 在查询前更新树状数组，使当前元素参与自己的统计。
  • 树状数组使用 0 下标，导致 index += index & -index 在 0 处无法前进。
  • 只在最终返回时取模，某些语言可能在累计过程中溢出。
