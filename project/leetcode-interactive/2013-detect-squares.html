2013. 检测正方形

Detect Squares · 在点的数据流里，数出每一种选择。

同一个坐标可以拥有多份点。查询点与三个已添加的点，能拼出多少个轴对齐正方形？

设计数据流计数官方题目 ↗

01 / 任务与接口

维护平面上的一个点集合，允许重复添加。每次查询给定坐标，从已经添加的点中选出三个点实例，与查询点共同组成面积大于零、各边平行于坐标轴的正方形，返回选择方案数。重复坐标上的不同实例分别计数；查询操作不会把查询点加入集合，也不要求查询点已经存在。

  • DetectSquares()：初始化空对象。
  • void add(int[] point)：添加 point = [x, y]。
  • int count(int[] point)：查询 point = [x, y] 对应的正方形方案数。

约束

  • point.length == 2。
  • 0 ≤ x, y ≤ 1000，坐标为整数。
  • 官方英文元数据：add 与 count 的总调用次数最多 3000。

元数据版本差异：同一 JSON 中的中文题面写作最多 5000 次。这里保留该差异，以下可提交代码与整数返回范围分析采用英文 3000 次约束。

05 / 题解笔记

先自己思考，再展开原理与完整代码。

核心洞察：一个对角点确定整个正方形

用频次表记录每个不同坐标出现的次数。固定查询点 Q=(x,y)，枚举已存的不同坐标 D=(a,b)。只有 a ≠ x 且 |a−x| = |b−y| 时，D 才能作为正方形的对角点。此时另外两个角必为 A=(a,y)、B=(x,b)。

本次贡献 = freq(a,b) × freq(a,y) × freq(x,b)
答案 = 所有合法对角坐标的贡献之和

查询点由调用方提供，因此不乘 freq(x,y)。若任一所需角不存在，其频次为 0，贡献自然为 0。四个方向都被绝对值条件覆盖。

完整过程

  1. 初始化空频次表。
  2. add 时将指定坐标的频次加一，不存储重复的键。
  3. count 时将答案设为 0，枚举频次表中的每个不同坐标。
  4. 先排除同列点，再排除横纵距离不同的点；同列排除也覆盖零面积情况。
  5. 查询剩余两个角的频次，乘上对角点频次，加入答案。
  6. 返回总和，整个查询不改变频次表。

官方首次查询 Q=(11,10)：D=(3,2) 满足横纵距离都为 8；另外两个角为 (3,10)、(11,2)，贡献为 1×1×1。重复添加 (11,2) 后同一几何形状的贡献变成 1×1×2=2。

正确性论证

合法性：通过筛选的 D 与 Q 横纵距离相等且非零，两补角与它们构成边平行坐标轴的正方形。只有三个位置都有点实例时乘积非零，乘法原理恰好计算独立选取三个实例的方案数。

完整性：任意满足题意的正方形，相对 Q 有且只有一个对角坐标 D；D 一定出现在频次表中且满足筛选条件，因此该方案必被统计。

不重复：频次表对每个对角坐标只枚举一次，而一个方案的对角坐标唯一；同一坐标的不同实例已经在乘积内计数，不再逐实例枚举，所以既不遗漏也不重复。

边界与数值

  • 空集合、缺角、共线点或非正方形长方形均得到 0。
  • 与查询点重合的坐标被跳过，无论它重复多少次；查询点无需被添加。
  • 坐标编码使用 x * 1001 + y；1001 大于 y 的最大值，因此无冲突。仅对符合题目约束的非负整数坐标使用此编码。
  • Java / C++ 使用 64 位中间乘积。按英文最多 3000 次调用，任一查询前添加数 N≤2999，所有三点选择不超过 C(N,3)，更强地，每个正方形分别使用同一列、同一行、其他位置中的一个点，总数不超过 (N/3)³<10⁹，符合官方 int 返回类型。
  • 若采用中文 5000 次并允许极端重复分布，计数可能超过 32 位；扩展接口应返回 64 位整数。以下 Java / C++ 保留官方 int 签名，不承诺该扩展范围。

复杂度

令 U 为已存的不同坐标数，N 为添加次数，U≤N。哈希操作平均 O(1)：add 平均 O(1)，count 平均 O(U)，存储 O(U)，单次查询额外空间 O(1)。这些是哈希表的期望复杂度；极端冲突时哈希性能可能退化。

替代方案

按列保存 x → (y → 频次)，只枚举与查询点同列的其他点；其纵向距离决定边长，分别检查左、右两个正方形。查询可降到平均 O(K)，K 为查询列中不同 y 的数量，但实现比单表更长。固定 1001×1001 频次数组也可用，增加常驻空间以获得直接索引；暴力枚举三点需 O(N³)，只适合作为小数据参考。

常见错误

  • 用 Set 去重，丢失点实例的频次。
  • 对每个重复实例都枚举一次，同时又乘其频次，导致重复计数。
  • 只判断 a−x = b−y，漏掉另一斜率的对角线。
  • 忘记排除零面积，或把查询点的已有频次也乘进去。
  • 只检查补角存在，不乘三个角各自的频次。
  • 查询时用会插入缺省键的 API，改变容器，甚至让迭代失效。

面试追问

支持删除？ 将频次减一，变成零时删除键，并明确不存在点时的行为。查询远多于添加？ 按行或列建立索引，缩小候选范围。允许旋转？ 当前轴对齐条件不再适用，需由向量旋转或对角线中点构造补角，额外处理整数坐标与重复统计。怎样处理无限坐标？ 用坐标对作为键，替换依赖 1000 上界的整数编码。

Java · 官方类接口

import java.util.HashMap;
import java.util.Map;

class DetectSquares {
    private final Map<Integer, Integer> freq = new HashMap<>();

    public DetectSquares() {}

    public void add(int[] point) {
        int key = point[0] * 1001 + point[1];
        freq.merge(key, 1, Integer::sum);
    }

    public int count(int[] point) {
        int x = point[0], y = point[1];
        long answer = 0;
        for (Map.Entry<Integer, Integer> entry : freq.entrySet()) {
            int a = entry.getKey() / 1001;
            int b = entry.getKey() % 1001;
            if (a == x || Math.abs(a - x) != Math.abs(b - y)) continue;
            answer += (long) entry.getValue()
                    * freq.getOrDefault(a * 1001 + y, 0)
                    * freq.getOrDefault(x * 1001 + b, 0);
        }
        return (int) answer;
    }
}

JavaScript · 官方原型接口

var DetectSquares = function() {
    this.freq = new Map();
};

DetectSquares.prototype.add = function(point) {
    const key = point[0] * 1001 + point[1];
    this.freq.set(key, (this.freq.get(key) || 0) + 1);
};

DetectSquares.prototype.count = function(point) {
    const [x, y] = point;
    let answer = 0;
    for (const [key, n] of this.freq) {
        const a = Math.floor(key / 1001), b = key % 1001;
        if (a === x || Math.abs(a - x) !== Math.abs(b - y)) continue;
        answer += n * (this.freq.get(a * 1001 + y) || 0)
                    * (this.freq.get(x * 1001 + b) || 0);
    }
    return answer;
};

Python 3 · 官方类接口

from collections import Counter
from typing import List

class DetectSquares:
    def __init__(self):
        self.freq = Counter()

    def add(self, point: List[int]) -> None:
        self.freq[tuple(point)] += 1

    def count(self, point: List[int]) -> int:
        x, y = point
        answer = 0
        for (a, b), n in self.freq.items():
            if a == x or abs(a - x) != abs(b - y):
                continue
            answer += n * self.freq[(a, y)] * self.freq[(x, b)]
        return answer

C++ · 官方类接口

#include <vector>
#include <unordered_map>
#include <cstdlib>
using namespace std;

class DetectSquares {
    unordered_map<int, int> freq;

    int get(int x, int y) const {
        auto it = freq.find(x * 1001 + y);
        return it == freq.end() ? 0 : it->second;
    }

public:
    DetectSquares() = default;

    void add(vector<int> point) {
        ++freq[point[0] * 1001 + point[1]];
    }

    int count(vector<int> point) {
        int x = point[0], y = point[1];
        long long answer = 0;
        for (const auto& entry : freq) {
            int a = entry.first / 1001, b = entry.first % 1001;
            if (a == x || abs(a - x) != abs(b - y)) continue;
            answer += 1LL * entry.second * get(a, y) * get(x, b);
        }
        return static_cast<int>(answer);
    }
};
