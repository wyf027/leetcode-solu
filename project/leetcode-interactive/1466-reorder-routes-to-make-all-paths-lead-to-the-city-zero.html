重新规划路线

Reorder Routes to Make All Paths Lead to the City Zero

图深度优先搜索广度优先搜索树
Problem

题目描述

有 n 座城市，编号为 0 到 n - 1。城市间恰有 n - 1 条路线，并且任意两座城市之间只有一条路径，因此路线网是一棵树。

connections[i] = [aᵢ, bᵢ] 表示一条从城市 aᵢ 指向城市 bᵢ 的单向路线。现在所有城市的居民都需要前往首都城市 0。

改变若干路线的方向，使每座城市都能到达城市 0。返回需要改变方向的最少路线数。题目保证可以完成规划。

约束

  • 2 ≤ n ≤ 5 × 10⁴
  • connections.length = n - 1
  • connections[i].length = 2
  • 0 ≤ aᵢ, bᵢ ≤ n - 1
  • aᵢ ≠ bᵢ
  • 忽略方向后，所有路线构成一棵树。

输入：n = 6
connections = [[0,1],[1,3],

输出：3

Solution

完整题解

需要时再展开。阅读状态不会影响上方交互。

核心洞察：忽略方向后是一棵树。以城市 0 为根向外遍历时，每遇到一条“父节点 → 子节点”的原始边，它背离首都，必须翻转；“子节点 → 父节点”则无需改变。

完整过程

  1. 对每条有向边 a → b，加入 a → (b, 1) 与 b → (a, 0) 两个邻接项。
  2. 从城市 0 开始 BFS 或 DFS，按无向树遍历。
  3. 每走到未访问邻居，将该邻接项的 0/1 代价累加。
  4. 遍历结束，累加值就是最少翻转数。

边界处理

  • n = 2 时只需判断唯一一条边。
  • 答案可能是 0，也可能达到 n - 1。
  • n 可达 5 × 10⁴；迭代 BFS/DFS 可避免递归栈限制。
  • 树没有环，但遍历无向邻接表仍需访问标记。

正确性证明

唯一父边：以 0 为根后，每个非根城市都有且仅有一条连接父节点的边。
必要性：若父边由父节点指向子节点，子树无法跨过它走向 0，所以必须翻转。
充分性：翻转所有背离根的父边后，每个城市都能沿父链到达 0。
最优性：算法只翻转这些必需边且各计一次，任何方案都不能更少。
复杂度：建图与遍历均为 O(n) 时间；邻接表、队列和访问数组占 O(n) 空间。
常见错误：仅沿原有向边搜索；重复统计父边；遗漏访问标记；把指向根和背离根判断反；大数据递归栈溢出。

替代方案与面试追问

替代方案：DFS 与 BFS 等价；也可把原始有向边放入集合，遍历无向树时查询 (parent, child) 是否存在。带 0/1 代价的邻接表更直接。

  • 要输出具体翻转边：遇到代价 1 时记录原始边。
  • 若原图不是树：路径不再唯一，简单计数结论失效，需要有向图可达性与更复杂的优化。
  • 从叶子贪心是否可行：必须先确定以 0 为根的父子关系，本质仍是树遍历。

四语言完整代码

Java · iterative BFS
import java.util.*;

class Solution {
    public int minReorder(int n, int[][] connections) {
        List<int[]>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : connections) {
            graph[e[0]].add(new int[]{e[1], 1});
            graph[e[1]].add(new int[]{e[0], 0});
        }
        boolean[] seen = new boolean[n];
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        seen[0] = true;
        int changes = 0;
        while (!queue.isEmpty()) {
            int city = queue.poll();
            for (int[] next : graph[city]) {
                if (seen[next[0]]) continue;
                seen[next[0]] = true;
                changes += next[1];
                queue.offer(next[0]);
            }
        }
        return changes;
    }
}

var minReorder = function(n, connections) {
    const graph = Array.from({ length: n }, () => []);
    for (const [from, to] of connections) {
        graph[from].push([to, 1]);
        graph[to].push([from, 0]);
    }
    const seen = new Uint8Array(n);
    const queue = [0];
    seen[0] = 1;
    let head = 0, changes = 0;
    while (head < queue.length) {
        const city = queue[head++];
        for (const [next, cost] of graph[city]) {
            if (seen[next]) continue;
            seen[next] = 1;
            changes += cost;
            queue.push(next);
        }
    }
    return changes;
};
Python 3 · iterative BFS
from collections import deque
from typing import List

class Solution:
    def minReorder(self, n: int, connections: List[List[int]]) -> int:
        graph = [[] for _ in range(n)]
        for source, target in connections:
            graph[source].append((target, 1))
            graph[target].append((source, 0))
        seen = [False] * n
        seen[0] = True
        queue = deque([0])
        changes = 0
        while queue:
            city = queue.popleft()
            for neighbor, cost in graph[city]:
                if seen[neighbor]:
                    continue
                seen[neighbor] = True
                changes += cost
                queue.append(neighbor)
        return changes
C++ · iterative BFS
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int minReorder(int n, vector<vector<int>>& connections) {
        vector<vector<pair<int, int>>> graph(n);
        for (const auto& edge : connections) {
            graph[edge[0]].push_back({edge[1], 1});
            graph[edge[1]].push_back({edge[0], 0});
        }
        vector<bool> seen(n, false);
        queue<int> cities;
        cities.push(0);
        seen[0] = true;
        int changes = 0;
        while (!cities.empty()) {
            int city = cities.front();
            cities.pop();
            for (auto [next, cost] : graph[city]) {
                if (seen[next]) continue;
                seen[next] = true;
                changes += cost;
                cities.push(next);
            }
        }
        return changes;
    }
};
