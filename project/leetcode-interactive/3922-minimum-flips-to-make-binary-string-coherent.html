LEETCODE 3922 · MEDIUM

使二进制字符串连贯的最少翻转次数

把字符串修成不含 011、110 子序列的形状，并让翻转次数最小。

线性扫描四类目标形状O(n)

题意

给定二进制字符串 s。若它不把 "011" 或 "110" 包含为子序列，则它连贯。每次可翻转一个位置，求最少操作数。

示例 1

s = "1010"

输出：1。翻转首位得到 "0010"。

示例 2

s = "0110"

输出：1。翻转 s[1] 可得 "0010"。

示例 3

s = "1000"

输出：0。

约束：1 ≤ s.length ≤ 10⁵；每个字符是 '0' 或 '1'。

形状比对器

演示最多 60 位；算法本身支持 10⁵ 位。

题解：只需比较四种合法目标

若有两个 1，任何位于倒数第二个 1 前的 0 都会与这两个 1 组成 011；同理处理 110。整理这两个限制后，连贯串只可能属于四个候选族：

  1. 全为 0；
  2. 全为 1；
  3. 恰好一个 1（其位置任意）；
  4. 首尾为 1、中间全为 0，即 10…01。

扫描一次统计 ones。前三类代价分别是 ones、n - ones、n==1 ? 0 : |ones - 1|。第四类直接逐位和固定模板的不同字符数。取最小值。

复杂度

时间 O(n)，额外空间 O(1)。

边界

长度 1、全相同、端点已为 1 都被四类候选自然覆盖。

替代方案与常见错误

可用小状态 DP 描述已选子序列，但状态更多且没有必要。常见错误是把“子序列”误当作“子串”，或漏掉首尾为 1 的模板。

面试追问

若禁用模式变成任意长度的集合，可把“目标串结构”转为有限自动机，再做最短路径/DP；本题的关键是先证明自动机坍缩为四类形状。
