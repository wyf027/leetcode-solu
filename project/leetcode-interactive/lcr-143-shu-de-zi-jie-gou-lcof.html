子结构判断

给定两棵二叉树 A 和 B，判断 B 是否是 A 的子结构。空树不算作任何树的子结构。

开始推演

首屏只呈现任务与输入；题解默认收起，准备好后再展开。

题意

若树 B 的结构与节点值能在树 A 的某个节点开始完全匹配，则 B 是 A 的子结构。匹配只需要覆盖 B 已有的节点；A 在相应位置多出的分支不影响结果。

示例 1

输入：A = [1,2,3], B = [3,1]
输出：false

示例 2

输入：A = [3,4,5,1,2], B = [4,1]
输出：true

约束

  • 0 <= A、B 的节点数 <= 10000。
  • 节点值范围为 -10000 到 10000。
  • 空树不是任意树的子结构。

先想一想

  1. 1可能的起点在哪里？
  2. 2从一个起点出发，怎样判断“完全匹配”？
  3. 3当 B 走到空节点时，这轮匹配该返回什么？

SOLUTION

递归：枚举起点 + 验证匹配

核心洞察

外层递归负责在 A 中寻找起点；内层递归负责从两个当前节点出发，验证 B 的结构和值是否都能被 A 覆盖。这两层职责不能混在一起。

匹配过程

  1. 若 B 为空，本轮 B 已全部匹配，返回 true。
  2. 若 A 为空或当前值不同，返回 false。
  3. 递归要求左右孩子也分别匹配。

边界条件

  • 题目规定 B 为空时，整体答案为 false。
  • B 为空只在“已开始的一轮 match”中表示成功。
  • A 为空且 B 非空，无法继续覆盖。

复杂度

最坏情况下会把 B 与 A 的多个起点比较：时间 O(|A| × |B|)。递归调用栈最深为两棵树高度，空间 O(hA + hB)。

class Solution {
    public boolean isSubStructure(TreeNode A, TreeNode B) {
        return A != null && B != null &&
            (match(A, B) || isSubStructure(A.left, B) || isSubStructure(A.right, B));
    }
    private boolean match(TreeNode a, TreeNode b) {
        if (b == null) return true;
        if (a == null || a.val != b.val) return false;
        return match(a.left, b.left) && match(a.right, b.right);
    }
}

    if (!b) return true;
    if (!a || a.val !== b.val) return false;

替代思路与追问

可以把 B 序列化后做模式匹配，但必须编码空指针，且复杂度与实现细节都更重。追问：若要匹配“子树”而非“子结构”，空孩子也必须严格一致，match 的空节点规则要改变。

常见错误

  • 把 B 为空直接当作整体 true，违反题意。
  • 只比较根值，没有递归比较左右结构。
  • 要求 A 多出来的孩子也为空，把子结构误当子树。
