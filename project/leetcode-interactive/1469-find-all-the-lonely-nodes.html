Find All The Lonely Nodes

给你一棵二叉树的根节点 root。如果一个节点是其父节点唯一的子节点，就称它为“独生节点”。请返回树中所有独生节点的值，答案顺序不限。

01 · Problem

先读懂规则

输出顺序任意
判断关键：节点必须有父节点，并且父节点只有这一个非空孩子。根节点没有父节点，因此永远不是独生节点。

List<Integer> getLonelyNodes(TreeNode root)

示例 1
输入：root = [1,2,3,null,4]
输出：[4]
说明：4 是节点 2 唯一的孩子。
示例 2
输入：root = [7,1,4,6,null,5,3,
     null,null,null,null,null,2]
输出：[6,2]
说明：6 与 2 各自没有兄弟节点。
示例 3
输入：root = [11,99,88,77,null,
     null,66,55,null,null,44,
     33,null,null,22]
输出：[77,55,33,66,44,22]
说明：答案顺序可以不同。

约束

  • 1 <= Node.val <= 10^6
  • 树中节点数在 [1, 1000] 范围内
  • root 为有效二叉树根节点
  • 返回值顺序不作要求

03 · Solution

准备好再揭晓

先尝试自己总结判断条件，再展开完整题解。

核心洞察

“独生”是一个父子关系属性。遍历到父节点时最容易判断：左孩子非空且右孩子为空，则左孩子独生；右孩子非空且左孩子为空，则右孩子独生。

完整过程

  1. 创建结果列表。
  2. 从根节点遍历整棵树。
  3. 对每个节点检查左右孩子是否恰好一个为空。
  4. 把唯一存在的孩子值加入结果，再继续访问非空子树。

正确性证明

若算法加入节点 x，其父节点恰好只有 x 一个非空孩子，故 x 一定独生。
任一独生节点 y 的父节点都会在完整遍历中被访问；届时恰有一个孩子非空，算法必加入 y。
因此结果既无误报也无遗漏。

边界与复杂度

  • 空树：返回空列表（防御式处理）。
  • 只有根节点：没有独生节点。
  • 链状树：除根外每个节点都独生。
  • 时间复杂度：O(n)。
  • 递归 DFS 空间：O(h)，最坏 O(n)。

替代方案

可用 BFS 队列逐层扫描，判断逻辑相同。它避免递归栈过深，额外空间为树的最大宽度 O(w)。本题无需为每个节点保存父指针。

面试追问

  • 如果还要返回深度，如何在 DFS/BFS 中携带层数？
  • 若是 N 叉树，“独生”应如何定义和判断？
  • 如何用迭代 DFS 避免递归栈溢出？

常见错误

  • 把叶子节点误认为独生节点；叶子描述“有没有孩子”，独生描述“有没有兄弟”。
  • 把根节点算入结果；根节点没有父节点。
  • 只判断某个孩子存在，却忘记确认另一个孩子为空。
  • 假设答案必须按层序或升序排列；题目允许任意顺序。

四语言完整实现

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    public List<Integer> getLonelyNodes(TreeNode root) {
        List<Integer> answer = new ArrayList<>();
        dfs(root, answer);
        return answer;
    }
    private void dfs(TreeNode node, List<Integer> answer) {
        if (node == null) return;
        if (node.left != null && node.right == null) {
            answer.add(node.left.val);
        } else if (node.left == null && node.right != null) {
            answer.add(node.right.val);
        }
        dfs(node.left, answer);
        dfs(node.right, answer);
    }
}
/**
 * @param {TreeNode} root
 * @return {number[]}
 */
var getLonelyNodes = function(root) {
    const answer = [];
    function dfs(node) {
        if (node === null) return;
        if (node.left !== null && node.right === null) {
            answer.push(node.left.val);
        } else if (node.left === null && node.right !== null) {
            answer.push(node.right.val);
        }
        dfs(node.left);
        dfs(node.right);
    }
    dfs(root);
    return answer;
};

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class Solution {
public:
    vector<int> getLonelyNodes(TreeNode* root) {
        vector<int> answer;
        dfs(root, answer);
        return answer;
    }
private:
    void dfs(TreeNode* node, vector<int>& answer) {
        if (node == nullptr) return;
        if (node->left != nullptr && node->right == nullptr) {
            answer.push_back(node->left->val);
        } else if (node->left == nullptr && node->right != nullptr) {
            answer.push_back(node->right->val);
        }
        dfs(node->left, answer);
        dfs(node->right, answer);
    }
};
