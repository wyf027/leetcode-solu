好子序列的个数

Count the Number of Good Subsequences

从一个字符串中挑出一些位置，怎样才算一次“好”的选择？
先读规则、观察示例，再按需打开计数实验室。

01题目

给定字符串 s，统计其非空子序列中，所有实际出现的字符出现次数都相同的方案数。结果对 1,000,000,007 取模。

子序列由保留部分原位置得到，顺序不变。按选择的位置计数：即使得到相同文本，只要选取的位置不同，也属于不同方案。没有选中的字符不参与频次比较。

参数与返回值

countGoodSubsequences(s: string) → integer

约束

1 ≤ s.length ≤ 10⁴
s 仅含小写英文字母。

元数据中题面与代码片段为空；题名、签名和示例输入来自本轮官方元数据。题意、示例输出和约束参考 LeetCode Wiki 公开资料，以中文重新转述。官方题目。

04独立题解

包含交互演示、推导与四语言实现。

把“相等”固定下来

设字符 c 在原串中有 f[c] 个位置。如果最终每个被选字符都出现 k 次，那么它只有两条路：完全不选，或从这些位置中选出恰好 k 个。

本层贡献 G(k) = ∏c: f[c] ≥ k (1 + C(f[c], k)) − 1
答案 = ∑k=1..max(f) G(k) mod 1,000,000,007

乘积把各字符的独立选择组合起来；减去 1，是排除所有字符都不选的空集。不同 k 的非空结果互不重叠。位置选好后按原下标排列，顺序已唯一确定，不需要再乘排列数。

FREQUENCY LAYERS

共同频次实验室

输入 1–12 个小写字母。逐步观察每个字符的选择因子、层内乘积与累计值。此处显示精确小整数，无需取模；正式代码支持 10⁴ 长度。

键盘：Tab 定位按钮，Enter / 空格操作。减少动态效果偏好下默认不自动播放，可手动逐步查看。

层记录

完整过程与组合数递推

  1. 扫描 s，得到 26 个字符频次及最大频次 m。
  2. 预计算 1 到 m 的模逆元 inv。因为 m < 素数 P，所有这些数都可逆。
  3. 初始化每个字符的 choose 为 C(f, 0) = 1。依次枚举 k = 1..m。
  4. 若 f ≥ k，更新 choose = choose × (f − k + 1) × inv[k] mod P，即 C(f, k)。将 1 + choose 乘入本层乘积。若 f < k，仅有“不选”方案，因子为 1。
  5. 每层乘积减 1，规范化取模后累加，得到答案。

逆元递推：inv[1] = 1；inv[k] = P − ⌊P/k⌋ × inv[P % k] mod P。由 P = qk + r，可得 qk + r ≡ 0，乘以 k 与 r 的逆元即可推出此式；且 r < k，所需值已算出。

用 aabb 走一遍

k = 1：a 有 1 + 2 种选择，b 也有 1 + 2 种，贡献 3 × 3 − 1 = 8。k = 2：两个字符的因子都为 1 + 1，贡献 2 × 2 − 1 = 3。总数 8 + 3 = 11。

正确性

固定层的双射：每个字符独立选择空集或 k 个位置，联合后得到一个位置子集。除了全空选择，其被选字符的频次恰为 k，必然是好子序列。反过来，每个共同频次为 k 的好子序列都能唯一拆成这些字符位置的选择，因此乘积减一恰好计数一次。

层间无重无漏：每个好子序列非空，其共同正频次唯一且不超过 m，所以恰好落入一个枚举层。相加得到全部答案。组合数递推由相邻二项式系数之比得到；逆元合法，模运算保持最终余数。

边界与常见错误

  • 长度 1 返回 1；单一字符时全部非空位置子集都合格，答案为 2ⁿ − 1。
  • 全部字符不同，仅 k = 1 层有效，仍为 2ⁿ − 1。
  • 不要用文本 Set 去重；例如 aa 的两个单字符选择计为 2 个方案。
  • 每一层都要减去空集，不能最后只减一次；k 不能从 0 开始。
  • 频次不足 k 的字符应跳过，不能把整个乘积清零，也不能限制 k ≤ 最小频次。
  • 模除法要乘逆元；普通除法不保留模意义。Java/C++ 乘法使用 64 位并及时取模；JavaScript 使用 BigInt 避免超过 2⁵³ 的精度损失。
  • 原题不包含空串；实现依赖 1 ≤ n。演示输入另行限制为 12，仅为控制展示规模。

复杂度

记 n 为字符串长度，m 为最大字符频次，Σ = 26。计数 O(n)，逆元 O(m)，枚举 O(Σm)，总时间 O(n + Σm)，额外空间 O(m + Σ)。固定 26 字母时可写成 O(n) 时间、O(n) 空间。上述按模整数运算计；JavaScript 的 BigInt 操作数始终受常数模数控制。

替代方案

可预处理阶乘与逆阶乘，用一次快速幂和逆向递推完成预处理，以 O(1) 求每个组合数；时间 O(n + Σm + log P)，空间 O(n + Σ)，适合同时支持随机组合数查询。逐个枚举位置子集需 O(n·2ⁿ)，仅适合很小的输入。帕斯卡三角无需模逆元但 O(m²) 预处理对本题上限不划算。

面试追问

  • 打乱 s 后答案变化吗？不变。重排对原位置集合建立双射，字符频次条件保持。
  • 要求恰好 d 种字符呢？固定 k 后，用一维 DP 求 ∏(1 + C(f[c], k)x) 的 xᵈ 系数。
  • 若模数不为素数？逆元未必存在，本递推不能直接套用，需要选择适合模数的组合数算法。
  • 若改为不同文本的子序列？本题按下标的乘法计数会重复，需要处理字符顺序与文本去重，频次表本身不足以解决。

Java

class Solution {
    public int countGoodSubsequences(String s) {
        final long MOD = 1_000_000_007L;
        int[] count = new int[26];
        int max = 0;
        for (char ch : s.toCharArray()) {
            int c = ++count[ch - 'a'];
            max = Math.max(max, c);
        }
        long[] inv = new long[max + 1];
        inv[1] = 1;
        for (int k = 2; k <= max; k++)
            inv[k] = MOD - (MOD / k) * inv[(int)(MOD % k)] % MOD;
        long[] choose = new long[26];
        java.util.Arrays.fill(choose, 1);
        long answer = 0;
        for (int k = 1; k <= max; k++) {
            long product = 1;
            for (int j = 0; j < 26; j++) {
                if (count[j] < k) continue;
                choose[j] = choose[j] * (count[j] - k + 1) % MOD
                            * inv[k] % MOD;
                product = product * (1 + choose[j]) % MOD;
            }
            answer = (answer + product - 1 + MOD) % MOD;
        }
        return (int) answer;
    }
}

/** @param {string} s @return {number} */
var countGoodSubsequences = function(s) {
    const MOD = 1000000007n;
    const count = Array(26).fill(0);
    for (const ch of s) count[ch.charCodeAt(0) - 97]++;
    const max = Math.max(...count);
    const inv = Array(max + 1).fill(0n);
    inv[1] = 1n;
    for (let k = 2; k <= max; k++) {
        const b = BigInt(k);
        inv[k] = MOD - (MOD / b) * inv[Number(MOD % b)] % MOD;
    }
    const choose = Array(26).fill(1n);
    let answer = 0n;
    for (let k = 1; k <= max; k++) {
        let product = 1n;
        for (let j = 0; j < 26; j++) {
            if (count[j] < k) continue;
            choose[j] = choose[j] * BigInt(count[j] - k + 1)
                        % MOD * inv[k] % MOD;
            product = product * (1n + choose[j]) % MOD;
        }
        answer = (answer + product - 1n + MOD) % MOD;
    }
    return Number(answer);
};

class Solution:
    def countGoodSubsequences(self, s: str) -> int:
        mod = 10**9 + 7
        count = [0] * 26
        for ch in s:
            count[ord(ch) - ord('a')] += 1
        maximum = max(count)
        inv = [0] * (maximum + 1)
        inv[1] = 1
        for k in range(2, maximum + 1):
            inv[k] = mod - (mod // k) * inv[mod % k] % mod
        choose = [1] * 26
        answer = 0
        for k in range(1, maximum + 1):
            product = 1
            for j, c in enumerate(count):
                if c < k:
                    continue
                choose[j] = choose[j] * (c - k + 1) % mod * inv[k] % mod
                product = product * (1 + choose[j]) % mod
            answer = (answer + product - 1) % mod
        return answer
