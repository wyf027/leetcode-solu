01 / 题目与规则

给定仅包含数字字符的字符串 num，可以任选其中的数字并重新排列。请返回能组成的数值最大的回文整数，结果以字符串表示。

至少选一个数字；每个数字字符最多使用一次；可以舍弃数字。结果不得有前导零，但单独的 "0" 合法。回文指从左往右与从右往左读完全相同。

官方示例 1

输入：num = "444947137"
输出："7449447"

选出四个 4、两个 7 和一个 9，重排得到 7449447；其余数字可以舍弃。

官方示例 2

输入：num = "00009"
输出："9"

0 不能放在多位整数的开头，因此可以只保留 9。

参数与约束

  • 1 ≤ num.length ≤ 100000。
  • num 中每个字符都属于 0–9。
  • 函数：largestPalindromic(num: string) → string。

04 / 独立题解
准备好后再展开：包含推导、正确性说明与四种语言代码。




核心洞察：先争取长度，再争取高位
没有前导零的非负整数，位数越多越大；位数相同则从左到右比较。回文的非中心位置必须成对出现，所以每个数字可以贡献 floor(count[d] / 2) 对，最多另选一个剩余数字作为中心。
左半部分按 9 到 0 降序排列，再镜像到右侧。只有当左边已经有非零数字时，才能追加零对；否则这些零对会制造前导零，应全部跳过。最后从剩余库存中挑最大的一个作为中心。


完整过程
  1. 扫描字符串，统计 0–9 的出现次数，准备空左串。
  2. 从 9 递减到 0：若当前数字为 0 且左串为空，跳过；否则取尽该数字的配对数量，将每对中的一个追加到左串，并从库存扣除两倍数量。
  3. 从 9 到 0 找第一个仍有库存的数字，作为中心。都没有剩余则中心为空。
  4. 返回 左串 + 中心 + reverse(左串)。全零时，配对阶段跳过零，中心仍会取得一个 0。
示例 1：库存为 4×4、7×2、9×1、1×1、3×1。先取 7 对，再取两对 4，左侧为 744；余量中最大为 9，得到 744 + 9 + 447 = 7449447。


正确性说明
  1. 合法性：每次扣除一对相同数字，放到对称位置；中心只消耗一位，因此不超用库存且结果对称。零仅在已有非零左串时参与配对，结果不会有前导零。
  2. 最大长度：存在非零对时，所有数字对都能被非零外层包住。每一对都增加两位；拆开一对最多补一个中心，反而少一位，因此取尽所有对能达到最大长度。有剩余时再选一个中心即可。
  3. 相同长度下最大：左半串首次不同的位置决定数值大小。若较小数字在较大数字前，交换这两对可增大结果，所以左串应降序。固定左串后，最大的剩余中心令结果最大。
  4. 无非零对：任意合法多位回文都要求首尾是相同非零数字，此时不可能做到；答案只能是一位，算法选择全体数字中的最大值，全零则为 0。


边界与常见错误
  • 全零：返回 "0"，不能返回空串或 "00"。
  • 只有单个非零数字和若干零：只能取最大的单个数字。
  • 不能因担心前导零而删除所有零；非零外层内的零能增加位数。
  • 中心必须从配对后的余量中选择，不能重复使用已配对数字。
  • 不要把结果转为整数；十万位会超出常见数值类型。
  • 右侧必须是左侧的逆序，直接复制左侧一般不是回文。
复杂度
设输入长度为 n，输出长度为 m（m ≤ n）。统计需要 O(n)，拼接需要 O(m)，总时间 O(n)。十个计数槽是 O(1)，左串、镜像和结果占 O(n) 空间；四语言实现都计入了构造缓冲。
替代方案
先排序所有字符，再按组配对，可得到同样结果，但通常需要 O(n log n) 时间。因为字符集只有十种，频次数组更直接。枚举排列开销过大，只适合极小规模的独立参考。


面试追问
  • 必须使用全部数字？要检查奇数频次是否至多一个，并检查能否建立合法非零首尾；多位全零仍不满足无前导零要求。
  • 改为 k 进制？将计数数组扩展到 k 个符号，依旧按位值降序配对，复杂度为 O(n + k)。
  • 输入以数据流到达？统计时只保存十个计数；结束后构造输出。若要流式输出，可按各数字配对数量输出左侧、中心，再按相反顺序输出右侧。
  • 为什么不能把最大的两位拆出一位放中心？拆一对会少两位，中心最多增加一位；长度更短必然更小。

class Solution {
    public String largestPalindromic(String num) {
        int[] count = new int[10];
        for (int i = 0; i < num.length(); i++) {
            count[num.charAt(i) - '0']++;
        }
        StringBuilder left = new StringBuilder();
        for (int d = 9; d >= 0; d--) {
            if (d == 0 && left.length() == 0) continue;
            int pairs = count[d] / 2;
            for (int i = 0; i < pairs; i++) {
                left.append((char) ('0' + d));
            }
            count[d] -= pairs * 2;
        }
        String middle = "";
        for (int d = 9; d >= 0; d--) {
            if (count[d] > 0) {
                middle = String.valueOf(d);
                break;
            }
        }
        String prefix = left.toString();
        return prefix + middle + left.reverse().toString();
    }
}

/**
 * @param {string} num
 * @return {string}
 */
var largestPalindromic = function(num) {
    const count = Array(10).fill(0);
    for (const ch of num) count[Number(ch)]++;
    const chunks = [];
    let length = 0;
    for (let d = 9; d >= 0; d--) {
        if (d === 0 && length === 0) continue;
        const pairs = Math.floor(count[d] / 2);
        chunks.push(String(d).repeat(pairs));
        length += pairs;
        count[d] -= pairs * 2;
    }
    let middle = "";
    for (let d = 9; d >= 0; d--) {
        if (count[d] > 0) {
            middle = String(d);
            break;
        }
    }
    const left = chunks.join("");
    return left + middle + left.split("").reverse().join("");
};

class Solution:
    def largestPalindromic(self, num: str) -> str:
        count = [0] * 10
        for ch in num:
            count[int(ch)] += 1
        chunks = []
        length = 0
        for d in range(9, -1, -1):
            if d == 0 and length == 0:
                continue
            pairs = count[d] // 2
            chunks.append(str(d) * pairs)
            length += pairs
            count[d] -= pairs * 2
        middle = ""
        for d in range(9, -1, -1):
            if count[d] > 0:
                middle = str(d)
                break
        left = "".join(chunks)
        return left + middle + left[::-1]

#include <string>
using namespace std;

class Solution {
public:
    string largestPalindromic(string num) {
        int count[10] = {};
        for (char ch : num) ++count[ch - '0'];
        string left;
        left.reserve(num.size() / 2);
        for (int d = 9; d >= 0; --d) {
            if (d == 0 && left.empty()) continue;
            int pairs = count[d] / 2;
            left.append(pairs, char('0' + d));
            count[d] -= pairs * 2;
        }
        string middle;
        for (int d = 9; d >= 0; --d) {
            if (count[d] > 0) {
                middle = string(1, char('0' + d));
                break;
            }
        }
        string right(left.rbegin(), left.rend());
        return left + middle + right;
    }
};
