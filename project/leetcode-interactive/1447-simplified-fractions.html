1447. 最简分数

Simplified Fractions

中等数学字符串最大公约数欧几里得算法

01题目

给定整数 n，返回所有严格位于 0 与 1 之间、且分母不超过 n 的最简分数。返回顺序不限。

“最简”是什么意思？ 分子与分母没有大于 1 的公因数；也就是二者的最大公约数等于 1。

示例 1

输入：n = 2
输出：["1/2"]
解释：分母不超过 2 时，1/2 是唯一符合条件的最简分数。

示例 2

输入：n = 3
输出：["1/2","1/3","2/3"]

示例 3

输入：n = 4
输出：["1/2","1/3","1/4","2/3","3/4"]
解释：2/4 可化简为 1/2，因此不属于最简分数。

示例 4

输入：n = 1
输出：[]
约束1 <= n <= 100

03题解：枚举 + 最大公约数

核心洞察

任何严格位于 0 和 1 之间、分母为 b 的正分数，其分子 a 必须满足 1 ≤ a < b。而 a/b 已经最简，当且仅当 gcd(a, b) = 1。所以只需完整枚举候选对，再用最大公约数做精确筛选。

for b = 2..n → for a = 1..b-1 → gcd(a, b) == 1 ? 收集 "a/b" : 跳过

完整过程

  1. 创建空字符串列表 answer。
  2. 让分母 b 从 2 枚举到 n；分母为 1 时不存在严格位于 0 和 1 之间的正分数。
  3. 对每个 b，让分子 a 从 1 枚举到 b - 1。
  4. 用欧几里得算法计算 gcd(a, b)。若结果为 1，将 "a/b" 加入答案。
  5. 扫描结束后返回列表。题目允许任意顺序，因此无需额外排序。

正确性：不会漏

设 a/b 是任意符合条件的最简分数。由范围可知 2 ≤ b ≤ n 且 1 ≤ a < b，两层循环一定会枚举到它；又因为它最简，所以 gcd(a,b)=1，算法必然收集它。

正确性：不会多

算法只枚举 1 ≤ a < b ≤ n，因此收集项必在 (0,1) 内且分母合规；只有最大公约数为 1 时才收集，所以每一项都是最简分数。不同整数对对应不同的最简表示，不会重复。

边界情况

  • n = 1：外层循环不执行，返回空列表。
  • n = 2：唯一候选是 1/2。
  • 分子等于 1 时总与分母互质，因此所有 1/b 都会保留。
  • 分子和分母有公共质因数时必须跳过，例如 2/4、3/6。

复杂度

时间 O(n² log n)共有 O(n²) 个候选；每次欧几里得算法耗时 O(log n)。在 n ≤ 100 下非常充裕。
空间 O(1) 额外空间除返回答案外只使用常数个变量；答案本身占 O(n²) 量级。

替代方案

可以为每个分母用筛法标记与它互质的分子，或借助 Farey 序列按数值顺序生成所有既约分数。它们适合更大的范围或要求有序输出的场景；本题 n 很小，直接枚举配合 gcd 更短、更清晰，也更不容易出错。

面试追问

  • 为什么不需要集合去重？ 两个相等的既约正分数必有相同的分子和分母；每个整数对只枚举一次。
  • 如果要求按数值升序返回？ 可以按交叉乘积比较后排序，或直接使用 Farey 序列生成。
  • 若 n 非常大如何优化？ 可考虑欧拉函数、筛法或 Farey 序列，并关注输出本身已经可能达到 Θ(n²)。
  • 为何 gcd 为 1 等价于最简？ 有大于 1 的公约数就能同时约掉；没有这样的公约数就无法继续化简。

常见错误

  • 把分子枚举到 b，错误地加入值为 1 的分数。
  • 从分母 1 开始并构造无意义候选，或忘记处理 n = 1。
  • 仅判断“分母不能整除分子”，这不足以排除像 2/6 这样的可约分数。
  • 先生成全部分数再用浮点值去重，可能引入精度问题，也没有保证输出为最简表示。

class Solution {
    public List<String> simplifiedFractions(int n) {
        List<String> answer = new ArrayList<>();

        for (int denominator = 2; denominator <= n; denominator++) {
            for (int numerator = 1; numerator < denominator; numerator++) {
                if (gcd(numerator, denominator) == 1) {
                    answer.add(numerator + "/" + denominator);
                }
            }
        }
        return answer;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }
}

var simplifiedFractions = function(n) {
    const answer = [];

    const gcd = (a, b) => {
        while (b !== 0) {
            [a, b] = [b, a % b];
        }
        return a;
    };

    for (let denominator = 2; denominator <= n; denominator++) {
        for (let numerator = 1; numerator < denominator; numerator++) {
            if (gcd(numerator, denominator) === 1) {
                answer.push(`${numerator}/${denominator}`);
            }
        }
    }
    return answer;
};
