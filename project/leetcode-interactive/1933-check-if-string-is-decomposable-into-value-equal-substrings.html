Check if String Is Decomposable Into Value-Equal Substrings

判断字符串是否可分解为
值均等的子串

一串数字，一次完整切分。能否让每块内部相同，并恰好留出一个双字符块？

01 / 问题

把整串切成符合规则的连续块

给定数字字符串 s，在字符之间选择切点，把原串完整分成若干非空子串。每一块中的字符都必须相同；所有块中，恰好一块长度为 2，其余块长度均为 3。存在这样的切分就返回 true，否则返回 false。

必须保留原顺序，不允许重排、跳过或重复使用字符。“值均等”指单个子串内字符相同，不要求不同子串使用同一个数字。

参数与返回值

isDecomposable(s: string) → boolean

只有一个参数 s；前导 0 是普通字符，不转成数值。

约束

1 ≤ s.length ≤ 1000

s 仅含 ASCII 数字 '0' 至 '9'。

04 / 独立题解

想好你的切分方法了吗？

展开后查看分段动画、证明和四种语言实现。

洞察 / 连续段 × 余数

每段独立切分，全局只允许一个余 2

先将相邻相同字符合成极大连续段。合法子串不可能跨过数字变化的位置，所以只需检查每段长度 L。该段要么完全由三字符块覆盖，要么包含唯一的双字符块。

  • L % 3 = 0：全切为长度 3。
  • L % 3 = 2：需要一个长度 2 的块，其余切为长度 3。
  • L % 3 = 1：即使使用唯一双字符块也不能填满，立即失败。

最终条件：没有余 1 的段，并且恰好一个段余 2。全串长度余 2 只是必要条件，不能代替逐段检查。

完整过程与正确性

  1. 令 i = 0，记录是否已用过双字符块的 used = false。
  2. 从 i 向右移动 j，直到末尾或数字变化，得到段 [i, j)。
  3. 计算 r = (j - i) % 3。若 r == 1，或 r == 2 且已用过双字符块，返回 false。
  4. 若余数为 2，设置 used = true；令 i = j，处理下一段。
  5. 全部处理完后返回 used，保证双字符块确实存在。

必要性

不同字符之间一定是切分边界。对于每一段，设三字符块数为 a，双字符块数为 b，则 L = 3a + 2b。全串只允许一个双字符块，所以每段 b 只能取 0 或 1，且全局之和为 1。因此段长只能余 0 或余 2，并且恰好一个段余 2。

充分性

若所有段都符合该条件，将每个余 0 的段切成三字符块；将唯一余 2 的段先切若干三字符块，再切一个双字符块。每块字符相同，覆盖全串且不重叠，长度要求全部满足，所以条件充分。

循环不变量

每次进入外层循环时，位置 i 之前的段已经可合法覆盖；used 表示其中是否需要唯一的双字符块。每次推进完整一段，保持不变量；拒绝条件对应无法继续的必要条件。结束时 used 为真，正好满足全局数量限制。

复杂度

时间 O(n)：两个指针只向右移动，每个字符参与常数次操作。额外空间 O(1)：实现只保存指针和布尔值。交互页为了回退会保存分段与步骤，使用 O(n) 展示空间，不计入提交算法。

边界、替代方案与面试追问

需要特别留意

长度 1 无解；长度 2 且字符相同可直接成立，不要求再有一个三字符块。全是长度 3 倍数的段时仍返回 false，因为缺少双字符块。余 2 的段长度可以是 2、5、8……，并不限于长度 2。

替代方案

可以逐块贪心：当前位置能取三个相同字符就先取 3 个，否则尝试唯一的 2 个，否则失败。这相当于每段尽量消去 3，余数仍然决定结局，复杂度同为 O(n) / O(1)。动态规划也可用“前缀长度 × 是否使用双块”枚举长度 2 和 3 的转移，但本题直接利用段长余数更简洁。

如果需要输出一种切分？

记录每个段的字符和长度，按 3 逐块输出，唯一余 2 的段末尾输出 2。输出本身占 O(n) 空间；是否要生成结果应由接口需求决定。

如果允许恰好 k 个双字符块？

每段需选 b，使 0 ≤ 2b ≤ L 且 L - 2b 能被 3 整除，再让所有段的 b 之和等于 k。原来的布尔标记不再够用，可用计数状态动态规划；不能直接沿用“余 1 就失败”。例如长度 4 可由两个双字符块覆盖。

如果数据以流输入？

只需保存当前数字、当前段长度和 used；数字改变时结算，流结束再结算最后一段，空间依旧为常数。

常见错误

  • 仅检查 n % 3 == 2。如 00112233 长度符合，却需要四个双字符块。
  • 统计每个数字的总频次。分开的同值段不能越过其他字符合并。
  • 把“恰好一个”写成“至多一个”，导致示例 1 被误判。
  • 忘记处理最后一段，或把右边界 j 当作含在段内的下标。
  • 将字符串转为数字，丢失前导 0。

四语言完整实现

遵循官方方法名 isDecomposable 与 string → boolean 签名；代码按在线评测提交形式给出，尚未编译或执行。输入满足题目约束。

Java

class Solution {
    public boolean isDecomposable(String s) {
        boolean used = false;
        int i = 0, n = s.length();
        while (i < n) {
            int j = i + 1;
            while (j < n && s.charAt(j) == s.charAt(i)) j++;
            int r = (j - i) % 3;
            if (r == 1 || (r == 2 && used)) return false;
            if (r == 2) used = true;
            i = j;
        }
        return used;
    }
}

#include <string>
using std::string;

class Solution {
public:
    bool isDecomposable(string s) {
        bool used = false;
        int i = 0, n = static_cast<int>(s.size());
        while (i < n) {
            int j = i + 1;
            while (j < n && s[j] == s[i]) ++j;
            int r = (j - i) % 3;
            if (r == 1 || (r == 2 && used)) return false;
            if (r == 2) used = true;
            i = j;
        }
        return used;
    }
};
