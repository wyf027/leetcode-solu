01 / 理解任务

先异或，再相加

给定整数数组 nums，枚举按元素位置选择得到的所有子集。每个子集内部的元素执行按位异或（XOR），空子集的结果记为 0。返回所有子集异或结果的算术和。

子集可以通过删除任意个元素得到，也可以一个都不删。即使两个子集包含相同的数，只要选择的位置不同，就需要分别计数。例如 nums = [1,1] 的两个单元素子集是两个不同选择。

异或规则：相同位为 0，不同位为 1。例如 2 XOR 5 XOR 6 = 1。这里“异或总和”指异或结果，不是普通加法。
1 ≤ nums.length ≤ 121 ≤ nums[i] ≤ 20返回值：integer

官方示例

示例 1
输入：nums = [1,3]
输出：6

子集 ∅、[1]、[3]、[1,3] 的异或值依次为 0、1、3、2。相加得到 6。

示例 2
输入：nums = [5,1,6]
输出：28

子集 ∅、[5]、[1]、[6]、[5,1]、[5,6]、[1,6]、[5,1,6] 的异或值依次为 0、5、1、6、4、3、7、2。相加得到 28。

示例 3
输入：nums = [3,4,5,6,7,8]
输出：480

全部 64 个子集的异或值相加得到 480。

04 / 独立题解

准备好解释你的观察了吗？

展开后阅读推导、正确性证明与四语言代码。

从枚举子集，到统计每一位

核心洞察

可以不枚举每个子集，而是分别计算每个二进制位对答案的贡献。如果所有元素在某一位都为 0，那么任何子集的该位也都为 0。如果至少有一个元素在该位为 1，那么恰好一半的子集在该位异或为 1。

答案 = (nums[0] | nums[1] | … | nums[n−1]) × 2^(n−1)

完整过程

  1. 初始化 bits = 0。
  2. 扫描数组，把每个元素按位或到 bits 中，收集所有出现过的 1 位。
  3. 每个出现过的位在 2^(n−1) 个子集中贡献自己的位权。
  4. 返回 bits × 2^(n−1)，这里是普通乘法。

以 nums = [5,1,6] 为例：101 | 001 | 110 = 111，即 7。三个位分别在 4 个子集中出现，贡献为 4×4 + 2×4 + 1×4 = 28。

为什么恰好一半？正确性证明

固定一个至少出现过一次的位 b，选定一个在 b 位为 1 的元素位置 j。把所有子集按“是否包含位置 j”配成对：对任意子集 S，切换位置 j 得到唯一的另一个子集 T。再次切换会回到 S，因此不会遗漏或重复配对。

切换位置 j 会翻转第 b 位的 XOR 结果，所以每一对恰有一个子集在该位为 1。共 2^n 个子集，即 2^(n−1) 对。把所有有效位的贡献相加，得到按位或结果乘以 2^(n−1)。各位贡献通过普通加法汇总，进位由整数加法自然处理。

复杂度与边界

  • 时间 O(n)：只扫描一次数组。在本题固定整数范围内，位运算视为 O(1)。
  • 额外空间 O(1)：仅保存按位或结果。
  • n = 1 时乘数为 1，答案就是唯一元素。
  • 相同数值仍按位置区分，配对论证同样成立，不能用 Set 去重。
  • 本题不包含空数组或 0。若扩展允许空数组，应先返回 0，避免计算负移位；允许零元素时，非空数组的公式仍然成立。
  • 元素最多 20，按位或结果最多 31；答案最多 31 × 2^11 = 63488，四种语言的下列写法均满足本题数值范围。扩大范围后，Java/C++ 要考虑更宽整数，JavaScript 的位运算受有符号 32 位限制，可改用 BigInt。

替代方案：回溯枚举

维护 dfs(i, xor) 表示处理到位置 i、当前选中元素异或值为 xor。每个位置分“不选”和“选”两支；走完全部位置时，把 xor 计入答案。它直接对应演示中的位置选择。

dfs(i, xor):
    if i == n: return xor
    return dfs(i + 1, xor) + dfs(i + 1, xor XOR nums[i])
answer = dfs(0, 0)

回溯的时间为 O(2^n)，递归栈 O(n)。也可以用位掩码从 0 到 2^n−1 枚举，每个掩码扫描 n 个位置，时间 O(n·2^n)，额外空间 O(1)。本页演示采用位掩码顺序，并缓存每个子集的异或值和前缀和以支持前后切换；这部分演示缓存使用 O(2^n) 空间。

四语言完整提交代码

以下均采用按位贡献公式；签名与官方元数据对应。代码尚未执行验证。

Java

class Solution {
    public int subsetXORSum(int[] nums) {
        int bits = 0;
        for (int num : nums) {
            bits |= num;
        }
        return bits * (1 << (nums.length - 1));
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number}
 */
var subsetXORSum = function(nums) {
    let bits = 0;
    for (const num of nums) {
        bits |= num;
    }

};

C++

#include <vector>
using std::vector;

class Solution {
public:
    int subsetXORSum(vector<int>& nums) {
        int bits = 0;
        for (int num : nums) {
            bits |= num;
        }
        return bits * (1 << (nums.size() - 1));
    }
};

常见错误

  • 对所有元素只做一次 XOR：那只代表完整子集，无法代表全部子集的算术和。
  • 对各个子集的结果继续 XOR：题目要求的是相加。
  • 使用 2^n 作为乘数：有效位只在一半的子集中为 1。
  • 混淆运算符：代码里的 ^ 表示 XOR，不是乘方。JavaScript 乘方是 **。
  • 漏掉空子集或把重复元素去重：空子集贡献 0，但仍属于枚举空间；位置必须保留。

面试追问

如果只统计大小为 k 的子集？ 切换一个位置会改变子集大小，原来的配对不再适用。对某个位，设 m 个元素该位为 1，需要用 Σ C(m,j) × C(n−m,k−j) 统计选择奇数个 j 的方案，再乘位权并汇总。

若要求所有子集的 AND 总和？ 某个位只有从该位为 1 的 m 个元素中选取非空子集时才保留，贡献为 (2^m−1) × 位权（约定空子集贡献为 0）。

为什么公式解不需要构造子集？ 我们只需要总和，不需要输出子集本身；逐位统计贡献能绕过指数级的输出空间。
