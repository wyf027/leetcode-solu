第 K 小的子数组和

Kth Smallest Subarray Sum · 付费题

每一段连续区间，都是一个独立的排名候选。

题目

给定正整数数组 nums 和整数 k，计算所有非空连续子数组的和，将这些和按非递减顺序排列，返回第 k 个值。不同区间即使和相等，也分别占据一个名次。k 从 1 开始。

kthSmallestSubarraySum(nums, k) → integer

官方示例 1

输入：nums = [2,1,3], k = 4
输出：3

所有和排序后为 1、2、3、3、4、6。

官方示例 2

输入：nums = [3,3,5,5], k = 7
输出：10

所有和排序后为 3、3、5、5、6、8、10、11、13、16。

约束

  • n == nums.length；1 ≤ n ≤ 2 × 10⁴
  • 1 ≤ nums[i] ≤ 5 × 10⁴
  • 1 ≤ k ≤ n × (n + 1) / 2

题解：二分阈值 + 滑动窗口

核心洞察

定义 C(x) 为和不超过 x 的子数组数。C 随 x 单调不减。第 k 小的和就是使 C(x) ≥ k 成立的最小整数 x。

完整过程

  1. lo 为数组最小值，hi 为数组总和，取中点 mid。
  2. 求 C(mid)：右端点逐个加入窗口，若和超过 mid，就不断移除左端点。
  3. 收缩后，以 r 结尾、起点从 l 到 r 的区间都合法，共 r−l+1 个，累加计数。
  4. 计数 ≥ k 时 hi=mid，否则 lo=mid+1。lo=hi 时返回 lo。

阈值实验台

逐个右端点观察窗口，随后观察二分边界收缩。青色表示合法窗口；演示计算不代表验证结果。

正确性

固定右端点 r，正数保证移除左端元素会减小和。收缩完成后，[l,r] 的所有非空后缀都合法。早于 l 的起点此前已超限，右端继续扩展也不会变合法。因此合法区间恰好有 r−l+1 个。每个区间有唯一右端点，累加不重不漏。

设第 k 小的值为 a。x<a 时 C(x)<k，x≥a 时 C(x)≥k。二分始终保留 a：计数足够则 a≤mid，否则 a>mid。每轮区间缩小，最终唯一值即 a。

边界与复杂度

单元素直接得到答案；k=1 返回最小元素，k=n(n+1)/2 返回总和。重复和不去重。窗口可能为空，此时 l=r+1，贡献为0。

时间 O(n log S)，额外空间 O(1)，S 为总和。每轮左右指针各最多前进 n 次。S≤10⁹，区间数≤200010000。Java/C++ 用64位中间值；JS Number 在此范围内精确。演示保存快照的开销不属于提交算法。

替代方案

枚举全部区间和排序：时间 O(n² log n)、空间 O(n²)。也可把每个起点对应的递增区间和作为有序流，用最小堆合并，时间 O(n+k log n)、空间 O(n)，适合 k 很小的情况。

常见错误

  • 把 ≤mid 写成 <mid，导致排名边界错位。
  • 每个右端点只加1，漏掉合法后缀。
  • 排序 nums，破坏原数组连续性。
  • C(mid)==k 就返回：mid 可能处于两个可达和之间。
  • 用 if 收缩一次，而非 while 收缩到合法。

面试追问

含0时仍可滑窗，下界允许0。含负数时阈值单调性仍成立，但窗口计数失效，需要前缀和配合有序统计结构，并重新设置搜索范围。第 k 大可转为第 M−k+1 小，M 是子数组总数。

Java

class Solution {
    public int kthSmallestSubarraySum(int[] nums, int k) {
        long lo = nums[0], hi = 0;
        for (int v : nums) { lo = Math.min(lo, v); hi += v; }
        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;
            long sum = 0, count = 0;
            int l = 0;
            for (int r = 0; r < nums.length; r++) {
                sum += nums[r];
                while (sum > mid) sum -= nums[l++];
                count += r - l + 1;
            }
            if (count >= k) hi = mid;
            else lo = mid + 1;
        }
        return (int) lo;
    }
}

Python

from typing import List

class Solution:
    def kthSmallestSubarraySum(self, nums: List[int], k: int) -> int:
        lo, hi = min(nums), sum(nums)
        while lo < hi:
            mid = lo + (hi - lo) // 2
            total = count = left = 0
            for right, value in enumerate(nums):
                total += value
                while total > mid:
                    total -= nums[left]
                    left += 1
                count += right - left + 1
            if count >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo

#include <vector>
#include <algorithm>
using namespace std;
class Solution {
public:
    int kthSmallestSubarraySum(vector<int>& nums, int k) {
        long long lo = nums[0], hi = 0;
        for (int v : nums) { lo = min(lo, (long long)v); hi += v; }
        while (lo < hi) {
            long long mid = lo + (hi - lo) / 2;
            long long sum = 0, count = 0;
            int l = 0;
            for (int r = 0; r < (int)nums.size(); r++) {
                sum += nums[r];
                while (sum > mid) sum -= nums[l++];
                count += r - l + 1;
            }
            if (count >= k) hi = mid;
            else lo = mid + 1;
        }
        return (int)lo;
    }
};
