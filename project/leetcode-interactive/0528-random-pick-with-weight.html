按权重随机选择

Random Pick with Weight · 把概率区间化，再用二分查找命中区间。

数组前缀和二分查找随机化

题目

给定一个下标从 0 开始的正整数数组 w，其中 w[i] 是下标 i 的权重。实现 pickIndex()，每次在 [0, w.length - 1] 中返回一个下标，使返回 i 的概率恰为 w[i] / sum(w)。

输出具有随机性：单次调用没有唯一答案；正确性体现在长期分布符合各下标的权重比例。

约束

  • 1 ≤ w.length ≤ 10⁴
  • 1 ≤ w[i] ≤ 10⁵
  • pickIndex 最多调用 10⁴ 次

官方示例

示例 1

输入：
["Solution","pickIndex"]
[[[1]],[]]
输出：[null,0]
解释：唯一可选下标为 0。

示例 2

输入：
["Solution","pickIndex","pickIndex",
 "pickIndex","pickIndex","pickIndex"]
[[[1,3]],[],[],[],[],[]]
输出：[null,1,1,1,1,0]
解释：0 的概率为 1/4，1 为 3/4；
其他符合随机分布的输出也有效。

Solution

前缀和 + 二分查找

核心洞察

将总权重 S 看作票号 1..S。下标 i 获得连续的 w[i] 张票，因此均匀抽一张票后，它落入某下标区间的概率自然是 w[i]/S。

完整过程

  1. 构造前缀和：prefix[i] = w[0] + … + w[i]。
  2. 每次调用生成均匀整数 target ∈ [1, S]。
  3. 二分查找第一个满足 prefix[i] ≥ target 的下标。

正确性

令 prefix[-1]=0。算法返回 i 当且仅当 prefix[i-1] < target ≤ prefix[i]。该整数区间恰有 prefix[i]-prefix[i-1]=w[i] 个票号，而全部票号共 S 个且等概率，因此返回 i 的概率为 w[i]/S。二分返回首个不小于目标的前缀，正好定位该唯一区间。

边界与复杂度

  • 单元素数组：所有票均属于下标 0。
  • 目标为 1 或总和：分别落入首段或末段。
  • 总和最大为 10⁹；Java 使用 long、JavaScript 的安全整数范围足够，C++ 使用 long long 更稳妥。
  • 构造：时间 O(n)，空间 O(n)；每次抽取：时间 O(log n)。

替代方案

线性扫描同样正确，但每次为 O(n)。Alias Method 可做到预处理 O(n)、抽取期望 O(1)，实现更复杂，本题在最多 10⁴ 次调用下通常无需采用。

面试追问

  • 权重会动态更新？可用树状数组或线段树维护前缀和，并按累计权重查找。
  • 如何检验随机实现？进行足够多次抽样，以卡方检验或置信区间判断频率偏差，而非要求固定序列。
  • 浮点随机数有什么风险？边界舍入可能产生偏差；优先映射到离散整数票号并明确随机 API 的区间。

常见错误

  • 生成 [0,S) 的目标，却仍用“首个 ≥ target”查找，造成边界偏移。
  • 返回最后一个小于目标的前缀，而不是首个不小于目标的前缀。
  • 直接随机下标，忽略权重；或把每份权重展开成数组，导致空间达到总权重规模。

四语言完整代码

import java.util.concurrent.ThreadLocalRandom;

class Solution {
    private final long[] prefix;
    private final long total;

    public Solution(int[] w) {
        prefix = new long[w.length];
        long sum = 0;
        for (int i = 0; i < w.length; i++) {
            sum += w[i];
            prefix[i] = sum;
        }
        total = sum;
    }

    public int pickIndex() {
        long target = ThreadLocalRandom.current().nextLong(1, total + 1);
        int left = 0, right = prefix.length - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (prefix[mid] >= target) right = mid;
            else left = mid + 1;
        }
        return left;
    }
}
/** @param {number[]} w */
var Solution = function(w) {
    this.prefix = [];
    let sum = 0;
    for (const weight of w) {
        sum += weight;
        this.prefix.push(sum);
    }
    this.total = sum;
};

/** @return {number} */
Solution.prototype.pickIndex = function() {
    const target = Math.floor(Math.random() * this.total) + 1;
    let left = 0, right = this.prefix.length - 1;
    while (left < right) {
        const mid = left + Math.floor((right - left) / 2);
        if (this.prefix[mid] >= target) right = mid;
        else left = mid + 1;
    }
    return left;
};
from bisect import bisect_left
from itertools import accumulate
from random import randint
from typing import List

class Solution:
    def __init__(self, w: List[int]):
        self.prefix = list(accumulate(w))

    def pickIndex(self) -> int:
        target = randint(1, self.prefix[-1])
        return bisect_left(self.prefix, target)
class Solution {
    vector<long long> prefix;
    mt19937_64 generator;
public:
    Solution(vector<int>& w) : generator(random_device{}()) {
        long long sum = 0;
        for (int weight : w) {
            sum += weight;
            prefix.push_back(sum);
        }
    }

    int pickIndex() {
        uniform_int_distribution<long long> dist(1, prefix.back());
        long long target = dist(generator);
        return lower_bound(prefix.begin(), prefix.end(), target)
             - prefix.begin();
    }
};
