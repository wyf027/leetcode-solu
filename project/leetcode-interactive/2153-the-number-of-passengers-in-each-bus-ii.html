2153. 每辆车的乘客人数 II

The Number of Passengers in Each Bus II

一座车站，有限座位。观察每次到站后，哪些乘客上车，哪些继续等待。

阅读题意进入车站测试与验证
01 / 题目与数据

按车统计实际载客人数

给定公交车表 Buses(bus_id, arrival_time, capacity) 和乘客表 Passengers(passenger_id, arrival_time)。车到站时，所有已到站且尚未上车的乘客都可乘坐；人数超过空座数时，只搭载容量允许的人数，其余乘客继续等后车。同刻到达的乘客也可上车。

输出每辆车的 bus_id 与 passengers_cnt，包含载客为 0 的车，结果按 bus_id 升序排列。

Buses 表

字段类型含义
bus_idINT唯一车辆编号
arrival_timeINT到站时刻
capacityINT空座数量

Passengers 表

字段类型含义
passenger_idINT唯一乘客编号
arrival_timeINT到站时刻

约束与语义

  • 两张表的编号分别唯一；不同公交车的到站时刻互不相同。
  • 每辆车的容量为正整数；不同乘客可同时到站。每名乘客最多上车一次。
  • 上车条件为乘客到达时间 ≤ 车辆到达时间；公交车不会等待未来的乘客。
  • 题面未给出行数、时间、容量的具体数值上界，不额外假定范围。
  • 只要求人数，不要求确定同刻乘客的上车顺序。

04 / 独立题解

准备好后，再展开推导

SQL 主解、正确性论证与四语言本地语义参考。

核心洞察：已到达，不等于还在等

按到站时间处理第 i 辆车。Aᵢ 表示截至当前时刻到达的乘客总数，Sᵢ₋₁ 表示之前所有车已载走的总人数。站台人数恰为 Aᵢ − Sᵢ₋₁。只需维护累计上车人数，无需在 SQL 中逐个分配乘客。

S₀ = 0
本车人数 Xᵢ = min(capacityᵢ, Aᵢ − Sᵢ₋₁)
累计人数 Sᵢ = Sᵢ₋₁ + Xᵢ
             = min(Aᵢ, Sᵢ₋₁ + capacityᵢ)

完整过程

  1. 用 LEFT JOIN 和时间条件统计每车对应的 Aᵢ。COUNT(p.passenger_id) 使没有乘客的车得到 0。
  2. ROW_NUMBER 按 arrival_time 编号，确定递推顺序，不能按 bus_id 计算。
  3. 递归首行从累计 0 人开始，后续行根据上车总数计算本车载客与新累计数。
  4. 所有车处理完成后，输出 bus_id、passengers_cnt，按编号排序。

正确性

不变量：处理第 i 辆车前，Sᵢ₋₁ 正好是已离站乘客总数。初始 S₀ = 0 成立。此前上车的乘客必然已在当前时刻到达，所以 Aᵢ 减去已载人数，正好得到所有可上车且尚未上车的乘客。

容量规则要求本车接走 min(capacityᵢ, Aᵢ − Sᵢ₋₁) 人。更新累计人数后，不变量保持。归纳覆盖全部车辆，故每车人数正确。最终排序不改变计数。

边界与常见错误

  • 同刻到达要用 ≤，不能用 <。
  • 前车满载后有人滞留；只统计两车之间新来的人会漏算。
  • 前车的空座不能结转。累计载客数不能简单写成 min(累计容量, 累计到达)。
  • 无乘客时用 LEFT JOIN 保留车；COUNT(*) 会错误计入空连接行。
  • 计算按时间，输出按编号；到站时间互异，无需定义车辆的平局次序。
  • 无车返回空结果；末班车后的乘客不会被计入。空输入作为防御性边界展示。
  • 避免依赖 MySQL 用户变量在同一 SELECT 内的赋值顺序，明确表达递推依赖。

复杂度与环境限制

设 B 为车数、P 为乘客数。SQL 范围连接最坏展开 O(BP) 行；排序约 O(B log B)，递推 B 步。临时空间与聚合、排序、CTE 的具体成本取决于执行计划，不能把整条 SQL 称为线性。

四语言参考排序后用单调指针扫描：时间 O(B log B + P log P + B + P)，含复制和结果的额外空间 O(B + P)。它们不会修改调用方输入行。

主代码使用 MySQL 8.0。递归层数受 cte_max_recursion_depth 限制，车表很长时需要调整允许的递归限制或采用非递归方案。未执行数据库验证，未声称平台通过。

替代方案

非递归窗口方案：Cᵢ 为累计容量，Dᵢ = max(0, maxₖ≤ᵢ(Cₖ − Aₖ)) 为累计无法使用的空座。则 Sᵢ = Cᵢ − Dᵢ，Xᵢ = Sᵢ − Sᵢ₋₁。把前缀 SUM、前缀 MAX 与 LAG 分层放入 CTE 即可避免递归深度限制，累计容量应使用足够宽的整数。

该式由 Dᵢ = max(Dᵢ₋₁, Cᵢ − Aᵢ) 推出，与递推等价。应用程序中可直接排序加双指针。大数据可先按时间聚合乘客事件并做累计，减少范围连接展开。

面试追问

  • 多辆车同刻到达？必须补充车辆优先级，否则每车计数可能不唯一。
  • 需要每位乘客的上车编号？按时间与唯一编号排队，用相邻累计载客数划分乘客排名区间。
  • 乘客有优先级？一个计数可能不足，应维护显式候车队列或优先队列。
  • 如何优化 Aᵢ？讨论时间索引、乘客时间聚合与事件流累计，再依实际执行计划选择。

MySQL 8.0 · 官方可提交语言

WITH RECURSIVE
arrivals AS (
  SELECT b.bus_id, b.arrival_time, b.capacity,
         COUNT(p.passenger_id) AS arrived
  FROM Buses b
  LEFT JOIN Passengers p ON p.arrival_time <= b.arrival_time
  GROUP BY b.bus_id, b.arrival_time, b.capacity
),
ordered AS (
  SELECT *, ROW_NUMBER() OVER (ORDER BY arrival_time) AS rn
  FROM arrivals
),
ride (rn, bus_id, passengers_cnt, total) AS (
  SELECT rn, bus_id,
         CAST(LEAST(capacity, arrived) AS SIGNED),
         CAST(LEAST(capacity, arrived) AS SIGNED)
  FROM ordered WHERE rn = 1
  UNION ALL
  SELECT o.rn, o.bus_id,
         CAST(LEAST(o.capacity, o.arrived - r.total) AS SIGNED),
         CAST(LEAST(o.arrived, r.total + o.capacity) AS SIGNED)
  FROM ride r JOIN ordered o ON o.rn = r.rn + 1
)
SELECT bus_id, passengers_cnt FROM ride ORDER BY bus_id;

Java · 本地语义参考

import java.util.*;
public class Solution {
    // buses: [id,time,capacity]; passengers: [id,time]
    // Returns [bus_id,passengers_cnt], ordered by bus_id.
    public static int[][] numberOfPassengers(int[][] buses, int[][] passengers) {
        int[][] bs = buses.clone(), ps = passengers.clone();
        Arrays.sort(bs, Comparator.comparingInt(x -> x[1]));
        Arrays.sort(ps, Comparator.comparingInt(x -> x[1]));
        int[][] result = new int[bs.length][2];
        int arrived = 0, total = 0;
        for (int i = 0; i < bs.length; i++) {
            int[] b = bs[i];
            while (arrived < ps.length && ps[arrived][1] <= b[1]) arrived++;
            int count = Math.min(b[2], arrived - total);
            total += count;
            result[i] = new int[]{b[0], count};
        }
        Arrays.sort(result, Comparator.comparingInt(x -> x[0]));
        return result;
    }
}

JavaScript · 本地语义参考

// buses: [id,time,capacity][]; passengers: [id,time][]
// Returns [bus_id,passengers_cnt][] ordered by bus_id.
function numberOfPassengers(buses, passengers) {
  const bs = [...buses].sort((a,b) => a[1]-b[1]);
  const ps = [...passengers].sort((a,b) => a[1]-b[1]);
  let arrived = 0, total = 0;
  const result = [];
  for (const [id,time,capacity] of bs) {
    while (arrived < ps.length && ps[arrived][1] <= time) arrived++;
    const count = Math.min(capacity, arrived-total);
    total += count;
    result.push([id,count]);
  }
  return result.sort((a,b) => a[0]-b[0]);
}

Python · 本地语义参考

def number_of_passengers(buses: list[list[int]],
                         passengers: list[list[int]]) -> list[list[int]]:
    """buses=[id,time,capacity], passengers=[id,time].
    Return [bus_id,passengers_cnt] rows ordered by bus_id.
    """
    bs = sorted(buses, key=lambda row: row[1])
    ps = sorted(passengers, key=lambda row: row[1])
    arrived = total = 0
    result = []
    for bus_id, time, capacity in bs:
        while arrived < len(ps) and ps[arrived][1] <= time:
            arrived += 1
        count = min(capacity, arrived - total)
        total += count
        result.append([bus_id, count])
    return sorted(result)

C++17 · 本地语义参考

#include <algorithm>
#include <array>
#include <vector>
using namespace std;
class Solution {
public:
    // buses: {id,time,capacity}; passengers: {id,time}
    // Returns {bus_id,passengers_cnt}, ordered by bus_id.
    vector<array<int,2>> numberOfPassengers(
        vector<array<int,3>> buses, vector<array<int,2>> passengers) {
        sort(buses.begin(), buses.end(),
             [](const auto& a, const auto& b) { return a[1] < b[1]; });
        sort(passengers.begin(), passengers.end(),
             [](const auto& a, const auto& b) { return a[1] < b[1]; });
        size_t arrived = 0, total = 0;
        vector<array<int,2>> result;
        for (const auto& b : buses) {
            while (arrived < passengers.size() &&
                   passengers[arrived][1] <= b[1]) ++arrived;
            size_t count = min(static_cast<size_t>(b[2]), arrived-total);
            total += count;
            result.push_back({b[0],static_cast<int>(count)});
        }
        sort(result.begin(), result.end());
        return result;
    }
};
