所有子字符串中的元音

Vowels of All Substrings

同一个元音，会出现在多少段连续文字里？

先理解计数对象，再展开底部题解探索。无需联网，双击即可阅读。

01 / 题目

给定字符串 word，把它的每一个非空连续子字符串分别取出，计算每段中元音的个数，再把这些个数相加并返回。元音仅包括 a、e、i、o、u。

不同位置的子字符串即使内容相同，也要分别计数；同一子字符串里的多个元音也要逐个计入。这里求的是元音出现次数之和，而不是“含元音的子字符串数量”。

参数与约束
  • 参数：word: string；返回值：整数总和。
  • 1 ≤ word.length ≤ 10⁵。
  • word 仅含小写英文字母。
  • 答案可能超出有符号 32 位整数范围，计算过程中也需要避免溢出。

02 / 官方示例

示例 1

输入：word = "aba"
输出：6

按位置枚举为 a、ab、aba、b、ba、a。各自元音数为 1、1、2、0、1、1，总和为 6；两个 a 分别属于不同位置。

示例 2

输入：word = "abc"
输出：3

a、ab、abc 各含 1 个元音；b、bc、c 各含 0 个元音，总和为 3。

示例 3

输入：word = "ltcd"
输出：0

整个字符串没有元音，因此任何子字符串的元音数都是 0。

示例 4 · 中文官方题面

输入：word = "noosabasboosa"
输出：237

将所有非空连续子字符串中的元音数相加，结果为 237。

04 / 准备好再揭晓

题解包含可操作的计数模型、证明和四种语言的提交代码。

题解 / 从枚举子串到统计位置贡献

核心洞察

换一个求和顺序：固定一个元音位置 i（从 0 开始），统计有多少个子字符串包含它。左端点可选 0…i，共 i + 1 个；右端点可选 i…n − 1，共 n − i 个。左右选择独立，每一对端点确定唯一子字符串。

贡献(i) = (i + 1) × (n − i)

只把元音位置的贡献相加；辅音贡献为 0。一个子字符串若有两个元音，被不同元音各计一次正好符合题意。

完整过程

  1. 令字符串长度为 n，初始化总和 ans = 0。
  2. 从左到右遍历 i = 0…n − 1。
  3. 如果 word[i] 是元音，就把 (i + 1) × (n − i) 加入 ans。
  4. 扫描结束后返回 ans。

以 word = "aba" 为例：位置 0 的 a 贡献 1 × 3 = 3；位置 1 的 b 贡献 0；位置 2 的 a 贡献 3 × 1 = 3，最终答案为 6。

正确性证明

考虑所有二元对象“一个子字符串以及其中的一个元音位置”。题目答案恰好等于这些对象的数量。固定元音位置 i，每个合法对象满足 0 ≤ L ≤ i ≤ R < n。左端点有 i + 1 种，右端点有 n − i 种，且任意组合都合法，因此对象数量为二者乘积。

不同元音位置对应的对象互不相同，而每个需要计数的元音出现都属于某个位置。对所有元音位置求和既无遗漏，也不重复计算同一个对象，所以返回值正确。

边界与数值范围

  • 长度为 1：元音返回 1，辅音返回 0。
  • 没有元音：没有任何贡献，返回 0。
  • 重复元音：按位置分别统计，不能先去重。
  • 全部为元音时答案最大：n(n + 1)(n + 2) / 6。n = 100000 时为 166671666700000。
  • Java 使用 long，且乘法前转为 long；C++ 使用 long long 并以 1LL 开始乘法。Python 整数自动扩展。JavaScript Number 的精确整数上限为 2⁵³ − 1，大于本题最大值，足够使用。

复杂度

时间 O(n)：遍历一次，每次在固定的 5 个元音里判断。额外空间 O(1)：只保存索引、长度和累计值。实验台为展示端点而生成矩阵，它的开销不属于提交算法。

替代方案

按右端点做动态规划：令 ending 为“以当前索引结尾的全部子串的元音数总和”。旧子串追加当前字符会继承原有元音；若当前字符为元音，它出现在新增的 i + 1 个后缀子串中，因此 ending += i + 1。每轮再执行 ans += ending。这同样是 O(n) 时间、O(1) 空间，适合流式处理。

枚举区间：固定左端点，向右移动并维护区间元音数，再累加，可做到 O(n²) 时间、O(1) 空间。前缀和也可在 O(1) 时间查询一段的元音数，但仍要枚举 O(n²) 个区间；对 10⁵ 规模不合适。

Java

class Solution {
    public long countVowels(String word) {
        int n = word.length();
        long ans = 0;
        for (int i = 0; i < n; i++) {
            if ("aeiou".indexOf(word.charAt(i)) >= 0) {
                ans += (long) (i + 1) * (n - i);
            }
        }
        return ans;
    }
}

C++

#include <string>
using namespace std;

class Solution {
public:
    long long countVowels(string word) {
        int n = static_cast<int>(word.size());
        long long ans = 0;
        const string vowels = "aeiou";
        for (int i = 0; i < n; ++i) {
            if (vowels.find(word[i]) != string::npos) {
                ans += 1LL * (i + 1) * (n - i);
            }
        }
        return ans;
    }
};

常见错误

  • 把结果算成“包含至少一个元音的子串数”；例如 aba 应贡献 2 次元音出现。
  • 把 i + 1 写成 i，或把 n − i 写成 n − i − 1，遗漏包含当前位置作为端点的情况。
  • 先用 int 相乘再赋值到 long：溢出已经发生，必须提前提升类型。
  • 对字符串内容去重，丢失不同位置的同内容子串。
  • 生成全部子串后再逐字符计数，最坏 O(n³)，无法处理上限。

面试追问

元音带权重怎么办？把每个元音的贡献再乘该字符权重，并重新评估数值范围。

字符逐个到达，长度未知怎么办？用上面的 ending 动态规划，无需预先知道 n。

只统计长度恰好 k 的子串呢？对于位置 i，合法左端点范围是 [max(0, i − k + 1), min(i, n − k)]，贡献是这个整数区间的长度，若为空则为 0。

改成统计含元音子串数量呢？这是不同问题，可用全部子串数减去各段连续辅音产生的子串数；原来的按元音求和会把多元音子串重复计入。
