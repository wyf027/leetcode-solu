Problem 648 · Replace Words

单词替换

一句话里，每个长单词都可能藏着一个更短的来源。你的任务，是找到能形成它的最短词根，并保持句子原有的节奏。

01 · Problem

题意与输入输出

准确转述

词根可以作为某个更长单词的开头，并与后续字母共同形成衍生词。例如，词根 help 可以形成 helpful。

给定由若干小写词根组成的 dictionary，以及由单个空格分隔单词的 sentence。对句中每个单词，如果它以词典里的一个或多个词根开头，就把它替换成其中长度最短的词根；如果没有匹配词根，则保留原单词。返回替换后的完整句子。

replaceWords(dictionary: List<string>, sentence: string) -> string
参数 1：dictionary，字符串数组，每项是一个词根。
参数 2：sentence，由小写单词和单个空格组成的句子。
返回：完成最短词根替换后的字符串。

约束

  • 1 <= dictionary.length <= 1000
  • 1 <= dictionary[i].length <= 100
  • dictionary[i] 仅含小写英文字母。
  • 1 <= sentence.length <= 10^6
  • sentence 仅含小写字母与空格。
  • 句中单词数量为 [1, 1000]。
  • 每个单词长度为 [1, 1000]。
  • 相邻单词间恰有一个空格。
  • 句子没有前导或尾随空格。
官方示例 1
输入：dictionary = ["cat","bat","rat"],
      sentence = "the cattle was rattled by the battery"
输出："the cat was rat by the bat"
官方示例 2
输入：dictionary = ["a","b","c"],
      sentence = "aadsfasf absbs bbab cadsfafs"
输出："a a b c"

Solution · Keep folded until needed

准备好核对思路了吗？

Core insight

题解：让最早到达的词根胜出

核心洞察：需要匹配的是单词的前缀，而且一旦遇到最短可用词根，后面更长的前缀就不可能成为更优答案。字典树把公共前缀合并；从单词首字母向后走，第一次到达“词根结尾”节点时立即返回。

  1. 建树：把 dictionary 中每个词根逐字符插入字典树，并在词根最后一个节点标记结束。
  2. 拆句：按空格把 sentence 分成单词。
  3. 逐词扫描：从字典树根节点出发，依次跟随当前单词的字符。
  4. 提前停止：若下一条边不存在，原词没有可用词根，保留原词；若当前节点是词根结尾，立刻返回已经扫描的前缀。
  5. 重组：使用单个空格连接每个处理结果。

正确性证明

引理 1：扫描单词前 k 个字符后所在的节点，恰好表示该长度为 k 的前缀。因为每一步都沿对应字符边移动，按字典树定义成立。

引理 2：扫描时遇到的第一个结束节点代表所有可用词根中最短者。扫描长度严格递增，因此更早遇到的结束节点长度更小。

定理：算法对每个单词返回题目要求的替换结果。若遇到第一个结束节点，由引理 1 它确为该单词前缀，由引理 2 它最短；若路径中断或扫描结束仍未遇到结束节点，则不存在词典中的前缀词根，保留原词正确。逐词结果正确，按原顺序连接后整个句子正确。

复杂度与边界

设所有词根字符总数为 D，句子中所有单词字符总数为 S。

  • 建树时间：O(D)
  • 处理句子时间：O(S)，提前命中时通常更少
  • 额外空间：O(D)，不计输出字符串

边界：词根本身作为单词时应保留；无匹配时保留原词；多个词根都匹配时返回最短者；单字符词根可以立即截断；重复词根不会改变结果。

class Solution {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean isRoot;
    }

    public String replaceWords(List<String> dictionary, String sentence) {
        TrieNode trie = new TrieNode();
        for (String root : dictionary) {
            insert(trie, root);
        }

        String[] words = sentence.split(" ");
        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < words.length; i++) {
            if (i > 0) answer.append(' ');
            answer.append(shortestRoot(trie, words[i]));
        }
        return answer.toString();
    }

    private void insert(TrieNode trie, String root) {
        TrieNode node = trie;
        for (char ch : root.toCharArray()) {
            int index = ch - 'a';
            if (node.children[index] == null) {
                node.children[index] = new TrieNode();
            }
            node = node.children[index];
        }
        node.isRoot = true;
    }

    private String shortestRoot(TrieNode trie, String word) {
        TrieNode node = trie;
        for (int i = 0; i < word.length(); i++) {
            int index = word.charAt(i) - 'a';
            if (node.children[index] == null) return word;
            node = node.children[index];
            if (node.isRoot) return word.substring(0, i + 1);
        }
        return word;
    }
}

var replaceWords = function(dictionary, sentence) {
    const trie = new Map();
    const END = Symbol("rootEnd");

    for (const root of dictionary) {
        let node = trie;
        for (const ch of root) {
            if (!node.has(ch)) node.set(ch, new Map());
            node = node.get(ch);
        }
        node.set(END, true);
    }

    const shortestRoot = (word) => {
        let node = trie;
        let prefix = "";

        for (const ch of word) {
            if (!node.has(ch)) return word;
            node = node.get(ch);
            prefix += ch;
            if (node.has(END)) return prefix;
        }
        return word;
    };

    return sentence.split(" ").map(shortestRoot).join(" ");
};
class Solution:
    def replaceWords(self, dictionary: List[str], sentence: str) -> str:
        trie = {}
        end = "#"

        for root in dictionary:
            node = trie
            for ch in root:
                node = node.setdefault(ch, {})
            node[end] = True

        def shortest_root(word: str) -> str:
            node = trie
            prefix = []

            for ch in word:
                if ch not in node:
                    return word
                node = node[ch]
                prefix.append(ch)
                if end in node:
                    return "".join(prefix)
            return word

        return " ".join(shortest_root(word) for word in sentence.split(" "))
class Solution {
    struct TrieNode {
        array<TrieNode*, 26> children{};
        bool isRoot = false;

        ~TrieNode() {
            for (TrieNode* child : children) delete child;
        }
    };

    void insert(TrieNode& trie, const string& root) {
        TrieNode* node = &trie;
        for (char ch : root) {
            int index = ch - 'a';
            if (node->children[index] == nullptr) {
                node->children[index] = new TrieNode();
            }
            node = node->children[index];
        }
        node->isRoot = true;
    }

    string shortestRoot(TrieNode& trie, const string& word) {
        TrieNode* node = &trie;
        for (int i = 0; i < static_cast<int>(word.size()); ++i) {
            int index = word[i] - 'a';
            if (node->children[index] == nullptr) return word;
            node = node->children[index];
            if (node->isRoot) return word.substr(0, i + 1);
        }
        return word;
    }

public:
    string replaceWords(vector<string>& dictionary, string sentence) {
        TrieNode trie;
        for (const string& root : dictionary) insert(trie, root);

        istringstream input(sentence);
        ostringstream output;
        string word;
        bool first = true;

        while (input >> word) {
            if (!first) output << ' ';
            output << shortestRoot(trie, word);
            first = false;
        }
        return output.str();
    }
};

替代方案：哈希集合

把所有词根放进哈希集合。对每个单词，从长度 1 开始枚举它的前缀，第一次命中集合就替换。

实现更短，也自然保证最短词根；但频繁构造前缀可能带来额外开销。若单词最大长度较小或更看重代码简洁，它是很实用的选择。

面试追问

  • 词典特别大时，如何压缩字典树或使用紧凑数组？
  • 词典支持动态增删时，节点如何维护引用计数？
  • 句子以数据流到达时，如何逐词处理并输出？
  • 扩展到 Unicode 与大小写时，节点结构如何调整？

常见错误清单

  • 找到匹配后仍继续扫描，最终错误地选到更长词根。
  • 只判断完整单词是否在词典中，遗漏“词根是前缀”的核心条件。
  • 路径中断后返回已经扫描的部分，而不是保留原单词。
  • 拼接答案时多出首尾空格，或破坏题目要求的单空格格式。
  • JavaScript 使用普通对象却未谨慎处理原型键；使用 Map 更直接。
