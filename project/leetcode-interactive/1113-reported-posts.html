任务

表 Actions 记录用户对帖子的行为。对每个发生垃圾内容举报的日期，统计当天被举报为 spam 的不同帖子数量。

输出 report_date 与 report_count，顺序不限。同一帖子在同一天被多个用户举报也只计算一次。

表结构与约束

Actions(
  user_id     INT,
  post_id     INT,
  action_date DATE,
  action      ENUM('view','like','reaction',
                   'comment','report','share'),
  extra       VARCHAR(10)
)

当行为为 report 时，extra 表示举报原因；只保留 extra = spam。输出日期直接来自 action_date。

核心洞察

计数单位不是举报行或用户，而是“同一天内不同的 post_id”。先限定 action='report' 且 extra='spam'，再按日期分组并使用 COUNT(DISTINCT post_id)。

完整过程

  1. WHERE 丢弃浏览、点赞及其他举报原因。
  2. GROUP BY action_date 建立每日分组。
  3. COUNT(DISTINCT post_id) 消除重复举报。
  4. 设置题目要求的列别名。

正确性

筛选后留下且仅留下垃圾举报；每行进入自身日期的唯一分组。组内 distinct 集合恰好包含当天至少被垃圾举报一次的帖子，因此集合大小就是所求计数。

边界与复杂度

  • 同帖同日多次举报：一次。
  • 同帖不同日期举报：各计一次。
  • 只有非 spam 举报的日期：不输出。
  • 空表：空结果。

概念上扫描 O(n)，哈希分组与去重空间最坏 O(n)；实际取决于数据库执行计划和索引。

替代方案

子查询先选出不同的 action_date, post_id，外层按日期 COUNT(*)，语义清晰但更冗长。普通 COUNT 会把重复举报重复计数。

面试追问与常见错误

  • 统计举报用户数：distinct user_id。
  • 输出零举报日期：日期维表左连接。
  • 遗漏 extra='spam' 会混入其他原因。
  • COUNT(*) 会重复计数。
  • 按 post_id 分组会改变输出粒度。

SELECT action_date AS report_date,
       COUNT(DISTINCT post_id) AS report_count
FROM Actions
WHERE action = 'report' AND extra = 'spam'
GROUP BY action_date;
import java.util.*;
record Action(int userId,int postId,String date,String action,String extra){}
class Solution {
  static Map<String,Integer> reportedPosts(List<Action> rows) {
    Map<String,Set<Integer>> groups=new TreeMap<>();
    for(Action r:rows)
      if("report".equals(r.action()) && "spam".equals(r.extra()))
        groups.computeIfAbsent(r.date(),k->new HashSet<>()).add(r.postId());
    Map<String,Integer> out=new LinkedHashMap<>();
    groups.forEach((date,posts)->out.put(date,posts.size()));
    return out;
  }
}
function reportedPosts(actions) {
  const groups = new Map();
  for (const r of actions) {
    if (r.action !== "report" || r.extra !== "spam") continue;
    if (!groups.has(r.action_date)) groups.set(r.action_date, new Set());
    groups.get(r.action_date).add(r.post_id);
  }
  return [...groups].sort(([a],[b]) => a.localeCompare(b))
    .map(([report_date, posts]) => ({report_date, report_count: posts.size}));
}
from collections import defaultdict
def reported_posts(actions):
    groups = defaultdict(set)
    for row in actions:
        if row["action"] == "report" and row["extra"] == "spam":
            groups[row["action_date"]].add(row["post_id"])
    return [{"report_date": d, "report_count": len(groups[d])}
            for d in sorted(groups)]
#include <map>
#include <set>
#include <string>

struct Action { int userId,postId; string date,action,extra; };
vector<pair<string,int>> reportedPosts(const vector<Action>& rows) {
  map<string,set<int>> groups;
  for (const auto& r:rows)
    if (r.action=="report" && r.extra=="spam") groups[r.date].insert(r.postId);
  vector<pair<string,int>> out;
  for (const auto& [date,posts]:groups) out.push_back({date,(int)posts.size()});
  return out;
}
