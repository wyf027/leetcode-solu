得分最高的单词集合

一盒数量有限的字母、一组候选单词，以及每个字母各自的价值。你的任务，是找到能被真实拼出的最高分组合。

HARD数组字符串回溯位掩码
先读规则，不剧透答案
Problem brief

把字母当成不可重复消耗的资源

给定候选单词 words、可重复出现的字母数组 letters，以及从 a 到 z 的 26 个字母分值 score。从候选单词中选出一个子集，使其所有字母均能由给定字母提供，并最大化总分。

规则

  1. 1每个 words[i] 最多选择一次，也可以一个都不选。
  2. 2letters 中的每个字母实例最多使用一次；相同字符出现几次，就最多可消耗几次。
  3. 3不要求用完所有字母；所选单词中的每个字符都必须有库存。
  4. 4字符 'a'...'z' 的分值依次为 score[0]...score[25]。

函数签名

maxScoreWords(words: string[], letters: character[], score: integer[]) → integer

一眼看懂

集合中的分数，是所有被选择单词里每个字母的分值之和。某个高分单词可能会抢走多个低分单词共同需要的稀缺字母，因此不能只按单词分数贪心。

返回值

所有合法单词子集中的最大总分，类型为整数。

1 ≤ words[i].length ≤ 15
1 ≤ letters.length ≤ 100
letters[i].length == 1
score.length == 26
0 ≤ score[i] ≤ 10
words[i] 仅含小写英文字母
letters[i] 仅含小写英文字母

准备好看完整题解了吗？

下面会揭示搜索结构、剪枝、正确性证明，以及四种语言的完整实现。

Core insight

核心洞察：每个单词只有选或不选

因为 words.length ≤ 14，最多只有 2¹⁴ = 16384 个子集。用深度优先搜索枚举每个单词的“跳过 / 选择”，并用 26 位计数数组维护剩余字母。当库存不够时，直接放弃选择分支。

01
预处理单词

计算每个单词的 26 字母需求量和单词分值。

02
二叉决策

位置 i 分成“不选 words[i]”和“库存足够则选择”两支。

03
原地回溯

选择时扣减库存，递归返回后加回来，供其他分支复用。

完整过程

  1. 1统计 letters，得到长度为 26 的初始库存 available。
  2. 2为每个单词预计算需求数组 need[i] 与分数 wordScore[i]，避免在递归中重复扫描字符。
  3. 3定义 dfs(i)：返回从下标 i 开始、在当前库存下能取得的最高附加分。
  4. 4先计算跳过当前单词的结果；若当前库存覆盖全部需求，则扣减库存，计算选择分支，再恢复库存。
  5. 5两条合法分支取最大值。到达数组末尾时返回 0。

正确性证明

覆盖全部候选集合

对每个下标 i，算法分别考虑不选择与选择 words[i]。因此每条根到叶路径唯一对应一个单词子集，所有子集都会被覆盖。

只计算合法集合

选择分支只在剩余库存逐字母覆盖当前单词需求时进入；进入后准确扣减需求。所以任何被计分的路径都不会重复使用字母。

取到最优值

任意最优合法集合都对应某条被枚举的合法路径。每一层对两个可能分支取最大值，归纳可知 dfs(0) 等于所有合法集合中的最大分数。

库存恢复正确

选择分支返回后将同一需求数组加回，使兄弟分支看到与进入本层前完全相同的库存，不会相互污染。

边界与复杂度

时间复杂度O(2ⁿ · 26 + L)

n 为单词数，L 为所有单词和 letters 的字符总量；每个决策节点最多检查 26 种字母。

空间复杂度O(n · 26)

预处理需求占 O(n·26)，递归栈为 O(n)；原地库存避免为每个分支复制数组。

必须照顾的边界

空集合总是合法，因此答案至少为 0；零分字母仍会消耗库存；重复单词若位于不同下标，仍是两个独立候选；一个单词需求不足时只能剪掉“选择”分支，不能终止整棵搜索。

JavaLeetCode signature
class Solution {
    private int[][] needs;
    private int[] wordScores;
    private int[] available;

    public int maxScoreWords(String[] words, char[] letters, int[] score) {
        int n = words.length;
        needs = new int[n][26];
        wordScores = new int[n];
        available = new int[26];

        for (char ch : letters) available[ch - 'a']++;
        for (int i = 0; i < n; i++) {
            for (char ch : words[i].toCharArray()) {
                int index = ch - 'a';
                needs[i][index]++;
                wordScores[i] += score[index];
            }
        }
        return dfs(0);
    }

    private int dfs(int index) {
        if (index == needs.length) return 0;

        int best = dfs(index + 1);
        boolean canTake = true;
        for (int c = 0; c < 26; c++) {
            if (needs[index][c] > available[c]) {
                canTake = false;
                break;
            }
        }
        if (canTake) {
            for (int c = 0; c < 26; c++) available[c] -= needs[index][c];
            best = Math.max(best, wordScores[index] + dfs(index + 1));
            for (int c = 0; c < 26; c++) available[c] += needs[index][c];
        }
        return best;
    }
}

var maxScoreWords = function(words, letters, score) {
    const available = new Array(26).fill(0);
    for (const ch of letters) available[ch.charCodeAt(0) - 97]++;

    const needs = words.map(() => new Array(26).fill(0));
    const wordScores = new Array(words.length).fill(0);
    for (let i = 0; i < words.length; i++) {
        for (const ch of words[i]) {
            const c = ch.charCodeAt(0) - 97;
            needs[i][c]++;
            wordScores[i] += score[c];
        }
    }

    function dfs(index) {
        if (index === words.length) return 0;
        let best = dfs(index + 1);
        let canTake = true;
        for (let c = 0; c < 26; c++) {
            if (needs[index][c] > available[c]) {
                canTake = false;
                break;
            }

            for (let c = 0; c < 26; c++) available[c] -= needs[index][c];
            best = Math.max(best, wordScores[index] + dfs(index + 1));
            for (let c = 0; c < 26; c++) available[c] += needs[index][c];

        return best;

    return dfs(0);

class Solution:
    def maxScoreWords(self, words: List[str], letters: List[str], score: List[int]) -> int:
        available = [0] * 26
        for ch in letters:
            available[ord(ch) - ord('a')] += 1

        needs = [[0] * 26 for _ in words]
        word_scores = [0] * len(words)
        for i, word in enumerate(words):
            for ch in word:
                c = ord(ch) - ord('a')
                needs[i][c] += 1
                word_scores[i] += score[c]

        def dfs(index: int) -> int:
            if index == len(words):
                return 0

            best = dfs(index + 1)
            can_take = all(needs[index][c] <= available[c] for c in range(26))
            if can_take:
                for c in range(26):
                    available[c] -= needs[index][c]
                best = max(best, word_scores[index] + dfs(index + 1))
                for c in range(26):
                    available[c] += needs[index][c]
            return best

        return dfs(0)

class Solution {
    vector<array<int, 26>> needs;
    vector<int> wordScores;
    array<int, 26> available{};

    int dfs(int index) {
        if (index == static_cast<int>(needs.size())) return 0;

        int best = dfs(index + 1);
        bool canTake = true;
        for (int c = 0; c < 26; ++c) {
            if (needs[index][c] > available[c]) {
                canTake = false;
                break;
            }
        }
        if (canTake) {
            for (int c = 0; c < 26; ++c) available[c] -= needs[index][c];
            best = max(best, wordScores[index] + dfs(index + 1));
            for (int c = 0; c < 26; ++c) available[c] += needs[index][c];
        }
        return best;
    }

public:
    int maxScoreWords(vector<string>& words, vector<char>& letters,
                      vector<int>& score) {
        for (char ch : letters) available[ch - 'a']++;
        needs.resize(words.size());
        wordScores.assign(words.size(), 0);

        for (int i = 0; i < static_cast<int>(words.size()); ++i) {
            needs[i].fill(0);
            for (char ch : words[i]) {
                int c = ch - 'a';
                needs[i][c]++;
                wordScores[i] += score[c];
            }
        }
        return dfs(0);
    }
};

替代方案

位掩码枚举

遍历 0...(1<<n)-1，对每个子集重新累计字母需求并判断合法。逻辑直接，但朴素实现会重复扫描单词，时间可达 O(2ⁿ·L)。

复制库存的回溯

每次选择时复制一份 26 长数组，写法更不易忘记恢复，但会增加大量小数组分配。面试中可先写清楚版本，再优化为原地回溯。

常见错误

按单词分数贪心

最高分的单词可能占用稀缺字母，阻止多个单词形成更高总分。

忘记恢复库存

回溯返回后不加回字母，会让后续兄弟分支继承错误状态。

库存不足就整体返回

只能跳过当前单词继续搜索；后面的单词仍可能可选。

把零分字母当成免费

零分只代表不贡献分数，它仍是数量有限的必要资源。

面试追问

为什么不用动态规划记忆化？

状态不仅包含下标，还包含 26 种剩余字母数量；编码这个高维状态的成本不低。n 最多 14，直接枚举 2ⁿ 已足够。若字母种类很少或库存状态重复很多，记忆化才更有吸引力。

能否进一步剪枝？

可以预计算后缀所有单词分值之和作为乐观上界；若“当前分 + 上界”不超过历史最佳，就可停止该分支。也可先过滤任何单独都无法组成的单词。

如果每个单词可无限次使用呢？

问题会变为受字母库存约束的无界组合优化，原先按下标二选一不再适用；需要继续选择同一项或使用状态压缩 / 多维背包思路。

若 score 中允许负数呢？

空集合仍提供 0 分，因此负贡献单词不必选择。当前搜索仍正确；可以预先丢弃总分为负且不会解锁其他收益的单词，因为单词之间没有额外组合奖励。
