数组的度
Degree of an Array

Problem

题目要求

给定一个非空、仅含非负整数的数组 nums。数组的度是任一元素在整个数组中出现次数的最大值。

请从 nums 中选出一个连续子数组，使它的度与原数组相同，并返回所有满足条件的连续子数组中的最短长度。

示例 1

输入：nums = [1,2,2,3,1]
输出：2
解释：整个数组的度为 2；
最短的同度连续子数组是 [2,2]。

示例 2

输入：nums = [1,2,2,3,1,4,2]
输出：6
解释：元素 2 出现 3 次；
最短的同度连续子数组是 [2,2,3,1,4,2]。
约束
  • 1 ≤ nums.length ≤ 50,000
  • 0 ≤ nums[i] ≤ 49,999
  • 返回值类型：integer

Full Solution

一次扫描：计数 + 首末位置

核心洞察

设某个数字 x 的出现次数等于整个数组的度。任何与原数组同度的连续子数组若依靠 x 达到这个度，就必须包含 x 的全部出现位置；因此它至少覆盖 x 的第一次出现到最后一次出现。

答案 = min(last[x] − first[x] + 1)，其中 count[x] = degree

所以只需为每个值记录三个信息：出现次数 count、首次位置 first、末次位置 last。

完整过程

  1. 从左到右扫描数组。
  2. 第一次看到一个值时，记下当前下标为 first。
  3. 每次更新它的 count 与 last。
  4. 若新计数超过当前度，更新度并把答案设为该值的跨度。
  5. 若新计数恰好等于当前度，用该值跨度缩小答案。

边界情况

  • 只有一个元素：度为 1，答案为 1。
  • 所有元素互不相同：任意单元素子数组同度，答案为 1。
  • 所有元素相同：必须保留整个数组。
  • 多个值并列最高频：比较它们的首末跨度，取最小值。

正确性证明

  1. 候选区间足够：对任意满足 count[x] = degree 的值 x，区间 [first[x], last[x]] 包含 x 的全部出现次数，因此该区间的度至少等于原数组的度；它又不可能超过原数组的度，所以二者相等。
  2. 候选区间最短：任何依靠 x 达到同样度的连续子数组都必须包含 x 的第一次和最后一次出现，因此长度不小于 last[x] - first[x] + 1。
  3. 全局最优：任意同度子数组中必有某个值出现了 degree 次；该值在原数组中也是最高频值。算法枚举了所有这类值的最短必要跨度并取最小，因此所得答案不大于任何可行解，同时自身可行，故为最优解。

复杂度

时间：O(n)，每个元素只处理一次。

空间：O(k)，其中 k 是不同元素个数；最坏为 O(n)。

替代方案

也可以先完整统计所有值的频率、首次和末次位置，再进行第二次遍历筛选最高频值。仍是 O(n) 时间、O(k) 空间，逻辑更分离；单次扫描则能在更新度时同步维护答案。

排序会破坏原下标关系，除非额外携带位置；复杂度也会升至 O(n log n)，没有必要。

面试追问

  • 如果要求返回最短子数组本身，如何记录左右端点？
  • 若并列时还要选择起点最小的区间，更新规则怎么改？
  • 若数据流无法一次保存在内存中，哪些信息仍可在线维护？
  • 已知值域固定在 [0, 49999]，能否用数组替代哈希表？代价是什么？

常见错误

  • 只统计频率，没有记录首末位置。
  • 把子数组误当成可以跳过元素的子序列。
  • 跨度忘记加一：应为 last - first + 1。
  • 出现并列最高频时覆盖答案，而不是取更小跨度。
  • 初始化答案为 0，导致后续 min 永远错误。

四种语言完整实现

均遵循官方函数签名，使用一次扫描同步维护当前度与最短跨度。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int findShortestSubArray(int[] nums) {
        Map<Integer, Integer> count = new HashMap<>();
        Map<Integer, Integer> first = new HashMap<>();

        int degree = 0;
        int shortest = nums.length;

        for (int i = 0; i < nums.length; i++) {
            int value = nums[i];
            first.putIfAbsent(value, i);

            int frequency = count.getOrDefault(value, 0) + 1;
            count.put(value, frequency);
            int span = i - first.get(value) + 1;

            if (frequency > degree) {
                degree = frequency;
                shortest = span;
            } else if (frequency == degree) {
                shortest = Math.min(shortest, span);
            }
        }

        return shortest;
    }
}

var findShortestSubArray = function(nums) {
    const count = new Map();
    const first = new Map();

    let degree = 0;
    let shortest = nums.length;

    for (let i = 0; i < nums.length; i++) {
        const value = nums[i];
        if (!first.has(value)) {
            first.set(value, i);
        }

        const frequency = (count.get(value) || 0) + 1;
        count.set(value, frequency);
        const span = i - first.get(value) + 1;

        if (frequency > degree) {
            degree = frequency;
            shortest = span;
        } else if (frequency === degree) {
            shortest = Math.min(shortest, span);
        }
    }

    return shortest;
};
from typing import List


class Solution:
    def findShortestSubArray(self, nums: List[int]) -> int:
        count = {}
        first = {}

        degree = 0
        shortest = len(nums)

        for index, value in enumerate(nums):
            if value not in first:
                first[value] = index

            count[value] = count.get(value, 0) + 1
            frequency = count[value]
            span = index - first[value] + 1

            if frequency > degree:
                degree = frequency
                shortest = span
            elif frequency == degree:
                shortest = min(shortest, span)

        return shortest
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int findShortestSubArray(vector<int>& nums) {
        unordered_map<int, int> count;
        unordered_map<int, int> first;

        int degree = 0;
        int shortest = static_cast<int>(nums.size());

        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            int value = nums[i];
            if (!first.count(value)) {
                first[value] = i;
            }

            int frequency = ++count[value];
            int span = i - first[value] + 1;

            if (frequency > degree) {
                degree = frequency;
                shortest = span;
            } else if (frequency == degree) {
                shortest = min(shortest, span);
            }
        }

        return shortest;
    }
};
