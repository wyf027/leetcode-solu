Interview 01.08 · Signal control matrix

让一个零封锁整条行列

矩阵中的零会向所在行与列传播。把首行和首列改造成“信号总线”，就能原地记录所有待清零区域，不再额外申请 M + N 个标记。

面试题 01.08 中等 原地标记 · O(1) 空间

题意：零值触发行列清零

给定 M × N 整数矩阵 matrix，若某元素为 0，将它所在的整行与整列全部改为 0；必须原地修改。

官方示例 1

输入 matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出 matrix = [[1,0,1],[0,0,0],[1,0,1]]

官方示例 2

输入 matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出 matrix = [[0,0,0,0],[0,4,5,0],[0,3,1,0]]

接口契约

官方函数名为 setZeroes，返回 void；结果通过参数 matrix 本身输出。不能只构造并返回一份新矩阵。

展示约定

所有输入都以“参数名 = 值”完整展示。若字符串含空格，本页会用 ␠ 标记；本题参数为二维整数数组，不含字符串。

行列信号传播台

虚线单元格是首行/首列信号总线。逐步观察“发现零 → 写标记 → 执行清零”。

步骤 1 / 5

题解隔离舱

核心洞察、证明、复杂度与四语言代码默认隐藏，准备好后再解除隔离。

核心洞察

用 matrix[i][0] 标记第 i 行，用 matrix[0][j] 标记第 j 列。首行首列既是数据又是标记区，所以先用两个布尔值保存它们自身是否需要清零。

matrix[i][j] == 0
⇒ matrix[i][0] = 0
⇒ matrix[0][j] = 0

完整过程

  1. 扫描首行与首列，保存 firstRowZero、firstColZero。
  2. 扫描内部区域；遇到零，只在对应首行/首列单元写零标记。
  3. 再次扫描内部区域，根据两个标记清零。
  4. 最后依据两个布尔值处理首行与首列。

边界

  • 1 × 1、1 × N、M × 1 都能由首行/首列标志覆盖。
  • 首元素 matrix[0][0] 同时属于首行首列，不能只靠它保存两个状态。
  • 没有零时矩阵保持不变；全零时所有标记自然生效。

复杂度

时间复杂度 O(MN)：常数轮扫描整个矩阵。额外空间复杂度 O(1)：只保存两个布尔标志与循环变量。

替代方案

使用两个集合记录待清零行列最直观，时间仍为 O(MN)，但需要 O(M + N) 空间。逐个零立即清行列会让新零继续传播，除非先用特殊哨兵值标记，容易与合法数据冲突。

面试追问

  • 为什么必须先保存首行首列状态，再修改标记区？
  • 能否把第二轮清零改为从右下角逆序扫描？
  • 矩阵存于磁盘、无法随机写入时，怎样设计外部存储方案？

常见错误

  • 发现零后立即清整行整列，后续无法区分原始零和新产生的零。
  • 仅使用 matrix[0][0]，混淆首行与首列两个独立状态。
  • 标记尚未全部写完就开始清零，破坏仍待扫描的原始信息。
  • 返回新矩阵而没有原地修改参数，违反接口的 void 输出契约。

class Solution {
    public void setZeroes(int[][] matrix) {
        int rows = matrix.length;
        int cols = matrix[0].length;
        boolean firstRowZero = false;
        boolean firstColZero = false;

        for (int col = 0; col < cols; col++) {
            if (matrix[0][col] == 0) firstRowZero = true;
        }
        for (int row = 0; row < rows; row++) {
            if (matrix[row][0] == 0) firstColZero = true;
        }

        for (int row = 1; row < rows; row++) {
            for (int col = 1; col < cols; col++) {
                if (matrix[row][col] == 0) {
                    matrix[row][0] = 0;
                    matrix[0][col] = 0;
                }
            }
        }

        for (int row = 1; row < rows; row++) {
            for (int col = 1; col < cols; col++) {
                if (matrix[row][0] == 0 || matrix[0][col] == 0) {
                    matrix[row][col] = 0;
                }
            }
        }

        if (firstRowZero) {
            for (int col = 0; col < cols; col++) matrix[0][col] = 0;
        }
        if (firstColZero) {
            for (int row = 0; row < rows; row++) matrix[row][0] = 0;
        }
    }
}

var setZeroes = function (matrix) {
    const rows = matrix.length;
    const cols = matrix[0].length;
    let firstRowZero = false;
    let firstColZero = false;

    for (let col = 0; col < cols; col += 1) {
        if (matrix[0][col] === 0) firstRowZero = true;
    }
    for (let row = 0; row < rows; row += 1) {
        if (matrix[row][0] === 0) firstColZero = true;
    }

    for (let row = 1; row < rows; row += 1) {
        for (let col = 1; col < cols; col += 1) {
            if (matrix[row][col] === 0) {
                matrix[row][0] = 0;
                matrix[0][col] = 0;
            }
        }
    }

    for (let row = 1; row < rows; row += 1) {
        for (let col = 1; col < cols; col += 1) {
            if (matrix[row][0] === 0 || matrix[0][col] === 0) {
                matrix[row][col] = 0;
            }
        }
    }

    if (firstRowZero) matrix[0].fill(0);
    if (firstColZero) {
        for (let row = 0; row < rows; row += 1) matrix[row][0] = 0;
    }
};
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        rows, cols = len(matrix), len(matrix[0])
        first_row_zero = any(matrix[0][col] == 0 for col in range(cols))
        first_col_zero = any(matrix[row][0] == 0 for row in range(rows))

        for row in range(1, rows):
            for col in range(1, cols):
                if matrix[row][col] == 0:
                    matrix[row][0] = 0
                    matrix[0][col] = 0

        for row in range(1, rows):
            for col in range(1, cols):
                if matrix[row][0] == 0 or matrix[0][col] == 0:
                    matrix[row][col] = 0

        if first_row_zero:
            for col in range(cols):
                matrix[0][col] = 0
        if first_col_zero:
            for row in range(rows):
                matrix[row][0] = 0
class Solution {
public:
    void setZeroes(vector<vector<int>>& matrix) {
        int rows = matrix.size();
        int cols = matrix[0].size();
        bool firstRowZero = false;
        bool firstColZero = false;

        for (int col = 0; col < cols; ++col) {
            if (matrix[0][col] == 0) firstRowZero = true;
        }
        for (int row = 0; row < rows; ++row) {
            if (matrix[row][0] == 0) firstColZero = true;
        }

        for (int row = 1; row < rows; ++row) {
            for (int col = 1; col < cols; ++col) {
                if (matrix[row][col] == 0) {
                    matrix[row][0] = 0;
                    matrix[0][col] = 0;
                }
            }
        }

        for (int row = 1; row < rows; ++row) {
            for (int col = 1; col < cols; ++col) {
                if (matrix[row][0] == 0 || matrix[0][col] == 0) {
                    matrix[row][col] = 0;
                }
            }
        }

        if (firstRowZero) {
            fill(matrix[0].begin(), matrix[0].end(), 0);
        }
        if (firstColZero) {
            for (int row = 0; row < rows; ++row) matrix[row][0] = 0;
        }
    }
};
