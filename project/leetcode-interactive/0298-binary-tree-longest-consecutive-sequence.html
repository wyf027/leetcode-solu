Problem

题目描述

给定一棵二叉树的根节点 root，返回其中最长连续序列路径的长度。

一条路径必须沿父节点到子节点向下移动；如果相邻节点值满足“子节点值 = 父节点值 + 1”，它们便属于同一条连续序列。路径可以从树中的任意节点开始，但不能反向从子节点走向父节点，也不能跨越兄弟节点。

关键语义

只认方向为父 → 子、差值为 +1 的相邻关系。例如 3 → 2 → 1 虽然数值连续，却不符合递增规则。

示例 1

连续链为 3 → 4 → 5，长度是 3。

输入：root = [1,null,3,2,4,null,null,null,5]
输出：3

示例 2

可取 2 → 3；3 → 2 → 1 的方向和值变化均不符合要求。

输入：root = [2,null,3,2,null,1]
输出：2

参数与约束

  • root 是二叉树根节点；提交函数接收完整参数 TreeNode root。
  • 树中节点数在 [1, 3 × 10⁴] 范围内。
  • -3 × 10⁴ ≤ Node.val ≤ 3 × 10⁴。
  • TreeNode 由整数值 val 及左右子节点 left、right 组成。

Solution

一次 DFS，向下携带连续长度

时间 O(n) · 额外空间 O(h)

核心洞察

判断当前节点能否延续序列，只需要知道父节点的值与“以父节点结尾”的连续长度。如果 node.val == parent.val + 1，当前长度加一；否则当前节点成为新起点，长度重置为 1。每访问一个节点就更新全局最大值。

完整过程

  1. 初始化。 全局答案设为 0，从根节点开始 DFS；根节点没有父节点，所以当前长度从 1 起步。
  2. 决定延续或重置。 对每个非根节点比较它与父节点：恰好大 1 就沿用并增加长度，否则把长度改回 1。
  3. 更新答案。 用当前连续长度更新全局最大值。序列可在任意节点开始，因此每次重置并不会漏掉候选路径。
  4. 递归子树。 把当前节点和值、当前长度传给左右子节点；两个分支各自独立继续。
  5. 返回结果。 所有节点访问结束后，全局最大值就是答案。

正确性证明

引理：DFS 到达任意节点 v 时，携带的长度等于以 v 结尾的最长合法向下连续序列长度。

对根节点，唯一以根结尾的序列只含自身，长度为 1。假设父节点处结论成立：若 v 的值等于父值加一，所有以 v 结尾的合法序列必须由父节点对应序列延长一位，因此长度是父长度加一；否则父子边不能属于合法序列，以 v 结尾的最佳序列只能从 v 自身开始，长度为 1。故结论对 v 成立。

定理：算法返回整棵树中最长连续序列的长度。

DFS 会访问每个节点。由引理，访问每个节点时得到所有“以该节点结尾”的最优合法长度；算法取这些长度的最大值。任何合法序列都有唯一终点，因此其长度一定被计入；反之，被计入的长度均由合法父子关系构成。故最终最大值恰为答案。

复杂度

  • 时间：O(n)，每个节点访问一次。
  • 额外空间：O(h)，递归栈取决于树高；最坏退化为 O(n)。

边界处理

  • 单节点树的答案是 1。
  • 值相等、下降或跳跃时都重置为 1。
  • 负数不影响“恰好加一”的比较。
  • 极深的退化树可能触及语言递归深度限制。

四种语言完整实现

下列实现均遵循官方函数参数形式；平台已提供 TreeNode 定义。

class Solution {
    private int best;

    public int longestConsecutive(TreeNode root) {
        best = 0;
        dfs(root, null, 0);
        return best;
    }

    private void dfs(TreeNode node, TreeNode parent, int parentLength) {
        if (node == null) {
            return;
        }

        int currentLength = 1;
        if (parent != null && node.val == parent.val + 1) {
            currentLength = parentLength + 1;
        }

        best = Math.max(best, currentLength);
        dfs(node.left, node, currentLength);
        dfs(node.right, node, currentLength);
    }
}

 * @param {TreeNode} root
 * @return {number}

var longestConsecutive = function(root) {
    let best = 0;

    const dfs = (node, parentValue, parentLength) => {
        if (node === null) {
            return;
        }

        const currentLength =
            parentValue !== null && node.val === parentValue + 1
                ? parentLength + 1
                : 1;

        best = Math.max(best, currentLength);
        dfs(node.left, node.val, currentLength);
        dfs(node.right, node.val, currentLength);
    };

    dfs(root, null, 0);
    return best;
};

替代方案

可用显式栈保存 (节点, 父值, 父长度)，把递归 DFS 改成迭代 DFS。时间复杂度仍为 O(n)，并能规避递归栈溢出；代价是状态管理更显式、代码稍长。

常见错误

  • 把下降序列或子 → 父方向也算进去。
  • 连续关系断开后把长度清零；当前节点本身仍构成长为 1 的序列。
  • 只从根节点统计，漏掉从树中间开始的更长路径。
  • 左右子树共享并修改同一个局部长度，导致分支相互污染。

面试追问

如果树高可能达到 3 × 10⁴？

将递归改为显式栈，避免某些语言的调用栈或递归深度限制。

如果允许连续递减？

把延续条件改为 child = parent - 1；若递增和递减都允许，则分别维护两种状态。

如果路径可以拐弯经过父节点？

需要在每个节点合并来自左右子树的方向状态，问题会变成树形 DP，不能只携带单条向下长度。

如何返回具体路径？

除最大长度外记录最佳终点，并维护父指针或在 DFS 中保留当前路径；更新答案时保存对应节点序列。
