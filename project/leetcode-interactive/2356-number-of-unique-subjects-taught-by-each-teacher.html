科目种类的数量

Number of Unique Subjects Taught by Each Teacher

从任课记录中回答一个问题：每位教师究竟教授了几种科目？

01 / 读懂数据

题目与数据约定

给定 Teacher 表，每行表示教师 teacher_id 在院系 dept_id 教授科目 subject_id。请返回每位教师教授的不同科目数量，结果列名为 teacher_id 和 cnt，行顺序不限。

官方约束

  • 输出可按任意顺序返回。

05 / 独立题解

想清楚后，再揭晓

按教师分组，在组内对科目去重

核心洞察

记录数、院系数和科目种类数是不同的量。教师是分组维度，科目是去重对象，院系仅说明任课地点，不参与最终计数。

完整过程

  1. 按 teacher_id 将 Teacher 中的记录分组。
  2. 对每组的 subject_id 取不同值；同一教师在多个院系教相同科目时，只保留一种。
  3. 统计不同科目数并命名为 cnt，连同教师编号输出。

官方示例中，教师 1 的科目序列为 [2,2,3]，去重后为 {2,3}；教师 2 的科目集合为 {1,2,3,4}。

官方可提交 · SQL

下列查询适用于元数据列出的 MySQL、MS SQL Server、PostgreSQL、Oracle。

SELECT teacher_id, COUNT(DISTINCT subject_id) AS cnt
FROM Teacher
GROUP BY teacher_id;

官方可提交 · Pandas

import pandas as pd

def count_unique_subjects(teacher: pd.DataFrame) -> pd.DataFrame:
    return (teacher.groupby("teacher_id", dropna=False)["subject_id"]
            .nunique()
            .reset_index(name="cnt"))

为什么正确

固定任意教师 t。分组操作恰好收集所有 teacher_id=t 的记录，因此该教师教授的每个科目都会出现在这一组中，其他教师的记录不会混入。DISTINCT 恰好保留组内每个不同的 subject_id 一次，COUNT 再计算这些值的数量，所以所得 cnt 正好是教师 t 的科目种类数。对所有分组同理成立。

从集合模拟看，每处理一行，只向对应教师的集合加入该科目。处理前 k 行后，每个集合恰好包含该教师在这 k 行中出现过的科目；加入新行保持此不变式。所有行结束时，集合大小就是答案。

边界与 SQL 语义

  • 空表返回零行；单条记录产生一行且 cnt=1。
  • 重复科目跨院系不增加 cnt；不同教师拥有相互独立的统计。
  • 不要凭空输出没有出现在 Teacher 表中的教师；需要教师名册才能包含零任课教师。
  • 主键中的 subject_id 非空，COUNT(DISTINCT subject_id) 不会面临空科目。若推广到可空科目列，SQL 会忽略 NULL，集合模拟也应相应忽略。
  • SQL 会把 NULL teacher_id 归入同一组；Pandas 用 dropna=False 保留对应分组。下面四份本地参考为三列非空整数输入，不模拟 NULL 扩展场景。

复杂度

设 n 为行数，u 为不同 (teacher_id, subject_id) 组合数。哈希分组和去重的常见实现期望时间 O(n)、额外空间 O(u)。排序实现通常需要 O(n log n) 时间；实际 SQL 执行计划受索引、数据库和内存限制影响，不能保证固定的运行复杂度。以下本地集合参考按哈希操作均摊 O(1) 分析，期望时间 O(n)、空间 O(u)。

替代方案

SELECT teacher_id, COUNT(*) AS cnt
FROM (
    SELECT DISTINCT teacher_id, subject_id
    FROM Teacher
) unique_pairs
GROUP BY teacher_id;

先去重教师与科目的二元组，再按教师计数，语义相同。直接 COUNT(DISTINCT subject_id) 更简洁。大型数据可评估 (teacher_id, subject_id) 索引与执行计划；不要假定添加索引一定更快。

常见错误

  • COUNT(*)：统计的是任课记录，教师 1 会被误算成 3。
  • COUNT(DISTINCT dept_id)：统计院系种类，目标列选错。
  • GROUP BY teacher_id, dept_id：每位教师被拆成多行，结果粒度错误。
  • 先全局对 subject_id 去重：会丢失教师归属。
  • 漏写别名 cnt，或把展示排序误当成题目要求。

面试追问

  • 如何输出零任课的教师？用教师名册 LEFT JOIN 任课表，再按名册教师分组。
  • 若统计每位教师每个院系的不同科目数？分组键改为 teacher_id、dept_id。
  • 如果只统计教授至少 3 种科目的教师？添加 HAVING COUNT(DISTINCT subject_id) >= 3。
  • 重复任课记录撤销时如何维护实时统计？仅存集合不足以判断是否还有其他院系记录，应维护教师与科目组合的引用计数。

import java.util.*;

public class Main {
    static List<int[]> countUniqueSubjects(int[][] teacher) {
        Map<Integer, Set<Integer>> groups = new HashMap<>();
        for (int[] row : teacher) {
            groups.computeIfAbsent(row[0], k -> new HashSet<>()).add(row[1]);
        }
        List<int[]> result = new ArrayList<>();
        for (Map.Entry<Integer, Set<Integer>> entry : groups.entrySet()) {
            result.add(new int[]{entry.getKey(), entry.getValue().size()});
        }
        return result;
    }

    public static void main(String[] args) {
        int[][] teacher = {{1,2,3},{1,2,4},{1,3,3},
                           {2,1,1},{2,2,1},{2,3,1},{2,4,1}};
        for (int[] row : countUniqueSubjects(teacher)) {
            System.out.println(Arrays.toString(row));
        }
    }
}

JavaScript · 本地语义参考

function countUniqueSubjects(teacher) {
  const groups = new Map();
  for (const [teacherId, subjectId] of teacher) {
    if (!groups.has(teacherId)) groups.set(teacherId, new Set());
    groups.get(teacherId).add(subjectId);
  }
  return Array.from(groups, ([id, subjects]) => [id, subjects.size]);
}

Python · 本地语义参考（非 Pandas 提交接口）

def count_unique_subjects(teacher):
    groups = {}
    for teacher_id, subject_id, dept_id in teacher:
        groups.setdefault(teacher_id, set()).add(subject_id)
    return [[teacher_id, len(subjects)]
            for teacher_id, subjects in groups.items()]

C++ · 本地语义参考

#include <array>
#include <iostream>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

vector<array<int, 2>> countUniqueSubjects(
        const vector<array<int, 3>>& teacher) {
    unordered_map<int, unordered_set<int>> groups;
    for (const auto& row : teacher) {
        groups[row[0]].insert(row[1]);
    }
    vector<array<int, 2>> result;
    for (const auto& entry : groups) {
        result.push_back({entry.first, static_cast<int>(entry.second.size())});
    }
    return result;
}

int main() {
    vector<array<int, 3>> teacher = {
        {1,2,3}, {1,2,4}, {1,3,3},
        {2,1,1}, {2,2,1}, {2,3,1}, {2,4,1}
    };
    for (const auto& row : countUniqueSubjects(teacher)) {
        cout << row[0] << " " << row[1] << "\n";
    }
    return 0;
}
