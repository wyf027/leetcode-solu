题目

压缩频率表中的中位数

表 Numbers 用一行表示一个不同的整数：num 是数值，frequency 是该数值在原始数据集中出现的次数。请写一个查询，返回把频率逻辑展开后全部数字的中位数，结果列名为 median，并保留一位小数。

中位数定义

排序后，奇数个元素取正中间；偶数个元素取中间两个元素的算术平均值。

约束与数据契约

  • • num 为表的主键，每个数值至多一行。
  • • frequency 表示正整数次数；展开后的数据集非空。
  • • 数值可参与排序与平均；计算频率总和时应使用足够宽的整数类型。
  • • 返回单行单列 median；偶数长度时允许结果为小数。

Complete solution

用前缀区间命中中间秩

MySQL 8.0+ 主解

核心洞察

按 num 升序后，一行 (num, frequency) 实际占据排序序列中的一段连续秩区间。用窗口前缀和求出区间终点，就能直接判断中间秩落在哪一行，而不需要生成重复记录。

T = Σ frequency
L = floor((T + 1) / 2)
R = floor((T + 2) / 2)

完整过程

  1. 按 num 排序，用窗口函数计算前缀频率 P 与总频率 T。
  2. 当前行覆盖秩区间 [P-frequency+1, P]。
  3. 筛选与 [L, R] 相交的行，得到一个或两个中间数值。
  4. 对命中的 num 求平均并四舍五入到一位小数。

正确性证明

引理：前缀终点为 P、频率为 f 的行，恰好表示排序序列中秩 P-f+1 到 P 的所有元素，且这些元素都等于该行的 num。

命中条件：P ≥ L 保证区间终点不在左中间秩之前；P-f < R 等价于区间起点不在右中间秩之后，因此该行与 [L,R] 相交。

结论：筛选结果恰好包含第 L、R 个元素所在的一个或两个数值。奇数时二者是同一秩，偶数时取两者平均，均符合中位数定义。

边界与复杂度

  • 奇数总频率：L = R，只命中中间值所在行。
  • 偶数且两个秩在同一频率段：只命中一行，平均仍是该值。
  • 偶数且两个秩跨段：命中两行，AVG 得到小数中位数。
  • 负数不影响秩区间；大频率要求总和避免窄整数溢出。

时间：O(m log m)，主要来自对 m 个不同数值排序；若已有合适索引，执行器可能降低排序成本。额外空间：O(m) 级窗口处理空间，具体取决于数据库执行计划。

WITH ordered AS (
    SELECT
        num,
        frequency,
        SUM(frequency) OVER (ORDER BY num) AS prefix_sum,
        SUM(frequency) OVER () AS total
    FROM Numbers
),
middle_values AS (
    SELECT num
    FROM ordered
    WHERE prefix_sum >= FLOOR((total + 1) / 2)
      AND prefix_sum - frequency < FLOOR((total + 2) / 2)
)
SELECT ROUND(AVG(num), 1) AS median
FROM middle_values;

官方提交主解 · 需要支持窗口函数的 MySQL 8.0+

import java.util.Arrays;

public class Main {
    public static double medianFromFrequencies(long[][] rows) {
        Arrays.sort(rows, (a, b) -> Long.compare(a[0], b[0]));
        long total = 0;
        for (long[] row : rows) total += row[1];

        long leftRank = (total + 1) / 2;
        long rightRank = (total + 2) / 2;
        long prefix = 0;
        Long leftValue = null;
        Long rightValue = null;

        for (long[] row : rows) {
            prefix += row[1];
            if (leftValue == null && prefix >= leftRank) leftValue = row[0];
            if (prefix >= rightRank) {
                rightValue = row[0];
                break;
            }
        }
        if (leftValue == null || rightValue == null) {
            throw new IllegalArgumentException("frequency data must be non-empty");
        }
        return leftValue / 2.0 + rightValue / 2.0;
    }

    public static void main(String[] args) {
        long[][] rows = {{0, 7}, {1, 1}, {2, 3}, {3, 1}};
        System.out.printf("%.1f%n", medianFromFrequencies(rows));
    }
}

function medianFromFrequencies(rows) {
  const sorted = rows.slice().sort((a, b) => a[0] - b[0]);
  const total = sorted.reduce((sum, [, frequency]) => sum + frequency, 0);
  if (!Number.isSafeInteger(total) || total <= 0) {
    throw new RangeError("total frequency must be a positive safe integer");
  }

  const leftRank = Math.floor((total + 1) / 2);
  const rightRank = Math.floor((total + 2) / 2);
  let prefix = 0;
  let leftValue;
  let rightValue;

  for (const [num, frequency] of sorted) {
    prefix += frequency;
    if (leftValue === undefined && prefix >= leftRank) leftValue = num;
    if (prefix >= rightRank) {
      rightValue = num;
      break;
    }
  }
  if (leftValue === undefined || rightValue === undefined) {
    throw new Error("frequency data must be non-empty");
  }
  return leftValue / 2 + rightValue / 2;
}

const numbers = [[0, 7], [1, 1], [2, 3], [3, 1]];
console.log(medianFromFrequencies(numbers).toFixed(1));

from typing import Iterable, Tuple


def median_from_frequencies(rows: Iterable[Tuple[int, int]]) -> float:
    ordered = sorted(rows)
    total = sum(frequency for _, frequency in ordered)
    if total <= 0:
        raise ValueError("frequency data must be non-empty")

    left_rank = (total + 1) // 2
    right_rank = (total + 2) // 2
    prefix = 0
    left_value = None
    right_value = None

    for num, frequency in ordered:
        prefix += frequency
        if left_value is None and prefix >= left_rank:
            left_value = num
        if prefix >= right_rank:
            right_value = num
            break

    if left_value is None or right_value is None:
        raise ValueError("invalid frequency data")
    return (left_value + right_value) / 2.0


if __name__ == "__main__":
    numbers = [(0, 7), (1, 1), (2, 3), (3, 1)]
    print(f"{median_from_frequencies(numbers):.1f}")

本地语义参考 · 不是本数据库题的可提交代码

#include <algorithm>
#include <iomanip>
#include <iostream>
#include <stdexcept>
#include <utility>
#include <vector>

double medianFromFrequencies(
    std::vector<std::pair<long long, long long>> rows) {
    std::sort(rows.begin(), rows.end());
    long long total = 0;
    for (const auto& [num, frequency] : rows) total += frequency;
    if (total <= 0) throw std::invalid_argument("frequency data must be non-empty");

    const long long leftRank = (total + 1) / 2;
    const long long rightRank = (total + 2) / 2;
    long long prefix = 0;
    long long leftValue = 0;
    long long rightValue = 0;
    bool foundLeft = false;

    for (const auto& [num, frequency] : rows) {
        prefix += frequency;
        if (!foundLeft && prefix >= leftRank) {
            leftValue = num;
            foundLeft = true;
        }
        if (prefix >= rightRank) {
            rightValue = num;
            return leftValue / 2.0 + rightValue / 2.0;
        }
    }
    throw std::invalid_argument("invalid frequency data");
}

int main() {
    std::vector<std::pair<long long, long long>> numbers{
        {0, 7}, {1, 1}, {2, 3}, {3, 1}
    };
    std::cout << std::fixed << std::setprecision(1)
              << medianFromFrequencies(numbers) << '\n';
    return 0;
}

替代方案

  • 相关子查询：对每个数值分别统计左右累计频率；写法兼容旧版 MySQL，但通常重复扫描，代价更高。
  • 递归或序列表展开：先复制出每个元素再求中位数，概念直观，却会让行数膨胀到总频率，不适合大数据。
  • 双侧累计判定：比较小于、等于、大于当前值的频率，也能找候选值，但边界表达往往比秩区间更绕。

面试追问

  • 如果数据库不支持窗口函数，如何用变量或相关子查询改写？
  • 若 frequency 允许为 0，应在哪一层过滤，是否影响正确性？
  • 如何设计索引来减少 ORDER BY num 的成本？
  • 当总频率可能超过 64 位整数时，怎样选择数值类型？

常见错误

  • 把偶数长度中位数误写成第 T/2 个元素，漏掉第 T/2+1 个。
  • 用 COUNT(*) 当作总样本数；这里应求 SUM(frequency)。
  • 边界条件同时使用严格不等号，导致恰好落在频率段端点的秩被漏掉。
  • 整数相加后再除以 2 产生溢出；本地参考代码用“各除一半再相加”规避。
  • 为直观而真实展开频率，导致中间表规模不可控。

一分钟复盘

频率表的本质是“值域上的游程编码”。窗口前缀和把每行映射为排序序列中的秩区间；只要算出一对统一的中间秩，奇偶分支就被折叠成同一套相交判断，最后用平均值自然收口。
