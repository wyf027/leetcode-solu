每家商店的产品价格

Product's Price for Each Store

Problem brief

题目

给定关系表 Products，每条记录表示某件产品在某一家商店中的售价。请返回每个产品在 store1、store2、store3 三家商店的价格；产品未在某家商店出售时，该位置应为 NULL。结果行顺序不限。

product_idINT · 联合主键的一部分
storeENUM('store1','store2','store3') · 联合主键的一部分
priceINT · 该产品在该店的价格
约束（来自官方表定义）

(product_id, store) 是联合主键，因此同一产品在同一商店至多出现一次；store 只可能是三种固定值。官方可用元数据未给出额外的行数或数值范围，本文不补造范围。

Solution

题解

核心洞察

输出需要把 store 的三种行值展开成三列。按 product_id 分组，再对每个固定商店做条件聚合即可。条件不匹配时 CASE 返回 NULL；若某产品没有该店记录，聚合结果自然保留为 NULL。

为什么用 MAX

联合主键保证每个“产品 + 商店”组合至多一行，因此每组每列最多只有一个非空价格。MAX 只是从“一个值或全空”中取得那个值，并非在多个冲突价格里挑最大值。

完整过程

  1. 按产品分组：让同一 product_id 的所有商店记录进入同一输出行。
  2. 为每家店建立条件：只有 store 等于目标店名时才返回 price，否则返回 NULL。
  3. 聚合条件结果：使用 MAX 把每组的目标价格折叠成一个单元格。
  4. 保留缺失：某家店没有匹配记录时，该列全为 NULL，结果仍为 NULL。

MySQL 可提交答案

SELECT
    product_id,
    MAX(CASE WHEN store = 'store1' THEN price END) AS store1,
    MAX(CASE WHEN store = 'store2' THEN price END) AS store2,
    MAX(CASE WHEN store = 'store3' THEN price END) AS store3
FROM Products
GROUP BY product_id;

正确性说明

分组完整性：每个不同的 product_id 形成且只形成一个分组，所以输出中每件产品恰有一行。

列值正确性：以 store1 为例，条件表达式只在当前行属于 store1 时产生价格。联合主键保证组内至多一个这样的非空值，故 MAX 返回该产品在 store1 的唯一价格；若没有该行，则全部为 NULL，结果也是 NULL。store2、store3 同理。

因此每个输出单元格都与题目要求一致，查询正确。

边界情况

  • 产品只在一家店出售：另外两列为 NULL。
  • 产品在三家店均出售：三列都有价格。
  • 不同产品的商店覆盖范围不同：按各自分组独立计算。
  • 价格可以相同：条件依据店名，不会混淆。

复杂度

设输入有 n 行、不同产品数为 p。逻辑扫描成本为 O(n)；数据库为分组可能使用排序或哈希，具体代价取决于执行计划。结果占用 O(p)，分组工作空间通常也是 O(p)。

替代方案

数据库原生 PIVOT：SQL Server、Oracle 等方言可以使用 PIVOT，但语法不通用；固定三列时，条件聚合更直观且便于迁移。

三次自连接：也可从产品列表分别连接三家店，但需要更多扫描与连接，表达更冗长。除非要展示连接技巧，否则不如条件聚合。

import java.util.*;

class Solution {
    static class ProductRow {
        int productId;
        String store;
        int price;

        ProductRow(int productId, String store, int price) {
            this.productId = productId;
            this.store = store;
            this.price = price;
        }
    }

    static class ProductPrice {
        int productId;
        Integer store1;
        Integer store2;
        Integer store3;

        ProductPrice(int productId, Integer[] prices) {
            this.productId = productId;
            this.store1 = prices[0];
            this.store2 = prices[1];
            this.store3 = prices[2];
        }
    }

    public List<ProductPrice> productsPrice(List<ProductRow> rows) {
        Map<Integer, Integer[]> grouped = new TreeMap<>();

        for (ProductRow row : rows) {
            Integer[] prices = grouped.computeIfAbsent(
                row.productId, ignored -> new Integer[3]
            );
            int index = Integer.parseInt(row.store.substring(5)) - 1;
            prices[index] = row.price;
        }

        List<ProductPrice> result = new ArrayList<>();
        for (Map.Entry<Integer, Integer[]> entry : grouped.entrySet()) {
            result.add(new ProductPrice(entry.getKey(), entry.getValue()));
        }
        return result;
    }
}
function productsPrice(rows) {
  const grouped = new Map();

  for (const { product_id, store, price } of rows) {
    if (!grouped.has(product_id)) {
      grouped.set(product_id, {
        product_id,
        store1: null,
        store2: null,
        store3: null,
      });
    }
    grouped.get(product_id)[store] = price;
  }

  return [...grouped.values()].sort(
    (a, b) => a.product_id - b.product_id
  );
}
from typing import TypedDict


class ProductRow(TypedDict):
    product_id: int
    store: str
    price: int


class ProductPrice(TypedDict):
    product_id: int
    store1: int | None
    store2: int | None
    store3: int | None


def products_price(rows: list[ProductRow]) -> list[ProductPrice]:
    grouped: dict[int, ProductPrice] = {}

    for row in rows:
        product_id = row["product_id"]
        if product_id not in grouped:
            grouped[product_id] = {
                "product_id": product_id,
                "store1": None,
                "store2": None,
                "store3": None,
            }
        grouped[product_id][row["store"]] = row["price"]

    return [grouped[key] for key in sorted(grouped)]
#include <array>
#include <map>
#include <optional>
#include <string>
#include <vector>
using namespace std;

struct ProductRow {
    int productId;
    string store;
    int price;
};

struct ProductPrice {
    int productId;
    optional<int> store1;
    optional<int> store2;
    optional<int> store3;
};

class Solution {
public:
    vector<ProductPrice> productsPrice(
        const vector<ProductRow>& rows
    ) {
        map<int, array<optional<int>, 3>> grouped;

        for (const ProductRow& row : rows) {
            int index = row.store.back() - '1';
            grouped[row.productId][index] = row.price;
        }

        vector<ProductPrice> result;
        for (const auto& [productId, prices] : grouped) {
            result.push_back({
                productId, prices[0], prices[1], prices[2]
            });
        }
        return result;
    }
};

常见错误

  • 忘记 GROUP BY product_id，导致全部产品被聚成一行。
  • 使用 ELSE 0，把“未出售”错误地表示成价格 0。
  • 三列的店名或别名复制粘贴错误。
  • 把行顺序当成要求；题目明确允许任意顺序。
