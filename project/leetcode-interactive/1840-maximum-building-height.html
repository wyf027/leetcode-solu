最高建筑高度

Maximum Building Height · 在相邻高度差的规则下，城市能长到多高？

先理解规则并尝试推导，再展开底部题解与交互实验。

题目

将 n 栋建筑依次编号为 1 到 n。每栋高度必须是非负整数，第 1 栋高度固定为 0，任意相邻两栋的高度差绝对值不能超过 1。

额外输入 restrictions，其中每个 [id, maxHeight] 表示对应建筑的高度上限。编号不重复，且不包含建筑 1。请返回所有合法建造方案中，最高的一栋建筑可以达到的最大高度。

上限不代表必须达到的高度。目标是最大化单栋建筑的高度，不是建筑高度总和。

参数与约束

  • n：整数，2 ≤ n ≤ 10⁹。
  • restrictions：二维整数数组，0 ≤ 长度 ≤ min(n − 1, 10⁵)。
  • 每项 [idᵢ, maxHeightᵢ] 满足 2 ≤ idᵢ ≤ n，且 idᵢ 唯一。
  • 0 ≤ maxHeightᵢ ≤ 10⁹。
  • 返回值：整数。函数名：maxBuilding(n, restrictions)。

官方示例

示例 1

输入：n = 5, restrictions = [[2,1],[4,1]]
输出：2

题解 · 压缩坐标上的双向约束传播

只维护被限制的位置。先把每个上限收紧到全局可达范围，再计算相邻限制之间的山峰。

核心洞察

在位置 p 的上限为 h 时，距离它 t 的建筑最多为 h + t。这是一条左右斜率为 ±1 的“屋顶”。多个限制同时存在时，每个位置都必须位于所有屋顶之下。补入 [1,0] 后，按位置排序，左右各传播一次即可得到所有限制点的有效上限。

完整过程
  1. 复制 restrictions，补入 [1,0]，按编号升序排序。
  2. 从左到右：h[i] = min(h[i], h[i−1] + id[i] − id[i−1])。
  3. 从右到左：h[i] = min(h[i], h[i+1] + id[i+1] − id[i])。
  4. 对相邻端点 (l,a)、(r,b)，令 d = r−l。区间内位置 l+t 的上限为 min(a+t, b+d−t)，峰值是 floor((a+b+d)/2)。取所有区间峰值的最大值。
  5. 最后一个限制点 (p,h) 之后没有新限制，尾部最多单调增长到 h+n−p；与区间结果取最大值。


为什么是这个峰值？
两条直线相交于 t = (b+d−a)/2。两遍传播保证 |a−b| ≤ d，所以交点位于区间内。整数建筑位置取交点附近的整数即可得到 floor((a+b+d)/2)。也可写成 max(a,b) + floor((d−|a−b|)/2)。注意 d 是编号差，不是区间建筑数量。


正确性证明
  1. 传播上界正确：相邻高度差约束推得任意两点高度差不超过编号差。因此每一次收紧都是必需的。左扫聚合所有左侧限制，右扫补上所有右侧限制；传播经过另一点的路径不会比直接距离更短，不会产生过度收紧。
  2. 上界可达：定义 H(x)=min₍p,h₎(h+|x−p|)，其中包含原始限制与 [1,0]。每条屋顶非负且相邻差至多 1，它们的逐点最小值也具有此性质，且 H(1)=0 并满足全部上限。因此 H 是合法的全局高度序列，也逐点支配任意合法方案。
  3. 区间计算完备：无内部限制的区间中，左侧限制合并为左端点屋顶，右侧限制合并为右端点屋顶。两条线的最小值即 H。按交点求峰并处理尾段，就覆盖了所有建筑，因此所得最大值既不可超越又可达到。


边界与复杂度
空数组只剩 [1,0]，答案为 n−1。末点就是 n 时尾段长度为 0。零上限仍合法；相邻限制不留内部建筑时公式仍然成立；原始上限再大也会受建筑 1 约束。复制数组避免修改调用者输入。
令 m = restrictions.length，时间为 O((m+1) log(m+1))，两次扫描为 O(m+1)；复制数组使用 O(m+1) 空间。无需展开十亿栋建筑。Java / C++ 使用 64 位中间值，JavaScript Number 的整数精度足够；最终答案不超过 n−1。


替代方案
小 n 可直接对每栋建筑做左右扫描，时间和空间均为 O(n)，但不适合本题上限。也可补入 [n,n−1] 统一尾段，需要注意已有 n 限制时合并重复位置。二分答案也需要额外可行性判断，没有直接求区间峰值简洁。


常见错误
  • 只左扫：右侧低上限对左侧的影响会遗漏。
  • 把限制视为精确高度，或直接用未收紧的端点计算峰。
  • 对峰值四舍五入；整数位置应向下取整。
  • 漏掉最后限制点到 n 的尾部。
  • 按 n 分配数组，或排序后意外修改传入数组。


面试追问
如何构造完整方案？用区间屋顶逐点恢复 H，输出所有 n 个高度本身就需 O(n) 时间；大 n 可输出分段表示。
相邻差允许 k 呢？传播改为 k×距离。区间交点为 (b+kd−a)/(2k)，应在相邻整数位置计算 min(a+kt,b+k(d−t))，不能直接照搬 k=1 的取整公式；k=0 单独处理。
限制实时更新？当前解适合静态输入；更新会影响远处的有效上限，不能仅重算相邻峰值，可从重新排序扫描开始再按查询规模设计数据结构。

Java
import java.util.Arrays;

class Solution {
    public int maxBuilding(int n, int[][] restrictions) {
        int m = restrictions.length + 1;
        long[][] r = new long[m][2];
        r[0] = new long[]{1, 0};
        for (int i = 1; i < m; i++)
            r[i] = new long[]{restrictions[i-1][0], restrictions[i-1][1]};
        Arrays.sort(r, (a, b) -> Long.compare(a[0], b[0]));
        for (int i = 1; i < m; i++)
            r[i][1] = Math.min(r[i][1], r[i-1][1] + r[i][0] - r[i-1][0]);
        for (int i = m-2; i >= 0; i--)
            r[i][1] = Math.min(r[i][1], r[i+1][1] + r[i+1][0] - r[i][0]);
        long ans = r[m-1][1] + n - r[m-1][0];
        for (int i = 1; i < m; i++) {
            long d = r[i][0] - r[i-1][0];
            ans = Math.max(ans, (r[i-1][1] + r[i][1] + d) / 2);
        }
        return (int) ans;
    }
}

from typing import List

class Solution:
    def maxBuilding(self, n: int, restrictions: List[List[int]]) -> int:
        r = sorted([[1, 0]] + [pair[:] for pair in restrictions])
        m = len(r)
        for i in range(1, m):
            r[i][1] = min(r[i][1], r[i-1][1] + r[i][0] - r[i-1][0])
        for i in range(m-2, -1, -1):
            r[i][1] = min(r[i][1], r[i+1][1] + r[i+1][0] - r[i][0])
        ans = r[-1][1] + n - r[-1][0]
        for i in range(1, m):
            d = r[i][0] - r[i-1][0]
            ans = max(ans, (r[i-1][1] + r[i][1] + d) // 2)
        return ans
C++
#include <vector>
#include <array>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxBuilding(int n, vector<vector<int>>& restrictions) {
        vector<array<long long, 2>> r{{1, 0}};
        for (const auto& p : restrictions) r.push_back({p[0], p[1]});
        sort(r.begin(), r.end());
        int m = static_cast<int>(r.size());
        for (int i = 1; i < m; ++i)
            r[i][1] = min(r[i][1], r[i-1][1] + r[i][0] - r[i-1][0]);
        for (int i = m-2; i >= 0; --i)
            r[i][1] = min(r[i][1], r[i+1][1] + r[i+1][0] - r[i][0]);
        long long ans = r.back()[1] + n - r.back()[0];
        for (int i = 1; i < m; ++i) {
            long long d = r[i][0] - r[i-1][0];
            ans = max(ans, (r[i-1][1] + r[i][1] + d) / 2);
        }
        return static_cast<int>(ans);
    }
};
