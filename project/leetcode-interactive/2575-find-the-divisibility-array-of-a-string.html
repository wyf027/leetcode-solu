题目

难度：中等非付费题返回 int[]

给定一个下标从 0 开始、长度为 n 的数字字符串 word，以及正整数 m。

构造长度为 n 的可整除数组 div：如果前缀 word[0…i] 表示的数值能被 m 整除，则 div[i] = 1；否则 div[i] = 0。返回 div。

函数签名

divisibilityArray(word: string, m: integer) → integer[]

官方示例

示例 14 个命中前缀
输入：word = "998244353", m = 3
输出：[1,1,0,0,0,1,1,0,0]

可整除前缀为 "9"、"99"、"998244" 和 "9982443"。

示例 22 个命中前缀
输入：word = "1010", m = 10
输出：[0,1,0,1]

可整除前缀为 "10" 和 "1010"。

约束

  • 1 ≤ n ≤ 10⁵
  • word.length == n
  • word 仅由数字 0 到 9 组成
  • 1 ≤ m ≤ 10⁹

Solution

一次扫描，始终只保留余数

核心洞察

前缀可能有十万位，不能把它直接转成普通整数。设旧前缀除以 m 的余数为 r，追加数字 d 后，新前缀的余数是：

nextRemainder = (r × 10 + d) mod m

因此每次只保存小于 m 的余数；新余数为 0 时，当前位置输出 1。

完整过程

  1. 初始化 remainder = 0，并创建长度为 n 的答案数组。
  2. 从左到右读取 word[i]，把字符转换为数字 digit。
  3. 更新 remainder = (remainder × 10 + digit) % m。
  4. 若余数为 0，令 answer[i] = 1，否则为 0。
  5. 扫描结束后返回答案。

正确性证明

循环不变式：处理完下标 i 后，remainder 等于前缀 word[0…i] 对 m 的余数，且 answer[0…i] 已正确。

初始：读取任何数字前，空前缀按计算状态取余数 0。

保持：若旧前缀值为 P、新数字为 d，新值为 10P+d。以 P mod m 代替 P 不改变最终模 m 的结果，所以更新式得到新前缀的真实余数。余数为零当且仅当前缀可被整除，因此写入位正确。

终止：处理最后一位后，每个前缀都被处理一次，故返回数组全部正确。

边界与复杂度

  • m = 1：所有余数都是零。
  • 数字含前导零：递推仍成立。
  • 单字符 "0"：零可被任意正整数整除。
  • 超长 word：从不构造完整大整数。

时间：O(n)；额外空间：除返回数组外为 O(1)。

数值类型：Java / C++ 中乘以 10 前应使用 64 位整数。JavaScript 在本题上界下，中间值小于 10¹⁰，仍在安全整数范围内。

替代方案

大整数逐前缀

语言若支持 BigInt，可以持续构造完整数值，但数值位数不断增长，做了本题不需要的工作。

每个前缀重新计算

从头计算每个前缀会达到 O(n²)，无法承受 10⁵ 的长度。

Javalong 中间值
class Solution {
    public int[] divisibilityArray(String word, int m) {
        int[] answer = new int[word.length()];
        long remainder = 0;

        for (int i = 0; i < word.length(); i++) {
            int digit = word.charAt(i) - '0';
            remainder = (remainder * 10 + digit) % m;
            answer[i] = remainder == 0 ? 1 : 0;
        }
        return answer;
    }
}

var divisibilityArray = function(word, m) {
    const answer = new Array(word.length);
    let remainder = 0;

    for (let i = 0; i < word.length; i++) {
        remainder = (remainder * 10 + Number(word[i])) % m;
        answer[i] = remainder === 0 ? 1 : 0;
    }
    return answer;
};
Python 3逐字符
from typing import List


class Solution:
    def divisibilityArray(self, word: str, m: int) -> List[int]:
        answer = []
        remainder = 0

        for char in word:
            remainder = (remainder * 10 + int(char)) % m
            answer.append(1 if remainder == 0 else 0)
        return answer
C++long long 中间值
class Solution {
public:
    vector<int> divisibilityArray(string word, int m) {
        vector<int> answer(word.size());
        long long remainder = 0;

        for (int i = 0; i < static_cast<int>(word.size()); ++i) {
            int digit = word[i] - '0';
            remainder = (remainder * 10 + digit) % m;
            answer[i] = remainder == 0 ? 1 : 0;
        }
        return answer;
    }
};

常见错误

  • 把整个字符串或超长前缀转换成整数，导致溢出。
  • 忘记把旧余数乘以 10 再加入新数字。
  • 先使用 32 位乘法，再把结果赋给 64 位变量。
  • 把“余数为零”误写成“当前数字能被 m 整除”。
