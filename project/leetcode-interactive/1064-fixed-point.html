不动点Fixed Point

在严格递增的整数数组中，找到最小的下标 i，使数组值恰好等于它自己的位置。

难度EASY
访问会员题
函数fixedPoint
返回integer

题目

给定一个按严格递增顺序排列的整数数组 arr，返回满足 arr[i] == i 的最小下标。如果不存在，返回 -1。

“最小”很重要：即使搜索途中发现一个不动点，仍要确认左侧是否存在更早的不动点。

示例

示例 1
输入：arr = [-10, -5, 0, 3, 7]
输出：3
解释：arr[3] = 3，且它是最小的不动点。
示例 2
输入：arr = [0, 2, 5, 8, 17]
输出：0
解释：arr[0] = 0。
示例 3
输入：arr = [-10, -5, 3, 4, 7, 9]
输出：-1
解释：不存在满足条件的下标。

参数与约束

  • fixedPoint(arr: integer[]) → integer
  • 数组非空，元素均为整数。
  • arr 严格递增。
  • 返回最小匹配下标；没有匹配时返回 -1。

让二分查找动起来

比较 arr[mid] 和 mid。演示特别保留了“命中后继续向左”的动作。

题解：在差值上二分

核心洞察

令 f(i) = arr[i] - i。数组严格递增，而索引每次只加 1，因此 f(i) 单调不减。我们可二分寻找第一个满足 arr[i] ≥ i 的位置，并判断是否相等。

完整过程

  1. 令 left = 0、right = n - 1、answer = -1。
  2. 取中点。若 arr[mid] < mid，令 left = mid + 1。
  3. 否则当前点或左侧可能包含最小答案；相等时记录中点，再令 right = mid - 1。
  4. 区间为空后返回记录值。

正确性

若 arr[mid] < mid，严格递增保证任意 j ≤ mid 都有 arr[j] < j，左半边可排除。否则保留左半边；命中后仍向左，最终记录的就是最小不动点。

复杂度

搜索区间每轮减半，时间 O(log n)；仅用常数变量，空间 O(1)。

边界情况

  • 答案为 0，如 [0,2,5]。
  • 所有元素都小于或都大于对应下标。
  • 单元素数组：[0] 返回 0，其余返回 -1。
  • 存在多个候选时仍须返回最左者。

替代方案

线性扫描首个匹配即可返回，时间 O(n)，也适用于未排序数组；本题的严格递增性质使二分更优。

面试追问

  • 若数组仅非递减，差值不再必然单调，怎么调整？
  • 如何返回所有不动点？
  • 若读取一个元素代价很高，如何最少化访问次数？

常见错误

  • 找到相等值立即返回，漏掉更小下标。
  • 在 arr[mid] ≥ mid 时错误地丢弃中点或左侧。
  • 边界没有前进，造成死循环。
