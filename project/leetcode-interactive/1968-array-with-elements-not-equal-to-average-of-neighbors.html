05 / 独立题解

准备好后再展开，观察重排如何消除相邻平均值。

排序后，把奇数位置变成局部峰值

核心洞察

如果一个数比左右邻居都大，它一定大于两者的平均值；如果比左右邻居都小，它一定小于两者的平均值。因此构造严格的波形 a₀ < a₁ > a₂ < a₃ > a₄ … 就足够了。

完整过程

  1. 将数组按数值升序排序。
  2. 从下标 1 开始，每次前进 2，把 nums[i] 与 nums[i+1] 交换，前提是 i+1 < n。
  3. 返回重排后的数组。无需逐个计算平均值来决定交换。
[1,2,3,4,5] → 排序不变 交换 (1,2)：[1,3,2,4,5] 交换 (3,4)：[1,3,2,5,4]

波峰实验台 · 排序 → 成对交换 → 三元组观察

正确性证明

记排序后的数组为 b₀ < b₁ < … < bₙ₋₁。交换只改变位置，所以元素及其数量保持不变。

对任意内部奇数下标 i，交换后该处为 bᵢ₊₁，右邻居为 bᵢ；左邻居在 i=1 时是 b₀，否则是 bᵢ₋₂。它严格大于左右邻居，因而大于它们的平均值。

对任意内部偶数下标 i≥2，该处为 bᵢ₋₁，左邻居为 bᵢ；右邻居若参与下一次交换则为 bᵢ₊₂，否则为末尾未交换的 bᵢ₊₁。它严格小于两个邻居，因而小于它们的平均值。内部位置均被覆盖，因此答案合法。

边界与复杂度

  • n = 3：只交换下标 1 和 2，唯一内部位置成为峰值。
  • n 为偶数时，最后一个元素可能不交换；它大于前一个谷值，仍满足所需关系。首尾自身无需判定。
  • 互异性确保所有比较严格。允许重复值是另一类问题，例如全相等数组无解。
  • 时间：排序 O(n log n)，交换 O(n)，合计 O(n log n)。
  • 交换本身额外空间 O(1)。下方原地修改代码的总辅助空间取决于排序：Python 最坏 O(n)；C++ 常用 std::sort 为 O(log n) 栈；Java 基本类型排序与 JavaScript 排序内部开销依运行库而定，不能统一宣称总空间 O(1)。

四语言代码

均采用官方函数签名，原地修改 nums 并返回。以下为生成的实现，尚未运行或验证。

Java

import java.util.Arrays;

class Solution {
    public int[] rearrangeArray(int[] nums) {
        Arrays.sort(nums);
        for (int i = 1; i + 1 < nums.length; i += 2) {
            int t = nums[i];
            nums[i] = nums[i + 1];
            nums[i + 1] = t;
        }
        return nums;
    }
}

JavaScript

/**

var rearrangeArray = function(nums) {
    nums.sort((a, b) => a - b);
    for (let i = 1; i + 1 < nums.length; i += 2) {
        [nums[i], nums[i + 1]] = [nums[i + 1], nums[i]];
    }
    return nums;
};

Python

from typing import List

class Solution:
    def rearrangeArray(self, nums: List[int]) -> List[int]:
        nums.sort()
        for i in range(1, len(nums) - 1, 2):
            nums[i], nums[i + 1] = nums[i + 1], nums[i]
        return nums

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> rearrangeArray(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        for (int i = 1; i + 1 < static_cast<int>(nums.size()); i += 2) {
            swap(nums[i], nums[i + 1]);
        }
        return nums;
    }
};

C++ 返回引用参数对应的 vector 值时还需 O(n) 的返回结果存储；通常将输出空间单独计算。

替代方案

分两半交错填充：排序后，把较小的 ⌈n/2⌉ 个数依次放偶数下标，余下较大数放奇数下标。每个峰都高于两侧的谷；时间 O(n log n)，新结果数组 O(n)。

一次扫描构造波形：从 i=1 扫到末尾，奇数 i 若 a[i] < a[i−1] 则交换，偶数 i 若 a[i] > a[i−1] 则交换。奇数步把较小者放回左边，不会破坏前一个谷；偶数步把较大者放回左边，不会破坏前一个峰。互异条件下可在 O(n) 时间、O(1) 辅助空间完成。排序方案的优点是位置关系更容易直接证明。

面试追问

  • 可以不排序吗？可以，使用上面相邻比较的线性扫描，说明新交换不会破坏已建立的关系。
  • 必须返回示例输出吗？不必；只需保持元素并满足全部内部位置的不等式。
  • 可以不修改输入吗？先复制数组；因此额外增加 O(n) 空间。
  • 如果只是判定结果，如何避免小数？检查 2 * a[i] != a[i−1] + a[i+1]；本题上界下这些运算安全，更大范围应使用宽整数。

常见错误

  • 只排序：等差数列仍可能让每个内部数恰好等于平均值。
  • 只处理一个违规三元组：任意交换可能破坏邻近位置，必须使用全局构造或维持不变量。
  • JavaScript 忘记数值比较器，导致按字符串顺序排序。
  • 使用整数除法计算平均值：例如 (1+4)/2 被截断为 2，会误判。
  • 循环条件仅写 i < n：访问 i+1 可能越界。
  • 把“互不相同”当作可选条件，或把严格波形当作所有合法答案必须具有的形式。波形是充分条件，并非必要条件。
