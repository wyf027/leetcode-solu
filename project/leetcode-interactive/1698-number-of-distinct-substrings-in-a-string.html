字符串的不同
子字符串个数

给定一个仅由小写英文字母组成的字符串 s，返回其中不同的非空连续子字符串数量。 相同内容无论出现多少次，只计一次。

MEDIUM 字典树 字符串 后缀数组 滚动哈希

Problem

题目说明

任务

子字符串必须由原字符串中一段连续字符构成。枚举所有非空连续片段后，按其文本内容去重， 返回剩余的数量。

函数签名：countDistinct(s: string): integer

约束

  • 1 <= s.length <= 500
  • s 仅包含小写英文字母
  • 只统计非空子字符串

Solution

字典树统计新节点

核心洞察

每个子字符串都是某个后缀的前缀。把所有后缀插入同一棵字典树后， 从根到任意非根节点的路径文字恰好表示一个不同子字符串，因此答案就是新建节点的总数。

完整过程

  1. 创建只有根节点的字典树，并令答案 answer = 0。
  2. 依次选择每个起点 i，把后缀 s[i..n-1] 从根开始插入。
  3. 读取字符 s[j]。若当前节点没有对应子节点，则创建它，并把答案加一。
  4. 移动到该子节点，继续读取当前后缀的下一个字符。
  5. 所有后缀完成后，返回累计的新节点数。

边界处理

  • 长度为 1：只会创建一个节点，答案为 1。
  • 全部相同：如 aaaa，只有 a 到 aaaa，答案为 4。
  • 字符全部不同：没有路径复用，答案达到 n(n+1)/2。
  • 题目约束排除了空串；实现无需把空串计入答案。

正确性证明

对任意非空子字符串 s[i..j]，它是后缀 s[i..n-1] 的前缀， 所以插入该后缀时，字典树中必存在一条从根出发、标签正好为该子字符串的路径。 反过来，每个非根节点都位于某个已插入后缀的前缀路径末端，因此它表示原串中的一个非空子字符串。 字典树共享相同前缀，所以相同文本只对应同一个节点；一个节点仅在首次出现时创建并计数。 由此，新建节点总数与不同非空子字符串一一对应，算法返回值正确。

复杂度

时间
O(n²)

处理所有后缀的全部字符。

空间
O(n²)

最坏情况下没有可复用的路径。

Implementations

四种语言完整代码

Java

LeetCode
class Solution {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
    }

    public int countDistinct(String s) {
        TrieNode root = new TrieNode();
        int answer = 0;

        for (int i = 0; i < s.length(); i++) {
            TrieNode node = root;
            for (int j = i; j < s.length(); j++) {
                int index = s.charAt(j) - 'a';
                if (node.children[index] == null) {
                    node.children[index] = new TrieNode();
                    answer++;
                }
                node = node.children[index];
            }
        }

        return answer;
    }
}

    const root = new Map();
    let answer = 0;

    for (let i = 0; i < s.length; i++) {
        let node = root;
        for (let j = i; j < s.length; j++) {
            const char = s[j];
            if (!node.has(char)) {
                node.set(char, new Map());
                answer++;
            }
            node = node.get(char);
        }
    }

    return answer;
};

class Solution:
    def countDistinct(self, s: str) -> int:
        root = {}
        answer = 0

        for start in range(len(s)):
            node = root
            for end in range(start, len(s)):
                char = s[end]
                if char not in node:
                    node[char] = {}
                    answer += 1
                node = node[char]

        return answer

C++

LeetCode
class Solution {
private:
    struct TrieNode {
        TrieNode* children[26]{};

        ~TrieNode() {
            for (TrieNode* child : children) {
                delete child;
            }
        }
    };

public:
    int countDistinct(string s) {
        TrieNode root;
        int answer = 0;

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            TrieNode* node = &root;
            for (int j = i; j < static_cast<int>(s.size()); ++j) {
                int index = s[j] - 'a';
                if (node->children[index] == nullptr) {
                    node->children[index] = new TrieNode();
                    ++answer;
                }
                node = node->children[index];
            }
        }

        return answer;
    }
};

Deep Dive

替代方案与面试追问

替代方案

  • 后缀数组 + LCP：全部子串数为 n(n+1)/2，减去相邻排序后缀的最长公共前缀长度之和。典型构建可做到 O(n log² n)，更优实现可继续下降。
  • 后缀自动机：每个状态贡献 maxLen - link.maxLen，总时间和空间均可达到 O(n)，但实现与证明更复杂。
  • 双滚动哈希：枚举所有子串并把双哈希加入集合，写法直观，期望时间 O(n²)，但仍需诚实讨论碰撞风险。

面试追问

  • 如果 n 扩大到 10⁵，如何改用后缀自动机并计算每个状态的贡献？
  • 后缀数组公式为什么只需要减去相邻后缀的 LCP？
  • 字符集很大时，数组子节点和哈希映射如何权衡内存与常数？
  • 若要同时输出第 k 个字典序子字符串，需要为数据结构补充哪些计数？

常见错误

  • 把相同内容在不同位置的出现次数重复计入。
  • 只插入完整后缀，却忘记沿途每个节点都代表一个子字符串。
  • 把根节点对应的空串也加进答案。
  • 在每个起点重新创建一棵树，失去跨后缀去重能力。
  • 使用单哈希后宣称绝无碰撞。
  • 对输入字符范围没有把握时仍直接执行 char - 'a'。
