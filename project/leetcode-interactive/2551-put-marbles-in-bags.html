LeetCode 2551 · Hard

将珠子放入背包中

连续的珠子必须留在同一个背包。你能在不枚举所有切法的情况下，找出最高分与最低分之间的距离吗？

Put Marbles in Bags 贪心 数组 排序 非付费题

先读题、动手推演；完整题解藏在页面底部。

01 · Problem

题意

连续分组，端点计价

给定从 0 开始编号的整数数组 weights 和整数 k，把所有珠子依照原顺序分进恰好 k 个非空背包。

  • 每个背包中的珠子必须构成原数组的一段连续子数组。
  • 若一个背包含有下标 i..j 的珠子，它的价格为 weights[i] + weights[j]。
  • 一次分配的分数是全部背包价格之和。

返回所有合法分配中，最大分数与最小分数的差值。

函数与约束

putMarbles(weights, k) → long

  • 1 ≤ k ≤ weights.length ≤ 10⁵
  • 1 ≤ weights[i] ≤ 10⁹

数组很长、数值很大：返回值需要覆盖远超 32 位整数的范围。

示例 1
输入：weights = [1,3,5,1], k = 2
输出：4
解释：
[1]｜[3,5,1] 的分数为 (1+1)+(3+1)=6（最小）。
[1,3]｜[5,1] 的分数为 (1+3)+(5+1)=10（最大）。
因此返回 10−6=4。
示例 2
输入：weights = [1,3], k = 2
输出：0
解释：
唯一合法分配是 [1]｜[3]。
最高分与最低分相同，因此返回 0。

04 · Solution

准备好看答案了吗？

下面包含核心推导、证明、复杂度与四种语言的完整实现。

Core insight

真正变化的，只有切口两侧

不切时，整个数组的两个外端点贡献固定值 weights[0] + weights[n−1]。每在 i 与 i+1 之间切一刀，左侧背包多出右端点 weights[i]，右侧背包多出左端点 weights[i+1]。

score = weights[0] + weights[n−1] + Σ(weights[i] + weights[i+1])，i 为切口

所有方案都有相同的外端点贡献，而且都要选恰好 k−1 个切口。因此只需计算每个相邻对之和：最小分数选择最小的 k−1 个，最大分数选择最大的 k−1 个。固定项在相减时自动消失。

完整过程

  1. 对每个缝隙 i，计算 weights[i] + weights[i+1]。
  2. 将全部 n−1 个缝隙代价升序排序。
  3. 累加最大的 k−1 个代价，同时减去最小的 k−1 个代价。
  4. 所得值就是最大分数与最小分数之差。

正确性证明

引理：任意合法分配的分数等于固定外端点之和，加上其全部切口的相邻权重之和。因为每个内部背包边界恰好由某个切口两侧的两个端点组成，且每个端点只计一次。

最优性：所有合法方案一一对应于从 n−1 个缝隙中选择 k−1 个。若最小方案包含更大代价而遗漏更小代价，交换两者会降低分数，与最优矛盾；最大方案同理。因此分别选择最小与最大的 k−1 个代价最优。

结论：两组切口代价之差就是所求答案。

复杂度

构造相邻和为 O(n)，排序为 O(n log n)；额外空间为 O(n)。

边界情况

  • k=1：没有切口，答案为 0。
  • k=n：所有缝隙都被选择，答案为 0。
  • 相同权重或重复相邻和不影响选择。
  • Java/C++ 累加必须使用 64 位整数。

替代方案

可以用两个大小为 k−1 的堆维护最大与最小切口，将时间改为 O(n log k)、空间改为 O(k)。全量排序更短、更直观。

Implementations

四语言完整代码

Java
import java.util.Arrays;

class Solution {
    public long putMarbles(int[] weights, int k) {
        int n = weights.length;
        long[] pairs = new long[n - 1];
        for (int i = 0; i < n - 1; i++) {
            pairs[i] = (long) weights[i] + weights[i + 1];
        }

        Arrays.sort(pairs);
        long answer = 0;
        for (int i = 0; i < k - 1; i++) {
            answer += pairs[n - 2 - i] - pairs[i];
        }
        return answer;
    }
}

    }

    let answer = 0;
    for (let i = 0; i < k - 1; i++) {
        answer += pairs[pairs.length - 1 - i] - pairs[i];
    }
    return answer;
};
Python 3
from typing import List


class Solution:
    def putMarbles(self, weights: List[int], k: int) -> int:
        pairs = sorted(
            weights[i] + weights[i + 1]
            for i in range(len(weights) - 1)
        )

        cuts = k - 1
        return sum(pairs[-cuts:]) - sum(pairs[:cuts]) if cuts else 0
C++
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    long long putMarbles(vector<int>& weights, int k) {
        vector<long long> pairs;
        pairs.reserve(weights.size() - 1);
        for (int i = 0; i + 1 < weights.size(); ++i) {
            pairs.push_back((long long)weights[i] + weights[i + 1]);
        }

        sort(pairs.begin(), pairs.end());
        long long answer = 0;
        for (int i = 0; i < k - 1; ++i) {
            answer += pairs[pairs.size() - 1 - i] - pairs[i];
        }
        return answer;
    }
};

面试追问

  • 能否不用完整排序？ 用两个定长堆，或用选择算法找分界。
  • 如何还原具体分包？ 相邻和与原下标一起排序，再按选中下标切分。
  • 数据流不断到来呢？ 分别维护最小和最大 k−1 项的堆。
  • 允许负权重会怎样？ 推导不变，仍选择最小/最大相邻和。

常见错误

  • 对珠子重量本身排序，破坏了相邻关系。
  • 选择 k 个切口，而不是 k−1 个。
  • 分别计算完整最高/最低分，却错误地重复计入端点。
  • Java/C++ 使用 32 位累加导致溢出。
  • JavaScript 忘记给 sort 提供数值比较函数。
