Reachable Nodes With Restrictions

一棵树，一些禁行节点。从 0 出发，你能走到哪里？

阅读题目 ↓

01 / 题目

给定一棵无向树，包含编号为 0 到 n - 1 的 n 个节点。二维数组 edges 有 n - 1 项，每项 [aᵢ, bᵢ] 表示连接两节点的一条无向边。数组 restricted 列出禁止访问的节点。

求从节点 0 出发，全程不进入任何受限节点时，可以到达的节点总数。起点 0 也计入；题目保证 0 不受限。

“最多”统计的是所有可到达节点的集合大小。路线中只要经过受限节点，就不允许继续通行。

参数与返回值

reachableNodes(n: integer, edges: integer[][],
               restricted: integer[]) → integer

完整约束

  • 2 ≤ n ≤ 10⁵。
  • edges.length == n - 1，edges[i].length == 2。
  • 0 ≤ aᵢ, bᵢ < n，且 aᵢ != bᵢ。
  • edges 构成一棵有效的树。
  • 1 ≤ restricted.length < n。
  • 1 ≤ restricted[i] < n，所有受限节点编号互不相同。

示例 1

n = 7
edges = [[0,1],[1,2],[3,1],[4,0],[0,5],[5,6]]
restricted = [4,5]
输出：4

可到达节点为 [0,1,2,3]。节点 6 虽未受限，但通向它的路线被节点 5 阻断。

示例 2

n = 7
edges = [[0,1],[0,2],[0,5],[0,4],[3,2],[6,5]]
restricted = [4,2,1]
输出：3

可到达节点为 [0,5,6]。节点 3 本身可通行，但无法越过节点 2 到达它。

04 / 独立题解

先想一想：不受限的节点，一定能到达吗？

核心洞察：统计 0 所在的可通行连通块

把受限节点以及连接它们的边视为不可通行。答案就是剩余图里包含 0 的连通块大小。“最多”无需搜索最优路线，因为所有合法可达节点都可以计入。

完整过程 · 广度优先遍历（BFS）

  1. 建立双向邻接表；每条无向边同时加入两个端点的邻居列表。
  2. 用 blocked 标记受限节点，用 seen 标记已发现节点。
  3. 将 0 加入队列，立即标记 seen[0] = true，计数从 1 开始。
  4. 取出队首 u。遍历它的每个邻居 v；若 v 受限或已发现就跳过，否则立即标记、入队，并将计数加 1。
  5. 队列为空时返回计数。示例 1 中队列从 [0] 变为 [1]，再变为 [2,3]，最后清空，计数为 4。

正确性证明

合法性：初始队列中的 0 合法。每次新入队节点均与一个已到达节点相邻，且不受限，因此通过归纳，所有计数节点都有从 0 出发的合法路径。

完整性：任取一个合法可达节点 x，考察 0 到 x 的路径。0 已被发现；当路径上一个节点被处理时，它的下一个未发现节点必定不受限，因而会入队。沿路径归纳，x 最终被发现。

不重不漏与终止：入队时立即标记 seen，每个节点最多入队一次，因此计数无重复，过程有限。结合合法性和完整性，返回值恰为所有合法可达节点的数量。

边界与复杂度

  • 所有其他节点都受限时，仍返回 1，不能漏掉起点。
  • 限制内部节点会阻断其后方整段分支；不能直接计算 n - restricted.length。
  • 最长链可有 10⁵ 个节点，采用迭代遍历避免递归栈溢出。
  • 时间 O(n)：建图 O(n)，每个可达节点最多处理一次，每条邻接项最多检查一次。
  • 额外空间 O(n)：双向邻接表、两个标记数组和队列。即使可达节点很少，完整建图仍需 O(n)。

替代方案

迭代 DFS 用栈替换队列，同样为 O(n) 时间和空间。树上还可在栈中记录父节点以避免回边，省去 seen；若推广到有环图则仍需 seen。并查集可以只合并两端均不受限的边，再查询 0 的集合大小，时间 O(n α(n))、空间 O(n)，单次查询通常不如直接遍历简洁。

常见错误

  • 只建单向边：输入端点没有父子方向保证。
  • 受限节点不计数却继续扩展它的邻居：这相当于违规穿越。
  • 既不记录父节点也不记录 seen：无向边会导致反复往返。
  • JavaScript 反复使用 shift()：可能造成大量数组搬移；改用头下标。
  • 只在出队时标记却在入队时计数：推广到一般图会重复计数。

面试追问

若不是树？保留 seen 的 BFS 仍成立，复杂度变为 O(n + m)。若要最短路径？BFS 记录距离和前驱即可。若受限集合固定、起点多次变化？可预先标记所有可通行连通块并记录大小。若限制动态变化？删除节点可能拆分连通块，普通并查集不能直接处理，需按查询方式选择离线逆序或其他动态连通方法。

Java · 官方签名

import java.util.ArrayList;
import java.util.List;

class Solution {
    public int reachableNodes(int n, int[][] edges, int[] restricted) {
        List<List<Integer>> graph = new ArrayList<>(n);
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        boolean[] blocked = new boolean[n], seen = new boolean[n];
        for (int v : restricted) blocked[v] = true;
        int[] queue = new int[n];
        int head = 0, tail = 1;
        queue[0] = 0;
        seen[0] = true;
        while (head < tail) {
            int u = queue[head++];
            for (int v : graph.get(u)) {
                if (blocked[v] || seen[v]) continue;
                seen[v] = true;
                queue[tail++] = v;
            }
        }
        return tail;
    }
}

JavaScript · 官方签名

/**
 * @param {number} n
 * @param {number[][]} edges
 * @param {number[]} restricted
 * @return {number}
 */
var reachableNodes = function(n, edges, restricted) {
    const graph = Array.from({ length: n }, () => []);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
    }
    const blocked = new Uint8Array(n);
    const seen = new Uint8Array(n);
    for (const v of restricted) blocked[v] = 1;
    const queue = [0];
    seen[0] = 1;
    for (let head = 0; head < queue.length; head++) {
        const u = queue[head];
        for (const v of graph[u]) {
            if (blocked[v] || seen[v]) continue;
            seen[v] = 1;
            queue.push(v);
        }
    }
    return queue.length;
};

Python 3 · 官方签名

from collections import deque
from typing import List

class Solution:
    def reachableNodes(self, n: int, edges: List[List[int]],
                       restricted: List[int]) -> int:
        graph = [[] for _ in range(n)]
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)
        blocked = [False] * n
        seen = [False] * n
        for v in restricted:
            blocked[v] = True
        queue = deque([0])
        seen[0] = True
        count = 1
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                if blocked[v] or seen[v]:
                    continue
                seen[v] = True
                queue.append(v)
                count += 1
        return count

C++ · 官方签名

#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    int reachableNodes(int n, vector<vector<int>>& edges,
                       vector<int>& restricted) {
        vector<vector<int>> graph(n);
        for (const auto& e : edges) {
            graph[e[0]].push_back(e[1]);
            graph[e[1]].push_back(e[0]);
        }
        vector<bool> blocked(n, false), seen(n, false);
        for (int v : restricted) blocked[v] = true;
        queue<int> q;
        q.push(0);
        seen[0] = true;
        int count = 1;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : graph[u]) {
                if (blocked[v] || seen[v]) continue;
                seen[v] = true;
                q.push(v);
                ++count;
            }
        }
        return count;
    }
};

Java 的 tail 与 JavaScript 的 queue.length 保留了全部入队记录，因此可直接作为计数。Python / C++ 的队列会移除元素，使用独立 count。
