题意

在双向升序矩阵中找目标

给定一个 M × N 矩阵，每一行从左到右升序、每一列从上到下升序。判断 target 是否存在。矩阵可能为空；题目只要求返回布尔值。

题解

核心洞察

右上角是唯一的“双向裁决点”

右上角元素左边都不大于它，下方都不小于它。因此若当前值大于目标，当前列从这里向下全部过大，可删列；若当前值小于目标，当前行从这里向左全部过小，可删行。

不变量

目标若存在，一直留在左下候选矩形

指针每次只左移一列或下移一行。被删除的区域已经由单调性证明不可能含目标，所以无需回溯。

完整过程

  1. 1. 空矩阵直接返回 false。
  2. 2. 从 (0, n-1) 开始。
  3. 3. 大则左移，小则下移，相等返回 true。
  4. 4. 越界仍未命中，返回 false。

边界

  • 空矩阵或零列。
  • 单行、单列与单元素。
  • 目标小于最小值或大于最大值。
  • 允许重复值，遇到任一相等即可返回。

复杂度

时间
O(M + N)，每次删除一行或一列。
空间
O(1)，只保存坐标。

常见错误

  • 从左上角开始，两个方向都变大，无法唯一决策。
  • 没有先判断空矩阵就访问 matrix[0]。
  • 比较方向写反：大要左移，小要下移。
  • 循环条件少写一侧越界检查。

替代方案

方案 时间 空间 评价
右上角阶梯搜索 O(M+N) O(1) 面试首选，证明简洁。
逐行二分 O(M log N) O(1) 容易想到，没充分利用列有序。
分治 约 O(N^log₂3) 递归栈 可扩展思维，但实现和边界更复杂。

面试追问

  • 为什么左下角同样可行？移动规则如何镜像？
  • 若只有每行有序、列无序，复杂度会变成什么？
  • 若要返回全部坐标且存在重复值，如何避免漏解？
  • 怎样把候选矩形不变量写成形式化证明？

一句话证明

右上角比左侧不小、比下方不大，因此每次比较至少安全排除一整行或一整列；指针单调移动，终止且完备。

class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return false;
        }

        int row = 0;
        int col = matrix[0].length - 1;
        while (row < matrix.length && col >= 0) {
            int value = matrix[row][col];
            if (value == target) {
                return true;
            }
            if (value > target) {
                col--;
            } else {
                row++;
            }
        }
        return false;
    }
}

  let row = 0;
  let col = matrix[0].length - 1;
  while (row < matrix.length && col >= 0) {
    const value = matrix[row][col];
    if (value === target) return true;
    if (value > target) col -= 1;
    else row += 1;
  }
  return false;
