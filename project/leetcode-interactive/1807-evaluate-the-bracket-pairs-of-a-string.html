STRING LAB / 1807 MEDIUM

替换字符串中的括号内容

Evaluate the Bracket Pairs of a String

括号里是名字，括号外是原文。先想想：哪些字符应该保留，哪些应当整段替换？

官方题目 ↗

01 / 题目

给定字符串 s 和二维字符串数组 knowledge，其中每项 [keyᵢ, valueᵢ] 表示一组键值关系。将 s 内每个 (key) 整体替换为对应的值；查不到时替换为 ?。括号外的字符原样保留，返回最终字符串。

括号合法、不嵌套，内部键非空；知识表中的键互不重复，但字符串可多次引用同一个键。

参数与返回值

evaluate(s: string, knowledge: string[][]) → string

约束

  • 1 ≤ s.length ≤ 10⁵；0 ≤ knowledge.length ≤ 10⁵。
  • knowledge[i].length = 2；1 ≤ keyᵢ.length, valueᵢ.length ≤ 10。
  • s 仅含小写英文字母和圆括号，每个左括号均有对应右括号。
  • 每对括号内部非空，无嵌套。
  • keyᵢ 和 valueᵢ 仅含小写英文字母；knowledge 中的 keyᵢ 唯一。

02 / 官方示例

示例 1 · 两次替换

s = "(name)is(age)yearsold"
knowledge = [["name","bob"],["age","two"]]
输出 = "bobistwoyearsold"

(name) 替换为 bob，(age) 替换为 two。

示例 2 · 未知键

s = "hi(name)"
knowledge = [["a","b"]]
输出 = "hi?"

name 不在知识表中，整对括号替换为一个问号。

示例 3 · 重复引用

s = "(a)(a)(a)aaa"
knowledge = [["a","yes"]]
输出 = "yesyesyesaaa"

三处括号分别替换，末尾的 aaa 保留。

05 / 独立题解
先自己推演，再展开思路与四语言实现。
核心洞察：边界比替换更重要
没有嵌套，所以无需栈。先用哈希表保存 knowledge，再用 start 表示当前键的起点；-1 表示在括号外。不要在原字符串上反复修改，只向结果末尾追加。
完整过程
  1. 建立 key → value 哈希表，结果置空，start = -1。
  2. 遇到左括号，记录 start = i + 1。
  3. 遇到右括号，截取 s[start:i]，查表并追加值或 ?，然后令 start = -1。
  4. 遇到普通字符：括号外追加，括号内暂不输出。
  5. 扫描结束，将结果片段合并并返回。
正确性
循环不变式：每次扫描后，结果恰为已扫描前缀中所有已完成单元的正确替换；若处于括号内部，start 指向尚未完成键的首字符。初始为空显然成立。普通外部字符直接追加保持原文；左括号只开启未完成单元；内部字符不应输出；右括号使该单元完成，追加映射值或问号正好符合规则。合法且配对的括号保证终止时没有未完成单元，因此结果覆盖整个字符串。
边界与常见错误
  • 空知识表：所有括号单元变成 ?；没有括号：直接返回原文。
  • 连续括号、重复键每次独立处理，不能移除用过的映射。
  • 切片不含两个括号；处理右括号后必须重置 start。
  • 不能全局替换裸键，否则会误改括号外字符。
  • 避免反复拼接不可变长字符串；Java 用 StringBuilder，JS/Python 用片段数组。
复杂度
令 n 为 s 长度，K 为知识表全部键和值的总字符数，L 为输出长度。哈希表平均查找假设下，时间 O(K + n + L)，包含建表、键哈希和结果构造；空间 O(K + n + L)，包含表、结果片段及临时键。若只算输出以外的辅助空间，最大待查键长度记为 b，则扫描与表占 O(K + b)，JS/Python 的片段数组另占 O(n)。哈希冲突严重时查找可能退化。
替代方案
正则匹配括号并通过回调查表更短，但依赖语言替换 API；逐段双指针寻找右括号与本方案同阶。逐个遍历 knowledge 做多轮替换会重复扫描字符串，且还要额外处理未知键。只有扩展为嵌套语法时才考虑栈或递归解析。
面试追问
输出很大怎么办？向可写流逐段输出，避免保存完整结果。映射值中也含括号呢？本题值只有小写字母；扩展后需先定义是否递归替换及循环引用策略。支持嵌套呢？必须明确内层替换是否参与外层键构造，再设计栈。
JavaScript
/** @param {string} s @param {string[][]} knowledge @return {string} */
var evaluate = function(s, knowledge) {
    const dict = new Map(knowledge), out = [];
    let start = -1;
    for (let i = 0; i < s.length; i++) {
        if (s[i] === '(') start = i + 1;
        else if (s[i] === ')') {
            out.push(dict.get(s.slice(start, i)) ?? '?');
            start = -1;
        } else if (start === -1) out.push(s[i]);
    }
    return out.join('');
};
Java
import java.util.*;
class Solution {
    public String evaluate(String s, List<List<String>> knowledge) {
        Map<String, String> dict = new HashMap<>();
        for (List<String> pair : knowledge) dict.put(pair.get(0), pair.get(1));
        StringBuilder out = new StringBuilder();
        int start = -1;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(') start = i + 1;
            else if (c == ')') {
                out.append(dict.getOrDefault(s.substring(start, i), "?"));
                start = -1;
            } else if (start == -1) out.append(c);
        }
        return out.toString();
    }
}
Python
from typing import List
class Solution:
    def evaluate(self, s: str, knowledge: List[List[str]]) -> str:
        mapping = dict(knowledge)
        out = []
        start = -1
        for i, c in enumerate(s):
            if c == '(':
                start = i + 1
            elif c == ')':
                out.append(mapping.get(s[start:i], '?'))
                start = -1
            elif start == -1:
                out.append(c)
        return ''.join(out)
C++
#include <string>
#include <vector>
#include <unordered_map>
using namespace std;
class Solution {
public:
    string evaluate(string s, vector<vector<string>>& knowledge) {
        unordered_map<string, string> dict;
        for (const auto& pair : knowledge) dict[pair[0]] = pair[1];
        string out;
        int start = -1;
        for (int i = 0; i < (int)s.size(); ++i) {
            if (s[i] == '(') start = i + 1;
            else if (s[i] == ')') {
                auto it = dict.find(s.substr(start, i - start));
                out += it == dict.end() ? "?" : it->second;
                start = -1;
            } else if (start == -1) out += s[i];
        }
        return out;
    }
};
