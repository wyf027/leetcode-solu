Problem / 02

题意与接口

设计一个完全驻留在内存中的简化文件系统。路径是绝对路径，目录可递归创建，文件内容支持追加，并且目录列表必须保持字典序。

任务说明

实现 FileSystem 类。系统需要区分目录与文件：列出目录时返回该目录下第一层的全部目录名和文件名；列出文件路径时只返回该文件自身的名称。所有列出结果按字典序排列。

创建目录时，路径中缺失的父目录也要一并创建。向文件写入内容时，如果文件不存在就创建它；如果已经存在，则把新内容追加在原内容之后。读取文件时返回它当前的完整文本。

官方方法签名

  • FileSystem() 初始化一个空文件系统，根目录始终为 /。
  • List<String> ls(String path) 列出目录的直接子项；若 path 指向文件，仅返回文件名。
  • void mkdir(String path) 递归创建指定目录以及缺失的中间目录。
  • void addContentToFile(String filePath, String content) 新建文件或把 content 追加到已有文件。
  • String readContentFromFile(String filePath) 返回指定文件保存的全部内容。

调用 参数 结果 含义

ls ["/"] [] 根目录暂时没有子项。

约束

  • 1 <= path.length, filePath.length <= 100
  • path 与 filePath 均为以 / 开头的绝对路径；除根路径外，不以 / 结尾。
  • 目录名和文件名只包含小写英文字母；同一目录中不会出现重名项。
  • 所有操作参数均有效，不会读取或列出不存在的路径。
  • 1 <= content.length <= 50
  • ls、mkdir、addContentToFile 与 readContentFromFile 合计最多调用 300 次。

Solution / 04

准备好再展开题解

先独立想一想：目录与文件是否可以共用一种节点？每次路径操作中，真正重复的步骤是什么？

Core insight

一棵路径树，统一承载目录和文件

把根目录作为树根，每一段路径名作为一条边。每个节点保存“名称到子节点”的映射、是否为文件的标记，以及仅文件需要的内容。四个接口因此都归结为同一件事：按 / 拆分路径，然后从根节点逐段向下走。

完整过程

  1. 根节点表示 /，初始没有任何子节点。
  2. mkdir 逐段访问路径；不存在的子节点立即创建。
  3. addContentToFile 同样走到末节点，把它标记为文件并追加内容。
  4. readContentFromFile 找到末节点后直接返回内容。
  5. ls 需要分支处理：文件返回自身名称；目录收集全部直接子节点名并排序。

边界处理

  • 根路径 / 拆分后没有有效路径段，应直接返回根节点。
  • 文件路径执行 ls 时不能列出孩子，而要返回最后一段文件名。
  • 重复写同一文件是追加，不是覆盖。
  • 目录只列直接子项，不递归列出后代。
  • 输出排序与内部容器是否有序无关；若用哈希表，返回前显式排序。

正确性说明

对任意有效绝对路径，路径中的第 i 段唯一对应根节点向下第 i 层的节点。逐段查找（或创建）保持这一对应关系，因此遍历结束时一定到达该路径表示的对象。

mkdir 为每个缺失路径段补节点，所以目标目录及所有中间目录均存在；addContentToFile 到达唯一末节点后追加字符串，所以保存内容恰好等于历次写入的串联；readContentFromFile 返回该节点内容，结果因此正确。对 ls，文件分支返回唯一文件名，目录分支枚举且仅枚举直接子节点，再排序，所以返回集合与顺序都满足要求。故四个接口均正确。

复杂度

设路径含 d 段，总字符数为 L，待列目录有 k 个直接子项。

  • 路径解析与遍历：平均 O(L)。
  • mkdir：平均 O(L)，新增空间最多 O(L)。
  • 追加/读取：遍历为 O(L)；另计写入或返回文本的字符量。
  • ls：文件为 O(L)；目录为 O(L + k log k)。
  • 总空间：所有节点、名称与文件内容之和。

替代方案

可以分别用两个映射保存“完整目录路径 → 子项集合”和“完整文件路径 → 内容”。它更直接，但每次创建目录都要维护父目录的子项，路径层级关系也被拆散。路径树更自然地表达层级，也更容易扩展删除、移动、前缀查询和权限等能力。

常见错误

  • 忘记区分“对目录 ls”和“对文件 ls”。
  • 用覆盖赋值实现追加写入。
  • 返回哈希表键时没有排序。
  • 拆分 / 后把空字符串当成节点名。
  • 只创建末级目录，遗漏中间目录。

实现备注

Java、JavaScript 与 Python 使用哈希映射，并在 ls 时排序；C++ 使用 map，遍历键时天然按字典序。四份代码均遵循官方 FileSystem 类与四个方法的提交形式。

四语言完整代码

Java · 官方提交形式HashMap + sort
import java.util.*;

class FileSystem {
    private static class FsNode {
        Map<String, FsNode> children = new HashMap<>();
        boolean isFile = false;
        StringBuilder content = new StringBuilder();
    }

    private final FsNode root;

    public FileSystem() {
        root = new FsNode();
    }

    public List<String> ls(String path) {
        FsNode node = find(path, false);
        if (node.isFile) {
            return Collections.singletonList(lastName(path));
        }

        List<String> names = new ArrayList<>(node.children.keySet());
        Collections.sort(names);
        return names;
    }

    public void mkdir(String path) {
        find(path, true);
    }

    public void addContentToFile(String filePath, String content) {
        FsNode file = find(filePath, true);
        file.isFile = true;
        file.content.append(content);
    }

    public String readContentFromFile(String filePath) {
        return find(filePath, false).content.toString();
    }

    private FsNode find(String path, boolean create) {
        FsNode current = root;
        if (path.equals("/")) {
            return current;
        }

        for (String name : path.substring(1).split("/")) {
            if (create) {
                current.children.putIfAbsent(name, new FsNode());
            }
            current = current.children.get(name);
        }
        return current;
    }

    private String lastName(String path) {
        return path.substring(path.lastIndexOf('/') + 1);
    }
}
JavaScript · 官方提交形式Map + sort
class FsNode {
  constructor() {
    this.children = new Map();
    this.isFile = false;
    this.content = "";
  }
}

var FileSystem = function () {
  this.root = new FsNode();
};

FileSystem.prototype._find = function (path, create) {
  let current = this.root;
  const parts = path.split("/").filter(Boolean);

  for (const name of parts) {
    if (create && !current.children.has(name)) {
      current.children.set(name, new FsNode());
    }
    current = current.children.get(name);
  }

  return current;
};

FileSystem.prototype.ls = function (path) {
  const node = this._find(path, false);
  if (node.isFile) {
    const parts = path.split("/").filter(Boolean);
    return [parts[parts.length - 1]];
  }
  return Array.from(node.children.keys()).sort();
};

FileSystem.prototype.mkdir = function (path) {
  this._find(path, true);
};

FileSystem.prototype.addContentToFile = function (filePath, content) {
  const file = this._find(filePath, true);
  file.isFile = true;
  file.content += content;
};

FileSystem.prototype.readContentFromFile = function (filePath) {
  return this._find(filePath, false).content;
};
Python · 官方提交形式dict + sorted
class FsNode:
    def __init__(self):
        self.children = {}
        self.is_file = False
        self.content = ""


class FileSystem:
    def __init__(self):
        self.root = FsNode()

    def _find(self, path: str, create: bool) -> FsNode:
        current = self.root
        for name in path.split("/"):
            if not name:
                continue
            if create and name not in current.children:
                current.children[name] = FsNode()
            current = current.children[name]
        return current

    def ls(self, path: str) -> list[str]:
        node = self._find(path, False)
        if node.is_file:
            return [path.rsplit("/", 1)[-1]]
        return sorted(node.children.keys())

    def mkdir(self, path: str) -> None:
        self._find(path, True)

    def addContentToFile(self, filePath: str, content: str) -> None:
        file = self._find(filePath, True)
        file.is_file = True
        file.content += content

    def readContentFromFile(self, filePath: str) -> str:
        return self._find(filePath, False).content
C++ · 官方提交形式map + unique_ptr
class FileSystem {
    struct FsNode {
        map<string, unique_ptr<FsNode>> children;
        bool isFile = false;
        string content;
    };

    unique_ptr<FsNode> root;

    vector<string> parts(const string& path) {
        vector<string> result;
        string name;

        for (char ch : path) {
            if (ch == '/') {
                if (!name.empty()) {
                    result.push_back(name);
                    name.clear();
                }
            } else {
                name.push_back(ch);
            }
        }
        if (!name.empty()) result.push_back(name);
        return result;
    }

    FsNode* find(const string& path, bool create) {
        FsNode* current = root.get();

        for (const string& name : parts(path)) {
            if (create && !current->children.count(name)) {
                current->children[name] = make_unique<FsNode>();
            }
            current = current->children[name].get();
        }
        return current;
    }

public:
    FileSystem() : root(make_unique<FsNode>()) {}

    vector<string> ls(string path) {
        FsNode* node = find(path, false);
        if (node->isFile) {
            size_t slash = path.find_last_of('/');
            return {path.substr(slash + 1)};
        }

        vector<string> names;
        for (const auto& entry : node->children) {
            names.push_back(entry.first);
        }
        return names;
    }

    void mkdir(string path) {
        find(path, true);
    }

    void addContentToFile(string filePath, string content) {
        FsNode* file = find(filePath, true);
        file->isFile = true;
        file->content += content;
    }

    string readContentFromFile(string filePath) {
        return find(filePath, false)->content;
    }
};

面试追问

如果调用量和目录规模显著增大，如何优化 ls？

可以让每个目录使用有序映射，或缓存已排序的子项名，并在目录结构变更时使缓存失效。需要权衡写入成本、内存开销与列表读取频率。

如何支持删除与移动？

删除要从父节点移除对应边；移动需要先定位源节点与两个父节点，再检查目标冲突和“目录移动到自身后代”等非法情况。

如何支持并发访问？

可从全局读写锁开始，随后细化为节点级锁或路径级锁。多节点操作需要稳定的加锁顺序，以避免死锁和观察到中间状态。

如果文件内容很大，字符串追加还合适吗？

不一定。可改用分块内容、rope、追加日志或对象存储引用，避免每次追加产生大规模复制，并为范围读取保留空间。
