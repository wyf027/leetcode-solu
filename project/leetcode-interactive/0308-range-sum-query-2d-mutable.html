矩阵可修改

在同一张矩阵上交替完成单点赋值与矩形区域求和。先理解接口与数据流，再决定怎样让两类操作都足够快。

01 / Problem

题目转述

设计 NumMatrix，保存一个整数矩阵，并支持修改某个单元格，以及计算包含边界的矩形区域元素之和。

接口要求

NumMatrix(int[][] matrix)
用给定矩阵初始化对象。
void update(int row, int col, int val)
把 matrix[row][col] 赋值为 val。
int sumRegion(int row1, int col1, int row2, int col2)
返回左上角 (row1, col1) 到右下角 (row2, col2) 的闭区间矩形和。

关键语义

更新是“赋值”而非“累加”；查询矩形包含四条边及四个角。调用顺序可以任意交错，后续查询必须反映之前的更新。

约束

  • m == matrix.length，n == matrix[i].length
  • 1 <= m, n <= 200
  • -10^5 <= matrix[i][j] <= 10^5
  • 0 <= row < m，0 <= col < n
  • -10^5 <= val <= 10^5
  • 0 <= row1 <= row2 < m
  • 0 <= col1 <= col2 < n
  • update 与 sumRegion 总调用次数不超过 10^4

官方示例（完整调用形式）

输入
["NumMatrix", "sumRegion", "update", "sumRegion"]
[[[[3, 0, 1, 4, 2],
   [5, 6, 3, 2, 1],
   [1, 2, 0, 1, 5],
   [4, 1, 0, 1, 7],
   [1, 0, 3, 0, 5]]],
 [[2, 1, 4, 3]],
 [[3, 2, 2]],
 [[2, 1, 4, 3]]]

输出
[null, 8, null, 10]

初始化后，第一次查询区域和为 8；把坐标 (3, 2) 从 0 改为 2；同一区域再次查询得到 10。构造与无返回值的更新对应 null。

    04 / Deep dive

    题解：二维树状数组

    把一维树状数组的“低位块”同时扩展到行、列两个维度。每个节点维护一个右下角固定、尺寸由两个 lowbit 决定的子矩形和。

    核心洞察

    任意闭区间矩形可以用四个二维前缀和做容斥：

    R = P(r2,c2) - P(r1-1,c2) - P(r2,c1-1) + P(r1-1,c1-1)

    因此问题变成：在单点赋值后，仍能快速维护并查询二维前缀和。二维树状数组让更新与前缀查询都只沿若干个低位块跳转。

    状态定义

    • values[r][c] 保存当前真实值，用于把赋值转换成差量 delta = val - old。
    • tree[i][j] 保存行区间 (i-lowbit(i), i] 与列区间 (j-lowbit(j), j] 的笛卡尔积之和。
    • 对外矩阵坐标是 0 基；树状数组内部统一加一，避免索引 0 无法跳转。

    完整过程

    01
    初始化。创建全零的 values 与 tree，对每个原始单元调用一次 update，复用同一套差量维护逻辑。
    02
    单点赋值。计算新旧差值 delta。从内部坐标 (row+1,col+1) 出发，行和列分别执行 x += lowbit(x)，把差量加入所有覆盖该点的树节点。
    03
    前缀查询。从内部坐标 (row+1,col+1) 出发，行和列分别执行 x -= lowbit(x)，累加互不重叠的低位块，直到任一维回到 0。
    04
    矩形查询。右下前缀减去上方与左方前缀；左上重叠区域被减了两次，再加回一次。

    正确性证明

    引理 1：更新覆盖完整

    二维树节点 tree[i][j] 对应一个低位块矩形。沿两维执行 += lowbit 恰好枚举所有包含目标单元的祖先块，因此每个相关块都增加 delta，无关块保持不变。

    引理 2：前缀和正确

    沿两维执行 -= lowbit 得到的低位块两两不重叠，并恰好铺满从原点到查询坐标的前缀矩形；累加它们即得到该前缀的真实元素和。

    定理：sumRegion 正确

    由引理 1，任意时刻树中各块都与当前矩阵一致；由引理 2，四个前缀值正确。二维容斥保留目标矩形中的每个单元恰好一次、外部单元零次，所以返回值就是所求区域和。

    复杂度与边界

    UpdateO(log m · log n)
    QueryO(log m · log n)
    SpaceO(m · n)
    • 单行、单列和 1×1 矩阵无需特判。
    • row1=0 或 col1=0 时，负下标前缀直接返回 0。
    • 更新为相同值时 delta=0，结构保持不变。
    • 矩阵允许负数；容斥公式仍成立。
    • 内部累计可使用 64 位整数，接口按题目签名返回整数。

    替代方案

    • 直接扫描：更新 O(1)，查询 O(mn)。仅适合查询极少。
    • 逐行前缀和：更新一整行 O(n)，区域查询 O(m)；实现简单，是常见折中。
    • 二维线段树：同阶复杂度，但代码、常数与内存通常更大；若需要更复杂的区间合并信息才更有优势。
    • 二维静态前缀和：查询 O(1)，但单点更新需重建大量状态，不适合本题的可修改场景。

    常见错误

    • 把赋值 val 直接加进树中，忘记先计算差量。
    • 外部 0 基与内部 1 基混用，导致死循环或整行偏移。
    • 容斥最后一项写成减号，或忘记 r1-1、c1-1。
    • 前缀查询内层列索引没有在每个新行索引处重置。
    • 累计量使用过窄的整数类型，边界数据发生溢出。

    面试追问

    更新远少于查询？

    可讨论逐行前缀或分块，并基于操作比例比较常数与实现成本。

    怎样把初始化降到 O(mn)？

    先放入原值，再分别沿行、列把节点贡献传播到直接父节点；需谨慎避免重复累计。

    支持矩形加、矩形和？

    可以推广到多棵二维树状数组，用二维差分与加权前缀组合维护。

    矩阵非常稀疏？

    可用哈希映射保存访问到的树节点，或先离线做坐标压缩。

    Javalong 内部累计
    class NumMatrix {
    private final int rows;
    private final int cols;
    private final int[][] values;
    private final long[][] tree;

    public NumMatrix(int[][] matrix) {
        rows = matrix.length;
        cols = matrix[0].length;
        values = new int[rows][cols];
        tree = new long[rows + 1][cols + 1];

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                update(r, c, matrix[r][c]);
            }
        }
    }

    public void update(int row, int col, int val) {
        long delta = (long) val - values[row][col];
        values[row][col] = val;

        for (int i = row + 1; i <= rows; i += i & -i) {
            for (int j = col + 1; j <= cols; j += j & -j) {
                tree[i][j] += delta;
            }
        }
    }

    public int sumRegion(int row1, int col1, int row2, int col2) {
        long answer = prefix(row2, col2)
                - prefix(row1 - 1, col2)
                - prefix(row2, col1 - 1)
                + prefix(row1 - 1, col1 - 1);
        return (int) answer;
    }

    private long prefix(int row, int col) {
        long sum = 0;
        for (int i = row + 1; i > 0; i -= i & -i) {
            for (int j = col + 1; j > 0; j -= j & -j) {
                sum += tree[i][j];
            }
        }
        return sum;
    }
}

    var NumMatrix = function(matrix) {
    this.rows = matrix.length;
    this.cols = matrix[0].length;
    this.values = Array.from(
        { length: this.rows },
        () => Array(this.cols).fill(0)
    );
    this.tree = Array.from(
        { length: this.rows + 1 },
        () => Array(this.cols + 1).fill(0)
    );

    for (let r = 0; r < this.rows; r++) {
        for (let c = 0; c < this.cols; c++) {
            this.update(r, c, matrix[r][c]);
        }
    }
};

NumMatrix.prototype.update = function(row, col, val) {
    const delta = val - this.values[row][col];
    this.values[row][col] = val;

    for (let i = row + 1; i <= this.rows; i += i & -i) {
        for (let j = col + 1; j <= this.cols; j += j & -j) {
            this.tree[i][j] += delta;
        }
    }
};

NumMatrix.prototype.sumRegion = function(row1, col1, row2, col2) {
    return this.prefix(row2, col2)
        - this.prefix(row1 - 1, col2)
        - this.prefix(row2, col1 - 1)
        + this.prefix(row1 - 1, col1 - 1);
};

    PythonLeetCode 提交格式
    from typing import List


class NumMatrix:
    def __init__(self, matrix: List[List[int]]):
        self.rows = len(matrix)
        self.cols = len(matrix[0])
        self.values = [
            [0] * self.cols for _ in range(self.rows)
        ]
        self.tree = [
            [0] * (self.cols + 1)
            for _ in range(self.rows + 1)
        ]

        for row in range(self.rows):
            for col in range(self.cols):
                self.update(row, col, matrix[row][col])

    def update(self, row: int, col: int, val: int) -> None:
        delta = val - self.values[row][col]
        self.values[row][col] = val

        i = row + 1
        while i <= self.rows:
            j = col + 1
            while j <= self.cols:
                self.tree[i][j] += delta
                j += j & -j
            i += i & -i

    def sumRegion(
        self,
        row1: int,
        col1: int,
        row2: int,
        col2: int,
    ) -> int:
        return (
            self._prefix(row2, col2)
            - self._prefix(row1 - 1, col2)
            - self._prefix(row2, col1 - 1)
            + self._prefix(row1 - 1, col1 - 1)
        )

    def _prefix(self, row: int, col: int) -> int:
        total = 0
        i = row + 1
        while i > 0:
            j = col + 1
            while j > 0:
                total += self.tree[i][j]
                j -= j & -j
            i -= i & -i
        return total
    C++long long 内部累计
    class NumMatrix {
private:
    int rows;
    int cols;
    vector<vector<int>> values;
    vector<vector<long long>> tree;

    long long prefix(int row, int col) const {
        long long sum = 0;
        for (int i = row + 1; i > 0; i -= i & -i) {
            for (int j = col + 1; j > 0; j -= j & -j) {
                sum += tree[i][j];
            }
        }
        return sum;
    }

public:
    NumMatrix(vector<vector<int>>& matrix) {
        rows = matrix.size();
        cols = matrix[0].size();
        values.assign(rows, vector<int>(cols, 0));
        tree.assign(
            rows + 1,
            vector<long long>(cols + 1, 0)
        );

        for (int r = 0; r < rows; ++r) {
            for (int c = 0; c < cols; ++c) {
                update(r, c, matrix[r][c]);
            }
        }
    }

    void update(int row, int col, int val) {
        long long delta =
            static_cast<long long>(val) - values[row][col];
        values[row][col] = val;

        for (int i = row + 1; i <= rows; i += i & -i) {
            for (int j = col + 1; j <= cols; j += j & -j) {
                tree[i][j] += delta;
            }
        }
    }

    int sumRegion(int row1, int col1, int row2, int col2) {
        long long answer = prefix(row2, col2)
            - prefix(row1 - 1, col2)
            - prefix(row2, col1 - 1)
            + prefix(row1 - 1, col1 - 1);
        return static_cast<int>(answer);
    }
};
