01

任务简报

先理解“天际线不变”究竟限制了什么

一座城市由 n × n 个街区组成，每个街区恰有一栋竖直建筑。下标从 0 开始的整数矩阵 grid 中，grid[r][c] 表示第 r 行、第 c 列建筑的高度。

从东、南、西、北四个方向远望，建筑外轮廓分别形成城市的天际线。你可以把任意数量的建筑增高任意非负高度，包括原高度为 0 的建筑，但四个方向看到的天际线都不能改变。

请返回所有建筑可增加高度的最大总和。

解释

约束

  • n == grid.length
  • n == grid[r].length
  • 2 <= n <= 50
  • 0 <= grid[r][c] <= 100

03

完整题解

每个位置同时受所在行和所在列的轮廓约束

核心洞察：两个上限，取更小者

从东西方向看，同一行只有最高楼决定轮廓；从南北方向看，同一列只有最高楼决定轮廓。因此位置 (r, c) 增高后既不能超过第 r 行原最大值，也不能超过第 c 列原最大值。要让总增量最大，就把每栋楼独立增高到这两个上限中的较小值。

limit[r][c] = min(rowMax[r], colMax[c])
时间复杂度O(n²)
空间复杂度O(n)

1完整过程

  1. 初始化长度为 n 的 rowMax 与 colMax。
  2. 扫描整个矩阵，分别记录每一行与每一列的原始最大高度。
  3. 再次扫描每个位置，计算允许的最高高度 min(rowMax[r], colMax[c])。
  4. 把“允许高度减去原高度”累加，即得最大总增量。

2示例落地

示例一的行最大值为 [8,7,9,3]，列最大值为 [9,4,8,7]。例如位置 (1,0) 原高度为 2，上限是 min(7,9)=7，可增加 5；位置 (0,2) 原本就是行上限 8，不能再增加。全部位置累加得到 35。

3边界情况

  • 全 0 矩阵：所有行列上限都是 0，答案为 0。
  • 所有建筑等高：每个位置已等于行列上限，答案为 0。
  • 某位置是行最大值或列最大值：它的可增量可能为 0。
  • n = 2 与高度 100 都可直接按同一公式处理。

4替代方案

可以为每个位置分别重新扫描它所在的整行与整列寻找最大值，结果仍正确，但需要 O(n³) 时间。预处理两个一维最大值数组把重复工作压缩到 O(n²)。无需构造新矩阵，也无需排序或使用单调栈。

正确性证明

引理 1：任意位置 (r,c) 的新高度不能超过 rowMax[r]，否则从东或西方向看到的第 r 行轮廓会升高；同理，它也不能超过 colMax[c]。因此任何合法新高度都不大于二者的较小值。

引理 2：把位置 (r,c) 增高到 min(rowMax[r], colMax[c]) 是合法的。新高度不超过原行最大值和原列最大值，因此不会提高任一方向的轮廓；原来达到这些最大值的建筑没有降低，所以轮廓也不会变低。

定理：由引理 1，算法为每个位置选取了所有合法方案中的最高可能值；由引理 2，这些选择可同时成立且保持四向天际线。每个位置的增量都逐点最大，故其总和也是全局最大。

Solution.javaO(n²) time · O(n) space
class Solution {
    public int maxIncreaseKeepingSkyline(int[][] grid) {
        int n = grid.length;
        int[] rowMax = new int[n];
        int[] colMax = new int[n];

        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                rowMax[r] = Math.max(rowMax[r], grid[r][c]);
                colMax[c] = Math.max(colMax[c], grid[r][c]);
            }
        }

        int totalIncrease = 0;
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                int limit = Math.min(rowMax[r], colMax[c]);
                totalIncrease += limit - grid[r][c];
            }
        }
        return totalIncrease;
    }
}

from typing import List


class Solution:
    def maxIncreaseKeepingSkyline(self, grid: List[List[int]]) -> int:
        n = len(grid)
        row_max = [0] * n
        col_max = [0] * n

        for r in range(n):
            for c in range(n):
                row_max[r] = max(row_max[r], grid[r][c])
                col_max[c] = max(col_max[c], grid[r][c])

        total_increase = 0
        for r in range(n):
            for c in range(n):
                limit = min(row_max[r], col_max[c])
                total_increase += limit - grid[r][c]

        return total_increase

面试追问

为什么每栋楼可以独立增高？

所有限制都是“不能超过原行最大值、原列最大值”的上界。增高一栋楼到上界不会降低或抬高原最大轮廓，也不会收紧其他位置的上界。

矩阵不是正方形怎么办？

思路完全不变：分别建立行数长度和列数长度的最大值数组。只是本题官方约束固定为 n × n。

若允许降低建筑呢？

目标和约束会改变。原来唯一达到某行或列最大值的建筑不能随意降低，需要维护最大值是否有其他建筑支撑。

常见错误

只看行最大值或只看列最大值

会满足两个方向，却可能改变另外两个方向的天际线。

取两个上限的较大值

正确的是较小值；取较大值会越过另一个观察方向允许的高度。

把目标高度直接累加

题目要的是增量总和，应累加 limit - grid[r][c]，而不是累加 limit。

边扫描边修改 grid

若修改后的值参与后续最大值计算，会污染原始天际线。应先完成所有原始行列最大值的预处理。
