LeetCode 1052 · Medium

爱生气的
书店老板

有些分钟注定友好，有些分钟需要一段“冷静技巧”。拖动一扇固定长度的时间窗，找出能挽回最多顾客的时刻。

数组滑动窗口时间 O(n)空间 O(1)

题目

书店营业 n 分钟。customers[i] 表示第 i 分钟进入并在该分钟结束后离开的顾客数；grumpy[i] 为 1 表示老板生气，这一分钟的顾客不满意，为 0 则顾客满意。

老板可以且仅可以选择一次连续 minutes 分钟的区间，在其中保持不生气。求全天最多能有多少顾客满意。

示例 1

输入： customers = [1,0,1,2,1,1,7,5], grumpy = [0,1,0,1,0,1,0,1], minutes = 3
输出： 16
说明：在最后 3 分钟使用技巧，最多有 1 + 1 + 1 + 1 + 7 + 5 = 16 位顾客满意。

示例 2

输入： customers = [1], grumpy = [0], minutes = 1
输出： 1

约束

  • n == customers.length == grumpy.length
  • 1 <= minutes <= n <= 2 × 10⁴
  • 0 <= customers[i] <= 1000
  • grumpy[i] 只能是 0 或 1

冷静窗口实验室

橙框是当前长度为 3 的技巧区间；绿色底线表示原本满意，红色底线表示原本不满意。观察窗口怎样只“挽回”红色分钟。

原本满意10
当前挽回2
当前总数12

窗口 [0, 2]：挽回第 1 分钟的 0 位顾客。

先试着解释：为什么技巧区间只需统计老板原本生气时的顾客？

题解：把满意拆成“不动”与“可挽回”

核心洞察
老板本来不生气的分钟，其顾客无论技巧放在哪里都会满意，先全部计入 base。技巧唯一能增加的，是窗口内那些原本因生气而不满意的顾客；因此在 customers[i] × grumpy[i] 上寻找长度固定为 minutes 的最大窗口和。

完整过程

  1. 遍历数组，把所有 grumpy[i] == 0 的 customers[i] 累加为基础满意数。
  2. 维护长度不超过 minutes 的滑动窗口，加入右端点处可挽回人数 customers[right] × grumpy[right]。
  3. 窗口过长时减去离开窗口的左端贡献；每当窗口形成，更新最大可挽回人数。
  4. 返回 base + bestGain。

正确性证明

  1. 基础部分完备：所有 grumpy[i] = 0 的顾客始终满意，计入 base 且不会受技巧影响。
  2. 窗口收益准确：选定区间后，新增满意顾客恰好是区间内 grumpy[i] = 1 的顾客之和。
  3. 最优性：滑动窗口逐一考察每个长度为 minutes 的合法区间，bestGain 必为所有选择中的最大新增收益。因此两部分之和是全局最优答案。

复杂度与边界

时间：O(n)；额外空间：O(1)。

  • minutes == n：窗口覆盖全天，所有顾客都满意。
  • 老板从不生气：所有窗口收益均为 0。
  • 顾客数可为 0，不影响窗口移动。
  • 技巧只能用一次，但放在收益为 0 的任意窗口也等价合法。

替代方案

可先构造前缀和 prefix[i + 1] = prefix[i] + customers[i] × grumpy[i]，再枚举每个固定区间，时间同为 O(n)，但需 O(n) 空间。暴力枚举并重算每个区间则为 O(n × minutes)，在上界下不合适。

面试追问

  • 若技巧能使用两次且区间不能重叠？ 可用前后缀最优窗口或动态规划组合两个区间。
  • 若技巧长度至多为 minutes？ 因贡献非负，使用满长度不会更差。
  • 若每分钟收益可能为负？ 固定长度仍可滑窗；若长度可变，则转为受长度约束的最大子数组问题。

常见错误

  • 把窗口内原本就满意的顾客再次加入，造成重复计数。
  • 窗口左端移出时减错下标，或在窗口达到长度前过早更新。
  • 返回最大窗口收益而忘记加基础满意数。

四种语言实现

class Solution {
    public int maxSatisfied(int[] customers, int[] grumpy, int minutes) {
        int base = 0, gain = 0, bestGain = 0;
        for (int right = 0; right < customers.length; right++) {
            if (grumpy[right] == 0) base += customers[right];
            else gain += customers[right];
            if (right >= minutes && grumpy[right - minutes] == 1) {
                gain -= customers[right - minutes];
            }
            bestGain = Math.max(bestGain, gain);
        }
        return base + bestGain;
    }
}
