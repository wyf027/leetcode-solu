统计最高分的节点数目

Count Nodes With the Highest Score

拿走一个节点，看看整棵树会分成什么。

先理解分数的定义，再动手探索。完整推导与代码在底部按需展开。

01 / THE QUESTION

题目与输入约定

整数数组 parents 描述一棵含有 n 个节点的二叉树。节点编号为 0 … n−1，根是节点 0；parents[i] 表示节点 i 的父节点，根的父节点记为 -1。

对于任意节点，单独设想删除它以及所有相连的边。将剩余每个非空连通部分的节点数相乘，得到该节点的分数。返回达到全树最高分的节点数量。

每次删除都是独立假设，下一次仍从原树出发。调用形式为 countHighestScoreNodes(parents)，返回整数。

  • n == parents.length
  • 2 ≤ n ≤ 10⁵
  • parents[0] == -1
  • 对于所有 i ≠ 0，0 ≤ parents[i] ≤ n−1
  • 输入保证为合法二叉树，每个节点最多两个孩子。

官方示例

示例 1

输入：parents = [-1,2,0,2,0]
输出：3

节点 0、1、2、3、4 的分数依次为 3×1=3、4、1×1×2=2、4、4。最高分为 4，节点 1、3、4 达到最高分，数量为 3。

示例 2

输入：parents = [-1,2,0]
输出：2

节点 0、1、2 的分数依次为 2、2、1×1=1。最高分为 2，节点 0、1 达到最高分，数量为 2。

04 / GO DEEPER

想好你的方法了吗？

展开核心洞察、证明与四语言代码。

题解 · 先算大小，再比较乘积

核心洞察

删除 u 后，每个孩子 v 的整棵子树各自成为一个连通部分；u 非根时，还存在包含原根的上方部分。设 size[u] 为以 u 为根的子树大小，上方部分就是 n−size[u]。

size[u] = 1 + Σ size[v]  （v 是 u 的孩子）
score[u] = Π size[v] × max(1, n − size[u])

max(1, …) 让不存在的上方部分不影响乘积，不代表把空树当作一个部分。代码中仅在剩余大小大于 0 时相乘。

完整过程

  1. 从 parents 建立孩子列表。节点编号不能作为计算顺序。
  2. 从根 0 出发，用数组和游标逐个加入孩子，获得父节点先于孩子的遍历序列 order。
  3. 倒序处理 order，此时每个孩子的子树大小已知。将本节点大小初始化为 1，乘积初始化为 1。
  4. 累加每个孩子的 size，同时乘入它的大小；若 n−size[u] 为正，再乘入这个上方部分。
  5. 分数大于 best 时更新 best，count 重置为 1；等于 best 时 count 加 1。返回 count。

示例 1 可得到 order=[0,2,4,1,3]，实际处理顺序为 [3,1,4,2,0]。前三个叶子得 4 分；节点 2 得 1×1×2=2 分；根得 3×1=3 分。最高分计数最终为 3。

正确性证明

  1. 大小正确：叶子大小为 1。若孩子大小已正确，子树由本节点与互不重叠的孩子子树构成，累加再加 1 正确。倒序 order 保证孩子先完成，归纳成立。
  2. 分数正确：树中两点之间路径唯一。删除 u 后，不同孩子子树之间无法连通，而它们内部仍然连通。u 非根时，其他节点通过原根构成一个上方部分。这些部分互不重叠且覆盖所有剩余节点，大小分别为 size[v] 和 n−size[u]，故乘积符合定义。
  3. 计数正确：每步结束后，best 是已处理节点的最高分，count 是达到它的数量。更高时重置、相等时递增、更低时不变，维持这一不变量，遍历结束得到全树答案。

边界与数值

  • 根没有上方部分，不能乘入 0；叶子的分数是 n−1；没有孩子的方向无需处理。
  • n=2 时两节点分数都是 1，答案为 2。
  • 树高可能达到 10⁵，递归容易栈溢出。四份代码均使用迭代。
  • 删除二叉树节点至多得到三个部分，大小和为 n−1。三个因子时乘积不超过 ((n−1)/3)³；一、两个因子也远小于 10¹⁵。因此 Java long、C++ long long 足够，JavaScript Number 在 2⁵³−1 的精确整数范围内，Python 使用任意精度整数。
  • Java / C++ 应让乘积变量一开始就是 64 位，不能先使用 int 相乘再转换。

复杂度

时间 O(n)：建图、生成 order、倒序处理各访问 O(n) 个节点和边。额外空间 O(n)：孩子列表、order 与 size。演示为了回放和给连通部分着色，只支持 31 个节点，不代表提交算法的开销。

替代方案

  • 递归 DFS：返回子树大小时统计分数，代码简短，但需应对深链的递归栈限制。
  • 叶子向上剥离：记录每个节点未处理的孩子数，用队列把完成的大小汇总到父节点，同样 O(n)，但状态更多。
  • 逐点删除再搜索：每个点各做一次 BFS / DFS，统计剩余连通部分，时间 O(n²)，只适合小规模理解定义。

常见错误

  • 返回 best 而不是 count；遇到更高分后忘记把 count 重置为 1。
  • 上方大小写成 n−size[u]−1，重复减掉 u；size[u] 已包含 u。
  • 按节点编号倒序计算，错误假设父节点编号一定更小。
  • 给根的不存在部分乘 0，或把各次假想删除累积到原树。

面试追问

  • 推广到一般树？大小公式不变，但因子数增多，分数可能超过固定整数范围，需 BigInt / BigInteger 等任意精度整数。
  • 节点有正权重？把子树大小换成子树权重和，上方用总权重减子树权重。
  • 倒序广度遍历为什么可行？只需要孩子先于父亲完成，并不要求严格 DFS 后序。

Java

import java.util.*;

class Solution {
    public int countHighestScoreNodes(int[] parents) {
        int n = parents.length;
        List<List<Integer>> children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int i = 1; i < n; i++) children.get(parents[i]).add(i);
        int[] order = new int[n];
        int end = 1;
        for (int k = 0; k < n; k++) {
            for (int v : children.get(order[k])) order[end++] = v;
        }
        int[] size = new int[n];
        long best = 0;
        int count = 0;
        for (int k = n - 1; k >= 0; k--) {
            int u = order[k];
            size[u] = 1;
            long score = 1;
            for (int v : children.get(u)) {
                size[u] += size[v];
                score *= size[v];
            }
            int rest = n - size[u];
            if (rest > 0) score *= rest;
            if (score > best) {
                best = score;
                count = 1;
            } else if (score == best) {
                count++;
            }
        }
        return count;
    }
}

var countHighestScoreNodes = function(parents) {
    const n = parents.length;
    const children = Array.from({length: n}, () => []);
    for (let i = 1; i < n; i++) children[parents[i]].push(i);
    const order = [0];
    for (let k = 0; k < order.length; k++) {
        for (const v of children[order[k]]) order.push(v);
    }
    const size = Array(n).fill(1);
    let best = 0, count = 0;
    for (let k = n - 1; k >= 0; k--) {

            size[u] += size[v];
            score *= size[v];
        }
        const rest = n - size[u];

        if (score > best) {
            best = score;
            count = 1;
        } else if (score === best) {
            count++;
        }
    }
    return count;
};

Python 3

from typing import List

class Solution:
    def countHighestScoreNodes(self, parents: List[int]) -> int:
        n = len(parents)
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[parents[i]].append(i)
        order = [0]
        k = 0
        while k < len(order):
            order.extend(children[order[k]])
            k += 1
        size = [1] * n
        best = count = 0
        for u in reversed(order):
            score = 1
            for v in children[u]:
                size[u] += size[v]
                score *= size[v]
            rest = n - size[u]
            if rest > 0:
                score *= rest
            if score > best:
                best, count = score, 1
            elif score == best:
                count += 1
        return count
