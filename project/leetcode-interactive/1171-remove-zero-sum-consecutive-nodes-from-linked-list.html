一条链表里，某些连续节点会彼此抵消。你的任务是反复移除所有总和为 0 的连续片段，返回任意一个满足条件的最终链表。

题意与示例

题目转述

给定单链表头节点 head。只要链表中仍存在一个非空的连续节点序列，其节点值之和为 0，就可以删除该序列；重复此过程，直到不存在这样的连续序列，最后返回链表头节点。

示例中的数组是 ListNode 链表的序列化形式。

约束

  • 链表包含 1 到 1000 个节点。
  • 每个节点满足 -1000 ≤ node.val ≤ 1000。
示例 1
输入：head = [1,2,-3,3,1]
输出：[3,1]
说明：[1,2,1] 也会被接受。
示例 2
输入：head = [1,2,3,-3,4]
输出：[1,2,4]
示例 3
输入：head = [1,2,3,-3,-2]
输出：[1]

    准备好看完整题解了吗？

    核心洞察、证明、复杂度与四语言代码都藏在这里。

    核心洞察：相同前缀和之间的区间和为 0

    在链表前加入值为 0 的哑节点。若节点 a 与后续节点 b 的前缀和相同，那么 a.next 到 b 的总和就是 0，可以令 a.next = b.next 一次删除整段。

    完整过程

    1. 创建值为 0、指向原头节点的哑节点，以统一处理“答案头节点也被删除”的情况。
    2. 第一遍从哑节点开始累计前缀和，用哈希表保存每个前缀和最后一次出现的节点。
    3. 第二遍重新累计前缀和。对当前节点，把它的 next 直接连到该前缀和最后出现节点的 next。
    4. 遍历结束后返回 dummy.next。

    为什么要记录最后一次？

    使用最靠后的相同前缀和，能够一次跨过尽可能长的零和区域，并正确处理嵌套或重叠的零和片段。

    正确性

    删除合法：每次重连的两个端点前缀和相同，因此中间被跨越部分的总和必为 0。

    结果完整：若结果中仍有零和连续段，其两端前缀和相同；第一遍记录的最后位置会使第二遍跨过该段，产生矛盾。因此返回链表不再含零和连续段。

    复杂度

    时间：O(n)

    空间：O(n)

    关键边界

    整条链表和为 0；首段和为 0；只有一个 0；不存在零和片段；多段、嵌套或重叠片段。

    替代方案

    可反复用哈希表找到并删除一段零和序列，写法直观，但最坏时间会退化到 O(n²)。

    /**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode removeZeroSumSublists(ListNode head) {
        ListNode dummy = new ListNode(0, head);
        Map<Integer, ListNode> last = new HashMap<>();
        int prefix = 0;

        for (ListNode node = dummy; node != null; node = node.next) {
            prefix += node.val;
            last.put(prefix, node);
        }

        prefix = 0;
        for (ListNode node = dummy; node != null; node = node.next) {
            prefix += node.val;
            node.next = last.get(prefix).next;
        }
        return dummy.next;
    }
}

    常见错误

    • 哈希表记录第一次出现位置，导致重叠片段处理不完整。
    • 忘记哑节点，无法优雅删除从头节点开始的零和段。
    • 第二遍沿原始数组下标走，而不是沿已经重连后的链表走。
    • 只删除一次，没有保证最终链表不存在新的零和连续段。
