Reverse Words in a String III

保持单词顺序和空格不变，只把每个单词内部的字符翻转。

题目

给定字符串 s，逐个反转句子中每个单词的字符顺序，同时保留原有的单词顺序和空格。

示例 1

输入：s = "Let's take LeetCode contest"
输出："s'teL ekat edoCteeL tsetnoc"

示例 2

输入：s = "Mr Ding"
输出："rM gniD"

约束

  • 1 <= s.length <= 5 × 10⁴
  • s 只包含可打印 ASCII 字符。
  • 字符串无前导或尾随空格，且至少包含一个单词。
  • 相邻单词恰由一个空格分隔。

完整题解

核心洞察

空格已经标明单词边界。扫描字符串，一旦找到一个单词区间 [left, right]，便用两端向中间收缩的指针原地交换，之后从下一个单词继续。

完整过程

  1. 将字符串转为可修改的字符序列，令 start = 0。
  2. 从左到右扫描；当当前位置是空格或已到末尾时，当前单词结束。
  3. 令左右指针分别指向单词首尾，持续交换直到相遇。
  4. 把 start 移到下一单词开头，最终返回字符序列。

正确性证明

对每个单词区间，交换第 1 个与倒数第 1 个、第 2 个与倒数第 2 个，直到中点，因此该区间字符顺序恰好反转。算法从不交换空格，也不跨越单词边界，所以单词顺序和空格位置保持不变。所有单词区间都被处理一次，故返回结果满足要求。

边界情况

  • 单字符单词：左右指针立即相遇。
  • 只有一个单词：末尾触发最后一次翻转。
  • 标点或数字：作为普通可打印字符参与翻转。

复杂度

时间复杂度 O(n)；每个字符至多参与一次交换。若语言字符串不可变，字符数组占 O(n) 空间；可变字符缓冲区上的额外空间为 O(1)。

替代方案

可按空格切分，分别反转后再拼接，代码更短，但通常创建更多临时字符串。也可边扫描边把每个单词倒序追加到结果缓冲区。

四语言实现

class Solution {
    public String reverseWords(String s) {
        char[] a = s.toCharArray();
        for (int start = 0, end = 0; end <= a.length; end++) {
            if (end == a.length || a[end] == ' ') {
                for (int l = start, r = end - 1; l < r; l++, r--) {
                    char t = a[l]; a[l] = a[r]; a[r] = t;
                }
                start = end + 1;
            }
        }
        return new String(a);
    }
}
/** @param {string} s @return {string} */
var reverseWords = function(s) {
    const a = Array.from(s);
    let start = 0;
    for (let end = 0; end <= a.length; end++) {
        if (end === a.length || a[end] === ' ') {
            for (let l = start, r = end - 1; l < r; l++, r--) {
                [a[l], a[r]] = [a[r], a[l]];
            }
            start = end + 1;
        }
    }
    return a.join('');
};
class Solution:
    def reverseWords(self, s: str) -> str:
        chars = list(s)
        start = 0
        for end in range(len(chars) + 1):
            if end == len(chars) or chars[end] == " ":
                left, right = start, end - 1
                while left < right:
                    chars[left], chars[right] = chars[right], chars[left]
                    left += 1
                    right -= 1
                start = end + 1
        return "".join(chars)
class Solution {
public:
    string reverseWords(string s) {
        int start = 0, n = s.size();
        for (int end = 0; end <= n; ++end) {
            if (end == n || s[end] == ' ') {
                reverse(s.begin() + start, s.begin() + end);
                start = end + 1;
            }
        }
        return s;
    }
};

面试追问

  • 若空格数量不固定，如何精确保留？答案：仍以连续非空格区间为单词，只翻转区间，不重建分隔符。
  • 能否原地完成？答案：在可变字符数组中可以，额外空间为常数。
  • 若输入是 Unicode，按字节翻转安全吗？答案：不安全，应按代码点或字素簇处理。

常见错误

  • 忘记在字符串末尾触发最后一个单词的翻转。
  • 直接反转整个字符串，导致单词顺序也改变。
  • 切分后忽略原始空格语义（本题虽保证单空格，扩展题未必保证）。
  • 左右指针跨过空格或使用错误的右端点。
