LCR 018 / TWO POINTERS

验证回文串

左右指针向中间靠拢：非字母数字字符直接跳过；其余字符忽略大小写比较。一对不等立即返回 false。

时间 O(n)空间 O(1)官方 slug：xltzeq

INTERVIEW ANSWER

不用额外字符串

  1. 1. l、r 分别落在字符串两端。
  2. 2. 任一端不是字母或数字，就只移动该端。
  3. 3. 比较小写字符；相同则 l++、r--。

LIVE WALKTHROUGH

两端探测器

样例：A man, a plan, a canal: Panama
■ left 指针■ right 指针虚线：忽略的非字母数字

本步动作

循环不变量

每次有效比较前，已越过的左右字符都已匹配；跳过的符号不参与回文定义。两指针交错时，所有有效字符都已验证。

提前退出：一旦两端的小写字符不同，后续比较不可能改变答案。

为什么跳过符号？

题意只保留字母和数字，空格、逗号和冒号没有镜像含义，所以它们只推进指针。

为什么是 O(1)？

没有构造过滤后的新字符串，只维护两个下标；每个位置最多被访问一次。

常见失误

先比较再跳过符号；大小写未统一；r-- 后忘记继续循环，都会改变结果。

class Solution {
  public boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
      while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
      while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
      if (Character.toLowerCase(s.charAt(l)) != Character.toLowerCase(s.charAt(r))) return false;
      l++; r--;
    }
    return true;
  }
}

class Solution:
    def isPalindrome(self, s: str) -> bool:
        l, r = 0, len(s) - 1
        while l < r:
            while l < r and not s[l].isalnum(): l += 1
            while l < r and not s[r].isalnum(): r -= 1

class Solution {
public:
  bool isPalindrome(string s) {
    int l = 0, r = (int)s.size() - 1;
    while (l < r) {
      while (l < r && !isalnum(s[l])) ++l;
      while (l < r && !isalnum(s[r])) --r;
      if (tolower(s[l]) != tolower(s[r])) return false;
      ++l; --r;
    }
    return true;
  }
};
