01 / 读懂任务

从左上角开始，顺时针填入每个节点

给定矩阵的行数 m、列数 n 和整数单链表的头节点 head。按照链表顺序，从矩阵左上角出发，沿顺时针螺旋依次放入节点值。链表结束后，未放入节点的格子保留为 -1。返回这个 m × n 二维整数数组。输入中的数组形式仅表示链表的节点序列。

官方示例 1

输入：m = 3, n = 5,
head = [3,0,2,6,8,1,7,9,4,2,5,5,0]
输出：[[3,0,2,6,8],[5,0,-1,-1,1],[5,2,4,9,7]]

13 个节点填入 15 个格子，内圈剩余两格为 -1。

官方示例 2

输入：m = 1, n = 4, head = [0,1,2]
输出：[[0,1,2,-1]]

只有一行，三个节点从左向右放置，最后一格保留 -1。

完整约束

  • 1 ≤ m, n ≤ 10⁵
  • 1 ≤ m × n ≤ 10⁵
  • 链表节点数 L 满足 1 ≤ L ≤ m × n。
  • 0 ≤ Node.val ≤ 1000

04 / 独立题解
方向模拟：用输出矩阵记录已访问位置


核心洞察
顺时针只需要循环四个方向：右 → 下 → 左 → 上。先把矩阵初始化为 -1；因为节点值非负，-1 同时表示“还没写入”。前方越界或已经填过，就顺时针转 90°，不需要额外的 visited 数组。


完整过程
  1. 构造全为 -1 的 m × n 矩阵，位置从 (0,0) 开始，方向为右。
  2. 把当前 head.val 写入当前位置，再令 head = head.next。
  3. 若链表已经结束，直接退出，不再计算或访问下一个落点。
  4. 试探前方坐标。若越界或对应值不是 -1，将方向编号改为 (d + 1) % 4，重新计算下一格。
  5. 移动位置，继续处理下一个节点。循环结束返回矩阵。
示例 1 的首行接收 3、0、2、6、8；接着沿右列写入 1、7；底行从右向左写入 9、4、2、5；左侧写入 5，然后转入内圈写入 0。链表结束，内圈另外两格保持 -1。


为什么正确
循环不变式：处理第 k 个节点之前，前 k−1 个节点已经按顺时针螺旋顺序写入，当前位置是第 k 个尚未写入的螺旋格子，其余未访问格均为 -1。
初始化：第一个螺旋格是左上角，矩阵还未填充，不变式成立。保持：将第 k 个节点写入当前格后，如果直行可用，下一格就是螺旋路径的后继；否则当前直边结束，顺时针转弯进入下一条边。已填格围成外侧边界，未填区域保持沿矩形逐层收缩的结构，因此只要还有节点，一次转弯就能找到后继，无须尝试四个方向。写入后推进链表和位置，不变式继续成立。
终止：每轮消耗一个节点，最终恰好放置 L 个值。初始 -1 在未访问位置保持不变，故返回矩阵符合要求。若最后一格已经填满，代码在 head 为空时提前退出，避免继续寻路。


边界与复杂度
  • 单行、单列和 1×1：同一套边界判断即可处理。
  • 节点值可以为 0 或重复值，必须判断 != -1，不能用真假值判断已访问。
  • 不足一圈或在内圈结束：剩余位置已经是 -1，不需补填。
  • 官方保证链表非空且不超过容量；四份代码也会在空链表时返回全 -1 矩阵，但不承诺处理超容量链表。
  • 初始化 O(mn)，遍历链表 O(L)。因 L ≤ mn，总时间 O(mn)。
  • 输出矩阵占 O(mn)；不计返回结果，额外空间 O(1)。交互页面为回放保存落点序列，与提交解法的空间分析分开。


替代方案
使用 top、bottom、left、right 四个边界，每轮依次遍历顶行、右列、底行、左列，再收缩边界。时间同为 O(mn)，额外空间 O(1)，也不依赖 -1 哨兵；但每段都要处理链表提前结束，且底行、左列必须判断是否还存在，避免单行单列重复写入。


常见错误
  • 把方向顺序写成右、上、左、下，走成逆时针。
  • 先访问 a[nr][nc] 再判越界，造成非法访问。
  • 把 0 当空格，误覆盖值为 0 的节点。
  • JavaScript 使用 Array(m).fill(Array(n).fill(-1)) 或 Python 使用 [[-1] * n] * m，导致所有行共享同一个数组。
  • 以“矩阵是否填满”为唯一终止条件，在链表提前结束时访问空节点。


面试追问
如果节点值允许 -1？哨兵会和真实值冲突，改用四边界法，或独立 visited 数组。
能做到 O(L) 时间吗？返回普通稠密矩阵时不能，初始化 mn 个输出元素已经需要 O(mn)；若允许稀疏表示，才可改变输出成本。
需要先把链表变成数组吗？不需要，顺序推进 head 即可，转数组额外花 O(L) 空间。
为什么不是反复转弯直到找到空格？在矩形螺旋的不变式下，有后继时最多转一次；最后一个节点无需后继，提前退出即可。

// ListNode 由 LeetCode 提供，包含 int val 和 ListNode next。
class Solution {
    public int[][] spiralMatrix(int m, int n, ListNode head) {
        int[][] a = new int[m][n];
        for (int[] row : a) java.util.Arrays.fill(row, -1);
        int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        int r = 0, c = 0, d = 0;
        while (head != null) {
            a[r][c] = head.val;
            head = head.next;
            if (head == null) break;
            int nr = r + dirs[d][0], nc = c + dirs[d][1];
            if (nr < 0 || nr >= m || nc < 0 || nc >= n || a[nr][nc] != -1) {
                d = (d + 1) % 4;
                nr = r + dirs[d][0];
                nc = c + dirs[d][1];
            }
            r = nr;
            c = nc;
        }
        return a;
    }
}
