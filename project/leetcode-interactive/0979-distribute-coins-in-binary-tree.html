在二叉树中分配硬币

Distribute Coins in Binary Tree

让硬币沿树边流动，直到每个节点恰好持有一枚。先观察流动，再决定何时展开题解。

题目

给定一棵含 n 个节点的二叉树，节点值表示该节点持有的硬币数，且全树硬币总数也是 n。一次操作可在一对相邻的父子节点之间移动一枚硬币，方向不限。求使每个节点恰好拥有一枚硬币所需的最少操作次数。

函数签名

distributeCoins(root: TreeNode) -> integer

约束

  • 节点数为 n，1 <= n <= 100
  • 0 <= Node.val <= n
  • 所有节点值之和等于 n

官方示例

示例 1

输入：root = [3,0,0] 输出：2 解释：根节点分别向左右孩子移动一枚硬币。

示例 2

输入：root = [0,3,0] 输出：3 解释：左孩子向根移动两枚，再由根向右孩子移动一枚。

题解：让子树只汇报净余额

核心洞察

对任意节点，设左、右子树返回的余额分别为 L、R。节点处理完成后向父节点返回 node.val + L + R - 1：正数表示多出的硬币，负数表示缺少的硬币。无论硬币沿一条父子边向哪边移动，跨越该边的次数都必为对应子树余额的绝对值，因此累加 |L| + |R|。

完整过程

  1. 后序遍历，先得到左右子树余额。
  2. 将两条子边所需操作数 |L| + |R| 加入答案。
  3. 当前节点保留一枚硬币，把合并后的净余额返回父节点。
  4. 根节点没有父边；题目保证总硬币数等于节点数，所以最终根余额为 0。

正确性

引理：一棵子树最终每个节点各有一枚时，它与外界之间必须净交换“当前硬币总数 − 节点数”枚硬币；唯一出口是连接父节点的边，所以该边至少被使用其绝对值次。构造：后序遍历先平衡内部，再恰好沿父边传递这个余额，达到下界。每条边的最少次数相加即为全局最优。

边界与复杂度

单节点返回 0；空孩子余额视为 0；某节点可一次性持有全部硬币。每个节点访问一次，时间 O(n)；递归栈为树高 O(h)，最坏 O(n)。

替代方案

可写成显式栈的迭代后序遍历并用映射保存余额，避免深递归，但代码更长，额外空间仍为 O(n)。逐枚模拟硬币移动会重复搜索路径，不利于证明最优且效率更低。

面试追问

  • 若总硬币数不等于节点数，问题何时无解？根余额不为 0 时无解。
  • 若每条边移动成本不同？累加 |balance| × edgeCost。
  • 如何返回具体移动方案？在回溯时根据余额符号记录沿边方向及次数。

常见错误

  • 累加当前节点余额而非左右孩子余额，误把根节点也当作需要跨父边。
  • 忘记取绝对值，导致缺口抵消操作数。
  • 使用前序遍历，尚未掌握子树完整供需。
  • 返回值漏减 1，没有为当前节点保留一枚。

四语言完整代码

class Solution {
    private int moves = 0;
    public int distributeCoins(TreeNode root) {
        dfs(root);
        return moves;
    }
    private int dfs(TreeNode node) {
        if (node == null) return 0;
        int left = dfs(node.left), right = dfs(node.right);
        moves += Math.abs(left) + Math.abs(right);
        return node.val + left + right - 1;
    }
}
