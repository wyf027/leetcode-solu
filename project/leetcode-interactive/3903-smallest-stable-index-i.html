最小稳定下标 I

把每个切分点左侧的最大值，与右侧的最小值放到同一把尺子上比较：第一个差值不超过 k 的位置，就是答案。

题意

给定整数数组 nums 和整数 k。对每个下标 i，不稳定值为 max(nums[0..i]) - min(nums[i..n-1])。不稳定值不大于 k 时，i 稳定；返回最小稳定下标，不存在则返回 -1。

示例 1

nums = [5, 0, 1, 4]
k = 3

输出：3

示例 2

nums = [3, 2, 1]
k = 1

输出：-1

示例 3

nums = [0]
k = 0

输出：0

约束：1 ≤ nums.length ≤ 100；0 ≤ nums[i], k ≤ 10⁹。输入中的空格以 ␠ 表示时仅用于显示，不属于数值。

这页怎么玩？

  1. 选择一个数组示例或编辑输入。
  2. 用“下一步”观察前缀最大值和后缀最小值。
  3. 看到第一个 差值 ≤ k 的格子，它就是最小稳定下标。

键盘：←/→ 前后步；Space 自动播放。

题解：前缀最大值 + 后缀最小值

核心洞察

第 i 个切分点需要的两个量，分别只依赖左边和右边。先从右向左得到 suffixMin[i]，再从左向右维护 prefixMax；第一次满足 prefixMax - suffixMin[i] ≤ k 时立即返回。

完整过程

  1. 初始化后缀最小数组，末项等于最后一个数。
  2. 倒序递推每个后缀的最小值。
  3. 正序更新前缀最大值并比较差值。
  4. 首个合格位置即最小答案；扫完仍没有则返回 -1。

边界与复杂度

  • 长度为 1 时，最大值和最小值都等于该元素，答案为 0（当 k ≥ 0）。
  • 数值可到 10⁹；Java/C++ 用 long/long long 做差更稳妥。
  • 时间 O(n)，额外空间 O(n)。

替代方案与追问

可把后缀最小值压缩为原数组的预处理副本，空间仍是 O(n)。追问：若允许离线多次查询不同 k，可先计算每个下标的不稳定值，再排序回答阈值查询。

常见错误

  • 把右侧写成 nums[i + 1..n - 1]，漏掉了切分点自身。
  • 找到稳定点后继续扫描，丢失“最小”的要求。
  • 直接双层枚举求区间极值，退化为 O(n²)。
