回环句

Circular Sentence

一句话绕一圈，还能接回起点吗？
从单词之间的连接，理解一个句子的回环规则。

官方题目 ↗离线交互 · 四语言题解 · 待补验证

01 / 题目

判断句子是否形成回环

给定字符串 sentence，它由一个或多个英文单词组成，单词之间恰好一个空格，没有首尾空格。大小写视为不同字符。

若每个单词的末字母都等于下一个单词的首字母，并且最后一个单词的末字母也等于第一个单词的首字母，返回 true；否则返回 false。

参数与返回值

isCircularSentence(sentence: string) → boolean

约束

  • 1 ≤ sentence.length ≤ 500
  • 只含大写英文字母、小写英文字母和空格。
  • 单词由单个空格分隔，不含前导或尾随空格。

05 / 独立题解

想好以后，再打开思路

包含证明、复杂度和四份官方签名代码。

核心洞察：只看连接处

单词内部的字符不影响相邻单词能否衔接。每个空格的左、右字符恰好是一对词尾与词首；再补上整个字符串末尾到开头的连接，就覆盖了所有条件。不必切分单词。

完整过程

  1. 令 n 为 sentence 的长度，先比较 sentence[n − 1] 与 sentence[0]；不同则立即返回 false。
  2. 从索引 1 扫描到 n − 2；仅当当前位置是空格时，比较 sentence[i − 1] 与 sentence[i + 1]。不同则立即返回 false。
  3. 所有检查结束仍无矛盾，返回 true。

示例 1 先检查闭环 l = l，再依次检查 e = e、s = s、d = d，最后返回 true。交互面板把不参与比较的普通字符扫描折叠掉，每一步对应一次有效比较。示例 3 会先因末尾 l ≠ 开头 L 失败；这和题面举出的 e ≠ i 都能独立证明答案为 false。

正确性证明

必要性：回环句的首尾连接必须相等，每个空格两侧也必须相等，所以任何一次失败都足以返回 false。

循环不变式：扫描到索引 i 前，首尾连接及所有已遇到的空格边界均已满足条件。普通字符不增加新边界；遇到空格并比较成功后，不变式继续成立。

充分性：扫描完成时，每个相邻单词边界都已被检查，再加上预先检查的首尾连接，全部回环条件均满足，因此返回 true 正确。

边界与复杂度

  • 只有一个字符：首尾就是同一字符，循环为空，返回 true。
  • 一个单词：没有空格，只需比较首尾；并非所有单词都能回环。
  • 大小写不转换；A 和 a 必须判为不同。
  • 合法输入保证空格不在两端，因此空格两侧索引安全。

最坏时间 O(n)，首尾不等时可在 O(1) 时间提前返回。算法额外空间 O(1)。C++ 按官方签名以值传参，若计入调用方字符串复制，可能产生 O(n) 参数复制成本；函数内部不分配额外字符串。演示为记录步骤会用 O(n) 空间，与提交算法不同。

替代方案

按空格拆为 m 个单词，对每个单词 k 比较其末字母与第 (k + 1) % m 个单词的首字母。时间 O(n)，拆分通常需要 O(n) 额外空间；语义直观，但本题无需为每个词建立新字符串。

常见错误

  • 只检查空格，忘记最后一个词与第一个词之间的闭环。
  • 只比较整个句子的首尾，漏掉内部断开，例如 "ab ca"。
  • 把所有相邻字符都拿来比较，误把单词内部字符也作为限制。
  • 把输入转小写，或把“单词首尾相等”误认为每个词都必须满足。

面试追问

如果允许多个空格？应在跳过分隔符后记录实际单词的首尾，不能继续直接比较空格两侧。

如果字符串以流输入？保存首词首字母、前词末字母及当前字符位置状态；单遍检查内部边界，流结束时补检查首尾。

如果需要返回断点？保留当前边界的索引并在不匹配时返回；也可继续扫描收集全部断点，此时额外空间随断点数量增长。

Java

class Solution {
    public boolean isCircularSentence(String sentence) {
        int n = sentence.length();
        if (sentence.charAt(n - 1) != sentence.charAt(0)) return false;
        for (int i = 1; i < n - 1; i++) {
            if (sentence.charAt(i) == ' ' &&
                sentence.charAt(i - 1) != sentence.charAt(i + 1)) {
                return false;
            }
        }
        return true;
    }
}

var isCircularSentence = function(sentence) {
    const n = sentence.length;
    if (sentence[n - 1] !== sentence[0]) return false;
    for (let i = 1; i < n - 1; i++) {
        if (sentence[i] === ' ' && sentence[i - 1] !== sentence[i + 1]) {
            return false;
        }
    }
    return true;
};

class Solution:
    def isCircularSentence(self, sentence: str) -> bool:
        n = len(sentence)
        if sentence[n - 1] != sentence[0]:
            return False
        for i in range(1, n - 1):
            if sentence[i] == ' ' and sentence[i - 1] != sentence[i + 1]:
                return False
        return True

        int n = static_cast<int>(sentence.size());
        if (sentence[n - 1] != sentence[0]) return false;
        for (int i = 1; i < n - 1; ++i) {

                return false;
            }
        }
        return true;
    }
