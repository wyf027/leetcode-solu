斐波那契数列

从 0 和 1 起步，让每一项等于前两项之和。结果很快变大，因此需要在每一步取模。

题意

写一个函数，计算斐波那契数列第 n 项。数列满足 F(0)=0、F(1)=1，其余各项等于前两项之和。答案对 1000000007 取模。

示例

输入：n = 5

输出：5

解释：0, 1, 1, 2, 3, 5

约束

  • 0 <= n <= 100
  • 答案需要对 1_000_000_007 取模。

题解工作台

核心洞察

计算下一项时，真正需要的只有最近两项。较早的历史不会再被读取，因此可将 DP 数组压缩成两个变量。

过程

  1. 处理 n=0 与 n=1。
  2. 令 a=0、b=1。
  3. 重复计算 next=(a+b)%MOD，并将窗口向前移动。

边界

不要把循环从 0 开始，否则会额外推进状态；每次相加后再取模，避免结果无限增长并符合题意。

复杂度

迭代 n 次，时间复杂度为 O(n)；只维护两个状态，额外空间为 O(1)。

替代方案

递归表达式最直接，但未经记忆化会指数级重复计算。DP 数组能保留全部中间结果，但本题不需要回溯，所以滚动变量更省空间。

常见错误

  • 忘记对每一步结果取模。
  • 把 F(0) 误写为 1。
  • 更新 a 后再用更新后的值计算 b，导致状态丢失。

参考实现

Java

class Solution {
    public int fib(int n) {
        final int MOD = 1000000007;
        int a = 0, b = 1;
        for (int i = 2; i <= n; i++) {
            int next = (a + b) % MOD;
            a = b;
            b = next;
        }
        return n == 0 ? 0 : b;
    }
}

Python

class Solution:
    def fib(self, n: int) -> int:
        mod = 1_000_000_007
        a, b = 0, 1
        for _ in range(2, n + 1):
            a, b = b, (a + b) % mod
        return 0 if n == 0 else b
