01 / THE QUESTION

题意与数据契约

输入两张表：Sales 记录购买，Product 提供单价。返回每位有购买记录的用户及其累计消费金额最高的商品 ID；如果多个商品并列，全部输出。结果行顺序不限。

Sales · 销售明细
字段类型含义
sale_idint唯一销售 ID
product_idint购买商品
user_idint购买用户
quantityint本次购买数量
Product · 商品价格
字段类型含义
product_idint唯一商品 ID

约束与返回格式

  • Sales.sale_id 唯一；Product.product_id 唯一。
  • Sales.product_id 是指向 Product.product_id 的外键。
  • 同一用户可以重复购买同一商品，每次消费都需要累计。
  • 输出列为 user_id, product_id；每个用户与商品组合只返回一次，所有并列最高商品都要保留。
  • 公开题面没有提供行数或字段数值范围，也没有额外的 NULL 约定，不补造这些限制。

05 / SOLUTION NOTES

独立题解

按需查看思路、证明、SQL 与本地语言参考。

核心洞察：先统一粒度，再在用户内部比较

输入是一笔笔交易，答案却针对“用户 × 商品”。先把同一组合的交易金额累加，再与同一用户的最大累计金额比较。相等的项全部留下，无需打破平局。

完整过程

  1. 按 product_id 连接 Sales 和 Product，为销售记录补充单价。
  2. 按 user_id、product_id 分组，得到 SUM(quantity × price)。
  3. 使用 MAX(total) OVER (PARTITION BY user_id)，把该用户最高金额附到每个商品分组上。
  4. 保留 total = user_max，只输出 user_id、product_id。

正确性

累计准确：商品 ID 唯一且销售商品 ID 是外键，故每笔销售恰好匹配一个商品价格，不会因为连接而重复或遗漏。按用户和商品分组得到的总金额，恰好是该用户对该商品的所有消费之和。

结果充分且必要：窗口按用户分区，最大值来自该用户的全部商品累计金额。任何留下的商品均达到这个最大值，因此满足要求；任何满足要求的商品都通过等值筛选，因此不会遗漏。并列项全部保留，分组确保每个组合仅有一行。

边界与数值

  • 用户仅买过一种商品：该商品自然入选。多次购买同一商品：只返回一个累计后的组合。
  • 空 Sales：返回空结果。未购买商品：不会凭空生成用户与商品组合。
  • 多个用户须独立比较；相同金额的所有商品须全部返回。
  • 题面未列 NULL 和数值上界；本地参考按有效非空整数数据解释。业务中的退款、NULL、历史价格需要先明确规则。
  • SQL 在乘法前转为 DECIMAL，避免先以较窄整数相乘；仍受数据库数值容量约束。Java 用 long 并显式检测溢出；C++ 假定乘积和累计金额在 long long 范围内。JavaScript 使用 BigInt，Python 使用任意精度整数。JavaScript 的超安全整数输入应使用整数字符串，避免在转换前丢失精度。

复杂度

令 N 为销售记录数，P 为商品数，G 为不同用户与商品组合数。典型哈希连接与聚合耗时 O(N + P)，窗口分区排序可能耗时 O(G log G)，总体典型上界为 O(N + P + G log G)，中间空间 O(P + G)。实际 SQL 性能由执行计划、索引与落盘决定，不能无条件承诺线性耗时。

四语言哈希参考平均时间 O(N + P + G)，辅助空间 O(P + G)，输出最多 G 行。这里按数值运算计次；大整数的位数增长还会增加单次运算成本。

替代方案

  • 对累计值用 RANK 或 DENSE_RANK 降序排名，按用户分区，取排名 1，同样保留并列。
  • 把累计表按用户再次分组求最大值，再按用户 ID 与金额连接回累计表，无需窗口函数。
  • NOT EXISTS 排除存在同用户更大累计金额的商品；执行效率取决于优化器。

常见错误

  • 求 MAX(quantity × price)：选出的是最大单笔，忽略重复购买。
  • 用 ROW_NUMBER = 1 或 LIMIT 1：会遗漏并列商品。
  • 只按 product_id 分组，或使用全表最大值：混淆不同用户。
  • 分组时加入 sale_id：无法合并重复购买。
  • 只比较数量：单价不同，最多数量不代表最高消费。

面试追问

如何扩展 Top K？先区分前 K 个不同金额与前 K 个名次。前者可用 DENSE_RANK，后者可用 RANK；若要固定 K 行，必须额外明确平局排序，再用 ROW_NUMBER。

商品价格发生变化怎么办？当前表只有一个商品单价。若业务要求成交时价格，应使用销售记录中的成交单价或按有效期关联历史价格。

数据量大如何优化？先看执行计划，利用商品唯一键与连接索引；是否先按用户与商品预聚合数量、增加组合索引，应由数据分布和查询模式决定。

MySQL 8+ · 官方可提交 SQL

WITH spending AS (
    SELECT s.user_id, s.product_id,
           SUM(CAST(s.quantity AS DECIMAL(38, 0)) * p.price) AS total
    FROM Sales AS s
    JOIN Product AS p ON p.product_id = s.product_id
    GROUP BY s.user_id, s.product_id
), compared AS (
    SELECT user_id, product_id, total,
           MAX(total) OVER (PARTITION BY user_id) AS user_max
    FROM spending
)
SELECT user_id, product_id
FROM compared
WHERE total = user_max;

Java · 本地语义参考，非本题提交格式

import java.util.*;

public class Main {
    // Sales: [sale_id, product_id, user_id, quantity]
    // Product: [product_id, price]
    static List<long[]> productSalesAnalysis(long[][] sales, long[][] products) {
        Map<Long, Long> prices = new HashMap<>();
        for (long[] p : products) prices.put(p[0], p[1]);
        Map<Long, Map<Long, Long>> totals = new HashMap<>();
        for (long[] s : sales) {
            long amount = Math.multiplyExact(s[3], prices.get(s[1]));
            Map<Long, Long> user = totals.computeIfAbsent(s[2], k -> new HashMap<>());
            user.put(s[1], Math.addExact(user.getOrDefault(s[1], 0L), amount));
        }
        List<long[]> result = new ArrayList<>();
        for (Map.Entry<Long, Map<Long, Long>> entry : totals.entrySet()) {
            long best = Collections.max(entry.getValue().values());
            for (Map.Entry<Long, Long> p : entry.getValue().entrySet())
                if (p.getValue() == best)
                    result.add(new long[]{entry.getKey(), p.getKey()});
        }
        return result;
    }
    public static void main(String[] args) {
        long[][] sales = {{1,1,101,10},{2,3,101,7},{3,1,102,9},
                          {4,2,102,6},{5,3,102,10},{6,1,102,6}};
        long[][] products = {{1,10},{2,25},{3,15}};
        for (long[] row : productSalesAnalysis(sales, products))
            System.out.println(Arrays.toString(row));
    }
}

JavaScript · 本地语义参考，非本题提交格式

// Input amounts: safe integers or integer strings.
function productSalesAnalysis(sales, products) {
    const price = new Map(products.map(([p, value]) => [String(p), BigInt(value)]));
    const totals = new Map();
    for (const [, p, u, q] of sales) {
        const userId = String(u), productId = String(p);
        if (!totals.has(userId)) totals.set(userId, new Map());
        const user = totals.get(userId);
        const amount = BigInt(q) * price.get(productId);
        user.set(productId, (user.get(productId) ?? 0n) + amount);
    }
    const result = [];
    for (const [u, user] of totals) {
        let best = null;
        for (const amount of user.values())
            if (best === null || amount > best) best = amount;
        for (const [p, amount] of user)
            if (amount === best) result.push([u, p]);
    }
    return result; // IDs are strings, preserving integer precision.
}
const sales = [[1,1,101,10],[2,3,101,7],[3,1,102,9],
               [4,2,102,6],[5,3,102,10],[6,1,102,6]];
const products = [[1,10],[2,25],[3,15]];
console.log(productSalesAnalysis(sales, products));

Python · 本地语义参考，非 Pandas 提交签名

from collections import defaultdict


def product_sales_analysis(sales, products):
    # Sales: [sale_id, product_id, user_id, quantity]
    # Product: [product_id, price]
    prices = dict(products)
    totals = defaultdict(lambda: defaultdict(int))
    for _, product_id, user_id, quantity in sales:
        totals[user_id][product_id] += quantity * prices[product_id]
    result = []
    for user_id, amounts in totals.items():
        best = max(amounts.values())
        for product_id, amount in amounts.items():
            if amount == best:
                result.append([user_id, product_id])
    return result

C++17 · 本地语义参考，非本题提交格式

#include <array>
#include <iostream>
#include <limits>
#include <unordered_map>
#include <vector>
using namespace std;
using ll = long long;

// Local reference: all products and accumulated amounts must fit in ll.
vector<array<ll, 2>> productSalesAnalysis(
    const vector<array<ll, 4>>& sales,
    const vector<array<ll, 2>>& products) {
    unordered_map<ll, ll> prices;
    for (const auto& p : products) prices[p[0]] = p[1];
    unordered_map<ll, unordered_map<ll, ll>> totals;
    for (const auto& s : sales)
        totals[s[2]][s[1]] += s[3] * prices.at(s[1]);
    vector<array<ll, 2>> result;
    for (const auto& [u, amounts] : totals) {
        ll best = numeric_limits<ll>::lowest();
        for (const auto& [p, amount] : amounts)
            if (amount > best) best = amount;
        for (const auto& [p, amount] : amounts)
            if (amount == best) result.push_back({u, p});
    }
    return result;
}
int main() {
    vector<array<ll, 4>> sales = {{1,1,101,10},{2,3,101,7},{3,1,102,9},
                                  {4,2,102,6},{5,3,102,10},{6,1,102,6}};
    vector<array<ll, 2>> products = {{1,10},{2,25},{3,15}};
    for (const auto& row : productSalesAnalysis(sales, products))
        cout << row[0] << " " << row[1] << '\n';
}
