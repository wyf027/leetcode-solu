员工奖金

Employee Bonus — 从员工全集出发，追踪奖金记录是否命中，再决定哪些行进入结果集。

给定 Employee 与 Bonus 两张表，报告满足以下任一条件的员工姓名及奖金：奖金严格少于 1000，或者没有奖金记录。结果可以按任意顺序返回。

约束与关系
  • Employee.empId 在 Employee 表中唯一。
  • Bonus.empId 在 Bonus 表中唯一，并引用 Employee.empId。

Solution

完整题解

核心洞察

结果必须覆盖“没有奖金记录”的员工，因此查询不能从 Bonus 出发，也不能使用会丢失未匹配员工的内连接。应从 Employee 出发做左连接，再保留奖金小于 1000 或连接结果为 null 的行。

01 · 保留全集

Employee 为左表

左连接确保每位员工至少产生一行，即使 Bonus 中没有对应记录。

02 · 连接奖金

按 empId 匹配

Bonus.empId 唯一，所以每位员工至多匹配一条奖金记录。

03 · 过滤结果

处理值与缺失

显式检查 bonus < 1000 或 bonus IS NULL，覆盖题目的两个条件。

完整过程

  1. 扫描 Employee，得到所有员工。
  2. 通过 empId 左连接 Bonus；没有匹配时，连接后的 bonus 为 null。
  3. 使用两个分支过滤：奖金严格小于 1000，或奖金为 null。
  4. 只投影 name 与 bonus 两列；题目允许任意输出顺序，无需排序。

官方可提交语言：MySQL

SELECT e.name, b.bonus
FROM Employee AS e
LEFT JOIN Bonus AS b
  ON e.empId = b.empId
WHERE b.bonus < 1000
   OR b.bonus IS NULL;

正确性说明

对任意员工 e，左连接都会保留 e：若 Bonus 中存在相同 empId，则 b.bonus 是该奖金；否则为 null。WHERE 条件恰好保留 b.bonus < 1000 的员工与 b.bonus IS NULL 的员工，分别对应题目要求的两类。奖金大于等于 1000 的已匹配员工不满足任一分支， 因而被排除。投影只返回 name 与 bonus，所以查询结果正确。

边界情况

  • Bonus 为空：所有员工都以 null 奖金返回。
  • bonus = 999：返回。
  • bonus = 1000：不返回。
  • 所有奖金都 ≥ 1000：结果为空。

复杂度

设 Employee 有 n 行、Bonus 有 m 行。逻辑上读取两表；常见哈希连接时间为 O(n + m)，额外空间 O(m)。具体执行计划由数据库优化器与索引决定。

替代方案

可写 COALESCE(b.bonus, 0) < 1000，但显式的 OR 更直接表达题意，也不会把“缺失”与数值 0 在语义上混为一谈。

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class EmployeeBonusReference {
    record Employee(int empId, String name, Integer supervisor, int salary) {}
    record Bonus(int empId, int bonus) {}
    record Result(String name, Integer bonus) {}

    public static List<Result> employeeBonus(
            List<Employee> employees, List<Bonus> bonuses) {
        Map<Integer, Integer> bonusByEmployee = new HashMap<>();
        for (Bonus bonus : bonuses) {
            bonusByEmployee.put(bonus.empId(), bonus.bonus());
        }

        List<Result> result = new ArrayList<>();
        for (Employee employee : employees) {
            Integer bonus = bonusByEmployee.get(employee.empId());
            if (bonus == null || bonus < 1000) {
                result.add(new Result(employee.name(), bonus));
            }
        }
        return result;
    }
}
/**
 * @param {{empId:number, name:string, supervisor:number|null, salary:number}[]} employees
 * @param {{empId:number, bonus:number}[]} bonuses
 * @returns {{name:string, bonus:number|null}[]}
 */
function employeeBonus(employees, bonuses) {
  const bonusByEmployee = new Map(
    bonuses.map(({ empId, bonus }) => [empId, bonus]),
  );

  const result = [];
  for (const employee of employees) {
    const bonus = bonusByEmployee.has(employee.empId)
      ? bonusByEmployee.get(employee.empId)
      : null;
    if (bonus === null || bonus < 1000) {
      result.push({ name: employee.name, bonus });
    }
  }
  return result;
}
from dataclasses import dataclass
from typing import Optional


@dataclass(frozen=True)
class Employee:
    emp_id: int
    name: str
    supervisor: Optional[int]
    salary: int


@dataclass(frozen=True)
class Bonus:
    emp_id: int
    bonus: int


def employee_bonus(
    employees: list[Employee], bonuses: list[Bonus]
) -> list[tuple[str, Optional[int]]]:
    bonus_by_employee = {row.emp_id: row.bonus for row in bonuses}
    result: list[tuple[str, Optional[int]]] = []

    for employee in employees:
        bonus = bonus_by_employee.get(employee.emp_id)
        if bonus is None or bonus < 1000:
            result.append((employee.name, bonus))

    return result
#include <optional>
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>

struct Employee {
    int empId;
    std::string name;
    std::optional<int> supervisor;
    int salary;
};

struct Bonus {
    int empId;
    int bonus;
};

using Result = std::pair<std::string, std::optional<int>>;

std::vector<Result> employeeBonus(
    const std::vector<Employee>& employees,
    const std::vector<Bonus>& bonuses) {
    std::unordered_map<int, int> bonusByEmployee;
    for (const Bonus& row : bonuses) {
        bonusByEmployee[row.empId] = row.bonus;
    }

    std::vector<Result> result;
    for (const Employee& employee : employees) {
        const auto it = bonusByEmployee.find(employee.empId);
        const std::optional<int> bonus =
            it == bonusByEmployee.end()
                ? std::nullopt
                : std::optional<int>(it->second);
        if (!bonus.has_value() || *bonus < 1000) {
            result.emplace_back(employee.name, bonus);
        }
    }
    return result;
}

常见错误

  • 使用 INNER JOIN，导致无奖金员工消失。
  • 只写 b.bonus < 1000，忽略 SQL 三值逻辑下 null 不会通过比较。
  • 误写 <= 1000，把临界值 1000 纳入结果。
  • 从 Bonus 出发连接 Employee，天然无法覆盖没有 Bonus 行的员工。
