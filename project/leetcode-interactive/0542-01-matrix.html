MEDIUM广度优先搜索数组动态规划矩阵
Problem

题目

给定一个由 0 和 1 组成的 m × n 矩阵 mat，返回同样大小的矩阵；每个位置的值表示它到原矩阵中最近的 0 的距离。仅共享一条边的两个格子相邻，它们之间的距离为 1。

函数形式：updateMatrix(mat: integer[][]): integer[][]

约束

  • m == mat.length，n == mat[i].length
  • 1 ≤ m, n ≤ 10⁴
  • 1 ≤ m × n ≤ 10⁴
  • mat[i][j] 只能是 0 或 1
  • mat 中至少存在一个 0
示例 1
输入：mat = [[0,0,0],[0,1,0],[0,0,0]]
输出：[[0,0,0],[0,1,0],[0,0,0]]
示例 2
输入：mat = [[0,0,0],[0,1,0],[1,1,1]]
输出：[[0,0,0],[0,1,0],[1,2,1]]

Solution

多源 BFS

核心洞察

把所有值为 0 的格子同时加入队列，并令它们的距离为 0；其余格子先标记为未访问。BFS 每向外扩展一层，距离恰好增加 1。这样每个 1 首次被访问时，就已经沿着最短路径连接到了某个 0。

完整过程

  1. 扫描矩阵，把所有 0 入队，建立同尺寸距离矩阵，其余位置设为 -1。
  2. 从队首取出格子，检查上、下、左、右四个方向。
  3. 若邻居合法且距离仍为 -1，令其距离等于当前距离加 1，并加入队尾。
  4. 队列清空后返回距离矩阵。

正确性证明

引理：BFS 按非递减距离处理格子。初始队列中的所有 0 距离均为 0；若队首距离为 d，它新发现的邻居距离为 d+1，因此不会跳过更短层。

定理：某格子第一次被发现时得到的值就是到最近 0 的距离。BFS 给出一条长度为 d 的路径，故真实最短距离至多 d；若存在更短路径，该路径所起始的 0 会在更早层发现此格子，与“第一次在 d 层发现”矛盾。

边界处理

  • 只有一个格子时，约束保证它是 0，结果为 [[0]]。
  • 全为 0 时，所有位置初始入队，结果不变。
  • 单行或单列无需特殊分支，边界判断自然覆盖。
  • 矩阵很长但总元素不超过 10⁴，队列规模仍为 O(mn)。

复杂度

每个格子最多入队一次，每次检查四条边，时间复杂度 O(mn)；距离矩阵与队列占用 O(mn) 额外空间。

替代方案

可用两遍动态规划：第一遍从左上到右下，只参考上方和左方；第二遍反向，只参考下方和右方。它同样是 O(mn)，且可直接复用输出矩阵，但需要谨慎选择足够大的初始值。逐个 1 单独 BFS 最坏会达到 O((mn)²)，不推荐。

面试追问

  • 如果八方向都可移动，只需扩展方向数组，距离定义会改变。
  • 如果边权不同，普通 BFS 不再适用，可考虑多源 Dijkstra。
  • 若要返回最近 0 的坐标，可在传播距离时同步传播源坐标。

常见错误

  • 只放入一个 0，导致答案依赖错误的单一源点。
  • 入队时不立刻标记访问，使同一格子重复入队。
  • 把对角线也当成相邻方向。
  • 动态规划初始化成 0，使未计算格子看起来已经有最优距离。

import java.util.*;

class Solution {
    public int[][] updateMatrix(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, -1);
        ArrayDeque<int[]> queue = new ArrayDeque<>();
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (mat[r][c] == 0) { dist[r][c] = 0; queue.offer(new int[]{r, c}); }
            }
        }
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            for (int[] d : dirs) {
                int nr = cur[0] + d[0], nc = cur[1] + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && dist[nr][nc] == -1) {
                    dist[nr][nc] = dist[cur[0]][cur[1]] + 1;
                    queue.offer(new int[]{nr, nc});
                }
            }
        }
        return dist;
    }
}

var updateMatrix = function(mat) {
    const m = mat.length, n = mat[0].length;
    const dist = Array.from({ length: m }, () => Array(n).fill(-1));
    const queue = [];
    for (let r = 0; r < m; r++) for (let c = 0; c < n; c++) {
        if (mat[r][c] === 0) { dist[r][c] = 0; queue.push([r, c]); }
    }
    const dirs = [[1,0],[-1,0],[0,1],[0,-1]];
    for (let head = 0; head < queue.length; head++) {
        const [r, c] = queue[head];
        for (const [dr, dc] of dirs) {
            const nr = r + dr, nc = c + dc;
            if (nr >= 0 && nr < m && nc >= 0 && nc < n && dist[nr][nc] === -1) {
                dist[nr][nc] = dist[r][c] + 1;
                queue.push([nr, nc]);
            }
        }
    }
    return dist;
};
from collections import deque
from typing import List

class Solution:
    def updateMatrix(self, mat: List[List[int]]) -> List[List[int]]:
        m, n = len(mat), len(mat[0])
        dist = [[-1] * n for _ in range(m)]
        queue = deque()
        for r in range(m):
            for c in range(n):
                if mat[r][c] == 0:
                    dist[r][c] = 0
                    queue.append((r, c))
        while queue:
            r, c = queue.popleft()
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n and dist[nr][nc] == -1:
                    dist[nr][nc] = dist[r][c] + 1
                    queue.append((nr, nc))
        return dist
class Solution {
public:
    vector<vector<int>> updateMatrix(vector<vector<int>>& mat) {
        int m = mat.size(), n = mat[0].size();
        vector<vector<int>> dist(m, vector<int>(n, -1));
        queue<pair<int,int>> q;
        for (int r = 0; r < m; ++r) for (int c = 0; c < n; ++c) {
            if (mat[r][c] == 0) { dist[r][c] = 0; q.push({r, c}); }
        }
        int dirs[5] = {1, 0, -1, 0, 1};
        while (!q.empty()) {
            auto [r, c] = q.front(); q.pop();
            for (int k = 0; k < 4; ++k) {
                int nr = r + dirs[k], nc = c + dirs[k + 1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && dist[nr][nc] == -1) {
                    dist[nr][nc] = dist[r][c] + 1;
                    q.push({nr, nc});
                }
            }
        }
        return dist;
    }
