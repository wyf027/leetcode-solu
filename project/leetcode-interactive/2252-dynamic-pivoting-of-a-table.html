Dynamic Pivoting of a Table

同一份商品价格，换一个观察维度。让商店成为列，让商品成为行。

01 / 任务说明

输入数据库表 Products(product_id INT, store VARCHAR(7), price INT)。实现无参数存储过程 PivotProducts()，读取该表并返回宽表：每个商品占一行，每家出现过的商店占一列，单元格保存对应价格；商品未在该店出售时为 NULL。

  • (product_id, store) 是联合主键，同一商品与同一商店的组合不会重复。
  • 最多 30 家不同商店。商店列位于 product_id 之后，按店名的字典序排列。
  • 结果行顺序不限。商店集合会随输入变化。
  • 官方建表元数据使用 VARCHAR(7)；公开题面未提供行数、商品编号或价格的额外数值范围，不补造范围。

05 / 题解：先确定列，再执行聚合

核心洞察

输出列名取决于输入中的 store 值。普通 SELECT 在解析时就要确定列结构，参数占位符也不能替代列名。因此先构建包含完整列清单的 SQL，再准备并执行。

每家商店对应 MAX(CASE WHEN store = 目标商店 THEN price END)。按 product_id 分组后，联合主键保证每店至多一条匹配价格。MAX 用于折叠多行，不是在多条有效报价中取最高价。

完整过程

  1. 提取不同店名，并按 store 排序。
  2. 为每个店名生成条件聚合表达式与列别名。值与标识符分别处理：下方 SQL 将店名值编码为十六进制字符串，列别名以反引号包围并转义。
  3. GROUP_CONCAT 按店名顺序连接片段。提高长度上限以容纳全部表达式，生成后恢复原会话值。
  4. 拼出 SELECT product_id, … FROM Products GROUP BY product_id。空表没有动态列，应省略逗号。
  5. PREPARE 解析，EXECUTE 返回结果，DEALLOCATE PREPARE 释放预处理语句。

正确性

列覆盖：DISTINCT 恰好枚举出现过的全部商店，GROUP_CONCAT 内的 ORDER BY 保证列顺序。行覆盖：GROUP BY product_id 恰好为每个商品建立一组。

固定商品 p 和商店 s：若 (p,s) 存在，唯一匹配行的 CASE 返回价格，其余行返回 NULL，MAX 得到对应价格；若不存在，所有候选为 NULL，聚合结果也是 NULL。每个格子满足要求，行列也完整覆盖，因此结果正确。

边界与常见错误

  • 不能写死示例的四家商店；新输入可能改变列集合。
  • 列顺序必须由 GROUP_CONCAT 内部排序保证；最终查询的 ORDER BY 只影响行。
  • 不要使用 ELSE 0，也不要用真假值判断价格存在性。缺货是 NULL，真实价格 0 应保留。
  • GROUP_CONCAT 有长度上限，截断可能导致语法错误。本实现按最多 30 家、店名长度 7 的元数据设置为 10000 字节。
  • 店名用作字符串值和列别名时，需要不同处理。下方十六进制字面量避免把任意店名直接插入引号内；反引号别名须把内部反引号加倍。
  • 单店、稀疏价格、空表都应单独覆盖。空表返回仅 product_id 表头的空表是本页补充约定；公开题面未说明是否测试空表。
  • 如果输入 price 为 NULL，现有空报价与缺失记录在结果中均为 NULL。
  • 四语言参考假设主键约束成立，重复输入会覆盖旧值，不能用于处理违反主键的数据。

复杂度

设 N 为记录数，S 为商店数（≤30），P 为商品数，L 为生成 SQL 的长度。枚举店名需要扫描输入，店名排序约 O(S log S)，SQL 生成 O(L)。条件聚合约需评估 N×S 个条件，输出本身为 O(P×S)。GROUP BY 的排序、哈希或索引成本取决于执行计划，不能宣称整个 SQL 是 O(N)。聚合状态可达 O(P×S)，SQL 文本占 O(L)。

JavaScript、Python 的哈希映射参考平均时间 O(N + S log S + P×S)，含输出空间 O(N + P×S)。Java 使用 TreeSet，插入店名另有 O(N log S)。C++ 使用有序 map/set，时间 O(N(log P + log S) + P×S log S)，空间 O(N + P×S)。这里按短店名比较为常数。

替代方案与面试追问

  • 商店集合固定时，静态 CASE 聚合更直接；列集合变化仍需修改 SQL。
  • 应用层哈希映射可实现相同宽表语义，但不替代本题要求的数据库存储过程。
  • JSON_OBJECTAGG 返回一个 JSON 列，不符合本题独立商店列的输出结构。
  • 若取消联合主键，应先明确取最新、求和或取最大；不能靠 MAX 随意吞掉冲突。
  • 如何对齐排序规则？SQL 的去重、比较与排序遵循数据库 collation；本地语言默认比较不自动模拟大小写、重音或 Unicode 的数据库规则。
  • 如果商店有数万家，宽表会触及数据库列数、报文及展示限制，可考虑保留长表或返回 JSON。本题最多 30 家限制了该问题。

以下为完整过程定义，未执行或提交。LeetCode 编辑器不包含客户端 DELIMITER 指令；若在 mysql 命令行执行，需先由客户端切换分隔符，创建后 CALL PivotProducts()。

CREATE PROCEDURE PivotProducts()
BEGIN
    DECLARE old_limit BIGINT UNSIGNED;
    SET old_limit = @@SESSION.group_concat_max_len;
    SET SESSION group_concat_max_len = 10000;

    SELECT GROUP_CONCAT(
        CONCAT(
            'MAX(CASE WHEN store = CONVERT(X''', HEX(store),
            ''' USING utf8mb4) THEN price END) AS `',
            REPLACE(store, '`', '``'), '`'
        ) ORDER BY store SEPARATOR ', '
    ) INTO @pivot_columns
    FROM (SELECT DISTINCT store FROM Products) AS stores;

    SET SESSION group_concat_max_len = old_limit;
    SET @pivot_sql = CONCAT(
        'SELECT product_id',
        IF(@pivot_columns IS NULL, '', CONCAT(', ', @pivot_columns)),
        ' FROM Products GROUP BY product_id'
    );
    PREPARE pivot_stmt FROM @pivot_sql;
    EXECUTE pivot_stmt;
    DEALLOCATE PREPARE pivot_stmt;
END

Java 17+ · 本地语义参考

import java.util.*;

public class Main {
    record Product(int id, String store, Integer price) {}
    record Table(List<String> headers, List<List<Object>> rows) {}

    static Table pivotProducts(List<Product> products) {
        SortedSet<String> stores = new TreeSet<>();
        Map<Integer, Map<String, Integer>> prices = new LinkedHashMap<>();
        for (Product p : products) {
            stores.add(p.store());
            prices.computeIfAbsent(p.id(), k -> new HashMap<>())
                  .put(p.store(), p.price());
        }
        List<String> headers = new ArrayList<>();
        headers.add("product_id");
        headers.addAll(stores);
        List<List<Object>> rows = new ArrayList<>();
        for (var entry : prices.entrySet()) {
            List<Object> row = new ArrayList<>();
            row.add(entry.getKey());
            for (String store : stores) row.add(entry.getValue().get(store));
            rows.add(row);
        }
        return new Table(headers, rows);
    }
    public static void main(String[] args) {
        var products = List.of(new Product(1,"Shop",110),
            new Product(1,"LC_Store",100), new Product(2,"Nozama",200),
            new Product(2,"Souq",190), new Product(3,"Shop",1000),
            new Product(3,"Souq",1900));
        System.out.println(pivotProducts(products));
    }
}

JavaScript · 本地语义参考

function pivotProducts(products) {
  const stores = [...new Set(products.map(row => row[1]))].sort();
  const prices = new Map();
  for (const [id, store, price] of products) {
    if (!prices.has(id)) prices.set(id, new Map());
    prices.get(id).set(store, price);
  }
  return {
    headers: ['product_id', ...stores],
    rows: [...prices].map(([id, values]) =>
      [id, ...stores.map(s => values.has(s) ? values.get(s) : null)])
  };
}

def pivot_products(products):
    stores = sorted({store for _, store, _ in products})
    prices = {}
    for product_id, store, price in products:
        prices.setdefault(product_id, {})[store] = price
    return {
        "headers": ["product_id", *stores],
        "rows": [[product_id, *(values.get(s) for s in stores)]
                 for product_id, values in prices.items()]
    }

#include <iostream>
#include <map>
#include <optional>
#include <set>
#include <string>
#include <vector>
using namespace std;
struct Product { int id; string store; optional<int> price; };
struct Table {
    vector<string> headers;
    vector<vector<optional<int>>> rows;
};
Table pivotProducts(const vector<Product>& products) {
    set<string> stores;
    map<int, map<string, optional<int>>> prices;
    for (const auto& p : products) {
        stores.insert(p.store);
        prices[p.id][p.store] = p.price;
    }
    Table result;
    result.headers.push_back("product_id");
    for (const auto& s : stores) result.headers.push_back(s);
    for (const auto& [id, values] : prices) {
        vector<optional<int>> row{id};
        for (const auto& s : stores) {
            auto it = values.find(s);
            row.push_back(it == values.end() ? nullopt : it->second);
        }
        result.rows.push_back(row);
    }
    return result;
}
int main() {
    vector<Product> products{{1,"Shop",110},{1,"LC_Store",100},
        {2,"Nozama",200},{2,"Souq",190},{3,"Shop",1000},{3,"Souq",1900}};
    auto result = pivotProducts(products);
    for (const auto& h : result.headers) cout << h << '\t';
    cout << '\n';
    for (const auto& row : result.rows) {
        for (const auto& x : row) {
            if (x.has_value()) cout << *x; else cout << "null";
            cout << '\t';
        }
        cout << '\n';
    }
}
