消费者下单频率

从订单、商品和客户三张表中，找出在指定的两个自然月里都达到消费门槛的客户。先读题并亲手推进数据，再决定是否展开完整题解。

Problem brief

题意

给定客户表 Customers、商品表 Product 与订单表 Orders。每笔订单的消费额是商品单价乘购买数量。查询在 2020 年 6 月和 2020 年 7 月的月消费额都不低于 100 美元的客户，返回 customer_id 和 name；结果顺序不限。

Customers

  • customer_id PKINT
  • nameVARCHAR(30)
  • countryVARCHAR(30)

Product

  • product_id PKINT
  • descriptionVARCHAR(30)
  • priceINT

Orders

  • order_id PKINT
  • customer_idINT
  • product_idINT
  • order_dateDATE
  • quantityINT
约束与关系： 三张表各自的主键列值唯一；订单中的 customer_id 与 product_id 分别对应已有客户和商品；单价、数量为整数；目标月份固定为 2020-06 与 2020-07，门槛固定为每月 100 美元。

Spoiler gate

准备好核对思路了吗？

Solution

按月条件聚合，一次完成双门槛判断

核心洞察

订单没有金额，先连接商品表取得单价，再以 price × quantity 算出每笔消费。对每位客户做条件聚合，分别计算六月和七月金额；两个和都达到 100 才保留。

完整过程

  1. Orders 按 product_id 连接 Product。
  2. 按 customer_id 分组。
  3. 两个 SUM(CASE WHEN ...) 分别统计六月和七月。
  4. HAVING 同时检查两个门槛。
  5. 连接 Customers 取得姓名。

正确性

每笔订单连接唯一商品，金额不会重复。两个条件表达式分别只接收目标月份，故求和正好等于对应月消费。HAVING 使用逻辑与，所以返回者恰好是两个总额都不低于 100 的客户；任何合格客户也一定通过两项判断。

边界

  • 某月无订单时条件和为 0。
  • 恰好 100 时应保留。
  • 五月、八月等订单不计入。
  • 同月多笔订单必须累加。

复杂度

设订单数为 O。在合理索引与哈希/排序聚合模型下，主要扫描和聚合成本近似 O(O)；分组状态占 O(C)，其中 C 是出现订单的客户数。实际执行计划由数据库决定。

替代方案

可先按客户和月份生成月账单，再二次分组要求合格月份数为 2；也可分别聚合六月、七月后连接。条件聚合通常最紧凑，只需一次分组。

  • 如何改为连续 N 个月都达标？

常见错误

  • 用订单数量代替金额。
  • 两个月合计后只判断总额 ≥ 200。
  • 误用 OR。
  • 用字符串模糊匹配日期边界。
monthly_spend = Σ(price × quantity), qualifying = june_spend ≥ 100 AND july_spend ≥ 100

SELECT c.customer_id, c.name
FROM Customers AS c
JOIN Orders AS o ON o.customer_id = c.customer_id
JOIN Product AS p ON p.product_id = o.product_id
GROUP BY c.customer_id, c.name
HAVING SUM(
  CASE WHEN o.order_date >= '2020-06-01'
        AND o.order_date <  '2020-07-01'
       THEN p.price * o.quantity ELSE 0 END
) >= 100
AND SUM(
  CASE WHEN o.order_date >= '2020-07-01'
        AND o.order_date <  '2020-08-01'
       THEN p.price * o.quantity ELSE 0 END
) >= 100;
import java.time.LocalDate;
import java.util.*;

public class CustomerOrderFrequency {
  record Customer(int id, String name) {}
  record Product(int id, int price) {}
  record Order(int customerId, int productId,
               LocalDate date, int quantity) {}

  public static List<Customer> solve(
      List<Customer> customers,
      List<Product> products,
      List<Order> orders) {
    Map<Integer, Integer> prices = new HashMap<>();
    for (Product p : products) prices.put(p.id(), p.price());

    Map<Integer, long[]> spend = new HashMap<>();
    for (Order o : orders) {
      int month = targetMonth(o.date());
      if (month < 0) continue;
      long amount = (long) prices.get(o.productId()) * o.quantity();
      spend.computeIfAbsent(o.customerId(), k -> new long[2])
           [month] += amount;
    }

    List<Customer> answer = new ArrayList<>();
    for (Customer c : customers) {
      long[] monthly = spend.getOrDefault(c.id(), new long[2]);
      if (monthly[0] >= 100 && monthly[1] >= 100) answer.add(c);
    }
    return answer;
  }

  private static int targetMonth(LocalDate date) {
    if (date.getYear() != 2020) return -1;
    if (date.getMonthValue() == 6) return 0;
    if (date.getMonthValue() == 7) return 1;
    return -1;
  }
}
function customerOrderFrequency(customers, products, orders) {
  const prices = new Map(
    products.map((p) => [p.product_id, p.price])
  );
  const spend = new Map();

  for (const order of orders) {
    const month = order.order_date.slice(0, 7);
    if (month !== "2020-06" && month !== "2020-07") continue;
    const monthly = spend.get(order.customer_id) ?? [0, 0];
    const index = month === "2020-06" ? 0 : 1;
    monthly[index] += prices.get(order.product_id) * order.quantity;
    spend.set(order.customer_id, monthly);
  }

  return customers
    .filter((c) => {
      const [june, july] = spend.get(c.customer_id) ?? [0, 0];
      return june >= 100 && july >= 100;
    })
    .map(({ customer_id, name }) => ({ customer_id, name }));
}
from collections import defaultdict
from typing import TypedDict

class Customer(TypedDict):
    customer_id: int
    name: str

def customer_order_frequency(
    customers: list[Customer],
    products: list[dict],
    orders: list[dict],
) -> list[Customer]:
    prices = {p["product_id"]: p["price"] for p in products}
    spend: dict[int, list[int]] = defaultdict(lambda: [0, 0])

    for order in orders:
        month = str(order["order_date"])[:7]
        if month not in ("2020-06", "2020-07"):
            continue
        index = 0 if month == "2020-06" else 1
        spend[order["customer_id"]][index] += (
            prices[order["product_id"]] * order["quantity"]
        )

    return [
        {"customer_id": c["customer_id"], "name": c["name"]}
        for c in customers
        if spend[c["customer_id"]][0] >= 100
        and spend[c["customer_id"]][1] >= 100
    ]
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>

struct Customer { int id; std::string name; };
struct Product { int id; int price; };
struct Order {
  int customerId, productId;
  std::string date;
  int quantity;
};

std::vector<Customer> customerOrderFrequency(
    const std::vector<Customer>& customers,
    const std::vector<Product>& products,
    const std::vector<Order>& orders) {
  std::unordered_map<int, int> prices;
  for (const auto& p : products) prices[p.id] = p.price;

  std::unordered_map<int, std::pair<long long, long long>> spend;
  for (const auto& o : orders) {
    std::string month = o.date.substr(0, 7);
    if (month != "2020-06" && month != "2020-07") continue;
    long long amount = 1LL * prices[o.productId] * o.quantity;
    auto& monthly = spend[o.customerId];
    if (month == "2020-06") monthly.first += amount;
    else monthly.second += amount;
  }

  std::vector<Customer> answer;
  for (const auto& c : customers) {
    auto monthly = spend[c.id];
    if (monthly.first >= 100 && monthly.second >= 100)
      answer.push_back(c);
  }
  return answer;
}
