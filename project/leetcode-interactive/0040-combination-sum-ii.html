题意转述

唯一组合，单票单用

给定一个可能含重复值的正整数数组 candidates 和正整数 target，找出所有和等于 target 的唯一组合。数组中的每个位置最多使用一次，答案顺序不限。

两层“不同”：下标不同的两张 1 可以同时出现在 [1,1,6] 中；但从不同 1 开始得到的相同数值组合只能保留一份。

官方样例 · 格式化输入输出

输入

candidates = [10, 1, 2, 7, 6, 1, 5]
target = 8

输出 

[[1, 1, 6], [1, 2, 5],
 [1, 7], [2, 6]]

约束：1 ≤ candidates.length ≤ 100；1 ≤ candidates[i] ≤ 50；1 ≤ target ≤ 30。数组参数保留参数名、等号和值；本题无字符串，若出现空格会显示为 ␠。

    CORE INSIGHT

    排序让“同层重复”相邻出现

    状态：dfs(start, remaining)

    路径只从 start 右侧继续取。命中 remaining = 0 时复制路径；候选值大于 remaining 时停止本层。

    跳重：i > start

    只有 i 不是本层第一个位置且值等于前一项时才跳过。不要写成 i > 0，否则会误删跨层重复选择。

    FULL PROCESS

    完整解题过程

    1. 1

      排序。重复值相邻，且可用 value > remaining 提前 break。

    2. 2

      同层跳重。若 i > start 且值等于前一项，continue。

    3. 3

      选择一次。push 当前值，递归传 i + 1。

    4. 4

      撤销。递归返回后 pop，恢复路径尝试下一张票。

    WHY [1,1,6] SURVIVES 

    层 0: start=0
  i=0 → 选第一张 1

层 1: start=1
  i=1，i == start
  第二张 1 可以选择 ✓

回到层 0:
  i=1 > start
  a[1] == a[0]
  同层第二张 1 跳过 ✓

    TIME

    O(2ⁿ)

    最坏枚举所有子集；排序与剪枝降低实际节点数。

    SPACE

    O(n)

    不计输出，递归栈与 path 最深为 n。

    SORT

    O(n log n)

    让重复相邻，也为超出 remaining 的 break 提供前提。

    OUTPUT

    O(S)

    S 为所有结果元素总数，保存答案不可省略。

    EDGE CASES

    边界情况

    • • 所有数都大于 target：排序后首项即剪枝。
    • • 多个相同值：可以跨层选多个，但同层只从第一个开始。
    • • 某项等于 target：产生单元素组合，之后返回。
    • • candidates 无序：必须先排序再跳重。
    • • 保存答案必须复制 path。

    ALTERNATIVES

    替代方案取舍

    主推：排序 + 同层跳重回溯

    直接在生成阶段保证唯一，面试表达最清晰。

    位掩码 + Set 去重

    实现直观但最多枚举 2ⁿ 个子集并保存字符串键，n=100 不可行。

    按值计数 DFS

    先压缩为 value-count，可减少重复节点，但代码与面试讲解更复杂。

    INTERVIEW FOLLOW-UPS

    面试高频追问

    为什么传 i + 1？
    数组每个位置只能使用一次，下一层必须越过当前票。
    为什么 i > start 而不是 i > 0？
    前者只去除兄弟分支重复；后者会误伤下一层合法的相同值。
    和第 39 题差在哪？
    39 题元素互异且可无限使用，递归传 i；40 题输入可重复且位置只用一次，传 i+1 并同层跳重。

    COMMON MISTAKES

    常见错误

    • ✕ 递归继续传 i，导致同一实体票反复使用。
    • ✕ 跳重写成 i > 0，漏掉 [1,1,6]。
    • ✕ 不排序就比较相邻值，去重失效。
    • ✕ 用 Set 事后去重，搜索仍大量重复。
    • ✕ 忘记 pop 或忘记复制 path。
    • ✕ 未排序却在 value > remaining 时 break。
