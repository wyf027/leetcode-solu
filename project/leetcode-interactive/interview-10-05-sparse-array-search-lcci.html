Problem

题意

给定一个按字典序排好的字符串数组，其中夹杂若干空字符串。请返回目标字符串 s 的下标；若不存在，返回 -1。

官方约束：words.length 在 [1, 1,000,000] 内。

Example 01 / Miss

words = ["at", "", "", "", "ball", "", "", "car", "", "", "dad", "", ""]
s = "ta"

输出：-1

Example 02 / Hit

words = ["at", "", "", "", "ball", "", "", "car", "", "", "dad", "", ""]
s = "ball"

输出：4

可见字符约定：空字符串完整写作 ""；若输入里真的出现空格，将以 ␠ 表示。本题示例没有空格字符。

Core Insight

空白不是比较结果，只是一次邻近信号搜索

普通二分唯一被破坏的地方，是 words[mid] == "" 时无法判断左右方向。此时从 mid 同时向两侧扩展，在当前 [left, right] 内找到最近的非空字符串；找到后，余下步骤恢复为普通二分。

Complete Process

完整过程

  1. 令 left = 0，right = n - 1。
  2. 计算中点 mid；若不是空串，直接比较。
  3. 若是空串，从 mid - 1 与 mid + 1 同时向外扫描。
  4. 两侧都越过区间时，区间内没有有效信号，返回 -1。
  5. 比较最近非空字符串，命中则返回，否则收缩一半区间。

Boundary

边界处理

  • 数组只有一个元素时，循环仍需执行一次。
  • 当前区间全为空串时，双向扫描必须安全退出。
  • 目标落在有效字符串范围之外时，最终返回 -1。
  • 不要把空串直接当成“小于目标”，否则可能错误丢弃左半区。

Complexity

复杂度

空串很少时接近 O(log n)。连续空串可迫使扫描覆盖整个区间，故最坏时间 O(n)；额外空间 O(1)。

Alternative

替代方案

线性扫描稳定 O(n)。若同一数组会被反复查询，可预处理非空下标，使用 O(n) 空间换取每次 O(log m) 查询。

Why Recommended

面试推荐

修改二分只改变“中点为空”这一处，保留原数组、不增加空间，并能清楚展示你对二分不变量的掌握。

Interview Follow-ups

面试追问

  • 为什么复杂度不能无条件写成 O(log n)？
  • 大量重复查询时，怎样设计非空下标缓存？
  • 若有效字符串允许重复，怎样返回最左下标？
  • 只向左找非空字符串时，更新 left 要注意什么？

Common Mistakes

常见错误

  • 扫描越过 left/right 后仍访问数组。
  • 找到非空下标后，仍拿原始中点做区间更新。
  • 目标未找到时忘记返回 -1。
  • 把平均表现当成最坏复杂度。
class Solution {
    public int findString(String[] words, String s) {
        int left = 0, right = words.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (words[mid].isEmpty()) {
                int low = mid - 1, high = mid + 1;
                while (true) {
                    if (low < left && high > right) return -1;
                    if (high <= right && !words[high].isEmpty()) {
                        mid = high;
                        break;
                    }
                    if (low >= left && !words[low].isEmpty()) {
                        mid = low;
                        break;
                    }
                    low--;
                    high++;
                }
            }
            int cmp = words[mid].compareTo(s);
            if (cmp == 0) return mid;
            if (cmp < 0) left = mid + 1;
            else right = mid - 1;
        }
        return -1;
    }
}
