第 95 题完整题解

Core insight

空区间必须返回一个 null

对每个根 r，枚举 build(lo, r−1) 与 build(r+1, hi) 的所有组合。空区间返回 [null] 而不是 []，这样“没有孩子”仍能参与一次配对。

Complete process

完整过程

  1. 1. build(lo, hi) 表示生成值域 lo…hi 的全部 BST。
  2. 2. 依次令 r = lo…hi，作为当前根。
  3. 3. 递归获得所有左子树与右子树。
  4. 4. 双重循环配对 left × right，并创建根 r。
  5. 5. 汇总所有根产生的树并返回。

Edges

边界条件

  • lo > hi：返回 [null]，表示唯一的空子树。
  • lo = hi：只产生一个单节点树。
  • 根在区间端点：其中一侧苗床只有 null。
  • 返回顺序任意，但每个结构必须唯一。
  • 约束 n ≤ 8，输出规模仍会快速增长。

Complexity

复杂度与替代方案

共有第 n 个卡特兰数 Cₙ 棵答案，每棵序列化含 n 个节点，因此时间和输出空间均为 O(n·Cₙ)，递归深度 O(n)。区间记忆化能减少重复子问题，但会共享子树对象；若后续可能修改节点，应深拷贝或使用纯递归。

Interview follow-ups

面试追问

为什么不是返回空数组？
空子树是一种合法选择，必须让另一侧的每棵树都能与它配对。
为什么不会重复？
每棵 BST 的根唯一；固定根后，左右值域也唯一，递归组合因此互斥且完备。
如何只计算数量？
改用 Catalan DP：dp[n] = Σ dp[left]·dp[right]。
能否记忆化？
可以按 (lo, hi) 缓存，但要说明共享节点的可变性风险。

Common mistakes

常见错误

  • 空区间返回 []，导致端点根无法生成。
  • 只组合相同下标的左右子树，漏掉笛卡尔积。
  • 左右区间仍使用 1…n，破坏 BST 值域。
  • 复用同一个根对象并反复改左右指针，覆盖先前答案。
  • 把第 96 题的“计数”误当成本题的“构造”。

import java.util.*;

class Solution {
    public List<TreeNode> generateTrees(int n) {
        return build(1, n);
    }

    private List<TreeNode> build(int lo, int hi) {
        List<TreeNode> trees = new ArrayList<>();
        if (lo > hi) {
            trees.add(null);
            return trees;
        }

        for (int rootValue = lo; rootValue <= hi; rootValue++) {
            List<TreeNode> leftTrees = build(lo, rootValue - 1);
            List<TreeNode> rightTrees = build(rootValue + 1, hi);
            for (TreeNode left : leftTrees) {
                for (TreeNode right : rightTrees) {
                    trees.add(new TreeNode(rootValue, left, right));
                }
            }
        }
        return trees;
    }
}

    const build = (lo, hi) => {

                }

        }
        return trees;
    };

    return build(1, n);
};

    vector<TreeNode*> build(int lo, int hi) {
        if (lo > hi) return {nullptr};
        vector<TreeNode*> trees;

        for (int rootValue = lo; rootValue <= hi; ++rootValue) {
            auto leftTrees = build(lo, rootValue - 1);
            auto rightTrees = build(rootValue + 1, hi);
