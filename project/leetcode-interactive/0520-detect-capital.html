检测大写字母

先观察一串字母如何形成一致的“大写风格”，再决定它是否合法。交互区不会直接给出代码答案。

题目

给定字符串 word。若它满足以下任意一种大写规则，返回 true；否则返回 false。

全大写：例如 "USA"
全小写：例如 "leetcode"
仅首字母大写：例如 "Google"

示例 1

输入：word = "USA"
输出：true

示例 2

输入：word = "FlaG"
输出：false

约束

  • 1 <= word.length <= 100
  • word 仅由大小写英文字母组成。

字母风格扫描仪

逐字符统计大写数量，观察三个合法模式何时仍有可能成立。

步骤 0 / 0

仅接受 1–100 个英文字母；输入会通过 textContent 安全写入页面。

题解：计数归纳三种模式

核心洞察

设单词长度为 n，大写字母数为 capitals。三种合法形态可以统一为：capitals == n（全大写）、capitals == 0（全小写），或 capitals == 1 且首字母大写（首字母大写）。

完整过程

  1. 遍历单词，统计大写英文字母数量。
  2. 依次判断三个合法条件。
  3. 任一条件成立即返回 true，否则返回 false。

正确性说明

若算法返回真，它命中了三个条件之一，分别精确对应题目允许的三种形式，因此用法正确。反过来，任何正确用法必属于这三种形式，其大写计数和首字母特征必命中对应条件，因此算法不会漏掉合法单词。故算法当且仅当大写用法正确时返回真。

边界情况

  • 长度为 1 时，无论大小写都合法。
  • 全大写、全小写直接命中计数条件。
  • 只有一个大写但不在首位（如 leetcodE）不合法。
  • 首字母大写但后续又出现大写（如 FlaG）不合法。

复杂度

遍历一次：时间复杂度 O(n)；只使用计数器：额外空间复杂度 O(1)。

替代方案

可以逐字符维护预期模式，或用正则表达式 ^[A-Z]+$|^[a-z]+$|^[A-Z][a-z]+$。正则更短，但计数法更直观、跨语言稳定，也更容易解释复杂度。

面试追问

  • 若输入包含 Unicode 字母，ASCII 范围判断应如何替换？
  • 能否在发现模式必然非法时提前返回？
  • 若规则扩展为标题格式的多个单词，接口与状态应如何设计？

常见错误

  • 只检查首字母，忽略后续大小写是否一致。
  • 把单字母小写误判为非法。
  • 使用语言的大小写转换却未考虑空串或区域设置；本题虽保证非空，解释时仍应说明前提。

class Solution {
    public boolean detectCapitalUse(String word) {
        int capitals = 0;
        for (int i = 0; i < word.length(); i++) {
            char c = word.charAt(i);
            if (c >= 'A' && c <= 'Z') capitals++;
        }
        int n = word.length();
        return capitals == 0 || capitals == n
            || (capitals == 1 && Character.isUpperCase(word.charAt(0)));
    }
}
/** @param {string} word @return {boolean} */
var detectCapitalUse = function(word) {
    let capitals = 0;
    for (const c of word) {
        if (c >= 'A' && c <= 'Z') capitals++;
    }
    return capitals === 0 || capitals === word.length
        || (capitals === 1 && word[0] >= 'A' && word[0] <= 'Z');
};
