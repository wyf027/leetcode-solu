逆波兰表达式求值

把中缀表达式的“找优先级”换成一个更直接的问题：扫描每个 token，数字压栈，运算符弹出两个操作数并把结果压回。最后栈顶就是答案。

标签：栈 / 数组 / 模拟 时间：O(n) 空间：O(n)

题目

给定一个字符串数组 tokens，表示一个逆波兰表达式。请计算该表达式的值。有效运算符为 +、-、*、/；除法向零截断。

示例

tokens = ["2", "1", "+", "3", "*"]

输出：9

解释：(2 + 1) * 3 = 9

输入边界
1 ≤ tokens.length ≤ 10⁴

数值边界
中间结果与最终结果均在 32 位有符号整数范围内。

面试一句话

逆波兰表达式的运算顺序已写在 token 顺序里；栈保存尚未参与计算的操作数，遇到运算符时按 先弹右、再弹左 的顺序计算。

  1. 1从左到右遍历 token。
  2. 2数字直接入栈。
  3. 3运算符弹出 b，再弹出 a，压回 a 运算 b。

核心洞察与过程

为什么不需要优先级？ 后缀写法保证了每个运算符出现时，它需要的两个操作数已经出现。因此栈顶的两个值恰好就是它的输入。

减法和除法的关键：若依次弹出 b、a，必须计算 a - b 或 a / b，不可反过来。

过程不变量：扫描到当前位置后，栈从底到顶保存的是已扫描前缀中所有“尚未归约”的子表达式值。

复杂度、替代方案与边界

复杂度
每个 token 进栈一次、出栈至多一次：时间 O(n)，最坏空间 O(n)。
替代方案
递归也能解析后缀表达式，但会产生递归深度风险；显式栈更直观、更稳妥。
边界
负数是普通数字 token；除法要向零截断；题目保证表达式有效，所以无需额外处理栈不足或除零。

高频失误与追问

  • 把 a、b 写反：加乘不会暴露问题，减除会立刻出错。始终先取右操作数 b。
  • JavaScript 直接 /：它会得到小数，须用 Math.trunc(a / b)。
  • 面试追问：若输入改为中缀表达式？需要先用双栈或 Shunting-yard 算法处理优先级和括号，再求值。
