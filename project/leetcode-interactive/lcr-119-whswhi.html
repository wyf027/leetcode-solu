最长连续序列

不用排序，在无序数组中以 O(n) 时间找到数字连续序列的最大长度。

开始演示

题意

给定未排序整数数组 nums，返回其中最长的连续整数序列长度。序列元素在原数组中不必相邻。

示例

输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长连续序列为 [1,2,3,4]

约束

  • 0 <= nums.length <= 105
  • -109 <= nums[i] <= 109
  • 要求设计并实现 O(n) 时间复杂度的算法。

核心洞察

只从“序列起点”开始向右扩展：若 x - 1 存在，x 绝不可能是起点，直接跳过。这样每个连续段只被完整扫描一次。

起点判定：x - 1 不在集合中。

分步交互

对集合 {100, 4, 200, 1, 3, 2} 观察从起点 1 的扩展。

快捷键：Enter

完整过程

  1. 将所有数字放入哈希集合，自动去重且可 O(1) 查询。
  2. 枚举集合中的每个 x；若 x - 1 存在，跳过。
  3. 否则从 x 开始不断查询 x + 1、x + 2……并记录长度。
  4. 用最大长度更新答案。

边界

  • 空数组返回 0；重复数字不会影响集合中的长度。
  • 单个数的最长长度为 1。
  • 负数同样适用；不要把数组下标当作数字范围。

复杂度

时间 O(n)：每段只从起点扩展一次。

空间 O(n)：哈希集合。

替代方案

排序后扫描相邻数，逻辑直观且可处理重复值，但时间为 O(n log n)，不满足本题的线性要求。

官方签名代码

class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) set.add(x);
        int best = 0;
        for (int x : set) if (!set.contains(x - 1)) {
            int y = x; while (set.contains(y)) y++;
            best = Math.max(best, y - x);
        }
        return best;
    }
}

追问与常见错误

追问

如果数据持续流入？维护并查集或“端点长度”哈希表，可以在每次插入后更新相邻区间长度。

常见错误

  • 从每个数字都向右扫描，退化为 O(n²)。
  • 没有用集合去重，重复数干扰计数。
  • 排序解法被误认为满足 O(n) 要求。

测试与验证区

建议覆盖空数组、重复值、负数、单一长序列及多个不相交序列。
