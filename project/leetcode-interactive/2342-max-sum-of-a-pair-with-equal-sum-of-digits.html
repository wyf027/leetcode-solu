LeetCode 2342 / Max Sum of a Pair With Equal Sum of Digits

数位和相等数对的最大和

两个不同位置的数，各位数字相加后相同。你能找到总和最大的一对吗？

官方题目 ↗

01 / 题目

先理解什么是合法数对

给定从下标 0 开始的正整数数组 nums，选择不同下标 i、j。若 nums[i] 与 nums[j] 的十进制数位和相等，该数对合法。返回所有合法数对中最大的 nums[i] + nums[j]；没有合法数对则返回 -1。

数位和例子：43 → 4 + 3 = 7。下标必须不同，但数值可以相同。

官方示例 1

输入：nums = [18,43,36,13,7]
输出：54

下标 (0, 2) 的 18、36 数位和均为 9，总和 54；下标 (1, 4) 的 43、7 数位和均为 7，总和 50。最大值是 54。

官方示例 2

输入：nums = [10,12,19,14]
输出：-1

数位和分别为 1、3、10、5，没有任何合法数对，因此返回 -1。

约束与参数

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁹
  • 函数：maximumSum(nums)，参数为整数数组，返回整数。

04 / 深入推导

准备好再看解法

从需要保留的信息出发，推导一次遍历的做法。

核心洞察：当前数只需要一个最佳搭档

固定当前数字 x 后，合法搭档必须与它有相同数位和。为了让 x + y 最大，只需要保留此前该数位和组里的最大值 y。用长度 82 的数组 best 存储各组最大值，用 0 表示还没有数字。

为何 82 格足够？小于 10⁹ 的数最多九位，最大数位和为 9 × 9 = 81；唯一的十位数 10⁹ 数位和为 1。因此下标 0–81 足够，0 格闲置。

完整过程

  1. 令答案 ans = -1，所有 best[s] = 0。
  2. 对每个 x，用临时变量不断取余 10、整除 10，计算数位和 s，不改变原值。
  3. 若 best[s] > 0，此前存在合法搭档，更新 ans = max(ans, x + best[s])。
  4. 再更新 best[s] = max(best[s], x)，继续处理下一个数字。
  5. 返回 ans；没有配对时仍为 -1。

必须先配对，后存入当前数字。反过来会让当前数字与自身配对，违反不同下标条件。

示例 1：18 进入 9 格；43 进入 7 格；36 与 9 格的 18 得到 54，并把记录换为 36；13 进入 4 格；7 与 7 格的 43 得到 50，答案保留 54。

正确性证明

循环不变式：处理当前元素前，best[s] 是已处理前缀中数位和为 s 的最大数；ans 是该前缀内所有合法数对的最大和，或无数对时的 -1。空前缀显然成立。

加入 x 后，新增合法数对都由 x 和此前同组数字组成。选择其中最大的 best[s]，便得到所有新增数对的最大和，与旧答案取最大就涵盖了全部合法数对。随后更新组内最大数，不变式继续成立。遍历结束时前缀即整个数组，所以答案正确。

边界与复杂度

  • 只有一个数、所有数位和互不相同：返回 -1。
  • 相同数值出现在两个位置可以配对；不要对输入去重。
  • 所有输入为正整数，因此可以用 0 表示空组。
  • 两数和不超过 2 × 10⁹，Java / C++ 的 32 位有符号整数足够；JavaScript Number 也可精确表示。

设 n 为长度、D 为最大十进制位数、S 为最大数位和：时间 O(nD + S)，额外空间 O(S)。本题 D ≤ 10、S = 81，因此可写为时间 O(n)、额外空间 O(1)。

替代方案

按数位和分组，每组排序并取最大两个数：思路直观，最坏时间 O(n log n)，分组存储 O(n)。也可在每组直接维护前两大值，最后统一统计；一次遍历即时配对只需保存每组一个最大值。暴力枚举所有下标对要 O(n²D)，无法适配 10⁵ 个元素。

四语言完整提交代码

Java

class Solution {
    public int maximumSum(int[] nums) {
        int[] best = new int[82];
        int ans = -1;
        for (int x : nums) {
            int s = 0;
            for (int t = x; t > 0; t /= 10) s += t % 10;
            if (best[s] > 0) ans = Math.max(ans, x + best[s]);
            best[s] = Math.max(best[s], x);
        }
        return ans;
    }
}

var maximumSum = function(nums) {
    const best = Array(82).fill(0);
    let ans = -1;
    for (const x of nums) {
        let s = 0;
        for (let t = x; t > 0; t = Math.floor(t / 10)) s += t % 10;
        if (best[s] > 0) ans = Math.max(ans, x + best[s]);
        best[s] = Math.max(best[s], x);
    }
    return ans;
};

Python 3

from typing import List

class Solution:
    def maximumSum(self, nums: List[int]) -> int:
        best = [0] * 82
        ans = -1
        for x in nums:
            s, t = 0, x
            while t > 0:
                s += t % 10
                t //= 10
            if best[s] > 0:
                ans = max(ans, x + best[s])
            best[s] = max(best[s], x)
        return ans

常见错误

  • 先写入 best 再配对，错误地把同一个下标使用两次。
  • 用当前数直接覆盖 best，丢掉之前更大的搭档。
  • 计算数位和时消耗了原始 x，最终用 0 参与加法。
  • 答案从 0 开始，导致无合法数对时返回值错误。
  • 把数位和当成反复求和的个位数（数字根），错误合并了不同组。

面试追问

  • 还要返回下标？每组同时保存最大数对应的下标，答案更新时记录这一对。
  • 改为选三个数？每组维护最大的三个数及数量，数量至少为 3 时统计三数和。
  • 输入为数据流？沿用组内最大值和全局答案，每来一个数更新即可。
  • 允许负数或零？先明确负数的数位和定义，并用显式存在标记替代 0 哨兵。
