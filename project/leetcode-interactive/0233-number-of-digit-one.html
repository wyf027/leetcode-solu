Number of Digit One
按位数一

不要真的枚举 1 到 n。固定某个十进制位，把数字拆成高位、当前位、低位；一位中出现 1 的次数可以在 O(1) 内算出，所有位只需 O(log n)。

题意

给定整数 n，计算 1 到 n 的所有非负整数十进制表示中，数字字符 '1' 出现的总次数。

官方样例
n = 13
输出：6；其中 1、10、11、12、13 分别贡献 1、1、2、1、1 个 1。

约束：0 ≤ n ≤ 10⁹

交互：n = 13 的逐位贡献

从个位开始，令 high = n / (digit × 10)、cur = (n / digit) % 10、low = n % digit。

interview answer

题解：high / cur / low

O(log₁₀ n)

核心洞察

固定位置 digit = 1, 10, 100…。高位每完整循环都会让该位为 1 恰好 digit 次；当前位决定是否有额外不完整循环：cur = 0 时没有，cur = 1 时加 low + 1，cur > 1 时加完整的 digit。

完整过程

  1. 初始化 answer=0，digit=1。
  2. 拆出 high、cur、low。
  3. 加 high × digit 个完整循环贡献。
  4. 按 cur 分支补齐，digit 乘 10。

边界与复杂度

n = 0 返回 0。Java/C++ 计算 digit × 10 时用 long，避免接近整型上界时溢出。

时间：O(log n)
空间：O(1)

替代方案取舍

逐个数每一位，时间至少 O(n log n)，n=10⁹ 不可行。数字 DP 同样可解，但状态更多；本题只统计一个数字，位贡献公式更简洁。

常见错误

  • 把 cur = 1 的额外量写成 low，漏掉当前数字自身，所以应为 low + 1。
  • 遗漏基础项 high × digit。
  • 把 digit 从 0 开始或忘记每轮乘 10。
  • 使用 int 保存 digit 并让 digit × 10 溢出。

面试追问

统计数字 0 怎么办？ 前导零不能计数，需要对 high=0 单独处理。
能统计任意 digit 吗？ 非零数字可类推，将阈值从 1 换成目标数字。

class Solution {
    public int countDigitOne(int n) {
        long answer = 0;
        for (long digit = 1; digit <= n; digit *= 10) {
            long high = n / (digit * 10), cur = n / digit % 10, low = n % digit;
            answer += high * digit;
            if (cur == 1) answer += low + 1;
            else if (cur > 1) answer += digit;
        }
        return (int) answer;
    }
}
/** @param {number} n @return {number} */
var countDigitOne = function (n) {
  let answer = 0;
  for (let digit = 1; digit <= n; digit *= 10) {
    const high = Math.floor(n / (digit * 10));
    const cur = Math.floor(n / digit) % 10, low = n % digit;
    answer += high * digit + (cur === 1 ? low + 1 : cur > 1 ? digit : 0);
  }
  return answer;
};

    def countDigitOne(self, n: int) -> int:
        answer, digit = 0, 1
        while digit <= n:
            high, cur, low = n // (digit * 10), n // digit % 10, n % digit

        return answer
