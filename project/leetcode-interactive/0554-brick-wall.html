函数 leastBricks(wall)

返回 最少穿过的砖块数

非付费题
01 / Problem

把线落在砖缝上

墙的左右外边缘不能选。

给定二维数组 wall，每个子数组表示一行砖块从左到右的宽度；所有行总宽度相同、砖块高度均为 1。画一条从墙顶到底的垂线：穿过砖块内部计作穿过，恰好经过砖块边缘则不计。

返回最少穿过的砖块数。垂线不能与墙的左、右边缘重合。

函数形式

输入：wall: List<List<Integer>>

输出：Integer

每一行的宽度和都相等。

示例 1
输入：wall = [[1,2,2,1],[3,1,2],[1,3,2],
[2,4],[3,1,2],[1,3,1,1]]
输出：2
示例 2
输入：wall = [[1],[1],[1]]
输出：3
约束
  • n == wall.length，1 ≤ n ≤ 10⁴
  • 1 ≤ wall[i].length ≤ 10⁴
  • 1 ≤ Σ wall[i].length ≤ 2 × 10⁴
  • 各行宽度和相同
  • 1 ≤ wall[i][j] ≤ 2³¹ − 1

04 / Explanation

最多砖缝 = 最少穿砖

把每行内部砖缝转成“距左边缘的坐标”。若某坐标出现 k 次，垂线在那里只穿过 n − k 块砖。

完整过程

  1. 创建哈希表：键为砖缝坐标，值为出现行数。
  2. 逐行累加砖宽，得到前缀和。
  3. 只登记前 row.length - 1 块之后的前缀和，排除右外边缘。
  4. 维护最大出现次数 maxGaps。
  5. 返回 wall.length - maxGaps。

正确性

任取合法坐标 x。一行在 x 有内部砖缝，当且仅当该行不被垂线穿过。若 x 出现 count[x] 次，恰有 n-count[x] 行被穿过。因此最小化穿砖数等价于最大化砖缝计数。算法枚举了所有合法内部砖缝，必然包含最优位置，故返回值正确。

复杂度与边界

设砖块总数为 B：时间 O(B)，空间 O(B)。每行只有一块时哈希表为空，答案为行数。Java/C++ 用 long/long long 保存前缀和更稳妥。

完整代码

import java.util.*;
class Solution {
    public int leastBricks(List<List<Integer>> wall) {
        Map<Long, Integer> count = new HashMap<>();
        int maxGaps = 0;
        for (List<Integer> row : wall) {
            long prefix = 0;
            for (int i = 0; i < row.size() - 1; i++) {
                prefix += row.get(i);
                int now = count.getOrDefault(prefix, 0) + 1;
                count.put(prefix, now);
                maxGaps = Math.max(maxGaps, now);
            }
        }
        return wall.size() - maxGaps;
    }
}

替代方案

收集所有内部砖缝坐标，排序后统计最长相同段，时间 O(B log B)，空间 O(B)。

常见错误

  • 把每行总宽度也计入，非法选择右边缘。
  • 按砖宽计数，而非按前缀和坐标。
  • 直接返回最大砖缝数，忘记用行数相减。

面试追问

返回最佳坐标？ 更新最大值时同步保存前缀和。

多个位置并列？ 返回任意一个，或收集全部最大计数键。

为何不枚举横坐标？ 宽度可极大，且穿砖数只在砖缝处变化。
