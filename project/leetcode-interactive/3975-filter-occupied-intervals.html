筛选忙碌区间

先把相交或相邻的闭区间合并，再从合并结果中挖去一段空闲时间。

闭区间：端点也算在区间内

题意

给定若干可能重叠的忙碌闭区间 occupiedIntervals[i] = [startᵢ, endᵢ]，以及空闲闭区间 [freeStart, freeEnd]。先合并所有重叠或相接的忙碌区间，再删除落在空闲区间内的全部整数点。

例如 [1,1] 与 [2,2] 相接，要合成 [1,2]。答案须升序、互不重叠，并且区间数量最少。

示例

occupiedIntervals = [[2,6],[4,8],[10,10],[10,12],[14,16]]

freeStart = 7, freeEnd = 11

合并得到 [[2,8],[10,12],[14,16]]；扣掉 [7,11]，结果是 [[2,6],[12,12],[14,16]]。

题解

首屏保持问题与实验；需要时再展开完整推导与代码。

核心洞察

排序后只需维护最后一个合并段 [s,e]。当前段从 x 开始时，只有 x > e + 1 才真有空档；否则它重叠或相接，更新右端点即可。

扣除一个闭区间至多把一个合并段切成左、右两段：[s, freeStart-1] 和 [freeEnd+1, e]。

完整过程

  1. 按左端点升序排序。
  2. 扫描并合并重叠或相接段。
  3. 对每个合并段，若与空闲段无交集直接加入；否则按左右残留段加入。

复杂度

排序为 O(n log n)，两次线性扫描为 O(n)；结果与合并列表使用 O(n) 空间。

边界与常见错误

  • 忘记 +1：会把相接段错误拆开。
  • 自由区间端点是包含关系，左残留的右端应为 freeStart - 1。
  • 被空闲区间完全覆盖的段不应输出。
  • 输入数组若原地排序，调用方需接受其顺序变化。

替代方案与面试追问

替代：若输入已按左端点排序，可跳过排序达到 O(n)。若需动态插入/删除区间，可用有序映射维护不相交段。

追问：如果要扣除多个空闲区间？先各自合并，再使用双指针做区间差集。 

function filterOccupiedIntervals(occupiedIntervals, freeStart, freeEnd) {
  const a = occupiedIntervals.map(x => [...x]).sort((x, y) => x[0] - y[0]);
  const merged = [];
  for (const [s, e] of a) {
    if (!merged.length || s > merged[merged.length - 1][1] + 1) merged.push([s, e]);
    else merged[merged.length - 1][1] = Math.max(merged[merged.length - 1][1], e);
  }
  const ans = [];
  for (const [s, e] of merged) {
    if (e < freeStart || s > freeEnd) ans.push([s, e]);
    else { if (s < freeStart) ans.push([s, freeStart - 1]); if (e > freeEnd) ans.push([freeEnd + 1, e]); }
  }
  return ans;
}
class Solution {
  public int[][] filterOccupiedIntervals(int[][] a, int freeStart, int freeEnd) {
    Arrays.sort(a, (x, y) -> Integer.compare(x[0], y[0]));
    List<int[]> merged = new ArrayList<>();
    for (int[] x : a) {
      if (merged.isEmpty() || x[0] > merged.get(merged.size()-1)[1] + 1) merged.add(new int[]{x[0], x[1]});
      else merged.get(merged.size()-1)[1] = Math.max(merged.get(merged.size()-1)[1], x[1]);
    }
    List<int[]> ans = new ArrayList<>();
    for (int[] x : merged) { if (x[1] < freeStart || x[0] > freeEnd) ans.add(x); else { if (x[0] < freeStart) ans.add(new int[]{x[0], freeStart-1}); if (x[1] > freeEnd) ans.add(new int[]{freeEnd+1, x[1]}); } }
    return ans.toArray(new int[0][]);
  }
}
