分隔数组
以得到最大和

Partition Array for Maximum Sum

把数组切成连续小段，让每段贡献“段内最大值 × 段长”。边界怎么放，决定了最后的总和。

题目说明

给定整数数组 arr 和整数 k，将数组完整分隔为若干互不重叠的连续子数组，每段长度最多为 k。随后把每段中的所有值替换为该段最大值。返回变换后元素总和的最大可能值；答案保证适合 32 位整数。

参数形式

maxSumAfterPartitioning(arr, k) → integer

约束

  • 1 ≤ arr.length ≤ 500
  • 0 ≤ arr[i] ≤ 10⁹
  • 1 ≤ k ≤ arr.length

官方示例

输入：arr = [1,15,7,9,2,5,10], k = 3
输出：84
解释：数组可变为 [15,15,15,9,10,10,10]
输入：arr = [1,4,1,5,7,3,6,1,9,9,3], k = 4
输出：83
输入：arr = [1], k = 1
输出：1

最后一段决策实验台

逐步观察每个前缀如何枚举最后一段。

题解：用最后一段连接最优前缀

核心洞察

令 dp[i] 表示前 i 个元素的最大和。枚举最后一段长度 len = 1..min(k,i)，向左扩展时维护段内最大值 mx：

dp[i] = max(dp[i-len] + mx × len)

完整过程

  1. 令 dp[0]=0。
  2. 按 i=1..n 计算每个前缀。
  3. 对每个 i 向左查看至多 k 个数，持续更新 mx。
  4. 取全部合法最后一段的最大候选，返回 dp[n]。

正确性

任意覆盖前 i 项的最优分割都有唯一的最后一段。去掉它后，前面部分必为对应前缀的最优解，否则替换成更优前缀就能提高总和，产生矛盾。转移枚举了每一种合法最后一段，因此取到的最大值正是 dp[i]；归纳至 n 即得全局最优。

边界与复杂度

  • k=1 时答案是原数组和；单元素与全零无需特判。
  • 时间 O(nk)，空间 O(n)。

替代方案与面试追问

记忆化搜索具有相同复杂度但多出递归开销；暴力枚举分割会指数增长。若要恢复分段，可额外记录每个 i 的最佳 len 并回溯；若只求答案，可用循环数组压缩空间。

常见错误

  • 混淆前缀长度与数组下标。
  • 最后一段枚举超过 min(k,i)。
  • 每次重新扫描求最大值，退化成 O(nk²)。
  • 乘法中间值使用过窄整数。
  • 误用局部贪心；当前边界会影响后续选择。

class Solution {
    public int maxSumAfterPartitioning(int[] arr, int k) {
        long[] dp = new long[arr.length + 1];
        for (int i = 1; i <= arr.length; i++) {
            int mx = 0;
            for (int len = 1; len <= Math.min(k, i); len++) {
                mx = Math.max(mx, arr[i - len]);
                dp[i] = Math.max(dp[i], dp[i - len] + (long) mx * len);
            }
        }
        return (int) dp[arr.length];
    }
}
