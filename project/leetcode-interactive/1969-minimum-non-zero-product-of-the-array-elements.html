数组元素的最小非零乘积

Minimum Non-Zero Product of the Array Elements

每一列的 1 都留在原位列中。交换它们的归属，乘积会怎样变化？

打开官方题目 ↗

01 / 题目与规则

输入正整数 p，数组 nums 按下标从 1 开始，包含闭区间 [1, 2p − 1] 的全部整数。把每个数写成 p 位二进制后，可以任意次选择两个元素，交换它们相同位位置上的二进制位。

例如交换 1101 与 0011 从右数第 2 位，得到 1111 和 0001。目标是使整个数组的乘积为最小的非零值，最后返回该最小值对 1,000,000,007 取模的结果。先比较原始乘积，再取模。

参数：p: integer　返回：integer　约束：1 ≤ p ≤ 60

02 / 官方示例

示例 1

输入：p = 1
输出：1

nums = [1]，仅有一个元素，乘积为 1。

示例 2

输入：p = 2
输出：6

nums = [01, 10, 11]。交换无法得到更小的正乘积；原乘积 1 × 2 × 3 = 6 已最小。

示例 3

输入：p = 3
输出：1512

初始 [001, 010, 011, 100, 101, 110, 111]。交换第 2、5 个数的最高位，再交换第 3、4 个数的中间位，得到 [001, 110, 001, 110, 001, 110, 111]，乘积为 1512。

05 / 独立题解
准备好后，再展开推导与完整实现。




从同位交换到快速幂


核心洞察
记 M = 2ᵖ − 1，k = 2ᵖ⁻¹ − 1。保留最大的全 1 元素 M，其余元素按互补关系配成 (x, M − x)，共 k 对。每对每一列恰有一个 1，因此可以让一方只保留最低位，另一方接收其余所有 1，变为 (1, M − 1)。


最小非零乘积 = M × (M − 1)k
答案 = ((M mod MOD) × powMod(M − 1, k)) mod MOD


完整过程
  1. 计算 M = (1 << p) − 1，注意使用足够宽的整数类型。
  2. 计算底数 M − 1 与指数 k = (1 << (p − 1)) − 1。实际不生成数组。
  3. 快速幂维护结果 r = 1：指数最低位是 1 时把当前底数乘入 r；然后底数平方、指数右移。
  4. 每次乘法后取模，最后乘 M mod MOD。指数使用真实整数，不对 MOD 取模。


例如 p = 3：互补对 (1, 6)、(2, 5)、(3, 4) 最终都成为 (1, 6)，7 保留，得到 7 × 6³ = 1512。逐位操作时先确保“小数”最低位为 1，再移出它的高位，可始终保持双方非零。


正确性：可达性与下界


可达性。互补数对中每列只有一个 1，同位交换可以独立决定它落在哪一边。将最低位放入小数、高位全部放入大数，就得到 (1, M − 1)。不同数对互不干扰，因此上述构造合法。


为什么没有更小的正乘积？以下给出全局下界，而不仅凭“两数越悬殊乘积越小”猜测。p = 1 时显然成立。对 p ≥ 2，令 q = 2ᵖ⁻¹ − 1，故 M = 2q + 1。任何非零结果中，最低位为 0 的元素恰有 q 个，最低位为 1 的元素恰有 q + 1 个。写每个数为 x = 2t + b，b ∈ {0, 1}。各高位的 1 的数量不变，所以所有 t 的总和恒为 q(q + 1)。


由对数的凹性，对奇数有 ln(2t + 1) ≥ (t/q) ln(2q + 1)，0 ≤ t ≤ q；对偶数有 ln(2t) ≥ (t/q) ln(2q)，1 ≤ t ≤ q。第二式可在端点 t = 1、q 验证，再用凹性覆盖区间：端点 1 等价于 2ᑫ ≥ 2q，该式对整数 q ≥ 1 成立。


令 E 为所有偶数元素的 t 之和。因为有 q 个偶数且 t ≤ q，所以 E ≤ q²。于是：


ln(乘积) ≥ (E/q) ln(2q) + ((q(q+1)−E)/q) ln(2q+1)
≥ q ln(2q) + ln(2q+1)


最后一步利用 ln(2q) < ln(2q + 1)，右式随 E 增大而减小。取指数后得到乘积 ≥ (M − 1)ᑫ × M；构造正好达到它，故最优。快速幂按指数的二进制位展开，并在模环中保持乘法等价，返回的就是该最小值的余数。


边界与复杂度
  • p = 1 时 k = 0，快速幂返回 1；这里底数为 0，代码中的空乘积定义为 1，最终答案是 1。
  • p = 60 时 2ᵖ 可用 Java long、C++ long long 保存；JavaScript 必须使用 BigInt。
  • 循环次数为 O(log k) = O(p)，辅助空间为 O(1)，以固定 64 位整数 / 本题有界大整数运算为计量模型。Python 内置模幂同样需要 O(p) 级别模乘。
  • Java / C++ 中已取模的两个数相乘小于约 10¹⁸，位于有符号 64 位范围内。


Java
class Solution {
    private static final long MOD = 1_000_000_007L;

    public int minNonZeroProduct(int p) {
        long max = (1L << p) - 1;
        long exponent = (1L << (p - 1)) - 1;
        return (int) ((max % MOD) * powMod(max - 1, exponent) % MOD);
    }

    private long powMod(long base, long exponent) {
        long result = 1;
        base %= MOD;
        while (exponent > 0) {
            if ((exponent & 1) != 0) result = result * base % MOD;
            base = base * base % MOD;
            exponent >>= 1;
        }
        return result;
    }
}


JavaScript
/**
 * @param {number} p
 * @return {number}
 */
var minNonZeroProduct = function(p) {
    const MOD = 1000000007n;
    const max = (1n << BigInt(p)) - 1n;
    let exponent = (1n << BigInt(p - 1)) - 1n;
    let base = (max - 1n) % MOD;
    let result = 1n;
    while (exponent > 0n) {
        if (exponent & 1n) result = result * base % MOD;
        base = base * base % MOD;
        exponent >>= 1n;
    }
    return Number((max % MOD) * result % MOD);
};


Python
class Solution:
    def minNonZeroProduct(self, p: int) -> int:
        mod = 1_000_000_007
        maximum = (1 << p) - 1
        exponent = (1 << (p - 1)) - 1
        return (maximum % mod) * pow(maximum - 1, exponent, mod) % mod


C++
class Solution {
public:
    int minNonZeroProduct(int p) {
        const long long mod = 1000000007LL;
        long long maximum = (1LL << p) - 1;
        long long exponent = (1LL << (p - 1)) - 1;
        long long base = (maximum - 1) % mod;
        long long result = 1;
        while (exponent > 0) {
            if (exponent & 1LL) result = result * base % mod;
            base = base * base % mod;
            exponent >>= 1;
        }
        return static_cast<int>((maximum % mod) * result % mod);
    }
};


替代方案
递归快速幂可代替迭代快速幂，时间 O(p)，调用栈 O(p)。显式构造所有互补对适合小 p 的教学动画，但至少需要 O(2ᵖ) 的元素空间，不能用于 p = 60。暴力枚举位交换状态只适合极小规模研究。


常见错误
  • 把“余数最小”当作目标；取模不保持大小关系。
  • 把不同列的位互换；合法操作必须保持列位置。
  • 让元素变成 0；虽然乘积更小，却不符合非零要求。
  • 把指数写成 2ᵖ − 1，或者遗漏最后单独的 M。
  • Java / C++ 用 1 而非 1L / 1LL 左移；JavaScript 用 Number 位运算或浮点乘法处理大整数。
  • Python 使用 pow(base, exponent) 后才取模，构造无法承受的大整数；应使用三参数 pow。


面试追问
为什么不能只说保持总和、拉大差距？同位交换还保持每列 1 的数量，一般固定总和的极值未必可达，需要合法构造和全局下界。
如果模数不是质数？此实现不约简指数，也不使用逆元，快速幂仍然适用；若改用费马小定理约简指数，则需要重新检查条件。
能否输出完整操作序列？可以按互补对逐列调整，如本页演示；但输出本身可能需要 O(p · 2ᵖ) 规模，不适用于大 p。
