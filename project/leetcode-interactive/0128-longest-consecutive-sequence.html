Hash Dispatch Yard · LC 128
MEDIUM · O(n)

Unsorted arrivals / 连续轨道

最长连续序列 Longest Consecutive Sequence

数字抵达时没有顺序。把它们放进哈希货场后，只允许“左邻居不存在”的数字发车； 从这个唯一的序列起点向右铺轨，就能在不排序的前提下找到最长连续长度。

Departure rule

没有 x − 1，才从 x 发车。

若前驱已经在集合中，x 只是某条列车的中间站；跳过它，避免重复走同一段轨道。

Problem brief

先看任务，不偷看答案

给定一个未排序整数数组，返回其中最长连续元素序列的长度。元素在原数组中不必相邻， 但数值必须逐一相差 1；算法需要达到 O(n) 时间。

输入与约束

  • 0 ≤ nums.length ≤ 10⁵
  • −10⁹ ≤ nums[i] ≤ 10⁹
  • 重复数字只能占据同一个数值站点。
  • 只返回长度，不要求返回具体序列。

本题参数不含字符串；所有输入都以 nums = [...] 完整展示。页面若需表示空格，会使用可见符号 ␠。

题解

核心洞察

把所有数字放进集合。若 x − 1 存在，x 一定不是序列起点，不从它扫描； 只有前驱不存在时，才连续查询 x + 1、x + 2……。 因此每个数字最多作为某条起点扫描的一部分被访问一次。

复杂度

  • 时间：平均 O(n)，依赖哈希集合平均 O(1) 查询。
  • 空间：O(n)，集合最多保存 n 个不同数字。
  • 重复数字先由集合去重，不会重复扩展。

完整过程

  1. 用数组构建 HashSet，得到全部不同数字。
  2. 遍历集合中的每个 x；若集合含有 x − 1，直接跳过。
  3. 否则令当前长度为 1，并持续检查 x + 1、x + 2……。
  4. 每次找到后继就把当前长度加一，链断开时更新全局最大值。
  5. 遍历结束后返回最大值；空数组自然得到 0。

边界

  • 空数组：集合为空，答案为 0。
  • 只有一个元素：它没有前驱，答案为 1。
  • 含负数：连续规则不变，例如 −2 到 2 的长度是 5。
  • 全是重复值：集合只剩一个元素，答案为 1。

替代方案取舍

  • 排序后线性扫描：实现直观，但总体为 O(n log n)，不满足题目目标。
  • 并查集：可把相邻数字合并并维护集合大小，但状态更多、面试表达更重。
  • 哈希“起点扫描”最短、最容易证明平均 O(n)，因此作为主线。

面试追问

  • 为什么不会退化成 O(n²)？因为只从序列唯一的最小值启动扫描。
  • 若要求返回序列？在更新 best 时同时记录 bestStart，最后构造结果。
  • 若数据流不断到达？可用边界长度哈希表动态合并左右区间。

常见错误

  • 从每个数字都向右扫描，最坏会重复遍历成长链。
  • 遍历原数组时忘记处理重复值，增加无效判断。
  • 把“数组中相邻”误认为“数值连续”。
  • 排序后仍宣称 O(n)，忽略排序成本。

四语言可提交代码

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> values = new HashSet<>();
        for (int num : nums) {
            values.add(num);
        }

        int best = 0;
        for (int num : values) {
            if (values.contains(num - 1)) {
                continue;
            }

            int current = num;
            int length = 1;
            while (values.contains(current + 1)) {
                current++;
                length++;
            }
            best = Math.max(best, length);
        }
        return best;
    }
}
