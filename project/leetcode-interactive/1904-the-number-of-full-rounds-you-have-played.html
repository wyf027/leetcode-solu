你完成的完整对局数

The Number of Full Rounds You Have Played

每隔一刻钟开局，你在线时完整参与了多少场？

题意与约束

每天从 00:00 起，每 15 分钟开启一场持续 15 分钟的对局。给定进入时间 loginTime 与退出时间 logoutTime，返回从开局到结束都处于在线区间内的对局数。恰好在开局时进入、结束时退出，也算完整参与。

退出时刻早于进入时刻意味着退出发生在次日。两个参数均为 HH:MM 格式的字符串，00 ≤ HH ≤ 23，00 ≤ MM ≤ 59，且两个时间不相等。中文元数据使用 startTime、finishTime，代码采用官方签名 loginTime、logoutTime。

官方英文示例

loginTime = "09:31", logoutTime = "10:14"
输出：1
完整对局：09:45–10:00。
loginTime = "21:30", logoutTime = "03:00"
输出：22
午夜前 10 局，午夜后 12 局。

官方中文示例

startTime = "12:01", finishTime = "12:44"
输出：1（12:15–12:30）
startTime = "20:00", finishTime = "06:00"
输出：40（16 + 24）
startTime = "00:00", finishTime = "23:59"
输出：95（最后一局未完整参与）

题解：对齐刻钟边界

核心洞察与完整过程

  1. 把时间转成分钟数 s、e。
  2. 若 e < s，给 e 加 1440，展开跨午夜区间。
  3. 最早合法开局为 A = ceil(s/15) × 15。
  4. 最晚合法结束为 B = floor(e/15) × 15。
  5. 返回 max(0, (B−A)/15)。

09:31 对应 571 分钟，10:14 对应 614 分钟。对齐后 A=585，B=600，只含 1 局。21:30 至次日 03:00 展开为 1290 至 1620，完整覆盖 22 局。

正确性

完整对局必须在进入之后开始，所以开局不早于 A；必须在退出之前结束，所以结束不晚于 B。反过来，A 到 B 间的每个相邻刻钟区间都完全在线，因而合法。这些区间恰好包含所有完整对局，数量为 (B−A)/15。若 B 小于 A，则没有合法对局，答案取 0。

边界与常见错误

  • 12:01 至 12:14：边界反向，必须截断为 0。
  • 12:00 至 12:15：两端对齐，答案为 1。
  • 23:50 至 00:10：跨日但不足以覆盖完整局，答案为 0。
  • 不能直接用在线时长除以 15：00:01 至 00:16 虽有 15 分钟，仍没有完整局。
  • 先用原始时间判断跨午夜，再取整，避免把短区间误判为跨日。
  • 相等时间不在输入范围，不应自行解释为一整天。

复杂度与替代方案

固定长度字符串解析和算术均为 O(1) 时间、O(1) 额外空间。替代方案是枚举各刻钟区间，检查开始 ≥ s 且结束 ≤ e；一般化为 R 个区间时为 O(R)，本题时间跨度有固定上界。观察台采用枚举展示机制。

面试追问

每局 k 分钟、起点偏移 t₀ 时，可对 s−t₀、e−t₀ 作相同取整。跨多天需要日期信息。多段在线区间应先合并重叠和相接区间，再统计，避免重复计数。

Java

class Solution {
    private int minutes(String t) {
        return Integer.parseInt(t.substring(0, 2)) * 60
             + Integer.parseInt(t.substring(3));
    }
    public int numberOfRounds(String loginTime, String logoutTime) {
        int s = minutes(loginTime), e = minutes(logoutTime);
        if (e < s) e += 1440;
        return Math.max(0, e / 15 - (s + 14) / 15);
    }
}

JavaScript

var numberOfRounds = function(loginTime, logoutTime) {
    const minutes = t => Number(t.slice(0, 2)) * 60 + Number(t.slice(3));
    const s = minutes(loginTime);
    let e = minutes(logoutTime);
    if (e < s) e += 1440;
    return Math.max(0, Math.floor(e / 15) - Math.ceil(s / 15));
};

class Solution:
    def numberOfRounds(self, loginTime: str, logoutTime: str) -> int:

        if e < s:
            e += 1440
