IP 地址无效化

Defanging an IP Address · 用方括号安全包裹每个句点。

Problem

题目

给定有效 IPv4 地址字符串 address，返回它的无效化版本：将每个 . 替换成 [.]，其余字符与顺序保持不变。

函数形式
defangIPaddr(address: string) → string

约束

  • address 是有效 IPv4 地址。
  • 它包含四个数字段和三个句点。

Examples

官方示例

示例 1
输入：address = "1.1.1.1"
输出："1[.]1[.]1[.]1"

示例 2
输入：address = "255.100.50.0"
输出："255[.]100[.]50[.]0"

Solution vault

独立题解

题解：一次线性扫描

核心洞察与过程

无需解析 IP，只需确定性字符替换。创建结果缓冲区，从左至右扫描；遇到句点追加 [.]，否则追加原字符，最后返回结果。

正确性

处理完前 i 个字符时，缓冲区恰是此前缀的无效化结果。下一字符若是点就按定义追加 [.]，否则原样追加，因此不变式成立；扫描结束即得到完整答案。

边界与复杂度

零值段和三位数字段都无需特判。时间复杂度 O(n)，结果空间 O(n)。

替代方案

可用全局替换，或按点分割后以 [.] 连接。手动扫描更清楚，也避开某些语言只替换首个匹配的 API 差异。

四语言完整代码

Java
class Solution {
    public String defangIPaddr(String address) {
        StringBuilder r = new StringBuilder();
        for (char c : address.toCharArray())
            r.append(c == '.' ? "[.]" : c);
        return r.toString();
    }
}
JavaScript
/**
 * @param {string} address
 * @return {string}
 */
var defangIPaddr = function(address) {
    let result = "";
    for (const ch of address)
        result += ch === "." ? "[.]" : ch;
    return result;
};
Python 3
class Solution:
    def defangIPaddr(self, address: str) -> str:
        result = []
        for ch in address:
            result.append("[.]" if ch == "." else ch)
        return "".join(result)
C++
class Solution {
public:
    string defangIPaddr(string address) {
        string result;
        for (char ch : address)
            result += ch == '.' ? "[.]" : string(1, ch);
        return result;
    }
};
