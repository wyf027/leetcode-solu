LEETCODE 741摘樱桃Cherry Pickup

在布满樱桃与荆棘的方格田里，完成一次从左上到右下的旅程，再安全返回。每颗樱桃只能被摘一次——你的目标是让两段路线的总收获最大。

先理解规则与路线实验；完整解法不会在首屏泄露。

Round trip 去程与返程
共享同一片樱桃地

可通行：0 / 1
不可通行：−1
目标：最大化不重复收获

01 · Problem

题意与规则

从原题规则出发，先把输入、移动方向和“樱桃只能摘一次”这三件事钉牢。

给定一个 n × n 整数网格 grid。先从 (0, 0) 出发，只能向右或向下走到 (n − 1, n − 1)；再从终点只向左或向上返回起点。

经过值为 1 的格子会摘走其中的樱桃，之后该格变为 0。两段路都不能经过荆棘。返回整个往返过程中最多能摘到的樱桃数；若起终点间没有有效路径，返回 0。

格子含义

  • 0空地
    可以通过，没有樱桃。
  • 1樱桃
    通过时收获一次，然后变为空地。
  • −1荆棘
    不可进入，必须绕开。
02 · Examples

官方示例

参数名、完整网格和返回值均按官方元数据呈现。

示例 1 · 可完成往返

输入：grid = [[0,1,-1],
              [1,0,-1],
              [1,1,1]]
输出：5

一条路线沿左边缘和底边到终点，可先摘 4 颗；返程再覆盖顶部尚未摘取的 1 颗，总计 5 颗。

示例 2 · 不存在有效路径

输入：grid = [[1,1,-1],
              [1,-1,1],
              [-1,1,1]]
输出：0

荆棘切断了从起点到终点的所有单调路径，因此无法完成行程，结果为 0。

03 · Limits

约束

方阵最大边长为 50，状态设计需要避免枚举两条完整路径。

  • →n == grid.length
  • →n == grid[i].length
  • →1 ≤ n ≤ 50
  • →grid[i][j] ∈ {-1, 0, 1}
  • →grid[0][0] != -1
  • →grid[n - 1][n - 1] != -1

06 · Solution

同步双人动态规划

把一次往返变成两条同时从起点走向终点的单调路径，再按共同步数推进。

核心洞察

  1. 反转返程。原返程只向左或上；把它倒过来看，就是另一条从起点只向右或下走到终点的路径。
  2. 同步两条路径。两名行者都走了 k 步时，各自满足 row + col = k，所以列坐标能由步数与行坐标推出。
  3. 同格只计一次。若两人在同一步站到同一格，那颗樱桃只加入一次；否则分别加入两格的值。

状态与完整过程

令 dp[r1][r2] 表示完成当前步数 k 后，行者 A 位于 (r1, k-r1)、行者 B 位于 (r2, k-r2) 时，已收获的最大樱桃数。不可达状态记为负无穷。

  1. 初始化 dp[0][0] = grid[0][0]。
  2. 依次枚举 k = 1 ... 2n-2，仅枚举坐标仍在网格内的 r1 与 r2。
  3. 跳过任一当前位置是荆棘的状态。
  4. 两人上一步各有两种来源：本步向右意味着行号不变，本步向下意味着行号增加 1。因此，从四种前驱组合中取最大值。
  5. 加上当前位置的樱桃；若两人同格，只加一次。用新层替换旧层。
  6. 最终状态若不可达则返回 0，否则返回终点状态值。
next[r1][r2] = max(dp[r1][r2], dp[r1-1][r2], dp[r1][r2-1], dp[r1-1][r2-1]) + gain

正确性证明

引理 1：往返方案与两条起点到终点的单调路径一一对应

把任意合法返程的移动顺序倒置，并将左、上分别反向为右、下，就得到一条合法的起点到终点路径；反向操作也能还原返程。因此优化往返总收获，等价于优化两条单调路径覆盖的不同樱桃格数量。

引理 2：状态转移枚举了当前状态的所有可能前驱

每名行者本步只可能向右或向下。到达当前行号 r 时，其上一步行号只可能是 r 或 r-1。两人选择两两组合，恰好得到转移式中的四种前驱，没有遗漏也没有额外情况。

引理 3：每个状态的收益计数准确

两人当前位置不同时，两格樱桃都应计入；当前位置相同时，该格在真实往返中只能摘一次，转移只加一次。此前步数的最优收益由归纳假设保存在前驱状态中，因此当前状态也得到准确最大值。

定理

由引理 1，所有合法往返方案都被两条同步路径表示；由引理 2 和 3，动态规划在每一层完整且准确地保留最大收益。最终 dp[n-1][n-1] 因而是最多可摘樱桃数；不可达时返回 0。算法正确。

边界情况

  • 单格网格：两人始终同格，起点樱桃只计算一次。
  • 无有效路径：所有终点状态保持负无穷，返回 0。
  • 两路频繁重合：每一层都检查坐标是否完全相同，避免重复计数。
  • 零值格与边界路径：零值不增加收益；行范围随步数收缩，避免越界。

复杂度

共有 2n-1 个步数层，每层最多枚举 n² 对行坐标，每个状态检查 4 个前驱，因此时间复杂度为 O(n³)。滚动数组只保留前后两层，空间复杂度为 O(n²)。

替代方案

  • 三维 DP：显式保存 dp[k][r1][r2]，逻辑更直观，但空间为 O(n³)。
  • 记忆化搜索：使用 dfs(r1,c1,r2)，由共同步数推出 c2；复杂度同阶，但递归与无效状态处理更重。
  • 先贪心走一条再走第二条：不正确。第一条局部最优路线可能占用关键樱桃，破坏两条路线的全局最优组合。

Java 官方签名：cherryPickup(int[][] grid)
import java.util.Arrays;

class Solution {
    public int cherryPickup(int[][] grid) {
        int n = grid.length;
        int neg = -1_000_000_000;
        int[][] dp = new int[n][n];
        for (int[] row : dp) Arrays.fill(row, neg);
        dp[0][0] = grid[0][0];

        for (int k = 1; k <= 2 * n - 2; k++) {
            int[][] next = new int[n][n];
            for (int[] row : next) Arrays.fill(row, neg);
            int low = Math.max(0, k - (n - 1));
            int high = Math.min(n - 1, k);

            for (int r1 = low; r1 <= high; r1++) {
                int c1 = k - r1;
                if (grid[r1][c1] == -1) continue;
                for (int r2 = low; r2 <= high; r2++) {
                    int c2 = k - r2;
                    if (grid[r2][c2] == -1) continue;

                    int best = dp[r1][r2];
                    if (r1 > 0) best = Math.max(best, dp[r1 - 1][r2]);
                    if (r2 > 0) best = Math.max(best, dp[r1][r2 - 1]);
                    if (r1 > 0 && r2 > 0) {
                        best = Math.max(best, dp[r1 - 1][r2 - 1]);
                    }
                    if (best == neg) continue;

                    int gain = grid[r1][c1];
                    if (r1 != r2 || c1 != c2) gain += grid[r2][c2];
                    next[r1][r2] = best + gain;
                }
            }
            dp = next;
        }
        return Math.max(0, dp[n - 1][n - 1]);
    }
}

var cherryPickup = function(grid) {
    const n = grid.length;
    const NEG = Number.NEGATIVE_INFINITY;
    let dp = Array.from({ length: n }, () => Array(n).fill(NEG));
    dp[0][0] = grid[0][0];

        for (let r1 = low; r1 <= high; r1++) {
            const c1 = k - r1;
            if (grid[r1][c1] === -1) continue;
            for (let r2 = low; r2 <= high; r2++) {
                const c2 = k - r2;
                if (grid[r2][c2] === -1) continue;

                let best = dp[r1][r2];
                if (r1 > 0) best = Math.max(best, dp[r1 - 1][r2]);
                if (r2 > 0) best = Math.max(best, dp[r1][r2 - 1]);
                if (r1 > 0 && r2 > 0) {
                    best = Math.max(best, dp[r1 - 1][r2 - 1]);

                let gain = grid[r1][c1];
                if (r1 !== r2 || c1 !== c2) gain += grid[r2][c2];
                next[r1][r2] = best + gain;
            }
        }
        dp = next;
    }
    return Math.max(0, dp[n - 1][n - 1]);

Python 官方签名：cherryPickup(self, grid)
from typing import List


class Solution:
    def cherryPickup(self, grid: List[List[int]]) -> int:
        n = len(grid)
        neg = float("-inf")
        dp = [[neg] * n for _ in range(n)]
        dp[0][0] = grid[0][0]

        for k in range(1, 2 * n - 1):
            nxt = [[neg] * n for _ in range(n)]
            low = max(0, k - (n - 1))
            high = min(n - 1, k)

            for r1 in range(low, high + 1):
                c1 = k - r1
                if grid[r1][c1] == -1:
                    continue
                for r2 in range(low, high + 1):
                    c2 = k - r2
                    if grid[r2][c2] == -1:
                        continue

                    best = dp[r1][r2]
                    if r1 > 0:
                        best = max(best, dp[r1 - 1][r2])
                    if r2 > 0:
                        best = max(best, dp[r1][r2 - 1])
                    if r1 > 0 and r2 > 0:
                        best = max(best, dp[r1 - 1][r2 - 1])
                    if best == neg:
                        continue

                    gain = grid[r1][c1]
                    if (r1, c1) != (r2, c2):
                        gain += grid[r2][c2]
                    nxt[r1][r2] = best + gain
            dp = nxt

        return max(0, dp[n - 1][n - 1])
C++ 官方签名：cherryPickup(vector<vector<int>>& grid)
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int cherryPickup(vector<vector<int>>& grid) {
        int n = static_cast<int>(grid.size());
        const int NEG = -1000000000;
        vector<vector<int>> dp(n, vector<int>(n, NEG));
        dp[0][0] = grid[0][0];

        for (int k = 1; k <= 2 * n - 2; ++k) {
            vector<vector<int>> next(n, vector<int>(n, NEG));
            int low = max(0, k - (n - 1));
            int high = min(n - 1, k);

            for (int r1 = low; r1 <= high; ++r1) {
                int c1 = k - r1;
                if (grid[r1][c1] == -1) continue;
                for (int r2 = low; r2 <= high; ++r2) {
                    int c2 = k - r2;
                    if (grid[r2][c2] == -1) continue;

                    int best = dp[r1][r2];
                    if (r1 > 0) best = max(best, dp[r1 - 1][r2]);
                    if (r2 > 0) best = max(best, dp[r1][r2 - 1]);
                    if (r1 > 0 && r2 > 0) {
                        best = max(best, dp[r1 - 1][r2 - 1]);
                    }
                    if (best == NEG) continue;

                    int gain = grid[r1][c1];
                    if (r1 != r2 || c1 != c2) gain += grid[r2][c2];
                    next[r1][r2] = best + gain;
                }
            }
            dp.swap(next);
        }
        return max(0, dp[n - 1][n - 1]);
    }
};

面试追问

为什么不能分别求两次最优路径？第一次选择会改变第二次可获得的樱桃，两条路线必须联合优化；局部最优不保证覆盖集合的全局最优。
为什么只保存两名行者的行坐标？同一步 k 下，列坐标恒为 k-row，无需再做独立维度。
能否原地更新 dp？不建议。当前层依赖完整上一层，原地写入可能把本层新值误当作前驱；滚动的两个二维数组更安全。
如果格子权值不只 0/1 呢？只要同一格仍只能计一次，转移与证明不变；需要把负无穷设置得足够小，避免与合法负收益混淆。

常见错误

  • 两人同格时把该格樱桃加了两次。
  • 只判断坐标边界，却忘记跳过值为 -1 的荆棘。
  • 把“不可达”初始化成 0，导致不存在的路径参与最大值比较。
  • 步数循环少走或多走一层；终点对应的步数恰为 2n-2。
  • 直接模拟去程后修改网格再求返程，错误地把两次路线选择拆开。
