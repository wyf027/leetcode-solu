最小的仅由两个数组成的倍数

Smallest Greater Multiple Made of Two Digits

两枚数字，三个条件。找到符合规则的最小整数。

01 / 题目任务

什么样的数，才符合要求？

给定三个整数 k、digit1、digit2，返回同时满足以下条件的最小整数 x：

  1. x > k，必须严格大于。
  2. x % k = 0，是 k 的倍数。
  3. 十进制的每一位都属于 {digit1, digit2}。

允许只用其中一种数字，两种数字也可以相同。使用正常十进制表示，不保留前导零。若不存在这样的数，或最小答案超过 2³¹ − 1 = 2147483647，返回 -1。

接口与约束

findInteger(k, digit1, digit2) → integer

  • 1 ≤ k ≤ 1000
  • 0 ≤ digit1 ≤ 9
  • 0 ≤ digit2 ≤ 9

02 / 官方示例

完整参数，逐一理解

示例 1

k = 2, digit1 = 0, digit2 = 2

输出：20

2 本身不符合严格大于；20 是最小合法倍数。

示例 2

k = 3, digit1 = 4, digit2 = 2

输出：24

24 只使用 2、4，且是大于 3 的最小合法倍数。

示例 3

k = 2, digit1 = 0, digit2 = 0

输出：-1

仅用 0 无法组成大于 2 的整数。

核心洞察：构造候选，而非扫描倍数

答案最多 10 位，每位最多两种选择。将允许数字排序去重，从非零的一位数出发，每次在末尾追加一个允许数字。用队列逐层访问，就能按数值从小到大遍历候选；第一个满足严格大于 k 且可整除 k 的候选就是答案。

状态是完整整数 x，转移为 x → 10x+d。只把不超过 2147483647 的子节点入队。

完整过程

  1. 排序去重，将非零的一位数按升序入队。
  2. 取出队首 x，检查 x > k && x % k == 0，满足就返回。
  3. 不满足则依次构造 10x+d，仅将界内子节点入队。
  4. 重复以上过程；队列耗尽则返回 -1。

示例 2 的队首依次为 2、4、22、24。处理 2 生成 22、24；处理 4 生成 42、44；处理 22 生成 222、224；取出 24 时命中。22 不能被 3 整除，因此不能提前返回。

正确性

合法且完整：非零起点加合法末位保证每个候选有效。任一界内合法正整数，都能沿自己的十进制数字从首位构造出来；前缀不超过完整数，因此不会被上限剪枝误删。

数值递增：FIFO 先访问较短位数。同位数父节点递增，每组孩子按末位升序生成；对于 x<y，有 10x+9 < 10y，前一父节点的全部孩子都小于后一父节点的孩子。过滤超界项也不破坏顺序。

最优且终止：首次命中之前的所有候选均不符合条件，所以返回值最小。候选最多 10 位，构造树有限；耗尽代表所有界内候选已被排除，-1 正确。

边界与常见错误

  • 严格大于：x=k 不可返回，例如 k=1、两数字均为 1，答案是 11。
  • 两数字为零：队列初始为空，返回 -1；不要让 0 反复生成自己。
  • 数字相同：先去重，避免重复构造。无需额外的数值 visited 集合。
  • 输入无序：先排序，不能按输入 4、2 的顺序直接搜索并返回首个答案。
  • 只用一种也合法：题目并不要求两种数字各出现一次。
  • 溢出：Java 使用 long、C++ 使用 long long 构造子节点，再比较 32 位上限；JS 不使用位运算强转。
  • 不要仅按余数去重：k=1、digits={1} 时，1 与 11 余数相同，但只有后者严格大于 k，直接合并会丢失答案。

复杂度与替代方案

令 L 为上限的位数，本题 L=10。候选数不超过 2¹+…+2ᴸ=2046；每个候选最多两次转移，时间 O(2ᴸ)，队列空间 O(2ᴸ)。这里整数运算按固定宽度 O(1) 计。只有一个有效数字时，候选规模是 O(L)。JS 的数组加 head 会保留已访问项，仍满足上述空间上界。

DFS：也能枚举全部候选并维护最小值，时间同阶，递归栈 O(L)。但普通 DFS 不能直接返回第一次命中。

扫描倍数：从 2k 开始不断加 k 并检查数字，时间约 O((M/k)·L)，M 为上限，最坏远高于构造法。

Java

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int findInteger(int k, int digit1, int digit2) {
        int a = Math.min(digit1, digit2);
        int b = Math.max(digit1, digit2);
        int[] digits = a == b ? new int[]{a} : new int[]{a, b};
        Deque<Long> q = new ArrayDeque<>();
        for (int d : digits) if (d != 0) q.addLast((long) d);
        while (!q.isEmpty()) {
            long x = q.removeFirst();
            if (x > k && x % k == 0) return (int) x;
            for (int d : digits) {
                long next = x * 10 + d;
                if (next <= Integer.MAX_VALUE) q.addLast(next);
            }
        }
        return -1;
    }
}

JavaScript

/**
 * @param {number} k
 * @param {number} digit1
 * @param {number} digit2
 * @return {number}
 */
var findInteger = function(k, digit1, digit2) {
    const digits = [...new Set([digit1, digit2])].sort((a, b) => a - b);
    const q = digits.filter(d => d !== 0);
    for (let head = 0; head < q.length; head++) {
        const x = q[head];
        if (x > k && x % k === 0) return x;
        for (const d of digits) {
            const next = x * 10 + d;
            if (next <= 2147483647) q.push(next);
        }
    }
    return -1;
};

Python

from collections import deque

class Solution:
    def findInteger(self, k: int, digit1: int, digit2: int) -> int:
        digits = sorted({digit1, digit2})
        q = deque(d for d in digits if d != 0)
        while q:
            x = q.popleft()
            if x > k and x % k == 0:
                return x
            for d in digits:
                nxt = x * 10 + d
                if nxt <= 2**31 - 1:
                    q.append(nxt)
        return -1

C++

#include <algorithm>
#include <climits>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    int findInteger(int k, int digit1, int digit2) {
        vector<int> digits{digit1, digit2};
        sort(digits.begin(), digits.end());
        digits.erase(unique(digits.begin(), digits.end()), digits.end());
        queue<long long> q;
        for (int d : digits) if (d != 0) q.push(d);
        while (!q.empty()) {
            long long x = q.front();
            q.pop();
            if (x > k && x % k == 0) return static_cast<int>(x);
            for (int d : digits) {
                long long next = x * 10 + d;
                if (next <= INT_MAX) q.push(next);
            }
        }
        return -1;
    }
};

面试追问

  • 为何不用最小堆？排序后的数字构造加 FIFO 已保证升序，普通队列就够。
  • 上限改为 100 位呢？枚举指数增长，需要按位构建并维护模 k 状态、长度及与下界的大小关系，再重建最小答案。
  • 要求两种数字都出现呢？附带数字出现情况的位掩码，命中时再检查；两数字相同时需要先明确语义。
  • 为什么余数状态不足？相同余数的数可能处于 k 的不同侧，合并状态必须保留严格大于下界所需的信息。
