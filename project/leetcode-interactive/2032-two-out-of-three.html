至少在两个数组中出现的值

Two Out of Three

三个数组，一份不重复的名单。先理解任务，再探索每个值的来源。

阅读示例 ↓

01 / 题目

给定三个整数数组 nums1、nums2、nums3，找出在其中至少两个不同数组中出现的所有整数，返回一个不含重复值的数组。返回顺序不限。

注意区分“出现次数”和“出现在哪几个数组”：同一个数组中的重复值不代表它出现在两个数组里。

约束

  • 1 ≤ nums1.length, nums2.length, nums3.length ≤ 100
  • 1 ≤ nums1[i], nums2[j], nums3[k] ≤ 100

02 / 官方示例

示例 1

输入：nums1 = [1,1,3,2], nums2 = [2,3], nums3 = [3]
输出：[3,2]

3 出现在三个数组中；2 出现在 nums1 和 nums2 中。

示例 2

输入：nums1 = [3,1], nums2 = [2,3], nums3 = [1,2]
输出：[2,3,1]

1、2、3 都分别出现在两个数组中。

示例 3

输入：nums1 = [1,2,2], nums2 = [4,3,3], nums3 = [5]
输出：[]

没有值出现在两个不同数组中。

05 / 独立题解

准备好后再展开，查看推导与四种语言实现。

核心洞察：统计来源，不统计总次数

为每个值保存三个布尔标记，分别表示它是否出现在 nums1、nums2、nums3 中。将当前数组对应的位置设为 true；重复赋值不改变已有标记。最终来源数量至少为 2 的值就是答案。

完整过程

  1. 初始化 seen[101][3]，全部为 false。索引 0 不使用。
  2. 依次扫描三个数组。读取数组 i 中的 x 时，设置 seen[x][i] = true。
  3. 枚举 1 到 100，统计每个值的三个 true 标记。
  4. 若数量至少为 2，则将值加入答案一次。

示例 1 中，重复的 1 只获得 nums1 印章；2 获得前两个数组的印章；3 获得全部三个印章。枚举值域得到 [2,3]，与官方 [3,2] 等价。

正确性证明

不变式：扫描任意前缀后，seen[x][i] 为 true 当且仅当已扫描的第 i 个数组部分出现过 x。初始没有元素，标记全为 false；每次仅将当前元素与数组对应的标记设为 true，故不变式保持，且同组重复不会多算。

扫描结束后，三个标记的和恰好等于 x 出现的不同数组数。筛选和至少为 2 的值，因此所有加入的值都满足条件，所有满足条件的值也都被加入。每个值只枚举一次，所以结果无重复。

边界与复杂度

同一数组内重复任意次只算一个来源；三组都有的值只加入一次；没有交集时返回空数组。合法输入没有空数组，值 1 和 100 都必须纳入枚举。

设 N 为三个数组的总长度，U 为值域大小（本题 100）。时间 O(N + U)，辅助空间 O(U)，输出最多 O(U)。固定 U = 100 时可表述为时间 O(N)、辅助空间 O(1)。

替代方案

  • 三个集合：求 (A∩B)∪(A∩C)∪(B∩C)，自然去重，适合无固定值域；哈希实现期望 O(N) 时间、O(N) 空间。
  • 逐组去重再计数：每组先构造 Set，每个不同值只对全局计数加一。
  • 位掩码：三个来源分别用 1、2、4，读到值就按位 OR。非零 mask 满足 (mask & (mask - 1)) != 0 表示至少两个二进制位为 1。

常见错误

  • 直接累计原数组所有出现次数，会把同组重复误判成多来源。
  • 仅取三个集合的共同交集，会漏掉恰好出现在两组中的值。
  • 拼接两两交集却不去重，会重复输出三组共有的元素。
  • 用“等于 2”筛选，会遗漏在全部三个数组中出现的值。

面试追问

推广到 k 个数组、至少 t 组？ 每组去重后累计来源数，最后筛选计数 ≥ t。若 k 较小也可以使用位掩码。

值域无限或含负数？ 用 Map 替代按值索引的固定数组。

能在扫描时提前输出吗？ 可以在某值第一次获得第二种来源时加入答案，仍要记录来源状态，防止第三组或重复元素再次输出。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> twoOutOfThree(int[] nums1, int[] nums2, int[] nums3) {
        boolean[][] seen = new boolean[101][3];
        int[][] arrays = {nums1, nums2, nums3};
        for (int i = 0; i < 3; i++) {
            for (int x : arrays[i]) seen[x][i] = true;
        }
        List<Integer> answer = new ArrayList<>();
        for (int x = 1; x <= 100; x++) {
            int count = 0;
            for (int i = 0; i < 3; i++) if (seen[x][i]) count++;
            if (count >= 2) answer.add(x);
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number[]} nums1
 * @param {number[]} nums2
 * @param {number[]} nums3
 * @return {number[]}
 */
var twoOutOfThree = function(nums1, nums2, nums3) {
    const seen = Array.from({ length: 101 }, () => [false, false, false]);
    [nums1, nums2, nums3].forEach((nums, i) => {
        for (const x of nums) seen[x][i] = true;
    });
    const answer = [];
    for (let x = 1; x <= 100; x++) {
        const count = seen[x].reduce((sum, flag) => sum + Number(flag), 0);
        if (count >= 2) answer.push(x);
    }
    return answer;
};

Python 3

from typing import List

class Solution:
    def twoOutOfThree(self, nums1: List[int], nums2: List[int],
                      nums3: List[int]) -> List[int]:
        seen = [[False] * 3 for _ in range(101)]
        for i, nums in enumerate((nums1, nums2, nums3)):
            for x in nums:
                seen[x][i] = True
        return [x for x in range(1, 101) if sum(seen[x]) >= 2]

C++

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> twoOutOfThree(vector<int>& nums1, vector<int>& nums2,
                              vector<int>& nums3) {
        bool seen[101][3] = {};
        const vector<int>* arrays[] = {&nums1, &nums2, &nums3};
        for (int i = 0; i < 3; ++i)
            for (int x : *arrays[i]) seen[x][i] = true;
        vector<int> answer;
        for (int x = 1; x <= 100; ++x) {
            int count = seen[x][0] + seen[x][1] + seen[x][2];
            if (count >= 2) answer.push_back(x);
        }
        return answer;
    }
};
