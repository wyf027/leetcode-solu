没有卖出的卖家Sellers With No Sales

从卖家全集出发，找出在指定自然年里没有产生任何订单的人。重点不是“谁卖得少”，而是判断目标时间段内是否存在关联记录。

题目说明

保留完整输入结构，同时把判断条件压缩成一句话：目标是 2020 年“零销售”。

给定 Customer、Orders 和 Seller 三张表。请查询所有在 2020 年内没有任何销售订单 的卖家姓名，结果顺序不限。

准备好核对思路了吗？

题解、证明、复杂度和完整代码都收在这里，不影响你先独立思考。

题解

把“没有”翻译为不存在性判断，是这道反连接题的关键。

核心洞察

对每个卖家询问：是否不存在一条属于该卖家、且日期落在 2020 年的订单？这正对应相关子查询 NOT EXISTS。年份用半开区间表达，既清楚又避免对日期列套函数。

完整过程

  1. 从 Seller 逐个枚举卖家。
  2. 在 Orders 中按 seller_id 关联。
  3. 只检查日期在 2020-01-01（含）至 2021-01-01（不含）的订单。
  4. 若一条都找不到，保留该卖家姓名。

正确性证明

充分性：若查询返回卖家 S，则相关子查询没有找到 S 的 2020 年订单，所以 S 在 2020 年没有销售。
必要性：若 S 在 2020 年没有销售，则不存在同时满足卖家关联和日期区间的订单，NOT EXISTS 为真，S 必被返回。因此结果恰好是题目要求的卖家集合。

边界情况

  • 从未产生任何订单的卖家应被返回。
  • 只有 2019 或 2021 年订单的卖家仍应被返回。
  • 2020-01-01 和 2020-12-31 的订单都属于目标年。
  • 同一卖家有多条 2020 年订单也只需判定“存在”。

复杂度

设卖家数为 S、订单数为 O。逻辑层面需要检查两表关系；数据库若在 Orders(seller_id, sale_date) 上有合适索引，可高效完成存在性查找。结果额外空间通常为 O(S)，具体执行代价由优化器与索引决定。

替代方案

也可先过滤出 2020 年订单，再对 Seller 做 LEFT JOIN，最后筛选连接结果为 NULL；或用 NOT IN。其中 NOT EXISTS 对 NULL 语义更稳健，也更直接表达“没有”。

面试追问

  • 为什么不用 YEAR(sale_date)=2020？——可能妨碍普通日期索引的范围扫描。
  • 若要查询任意年份？——把起止日期参数化。
  • 若要求零销售额而非零订单？——要明确退款、负数订单和聚合口径。

常见错误

  • 先内连接 Orders，会丢掉从未下单的卖家。
  • 只排除某一条订单，没有按卖家判断整个年份。
  • 用 NOT IN 却忽略子查询 NULL 的三值逻辑。
  • 日期上界写成 2020-12-31 但字段含时间时漏掉当天数据。

官方提交语言：SQL

SELECT s.seller_name
FROM Seller AS s
WHERE NOT EXISTS (
    SELECT 1
    FROM Orders AS o
    WHERE o.seller_id = s.seller_id
      AND o.sale_date >= '2020-01-01'
      AND o.sale_date <  '2021-01-01'
);

Java 17 · 本地语义参考O(S + O)
import java.time.LocalDate;
import java.util.*;

public class Solution {
    record Seller(int id, String name) {}
    record Order(int sellerId, LocalDate saleDate) {}

    public static List<String> sellersWithNoSales(
            List<Seller> sellers, List<Order> orders) {
        LocalDate start = LocalDate.of(2020, 1, 1);
        LocalDate end = LocalDate.of(2021, 1, 1);
        Set<Integer> active = new HashSet<>();
        for (Order order : orders) {
            if (!order.saleDate().isBefore(start)
                    && order.saleDate().isBefore(end)) {
                active.add(order.sellerId());
            }
        }
        List<String> answer = new ArrayList<>();
        for (Seller seller : sellers) {
            if (!active.contains(seller.id())) answer.add(seller.name());
        }
        return answer;
    }
}
JavaScript · 本地语义参考O(S + O)
/**
 * @param {{seller_id:number, seller_name:string}[]} sellers
 * @param {{seller_id:number, sale_date:string}[]} orders
 * @return {string[]}
 */
function sellersWithNoSales(sellers, orders) {
  const start = "2020-01-01";
  const end = "2021-01-01";
  const active = new Set();

  for (const order of orders) {
    if (order.sale_date >= start && order.sale_date < end) {
      active.add(order.seller_id);
    }
  }

  return sellers
    .filter((seller) => !active.has(seller.seller_id))
    .map((seller) => seller.seller_name);
}
Python 3 · 本地语义参考O(S + O)
from dataclasses import dataclass
from datetime import date

@dataclass(frozen=True)
class Seller:
    seller_id: int
    seller_name: str

@dataclass(frozen=True)
class Order:
    seller_id: int
    sale_date: date

def sellers_with_no_sales(
    sellers: list[Seller], orders: list[Order]
) -> list[str]:
    start, end = date(2020, 1, 1), date(2021, 1, 1)
    active = {
        order.seller_id
        for order in orders
        if start <= order.sale_date < end
    }
    return [
        seller.seller_name
        for seller in sellers
        if seller.seller_id not in active
    ]
C++17 · 本地语义参考O(S + O)
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

struct Seller { int sellerId; string sellerName; };
struct Order { int sellerId; string saleDate; };

vector<string> sellersWithNoSales(
    const vector<Seller>& sellers,
    const vector<Order>& orders
) {
    unordered_set<int> active;
    for (const Order& order : orders) {
        if (order.saleDate >= "2020-01-01"
            && order.saleDate < "2021-01-01") {
            active.insert(order.sellerId);
        }
    }
    vector<string> answer;
    for (const Seller& seller : sellers) {
        if (!active.count(seller.sellerId)) {
            answer.push_back(seller.sellerName);
        }
    }
    return answer;
}
