仓库经理Warehouse Manager

两张表记录了“仓库里有多少件商品”和“每件商品有多大”。你的任务是整理出每个仓库实际占用的总体积。

EASY 数据库 付费题 聚合统计
01 / Brief

任务说明

仓库库存记录只给出商品数量；商品尺寸记录则给出每件商品的宽、长、高。请编写查询，报告每个仓库中所有库存商品的总体积，结果顺序不限。

输入关系

Warehouse 的每行说明某仓库存放某商品的件数；Products 的每行说明某商品的三维尺寸。

输出关系

每个仓库输出一行：仓库名 warehouse_name 与库存总体积 volume。

关系约束

  • (name, product_id) 是 Warehouse 的主键；同一仓库与商品组合只出现一次。
  • product_id 是 Products 的主键；库存表中的商品编号可与商品表对应。
  • units 表示库存商品件数；Width、Length、Height 表示单件商品的三维尺寸。
  • 体积结果按题目给定的尺寸单位计算；每个仓库只输出一行，行顺序不作要求。

核心洞察

一条库存记录自身没有尺寸，一条商品记录自身没有仓库与件数。先用 product_id 把两类信息对齐；随后计算每条库存记录的贡献，最后按仓库汇总。

单条贡献
units × Width × Length × Height

完整过程

  1. 按照 product_id 连接 Warehouse 与 Products。
  2. 对连接后的每行计算库存件数乘单件三维体积。
  3. 以仓库名分组，用 SUM 汇总同一仓库的所有贡献。
  4. 将仓库名别名设为 warehouse_name，汇总值别名设为 volume。

正确性说明

连接后，每条库存记录恰好获得其商品的唯一尺寸。表达式计算的正是该记录全部库存的体积。按仓库分组求和会纳入该仓库的每种商品各一次，因此得到且只得到该仓库的总体积。

边界情况

  • 单个仓库只有一种商品时，聚合结果就是该行贡献。
  • 同一商品位于多个仓库时，每条库存记录按各自件数独立计入。
  • 仓库有多种商品时，分组确保它们只累加到相同仓库名下。
  • 乘法链可能超过较小整数范围；本地参考实现使用 64 位整数或安全数值类型。

复杂度

设库存记录数为 W、商品记录数为 P。数据库采用哈希连接与哈希聚合时，期望时间为 O(W + P)，额外空间为 O(P + K)，其中 K 是仓库数；实际执行计划由数据库优化器决定。

替代方案

可以先在子查询中算出每种商品的单件体积，再与库存表连接；可读性较好，但本题无需额外层级。相关子查询也能表达，但通常比一次连接加分组更绕。

官方提交语言 · MySQL

数据库题应提交 SQL；下列查询直接符合题目的关系模型。

SELECT
    w.name AS warehouse_name,
    SUM(w.units * p.Width * p.Length * p.Height) AS volume
FROM Warehouse AS w
INNER JOIN Products AS p
    ON p.product_id = w.product_id
GROUP BY w.name;

Java · 本地语义参考
使用 long 保存体积，并以插入顺序返回仓库统计。
import java.util.*;

public class WarehouseManager {
    record Stock(String name, int productId, int units) {}
    record Product(int productId, String productName,
                   int width, int length, int height) {}

    public static Map<String, Long> calculate(
            List<Stock> warehouse,
            List<Product> products) {
        Map<Integer, Product> byId = new HashMap<>();
        for (Product product : products) {
            byId.put(product.productId(), product);
        }

        Map<String, Long> totals = new LinkedHashMap<>();
        for (Stock stock : warehouse) {
            Product p = byId.get(stock.productId());
            if (p == null) continue;
            long contribution = (long) stock.units()
                    * p.width() * p.length() * p.height();
            totals.merge(stock.name(), contribution, Long::sum);
        }
        return totals;
    }

    public static void main(String[] args) {
        List<Stock> warehouse = List.of(
            new Stock("LCHouse1", 1, 1),
            new Stock("LCHouse1", 2, 10),
            new Stock("LCHouse1", 3, 5),
            new Stock("LCHouse2", 1, 2),
            new Stock("LCHouse2", 2, 2),
            new Stock("LCHouse3", 4, 1)
        );
        List<Product> products = List.of(
            new Product(1, "LC-TV", 5, 50, 40),
            new Product(2, "LC-KeyChain", 5, 5, 5),
            new Product(3, "LC-Phone", 2, 10, 10),
            new Product(4, "LC-T-Shirt", 4, 10, 20)
        );
        calculate(warehouse, products).forEach(
            (name, volume) -> System.out.println(name + " " + volume));
    }
}

function calculateWarehouseVolume(warehouse, products) {
  const byId = new Map(products.map((product) => [product.productId, product]));
  const totals = new Map();

  for (const stock of warehouse) {
    const product = byId.get(stock.productId);
    if (!product) continue;
    const contribution = stock.units * product.width
      * product.length * product.height;
    totals.set(stock.name, (totals.get(stock.name) ?? 0) + contribution);
  }

  return [...totals].map(([warehouseName, volume]) => ({
    warehouseName,
    volume,
  }));
}

以字典模拟连接索引，以有序字典语义累加结果。
from collections import defaultdict
from typing import TypedDict


class Stock(TypedDict):
    name: str
    product_id: int
    units: int


class Product(TypedDict):
    product_id: int
    product_name: str
    width: int
    length: int
    height: int


def calculate_warehouse_volume(
    warehouse: list[Stock], products: list[Product]
) -> list[dict[str, int | str]]:
    by_id = {product["product_id"]: product for product in products}
    totals: defaultdict[str, int] = defaultdict(int)

    for stock in warehouse:
        product = by_id.get(stock["product_id"])
        if product is None:
            continue
        totals[stock["name"]] += (
            stock["units"]
            * product["width"]
            * product["length"]
            * product["height"]
        )

    return [
        {"warehouse_name": name, "volume": volume}
        for name, volume in totals.items()
    ]

C++ · 本地语义参考
以 unordered_map 模拟连接，并用 long long 规避常见乘法溢出。
#include <iostream>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Stock {
    string name;
    int productId;
    int units;
};

struct Product {
    int productId;
    string productName;
    int width;
    int length;
    int height;
};

vector<pair<string, long long>> calculateWarehouseVolume(
        const vector<Stock>& warehouse,
        const vector<Product>& products) {
    unordered_map<int, Product> byId;
    for (const auto& product : products) {
        byId.emplace(product.productId, product);
    }

    vector<pair<string, long long>> result;
    unordered_map<string, size_t> position;
    for (const auto& stock : warehouse) {
        auto productIt = byId.find(stock.productId);
        if (productIt == byId.end()) continue;
        const auto& p = productIt->second;
        long long contribution = 1LL * stock.units
            * p.width * p.length * p.height;

        auto [it, inserted] = position.emplace(stock.name, result.size());
        if (inserted) result.push_back({stock.name, 0});
        result[it->second].second += contribution;
    }
    return result;
}

int main() {
    vector<Stock> warehouse = {
        {"LCHouse1", 1, 1}, {"LCHouse1", 2, 10},
        {"LCHouse1", 3, 5}, {"LCHouse2", 1, 2},
        {"LCHouse2", 2, 2}, {"LCHouse3", 4, 1}
    };
    vector<Product> products = {
        {1, "LC-TV", 5, 50, 40}, {2, "LC-KeyChain", 5, 5, 5},
        {3, "LC-Phone", 2, 10, 10}, {4, "LC-T-Shirt", 4, 10, 20}
    };
    for (const auto& [name, volume] :
         calculateWarehouseVolume(warehouse, products)) {
        cout << name << ' ' << volume << '\n';
    }
}

面试追问

  • 为什么这里使用 INNER JOIN？若允许商品尺寸缺失，应如何定义并保留这些库存？
  • 体积可能很大时，如何显式转换数值类型避免溢出？
  • 如果要求同时输出仓库中不同商品种类数，应增加什么聚合表达式？
  • 哪些索引有助于连接？主键约束已经提供了哪部分能力？

常见错误

  • 只计算 Width × Length × Height，忘记乘库存件数 units。
  • 按 product_id 分组，导致同一仓库被拆成多行。
  • 缺少连接条件，形成笛卡尔积并把体积成倍放大。
  • 使用 product_name 连接；题目给出的稳定关联键是 product_id。
  • 输出列别名与题目要求的 warehouse_name、volume 不一致。
