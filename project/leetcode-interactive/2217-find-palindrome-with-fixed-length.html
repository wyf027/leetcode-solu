2217. 找到指定长度的回文数

Find Palindrome With Fixed Length

数组数学免费题

题目 · 按名次寻找

给定整数数组 queries 和正整数 intLength。把所有恰好有 intLength 位的正回文数按从小到大排列；对每个查询 queries[i]，返回这个排列中第 queries[i] 个数。该名次不存在时，返回 -1，最终结果按查询的原始顺序组成数组 answer。

回文数正读、反读相同，且不能以 0 开头。名次从 1 开始，各个查询相互独立。

先思考：长度相同的回文数如何排序？你能直接找到某个名次，而不列出前面的所有数字吗？下方题解默认折叠。

参数与返回值

kthPalindrome(queries, intLength) → answer

  • queries：待查询的名次数组。
  • intLength：目标回文数的十进制位数。
  • answer：与查询等长的整数数组，元素可能超过 32 位有符号整数范围。

约束

  • 1 ≤ queries.length ≤ 5 × 10⁴
  • 1 ≤ queries[i] ≤ 10⁹
  • 1 ≤ intLength ≤ 15

官方示例

示例 1

输入：queries = [1,2,3,4,5,90], intLength = 3
输出：[101,111,121,131,141,999]

三位回文数开头依次为 101、111、121、131、141、151、161、171、181、191、202……第 90 个是 999。

示例 2

输入：queries = [2,4,6], intLength = 4
输出：[1111,1331,1551]

四位回文数的前六个是 1001、1111、1221、1331、1441、1551，所以选出第 2、4、6 个。

题解 · 前半段决定整个回文

令 L = intLength，h = ⌈L / 2⌉。每个回文数由前 h 位唯一决定：偶数长度复制整个前半段的倒序；奇数长度跳过中间位，再倒序复制。

合法前缀从 start = 10^(h−1) 到 10^h − 1，共 9 × start 个。第 k 个前缀就是 start + k − 1。只需构造这一个数字。

镜像工作台 · 名次 → 前缀 → 对称补全

一次观察一个查询。绿色是前缀，黄色是奇数长度的中心位，紫色是镜像复制的位；描边标出当前复制的位置。

完整过程

  1. 计算前缀长度 h = (L + 1) // 2，起始前缀 start = 10^(h−1)。
  2. 对每个名次 k，若 k > 9 × start，答案为 −1。
  3. 否则把 start + k − 1 转成字符串 s。
  4. 偶数长度取整个 s；奇数长度取去掉末位的 s。将所取部分反转，追加到 s 后面。
  5. 把结果转成足够宽的整数，按输入查询顺序写入答案。

例：L = 3, k = 4，h = 2，start = 10，前缀为 13。中心位 3 不复制，把 1 镜像到右侧，得到 131。L = 4, k = 6 时前缀为 15，反转完整前缀得到 51，拼接得到 1551。

正确性证明

  1. 一一对应：每个合法 h 位前缀按上述规则都生成一个长度恰为 L、没有前导零的回文数。任意合法回文数也只能由它自己的前 h 位生成，所以没有遗漏或重复。
  2. 保持顺序：两个不同前缀的第一个不同数字，也是在对应回文数中最早出现的不同数字。位数相同，所以较小前缀生成的回文数一定较小。
  3. 名次正确：前缀连续地从 start 开始，第 k 个恰为 start + k − 1；结合一一对应和顺序保持，生成值正是第 k 小回文数。合法前缀仅有 9 × start 个，超出数量时返回 −1 正确。

边界与常见错误

  • L = 1：前缀就是答案，镜像部分为空；只有 1 到 9，没有 0。
  • 最后一个与越界：k 等于总数仍合法，只有严格大于总数才返回 −1。
  • 奇数中心：反转前要跳过 s 的最后一位，否则输出会多一位。
  • 名次偏移：k 从 1 开始，必须使用 start + k − 1。
  • 类型范围：最大输出是 999999999999999。Java 使用 long，C++ 使用 long long；Python 整数可直接容纳。JavaScript Number 的安全整数上限是 2⁵³−1，覆盖本题所有输出；不要对答案做 32 位位运算。
  • 查询无需排序：重复查询得到重复答案，保持原数组顺序即可。

复杂度

设查询数为 Q，目标长度为 L。每个查询的字符串构造和数值转换耗时 O(L)，总时间 O(Q × L)；不计返回数组时，临时字符串空间 O(L)，返回数组占 O(Q)。L ≤ 15 时也可视为每次查询常数规模工作。

替代方案

  • 算术镜像：以 prefix 为答案初值；奇数长度先令 tail = prefix / 10 的整数部分，偶数长度令 tail = prefix。不断把 tail 的末位接到答案末尾。时间仍为 O(Q × L)，按本题固定宽整数模型，额外工作空间 O(1)。
  • 枚举所有回文：逐个枚举合法前缀再镜像，适合需要整张列表的任务；本题最多有 9000 万个合法回文，预生成会浪费时间与空间。
  • 枚举所有 L 位数再判断：需要扫描 9 × 10^(L−1) 个候选，远比直接按名次构造昂贵。

面试追问

  • 推广到 B 进制？起点改为 B^(h−1)，数量为 (B−1) × B^(h−1)，在 B 进制下镜像。
  • 给定回文数求名次？确认长度、回文和无前导零后，取前 h 位，计算 prefix − start + 1。
  • 长度超过 15？输出可以保留为字符串；涉及超出精确整数范围的前缀和名次时使用大整数，不能依赖浮点精度。
  • 限制某些数字出现怎么办？合法前缀不再连续，可按前缀分支计数，再按名次选择分支；需要根据具体限制设计计数方法。

Java

long[]
class Solution {
    public long[] kthPalindrome(int[] queries, int intLength) {
        int h = (intLength + 1) / 2;
        long start = 1;
        for (int i = 1; i < h; i++) start *= 10;
        long[] answer = new long[queries.length];
        for (int i = 0; i < queries.length; i++) {
            if (queries[i] > 9 * start) {
                answer[i] = -1;
                continue;
            }
            String s = Long.toString(start + queries[i] - 1);
            String tail = s.substring(0, s.length() - intLength % 2);
            answer[i] = Long.parseLong(
                s + new StringBuilder(tail).reverse().toString()
            );
        }
        return answer;
    }
}

/**
 * @param {number[]} queries
 * @param {number} intLength
 * @return {number[]}
 */
var kthPalindrome = function(queries, intLength) {
    const h = Math.ceil(intLength / 2);
    const start = 10 ** (h - 1);
    return queries.map(k => {
        if (k > 9 * start) return -1;
        const s = String(start + k - 1);
        const tail = s.slice(0, s.length - intLength % 2);
        return Number(s + tail.split('').reverse().join(''));
    });
};

from typing import List

class Solution:
    def kthPalindrome(self, queries: List[int], intLength: int) -> List[int]:
        h = (intLength + 1) // 2
        start = 10 ** (h - 1)
        answer = []
        for k in queries:
            if k > 9 * start:
                answer.append(-1)
                continue
            s = str(start + k - 1)
            tail = s[:len(s) - intLength % 2]
            answer.append(int(s + tail[::-1]))
        return answer

#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<long long> kthPalindrome(vector<int>& queries, int intLength) {
        int h = (intLength + 1) / 2;
        long long start = 1;
        for (int i = 1; i < h; ++i) start *= 10;
        vector<long long> answer;
        answer.reserve(queries.size());
        for (int k : queries) {
            if (k > 9 * start) {
                answer.push_back(-1);
                continue;
            }
            string s = to_string(start + k - 1);
            string tail = s.substr(0, s.size() - intLength % 2);
            reverse(tail.begin(), tail.end());
            answer.push_back(stoll(s + tail));
        }
        return answer;
    }
};
