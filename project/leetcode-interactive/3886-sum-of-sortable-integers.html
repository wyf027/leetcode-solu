可排序整数求和

把数组切成等长块，每块只能原地循环移位。哪些块长 k 能让整体恰好成为排序后的数组？用 KMP 验证每一块是否是目标块的循环移位。

进入实验室

题意

给定 nums，长度为 n。当 k 是 n 的因数时，将数组按长度 k 切成连续块；每个块可以独立向左或向右循环移动任意次。若可以得到非递减数组，k 就是可排序整数。返回全部这类 k 的和。

示例 1：nums = [3, 1, 2]

输出：3。只有 k = 3，块 [3, 1, 2] 左移一次变为 [1, 2, 3]。

约束：1 ≤ n ≤ 10⁵，1 ≤ nums[i] ≤ 10⁵。

先观察终点

  1. 最终数组已经确定：就是 sorted(nums)。
  2. 长度 k 的第 b 块，不能和其他块交换元素；所以它必须变成排序结果中同位置的第 b 块。
  3. 一个序列能靠循环移位变为另一个等长序列，等价于目标序列出现于原序列的“双倍串”中。

因此：枚举 n 的因数 k，对每个块用 KMP 判断 targetBlock 是否匹配 sourceBlock + sourceBlock 的前 2k - 1 个位置。

题解：枚举因数 + 分块 KMP

核心洞察

排序后的完整数组唯一。固定 k 时，第 b 个原始块只能靠自身的循环移位到达第 b 个目标块，不能借用邻块元素。因此每一块都必须是对应目标块的旋转。

复杂度

排序 O(n log n)。n 的每个因数各扫描 O(n) 个位置并做线性 KMP，总计 O(n · τ(n))；τ(n) 是因数个数，n ≤ 10⁵ 时足够安全。额外空间 O(k)。

边界与替代方案

  • 数组已排序：每个因数都成立。
  • 含重复值：不能只找最小元素的下标；KMP 可靠处理重复。
  • 暴力枚举每次旋转会把单块变成 O(k²)，应避免。
  • 也可用滚动哈希比较旋转，但要处理碰撞；KMP 是确定性的。

面试追问与常见错误

追问：若允许块间交换，问题会变成另一个排列约束。常见错误是只判断每块内部可排序，忽略它必须对齐到排序结果的同一段；或在双倍串中允许起点达到 k，那会把“旋转两圈”的重复匹配误算进去。
