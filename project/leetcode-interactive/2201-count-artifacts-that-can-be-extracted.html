第 2201 题 · 一块工件，必须完整露出，才能带走。

数组哈希表模拟离线单文件

01 /任务简报

给定一个从 0 开始编号的 n × n 网格。数组 artifacts 中，每项 [r1, c1, r2, c2] 描述一个矩形工件：左上角是 (r1, c1)，右下角是 (r2, c2)，两端都包含。

dig 中的每项 [r, c] 表示挖开这个单元格。只有工件覆盖的每个格子都被挖开，它才可以提取。返回可提取的工件个数，不是挖开的格子数。

工件互不重叠，每件至多占 4 格；挖掘坐标不会重复。挖到没有工件的格子也是合法操作。

打开官方题目 ↗

完整约束

  • 1 ≤ n ≤ 1000
  • 1 ≤ artifacts.length, dig.length ≤ min(n², 10⁵)
  • artifacts[i].length = 4
  • dig[i].length = 2
  • 所有坐标 r1, c1, r2, c2, r, c 均在 [0, n − 1] 内。
  • r1 ≤ r2 且 c1 ≤ c2
  • 不同工件没有公共格子。
  • 每件覆盖格子数至多为 4。
  • dig 中的坐标两两不同。

官方示例 1

n = 2
artifacts = [[0,0,0,0],[0,1,1,1]]
dig = [[0,0],[0,1]]

输出：1

单格工件已全部露出；纵向工件还缺 (1,1)，不能提取。

官方示例 2

n = 2
artifacts = [[0,0,0,0],[0,1,1,1]]
dig = [[0,0],[0,1],[1,1]]

输出：2

追加挖掘 (1,1) 后，两件工件都完整露出。

04 /题解 · 建立挖掘集合，逐件确认




核心洞察
不必模拟泥土或真正移动工件。最终是否可提取，只取决于工件的所有坐标是否属于已挖掘集合。每件最多 4 格，直接枚举它覆盖的格子已经很便宜。
把坐标编码为 r × n + c，将 dig 的编码放入哈希集合。合法坐标中，除以 n 的商与余数分别恢复行、列，因此编码不会混淆不同格子。


完整过程
  1. 遍历 dig，把每个 r × n + c 放入集合 dug。
  2. 初始化答案为 0，对每件工件设置 complete = true。
  3. 枚举行 r1…r2 和列 c1…c2，两端都包含。
  4. 任意格不在 dug 中，就把 complete 置为 false。
  5. 只有 complete 仍为 true 时，答案加 1；最后返回答案。




以官方示例 1 追踪
n = 2 时，挖掘集合为 {0, 1}。工件 A 的唯一格子 (0,0) 编码为 0，存在，答案变为 1。工件 B 的 (0,1) 编码 1 存在，但 (1,1) 编码 3 不存在，整件失败，答案保持 1。示例 2 把 3 加入集合，因此 B 也满足条件，得到 2。




正确性证明
标记准确：集合恰好包含 dig 中的全部坐标编码，由编码唯一性，成员查询等价于该格是否挖开。
单件判定：扫描期间，complete 为 true 当且仅当目前检查的所有格都已挖开。一旦发现缺失格，它保持 false。完整遍历后，complete 恰好表达题目要求的“全部裸露”。
计数准确：处理前 k 件后，答案等于其中满足提取条件的件数。初始 k = 0 时成立；每次仅在当前工件满足条件时加 1，保持不变式。最终答案就是全部可提取工件的数量。


复杂度与边界
设 A 为工件数，D 为挖掘格数，S 为所有工件的总面积。哈希集合操作按平均 O(1) 计，时间为 O(D + S) = O(D + A)，因为 S ≤ 4A；额外空间为 O(D)。哈希表理论最坏情况不保证常数查询。
n = 1、单行或单列工件、完全未露出、仅缺一格、全部露出都使用同一逻辑。空地的标记不会被任何工件查询，不影响答案。最大编码为 n² − 1 ≤ 999999，四份实现的整数表示均可容纳。




替代方案
  • 二维布尔数组：分配 n × n 网格后标记 dig，再逐件扫描。查询为确定 O(1)，但初始化时间 O(n²)，总时间 O(n² + D + A)，空间 O(n²)。
  • 二维前缀和：若去掉“每件最多 4 格”，可构造挖掘标记的前缀和，O(1) 查询每个矩形已挖面积并与工件面积比较。时间 O(n² + D + A)，空间 O(n²)；当前限制下无须增加实现复杂度。
  • 在线计数：若每次挖掘后都要返回答案，可预先建立“格子 → 工件”的映射，为每件维护剩余格数，降到 0 时更新答案。当前只需要最终结果，集合更直接。


常见错误
  • 只查左上角和右下角：2 × 2 工件还有另外两个格子。
  • 使用 r < r2 或 c < c2：丢失右、下边界，单格工件也会出错。
  • 把每个裸露格计入答案：答案单位是工件，必须整件判定。
  • 每查询一格就扫描整个 dig：把线性时间放大到 O(A × D)。
  • JavaScript 用数组作为 Set 键：[r,c] 按引用比较，应该使用数字编码或字符串。
  • 对每个格重新覆盖 complete：发现缺失后必须一直为 false，不能被后续已挖格改回 true。


面试追问
挖掘顺序重要吗？最终答案不重要，因为集合相同；只有逐步答案依赖顺序。
如果 dig 允许重复呢？本方案用集合自然去重；在线计数方案则必须防止重复递减。
如果工件可以重叠呢？最终逐件集合检查依然成立，因为每件独立判定；在线映射则需要一个格对应多件工件。

Java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int digArtifacts(int n, int[][] artifacts, int[][] dig) {
        Set<Integer> dug = new HashSet<>();
        for (int[] cell : dig) {
            dug.add(cell[0] * n + cell[1]);
        }
        int answer = 0;
        for (int[] a : artifacts) {
            boolean complete = true;
            for (int r = a[0]; r <= a[2]; r++) {
                for (int c = a[1]; c <= a[3]; c++) {
                    if (!dug.contains(r * n + c)) {
                        complete = false;
                    }
                }
            }
            if (complete) answer++;
        }
        return answer;
    }
}


JavaScript
/**
 * @param {number} n
 * @param {number[][]} artifacts
 * @param {number[][]} dig
 * @return {number}
 */
var digArtifacts = function(n, artifacts, dig) {
    const dug = new Set(dig.map(([r, c]) => r * n + c));
    let answer = 0;
    for (const [r1, c1, r2, c2] of artifacts) {
        let complete = true;
        for (let r = r1; r <= r2; r++) {
            for (let c = c1; c <= c2; c++) {
                if (!dug.has(r * n + c)) complete = false;
            }
        }
        if (complete) answer++;
    }
    return answer;
};


Python 3
from typing import List

class Solution:
    def digArtifacts(self, n: int, artifacts: List[List[int]],
                     dig: List[List[int]]) -> int:
        dug = {r * n + c for r, c in dig}
        answer = 0
        for r1, c1, r2, c2 in artifacts:
            complete = True
            for r in range(r1, r2 + 1):
                for c in range(c1, c2 + 1):
                    if r * n + c not in dug:
                        complete = False
            if complete:
                answer += 1
        return answer


C++
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int digArtifacts(int n, vector<vector<int>>& artifacts,
                     vector<vector<int>>& dig) {
        unordered_set<int> dug;
        for (const auto& cell : dig) {
            dug.insert(cell[0] * n + cell[1]);
        }
        int answer = 0;
        for (const auto& a : artifacts) {
            bool complete = true;
            for (int r = a[0]; r <= a[2]; ++r) {
                for (int c = a[1]; c <= a[3]; ++c) {
                    if (dug.count(r * n + c) == 0) {
                        complete = false;
                    }
                }
            }
            if (complete) ++answer;
        }
        return answer;
    }
};
