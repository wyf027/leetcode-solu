1809 · 没有广告的剧集

Ad-Free Sessions · 付费数据库题

在播放时间轴上观察广告，找出完整的无广告会话。

01 / 题意与官方示例

给定播放表 Playback 与广告表 Ads，返回播放期间没有向该顾客展示任何广告的 session_id。返回顺序不限。这里的“剧集”指一段播放会话。

Playback(session_id INT, customer_id INT, start_time INT, end_time INT)
Ads(ad_id INT, customer_id INT, timestamp INT)

session_id 和 ad_id 分别是各表主键；customer_id 指观看者。播放区间包含开始、结束两个端点；start_time ≤ end_time；同一顾客的播放区间互不相交。timestamp 为广告展示时刻。题面未提供行数或整数范围的具体上限。

04 / 独立题解

核心洞察：不存在匹配广告

广告必须同时满足顾客相同与时间落在闭区间内，才能影响某段播放。只关心是否存在，不需要统计条数。

完整过程

  1. 枚举一条 Playback 记录。
  2. 在 Ads 中寻找同顾客且 timestamp BETWEEN start_time AND end_time 的记录。
  3. 找到任何一条就排除；找不到则输出 session_id。

示例中会话 1 命中广告 1，会话 2、3 都无命中，会话 4 命中广告 2 即可停止，会话 5 无命中，最终得到 2、3、5。

正确性

可靠性：输出会话的子查询为空，因此不存在播放期间展示给该顾客的广告，必为无广告会话。完整性：每个无广告会话都没有满足条件的 Ads 记录，NOT EXISTS 必为真，因此不会漏掉。外层主键唯一，输出无需 DISTINCT。

边界与常见错误

  • 端点也算命中，不能改成严格不等式。
  • 不能省略 customer_id，否则其他顾客的广告也会导致排除。
  • Ads 为空时全部播放保留；Playback 为空时结果为空。
  • 零长度区间只匹配那个时刻；多个广告不会重复输出会话。
  • 仅按顾客排除会误删其他时间的会话；NOT IN 需要特别注意 NULL 的三值逻辑。

复杂度

设 P、A 为两表行数。四语言参考最坏时间 O(PA)，除结果外辅助空间 O(1)，结果空间 O(P)。SQL 依赖执行计划；朴素嵌套扫描最坏 O(PA)。Ads(customer_id, timestamp) 复合索引通常支持等值加范围探测，典型每段播放可接近 O(log A) 查找，实际代价由数据库和数据分布决定。

替代方案

LEFT JOIN：把顾客和时间条件都写进 ON，再用 WHERE a.ad_id IS NULL 保留未匹配行。把范围条件放到 WHERE 会过滤掉未匹配记录。本地大数据可按顾客分组并排序广告时间，再二分查找第一个不小于开始时间的广告，判断它是否不大于结束时间。

面试追问

怎样统计广告数？LEFT JOIN 后按会话分组，COUNT(a.ad_id)。会话允许重叠呢？存在性解法仍成立，同一广告可以影响多个会话。为什么找到一条即可停止？目标只判断零条还是至少一条。

MySQL · 官方可提交语言

SELECT p.session_id
FROM Playback AS p
WHERE NOT EXISTS (
    SELECT 1 FROM Ads AS a
    WHERE a.customer_id = p.customer_id
      AND a.timestamp BETWEEN p.start_time AND p.end_time
);

以下四份完整函数仅为本地语义参考，非本数据库题官方提交签名。输入为整数行数组，Playback 列顺序为 session_id、customer_id、start_time、end_time；Ads 为 ad_id、customer_id、timestamp。返回 session_id 列表。

Java · 本地语义参考

import java.util.*;
class Solution {
    public List<Integer> adFreeSessions(int[][] playback, int[][] ads) {
        List<Integer> result = new ArrayList<>();
        for (int[] p : playback) {
            boolean found = false;
            for (int[] a : ads) {
                if (a[1] == p[1] && p[2] <= a[2] && a[2] <= p[3]) {
                    found = true;
                    break;
                }
            }
            if (!found) result.add(p[0]);
        }
        return result;
    }
}

function adFreeSessions(playback, ads) {
  return playback.filter(p => !ads.some(a =>
    a[1] === p[1] && p[2] <= a[2] && a[2] <= p[3]
  )).map(p => p[0]);
}

Python · 本地语义参考

def ad_free_sessions(playback, ads):
    return [p[0] for p in playback if not any(
        a[1] == p[1] and p[2] <= a[2] <= p[3]
        for a in ads
    )]
