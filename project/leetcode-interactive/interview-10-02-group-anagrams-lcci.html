Core insight

排列会变，频次向量不变

26 个计数就是唯一货号

对每个单词统计 a…z 的出现次数。互为变位词当且仅当这 26 个数字逐项相等，因此计数向量可以直接作为哈希键。字符串键必须加入分隔符，例如 #1#0#12…，避免数字拼接歧义。

INVARIANT

同一料箱里的所有字符串具有完全相同的 26 位频次向量。

Complete process

完整过程

  1. 1. 创建“签名 → 字符串列表”的哈希表。
  2. 2. 扫描一个字符串，用长度为 26 的数组累计每个字母的次数。
  3. 3. 将计数数组序列化为带分隔符的签名，或在支持的语言中直接使用不可变元组。
  4. 4. 把原字符串追加到对应列表，最后返回哈希表的全部列表。

Correctness

为什么一定正确

不会错分：若两个字符串进入同一组，它们的签名相同，故每个字母的出现次数都相等，必互为变位词。

不会漏分：若两个字符串互为变位词，每个字母的次数必相同，生成的签名相同，因此会进入同一组。

两个方向同时成立，最终分组与变位词等价关系完全一致。

Time

O(L + 26N)

N 为字符串数，L 为所有字符串总长度。

Space

O(L + 26N)

包含输出与哈希键；临时计数仅 O(26)。

Boundary desk

  • • 空字符串的 26 位计数全为 0，所有空串自然进入同一组。
  • • 重复字符串应保留重复次数，不可用集合去重。
  • • 单字符和只有一个元素的输入无需特殊分支。
  • • 本题限定小写字母；扩展到 Unicode 时应改用字符频次映射或排序键。

Alternative

排序字符串作键

将每个字符串的字符排序，排序结果作为键。实现直观，也自然支持更广字符集；代价是每个长度为 K 的字符串需要 O(K log K) 时间。本题明确为小写字母时，计数签名更优。

Interview follow-up

面试追问

  • 若字符集很大？ 改用排序键或稀疏频次映射。
  • 数据流持续到达？ 哈希表可增量追加，按需输出料箱。
  • 输出需稳定？ 使用保持插入顺序的映射，并按输入顺序追加。

Failure log

常见错误

  • 直接拼接数字却不加分隔符，产生签名碰撞。
  • 把计数数组对象本身当 JavaScript Map 键，每次对象引用不同。
  • 误以为输出顺序固定，测试时直接比较未标准化的二维数组。
  • 复用计数数组却未清零，导致前一个单词污染后一个单词。

import java.util.*;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> groups = new LinkedHashMap<>();

        for (String word : strs) {
            int[] count = new int[26];
            for (char ch : word.toCharArray()) {
                count[ch - 'a']++;
            }

            StringBuilder key = new StringBuilder();
            for (int value : count) {
                key.append('#').append(value);
            }
            groups.computeIfAbsent(key.toString(), unused -> new ArrayList<>())
                .add(word);
        }

        return new ArrayList<>(groups.values());
    }
}
var groupAnagrams = function (strs) {
  const groups = new Map();

  for (const word of strs) {
    const count = new Array(26).fill(0);
    for (const ch of word) {
      count[ch.charCodeAt(0) - 97] += 1;
    }

    const key = count.join("#");
    if (!groups.has(key)) {
      groups.set(key, []);
    }
    groups.get(key).push(word);
  }

  return [...groups.values()];
};
from collections import defaultdict
from typing import List


class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = defaultdict(list)

        for word in strs:
            count = [0] * 26
            for ch in word:
                count[ord(ch) - ord("a")] += 1
            groups[tuple(count)].append(word)

        return list(groups.values())
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> groups;

        for (const string& word : strs) {
            array<int, 26> count{};
            for (char ch : word) {
                count[ch - 'a']++;
            }

            string key;
            for (int value : count) {
                key += '#' + to_string(value);
            }
            groups[key].push_back(word);
        }

        vector<vector<string>> answer;
        answer.reserve(groups.size());
        for (auto& [key, group] : groups) {
            answer.push_back(move(group));
        }
        return answer;
    }
};
