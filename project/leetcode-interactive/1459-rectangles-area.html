矩形面积 Rectangles Area

从一张坐标表中找出每一对能构成非零轴对齐矩形的对角点，并按规定顺序给出点号与面积。

1459难度：中等题型：数据库付费题

题目转述

表 Points 保存平面点。任选两行作为一个轴与坐标轴平行的矩形的两个对角点；仅保留横、纵坐标都不同的点对，因此面积必须大于 0。

输出 (p1, p2, area)：p1、p2 是两个对角点的 id，且 p1 < p2；area 是矩形面积。先按面积降序，再按 p1 升序，最后按 p2 升序排列。

输入表：Points

列名类型说明
idint唯一值
x_valueint横坐标
y_valueint纵坐标

约束与保证

  • 三列均为整数；id 唯一。
  • 每行表示坐标 (x_value, y_value)。
  • 结果只含面积非零的轴对齐矩形。
  • 同一无序点对只输出一次，并满足 p1 < p2。

官方示例 · 完整参数形式

输入：Points

+----+---------+---------+
| id | x_value | y_value |
+----+---------+---------+
| 1  | 2       | 7       |
| 2  | 4       | 8       |
| 3  | 2       | 10      |
+----+---------+---------+

输出

+----+----+------+
| p1 | p2 | area |
+----+----+------+
| 2  | 3  | 4    |
| 1  | 2  | 2    |
+----+----+------+
点 2 与点 3 得到面积 4；点 1 与点 2 得到面积 2。点 1 与点 3 的横坐标相同，矩形退化为线段，因此不输出。

Solution

自连接枚举无序点对

核心洞察

一对横、纵坐标都不同的点，恰好能确定一个非退化轴对齐矩形。面积是两维坐标差绝对值的乘积。

去重

连接条件使用 a.id < b.id，每个无序点对仅出现一次，同时天然满足 p1 小于 p2。

过滤

若横坐标或纵坐标相同，乘积为 0。提前用两个不等条件排除退化矩形。

完整过程

  1. 将 Points 与自身连接，左侧别名为 a，右侧别名为 b。
  2. 用 a.id < b.id 枚举所有不重复点对。
  3. 要求 a.x_value != b.x_value 且 a.y_value != b.y_value。
  4. 计算 ABS(Δx) × ABS(Δy)。
  5. 依次按 area 降序、p1 升序、p2 升序排序。

正确性说明

完备性：任一合法矩形的两个给定对角点 id 有确定大小关系，因此自连接中恰有一次满足 a.id < b.id；两坐标均不同，所以不会被过滤。

可靠性：保留下来的每对点在 x、y 两维差值都非零，能够确定边长分别为 |Δx|、|Δy| 的轴对齐矩形，所得面积严格为正。

唯一性：严格 id 顺序排除了反向点对，故不会重复。

边界与复杂度

  • 不足两个点：结果为空。
  • 所有点共线：结果为空。
  • 负坐标：绝对值保证边长为正。
  • 相同面积：仍按 p1、p2 稳定排序。
  • n 行时最多考察 n(n−1)/2 对；时间 O(n²)，查询额外工作空间视数据库执行计划而定，逻辑上 O(1)，结果/排序空间另计。

官方可提交语言：MySQL

SELECT
    a.id AS p1,
    b.id AS p2,
    ABS(a.x_value - b.x_value)
      * ABS(a.y_value - b.y_value) AS area
FROM Points AS a
JOIN Points AS b
  ON a.id < b.id
WHERE a.x_value != b.x_value
  AND a.y_value != b.y_value
ORDER BY area DESC, p1 ASC, p2 ASC;

本题是数据库题，在线判题应提交 SQL。以下 Java、JavaScript、Python、C++ 代码仅在本地数组上复现相同语义，并非该题官方提交语言。

Java · 本地语义参考

import java.util.*;

class Solution {
  record Point(int id, long x, long y) {}
  record Row(int p1, int p2, long area) {}

  List<Row> rectanglesArea(List<Point> points) {
    List<Row> ans = new ArrayList<>();
    for (int i = 0; i < points.size(); i++) {
      for (int j = i + 1; j < points.size(); j++) {
        Point a = points.get(i), b = points.get(j);
        if (a.x == b.x || a.y == b.y) continue;
        int p1 = Math.min(a.id, b.id);
        int p2 = Math.max(a.id, b.id);
        long area = Math.abs(a.x - b.x) * Math.abs(a.y - b.y);
        ans.add(new Row(p1, p2, area));
      }
    }
    ans.sort(Comparator.comparingLong(Row::area).reversed()
        .thenComparingInt(Row::p1).thenComparingInt(Row::p2));
    return ans;
  }
}

JavaScript · 本地语义参考

function rectanglesArea(points) {
  const rows = [];
  for (let i = 0; i < points.length; i++) {
    for (let j = i + 1; j < points.length; j++) {
      const a = points[i], b = points[j];
      if (a.x_value === b.x_value || a.y_value === b.y_value) continue;
      rows.push({
        p1: Math.min(a.id, b.id),
        p2: Math.max(a.id, b.id),
        area: Math.abs(a.x_value - b.x_value)
          * Math.abs(a.y_value - b.y_value)
      });
    }
  }
  return rows.sort((u, v) =>
    v.area - u.area || u.p1 - v.p1 || u.p2 - v.p2
  );
}

Python · 本地语义参考

def rectangles_area(points):
    rows = []
    for i, a in enumerate(points):
        for b in points[i + 1:]:
            if a["x_value"] == b["x_value"]:
                continue
            if a["y_value"] == b["y_value"]:
                continue
            p1, p2 = sorted((a["id"], b["id"]))
            area = (abs(a["x_value"] - b["x_value"])
                    * abs(a["y_value"] - b["y_value"]))
            rows.append((p1, p2, area))
    rows.sort(key=lambda row: (-row[2], row[0], row[1]))
    return rows

C++ · 本地语义参考

#include <algorithm>
#include <cstdlib>
#include <tuple>
#include <vector>
using namespace std;

struct Point { int id; long long x, y; };

vector<tuple<int, int, long long>>
rectanglesArea(const vector<Point>& points) {
  vector<tuple<int, int, long long>> rows;
  for (int i = 0; i < (int)points.size(); ++i) {
    for (int j = i + 1; j < (int)points.size(); ++j) {
      const auto& a = points[i];
      const auto& b = points[j];
      if (a.x == b.x || a.y == b.y) continue;
      int p1 = min(a.id, b.id), p2 = max(a.id, b.id);
      long long area = llabs(a.x - b.x) * llabs(a.y - b.y);
      rows.emplace_back(p1, p2, area);
    }
  }
  sort(rows.begin(), rows.end(), [](const auto& u, const auto& v) {
    if (get<2>(u) != get<2>(v)) return get<2>(u) > get<2>(v);
    if (get<0>(u) != get<0>(v)) return get<0>(u) < get<0>(v);
    return get<1>(u) < get<1>(v);
  });
  return rows;
}

替代方案

可先做笛卡尔积再在 WHERE 中筛选 id 顺序，但把点对约束写进 JOIN 更清晰。也可使用 LEAST/GREATEST 后去重，不过需要额外去重且可移植性更差。

常见错误

重复

只写 a.id != b.id，导致正反两次输出。

退化

仅判断两点不同，没有排除同 x 或同 y，最终混入面积 0。

符号与排序

忘记 ABS，或只按面积排序，遗漏题目规定的并列次序。
