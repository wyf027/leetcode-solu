苹果和桔子

Apples & Oranges — 从每天两条销售记录中，报告苹果销量与桔子销量的差，并按日期升序返回。

数据库条件聚合按日分组

Problem

题目与数据结构

给定销售表 Sales，计算每个销售日期的 apples − oranges，输出日期和差值，并按日期升序排列。

Sales 表

列名类型含义
sale_dateDATE销售日期
fruitENUMapples 或 oranges
sold_numINT当天该水果的销量

约束与输出

  • (sale_date, fruit) 是主键，因此同一天同一种水果至多一条记录。
  • fruit 只取 apples、oranges。
  • 每条记录描述某一天某一种水果的销量。
  • 结果列为 sale_date 与 diff，其中差值允许为负数。
  • 结果必须按 sale_date 升序。
这是数据库题；在线提交应使用 SQL。页面后面的四种通用语言代码仅用于本地理解同一聚合语义。

Solution

条件聚合：一次扫描完成正负记账

核心洞察

同一天的苹果和桔子最终只需要一个差值。把苹果销量视为正数，把桔子销量视为负数，再按日期求和，所得恰好是 苹果销量 − 桔子销量。

完整过程

  1. 按 sale_date 分组。
  2. 用条件表达式把 apples 对应的 sold_num 保持为正数，把 oranges 对应的值变为负数。
  3. 对每组求和并命名为 diff。
  4. 按日期升序输出。

正确性证明

1

对任意日期 d，主键保证该日期与某一水果类型不会重复出现；分组会把日期 d 的相关记录放入同一组。

2

条件表达式为苹果记录贡献 +apples(d)，为桔子记录贡献 −oranges(d)。

3

因此该组之和为 apples(d) − oranges(d)，正是要求的 diff；排序只改变输出顺序，不改变数值。对每个日期均成立，算法正确。

复杂度

设表中有 n 行、不同日期有 d 个。聚合扫描为 O(n)；若最终排序单独执行，则为 O(d log d)。数据库执行计划可能使用索引或排序聚合。聚合状态空间为 O(d)。

边界情况

  • 两种销量相等，差值为 0。
  • 桔子更多，差值为负。
  • 某种销量为 0，仍参与计算。
  • 日期不能按输入出现顺序假定，必须显式排序。

替代方案

可以将同一张表按日期自连接，分别匹配苹果行和桔子行后相减。它直观但更冗长；若输入保证每天两种水果都有记录，条件聚合通常更简洁。

可提交 SQL（MySQL）

这是本题官方题型对应的主要提交语言。

SELECT
    sale_date,
    SUM(
        CASE
            WHEN fruit = 'apples' THEN sold_num
            ELSE -sold_num
        END
    ) AS diff
FROM Sales
GROUP BY sale_date
ORDER BY sale_date;

四语言本地语义参考

数据库题在 LeetCode 应提交 SQL。以下代码完整演示“按日期聚合苹果减桔子”的本地计算语义，不是该题在线判题的提交格式。

import java.time.LocalDate;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

public class Main {
    record Sale(LocalDate date, String fruit, int soldNum) {}
    record DailyDiff(LocalDate date, int diff) {}

    static List<DailyDiff> applesMinusOranges(List<Sale> sales) {
        Map<LocalDate, Integer> totals = new TreeMap<>();
        for (Sale sale : sales) {
            int signed = sale.fruit().equals("apples")
                    ? sale.soldNum() : -sale.soldNum();
            totals.merge(sale.date(), signed, Integer::sum);
        }
        List<DailyDiff> answer = new ArrayList<>();
        totals.forEach((date, diff) -> answer.add(new DailyDiff(date, diff)));
        return answer;
    }

    public static void main(String[] args) {
        List<Sale> sales = List.of(
            new Sale(LocalDate.parse("2020-05-01"), "apples", 10),
            new Sale(LocalDate.parse("2020-05-01"), "oranges", 8)
        );
        applesMinusOranges(sales).forEach(System.out::println);
    }
}
/** @typedef {{saleDate: string, fruit: 'apples'|'oranges', soldNum: number}} Sale */

/** @param {Sale[]} sales */
function applesMinusOranges(sales) {
  const totals = new Map();
  for (const sale of sales) {
    const signed = sale.fruit === 'apples' ? sale.soldNum : -sale.soldNum;
    totals.set(sale.saleDate, (totals.get(sale.saleDate) ?? 0) + signed);
  }
  return [...totals.entries()]
    .sort(([dateA], [dateB]) => dateA.localeCompare(dateB))
    .map(([saleDate, diff]) => ({ saleDate, diff }));
}

const sales = [
  { saleDate: '2020-05-01', fruit: 'apples', soldNum: 10 },
  { saleDate: '2020-05-01', fruit: 'oranges', soldNum: 8 }
];
console.log(applesMinusOranges(sales));
from collections import defaultdict
from dataclasses import dataclass
from datetime import date

@dataclass(frozen=True)
class Sale:
    sale_date: date
    fruit: str
    sold_num: int

def apples_minus_oranges(sales: list[Sale]) -> list[tuple[date, int]]:
    totals: dict[date, int] = defaultdict(int)
    for sale in sales:
        sign = 1 if sale.fruit == "apples" else -1
        totals[sale.sale_date] += sign * sale.sold_num
    return sorted(totals.items())

if __name__ == "__main__":
    rows = [
        Sale(date(2020, 5, 1), "apples", 10),
        Sale(date(2020, 5, 1), "oranges", 8),
    ]
    print(apples_minus_oranges(rows))
#include <iostream>
#include <map>
#include <string>
#include <vector>
using namespace std;

struct Sale {
    string saleDate;
    string fruit;
    int soldNum;
};

vector<pair<string, int>> applesMinusOranges(const vector<Sale>& sales) {
    map<string, int> totals;
    for (const Sale& sale : sales) {
        totals[sale.saleDate] += sale.fruit == "apples"
                ? sale.soldNum : -sale.soldNum;
    }
    return {totals.begin(), totals.end()};
}

int main() {
    vector<Sale> sales = {
        {"2020-05-01", "apples", 10},
        {"2020-05-01", "oranges", 8}
    };
    for (const auto& [date, diff] : applesMinusOranges(sales)) {
        cout << date << " " << diff << '\n';
    }
    return 0;
}

常见错误

  • 忘记给桔子销量加负号，算成总销量。
  • 用 WHERE 过滤掉一种水果，导致无法相减。
  • 按水果分组，结果变成每日期两行。
  • 使用输入顺序代替显式日期排序。
  • 将差值绝对值化，丢失“桔子更多”的信息。
