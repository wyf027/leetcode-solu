二进制求和

给你两个二进制字符串 a 和 b，以二进制字符串形式返回它们的和。把十进制竖式加法的“从低位到高位 + 进位”规则原样搬过来即可。

可视化实验台

从右向左，逐位相加

准备开始

仅输入 0 和 1；空输入会被当作 0。

核心不变量

  1. 1指针 i、j 始终指向尚未处理的最低位。
  2. 2carry 只可能是 0 或 1，携带上一列的进位。
  3. 3每轮把 sum % 2 放入答案，再令 carry = sum / 2。

复杂度

时间
O(max(m,n))
额外空间
O(max(m,n))

答案长度最多比两个输入的较长者多 1 位。倒序追加后统一反转，避免频繁头插。

边界检查

  • • 长度不同：越界的一方按 0 处理。
  • • 最后一位仍有进位：循环条件必须包含 carry。
  • • 例如 111 + 1 = 1000，答案需要多一位。

class Solution {
  public String addBinary(String a, String b) {
    StringBuilder answer = new StringBuilder();
    int i = a.length() - 1, j = b.length() - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry != 0) {
      int sum = carry;
      if (i >= 0) sum += a.charAt(i--) - '0';
      if (j >= 0) sum += b.charAt(j--) - '0';
      answer.append(sum % 2);
      carry = sum / 2;
    }
    return answer.reverse().toString();
  }
}

var addBinary = function (a, b) {
  let i = a.length - 1, j = b.length - 1, carry = 0;
  const answer = [];
  while (i >= 0 || j >= 0 || carry) {
    const sum = carry + (i >= 0 ? Number(a[i--]) : 0) + (j >= 0 ? Number(b[j--]) : 0);
    answer.push(sum % 2);
    carry = Math.floor(sum / 2);
  }
  return answer.reverse().join('');
};
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        i, j, carry = len(a) - 1, len(b) - 1, 0
        answer = []
        while i >= 0 or j >= 0 or carry:
            total = carry
            if i >= 0:
                total += int(a[i])
                i -= 1
            if j >= 0:
                total += int(b[j])
                j -= 1
            answer.append(str(total % 2))
            carry = total // 2
        return ''.join(reversed(answer))
class Solution {
public:
  string addBinary(string a, string b) {
    string answer;
    int i = a.size() - 1, j = b.size() - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry) {
      int sum = carry;
      if (i >= 0) sum += a[i--] - '0';
      if (j >= 0) sum += b[j--] - '0';
      answer.push_back('0' + sum % 2);
      carry = sum / 2;
    }
    reverse(answer.begin(), answer.end());
    return answer;
  }
};
