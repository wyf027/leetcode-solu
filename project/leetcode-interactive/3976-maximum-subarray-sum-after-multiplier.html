乘以系数后最大子数组和

一次操作区间与最终求和区间可以不同。把“操作前 / 操作中 / 操作后”变成 3 条并行的 DP 轨道。

O(n) 时间 · O(1) 额外空间
可乘 k 或按题意向零截断除以 k

题意

先选一个连续区间，再求变换后任意非空子数组的最大和

给定 nums 与正整数 k，必须选择一个非空连续区间，选择其一：每个元素乘 k，或按向零截断规则除以 k。随后从结果数组选任意非空连续子数组，返回最大可能和。

示例 1

nums = [1, -2, 3, 4, -5]
k = 2

乘 [3, 4]，最大和为 14。

示例 2

nums = [-5, -4, -3]
k = 2

除 [-3] 得 -1，答案为 -1。

约束

1 ≤ nums.length ≤ 10⁵； -10⁵ ≤ nums[i] ≤ 10⁵；1 ≤ k ≤ 10⁵

三段式直觉

  1. 0前缀轨道：还没让最终子数组碰到操作区间。
  2. 1变换轨道：当前元素属于被乘/除的区间。
  3. 2后缀轨道：操作区间已结束，继续原数累加。

不要把“操作区间”和“最终最大和区间”强行绑定为同一段；三轨 DP 正是在表达它们可以错开。

核心洞察与完整过程

分别对“全乘”和“全除”运行一次三状态 Kadane。对当前位置 x，A 是操作尚未开始的最佳和，B 是操作正在覆盖当前位置的最佳和，C 是操作已经结束的最佳和。每一步只保留上一列，所以空间是 O(1)。 

A' = max(x, A + x)
B' = max(f(x), A + f(x), B + f(x))
C' = max(B + x, C + x)
ans = max(ans, B', C')

边界

  • 答案子数组必须非空，初值用负无穷而非 0。
  • 负数除法按题意向零截断；Java/C++/JS/Python 的整数处理需显式一致。
  • k = 1 时两个运算都不改变数值，DP 仍成立。

复杂度与替代方案

两次线性扫描：O(n) 时间、O(1) 空间。枚举操作区间再 Kadane 为 O(n²)，在 10⁵ 规模不可用。也可写成前后缀 DP 数组，逻辑直观但用 O(n) 空间。

面试追问 / 常见错误

追问：若允许两次操作，可把阶段数扩展。错误：只对操作区间求最大和；漏掉“操作结束后继续接原数”；把负数除法写成数学 floor；用 32 位整数累计。
