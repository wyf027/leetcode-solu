跳跃游戏 IV

在相邻移动与“相同数值传送”之间，找出抵达数组末端所需的最少跳跃次数。

困难广度优先搜索数组哈希表非付费题
Problem

题目描述

函数签名：minJumps(arr)，返回整数。

给定整数数组 arr，你从下标 0 出发。每次可以执行以下一种合法跳跃：

1向右一步跳到 i + 1，且 i + 1 < arr.length
2向左一步跳到 i - 1，且 i - 1 ≥ 0
3同值传送跳到 j，且 arr[i] = arr[j]、i ≠ j

请返回到达最后一个下标 arr.length - 1 的最少操作次数。任何时候都不能跳出数组边界。

示例 1

输入：arr = [100,-23,-23,404,100,23,23,23,3,404]
输出：3
解释：0 → 4 → 3 → 9

示例 2

输入：arr = [7]
输出：0
解释：起点已经是终点

示例 3

输入：arr = [7,6,9,6,9,6,9,7]
输出：1
解释：0 可直接传送到 7
  • 1 ≤ arr.length ≤ 5 × 10⁴
  • -10⁸ ≤ arr[i] ≤ 10⁸

Full Solution

哈希表建索引 + 分层广度优先搜索

核心洞察

把每个数组下标看成图节点，三种跳跃就是边。所有边权都为 1，因此从 0 开始的 BFS 第一次到达末尾时，层数就是最少跳跃数。关键优化是：某个数值对应的全部下标只展开一次。

完整过程

  1. 预处理哈希表 value → indices，记录每个数值出现的全部下标。
  2. 队列从下标 0 开始，并用布尔数组或集合记录已访问下标。
  3. 从队首取出 i，依次尝试 i - 1、i + 1，以及与 arr[i] 相等的全部下标；合法且未访问的节点入队。
  4. 展开完同值节点后，立即删除或清空 value → indices 中的这一组。以后再次遇到相同数值时无需重复扫描。
  5. 按层推进；首次发现末尾下标时返回当前距离。

正确性说明

引理 1：BFS 第 d 层恰好包含从 0 经过 d 次跳跃可首次到达的节点。初始层只有 0；若结论对第 d 层成立，枚举该层每个节点的全部合法边，就得到所有能在 d + 1 步到达且此前未到达的节点，因此归纳成立。

引理 2：清空某个数值的索引组不会漏掉更短路径。第一次展开该组时，组内所有未访问节点会同时以当前距离 + 1 入队；以后再扫描同一组，只可能产生已访问节点或不更短的路径。

结论：末尾下标第一次被发现时，其层数是所有可行路径中的最小值，算法返回值正确。

边界情况

  • 数组长度为 1：无需跳跃，直接返回 0。
  • 所有元素相同：起点可一次跳到末尾（长度大于 1 时答案为 1）。
  • 全部元素互不相同：问题退化为沿相邻下标移动。
  • 重复值很多且连续出现：仍必须及时清空索引组，否则会反复扫描并退化。
  • 数值可为负数或很大；它们只作为哈希键，不影响方法。
时间复杂度 O(n)每个下标至多入队一次；每个同值索引组至多完整遍历一次。
空间复杂度 O(n)哈希表、队列与访问标记最多保存线性数量的数据。

替代方案

朴素建图：显式为每对相同值下标连边，最坏会产生 O(n²) 条边，不适合 5 × 10⁴ 的规模。双向 BFS：可以从首尾同时搜索，部分数据上更快，但同值组的全局清理和两侧访问状态更复杂；单向 BFS 已能保证线性复杂度。

面试追问

  • 为什么第一次到达终点就是最短路？
  • 为什么同值列表只需展开一次？
  • 如果每种跳跃代价不同，应换成什么算法？
  • 如何改写成双向 BFS？

常见错误

  • 入队时不标记访问，导致同一节点重复入队。
  • 没有清空同值索引列表，出现平方级扫描。
  • 把 BFS 层数与队列长度混为一谈。
  • 遗漏长度为 1 时答案为 0。

import java.util.*;

class Solution {
    public int minJumps(int[] arr) {
        int n = arr.length;
        if (n == 1) return 0;

        Map<Integer, List<Integer>> positions = new HashMap<>();
        for (int i = 0; i < n; i++) {
            positions.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);
        }

        Queue<Integer> queue = new ArrayDeque<>();
        boolean[] visited = new boolean[n];
        queue.offer(0);
        visited[0] = true;
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            while (size-- > 0) {
                int i = queue.poll();
                if (i == n - 1) return steps;

                List<Integer> next = positions.get(arr[i]);
                next.add(i - 1);
                next.add(i + 1);
                for (int j : next) {
                    if (j >= 0 && j < n && !visited[j]) {
                        if (j == n - 1) return steps + 1;
                        visited[j] = true;
                        queue.offer(j);
                    }
                }
                positions.remove(arr[i]);
            }
            steps++;
        }
        return -1;
    }
}

var minJumps = function(arr) {
    const n = arr.length;
    if (n === 1) return 0;

    const positions = new Map();
    for (let i = 0; i < n; i++) {
        if (!positions.has(arr[i])) positions.set(arr[i], []);
        positions.get(arr[i]).push(i);
    }

    const queue = [0];
    const visited = new Uint8Array(n);
    visited[0] = 1;
    let head = 0;
    let steps = 0;

    while (head < queue.length) {
        const levelEnd = queue.length;
        while (head < levelEnd) {
            const i = queue[head++];
            if (i === n - 1) return steps;

            const next = positions.get(arr[i]) || [];
            next.push(i - 1, i + 1);
            for (const j of next) {
                if (j >= 0 && j < n && !visited[j]) {
                    if (j === n - 1) return steps + 1;
                    visited[j] = 1;
                    queue.push(j);
                }
            }
            positions.delete(arr[i]);
        }
        steps++;
    }
    return -1;
};
from collections import defaultdict, deque
from typing import List

class Solution:
    def minJumps(self, arr: List[int]) -> int:
        n = len(arr)
        if n == 1:
            return 0

        positions = defaultdict(list)
        for i, value in enumerate(arr):
            positions[value].append(i)

        queue = deque([0])
        visited = [False] * n
        visited[0] = True
        steps = 0

        while queue:
            for _ in range(len(queue)):
                i = queue.popleft()
                if i == n - 1:
                    return steps

                next_indices = positions.pop(arr[i], [])
                next_indices.extend((i - 1, i + 1))
                for j in next_indices:
                    if 0 <= j < n and not visited[j]:
                        if j == n - 1:
                            return steps + 1
                        visited[j] = True
                        queue.append(j)
            steps += 1
        return -1
#include <vector>
#include <queue>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int minJumps(vector<int>& arr) {
        int n = static_cast<int>(arr.size());
        if (n == 1) return 0;

        unordered_map<int, vector<int>> positions;
        for (int i = 0; i < n; ++i) positions[arr[i]].push_back(i);

        queue<int> q;
        vector<char> visited(n, false);
        q.push(0);
        visited[0] = true;
        int steps = 0;

        while (!q.empty()) {
            int size = static_cast<int>(q.size());
            while (size--) {
                int i = q.front();
                q.pop();
                if (i == n - 1) return steps;

                vector<int> next = move(positions[arr[i]]);
                positions.erase(arr[i]);
                next.push_back(i - 1);
                next.push_back(i + 1);

                for (int j : next) {
                    if (j >= 0 && j < n && !visited[j]) {
                        if (j == n - 1) return steps + 1;
                        visited[j] = true;
                        q.push(j);
                    }
                }
            }
            ++steps;
        }
        return -1;
    }
};
