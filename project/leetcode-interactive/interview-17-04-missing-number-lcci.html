Problem brief

题意

OFFICIAL

给定整数数组 nums。它本应包含从 0 到 n 的全部整数，其中 n = nums.length，但恰好缺少一个数字。返回这个缺失值，并做到线性时间。

数组顺序任意；答案可能位于区间中间，也可能是边界值 0 或 n。

有效输入与边界
  • nums 中的元素互不相同。
  • 所有元素来自闭区间 [0, n]。
  • 该区间中恰好有一个整数没有出现在数组里。
  • 官方页面未另列数值规模；目标明确要求 O(n) 时间。

官方样例 1

输入nums = [3, 0, 1]
输出2

官方样例 2

输入nums = [9, 6, 4, 2, 3, 5, 7, 0, 1]
输出8

输入采用可直接核对的 参数名 = 值 格式。本题输入不含字符串；若页面出现字符串值，将保留成对直引号，并用 ␠ 表示空格。

Interview solution

题解

O(n) / O(1)

核心洞察

异或满足 x ⊕ x = 0、x ⊕ 0 = x，并且交换、结合顺序不影响结果。把完整编号 0..n 与数组全部异或，出现过的数字都会成对消失，只剩缺失值。

完整过程

  1. 令 answer = n，先补入数组下标中没有出现的上界。
  2. 对每个位置 i，执行 answer ^= i ^ nums[i]。
  3. 扫描结束后，所有同时出现在两份清单里的编号都异或为 0。
  4. 返回唯一没有搭档的编号。

边界与复杂度

  • 缺少 0：0 不改变异或值，其他编号仍能成对消失。
  • 缺少 n：初始化放入的 n 没有对应数组值，最终被留下。
  • 时间复杂度 O(n)，额外空间复杂度 O(1)。

替代方案取舍

  • 求和差：公式最直观，使用固定宽度整数时要考虑总和溢出。
  • 排序：扫描相邻值即可，但会把时间提升到 O(n log n)。
  • 哈希集合：线性时间，但需要 O(n) 额外空间。

面试追问

  • 如果缺失两个数字，单个异或值为什么不够？
  • 若数组允许重复，当前不变量会在哪一步失效？
  • 求和法在 JavaScript 中何时需要考虑安全整数上限？

常见错误

  • 把寄存器初始化为 0，却忘了额外异或 n。
  • 循环写成 i <= nums.length，导致访问越界。
  • 误以为异或只适用于有序数组，先做了不必要的排序。
  • 用字符运算或字符串拼接代替整数位运算。
class Solution {
    public int missingNumber(int[] nums) {
        int answer = nums.length;
        for (int i = 0; i < nums.length; i++) {
            answer ^= i ^ nums[i];
        }
        return answer;
    }
}
var missingNumber = function (nums) {
    let answer = nums.length;
    for (let i = 0; i < nums.length; i++) {
        answer ^= i ^ nums[i];
    }
    return answer;
};
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        answer = len(nums)
        for i, value in enumerate(nums):
            answer ^= i ^ value
        return answer
