LeetCode 1366 · Rank Teams by Votes

通过投票
对团队排名

一张选票表达完整偏好，所有选票共同决定名次。真正棘手的不是计票，而是在多层并列中，按规则稳定地找到下一个判断依据。

输入：String[] votes 输出：String 团队数最多 26 投票人数最多 1000

Problem brief

题意与排名规则

每位投票者用一个字符串，按从高到低列出所有参赛团队。给定字符串数组 votes，需要返回按照下面规则排好序的团队字符串。

01

先看第一名票

第一名票更多的团队排在前面。这是最高优先级，后面的票数无法推翻它。

02

并列就逐位比较

第一名票相同，再比较第二名票；仍相同就继续向后，直到出现差异。

03

完全相同按字母

若所有位置票数都相同，则团队字母较小者排在前面。

Official examples

完整示例

示例 1

输入：votes = ["ABC","ACB","ABC","ACB","ACB"]
输出："ACB"

A 获得 5 张第一名票。B 与 C 的第二名票分别为 2 和 3，因此 C 排在 B 前面。

示例 2

输入：votes = ["WXYZ","XYZW"]
输出："XWYZ"

X 与 W 的第一名票相同，但 X 有一张第二名票，W 没有，所以 X 更靠前。

示例 3

输入：votes = ["ZMNAGUEDSJYLBOPHRQICWFXTVK"]
输出："ZMNAGUEDSJYLBOPHRQICWFXTVK"

只有一位投票者，最终排名就是这张选票本身。

Constraints

约束

  • 1 ≤ votes.length ≤ 1000
  • 1 ≤ votes[i].length ≤ 26
  • 所有 votes[i] 长度相同。
  • votes[i][j] 是大写英文字母。
  • 每张选票内的团队字母互不重复。
  • 第一张选票出现的所有团队，也恰好出现在每一张其他选票中。

Complete solution

计数向量 + 字典序比较

把每支团队的表现压缩成一个长度为团队数的计数向量。向量从左到右依次表示第一名票、第二名票……比较团队时，从左到右寻找第一个不同的计数，票数多者优先。

核心洞察

规则本身就是一个多关键字排序：第 1 位票数降序、第 2 位票数降序……最后团队字母升序。

状态表示

count[team][position] 记录某团队被投到该位置的次数，最多只需 26 × 26 个整数。

排序准则

逐列比较两个团队的计数；首个不同位置票数更多者靠前。全部相同则直接比较字母。

完整过程

  1. 团队集合可直接从 votes[0] 取得，因为每张票包含相同团队。
  2. 创建二维计数表；遍历每张选票和其中每个位置，把对应团队、对应位置的计数加一。
  3. 对团队字符排序。比较两个团队时，从第一名票开始逐位比较计数，首个差异决定顺序。
  4. 如果整条计数向量完全相同，按团队字母升序打破平局。
  5. 将排序后的团队字符拼接成答案。

正确性证明

引理 1：计数表准确记录了每支团队在每个名次获得的票数。因为算法恰好遍历每张选票的每个位置，并对唯一对应的团队与位置加一。

引理 2：比较器对任意两支团队给出的先后关系与题目规则一致。若两队存在票数不同的位置，比较器选择最靠前的该位置，并让票数更多者优先；这正是题目逐名次打破平局的规则。若不存在差异，比较器按字母升序，也与最终规则一致。

结论：排序过程对每一对团队都采用题目规定的先后关系，因此拼接后的团队序列就是题目要求的唯一排名。

边界情况

  • 只有一支团队：无需真正比较，直接返回该字母。
  • 只有一张选票：每个位置都有唯一的一票，结果等于原选票。
  • 多支团队所有位置计数都相同：必须使用字母序，不能依赖排序稳定性。
  • 最多 26 支团队、1000 张票：计数值用普通 32 位整数足够。

复杂度

时间 · O(V × T + T² log T)
V 为票数、T 为团队数。计数是 O(VT)，每次排序比较最坏检查 T 个位置。
空间 · O(T²)
为每支团队保存长度为 T 的位置计数向量；T 最大为 26。

替代方案

可以把每个位置计数编码进一个大整数或字符串排序键，但整数方案容易溢出，字符串方案还要处理定长编码。直接保留计数向量最清晰，也最不容易出错。也可以预先构造负计数元组作为排序键；这在 Python 中很简洁，本质仍是同一算法。

import java.util.*;

class Solution {
    public String rankTeams(String[] votes) {
        int teamCount = votes[0].length();
        int[][] count = new int[26][teamCount];

        for (String vote : votes) {
            for (int position = 0; position < teamCount; position++) {
                count[vote.charAt(position) - 'A'][position]++;
            }
        }

        Character[] teams = new Character[teamCount];
        for (int i = 0; i < teamCount; i++) {
            teams[i] = votes[0].charAt(i);
        }

        Arrays.sort(teams, (a, b) -> {
            for (int position = 0; position < teamCount; position++) {
                int aVotes = count[a - 'A'][position];
                int bVotes = count[b - 'A'][position];
                if (aVotes != bVotes) {
                    return Integer.compare(bVotes, aVotes);
                }
            }
            return Character.compare(a, b);
        });

        StringBuilder answer = new StringBuilder();
        for (char team : teams) answer.append(team);
        return answer.toString();
    }
}

var rankTeams = function(votes) {
    const teamCount = votes[0].length;
    const count = new Map();

    for (const team of votes[0]) {
        count.set(team, Array(teamCount).fill(0));
    }

    for (const vote of votes) {
        for (let position = 0; position < teamCount; position++) {
            count.get(vote[position])[position]++;
        }
    }

    return [...votes[0]]
        .sort((a, b) => {
            for (let position = 0; position < teamCount; position++) {
                const difference = count.get(b)[position] - count.get(a)[position];
                if (difference !== 0) return difference;
            }
            return a.charCodeAt(0) - b.charCodeAt(0);
        })
        .join("");
};
from typing import List


class Solution:
    def rankTeams(self, votes: List[str]) -> str:
        team_count = len(votes[0])
        count = {team: [0] * team_count for team in votes[0]}

        for vote in votes:
            for position, team in enumerate(vote):
                count[team][position] += 1

        def ranking_key(team: str):
            return tuple(-value for value in count[team]) + (team,)

        return "".join(sorted(votes[0], key=ranking_key))
class Solution {
public:
    string rankTeams(vector<string>& votes) {
        int teamCount = votes[0].size();
        vector<vector<int>> count(26, vector<int>(teamCount, 0));

        for (const string& vote : votes) {
            for (int position = 0; position < teamCount; ++position) {
                ++count[vote[position] - 'A'][position];
            }
        }

        string teams = votes[0];
        sort(teams.begin(), teams.end(), [&](char a, char b) {
            for (int position = 0; position < teamCount; ++position) {
                int aVotes = count[a - 'A'][position];
                int bVotes = count[b - 'A'][position];
                if (aVotes != bVotes) return aVotes > bVotes;
            }
            return a < b;
        });
        return teams;
    }
};

面试追问

为什么不能只统计第一名票？

因为第一名票可能相同，题目要求继续比较第二名、第三名，直到分出先后。

比较器满足传递性吗？

满足。它等价于对固定长度键进行字典序比较：负计数向量后接团队字母。

若团队名不是单个大写字母？

把数组索引改为哈希表，最终平局时按题目规定的团队标识比较即可。

票单流式到达怎么办？

计数表可增量更新；需要展示排名时再排序，或用有序结构维护，但更新代价会增加。

常见错误

  • 把较少的票数排在前面，写反降序比较方向。
  • 只比较某一个位置，没有在平票时继续检查下一位置。
  • 所有位置都相同时返回 0，却遗漏字母序兜底。
  • 用加权总分代替逐位比较；较低名次的累计分可能错误地压过高优先级名次。
  • 在比较器内部重复统计票数，导致不必要的高复杂度。
