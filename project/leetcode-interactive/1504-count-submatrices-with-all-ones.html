子矩形

给定一个 m × n 的二进制矩阵 mat，返回其中元素全部为 1 的非空轴对齐子矩形数量。

输入mat: integer[][]
输出一个整数，表示全 1 子矩形总数
注意位置不同的相同尺寸矩形分别计数

先读懂样例，再向下进入逐步推演；核心解法默认收起。

核心洞察

固定子矩形的底边为第 r 行。把每一列向上连续的 1 的个数记为 height[j]，问题就变成：求柱状图所有连续区间的最小高度之和。

endingAt(j) = Σ min(height[l..j])，0 ≤ l ≤ j

单调递增栈把相同“当前最小高度”的区间合并为 [高度, 区间数量]，从而在线性时间内算完一行。

完整过程

  1. 逐行扫描；遇到 1 就令该列高度加一，遇到 0 就清零。
  2. 对当前高度数组从左到右扫描，维护严格递增的高度栈。
  3. 新高度 h 不大于栈顶时弹栈；弹出的区间都被 h 接管。
  4. 维护 sum：以当前列为右端点、当前行为底边的全 1 矩形数。
  5. 每处理一列把 sum 加入总答案。

正确性说明

高度等价：固定底边后，连续列区间能向上延伸的最大高度，正是该区间柱高最小值，因此每个“底边 + 左右边界 + 高度”唯一对应一个全 1 子矩形。

栈不漏不重：栈中每组记录一批左端点，它们在当前右端点下拥有相同最小高度。弹栈只会在更矮柱出现时把这些左端点合并到新最小值；每个左端点始终属于恰好一组。

求和完备：每列的 sum 枚举该列作为右边界的全部矩形；再枚举行和列，所有矩形恰好计数一次。

边界与复杂度

  • 全 0：所有高度与贡献始终为 0。
  • 单行：退化为统计所有连续 1 子数组。
  • 单列：高度依次贡献以当前行为底的矩形数。
  • 相等高度使用 >= 弹栈并合并，避免重复分组。

时间：O(mn)，每个柱子每行至多入栈、出栈一次。
空间：O(n)。

替代方案

可先计算每格向左连续 1 的宽度，再固定底边向上枚举行，维护最小宽度并累加。实现直观，但最坏时间为 O(m²n)。也可枚举左右边界检查连续有效行，复杂度通常为 O(mn²)。

面试追问与常见错误

  • 为何是区间最小值？最矮列限制矩形能向上延伸的高度。
  • 能否原地复用矩阵？可以，但会修改输入；一维高度数组更稳妥。
  • 常见错误：只加每个柱高，漏掉跨列矩形；遇 0 忘记清高度；弹栈时只减高度、不乘该组宽度；累计了整行贡献却忘记逐列加答案。

class Solution {
    public int numSubmat(int[][] mat) {
        int rows = mat.length, cols = mat[0].length;
        int[] height = new int[cols];
        int answer = 0;

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                height[c] = mat[r][c] == 0 ? 0 : height[c] + 1;
            }

            int[][] stack = new int[cols][2]; // [height, count]
            int top = -1, sum = 0;
            for (int h : height) {
                int count = 1;
                while (top >= 0 && stack[top][0] >= h) {
                    sum -= stack[top][0] * stack[top][1];
                    count += stack[top][1];
                    top--;
                }
                stack[++top][0] = h;
                stack[top][1] = count;
                sum += h * count;
                answer += sum;
            }
        }
        return answer;
    }
}

var numSubmat = function(mat) {
    const rows = mat.length;
    const cols = mat[0].length;
    const height = Array(cols).fill(0);
    let answer = 0;

    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            height[c] = mat[r][c] === 0 ? 0 : height[c] + 1;
        }

        const stack = []; // [height, count]
        let sum = 0;
        for (const h of height) {
            let count = 1;
            while (stack.length && stack[stack.length - 1][0] >= h) {
                const [oldHeight, oldCount] = stack.pop();
                sum -= oldHeight * oldCount;
                count += oldCount;
            }
            stack.push([h, count]);
            sum += h * count;
            answer += sum;
        }
    }
    return answer;
};
from typing import List


class Solution:
    def numSubmat(self, mat: List[List[int]]) -> int:
        rows, cols = len(mat), len(mat[0])
        height = [0] * cols
        answer = 0

        for r in range(rows):
            for c in range(cols):
                height[c] = 0 if mat[r][c] == 0 else height[c] + 1

            stack = []  # [height, count]
            current_sum = 0
            for h in height:
                count = 1
                while stack and stack[-1][0] >= h:
                    old_height, old_count = stack.pop()
                    current_sum -= old_height * old_count
                    count += old_count
                stack.append((h, count))
                current_sum += h * count
                answer += current_sum

        return answer
class Solution {
public:
    int numSubmat(vector<vector<int>>& mat) {
        int rows = mat.size(), cols = mat[0].size();
        vector<int> height(cols, 0);
        int answer = 0;

        for (int r = 0; r < rows; ++r) {
            for (int c = 0; c < cols; ++c) {
                height[c] = mat[r][c] == 0 ? 0 : height[c] + 1;
            }

            vector<pair<int, int>> stack; // {height, count}
            int sum = 0;
            for (int h : height) {
                int count = 1;
                while (!stack.empty() && stack.back().first >= h) {
                    sum -= stack.back().first * stack.back().second;
                    count += stack.back().second;
                    stack.pop_back();
                }
                stack.push_back({h, count});
                sum += h * count;
                answer += sum;
            }
        }
        return answer;
    }
};
