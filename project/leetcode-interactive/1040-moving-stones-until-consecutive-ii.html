移动石子直到连续 II

Moving Stones Until Consecutive II

MEDIUM · 免费题

先把石子真的“摆”到数轴上：最大次数在数空位，最小次数在寻找一段已经最拥挤的长度为 n 的窗口。先探索动画，再决定是否展开完整题解。

题目

给定互不相同的整数数组 stones，表示 X 轴上的石子位置。每次只能拿走当前最左或最右的端点石子，并把它放到未占用的位置；移动后，这颗石子不能仍是端点。所有石子占据连续整数位置时结束。返回 [最少移动次数, 最大移动次数]。

例如 [1,2,5] 中不能把 5 移到 3：移动后 3 仍是最右端点，因此这一步不合法。

示例 1

输入：stones = [7,4,9]
输出：[1,2]
解释：最少可移动 4 → 8；最多可依次移动 9 → 5、4 → 6。

示例 2

输入：stones = [6,5,4,3,10]
输出：[2,3]
解释：最少可移动 3 → 8，再移动 10 → 7。
最多可移动 3 → 7、4 → 8、5 → 9。
10 → 2 不合法，因为 2 仍会是端点。

约束

  • 3 ≤ stones.length ≤ 10⁴
  • 1 ≤ stones[i] ≤ 10⁹
  • 所有 stones[i] 互不相同。

完整题解

核心洞察

先排序为 a，令石子数为 n。最大次数的目标是故意慢慢填空：最终一定要舍弃最左端间隔或最右端间隔之一，因此：

max = max(a[n−2] − a[0], a[n−1] − a[1]) − (n−2)

最小次数等价于找一个跨度不超过 n−1（即能装进连续 n 个坐标）的窗口，保留窗口内尽可能多的石子，其余石子各移动一次。用双指针求窗口最大石子数。

特殊局面

若窗口里恰有 n−1 颗石子，但其跨度只有 n−2（它们已经连续），孤立端点不能一步塞到唯一空位，因为移动后仍会成为端点；此时必须绕一步，所以候选答案是 2，而不是 1。

完整过程

  1. 升序排序。
  2. 用公式计算最大次数。
  3. 右指针逐个扩张；当 a[right] − a[left] + 1 > n 时移动左指针。
  4. 窗口大小为 inside。一般候选值是 n − inside；命中特殊局面则为 2。
  5. 取所有窗口候选值的最小值。

正确性说明

最小值：任意最终连续区间长度为 n，原本落在其中的石子可保留，区间外每颗石子至少移动一次；滑动窗口枚举了所有可作为最终区间核心的最大集合，所以一般情况下界可达到。唯一的一步不可达情况正是 n−1 颗已连续、另一颗孤立，规则迫使两步完成，单独修正即可。

最大值：最终过程必须保留左侧第二颗或右侧倒数第二颗作为一端；两种选择可填的内部空位分别对应公式两项。选择空位更多的一侧，并从远端逐次合法搬入，可以逐个填满，因此该上界可达到。

边界与复杂度

  • 已经连续时返回 [0,0]。
  • 坐标可达 10⁹，算法只比较差值，不创建巨大数轴数组。
  • 排序耗时 O(n log n)，窗口扫描 O(n)；除排序所需空间外为 O(1)。

替代方案与面试追问

暴力枚举最终区间并逐个计数会达到 O(n²)；二分搜索每个左端对应的右端可做到 O(n log n)，但双指针更直接。追问可包括：为何窗口跨度条件是 < n？为何最大值只舍弃首尾两段之一？如何构造达到最大次数的具体移动序列？

常见错误

  • 漏掉 n−1 颗连续石子的特殊两步局面。
  • 把窗口条件写成 a[r]−a[l]≤n，产生一位偏差。
  • 最大值直接用总空位，忘记必须舍弃一个端点间隔。
  • 模拟所有坐标，导致坐标范围 10⁹ 时内存爆炸。

import java.util.Arrays;

class Solution {
    public int[] numMovesStonesII(int[] stones) {
        Arrays.sort(stones);
        int n = stones.length;
        int maxMoves = Math.max(stones[n - 2] - stones[0],
                                stones[n - 1] - stones[1]) - (n - 2);
        int minMoves = n, left = 0;
        for (int right = 0; right < n; right++) {
            while (stones[right] - stones[left] + 1 > n) left++;
            int inside = right - left + 1;
            if (inside == n - 1 && stones[right] - stones[left] == n - 2)
                minMoves = Math.min(minMoves, 2);
            else
                minMoves = Math.min(minMoves, n - inside);
        }
        return new int[]{minMoves, maxMoves};
    }
}
