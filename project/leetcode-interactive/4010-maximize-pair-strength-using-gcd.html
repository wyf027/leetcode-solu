4010. 数对的最大强度

在数组中选两个不同下标，数对强度定义为两数的最大公约数；求可取得的最大强度。

打开题目

题意与例子

给定正整数数组 nums。选择 i ≠ j，该数对的强度为 gcd(nums[i], nums[j])。返回所有合法数对中最大的强度。

输入 可选最佳数对 答案
[12, 18, 6, 25] (12, 18)，gcd = 6 6
[7, 7, 10] (7, 7)，下标不同 7

先排除的误区

  • 不能只取数组最大两个数：数值大不代表公约数大。
  • 相同值可以配对，但必须来自两个不同下标，因此需要出现至少两次。
  • 不必枚举全部 n² 个数对；问题的真正候选是“某个 GCD 值”。

可见交互：试一组数字

例如：12, 18, 6, 25。按 Enter 也可计算。

输入数组后点击“计算最大强度”。

洞察：从“选数对”改为“试 GCD”

1. 候选上界

设 M = max(nums)。答案一定在 1 到 M 之间，且只需从大到小找第一个可行值。

2. 可行性

若有至少两个数组元素是 g 的倍数，则它们的 GCD 至少含有 g；该 g 可作为答案下界。

3. 单调停止

倒序枚举 g，第一个拥有两项倍数的 g 就是最大强度，无需再看更小的值。

边界：数组少于两个元素没有合法数对（题目通常保证至少两个）；所有数为正整数；重复的 x 会在检查 g=x 时贡献两次。复杂度：用频次数组枚举倍数，时间为 O(M log M + n)，空间 O(M)。若 M 极大而 n 很小，可改为逐对计算 O(n² log V)；这里的倍数枚举更适合数值上界可控的题设。

题解与四语言实现

默认折叠，先自行推导再展开核对。

  1. 统计每个值出现次数。
  2. 从 M 倒数到 1；扫描其倍数并累计出现次数。
  3. 累计到 2 时立即返回当前 g。
class Solution {
    public int maxPairStrength(int[] nums) {
        int max = 0;
        for (int x : nums) max = Math.max(max, x);
        int[] count = new int[max + 1];
        for (int x : nums) count[x]++;
        for (int g = max; g >= 1; g--) {
            int seen = 0;
            for (int multiple = g; multiple <= max; multiple += g) {
                seen += count[multiple];
                if (seen >= 2) return g;
            }
        }
        return 0;
    }
}
function maxPairStrength(nums) {
  const max = Math.max(...nums);
  const count = Array(max + 1).fill(0);
  for (const x of nums) count[x]++;
  for (let g = max; g >= 1; g--) {
    let seen = 0;
    for (let multiple = g; multiple <= max; multiple += g) {
      seen += count[multiple];
      if (seen >= 2) return g;
    }
  }
  return 0;
}
class Solution:
    def maxPairStrength(self, nums: list[int]) -> int:
        maximum = max(nums)
        count = [0] * (maximum + 1)
        for x in nums:
            count[x] += 1
        for g in range(maximum, 0, -1):
            seen = 0
            for multiple in range(g, maximum + 1, g):
                seen += count[multiple]
                if seen >= 2:
                    return g
        return 0
