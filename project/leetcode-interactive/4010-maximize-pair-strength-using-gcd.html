4010. 数对的最大强度

选择恰好一对不同下标，去掉两数共同的质因子后，谁的乘积最大？

打开题目

题意与例子

给定整数数组 nums，选恰好一对不同下标 i、j。令 g = gcd(nums[i], nums[j])，数对强度为 (nums[i] * nums[j]) / g²，返回最大强度。

输入 最佳数对 强度
nums = [2, 3, 5] (3, 5)，gcd = 1 15 / 1 = 15
nums = [4, 6, 8] (6, 8)，gcd = 2 48 / 4 = 12
nums = [3, 3] (3, 3)，gcd = 3 9 / 9 = 1

约束：2 ≤ nums.length ≤ 2000，1 ≤ nums[i] ≤ 10⁵。结果最高约为 10¹⁰，Java/C++ 需使用 64 位整数。

可见交互：枚举一对数

字符串中的空格仅用于分隔；按 Enter 或按钮计算。

输入数组后点击“计算最大强度”。

算法对拍：对小数组逐对计算公式；主算法同样枚举所有 i < j，因此每个测试行都由页面的真实实现计算。

题解与四语言实现

默认折叠；先自己推导，再展开核对。

1. 直接枚举

n ≤ 2000，数对最多约两百万个，逐对检查完全可行。

2. 每对求 gcd

欧几里得算法得到 g，再算 (a / g) * (b / g)，先除后乘避免不必要的中间放大。

3. 保留最大值

遍历所有 i < j，将最大 64 位强度作为答案。

完整过程：对 [4, 6, 8]： (4,6) 的强度为 6，(4,8) 为 2，(6,8) 为 12，所以答案是 12。
边界与常见错误：相同值的数对强度为 1；下标必须不同；不要误把答案当作最大的 gcd；乘积不能放在 Java int 或 C++ int 中。
复杂度：时间 O(n² log V)，空间 O(1)（除输入外）。替代方案是先质因数分解再约分，但在此约束下实现更复杂且没有必要。面试追问：若 n 进一步增大，应基于值域与质因子分布重新设计计数方案。 
class Solution {
    public long maxStrength(int[] nums) {
        long best = 0;
        for (int i = 0; i < nums.length; i++) {
            for (int j = i + 1; j < nums.length; j++) {
                long g = gcd(nums[i], nums[j]);
                best = Math.max(best, (nums[i] / g) * (nums[j] / g));
            }
        }
        return best;
    }

    private long gcd(long a, long b) {
        while (b != 0) { long t = a % b; a = b; b = t; }
        return a;
    }
}
