01 / 题目

先把“不同”定义清楚

子序列允许删除任意数量的字符，但保留下来的相对顺序不能改变；答案按字符序列去重，而不是按下标选择方案去重。

题意

给定字符串 s，返回其中不同的非空回文子序列数量。由于答案可能很大，结果需要对 10^9 + 7 取余。

删除零个或多个字符即可得到子序列。若某个字符序列正着读与反着读相同，它就是回文序列。两个结果只要在任一位置上的字符不同，就视为不同；由不同下标产生的同一字符序列仍然只算一个。

示例 1

输入：s = "bccb"
输出：6
解释：不同的非空回文子序列为
"b", "c", "bb", "cc", "bcb", "bccb"。
"bcb" 虽有两种下标取法，但只计一次。

示例 2

输入：s = "abcdabcdabcdabcdabcdabcdabcdabcddcbadcbadcbadcbadcbadcbadcbadcba"
输出：104860361
解释：不同的非空回文子序列共有
3104860382 个，取模后为 104860361。

完整题解

区间 DP + 同字符去重

关键不在于数出多少种下标选择，而在于当两端字符相同时，识别内部同字符会制造哪些重复结果。

核心洞察

令 dp[i][j] 表示子串 s[i…j] 内不同非空回文子序列的数量。按区间长度从短到长计算。

两端不同就做集合容斥；两端相同则把内部回文两侧包上同一字符，同时根据内部同字符出现 0、1、至少 2 次，分别补 2、补 1、或减去重复区间。

状态转移

若 s[i] != s[j]：
dp[i][j] = dp[i+1][j] + dp[i][j-1] - dp[i+1][j-1]

若 s[i] == s[j]，令 low 为 i 后第一个相同字符，
high 为 j 前最后一个相同字符，inner = dp[i+1][j-1]：
low > high  : dp[i][j] = 2 × inner + 2
low == high : dp[i][j] = 2 × inner + 1
low < high  : dp[i][j] = 2 × inner - dp[low+1][high-1]

完整过程

  1. 预处理每个位置左边、右边最近的相同字符位置，之后每个状态都能 O(1) 找到 low 和 high。
  2. 初始化 dp[i][i] = 1，因为单字符只有它自身这一种非空回文子序列。
  3. 从长度 2 开始枚举区间 [i, j]。
  4. 端点不同时，来自 [i+1,j] 和 [i,j-1] 的结果取并集，交集恰为 [i+1,j-1]。
  5. 端点相同时，内部每个不同回文既可以原样保留，也可以被当前端点包住，因此先得到两倍；再依据内部同端点字符的数量修正新增或重复。
  6. 每次运算后规范到 [0, MOD)，最终返回 dp[0][n-1]。

为什么相同端点有三种情况？

设端点字符为 x。内部没有 x 时，新出现 x 与 xx；只有一个 x 时，只新增 xx（单个 x 已存在）；至少两个时，短包裹结果已在内部出现，需要减掉最内侧两个 x 之间的全部回文。

正确性证明

归纳假设：所有长度小于当前区间的 dp 都准确表示其区间内不同非空回文子序列集合的大小。

端点不同：当前区间的任一回文至少不使用左端点或不使用右端点，因此属于两个较小区间的并集；同时不使用两端点的回文恰被计算两次，减去内部区间后，每个不同回文恰好一次。

端点相同：不同时使用两端点的不同回文由内部集合完整覆盖；同时使用两端点的结果与内部回文一一对应（加上空内部产生的 xx）。按内部 x 的 0、1、至少 2 次分类进行补项或减项，恰好消除与已有 x…x 结果的重叠。

结论：两种端点关系都得到准确集合大小。由区间长度归纳，dp[0][n-1] 即所求。

复杂度

预处理 O(n)，共有 O(n²) 个区间且每个 O(1) 转移，所以时间复杂度为 O(n²)；二维表空间复杂度为 O(n²)。

边界处理

  • 单字符区间固定为 1；空内部区间在公式中按 0 处理。
  • 当 low < high 但二者相邻时，dp[low+1][high-1] 也是空区间，按 0 处理。
  • 减法可能暂时为负；取模时必须先加 MOD 再规范，尤其是 JavaScript、Java 与 C++。
  • 官方约束保证字符串非空且仅含 a、b、c、d；代码仍对空串返回 0，使函数边界更完整。

四语言完整实现

均采用 O(n²) 区间 DP，并用最近同字符位置把转移压到 O(1)。

import java.util.Arrays;

class Solution {
    private static final long MOD = 1_000_000_007L;

    public int countPalindromicSubsequences(String s) {
        int n = s.length();
        if (n == 0) return 0;

        int[] prevSame = new int[n];
        int[] nextSame = new int[n];
        int[] last = new int[4];

        Arrays.fill(last, -1);
        for (int i = 0; i < n; i++) {
            int c = s.charAt(i) - 'a';
            prevSame[i] = last[c];
            last[c] = i;
        }

        Arrays.fill(last, n);
        for (int i = n - 1; i >= 0; i--) {
            int c = s.charAt(i) - 'a';
            nextSame[i] = last[c];
            last[c] = i;
        }

        long[][] dp = new long[n][n];
        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                long value;
                if (s.charAt(i) != s.charAt(j)) {
                    value = dp[i + 1][j] + dp[i][j - 1]
                            - dp[i + 1][j - 1];
                } else {
                    long inner = i + 1 <= j - 1 ? dp[i + 1][j - 1] : 0;
                    int low = nextSame[i];
                    int high = prevSame[j];
                    if (low > high) {
                        value = 2 * inner + 2;
                    } else if (low == high) {
                        value = 2 * inner + 1;
                    } else {
                        long duplicate = low + 1 <= high - 1
                                ? dp[low + 1][high - 1] : 0;
                        value = 2 * inner - duplicate;
                    }
                }
                dp[i][j] = (value % MOD + MOD) % MOD;
            }
        }
        return (int) dp[0][n - 1];
    }
}

    def countPalindromicSubsequences(self, s: str) -> int:
        MOD = 1_000_000_007
        n = len(s)
        if n == 0:
            return 0

        prev_same = [-1] * n
        next_same = [n] * n
        last = [-1] * 4

        for i, ch in enumerate(s):
            c = ord(ch) - ord("a")
            prev_same[i] = last[c]
            last[c] = i

        last = [n] * 4
        for i in range(n - 1, -1, -1):
            c = ord(s[i]) - ord("a")
            next_same[i] = last[c]
            last[c] = i

        dp = [[0] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):
            dp[i][i] = 1
            for j in range(i + 1, n):
                if s[i] != s[j]:
                    value = dp[i + 1][j] + dp[i][j - 1] - dp[i + 1][j - 1]
                else:

替代方案

由于字符集只有 a、b、c、d，也可以定义 dp[c][i][j]：区间内以字符 c 开头并结尾的不同回文数。转移时按端点与 c 的关系分类，再对 4 个字符求和。

它同样可以做到 O(4n²) 时间和 O(4n²) 空间，去重含义直观；但状态维度更高、实现常数更大。暴力枚举所有子序列并用集合去重需要指数级时间与空间，不适合 n = 1000。

面试追问

  • 为什么不能只做普通回文子序列计数？普通计数按选择路径累计，会把字符序列相同但下标不同的结果重复计算。
  • 怎样把找 low / high 从 O(n) 降到 O(1)？分别正向、反向扫描，预处理每个位置最近的相同字符。
  • 空间能否降到 O(n)？端点相同且有多次内部出现时会访问任意子区间，滚动数组不再只依赖相邻层；需要额外结构或改变状态设计，不能直接机械压缩。

常见错误

  • 把下标方案当成不同结果题目按最终字符序列去重，不能用普通“选或不选”DP。
  • 相同端点统一写成 2 × inner + 2内部已出现端点字符时会重复，必须区分 0、1、至少 2 次。
  • 每个状态线性寻找 low / high这样最坏会退化到 O(n³)；n = 1000 时风险明显。
  • 负数直接取模部分语言的负数余数仍为负，要用 (value % MOD + MOD) % MOD。
