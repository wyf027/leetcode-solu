Find All K-Distant Indices in an Array

距离足够近，就有资格入选。先理解“至少存在一个”，再开始探索。

01 / 题目

给定下标从 0 开始的整数数组 nums 和整数 key、k。如果至少存在一个下标 j，同时满足 nums[j] == key 与 |i − j| ≤ k，那么下标 i 就是 K 近邻下标。返回所有这样的下标，按递增顺序排列。

距离比较的是下标，不是元素值；返回的也是下标。

官方示例 1

输入：nums = [3,4,9,1,3,9,5], key = 9, k = 1
输出：[1,2,3,4,5,6]

key 位于下标 2 和 5。下标 1、2、3 到位置 2 的距离不超过 1；下标 4、5、6 到位置 5 的距离不超过 1。下标 0 距离两者都超过 1，因此排除。

官方示例 2

输入：nums = [2,2,2,2,2], key = 2, k = 2
输出：[0,1,2,3,4]

每个位置的值都是 key。选取 j = i 时距离为 0，所以全部下标都满足条件。

约束与接口

  • 1 ≤ nums.length ≤ 1000
  • 1 ≤ nums[i] ≤ 1000
  • key 一定是 nums 中的一个整数。
  • 1 ≤ k ≤ nums.length
findKDistantIndices(nums, key, k) → 整数下标列表

04 / 独立题解

先想一想：多个 key 的范围重叠时，怎样避免重复收集下标？

核心洞察：按顺序追加区间

对于每个满足 nums[j] = key 的位置，合法下标恰好组成闭区间 [max(0, j − k), min(n − 1, j + k)]。答案是这些区间的并集。由于 j 递增，左右端点都不会减小。

使用单调指针 next 保存下次可能追加的起点。遇到新区间时先令 next = max(next, j − k, 0)，再从 next 追加到右端点。已收集的重叠前缀就会自然跳过。

完整过程

  1. 创建空答案，令 next = 0。
  2. 从左到右扫描 j；不是 key 则继续。
  3. 计算裁剪后的左右边界，把 next 移到不小于左边界的位置。
  4. 当 next 不超过右边界时，追加 next 并将其递增。
  5. 扫描结束返回答案，无需排序或集合去重。

示例 1：j = 2 时处理 [1,3]，加入 1、2、3，next 变为 4；j = 5 时处理 [4,6]，加入 4、5、6。重叠示例中 [0,2] 后接 [1,3]，第二轮只追加 3。

正确性

合法性：每个加入的下标都属于某个 key 的裁剪覆盖区间，所以一定满足距离条件。

完整性：归纳假设已完整收集此前区间的并集。当前左端点不会小于前一个左端点；若当前区间与此前覆盖相交，next 之前且属于当前区间的部分已被收集，剩余后缀会全部追加。若不相交，next 跳到新区间左端点后会追加整个新区间。跳过的空隙不会被将来的区间补盖，因为后续左端点不会向左移动。于是每轮结束都完整收集了截至当前的区间并集。

有序且无重复：next 只递增或向右跳，每个追加值严格大于上一个。最终答案恰好包含所有合法下标，并满足递增顺序。

复杂度

外层扫描 n 次；内层累计最多追加 n 次，因为 next 从不回退。总时间 O(n)，返回值之外的辅助空间 O(1)；答案最坏占 O(n) 空间。双层循环并不代表 O(n²)。

边界

n = 1、key 位于两端、连续 key、k = n 均由边界裁剪和单调指针处理。官方保证 key 存在且 k ≥ 1；key 不存在与 k = 0 是扩展输入，不是本题约束内的情况。

JavaScript
/**
 * @param {number[]} nums
 * @param {number} key
 * @param {number} k
 * @return {number[]}
 */
var findKDistantIndices = function(nums, key, k) {
    const ans = [];
    let next = 0;
    for (let j = 0; j < nums.length; j++) {
        if (nums[j] !== key) continue;
        next = Math.max(next, j - k, 0);
        const right = Math.min(nums.length - 1, j + k);
        while (next <= right) ans.push(next++);
    }
    return ans;
};

    public List<Integer> findKDistantIndices(int[] nums, int key, int k) {

        int next = 0;

    }

from typing import List

class Solution:
    def findKDistantIndices(self, nums: List[int], key: int, k: int) -> List[int]:
        ans = []
        next_index = 0
        for j, value in enumerate(nums):
            if value != key:
                continue
            next_index = max(next_index, j - k, 0)
            right = min(len(nums) - 1, j + k)
            while next_index <= right:
                ans.append(next_index)
                next_index += 1
        return ans

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> findKDistantIndices(vector<int>& nums, int key, int k) {
        vector<int> ans;
        int n = static_cast<int>(nums.size());
        int next = 0;
        for (int j = 0; j < n; ++j) {
            if (nums[j] != key) continue;
            next = max(next, max(0, j - k));
            int right = min(n - 1, j + k);
            while (next <= right) ans.push_back(next++);
        }
        return ans;

替代方案

  • 按定义枚举：为每个 i 搜索任意满足条件的 j，找到后加入 i 并 break。时间 O(n²)，辅助空间 O(1)，便于直接理解题意。
  • 差分数组：对每个区间左端 +1、右端后一位 −1，再求前缀和。时间 O(n)，辅助空间 O(n)，还可得到每个位置被覆盖的次数。
  • 最近 key：从左右各扫描一次，保存每个位置到最近 key 的距离，再筛选距离不大于 k 的位置。时间 O(n)，保存距离需要 O(n) 空间。

常见错误

  • 比较元素值之差，或返回元素值而不是下标。
  • 用严格小于 k，漏掉恰好相距 k 的位置。
  • 忘记裁剪到 [0, n − 1]。
  • 每轮把 next 重置为左端点，重复加入已覆盖下标。
  • 发现一个不符合的 j 就排除 i；题目只要求存在一个符合的 j。

面试追问

只需要数量？每轮直接累加未收集后缀的长度，仍是 O(n) 时间、O(1) 辅助空间。

每个 key 半径不同？端点单调性不再保证，可用差分数组，或对区间排序后合并。

能否从最左 key 一直填到最右 key？不能，覆盖区间之间可能有空隙，例如 [0,1] 与 [5,6] 之间的下标并不符合条件。
