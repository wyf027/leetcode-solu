Operating brief

题意

只准使用一个额外临时栈，目标不是每次取最小值时再搜索，而是让“最小值在栈顶”始终成立。

任务

设计 SortedStack，支持 push、pop、peek 与 isEmpty。栈中最小元素必须位于栈顶；空栈 peek 返回 -1。

元素不能复制到数组、堆等其他数据结构中，最多只能使用一个临时栈。

Restricted maintenance manual

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码默认隐藏。

Core insight

把“排序成本”集中到 push，换取三个 O(1) 查询操作

主栈始终保持从顶到底非递减。插入 val 时，先把所有小于 val 的栈顶元素搬到临时栈，再压入 val，最后逐个搬回。搬回动作会恢复原顺序，因此栈顶仍是最小值。

完整过程

  1. 初始化主栈与唯一临时栈。
  2. push(val)：当主栈顶小于 val 时，搬到临时栈。
  3. 把 val 压入主栈，再把临时栈全部搬回。
  4. pop、peek 直接操作主栈顶。
  5. isEmpty 只检查主栈，因为每次 push 结束临时栈必为空。

边界

  • 空栈 pop 不做任何事，peek 返回 -1。
  • 重复值无需移动，仍满足非递减顺序。
  • 递增插入是最坏情况，每次可能搬动已有全部元素。
  • 负数同样适用，比较逻辑与数值范围无关。

复杂度

pushO(n)
popO(1)
peek / emptyO(1)
额外空间O(n)

替代方案

可以让 push O(1)，在 peek/pop 前再整理两个栈，但状态更复杂；最小堆虽然接口高效，却违反“只能使用一个临时栈”的题意。递归插入会借用调用栈，面试中应先确认是否允许。

面试追问

  • 为什么移动条件是 top < val 而不是大于？
  • 如何证明搬回后主栈顺序被恢复？
  • 若要求 push O(1)，你会如何调整不变式？
  • 能否用摊还分析描述双栈延迟整理方案？

常见错误

  • 比较方向写反，最终把最大值放到栈顶。
  • 移动后忘记把临时栈全部恢复，导致查询依赖两个栈。
  • 空栈 peek 抛异常，没有按题意返回 -1。
  • 为了省事使用数组排序或优先队列，违反数据结构限制。

class SortedStack {
    private final java.util.Deque<Integer> stack = new java.util.ArrayDeque<>();
    private final java.util.Deque<Integer> buffer = new java.util.ArrayDeque<>();

    public SortedStack() {}

    public void push(int val) {
        while (!stack.isEmpty() && stack.peek() < val) {
            buffer.push(stack.pop());
        }
        stack.push(val);
        while (!buffer.isEmpty()) {
            stack.push(buffer.pop());
        }
    }

    public void pop() {
        if (!stack.isEmpty()) stack.pop();
    }

    public int peek() {
        return stack.isEmpty() ? -1 : stack.peek();
    }

    public boolean isEmpty() {
        return stack.isEmpty();
    }
}
var SortedStack = function () {
  this.stack = [];
  this.buffer = [];
};

SortedStack.prototype.push = function (val) {
  while (this.stack.length && this.stack[this.stack.length - 1] < val) {
    this.buffer.push(this.stack.pop());
  }
  this.stack.push(val);
  while (this.buffer.length) {
    this.stack.push(this.buffer.pop());
  }
};

SortedStack.prototype.pop = function () {
  if (this.stack.length) this.stack.pop();
};

SortedStack.prototype.peek = function () {
  return this.stack.length ? this.stack[this.stack.length - 1] : -1;
};

SortedStack.prototype.isEmpty = function () {
  return this.stack.length === 0;
};
class SortedStack:
    def __init__(self):
        self.stack = []
        self.buffer = []

    def push(self, val: int) -> None:
        while self.stack and self.stack[-1] < val:
            self.buffer.append(self.stack.pop())
        self.stack.append(val)
        while self.buffer:
            self.stack.append(self.buffer.pop())

    def pop(self) -> None:
        if self.stack:
            self.stack.pop()

    def peek(self) -> int:
        return self.stack[-1] if self.stack else -1

    def isEmpty(self) -> bool:
        return not self.stack
class SortedStack {
private:
    std::stack<int> data;
    std::stack<int> buffer;

public:
    SortedStack() = default;

    void push(int val) {
        while (!data.empty() && data.top() < val) {
            buffer.push(data.top());
            data.pop();
        }
        data.push(val);
        while (!buffer.empty()) {
            data.push(buffer.top());
            buffer.pop();
        }
    }

    void pop() {
        if (!data.empty()) data.pop();
    }

    int peek() {
        return data.empty() ? -1 : data.top();
    }

    bool isEmpty() {
        return data.empty();
    }
};
