通过交换使数组相等的最小花费

数组内部交换免费，真正要付费的只有同下标的跨数组交换。把位置问题降维为每个数的计数差：只要每个差值能被 2 整除，最少花费就是所有正差值的一半。

题意

先忽略位置，再平衡多重集合

给定等长数组 nums1、nums2。同一数组内任选两个位置交换是免费的；同一位置的两个数组元素互换花费 1。求让两个数组最终完全相同的最小花费，无解返回 -1。

示例：nums1 = [10,10]，nums2 = [20,20]，一次跨数组交换后再免费重排，答案为 1。

约束

规模决定做法

  • 2 ≤ n ≤ 8 × 10⁴
  • 1 ≤ nums1[i], nums2[i] ≤ 8 × 10⁴
  • 不能枚举位置交换；一次计数扫描即可。

最小花费

1

Σ max(diff[x], 0) / 2 = 1

步骤 1：统计每个值在两边的计数差。

为什么能免费忽略下标？ 一旦确定每个数组最终该拥有哪些值，数组内部的免费交换就能把它们放到与另一数组相同的位置。因此只需计算每个值有多少个必须跨边移动。

题解

把完整推导放在首屏之后

核心洞察

  1. 令 diff[x] = count(nums1,x) - count(nums2,x)。
  2. 最终每个数组各拿总数的一半，故任一 diff[x] 为奇数时必无解。
  3. diff[x] / 2 表示值 x 多在某一侧、必须跨边移动的个数。
  4. 一次付费跨数组交换同时送走一个正差值和一个负差值，因此答案是 Σ max(diff[x], 0) / 2。

完整过程与边界

扫描两个数组：前者加一、后者减一。遍历哈希表，若差值为奇数立即返回 -1；否则累加所有正差值并除以二。

  • 两个数组已经只是排列不同：所有差值为 0，花费 0。
  • 某值总出现次数为奇数：无法均分到两边，花费 -1。
  • 不依赖原下标；免费重排总能在最后对齐位置。

复杂度、替代方案与面试追问

时间 O(n)，空间 O(k)，k 是不同值的数量。因数值上界为 8×10⁴，也可用整型数组替代哈希表，获得更稳定的常数。

替代方案：先分别统计两个频次表再做差，逻辑更直观但要维护两个容器。追问：若跨数组交换的费用随下标变化，不能再只看频次，需要考虑匹配/最小费用流。

常见错误：把 Σ |diff| 直接当答案（每次配对被算两次）；检查“总频率奇偶”时忘了它等价于 diff 为偶数；误以为必须逐下标修复而忽略免费重排。
