LCR 177 · MEDIUM · 位运算 / 数组

撞色搭配

每种普通颜色有两只，只有一组撞色袜子的两个颜色各出现一次。找出这两个颜色编号，顺序不限。

Medium数组 · 位运算

题意与示例

整数数组 sockets 记录袜子颜色编号。除一双撞色袜子外，每个颜色都恰好出现两次。返回两个只出现一次的编号。

sockets = [4, 5, 2, 4, 6, 6] 输出 = [2, 5] 或 [5, 2]
sockets = [1, 2, 4, 1, 4, 3, 12, 3] 输出 = [2, 12] 或 [12, 2]

约束：2 <= sockets.length <= 10000。空格在输入展示中用 ␠ 表示；本题数组输入没有字符串空格歧义。

袜子配对实验室

先载入完整参数，再逐步观察成对颜色如何抵消、两个撞色编号如何被拆分出来。具体推导与可提交代码统一放在底部隐藏题解中。

支持负数；每个普通编号必须恰好出现两次，恰有两个不同编号只出现一次。

快捷键：←/→ 步进，Space 自动播放；编辑框获得焦点时不会劫持按键。

题解：异或分组，而不是哈希表

核心洞察

  1. 相同数字异或为 0，所有成对编号在总异或中抵消。
  2. 总异或 x = a XOR b 不为 0。
  3. lowbit = x & -x 提取一个差异位。
  4. 按该位分组，两个单例被拆开；每组的成对元素仍在同组抵消。

完整过程

样例一总异或为 7（二进制 111），低位掩码为 1。最低位为 0 的队异或出 2；为 1 的队异或出 5。

边界

两个单例可包含 0 或负数；Java/C++ 的位运算按补码进行，仍成立。题目保证恰有两个不同单例，若交互输入不满足会提示而不伪造答案。

复杂度

两次线性扫描，时间 O(n)，除输出外空间 O(1)。

替代方案与面试追问

哈希表计数可读性好但耗 O(n) 空间；排序后扫描需 O(n log n)。追问“若只有一个单例”则直接全体异或；若其余出现三次则按每一位计数模 3。

常见错误

  • 用 x & (x - 1)：它是清除最低 1，不是掩码。
  • 分组时用不同掩码，或忘记把两个单例分到不同组。
  • 把输出顺序写死；本题两种顺序都正确。

可提交代码

class Solution {
    public int[] sockCollocation(int[] sockets) {
        int xor = 0;
        for (int value : sockets) xor ^= value;
        int lowbit = xor & -xor, first = 0, second = 0;
        for (int value : sockets) {
            if ((value & lowbit) == 0) first ^= value;
            else second ^= value;
        }
        return new int[] {first, second};
    }
}

class Solution {
public:
    vector<int> sockCollocation(vector<int>& sockets) {
        int x = 0, a = 0, b = 0;
        for (int v : sockets) x ^= v;
        int lowbit = x & -x;
        for (int v : sockets) (v & lowbit ? a : b) ^= v;
        return {a, b};
    }
