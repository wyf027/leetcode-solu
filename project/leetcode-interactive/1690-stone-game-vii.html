Interactive problem brief

石子游戏 VII

一排石子，两种选择，一条不断收缩的区间。Alice 想把分差拉大，Bob 想把它压小；双方都不会犯错。你能算出最终分差吗？

Stone Game VII2 ≤ n ≤ 1000非付费题

Problem

题目描述

返回整数

Alice 和 Bob 轮流操作，Alice 先手。桌面上有 n 块石子排成一行，每次只能移除当前最左端或最右端的一块，并立即获得“移除后剩余石子总和”这么多分。

所有石子都被取走后游戏结束。Alice 选择让最终的“自己的总分 − Bob 的总分”尽可能大；Bob 则选择让这个差值尽可能小。给定 stones，返回两人均采用最优策略时的最终得分差。

函数参数： stoneGameVII(stones: integer[]) -> integer
这里比较的是最终得分差，不是最后一手、获胜分数或被移除石子的价值。

Examples

官方示例

示例 1

输入：stones = [5,3,1,4,2]
输出：6
解释：
Alice 移除 2，获得 13 分；Bob 移除 5，获得 8 分；
Alice 移除 3，获得 5 分；Bob 移除 1，获得 4 分；
最后移除 4 得 0 分。最终为 18 − 12 = 6。

示例 2

完整题解

先独立思考，再按需展开推导、证明与代码。

区间 DP：站在当前玩家的视角

核心洞察

不要分别维护 Alice 和 Bob 的分数。令 dp[i][j] 表示只剩 stones[i..j] 时，轮到行动的人相对另一人最多能领先多少分。这样，无论轮到谁，同一个状态定义始终成立。

若移除左端 stones[i]，本回合得分是剩余区间 [i+1, j] 的总和；随后对手能在该区间取得 dp[i+1][j] 的相对优势，所以当前玩家的净优势为：

removeLeft = sum(i+1, j) - dp[i+1][j]
removeRight = sum(i, j-1) - dp[i][j-1]
dp[i][j] = max(removeLeft, removeRight)

完整过程

  1. 用前缀和在 O(1) 时间查询任意区间和。
  2. 单个石子时，移走后剩余和为 0，所以 dp[i][i] = 0。
  3. 按区间长度从 2 到 n 枚举，保证两个更短的依赖状态已经计算。
  4. 取移除左端和右端两种净优势中的较大值。
  5. 答案是完整区间 dp[0][n-1]。

正确性证明

基例：区间只有一块石子时，当前玩家移除它只能得到 0 分，因此双方从该状态起的分差为 0，dp[i][i] = 0 正确。

归纳步骤：假设所有长度小于 L 的区间状态都正确。对长度为 L 的 [i,j]，合法首步只有移除左端或右端。移除左端得到剩余区间和，之后对手在 [i+1,j] 的最优领先恰为归纳假设中的 dp[i+1][j]，所以当前玩家净领先是二者之差；右端同理。当前玩家必选两者较大值，因此递推覆盖全部合法策略并取到最优值，dp[i][j] 正确。由数学归纳法，dp[0][n-1] 即最优最终分差。

边界与复杂度

  • 最小数组：n = 2 时仍直接使用同一递推。
  • 相等石子：两种选择可能并列，取任一端都不影响最优分差。
  • 数值范围：最大总和为 10^6，32 位有符号整数足够。
  • 时间：O(n²)；空间：以下代码用滚动数组压缩到 O(n)。

替代方案

二维 dp[n][n] 更直观，也便于恢复具体操作序列，但空间为 O(n²)。记忆化搜索同样能表达极小化极大过程，却会有递归栈和函数调用开销。若只需要最终答案，一维滚动数组更紧凑。

面试追问

  • 如何记录每个状态选了哪一端，从而恢复一条完整最优对局？
  • 为什么状态要定义为“当前玩家相对对手”的分差，而不是 Alice 的绝对得分？
  • 一维压缩时为什么要按左端点从小到大更新？若反向会覆盖哪个依赖？
  • 如果每次得分改成“被移除石子的值”，状态转移会怎样变化？

常见错误

  • 把本回合得分误写成被移除石子的值。
  • 转移中忘记减去对手在剩余区间的最优优势。
  • 一维 DP 从右向左更新，导致 dp[i+1] 已被本轮覆盖。
  • 区间和左右边界写错；建议统一使用左闭右开前缀和。

class Solution {
    public int stoneGameVII(int[] stones) {
        int n = stones.length;
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + stones[i];
        }

        int[] dp = new int[n];
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len <= n; i++) {
                int j = i + len - 1;
                int removeLeft = prefix[j + 1] - prefix[i + 1] - dp[i + 1];
                int removeRight = prefix[j] - prefix[i] - dp[i];
                dp[i] = Math.max(removeLeft, removeRight);
            }
        }
        return dp[0];
    }
}

from typing import List


class Solution:
    def stoneGameVII(self, stones: List[int]) -> int:
        n = len(stones)
        prefix = [0] * (n + 1)
        for i, value in enumerate(stones):
            prefix[i + 1] = prefix[i] + value

        dp = [0] * n
        for length in range(2, n + 1):
            for i in range(0, n - length + 1):
                j = i + length - 1
                remove_left = prefix[j + 1] - prefix[i + 1] - dp[i + 1]
                remove_right = prefix[j] - prefix[i] - dp[i]
                dp[i] = max(remove_left, remove_right)
        return dp[0]
