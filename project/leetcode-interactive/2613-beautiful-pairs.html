Problem 2613 · 0-indexed arrays

美数对
Beautiful Pairs

两列数字可以看成平面上的点。你的任务不是求最小距离本身，而是找出达到最小值、且原始下标字典序最小的那一对。

Problem statement

题意

给定两个长度相同、下标从 0 开始的整数数组 nums1 和 nums2。对任意 i < j，定义该下标对的值为：

|nums1[i] − nums1[j]| + |nums2[i] − nums2[j]|

在所有合法下标对中，使这个值最小的称为美数对。返回它的两个下标 [i, j]；若有多个答案，返回字典序最小的一对，即先比较 i，再比较 j。

示例 1

输入：nums1 = [1,2,3,2,4]
      nums2 = [2,3,1,2,3]
输出：[0,3]

下标 0 与 3 的值为 |1−2|+|2−2|=1，已经最小。

示例 2

输入：nums1 = [1,2,4,3,2,5]
      nums2 = [1,4,2,3,5,1]
输出：[1,4]

下标 1 与 4 的值为 |2−2|+|4−5|=1。

约束

  • 2 ≤ nums1.length, nums2.length ≤ 10⁵
  • nums1.length == nums2.length
  • 0 ≤ nums1[i] ≤ nums1.length
  • 0 ≤ nums2[i] ≤ nums2.length

Editorial

扫描线 + 两棵线段树

把第 i 项看作点 (x,y)=(nums1[i],nums2[i])，目标就是最小曼哈顿距离；难点是把绝对值拆掉，并始终保留字典序最小的原始下标对。

1. 固定纵向关系

按 y 升序扫描。处理当前点时，树里所有旧点都满足 y旧 ≤ y当前。

2. 只剩两个横向分支

x旧 ≤ x当前 时用 x+y；x旧 ≥ x当前 时用 y−x。

3. 范围最大值

值域恰为 [0,n]。线段树按 x 存“变换值最大、下标最小”的旧点。

核心推导

设当前点为 p=(xp,yp)，旧点为 q=(xq,yq)。扫描顺序保证 yp ≥ yq。

若 xq ≤ xp：dist = (yp + xp) − (yq + xq)

当前项固定，要让距离最小，只需在横坐标范围 [0,xp] 中最大化旧点的 y+x。

若 xq ≥ xp：dist = (yp − xp) − (yq − xq)

同理，在范围 [xp,n] 中最大化旧点的 y−x。两棵线段树分别维护这两个最大值；节点出现同值时保留较小原始下标。

完整过程

  1. 建点并排序。 生成下标 0..n−1，按 (nums2[i], i) 排序，保证过程确定。
  2. 查询左侧。 第一棵树查询横坐标 [0,x]，取最大的 y+x 候选。
  3. 查询右侧。 第二棵树查询横坐标 [x,n]，取最大的 y−x 候选。
  4. 更新答案。 比较距离；距离相同则比较规范化后的 [min(i,j), max(i,j)]。
  5. 再插入当前点。 必须先查询后插入，避免当前点和自己组成距离 0 的假答案。

正确性证明

引理 1：任意两个不同点，按排序顺序后出现的点处理时，先出现的点已经在线段树中。因此每个合法下标对都会在某一步被覆盖。

引理 2：对固定当前点，旧点按 x旧≤x当前 与 x旧≥x当前 分成两类。上面的两个恒等式分别精确等于曼哈顿距离，不是估计值。

引理 3：在每一类中，当前点的变换值固定，所以最大化旧点变换值等价于最小化两点距离。线段树返回该范围的最优旧点；变换值相同时取更小下标，不会丢失字典序更优候选。

结论：每个点处理时得到与所有旧点组成的最优候选，全局再按“距离优先、下标对字典序次优先”合并，最终答案就是题目要求的美数对。

边界情况

  • n=2：唯一一对直接成为答案。
  • 重复点：距离为 0；全局比较仍选最小下标对。
  • 相同 y：排序中的先后不影响距离公式，每对仍被处理一次。
  • 同距离：比较原始下标，而不是排序后位置。
  • x=0 或 x=n：线段树查询端点仍是闭区间。

复杂度

时间：O(n log n)。排序一次，每个点进行常数次线段树查询与更新。

空间：O(n)。排序下标、两组变换值与两棵线段树均为线性空间。

Java · O(n log n)
import java.util.*;

class Solution {
    private int bestDistance;
    private int[] answer;

    public int[] beautifulPair(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int[] plus = new int[n];
        int[] minus = new int[n];
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) {
            plus[i] = nums2[i] + nums1[i];
            minus[i] = nums2[i] - nums1[i];
            order[i] = i;
        }
        Arrays.sort(order, (a, b) -> nums2[a] != nums2[b]
                ? Integer.compare(nums2[a], nums2[b]) : Integer.compare(a, b));

        SegmentTree left = new SegmentTree(n, plus);
        SegmentTree right = new SegmentTree(n, minus);
        bestDistance = Integer.MAX_VALUE;
        answer = new int[]{n, n};

        for (int i : order) {
            int x = nums1[i];
            int j = left.query(0, x);
            if (j != -1) consider(i, j, plus[i] - plus[j]);
            j = right.query(x, n);
            if (j != -1) consider(i, j, minus[i] - minus[j]);
            left.update(x, i);
            right.update(x, i);
        }
        return answer;
    }

    private void consider(int a, int b, int distance) {
        int i = Math.min(a, b), j = Math.max(a, b);
        if (distance < bestDistance ||
            distance == bestDistance &&
            (i < answer[0] || i == answer[0] && j < answer[1])) {
            bestDistance = distance;
            answer = new int[]{i, j};
        }
    }

    private static class SegmentTree {
        private final int size;
        private final int[] tree, score;

        SegmentTree(int n, int[] score) {
            int s = 1;
            while (s < n + 1) s <<= 1;
            size = s;
            tree = new int[size * 2];
            Arrays.fill(tree, -1);
            this.score = score;
        }

        private int better(int a, int b) {
            if (a == -1) return b;
            if (b == -1) return a;
            if (score[a] != score[b]) return score[a] > score[b] ? a : b;
            return Math.min(a, b);
        }

        void update(int position, int index) {
            int p = position + size;
            tree[p] = better(tree[p], index);
            for (p >>= 1; p > 0; p >>= 1)
                tree[p] = better(tree[p << 1], tree[p << 1 | 1]);
        }

        int query(int left, int right) {
            int resultLeft = -1, resultRight = -1;
            for (left += size, right += size; left <= right; left >>= 1, right >>= 1) {
                if ((left & 1) == 1) resultLeft = better(resultLeft, tree[left++]);
                if ((right & 1) == 0) resultRight = better(tree[right--], resultRight);
            }
            return better(resultLeft, resultRight);
        }
    }
}
JavaScript · O(n log n)
class SegmentTree {
  constructor(n, score) {
    this.size = 1;
    while (this.size < n + 1) this.size *= 2;
    this.tree = Array(this.size * 2).fill(-1);
    this.score = score;
  }

  better(a, b) {
    if (a === -1) return b;
    if (b === -1) return a;
    if (this.score[a] !== this.score[b])
      return this.score[a] > this.score[b] ? a : b;
    return Math.min(a, b);
  }

  update(position, index) {
    let p = position + this.size;
    this.tree[p] = this.better(this.tree[p], index);
    for (p = Math.floor(p / 2); p; p = Math.floor(p / 2))
      this.tree[p] = this.better(this.tree[p * 2], this.tree[p * 2 + 1]);
  }

  query(left, right) {
    let a = -1, b = -1;
    for (left += this.size, right += this.size; left <= right;
         left = Math.floor(left / 2), right = Math.floor(right / 2)) {
      if (left % 2 === 1) a = this.better(a, this.tree[left++]);
      if (right % 2 === 0) b = this.better(this.tree[right--], b);
    }
    return this.better(a, b);
  }
}

var beautifulPair = function(nums1, nums2) {
  const n = nums1.length;
  const plus = nums1.map((x, i) => x + nums2[i]);
  const minus = nums1.map((x, i) => nums2[i] - x);
  const order = Array.from({length: n}, (_, i) => i)
    .sort((a, b) => nums2[a] - nums2[b] || a - b);
  const left = new SegmentTree(n, plus);
  const right = new SegmentTree(n, minus);
  let bestDistance = Infinity;
  let answer = [n, n];

  const consider = (a, b, distance) => {
    const pair = a < b ? [a, b] : [b, a];
    if (distance < bestDistance ||
        distance === bestDistance &&
        (pair[0] < answer[0] || pair[0] === answer[0] && pair[1] < answer[1])) {
      bestDistance = distance;
      answer = pair;
    }
  };

  for (const i of order) {
    const x = nums1[i];
    let j = left.query(0, x);
    if (j !== -1) consider(i, j, plus[i] - plus[j]);
    j = right.query(x, n);
    if (j !== -1) consider(i, j, minus[i] - minus[j]);
    left.update(x, i);
    right.update(x, i);
  }
  return answer;
};

from typing import List


class SegmentTree:
    def __init__(self, n: int, score: List[int]):
        self.size = 1
        while self.size < n + 1:
            self.size *= 2
        self.tree = [-1] * (self.size * 2)
        self.score = score

    def better(self, a: int, b: int) -> int:
        if a == -1:
            return b
        if b == -1:
            return a
        if self.score[a] != self.score[b]:
            return a if self.score[a] > self.score[b] else b
        return min(a, b)

    def update(self, position: int, index: int) -> None:
        p = position + self.size
        self.tree[p] = self.better(self.tree[p], index)
        p //= 2
        while p:
            self.tree[p] = self.better(self.tree[p * 2], self.tree[p * 2 + 1])
            p //= 2

    def query(self, left: int, right: int) -> int:
        left += self.size
        right += self.size
        a = b = -1
        while left <= right:
            if left % 2:
                a = self.better(a, self.tree[left])
                left += 1
            if right % 2 == 0:
                b = self.better(self.tree[right], b)
                right -= 1
            left //= 2
            right //= 2
        return self.better(a, b)


class Solution:
    def beautifulPair(self, nums1: List[int], nums2: List[int]) -> List[int]:
        n = len(nums1)
        plus = [x + y for x, y in zip(nums1, nums2)]
        minus = [y - x for x, y in zip(nums1, nums2)]
        order = sorted(range(n), key=lambda i: (nums2[i], i))
        left = SegmentTree(n, plus)
        right = SegmentTree(n, minus)
        best_distance = float("inf")
        answer = [n, n]

        def consider(a: int, b: int, distance: int) -> None:
            nonlocal best_distance, answer
            pair = [min(a, b), max(a, b)]
            if distance < best_distance or distance == best_distance and pair < answer:
                best_distance, answer = distance, pair

        for i in order:
            x = nums1[i]
            j = left.query(0, x)
            if j != -1:
                consider(i, j, plus[i] - plus[j])
            j = right.query(x, n)
            if j != -1:
                consider(i, j, minus[i] - minus[j])
            left.update(x, i)
            right.update(x, i)
        return answer

class SegmentTree {
    int size;
    vector<int> tree;
    const vector<int>& score;

    int better(int a, int b) const {
        if (a == -1) return b;
        if (b == -1) return a;
        if (score[a] != score[b]) return score[a] > score[b] ? a : b;
        return min(a, b);
    }

public:
    SegmentTree(int n, const vector<int>& values) : size(1), score(values) {
        while (size < n + 1) size *= 2;
        tree.assign(size * 2, -1);
    }

    void update(int position, int index) {
        int p = position + size;
        tree[p] = better(tree[p], index);
        for (p /= 2; p; p /= 2)
            tree[p] = better(tree[p * 2], tree[p * 2 + 1]);
    }

    int query(int left, int right) const {
        int a = -1, b = -1;
        for (left += size, right += size; left <= right; left /= 2, right /= 2) {
            if (left % 2) a = better(a, tree[left++]);
            if (right % 2 == 0) b = better(tree[right--], b);
        }
        return better(a, b);
    }
};

class Solution {
public:
    vector<int> beautifulPair(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        vector<int> plus(n), minus(n), order(n);
        for (int i = 0; i < n; ++i) {
            plus[i] = nums2[i] + nums1[i];
            minus[i] = nums2[i] - nums1[i];
            order[i] = i;
        }
        sort(order.begin(), order.end(), [&](int a, int b) {
            return nums2[a] != nums2[b] ? nums2[a] < nums2[b] : a < b;
        });

        SegmentTree left(n, plus), right(n, minus);
        int bestDistance = INT_MAX;
        vector<int> answer{n, n};
        auto consider = [&](int a, int b, int distance) {
            vector<int> pair{min(a, b), max(a, b)};
            if (distance < bestDistance ||
                (distance == bestDistance && pair < answer)) {
                bestDistance = distance;
                answer = pair;
            }
        };

        for (int i : order) {
            int x = nums1[i];
            int j = left.query(0, x);
            if (j != -1) consider(i, j, plus[i] - plus[j]);
            j = right.query(x, n);
            if (j != -1) consider(i, j, minus[i] - minus[j]);
            left.update(x, i);
            right.update(x, i);
        }
        return answer;
    }
};

替代方案

暴力枚举：O(n²)，只适合极小输入或作为对拍基线。

平面最近点分治：也可做到近似经典最近点流程，但曼哈顿条带、字典序和实现细节更繁琐。

若坐标不再落在 [0,n]：先离散化所有 x，线段树逻辑无需改变。

常见错误

  • 先插入再查询，错误地选到当前点自己。
  • 只比较最小距离，忘记字典序。
  • 线段树同分时随便保留下标，导致最终 tie-break 错误。
  • 把排序后位置当成原始下标返回。
  • 查询区间写成开区间，漏掉 x 相同的点。

面试追问

  1. 为什么只要两种变换？ 因为按 y 排序已经固定了纵坐标绝对值的符号，只需再按 x 的左右关系分两类。
  2. 为什么树节点要保留最小下标？ 变换值相同意味着对当前点产生相同距离，较小原始下标能给出不差且通常更小的规范化下标对。
  3. 能否提前在距离 0 时返回？ 可以，但必须确认已经得到全局字典序最小的重复点对；统一走全局比较更不易写错。
  4. 值域扩大到 10⁹ 怎么办？ 对 nums1 做坐标压缩，范围查询改用压缩排名。
