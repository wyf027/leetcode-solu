Minimum Cost to Reach City With Discounts

城市之间，路费各不相同。手中的折扣有限：你会如何选择路线，又把优惠留给哪段旅程？

01 / Problem

题意与输入约定

有 n 座城市，编号为 0 … n−1。数组中的 highways[i] = [a, b, toll] 表示一条连接 a、b 的双向公路，正常通过需支付 toll。

你持有 discounts 次折扣：每次可把一条公路的费用改为 ⌊toll / 2⌋，一张券只能用一次，同一条公路最多使用一次折扣，不能叠加。求从城市 0 到城市 n−1 的最小总费用；无法到达时返回 −1。

minimumCost(n: integer, highways: integer[][], discounts: integer) → integer

参数范围

  • 2 ≤ n ≤ 1000
  • 1 ≤ highways.length ≤ 1000
  • highways[i].length = 3
  • 0 ≤ a, b ≤ n−1，且 a ≠ b

道路与折扣

  • 0 ≤ toll ≤ 10⁵
  • 0 ≤ discounts ≤ 500
  • 任意两个城市之间最多一条公路。
  • 图可能不连通；零费用道路合法。

04 / Solution notebook

准备好，再打开题解

先想一想：抵达同一个城市时，手里剩余的折扣不同，后续的最佳路线是否也会不同？

Insight

给每座城市增加一维：已用折扣数

到达城市 u 的费用并不是全部信息。用 (u, k) 表示“在城市 u，恰好用过 k 次折扣”，才能保留剩余资源的区别。

定义 dist[u][k] 为到达这一状态的最小费用。经过费用 w 的道路 u ↔ v 时，可以原价走到 (v, k)，或在 k < discounts 时折价走到 (v, k+1)。两种边权分别为 w 和 ⌊w/2⌋，都非负，因此对这些状态使用 Dijkstra。

完整过程

  1. 建双向邻接表。距离表全部设为 ∞，仅 dist[0][0] = 0。
  2. 最小堆保存 (费用, 城市, 已用券数)，先放入 (0,0,0)。
  3. 弹出费用最小的状态；如果费用与距离表不相等，说明它已过期，跳过。
  4. 如果弹出的有效状态位于 n−1，立即返回费用。
  5. 遍历邻接道路，分别尝试原价与折价。只有费用严格变小，才更新距离并入堆。
  6. 堆空仍未抵达终点，返回 −1。

正确性：为什么第一次有效到达终点就足够？

  1. 状态转移完整。 任意合法路径及其用券方案，都可以映射成分层图中的一条路径；每走一段路选择原价或折价，费用完全一致。
  2. 无须保存走过的公路集合。 分层搜索可能枚举带环的行走，但所有费用非负，删除一段回路不会增加费用，且只会减少用券数。因为要求是“最多”使用折扣，总存在不重复城市的最优路径，所以不需要在状态中记录道路历史，也不会因重复优惠得到更小的非法最优值。
  3. 出堆时最优。 对每个有效出堆状态，若还有更便宜的路径，则该路径上首个尚未确定的状态此前已被更便宜的前驱松弛；它的队列费用应更小，与最小堆选择矛盾。零权边也满足这一论证。
  4. 终点跨层取最小。 目标是所有 (n−1,k) 中最便宜的一个。堆按全局费用弹出，所以第一个有效终点状态已是全局最小，无需恰好用完折扣。

复杂度

令 m 为公路数、K = discounts + 1。分层图有 nK 个状态和 O(mK) 条转移。下方代码采用允许重复条目的二叉堆：时间 O(nK + mK log(mK+2))；空间 O(nK + mK + n + m)，其中堆最坏包含 O(mK) 个条目。若使用带 decrease-key 的索引堆，堆可以限制为 O(nK)，但实现更复杂。

边界与常见错误

  • 只记 dist[city]： 会把“费用略高但还有券”的有用状态误删。
  • 先算原价最短路再给最大边打折： 折扣会改变最优路线，顺序贪心不成立。
  • 终点入堆就返回： 入堆费用还可能改进，只在有效出堆时返回。
  • 把半价写成四舍五入： 11 的折价是 5；Python 用 //，JavaScript 用 Math.floor。
  • 重复扩展相等费用： 零权环会产生大量冗余。仅在新费用严格小于旧费用时入堆。
  • 漏建反向边、强制用完优惠： 道路双向，优惠可不使用；discounts=0 退化成普通最短路。
  • 不连通时返回 −1；不存在负权。Java / C++ 内部使用 64 位费用。存在简单最优路径时费用不超过 (n−1)·10⁵，返回整数安全。

替代方案

可按用券数分层：先在上一层跨一条折价边得到本层初值，再在本层用多源 Dijkstra 传播原价距离，最终取所有终点层的最小值。Bellman–Ford 也能在展开图上工作，但一般时间过高；普通 BFS 不能处理不同路费。实际写题时，统一状态堆更直接。

面试追问

  • 如何还原路线与折扣位置？ 每次改进距离时保存前驱状态及是否用券，从终点回溯。
  • 折扣很多能否压缩？ 可令 discounts = min(discounts,n−1)。非负边权保证存在简单最优路径，它最多经过 n−1 条边。
  • 如果必须恰好用完所有券？ 只接受目标层 (n−1,discounts)，且要重新审视回路、每条道路使用限制；本题“删环即可”的论证不能直接照搬。
  • 能否做状态支配剪枝？ 同一城市中，若一个状态费用更低且用券更少，它支配另一个状态；维护这个关系也有成本，基础二维距离表已符合本题规模。

Java

PriorityQueue · long
import java.util.*;

class Solution {
    public int minimumCost(int n, int[][] highways, int discounts) {
        List<int[]>[] g = new ArrayList[n];
        for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
        for (int[] e : highways) {
            g[e[0]].add(new int[]{e[1], e[2]});
            g[e[1]].add(new int[]{e[0], e[2]});
        }
        long[][] dist = new long[n][discounts + 1];
        for (long[] row : dist) Arrays.fill(row, Long.MAX_VALUE);
        dist[0][0] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(
            Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, 0, 0});
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long cost = cur[0];
            int u = (int) cur[1], k = (int) cur[2];
            if (cost != dist[u][k]) continue;
            if (u == n - 1) return (int) cost;
            for (int[] e : g[u]) {
                int v = e[0], w = e[1];
                for (int use = 0; use <= 1; use++) {
                    int nk = k + use;
                    if (nk > discounts) continue;
                    long next = cost + (use == 0 ? w : w / 2);
                    if (next < dist[v][nk]) {
                        dist[v][nk] = next;
                        pq.offer(new long[]{next, v, nk});
                    }
                }
            }
        }
        return -1;
    }
}

/**
 * @param {number} n
 * @param {number[][]} highways
 * @param {number} discounts
 * @return {number}
 */
var minimumCost = function(n, highways, discounts) {
    const g = Array.from({length: n}, () => []);
    for (const [u, v, w] of highways) {
        g[u].push([v, w]);
        g[v].push([u, w]);
    }
    const dist = Array.from({length: n},
        () => Array(discounts + 1).fill(Infinity));
    const heap = [];
    function push(item) {
        let i = heap.length;
        heap.push(item);
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (heap[p][0] <= item[0]) break;
            heap[i] = heap[p];
            i = p;
        }
        heap[i] = item;
    }
    function pop() {
        const top = heap[0], last = heap.pop();
        if (heap.length) {
            let i = 0;
            while (2 * i + 1 < heap.length) {
                let c = 2 * i + 1;
                if (c + 1 < heap.length &&
                    heap[c + 1][0] < heap[c][0]) c++;
                if (heap[c][0] >= last[0]) break;
                heap[i] = heap[c];
                i = c;
            }
            heap[i] = last;
        }
        return top;
    }
    dist[0][0] = 0;
    push([0, 0, 0]);
    while (heap.length) {
        const [cost, u, k] = pop();
        if (cost !== dist[u][k]) continue;
        if (u === n - 1) return cost;
        for (const [v, w] of g[u]) {
            for (let use = 0; use <= 1; use++) {
                const nk = k + use;
                if (nk > discounts) continue;
                const next = cost + (use ? Math.floor(w / 2) : w);
                if (next < dist[v][nk]) {
                    dist[v][nk] = next;
                    push([next, v, nk]);
                }
            }
        }
    }
    return -1;
};

Python

heapq · 整数除法
from typing import List
from heapq import heappop, heappush
from math import inf

class Solution:
    def minimumCost(self, n: int, highways: List[List[int]],
                    discounts: int) -> int:
        g = [[] for _ in range(n)]
        for u, v, w in highways:
            g[u].append((v, w))
            g[v].append((u, w))
        dist = [[inf] * (discounts + 1) for _ in range(n)]
        dist[0][0] = 0
        pq = [(0, 0, 0)]
        while pq:
            cost, u, k = heappop(pq)
            if cost != dist[u][k]:
                continue
            if u == n - 1:
                return cost
            for v, w in g[u]:
                for use in range(2):
                    nk = k + use
                    if nk > discounts:
                        continue
                    nxt = cost + (w // 2 if use else w)
                    if nxt < dist[v][nk]:
                        dist[v][nk] = nxt
                        heappush(pq, (nxt, v, nk))
        return -1

#include <vector>
#include <queue>
#include <tuple>
#include <functional>
#include <limits>
#include <utility>
using namespace std;

class Solution {
public:
    int minimumCost(int n, vector<vector<int>>& highways,
                    int discounts) {
        vector<vector<pair<int, int>>> g(n);
        for (const auto& e : highways) {
            g[e[0]].push_back({e[1], e[2]});
            g[e[1]].push_back({e[0], e[2]});
        }
        using State = tuple<long long, int, int>;
        priority_queue<State, vector<State>, greater<State>> pq;
        vector<vector<long long>> dist(
            n, vector<long long>(discounts + 1,
                numeric_limits<long long>::max()));
        dist[0][0] = 0;
        pq.emplace(0, 0, 0);
        while (!pq.empty()) {
            auto [cost, u, k] = pq.top();
            pq.pop();
            if (cost != dist[u][k]) continue;
            if (u == n - 1) return static_cast<int>(cost);
            for (auto [v, w] : g[u]) {
                for (int use = 0; use <= 1; ++use) {
                    int nk = k + use;
                    if (nk > discounts) continue;
                    long long next = cost + (use ? w / 2 : w);
                    if (next < dist[v][nk]) {
                        dist[v][nk] = next;
                        pq.emplace(next, v, nk);
                    }
                }
            }
        }
        return -1;
    }
};
