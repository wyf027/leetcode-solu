判断矩阵经轮转后是否一致

Determine Whether Matrix Can Be Obtained By Rotation

把一个方阵转过直角，它能与另一个方阵重合吗？先动手观察，再展开下方题解。

01 / 题目

给定两个大小相同的 n × n 二进制矩阵 mat 和 target。允许将整个 mat 顺时针旋转 90° 任意次（也可以不旋转）。如果某个旋转结果与 target 的每个位置都相同，返回 true，否则返回 false。只允许旋转，不能翻面或单独移动元素。

参数与返回：findRotation(mat, target) → boolean

  • n == mat.length == target.length
  • n == mat[i].length == target[i].length
  • 1 ≤ n ≤ 10
  • mat[i][j]、target[i][j] 均为 0 或 1。

官方示例

示例 1
输入：mat = [[0,1],[1,0]], target = [[1,0],[0,1]]
输出：true

顺时针旋转 90° 后一致。

示例 2
输入：mat = [[0,1],[1,1]], target = [[1,0],[0,1]]
输出：false

任何允许的旋转都无法使两个矩阵一致。

示例 3
输入：mat = [[0,0,0],[0,1,0],[1,1,1]], target = [[1,1,1],[0,1,0],[0,0,0]]
输出：true

顺时针旋转两次，即 180° 后一致。

04 / 独立题解

核心洞察：四个朝向已经覆盖全部可能

四次 90° 旋转会回到原矩阵，所以只需考虑 0°、90°、180°、270°。无需创建旋转后的矩阵：对原矩阵中的一个元素计算它旋转后的目的坐标，直接与 target 比较。

一次顺时针旋转把原坐标 (r, c) 送到 (c, n − 1 − r)。例如 3 × 3 矩阵左下角 (2, 0) 会来到左上角 (0, 0)。

完整过程

  1. 枚举旋转次数 k = 0、1、2、3，每次重新令 same = true。
  2. 遍历每个原坐标 (i, j)，从 (r, c) = (i, j) 开始，应用 k 次坐标变换。
  3. 比较 mat[i][j] 与 target[r][c]。遇到不同，该朝向失败，停止检查该朝向。
  4. 若全部对应元素相同，返回 true；四个朝向都失败才返回 false。

以官方示例 3 为例：0° 的底行是 111，目标顶行是 111；90° 时这条横线变成竖线，仍不匹配；180° 时底行移动到顶行，中间的 1 保持居中，全部对应元素相同。

为什么正确

映射正确：顺时针转动后，原行 r 变成从右侧计数的列 n − 1 − r，原列 c 变成行 c。反复使用该变换即可得到任意 k 次旋转的位置。每次变换是一一映射，因此不会遗漏或重复占据目标格。

比较正确：对固定的 k，每次比较检查一个原元素在目标位置的值。循环结束时 same 为 true 当且仅当该朝向下每一个元素都匹配。因此返回 true 必有合法旋转。

枚举完整：任意非负旋转次数都与其模 4 的余数等价，四种余数均已检查。因此全部失败时确实不存在合法旋转。

边界与复杂度

  • n = 1 时旋转不会改变数值；直接比较唯一格即可。
  • 原本相等时 k = 0 就成功；全 0、全 1 或对称图案可能在多个朝向匹配。
  • 时间 O(n²)：最多检查四个朝向，每个格最多做三次坐标变换，都是固定常数。
  • 辅助空间 O(1)：仅使用标量，不修改两个输入。演示界面额外创建格子节点，不属于提交算法的空间。

替代方案

可每次创建新矩阵，让 new[c][n−1−r] = old[r][c]，再逐格比较，时间 O(n²)、空间 O(n²)，更直观。也可先转置再反转每一行实现原地顺时针旋转，辅助空间 O(1)，但会改变输入。直接写四组坐标公式可以减少循环常数，但更容易写错下标。

常见错误

  • 漏掉 0°，导致原本一致的输入被误判。
  • 把 (c, n−1−r) 写成 (n−1−c, r)，混淆顺逆时针。
  • 仅比较 1 的数量；数量相同是必要条件，不能保证位置可重合。
  • 每换一个朝向没有重置 same，或发现一次不匹配就直接返回 false。
  • 直接覆盖 mat[c][n−1−r]，破坏后续尚未读取的原值。

面试追问

允许翻转怎么办？考虑正方形的八种旋转 / 镜像变换。矩形还能照搬吗？90° 后行列数量交换，需先判断形状，原来的 n × n 坐标公式不能直接使用。如何返回最小旋转次数？按 0 到 3 枚举，第一次成功时返回 k，无解返回 −1。

Java
class Solution {
    public boolean findRotation(int[][] mat, int[][] target) {
        int n = mat.length;
        for (int k = 0; k < 4; k++) {
            boolean same = true;
            for (int i = 0; i < n && same; i++) {
                for (int j = 0; j < n; j++) {
                    int r = i, c = j;
                    for (int t = 0; t < k; t++) {
                        int nextR = c;
                        c = n - 1 - r;
                        r = nextR;
                    }
                    if (mat[i][j] != target[r][c]) {
                        same = false;
                        break;
                    }
                }
            }
            if (same) return true;
        }
        return false;
    }
}

from typing import List

class Solution:
    def findRotation(self, mat: List[List[int]],
                     target: List[List[int]]) -> bool:
        n = len(mat)
        for k in range(4):
            same = True
            for i in range(n):
                for j in range(n):
                    r, c = i, j
                    for _ in range(k):
                        r, c = c, n - 1 - r
                    if mat[i][j] != target[r][c]:
                        same = False
                        break
                if not same:
                    break
            if same:
                return True
        return False
