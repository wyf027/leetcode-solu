Problem

题目描述

给定字符串 s，其中只含字符 'a' 与 'b'。每次操作可以从当前字符串中删除一个回文子序列。求删光所有字符所需的最少操作次数。

函数形式： removePalindromeSub(s: string) -> integer
Vocabulary

两个关键词

  • 子序列：可删除若干字符，但剩余字符的相对顺序不能改变；它不必连续。
  • 回文：从左向右与从右向左读取完全相同。

Solution

答案只有 1 或 2

核心洞察

若 s 本身是回文，一次删掉全部字符即可；否则，因为字符只有 a 和 b，可先删除所有 a，再删除所有 b。同一字符组成的任意序列都是回文，所以最多只需两次。

  1. 双指针判回文
    令 left = 0、right = n - 1，持续比较两端字符。
  2. 全部相等
    若指针相遇前没有差异，整个 s 是回文，返回 1。
  3. 出现差异
    s 不是回文，不能一次删空；但按字符种类分两次一定能删空，返回 2。

正确性证明

情形一：s 是回文。一次操作可选择整个字符串，故答案至多为 1；由于初始字符串非空，至少需要 1 次，因此答案为 1。

情形二：s 不是回文。若一次就能删空，被删除的子序列必须包含全部字符，也就是 s 本身，这与它不是回文矛盾，故至少需要 2 次。所有 a 构成回文子序列，所有 b 也构成回文子序列，分两次可删空，故至多需要 2 次。因此答案为 2。

时间复杂度O(n)最多比较一半字符
空间复杂度O(1)只维护两个指针

边界情况 必看

  • 长度为 1：单字符天然回文，答案为 1。
  • 全部相同：例如 "aaaa"，整体回文，答案为 1。
  • 偶数长度回文：例如 "abba"，指针最终交错。
  • 首尾相等但内部不同：例如 "aabbba"，必须继续比较到内部。

替代方案 不推荐

可以反转字符串后与原串比较，但会额外使用 O(n) 空间。动态规划求回文子序列或最少删除则明显过度设计：本题的二字符限制直接给出了“最多两次”的上界。

若题目允许空字符串，才需要额外返回 0；官方约束保证长度至少为 1。

Implementations

四种语言完整代码

JavaO(n) / O(1)
class Solution {
    public int removePalindromeSub(String s) {
        int left = 0;
        int right = s.length() - 1;

        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return 2;
            }
            left++;
            right--;
        }
        return 1;
    }
}

class Solution {

Interview Follow-ups

面试追问

为什么删除所有 a 是合法操作？

这些字符在原字符串中的相对顺序保持不变，因此组成子序列；而全部由同一字符组成的字符串正读反读相同，因此还是回文。

如果字符集扩大到 a、b、c 呢？

仍可按字符分别删除，得到“最多 3 次”的上界，但最优答案不再只由“整个字符串是否回文”决定，可能为 2，需要更深入的状态设计。

能不能直接写 s == reverse(s)？

可以，时间仍是 O(n)，但通常会创建反转副本并使用 O(n) 额外空间；双指针更能体现原地判断。

Common Mistakes

常见错误

把子序列看成子串

删除的字符不要求连续。正因为如此，所有 a 可以在一次操作中一并删除。

只比较首尾

首尾相等不能证明整体回文，双指针必须持续收拢，直到相遇或发现第一处差异。

误返回 0

官方输入保证非空，因此最少也要执行一次删除。

真的模拟删除

无需构造删除后的字符串；只判定原串是否回文即可决定最终答案。
