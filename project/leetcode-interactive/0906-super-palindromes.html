超级回文数

Super Palindromes — 从“平方结果”逆向缩小到“回文平方根”，在极大的字符串区间里只枚举极少候选。

HARD非会员题字符串边界至 10¹⁸−1

题目

正整数若自身是回文数，同时又是某个回文数的平方，则称为超级回文数。给定两个以字符串表示的正整数 left、right，返回闭区间 [left, right] 内超级回文数的数量。

示例 1

输入：left = "4", right = "1000" 输出：4 解释：4、9、121、484 符合。676 虽是回文数，但平方根 26 不是回文数。

示例 2

输入：left = "1", right = "2" 输出：1

约束

  • 1 <= left.length, right.length <= 18
  • 二者只含数字且无前导零。
  • 数值位于 [1, 10¹⁸ - 1]，且 left <= right。

题解：构造回文平方根

核心洞察：答案的平方根必须是回文数。右端点小于 10¹⁸，所以根小于 10⁹；一个至多 9 位的回文根只需枚举它的前半部分（最多 5 位），候选规模约 10⁵。

完整过程

  1. 将边界解析成 64 位整数（JavaScript 使用 BigInt）。
  2. 枚举前半部分 seed = 1..99999，分别镜像构造奇数长度和偶数长度回文根。
  3. 计算平方。若平方超过右边界，可跳过；否则判断平方的十进制字符串是否回文。
  4. 平方同时位于闭区间内且为回文时，答案加一。奇偶构造不会产生同一个正整数根。

正确性说明

完备性：任意可行数 x 的根 r 是不超过 9 位的回文数；其前半部分唯一决定 r，必被对应的奇/偶镜像枚举到。可靠性：算法只计入由回文根平方得到、位于区间内且平方本身回文的数，恰好满足定义。因此计数准确。

边界与复杂度

  • 边界是闭区间；1 也是超级回文数。
  • 平方必须使用 64 位整数；JavaScript 的普通 Number 无法精确覆盖 10¹⁸。
  • 设枚举种子上限为 M = 10⁵，时间 O(M · d)，其中 d ≤ 18 为回文检查位数；额外空间 O(d)。

替代方案

可以预生成所有不超过 10¹⁸ 的超级回文数并排序，然后对每次查询二分计数；适合大量查询。直接遍历区间、逐个开方或枚举所有平方根都会在大范围上超时。

面试追问

  • 为什么只需枚举 5 位 seed？因为根最多 9 位，回文由前 ceil(9/2)=5 位决定。
  • 如何处理许多查询？预计算一次，使用两次二分。
  • 能否提前终止？当两种构造随 seed 均已超出右界时可以，但固定 99999 次已经足够小。

常见错误

  • 只检查平方是回文，忘记平方根也必须回文。
  • 偶数与奇数长度镜像方式写反，或重复中心位。
  • JavaScript 使用 Number 导致大整数精度丢失。
  • 边界使用严格不等号，漏掉恰好等于 left/right 的答案。

Java

class Solution {
    public int superpalindromesInRange(String left, String right) {
        long lo = Long.parseLong(left), hi = Long.parseLong(right);
        int ans = 0;
        for (int seed = 1; seed < 100000; seed++) {
            String s = String.valueOf(seed);
            long odd = Long.parseLong(s + new StringBuilder(s.substring(0, s.length() - 1)).reverse());
            long even = Long.parseLong(s + new StringBuilder(s).reverse());
            ans += valid(odd, lo, hi) ? 1 : 0;
            ans += valid(even, lo, hi) ? 1 : 0;
        }
        return ans;
    }
    private boolean valid(long root, long lo, long hi) {
        long square = root * root;
        if (square < lo || square > hi) return false;
        String s = String.valueOf(square);
        return s.contentEquals(new StringBuilder(s).reverse());
    }
}

JavaScript

/** @param {string} left @param {string} right @return {number} */
var superpalindromesInRange = function(left, right) {
  const lo = BigInt(left), hi = BigInt(right);
  const palindrome = s => s === [...s].reverse().join('');
  let answer = 0;
  for (let seed = 1; seed < 100000; seed++) {
    const s = String(seed);
    const roots = [
      BigInt(s + [...s.slice(0, -1)].reverse().join('')),
      BigInt(s + [...s].reverse().join(''))
    ];
    for (const root of roots) {
      const square = root * root;
      if (square >= lo && square <= hi && palindrome(String(square))) answer++;
    }
  }
  return answer;
};

Python

class Solution:
    def superpalindromesInRange(self, left: str, right: str) -> int:
        lo, hi = int(left), int(right)
        answer = 0
        for seed in range(1, 100000):
            s = str(seed)
            roots = (int(s + s[-2::-1]), int(s + s[::-1]))
            for root in roots:
                square = root * root
                if lo <= square <= hi and str(square) == str(square)[::-1]:
                    answer += 1
        return answer

C++

class Solution {
public:
    int superpalindromesInRange(string left, string right) {
        long long lo = stoll(left), hi = stoll(right);
        int answer = 0;
        for (int seed = 1; seed < 100000; ++seed) {
            string s = to_string(seed), a = s, b = s;
            for (int i = (int)s.size() - 2; i >= 0; --i) a += s[i];
            for (int i = (int)s.size() - 1; i >= 0; --i) b += s[i];
            answer += valid(stoll(a), lo, hi);
            answer += valid(stoll(b), lo, hi);
        }
        return answer;
    }
private:
    bool valid(long long root, long long lo, long long hi) {
        long long square = root * root;
        if (square < lo || square > hi) return false;
        string s = to_string(square), r = s;
        reverse(r.begin(), r.end());
        return s == r;
    }
};
