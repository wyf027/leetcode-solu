3944. 使数组变为模交替数组的最少操作次数 II

把每个位置落到一个模类的代价看成环上的最短距离：偶、奇位置分别求所有目标余数的代价，再挑两个不同的目标。

题意

给定整数数组 nums 和 k。每次可把任一元素加一或减一。若存在两个不同余数 x、y（均在 [0, k)）使偶数下标都模 k 等于 x、奇数下标都等于 y，数组即为模交替数组。求最小操作数。

示例：nums = [1, 4, 2, 8], k = 3，答案为 2。

约束：1 ≤ nums.length ≤ 10⁵，1 ≤ nums[i] ≤ 10⁹，2 ≤ k ≤ 10⁵。

环形余数仪表盘

目标余数 1：偶数下标的余数 1、2、2 到 1 的环形距离分别为 0、1、1。

核心洞察

把数 a 改成模类 r 的最少步数是环长 k 上的 min((a%k-r+k)%k, (r-a%k+k)%k)。偶、奇下标互不影响，因此各自统计余数频次，并一次滑动得到所有 k 个目标余数的总代价。最后从两组代价各取前二小，保证两目标不同。

完整过程

  1. 按下标奇偶统计 cnt[0..k-1]。
  2. 先求目标为 0 的环形距离和。
  3. 目标从 r-1 滑到 r：半环内频次距离减一，另一半加一；奇数环要修正对径附近的不变点。
  4. 每个奇偶组保留代价最小的两个余数；若最优余数相同，交叉配第二名。

边界

长度为 1 时另一类频次为零，仍可选择不同余数；k=2 也适用。

复杂度

时间 O(n+k)，空间 O(k)。

替代方案

枚举两个余数会到 O(nk²)，在 10⁵ 级约束下不可行。

面试追问与常见错误

  • 为什么不能只选每组最小值？两个目标余数必须不同。
  • 为什么用 long？总代价最高可达约 10¹⁰。
  • 不要把模距离误当普通绝对差；余数 0 与 k-1 在环上只差一步。
