查找共用字符

Find Common Characters

先把每个单词想成一张“字母库存表”。逐个取交集，看看哪些字母能一路留到最后。

数组哈希表字符串非付费题

题目

给定字符串数组 words，返回在每个字符串中都出现的全部共用字符，重复字符也要重复返回。答案顺序不限。

示例 1

输入：words = ["bella", "label", "roller"] 输出：["e", "l", "l"]

示例 2

输入：words = ["cool", "lock", "cook"] 输出：["c", "o"]

约束与签名

  • 1 <= words.length <= 100
  • 1 <= words[i].length <= 100
  • words[i] 仅由小写英文字母组成

参数形式

commonChars(words: string[]): string[]

关键字“包括重复字符”意味着需要比较出现次数，而不只是判断是否出现。

字母库存交集实验室

以 ["bella", "label", "roller"] 为例，观察全局最小频次如何收缩。

准备开始：先建立 26 个字母的库存上限。

先形成自己的答案，再看题解

想一想：若某字符在三个单词中分别出现 2、2、1 次，答案里应该保留几次？

题解：逐词压缩频次上限

核心洞察：字符在答案中的重复次数，等于它在所有单词中出现次数的最小值。比如 l 的频次是 2、2、2，所以输出两个 l。

完整过程

  1. 创建长度为 26 的数组 minFreq，先用第一个单词的字符频次初始化。
  2. 对后续每个单词单独统计 current。
  3. 对每个字母执行 minFreq[i] = min(minFreq[i], current[i])。
  4. 全部单词处理完后，按 minFreq 中的次数把字母加入答案。

正确性证明

对任意字母 x，设它在第 i 个单词中的出现次数为 cᵢ。算法逐词取最小值，最终保存 min(c₁,…,cₙ)。输出超过这个次数时，至少有一个单词无法提供足够的 x；输出恰好这么多次时，每个单词都能提供。因此算法对每个字母保留且只保留合法的最大次数，合并所有字母后答案正确。

边界情况

  • 只有一个单词：它的全部字符（含重复）都返回。
  • 没有任何共同字符：返回空数组。
  • 某字符只在一个单词缺失：最小频次变为 0。
  • 答案顺序任意；下面实现按字母序生成。

复杂度：设所有字符串总长度为 S，时间 O(S + 26n)，可简写为 O(S)；额外空间 O(26)（不计输出）。

替代方案

也可以把第一个单词拆成字符列表，然后与后续单词逐一匹配并删除已使用字符；写法直观，但频繁查找与删除可能退化到更高时间复杂度。固定 26 位计数数组更稳定。

面试追问

  • 若字符集扩展到 Unicode？改用 Map 统计，只遍历候选键。
  • 若输入是流式、无法全部放入内存？保留全局 26 位数组，逐个消费单词即可。
  • 能否提前结束？当 26 个全局频次都为 0 时，后续不可能恢复，可直接返回空数组。

常见错误

  • 使用 Set，丢失重复次数。
  • 复用当前单词计数数组却没有清零。
  • 取最大值或累加，而不是逐项取最小值。
  • 初始化为全 0，导致任何最小值都永远是 0。

四语言完整代码

import java.util.*;

class Solution {
    public List<String> commonChars(String[] words) {
        int[] minFreq = new int[26];
        Arrays.fill(minFreq, Integer.MAX_VALUE);
        for (String word : words) {
            int[] current = new int[26];
            for (char ch : word.toCharArray()) current[ch - 'a']++;
            for (int i = 0; i < 26; i++) minFreq[i] = Math.min(minFreq[i], current[i]);
        }
        List<String> answer = new ArrayList<>();
        for (int i = 0; i < 26; i++)
            for (int k = 0; k < minFreq[i]; k++) answer.add(String.valueOf((char) ('a' + i)));
        return answer;
    }
}

var commonChars = function(words) {
  const minFreq = new Array(26).fill(Infinity);
  for (const word of words) {
    const current = new Array(26).fill(0);
    for (const ch of word) current[ch.charCodeAt(0) - 97]++;
    for (let i = 0; i < 26; i++) minFreq[i] = Math.min(minFreq[i], current[i]);
  }
  const answer = [];
  for (let i = 0; i < 26; i++)
    for (let k = 0; k < minFreq[i]; k++) answer.push(String.fromCharCode(97 + i));
  return answer;
};
from typing import List

class Solution:
    def commonChars(self, words: List[str]) -> List[str]:
        min_freq = [float("inf")] * 26
        for word in words:
            current = [0] * 26
            for ch in word:
                current[ord(ch) - ord("a")] += 1
            for i in range(26):
                min_freq[i] = min(min_freq[i], current[i])
        answer = []
        for i, count in enumerate(min_freq):
            answer.extend([chr(ord("a") + i)] * int(count))
        return answer
class Solution {
public:

        vector<string> answer;
        for (int i = 0; i < 26; ++i)
