使数组变成交替数组的
最少操作数

Minimum Operations to Make the Array Alternating

一次修改，一个位置。让数组满足交替规则，最少需要几步？

LeetCode 官方题目 ↗

题目

给定一个从下标 0 开始、由 n 个正整数组成的数组 nums。交替数组需要同时满足：

  • 对所有 2 ≤ i ≤ n − 1，nums[i − 2] == nums[i]，即相隔两个位置的元素相等。
  • 对所有 1 ≤ i ≤ n − 1，nums[i − 1] != nums[i]，即相邻元素不同。

每次操作可以选择一个下标，把该元素改成任意正整数。返回使数组满足条件的最少操作数。

参数：nums: integer[]；返回：integer。

约束：1 ≤ nums.length ≤ 10⁵，1 ≤ nums[i] ≤ 10⁵。

官方示例

示例 1

输入：nums = [3,1,3,2,4,3]
输出：3

变为 [3,1,3,1,3,1]：修改下标 3、4、5，共 3 次，无法用更少操作完成。

示例 2

输入：nums = [1,2,2,2,2]
输出：2

变为 [1,2,1,2,1]：修改下标 2、4，共 2 次。全部变成 2 会违反相邻元素不同的条件。

独立题解

核心洞察：最大化保留数

偶数下标都要变成同一个值 A，奇数下标都要变成另一个值 B，且 A ≠ B。这里的奇偶指下标，不是元素本身。

设 E(v)、O(v) 分别是值 v 在偶数、奇数下标的频次。选定 A、B 后，修改次数为 n − E(A) − O(B)。因此，最少修改等价于最多保留。

  1. 按下标奇偶建立两张频次表。
  2. 扫描每张表，找出频次最高的两个不同值：第一名与第二名。并列第一也可以作为第二名。
  3. 两组第一名不同：直接选择这两个值。
  4. 两组第一名相同：比较“偶第一 + 奇第二”和“偶第二 + 奇第一”，选择保留数较大的方案。
  5. 用 n 减去该方案的保留数。

将两组前两名记为 (e₁,c₁)、(e₂,c₂) 和 (o₁,d₁)、(o₂,d₂)。首选同值时，答案为 n − max(c₁+d₂, c₂+d₁)。缺少第二名时，其频次为 0，表示改用未出现的正整数。

正确性证明

结构：相隔 2 的相等关系沿下标链传递，所以每个合法数组必然由 A、B 交替组成；相邻不等要求 A ≠ B。反过来，这种结构也一定合法。

固定选值：所有与目标值不同的位置都至少要改一次，其他位置可以保留。因此 n − E(A) − O(B) 既是下界，也是可达到的次数。

候选完备：首选不同，分别选择两组最高频值已经达到保留数上界。首选同为 x 时，合法方案至少一组不选 x。偶数组选 x，则奇数组的最优选择是排除 x 后的最高频值，也就是第二名；反向同理。若两组都不选 x，把偶数组改选 x 不会降低保留数，且仍与奇数组不同。因此至少存在一个最优方案属于这两个候选。

结论：算法求得最大的合法保留数，n 减去它即为最少操作数。

边界与复杂度

  • n = 1：奇数组为空，答案为 0。
  • 全相同：修改较短的一组，答案为 ⌊n/2⌋。
  • 缺少第二名：用 (0,0) 占位。值 0 仅供内部比较，实际目标必须是与另一组不同的正整数。
  • 并列频次：保留两个不同值即可，不要求频次不同。
  • 时间 O(n)，额外空间 O(k)，k 为两张表不同值数量之和，最坏 O(n)。哈希表操作按平均 O(1) 计算。

JavaScript

/**
 * @param {number[]} nums
 * @return {number}
 */
var minimumOperations = function(nums) {
    const even = new Map(), odd = new Map();
    for (let i = 0; i < nums.length; i++) {
        const m = i % 2 === 0 ? even : odd;
        m.set(nums[i], (m.get(nums[i]) || 0) + 1);
    }
    function top2(m) {
        let first = [0, 0], second = [0, 0];
        for (const [value, count] of m) {
            if (count > first[1]) {
                second = first;
                first = [value, count];
            } else if (count > second[1]) {
                second = [value, count];
            }
        }
        return [first, second];
    }
    const [e1, e2] = top2(even), [o1, o2] = top2(odd);
    const keep = e1[0] !== o1[0]
        ? e1[1] + o1[1]
        : Math.max(e1[1] + o2[1], e2[1] + o1[1]);
    return nums.length - keep;
};

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    private int[][] top2(Map<Integer, Integer> counts) {
        int[] first = {0, 0}, second = {0, 0};
        for (Map.Entry<Integer, Integer> e : counts.entrySet()) {
            int value = e.getKey(), count = e.getValue();
            if (count > first[1]) {
                second = first;
                first = new int[]{value, count};
            } else if (count > second[1]) {
                second = new int[]{value, count};
            }
        }
        return new int[][]{first, second};
    }
    public int minimumOperations(int[] nums) {
        Map<Integer, Integer> even = new HashMap<>();
        Map<Integer, Integer> odd = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            Map<Integer, Integer> m = i % 2 == 0 ? even : odd;
            m.put(nums[i], m.getOrDefault(nums[i], 0) + 1);
        }
        int[][] e = top2(even), o = top2(odd);
        int keep = e[0][0] != o[0][0]
            ? e[0][1] + o[0][1]
            : Math.max(e[0][1] + o[1][1], e[1][1] + o[0][1]);
        return nums.length - keep;
    }
}

Python

from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:
        even, odd = {}, {}
        for i, value in enumerate(nums):
            counts = even if i % 2 == 0 else odd
            counts[value] = counts.get(value, 0) + 1

        def top2(counts):
            first = second = (0, 0)
            for value, count in counts.items():
                if count > first[1]:
                    second, first = first, (value, count)
                elif count > second[1]:
                    second = (value, count)
            return first, second

        e1, e2 = top2(even)
        o1, o2 = top2(odd)
        if e1[0] != o1[0]:
            keep = e1[1] + o1[1]
        else:
            keep = max(e1[1] + o2[1], e2[1] + o1[1])
        return len(nums) - keep

C++

#include <vector>
#include <unordered_map>
#include <array>
#include <utility>
#include <algorithm>
using namespace std;

class Solution {
    array<pair<int, int>, 2> top2(
        const unordered_map<int, int>& counts) {
        pair<int, int> first{0, 0}, second{0, 0};
        for (const auto& entry : counts) {
            pair<int, int> item{entry.first, entry.second};
            if (item.second > first.second) {
                second = first;
                first = item;
            } else if (item.second > second.second) {
                second = item;
            }
        }
        return {first, second};
    }
public:
    int minimumOperations(vector<int>& nums) {
        unordered_map<int, int> even, odd;
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            auto& counts = i % 2 == 0 ? even : odd;
            ++counts[nums[i]];
        }
        auto e = top2(even), o = top2(odd);
        int keep = e[0].first != o[0].first
            ? e[0].second + o[0].second
            : max(e[0].second + o[1].second,
                  e[1].second + o[0].second);
        return static_cast<int>(nums.size()) - keep;
    }
};

替代方案

排序频次表后取前两名也可行，但时间为 O(n + k log k)。利用题目值域建立两个计数数组，可得到 O(n + U) 时间、O(U) 空间，U = 100000。枚举全部值对会达到 O(k²)，没有必要。

常见错误

  • 按数值奇偶分组，或只检查相邻不等。
  • 两组第一名相同时仍把频次相加，选出了非法方案。
  • 固定舍弃某一组首选，没有比较两个方向。
  • 将第二名误写为第二个不同的频次数，漏掉并列。
  • 不处理空组或缺少第二名，导致单元素和全相同数组出错。

面试追问

如何构造最终数组？保存获胜的 A、B，依下标交替填充。若某候选为占位值 0，改用一个与另一组不同的正整数。

每个位置修改费用不同呢？如果费用非负且只依赖下标，把频次换成能保留的费用之和，总费用减去最多能保留的费用，仍可用前两名。

周期为 3 且三个值互不相同呢？变成三组之间的值冲突选择问题，当前二选一公式不能直接套用，应重新设计候选组合或匹配算法。
