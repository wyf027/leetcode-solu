#939 Minimum Area Rectangle
难度：中等坐标轴平行点数 ≤ 500返回最小面积
题目交互演示测试与验证题解

题目说明

给定 X-Y 平面上的点数组 points，其中 points[i] = [xᵢ, yᵢ]。请选择其中四个点组成边与 X、Y 轴平行的矩形，返回所有可行矩形中的最小面积；若不存在，返回 0。

示例

示例 1
输入：points = [[1,1],[1,3],[3,1],[3,3],[2,2]] 输出：4

四角为 (1,1)、(1,3)、(3,1)、(3,3)，面积为 2 × 2。

示例 2
输入：points = [[1,1],[1,3],[3,1],[3,3],[4,1],[4,3]] 输出：2

选择横坐标 3 与 4、纵坐标 1 与 3，面积为 1 × 2。

约束

  • 1 <= points.length <= 500
  • points[i].length == 2
  • 0 <= xᵢ, yᵢ <= 4 × 10⁴
  • 所有点互不相同。

对角点侦测器

演示枚举一对点：只有当它们是斜对角，且另外两个角也存在时，才形成合法矩形。

完整题解

核心洞察

一个轴对齐矩形由任意一对斜对角点唯一确定。若选中 (x₁,y₁) 与 (x₂,y₂)，要求 x₁ ≠ x₂、y₁ ≠ y₂，并且另外两角 (x₁,y₂)、(x₂,y₁) 都在输入点集中。把所有点编码进哈希集合，就能用均摊 O(1) 完成两次存在性查询。

面积公式： |x₁-x₂| × |y₁-y₂|。每个矩形会由两条对角线各发现一次，但只更新最小值，不影响答案。

完整过程

  1. 把每个坐标编码后放入哈希集合。
  2. 用双重循环枚举任意两个点。
  3. 跳过同横坐标或同纵坐标的点对，因为它们不能是矩形斜对角。
  4. 查询另外两个交叉组合的坐标是否存在。
  5. 存在则计算面积并更新全局最小值；最终若仍未找到则返回 0。

正确性证明

  1. 不会误收：算法更新答案前，已确认四个点分别是两种横坐标与两种纵坐标的所有组合，因此四条边分别平行于坐标轴，必然构成合法矩形。
  2. 不会漏解：任意合法矩形都有一对斜对角点。双重循环必然枚举到这对点，集合查询也必然找到余下两角，所以该矩形面积会参与比较。
  3. 最优性：所有合法矩形面积均参与最小值更新，因此最终保留的正是全局最小面积；若从未更新，说明不存在矩形，返回 0。

边界与复杂度

  • 点少于 4 个、所有点共线或缺少任一角：返回 0。
  • 坐标可为 0；面积使用非负差值。
  • 时间复杂度 O(n²)，空间复杂度 O(n)。

替代方案

也可以按横坐标分组，枚举同一列中的纵坐标对，并记录该纵坐标对上一次出现的横坐标；再次出现时即可计算面积。这一方案在列分布稀疏时可能更快，但实现与复杂度分析更依赖数据分布。还可先排序后枚举，通常不如哈希对角线方案直接。

面试追问

  • 若矩形允许旋转，应如何用“同中点 + 同对角线长度”分组？
  • 如何避免字符串坐标键的分配成本？可使用整数编码或语言原生的复合键。
  • 若数据是流式到达，怎样增量维护最小面积？

常见错误

  • 只检查一个交叉角，导致把三点误判为矩形。
  • 没有排除同横/同纵点对，产生零面积候选。
  • 坐标编码缺少可靠分隔符，造成键碰撞。
  • 无解时返回无穷大而不是 0。

四语言完整代码

Java O(n²)

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minAreaRect(int[][] points) {
        Set<Long> seen = new HashSet<>();
        for (int[] p : points) seen.add(key(p[0], p[1]));
        int best = Integer.MAX_VALUE;
        for (int i = 0; i < points.length; i++) {
            for (int j = i + 1; j < points.length; j++) {
                int x1 = points[i][0], y1 = points[i][1];
                int x2 = points[j][0], y2 = points[j][1];
                if (x1 == x2 || y1 == y2) continue;
                if (seen.contains(key(x1, y2)) &&
                    seen.contains(key(x2, y1))) {
                    best = Math.min(best,
                        Math.abs(x1 - x2) * Math.abs(y1 - y2));
                }
            }
        }
        return best == Integer.MAX_VALUE ? 0 : best;
    }
    private long key(int x, int y) {
        return ((long) x << 32) ^ (y & 0xffffffffL);
    }
}

/**

var minAreaRect = function(points) {
    const seen = new Set(points.map(([x, y]) => `${x},${y}`));
    let best = Infinity;
    for (let i = 0; i < points.length; i++) {
        for (let j = i + 1; j < points.length; j++) {
            const [x1, y1] = points[i];
            const [x2, y2] = points[j];
            if (x1 === x2 || y1 === y2) continue;
            if (seen.has(`${x1},${y2}`) &&
                seen.has(`${x2},${y1}`)) {
                best = Math.min(best,
                    Math.abs(x1 - x2) * Math.abs(y1 - y2));
            }
        }
    }
    return best === Infinity ? 0 : best;
};

Python O(n²)

from typing import List

class Solution:
    def minAreaRect(self, points: List[List[int]]) -> int:
        seen = {tuple(point) for point in points}
        best = float("inf")
        for i in range(len(points)):
            x1, y1 = points[i]
            for j in range(i + 1, len(points)):
                x2, y2 = points[j]
                if x1 == x2 or y1 == y2:
                    continue
                if (x1, y2) in seen and (x2, y1) in seen:
                    best = min(best,
                               abs(x1 - x2) * abs(y1 - y2))
        return 0 if best == float("inf") else best

C++ O(n²)

class Solution {
public:
    int minAreaRect(vector<vector<int>>& points) {
        unordered_set<long long> seen;
        for (const auto& p : points) seen.insert(key(p[0], p[1]));
        int best = INT_MAX;
        for (int i = 0; i < (int)points.size(); ++i) {
            for (int j = i + 1; j < (int)points.size(); ++j) {
                int x1 = points[i][0], y1 = points[i][1];
                int x2 = points[j][0], y2 = points[j][1];
                if (x1 == x2 || y1 == y2) continue;
                if (seen.count(key(x1, y2)) &&
                    seen.count(key(x2, y1))) {
                    best = min(best, abs(x1 - x2) * abs(y1 - y2));
                }
            }
        }
        return best == INT_MAX ? 0 : best;
    }
private:
    long long key(int x, int y) {
        return (static_cast<long long>(x) << 32) |
               static_cast<unsigned int>(y);
    }
};
