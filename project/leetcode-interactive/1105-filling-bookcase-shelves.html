填充书架

书的顺序不能改变，但每一层在哪里“断开”由你决定。先亲手观察一次决策过程，再展开完整题解。

MEDIUM数组动态规划非付费题

题目

给定 books，其中 books[i] = [thicknessᵢ, heightᵢ] 表示第 i 本书的厚度和高度；另给书架宽度 shelfWidth。

必须保持原顺序，把连续的若干本书分到同一层，且每层厚度之和不超过书架宽度。每层高度等于该层最高的书，整体高度为各层高度之和。求可能的最小整体高度。

函数签名

minHeightShelves(books: integer[][], shelfWidth: integer) -> integer

约束

  • 1 ≤ books.length ≤ 1000
  • 1 ≤ thicknessᵢ ≤ shelfWidth ≤ 1000
  • 1 ≤ heightᵢ ≤ 1000

官方示例

示例 1
输入：books = [[1,1],[2,3],[2,3],[1,1],[1,1],[1,1],[1,2]], shelfWidth = 4
输出：6
解释：可分成 3 层，层高之和为 1 + 3 + 2 = 6；第 2 本书不必放在第一层。
示例 2
输入：books = [[1,3],[2,4],[3,2]], shelfWidth = 6
输出：4

思考：若最后一层放第 j...i 本书，那么前 j-1 本书的最佳摆法是否可以直接复用？

动态规划：枚举最后一层

核心洞察

令 dp[i] 为放好前 i 本书的最小总高度，dp[0]=0。计算 dp[i] 时，从第 i 本书向左枚举最后一层的起点 j，同步累加宽度和更新最高书；只要宽度合法，就用 dp[j-1] + maxHeight(j...i) 更新答案。

完整过程

  1. 初始化 dp[0]=0，其余为无穷大。
  2. 依次计算 i=1..n。
  3. 向左枚举 j=i..1；加入第 j 本书后若超宽立即停止。
  4. 否则更新当前层最高高度，并取所有切分方案的最小值。
  5. 返回 dp[n]。

正确性

最优子结构：任意最优摆法的最后一层必然由某段连续书 j...i 组成；此前的书若不是以最小高度摆放，就能替换成更优方案，从而与整体最优矛盾。因此该方案高度正是 dp[j-1] + maxHeight(j...i)。算法枚举了所有宽度合法的 j，不会遗漏最优最后一层；取最小值即得到 dp[i]。由 dp[0] 起归纳，最终 dp[n] 正确。

边界与复杂度

  • 单本书恰好占满一层；所有书都能同层；高书在层首或层尾。
  • 时间复杂度 O(n²)，空间复杂度 O(n)。

替代方案

记忆化搜索同样可枚举下一层放多少本书，复杂度仍为 O(n²)，但有递归栈。贪心地“能塞就塞”并不正确：提前换层可能让后续高书与其他书合层，从而降低总高度。

面试追问

  • 为什么只能枚举连续段？因为题目禁止改变书的相对顺序。
  • 为什么超宽后可以停止向左？厚度均为正数，继续加入只会更宽。
  • 能否降到线性？一般输入下，层内最大值与宽度约束让候选切分无法简单合并。

常见错误

  • 把层高累加成每本书高度，而不是取本层最大值。
  • 更新最大高度后才检查宽度虽不影响结果，但容易误用非法候选。
  • dp 下标与书本下标差 1，写成 dp[j] 会错。

完整代码

class Solution {
    public int minHeightShelves(int[][] books, int shelfWidth) {
        int n = books.length;
        int[] dp = new int[n + 1];
        java.util.Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;
        for (int i = 1; i <= n; i++) {
            int width = 0, height = 0;
            for (int j = i; j >= 1; j--) {
                width += books[j - 1][0];
                if (width > shelfWidth) break;
                height = Math.max(height, books[j - 1][1]);
                dp[i] = Math.min(dp[i], dp[j - 1] + height);
            }
        }
        return dp[n];
    }
}
