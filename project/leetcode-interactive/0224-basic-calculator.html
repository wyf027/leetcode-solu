基本计算器

Basic Calculator：在不使用 eval 等表达式求值函数的前提下，计算只含整数、加减、括号和空格的有效表达式。

O(n) 单次扫描括号栈帧符号上下文

题意

扫描字符并返回计算结果

输入是合法表达式 s，只会出现数字、+、-、(、) 与空格。- 可以一元使用；所有中间值均在 32 位有符号整数范围内。

输入：s = "(1+(4+5+2)-3)+(6+8)"

输出：23

空格写作可见符号 ␠：例如 s = "1␠+␠1"。

核心洞察

括号前先存“外层结果 × 符号”

维护当前层的 result、sign 与正在读取的 number。遇到 (，压入 result 与 sign，然后从 0、+1 重新开始；遇到 )，先结算 number，再恢复并合并外层栈帧。

关键不变量：任何时刻 result 都是已完整读完项的和，未完成 number 尚未加入。

题解：符号 + 栈帧

数字读完时加入 result += sign * number。括号把已有结果和进入括号前的符号压栈；右括号先结算当前数，然后以 outerResult + outerSign * innerResult 合并。

完整过程

  1. 累积连续数字。
  2. 遇到 + / -，结算数字并更新下一项符号。
  3. 遇到 (，压入 result、sign 并重置。
  4. 遇到 )，结算、弹出符号和外层结果。

复杂度与边界

每个字符最多处理常数次，时间 O(n)，嵌套括号的栈空间 O(n)。注意前导一元负号、空格、深括号和末尾数字。

替代方案

递归下降解析器同样清晰，但递归深度受语言栈限制。此迭代栈方案更适合 n 可达 300,000 的约束。

常见错误 / 追问

忘记在 ) 或字符串末尾结算数字、把 sign 只压不弹、用 eval 都会出错或违题意。追问乘除时要增加运算符优先级层。
