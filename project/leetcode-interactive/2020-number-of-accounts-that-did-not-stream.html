Number of Accounts That Did Not Stream

题意与约束

统计在 2021 年内至少一天订阅有效，且 2021 年没有任何播放会话的帐户数。输出一行，列名为 accounts_count。跨年延续的订阅也算；其他年份的播放不影响结果。

独立题解

先自行思考，再展开推导和代码。

核心洞察：集合差

A 是订阅覆盖 2021 的帐户集合，B 是 2021 有播放的帐户集合。答案是 |A ∖ B|。SQL 用 NOT EXISTS 判断 B 中不存在该帐户。

完整过程

  1. 订阅有交集：start_date < 2022-01-01 且 end_date ≥ 2021-01-01。
  2. 相关子查询只找同帐户、日期处于 [2021-01-01, 2022-01-01) 的会话。
  3. 不存在此类会话时保留订阅行，最后 COUNT(*)。

示例 A = {9,3,13,4,5}，B = {3,13,5}；差集 {9,4} 的大小为 2。2020 年会话不加入 B。

正确性证明

订阅与目标年不相交，当且仅当它在目标年之前结束，或在目标年之后开始。两个日期条件恰好排除这些情况，所以候选集合就是 A。子查询存在当且仅当有该帐户的目标年播放，因此 NOT EXISTS 恰好保留 A 中不属于 B 的帐户。account_id 为订阅表主键，每个帐户只计一次，计数既不重复也不遗漏。

边界与常见错误

  • 结束于 2021-01-01 仍有效；开始于 2022-01-01 则无效。
  • 2021-12-31 的播放算目标年；2022-01-01 的播放不算。
  • 空播放表应保留全部有效订阅；空订阅表返回 0。
  • 不要只判断订阅开始年份；会漏掉跨年订阅。
  • 不要以“存在非 2021 播放”代替“没有 2021 播放”，同帐户可以同时有这两类记录。
  • 直接连接会话再计数可能重复。NOT IN 的子查询若含 NULL 会触发三值逻辑陷阱；NOT EXISTS 不受无关 NULL 记录影响。

复杂度

设 n 为订阅数，m 为会话数。四语言哈希实现的期望时间 O(n+m)，额外空间 O(m)。SQL 依赖执行计划：朴素相关扫描最坏可达 O(nm)，哈希反连接可接近 O(n+m)。Streams(account_id, stream_date) 索引适合相关范围查找；不要仅凭 SQL 文本承诺固定成本。日期范围比较避免给索引列包裹 YEAR。

替代方案

LEFT JOIN 把帐户匹配与目标年日期条件放在 ON 中，WHERE 判断 t.session_id IS NULL。session_id 是非空主键，能识别未匹配行。也可先对目标年播放帐户去重，再做集合差。

面试追问

一个帐户有多段订阅？候选帐户需要 DISTINCT，或从独立帐户表用 EXISTS 找有效订阅，再反查播放。

只检查订阅有效期内的播放？必须额外与订阅区间相交，这是新的业务条件，不应暗中加入本题。

目标年可变？参数化该年与次年 1 月 1 日，保留半开时间窗口。

MySQL · 官方可提交语言

SELECT COUNT(*) AS accounts_count
FROM Subscriptions AS s
WHERE s.start_date < '2022-01-01'
  AND s.end_date >= '2021-01-01'
  AND NOT EXISTS (
    SELECT 1 FROM Streams AS t
    WHERE t.account_id = s.account_id
      AND t.stream_date >= '2021-01-01'
      AND t.stream_date < '2022-01-01'
  );

以下四语言为完整的本地语义函数，不是该数据库题的官方提交接口。输入遵守表约束，日期采用固定宽度 YYYY-MM-DD 字符串，返回整数。全部代码待补验证。

Java · 本地语义参考（Java 17）

import java.util.*;

public class Solution {
    public record Subscription(int accountId, String start, String end) {}
    public record Stream(int sessionId, int accountId, String date) {}
    public static long findTargetAccounts(List<Subscription> subscriptions,
                                           List<Stream> streams) {
        Set<Integer> watched = new HashSet<>();
        for (Stream t : streams)
            if (t.date().compareTo("2021-01-01") >= 0
                    && t.date().compareTo("2022-01-01") < 0)
                watched.add(t.accountId());
        long count = 0;
        for (Subscription s : subscriptions)
            if (s.start().compareTo("2022-01-01") < 0
                    && s.end().compareTo("2021-01-01") >= 0
                    && !watched.contains(s.accountId())) count++;
        return count;
    }
}

JavaScript · 本地语义参考

// subscriptions: [account_id, start_date, end_date][]
// streams: [session_id, account_id, stream_date][]
function findTargetAccounts(subscriptions, streams) {
  const watched = new Set();
  for (const [, id, date] of streams)
    if (date >= '2021-01-01' && date < '2022-01-01') watched.add(id);
  let count = 0;
  for (const [id, start, end] of subscriptions)
    if (start < '2022-01-01' && end >= '2021-01-01'
        && !watched.has(id)) count++;
  return count;
}

Python · 本地语义参考（非 Pandas 提交）

# subscriptions: (account_id, start_date, end_date) rows
# streams: (session_id, account_id, stream_date) rows
def find_target_accounts(subscriptions, streams):
    watched = {
        account_id for _, account_id, date in streams
        if "2021-01-01" <= date < "2022-01-01"
    }
    return sum(
        start < "2022-01-01" and end >= "2021-01-01"
        and account_id not in watched
        for account_id, start, end in subscriptions
    )

C++ · 本地语义参考（C++17）

#include <string>
#include <vector>
#include <unordered_set>
using namespace std;
struct Subscription { int accountId; string start, end; };
struct Stream { int sessionId, accountId; string date; };
long long findTargetAccounts(const vector<Subscription>& subscriptions,
                             const vector<Stream>& streams) {
    unordered_set<int> watched;
    for (const auto& t : streams)
        if (t.date >= "2021-01-01" && t.date < "2022-01-01")
            watched.insert(t.accountId);
    long long count = 0;
    for (const auto& s : subscriptions)
        if (s.start < "2022-01-01" && s.end >= "2021-01-01"
            && !watched.count(s.accountId)) ++count;
    return count;
}
