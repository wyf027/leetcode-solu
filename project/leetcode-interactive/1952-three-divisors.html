三除数.

Three Divisors

一个整数，恰好三个正除数。先观察，再解释。

01题目

给定整数 n，判断它是否恰好有 3 个不同的正除数。有则返回 true，否则返回 false。正整数 m 能整除 n，即存在整数 k 使 n = k × m 时，m 就是它的正除数。

官方示例 1

输入：n = 2
输出：false

正除数只有 1、2，共 2 个。

官方示例 2

输入：n = 4
输出：true

正除数为 1、2、4，共 3 个。

约束：1 ≤ n ≤ 10⁴。参数为整数 n，返回值为布尔值；函数名 isThree。

04独立题解

准备好后，再揭开计数规律。

让除数两两相遇

核心洞察

若 d 能整除 n，那么 n / d 也能整除 n。每一对除数中至少有一个不超过 √n，因此只需枚举 d = 1 到 ⌊√n⌋。一对不同的除数贡献 2；当 d × d = n 时，两个值相同，只贡献 1。

完整过程 · 与实验台一致

  1. 令 count = 0，从 d = 1 开始，循环条件为 d × d ≤ n。
  2. 如果 n % d ≠ 0，跳过这个候选数；否则令 q = n / d。
  3. 若 d = q，则 count 加 1；否则 count 加 2。
  4. 枚举结束，返回 count === 3。实验台用集合展示已发现的除数，提交代码只需计数。

例如 n = 4：d = 1 找到 (1, 4)，计数为 2；d = 2 找到 (2, 2)，只加 1。最终计数为 3，返回 true。n = 12 时依次找到 (1, 12)、(2, 6)、(3, 4)，最终为 6，返回 false。

正确性证明

完整性：对于任意正除数 a，它的配对除数为 b = n / a。若二者均大于 √n，则 ab > n，矛盾。所以每一对必然会在枚举较小者时被找到。

唯一性：不同的非平方配对仅有较小者被枚举，较大者不超过边界的情况只会出现在两者相等时。相等时只计 1，因此无重复计数。循环结束后 count 就是不同正除数的总数，比较它与 3 即得到题目要求的结果。

边界与复杂度

n = 1 时 (1, 1) 只计一次，返回 false；质数仅有 1 与自身，返回 false；平方根必须去重，例如 4 只计三个除数。n = 10000 在官方范围内，d × d 至多略超过 10000，四种语言的整数计算均足够。

时间 O(√n)，辅助空间 O(1)。这是四份提交代码的复杂度；交互页面为展示除数额外保存列表，不属于提交算法的空间开销。

替代方案

  • 直接枚举：检查 1 到 n 的每个整数并计数。时间 O(n)、空间 O(1)，简单且在当前范围可行。
  • 质数平方判定：恰好三个正除数当且仅当 n = p² 且 p 为质数。除数配对说明三个除数必包含 1、√n、n；若 √n 为合数，就会产生额外除数。反之质数平方只有 1、p、p²。先判断完全平方，再试除检查 p 的素性，最坏时间 O(n^(1/4))、空间 O(1)，并明确排除 p < 2。
  • 多次查询：对 √N 以内的整数筛出质数，再标记质数平方。适合大量查询，不必为单次小范围输入增加预处理。

四语言完整代码

采用相同的配对计数算法，签名对应官方提交格式。以下代码尚未执行验证。

Java

class Solution {
    public boolean isThree(int n) {
        int count = 0;
        for (int d = 1; d * d <= n; d++) {
            if (n % d == 0) {
                count += (d * d == n) ? 1 : 2;
            }
        }
        return count == 3;
    }
}

Python

class Solution:
    def isThree(self, n: int) -> bool:
        count = 0
        d = 1
        while d * d <= n:
            if n % d == 0:
                count += 1 if d * d == n else 2
            d += 1
        return count == 3

常见错误

  • 将“恰好三个”写成“至少三个”。例如 12 有六个除数，应返回 false。
  • 对平方根仍加 2，重复计数；或者用 d × d < n，漏掉平方根。
  • 把所有完全平方数当作答案：16 的除数为 1、2、4、8、16，共 5 个。
  • 将 1 当作质数。1 只有一个正除数，不能作为质数平方方案的正例。

面试追问

能否提前返回？计数超过 3 后可以立即返回 false，因为计数只增不减；计数等于 3 时却不能立即返回 true，后续可能还有除数。

范围扩大到大整数怎么办？循环比较可改为 d ≤ n / d，避免固定宽度整数乘法溢出。JavaScript 超过安全整数范围时需要 BigInt，并统一所有算术操作的类型。

如何推广到恰好 k 个除数？仍可用配对计数。若已有质因数分解 n = ∏pᵢ^aᵢ，则正除数个数为 ∏(aᵢ + 1)；恰好 3 个时只能有一个指数 2。
