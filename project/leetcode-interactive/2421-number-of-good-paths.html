01 / 题目

沿途不能出现更大的值

给定一棵含 n 个节点的无向树，节点编号为 0 到 n − 1。数组 vals 表示节点值；二维数组 edges 中每个 [a, b] 表示 a 与 b 之间的无向边。树连通、无环，恰有 n − 1 条边。

统计所有满足以下条件的简单路径：

  1. 两个端点的节点值相同。
  2. 沿途所有节点的值都不超过端点的值。

简单路径不重复经过节点。单个节点也是一条好路径；一条路径与其反向只计一次。返回不同好路径的总数。

参数：numberOfGoodPaths(vals: integer[], edges: integer[][]) → integer

约束

  • n == vals.length，1 ≤ n ≤ 3 × 10⁴。
  • 0 ≤ vals[i] ≤ 10⁵。
  • edges.length == n − 1，edges[i].length == 2。
  • 0 ≤ aᵢ, bᵢ < n，aᵢ ≠ bᵢ。
  • edges 保证构成一棵合法的树。

04 / 独立题解

准备好拆开这道题了吗？

展开后可使用阈值森林推演器，查看证明与完整代码。

核心洞察：把路径限制变成连通性

固定端点值 t，只保留值 ≤ t 的节点及它们之间的边。两个值为 t 的节点能够组成好路径，当且仅当它们处在这片森林的同一个连通分量里。

若一个分量含 c 个值恰好为 t的节点，就新增 c(c − 1) / 2 条非单节点好路径。较小值节点只充当连接桥梁，不参与本轮端点计数。所有单节点路径一开始统一计入答案 n。

完整过程

  1. 建立邻接表，把节点按值升序排序，初始化并查集与答案 n。
  2. 取当前值 t 的整组节点，把它们与所有值 ≤ t 的邻居合并。
  3. 整组的合并完成后，按最终根节点统计本组节点数量 c。
  4. 每个分量加上 c(c − 1) / 2，处理下一个值，最后返回总数。

为什么一定正确

  1. 连通不变量：完成阈值 t 的整组合并后，并查集恰好表示由值 ≤ t 的节点形成的森林。较小阈值内的边已处理；新出现的边至少有一个端点值为 t，会在本轮被合并。大于 t 的节点不会被连接进来。
  2. 充要关系：好路径的所有节点值 ≤ t，所以两个端点在该森林中连通。反过来，森林中连通意味着存在一条所有节点值 ≤ t 的路径；树保证这条简单路径唯一，端点值又同为 t，因此它是好路径。
  3. 不重不漏：同一分量中的 c 个本轮节点恰有 C(c,2) 个无序端点对，每对对应唯一一条路径；不同分量无法形成路径，不同阈值对应不同端点值，不会重复。再加初始化时计入的 n 条单节点路径，得到全部答案。

边界与数值范围

  • n = 1 时没有边，答案为 1；值为 0 不需要特殊处理。
  • 全不同值时答案为 n；全相同值时答案为 n(n + 1) / 2。
  • 同值端点被较大节点隔开时，当前阈值下不会连通。
  • 最大答案为 30000 × 30001 / 2 = 450015000，四份代码所用数值类型均可容纳；c(c − 1) 最大 899970000，Java / C++ 的 int 中间乘积也在范围内。
  • find 使用迭代路径压缩与按大小合并，避免长链上的递归栈问题。

复杂度

排序 O(n log n)；邻接表共扫描 2(n − 1) 个邻居，并查集操作摊还 O(n α(n))。采用哈希计数的通常平均复杂度下，总时间 O(n log n)，辅助空间 O(n)。α(n) 是反阿克曼函数，实际规模下增长极慢。

替代方案

  • 逐起点 DFS：枚举端点并沿途维护最大值，最坏 O(n²)，只适合小规模推导，n = 30000 时不合适。
  • 按边阈值排序：令边权为两个端点值的最大值，递增合并，维护分量最大值及其数量；相同最大值的分量合并时贡献数量乘积。仍为 O(n log n)，但合并计数逻辑更易出错。
  • 值域桶：利用值 ≤ 10⁵ 按值分桶，省去比较排序，时间 O(n α(n) + U)，空间 O(n + U)，U 是值域大小；本页选择更直接的排序。

常见错误

  • 把整个分量大小当成 c：只统计本轮值等于 t 的节点。
  • 尚未完成同值组的合并就计数：根与分量还可能变化。
  • 只连接值严格小于 t 的邻居：会漏掉相同值节点之间的边。
  • 对路径正反方向分别计数，或忘记单节点路径。
  • JavaScript 使用默认字典序排序，或将计数除法写成不必要的位运算。

面试追问

如果输入是一般图？并查集仍能判断端点之间是否存在合规路径，但一对端点可能对应多条简单路径，因此这个组合计数不再是所有好路径的数量。

能输出所有路径吗？路径条数本身可达 O(n²)，逐条输出节点序列的总长度还可能达到 O(n³)。当前算法只返回数量。

为什么整组处理？同值节点可互相连接，只有全部相关边处理完成后分量才稳定；统一计数避免对临时分量重复计算。

import java.util.*;

class Solution {
    private int[] parent, size;

    private int find(int x) {
        while (x != parent[x]) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    private void union(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (size[a] < size[b]) {
            int t = a; a = b; b = t;
        }
        parent[b] = a;
        size[a] += size[b];
    }

    public int numberOfGoodPaths(int[] vals, int[][] edges) {
        int n = vals.length;
        List<List<Integer>> graph = new ArrayList<>();
        parent = new int[n];
        size = new int[n];
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
            parent[i] = i; size[i] = 1; order[i] = i;
        }
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        Arrays.sort(order, Comparator.comparingInt(i -> vals[i]));
        int answer = n;
        for (int i = 0; i < n;) {
            int j = i, value = vals[order[i]];
            while (j < n && vals[order[j]] == value) j++;
            for (int k = i; k < j; k++) {
                int u = order[k];
                for (int v : graph.get(u)) {
                    if (vals[v] <= value) union(u, v);
                }
            }
            Map<Integer, Integer> count = new HashMap<>();
            for (int k = i; k < j; k++) {
                count.merge(find(order[k]), 1, Integer::sum);
            }
            for (int c : count.values()) answer += c * (c - 1) / 2;
            i = j;
        }
        return answer;
    }
}

/**
 * @param {number[]} vals
 * @param {number[][]} edges
 * @return {number}
 */
var numberOfGoodPaths = function(vals, edges) {
    const n = vals.length;
    const graph = Array.from({length: n}, () => []);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
    }
    const parent = Array.from({length: n}, (_, i) => i);
    const size = Array(n).fill(1);
    function find(x) {
        while (x !== parent[x]) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    function union(a, b) {
        a = find(a); b = find(b);
        if (a === b) return;
        if (size[a] < size[b]) [a, b] = [b, a];
        parent[b] = a;
        size[a] += size[b];
    }
    const order = Array.from({length: n}, (_, i) => i)
        .sort((a, b) => vals[a] - vals[b]);
    let answer = n;
    for (let i = 0; i < n;) {
        let j = i;
        const value = vals[order[i]];
        while (j < n && vals[order[j]] === value) j++;
        for (let k = i; k < j; k++) {
            const u = order[k];
            for (const v of graph[u]) {
                if (vals[v] <= value) union(u, v);
            }
        }
        const count = new Map();
        for (let k = i; k < j; k++) {
            const root = find(order[k]);
            count.set(root, (count.get(root) || 0) + 1);
        }
        for (const c of count.values()) answer += c * (c - 1) / 2;
        i = j;
    }
    return answer;
};

Python 3

from typing import List
from collections import Counter

class Solution:
    def numberOfGoodPaths(self, vals: List[int], edges: List[List[int]]) -> int:
        n = len(vals)
        graph = [[] for _ in range(n)]
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)
        parent = list(range(n))
        size = [1] * n

        def find(x):
            while x != parent[x]:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            a, b = find(a), find(b)
            if a == b:
                return
            if size[a] < size[b]:
                a, b = b, a
            parent[b] = a
            size[a] += size[b]

        order = sorted(range(n), key=lambda u: vals[u])
        answer = n
        i = 0
        while i < n:
            j = i
            value = vals[order[i]]
            while j < n and vals[order[j]] == value:
                j += 1
            for k in range(i, j):
                u = order[k]
                for v in graph[u]:
                    if vals[v] <= value:
                        union(u, v)
            count = Counter(find(order[k]) for k in range(i, j))
            answer += sum(c * (c - 1) // 2 for c in count.values())
            i = j
        return answer

C++

#include <vector>
#include <numeric>
#include <algorithm>
#include <unordered_map>
using namespace std;

class Solution {
    vector<int> parent, sz;
    int find(int x) {
        while (x != parent[x]) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a;
        sz[a] += sz[b];
    }
public:
    int numberOfGoodPaths(vector<int>& vals, vector<vector<int>>& edges) {
        int n = vals.size();
        vector<vector<int>> graph(n);
        for (const auto& e : edges) {
            graph[e[0]].push_back(e[1]);
            graph[e[1]].push_back(e[0]);
        }
        parent.resize(n);
        iota(parent.begin(), parent.end(), 0);
        sz.assign(n, 1);
        vector<int> order(n);
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int a, int b) {
            return vals[a] < vals[b];
        });
        int answer = n;
        for (int i = 0; i < n;) {
            int j = i, value = vals[order[i]];
            while (j < n && vals[order[j]] == value) ++j;
            for (int k = i; k < j; ++k) {
                int u = order[k];
                for (int v : graph[u]) {
                    if (vals[v] <= value) unite(u, v);
                }
            }
            unordered_map<int, int> count;
            for (int k = i; k < j; ++k) ++count[find(order[k])];
            for (const auto& entry : count) {
                int c = entry.second;
                answer += c * (c - 1) / 2;
            }
            i = j;
        }
        return answer;
    }
};
