Minimum Swaps to Group All 1's Together

函数签名：minSwaps(data)

返回值：完成目标所需的最少交换次数。

01 / 题目

让所有 1 紧挨在一起

交换可以发生在数组中的任意两个位置；只需要返回最少次数，不需要输出交换方案。

给定一个仅由 0 和 1 组成的数组 data。一次操作可以选取两个位置并交换它们的值。

请计算最少需要多少次交换，才能让数组中的所有 1 出现在同一个连续区间内。这个连续区间可以位于数组的任意位置；区间之外允许保留 0。

参数与约束

  • 1 ≤ data.length ≤ 105
  • data[i] 只能是 0 或 1
  • 输入：data: integer[]
  • 输出：integer

示例 1

输入：data = [1,0,1,0,1]
输出：1

交换一对 0 与 1 后，可以得到形如 [1,1,1,0,0] 的排列，三个 1 连续。

示例 2

输入：data = [0,0,0,1,0]
输出：0

数组中只有一个 1，它本身已经构成连续区间，因此不需要交换。

示例 3

输入：data = [1,0,1,0,1,0,0,1,1,0,1]
输出：3

选择合适的目标连续区间，将区间外的 1 与区间内的 0 成对交换，最少需要 3 次。

03 / 题解

固定长度窗口里的 0，就是代价

把最终形态反过来看：不是模拟每次交换，而是选择最省代价的目标区间。

设数组中共有 k 个 1。所有 1 聚在一起后，必然占据某个长度为 k 的连续区间。这个区间里每出现一个 0，就需要从区间外换入一个 1。

答案 = 长度为 k 的窗口中，0 的最少数量 = k − 窗口内 1 的最大数量

完整过程

  1. 遍历数组，统计 1 的总数 k。
  2. 若 k ≤ 1，已经天然连续，直接返回 0。
  3. 计算前 k 个元素里有多少个 1，作为第一个窗口的计数。
  4. 窗口每次右移一格：加入新元素，移除左端旧元素，维护窗口内 1 的数量。
  5. 记录所有窗口中的最大 1 数 maxOnes，返回 k - maxOnes。

为什么正确

任意可行的最终状态都对应某个长度为 k 的目标区间，因为 k 个 1 必须连续且总数不变。假设该区间内有 z 个 0，那么区间内就缺 z 个 1；由于全数组共有 k 个 1，区间外恰好也有 z 个 1。

每次把一个区间内的 0 与一个区间外的 1 交换，可以同时消除一对错位，因此恰好需要 z 次；少于 z 次不可能填满全部 z 个空位。于是固定目标区间的最优代价就是其 0 的数量，在全部长度为 k 的区间中取最小值即得到全局最优解。

边界情况

  • 全是 0：k = 0，无需交换。
  • 只有一个 1：单个元素已经连续，答案为 0。
  • 全是 1：唯一窗口不含 0，答案为 0。
  • 最佳窗口可能在数组最左端或最右端，滑动时必须覆盖最后一个窗口。
时间 O(n) 空间 O(1)

替代方案

  • 前缀和：预处理 1 的前缀数量后，O(1) 查询每个长度 k 的区间，总时间 O(n)、空间 O(n)。思路直观，但空间不如滑动窗口。
  • 逐窗口重数：对每个起点重新数窗口中的 0，最坏 O(nk)，在 105 数据规模下会超时。
  • 记录 1 的位置：更适合“只能相邻交换”的变体；本题可任意交换，不需要计算移动距离。

class Solution {
    public int minSwaps(int[] data) {
        int ones = 0;
        for (int value : data) {
            ones += value;
        }

        if (ones <= 1) {
            return 0;
        }

        int windowOnes = 0;
        for (int i = 0; i < ones; i++) {
            windowOnes += data[i];
        }

        int maxOnes = windowOnes;
        for (int right = ones; right < data.length; right++) {
            windowOnes += data[right];
            windowOnes -= data[right - ones];
            maxOnes = Math.max(maxOnes, windowOnes);
        }

        return ones - maxOnes;
    }
}

var minSwaps = function (data) {
    const ones = data.reduce((total, value) => total + value, 0);

    if (ones <= 1) {
        return 0;
    }

    let windowOnes = 0;
    for (let i = 0; i < ones; i += 1) {
        windowOnes += data[i];
    }

    let maxOnes = windowOnes;
    for (let right = ones; right < data.length; right += 1) {
        windowOnes += data[right];
        windowOnes -= data[right - ones];
        maxOnes = Math.max(maxOnes, windowOnes);
    }

    return ones - maxOnes;
};

class Solution:
    def minSwaps(self, data: List[int]) -> int:
        ones = sum(data)

        if ones <= 1:
            return 0

        window_ones = sum(data[:ones])
        max_ones = window_ones

        for right in range(ones, len(data)):
            window_ones += data[right]
            window_ones -= data[right - ones]
            max_ones = max(max_ones, window_ones)

        return ones - max_ones

class Solution {
public:
    int minSwaps(vector<int>& data) {
        int ones = accumulate(data.begin(), data.end(), 0);

        if (ones <= 1) {
            return 0;
        }

        int windowOnes = accumulate(data.begin(), data.begin() + ones, 0);
        int maxOnes = windowOnes;

        for (int right = ones; right < static_cast<int>(data.size()); ++right) {
            windowOnes += data[right];
            windowOnes -= data[right - ones];
            maxOnes = max(maxOnes, windowOnes);
        }

        return ones - maxOnes;
    }
};

面试追问

  • 如果数组首尾相连？ 在长度 2n 的逻辑数组上扫描，但窗口起点只取前 n 个，并保持窗口长度 k。
  • 如果只能交换相邻元素？ 代价变成移动距离，通常记录 1 的位置并围绕中位数计算，不能再只数窗口中的 0。
  • 能否返回一个最佳目标区间？ 更新最大窗口计数时同步记录窗口左端点即可。
  • 若数据以流形式到达？ k 未知时通常需要两遍：先统计 k，再用大小为 k 的队列维护窗口。

常见错误

  • 把“任意交换”误解成“相邻交换”，进而累加下标距离。
  • 窗口长度写成 k - 1 或数组长度，偏离最终连续块的真实长度。
  • 滑动时只加入右端，没有移除 right - k 位置的旧元素。
  • 把本题当成环形数组，错误地跨越首尾寻找窗口。
  • 没有处理 k 为 0 或 1 的情况，导致空窗口逻辑难以理解或越界。
