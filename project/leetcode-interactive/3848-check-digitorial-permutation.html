3848. 阶数数字排列

把所有数字重排后，能否得到一个“各位阶乘之和等于自身”的数字？这题不必枚举排列：阶乘和与数字的出现次数都是排列不变量。

题意

给定 n。若某个数的每一位阶乘之和等于该数，称它为阶数数字。判断 n 的某个不含前导零的排列是否是阶数数字。

排列只会改变位置，不会改变每个数字出现的次数；因此也不会改变各位阶乘之和。

示例

n = 145
阶乘和：1! + 4! + 5! = 145，原顺序已经可用。
n = 10
1! + 0! = 2；01 又是无效前导零排列。

约束：1 ≤ n ≤ 10^9。

交互：追踪阶乘和与数字频次

边界提示

  • 0! = 1，零也必须计入阶乘和。
  • 若阶乘和的十进制数字频次不同，任何排列都无能为力。
  • 目标阶数数字本身是正整数，标准十进制写法天然没有前导零。

题解区域

默认折叠，按需展开完整推导与四语言代码。

核心洞察

设 S = Σ digit!。无论怎样排列，S 都相同。某个排列成为阶数数字，当且仅当它等于 S；所以只要比较 n 与 S 的十个数字频次。

完整过程

  1. 预存 0! 到 9!。
  2. 逐位累加阶乘，得到 S。
  3. 分别统计 n 与 S 的数字频次；数组相等即有解。

复杂度与替代方案

时间 O(d)，空间 O(1)，其中 d 是位数。枚举全排列会达到 O(d! · d)，既慢又忽略了不变量。

面试追问与常见错误

追问：若允许任意删改数字，就不再能只用频次比较。常见错误：忘记 0! = 1、把阶乘和与原数直接比较（漏掉重排）、或枚举所有排列。

class Solution {
    public boolean isDigitorialPermutation(int n) {
        int[] fact = {1, 1, 2, 6, 24, 120, 720, 5040, 40320, 362880};
        int[] count = new int[10];
        int x = n, sum = 0;
        while (x > 0) { count[x % 10]++; sum += fact[x % 10]; x /= 10; }
        while (sum > 0) { count[sum % 10]--; sum /= 10; }
        for (int v : count) if (v != 0) return false;
        return true;
    }
}

var isDigitorialPermutation = function(n) {
  const fact = [1,1,2,6,24,120,720,5040,40320,362880], count = Array(10).fill(0);
  let x = n, sum = 0;
  while (x > 0) { count[x % 10]++; sum += fact[x % 10]; x = Math.floor(x / 10); }
  while (sum > 0) { count[sum % 10]--; sum = Math.floor(sum / 10); }
  return count.every(v => v === 0);
};
