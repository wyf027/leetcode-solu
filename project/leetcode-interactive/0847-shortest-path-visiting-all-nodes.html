题目描述

给定一个含 n 个节点（编号 0 到 n - 1）的无向连通图。graph[i] 列出与节点 i 直接相连的全部节点。

求一条能够访问所有节点的最短路径的边数。起点和终点可以任意选择；节点可以重复访问，边也可以重复经过。

输入 / 输出：函数 shortestPathLength(graph: integer[][]): integer 接收邻接表，返回最短路径长度。路径本身不要求返回。

示例 1

星形图输出 4
输入：graph = [[1,2,3],[0],[0],[0]]
输出：4
解释：一种可行的最短路径是 [1,0,2,0,3]。

示例 2

含环连通图输出 4
输入：graph = [[1],[0,2,4],[1,3,4],[2],[1,2]]
输出：4
解释：一种可行的最短路径是 [0,1,4,2,3]。

约束

  • n == graph.length
  • 1 <= n <= 12
  • 0 <= graph[i].length < n
  • graph[i] 不包含 i
  • 若 graph[a] 包含 b，则 graph[b] 包含 a
  • 输入图始终连通

题解：在扩展图上做多源 BFS

状态
(u, mask) 表示当前位于 u，且 mask 记录走过的节点。
起点
任意起点都合法，因此把所有 (i, 1<<i) 同时作为距离 0 的起点。
终点
任一状态的 mask == (1<<n)-1，即已经覆盖全部节点。

核心洞察

只记录“现在在哪”会丢失已经访问过哪些节点的信息；只记录“访问集合”又无法判断下一步能走到哪里。把二者组合后，原问题变成状态图上的无权最短路。原图一条边 u → v 对应状态转移 (u, mask) → (v, mask | (1<<v))。

完整过程

  1. 令 full = (1 << n) - 1，创建 n × 2^n 的访问标记。
  2. 将每个节点作为独立起点：把 (i, 1 << i) 全部放入同一个队列，标记为已见。
  3. 按 BFS 层弹出状态。若掩码为 full，立即返回当前层数。
  4. 枚举当前节点的邻居 v，构造新掩码；未见过的新状态入队。每处理完一层，距离加一。

正确性证明

状态完备：任意原图行走序列都逐边映射为状态图中的路径，状态中的掩码恰好是该序列已访问节点的集合；反之，每次状态转移都沿原图真实边移动，因此状态路径也对应合法行走。

覆盖所有起点：初始化包含所有可能的单节点起点，所以任意最优路径的起点都已纳入搜索。

最短性：状态图的每条边代价均为 1。BFS 按距离非递减顺序访问状态，因此第一次遇到全覆盖掩码时，其距离不大于任何其他可达全覆盖状态。由状态完备性，它就是原问题答案。

边界情况

  • n = 1 时初始掩码已全覆盖，答案为 0。
  • 树或星形图中允许重复经过中心与边，这是题意允许且可能必要的。
  • 不同路径到达相同 (节点, 掩码) 后，后续选择完全相同，因此只需保留首次到达。

复杂度

状态数最多为 n · 2^n。每个状态枚举当前节点的邻边，总时间为 O((n + m) · 2^n)，常简写为 O(n² · 2^n)；访问表与队列空间为 O(n · 2^n)。

四语言完整代码

import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int shortestPathLength(int[][] graph) {
        int n = graph.length;
        int full = (1 << n) - 1;
        boolean[][] seen = new boolean[n][1 << n];
        Queue<int[]> queue = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            int mask = 1 << i;
            queue.offer(new int[]{i, mask});
            seen[i][mask] = true;
        }

        int distance = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();
            while (size-- > 0) {
                int[] state = queue.poll();
                int node = state[0], mask = state[1];
                if (mask == full) return distance;
                for (int next : graph[node]) {
                    int nextMask = mask | (1 << next);
                    if (!seen[next][nextMask]) {
                        seen[next][nextMask] = true;
                        queue.offer(new int[]{next, nextMask});
                    }
                }
            }
            distance++;
        }
        return -1;
    }
}

var shortestPathLength = function(graph) {
    const n = graph.length;
    const full = (1 << n) - 1;
    const seen = Array.from({ length: n }, () => new Uint8Array(1 << n));
    const queue = [];

    for (let node = 0; node < n; node++) {
        const mask = 1 << node;
        queue.push([node, mask]);
        seen[node][mask] = 1;
    }

    let head = 0;
    let distance = 0;
    while (head < queue.length) {
        const levelEnd = queue.length;
        while (head < levelEnd) {
            const [node, mask] = queue[head++];
            if (mask === full) return distance;
            for (const next of graph[node]) {
                const nextMask = mask | (1 << next);
                if (!seen[next][nextMask]) {
                    seen[next][nextMask] = 1;
                    queue.push([next, nextMask]);
                }
            }
        }
        distance++;
    }
    return -1;
};
from collections import deque
from typing import List

class Solution:
    def shortestPathLength(self, graph: List[List[int]]) -> int:
        n = len(graph)
        full = (1 << n) - 1
        seen = [[False] * (1 << n) for _ in range(n)]
        queue = deque()

        for node in range(n):
            mask = 1 << node
            queue.append((node, mask))
            seen[node][mask] = True

        distance = 0
        while queue:
            for _ in range(len(queue)):
                node, mask = queue.popleft()
                if mask == full:
                    return distance
                for nxt in graph[node]:
                    next_mask = mask | (1 << nxt)
                    if not seen[nxt][next_mask]:
                        seen[nxt][next_mask] = True
                        queue.append((nxt, next_mask))
            distance += 1
        return -1

替代方案

可以先用 Floyd–Warshall 求任意两点最短距离，再做旅行商式状态压缩 DP：dp[mask][u] 表示访问集合为 mask 且停在 u 的最短长度。它同样是 O(n²·2^n)，但实现与常数更大；直接在原图状态空间做多源 BFS 更自然。

面试追问

为什么不能从节点 0 单源 BFS？

最优路径允许从任意节点开始。固定节点 0 可能强迫额外路程；多源初始化等价于给所有合法起点接一个代价为 0 的超级源点。

为什么访问标记必须同时包含 node 和 mask？

同一节点携带不同已访问集合时，未来补齐剩余节点的成本不同，不能相互剪枝。

若边有非负权重怎么办？

状态定义不变，把 BFS 换成 Dijkstra，并按最短距离松弛 (node, mask)。

常见错误

  • 把答案理解为访问节点数；题目要求的是经过的边数。
  • 只用 visited[node] 去重，错误合并不同掩码状态。
  • 忘记所有节点都能作为起点，只从某一个节点搜索。
  • 把“访问全部节点”误写成哈密顿路径，禁止重复节点；本题明确允许重复。
  • 用数组 shift() 实现 JavaScript 队列，造成不必要的线性移动；应维护头指针。
