让相邻两层的接缝错开。

01 / 任务说明

用高度均为 1、宽度来自 bricks 的砖，搭出高 height、宽 width 的矩形墙。每种砖数量无限，不能旋转；每层必须恰好铺满。

坚实的要求是：任意相邻两层，在墙内部不能有处于同一横坐标的接缝。两侧边界不受限制。求不同铺法的数量，对 1,000,000,007 取模。

参数：buildWall(height: integer, width: integer, bricks: integer[]) → integer。不同层或同层中的砖块位置不同，视为不同铺法。

官方示例 1

height = 2, width = 3, bricks = [1,2]
输出：2

上下两层分别采用 [1,2] 与 [2,1]，交换两层后得到另一种。相同排列叠放会产生重合接缝。

官方示例 2

height = 1, width = 1, bricks = [5]
输出：0

唯一的砖比整面墙更宽，无法铺出一层。

约束

  • 1 ≤ height ≤ 100
  • 1 ≤ width ≤ 10
  • 1 ≤ bricks.length ≤ 10
  • 1 ≤ bricks[i] ≤ 10
  • bricks 中的所有值互不相同。

03 / 用接缝表示一层，再逐层计数

一层的排列由内部接缝唯一决定。把横坐标 x 的接缝编码为 1 << (x - 1)，只需要 width − 1 位。上下两层的掩码按位与为 0，就能相邻。墙的左右边界不编码。

接缝实验台

固定 width = 3, bricks = [1,2]。先观察所有行状态，再逐对比较，最后汇总逐层方案。高度可切换；这是算法演示，所有验证待补。

等待开始

所有按钮支持 Tab 聚焦及 Enter / 空格操作。自动播放可随时暂停；减少动态效果设置下使用较慢的切换。

核心洞察与完整过程

  1. 枚举行状态：从已铺长度 0 开始 DFS。尝试每种不会超宽的砖；若新长度小于 width，记录该接缝；等于 width 时收集掩码。砖宽互异，所以同一个行掩码不会被重复生成。
  2. 构建相容关系：枚举状态 i、j，若 (masks[i] & masks[j]) == 0，记录从 i 到 j 的转移，包括可能的自身转移。
  3. 初始化：dp[i] = 1，表示一层且末行为 i 的方案数。没有任何行状态时直接得到 0。
  4. 逐层扩展：每轮创建全零 next；沿相容边累加 next[j] += dp[i]，每次取模，再令 dp = next。执行 height − 1 轮。
  5. 汇总：所有末行状态互斥，因此答案为 dp 所有元素之和取模。
dp₁[j] = 1
 dpₕ[j] = Σ dpₕ₋₁[i]，其中 masks[i] & masks[j] = 0
 answer = Σ dp_height[j] mod 1,000,000,007

示例如何流过状态

按 DFS 顺序，A = [1,1,1] 的 mask 为 11，B = [1,2] 为 01，C = [2,1] 为 10（二进制左侧是 x=2）。第一层的向量是 [1,1,1]。A 不能连接任一行；B 只能连接 C，C 只能连接 B。因此第二层是 [0,1,1]，总数 2。

正确性

行枚举：DFS 的每条完整路径都由合法砖宽构成且总宽度恰好正确；反过来任意合法行的砖宽序列对应唯一 DFS 路径。接缝间距恢复每块砖的宽度，掩码不会丢失行信息。

相容判定：按位与的某位为 1 当且仅当相邻两层在对应内部位置都有接缝。因此按位与为 0 与坚实条件等价。

归纳：高度 1 时每种行排列恰有一种墙。假设 dp 正确计数高度 h − 1 的墙，把合法末行 j 接到每个相容的末行 i 后恰好产生全部高度 h、末行为 j 的墙。删除末行可以唯一恢复前驱，故无遗漏、无重复。对末行求和即为所求。

边界与常见错误

  • height = 1 时所有合法行都有效，不必要求自己与自己相容。
  • width = 1 时没有内部位；若有宽度 1 的砖，任意合法高度的答案均为 1。
  • 单块整砖的 mask = 0，可与自身或任意行相邻，不能统一禁止自环。
  • 砖过长直接跳过；不能整铺一层时，状态集为空，结果为 0。
  • 约束针对任意相邻两层，不是只禁止贯穿整面墙的长接缝；非相邻层可以重合。
  • 不要记录两侧边界，否则所有行都会被错误判为冲突。不要原地更新 dp，否则会混入同轮结果。
  • 每次加法立即取模。下面 Java/C++ 用 64 位累加；JavaScript 每步最多相加两个小于 MOD 的数，保持整数精确。

复杂度

令 W = width、H = height、B = bricks.length、S 为合法行状态数、E 为有向相容边数。S ≤ 2W−1 ≤ 512。DFS 总前缀节点数 O(2W)，每个节点尝试 B 种砖，因此生成耗时 O(B·2W)；建图 O(S²)，滚动 DP 为 O(H·(S+E))。总时间 O(B·2W + S² + H·(S+E))，空间 O(S+E+W)。最坏 E ≤ S²；显式计入 DFS 代价也覆盖 S=0 的情况。

替代方案

可以逐轮枚举所有状态对，省去邻接表，空间降为 O(S+W)，但每层做 S² 次判断。记忆化搜索 (剩余高度, 末行) 与此 DP 等价。若 H 极大，可用相容矩阵快速幂，典型稠密实现 O(S³ log H)，本题 H ≤ 100 没有必要。宽度成为瓶颈时还可研究对子集补集做和的 SOS DP。

面试追问

  • 为什么不记录整个墙？ 新行只与上一行发生约束，较早的层已经被方案数汇总。
  • 如果砖宽允许重复？ 若只是重复规格，先去重；若是不同颜色的砖，则同接缝状态具有多种权重，需要加权初始化和转移。
  • 如果要还原一面墙？ 另外记录可达性和前驱，不能以模后计数非零替代可达性，因为真实正数可能模后为 0。
  • 如果改成禁止贯穿全墙的接缝？ 需追踪多层接缝交集，原来的相邻行相容关系过强，不能直接复用。

Java

import java.util.*;

class Solution {
    private void enumerate(int pos, int mask, int width,
                           int[] bricks, List<Integer> masks) {
        if (pos == width) {
            masks.add(mask);
            return;
        }
        for (int b : bricks) {
            int end = pos + b;
            if (end <= width) {
                int bit = end < width ? 1 << (end - 1) : 0;
                enumerate(end, mask | bit, width, bricks, masks);
            }
        }
    }

    public int buildWall(int height, int width, int[] bricks) {
        final long MOD = 1_000_000_007L;
        List<Integer> masks = new ArrayList<>();
        enumerate(0, 0, width, bricks, masks);
        int n = masks.size();
        List<List<Integer>> nextRows = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            nextRows.add(new ArrayList<>());
            for (int j = 0; j < n; j++)
                if ((masks.get(i) & masks.get(j)) == 0)
                    nextRows.get(i).add(j);
        }
        long[] dp = new long[n];
        Arrays.fill(dp, 1);
        for (int row = 1; row < height; row++) {
            long[] next = new long[n];
            for (int i = 0; i < n; i++)
                for (int j : nextRows.get(i))
                    next[j] = (next[j] + dp[i]) % MOD;
            dp = next;
        }
        long answer = 0;
        for (long ways : dp) answer = (answer + ways) % MOD;
        return (int) answer;
    }
}

JavaScript

/**
 * @param {number} height
 * @param {number} width
 * @param {number[]} bricks
 * @return {number}
 */
var buildWall = function(height, width, bricks) {
    const MOD = 1000000007;
    const masks = [];
    function enumerate(pos, mask) {
        if (pos === width) {
            masks.push(mask);
            return;
        }
        for (const b of bricks) {
            const end = pos + b;
            if (end <= width) {
                const bit = end < width ? 1 << (end - 1) : 0;
                enumerate(end, mask | bit);
            }
        }
    }
    enumerate(0, 0);
    const n = masks.length;
    const nextRows = Array.from({length: n}, () => []);
    for (let i = 0; i < n; i++)
        for (let j = 0; j < n; j++)
            if ((masks[i] & masks[j]) === 0) nextRows[i].push(j);
    let dp = Array(n).fill(1);
    for (let row = 1; row < height; row++) {
        const next = Array(n).fill(0);
        for (let i = 0; i < n; i++)
            for (const j of nextRows[i])
                next[j] = (next[j] + dp[i]) % MOD;
        dp = next;
    }
    return dp.reduce((sum, ways) => (sum + ways) % MOD, 0);
};

Python

from typing import List

class Solution:
    def buildWall(self, height: int, width: int, bricks: List[int]) -> int:
        mod = 10**9 + 7
        masks = []

        def enumerate_rows(pos: int, mask: int) -> None:
            if pos == width:
                masks.append(mask)
                return
            for b in bricks:
                end = pos + b
                if end <= width:
                    bit = (1 << (end - 1)) if end < width else 0
                    enumerate_rows(end, mask | bit)

        enumerate_rows(0, 0)
        n = len(masks)
        next_rows = [[] for _ in range(n)]
        for i in range(n):
            for j in range(n):
                if masks[i] & masks[j] == 0:
                    next_rows[i].append(j)
        dp = [1] * n
        for _ in range(1, height):
            nxt = [0] * n
            for i in range(n):
                for j in next_rows[i]:
                    nxt[j] = (nxt[j] + dp[i]) % mod
            dp = nxt
        return sum(dp) % mod

C++

#include <vector>
#include <functional>
using namespace std;

class Solution {
public:
    int buildWall(int height, int width, vector<int>& bricks) {
        const long long MOD = 1000000007;
        vector<int> masks;
        function<void(int, int)> enumerate = [&](int pos, int mask) {
            if (pos == width) {
                masks.push_back(mask);
                return;
            }
            for (int b : bricks) {
                int end = pos + b;
                if (end <= width) {
                    int bit = end < width ? 1 << (end - 1) : 0;
                    enumerate(end, mask | bit);
                }
            }
        };
        enumerate(0, 0);
        int n = masks.size();
        vector<vector<int>> nextRows(n);
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if ((masks[i] & masks[j]) == 0)
                    nextRows[i].push_back(j);
        vector<long long> dp(n, 1);
        for (int row = 1; row < height; row++) {
            vector<long long> next(n, 0);
            for (int i = 0; i < n; i++)
                for (int j : nextRows[i])
                    next[j] = (next[j] + dp[i]) % MOD;
            dp.swap(next);
        }
        long long answer = 0;
        for (long long ways : dp) answer = (answer + ways) % MOD;
        return static_cast<int>(answer);
    }
};
