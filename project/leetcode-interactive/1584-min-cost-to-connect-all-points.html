Min Cost to Connect All Points

数组图最小生成树Prim

题目

给定整数坐标数组 points，其中 points[i] = [xᵢ, yᵢ] 表示二维平面上的一个点。连接两点的费用等于它们的曼哈顿距离：

distance(i, j) = |xᵢ - xⱼ| + |yᵢ - yⱼ|

请选择一些连接，使任意两点之间都存在且仅存在一条简单路径，并返回所需的最小总费用。

函数签名

minCostConnectPoints(points: integer[][]): integer

示例 1 输入：points = [[0,0],[2,2],[3,10],[5,2],[7,0]]
输出：20
解释：可以用总费用 20 将五个点连成一棵树。
示例 2 输入：points = [[3,12],[-2,5],[-4,1]]
输出：18
补充官方示例 输入：points = [[0,0],[1,1],[1,0],[-1,1]]
输出：4

约束与目标

  • 1 ≤ points.length ≤ 1000
  • -10⁶ ≤ xᵢ, yᵢ ≤ 10⁶
  • 所有坐标对互不相同。

“连接”意味着什么？

最终结构不能有孤立点，也不能有环；对 n 个点，它恰好包含 n - 1 条边。

Solution

题解：用 Prim 构造最小生成树

核心洞察完整过程正确性四语言代码测试与验证

核心洞察

把每个点看成图的顶点，任意两点之间都有一条权重为曼哈顿距离的边。题目要找的正是这张完全图的最小生成树（MST）权重。

直接列出全部边再用 Kruskal，需要存储并排序约 n² / 2 条边。由于图是稠密完全图，使用朴素 Prim 更直接：用 minDist[i] 维护未加入点 i 到当前生成树的最小连接费用，每轮挑选其中最小者。

完整过程

  1. 任选点 0 作为起点；令它的 minDist 为 0，其余为无穷大。
  2. 在所有未加入生成树的点中，找到 minDist 最小的点 u。
  3. 把 u 加入生成树，并将 minDist[u] 计入答案。
  4. 枚举每个未加入点 v，用 distance(u, v) 尝试更新 minDist[v]。
  5. 重复 n 轮。每个点恰好加入一次，累计费用即答案。

正确性证明

  1. 维护含义：每轮开始时，对任意未加入点 v，minDist[v] 是从当前树中某点连到 v 的最小边权。初始及每次用新点更新后，该性质都成立。
  2. 选择安全：算法选择的边是跨越“已加入点集合 / 未加入点集合”这一割的最小权边。根据最小生成树的割性质，存在一棵最小生成树包含这条边，因此加入它不会失去最优解。
  3. 终止与最优：每轮加入一个新点，经过 n 轮所有点均已加入，除起点外每点对应一条连接边，共 n-1 条且无环。连续采用安全边，最终得到的生成树就是最小生成树，累计费用最小。

复杂度

  • 时间：O(n²)。进行 n 轮，每轮线性选点并线性更新。
  • 空间：O(n)，只保存访问状态与最短连接费用。

边界情况

  • 只有一个点：无需边，返回 0。
  • 存在负坐标：绝对值距离照常计算。
  • 两点极远：单边费用可达 4 × 10⁶。
  • 点共线或多条边同权：任选安全的最小边均可。

替代方案

Kruskal + 并查集

生成所有 O(n²) 条边并排序，时间约 O(n² log n)，空间 O(n²)。概念直观，但本题不如朴素 Prim 节省内存。

堆优化 Prim

可把候选边放进优先队列，但完全图仍需处理大量边，复杂度通常为 O(n² log n)，并不优于数组选点。

四语言完整代码

import java.util.Arrays;

class Solution {
    public int minCostConnectPoints(int[][] points) {
        int n = points.length;
        int[] minDist = new int[n];
        boolean[] used = new boolean[n];
        Arrays.fill(minDist, Integer.MAX_VALUE);
        minDist[0] = 0;
        int answer = 0;

        for (int round = 0; round < n; round++) {
            int u = -1;
            for (int i = 0; i < n; i++) {
                if (!used[i] && (u == -1 || minDist[i] < minDist[u])) {
                    u = i;
                }
            }

            used[u] = true;
            answer += minDist[u];

            for (int v = 0; v < n; v++) {
                if (!used[v]) {
                    int distance = Math.abs(points[u][0] - points[v][0])
                                 + Math.abs(points[u][1] - points[v][1]);
                    minDist[v] = Math.min(minDist[v], distance);
                }
            }
        }
        return answer;
    }
}

面试追问

  • 为什么不用 Dijkstra？ Dijkstra 最小化单源到各点的路径距离；本题最小化连接所有顶点的边权总和，目标不同。
  • Prim 为什么可以任选起点？ 起点只影响构造顺序或具体树形，不影响最小生成树的最小总权值。
  • 如何恢复具体边？ 更新 minDist[v] 时同步记录 parent[v] = u，点 v 加入时取 (parent[v], v)。
  • 坐标规模会溢出吗？ 单边最大 4×10⁶，最多 999 条边，总和小于 Java/C++ 32 位有符号整数上限。

常见错误

  • 误用欧氏距离，或忘记对坐标差取绝对值。
  • 只连接每个点最近的邻居；局部最近不保证形成连通且无环的全局最优结构。
  • 更新 minDist 时没有排除已加入点，或把同一点重复计费。
  • 把 minDist 理解为到起点的最短路径；它表示到“整棵当前树”的最便宜单边连接。
