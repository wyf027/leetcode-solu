堆叠长方体
的最大高度

Maximum Height by Stacking Cuboids——先把旋转自由度“折叠”掉，再把三维堆叠变成一条可计算的最长链。

◇先读题、再操作可视化；完整题解默认锁在页面底部。
Problem

题目描述

你需要做什么？

给定 n 个长方体，第 i 个的三个边长是 cuboids[i] = [widthᵢ, lengthᵢ, heightᵢ]。你可以选择其中任意子集，把选中的长方体竖直堆叠。

每个长方体都允许旋转，也就是它的三个尺寸可以重新分配给宽、长、高。若上方长方体的对应三个尺寸都不大于下方长方体，它就可以放在下方长方体之上。

返回所有合法堆叠方式中，竖直方向总高度的最大值。

  • 1可以只选一个长方体，也可以选多个；每个长方体至多使用一次。
  • 2上方 i 可放在下方 j 的条件是三个对应尺寸均满足 i ≤ j。
  • 3函数形式：maxHeight(cuboids: integer[][]): integer。

官方示例

示例 1
输入：cuboids = [[50,45,20],[95,37,53],[45,23,12]]
输出：190
解释：三层高度分别为 95、50、45，总高度 190。
示例 2
输入：cuboids = [[38,25,45],[76,35,3]]
输出：76
解释：两者无法互相堆叠，旋转第二个使高度为 76。
示例 3
输入：cuboids = [[7,11,17],[7,17,11],[11,7,17],
                 [11,17,7],[17,7,11],[17,11,7]]
输出：102
解释：六个长方体均可旋转为同样朝向，6 × 17 = 102。
n == cuboids.length
1 ≤ n ≤ 100
1 ≤ 每条边长 ≤ 100

排序归一化 + 三维最长链 DP

核心洞察

对每个长方体内部的三条边升序排序为 [a,b,c]。可以统一把最大边 c 当作高度，另外两边作底面；旋转选择由此不再需要枚举。

状态与转移

再将所有三元组按字典序升序排列。令 dp[i] 为以第 i 个长方体作最底层时的最大高度：

dp[i] = cᵢ + max(dp[j])，其中 j < i 且 box[j] 的三维都 ≤ box[i]

完整过程

  1. 逐个对三个尺寸升序排序，得到规范表示 [a,b,c]。
  2. 对全部长方体按 a、再按 b、最后按 c 升序排序。
  3. 从左到右枚举底层 i，先令 dp[i] = cᵢ。
  4. 枚举所有 j < i。若 aⱼ ≤ aᵢ、bⱼ ≤ bᵢ、cⱼ ≤ cᵢ，就尝试用 dp[j] + cᵢ 更新。
  5. 所有 dp[i] 的最大值就是答案。

正确性证明

①
归一化不丢最优解。 将一个长方体的三边记为升序 a≤b≤c。若两个长方体存在某种旋转，使上方三维分别不大于下方三维，那么它们各自的第 1、2、3 小边也分别满足该关系。因此比较升序三元组足以刻画可堆叠性；同时把最大边当高度不会破坏任何原本可行的相邻关系。
②
状态覆盖所有候选。 固定底层 i。它上面的直接相邻长方体必是某个三维均不大于它的 j；全局排序保证这样的候选可在不晚于 i 的位置处理。转移枚举了每个候选 j。
③
最优子结构成立。 选择直接位于 i 上的 j 后，其上方必须采用以 j 为底的最优堆叠，否则替换成更高的合法堆叠即可改善原方案。因此转移准确得到以 i 为底的最优值。
④
答案正确。 任意非空最优堆叠都有一个底层 i，已被对应的 dp[i] 覆盖；取最大值即得到全局最优高度。

边界情况

  • 只有一个长方体：答案是它的最大边。
  • 尺寸完全相同：允许等号，全部都能堆叠。
  • 没有两者可堆叠：答案是所有长方体最大边中的最大值。
  • 重复长方体仍是不同实体，可分别使用一次。

复杂度与替代方案

时间：O(n²)；内部三边排序是常数，整体排序为 O(n log n)。

空间：O(n)，不计语言排序栈。

替代方案是枚举每个盒子的多种朝向，再做类似“盒子堆叠”的 DAG/DP；状态更大且容易重复使用同一盒子。本题的三维同时比较结构让规范化方案更简洁。

JavaLeetCode 可提交实现
import java.util.Arrays;

class Solution {
    public int maxHeight(int[][] cuboids) {
        for (int[] cuboid : cuboids) {
            Arrays.sort(cuboid);
        }

        Arrays.sort(cuboids, (x, y) -> {
            if (x[0] != y[0]) return Integer.compare(x[0], y[0]);
            if (x[1] != y[1]) return Integer.compare(x[1], y[1]);
            return Integer.compare(x[2], y[2]);
        });

        int n = cuboids.length;
        int[] dp = new int[n];
        int answer = 0;

        for (int i = 0; i < n; i++) {
            dp[i] = cuboids[i][2];
            for (int j = 0; j < i; j++) {
                if (cuboids[j][0] <= cuboids[i][0]
                        && cuboids[j][1] <= cuboids[i][1]
                        && cuboids[j][2] <= cuboids[i][2]) {
                    dp[i] = Math.max(dp[i], dp[j] + cuboids[i][2]);
                }
            }
            answer = Math.max(answer, dp[i]);
        }
        return answer;
    }
}

/**
 * @param {number[][]} cuboids

var maxHeight = function(cuboids) {
    for (const cuboid of cuboids) {
        cuboid.sort((a, b) => a - b);
    }

    cuboids.sort((x, y) =>
        x[0] - y[0] || x[1] - y[1] || x[2] - y[2]
    );

    const n = cuboids.length;
    const dp = new Array(n).fill(0);
    let answer = 0;

    for (let i = 0; i < n; i++) {
        dp[i] = cuboids[i][2];
        for (let j = 0; j < i; j++) {
            if (cuboids[j][0] <= cuboids[i][0] &&
                cuboids[j][1] <= cuboids[i][1] &&
                cuboids[j][2] <= cuboids[i][2]) {
                dp[i] = Math.max(dp[i], dp[j] + cuboids[i][2]);
            }
        }
        answer = Math.max(answer, dp[i]);
    }
    return answer;
};
Python 3LeetCode 可提交实现
from typing import List


class Solution:
    def maxHeight(self, cuboids: List[List[int]]) -> int:
        boxes = sorted(sorted(cuboid) for cuboid in cuboids)
        n = len(boxes)
        dp = [0] * n
        answer = 0

        for i, (a, b, c) in enumerate(boxes):
            dp[i] = c
            for j in range(i):
                x, y, z = boxes[j]
                if x <= a and y <= b and z <= c:
                    dp[i] = max(dp[i], dp[j] + c)
            answer = max(answer, dp[i])

        return answer

class Solution {
public:
    int maxHeight(vector<vector<int>>& cuboids) {
        for (auto& cuboid : cuboids) {
            sort(cuboid.begin(), cuboid.end());
        }
        sort(cuboids.begin(), cuboids.end());

        int n = static_cast<int>(cuboids.size());
        vector<int> dp(n, 0);
        int answer = 0;

        for (int i = 0; i < n; ++i) {
            dp[i] = cuboids[i][2];
            for (int j = 0; j < i; ++j) {
                if (cuboids[j][0] <= cuboids[i][0]
                        && cuboids[j][1] <= cuboids[i][1]
                        && cuboids[j][2] <= cuboids[i][2]) {
                    dp[i] = max(dp[i], dp[j] + cuboids[i][2]);
                }
            }
            answer = max(answer, dp[i]);
        }
        return answer;
    }
};

面试追问

  • 为什么一定能把最大边当高度？ 请从升序三元组的逐维支配关系解释，而不是只说“贪心”。
  • 若不允许旋转呢？ 不再做盒内排序，直接按题目给定的宽长高比较，DP 框架仍可沿用。
  • 若要求输出具体堆叠序列？ 增加 parent[i]，每次更新 dp[i] 时记录前驱，再从最大值位置回溯。
  • 能否快于 O(n²)？ 本质是三维偏序最长链并带权；可讨论坐标压缩、二维数据结构，但在 n ≤ 100 时没有工程必要。

常见错误

  • 只比较底面的两条边，忘记题目要求高度也必须满足逐维不大于。
  • 使用严格小于号，导致尺寸相等的长方体不能堆叠。
  • 只给全局排序，却没有先对每个长方体内部排序。
  • 把 dp[i] 定义为以 i 为顶，却在转移里把它当底，造成方向混乱。
  • 枚举六种朝向后没有记录原始编号，错误地重复使用同一长方体。
