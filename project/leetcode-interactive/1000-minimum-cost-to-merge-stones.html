合并石头的最低成本

每次只能合并连续的 k 堆。真正的难点不是“先合并哪一堆”，而是发现堆数变化的模规律，并让区间 DP 只枚举可能的切分。

题目

给定排成一行的 n 堆石头，第 i 堆有 stones[i] 块。一次操作必须把连续的恰好 k 堆合成一堆，代价为这 k 堆石头总数。求最终合成一堆的最小总代价；若无法完成，返回 -1。

约束

  • n == stones.length
  • 1 ≤ n ≤ 30
  • 1 ≤ stones[i] ≤ 100
  • 2 ≤ k ≤ 30

官方示例

输入：stones = [3,2,4,1], k = 2
输出：20

依次合并 [3,2]、[4,1]、[5,5]，总代价 5 + 5 + 10。

输入：stones = [3,2,4,1], k = 3
输出：-1

一次操作后剩 2 堆，无法继续。

输入：stones = [3,5,1,2,6], k = 3
输出：25

先合并 [5,1,2] 得 8，再合并 [3,8,6] 得 17。

区间折叠实验室

用示例 stones = [3,5,1,2,6], k = 3 观察可行性与 DP 状态如何收敛。

步骤 1 / 7
💡
先自己推一推：一次合并让堆数减少 k - 1。从 n 堆变成 1 堆，需要满足怎样的同余条件？区间又会自然缩成几堆？

题解：步长为 k − 1 的区间 DP

核心洞察

每次合并使堆数减少 k − 1，所以整体可行的必要且充分条件是 (n − 1) % (k − 1) == 0。对任一区间，我们先算把它尽量合并后的最低代价；只有区间长度满足同一模条件时，它才能再从 k 堆合为 1 堆，此时加上区间总和。

状态与转移

dp[i][j] 表示区间 [i, j] 尽可能合并到最少合法堆数的最低成本。用前缀和 O(1) 得到区间总石数。

dp[i][j] = min(dp[i][m] + dp[m+1][j])，m = i, i+(k−1), …, j−1
若 (j−i) % (k−1) == 0，再令 dp[i][j] += sum(i, j)

切分点按 k − 1 跳跃，是因为左半区必须能收缩成 1 堆，才能与右半区保留的若干堆共同形成合法状态。

完整过程

  1. 若整体不可行，立即返回 -1。
  2. 建立前缀和；令所有单点区间代价为 0。
  3. 按区间长度从 2 到 n 枚举左右端点。
  4. 枚举合法切分点，取左右区间代价之和的最小值。
  5. 若当前区间可进一步合成一堆，加上该区间石头总数。
  6. 返回 dp[0][n−1]。

正确性证明

可行性：每次操作固定减少 k−1 堆，因此 n 只有在与 1 模 k−1 同余时才能到达 1；反之可按 DP 构造逐层合法合并。
最优子结构：任一最优合并树的最后阶段，都可在某个合法切分点分为两个互不重叠的区间子问题；若任一子问题不是最优，替换它会得到更小总代价，与整体最优矛盾。
转移完备：算法枚举所有能让左区间收成一堆的切分点，因此覆盖最后阶段所有合法划分；取最小值后，在允许合成一堆时加区间和，恰好计入最后一次操作。
归纳结论：单点代价为 0。假设所有更短区间均正确，则当前区间由正确子问题和所有合法切分的最小值构成，故也正确；最终答案正确。

复杂度

时间 O(n³ / k)（通常写作 O(n³)）；空间 O(n²)。前缀和使每次区间求和为 O(1)。

边界

  • n = 1：无需操作，返回 0。
  • k > n 且 n > 1：不可行。
  • 不可行条件应在 DP 前判断。
  • 代价上界不大，但实现仍应使用足够大的 INF，避免加法溢出。

替代方案

可定义三维状态 dp[i][j][p]：把区间合成 p 堆的最低代价，语义更直接，复杂度和常数更高。二维写法利用“长度决定最终堆数”的模性质压缩了 p 维。

面试追问

  • 为什么切分点不是每次加 1？
  • 二维状态为何没有显式记录剩余堆数？
  • 若允许每次合并 2 到 k 堆，原状态还能成立吗？
  • 如何恢复具体的最优合并顺序？

常见错误

  • 漏掉整体可行性判断，错误返回一个有限值。
  • 对所有区间都加区间和；只有能从 k 堆合到 1 堆的区间才加。
  • 切分点步长写成 1，虽可能仍得到某些答案，但破坏状态语义并增加无效枚举。
  • 前缀和下标错一位，区间和应为 prefix[j+1] - prefix[i]。

四语言完整实现

class Solution {
    public int mergeStones(int[] stones, int k) {
        int n = stones.length;
        if ((n - 1) % (k - 1) != 0) return -1;
        int[] prefix = new int[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + stones[i];
        int[][] dp = new int[n][n];
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len <= n; i++) {
                int j = i + len - 1;
                dp[i][j] = Integer.MAX_VALUE / 4;
                for (int m = i; m < j; m += k - 1) {
                    dp[i][j] = Math.min(dp[i][j], dp[i][m] + dp[m + 1][j]);
                }
                if ((len - 1) % (k - 1) == 0) {
                    dp[i][j] += prefix[j + 1] - prefix[i];
                }
            }
        }
        return dp[0][n - 1];
    }
}

from typing import List

class Solution:
    def mergeStones(self, stones: List[int], k: int) -> int:
        n = len(stones)
        if (n - 1) % (k - 1) != 0:
            return -1
        prefix = [0] * (n + 1)
        for i, value in enumerate(stones):
            prefix[i + 1] = prefix[i] + value
        dp = [[0] * n for _ in range(n)]
        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                dp[i][j] = float("inf")
                for m in range(i, j, k - 1):
                    dp[i][j] = min(dp[i][j], dp[i][m] + dp[m + 1][j])
                if (length - 1) % (k - 1) == 0:
                    dp[i][j] += prefix[j + 1] - prefix[i]
        return dp[0][n - 1]
