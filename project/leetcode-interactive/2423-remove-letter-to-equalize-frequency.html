Remove Letter To Equalize Frequency

01 / 题目

给定从下标 0 开始、只包含小写英文字母的字符串 word。选择其中一个下标并删除该位置的字符。如果能使删除后仍然存在的每种字母出现次数全部相同，返回 true；否则返回 false。

必须恰好删除一个字符，不能选择不删。频率是出现次数；已经消失的字母不参与比较。

参数与返回：equalFrequency(word: string) → boolean

约束：2 ≤ word.length ≤ 100；word 只含小写英文字母 a–z。

官方示例 1

输入：word = "abcc"
输出：true

删除下标 3 的 c，得到 abc，三个字母各出现一次。

官方示例 2

输入：word = "aazz"
输出：false

删除任意一个字符后，两种字母的次数都会变成 1 和 2，无法相同。

04 / 独立题解

准备好后再展开：思路、证明与四种语言实现。

枚举要删的字母，检查剩余正频率

核心洞察

删除同一种字母的不同位置，对频率产生的影响完全相同。因此只需枚举最多 26 种字母：把该字母计数减一，再检查所有大于 0 的计数是否一致。

完整过程

  1. 用长度 26 的数组统计每个字母的次数。
  2. 枚举每个计数大于 0 的字母，将其计数减一，模拟恰好删除一个字符。
  3. 扫描频率数组，跳过 0；把第一个正频率记为目标值。之后发现不同的正频率则本次失败。
  4. 恢复被减去的次数。若本次全部相同，返回 true；否则继续枚举。
  5. 所有候选都失败，返回 false。

例如 abcc：原频率是 (1,1,2)。删 a 得 (0,1,2)，失败并恢复；删 b 得 (1,0,2)，失败并恢复；删 c 得 (1,1,1)，成功。

正确性

可靠性：算法只对原本存在的字母减一，所以每次模拟都对应合法的一次删除。只有剩余全部正频率相同才返回 true，满足题目条件。

完备性：任何合法删除都属于某一种字母。算法会枚举该字母，并得到与该删除相同的频率数组；若存在解，对应候选一定被识别。

候选独立性：每轮检查后恢复计数，保证后续候选仍从原始字符串开始，不会误删多个字符。结合上述性质，算法恰好判定是否存在有效删除。

边界与常见错误

  • 单一字母重复出现：删除一个后仍只剩一种字母，返回 true。
  • 所有字母各出现一次：删掉一种后，其余仍各一次，返回 true。
  • 只出现一次的字母被删除后计数为 0，必须忽略，否则会错判 abbcc。
  • 原频率已经相同也不一定成功，例如 aazz；不能跳过删除直接返回 true。
  • 不能只看最大频率与最小频率之差：aabbcccddd 差为 1，仍无法只删一个就平衡。
  • 每轮必须恢复计数；长度至少 2，删除后不可能没有字母。

复杂度

设字符串长度为 n，字母表大小为 Σ。统计用 O(n)，枚举与检查用 O(Σ²)，额外空间 O(Σ)。本题 Σ = 26，所以时间 O(n + 26²)，通常记作 O(n)；额外空间 O(1)。

替代方案

逐下标删除并重新统计：实现直观，但重复处理相同字母，时间 O(n²)、构造字符串时额外空间 O(n)。还可以统计“频率的频率”：只有一个频率组时，需只有一种字母或所有频率都是 1；有两个频率组时，需唯一的低频字母只出现一次，或唯一的高频字母比其他字母多一次。该方案统计后 O(Σ) 判定，但分类边界更多。

面试追问

  • 如何返回被删下标？保存成功的字母，再在线性扫描中取其任意一个位置。
  • 如果字符集很大？用哈希表计数，并采用频率分组判定，避免平方级枚举。
  • 如果允许最多删一个？先判断原字符串是否等频，再执行当前算法。
  • 如果恰好删 k 个？当前枚举不再充分；可以枚举目标正频率，并计算保留或删除各字母所需的代价，检查总删除数。

Java

class Solution {
    public boolean equalFrequency(String word) {
        int[] count = new int[26];
        for (char c : word.toCharArray()) count[c - 'a']++;
        for (int i = 0; i < 26; i++) {
            if (count[i] == 0) continue;
            count[i]--;
            int target = 0;
            boolean ok = true;
            for (int value : count) {
                if (value == 0) continue;
                if (target == 0) target = value;
                else if (value != target) {
                    ok = false;
                    break;
                }
            }
            count[i]++;
            if (ok) return true;
        }
        return false;
    }
}

class Solution:
    def equalFrequency(self, word: str) -> bool:
        count = [0] * 26
        for c in word:
            count[ord(c) - ord('a')] += 1
        for i in range(26):
            if count[i] == 0:
                continue
            count[i] -= 1
            target = 0
            ok = True
            for value in count:
                if value == 0:
                    continue
                if target == 0:
                    target = value
                elif value != target:
                    ok = False
                    break
            count[i] += 1
            if ok:
                return True
        return False

#include <string>
using namespace std;

class Solution {
public:
    bool equalFrequency(string word) {
        int count[26] = {};
        for (char c : word) count[c - 'a']++;
        for (int i = 0; i < 26; ++i) {
            if (count[i] == 0) continue;
            --count[i];
            int target = 0;
            bool ok = true;
            for (int value : count) {
                if (value == 0) continue;
                if (target == 0) target = value;
                else if (value != target) {
                    ok = false;
                    break;
                }
            }
            ++count[i];
            if (ok) return true;
        }
        return false;
    }
};
