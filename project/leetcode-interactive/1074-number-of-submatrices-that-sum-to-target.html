把二维矩阵，压成一维来数。

元素和为目标值的子矩阵数量 · Number of Submatrices That Sum to Target

HARD数组哈希表矩阵前缀和
Problem

题目

给定整数矩阵 matrix 和整数 target，返回元素总和恰好等于 target 的非空子矩阵数量。

子矩阵由 (x1,y1,x2,y2) 定义，包含全部满足 x1 ≤ x ≤ x2 且 y1 ≤ y ≤ y2 的单元格。任一边界坐标不同，就视为不同子矩阵。

numSubmatrixSumTarget(matrix: integer[][], target: integer) → integer

Examples

官方示例

示例 1

输入：matrix = [[0,1,0],
 [1,1,1],[0,1,0]], target = 0
输出：4
解释：四个只含 0 的 1×1 子矩阵。

示例 2

输入：matrix = [[1,-1],
 [-1,1]], target = 0
输出：5
解释：两个 1×2、两个 2×1，
以及整个 2×2 子矩阵。

示例 3

输入：matrix = [[904]], target = 0
输出：0
Constraints

约束

1 ≤ matrix.length ≤ 100

1 ≤ matrix[0].length ≤ 100

-1000 ≤ matrix[i][j] ≤ 1000

-10⁸ ≤ target ≤ 10⁸

Solution

枚举行带 + 前缀和频次

核心洞察

枚举 top 和 bottom，把行带内每列相加为 colSums。横跨该行带的目标子矩阵，与 colSums 中和为 target 的连续子数组一一对应。

一维计数

扫描时维护前缀和 P。此前每出现一次 P-target，就找到一个合法左端点。哈希表保存频次，初始为 {0:1}。

完整过程

  1. 枚举上边界，创建全零列和数组。
  2. 下边界向下扩展，逐列累加当前行。
  3. 为当前压缩数组新建前缀频次表 {0:1}。
  4. 扫描并累加 count[prefix-target]，再记录当前前缀。
  5. 处理完全部行带后返回答案。

正确性

  1. 每个子矩阵都有唯一上下边界，对应行带必被枚举。
  2. 固定行带后，连续列和等于对应子矩阵和。
  3. 区间和为 target 当且仅当两端前缀差为 target；频次表逐一计数合法左端点。
  4. 边界组合唯一，所以不重不漏。

边界与复杂度

必须记录空前缀；负数使普通滑动窗口失效。单行、单列、全零矩阵都自然适用。

时间 O(rows²×cols)，空间 O(cols)。枚举较短维度可达 O(min(m,n)²×max(m,n))。

import java.util.*;
class Solution {
 public int numSubmatrixSumTarget(int[][] a,int target){
  int m=a.length,n=a[0].length,ans=0;
  for(int top=0;top<m;top++){int[] s=new int[n];
   for(int bot=top;bot<m;bot++){
    for(int c=0;c<n;c++)s[c]+=a[bot][c];
    Map<Integer,Integer> f=new HashMap<>();f.put(0,1);
    int p=0;for(int x:s){p+=x;ans+=f.getOrDefault(p-target,0);
     f.put(p,f.getOrDefault(p,0)+1);}
   }
  }return ans;
 }
}

替代方案

二维前缀和配合四边枚举为 O(m²n²)，通常过慢。也可枚举左右列、按行压缩；应枚举较短维度。

常见错误

  • 用 Set 丢失重复前缀频次。
  • 忘记 count[0]=1。
  • 换 top 时没清零列和。
  • 含负数却使用滑动窗口。
  • 跨行带复用频次表。
