LCR 138/MEDIUM/字符串 · 有限状态机

有效数字

判断一个字符串能否表示十进制数字。关键不在于把它转成浮点数，而在于逐字符校验符号、小数点和指数的相对位置。

试一试

题意

给定字符串 s，若它是一个有效数字则返回 true。有效形式包括整数、小数，以及后接 e 或 E 和整数指数的科学计数法。

本题不允许依赖语言内置的数值解析器；需要自己识别语法。

约束

  • • s 仅含英文字母、数字、加号、减号或小数点。
  • • 需要在线性扫描中完成判断。
  • • 指数部分必须至少有一位数字，且不能出现小数点。

核心洞察

维护三个布尔量：seenDigit 表示当前段是否出现数字，seenDot 表示底数是否已有小数点，seenExp 表示是否进入指数。遇到指数时，必须保证此前有数字，并把 seenDigit 重置为 false，强制指数段重新出现数字。

完整过程

  1. 1. 数字：标记当前段已有数字。
  2. 2. 正负号：只能在开头，或紧跟 e/E。
  3. 3. 小数点：只能在指数前且只能一次。
  4. 4. 指数：只能一次，且前面必须已有数字；随后要求整数指数。
  5. 5. 其他字符：立即非法；扫描结束时必须有数字。

边界

  • • "."：没有数字，非法。
  • • ".1"、"3."：合法。
  • • "46.e3"：合法。
  • • "6e-1.5"：指数不能含小数点，非法。

复杂度

时间 O(n)：每个字符访问一次。空间 O(1)：仅维护常数个标记。

替代方案

可写正则表达式，但可读性和面试解释性较弱；有限状态机更容易逐条说明规则。

常见错误与追问

常见错误

未在 e/E 后重置数字标记，错误接受 "1e"；或允许指数后的点。

追问

若允许前后空格，可在扫描前裁剪；若需要识别十六进制或 NaN，应另行定义语法状态。

官方签名代码

// Java
class Solution {
  public boolean validNumber(String s) {
    boolean digit=false, dot=false, exp=false;
    for (int i=0;i<s.length();i++) {
      char c=s.charAt(i);
      if (Character.isDigit(c)) digit=true;
      else if (c=='.' && !dot && !exp) dot=true;
      else if ((c=='e'||c=='E') && digit && !exp) { exp=true; digit=false; }
      else if ((c=='+'||c=='-') && (i==0||s.charAt(i-1)=='e'||s.charAt(i-1)=='E')) {}
      else return false;
    } return digit;
  }
}
// JavaScript
var validNumber = function(s) {
  let digit=false, dot=false, exp=false;
  for (let i=0;i<s.length;i++) { const c=s[i];
    if (/\d/.test(c)) digit=true;
    else if (c==='.' && !dot && !exp) dot=true;
    else if ((c==='e'||c==='E') && digit && !exp) { exp=true; digit=false; }
    else if ((c==='+'||c==='-') && (i===0||s[i-1]==='e'||s[i-1]==='E')) continue;
    else return false;
  } return digit;
};

class Solution:
    def validNumber(self, s: str) -> bool:
        digit = dot = exp = False
        for i, c in enumerate(s):
            if c.isdigit(): digit = True
            elif c == '.' and not dot and not exp: dot = True
            elif c in 'eE' and digit and not exp: exp, digit = True, False
            elif c in '+-' and (i == 0 or s[i-1] in 'eE'): pass
            else: return False
        return digit
