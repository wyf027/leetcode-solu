题目

给定一棵以 root 为根的二叉树。若从根节点到节点 X 的整条路径上，不存在值严格大于 X 的节点，则称 X 是“好节点”。返回树中好节点的总数。

等价判断：当前节点值大于或等于到达它之前路径上的最大值时，它就是好节点。根节点始终是好节点。

约束

  • 二叉树节点数在 [1, 105] 范围内。
  • 每个节点的值在 [-104, 104] 范围内。
示例 1
输入：root = [3,1,4,3,null,1,5]
输出：4
解释：好节点为根 3、左下 3、4 和 5。
示例 2
输入：root = [3,3,null,4,2]
输出：3
解释：节点 2 的路径为 3 → 3 → 2，
      它不是好节点。
示例 3
输入：root = [1]
输出：1
解释：根节点是好节点。

题解：DFS + 路径最大值

状态走到节点时，只需携带从根到父节点的最大值 pathMax。
判断若 node.val >= pathMax，当前节点计入答案。
传递对子节点传入 max(pathMax, node.val)，两条分支互不干扰。

完整过程

  1. 从根节点开始 DFS。将根的值作为初始路径最大值，因此根必然满足条件。
  2. 访问节点时，把节点值与当前路径最大值比较；大于或等于时贡献 1，否则贡献 0。
  3. 用当前节点值更新路径最大值，再递归处理左右子树。
  4. 返回当前贡献、左子树答案和右子树答案之和。

正确性证明

不变式：每次 DFS 到达节点 x 时，参数 pathMax 等于从根到 x 的父节点这段路径上的最大节点值；根节点可直接以自身值作为初始最大值。

判断正确：根据定义，x 是好节点当且仅当路径上没有值严格大于 x.val 的节点，即 x.val >= pathMax。

传递正确：到任一子节点的路径只多出 x，因此新最大值恰为 max(pathMax, x.val)。

完备性：DFS 恰好访问每个节点一次并执行等价判断，累计结果就是全部好节点数。

边界情况

  • 单节点树：根节点直接计数，返回 1。
  • 重复值：禁止的是“严格更大”，所以等于路径最大值仍是好节点。
  • 负数节点：不要错误地把路径最大值初始化为 0。
  • 退化树：深度可达 105，工程环境中可改用显式栈。

复杂度

时间：O(n)递归空间：O(h)最坏空间：O(n)

四种语言完整代码

JavaLeetCode 签名
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int goodNodes(TreeNode root) {
        return dfs(root, root.val);
    }

    private int dfs(TreeNode node, int pathMax) {
        if (node == null) return 0;
        int count = node.val >= pathMax ? 1 : 0;
        int nextMax = Math.max(pathMax, node.val);
        return count + dfs(node.left, nextMax)
                     + dfs(node.right, nextMax);
    }
}

    const dfs = (node, pathMax) => {
        if (node === null) return 0;

        const nextMax = Math.max(pathMax, node.val);

C++LeetCode 签名
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int goodNodes(TreeNode* root) {
        return dfs(root, root->val);
    }
private:
    int dfs(TreeNode* node, int pathMax) {
        if (node == nullptr) return 0;
        int count = node->val >= pathMax ? 1 : 0;
        int nextMax = max(pathMax, node->val);
        return count + dfs(node->left, nextMax)
                     + dfs(node->right, nextMax);
    }
};

替代方案

  • BFS：队列中保存 [node, pathMax]，逻辑相同，空间为树的最大宽度。
  • 迭代 DFS：显式栈保存节点和路径最大值，避免递归调用栈过深；时间仍为 O(n)。
  • 回溯维护全局结构：可以维护路径上的有序结构，但只需最大值时明显过重。

面试追问

  • 若定义改为严格大于此前所有节点，比较符号应从 >= 改为 >。
  • 若要返回所有好节点，应在满足条件时收集节点或路径，而非只累加计数。
  • 如何避免深度为 105 时栈溢出？使用显式栈的迭代 DFS。
  • 为什么左右子树可以共享数值型 nextMax？因为它按值传递，分支不会互相污染。

常见错误

  • 只与父节点比较，而不是与整条根路径的最大值比较。
  • 使用 >，错误排除与路径最大值相等的节点。
  • 将最大值初始化为 0，导致全负数树判断错误。
  • 更新全局最大值后不回溯，使一条分支的值泄漏到另一条分支。
