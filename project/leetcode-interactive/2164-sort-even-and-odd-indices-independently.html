对奇偶下标分别排序

Sort Even and Odd Indices Independently

两类位置，两种顺序。先读规则，再想想哪些值可以互换。

题目

给定一个从 0 开始编号的整数数组 nums。重新排列其中的值，使奇数下标上的值按非递增顺序排列，偶数下标上的值按非递减顺序排列。返回调整后的数组。

区分的是下标的奇偶，不是数值的奇偶。非递增、非递减都允许相邻值相等。

官方示例 1

输入：nums = [4,1,2,3]
输出：[2,3,4,1]

奇数位置 1、3 的值从 1、3 调整为 3、1，得到 [4,3,2,1]；偶数位置 0、2 的值从 4、2 调整为 2、4，最终得到 [2,3,4,1]。

官方示例 2

输入：nums = [2,1]
输出：[2,1]

每类下标都只有一个元素，因此结果不变。

约束与接口

  • 1 ≤ nums.length ≤ 100
  • 1 ≤ nums[i] ≤ 100
  • 参数：nums: integer[]；返回：integer[]；函数名：sortEvenOdd。

核心洞察：下标决定归属

偶数位置的值只在偶数位置间重排，奇数位置同理。分别收集成两组，偶数组升序、奇数组降序，再交替回填。两组互不影响，先处理哪组都可以。

完整过程

  1. 扫描数组，把 0、2、4… 位置的值放入 even，把 1、3、5… 位置的值放入 odd。
  2. even 从小到大排序；odd 从大到小排序。
  3. 遍历位置 i：偶数位置使用 even[i // 2]，奇数位置使用 odd[i // 2]。

正确性、边界与代价

正确性

分组完整保留每类下标的所有值及其重复次数；排序不改变组内元素集合。回填时位置 2k 取偶数组第 k 项，位置 2k+1 取奇数组第 k 项，因此偶数位置序列非递减，奇数位置序列非递增。每项恰好使用一次，也没有跨组移动，故结果满足题意。

边界

n=1 时奇数组为空且不会被读取；n=2 时每组只有一项；奇数长度时偶数组多一项。重复值合法，不要求严格递增或递减。

复杂度

两组大小分别为 ⌈n/2⌉、⌊n/2⌋，常规比较排序总时间 O(n log n)，收集和回填各 O(n)。辅助分组占 O(n) 空间。JavaScript 内置排序的具体算法由引擎决定，此处按常规比较排序分析。

替代方案

值域为 1–100，可用两个长度 101 的计数数组：偶轨从低值向高值消费计数，奇轨反向消费。时间 O(n+U)，空间 O(U)，U=100。若要求常数额外空间，可对步长为 2 的两组位置做选择排序，代价是 O(n²) 时间。

常见错误

  • 判断数值奇偶而不是下标奇偶。
  • 排序整个数组，破坏两组各自的元素集合。
  • 奇数组也升序，违反非递增规则。
  • JavaScript 不传数值比较器，导致按字符串排序。
  • 用原下标直接访问分组，应使用整数商 i / 2。

面试追问

  • 能线性求解吗？可以利用有限值域计数排序。
  • 按下标模 k 分组呢？建立 k 个组，各自排序，用商确定组内位置。
  • 结果唯一吗？数值数组唯一，相同数值的身份顺序不要求稳定。
  • 不修改输入怎么做？新建长度 n 的结果数组再回填，空间仍为 O(n)。

Java

import java.util.Arrays;

class Solution {
    public int[] sortEvenOdd(int[] nums) {
        int n = nums.length;
        int[] even = new int[(n + 1) / 2];
        int[] odd = new int[n / 2];
        for (int i = 0; i < n; i++) {
            if (i % 2 == 0) even[i / 2] = nums[i];
            else odd[i / 2] = nums[i];
        }
        Arrays.sort(even);
        Arrays.sort(odd);
        for (int i = 0; i < n; i++) {
            nums[i] = i % 2 == 0
                ? even[i / 2]
                : odd[odd.length - 1 - i / 2];
        }
        return nums;
    }
}

/**
 * @param {number[]} nums
 * @return {number[]}

var sortEvenOdd = function(nums) {
    const even = nums.filter((_, i) => i % 2 === 0);
    const odd = nums.filter((_, i) => i % 2 === 1);
    even.sort((a, b) => a - b);
    odd.sort((a, b) => b - a);
    for (let i = 0; i < nums.length; i++) {
        nums[i] = (i % 2 === 0 ? even : odd)[Math.floor(i / 2)];
    }
    return nums;
};

from typing import List

class Solution:
    def sortEvenOdd(self, nums: List[int]) -> List[int]:
        even = sorted(nums[::2])
        odd = sorted(nums[1::2], reverse=True)
        for i in range(len(nums)):
            nums[i] = even[i // 2] if i % 2 == 0 else odd[i // 2]
        return nums
