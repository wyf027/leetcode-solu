购买最多物品数目 II

把“限次赠品”视作有限张 两件套券：只挑比单买两件更便宜的券。

题意

每种物品 items[i] = [factor_i, price_i] 可无限购买。买一份 i 最多送一份不同的 j，且 factor_i 整除 factor_j。同一有序对 (i,j) 最多赠送一次。总花费不得超过 budget，求拿到的购买品与赠品总数。

示例 1

items = [[1,6],[2,4],[3,5]], budget = 19

输出：5。买 0 两次、1 一次，0 的两次购买分别送 1 和 2。

约束

1 ≤ n ≤ 10^5，factor_i ≤ n，price_i, budget ≤ 10^9。

交互：先用哪些两件套券？

题解：容量有限的两件套，外加无限单件

核心洞察

购买 i 的前 c_i 份都能各送一件，其中 c_i 是所有满足 j ≠ i 且 factor_i | factor_j 的 j 数量。于是这 c_i 次购买，每次花 price_i 得 2 件；之后只能每次花全局最小价格得 1 件。

为何可贪心

两件套的单位成本为 price_i / 2。若 price_i ≥ 2·minPrice，它不优于买两个最便宜的单件；否则按 price_i 从小到大消费其有限容量，交换论证保证先取更便宜的券不会变差。

完整过程

  1. 用倍数筛：统计每个 factor 值出现次数；对 d 累加其倍数的频次，减去自身同一物品，得到每个物品的券容量。
  2. 取 minPrice，将 price < 2·minPrice 且容量正的物品按价格排序。
  3. 对每种券取 min(capacity, budget / price) 次，答案加两倍次数。
  4. 最后用 budget / minPrice 买单件。

边界

相同 factor 的不同下标可互送；同一物品不可送自己，因此容量要减一。预算和成本使用 64 位整数。

复杂度

倍数筛 O(n log n)，排序 O(n log n)，空间 O(n)。

替代方案

逐对检查整除关系是 O(n²)，在 10^5 下不可用。枚举购买数量也会遗漏无限单件阶段。

面试追问与常见错误

追问：若每对可赠送 k 次，只需把容量乘 k。常错：把 price == 2·minPrice 当作必须购买；它与两单件等价，可跳过。也不要把“同 factor”物品误判为不能互送。

class Solution {
  public long maxItems(int[][] items, int budget) {
    int n=items.length, max=0; long mn=Long.MAX_VALUE;
    for(int[] x:items){max=Math.max(max,x[0]); mn=Math.min(mn,x[1]);}
    int[] cnt=new int[max+1]; for(int[] x:items) cnt[x[0]]++;
    int[] cap=new int[n];
    for(int i=0;i<n;i++){int s=0; for(int v=items[i][0];v<=max;v+=items[i][0]) s+=cnt[v]; cap[i]=s-1;}
    Integer[] id=new Integer[n]; for(int i=0;i<n;i++) id[i]=i;
    java.util.Arrays.sort(id,(a,b)->Integer.compare(items[a][1],items[b][1]));
    long b=budget, ans=0;
    for(int i:id){long p=items[i][1]; if(p>=2*mn) break; long k=Math.min(cap[i],b/p); b-=k*p; ans+=2*k;}
    return ans+b/mn;
  }
}
