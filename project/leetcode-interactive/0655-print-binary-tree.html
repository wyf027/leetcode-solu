01 / Problem Brief

将树排进一张严格对称的坐标纸

给定二叉树根节点 root，构造从 0 开始编号的 m × n 字符串矩阵 res，并返回它。 这里的树高 height 按“根到最深叶子的边数”计算。

1

先确定画布

行数为 m = height + 1，列数为 n = 2^(height + 1) - 1。所有单元格初始都是空字符串。

2

根节点放正中

根节点位于顶行中点：res[0][(n - 1) / 2]。

3

孩子按幂次偏移

若节点在 res[r][c]，其左右孩子的列坐标分别是 c - 2^(height-r-1) 与 c + 2^(height-r-1)。

4

直到全部落位

对每个真实节点重复放置规则；不存在节点的位置保持 ""。 最终返回完整矩阵。

输入 
root = [1,2]
输出 
[["","1",""],
 ["2","",""]]

官方示例 2

输入 
root = [1,2,3,null,4]
输出 
[["","","","1","","",""],
 ["","2","","","","3",""],
 ["","","4","","","",""]]

Complete Solution

预留整棵满二叉树的宽度

真正的关键不是“画线”，而是先用最深层所需的满二叉树宽度锁定坐标，再让每一层的水平偏移按 2 的幂逐层减半。

核心洞察

  • 高度为 h 的树需要 2^(h+1)-1 列，正好对应同高度满二叉树的节点槽位。
  • 根在整个区间中点；到下一层时，孩子相对父节点偏移 2^(h-r-1) 列。
  • DFS 或 BFS 都能完成放置；坐标只由层数与父节点列坐标决定。

完整过程

  1. 递归求树高 h，空节点高度记为 -1。
  2. 创建 h+1 行、2^(h+1)-1 列的空字符串矩阵。
  3. 从根节点、行 0、列中点开始 DFS。
  4. 写入当前值；若有孩子，用本层偏移量计算下一行列坐标并继续。
  5. 遍历结束后返回矩阵。

正确性证明

  1. 根节点：算法把根写入第 0 行中点，符合顶行居中规则。
  2. 归纳假设：假设某节点已被正确放在 res[r][c]。
  3. 归纳步骤：算法把左右孩子分别放到下一行的 c ± 2^(h-r-1)，与题目定义完全一致。
  4. 终止：DFS 访问每个真实节点一次，空节点不写入，因此全部节点正确落位，其余格子保持空字符串。

边界与复杂度

  • 单节点：h=0，矩阵恰为 1×1。
  • 单侧链：仍按整棵满二叉树宽度建表，另一侧保持空字符串。
  • 负数与两位数：一个节点值仍作为一个字符串单元，不影响坐标。
  • 时间：初始化矩阵为 O(h·2^h)，放置节点为 O(N)。
  • 空间：返回矩阵占 O(h·2^h)；递归栈额外占 O(h)。

替代方案：递归维护区间中点

也可以为每个节点携带当前可用列区间 [left, right]，把节点放在 mid = (left + right) / 2；左子树使用 [left, mid-1]，右子树使用 [mid+1, right]。它与幂次偏移法等价，直观但每次递归要传更多边界参数。 若改用 BFS，则可避免递归栈，但队列需要同时保存节点、行与列坐标。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    public List<List<String>> printTree(TreeNode root) {
        int height = getHeight(root);
        int rows = height + 1;
        int cols = (1 << (height + 1)) - 1;

        List<List<String>> result = new ArrayList<>();
        for (int r = 0; r < rows; r++) {
            List<String> row = new ArrayList<>(
                Collections.nCopies(cols, "")
            );
            result.add(row);
        }

        place(root, 0, (cols - 1) / 2, height, result);
        return result;
    }

    private int getHeight(TreeNode node) {
        if (node == null) return -1;
        return Math.max(getHeight(node.left), getHeight(node.right)) + 1;
    }

    private void place(
        TreeNode node,
        int row,
        int col,
        int height,
        List<List<String>> result
    ) {
        if (node == null) return;
        result.get(row).set(col, Integer.toString(node.val));

        if (row == height) return;
        int offset = 1 << (height - row - 1);
        place(node.left, row + 1, col - offset, height, result);
        place(node.right, row + 1, col + offset, height, result);
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *   this.val = val;
 *   this.left = left || null;
 *   this.right = right || null;
 * }
 *
 * @param {TreeNode} root
 * @return {string[][]}
 */
var printTree = function (root) {
    const getHeight = (node) => {
        if (node === null) return -1;
        return Math.max(getHeight(node.left), getHeight(node.right)) + 1;
    };

    const height = getHeight(root);
    const rows = height + 1;
    const cols = (1 << (height + 1)) - 1;
    const result = Array.from(
        { length: rows },
        () => Array(cols).fill("")
    );

    const place = (node, row, col) => {
        if (node === null) return;
        result[row][col] = String(node.val);

        if (row === height) return;
        const offset = 1 << (height - row - 1);
        place(node.left, row + 1, col - offset);
        place(node.right, row + 1, col + offset);
    };

    place(root, 0, (cols - 1) / 2);
    return result;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def printTree(self, root: Optional[TreeNode]) -> List[List[str]]:
        def get_height(node: Optional[TreeNode]) -> int:
            if node is None:
                return -1
            return max(get_height(node.left), get_height(node.right)) + 1

        height = get_height(root)
        rows = height + 1
        cols = (1 << (height + 1)) - 1
        result = [[""] * cols for _ in range(rows)]

        def place(node: Optional[TreeNode], row: int, col: int) -> None:
            if node is None:
                return
            result[row][col] = str(node.val)

            if row == height:
                return
            offset = 1 << (height - row - 1)
            place(node.left, row + 1, col - offset)
            place(node.right, row + 1, col + offset)

        place(root, 0, (cols - 1) // 2)
        return result
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class Solution {
public:
    vector<vector<string>> printTree(TreeNode* root) {
        int height = getHeight(root);
        int rows = height + 1;
        int cols = (1 << (height + 1)) - 1;
        vector<vector<string>> result(
            rows,
            vector<string>(cols, "")
        );

        place(root, 0, (cols - 1) / 2, height, result);
        return result;
    }

private:
    int getHeight(TreeNode* node) {
        if (node == nullptr) return -1;
        return max(getHeight(node->left), getHeight(node->right)) + 1;
    }

    void place(
        TreeNode* node,
        int row,
        int col,
        int height,
        vector<vector<string>>& result
    ) {
        if (node == nullptr) return;
        result[row][col] = to_string(node->val);

        if (row == height) return;
        int offset = 1 << (height - row - 1);
        place(node->left, row + 1, col - offset, height, result);
        place(node->right, row + 1, col + offset, height, result);
    }

常见错误

  • 把高度按节点数计算，却仍使用按边数定义的列公式，导致矩阵扩大一倍。
  • 将本层偏移写成 2^(height-r)，孩子越过正确槽位。
  • 只创建存在节点的格子，返回的每一行长度不一致。
  • 直接存整数而不是节点值的字符串形式。
  • 递归到叶子后仍计算负指数偏移。

面试追问

  • 能否不显式使用幂次偏移？可以，传递左右区间并取中点。
  • 为什么初始化矩阵可能比遍历节点更贵？因为稀疏树也必须返回完整矩形。
  • 可以使用 BFS 吗？可以，队列元素保存 (node,row,col)。
  • 若深度不受 10 限制会怎样？列数指数增长，需要检查整数溢出与内存上限。
坐标来源满二叉树槽位，而非节点实际数量。
