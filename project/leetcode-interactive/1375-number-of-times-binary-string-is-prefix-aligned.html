Problem

题目描述

有一个长度为 n、下标从 1 开始的二进制字符串，初始时每一位都是 0。

翻转规则

给定一个下标从 1 开始的整数数组 flips。第 i 步会把位置 flips[i] 从 0 翻转为 1。由于 flips 是 [1, n] 的一个排列，每一位恰好被翻转一次。

目标状态

第 i 步结束后，如果闭区间 [1, i] 内的所有位都是 1，且其余位都是 0，就称当前字符串“前缀一致”。返回整个翻转过程中出现这种状态的次数。

函数形式

numTimesAllBlue(flips: integer[]) → integer

约束

  • n == flips.length
  • 1 ≤ n ≤ 5 × 10⁴
  • flips 是 [1, n] 中整数的一个排列
示例 1
输入：flips = [3,2,4,1,5] 输出：2

状态依次为 00100、01100、01110、11110、11111；第 4、5 步满足前缀一致，共 2 次。

示例 2
输入：flips = [4,1,2,3] 输出：1

状态依次为 0001、1001、1101、1111；只有第 4 步满足前缀一致，共 1 次。

Answer

题解：只追踪最远位置

核心洞察

第 i 步之后，恰好有 i 个位置被翻成 1。若这些 1 全部落在前 i 个位置，那么它们只能恰好占满区间 [1, i]。

判定条件：扫描到第 i 步时，记录已翻转位置的最大值 maxPosition。当且仅当 maxPosition == i，当前状态前缀一致。

因为已翻转位置互不相同且都为正数，前 i 次翻转得到 i 个不同位置；若最大值为 i，它们就只能是 1, 2, …, i。

maxPosition = max(maxPosition, flips[i - 1]) if maxPosition == i: answer += 1

完整过程

  1. 初始化 maxPosition = 0、answer = 0。
  2. 按顺序扫描 flips，第 i 步用当前翻转位置更新最大值。
  3. 若最大值等于当前步数 i，说明前 i 位全部亮起，答案加一。
  4. 扫描完成后返回答案。

正确性证明

1
充分性。若第 i 步时 maxPosition = i，前 i 次翻转产生 i 个互不相同、取值不超过 i 的正整数。这样的集合只能是 {1,…,i}，所以前 i 位全为 1；其余位置尚未翻转，均为 0，状态前缀一致。
2
必要性。若第 i 步后状态前缀一致，则已经翻转的位置恰为 {1,…,i}，其中最大位置必为 i，所以 maxPosition = i。
3
结论。算法只在且一定在前缀一致时计数，因此最终返回的次数正确。

边界与复杂度

时间复杂度 O(n)只顺序扫描数组一次，每一步做常数次操作。
空间复杂度 O(1)仅维护最大位置和答案，不需要模拟整个字符串。
  • n = 1：唯一位置在第一步亮起，答案为 1。
  • 最后一步：所有位必然都亮起，因此最后一步一定会被计数。
  • 严格依赖排列条件：互不重复是“最大值等于步数即可判定”的关键前提。

四种语言完整代码

JavaLeetCode 提交格式
class Solution {
    public int numTimesAllBlue(int[] flips) {
        int maxPosition = 0;
        int answer = 0;

        for (int i = 0; i < flips.length; i++) {
            maxPosition = Math.max(maxPosition, flips[i]);
            if (maxPosition == i + 1) {
                answer++;
            }
        }
        return answer;
    }
}

Python 3LeetCode 提交格式
from typing import List

class Solution:
    def numTimesAllBlue(self, flips: List[int]) -> int:
        max_position = 0
        answer = 0

        for step, position in enumerate(flips, 1):
            max_position = max(max_position, position)
            if max_position == step:
                answer += 1
        return answer

替代方案

前缀和判定记录已翻转位置之和。第 i 步若总和等于 i(i+1)/2，也能判定前缀一致。时间 O(n)、空间 O(1)，但要留意大整数溢出。
显式模拟维护布尔数组并检查前缀，直观但若每一步都重新扫描会退化到 O(n²)；即使优化，也比“维护最大值”多用 O(n) 空间。

面试追问与常见错误

为什么不用检查最小位置？

前 i 次翻转得到 i 个互不相同的正整数。只要最大值不超过 i，这 i 个数就被迫填满 1 到 i，因此无需额外维护最小值。

如果 flips 允许重复，方法还成立吗？

不成立。重复会破坏“i 个不同位置”的计数基础；这时需要记录每个位置的状态或频次，并重新设计判定条件。

可以在线处理流式输入吗？

可以。算法只依赖当前步数、历史最大值和累计答案，不必保存过去的翻转位置。

常见错误
  • 混淆数组的 0 下标与题意的 1 下标，错误比较 maxPosition === i。
  • 只判断当前位置是否等于步数，忽略之前可能翻到更远的位置。
  • 真的构造字符串并反复扫描，造成不必要的时间或空间开销。
  • 使用求和方案时在 Java/C++ 中用 32 位整数计算大规模扩展数据，产生溢出。
