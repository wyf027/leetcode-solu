Number of Students Unable to Eat Lunch

无法吃午餐的学生数量

一场发生在队列与三明治栈之间的午餐匹配实验。先理解规则，再亲手推动每一步。

题目场景

学校午餐提供两种三明治：0 表示圆形，1 表示方形。学生排成队列，每人只偏好其中一种；三明治叠成一摞，并且数组下标 0 对应栈顶。

每轮只看队首学生和栈顶三明治：若类型符合偏好，该学生取走三明治并离队；否则学生不取，并移动到队尾。

当队列中没有任何学生愿意取走当前栈顶三明治时，过程停止。给定整数数组 students 与 sandwiches，返回最终无法吃到午餐的学生数量。

05

Editorial

题解：只统计偏好，不模拟轮转

核心洞察

队列中只要还存在一名偏好当前栈顶类型的学生，无论他现在排在哪里，反复把不匹配者移到队尾，最终一定会轮到他。于是学生的具体顺序不影响“当前三明治能否被取走”，只需记录偏好 0 和 1 的人数。

完整过程

  1. 遍历 students，得到 count[0] 与 count[1]。
  2. 从栈顶开始依次扫描 sandwiches。
  3. 若当前类型还有学生喜欢，对应计数减一。
  4. 若对应计数为零，剩余学生都会拒绝栈顶，立即返回未处理三明治数。
  5. 扫描结束则返回 0。
示例 2 的计数视角：初始偏好为 [2,4]。处理 1,0,0 后变为 [0,3]；下一个仍是 0，但已无人喜欢，剩余 3 人无法吃到。

正确性证明

引理：若剩余学生中至少一人偏好当前栈顶三明治，则它最终会被取走。不偏好者只会移到队尾；有限次轮转后，某位偏好它的学生必然到达队首。

反之：若无人偏好当前栈顶，则每个人都会拒绝它，流程停止。

结论：算法在计数大于零时消耗当前类型，恰好对应一名学生成功取走三明治；计数为零时返回全部剩余人数，恰好对应题目停止状态。因此算法正确。

复杂度

设学生数为 n。统计和扫描各一次，时间复杂度为 O(n)；计数数组大小固定，额外空间复杂度为 O(1)。

边界情况

  • 只有一名学生，偏好不同时返回 1。
  • 所有人偏好相同且全部匹配，返回 0。
  • 第一块三明治无人喜欢，直接返回 n。
  • 直到最后一块才无法匹配，返回 1。

替代方案：直接模拟队列

可以使用队列逐轮模拟，并用“连续拒绝次数”判断停止：成功取走后三明治指针前移、拒绝计数归零；拒绝时把学生移到队尾。当连续拒绝次数等于当前队列长度时停止。

它更贴近题意，但最坏可能执行 O(n²) 次轮转，并需要 O(n) 队列空间。计数法更简洁。

面试追问

  • 若三明治不止两种？使用哈希表或长度为 k 的计数数组。
  • 为什么能忽略学生顺序？不匹配者不会离开，匹配者最终一定到队首。
  • 若不匹配的学生会直接离开呢？计数法不一定成立，需要按新规则重建状态转移。

四语言完整实现

四份代码均采用 O(n) 的偏好计数思路。

Java

class Solution {
    public int countStudents(int[] students, int[] sandwiches) {
        int[] count = new int[2];
        for (int preference : students) {
            count[preference]++;
        }

        for (int i = 0; i < sandwiches.length; i++) {
            int type = sandwiches[i];
            if (count[type] == 0) {
                return sandwiches.length - i;
            }
            count[type]--;
        }
        return 0;
    }
}

Python

from typing import List


class Solution:
    def countStudents(
        self,
        students: List[int],
        sandwiches: List[int]
    ) -> int:
        count = [0, 0]
        for preference in students:
            count[preference] += 1

        for i, sandwich_type in enumerate(sandwiches):
            if count[sandwich_type] == 0:
                return len(sandwiches) - i
            count[sandwich_type] -= 1
        return 0

C++

class Solution {
public:
    int countStudents(
        vector<int>& students,
        vector<int>& sandwiches
    ) {
        int count[2] = {0, 0};
        for (int preference : students) {
            ++count[preference];
        }

        for (int i = 0; i < sandwiches.size(); ++i) {
            int type = sandwiches[i];
            if (count[type] == 0) {
                return sandwiches.size() - i;
            }
            --count[type];
        }
        return 0;
    }
};

常见错误

  • 把 sandwiches[0] 误认为栈底；题目明确它是栈顶。
  • 计数为零后仍继续扫描；流程已永久阻塞，应立即返回剩余人数。
  • 只返回某一种偏好的剩余人数；答案是队列总人数，即 n - i。
  • 直接模拟却没有“连续拒绝达到队列长度”的停止条件，造成死循环。
