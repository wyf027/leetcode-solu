判定字符是否唯一

给定仅含小写字母的字符串 s，判断每个字符是否最多出现一次。这里把 26 个字母看成一排“指纹灯”：重复触碰同一盏灯，马上判定失败。

官方限制
0 <= len(s) <= 100
s[i] 仅包含小写字母。若不使用额外数据结构会很加分。

题意与示例

逐个读取字符；只要某个字符此前已经出现，返回 false；全部读完仍未重复，返回 true。

示例 1
s = "leetcode"
输出：false（第二次遇到 e）。
示例 2
s = "abc"
输出：true。

引号保留字符串边界；若例子含空格，使用 ␠ 显示一个真实空格。

题解

首屏只练习观察；需要时再展开完整答案。

核心洞察

第 i 个小写字母映射到二进制第 i 位。mask 的这一位为 1，表示字符已出现；再次遇到 1 就可立刻返回。

完整过程

  1. 令 mask = 0。
  2. 对每个 c，计算 bit = 1 << (c - 'a')。
  3. 若 mask & bit 非 0，发现重复。
  4. 否则执行 mask |= bit，继续扫描。

边界

空串没有重复字符；长度超过 26 时必然重复（本题仍可直接扫描）；位运算方案依赖题目“小写字母”限制。

复杂度

时间 O(n)，每个字符一次常数操作；空间 O(1)，只用一个整数。

替代方案

哈希集合更通用，能覆盖任意字符集，但占用 O(k) 额外空间。排序后比较相邻字符需要 O(n log n)，通常不是最优。

面试追问

若字符改为 Unicode，不能把所有字符装入 32 位整数；可使用 Set，或按编码范围选择 BitSet。若禁止额外空间且允许改动字符串，可排序后检查相邻元素。

常见错误

  • 先 OR 再检查，会掩盖重复。
  • 忘记减去 'a'，位索引错误。
  • 把此方案误用于大写字母、空格或 Unicode。

四语言可提交代码

class Solution {
    public boolean isUnique(String astr) {
        int mask = 0;
        for (char c : astr.toCharArray()) {
            int bit = 1 << (c - 'a');
            if ((mask & bit) != 0) return false;
            mask |= bit;
        }
        return true;
    }
}
