Problem

题意

对于整数数组 nums，若一对下标 [i, j] 满足：

0 ≤ i < j < nums.length 且 nums[i] > nums[j]

那么 [i, j] 是一个逆序对。

给定整数 n 和 k，数组必须由 1 到 n 的每个数字各组成一次。返回其中恰好含有 k 个逆序对的不同数组数量；答案对 10⁹ + 7 取模。

函数形式

kInversePairs(n: integer, k: integer): integer

官方示例 1

输入： n = 3, k = 0
输出： 1
解释： 只有 [1,2,3] 恰好拥有 0 个逆序对。

官方示例 2

输入： n = 3, k = 1
输出： 2
解释： [1,3,2] 与 [2,1,3] 各有 1 个逆序对。

约束

  • 1 ≤ n ≤ 1000
  • 0 ≤ k ≤ 1000

Solution

动态规划 + 前缀滑动窗口

核心洞察

把最大数字 i 插入一个由 1…i-1 构成的排列。若它从最右端向左移动 x 个位置，就会新增恰好 x 个逆序对，其中 0 ≤ x ≤ i-1。因此，目标 j 可以从上一行连续的若干状态汇总而来。

dp[i][j] = Σ dp[i-1][j-x]，其中 0 ≤ x ≤ min(j, i-1)

直接求和会多一层循环；相邻的 j 共享绝大多数项，所以维护长度为 i 的滑动窗口即可把单格更新降为 O(1)。

完整过程

  1. 定义 dp[j] 为当前规模下，恰好有 j 个逆序对的排列数量。
  2. 初始化空前缀或规模 0：dp[0] = 1，其余为 0。
  3. 依次加入数字 i = 1…n。扫描 j = 0…k 时，把 dp[j] 加入窗口。
  4. 若 j ≥ i，减去已离开合法范围的 dp[j-i]。
  5. 窗口值就是新一行 next[j]。一行完成后令 dp = next。
  6. 最终返回 dp[k]；所有加减均对 10⁹+7 取模。

状态为何能压缩

第 i 行只依赖第 i-1 行。计算新行时，不会再修改旧数组，而是写入独立的 next；整行结束后替换，因此只需两个长度 k+1 的一维数组。

复杂度

  • 时间：O(nk)
  • 空间：O(k)

若 k > n(n-1)/2，目标超过最大逆序对数，可立即返回 0。

正确性证明

1
基础情形。规模为 0 时只有一个空排列，且逆序对数为 0，所以 dp[0]=1 正确。
2
唯一分解。任取一个 1…i 的排列，删除最大值 i 后会得到唯一的 1…i-1 排列。若 i 右侧有 x 个元素，它恰好贡献 x 个新逆序对，且 x∈[0,i-1]。
3
完备且不重复。反过来，对任一具有 j-x 个逆序对的旧排列，把 i 插到使其右侧恰有 x 个元素的位置，就得到一个具有 j 个逆序对的新排列。不同的旧排列或插入位置不会得到同一结果。
4
归纳结论。因此所有合法 x 对应的计数之和恰好等于 dp[i][j]。滑动窗口只改变求和方式，不改变求和项。由归纳法，算法最终返回的 dp[n][k] 正确。

边界情况

  • k = 0：只有严格递增排列，答案为 1。
  • n = 1：仅 k = 0 时答案为 1。
  • k > n(n-1)/2：不可能达到，答案为 0。
  • 窗口做减法后可能为负，必须先加模数再取模。
  • 中间和可能超出 32 位有符号整数；Java/C++ 用 64 位暂存。

替代方案

三重循环 DP：直接枚举插入产生的 x，逻辑最直观，但时间为 O(n²k)，在上界下不可接受。

二维前缀和：保存整张 dp[i][j] 表，仍可做到 O(nk)，但空间是 O(nk)。适合教学或需要回溯所有行的场景。

生成函数：答案是多项式 ∏(1+x+…+x^(i-1)) 的 x^k 系数，数学表达漂亮，但普通卷积实现不如滑动窗口直接。

四语言完整代码

class Solution {
    private static final int MOD = 1_000_000_007;

    public int kInversePairs(int n, int k) {
        if (k > n * (n - 1) / 2) return 0;

        int[] dp = new int[k + 1];
        dp[0] = 1;

        for (int size = 1; size <= n; size++) {
            int[] next = new int[k + 1];
            long window = 0;
            int limit = Math.min(k, size * (size - 1) / 2);

            for (int inv = 0; inv <= limit; inv++) {
                window = (window + dp[inv]) % MOD;
                if (inv >= size) {
                    window = (window - dp[inv - size] + MOD) % MOD;
                }
                next[inv] = (int) window;
            }
            dp = next;
        }
        return dp[k];
    }
}

class Solution {
public:
    int kInversePairs(int n, int k) {
        const int MOD = 1'000'000'007;
        if (k > n * (n - 1) / 2) return 0;

        vector<int> dp(k + 1, 0);
        dp[0] = 1;

        for (int size = 1; size <= n; ++size) {
            vector<int> next(k + 1, 0);
            long long window = 0;
            int limit = min(k, size * (size - 1) / 2);

            for (int inv = 0; inv <= limit; ++inv) {
                window = (window + dp[inv]) % MOD;
                if (inv >= size) {
                    window = (window - dp[inv - size] + MOD) % MOD;
                }
                next[inv] = static_cast<int>(window);
            }
            dp.swap(next);
        }
        return dp[k];
    }
};

常见错误

  • 窗口过期条件写成 inv > size；正确条件是 inv ≥ size。
  • 原地覆盖旧 dp，导致同一行的新值污染后续计算。
  • 减法取模后保留负数，尤其在 Java/C++/JavaScript 中。
  • 把最大逆序对数误写为 n²，正确值是 n(n-1)/2。
  • 使用三重循环，复杂度在 n,k=1000 时超时。
