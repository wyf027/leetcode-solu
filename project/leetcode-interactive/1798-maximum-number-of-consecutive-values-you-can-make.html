Maximum Number of Consecutive Values You Can Make

一袋硬币，可以拼出多少个从零开始、不间断的整数？先独立思考，再打开下方的交互题解。

LeetCode 官方题目 ↗

01 / 题目

给定整数数组 coins，长度为 n。数组中的每个元素代表一枚硬币的面值。选择其中任意若干枚硬币，它们的面值之和就是一个可以构造的值；每枚硬币最多使用一次，相同面值的不同硬币可以分别使用。

返回从 0 开始，能够连续构造出的整数的个数。允许一枚硬币也不选，所以 0 总能构造。遇到第一个不能构造的整数，连续序列就结束。

参数：coins: integer[]　返回：integer
官方方法：getMaximumConsecutive(coins)

约束

  • coins.length == n
  • 1 ≤ n ≤ 4 × 10⁴
  • 1 ≤ coins[i] ≤ 4 × 10⁴

02 / 官方示例

示例 1

输入：coins = [1,3]
输出：2

0 对应空集，1 对应 [1]。2 无法构造，因此从 0 起只有两个连续值。

示例 2

输入：coins = [1,1,1,4]
输出：8

0～3 分别使用 0、1、2、3 枚面值 1 的硬币；4～7 再分别加上一枚面值 4 的硬币，共 8 个值。

示例 3

输入：coins = [1,4,10,3,1]
输出：20

可构造 0～19，共 20 个连续值。中文元数据中的 nums 为笔误，此处按英文题面与官方签名统一为 coins。

04 / 准备好拆解了吗？

展开后可查看区间拼接动画、证明和四种语言实现。

题解 / 用一段区间概括所有组合

把硬币升序排序。维护 reach：已经能够构造整个半开区间 [0, reach)，即 0～reach−1。初始化 reach = 1，因为空集能组成 0。

下一枚硬币为 c，选择它后，原区间会平移成 [c, c + reach)。只要 c ≤ reach，两个整数区间就重叠或紧邻，可合并为 [0, reach + c)；若 c > reach，值 reach 就落在无法填补的缺口中。

完整过程与正确性

  1. 升序排列示例 3 得到 [1,1,3,4,10]，初始 reach = 1。
  2. 依次接入两个 1，reach 变为 2、3。
  3. 3 等于当前 reach，恰好衔接，reach = 6。
  4. 4 ≤ 6，两个区间重叠，reach = 10。
  5. 10 ≤ 10，继续衔接，reach = 20。返回 20，最大连续值为 19。

循环不变式

已处理硬币的所有子集和恰好覆盖 [0, reach)，且它们的总和是 reach−1。初始没有硬币，总和为 0，不变式成立。若 c ≤ reach，不选 c 的和覆盖 [0, reach)，选 c 的和覆盖 [c, c+reach)；二者无整数缺口，且新总和为 reach+c−1，因此更新 reach += c 后不变式继续成立。

为什么可以提前结束？

若 c > reach，只用之前的硬币最多得到 reach−1；选任意未处理硬币，因为它们都不小于 c，和至少是 c > reach。两种情况都不能构造 reach，后面再多硬币也不能填补它，因此返回 reach 最优。全部处理完时，总和之外的值同样不可达。

边界与复杂度

  • 没有面值 1：立即返回 1，只有 0。相同面值硬币不能去重，每枚都可扩展覆盖范围。
  • c == reach 可以衔接，判断中应使用大于号才能停止。
  • 返回 reach 是个数；reach−1 才是最后一个连续值。
  • 总和最多为 1,600,000,000，reach 最多为 1,600,000,001，在 32 位有符号整数范围内。
  • 排序 O(n log n)，扫描 O(n)。扫描额外空间 O(1)；代码原地排序会改变输入。
  • 排序工作空间取决于语言实现：Java 基本类型排序与 C++ 通常需要 O(log n) 栈空间，Python 排序最坏 O(n)，JavaScript 由引擎决定。若先复制数组保留输入，则额外 O(n)。

替代方案

子集和动态规划可记录每个可达和，时间 O(nS)、空间 O(S)，S 为总和；本题 S 可达 16 亿，不适合。枚举子集 O(2ⁿ) 只适合极小规模。利用面值上限建立频次数组可把排序替换为计数扫描，时间 O(n+V)、空间 O(V)，V=40000；常规面试实现采用排序更直观。

常见错误

  • 未排序就遇大币停止，会错过后面的较小硬币。
  • 把 reach 初始化为 0，忽略空集能组成 0。
  • 只计算总和加 1，不检查中间缺口，例如 [1,3]。
  • JavaScript 使用无比较器的 sort() 会按字符串排序。
  • 把问题当成硬币无限次使用，或误把重复硬币去重。

面试追问

允许添加硬币来覆盖到目标 T？ 遇到缺口时添加面值 reach，使覆盖长度翻倍，重复到 reach > T。允许负数？ “后续硬币太大所以无法补缺”的证明失效，需要重新建模。硬币无限次使用？ 若包含 1 则可覆盖任意非负整数，本题的有限区间更新不再适用。

Java

import java.util.Arrays;

class Solution {
    public int getMaximumConsecutive(int[] coins) {
        Arrays.sort(coins);
        int reach = 1;
        for (int coin : coins) {
            if (coin > reach) break;
            reach += coin;
        }
        return reach;
    }
}
