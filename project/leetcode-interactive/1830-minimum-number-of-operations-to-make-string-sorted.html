使字符串有序的最少操作次数

Minimum Number of Operations to Make String Sorted

先观察字符串如何变化，再思考如何应对 3000 个字符。

01 / 题目

给定下标从 0 开始的字符串 s，重复以下操作，直到字符按非递减顺序排列。返回所需操作次数，对 10⁹ + 7 取模。

  1. 找到最大的 i，满足 1 ≤ i < s.length 且 s[i] < s[i−1]。
  2. 找到最大的 j，满足 i ≤ j < s.length，并且区间 [i,j] 中每个字符都严格小于 s[i−1]。
  3. 交换 s[i−1] 与 s[j]。
  4. 反转从下标 i 开始的整个后缀。

没有下降位置时停止。约束：1 ≤ s.length ≤ 3000，s 仅含小写英文字母。

输出：5

输入：s = "aabaa"
输出：2
过程：aabaa → aaaba → aaaab
输入：s = "cdbea"
输出：63

04 / 从操作到字典序排名

核心洞察

一次操作恰好得到当前字符串的前一个不同排列。有序字符串是最小排列，所以答案等于所有不同排列中严格小于 s 的数量，即零基字典序排名。

为什么是前一个排列？

最大下降位置 i 之后的后缀非递减。要让字符串变小且尽量接近原串，必须在最靠右的可降低位置 i−1 改动。后缀中最后一个小于枢轴的字符是可替换的最大值；交换后后缀仍非递减，反转后变成降序，得到该新前缀下最大的后缀。因此没有跳过任何不同排列。

完整过程

  1. 预处理阶乘 fact[t] 与逆阶乘 inv[t]。通过快速幂求 inv[n]，再倒推其余逆阶乘。
  2. 记录剩余字符频次 cnt，维护 D = ∏ inv[cnt[c]] mod M。
  3. 从左到右扫描 i，当前字符 x，剩余长度（含当前位）为 m。计算 less = Σ cnt[c]，c < x。
  4. 当前位置换成更小字符 c 后，后缀有 (m−1)! × D × cnt[c] 种排列。总贡献为 fact[m−1] × D × less。
  5. 累加贡献后固定真实字符 x：先更新 D = D × cnt[x] mod M，再令 cnt[x] 减一。
s = "cba"
位置 0：放 a 或 b，各有 2! 种后缀，贡献 4
位置 1：前缀 c 固定，放 a，贡献 1
位置 2：无更小字符，贡献 0
答案 4 + 1 = 5

s = "aabaa"
前两个 a 固定，遇到 b 时剩余 a:2, b:1
贡献 2! × (1 / 2!) × 2 = 2，其余贡献为 0

正确性证明

每个严格小于 s 的排列都有唯一的首次不同位置 i，且该位字符小于 s[i]。按首次不同位置与较小字符划分的集合互不相交，多重集合排列公式准确计算每个集合大小。算法累加所有集合，无遗漏、无重复，因此得到排名。每次操作恰好减少一个排名，直到排名为 0，所以排名就是所需次数。

边界与数值

单字符、全相同或已经有序时，每个 less 都是 0。重复字符必须用频次阶乘去重。M 为质数且 n ≤ 3000 < M，所有阶乘都可逆，费马小定理给出 a⁻¹ ≡ a^(M−2)。Java / C++ 使用 64 位乘法并及时取模，JavaScript 使用 BigInt，最终余数转为 Number。

复杂度

时间 O(26n + log M)，空间 O(n + 26)。字母表与模数固定时均为 O(n)。

替代方案

直接模拟适合短串演示，每次 O(n)，次数最坏接近 n!。每步重新计算 D 也可达 O(26n)，维护 D 可减少重复乘法。大字母表可用树状数组求更小字符频次，使查询部分变成 O(n log σ)。

常见错误

  • 把答案当成逆序对数：题目一次操作包含后缀反转。
  • 忽略重复字符，直接套普通排列阶乘。
  • 在模意义下直接整数除法，或用 JavaScript Number 计算大乘积。
  • 先递减 cnt[x] 再更新 D，漏掉原频次因子。
  • 使用一基排名，导致有序字符串返回 1。

面试追问

为什么乘 cnt[c]？消耗 c 后分母中的 cnt[c]! 变成 (cnt[c]−1)!，逆分母多出 cnt[c] 因子。

可以按排名还原排列吗？逐位计算候选字符的排列块大小并扣除，但需要精确大小；模 M 的排名本身不足以唯一还原。

若 n ≥ M？阶乘可能为 0，当前逆阶乘方法失效，需要额外处理质因子幂次等模组合计数问题。

Java

class Solution {
    static final long MOD = 1_000_000_007L;
    long pow(long a, long e) {
        long r = 1;
        while (e > 0) {
            if ((e & 1) != 0) r = r * a % MOD;
            a = a * a % MOD;
            e >>= 1;
        }
        return r;
    }
    public int makeStringSorted(String s) {
        int n = s.length();
        long[] f = new long[n + 1], inv = new long[n + 1];
        f[0] = 1;
        for (int i = 1; i <= n; i++) f[i] = f[i-1] * i % MOD;
        inv[n] = pow(f[n], MOD - 2);
        for (int i = n; i > 0; i--) inv[i-1] = inv[i] * i % MOD;
        int[] cnt = new int[26];
        for (char c : s.toCharArray()) cnt[c - 'a']++;
        long d = 1, ans = 0;
        for (int c : cnt) d = d * inv[c] % MOD;
        for (int i = 0; i < n; i++) {
            int x = s.charAt(i) - 'a', less = 0;
            for (int c = 0; c < x; c++) less += cnt[c];
            ans = (ans + f[n-i-1] * d % MOD * less) % MOD;
            d = d * cnt[x] % MOD;
            cnt[x]--;
        }
        return (int) ans;
    }
}

var makeStringSorted = function(s) {
    const M = 1000000007n, n = s.length;
    function pow(a, e) {
        let r = 1n;
        while (e > 0n) {
            if (e & 1n) r = r * a % M;
            a = a * a % M;
            e >>= 1n;
        }
        return r;
    }
    const f = Array(n + 1).fill(1n), inv = Array(n + 1).fill(1n);
    for (let i = 1; i <= n; i++) f[i] = f[i-1] * BigInt(i) % M;
    inv[n] = pow(f[n], M - 2n);
    for (let i = n; i > 0; i--) inv[i-1] = inv[i] * BigInt(i) % M;
    const cnt = Array(26).fill(0);
    for (const c of s) cnt[c.charCodeAt(0) - 97]++;
    let d = 1n, ans = 0n;
    for (const c of cnt) d = d * inv[c] % M;

Python

class Solution:
    def makeStringSorted(self, s: str) -> int:
        mod = 10**9 + 7
        n = len(s)
        f = [1] * (n + 1)
        inv = [1] * (n + 1)
        for i in range(1, n + 1):
            f[i] = f[i-1] * i % mod
        inv[n] = pow(f[n], mod - 2, mod)
        for i in range(n, 0, -1):
            inv[i-1] = inv[i] * i % mod
        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - 97] += 1
        d = 1
        for c in cnt:
            d = d * inv[c] % mod
        ans = 0
        for i, ch in enumerate(s):
            x = ord(ch) - 97
            less = sum(cnt[:x])
            ans = (ans + f[n-i-1] * d * less) % mod
            d = d * cnt[x] % mod
            cnt[x] -= 1
        return ans

        while (e > 0) {
            if (e & 1) r = r * a % M;
            a = a * a % M;
            e >>= 1;
        }
        return r;
    }
public:

        int n = s.size();

        for (int i = 1; i <= n; ++i) f[i] = f[i-1] * i % M;

        for (int i = n; i > 0; --i) inv[i-1] = inv[i] * i % M;

            d = d * cnt[x] % M;
