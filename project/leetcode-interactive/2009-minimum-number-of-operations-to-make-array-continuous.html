ALGORITHM NOTE / 245HARD公开题 · #2009

使数组连续的
最少操作数

Minimum Number of Operations to Make Array Continuous

一次替换可以跨越任意距离。你能让数组恰好包含一段连续整数吗？

01 / 题目

给定整数数组 nums，一次操作可以选择其中任意一个位置，将该元素替换成任意整数。返回使数组变为连续数组所需的最少操作次数。

连续数组同时满足：

  • 所有元素互不相同。
  • 最大值与最小值之差恰好等于 nums.length - 1。

“连续”描述的是值的集合，不要求原数组按大小排列。例如 [4,2,5,3] 已连续。

参数与返回值

minOperations(nums: integer[]) → integer
返回最少替换次数，不需要返回操作序列。

约束

1 ≤ nums.length ≤ 10⁵
1 ≤ nums[i] ≤ 10⁹

02 / 官方示例

示例 1

输入：nums = [4,2,5,3]
输出：0

所有数互不相同，且 5 − 2 = 4 − 1，已经连续。

示例 2

输入：nums = [1,2,3,5,6]
输出：1

将最后的 6 替换为 4，得到 [1,2,3,5,4]，一次操作即可。

示例 3

输入：nums = [1,10,100,1000]
输出：3

依次把 10、100、1000 替换为 2、3、4，得到 [1,2,3,4]。

05 / 独立题解

包含交互演示、证明与四语言代码。

核心洞察：把“改多少”变成“留多少”

设原数组长度为 n。最终的值一定恰好是整数区间 [L, L+n-1]。若原数组在这个区间中出现过 k 个不同的值，就可以各保留一次，并把其余 n-k 个位置改为缺失的值。

因此只需要寻找：宽度差不超过 n-1 的区间里，最多能容纳多少个不同的原值。先去重、排序得到 a，再用双指针找最长合法窗口，答案为 n - best。注意 n 始终是原数组长度。

交互 / 连续值区间扫描器

去重轨道 → 候选区间 → 缺失槽位

每一步把左端点移到下一个不同值，并将右指针推进到区间外。演示展示每次扩展完成的窗口快照；槽位按整数值排列，不代表原数组顺序。交互计算不计为验证结果。

元素范围 1–10⁹；演示限制只为清晰展示，提交算法支持官方完整约束。

完整过程与窗口不变量

  1. 保存原长度 n，生成升序且无重复的数组 a，长度为 m。
  2. 初始化右指针 j=0 和最大保留数 best=0。
  3. 依次枚举左指针 i，当 j<m 且 a[j]-a[i]<n 时持续增加 j。
  4. 循环结束时 [i,j) 是以 a[i] 为左端的最大合法窗口，保留数为 j-i。更新 best=max(best,j-i)。
  5. 所有左端点处理完后返回 n-best。左端点递增使允许的右端上界递增，故 j 不必回退。

示例 [1,2,2,3,7]：原长度 5，去重后为 [1,2,3,7]。区间 [1,5] 可保留 1、2、3，共 3 个不同值，因此需要 2 次操作，把多余的 2 和 7 改为 4、5 即可。后续窗口不会保留更多，最终答案为 2。

正确性证明

一、固定区间的最优代价。 对任意长度为 n 的整数区间，设其中有 k 个原数组不同值。每个不同值最多保留一个位置，因此至少要改 n−k 个位置。保留这 k 个值，把其他位置一一改为区间中缺失的 n−k 个值即可达到该下界，所以代价恰为 n−k。

二、只枚举已有值作为左端点足够。 对任一含有原值的候选区间 [L,L+n−1]，令 s 为其中最小的原值。把区间右移至 [s,s+n−1]：原先保留的值全部不小于 s，且不大于 L+n−1 ≤ s+n−1，所以不会失去任何保留值。空区间保留数为零，而非空输入总能保留至少一个值，因此最优解可取已有值为左端点。

三、双指针得到每个左端的最大保留数。 去重排序后，符合 a[j]-a[i]<n 的值构成连续下标段。扩展 j 到第一个不合法位置或数组末尾，得到该左端的全部可保留值。左端增大时上界不会减小，故右指针单调推进不漏值。算法遍历了充分的候选左端并取最大保留数，结合第一步，返回的 n−best 就是全局最少操作数。

边界与复杂度

  • n=1：单元素天然连续，答案 0。
  • 全部重复：最多保留一个，答案 n−1；不能以去重长度替代原长度。
  • 已经连续但无序：不必计入排序的“操作”，排序只是算法内部处理，答案 0。
  • 端点：差为 n−1 时仍可保留；差为 n 时必须排除。
  • 数值：四语言代码使用差值判断。在本题约束内 Java/C++ 的 int 与 JavaScript Number 均足够；若约束扩到更大整数，需调整数值类型。

排序耗时 O(n log n)，双指针总共推进 O(m) 次；整体时间 O(n log n)。以下四份代码均保留独立排序/去重存储，额外空间 O(n)，不修改调用者的输入数组。

四语言完整提交代码

Java

import java.util.Arrays;

class Solution {
    public int minOperations(int[] nums) {
        int n = nums.length;
        int[] a = nums.clone();
        Arrays.sort(a);
        int m = 0;
        for (int k = 0; k < n; k++) {
            if (m == 0 || a[k] != a[m - 1]) {
                a[m++] = a[k];
            }
        }
        int best = 0, j = 0;
        for (int i = 0; i < m; i++) {
            while (j < m && a[j] - a[i] < n) {
                j++;
            }
            best = Math.max(best, j - i);
        }
        return n - best;
    }
}

/**

var minOperations = function(nums) {
    const n = nums.length;
    const a = [...new Set(nums)].sort((x, y) => x - y);
    let best = 0, j = 0;
    for (let i = 0; i < a.length; i++) {
        while (j < a.length && a[j] - a[i] < n) {
            j++;
        }
        best = Math.max(best, j - i);
    }
    return n - best;
};

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int minOperations(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        vector<int> a = nums;
        sort(a.begin(), a.end());
        a.erase(unique(a.begin(), a.end()), a.end());
        int m = static_cast<int>(a.size());
        int best = 0, j = 0;
        for (int i = 0; i < m; ++i) {
            while (j < m && a[j] - a[i] < n) {
                ++j;
            }
            best = max(best, j - i);
        }
        return n - best;
    }
};

替代方案

排序去重 + 二分：对于每个左端 a[i]，二分查找第一个大于 a[i]+n−1 的下标 j，保留 j−i 个值。查询阶段为 O(m log m)，总时间仍为 O(n log n)，空间 O(n)。双指针利用上界单调性，把查询阶段降为 O(m)。

枚举区间并逐个计数：去重后对每个候选起点扫描全部值，最坏 O(n²)，不适合 10⁵ 的输入规模；可用于理解固定区间的含义。不能枚举 1 到 10⁹ 的每个整数起点。

常见错误

  • 未去重直接数窗口长度：重复值被错误地重复保留。
  • 去重后把 n 改成 m：改变了目标区间长度和操作数基准。
  • 用 差 ≤ n：多纳入了一个整数位置，正确条件是 差 < n。
  • JavaScript 默认 sort() 按字符串排序，必须提供数值比较器。
  • 把最终连续误解为原数组必须有序；或者累加相邻缺口大小，把一次任意替换误当成一次加减 1。
  • 每次左端变化都重置 j，可能退化成平方时间。

面试追问

怎样返回实际替换方案？记录最佳区间；扫描原数组，保留区间内每个不同值的首次出现，把其余位置记录下来，再与缺失整数一一配对。总共恰好 n−best 次替换。

若输入已排序？去重和滑窗都可线性完成；若允许修改输入，可原地压缩去重值，减少额外存储。

若每个位置替换成本不同？同一个值优先保留替换成本最高的位置，把不同值的最高成本作为权重，寻找宽度合法的最大权重窗口。最少成本等于全部成本减去最大保留权重（成本非负）。
