LCP 06 · 拿硬币

EASY

One move, at most two

两枚一组，
次数最少。

每一堆硬币都能在一次操作中拿走 1 或 2 枚。想要总次数最小，就让每次操作尽量拿满两枚；奇数时最后剩下的一枚再单独拿走。

The rule

第 i 堆有 coins[i] 枚。

一次只能从同一堆拿 1 枚或 2 枚。各堆互不影响，答案就是所有 ceil(coins[i] / 2) 的和。

221= 3 次

Problem brief

题意与约束

桌上有 n 堆硬币，第 i 堆数量为 coins[i]。每次操作可以任选一堆并拿走 1 枚或 2 枚；求拿走所有硬币的最少操作次数。

样例 1

[4, 2, 1]

输出：4

样例 2

[2, 3, 10]

输出：8

约束

1 ≤ n ≤ 4

1 ≤ coins[i] ≤ 10

Live grouping

动手分组

Minimum moves

4

4 枚 = 2 次；2 枚 = 1 次；1 枚 = 1 次。

Core insight

为什么贪心正确？

一堆有 c 枚硬币时，任何操作最多移走 2 枚，至少需要 ceil(c / 2) 次。连续拿 2 枚，若有剩余就再拿 1 枚，恰好达到这个下界。因此每堆独立取最优，累加就是全局最优。

计算公式

ceil(c / 2) = (c + 1) / 2

整数除法向下取整时，使用 (c + 1) / 2；或写成 c / 2 + c % 2。

过程、边界与延伸

完整过程

遍历每一堆，把 coins[i] / 2 的向上取整加入答案。不需要排序、动态规划或在堆之间搬运硬币。

边界与复杂度

当数量为 1 时需要一次；为偶数时全由两枚操作组成；为奇数时多一次单枚操作。时间 O(n)，额外空间 O(1)。

替代方案与常见错误

模拟逐枚拿取也正确但多余。常见错误是使用向下取整的 c / 2，从而漏掉奇数堆最后的一枚。

面试追问

若每次最多拿 k 枚，答案变为 Σ ceil(coins[i] / k)。若允许一次跨堆拿硬币，独立性被破坏，需要重新分析操作约束。

实现与验证

四种实现都使用同一个公式。官方方法签名分别保留为 minCount，可直接提交。 

class Solution {
    public int minCount(int[] coins) {
        int answer = 0;
        for (int coin : coins) answer += (coin + 1) / 2;
        return answer;
    }
}
/**
 * @param {number[]} coins
 * @return {number}
 */
var minCount = function (coins) {
  return coins.reduce((answer, coin) => answer + Math.ceil(coin / 2), 0);
};
