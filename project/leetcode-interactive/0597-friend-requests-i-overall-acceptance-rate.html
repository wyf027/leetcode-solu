从两张关系表中还原“申请”与“接受”的真实数量。关键不在表有多长，而在有多少个不同的用户对。

Problem

题目转述

Friend Requests I: Overall Acceptance Rate

给定好友申请表 FriendRequest 与申请接受表 RequestAccepted，计算所有好友申请的总体通过率。

通过率等于“被接受的不同用户对数量”除以“发出申请的不同用户对数量”，结果四舍五入到小数点后两位。重复出现的同一申请双方只能计一次；如果没有任何好友申请，返回 0.00。

返回形式：结果仅含一列 accept_rate，行顺序无要求。

Schema

数据表结构

FriendRequest

一条记录表示发送者在某天向接收者发出申请。

列名类型含义
sender_idINT发送者
send_to_idINT接收者
request_dateDATE申请日期

RequestAccepted

一条记录表示接收者在某天接受了申请。

列名类型含义
requester_idINT原申请人
accepter_idINT接受者
accept_dateDATE接受日期

约束语义：两表可能出现重复的用户对；计数应以有方向的用户对为单位，日期不参与去重键。输入列遵循上表类型。

Solution

去重后再相除

核心洞察

业务对象是有方向的“用户对”，不是表中的物理行。先分别用双方 ID 去重，再让接受对数除以申请对数；分母为空时返回零。

完整过程

  1. 从 FriendRequest 取不同的 (sender_id, send_to_id)。
  2. 从 RequestAccepted 取不同的 (requester_id, accepter_id)。
  3. 分别计数，相除后处理空分母，并四舍五入两位。

正确性

去重后的申请集合与题目定义中的每个不同申请一一对应，因此其大小恰为总申请数；同理，去重后的接受集合大小恰为已接受申请数。两集合大小相除得到定义中的总体通过率，空分母单独返回零，最后的舍入满足输出要求。

边界情况

  • 申请表为空：避免除零，返回 0.00。
  • 接受表为空：分子为零，通过率为零。
  • 同一用户对多次出现：无论日期是否相同都只计一次。
  • 所有申请都被接受：结果为 1.00。

复杂度

设申请表与接受表行数分别为 R、A。数据库通常通过哈希或排序执行去重，期望时间约为 O(R + A)，中间集合空间为 O(R + A)；实际计划取决于索引与执行器。

替代方案

可将双方 ID 编码后做单列 COUNT(DISTINCT ...)，但字符串拼接存在分隔符碰撞与类型转换问题。用两列 SELECT DISTINCT 的子查询更直观、可移植。

面试追问

  • 如果要按天统计，是按申请日还是接受日归因？
  • 接受记录不存在对应申请时，是否应过滤异常数据？
  • 数据量很大时，哪种复合索引最适合两列去重？

常见错误

  • 直接 COUNT(*)，把重复接受计入分子。
  • 把日期放进唯一键，导致同一用户对被重复计数。
  • 整数除法截断小数，或先舍入再相除。
  • 没有处理空申请表造成除零或 NULL。

SELECT ROUND(
         IFNULL(
           (SELECT COUNT(*)
            FROM (
              SELECT DISTINCT requester_id, accepter_id
              FROM RequestAccepted
            ) AS accepted_pairs) * 1.0
           /
           NULLIF(
             (SELECT COUNT(*)
              FROM (
                SELECT DISTINCT sender_id, send_to_id
                FROM FriendRequest
              ) AS requested_pairs),
             0
           ),
           0
         ),
         2
       ) AS accept_rate;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

public class Main {
    record Pair(int from, int to) {}

    static double acceptanceRate(List<Pair> requests,
                                 List<Pair> accepted) {
        Set<Pair> requestPairs = new HashSet<>(requests);
        if (requestPairs.isEmpty()) return 0.00;

        Set<Pair> acceptedPairs = new HashSet<>(accepted);
        double rate = (double) acceptedPairs.size() / requestPairs.size();
        return Math.round(rate * 100.0) / 100.0;
    }

    public static void main(String[] args) {
        List<Pair> requests = List.of(
            new Pair(1, 2), new Pair(1, 3), new Pair(1, 4),
            new Pair(2, 3), new Pair(3, 4)
        );
        List<Pair> accepted = List.of(
            new Pair(1, 2), new Pair(1, 3), new Pair(2, 3),
            new Pair(3, 4), new Pair(3, 4)
        );
        System.out.printf("%.2f%n", acceptanceRate(requests, accepted));
    }
}
function acceptanceRate(requests, accepted) {
  const keyOf = ([from, to]) => `${from}:${to}`;
  const requestPairs = new Set(requests.map(keyOf));
  if (requestPairs.size === 0) return 0.0;

  const acceptedPairs = new Set(accepted.map(keyOf));
  const rate = acceptedPairs.size / requestPairs.size;
  return Math.round((rate + Number.EPSILON) * 100) / 100;
}

const requests = [
  [1, 2], [1, 3], [1, 4], [2, 3], [3, 4],
];
const accepted = [
  [1, 2], [1, 3], [2, 3], [3, 4], [3, 4],
];

from typing import Iterable, Tuple

Pair = Tuple[int, int]


def acceptance_rate(
    requests: Iterable[Pair], accepted: Iterable[Pair]
) -> float:
    request_pairs = set(requests)
    if not request_pairs:
        return 0.00

    accepted_pairs = set(accepted)
    return round(len(accepted_pairs) / len(request_pairs) + 1e-12, 2)

double acceptanceRate(const vector<pair<int, int>>& requests,
                      const vector<pair<int, int>>& accepted) {
    set<pair<int, int>> requestPairs(requests.begin(), requests.end());
    if (requestPairs.empty()) return 0.00;

    set<pair<int, int>> acceptedPairs(accepted.begin(), accepted.end());
    double rate = static_cast<double>(acceptedPairs.size())
                / requestPairs.size();
    return round(rate * 100.0) / 100.0;
}

int main() {
    vector<pair<int, int>> requests{
        {1, 2}, {1, 3}, {1, 4}, {2, 3}, {3, 4}
    };
    vector<pair<int, int>> accepted{
        {1, 2}, {1, 3}, {2, 3}, {3, 4}, {3, 4}
    };
    cout << fixed << setprecision(2)
         << acceptanceRate(requests, accepted) << '\n';
    return 0;
}
