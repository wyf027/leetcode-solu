3n 块
披萨

圆桌上的选择从来不是孤立的：你拿走一块，它两侧的相邻块也随之离场。目标是在恰好 n 轮中，让自己拿到的总大小最大。

HARD动态规划数组环形序列非付费题

Problem

规则很简单，后果会连锁

  1. 披萨共有 3n 块，数组 slices 按顺时针记录每块大小。
  2. 每轮你先任选一块；Alice 随后拿走它逆时针相邻的一块。
  3. Bob 再拿走它顺时针相邻的一块；剩余披萨重新首尾相邻。
  4. 重复直到披萨用尽。返回你拿到的 n 块的最大大小总和。

Contract

函数与约束

maxSizeSlices(slices: integer[]) → integer
  • 3 × n == slices.length
  • 1 ≤ slices.length ≤ 500
  • slices.length % 3 == 0
  • 1 ≤ slices[i] ≤ 1000

返回值为整数；输入表示一个环，首块与末块相邻。

示例 1

官方示例

输入：slices = [1,2,3,4,5,6]
输出：10

先取 4，Alice 与 Bob 取走 3 和 5；再取 6，余下的 2 和 1 被朋友取走。你的总和为 4 + 6 = 10。

示例 2

官方示例

输入：slices = [8,9,8,6,1,1]
输出：16

两轮各取一块大小为 8 的披萨。若先取 9，相邻的 8 会被朋友拿走，无法达到最大总和。

Full solution

环形定量选取：两次线性 DP

核心洞察

操作过程等价于：从长度为 3n 的环形数组中，恰好选出 n 个互不相邻的元素，并让它们的和最大。

每当你选一块，它当时的两个邻居会被朋友拿走，因此你的任意两次选择在原环上不可能相邻。反过来，对任意一组互不相邻的 n 块，都可以安排选择顺序使它们成为你的选择，所以只需解决定量的环形不相邻选取。

完整过程

1
断开环。首块与末块相邻，二者不能同时选。所有合法方案必然属于“排除末块”或“排除首块”至少一种，因此分别求解区间 [0, m-2] 与 [1, m-1]。
2
定义线性状态。在一个线性区间中，令 dp[i][j] 表示只看前 i 个元素、恰好选择 j 个互不相邻元素时的最大和。
3
处理第 i 个元素。不选它，值来自 dp[i-1][j]；选它，则不能选前一个，值来自 dp[i-2][j-1] + value。二者取最大。
4
汇总。每个线性区间都必须恰选 n = m/3 块，最终取两种断环结果的最大值。
dp[i][j] = max(dp[i - 1][j], dp[i - 2][j - 1] + nums[i - 1])

正确性证明

引理 1：线性 DP 的状态值正确。考虑前 i 个元素的任一最优合法方案：若它不选第 i 个元素，该方案完全落在前 i-1 个元素中，对应第一项；若它选择第 i 个元素，则第 i-1 个元素必不选，删去当前元素后得到前 i-2 个元素中恰选 j-1 个的最优子结构，对应第二项。两类互斥且覆盖全部方案，因此转移正确。

引理 2：两次线性求解覆盖所有环形合法方案。环形方案不能同时包含首尾元素；若不含末元素，它属于第一个区间，若不含首元素，它属于第二个区间。每个区间中的方案也天然满足环形首尾约束。

结论：两种区间最优值的最大值覆盖且只覆盖合法环形方案，故算法返回恰选 n 块时的最大总和。

边界处理

  • 最小长度 3 时，只需取最大的一块。
  • 所有大小都为正，但状态仍必须表达“恰好选 j 块”，不能偷换成“至多”。
  • 不可达状态设为负无穷，避免被默认的 0 错误参与转移。
  • 两个断环区间长度均为 3n-1，足以放下 n 个不相邻元素。

复杂度

设披萨块数为 m，需选 n=m/3 块。

时间：O(mn) = O(m²)。两次线性 DP 只影响常数。

空间：以下实现采用二维表，为 O(mn)；可滚动压缩到 O(n)。

四语言完整实现

import java.util.Arrays;

class Solution {
    public int maxSizeSlices(int[] slices) {
        int choose = slices.length / 3;
        int a = solve(slices, 0, slices.length - 2, choose);
        int b = solve(slices, 1, slices.length - 1, choose);
        return Math.max(a, b);
    }

    private int solve(int[] slices, int left, int right, int choose) {
        int length = right - left + 1;
        int negative = Integer.MIN_VALUE / 4;
        int[][] dp = new int[length + 1][choose + 1];

        for (int i = 0; i <= length; i++) {
            Arrays.fill(dp[i], negative);
            dp[i][0] = 0;
        }

        for (int i = 1; i <= length; i++) {
            int value = slices[left + i - 1];
            for (int j = 1; j <= choose; j++) {
                dp[i][j] = dp[i - 1][j];
                int previous = i >= 2 ? dp[i - 2][j - 1]
                                      : (j == 1 ? 0 : negative);
                dp[i][j] = Math.max(dp[i][j], previous + value);
            }
        }
        return dp[length][choose];
    }
}

var maxSizeSlices = function(slices) {
    const choose = slices.length / 3;

    function solve(left, right) {
        const length = right - left + 1;
        const negative = Number.NEGATIVE_INFINITY;
        const dp = Array.from(
            { length: length + 1 },
            () => Array(choose + 1).fill(negative)
        );

        for (let i = 0; i <= length; i++) dp[i][0] = 0;

        for (let i = 1; i <= length; i++) {
            const value = slices[left + i - 1];
            for (let j = 1; j <= choose; j++) {
                const skip = dp[i - 1][j];
                const base = i >= 2
                    ? dp[i - 2][j - 1]
                    : (j === 1 ? 0 : negative);
                dp[i][j] = Math.max(skip, base + value);
            }
        }
        return dp[length][choose];
    }

    return Math.max(
        solve(0, slices.length - 2),
        solve(1, slices.length - 1)
    );
};
from typing import List


class Solution:
    def maxSizeSlices(self, slices: List[int]) -> int:
        choose = len(slices) // 3

        def solve(nums: List[int]) -> int:
            length = len(nums)
            negative = float("-inf")
            dp = [[negative] * (choose + 1)
                  for _ in range(length + 1)]

            for i in range(length + 1):
                dp[i][0] = 0

            for i in range(1, length + 1):
                value = nums[i - 1]
                for j in range(1, choose + 1):
                    skip = dp[i - 1][j]
                    if i >= 2:
                        base = dp[i - 2][j - 1]
                    else:
                        base = 0 if j == 1 else negative
                    dp[i][j] = max(skip, base + value)

            return int(dp[length][choose])

        return max(solve(slices[:-1]), solve(slices[1:]))
#include <algorithm>
#include <climits>
#include <vector>
using namespace std;

class Solution {
public:
    int maxSizeSlices(vector<int>& slices) {
        int choose = static_cast<int>(slices.size()) / 3;
        int last = static_cast<int>(slices.size()) - 1;
        return max(solve(slices, 0, last - 1, choose),
                   solve(slices, 1, last, choose));
    }

private:
    int solve(const vector<int>& slices,
              int left, int right, int choose) {
        int length = right - left + 1;
        const int negative = INT_MIN / 4;
        vector<vector<int>> dp(
            length + 1, vector<int>(choose + 1, negative)
        );

        for (int i = 0; i <= length; ++i) dp[i][0] = 0;

        for (int i = 1; i <= length; ++i) {
            int value = slices[left + i - 1];
            for (int j = 1; j <= choose; ++j) {
                dp[i][j] = dp[i - 1][j];
                int base = i >= 2 ? dp[i - 2][j - 1]
                                  : (j == 1 ? 0 : negative);
                dp[i][j] = max(dp[i][j], base + value);
            }
        }
        return dp[length][choose];
    }
};

替代方案

滚动数组：只保留 i-1 与 i-2 两行，可降至 O(n) 空间，但要谨慎维护两代状态。

贪心 + 堆：存在利用环形双向链表与优先队列的技巧性做法，时间可达 O(m log m)，但证明、删除与权值回填更复杂；面试中二维 DP 更稳健。

常见错误

  • 直接在线性数组上做一次 DP，忘记首尾相邻。
  • 只限制不相邻，却没有强制恰好选 n 块。
  • 用 0 初始化不可达状态，产生“凭空选够”的方案。
  • 转移选当前块时错误引用 i-1 行。
  • 区间端点写错，导致首尾仍同时出现或漏掉元素。

面试追问

  1. 为什么能把原操作等价为环形不相邻选取？ 需要说明必要性与可实现性两个方向，而不只是直觉。
  2. 为什么要恰好选 n 个？ 每轮三个人各拿一块，共有 3n 块，所以你固定进行 n 次选择。
  3. 若允许负数怎么办？ “恰好选择”的状态与负无穷初始化必须保留；不能用非负性简化。
  4. 如何恢复具体选择了哪些下标？ 保存每个状态来自 skip 还是 take，从最终状态反向回溯，再映射回原数组下标。
  5. 如何压缩空间？ 维护前一行和前两行；每轮生成新行，避免原地更新破坏 i-2 依赖。
