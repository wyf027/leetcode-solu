报数

给定整数 cnt，按从小到大的顺序返回从 1 到最大 cnt 位十进制数的数组。

题意

最大 cnt 位数为 10cnt - 1。因此答案就是连续整数序列 [1, 2, …, 10cnt-1]。

约束

  • 1 ≤ cnt ≤ 5
  • 结果数组按升序返回。

示例

输入：cnt = 2
输出：[1,2,3,...,99]
解释：最大的 2 位数是 99。

输出过长时，题面通常以省略号展示；实际返回的数组包含全部元素。

分步交互

输入位数，观察“先算上界，再顺序填充”的过程。

步骤 1：等待输入。

尚未生成

核心洞察

不需要逐位模拟：题目要的正是一个确定长度的连续区间。计算 limit = 10cnt 后，创建长度 limit - 1 的数组，并把第 i 个位置填为 i + 1。

完整过程

  1. 计算 limit = 10cnt。
  2. 分配 limit - 1 个元素的结果数组。
  3. 从 0 遍历到 limit - 2，写入 i + 1。
  4. 返回结果。

边界

cnt = 1 时返回 1 到 9；cnt = 5 时数组有 99,999 个元素，仍需注意输出展示不应阻塞界面。

复杂度

时间 O(10cnt)，空间 O(10cnt)；输出本身已要求这么多空间。

替代方案

可使用流式迭代器按需产出数字，降低额外缓存；但本题接口要求返回数组，最终仍需完整物化。

追问

若 cnt 很大，如何避免整数溢出？可改为字符串递增或大整数，并根据消费方改造为分页/迭代协议。

常见错误

  • 数组长度写成 10cnt，会多出 0 或越过最大值。
  • 循环从 0 写入结果，漏掉 1。
  • 把指数运算误写为位运算或整数乘法。

参考代码

// Java
class Solution {
    public int[] countNumbers(int cnt) {
        int limit = (int) Math.pow(10, cnt);
        int[] ans = new int[limit - 1];
        for (int i = 0; i < ans.length; i++) ans[i] = i + 1;
        return ans;
    }
}
// JavaScript
var countNumbers = function(cnt) {
  const ans = new Array(10 ** cnt - 1);
  for (let i = 0; i < ans.length; i++) ans[i] = i + 1;
  return ans;
};
# Python
class Solution:
    def countNumbers(self, cnt: int) -> list[int]:
        return list(range(1, 10 ** cnt))
// C++
class Solution {
public:
    vector<int> countNumbers(int cnt) {
        int limit = pow(10, cnt);
        vector<int> ans(limit - 1);
        iota(ans.begin(), ans.end(), 1);
        return ans;
    }
};
