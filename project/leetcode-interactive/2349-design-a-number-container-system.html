2349. 设计数字容器系统

Design a Number Container System

一个下标，只保存一个数字。一次查询，找到这个数字当前最靠前的位置。

官方题目 ↗免费题 · 本页可离线阅读

01 / 任务说明

实现 NumberContainers。下标空间很大，起初所有下标都没有数字。写入某个下标时，如果已有旧数字，就用新数字覆盖。

  • NumberContainers()：构造一个空系统。
  • void change(int index, int number)：在下标 index 写入 number。
  • int find(int number)：返回当前保存该数字的最小下标；如果不存在，返回 -1。

注意参数顺序：先下标，再数字。题目要求的是最小下标，而不是最早的写入时间。

约束与思考

  • 1 ≤ index, number ≤ 10⁹
  • change 与 find 的调用总次数不超过 10⁵。

如果同一个数字出现多次，修改它的最小下标后，下一次查询应该返回哪里？

先读示例，再展开页面底部的题解。算法结构与代码默认隐藏。

04 / 独立题解

展开后查看机制演示、分析与四语言实现。

核心洞察：记住现状，延后清理历史

用哈希表 current[index] = number 保存真实现状；为每个数字维护一个存放下标的最小堆。覆盖下标时不必去旧堆中间删除，只把新下标加入新数字的堆。旧记录暂留，查询时再检查堆顶是否仍然属于这个数字。

  1. change：若下标已经是该数字，直接返回；否则更新 current，并将 index 压入 number 的堆。
  2. find：若没有对应堆，返回 -1；只要堆非空且 current[堆顶] ≠ number，就弹出无效堆顶。
  3. 清理后若堆为空，返回 -1；否则堆顶就是最小有效下标。

堆只负责给出最小候选；哈希表负责判断候选现在是否有效。

正确性与完整过程

不变量 1：真实映射始终准确

构造时映射为空。每次 change 都将指定下标更新为最新数字，其他下标不变；同值写入无需修改。因此映射始终表示当前状态。

不变量 2：每个有效下标都有候选记录

一次实际赋值会把下标压入对应堆。只有当下标当前不属于该数字时，find 才会删除它。如果之后又改回该数字，change 会重新压入下标。因此任何当前有效的下标，至少有一份记录仍在其数字的堆中。

返回值为何最小

清理掉无效堆顶不会丢失当前有效下标。停止时若堆为空，由不变量 2 可知该数字没有有效下标；否则堆顶有效，且不大于堆中的任何其他候选，因此不大于任何有效下标，正是答案。

官方示例的关键变化

写入四个下标后，10 的最小候选为 1，查询返回 1。执行 change(1,20) 后，映射变为 1→20，但 10 的堆中仍保留候选 1。下一次 find(10) 先发现它失效并弹出，然后看到有效候选 2，返回 2。

边界

  • 数字从未出现、或其所有候选都已失效：返回 -1。
  • 重复写入同一个值：提前返回，避免无意义的堆记录。
  • 从 A 改为 B 再改回 A：旧 A 记录可能重新有效，并出现重复下标；仅查询最小值时不影响正确性。
  • 多个堆顶连续失效：必须用 while 清理，不能只弹出一次。
  • 下标可达 10⁹：使用稀疏映射，不按最大下标分配数组。

复杂度、替代方案与追问

设总调用数为 Q，实际压堆次数为 C（C ≤ Q），一次查询清理 k 个条目。哈希操作按期望 O(1) 计：

  • change：O(log(C+1))；同值写入为期望 O(1)。
  • find：O(1 + k log(C+1))；单次最坏可达 O(C log(C+1))，不能保证每次都是 O(log C)。
  • 整个序列：每条记录至多压入、弹出各一次，总时间 O(Q + C log(C+1))；每次调用均摊 O(log(Q+1))。
  • 空间：O(C+1)，一般写为 O(Q)。旧记录可能一直保留，不能只按当前有效下标数估计。

替代方案

映射 + 有序集合：覆盖时从旧数字的集合中删除下标，再插入新集合。Java 可用 TreeSet，C++ 可用 set；更新 O(log N)，获取最小值至多 O(log N)，具体取决于集合接口。空间按当前有效下标 O(N) 计，需删除空集合。Python 与 JavaScript 标准库没有同等的内置有序集合，最小堆方案更容易跨语言实现。

只保存下标映射并在每次 find 扫描全部下标：实现短，但查询 O(N)，高频查询时总计可能 O(Q²)。

面试追问

  • 需要严格限制查询延迟？选择有序集合，或支持按下标删除的索引堆，避免某次 find 集中清理大量记录。
  • 需要限制历史记录占用？用有序集合维护活跃下标，或按阈值重建堆，但重建有额外延迟。
  • 为什么不需要时间戳？本题只关心当前归属与最小下标，历史记录重新有效也不影响答案；若查询版本或写入顺序，则需额外版本信息。

常见错误

  • 把 number 与 index 的位置传反，或返回最小数字而非最小下标。
  • 直接返回旧堆顶，不用 current 判断是否已被覆盖。
  • 使用普通数组排序代替堆，却仍声称更新 O(log N)。
  • Java 用 Integer 引用相等比较；下方代码通过 int 参数触发拆箱按值比较。
  • 误称懒删除的每一次 find 都是 O(1)，忽略集中清理开销。

四语言完整实现

均采用相同的延迟清理策略。JavaScript 自带最小堆，不依赖评测环境的第三方队列。代码尚未执行或提交验证。

Java

import java.util.HashMap;
import java.util.Map;
import java.util.PriorityQueue;

class NumberContainers {
    private final Map<Integer, Integer> current = new HashMap<>();
    private final Map<Integer, PriorityQueue<Integer>> heaps = new HashMap<>();

    public NumberContainers() {}

    public void change(int index, int number) {
        Integer old = current.get(index);
        if (old != null && old == number) return;
        current.put(index, number);
        heaps.computeIfAbsent(number, key -> new PriorityQueue<>()).offer(index);
    }

    public int find(int number) {
        PriorityQueue<Integer> heap = heaps.get(number);
        if (heap == null) return -1;
        while (!heap.isEmpty() && current.get(heap.peek()) != number) {
            heap.poll();
        }
        return heap.isEmpty() ? -1 : heap.peek();
    }
}

JavaScript

class MinHeap {
    constructor() { this.a = []; }
    push(value) {
        const a = this.a;
        a.push(value);
        let i = a.length - 1;
        while (i > 0) {
            const p = Math.floor((i - 1) / 2);
            if (a[p] <= value) break;
            a[i] = a[p];
            i = p;
        }
        a[i] = value;
    }
    pop() {
        const a = this.a;
        if (!a.length) return undefined;
        const root = a[0];
        const last = a.pop();
        if (!a.length) return root;
        let i = 0;
        while (2 * i + 1 < a.length) {
            let child = 2 * i + 1;
            if (child + 1 < a.length && a[child + 1] < a[child]) child++;
            if (a[child] >= last) break;
            a[i] = a[child];
            i = child;
        }
        a[i] = last;
        return root;
    }
}

class NumberContainers {
    constructor() {
        this.current = new Map();
        this.heaps = new Map();
    }
    change(index, number) {
        if (this.current.get(index) === number) return;
        this.current.set(index, number);
        if (!this.heaps.has(number)) this.heaps.set(number, new MinHeap());
        this.heaps.get(number).push(index);
    }
    find(number) {
        const heap = this.heaps.get(number);
        if (!heap) return -1;
        while (heap.a.length && this.current.get(heap.a[0]) !== number) {
            heap.pop();
        }
        return heap.a.length ? heap.a[0] : -1;
    }
}

Python 3

from heapq import heappush, heappop

class NumberContainers:
    def __init__(self):
        self.current = {}
        self.heaps = {}

    def change(self, index: int, number: int) -> None:
        if self.current.get(index) == number:
            return
        self.current[index] = number
        if number not in self.heaps:
            self.heaps[number] = []
        heappush(self.heaps[number], index)

    def find(self, number: int) -> int:
        heap = self.heaps.get(number)
        if heap is None:
            return -1
        while heap and self.current.get(heap[0]) != number:
            heappop(heap)
        return heap[0] if heap else -1

C++

#include <unordered_map>
#include <queue>
#include <vector>
#include <functional>
using namespace std;

class NumberContainers {
    unordered_map<int, int> current;
    unordered_map<int, priority_queue<int, vector<int>, greater<int>>> heaps;
public:
    NumberContainers() {}

    void change(int index, int number) {
        auto it = current.find(index);
        if (it != current.end() && it->second == number) return;
        current[index] = number;
        heaps[number].push(index);
    }

    int find(int number) {
        auto it = heaps.find(number);
        if (it == heaps.end()) return -1;
        auto& heap = it->second;
        while (!heap.empty() && current.at(heap.top()) != number) {
            heap.pop();
        }
        return heap.empty() ? -1 : heap.top();
    }
};
