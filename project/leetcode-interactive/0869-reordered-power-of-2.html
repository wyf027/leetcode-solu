示例 1
输入：n = 1
输出：true

说明：1 = 20。

输出：false

说明：10 与 01 都不能得到合法的 2 的幂。

Complete solution

题解：枚举 2 的幂，比较数字频次

核心洞察
重排不会改变每个十进制数字出现的次数。因此，两个正整数能通过重排互相得到，当且仅当它们的 10 维数字频次数组完全相同。

完整过程

1
提取指纹

统计 n 中数字 0～9 的出现次数。

2
枚举候选

从 2⁰ 开始枚举不超过 10⁹ 的 2 的幂。

3
匹配返回

任一候选指纹相同就返回 true；全部不同则返回 false。

因为 n ≤ 10⁹，候选只需检查 2⁰ 到 2²⁹；实现中使用 p ≤ 10⁹ 的循环条件，范围清晰且不会把 10 位的 2³⁰ 纳入候选。前导零无需额外特判：2 的幂本身没有前导零；若频次相同，直接采用该 2 的幂的数字排列就是合法构造。

正确性证明

必要性：若 n 的某个重排等于 2 的幂 p，重排只改变位置，不改变各数字数量，所以 n 与 p 的数字频次相同。

充分性：若 n 与某个 2 的幂 p 的数字频次相同，则可按 p 的数字顺序重排 n。由于 p 的首位非零，该重排合法，并恰好得到 2 的幂。

算法枚举范围内所有可能的 2 的幂，并仅在频次相同的时候返回 true，因此返回结果当且仅当存在合法重排，算法正确。

复杂度

  • 时间：O(log M · log M)，其中 M = 10⁹；约 30 个候选，每次统计至多 10 位，实际可视为常数。
  • 空间：O(1)，频次数组长度固定为 10。

边界情况

  • n = 1，对应 2⁰。
  • 包含多个 0；不能把 0 放在首位，但匹配到的幂提供了合法顺序。
  • 重复数字必须逐个计数，集合无法表达重复次数。
  • 上界 10⁹ 仍在检查范围内。

class Solution {
    public boolean reorderedPowerOf2(int n) {
        int[] target = countDigits(n);
        for (int power = 1; power <= 1_000_000_000; power *= 2) {
            if (java.util.Arrays.equals(target, countDigits(power))) {
                return true;
            }
        }
        return false;
    }

    private int[] countDigits(int value) {
        int[] count = new int[10];
        while (value > 0) {
            count[value % 10]++;
            value /= 10;
        }
        return count;
    }
}

var reorderedPowerOf2 = function(n) {
    const countDigits = (value) => {
        const count = Array(10).fill(0);
        while (value > 0) {
            count[value % 10]++;
            value = Math.floor(value / 10);
        }
        return count.join(',');
    };

    const target = countDigits(n);
    for (let power = 1; power <= 1_000_000_000; power *= 2) {
        if (countDigits(power) === target) return true;
    }
    return false;

class Solution:
    def reorderedPowerOf2(self, n: int) -> bool:
        def count_digits(value: int) -> tuple[int, ...]:
            count = [0] * 10
            while value > 0:
                count[value % 10] += 1
                value //= 10
            return tuple(count)

        target = count_digits(n)
        power = 1
        while power <= 10**9:
            if count_digits(power) == target:
                return True
            power *= 2
        return False
class Solution {
public:
    bool reorderedPowerOf2(int n) {
        const auto target = countDigits(n);
        for (int power = 1; power <= 1000000000; power *= 2) {
            if (countDigits(power) == target) return true;
        }
        return false;
    }

private:
    std::array<int, 10> countDigits(int value) {
        std::array<int, 10> count{};
        while (value > 0) {
            ++count[value % 10];
            value /= 10;
        }
        return count;
    }
};

替代方案

可以把 n 的数字排序后形成字符串，并与每个 2 的幂的排序字符串比较。它同样正确，也更短；但每个候选都要排序，概念复杂度为 O(log M · log M · log log M)。还可以预计算所有指纹放进集合，适合多次查询。

常见错误

  • 枚举所有排列，最多 10! 个且存在大量重复。
  • 只比较数字集合，忽略重复次数。
  • 用 32 位有符号位移持续左移，引发溢出死循环。
  • 误把“数字和相同”当作指纹相同。

面试追问

  • 如果有大量查询？预先生成所有候选指纹并存入哈希集合，每次查询只统计一次。
  • 如果上界变大？使用 64 位整数或大整数枚举，并让停止条件匹配新上界。
  • 为什么不用处理前导零？匹配的目标是一个标准十进制 2 的幂，直接按它的排列就不会以前导零开始。
  • 能否用数学性质快速判断？末位、模数等条件只能剪枝，数字频次才给出充要条件。
