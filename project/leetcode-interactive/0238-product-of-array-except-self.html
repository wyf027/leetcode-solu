除自身以外数组的乘积

把每一格拆成“左边所有数的乘积”和“右边所有数的乘积”：相乘即可自然排除自己。

题意

给定整数数组 nums，返回 answer，其中 answer[i] 等于除 nums[i] 之外所有元素的乘积。要求 O(n) 时间，且不能使用除法。

官方样例 1

nums = [1, 2, 3, 4]

输出：[24, 12, 8, 6]

官方样例 2

nums = [-1, 1, 0, -3, 3]

输出：[0, 0, 9, 0, 0]

约束：2 ≤ nums.length ≤ 10⁵，−30 ≤ nums[i] ≤ 30；答案和任意前后缀乘积均保证适合 32 位整数。

两趟扫描

  1. 1. 左→右：answer[i] 暂存 i 左侧的乘积。
  2. 2. 右→左：用一个 suffix 累乘右侧，并乘入 answer[i]。
  3. 3. answer 被视为输出，不计额外空间，因此额外空间为 O(1)。

键盘：←/→ 前后步骤，T 自动播放，R 重置。

题解

首屏保持隐藏，点击按钮展开。

核心洞察：每个位置只缺自己

对于 i，所求正好是 nums[0..i−1] 的乘积乘以 nums[i+1..n−1] 的乘积。先让 answer[i] 保存左乘积，随后从右维护一个滚动后缀乘积并相乘。零自然被正确处理，无需另写分支。

不能用“全部乘积 ÷ nums[i]”：题目禁止除法，且有零时它也会失效。

完整过程：[1,2,3,4]

  1. 1. 左扫得到 answer = [1,1,2,6]。
  2. 2. 从右侧 suffix = 1 开始，在 i=3 处得到 6，suffix 变为 4。
  3. 3. i=2：2 × 4 = 8；suffix 变为 12。
  4. 4. 继续至开头，最终 [24,12,8,6]。

边界

一个零时只有零所在位置可能非零；两个及以上零时答案全为零；负数只会改变符号。

复杂度

两趟各扫 n 个元素，时间 O(n)；除返回数组外仅保存两个乘积变量，额外空间 O(1)。

替代方案与常见错

显式 prefix/suffix 两个数组更直观但 O(n) 额外空间。常见错误是后缀更新和乘入的顺序颠倒，导致把自身乘进去。

面试追问

若准许除法，可记录总乘积和零个数；但原题的前后缀解法更通用，也天然满足零与空间要求。 

class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];
        answer[0] = 1;
        for (int i = 1; i < n; i++) answer[i] = answer[i - 1] * nums[i - 1];
        int suffix = 1;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] *= suffix;
            suffix *= nums[i];
        }
        return answer;
    }
}
