翻转对

Reverse Pairs

给定整数数组 nums，统计所有满足 i < j 且 nums[i] > 2 × nums[j] 的下标对数量。

数组 分治 归并排序 双指针

Pair condition

i < j
并且
nums[i] > 2 × nums[j]

注意是严格大于。相等时不计入，例如 nums = [2, 1] 的答案是 0。

Problem

题意与输入输出

函数接收一个整数数组 nums，返回数组中“翻转对”的总数。一个下标对 (i, j) 成为翻转对，当且仅当：

  • 0 ≤ i < j < nums.length；
  • nums[i] > 2 × nums[j]。

函数形式：reversePairs(nums: integer[]) -> integer

示例 1

2 对
输入：nums = [1,3,2,3,1]
输出：2

解释：翻转对为
(1, 4)：3 > 2 × 1
(3, 4)：3 > 2 × 1

示例 2

3 对
输入：nums = [2,4,3,5,1]
输出：3

解释：翻转对为
(1, 4)：4 > 2 × 1
(2, 4)：3 > 2 × 1
(3, 4)：5 > 2 × 1

约束

  • 1 ≤ nums.length ≤ 5 × 10⁴
  • −2³¹ ≤ nums[i] ≤ 2³¹ − 1

Solution

归并排序中顺手计数

核心洞察

暴力枚举所有 (i, j) 需要 O(n²)。关键是把数组递归拆成左右两半：如果左右两半各自已经有序，就能用一个只向前移动的右指针，在线性时间内统计所有“左端点在左半、右端点在右半”的翻转对。

为什么能批量统计？

设左右半区升序。对当前左值 left[i]，从右半区起点推进 j，直到不再满足 left[i] > 2 × right[j]。那么右半区起点到 j - 1 的全部元素都与该左值构成翻转对，贡献就是 j - (mid + 1)。

完整过程

  1. 递归处理区间 [left, right]，在中点 mid 分成两半。
  2. 分别递归统计完全位于左半区、完全位于右半区的翻转对；递归返回时两半已经升序。
  3. 令 j = mid + 1。按升序遍历左半区的每个 i，只要 nums[i] > 2 × nums[j] 就推进 j。
  4. 对每个 i，加入 j - (mid + 1) 个跨区间翻转对。随着 nums[i] 变大，j 不必回退。
  5. 按普通归并排序方式合并两半，使整个区间升序，供上一层继续计数。

正确性证明

引理：跨区间计数准确

左右半区均升序。固定左下标 i 时，右半区中满足 nums[i] > 2 × nums[j] 的元素必构成一个前缀；双指针找到的边界恰是该前缀末尾之后的位置。因此加入的前缀长度不多不少。左值递增时满足条件的前缀只会扩张，右指针无需回退。

定理：算法返回全部翻转对

对区间长度归纳。长度为 1 时没有翻转对，结论成立。对更长区间，任意翻转对只可能完全在左半、完全在右半，或横跨两半。前两类由归纳假设准确统计，第三类由上述引理准确统计，三类互斥且覆盖全部情况，故总数正确。

复杂度

  • 时间：O(n log n)。每层递归的计数与归并总计 O(n)，共有 O(log n) 层。
  • 空间：O(n) 辅助数组，加上 O(log n) 递归栈。

边界处理

  • 比较必须使用严格大于号；2 > 2 × 1 为假。
  • 存在负数时，不能用“正数直觉”剪枝；排序双指针本身仍然成立。
  • Java / C++ 中先提升到 64 位再计算 2 × nums[j]，避免 32 位整数溢出。
  • 数组长度为 1 时直接返回 0；重复值不需要特殊处理。

Java

long 防溢出
class Solution {
    private int[] temp;

    public int reversePairs(int[] nums) {
        temp = new int[nums.length];
        return sortAndCount(nums, 0, nums.length - 1);
    }

    private int sortAndCount(int[] nums, int left, int right) {
        if (left >= right) return 0;

        int mid = left + (right - left) / 2;
        int count = sortAndCount(nums, left, mid)
                  + sortAndCount(nums, mid + 1, right);

        int j = mid + 1;
        for (int i = left; i <= mid; i++) {
            while (j <= right
                    && (long) nums[i] > 2L * nums[j]) {
                j++;
            }
            count += j - (mid + 1);
        }

        int i = left;
        j = mid + 1;
        int k = left;
        while (i <= mid && j <= right) {
            if (nums[i] <= nums[j]) temp[k++] = nums[i++];
            else temp[k++] = nums[j++];
        }
        while (i <= mid) temp[k++] = nums[i++];
        while (j <= right) temp[k++] = nums[j++];
        for (k = left; k <= right; k++) nums[k] = temp[k];

        return count;
    }
}

/**
 * @param {number[]} nums
 * @return {number}
 */
var reversePairs = function(nums) {
    const temp = new Array(nums.length);

    function sortAndCount(left, right) {
        if (left >= right) return 0;

        const mid = left + Math.floor((right - left) / 2);
        let count = sortAndCount(left, mid)
                  + sortAndCount(mid + 1, right);

        let j = mid + 1;
        for (let i = left; i <= mid; i++) {
            while (j <= right && nums[i] > 2 * nums[j]) {
                j++;
            }
            count += j - (mid + 1);
        }

        let i = left;
        j = mid + 1;
        let k = left;
        while (i <= mid && j <= right) {
            temp[k++] = nums[i] <= nums[j]
                ? nums[i++] : nums[j++];
        }
        while (i <= mid) temp[k++] = nums[i++];
        while (j <= right) temp[k++] = nums[j++];
        for (k = left; k <= right; k++) nums[k] = temp[k];

        return count;
    }

    return sortAndCount(0, nums.length - 1);
};

Python

整数任意精度
from typing import List


class Solution:
    def reversePairs(self, nums: List[int]) -> int:
        temp = [0] * len(nums)

        def sort_and_count(left: int, right: int) -> int:
            if left >= right:
                return 0

            mid = left + (right - left) // 2
            count = sort_and_count(left, mid)
            count += sort_and_count(mid + 1, right)

            j = mid + 1
            for i in range(left, mid + 1):
                while j <= right and nums[i] > 2 * nums[j]:
                    j += 1
                count += j - (mid + 1)

            i, j, k = left, mid + 1, left
            while i <= mid and j <= right:
                if nums[i] <= nums[j]:
                    temp[k] = nums[i]
                    i += 1
                else:
                    temp[k] = nums[j]
                    j += 1
                k += 1

            while i <= mid:
                temp[k] = nums[i]
                i += 1
                k += 1
            while j <= right:
                temp[k] = nums[j]
                j += 1
                k += 1

            nums[left:right + 1] = temp[left:right + 1]
            return count

        return sort_and_count(0, len(nums) - 1)

class Solution {
    vector<int> temp;

    int sortAndCount(vector<int>& nums, int left, int right) {
        if (left >= right) return 0;

        int mid = left + (right - left) / 2;
        int count = sortAndCount(nums, left, mid)
                  + sortAndCount(nums, mid + 1, right);

        int j = mid + 1;
        for (int i = left; i <= mid; ++i) {
            while (j <= right
                    && static_cast<long long>(nums[i])
                       > 2LL * nums[j]) {
                ++j;
            }
            count += j - (mid + 1);
        }

        int i = left;
        j = mid + 1;
        int k = left;
        while (i <= mid && j <= right) {
            if (nums[i] <= nums[j]) temp[k++] = nums[i++];
            else temp[k++] = nums[j++];
        }
        while (i <= mid) temp[k++] = nums[i++];
        while (j <= right) temp[k++] = nums[j++];
        for (k = left; k <= right; ++k) nums[k] = temp[k];

        return count;
    }

public:
    int reversePairs(vector<int>& nums) {
        temp.resize(nums.size());
        return sortAndCount(nums, 0, static_cast<int>(nums.size()) - 1);
    }
};

替代方案

  • 树状数组 + 离散化：依次处理元素，维护已见值频次，查询严格大于 2 × nums[j] 的数量。时间 O(n log n)、空间 O(n)，但倍数边界与离散化更易出错。
  • 线段树：同样先离散化，再做区间频次查询。能力更通用，但常数和代码量通常高于树状数组。
  • 有序集合 / 平衡树：若语言提供可统计秩的有序多重集，可在线维护；普通集合无法正确处理重复值和秩查询。
  • 暴力枚举：O(n²)，只适合极小输入或作为对拍基准，不满足本题最大规模。

面试追问

  1. 如果条件改为 nums[i] > k × nums[j]，哪些部分不变？当 k 为负数时单调性是否仍成立？
  2. 能否复用同一个辅助数组，避免每次递归创建新数组？
  3. 如何将递归归并改写为自底向上的迭代版本，消除递归栈？
  4. 如果数据以流式到达且必须实时给出答案，归并排序为什么不再直接适用？可换成什么数据结构？

常见错误

  • 把条件写成 >=，错误计入刚好等于两倍的情况。
  • 先归并再计数，导致左右半区边界或原下标关系被破坏。
  • 每次更换左指针都把右指针重置，虽然可能仍正确，却会退化到 O(n²)。
  • Java / C++ 在提升类型之前已经完成 2 * nums[j] 的 32 位乘法，发生溢出。
  • 只统计当前左右指针这一对，遗漏“有序前缀可整体计数”的核心批量贡献。
