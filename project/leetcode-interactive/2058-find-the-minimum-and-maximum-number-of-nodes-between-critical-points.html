Find the Minimum and Maximum Number of Nodes Between Critical Points

先观察相邻节点的起伏，再思考两个临界点之间的距离。

01 / 题目

给定单链表 head。一个节点只有同时拥有前驱和后继，才可能成为临界点：它的值必须严格大于两侧的值（局部极大），或严格小于两侧的值（局部极小）。相等不满足条件，头尾节点也不满足条件。

返回长度为 2 的整数数组 [minDistance, maxDistance]，分别表示任意两个不同临界点之间的最小与最大距离。距离是节点位置之差，即从一个节点走到另一个节点的边数。若临界点不足两个，返回 [-1, -1]。

参数：head: ListNode，示例用数组展示链表节点值。

返回：integer[2]

约束：节点数为 [2, 10⁵]；1 ≤ Node.val ≤ 10⁵。

距离不是“两端之间排除端点的节点数”。例如第 5 与第 6 个节点相距 1。

02 / 官方示例

示例 1 · 没有内部节点

输入：head = [3,1]
输出：[-1,-1]

两个节点都是端点，不能成为临界点。

示例 2 · 多个转折

输入：head = [5,3,1,2,5,1,2]
输出：[1,3]

从 1 开始计数，第 3、5、6 个节点为临界点。第 5 与第 6 个相距 1；第 3 与第 6 个相距 3。

示例 3 · 相等的邻居

输入：head = [1,3,2,2,3,2,2,2,7]
输出：[3,3]

第 2 和第 5 个节点为局部极大值点，距离为 3。平坦部分不满足严格比较，末尾的 7 也不是临界点。

示例 4 · 平台不算峰顶

输入：head = [2,3,3,2]
输出：[-1,-1]

两个 3 各有一个与自己相等的邻居，都不是严格极值。此例来自官方中文元数据。

04 / 独立题解

准备好后，展开推导、扫描演示与四语言代码。

题解 / 用位置记录起伏

核心洞察

把临界点的位置按遍历顺序写成 p₁ < p₂ < … < pₖ。最小距离只需比较相邻临界点的间距；最大距离一定是最后一个位置减去第一个位置。无需保存整张位置表。

完整过程

  1. 使用 prev 与 cur 从第二个节点开始扫描，令其下标 i = 1（代码使用 0 基下标）。循环要求 cur.next 存在。
  2. 用严格比较判断 cur 是否高于两侧或低于两侧。
  3. 首次遇到临界点时设置 first = i；后续遇到时先用 i - last 更新 best，然后再设置 last = i。
  4. 每次前进一个节点并增加下标。结束时，若 first == last，表示没有或只有一个临界点，返回 [-1,-1]；否则返回 [best, last - first]。

正确性：为什么只记这些量就够了？

判定完备。头尾没有完整邻居，均不合法；循环恰好访问所有内部节点，且使用与定义完全一致的两个严格不等式组合，所以每个临界点被发现一次，非临界点不会被记录。

最小距离。任意非相邻临界点的距离 pⱼ - pᵢ 是它们之间若干个正的相邻间距之和，不可能小于所有相邻间距的最小值。因此，全局最小距离在相邻临界点之间取得。

状态不变式。处理完任意前缀后，first 是已见第一个临界点，last 是已见最后一个，best 是已见相邻临界点的最小间距。新临界点只引入一个新相邻间距 i - last，先更新最小值再移动 last，不变式持续成立。

最大距离与返回。任意两点均位于首尾临界点之间，因此最大距离为 last - first。初始 first = last = -1，且每个临界点位置严格递增；二者相等当且仅当临界点不足两个。最终返回满足题意。

边界与常见错误

  • 只有两个节点：循环一次也不进入；只有一个临界点：也无法组成一对。
  • 与任何一侧相等都不算极值。不要把 > / < 写成非严格比较。
  • 先计算 i - last，再更新 last，否则新间距会变成 0。
  • 相邻的临界点距离可以是 1。不能对位置差再减 1，也不能计算节点值之差。
  • 单调链表、全相等链表都没有临界点；末尾数值即使最大也不能纳入。
  • 下标从 0 或 1 开始都可以，但必须统一；实际链表长度至少为 2，提交代码按官方约束访问 head.next。

复杂度与替代方案

直接扫描时间 O(n)、额外空间 O(1)；只维护固定数量指针和整数，不修改链表。最大距离小于 n，四种语言中的整数范围均足够。

替代方案：先收集所有临界点下标，再比较相邻差与首尾差，时间 O(n)、额外空间 O(k)，更方便展示完整位置序列。转成数组也可做，但额外空间 O(n)；两两枚举距离则为 O(k²)，没有必要。演示为了回退按当前步重算前缀并绘制数组，不属于提交算法的 O(1) 空间实现。

面试追问

  • 如果要返回具体节点对？最小值改进时记录上一临界点与当前点的位置或引用；最大值记录首尾。先约定并列时的规则。
  • 数据是流而不是链表？保存最近三个值与位置；只有读到下一个值后，才能确认中间值是否为临界点，状态仍为常量级。
  • 如果改为非严格极值？必须先重新约定平台的含义，是每个符合条件的节点还是整个平台；不能在原题中擅自放宽比较。
  • 能否提前返回？即使最小距离已达到 1，后续临界点仍可能扩大最大距离，所以仍需扫到末尾。

Java

// ListNode 由 LeetCode 提供：int val; ListNode next;
class Solution {
    public int[] nodesBetweenCriticalPoints(ListNode head) {
        int first = -1, last = -1, best = Integer.MAX_VALUE;
        int i = 1;
        ListNode prev = head, cur = head.next;
        while (cur != null && cur.next != null) {
            int a = prev.val, b = cur.val, c = cur.next.val;
            if ((b > a && b > c) || (b < a && b < c)) {
                if (first == -1) {
                    first = i;
                } else {
                    best = Math.min(best, i - last);
                }
                last = i;
            }
            prev = cur;
            cur = cur.next;
            i++;
        }
        if (first == last) return new int[]{-1, -1};
        return new int[]{best, last - first};
    }
}

var nodesBetweenCriticalPoints = function(head) {
    let first = -1, last = -1, best = Infinity;
    let i = 1, prev = head, cur = head.next;
    while (cur !== null && cur.next !== null) {
        const a = prev.val, b = cur.val, c = cur.next.val;
        if ((b > a && b > c) || (b < a && b < c)) {
            if (first === -1) first = i;
            else best = Math.min(best, i - last);
            last = i;
        }
        prev = cur;
        cur = cur.next;
        i++;
    }
    return first === last ? [-1, -1] : [best, last - first];
};

class Solution {

    vector<int> nodesBetweenCriticalPoints(ListNode* head) {
        int first = -1, last = -1, best = INT_MAX;

                else best = min(best, i - last);
                last = i;

            prev = cur;
            cur = cur->next;
            ++i;
        }
        if (first == last) return {-1, -1};
        return {best, last - first};
    }
