根据规则将箱子分类

Categorize Box According to Criteria

四个整数，一个分类结果。先读规则，再亲手把箱子送过分拣站。

题解默认折叠；你可以先独立思考，再使用逐步演示。

01 / 分拣规则

输入整数 length、width、height 和 mass，依次表示箱子的长、宽、高和质量。返回区分大小写的英文分类字符串。体积为三个维度的乘积。

  • Bulky（体积或尺寸大）：至少一个维度 ≥ 104，或者体积 ≥ 109。
  • Heavy（质量大）：质量 ≥ 100。
  • 两个条件都满足，返回 "Both"；都不满足，返回 "Neither"。
  • 仅满足 Bulky，返回 "Bulky"；仅满足 Heavy，返回 "Heavy"。

约束：1 ≤ length, width, height ≤ 105；1 ≤ mass ≤ 103。四个输入均为整数。

官方示例 1

输入：length = 1000, width = 35,
      height = 700, mass = 300
输出："Heavy"

三条边都小于 10000，体积为 24,500,000，小于 109；质量 300 ≥ 100，因此只属于 Heavy。

官方示例 2

输入：length = 200, width = 50,
      height = 800, mass = 50
输出："Neither"

三条边都小于 10000，体积为 8,000,000，小于 109；质量 50 < 100，因此两个条件都不满足。

04 / 独立题解

准备好后，展开思路与四语言代码。

核心洞察：两张标签，四个出口

Bulky 与 Heavy 是两个独立的布尔条件。先各算一次，再根据真假组合返回结果。质量不参与体积计算；尺寸检查和体积检查之间是“或”。

完整过程

  1. 计算体积 volume = length × width × height。
  2. 任一边 ≥ 10000 或体积 ≥ 1000000000 时，令 bulky = true。
  3. 质量 ≥ 100 时，令 heavy = true。
  4. 优先处理二者都真，返回 Both；随后处理仅 bulky、仅 heavy；最后返回 Neither。

示例 1：体积 24,500,000，三条边均未达到阈值，所以 bulky=false；质量 300 使 heavy=true，最终返回 Heavy。

正确性

bulky 的表达式恰好包含题目规定的全部尺寸与体积条件，因此它为真当且仅当箱子属于 Bulky。heavy 的比较与题目质量条件完全一致。两个布尔量共有四种组合，依次对应 Both、Bulky、Heavy、Neither；这些组合互斥且覆盖所有合法输入，故返回值正确。

边界与数值范围

  • 所有阈值包含等号。10000 的边长、109 的体积、100 的质量都应触发条件。
  • 即使每条边都小于 10000，乘积仍可能达到 109，不能省略体积检查。
  • 体积最大为 1015。Java 使用 long，C++ 使用 long long，并在乘法开始前提升类型。
  • JavaScript 的 Number 可精确表示本题范围内的整数，最大体积低于 253−1；Python 整数无需额外处理。

复杂度

时间 O(1)：固定次数的乘法、比较和分支。额外空间 O(1)：仅使用体积和两个布尔变量。

Java

class Solution {
    public String categorizeBox(int length, int width, int height, int mass) {
        long volume = 1L * length * width * height;
        boolean bulky = length >= 10000 || width >= 10000
                || height >= 10000 || volume >= 1000000000L;
        boolean heavy = mass >= 100;
        if (bulky && heavy) return "Both";
        if (bulky) return "Bulky";
        if (heavy) return "Heavy";
        return "Neither";
    }
}

替代方案

可使用索引 2 × bulky + heavy 查表 ["Neither", "Heavy", "Bulky", "Both"]。也可写嵌套条件表达式。二者复杂度不变；直接分支更便于解释和核对返回值。

面试追问

  • 为何先判断 Both？ 若先直接返回 Bulky，会把同时满足 Heavy 的箱子提前归类。
  • 范围扩大后如何处理？ 按新的最大乘积选择类型；超出 JavaScript 安全整数时使用 BigInt，固定宽度语言需采用更宽整数或防溢出的阈值比较。
  • 有很多箱子怎么办？ 对每个箱子做常数次判断，n 个箱子的总时间 O(n)，流式处理时额外工作空间仍为 O(1)。

常见错误

  • 把 ≥ 写成 >，遗漏恰好等于阈值的输入。
  • 把尺寸和体积条件连接成“且”，或要求所有边都达到 10000。
  • 将质量乘入体积，或认为体积大就必然 Heavy。
  • Java/C++ 先用 int 相乘再赋给宽整数；溢出已经发生，应从首个乘数开始提升类型。
  • 返回大小写不匹配的字符串，或漏掉 Both/Neither。
