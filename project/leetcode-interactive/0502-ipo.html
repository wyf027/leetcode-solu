The brief

先读懂资本规则

有 n 个互不相同的项目。项目 i 需要至少 capital[i] 的启动资本，完成后会把纯利润 profits[i] 加到当前资本中。

你的任务

初始资本为 w，最多完成 k 个不同项目。每一步只能启动当前资本足够覆盖门槛的项目；项目完成后，利润立即进入资本，可用于解锁后续项目。

返回所有合法选择方案中可以达到的最大最终资本。答案保证在 32 位有符号整数范围内。

函数签名

四个参数共同描述名额、起点以及每个项目的收益与准入门槛：

findMaximizedCapital(k, w, profits, capital) → int
官方示例 01 
输入：k = 2, w = 0,
profits = [1,2,3],
capital = [0,1,1]
输出：4

先完成门槛为 0、利润为 1 的项目，资本变为 1；第二次在已解锁项目中选择利润 3，最终资本为 4。

官方示例 02 
输入：k = 3, w = 0,
profits = [1,2,3],
capital = [0,1,2]
输出：6

每次完成项目后，增长的资本会继续解锁更高门槛的项目；三个名额都可被使用。

约束

  • 1 ≤ k ≤ 10⁵，0 ≤ w ≤ 10⁹
  • n = profits.length = capital.length，且 1 ≤ n ≤ 10⁵
  • 0 ≤ profits[i] ≤ 10⁴，0 ≤ capital[i] ≤ 10⁹

Core insight

把“能不能做”与“最值得做”拆开

核心洞察：项目一旦满足资本门槛，就会一直保持可做；而所有利润都非负。因此每一轮在当前可做项目中选择利润最大的项目，不会减少未来选择，反而让下一轮资本达到最大。

将项目按启动资本升序排列，用指针逐个把所有 capital[i] ≤ 当前资本 的项目利润加入最大堆。若堆非空，弹出最大利润并累加到资本；最多重复 k 轮。若堆为空，说明当前没有项目能启动，之后也无法凭空增加资本，可以提前结束。

按门槛排序

把项目组合成 (capital, profit)，按资本门槛升序排列。指针只前进，不回退。

收集已解锁项目

在每轮开始时，把门槛不超过当前资本的未入池项目全部加入最大堆。

选择最大利润

从堆顶取出最大利润，项目自然只会被选择一次；将利润加到当前资本。

结束或继续

做满 k 个项目即结束；若候选堆提前为空，也立即返回当前资本。

正确性证明

引理：在某一轮开始时，从所有当前可启动项目中选择利润最大的项目，所得资本不小于选择任意其他可启动项目后的资本。

证明：设当前资本为 W，最大可得利润为 p*，另一个合法选择利润为 p。因为 p* ≥ p ≥ 0，选择前者后的资本 W + p* ≥ W + p。资本更高时，下一轮所有原本可启动的项目仍然可启动，还可能解锁更多项目，所以可行选择集合不会缩小。

归纳：第一轮采用最大利润选择后，资本不低于任何其他合法方案。假设前 t 轮后该策略资本不低于对照方案，那么它在第 t+1 轮拥有至少同样大的可行集合；再选其中最大利润，资本仍不低于对照方案。故在不超过 k 轮后，该策略得到最大最终资本。

边界情况

  • 初始资本不足以启动任何项目：最大堆为空，直接返回 w。
  • k > n：每个项目最多入堆并被选一次，不会重复选择。
  • 利润为 0：选择不会增加资本；若还有名额，算法仍可继续，但不会影响最终最大值。
  • 多个项目门槛或利润相同：堆中次序不影响最大最终资本。
  • 资本与答案较大：题目保证最终答案在 32 位有符号整数范围内；JavaScript 的安全整数范围也足够覆盖。

复杂度

时间O(n log n + k log n)排序加最多 k 次堆操作
空间O(n)项目排序与最大堆

因为每个项目只会入堆一次，常写作 O(n log n + k log n)；当 k ≤ n 时可概括为 O(n log n)。

替代方案

每轮线性扫描：每轮遍历所有未选择项目，找出门槛满足且利润最大的一个。实现直观，但时间达到 O(kn)，在 10⁵ 规模下不可行。

两个优先队列：一个最小堆按资本门槛存所有未解锁项目，另一个最大堆存可做项目利润。每轮搬运门槛合格的项目。复杂度同阶，但通常比“排序 + 指针”常数与代码复杂度更高。

面试追问

  • 如果利润允许为负数，为什么要在最大利润不为正时提前停止？
  • 如果项目有持续时间且只能在截止日前完成，当前贪心是否仍成立？
  • 如果资本被项目占用、完成后才返还本金，状态应该如何变化？
  • 能否解释为什么只按利润排序，或只按门槛排序，都不足以直接得到答案？

常见错误

  • 把 capital[i] 当成项目成本并从 w 中扣除；它只是启动门槛。
  • 项目刚满足门槛时立即执行，而不是先收集本轮所有可做项目再比较利润。
  • 最大堆为空时继续循环，导致空堆访问；此时应直接结束。
  • 只向候选池加入一个新解锁项目，遗漏同一轮里其余也满足门槛的项目。
  • JavaScript 自制堆的上浮/下沉边界写错，或误用默认升序结构。

import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int findMaximizedCapital(int k, int w,
                                    int[] profits, int[] capital) {
        int n = profits.length;
        int[][] projects = new int[n][2];
        for (int i = 0; i < n; i++) {
            projects[i][0] = capital[i];
            projects[i][1] = profits[i];
        }
        Arrays.sort(projects, (a, b) -> Integer.compare(a[0], b[0]));

        PriorityQueue<Integer> maxProfit =
            new PriorityQueue<>((a, b) -> Integer.compare(b, a));
        int next = 0;

        for (int round = 0; round < k; round++) {
            while (next < n && projects[next][0] <= w) {
                maxProfit.offer(projects[next][1]);
                next++;
            }
            if (maxProfit.isEmpty()) {
                break;
            }
            w += maxProfit.poll();
        }
        return w;
    }
}
/**
 * @param {number} k
 * @param {number} w
 * @param {number[]} profits
 * @param {number[]} capital
 * @return {number}
 */
var findMaximizedCapital = function(k, w, profits, capital) {
    const projects = capital.map((need, i) => [need, profits[i]]);
    projects.sort((a, b) => a[0] - b[0]);

    const heap = [];
    const push = (value) => {
        heap.push(value);
        let i = heap.length - 1;
        while (i > 0) {
            const parent = Math.floor((i - 1) / 2);
            if (heap[parent] >= heap[i]) break;
            [heap[parent], heap[i]] = [heap[i], heap[parent]];
            i = parent;
        }
    };
    const pop = () => {
        const top = heap[0];
        const last = heap.pop();
        if (heap.length > 0) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let largest = i;
                const left = i * 2 + 1;
                const right = left + 1;
                if (left < heap.length && heap[left] > heap[largest]) {
                    largest = left;
                }
                if (right < heap.length && heap[right] > heap[largest]) {
                    largest = right;
                }
                if (largest === i) break;
                [heap[i], heap[largest]] = [heap[largest], heap[i]];
                i = largest;
            }
        }
        return top;
    };

    let next = 0;
    for (let round = 0; round < k; round++) {
        while (next < projects.length && projects[next][0] <= w) {
            push(projects[next][1]);
            next++;
        }
        if (heap.length === 0) break;
        w += pop();
    }
    return w;
};
from typing import List
import heapq


class Solution:
    def findMaximizedCapital(
        self,
        k: int,
        w: int,
        profits: List[int],
        capital: List[int],
    ) -> int:
        projects = sorted(zip(capital, profits))
        max_profit = []
        next_project = 0

        for _ in range(k):
            while (
                next_project < len(projects)
                and projects[next_project][0] <= w
            ):
                profit = projects[next_project][1]
                heapq.heappush(max_profit, -profit)
                next_project += 1

            if not max_profit:
                break

            w += -heapq.heappop(max_profit)

        return w
#include <algorithm>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int findMaximizedCapital(int k, int w,
                             vector<int>& profits,
                             vector<int>& capital) {
        vector<pair<int, int>> projects;
        projects.reserve(profits.size());
        for (int i = 0; i < static_cast<int>(profits.size()); ++i) {
            projects.emplace_back(capital[i], profits[i]);
        }
        sort(projects.begin(), projects.end());

        priority_queue<int> maxProfit;
        int next = 0;

        for (int round = 0; round < k; ++round) {
            while (next < static_cast<int>(projects.size()) &&
                   projects[next].first <= w) {
                maxProfit.push(projects[next].second);
                ++next;
            }
            if (maxProfit.empty()) {
                break;
            }
            w += maxProfit.top();
            maxProfit.pop();
        }
        return w;
    }
};
