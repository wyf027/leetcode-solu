拼接数组的最大分数

Maximum Score Of Spliced Array

同一段下标，两条数组。一次交换，哪一条能拿到更高的总分？

01 / 问题

交换的是连续区间

给定两个长度同为 n、下标从 0 开始的整数数组 nums1 和 nums2。你可以不操作，或选择一次闭区间 [left, right]，将两个数组在这段相同下标上的元素逐一互换。

操作后的分数是两个数组元素和的较大者，即 max(sum(nums1), sum(nums2))。返回所有合法选择中可以得到的最大分数。

必须满足 0 ≤ left ≤ right < n。区间必须连续、两侧位置必须相同，并且最多交换一次；分数不是两个数组的总和。

约束

  • n == nums1.length == nums2.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ nums1[i], nums2[i] ≤ 10⁴

接口：maximumsSplicedArray(nums1, nums2) → integer

04 / 独立题解

准备好后，再打开思路

包含逐步交互、推导与四种语言实现。

把交换区间，变成连续增益

核心洞察

先固定目标数组 nums1。记原数组和为 S1、S2，令 d[i] = nums2[i] − nums1[i]。交换 [l,r] 后，nums1 的和恰好增加该区间的 d 之和；nums2 的和减少同样的数。

nums1 的最优分数 = S1 + max(0, d 的最大连续子数组和)
nums2 的最优分数 = S2 + max(0, -d 的最大连续子数组和)
答案 = max(上述两者)

两个方向分别求最优，不需要使用同一个区间。最终只执行获胜方向对应的一次交换。允许不交换，所以最大增益至少为 0。

完整过程
  1. 累计 S1、S2。两个方向的 cur、best 都从 0 开始。
  2. 扫描下标 i，计算差值 d。目标 1 更新 cur1 = max(0, cur1 + d)，目标 2 更新 cur2 = max(0, cur2 − d)。
  3. 分别用当前 cur 更新历史最大值 best。cur 变成 0 时，可以把负担丢弃，从后一个位置重新开始。
  4. 全部扫描完，返回 max(S1 + best1, S2 + best2)。代码无需构建差值数组，也无需真的交换。


以示例 2 为例：S1 = S2 = 180，d = [30,−20,30,−30,−10]。目标 1 的 cur 依次为 [30,10,40,10,0]，best1 = 40；目标 2 的 cur 为 [0,20,0,30,40]，best2 = 40。两个方向都可达到 220；官方示例采用给 nums2 换入 [3,4] 的方案。


正确性证明
  1. 交换与区间增益一一对应。 固定目标 nums1 后，区间外的贡献不变，区间内每项变化为 d[i]。所有合法交换正好对应 d 的所有非空连续区间，不交换对应增益 0。
  2. 递推找全连续区间。 处理到 i 时，cur 等于 0 与所有以 i 结尾的区间和中的最大值。以 i 结尾的区间要么从 i 开始，要么接在前一个结尾区间后；若之前最佳和为负，舍弃它更优，因此递推为 max(0,cur+d)。归纳可知状态始终成立，best 保存所有终点中的最大值。
  3. 覆盖最终赢家。 对任意交换 t，分数是 max(A(t),B(t))。有限选择集合中，maxₜ max(A(t),B(t)) = max(maxₜ A(t),maxₜ B(t))。对 d 与 −d 各做一次递推，恰好覆盖这两个最优值，取较大者即为答案。


边界与数值范围
  • n = 1：交换仅调换两个值的位置，最大分数不变。
  • 两数组相同：全部差值为 0，不交换即可。
  • 某方向差值全负：该方向最佳增益为 0；仍需计算另一个方向。
  • 整段交换只会互换 S1、S2，不能提高原有最大值，但算法可以自然处理该选择。
  • 单个数组的和及答案至多 10⁹，Java / C++ 的 32 位有符号 int 足够；JavaScript Number 精确覆盖此范围。若约束放大，要重新评估并使用 long / long long 等。
  • 多个区间同样最优时返回分数即可；演示保留先找到的正增益区间，平分时选择目标 1。


复杂度
提交实现仅一次扫描：时间 O(n)，额外空间 O(1)。交互页面为了回放保存每步状态，并生成表格，使用 O(n) 空间；演示上限为 24 项。


替代方案
  • 前缀和：维护 d 的前缀和与先前最小前缀，当前前缀减去最小前缀即最佳区间增益；对 −d 同理，仍为 O(n) 时间、O(1) 空间。
  • 三状态动态规划：按“未交换 / 正在交换 / 已结束交换”推进，每种目标各求一次。状态更多，但更容易推广到多次区间操作。
  • 枚举所有区间：用前缀和 O(1) 算每段增益，总时间 O(n²)，只适合未来的小数据参考验证，无法满足最大规模。


常见错误
  • 只优化原本和较大的数组，漏掉另一个数组反超的可能。
  • 把所有正差值相加：这会非法选择多个不连续区间。
  • 同时加上 best1 与 best2：它们是互斥的候选操作，不能一起执行。
  • 遗漏增益 0，导致把“最多一次”误写成必须进行有损交换。
  • 提前返回部分扫描的原数组和，或先修改原数组再计算另一个方向。


面试追问
  • 如何返回交换区间？ cur 清零时记录下一段起点，best 严格提高时保存起点与当前下标；最后选出获胜方向。增益为 0 可以返回“不交换”。
  • 允许至多 k 段不重叠交换？ 对固定目标求至多 k 个不重叠子数组的最大和，用段数与“段内 / 段外”状态推进，典型为 O(nk) 时间、O(k) 空间。
  • 允许输入负数？ 增益转化和递推仍然成立，但原数组和不能以 0 替代；答案可能为负，且需重新检查数值范围。
  • 区间长度必须恰好为 L？ 对差值使用固定长度滑动窗口；若仍允许不交换，继续与增益 0 比较。

Java
class Solution {
    public int maximumsSplicedArray(int[] nums1, int[] nums2) {
        int sum1 = 0, sum2 = 0;
        int cur1 = 0, cur2 = 0, best1 = 0, best2 = 0;
        for (int i = 0; i < nums1.length; i++) {
            sum1 += nums1[i];
            sum2 += nums2[i];
            int d = nums2[i] - nums1[i];
            cur1 = Math.max(0, cur1 + d);
            cur2 = Math.max(0, cur2 - d);
            best1 = Math.max(best1, cur1);
            best2 = Math.max(best2, cur2);
        }
        return Math.max(sum1 + best1, sum2 + best2);
    }
}

class Solution:
    def maximumsSplicedArray(self, nums1: List[int], nums2: List[int]) -> int:
        sum1 = sum2 = 0
        cur1 = cur2 = best1 = best2 = 0
        for a, b in zip(nums1, nums2):
            sum1 += a
            sum2 += b
            d = b - a
            cur1 = max(0, cur1 + d)
            cur2 = max(0, cur2 - d)
            best1 = max(best1, cur1)
            best2 = max(best2, cur2)
        return max(sum1 + best1, sum2 + best2)
