CORE INSIGHT

把数字下标当作递归深度

递归函数只需要两个状态：当前处理到的下标 index，以及已经选择的路径 path。在第 index 层，遍历该数字映射的每个字母：加入路径、进入下一层、返回后撤销选择。下标到达 digits.length 时，路径就是一个完整答案。

digit position → tree level
mapped letter → branch
path length == n → emit answer

30-SECOND PITCH

“我用回溯枚举决策树。每层对应一位数字，每条边选择该按键的一个字母；到叶子收集字符串，返回时撤销字母。输出本身有指数规模，因此算法已经是输出敏感的最优量级。”

完整解题过程

  1. 1. 准备固定映射：2→abc，3→def，…，7→pqrs，9→wxyz。
  2. 2. 空输入直接返回空数组，避免把空路径误当答案。
  3. 3. DFS 读取当前数字，逐一尝试其对应字母。
  4. 4. 选择字母后递归；返回时删除路径末尾字符，恢复现场。
  5. 5. 当深度等于号码长度，把路径副本加入答案。

边界与复杂度

  • 空字符串：防御性返回 []，不是 [""]。
  • 7 / 9：各有 4 个字母，是最容易漏掉的映射。
  • 单个数字：答案就是该按键的字母列表。
  • 时间：O(n × K)，K 是输出组合数，最坏 K=4ⁿ。
  • 额外空间：O(n) 递归栈与路径；计入输出为 O(n × K)。

替代方案

迭代 BFS 从 [""] 开始，每读一位就做笛卡尔积。它避免递归，但每层都要创建中间列表。面试主线优先回溯：决策树语义更直接，辅助空间更清晰。

面试高频追问

  • 为什么复杂度不能只写 O(4ⁿ)？
  • 怎样改成惰性迭代器，逐个产生答案？
  • 如果输入允许 0、1，该如何定义行为？
  • 回溯与 BFS 的峰值内存差异是什么？

常见错误

  • 把空输入返回成 [""]。
  • 漏写 7 的 s 或 9 的 z。
  • 递归返回后忘记删除路径末尾字符。
  • 把同一个可变 path 对象直接存入结果。
  • 下标用数字值而非输入位置，层级错乱。

class Solution {
    private static final String[] KEYS = {
        "", "", "abc", "def", "ghi",
        "jkl", "mno", "pqrs", "tuv", "wxyz"
    };

    public List<String> letterCombinations(String digits) {
        List<String> answer = new ArrayList<>();
        if (digits == null || digits.isEmpty()) {
            return answer;
        }

        char[] path = new char[digits.length()];
        dfs(digits, 0, path, answer);
        return answer;
    }

    private void dfs(String digits, int index, char[] path,
                     List<String> answer) {
        if (index == digits.length()) {
            answer.add(new String(path));
            return;
        }

        String letters = KEYS[digits.charAt(index) - '0'];
        for (int i = 0; i < letters.length(); i++) {
            path[index] = letters.charAt(i);
            dfs(digits, index + 1, path, answer);
        }
    }
}
var letterCombinations = function (digits) {
  if (digits.length === 0) return [];

  const keys = [
    "", "", "abc", "def", "ghi",
    "jkl", "mno", "pqrs", "tuv", "wxyz",
  ];
  const answer = [];
  const path = [];

  function dfs(index) {
    if (index === digits.length) {
      answer.push(path.join(""));
      return;
    }

    const letters = keys[Number(digits[index])];
    for (const letter of letters) {
      path.push(letter);
      dfs(index + 1);
      path.pop();
    }
  }

  dfs(0);
  return answer;
};

class Solution {
public:
    vector<string> letterCombinations(string digits) {
        if (digits.empty()) return {};

        const vector<string> keys = {
            "", "", "abc", "def", "ghi",
            "jkl", "mno", "pqrs", "tuv", "wxyz"
        };
        vector<string> answer;
        string path;

        function<void(int)> dfs = [&](int index) {
            if (index == static_cast<int>(digits.size())) {
                answer.push_back(path);
                return;
            }

            for (char letter : keys[digits[index] - '0']) {
                path.push_back(letter);
                dfs(index + 1);
                path.pop_back();
            }
        };

        dfs(0);
        return answer;
    }
};
