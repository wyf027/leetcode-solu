01 / 题目

给定正整数数组 nums。设所有元素相乘得到整数 P，返回 P 的不同质因数数量；相同质因数无论出现多少次，只计一次。

质数是大于 1 且只有 1 和自身这两个正因数的整数；若 b 能被 a 整除，则 a 是 b 的因数。

官方示例 1

输入：nums = [2,4,3,7,10,6]
输出：4

乘积为 10080 = 2⁵ × 3² × 5 × 7，包含 2、3、5、7 四种质因数。

官方示例 2

输入：nums = [2,4,8,16]
输出：1

乘积为 1024 = 2¹⁰，只有质因数 2，因此返回 1。

约束与接口

  • 1 ≤ nums.length ≤ 10⁴
  • 2 ≤ nums[i] ≤ 1000
  • 参数：整数数组 nums；返回：整数。

04 / 独立题解

核心洞察：乘积的质因数 = 各元素质因数的并集

不必计算可能极大的乘积。对每个元素做质因数分解，把遇到的质因数放进同一个集合，最终返回集合大小。

完整过程

  1. 建立空集合 seen。
  2. 对每个原数取局部副本 x，从 d = 2 开始试除。
  3. 只要 d × d ≤ x，检查 x 是否能整除 d；能则把 d 加入集合，并反复令 x = x / d，直到消去所有 d。
  4. 把 d 加一，继续试除。当循环结束且 x > 1，把这个剩余质数加入集合。
  5. 所有元素处理完毕后返回 seen 的大小。

例如 10：除去 2 后余数变成 5；此时下一个候选 3 的平方大于 5，所以直接收集剩余质数 5。对 4 则连续除两次 2，但集合只记录一次。

正确性

单个元素：轮到候选 d 时，小于 d 的质因数已全部消去。如果 d 整除余数，d 不可能是合数，否则它的某个更小质因数应仍能整除余数，与不变量矛盾。因此加入的 d 是质数。反复除去 d 保留了尚未收集的全部质因数。当 d² > x 时，若余数 x > 1 仍是合数，就应有不超过 √x 的质因数，但这些候选已被排除，矛盾；故剩余 x 是质数。于是每个数的质因数被完整且正确地收集。

整个数组：若质数 p 整除某个元素，它也整除乘积；反之，由质数整除乘积的性质，p 必整除至少一个元素。因此乘积的质因数恰好是这些集合的并集。集合去重后，其大小就是所求数量。

边界与复杂度

  • 单个质数最终由余数分支收集；平方数必须使用 ≤，例如 49 的因子 7。
  • 相同质数的高次幂、重复元素和跨元素重复都只计一次；余数 1 不能加入集合。
  • 题目不包含空数组或数值 1；代码只修改局部 x，不改变输入数组。
  • 设 n 为数组长度，M 为最大元素，K 为最终不同质因数数目。时间为 O(n√M)（哈希集合操作按期望 O(1)）；额外空间 O(K)，且 K ≤ π(M)，π(M) 表示不大于 M 的质数数量。

替代方案

可以筛出不超过 M 的所有质数，只使用质数试除；如果同一值域有大量查询，可以用最小质因数表：预处理约 O(M log log M)、空间 O(M)，之后每个数按最小质因数反复分解，总计 O(n log M)。本题 M ≤ 1000，直接试除更简洁。计算总乘积再分解会产生巨大整数，应避免。

常见错误

  • 计算质因数出现次数，而不是种类；应使用全局集合。
  • 把所有因数都加入集合，误把 4、6 等合数计入。
  • 遗漏循环后 x > 1 的剩余因子。
  • 只除一次就递增 d，可能把合数余数当作质数，例如 12 只除一次 2 后剩下 6。
  • 误用 d × d < x 导致平方边界遗漏；Python 需使用整数除法 //。

面试追问

若元素到 10⁹？可先筛到 √M，用质数表试除，仍需结合 n 评估成本。若需回答多批同值域数组？预处理最小质因数或缓存每个不同值的分解结果。若要每个质因数在乘积中的指数？把集合改为计数表，每除一次就累加一次指数。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int distinctPrimeFactors(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int value : nums) {
            int x = value;
            for (int d = 2; d * d <= x; d++) {
                if (x % d == 0) {
                    seen.add(d);
                    while (x % d == 0) x /= d;
                }
            }
            if (x > 1) seen.add(x);
        }
        return seen.size();
    }
}

var distinctPrimeFactors = function(nums) {
    const seen = new Set();
    for (let x of nums) {
        for (let d = 2; d * d <= x; d++) {
            if (x % d === 0) {
                seen.add(d);
                while (x % d === 0) x /= d;
            }
        }
        if (x > 1) seen.add(x);
    }
    return seen.size;
};

Python 3

from typing import List

class Solution:
    def distinctPrimeFactors(self, nums: List[int]) -> int:
        seen = set()
        for x in nums:
            d = 2
            while d * d <= x:
                if x % d == 0:
                    seen.add(d)
                    while x % d == 0:
                        x //= d
                d += 1
            if x > 1:
                seen.add(x)
        return len(seen)

C++

#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int distinctPrimeFactors(vector<int>& nums) {
        unordered_set<int> seen;
        for (int x : nums) {
            for (int d = 2; d * d <= x; ++d) {
                if (x % d == 0) {
                    seen.insert(d);
                    while (x % d == 0) x /= d;
                }
            }
            if (x > 1) seen.insert(x);
        }
        return static_cast<int>(seen.size());
    }
};
