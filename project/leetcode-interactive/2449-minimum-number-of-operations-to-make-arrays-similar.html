使数组相似的
最少操作次数

Minimum Number of Operations to Make Arrays Similar

一次给一个元素加 2，同时给另一个元素减 2。怎样用最少的操作，让两个数组拥有相同的元素频率？

官方题目 ↗

01 / 题目

给定两个长度相同的正整数数组 nums 和 target。每次在 nums 中选择不同下标 i、j（0 ≤ i, j < nums.length），同时执行 nums[i] += 2 和 nums[j] -= 2。

“相似”指每个数的出现次数都相同，元素位置可以不同。返回使两数组相似的最少操作次数。题目保证存在可行方案。

先尝试独立思考：操作改变了什么，又保留了什么？题解与演示均在页面底部，默认收起。

约束

  • n == nums.length == target.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ nums[i], target[i] ≤ 10⁶
  • 输入保证 nums 能变为与 target 相似。

函数形式

makeSimilar(nums: integer[], target: integer[]) → long

02 / 官方示例

示例 1

输入：nums = [8,12,6], target = [2,14,10]
输出：2

先选 i = 0, j = 2，得到 [10,12,4]；再选 i = 1, j = 2，得到 [10,14,2]。元素频率与目标一致，最少 2 次。

示例 2

输入：nums = [1,2,5], target = [4,1,3]
输出：1

选择 i = 1, j = 2，得到 [1,4,3]，一次即可。

示例 3

输入：nums = [1,1,1,1,1], target = [1,1,1,1,1]
输出：0

初始数组已经相似，不需要操作。

04 / 独立题解

准备好了再展开：可视化、证明与四语言代码。

把数值看成可转移的双单位筹码

每次操作保持总和不变，也保持每个位置的奇偶性。因此只能把原数组中的偶数配给目标偶数、奇数配给目标奇数；但一次转移的两个位置可以具有不同奇偶性。

核心洞察

  1. 分别提取奇数与偶数，在各自组内升序排序后按位置配对。
  2. 记配对差的绝对值总和为 D = Σ |a[i] − b[i]|。
  3. 一次操作让一个多余位置减少 2，让一个不足位置增加 2，恰好消除 4 的总差，所以最少次数是 D / 4。

完整过程：以示例 1 为例

偶数组分别排序得到 [6,8,12] 与 [2,10,14]。差值为 [4,−2,−2]，绝对差为 8。让 6 所在位置向 8 所在位置转移 2，再向 12 所在位置转移 2，最终得到配对后的 [2,10,14]，共 8 / 4 = 2 次。演示中显示的是原下标上的变化。

正确性证明

  1. 配对合法性。每个位置只能变化偶数，故终值与初值同奇偶。目标只要求频率一致，任意合法结果都对应组内的一个配对。
  2. 排序配对最优。若 a ≤ b 且 x ≤ y，有 |a−x| + |b−y| ≤ |a−y| + |b−x|。交换一个交叉配对不会增大代价，反复去掉交叉，得到组内升序一一配对。因此该方案使总绝对差 D 最小。
  3. 操作下界。对任意最终配对，每次操作只影响两个位置，各改变 2，总绝对差最多减少 4。至少需要 D / 4 次。
  4. 下界可达。总和相等意味着总盈余等于总不足，且每个差值都是偶数。只要没完成，就存在不同的盈余、缺额位置。从前者向后者转移 2，两处差距同时缩小 2，直至全部归零，正好 D / 4 次。每个位置单调趋向正目标，不会出现负值。

边界与复杂度

  • n = 1 且保证可行时，两值必相同，答案为 0。全奇数、全偶数和重复元素均按同一流程处理。
  • 某个奇偶组的和不一定相等。例如 [1,4] → [3,2] 要跨组转移；仅组内配对，不能强迫转移也留在组内。
  • 时间 O(n log n)；下面四份实现均使用排序副本或分组数组，额外空间 O(n)，不修改调用方数组。
  • D 的粗略上界小于 10¹¹。Java 使用 long，C++ 使用 long long；Python 整数足够，JavaScript Number 在该范围内能精确表示整数，避免位运算累加截断。

替代方案

只累计正差 S = Σ max(a[i]−b[i], 0)，答案为 S / 2，与 D / 4 等价。值域有限时也可以按奇偶建立计数桶，依次消耗频次配对，将时间改为 O(n + U)、空间改为 O(U)；这里排序实现更直接。逐次模拟仅适合演示，真实答案可能超过百亿，不能循环执行每次操作。

常见错误

  • 直接将整体数值排序后按索引配对，可能把奇数配给偶数。应分组排序，或先按奇偶再按数值排序。
  • 将绝对差除以 2，重复计算了操作的两端。绝对差应除以 4，单侧盈余才除以 2。
  • 对每个奇偶组分别整除 4 后求和。单组 D 可能仅为 2，必须先合计所有组再除。
  • 比较数组原下标的差，忽略只需频率相等；或用集合丢失重复次数。
  • 用 32 位整数累计，或用排序默认的字符串顺序处理 JavaScript 数字。

面试追问

不保证可行怎么办？检查长度、总和、奇数数量是否一致；三者一致即可用上述配对与转移构造方案。
每次改为 ±k 呢？按模 k 的余数分组排序，累计绝对差再除以 2k，总和与各余数组数量是可行条件。
需要具体方案呢？保留原下标，用盈余和不足两个指针配对，每次批量转移两者较小的差值；可输出 O(n) 个带重复次数的转移记录。

四语言完整提交代码

采用官方 makeSimilar 签名；以下代码均未执行验证。统一计算同奇偶配对的总绝对差，最后除以 4。

Java

import java.util.Arrays;

class Solution {
    public long makeSimilar(int[] nums, int[] target) {
        long distance = 0;
        for (int parity = 0; parity < 2; parity++) {
            final int p = parity;
            int[] a = Arrays.stream(nums)
                .filter(x -> x % 2 == p).sorted().toArray();
            int[] b = Arrays.stream(target)
                .filter(x -> x % 2 == p).sorted().toArray();
            for (int i = 0; i < a.length; i++) {
                distance += Math.abs((long) a[i] - b[i]);
            }
        }
        return distance / 4;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @param {number[]} target
 * @return {number}

var makeSimilar = function(nums, target) {
    const compare = (a, b) => (a % 2 - b % 2) || (a - b);
    const a = [...nums].sort(compare);
    const b = [...target].sort(compare);
    let distance = 0;
    for (let i = 0; i < a.length; i++) {
        distance += Math.abs(a[i] - b[i]);
    }
    return distance / 4;
};

Python 3

from typing import List

class Solution:
    def makeSimilar(self, nums: List[int], target: List[int]) -> int:
        a = sorted(nums, key=lambda x: (x % 2, x))
        b = sorted(target, key=lambda x: (x % 2, x))
        return sum(abs(x - y) for x, y in zip(a, b)) // 4

C++

#include <algorithm>
#include <cstdlib>
#include <vector>
using namespace std;

class Solution {
public:
    long long makeSimilar(vector<int>& nums, vector<int>& target) {
        vector<int> a = nums, b = target;
        auto compare = [](int x, int y) {
            if (x % 2 != y % 2) return x % 2 < y % 2;
            return x < y;
        };
        sort(a.begin(), a.end(), compare);
        sort(b.begin(), b.end(), compare);
        long long distance = 0;
        for (size_t i = 0; i < a.size(); ++i) {
            distance += llabs((long long) a[i] - b[i]);
        }
        return distance / 4;
    }
};
