满足不等式的最大值

两点之间有距离限制，但目标式同时混合了坐标与绝对值。先通过题面和动态演示建立直觉，再决定是否展开完整题解。

困难数组滑动窗口单调队列优先队列

Problem

题目

函数：findMaxValueOfEquation(points, k) → integer

题意转述

给定按横坐标严格递增排列的二维点数组 points，其中第 i 个点为 [xᵢ, yᵢ]，以及整数 k。

从中选择下标满足 i < j 的两个点，并要求它们的横坐标距离不超过 k。返回下式能取得的最大值；题目保证至少存在一对合法点。

yᵢ + yⱼ + |xᵢ − xⱼ|，且 |xᵢ − xⱼ| ≤ k

约束

  • 2 ≤ points.length ≤ 10⁵
  • points[i].length == 2
  • −10⁸ ≤ xᵢ, yᵢ ≤ 10⁸
  • 0 ≤ k ≤ 2 × 10⁸
  • 对所有 i < j，都有 xᵢ < xⱼ
  • 至少有一对点满足距离限制

示例 1

输入：points = [[1,3],[2,0],[5,10],[6,-10]], k = 1
输出：4

合法点对是前两个点与后两个点；对应结果分别为 4 和 1，因此答案为 4。

示例 2

输入：points = [[0,0],[3,0],[9,2]], k = 3
输出：3

只有前两个点的横坐标距离不超过 3，代入后得到 3。

Core insight

把“找点对”拆成“当前点 + 最优历史点”

因为点按横坐标递增，选择 i < j 时必有 xⱼ > xᵢ，所以绝对值可直接展开：

yᵢ + yⱼ + |xᵢ − xⱼ| = (yᵢ − xᵢ) + (yⱼ + xⱼ)

扫描到右端点 j 时，第二项固定，只需在所有满足 xⱼ − xᵢ ≤ k 的历史点中找到最大的 yᵢ − xᵢ。候选窗口随着 j 只向右移动，适合用维护递减值的双端队列。

完整过程

  1. 过期。 队首若满足 xⱼ − xᵢ > k，该点对当前及后续所有右端点都不再合法，持续从队首删除。
  2. 结算。 若队列非空，队首拥有窗口内最大的 yᵢ − xᵢ，用它与当前点计算候选答案。
  3. 去弱。 从队尾删除所有 yᵢ − xᵢ ≤ yⱼ − xⱼ 的点；新点更靠右且值不小，它们以后不会更优。
  4. 入队。 把当前点以 [xⱼ, yⱼ − xⱼ] 的形式放到队尾，供未来点使用。

边界

必须先结算再让当前点入队，以保证 i < j。k = 0 时，由于横坐标严格递增，题目保证存在合法点对的前提实际上不会成立；但算法仍能安全处理为空窗口的情况。

复杂度

每个点至多入队一次、从队首或队尾出队一次，因此时间复杂度 O(n)，队列最坏占用 O(n) 空间。

数值范围

目标值理论范围在 32 位有符号整数内，但中间表达式在工程语言中使用 64 位更稳妥。官方 Java / C++ 签名返回 int。

正确性证明

不变式 1：处理点 j 并完成过期删除后，队列中的点都位于合法窗口 xⱼ − k ≤ xᵢ < xⱼ 内。

不变式 2：队列中 yᵢ − xᵢ 严格递减。因此队首是合法历史点中该值最大的点。若某旧点从队尾被新点淘汰，新点的值不小且横坐标更大：在旧点仍合法的任意未来时刻，新点也合法且不会更差，所以删除不影响最优解。

结论：对每个右端点 j，算法都用最优合法左端点计算该 j 下的最大值。遍历全部右端点并取最大值，覆盖所有合法点对，故返回全局最优解。

Solution.java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int findMaxValueOfEquation(int[][] points, int k) {
        // 每项为 {x, y - x}，按 y - x 严格递减。
        Deque<int[]> deque = new ArrayDeque<>();
        long answer = Long.MIN_VALUE;

        for (int[] point : points) {
            int x = point[0];
            int y = point[1];

            while (!deque.isEmpty() && (long) x - deque.peekFirst()[0] > k) {
                deque.pollFirst();
            }

            if (!deque.isEmpty()) {
                answer = Math.max(answer, (long) x + y + deque.peekFirst()[1]);
            }

            int value = y - x;
            while (!deque.isEmpty() && deque.peekLast()[1] <= value) {
                deque.pollLast();
            }
            deque.offerLast(new int[] {x, value});
        }

        return (int) answer;
    }
}
solution.js
/**
 * @param {number[][]} points
 * @param {number} k
 * @return {number}
 */
var findMaxValueOfEquation = function(points, k) {
    // deque[head...] 存 [x, y - x]，值严格递减。
    const deque = [];
    let head = 0;
    let answer = -Infinity;

    for (const [x, y] of points) {
        while (head < deque.length && x - deque[head][0] > k) {
            head++;
        }

        if (head < deque.length) {
            answer = Math.max(answer, x + y + deque[head][1]);
        }

        const value = y - x;
        while (deque.length > head && deque[deque.length - 1][1] <= value) {
            deque.pop();
        }
        deque.push([x, value]);
    }

    return answer;
};
solution.py
from collections import deque
from typing import List


class Solution:
    def findMaxValueOfEquation(
        self, points: List[List[int]], k: int
    ) -> int:
        # 每项为 (x, y - x)，按 y - x 严格递减。
        candidates = deque()
        answer = float("-inf")

        for x, y in points:
            while candidates and x - candidates[0][0] > k:
                candidates.popleft()

            if candidates:
                answer = max(answer, x + y + candidates[0][1])

            value = y - x
            while candidates and candidates[-1][1] <= value:
                candidates.pop()
            candidates.append((x, value))

        return int(answer)
solution.cpp
#include <algorithm>
#include <climits>
#include <deque>
#include <vector>
using namespace std;

class Solution {
public:
    int findMaxValueOfEquation(vector<vector<int>>& points, int k) {
        // 每项为 {x, y - x}，按 y - x 严格递减。
        deque<pair<int, int>> candidates;
        long long answer = LLONG_MIN;

        for (const auto& point : points) {
            int x = point[0];
            int y = point[1];

            while (!candidates.empty() &&
                   static_cast<long long>(x) - candidates.front().first > k) {
                candidates.pop_front();
            }

            if (!candidates.empty()) {
                answer = max(answer,
                             static_cast<long long>(x) + y + candidates.front().second);
            }

            int value = y - x;
            while (!candidates.empty() && candidates.back().second <= value) {
                candidates.pop_back();
            }
            candidates.emplace_back(x, value);
        }

        return static_cast<int>(answer);
    }
};

替代方案：最大堆

也可以把 yᵢ − xᵢ 作为最大堆的主键。对每个当前点，持续弹出堆顶中过期的点，再用堆顶更新答案。写法直观，时间复杂度为 O(n log n)，空间复杂度为 O(n)。由于输入已按 x 递增，单调队列能进一步做到线性时间。

面试追问

  • 为什么被队尾淘汰的点永远不会重新成为最优候选？
  • 如果输入没有按横坐标排序，复杂度会怎样变化？
  • 若要求返回最优点对的下标，需要在队列中额外保存什么？
  • 若约束变为横坐标距离严格小于 k，过期条件如何修改？

常见错误

  • 把拆式写成 yᵢ + xᵢ，忽略了 i < j 下绝对值的方向。
  • 先入队再计算，使同一个点与自己配对。
  • 只删过期队首，却没有从队尾删除被支配候选，退化或得到错误队首。
  • 使用数组 shift() 实现 JavaScript 队首删除，导致潜在的平方级搬移成本。
  • 答案初始化为 0，从而在所有合法结果为负数时出错。
