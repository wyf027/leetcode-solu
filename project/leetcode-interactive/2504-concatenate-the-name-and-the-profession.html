把名字和职业联系起来

Concatenate the Name and the Profession

把一张人员表整理成简洁的显示列表。先想清楚每行该显示什么，以及行与行之间的顺序。

离线学习页 · 第 59 / 100 题 · 题解默认折叠

01 / 题意与数据约定

给定人员表 Person，输出每个人的 person_id，以及“名字 + 括号中的职业首字母”组成的 name。名字后直接接左括号，不额外插入空格。结果按 person_id 从大到小排列。

字段类型含义
person_idINT主键，唯一标识一个人
nameVARCHAR(30)名字
professionENUM职业
  • 职业范围：Doctor、Singer、Actor、Player、Engineer、Lawyer。
  • 输入为整张表，没有数组函数签名；输出列名为 person_id 与 name。
  • 公开题面没有给出行数或 ID 数值范围，不能自行补造。VARCHAR(30) 来自官方建表元数据。
  • 题面没有额外说明空值约定；主解保留 MySQL 原生空值行为，空值扩展在题解中说明。

来源说明：官方元数据题面为空，表结构与示例输入取自本轮官方 JSON；格式与排序要求结合公开题面转述。官方题目 · 公开题面参考。页面不复制完整原文。

05 / 独立题解

核心洞察：每行独立生成，再明确输出顺序

不需要关联其他表，也不需要分组。每个输入行只对应一个输出行：保留 ID，计算显示名字，最后按 ID 降序输出。

完整过程

  1. 从 Person 逐行读取 name 与 profession。
  2. 用 LEFT(profession, 1) 取职业第一个字母。职业枚举均为英文，首字母已是所需大写。
  3. 用 CONCAT(name, '(', 首字母, ')') 生成新 name，不加入空格。
  4. 投影 person_id 与新 name，使用 AS name 固定输出列名。
  5. ORDER BY person_id DESC 指定最终顺序。演示先变换再排序只是逻辑教学顺序，数据库可能优化执行顺序。

正确性说明

对任一合法输入行，LEFT 提取其职业首字母，CONCAT 将名字、左右括号和该字母按要求连接，因此该行输出的 name 正确。SELECT 没有过滤、连接、分组或去重，每行恰好保留一次且 ID 不变。ORDER BY 的降序比较满足所有相邻结果 ID 从大到小，故整个结果同时满足内容和顺序要求。

边界与空值

  • 空表输出空表，单行不需要改变顺序。
  • 相同名字可能属于不同的人，不能 DISTINCT name 或按名字分组。
  • 名字内已有空格应保留，不应 TRIM、拆词或改变大小写。
  • 题面没有为 NULL 规定额外显示格式。在 MySQL 中，name 或 profession 为 NULL 时，CONCAT 的结果为 NULL。不要擅自替换成空字符串。四语言参考也保留这个行为；职业非空时假设来自给定枚举。

复杂度

设 n 为人数，L 为所有生成字符串的总长度。字符串构造花费 O(L)；一般比较排序花费 O(n log n)，总计 O(L + n log n)。若数据库能反向扫描适用的主键索引，可省去单独排序，接近 O(n + L)。输出占 O(n + L)；排序工作空间取决于数据库执行计划，不能断言始终 O(1)。四语言版本复制并排序列表，另需 O(n) 级存储及输出字符串空间。

替代方案

MySQL 中可用 SUBSTRING(profession, 1, 1) 替代 LEFT。SQL Server 也有 CONCAT / LEFT；PostgreSQL 可用 || 与 LEFT，但不同数据库 CONCAT 对 NULL 的行为不完全相同。不要在 MySQL 默认模式里把 + 或 || 当成可移植字符串连接符。

提交代码与本地参考

优先提交下方 MySQL 查询。四语言代码仅模拟表到结果的映射，并非本题官方四语言提交签名；Python 这里也不是 pandas 提交版本。Java 使用 Java 17+ 的 record，C++ 使用 C++17 optional。

MySQL · 官方可提交语言

SELECT person_id,
       CONCAT(name, '(', LEFT(profession, 1), ')') AS name
FROM Person
ORDER BY person_id DESC;

Java · 本地语义参考

import java.util.*;

public class Main {
    record Person(int personId, String name, String profession) {}
    record Result(int personId, String name) {}

    static List<Result> concatenateInfo(List<Person> people) {
        List<Person> sorted = new ArrayList<>(people);
        sorted.sort(Comparator.comparingInt(Person::personId).reversed());
        List<Result> result = new ArrayList<>();
        for (Person p : sorted) {
            String name = p.name() == null || p.profession() == null
                ? null : p.name() + "(" + p.profession().substring(0, 1) + ")";
            result.add(new Result(p.personId(), name));
        }
        return result;
    }

    public static void main(String[] args) {
        var people = List.of(
            new Person(1, "Alex", "Singer"), new Person(3, "Alice", "Actor"),
            new Person(2, "Bob", "Player"), new Person(4, "Messi", "Doctor"),
            new Person(6, "Tyson", "Engineer"), new Person(5, "Meir", "Lawyer"));
        for (Result r : concatenateInfo(people))
            System.out.println(r.personId() + " | " + r.name());
    }
}

def concatenate_info(people):
    return [
        {"person_id": p["person_id"],
         "name": None if p["name"] is None or p["profession"] is None
         else f"{p['name']}({p['profession'][0]})"}
        for p in sorted(people, key=lambda p: p["person_id"], reverse=True)
    ]

if __name__ == "__main__":
    rows = [(1, "Alex", "Singer"), (3, "Alice", "Actor"),
            (2, "Bob", "Player"), (4, "Messi", "Doctor"),
            (6, "Tyson", "Engineer"), (5, "Meir", "Lawyer")]
    people = [dict(zip(("person_id", "name", "profession"), row))
              for row in rows]
    print(concatenate_info(people))

C++ · 本地语义参考

#include <algorithm>
#include <iostream>
#include <optional>
#include <string>
#include <vector>
using namespace std;

struct Person { int person_id; optional<string> name, profession; };
struct Result { int person_id; optional<string> name; };

vector<Result> concatenateInfo(vector<Person> people) {
    sort(people.begin(), people.end(), [](const Person& a, const Person& b) {
        return a.person_id > b.person_id;
    });
    vector<Result> result;
    for (const auto& p : people) {
        optional<string> name;
        if (p.name && p.profession)
            name = *p.name + "(" + p.profession->substr(0, 1) + ")";
        result.push_back({p.person_id, name});
    }
    return result;
}

int main() {
    vector<Person> people = {
        {1, "Alex", "Singer"}, {3, "Alice", "Actor"},
        {2, "Bob", "Player"}, {4, "Messi", "Doctor"},
        {6, "Tyson", "Engineer"}, {5, "Meir", "Lawyer"}
    };
    for (const auto& r : concatenateInfo(people))
        cout << r.person_id << " | " << r.name.value_or("NULL") << '\n';
}

常见错误

  • 漏掉 DESC，或错误地按 name / profession 排序。
  • 生成 Alex (S) 或 Alex(Singer)，插入了多余空格或整个职业。
  • 忘记输出 person_id，或忘记将计算列命名为 name。
  • 将 SUBSTRING 的 SQL 起始位置写成 0；MySQL 此处应从 1 开始。
  • 依赖输入展示顺序或主键天然有序；SQL 结果顺序必须显式指定。

面试追问

千万行如何优化？ 先看执行计划，确认主键索引是否支持所需扫描顺序；仍需生成并返回全部字符串。
如果职业改为任意文本？ 先定义空字符串、NULL、大小写与多字符文字的“首字母”规则，再选字符提取函数。
是否需要更新原表？ 不需要，题目要求查询结果，SELECT 的别名不会修改 Person.name。
