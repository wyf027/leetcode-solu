Merge Overlapping Events in the Same Hall

一张活动排期表。多个大厅。把属于同一段重叠日程的记录合并。

01 / PROBLEM

题意与数据契约

输入表 HallEvents 的每行是一场活动。在同一个大厅内，把有共同日期的活动合并；通过其他活动间接连在一起的活动，也属于同一合并区间。输出各区间的大厅、最早开始日和最晚结束日。

列名类型含义
hall_idINT大厅标识
start_dayDATE开始日期
end_dayDATE结束日期

约束与规则

  • 表可能有重复行，不能假定三列组合唯一。
  • 区间包含开始日和结束日；至少共享一天才重叠。
  • 结束于 01-14 和开始于 01-14 的两场重叠；开始于 01-15 则不重叠。
  • 不同大厅单独处理。结果可按任意顺序返回。
  • 公开题面未列出行数、日期范围的数值上限，不补造限制。代码以有效日期区间为前提；NULL 和反向日期未在题面定义。

题名、表结构及示例输入来自本地官方元数据。付费题面字段为空，语义参考 LeetCode Wiki 题面转录，本页以简要转述呈现。官方题目入口。

05 / SOLUTION

独立题解

准备好再展开：核心机制、正确性、SQL 与四语言参考。

核心洞察：此前所有活动的最远右端

每个大厅按开始日排序。当前开始日不晚于此前最大结束日，就还在同一重叠组；只有严格更晚才开启新组。必须看前缀最大值，不能只看上一条活动的结束日。

反例：[01-01, 01-10]、[01-02, 01-03]、[01-09, 01-12]。第三场虽不和第二场重叠，但与第一场相连。此前最远端是 01-10，三场应合为一场。

完整过程

  1. 按三列 DISTINCT 去重。相同活动不影响区间结果，去重后每个大厅内的两列排序键唯一。
  2. 按 hall_id 分区，再按 start_day、end_day 升序；计算“截至前一行”的 MAX(end_day)。
  3. 首行或 start_day > prev_max_end 时标记 1，否则标记 0。
  4. 对标记做前缀和，得到大厅内的 group_id。
  5. 按 hall_id 和 group_id 聚合，取 MIN(start_day)、MAX(end_day)。

正确性

不变量：处理排序前缀后，已有组分别对应互不重叠的连通日期区间，组的结束日是组内最大结束日。第一条独立成组，不变量成立。

若新活动开始日不晚于此前最远端，达到该端点的旧活动开始日也不晚于新活动开始日，因而它们共享这一天，可以合法归入当前组。若新活动开始日晚于此前最远端，所有旧活动都已结束，它与旧组之间存在断开，必须新建组；后续活动开始日更晚，也不可能弥补这个断开。更新最大结束日后不变量保持，最终合并没有遗漏，也没有错误地连接不同区间。

边界与常见错误

  • 结束日更新取 MAX；包含区间不能把已覆盖范围缩短。
  • 相等端点合并，隔日不合并，不能擅自给 end_day 加一天。
  • 所有窗口按大厅分区，最终分组也要包含大厅。
  • 前缀最大窗口必须排除当前行，否则有效区间总满足 start_day ≤ 自己的 end_day，新组标记会失真。
  • 本查询先去重，使用两列排序和显式 ROWS 窗口，避免重复行的并列顺序歧义。
  • 空表返回空表，单条及单日活动原样保留。NULL、反向日期需在业务中另行定义处理规则。

复杂度

设 n 为输入行数。常见执行计划中，去重及排序 O(n log n)，后续窗口扫描、聚合通常 O(n)，总体通常 O(n log n)。中间表与排序可能使用 O(n) 空间或落盘，实际以执行计划为准。四语言排序扫描版本时间 O(n log n)，复制输入和结果空间 O(n)。

替代方案

应用层直接排序扫描，维护最后一个合并区间，见四语言参考。递归 CTE 也能按行推进，但状态管理和递归深度更复杂。成对连接所有重叠活动再找连通分量，最多产生 O(n²) 条边；只做一次直接重叠聚合无法解决传递连接。

面试追问

  • 若相邻日期也合并？新组判断改为开始日晚于旧端点加一天，同时考虑最大日期溢出。
  • 若是半开区间 [start, end)？相等端点不再重叠，新组条件变为 ≥，并定义空区间行为。
  • 数据量很大如何优化？看 EXPLAIN，评估 (hall_id, start_day, end_day) 索引、去重成本和排序内存，不能保证索引必然消除窗口排序。
  • 是否支持流式合并？每个大厅按开始日有序时可以，否则需要缓冲或重新归并。

MySQL 8.0 · 官方可提交语言

WITH distinct_events AS (
    SELECT DISTINCT hall_id, start_day, end_day
    FROM HallEvents
), prefix_ends AS (
    SELECT *, MAX(end_day) OVER (
        PARTITION BY hall_id ORDER BY start_day, end_day
        ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING
    ) AS prev_max_end
    FROM distinct_events
), boundaries AS (
    SELECT *, CASE
        WHEN prev_max_end IS NULL OR start_day > prev_max_end THEN 1
        ELSE 0
    END AS is_new
    FROM prefix_ends
), numbered AS (
    SELECT *, SUM(is_new) OVER (
        PARTITION BY hall_id ORDER BY start_day, end_day
        ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
    ) AS group_id
    FROM boundaries
)
SELECT hall_id, MIN(start_day) AS start_day, MAX(end_day) AS end_day
FROM numbered
GROUP BY hall_id, group_id;

Java · 本地语义参考（Java 17+）

import java.time.LocalDate;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

public class Solution {
    public record Event(int hallId, LocalDate startDay, LocalDate endDay) {}

    // 日期非 null，且 startDay <= endDay；不修改输入。
    public static List<Event> mergeEvents(List<Event> hallEvents) {
        List<Event> rows = new ArrayList<>(hallEvents);
        rows.sort(Comparator.comparingInt(Event::hallId)
            .thenComparing(Event::startDay).thenComparing(Event::endDay));
        List<Event> result = new ArrayList<>();
        for (Event event : rows) {
            if (result.isEmpty()) {
                result.add(event);
                continue;
            }
            int i = result.size() - 1;
            Event last = result.get(i);
            if (last.hallId() != event.hallId()
                    || event.startDay().isAfter(last.endDay())) {
                result.add(event);
            } else if (event.endDay().isAfter(last.endDay())) {
                result.set(i, new Event(last.hallId(), last.startDay(), event.endDay()));
            }
        }
        return result;
    }
}

JavaScript · 本地语义参考

// 输入：[hall_id, "YYYY-MM-DD", "YYYY-MM-DD"][]。
// 前提：合法、补零的 ISO 日期，start_day <= end_day。
function mergeEvents(hallEvents) {
  const rows = hallEvents.map(row => [...row]).sort((a, b) =>
    a[0] - b[0] || a[1].localeCompare(b[1]) || a[2].localeCompare(b[2]));
  const result = [];
  for (const [hall, start, end] of rows) {
    const last = result[result.length - 1];
    if (!last || last[0] !== hall || start > last[2]) {
      result.push([hall, start, end]);
    } else if (end > last[2]) {
      last[2] = end;
    }
  }
  return result;
}

# 输入行：(hall_id, "YYYY-MM-DD", "YYYY-MM-DD")。
# 前提：合法、补零的 ISO 日期，start_day <= end_day。
# 此函数使用列表，不是本题 pandas 提交接口。
def merge_events(hall_events):
    result = []
    for hall, start, end in sorted(hall_events):
        if not result or result[-1][0] != hall or start > result[-1][2]:
            result.append([hall, start, end])
        else:
            result[-1][2] = max(result[-1][2], end)
    return result

#include <algorithm>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

// 前提：合法、补零的 ISO 日期，start_day <= end_day。
struct Event {
    int hall_id;
    string start_day, end_day;
};
vector<Event> mergeEvents(vector<Event> rows) {
    sort(rows.begin(), rows.end(), [](const Event& a, const Event& b) {
        return tie(a.hall_id, a.start_day, a.end_day)
             < tie(b.hall_id, b.start_day, b.end_day);
    });
    vector<Event> result;
    for (const auto& event : rows) {
        if (result.empty() || result.back().hall_id != event.hall_id
                || event.start_day > result.back().end_day) {
            result.push_back(event);
        } else {
            result.back().end_day = max(result.back().end_day, event.end_day);
        }
    }
    return result;
}
