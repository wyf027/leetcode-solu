按受欢迎程度
排列功能

把每条用户反馈看作一张独立选票：某个功能在同一条反馈里被重复提到，也只获得这一票。最终按得票数降序排列；平票时尊重原始顺序。

MEDIUM 会员题 数组哈希表字符串排序
01 · Problem

题目说明

函数：sortFeatures

给定字符串数组 features，其中每个元素都是一个产品功能的单词名称。另给定字符串数组 responses，每个元素是一条由空格分隔单词的用户反馈。

一个功能的受欢迎度，等于包含该功能完整单词的反馈条数。同一个功能即使在一条反馈中出现多次，也只计一次。请按受欢迎度从高到低排列所有功能；若受欢迎度相同，则保持它们在 features 中的原始先后顺序。

匹配口径：按空格切分后的完整单词匹配。因此 lock 不会匹配 locker，也不会匹配 cool。

官方函数形式

sortFeatures(features: string[], responses: string[]): string[]

约束

  • 1 ≤ features.length ≤ 10⁴
  • 1 ≤ features[i].length ≤ 10
  • features 中没有重复项
  • features[i] 只含小写英文字母
  • 1 ≤ responses.length ≤ 10²
  • 1 ≤ responses[i].length ≤ 10³
  • 反馈只含小写字母与空格
  • 反馈无连续空格，首尾也无空格
官方示例 1
输入：features = ["cooler","lock","touch"]
responses = ["i like cooler cooler",
             "lock touch cool",
             "locker like touch"]
输出：["touch","cooler","lock"]
touch 被 2 条反馈提到；cooler 与 lock 都是 1 条，平票时 cooler 的原始位置更靠前。
官方示例 2
输入：features = ["a","aa","b","c"]
responses = ["a","a aa","a a a a a","b a"]
输出：["a","aa","b","c"]
a 出现在 4 条反馈中，而不是按总出现次数计 8 次；aa 与 b 各 1 条，依原始顺序排列。

04 · Solution

哈希计票 + 稳定排序

01

每条反馈先去重

把反馈按空格拆词，并放入集合。集合让同一条反馈里的重复功能只保留一份，正好对应“一条反馈至多贡献一票”。

02

只统计候选功能

先把功能放入哈希映射。扫描每条反馈的不同单词时，仅当单词是候选功能才加一，空间上不必记录无关词。

03

排序键写完整

将功能与原索引绑定，比较器先按计数降序；计数相同则按原索引升序。这样无需依赖具体语言的排序稳定性。

04

映射回字符串

排序索引而非修改计数结构，最后按索引取回功能名称，即得到唯一符合规则的结果。

完整过程

  1. 建立 count，为每个 features[i] 初始化计数 0。
  2. 对每条 response：切分为单词集合 seen。
  3. 遍历 seen；若单词存在于 count，就把对应值加 1。
  4. 创建原索引数组 [0, 1, ..., n - 1]。
  5. 按 (-count[features[i]], i) 排序索引，再映射为功能名。

正确性证明

引理 1：处理完一条反馈后，每个功能的计数恰好在且仅在该反馈包含它时增加 1。因为集合保留该反馈中每个单词的一份，成员检查又排除了非功能词。

引理 2：处理完全部反馈后，count[f] 等于包含功能 f 的反馈条数。由引理 1 对所有反馈累加即可。

定理：比较器优先将计数更大的功能放前面；计数相等时将原索引更小者放前面。结合引理 2，输出同时满足受欢迎度降序与平票保持原顺序，因此算法正确。

复杂度与边界

设全部反馈的总字符数为 L，功能数为 n。分词与计票为 O(L)，排序为 O(n log n)，总时间 O(L + n log n)。

哈希计数占 O(n)；单条反馈的临时集合占 O(k)，其中 k 是该反馈的不同单词数；索引数组占 O(n)。

  • 所有功能均为 0 票：完整保留输入顺序。
  • 一条反馈重复同一功能：只加 1。
  • 前缀相同：a 与 aa 是两个完整单词。
  • 反馈出现未知单词：直接忽略。

替代方案与取舍

依赖稳定排序：直接对 features 按负计数排序，代码更短；但面试中要能说明语言的排序是否稳定。显式加入原索引更可移植。
桶排序：票数范围是 0..responses.length，可按票数建桶，把功能按原顺序放入桶，再从高票桶向低票桶输出，时间可到 O(L + n + m)，但实现更长。

面试追问

  • 若不区分大小写或要忽略标点？ 在分词边界统一正规化，再做集合去重；原题只含小写字母和空格，不需要额外处理。
  • 若功能名包含多个单词？ 单词集合不再够用，可用 Trie、Aho–Corasick 或短语索引匹配，并仍需对每条反馈去重。
  • 若响应流非常大？ 计数可增量维护；每条响应只保留当前去重集合，不必保存历史反馈。
  • 能否去掉排序的 log n？ 可以利用最大票数不超过响应数的性质做桶排序。

常见错误

  • 按功能在所有文本中的总出现次数计票，导致重复词被多算。
  • 用子串搜索，使 lock 错误匹配 locker。
  • 平票时按字典序，而不是按 features 原顺序。
  • 比较器只返回票数差，却错误假设所有语言、版本的排序都稳定。

JavaLeetCode 提交格式
import java.util.*;

class Solution {
    public String[] sortFeatures(String[] features, String[] responses) {
        Map<String, Integer> count = new HashMap<>();
        for (String feature : features) {
            count.put(feature, 0);
        }

        for (String response : responses) {
            Set<String> seen = new HashSet<>(Arrays.asList(response.split(" ")));
            for (String word : seen) {
                if (count.containsKey(word)) {
                    count.put(word, count.get(word) + 1);
                }
            }
        }

        Integer[] order = new Integer[features.length];
        for (int i = 0; i < features.length; i++) {
            order[i] = i;
        }

        Arrays.sort(order, (a, b) -> {
            int byPopularity = Integer.compare(
                count.get(features[b]), count.get(features[a])
            );
            return byPopularity != 0 ? byPopularity : Integer.compare(a, b);
        });

        String[] answer = new String[features.length];
        for (int i = 0; i < order.length; i++) {
            answer[i] = features[order[i]];
        }
        return answer;
    }
}
JavaScriptLeetCode 提交格式
/**
 * @param {string[]} features
 * @param {string[]} responses
 * @return {string[]}
 */
var sortFeatures = function(features, responses) {
  const count = new Map(features.map(feature => [feature, 0]));

  for (const response of responses) {
    const seen = new Set(response.split(" "));
    for (const word of seen) {
      if (count.has(word)) {
        count.set(word, count.get(word) + 1);
      }
    }
  }

  return features
    .map((feature, index) => ({ feature, index }))
    .sort((a, b) =>
      count.get(b.feature) - count.get(a.feature) || a.index - b.index
    )
    .map(item => item.feature);
};
PythonLeetCode 提交格式
from typing import List


class Solution:
    def sortFeatures(
        self, features: List[str], responses: List[str]
    ) -> List[str]:
        count = {feature: 0 for feature in features}

        for response in responses:
            for word in set(response.split(" ")):
                if word in count:
                    count[word] += 1

        order = list(range(len(features)))
        order.sort(key=lambda i: (-count[features[i]], i))
        return [features[i] for i in order]
C++LeetCode 提交格式
#include <algorithm>
#include <numeric>
#include <sstream>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> sortFeatures(
        vector<string>& features,
        vector<string>& responses
    ) {
        unordered_map<string, int> count;
        for (const string& feature : features) {
            count[feature] = 0;
        }

        for (const string& response : responses) {
            istringstream input(response);
            unordered_set<string> seen;
            string word;
            while (input >> word) {
                seen.insert(word);
            }
            for (const string& candidate : seen) {
                auto it = count.find(candidate);
                if (it != count.end()) {
                    ++it->second;
                }
            }
        }

        vector<int> order(features.size());
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int a, int b) {
            if (count[features[a]] != count[features[b]]) {
                return count[features[a]] > count[features[b]];
            }
            return a < b;
        });

        vector<string> answer;
        answer.reserve(features.size());
        for (int index : order) {
            answer.push_back(features[index]);
        }
        return answer;
    }
};
