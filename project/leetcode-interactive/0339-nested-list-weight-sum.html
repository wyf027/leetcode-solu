Problem

让深度成为整数的权重

给定一个由整数或嵌套列表构成的列表 nestedList。顶层整数的深度为 1，进入一层子列表后深度加 1。请返回每个整数乘以其深度后的总和。

Example 01
输入：nestedList = [[1,1],2,[1,1]]
输出：10
解释：四个 1 位于深度 2，一个 2 位于深度 1，
      因此 4 × (1 × 2) + 2 × 1 = 10。
Example 02
输入：nestedList = [1,[4,[6]]]
输出：27
解释：1 × 1 + 4 × 2 + 6 × 3 = 27。
Example 03
输入：nestedList = [0]
输出：0
解释：唯一整数为 0，0 × 1 = 0。

函数参数形式

depthSum(nestedList: List<NestedInteger>) -> int

NestedInteger 由平台提供，可判断当前元素是单个整数还是子列表，并读取相应值。

约束

  • 1 ≤ nestedList.length ≤ 50
  • 嵌套列表中的整数值位于 [-100, 100]
  • 任意整数的最大深度不超过 50

Complete Solution

深度优先遍历：携带深度进入下一层

核心洞察

每个整数的贡献只由两个量决定：整数值和它所在的深度。遍历嵌套结构时，把当前深度作为状态一同传递：遇到整数就累加 value × depth；遇到列表就以 depth + 1 继续遍历。

完整过程

  1. 从顶层列表和深度 1 开始。
  2. 依次查看列表中的每个 NestedInteger。
  3. 若它是整数，将 getInteger() × depth 加入答案。
  4. 若它是子列表，递归处理 getList()，并将深度增加为 depth + 1。
  5. 所有分支处理完成后返回累计和。

正确性证明

引理：调用 dfs(list, d) 会返回该列表内所有整数按其真实深度加权后的和，其中该列表直接包含的整数深度为 d。
证明：对列表结构归纳。直接整数被加入 value × d，与定义一致；对子列表调用 dfs(child, d + 1)，由归纳假设，它会正确计算子列表中的全部整数。各元素互不遗漏且不重复，求和后即为当前列表的正确加权和。
结论：顶层调用 dfs(nestedList, 1)，因此返回所有整数以题目规定深度为权重的总和，算法正确。

复杂度

设嵌套结构中整数与列表节点总数为 N，最大深度为 D。

  • 时间：O(N)
  • 递归额外空间：O(D)

边界情况

  • 单个整数或零值，如 [0]
  • 负数会贡献负的加权值
  • 空的内部列表贡献为 0
  • 深度很大的链式嵌套

替代方案：广度优先遍历

也可以逐层使用队列：第一层深度为 1，每处理完一层就让深度加 1。它同样访问每个节点一次，时间为 O(N)；队列空间取决于最宽一层。DFS 代码通常更短，BFS 则天然按层组织。
