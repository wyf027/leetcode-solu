有效单词计数

把 chunks 连成字符流：只有字母，或两侧均为字母的连字符，才能留在同一个完整单词里。

题面示例：chunks = ["hello wor", "ld hello"]，queries = ["hello", "world", "wor"]。

题意

拼接所有片段为 s。单词是极大的合法子串：由小写字母组成，连字符 - 只在左右都是小写字母时可连接。其他字符均为分隔符。返回每个查询作为完整单词的次数。

片段边界不是词边界："wor" + "ld" 必须组成 world。

题解：单趟有限状态扫描

核心洞察：无需按 chunks 分别处理。先拼接，或跨片段维护相同状态；每个位置用前后字符判断 - 是否合法。遇到分隔符就提交正在累积的单词。

完整过程

  1. 令 isLetter(c) 判断小写字母。
  2. 遍历 s：字母直接加入；连字符仅当相邻两端均为字母时加入。
  3. 否则为分隔符，若缓冲非空就计入哈希表并清空。
  4. 循环结束提交末尾缓冲，再按 queries 读取计数。

边界

  • 开头/结尾连字符没有完整两侧，必为分隔符。
  • 相邻两个连字符均不能连接。
  • 片段边界前后两个字母仍属同一单词。

复杂度

所有片段总长度 N、查询总长度 Q：时间 O(N + Q)，空间为不同单词的哈希表。

替代方案

若不能整体拼接，可在遍历 chunks 时保留上一个字符和当前词缓冲，实现同一状态机。数据流无限长时也无需保存整个 s。

常见错误

  • 把任意连字符都加入单词。
  • 在 chunks 边界强行提交单词。
  • 忘记循环结束后提交末尾缓冲。
