LCR 090 · MEDIUM

打家劫舍 II

房屋围成一圈，不能偷相邻两间。求能偷到的最高金额。

题意与示例

nums = [2,3,2]
输出 = 3
首尾相邻，不能同时选择 2。

约束

  • 1 ≤ nums.length ≤ 100
  • 0 ≤ nums[i] ≤ 1000
  • 首尾也是相邻房屋。

分步交互：拆成两条直线

环形的关键是：要么不选第一间，要么不选最后一间。分别对两段线性数组做打家劫舍。

洞察与过程

  1. 长度为 1 时直接返回。
  2. 计算 [0,n-2] 的最佳收益。
  3. 计算 [1,n-1] 的最佳收益。
  4. 返回两者最大值；线性转移为 max(prev1, prev2+x)。

边界、复杂度、替代

单屋是特例；两屋取较大值。时间 O(n)，空间 O(1)。也可用 DP 数组，逻辑直观但空间 O(n)。
