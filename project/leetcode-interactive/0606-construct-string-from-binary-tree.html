Problem 606

根据二叉树创建字符串

Construct String from Binary Tree

读懂括号的取舍规则，在不丢失树结构的前提下，把一次前序遍历压缩成唯一字符串。

Problem statement

题意

给定二叉树根节点 root，按照前序遍历的顺序，把每个节点的整数值写入字符串；子树内容放在紧跟父节点值的括号中。

应省略所有不会影响“字符串与原树一一对应”的空括号。唯一必须保留空括号的情况是：某个节点没有左孩子、但有右孩子，此时要先写 ()，否则无法判断后面的子树位于左侧还是右侧。

括号速记： 无孩子不写；只有左孩子写左；有右孩子时，左侧括号一定要占位。

函数与约束

参数 root: TreeNode
返回 string
  • 树中节点数在 [1, 10⁴] 范围内。
  • -1000 ≤ Node.val ≤ 1000。

Example 01

输入root = [1,2,3,4]
输出"1(2(4))(3)"

完整形式中的叶子空括号都可省略，保留左右子树的必要括号即可。

Example 02

输入root = [1,2,3,null,4]
输出"1(2()(4))(3)"

节点 2 只有右孩子 4，因此必须保留左侧的 () 占位。

核心洞察

前序遍历天然满足“父节点值先出现，再处理左、右子树”的输出顺序。真正需要决策的不是遍历顺序，而是三种子树形态对应的括号规则：

  • 左右都空：只返回节点值。
  • 只有左子树：返回 值(左)。
  • 存在右子树：无论左子树是否存在，都返回 值(左)(右)；左空时自然产生 ()。

完整过程

  1. 把当前节点值转成字符串，作为当前结果。
  2. 如果当前节点没有任何孩子，立即返回。
  3. 只要存在左孩子或右孩子，就追加一对左子树括号；左孩子为空时括号内容为空。
  4. 若右孩子存在，再递归构造右子树并包入第二对括号。
  5. 递归返回时，各子树字符串已按相同规则完成，直接拼接即可。

正确性证明

命题：递归函数对任意节点都返回与其子树一一对应、且省略了所有可省略空括号的前序字符串。

基础情形：叶子节点没有子树，函数只输出节点值。这既是前序表示，也不存在需要保留的空括号。

归纳步骤：假设函数能正确构造当前节点左右子树。当前节点先输出自身值；有左子树时把其正确表示放入第一对括号；没有左子树但有右子树时保留空的第一对括号，从而标明右子树方向；有右子树时把其正确表示放入第二对括号。若右子树不存在，则第二对空括号不会提供额外结构信息，故省略。于是顺序、结构唯一性与最简括号规则都成立。

由结构归纳，命题对整棵树成立。

边界与复杂度

  • 单节点：直接返回数值文本，不带括号。
  • 负数：整数转字符串即可，负号不改变结构。
  • 仅右孩子：必须产生左侧 ()。
  • 退化链：递归深度最坏达到节点数。

时间复杂度：O(n)，每个节点访问一次；在可变字符串构造器或等价实现下，输出拼接总量与答案长度同阶。

空间复杂度：O(h) 递归栈，其中 h 为树高；最坏 O(n)，平衡树为 O(log n)。返回字符串本身占 O(n)。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public String tree2str(TreeNode root) {
        StringBuilder result = new StringBuilder();
        build(root, result);
        return result.toString();
    }

    private void build(TreeNode node, StringBuilder result) {
        result.append(node.val);

        if (node.left == null && node.right == null) {
            return;
        }

        result.append('(');
        if (node.left != null) {
            build(node.left, result);
        }
        result.append(')');

        if (node.right != null) {
            result.append('(');
            build(node.right, result);
            result.append(')');
        }
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {string}
 */
var tree2str = function(root) {
    const parts = [];

    const build = (node) => {
        parts.push(String(node.val));

        if (node.left === null && node.right === null) {
            return;
        }

        parts.push("(");
        if (node.left !== null) {
            build(node.left);
        }
        parts.push(")");

        if (node.right !== null) {
            parts.push("(");
            build(node.right);
            parts.push(")");
        }
    };

    build(root);
    return parts.join("");
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def tree2str(self, root: Optional[TreeNode]) -> str:
        def build(node: TreeNode) -> str:
            value = str(node.val)

            if node.left is None and node.right is None:
                return value

            left = build(node.left) if node.left is not None else ""
            result = value + "(" + left + ")"

            if node.right is not None:
                result += "(" + build(node.right) + ")"

            return result

        return build(root)
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    string tree2str(TreeNode* root) {
        string result;
        build(root, result);
        return result;
    }

private:
    void build(TreeNode* node, string& result) {
        result += to_string(node->val);

        if (node->left == nullptr && node->right == nullptr) {
            return;
        }

        result += '(';
        if (node->left != nullptr) {
            build(node->left, result);
        }
        result += ')';

        if (node->right != nullptr) {
            result += '(';
            build(node->right, result);
            result += ')';
        }
    }
};

替代方案

可以显式维护栈和“进入/离开节点”状态，用迭代方式模拟递归。这能规避极深树上的语言递归栈限制，但状态机更复杂：必须在正确时机写左右括号，并区分首次访问与回溯。

另一种写法是先生成包含所有空节点的完整表示，再删除冗余括号；它会制造额外中间内容，而且删除规则容易误伤“只有右孩子”所需的占位，不如在构造时直接决定。

常见错误

  • 无条件省略空左子树，导致 1()(2) 错写为 1(2)，结构含义改变。
  • 给每个叶子都输出 ()()，虽可描述树，却不满足省略冗余括号的要求。
  • 先处理右子树再处理左子树，破坏前序与左右顺序。
  • 在 JavaScript 或 Python 中反复拼接超长不可变字符串，可能产生额外复制；可用片段数组或构造器。
  • 忽视最多 10⁴ 个节点时的递归深度风险。

一句话模板

值 + 必要的 (左) + 存在时的 (右)

“必要的左括号”指：只要至少有一个孩子就输出；当右孩子存在而左孩子为空时，它恰好成为不可省略的 ()。
