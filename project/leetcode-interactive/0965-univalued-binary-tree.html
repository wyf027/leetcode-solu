单值二叉树

Univalued Binary Tree —— 沿树遍历，把每个节点与根节点的值对照；一次不一致，就足以推翻结论。

1–100节点数量
0–99节点取值
DFS主解方法
O(n)访问全部节点
1

题目

若一棵二叉树中的每个节点都拥有相同的值，则称它为单值二叉树。给定二叉树根节点 root，判断整棵树是否为单值二叉树：是则返回 true，否则返回 false。

示例 1
输入：root = [1,1,1,1,1,null,1] 输出：true
示例 2
输入：root = [2,2,2,5,2] 输出：false

约束

  • 树中节点数在 [1, 100] 内。
  • 0 <= Node.val < 100。
2

完整题解

核心洞察

“全都相同”需要一个固定参照。根节点天然提供基准值；遍历过程中，任何节点一旦与它不同即可立即返回 false。

算法选择

用 DFS 递归访问节点。空子树不产生冲突；当前节点相等且左右子树都合格，整棵树才合格。

完整过程

  1. 记录 target = root.val。
  2. 递归检查当前节点；空节点返回 true。
  3. 若 node.val != target，立即返回 false。
  4. 对左右子树递归，并取逻辑与。

正确性

DFS 会覆盖树中每个可达节点。若返回 true，每个访问节点都等于根值，故全树单值；若存在不同值，访问该节点时必返回 false。因此结果充分且必要。

边界与复杂度

  • 单节点树必为单值树。
  • 缺失左/右孩子不会影响结论。
  • 时间：O(n)；递归栈：O(h)，最坏 O(n)。

替代方案

BFS 可用队列逐层比较，时间同为 O(n)，额外空间为树的最大层宽。也可只比较父子值，但仍须覆盖全部边。

面试追问

  • 若树极深，如何改成显式栈避免调用栈溢出？
  • 如何返回第一个不一致节点，而非布尔值？
  • 若节点流式到达，怎样尽早失败？

常见错误

  • 只比较根的两个孩子，漏掉更深节点。
  • 左右子树结果误用逻辑或。
  • 改变基准值，导致不同分支各自“局部相同”。

四语言完整代码

Java递归 DFS
class Solution {
    public boolean isUnivalTree(TreeNode root) {
        return dfs(root, root.val);
    }

    private boolean dfs(TreeNode node, int target) {
        if (node == null) return true;
        if (node.val != target) return false;
        return dfs(node.left, target) && dfs(node.right, target);
    }
}
JavaScript递归 DFS
/**
 * @param {TreeNode} root
 * @return {boolean}
 */
var isUnivalTree = function(root) {
    const target = root.val;
    const dfs = (node) => {
        if (node === null) return true;
        if (node.val !== target) return false;
        return dfs(node.left) && dfs(node.right);
    };
    return dfs(root);
};
Python递归 DFS
class Solution:
    def isUnivalTree(self, root: Optional[TreeNode]) -> bool:
        target = root.val

        def dfs(node: Optional[TreeNode]) -> bool:
            if node is None:
                return True
            if node.val != target:
                return False
            return dfs(node.left) and dfs(node.right)

        return dfs(root)
C++递归 DFS
class Solution {
public:
    bool isUnivalTree(TreeNode* root) {
        return dfs(root, root->val);
    }

private:
    bool dfs(TreeNode* node, int target) {
        if (node == nullptr) return true;
        if (node->val != target) return false;
        return dfs(node->left, target) &&
               dfs(node->right, target);
    }
};
