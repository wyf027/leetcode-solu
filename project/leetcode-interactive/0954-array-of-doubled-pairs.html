二倍数对数组

Array of Doubled Pairs — 判断一组正负交织、可能含零的整数，能否被完整拆成若干个 (x, 2x) 数对。

题目

给定一个长度为偶数的整数数组 arr。你可以任意重排它。若能让每个偶数下标上的数 arr[2*i] 与紧随其后的数满足 arr[2*i+1] = 2 * arr[2*i]，返回 true；否则返回 false。

函数形式： boolean canReorderDoubled(int[] arr)（不同语言使用对应数组与布尔类型）。数组中的每个元素必须恰好使用一次。

官方示例

输入：arr = [3,1,3,6]

输出：false

输入：arr = [2,1,2,6]

输出：false

输入：arr = [4,-2,2,-4]

输出：true

可组成数对 (-2,-4) 与 (2,4)。

约束

  • 2 <= arr.length <= 3 * 10^4
  • arr.length 为偶数
  • -10^5 <= arr[i] <= 10^5

题解

核心洞察：总是先处理绝对值最小的尚未配对元素 x，它只能去匹配 2x；使用频次表完成消耗。

完整过程

统计每个值出现次数，得到频次表 count。
复制数组并按 |x| 升序排序。相同绝对值的先后不影响结果。
依次访问 x。若它已被前面的配对消耗（频次为 0），直接跳过。
若 count[2x] == 0，说明无法为当前 x 找到伙伴，立即返回 false。
否则同时减少 x 与 2x 的频次。遍历结束返回 true。

为什么正确

贪心选择：设 x 是剩余元素中绝对值最小者。若存在合法配对，它不能充当某个更小绝对值元素的二倍值，因为那样的元素已被优先处理；因此当前可安全地把 x 作为数对前项，并且它的伙伴只能是 2x。

归纳：若 2x 不存在，任何重排都无法安置 x。若存在，移除 (x,2x) 后，剩余问题仍是同类问题。不断应用此选择，成功耗尽即得到合法划分。

负数关键：例如 -2 应匹配 -4。按普通升序会先处理 -4 并错误寻找 -8，所以必须按绝对值排序。

复杂度

  • 时间：O(n log n)，排序占主导。
  • 空间：O(n)，频次表与排序副本。

边界情况

  • 零只能与零配对，因此零的数量必须为偶数；通用流程会自然处理。
  • 重复值必须按频次逐个消耗。
  • 负数的二倍仍是负数，不能改成匹配绝对值。
  • 题目数值范围内二倍值安全；其他环境需留意整数溢出。

替代方案

利用值域上限可使用计数数组，并按绝对值枚举整个值域，将排序成本降为与值域相关的线性扫描；但实现更繁琐、泛化性较弱。也可分别处理负数与非负数，本质仍是在保证“小绝对值先行”。

面试追问与常见错误

  • 追问：能否不用排序？值域有限时怎样做？
  • 追问：为什么零不会被一次错误地减两遍？
  • 错误：按数值升序，负数顺序错误。
  • 错误：只检查存在性，不消耗频次。
  • 错误：尝试让偶数优先匹配一半，遇到多种角色时容易冲突。

class Solution {
    public boolean canReorderDoubled(int[] arr) {
        java.util.Map<Integer, Integer> count = new java.util.HashMap<>();
        for (int x : arr) count.put(x, count.getOrDefault(x, 0) + 1);

        Integer[] order = java.util.Arrays.stream(arr).boxed().toArray(Integer[]::new);
        java.util.Arrays.sort(order, java.util.Comparator.comparingInt(Math::abs));

        for (int x : order) {
            if (count.getOrDefault(x, 0) == 0) continue;
            int doubled = x * 2;
            if (count.getOrDefault(doubled, 0) == 0) return false;
            count.put(x, count.get(x) - 1);
            count.put(doubled, count.get(doubled) - 1);
        }
        return true;
    }
}

var canReorderDoubled = function(arr) {
    const count = new Map();
    for (const x of arr) count.set(x, (count.get(x) || 0) + 1);
    const order = [...arr].sort((a, b) => Math.abs(a) - Math.abs(b));

    for (const x of order) {
        if ((count.get(x) || 0) === 0) continue;
        const doubled = x * 2;
        if ((count.get(doubled) || 0) === 0) return false;
        count.set(x, count.get(x) - 1);
        count.set(doubled, count.get(doubled) - 1);
    }
    return true;
};
from collections import Counter
from typing import List

class Solution:
    def canReorderDoubled(self, arr: List[int]) -> bool:
        count = Counter(arr)
        for x in sorted(arr, key=abs):
            if count[x] == 0:
                continue
            if count[2 * x] == 0:
                return False
            count[x] -= 1
            count[2 * x] -= 1
        return True

public:
    bool canReorderDoubled(vector<int>& arr) {

        for (int x : arr) ++count[x];
        sort(arr.begin(), arr.end(), [](int a, int b) {
            return abs(a) < abs(b);
        });
        for (int x : arr) {
            if (count[x] == 0) continue;
            if (count[2 * x] == 0) return false;
            --count[x];
            --count[2 * x];
        }
        return true;
    }
