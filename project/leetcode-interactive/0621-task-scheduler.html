LEETCODE 621 任务调度器

Task Scheduler · 把任务放入离散的 CPU 周期，在冷却限制下找出完成全部任务所需的最少周期数。

题目转述

给定一个由大写字母 A–Z 表示的任务数组 tasks，以及非负整数 n。每个 CPU 周期可以执行一个任务，也可以空闲；任务顺序可自由安排，但两次执行同一种任务之间至少要隔开 n 个完整周期。

返回执行完所有任务需要的最少 CPU 周期数。函数签名：leastInterval(tasks, n) → integer。

官方示例与约束

先把输入、冷却间隔和目标结果读准确；调度顺序可能不唯一，但最短周期数唯一。

1 输出 8
tasks = ["A","A","A","B","B","B"], n = 2

一种安排是 A → B → idle → A → B → idle → A → B；相同任务之间隔开两个周期。

2 输出 6
tasks = ["A","C","A","B","D","B"], n = 1

一种安排是 A → B → C → D → A → B。现有任务足以填满间隔，因此不必空闲。

3 输出 10
tasks = ["A","A","A","B","B","B"], n = 3

一种安排是 A → B → idle → idle → A → B → idle → idle → A → B。

约束
  • 1 ≤ tasks.length ≤ 10⁴
  • tasks[i] ∈ {A … Z}
  • 0 ≤ n ≤ 100
  • 每个周期至多完成一个任务

准备好看题解了吗？

建议先在上方实验室改变任务频率和冷却时间，观察什么时候必须出现 idle，再展开完整推导。

Greedy Counting

用最高频任务搭骨架

max(T, (f − 1)(n + 1) + m)

核心洞察

最频繁的任务最难安排。设任务总数为 T，最高频次为 f，达到最高频次的任务种类数为 m。先把这些最高频任务看作调度骨架。

前 f − 1 组都必须至少占 n + 1 个位置；最后一组只需放下并列最高频的 m 个任务。

完整过程

  1. 统计 26 个大写字母的频次。
  2. 找出最高频次 f。
  3. 统计有多少种任务的频次等于 f，记为 m。
  4. 骨架长度为 (f − 1)(n + 1) + m。
  5. 返回骨架长度与任务总数 T 的较大值。

为什么取最大值

当其他任务不足以填满最高频任务之间的冷却空位时，骨架中的空位只能由 idle 占据，答案就是骨架长度。若其他任务足够多，它们不仅填满空位，还会把调度继续向后延伸；此时所有周期都在执行任务，答案就是任务总数 T。

正确性说明

  1. 下界：任取一个最高频任务，它的前 f − 1 次出现后都需要至少 n 个间隔；并列最高频的 m 种任务共同占据最后一列，因此任何合法调度都不少于骨架长度。
  2. 可达：把最高频任务分布到各组，再用其余任务逐组填空。填不满的位置用 idle；填满后多出的任务接着排，不会让总长度超过 T。
  3. 同时任何调度至少包含全部 T 个任务，所以两种下界的最大值既是下界也可构造达到，即为最优答案。

边界与复杂度

  • n = 0：无需冷却，结果就是 tasks.length。
  • 所有任务不同：最高频次为 1，结果仍为任务总数。
  • 只有一种任务：答案为 (T − 1)(n + 1) + 1。
  • 时间复杂度 O(T + 26)，额外空间 O(26)，均可写作 O(T) 与 O(1)。

替代方案

可用最大堆维护当前可执行任务的剩余频次，再用冷却队列记录释放时间，逐周期模拟调度。它更容易恢复一条具体序列，也能扩展到不同任务拥有不同冷却时间；本题仅求最短长度时，计数公式更简洁，复杂度也更低。

面试追问

  • 若要返回一条实际调度序列，如何用堆与队列构造？
  • 若每种任务的冷却时间不同，公式为何失效？
  • 若多个 CPU 可并行执行，状态与下界如何变化？
  • 如何证明并列最高频任务要计入最后一组的宽度？

常见错误

  • 只考虑一个最高频任务，漏掉多个任务并列最高频时的 m。
  • 直接返回骨架长度，忘记其他任务很多时答案至少为 T。
  • 把“间隔至少为 n”误写成相同任务起始位置相差 n；正确的位置差至少是 n + 1。
  • 模拟时提前释放冷却任务，或在同一周期既释放又错误地执行两项任务。

四种语言完整实现

Java官方可提交签名
class Solution {
    public int leastInterval(char[] tasks, int n) {
        int[] count = new int[26];
        for (char task : tasks) {
            count[task - 'A']++;
        }

        int maxFrequency = 0;
        for (int frequency : count) {
            maxFrequency = Math.max(maxFrequency, frequency);
        }

        int maxCount = 0;
        for (int frequency : count) {
            if (frequency == maxFrequency) {
                maxCount++;
            }
        }

        int frameLength =
            (maxFrequency - 1) * (n + 1) + maxCount;
        return Math.max(tasks.length, frameLength);
    }
}

var leastInterval = function(tasks, n) {
    const count = new Array(26).fill(0);
    for (const task of tasks) {
        count[task.charCodeAt(0) - 65]++;
    }

    const maxFrequency = Math.max(...count);
    let maxCount = 0;
    for (const frequency of count) {
        if (frequency === maxFrequency) {
            maxCount++;
        }
    }

    const frameLength =
        (maxFrequency - 1) * (n + 1) + maxCount;
    return Math.max(tasks.length, frameLength);
};
Python 3官方可提交签名
from typing import List


class Solution:
    def leastInterval(self, tasks: List[str], n: int) -> int:
        count = [0] * 26
        for task in tasks:
            count[ord(task) - ord("A")] += 1

        max_frequency = max(count)
        max_count = sum(
            frequency == max_frequency for frequency in count
        )

        frame_length = (
            (max_frequency - 1) * (n + 1) + max_count
        )
        return max(len(tasks), frame_length)
C++官方可提交签名
class Solution {
public:
    int leastInterval(vector<char>& tasks, int n) {
        vector<int> count(26, 0);
        for (char task : tasks) {
            count[task - 'A']++;
        }

        int maxFrequency =
            *max_element(count.begin(), count.end());
        int maxCount = 0;
        for (int frequency : count) {
            if (frequency == maxFrequency) {
                maxCount++;
            }
        }

        int frameLength =
            (maxFrequency - 1) * (n + 1) + maxCount;
        return max(static_cast<int>(tasks.size()), frameLength);
    }
};
