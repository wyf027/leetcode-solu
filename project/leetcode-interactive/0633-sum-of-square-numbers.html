Solution

双指针夹逼

时间O(√c) 空间O(1)

核心洞察

只考虑非负且 a <= b 的组合即可。令 a = 0，b = floor(√c)。当前和偏小时增大 a；偏大时减小 b。两者单调变化，不会回头。

为什么从 √c 开始？

任何平方项都不能超过 c，所以绝对值最多为 floor(√c)。平方不受正负号影响，因此只枚举非负值。

完整过程

  1. 初始化 a = 0、b = floor(√c)。
  2. 当 a <= b 时，计算 sum = a² + b²。
  3. 若 sum == c，已经找到数对，返回 true。
  4. 若 sum < c，固定当前 a 时，再小的 b 只会让和更小，因此令 a++。
  5. 若 sum > c，固定当前 b 时，再大的 a 只会让和更大，因此令 b--。
  6. 若两指针交错仍未相等，返回 false。

正确性说明

把候选数对规范为 0 <= a <= b <= floor(√c)。当当前和小于 c 时，对这个 a 而言，所有不超过当前 b 的候选都会更小，所以删除这一行是安全的；当当前和大于 c 时，对这个 b 而言，所有不小于当前 a 的候选都会更大，所以删除这一列也是安全的。每一步都只排除不可能的候选；若遇到相等就得到解，若指针交错则所有候选均已排除，故算法正确。

边界情况

  • c = 0：0² + 0² = 0，返回 true。
  • 完整平方数：可以由 0² + b² 表示。
  • a = b：循环条件必须包含等号。
  • 上界输入：Java/C++ 计算平方和要使用 64 位整数。

复杂度

a 最多增加 √c 次，b 最多减少 √c 次，因此时间复杂度为 O(√c)。只维护常数个变量，空间复杂度为 O(1)。

四语言完整实现

使用方向键左右切换标签；代码区可独立横向、纵向滚动。

Solution.java64 位计算平方和
class Solution {
    public boolean judgeSquareSum(int c) {
        long left = 0;
        long right = (long) Math.sqrt(c);

        while (left <= right) {
            long sum = left * left + right * right;
            if (sum == c) {
                return true;
            }
            if (sum < c) {
                left++;
            } else {
                right--;
            }
        }
        return false;
    }
}

var judgeSquareSum = function(c) {
    let left = 0;
    let right = Math.floor(Math.sqrt(c));

    while (left <= right) {
        const sum = left * left + right * right;
        if (sum === c) {
            return true;
        }
        if (sum < c) {
            left += 1;
        } else {
            right -= 1;
        }
    }
    return false;
};

    bool judgeSquareSum(int c) {
        long long left = 0;
        long long right = static_cast<long long>(sqrt(c));

        while (left <= right) {
            long long sum = left * left + right * right;
            if (sum == c) {
                return true;
            }
            if (sum < c) {
                ++left;
            } else {
                --right;
            }
        }
        return false;
    }

替代方案

枚举 + 整数判方

枚举 a，再判断 c - a² 是否为完整平方数。时间 O(√c)，实现直观；要谨慎处理浮点误差。

枚举 + 二分查找

对每个 a，在区间中二分寻找 b。时间 O(√c log c)，不如双指针紧凑，但适合讨论二分边界。

费马平方和定理

若质因数分解中每个形如 4k + 3 的质因子指数均为偶数，则可表示。理论漂亮，分解实现更复杂。

面试追问与常见错误

追问：为什么允许忽略负数？

因为平方后符号消失。若负数解存在，取其绝对值仍是同一个平方和。

追问：能否返回具体数对？

可以。相等时返回当前 [a, b]；遍历结束返回空值即可，复杂度不变。

错误：使用 32 位平方和

两个接近 √c 的平方相加可能超过有符号 32 位上限。Java/C++ 应先提升到 64 位。

错误：循环写成 a < b

这会漏掉 a = b 的答案，例如 c = 2。

错误：无条件调整两端

每轮只能根据当前和调整一端；同时移动会跨过尚未排除的候选。

错误：直接比较浮点平方根

用 sqrt(x) == floor(sqrt(x)) 时要关注精度。这里的双指针只用整数平方和比较。
