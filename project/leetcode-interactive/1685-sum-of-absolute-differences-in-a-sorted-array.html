有序数组中
差绝对值之和Sum of Absolute Differences in a Sorted Array

给定一个非递减有序整数数组 nums。返回同长度数组 result，其中 result[i] 是 nums[i] 与数组所有元素之差的绝对值总和。

输入integer[] nums
输出integer[]
排序非递减
付费限制无

01 / Problem

题意与示例

示例 1

基础拆解
输入：nums = [2,3,5]
输出：[4,3,5]
解释：
result[0] = |2-2| + |2-3| + |2-5| = 4
result[1] = |3-2| + |3-3| + |3-5| = 3
result[2] = |5-2| + |5-3| + |5-5| = 5

示例 2

完整参数
输入：nums = [1,4,6,8,10]
输出：[24,15,13,15,21]

约束

  • 2 <= nums.length <= 105
  • 1 <= nums[i] <= nums[i + 1] <= 104
  • 下标从 0 开始；求和可包含 j = i，因为这一项恒为 0。

03 / Solution

准备好查看线性解法了吗？

下面的内容包含核心推导、正确性证明和完整代码，默认保持收起。

Core insight

排序消掉绝对值，前缀和消掉重复求和

固定位置 i。左边元素都不大于 nums[i]，所以每项绝对差可写成 nums[i] - nums[j]；右边则写成 nums[j] - nums[i]。

left = nums[i] × i − prefix right = (total − prefix − nums[i]) − nums[i] × (n − i − 1) result[i] = left + right
关键状态：prefix 始终表示下标 i 之前所有元素的和。每次算完当前位置，再把 nums[i] 加进去。

Walkthrough

以 [1,4,6,8,10] 的 i = 2 为例

  1. nums[i] = 6，左边有 2 项，prefix = 1 + 4 = 5。
  2. left = 6 × 2 − 5 = 7。
  3. 右侧和为 8 + 10 = 18，右边有 2 项。
  4. right = 18 − 6 × 2 = 6。
  5. result[2] = 7 + 6 = 13。

Correctness

正确性证明

左侧：对任意 j < i，有 nums[j] <= nums[i]，故 |nums[i]-nums[j]| = nums[i]-nums[j]。合并后正是 nums[i]×i-prefix。
右侧：对任意 j > i，有 nums[j] >= nums[i]，故绝对差为 nums[j]-nums[i]。合并后正是右侧元素和减去 nums[i] 的重复份数。
合并：左右两组与当前位置自身（贡献 0）完整且互斥地覆盖所有下标，因此两组和就是题目定义的 result[i]。

Edges & cost

边界与复杂度

  • 重复值合法，差为 0，推导仍成立。
  • i = 0 时左侧为空；i = n-1 时右侧为空。
  • 只有两个元素时，两项答案相同。
  • 时间复杂度 O(n)：一次求总和，一次扫描。
  • 除返回数组外额外空间 O(1)。

Implementations

四语言完整代码

class Solution {
    public int[] getSumAbsoluteDifferences(int[] nums) {
        int n = nums.length;
        int total = 0;
        for (int value : nums) total += value;

        int[] result = new int[n];
        int prefix = 0;
        for (int i = 0; i < n; i++) {
            int left = nums[i] * i - prefix;
            int rightSum = total - prefix - nums[i];
            int right = rightSum - nums[i] * (n - i - 1);
            result[i] = left + right;
            prefix += nums[i];
        }
        return result;
    }
}

from typing import List

class Solution:
    def getSumAbsoluteDifferences(self, nums: List[int]) -> List[int]:
        n = len(nums)
        total = sum(nums)
        result = [0] * n
        prefix = 0

        for i, value in enumerate(nums):
            left = value * i - prefix
            right_sum = total - prefix - value
            right = right_sum - value * (n - i - 1)
            result[i] = left + right
            prefix += value

        return result

Alternatives

替代方案

逐项枚举：对每个位置遍历整个数组，时间 O(n²)，会在 10⁵ 规模超时。

答案递推：先算 result[0]，从 i-1 移到 i 时，距离变化为 (2i-n) × (nums[i]-nums[i-1])。同样是 O(n)，但推导更不直观。

Pitfalls

常见错误

  • 把 prefix 误写成包含当前位置的前缀和。
  • 右侧元素数量误写为 n-i，正确是 n-i-1。
  • 忽略“已排序”条件，仍对每一对元素调用绝对值。
  • 某些扩展约束下使用 32 位整数导致溢出。
