CORE INSIGHT

把例外变成普通面额

若只保存 7 个基础符号，就要不断特判 4 和 9。把六个减法组合也加入降序表后，所有情况统一成：选择不超过余数的最大面额，追加符号并扣减。

13 MINT MOLDS

1000 M · 900 CM · 500 D · 400 CD · 100 C · 90 XC · 50 L · 40 XL · 10 X · 9 IX · 5 V · 4 IV · 1 I

面额严格降序保证每次选择都不会破坏规范表示。

FULL WALKTHROUGH

完整解题过程

  1. 1. 建表：面额与符号一一对应，并按面额降序排列。
  2. 2. 扫描：从 1000 开始，检查当前面额是否不超过余数。
  3. 3. 压印：能扣就把对应符号追加到答案，并从余数中扣除面额。
  4. 4. 重复：同一面额可能连续使用，例如 3000 需要三个 M。
  5. 5. 收口：余数归零时，按顺序压印出的字符串就是规范罗马数字。

边界情况

  • 1 直接映射为 I。
  • 4、9 及其十倍/百倍必须使用减法组合。
  • V、L、D 不会连续重复。
  • 3999 是题目允许的最大值 MMMCMXCIX。

复杂度

时间：O(1)

额外空间：O(1)

输入被限制在 3999，表长和输出长度都有固定上界；若推广到任意 n，可写作 O(输出长度)。

替代方案

可以按千、百、十、个位分别查表，代码同样 O(1) 且更短；但完整贪心表更容易解释通用策略，也便于面试官追问扩展规则。

class Solution {
    public String intToRoman(int num) {
        int[] values = {
            1000, 900, 500, 400, 100, 90, 50,
            40, 10, 9, 5, 4, 1
        };
        String[] symbols = {
            "M", "CM", "D", "CD", "C", "XC", "L",
            "XL", "X", "IX", "V", "IV", "I"
        };
        StringBuilder result = new StringBuilder();

        for (int i = 0; i < values.length; i++) {
            while (num >= values[i]) {
                result.append(symbols[i]);
                num -= values[i];
            }
        }
        return result.toString();
    }
}

面试高频追问

为什么贪心一定得到规范表示？
规则本身要求从高位到低位表达；完整表包含所有合法减法组合，最大可用面额正是当前最高位的规范选择。
为什么不能把 49 写成 IL？
罗马数字按十进制位分别转换，49 = 40 + 9，因此是 XLIX。
减法组合为什么只有六个？
只有 I、X、C 能作为减号，并且只能放在相邻的 5 倍或 10 倍符号前。

常见错误

  • 映射表漏掉 900、400、90、40、9、4。
  • 只用一次 if，导致 3000 只输出一个 M。
  • 面额没有降序排列，生成非规范甚至错误结果。
  • 为 4 和 9 写大量分支，代码重复且容易遗漏十倍、百倍情况。
