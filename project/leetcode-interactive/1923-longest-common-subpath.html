1923 · 最长公共子路径

Longest Common Subpath

寻找每位旅人都走过的一段连续旅程。

题目

一个国家有 n 座城市，编号为 0 到 n − 1，任意两座城市间都有道路。m 位朋友分别按 paths[i] 中的顺序访问城市。城市允许重复到访，但相邻位置不会是同一城市。

给定整数 n 和二维整数数组 paths，返回每条路径共同包含的最长连续、同方向城市序列的长度。没有公共子路径则返回 0。子路径不能跳过中间城市，也不能倒序匹配。

参数：n: integer，paths: integer[][]；返回：integer。

官方示例

示例 1
输入：n = 5, paths = [[0,1,2,3,4],[2,3,4],[4,0,1,2,3]]
输出：2
解释：公共子路径 [2,3] 的长度为 2。

示例 2
输入：n = 3, paths = [[0],[1],[2]]
输出：0
解释：三条路径没有公共城市。

示例 3
输入：n = 5, paths = [[0,1,2,3,4],[4,3,2,1,0]]
输出：1
解释：[0]、[1]、[2]、[3]、[4] 都是长度为 1 的答案。

约束

  • 1 ≤ n ≤ 10⁵。
  • m = paths.length，2 ≤ m ≤ 10⁵。
  • sum(paths[i].length) ≤ 10⁵。
  • 0 ≤ paths[i][j] < n。
  • 同一条 paths[i] 中，相邻城市不会相同。

独立题解

先想一想：若长度 3 可行，长度 2 是否一定可行？

核心洞察：二分长度 + 双滚动哈希

公共片段的任意前缀仍是公共片段，所以真实可行性随长度增大呈“真 → 假”。答案范围是 [0,L]，L 为最短路径长度。

完整过程

  1. 选最短路径作为首个候选来源，减少候选数量。
  2. 判定长度 k：枚举每条路径的所有长度 k 窗口，以双哈希去重，逐条与已有候选集合求交。
  3. 交集为空立即返回假。处理完所有路径仍非空，则在无碰撞前提下返回真。长度 0 直接为真。
  4. 取上中位数 mid = floor((lo + hi + 1) / 2)，可行则 lo = mid，否则 hi = mid − 1，直到 lo = hi。

示例 1 中，检查 k = 2，最短路径给出 [2,3]、[3,4]；与其他两条路径求交后只剩 [2,3]。再检查 k = 3，[2,3,4] 不在最后一条路径出现，故答案为 2。

滚动窗口公式

x = city + 1，B = 100003
H = (x₀·B^(k−1) + … + xₖ₋₁) mod M
右移后：H' = (H·B + 新编码 − 旧编码·B^k) mod M
M₁ = 1,000,000,007，M₂ = 1,000,000,009

先加入新城市，再删除超出窗口的旧城市贡献，i ≥ k − 1 时记录哈希。Java/C++ 用 64 位整数，组合键 h₁·M₂ + h₂ 在范围内。JavaScript 用 BigInt，不能先用 Number 算大乘积再转 BigInt。

正确性与保证范围

真实序列求交的不变量：处理完前 t 条路径后，候选恰为这 t 条路径共同包含的长度 k 序列。第一条路径初始化所有窗口；后续求交恰好删除当前路径不包含的窗口；最终非空当且仅当长度 k 可行。

判定准确时，二分始终把真实答案保留在 [lo,hi]。mid 可行说明答案不小于 mid；不可行则答案至多 mid − 1。区间严格缩短，最终唯一值就是答案。

下方四份代码是双哈希概率性方案。不同序列仍可能产生相同的双哈希。固定基数和双模数不提供绝对保证；碰撞会产生假阳性，甚至影响判定单调性。上述证明依赖相关窗口不碰撞。若需确定性保证，应使用后缀自动机，或保留所有同哈希窗口并逐个比较真实序列；精确比较方案需重新分析最坏时间。

边界与常见错误

  • k = 0 直接返回真；空最短路径也自然得到 0。
  • 路径可以重复到访城市，但每条路径内部同一窗口只计一次。
  • 不能统计所有窗口出现次数后与 m 比较：次数可能全来自同一条路径。
  • 连续性和方向必须保持，最长公共子序列算法不适用。
  • 使用上中位数避免相邻边界死循环；删除旧项乘 B^k，并修正负余数。
  • n 限定城市编号，不需要构造完全图。

复杂度

记 S 为总长度、L 为最短路径长度、P 为最长路径长度。哈希集合期望常数操作下，一次判定 O(S)，总时间 O(S log(L + 1))。每条路径求 B^k 的总开销 m·k ≤ S。辅助集合 O(P + L)，Java/JavaScript/Python 另复制 O(m) 个引用，总辅助空间 O(P + L + m)，C++ 为 O(P + L)，均可粗略记作 O(S)。BigInt 带来额外常数开销，未做性能验证；哈希容器最坏操作时间不保证常数。

替代方案

后缀自动机：以最短路径建 SAM，对每条其他路径扫描并记录各状态最大匹配长度，再按状态长度降序沿后缀链接传播，取跨路径最小值，最后求最大值。它避免内容哈希碰撞，映射转移下期望 O(S) 时间、O(L) 空间，但实现更复杂。广义后缀数组 + LCP + 覆盖全部路径的滑动窗口也是确定性方向，需使用不同分隔符避免跨路径匹配。

面试追问

  • 怎样返回具体片段？保存最短路径中候选起点，在最终长度处恢复；严格模式下再逐条核对。
  • 为什么最短路径优先？候选数受 L 限制，交集为空时可提前终止。
  • 如何消除碰撞？用后缀结构，或对同哈希桶所有候选逐个精确核对；后者有更高最坏成本。

JavaScript

/** @param {number} n @param {number[][]} paths @return {number} */
var longestCommonSubpath = function(n, paths) {
    const a = [...paths];
    let s = 0;
    for (let i = 1; i < a.length; i++)
        if (a[i].length < a[s].length) s = i;
    [a[0], a[s]] = [a[s], a[0]];
    const B = 100003n, mods = [1000000007n, 1000000009n];
    function windows(path, k) {
        const pow = mods.map(mod => {
            let v = 1n;
            for (let i = 0; i < k; i++) v = v * B % mod;
            return v;
        });
        const h = [0n, 0n], out = new Set();
        for (let i = 0; i < path.length; i++) {
            for (let j = 0; j < 2; j++) {
                h[j] = (h[j] * B + BigInt(path[i] + 1)) % mods[j];
                if (i >= k) h[j] = (h[j] -
                    BigInt(path[i-k] + 1) * pow[j] % mods[j] + mods[j]) % mods[j];
            }
            if (i >= k-1) out.add(h[0] + ':' + h[1]);
        }
        return out;
    }
    function ok(k) {
        if (k === 0) return true;
        let common = windows(a[0], k);
        for (let i = 1; i < a.length && common.size; i++) {
            const current = windows(a[i], k);
            common = new Set([...common].filter(x => current.has(x)));
        }
        return common.size > 0;
    }
    // ponytail: hash collisions possible; use SAM for exactness.
    let lo = 0, hi = a[0].length;
    while (lo < hi) {
        const mid = Math.floor((lo + hi + 1) / 2);
        if (ok(mid)) lo = mid;
        else hi = mid - 1;
    }
    return lo;
};

Python

from typing import List

class Solution:
    def longestCommonSubpath(self, n: int, paths: List[List[int]]) -> int:
        a = list(paths)
        s = min(range(len(a)), key=lambda i: len(a[i]))
        a[0], a[s] = a[s], a[0]
        B, M1, M2 = 100003, 1000000007, 1000000009

        def windows(path, k):
            p1, p2 = pow(B, k, M1), pow(B, k, M2)
            h1 = h2 = 0
            out = set()
            for i, city in enumerate(path):
                h1 = (h1 * B + city + 1) % M1
                h2 = (h2 * B + city + 1) % M2
                if i >= k:
                    h1 = (h1 - (path[i-k] + 1) * p1) % M1
                    h2 = (h2 - (path[i-k] + 1) * p2) % M2
                if i >= k-1:
                    out.add((h1, h2))
            return out

        def ok(k):
            if k == 0:
                return True
            common = windows(a[0], k)
            for i in range(1, len(a)):
                common.intersection_update(windows(a[i], k))
                if not common:
                    return False
            return bool(common)

        # ponytail: hash collisions possible; use SAM for exactness.
        lo, hi = 0, len(a[0])
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if ok(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo

Java

import java.util.*;

class Solution {
    static final long B = 100003, M1 = 1000000007, M2 = 1000000009;
    Set<Long> windows(int[] path, int k) {
        long p1 = 1, p2 = 1, h1 = 0, h2 = 0;
        for (int i = 0; i < k; i++) {
            p1 = p1 * B % M1;
            p2 = p2 * B % M2;
        }
        Set<Long> out = new HashSet<>();
        for (int i = 0; i < path.length; i++) {
            h1 = (h1 * B + path[i] + 1) % M1;
            h2 = (h2 * B + path[i] + 1) % M2;
            if (i >= k) {
                h1 = (h1 - (path[i-k] + 1L) * p1 % M1 + M1) % M1;
                h2 = (h2 - (path[i-k] + 1L) * p2 % M2 + M2) % M2;
            }
            if (i >= k-1) out.add(h1 * M2 + h2);
        }
        return out;
    }
    boolean ok(int[][] a, int k) {
        if (k == 0) return true;
        Set<Long> common = windows(a[0], k);
        for (int i = 1; i < a.length && !common.isEmpty(); i++)
            common.retainAll(windows(a[i], k));
        return !common.isEmpty();
    }
    public int longestCommonSubpath(int n, int[][] paths) {
        int[][] a = paths.clone();
        int s = 0;
        for (int i = 1; i < a.length; i++)
            if (a[i].length < a[s].length) s = i;
        int[] temp = a[0]; a[0] = a[s]; a[s] = temp;
        // ponytail: hash collisions possible; use SAM for exactness.
        int lo = 0, hi = a[0].length;
        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;
            if (ok(a, mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }
}

C++

#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
    using ll = long long;
    static constexpr ll B = 100003, M1 = 1000000007, M2 = 1000000009;
    unordered_set<ll> windows(const vector<int>& path, int k) {
        ll p1 = 1, p2 = 1, h1 = 0, h2 = 0;
        for (int i = 0; i < k; ++i) {
            p1 = p1 * B % M1;
            p2 = p2 * B % M2;
        }
        unordered_set<ll> out;
        for (int i = 0; i < (int)path.size(); ++i) {
            h1 = (h1 * B + path[i] + 1) % M1;
            h2 = (h2 * B + path[i] + 1) % M2;
            if (i >= k) {
                h1 = (h1 - (path[i-k] + 1LL) * p1 % M1 + M1) % M1;
                h2 = (h2 - (path[i-k] + 1LL) * p2 % M2 + M2) % M2;
            }
            if (i >= k-1) out.insert(h1 * M2 + h2);
        }
        return out;
    }
public:
    int longestCommonSubpath(int n, vector<vector<int>>& paths) {
        int s = 0;
        for (int i = 1; i < (int)paths.size(); ++i)
            if (paths[i].size() < paths[s].size()) s = i;
        auto ok = [&](int k) {
            if (k == 0) return true;
            auto common = windows(paths[s], k);
            for (int i = 0; i < (int)paths.size() && !common.empty(); ++i) {
                if (i == s) continue;
                auto current = windows(paths[i], k);
                for (auto it = common.begin(); it != common.end(); ) {
                    if (!current.count(*it)) it = common.erase(it);
                    else ++it;
                }
            }
            return !common.empty();
        };
        // ponytail: hash collisions possible; use SAM for exactness.
        int lo = 0, hi = paths[s].size();
        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;
            if (ok(mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }
};
