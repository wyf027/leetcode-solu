划分二进制字符串的最小费用

每个偶长段可二分成两个等长连续段。把“是否继续拆”看作一棵受字符串位置约束的二叉树：每个节点只需比较 不拆 与 拆成左右子树。

题意

给定 s、encCost、flatCost。一段长度为 L、其中 1 的数量为 X：

  • X = 0：费用为 flatCost；
  • X > 0：费用为 L × X × encCost。
  • 仅偶数长度段能沿中点切成两个等长连续段；可递归继续切。

示例：s = "1010", encCost = 2, flatCost = 1，最小费用为 6。

约束：1 ≤ s.length ≤ 10^5；s 仅由 0、1 构成；两种单价均不超过 10^5。费用用 64 位整数保存。

节点公式

cost(l, r)
X = prefix[r] − prefix[l]
keep = X === 0 ? flatCost : (r − l) × X × encCost
dp(l, r)
min(keep, dp(l, mid) + dp(mid, r))
仅当 r − l 为偶数时存在第二项。

区间的中点唯一，因此无需枚举切割位置。前缀和让每个节点的 X 在 O(1) 得到。

核心洞察

一个区间没有“任选分割点”：若长度为偶数，只能从中点切开。因此所有可达区间组成固定的二叉树。对每个节点取不切分费用和两棵子树最优费用之和的较小值即可。

完整过程

  1. 构造 prefix[i]，表示前 i 个字符中 1 的个数。
  2. 访问区间 [l, r)，O(1) 计算该段 X 与 keep。
  3. 若长度为奇数，不能切，答案就是 keep。
  4. 若长度为偶数，递归计算左右半区并取较小值。

边界与复杂度

全 0 段的 flatCost 有时比继续拆更小；长度为奇数时强制停止；最大费用可达 10^15。每个可达区间只处理一次，二叉树节点数为 O(n)，时间 O(n)，额外空间 O(n)（前缀和与递归栈）。

替代方案、追问与常见错误

可用显式栈做后序遍历以避免递归写法；不能把它误做成任意切点的区间 DP（那会多余地达到 O(n²)）。常见错误包括：把 [l,r) 的长度写成 r-l+1、忽略全零段的固定费用、以及用 32 位整数乘法。 

class Solution {
    private int[] prefix;
    private long enc, flat;
    public long minCost(String s, int encCost, int flatCost) {
        int n = s.length(); prefix = new int[n + 1];
        for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + (s.charAt(i) == '1' ? 1 : 0);
        enc = encCost; flat = flatCost; return solve(0, n);
    }
    private long solve(int l, int r) {
        long len = r - l, ones = prefix[r] - prefix[l];
        long keep = ones == 0 ? flat : len * ones * enc;
        if ((len & 1) == 1) return keep;
        long split = solve(l, (l + r) / 2) + solve((l + r) / 2, r);
        return Math.min(keep, split);
    }
}
var minCost = function(s, encCost, flatCost) {
  const prefix = [0];
  for (const ch of s) prefix.push(prefix[prefix.length - 1] + (ch === '1'));
  const solve = (l, r) => {
    const len = r - l, ones = prefix[r] - prefix[l];
    const keep = ones === 0 ? flatCost : len * ones * encCost;
    if (len % 2) return keep;
    const m = (l + r) >> 1;
    return Math.min(keep, solve(l, m) + solve(m, r));
  };
  return solve(0, s.length);
};
