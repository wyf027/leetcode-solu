01 / 题意

The brief

记录每一回合，
也允许推翻上一笔。

比赛开始时记录为空。给定字符串数组 operations，依次执行每个操作；最终返回仍然有效的全部得分之和。所有操作都保证合法。

四种记分指令

x

若操作是整数 x，把 x 作为一个新的有效得分。

+

把前两个有效得分之和，作为新的有效得分。

D

把前一个有效得分的两倍，作为新的有效得分。

C

让前一个有效得分作废，并将它从记录中移除。

约束

  • 1 <= operations.length <= 1000
  • 整数操作范围：[-3 × 10^4, 3 × 10^4]
  • + 出现时至少已有两个有效得分。
  • C、D 出现时至少已有一个有效得分。
  • 答案与全部中间计算结果均在 32 位整数范围内。

Solution · Spoilers ahead

让记录本身，
承担历史。

核心洞察

每个操作只依赖“目前仍有效”的最后一个或两个得分；C 又恰好删除最后一个有效得分。于是需要的数据结构必须能从尾部读取、追加和删除。把有效记录按先后顺序存放在一个栈（或动态数组）里，就能让四种操作都直接对应到栈顶动作。

完整过程

  1. 创建空栈 scores。
  2. 从左到右遍历 operations。
  3. 整数：解析后压栈；C：弹出栈顶。
  4. D：将栈顶两倍压栈；+：将栈顶两项之和压栈。
  5. 遍历结束后，对栈内所有有效得分求和。

正确性

  1. 不变式：处理前 i 项操作后，栈从底到顶恰好等于此时按时间顺序排列的所有有效得分。
  2. 初始化：尚未处理操作时，两者都为空，不变式成立。
  3. 保持：整数、D、+ 都把题目规定的新得分追加到尾部；C 删除最后一项。四种情况都与栈操作一致。
  4. 终止：全部操作处理完后，栈恰好包含最终全部有效得分，因此栈元素之和就是答案。

边界情况

  • 唯一得分被 C 撤销后，结果是 0。
  • 得分可以为负数，D 后仍可能为负。
  • + 可以引用由此前 + 或 D 生成的得分。
  • 题目保证操作合法，无需为缺少前项编造默认值。

复杂度

时间O(n)每项操作一次，末尾求和一次
空间O(n)最坏情况下全部得分有效

替代方案

可以在每次追加或撤销时同步维护总和，将最后的求和省掉；渐进时间仍是 O(n)，但每步都能立刻得到当前总分。也可以用链表模拟尾部操作，不过数组栈更简单、局部性更好。仅维护“最近两个分数”并不可行，因为之后的 C 可能连续回退，需要恢复更早的历史。

Java LeetCode signature
class Solution {
    public int calPoints(String[] operations) {
        java.util.Deque<Integer> scores = new java.util.ArrayDeque<>();

        for (String op : operations) {
            switch (op) {
                case "C":
                    scores.removeLast();
                    break;
                case "D":
                    scores.addLast(scores.peekLast() * 2);
                    break;
                case "+":
                    int last = scores.removeLast();
                    int previous = scores.peekLast();
                    scores.addLast(last);
                    scores.addLast(previous + last);
                    break;
                default:
                    scores.addLast(Integer.parseInt(op));
            }
        }

        int total = 0;
        for (int score : scores) total += score;
        return total;
    }
}

/**
 * @param {string[]} operations
 * @return {number}
 */
var calPoints = function(operations) {
    const scores = [];

    for (const op of operations) {
        if (op === "C") {
            scores.pop();
        } else if (op === "D") {
            scores.push(scores[scores.length - 1] * 2);
        } else if (op === "+") {
            const n = scores.length;
            scores.push(scores[n - 1] + scores[n - 2]);
        } else {
            scores.push(Number(op));
        }
    }

    return scores.reduce((sum, score) => sum + score, 0);
};

class Solution {
public:
    int calPoints(vector<string>& operations) {
        vector<int> scores;

        for (const string& op : operations) {
            if (op == "C") {
                scores.pop_back();
            } else if (op == "D") {
                scores.push_back(scores.back() * 2);
            } else if (op == "+") {
                int n = scores.size();
                scores.push_back(scores[n - 1] + scores[n - 2]);

                scores.push_back(stoi(op));
            }
        }

Interview follow-ups

面试追问与常见错误

如果要求每次操作后都报告总分，怎么改？

额外维护变量 total。追加得分时加上它，C 时减去被弹出的分数；每步即可在 O(1) 时间报告当前总分。

能否做到 O(1) 额外空间？

一般不能。连续撤销可能要求恢复任意早的有效历史，必须保留尚未被撤销的分数；最坏情况下需要 O(n) 空间。

常见错误有哪些？

把 C 当作新增 0 分；使用原始操作数组找前两项而忽略已撤销记录；处理 + 时覆盖倒数项；把负数字符串误判为指令；以及在空栈求和时忘记结果应为 0。
