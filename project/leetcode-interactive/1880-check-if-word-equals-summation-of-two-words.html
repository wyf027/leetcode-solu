01 / 题目

按顺序连接，再比较数值

字母值从 0 开始：a 表示 0，b 表示 1，依次类推，j 表示 9。将单词中每个字母的值按原顺序连接，所得十进制数字串转成整数，就是这个单词的数值；前导零不影响整数值。

给定 firstWord、secondWord、targetWord，判断前两个单词的数值之和，是否等于第三个单词的数值。相等返回 true，否则返回 false。

例如 acb 对应数字串 021，它表示整数 21。

约束

  • 三个字符串的长度分别满足 1 ≤ length ≤ 8。
  • 所有字符都是 a 至 j（包含两端）的小写英文字母。

参数：三个 string；返回值：boolean。题意及示例依据本地官方元数据转述。官方题目

02 / 官方示例

先观察输入与输出

示例 1

firstWord = "acb", secondWord = "cba", targetWord = "cdb"

输出：true

acb → 021 → 21；cba → 210 → 210；cdb → 231 → 231。21 + 210 = 231。

示例 2

firstWord = "aaa", secondWord = "a", targetWord = "aab"

输出：false

aaa → 000 → 0；a → 0 → 0；aab → 001 → 1。0 + 0 ≠ 1。

示例 3

firstWord = "aaa", secondWord = "a", targetWord = "aaaa"

输出：true

aaa → 000 → 0；a → 0 → 0；aaaa → 0000 → 0。0 + 0 = 0。

05 / 独立题解

想好思路后，再展开

包含核心推导、正确性证明、四语言完整代码与面试延伸。

逐位累积，再相加比较

核心洞察

a–j 恰好对应单个十进制数字 0–9。若已读前缀的数值是 v，再追加一位 d，新的值就是 v × 10 + d。因此无需真正创建数字字符串。

完整过程

  1. 定义转换函数，累积值 v 初始化为 0。
  2. 从左至右读取每个字符，令 d 为该字符与 'a' 的字符编码差，再更新 v = v × 10 + d。
  3. 分别转换 firstWord、secondWord、targetWord，得到 x、y、z。
  4. 返回 x + y == z。

以 acb 为例：初始 0；读 a 后 0 × 10 + 0 = 0；读 c 后 0 × 10 + 2 = 2；读 b 后 2 × 10 + 1 = 21。再得 cba = 210、cdb = 231，最终返回 true。

正确性证明

循环不变式：处理前 k 个字符后，v 等于这 k 个字母对应的十进制数字串的整数值。初始 k = 0，空前缀以 0 为累积起点，成立。若处理 k 个字符后成立，追加数字 d 时，十进制位权使此前各位乘以 10，再加个位 d，因此更新后仍成立。循环结束，转换函数得到整个单词的数值。三个转换都正确，最后的加法相等判断便与题目要求完全一致。

边界与数值范围

  • 开头多个 a 自动作为前导零处理；全是 a 的字符串得到 0。
  • 单字符也遵循同一更新规则，最短输入无需特殊分支。
  • 每个单词最多 8 位，数值至多 99,999,999；两数之和至多 199,999,998。Java int 和通常在线评测的 32 位 C++ int 足够，JavaScript Number 可精确表示，Python 整数也足够。
  • 进位交给整数加法，不应对单词按字母位置直接相加。

复杂度

令三个长度为 n、m、k。转换共访问 n + m + k 个字符，时间复杂度为 O(n + m + k)；仅维护固定数量的数值变量，额外空间为 O(1)，不计输入。不要因为本题长度上限为 8 就掩盖算法随输入增长的线性行为。

替代方案

先将字母映射成数字字符串，再按十进制解析，也能解决本题；需要构造中间串，额外空间为 O(n + m + k)。必须按十进制处理前导零。如果允许任意长单词，可以用任意精度整数，或从右向左模拟十进制加法并处理进位、忽略前导零。

Java

class Solution {
    private int value(String word) {
        int v = 0;
        for (int i = 0; i < word.length(); i++) {
            v = v * 10 + (word.charAt(i) - 'a');
        }
        return v;
    }

    public boolean isSumEqual(String firstWord, String secondWord,
                              String targetWord) {
        return value(firstWord) + value(secondWord) == value(targetWord);
    }
}

var isSumEqual = function(firstWord, secondWord, targetWord) {
    function value(word) {
        let v = 0;

            v = v * 10 + (word.charCodeAt(i) - 97);

    return value(firstWord) + value(secondWord) === value(targetWord);
};

        def value(word: str) -> int:
            v = 0

                v = v * 10 + ord(ch) - ord('a')

常见错误

  • 把字母值相加：acb 不是 0 + 2 + 1，而是十进制 021。
  • 把 a 映射成 1：题目从 0 开始计数。
  • 比较原始数字串或长度：000 和 0 的数值相同。
  • 遗漏乘以 10：会丢失位置所代表的权重。
  • 用带八进制推断的解析方式处理前导零：若转换字符串，应显式指定十进制。

面试追问

如果长度变为十万？ 固定精度整数可能溢出。可从末尾逐位相加，维护一个进位，并与目标数字位比较；剩余位置按 0 对待，最后还要确认没有非零进位。

如果允许 k–z？ 需要重新确认编码规则：若仍连接字母值，k 对应的 10 占两位，不能再统一乘以 10；追加两位值时需要乘以 100。若改成 26 进制，则是另一套数值定义。

能提前因长度不同返回 false 吗？ 不能直接比较单词长度，因为前导 a 不改变数值；需先考虑有效数字长度与加法进位。
