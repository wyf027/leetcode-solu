直线镜像LINE REFLECTION

一组散落在二维平面上的点，能否被同一面竖直的“镜子”完整映回自身？先读题并亲手推进可视化；完整题解在页面底部，默认不会提前揭晓。

官方函数：isReflected(points) 返回：boolean 目标：优于 O(n²)
Problem

题目描述

给定二维平面上的点列表 points。判断是否存在一条与 y 轴平行的直线，使所有点关于该直线反射后，得到的点集与原点集完全相同。

反射不会改变点的 y 坐标；落在镜像直线上的点会映射到自身。输入中允许出现重复点。

官方参数形式
boolean isReflected(integer[][] points)

示例 1

输入points = [[1,1],[-1,1]]
输出true

可选择直线 x = 0，两个点恰好互为镜像。

示例 2

输入points = [[1,1],[-1,-1]]
输出false

两个点的 y 不同，无法关于任何竖直直线互相映射。

Constraints

约束与追问

  • n == points.length
  • 1 <= n <= 10⁴
  • 每个点均为二元整数坐标 [x, y]
  • -10⁸ <= points[i][j] <= 10⁸
  • 可能存在重复坐标

Solution

极值定轴 + 哈希镜像

镜面并不需要枚举：最左点与最右点已经把它唯一锁定。全程保存横坐标和，避开小数镜面与浮点误差。

核心洞察

设最小横坐标为 minX，最大横坐标为 maxX。若存在竖直对称轴，那么两个极值必然互为镜像，因此镜面只能是：

axisX = (minX + maxX) / 2

无需真的除以 2。记录 sum = minX + maxX，点 (x, y) 的镜像应为 (sum - x, y)。

完整过程

  1. 扫描全部点，得到 minX 与 maxX。
  2. 计算 sum = minX + maxX。
  3. 把每个坐标对放进哈希集合；重复点自然被折叠。
  4. 再次遍历每个 (x, y)，检查 (sum - x, y) 是否存在。
  5. 任一镜像缺失就返回 false；全部存在则返回 true。

正确性证明

候选轴的必要性。 若点集关于 x = c 对称，最左点必映射到最右位置，所以 2c = minX + maxX = sum。
检查条件的充分性。 对每个输入点 (x,y)，算法都确认 (sum-x,y) 存在；它恰是关于 x=sum/2 的镜像。
结论。 必要性保证没有漏掉其他候选轴，充分性保证通过检查时整个点集在该轴下保持不变，故返回值正确。

边界与复杂度

  • 单点 / 轴上点：镜像就是自身，集合查找会成功。
  • 重复点：题目比较点集，存在性检查足够，不需要匹配出现次数。
  • 半整数轴：例如 minX + maxX 为奇数时仍可用整数和精确检查。
  • 大坐标：Java / C++ 示例用更宽整数保存横坐标和，避免扩展约束下溢出。
  • 时间：O(n) 期望时间；空间：O(n)。

替代方案：按行排序配对

也可以按 y 分组，把每一行的横坐标排序后从两端向内配对，并要求所有配对的横坐标和都等于同一个 sum。该方案不依赖哈希的期望复杂度，但整体通常需要 O(n log n) 时间。仅比较每行的最小值与最大值并不充分，因为中间可能缺少对应点。

Java HashSet 
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean isReflected(int[][] points) {
        if (points == null || points.length <= 1) {
            return true;
        }

        int minX = Integer.MAX_VALUE;
        int maxX = Integer.MIN_VALUE;
        Set<String> seen = new HashSet<>();

        for (int[] point : points) {
            int x = point[0];
            int y = point[1];
            minX = Math.min(minX, x);
            maxX = Math.max(maxX, x);
            seen.add(key(x, y));
        }

        long sum = (long) minX + maxX;
        for (int[] point : points) {
            long reflectedX = sum - point[0];
            if (!seen.contains(key(reflectedX, point[1]))) {
                return false;
            }
        }
        return true;
    }

    private String key(long x, int y) {
        return x + "," + y;
    }
}

var isReflected = function(points) {
    if (points.length <= 1) {
        return true;
    }

    let minX = Infinity;
    let maxX = -Infinity;
    const seen = new Set();
    const key = (x, y) => `${x},${y}`;

    for (const [x, y] of points) {
        minX = Math.min(minX, x);
        maxX = Math.max(maxX, x);
        seen.add(key(x, y));
    }

    const sum = minX + maxX;
    for (const [x, y] of points) {
        if (!seen.has(key(sum - x, y))) {
            return false;
        }
    }
    return true;
};
Python set 
from typing import List


class Solution:
    def isReflected(self, points: List[List[int]]) -> bool:
        if len(points) <= 1:
            return True

        min_x = min(x for x, _ in points)
        max_x = max(x for x, _ in points)
        reflection_sum = min_x + max_x
        point_set = {(x, y) for x, y in points}

        return all(
            (reflection_sum - x, y) in point_set
            for x, y in points
        )
C++ unordered_set 
#include <algorithm>
#include <climits>
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    bool isReflected(vector<vector<int>>& points) {
        if (points.size() <= 1) {
            return true;
        }

        int minX = INT_MAX;
        int maxX = INT_MIN;
        unordered_set<string> seen;

        for (const auto& point : points) {
            minX = min(minX, point[0]);
            maxX = max(maxX, point[0]);
            seen.insert(key(point[0], point[1]));
        }

        const long long sum = static_cast<long long>(minX) + maxX;
        for (const auto& point : points) {
            const long long reflectedX = sum - point[0];
            if (!seen.count(key(reflectedX, point[1]))) {
                return false;
            }
        }
        return true;
    }

private:
    string key(long long x, int y) {
        return to_string(x) + "," + to_string(y);
    }
};

面试追问

  • 为什么对称轴一定由全局 minX 与 maxX 决定？
  • 如果题意要求重复点的出现次数也必须镜像相等，数据结构要怎样改？
  • 若镜面允许是任意方向的直线，当前方法哪里会失效？
  • 如何设计一个不使用额外哈希集合的 O(n log n) 解法？

常见错误

  • 把镜面误写成 y = (minX + maxX) / 2；竖直线应写作 x = ...。
  • 直接用浮点中点，再用浮点数作为哈希键。
  • 只验证最左与最右点，没有逐点检查相同 y 上的镜像。
  • 用易碰撞的算术编码拼坐标，却没有证明编码范围安全。
  • 误以为轴上的点必须与另一个不同点配对。
