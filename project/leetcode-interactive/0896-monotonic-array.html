单调数列

Monotonic Array

EASY非付费题一次遍历

题目

若一个整数数组整体保持非递减，或整体保持非递增，就称它为单调数组。给定整数数组 nums，判断它是否单调。相邻元素可以相等。

函数：isMonotonic(nums: integer[]) -> boolean

示例 1
输入：nums = [1,2,2,3]
输出：true
示例 2
输入：nums = [6,5,4,4]
输出：true
示例 3
输入：nums = [1,3,2]
输出：false

约束

  • 1 <= nums.length <= 10^5
  • -10^5 <= nums[i] <= 10^5
Direction Lab

让数组自己排除方向

每比较一对相邻元素，若出现下降就排除“非递减”；若出现上升就排除“非递增”。等号不会排除任何方向。

非递减仍可能：是
非递增仍可能：是
准备开始：两个方向都仍有可能。

先自己想一想

  • 只看数组首尾，能否判断中间没有“拐弯”？
  • 遇到相等元素时，应该决定方向还是跳过？
  • 是否真的需要先判断方向，再进行第二次遍历？
Solution

一次遍历，同时保留两个可能

核心洞察

单调数组只需满足两个候选条件中的至少一个：所有相邻对均不下降，或所有相邻对均不上升。维护 increasing 与 decreasing 两个布尔值；一旦某对元素违反某个方向，该方向永久不可能恢复。

完整过程

  1. 两个标记都初始化为 true。
  2. 从下标 1 开始比较 nums[i] 与 nums[i-1]。
  3. 若当前值更小，令 increasing = false；若当前值更大，令 decreasing = false。
  4. 若两个标记都为假可提前返回；遍历结束返回两者的逻辑或。

正确性

循环处理完下标 i 后，increasing 为真当且仅当前缀中每一对相邻元素都满足前者不大于后者；decreasing 同理。初始化对长度 1 的前缀成立，每一步恰好根据新增相邻对更新条件，因此不变式始终成立。最终覆盖全部相邻对；任一标记为真等价于整个数组沿对应方向单调，故返回结果正确。

边界

  • 长度为 1：无需比较，两个方向都成立。
  • 全部相等：同时非递减、非递增。
  • 负数与重复值：比较规则不变。

复杂度

  • 时间：O(n)
  • 额外空间：O(1)

替代方案

可以先寻找第一对不相等元素以确定方向，再检查余下元素；也可分别调用一次非递减检查和一次非递增检查。前者状态分支更多，后者最坏会扫描两遍；双标记写法更对称。

面试追问

  • 如何流式处理未知长度的数据？只保存前一个元素和两个标记。
  • 如何返回首个破坏单调性的下标？当第二个标记也被排除时返回当前下标。
  • 严格单调如何修改？把相等也视为同时破坏两个严格方向。

常见错误

  • 把相等误判为破坏单调性。
  • 仅比较首尾元素，漏掉中间拐点。
  • 用排序后比较，增加 O(n log n) 时间与额外存储。

Java

class Solution {
    public boolean isMonotonic(int[] nums) {
        boolean increasing = true, decreasing = true;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] < nums[i - 1]) increasing = false;
            if (nums[i] > nums[i - 1]) decreasing = false;
            if (!increasing && !decreasing) return false;
        }
        return true;
    }
}

Python

from typing import List

class Solution:
    def isMonotonic(self, nums: List[int]) -> bool:
        increasing = decreasing = True
        for i in range(1, len(nums)):
            if nums[i] < nums[i - 1]:
                increasing = False
            if nums[i] > nums[i - 1]:
                decreasing = False
            if not increasing and not decreasing:
                return False
        return True

    bool isMonotonic(vector<int>& nums) {

        }
