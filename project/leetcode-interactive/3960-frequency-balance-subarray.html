FREQUENCY OF FREQUENCY

频率平衡
子数组

不是要求所有数字出现次数相等：有效区间要么只有一种值；要么所有频率恰好落在 f 与 2f 两层，而且两层都出现。固定左端点、逐步扩展右端点，就能把检查压到常数级。

打开频率实验台

题目契约

输入
nums：正整数数组。
返回
最长频率平衡连续子数组的长度。
平衡规则
单一不同值直接有效；否则只允许 f、2f 两种频率，并且两种都必须存在。
约束
1 ≤ nums.length ≤ 1000；1 ≤ nums[i] ≤ 10⁹。

STATE A

单值区间无条件有效

例如 [5,5,5,5] 只有一种不同值，无论频率是奇是偶，整个区间都有效。

STATE B

两层频率且比例为 1:2

维护“频率的频率表”。若其中恰有两个键 a,b 且 max(a,b)=2·min(a,b)，就满足定义。

SOLUTION UNLOCKED

完整过程：枚举 + 两张哈希表

  1. 固定左端点 l。 清空 count（数值 → 出现次数）和 freqCount（频率 → 有多少个数值）。
  2. 右端点 r 右移。 设新元素旧频率为 c；先从 freqCount[c] 删除一个，再把该元素频率改成 c+1 并加入 freqCount[c+1]。
  3. 常数时间判断。 count.size === 1 时有效；否则 freqCount 恰有两个键，且较大键为较小键的两倍时有效。
  4. 记录长度。 对每个有效窗口更新 ans=max(ans,r-l+1)。

核心洞察

重新扫描所有数值频率会把每个窗口检查变成线性；频率的频率表只维护发生变化的两个桶，因此一次扩展后的判定只需看键数与比例。

复杂度

n≤1000 允许枚举所有 O(n²) 个窗口。每次更新均摊 O(1)，总时间 O(n²)，空间 O(n)。

边界

  • 全相同数组必须返回完整长度。
  • 频率只有一个键、但不同值多于一个，例如 [1,2]，不满足“两种频率都出现”。
  • 频率为 1 与 2、或 2 与 4 均有效。

替代方案、追问与常见错误

朴素做法每次扫描 count 判断，会退化为 O(n³)。若约束增至 10⁵，需要重新寻找更强的频率结构。常见错误是把“所有频率相同”误当有效，或忘记双频率状态必须同时存在。

class Solution {
    public int getLength(int[] nums) {
        int ans = 1;
        for (int l = 0; l < nums.length; l++) {
            Map<Integer, Integer> count = new HashMap<>();
            Map<Integer, Integer> freqCount = new HashMap<>();
            for (int r = l; r < nums.length; r++) {
                int x = nums[r], old = count.getOrDefault(x, 0);
                if (old > 0 && freqCount.merge(old, -1, Integer::sum) == 0) freqCount.remove(old);
                int now = old + 1;
                count.put(x, now);
                freqCount.merge(now, 1, Integer::sum);
                if (count.size() == 1 || (freqCount.size() == 2 && hasDouble(freqCount))) ans = Math.max(ans, r - l + 1);
            }
        }
        return ans;
    }
    private boolean hasDouble(Map<Integer, Integer> m) {
        int a = 0, b = 0; for (int x : m.keySet()) { if (a == 0) a = x; else b = x; }
        return a == 2 * b || b == 2 * a;
    }
}

var getLength = function (nums) {
  let ans = 1;
  const balanced = (freqCount) => {
    const [a, b] = [...freqCount.keys()];
    return a === 2 * b || b === 2 * a;
  };
  for (let l = 0; l < nums.length; l++) {
    const count = new Map(), freqCount = new Map();
    for (let r = l; r < nums.length; r++) {
      const old = count.get(nums[r]) ?? 0;
      if (old > 0) { const left = freqCount.get(old) - 1; left ? freqCount.set(old, left) : freqCount.delete(old); }
      const now = old + 1;
      count.set(nums[r], now);
      freqCount.set(now, (freqCount.get(now) ?? 0) + 1);
      if (count.size === 1 || (freqCount.size === 2 && balanced(freqCount))) ans = Math.max(ans, r - l + 1);
    }
  }
  return ans;
};

    def getLength(self, nums: List[int]) -> int:
        ans = 1
        for left in range(len(nums)):
            count, freq_count = {}, {}
            for right in range(left, len(nums)):
                x = nums[right]
                old = count.get(x, 0)
                if old:
                    freq_count[old] -= 1
                    if freq_count[old] == 0: del freq_count[old]
                now = old + 1
                count[x] = now
                freq_count[now] = freq_count.get(now, 0) + 1
                keys = list(freq_count)
                if len(count) == 1 or (len(keys) == 2 and (keys[0] == 2 * keys[1] or keys[1] == 2 * keys[0])):
                    ans = max(ans, right - left + 1)
        return ans
class Solution {
public:
    int getLength(vector<int>& nums) {
        int ans = 1, n = nums.size();
        for (int l = 0; l < n; ++l) {
            unordered_map<int, int> count, freqCount;
            for (int r = l; r < n; ++r) {
                int old = count[nums[r]];
                if (old > 0 && --freqCount[old] == 0) freqCount.erase(old);
                int now = ++count[nums[r]];
                ++freqCount[now];
                if (count.size() == 1 || (freqCount.size() == 2 && balanced(freqCount))) ans = max(ans, r - l + 1);
            }
        }
        return ans;
    }
private:
    bool balanced(const unordered_map<int, int>& m) {
        auto it = m.begin(); int a = (it++)->first, b = it->first;
        return a == 2 * b || b == 2 * a;
    }
};
