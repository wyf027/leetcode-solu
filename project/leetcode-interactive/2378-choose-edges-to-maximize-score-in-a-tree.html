2378 · Choose Edges to Maximize Score in a Tree

每个节点只能参与一条被选中的边。
在局部收益与彼此冲突之间，找出得分最高的选择。

阅读题意查看示例前往题解入口

01题意与输入

输入一棵以 0 为根的带权树，节点编号是 0 … n−1。数组 edges[i] = [parᵢ, weightᵢ] 记录节点 i 的父节点及这条父子边的权重；根的记录固定为 [-1, -1]。

选择若干条边，使任何两条被选中的边都不共用节点，返回它们权重之和的最大值。允许一条也不选，此时得分为 0。

读入提醒：edges 是按节点编号排列的父节点记录，长度为 n；实际只有 n−1 条边，根记录不计分。

约束

  • n == edges.length，1 ≤ n ≤ 10⁵。
  • 每个 edges[i] 恰含两个整数。
  • par₀ == weight₀ == −1。
  • 对 i ≥ 1，0 ≤ parᵢ ≤ n−1 且 parᵢ ≠ i。
  • 对 i ≥ 1，−10⁶ ≤ weightᵢ ≤ 10⁶。
  • 输入保证构成有效的树；父节点编号未必小于子节点编号。

官方接口元数据：maxScore(edges: integer[][]) → long。

02官方示例

示例 1

edges = [[-1,-1],[0,5],[0,10],[2,6],[2,4]]

输出：11

选择 0—1（5）与 2—3（6），端点互不重合，总分为 11。

示例 2

edges = [[-1,-1],[0,5],[0,-6],[0,7]]

输出：7

所有边都经过节点 0，因此最多选一条；选择 0—3 得到 7。

03题解 · 树上的最大权匹配

每条父子边是否被选择，决定子树根节点能否继续连接孩子。兄弟子树之间没有边，因此边界条件确定后，可以独立求最优值再相加。

核心洞察：只传递“父边是否占用”

  • free[u]：父边不选，u 还能向下选择至多一条边，子树内部的最大得分。
  • blocked[u]：父边已选，u 不能再选任何孩子边，子树内部的最大得分。
  • 两个状态都不计父边权重；父边在父节点的转移中计入一次。

先假设 u 不连接任何孩子，让每个孩子子树自由取最优。随后只需尝试把其中一个孩子 v 改成“被父边占用”。

base = Σ free[v] // v 为 u 的孩子 Δ(v) = weight(u,v) + blocked[v] − free[v] blocked[u] = base free[u] = base + max(0, max Δ(v)) 答案 = free[0]

减去 free[v] 是撤销基线中原有的子树方案，再加上选边收益和受限子树方案。max(0, …) 表示可以不选任何孩子边。

完整过程与正确性

  1. 由父节点记录建立孩子列表，跳过根记录。
  2. 从 0 开始生成父节点先于孩子的遍历序，反向处理以保证孩子状态已知；不能直接按节点编号倒序。
  3. 叶子的两个状态都是 0。对每个内部节点累加基线，比较每个孩子的净增益，只取最大的非负增益。
  4. 根没有父边，返回 free[0]。

示例 1：一次“替换”

节点 2 的基线为 0，选权重 6 的边使 free[2]=6，而 blocked[2]=0。根的基线为 6。连接节点 1 的净增益是 5；连接节点 2 的净增益是 10+0−6=4。所以选择前者，得到 6+5=11。

正确性：对子树大小归纳

叶子没有内部边，两个状态均为 0，结论成立。假设所有孩子状态已最优：当父边已选时，u 的所有孩子边都必须不选，孩子子树彼此独立，因此 Σ free[v] 恰为最优。

当父边未选时，合法方案只有“不选任何孩子边”或“恰选某一条孩子边”两类。后者使该孩子进入 blocked 状态，其他孩子保持 free。转移枚举了全部合法类别，并在每类使用最优子问题，所以取最大值即得到 free[u] 的最优值。归纳到根，算法返回全树最优分数。

复杂度与数值范围

每个节点及每条父子边只处理常数次，时间 O(n)；孩子列表、遍历序和状态数组占用 O(n) 空间。不使用递归，避免深链导致调用栈溢出。

至多选 ⌊n/2⌋ 条边，答案不超过 5×10¹⁰。Java 使用 long，C++ 使用 long long；Python 整数足够，JavaScript Number 在此范围内保持整数精确。

边界与常见错误

  • 只有根、全负权：答案为 0，不要强制选边。
  • 零权或增益并列：可以跳过，或任选一种最优方案。
  • 星形树：根至多连接一个孩子，不能把所有正增益相加。
  • 选父子边时忘记减 free[v]，会重复计算互相冲突的两套方案。
  • 根的 −1 是占位值，不能计分；父边权重不能在两个端点各加一次。
  • 最大边贪心会失败：示例 1 先选 10，只能得 10，而 5+6 得 11。

替代方案

递归后序遍历使用相同状态和转移，表达简洁，但深度可能达到 10⁵，需要处理栈限制。枚举所有边子集并判断端点冲突适合小规模推理，复杂度 O(n·2ⁿ)，不能应对正式约束。一般图的最大权匹配算法适用面更广，但这棵树允许线性动态规划。

面试追问

  • 恢复选边：记录 free[u] 最佳增益对应的孩子，从根向下传播父边是否已选；u 被占用时，所有孩子的父边都不选。
  • 每节点最多参与 k 条边：仍区分父边占用状态，分别取孩子正增益中最大的 k 条或 k−1 条，并计入排序成本。
  • 必须至少选一条：需要增加“是否已选边”状态，不能直接把负值截断为 0；单节点输入可能无解。

Java

import java.util.*;

class Solution {
    public long maxScore(int[][] edges) {
        int n = edges.length;
        List<List<Integer>> children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int v = 1; v < n; v++) children.get(edges[v][0]).add(v);
        int[] order = new int[n];
        int size = 1;
        for (int i = 0; i < size; i++) {
            for (int v : children.get(order[i])) order[size++] = v;
        }
        long[] free = new long[n], blocked = new long[n];
        for (int i = n - 1; i >= 0; i--) {
            int u = order[i];
            long base = 0, gain = 0;
            for (int v : children.get(u)) {
                base += free[v];
                gain = Math.max(gain, (long) edges[v][1] + blocked[v] - free[v]);
            }
            blocked[u] = base;
            free[u] = base + gain;
        }
        return free[0];
    }
}

Python

from typing import List

class Solution:
    def maxScore(self, edges: List[List[int]]) -> int:
        n = len(edges)
        children = [[] for _ in range(n)]
        for v in range(1, n):
            children[edges[v][0]].append(v)
        order = [0]
        i = 0
        while i < len(order):
            order.extend(children[order[i]])
            i += 1
        free = [0] * n
        blocked = [0] * n
        for u in reversed(order):
            base = 0
            gain = 0
            for v in children[u]:
                base += free[v]
                gain = max(gain, edges[v][1] + blocked[v] - free[v])
            blocked[u] = base
            free[u] = base + gain
        return free[0]

    long long maxScore(vector<vector<int>>& edges) {

                base += free[v];
                gain = max(gain, (long long)edges[v][1] + blocked[v] - free[v]);
            }
            blocked[u] = base;
            free[u] = base + gain;
        }
        return free[0];
