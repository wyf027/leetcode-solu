Redistribute Characters to Make All Strings Equal

把字符从一个字符串搬到另一个。最终，它们能变成完全一样的字符串吗？

先理解允许的操作，再自行思考。交互演示、思路和代码均在底部题解中。

01 / 题目

给定下标从 0 开始的字符串数组 words。每次选择两个不同下标 i、j，要求 words[i] 非空；取出其中任意一个字符，将它插入 words[j] 的任意位置。

允许进行零次或任意多次操作。若能让数组中所有字符串完全相同，返回 true；否则返回 false。比较的是字符及其顺序，不只是长度。

移动不会新增或删除字符；操作过程中允许出现空字符串。下标 i 与 j 必须不同。

参数与返回值

makeEqual(words: string[]) → boolean

约束

  • 1 ≤ words.length ≤ 100
  • 1 ≤ words[i].length ≤ 100
  • words[i] 只包含小写英文字母 a–z。

来源：随任务提供的官方元数据（2026-09-02）。官方题目 ↗

示例 1

输入：words = ["abc","aabc","bc"]
输出：true

把 words[1] 的第一个 a 移到 words[2] 开头。三项都变为 "abc"。

示例 2

输入：words = ["ab","a"]
输出：false

不存在一系列合法移动，可以让这两个字符串相同。

核心洞察 / 每种字符都要平分

设字符串个数为 n，字母 c 在所有字符串中的总次数为 count[c]。每个目标字符串必须分到相同数量的 c，所以必须满足 count[c] % n === 0。对全部 26 种字母都成立时，就可以返回 true。

所有 c ∈ {a, …, z}：count[c] mod n = 0

原来的归属和排列可以通过移动调整。我们只需要判断能否完成分配，无须求操作序列或最少移动次数。

完整过程


  1. 建立长度为 26 的数组，初始值全部为 0。
  2. 遍历每个单词及其中每个字符，按字符到 a 的偏移累加计数。
  3. 逐项检查计数是否能被 words.length 整除。遇到任一非零余数，立即返回 false。
  4. 26 项全部满足条件，返回 true。未出现的字符计数是 0，同样能整除。


示例 1 中 a、b、c 总数分别为 3、3、3，n = 3，每个字符串各得一个 a、b、c。示例 2 中 a 有 2 个，b 只有 1 个，n = 2；b 无法平分，返回 false。


为什么正确
必要性：每次移动只改变字符所在的位置，不改变全局次数。若最终 n 个字符串都为 t，则每种字符的总数等于它在 t 中的次数乘以 n，因此总数必须能被 n 整除。


充分性：若 n = 1，不操作即可。若 n ≥ 2，先把所有字符移入一个字符串，作为暂存处；再按每种字母应得的次数，为其余 n−1 个字符串抽取字符并按字母顺序插入。暂存处剩余的字符数量正好构成同一份。它的顺序也可调整：将需要调整的字符暂移到另一个字符串，再移回指定位置；另一个字符串因此恢复原样。重复即可使全部字符串相同。故整除条件足够。


循环不变式：扫描任意前缀后，计数数组准确记录该前缀中的全部字母次数。每读取一个字母，只增加对应项，因此扫描结束时得到全局次数；随后逐项验证上述充要条件，返回值正确。


边界与复杂度
  • 只有一个字符串时总为 true；本来相等时允许零次操作。
  • 相同字母、不同长度也可能可行，例如 ["a","aaa"]。
  • 总长度可整除只是必要条件：["aa","bc"] 的总长度是 4，但 b、c 各一个，无法平分。
  • 设总字符数为 L，时间为 O(L + 26)，通常写作 O(L)；额外空间 O(26) = O(1)。计数最多 10,000，四份代码的整型范围均足够。


替代方案
使用哈希表或 Python Counter 记录出现过的字符，时间仍为 O(L)，空间为 O(k)，k 是不同字符数。本题字母表固定为 26，定长数组更直接。先检查总长度能否整除可提前排除部分输入，但不能代替逐字母检查。直接模拟搬运增加状态维护成本，对于布尔判断没有必要。


面试追问
  • 如果要求输出目标字符串？对每种字符重复 count[c] / n 次并按顺序拼接。n = 1 时也可以直接返回原字符串。
  • 如果扩展到任意 Unicode？用映射统计约定的字符单位，先明确按码点还是按用户可见字符处理。
  • 如果要求最少移动次数？当前条件只解决可行性；还需考虑每个字符串对目标的缺额、剩余以及插入顺序。


常见错误
  • 只检查各字符串长度，或只检查总长度。
  • 要求所有单词初始频次相同，忽略了跨单词搬运。
  • 把除数写成总长度或字符种类数；应是字符串个数 n。
  • 在统计完之前因临时计数不能整除就退出；后续字符仍可能补齐。
  • 把“任意位置插入”当成“只能追加”，误判排列不同的输入。

Java
class Solution {
    public boolean makeEqual(String[] words) {
        int[] counts = new int[26];
        for (String word : words) {
            for (int i = 0; i < word.length(); i++) {
                counts[word.charAt(i) - 'a']++;
            }
        }
        for (int count : counts) {
            if (count % words.length != 0) return false;
        }
        return true;
    }
}

from typing import List

class Solution:
    def makeEqual(self, words: List[str]) -> bool:
        counts = [0] * 26
        for word in words:
            for ch in word:
                counts[ord(ch) - ord('a')] += 1
        for count in counts:
            if count % len(words) != 0:
                return False
        return True


C++
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    bool makeEqual(vector<string>& words) {
        int counts[26] = {};
        for (const string& word : words) {
            for (char ch : word) {
                ++counts[ch - 'a'];
            }
        }
        const int n = static_cast<int>(words.size());
        for (int count : counts) {
            if (count % n != 0) return false;
        }
        return true;
    }
};
