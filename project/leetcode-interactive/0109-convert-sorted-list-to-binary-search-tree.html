Problem brief

把线性顺序
折叠成树

给定单链表头节点 head，其中节点值按升序排列。请将全部节点值转换为一棵高度平衡的二叉搜索树。

“高度平衡”表示任意节点的左右子树高度差不超过 1。答案不唯一；只要同时满足 BST、有序值完整保留和高度平衡即可。

  • 链表节点数范围：[0, 2 × 10⁴]
  • 节点值范围：[-10⁵, 10⁵]
  • 输入已经按升序排列

Core insight

用树的中序顺序
消费链表

面试首选：模拟中序遍历，O(n) 单次读取

先统计链表长度。构造区间 [left, right] 时，先递归完成左子树；此刻链表当前节点恰好就是根；读取并前进一步，再递归构造右子树。

build(left, right) = 左子树 → 消费 current 作为根 → current = current.next → 右子树

中序遍历 BST 会得到升序序列，而链表本来就是升序。两者节拍对齐，就不需要在每个子区间重新寻找链表中点。

两个不变量

  1. 进入 build(left, right) 时，current 指向这个子树中序序列的第一个未消费节点。
  2. 返回时，恰好消费 right - left + 1 个节点，且得到高度平衡 BST。

    Complete process

    三段节拍
    一条链表只走一遍

    PHASE A · COUNT

    先统计长度

    从头走到尾得到 n，用来确定每个子树应包含多少节点。此遍不改变真正的读取指针。

    PHASE B · LEFT

    先搭左半边

    区间中点决定左右子树节点数。递归构造左子树时，当前链表节点暂时不动。

    PHASE C · READ + RIGHT

    读根，再搭右边

    左子树返回后消费 current 作为根并前进一次，接着构造右子树，返回完整节点。

    复杂度

    时间O(n)
    递归栈O(log n)
    额外数组O(1)

    边界处理

    • head = null：长度为 0，直接返回空树。
    • 单节点：左右区间均为空，节点自然成为叶子。
    • 偶数节点：使用下中点，左右规模最多相差 1。
    • 上界 20,000：树高约为 15，不会形成线性递归深度。
    方案 时间 额外空间 取舍
    中序模拟（推荐） O(n) O(log n) 栈 单次顺序读取，最能利用链表特性；需要理解递归不变量。
    每层快慢指针找中点 O(n log n) O(log n) 栈 代码直观，但各层重复扫描链表。
    复制到数组再分治 O(n) O(n) 实现简单，却失去链表原地顺序读取的空间优势。

    class Solution {
    private ListNode current;

    public TreeNode sortedListToBST(ListNode head) {
        int length = 0;
        for (ListNode node = head; node != null; node = node.next) {
            length++;
        }

        current = head;
        return build(0, length - 1);
    }

    private TreeNode build(int left, int right) {
        if (left > right) {
            return null;
        }

        int mid = left + (right - left) / 2;
        TreeNode leftTree = build(left, mid - 1);

        TreeNode root = new TreeNode(current.val);
        current = current.next;

        root.left = leftTree;
        root.right = build(mid + 1, right);
        return root;
    }
}

    Interview follow-ups

    面试追问

    Q1 · 为什么不是 O(n log n)？

    统计长度一次 O(n)，构造时每个链表节点只被读取一次。区间递归只做 O(1) 的节点工作，总计仍是 O(n)。

    Q2 · 为什么一定平衡？

    每个区间用中点分成两部分，左右节点数最多相差 1；对每个子区间递归应用同样规则。

    Q3 · 为什么 BST 正确？

    构造顺序就是中序遍历顺序，消费的链表值严格递增，因此左子树值小于根，右子树值大于根。

    Q4 · 能否消除递归？

    可以显式模拟调用栈，但状态机会更复杂。由于树高 O(log n)，递归是面试中更清晰且安全的表达。

    Common mistakes

    常见错误

    先取根，再构造左树

    这会破坏中序顺序。必须先完成左子树，当前链表节点才对应根。

    忘记前进 current

    每创建一个根节点后必须执行 current = current.next，否则会重复使用同一个值。

    用固定序列化判断答案

    平衡 BST 不唯一。应验证中序序列、节点数量和每个节点的高度差。

    递归边界混用

    这里使用闭区间 [left, right]，空区间条件是 left > right。
