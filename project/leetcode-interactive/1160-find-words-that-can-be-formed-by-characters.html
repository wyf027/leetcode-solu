拼写单词

Find Words That Can Be Formed by Characters

任务目标

判断哪些单词能使用给定字符表中的字母拼出，并返回这些单词的长度总和。

简单数组哈希表字符串计数
Problem brief

题意

给定字符串数组 words 和字符串 chars。如果某个单词能完全由 chars 中的字符组成，则称它为“好单词”。拼写一个单词时，每个字符最多使用一次；判断下一个单词时，chars 可以重新完整使用。返回所有好单词的长度之和。

官方函数形式 countCharacters(words: string[], chars: string): integer

示例 1

输入：words = ["cat","bt","hat","tree"],
      chars = "atach"
输出：6
解释：可以形成 "cat" 和 "hat"，
      因此答案为 3 + 3 = 6。

示例 2

输入：words = ["hello","world","leetcode"],
      chars = "welldonehoneyr"
输出：10
解释：可以形成 "hello" 和 "world"，
      因此答案为 5 + 5 = 10。

约束

  • 1 <= words.length <= 1000
  • 1 <= words[i].length, chars.length <= 100
  • words[i] 和 chars 均只包含小写英文字母。

计数表：一次建库，逐词核对

核心洞察

一个单词可被拼出，当且仅当它对每个字母的需求次数，都不超过 chars 中该字母的可用次数。因为字符范围固定为 26 个小写英文字母，可用长度为 26 的数组充当计数表。

完整过程

  1. 遍历一次 chars，得到 26 个字母的库存计数 supply。
  2. 对每个 word 单独建立需求计数 need。
  3. 检查 26 个位置；若存在 need[i] > supply[i]，该单词无法拼出，立即停止检查它。
  4. 若全部位置均满足要求，将该单词长度加入答案。随后处理下一个单词，仍与原始 supply 比较。

正确性证明

充分性

若对每个字母都有 need[i] <= supply[i]，便能从库存中为单词的每次字母出现分配一个不同字符，因此该单词可以拼成。

必要性

若某字母满足 need[i] > supply[i]，单词需要的该字母比库存更多。每个库存字符只能使用一次，所以无论如何都无法拼成该单词。

算法恰好接受所有且仅接受可拼出的单词，并只累加这些单词的长度，因此最终答案正确。

复杂度与边界

时间

O(C + S + 26W)

C 为 chars 长度，S 为所有单词总长度，W 为单词数；26 为常数，可简写为 O(C + S)。

空间

O(26) = O(1)

只维护两个固定大小的字母计数数组。

关键边界

重复字母必须逐次计数；不同单词之间不共享消耗；单词一旦发现短缺即可提前结束。

Javaint[26]
class Solution {
    public int countCharacters(String[] words, String chars) {
        int[] supply = new int[26];
        for (char c : chars.toCharArray()) {
            supply[c - 'a']++;
        }

        int answer = 0;
        for (String word : words) {
            int[] need = new int[26];
            for (char c : word.toCharArray()) {
                need[c - 'a']++;
            }

            boolean good = true;
            for (int i = 0; i < 26; i++) {
                if (need[i] > supply[i]) {
                    good = false;
                    break;
                }
            }
            if (good) answer += word.length();
        }
        return answer;
    }
}

var countCharacters = function(words, chars) {
    const supply = new Int32Array(26);
    const base = "a".charCodeAt(0);

    for (const ch of chars) {
        supply[ch.charCodeAt(0) - base]++;
    }

    let answer = 0;
    for (const word of words) {
        const need = new Int32Array(26);
        for (const ch of word) {
            need[ch.charCodeAt(0) - base]++;
        }

        let good = true;
        for (let i = 0; i < 26; i++) {
            if (need[i] > supply[i]) {
                good = false;
                break;
            }
        }
        if (good) answer += word.length;
    }
    return answer;
};
Python 3list[26]
from typing import List

class Solution:
    def countCharacters(self, words: List[str], chars: str) -> int:
        supply = [0] * 26
        for ch in chars:
            supply[ord(ch) - ord("a")] += 1

        answer = 0
        for word in words:
            need = [0] * 26
            for ch in word:
                need[ord(ch) - ord("a")] += 1

            good = all(
                need[i] <= supply[i]
                for i in range(26)
            )
            if good:
                answer += len(word)

        return answer

class Solution {
public:
    int countCharacters(vector<string>& words, string chars) {
        array<int, 26> supply{};
        for (char c : chars) {
            ++supply[c - 'a'];
        }

        int answer = 0;
        for (const string& word : words) {
            array<int, 26> need{};
            for (char c : word) {
                ++need[c - 'a'];
            }

            bool good = true;
            for (int i = 0; i < 26; ++i) {
                if (need[i] > supply[i]) {
                    good = false;
                    break;
                }
            }
            if (good) answer += static_cast<int>(word.size());
        }
        return answer;
    }
};

替代方案与面试追问

替代方案

也可以为每个单词复制一份库存，然后逐字符递减；写法直观，但每个单词都要复制 26 个计数。排序后双指针也能判断，却引入排序成本，并会改动或复制字符串。

面试追问

  • 若字符不只限于小写字母，改用哈希表。
  • 若库存会跨单词真实消耗，选择顺序会影响答案，问题将不再是独立判断。
  • 若数据流持续到来，可预先保存库存计数并在线处理单词。

常见错误

  • 只检查字母是否出现，却忽略重复次数，例如库存只有一个 a 时错误接受 aa。
  • 处理完一个单词后不恢复库存，误把不同单词当成共享同一批字符。
  • 发现短缺后仍把部分长度计入答案；只能累加完整可拼出的单词。
  • 用嵌套搜索反复扫描 chars，使实现更复杂且容易漏掉“一次使用”的限制。
