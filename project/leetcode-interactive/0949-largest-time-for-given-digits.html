题目

给定一个恰好包含 4 个数字的数组 arr，每个元素必须且只能使用一次，把它们排列成 24 小时制时间 "HH:MM"。小时必须位于 00～23，分钟必须位于 00～59。返回能够组成的最晚时间；若不存在合法排列，返回空字符串。

示例 1
输入：arr = [1,2,3,4]
输出："23:41"
解释：可组成多个合法时间，其中 23:41 最晚。
示例 2
输入：arr = [5,5,5,5]
输出：""
解释：唯一数值排列 55:55 不是合法时间。
示例 3
输入：arr = [0,0,0,0]
输出："00:00"
示例 4
输入：arr = [0,0,1,0]
输出："10:00"

约束

  • arr.length == 4
  • 0 <= arr[i] <= 9

题解、证明、复杂度与四种语言代码都收在下面。

题解：枚举全部位置排列

核心洞察：只有 4 个位置，位置排列最多 4! = 24 种。直接枚举每个排列，把 HH × 60 + MM 作为统一评分，保留最大的合法评分即可。这个常数级搜索比复杂贪心更短，也更不容易遗漏重复数字。

完整过程

  1. 用四重循环选择互不相同的下标 i, j, k, l，从而覆盖所有位置排列。
  2. 计算 hour = 10×arr[i] + arr[j] 和 minute = 10×arr[k] + arr[l]。
  3. 只有当 hour < 24 且 minute < 60 时，候选时间才合法。
  4. 把候选换算成午夜后的分钟数；若大于当前最佳值，就更新答案。
  5. 若最终仍未找到候选，返回空字符串；否则补零格式化为固定的 HH:MM。

覆盖性

四重循环从四个不同下标依次填入四个位置，任意使用每个元素一次的排列都恰好对应一组下标，因此不会漏掉候选。

合法性

算法只在小时小于 24、分钟小于 60 时记录候选，所以被记录的字符串一定是合法 24 小时时间。

最优性

所有合法排列都被检查，并按分钟总数比较；最终保存的最大值不小于任一合法候选，因此就是最晚时间。

边界情况

  • 没有合法排列：返回 ""。
  • 全为 0：结果为 "00:00"。
  • 存在重复数字：按下标选择，仍能正确覆盖。
  • 小时或分钟需要前导零：格式化时统一补齐两位。

复杂度

一般写作时间 O(4!)、额外空间 O(1)；由于输入长度固定为 4，实际时间和空间均可视为 O(1)。

替代方案

也可以生成所有排列后逆序排序，返回第一个合法时间；或从 23:59 倒序检查数字多重集合。前者需要额外存储，后者最多检查 1440 个时间，都不如直接枚举简洁。

面试追问

  • 若数字数量扩大，如何用回溯与剪枝？
  • 若允许不使用全部数字，状态应如何表示？
  • 如何改为 12 小时制并处理 AM/PM？

常见错误

  • 只做贪心，最大数字放前面后没有正确回退。
  • 忘记分钟十位只能是 0～5。
  • 用字符串比较却没有补前导零。
  • 用数值去重而错误丢失重复数字的不同下标。

四语言完整代码

Java

官方签名
class Solution {
    public String largestTimeFromDigits(int[] arr) {
        int best = -1;
        for (int i = 0; i < 4; i++) {
            for (int j = 0; j < 4; j++) {
                if (j == i) continue;
                for (int k = 0; k < 4; k++) {
                    if (k == i || k == j) continue;
                    for (int l = 0; l < 4; l++) {
                        if (l == i || l == j || l == k) continue;
                        int hour = arr[i] * 10 + arr[j];
                        int minute = arr[k] * 10 + arr[l];
                        if (hour < 24 && minute < 60) {
                            best = Math.max(best, hour * 60 + minute);
                        }
                    }
                }
            }
        }
        if (best < 0) return "";
        return String.format("%02d:%02d", best / 60, best % 60);
    }
}

var largestTimeFromDigits = function(arr) {
    let best = -1;
    for (let i = 0; i < 4; i++) {
        for (let j = 0; j < 4; j++) {
            if (j === i) continue;
            for (let k = 0; k < 4; k++) {
                if (k === i || k === j) continue;
                for (let l = 0; l < 4; l++) {
                    if (l === i || l === j || l === k) continue;
                    const hour = arr[i] * 10 + arr[j];
                    const minute = arr[k] * 10 + arr[l];
                    if (hour < 24 && minute < 60) {
                        best = Math.max(best, hour * 60 + minute);
                    }
                }
            }
        }
    }
    if (best < 0) return "";
    const pad = value => String(value).padStart(2, "0");
    return pad(Math.floor(best / 60)) + ":" + pad(best % 60);
};

class Solution {
public:
    string largestTimeFromDigits(vector<int>& arr) {
        int best = -1;
        for (int i = 0; i < 4; ++i) {
            for (int j = 0; j < 4; ++j) {
                if (j == i) continue;
                for (int k = 0; k < 4; ++k) {
                    if (k == i || k == j) continue;
                    for (int l = 0; l < 4; ++l) {
                        if (l == i || l == j || l == k) continue;
                        int hour = arr[i] * 10 + arr[j];
                        int minute = arr[k] * 10 + arr[l];
                        if (hour < 24 && minute < 60) {
                            best = max(best, hour * 60 + minute);
                        }
                    }
                }
            }
        }
        if (best < 0) return "";
        char answer[6];
        snprintf(answer, sizeof(answer), "%02d:%02d", best / 60, best % 60);
        return string(answer);
    }
};
