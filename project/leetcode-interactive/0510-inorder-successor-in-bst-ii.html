二叉搜索树中的
中序后继 II

节点多了一根指向父节点的指针。无需从根节点重新搜索，只沿结构本身观察“中序遍历的下一站”。先在实验区亲手移动指针，再决定是否展开题解。

Problem brief

题意与约束

每个节点均携带 parent 指针；返回值也是节点对象，不是节点值。

给定一棵二叉搜索树中的节点 node。节点结构包含 val、left、right 和指向父节点的 parent。

请返回该节点在这棵树的中序遍历序列中的后继节点，也就是严格出现在它之后的第一个节点。如果它已经是中序序列的最后一个节点，返回 null。

inorderSuccessor(node: Node): Node | null

输入展示中的 tree 用层序数组描述整棵树，node 用目标节点值定位；实际提交函数接收的是节点引用。

约束

  • 树中节点数在 [1, 104] 范围内。
  • -105 ≤ Node.val ≤ 105。
  • 所有节点值互不相同，且满足二叉搜索树性质。
  • node 非空，并且确实属于给定的树。
  • 每个非根节点的 parent 正确指向其父节点。

输入

输出

Core insight

完整题解

右子树向左到底；
否则向上等一次左转。
01

先看右子树

若 node.right 存在，后继一定在右子树中。先走到右孩子，再不断沿 left 向下，返回其中最小的节点。

02

否则沿 parent 上行

若没有右孩子，就离开已经遍历完的祖先链。只要当前节点仍是父节点的右孩子，就继续向上移动。

03

捕捉第一次左转

当当前节点第一次成为其父节点的左孩子时，这个父节点尚未在中序遍历中出现，因此它就是最近的后继。

04

到根之上仍没找到

若一路上行直到 parent == null，说明原节点位于整棵树中序序列的末尾，返回 null。

正确性说明

  1. 有右子树：中序遍历会在访问当前节点后进入其右子树。右子树中最先被访问的是最左节点，所以返回该节点正确。
  2. 无右子树：当前节点及其向上的连续右孩子链都已被完整访问。第一个把这条链放在左子树中的祖先尚未访问，并且比更高祖先更早出现，所以它恰为后继。
  3. 不存在这样的祖先：当前节点位于所有祖先的右侧，向上直至越过根，说明没有任何未访问节点，返回 null 正确。
O(h)时间复杂度；最坏沿一条树高路径移动
O(1)额外空间；只维护当前节点引用

Implementations

四语言完整代码

题目平台预先定义 Node；提交时只需保留 Solution。

JavaLeetCode 提交形式
/*
// Definition for a Node.
class Node {
    public int val;
    public Node left;
    public Node right;
    public Node parent;
};
*/

class Solution {
    public Node inorderSuccessor(Node node) {
        if (node.right != null) {
            node = node.right;
            while (node.left != null) {
                node = node.left;
            }
            return node;
        }

        while (node.parent != null
                && node == node.parent.right) {
            node = node.parent;
        }
        return node.parent;
    }
}

    Node* left;
    Node* right;

class Solution {
public:
    Node* inorderSuccessor(Node* node) {
        if (node->right != nullptr) {
            node = node->right;
            while (node->left != nullptr) {
                node = node->left;
            }
            return node;
        }

        while (node->parent != nullptr
                && node == node->parent->right) {
            node = node->parent;
        }
        return node->parent;
    }
};

边界情况

  • 节点有右孩子，但右孩子没有左链：直接返回右孩子。
  • 节点是根且无右子树：返回 null。
  • 节点位于深层左链：最近父节点可能立即就是答案。
  • 节点位于最右链：持续上行后返回 null。

替代方案

  • 先沿 parent 找到根，再按 BST 值搜索候选祖先，仍为 O(h)，但路径重复。
  • 从根做完整中序遍历可求答案，但需 O(n) 时间及栈空间，没有利用 parent 指针。
  • 若允许维护额外索引，可预存中序序列，但不适合单次查询。

常见错误

  • 返回节点值而不是 Node 引用。
  • 有右子树时只返回右孩子，忘记继续向左到底。
  • 向上时判断成 node == parent.left 才继续，方向恰好反了。
  • 根节点之上直接解引用空 parent。

面试追问

  • 如果节点没有 parent 指针，如何利用根节点和 BST 性质求后继？
  • 若允许重复值，节点身份比较与值比较应如何区分？
  • 如何对称地求中序前驱？
  • 大量查询时，是否值得建立中序双向链表或跳表索引？

机制迁移

  • “有右向左到底”与“无右向上等左转”互为完整分支。
  • 求前驱时镜像所有方向：有左向右到底；否则向上等右转。
  • parent 指针把递归调用栈显式编码进了数据结构。

复杂度细节

  • h 是树高；平衡 BST 中为 O(log n)。
  • 退化为链时最坏为 O(n)。
  • 算法只重用输入节点指针，不分配随树高增长的容器。
