训练计划 I

原地调整训练行动的顺序：奇数在前、偶数在后。用双指针把一次线性扫描讲清楚。

跳到交互练习

题意

给定整数数组 actions，请调整其顺序，使所有奇数位于所有偶数之前。奇数之间与偶数之间的相对顺序均不作要求。

示例

输入：actions = [1,2,3,4]

输出：[1,3,2,4]（或其他奇数在前的排列）

约束

  • 0 <= actions.length <= 50000
  • 0 <= actions[i] <= 10000

核心洞察

把“放错位置”的一对数直接交换：左侧应保留奇数，右侧应保留偶数。两个指针只向中间移动，因此每个元素至多被检查一次。

不变量：左指针左边均为奇数；右指针右边均为偶数。

分步交互

观察双指针如何发现并交换错误位置的元素。

快捷键：Enter

完整过程

  1. 令 left = 0、right = n - 1。
  2. 左侧已经是奇数时，left 右移；右侧已经是偶数时，right 左移。
  3. 若两指针尚未相遇，此时左边为偶数、右边为奇数，交换它们并继续收缩区间。

边界

  • 空数组、只有一个元素：循环不会执行。
  • 全奇数或全偶数：只会移动一个指针，无需交换。
  • 不要要求稳定性；本题明确允许改变同类元素的相对顺序。

复杂度

时间 O(n)：双指针总共线性移动。

额外空间 O(1)：只使用常数个变量。

替代方案

可新建数组，先收集奇数再收集偶数，写法直观但需 O(n) 额外空间；若题目要求稳定顺序，这个方案更适合。

官方签名代码

class Solution {
    public int[] trainPlan(int[] actions) {
        int left = 0, right = actions.length - 1;
        while (left < right) {
            while (left < right && (actions[left] & 1) == 1) left++;
            while (left < right && (actions[right] & 1) == 0) right--;
            int temp = actions[left]; actions[left] = actions[right]; actions[right] = temp;
        }
        return actions;
    }
}
var trainPlan = function(actions) {
  let left = 0, right = actions.length - 1;
  while (left < right) {
    while (left < right && actions[left] % 2 === 1) left++;
    while (left < right && actions[right] % 2 === 0) right--;
    [actions[left], actions[right]] = [actions[right], actions[left]];
  }
  return actions;
};

class Solution {
public:
    vector<int> trainPlan(vector<int>& actions) {
        int left = 0, right = actions.size() - 1;
        while (left < right) {
            while (left < right && actions[left] % 2) ++left;
            while (left < right && !(actions[right] % 2)) --right;
            swap(actions[left], actions[right]);
        }
        return actions;
    }
};

追问与常见错误

追问

若要求奇偶元素内部相对顺序不变？使用额外数组，或采用稳定划分；需要权衡空间与实现复杂度。

常见错误

  • 内层扫描未检查 left < right，造成越界。
  • 交换后没有继续移动，或循环条件写成 left <= right。
  • 误以为结果必须与示例数组完全一致。

测试与验证区

建议覆盖空数组、单元素、全奇数、全偶数、交错奇偶和大量重复值。
