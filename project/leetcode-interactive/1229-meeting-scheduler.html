Meeting Scheduler

两个人各自有一些空闲时间。你需要找出最早一段足够长的共同空档，并返回会议的开始与结束时刻。

阅读题目打开时间轴
Problem

题目说明

给定两个人的空闲时间段列表 slots1 与 slots2，以及会议需要持续的正整数分钟数 duration。每个时间段 [start, end] 表示从 start 到 end 的可用区间。

请返回能够容纳该会议的最早共同时间段 [start, start + duration]。如果不存在满足要求的共同空档，返回空数组 []。

注意：同一个人的空闲时间段彼此不重叠；输入顺序不保证已经按开始时间排序。会议结束时刻等于共同区间端点是允许的。

函数签名

minAvailableDuration( slots1: integer[][], slots2: integer[][], duration: integer ) -> integer[]

目标

返回按时间最早的长度恰为 duration 的共同会议区间，而不是整个交集。

示例 1

找到会议
输入：slots1 = [[10,50],[60,120],[140,210]], slots2 = [[0,15],[60,70]], duration = 8 输出：[60,68]

最早的可用交集是 [60,70]，其中前 8 分钟即 [60,68]。

示例 2

无解
输入：slots1 = [[10,50],[60,120],[140,210]], slots2 = [[0,15],[60,70]], duration = 12 输出：[]

两人最长的共同空档只有 10 分钟，无法安排 12 分钟的会议。

约束

  • 1 <= slots1.length, slots2.length <= 104
  • slots1[i].length == slots2[j].length == 2
  • slots1[i][0] < slots1[i][1]，且 slots2[j][0] < slots2[j][1]
  • 0 <= slots1[i][k], slots2[j][k] <= 109
  • 1 <= duration <= 106
  • 同一个人的任意两个空闲时间段互不重叠。

Solution

Core insight

排序 + 双指针

先按开始时间排序两组区间。每次只比较两指针指向的区间：交集从较晚的开始时刻起，到较早的结束时刻止。

核心洞察

若当前交集长度至少为 duration，因为所有此前可能更早的组合都已被排除，直接返回从交集起点开始的会议即可。

如何前进

若交集太短，结束更早的区间不可能再与对方当前或后续区间形成更长的有效交集，因此移动它对应的指针。

完整过程

1
分别排序

将 slots1 和 slots2 按区间开始时间升序排列。

2
计算交集

令 start = max(a.start, b.start)，end = min(a.end, b.end)。

3
检查时长

若 end - start >= duration，返回 [start, start + duration]。

4
淘汰较早结束者

若 a.end < b.end，移动 A 指针；否则移动 B 指针。任一列表扫描完仍未找到则返回空数组。

正确性说明

引理：当当前区间 A 的结束时刻不晚于当前区间 B 时，若两者不能形成足够长的会议，A 与 B 以及 B 之后的任何区间都不可能形成更早且有效的会议。

理由：后续 B 区间的开始时间不会更早，而 A 的结束时间固定，因此交集只会不变或更短。故丢弃 A 不会遗漏答案；另一方向对称成立。

结论：算法每一步都安全淘汰一个不可能产生答案的区间。找到的第一个可行交集具有最早开始时刻，返回其前 duration 分钟即为题目要求的答案。

复杂度

时间：O(n log n + m log m)，排序占主导；双指针扫描为 O(n + m)。

空间：取决于语言排序实现。忽略排序栈时可视为 O(1) 额外扫描空间；部分语言排序需要 O(log n + log m) 或更多辅助空间。

边界情况

  • 两个区间只在端点相接，交集长度为 0。
  • 交集长度恰好等于 duration。
  • 所有区间完全错开。
  • 答案出现在任一列表的最后一个区间。
  • 时间值接近 109。

替代方案

暴力枚举

比较所有 n × m 对区间，正确但最坏达到 O(nm)，无法应对每组一万段的规模。

事件扫描线

把所有端点转为事件再维护同时可用人数，能做但状态与端点规则更复杂，本题没有必要。

区间树

适合大量动态查询；对于一次性的两组静态输入，构建成本与实现复杂度都不划算。

import java.util.*;

class Solution {
    public List<Integer> minAvailableDuration(
            int[][] slots1, int[][] slots2, int duration) {
        Arrays.sort(slots1, Comparator.comparingInt(a -> a[0]));
        Arrays.sort(slots2, Comparator.comparingInt(a -> a[0]));

        int i = 0, j = 0;
        while (i < slots1.length && j < slots2.length) {
            int start = Math.max(slots1[i][0], slots2[j][0]);
            int end = Math.min(slots1[i][1], slots2[j][1]);

            if (end - start >= duration) {
                return Arrays.asList(start, start + duration);
            }

            if (slots1[i][1] < slots2[j][1]) {
                i++;
            } else {
                j++;
            }
        }
        return Collections.emptyList();
    }
}

常见错误

  • 忘记排序就直接使用双指针。
  • 把可行条件写成 end - start > duration，漏掉恰好相等。
  • 返回整个交集，而不是长度恰为 duration 的会议。
  • 按开始更早的区间移动指针，而非结束更早者。
  • 没有在任一指针到达末尾后返回空数组。
