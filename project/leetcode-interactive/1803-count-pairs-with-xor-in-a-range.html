Count Pairs With XOR in a Range

两个数，逐位比较；一个区间，筛选数对。先理解目标，再打开推导。

官方题目 ↗

01 / 题目

给定从 0 开始编号的整数数组 nums 和整数 low、high。统计下标满足 0 ≤ i < j < nums.length，且 low ≤ (nums[i] XOR nums[j]) ≤ high 的数对数量。

统计的是下标对：相同数值出现在不同位置时仍分别参与计数。XOR 的每一位在两个输入位不同时为 1，相同时为 0。

官方示例 1

nums = [1,4,2,7], low = 2, high = 6
输出：6

六个下标对的异或值依次为：
(0,1)→5，(0,2)→3，(0,3)→6，
(1,2)→6，(1,3)→3，(2,3)→5。全部位于区间内。

官方示例 2

nums = [9,8,4,2,1], low = 5, high = 14
输出：8

有效下标对：
(0,2)→13，(0,3)→11，(0,4)→8，
(1,2)→12，(1,3)→10，(1,4)→9，
(2,3)→6，(2,4)→5。

约束与签名

  • 1 ≤ nums.length ≤ 2 × 10⁴
  • 1 ≤ nums[i] ≤ 2 × 10⁴
  • 1 ≤ low ≤ high ≤ 2 × 10⁴

countPairs(nums, low, high) → 整数

02 / 思考停靠点

枚举所有下标对需要多少次比较？比较两个二进制数的大小时，哪一个不同位最先决定结果？

下面的独立题解包含交互演示与完整实现，默认收起。

03 / 题解：按前缀整批计数

核心洞察

把闭区间拆成两个严格上界：F(high + 1) − F(low)，其中 F(K) 是异或值小于 K 的数对数。对当前 x，只查询已经出现的数；查询结束后再插入 x，就自然满足 i < j。

用 01 字典树存放已出现数字的 15 位二进制（位 14 到 0），每个节点记录经过它的数字个数。查询 less(x, K) 时，从最高位开始，只沿“异或前缀与 K 相等”的路径继续：

  • K 当前位为 0：异或位只能为 0，沿与 x 当前位相同的分支继续；另一支必然超界。
  • K 当前位为 1：异或位为 0 的整棵子树已严格更小，直接加上它的 count；异或位为 1 的分支仍相等，继续向下。
  • 走到空节点就结束。全部位处理完后，仍相等的数字不能计入，因为要求严格小于 K。

逐位分流台 / 一次 less 查询

用候选数字展开字典树的节点内容。绿色整支接收，黄色继续比较，棕色丢弃。实现中只读取子树 count，不逐个扫描数字。

完整过程

  1. 建立空树，答案为 0。
  2. 对 nums 中每个 x，累加 less(x, high + 1) − less(x, low)。
  3. 将 x 的 15 位路径插入树，每个经过节点的 count 加 1。
  4. 遍历结束返回答案。

示例 1 中，处理 1、4、2、7 时新增有效对数分别为 0、1、2、3，总计 6。处理 x=7 时树中只有 [1,4,2]，与它们的异或分别为 6、3、5，均被区间接收。

正确性

查询不变式：每轮开始，当前节点恰好代表高位异或前缀与 K 相同的候选数；已加入结果的子树，其前缀已经严格小于 K。K 位为 0 时只保留相等分支；K 位为 1 时把更小分支完整计数并继续相等分支。各子树互不重叠，因此不漏计、不重复。末尾排除相等路径，所得正是严格小于 K 的数量。

外层不变式：处理下标 j 之前，树中恰有 nums[0..j−1]，且每次插入保留出现次数。查询差值恰好覆盖以 j 为右端点的有效下标对。所有 i < j 的数对只会在其右端点被统计一次，因此最终答案正确。

边界与复杂度

  • n=1 时空树查询返回 0。重复值要累计频次，不能只用集合。
  • low=high 仍适用；闭区间右端用 high+1 转为严格小于。
  • nums[i]、high+1 均小于 2¹⁵，固定 15 位足够；此实现不可直接用于超出约束的整数。
  • 时间 O(nB)，空间 O(nB)，B=15。每个数两次查询、一次插入。
  • 答案至多 n(n−1)/2=199,990,000，32 位有符号整数足够。扩大 n 时 Java/C++ 需考虑 64 位计数。

替代方案

暴力枚举 i < j：时间 O(n²)、额外空间 O(1)，容易理解，但在 n=20,000 时最多约两亿次比较。另一方向是在 2¹⁵ 大小的值域上做异或卷积（FWHT），复杂度约 O(U log U+n)、空间 O(U)，需要处理有序对与自身配对，实现及证明成本更高。

面试追问

  • 怎样支持删除？沿路径减 count；查询时忽略计数为 0 的分支，可扩展为滑动窗口。
  • 数值达到 10⁹ 怎么办？扩展位宽；JavaScript 位运算有 32 位语义，更大非负整数应考虑 BigInt。
  • 为何不把所有数先插入？那会得到双向统计，并需处理自身配对；边查边插更直接。

常见错误

把 F(high) 当成闭区间上界；查询前插入当前元素；K 位为 1 时只选一支而忘了子树计数；叶子处把“等于 K”也加进去；树中去重而丢失频次；C++ 在 vector 扩容后继续使用旧引用。下面实现用节点下标避免最后一种问题。

Java

class Solution {
    static class Node {
        Node[] next = new Node[2];
        int count;
    }
    private void insert(Node root, int x) {
        Node node = root;
        for (int b = 14; b >= 0; b--) {
            int bit = (x >> b) & 1;
            if (node.next[bit] == null) node.next[bit] = new Node();
            node = node.next[bit];
            node.count++;
        }
    }
    private int less(Node node, int x, int k) {
        int result = 0;
        for (int b = 14; b >= 0 && node != null; b--) {
            int bit = (x >> b) & 1;
            if (((k >> b) & 1) == 1) {
                Node same = node.next[bit];
                if (same != null) result += same.count;
                node = node.next[bit ^ 1];
            } else {
                node = node.next[bit];
            }
        }
        return result;
    }
    public int countPairs(int[] nums, int low, int high) {
        Node root = new Node();
        int answer = 0;
        for (int x : nums) {
            answer += less(root, x, high + 1) - less(root, x, low);
            insert(root, x);
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @param {number} low
 * @param {number} high
 * @return {number}
 */
var countPairs = function(nums, low, high) {
    const makeNode = () => ({ next: [null, null], count: 0 });
    const root = makeNode();
    function less(x, k) {
        let node = root, result = 0;
        for (let b = 14; b >= 0 && node !== null; b--) {
            const bit = (x >>> b) & 1;
            if ((k >>> b) & 1) {
                result += node.next[bit]?.count ?? 0;
                node = node.next[bit ^ 1];
            } else {
                node = node.next[bit];
            }
        }
        return result;
    }
    let answer = 0;
    for (const x of nums) {
        answer += less(x, high + 1) - less(x, low);
        let node = root;
        for (let b = 14; b >= 0; b--) {
            const bit = (x >>> b) & 1;
            if (node.next[bit] === null) node.next[bit] = makeNode();
            node = node.next[bit];
            node.count++;
        }
    }
    return answer;
};

Python

from typing import List

class Node:
    def __init__(self):
        self.next = [None, None]
        self.count = 0

class Solution:
    def countPairs(self, nums: List[int], low: int, high: int) -> int:
        root = Node()

        def less(x: int, k: int) -> int:
            node, result = root, 0
            for b in range(14, -1, -1):
                if node is None:
                    break
                bit = (x >> b) & 1
                if (k >> b) & 1:
                    same = node.next[bit]
                    if same is not None:
                        result += same.count
                    node = node.next[bit ^ 1]
                else:
                    node = node.next[bit]
            return result

        answer = 0
        for x in nums:
            answer += less(x, high + 1) - less(x, low)
            node = root
            for b in range(14, -1, -1):
                bit = (x >> b) & 1
                if node.next[bit] is None:
                    node.next[bit] = Node()
                node = node.next[bit]
                node.count += 1
        return answer

C++

#include <vector>
using namespace std;

class Solution {
    struct Node {
        int next[2] = {-1, -1};
        int count = 0;
    };
    vector<Node> trie;
    void insert(int x) {
        int node = 0;
        for (int b = 14; b >= 0; --b) {
            int bit = (x >> b) & 1;
            if (trie[node].next[bit] == -1) {
                int id = static_cast<int>(trie.size());
                trie.emplace_back();
                trie[node].next[bit] = id;
            }
            node = trie[node].next[bit];
            ++trie[node].count;
        }
    }
    int less(int x, int k) const {
        int node = 0, result = 0;
        for (int b = 14; b >= 0 && node != -1; --b) {
            int bit = (x >> b) & 1;
            if ((k >> b) & 1) {
                int same = trie[node].next[bit];
                if (same != -1) result += trie[same].count;
                node = trie[node].next[bit ^ 1];
            } else {
                node = trie[node].next[bit];
            }
        }
        return result;
    }
public:
    int countPairs(vector<int>& nums, int low, int high) {
        trie.clear();
        trie.emplace_back();
        int answer = 0;
        for (int x : nums) {
            answer += less(x, high + 1) - less(x, low);
            insert(x);
        }
        return answer;
    }
};
