词典中最长的单词

从一个字母出发，每次只在末尾增加一个字母。你能在给定词典里，找到一条完整不断裂的构词链吗？

题意

给定字符串数组 words，它表示一本英语词典。请返回其中最长的可构造单词：从左到右构造时，它的每一个非空前缀都必须出现在 words 中。

若最长答案不止一个，返回字典序最小的那个；若不存在可构造单词，返回空字符串。每一步只能把一个新字母添加到已有单词的末尾。

示例 1
输入：words = ["w","wo","wor","worl","world"]
输出："world"
解释："w" → "wo" → "wor" → "worl" → "world"，构词链完整。
示例 2
输入：words = ["a","banana","app","appl","ap","apply","apple"]
输出："apple"
解释："apple" 与 "apply" 都可构造，但 "apple" 的字典序更小。

约束

  • 1 <= words.length <= 1000
  • 1 <= words[i].length <= 30
  • words[i] 只包含小写英文字母
函数签名

Full explanation

排序 + 可构造集合

让短单词先被处理，再用哈希集合记录已经确认可构造的单词。

核心洞察

把单词按“长度升序、同长度字典序升序”排列。处理单词 word 时，若它只有一个字母，或 word.slice(0, -1) 已经可构造，那么 word 也可构造。

只查直接前缀就够了：直接前缀能进入集合，本身就意味着它更短的所有前缀已经逐层通过检查。

完整过程

01
排序
长度更短的词先处理；长度相同则字典序更小的词先处理。
02
维护集合
用 buildable 保存已经确认可逐步构造的单词。
03
检查直接前缀
单字母词天然是起点；其他词只需检查去掉最后一个字符后的前缀。
04
更新答案
可构造词更长时替换答案；同长时保留字典序更小者。

正确性证明

引理：每个加入 buildable 的单词，其全部非空前缀都在词典中。

按单词长度归纳。长度为 1 的单词自身在词典中，结论成立。设所有更短、已加入集合的单词都满足结论。长度大于 1 的 word 只有在直接前缀 prefix 已在集合时才会加入；由归纳假设，prefix 的全部非空前缀都在词典中，再加上 word 自身，故 word 的全部非空前缀都在词典中。

完备性：若某个词确实可构造，它的直接前缀也可构造且长度更短，因此排序后一定已先进入集合，该词不会被漏掉。

最优性：算法检查所有可构造词，并按长度优先、字典序决胜更新答案，因此最终答案恰为最长且字典序最小的可构造单词。

复杂度

时间：O(n log n · L)，其中 L 是单词最大长度；排序比较与字符串处理计入字符成本。

空间：O(n · L)，用于可构造集合与排序存储。

边界情况

  • 只有长词、缺少单字母起点：返回空串。
  • 多个同长答案：选择字典序最小者。
  • 单个单字母词：它就是答案。
  • 大量共享前缀：集合检查仍保持清晰。

替代方案

可把所有单词插入字典树，再只沿“每个经过节点都标记为完整单词”的路径 DFS。该方案适合复用前缀结构，但实现与额外节点管理更复杂。

也可对每个词枚举全部前缀并查哈希集合，思路直接，但重复检查较多。

import java.util.Arrays;
import java.util.Comparator;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public String longestWord(String[] words) {
        Arrays.sort(words, Comparator
                .comparingInt(String::length)
                .thenComparing(Comparator.naturalOrder()));

        Set<String> buildable = new HashSet<>();
        String answer = "";

        for (String word : words) {
            String prefix = word.substring(0, word.length() - 1);
            if (word.length() == 1 || buildable.contains(prefix)) {
                buildable.add(word);
                if (word.length() > answer.length()
                        || (word.length() == answer.length()
                        && word.compareTo(answer) < 0)) {
                    answer = word;
                }
            }
        }
        return answer;
    }
}

var longestWord = function(words) {
    words.sort((a, b) => a.length - b.length || a.localeCompare(b));

    const buildable = new Set();
    let answer = "";

    for (const word of words) {
        const prefix = word.slice(0, -1);
        if (word.length === 1 || buildable.has(prefix)) {
            buildable.add(word);
            if (
                word.length > answer.length ||
                (word.length === answer.length && word < answer)
            ) {
                answer = word;
            }
        }
    }
    return answer;
};
from typing import List


class Solution:
    def longestWord(self, words: List[str]) -> str:
        words.sort(key=lambda word: (len(word), word))

        buildable = set()
        answer = ""

        for word in words:
            prefix = word[:-1]
            if len(word) == 1 or prefix in buildable:
                buildable.add(word)
                if (len(word) > len(answer) or
                        (len(word) == len(answer) and word < answer)):
                    answer = word

        return answer
#include <algorithm>
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    string longestWord(vector<string>& words) {
        sort(words.begin(), words.end(), [](const string& a, const string& b) {
            if (a.size() != b.size()) return a.size() < b.size();
            return a < b;
        });

        unordered_set<string> buildable;
        string answer;

        for (const string& word : words) {
            string prefix = word.substr(0, word.size() - 1);
            if (word.size() == 1 || buildable.count(prefix)) {
                buildable.insert(word);
                if (word.size() > answer.size()
                    || (word.size() == answer.size() && word < answer)) {
                    answer = word;
                }
            }
        }
        return answer;
    }
};

常见错误

  • 只检查单词是否有任意前缀，而不是完整的逐层前缀链。
  • 排序只看长度，忘记字典序决胜规则。
  • 把缺少起点的长词错误地加入可构造集合。
  • 同长度时无条件覆盖答案，导致返回字典序更大的词。
