Minimum Absolute Difference in BST

给定二叉搜索树根节点 root，返回树中任意两个不同节点值之间的最小绝对差。差值为正数。

题目说明

参数：root: TreeNode；返回：整数。

约束

  • 节点数：[2, 10⁴]
  • 0 ≤ Node.val ≤ 10⁵

核心洞察与过程

BST 的中序遍历得到递增序列。最小差必来自相邻元素：按左、根、右遍历，保留前驱，每次用当前值减前驱并更新答案。

正确性

若最优值对 a<b 不相邻，中间存在 c，则 c-a<b-a，产生矛盾。因此检查所有中序相邻对充分且必要。

边界、复杂度、替代方案

  • 两个节点只比较一次；值可为 0，不能用 0 充当“无前驱”。
  • 时间 O(n)，递归空间 O(h)。
  • 倾斜树可用显式栈；Morris 遍历可达 O(1) 辅助空间。
  • 普通二叉树可收集后排序，时间 O(n log n)。

面试追问与常见错误

  • 允许重复值时答案可为 0，本算法仍适用。
  • 只比较父子节点会漏解；过早覆盖前驱也会出错。
  • 若不是 BST，可排序或用有序集合维护前驱、后继。

Java

class Solution {
 Integer prev; int ans = Integer.MAX_VALUE;
 public int getMinimumDifference(TreeNode root) {
  dfs(root); return ans;
 }
 void dfs(TreeNode n) {
  if (n == null) return;
  dfs(n.left);
  if (prev != null) ans = Math.min(ans, n.val-prev);
  prev=n.val; dfs(n.right);
 }
}

Python

class Solution:
 def getMinimumDifference(self, root):
  prev, ans = None, float("inf")
  def dfs(node):
   nonlocal prev, ans
   if not node: return
   dfs(node.left)
   if prev is not None:
    ans = min(ans, node.val-prev)
   prev = node.val
   dfs(node.right)
  dfs(root)
  return ans

  if (!n) return;
  dfs(n->left);
  if (prev) ans=min(ans,n->val-prev->val);
  prev=n; dfs(n->right);
