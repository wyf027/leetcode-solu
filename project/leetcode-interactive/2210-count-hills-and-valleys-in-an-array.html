统计数组中峰和谷的数量

Count Hills and Valleys in an Array

一段平坦的地形，究竟算几个峰谷？先读定义，再动手观察。

01 / PROBLEM

题目与约定

给定一个下标从 0 开始的整数数组 nums。对于某个位置，分别向左、向右寻找最近的值不相等的邻居：两边都比它小时，它属于一个峰；两边都比它大时，它属于一个谷。

相邻且值相同的位置，若属于峰或谷，只算同一个峰或谷。左右必须都能找到不相等的邻居，否则不计入。返回峰与谷的总数量。

参数与返回值

countHillValley(nums: integer[]) → integer

nums：输入整数数组；返回值：峰数 + 谷数。

官方约束

  • 3 ≤ nums.length ≤ 100
  • 1 ≤ nums[i] ≤ 100

LeetCode 官方题目 ↗ · 题意、示例与约束依据随任务提供的官方元数据转述。

官方示例

示例 1

输入：nums = [2,4,1,1,6,5]
输出：3

下标 1 的 4 是峰；下标 2、3 的两个 1 共同构成一个谷；下标 4 的 6 是峰。两端缺少一侧邻居，不计入。因此总计 3。

示例 2

输入：nums = [6,6,5,5,4,1]
输出：0

开头两个 6 没有左侧不相等邻居，末尾 1 没有右侧邻居。中间的 5 与 4 都是一侧较大、另一侧较小，均不构成峰或谷。

03 / THINK FIRST

准备好，再翻开解法

试着说明：相邻相等值为什么只能计数一次？解法、交互演示与代码都在下方折叠区域。

题解 · 只在方向反转时计数

核心洞察：忽略相邻相等值产生的水平边，剩下的变化只有上升和下降。上升后转为下降形成一个峰；下降后转为上升形成一个谷。持续同方向移动不会增加峰谷。

保存上一个非零方向 prev。扫描相邻的两项，当前方向记为 dir：上升为 1，下降为 −1，相等为 0。遇到 0 直接跳过；遇到与已存在的 prev 不同的非零方向，就将答案加 1，再更新 prev。

完整过程

  1. 初始化答案 ans = 0，方向 prev = 0，表示还没有非零变化。
  2. 从下标 1 起，比较 nums[i] 与 nums[i−1]，得到当前方向。
  3. 若相等，继续扫描，保留原来的 prev。
  4. 若当前方向非零，并且 prev 已建立且与它相反，就发现一个峰或谷，答案加一。
  5. 用当前非零方向更新 prev。扫描结束返回答案。

示例 1 的方向是 ↑ ↓ → ↑ ↓。三个非零方向反转分别对应峰 4、谷 [1,1]、峰 6，因此答案为 3。

正确性说明

把每段连续相同的值视为一个平台。相邻平台的高度必不相等，因此平台间的方向总是非零。内部平台是峰，当且仅当进入它的方向向上、离开它的方向向下；谷的情况恰好相反。因此峰谷与非零方向序列中的相邻反转一一对应。

扫描过程中，prev 始终是已读边中最后一个非零方向，ans 始终是已读非零方向中的反转次数。水平边不改变它们；非零边只需与 prev 比较即可判断是否新增一次反转。由此不变式，扫描结束时答案就是所有峰谷数量。首尾平台没有两侧方向，无法形成一次反转，因而不会误计。

边界与复杂度

  • 全相等：没有非零方向，结果为 0。
  • 单调数组（含平台）：没有方向反转，结果为 0。
  • 平台峰谷：水平边被跳过，只会在离开平台时计数一次。
  • 开头的水平边不会建立方向；结尾的水平边不会新增反转。
  • 最短合法长度是 3；峰谷最多为 n−2，严格交替时可达到。
  • 时间 O(n)，额外空间 O(1)；不修改输入。可视化为了支持回退保存各步状态，使用 O(n) 空间，不属于提交算法的空间开销。

替代方案

先压缩连续重复值，再对压缩数组中的每个内部元素比较左右两项，时间 O(n)、额外空间 O(n)，更直观。也可对每个平台向两侧寻找不相等邻居，但必须避免重复计数；若对每个位置重复向外扫描，最坏可达 O(n²)。

常见错误

  • 只比较紧邻的三个元素，漏掉跨平台的峰谷。
  • 相等时把 prev 置 0，丢失进入平台的方向。
  • 第一次非零方向也计数：此时还没有两侧方向。
  • 对平台的每个位置都加一，造成重复计数。

面试追问

如果数组作为数据流到达？保留上一项的值、上一非零方向和计数即可，仍为 O(1) 空间。一个峰谷在离开它的非零变化到达时才能确认。

如果要返回峰谷区间？额外记录当前连续等值平台的起止下标，检测到方向反转时输出刚离开的平台区间；输出本身需要 O(k) 空间。

Java

class Solution {
    public int countHillValley(int[] nums) {
        int prev = 0, ans = 0;
        for (int i = 1; i < nums.length; i++) {
            int dir = Integer.compare(nums[i], nums[i - 1]);
            if (dir == 0) continue;
            if (prev != 0 && dir != prev) ans++;
            prev = dir;
        }
        return ans;
    }
}

var countHillValley = function(nums) {
    let prev = 0, ans = 0;
    for (let i = 1; i < nums.length; i++) {
        const dir = Math.sign(nums[i] - nums[i - 1]);
        if (dir === 0) continue;
        if (prev !== 0 && dir !== prev) ans++;
        prev = dir;
    }
    return ans;
};

from typing import List

class Solution:
    def countHillValley(self, nums: List[int]) -> int:
        prev = ans = 0
        for i in range(1, len(nums)):
            dir = (nums[i] > nums[i - 1]) - (nums[i] < nums[i - 1])
            if dir == 0:
                continue
            if prev != 0 and dir != prev:
                ans += 1
            prev = dir
        return ans
