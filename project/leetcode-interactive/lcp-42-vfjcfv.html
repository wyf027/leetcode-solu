LCP 42 · 玩具套圈

将半径很小的投圈按坐标分桶。每个玩具只检查周围 3 × 3 个桶里的圈，再用平方距离做精确判定。

半径 r ≤ 10坐标 ≤ 10⁹O(n + m + 候选数)

题意

玩具 toys[i] = [xi, yi, ri] 是一个圆；所有投圈半径相同为 r，圆心为 circles[j] = [xj, yj]。若玩具整个圆都在某个投圈内或圆上，即 distance ≤ r - ri，就套中一次；被多个圈套中仍只计一个玩具。

toys = [[3,3,1],[3,2,1]]
circles = [[4,3]], r = 2，答案 1。

为什么不两两枚举？

10⁴ × 10⁴ 次距离比较太多。但每个圈半径至多 10，以边长 r 分格后，可能覆盖某个玩具的圈只会落在玩具所在格及邻近 8 格。

核心洞察

  1. 先忽略 ri > r 的玩具，它永远无法被更小的圈完整覆盖。
  2. 取格边长 r，圈与玩具的圆心距离至多 r，因此候选圈只能位于玩具格的 3 × 3 邻域。
  3. 对候选圈用 (x-xj)²+(y-yj)² ≤ (r-ri)² 精确判断，避免浮点误差。
  4. 第一个命中的圈即可停止，保证每个玩具最多计数一次。

边界、复杂度与替代方案

坐标为 10⁹，键必须用字符串或 64 位打包，距离计算必须用 64 位整数。哈希平均复杂度 O(n+m+候选数)。也可按 x 排序做扫描线，但本题半径上界很小，网格哈希最直接。

常见错误 / 面试追问

不能判断“两个圆相交”；题目要求玩具完整包含。不要用 r 替代 r-ri。若 r 不再有小上界，可用 KD-tree 或扫描线范围查询。
