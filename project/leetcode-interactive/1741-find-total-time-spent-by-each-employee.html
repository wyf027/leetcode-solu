Find Total Time Spent by Each Employee

查找每个员工
花费的总时间

一次进出形成一段时长。真正的任务不是逐行计算，而是把这些时长放回正确的“员工 × 日期”桶里。

题目

给定 Employees 表，计算每位员工在每个日期停留在办公室的总分钟数。一次记录的时长为 out_time - in_time；同一员工同一天可能有多条记录。结果列为 day、emp_id、total_time，返回顺序不限。

参数形式与约束

  • 输入表：Employees(emp_id int, event_day date, in_time int, out_time int)。
  • 主键为 (emp_id, event_day, in_time)。
  • 1 ≤ in_time, out_time ≤ 1440，且 in_time < out_time。
  • 同一天内的事件时间段互不相交。
先想一想：如果只按员工分组，会丢掉哪一个维度？如果只计算每行时长，又缺少哪一步？

官方示例 1

输入：Employees
+--------+------------+---------+----------+
| emp_id | event_day  | in_time | out_time |
+--------+------------+---------+----------+
| 1      | 2020-11-28 | 4       | 32       |
| 1      | 2020-11-28 | 55      | 200      |
| 1      | 2020-12-03 | 1       | 42       |
| 2      | 2020-11-28 | 3       | 33       |
| 2      | 2020-12-09 | 47      | 74       |
+--------+------------+---------+----------+

输出：
+------------+--------+------------+
| day        | emp_id | total_time |
+------------+--------+------------+
| 2020-11-28 | 1      | 173        |
| 2020-11-28 | 2      | 30         |
| 2020-12-03 | 1      | 41         |
| 2020-12-09 | 2      | 27         |
+------------+--------+------------+

解释：员工 1 在 2020-11-28 的总时间是
(32 - 4) + (200 - 55) = 28 + 145 = 173；
其他“员工 × 日期”组合分别汇总。

Solution vault

想好分组键了吗？

题解独立放在下方，不会在首屏直接泄露。

题解：先做行级差，再做二维分组

核心洞察：每行贡献 out_time - in_time，分组键必须同时包含 event_day 与 emp_id。

完整过程

  1. 读取一条进出记录。
  2. 用离开分钟减去进入分钟，得到该记录对总时长的贡献。
  3. 按日期和员工编号分组；同一组的所有贡献求和。
  4. 把 event_day 重命名 / 投影为题目要求的 day，返回总时间。

正确性说明

对任意固定组合 (d, e)，查询只收集日期为 d 且员工为 e 的记录。每条记录的停留分钟数按定义等于 out_time - in_time，对组内所有记录求和，因此所得值恰好是员工 e 在日期 d 的总停留时间。所有分组都会被输出，所以结果完整且正确。

边界情况

  • 某员工某天只有一次进出：总和就是这一行的差。
  • 同一员工跨多天：日期在分组键中，不会混在一起。
  • 同一天多个员工：员工编号在分组键中，不会互相累加。
  • 同组多次进出：SUM 会合并所有记录。

复杂度

令记录数为 n。从算法语义看，扫描并累计为 O(n) 时间，分组结果占 O(k) 空间，k 为不同“员工 × 日期”组合数。数据库实际执行计划可能选择哈希聚合或排序聚合。

官方可提交语言：MySQL

MySQL可提交
SELECT
    event_day AS day,
    emp_id,
    SUM(out_time - in_time) AS total_time
FROM Employees
GROUP BY event_day, emp_id;

四语言本地语义参考

本题是数据库题，LeetCode 的正式提交入口以 SQL / Pandas 为主。以下 Java、JavaScript、Python、C++ 代码用于在本地数组上复现相同的分组聚合语义，不能冒充本题的官方通用语言提交。

Java本地语义参考
import java.util.*;

class Solution {
    record Event(int empId, String day, int inTime, int outTime) {}
    record Result(String day, int empId, int totalTime) {}

    public List<Result> totalTime(List<Event> events) {
        Map<String, Integer> totals = new LinkedHashMap<>();
        for (Event event : events) {
            String key = event.day() + "#" + event.empId();
            int duration = event.outTime() - event.inTime();
            totals.merge(key, duration, Integer::sum);
        }

        List<Result> answer = new ArrayList<>();
        for (Map.Entry<String, Integer> entry : totals.entrySet()) {
            String[] parts = entry.getKey().split("#");
            answer.add(new Result(parts[0], Integer.parseInt(parts[1]),
                                  entry.getValue()));
        }
        return answer;
    }
}
JavaScript本地语义参考
function totalTime(events) {
  const totals = new Map();

  for (const { emp_id, event_day, in_time, out_time } of events) {
    const key = `${event_day}#${emp_id}`;
    const duration = out_time - in_time;
    totals.set(key, (totals.get(key) ?? 0) + duration);
  }

  return [...totals].map(([key, total_time]) => {
    const [day, empId] = key.split("#");
    return { day, emp_id: Number(empId), total_time };
  });
}

from collections import defaultdict

def total_time(events: list[dict]) -> list[dict]:
    totals = defaultdict(int)

    for event in events:
        key = (event["event_day"], event["emp_id"])
        totals[key] += event["out_time"] - event["in_time"]

    return [
        {"day": day, "emp_id": emp_id, "total_time": value}
        for (day, emp_id), value in totals.items()
    ]
C++本地语义参考
#include <map>
#include <string>
#include <tuple>
#include <utility>
#include <vector>
using namespace std;

struct Event { int empId; string day; int inTime; int outTime; };
struct Result { string day; int empId; int totalTime; };

vector<Result> totalTime(const vector<Event>& events) {
    map<pair<string, int>, int> totals;
    for (const Event& event : events) {
        totals[{event.day, event.empId}] += event.outTime - event.inTime;
    }

    vector<Result> answer;
    for (const auto& [key, value] : totals) {
        answer.push_back({key.first, key.second, value});
    }
    return answer;
}

替代方案

也可先在子查询中计算每行 duration，外层再分组求和；语义更分阶段，但本题中会增加不必要的层级。Pandas 可用 assign 计算差值后按两列 groupby。

面试追问

为什么不能只按 emp_id 分组？

那会把该员工不同日期的时间混成一个总数，输出无法保留每天的粒度。

同一员工同一天的时间段若发生重叠怎么办？

本题保证不重叠。若取消该保证，直接求和会重复计算，需要先合并区间，再累计并集长度。

索引如何考虑？

数据量大时，可结合执行计划评估以 (event_day, emp_id) 为前缀的索引；但索引是否收益取决于扫描范围、数据分布与数据库优化器。

常见错误

  • 写成 SUM(out_time) - in_time，让未聚合列混入表达式。
  • 只按一列分组，破坏题目要求的“每位员工、每天”粒度。
  • 把 event_day 的输出别名遗漏为 day。
  • 误用 COUNT(*) 统计次数，而不是累加分钟数。
