基于时间的
键值存储

同一个键会随时间拥有多个版本。查询时，不是寻找“恰好相等”，而是返回查询时刻之前最近的一次写入。

MEDIUMTime Based Key-Value Store非付费题

题目

设计 TimeMap，让同一 key 能在不同时间戳保存多个 value。

  • TimeMap()：初始化。
  • set(String key, String value, int timestamp)：保存该键在指定时间的值。
  • get(String key, int timestamp)：在所有不晚于查询时间的记录中，返回时间戳最大的那条；不存在则返回空字符串。
所有 set 的时间戳全局严格递增，因此每个键对应的记录天然按时间升序排列。

约束

  • 1 ≤ key.length, value.length ≤ 100
  • key、value 仅含小写字母和数字
  • 1 ≤ timestamp ≤ 10⁷
  • set 的时间戳严格递增
  • set 与 get 总调用数至多 2 × 10⁵

官方示例

输入
["TimeMap", "set", "get", "get", "set", "get", "get"]
[[], ["foo", "bar", 1], ["foo", 1], ["foo", 3], ["foo", "bar2", 4], ["foo", 4], ["foo", 5]]

输出
[null, null, "bar", "bar", null, "bar2", "bar2"]

解释：在 t=1 写入 bar，所以 t=1 与 t=3 都读到它；t=4 写入 bar2 后，t=4 与 t=5 都读到新值。

题解：哈希表 + 二分查找

核心洞察

用哈希表把每个键映射到一个按时间升序的 (timestamp, value) 数组。写入直接追加；查询在对应数组中二分查找最后一个不大于目标时间戳的位置。

完整过程

  1. set：取得键的数组，不存在则创建，然后追加记录。
  2. get：若键不存在，返回空字符串。
  3. 令 lo=0, hi=n，在半开区间中查找第一个时间戳大于查询值的位置。
  4. 答案是该位置的前一项；若位置为 0，则返回空字符串。

正确性

循环保持：索引小于 lo 的记录时间戳均不大于查询时间，索引不小于 hi 的记录均大于查询时间。终止时 lo=hi，它正是第一个过晚记录的位置，因此 lo-1 是合法记录中时间戳最大的；若其不存在，说明没有合法记录。

边界与复杂度

需处理未知键、查询早于首条记录、等于某条记录、晚于末条记录。设某键有 m 条记录：set 摊还 O(1)，get O(log m)，总空间 O(n)。

替代方案

线性倒序扫描最坏 O(m)；平衡树可做 O(log m) 写入与查询，但没有利用时间戳递增条件，结构更重。当前数组方案更简单且缓存友好。

面试追问与常见错误

  • 若写入时间戳无序？可使用有序映射，或插入时维护有序数组。
  • 如何支持删除？明确按版本删还是按键删，再选择墓碑或有序结构。
  • 常见错误：寻找“等于”而非“最后一个小于等于”；边界用错导致访问 -1；对未知键意外创建空数组。

class TimeMap {
    private static class Entry {
        int time; String value;
        Entry(int time, String value) { this.time = time; this.value = value; }
    }
    private final Map<String, List<Entry>> data = new HashMap<>();
    public TimeMap() {}
    public void set(String key, String value, int timestamp) {
        data.computeIfAbsent(key, k -> new ArrayList<>()).add(new Entry(timestamp, value));
    }
    public String get(String key, int timestamp) {
        List<Entry> a = data.get(key);
        if (a == null) return "";
        int lo = 0, hi = a.size();
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (a.get(mid).time <= timestamp) lo = mid + 1; else hi = mid;
        }
        return lo == 0 ? "" : a.get(lo - 1).value;
    }
}
var TimeMap = function() { this.data = new Map(); };
TimeMap.prototype.set = function(key, value, timestamp) {
    if (!this.data.has(key)) this.data.set(key, []);
    this.data.get(key).push([timestamp, value]);
};
TimeMap.prototype.get = function(key, timestamp) {
    const a = this.data.get(key);
    if (!a) return "";
    let lo = 0, hi = a.length;
    while (lo < hi) {
        const mid = lo + Math.floor((hi - lo) / 2);
        if (a[mid][0] <= timestamp) lo = mid + 1; else hi = mid;
    }
    return lo === 0 ? "" : a[lo - 1][1];
};

    def __init__(self):
        self.data = {}

    def set(self, key: str, value: str, timestamp: int) -> None:
        self.data.setdefault(key, []).append((timestamp, value))

    def get(self, key: str, timestamp: int) -> str:

class TimeMap {
    unordered_map<string, vector<pair<int, string>>> data;
public:
    TimeMap() {}
    void set(string key, string value, int timestamp) {
        data[key].push_back({timestamp, value});
    }
    string get(string key, int timestamp) {
        auto it = data.find(key);
        if (it == data.end()) return "";
        const auto& a = it->second;
        int lo = 0, hi = static_cast<int>(a.size());
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (a[mid].first <= timestamp) lo = mid + 1; else hi = mid;
        }
        return lo == 0 ? "" : a[lo - 1].second;
    }
};
