完整题解

核心洞察

普通二进制相加可以拆成两个互不混淆的部分：异或得到忽略进位的和，按位与后左移一位得到应加入下一高位的进位。把这两部分当作新的两个数继续处理，直到进位为零。

partial = x XOR y    carry = (x AND y) << 1

完整过程

  1. 令 x = a、y = b，其中 y 表示当前仍待合并的进位。
  2. 用 x ^ y 计算所有位上不考虑进位的结果。
  3. 用 (x & y) << 1 找到共同为 1 的位置，并把进位移动到更高一位。
  4. 以这两个新值替换 x 和 y，重复直到 y = 0。
  5. 此时没有未处理进位，x 即 32 位有符号整数结果。

正确性证明

循环不变量：每轮开始时，按 32 位补码模 2³² 解释，x + y 始终等于原始 a + b。

对任意一位，x ^ y 保留恰有一个操作数为 1 的无进位和；x & y 标出两个操作数都为 1、因而必须进位的位置，左移一位后正好赋予进位正确的位权。因此，把两者作为新的 x 与 y 不改变总和，不变量成立。

32 位内的进位只会向更高位移动，最终 y 变为 0。终止时由不变量得 x = a + b（按 32 位补码解释），算法正确。

边界与语言差异

  • 任一参数为 0 时，进位立即为空。
  • 正数与负数同样使用补码运算；像 -1 与 1 可能让进位穿过很多位。
  • Java、JavaScript 的位运算天然按 32 位整数工作；C++ 使用无符号中间量以避免对负数左移。
  • Python 整数没有固定位宽，负数按无限符号扩展，因此必须用 0xffffffff 遮罩模拟 32 位。

复杂度

固定 32 位整数下，循环最多处理 32 次，时间复杂度为 O(1)，空间复杂度为 O(1)。若推广到位宽 w，时间复杂度可记为 O(w)。

四语言完整代码

class Solution {
    public int getSum(int a, int b) {
        while (b != 0) {
            int carry = (a & b) << 1;
            a = a ^ b;
            b = carry;
        }
        return a;
    }
}
/**
 * @param {number} a
 * @param {number} b
 * @return {number}
 */
var getSum = function(a, b) {
    a |= 0;
    b |= 0;

    while (b !== 0) {
        const carry = (a & b) << 1;
        a = (a ^ b) | 0;
        b = carry | 0;
    }
    return a;
};
class Solution:
    def getSum(self, a: int, b: int) -> int:
        mask = 0xFFFFFFFF
        max_int = 0x7FFFFFFF

        a &= mask
        b &= mask
        while b:
            carry = ((a & b) << 1) & mask
            a = (a ^ b) & mask
            b = carry

        return a if a <= max_int else ~(a ^ mask)
#include <cstdint>

class Solution {
public:
    int getSum(int a, int b) {
        std::uint32_t x = static_cast<std::uint32_t>(a);
        std::uint32_t y = static_cast<std::uint32_t>(b);

        while (y != 0U) {
            std::uint32_t carry = (x & y) << 1U;
            x ^= y;
            y = carry;
        }
        return static_cast<std::int32_t>(x);
    }
};

替代方案

可以把同一递推写成递归：当进位为零时返回当前值，否则以异或结果和左移进位继续调用。但递归没有带来新的算法优势，还会增加调用栈开销；面试和工程实现更推荐迭代。

面试追问

  • 为什么异或等价于“不带进位的加法”？请按单个二进制位列真值表。
  • 为什么 Python 版本必须限制到 32 位？若不加遮罩，负数会发生什么？
  • 若题目要求检测而不是接受整数溢出，应在哪一步判断符号变化？
  • 能否用半加器、全加器的概念解释这段程序与硬件加法器的关系？

常见错误

  • 先更新 a 再用更新后的值计算 carry，破坏了同一轮数据快照。
  • 忘记将 a & b 左移一位，导致进位留在错误的位权。
  • Python 直接对负数循环，因无限符号扩展而无法按预期终止。
  • C++ 对负的有符号整数左移，可能触发未定义行为；应使用无符号中间量。
  • 把固定 32 位下的复杂度机械写成 O(log n)，却没有说明采用的位宽模型。
