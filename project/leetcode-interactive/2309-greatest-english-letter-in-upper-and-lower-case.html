2309. 兼具大小写的
最好英文字母

Greatest English Letter in Upper and Lower Case

从字母的两种形态中，找出字母表顺序最大的那一对。

LeetCode 官方题目 ↗

题目

给定字符串 s，其中仅包含大小写英文字母。一个字母只有在它的大写形式和小写形式都出现过时，才符合要求。在所有符合要求的字母中，返回英文字母表位置最靠后的一个，并使用大写形式返回；若没有这样的字母，返回空字符串 ""。

“最好”比较的是字母表位置，例如 Z 大于 Y；与出现次数、字符位置无关。

参数与返回值

greatestLetter(s: string) → string

  • 1 ≤ s.length ≤ 1000
  • s 仅由 a–z 和 A–Z 组成。

官方示例

01 / 唯一成对

输入：s = "lEeTcOdE"
输出："E"

只有 E 的大写与小写都出现过；多出的 E 不改变结果。

02 / 多对竞争

输入：s = "arRAzFif"
输出："R"

A、F、R 都符合条件，R 的字母表位置最靠后。

03 / 没有配对

输入：s = "AbCdEfGhIjK"
输出：""

每个字母都只出现一种大小写形式。

题解与交互实验

记录存在性，再从 Z 向 A 寻找

核心洞察：只需知道每种字符是否出现，不必统计次数。把原串字符放入集合，然后从 Z 到 A 枚举；第一个同时拥有大写和小写形式的字母就是答案。

大小写配对仪

先逐字符点亮两种形态，再沿字母表逆向检查。绿色卡片表示两种形态齐全，紫色框表示本步关注的字母。演示为按算法生成的状态，未经独立验证。

1–1000 个英文字母；编辑后点击“应用输入”。

Tab 移动焦点，Enter / 空格操作按钮。启用减少动态效果偏好时，自动播放不可用，仍可单步操作。

完整过程

  1. 构建字符集合 seen，保留大小写区别。
  2. 枚举大写字母 Z、Y、…、A，并得到其小写形式。
  3. 若两种形式都在集合中，立即返回该大写字母。
  4. 26 个字母均不满足时，返回 ""。

以 s = "arRAzFif" 为例：集合中 A/a、F/f、R/r 齐全；检查 Z 时缺 Z，检查 Y 到 S 也无法配对，检查 R 时满足条件，直接返回 "R"。

正确性

扫描字符串后，集合包含的字符恰好是原串出现过的字符，因此双重成员判断与题目要求完全等价。逆序枚举到某个字母时，所有比它大的字母都已检查且不符合条件；所以第一个符合条件的字母必然最大。若遍历结束仍未返回，所有 26 个字母都不符合条件，空字符串就是正确结果。

边界与复杂度

  • 单字符无法同时提供两种形式；同一形态重复出现也无法配对。
  • Z/z 成对时直接得到最大答案；较大的单形态字母不能压过较小的完整配对。
  • 时间：O(n + 26) = O(n)，集合成员查找按均摊常数时间计算。
  • 额外空间：至多 52 个字符，即 O(52) = O(1)。固定字母表是此结论的前提。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public String greatestLetter(String s) {
        Set<Character> seen = new HashSet<>();
        for (char c : s.toCharArray()) seen.add(c);
        for (char upper = 'Z'; upper >= 'A'; upper--) {
            char lower = (char) (upper - 'A' + 'a');
            if (seen.contains(upper) && seen.contains(lower)) {
                return String.valueOf(upper);
            }
        }
        return "";
    }
}

Java 的 toCharArray() 会额外复制 O(n) 空间；若要求整体 O(1) 辅助空间，按下标用 s.charAt(i) 扫描即可。此处下方复杂度说明中的集合空间与该临时副本分开计。

/**

var greatestLetter = function(s) {
    const seen = new Set(s);
    for (let code = 90; code >= 65; code--) {
        const upper = String.fromCharCode(code);
        if (seen.has(upper) && seen.has(upper.toLowerCase())) {
            return upper;
        }
    }
    return "";
};

Python 3

class Solution:
    def greatestLetter(self, s: str) -> str:
        seen = set(s)
        for code in range(ord('Z'), ord('A') - 1, -1):
            upper = chr(code)
            if upper in seen and upper.lower() in seen:
                return upper
        return ""

C++

#include <string>
#include <unordered_set>
using namespace std;

class Solution {
public:
    string greatestLetter(string s) {
        unordered_set<char> seen(s.begin(), s.end());
        for (int code = 'Z'; code >= 'A'; --code) {
            char upper = static_cast<char>(code);
            char lower = static_cast<char>(code - 'A' + 'a');
            if (seen.count(upper) && seen.count(lower)) {
                return string(1, upper);
            }
        }
        return "";
    }
};

替代方案

  • 两个 26 位布尔数组：分别记录大小写出现情况，再逆序查找同时为真的位置。时间 O(n)，空间 O(1)，避免哈希开销。
  • 位掩码：大写、小写各用一个整数，按位与得到成对字母的位；从第 25 位向第 0 位查找。26 位足够，仍为 O(n) 时间、O(1) 空间。
  • 逐字母搜索原串：对 Z 到 A 分别检查两个形式是否包含在字符串中。O(26n) 时间、O(1) 空间；固定字母表下也可记为 O(n)，但重复扫描更多。

常见错误

  • 先把整串转成同一种大小写：丢失原始形态信息，无法判断是否真的配对。
  • 使用“或”判断：题目要求大写且小写都存在。
  • 找到原串中的第一对就返回：扫描顺序不是字母表逆序，后面可能有更大的配对。
  • 从 A 升序遍历并立即返回：得到的是最小配对，而不是最大配对。
  • 没有配对时返回空格、null 或小写字母：返回值必须是大写字母或空字符串。

面试追问

输入流只能读一遍？使用大小写两个数组或集合；每读入一个字符就判断其另一种形态是否已出现，并更新当前最大答案。

还要返回全部配对？完成记录后遍历 26 个字母，将符合条件者收集到列表中，无须排序原串。

扩展到 Unicode？不能直接套用 ASCII 偏移或 26 位掩码，需要先定义大小写映射、规范化规则和排序规则；某些映射不是一对一。
