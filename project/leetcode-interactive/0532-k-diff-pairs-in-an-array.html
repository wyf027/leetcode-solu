数组中的 k-diff 数对

K-diff Pairs in an Array · 数组 / 哈希表 / 双指针 / 排序

题目

给你整数数组 nums 和非负整数 k，请统计其中不同的 k-diff 数对数量。数对对应两个不同下标，且两数之差的绝对值等于 k；相同的值对只计算一次。

约束

  • 1 ≤ nums.length ≤ 10⁴
  • -10⁷ ≤ nums[i] ≤ 10⁷
  • 0 ≤ k ≤ 10⁷

官方示例

示例 1 输入：nums = [3, 1, 4, 1, 5], k = 2 输出：2 解释：(1, 3)、(3, 5)；重复的 1 不会重复计数。 示例 2 输入：nums = [1, 2, 3, 4, 5], k = 1 输出：4 解释：(1, 2)、(2, 3)、(3, 4)、(4, 5)。 示例 3 输入：nums = [1, 3, 1, 5, 4], k = 0 输出：1 解释：唯一的值对是 (1, 1)。

频次地图探索器

逐步观察数组如何变成频次表，以及候选值如何配对。

题解：按 k 的取值分流

核心洞察

题目要求不同的值对。先建立 值 → 频次：若 k > 0，对每个键 x 只查 x+k；若 k = 0，只统计频次至少为 2 的值。

完整过程

  1. 遍历数组建立频次表。
  2. k=0 时统计频次大于 1 的键。
  3. k>0 时遍历不同键，若 x+k 存在则答案加一。
  4. 返回答案；单向检查避免重复。

正确性

完备性：任意合法值对都可写成 (a,a+k)。当 k>0，遍历到 a 必然发现另一值；当 k=0，频次至少为 2 恰好保证两个不同下标。

唯一性：每个哈希键只遍历一次，且只向 x+k 查找，故不会反向重复；零差时每个重复值也只计一次。

边界与复杂度

  • 单元素返回 0；同一值重复多次且 k=0 仍只计 1。
  • 负数可直接作为哈希键。
  • 时间 O(n)，空间 O(n)。

替代方案

排序后使用双指针，时间 O(n log n)；需要跳过重复值，并保证两指针不指向同一位置。

面试追问

  • 返回数对本身：命中时收集 [x,x+k]。
  • 数据流版本：维护频次以及插入、删除对合法数对数的贡献。
  • 若允许负 k：绝对差不可能为负，直接返回 0。

常见错误

  • 统计下标组合，而非不同值对。
  • k=0 时忘记要求出现至少两次。
  • 同时检查 x-k 和 x+k，造成重复。

四种语言实现

class Solution {
    public int findPairs(int[] nums, int k) {
        Map<Integer, Integer> f = new HashMap<>();
        for (int x : nums) f.put(x, f.getOrDefault(x, 0) + 1);
        int ans = 0;
        for (int x : f.keySet())
            if (k == 0 ? f.get(x) > 1 : f.containsKey(x + k)) ans++;
        return ans;
    }
}
var findPairs = function(nums, k) {
    const f = new Map();
    for (const x of nums) f.set(x, (f.get(x) || 0) + 1);
    let ans = 0;
    for (const [x, count] of f)
        if (k === 0 ? count > 1 : f.has(x + k)) ans++;
    return ans;
};
from typing import List
from collections import Counter

class Solution:
    def findPairs(self, nums: List[int], k: int) -> int:
        f = Counter(nums)
        if k == 0:
            return sum(count > 1 for count in f.values())
        return sum(x + k in f for x in f)
class Solution {
public:
    int findPairs(vector<int>& nums, int k) {
        unordered_map<int, int> f;
        for (int x : nums) ++f[x];
        int ans = 0;
        for (auto [x, count] : f)
            if (k == 0 ? count > 1 : f.count(x + k)) ++ans;
        return ans;
    }
};
