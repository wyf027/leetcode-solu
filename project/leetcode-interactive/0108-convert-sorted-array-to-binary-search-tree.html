Problem brief

任务与约束

给定一个按严格升序排列的整数数组 nums，把它转换成一棵高度平衡的二叉搜索树。

“高度平衡”表示任意节点左右子树的高度差不超过 1。符合条件的树可能不止一棵，因此输出并不唯一。

  • 1 <= nums.length <= 104
  • -104 <= nums[i] <= 104
  • nums 严格递增，不含重复元素
官方样例 1
输入 nums = [-10,-3,0,5,9]
一种合法输出 [0,-3,9,-10,null,5]

只要同时满足 BST 与高度平衡，其他树形也会被接受。

官方样例 2
输入 nums = [1,3]
一种合法输出 [1,null,3]

[3,1] 同样合法。

可见字符说明：若输入含字符串，页面会用 ␠ 表示空格并保留成对直引号；本题输入只有整数数组，不涉及字符串空格。

Solution blueprint

中点分治：让规模先平衡

面试最推荐的主线是递归分治：每个区间取中点作为根，左右两半分别构造左右子树。由于两半长度最多相差 1，平衡性从区间规模上自然成立。

核心洞察

有序数组已经给出了 BST 的中序遍历。我们只需要决定谁当根：取中点后，左边所有值都更小、右边所有值都更大；同时左右元素数量尽可能接近。

为什么答案不唯一

偶数长度区间有两个“中间位置”。选择较左或较右的中点，都能保持高度平衡；LeetCode 会验证结构性质，而不是要求某个唯一序列化。

完整过程

  1. 定义递归函数 build(left, right)，负责构造闭区间对应的子树。
  2. 若 left > right，区间为空，返回 null。
  3. 计算 mid = left + (right - left) / 2，用 nums[mid] 创建根节点。
  4. 左半区间构造左子树，右半区间构造右子树，最后返回根节点。

关键边界

  • 单元素区间：该元素直接成为叶子。
  • 空区间：必须返回 null，避免越界。
  • 偶数长度：取左中点或右中点都正确。
  • 长度 10^4：递归深度约为 log₂n，不会退化成链。

复杂度

O(n)每个数组元素恰好创建一次节点
O(log n)递归栈；不计返回的树本身
O(n)若把输出树也计入总空间

替代方案与取舍

  • 显式栈 / 队列保存区间：同为 O(n)，可避免递归，但状态更繁琐。
  • 逐个插入 BST：通常为 O(n log n)，还要精心安排插入顺序，不如分治直接。
  • 上中点策略：同样正确，只会得到另一棵合法树。

常见错误

  • 把输出数组样例误当作唯一答案，使用严格序列化比较。
  • 左右递归仍包含 mid，导致无限递归。
  • 边界混用闭区间与半开区间，遗漏或重复节点。
  • 先建一条 BST 再“修平衡”，把简单问题复杂化。

面试追问

  • 如何证明任意节点左右高度差不超过 1？
  • 如果输入是有序链表，怎样做到 O(n)？
  • 如何写成非递归版本？需要保存哪些区间与父子关系？
  • 为什么中序遍历可以恢复原数组，却不能唯一确定树？

一句话证明

中点保证 BST 顺序；左右区间长度至多差 1，递归地每个子区间也如此，因此整棵树高度平衡。

class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    private TreeNode build(int[] nums, int left, int right) {
        if (left > right) {
            return null;
        }

        int mid = left + (right - left) / 2;
        TreeNode root = new TreeNode(nums[mid]);
        root.left = build(nums, left, mid - 1);
        root.right = build(nums, mid + 1, right);
        return root;
    }
}

      return null;
    }

    const mid = left + Math.floor((right - left) / 2);
    const root = new TreeNode(nums[mid]);
    root.left = build(left, mid - 1);
    root.right = build(mid + 1, right);
    return root;
  }

  return build(0, nums.length - 1);
};
