692. 前 K 个高频单词

从一串重复单词里选出频率最高的 k 个；当频率相同，字典序更小的单词必须排在前面。

Top K Frequent Words 哈希表 堆 / 优先队列 非付费题

The ranking contract

两级排序，
一个明确答案。

  • 01
    频率优先出现次数越多，答案位置越靠前。
  • 02
    字典序裁决频率相同时，字典序更小者靠前。
  • 03
    恰好取 K 个只返回排名最靠前的 k 个不同单词。

01 · Problem

读懂任务

给定字符串数组 words 和整数 k，返回出现次数最多的 k 个单词。输出先按频率降序排列；频率相同则按字典序升序排列。

函数参数

topKFrequent(words, k)

  • 1 <= words.length <= 500
  • 1 <= words[i].length <= 10
  • words[i] 仅由小写英文字母组成。
  • 1 <= k <= 不同单词的数量

进阶：尝试达到 O(n log k) 时间与 O(n) 额外空间。

输出顺序

比较两个单词时，先看频率。只有频率相同，才进入字典序比较。

频率 ↓高频在前
→
字典序 ↑小词在前

官方示例 1

输入
words = ["i", "love", "leetcode", "i", "love", "coding"], k = 2
输出
["i", "love"]
解释
“i”和“love”均出现 2 次；同频时，“i”的字典序更小。

官方示例 2

输入
words = ["the", "day", "is", "sunny", "the", "the", "the", "sunny", "is", "is"], k = 4
输出
["the", "is", "sunny", "day"]
解释
四个单词分别出现 4、3、2、1 次，按频率从高到低输出。

完整题解

题解默认收起，不影响你先独立推导。展开后焦点会进入题解区域；收起后焦点返回按钮。

核心洞察

排序标准有“频率降序、字典序升序”两层。若只需前 k 个，无须让所有不同单词完全排序：维护一个容量为 k 的小顶堆，并把当前最差候选放在堆顶。

“最差”的定义恰好反过来：频率更低更差；同频时，字典序更大的单词更差。候选超过 k 个便弹出堆顶。

完整过程

  1. 用哈希表统计每个单词的出现次数。
  2. 遍历所有不同单词，将其加入容量为 k 的小顶堆。
  3. 若堆大小超过 k，弹出“频率低；同频时字典序大”的堆顶。
  4. 遍历结束后，堆中恰好是全局最优的 k 个单词。
  5. 依次弹堆得到从差到好的次序，反转即为题目要求的结果。

正确性证明

引理 1堆顶始终是堆内排名最差的单词，因为比较器优先把低频词放上来，同频时把字典序更大的词放上来。
引理 2处理任意前缀后，堆内保存该前缀不同单词中排名最好的至多 k 个。新词加入后若超容，只删去 k+1 个候选中最差者，因此不变量保持。
结论所有不同单词处理完后，由引理 2，堆中正是全局前 k 名。按堆顶依次弹出得到从差到好，反转后满足频率降序与同频字典序升序。

边界与细节

  • k = 1：堆只保留全局最优单词。
  • k 等于不同单词数：没有最终淘汰，但弹堆后仍须反转。
  • 全部同频：结果完全由字典序决定。
  • 比较器方向：堆内顺序与最终答案顺序相反，这是最易出错之处。

复杂度

时间 O(n + m log k)n 为数组长度，m 为不同单词数；满足 O(n log k) 的进阶目标。
空间 O(m + k)频次表保存 m 项，有界堆最多保存 k 项。

替代方案

  • 全部排序：统计后按目标规则排序所有不同单词，代码更短，时间 O(n + m log m)。
  • 桶排序：按频率分桶，再在桶内按字典序排序；适合频率范围较小的场景。
  • Trie：可帮助按字典序枚举，但本题仍需处理频率优先级，通常不如哈希表配合堆直接。

面试追问

  • 若输入是持续到来的数据流，如何在线更新 Top K？
  • 若 k 很接近不同单词总数，堆与全排序谁更合适？
  • 若字典序需遵循本地化语言规则，比较器如何变化？
  • 如何合并多台机器各自统计出的局部频次？

常见错误

  • 同频时把字典序写成降序，导致保留或输出顺序颠倒。
  • 使用容量 k 的堆却把“最好”放在堆顶，无法 O(log k) 淘汰最差者。
  • 弹堆后忘记反转结果。
  • 直接按频率排序，遗漏题目规定的同频字典序规则。

import java.util.*;

class Solution {
    public List<String> topKFrequent(String[] words, int k) {
        Map<String, Integer> frequency = new HashMap<>();
        for (String word : words) {
            frequency.put(word, frequency.getOrDefault(word, 0) + 1);
        }

        PriorityQueue<String> heap = new PriorityQueue<>((a, b) -> {
            int countCompare = Integer.compare(frequency.get(a), frequency.get(b));
            if (countCompare != 0) {
                return countCompare;          // 低频词更接近堆顶
            }
            return b.compareTo(a);            // 同频时字典序大的更接近堆顶
        });

        for (String word : frequency.keySet()) {
            heap.offer(word);
            if (heap.size() > k) {
                heap.poll();
            }
        }

        List<String> answer = new ArrayList<>(k);
        while (!heap.isEmpty()) {
            answer.add(heap.poll());
        }
        Collections.reverse(answer);
        return answer;
    }
}
/**
 * @param {string[]} words
 * @param {number} k
 * @return {string[]}
 */
var topKFrequent = function(words, k) {
    const frequency = new Map();
    for (const word of words) {
        frequency.set(word, (frequency.get(word) || 0) + 1);
    }

    // compare(a, b) < 0 表示 a 比 b 更差、更靠近堆顶。
    const compare = (a, b) => {
        const countDiff = frequency.get(a) - frequency.get(b);
        if (countDiff !== 0) return countDiff;
        if (a === b) return 0;
        return a > b ? -1 : 1;
    };

    const heap = [];
    const swap = (i, j) => {
        [heap[i], heap[j]] = [heap[j], heap[i]];
    };
    const push = (word) => {
        heap.push(word);
        let index = heap.length - 1;
        while (index > 0) {
            const parent = Math.floor((index - 1) / 2);
            if (compare(heap[index], heap[parent]) >= 0) break;
            swap(index, parent);
            index = parent;
        }
    };
    const pop = () => {
        const root = heap[0];
        const last = heap.pop();
        if (heap.length > 0) {
            heap[0] = last;
            let index = 0;
            while (true) {
                let smallest = index;
                const left = index * 2 + 1;
                const right = left + 1;
                if (left < heap.length && compare(heap[left], heap[smallest]) < 0) {
                    smallest = left;
                }
                if (right < heap.length && compare(heap[right], heap[smallest]) < 0) {
                    smallest = right;
                }
                if (smallest === index) break;
                swap(index, smallest);
                index = smallest;
            }
        }
        return root;
    };

    for (const word of frequency.keys()) {
        push(word);
        if (heap.length > k) pop();
    }

    const answer = [];
    while (heap.length > 0) answer.push(pop());
    return answer.reverse();
};
from collections import Counter
from dataclasses import dataclass
from typing import List
import heapq


@dataclass
class HeapItem:
    word: str
    count: int

    def __lt__(self, other: "HeapItem") -> bool:
        if self.count != other.count:
            return self.count < other.count   # 低频词更差
        return self.word > other.word         # 同频时字典序大的更差


class Solution:
    def topKFrequent(self, words: List[str], k: int) -> List[str]:
        frequency = Counter(words)
        heap: List[HeapItem] = []

        for word, count in frequency.items():
            heapq.heappush(heap, HeapItem(word, count))
            if len(heap) > k:
                heapq.heappop(heap)

        answer = []
        while heap:
            answer.append(heapq.heappop(heap).word)
        answer.reverse()
        return answer
#include <algorithm>
#include <queue>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> topKFrequent(vector<string>& words, int k) {
        unordered_map<string, int> frequency;
        for (const string& word : words) {
            ++frequency[word];
        }

        auto better = [&frequency](const string& a, const string& b) {
            if (frequency[a] != frequency[b]) {
                return frequency[a] > frequency[b];
            }
            return a < b;
        };

        // priority_queue 的 top 是“优先级最高”项；这里让最差词位于 top。
        priority_queue<string, vector<string>, decltype(better)> heap(better);

        for (const auto& entry : frequency) {
            heap.push(entry.first);
            if (static_cast<int>(heap.size()) > k) {
                heap.pop();
            }
        }

        vector<string> answer;
        answer.reserve(k);
        while (!heap.empty()) {
            answer.push_back(heap.top());
            heap.pop();
        }
        reverse(answer.begin(), answer.end());
        return answer;
    }
};
