题解

04

核心洞察

不枚举每个数，而是分别询问：从 0 到 n，个位有多少个 2？十位有多少个 2？每个数位的答案相加，就是总次数。

对权值 factor，把 n 拆为 higher | current | lower。 完整周期每 10 × factor 个数出现一次，因此高位先贡献 higher × factor。

三种当前位

< 2higher × factor
= 2higher × factor + lower + 1
> 2(higher + 1) × factor

完整过程 · n = 25

  1. 个位：higher = 2，current = 5，lower = 0，贡献 (2 + 1) × 1 = 3。
  2. 十位：higher = 0，current = 2，lower = 5，贡献 0 × 10 + 5 + 1 = 6。
  3. 总计 3 + 6 = 9。

边界与复杂度

  • n = 0 时直接得到 0。
  • factor = 1 时 lower 为 0。
  • 中间乘法使用 64 位整数，避免 factor × 10 溢出。
  • 时间复杂度 O(log₁₀ n)，额外空间 O(1)。

替代方案取舍

  • 暴力枚举：容易验证，但为 O(n log n)，只适合作为对拍基线。
  • 数位 DP：能推广到更复杂限制，但本题状态与模板成本偏高。
  • 逐位统计：O(log n)、O(1)，公式可解释，是面试最推荐方案。

面试追问

  • 如果统计任意数字 d，d = 0 时为何要扣除前导零？
  • 如果区间改成 [L, R]，如何用两个前缀答案相减？
  • 如何将方法推广到二进制或任意进制？

常见错误

  • 当前位等于 2 时漏掉 lower + 1，尤其容易忘记“+1”。
  • 用 n % (factor × 10) 当 lower，导致把当前位也包含进去。
  • 循环边界写成 factor < n，遗漏最高位。
  • 在 Java / C++ 中用 32 位中间变量计算 factor × 10。 
class Solution {
    public int numberOf2sInRange(int n) {
        long answer = 0;

        for (long factor = 1; factor <= n; factor *= 10) {
            long lower = n % factor;
            long current = (n / factor) % 10;
            long higher = n / (factor * 10);

            if (current < 2) {
                answer += higher * factor;
            } else if (current == 2) {
                answer += higher * factor + lower + 1;
            } else {
                answer += (higher + 1) * factor;
            }
        }

        return (int) answer;
    }
}
