01 / PROBLEM

题目说明

给定二维整数数组 ranges 和整数 left、right。其中 ranges[i] = [start_i, end_i] 是包含两端点的闭区间。当 start_i ≤ x ≤ end_i 时，整数 x 被这个区间覆盖。

判断闭区间 [left, right] 内的所有整数是否各自被至少一个给定区间覆盖。全部覆盖返回 true；只要有一个整数未覆盖，就返回 false。

只关心整数点；可以由多个不同区间共同完成覆盖，端点也要计算在内。

官方示例 1

ranges = [[1,2],[3,4],[5,6]], left = 2, right = 5
输出：true

2 由 [1,2] 覆盖，3 和 4 由 [3,4] 覆盖，5 由 [5,6] 覆盖。

官方示例 2

ranges = [[1,10],[10,20]], left = 21, right = 21
输出：false

目标只有整数 21，它不属于任何给定区间。

约束

  • 1 ≤ ranges.length ≤ 50
  • 1 ≤ start_i ≤ end_i ≤ 50
  • 1 ≤ left ≤ right ≤ 50

04 / SOLUTION

想清楚后，再揭开题解

包含过程、证明、四语言代码与面试延伸。

核心洞察：每个整数寻找一个见证区间

本题最多有 50 个目标整数、50 个区间。对每个整数逐一查找即可，最多进行 2500 次区间判断。整数 x 只需要找到一个覆盖它的区间，不必统计覆盖次数，也不要求同一个区间覆盖整个目标。

完整过程

  1. 枚举 x = left, left + 1, …, right，每次令 covered = false。
  2. 遍历所有区间 [start, end]，判断 start ≤ x 且 x ≤ end。
  3. 一旦命中，将 covered 置为 true，并结束当前整数的区间搜索。
  4. 搜索完仍未命中，立即返回 false；如果所有整数都命中，则返回 true。

例如示例 1：整数 2 命中 [1,2]；整数 3、4 各自跳过 [1,2] 后命中 [3,4]；整数 5 跳过前两个区间后命中 [5,6]。可视化中每一次“下一步”对应一次区间比较，最后单独呈现结论。

正确性证明

内层：遍历前 j 个区间后，若尚未命中，就说明这些区间均不包含 x；命中时条件 start ≤ x ≤ end 正是覆盖的定义，因此可以提前结束。全部区间都不命中时，x 确实未被覆盖。

外层：开始检查 x 时，[left, x − 1] 内的所有整数都已确认覆盖。内层命中后，该性质扩展到 [left, x]；内层失败则找到了一个反例，返回 false 正确。完成 right 的检查后，[left, right] 全部覆盖，返回 true 正确。两层循环均遍历有限集合，算法终止。

边界与常见错误

  • 闭区间：比较用 ≤，循环也要包含 right；left = right 时仍需检查一次。
  • 中间断点：只判断 left 和 right 不够，例如 [[1,2],[4,5]] 没有覆盖 3。
  • 整数语义：[1,2] 和 [3,4] 能覆盖 1 到 4 的所有整数，无需处理 2.5。
  • 状态重置：covered 必须对每个 x 重新设为 false，不能让前一个点的成功延续到下一个点。
  • 提前结束的层级：一个区间未命中不能立即返回 false；一个整数命中也不能立即返回 true。
  • 无序、重复、重叠：不影响逻辑，无需排序；范围外的区间自然不会命中目标点。

复杂度

设 n = ranges.length，m = right − left + 1。最坏时间为 O(nm)，额外空间为 O(1)，不修改输入。动画为支持回退保存了帧，其存储不计入提交算法的空间复杂度。

替代方案

  • 布尔标记：用 51 个位置标记每个区间覆盖的整数，再扫描目标。值域为 U 时，时间 O(nU + U)，空间 O(U)。适合直观地保存整个覆盖图。
  • 差分与前缀和：在 start 处 +1、end + 1 处 −1，从 1 累加到 right，目标内的计数都应大于 0。时间 O(n + U)，空间 O(U)。本题数组可设为 52，容纳 end = 50 时的位置 51；不能只从 left 开始累加。
  • 排序合并：坐标很大时，按起点排序，维护第一个未覆盖整数 reach = left；跳过 end < reach 的区间，start > reach 表示存在缺口，否则推进 reach = max(reach, end + 1)。reach > right 即成功。时间 O(n log n)，空间取决于排序实现及是否复制输入。

Java

class Solution {
    public boolean isCovered(int[][] ranges, int left, int right) {
        for (int x = left; x <= right; x++) {
            boolean covered = false;
            for (int[] range : ranges) {
                if (range[0] <= x && x <= range[1]) {
                    covered = true;
                    break;
                }
            }
            if (!covered) return false;
        }
        return true;
    }
}

from typing import List

class Solution:
    def isCovered(self, ranges: List[List[int]], left: int, right: int) -> bool:
        for x in range(left, right + 1):
            covered = False
            for start, end in ranges:
                if start <= x <= end:
                    covered = True
                    break
            if not covered:
                return False
        return True

面试追问

  • 坐标上限变成 10⁹？避免逐点扫描，改用排序合并区间；end + 1 需要注意整数溢出。
  • 需要找出第一个缺失整数？在首次内层失败时返回 x；当前扫描顺序已保证它最小。
  • 同一组区间查询很多次？小值域先构造覆盖计数，再对“未覆盖标记”做前缀和，每次查询可 O(1) 判断是否有缺口。
  • 允许动态添加和删除区间？若操作和查询都很多，可考虑支持区间加与区间最小值查询的线段树，查询最小覆盖数是否大于 0。
