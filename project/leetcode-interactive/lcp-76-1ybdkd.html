魔法棋盘

为棋盘中的问号选择空、黑、红，使任意一行或一列都不存在一对异色棋子，且它们之间恰好隔着一颗棋子。返回所有合法方案数。

约束的自动机化

对一条线从左到右读入非空棋子：合法序列只能是“全同色”或“黑红交替”。用 7 个状态记录当前线：空、单黑、单红、多黑、多红、交替末黑、交替末红。加入一个棋子时查状态转移表即可。

关键降维

转置棋盘后，让列数 m ≤ 5。每列状态仅占 3 bit；逐行 DFS 时，轮廓线掩码同时保存全部列的自动机状态。

算法正确性

自动机恰好拒绝“同色连续后出现异色”的首次违规，也保留全同色与严格交替的所有前缀。每个格子的三种选择同时检查当前行和当前列，因此叶节点与合法完整棋盘一一对应。

DP 过程

  1. 1. 若 n < m，转置，使状态维度不超过 5 列。
  2. 2. 外层记忆化 dfs(row, colMask)：mask 记录每列的 3-bit 自动机状态。
  3. 3. 在一行中递归枚举当前格的空/黑/红；行状态单独传递，列状态写回轮廓线。
  4. 4. 强制格只保留对应分支；处理完所有行时贡献 1。

复杂度与边界

  • 约束：n × m ≤ 30；转置后 m ≤ 5。
  • 状态：列自动机共 7^m 种，每行枚举最多 3^m 条局部路径。
  • 时间：约 O(n · 21^m)；空间 O(n · 8^m)。
  • 易错：空格不改变自动机；转置不是旋转，只交换行列；状态机要同时用于行与列。

常见误区

  • 仅检查相邻三格，忽略空位可跨越。
  • 把连续的全同色误判为非法。
  • 对宽边做轮廓线，导致状态爆炸。

每个自动机状态描述当前行/列已出现的非空颜色序列。dfs(row, mask) 逐格尝试空、B、R；放 B/R 时分别执行 TRANS[rowState][color] 与 TRANS[colState][color]，任一为 -1 就剪枝。行末将更新后的 mask 交给下一行并记忆化。
