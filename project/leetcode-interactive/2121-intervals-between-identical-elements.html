01 / 题目

只统计相同值之间的下标距离

给定长度为 n、下标从 0 开始的整数数组 arr。对每个位置 i，找出所有满足 arr[j] == arr[i] 的位置 j，把它们与 i 的下标绝对差相加。返回长度同为 n 的数组 intervals，按原下标保存这些和。自己到自己的距离是 0，不影响结果。

intervals[i] = Σ |i − j|，其中 arr[j] = arr[i]

参数与约束

  • getDistances(arr)：输入整数数组，返回长整数语义的距离和数组。
  • n == arr.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ arr[i] ≤ 10⁵

题意及示例依据随任务提供的官方元数据转述。本题与 2615「等值距离和」相同。官方题目

官方示例 1

输入：arr = [2,1,3,1,2,3,3]
输出：[4,2,7,2,4,4,5]
  • i=0：|0−4|=4
  • i=1：|1−3|=2
  • i=2：|2−5|+|2−6|=7
  • i=3：|3−1|=2
  • i=4：|4−0|=4
  • i=5：|5−2|+|5−6|=4
  • i=6：|6−2|+|6−5|=5

官方示例 2

输入：arr = [10,5,10,10]
输出：[5,0,3,4]
  • i=0：|0−2|+|0−3|=5
  • i=1：没有其他 5，结果为 0
  • i=2：|2−0|+|2−3|=3
  • i=3：|3−0|+|3−2|=4

04 / 独立题解

准备好再展开

双向扫描：用计数和下标和汇总距离

核心洞察

绝对值难以直接合并，但按当前位置左右拆开后就可以。对值 v = arr[i]，左侧同值下标都小于 i，距离和为 i × count[v] − sum[v]；右侧同值下标都大于 i，距离和为 sum[v] − i × count[v]。只需知道同值元素的数量和下标总和，无需再次逐个访问它们。

完整过程

  1. 答案初始化为全 0；创建从元素值到「数量、下标和」的映射。
  2. 从左到右扫描。在加入当前位置前，用 i × count − sum 记录左侧贡献，再把当前位置计入映射。
  3. 清空映射，从右到左扫描。用 sum − i × count 加上右侧贡献，再计入当前位置。
  4. 返回按原始下标存储的答案。

正确性说明
第一趟处理 i 前，映射中恰好保存所有 j<i 且值相同的位置数量和下标和。初始为空满足这一不变式；处理后加入 i，使下一位置仍满足它。因此 i × count − sum = Σ(i−j) 精确给出左侧距离和。第二趟同理，处理 i 前只保存 j>i 的同值位置，sum − i × count = Σ(j−i) 精确给出右侧距离和。左右集合互不相交，合起来包含除自身外全部同值位置；自身贡献为 0。两趟相加即为题目所求。


边界与数值类型
  • 仅出现一次的值：两侧计数均为 0，答案为 0；长度 1 同理。
  • 全部相同：仍只有两次线性扫描，无需逐对枚举。
  • 最大单项答案为 n(n−1)/2，n=100000 时是 4,999,950,000，超过有符号 32 位整数。
  • Java 用 long，并在乘法前提升类型；C++ 用 long long；Python int 自动扩展；JavaScript Number 在本题范围内可精确表示整数，不使用 32 位位运算。


复杂度
设不同值数量为 k。哈希表查询与更新按平均 O(1) 计，两趟总时间为 O(n)；映射辅助空间 O(k)，答案空间 O(n)，总空间 O(n)。哈希表方案的时间结论采用平均复杂度口径。


替代方案
  • 按值分组 + 前缀和：从左到右收集每个值的下标，天然有序。某组位置为 p，大小 m，总下标和 T，处理第 r 项前的前缀和为 S，则答案是 r*p[r]−S + (T−S−p[r])−(m−r−1)*p[r]。总时间平均 O(n)，保存全部分组需要 O(n) 空间。
  • 值域数组：利用 arr[i]≤100000，用固定计数数组与下标和数组替代映射，可避免哈希；初始化成本 O(U)，时间 O(n+U)、辅助空间 O(U)，U=100001。
  • 逐对比较：直接按定义累加，O(n²) 时间，适合解释小样例，无法承受最大输入。


常见错误
  • 计算元素值的差，或同值元素在组内序号的差；距离需要原数组下标。
  • 第二趟忘记清空映射，混入错误方向的数据。
  • 右侧仍写成 i×count−sum，产生负贡献。
  • 按值排序后把新下标当原下标，或没有把答案放回原位置。
  • Java/C++ 先做 32 位乘法再转为长整数：溢出已发生。


面试追问
  • 能一趟给出最终结果吗？普通在线扫描尚不知道未来同值位置，只能得出左侧部分；可先统计总数和总下标和，再扫描得到两侧贡献。
  • 相邻组内位置能递推吗？若从 p[r−1] 移动 d 到 p[r]，距离和增加 (2r−m)×d，其中 r 从 1 开始表示新位置的组内下标。
  • 若只向尾部追加元素？新元素到既有同值元素的距离可由 count、sum 常数时间求出；所有旧元素的最终答案也会改变，批量维护需要额外设计。


Java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long[] getDistances(int[] arr) {
        int n = arr.length;
        long[] ans = new long[n];
        Map<Integer, long[]> stats = new HashMap<>();
        for (int i = 0; i < n; i++) {
            long[] s = stats.computeIfAbsent(arr[i], v -> new long[2]);
            ans[i] = (long) i * s[0] - s[1];
            s[0]++;
            s[1] += i;
        }
        stats.clear();
        for (int i = n - 1; i >= 0; i--) {
            long[] s = stats.computeIfAbsent(arr[i], v -> new long[2]);
            ans[i] += s[1] - (long) i * s[0];
            s[0]++;
            s[1] += i;
        }
        return ans;
    }
}

/**

var getDistances = function(arr) {
    const n = arr.length;
    const ans = new Array(n).fill(0);
    const stats = new Map();
    for (let i = 0; i < n; i++) {
        const s = stats.get(arr[i]) || [0, 0];
        ans[i] = i * s[0] - s[1];
        s[0]++;
        s[1] += i;
        stats.set(arr[i], s);
    }
    stats.clear();
    for (let i = n - 1; i >= 0; i--) {
        const s = stats.get(arr[i]) || [0, 0];
        ans[i] += s[1] - i * s[0];
        s[0]++;
        s[1] += i;
        stats.set(arr[i], s);
    }
    return ans;
};


Python 3
from typing import List

class Solution:
    def getDistances(self, arr: List[int]) -> List[int]:
        n = len(arr)
        ans = [0] * n
        stats = {}
        for i, value in enumerate(arr):
            count, total = stats.get(value, (0, 0))
            ans[i] = i * count - total
            stats[value] = (count + 1, total + i)
        stats.clear()
        for i in range(n - 1, -1, -1):
            value = arr[i]
            count, total = stats.get(value, (0, 0))
            ans[i] += total - i * count
            stats[value] = (count + 1, total + i)
        return ans


C++
#include <vector>
#include <unordered_map>
#include <utility>
using namespace std;

class Solution {
public:
    vector<long long> getDistances(vector<int>& arr) {
        int n = static_cast<int>(arr.size());
        vector<long long> ans(n, 0);
        unordered_map<int, pair<long long, long long>> stats;
        for (int i = 0; i < n; ++i) {
            auto& s = stats[arr[i]];
            ans[i] = 1LL * i * s.first - s.second;
            ++s.first;
            s.second += i;
        }
        stats.clear();
        for (int i = n - 1; i >= 0; --i) {
            auto& s = stats[arr[i]];
            ans[i] += s.second - 1LL * i * s.first;
            ++s.first;
            s.second += i;
        }
        return ans;
    }
};
