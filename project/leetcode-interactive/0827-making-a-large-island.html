最大人工岛

一格海水，能让岛屿长多大？在一个由 0 与 1 组成的方阵中，最多把一个 0 改成 1，求可能得到的最大四向连通岛屿面积。

核心标签DFS / BFS · 并查集 · 矩阵
函数签名largestIsland(grid) → integer

Problem

题目说明

深度优先搜索广度优先搜索并查集矩阵

给定一个 n × n 的二进制矩阵 grid。你可以执行至多一次操作：选择任意一格 0，把它改成 1。

请返回操作后矩阵中最大的岛屿面积。岛屿由若干个值为 1 的格子构成，并且格子之间只能通过上、下、左、右四个方向连通。

“至多一次”意味着全为 1 时无需修改；答案就是整个方阵的面积。

约束

  • n == grid.length
  • n == grid[i].length
  • 1 ≤ n ≤ 500
  • grid[i][j] 只能是 0 或 1

Example 01

输入：grid = [[1,0],[0,1]]
输出：3
解释：翻转一个 0，连接两个单格岛屿。

Example 02

输入：grid = [[1,1],[1,0]]
输出：4
解释：把右下角改为 1，整张网格连通。

Example 03

输入：grid = [[1,1],[1,1]]
输出：4
解释：没有海水需要翻转，面积仍为 4。

Complete solution

先标记，再尝试桥接

时间 O(n²) · 空间 O(n²)
INSIGHT 01

每座现有岛屿只计算一次

遍历矩阵，用 DFS 或 BFS 把每个连通块染成唯一编号，并记录编号对应的面积。之后遇到相邻陆地时，可以 O(1) 查到整座岛屿的大小。

INSIGHT 02

翻转一个 0，最多连接四座岛

一个海水格只有四个邻居。把它变成陆地后，新面积等于 1 加上四邻域中不同岛屿的面积总和。

INSIGHT 03

相同编号必须去重

同一座岛可能从两个方向接触候选海水格。用集合记录已计入的岛屿编号，避免重复累加。

Process

完整过程

1
标记岛屿

扫描所有格子。遇到未标记的 1，从编号 2 开始执行一次遍历，把连通块改成该编号，同时统计面积。

2
保存面积

建立 area[id] = size。同时用现有岛屿面积更新答案，以覆盖全为 1 的情况。

3
枚举海水

对每个 0，检查四邻域。把相邻且不同的岛屿编号放入集合。

4
计算桥接面积

候选面积从 1 开始，加上集合中每个编号对应的面积，并更新全局最大值。

5
返回最优值

所有候选格处理完后，答案覆盖全 0、普通混合矩阵以及全 1 三类情况。

Correctness

正确性证明

引理 1：标记阶段为每座原始岛屿分配唯一编号，并正确记录其面积。因为遍历从一个未标记陆地出发，恰好访问所有与它四向连通的陆地；已染色格不会被其他遍历再次计入。

引理 2：翻转某个海水格后，新连通块的面积等于 1 + Σ area[id]，其中 id 来自它四邻域中的不同岛屿。新格只可能直接连接四邻域中的岛屿；同编号去重后，每座被连接的岛恰好贡献一次完整面积。

引理 3：算法会计算每一种合法单格翻转产生的岛屿面积。因为第二次扫描枚举了矩阵中的每一个 0。

定理：算法返回允许至多翻转一个 0 后的最大岛屿面积。由引理 2，每个候选值都准确；由引理 3，所有翻转方案都被枚举；答案还与原有岛屿面积比较，因此不翻转的合法方案也被覆盖。故返回值为全局最优。

Complexity & edges

复杂度与边界

时间复杂度O(n²)

每个格子在标记与枚举阶段各处理常数次。

空间复杂度O(n²)

最坏情况下遍历栈、岛屿编号与面积表占用平方级空间。

全是 0

翻转任意一格即可得到面积 1。

全是 1

没有候选海水，但标记阶段已把答案更新为 n²。

同一岛多面相邻

必须按岛屿编号去重，否则面积会被重复计算。

最大尺寸 500

使用显式栈可避免深递归造成调用栈溢出。

import java.util.*;

class Solution {
    private static final int[][] DIRS = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    public int largestIsland(int[][] grid) {
        int n = grid.length;
        Map<Integer, Integer> area = new HashMap<>();
        int islandId = 2;
        int answer = 0;

        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) {
                    int size = paint(grid, r, c, islandId);
                    area.put(islandId, size);
                    answer = Math.max(answer, size);
                    islandId++;
                }
            }
        }

        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] != 0) continue;

                int candidate = 1;
                Set<Integer> seen = new HashSet<>();
                for (int[] d : DIRS) {
                    int nr = r + d[0], nc = c + d[1];
                    if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                        int id = grid[nr][nc];
                        if (id > 1 && seen.add(id)) {
                            candidate += area.get(id);
                        }
                    }
                }
                answer = Math.max(answer, candidate);
            }
        }
        return answer;
    }

    private int paint(int[][] grid, int startR, int startC, int id) {
        int n = grid.length;
        int[] rows = new int[n * n];
        int[] cols = new int[n * n];
        int top = 0;
        rows[top] = startR;
        cols[top++] = startC;
        grid[startR][startC] = id;
        int size = 0;

        while (top > 0) {
            top--;
            int r = rows[top], c = cols[top];
            size++;
            for (int[] d : DIRS) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < n && nc >= 0 && nc < n
                        && grid[nr][nc] == 1) {
                    grid[nr][nc] = id;
                    rows[top] = nr;
                    cols[top++] = nc;
                }
            }
        }
        return size;
    }
}

var largestIsland = function(grid) {
    const n = grid.length;
    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    const area = new Map();
    let islandId = 2;
    let answer = 0;

    const paint = (startR, startC, id) => {
        const stack = [[startR, startC]];
        grid[startR][startC] = id;
        let size = 0;

        while (stack.length > 0) {
            const [r, c] = stack.pop();
            size++;
            for (const [dr, dc] of dirs) {
                const nr = r + dr;
                const nc = c + dc;
                if (nr >= 0 && nr < n && nc >= 0 && nc < n
                    && grid[nr][nc] === 1) {
                    grid[nr][nc] = id;
                    stack.push([nr, nc]);
                }
            }
        }
        return size;
    };

    for (let r = 0; r < n; r++) {
        for (let c = 0; c < n; c++) {
            if (grid[r][c] === 1) {
                const size = paint(r, c, islandId);
                area.set(islandId, size);
                answer = Math.max(answer, size);
                islandId++;
            }
        }
    }

    for (let r = 0; r < n; r++) {
        for (let c = 0; c < n; c++) {
            if (grid[r][c] !== 0) continue;

            let candidate = 1;
            const seen = new Set();
            for (const [dr, dc] of dirs) {
                const nr = r + dr;
                const nc = c + dc;
                if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                    const id = grid[nr][nc];
                    if (id > 1 && !seen.has(id)) {
                        seen.add(id);
                        candidate += area.get(id);
                    }
                }
            }
            answer = Math.max(answer, candidate);
        }
    }
    return answer;
};
from typing import List


class Solution:
    def largestIsland(self, grid: List[List[int]]) -> int:
        n = len(grid)
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
        area = {}
        island_id = 2
        answer = 0

        def paint(start_row: int, start_col: int, mark: int) -> int:
            stack = [(start_row, start_col)]
            grid[start_row][start_col] = mark
            size = 0

            while stack:
                row, col = stack.pop()
                size += 1
                for dr, dc in directions:
                    nr, nc = row + dr, col + dc
                    if 0 <= nr < n and 0 <= nc < n and grid[nr][nc] == 1:
                        grid[nr][nc] = mark
                        stack.append((nr, nc))
            return size

        for row in range(n):
            for col in range(n):
                if grid[row][col] == 1:
                    size = paint(row, col, island_id)
                    area[island_id] = size
                    answer = max(answer, size)
                    island_id += 1

        for row in range(n):
            for col in range(n):
                if grid[row][col] != 0:
                    continue

                candidate = 1
                seen = set()
                for dr, dc in directions:
                    nr, nc = row + dr, col + dc
                    if 0 <= nr < n and 0 <= nc < n:
                        mark = grid[nr][nc]
                        if mark > 1 and mark not in seen:
                            seen.add(mark)
                            candidate += area[mark]
                answer = max(answer, candidate)

        return answer
#include <algorithm>
#include <unordered_map>
#include <unordered_set>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int largestIsland(vector<vector<int>>& grid) {
        const int n = static_cast<int>(grid.size());
        const int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        unordered_map<int, int> area;
        int islandId = 2;
        int answer = 0;

        auto paint = [&](int startR, int startC, int id) {
            vector<pair<int, int>> stack = {{startR, startC}};
            grid[startR][startC] = id;
            int size = 0;

            while (!stack.empty()) {
                auto [r, c] = stack.back();
                stack.pop_back();
                size++;
                for (const auto& d : dirs) {
                    int nr = r + d[0], nc = c + d[1];
                    if (nr >= 0 && nr < n && nc >= 0 && nc < n
                        && grid[nr][nc] == 1) {
                        grid[nr][nc] = id;
                        stack.push_back({nr, nc});
                    }
                }
            }
            return size;
        };

        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 1) {
                    int size = paint(r, c, islandId);
                    area[islandId] = size;
                    answer = max(answer, size);
                    islandId++;
                }
            }
        }

        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] != 0) continue;

                int candidate = 1;
                unordered_set<int> seen;
                for (const auto& d : dirs) {
                    int nr = r + d[0], nc = c + d[1];
                    if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                        int id = grid[nr][nc];
                        if (id > 1 && seen.insert(id).second) {
                            candidate += area[id];
                        }
                    }
                }
                answer = max(answer, candidate);
            }
        }
        return answer;
    }
};

Alternative

替代方案：并查集

先把相邻陆地合并，在根节点维护集合大小，再枚举每个 0 的相邻根。复杂度同为近似 O(n²)，但实现常数与代码量通常更大。

Why not brute force

为什么不逐格重算？

若每翻转一个 0 都重新遍历整张矩阵，最坏会枚举 O(n²) 个候选，每次又花 O(n²)，总计 O(n⁴)，在 n = 500 时不可接受。

Interview follow-up

如果允许翻转 k 个 0？

单格局部合并不再足够。可讨论参数较小时的状态搜索、网格图上的连通优化，或特定约束下的滑动窗口；一般形式明显更复杂。

Interview follow-up

能否不修改输入？

可以另建 labels[n][n] 保存编号，逻辑不变；代价是显式增加 O(n²) 辅助空间，但保留原矩阵。

Common mistakes

常见错误

  • 把对角线也视为连通；本题只允许四个正交方向。
  • 没有为相邻岛屿编号去重，导致同一座岛被重复累加。
  • 答案只在枚举 0 时更新，遗漏全为 1 的矩阵。
  • 使用深度递归处理 500 × 500 的单一大岛，造成语言运行时栈溢出。
  • 染色时仍只判断值是否为 1 不够谨慎，重复入栈；应在入栈时立即写入编号。
