1172. Dinner Plate Stacks

HARD栈设计哈希表堆（优先队列）

题目

有无限个从左到右编号为 0, 1, 2, ... 的栈，每个栈的最大容量均为 capacity。请实现 DinnerPlates，使放盘子总是优先填入最左侧未满栈，而普通取盘子总是从最右侧非空栈取出。

DinnerPlates(int capacity)

以统一的栈容量初始化对象。

void push(int val)

把 val 放到最左边尚未满的栈顶。

int pop()

弹出最右边非空栈的栈顶；全部为空时返回 -1。

int popAtStack(int index)

弹出指定编号栈的栈顶；下标无效或该栈为空时返回 -1。

关键语义：栈内部仍然后进先出；“最左未满”只约束 push，“最右非空”只约束 pop。

  • 1 ≤ val ≤ 2 × 10⁴

Spoiler gate

准备好再揭晓

题解独立收起，先尝试找到“最左可放”和“最右可取”的高效维护方式。

题解：数组栈 + 最小堆

核心洞察

难点不在栈操作，而在快速定位位置。用动态数组保存所有栈，可在末尾找到最右非空栈；再用最小堆保存“可能未满”的栈下标，堆顶就是最左候选。堆内允许暂时存在重复或失效下标，每次使用前惰性清理，能让实现更简单。

  1. push(val)：持续弹出堆顶中已经越界或已满的下标；若堆空，创建一个新栈。把值放入堆顶所指的最左未满栈；若放满了，弹出这个堆顶候选。
  2. popAtStack(index)：若指定栈存在且非空，弹出顶部，并把该下标压入最小堆，因为它现在必然有空位。重复下标不影响正确性，会在栈满时被惰性清掉。
  3. pop()：先删除数组尾部的空栈，再对最后一个栈调用 popAtStack，最后再次收缩尾部空栈。

正确性证明

引理 1：执行 push 清理后，若堆非空，堆顶必是当前最左未满栈。所有曾被弹出而变为未满的栈都会由 popAtStack 加入堆；新栈也会加入。清理仅删除越界或已满候选，因此所有有效未满下标都至少有一份留在堆中，最小者位于堆顶。

引理 2：删除尾部空栈后，数组最后一个栈就是最右非空栈。数组按栈编号顺序存放，尾部空栈已全部移除，所以结论直接成立。

定理：由引理 1，所有 push 都进入最左未满栈；由引理 2，所有 pop 都来自最右非空栈；popAtStack 直接操作指定栈。因此实现满足全部接口语义。

复杂度

push
O(log q) 摊还
popAtStack
O(log q)
pop
O(log q) 摊还

其中 q 为操作次数。尾部空栈和失效堆项各自只会被删除有限次，因此清理成本可摊还；空间复杂度为 O(q)。

边界情况

  • 所有栈为空时，pop() 返回 -1。
  • popAtStack 的下标越界或对应栈为空时返回 -1。
  • 容量为 1 时，每个 push 可能创建新栈，定位规则仍不变。
  • 从中间栈弹出后，下次 push 必须先补这个更靠左的洞，而不是追加到末尾。

替代方案

可以用有序集合维护所有未满下标，插入、删除和取最小值均为 O(log q)，且不会有重复候选；Java 的 TreeSet、C++ 的 set 很适合。堆方案跨语言更统一，但需要惰性清理。若线性扫描未满栈，最坏会退化到 O(q²)。

面试追问

  • 如何把堆改成无重复的有序集合？状态更新点有哪些？
  • 为什么尾部收缩是摊还 O(1)，而不是每次 O(q)？
  • 如果 pop 也需要支持“第 k 个非空栈”，应换用什么索引结构？
  • 并发调用时，如何保证“最左未满”的选择与实际 push 原子一致？

常见错误

  • 用最大堆维护未满栈，导致 push 填入最右空位。
  • 中间栈弹出后忘记重新加入候选集合。
  • 只在 pop 前清理尾部，导致无意义空栈长期保留。
  • 认为堆内重复下标必然错误，却又没有配套去重集合；重复可以保留，但使用前必须检查是否仍未满。

import java.util.*;

class DinnerPlates {
    private final int capacity;
    private final List<Deque<Integer>> stacks = new ArrayList<>();
    private final PriorityQueue<Integer> available = new PriorityQueue<>();

    public DinnerPlates(int capacity) {
        this.capacity = capacity;
    }

    public void push(int val) {
        while (!available.isEmpty()) {
            int i = available.peek();
            if (i >= stacks.size() || stacks.get(i).size() == capacity) {
                available.poll();
            } else {
                break;
            }
        }
        if (available.isEmpty()) {
            stacks.add(new ArrayDeque<>());
            available.offer(stacks.size() - 1);
        }
        int i = available.peek();
        stacks.get(i).push(val);
        if (stacks.get(i).size() == capacity) available.poll();
    }

    public int pop() {
        trim();
        if (stacks.isEmpty()) return -1;
        int value = popAtStack(stacks.size() - 1);
        trim();
        return value;
    }

    public int popAtStack(int index) {
        if (index < 0 || index >= stacks.size() || stacks.get(index).isEmpty()) {
            return -1;
        }
        int value = stacks.get(index).pop();
        available.offer(index);
        return value;
    }

    private void trim() {
        while (!stacks.isEmpty() && stacks.get(stacks.size() - 1).isEmpty()) {
            stacks.remove(stacks.size() - 1);
        }
    }
}
var DinnerPlates = function(capacity) {
  this.capacity = capacity;
  this.stacks = [];
  this.heap = [];
};

DinnerPlates.prototype.heapPush = function(x) {
  const h = this.heap;
  h.push(x);
  let i = h.length - 1;
  while (i > 0) {
    const p = (i - 1) >> 1;
    if (h[p] <= h[i]) break;
    [h[p], h[i]] = [h[i], h[p]];
    i = p;
  }
};

DinnerPlates.prototype.heapPop = function() {
  const h = this.heap;
  const top = h[0];
  const last = h.pop();
  if (h.length) {
    h[0] = last;
    let i = 0;
    while (true) {
      let m = i, l = i * 2 + 1, r = l + 1;
      if (l < h.length && h[l] < h[m]) m = l;
      if (r < h.length && h[r] < h[m]) m = r;
      if (m === i) break;
      [h[i], h[m]] = [h[m], h[i]];
      i = m;
    }
  }
  return top;
};

DinnerPlates.prototype.push = function(val) {
  while (this.heap.length) {
    const i = this.heap[0];
    if (i >= this.stacks.length || this.stacks[i].length === this.capacity) {
      this.heapPop();
    } else break;
  }
  if (!this.heap.length) {
    this.stacks.push([]);
    this.heapPush(this.stacks.length - 1);
  }
  const i = this.heap[0];
  this.stacks[i].push(val);
  if (this.stacks[i].length === this.capacity) this.heapPop();
};

DinnerPlates.prototype.pop = function() {
  while (this.stacks.length && !this.stacks[this.stacks.length - 1].length) {
    this.stacks.pop();
  }
  if (!this.stacks.length) return -1;
  const value = this.popAtStack(this.stacks.length - 1);
  while (this.stacks.length && !this.stacks[this.stacks.length - 1].length) {
    this.stacks.pop();
  }
  return value;
};

DinnerPlates.prototype.popAtStack = function(index) {
  if (index < 0 || index >= this.stacks.length || !this.stacks[index].length) return -1;
  const value = this.stacks[index].pop();
  this.heapPush(index);
  return value;
};
import heapq

class DinnerPlates:
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.stacks = []
        self.available = []

    def push(self, val: int) -> None:
        while self.available:
            i = self.available[0]
            if i >= len(self.stacks) or len(self.stacks[i]) == self.capacity:
                heapq.heappop(self.available)
            else:
                break
        if not self.available:
            self.stacks.append([])
            heapq.heappush(self.available, len(self.stacks) - 1)
        i = self.available[0]
        self.stacks[i].append(val)
        if len(self.stacks[i]) == self.capacity:
            heapq.heappop(self.available)

    def pop(self) -> int:
        while self.stacks and not self.stacks[-1]:
            self.stacks.pop()
        if not self.stacks:
            return -1
        value = self.popAtStack(len(self.stacks) - 1)
        while self.stacks and not self.stacks[-1]:
            self.stacks.pop()
        return value

    def popAtStack(self, index: int) -> int:
        if index < 0 or index >= len(self.stacks) or not self.stacks[index]:
            return -1
        value = self.stacks[index].pop()
        heapq.heappush(self.available, index)
        return value
#include <vector>
#include <queue>
#include <functional>
using namespace std;

class DinnerPlates {
    int capacity;
    vector<vector<int>> stacks;
    priority_queue<int, vector<int>, greater<int>> available;

    void trim() {
        while (!stacks.empty() && stacks.back().empty()) stacks.pop_back();
    }

public:
    DinnerPlates(int capacity) : capacity(capacity) {}

    void push(int val) {
        while (!available.empty()) {
            int i = available.top();
            if (i >= (int)stacks.size() || (int)stacks[i].size() == capacity) {
                available.pop();
            } else break;
        }
        if (available.empty()) {
            stacks.push_back({});
            available.push((int)stacks.size() - 1);
        }
        int i = available.top();
        stacks[i].push_back(val);
        if ((int)stacks[i].size() == capacity) available.pop();
    }

    int pop() {
        trim();
        if (stacks.empty()) return -1;
        int value = popAtStack((int)stacks.size() - 1);
        trim();
        return value;
    }

    int popAtStack(int index) {
        if (index < 0 || index >= (int)stacks.size() || stacks[index].empty()) {
            return -1;
        }
        int value = stacks[index].back();
        stacks[index].pop_back();
        available.push(index);
        return value;
    }
};
