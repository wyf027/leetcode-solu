题目

准确转述

给定一个 m × n 的整数矩阵 mat 和整数阈值 threshold，请在矩阵中选择一个轴对齐的正方形区域，使该区域内所有元素的总和不超过阈值。

返回所有满足条件的正方形中的最大边长；若连边长为 1 的正方形也不存在，返回 0。

maxSideLength(mat: integer[][], threshold: integer) → integer
输入非空矩阵 mat 与非负整数 threshold
输出满足区域和 ≤ threshold 的最大正方形边长
注意矩阵元素均非负，因此“可行边长”具有单调性

Solution

二维前缀和 + 二分答案

核心洞察

二维前缀和让任意正方形的元素和在 O(1) 时间内得到。由于所有矩阵元素非负：若存在边长为 x 的可行正方形，则其中任取更小的正方形也可行。因此“某个边长是否可行”关于边长呈单调性，可以二分最大可行边长。

前缀和公式

定义 pre[i][j] 为前 i 行、前 j 列的矩形和，并额外保留第 0 行、第 0 列为 0。

sum(r, c, k) = pre[r+k][c+k] − pre[r][c+k] − pre[r+k][c] + pre[r][c]

完整过程

  1. 建立大小为 (m + 1) × (n + 1) 的二维前缀和数组。
  2. 令二分区间为 [0, min(m, n)]，其中 0 必然可行。
  3. 用向上取整的中点 mid = floor((left + right + 1) / 2)，避免区间只剩两个数时停滞。
  4. 枚举每个可能的左上角，用四个前缀值检查边长 mid 的区域和。
  5. 只要找到一个区域和不超过阈值，就令 left = mid；否则令 right = mid - 1。
  6. 当左右边界相等时，该值就是最大可行边长。

正确性证明

引理 1：二维前缀和的容斥公式精确计算任意候选正方形的元素和，因此可行性检查正确。

引理 2：若边长 k 可行，其可行正方形内任取一个更小正方形；元素非负，所以更小区域和不会增大，故所有小于 k 的边长也可行。

结论：可行性具有“真…真假…假”的单调结构。二分始终保留最大可行答案，终止时 left == right，返回值正是最大可行边长。

边界与复杂度

  • threshold = 0 时，零元素组成的正方形仍可能可行。
  • 没有任何 1 × 1 区域可行时返回 0。
  • 整张矩阵可行时返回 min(m, n)。
  • 时间：O(mn log(min(m,n)))。
  • 空间：O(mn)。

替代方案

可以从边长 1 开始递增扫描，并利用“当前已知答案”只尝试扩大一圈。在非负矩阵下，这种写法可做到 O(mn) 次区域查询，通常更快；但二分答案更直接地体现单调性，也更容易推广到其他“最大可行尺寸”问题。

常见错误

  • 前缀数组没有多留一行一列，导致边界判断复杂且容易越界。
  • 容斥时加减符号或右下角下标写错。
  • 使用向下取整中点并令 left = mid，造成死循环。
  • 误以为一定存在答案 1，忽略答案可能为 0。

面试追问

为什么元素非负很关键？

它保证缩小区域不会让总和增加，从而建立按边长的可行性单调性。若允许负数，更大的正方形可能反而更小，二分依据不再成立。

能否降低额外空间？

完整二维区域和的常数时间查询通常需要 O(mn) 前缀存储。若改用逐行滑动窗口，可在不同时间/实现复杂度权衡下压缩部分空间，但不再是相同的简单查询模型。

为什么检查一个边长需要 O(mn)？

该边长共有 (m-k+1)(n-k+1) 个左上角，每个区域和通过前缀和在 O(1) 时间计算。

class Solution {
    public int maxSideLength(int[][] mat, int threshold) {
        int m = mat.length, n = mat[0].length;
        int[][] pre = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                pre[i][j] = mat[i - 1][j - 1]
                    + pre[i - 1][j] + pre[i][j - 1]
                    - pre[i - 1][j - 1];
            }
        }

        int left = 0, right = Math.min(m, n);
        while (left < right) {
            int mid = left + (right - left + 1) / 2;
            if (exists(pre, m, n, mid, threshold)) {
                left = mid;
            } else {
                right = mid - 1;
            }
        }
        return left;
    }

    private boolean exists(int[][] pre, int m, int n,
                           int size, int threshold) {
        for (int i = size; i <= m; i++) {
            for (int j = size; j <= n; j++) {
                int sum = pre[i][j] - pre[i - size][j]
                    - pre[i][j - size] + pre[i - size][j - size];
                if (sum <= threshold) return true;
            }
        }
        return false;
    }
}

var maxSideLength = function(mat, threshold) {
    const m = mat.length;
    const n = mat[0].length;
    const pre = Array.from({ length: m + 1 },
        () => Array(n + 1).fill(0));

    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            pre[i][j] = mat[i - 1][j - 1]
                + pre[i - 1][j] + pre[i][j - 1]
                - pre[i - 1][j - 1];
        }
    }

    const exists = (size) => {
        for (let i = size; i <= m; i++) {
            for (let j = size; j <= n; j++) {
                const sum = pre[i][j] - pre[i - size][j]
                    - pre[i][j - size] + pre[i - size][j - size];
                if (sum <= threshold) return true;
            }
        }
        return false;
    };

    let left = 0;
    let right = Math.min(m, n);
    while (left < right) {
        const mid = Math.floor((left + right + 1) / 2);
        if (exists(mid)) left = mid;
        else right = mid - 1;
    }
    return left;
};
from typing import List


class Solution:
    def maxSideLength(
        self, mat: List[List[int]], threshold: int
    ) -> int:
        m, n = len(mat), len(mat[0])
        pre = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                pre[i][j] = (
                    mat[i - 1][j - 1]
                    + pre[i - 1][j]
                    + pre[i][j - 1]
                    - pre[i - 1][j - 1]
                )

        def exists(size: int) -> bool:
            for i in range(size, m + 1):
                for j in range(size, n + 1):
                    square_sum = (
                        pre[i][j]
                        - pre[i - size][j]
                        - pre[i][j - size]
                        + pre[i - size][j - size]
                    )
                    if square_sum <= threshold:
                        return True
            return False

        left, right = 0, min(m, n)
        while left < right:
            mid = (left + right + 1) // 2
            if exists(mid):
                left = mid
            else:
                right = mid - 1
        return left
