找到和最大的长度为 K 的子序列

Find Subsequence of Length K With the Largest Sum

留下恰好 k 个数字，让总和尽可能大。
你可以删除元素，但留下的数字必须保持原来的先后顺序。

官方题目 ↗

01 / 题目与输入

给定整数数组 nums 和整数 k，返回长度恰好为 k、元素总和最大的任意一个子序列。子序列不要求连续，但不能调换元素顺序；若多个结果达到同一个最大和，返回其中任何一个即可。

函数：maxSubsequence(nums, k) → 整数数组

官方示例 1

nums = [2,1,3,3]
k = 2
输出：[3,3]

总和为 6。

官方示例 2

nums = [-1,-2,3,4]
k = 3
输出：[-1,3,4]

总和为 6，负数也可能必须保留。

官方示例 3

nums = [3,4,3,3]
k = 2
输出：[3,4]

总和为 7；[4,3] 也是合法答案。

约束

  • 1 ≤ nums.length ≤ 1000
  • −10⁵ ≤ nums[i] ≤ 10⁵
  • 1 ≤ k ≤ nums.length

04 / 独立题解

准备好后展开思路、证明与四种语言实现。

核心洞察：数值决定选择，位置决定顺序

任何 k 个位置都能按下标升序构成一个子序列。因此最大化总和时，只需选择最大的 k 个元素；为了满足子序列定义，最后再按它们的原始下标排序。相同数字仍是不同位置上的元素，不能去重。

完整过程

  1. 建立原下标列表 [0,1,…,n−1]，始终保留原数组。
  2. 按 nums[i] 降序排列下标。为使演示和四份代码结果一致，同值时优先较小下标。
  3. 截取前 k 个下标，这些位置对应最大的 k 个数。
  4. 将入选下标按升序排列，再映射回 nums 的值。

例如 nums = [3,4,3,3], k = 2：下标排名为 [1,0,2,3]，取 [1,0]，恢复原序为 [0,1]，返回 [3,4]。

正确性 · 交换论证

设算法选择的位置集合为 S，包含数值最大的 k 个元素。对任意其他大小为 k 的位置集合 T，如果 T 与 S 不同，可以找到 T 中未被 S 选中的位置 a，以及 S 中尚未在 T 的位置 b。由于 S 取前 k 大，必有 nums[b] ≥ nums[a]。用 b 替换 a 不会减小总和。重复交换直到得到 S，说明 S 的总和不小于任意 T。最后按原下标升序排列 S，不改变集合及总和，且保证结果是原数组的合法子序列。因此算法正确。

边界与常见错误

  • k = 1 选最大值；k = n 返回原顺序的全部元素。
  • 全为负数时，仍必须选择 k 个数，优先选择更接近 0 的值。
  • 同值可以任取合适的出现位置；固定下标作为次序仅用于确定性输出。
  • 直接把数值降序排序后返回，会破坏子序列顺序。例如 [2,3,1] 不能返回 [3,2]。
  • 用值的 Set 去重会丢失重复元素；应记录下标。
  • JavaScript 默认排序是字符串排序，数值及下标排序均需提供比较函数。
  • 这不是长度为 k 的连续子数组，滑动窗口会错误限制选择范围。

复杂度

建立索引 O(n)，排序 O(n log n)，截取 O(k)，恢复次序 O(k log k)，生成结果 O(k)。总时间 O(n log n)，额外空间 O(n)（包括索引及排序辅助空间），返回数组 O(k)。题目范围内总和绝对值不超过 10⁸；实现本身不需要计算总和。

替代方案

  • 大小为 k 的最小堆：维护当前最大的 k 个“值、下标”对，再将入选下标排序。时间 O(n log(k+1) + k log k)，空间 O(k)，适合 k 远小于 n。
  • 快速选择：在带下标的副本上划分出前 k 大，再恢复下标顺序。期望时间 O(n + k log k)，普通快速选择最坏 O(n²)；需要正确处理相同值。
  • 阈值加原序扫描：求出第 k 大值，保留所有大于阈值的数，再按剩余额度取等于阈值的数。一次原序扫描即可输出，注意同值计数。

面试追问

要求字典序最小怎么办？最大和相同并不代表字典序相同，按较小下标打破平局不保证字典序最小，需要额外设计满足可行性的选择策略。输入是流怎么办？保留递增位置编号并维护大小为 k 的堆，结束时按位置输出。改为连续子数组呢？改用长度为 k 的滑动窗口，问题约束已经不同。

Java

import java.util.Arrays;

class Solution {
    public int[] maxSubsequence(int[] nums, int k) {
        Integer[] indices = new Integer[nums.length];
        for (int i = 0; i < nums.length; i++) indices[i] = i;
        Arrays.sort(indices, (a, b) -> {
            int byValue = Integer.compare(nums[b], nums[a]);
            return byValue != 0 ? byValue : Integer.compare(a, b);
        });
        Integer[] chosen = Arrays.copyOf(indices, k);
        Arrays.sort(chosen);
        int[] answer = new int[k];
        for (int i = 0; i < k; i++) answer[i] = nums[chosen[i]];
        return answer;
    }
}

/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number[]}
 */
var maxSubsequence = function(nums, k) {
    return Array.from(nums.keys())
        .sort((a, b) => nums[b] - nums[a] || a - b)
        .slice(0, k)
        .sort((a, b) => a - b)
        .map(i => nums[i]);
};

Python 3

from typing import List

class Solution:
    def maxSubsequence(self, nums: List[int], k: int) -> List[int]:
        indices = sorted(range(len(nums)), key=lambda i: (-nums[i], i))
        chosen = sorted(indices[:k])
        return [nums[i] for i in chosen]

C++

#include <algorithm>
#include <numeric>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> maxSubsequence(vector<int>& nums, int k) {
        vector<int> indices(nums.size());
        iota(indices.begin(), indices.end(), 0);
        sort(indices.begin(), indices.end(), [&](int a, int b) {
            if (nums[a] != nums[b]) return nums[a] > nums[b];
            return a < b;
        });
        indices.resize(k);
        sort(indices.begin(), indices.end());
        vector<int> answer;
        answer.reserve(k);
        for (int i : indices) answer.push_back(nums[i]);
        return answer;
    }
};
