Problem

题目转述

给定产品表和发票表，输出所有产品在全部发票中的未付、已付、取消与退款金额总和，并按产品名升序排列。

任务

每条发票属于一个产品，并记录四个互相独立的金额字段：rest、paid、canceled 与 refunded。

请编写 SQL 查询，让结果中的每一行对应一个产品，包含产品名称以及四个字段在该产品全部发票上的合计。

即使某个产品没有任何发票，它也属于“所有产品”，四项金额应以 0 表示。最终结果按 name 升序排列。

输出列： name、rest、paid、canceled、refunded。

约束与关系

  • Product.product_id 是产品表主键。
  • Invoice.invoice_id 是发票表主键，Invoice.product_id 指向对应产品。
  • 产品名称只含小写英文字母，且任意两个产品的名称不同。
  • 四类金额字段均为整数；官方元数据未提供额外的行数或数值范围，本文不虚构范围。

Solution

保留产品，再聚合发票

关键不是“如何求和”，而是“如何保证零张发票的产品仍出现在结果中”。

1

从产品出发

结果要求覆盖所有产品，因此产品表必须是保留侧。

2

按产品汇总

同一产品可对应多张发票，四个字段需要分别求和。

3

把空值归零

没有匹配发票时，聚合结果为 NULL，要显式转成 0。

完整过程

  1. 以 Product 为左表，对 Invoice 按 product_id 做 LEFT JOIN，让无发票产品也拥有一条连接结果。
  2. 按产品的主键与名称分组。主键明确分组身份，名称用于输出。
  3. 分别对 rest、paid、canceled、refunded 求和。
  4. 对每个和使用 COALESCE(..., 0)，覆盖无匹配发票时的空值。
  5. 最后按 name 升序排列，得到题目要求的稳定顺序。

官方提交语言：MySQL

可直接作为本题数据库查询提交；本页未执行验证。
SELECT
    p.name,
    COALESCE(SUM(i.rest), 0) AS rest,
    COALESCE(SUM(i.paid), 0) AS paid,
    COALESCE(SUM(i.canceled), 0) AS canceled,
    COALESCE(SUM(i.refunded), 0) AS refunded
FROM Product AS p
LEFT JOIN Invoice AS i
    ON i.product_id = p.product_id
GROUP BY p.product_id, p.name
ORDER BY p.name;

正确性说明

引理 1：LEFT JOIN 保证每个 Product 行至少贡献一条连接结果；所以有发票和无发票的产品都不会消失。

引理 2：按产品分组后，一个分组恰好包含该产品的全部匹配发票；对四列分别执行 SUM，得到对应产品的四项总额。

引理 3：若产品没有发票，连接出的发票列为空，聚合和也是空；COALESCE 将其变为题意所需的 0。

结论：每个产品恰好输出一行，四项金额正确，且 ORDER BY p.name 使结果满足升序要求，因此查询正确。

复杂度与边界

  • 设产品数为 P、发票数为 I。典型哈希连接/聚合计划约为 O(P + I)，最终排序约为 O(P log P)。
  • 聚合状态通常需要 O(P) 空间；具体执行计划与索引由数据库优化器决定。
  • 零张发票、单张发票、多张发票都由同一查询覆盖。
  • 若金额允许负数，SUM 仍按数据原值累计；业务有效性应由数据规则另行保证。

替代方案

  • 先在子查询中按 product_id 聚合 Invoice，再左连接 Product，可先压缩发票行数。
  • 为四列分别写相关子查询更直观，但可能重复扫描 Invoice，通常不如一次聚合简洁。
  • IFNULL 可替代 MySQL 中的 COALESCE；后者更接近通用 SQL。

面试追问

  • 为什么不能使用 INNER JOIN？
  • 若只要最近 30 天发票，应把日期过滤放在哪里，才能保留无发票产品？
  • 哪些索引可能帮助连接与分组？
  • 若产品名称不唯一，分组依据应该怎样设计？

常见错误

  • 使用内连接，意外丢掉没有发票的产品。
  • 忘记处理空聚合，输出 NULL 而不是 0。
  • 只按名称分组，依赖了不必要的唯一性假设。
  • 漏写排序，导致结果顺序不满足题意。

import java.util.*;

public class SolutionRef {
    static class Product {
        int productId;
        String name;
        Product(int productId, String name) {
            this.productId = productId;
            this.name = name;
        }
    }

    static class Invoice {
        int invoiceId, productId;
        long rest, paid, canceled, refunded;
        Invoice(int invoiceId, int productId, long rest,
                long paid, long canceled, long refunded) {
            this.invoiceId = invoiceId;
            this.productId = productId;
            this.rest = rest;
            this.paid = paid;
            this.canceled = canceled;
            this.refunded = refunded;
        }
    }

    static class Result {
        String name;
        long rest, paid, canceled, refunded;
        Result(String name, long[] sum) {
            this.name = name;
            this.rest = sum[0];
            this.paid = sum[1];
            this.canceled = sum[2];
            this.refunded = sum[3];
        }
    }

    static List<Result> analyzeProducts(
            List<Product> products, List<Invoice> invoices) {
        Map<Integer, long[]> totals = new HashMap<>();
        for (Product product : products) {
            totals.put(product.productId, new long[4]);
        }
        for (Invoice invoice : invoices) {
            long[] sum = totals.get(invoice.productId);
            if (sum == null) continue;
            sum[0] += invoice.rest;
            sum[1] += invoice.paid;
            sum[2] += invoice.canceled;
            sum[3] += invoice.refunded;
        }

        List<Result> answer = new ArrayList<>();
        for (Product product : products) {
            answer.add(new Result(product.name, totals.get(product.productId)));
        }
        answer.sort(Comparator.comparing(result -> result.name));
        return answer;
    }
}

function analyzeProducts(products, invoices) {
  const totals = new Map();

  for (const product of products) {
    totals.set(product.product_id, {
      name: product.name,
      rest: 0,
      paid: 0,
      canceled: 0,
      refunded: 0,
    });
  }

  for (const invoice of invoices) {
    const total = totals.get(invoice.product_id);
    if (!total) continue;
    total.rest += invoice.rest;
    total.paid += invoice.paid;
    total.canceled += invoice.canceled;
    total.refunded += invoice.refunded;
  }

  return [...totals.values()].sort((a, b) =>
    a.name.localeCompare(b.name)
  );
}

from typing import Any


def analyze_products(
    products: list[dict[str, Any]],
    invoices: list[dict[str, int]],
) -> list[dict[str, Any]]:
    totals = {
        product["product_id"]: {
            "name": product["name"],
            "rest": 0,
            "paid": 0,
            "canceled": 0,
            "refunded": 0,
        }
        for product in products
    }

    for invoice in invoices:
        total = totals.get(invoice["product_id"])
        if total is None:
            continue
        total["rest"] += invoice["rest"]
        total["paid"] += invoice["paid"]
        total["canceled"] += invoice["canceled"]
        total["refunded"] += invoice["refunded"]

    return sorted(totals.values(), key=lambda row: row["name"])
本地语义参考：结构体向量输入，返回排序后的结果向量。
#include <algorithm>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Product {
    int productId;
    string name;
};

struct Invoice {
    int invoiceId;
    int productId;
    long long rest;
    long long paid;
    long long canceled;
    long long refunded;
};

struct Result {
    string name;
    long long rest;
    long long paid;
    long long canceled;
    long long refunded;
};

vector<Result> analyzeProducts(
    const vector<Product>& products,
    const vector<Invoice>& invoices
) {
    unordered_map<int, vector<long long>> totals;
    for (const Product& product : products) {
        totals[product.productId] = vector<long long>(4, 0);
    }

    for (const Invoice& invoice : invoices) {
        auto it = totals.find(invoice.productId);
        if (it == totals.end()) continue;
        it->second[0] += invoice.rest;
        it->second[1] += invoice.paid;
        it->second[2] += invoice.canceled;
        it->second[3] += invoice.refunded;
    }

    vector<Result> answer;
    answer.reserve(products.size());
    for (const Product& product : products) {
        const vector<long long>& sum = totals[product.productId];
        answer.push_back({
            product.name, sum[0], sum[1], sum[2], sum[3]
        });
    }
    sort(answer.begin(), answer.end(),
         [](const Result& a, const Result& b) {
             return a.name < b.name;
         });
    return answer;
}
