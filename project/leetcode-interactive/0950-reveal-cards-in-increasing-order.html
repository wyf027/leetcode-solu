让一副牌
按递增顺序亮相

你可以先任意排列牌组。之后不断“翻开顶部，再把新的顶部移到底部”。如何安排初始顺序，才能让翻出的数字严格递增？

唯一整数1 ≤ n ≤ 10001 ≤ deck[i] ≤ 10⁶

Problem

题意

给定整数数组 deck，每张牌上的整数互不相同。你可以重新排列所有牌；返回一种初始牌序，使下面的操作最终按递增顺序显示所有牌。返回数组的第一项表示牌组顶部。

  1. 翻开并移除顶部牌。
  2. 若仍有牌，把此时的顶部牌移到牌组底部。
  3. 仍有未翻开的牌则重复。
输入 / 输出
deckRevealedIncreasing(deck: integer[]) → integer[]

官方示例 1

输入：deck = [17,13,11,2,3,5,7]
输出：[2,13,3,11,5,17,7]
解释：依次翻出 2、3、5、7、11、13、17。

官方示例 2

输入：deck = [1,1000]
输出：[1,1000]

Solution

准备好看逆向思路了吗？

Walkthrough

题解：让下标先走一遍流程

核心洞察：数字应递增出现已经确定；真正未知的是每个数字应该放在哪个初始位置。用一个下标队列模拟“翻开、移动”，依次把排序后的数字填到被翻开的下标即可。

完整过程

  1. 将 deck 升序排序。
  2. 队列初始化为所有位置 0..n-1。
  3. 取出队首下标，把当前最小数字放到答案的该位置。
  4. 若队列非空，再把队首下标移到队尾，模拟“下一张牌放到底部”。
  5. 数字用完后，答案就是所求初始牌序。
示例中的位置轨迹

填 2→位置 0，移动位置 1；填 3→位置 2，移动位置 3；继续得到位置顺序 0, 2, 4, 6, 3, 1, 5，最终答案为 [2,13,3,11,5,17,7]。

正确性证明

下标队列执行的操作与真实牌组完全相同：每轮取出的队首下标正是下一张会被翻开的牌的位置，随后移动的新队首也正是会被放到底部的位置。因此第 k 次翻开的位置被填入排序后第 k 小的数字。对每一轮成立，最终实际翻牌序列必为严格递增序列。

边界与复杂度

单张牌直接放入唯一位置；两张牌也由同一流程自然处理。排序耗时 O(n log n)，队列模拟 O(n)；答案和队列共占 O(n) 空间。

替代方案

也可从最大值向最小值反向构造双端队列：若非空，先把队尾移到队首，再把当前数字放到队首。它更贴近操作的逆过程，但某些语言需要双端队列支持；下标法通常更容易解释与实现。

常见错误

  • 把牌值本身拿去模拟，而不是先确定每个值的初始位置。
  • 队列只剩零个元素时仍取队首并移动。
  • 用数组频繁 shift() 导致 JavaScript 退化为 O(n²)；应使用头指针。
  • 误以为输入已经排序，或忘记所有牌值唯一。

面试追问

若规则变为“每次把接下来的 k 张依次移到底部”，只需在每次填值后对下标队列执行至多 k 次轮转；若 k 很大，可先取模当前队列长度。

Java

import java.util.*;

class Solution {
    public int[] deckRevealedIncreasing(int[] deck) {
        Arrays.sort(deck);
        int n = deck.length;
        int[] answer = new int[n];
        Deque<Integer> indexes = new ArrayDeque<>();
        for (int i = 0; i < n; i++) indexes.offerLast(i);

        for (int card : deck) {
            answer[indexes.pollFirst()] = card;
            if (!indexes.isEmpty())
                indexes.offerLast(indexes.pollFirst());
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number[]} deck
 * @return {number[]}
 */
var deckRevealedIncreasing = function(deck) {
    deck.sort((a, b) => a - b);
    const n = deck.length;
    const answer = Array(n);
    const queue = Array.from({ length: n }, (_, i) => i);
    let head = 0;

    for (const card of deck) {
        answer[queue[head++]] = card;
        if (head < queue.length) queue.push(queue[head++]);
    }
    return answer;
};

Python

from collections import deque
from typing import List

class Solution:
    def deckRevealedIncreasing(self, deck: List[int]) -> List[int]:
        deck.sort()
        indexes = deque(range(len(deck)))
        answer = [0] * len(deck)

        for card in deck:
            answer[indexes.popleft()] = card
            if indexes:
                indexes.append(indexes.popleft())
        return answer

C++

#include <algorithm>
#include <numeric>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> deckRevealedIncreasing(vector<int>& deck) {
        sort(deck.begin(), deck.end());
        int n = deck.size();
        vector<int> answer(n);
        queue<int> indexes;
        for (int i = 0; i < n; ++i) indexes.push(i);

        for (int card : deck) {
            answer[indexes.front()] = card;
            indexes.pop();
            if (!indexes.empty()) {
                indexes.push(indexes.front());
                indexes.pop();
            }
        }
        return answer;
    }
};
