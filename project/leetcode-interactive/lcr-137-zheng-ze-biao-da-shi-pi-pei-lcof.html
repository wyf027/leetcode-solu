LCR 137 · HARD

模糊搜索验证

实现只包含 . 与 * 的正则表达式完整匹配：. 匹配任意单字符，* 匹配其前一个元素零次或多次。

题意

给定字符串 s 与模式 p，判断 p 是否能完整匹配 s。模式不会出现连续的 *，且 * 总有一个前导元素。

示例

s = "aa", p = "a" → false

s = "aa", p = "a*" → true

s = "aab", p = "c*a*b" → true

约束

0 ≤ s.length, p.length ≤ 20；s 由小写字母组成；p 由小写字母、.、* 组成。

分步交互：DP 状态观察器

输入只使用小写字母、. 和 *；矩阵展示 dp[i][j]。

准备就绪。

核心洞察

令 dp[i][j] 表示 s 的前 i 个字符与 p 的前 j 个字符能否完整匹配。普通字符或 . 消耗两个末尾字符；遇到 x*，它要么匹配零次，要么在当前字符匹配时再消耗一个文本字符。

完整过程

  1. 初始化 dp[0][0] = true；空文本只可被形如 a*b*c* 的模式匹配。
  2. 若 p[j-1] 不是 *，且它等于 s[i-1] 或为 .，转移 dp[i][j] = dp[i-1][j-1]。
  3. 若是 *，先尝试零次：dp[i][j-2]；若前导字符能匹配当前文本，再尝试多次：dp[i-1][j]。

边界

  • 空字符串与空模式匹配。
  • * 的零次分支必须保留。
  • 完整匹配不是子串匹配，答案只能取 dp[m][n]。

复杂度

时间 O(mn)，空间 O(mn)。可将空间压缩为 O(n)，但二维表更直观且不易写错。

替代方案与追问

记忆化 DFS 可直接表达“匹配/跳过星号”，但递归状态仍是 O(mn)。追问：若加入 +、?、分组或或运算，需要先定义语法与优先级，再构造 NFA/DFA 或解析树；不能继续把规则硬塞进本题 DP。

常见错误

  • 把 * 当成独立字符，而非前一个元素的量词。
  • 多次匹配时错误地写成 dp[i-1][j-2]，会丢失连续重复。
  • 遗漏空文本的星号链初始化。
