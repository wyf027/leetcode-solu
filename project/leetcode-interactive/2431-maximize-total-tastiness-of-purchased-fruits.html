01 / 问题

给购物篮分配预算

题意转述

有 n 个水果，数组 price 和 tastiness 分别给出每个水果的价格与口味分值。你可以选择其中任意一些水果，每个最多购买一次。

总花费不能超过 maxAmount。最多使用 maxCoupons 张优惠券，每张券把一个水果的价格变为 ⌊price[i] / 2⌋；同一个水果最多用一张券。口味分值不受打折影响。

返回能买到的最大口味分值之和。不要求花光预算或用完优惠券，也可以一个都不买。

参数与约束

  • n == price.length == tastiness.length
  • 1 ≤ n ≤ 100
  • 0 ≤ price[i], tastiness[i], maxAmount ≤ 1000
  • 0 ≤ maxCoupons ≤ 5

返回值为整数。水果价格、口味以及预算都可以为 0。

maxTastiness(
  price: integer[],
  tastiness: integer[],
  maxAmount: integer,
  maxCoupons: integer
) → integer

04 / 独立题解

同时记录钱和券的 0/1 背包

核心洞察

钱和优惠券是两种有限资源。只记录剩余钱会丢掉可用优惠券的信息；按价格或性价比贪心也不能覆盖组合选择。每个水果只有三种互斥决策：跳过、原价购买、用券购买。

令 Dᵢ[b][c] 表示只考虑前 i 个水果，在预算至多 b、优惠券至多 c时的最大口味。所有容量在空前缀时都为 0，因为空购物篮总是可行。每一层只读上一层，因此零价格水果也不会被反复选取。

交互实验 · 预算货架

按水果逐层推进

每格是指定预算与券上限下的最佳口味。点选格子，比较三条候选来源。棕色水果是本层刚处理的水果，绿色为已处理。演示值由页面运行时计算，尚未验证。

当前前缀的全预算最优口味

切换券上限只切换表格切片；这里始终使用清单的全部预算和券上限。

完整过程与转移

  1. 初始化上一层 prev[b][c] = 0。
  2. 读取当前水果价格 p、口味 t，并计算 h = floor(p / 2)。
  3. 为当前水果分配新层。每个 (b,c) 从跳过开始，再比较可行的两种购买方式。
  4. 整层结束后，以新层替换旧层。最终返回 prev[maxAmount][maxCoupons]。
跳过：  prev[b][c]
原价：  prev[b-p][c] + t      （b ≥ p）
用券：  prev[b-h][c-1] + t    （c ≥ 1 且 b ≥ h）
next[b][c] = 上述可行候选的最大值

示例 2 在 (b=10,c=2) 的层值依次为 0 → 5 → 8 → 28。最后一层用券买价格 7 的水果，需要 3 元；上一层在 (7,1) 可取得口味 8，所以候选为 8 + 20 = 28。

正确性

对处理的水果数 i 归纳。i=0 时无水果，最大口味确实为 0。

假定上一层每个状态都最优。任意合法购物篮对当前水果必属于三种决策之一；购买时扣除对应的钱与券，余下购物篮只含前 i−1 个水果，口味不超过对应上一层值。转移取最大值，因此不会漏掉更优方案。

反之，每个候选都是合法上一层方案加上一个可行决策，既不超资源，也不重复水果。因此候选都可实现，新层值等于最优解。归纳至 n 后结论成立。

边界与复杂度

  • 预算为 0：仍应遍历，免费水果或价格 1 的打折水果可以买。
  • 券为 0：用券分支关闭，退化为普通 0/1 背包。
  • 口味为 0：正常参与最大值比较，不影响正确性。
  • 不可购买：跳过分支保证状态有效。
  • 总口味上界 100 × 1000 = 100000，四种语言的整数表示都足够。

令 A=maxAmount，C=maxCoupons。时间 O(n(A+1)(C+1))，额外空间 O((A+1)(C+1))，两层轮换。保留 +1 可以准确覆盖预算或券为 0 的情形。

Java

class Solution {
    public int maxTastiness(int[] price, int[] tastiness,
                           int maxAmount, int maxCoupons) {
        int[][] prev = new int[maxAmount + 1][maxCoupons + 1];
        for (int i = 0; i < price.length; i++) {
            int p = price[i], t = tastiness[i], h = p / 2;
            int[][] next = new int[maxAmount + 1][maxCoupons + 1];
            for (int b = 0; b <= maxAmount; b++) {
                for (int c = 0; c <= maxCoupons; c++) {
                    int best = prev[b][c];
                    if (b >= p)
                        best = Math.max(best, prev[b - p][c] + t);
                    if (c > 0 && b >= h)
                        best = Math.max(best, prev[b - h][c - 1] + t);
                    next[b][c] = best;
                }
            }
            prev = next;
        }
        return prev[maxAmount][maxCoupons];
    }
}

from typing import List

class Solution:
    def maxTastiness(self, price: List[int], tastiness: List[int],
                     maxAmount: int, maxCoupons: int) -> int:
        prev = [[0] * (maxCoupons + 1) for _ in range(maxAmount + 1)]
        for p, t in zip(price, tastiness):
            h = p // 2
            nxt = [[0] * (maxCoupons + 1) for _ in range(maxAmount + 1)]
            for b in range(maxAmount + 1):
                for c in range(maxCoupons + 1):
                    best = prev[b][c]
                    if b >= p:
                        best = max(best, prev[b - p][c] + t)
                    if c > 0 and b >= h:
                        best = max(best, prev[b - h][c - 1] + t)
                    nxt[b][c] = best
            prev = nxt
        return prev[maxAmount][maxCoupons]

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maxTastiness(vector<int>& price, vector<int>& tastiness,
                     int maxAmount, int maxCoupons) {
        vector<vector<int>> prev(maxAmount + 1,
                                 vector<int>(maxCoupons + 1));
        for (int i = 0; i < static_cast<int>(price.size()); ++i) {
            int p = price[i], t = tastiness[i], h = p / 2;
            vector<vector<int>> next(maxAmount + 1,
                                     vector<int>(maxCoupons + 1));
            for (int b = 0; b <= maxAmount; ++b) {
                for (int c = 0; c <= maxCoupons; ++c) {
                    int best = prev[b][c];
                    if (b >= p) best = max(best, prev[b - p][c] + t);
                    if (c > 0 && b >= h)
                        best = max(best, prev[b - h][c - 1] + t);
                    next[b][c] = best;
                }
            }
            prev.swap(next);
        }
        return prev[maxAmount][maxCoupons];
    }

替代方案

  • 记忆化搜索：状态为 (水果下标, 剩余钱, 剩余券)，同样三分支。时间阶相同，缓存空间 O(n(A+1)(C+1))，并有 O(n) 递归栈。
  • 完整三维表：保留全部层，更直观，也方便回溯购买方案；空间增加到 O(n(A+1)(C+1))。
  • 原地压缩：预算与券数都逆序，防止读取本轮更新。零价时尤其要注意券维方向。双层写法免去这些遍历顺序风险。
  • 穷举：每个水果三种选择，共 O(3ⁿ) 个分支，只适合极小输入的独立参考。

面试追问

  • 如何输出购买方案？保存每层各状态所选分支，从 (n,A,C) 逆向回溯；遇到并列可以固定优先级。
  • 为什么不能先给最贵水果用券？省钱最多并不保证口味组合最优。示例 2 若强行购买价格 15 的水果并用券，在券数改为 1 时只能得 8；直接花 7 元买口味 20 的水果更好。
  • 预算变得很大怎么办？若总口味较小，可改为记录达到某口味所需的最小花费，并保留券维；否则考虑稀疏状态及支配剪枝。
  • 能否提前结束零预算状态？不能，后面可能仍有免费或用券后免费的水果。

常见错误

  • 把半价四舍五入；本题要求向下取整。
  • 把券作用于总订单，或允许一个水果叠加多张券。
  • 把“至多”当“恰好”，要求必须花光钱或用完券。
  • 预算从 1 开始，漏掉免费水果的转移。
  • 把新旧层指向同一个数组，引入重复购买。
  • JavaScript 用 fill(同一个数组) 建表，或 Python 用列表乘法复用行，导致不同预算互相污染。
