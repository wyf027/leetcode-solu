别在每次插入时重走整棵树。初始化时把仍有空位的节点排成队列，之后队首就是唯一正确的父节点。

DEFERRED QUEUE

    只把还有位置的节点放进队列；新节点也先入队，因为它未来仍可接收孩子。

    洞察 / 初始化

    层序扫描一次

    BFS 遍历已有树；每遇到孩子不满两个的节点，放入队列。

    过程 / 边界

    队首决定父亲

    先补左，再补右。队首节点在右孩子补齐前延迟出队（deferred dequeue），补到右侧后才完成并出队。

    把成本前置

    替代 / 追问 / 错误

    为什么队列顺序不会错？

    完全二叉树按层从左到右填充。BFS 恰好产生这个顺序：更早出现的空位一定优先填补；当一个父节点补满右孩子才离开队首，因此永远不会跳过左侧空位。若每次插入都重新 BFS，虽然可行但会退化到 O(n)；不要在补完左孩子时提前出队。
