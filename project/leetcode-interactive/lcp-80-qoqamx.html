生物进化录

记录 0 表示新建子节点并下潜，记录 1 表示回退父节点。对子树编码排序后拼接，才能拿到字典序最小的复刻字符串。

树形 DFS贪心排序官方 slug：qoqamx

ENCODING RULE

  1. 0：创建一个孩子，指针移动到该孩子。
  2. 1：回到当前节点的父节点。
  3. 结束：指针可以停在任意节点，因此末尾连续的 1 不必保留。

贪心原因

每个孩子的完整往返片段均以 0 开头、以 1 结尾；排序这些独立片段后拼接，最早出现差异的位置最小，因此整体字典序最小。

收尾：根外没有父节点需要回退，末尾连续 1 可删去。

建树

parents[i] 指出父节点。先建立 children 邻接表，才能在每个节点聚合孩子编码。

后序 DFS

先得到所有 child 的记录，再为每个孩子包上 0 + child + 1。

复杂度

DFS 访问每个节点；排序成本来自同一父节点的子树片段比较。

class Solution {
  List<Integer>[] g;
  String dfs(int u) {
    List<String> a = new ArrayList<>();
    for (int v : g[u]) a.add("0" + dfs(v) + "1");
    Collections.sort(a);
    return String.join("", a);
  }
  public String evolutionaryRecord(int[] parents) {
    g = new List[parents.length];
    for (int i = 0; i < g.length; i++) g[i] = new ArrayList<>();
    for (int i = 1; i < parents.length; i++) g[parents[i]].add(i);
    return dfs(0).replaceFirst("1+$", "");
  }
}

class Solution:
    def evolutionaryRecord(self, parents: List[int]) -> str:
        g = [[] for _ in parents]
        for i in range(1, len(parents)): g[parents[i]].append(i)
        def dfs(u):
            return ''.join(sorted('0' + dfs(v) + '1' for v in g[u]))

class Solution {
  vector<vector<int>> g;
  string dfs(int u) {
    vector<string> a;
    for (int v : g[u]) a.push_back("0" + dfs(v) + "1");
    sort(a.begin(), a.end()); string ans;
    for (auto& s : a) ans += s;
    return ans;
  }
