Max Difference You Can Get From Changing an Integer

改变一个整数能得到的最大差值

同一个数字，两次独立换位：一次尽量变大，一次尽量变小。真正的难点，是找准每次最值得替换的那一位。

Problem

题意

给定整数 num。对原始 num 独立执行两次操作，每次任选数字 x 与 y（都在 0 到 9 之间，且可以相等），把十进制表示中所有的 x 同时替换为 y。两次所得整数记为 a、b，求可能的最大差值 a - b。

合法性：两个结果都不能有前导零，也不能等于 0。两次操作都从原始 num 出发，不是在第一次结果上继续修改。

Solution

贪心：最大化与最小化分别做最优选择

核心洞察

高位对数值的影响永远压过所有低位之和。因此，每条轨道都应从左到右寻找第一个“仍可改善”的数字，并把该数字的所有出现位置一起替换。

最大值

找到第一个不是 9 的数字 d，将所有 d 替换成 9。若全是 9，则不变。

最小值

若首位不是 1，把所有首位数字替换成 1；否则从第二位起找第一个既非 0 又非 1 的数字，把它全部替换成 0。

完整过程

  1. 把 num 转为字符串，分别复制为最大化串和最小化串。
  2. 最大化：定位首个非 9 字符；若存在，将它在整个字符串中的所有出现位置改为 9。
  3. 最小化：首位不是 1 时，将所有等于首位的字符改为 1；首位已经是 1 时，从下标 1 开始定位首个不是 0/1 的字符，将它的所有出现位置改为 0。
  4. 把两个字符串转回整数，返回最大值减最小值。

正确性证明

  1. 最大化策略最优。设从左起第一个非 9 数字是 d。更早的位置已经是 9，无法增加。在该位置把 d 改成 9，会获得此位置可实现的最大增量；任何只从更低位开始的方案都无法抵消这里少增加 1 所造成的位权差。操作要求替换所有 d，因此同步替换其余 d 也只会增加或保持数值。所得值最大。
  2. 首位非 1 时的最小化策略最优。首位不能变成 0。把首位数字改成最小合法首位 1，得到首位上的最大降幅；任何不降低首位而只修改低位的方案都不会更小。同步把相同数字改成 1 也不会破坏合法性。
  3. 首位为 1 时的最小化策略最优。首位已是最小合法值，不能再降低。从第二位开始，0 和 1 都无法通过一次合法的全量替换获得更优下降：替换 1 会同时影响首位并可能产生前导零；替换 0 不会下降。故应选首个既非 0 又非 1 的数字并替换为 0。按最高可改善位优先的位权性质，结果最小。
  4. 两次操作彼此独立，前述策略分别得到全局最大值与全局最小值，所以二者之差就是所求最大差值。

边界情况

  • 只有一位：如 9，最大化可保持 9，最小化得到 1。
  • 全部为 9：最大值不变；最小值把 9 全部改成 1。
  • 以 1 开头且其余只有 0/1：最小值不变，例如 10000。
  • 候选数字重复出现：必须一次改完全部出现位置，如 9288 中两个 8 同时变化。

复杂度

设十进制位数为 n。扫描和替换均为 O(n)；构造结果字符串需要 O(n) 额外空间。题目中 n ≤ 9。

替代方案

可枚举每个 x, y ∈ [0,9] 的 100 种替换，过滤前导零和零值，分别维护最大与最小结果。它更直接，也容易作为对照实现，但时间为 O(100n)，没有揭示最高有效位决定最优选择的贪心结构。

面试追问

  • 如果允许只替换某一次出现，而不是所有出现，策略会如何改变？
  • 如果结果允许前导零，最小化首位时的选择会变成什么？
  • 如何在不转字符串的情况下，使用数学拆位完成相同逻辑？
  • 如果操作可执行 k 次，怎样描述状态或证明贪心是否仍成立？

常见错误

  • 把两次操作串联，错误地在最大化结果上继续做最小化。
  • 最小化时一律把首位改成 0，产生非法前导零。
  • 首位是 1 时把后面的 1 改成 0；由于是全量替换，这会同时把首位改成 0。
  • 只替换选中数字的一次出现，而不是全部出现。
  • 寻找最大化目标时错误地选择“最小数字”，而没有优先考虑最左侧可改善位置。

class Solution {
    public int maxDiff(int num) {
        char[] maxDigits = String.valueOf(num).toCharArray();
        char maxTarget = 0;
        for (char digit : maxDigits) {
            if (digit != '9') {
                maxTarget = digit;
                break;
            }
        }
        if (maxTarget != 0) {
            for (int i = 0; i < maxDigits.length; i++) {
                if (maxDigits[i] == maxTarget) maxDigits[i] = '9';
            }
        }

        char[] minDigits = String.valueOf(num).toCharArray();
        char minTarget = 0;
        char replacement = 0;
        if (minDigits[0] != '1') {
            minTarget = minDigits[0];
            replacement = '1';
        } else {
            for (int i = 1; i < minDigits.length; i++) {
                if (minDigits[i] != '0' && minDigits[i] != '1') {
                    minTarget = minDigits[i];
                    replacement = '0';
                    break;
                }
            }
        }
        if (minTarget != 0) {
            for (int i = 0; i < minDigits.length; i++) {
                if (minDigits[i] == minTarget) minDigits[i] = replacement;
            }
        }
        return Integer.parseInt(new String(maxDigits))
             - Integer.parseInt(new String(minDigits));
    }
}

var maxDiff = function(num) {
    const source = String(num);

    const maxTarget = [...source].find((digit) => digit !== '9');
    const maxValue = maxTarget === undefined
        ? num
        : Number([...source]
            .map((digit) => digit === maxTarget ? '9' : digit)
            .join(''));

    let minTarget;
    let replacement;
    if (source[0] !== '1') {
        minTarget = source[0];
        replacement = '1';
    } else {
        minTarget = [...source.slice(1)]
            .find((digit) => digit !== '0' && digit !== '1');
        replacement = '0';
    }

    const minValue = minTarget === undefined
        ? num
        : Number([...source]
            .map((digit) => digit === minTarget ? replacement : digit)
            .join(''));

    return maxValue - minValue;
};
class Solution:
    def maxDiff(self, num: int) -> int:
        source = str(num)

        max_target = next(
            (digit for digit in source if digit != "9"),
            None,
        )
        max_value = (
            num if max_target is None
            else int(source.replace(max_target, "9"))
        )

        if source[0] != "1":
            min_target = source[0]
            replacement = "1"
        else:
            min_target = next(
                (digit for digit in source[1:]
                 if digit not in ("0", "1")),
                None,
            )
            replacement = "0"

        min_value = (
            num if min_target is None
            else int(source.replace(min_target, replacement))
        )
        return max_value - min_value
class Solution {
public:
    int maxDiff(int num) {
        string source = to_string(num);
        string maximum = source;
        string minimum = source;

        char maxTarget = '\0';
        for (char digit : source) {
            if (digit != '9') {
                maxTarget = digit;
                break;
            }
        }
        if (maxTarget != '\0') {
            for (char& digit : maximum) {
                if (digit == maxTarget) digit = '9';
            }
        }

        char minTarget = '\0';
        char replacement = '\0';
        if (source[0] != '1') {
            minTarget = source[0];
            replacement = '1';
        } else {
            for (int i = 1; i < static_cast<int>(source.size()); i++) {
                if (source[i] != '0' && source[i] != '1') {
                    minTarget = source[i];
                    replacement = '0';
                    break;
                }
            }
        }
        if (minTarget != '\0') {
            for (char& digit : minimum) {
                if (digit == minTarget) digit = replacement;
            }
        }
        return stoi(maximum) - stoi(minimum);
    }
};
