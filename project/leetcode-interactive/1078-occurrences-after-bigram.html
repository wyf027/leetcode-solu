Occurrences After Bigram

Bigram
分词

在一段由单词组成的文本里，找到每个连续出现的 first → second，收集紧随其后的第三个单词。

先自己想一想如果把文本拆成单词数组，需要观察多宽的“窗口”，才能同时确认前两个词并取出答案？
SLIDING TRIPLE
firsta
secondgood
thirdgirl

前两格匹配时，第三格就是一次命中的答案。

题目

函数签名：findOcurrences(text, first, second) → string[]

准确转述

给定文本 text 与两个词 first、second。每当文本中出现连续的三个词 first second third，且顺序与相邻关系完全一致，就把该处的 third 加入结果。按它们在文本中出现的顺序返回全部结果；重复结果也要保留。

约束

  • 1 ≤ text.length ≤ 1000
  • 1 ≤ first.length, second.length ≤ 10
  • 字符串只含小写英文字母与空格。
  • 文本单词间恰有一个空格，无首尾空格。

官方示例 1

输入
text = "alice is a good girl she is a good student" first = "a" second = "good"
输出
["girl","student"]

官方示例 2

输入
text = "we will we will rock you" first = "we" second = "will"
输出
["we","rock"]

完整题解

先完成你的推导，再展开核对。

核心洞察

条件描述的不是任意距离的两个词，而是连续的三词片段。因此拆词后，只需从左到右查看每个长度为 3 的窗口：若前两项分别等于 first、second，就记录第三项。

边界

  • 少于 3 个词时结果必为空。
  • 窗口允许重叠，例如 we will we will。
  • 相同第三词出现多次，需要保留多次。
  • 最后两个词无法构成完整三词窗口。

完整过程

按单个空格拆分 text，得到单词数组 words。
令下标 i 从 0 遍历到 words.length - 3。
检查 words[i] == first 且 words[i + 1] == second。
匹配时追加 words[i + 2]；遍历结束后返回结果。

正确性证明

完备性：任意合法的 first second third 都以某个下标 i 开始。遍历会访问该 i，前两词匹配，于是其第三词被加入。

可靠性：算法仅在连续位置 i 与 i+1 分别匹配时加入 i+2，故每个加入项都确实来自一个合法三词片段。

两者合起来，结果恰好包含所有应返回的第三词，并保持原顺序。

复杂度

设文本长度为 n，单词数为 m。拆分与扫描总时间为 O(n)；单词数组及输出占 O(n) 空间（不计输出时，辅助空间仍取决于语言的拆分实现）。

替代方案

可用正则表达式寻找模式，但处理重叠匹配更容易出错，且可读性不如单次窗口扫描。流式分词可把额外工作空间降到最近两个词，但在本题约束下收益有限。

面试追问

  • 若允许多个空格或标点，怎样定义“单词”与分隔？
  • 若文本巨大、只能流式读取，如何只保留最近两个词？
  • 若要同时查询很多组 bigram，如何建立索引减少重复扫描？

常见错误

  • 循环到数组末尾，访问越界的 i+2。
  • 只返回唯一单词，错误地去重。
  • 匹配子串而不是完整单词。
  • 匹配后跳过三格，漏掉重叠窗口。

四语言完整代码

import java.util.ArrayList;
import java.util.List;

class Solution {
    public String[] findOcurrences(String text, String first, String second) {
        String[] words = text.split(" ");
        List<String> answer = new ArrayList<>();
        for (int i = 0; i + 2 < words.length; i++) {
            if (words[i].equals(first) && words[i + 1].equals(second)) {
                answer.add(words[i + 2]);
            }
        }
        return answer.toArray(new String[0]);
    }
}

#include <string>

using namespace std;

class Solution {
public:
    vector<string> findOcurrences(
        string text, string first, string second
    ) {
        istringstream input(text);
        vector<string> words;
        vector<string> answer;
        string word;
        while (input >> word) words.push_back(word);
        for (int i = 0; i + 2 < (int)words.size(); ++i) {
            if (words[i] == first && words[i + 1] == second) {
                answer.push_back(words[i + 2]);
            }
        }
        return answer;
    }
