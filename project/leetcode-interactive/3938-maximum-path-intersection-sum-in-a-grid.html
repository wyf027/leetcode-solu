矩阵中最大共享路径和

把两位玩家的相交部分，压缩成一段横向或纵向的连续子数组。

题意

玩家 1 从左上到右下，只能向右或向下；玩家 2 从左下到右上，只能向右或向上。两条路径共同经过的单元格称为共享单元格。请选择两条合法路径，使共享单元格值之和最大。

grid = [[1,2,0,-3],[1,-2,1,0],[-4,2,-1,3],[3,-3,3,-2],[-1,-5,0,1]]，期望输出 4。约束：2 ≤ m,n ≤ 1000，m × n ≤ 5×10⁵。

交互：一条共享水平段

紫色单元格是示例中的公共段 (2,1) → (2,3)；点击“下一步”观察一维扫描的状态。

第 1 步：共享格必须在同一行或同一列，并且连续。

测试与验证

用例 1：输入 grid = [[1,2,0,-3],[1,-2,1,0],[-4,2,-1,3],[3,-3,3,-2],[-1,-5,0,1]]；期望输出 4；实际输出 —；状态：待补。

用例 2：输入 grid = [[4,-2,-3],[-1,-3,-1],[-4,2,-1]]；期望输出 3；实际输出 —；状态：待补。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补

题解：按行、按列做“长度至少 2”的 Kadane

公共格若超过一个，必然是一条同一行或同一列的连续段；对每行、每列求长度至少为 2 的最大子数组和。公共格只有一个时，格子不能在四条边界上，单独枚举内部单元格即可。

  1. 扫描每一行、每一列，维护“以当前位置结尾且长度至少为 2”的最大和。
  2. 枚举内部格，补上长度为 1 的共享情况。
  3. 取所有候选最大值。

复杂度：O(mn) 时间，O(1) 额外空间。替代方案是前缀和枚举端点，但会退化为平方复杂度。常见错误：遗漏单格公共路径，或让 Kadane 允许长度为 1 的边界段。
