328. Odd Even Linked List

按节点在链表中的位置奇偶性重新分组，同时保留每组原有的相对次序。注意：判断的是位置，不是节点值。

MEDIUM单链表原地重排非付费题
官方函数oddEvenList(head) 参数

head：单链表头节点，可为空

返回

重排后的同一条链表的头节点

目标

O(n) 时间 · O(1) 额外空间

Problem

题目要求

给定单链表的头节点 head，把处在奇数位置的所有节点排在前面，再接上处在偶数位置的所有节点，返回重排后的链表。

第 1 个节点属于奇数组，第 2 个节点属于偶数组，以此类推。两个分组内部的节点相对顺序必须与输入时一致。

位置从 1 开始计数。节点值为偶数，不代表它属于偶数组；节点值为奇数，也不代表它属于奇数组。

参数形式

输入：head: ListNode | null
输出：ListNode | null

官方示例

示例 1

输入：head = [1,2,3,4,5]
输出：[1,3,5,2,4]

示例 2

输入：head = [2,1,3,5,6,4,7]
输出：[2,3,6,7,1,5,4]

约束

  • n 为链表中的节点数。
  • 0 <= n <= 104
  • -106 <= Node.val <= 106
  • 要求时间复杂度为 O(n)，额外空间复杂度为 O(1)。

双链原地穿针：完整题解

维护奇链与偶链的尾指针，扫描结束后把两段接回。

核心洞察

原链表中相邻的奇、偶位置节点天然交替出现。令 odd 和 even 分别指向当前奇链、偶链的尾节点，再保存偶链头 evenHead。每轮把两根尾指针各自跨过一个节点，就能在原节点上稳定地拆出两条链，最后只需 odd.next = evenHead。

完整过程

  1. 若链表为空或只有一个节点，直接返回 head。
  2. 初始化 odd = head、even = head.next，并用 evenHead 永久记住偶链的第一个节点。
  3. 当 even != null && even.next != null 时，令 odd.next = even.next 并前移 odd；再令 even.next = odd.next 并前移 even。
  4. 循环结束后，奇链已经完整；把它的尾节点指向 evenHead，返回原头节点。

正确性证明

循环不变式：每轮开始时，odd 是已处理奇数位置节点构成链的尾节点，even 是已处理偶数位置节点构成链的尾节点；两条链中的相对顺序均与原链一致。

保持：even.next 是下一个尚未接入奇链的奇数位置节点，将其接到 odd 后不改变奇组顺序；更新后的 odd.next 是下一个偶数位置节点，将其接到 even 后也不改变偶组顺序，因此不变式继续成立。

终止：当偶指针为空或没有后继时，所有节点均已归入对应分组。把奇链尾接到保存的偶链头，所得链表恰好是全部奇数位置节点后接全部偶数位置节点。

边界处理

空链表：head == null，直接返回。

1 个节点：没有偶链，保持不变。

2 个节点：循环条件不成立，最终连接不改变原顺序。

奇数长度：最后一个节点进入奇链。

偶数长度：最后一个节点留在偶链；循环退出时其后继为 null。

复杂度

时间复杂度O(n)每个节点只被常数次访问
额外空间O(1)只维护三个节点引用

Java · LeetCode 可提交oddEvenList
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode oddEvenList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }

        ListNode odd = head;
        ListNode even = head.next;
        ListNode evenHead = even;

        while (even != null && even.next != null) {
            odd.next = even.next;
            odd = odd.next;
            even.next = odd.next;
            even = even.next;
        }

        odd.next = evenHead;
        return head;
    }
}

替代方案

可以顺序扫描原链表，把奇数位置值和偶数位置值分别放入数组，再创建新链表；思路直观，但需要 O(n) 额外空间，并且没有复用原节点，不符合题目对常数额外空间的要求。递归拆分同样会引入 O(n) 调用栈。

常见错误

  • 按节点值的奇偶性分组，而不是按一基位置分组。
  • 没有保存 evenHead，循环结束后找不到偶链起点。
  • 循环条件只写 even != null，访问 even.next 时可能越界。
  • 忘记把奇链尾连接到偶链头，导致返回结果丢失一半节点。
  • 为了“方便”新建全部节点，破坏 O(1) 额外空间目标。

面试追问

  • 为什么循环条件依赖 even？ 每一轮要读取 even.next 作为下一个奇节点；只要它不存在，就没有新的奇偶对需要拆分。
  • 算法是否稳定？ 稳定。奇链和偶链均按原链表中的出现次序追加节点。
  • 会不会形成环？ 正确实现不会。每轮都重写偶尾的后继；退出时偶链尾原本就指向 null，最终只从奇尾单向接到偶链头。
  • 能推广到按位置模 k 分组吗？ 可以维护 k 组头尾指针，再按余数归组并依次拼接，但需要 O(k) 引用空间；若 k 视为变量，就不再是严格的 O(1)。
