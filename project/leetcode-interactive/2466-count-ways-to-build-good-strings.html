统计构造好字符串的方案数

Count Ways To Build Good Strings

用固定长度的 0 块与 1 块拼接，数一数落在指定长度区间中的不同字符串。

官方题目 ↗

01 / PROBLEM

题意与规则

给定整数 low, high, zero, one。从空字符串开始，每一步任选一种操作：追加 zero 个字符 '0'，或追加 one 个字符 '1'。可以操作任意次。

最终长度属于闭区间 [low, high] 的字符串是好字符串。返回能够构造的不同好字符串的数量，结果对 1,000,000,007 取余。

0 块

每次追加 zero 个 0

1 块

每次追加 one 个 1

约束

  • 1 ≤ low ≤ high ≤ 10⁵
  • 1 ≤ zero, one ≤ low

提交函数：countGoodStrings(low, high, zero, one) → integer

02 / EXAMPLES

low = 3, high = 3, zero = 1, one = 1
输出：8

长度为 3 的所有二进制字符串均可构造，从 000 到 111 共 8 个。例如：空串 → 0 → 01 → 011。

输出：5

好字符串为 00、11、000、110、011，共 5 个。

03 / SOLUTION

按长度计数，两条支流汇入一个状态

核心洞察

定义 dp[i] 为长度恰好为 i 的可构造字符串数。追加什么只取决于长度是否允许，无须保存已经构造的内容。

dp[0] = 1
当 i ≥ zero：dp[i] += dp[i - zero]
当 i ≥ one ：dp[i] += dp[i - one]
每一步对 MOD = 1_000_000_007 取余
答案 = Σ dp[i]，low ≤ i ≤ high

空串是唯一的起点，所以 dp[0] = 1。它只负责发起构造；由于 low ≥ 1，不会计入答案。即使 zero = one，两条转移仍需分别计数，因为追加的字符不同。

长度汇流台

每次推进一个长度，看末尾为 0 的支流与末尾为 1 的支流如何合并。浅绿色卡片属于目标区间；虚线表示当前前驱；粗绿框表示当前长度。

可视化限制 high ≤ 24；提交代码支持官方上限 10⁵。修改参数后点击应用。

所有按钮支持 Tab 聚焦、Enter / 空格操作。演示是学习工具，运行结果不代表验证记录。

完整过程与正确性

  1. 创建长度为 high + 1 的数组，初值为 0，令 dp[0] = 1。
  2. 从长度 1 到 high 递增计算。若前驱下标非负，分别累加追加 0 块与 1 块的方案数。
  3. 每次加法取模；当前长度达到 low 时，将 dp[i] 累加到答案中。
  4. 返回累加值，不需要枚举具体字符串。

为什么不重不漏？

对长度作归纳。基础情况空串只有 1 个。对任意可构造的非空字符串，最后一个字符确定最后追加的是哪一类块；删除固定长度的末块，就得到唯一前驱字符串。因此两类末块产生的集合互不相交，每一类与其前驱集合一一对应。所有前驱长度更小，归纳假设保证它们计数正确，故相加即为 dp[i]。

同一字符连续出现时，块长固定，块边界也可从末尾逐块唯一还原。不同长度的字符串互不相同，所以把区间内各 dp[i] 相加就是答案。模加法保留最终余数。

用示例 2 走一遍

  • dp[0] = 1。
  • dp[1] = dp[0] = 1，对应 0；长度未达到 low，不纳入答案。
  • dp[2] = dp[1] + dp[0] = 2，对应 00、11；累计 2。
  • dp[3] = dp[2] + dp[1] = 3，对应 000、110、011；累计 5。

边界与复杂度

  • 无法到达的长度保持 0，无须特殊处理。
  • low = high 时只统计该长度。
  • zero = one 时两条支流来自同一位置，但贡献都保留。
  • 若 gcd(zero, one) 不整除 i，长度 i 不可达；整除只是必要条件，并不保证小长度可达。
  • 时间 O(high)，额外空间 O(high)。每次更新只有常数次加法。
  • Java/C++ 使用宽整数累加；JavaScript 每次模加只涉及约 2 × 10⁹ 的数，低于安全整数上限。

替代方案

  • 记忆化搜索：相同递推，时间和空间仍为 O(high)，但递归深度可能达到 10⁵，有栈溢出风险。
  • 向前推送：从 i 向 i + zero 和 i + one 分发 dp[i]，也能在线性时间完成。
  • 环形数组：只保留最近 max(zero, one) + 1 个状态，空间 O(max(zero, one))；需要谨慎覆盖，当前约束下完整数组更直观。
  • 暴力生成：字符串数呈指数增长，只适合手工理解极小样例。

Java

class Solution {
    public int countGoodStrings(int low, int high, int zero, int one) {
        final long MOD = 1_000_000_007L;
        long[] dp = new long[high + 1];
        dp[0] = 1;
        long answer = 0;
        for (int i = 1; i <= high; i++) {
            if (i >= zero) dp[i] = (dp[i] + dp[i - zero]) % MOD;
            if (i >= one) dp[i] = (dp[i] + dp[i - one]) % MOD;
            if (i >= low) answer = (answer + dp[i]) % MOD;
        }
        return (int) answer;
    }
}

C++

#include <vector>
using namespace std;

class Solution {
public:
    int countGoodStrings(int low, int high, int zero, int one) {
        const long long MOD = 1'000'000'007;
        vector<long long> dp(high + 1, 0);
        dp[0] = 1;
        long long answer = 0;
        for (int i = 1; i <= high; ++i) {
            if (i >= zero) dp[i] = (dp[i] + dp[i - zero]) % MOD;
            if (i >= one) dp[i] = (dp[i] + dp[i - one]) % MOD;
            if (i >= low) answer = (answer + dp[i]) % MOD;
        }
        return static_cast<int>(answer);
    }
};

常见错误

  • 把 dp[0] 设为 0，导致所有状态都是 0。
  • 使用 else if，漏掉同时满足的另一种末块。
  • 只返回 dp[high]，忽略 low 到 high − 1。
  • zero = one 时把两个操作去重，漏算不同字符。
  • 访问负下标，或最后才取模导致溢出。
  • 把题目误解为无序选块：01 与 10 是不同字符串。

面试追问

  • 为何只需长度？ 所有内容不同但等长的前缀拥有相同追加选择。
  • 有多种块呢？ 可以按末块求和，但若块集合能以不同分块方式形成相同字符串，必须先解决重复计数；本题由末字符和固定块长确保唯一性。
  • 多次查询区间怎么办？ 预处理到最大 high，再建立 dp 的模前缀和，每次查询 O(1)。
  • 长度极大怎么办？ 步长较小时可考虑线性递推加速或矩阵快速幂，需同时维护前缀和；本题无需引入这些成本。
