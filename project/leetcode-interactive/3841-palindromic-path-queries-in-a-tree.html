查询树上回文路径

路径字符能重排成回文，当且仅当奇数次数的字母不超过一个。把 26 个计数的奇偶性压进一个异或掩码，路径问题便变成可维护的区间异或。

树链剖分把一条树路径切成 O(log n) 段；线段树支持节点字符的单点更新。

主线：HLD + XOR 线段树

节点 c 的值是 1 << (c-'a')。路径 XOR 的 1 位正是出现奇数次的字符。

更新
O(log n)
查询
O(log² n)

题意与示例

给定一棵 n 个节点的无向树、每个节点的小写字母和两类操作：update u c 改写节点字符；query u v 判断 u 到 v 的唯一简单路径字符能否重排为回文。

示例 1：n = 3, edges = [[0,1],[1,2]], s = "aac"，依次执行 queries = ["query 0 2", "update 1 b", "query 0 2"]，结果为 [true, false]。

  • n 与操作数均至多 5 × 10⁴。
  • 字符串保留成对直引号；若输入含空格，本文以 ␠ 可视化表示。

交互：掩码怎样判回文？

题解：把频次变成 26 位奇偶向量

  1. 字符 x 映射到位掩码 1 << (x - 'a')。相同位 XOR 两次会抵消。
  2. 一段路径的 XOR 因而记录每种字母的奇偶次数；mask == 0 || (mask & (mask - 1)) == 0 等价于最多一个奇数频次。
  3. 任选根，预处理 parent、depth、subtree size、heavy child，再建立 head 与 dfn。
  4. 路径两端所在重链不同就取较深链顶到端点的线段树 XOR，并向父亲跳；最后取同链区间。

边界

单节点路径永远可行；更新成相同字符也可安全重置；树退化为链时 HLD 仍保证链段数对数级。

替代方案

若没有更新，可用根到点的前缀 XOR 和 LCA 在 O(log n) 查询。存在更新时前缀不可直接维护，HLD 更稳健。

面试追问与常见错误

  • 字母表改为 52 个字符时，使用 64 位整数或位集合。
  • 不要保存真实计数再逐字扫描路径，最坏会退化为 O(n)。
  • HLD 里区间端点必须是 dfn；不要误把节点编号当作线段树位置。
