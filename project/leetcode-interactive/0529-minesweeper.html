扫雷游戏 / Minesweeper

一次点击，可能只揭开一个数字，也可能沿着整片安全区域扩散。先理解规则，再亲手观察队列怎样推动“波纹”展开。

广度优先搜索深度优先搜索数组矩阵非付费题

题目

给定 m × n 字符矩阵 board 与点击坐标 click = [clickr, clickc]。盘面中，M 是未揭露地雷，E 是未揭露空格，B 是已揭露且周围八格没有地雷的空白；1 到 8 表示相邻地雷数，X 是已揭露地雷。返回本次点击完成后的盘面。

  1. 点到 M：将其改为 X，立即结束。
  2. 点到周围没有地雷的 E：改为 B，并递归揭露它周围仍为 E 的格子。
  3. 点到周围至少有一颗雷的 E：改为对应数字，只揭露这一格。
  4. 没有更多格子可揭露时返回盘面。

函数形式： updateBoard(board: character[][], click: integer[]): character[][]

示例 1 · 安全区域扩散
输入：board = [["E","E","E","E","E"],
["E","E","M","E","E"],
["E","E","E","E","E"],
["E","E","E","E","E"]], click = [3,0]

输出：[["B","1","E","1","B"],
["B","1","M","1","B"],
["B","1","1","1","B"],
["B","B","B","B","B"]]
示例 2 · 点击地雷
输入：board = [["B","1","E","1","B"],
["B","1","M","1","B"],
["B","1","1","1","B"],
["B","B","B","B","B"]], click = [1,2]

输出：[["B","1","E","1","B"],
["B","1","X","1","B"],
["B","1","1","1","B"],
["B","B","B","B","B"]]

约束

  • m == board.length，n == board[i].length
  • 1 <= m, n <= 50
  • 每格是 M、E、B 或 1 到 8
  • click.length == 2，且坐标在盘面范围内
  • 被点击格一定是 M 或 E

每一步处理队首格：数字会阻断扩散，空白才把相邻未揭露空格加入队列。

题解

核心洞察

揭露过程就是从点击格出发的图搜索：每个格子是节点，八方向相邻关系是边。唯一关键是只有相邻雷数为 0 的格子才继续扩展；相邻雷数大于 0 的格子写成数字后成为搜索边界。下面采用 BFS，入队时立刻标记为 B，避免同一格被重复入队。

完整过程

  1. 若点击的是 M，改为 X 并返回。
  2. 否则将点击格改为 B 后入队。
  3. 取出队首，遍历八方向，统计原盘面中的 M 数量。
  4. 若数量大于 0，把当前格改为对应数字，不扩展。
  5. 若数量为 0，保持 B，将八邻域中仍为 E 的格子标成 B 并入队。
  6. 队列为空后返回原地修改的盘面。

正确性证明

引理 1：每个入队格都可由点击格经过若干个相邻雷数为 0 的已揭露格到达，因此规则要求它被揭露。

引理 2：所有规则要求揭露的格最终都会入队。点击格首先入队；若某格应通过空白格扩散揭露，则其前驱空白格出队时会遍历到它并入队。

引理 3：每格最多入队一次，因为入队时立即从 E 改为 B。

结论：算法恰好揭露规则要求的所有格，并按相邻雷数写入数字或 B；点击地雷分支也直接符合规则，因此返回盘面正确。

边界情况

  • 点击地雷：只改一个字符并结束。
  • 点击格靠边或在角落：方向遍历必须检查边界。
  • 单行、单列和 1 × 1 盘面。
  • 点击格紧邻地雷：写数字后不能继续扩展。
  • 大片无雷区域：必须用访问标记避免重复入队；这里复用盘面字符。

复杂度

设盘面共有 m × n 格。每格最多入队一次，每次检查固定 8 个方向，时间复杂度 O(mn)；最坏队列容纳 O(mn) 个格，额外空间 O(mn)。

替代方案

DFS 的逻辑完全相同，代码更短，但最坏递归深度可达 mn，在大连通区域可能触发调用栈限制。BFS 使用显式队列，空间上界相同，执行过程也更便于观察。也可以不在入队时标记、另设 visited，但会多用一份矩阵。

面试追问

  • 为什么数字格不能继续扩散？——它是安全区域与未知区域的边界。
  • 为什么统计时只数 M 而不是 X？——本次算法只会在点击地雷时直接结束；正常扩散过程中不会产生 X。
  • 如何支持连续点击？——每次对当前盘面调用同一过程，已揭露字符不会被加入队列。
  • 如何避免修改输入？——先深拷贝盘面，复杂度仍为 O(mn)。

常见错误

  • 只遍历上下左右，漏掉四个对角线。
  • 数字格仍将邻居加入队列，导致揭露过多。
  • 出队时才标记访问，使同一格被多次入队。
  • 统计地雷与扩展邻居混在一起，尚未知道雷数就扩散。
  • 使用字符加法时忘记从 '0' 转换。

import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    private static final int[] D = {-1, 0, 1};

    public char[][] updateBoard(char[][] board, int[] click) {
        int r = click[0], c = click[1];
        if (board[r][c] == 'M') {
            board[r][c] = 'X';
            return board;
        }

        Queue<int[]> queue = new ArrayDeque<>();
        board[r][c] = 'B';
        queue.offer(new int[]{r, c});

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int mines = countMines(board, cur[0], cur[1]);
            if (mines > 0) {
                board[cur[0]][cur[1]] = (char) ('0' + mines);
                continue;
            }
            for (int dr : D) for (int dc : D) {
                int nr = cur[0] + dr, nc = cur[1] + dc;
                if ((dr != 0 || dc != 0) && inside(board, nr, nc)
                        && board[nr][nc] == 'E') {
                    board[nr][nc] = 'B';
                    queue.offer(new int[]{nr, nc});
                }
            }
        }
        return board;
    }

    private int countMines(char[][] b, int r, int c) {
        int count = 0;
        for (int dr : D) for (int dc : D) {
            int nr = r + dr, nc = c + dc;
            if ((dr != 0 || dc != 0) && inside(b, nr, nc) && b[nr][nc] == 'M') count++;
        }
        return count;
    }

    private boolean inside(char[][] b, int r, int c) {
        return r >= 0 && r < b.length && c >= 0 && c < b[0].length;
    }
}

var updateBoard = function(board, click) {
    const [sr, sc] = click;
    if (board[sr][sc] === 'M') {
        board[sr][sc] = 'X';
        return board;
    }

    const rows = board.length, cols = board[0].length;
    const queue = [[sr, sc]];
    let head = 0;
    board[sr][sc] = 'B';

    while (head < queue.length) {
        const [r, c] = queue[head++];
        let mines = 0;
        for (let dr = -1; dr <= 1; dr++) {
            for (let dc = -1; dc <= 1; dc++) {
                const nr = r + dr, nc = c + dc;
                if ((dr !== 0 || dc !== 0) && nr >= 0 && nr < rows &&
                    nc >= 0 && nc < cols && board[nr][nc] === 'M') mines++;
            }
        }
        if (mines > 0) {
            board[r][c] = String(mines);
            continue;
        }
        for (let dr = -1; dr <= 1; dr++) {
            for (let dc = -1; dc <= 1; dc++) {
                const nr = r + dr, nc = c + dc;
                if ((dr !== 0 || dc !== 0) && nr >= 0 && nr < rows &&
                    nc >= 0 && nc < cols && board[nr][nc] === 'E') {
                    board[nr][nc] = 'B';
                    queue.push([nr, nc]);
                }
            }
        }
    }
    return board;
};
from collections import deque
from typing import List

class Solution:
    def updateBoard(self, board: List[List[str]], click: List[int]) -> List[List[str]]:
        sr, sc = click
        if board[sr][sc] == "M":
            board[sr][sc] = "X"
            return board

        rows, cols = len(board), len(board[0])
        queue = deque([(sr, sc)])
        board[sr][sc] = "B"

        while queue:
            r, c = queue.popleft()
            mines = 0
            for dr in (-1, 0, 1):
                for dc in (-1, 0, 1):
                    nr, nc = r + dr, c + dc
                    if ((dr or dc) and 0 <= nr < rows and 0 <= nc < cols
                            and board[nr][nc] == "M"):
                        mines += 1

            if mines:
                board[r][c] = str(mines)
                continue

            for dr in (-1, 0, 1):
                for dc in (-1, 0, 1):
                    nr, nc = r + dr, c + dc
                    if ((dr or dc) and 0 <= nr < rows and 0 <= nc < cols
                            and board[nr][nc] == "E"):
                        board[nr][nc] = "B"
                        queue.append((nr, nc))
        return board
