将字符串拆分为
递减的连续值

Splitting a String Into Descending Consecutive Values

寻找数字间的切口，拼出每次下降 1 的阶梯。

题目

给定只含数字的字符串 s，能否将整个字符串切成至少两个非空连续片段，使各片段的数值按原顺序每次恰好减少 1？允许前导零，不能跳过或重排字符。有合法拆分返回 true，否则返回 false。

例如 "0090" | "089" 表示 90 → 89，合法；"001" 无论切成 "0" | "01"、"00" | "1" 或 "0" | "0" | "1" 都不合法。

约束：1 ≤ s.length ≤ 20，s 仅含数字字符 0–9。

题解 · 枚举首段，逐段匹配

核心洞察

首段数值一旦确定，后面的数值就必须每次减 1。对正目标值，逐位累积数值：小于目标继续，大于目标失败，等于目标立即切开。命中正目标后继续追加任意数字都会增大数值，因此切口唯一。

完整过程

  1. 枚举首段长度 1 到 n−1，确保至少留一个字符。
  2. 若上一段值为 0 且仍有字符，失败，因为下一个目标为负数。
  3. 若目标为 0，检查整个剩余后缀是否全为零；若是，把后缀合成最后一段，否则失败。
  4. 正目标逐字符累积，命中就提交切口并继续。
  5. 恰好用完全部字符即成功，否则尝试下一个首段。

以 "050043" 的首段 "05" 为例：目标 4，依次读到 "0"、"00"、"004"，值为 0、0、4；切下 "004"，再匹配目标 3，用尽字符串。

正确性

任何合法拆分的首段必被枚举覆盖。固定首段后，正目标的匹配位置唯一：前导零不改变值，但命中正数后追加数字严格增大，无法在更远处再次命中同值。目标零只能是最后一段，且剩余字符必须全零。因此各步不会遗漏该首段对应的合法解。反过来，算法成功时每段非空、相邻值差 1、全部字符已使用，且首段未占满字符串，故至少两段，必为合法拆分。

边界与精度

长度 1 返回 false；"00" 不能递减；"10"、"1000" 合法，后者把 "000" 整体作为 0。不要禁止前导零。20 位数超出普通 64 位有符号整数与 JavaScript Number 的安全范围：使用 BigInteger、BigInt、Python int 或 GNU __int128。

复杂度

共 O(n) 个首段，每个分支顺序扫描 O(n) 字符。把整数运算视作常数时为 O(n²) 时间；考虑最多 n 位的大整数运算，保守上界 O(n³) 时间。辅助空间 O(n)，用于大整数及切片，没有递归栈。

替代方案

可以回溯所有切口，只沿满足差值的片段递归；朴素分割共有 2^(n−1) 种，剪枝可减少探索。这里利用目标唯一性省掉回溯。若不使用大整数，也可实现十进制字符串减一与去前导零后的比较。

常见错误

  • 允许整串独占一段，忽略至少两个片段。
  • 目标零时只吃一个零，漏掉合法全零后缀。
  • 一个首段失败就返回 false，没有枚举其他首段。
  • 使用 Number 或 long 直接解析长数字，造成精度或溢出问题。

面试追问

差值改为固定正整数 d？目标改为 prev−d，负数失败，零目标仍检查全零后缀。需要返回切分？记录每段起止位置。为什么不需要记忆化？固定首段后正目标没有多个切口分支。

Java

import java.math.BigInteger;
class Solution {
    public boolean splitString(String s) {
        for (int k = 1; k < s.length(); k++)
            if (match(s, k, new BigInteger(s.substring(0, k)))) return true;
        return false;
    }
    private boolean match(String s, int i, BigInteger prev) {
        while (i < s.length()) {
            if (prev.signum() == 0) return false;
            BigInteger target = prev.subtract(BigInteger.ONE);
            if (target.signum() == 0) {
                for (int j = i; j < s.length(); j++)
                    if (s.charAt(j) != '0') return false;
                return true;
            }
            BigInteger value = BigInteger.ZERO;
            boolean found = false;
            while (i < s.length()) {
                value = value.multiply(BigInteger.TEN)
                    .add(BigInteger.valueOf(s.charAt(i++) - '0'));
                int cmp = value.compareTo(target);
                if (cmp > 0) return false;
                if (cmp == 0) { found = true; break; }
            }
            if (!found) return false;
            prev = target;
        }
        return true;
    }
}

/** @param {string} s @return {boolean} */
var splitString = function(s) {
    function match(i, prev) {
        while (i < s.length) {
            if (prev === 0n) return false;
            const target = prev - 1n;
            if (target === 0n) {
                for (let j = i; j < s.length; j++)
                    if (s[j] !== '0') return false;
                return true;
            }
            let value = 0n, found = false;
            while (i < s.length) {
                value = value * 10n + BigInt(s[i++]);
                if (value > target) return false;
                if (value === target) { found = true; break; }
            }
            if (!found) return false;
            prev = target;
        }
        return true;
    }
    for (let k = 1; k < s.length; k++)
        if (match(k, BigInt(s.slice(0, k)))) return true;
    return false;
};

Python 3

class Solution:
    def splitString(self, s: str) -> bool:
        def match(i, prev):
            while i < len(s):
                if prev == 0:
                    return False
                target = prev - 1
                if target == 0:
                    return all(s[j] == '0' for j in range(i, len(s)))
                value, found = 0, False
                while i < len(s):
                    value = value * 10 + int(s[i])
                    i += 1
                    if value > target:
                        return False
                    if value == target:
                        found = True
                        break
                if not found:
                    return False
                prev = target
            return True
        for k in range(1, len(s)):
            if match(k, int(s[:k])):
                return True
        return False

C++

#include <string>
using namespace std;
class Solution {
    bool match(const string& s, int i, __int128 prev) {
        int n = (int)s.size();
        while (i < n) {
            if (prev == 0) return false;
            __int128 target = prev - 1;
            if (target == 0) {
                for (int j = i; j < n; ++j)
                    if (s[j] != '0') return false;
                return true;
            }
            __int128 value = 0;
            bool found = false;
            while (i < n) {
                value = value * 10 + (s[i++] - '0');
                if (value > target) return false;
                if (value == target) { found = true; break; }
            }
            if (!found) return false;
            prev = target;
        }
        return true;
    }
public:
    bool splitString(string s) {
        __int128 first = 0;
        for (int k = 1; k < (int)s.size(); ++k) {
            first = first * 10 + (s[k - 1] - '0');
            if (match(s, k, first)) return true;
        }
        return false;
    }
};
