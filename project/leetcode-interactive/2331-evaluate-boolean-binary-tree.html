计算布尔二叉树的值

Evaluate Boolean Binary Tree

每片叶子是一个真假值，每个分叉是一个逻辑运算。根节点最终会得到什么？

前往官方题目 ↗
01 / PROBLEM

题意与输入约定

给定二叉树根节点 root，返回它所表示的布尔表达式的值，返回类型是 boolean。每个节点要么没有孩子，要么恰好有两个孩子。

叶子节点

0 表示 false；1 表示 true。

非叶子节点

2 表示 OR（或）；3 表示 AND（与）。把两个孩子的结果按该运算组合。

这里的 full binary tree 指“每个节点有 0 或 2 个孩子”，并不要求层层填满，也不等同于 complete binary tree（完全二叉树）。示例数组是层序序列化，null 表示缺失节点；提交函数接收的是 TreeNode。

官方约束

  • 节点总数在 [1, 1000] 之间，根节点不为空。
  • 0 ≤ Node.val ≤ 3。
  • 每个节点的孩子数为 0 或 2。
  • 叶子节点的值只能是 0 或 1。
  • 非叶子节点的值只能是 2 或 3。
02 / EXAMPLES

官方示例

示例 1 · 两种运算

输入：root = [2,1,3,null,null,0,1]
输出：true

右子树表示 false AND true，得到 false；根节点表示 true OR false，得到 true。

示例 2 · 单节点

输入：root = [0]
输出：false

根节点本身就是叶子，对应 false。

05 / SOLUTION

先想一想，再看题解

完整推导、四语言代码和面试延伸均在下方折叠区域。

题解 · 后序遍历

核心洞察

一个节点只需要两个孩子的布尔结果，不需要知道子树内部的结构。让函数 evaluateTree(node) 始终返回“这棵子树的值”，就能把问题缩小为同一种子问题。

完整过程

  1. 如果当前节点是叶子，返回 node.val == 1。
  2. 递归计算左子树，记为 left。
  3. 递归计算右子树，记为 right。
  4. 值为 2 时返回 left OR right；值为 3 时返回 left AND right。

示例 1 的求值完成顺序为：左叶子 1 → 右子树的叶子 0 → 叶子 1 → AND 节点得到 false → OR 根节点得到 true。访问节点时先进入父节点，但完成计算时先孩子、后父亲，这就是后序。

四份代码都先保存左右子树的结果，再做逻辑运算，因此所有节点都会被访问，与上方演示一致。

正确性证明

对树的结构归纳。基础情形：叶子值只有 0 或 1，判断是否为 1 恰好返回题目规定的真值。归纳情形：假设左右子树的递归结果均正确；非叶子必有两个孩子，按节点值选择 OR 或 AND，对这两个正确的结果进行运算，便得到当前子树的正确值。因此根节点返回值正确。每次递归都进入更小的子树，最终到达叶子，算法必然终止。

复杂度

时间 O(n)：每个节点访问一次。额外空间 O(h)：递归栈长度为树高。平衡树为 O(log n)，高度偏斜时为 O(n)；full 并不保证平衡。

边界

单节点直接返回；false 是有效结果，不能当作“尚未计算”。题目保证 root 非空且不存在单孩子节点，所以使用 left 为空识别叶子是充分的。通用树输入则需要另外校验结构。

四语言可提交代码

TreeNode 由 LeetCode 环境提供；以下均使用官方 evaluateTree 签名，不包含输入解析和 main。

Java

/** TreeNode 由平台提供。 */
class Solution {
    public boolean evaluateTree(TreeNode root) {
        if (root.left == null) {
            return root.val == 1;
        }
        boolean left = evaluateTree(root.left);
        boolean right = evaluateTree(root.right);
        return root.val == 2 ? left || right : left && right;
    }
}

替代方案

  • 迭代后序：用栈存储“节点 + 是否已展开”。首次取出时依次压回父节点、右孩子、左孩子；再次取出时合并孩子结果。若用映射保存全部结果，额外空间为 O(n)。适合树更深、需要避免递归调用栈限制的情形。
  • 短路递归：OR 左边为 true 时可不访问右子树；AND 左边为 false 时也可跳过右子树。最坏时间仍为 O(n)，但某些输入访问更少。只有纯求值场景适合跳过；若需要记录每个节点的结果，使用本文的完整遍历。

常见错误

  • 把 2、3 直接转换为布尔值：它们代表运算符，不代表 true。
  • 把 OR 与 AND 编码记反：2 是 OR，3 是 AND。
  • 先计算父节点却没有孩子结果：父节点依赖两个子树的返回值。
  • 在 JavaScript 中使用位运算 |、& 返回数字，遗漏题目要求的 boolean 类型。
  • 认为 full binary tree 高度必为 log n，低估递归空间。

面试追问

如何支持 NOT？扩展节点运算符及孩子数量约定，NOT 只对子节点的值取反；不能继续无条件假设每个非叶子都有两个孩子。

如果树变成共享子表达式的有向无环图？可以按节点身份缓存计算结果，避免重复求值；若允许环，还需要检测环并定义相应语义。

叶子值频繁变化怎么办？维护父指针与每个节点的缓存结果，叶子修改后沿祖先链更新，单次更新 O(h)。
