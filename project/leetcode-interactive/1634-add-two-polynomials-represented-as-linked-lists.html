求两个多项式链表的和

Add Two Polynomials Represented as Linked Lists

先把每个节点看成一个“系数 + 次幂”的项。你的任务不是计算某个 x 的数值，而是返回仍处于标准形式的多项式链表。

Problem

题意

给定两个单变量多项式的头节点 poly1 与 poly2。每个多项式都用单链表表示，链表中的每个节点对应一项。请将两个多项式相加，返回和的链表头节点。结果也必须是标准形式：按次幂严格递减排列，并省略系数为 0 的项。

coefficient该项的整数系数，例如 9x⁴ 的系数为 9。
power该项的非负整数次幂，例如 9x⁴ 的次幂为 4。
next指向下一项；最后一个节点的 next 为 null。
addPoly(poly1: PolyNode, poly2: PolyNode) → PolyNode 节点序列格式：[coefficient, power] 示例：[[5,3],[4,1],[-7,0]] 代表 5x³ + 4x − 7

官方示例

EX. 01

输入：poly1 = [[1,1]], poly2 = [[1,0]]

输出：[[1,1],[1,0]]

x 与 1 相加，结果为 x + 1。

EX. 02

输入：poly1 = [[2,2],[4,1],[3,0]], poly2 = [[3,2],[-4,1],[-1,0]]

输出：[[5,2],[2,0]]

2x² + 4x + 3 与 3x² − 4x − 1 相加得到 5x² + 2；相消后的 0x 项不进入结果。

EX. 03

输入：poly1 = [[1,2]], poly2 = [[-1,2]]

输出：[]

唯一的两项完全抵消，零多项式用空链表表示。

约束

  • 0 ≤ n ≤ 10⁴，其中 n 表示每条多项式链表中的节点数。
  • −10⁹ ≤ PolyNode.coefficient ≤ 10⁹，且输入节点的系数不为 0。
  • 0 ≤ PolyNode.power ≤ 10⁹。
  • 每条输入链表均满足 PolyNode.power > PolyNode.next.power。

Solution

题解：像归并排序一样合并

核心洞察

输入链表已经按次幂严格递减，所以结果的下一项只可能来自两个当前节点中次幂较大的那个，或者来自两个同次幂节点的系数之和。用两个指针同步向后扫描，就能自然保持结果有序。

完整过程

  1. 建立哑节点 dummy 与结果尾指针 tail。
  2. 两个指针都非空时比较次幂。
  3. 次幂较大的一项直接复制到结果，并只移动对应指针。
  4. 次幂相同则相加系数；和非 0 才创建节点，然后同时移动两个指针。
  5. 主循环结束后，逐项复制仍未处理的链表。
  6. 返回 dummy.next。

为什么不用排序

两个输入本身已经有序。每一步选出的都是尚未处理项中次幂最大的合法下一项，因此追加顺序天然严格递减。使用哈希表虽然也能汇总同次幂系数，但还要额外排序所有次幂。

边界情况

  • 一条或两条链表为空。
  • 同次幂系数相加为 0，必须跳过。
  • 所有项都抵消，返回空链表。
  • 两条链表的次幂完全不重合。
  • 常数项的次幂为 0。
  • 本页实现复制节点，不修改输入链表。

复杂度

设两条链表长度分别为 m、n。每个节点只访问一次，时间复杂度为 O(m + n)。除返回结果所需节点外，只使用固定数量指针，额外空间复杂度为 O(1)。

正确性证明

  1. 循环不变量：每轮开始时，结果链表恰好包含两个指针之前所有已处理项的多项式和，且按次幂严格递减，没有零系数项。
  2. 保持：若次幂不同，较大次幂不可能在另一链表后续再次出现，因此可安全追加；若次幂相同，把系数和追加或在和为 0 时跳过，恰好处理该次幂。两种情况都维持标准形式。
  3. 终止：每轮至少移动一个指针，循环必然结束。剩余链表的所有次幂都小于结果最后一项，且自身已是标准形式，依次复制后仍有序。
  4. 结论：返回链表包含且仅包含两个输入多项式相加后的所有非零项，因此算法正确。

替代方案

可以用哈希表按次幂累加系数，再筛掉 0 并按次幂降序建链表。实现直观，但需要保存至多 m+n 个键，并产生 O(k log k) 的排序成本；没有利用输入已排序这一关键信息。

常见错误

  • 同次幂相加后仍把 0 系数节点放入结果。
  • 只移动一个同次幂指针，导致重复处理。
  • 误按系数而不是次幂比较节点。
  • 拼接原链表时意外修改输入结构。
  • 返回 dummy 而不是 dummy.next。

面试追问

  • 如果输入没有按次幂排序，怎样处理？

表达要点

先说明“有序链表归并”模型，再讲清同次幂的三件事：系数相加、零和跳过、双指针同时移动。最后用循环不变量解释为什么追加顺序不会破坏标准形式。

四语言完整代码

/*
 * Definition for polynomial singly-linked list.
 * class PolyNode {
 *     int coefficient, power;
 *     PolyNode next;
 *     PolyNode() {}
 *     PolyNode(int x, int y) { coefficient = x; power = y; }
 *     PolyNode(int x, int y, PolyNode next) {
 *         coefficient = x; power = y; this.next = next;
 *     }
 * }
 */
class Solution {
    public PolyNode addPoly(PolyNode poly1, PolyNode poly2) {
        PolyNode dummy = new PolyNode();
        PolyNode tail = dummy;
        PolyNode p1 = poly1, p2 = poly2;

        while (p1 != null && p2 != null) {
            if (p1.power > p2.power) {
                tail.next = new PolyNode(p1.coefficient, p1.power);
                p1 = p1.next;
            } else if (p1.power < p2.power) {
                tail.next = new PolyNode(p2.coefficient, p2.power);
                p2 = p2.next;
            } else {
                int sum = p1.coefficient + p2.coefficient;
                if (sum != 0) {
                    tail.next = new PolyNode(sum, p1.power);
                }
                p1 = p1.next;
                p2 = p2.next;
                if (sum == 0) continue;
            }
            tail = tail.next;
        }

        while (p1 != null) {
            tail.next = new PolyNode(p1.coefficient, p1.power);
            tail = tail.next;
            p1 = p1.next;
        }
        while (p2 != null) {
            tail.next = new PolyNode(p2.coefficient, p2.power);
            tail = tail.next;
            p2 = p2.next;
        }
        return dummy.next;
    }
}

 * Definition for polynomial singly-linked list.
 * function PolyNode(x = 0, y = 0, next = null) {
 *     this.coefficient = x;
 *     this.power = y;
 *     this.next = next;
 * }
 */
var addPoly = function(poly1, poly2) {
    const dummy = new PolyNode(0, 0);
    let tail = dummy;
    let p1 = poly1;
    let p2 = poly2;

    while (p1 !== null && p2 !== null) {
        if (p1.power > p2.power) {
            tail.next = new PolyNode(p1.coefficient, p1.power);
            p1 = p1.next;
        } else if (p1.power < p2.power) {
            tail.next = new PolyNode(p2.coefficient, p2.power);
            p2 = p2.next;
        } else {
            const sum = p1.coefficient + p2.coefficient;
            const power = p1.power;
            p1 = p1.next;
            p2 = p2.next;
            if (sum === 0) continue;
            tail.next = new PolyNode(sum, power);
        }
        tail = tail.next;
    }

    while (p1 !== null) {
        tail.next = new PolyNode(p1.coefficient, p1.power);
        tail = tail.next;
        p1 = p1.next;
    }
    while (p2 !== null) {
        tail.next = new PolyNode(p2.coefficient, p2.power);
        tail = tail.next;
        p2 = p2.next;
    }
    return dummy.next;
};

#         self.coefficient = x
#         self.power = y
#         self.next = next

    def addPoly(self, poly1: 'PolyNode',
                poly2: 'PolyNode') -> 'PolyNode':
        dummy = PolyNode()
        tail = dummy
        p1, p2 = poly1, poly2

        while p1 and p2:
            if p1.power > p2.power:
                tail.next = PolyNode(p1.coefficient, p1.power)
                p1 = p1.next
            elif p1.power < p2.power:
                tail.next = PolyNode(p2.coefficient, p2.power)
                p2 = p2.next
            else:
                coefficient = p1.coefficient + p2.coefficient
                power = p1.power
                p1, p2 = p1.next, p2.next
                if coefficient == 0:
                    continue
                tail.next = PolyNode(coefficient, power)
            tail = tail.next

            tail.next = PolyNode(p1.coefficient, p1.power)
            tail, p1 = tail.next, p1.next
        while p2:
            tail.next = PolyNode(p2.coefficient, p2.power)
            tail, p2 = tail.next, p2.next

        return dummy.next

 * Definition for polynomial singly-linked list.
 * struct PolyNode {
 *     int coefficient, power;

 *     PolyNode(int x, int y, PolyNode* next):
 *         coefficient(x), power(y), next(next) {}
 * };
 */
class Solution {
public:
    PolyNode* addPoly(PolyNode* poly1, PolyNode* poly2) {
        PolyNode dummy;

        PolyNode* p1 = poly1;
        PolyNode* p2 = poly2;

            if (p1->power > p2->power) {
                tail->next = new PolyNode(p1->coefficient, p1->power);
                p1 = p1->next;
            } else if (p1->power < p2->power) {
                tail->next = new PolyNode(p2->coefficient, p2->power);
                p2 = p2->next;
            } else {
                int sum = p1->coefficient + p2->coefficient;
                int power = p1->power;
                p1 = p1->next;
                p2 = p2->next;
                if (sum == 0) continue;
                tail->next = new PolyNode(sum, power);
            }
            tail = tail->next;
        }

        while (p1 != nullptr) {
            tail->next = new PolyNode(p1->coefficient, p1->power);
            tail = tail->next;
            p1 = p1->next;
        }

            tail->next = new PolyNode(p2->coefficient, p2->power);
            tail = tail->next;
