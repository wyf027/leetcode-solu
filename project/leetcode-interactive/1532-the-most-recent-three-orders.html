01 · Problem

题目转述

给定客户表与订单表，为每位确实下过单的客户找出日期最新的至多三笔订单。若客户不足三单，则全部返回；没有订单的客户不出现在结果中。

结果列为 customer_name、customer_id、order_id、order_date，先按客户名升序，再按客户编号升序，最后按订单日期降序。

数据库题官方提交语言是 SQL。页面后附的 Java、JavaScript、Python 与 C++ 版本仅用于本地模拟相同数据语义，不能替代 LeetCode 的 SQL 提交。

Customers

customer_id 唯一
列名类型含义
customer_idint客户唯一编号
namevarchar客户姓名

Orders

order_id 唯一
列名类型含义
order_idint订单唯一编号
order_datedate下单日期
customer_idint下单客户
costint订单金额（本题不输出）

数据约束

两表主键列均唯一；每位客户每天至多一笔订单，因此仅按日期降序就能确定其订单先后。

数量规则

每个客户最多返回 3 行；少于 3 行时全部保留，不需要补空记录。

排序规则

customer_name ASC → customer_id ASC → order_date DESC。

05 · Solution

窗口函数取每组 Top 3

用 ROW_NUMBER() 在每位客户自己的订单序列里编号，最新为 1。外层筛选编号不超过 3，最后按题目要求输出。

1

核心洞察

这是典型的 group-wise Top K：不是从整张表取 3 行，而是从每个 customer_id 分区各取 3 行。

2

完整过程

Orders 与 Customers 内连接 → 按客户分区 → 组内按日期降序编号 → 保留 rn ≤ 3 → 按指定三列排序。

MySQL 8+ · 官方可提交语言窗口函数
WITH ranked_orders AS (
    SELECT
        c.name AS customer_name,
        c.customer_id,
        o.order_id,
        o.order_date,
        ROW_NUMBER() OVER (
            PARTITION BY o.customer_id
            ORDER BY o.order_date DESC
        ) AS rn
    FROM Orders AS o
    INNER JOIN Customers AS c
        ON c.customer_id = o.customer_id
)
SELECT
    customer_name,
    customer_id,
    order_id,
    order_date
FROM ranked_orders
WHERE rn <= 3
ORDER BY
    customer_name ASC,
    customer_id ASC,
    order_date DESC;

正确性证明

  1. 分区完整。内连接后，每一笔有效订单都恰好属于其 customer_id 对应的分区；无订单客户自然没有候选行。
  2. 排名正确。同一客户每天至多一单。按 order_date DESC 编号后，第 1、2、3 行恰好是该客户最近的三笔订单。
  3. 筛选正确。rn ≤ 3 保留前三行；若分区不足三行，其中每行编号都不超过 3，故全部保留。
  4. 展示正确。最终 ORDER BY 仅重排已选出的结果，严格满足姓名、编号、日期的优先级，不改变入选集合。

时间复杂度（概念上）

O(M log M)

M 为订单数；主要成本来自各分区排序。数据库优化器可能按索引与执行计划采用不同实现。

额外空间（概念上）

O(M)

窗口排序与中间结果可能需要与订单规模同阶的工作空间；实际内存/磁盘占用由数据库执行器决定。

边界情况

  • 客户没有订单：不返回。
  • 客户只有 1～2 单：全部返回。
  • 客户恰好 3 单：全部返回。
  • 客户超过 3 单：仅保留日期最新的 3 单。
  • 不同客户同名：用 customer_id 保证稳定的客户顺序。

常见错误

  • 全局使用 LIMIT 3，只得到所有客户合计三单。
  • 漏写 PARTITION BY，导致全表统一编号。
  • 窗口中使用日期升序，选成最旧三单。
  • 最终排序只写客户名，漏掉同名客户与日期规则。
  • 用 LEFT JOIN 后未排除空订单，让无订单客户混入结果。

替代方案

相关子查询：统计同一客户中比当前订单更新的订单数，小于 3 即保留。它能兼容不支持窗口函数的老版本，但通常更难读，且可能产生昂贵的重复比较。

DENSE_RANK：若同一天允许多单且业务要求“最近三个日期的全部订单”，可用它；本题保证每位客户每天一单，ROW_NUMBER 最直接。

面试追问

  • 如何把 3 参数化为任意 N？将阈值改为绑定参数，并讨论 N 的边界。
  • 若同一天可有多单，如何定义“最近三笔”？增加 order_id DESC 作为确定性 tie-breaker。
  • 怎样设计索引？可考虑 Orders(customer_id, order_date DESC)，并结合真实执行计划判断。
  • 要保留并列第三名的全部订单怎么办？按日期使用 DENSE_RANK 并明确返回行数可能超过 3。

Java · 本地语义参考不可替代 SQL 提交
import java.time.LocalDate;
import java.util.*;
import java.util.stream.Collectors;

public class RecentThreeOrders {
    record Customer(int customerId, String name) {}
    record Order(int orderId, LocalDate orderDate, int customerId, int cost) {}
    record Result(String customerName, int customerId,
                  int orderId, LocalDate orderDate) {}

    public static List<Result> solve(
            List<Customer> customers, List<Order> orders) {
        Map<Integer, String> names = customers.stream()
            .collect(Collectors.toMap(Customer::customerId, Customer::name));

        Map<Integer, List<Order>> groups = orders.stream()
            .filter(o -> names.containsKey(o.customerId()))
            .collect(Collectors.groupingBy(Order::customerId));

        List<Result> answer = new ArrayList<>();
        for (Map.Entry<Integer, List<Order>> entry : groups.entrySet()) {
            List<Order> sorted = new ArrayList<>(entry.getValue());
            sorted.sort(Comparator.comparing(Order::orderDate).reversed());
            for (int i = 0; i < Math.min(3, sorted.size()); i++) {
                Order o = sorted.get(i);
                answer.add(new Result(names.get(o.customerId()),
                    o.customerId(), o.orderId(), o.orderDate()));
            }
        }

        answer.sort(Comparator.comparing(Result::customerName)
            .thenComparingInt(Result::customerId)
            .thenComparing(Result::orderDate, Comparator.reverseOrder()));
        return answer;
    }
}
JavaScript · 本地语义参考不可替代 SQL 提交
function recentThreeOrders(customers, orders) {
  const names = new Map(
    customers.map(({ customer_id, name }) => [customer_id, name])
  );
  const groups = new Map();

  for (const order of orders) {
    if (!names.has(order.customer_id)) continue;
    if (!groups.has(order.customer_id)) groups.set(order.customer_id, []);
    groups.get(order.customer_id).push(order);
  }

  const answer = [];
  for (const [customerId, group] of groups) {
    group
      .slice()
      .sort((a, b) => b.order_date.localeCompare(a.order_date))
      .slice(0, 3)
      .forEach((order) => answer.push({
        customer_name: names.get(customerId),
        customer_id: customerId,
        order_id: order.order_id,
        order_date: order.order_date,
      }));
  }

  return answer.sort((a, b) =>
    a.customer_name.localeCompare(b.customer_name) ||
    a.customer_id - b.customer_id ||
    b.order_date.localeCompare(a.order_date)
  );
}
Python · 本地语义参考不可替代 SQL 提交
from collections import defaultdict
from dataclasses import dataclass
from datetime import date
from typing import List

@dataclass(frozen=True)
class Customer:
    customer_id: int
    name: str

@dataclass(frozen=True)
class Order:
    order_id: int
    order_date: date
    customer_id: int
    cost: int

def recent_three_orders(
    customers: List[Customer], orders: List[Order]
) -> list[tuple[str, int, int, date]]:
    names = {c.customer_id: c.name for c in customers}
    groups: dict[int, list[Order]] = defaultdict(list)

    for order in orders:
        if order.customer_id in names:
            groups[order.customer_id].append(order)

    answer: list[tuple[str, int, int, date]] = []
    for customer_id, group in groups.items():
        newest = sorted(
            group, key=lambda order: order.order_date, reverse=True
        )[:3]
        answer.extend(
            (names[customer_id], customer_id, order.order_id,
             order.order_date)
            for order in newest
        )

    return sorted(answer, key=lambda row: (row[0], row[1], -row[3].toordinal()))
C++ · 本地语义参考不可替代 SQL 提交
#include <algorithm>
#include <string>
#include <tuple>
#include <unordered_map>
#include <vector>
using namespace std;

struct Customer { int customerId; string name; };
struct Order { int orderId; string orderDate; int customerId; int cost; };
struct Result { string customerName; int customerId; int orderId; string orderDate; };

vector<Result> recentThreeOrders(
    const vector<Customer>& customers,
    const vector<Order>& orders) {
    unordered_map<int, string> names;
    for (const auto& customer : customers)
        names[customer.customerId] = customer.name;

    unordered_map<int, vector<Order>> groups;
    for (const auto& order : orders)
        if (names.count(order.customerId))
            groups[order.customerId].push_back(order);

    vector<Result> answer;
    for (auto& [customerId, group] : groups) {
        sort(group.begin(), group.end(), [](const Order& a, const Order& b) {
            return a.orderDate > b.orderDate;
        });
        for (int i = 0; i < min(3, static_cast<int>(group.size())); ++i)
            answer.push_back({names[customerId], customerId,
                              group[i].orderId, group[i].orderDate});
    }

    sort(answer.begin(), answer.end(), [](const Result& a, const Result& b) {
        if (a.customerName != b.customerName)
            return a.customerName < b.customerName;
        if (a.customerId != b.customerId)
            return a.customerId < b.customerId;
        return a.orderDate > b.orderDate;
    });
    return answer;
}
