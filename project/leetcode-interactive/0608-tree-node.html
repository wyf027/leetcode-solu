LeetCode 608 树节点 Tree Node

一张只有节点与父节点的表，隐藏着一棵完整的树。你的任务是为每一行标记它在结构中的角色。

MEDIUM 数据库 非付费题 结果可任意排序
Input relation
Tree
column type meaning
id int unique
p_id int parent

输出列：id、type

01 / Brief

读懂题目

Tree 的每一行记录一个节点的 id 与它的父节点 p_id。给定结构保证是一棵有效的树。

任务

报告树中每个节点的类型，返回包含 id 和 type 的结果表；行的顺序不限。

Root 根节点。
Inner 既不是根节点，也不是叶子节点的内部节点。
Leaf 叶子节点。

表结构与约束

列名 类型 约束 / 含义
id int 唯一值，节点编号
p_id int 父节点编号；根的该值为空
  • 输入结构始终是一棵有效的树。
  • 结果可以按任意顺序返回。
  • 官方题面未给出额外的数值范围。

04 / Spoiler gate

准备好再看题解

建议先在脑中回答：一行记录中，哪些信息足以区分三种节点？

Solution unlocked

从两次集合判断，到一个 CASE

先认根

根节点没有父节点，所以 p_id IS NULL 必须优先判断。

01

再找“当过父亲”的 id

若当前 id 出现在其他行的 p_id 中，它拥有子节点。

02

剩下就是叶子

非根且从未出现在父节点列中的节点没有孩子，因此标记为 Leaf。

03

完整过程

  1. 扫描每一行的 p_id，得到非空父节点编号集合。
  2. 对每个节点先检查 p_id IS NULL；满足则输出 Root。
  3. 否则检查它的 id 是否属于父节点集合；属于则输出 Inner。
  4. 其余节点输出 Leaf。

官方可提交语言

MySQL / PostgreSQL可提交查询
SELECT
    id,
    CASE
        WHEN p_id IS NULL THEN 'Root'
        WHEN id IN (
            SELECT p_id
            FROM Tree
            WHERE p_id IS NOT NULL
        ) THEN 'Inner'
        ELSE 'Leaf'
    END AS type
FROM Tree;
Pandas官方可提交语言
import pandas as pd

def tree_node(tree: pd.DataFrame) -> pd.DataFrame:
    parent_ids = set(tree["p_id"].dropna())

    def classify(row: pd.Series) -> str:
        if pd.isna(row["p_id"]):
            return "Root"
        if row["id"] in parent_ids:
            return "Inner"
        return "Leaf"

    result = tree[["id"]].copy()
    result["type"] = tree.apply(classify, axis=1)
    return result

正确性说明

对任意节点 v：若它的父节点为空，根据有效树的定义，v 是唯一根节点，查询第一分支输出 Root。否则，若 v.id 出现在某行的 p_id 中，则至少有一个节点以 v 为父节点；它有父也有子，故是 Inner。若不出现， v 没有任何子节点，故是 Leaf。三种情况互斥且覆盖全部节点，因此分类正确。

复杂度

SQL：由执行计划决定 概念上扫描输入并构造父节点集合；实际时间与索引、优化器及数据库实现有关。
语义参考：O(n) 使用哈希集合时，时间 O(n)，额外空间 O(n)。

Java本地语义参考
import java.util.*;

public class TreeNodeClassifier {
    static class Row {
        final int id;
        final Integer parentId;

        Row(int id, Integer parentId) {
            this.id = id;
            this.parentId = parentId;
        }
    }

    static class Result {
        final int id;
        final String type;

        Result(int id, String type) {
            this.id = id;
            this.type = type;
        }
    }

    public static List<Result> treeNode(List<Row> tree) {
        Set<Integer> parentIds = new HashSet<>();
        for (Row row : tree) {
            if (row.parentId != null) {
                parentIds.add(row.parentId);
            }
        }

        List<Result> answer = new ArrayList<>();
        for (Row row : tree) {
            String type;
            if (row.parentId == null) {
                type = "Root";
            } else if (parentIds.contains(row.id)) {
                type = "Inner";
            } else {
                type = "Leaf";
            }
            answer.add(new Result(row.id, type));
        }
        return answer;
    }
}
JavaScript本地语义参考
/**
 * @param {{ id: number, p_id: number | null }[]} tree
 * @returns {{ id: number, type: string }[]}
 */
function treeNode(tree) {
  const parentIds = new Set(
    tree
      .map((row) => row.p_id)
      .filter((parentId) => parentId !== null)
  );

  return tree.map((row) => {
    let type;
    if (row.p_id === null) {
      type = "Root";
    } else if (parentIds.has(row.id)) {
      type = "Inner";
    } else {
      type = "Leaf";
    }
    return { id: row.id, type };
  });
}

from dataclasses import dataclass
from typing import List, Optional


@dataclass(frozen=True)
class Row:
    id: int
    p_id: Optional[int]


def tree_node(tree: List[Row]) -> List[tuple[int, str]]:
    parent_ids = {
        row.p_id for row in tree if row.p_id is not None
    }

    answer: List[tuple[int, str]] = []
    for row in tree:
        if row.p_id is None:
            node_type = "Root"
        elif row.id in parent_ids:
            node_type = "Inner"
        else:
            node_type = "Leaf"
        answer.append((row.id, node_type))

    return answer
C++17本地语义参考
#include <optional>
#include <string>
#include <unordered_set>
#include <utility>
#include <vector>

struct Row {
    int id;
    std::optional<int> parentId;
};

std::vector<std::pair<int, std::string>>
treeNode(const std::vector<Row>& tree) {
    std::unordered_set<int> parentIds;
    for (const Row& row : tree) {
        if (row.parentId.has_value()) {
            parentIds.insert(*row.parentId);
        }
    }

    std::vector<std::pair<int, std::string>> answer;
    answer.reserve(tree.size());

    for (const Row& row : tree) {
        std::string type;
        if (!row.parentId.has_value()) {
            type = "Root";
        } else if (parentIds.count(row.id) > 0) {
            type = "Inner";
        } else {
            type = "Leaf";
        }
        answer.emplace_back(row.id, type);
    }

    return answer;
}

边界、替代方案与面试追问

边界情况
单节点树必须输出 Root，所以根判断应先于“是否有孩子”。另外，SQL 子查询中过滤 NULL 能避免 NOT IN 一类写法的三值逻辑陷阱；本解虽使用 IN，仍显式过滤以清楚表达父节点集合。
替代方案：LEFT JOIN / EXISTS
可以把 Tree 与去重后的父节点编号表做 LEFT JOIN，也可以在 CASE 中使用相关 EXISTS 子查询。三者表达相同语义；在真实数据库中应结合执行计划、数据量和索引选择。
面试追问：为什么不能只看 p_id？
p_id 只能直接识别根；非根节点的 p_id 都非空，无法区分 Inner 和 Leaf。还必须判断当前 id 是否被其他节点当作父节点。
常见错误
把“有父节点”误当成叶子条件；忘记单节点树；把 NULL 写成 = NULL；为了联结而未对父节点编号去重，导致一个节点因多个孩子产生重复结果行；或者在结果顺序不限时擅自假设固定顺序。
