Solution

准备好核对思路了吗？

完整题解默认隐藏。展开后会看到核心查询、正确性、边界、复杂度、替代方案与四种本地语义参考实现。

答案的关键：NULL 不是一个普通值

SQL 使用 TRUE、FALSE、UNKNOWN 三值逻辑。NULL <> 2 的结果是 UNKNOWN，而 WHERE 只保留结果为 TRUE 的行。

核心洞察：把“推荐人不是 2”和“没有推荐人”写成两个明确分支，再用 OR 合并。

完整过程

  1. 从 Customer 逐行读取 referee_id。
  2. 若推荐人 id 明确不等于 2，则保留。
  3. 若推荐人为空，也保留，因为它表示“没有被任何人推荐”。
  4. 其余行的推荐人只能是 2，因此排除。
  5. 最后只投影 name 列；无需排序。

边界情况

  • referee_id = NULL：必须显式使用 IS NULL。
  • referee_id = 2：应排除，即便该客户自己的 id 不是 2。
  • 客户 id = 2：题目不要求排除本人；只看其推荐人。
  • 所有行均为空或均为 2 时，逻辑仍然成立。
  • 结果允许任意顺序，不要为排序增加无关成本。

正确性证明

对任意客户行 r 分三类讨论。若 r.referee_id 为 NULL，第二个条件为 TRUE，行被保留，恰好对应“没有推荐人”。若它是非空且不等于 2，第一个条件为 TRUE，行被保留，恰好对应“由 id 非 2 的客户推荐”。若它等于 2，则第一个条件为 FALSE、第二个条件也为 FALSE，行被排除。三类覆盖所有可能，因此查询返回且仅返回题目要求的客户。

复杂度：扫描 n 行，时间复杂度 O(n)；查询逻辑的额外空间复杂度 O(1)，结果集存储不计。

替代方案

可以写成 COALESCE(referee_id, -1) <> 2，但它依赖一个不会与真实 id 冲突的哨兵值，表达也不如显式 NULL 分支清楚。也可用 NOT (referee_id = 2)，但 NULL 仍会变成 UNKNOWN，不能单独解决问题。

常见错误

  • 只写 referee_id <> 2，误丢所有 NULL 行。
  • 写 referee_id = NULL；SQL 判空必须用 IS NULL。
  • 把条件错误写在客户自身 id 上。
  • 用 AND 连接两个互斥分支，导致结果为空。
  • 误以为输出必须与示例顺序完全一致。

面试追问

  • 为什么 WHERE 不保留 UNKNOWN？ SQL 标准中，WHERE 只保留谓词为 TRUE 的行。
  • 能用 NOT IN 吗？ 可以构造，但子查询或列表含 NULL 时容易触发三值逻辑陷阱，不适合这道直接筛选题。
  • 索引会有帮助吗？ 大表且选择性合适时，referee_id 索引可能有帮助；OR 与 NULL 分支的实际计划仍由优化器、统计信息和数据库实现决定。
  • 如何要求稳定顺序？ 题目若新增排序要求，应显式添加 ORDER BY，不能依赖物理返回顺序。

MySQL 是官方可提交方案；Java、JavaScript、Python、C++ 仅为本地语义参考，并非本数据库题的 LeetCode 提交语言。

SELECT name
FROM Customer
WHERE referee_id <> 2
   OR referee_id IS NULL;
import java.util.ArrayList;
import java.util.List;

public class CustomerReferee {
    public record Customer(int id, String name, Integer refereeId) {}

    public static List<String> findCustomerReferee(List<Customer> customers) {
        List<String> result = new ArrayList<>();

        for (Customer customer : customers) {
            Integer refereeId = customer.refereeId();
            if (refereeId == null || refereeId != 2) {
                result.add(customer.name());
            }
        }

        return result;
    }
}
/**
 * @param {{ id: number, name: string, referee_id: number | null }[]} customers
 * @return {string[]}
 */
function findCustomerReferee(customers) {
  return customers
    .filter((customer) => {
      const refereeId = customer.referee_id;
      return refereeId === null || refereeId !== 2;
    })
    .map((customer) => customer.name);
}
from dataclasses import dataclass
from typing import Iterable, Optional


@dataclass(frozen=True)
class Customer:
    id: int
    name: str
    referee_id: Optional[int]


def find_customer_referee(customers: Iterable[Customer]) -> list[str]:
    return [
        customer.name
        for customer in customers
        if customer.referee_id is None or customer.referee_id != 2
    ]
#include <optional>
#include <string>
#include <vector>

struct Customer {
    int id;
    std::string name;
    std::optional<int> refereeId;
};

std::vector<std::string> findCustomerReferee(
    const std::vector<Customer>& customers
) {
    std::vector<std::string> result;

    for (const Customer& customer : customers) {
        if (!customer.refereeId.has_value() || customer.refereeId.value() != 2) {
            result.push_back(customer.name);
        }
    }

    return result;
}
