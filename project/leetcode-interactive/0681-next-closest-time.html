最近时刻

Next Closest Time

给定一个 24 小时制时刻，只复用其中已经出现的数字，寻找时间轴上的下一次合法落点。先亲手探索时钟环；完整思路与代码留在页面底部，默认不会揭示。

Problem

题目说明

给定字符串 time，它以 HH:MM 表示一个有效的 24 小时制时刻。只能使用 time 中出现过的四个数字来组成新时刻，同一个数字可以重复使用。

返回严格晚于当前时刻且等待时间最短的合法时刻。时间跨过 23:59 后会从下一天 00:00 继续；如果只有原时刻可组成，它会在 24 小时后再次出现。

函数签名

nextClosestTime(time: string): string

约束

  • time.length == 5
  • time[2] == ':'
  • time 的形式为 HH:MM，且输入保证是有效时刻。
  • 00 <= HH <= 23，00 <= MM <= 59。

Complete solution

枚举一天内的所有时刻

核心洞察

一天只有 1440 个分钟刻度。把输入里的数字放入集合，枚举 00:00 到 23:59；只保留四个位置都来自集合的时刻。对每个候选计算从当前时刻向前走的循环分钟差，取最小正值。

完整过程

  1. 将 HH:MM 转成从午夜起的分钟数 current。
  2. 收集冒号之外的可用数字。
  3. 枚举一天内的 1440 个分钟刻度并格式化为五字符时刻。
  4. 若四个数字均可用，计算循环等待时间。
  5. 等待时间为 0 时改记为 1440，表示下一天的同一时刻。
  6. 维护等待时间最小的候选并返回。

正确性证明

完备性：枚举覆盖一天内每一个合法的 24 小时制时刻，因此任何能由输入数字组成的答案都一定会被检查。

合法性：算法只接纳四个数字位都属于可用数字集合的候选，所以保存的每个候选都满足题目限制。

最优性：循环差 (candidate - current + 1440) % 1440 给出候选下一次出现前的等待分钟数；差为 0 时对应 24 小时。算法在全部合法候选中选择最小正等待时间，因此返回的一定是最近时刻。

终止性：输入时刻自身一定可以由输入数字组成，最晚可在下一天再次出现，所以算法必有答案。

边界情况

  • 跨午夜：例如 23:59 的答案落在下一天。
  • 只有一个不同数字：例如 11:11，答案仍是次日的 11:11。
  • 前导零：00:01 必须始终保留五字符格式。
  • 候选与当前显示相同：等待时间是 1440，而不是 0。

复杂度

固定枚举 1440 个时刻，每个检查 4 个数字，时间复杂度为 O(1440 × 4)，在题目范围内可视为 O(1)；数字集合和若干变量占用 O(1) 空间。

替代方案

  • 逐分钟推进：最多尝试 1440 次，遇到第一个可表示时刻就返回，代码更短。
  • 四位回溯：从至多 4 个不同数字生成 D⁴ 个组合，过滤合法时刻后比较循环差。

面试追问

  • 如何把规则推广到 12 小时制或包含秒的 HH:MM:SS？
  • 如果每个数字只能使用原输入中的次数，检查条件应如何改变？
  • 能否用有序数字和回溯直接构造后继，而不枚举整天？

常见错误

  • 把相同时刻的循环差保留为 0，误当作“现在”。
  • 只比较整数大小，忘记跨午夜。
  • 格式化时丢失小时或分钟的前导零。
  • 错误地限制数字使用次数；本题允许重复使用。
Java可提交实现
import java.util.HashSet;
import java.util.Set;

class Solution {
    public String nextClosestTime(String time) {
        int current = Integer.parseInt(time.substring(0, 2)) * 60
                + Integer.parseInt(time.substring(3, 5));

        Set<Character> allowed = new HashSet<>();
        for (char ch : time.toCharArray()) {
            if (ch != ':') allowed.add(ch);
        }

        int bestDelta = 1441;
        String answer = time;

        for (int minute = 0; minute < 1440; minute++) {
            String candidate = String.format("%02d:%02d", minute / 60, minute % 60);
            if (!canBuild(candidate, allowed)) continue;

            int delta = (minute - current + 1440) % 1440;
            if (delta == 0) delta = 1440;
            if (delta < bestDelta) {
                bestDelta = delta;
                answer = candidate;
            }
        }
        return answer;
    }

    private boolean canBuild(String candidate, Set<Character> allowed) {
        for (char ch : candidate.toCharArray()) {
            if (ch != ':' && !allowed.contains(ch)) return false;
        }
        return true;
    }
}

/**

var nextClosestTime = function(time) {
  const current = Number(time.slice(0, 2)) * 60 + Number(time.slice(3));
  const allowed = new Set(time.replace(":", ""));
  let bestDelta = 1441;
  let answer = time;

  for (let minute = 0; minute < 1440; minute += 1) {
    const hourText = String(Math.floor(minute / 60)).padStart(2, "0");
    const minuteText = String(minute % 60).padStart(2, "0");
    const candidate = hourText + ":" + minuteText;
    const digits = candidate.replace(":", "");

    if (![...digits].every((digit) => allowed.has(digit))) continue;

    let delta = (minute - current + 1440) % 1440;
    if (delta === 0) delta = 1440;
    if (delta < bestDelta) {
      bestDelta = delta;
      answer = candidate;
    }
  }
  return answer;
};

C++可提交实现
#include <array>
#include <string>
using namespace std;

class Solution {
public:
    string nextClosestTime(string time) {
        int current = stoi(time.substr(0, 2)) * 60 + stoi(time.substr(3, 2));
        array<bool, 10> allowed{};
        for (char ch : time) {
            if (ch != ':') allowed[ch - '0'] = true;
        }

        int bestDelta = 1441;
        string answer = time;

        for (int minute = 0; minute < 1440; ++minute) {
            string candidate = render(minute);
            if (!canBuild(candidate, allowed)) continue;

            int delta = (minute - current + 1440) % 1440;
            if (delta == 0) delta = 1440;
            if (delta < bestDelta) {
                bestDelta = delta;
                answer = candidate;
            }
        }
        return answer;
    }

private:
    string render(int minute) {
        int hour = minute / 60;
        int part = minute % 60;
        string result = "00:00";
        result[0] = char('0' + hour / 10);
        result[1] = char('0' + hour % 10);
        result[3] = char('0' + part / 10);
        result[4] = char('0' + part % 10);
        return result;
    }

    bool canBuild(const string& candidate, const array<bool, 10>& allowed) {
        for (char ch : candidate) {
            if (ch != ':' && !allowed[ch - '0']) return false;
        }
        return true;
    }
};
