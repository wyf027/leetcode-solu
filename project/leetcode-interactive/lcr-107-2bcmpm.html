01 矩阵

给定由 0 和 1 组成的矩阵，返回每个单元格到最近 0 的曼哈顿距离。相邻单元格共享边，不能斜向移动。

题意

对每个值为 1 的格子，计算走到任意一个 0 所需的最短步数；0 到自身的距离为 0。答案矩阵与输入矩阵大小相同。

示例

输入：[[0,0,0],[0,1,0],[1,1,1]]
输出：[[0,0,0],[0,1,0],[1,2,1]]

约束

1 ≤ m,n ≤ 10⁴，1 ≤ m×n ≤ 10⁴；矩阵至少包含一个 0。

分步交互：多源 BFS

所有 0 同时入队；每轮向四个方向扩散。

准备就绪。

核心洞察

不能从每个 1 分别寻找最近的 0：这样会重复遍历。将所有 0 当成 BFS 的起点同时入队，第一次访问某格时的层数就是它到最近 0 的最短距离。

完整过程

  1. 新建距离矩阵，初始为 -1；扫描输入，把所有 0 标为 0 并入队。
  2. 每次取出队首，检查上、下、左、右四邻居。
  3. 未访问的邻居距离为当前距离加 1，并立即入队。

边界

  • 0 必须全部作为起点，而非只选第一个。
  • 边界格访问邻居前要检查下标。
  • 入队时标记访问，避免重复入队。

复杂度

每个格子最多入队一次，时间 O(mn)；距离矩阵与队列共用 O(mn) 空间。

替代方案与追问

两次动态规划扫描也可完成：左上到右下、右下到左上分别松弛相邻状态。追问：若每个格子的移动代价不同，应改用多源 Dijkstra；若允许对角移动，增加四个方向即可。

常见错误

  • 对每个 1 单独 BFS，最坏会超时。
  • 将 1 初始为 0，失去未访问标记。
  • 更新距离后未及时入队，扩散链路断开。

class Solution { public int[][] updateMatrix(int[][] mat) { int m=mat.length,n=mat[0].length; Queue<int[]> q=new ArrayDeque<>(); for(int i=0;i<m;i++)for(int j=0;j<n;j++){if(mat[i][j]==0)q.offer(new int[]{i,j});else mat[i][j]=-1;} int[][] d={{1,0},{-1,0},{0,1},{0,-1}}; while(!q.isEmpty()){int[] a=q.poll();for(int[] x:d){int r=a[0]+x[0],c=a[1]+x[1];if(r>=0&&r<m&&c>=0&&c<n&&mat[r][c]==-1){mat[r][c]=mat[a[0]][a[1]]+1;q.offer(new int[]{r,c});}}} return mat; } }

# Python
from collections import deque
class Solution:
    def updateMatrix(self, mat: list[list[int]]) -> list[list[int]]:
        m, n, q = len(mat), len(mat[0]), deque()
        for i in range(m):
            for j in range(n):
                if mat[i][j] == 0: q.append((i,j))
                else: mat[i][j] = -1
        while q:
            i,j = q.popleft()
            for x,y in ((1,0),(-1,0),(0,1),(0,-1)):
                r,c = i+x,j+y
                if 0 <= r < m and 0 <= c < n and mat[r][c] == -1: mat[r][c] = mat[i][j]+1; q.append((r,c))
        return mat
