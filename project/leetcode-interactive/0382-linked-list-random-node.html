链表随机节点

给定一个单链表，从所有节点中随机返回一个节点值。每个节点位置必须拥有完全相同的被选概率；链表可能很长，且长度未必预先可知。

01 · Problem

题目与调用形式

实现 Solution 类。构造时接收单链表头节点，随后每次调用 getRandom() 都要独立地从全部节点中等概率选择一个并返回其值。

完整参数形式示例

输入
["Solution", "getRandom", "getRandom", "getRandom", "getRandom", "getRandom"]
[[[1, 2, 3]], [], [], [], [], []]

输出（一次可能的随机结果）
[null, 1, 3, 2, 2, 3]

解释
Solution solution = new Solution([1, 2, 3]);
solution.getRandom(); // 可能返回 1
solution.getRandom(); // 可能返回 3
solution.getRandom(); // 可能返回 2
solution.getRandom(); // 可能返回 2
solution.getRandom(); // 可能返回 3

输出序列不是固定答案；每次调用都可以返回 1、2 或 3，但长期来看三个节点位置各自被返回的概率都应为 1/3。

接口

Solution(ListNode head) int getRandom()

约束

  • 链表节点数在 [1, 10⁴] 内。
  • -10⁴ ≤ Node.val ≤ 10⁴。
  • 最多调用 getRandom 10⁴ 次。
  • 进阶要求：长度未知时仍高效，并且不使用随节点数增长的额外空间。

    04 · Solution

    准备好再揭晓

    完整洞察、证明、复杂度、四语言代码与追问都收在这里。

    核心洞察

    对长度未知的数据流，维护一个候选答案。扫描到第 i 个节点时，以 1 / i 的概率用它替换候选。第一个节点以 1/1 的概率进入候选，因此始终有合法答案。

    这正是一号水塘抽样：只保存一个样本，却能让最终每个节点等概率留下。

    完整过程

    1. 构造函数只保存链表头节点。
    2. 每次调用 getRandom() 都从头扫描，计数 i 从 1 开始。
    3. 对第 i 个节点，在 [0, i) 中均匀取整数；若为 0，就替换当前答案。
    4. 到达链表末尾后返回候选值。

    正确性证明

    设链表共有 n 个节点。第 k 个节点先以 1/k 的概率被选中；随后它必须躲过第 k+1 到第 n 个节点的替换。

    P(k 最终留下) = 1/k × ∏(i=k+1..n) (i−1)/i = 1/k × k/n = 1/n

    所以任意 k 的最终概率都为 1/n，算法满足对每个节点位置等概率抽样。

    边界与复杂度

    • 单节点：以 1/1 概率选择，必然返回该值。
    • 重复值：均匀性针对节点位置；两个相同值仍是两个独立节点。
    • 负数与零：只作为保存的值，不影响抽样概率。
    • 每次调用时间 O(n)，额外空间 O(1)。

    替代方案

    • 构造时缓存数组：预处理 O(n)、空间 O(n)，之后每次抽样 O(1)。适合内存允许且调用特别频繁的场景。
    • 先求长度再随机下标：空间 O(1)，但需要额外遍历，长度变化时也更难维护。
    • 若已知长度且支持随机访问，直接随机下标最简单；单链表并不支持 O(1) 随机访问。

    常见错误

    • 每一步使用固定替换概率，导致越靠后的节点概率越大或越小。
    • 计数从 0 开始却直接计算 1/i，引发除零或概率偏差。
    • 随机整数区间写成 [0, i]，把正确的 1/i 变成 1/(i+1)。
    • 按“不同值”去重后再抽样，破坏节点位置层面的均匀性。

    四语言完整代码

    import java.util.concurrent.ThreadLocalRandom;

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    private final ListNode head;

    public Solution(ListNode head) {
        this.head = head;
    }

    public int getRandom() {
        int answer = head.val;
        ListNode node = head.next;
        int i = 2;

        while (node != null) {
            if (ThreadLocalRandom.current().nextInt(i) == 0) {
                answer = node.val;
            }
            node = node.next;
            i++;
        }
        return answer;
    }
}
    /**
 * Definition for singly-linked list.
 * function ListNode(val, next) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.next = (next === undefined ? null : next);
 * }
 */
/**
 * @param {ListNode} head
 */
var Solution = function(head) {
    this.head = head;
};

/**
 * @return {number}
 */
Solution.prototype.getRandom = function() {
    let answer = this.head.val;
    let node = this.head.next;
    let i = 2;

    while (node !== null) {
        if (Math.floor(Math.random() * i) === 0) {
            answer = node.val;
        }
        node = node.next;
        i++;
    }
    return answer;
};
    import random


# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:

    def __init__(self, head: Optional[ListNode]):
        self.head = head

    def getRandom(self) -> int:
        answer = self.head.val
        node = self.head.next
        i = 2

        while node:
            if random.randrange(i) == 0:
                answer = node.val
            node = node.next
            i += 1

        return answer
    #include <random>

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
private:
    ListNode* head;
    std::mt19937 generator;

public:
    Solution(ListNode* head)
        : head(head), generator(std::random_device{}()) {}

    int getRandom() {
        int answer = head->val;
        ListNode* node = head->next;
        int i = 2;

        while (node != nullptr) {
            std::uniform_int_distribution<int> pick(1, i);
            if (pick(generator) == 1) {
                answer = node->val;
            }
            node = node->next;
            ++i;
        }
        return answer;
    }
};
