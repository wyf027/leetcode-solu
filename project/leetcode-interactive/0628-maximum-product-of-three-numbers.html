Maximum Product of Three Numbers

三个数的
最大乘积

给定一个整数数组，从中选出三个数，使它们的乘积最大，并返回这个最大乘积。你能在不枚举所有三元组的情况下完成吗？

Problem

题目说明

maximumProduct(nums) → integer

输入整数数组 nums。在数组中选择三个不同位置上的元素，使三者乘积尽可能大；返回这个最大乘积。

示例 01

输入nums = [1,2,3]
输出6
解释唯一的三个数相乘：1 × 2 × 3 = 6。

示例 02

输入nums = [1,2,3,4]
输出24
解释选择 2、3、4，乘积为 24。

示例 03

输入nums = [-1,-2,-3]
输出-6
解释三个负数相乘，结果为 -6。

约束

  • 3 ≤ nums.length ≤ 10⁴
  • -1000 ≤ nums[i] ≤ 1000
  • 返回值类型为整数。

Solution

一次扫描，维护五个极值

核心洞察

最大乘积只可能来自两种组合：三个最大的数，或两个最小的数与一个最大的数。原因是两个很小的负数相乘会变成很大的正数。于是只要保留最小的两个值和最大的三个值，不必关心其余元素。

完整过程

  1. 初始化 min1、min2 为正无穷，max1、max2、max3 为负无穷。
  2. 依次扫描每个数。若它进入最小的两个数，就向后移动旧值；最大的三个数同理。
  3. 扫描结束后计算 max1 × max2 × max3。
  4. 再计算 min1 × min2 × max1，返回二者较大值。

正确性证明

引理 1：若最优三元组包含零个或两个负数，它的最大候选要么是三个最大值，要么是两个最小值加最大值。固定符号结构后，选择绝对贡献更大的极值不会使乘积变小。

引理 2：三个负数的乘积为负；当所有可选乘积都为负时，数组全为负数，三个最大的数最接近零，因此它们的乘积最大。

结论：所有可能的最优符号结构都被上述两个候选覆盖。算法返回两者最大值，因此一定得到全局最大乘积。

边界情况

  • 数组恰有 3 个元素：两个候选最终等价或其中一个覆盖全部元素。
  • 全为负数：选择数值最大的三个负数。
  • 包含零：零可能优于任何负乘积。
  • 重复极值：按元素位置选择，数值可相同。
  • 约束下最大绝对乘积为 10⁹，四种实现的所用数值类型均可安全表示。

复杂度

时间 O(n)：数组仅扫描一次。

空间 O(1)：只保存五个极值，不随输入规模增长。

替代方案

先排序，再比较末尾三个数与开头两个数加末尾最大值。代码更短，但时间复杂度为 O(n log n)；若原地排序，还会改变输入数组。

JavaScript · O(n) / O(1)
/**
 * @param {number[]} nums
 * @return {number}
 */
var maximumProduct = function(nums) {
    let min1 = Infinity;
    let min2 = Infinity;
    let max1 = -Infinity;
    let max2 = -Infinity;
    let max3 = -Infinity;

    for (const x of nums) {
        if (x <= min1) {
            min2 = min1;
            min1 = x;
        } else if (x < min2) {
            min2 = x;
        }

        if (x >= max1) {
            max3 = max2;
            max2 = max1;
            max1 = x;
        } else if (x >= max2) {
            max3 = max2;
            max2 = x;
        } else if (x > max3) {
            max3 = x;
        }
    }

    return Math.max(
        max1 * max2 * max3,
        min1 * min2 * max1
    );
};

Python · O(n) / O(1)
from typing import List


class Solution:
    def maximumProduct(self, nums: List[int]) -> int:
        min1 = min2 = float("inf")
        max1 = max2 = max3 = float("-inf")

        for x in nums:
            if x <= min1:
                min1, min2 = x, min1
            elif x < min2:
                min2 = x

            if x >= max1:
                max1, max2, max3 = x, max1, max2
            elif x >= max2:
                max2, max3 = x, max2
            elif x > max3:
                max3 = x

        return max(max1 * max2 * max3,
                   min1 * min2 * max1)

面试追问

  • 为什么不能只维护绝对值最大的三个数？
  • 若数据以流式到达，当前方案是否仍然适用？
  • 若数值范围更大，如何处理整数溢出？

常见错误

  • 只取最大的三个数，漏掉“两个负数翻正”的情况。
  • 更新三个最大值时顺序写反，导致旧值被提前覆盖。
  • 用零初始化极值，在全负数组上得到错误结果。
  • 排序后忘记输入可能被原地修改。
  • 跨语言迁移时忽略乘积可能溢出的范围。
