01 · Mission Brief

题意转述

给定一个无向连通图中的节点引用，返回整张图的深拷贝。每个节点包含整数 val 和邻居节点列表 neighbors；空图输入返回空引用。

测试用邻接表描述图，但函数真正接收的是节点对象。输出看起来相同，内部引用必须全部换新。

04 · Sealed Solution

先操作，再揭晓题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码都封存在下方。

Core Insight

原节点 → 克隆节点，一张映射表贯穿始终

第一次看到原节点时立刻创建克隆并入队；以后再次遇到它，只复用映射中的克隆。处理原节点 u 的邻居 v 时，把 copy[v] 加入 copy[u].neighbors。这样既防止环导致无限遍历，也保证克隆边不指回原图。

Complexity

时间
O(V + E)
辅助空间
O(V)
输出本身
O(V + E)

Complete Process

  1. 空引用直接返回空。
  2. 为起点建克隆，写入映射并入队。
  3. 循环取出原节点，逐个查看邻居。
  4. 未映射的邻居：新建克隆、记录并入队。
  5. 把邻居克隆接到当前克隆的邻居表。
  6. 队列清空后返回起点克隆。

Edges & Pitfalls

  • 空图：先判空，避免访问成员。
  • 单节点：也必须返回新对象。
  • 环：创建时就写映射，而不是出队后才写。
  • 身份：映射键用原节点对象；不要把原邻居直接塞进克隆。

Alternatives

DFS 递归同样是 O(V + E)，代码更短；但递归深度由图形状决定。面试主线选 BFS，队列状态更易解释，也避开递归栈风险。仅复制邻接表无法直接生成题目要求的节点对象，因此不是可提交解法。

Interview Follow-ups

  • 为什么 map 要在入队时写？ 防止两个父节点重复创建同一邻居。
  • 值不唯一怎么办？ 仍可按对象引用做键，不依赖 val。
  • 图不连通怎么办？ 题目只给一个入口时只能克隆其连通分量；若给所有节点，则对未访问节点逐一启动 BFS。

Common Mistakes

  • 只 new 起点，却复用原图的 neighbors。
  • 先连边、后创建邻居克隆，导致空映射。
  • 没有 visited / map，在无向边上来回循环。
  • 把节点值当数组下标，错误依赖值连续。

class Solution {
    public Node cloneGraph(Node node) {
        if (node == null) return null;

        Map<Node, Node> copies = new HashMap<>();
        Queue<Node> queue = new ArrayDeque<>();
        copies.put(node, new Node(node.val));
        queue.offer(node);

        while (!queue.isEmpty()) {
            Node current = queue.poll();
            for (Node neighbor : current.neighbors) {
                if (!copies.containsKey(neighbor)) {
                    copies.put(neighbor, new Node(neighbor.val));
                    queue.offer(neighbor);
                }
                copies.get(current).neighbors.add(copies.get(neighbor));
            }
        }
        return copies.get(node);
    }
}

  if (node === null) return null;

  const copies = new Map([[node, new _Node(node.val)]]);
  const queue = [node];
  let head = 0;

  while (head < queue.length) {
    const current = queue[head++];
    for (const neighbor of current.neighbors) {
      if (!copies.has(neighbor)) {
        copies.set(neighbor, new _Node(neighbor.val));
        queue.push(neighbor);

  }

class Solution {
public:
    Node* cloneGraph(Node* node) {
        if (node == nullptr) return nullptr;

        unordered_map<Node*, Node*> copies;
        queue<Node*> nodes;
        copies[node] = new Node(node->val);
        nodes.push(node);

        while (!nodes.empty()) {
            Node* current = nodes.front();
            nodes.pop();
            for (Node* neighbor : current->neighbors) {
                if (!copies.count(neighbor)) {
                    copies[neighbor] = new Node(neighbor->val);
                    nodes.push(neighbor);
                }
                copies[current]->neighbors.push_back(copies[neighbor]);
            }
        }
        return copies[node];
    }
};
