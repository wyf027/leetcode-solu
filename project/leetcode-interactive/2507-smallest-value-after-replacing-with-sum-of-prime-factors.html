01 / 题目

重复替换，寻找最小值

给定正整数 n，每次将它替换成所有质因数的和，然后对新值继续执行同样的操作。重复出现的质因数要按出现次数分别计入。返回整个过程中 n 能达到的最小值，初始值也属于这个过程。

参数与返回值

smallestValue(n: integer) → integer

约束：2 ≤ n ≤ 105。

质因数按重数计算

例如 12 = 2 × 2 × 3，其中两个 2 都必须参与求和。

官方示例 1

输入：n = 15
输出：5

15 = 3 × 5 → 8；8 = 2 × 2 × 2 → 6；6 = 2 × 3 → 5。过程中最小值为 5。

官方示例 2

输入：n = 3
输出：3

3 只有一个质因数 3，替换后仍为 3，因此最小值是 3。

04 / 解题笔记

准备好揭开规律了吗？

包含证明、复杂度与四语言完整实现。

题解 · 试除分解，直到值不再变化

核心洞察

质因数之和不会大于原数，因此持续替换就能找到最小值。停止条件应当是“本轮和等于原数”，而不是“遇到质数”：4 = 2 × 2，且 2 + 2 = 4，也是固定点。

完整过程

  1. 保存本轮原数 n，令工作副本 x = n，累加和 sum = 0。
  2. 从 d = 2 开始试除，只要 d × d ≤ x 就继续。若 x % d == 0，反复把 d 加入和，并令 x /= d。
  3. 试除结束后，若 x > 1，它是剩余的一个质因数，将它加入和。
  4. 若 sum == n，返回 n；否则令 n = sum，进入下一轮。

15 → 8 → 6 → 5 → 5。相等时停止，返回 5。试除过程中始终保留本轮原数，才能正确比较新旧值。

正确性证明

  1. 单轮分解正确：每次成功除去 d 都记录一次贡献。按从小到大的顺序试除，较小质因数已被全部除尽，因此被记录的 d 必为质数。循环结束后，若剩余 x > 1 仍为合数，它必有不大于 √x 的质因数，与结束条件矛盾。故得到恰好全部质因数，且重数无遗漏。
  2. 数值单调不增：对于 a,b ≥ 2，有 ab ≥ a+b，因为 ab−a−b = (a−1)(b−1)−1 ≥ 0。对质因数逐个合并，即得乘积不小于总和。两个因数时只在 2、2 时相等；三个及以上因数时严格大于总和。质数本身也保持不变。
  3. 终止且最优：每轮要么得到更小的、至少为 2 的整数，要么达到固定点。因此过程必终止；到达固定点后不会再变化，之前的值又都不小于它，所以返回值正是可达到的最小值。

边界与常见错误

  • n = 2 或其他质数：剩余因数直接加回，立刻停止。
  • n = 4：返回 4。只以质数为停止条件会死循环。
  • 不能把质因数放入集合去重，12 的和应为 2 + 2 + 3 = 7。
  • 整除逻辑要使用 while，单次 if 会漏掉重数。
  • 不要漏加最后的 x > 1；不要用已被除小的 x 与和比较。
  • 当前约束下平方不会溢出；若扩大到大整数，试除条件可改用 d ≤ x / d。

复杂度

设初始值为 N、总轮数为 k。每轮试除上界为 O(√N)，因此直接上界为 O(k√N) 时间，O(1) 额外空间。还能取 k = O(log N)：合数 n ≥ 8 的质因数和至多 n/2 + 2 ≤ 3n/4，较小整数只需常数轮，故整体有保守上界 O(√N log N)。这里的空间结论针对提交代码；交互演示为回退操作额外保存了步骤。

收缩界的理由：将任意合数拆成 a × b（2 ≤ a ≤ b），两部分质因数和各自不超过 a、b；而 a+b ≤ 2+n/2，因为 (a−2)(b−2) ≥ 0。

替代方案

若要处理大量查询，可先用筛法预处理每个数的最小质因数 SPF，再沿 SPF 快速分解。普通 SPF 筛需要 O(N log log N) 预处理时间与 O(N) 空间；本题只有单个输入，直接试除更简单。也可仅试除 2 和奇数来减少常数，思路不变。

面试追问

  • 固定点有哪些？所有质数，以及唯一的合数固定点 4，可由上面的等号条件证明。
  • 需要维护全局最小值吗？不需要，单调不增确保终点就是最小值。
  • 如果忽略重数呢？那是另一种变换，例如 4 会变成 2；不能复用本题的等号结论。
  • 多次查询怎样复用？使用 SPF 分解，也可缓存每个数的最终结果，复用后续路径。

Java

class Solution {
    public int smallestValue(int n) {
        while (true) {
            int x = n, sum = 0;
            for (int d = 2; d * d <= x; d++) {
                while (x % d == 0) {
                    sum += d;
                    x /= d;
                }
            }
            if (x > 1) sum += x;
            if (sum == n) return n;
            n = sum;
        }
    }
}
