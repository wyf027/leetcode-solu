Problem

题目描述

原集合本应恰好包含从 1 到 n 的每个整数一次。一次数据错误让其中一个数被复制，从而造成一个数出现两次、另一个数消失。

给定长度为 n 的整数数组 nums，它记录了出错后的集合。请返回 [重复的数, 丢失的数]。

函数形式

findErrorNums(nums: integer[]) → integer[]

约束

  • 2 ≤ nums.length ≤ 10⁴
  • 1 ≤ nums[i] ≤ 10⁴
  • 令 n = nums.length，输入由 1..n 经一次复制错误得到。
  • 答案顺序固定为：先重复值，后丢失值。

示例 1

输入：nums = [1,2,2,4]
输出：[2,3]

示例 2

输入：nums = [1,1]
输出：[1,2]

Solution

原地符号标记

核心洞察

值域恰好是 1..n，因此值 x 可以映射到数组下标 x - 1。把该位置变成负数，相当于写下一条“x 已出现”的标记；若再次访问时它已经为负，x 就是重复值。最后仍为正的位置没有被任何值访问，其下标加一就是丢失值。

完整过程

  1. 初始化 duplicate = -1。
  2. 遍历每个元素，读取 x = abs(nums[i])，避免先前的负号干扰原值。
  3. 检查目标位置 x - 1：若已经为负，则记录重复值 x；否则将该位置取负。
  4. 第二次扫描数组；第一个仍为正的位置 i 表示数值 i + 1 从未出现。
  5. 按题目要求返回 [duplicate, missing]。

正确性证明

标记不变量：处理完任意前缀后，对于其中出现过的每个值 x，位置 x-1 为负；未出现过的值不会让对应位置变负。

由不变量，第二次遇到重复值 d 时，位置 d-1 必已为负，所以算法识别出 d。除丢失值 m 外，其余值都至少出现一次，因此对应位置都被标负；只有 m-1 保持为正。于是第二次扫描得到 m，最终返回结果正确。

边界与副作用

  • n = 2 时流程不变，例如 [1,1]。
  • 重复或丢失的是 1、n 时无需特殊分支。
  • 实现会修改输入数组的符号；若调用方需要保留输入，应先复制，或改用计数数组。
  • 题目保证输入满足“一重一失”；若保证取消，需要额外校验。

复杂度

时间 O(n) 两次线性扫描
额外空间 O(1) 忽略返回数组

JavaLeetCode 可提交
class Solution {
    public int[] findErrorNums(int[] nums) {
        int duplicate = -1;

        for (int i = 0; i < nums.length; i++) {
            int value = Math.abs(nums[i]);
            int target = value - 1;

            if (nums[target] < 0) {
                duplicate = value;
            } else {
                nums[target] = -nums[target];
            }
        }

        int missing = -1;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] > 0) {
                missing = i + 1;
                break;
            }
        }

        return new int[] {duplicate, missing};
    }
}

class Solution:

        duplicate = -1

        for value_with_sign in nums:
            value = abs(value_with_sign)
            target = value - 1

            if nums[target] < 0:

            else:
                nums[target] = -nums[target]

        missing = -1

            if value > 0:
                missing = index + 1
                break

        return [duplicate, missing]

    vector<int> findErrorNums(vector<int>& nums) {
        int duplicate = -1;

        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            int value = abs(nums[i]);
            int target = value - 1;

                duplicate = value;
            } else {
                nums[target] = -nums[target];
            }
        }

        int missing = -1;

                break;
            }

        return {duplicate, missing};
    }

替代方案

  • 计数数组：最直观，时间 O(n)、空间 O(n)，且不修改输入。
  • 排序：通过相邻重复与序列断点定位，时间 O(n log n)；排序通常也会修改输入。
  • 求和 + 平方和：解二元方程，额外空间 O(1)，但必须谨慎处理整数溢出。
  • XOR 分组：时间 O(n)、空间 O(1) 且不改输入，但推导和区分重复/丢失更复杂。

面试追问

  • 如果不允许修改 nums，你会如何权衡哈希、数学和 XOR？

  • 如果有多个重复值和多个丢失值，现有不变量还够用吗？
  • 如果数据以流式方式到达且无法回看，最少需要保留什么状态？

常见错误

  • 数组已被改成负数后仍直接使用 nums[i] 计算下标，导致负下标；必须先取绝对值。
  • 把重复值和丢失值的返回顺序写反。
  • 第二轮按元素值而不是按“位置是否仍为正”寻找丢失值。
  • 声称空间 O(1)，却先复制了整个数组而未说明。
  • 忘记告诉调用方原地标记会改变输入数组。
