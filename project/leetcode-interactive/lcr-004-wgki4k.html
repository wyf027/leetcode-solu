LCR 004MEDIUM位运算

只出现一次的数字 II

数组中除一个数字只出现一次外，其余数字均出现三次。在线性时间、常数额外空间内找出那个唯一数字。

题目转换

把每个整数拆成 32 个二进制位。对同一位的所有 1 求和：出现三次的数字贡献总是 3 的倍数，余数就是唯一数字在该位的值。

例： [2, 2, 3, 2]

二进制按位计数后取模 3，剩下 0011，即答案 3。

核心洞察

这不是“去重”问题，而是逐位做有限状态计数。位和对 3 取模能抹去所有重复三次的贡献；补码形式也自然覆盖负数。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

解题过程

  1. 1. 初始化答案 ans = 0。
  2. 2. 对第 0 到 31 位分别统计数组中 1 的数量。
  3. 3. 若 count % 3 != 0，在答案对应位设 1。
  4. 4. 使用位或合并每一位，得到唯一值。

边界、复杂度与替代

  • 负数：遍历完整 32 位，符号位会按补码恢复。
  • 零：零的所有位均为 0，不需要特判。
  • 复杂度：时间 O(32n)=O(n)，空间 O(1)。
  • 替代：哈希表计数直观但需 O(n) 空间；状态机 ones/twos 可把 32 次扫描压成一次。

四语言实现

逐位计数法，逻辑直接且易于解释。

面试追问与常见错误

面试追问

  • 若其他数出现 k 次，该如何泛化？
  • 怎样用 ones/twos 状态机一次扫描？
  • 如果出现两次的是噪声，异或为何失效？

常见错误

  • 误用异或：三次重复无法抵消。
  • 只循环到 31，漏掉符号位。
  • 右移负数时忽略语言的符号扩展差异。

对 bit 从 0 到 31：count = Σ((num >> bit) & 1)；若 count % 3 == 1，执行 ans |= 1 << bit。返回 ans。
