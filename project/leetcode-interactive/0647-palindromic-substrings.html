01 · Problem

题目与边界

回文必须是连续子串。长度为 1 的每个字符天然是回文；内容相同但位置不同的子串属于不同答案。

题意转述

输入：字符串 s。

任务：统计 s 中全部回文子串的数量。

输出：一个整数，表示符合条件的连续子串总数。

约束

  • 1 <= s.length <= 1000
  • s 仅由小写英文字母组成。

官方示例

Example 1
输入：s = "abc" 输出：3 解释："a"、"b"、"c"。
Example 2
输入：s = "aaa" 输出：6 解释：三个 "a"、两个 "aa"、一个 "aaa"。

03 · Solution

中心扩展

不要枚举完整子串再逐个判断。反过来枚举回文的中心，并从中心向两侧同步扩展；每次字符相等，就恰好发现一个新回文。

核心洞察

长度为奇数的回文中心落在字符上，长度为偶数的回文中心落在两个字符之间。长度为 n 的字符串一共存在 2n - 1 个这样的中心。对每个中心持续向外比较，就能覆盖全部回文子串。

奇数中心：(i, i)　　偶数中心：(i, i + 1)

完整过程

  1. 初始化答案 ans = 0。
  2. 依次选择每个字符作为奇数回文中心，令 left = right = i。
  3. 依次选择每对相邻字符之间的位置作为偶数回文中心，令 left = i、right = i + 1。
  4. 只要边界仍在字符串内且 s[left] == s[right]，就把答案加一，然后令 left--、right++。
  5. 任一边界越界或两端字符不同，当前中心停止扩展，继续下一个中心。

正确性证明

不漏计

任意回文子串都拥有唯一中心：奇数长度落在字符上，偶数长度落在字符间。算法会访问这个中心，并扩展到该子串边界。

不错计

算法仅在左右边界字符相等、内部已由更小一层扩展确认对称时计数，因此每次计入的窗口都是回文。

不重复

一个具体的回文子串由唯一的左右边界确定，也就拥有唯一的中心与扩展半径，只会在那一轮被计数一次。

综上，算法计入且仅计入所有回文子串，所以返回结果正确。

时间复杂度O(n²)

共有 O(n) 个中心，每个中心最坏向外扩展 O(n) 次。

空间复杂度O(1)

除计数器和左右边界外，不使用随输入规模增长的额外空间。

边界情况

  • s.length == 1：唯一字符本身就是唯一回文。
  • 所有字符不同：答案等于 n，只有单字符回文。
  • 所有字符相同：答案达到最大值 n(n + 1) / 2。
  • 偶数长度回文如 "abba"：必须处理字符间中心，否则会漏掉 "bb" 和 "abba"。

替代方案

方案时间空间取舍
暴力枚举 + 逐个判断O(n³)O(1)直观，但重复比较大量字符，输入上限 1000 时不理想。
动态规划O(n²)O(n²)dp[l][r] 表示区间是否回文，适合还要查询具体区间的场景。
中心扩展O(n²)O(1)本题最简洁实用，直接计数且无需二维表。
ManacherO(n)O(n)理论更快，但实现复杂；适合超长字符串或需要回文半径数组时。

class Solution {
    public int countSubstrings(String s) {
        int answer = 0;

        for (int center = 0; center < s.length(); center++) {
            answer += expand(s, center, center);       // odd length
            answer += expand(s, center, center + 1);   // even length
        }

        return answer;
    }

    private int expand(String s, int left, int right) {
        int count = 0;

        while (left >= 0 && right < s.length()
                && s.charAt(left) == s.charAt(right)) {
            count++;
            left--;
            right++;
        }

        return count;
    }
}

class Solution {
public:
    int countSubstrings(string s) {
        int answer = 0;

        for (int center = 0; center < static_cast<int>(s.size()); ++center) {
            answer += expand(s, center, center);       // odd length
            answer += expand(s, center, center + 1);   // even length
        }

        return answer;
    }

private:
    int expand(const string& s, int left, int right) {
        int count = 0;

        while (left >= 0 && right < static_cast<int>(s.size())
                && s[left] == s[right]) {
            ++count;
            --left;
            ++right;
        }

        return count;
    }
};

面试追问

  • 如何同时返回最长回文子串？记录扩展成功时的最大左右边界。
  • 如何做到线性时间？说明 Manacher 如何复用已知回文半径。
  • 若字符流不断追加，如何动态维护答案？需要讨论在线回文结构，例如回文树。
  • 如果只问不同内容的回文子串数量，为什么不能直接用当前计数？需要去重结构。

常见错误

  • 只处理 (i, i)，遗漏所有偶数长度回文。
  • 把相同内容的不同位置合并，误解了“子串个数”。
  • 在比较字符前没有检查左右边界，导致越界。
  • 扩展成功后忘记移动两侧指针，形成死循环。
  • 用切片创建子串再反转，带来不必要的额外时间与空间。
