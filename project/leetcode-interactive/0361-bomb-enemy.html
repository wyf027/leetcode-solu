轰炸敌人

Bomb Enemy

单文件 · 可离线打开 · 交互演示

题目描述

给定一个由字符组成的二维网格 grid：'W' 表示墙，'E' 表示敌人，'0' 表示可以放置炸弹的空地。

你只能在一处空地放置一枚炸弹。炸弹会消灭它所在行和列中能够直线到达的所有敌人；传播遇到墙就停止，墙后的敌人不会被波及。返回一枚炸弹最多可以消灭的敌人数。若没有空地，返回 0。

函数形式
int maxKilledEnemies(char[][] grid)

示例 1

输入：grid = [["0","E","0","0"],
              ["E","0","W","E"],
              ["0","E","0","0"]]
输出：3

把炸弹放在 grid[1][1]，可以消灭同一行左侧的 1 个敌人，以及同一列上下的 2 个敌人。

示例 2

输入：grid = [["W","W","W"],
              ["0","0","0"],
              ["E","E","E"]]
输出：1

约束

  • m == grid.length
  • n == grid[i].length
  • 1 <= m, n <= 500
  • grid[i][j] 只可能是 'W'、'E' 或 '0'

题解：按墙分段复用计数

核心洞察

墙把每一行和每一列切成互不影响的连续段。同一行段里的所有空地，能够看到的横向敌人数完全相同；同一列段也是如此。因此不必从每个空地向四个方向重新扫描，只在进入一个新段时统计一次并复用结果。

完整过程

  1. 按从上到下、从左到右的顺序遍历网格。
  2. 若当前格在某行的开头，或它左边是墙，就向右扫描到下一堵墙，得到当前行段的敌人数 rowHits。
  3. 为每一列维护 colHits[j]。若当前格在第一行，或它上方是墙，就向下扫描到下一堵墙，更新当前列段的敌人数。
  4. 只有当前格是 '0' 时才允许放炸弹，用 rowHits + colHits[j] 更新答案。

正确性证明

引理 1：在两堵相邻墙之间的同一行段内，任意空地可命中的横向敌人集合相同。因为段内没有墙阻隔，而段外的传播必被边界墙阻止。列段同理。

引理 2：算法处理空地 (i,j) 时，rowHits 等于它所在行段的敌人数，colHits[j] 等于它所在列段的敌人数。每当进入新行段或新列段时算法会重新扫描完整的对应段；段内其值持续复用，因此始终成立。

定理：对每个合法空地，横向和纵向只在炸弹位置相交，而该位置不是敌人，所以两项计数没有重复。由引理 2，二者之和正是该空地能消灭的敌人数。算法枚举所有空地并取最大值，故返回全局最优答案。

边界情况

  • 网格没有空地：答案保持为 0。
  • 网格只有一行或一列：同一套分段逻辑仍然成立。
  • 连续墙、墙位于边缘、段内没有敌人：对应段计数为 0。
  • 不能在敌人或墙上放置炸弹，只有 '0' 才更新答案。

复杂度

每个行段只被横向扫描一次，每个列段只被纵向扫描一次，总时间复杂度为 O(mn)。列缓存使用 O(n) 额外空间。

替代方案

  • 四方向暴力：从每个空地向四方扫描，最坏可达 O(mn(m+n))，简单但会重复工作。
  • 四张方向计数表：分别预处理左、右、上、下可见敌人数，查询直接相加，时间 O(mn)，但空间为 O(mn)。
  • 逐段收集空地：扫描每个无墙行段与列段，把敌人数累加到空地计数表，也可做到 O(mn) 时间和 O(mn) 空间。

面试追问

  • 如果允许放置 k 枚炸弹，敌人只能计数一次，状态如何设计？
  • 如果墙会被第一枚炸弹摧毁，第二枚炸弹的可见范围发生变化，应如何建模？
  • 能否把额外空间从 O(n) 改为 O(min(m,n))？可以按较短维度选择遍历方向。
  • 若网格以流式行输入，当前方案需要保留哪些状态？

常见错误

  • 遇到敌人而停止扫描；真正会阻断传播的只有墙。
  • 在每个格子都重新统计整段，退化为高复杂度。
  • 没有在墙后重置行缓存或列缓存。
  • 对 'E' 或 'W' 也更新答案。
  • 把横向与纵向交点重复减一；交点是空地，不需要去重。

Java

class Solution {
    public int maxKilledEnemies(char[][] grid) {
        if (grid == null || grid.length == 0 || grid[0].length == 0) {
            return 0;
        }

        int rows = grid.length;
        int cols = grid[0].length;
        int[] colHits = new int[cols];
        int best = 0;
        int rowHits = 0;

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (j == 0 || grid[i][j - 1] == 'W') {
                    rowHits = 0;
                    for (int k = j; k < cols && grid[i][k] != 'W'; k++) {
                        if (grid[i][k] == 'E') rowHits++;
                    }
                }

                if (i == 0 || grid[i - 1][j] == 'W') {
                    colHits[j] = 0;
                    for (int k = i; k < rows && grid[k][j] != 'W'; k++) {
                        if (grid[k][j] == 'E') colHits[j]++;
                    }
                }

                if (grid[i][j] == '0') {
                    best = Math.max(best, rowHits + colHits[j]);
                }
            }
        }
        return best;
    }
}

from typing import List


class Solution:
    def maxKilledEnemies(self, grid: List[List[str]]) -> int:
        if not grid or not grid[0]:
            return 0

        rows, cols = len(grid), len(grid[0])
        col_hits = [0] * cols
        row_hits = 0
        best = 0

        for i in range(rows):
            for j in range(cols):
                if j == 0 or grid[i][j - 1] == "W":
                    row_hits = 0
                    k = j
                    while k < cols and grid[i][k] != "W":
                        row_hits += grid[i][k] == "E"
                        k += 1

                if i == 0 or grid[i - 1][j] == "W":
                    col_hits[j] = 0
                    k = i
                    while k < rows and grid[k][j] != "W":
                        col_hits[j] += grid[k][j] == "E"
                        k += 1

                if grid[i][j] == "0":
                    best = max(best, row_hits + col_hits[j])

        return best
