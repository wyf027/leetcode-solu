删除元素后最大固定点数目

删除后元素左移并重新编号。目标是让尽可能多的保留元素满足 nums[i] = i。

多个固定点的值在原数组顺序中必须严格递增，因此可转化为最长严格递增子序列。

题意速览

删除任意元素后，剩余元素下标从 0 重新分配；求最大固定点数。

约束：1 ≤ nums.length ≤ 10⁵，0 ≤ nums[i] ≤ 10⁵。

交互分步可视化：LIS 尾值

预置 nums = [1, 0, 1, 2]。每一步用二分更新 tails；长度是当前最优固定点数。可用 ←/→ 步进。

    题解：耐心排序的严格 LIS

    tails[k] 表示长度 k + 1 的严格递增子序列能达到的最小结尾。扫描 x 时二分第一个不小于 x 的槽位并替换；若不存在则追加，最终长度就是答案。

    完整过程

    1. 从左到右读取 x。
    2. 二分找到 tails 中第一个 ≥ x 的位置。
    3. 替换该位置或追加 x，持续保持更小的末尾值。

    边界与复杂度

    重复值不构成严格递增链，故必须 lower_bound。时间 O(n log n)，空间 O(n)；O(n²) DP 不适合 10⁵。

    替代方案、面试追问、常见错误

    值域较小时可用 Fenwick 树；恢复保留方案时记录前驱。常见错误：使用 upper_bound、求非降 LIS、只统计原数组已有固定点。
