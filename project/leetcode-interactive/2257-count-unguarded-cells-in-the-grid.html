没有被保卫的格子数

Count Unguarded Cells in the Grid

墙会截断视线，警卫也会。哪些空格最终仍处于视野之外？

01 / 理解任务

在网格中寻找未被保卫的空格

给定 m × n 的网格，行、列下标都从 0 开始。guards[i] = [rowᵢ, colᵢ] 是警卫的位置；walls[j] = [rowⱼ, colⱼ] 是墙的位置。

每名警卫能看见上、右、下、左四个方向的所有格子，直到碰到墙、另一名警卫或网格边界。只要有一名警卫看见某个空格，该格就被保卫。

返回值：没有被任何警卫看见的空格数量。警卫和墙占用的格子不计入答案。

参数与约束

  • 1 ≤ m, n ≤ 10⁵
  • 2 ≤ m × n ≤ 10⁵
  • 1 ≤ guards.length, walls.length ≤ 5 × 10⁴
  • 2 ≤ guards.length + walls.length ≤ m × n
  • guards[i].length = walls[j].length = 2
  • 0 ≤ rowᵢ, rowⱼ < m
  • 0 ≤ colᵢ, colⱼ < n
  • 两数组里的全部位置互不相同。

官方示例

示例 1 · 多条视线交汇

m = 4, n = 6
guards = [[0,0],[1,1],[2,3]]
walls = [[0,1],[2,2],[1,4]]
输出：7

所有警卫的视野合并后，剩余 7 个空格无人保卫。

示例 2 · 四面被墙围住

m = 3, n = 3
guards = [[1,1]]
walls = [[0,1],[1,0],[2,1],[1,2]]
输出：4

中心警卫无法越过四面墙，四个角落均不被保卫。

04 / 独立题解

准备好再揭晓

核心思路、正确性推导与四语言实现。

题解：沿警卫的四条视线标记

核心洞察

只有墙与警卫会挡住视线。把格子分为四种状态：0 = 未标记空格、1 = 警卫、2 = 墙、3 = 已被保卫的空格。状态 3 仍然允许视线通过；把它误当成障碍会漏掉更远的格子。

完整过程

  1. 创建全 0 的网格，先放入所有警卫和墙。
  2. 依次取每名警卫，从其相邻格开始，按上、右、下、左推进。
  3. 越界，或遇到状态 1、2，立即结束当前方向。
  4. 其他格子标为 3，并沿当前方向继续，包括本来已经是 3 的格子。
  5. 全部视线处理完后，统计仍为 0 的格子数。

例如示例 1 中，警卫 [0,0] 向右立刻被 [0,1] 的墙挡住，向下能照到 [1,0]、[2,0]、[3,0]。其余警卫照常处理，重叠区域只需维持一个“已保卫”状态。最后剩余的 0 有 7 个。

为什么正确

循环不变量：在一条视线推进过程中，已经经过的格子都是该警卫与第一个障碍之间的空格，并且都被标为 3。起点是相邻格，推进只沿同一个坐标轴，遇障碍前不会停，因此不变量持续成立。

标记不会多：任何标成 3 的格子都来自某名警卫的一条无遮挡直线，符合被保卫的定义。标记不会少：任何被保卫的空格，至少位于一名警卫的无遮挡方向上；处理该警卫该方向时，循环一定走到它。

警卫和墙始终分别保留状态 1、2。因此，结束后状态 0 恰好对应未被保卫且未被占用的格子，计数就是答案。

复杂度：为什么不是警卫数乘整张网格

时间 O(mn)，额外空间 O(mn)。同一行内，墙或警卫之间的连续空段至多从左、右各被扫描一次；同一列同理。每个空格总共至多被四个方向的视线访问。每条射线另有常数次终止检查，共 O(guards.length)，而警卫数不超过 mn。初始化与最终统计也都是 O(mn)。

边界与常见错误

  • 单行、单列：越界检查自然处理无可走方向。
  • 全被占用或所有空格被保卫：结果均为 0。
  • 先标完全部障碍再发射视线，否则可能穿过尚未放入的警卫。
  • 已保卫的格子不是墙，不能用“非 0 就停”作为条件。
  • 不能简单累加射线长度来计数，交叉与重叠会重复统计。
  • 不能从警卫自身开始扫描；它会被误认成挡住视线的警卫。
  • 行界用 m，列界用 n；题目限制的是面积最多 10⁵，并非允许 10⁵ × 10⁵ 的网格。

替代方案

四遍扫描：每行从左到右、从右到左，每列从上到下、从下到上。用一个布尔变量表示当前方向是否有警卫的有效视线：遇警卫设为真，遇墙设为假，空格在变量为真时标记。每一行、每一列开头要重置该变量。时间与空间仍为 O(mn)，遍历次数更固定，但四遍循环稍长。

面试追问

  • 警卫为什么也阻挡？这是题目给定的可见性规则，也是限制每个空段被重复扫描次数的关键。
  • 能不用完整网格吗？如果面积极大且障碍稀疏，可讨论按行列排序、区间合并及交叉覆盖计数；本题面积上限仅 10⁵，直接网格更简单。
  • 允许在线增加墙怎么办？旧视野可能失效，单个布尔标记无法追踪来源；少量更新可重新计算，大量更新需要行列分段和覆盖来源管理。

Java

class Solution {
    public int countUnguarded(int m, int n, int[][] guards, int[][] walls) {
        int[][] grid = new int[m][n];
        for (int[] g : guards) grid[g[0]][g[1]] = 1;
        for (int[] w : walls) grid[w[0]][w[1]] = 2;
        int[][] directions = {{-1, 0}, {0, 1}, {1, 0}, {0, -1}};
        for (int[] g : guards) {
            for (int[] d : directions) {
                int r = g[0] + d[0], c = g[1] + d[1];
                while (r >= 0 && r < m && c >= 0 && c < n
                        && grid[r][c] != 1 && grid[r][c] != 2) {
                    grid[r][c] = 3;
                    r += d[0];
                    c += d[1];
                }
            }
        }
        int answer = 0;
        for (int[] row : grid) {
            for (int cell : row) if (cell == 0) answer++;
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number} m
 * @param {number} n
 * @param {number[][]} guards
 * @param {number[][]} walls
 * @return {number}
 */
var countUnguarded = function(m, n, guards, walls) {
    const grid = Array.from({ length: m }, () => Array(n).fill(0));
    for (const [r, c] of guards) grid[r][c] = 1;
    for (const [r, c] of walls) grid[r][c] = 2;
    const directions = [[-1, 0], [0, 1], [1, 0], [0, -1]];
    for (const [gr, gc] of guards) {
        for (const [dr, dc] of directions) {
            let r = gr + dr, c = gc + dc;
            while (r >= 0 && r < m && c >= 0 && c < n
                && grid[r][c] !== 1 && grid[r][c] !== 2) {
                grid[r][c] = 3;
                r += dr;
                c += dc;
            }
        }
    }
    let answer = 0;
    for (const row of grid) {
        for (const cell of row) if (cell === 0) answer++;
    }
    return answer;
};

from typing import List

class Solution:
    def countUnguarded(self, m: int, n: int,
                      guards: List[List[int]], walls: List[List[int]]) -> int:
        grid = [[0] * n for _ in range(m)]
        for r, c in guards:
            grid[r][c] = 1
        for r, c in walls:
            grid[r][c] = 2
        directions = [(-1, 0), (0, 1), (1, 0), (0, -1)]
        for gr, gc in guards:
            for dr, dc in directions:
                r, c = gr + dr, gc + dc
                while (0 <= r < m and 0 <= c < n
                       and grid[r][c] not in (1, 2)):
                    grid[r][c] = 3
                    r += dr
                    c += dc
        return sum(cell == 0 for row in grid for cell in row)

                    c += d[1];
                }
            }

        }
