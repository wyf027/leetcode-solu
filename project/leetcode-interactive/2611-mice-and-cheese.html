Problem 2611

老鼠和奶酪

Mice and Cheese

角色
2 只老鼠
物品
n 块奶酪
硬约束
第一只恰好吃 k 块
Brief

题目

有两只老鼠和 n 块不同类型的奶酪，每块奶酪必须且只能由其中一只老鼠吃掉。

第 i 块奶酪由第一只老鼠吃可得 reward1[i] 分，由第二只老鼠吃可得 reward2[i] 分。

给定正整数数组 reward1、reward2 和非负整数 k，求第一只老鼠恰好吃掉 k 块奶酪时，两只老鼠能获得的最大总分。

Contract

函数与约束

miceAndCheese(reward1, reward2, k) → integer

reward1: integer[]
reward2: integer[]
k:       integer
  • 1 ≤ n = reward1.length = reward2.length ≤ 10⁵
  • 1 ≤ reward1[i], reward2[i] ≤ 1000
  • 0 ≤ k ≤ n

示例 1

输入：reward1 = [1,1,3,4], reward2 = [4,4,1,1], k = 2
输出：15
解释：第一只老鼠吃下标 2、3 的奶酪，第二只吃下标 0、1。
总分 = 3 + 4 + 4 + 4 = 15。

示例 2

输入：reward1 = [1,1], reward2 = [1,1], k = 2
输出：2
解释：第一只老鼠吃下标 0、1 的奶酪，第二只不吃奶酪。
总分 = 1 + 1 = 2。
Ready to reveal?

先想一想，再打开完整题解

哪 k 块奶酪最值得交给第一只老鼠？

Solution

先全给第二只，再做 k 次最赚的交换

核心洞察

先假设所有奶酪都由第二只老鼠吃，总分为 Σ reward2[i]。把第 i 块改给第一只老鼠，总分变化量是：

gain[i] = reward1[i] - reward2[i]

第一只必须恰好吃 k 块，因此只需选出最大的 k 个变化量，加回基线总分。变化量即使为负也必须选，才能满足“恰好”。

完整过程

  1. 累加 reward2，得到第二只老鼠吃全部奶酪的基线。
  2. 对每块奶酪计算 reward1[i] - reward2[i]。
  3. 把变化量从大到小排序。
  4. 把前 k 个变化量加入基线并返回。

建立基线

先让第二只老鼠吃掉全部奶酪，得到 10 分。

正确性证明

基线：第二只老鼠吃全部奶酪时，总分为 B = Σ reward2[i]。

等价转换：若把集合 S 中的奶酪改给第一只老鼠，总分恰为 B + Σ(i∈S)(reward1[i]-reward2[i])。题目要求 |S| = k。

交换论证：若某个候选集合包含较小变化量 a、却未包含更大变化量 b，用 b 替换 a 不会降低总分。反复交换后，集合就是最大的 k 个变化量。

结论：算法选取最大的 k 个变化量，所以在满足第一只老鼠恰好吃 k 块的所有方案中总分最大。

边界与复杂度

  • k = 0：不取变化量，所有奶酪归第二只。
  • k = n：取全部变化量，所有奶酪归第一只。
  • 变化量全为负：仍取最大的 k 个，满足“恰好”。
  • 变化量相同：任选对应奶酪都得到同一总分。
  • n = 1：两种 k 值均由同一公式覆盖。
时间：O(n log n)
额外空间：O(n)

四语言完整代码

import java.util.Arrays;

class Solution {
    public int miceAndCheese(int[] reward1, int[] reward2, int k) {
        int n = reward1.length;
        int[] gain = new int[n];
        int answer = 0;

        for (int i = 0; i < n; i++) {
            answer += reward2[i];
            gain[i] = reward1[i] - reward2[i];
        }

        Arrays.sort(gain);
        for (int i = n - k; i < n; i++) {
            answer += gain[i];
        }
        return answer;
    }
}
/**
 * @param {number[]} reward1
 * @param {number[]} reward2
 * @param {number} k
 * @return {number}
 */
var miceAndCheese = function(reward1, reward2, k) {
    const gain = reward1.map((score, i) => score - reward2[i]);
    gain.sort((a, b) => b - a);

    let answer = reward2.reduce((sum, score) => sum + score, 0);
    for (let i = 0; i < k; i++) answer += gain[i];
    return answer;
};
from typing import List


class Solution:
    def miceAndCheese(
        self, reward1: List[int], reward2: List[int], k: int
    ) -> int:
        gains = sorted(
            (first - second for first, second in zip(reward1, reward2)),
            reverse=True,
        )
        return sum(reward2) + sum(gains[:k])

#include <numeric>
#include <vector>
using namespace std;

class Solution {
public:
    int miceAndCheese(vector<int>& reward1,
                      vector<int>& reward2,
                      int k) {
        int n = reward1.size();
        vector<int> gain(n);
        for (int i = 0; i < n; ++i) {
            gain[i] = reward1[i] - reward2[i];
        }

        sort(gain.rbegin(), gain.rend());
        return accumulate(reward2.begin(), reward2.end(), 0)
             + accumulate(gain.begin(), gain.begin() + k, 0);
    }

替代方案

大小为 k 的最小堆：扫描所有变化量，只保留最大的 k 个，时间 O(n log k)、空间 O(k)。当 k 远小于 n 时更省。

快速选择：可把平均时间降到 O(n)，但实现和最坏情况更复杂。

在 n ≤ 10⁵ 下，排序版本最直接，复杂度也完全足够。

常见错误

  • 按 reward1[i] 本身排序，忽略放弃 reward2[i] 的机会成本。
  • 只选择正变化量，导致第一只老鼠不足 k 块。
  • 先各自取最大值，造成同一块奶酪被分配两次。
  • JavaScript 用默认字典序排序，而不是传入数值比较器。

面试追问

如果要求至多 k 块？

只取前 k 个正变化量，不再强制选择负数。

如何恢复具体分配？

排序时保存原下标，前 k 个下标归第一只。

数据流无法全部保存？

用大小为 k 的最小堆在线维护候选。
