3952. 下标覆盖处的最大总和

每个 s[i]='1' 的 token 可保持在 i，或（i>0 时）只向左移动一次。最终有 token 的下标被覆盖；求覆盖下标 nums 值之和最大值。

题意与洞察

决定第 i 个 token 是否左移后，位置 i−1 是否覆盖就完全确定：前一个 token 留在 i−1，或当前 token 左移至 i−1，二者任一成立即可。

因此从左向右 DP，只需保留“上一 token 是否留下”的两种状态。

示例

nums=[9,2,6,1], s="0101"。令 1→0、3→2，覆盖 0、2，答案 15。

nums=[5,1,4], s="001"，选择不移动，答案 4。

题解与代码
默认隐藏，支持键盘切换语言。
转移：dp[stay] 表示处理到当前 token 后、当前 token 是否留在当前位置。处理 token i 时加入 nums[i−1]，当且仅当前一个 token 留下或当前 token 左移。最后若最后 token 留下，再加入 nums[n−1]。
复杂度：O(n) 时间、O(1) 额外空间。
常见错误：把每个 token 当成可连续移动，或把两个 token 覆盖同一格时重复计分。
