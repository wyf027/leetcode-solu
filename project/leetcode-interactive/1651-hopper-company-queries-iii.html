Hopper Company Queries III

Hopper 公司查询 III

把一年里的行程记录整理成十个连续三个月的运营视窗。你需要让缺失月份仍然出现，并保持数值口径准确。

Problem

题意转述

官方提交形态：MySQL 查询

数据库包含司机、行程请求与已接受行程三张表。请统计 2020 年中每个连续三个月区间的行程总距离与总时长，再分别除以 3，得到两项月均值。

区间依次为 1—3 月、2—4 月，直到 10—12 月。结果中的 month 表示区间的起始月份，按升序输出；两项平均值四舍五入到小数点后两位。未发生已接受行程的月份按 0 参与计算。

重要口径：只有同时存在于 Rides 与 AcceptedRides 的行程才有距离、时长；Drivers 是同系列题目的共享表，本题结果不依赖司机入职日期。

约束与数据保证

  • Drivers.driver_id、Rides.ride_id、AcceptedRides.ride_id 分别唯一。
  • 每条已接受行程都能在 Rides 中找到对应请求；请求可能没有被接受。
  • 只汇总请求日期位于 2020 年的已接受行程；最终固定输出起始月 1..10。
  • 空月份必须补 0；计算时先聚合每月总量，再对连续三个月求和并除以 3。
  • 官方元数据未给出额外行数或数值上限，因此不虚构数值范围。

Solution

题解：先补齐月份，再滑动聚合

主解 · MySQL 8+

01 · 月份是骨架

先生成 1 到 12 月，避免没有行程的月份从结果中消失。这也让窗口的“相邻三行”真正等价于相邻三个月。

02 · 只聚合已接单

月份骨架左连请求，再左连已接单信息。空值按 0 汇总，每个月得到一个距离总和和时长总和。

03 · 向后看三行

窗口从当前月覆盖到后两个月。对月总量做三行平均，最终只保留前 10 个起始月。

完整过程

  1. 递归生成月份。 从 1 开始递增到 12，得到稳定、无缺口的月份序列。
  2. 按请求日期连接。 只连接 2020 年且月份相同的请求，再用 ride_id 连接已接受行程。
  3. 按月求和。 对距离和时长分别使用 SUM(IFNULL(..., 0))，空月份也得到 0。
  4. 计算三月窗口。 ROWS BETWEEN CURRENT ROW AND 2 FOLLOWING 覆盖当前与后两月，AVG 等价于三月总和除以 3。
  5. 截取合法起点。 只有 1 到 10 月拥有完整的三个月窗口，升序输出前 10 行并四舍五入。

正确性说明

引理 1：月份 CTE 恰好包含 2020 年的十二个月，所以每月都对应且只对应一行月汇总，即使没有行程。

引理 2：月汇总只累加其请求发生于该月且已被接受的行程，因此两项总量与题意完全一致。

引理 3：按月份升序后，从任一 m ∈ [1,10] 开始的当前行及后两行，恰好代表月份 m,m+1,m+2。

结论：每个输出行都是指定三个月内两项总量除以 3 的结果，且覆盖全部十个合法窗口，因此查询正确。

边界与复杂度

  • 整年无已接单：十行都为 0.00。
  • 请求未接单：连接后度量为空，贡献为 0。
  • 2019 或 2021 请求：年份条件排除。
  • 同月多单：先全部汇总，不会遗漏。
  • 12 月数据只会进入起点为 10 的最后窗口。

时间：O(R + A) 级别扫描与连接，具体取决于索引和执行计划。
额外空间：月份与月汇总至多 12 行，可视为 O(1)；数据库连接/排序工作区另计。

WITH RECURSIVE Months AS (
    SELECT 1 AS month
    UNION ALL
    SELECT month + 1
    FROM Months
    WHERE month < 12
),
MonthlyRide AS (
    SELECT
        m.month,
        SUM(IFNULL(a.ride_distance, 0)) AS total_distance,
        SUM(IFNULL(a.ride_duration, 0)) AS total_duration
    FROM Months AS m
    LEFT JOIN Rides AS r
      ON YEAR(r.requested_at) = 2020
     AND MONTH(r.requested_at) = m.month
    LEFT JOIN AcceptedRides AS a
      ON a.ride_id = r.ride_id
    GROUP BY m.month
),
Rolling AS (
    SELECT
        month,
        ROUND(AVG(total_distance) OVER (
            ORDER BY month
            ROWS BETWEEN CURRENT ROW AND 2 FOLLOWING
        ), 2) AS average_ride_distance,
        ROUND(AVG(total_duration) OVER (
            ORDER BY month
            ROWS BETWEEN CURRENT ROW AND 2 FOLLOWING
        ), 2) AS average_ride_duration
    FROM MonthlyRide
)
SELECT month, average_ride_distance, average_ride_duration
FROM Rolling
WHERE month <= 10
ORDER BY month;

本题官方提交形态是 SQL，且官方元数据未提供常规函数签名。下面四份代码以三张内存表为完整参数，复现相同语义，适合本地理解与对照，不是 LeetCode 本题的官方可提交语言。

import java.time.LocalDate;
import java.util.*;

public class HopperQueriesIII {
    record Driver(int driverId, LocalDate joinDate) {}
    record Ride(int rideId, int userId, LocalDate requestedAt) {}
    record Accepted(int rideId, int driverId, int distance, int duration) {}
    record Result(int month, double averageDistance, double averageDuration) {}

    public static List<Result> solve(
            List<Driver> drivers,
            List<Ride> rides,
            List<Accepted> acceptedRides) {
        Map<Integer, Accepted> acceptedByRide = new HashMap<>();
        for (Accepted accepted : acceptedRides) {
            acceptedByRide.put(accepted.rideId(), accepted);
        }

        long[] distance = new long[12];
        long[] duration = new long[12];
        for (Ride ride : rides) {
            if (ride.requestedAt().getYear() != 2020) continue;
            Accepted accepted = acceptedByRide.get(ride.rideId());
            if (accepted == null) continue;
            int index = ride.requestedAt().getMonthValue() - 1;
            distance[index] += accepted.distance();
            duration[index] += accepted.duration();
        }

        List<Result> answer = new ArrayList<>();
        for (int start = 0; start < 10; start++) {
            long d = 0, t = 0;
            for (int i = start; i < start + 3; i++) {
                d += distance[i];
                t += duration[i];
            }
            answer.add(new Result(start + 1, round2(d / 3.0), round2(t / 3.0)));
        }
        return answer;
    }

    private static double round2(double value) {
        return Math.round(value * 100.0) / 100.0;
    }
}
/**
 * @param {{driver_id:number, join_date:string}[]} drivers
 * @param {{ride_id:number, user_id:number, requested_at:string}[]} rides
 * @param {{ride_id:number, driver_id:number,
 *   ride_distance:number, ride_duration:number}[]} acceptedRides
 * @returns {{month:number, average_ride_distance:number,
 *   average_ride_duration:number}[]}
 */
function hopperCompanyQueriesIII(drivers, rides, acceptedRides) {
  const acceptedByRide = new Map(
    acceptedRides.map((ride) => [ride.ride_id, ride])
  );
  const distance = Array(12).fill(0);
  const duration = Array(12).fill(0);

  for (const ride of rides) {
    const [year, month] = ride.requested_at.split("-").map(Number);
    const accepted = acceptedByRide.get(ride.ride_id);
    if (year !== 2020 || !accepted) continue;
    distance[month - 1] += accepted.ride_distance;
    duration[month - 1] += accepted.ride_duration;
  }

  const round2 = (value) => Math.round((value + Number.EPSILON) * 100) / 100;
  return Array.from({ length: 10 }, (_, start) => {
    const d = distance.slice(start, start + 3).reduce((a, b) => a + b, 0);
    const t = duration.slice(start, start + 3).reduce((a, b) => a + b, 0);
    return {
      month: start + 1,
      average_ride_distance: round2(d / 3),
      average_ride_duration: round2(t / 3),
    };
  });
}

vector<Result> hopperCompanyQueriesIII(
    const vector<Driver>& drivers,
    const vector<Ride>& rides,
    const vector<AcceptedRide>& acceptedRides) {
    unordered_map<int, AcceptedRide> acceptedByRide;
    for (const auto& row : acceptedRides) acceptedByRide[row.rideId] = row;

    array<long long, 12> distance{};
    array<long long, 12> duration{};
    for (const auto& ride : rides) {
        int year = stoi(ride.requestedAt.substr(0, 4));
        if (year != 2020 || !acceptedByRide.count(ride.rideId)) continue;
        int month = stoi(ride.requestedAt.substr(5, 2));
        const auto& accepted = acceptedByRide.at(ride.rideId);
        distance[month - 1] += accepted.distance;
        duration[month - 1] += accepted.duration;
    }

    auto round2 = [](double value) { return round(value * 100.0) / 100.0; };
    vector<Result> answer;
    for (int start = 0; start < 10; ++start) {
        long long d = 0, t = 0;

            d += distance[i];
            t += duration[i];

        answer.push_back({start + 1, round2(d / 3.0), round2(t / 3.0)});

替代方案

  • 条件聚合：生成 1..10 后，用日期范围条件分别求三个月总和。直观但可能重复扫描。
  • 自连接三份月汇总：把起始月分别连接到 m、m+1、m+2。兼容不支持窗口函数的数据库。
  • 前缀和：月汇总后用累计窗口作差。对固定 12 个月收益有限，但可推广到任意窗口长度。

常见错误

漏掉空月份

直接从 Rides 分组会让零数据月份消失，窗口行数不再对应自然月份。

窗口方向写反

输出 month 是起始月，应取当前行到后两行，不是前两行到当前行。

除以行程数

题目定义是三个月总量除以固定值 3，不是求每次行程的平均距离。

把未接单请求算入

未接单请求没有距离和时长，对两项总量贡献为 0。

只生成十个月

必须先有 12 个月，才能让起始月 10 的窗口覆盖 10—12 月。

过早四舍五入

先完成三月聚合与除法，最后再保留两位小数。
