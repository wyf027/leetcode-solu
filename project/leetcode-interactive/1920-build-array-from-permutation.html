基于排列构建数组

Build Array from Permutation 简单

把一个位置上的数字当作另一个位置的地址。先读清规则，再用下方实验台观察这两次访问。

官方题目 ↗

01 / 题目

给定从 0 开始的排列 nums，创建同长度数组 ans。对每个合法下标 i，要求 ans[i] = nums[nums[i]]，最终返回 ans。排列的含义是：0 到 n−1 每个整数恰好出现一次；数组下标也从 0 开始。

官方示例 1

输入：nums = [0,2,1,5,3,4]
输出：[0,1,2,4,5,3]

例如 i = 3 时，nums[3] = 5，而 nums[5] = 4，所以 ans[3] = 4。

官方示例 2

输入：nums = [5,0,1,2,3,4]
输出：[4,5,0,1,2,3]

例如 i = 0 时，nums[0] = 5，而 nums[5] = 4，所以 ans[0] = 4。

约束

  • 1 ≤ nums.length ≤ 1000
  • 0 ≤ nums[i] < nums.length
  • nums 中所有元素互不相同。

进阶：能否只使用 O(1) 额外空间？

04 / 独立题解

准备好后再展开思路与四语言代码。

核心洞察：值也能充当地址

先取 j = nums[i]，再取 nums[j]。第二次取到的值属于 ans[i]。新建结果数组可以保证所有读取始终来自原始 nums，不会被提前覆盖。

完整过程

  1. 创建长度为 n 的结果数组。
  2. 从 i = 0 遍历到 n−1，读取 j = nums[i]，赋值 ans[i] = nums[j]。
  3. 返回 ans。
nums = [0,2,1,5,3,4]
i       0  1  2  3  4  5
j       0  2  1  5  3  4
nums[j] 0  1  2  4  5  3

正确性

循环开始处理 i 时，所有 k < i 都满足 ans[k] = 原始 nums[原始 nums[k]]，且 nums 未改变。初始时没有已处理位置，该性质自然成立。当前赋值读取原始 nums 两次，恰好满足位置 i 的要求，且不影响此前结果。遍历结束时所有位置均正确，故返回值符合定义。约束保证 j 是合法下标。

边界与复杂度

n = 1 时输入只能为 [0]，返回 [0]。固定点 nums[i] = i 保持不变；长度为 2 的交换环走两步后回到原位置。每个元素进行常数次操作，时间 O(n)。返回数组占 O(n) 空间；若不计输出，辅助空间为 O(1)。这种写法仍分配了新数组，不能直接称为进阶的原地算法。

替代方案：整数编码，原地 O(1)

利用原始值小于 n，以低位保存旧值、高位保存新值。第一趟令 nums[i] += n * (nums[nums[i] % n] % n)；第二趟令 nums[i] = floor(nums[i] / n)。任何时候取模 n 都能恢复旧值，因此之前的编码不会污染后续读取。

时间 O(n)，额外空间 O(1)，但会修改输入。编码值最多 n²−1，在本题 n ≤ 1000 时适合 32 位整数；更大约束需重新考虑溢出。n = 1 时编码和解码仍然有效。

Java

class Solution {
    public int[] buildArray(int[] nums) {
        int[] ans = new int[nums.length];
        for (int i = 0; i < nums.length; i++) {
            ans[i] = nums[nums[i]];
        }
        return ans;
    }
}

Python 3

from typing import List

class Solution:
    def buildArray(self, nums: List[int]) -> List[int]:
        return [nums[value] for value in nums]

C++

#include <vector>
using std::vector;

class Solution {
public:
    vector<int> buildArray(vector<int>& nums) {
        vector<int> ans(nums.size());
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            ans[i] = nums[nums[i]];
        }
        return ans;
    }
};

常见错误

  • 直接写 nums[i] = nums[nums[i]]：覆盖了之后仍需读取的旧值。
  • 写成 nums[i] + nums[i]：本题是两次索引，不是数值相加。
  • 把 i、nums[i]、nums[nums[i]] 混淆：它们依次是起点、第二个地址、最终值。
  • 原地编码时忘记取模，可能用编码后的大数访问数组而越界。

面试追问

元素可以重复吗？只要仍是合法下标，双重索引算法依然正确；排列性质主要保证输入形式和结果也为排列。

为什么结果仍是排列？排列代表一个双射，双射与自身复合仍为双射。

若要连续跳 k 次？小 k 可以直接重复访问；大量跳跃查询可考虑倍增，或利用排列的环结构按环长取模。
