1288.
删除被覆盖区间

有些区间只是另一个区间的“影子”。先读懂覆盖关系，再亲手推进扫描过程；算法答案被收在页面底部，不会在首屏提前揭晓。

参数：integer[][] intervals 返回：integer 非付费题

Problem

题意与规则

给定区间数组 intervals，其中 intervals[i] = [lᵢ, rᵢ] 表示半开区间 [lᵢ, rᵢ)。删除所有被列表中另一个区间覆盖的区间，返回最终剩余的区间数量。

当且仅当 c ≤ a 且 b ≤ d 时，区间 [a,b) 被区间 [c,d) 覆盖。

示例 1 
输入：intervals = [[1,4],[3,6],[2,8]]
输出：2
解释：[3,6] 被 [2,8] 覆盖，因此删除。
示例 2 
输入：intervals = [[1,4],[2,3]]
输出：1
解释：[2,3] 被 [1,4] 覆盖。

Constraints

约束

  • 1 ≤ intervals.length ≤ 1000
  • intervals[i].length == 2
  • 0 ≤ lᵢ < rᵢ ≤ 10⁵
  • 所有给定区间互不相同。

准备好核对思路了吗？

题解包含排序策略、证明、四种语言实现与面试追问。

核心洞察

将区间按左端点升序排列；左端点相同时，按右端点降序排列。这样，可能覆盖当前区间的候选一定已经出现。扫描时只需维护已见区间的最大右端点 maxEnd。

若当前右端点 end ≤ maxEnd，当前区间被此前某个区间覆盖；否则它无法被此前区间覆盖，应保留并更新 maxEnd。

完整过程

  1. 按 start ↑, end ↓ 排序。
  2. 令 maxEnd = -1、remaining = 0。
  3. 从左到右扫描；若 end > maxEnd，计数加一并更新右界线。
  4. 否则当前区间已经落在右界线内，不计入答案。

正确性证明

引理：排序后，对任意当前区间 [a,b)，所有此前区间的左端点都不大于 a；若左端点相同，更长的区间也必在前面。

判定：若 b ≤ maxEnd，产生 maxEnd 的此前区间同时满足左端点不大于 a、右端点不小于 b，故覆盖当前区间。若 b > maxEnd，此前没有区间的右端点能覆盖它；而此后区间左端点不更小，也无法覆盖它。因此计数恰为所有未被覆盖区间数。

复杂度与边界

  • 时间：排序 O(n log n)，扫描 O(n)。
  • 额外空间：忽略排序实现所需空间时为 O(1)。
  • 单个区间必然保留；区间互不相同。
  • 相同左端点必须让更大的右端点在前，否则短区间会被错误计数。
  • 右端点相同、左端点更大的区间应判定为被覆盖。

替代方案

可以枚举每一对区间，直接检查某区间是否被任何其他区间覆盖，时间复杂度为 O(n²)、额外空间为 O(1)。它容易写对，也适合作为小规模校验思路，但没有利用排序带来的单调性。

面试追问与常见错误

  • 追问：若要返回剩余区间本身，只需在更新 maxEnd 时收集当前区间。
  • 追问：若输入不可修改，可先复制数组再排序。
  • 错误：同起点按右端点升序，导致短区间先被保留。
  • 错误：只和紧邻前一个区间比较，而不是维护历史最大右端点。
  • 错误：使用 end < maxEnd，漏掉右端点相等的覆盖关系。

import java.util.Arrays;

class Solution {
    public int removeCoveredIntervals(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> {
            if (a[0] != b[0]) {
                return Integer.compare(a[0], b[0]);
            }
            return Integer.compare(b[1], a[1]);
        });

        int maxEnd = -1;
        int remaining = 0;
        for (int[] interval : intervals) {
            if (interval[1] > maxEnd) {
                remaining++;
                maxEnd = interval[1];
            }
        }
        return remaining;
    }
}

class Solution {
public:
    int removeCoveredIntervals(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 if (a[0] != b[0]) return a[0] < b[0];
                 return a[1] > b[1];
             });

        int maxEnd = -1;
        int remaining = 0;
        for (const auto& interval : intervals) {
            if (interval[1] > maxEnd) {
                ++remaining;
                maxEnd = interval[1];
            }
        }
        return remaining;
    }
