检查字符串是否为数组前缀

Check If String Is a Prefix of Array

从第一个单词开始，允许在哪里停下？先读题、做出判断，再动手探索。

01 / 题目

给定字符串 s 和字符串数组 words，判断是否存在正整数 k，满足 1 ≤ k ≤ words.length，使数组前 k 个字符串依原顺序拼接后恰好等于 s。存在则返回 true，否则返回 false。

必须从数组第一项开始，不能跳过单词，也不能只使用最后一个单词的一部分。

官方示例 1

输入：s = "iloveleetcode",
words = ["i","love","leetcode","apples"]
输出：true

前三个单词依次连接，恰好得到 s。

官方示例 2

输入：s = "iloveleetcode",
words = ["apples","i","love","leetcode"]
输出：false

必须从 apples 开始；任何合法数组前缀都无法拼成 s。

约束

  • 1 ≤ words.length ≤ 100
  • 1 ≤ words[i].length ≤ 20
  • 1 ≤ s.length ≤ 1000
  • words[i] 和 s 仅包含小写英文字母。

参数：isPrefixString(s: string, words: string[]) → boolean

04 / 想好了吗？

展开后查看思路、证明与四种语言实现。

题解 / 顺序匹配，在单词边界判定

核心洞察

只把 s 看作所有单词连接后的普通字符串前缀是不够的：s 必须结束在某个完整单词的末尾。维护指针 p，表示已经匹配的 s 字符数；逐字符比较，只有完整处理完一个单词后，才允许返回 true。

完整过程

  1. 令 p = 0，依次读取 words 中每一个单词。
  2. 遍历当前单词的字符。若 p 已到 s 末尾，说明当前单词还没结束，返回 false；若字符不同，也返回 false。
  3. 当前字符相等，p 加一，继续比较。
  4. 当前单词全部结束后，若 p 等于 s.length，返回 true。
  5. 所有单词结束后仍没返回，表示 s 还有字符未匹配，返回 false。

示例 1：处理 i 后 p = 1；处理 love 后 p = 5；处理 leetcode 后 p = 13，恰好到 s 末尾，返回 true，不再读取 apples。对于 s = "ilove"、words = ["i","lovely"]，匹配到 e 后 s 耗尽，但 lovely 还剩 ly，因此返回 false。

正确性

不变式：每次比较前，已经消费的 words 字符恰好等于 s 的前 p 个字符。起初两者都是空串；比较相等后同时前进一个字符，不变式保持。

成功：只在完整单词处理结束时检查 p = s.length，此时不变式保证前 k 个完整单词连接恰好等于 s；由于至少处理一个非空单词，k 为正。

失败：字符不同后，继续追加无法改写已出现的差异；s 在词中耗尽时，当前以及后续前缀都过长，之前的词边界又都过短；数组耗尽时 p 仍小于 s.length，说明没有足够字符。三种失败都排除了合法 k，因此算法完整且正确。

边界与复杂度

覆盖第一个单词即相等、最后一个单词才相等、词中截断、首字符不同和数组总长度不足。题目不允许空 s、空数组或空单词；若扩展这些条件，需要重新考虑 k 必须为正的语义。

设 n = s.length，L 为 words 中字符总数。最多匹配 min(n, L) 个字符并进行一次失败判断，时间复杂度 O(min(n, L))（也可写 O(n) 上界）；由于每个单词非空，单词循环次数也受消费字符数约束。除循环变量外不创建拼接字符串，额外空间 O(1)。可视化会保存帧和 DOM，不属于提交代码的空间分析。

Java

class Solution {
    public boolean isPrefixString(String s, String[] words) {
        int p = 0;
        for (String word : words) {
            for (int j = 0; j < word.length(); j++) {
                if (p == s.length() || s.charAt(p) != word.charAt(j)) {
                    return false;
                }
                p++;
            }
            if (p == s.length()) return true;
        }
        return false;
    }
}

/**

var isPrefixString = function(s, words) {
    let p = 0;
    for (const word of words) {
        for (let j = 0; j < word.length; j++) {
            if (p === s.length || s[p] !== word[j]) return false;
            p++;
        }
        if (p === s.length) return true;
    }
    return false;
};

Python 3

from typing import List

class Solution:
    def isPrefixString(self, s: str, words: List[str]) -> bool:
        p = 0
        for word in words:
            for ch in word:
                if p == len(s) or s[p] != ch:
                    return False
                p += 1
            if p == len(s):
                return True
        return False

C++

#include <vector>

class Solution {
public:
    bool isPrefixString(string s, vector<string>& words) {
        size_t p = 0;
        for (const string& word : words) {
            for (char ch : word) {
                if (p == s.size() || s[p] != ch) return false;
                ++p;
            }
            if (p == s.size()) return true;
        }
        return false;
    }
};

替代方案

依次拼接前 k 个单词，每次比较是否等于 s，并在拼接长度超过 s 时停止，直观但反复复制和比较不可变字符串，最坏可达到 O(L²) 时间、O(L) 空间。另一种方式是逐词检查 s 从 p 开始的片段是否与 word 一致，再移动 p；仍需在单词边界判断终点，切片可能额外分配内存。

常见错误

  • 只判断 words.join("").startsWith(s)：会把在单词内部结束的 s 误判为 true。
  • 允许跳过数组第一项：题目要求数组前缀，不是任意连续子数组。
  • 在字符循环内看到 p == s.length 就返回 true：还需确认当前单词完整结束。
  • 成功后继续比较后续单词：找到一个合法 k 就足够，无须用完整个数组。
  • 先访问 s[p] 再判断越界：要先判断 p 是否等于长度，利用短路求值。

面试追问

如果单词通过流提供？同样顺序比较，不必保存之前的单词；在成功或失败时立即停止读取。

如果要返回 k？成功时返回当前单词下标加一，失败时返回约定的哨兵值。

若字符扩展到 Unicode？先明确按编码单元、码点还是字素比较。当前题目仅含小写英文字母，四种实现的字符语义一致。
