01 · Problem

题意与输入输出

准确转述

给定一个关于变量 x 的一元一次方程。等式中只会出现整数、变量 x、加号、减号以及唯一一个等号。请返回字符串 "x=#value"。

若等式恒成立，返回 "Infinite solutions"；若等式矛盾，返回 "No solution"。如果恰有一个解，题目保证该解是整数。

注意：系数 1 可以省略，例如 x 等价于 1x，-x 等价于 -1x。

函数签名

参数完整形式

solveEquation(equation: string): string

输入：equation 为方程字符串。

返回：唯一解、无解或无限解的规定字符串。

Example 01
输入：equation = "x+5-3+x=6+x-2" 输出："x=2"
Example 02
输入：equation = "x=x" 输出："Infinite solutions"
Example 03
输入：equation = "2x=x" 输出："x=0"

约束

  • 3 <= equation.length <= 1000
  • equation 中恰好包含一个 '='。
  • 方程由绝对值位于 [0, 100] 的整数和变量 'x' 组成，整数没有前导零；连接符号只有 '+' 与 '-'。
  • 若方程只有一个解，则该解一定是整数。

04 · Solution

准备好看题解了吗？

先尝试用上方账本说清楚三个分支：唯一解、无解、无限解。展开后将看到完整推导、证明与四种语言代码。

Full Explanation

一次扫描，把方程压缩成四个整数

核心洞察

等号每一侧都能表示为 ax + b。扫描时无需构造表达式树，只需维护两个数：x 的系数和常数项。

leftX · x + leftC = rightX · x + rightC

统一移项后得到：

(leftX − rightX) · x = rightC − leftC

三个结果分支

记 A = leftX - rightX，B = rightC - leftC。

  • A != 0：唯一解 x = B / A。
  • A == 0 且 B == 0：恒等式，无限解。
  • A == 0 且 B != 0：矛盾，无解。

完整过程

  1. 用唯一的 '=' 把方程切成左右两部分。
  2. 分别扫描每一侧。遇到正负号时记录当前项符号；读取连续数字作为数值。
  3. 若数字后面紧跟 'x'，该项属于系数；若直接遇到 'x'，省略的系数按 1 处理；否则属于常数。
  4. 取得左右两侧的 [x 系数, 常数] 后统一移项，并按 A、B 是否为零决定返回内容。

示例 1 推导：左侧为 2x + 2，右侧为 x + 4；因此 (2-1)x = 4-2，得到 x=2。

正确性证明

引理 1：单侧扫描结束后，累计的系数与常数之和等于该侧原表达式。因为每一项要么是带符号的 x 项，要么是带符号的常数项；算法按原符号把它恰好加入对应累计量，所以逐项保持等值。

引理 2：将右侧系数移到左侧、左侧常数移到右侧不会改变解集。这只是对等式两侧同步做加减法，所得方程为 Ax=B。

定理：若 A != 0，除以非零的 A 得到唯一的 x=B/A；若 A=0,B=0，任意 x 都满足；若 A=0,B!=0，没有 x 能满足。因此算法在三个分支中都返回正确结果。

边界情况

  • 省略系数：x、-x。
  • 解为零：2x=x。
  • 系数抵消但常数相同：x=x。
  • 系数抵消但常数不同：x=x+2。
  • 方程以负号开头，或一侧只有一个项。

复杂度

设方程字符串长度为 n。

时间：O(n)，每个字符至多被常数次处理。

额外空间：O(1)（不计语言切分字符串可能产生的临时对象）；只维护有限个整数与索引。

Java官方可提交签名
class Solution {
    public String solveEquation(String equation) {
        String[] sides = equation.split("=", -1);
        int[] left = parse(sides[0]);
        int[] right = parse(sides[1]);

        int coefficient = left[0] - right[0];
        int constant = right[1] - left[1];

        if (coefficient == 0) {
            return constant == 0 ? "Infinite solutions" : "No solution";
        }
        return "x=" + (constant / coefficient);
    }

    // 返回 [x 的系数, 常数项]
    private int[] parse(String expression) {
        int xCoefficient = 0;
        int constant = 0;
        int sign = 1;
        int i = 0;

        while (i < expression.length()) {
            char ch = expression.charAt(i);
            if (ch == '+' || ch == '-') {
                sign = ch == '+' ? 1 : -1;
                i++;
            }

            int value = 0;
            boolean hasDigits = false;
            while (i < expression.length()
                    && Character.isDigit(expression.charAt(i))) {
                hasDigits = true;
                value = value * 10 + expression.charAt(i) - '0';
                i++;
            }

            if (i < expression.length() && expression.charAt(i) == 'x') {
                xCoefficient += sign * (hasDigits ? value : 1);
                i++;
            } else {
                constant += sign * value;
            }
        }
        return new int[]{xCoefficient, constant};
    }
}

/**

var solveEquation = function(equation) {
    const [leftText, rightText] = equation.split("=");

    // 返回 [x 的系数, 常数项]
    const parse = (expression) => {
        let xCoefficient = 0;
        let constant = 0;
        let sign = 1;
        let i = 0;

        while (i < expression.length) {
            if (expression[i] === "+" || expression[i] === "-") {
                sign = expression[i] === "+" ? 1 : -1;
                i++;
            }

            let value = 0;
            let hasDigits = false;
            while (i < expression.length && /[0-9]/.test(expression[i])) {
                hasDigits = true;
                value = value * 10 + Number(expression[i]);
                i++;
            }

            if (i < expression.length && expression[i] === "x") {
                xCoefficient += sign * (hasDigits ? value : 1);
                i++;
            } else {
                constant += sign * value;
            }
        }
        return [xCoefficient, constant];
    };

    const [leftX, leftConstant] = parse(leftText);
    const [rightX, rightConstant] = parse(rightText);
    const coefficient = leftX - rightX;
    const constant = rightConstant - leftConstant;

    if (coefficient === 0) {
        return constant === 0 ? "Infinite solutions" : "No solution";
    }
    return `x=${constant / coefficient}`;
};

class Solution {
public:
    string solveEquation(string equation) {
        int equalPos = equation.find('=');
        auto left = parse(equation.substr(0, equalPos));
        auto right = parse(equation.substr(equalPos + 1));

        int coefficient = left.first - right.first;
        int constant = right.second - left.second;

        if (coefficient == 0) {
            return constant == 0 ? "Infinite solutions" : "No solution";
        }
        return "x=" + to_string(constant / coefficient);
    }

private:
    // 返回 {x 的系数, 常数项}
    pair<int, int> parse(const string& expression) {
        int xCoefficient = 0;
        int constant = 0;
        int sign = 1;
        int i = 0;

        while (i < static_cast<int>(expression.size())) {
            if (expression[i] == '+' || expression[i] == '-') {
                sign = expression[i] == '+' ? 1 : -1;
                i++;
            }

            int value = 0;
            bool hasDigits = false;
            while (i < static_cast<int>(expression.size())
                    && isdigit(expression[i])) {
                hasDigits = true;
                value = value * 10 + expression[i] - '0';
                i++;
            }

            if (i < static_cast<int>(expression.size())
                    && expression[i] == 'x') {
                xCoefficient += sign * (hasDigits ? value : 1);
                i++;
            } else {
                constant += sign * value;
            }
        }
        return {xCoefficient, constant};
    }
};

替代方案

按项切分：先在每个 '+'/'-' 前插入分隔符，再逐项解析。思路直观，但会创建更多临时字符串，处理开头负号也更容易出错。

正则匹配：用正则提取所有带符号项，代码可能更短，但不同语言的正则写法不统一，面试中不如手写扫描器清晰可控。

常见错误

  • 把裸 x 的系数当成 0，而不是 1。
  • 移项时只给部分项变号。
  • 只判断系数为 0，却没有继续比较常数。
  • 用浮点数计算唯一解，产生不必要的精度与格式问题。
  • 扫描完一项后忘记让索引越过 x。

面试追问

如果允许空格，怎么改？

扫描时在每轮开始跳过空白字符即可；不要简单删除所有字符，除非明确输入只含 ASCII 空格。

如果唯一解不保证是整数呢？

仍求得分子 B 与分母 A，再按题意输出最简分数或浮点数。输出分数时用最大公约数约分，并统一分母符号。

如果出现括号或乘法呢？

当前的“两个累计量”扫描器不再足够。需要词法分析与递归下降解析，把表达式归约为线性形式；若允许变量相乘，还可能超出一元一次方程范围。
