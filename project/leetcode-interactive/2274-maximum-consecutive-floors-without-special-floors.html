01 / 理解任务

找出最长的一段办公楼层

公司租下了从 bottom 到 top 的全部楼层，两端都包含在内。数组 special 列出只能用于休息的特殊楼层。返回一段完全不含特殊楼层的连续楼层的最大数量；若每层都特殊，返回 0。

参数：bottom（整数）、top（整数）、special（整数数组）；返回值：整数。连续楼层必须相邻，不能跨过特殊楼层。

官方示例 1

输入：bottom = 2, top = 9, special = [4,6]
输出：3

可用连续区间为 [2,3]、[5,5]、[7,9]，长度分别是 2、1、3，因此答案是 3。

官方示例 2

输入：bottom = 6, top = 8, special = [7,6,8]
输出：0

6、7、8 层全部为特殊楼层，没有可用的连续楼层。

完整约束

  • 1 ≤ special.length ≤ 10⁵
  • 1 ≤ bottom ≤ special[i] ≤ top ≤ 10⁹
  • special 中所有值互不相同。

04 / 独立题解

准备好再揭晓

先独立思考，再查看完整推导与四语言实现。

排序后，比较特殊楼层之间的空段

核心洞察

任何合法连续段都不能越过特殊楼层。把特殊楼层从小到大排列后，只需检查开头、相邻特殊楼层之间、结尾这 n + 1 个空段。

完整过程

  1. 复制 special 并按数值升序排序，得到 s，避免改变调用方的数组。
  2. 令 prev = bottom − 1，表示租赁范围之前的虚拟边界；答案 ans 初始为 0。
  3. 依次遇到特殊楼层 x 时，检查 [prev + 1, x − 1]，长度为 x − prev − 1，更新 ans，再令 prev = x。
  4. 最后检查 [prev + 1, top]，长度为 top − prev，并返回最大值。

例如 bottom = 2、top = 9、special = [4,6]：prev 初始为 1；遇到 4 时长度为 4 − 1 − 1 = 2；遇到 6 时为 6 − 4 − 1 = 1；尾段为 9 − 6 = 3。答案为 3。

为什么正确

覆盖性：排序后的特殊楼层将整个租赁范围分成互不相交的空段。任何不含特殊楼层的连续段都完整位于其中一个空段内，长度不会超过该空段。合法性：这些空段内部没有特殊楼层，因此它们本身都是合法候选。循环不变量：每次处理 x 后，ans 是已检查空段的最大长度，prev 是最近处理的特殊楼层。初始没有处理空段，ans = 0 成立；每轮取最大值维持不变量。再补上尾段，所有候选均被覆盖，因此返回全局最优值。

边界与数值

  • 特殊楼层位于 bottom 或 top：对应首段或尾段为 0。
  • 相邻特殊楼层间隔为 1：中间长度为 0，不是负数。
  • 全部楼层特殊，包含 bottom = top：答案为 0。
  • 只有一个特殊楼层：只比较左右两段。
  • 约束保证 special 非空且无重复，不需要为非法空数组另行定义答案。
  • 最大答案不超过 10⁹ − 1，32 位有符号整数足够；JavaScript Number 也能精确表示所有相关整数。

复杂度

设 n = special.length。排序耗时 O(n log n)，扫描 O(n)，总时间 O(n log n)。下列实现都复制数组，额外空间 O(n)，包含复制和排序开销；扫描本身只需 O(1) 变量。楼层范围可能达到 10⁹，不能逐层枚举。

替代方案

可以排序后直接比较 s[0] − bottom、所有 s[i] − s[i−1] − 1、top − s[n−1]；也可添加 bottom − 1 和 top + 1 两个哨兵后统一比较差值减一。若允许修改输入，可原地排序以省去显式副本，排序自身的辅助空间仍由语言实现决定。逐层扫描配合哈希集合需 O(top − bottom + 1) 时间，不适合本题大范围。

四语言完整代码

均使用官方可提交方法签名；Python 为 Python 3。代码仅生成，未编译或执行。

Java

import java.util.Arrays;

class Solution {
    public int maxConsecutive(int bottom, int top, int[] special) {
        int[] s = special.clone();
        Arrays.sort(s);
        int prev = bottom - 1;
        int ans = 0;
        for (int x : s) {
            ans = Math.max(ans, x - prev - 1);
            prev = x;
        }
        return Math.max(ans, top - prev);
    }
}

常见错误

  • 用楼层编号差当作中间楼层数：两个端点都是特殊楼层，中间必须减一。
  • 遗漏首段或尾段：最优区间不一定夹在两个特殊楼层之间。
  • JavaScript 使用无比较器的 sort()：它默认按字符串顺序排序。
  • 没有排序就比较相邻数组元素：输入顺序不等于楼层顺序。
  • 为了遍历每层而创建长度为 top 的数组：楼层跨度远大于特殊楼层数量。

面试追问

  • 还要返回最优区间？更新 ans 时同时记录左右端点；如有并列，明确选择最早区间或全部区间。
  • special 已排序？直接扫描，时间降为 O(n)，且无需复制即可只读处理。
  • 特殊楼层动态增删？用有序集合维护相邻关系，并维护空段长度的多重集合；每次更新只影响局部几个间隔。
  • 允许跨过至多 k 个特殊楼层？排序后围绕至多 k 个特殊楼层维护窗口，并仔细区分“总区间长度”和“普通楼层数量”的新目标。
