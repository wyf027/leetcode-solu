01 / 题目

给定等长数组 nums 和 removeQueries。按顺序删除 nums[removeQueries[i]]，删除位置成为断点，其他元素保留原下标，左右两边不会自动拼接。

每一段连续保留的正整数构成子段，子段和等于其中所有数之和。返回长度为 n 的数组 answer：answer[i] 记录第 i 次删除完成后的最大子段和；没有元素时为 0。

所有数都大于 0，因此一个连续保留区间整体的和就是该区间内最大的子段和。

约束

  • n == nums.length == removeQueries.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁹
  • 0 ≤ removeQueries[i] < n
  • removeQueries 的所有值互不相同，因此恰好删除每个下标一次。
官方题目 ↗

示例 1

nums = [1,2,5,6,1]
removeQueries = [0,3,2,4,1]
输出 = [14,7,2,2,0]

依次删除下标 0、3、2、4、1。最大区间依次为 [1..4]、[1..2]、[1..1]、[1..1]，最后为空，对应和为 14、7、2、2、0。

示例 2

nums = [3,2,11,1]
removeQueries = [3,2,1,0]
输出 = [16,5,3,0]

从右向左删除：剩余连续区间依次为 [3,2,11]、[3,2]、[3]、空，对应和为 16、5、3、0。

04 / 准备好看题解了吗？

包含算法推导、另一种时间方向的演示与四语言实现。

题解 / 把删除倒过来：逆序恢复 + 并查集

核心洞察

正向删除会把一个区间拆开，而普通并查集擅长合并，不擅长拆分。所有删除顺序已知，我们可以从全空数组开始，逆序恢复元素。恢复一个位置时，它只可能与左、右相邻的已恢复区间合并。

每个并查集的根维护该连通区间的元素和。正数使区间合并后的和不会减少，因此全局最大值只需要单调更新，不需要在删除最大区间后重新寻找第二大值。

完整过程与关键时序

  1. 初始化所有位置为未激活，当前最大和 best = 0。
  2. 从 i = n − 1 倒序到 0。先写 answer[i] = best：此时正好对应正向第 i 次删除后的状态。
  3. 令 x = removeQueries[i]，激活 x，初始化其大小为 1、区间和为 nums[x]。
  4. 检查左右邻居：只与已激活且合法的邻居合并。用路径压缩和按大小合并维护根与区间和。
  5. 令 best = max(best, sum[find(x)])，供下一轮写答案使用。最后恢复下标 removeQueries[0] 后得到原数组；这个全量和不再写入答案。
顺序不可颠倒：先记答案，再恢复。恢复完成后的数组对应“第 i 次删除之前”。

正确性证明

状态不变量：进入倒序第 i 轮时，已激活的下标恰好是 removeQueries[i+1..n−1]。因为删除序列是所有下标的排列，这正是正向执行第 0 到第 i 次删除后剩余的下标。

连通性不变量：初始为空，结论成立。恢复 x 后只连接其已激活邻居，恰好增加数组上相邻位置之间的边，不会跨越空位。因此并查集的每个集合对应一个完整连续区间，合并时求和保持区间和正确。

最大值不变量：恢复前 best 是所有区间和的最大值。恢复 x 只会产生一个新合并区间，其他区间不变。新和不小于任何被合并的旧区间和，所以与旧 best 取最大即可得到新的最大值。于是每轮恢复前写入的 answer[i] 正确，归纳覆盖所有查询。

边界与数值类型

  • n = 1：先记录 0，再恢复唯一元素，返回 [0]。
  • 首尾位置只检查存在的一侧；左右都未激活时形成单点区间。
  • 左右都激活时必须合并两侧，不能用 else if 漏掉另一边。
  • 总和最大为 10⁵ × 10⁹ = 10¹⁴。Java 用 long，C++ 用 long long；Python 整数可直接使用，JavaScript Number 在 2⁵³−1 以内可精确表示本题所有整数。
  • 所有和应从最终根读取；非根 sum 可能保留旧值，不能作为区间结果。

复杂度

每个位置激活一次，至多执行两次合并。路径压缩配合按大小合并，总时间为 O(n α(n))，α 是增长极慢的反阿克曼函数。父节点、大小、区间和、激活标记与答案各占 O(n)，总空间为 O(n)。

替代方案

  • 正向有序集合 + 区间和多重集合：用删除下标寻找左右边界，用前缀和算拆分后的两段；移除旧段和，加入新段和，并取最大。时间 O(n log n)，空间 O(n)。相同段和必须计数。
  • 逆序边界长度法：在每个连通区间的两端记录长度与和。恢复 x 后读左右相邻端点，合并并更新新端点；只访问真实边界，内部旧记录不参与计算。可做到 O(n) 时间和 O(n) 空间，端点不变量更容易写错。
  • 逐次扫描：每次删除后遍历整个数组累计连续段和，时间 O(n²)，仅适合小规模推演。本页正向演示只使用两个很小的官方样例。

常见错误

  • 恢复后才写 answer[i]，导致所有结果错位，并错误包含原数组总和。
  • 直接用并查集处理正向删除，无法拆开旧集合。
  • 删除后压紧数组，使原本被断点隔开的元素错误相连。
  • 用 32 位整数储存区间和，或对 JavaScript 和做位运算导致截断。
  • 使用递归 find 却没有平衡合并，构造长链引发调用栈问题；此处四语言都采用迭代 find。

面试追问

  • 如果查询必须在线处理？不能倒序预知未来，改用有序集合拆区间并维护段和的多重集合。
  • 允许负数，还要求任意连续子数组最大和？整段和不再等于最优子数组和；需要维护总和、最大前缀、最大后缀、最大子数组和，并明确空位屏障语义，通常使用线段树。
  • 允许同一下标多次删除？不能每次逆序都恢复。先记录每个下标的删除次数，逆序计数降至 0 时才激活，并调整初始未删除元素。
  • 为什么不能只维护正向最大值？最大区间被切断后可能变小，且次大区间可能成为新最大；需要可删除的有序结构，逆序则利用正数消除了这个问题。

Java
class Solution {
    private int find(int[] parent, int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    private void union(int[] parent, int[] size, long[] sum, int a, int b) {
        a = find(parent, a);
        b = find(parent, b);
        if (a == b) return;
        if (size[a] < size[b]) {
            int t = a; a = b; b = t;
        }
        parent[b] = a;
        size[a] += size[b];
        sum[a] += sum[b];
    }

    public long[] maximumSegmentSum(int[] nums, int[] removeQueries) {
        int n = nums.length;
        int[] parent = new int[n], size = new int[n];
        long[] sum = new long[n], answer = new long[n];
        boolean[] active = new boolean[n];
        for (int i = 0; i < n; i++) parent[i] = i;
        long best = 0;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] = best; // Record before restoring removeQueries[i].
            int x = removeQueries[i];
            active[x] = true;
            size[x] = 1;
            sum[x] = nums[x];
            if (x > 0 && active[x - 1]) union(parent, size, sum, x, x - 1);
            if (x + 1 < n && active[x + 1]) union(parent, size, sum, x, x + 1);
            best = Math.max(best, sum[find(parent, x)]);
        }
        return answer;
    }
}

var maximumSegmentSum = function(nums, removeQueries) {
    const n = nums.length;
    const parent = Array.from({length: n}, (_, i) => i);
    const size = Array(n).fill(1), sum = Array(n).fill(0);
    const active = Array(n).fill(false), answer = Array(n).fill(0);
    function find(x) {
        while (parent[x] !== x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    function union(a, b) {
        a = find(a); b = find(b);
        if (a === b) return;
        if (size[a] < size[b]) [a, b] = [b, a];
        parent[b] = a;
        size[a] += size[b];
        sum[a] += sum[b];
    }
    let best = 0;
    for (let i = n - 1; i >= 0; i--) {
        answer[i] = best;
        const x = removeQueries[i];
        active[x] = true;
        sum[x] = nums[x];
        if (x > 0 && active[x - 1]) union(x, x - 1);
        if (x + 1 < n && active[x + 1]) union(x, x + 1);
        best = Math.max(best, sum[find(x)]);
    }
    return answer;
};

from typing import List

class Solution:
    def maximumSegmentSum(self, nums: List[int], removeQueries: List[int]) -> List[int]:
        n = len(nums)
        parent = list(range(n))
        size = [1] * n
        sums = [0] * n
        active = [False] * n
        answer = [0] * n

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            a, b = find(a), find(b)
            if a == b:
                return
            if size[a] < size[b]:
                a, b = b, a
            parent[b] = a
            size[a] += size[b]
            sums[a] += sums[b]

        best = 0
        for i in range(n - 1, -1, -1):
            answer[i] = best
            x = removeQueries[i]
            active[x] = True
            sums[x] = nums[x]
            if x > 0 and active[x - 1]:
                union(x, x - 1)
            if x + 1 < n and active[x + 1]:
                union(x, x + 1)
            best = max(best, sums[find(x)])
        return answer
C++
#include <algorithm>
#include <numeric>
#include <vector>
using namespace std;

class Solution {
public:
    vector<long long> maximumSegmentSum(vector<int>& nums, vector<int>& removeQueries) {
        int n = nums.size();
        vector<int> parent(n), size(n, 1);
        vector<long long> sum(n, 0), answer(n, 0);
        vector<bool> active(n, false);
        iota(parent.begin(), parent.end(), 0);
        auto find = [&](int x) {
            while (parent[x] != x) {
                parent[x] = parent[parent[x]];
                x = parent[x];
            }
            return x;
        };
        auto unite = [&](int a, int b) {
            a = find(a); b = find(b);
            if (a == b) return;
            if (size[a] < size[b]) swap(a, b);
            parent[b] = a;
            size[a] += size[b];
            sum[a] += sum[b];
        };
        long long best = 0;
        for (int i = n - 1; i >= 0; --i) {
            answer[i] = best;
            int x = removeQueries[i];
            active[x] = true;
            sum[x] = nums[x];
            if (x > 0 && active[x - 1]) unite(x, x - 1);
            if (x + 1 < n && active[x + 1]) unite(x, x + 1);
            best = max(best, sum[find(x)]);
        }
        return answer;
    }
};
