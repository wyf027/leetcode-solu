Strings Differ by One Character

只有一个不同字符的字符串

给定一组等长字符串，判断其中是否存在一对字符串，恰好只有一个位置上的字符不同。

Problem

题目描述

给你一个字符串数组 dict。数组中的每个字符串长度相同，并且都只包含小写英文字母。

如果可以在数组中选出两个不同的字符串，使它们在相同下标处比较时恰好只有一个字符不同，返回 true；否则返回 false。

函数形式：differByOne(dict: string[]): boolean。注意，“恰好一个”意味着完全相同的两个字符串不能构成答案。

示例

示例 1

输入：dict = ["abcd","acbd","aacd"]
输出：true

"abcd" 与 "aacd" 只有下标 1 的字符不同。

示例 2

输入：dict = ["ab","cd","yz"]
输出：false

任意两个字符串都不满足恰好只有一个位置不同。

示例 3

输入：dict = ["abcd","cccc","abyd","abab"]
输出：true

"abcd" 与 "abyd" 只有下标 2 的字符不同。

约束

  • 2 <= dict.length <= 105
  • 1 <= dict[i].length <= 20
  • 所有 dict[i] 的长度相同。
  • dict[i] 仅由小写英文字母组成。

Full walkthrough

题解：位置遮罩 + 哈希表

核心洞察

若两个等长字符串只在下标 j 不同，那么把它们的第 j 位都替换成同一个占位符后，所得指纹完全相同。

哈希表将“遮罩指纹”映射到被遮住的原字符。再次遇到相同指纹且原字符不同，即找到答案。

为什么要保存原字符？

如果输入含两个完全相同的字符串，它们会生成相同指纹，但实际差异数为 0。只有同指纹对应的被遮字符不同，才能确认差异数恰好为 1。

完整过程

  1. 建立哈希表 seen，键为遮罩指纹，值为这个位置原先的字符。
  2. 依次处理每个字符串，并枚举其每个下标 j。
  3. 把第 j 位临时替换为 *，得到指纹。
  4. 若指纹已存在且登记字符与当前原字符不同，立即返回 true。
  5. 若指纹从未出现，登记当前原字符；全部枚举结束仍未命中则返回 false。

正确性证明

充分性：算法返回 true 时，存在两个字符串在同一位置生成相同遮罩指纹，说明其他所有位置均相同；同时登记字符不同，说明该位置不同。因此它们恰好一个字符不同。

必要性：若存在一对字符串恰好在位置 j 不同，则遮罩位置 j 后两者指纹相同，且被遮字符不同。后处理到的字符串查询哈希表时必然命中，算法会返回 true。

结论：算法返回 true 当且仅当存在满足条件的字符串对。

复杂度

设字符串数量为 n，统一长度为 m。常规字符串切片/复制生成指纹需要 O(m)，共生成 n·m 个，因此时间为 O(n·m²)，空间为 O(n·m²) 个字符。由于本题 m ≤ 20，该实现直接且稳健。

边界情况

  • 长度为 1：两个不同单字符字符串即可命中。
  • 重复字符串：不能误判为恰好一个位置不同。
  • 差异为 2 个或更多：不会得到相同的单位置遮罩指纹。
  • 答案较早出现：可立即返回，无需继续扫描。

四语言完整代码

Java官方提交签名
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean differByOne(String[] dict) {
        Map<String, Character> seen = new HashMap<>();

        for (String word : dict) {
            char[] chars = word.toCharArray();
            for (int j = 0; j < chars.length; j++) {
                char original = chars[j];
                chars[j] = '*';
                String signature = new String(chars);
                chars[j] = original;

                Character previous = seen.get(signature);
                if (previous != null && previous != original) {
                    return true;
                }
                if (previous == null) {
                    seen.put(signature, original);
                }
            }
        }
        return false;
    }
}

/**
 * @param {string[]} dict
 * @return {boolean}
 */
var differByOne = function(dict) {
    const seen = new Map();

    for (const word of dict) {
        for (let j = 0; j < word.length; j++) {
            const signature = word.slice(0, j) + '*' + word.slice(j + 1);
            const current = word[j];

            if (seen.has(signature) && seen.get(signature) !== current) {
                return true;
            }
            if (!seen.has(signature)) {
                seen.set(signature, current);
            }
        }
    }
    return false;
};
Python官方提交签名
from typing import List


class Solution:
    def differByOne(self, dict: List[str]) -> bool:
        seen = {}

        for word in dict:
            for j, current in enumerate(word):
                signature = word[:j] + "*" + word[j + 1:]

                if signature in seen and seen[signature] != current:
                    return True
                if signature not in seen:
                    seen[signature] = current

        return False
C++官方提交签名
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    bool differByOne(vector<string>& dict) {
        unordered_map<string, char> seen;

        for (string word : dict) {
            for (int j = 0; j < static_cast<int>(word.size()); ++j) {
                char original = word[j];
                word[j] = '*';

                auto it = seen.find(word);
                if (it != seen.end() && it->second != original) {
                    return true;
                }
                if (it == seen.end()) {
                    seen.emplace(word, original);
                }
                word[j] = original;
            }
        }
        return false;
    }
};

替代方案

暴力两两比较：时间 O(n²·m)，最容易想到但无法承受 n = 10⁵。

滚动哈希：预处理每个字符串的哈希后，可在近似 O(n·m) 时间生成“删除一位”的哈希。不过必须考虑哈希碰撞，面试中应说明双哈希或命中后原串复核。

面试追问

  • 如何把构造指纹的复杂度从 O(m) 降到 O(1)？
  • 如果允许恰好 k 个位置不同，状态如何设计？
  • 若字符集包含占位符 *，如何编码指纹避免歧义？
  • 怎样在返回布尔值之外，恢复那一对字符串的下标？

常见错误

  • 只用 Set 保存遮罩字符串，导致重复的完全相同字符串被误判。
  • 把条件理解成“至多一个字符不同”，错误接受完全相同的字符串。
  • 混淆两个字符串中不同的位置；必须在同一个下标生成同一指纹。
  • 宣称切片实现是 O(n·m)；字符串构造通常还需要复制 O(m) 个字符。
  • 用单哈希滚动值却不讨论碰撞风险。
