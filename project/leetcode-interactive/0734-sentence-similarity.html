Problem 734 · Array / Hash Table / String

句子相似性Sentence Similarity

给定两个按单词拆分的句子和一组相似词对，判断两个句子能否在每个相同位置上逐词匹配。相同单词天然相似；词对方向可互换，但关系不会沿多组词对传递。

核心动作对齐后逐词扫描
关键结构哈希邻接集合
目标复杂度O(n + p)
Problem

题意与规则

函数接收 sentence1、sentence2 与 similarPairs。只有当两个句子长度相同，并且每个位置 i 的两个单词满足下列任一条件时，才返回 true：

  • 两个单词完全相同；
  • 这两个单词以任意顺序直接出现在某一组相似词对中。
特别注意：相似关系是对称的，但不是传递的。若 a ~ b 且 b ~ c，不能据此推出 a ~ c。

约束

  • 1 ≤ sentence1.length, sentence2.length ≤ 1000
  • 每个句中单词长度为 1…20，由英文字母组成。
  • 0 ≤ similarPairs.length ≤ 1000，每项恰含两个单词。
  • 词对中的单词长度为 1…20，由英文字母组成。
  • 给出的相似词对互不重复。

官方示例

Example 01

三处均可直接匹配

输入
sentence1 = ["great","acting","skills"]
sentence2 = ["fine","drama","talent"]
similarPairs = [["great","fine"],
                ["drama","acting"],
                ["skills","talent"]]
输出true

三个对齐位置都能在直接词对中找到，词对顺序不影响匹配。

Example 02

相同单词无需词对

输入
sentence1 = ["great"]
sentence2 = ["great"]
similarPairs = []
输出true

同一个单词与自身相似。

Example 03

句长不同立即失败

输入
sentence1 = ["great"]
sentence2 = ["doubleplus","good"]
similarPairs = [["great","doubleplus"]]
输出false

即使首词相似，仍有一个位置无法对齐。

展开题解

Solution

哈希集合：只记录直接关系

核心洞察

先做长度检查。随后将每个词映射到它的直接相似词集合；扫描同一位置的两个词时，若二者相等或第二个词存在于第一个词的邻接集合中，该位置成立。这里无需并查集，因为并查集会错误地加入传递性。

完整过程

  1. 若两个句子的单词数不同，直接返回 false。
  2. 遍历 similarPairs，为每一对 (a,b) 同时加入 a → b 和 b → a。
  3. 从左到右扫描两个句子。相同单词直接继续；不同单词必须命中邻接集合。
  4. 某个位置不匹配便立即返回 false；全部位置成立后返回 true。

正确性说明

充分性：算法接受每个位置时，该位置的词要么相同，要么是题目给出的直接相似词对，因此所有位置均满足定义，两个句子相似。

必要性：若两个句子相似，则长度必相等，且每个位置必为相同词或直接相似词对。邻接集合完整保存了所有直接词对及其反向，算法不会拒绝任何合法位置。

复杂度

设句长为 n、词对数为 p。建表耗时 O(p)，扫描耗时 O(n)，总时间 O(n+p)；邻接集合占用 O(p) 空间。

边界

  • 句长不等；相似词对为空；所有位置词都相同。
  • 词对顺序与句中顺序相反。
  • 只能经第三个词连接，但不存在直接词对。

Java 
class Solution {
    public boolean areSentencesSimilar(
            String[] sentence1,
            String[] sentence2,
            List<List<String>> similarPairs) {
        if (sentence1.length != sentence2.length) {
            return false;
        }

        Map<String, Set<String>> neighbors = new HashMap<>();
        for (List<String> pair : similarPairs) {
            String a = pair.get(0);
            String b = pair.get(1);
            neighbors.computeIfAbsent(a, key -> new HashSet<>()).add(b);
            neighbors.computeIfAbsent(b, key -> new HashSet<>()).add(a);
        }

        for (int i = 0; i < sentence1.length; i++) {
            String a = sentence1[i];
            String b = sentence2[i];
            if (a.equals(b)) {
                continue;
            }
            if (!neighbors.getOrDefault(a, Collections.emptySet()).contains(b)) {
                return false;
            }
        }
        return true;
    }
}

/**
 * @param {string[]} sentence1
 * @param {string[]} sentence2
 * @param {string[][]} similarPairs
 * @return {boolean}

var areSentencesSimilar = function(sentence1, sentence2, similarPairs) {
    if (sentence1.length !== sentence2.length) {
        return false;
    }

    const neighbors = new Map();
    const add = (a, b) => {
        if (!neighbors.has(a)) neighbors.set(a, new Set());
        neighbors.get(a).add(b);
    };

    for (const [a, b] of similarPairs) {
        add(a, b);
        add(b, a);
    }

    for (let i = 0; i < sentence1.length; i++) {
        const a = sentence1[i];
        const b = sentence2[i];
        if (a !== b && !neighbors.get(a)?.has(b)) {
            return false;
        }
    }
    return true;
};
Python 
from collections import defaultdict
from typing import List


class Solution:
    def areSentencesSimilar(
        self,
        sentence1: List[str],
        sentence2: List[str],
        similarPairs: List[List[str]],
    ) -> bool:
        if len(sentence1) != len(sentence2):
            return False

        neighbors = defaultdict(set)
        for a, b in similarPairs:
            neighbors[a].add(b)
            neighbors[b].add(a)

        for a, b in zip(sentence1, sentence2):
            if a != b and b not in neighbors[a]:
                return False
        return True
C++ 
class Solution {
public:
    bool areSentencesSimilar(
        vector<string>& sentence1,
        vector<string>& sentence2,
        vector<vector<string>>& similarPairs
    ) {
        if (sentence1.size() != sentence2.size()) {
            return false;
        }

        unordered_map<string, unordered_set<string>> neighbors;
        for (const auto& pair : similarPairs) {
            neighbors[pair[0]].insert(pair[1]);
            neighbors[pair[1]].insert(pair[0]);
        }

        for (size_t i = 0; i < sentence1.size(); ++i) {
            const string& a = sentence1[i];
            const string& b = sentence2[i];
            if (a != b && !neighbors[a].count(b)) {
                return false;
            }
        }
        return true;
    }
};

替代方案

可以把每个无序词对编码为一个安全键并存入单个集合，查询时也用同样规则编码。邻接集合更直观，也避免字符串拼接产生歧义。逐次线性搜索词对只需 O(1) 额外空间，但最坏时间会升至 O(np)。

面试追问

  • 如果相似关系具有传递性？改用并查集维护连通分量。
  • 如果词对持续在线加入？邻接表可直接增量更新。
  • 如果需要返回首个失败位置？将布尔返回改为携带索引与原因的结果。

常见错误

  • 忘记先比较句长，导致漏检多出的单词。
  • 只保存词对的一个方向，误拒绝反向出现的合法匹配。
  • 忘记“相同单词天然相似”，要求所有位置都必须出现在词对中。
  • 错误使用并查集或图可达性，把非传递关系扩展为传递关系。
