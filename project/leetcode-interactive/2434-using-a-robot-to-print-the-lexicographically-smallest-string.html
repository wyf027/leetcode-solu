01任务与规则

给定字符串 s，机器人手中的字符串 t 初始为空，纸上的结果 p 也为空。你可以反复选择一个可执行的操作：

① 取入字符

从 s 的开头取走一个字符，接到 t 的末尾。

② 打印字符

从 t 的末尾取走一个字符，追加到纸上 p 的末尾。

直到 s 和 t 都为空，返回能得到的字典序最小的纸上字符串。字典序比较看第一个不同位置，字符较小的字符串更小。

参数：s: string；返回：string。约束：1 ≤ s.length ≤ 10⁵，s 仅含小写英文字母。

04独立题解

先自行思考：什么时候值得立刻打印栈顶？

核心洞察：栈顶与未来最小字符比较

机器人只能从 t 的末尾打印，因此 t 是一个栈。设未读输入中的最小字符为 m，当前栈顶为 x。如果 x ≤ m，可以立即打印 x；如果 x > m，应继续取入，让未来更小的字符先打印。没有剩余输入时，将 m 视为大于 'z' 的哨兵 '{'，即可清空栈。

完整过程

  1. 从右向左预处理 low[i]：s 从 i 开始的后缀最小字符，令 low[n] = '{'。
  2. 从左向右扫描 s，将 s[i] 压入栈。此时剩余输入的最小字符是 low[i + 1]。
  3. 只要栈非空且栈顶不大于 low[i + 1]，就弹出栈顶并写到答案。
  4. 继续扫描；最后一个字符入栈后，哨兵使所有剩余字符被打印。
以 s = "bac" 为例：low = ['a', 'a', 'c', '{']
取入 b：t="b"，剩余最小 a，b > a，等待
取入 a：t="ba"，剩余最小 c
打印 a：p="a"，t="b"；b ≤ c，继续
打印 b：p="ab"，t=""
取入 c：剩余为空，打印 c，p="abc"

正确性：为什么局部选择安全？

状态不变量：栈中按取入顺序保存尚未打印的字符；答案只由合法弹栈操作得到；low[i + 1] 恰好描述所有未读字符的最小值。

当 x > m：现在打印会令下一个输出为 x。继续取入直到某个 m 到达栈顶，就能以下一个输出 m 开始；因为 m < x，这个合法选择在第一个不同位置更小。因此最优结果不应此时打印 x。

当 x ≤ m：如果延迟打印 x，任何先于它打印的字符都来自新取入的字符，均不小于 x；栈内更深的字符在 x 弹出前无法打印。把 x 的打印移到这些新字符之前仍合法，且输出字典序不会增大。相等也可立刻打印。

因此每次打印都有一个最优方案与之相容；不打印时继续取入也是必需选择。重复此论证直到两个字符串为空，得到全局字典序最小结果。

边界与复杂度

  • 单字符、全部相同：正常逐个打印；重复字符使用 ≤，不应误写成严格小于。
  • 输入结束：哨兵必须严格大于 'z'；用 'z' 作为本实现哨兵也能比较，但 '{' 更清楚地区分“无剩余字符”。
  • 栈顶可能阻挡更小的旧字符，不能跳过栈顶取栈底。
  • 后缀数组构造 O(n)；每个字符入栈、出栈各一次，扫描总时间 O(n)，额外空间 O(n)，包含后缀数组、栈与答案缓冲。

替代方案

用长度为 26 的频次数组维护尚未读入字符的数量，并用只前进的指针寻找最小剩余字母。每次取入后先扣减频次，再推进指针，最后按同一规则弹栈。时间 O(n + 26)，除栈和结果外只需 O(26) 空间。后缀数组版本更直观，也容易推广到其他可排序字符集。

常见错误

  • 直接排序 s：违反操作限制，例如 "bdda" 无法打印成 "abdd"。
  • 只和下一个字符比较：需要比较整个未读后缀的最小字符。
  • 取入后比较 low[i]：它还包含刚刚取入的字符，应比较 low[i + 1]。
  • 用 if 只弹一次：栈顶变化后仍可能能打印，必须使用 while。
  • 反复删除输入首字符或拼接不可变字符串：可能退化成 O(n²)，应用索引及缓冲数组。

面试追问

  • 能不能真正在线、不知道后续输入？通常不能立即决定打印：当前见到 b，后续若有 a 就应该等待。
  • 为什么相等也打印？延迟不会带来更小的下一个字符，还可能把栈顶埋在更大的字符下面。
  • 字符集扩大怎么办？后缀最小仍适用；需统一字符序与遍历单位，不能直接假定 26 个字母或用 '{' 当通用哨兵。
  • 为什么嵌套 while 仍线性？整个执行期间每个字符最多弹出一次，总弹出次数为 n。

Java

class Solution {
    public String robotWithString(String s) {
        int n = s.length();
        char[] low = new char[n + 1];
        low[n] = '{';
        for (int i = n - 1; i >= 0; i--) {
            low[i] = (char) Math.min(s.charAt(i), low[i + 1]);
        }
        char[] stack = new char[n];
        int size = 0;
        StringBuilder answer = new StringBuilder(n);
        for (int i = 0; i < n; i++) {
            stack[size++] = s.charAt(i);
            while (size > 0 && stack[size - 1] <= low[i + 1]) {
                answer.append(stack[--size]);
            }
        }
        return answer.toString();
    }
}

JavaScript

/**
 * @param {string} s
 * @return {string}
 */
var robotWithString = function(s) {
    const n = s.length;
    const low = new Array(n + 1);
    low[n] = '{';
    for (let i = n - 1; i >= 0; i--) {
        low[i] = s[i] < low[i + 1] ? s[i] : low[i + 1];
    }
    const stack = [], answer = [];
    for (let i = 0; i < n; i++) {
        stack.push(s[i]);
        while (stack.length && stack[stack.length - 1] <= low[i + 1]) {
            answer.push(stack.pop());
        }
    }
    return answer.join('');
};

class Solution:
    def robotWithString(self, s: str) -> str:
        n = len(s)
        low = ['{'] * (n + 1)
        for i in range(n - 1, -1, -1):
            low[i] = min(s[i], low[i + 1])
        stack = []
        answer = []
        for i, ch in enumerate(s):
            stack.append(ch)
            while stack and stack[-1] <= low[i + 1]:
                answer.append(stack.pop())
        return ''.join(answer)

C++

#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string robotWithString(string s) {
        int n = static_cast<int>(s.size());
        vector<char> low(n + 1, '{');
        for (int i = n - 1; i >= 0; --i) {
            low[i] = min(s[i], low[i + 1]);
        }
        string stack, answer;
        stack.reserve(n);
        answer.reserve(n);
        for (int i = 0; i < n; ++i) {
            stack.push_back(s[i]);
            while (!stack.empty() && stack.back() <= low[i + 1]) {
                answer.push_back(stack.back());
                stack.pop_back();
            }
        }
        return answer;
    }
};
