231. 2 的幂

判断整数 n 是否恰好等于某个 2ˣ。二进制表达里，正的 2 的幂只有一个 1。

位运算二进制n & (n − 1)O(1) 空间

题意

给定整数 n，当且仅当存在整数 x 使 n == 2ˣ 时，返回 true；否则返回 false。

官方样例 1

输入n = 1
输出true

1 = 2⁰

官方样例 2

输入n = 16
输出true

16 = 2⁴

官方样例 3

输入n = 3
输出false

二进制为 11

约束：-2³¹ ≤ n ≤ 2³¹ − 1。

交互：每次消去最低位的 1

以 n = 40（101000₂）为例。n & (n - 1) 会消掉最低位 1；若结果为 0，原数恰有一个 1。

题解：清除最低位的 1

核心洞察

对正整数，n - 1 会把最低位的 1 变为 0，并把它右侧的 0 变为 1。因此 n & (n - 1) 恰好删除 n 最低位的一个 1。

判断过程

  1. 先判断 n > 0，排除 0 与负数。
  2. 计算 n & (n - 1)。
  3. 结果为 0 说明原数仅有一个二进制 1，即 2 的幂。

边界与复杂度

n = 1：是 2⁰，成立。

n = 0：0 & -1 = 0，所以必须先判断正数。

负数：补码形式会误导位运算，也必须排除。

复杂度：时间 O(1)，空间 O(1)。

替代方案

循环不断除以 2 或检查对数都能解决；位运算没有浮点精度风险，常数也更小，是面试首选。

常见错误：漏掉 n > 0。仅使用 (n & (n - 1)) == 0 会把 0 误判为 true。

面试追问

如何判断 4 的幂？先判断 2 的幂，再要求唯一的 1 位出现在偶数编号位置；可结合掩码 0x55555555。
