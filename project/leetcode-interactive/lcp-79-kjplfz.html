提取咒文

移动和提取各算一次操作。把“当前位置”和“已提取字符数”合成状态，三维 BFS 就能找到最短操作序列。

LCP 79矩阵 BFSO(m × n × |mantra|)

题意

按顺序从字符矩阵中提取 mantra

提取装置从左上角开始，每次可向上下左右移动一格，或在当前位置提取一个字符。移动、提取各记一次操作；同一格可重复提取。返回拼出 mantra 的最少操作数，无法完成返回 -1。

matrix

["sd","ep"]

mantra

"speed"

状态

  1. (x, y, k)：人在格子 (x,y)，已提取前 k 个字符。
  2. 移动边：k 不变，代价 1。
  3. 提取边：若当前格等于 mantra[k]，k+1，代价 1。

为什么二维 BFS 不够

同一格在不同咒文进度下是不同状态

装置可能反复回到同一位置提取不同的后续字符。仅按坐标标记访问会错误剪枝；加上进度 k 后，每个状态只首次入队，BFS 第一次到达终态就是最短操作数。

题解默认隐藏

先观察进度维度如何避免错误剪枝，再展开四语言实现。

队列保存 (row, col, index)。扩展四个移动邻居，并在格子字符等于当前目标时扩展一次“提取”边。所有边权为 1，因此普通 BFS 即可。

Java

class Solution { public int extractMantra(String[] a,String t){int m=a.length,n=a[0].length(),k=t.length(); boolean[][][] vis=new boolean[m][n][k+1]; Queue<int[]>q=new ArrayDeque<>();q.offer(new int[]{0,0,0});vis[0][0][0]=true;for(int d=0;!q.isEmpty();d++)for(int z=q.size();z>0;z--){int[] p=q.poll();if(p[2]==k)return d;if(p[2]<k&&a[p[0]].charAt(p[1])==t.charAt(p[2])&&!vis[p[0]][p[1]][p[2]+1]){vis[p[0]][p[1]][p[2]+1]=true;q.offer(new int[]{p[0],p[1],p[2]+1});}for(int[] v:new int[][]{{1,0},{-1,0},{0,1},{0,-1}}){int x=p[0]+v[0],y=p[1]+v[1];if(x>=0&&x<m&&y>=0&&y<n&&!vis[x][y][p[2]]){vis[x][y][p[2]]=true;q.offer(new int[]{x,y,p[2]});}}}return -1;} }

JavaScript

var extractMantra = function(a,t){const m=a.length,n=a[0].length,q=[[0,0,0]],vis=new Set(['0,0,0']);for(let h=0,d=0;h<q.length;d++){for(let end=q.length;h<end;h++){const [x,y,k]=q[h];if(k===t.length)return d;for(const [nx,ny,nk] of [[x,y,k+1],[x+1,y,k],[x-1,y,k],[x,y+1,k],[x,y-1,k]]){if(nx<0||nx>=m||ny<0||ny>=n||nk>t.length||(nk===k+1&&a[x][y]!==t[k]))continue;const key=`${nx},${ny},${nk}`;if(!vis.has(key)){vis.add(key);q.push([nx,ny,nk]);}}}}return -1;};

class Solution:
 def extractMantra(self,a,t):
  m,n=len(a),len(a[0]); q=deque([(0,0,0)]); seen={(0,0,0)}
  for d in count():
   for _ in range(len(q)):
    x,y,k=q.popleft()
    if k==len(t): return d
    for nx,ny,nk in [(x,y,k+1),(x+1,y,k),(x-1,y,k),(x,y+1,k),(x,y-1,k)]:
     if 0<=nx<m and 0<=ny<n and nk<=len(t) and (nk==k or a[x][y]==t[k]) and (nx,ny,nk) not in seen: seen.add((nx,ny,nk));q.append((nx,ny,nk))
  return -1
