纠正二叉树

一棵二叉树里混入了一条不可能出现的横向指针。你的任务不是修正那条边，而是把错误节点及其真正的子树从树中移除。

题目

树中恰好有一个错误节点，它的右指针被改为指向同一层、位于它右侧的另一个节点。

准确转述

给定这棵被破坏的二叉树的根节点 root。找到那个右指针异常的节点，并从树中删除以它为根的整棵真实子树；异常指针指向的右侧节点本身不属于待删除子树。返回修正后的根节点。

自定义测试参数：fromNode 与 toNode 是构造错误指针所需的节点值。平台先令 fromNode.right = toNode，再把 root 交给提交函数；通常提交签名仅接收 root。

约束

  • 树中节点数为 [3, 104]
  • -109 ≤ Node.val ≤ 109
  • 所有节点值互不相同
  • fromNode ≠ toNode，且二者均在树中
  • fromNode 与 toNode 深度相同，toNode 位于 fromNode 右侧
  • 树中恰好存在题述的一条错误指针

示例 1

输入：root = [1,2,3], fromNode = 2, toNode = 3
输出：[1,null,3]
解释：节点 2 的右指针错误地指向节点 3，
      因而删除以节点 2 为根的子树。

示例 2

输入：root = [8,3,1,7,null,9,4,2,null,null,null,5,6],
      fromNode = 7, toNode = 4
输出：[8,3,1,null,null,9,4,null,null,5,6]
解释：删除节点 7 及其真实后代节点 2；
      节点 4 保留。

准备好核对思路了吗？

下面包含完整算法、证明、复杂度与四种语言实现。先独立想一想：怎样利用“目标一定在同层右侧”这个条件？

题解：从右向左，让错误指针自己暴露

核心洞察：以“根 → 右 → 左”的顺序 DFS。当访问某节点时，若它的 right 已出现在全局 visited 集合，说明该指针不可能是向下的正常树边；当前节点就是错误节点，应直接返回 null。

完整过程

空节点直接返回。它不产生任何访问记录。
先检查右指针。若 node.right 已被访问，删除当前节点及其子树。
记录当前节点。把对象身份加入哈希集合，不能只依赖值。
先递归右子树，再递归左子树。用递归返回值回写孩子指针。
返回当前节点。最终得到修复后的根。

为什么正确

引理：右优先 DFS 在到达错误节点 x 前，已访问 x 同层且位于其右侧的目标节点 y。因为二者在同层，通向 y 的分支在二者最近公共祖先处位于右侧，会被优先完整处理。

识别：正常右孩子必比父节点深一层，首次从父节点访问它时不可能已在集合中；而错误的 x.right = y 指向已访问的同层节点，条件恰好成立。

删除：在 x 处返回 null，其父节点回写对应孩子指针，于是只断开 x 及其真实后代。y 所在正常分支不受影响。因此返回树正是题目要求的修正结果。

边界与复杂度

  • 错误节点可能是任一非根节点，也可能没有真实孩子。
  • 异常右指针不能继续递归，否则图中共享节点会导致重复访问甚至错误修改。
  • 时间复杂度：O(n)，每个保留或检查到的节点至多处理一次。
  • 空间复杂度：O(n)，哈希集合与最坏递归栈均可能为线性。

替代方案与面试追问

BFS：逐层从右向左扫描，用集合记录本层右侧节点；若当前节点的右指针已在集合中，就从父节点断开当前节点。它同样是 O(n)，但需同时维护父子关系。

追问：若节点值不唯一怎么办？集合应保存节点对象身份，算法不受影响。若错误边不保证指向右侧同层节点，则右优先顺序失去判定保证，需要通用的入度、父指针或图环检测信息。

常见错误：先递归左子树；检测后仍沿异常指针递归；仅把 right 置空而没有删除错误节点；把 fromNode/toNode 误写进平台提交签名。

四语言完整实现

选择语言查看。代码使用平台提供的 TreeNode 定义，提交函数只接收 root。

Java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    private final Set<TreeNode> visited = new HashSet<>();

    public TreeNode correctBinaryTree(TreeNode root) {
        return dfs(root);
    }

    private TreeNode dfs(TreeNode node) {
        if (node == null) return null;

        if (node.right != null && visited.contains(node.right)) {
            return null;
        }

        visited.add(node);
        node.right = dfs(node.right);
        node.left = dfs(node.left);
        return node;
    }
}

var correctBinaryTree = function (root) {
  const visited = new Set();

  const dfs = (node) => {
    if (node === null) return null;

    if (node.right !== null && visited.has(node.right)) {
      return null;

    visited.add(node);
    node.right = dfs(node.right);

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;

class Solution {
    unordered_set<TreeNode*> visited;

    TreeNode* dfs(TreeNode* node) {
        if (node == nullptr) return nullptr;

        if (node->right != nullptr && visited.count(node->right)) {
            return nullptr;
        }

        visited.insert(node);
        node->right = dfs(node->right);
        node->left = dfs(node->left);
        return node;
    }

public:
    TreeNode* correctBinaryTree(TreeNode* root) {
        return dfs(root);
    }
};
