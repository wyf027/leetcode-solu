从叶结点开始的
最小字符串

每个结点把数字映射成一个小写字母。沿每条根到叶路径走到底，再把路径倒过来，找出字典序最小的叶到根字符串。

↑阅读方向与遍历方向相反：
遍历向下，答案向上。

题意

给定二叉树根结点 root。每个结点值位于 [0, 25]，依次代表 a 到 z。对每个叶结点，读取从该叶结点到根结点的字符，返回其中字典序最小的字符串。

字典序比较遵循通常规则：若一个字符串是另一个的前缀，更短者更小。叶结点指没有任何子结点的结点。

函数形式

smallestFromLeaf(root: TreeNode) → string

约束

  • 树中结点数为 [1, 8500]
  • 0 ≤ Node.val ≤ 25
  • 输入保证是一棵有效二叉树

关键字

二叉树 深度优先搜索 回溯 字符串

输入：root = [0,1,2,3,4,3,4]\n输出："dba"
输入：root = [25,1,3,1,3,0,2]\n输出："adz"

Solution

一次 DFS，把路径留在递归栈里

核心洞察：遍历时方便维护的是“根 → 当前结点”路径，而题目要的是反方向。只有到达叶结点时才把路径逆序生成候选，并更新全局最小值。
  1. 进入结点时，把它对应的字符追加到路径。
  2. 若它是叶结点，逆序读取路径，得到叶到根字符串；与当前答案做字典序比较。
  3. 否则继续递归左右子树。
  4. 离开结点时删除路径末尾字符，恢复现场，供兄弟子树复用。

复杂度与边界

时间：O(nh)（直接在每个叶子构造长度至多为 h 的候选；最坏可写作 O(n²)）。

空间：O(h) 递归栈与路径，另计答案字符串。

边界

  • 单结点树：该结点同时是根与叶。
  • 只有单侧子树：不能把“缺一个孩子”误判成叶子。
  • 前缀关系：直接使用语言内建字符串比较即可。
  • 高度很深时，递归可能触及语言调用栈限制。

正确性说明

路径不变式：每次执行 DFS 的叶结点分支时，路径数组恰好按根到该叶的顺序保存所有字符。因此逆序后恰好得到该叶到根的合法字符串。

覆盖性：DFS 会访问树中的每个结点，因此会抵达每个叶结点，每个合法候选都被比较一次。

最优性：答案初始为空；每看到一个候选，仅在答案为空或候选更小时替换。处理完所有叶子后，答案就是全部合法候选中的字典序最小者。

为什么回溯不会污染兄弟分支？

每层递归退出前恰好删除本层追加的一个字符，路径恢复为父结点进入子树前的状态，所以左右分支看到的公共前缀完全一致。

替代方案

从路径头部插入字符：递归时直接维护叶到当前结点的字符串，叶子处无需翻转，但频繁头插会产生较多字符串复制。

迭代 DFS：栈中保存 [结点, 根到结点路径]，避免递归深度问题；代价是每个状态携带字符串，额外分配更多。

按叶到根方向逐字符剪枝：看似可以提前比较，但遍历从根开始，候选的最高优先级字符在叶子，通常无法在到叶前可靠剪枝，复杂度与实现都不划算。

常见错误

  • 比较了根到叶字符串，而不是叶到根。
  • 使用 left == null || right == null 判断叶子；正确条件是两者都为空。
  • 递归返回时忘记 pop / deleteCharAt。
  • 用数字值拼字符串，而不是映射到 'a' + val。
  • 答案为空时直接比较，导致空字符串错误地永远最小。

面试追问

若树高可能达到百万怎么办？可改用显式栈，并设计父指针或持久化路径结构，避免调用栈溢出和整段字符串复制。
