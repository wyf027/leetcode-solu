Problem

题意与示例

给定 root，删除树中的一条父子边。删除后会得到两棵子树，分别计算节点值总和，返回所有合法删除方式中最大的两树之和乘积，并对 10⁹ + 7 取模。

输出：110

删除连接节点 1 与节点 2 的边，两部分和为 10 与 11，乘积为 110。

示例 2

示例 3

在所有父子边中选择使两侧节点值之和乘积最大的那一条。

示例 4

输入：root = [1,1]
输出：1

树中只有一条边可删，两棵单节点树的和均为 1。

下面的题解会解释如何不真的拆树，也能在线性时间内评估每一条边。

Solution

一次后序，枚举每个子树和

真正需要枚举的不是“边”，而是边下方那棵子树的节点值总和。

核心洞察

设整棵树总和为 T。切断某个非根节点与父节点的边后，该节点为根的子树和为 S，另一部分的和必然为 T − S。

product(S) = S × (T − S)

所以只需拿到每个节点的子树和，跳过根节点，并取乘积最大值。取模必须放在最大值确定之后。

完整过程

  1. 用后序遍历，让孩子先于父节点被处理。
  2. 计算并保存每个节点的子树和，同时得到根节点的总和 T。
  3. 枚举所有非根节点对应的 S，计算 S × (T − S)。
  4. 保存原始乘积的最大值，最后返回 best mod (10⁹+7)。

正确性证明

每条可删边都被覆盖。除根以外，每个节点恰有一条连向父节点的边；枚举非根节点，就与所有可删边一一对应。
每个候选乘积计算正确。删除节点 u 的父边后，一部分恰为以 u 为根的完整子树，和为 S(u)；其余节点和为 T − S(u)，因此乘积为 S(u) × (T − S(u))。
最终答案最优。算法比较了所有且仅有的合法删除方式对应的乘积，并返回其中最大者，所以结果就是题目要求的最大乘积。

复杂度

  • 时间：O(n)，每个节点处理常数次。
  • 空间：O(n)，保存遍历顺序与子树和。
  • 下方代码用显式栈，避免极端链状树引发递归栈溢出。

边界情况

  • 只有两个节点时，唯一一条边就是答案。
  • 高度接近 n 的链状树要避免深递归。
  • 乘积可能远超 32 位；Java/C++ 用 64 位，JavaScript 用 BigInt。
  • 根节点不能当作切下的子树，因为根没有父边。

替代方案

可以递归 DFS 两遍：第一遍求总和，第二遍边求子树和边更新答案。代码更短，空间为递归深度；但在 50,000 节点的退化树上，语言运行时可能栈溢出。也可把所有子树和放入数组后排序，寻找最接近 T/2 的值，但排序会升至 O(n log n)，没有必要。

面试追问

  • 为什么越接近一半通常越好？函数 S(T−S) 是开口向下的抛物线，在 T/2 处最大；但只能选择真实存在的子树和。
  • 节点值允许负数怎么办？枚举公式仍成立，但“接近一半”的直觉不再足够；直接比较所有候选仍正确。
  • 能否一遍完成？后序计算时总和尚未知，因此可先存所有子树和，再统一比较；仍然只需一次树遍历加一次数组扫描。

常见错误

  • 在比较候选前先取模，破坏原始乘积的大小关系。
  • 使用 32 位整数保存总和或乘积而溢出。
  • 把根的总和也作为候选，相当于删除一条不存在的父边。
  • 只贪心选择节点值或节点数量最接近一半，而不是比较子树和。
  • 忽略退化树深度，使递归实现发生栈溢出。

四种语言实现

四份代码均采用显式栈生成“父节点先入、逆序后序处理”的顺序，再计算子树和。

Javalong · 迭代后序
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    private static final long MOD = 1_000_000_007L;

    public int maxProduct(TreeNode root) {
        List<TreeNode> order = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);

        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            order.add(node);
            if (node.left != null) stack.push(node.left);
            if (node.right != null) stack.push(node.right);
        }

        Map<TreeNode, Long> sum = new IdentityHashMap<>();
        for (int i = order.size() - 1; i >= 0; i--) {
            TreeNode node = order.get(i);
            long left = node.left == null ? 0L : sum.get(node.left);
            long right = node.right == null ? 0L : sum.get(node.right);
            sum.put(node, left + right + node.val);
        }

        long total = sum.get(root);
        long best = 0L;
        for (TreeNode node : order) {
            if (node == root) continue;
            long part = sum.get(node);
            best = Math.max(best, part * (total - part));
        }
        return (int) (best % MOD);
    }
}

/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *   this.val = (val === undefined ? 0 : val);
 *   this.left = (left === undefined ? null : left);
 *   this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var maxProduct = function(root) {
  const MOD = 1000000007n;
  const order = [];
  const stack = [root];

  while (stack.length) {
    const node = stack.pop();
    order.push(node);
    if (node.left) stack.push(node.left);
    if (node.right) stack.push(node.right);
  }

  const sum = new Map();
  for (let i = order.length - 1; i >= 0; i--) {
    const node = order[i];
    const left = node.left ? sum.get(node.left) : 0n;
    const right = node.right ? sum.get(node.right) : 0n;
    sum.set(node, BigInt(node.val) + left + right);
  }

  const total = sum.get(root);
  let best = 0n;
  for (const node of order) {
    if (node === root) continue;
    const part = sum.get(node);
    const product = part * (total - part);
    if (product > best) best = product;
  }
  return Number(best % MOD);
};

            node = stack.pop()
            order.append(node)
            if node.left:

            if node.right:

        subtree_sum = {}

            left = subtree_sum.get(node.left, 0)

C++long long · 迭代后序
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class Solution {
public:
    int maxProduct(TreeNode* root) {
        static constexpr long long MOD = 1'000'000'007LL;
        vector<TreeNode*> order;
        vector<TreeNode*> stack = {root};

        while (!stack.empty()) {
            TreeNode* node = stack.back();
            stack.pop_back();
            order.push_back(node);
            if (node->left) stack.push_back(node->left);
            if (node->right) stack.push_back(node->right);
        }

        unordered_map<TreeNode*, long long> sum;
        for (auto it = order.rbegin(); it != order.rend(); ++it) {
            TreeNode* node = *it;
            long long left = node->left ? sum[node->left] : 0LL;
            long long right = node->right ? sum[node->right] : 0LL;
            sum[node] = node->val + left + right;
        }

        long long total = sum[root];
        long long best = 0;
        for (TreeNode* node : order) {
            if (node == root) continue;
            long long part = sum[node];
            best = max(best, part * (total - part));
        }
        return static_cast<int>(best % MOD);
    }
};
