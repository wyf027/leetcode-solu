3874. 具有恰好一个峰值的有效子数组

把每个峰值当作唯一锚点：相邻峰值决定“不能越过”的边界，左右端点选择相乘。

O(n) 时间 · O(n) 空间

题意

给定 nums 与 k。全局下标 i 是峰值，当且仅当 0 < i < n-1 且同时大于两个相邻元素。统计连续非空子数组 [l, r]：它只包含一个这样的全局峰值 i，并满足 i-l ≤ k、r-i ≤ k。

约束：1 ≤ n ≤ 10^5，-10^5 ≤ nums[i] ≤ 10^5，1 ≤ k ≤ n。

示例

nums = [1, 3, 2]，k = 1，输出 4：[3]、[1, 3]、[3, 2]、[1, 3, 2]。

题解：相邻峰值隔离 + 乘法原理

1. 找全局峰值

扫描内部下标，把所有满足 nums[i] > nums[i-1] 且 nums[i] > nums[i+1] 的位置放入有序列表 peaks。

2. 固定一个峰值 p

左端点至少要在前一个峰值之后，且不能离 p 超过 k：left = max(0, p-k, prevPeak+1)。右端点类似：right = min(n-1, p+k, nextPeak-1)。

3. 独立选择端点

任取 l ∈ [left,p] 与 r ∈ [p,right] 都恰好保留该峰值，贡献为 (p-left+1) × (right-p+1)。

边界

首尾元素永远不算峰值；没有峰值答案为 0；相邻峰值之间必须用前/后峰值阻断，不能只按 k 扩张。

复杂度与替代方案

峰值扫描与一次贡献累加均线性，时间 O(n)，空间 O(n)。可用双指针维护峰值窗口降到常数额外空间，但代码更难直接体现“前后峰值边界”。

面试追问与常见错误

追问：若要求恰好 t 个峰值，可在峰值下标数组上做窗口。常见错误：把子数组内部重新定义峰值，或没有排除其他全局峰值，导致重复计数。
