3856. 移除尾部元音字母

从字符串右端倒着走，遇到第一个辅音立刻停止：中间的元音永远不需要改动。

题意

给定只含小写英文字母的字符串 s，删除它尾部所有元音字母，返回剩下的字符串。元音只包含 a、e、i、o、u。 

s = "idea"  →  "id"
s = "day"   →  "day"
s = "aeiou" →  ""

约束：1 ≤ s.length ≤ 100，且 s 仅含小写英文字母。

尾部扫描模拟器

当前结果："idea"

先观察，再展开题解

按“向左扫描一步”：橙色字符会被裁掉；扫描到绿色的辅音后算法结束。

核心洞察：只需确定保留前缀的右边界

设 i = s.length - 1。只要 s[i] 是元音，就把 i 左移；循环结束时 s[0..i] 正是答案。若所有字符都是元音，i = -1，取长度为 0 的前缀即可。

完整过程

  1. 把指针放在最后一个字符。
  2. 元音：标记为删除并左移。
  3. 辅音或越界：停止并返回 s.substring(0, i + 1)。

边界与复杂度

  • 末尾是辅音：不删除任何字符。
  • 全是元音：返回空字符串。
  • 中间元音不在扫描尾部，必须保留。
  • 单字符元音与单字符辅音都应正确处理。

时间 O(n)，额外空间 O(1)（不计返回值）。

替代方案与面试追问

可以反复调用字符串裁剪，但每次构造新字符串会让意图更模糊。逆序扫描一次最直接。

追问

若允许大小写或 Unicode 元音，应把“是否元音”抽成明确的字符集合或规范化步骤；本题约束下仅需五个小写字符。

常见错误

不要删除字符串中间的元音；不要遗漏 i = -1 时的空串边界。

四语言可提交实现

Java

class Solution {
    public String trimTrailingVowels(String s) {
        int i = s.length() - 1;
        while (i >= 0 && "aeiou".indexOf(s.charAt(i)) >= 0) i--;
        return s.substring(0, i + 1);
    }
}

JavaScript

var trimTrailingVowels = function (s) {
  let i = s.length - 1;
  while (i >= 0 && "aeiou".includes(s[i])) i--;
  return s.slice(0, i + 1);
};

Python

class Solution:
    def trimTrailingVowels(self, s: str) -> str:
        i = len(s) - 1
        while i >= 0 and s[i] in "aeiou":
            i -= 1
        return s[:i + 1]

C++

class Solution {
public:
    string trimTrailingVowels(string s) {
        int i = (int)s.size() - 1;
        while (i >= 0 && string("aeiou").find(s[i]) != string::npos) --i;
        return s.substr(0, i + 1);
    }
};
