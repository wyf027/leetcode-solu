Count Vowel Substrings of a String

一段连续字符，五种元音，一个计数问题。先读规则与示例，再动手观察字符区间；需要推导时，展开页面底部的题解。

01 / 题目与规则

给定字符串 word，返回满足以下两条规则的连续、非空子字符串数量：

  • 其中的每个字符都属于 a、e、i、o、u。
  • 这五种元音都至少出现一次，出现顺序不限，也允许重复。

按起止位置统计子字符串；即使内容相同，位置不同也分别计数。字符不能跳选。

参数：word: string → 返回：integer
约束：1 ≤ word.length ≤ 100；word 只包含小写英文字母。

官方示例

示例 1

输入：word = "aeiouu"
输出：2

有效区间为 [0,4] 的 aeiou 和 [0,5] 的 aeiouu。

示例 2

输入：word = "unicornarihan"
输出：0

字符串没有全部五种元音，因此没有有效子字符串。

示例 3

输入：word = "cuaieuouac"
输出：7

七个区间（下标从 0 开始）：

[1,6] uaieuo    [1,7] uaieuou
[1,8] uaieuoua  [2,6] aieuo
[2,7] aieuou    [2,8] aieuoua
[3,8] ieuoua

示例 4 · 中文题面

输入：word = "bbaeixoubb"
输出：0

任何覆盖全部五种元音的连续区间都包含辅音 x，因此无效。

04 / 独立题解

完成思考后，再查看推导与实现。

核心洞察：固定起点，向右收集五种元音

长度最多 100，枚举每个起点与终点足够简单。对固定起点 i，向右扩展终点 j：遇到辅音就结束这个起点；只要五种元音收集齐，每扩展一次就新增一个有效子字符串。

用五位二进制数 mask 存储是否出现过各元音：a → 0，e → 1，i → 2，o → 3，u → 4。看到第 k 种时执行 mask |= 1 << k。当 mask == 31（二进制 11111）时，恰好五种都出现。

完整过程

  1. 答案初始化为 0，依次选择起点 i = 0 … n−1。
  2. 每换一个起点，将 mask 清零。
  3. 终点 j 从 i 向右走，在 aeiou 中查找 word[j]。
  4. 若查不到，执行 break，转到下一个起点。
  5. 否则点亮对应位；若掩码为 31，答案加一。继续扩展，不提前结束。
  6. 所有起点处理完毕后返回答案。

以 aeiouu 为例：起点 0 的掩码依次为 1、3、7、15、31、31，最后两步各计数一次。后续起点都缺少 a，所以总数为 2。

正确性说明

不变式：处理当前 j 后，若未遇到辅音，mask 精确表示区间 [i,j] 出现的元音种类。初始为空；按位或只加入当前字符所属种类，因而不变式一直成立。

可靠性：计数时该区间没有辅音且掩码为 31，因此满足两条定义。完整性：任一合法区间 [l,r] 在起点 i=l 的扩展中不会提前碰到辅音，必定会走到 j=r 并计数。不重复：每对起止下标只被访问一次。

遇到辅音后，更长的同起点区间依然包含该辅音，所以停止扩展不会漏掉有效答案。

边界与复杂度

  • 长度小于 5 或缺少某种元音时返回 0；无需特殊分支。
  • 重复元音只设置同一位，不改变种类数；但新的终点仍可能产生新答案。
  • 辅音隔开不同段，合法子字符串不能跨段。
  • 最坏时间 O(n²)，辅助空间 O(1)。查找最多扫描 5 个字符，是常数时间。
  • 答案不超过 n(n+1)/2 ≤ 5050，32 位整数足够。可视化保存历史步骤使用额外 O(n²) 状态，不是提交代码的空间开销。

四语言完整实现

沿用官方函数签名；均为未执行、待补验证的提交代码。

Java

class Solution {
    public int countVowelSubstrings(String word) {
        int answer = 0;
        String vowels = "aeiou";
        // ponytail: n <= 100，使用平方枚举；大输入可改为最近位置法。
        for (int i = 0; i < word.length(); i++) {
            int mask = 0;
            for (int j = i; j < word.length(); j++) {
                int k = vowels.indexOf(word.charAt(j));
                if (k == -1) break;
                mask |= 1 << k;
                if (mask == 31) answer++;
            }
        }
        return answer;
    }
}

C++

#include <string>
using namespace std;

class Solution {
public:
    int countVowelSubstrings(string word) {
        int answer = 0;
        const string vowels = "aeiou";
        int n = static_cast<int>(word.size());
        // ponytail: n <= 100，平方枚举；大输入改为最近位置法。
        for (int i = 0; i < n; ++i) {
            int mask = 0;
            for (int j = i; j < n; ++j) {
                auto k = vowels.find(word[j]);
                if (k == string::npos) break;
                mask |= 1 << k;
                if (mask == 31) ++answer;
            }
        }
        return answer;
    }
};

替代方案

集合枚举：用集合代替掩码，集合大小达到 5 即计数。仍是 O(n²) 时间、O(1) 辅助空间，适合不熟悉位运算时使用。

最近位置法（O(n)）：记录五种元音最后出现的位置 last[5]，初始均为 −1；记录最近辅音下标 bad = −1。扫描右端点 r，元音更新对应位置，辅音更新 bad。令 m = min(last)，以 r 结尾的合法起点恰好满足 bad < l ≤ m，新增数量为 max(0, m − bad)。旧位置无需清零，因为辅音边界会过滤它们。

常见错误

  • 只检查包含五种元音，却允许夹杂辅音。
  • 遇到辅音用 continue 跳过，错误地把不连续的字符连接起来。
  • 收集齐后立即 break，漏掉继续扩展的合法区间。
  • 用字符总数代替种类数，例如把五个 a 当作五种元音。
  • 更换起点忘记清空掩码；或把按位置计数误写成字符串去重。
  • 未判断 indexOf/find 的失败结果就进行移位。

面试追问

输入长度增长到十万怎么办？ 使用最近位置法，将重复的区间扫描改为每个终点的一次贡献计算。

为什么不对答案做字符串去重？ 子字符串按位置定义；相同内容的不同区间也是不同对象。

改为恰好包含 k 种元音呢？ 在各纯元音段上用滑动窗口计算“至多 k 种”减去“至多 k−1 种”，并在遇到辅音时重置窗口。
