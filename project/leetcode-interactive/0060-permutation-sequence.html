Dispatcher manual

题解

Core insight

每个首位都占据相同大小的排列区块

当还剩 m 个数字时，固定任意一个数字作为当前位，后面都有 (m - 1)! 种排列。因此可直接用零基排名除以区块大小，得到本位应选择剩余数字中的第几个，而无需生成前面的排列。

Why k - 1

先转零基，整除才落在正确区块

题目把第一个排列编号为 1，而数组索引从 0 开始。令 rank = k - 1，则 index = rank / blockSize；选走该数字后，把 rank %= blockSize 作为新区块内的排名。

Full route

完整过程

  1. SIGNAL A

    准备候选数字 [1, 2, ..., n]，预计算 0! 到 (n-1)!。

  2. SIGNAL B

    将题目的一基编号转换为 rank = k - 1。

  3. SIGNAL C

    用 rank / (m-1)! 定位候选下标，取出并从列表删除。

  4. SIGNAL D

    令 rank %= (m-1)!，重复直到所有数字都被编组。

Boundaries

边界情况

  • n = 1, k = 1：直接选择唯一数字。
  • k = 1：每次下标都是 0，结果为升序。
  • k = n!：零基后每次选择最后一个候选，结果为降序。
  • 最后只剩一个数字时区块大小是 0! = 1。

Complexity

复杂度

时间：O(n²)。每位定位是 O(1)，但数组或列表删除需要移动后续元素。

空间：O(n)，用于阶乘表和剩余数字列表。

Alternatives

替代方案取舍

回溯生成到第 k 个排列要枚举大量结果；连续执行 k - 1 次 next permutation 是 O(kn)。若 n 很大，可用树状数组把第 index 个未使用数字查询降至 O(log n)，总时间 O(n log n)，但本题 n ≤ 9，面试首选清晰的数组删除实现。

Interview follow-ups

面试追问

为什么固定首位后一定有 (n - 1)! 个排列？

首位固定后，剩余 n - 1 个互不相同数字可以任意排列，数量按排列定义就是 (n - 1)!。

如何反向求一个排列的字典序排名？

逐位统计当前数字在未使用数字中有多少个更小值，把该数量乘以剩余位数的阶乘后累加，最后加 1 转回一基排名。

若数字含重复元素怎么办？

区块大小不再统一为阶乘，需要除以各重复元素计数的阶乘；选每个候选前动态计算对应的多重集排列数。

Wrong switches

常见错误

  • 忘记执行 k--：会让每个阶乘边界上的编号落入下一块。
  • 用 m! 作为区块大小：当前位固定后只排列剩余 m - 1 位，应使用 (m - 1)!。
  • 选中后没有删除数字：会产生重复数字，且后续候选下标含义失效。
  • 遗漏 0! = 1：最后一位会出现除零或数组越界。

class Solution {
    public String getPermutation(int n, int k) {
        int[] factorial = new int[n];
        factorial[0] = 1;
        for (int i = 1; i < n; i++) {
            factorial[i] = factorial[i - 1] * i;
        }

        List<Integer> numbers = new ArrayList<>();
        for (int value = 1; value <= n; value++) {
            numbers.add(value);
        }

        StringBuilder answer = new StringBuilder();
        k--;
        for (int remaining = n; remaining >= 1; remaining--) {
            int blockSize = factorial[remaining - 1];
            int index = k / blockSize;
            answer.append(numbers.remove(index));
            k %= blockSize;
        }
        return answer.toString();
    }
}

var getPermutation = function (n, k) {
    const factorial = Array(n).fill(1);
    for (let i = 1; i < n; i++) {
        factorial[i] = factorial[i - 1] * i;
    }

    const numbers = Array.from({ length: n }, (_, index) => index + 1);
    let answer = "";
    k--;

    for (let remaining = n; remaining >= 1; remaining--) {
        const blockSize = factorial[remaining - 1];
        const index = Math.floor(k / blockSize);
        answer += numbers.splice(index, 1)[0];
        k %= blockSize;
    }

    return answer;
};
class Solution:
    def getPermutation(self, n: int, k: int) -> str:
        factorial = [1] * n
        for i in range(1, n):
            factorial[i] = factorial[i - 1] * i

        numbers = list(range(1, n + 1))
        answer = []
        k -= 1

        for remaining in range(n, 0, -1):
            block_size = factorial[remaining - 1]
            index = k // block_size
            answer.append(str(numbers.pop(index)))
            k %= block_size

        return "".join(answer)
