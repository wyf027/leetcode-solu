寻找二叉搜索树中的目标节点

给定记录员工编号的二叉搜索树与目标排名 cnt，返回第 cnt 大的员工编号。先操作雷达观察访问轨迹，再到页面底部决定是否展开完整题解。

Easy树 · 二叉搜索树1 ≤ cnt ≤ 节点数

题意

某公司将员工编号组织成二叉搜索树。给定 root 与正整数 cnt，返回树中第 cnt 大的员工编号。

示例 1：root = [7, 3, 9, 1, 5]，cnt = 2，输出 7。

示例 2：root = [10, 5, 15, 2, 7, null, 20, 1, null, 6, 8]，cnt = 4，输出 8。

保证 1 ≤ cnt ≤ 二叉搜索树元素个数；层序数组中的 null 代表空位置。

怎么玩

  1. 输入层序树与目标排名 cnt。
  2. 每点一次“下一步”，雷达抵达一个更小的编号。
  3. 到第 cnt 个绿色节点即找到答案。可用 ←/→，空格自动播放。

题解：反向中序 + 显式栈提前停止

BST 的右子树都比当前节点大、左子树都比当前节点小。用显式栈模拟右、根、左的反向中序时，访问序列严格降序；弹出第 cnt 个节点就立即返回。

完整过程

  1. 沿右指针不断入栈，先走到当前子树的最大节点。
  2. 弹出栈顶并让 cnt -= 1。
  3. 若 cnt == 0，直接返回当前节点值。
  4. 否则转向当前节点的左子树，继续寻找较小编号。

边界与复杂度

cnt = 1 返回最右节点；单节点树直接命中；偏斜树仍正确。访问 cnt 个候选节点就停止，时间 O(h + cnt)（最坏 O(n)），显式栈 O(h)，h 是树高。

替代方案与面试追问

也可递归执行右、根、左并用全局计数提前停止；完整中序遍历后取倒数第 cnt 个则需 O(n) 额外数组空间且无法提前停止。追问如何到 O(h) 查第 k 大：可在节点上维护右子树大小，插入与查询时更新它。

常见错误

  • 写成左、根、右，得到的是第 cnt 小。
  • 弹栈后忘记转向左子树，遗漏较小编号。
  • 将层序数组直接当 BST，而没有确认左小右大。
class Solution {
    public int findTargetNode(TreeNode root, int cnt) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        while (root != null || !stack.isEmpty()) {
            while (root != null) {
                stack.push(root);
                root = root.right;
            }
            root = stack.pop();
            if (--cnt == 0) return root.val;
            root = root.left;
        }
        return -1;
    }
}
