数组的最大公因数排序

GCD Sort of an Array · 用受限交换，抵达有序终点。

234 / 300 · 免费题 · 官方题目

01 / 问题

给定整数数组 nums。每次任选两个位置 i、j，仅当这两个位置上的数满足 gcd(nums[i], nums[j]) > 1 时，才允许交换它们。gcd 表示最大公因数；位置不必相邻，操作次数不限，也可以不操作。

判断能否让数组按非递减顺序排列，能则返回 true，否则返回 false。

参数与返回值
gcdSort(nums: integer[]) → boolean
1 ≤ nums.length ≤ 3 × 10⁴
2 ≤ nums[i] ≤ 10⁵

先独立思考。核心算法与四语言代码位于底部，默认收起。

02 / 官方示例

示例 1

输入：nums = [7,21,3]
输出：true

交换 7 与 21（gcd = 7）→ [21,7,3]；交换 21 与 3（gcd = 3）→ [3,7,21]。

示例 2

输入：nums = [5,2,6,2]
输出：false

5 与其他元素的最大公因数都是 1，因此无法移动到排序所需的位置。

示例 3

输入：nums = [10,5,9,3,15]
输出：true

交换 10 与 15（gcd = 5）→ [15,5,9,3,10]；交换 15 与 3（gcd = 3）→ [3,5,9,15,10]；交换 10 与 15（gcd = 5）→ [3,5,9,10,15]。

05 / 独立题解

准备好后再展开，比较你的思路。

核心洞察：可达，不等于直接可换

7 与 3 不能直接交换，但 21 能成为桥梁。将数组里的数看作节点，共享质因子的数连边。同一连通分量内部，元素能通过合法交换完成任意排列；不同分量之间不能互换。

7 — 质因子 7 — 21 — 质因子 3 — 3
质因子是虚拟连接点，不是新增的数组元素。

令 target 为 nums 的排序副本。对每个位置 i，只需判断 nums[i] 与 target[i] 是否属于同一连通分量。全部相同则返回 true。

完整过程

  1. 设最大值为 M。初始化 spf[x] = x，用埃氏筛构建最小质因子表：对每个质数 p，从 p² 开始标记尚未处理的倍数。
  2. 建立值域 [0,M] 的并查集，使用路径压缩与按大小合并。
  3. 分解每个实际出现的原值 v。每取出一个质因子 p，合并 v 与 p；从临时变量 x 中除去所有 p，继续分解。
  4. 复制数组并按数值排序。
  5. 逐位置比较原值和目标值的根节点。若不一致，立即返回 false；否则最终返回 true。

示例 2 中 {2,6} 属于一个分量，{5} 独立。目标 [2,2,5,6] 的位置 0 需要 2，但原值 5 无法进入该分量，因而失败。

正确性证明

建图等价：gcd(a,b) > 1 当且仅当两数共享质因子。因此数值—质因子二分图与合法交换图在数值节点上有相同连通关系。只对实际出现的数建立质因子连接，未出现的合数不会成为虚假桥梁。

必要性：每次合法交换只涉及同一分量内的元素，所以各位置的分量标签不会改变。原值与目标值属于不同分量时，该位置不能到达目标。

充分性：把重复元素也视为独立的带标签元素。连通图中沿路径的边换位可以交换两个端点并恢复中间元素，进而生成分量内部任意排列。边的合法性由元素值决定，与当前下标无关。若每个位置的原值和目标值同分量，各分量占据的位置集合就与目标一致，且多重集合相同。因此可以在每个分量内部重新排列，得到整个排序目标。

边界与复杂度

  • 单元素、已经有序、全相等：允许零次操作，答案为 true。
  • 重复数值无需独立并查集节点，排序副本保留出现次数。
  • 互质的两个数可能间接连通，不能仅比较它们的 gcd。
  • 题目不含 1；若扩展到 1，它不能参与任何合法交换。

n 为长度，M 为最大值。筛表 O(M log log M)，分解 O(n log M)，并查集操作带反阿克曼因子 α(M)，排序 O(n log n)。总时间上界 O(M log log M + n log M · α(M) + n log n)，额外空间 O(M + n)，含排序副本。

替代方案

可使用下标并查集，记录每个质因子首次出现的下标，后续拥有相同因子的下标与之合并，再比较各分量内部原值和目标值的多重集合。两两求 gcd 建图更直观，但 O(n² log M) 不适合本题上限。也可以枚举每个质数的倍数，只连接实际出现的数。

常见错误

  • 只检查 gcd(nums[i], target[i])：遗漏间接连接。
  • 将值域中所有合数都与因子合并：引入数组里不存在的桥梁。
  • 原地排序再与自己比较：丢失原位置状态。
  • 分解时忘记合并原值 v，或没有去掉质因子的所有幂次。
  • JavaScript 默认 sort() 按字符串排序，必须传数值比较函数。

面试追问

如何输出交换序列？需要保留合法边生成树、元素位置和路径；并查集只回答连通性，也不保证最少交换次数。

M 特别大？用到 √M 的质数试除，并用稀疏映射维护质因子与下标，避免分配完整值域。

如果只允许相邻交换？本结论不再适用，充分性证明依赖任意位置的合法元素交换。

/** @param {number[]} nums @return {boolean} */
var gcdSort = function(nums) {
    let m = 0;
    for (const v of nums) m = Math.max(m, v);
    const spf = Array.from({length: m + 1}, (_, i) => i);
    for (let p = 2; p * p <= m; p++) {
        if (spf[p] !== p) continue;
        for (let k = p * p; k <= m; k += p)
            if (spf[k] === k) spf[k] = p;
    }
    const parent = Array.from({length: m + 1}, (_, i) => i);
    const size = new Array(m + 1).fill(1);
    function find(x) {
        while (parent[x] !== x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    function union(a, b) {
        a = find(a); b = find(b);
        if (a === b) return;
        if (size[a] < size[b]) [a, b] = [b, a];
        parent[b] = a;
        size[a] += size[b];
    }
    for (const v of nums) {
        let x = v;
        while (x > 1) {
            const p = spf[x];
            union(v, p);
            while (x % p === 0) x /= p;
        }
    }
    const target = [...nums].sort((a, b) => a - b);
    return nums.every((v, i) => find(v) === find(target[i]));
};

from typing import List

class Solution:
    def gcdSort(self, nums: List[int]) -> bool:
        m = max(nums)
        spf = list(range(m + 1))
        p = 2
        while p * p <= m:
            if spf[p] == p:
                for k in range(p * p, m + 1, p):
                    if spf[k] == k:
                        spf[k] = p
            p += 1
        parent = list(range(m + 1))
        size = [1] * (m + 1)

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            a, b = find(a), find(b)
            if a == b:
                return
            if size[a] < size[b]:
                a, b = b, a
            parent[b] = a
            size[a] += size[b]

        for v in nums:
            x = v
            while x > 1:
                p = spf[x]
                union(v, p)
                while x % p == 0:
                    x //= p
        return all(find(a) == find(b)
                   for a, b in zip(nums, sorted(nums)))

Java

import java.util.Arrays;

class Solution {
    private int[] parent, size;

    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    private void union(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (size[a] < size[b]) {
            int t = a; a = b; b = t;
        }
        parent[b] = a;
        size[a] += size[b];
    }
    public boolean gcdSort(int[] nums) {
        int m = 0;
        for (int v : nums) m = Math.max(m, v);
        int[] spf = new int[m + 1];
        parent = new int[m + 1];
        size = new int[m + 1];
        for (int i = 0; i <= m; i++) {
            spf[i] = parent[i] = i;
            size[i] = 1;
        }
        for (int p = 2; p * p <= m; p++) {
            if (spf[p] != p) continue;
            for (int k = p * p; k <= m; k += p)
                if (spf[k] == k) spf[k] = p;
        }
        for (int v : nums) {
            int x = v;
            while (x > 1) {
                int p = spf[x];
                union(v, p);
                while (x % p == 0) x /= p;
            }
        }
        int[] target = nums.clone();
        Arrays.sort(target);
        for (int i = 0; i < nums.length; i++)
            if (find(nums[i]) != find(target[i])) return false;
        return true;
    }
}

#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;

class Solution {
    vector<int> parent, sz;
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a;
        sz[a] += sz[b];
    }
public:
    bool gcdSort(vector<int>& nums) {
        int m = *max_element(nums.begin(), nums.end());
        vector<int> spf(m + 1);
        iota(spf.begin(), spf.end(), 0);
        for (int p = 2; p * p <= m; ++p) {
            if (spf[p] != p) continue;
            for (int k = p * p; k <= m; k += p)
                if (spf[k] == k) spf[k] = p;
        }
        parent.resize(m + 1);
        iota(parent.begin(), parent.end(), 0);
        sz.assign(m + 1, 1);
        for (int v : nums) {
            int x = v;
            while (x > 1) {
                int p = spf[x];
                unite(v, p);
                while (x % p == 0) x /= p;
            }
        }
        vector<int> target = nums;
        sort(target.begin(), target.end());
        for (int i = 0; i < (int)nums.size(); ++i)
            if (find(nums[i]) != find(target[i])) return false;
        return true;
    }
};
