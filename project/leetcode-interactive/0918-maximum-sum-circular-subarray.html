环形子数组的最大和

Maximum Sum Circular Subarray

先观察环形数组的两种答案形态，再决定如何把“跨越首尾”变成一个熟悉的问题。

题目

给定长度为 n 的环形整数数组 nums，返回其中一个非空连续子数组的最大元素和。末尾与开头相邻；每个原数组位置在所选子数组中最多出现一次。

输入：nums = [1,-2,3,-2] 输出：3 解释：[3] 的和最大。
输入：nums = [5,-3,5] 输出：10 解释：跨越首尾选择 [5,5]。
输入：nums = [-3,-2,-3] 输出：-2 解释：必须非空，选择 [-2]。

约束

  • n == nums.length
  • 1 ≤ n ≤ 3 × 10⁴
  • -3 × 10⁴ ≤ nums[i] ≤ 3 × 10⁴

环上双轨 Kadane

示例 [5,-3,5]。逐步扫描，同时维护最大连续和与最小连续和；虚线粉色轨道代表将被“挖掉”的中间最小段。

题解

核心洞察

答案只有两类：不跨首尾时，就是普通最大子数组和 maxSum；跨首尾时，等价于保留总和并挖掉中间一个最小连续子数组，因此为 total - minSum。

唯一例外：若所有元素都为负，最小子数组会覆盖整个数组，补集为空，不符合“非空”。此时直接返回 maxSum。

完整过程

  1. 用 Kadane 更新以当前位置结尾的最大和，并维护全局最大和。
  2. 对称地更新以当前位置结尾的最小和，并维护全局最小和。
  3. 累计数组总和。
  4. 若 maxSum < 0 返回它；否则返回 max(maxSum, total - minSum)。

正确性

任意合法答案若不跨边界，Kadane 必能在所有普通连续段中取得其最大值。若跨边界，它由一个后缀和一个前缀组成，其未选择部分必是中间的普通连续段；要使选择和最大，就应让未选段之和最小，所以最优值为总和减最小子数组和。全负时排除空补集后，最佳非空答案即最大的单个元素，由 maxSum 给出。因此算法覆盖且正确处理所有情况。

边界与复杂度

  • 单元素：直接得到该元素。
  • 全负：走特殊分支。
  • 最优答案不跨界或跨界：取两者较大值。

时间复杂度 O(n)，额外空间 O(1)。

替代方案

可以复制数组后用长度受限的前缀和 + 单调队列求解，时间 O(n)、空间 O(n)；也可分治，但本题的双 Kadane 更短、更直接。

面试追问

  • 为什么不能把数组复制后直接跑普通 Kadane？因为可能选取超过 n 个元素。
  • 如何返回区间？在最大/最小 Kadane 中同时记录起止位置，跨界答案取最小段的补集。
  • 为什么全负要特判？因为 total - minSum = 0 对应空子数组。

常见错误

  • 遗漏全负特判。
  • 把最小子数组初始化为 0，错误地允许空段。
  • 只考虑普通最大子数组，没有考虑跨首尾。

完整代码

class Solution {
    public int maxSubarraySumCircular(int[] nums) {
        int total = 0, curMax = 0, maxSum = nums[0];
        int curMin = 0, minSum = nums[0];
        for (int x : nums) {
            curMax = Math.max(x, curMax + x);
            maxSum = Math.max(maxSum, curMax);
            curMin = Math.min(x, curMin + x);
            minSum = Math.min(minSum, curMin);
            total += x;
        }
        return maxSum < 0 ? maxSum : Math.max(maxSum, total - minSum);
    }
}
