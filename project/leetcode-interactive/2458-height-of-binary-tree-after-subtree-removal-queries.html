01 / 题目

给定二叉树根节点 root，共有 n 个节点，节点值恰为互不相同的 1…n。再给定长度为 m 的查询数组 queries。对于每个查询值，移除该值对应节点及其全部后代，返回剩余树的高度，按查询顺序组成数组。

每次查询都从原树开始，移除操作不会累积；查询不会移除根节点。高度按边数计算，只有根节点时高度为 0。

treeQueries(root: TreeNode, queries: integer[]) → integer[]

官方示例 1

输入：root = [1,3,4,2,null,6,5,null,null,null,null,null,7], queries = [4]
输出：[2]

移除节点 4 的整棵子树（含 6、5、7），最长路径剩下 1 → 3 → 2，共 2 条边。

官方示例 2

输入：root = [5,8,9,2,1,3,7,4,6], queries = [3,2,4,8]
输出：[3,2,3,2]
  • 移除 3：路径 5 → 8 → 2 → 4，高度 3。
  • 移除 2：路径 5 → 8 → 1，高度 2。
  • 移除 4：路径 5 → 8 → 2 → 6，高度 3。
  • 移除 8：路径 5 → 9 → 3，高度 2。

完整约束

  • 树中节点数为 n，2 ≤ n ≤ 10⁵。
  • 1 ≤ Node.val ≤ n，所有节点值互不相同。
  • m = queries.length，1 ≤ m ≤ min(n, 10⁴)。
  • 1 ≤ queries[i] ≤ n，且 queries[i] ≠ root.val。

示例中的 root 使用层序数组表示，null 表示缺失子节点；提交函数接收 TreeNode，而非数组。

03 / 独立题解

准备好后，展开思路、交互和四语言代码。

把子树，折叠成连续的一段

核心洞察：先序 DFS 会连续访问某个节点的全部后代。删除子树，等价于从 DFS 序列中去掉一个连续区间。剩余节点的深度不变，因此答案就是区间外的最大深度。

使用官方示例 2；选项切换后恢复原树。粉色虚线表示移除，青色粗线节点表示仍可达到的最大深度。

完整过程

  1. 显式栈记录节点与深度，根深度为 0。先压右孩子再压左孩子，得到先序数组 nodes 和深度数组 D。
  2. 令 tin[v] 为节点 v 在先序数组中的下标。反向遍历 nodes，孩子先于父亲处理，计算 size[v] = 1 + size[left] + size[right]，空孩子大小为 0。
  3. 子树对应半开区间 [L,R) = [tin[v], tin[v]+size[v])。
  4. pre[k] 表示 D[0…k) 的最大值；suf[k] 表示 D[k…n) 的最大值。空区间最大值取 −1。
  5. 每个查询直接返回 max(pre[L], suf[R])。不需要真的修改树，也无需为下一次查询恢复数据。

正确性证明

连续性：先序遍历从 v 开始后，必须处理完其左右子树才离开；归纳可知 v 及全部后代在序列中恰好占据 size[v] 个连续位置。

深度保持：留下的节点不在 v 的子树中，其根路径不会经过 v，因此根到该节点的边数不变。

取最大值：移除区间外只剩前缀 [0,L) 和后缀 [R,n)。前后缀最大值覆盖所有保留节点，二者最大值就是剩余树的高度。

独立性：每次只读取原树预处理数据，因此回答严格对应独立移除。

边界与复杂度

  • 只剩根：最大保留深度为 0。
  • 删除叶子：区间长度为 1；另一条同长路径可能保留。
  • 区间到达 n：使用 suf[n] = −1，无越界。
  • 重复查询返回相同值，不能累积删除。
  • 链状树深度可达 n−1，四份实现均用显式栈，避免递归栈溢出。

预处理 O(n)；每次查询 O(1)；总时间 O(n+m)。辅助空间 O(n)，返回数组另占 O(m)。

替代方案

两趟 DFS / 换根：先计算以边计的子树高度 h，空树 h = −1；再传递子树外最大深度 out。对父 p 的孩子 c，令 s 为兄弟，out[c] = max(out[p], depth[p] + 1 + h[s])，根的 out 设 −1。总时间同为 O(n+m)。

每层最大与次大：保存同层各节点子树高度的前两名，查询时排除当前节点；同高必须保留两份，只有一个节点的层需要特殊处理。

逐次扫描：每次跳过被删子树再求高度，O(nm)，仅适合小规模推演；最大约束下不宜使用。

常见错误

  • 把节点数当高度，所有结果多 1。
  • 使用 BFS 序：子树在层序中通常不连续。
  • 混淆闭区间与半开区间，把 suf[R] 写成 suf[R+1]。
  • 用节点值代替 DFS 下标；值只保证唯一，不保证顺序。
  • 只移除节点，遗漏其后代。
  • 递归处理 10⁵ 深度链，存在调用栈溢出风险。

面试追问

如果删除会累积？静态前后缀会失效。仍可使用 DFS 区间，将删除变为区间赋值 −1，再用带懒标记的线段树维护全局最大深度。

如果是多叉树？子树连续性仍成立，size 改为累加全部孩子。

如果边有权重？改存根路径权重和；若权重可能为负，空区间哨兵需用负无穷，并明确树高定义。

需要返回一条最长路径？最大值同时记录对应节点，再沿父指针回溯到根。

Java

import java.util.*;

// TreeNode 由 LeetCode 提供：int val; TreeNode left, right;
class Solution {
    public int[] treeQueries(TreeNode root, int[] queries) {
        List<TreeNode> nodes = new ArrayList<>();
        List<Integer> depth = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        Deque<Integer> levels = new ArrayDeque<>();
        stack.push(root);
        levels.push(0);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            int d = levels.pop();
            nodes.add(node);
            depth.add(d);
            if (node.right != null) {
                stack.push(node.right);
                levels.push(d + 1);
            }
            if (node.left != null) {
                stack.push(node.left);
                levels.push(d + 1);
            }
        }
        int n = nodes.size();
        int[] tin = new int[n + 1], size = new int[n + 1];
        for (int i = 0; i < n; i++) tin[nodes.get(i).val] = i;
        for (int i = n - 1; i >= 0; i--) {
            TreeNode node = nodes.get(i);
            size[node.val] = 1 + (node.left == null ? 0 : size[node.left.val])
                               + (node.right == null ? 0 : size[node.right.val]);
        }
        int[] pre = new int[n + 1], suf = new int[n + 1];
        pre[0] = suf[n] = -1;
        for (int i = 0; i < n; i++) pre[i + 1] = Math.max(pre[i], depth.get(i));
        for (int i = n - 1; i >= 0; i--) suf[i] = Math.max(suf[i + 1], depth.get(i));
        int[] answer = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int v = queries[i];
            answer[i] = Math.max(pre[tin[v]], suf[tin[v] + size[v]]);
        }
        return answer;
    }
}

/**
 * TreeNode 由 LeetCode 提供，字段为 val、left、right。
 * @param {TreeNode} root
 * @param {number[]} queries
 * @return {number[]}
 */
var treeQueries = function(root, queries) {
    const nodes = [], depth = [], stack = [[root, 0]];
    while (stack.length) {
        const [node, d] = stack.pop();
        nodes.push(node);
        depth.push(d);
        if (node.right) stack.push([node.right, d + 1]);
        if (node.left) stack.push([node.left, d + 1]);
    }
    const n = nodes.length;
    const tin = new Int32Array(n + 1);
    const size = new Int32Array(n + 1);
    for (let i = 0; i < n; i++) tin[nodes[i].val] = i;
    for (let i = n - 1; i >= 0; i--) {
        const node = nodes[i];
        size[node.val] = 1 + (node.left ? size[node.left.val] : 0)
                           + (node.right ? size[node.right.val] : 0);
    }
    const pre = new Int32Array(n + 1);
    const suf = new Int32Array(n + 1);
    pre[0] = suf[n] = -1;
    for (let i = 0; i < n; i++) pre[i + 1] = Math.max(pre[i], depth[i]);
    for (let i = n - 1; i >= 0; i--) suf[i] = Math.max(suf[i + 1], depth[i]);
    return queries.map(v => Math.max(pre[tin[v]], suf[tin[v] + size[v]]));
};

Python

from typing import List, Optional

# TreeNode 由 LeetCode 提供，字段为 val、left、right。
class Solution:
    def treeQueries(self, root: Optional[TreeNode], queries: List[int]) -> List[int]:
        nodes, depth = [], []
        stack = [(root, 0)]
        while stack:
            node, d = stack.pop()
            nodes.append(node)
            depth.append(d)
            if node.right:
                stack.append((node.right, d + 1))
            if node.left:
                stack.append((node.left, d + 1))
        n = len(nodes)
        tin, size = [0] * (n + 1), [0] * (n + 1)
        for i, node in enumerate(nodes):
            tin[node.val] = i
        for node in reversed(nodes):
            size[node.val] = (1 + (size[node.left.val] if node.left else 0)
                               + (size[node.right.val] if node.right else 0))
        pre, suf = [-1] * (n + 1), [-1] * (n + 1)
        for i in range(n):
            pre[i + 1] = max(pre[i], depth[i])
        for i in range(n - 1, -1, -1):
            suf[i] = max(suf[i + 1], depth[i])
        return [max(pre[tin[v]], suf[tin[v] + size[v]]) for v in queries]

C++

#include <algorithm>
#include <utility>
#include <vector>
using namespace std;

// TreeNode 由 LeetCode 提供：int val; TreeNode *left, *right;
class Solution {
public:
    vector<int> treeQueries(TreeNode* root, vector<int>& queries) {
        vector<TreeNode*> nodes;
        vector<int> depth;
        vector<pair<TreeNode*, int>> stack{{root, 0}};
        while (!stack.empty()) {
            auto [node, d] = stack.back();
            stack.pop_back();
            nodes.push_back(node);
            depth.push_back(d);
            if (node->right) stack.emplace_back(node->right, d + 1);
            if (node->left) stack.emplace_back(node->left, d + 1);
        }
        int n = static_cast<int>(nodes.size());
        vector<int> tin(n + 1), size(n + 1);
        for (int i = 0; i < n; ++i) tin[nodes[i]->val] = i;
        for (int i = n - 1; i >= 0; --i) {
            auto node = nodes[i];
            size[node->val] = 1 + (node->left ? size[node->left->val] : 0)
                                + (node->right ? size[node->right->val] : 0);
        }
        vector<int> pre(n + 1, -1), suf(n + 1, -1);
        for (int i = 0; i < n; ++i) pre[i + 1] = max(pre[i], depth[i]);
        for (int i = n - 1; i >= 0; --i) suf[i] = max(suf[i + 1], depth[i]);
        vector<int> answer;
        answer.reserve(queries.size());
        for (int v : queries)
            answer.push_back(max(pre[tin[v]], suf[tin[v] + size[v]]));
        return answer;
    }
};
