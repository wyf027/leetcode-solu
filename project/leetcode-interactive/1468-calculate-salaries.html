Problem brief

题目转述

根据员工所属公司的最高工资确定统一税率，返回每位员工四个原字段，其中 salary 改为四舍五入后的税后工资。

给定表 Salaries，每行记录一名员工的公司、员工编号、姓名和税前工资。复合键 (company_id, employee_id) 唯一标识一行。

对每家公司先求员工最高工资，再按该最高工资选取公司税率。公司内所有员工都使用这个税率。输出 company_id、employee_id、employee_name 与税后 salary，工资须四舍五入到最接近的整数；结果顺序任意。

!边界要精确：最高工资等于 1000 或 10000 时，都属于 24% 档。

Full editorial

题解：聚合一次，传播到每行

1

分组作用域

税率属于公司。先为每个 company_id 找到唯一的最高工资。

2

传播结果

用窗口函数把公司最高工资写到该公司的每一行，无须丢失员工字段。

3

最后取整

先乘保留比例，再用 ROUND 处理结果；不要预先把税额截断。

核心洞察与完整过程

  1. 窗口表达式 MAX(salary) OVER (PARTITION BY company_id) 为每行附上同公司的最高工资 max_salary。
  2. 用 CASE 对 max_salary 分类：低于 1000 保留 100%；不高于 10000 保留 76%；否则保留 51%。
  3. 将原工资乘以保留比例并 ROUND。外层只投影题目要求的四列。

边界

  • 公司最高工资为 999：0% 税率。
  • 恰为 1000 或 10000：24% 税率。
  • 为 10001：49% 税率。
  • 公司只有一名员工时，他自己的工资同时也是公司最高工资。

复杂度

设共有 n 行。逻辑上扫描数据并按公司聚合，时间复杂度通常为 O(n)；数据库可能因窗口分区执行排序，实际执行可达到 O(n log n)。中间状态为窗口执行所需，空间复杂度通常为 O(n)，具体取决于优化器。

正确性

对任意员工行 r，窗口分区恰好包含与 r 具有相同 company_id 的全部员工，所以得到的 max_salary 正是 r 所属公司的最高工资。CASE 的三个条件互斥且覆盖所有数值，因而选择且只选择题目规定的公司税率。用 r.salary 乘对应保留比例并取最近整数，正好得到要求的税后工资。故每行输出正确。

替代方案

也可先 GROUP BY company_id 得到每家公司最高工资，再与 Salaries 按 company_id 连接。它兼容不支持窗口函数的旧数据库，语义同样清晰，但查询多一个聚合子表与连接步骤。

WITH salary_rank AS (
    SELECT
        company_id,
        employee_id,
        employee_name,
        salary,
        MAX(salary) OVER (PARTITION BY company_id) AS max_salary
    FROM Salaries
)
SELECT
    company_id,
    employee_id,
    employee_name,
    ROUND(
        salary * CASE
            WHEN max_salary < 1000 THEN 1.00
            WHEN max_salary <= 10000 THEN 0.76
            ELSE 0.51
        END
    ) AS salary
FROM salary_rank;
本地语义参考 · 输入员工记录列表，返回更新后的记录列表
import java.util.*;

class Solution {
    static class Employee {
        int companyId, employeeId, salary;
        String employeeName;

        Employee(int companyId, int employeeId, String employeeName, int salary) {
            this.companyId = companyId;
            this.employeeId = employeeId;
            this.employeeName = employeeName;
            this.salary = salary;
        }
    }

    public List<Employee> calculateSalaries(List<Employee> employees) {
        Map<Integer, Integer> companyMax = new HashMap<>();
        for (Employee employee : employees) {
            companyMax.merge(employee.companyId, employee.salary, Math::max);
        }

        List<Employee> result = new ArrayList<>();
        for (Employee employee : employees) {
            int maxSalary = companyMax.get(employee.companyId);
            double keepRate = maxSalary < 1000 ? 1.0
                    : maxSalary <= 10000 ? 0.76 : 0.51;
            int netSalary = (int) Math.round(employee.salary * keepRate);
            result.add(new Employee(employee.companyId, employee.employeeId,
                    employee.employeeName, netSalary));
        }
        return result;
    }
}
本地语义参考 · records 为对象数组
function calculateSalaries(records) {
  const companyMax = new Map();

  for (const row of records) {
    const current = companyMax.get(row.company_id) ?? -Infinity;
    companyMax.set(row.company_id, Math.max(current, row.salary));
  }

  return records.map((row) => {
    const maxSalary = companyMax.get(row.company_id);
    const keepRate = maxSalary < 1000
      ? 1
      : maxSalary <= 10000
        ? 0.76
        : 0.51;

    return {
      ...row,
      salary: Math.round(row.salary * keepRate),
    };
  });
}

from typing import Any


def calculate_salaries(records: list[dict[str, Any]]) -> list[dict[str, Any]]:
    company_max: dict[int, int] = {}
    for row in records:
        company_id = row["company_id"]
        company_max[company_id] = max(
            company_max.get(company_id, row["salary"]),
            row["salary"],
        )

    result = []
    for row in records:
        max_salary = company_max[row["company_id"]]
        keep_rate = 1.0 if max_salary < 1000 else (
            0.76 if max_salary <= 10000 else 0.51
        )
        updated = row.copy()
        # 工资均为整数；加 0.5 后向下取整对应正数的最近整数。
        updated["salary"] = int(row["salary"] * keep_rate + 0.5)
        result.append(updated)
    return result
本地语义参考 · 返回一组新的 Employee 记录
#include <algorithm>
#include <cmath>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Employee {
    int companyId;
    int employeeId;
    string employeeName;
    int salary;
};

class Solution {
public:
    vector<Employee> calculateSalaries(const vector<Employee>& employees) {
        unordered_map<int, int> companyMax;
        for (const Employee& employee : employees) {
            companyMax[employee.companyId] = max(
                companyMax[employee.companyId], employee.salary
            );
        }

        vector<Employee> result;
        result.reserve(employees.size());
        for (const Employee& employee : employees) {
            const int maxSalary = companyMax[employee.companyId];
            const double keepRate = maxSalary < 1000 ? 1.0
                : maxSalary <= 10000 ? 0.76 : 0.51;
            result.push_back({
                employee.companyId,
                employee.employeeId,
                employee.employeeName,
                static_cast<int>(round(employee.salary * keepRate))
            });
        }
        return result;
    }
};

面试追问

  • 不用窗口函数如何写？ 先按 company_id 聚合 MAX(salary)，再连接回原表。
  • 税率规则存进配置表怎么办？ 将工资区间建成规则表，按公司最高工资落入区间连接，避免硬编码 CASE。
  • 数据量很大时关注什么？ 检查 company_id 索引、分区策略、窗口排序开销和执行计划。
  • 为什么不能按员工自己的工资判断？ 因为题目把税率定义在公司层级；个人工资只参与最后的乘法。

常见错误

  • 把 1000 或 10000 归到错误档位。
  • 按每个员工自己的 salary 选税率。
  • GROUP BY 后丢失员工明细，却没有连接回原表。
  • 先对税额取整再相减，导致与“对最终工资取整”不一致。
  • 使用整数表达式 24 / 100，在部分语言或数据库中意外得到 0。
