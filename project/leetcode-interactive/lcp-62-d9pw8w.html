LCP 62 MEDIUM GRAPH · DEGREE COUNTING

所有城市都能到达它，但它不再通向任何城市。

交通枢纽

给定若干单向道路，寻找唯一的终点城市：每个其他出现过的城市都有一条道路直接通往它，而它没有任何出边。把道路表折叠成两列计数，就能在线性时间定位答案。

HUB CHECK

outdegree(hub) = 0

indegree(hub) = |V| − 1

V 只包含 roads 中出现过的城市。

PROBLEM BRIEF

题意与约束

数组 path 中的 [a, b] 表示一条从城市 a 到城市 b 的单向道路。题目保证存在唯一交通枢纽，返回该城市编号。

示例

[[0,1],[0,3],[1,3],[2,0],[2,1]]

城市 3 的入度为 3，其余三个城市都可直达它，且它没有出边。

答案

3

不需要搜索路径、拓扑排序或计算最短路。

1 ≤ path.length ≤ 1000；城市编号为非负整数。只需考察道路中实际出现的城市集合。

CORE INSIGHT

候选必须同时满足两条

  1. 1收集所有端点，得到参与本题的城市数 |V|。
  2. 2每条 a → b 令 out[a]++、in[b]++。
  3. 3寻找 out[x] = 0 且 in[x] = |V| − 1 的 x。
O(E + V)时间
O(V)空间

支持空格；城市编号使用 0~9999 的整数。

为什么度数条件充分？

若 in[x] = |V| - 1，则除 x 外的每个出现城市都至少贡献了一条到 x 的边。由于这些边来自不同起点，恰好说明“所有其他城市直达 x”。再加上 out[x] = 0，x 不会通向其他城市，完全符合枢纽定义。题目保证答案唯一，因此第一次满足条件的城市就是答案。

反过来，真正的枢纽从每个其他城市各收到一条边，入度为 |V|-1，且没有出边，必被筛选出来。

过程与边界

  • 不能只找出度为 0 的点：它可能没有被每座城市直达。
  • 不能只找最大入度：还须确认入度刚好为 |V|-1 且无出边。
  • 集合必须包含每条边的两个端点；不在 path 中出现的编号不属于本题网络。
  • 重复道路会增加入度计数；本题合法输入保证存在满足定义的唯一答案。

替代方案：可维护一个候选点，沿道路的终点不断替换候选，再验证；但仍需一轮统计验证，直接记录度数更直观、也更不易漏掉边界。

面试追问

若道路流式到达，可用哈希表持续维护集合、入度和出度；在流结束后扫描集合即可。若题目改成“经由任意路径可到达”，才需要反图遍历或拓扑性质，而不是本题的直接边计数。
