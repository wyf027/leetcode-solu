01 / Problem

四个下标，一次计数

给定四个长度都为 n 的整数数组 nums1、nums2、nums3 和 nums4，统计下标元组 (i, j, k, l) 的数量，使它们同时满足：

  • 0 ≤ i, j, k, l < n
  • nums1[i] + nums2[j] + nums3[k] + nums4[l] = 0
这里统计的是下标元组。即使不同下标取到相同数值，也要分别计数。

约束

  • n == nums1.length == nums2.length == nums3.length == nums4.length
  • 1 ≤ n ≤ 200
  • −228 ≤ nums1[i], nums2[i], nums3[i], nums4[i] ≤ 228

官方函数形式

fourSumCount(nums1, nums2, nums3, nums4) → integer

示例 1

OUTPUT 2 
输入：nums1 = [1,2], nums2 = [-2,-1],
      nums3 = [-1,2], nums4 = [0,2]
输出：2
解释：两个元组是
(0,0,0,1): 1 + (-2) + (-1) + 2 = 0
(1,1,0,0): 2 + (-1) + (-1) + 0 = 0

示例 2

OUTPUT 1 
输入：nums1 = [0], nums2 = [0],
      nums3 = [0], nums4 = [0]
输出：1

03 / Editorial

准备好对照完整题解了吗？

展开后包含证明、复杂度、四语言代码与面试追问。

Meet in the Middle

把四重枚举折成两个平方级问题

若直接枚举四个下标，需要检查 n⁴ 个组合。等式可以改写为 nums1[i] + nums2[j] = −(nums3[k] + nums4[l])：一边记录两数和出现次数，另一边逐项查询相反数。

Core insight

频次，而非存在性

哈希表的值必须是某个和出现的次数。相同和值可能来自多组不同下标，每次命中都要把整段频次加入答案。

Decomposition

2 + 2 分组

四个数组均为长度 n，平衡拆分使两边都只有 n² 个组合，空间和查询规模可控。

Invariant

每个元组恰好一次

固定 (k,l) 后，查询值准确代表所有匹配的 (i,j) 数量，因此既不遗漏也不重复。

完整过程

01

建立频次表

枚举 nums1 与 nums2 的所有元素对。令 s = a + b，执行 count[s] += 1。

02

扫描另一半

枚举 nums3 与 nums4 的所有元素对，算出 t = c + d。

03

查询相反数

所有满足 s = −t 的前半组合都能与当前后半组合组成零和元组，因此累加 count[−t]。

04

返回累计值

后半部分扫描结束时，累计值就是全部合法下标元组数。

正确性证明

完备性

任取合法元组 (i,j,k,l)。建立表时会记录 s = nums1[i] + nums2[j]；扫描到 (k,l) 时，由总和为零可知 s = −(nums3[k] + nums4[l])，故这组 (i,j) 必定被计入。

唯一性

每个后半下标对 (k,l) 只扫描一次；哈希频次中的每一份计数对应唯一前半下标对 (i,j)。两者的组合唯一确定一个四元组，所以不会重复计数。

复杂度与边界

  • 时间复杂度：O(n²)，两轮二重枚举。
  • 空间复杂度：O(n²)，最坏情况下两数和互不相同。
  • n = 1 时流程不变；四个零会得到 1。
  • 重复值需要保留频次，不能使用集合代替映射。
  • 元素和的范围可能较大；实现时选择足够宽的数值类型。JavaScript 的题目范围在安全整数内。

替代方案

  • 四重枚举：O(n⁴) 时间、O(1) 额外空间，n = 200 时不可行。
  • 两边和排序：生成两个长度 n² 的和数组，排序后用双指针计频；时间 O(n² log n)，空间 O(n²)。
  • 换一种 2 + 2：任意平衡分组都正确；若数组长度不同，应让存表侧的笛卡尔积更小以节省空间。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int fourSumCount(int[] nums1, int[] nums2,
                            int[] nums3, int[] nums4) {
        Map<Integer, Integer> count = new HashMap<>();

        for (int a : nums1) {
            for (int b : nums2) {
                int sum = a + b;
                count.put(sum, count.getOrDefault(sum, 0) + 1);
            }
        }

        int answer = 0;
        for (int c : nums3) {
            for (int d : nums4) {
                answer += count.getOrDefault(-(c + d), 0);
            }
        }
        return answer;
    }
}

 * @param {number[]} nums1
 * @param {number[]} nums2
 * @param {number[]} nums3
 * @param {number[]} nums4
 * @return {number}

var fourSumCount = function(nums1, nums2, nums3, nums4) {
    const count = new Map();

    for (const a of nums1) {
        for (const b of nums2) {
            const sum = a + b;
            count.set(sum, (count.get(sum) ?? 0) + 1);
        }
    }

    let answer = 0;
    for (const c of nums3) {
        for (const d of nums4) {
            answer += count.get(-(c + d)) ?? 0;
        }
    }
    return answer;
};
from collections import Counter
from typing import List


class Solution:
    def fourSumCount(
        self,
        nums1: List[int],
        nums2: List[int],
        nums3: List[int],
        nums4: List[int],
    ) -> int:
        pair_count = Counter(
            a + b
            for a in nums1
            for b in nums2
        )

        return sum(
            pair_count[-(c + d)]
            for c in nums3
            for d in nums4
        )
class Solution {
public:
    int fourSumCount(vector<int>& nums1,
                     vector<int>& nums2,
                     vector<int>& nums3,
                     vector<int>& nums4) {
        unordered_map<int, int> count;

        for (int a : nums1) {
            for (int b : nums2) {
                ++count[a + b];
            }
        }

        int answer = 0;
        for (int c : nums3) {
            for (int d : nums4) {
                auto it = count.find(-(c + d));
                if (it != count.end()) {
                    answer += it->second;
                }
            }
        }
        return answer;
    }
};

面试追问

  • 如果四个数组长度不同，怎样选择分组以降低峰值内存？
  • 如果目标值不是 0，查询表达式如何调整？
  • 如果不能使用哈希表，如何用排序与双指针解决？
  • 推广到 6 个数组时，如何用 3 + 3 的 meet-in-the-middle 思想处理？

常见错误

  • 把哈希表写成 Set，丢失重复和值的下标组合数。
  • 查找 c + d 而不是它的相反数。
  • 只统计数值组合，却忘记题目要求统计下标元组。
  • 在部分语言中使用过窄的中间数值类型，造成溢出。
