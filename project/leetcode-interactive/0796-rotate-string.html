796. 旋转字符串

Rotate String · 观察一次左旋如何改变字符位置，再亲手走完一圈。

EASY 字符串 字符串匹配 非付费题

Problem

题目说明

给定两个字符串 s 和 goal。如果对 s 进行若干次旋转操作后能够得到 goal，返回 true；否则返回 false。

一次旋转：把 s 最左侧的字符移动到最右侧。例如，"abcde" 旋转一次后变为 "bcdea"。

约束

  • 1 <= s.length, goal.length <= 100
  • s 与 goal 仅由小写英文字母组成。
示例 1
输入：s = "abcde", goal = "cdeab"
输出：true
示例 2
输入：s = "abcde", goal = "abced"
输出：false

Solution

◎

核心洞察：把圆环剪成两份

如果 s 的长度为 n，一次旋转只是改变“从哪里开始读”这个圆环。把 s 连写两遍，所有长度为 n 的旋转结果都会成为其中的连续子串。

s.length == goal.length && (s + s).contains(goal)

完整过程

  1. 先比较两字符串长度；不同则不可能通过旋转得到。
  2. 构造双倍字符串 s + s。
  3. 判断 goal 是否是双倍字符串的连续子串。
  4. 若存在返回 true，否则返回 false。

复杂度与边界

时间 O(n)额外空间 O(n)

这里按常见线性子串搜索实现计；不同语言标准库的具体实现可能不同。

  • 长度不同：立即返回 false。
  • 单字符：只需判断字符是否相同。
  • 重复字符：子串判定仍然成立。
  • 旋转 0 次也属于“若干次”，因此相同字符串返回 true。

正确性证明

充分性：若 goal 是 s + s 中长度为 n 的子串，从该子串起点把 s 分成后缀和前缀，结果正是“后缀 + 前缀”，也就是对 s 做若干次左旋所得。
必要性：若 s 左旋 k 次得到 goal，则 goal = s[k…n-1] + s[0…k-1]。这两段在 s + s 中从位置 k 起连续出现，所以 goal 必是其子串。
结论：在长度相等的前提下，子串条件与“可通过旋转得到”等价，算法正确。

常见错误

  • 忘记先比较长度，导致把较短字符串误判为匹配。
  • 只比较字符频次；频次相同不能保证循环顺序相同。
  • 模拟时少检查 0 次旋转或恰好多/少旋转一轮。
  • 把旋转误写成反转，破坏了字符的循环相对次序。

面试追问

  1. 如果不能调用标准库子串搜索，如何用 KMP 保证线性时间？
  2. 如何返回最少旋转次数，而不只是布尔结果？
  3. 若字符串非常大，怎样避免真实构造 s + s？
  4. 把左旋改成任意方向旋转，结论是否变化？

四种语言完整实现

选择语言查看可提交实现；使用左右方向键可切换标签。

Java标准提交签名
class Solution {
    public boolean rotateString(String s, String goal) {
        return s.length() == goal.length()
            && (s + s).contains(goal);
    }
}
JavaScript标准提交签名
/**
 * @param {string} s
 * @param {string} goal
 * @return {boolean}
 */
var rotateString = function(s, goal) {
    return s.length === goal.length
        && (s + s).includes(goal);
};
Python 3标准提交签名
class Solution:
    def rotateString(self, s: str, goal: str) -> bool:
        return len(s) == len(goal) and goal in (s + s)
C++标准提交签名
class Solution {
public:
    bool rotateString(string s, string goal) {
        return s.size() == goal.size()
            && (s + s).find(goal) != string::npos;
    }
};

直接模拟

最多旋转 n 次，每次构造新字符串并比较。易理解，但通常为 O(n²) 时间。

KMP 搜索

在逻辑上的 s + s 中用 KMP 查找 goal，保证 O(n) 时间，还可用取模避免实际拼接。

最少旋转次数

找到匹配起点 k 后，左旋最少次数就是对应起点；若同时允许右旋，可比较 k 与 n-k。
