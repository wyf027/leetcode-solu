Minimum Time to Eat All Grains

题号2604
难度HARD
函数minimumTime
数组双指针二分查找排序

Problem

题目描述

一条数轴上分布着若干只母鸡和若干粒谷子。整数数组 hens 表示母鸡的初始位置，grains 表示谷子的位置。

每只母鸡每秒可以向左或向右移动 1 个单位；所有母鸡能够同时、独立行动。当母鸡和谷子位于同一位置时，谷子会被立即吃掉，一只母鸡可以吃多粒谷子。

目标：在所有母鸡都采用最优行动方案时，返回吃完全部谷子所需的最短时间。

  • 移动耗时由数轴距离决定，吃谷子本身不耗时。
  • 答案是所有母鸡完成各自路线所需时间的最大值。
  • 母鸡可以不动，也可以经过同一位置；无需让每只母鸡都吃到谷子。

示例 1

输入
hens = [3,6,7], grains = [2,4,7,9]
输出
2

位置 3、6、7 的母鸡可分别处理谷子集合 {2}、{4}、{7,9}，最慢的一条路线用时 2 秒。

示例 2

输入
hens = [4,6,109,111,213,215], grains = [5,110,214]
输出
1

选择位置 4、111、215 的母鸡，各移动 1 个单位即可分别吃到三粒谷子。

约束

  • 1 <= hens.length, grains.length <= 2 × 10⁴
  • 0 <= hens[i], grains[j] <= 10⁹

Solution

排序 + 二分答案 + 双指针贪心

把“求最小时间”改写为“给定时间能否完成”，利用可行性的单调性搜索答案。

核心洞察

若时间 T 足够，更大的时间也一定足够，因此答案具有单调边界。排序后，让每只母鸡优先覆盖当前最左侧尚未吃掉的谷子；在一维线上，任何交叉分配都可交换成不交叉分配而不增加用时。

一只母鸡能到多远

母鸡在 x，最左未吃谷子在 l ≤ x，令 d = x-l。它可以先左后右，也可以先右后左。

right = x + max(T - 2d, floor((T - d) / 2))

若 l > x，只需一路向右，可到达 x + T。

完整过程

  1. 将 hens 和 grains 升序排列。
  2. 二分候选时间 T。
  3. 用指针记录最左未吃谷子，从左到右遍历母鸡。
  4. 计算当前母鸡的最远右端，连续吃掉范围内谷子。
  5. 全部吃完则收缩右边界，否则增大左边界。

为什么贪心正确

设当前最左未吃谷子为 g。若某只更靠右的母鸡负责 g，而当前母鸡负责更右的谷子，交换二者负责的连续区间不会增加任何一方需要跨越的最远端点。因此可固定由当前能覆盖它的最左母鸡尽量向右延伸。逐只归纳后，扫描吃完全部谷子当且仅当时间 T 可行。

边界情况

  • 母鸡与所有谷子同点时，答案为 0。
  • 最左谷子距当前母鸡超过 T 时，后面的母鸡更远，可立即判定失败。
  • 单只母鸡需要跨越左右两侧时，必须比较两种访问顺序。
  • 坐标可达 10⁹，中间计算在 Java/C++ 中使用 64 位整数。

复杂度

设母鸡数为 n、谷子数为 m，坐标上界为 C。

时间 O(n log n + m log m + (n+m) log C)
扫描额外空间 O(1)，排序空间依语言实现而定

替代方案

可将二分上界收紧到所有点跨度的两倍，减少少量轮次；也可用更复杂的分段/动态规划描述分配，但没有利用“答案可行性单调”这一结构，代码更长且无收益。

面试追问

  • 为什么分配区间一定可以视为连续且不交叉？
  • 如何从两种路线推导最远右端公式？
  • 若母鸡速度不同，可行性检查要怎样调整？
  • 若谷子带权且吃掉需要时间，单调性是否仍成立？

常见错误

  • 只考虑“先向左再向右”，漏掉先向右再回头可能更短。
  • 按最近母鸡逐粒匹配；局部最近会破坏连续区间的整体最优分配。
  • 把母鸡时间相加；母鸡并行移动，目标是各路线耗时的最大值。
  • 用 32 位中间值计算边界或距离表达式，导致溢出。
  • 可行性检查中反复回退谷子指针，使一轮退化为平方复杂度。

四语言完整代码

Java · LeetCode 提交格式
import java.util.Arrays;

class Solution {
    public int minimumTime(int[] hens, int[] grains) {
        Arrays.sort(hens);
        Arrays.sort(grains);
        long left = 0, right = 2_000_000_000L;

        while (left < right) {
            long time = left + (right - left) / 2;
            if (canEat(hens, grains, time)) {
                right = time;
            } else {
                left = time + 1;
            }
        }
        return (int) left;
    }

    private boolean canEat(int[] hens, int[] grains, long time) {
        int j = 0;
        for (int hen : hens) {
            if (j == grains.length) return true;

            long first = grains[j];
            long reach;
            if (first > hen) {
                reach = hen + time;
            } else {
                long leftDistance = hen - first;
                if (leftDistance > time) return false;
                reach = hen + Math.max(
                    time - 2 * leftDistance,
                    (time - leftDistance) / 2
                );
            }

            while (j < grains.length && grains[j] <= reach) j++;
        }
        return j == grains.length;
    }
}

C++ · LeetCode 提交格式
class Solution {
public:
    int minimumTime(vector<int>& hens, vector<int>& grains) {
        sort(hens.begin(), hens.end());
        sort(grains.begin(), grains.end());

        long long left = 0, right = 2'000'000'000LL;
        while (left < right) {
            long long time = left + (right - left) / 2;
            if (canEat(hens, grains, time)) right = time;
            else left = time + 1;
        }
        return static_cast<int>(left);
    }

private:
    bool canEat(const vector<int>& hens,
                const vector<int>& grains,
                long long time) {
        int j = 0;
        for (long long hen : hens) {
            if (j == grains.size()) return true;

            long long first = grains[j];
            long long reach;
            if (first > hen) {
                reach = hen + time;
            } else {
                long long leftDistance = hen - first;
                if (leftDistance > time) return false;
                reach = hen + max(
                    time - 2 * leftDistance,
                    (time - leftDistance) / 2
                );
            }

            while (j < grains.size() && grains[j] <= reach) ++j;
        }
        return j == grains.size();
    }
};
