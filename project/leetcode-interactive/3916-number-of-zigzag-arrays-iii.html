锯齿形数组的总数 III

值域可达 10⁹，无法按每个值直接 DP。把“值域大小 m 的答案”看成一个 n 次多项式：先在小 m 上精确 DP，再插值到真实 m。

DP有限差分拉格朗日插值

题意（付费题：按官方可见信息转述）

给定 n、l、r，统计长度为 n 的数组：每个元素在 [l,r] 内；相邻元素不相等；任意三个连续元素不能严格递增，也不能严格递减。答案对 1_000_000_007 取模。

约束：3 ≤ n ≤ 200，1 ≤ l < r ≤ 10⁹。平移整个值域不改变比较关系，因此只需 m = r-l+1。

两个样例

n = 3, l = 4, r = 5 → 2：仅 [4,5,4]、[5,4,5]。

n = 3, l = 1, r = 3 → 10。例如 [1,3,2] 与 [3,1,3] 都满足方向交替。

把相邻比较方向看成箭头：一旦上一箭头向上，下一箭头必须向下；反之亦然。

交互实验室：小值域 DP → 多项式插值

准备

边界与替代方案

  • m=1 时（虽不在原约束内）长度至少 2 已无解，正是多项式采样中的 F(1)=0。
  • 不要按真实 m 建数组；m 可为 10⁹。
  • 暴力枚举为 O(mⁿ)；直接 DP 为 O(nm)，仅适合插值采样点。
  • 本解对 m=0..n 做 DP，然后用 O(n) 的前后缀积拉格朗日求值，总复杂度 O(n³)、空间 O(n)。

题解：为何能插值？

固定长度 n 后，每种比较模式是一组严格不等式约束；在 m 个有序值中满足它的计数是次数不超过 n 的 order polynomial。两个起始方向的并集就是 F(m)，所以采样 n+1 个 m 值便能唯一恢复它。

对一个采样 m，维护 up[v]（最后一步上升且末值 v）和 down[v]（最后一步下降）。前缀和给出 newUp[v]=Σ down[x] (x<v)，后缀和给出 newDown[v]=Σ up[x] (x>v)。

面试追问：若 n 很大而模数固定，可将有限差分/线性递推再用矩阵或多项式加速；此题 n≤200，采样 DP 已足够。常见错误：把区间端点 l、r 当成状态；初始化长度 1 时同时放入 up/down 导致长度 2 双计数；插值分母忘记处理符号。

class Solution {
  static final long MOD = 1_000_000_007L;
  public int zigZagArrays(int n, int l, int r) {
    long[] y = new long[n + 1]; for (int m = 0; m <= n; m++) y[m] = sample(n, m);
    long x = ((long) r - l + 1) % MOD; if (x <= n) return (int) y[(int) x];
    long[] pre = new long[n + 2], suf = new long[n + 2]; pre[0] = suf[n + 1] = 1;
    for (int i = 0; i <= n; i++) pre[i + 1] = pre[i] * (x - i + MOD) % MOD;
    for (int i = n; i >= 0; i--) suf[i] = suf[i + 1] * (x - i + MOD) % MOD;
    long ans = 0; for (int i = 0; i <= n; i++) { long den = 1;
      for (int j = 0; j <= n; j++) if (i != j) den = den * (i - j + MOD) % MOD;
      ans = (ans + y[i] * pre[i] % MOD * suf[i + 1] % MOD * pow(den, MOD - 2)) % MOD; }
    return (int) ans;
  }
  long sample(int n, int m) { if (m == 0) return 0; long[] up = new long[m], down = new long[m];
    for (int v = 0; v < m; v++) { up[v] = v; down[v] = m - 1 - v; }
    for (int len = 3; len <= n; len++) { long[] a = new long[m], b = new long[m]; long pref=0, seen=0, total=0;
      for (long z: up) total=(total+z)%MOD; for (int v=0;v<m;v++){a[v]=pref;pref=(pref+down[v])%MOD;seen=(seen+up[v])%MOD;b[v]=(total-seen+MOD)%MOD;} up=a; down=b; }
    long ans=0; for(int v=0;v<m;v++) ans=(ans+up[v]+down[v])%MOD; return ans; }
  long pow(long a,long e){long z=1;while(e>0){if((e&1)==1)z=z*a%MOD;a=a*a%MOD;e>>=1;}return z;}
}

class Solution:
    MOD = 10**9 + 7
    def zigZagArrays(self, n: int, l: int, r: int) -> int:
        def sample(m):
            if not m: return 0
            up, down = list(range(m)), list(range(m - 1, -1, -1))
            for _ in range(3, n + 1):
                a, b = [0] * m, [0] * m; pref = seen = 0; total = sum(up) % self.MOD
                for v in range(m):
                    a[v] = pref; pref = (pref + down[v]) % self.MOD
                    seen = (seen + up[v]) % self.MOD; b[v] = (total - seen) % self.MOD
                up, down = a, b
            return sum(x + y for x, y in zip(up, down)) % self.MOD
        y = [sample(m) for m in range(n + 1)]; x = (r - l + 1) % self.MOD
        if x <= n: return y[x]
        pre, suf = [1] * (n + 2), [1] * (n + 2)
        for i in range(n + 1): pre[i + 1] = pre[i] * (x - i) % self.MOD
        for i in range(n, -1, -1): suf[i] = suf[i + 1] * (x - i) % self.MOD
        ans = 0
        for i in range(n + 1):
            den = 1
            for j in range(n + 1):
                if i != j: den = den * (i - j) % self.MOD
            ans = (ans + y[i] * pre[i] * suf[i + 1] * pow(den, self.MOD - 2, self.MOD)) % self.MOD
        return ans
