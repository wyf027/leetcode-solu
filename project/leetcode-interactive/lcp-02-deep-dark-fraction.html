LCP 02 EASY deep-dark-fraction

分式化简

把连分数从最里面的一层向外“翻转”。每轮只维护当前最简分数 n / d，新系数 a 会把它变成 (a × n + d) / n。

交互实验室

13 / 4

例如：[3, 2, 0, 2]。题目保证输入有效时，答案已经互质。

    为什么倒着算？

    连分数的最后一个系数本身就是一个整数，可看作 ak / 1。这就是唯一不依赖其他层的起点。

    若内层已是 n / d，外面多包一层 a + 1/(n/d)，就等于 (a × n + d) / n。

    每一步分子、分母都互换一次；相邻分数的行列式保持 ±1，所以最终天然互质，无需额外求 gcd。

    时间
    O(n)
    额外空间
    O(1)

    四种语言实现

    全部使用同一条反向递推。

    Java 

    class Solution {
  public int[] fraction(int[] cont) {
    int n = 1, d = 0;
    for (int i = cont.length - 1; i >= 0; i--) {
      int next = cont[i] * n + d;
      d = n; n = next;
    }
    return new int[] {n, d};
  }
}

    JavaScript 

    var fraction = function (cont) {
  let n = 1, d = 0;
  for (let i = cont.length - 1; i >= 0; i--) {
    [n, d] = [cont[i] * n + d, n];
  }
  return [n, d];
};

    Python 

    class Solution:
    def fraction(self, cont: list[int]) -> list[int]:
        n, d = 1, 0
        for a in reversed(cont):
            n, d = a * n + d, n
        return [n, d]

    C++ 

    class Solution {
public:
  vector<int> fraction(vector<int>& cont) {
    int n = 1, d = 0;
    for (int i = int(cont.size()) - 1; i >= 0; --i) {
      int next = cont[i] * n + d;
      d = n; n = next;
    }
    return {n, d};
  }
};
