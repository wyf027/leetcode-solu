INTERVIEW 01.02 · STRING

字符频次
天平

给定两个只含小写字母的字符串 s1、s2，判断其中一个重新排列后能否变成另一个。把每个字母看成筹码：左边加一、右边减一；所有格子归零，天平便平衡。

哈希表字符串简单 · O(n)

题意与样例

“字符重排”不在乎顺序，只在乎每个字母出现的次数是否完全一致。

样例 1：可以抵消

s1 = "abc"

s2 = "bca"

输出：true。a、b、c 的出现次数都相同。

样例 2：有余额

s1 = "abc"

s2 = "bad"

输出：false。c 没有被抵消，d 也多出一次。

约束

0 ≤ len(s1) ≤ 100

0 ≤ len(s2) ≤ 100

字符串仅由 a 到 z 的小写字母组成。

可见空格约定

题面字符串只含小写字母；本页的文字示例若出现空格，使用 ␠ 显示，表示一个真实空格，避免视觉上漏读。

题解

首屏不展开答案。准备好后查看频次法的关键不变量、四语言代码与替代方案。

核心洞察

重排等价于每种字符的频次一致。对 s1 加一、对 s2 减一；最后 26 个格子都为零，当且仅当答案为 true。

完整过程

  1. 长度不同，直接 false。
  2. 建立大小为 26 的计数数组。
  3. 扫描 s1 加一，扫描 s2 减一。
  4. 存在非零余额则 false，否则 true。

边界

两个空串互为重排；同一字符多次出现必须完整抵消；长度不同不必再建立计数。

复杂度

两次扫描为 O(n)，检查固定 26 格为 O(1)；额外空间 O(1)。

替代方案

分别排序再比较，代码短但时间为 O(n log n)。当字符集不固定时，使用 HashMap 取代 26 格数组。

面试追问

若包含 Unicode？用 Map 按码点统计。若输入很长且可流式读取？保持增减计数，最后检查所有余额。

常见错误

忘记长度剪枝；只检查 s1 中字符而漏掉 s2 多出的字符；把重复字符当作集合；用排序却误报 O(n)。 

class Solution {
    public boolean CheckPermutation(String s1, String s2) {
        if (s1.length() != s2.length()) return false;
        int[] count = new int[26];
        for (int i = 0; i < s1.length(); i++) count[s1.charAt(i) - 'a']++;
        for (int i = 0; i < s2.length(); i++) count[s2.charAt(i) - 'a']--;
        for (int value : count) if (value != 0) return false;
        return true;
    }
}
/**
 * @param {string} s1
 * @param {string} s2

var CheckPermutation = function (s1, s2) {
  if (s1.length !== s2.length) return false;
  const count = Array(26).fill(0);
  for (const char of s1) count[char.charCodeAt(0) - 97] += 1;
  for (const char of s2) count[char.charCodeAt(0) - 97] -= 1;
  return count.every((value) => value === 0);
};
class Solution:
    def CheckPermutation(self, s1: str, s2: str) -> bool:
