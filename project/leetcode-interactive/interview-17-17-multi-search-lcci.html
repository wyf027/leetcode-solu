MULTI-LINE SEARCH EXCHANGE

多次搜索 把共同前缀接到同一块交换台

一条长字符串，许多待查短词。不要为每个短词重新巡线：先把 smalls 接成字典树，再让每个起点沿着字符线路前进。

主线：字典树 + 枚举起点 重叠匹配不会漏 空短词返回空位置表
ROUTING BOARD / PREFIX LINES
Ris i / is
Rppi ppi
Rsi / s sis / ssippi
Rhi hi

深色插孔表示“到这里恰好构成一个短词”；线路仍可继续，因此 i 与 is 能共享同一段前缀。

01 / PROBLEM BRIEF

题意

所有字符均为小写字母

给定长字符串 big 与短字符串数组 smalls。对每个 smalls[i]，返回它在 big 中所有出现位置的起始下标；如果没有出现，对应结果就是空数组。不同短词的答案顺序必须与 smalls 保持一致。

输入 big = "mississippi"
smalls = ["is", "ppi", "hi", "sis", "i", "ssippi"]
期望输出 [[1, 4], [8], [], [3], [1, 4, 7, 10], [5]]

约束

  • 0 <= len(big) <= 1000
  • 0 <= len(smalls[i]) <= 1000
  • smalls 的总字符数不超过 10^6
  • smalls 中没有重复字符串

可见符号约定：␠ 表示一个空格；本题合法字符仅为 a-z，样例中没有空格。

SOLUTION VAULT

题解默认封存

先操作交换台形成直觉，再按需查看证明、复杂度与四语言代码。

CORE INSIGHT

核心洞察

把所有非空短词插入同一棵字典树。随后枚举 big 的每个起点 start，从根节点开始向右读字符；边不存在就立即停止，抵达终止节点就把 start 记录给对应短词。共同前缀只存一次，而每个起点都独立扫描，因此重叠出现也会被完整记录。

WHY IT WORKS

正确性要点

对任意短词 w 和起点 start：若 w 在该处出现，那么从字典树根沿 big[start...] 读取前 |w| 个字符，必然抵达 w 的终止节点，于是记录该起点；反过来，只有逐字符完全相等才能抵达终止节点，所以不会产生误报。

FULL PROCESS

完整过程

  1. STEP 1

    为每个短词保留原下标，空短词直接留下空答案。

  2. STEP 2

    把非空短词插入字典树，并在终点保存短词下标。

  3. STEP 3

    枚举 big 的每个起点，沿树向右扫描，缺边即停。

  4. STEP 4

    每遇终止节点，把当前起点追加到对应答案中。

边界处理

  • · big = ""：所有答案为空。
  • · 空短词：按常见判题约定返回空位置表，不插入根节点。
  • · 一个短词是另一个的前缀：终止节点命中后仍继续走。
  • · 重叠出现：每个起点独立扫描，不跳过字符。

复杂度

设 S 为所有短词总长度，B 为 big 长度，L 为最长短词长度。建树 O(S)；搜索最坏 O(B · min(B, L))；空间 O(S + 输出规模)。

替代方案取舍

逐短词 KMP 容易写但会反复扫描 big。Aho–Corasick 可把搜索降为近似 O(B + S + 输出)，适合更长文本流；本题 B <= 1000，字典树枚举起点更短、更稳，更符合面试主线。

面试追问

  • · 如果 big 是持续到来的文本流，如何引入失败指针？
  • · 如果字符集扩展为 Unicode，孩子节点结构如何选择？
  • · 如果允许重复短词，终止节点应存一个下标还是下标列表？
  • · 如何仅返回每个短词的第一次出现来节省输出空间？

常见错误

  • · 命中较短前缀后立即停止，漏掉更长短词。
  • · 命中后跳过整段长度，漏掉重叠匹配。
  • · 结果按命中顺序组织，而不是按 smalls 原顺序。
  • · 把空短词标在根节点，意外记录每个扫描起点。

class Solution {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        int wordIndex = -1;
    }

    public int[][] multiSearch(String big, String[] smalls) {
        TrieNode root = new TrieNode();
        for (int i = 0; i < smalls.length; i++) {
            if (smalls[i].isEmpty()) {
                continue;
            }
            TrieNode node = root;
            for (char ch : smalls[i].toCharArray()) {
                int next = ch - 'a';
                if (node.children[next] == null) {
                    node.children[next] = new TrieNode();
                }
                node = node.children[next];
            }
            node.wordIndex = i;
        }

        java.util.List<java.util.List<Integer>> hits =
            new java.util.ArrayList<>();
        for (int i = 0; i < smalls.length; i++) {
            hits.add(new java.util.ArrayList<>());
        }

        for (int start = 0; start < big.length(); start++) {
            TrieNode node = root;
            for (int end = start; end < big.length(); end++) {
                node = node.children[big.charAt(end) - 'a'];
                if (node == null) {
                    break;
                }
                if (node.wordIndex != -1) {
                    hits.get(node.wordIndex).add(start);
                }
            }
        }

        int[][] answer = new int[smalls.length][];
        for (int i = 0; i < smalls.length; i++) {
            answer[i] = hits.get(i).stream().mapToInt(Integer::intValue).toArray();
        }
        return answer;
    }
}
var multiSearch = function (big, smalls) {
  const root = { children: new Map(), wordIndex: -1 };

  smalls.forEach((word, index) => {
    if (word.length === 0) return;
    let node = root;
    for (const char of word) {
      if (!node.children.has(char)) {
        node.children.set(char, { children: new Map(), wordIndex: -1 });
      }
      node = node.children.get(char);
    }
    node.wordIndex = index;
  });

  const answer = Array.from({ length: smalls.length }, () => []);
  for (let start = 0; start < big.length; start += 1) {
    let node = root;
    for (let end = start; end < big.length; end += 1) {
      node = node.children.get(big[end]);
      if (!node) break;
      if (node.wordIndex !== -1) {
        answer[node.wordIndex].push(start);
      }
    }
  }
  return answer;
};
from typing import List


class TrieNode:
    def __init__(self) -> None:
        self.children = {}
        self.word_index = -1


class Solution:
    def multiSearch(self, big: str, smalls: List[str]) -> List[List[int]]:
        root = TrieNode()
        for index, word in enumerate(smalls):
            if not word:
                continue
            node = root
            for char in word:
                node = node.children.setdefault(char, TrieNode())
            node.word_index = index

        answer = [[] for _ in smalls]
        for start in range(len(big)):
            node = root
            for end in range(start, len(big)):
                char = big[end]
                if char not in node.children:
                    break
                node = node.children[char]
                if node.word_index != -1:
                    answer[node.word_index].append(start)
        return answer
class Solution {
    struct TrieNode {
        std::array<int, 26> next{};
        int wordIndex = -1;
    };

public:
    std::vector<std::vector<int>> multiSearch(
        std::string big,
        std::vector<std::string>& smalls
    ) {
        std::vector<TrieNode> trie(1);
        for (int index = 0; index < static_cast<int>(smalls.size()); ++index) {
            if (smalls[index].empty()) {
                continue;
            }
            int node = 0;
            for (char ch : smalls[index]) {
                int edge = ch - 'a';
                if (trie[node].next[edge] == 0) {
                    trie[node].next[edge] = static_cast<int>(trie.size());
                    trie.emplace_back();
                }
                node = trie[node].next[edge];
            }
            trie[node].wordIndex = index;
        }

        std::vector<std::vector<int>> answer(smalls.size());
        for (int start = 0; start < static_cast<int>(big.size()); ++start) {
            int node = 0;
            for (int end = start; end < static_cast<int>(big.size()); ++end) {
                int edge = big[end] - 'a';
                if (trie[node].next[edge] == 0) {
                    break;
                }
                node = trie[node].next[edge];
                if (trie[node].wordIndex != -1) {
                    answer[trie[node].wordIndex].push_back(start);
                }
            }
        }
        return answer;
    }
};
