2293. 极大极小游戏

Min Max GameEASY数组模拟

相邻的两个数，一次选择；每轮人数减半，直到只剩一个。

01 / 游戏规则

给定从下标 0 开始的整数数组 nums，长度为 2 的幂。若只剩一个元素，直接返回它；否则创建长度为原来一半的 newNums：

  • 新下标 i 是偶数：newNums[i] = min(nums[2*i], nums[2*i+1])。
  • 新下标 i 是奇数：newNums[i] = max(nums[2*i], nums[2*i+1])。
  • 用新数组替换旧数组，重复上述规则，返回最后的数字。

规则看的是新数组下标的奇偶性；每一轮都从新下标 0 重新开始。

约束

1 ≤ nums.length ≤ 1024，长度为 2 的幂；1 ≤ nums[i] ≤ 10⁹。

官方示例 1

输入：nums = [1,3,5,2,4,8,2,2]
输出：1

依次得到 [1,5,4,2]、[1,4]、[1]，因此返回 1。

官方示例 2

输入：nums = [3]
输出：3

数组已经只有一个数，无须进行任何一轮操作。

04 / 独立题解

先根据游戏规则尝试推导，再展开思路与四语言实现。

按轮模拟：忠实执行规则

核心洞察

这不是需要搜索策略的博弈：每对数字的去留已由规则确定。每轮只需扫描相邻元素，并根据目标下标选择 min 或 max。

完整过程

  1. 当前长度为 1 时返回唯一元素。
  2. 创建容量为当前长度一半的新数组。
  3. 枚举目标下标 i，取当前数组的第 2i 与 2i+1 个元素；i 为偶数取小，为奇数取大。
  4. 全部配对完成后，用新数组继续下一轮。
[1,3,5,2,4,8,2,2]
  min  max  min  max
       ↓
    [1,5,4,2]
     min max
       ↓
      [1,4]
       min
       ↓
       [1]

正确性证明

以轮数归纳。初始数组与题目输入相同。假设某轮开始时当前数组与题目规定一致：每个目标位置 i 都使用相同的输入位置 2i、2i+1，并按 i 的奇偶性执行相同的 min/max，因此新数组每个位置都与题目规定一致。整轮替换后，归纳条件继续成立。长度每轮减半，有限轮后变为 1，此时返回的就是题目所要求的剩余数字。

边界与复杂度

长度为 1 时不进入循环；长度为 2 时只执行一次 min。相等元素选任意一个值都相同；数值仅比较，不进行可能溢出的加法。合法输入没有空数组或奇数长度的中间轮。

设初始长度为 n。轮数为 log₂n，但总比较次数为 n/2 + n/4 + … + 1 = n−1，所以时间复杂度为 O(n)；新数组占用的峰值额外空间为 O(n)。n=1 时为常数开销。

替代方案

可将每轮结果从左到右写回原数组前半段，用有效长度控制后续轮次，额外空间降为 O(1)。写入位置 i 不会覆盖后续尚未读取的位置 2i+2 及以后，但会修改输入。分治也能按相同配对树递归合并，时间 O(n)、递归栈 O(log n)，实现时必须保留各层目标下标的奇偶关系。

常见错误

  • 按轮数交替 min/max：实际是在同一轮中按目标下标交替。
  • 判断原数组下标 2i 的奇偶性：它永远是偶数。
  • 直接返回全局最小值：例如 [5,6,1,9] 的答案为 5。
  • 看到 log n 轮就写 O(log n)：每轮还要处理该轮的元素。
  • 边生成边用未完成的新数组作为本轮输入：一轮必须始终读取同一个旧数组。

面试追问

能否不修改传入数组？下面四份实现均只读取原数组，再将局部变量指向新数组。

为何原地写回可行？从左向右处理时，写回位置不在未来输入区域内。

长度不是 2 的幂怎么办？这不属于题目输入，需要先明确奇数轮的配对规则，不能自行丢弃最后一项。

Java

class Solution {
    public int minMaxGame(int[] nums) {
        while (nums.length > 1) {
            int[] next = new int[nums.length / 2];
            for (int i = 0; i < next.length; i++) {
                next[i] = i % 2 == 0
                    ? Math.min(nums[2 * i], nums[2 * i + 1])
                    : Math.max(nums[2 * i], nums[2 * i + 1]);
            }
            nums = next;
        }
        return nums[0];
    }
}

Python 3

from typing import List

class Solution:
    def minMaxGame(self, nums: List[int]) -> int:
        while len(nums) > 1:
            next_nums = []
            for i in range(len(nums) // 2):
                a, b = nums[2 * i], nums[2 * i + 1]
                next_nums.append(min(a, b) if i % 2 == 0 else max(a, b))
            nums = next_nums
        return nums[0]

C++

#include <algorithm>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int minMaxGame(vector<int>& nums) {
        vector<int> current = nums;
        while (current.size() > 1) {
            vector<int> next(current.size() / 2);
            for (int i = 0; i < static_cast<int>(next.size()); ++i) {
                next[i] = i % 2 == 0
                    ? min(current[2 * i], current[2 * i + 1])
                    : max(current[2 * i], current[2 * i + 1]);
            }
            current = move(next);
        }
        return current[0];
    }
};
