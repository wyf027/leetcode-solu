题意

可以来自某棵 BST 吗？

输入整数数组 postorder。如果存在一棵二叉搜索树，其后序遍历结果恰好等于该数组，返回 true；否则返回 false。

二叉搜索树中，任意节点左子树的值都更小，右子树的值都更大。

核心洞察

末尾是根，前缀必须切成连续的左右两段

对任意后序区间 [left, right]，末尾 postorder[right] 是根。根之前先出现的连续小值属于左子树，剩余元素必须全部大于根，才能属于右子树。

完整过程

递归验证每一个子区间

  1. 若区间为空或只有一个元素，直接返回 true。
  2. 令末尾元素为 root，找到首个不小于根的位置 split。
  3. 扫描 [split, right - 1]；其中每个值都必须严格大于根。
  4. 递归验证左段 [left, split - 1] 与右段 [split, right - 1]。
  5. 右段规则和两个递归结果同时成立，当前区间才合法。

正确性

为什么这个判定充要？

后序遍历固定以根结尾；BST 又要求左子树所有值小于根、右子树所有值大于根。因此合法区间必然能被划分成“连续左段 + 连续右段 + 根”。反过来，若当前分区满足大小关系，且左右两段递归地也满足同一规则，就能组合成合法 BST。

复杂度

退化树会重复扫描长区间

  • 最坏时间复杂度：O(n²)。
  • 平衡划分时，时间约为 O(n log n)。
  • 最坏递归栈空间：O(n)；平衡时为 O(log n)。

替代方案

单调栈可把时间降到 O(n)

从右向左扫描后序数组，相当于按“根、右、左”的顺序观察节点。维护单调栈与祖先上界；从右子树切换到左子树时弹栈并收紧上界。若后续值大于上界，序列非法。每个元素至多进栈、出栈一次，因此时间 O(n)、空间 O(n)。

常见错误

四个高频陷阱

  • 把区间首元素误当成根。
  • 找到分割点，却没有验证整个右段。
  • 右段扫描时把末尾根节点也算进去。
  • 忽略“无重复数字”前提，混用严格与非严格比较。

class Solution {
    public boolean verifyTreeOrder(int[] postorder) {
        return check(postorder, 0, postorder.length - 1);
    }

    private boolean check(int[] postorder, int left, int right) {
        if (left >= right) {
            return true;
        }

        int root = postorder[right];
        int split = left;
        while (split < right && postorder[split] < root) {
            split++;
        }

        int cursor = split;
        while (cursor < right && postorder[cursor] > root) {
            cursor++;
        }

        return cursor == right
                && check(postorder, left, split - 1)
                && check(postorder, split, right - 1);
    }
}

  const check = (left, right) => {
    if (left >= right) {
      return true;

      split += 1;
    }

    let cursor = split;
    while (cursor < right && postorder[cursor] > root) {
      cursor += 1;
    }

    return cursor === right
      && check(left, split - 1)
      && check(split, right - 1);

  return check(0, postorder.length - 1);
