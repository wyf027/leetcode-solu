移动石子直到连续

Moving Stones Until Consecutive

先移动石子、观察空位如何消失，再决定是否展开题解。关键不在模拟所有走法，而在看清两段间隙。

题目

数轴上有三枚位于不同整数位置的石子，位置为 a、b、c。每次只能拿起最左或最右的石子，把它放到当前两端之间尚未占用的整数位置。

当三枚石子占据三个连续位置时无法继续移动。返回 [minimum_moves, maximum_moves]，分别表示结束游戏所需的最少与最多移动次数。

函数签名
numMovesStones(a, b, c) → integer[2]

规则与约束

  • 1 ≤ a, b, c ≤ 100
  • a、b、c 两两不同
  • 若排序后为 x < y < z，新位置 k 必须满足 x < k < z 且 k ≠ y
  • 一次移动后，被移动的石子不一定仍是端点

官方示例

示例 1
输入：a = 1, b = 2, c = 5
输出：[1, 2]
解释：5→3 只需一步；或 5→4→3。
示例 2
输入：a = 4, b = 3, c = 2
输出：[0, 0]
解释：三枚石子已经连续。
示例 3
输入：a = 3, b = 5, c = 1
输出：[1, 2]
解释：1→4；或 1→2→4。

题解

核心洞察

先排序得到 x < y < z，令两段空位数为 left = y-x-1、right = z-y-1。题目只需要这两个间隙。

  • 最少步：两段都为 0 时是 0；至少一段为 0 或 1 时是 1；否则是 2。
  • 最多步：每步故意只消掉一个空位，总共可走 left + right = z-x-2 步。

完整过程

  1. 将三个位置升序排列。
  2. 若 z-x=2，三者连续，最少步为 0。
  3. 否则，若 y-x≤2 或 z-y≤2，可以把另一端石子一步塞到紧邻位置，最少步为 1。
  4. 若两侧距离都大于 2，先让一端靠近中间，再让另一端补齐，最少步为 2。
  5. 最多步等于最左、最右之间除去三枚石子后剩余的位置数，即 z-x-2。

正确性说明

最少步：连续状态显然无需移动。非连续时，若某两个石子的距离不超过 2，则距离为 1 的两石已经相邻，或距离为 2 时中间恰有一个空位；把远端石子放入合适的邻位即可一步连续。若两段距离均大于 2，一步移动只能改变一个端点，无法同时让两段都变成相邻，因此至少两步；按上述构造又至多两步，所以恰为两步。

最多步：跨度 z-x 最终必须从当前值降到 2。任何合法移动都会让至少一个端点向内移动，跨度至少减少 1，因此移动数不超过 z-x-2。每次把端点移到距另一端仅一格更内的位置，可以令跨度恰好减少 1，直到连续，故上界可达。

边界

  • 输入顺序任意，必须先排序。
  • 三个位置已经连续时返回 [0,0]。
  • 形如 [1,3,10] 的“隔一个空位”是特殊的一步情形。
  • 位置范围虽小，但公式不依赖枚举。

复杂度

只排序 3 个数，时间复杂度 O(1)，额外空间复杂度 O(1)。

替代方案

可以对状态做广度优先搜索求最少步，对路径做搜索求最多步，但会把一个常数时间的数学问题变复杂。枚举在本题范围内或许可行，却掩盖了“两段间隙”这一结构。

面试追问

  • 为什么距离为 2 能一步结束？请给出具体落点。
  • 为何最大步数不是两段距离之和，而是两段“空位数”之和？
  • 若扩展为四枚石子，最少步的局部判断还能否直接沿用？

常见错误

  • 忘记排序，直接用原始参数计算间距。
  • 把最少步写成“有相邻就是 1”，漏掉距离为 2 的特殊情况。
  • 最大步误写为 z-x 或 z-x-1。
  • 用示例路径作为唯一规则，导致排列变化时失效。

Java

import java.util.Arrays;

class Solution {
    public int[] numMovesStones(int a, int b, int c) {
        int[] p = {a, b, c};
        Arrays.sort(p);
        int x = p[0], y = p[1], z = p[2];
        int min;
        if (z - x == 2) min = 0;
        else if (y - x <= 2 || z - y <= 2) min = 1;
        else min = 2;
        return new int[]{min, z - x - 2};
    }
}

var numMovesStones = function(a, b, c) {
    const [x, y, z] = [a, b, c].sort((m, n) => m - n);
    let minMoves;
    if (z - x === 2) minMoves = 0;
    else if (y - x <= 2 || z - y <= 2) minMoves = 1;
    else minMoves = 2;
    return [minMoves, z - x - 2];
};

        return {minMoves, z - x - 2};
    }
};
