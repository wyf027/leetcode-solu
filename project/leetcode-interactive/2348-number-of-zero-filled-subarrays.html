全 0 子数组的数目

Number of Zero-Filled Subarrays

给定整数数组 nums，统计其中所有元素都为 0 的子数组数量。子数组必须连续且非空；即使内容相同，所在位置不同也分别计数。

参数：nums: integer[]返回：整数计数（long）官方题目 ↗

先阅读示例，尝试自己找出合法区间。交互演示需要手动开启；完整题解位于页面底部，默认折叠。

示例 1

nums = [1,3,0,0,2,0,0,4]
输出：6

长度为 1 的全 0 区间有 4 个，长度为 2 的有 2 个；没有更长的合法区间。

示例 2

nums = [0,0,0,2,0,0]
输出：9

长度为 1、2、3 的全 0 区间分别有 5、3、1 个，合计 9 个。

示例 3

nums = [2,10,2019]
输出：0

没有任何元素为 0，因此不存在全 0 子数组。

约束
  • 1 ≤ nums.length ≤ 105
  • −109 ≤ nums[i] ≤ 109

04 / EXPLAIN

独立题解

核心洞察：按右端点分组

设 run 是以当前下标结束的连续 0 的长度。如果当前值是 0，则本步恰好新增 run 个合法子数组：它们的左端点可以取这段连续 0 内的任意位置。如果当前值非零，本步贡献为 0，并将 run 清零。

run = (x == 0) ? run + 1 : 0
answer += run

完整过程

  1. 初始化 run = 0、answer = 0。
  2. 从左到右读每个元素，先更新连续 0 的长度。
  3. 把当前 run 加入答案，即统计所有以当前位置为右端点的合法区间。
  4. 遍历完成后直接返回答案；不需要额外结算最后一段。

正确性证明

循环不变量：处理完下标 i 后，run 等于以 i 结尾的最长全 0 后缀长度，answer 等于右端点不超过 i 的合法子数组总数。

初始未处理元素，两个计数为 0，符合定义。若 nums[i] 非零，没有合法区间能以 i 结束，清零 run 并保持答案。若 nums[i] 为零，后缀长度增加 1；以 i 结尾的合法区间必须从该后缀内开始，恰有 run 个。累加后不变量继续成立。每个子数组只有一个右端点，因此不会重复或遗漏。遍历结束即得到全部合法子数组数。

边界与数值范围

  • 只有一个 0 时返回 1；全非零时返回 0。
  • 正数、负数都能切断零段，不能只判断是否大于 0。
  • 若全为 0，答案是 n(n+1)/2；最大为 5,000,050,000，超过 32 位有符号整数。
  • Java 使用 long，C++ 使用 long long；Python 整数可自动扩展；JavaScript Number 在本题范围内能精确表示整数。
  • 空数组不在官方输入范围；给出的实现自然返回 0。

复杂度

时间 O(n)，每个元素只处理一次；额外空间 O(1)，只保存 run 和 answer。交互页面为了展示历史区间会额外创建显示节点，这不属于提交算法。

替代方案

按最大连续零段分组，每段长度为 L 时累加 L × (L + 1) / 2，时间 O(n)、额外空间 O(1)。需要注意数组结尾的零段也要结算，且乘法之前就要使用宽整数。逐个枚举起点并向右扫描也能求解，但全 0 数组时为 O(n²)，不适合 10⁵ 的规模。

四种语言 · 官方签名实现

Java

class Solution {
    public long zeroFilledSubarray(int[] nums) {
        long run = 0, answer = 0;
        for (int x : nums) {
            run = x == 0 ? run + 1 : 0;
            answer += run;
        }
        return answer;
    }
}

常见错误

  • 只统计值为 0 的元素，漏掉长度大于 1 的区间。
  • 遇到非零不清空 run，错误跨越断点。
  • 先累加旧 run 再更新，导致每个零的贡献少 1。
  • 使用 32 位答案，或在转 long 之前已经发生乘法溢出。
  • 把内容相同的区间去重；本题按位置计数。

面试追问

数据以流式输入到达怎么办？保留 run 和 answer 即可在线更新，不需要完整数组。

只数长度恰好为 k 的全 0 子数组？k ≥ 1 时，每一步若 run ≥ k，贡献 1；长度至少为 k 的贡献为 max(0, run − k + 1)。

改为所有元素都等于给定值 v？把 x == 0 改成 x == v，不变量和复杂度不变。
