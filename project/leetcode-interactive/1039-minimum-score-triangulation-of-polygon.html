多边形三角剖分的最低得分

把一个凸多边形切成三角形，让所有三角形的“顶点值乘积”之和尽可能小。先观察剖分如何拆开区间，再决定是否揭开题解。

MEDIUM数组动态规划多边形三角剖分

题目

给定一个凸 n 边形，顶点按顺时针排列，values[i] 表示第 i 个顶点的整数值。用不相交的对角线把它剖分成恰好 n - 2 个三角形。

每个三角形的分数等于三个顶点值的乘积；一次剖分的总分是全部三角形分数之和。返回所有合法三角剖分中的最小总分。

minScoreTriangulation(values: integer[]) → integer

约束与观察

  • n == values.length
  • 3 <= n <= 50
  • 1 <= values[i] <= 100
  • 顶点次序固定，且多边形为凸多边形。

提示：任选一条边作为区间边界，与某个中间顶点组成的三角形会把问题分为左右两个更小区间。

官方示例

示例 1

输入：values = [1,2,3]

输出：6

解释：只有一个三角形，分数为 1 × 2 × 3 = 6。

示例 2

输入：values = [3,7,4,5]

输出：144

解释：两种剖分总分分别是 3×7×5 + 4×5×7 = 245 与 3×4×5 + 3×4×7 = 144，所以最小值为 144。

示例 3

输入：values = [1,3,1,4,1,5]

输出：13

解释：一种最优剖分的总分为 1×1×3 + 1×1×4 + 1×1×5 + 1×1×1 = 13。

题解：区间动态规划

核心洞察

固定区间端点 i、j 作为一条边。它在某个三角形中必与中间顶点 k 相连；这个三角形把区间独立拆成 [i,k] 与 [k,j]。

状态与转移

令 dp[i][j] 为顶点 i..j 形成的子多边形的最小剖分得分。相邻或相同顶点不足以形成三角形，因此初值为 0。

dp[i][j] = min(dp[i][k] + dp[k][j] + values[i] × values[k] × values[j])，i < k < j

完整过程

  1. 建立 n × n 的零矩阵。
  2. 按区间长度从 3 到 n 枚举。
  3. 对每个区间 [i,j] 枚举三角形的第三个顶点 k。
  4. 取左右子问题加当前三角形分数的最小值。
  5. 答案为 dp[0][n-1]。

正确性证明

  1. 结构：任一合法剖分中，边 (i,j) 恰属于一个三角形 (i,k,j)。去掉它后，余下部分正好是两个互不重叠的子多边形。
  2. 最优子结构：最优剖分在左右子多边形上的剖分也必须分别最优；否则替换成更优子剖分会降低总分，产生矛盾。
  3. 完备性：转移枚举了所有 i<k<j，因此覆盖边 (i,j) 所有可能对应的三角形，也就覆盖所有剖分。
  4. 结论：取所有候选的最小值，得到 dp[i][j] 的最优值；按区间长度归纳，dp[0][n-1] 即全局最优。

边界与复杂度

n=3 时只计算一个三角形。顶点值均为正数，无需处理负权。时间复杂度 O(n³)，空间复杂度 O(n²)；在 n≤50 时足够。

替代方案与面试追问

记忆化搜索与自底向上 DP 等价，时间和空间复杂度相同，但会有递归开销。贪心选择当前乘积最小的耳朵不保证全局最优，因为一次切分会改变后续可组合的边。

  • 如何恢复具体对角线？另存使 dp[i][j] 最优的 k，递归回溯。
  • 能否降到 O(n²)？一般权值下没有该简单优化；转移的代价不直接满足常见单调优化条件。
  • 最大可能答案是否溢出？每个三角形至多 10⁶，共至多 48 个，32 位有符号整数足够。

常见错误

  • 把边界写成 k≤j，导致无效三角形或自依赖。
  • 忘记左右子区间已经包含自身的最优分数。
  • 区间长度从 2 开始，却错误地把两点当成三角形。
  • 枚举顶点次序时改变原顺时针顺序。

四种语言完整实现

Java
class Solution {
    public int minScoreTriangulation(int[] values) {
        int n = values.length;
        int[][] dp = new int[n][n];
        for (int len = 3; len <= n; len++) {
            for (int i = 0; i + len <= n; i++) {
                int j = i + len - 1;
                dp[i][j] = Integer.MAX_VALUE;
                for (int k = i + 1; k < j; k++) {
                    dp[i][j] = Math.min(dp[i][j],
                        dp[i][k] + dp[k][j]
                        + values[i] * values[k] * values[j]);
                }
            }
        }
        return dp[0][n - 1];
    }
}

Python
from typing import List

class Solution:
    def minScoreTriangulation(self, values: List[int]) -> int:
        n = len(values)
        dp = [[0] * n for _ in range(n)]
        for length in range(3, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                dp[i][j] = float("inf")
                for k in range(i + 1, j):
                    candidate = (dp[i][k] + dp[k][j]
                                 + values[i] * values[k] * values[j])
                    dp[i][j] = min(dp[i][j], candidate)
        return dp[0][n - 1]

class Solution {
public:
    int minScoreTriangulation(vector<int>& values) {
        int n = values.size();
        vector<vector<int>> dp(n, vector<int>(n));
        for (int len = 3; len <= n; ++len) {
            for (int i = 0; i + len <= n; ++i) {
                int j = i + len - 1;
                dp[i][j] = INT_MAX;
                for (int k = i + 1; k < j; ++k) {
                    dp[i][j] = min(dp[i][j],
                        dp[i][k] + dp[k][j]
                        + values[i] * values[k] * values[j]);
                }
            }
        }
        return dp[0][n - 1];
    }
};
