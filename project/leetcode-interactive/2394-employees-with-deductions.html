开除员工

2394 / Employees With Deductions

从打卡记录到月度工时，找出没有达到要求的员工。

2394
01 / THE BRIEF

先读规则，再动手

给定员工表 Employees 和打卡表 Logs。每名员工有月度最低工时；每次打卡形成一个工作段，其时长按分钟向上取整后计入当月。返回累计工时严格少于最低要求的员工 ID，顺序不限。

中文官方标题为“开除员工”，英文业务描述指扣薪。本页用“未达标”表示需返回的员工。51 分 2 秒计作 52 分钟；整 51 分钟仍计作 51 分钟。

思考：跨午夜的一段如何计算？没有打卡记录的人应该被忽略吗？

数据契约与约束

输入表结构
表字段与类型
Employeesemployee_id INT
needed_hours INT
Logsemployee_id INT
in_time DATETIME
out_time DATETIME
  • Employees.employee_id 唯一。
  • Logs 的联合主键为 (employee_id, in_time, out_time)。
  • 所有时间在 2022 年 10 月，out_time 可以在 in_time 的次日，允许跨午夜。
  • needed_hours 表示获得工资所需的最低小时数。
  • 结果仅包含 employee_id 一列。

可得题面未列行数、工时、ID 的数值上下界，此处不虚构限制。

05 / SOLUTION · OPTIONAL

把规则翻译成查询

先独立思考，再展开完整推导和代码。

核心洞察：先逐段取整，再求和

统一以分钟比较：每段贡献 ceil(秒差 / 60)，员工门槛为 needed_hours × 60。两段各 29 分 1 秒分别计 30 分钟，总计 60 分钟；若先合并秒数再取整，则只有 59 分钟，会误判未达标。

完整过程

  1. 用完整日期时间计算每条日志的秒差，保留跨午夜信息。
  2. 将秒差除以 60.0，向上取整为本段分钟数。
  3. 按 employee_id 分组并汇总计入分钟。
  4. 从 Employees 出发 LEFT JOIN 聚合结果，保留无日志员工。
  5. COALESCE 将缺失工时补零；累计分钟严格小于要求分钟时，输出 ID。

正确性

固定任一员工 e，每条日志的计入分钟与题目定义完全相同。按员工分组求和，恰好得到 e 的全部计入工时。左连接使每名员工都被考虑，无日志时补零恰好符合零工时的定义。最终严格小于条件与“未达到要求”相同，因此结果包含所有且仅包含未达标员工。

边界与常见错误

  • 无日志：INNER JOIN 会漏掉缺勤员工。
  • 等于门槛：应达标，不能使用 <=。
  • 含秒尾数：不能先用 TIMESTAMPDIFF(MINUTE) 截断。
  • 跨午夜：不可只相减时分秒。
  • 取整位置：CEIL 必须在 SUM 内。
  • NULL 工时：不补零会使比较得到未知值。

复杂度

设 E 为员工数、L 为日志数、G 为日志中的不同员工数。哈希聚合和哈希连接模型下，预期时间 O(L + E)，辅助空间 O(G)。排序聚合可能需要 O(L log L)，具体成本由执行计划决定。

替代方案

可先左连接日志，再按员工 ID 和 needed_hours 分组，用 HAVING 筛选。相关子查询也能实现，但未被优化时可能重复扫描日志；应结合索引与真实执行计划判断。

面试追问

  • 多个月份如何扩展？先明确日志按哪个月归属，跨月切段后还需重新约定取整粒度。
  • 重叠打卡是否去重？本题按每条日志累加，业务若要求去重，需要先合并时间区间。
  • 大表如何优化？减少扫描范围、考虑 employee_id 索引和预聚合，并查看执行计划。
  • 有时区怎么办？在一致的时间基准下计算时长，防止本机时区影响秒差。

完整查询，输入为题目两张表，输出 employee_id。尚未执行。

SELECT e.employee_id
FROM Employees AS e
LEFT JOIN (
    SELECT employee_id,
           SUM(CEIL(TIMESTAMPDIFF(SECOND, in_time, out_time) / 60.0))
               AS worked_minutes
    FROM Logs
    GROUP BY employee_id
) AS w ON w.employee_id = e.employee_id
WHERE COALESCE(w.worked_minutes, 0) < e.needed_hours * 60;

Java

import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.time.temporal.ChronoUnit;
import java.util.*;

public class Solution {
    public record Employee(int employeeId, int neededHours) {}
    public record Log(int employeeId, String inTime, String outTime) {}

    public static List<Integer> employeesWithDeductions(
            List<Employee> employees, List<Log> logs) {
        var fmt = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
        Map<Integer, Long> total = new HashMap<>();
        for (Log log : logs) {
            long seconds = ChronoUnit.SECONDS.between(
                LocalDateTime.parse(log.inTime(), fmt),
                LocalDateTime.parse(log.outTime(), fmt));
            total.merge(log.employeeId(), (seconds + 59) / 60, Long::sum);
        }
        List<Integer> result = new ArrayList<>();
        for (Employee e : employees)
            if (total.getOrDefault(e.employeeId(), 0L) < e.neededHours() * 60L)
                result.add(e.employeeId());
        return result;
    }
}

JavaScript

// employees: [{employee_id, needed_hours}]
// logs: [{employee_id, in_time, out_time}]
function employeesWithDeductions(employees, logs) {
  // 将题目无时区时间统一映射到 UTC，避免本机夏令时影响差值。
  const stamp = s => Date.parse(s.replace(" ", "T") + "Z");
  const total = new Map();
  for (const log of logs) {
    const seconds = (stamp(log.out_time) - stamp(log.in_time)) / 1000;
    total.set(log.employee_id,
      (total.get(log.employee_id) ?? 0) + Math.ceil(seconds / 60));
  }
  return employees
    .filter(e => (total.get(e.employee_id) ?? 0) < e.needed_hours * 60)
    .map(e => ({employee_id: e.employee_id}));
}

Python

from datetime import datetime
from collections import defaultdict

# employees 与 logs 都是字典列表；不是本题 Pandas 提交模板。
def employees_with_deductions(employees, logs):
    total = defaultdict(int)
    for log in logs:
        start = datetime.fromisoformat(log["in_time"])
        end = datetime.fromisoformat(log["out_time"])
        seconds = int((end - start).total_seconds())
        total[log["employee_id"]] += (seconds + 59) // 60
    return [
        {"employee_id": e["employee_id"]}
        for e in employees
        if total[e["employee_id"]] < e["needed_hours"] * 60
    ]

C++

#include <chrono>
#include <string>
#include <vector>
#include <unordered_map>
using namespace std;
using namespace std::chrono;

struct Employee { int employee_id; long long needed_hours; };
struct Log { int employee_id; string in_time, out_time; };

// C++20，输入为题目保证有效的无时区日历时间字符串。
sys_seconds stamp(const string& s) {
    year_month_day date{year{stoi(s.substr(0, 4))},
        month{static_cast<unsigned>(stoi(s.substr(5, 2)))},
        day{static_cast<unsigned>(stoi(s.substr(8, 2)))}};
    return sys_days{date} + hours{stoi(s.substr(11, 2))}
         + minutes{stoi(s.substr(14, 2))} + seconds{stoi(s.substr(17, 2))};
}
vector<int> employeesWithDeductions(const vector<Employee>& employees,
                                   const vector<Log>& logs) {
    unordered_map<int, long long> total;
    for (const auto& log : logs) {
        auto seconds = (stamp(log.out_time) - stamp(log.in_time)).count();
        total[log.employee_id] += (seconds + 59) / 60;
    }
    vector<int> result;
    for (const auto& e : employees)
        if (total[e.employee_id] < e.needed_hours * 60LL)
            result.push_back(e.employee_id);
    return result;
}
