Core insight

递增路径 + 可行上界

路径中的数字始终递增，所以同一集合只会出现一次。若当前还缺 need = k - path.length 个数，循环最多只能从 n - need + 1 选起；再晚就凑不满。

Invariant

循环不变量

path 严格递增且所有元素都小于下一层的 start。进入任意节点时，path 是一个合法前缀；长度等于 k 时即可复制进答案。

完整过程

  1. 1. 从 start = 1 和空路径开始。
  2. 2. 计算本层最大可选值 upper = n - (k - path.length) + 1。
  3. 3. 依次选择 i ∈ [start, upper]，递归进入 i + 1。
  4. 4. 返回后弹出 i，恢复路径，尝试下一个候选。
  5. 5. 路径长度达到 k 时保存副本并返回。

边界与复杂度

  • • k = 1：每个数字单独成组。
  • • k = n：只有 [1…n] 一组。
  • • 时间：O(C(n,k) × k)，包含复制输出的成本。
  • • 额外空间：O(k)；答案占 O(C(n,k) × k)。

替代方案取舍

位掩码枚举会检查 2ⁿ 个子集，n=20 尚可但浪费明显。字典序迭代可避免递归栈，却更难在面试中一次写对。回溯直接对应组合定义，配合上界剪枝最清晰。

常见错误

  • • 下一层仍传 i，导致重复选同一个数；应传 i + 1。
  • • 保存 path 本身而非副本，后续撤销会污染答案。
  • • 循环到 n 才发现凑不满，漏掉上界剪枝。
  • • 用 visited 数组制造额外状态；递增 start 已经保证不重复。

面试追问

为什么上界是 n - need + 1？

如何改成从数组而不是 [1,n] 中选 k 个？

若要求按字典序返回，当前实现是否满足？ 

class Solution {
    private final List<List<Integer>> answer = new ArrayList<>();
    private int n;
    private int k;

    public List<List<Integer>> combine(int n, int k) {
        this.n = n;
        this.k = k;
        backtrack(1, new ArrayList<>());
        return answer;
    }

    private void backtrack(int start, List<Integer> path) {
        if (path.size() == k) {
            answer.add(new ArrayList<>(path));
            return;
        }
        int need = k - path.size();
        int upper = n - need + 1;
        for (int value = start; value <= upper; value++) {
            path.add(value);
            backtrack(value + 1, path);
            path.remove(path.size() - 1);
        }
    }
}
var combine = function (n, k) {
    const answer = [];
    const path = [];

    const backtrack = (start) => {
        if (path.length === k) {
            answer.push([...path]);
            return;
        }
        const need = k - path.length;
        const upper = n - need + 1;
        for (let value = start; value <= upper; value++) {
            path.push(value);
            backtrack(value + 1);
            path.pop();
        }
    };

    backtrack(1);
    return answer;
};

public:
    vector<vector<int>> combine(int n, int k) {

        vector<int> path;

        function<void(int)> backtrack = [&](int start) {
            if (path.size() == k) {
                answer.push_back(path);
                return;

                backtrack(value + 1);
                path.pop_back();
            }
        };

        backtrack(1);
