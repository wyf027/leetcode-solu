最后一块石头的重量

Last Stone Weight｜一次只取最重的两块石头。先观察规则与粉碎过程，再决定是否展开完整题解。

EASY数组最大堆 / 优先队列非付费题
Problem

题目

给定整数数组 stones，每个元素代表一块石头的重量。每回合选择当前最重的两块，设为 x ≤ y：

  • 若 x = y，两块都消失；
  • 若 x ≠ y，较轻的消失，较重的变为 y - x。

最终至多剩一块石头。返回它的重量；若全部消失，返回 0。

函数参数

lastStoneWeight(stones: integer[]) → integer

约束

  • 1 ≤ stones.length ≤ 30
  • 1 ≤ stones[i] ≤ 1000
Examples

官方示例

示例 1
输入：stones = [2,7,4,1,8,1]
输出：1
解释：8 与 7 → 1；4 与 2 → 2；
      2 与 1 → 1；1 与 1 → 0；最后剩 1。
示例 2
输入：stones = [1]
输出：1

Solution

最大堆模拟

核心洞察

题目反复要求得到当前最大值。最大堆让堆顶始终是最重石头：每回合弹出两次，若重量不同，再把差值放回。它直接对应游戏机制。

完整过程

  1. 将全部石头建立为最大堆。
  2. 堆中至少有两项时，取出最大值 y 与次大值 x。
  3. 若 y > x，把 y - x 压回；相等则不放回。
  4. 循环结束，堆空返回 0，否则返回堆顶。

正确性

循环不变式：每轮开始时，堆中的元素恰好是此前粉碎后仍存在的全部石头，堆顶为其中最重者。建堆后成立。每轮取出的两项正是规则要求的最重两块；相等时删除两者，不等时仅加入差值，所以堆仍精确表示下一状态。不变式保持。终止时不足两块，返回唯一石头或 0 即为答案。

边界

  • 单元素直接返回。
  • 两块相等后堆为空，返回 0。
  • 差值与已有重量相同也照常入堆，无需去重。
  • 输入顺序不影响答案。

复杂度

建堆 O(n)；至多 n-1 轮，每轮常数次堆操作，总时间 O(n log n)，空间 O(n)。

四语言完整代码

Java
import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public int lastStoneWeight(int[] stones) {
        PriorityQueue<Integer> heap =
            new PriorityQueue<>(Collections.reverseOrder());
        for (int stone : stones) heap.offer(stone);
        while (heap.size() > 1) {
            int y = heap.poll(), x = heap.poll();
            if (y != x) heap.offer(y - x);
        }
        return heap.isEmpty() ? 0 : heap.peek();
    }
}
JavaScript
var lastStoneWeight = function(stones) {
  const h = [];
  const push = v => {
    h.push(v); let i = h.length - 1;
    while (i) {
      const p = (i - 1) >> 1;
      if (h[p] >= h[i]) break;
      [h[p], h[i]] = [h[i], h[p]]; i = p;
    }
  };
  const pop = () => {
    const top = h[0], last = h.pop();
    if (h.length) {
      h[0] = last; let i = 0;
      while (true) {
        let b=i,l=i*2+1,r=l+1;
        if(l<h.length&&h[l]>h[b]) b=l;
        if(r<h.length&&h[r]>h[b]) b=r;
        if(b===i) break;
        [h[i],h[b]]=[h[b],h[i]]; i=b;
      }
    }
    return top;
  };
  stones.forEach(push);
  while (h.length > 1) {
    const y=pop(), x=pop();
    if (y !== x) push(y-x);
  }
  return h.length ? h[0] : 0;
};
Python 3
from typing import List
import heapq

class Solution:
    def lastStoneWeight(self, stones: List[int]) -> int:
        heap = [-stone for stone in stones]
        heapq.heapify(heap)
        while len(heap) > 1:
            y = -heapq.heappop(heap)
            x = -heapq.heappop(heap)
            if y != x:
                heapq.heappush(heap, -(y - x))
        return -heap[0] if heap else 0

class Solution {

        while (heap.size() > 1) {
            int y=heap.top(); heap.pop();
            int x=heap.top(); heap.pop();
            if (y != x) heap.push(y-x);
        }

替代方案

每轮重新排序后取末尾两项更直观，但最坏约 O(n² log n)。也可利用重量上限 1000 做计数桶，从大到小配对；它依赖有限取值范围，代码更复杂。

面试追问

  • 数据流持续加入石头时，为什么堆更合适？
  • 若还要返回每次粉碎记录，如何设计返回结构？
  • 石头极多但重量上限很小时，桶方案复杂度如何表示？

常见错误

  • 误用最小堆，取出两块最轻石头。
  • 相等时仍把 0 放回堆。
  • 自写堆下沉时没有选择两个孩子中较大的一个。
  • 堆空时直接读取堆顶。
