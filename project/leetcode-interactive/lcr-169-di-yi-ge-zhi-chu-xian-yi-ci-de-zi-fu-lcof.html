招式拆解 II

在一串仅由小写字母组成的连招中，返回第一个只出现一次的招式；若不存在则返回空格。

字符串仅小写字母长度至多 50000

题意与示例

连招 arr 只由小写字母组成。返回第一个只出现一次的招式名称；若没有，返回一个空格字符 "␠"。这里的 ␠ 用来可视化空格。 

arr = "abbccdeff"
输出 = "a"
arr = "ccdd"
输出 = "␠"

限制：0 <= arr.length <= 50000。

题解：淘汰重复候选

核心洞察

只要知道“某字母是否已出现两次”，就能淘汰它；队列按原顺序保留尚未被淘汰的候选。处理完以后，从队首开始跳过频次大于一的字符，第一个留下的就是最早唯一字符。

完整过程

  1. 用长度 26 的计数表统计每个字符。
  2. 再按原顺序扫描：频次为 1 时立刻返回该字符。
  3. 扫描结束仍未返回，按要求返回 ' '。

边界与复杂度

空串、所有字符重复、唯一字符在尾部都必须覆盖。两次扫描都是 O(n)，计数表固定为 O(1) 空间。

替代方案、追问与常见错误

可用 LinkedHashMap 保留出现顺序，但对限定小写字母而言数组更轻。追问：若字符集扩展到 Unicode，计数容器改为哈希表。常见错误：无答案时返回空串；或只在第一次扫描时就把“暂时唯一”的字符当作最终答案。

可提交代码

class Solution {
    public char dismantlingAction(String arr) {
        int[] count = new int[26];
        for (char ch : arr.toCharArray()) count[ch - 'a']++;
        for (char ch : arr.toCharArray()) if (count[ch - 'a'] == 1) return ch;
        return ' ';
    }
}

  const count = new Array(26).fill(0);

  for (const ch of arr) if (count[ch.charCodeAt(0) - 97] === 1) return ch;

};
