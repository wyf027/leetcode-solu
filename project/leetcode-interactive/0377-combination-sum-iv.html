Problem

题目说明

给定一个由互不相同的正整数组成的数组 nums，以及正整数 target。每个数可以选取任意次，请返回和恰好等于 target 的有序选择序列数量。

例如，[1, 3] 与 [3, 1] 是两个不同方案。题目保证最终答案可放入 32 位整数。

函数形式：
combinationSum4(nums, target) → integer

约束

  • 1 ≤ nums.length ≤ 200
  • 1 ≤ nums[i] ≤ 1000
  • nums 中所有元素互不相同
  • 1 ≤ target ≤ 1000
  • 返回值在 32 位整数范围内
官方示例 1 
输入：nums = [1,2,3], target = 4
输出：7
解释：(1,1,1,1)、(1,1,2)、(1,2,1)、
      (1,3)、(2,1,1)、(2,2)、(3,1)
      顺序不同的序列分别计数。
官方示例 2 
输入：nums = [9], target = 3
输出：0
解释：无法使用 9 累加得到 3。
进阶思考：如果允许负数，正负数组成的零和循环可能生成无限多序列；必须增加序列长度上限、每个数的使用次数上限，或其他能排除无限循环的条件。

Solution

把“最后一步”拆开

核心洞察

令 dp[s] 表示和为 s 的有序序列数。任何到达 s 的序列都有唯一的最后一个数 x；移除它后，前缀之和就是 s - x。

dp[s] = Σ dp[s - x]，其中 x ∈ nums 且 x ≤ s

完整过程

  1. 设 dp[0] = 1，表示空序列这一种起点。
  2. 按 s = 1..target 从小到大计算。
  3. 枚举每个 x；若 x ≤ s，累加 dp[s-x]。
  4. 最终返回 dp[target]。

为什么外层必须枚举“和”

外层先枚举当前总和、内层枚举最后选择的数，会把不同选择顺序分别计数。若把数字放在外层，状态会倾向于只统计不考虑顺序的组合，那是另一类问题。

正确性证明

命题：计算完成后，每个 dp[s] 都等于和为 s 的有序序列数。

基础：dp[0] = 1 对应唯一空序列。

归纳：假设所有小于 s 的状态正确。把和为 s 的序列按最后一个数 x 分类；每类与和为 s-x 的序列一一对应，共有 dp[s-x] 个。不同最后元素的分类互不重叠，求和得到全部且无重复的序列。因此 dp[s] 正确。按归纳法，dp[target] 正确。

边界处理

  • dp[0] 必须是 1，否则所有状态都无法产生。
  • 当 x > s 时跳过，避免负下标。
  • 单个数可重复使用，无须删除或标记元素。
  • 示例代码采用宽整数或任意精度中间值，最终按题目保证转回整数。

复杂度

设 n = nums.length、T = target：

  • 时间：O(nT)
  • 空间：O(T)

若严格计入任意精度整数运算，复杂度还与数值位数有关；常规面试分析通常按一次加法为常数时间。

import java.math.BigInteger;
import java.util.Arrays;

class Solution {
    public int combinationSum4(int[] nums, int target) {
        BigInteger[] dp = new BigInteger[target + 1];
        Arrays.fill(dp, BigInteger.ZERO);
        dp[0] = BigInteger.ONE;

        for (int sum = 1; sum <= target; sum++) {
            for (int num : nums) {
                if (num <= sum) {
                    dp[sum] = dp[sum].add(dp[sum - num]);
                }
            }
        }
        return dp[target].intValue();
    }
}

替代方案

记忆化搜索：定义 dfs(remain)，枚举下一步并缓存剩余目标。它与自底向上的状态关系相同，表达更贴近递归选择，但有递归栈开销。

生成函数 / 矩阵加速：当步长集合很小、目标极大且递推阶数可控时可讨论；本题 target ≤ 1000，一维动态规划更直接。

常见错误

  • 把 nums 放在外层循环，误算成不区分顺序的组合数。
  • 把 dp[0] 初始化为 0，导致所有答案均为 0。
  • 误以为元素只能使用一次，加入不必要的去重或访问标记。
  • 允许负数后仍直接递归，没有限制长度，造成无限循环。
  • 代码的中间计数类型过窄，产生与目标返回值无关的溢出风险。

面试追问

  1. 如果不区分顺序？ 把数字放在外层循环、总和放在内层正序循环，使每种多重集合只生成一次。
  2. 如果每个数只能用一次？ 总和应倒序更新，并依据是否需要处理重复输入决定去重策略。
  3. 如果需要输出一个具体序列？ 在首次形成可达状态时记录前驱选择，再从目标反向恢复。
  4. 为什么负数危险？ 正负数可能构造零和环；在某条有效序列中任意插入该环，便得到无限多不同序列。
  5. 能否降低空间？ 一般仍需保留多个较早状态；若最大步长为 M，可用长度约 M 的环形缓冲区，但实现更复杂。
