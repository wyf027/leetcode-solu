小众书籍 Unpopular Books

在日期边界、上架资格与销量聚合之间做一次精确筛选。先理解查询目标，再打开底部题解。

MEDIUM数据库Paid Only基准日 2019-06-23

题目转述

书库由 Books 与订单表 Orders 组成。以 2019-06-23 为“今天”，找出过去一年内累计售出数量 少于 10 本的书；但上架不足一个月的书不参与评选。

返回 book_id 与 name。没有符合时间窗口的订单也应按销量 0 处理，因此不能让普通内连接提前丢掉这类书。

数据表

Books
  • book_id INT
  • name VARCHAR(50)
  • available_from DATE
Orders
  • order_id INT
  • book_id INT
  • quantity INT
  • dispatch_date DATE

约束与口径

  • book_id、order_id 唯一；订单中的书籍存在于 Books。
  • 统计窗口为过去一年：2018-06-23 至 2019-06-23（含边界）。
  • 仅考虑 available_from <= 2019-05-23 的书，即至少已上架一个月。
  • 筛选条件是窗口内 SUM(quantity) < 10；没有订单时销量为 0。

题解

核心洞察

销量为 0 的书也可能是“小众书”，所以从 Books 出发做 LEFT JOIN。最关键的一点是：订单日期条件必须放在 ON 中，才能保留没有窗口内订单的书。

两个独立时间条件

上架资格约束书籍本身；过去一年约束参与求和的订单。把两者混在同一个 WHERE 中，往往会破坏左连接语义。

完整过程

  1. 从 Books 筛选至少上架一个月的书。
  2. 左连接过去一年内的订单。
  3. 按书聚合，并用 COALESCE 将无订单的 SUM 转成 0。
  4. 在 HAVING 中保留销量小于 10 的组。

正确性说明

对每一本满足上架资格的书，连接只纳入统计窗口内的订单；分组后求和恰好得到过去一年销量。左连接保证空订单组仍存在，COALESCE 将其解释为 0。最后的 < 10 与题目条件等价，因此输出且仅输出所有小众书籍。

边界情况

  • 正好在窗口起止日的订单计入。
  • 正好上架一个月的书计入候选。
  • 无订单或只有窗口外订单的销量为 0。
  • 销量恰好 10 不输出；必须严格小于 10。

复杂度

设书籍数为 B、订单数为 O。逻辑扫描为 O(B + O)，分组空间约 O(B)；实际代价由优化器与索引决定。建议为 Orders(book_id, dispatch_date) 建复合索引。

替代方案

可先在派生表或 CTE 中按 book_id 聚合窗口内订单，再左连接 Books；结构更易读。也可用相关子查询计算每本书销量，但大数据量下通常不如一次预聚合稳定。

面试追问

  • 日期条件为何不能放 WHERE？
  • 数据库的日期减一个月如何处理月末？
  • 如何改成“连续 12 个自然月”？
  • 怎样用执行计划判断复合索引是否生效？

常见错误

使用 INNER JOIN 丢失零订单书；在 WHERE 过滤 Orders 导致 LEFT JOIN 退化；遗漏 COALESCE；误写 <= 10；把最近一个月上架的书仍放入统计；只统计“现在以前”但忘记一年前的下界。

参考实现

SELECT b.book_id, b.name
FROM Books AS b
LEFT JOIN Orders AS o
  ON o.book_id = b.book_id
 AND o.dispatch_date BETWEEN '2018-06-23' AND '2019-06-23'
WHERE b.available_from <= '2019-05-23'
GROUP BY b.book_id, b.name
HAVING COALESCE(SUM(o.quantity), 0) < 10;
import java.time.LocalDate;
import java.util.*;

record Book(int id, String name, LocalDate availableFrom) {}
record Order(int bookId, int quantity, LocalDate dispatchDate) {}

class Solution {
  static List<Book> unpopularBooks(List<Book> books, List<Order> orders) {
    LocalDate today = LocalDate.of(2019, 6, 23);
    LocalDate start = today.minusYears(1);
    LocalDate latestEligible = today.minusMonths(1);
    Map<Integer, Integer> sold = new HashMap<>();
    for (Order o : orders) {
      if (!o.dispatchDate().isBefore(start) && !o.dispatchDate().isAfter(today)) {
        sold.merge(o.bookId(), o.quantity(), Integer::sum);
      }
    }
    List<Book> answer = new ArrayList<>();
    for (Book b : books) {
      if (!b.availableFrom().isAfter(latestEligible)
          && sold.getOrDefault(b.id(), 0) < 10) answer.add(b);
    }
    return answer;
  }
}
function unpopularBooks(books, orders) {
  const start = "2018-06-23";
  const today = "2019-06-23";
  const latestEligible = "2019-05-23";
  const sold = new Map();
  for (const order of orders) {
    if (order.dispatch_date >= start && order.dispatch_date <= today) {
      sold.set(order.book_id,
        (sold.get(order.book_id) ?? 0) + order.quantity);
    }
  }
  return books.filter(book =>
    book.available_from <= latestEligible &&
    (sold.get(book.book_id) ?? 0) < 10
  );
}
from collections import defaultdict
from datetime import date

def unpopular_books(books, orders):
    start = date(2018, 6, 23)
    today = date(2019, 6, 23)
    latest_eligible = date(2019, 5, 23)
    sold = defaultdict(int)
    for order in orders:
        if start <= order["dispatch_date"] <= today:
            sold[order["book_id"]] += order["quantity"]
    return [book for book in books
            if book["available_from"] <= latest_eligible
            and sold[book["book_id"]] < 10]
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Book { int id; string name, availableFrom; };
struct Order { int bookId, quantity; string dispatchDate; };

vector<Book> unpopularBooks(const vector<Book>& books,
                            const vector<Order>& orders) {
  unordered_map<int, int> sold;
  for (const auto& o : orders)
    if (o.dispatchDate >= "2018-06-23" &&
        o.dispatchDate <= "2019-06-23")
      sold[o.bookId] += o.quantity;
  vector<Book> answer;
  for (const auto& b : books)
    if (b.availableFrom <= "2019-05-23" && sold[b.id] < 10)
      answer.push_back(b);
  return answer;
}
