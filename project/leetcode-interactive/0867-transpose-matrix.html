01 / Problem

题目说明

给定二维整数数组 matrix，返回它的转置矩阵。转置相当于沿主对角线翻转，使行索引与列索引互换。

参数与映射

matrix 有 m 行、n 列；结果应有 n 行、m 列。

answer[j][i] = matrix[i][j]
示例 1
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[1,4,7],[2,5,8],[3,6,9]]
示例 2
输入：matrix = [[1,2,3],[4,5,6]]
输出：[[1,4],[2,5],[3,6]]

约束

  • m == matrix.length
  • n == matrix[i].length
  • 1 <= m, n <= 1000
  • 1 <= m * n <= 105
  • -109 <= matrix[i][j] <= 109

所有行长度一致；至少包含一个元素。

04 / Solution

题解：按坐标直接搬运

核心洞察
转置不是交换数值，而是交换每个数值的两个坐标。

输入尺寸为 m × n，先创建 n × m 的结果，再令 answer[j][i] = matrix[i][j]。

完整过程

  1. 读取行数 m 与列数 n。
  2. 创建一个有 n 行、每行 m 列的新矩阵。
  3. 枚举每个原坐标 (i, j)。
  4. 把该值写入结果坐标 (j, i)，最后返回结果。

正确性说明

对任意合法原坐标 (i, j)，算法把且只把 matrix[i][j] 写到 answer[j][i]。这正是转置的定义。两层循环覆盖原矩阵全部 m × n 个坐标，因此结果中的每个位置都获得对应的原元素，所得矩阵必然是原矩阵的转置。

边界与复杂度

  • 单元素矩阵转置后不变。
  • 单行会变成单列，单列会变成单行。
  • 负数和大整数不影响坐标映射。
  • 时间复杂度：O(mn)。
  • 输出空间：O(mn)；除返回值外额外空间为 O(1)。

替代方案与面试追问

  • 库函数：Python 可用 zip(*matrix)，但面试时应解释坐标映射。
  • 能否原地？方阵可沿主对角线交换；一般矩形尺寸会变化，不适合简单原地处理。
  • 为何不能复用 m × n？当 m != n 时结果形状是 n × m。
  • 还能优化吗？必须读取全部元素，时间下界就是 Ω(mn)。

常见错误

  • 结果仍创建为 m × n。
  • 赋值写反成 answer[i][j] = matrix[j][i]，导致越界。
  • 循环上界混用 m 和 n。
  • 只处理方阵，忽略矩形示例。

一句话记忆

形状 m × n → n × m
坐标 (i, j) → (j, i)

class Solution {
    public int[][] transpose(int[][] matrix) {
        int m = matrix.length;
        int n = matrix[0].length;
        int[][] answer = new int[n][m];

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                answer[j][i] = matrix[i][j];
            }
        }
        return answer;
    }
}

from typing import List

class Solution:
    def transpose(self, matrix: List[List[int]]) -> List[List[int]]:
        m, n = len(matrix), len(matrix[0])
        answer = [[0] * m for _ in range(n)]

        for i in range(m):
            for j in range(n):
                answer[j][i] = matrix[i][j]

        return answer
