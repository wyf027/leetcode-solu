播放列表的数量

Number of Music Playlists

HARD数学动态规划组合数学

题目

播放器中有 n 首不同的歌。创建恰好包含 goal 次播放的列表（允许重复），要求每首歌至少出现一次；同一首歌再次出现前，必须已播放另外 k 首歌。返回合法列表数对 10⁹+7 取模的结果。

示例 1
输入：n = 3, goal = 3, k = 1
输出：6
解释：三首歌各出现一次，共 3! 种。
示例 2
输入：n = 2, goal = 3, k = 0
输出：6
解释：[1,1,2]、[1,2,1]、[2,1,1]、
[2,2,1]、[2,1,2]、[1,2,2]。
示例 3
输入：n = 2, goal = 3, k = 1
输出：2
解释：[1,2,1] 与 [2,1,2]。
参数与约束
  • numMusicPlaylists(n, goal, k)
  • 0 ≤ k < n ≤ goal ≤ 100
  • 返回整数，模 1,000,000,007

Solution

二维动态规划：新歌 / 旧歌

核心洞察

只记录已放入的次数 i 与出现过的不同歌曲数 j。具体歌曲身份与最近顺序可由可选数量概括。

完整过程

  1. 令 dp[i][j] 为长度 i、恰好使用 j 种歌的合法列表数。
  2. 加入新歌：从 dp[i-1][j-1] 转移，有 n-j+1 首未出现。
  3. 重播旧歌：从 dp[i-1][j] 转移，最近 k 首受限，有 max(j-k,0) 首可选。
  4. dp[i][j]=dp[i-1][j-1]·(n-j+1)+dp[i-1][j]·max(j-k,0)，每步取模。
  5. 返回 dp[goal][n]，保证所有歌曲至少出现一次。

正确性

基础状态 dp[0][0]=1。任意非空合法列表按末尾歌曲是否首次出现，唯一分为“新歌”和“旧歌”两类。删除末尾分别得到上述两个前驱状态；新歌有 n−j+1 种选择，旧歌排除最近 k 种后有 max(j−k,0) 种选择。两类互斥且覆盖全部列表，所以转移无重无漏；由归纳法，最终答案正确。

边界与复杂度

  • 除 dp[0][0] 外初值为 0，仅遍历 j≤min(i,n)。
  • goal=n 时答案为 n!；k=n-1 时重播限制最强。
  • 时间 O(goal·n)，空间 O(goal·n)；滚动数组可降至 O(n)。

替代方案、面试追问与常见错误

容斥结合排列计数也可求解，但推导更复杂。常见追问：如何滚动压缩、为何旧歌选择是 j−k、若每首歌至少出现 t 次如何扩展。常见错误：新歌数写成 n−j；忘记旧歌数截断为非负；返回 dp[goal][goal]；JavaScript 用 Number 相乘产生精度误差。

Java

class Solution {
    public int numMusicPlaylists(int n, int goal, int k) {
        final long MOD = 1_000_000_007L;
        long[][] dp = new long[goal + 1][n + 1];
        dp[0][0] = 1;
        for (int i = 1; i <= goal; i++)
            for (int j = 1; j <= Math.min(i, n); j++)
                dp[i][j] = (dp[i-1][j-1] * (n-j+1)
                    + dp[i-1][j] * Math.max(j-k, 0)) % MOD;
        return (int) dp[goal][n];
    }
}
