Remove K Digits

Solution

贪心地维护单调栈

核心洞察

比较两个长度相同的十进制字符串时，第一个不同位置上的数字更小者，整体数值就更小。因此，若已选择序列的末位大于当前数字，并且还有删除额度，立刻删掉这个更靠前的大数字一定更优。用栈维护已选择数字，就能在一次扫描中完成这种局部替换。

完整过程

  1. 建立空栈，从左到右扫描 num。
  2. 当仍可删除、栈非空且栈顶大于当前数字时，持续弹出栈顶并消耗一次额度。
  3. 把当前数字压栈。扫描结束后，若额度仍未用完，说明序列整体非递减，应从末尾删除剩余位数。
  4. 将栈拼接后去掉前导零；若结果为空，返回 "0"。

正确性说明

贪心选择：设扫描到数字 x，栈顶为更大的数字 y。保留 y 会让第一个可改变的位置仍为较大值；删除 y 并让更小的 x 前移，可使结果的字典序严格变小，所以只要额度允许，删除 y 不会劣于保留它。

循环不变式：处理完每个前缀后，栈保存的是在已使用删除次数下，该前缀能得到的字典序最小候选。弹出所有大于当前数字的栈顶后，再压入当前数字，仍保持该性质。

收尾：若扫描结束仍有额度，栈必为非递减序列。此时删除越靠后的数字，越能保留更小的前缀，所以从末尾删是最优的。由此最终结果最小。

边界情况

  • k == num.length：全部删除，返回 "0"。
  • 数字整体非递减（如 "1129"）：扫描中不会弹栈，最后从末尾删除。
  • 结果含前导零（如 "10200"）：最终统一去零，不在扫描阶段特殊处理。
  • 结果全为零或为空：规范化为单个 "0"。

复杂度

每个数字最多入栈一次、出栈一次，因此时间复杂度为 O(n)，辅助空间复杂度为 O(n)。

替代方案

可以重复寻找第一个下降位置并删除前一个数字，但字符串搬移会让最坏时间复杂度达到 O(nk)。也可从每个可选窗口中挑最小数字来构造答案，但需要更复杂的数据结构；单调栈在本题约束下更直接。

面试追问

  • 如果要求删除“至多” k 位，目标是否仍会使用全部额度？对无前导零的非负整数，删除一位通常会缩短长度并变小，但零值规范化需单独说明。
  • 如果字符代表任意进制，只要字符可按数位大小比较，算法主体是否改变？
  • 若输入以流形式到达，能否边读边处理？可以维护栈，但最终去前导零与完整输出仍需谨慎设计。

常见错误

  • 只弹出一次较大栈顶，而不是用 while 连续弹出。
  • 扫描结束后忘记消费剩余的 k。
  • 用整数类型解析输入，导致超出范围或丢失字符串结构。
  • 去除前导零后返回空串，而不是 "0"。
  • JavaScript 使用 shift() 逐个去零，带来不必要的数组搬移。

class Solution {
    public String removeKdigits(String num, int k) {
        StringBuilder stack = new StringBuilder();

        for (int i = 0; i < num.length(); i++) {
            char digit = num.charAt(i);
            while (k > 0 && stack.length() > 0
                    && stack.charAt(stack.length() - 1) > digit) {
                stack.deleteCharAt(stack.length() - 1);
                k--;
            }
            stack.append(digit);
        }

        stack.setLength(stack.length() - k);

        int firstNonZero = 0;
        while (firstNonZero < stack.length()
                && stack.charAt(firstNonZero) == '0') {
            firstNonZero++;
        }

        String answer = stack.substring(firstNonZero);
        return answer.isEmpty() ? "0" : answer;
    }
}

 * @param {string} num
 * @param {number} k
 * @return {string}

var removeKdigits = function(num, k) {
    const stack = [];

    for (const digit of num) {
        while (k > 0 && stack.length > 0
                && stack[stack.length - 1] > digit) {
            stack.pop();
            k--;
        }
        stack.push(digit);
    }

    if (k > 0) {
        stack.length -= k;
    }

    let firstNonZero = 0;
    while (firstNonZero < stack.length
            && stack[firstNonZero] === '0') {
        firstNonZero++;
    }

    const answer = stack.slice(firstNonZero).join('');
    return answer === '' ? '0' : answer;
};
class Solution:
    def removeKdigits(self, num: str, k: int) -> str:
        stack: list[str] = []

        for digit in num:
            while k > 0 and stack and stack[-1] > digit:
                stack.pop()
                k -= 1
            stack.append(digit)

        if k > 0:
            del stack[-k:]

class Solution {
public:
    string removeKdigits(string num, int k) {
        string stack;
        stack.reserve(num.size());

        for (char digit : num) {
            while (k > 0 && !stack.empty()
                    && stack.back() > digit) {
                stack.pop_back();
                --k;
            }
            stack.push_back(digit);
        }

        if (k > 0) {
            stack.resize(stack.size() - k);
        }

        size_t firstNonZero = stack.find_first_not_of('0');
        if (firstNonZero == string::npos) {
            return "0";
        }
        return stack.substr(firstNonZero);
    }
};
