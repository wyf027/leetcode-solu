Maximum Repeating Substring · 非付费题

01 · Problem

题目说明

maxRepeating(sequence, word) → int

题意转述

给定字符串 sequence 和 word。把 word 连续拼接 k 次，如果得到的完整字符串出现在 sequence 的某个连续位置中，就称 word 是 k 重复的。

返回满足条件的最大非负整数 k。若 word 连一次都不是子串，则答案为 0。

约束

  • 1 ≤ sequence.length ≤ 100
  • 1 ≤ word.length ≤ 100
  • sequence 与 word 仅包含小写英文字母。
示例 1 
输入：sequence = "ababc", word = "ab"
输出：2
解释："abab" 是 "ababc" 的子串。
示例 2 
输入：sequence = "ababc", word = "ba"
输出：1
解释："ba" 是子串，但 "baba" 不是。
示例 3 
输入：sequence = "ababc", word = "ac"
输出：0
解释："ac" 不是 "ababc" 的子串。

核心洞察

从一个 word 开始，每轮再追加一个 word。只要新候选仍是 sequence 的子串，就把答案加一；第一次失败时立即停止。

关键的单调性是：如果 word × k 已经不是子串，那么任何更长的 word × (k + 1) 也不可能是子串，因为更长串的前缀正是失败的候选。

完整过程

  1. 令候选串 repeated 为空，答案 k = 0。
  2. 检查 repeated + word 是否出现在 sequence 中。
  3. 若存在，将这个新串保存为 repeated，并令 k + 1，继续下一轮。
  4. 若不存在，当前 k 就是最大重复值，返回它。

正确性证明

不变式：每轮检查开始前，repeated = word × k，且它是 sequence 的子串。

保持：若 repeated + word 仍是子串，更新后新候选等于 word × (k + 1)，不变式继续成立。

终止：循环在 word × (k + 1) 首次不是子串时停止。此时 word × k 成立；更大的重复串都以这个失败串为前缀，因此也不可能成立。所以返回的 k 恰为最大值。

边界与复杂度

  • word 从未出现：第一次检查失败，返回 0。
  • word.length > sequence.length：同样直接返回 0。
  • 候选恰好等于 sequence：该轮成功，下一轮因过长而停止。
  • 设 n = sequence.length，朴素子串查找每轮最多 O(n)；轮数不超过 n / m，时间上界 O(n²)，额外空间 O(n)。

替代方案

动态规划：从左到右枚举结束位置；若当前位置之前长度为 word.length 的片段等于 word，则令 dp[i] = dp[i - m] + 1。它能直接统计以各位置结尾的连续重复次数。

KMP / 滚动哈希：当字符串规模很大时，可降低重复子串匹配的代价；本题长度最多 100，简单方案更清楚，也足够快。

面试追问与常见错误

  • 追问：若输入长度扩展到百万级，如何避免每轮重新扫描？可转向 DP + 高效片段匹配或 KMP。
  • 错误：只统计 word 出现次数；题目要求它们无缝连续拼接。
  • 错误：限制匹配必须从 sequence[0] 开始；合法串可以出现在任意位置。
  • 错误：成功后没有追加新的 word，导致循环无法前进。

class Solution {
    public int maxRepeating(String sequence, String word) {
        int k = 0;
        String repeated = "";

        while (sequence.contains(repeated + word)) {
            repeated += word;
            k++;
        }
        return k;
    }
}
