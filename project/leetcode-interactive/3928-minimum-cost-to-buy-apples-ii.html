LeetCode 3928 · Hard · 图 / 最短路

购买苹果的最低成本 II

出发时空载、返回时带苹果，同一条路在两个方向拥有不同权重。把每个商店当作起点，分别在“空载图”和“带货图”跑最短路，再在所有购买点取最小和。

题意

有 n 家商店和无向道路 [u, v, cost, tax]。从商店 i 可在本地花 prices[i] 购买，或空载到任意商店 j 购买后带货返回。空载经过道路的代价为 cost，带货返回则为 cost × tax；两条路线可以不同。

示例 1
n = 2，prices = [8, 3]
roads = [[0, 1, 1, 2]]
输出 [6, 3]：从 0 到 1 空载花 1，带货返回花 2，再买苹果花 3。
示例 2
n = 3，prices = [10, 11, 1]
roads = [[0,2,1,3],[1,2,3,4],[0,1,5,2]]
输出 [5, 11, 1]。

关键拆分

固定起点 i 与购买点 j：
空载最短路(i,j) + prices[j] + 带货最短路(i,j)。两段互不影响，因此各自求最短路即可。

约束：1 ≤ n ≤ 1000、roads.length ≤ 2000、cost ≤ 10⁹、tax ≤ 100。距离计算须用 64 位中间值。

输入中的空格以 ␠ 表示；逗号后空格可以省略。

题解：每个起点的两次 Dijkstra

完整过程

  1. 建两张无向图：empty 的边权为 cost，loaded 的边权为 cost × tax。
  2. 对每个起点 s，在两张图各跑一次 Dijkstra，得到 d0[j] 与 d1[j]。
  3. 扫描所有 j，取 d0[j] + prices[j] + d1[j] 最小值；j=s 自然覆盖本地购买。

边界与复杂度

图可能不连通，无法到达的商店不参与最小值。单次 Dijkstra 是 O((n+m) log n)；总复杂度 O(n(n+m) log n)，空间 O(n+m)。

替代方案与常见错误

不能把两段边权相加后只跑一次最短路：去程和回程允许走不同路线。也不要直接用 Floyd；在稀疏图上反复 Dijkstra 更贴近约束。距离与 cost × tax 的中间结果使用 64 位。

面试追问

若所有 tax 都相同，可否复用距离？只有当两张权图相差统一比例时才能复用；本题税率按边变化，不能复用。

import java.util.*;
class Solution {
  static final long INF = Long.MAX_VALUE / 4;
  long[] dijkstra(List<long[]>[] g, int s) {
    int n = g.length; long[] d = new long[n]; Arrays.fill(d, INF); d[s] = 0;
    PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0])); pq.offer(new long[]{0, s});
    while (!pq.isEmpty()) { long[] cur = pq.poll(); long x = cur[0]; int u = (int)cur[1]; if (x != d[u]) continue;
      for (long[] e : g[u]) { int v = (int)e[0]; long nx = x + e[1]; if (nx < d[v]) { d[v] = nx; pq.offer(new long[]{nx, v}); } }
    } return d;
  }
  public int[] minCost(int n, int[] prices, int[][] roads) {
    List<long[]>[] a = new ArrayList[n], b = new ArrayList[n]; for (int i=0;i<n;i++){a[i]=new ArrayList<>();b[i]=new ArrayList<>();}
    for (int[] r: roads) { long c=r[2], t=r[3]; a[r[0]].add(new long[]{r[1],c});a[r[1]].add(new long[]{r[0],c}); b[r[0]].add(new long[]{r[1],c*t});b[r[1]].add(new long[]{r[0],c*t}); }
    int[] ans=new int[n]; for(int s=0;s<n;s++){long[] x=dijkstra(a,s), y=dijkstra(b,s); long best=INF; for(int j=0;j<n;j++) if(x[j]<INF&&y[j]<INF) best=Math.min(best,x[j]+prices[j]+y[j]); ans[s]=(int)best;} return ans;
  }
}

from typing import List
import heapq
class Solution:
    def minCost(self, n: int, prices: List[int], roads: List[List[int]]) -> List[int]:
        def build(loaded):
            g=[[] for _ in range(n)]
            for u,v,c,t in roads:
                w=c*(t if loaded else 1); g[u].append((v,w)); g[v].append((u,w))
            return g
        def dij(g,s):
            d=[10**30]*n; d[s]=0; q=[(0,s)]
            while q:
                x,u=heapq.heappop(q)
                if x!=d[u]: continue
                for v,w in g[u]:
                    if x+w<d[v]: d[v]=x+w; heapq.heappush(q,(d[v],v))
            return d
        a,b=build(False),build(True); ans=[]
        for s in range(n):
            x,y=dij(a,s),dij(b,s); ans.append(min(x[j]+prices[j]+y[j] for j in range(n)))
        return ans
