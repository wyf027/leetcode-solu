752. 打开转盘锁Open the Lock

四个拨轮、每轮十个刻度、一次只能转动一格。避开所有死亡数字，从 0000 抵达目标，并求出最少拨动次数。

  • 起点固定为 0000
  • 0 与 9 首尾相接
  • 不可达时返回 -1

01 / Brief

题目说明

把每一个四位数字看成锁的一个状态。死亡数字一旦出现，锁会卡死，不能再从该状态继续转动。

任务

转盘锁有 4 个圆形拨轮，每个拨轮包含数字 0 到 9，并且可以循环转动：9 的下一格是 0，0 的上一格是 9。每次操作只能把一个拨轮转动一格。

锁从 0000 开始。给定死亡数字列表 deadends 与解锁数字 target，返回抵达目标的最少转动次数；若无法避开死亡数字抵达目标，则返回 -1。

约束

  • 1 <= deadends.length <= 500
  • deadends[i].length == 4
  • target.length == 4
  • target 不在 deadends 中
  • target 与每个死亡数字均只含数字字符
02 / Cases

官方示例

输入均保留完整参数形式，输出为最少拨动次数。

EX 01
输入deadends = ["0201","0101","0102","1212","2002"], target = "0202"
输出6

一条有效路线是 0000 → 1000 → 1100 → 1200 → 1201 → 1202 → 0202。经过 0102 的看似更短路线无效，因为 0102 是死亡数字。

EX 02
输入deadends = ["8888"], target = "0009"
输出1

最后一个拨轮从 0 反向转一格即可到达 9。

EX 03
输入deadends = ["8887","8889","8878","8898","8788","8988","7888","9888"], target = "8888"
输出-1

目标周围的八个相邻状态全部被封锁，因此无法进入 8888。

04 / Solution

核心洞察

这是一个边权全部为 1 的隐式图最短路问题。

四位字符串共有至多 10⁴ = 10000 种状态。每个合法状态恰有 8 个候选邻居：选择 4 个拨轮中的一个，向前或向后转一格。广度优先搜索按距离从小到大访问状态，所以第一次遇到目标时的层数就是最少拨动次数。
05 / Procedure

完整过程

队列保存待扩展状态及其距离；集合同时承担死亡数字过滤与去重职责。

  1. 把 deadends 放入哈希集合。若起点 0000 已死亡，立即返回 -1。
  2. 将 0000 入队并标记为已访问，初始距离为 0。
  3. 取出队首状态；如果它等于 target，返回当前距离。
  4. 依次选择四个位置，分别生成数字加一和减一的状态；用模 10 处理 9 → 0 与 0 → 9。
  5. 邻居若不是死亡数字且从未访问，就在入队时立刻标记，随后以距离加一入队。
  6. 若队列耗尽仍未找到目标，说明所有可达合法状态都已检查，返回 -1。
06 / Proof

正确性证明

证明分为邻居完备、层序最短和不可达判定三个部分。

1. 转移完整

一次合法操作只能选择一个拨轮并向两个方向之一转一格。算法对四个位置各生成加一、减一两个邻居，因此枚举了当前状态的全部且仅有的单步转移。

2. 首次到达最短

队列先处理距离为 d 的所有状态，再处理距离为 d + 1 的状态。若目标首次在第 d 层出现，则不存在长度小于 d 的未检查路线，所以 d 就是最少拨动次数。

3. 失败判定可靠

死亡状态从不入队，合法状态至多入队一次。队列为空时，起点可达的全部合法状态都已访问；此时仍未见目标，目标必然不可达。

07 / Bounds

边界与复杂度

状态空间规模固定且很小，但几个边界条件仍值得优先处理。

边界清单

  • 起点在死亡数字中：直接返回 -1
  • 目标就是 0000 且起点合法：返回 0
  • 目标四周全部被封锁：最终返回 -1
  • 拨轮跨过边界时必须正确处理 0 与 9 的循环
  • 应在入队时标记访问，避免同一状态重复进入队列
O(10⁴ × 4)时间：每个状态最多处理一次，每次检查 4 个拨轮的两个方向。
O(10⁴)空间：队列、死亡集合与访问集合最多保存整个状态空间。

四种语言实现

均采用单向 BFS，保持与官方提交签名一致。

import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.HashSet;
import java.util.Queue;
import java.util.Set;

class Solution {
    public int openLock(String[] deadends, String target) {
        Set<String> blocked = new HashSet<>(Arrays.asList(deadends));
        String start = "0000";
        if (blocked.contains(start)) return -1;

        Queue<String> queue = new ArrayDeque<>();
        Set<String> visited = new HashSet<>();
        queue.offer(start);
        visited.add(start);
        int turns = 0;

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            for (int i = 0; i < levelSize; i++) {
                String state = queue.poll();
                if (state.equals(target)) return turns;

                for (int wheel = 0; wheel < 4; wheel++) {
                    char[] digits = state.toCharArray();
                    int value = digits[wheel] - '0';

                    digits[wheel] = (char) ('0' + (value + 1) % 10);
                    addIfValid(new String(digits), blocked, visited, queue);

                    digits[wheel] = (char) ('0' + (value + 9) % 10);
                    addIfValid(new String(digits), blocked, visited, queue);
                }
            }
            turns++;
        }
        return -1;
    }

    private void addIfValid(
        String state,
        Set<String> blocked,
        Set<String> visited,
        Queue<String> queue
    ) {
        if (!blocked.contains(state) && visited.add(state)) {
            queue.offer(state);
        }
    }
}

var openLock = function(deadends, target) {
    const blocked = new Set(deadends);
    const start = "0000";
    if (blocked.has(start)) return -1;

    const queue = [start];
    const visited = new Set([start]);
    let head = 0;
    let turns = 0;

    while (head < queue.length) {
        const levelEnd = queue.length;

        while (head < levelEnd) {
            const state = queue[head++];
            if (state === target) return turns;

            for (let wheel = 0; wheel < 4; wheel++) {
                const value = Number(state[wheel]);
                for (const delta of [1, -1]) {
                    const nextDigit = (value + delta + 10) % 10;
                    const next =
                        state.slice(0, wheel) +
                        nextDigit +
                        state.slice(wheel + 1);

                    if (!blocked.has(next) && !visited.has(next)) {
                        visited.add(next);
                        queue.push(next);
                    }
                }
            }
        }
        turns++;
    }
    return -1;
};
from collections import deque
from typing import List


class Solution:
    def openLock(self, deadends: List[str], target: str) -> int:
        blocked = set(deadends)
        start = "0000"
        if start in blocked:
            return -1

        queue = deque([(start, 0)])
        visited = {start}

        while queue:
            state, turns = queue.popleft()
            if state == target:
                return turns

            for wheel in range(4):
                value = int(state[wheel])
                for delta in (1, -1):
                    next_digit = str((value + delta) % 10)
                    next_state = (
                        state[:wheel] + next_digit + state[wheel + 1:]
                    )
                    if next_state not in blocked and next_state not in visited:
                        visited.add(next_state)
                        queue.append((next_state, turns + 1))

        return -1
#include <queue>
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    int openLock(vector<string>& deadends, string target) {
        unordered_set<string> blocked(deadends.begin(), deadends.end());
        const string start = "0000";
        if (blocked.count(start)) return -1;

        queue<string> states;
        unordered_set<string> visited{start};
        states.push(start);
        int turns = 0;

        while (!states.empty()) {
            int levelSize = static_cast<int>(states.size());
            while (levelSize-- > 0) {
                string state = states.front();
                states.pop();
                if (state == target) return turns;

                for (int wheel = 0; wheel < 4; ++wheel) {
                    for (int delta : {1, -1}) {
                        string next = state;
                        int value = state[wheel] - '0';
                        next[wheel] = char('0' + (value + delta + 10) % 10);

                        if (!blocked.count(next) && !visited.count(next)) {
                            visited.insert(next);
                            states.push(next);
                        }
                    }
                }
            }
            ++turns;
        }
        return -1;
    }
};
09 / Follow-up

替代方案与面试追问

状态空间只有一万，普通 BFS 已足够；双向搜索是最自然的进阶讨论。

能否使用双向 BFS？

可以。从 0000 与 target 同时扩展，每次优先扩展较小的前沿；两侧相遇时得到最短距离。它通常减少实际访问状态数，但实现与边界处理更复杂。

为什么不使用 DFS？

DFS 会先深入某条路线，第一次抵达目标不保证最短；若要枚举全部路线再取最小值，代价更高且没有必要。

可以用整数表示状态吗？

可以。用 0 到 9999 的整数配合布尔数组，常数更小；但要谨慎处理前导零和每一位的进位、退位。字符串写法更直观。

若每种转动代价不同呢？

此时边权不再全为 1，普通 BFS 的层数不能代表总代价。非负权重应改用 Dijkstra；若权重仅为 0 或 1，可用 0-1 BFS。

常见错误

  • 把数字加减后忘记对 10 取模，导致 0 与 9 不能首尾相接
  • 出队时才标记访问，让同一状态被多个父节点反复入队
  • 只过滤生成的邻居，却忘记先检查起点是否属于死亡数字
  • 使用数组的头部删除作为 JavaScript 队列，造成不必要的搬移成本；使用游标更稳妥
  • 双向 BFS 中只检测当前层集合，却没有正确检测另一侧已访问集合
