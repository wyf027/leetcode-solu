岛屿的周长

Island Perimeter

一张由 0 与 1 构成的海图，一座没有湖泊的岛。你的任务只有一个：准确数出陆地与水相遇的每一条单位边。

01 / PROBLEM

题目

把二维网格看作俯视地图：1 是陆地，0 是水域，相邻只认上下左右。

题意转述

给定 row × col 的整数矩阵 grid。每个值为 1 的格子是一块边长为 1 的正方形陆地，值为 0 的格子是水域。陆地仅通过水平或垂直方向相连。

网格外围全是水，网格内恰好有一座由至少一个陆地格组成的连通岛屿，且岛内没有与外海隔绝的湖。返回岛屿边界的总长度。

函数形式

islandPerimeter(grid: integer[][]) → integer

约束

  • row == grid.length
  • col == grid[i].length
  • 1 ≤ row, col ≤ 100
  • grid[i][j] 只能是 0 或 1
  • 网格中恰好存在一个岛屿
  • 格子边长为 1；对角接触不算连接

示例 1

输入：grid = [[0,1,0,0],
              [1,1,1,0],
              [0,1,0,0],
              [1,1,0,0]]
输出：16
解释：岛屿边界共有 16 条单位边。

示例 2

输入：grid = [[1]]
输出：4

示例 3

输入：grid = [[1,0]]
输出：4

04 / SOLUTION

CORE IDEA

逐格贡献：4 减去共享边

每个陆地格单独看有 4 条边。如果它与另一块陆地相邻，两块格子之间的公共边在各自的 4 条边中被算了两次，但它并不属于外边界，因此应减去 2。

周长 = 4 × 陆地格数量 − 2 × 陆地相邻对数量

按行扫描时，只检查当前格子的上方和左方。这样每一对相邻陆地恰好在“较晚出现的格子”处处理一次，不会重复。

完整过程

  1. 初始化 perimeter = 0。
  2. 从上到下、从左到右遍历每个格子；水域直接跳过。
  3. 遇到陆地，先把它当作孤立正方形，令周长加 4。
  4. 若上方也是陆地，当前格与上方共享一条边，周长减 2。
  5. 若左方也是陆地，同理再减 2。
  6. 遍历完成后返回累计周长。

正确性证明

命题：算法返回全部陆地格组成图形的周长。

计数：先为每个陆地格贡献 4，得到所有正方形边数之和。任意一条陆地共享边属于恰好两个相邻陆地格，因此在该和中出现两次；它不是外边界，减 2 后恰好消除。

无重无漏：每对水平相邻格只在右侧格检查左边时处理，每对垂直相邻格只在下侧格检查上边时处理，所以所有共享边各处理一次。剩余的边恰好都是只属于一个陆地格的外露边，也就是周长。故算法正确。

复杂度

  • 时间：O(row × col)，每个格子只处理一次。
  • 额外空间：O(1)，只使用常数个变量。

边界情况

  • 单个陆地格：没有共享边，答案为 4。
  • 细长岛屿：相邻对照常被准确消除。
  • 陆地贴近网格边缘：网格外视为水，无需额外填充。
  • 全为陆地的矩形：内部边全部抵消，只保留矩形轮廓。

替代方案

四方向暴露边

对每个陆地检查上下左右；邻居越界或为水就加 1。直观且同为 O(row×col)，但每格最多做四次邻居判断。

DFS / BFS

从某块陆地出发遍历岛屿，遇到水或边界就贡献 1。适合与“岛屿搜索”类问题统一，但需要访问标记或修改网格，空间可达 O(row×col)。

完整相邻对计数

先数陆地，再单独统计横向和纵向相邻对，套用公式。结构清楚，但通常需要多次扫描。

四语言完整代码

Java官方签名
class Solution {
    public int islandPerimeter(int[][] grid) {
        int perimeter = 0;

        for (int row = 0; row < grid.length; row++) {
            for (int col = 0; col < grid[0].length; col++) {
                if (grid[row][col] == 0) {
                    continue;
                }

                perimeter += 4;
                if (row > 0 && grid[row - 1][col] == 1) {
                    perimeter -= 2;
                }
                if (col > 0 && grid[row][col - 1] == 1) {
                    perimeter -= 2;
                }
            }
        }

        return perimeter;
    }
}

面试追问

  • 如果有多座岛呢？ 本计数法无需修改，会返回全部岛屿的周长总和。
  • 如果岛中有湖呢？ 本计数法会把湖岸也算入总边界；若只要外海岸线，需要先标记与网格边界连通的水。
  • 如果网格很稀疏呢？ 可改用陆地坐标集合，只遍历陆地，并用哈希集合判断邻居。
  • 能在线更新吗？ 每次翻转一个格子，只需根据它四个邻居对周长做局部增减。

常见错误

  • 把对角线接触误判为共享边。
  • 检查四个方向却每次减 2，导致一条共享边减了 4。
  • 只减 1，却又只检查上方和左方，导致共享边只消除一半。
  • 访问 row - 1 或 col - 1 前忘记判边界。
  • 用递归搜索时忽略最坏深度，造成调用栈风险。
