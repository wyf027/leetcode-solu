Repeated DNA Sequences

让长度 10 的观察窗沿 DNA 链移动：每个碱基编码成 2 bit，最近 10 个碱基正好组成无碰撞的 20-bit 指纹。

先读题意 启动测序仪

Encoding contract

四种碱基，恰好两位 

A → 00
C → 01
G → 10
T → 11

10 letters × 2 bits = 20 bits
mask = (1 << 20) - 1

return every repeated window once

输入字符串只含 "A" / "C" / "G" / "T"。示例字符串保留成对直引号；␠ 代表可见空格，但合法 DNA 中没有空格。

01 / Contract

题意、样例与约束

固定窗口长度 10

枚举 s.length - 9 个窗口；只返回出现次数超过一次的窗口，答案顺序任意。

每个结果只输出一次

片段出现第 2 次时加入结果集，第 3、4 次不重复追加。 

Example 1
s = "AAAAACCCCCAAAAACCCCCCAAAAAGGGTTT"
expected = ["AAAAACCCCC","CCCCCAAAAA"]

Example 2
s = "AAAAAAAAAAAAA"
expected = ["AAAAAAAAAA"]

Constraints
1 <= s.length <= 100000
s[i] ∈ {"A","C","G","T"}

    04 / Algorithm

    题解默认隐藏

    展开后查看洞察、过程、边界、复杂度、替代方案与四语言代码。

    Solution unlocked

    20 位是无碰撞指纹

    字符集大小只有 4，2 bit 能唯一表示一个碱基。固定长度 10 的窗口一一映射到 20-bit 整数，不需要概率哈希。

    核心洞察与完整过程

    1. 映射 A/C/G/T → 0/1/2/3。
    2. 每读一个字符，执行 code = (code << 2) | bits。
    3. 用 (1 << 20) - 1 只保留最近 10 个碱基。
    4. 从第 10 个字符开始查询 seen 集；未见则加入 seen，已见则把当前子串加入 repeated 集。
    5. repeated 是集合，所以片段出现三次以上仍只输出一次。

    复杂度、边界与替代方案

    扫描一次，时间 O(n)；20-bit 状态最多 4^10 种，空间 O(min(n, 4^10))，答案存储另计。

    • n < 10 或恰好一个窗口时答案为空。
    • 窗口高度重叠不影响正确性，例如连续 13 个 A。
    • 直接用两个字符串 Set 最简洁，同样是期望 O(n)，但不断创建长度 10 子串。
    • 普通多项式 rolling hash 会有碰撞风险；这里的 2-bit 编码是固定窗口上的精确编码。

    import java.util.*;

class Solution {
    public List<String> findRepeatedDnaSequences(String s) {
        Map<Character, Integer> bits = Map.of(
            'A', 0, 'C', 1, 'G', 2, 'T', 3
        );
        Set<Integer> seen = new HashSet<>();
        Set<String> repeated = new LinkedHashSet<>();
        int code = 0;
        int mask = (1 << 20) - 1;

        for (int i = 0; i < s.length(); i++) {
            code = ((code << 2) | bits.get(s.charAt(i))) & mask;
            if (i >= 9 && !seen.add(code)) {
                repeated.add(s.substring(i - 9, i + 1));
            }
        }
        return new ArrayList<>(repeated);
    }
}

    from typing import List

class Solution:
    def findRepeatedDnaSequences(self, s: str) -> List[str]:
        bits = {"A": 0, "C": 1, "G": 2, "T": 3}
        seen = set()
        repeated = set()
        mask = (1 << 20) - 1
        code = 0

        for i, ch in enumerate(s):
            code = ((code << 2) | bits[ch]) & mask
            if i >= 9:
                if code in seen:
                    repeated.add(s[i - 9 : i + 1])
                else:
                    seen.add(code)
        return list(repeated)
    #include <string>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> findRepeatedDnaSequences(string s) {
        int bits[26] = {};
        bits['C' - 'A'] = 1;
        bits['G' - 'A'] = 2;
        bits['T' - 'A'] = 3;
        unordered_set<int> seen;
        unordered_set<string> repeated;
        vector<string> answer;
        int code = 0;
        const int mask = (1 << 20) - 1;

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            code = ((code << 2) | bits[s[i] - 'A']) & mask;
            if (i >= 9 && !seen.insert(code).second) {
                string window = s.substr(i - 9, 10);
                if (repeated.insert(window).second) answer.push_back(window);
            }
        }
        return answer;
    }
};

    常见错误

    • 窗口边界写成 i ≥ 10，漏掉第一个窗口。
    • 忘记掩码，旧字符一直留在 code 中。
    • 只用一个 seen 集，第三次出现时重复追加答案。
    • 把随机哈希误认为无碰撞编码。
    • 返回所有出现位置而非不同的重复片段。
