Missing Ranges

给定闭区间 [lower, upper] 与其中一个升序、互异整数数组 nums。找出没有出现在数组中的所有整数，并用最短、升序的闭区间列表准确覆盖它们。

01 / Brief

题意与边界

任务

若整数 x 位于闭区间 [lower, upper] 内且不在 nums 中，它就是缺失数。返回最短的升序区间列表：不包含任何已出现数字，同时覆盖每一个缺失数字。

输入保证

  • -10⁹ ≤ lower ≤ upper ≤ 10⁹
  • 0 ≤ nums.length ≤ 100
  • lower ≤ nums[i] ≤ upper
  • nums 升序且所有值互异

Example 1

Input:  nums = [0,1,3,50,75], lower = 0, upper = 99
Output: [[2,2],[4,49],[51,74],[76,99]]

Example 2

Input:  nums = [-1], lower = -1, upper = -1
Output: []
Reason: 区间内唯一数字已经出现，没有缺失数。

Solution unlocked

线性扫描 + 两个虚拟哨兵

当前格式提醒： 返回 [[start,end], ...]；旧资料中的 "start->end" 字符串格式已经不适用于当前题面。

核心洞察

把真实数组两侧想成多了两个仅用于比较的值：左侧 lower − 1，右侧 upper + 1。令 previous 指向上一个检查点，current 依次取每个数组值，最后再取右哨兵。

当 current − previous ≥ 2，两者中间至少有一个整数；完整缺口恰好是 [previous + 1, current − 1]。同一条判断自然覆盖数组为空、头部缺口、中间缺口和尾部缺口。

完整过程

  1. 创建答案列表，并令 previous = lower − 1。
  2. 从索引 0 扫到 nums.length（包含末尾这一轮）。
  3. 普通轮次令 current = nums[i]；末尾轮次令 current = upper + 1。
  4. 若二者距离至少为 2，加入闭区间 [previous + 1, current − 1]。
  5. 更新 previous = current，继续扫描；全部完成后返回答案。

边界核对

空数组

左右哨兵直接产生 [lower,upper]。

没有缺失

每次距离都是 1，答案保持为空。

单点区间

该点出现则为空；不出现则返回单点范围。

整数安全

Java 用 long，C++ 用 long long 保存哨兵。

Time

O(n)

每个数组元素只访问一次，外加一次右哨兵检查。

Auxiliary space

O(1)

不计算必须返回的答案空间；扫描状态只有常数个变量。

替代方案

nextExpected 指针

维护下一个应该出现的值；若当前数更大就输出缺口，再把指针推进到当前数之后。同为 O(n)，语义直观，但尾端要单独补一次判断。

三段式边界检查

分别检查首元素之前、相邻元素之间、末元素之后。代码容易讲清楚，但空数组分支与重复逻辑更多。

逐值枚举

遍历区间内每个整数并查询集合。适合作为小范围测试参考实现，不适合正式解法：区间跨度可达 2×10⁹。

排序后再扫描

若面试变体不保证有序，可先排序与去重，复杂度变为 O(n log n)；当前题目不需要。

面试追问

  • 若输入不再有序或允许重复，如何预处理并说明复杂度？
  • 若上下界允许到 32 位整数极值，如何避免 lower − 1 / upper + 1 溢出？
  • 若数组来自数据流，怎样边读边输出区间而不保存整个数组？
  • 怎样用性质测试验证“无已出现值被覆盖”且“所有缺失值恰好覆盖一次”？

常见错误

  • 仍按旧题面返回字符串，而不是二维整数列表。
  • 只扫描相邻数组元素，漏掉头部或尾部缺口。
  • 使用 current − previous > 0，把相邻数字误判为缺口；正确阈值是至少 2。
  • 忘记空数组，直接访问 nums[0] 或末元素。
  • 在更宽整数边界的变体中用 32 位变量构造哨兵，造成溢出。

Java

class Solution {
    public List<List<Integer>> findMissingRanges(
            int[] nums, int lower, int upper) {
        List<List<Integer>> answer = new ArrayList<>();
        long previous = (long) lower - 1;

        for (int i = 0; i <= nums.length; i++) {
            long current = i < nums.length
                    ? nums[i]
                    : (long) upper + 1;

            if (current - previous >= 2) {
                answer.add(List.of(
                        (int) (previous + 1),
                        (int) (current - 1)));
            }
            previous = current;
        }
        return answer;
    }
}

var findMissingRanges = function (nums, lower, upper) {
    const answer = [];
    let previous = lower - 1;

    for (let i = 0; i <= nums.length; i++) {
        const current = i < nums.length
            ? nums[i]
            : upper + 1;

        previous = current;
    }
    return answer;
};

        self, nums: List[int], lower: int, upper: int
    ) -> List[List[int]]:
        answer = []
        previous = lower - 1

        for i in range(len(nums) + 1):
            current = nums[i] if i < len(nums) else upper + 1

            if current - previous >= 2:
                answer.append([previous + 1, current - 1])
            previous = current

class Solution {
public:
    vector<vector<int>> findMissingRanges(
            vector<int>& nums, int lower, int upper) {
        vector<vector<int>> answer;
        long long previous = static_cast<long long>(lower) - 1;

        for (size_t i = 0; i <= nums.size(); ++i) {
            long long current = i < nums.size()
                    ? nums[i]
                    : static_cast<long long>(upper) + 1;

            if (current - previous >= 2) {
                answer.push_back({
                    static_cast<int>(previous + 1),
                    static_cast<int>(current - 1)
                });
            }
            previous = current;
        }
        return answer;
    }
};
