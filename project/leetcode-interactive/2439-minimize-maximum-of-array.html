最小化数组中的最大值

Minimize Maximum of Array

数值只能向左移动。你能把最高的一列降到多低？

阅读题目 ↓测试与验证 ↓先思考，再展开页底题解

01 / PROBLEM

题目与操作规则

给定从下标 0 开始的非负整数数组 nums，长度为 n。每次选择一个满足 1 ≤ i < n 且 nums[i] > 0 的位置，将该位置的 1 个单位移动到左边相邻的位置：

nums[i]     -= 1
nums[i - 1] += 1

允许执行任意次操作，包括零次。返回所有可达数组中，数组最大元素的最小可能值。不需要返回最终数组或操作序列。

约束

  • n == nums.length
  • 2 ≤ n ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁹

函数：minimizeArrayValue(nums: integer[]) → integer

02 / EXAMPLES

官方示例

示例 1

输入：nums = [3,7,1,6]
输出：5

依次选择下标 1、3、1，可得到：

[3,7,1,6]
→ [4,6,1,6]
→ [4,6,2,5]
→ [5,5,2,5]

最终最大值为 5，且无法降到更小。

示例 2

输入：nums = [10,1]
输出：10

不做任何操作已经最优。首位的 10 无法向右移动，因此最大值无法低于 10。

05 / SOLUTION

准备好再揭晓

核心洞察：每一段前缀都要装得下

设前 k 个元素的原始和为 Sₖ。这些单位无法向右流出这个前缀，只能留在内部，或者再从右边移入一些。若最终所有位置都不超过 M，必须满足 Sₖ ≤ k × M。

答案 = max₁≤ₖ≤ₙ ⌈Sₖ / k⌉
累加前缀和，维护所有前缀平均数向上取整的最大值。

完整过程

  1. 初始化 sum = 0、answer = 0。
  2. 遍历下标 i，将 nums[i] 加入 sum，当前前缀长度为 i + 1。
  3. 计算 ceil(sum / (i + 1))；整数除法等价写法为 (sum + i) / (i + 1)。
  4. 更新 answer 的最大值，扫描结束后返回。

正确性证明

必要性：任何前缀的总和只能保持或增加。若最终每个元素不超过 M，前 k 个位置最多容纳 kM 个单位，所以 M 必须不小于每一个 ⌈Sₖ/k⌉。

充分性：令 M 为这些下界的最大值。从右向左处理，每个位置超过 M 的部分全部搬到左邻居。记位置 i 的超额为 eᵢ = max(0, nums[i] + eᵢ₊₁ − M)，边界 eₙ = 0。递推展开后，最终位置 0 的负担是所有 Sₖ − (k−1)M 的最大值。由所有 Sₖ ≤ kM，这些负担均不超过 M。右侧位置也都已被处理到不超过 M，所以这个上限可达。

搬运量均为非负整数，只向左移动，可拆成合法单次操作。因此算法得到的既是必要下界，也是可实现的最优值。

边界与数值范围

  • 全零时返回 0；可以不做操作。
  • 首元素本身构成前缀，答案至少为 nums[0]。
  • 平均数非整数时必须向上取整。
  • 前缀和最大 10¹⁴，Java 使用 long，C++ 使用 long long。
  • JavaScript Number 可精确表示该范围的整数，不要用位运算取整。
  • 答案不超过原数组最大值，返回 int 足够。

复杂度

时间 O(n)：每个元素扫描一次。

额外空间 O(1)：只需前缀和与当前答案，不修改输入。

交互页保存快照以支持回退，其空间开销不属于提交算法。

四语言完整代码

使用官方函数签名，以下实现均待补验证。

Java

class Solution {
    public int minimizeArrayValue(int[] nums) {
        long sum = 0, answer = 0;
        for (int i = 0; i < nums.length; i++) {
            sum += nums[i];
            answer = Math.max(answer,
                (sum + i) / (i + 1));
        }
        return (int) answer;
    }
}

JavaScript

/**

var minimizeArrayValue = function(nums) {
    let sum = 0, answer = 0;
    for (let i = 0; i < nums.length; i++) {
        sum += nums[i];
        answer = Math.max(answer,
            Math.ceil(sum / (i + 1)));
    }
    return answer;
};

from typing import List

class Solution:
    def minimizeArrayValue(self, nums: List[int]) -> int:
        total = 0
        answer = 0
        for i, value in enumerate(nums):
            total += value
            answer = max(answer, (total + i) // (i + 1))
        return answer

C++

#include <algorithm>

class Solution {
public:
    int minimizeArrayValue(vector<int>& nums) {
        long long sum = 0, answer = 0;
        for (int i = 0; i < (int)nums.size(); ++i) {
            sum += nums[i];
            answer = max(answer,
                (sum + i) / (i + 1));
        }
        return (int)answer;

替代方案：二分答案

在 [0, max(nums)] 中二分候选上限 M。检查时从右向左计算超额：carry = max(0, nums[i] + carry − M)，最后判断 nums[0] + carry ≤ M。上限越大越容易可行，可二分最小可行值。

时间 O(n log(U+1))，U 为原数组最大值；空间 O(1)。这个思路适合从“猜一个上限”切入，前缀公式进一步消除了二分过程。

常见错误

  • 只看整体平均数：[10,1] 的整体平均数上取整为 6，但首位 10 不能减少。
  • 漏掉中间前缀：[0,9,0] 的前两个位置要求容量至少为 5。
  • 向下取整：[0,3] 需要上限 2，而非 1。
  • 按单位模拟：元素可达 10⁹，逐次搬运可能严重超时。
  • 累加溢出：不能用 32 位整型存前缀和，也不能用 JavaScript 的 |0 取整。

面试追问

  • 如何构造最优数组？先求 M，再从右向左把每个位置超出 M 的量一次性加到左邻居，数值运算 O(n)。
  • 只能向右移动呢？对称地检查所有后缀的平均数上取整。
  • 允许双向移动呢？结果就是整个数组平均数的上取整。
  • 限制操作次数呢？前缀容量下界仍必要，但不再充分，还需考虑移动距离与次数预算。
