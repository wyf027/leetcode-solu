删除链表的节点

给定单链表的头节点 head 和待删除节点值 val，删除第一个值等于 val 的节点，并返回新头节点。

题意与示例

链表节点按顺序相连。找到第一个值为 val 的节点后，让它的前驱跳过它；若删除的是头节点，直接返回原头节点的下一节点。

示例 1

head = [4,5,1,9], val = 5
输出 [4,1,9]

示例 2

head = [4,5,1,9], val = 4
输出 [5,1,9]

约束

  • 链表中至少有一个节点。
  • 节点值互不相同。
  • val 保证在链表中出现。

分步交互：前驱节点如何跳过目标

准备开始

初始链表为 4 → 5 → 1 → 9，目标值是 5。

核心洞察与完整过程

  1. 1. 特判头节点：若 head.val == val，答案就是 head.next。
  2. 2. 保持前驱指针：从头开始扫描，令 cur 表示当前节点的前驱。
  3. 3. 发现目标：当 cur.next.val == val 时，执行 cur.next = cur.next.next。
  4. 4. 返回 head：非头节点删除不会改变头指针。
链表删除的关键不是“清空目标节点”，而是修复它前面那条连接。

边界与复杂度

唯一节点：删除后返回 null。

删除头节点：无需遍历，直接后移头指针。

时间：O(n)，最坏扫描整条链表。

空间：O(1)，只使用常数指针。

替代方案

可用哑节点统一处理头节点与普通节点：令 dummy.next = head，再从 dummy 开始寻找前驱。代码更统一，但本题直接特判头节点更简洁。

追问

  • 若值可能重复？删除第一个、全部，还是指定位置，决定遍历逻辑。
  • 若只给目标节点且不是尾节点？可复制后继值并跳过后继。
  • 若要删除倒数第 k 个？使用快慢双指针。

常见错误

  • 未处理目标恰好是头节点。
  • 访问 cur.next.val 前没有确保 cur.next 非空。
  • 删除后继续使用已断开的节点引用。

参考题解代码

默认收起，按语言查看官方签名风格实现。 

// Java
class Solution {
    public ListNode deleteNode(ListNode head, int val) {
        if (head.val == val) return head.next;
        ListNode cur = head;
        while (cur.next.val != val) cur = cur.next;
        cur.next = cur.next.next;
        return head;
    }
}
// JavaScript
var deleteNode = function(head, val) {
  if (head.val === val) return head.next;
  let cur = head;
  while (cur.next.val !== val) cur = cur.next;
  cur.next = cur.next.next;
  return head;
};

// C++
class Solution {
public:
    ListNode* deleteNode(ListNode* head, int val) {
        if (head->val == val) return head->next;
        ListNode* cur = head;
        while (cur->next->val != val) cur = cur->next;
        cur->next = cur->next->next;
        return head;
    }
};
