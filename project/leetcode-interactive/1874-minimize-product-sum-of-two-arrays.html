最小乘积和

Minimize Product Sum of Two Arrays

数字不变，位置可变。如何让每一对的乘积，加起来尽可能小？

先读题并尝试独立思考；交互演示与代码位于底部折叠题解内。

01 / PROBLEM

题目与接口

给定两个长度均为 n 的整数数组 nums1、nums2。它们的乘积和是所有相同下标元素乘积的总和，即 Σ nums1[i] × nums2[i]。你可以任意重排 nums1 的元素，nums2 的位置保持不变。返回能得到的最小乘积和。

minProductSum(nums1: integer[], nums2: integer[]) → integer
  • n == nums1.length == nums2.length
  • 1 ≤ n ≤ 105
  • 1 ≤ nums1[i], nums2[i] ≤ 100

题号、接口和示例输入来自本地官方元数据；因付费题面为空，题意以自述方式补全，示例输出与约束参考 LeetCode Wiki 题目资料。官方题目入口。

官方示例

示例 1

nums1 = [5,3,4,2]
nums2 = [4,2,2,5]
输出 = 40

一种最优重排是 [3,5,4,2]，对应 3×4 + 5×2 + 4×2 + 2×5 = 40。

示例 2

nums1 = [2,1,4,5,7]
nums2 = [3,2,4,8,6]
输出 = 65

一种最优重排是 [5,7,4,1,2]，对应 5×3 + 7×2 + 4×4 + 1×8 + 2×6 = 65。

核心洞察：让两端相遇

把 nums1 从小到大排列，把 nums2 的位置按值从大到小访问。每次将最小的剩余 nums1 元素分配给最大的剩余 nums2 元素，再累加乘积。

代码为了只求总和，可以排序两个数组的副本。对 nums2 排序只是改变遍历位置的顺序：把得到的配对放回其原下标，就得到只重排 nums1 的合法方案。

完整过程

  1. 复制两个数组，保留调用者输入。
  2. 将副本 A 升序排序，B 降序排序。
  3. ans 从 0 开始，对 i = 0…n−1 累加 A[i] × B[i]。
  4. 返回 ans。每个元素恰好使用一次。

示例 1 的排序视图：A = [2,3,4,5]，B = [5,4,2,2]。各项贡献为 10、12、8、10，累计为 10、22、30、40。相等的两个 2 可以互换配对，因此最优重排未必唯一。

正确性：交换不会让答案变差

固定 A 为升序。若两个位置满足 a ≤ b，却配到了 c ≤ d，则这两对是“小配小、大配大”。把它们交换成 a×d 和 b×c，有：

旧贡献 − 新贡献
= (a*c + b*d) − (a*d + b*c)
= (b-a)*(d-c) ≥ 0

因此交换后总和不会增加。反复交换 B 中不符合降序的相邻对，最终得到 B 的降序排列。任意初始方案都能在不增加总和的情况下变成该配对，所以升序 A 与降序 B 的配对达到全局最小值。

排序副本只是重标记位置。记 B 中元素的原下标为 j，将它所配的 A 元素放进 nums1[j]，便恢复了 nums2 原顺序，证明结果满足题目只允许重排 nums1 的条件。

边界与复杂度

  • n = 1：直接返回唯一乘积；重复元素不影响证明。
  • 最大总和为 105 × 100 × 100 = 109，Java/C++ 的 32 位有符号整数足够，JavaScript Number 也可精确表示。
  • 以下代码都使用副本：时间 O(n log n)，额外空间 O(n)（含副本与常见排序辅助空间）。累加本身仅 O(n) 时间、O(1) 额外空间。
  • 官方输入不为空、长度相同且值合法；网页输入另行校验，不把演示上限当作题目约束。

替代方案

计数桶：值域只有 1–100，可分别计数，用 i 从 1 递增、j 从 100 递减，跳过空桶。每次取 k = min(cnt1[i], cnt2[j])，贡献 k×i×j，并从两个桶扣掉 k。时间 O(n+U)，空间 O(U)，U=100。它仍然使用相反次序配对，只是按一批相同值处理。

全排列：枚举 nums1 的所有排列并求和需要 O(n!·n)，只适合作为非常小规模的概念参照，不能解决本题完整规模。

Java

import java.util.Arrays;

class Solution {
    public int minProductSum(int[] nums1, int[] nums2) {
        int[] a = nums1.clone();
        int[] b = nums2.clone();
        Arrays.sort(a);
        Arrays.sort(b);
        int ans = 0;
        for (int i = 0; i < a.length; i++) {
            ans += a[i] * b[b.length - 1 - i];
        }
        return ans;
    }
}

JavaScript

/**

 * @param {number[]} nums2

var minProductSum = function(nums1, nums2) {
    const a = [...nums1].sort((x, y) => x - y);
    const b = [...nums2].sort((x, y) => y - x);
    let ans = 0;
    for (let i = 0; i < a.length; i++) {
        ans += a[i] * b[i];
    }
    return ans;
};

Python

from typing import List

class Solution:
    def minProductSum(
        self, nums1: List[int], nums2: List[int]
    ) -> int:
        a = sorted(nums1)
        b = sorted(nums2, reverse=True)
        ans = 0
        for x, y in zip(a, b):
            ans += x * y
        return ans

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int minProductSum(vector<int>& nums1,
                      vector<int>& nums2) {
        vector<int> a = nums1, b = nums2;
        sort(a.begin(), a.end());
        sort(b.rbegin(), b.rend());
        int ans = 0;
        for (int i = 0; i < (int)a.size(); ++i) {
            ans += a[i] * b[i];
        }
        return ans;
    }
};

常见错误

  • 两数组同向排序后直接同下标相乘：通常得到的是最大乘积和。
  • 只翻转未排序的数组：原顺序没有单调性保证。
  • JavaScript 使用无比较函数的 sort()：会按字符串次序排列，例如 100 在 2 前面。
  • 把“能排序 nums2 副本”理解为题目允许修改 nums2：这只是等价计算，原位置可通过索引映射还原。
  • 写成先求和再相乘：会额外引入不同下标之间的乘积项。

面试追问

如果要求最大乘积和？
同向排序，交换式的不等号含义给出对应的最大化结论。
如果允许负数，策略还成立吗？
成立。证明依赖 b−a 和 d−c 的非负性，而非元素本身为正；计数桶则要调整值域或改用排序。
如果必须输出重排后的 nums1？
保存 nums2 的值与原下标，按值降序排列位置，再把升序 nums1 依次写回这些位置。
如何利用值域 100 进一步优化？
使用前述计数桶批量配对，把比较排序的 O(n log n) 降到 O(n+100)。
