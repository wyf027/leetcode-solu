Binary Tree Right Side View

站在二叉树的右侧，每一层只会看见最靠右的一个节点。用层序遍历把树拆成一层层队列：每层最后出队的节点，就是镜头里留下的答案。

题解 · 一层一个右边界

核心洞察

BFS 能准确告诉我们“这批队列元素属于同一层”。当处理该层第 size - 1 个元素时，它就是从右侧能看见的节点；把它加入结果即可。

完整过程

  1. 空树直接返回空数组。
  2. 根节点入队；每轮先固定当前层长度 size。
  3. 依次出队 size 个节点，并将左右孩子入队。
  4. 仅在本层最后一次出队时记录节点值。

复杂度与边界

n 个节点各进出队一次：时间 O(n)；队列最多容纳树的最大宽度 O(w)，最坏 O(n)。

  • root = null：返回 []。
  • 单节点：该节点就是答案。
  • 只有左链：每层唯一节点仍可见。
  • 稀疏树：只看真实节点，不能把 null 当层内节点。

替代方案取舍

DFS 也可先访问右子树，并让“第一次到达某深度”入答案，空间为递归深度 O(h)。BFS 更直观地对应“每层最右”，也规避了深树递归栈风险。

常见错误：把每次出队都加入结果（得到完整层序遍历）；在内层循环中读取会变化的 queue.size()；或未在空树时提前返回。

面试追问

若改为左视图？记录每层第一个出队节点即可。若用 DFS？先右后左，当 depth == result.size() 时追加。若只求最后一层？在 BFS 结束时保留最后一个层级的列表。

class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        if (root == null) return ans;
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
                if (i == size - 1) ans.add(node.val);
            }
        }
        return ans;
    }
}
var rightSideView = function(root) {
  if (root === null) return [];
  const ans = [], queue = [root];
  let head = 0;
  while (head < queue.length) {
    const end = queue.length;
    let last;
    while (head < end) {
      const node = queue[head++]; last = node;
      if (node.left) queue.push(node.left);
      if (node.right) queue.push(node.right);
    }
    ans.push(last.val);
  }
  return ans;
};

class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        ans, queue = [], deque([root])
        while queue:
            size = len(queue)
            for i in range(size):
                node = queue.popleft()
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
                if i == size - 1:
                    ans.append(node.val)
        return ans
