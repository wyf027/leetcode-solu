Problem

题目描述

给定一棵二叉树的根节点 root，返回一个整数数组：数组的第 i 项，是树中第 i 层（从第 0 层开始）的最大节点值。空树没有任何层，因此返回空数组。

largestValues(root: TreeNode | null) -> integer[]
  • 树中节点数量范围：[0, 104]
  • 节点值范围：-231 ≤ Node.val ≤ 231 - 1

Solution

题解：固定层宽的广度优先搜索

核心洞察

队列能按层保存节点。每轮开始时记录当前队列长度 levelSize，接下来只弹出这固定数量的节点，并在它们之间维护最大值；期间加入的孩子属于下一层，不能混入本轮比较。

关键不变量：一轮内被处理的恰好是同一深度的全部节点，因此该轮最大值就是这一行的答案。

完整过程

  1. 若 root 为空，直接返回空数组。
  2. 把根节点加入队列；当队列不为空时，先保存此刻的队列长度。
  3. 把本层最大值初始化为负无穷，避免全负数层得到错误结果。
  4. 连续取出 levelSize 个节点，更新本层最大值，并把非空左右孩子加入队尾。
  5. 本层处理完后记录最大值，继续下一轮，直到队列为空。

正确性证明

  1. 初始化：第一次循环开始时，队列只有根节点，恰好包含第 0 层全部节点。
  2. 保持：假设某轮开始时队列前 levelSize 个元素恰好是第 d 层全部节点。算法逐一比较它们，故得到第 d 层最大值；同时只把这些节点的非空孩子加入队尾，这些孩子恰好构成第 d+1 层。
  3. 终止：有限树的所有节点最终各入队、出队一次。队列为空时每一层均已处理，结果数组依次包含所有层的最大值。

边界与复杂度

  • 空树：返回 []。
  • 单节点：只产生一个答案。
  • 全负数：最大值必须从负无穷或本层第一个节点开始，不能从 0 开始。
  • 极度偏斜：每层只有一个节点，答案就是根到叶的值序列。
  • 32 位边界值：四份实现都使用能覆盖官方取值范围的整数类型。
O(n)时间；每个节点只访问一次。
O(w)额外空间；w 为树的最大层宽。

替代方案：深度优先搜索

DFS 携带深度 depth。首次到达某一深度时追加节点值，再次到达时更新该位置最大值。时间同为 O(n)，递归栈最坏为 O(h)。当树很深时，递归实现可能栈溢出；BFS 的层边界更直观，也更贴合“每行”语义。

面试追问

  • 如果要返回每层最大节点本身而非数值，候选状态需要保存什么？遇到相同最大值如何定义选择规则？
  • 如果还要同时返回最小值、总和与平均值，怎样在同一次层扫描中完成？
  • 如果树无法一次放入内存，而是按层从外部流式读取，哪些状态必须保留？
  • DFS 与 BFS 的空间上界分别与树的哪些结构参数有关？

常见错误

  • 把本层最大值初始化为 0，导致全负数层返回 0。
  • 在内层循环中持续读取变化后的队列长度，误把下一层孩子也处理进当前层。
  • 空根节点仍然入队，随后访问空对象。
  • JavaScript 使用 shift() 反复搬移数组；用头指针可避免额外的线性移动成本。
  • 先加入结果再完成本层比较，造成记录的是中间值而非最终最大值。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Integer> largestValues(TreeNode root) {
        List<Integer> answer = new ArrayList<>();
        if (root == null) {
            return answer;
        }

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            int levelMax = Integer.MIN_VALUE;

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                levelMax = Math.max(levelMax, node.val);

                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            answer.add(levelMax);
        }

        return answer;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number[]}
 */
var largestValues = function(root) {
    if (root === null) return [];

    const answer = [];
    const queue = [root];
    let head = 0;

    while (head < queue.length) {
        const levelEnd = queue.length;
        let levelMax = -Infinity;

        while (head < levelEnd) {
            const node = queue[head++];
            levelMax = Math.max(levelMax, node.val);

            if (node.left !== null) queue.push(node.left);
            if (node.right !== null) queue.push(node.right);
        }
        answer.push(levelMax);
    }

    return answer;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque
from typing import List, Optional


class Solution:
    def largestValues(self, root: Optional[TreeNode]) -> List[int]:
        if root is None:
            return []

        answer = []
        queue = deque([root])

        while queue:
            level_max = float("-inf")

            for _ in range(len(queue)):
                node = queue.popleft()
                level_max = max(level_max, node.val)

                if node.left is not None:
                    queue.append(node.left)
                if node.right is not None:
                    queue.append(node.right)

            answer.append(level_max)

        return answer
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<int> largestValues(TreeNode* root) {
        if (root == nullptr) return {};

        vector<int> answer;
        queue<TreeNode*> nodes;
        nodes.push(root);

        while (!nodes.empty()) {
            int levelSize = static_cast<int>(nodes.size());
            int levelMax = numeric_limits<int>::min();

            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = nodes.front();
                nodes.pop();
                levelMax = max(levelMax, node->val);

                if (node->left != nullptr) nodes.push(node->left);
                if (node->right != nullptr) nodes.push(node->right);
            }
            answer.push_back(levelMax);
        }

        return answer;
    }
};
