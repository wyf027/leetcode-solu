01 / PROBLEM

题意与输入约定

给定一棵包含 n 个节点的无向树，以节点 0 为根。节点编号为 0 到 n − 1。数组 parent 描述父节点：parent[i] 是节点 i 的父节点，且 parent[0] = -1。字符串 s 为每个节点指定一个小写字母，节点 i 的字母是 s[i]。

返回满足“路径上每一对相邻节点的字母都不同”的最长简单路径的节点数。单独一个节点也构成合法路径。

参数与返回值

longestPath(parent: integer[], s: string)
→ integer（最长合法路径的节点数）

官方约束

  • n == parent.length == s.length
  • 1 ≤ n ≤ 10⁵
  • 对所有 i ≥ 1：0 ≤ parent[i] ≤ n − 1
  • parent[0] == -1
  • parent 保证表示一棵有效的树。
  • s 只包含小写英文字母。

INSIGHT / 最多两条分支

从叶子向上，保留最长的两条合法分支

把同字符的边看成无法通过的边。对任意路径，选取它深度最小的节点 u：路径在这里最多连接两个子树。若连接三个子树，就会产生分叉，不再是一条简单路径。

令 first[u]、second[u] 表示可以连接到 u 的最长、次长子节点向下链的节点数；空分支长度为 0。连接条件是子节点与 u 的字符不同。

经过 u 的最佳路径 = 1 + first[u] + second[u]
u 能提供给父节点的链 = 1 + first[u]
全局答案 = 所有节点的「经过 u 的最佳路径」的最大值

采用叶子队列完成后序处理：用 remaining[u] 记录尚未汇总的孩子数。没有未处理孩子的节点即可入队。这样无需递归，也无需构造邻接表，适合 10⁵ 节点的链。

节点 / 字符未处理孩子firstsecond处理状态


first / second 是已收到的合法子链长度；只有节点出队时才保证最终确定。此处为机制演示，所有验证仍待补。




完整过程
  1. 扫描 parent[1..n−1]，统计每个节点的孩子数。两条最长分支均初始化为 0，答案初始化为 1。
  2. 将所有孩子数为 0 的节点加入队列。它们可以立即确定状态。
  3. 取出节点 u，用 1 + first[u] + second[u] 更新全局答案。
  4. 若 u 有父节点 p 且 s[u] != s[p]，把 1 + first[u] 合并进 p 的前两大分支长度。
  5. 无论字符是否相同，都将父节点的未处理孩子数减一；归零时把父节点入队。相同字符只阻断路径，不阻断处理顺序。
  6. 队列清空后返回全局答案。
以示例 2 为例：节点 1 的字符与根相同，链被拦下；节点 2、3 各传来长度 1 的链。根节点最终组合出 1 + 1 + 1 = 3，对应路径 2 → 0 → 3。


为什么正确
1. 单链状态正确
叶子没有子分支，向上链长是 1。假设孩子出队时的单链都正确，当节点 u 出队时所有孩子均已处理。合法向下链只能选择一个字符不同的孩子，因此选最大子链后加上 u，即 1 + first[u]，恰好得到最优单链。
2. 两分支组合既合法又最优
最长和次长分支来自不同孩子。它们分别合法且都能经过一条字符不同的边连到 u，而不同子树互不相交，因此组合得到合法简单路径。经过 u 且不进入其父节点的路径最多选择两个孩子，所以长度不可能超过这两条最大分支的总和再加 1。
3. 全局枚举没有遗漏
任意路径有唯一的最浅节点。该路径要么只有这个节点，要么向一个或两个孩子延伸，均被该节点的候选值覆盖。对所有节点取最大值就得到全局最优，包含完全位于同字符断边下方的路径。
4. 处理顺序保证上述前提
未处理孩子数只在一个孩子处理完后递减一次。有限树从叶子开始逐层剥离，每个节点恰好入队、出队一次，父节点一定在全部孩子之后出队。


边界与复杂度
  • 单节点：答案为 1。
  • 全同字符：不能通过任何边，答案仍为 1。
  • 交替字符链：可覆盖全部节点；迭代实现不消耗递归栈。
  • 重复长度：两个不同孩子的等长分支都要保留。
  • 父编号更大：队列按依赖顺序工作，不假设节点编号有序。
时间 O(n)，额外空间 O(n)。计数扫描与队列处理都只遍历节点一次；四个线性数组保存计数、两条分支及队列。
替代方案
递归树形 DP：相同的两个分支公式，DFS 后序实现简短，但深链在 Python / JavaScript 等环境中可能栈溢出。可用显式栈生成后序替代递归。
删边后求森林直径：去掉同字符边，逐连通分量用两次 BFS 求直径（边数加一），总体 O(n)。需要邻接表和遍历标记，结构更直观，但实现通常更长。
从每个点枚举路径：最坏 O(n²)，只适合小数据解释或后续对拍，不适合本题上限。


常见错误
  • 把答案计为边数，忘记中心节点的 +1。
  • 向父节点上传 first + second + 1：这已是一条双分支路径，再接父节点会分叉。只能上传 first + 1。
  • 遇到同字符边就跳过整个子树，漏掉子树内部最优路径。
  • 同字符孩子处理完后不减少计数，使父节点永远不能入队。
  • 只返回根的单链，遗漏跨两个子树或完全不经过根的答案。
  • 用 queue.shift() 反复移除数组头部，可能增加搬移成本；使用递增的队首下标。
  • 直接倒序扫描编号；约束没有保证 parent[i] < i。

Java
class Solution {
    public int longestPath(int[] parent, String s) {
        int n = parent.length;
        int[] remaining = new int[n];
        int[] first = new int[n];
        int[] second = new int[n];
        int[] queue = new int[n];
        for (int i = 1; i < n; i++) remaining[parent[i]]++;
        int head = 0, tail = 0, answer = 1;
        for (int i = 0; i < n; i++) {
            if (remaining[i] == 0) queue[tail++] = i;
        }
        while (head < tail) {
            int u = queue[head++];
            answer = Math.max(answer, 1 + first[u] + second[u]);
            int p = parent[u];
            if (p == -1) continue;
            if (s.charAt(u) != s.charAt(p)) {
                int length = 1 + first[u];
                if (length > first[p]) {
                    second[p] = first[p];
                    first[p] = length;
                } else if (length > second[p]) {
                    second[p] = length;
                }
            }
            if (--remaining[p] == 0) queue[tail++] = p;
        }
        return answer;
    }
}

Python 3
from typing import List

class Solution:
    def longestPath(self, parent: List[int], s: str) -> int:
        n = len(parent)
        remaining = [0] * n
        first = [0] * n
        second = [0] * n
        for i in range(1, n):
            remaining[parent[i]] += 1
        queue = [i for i in range(n) if remaining[i] == 0]
        head, answer = 0, 1
        while head < len(queue):
            u = queue[head]
            head += 1
            answer = max(answer, 1 + first[u] + second[u])
            p = parent[u]
            if p == -1:
                continue
            if s[u] != s[p]:
                length = 1 + first[u]
                if length > first[p]:
                    second[p] = first[p]
                    first[p] = length
                elif length > second[p]:
                    second[p] = length
            remaining[p] -= 1
            if remaining[p] == 0:
                queue.append(p)
        return answer


C++
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int longestPath(vector<int>& parent, string s) {
        int n = static_cast<int>(parent.size());
        vector<int> remaining(n), first(n), second(n), queue;
        queue.reserve(n);
        for (int i = 1; i < n; ++i) ++remaining[parent[i]];
        for (int i = 0; i < n; ++i) {
            if (remaining[i] == 0) queue.push_back(i);
        }
        int answer = 1;
        for (int head = 0; head < static_cast<int>(queue.size()); ++head) {
            int u = queue[head];
            answer = max(answer, 1 + first[u] + second[u]);
            int p = parent[u];
            if (p == -1) continue;
            if (s[u] != s[p]) {
                int length = 1 + first[u];
                if (length > first[p]) {
                    second[p] = first[p];
                    first[p] = length;
                } else if (length > second[p]) {
                    second[p] = length;
                }
            }
            if (--remaining[p] == 0) queue.push_back(p);
        }
        return answer;
    }
};




面试追问
如何返回路径本身？
维护前两大链对应的孩子编号，并保存全局最优中心节点。从中心沿两个孩子的最长链分别恢复，反转其中一段后拼上中心和另一段；避免在 DP 内复制整条路径，以保持 O(n)。
如果节点带权呢？
将长度改为权值和。正权时公式相同；允许负权时，子分支可以不选，用 0 截断负贡献，但非空路径答案应从实际节点权值初始化，不能固定为 0。
字符会动态修改怎么办？
一次修改可能使相邻边的可用性改变，并影响很长的祖先链。当前 O(n) 静态解可以整体重算；高频更新需要另行设计动态树结构，不能声称仅更新一个节点状态就足够。
