题解 · 单调递减双端队列

留下仍可能成为冠军的山峰

核心洞察

队列按海拔从大到小保存下标。新山峰进入时，队尾所有高度不大于它的山峰都可永久移除：它们更矮、又更早离开窗口，之后不可能再胜出。队首如果落到窗口左边界之外，也立刻出队。

完整过程

  1. 读到下标 i 前，移走 i - limit 及更早的队首下标。
  2. 从队尾弹出高度 ≤ heights[i] 的下标，再把 i 入队。
  3. 当 i ≥ limit - 1 时，队首就是当前完整窗口最大值。

边界与复杂度

limit = 1 时每个元素自己就是答案；重复值保留较新的下标以延后过期；全负数同样适用。每个下标最多入队、出队各一次，时间 O(n)，空间 O(limit)。

替代方案、追问与常见错误

  • 堆可做到 O(n log limit)，但需惰性删除过期元素；逐窗口扫描是 O(n × limit)。
  • 追问：若要窗口最小值，把队列改为递增；若窗口长度可变，过期边界仍由左指针控制。
  • 常见错误：队列存值却无法判断是否过期；忘记在读入后才对完整窗口输出；弹队尾只用 < 导致重复值占用更多空间（正确但不如 ≤ 简洁）。

class Solution {
    public int[] maxAltitude(int[] heights, int limit) {
        Deque<Integer> dq = new ArrayDeque<>();
        int[] ans = new int[heights.length - limit + 1];
        for (int i = 0; i < heights.length; i++) {
            while (!dq.isEmpty() && dq.peekFirst() <= i - limit) dq.pollFirst();
            while (!dq.isEmpty() && heights[dq.peekLast()] <= heights[i]) dq.pollLast();
            dq.offerLast(i);
            if (i >= limit - 1) ans[i - limit + 1] = heights[dq.peekFirst()];
        }
        return ans;
    }
}

var maxAltitude = function (heights, limit) {
  const dq = [], ans = [];
  let head = 0;
  for (let i = 0; i < heights.length; i++) {
    while (head < dq.length && dq[head] <= i - limit) head++;
    while (dq.length > head && heights[dq[dq.length - 1]] <= heights[i]) dq.pop();
    dq.push(i);
    if (i >= limit - 1) ans.push(heights[dq[head]]);
  }
  return ans;
};
from collections import deque
from typing import List

class Solution:
    def maxAltitude(self, heights: List[int], limit: int) -> List[int]:
        dq, ans = deque(), []
        for i, height in enumerate(heights):
            while dq and dq[0] <= i - limit: dq.popleft()
            while dq and heights[dq[-1]] <= height: dq.pop()
            dq.append(i)
            if i >= limit - 1: ans.append(heights[dq[0]])
        return ans
class Solution {
public:
    vector<int> maxAltitude(vector<int>& heights, int limit) {
        deque<int> dq;
        vector<int> ans;
        for (int i = 0; i < (int)heights.size(); ++i) {
            while (!dq.empty() && dq.front() <= i - limit) dq.pop_front();
            while (!dq.empty() && heights[dq.back()] <= heights[i]) dq.pop_back();
            dq.push_back(i);
            if (i >= limit - 1) ans.push_back(heights[dq.front()]);
        }
        return ans;
    }
