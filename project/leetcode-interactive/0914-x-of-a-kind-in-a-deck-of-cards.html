X of a Kind in a Deck of Cards

给定整数数组 deck，判断能否选择同一个 X ≥ 2，把所有牌分为一组或多组；每组恰有 X 张，且组内数字相同。

输入与返回

函数接收 deck: integer[]，其中 deck[i] 表示第 i 张牌上的整数。若存在统一组大小 X，返回 true；否则返回 false。

约束

  • 1 ≤ deck.length ≤ 104
  • 0 ≤ deck[i] < 104
  • 必须用完所有牌，且 X > 1。

官方示例 1

输入：deck = [1,2,3,4,4,3,2,1]
输出：true
解释：可分为 [1,1]、[2,2]、[3,3]、[4,4]。

官方示例 2

输入：deck = [1,1,1,2,2,2,3,3]
输出：false
解释：不存在满足要求的分组。

先形成自己的判断，再揭晓题解

每种点数的出现次数，必须同时满足怎样的整除关系？

Solution

题解：所有频次的最大公约数

每种牌的出现次数都必须被统一的 X 整除。因此，存在 X ≥ 2，当且仅当所有出现次数的最大公约数 ≥ 2。

完整过程

  1. 用哈希表统计每个数字的出现次数。
  2. 从 g = 0 开始，依次令 g = gcd(g, 当前频次)。
  3. 最终 g ≥ 2 则返回 true，否则返回 false。

边界

  • 只有一种牌：数量至少为 2 才可行。
  • 任一种牌只出现一次：最大公约数必为 1。
  • 可取 X = g，也可取 g 的任意大于 1 的因数。

复杂度

牌数 n、不同数字数 k、最大频次 M：时间 O(n + k log M)，空间 O(k)。

正确性证明

必要性：若能按 X 分组，同一数字的频次是若干个 X 之和，故所有频次都能被 X 整除，最大公约数至少为 X ≥ 2。

充分性：若频次的最大公约数 g ≥ 2，每个频次都可被 g 整除；把每种数字每 g 张分为一组即可用完所有牌。

必要性与充分性同时成立，算法正确。

替代方案

可从 2 枚举到最小频次并逐一检查整除，但会重复取模；最大公约数直接刻画共同组大小。

常见错误

  • 只检查总牌数是否整除。
  • 直接取最小频次，却不检查其他频次。
  • 允许 X = 1。
  • 只对两个频次求 gcd，未归并全部频次。

面试追问

  • 为何 g 从 0 开始？ gcd(0,a)=a。
  • 能否提前结束？ g 变为 1 后不会再回升。
  • 全部可行 X？ g 的所有大于 1 的因数。
  • 哈希表必要吗？ 值域固定时也可用计数数组。
