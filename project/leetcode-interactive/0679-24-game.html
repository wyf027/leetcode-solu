题意与规则

题目描述

给定长度为 4 的整数数组 cards。每张卡片上的数字都在 [1, 9] 范围内。需要将四个数字各使用一次，通过 +、-、*、/ 与括号组成表达式，使结果等于 24。若可以做到，返回 true；否则返回 false。

必须遵守

  • 除法是实数除法，不是整数除法。例如 4 / (1 - 2 / 3) = 12。
  • 每次操作必须连接两个数，不能把减号当作一元负号。例如 [-1, -1, -1, -1] 形式的构造不合法。
  • 不能拼接数字。例如输入 [1,2,1,2] 时，12 + 12 不合法。

官方示例 1

输入：cards = [4,1,8,7]

输出：true

解释：(8 - 4) * (7 - 1) = 24

官方示例 2

输入：cards = [1,2,1,2]

输出：false

回溯：枚举每一次两两合并

核心洞察完整过程正确性复杂度四语言代码测试与验证

核心洞察

不要枚举字符串、运算符位置和括号形状。任何合法表达式的最外层一定是“左子表达式 ⊙ 右子表达式”。反过来看，只要每次从当前集合任取两个值，用一种二元运算合并，再把结果放回集合，就能覆盖所有表达式树。

当集合只剩一个值时，用误差阈值 EPS 判断它是否接近 24。

完整过程

  1. 把四个整数转成浮点数。
  2. 枚举下标 i < j，取出两个值 a、b。
  3. 保留其他值，依次放回 a+b、a-b、b-a、a*b、a/b、b/a。
  4. 对缩短后的数组递归；任一分支成功就立刻返回。
  5. 除数接近零时跳过对应除法。

正确性证明

  1. 覆盖性：任意合法表达式都对应一棵二叉表达式树。树根连接两个子表达式；算法可选择这两个子表达式各自最终得到的值并执行根运算。递归使用同样方式构造两棵子树，因此不会漏掉任何合法表达式。
  2. 合法性：算法每次只选择两个已有值，应用允许的二元运算并放回一个结果；原数字不会被重复使用，也不会被拼接或用作一元运算。跳过零除保证每个候选表达式有定义。
  3. 终止判定：每次递归都把数组长度减少一。长度为一时，该值正是完整表达式的结果；它与 24 的差小于误差阈值，当且仅当当前分支得到可接受的 24。
  4. 结论：若算法返回真，必有一条合法构造得到 24；若存在合法构造，覆盖性保证算法会访问它并返回真。

复杂度

设当前有 n 个值：一层选择 O(n²) 对，每对至多产生 6 个结果，递归到 n-1。可写为 T(n)=O(6^(n-1)·(n!)²) 的宽松上界；本题固定 n=4，实际搜索空间很小。递归深度为 O(n)，每层保存一个至多长为 n 的数组，空间为 O(n²)。

边界与数值

  • 不能用 value == 24 比较浮点数，采用 1e-6。
  • 除数绝对值小于 EPS 时不得相除。
  • 减法与除法不满足交换律，两个方向都要枚举。
  • 加法与乘法只需一个方向，避免重复分支。

替代方案

可以用“子集动态规划”：为每个卡片子集保存所有可达数值，再枚举子集划分并合并结果。它更适合牌数增多或需要复用子问题的扩展题，但实现、去重与浮点哈希更复杂。本题只有 4 张牌，回溯更直接。

面试追问

  • 如何返回具体表达式？让每个状态携带 value + expression。
  • 如何完全避免浮点误差？用约分后的有理数 分子/分母。
  • 如何减少重复？对排序后的状态做记忆化，并规范化近似值。
  • 若卡片数不固定？分析搜索爆炸，再考虑子集 DP。

常见错误

  • 只枚举 a-b 与 a/b，漏掉反向运算。
  • 一边遍历一边原地修改数组，回溯恢复不完整。
  • 使用整数除法，错过分数中间态。
  • 把括号样式当成若干固定模板，遗漏表达式树结构。
  • 用严格相等判断浮点结果，或没有防止除以零。

Java官方签名 · double 回溯
class Solution {
    private static final double EPS = 1e-6;

    public boolean judgePoint24(int[] cards) {
        java.util.List<Double> values = new java.util.ArrayList<>();
        for (int card : cards) values.add((double) card);
        return dfs(values);
    }

    private boolean dfs(java.util.List<Double> values) {
        int n = values.size();
        if (n == 1) return Math.abs(values.get(0) - 24.0) < EPS;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                java.util.List<Double> rest = new java.util.ArrayList<>();
                for (int k = 0; k < n; k++) {
                    if (k != i && k != j) rest.add(values.get(k));
                }

                double a = values.get(i), b = values.get(j);
                java.util.List<Double> candidates = new java.util.ArrayList<>();
                candidates.add(a + b);
                candidates.add(a * b);
                candidates.add(a - b);
                candidates.add(b - a);
                if (Math.abs(b) > EPS) candidates.add(a / b);
                if (Math.abs(a) > EPS) candidates.add(b / a);

                for (double value : candidates) {
                    rest.add(value);
                    if (dfs(rest)) return true;
                    rest.remove(rest.size() - 1);
                }
            }
        }
        return false;
    }
}

/**
 * @param {number[]} cards

var judgePoint24 = function(cards) {
    const EPS = 1e-6;

    const dfs = (values) => {
        if (values.length === 1) {
            return Math.abs(values[0] - 24) < EPS;
        }

        for (let i = 0; i < values.length; i++) {
            for (let j = i + 1; j < values.length; j++) {
                const rest = values.filter((_, k) => k !== i && k !== j);
                const a = values[i];
                const b = values[j];
                const candidates = [a + b, a * b, a - b, b - a];

                if (Math.abs(b) > EPS) candidates.push(a / b);
                if (Math.abs(a) > EPS) candidates.push(b / a);

                for (const value of candidates) {
                    rest.push(value);
                    if (dfs(rest)) return true;
                    rest.pop();
                }
            }
        }
        return false;
    };

    return dfs(cards.map(Number));
};

from typing import List


class Solution:
    def judgePoint24(self, cards: List[int]) -> bool:
        eps = 1e-6

        def dfs(values: List[float]) -> bool:
            if len(values) == 1:
                return abs(values[0] - 24.0) < eps

            n = len(values)
            for i in range(n):
                for j in range(i + 1, n):
                    rest = [values[k] for k in range(n) if k != i and k != j]
                    a, b = values[i], values[j]
                    candidates = [a + b, a * b, a - b, b - a]

                    if abs(b) > eps:
                        candidates.append(a / b)
                    if abs(a) > eps:
                        candidates.append(b / a)

                    for value in candidates:
                        rest.append(value)
                        if dfs(rest):
                            return True
                        rest.pop()
            return False

        return dfs([float(card) for card in cards])
C++官方签名 · double 回溯
class Solution {
private:
    static constexpr double EPS = 1e-6;

    bool dfs(const vector<double>& values) {
        int n = static_cast<int>(values.size());
        if (n == 1) return abs(values[0] - 24.0) < EPS;

        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                vector<double> rest;
                for (int k = 0; k < n; ++k) {
                    if (k != i && k != j) rest.push_back(values[k]);
                }

                double a = values[i], b = values[j];
                vector<double> candidates = {a + b, a * b, a - b, b - a};
                if (abs(b) > EPS) candidates.push_back(a / b);
                if (abs(a) > EPS) candidates.push_back(b / a);

                for (double value : candidates) {
                    rest.push_back(value);
                    if (dfs(rest)) return true;
                    rest.pop_back();
                }
            }
        }
        return false;
    }

public:
    bool judgePoint24(vector<int>& cards) {
        vector<double> values(cards.begin(), cards.end());
        return dfs(values);
    }
};
