255. 验证二叉搜索树的前序序列 Medium

前序遍历先看根，再看左子树、右子树。一旦新值大于栈顶，就说明正从某些祖先的左子树跨入右子树，那个祖先成为不可回退的下界。

?题意

给定由互不相同整数构成的数组 preorder，判断它是否可能是一棵二叉搜索树（BST）的前序遍历结果。BST 中每个节点的左子树值更小，右子树值更大。

公开样例 1

preorder = [5,2,1,3,6]
输出：true

公开样例 2

preorder = [5,2,6,1,3]
输出：false

单节点

preorder = [8]
输出：true

该题为付费题。本页采用常见公开题面约束：数组值互异；长度可达 10⁴ 量级。核心解法只依赖比较关系，对具体数值范围无要求。

核心洞察

栈保存从根到当前节点的下降路径。读到 x 时，若 x < lower 立即失败。否则不断弹出所有小于 x 的栈顶：最后弹出的值就是刚进入其右子树的祖先，因此更新 lower。

完整过程

  1. 初始化 lower = −∞、空栈。
  2. 若 x 小于 lower，返回 false。
  3. 当栈顶小于 x，弹栈并把 lower 更新为弹出值。
  4. 压入 x；全程无冲突则返回 true。

边界与复杂度

  • 单调递减：始终进入左子树，栈可达 n。
  • 单调递增：持续弹栈，下界不断提高。
  • 值互异；若允许重复，必须先定义重复值放左或右的规则。

时间：O(n)，每个值最多进出一次；空间：O(n)。

替代方案、追问与常见错误

替代：递归携带 (lower, upper) 区间，但需推进全局下标。
追问：能否 O(1) 空间？可原地把输入数组当栈。
错误：只检查栈顶、不维护下界；弹栈时忘记更新 lower；写成 x ≤ lower 而未明确重复规则。

import java.util.*;
class Solution { public boolean verifyPreorder(int[] preorder) {
    int lower = Integer.MIN_VALUE; Deque<Integer> stack = new ArrayDeque<>();
    for (int x : preorder) { if (x < lower) return false;
        while (!stack.isEmpty() && stack.peek() < x) lower = stack.pop();
        stack.push(x); }
    return true;
} }
var verifyPreorder = function(preorder) { let lower = -Infinity; const stack = [];
  for (const x of preorder) { if (x < lower) return false;
    while (stack.length && stack.at(-1) < x) lower = stack.pop(); stack.push(x); }
  return true;
};
