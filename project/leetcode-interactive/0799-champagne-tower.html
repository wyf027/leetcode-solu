01 · Problem

题意与规则

杯子共有 100 行，行与杯子都从 0 开始编号。目标是返回指定杯子的装满比例。

准确转述

把杯子排成金字塔：第 0 行有 1 只，第 1 行有 2 只，依次到第 99 行。每只杯子的容量都是 1 杯。从顶端 (0, 0) 倒入 poured 杯香槟；一只杯子装满后，后续溢出的液体会等量流向下一行左下和右下的杯子。最底行的溢出会落到地面。

给定 poured、query_row 和 query_glass，返回杯子 (query_row, query_glass) 的装满比例，结果范围为 [0, 1]。

关键物理量

计算过程中记录“总流入量”，它可能大于 1；只有展示杯中存量和最终返回值时，才截断到 1。

overflow = max(0, received - 1) / 2
示例 1
输入：poured = 1, query_row = 1, query_glass = 1 输出：0.00000
顶杯恰好装满，没有多余香槟流到第 1 行。
示例 2
输入：poured = 2, query_row = 1, query_glass = 1 输出：0.50000
顶杯溢出 1 杯，下一行的两只杯子各收到 0.5 杯。
示例 3
输入：poured = 100000009, query_row = 33, query_glass = 17 输出：1.00000
倒入量足够大，所查询的杯子已经装满。

约束

  • 0 <= poured <= 10^9
  • 0 <= query_glass <= query_row < 100

03 · Solution

准备好再揭开题解

建议先用上方演示回答：为什么只需要保留当前行？为什么不能把收到的所有液体继续平分？

动态规划：只追踪溢出

每一行只依赖上一行。用数组保存每只杯子的总流入量，扣掉本杯留下的 1，再把正的溢出量平分给下一行。

核心洞察

把 dp[j] 定义为当前行第 j 只杯子的总流入量。它不是杯内最终存量，所以允许大于 1。对于收到 x 的杯子，左右孩子各增加：

max(0, x - 1) / 2

处理完一整行后，用新数组替换当前数组。到达 query_row 时，答案是 min(1, dp[query_glass])。

完整过程

  1. 令当前行为数组 [poured]，表示顶杯收到的总量。
  2. 从第 0 行循环到第 query_row - 1 行。
  3. 为下一行创建一个长度多 1 的全零数组。
  4. 逐杯计算一侧溢出量 flow = max(0, current[j] - 1) / 2。
  5. 把 flow 同时加到 next[j] 与 next[j + 1]。
  6. 循环结束后返回目标位置与 1 的较小值。

正确性证明

引理 1：若某杯总流入量为 x，它向每个孩子流出的量恰为 max(0, x - 1) / 2。

杯子最多保留 1；当 x <= 1 时没有溢出，当 x > 1 时溢出 x - 1，规则规定左右平分，故引理成立。

引理 2：处理完第 r - 1 行后，数组中每个位置都等于第 r 行对应杯子的总流入量。

第 r 行的杯子只可能接收左上和右上两个父杯的溢出。转移恰好把每个父杯按引理 1 得到的两份流量累加到这两个位置，没有遗漏或重复。

定理

初始数组 [poured] 正确表示第 0 行总流入量。由引理 2 逐行归纳，到循环结束时，数组正确表示 query_row 行所有杯子的总流入量。

杯中实际存量不能超过 1，因此 min(1, dp[query_glass]) 正是目标杯的装满比例。算法正确。

时间复杂度O(query_row²)逐杯处理三角形中的状态。
空间复杂度O(query_row)只保留当前行与下一行。

边界情况

  • poured = 0：所有位置均为 0。
  • query_row = 0：直接返回 min(1, poured)。
  • 每行两侧杯子只会收到一个父杯的流量。
  • 倒入量很大时，中间状态可远大于 1，但只在返回时截断。
  • 使用浮点数保存二分产生的 0.5、0.25 等比例。

替代方案

可以建立 100 × 100 的二维 DP 表，转移更直观，也方便回看所有行；代价是使用 O(query_row²) 空间。递归加记忆化同样可行，但边界判断和两条父路径的累加更繁琐。

不建议逐“杯”模拟每一单位香槟：poured 可达 10^9，其复杂度会依赖倒入量而不是最多 100 行的结构。

四种语言完整代码

Java 
class Solution {
    public double champagneTower(int poured, int query_row, int query_glass) {
        double[] current = new double[] { poured };

        for (int row = 0; row < query_row; row++) {
            double[] next = new double[row + 2];

            for (int glass = 0; glass <= row; glass++) {
                double flow = Math.max(0.0, current[glass] - 1.0) / 2.0;
                next[glass] += flow;
                next[glass + 1] += flow;
            }

            current = next;
        }

        return Math.min(1.0, current[query_glass]);
    }
}

常见错误

  • 写成 x / 2，忘记杯子先保留 1。
  • 对负溢出继续转移，未使用 max(0, x - 1)。
  • 过早把中间状态截断为 1，导致后续行少收到液体。
  • 在同一个一维数组中原地更新，混入本行刚产生的数据。
  • 把题目给出的 0 下标当成 1 下标。
