Find Leaves of Binary Tree

Problem

题目描述

二叉树深度优先搜索树形 DP

给定一棵二叉树的根节点 root。收集当前树中的所有叶子节点，然后把这些叶子从树中移除；继续重复这一过程，直到整棵树为空。

请按每一轮被移除的先后顺序返回节点值。每一轮中的节点按从左到右的树遍历顺序排列。

函数参数

findLeaves(root: TreeNode) -> List<List<Integer>>

root 是二叉树根节点；返回值的第 i 个列表表示第 i + 1 轮收集到的叶子节点值。

示例 1

输入：root = [1,2,3,4,5]
输出：[[4,5,3],[2],[1]]

第一轮收集 4、5、3；移除后 2 成为叶子；最后只剩根节点 1。

示例 2

输入：root = [1]
输出：[[1]]

单节点树的根节点本身就是叶子，只需一轮。

约束

  • 树中节点数量在 [1, 100] 范围内。
  • -100 <= Node.val <= 100。

Solution

后序 DFS：用子树高度确定落叶轮次

O(n) 时间

核心洞察

最先被移除的叶子，其“自底向上高度”为 0。一个非叶节点会在两个子树都消失后的下一轮被移除，所以：

height(node) = max(height(left), height(right)) + 1

空节点高度定义为 -1，因此叶子高度正好是 0。高度 h 的节点进入答案下标 h。

完整过程

  1. 对当前节点先递归处理左子树和右子树，分别得到它们的高度。
  2. 当前节点高度取两者最大值再加 1。
  3. 如果答案中还没有这个高度对应的列表，就新增一个空列表。
  4. 把当前节点值追加到该列表。由于先左后右的后序遍历，同一轮节点自然保持从左到右的顺序。
  5. 根节点处理完时，所有节点已经按轮次分组，不必真的反复删除树节点。

正确性证明

引理：任意节点 v 会在第 height(v) + 1 轮被移除，其中空节点高度为 -1。

证明：对节点子树高度归纳。若 v 是叶子，两侧为空，高度为 0，它在第一轮被移除，结论成立。若 v 不是叶子，根据归纳假设，它的左右子树分别在各自最高轮次后完全消失。只有较高子树也消失后，v 才成为叶子并在下一轮移除。因此其移除轮次是 max(height(left), height(right)) + 2 = height(v) + 1。结论对所有节点成立。

定理：算法返回的第 i 个列表，恰好包含第 i + 1 轮被移除的全部节点。由引理，节点被放入下标等于其高度的列表，与真实移除轮次一一对应；每个节点仅访问并加入一次，因此既无遗漏也无重复。

复杂度

  • 时间复杂度：O(n)，每个节点仅被 DFS 访问一次。
  • 额外空间复杂度：O(h) 递归栈，h 为树高；若把返回结果也计入，则总空间为 O(n)。

边界情况

  • 单节点树：根节点高度为 0，答案为一轮。
  • 完全偏斜树：每轮只有一个节点，递归深度达到 n。
  • 左右子树高度不同：父节点必须等待较高的一侧全部移除。
  • 节点值重复或为负数：归组依据是结构而非节点值，不受影响。

替代方案

可以每轮扫描整棵树、找到叶子并真实断开它们，但偏斜树会扫描约 n + (n-1) + ... + 1 个节点，最坏时间复杂度为 O(n²)，而且会修改输入树。高度分组法用一次后序遍历得到相同结果，更适合作为主解。

面试追问

  • 如果不允许递归，如何用显式栈模拟后序遍历并保存节点高度？
  • 如果要求真的逐轮删除并返回每轮剩余的树，应如何维护父指针或节点度数？
  • 若输入是一棵多叉树，高度递推式如何变化？
  • 为什么同一高度等于同一移除轮次？这个结论是否依赖二叉树？

常见错误

  • 把空节点高度定义为 0，却仍直接用高度作为下标，导致所有轮次整体偏移 1。
  • 使用前序遍历就立刻计算父节点高度，此时子树高度尚未得到。
  • 真的删除节点并重复遍历，得到正确结果但退化为 O(n²)。
  • 把结果按节点值排序，破坏题目需要的树中从左到右顺序。
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    public List<List<Integer>> findLeaves(TreeNode root) {
        List<List<Integer>> answer = new ArrayList<>();
        collectHeight(root, answer);
        return answer;
    }

    private int collectHeight(TreeNode node,
                              List<List<Integer>> answer) {
        if (node == null) {
            return -1;
        }

        int leftHeight = collectHeight(node.left, answer);
        int rightHeight = collectHeight(node.right, answer);
        int height = Math.max(leftHeight, rightHeight) + 1;

        if (height == answer.size()) {
            answer.add(new ArrayList<>());
        }
        answer.get(height).add(node.val);
        return height;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number[][]}
 */
var findLeaves = function(root) {
    const answer = [];

    function collectHeight(node) {
        if (node === null) {
            return -1;
        }

        const leftHeight = collectHeight(node.left);
        const rightHeight = collectHeight(node.right);
        const height = Math.max(leftHeight, rightHeight) + 1;

        if (answer.length === height) {
            answer.push([]);
        }
        answer[height].push(node.val);
        return height;
    }

    collectHeight(root);
    return answer;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def findLeaves(self, root: Optional[TreeNode]) -> List[List[int]]:
        answer: List[List[int]] = []

        def collect_height(node: Optional[TreeNode]) -> int:
            if node is None:
                return -1

            left_height = collect_height(node.left)
            right_height = collect_height(node.right)
            height = max(left_height, right_height) + 1

            if height == len(answer):
                answer.append([])
            answer[height].append(node.val)
            return height

        collect_height(root)
        return answer
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class Solution {
public:
    vector<vector<int>> findLeaves(TreeNode* root) {
        vector<vector<int>> answer;
        collectHeight(root, answer);
        return answer;
    }

private:
    int collectHeight(TreeNode* node,
                      vector<vector<int>>& answer) {
        if (node == nullptr) {
            return -1;
        }

        int leftHeight = collectHeight(node->left, answer);
        int rightHeight = collectHeight(node->right, answer);
        int height = max(leftHeight, rightHeight) + 1;

        if (height == static_cast<int>(answer.size())) {
            answer.push_back({});
        }
        answer[height].push_back(node->val);
        return height;
    }
};
