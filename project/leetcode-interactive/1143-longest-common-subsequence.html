01 / Problem

题目说明

非付费题

给定两个字符串 text1 和 text2，返回它们的最长公共子序列的长度；若不存在公共子序列，返回 0。

子序列可以通过删除原字符串中的任意数量字符（也可以不删）得到，但剩余字符的相对顺序不能改变。公共子序列则必须同时是两个字符串的子序列。

参数text1: string，text2: string
返回值integer，即最长公共子序列长度

官方示例

EXAMPLE 01→
输入：text1 = "abcde", text2 = "ace"
输出：3
解释：最长公共子序列为 "ace"。
EXAMPLE 02→
输入：text1 = "abc", text2 = "abc"
输出：3
解释：整个字符串 "abc" 即为答案。
EXAMPLE 03→
输入：text1 = "abc", text2 = "def"
输出：0
解释：两个字符串没有公共子序列。

约束

  • 1 <= text1.length, text2.length <= 1000
  • text1 与 text2 只包含小写英文字母。

04 / Solution

准备好核对思路了吗？

完整解法、证明、复杂度与四种语言代码默认收起。建议先在上面的网格里走完几个状态。

Solution Notes

动态规划：只保留必要历史

核心洞察：考察两个前缀的末尾字符。若它们相同，这个字符可以接在更短前缀的最优公共子序列之后；若不同，最优解必然至少舍弃其中一个末尾字符。

状态与转移

令 dp[i][j] 表示 text1 前 i 个字符与 text2 前 j 个字符的最长公共子序列长度。空前缀与任意前缀的答案都是 0。

dp[0][j] = dp[i][0] = 0

如果 text1[i - 1] == text2[j - 1]：
    dp[i][j] = dp[i - 1][j - 1] + 1
否则：
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

完整过程

  1. 把较短字符串作为列，创建长度为 n + 1 的一维数组 dp。
  2. 逐行扫描较长字符串。进入每一格前，用 diagonal 保存二维表左上角的旧值。
  3. 字符相同就写入 diagonal + 1；不同就取“上方旧值”和“左侧新值”的较大者。
  4. 每次更新后，把原来的当前格保存为下一格需要的左上角值。扫描结束时，dp[n] 就是答案。

正确性证明

基础情况任一前缀为空时，不可能选出非空公共子序列，因此长度为 0。
末尾相同若两个末尾字符相同，存在一个最优解包含该字符；去掉它后，剩余部分就是两个更短前缀的最优子结构，故加 1。
末尾不同任意公共子序列不可能同时以两个不同末尾字符结束，至少有一个末尾未被采用；枚举舍弃哪一个并取较大值即可覆盖最优解。

按前缀长度归纳，上述转移对所有状态都给出最优值，因此最终状态就是两个完整字符串的最长公共子序列长度。一维滚动数组只覆盖已不再需要的行，不改变转移值。

边界与复杂度

  • 两个字符串完全不同，数组始终为 0。
  • 两个字符串完全相同，答案等于字符串长度。
  • 重复字符不能贪心地就近匹配；相同字符的不同选法会影响后续空间。
  • 长度上限为 1000，二次时间可接受；一维优化能显著减少内存。
时间 O(mn)空间 O(min(m,n))

替代方案

二维动态规划空间为 O(mn)，最直观，也便于回溯出具体子序列；上方交互网格展示的就是这种形态。
记忆化搜索同样是 O(mn) 状态，但有递归栈与函数调用开销。若只求长度，迭代 DP 通常更稳妥。

四语言完整代码

class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        if (text1.length() < text2.length()) {
            String temp = text1;
            text1 = text2;
            text2 = temp;
        }

        int[] dp = new int[text2.length() + 1];
        for (int i = 1; i <= text1.length(); i++) {
            int diagonal = 0;
            for (int j = 1; j <= text2.length(); j++) {
                int above = dp[j];
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[j] = diagonal + 1;
                } else {
                    dp[j] = Math.max(dp[j], dp[j - 1]);
                }
                diagonal = above;
            }
        }
        return dp[text2.length()];
    }
}

class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        if len(text1) < len(text2):
            text1, text2 = text2, text1

        dp = [0] * (len(text2) + 1)
        for char1 in text1:
            diagonal = 0
            for j, char2 in enumerate(text2, start=1):
                above = dp[j]
                if char1 == char2:
                    dp[j] = diagonal + 1
                else:
                    dp[j] = max(dp[j], dp[j - 1])
                diagonal = above

        return dp[-1]
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        if (text1.size() < text2.size()) {
            swap(text1, text2);
        }

        vector<int> dp(text2.size() + 1, 0);
        for (int i = 1; i <= static_cast<int>(text1.size()); ++i) {
            int diagonal = 0;
            for (int j = 1; j <= static_cast<int>(text2.size()); ++j) {
                int above = dp[j];
                if (text1[i - 1] == text2[j - 1]) {
                    dp[j] = diagonal + 1;
                } else {
                    dp[j] = max(dp[j], dp[j - 1]);
                }
                diagonal = above;
            }
        }
        return dp[text2.size()];
    }
};

面试追问

如果要返回具体的公共子序列呢？

保留完整二维表，从右下角回溯：字符相同就收集并走向左上；否则走向值更大的上方或左侧。最后反转收集结果。

为什么一维数组必须从左到右更新？

当前状态需要本行左侧的新值和上一行同列的旧值。左到右更新时两者恰好可用，而左上角旧值由额外变量保存。

能否进一步降低时间复杂度？

一般字符序列上，标准解是二次动态规划。特殊数据分布可将问题转化为匹配位置上的 LIS，但实现与最坏界更复杂。

LCS 与最长公共子串有什么区别？

子序列只要求相对顺序，字符不必连续；子串必须连续，因此其状态在字符不同时通常重置为 0。

常见错误

  • 把“子序列”误读成“子串”，只统计连续匹配。
  • 字符不同时只固定删除某一侧，遗漏另一种最优选择。
  • 一维优化时覆盖了左上角旧值，导致匹配分支引用本行数据。
  • 循环从 0 开始却仍访问 i - 1 或 j - 1，造成越界或错位。
