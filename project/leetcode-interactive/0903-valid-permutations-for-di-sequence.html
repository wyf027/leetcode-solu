DI 序列的有效排列

给一串只包含 D 与 I 的方向指令，数一数 0…n 的排列中，有多少个能让每个相邻关系都恰好满足指令。

困难字符串动态规划前缀和

题目

给定长度为 n 的字符串 s。其中 D 表示下降，I 表示上升。

将 [0,n] 中的全部整数各使用一次，组成长度为 n+1 的排列 perm。对每个合法下标 i：

  • 若 s[i] == 'D'，要求 perm[i] > perm[i+1]；
  • 若 s[i] == 'I'，要求 perm[i] < perm[i+1]。

返回有效排列数量，答案对 10⁹ + 7 取模。

函数签名

numPermsDISequence(s: string) -> integer

官方示例与约束

输入：s = "DID" 输出：5 解释：有效排列为 (1,0,3,2) (2,0,3,1) (2,1,3,0) (3,0,2,1) (3,1,2,0)
输入：s = "D" 输出：1
  • n == s.length
  • 1 ≤ n ≤ 200
  • s[i] 只可能是 'I' 或 'D'

Complete Solution

秩动态规划 + 前缀 / 后缀累加

核心洞察

具体用了哪些数字并不重要；比较关系只关心相对大小。处理完前 i 个指令（已有 i+1 个元素）时，用 dp[j] 表示最后一个元素在这些元素中从小到大排名 j 的方案数。

若 s[i] = 'I'：next[j] = Σ dp[k]，其中 k < j 若 s[i] = 'D'：next[j] = Σ dp[k]，其中 k ≥ j

为什么下标关系看似没有偏移？插入一个新末尾元素后，若它的秩为 j，旧末尾小于它时旧秩落在 [0,j-1]；旧末尾大于它时，删去新元素后旧秩落在 [j,i]。

完整过程

  1. 初始只有一个元素：dp = [1]。
  2. 逐字符处理。遇到 I，从左向右维护前缀和；遇到 D，从右向左维护后缀和。
  3. 每轮产生长度多 1 的新数组，并在累加时对 1,000,000,007 取模。
  4. 所有指令处理完后，把最终数组全部求和，即为不限制最后秩的总方案数。

正确性证明

状态完备：任一长度为 i+1 的相对排列，都按末尾元素的唯一秩归入一个 dp[j]，各状态互不重叠。

转移正确：追加秩为 j 的新元素时，I 要求旧末尾更小，恰好对应所有旧秩 k<j；D 要求旧末尾更大，删除新元素并重新压缩秩后，恰好对应 k≥j。转移既不遗漏也不重复。

归纳结论：初始状态准确。若第 i 轮之前各状态准确，由上述双射，转移后各状态仍准确。因此最终所有末尾秩的方案数之和就是全部有效排列数。

边界与复杂度

  • 全 I 或全 D 都只有 1 个排列。
  • 最小长度 n=1 正常由一次转移得到答案。
  • 时间复杂度 O(n²)，空间复杂度 O(n)；n≤200 时足够。

四语言完整代码

class Solution {
    public int numPermsDISequence(String s) {
        final int MOD = 1_000_000_007;
        long[] dp = {1};
        for (int i = 0; i < s.length(); i++) {
            long[] next = new long[i + 2];
            if (s.charAt(i) == 'I') {
                long sum = 0;
                for (int j = 0; j <= i + 1; j++) {
                    next[j] = sum;
                    if (j < dp.length) sum = (sum + dp[j]) % MOD;
                }
            } else {
                long sum = 0;
                for (int j = i + 1; j >= 0; j--) {
                    if (j < dp.length) sum = (sum + dp[j]) % MOD;
                    next[j] = sum;
                }
            }
            dp = next;
        }
        long ans = 0;
        for (long value : dp) ans = (ans + value) % MOD;
        return (int) ans;
    }
}

class Solution:
    def numPermsDISequence(self, s: str) -> int:
        MOD = 1_000_000_007
        dp = [1]
        for i, char in enumerate(s):
            nxt = [0] * (i + 2)
            total = 0
            if char == "I":
                for j in range(i + 2):
                    nxt[j] = total
                    if j < len(dp):
                        total = (total + dp[j]) % MOD
            else:
                for j in range(i + 1, -1, -1):
                    if j < len(dp):
                        total = (total + dp[j]) % MOD
                    nxt[j] = total
            dp = nxt
        return sum(dp) % MOD

替代方案

可用二维 dp[i][j] 保存每一层，转移含义更直观，但空间为 O(n²)。也可把每个区间和逐项相加，写法更朴素，却会退化到 O(n³)。当前一维滚动数组兼顾清晰与效率。

  • 若要构造一个有效排列，而非计数，应额外保存什么信息？

常见错误

  • I 与 D 的求和边界写反，尤其是 D 的 k≥j。
  • 忘记 next 比 dp 多一个状态。
  • 只返回某个末尾秩，而没有汇总最终整层。
  • 累加过程中没有及时取模，导致固定宽度整数溢出。
