平分
正方形

两张方纸可以大小不同、位置不同。请拉出一条直线，让它同时平分两张纸，并只返回覆盖四个交点的最短线段。

几何 数学 返回 double[] 时间 O(1)
center → center · pull taut
Brief / 题意

先把返回值说清楚

每个正方形以左下角与边长表示，边平行于坐标轴。直线与两个正方形最多留下四个边界交点，答案是其中距离最远的两个。

任务

找到同时把两个正方形面积各分成一半的直线。若解不唯一，选择斜率最大的直线；竖直线的斜率视为无穷大。 返回 {X1, Y1, X2, Y2}，优先保证 X1 < X2；若两点横坐标相同，则保证 Y1 <= Y2。

官方示例

square1 = [-1, -1, 2] square2 = [0, -1, 2]

输出：[-1, 0, 2, 0]

输入约束

  • square1.length == 3
  • square2.length == 3
  • square1[2] > 0 且 square2[2] > 0

Core insight / 核心洞察

过中心的直线，一定平分正方形

正方形关于中心点中心对称。任意经过中心的直线都会把每个点与其中心对称点分到直线两侧，因此两侧面积相等。 要同时平分两个正方形，只需让直线经过两个中心。

若中心不同，方向被唯一确定；若中心重合，所有过中心的直线都可行，按题意选择斜率最大的竖直线。

d = (dx, dy) = C₂ − C₁
t = (side / 2) ÷ max(|dx|, |dy|)
P± = C ± t · d
Process / 完整过程
  1. 01 · CENTER用 x + side / 2、y + side / 2 求两个中心。
  2. 02 · DIRECTION以 C2 - C1 作为公用方向向量，不必计算斜率。
  3. 03 · CLIP对每个正方形计算缩放量 t，得到正负方向的两个边界交点。
  4. 04 · EXTREME把四个交点按横坐标、再按纵坐标排序，取首尾作为答案。

为什么是 max(|dx|, |dy|)？

从中心到正方形边界，横纵方向最多都只能移动半个边长。把方向向量乘以 t 后，先达到限制的轴满足 t · max(|dx|, |dy|) = side / 2。 这正是正方形的 L∞ 边界。

边界情况

  • 两个中心重合：返回覆盖两个正方形的竖直线段。
  • dx = 0：公式仍有效，得到竖直交点，不会除以零。
  • dy = 0：公式自然得到水平交点。
  • 正方形相交、包含或仅接触：仍统一收集四点并取极值。

复杂度

项目 复杂度 原因
时间 O(1) 固定计算两个中心与四个交点
空间 O(1) 只保存常数个坐标

替代方案

  • 按斜率绝对值是否大于 1 分水平边 / 竖直边：直观，但分支和符号处理较多。
  • 把直线分别与四条边求交并过滤：通用，但会重复处理顶点与浮点误差。
  • 参数直线裁剪：可扩展到矩形，本题则比 L∞ 缩放更重。

面试追问

  • 若输入改成轴对齐矩形，过中心的直线仍会平分吗？为什么？
  • 若正方形允许旋转，如何用局部坐标系计算交点？
  • 为什么对四点做字典序排序就能得到最远端点？
  • 如何证明同心时竖线符合“斜率最大”的约束？

常见错误

  • 直接计算 dy / dx，导致竖线除零和大量斜率分支。
  • 只返回两个中心，而不是直线穿过正方形后的最外侧端点。
  • 中心使用整数除法，奇数边长时丢失 0.5。
  • 同心时随意选水平线，违反题目“斜率最大”的要求。
  • 端点未按横坐标、再按纵坐标排序。

class Solution {
    public double[] cutSquares(int[] square1, int[] square2) {
        double x1 = square1[0] + square1[2] / 2.0;
        double y1 = square1[1] + square1[2] / 2.0;
        double x2 = square2[0] + square2[2] / 2.0;
        double y2 = square2[1] + square2[2] / 2.0;

        if (x1 == x2 && y1 == y2) {
            double bottom = Math.min(square1[1], square2[1]);
            double top = Math.max(
                square1[1] + square1[2],
                square2[1] + square2[2]
            );
            return new double[] {x1, bottom, x1, top};
        }

        double dx = x2 - x1;
        double dy = y2 - y1;
        double[][] points = new double[4][2];
        addIntersections(points, 0, square1, x1, y1, dx, dy);
        addIntersections(points, 2, square2, x2, y2, dx, dy);

        java.util.Arrays.sort(points, (a, b) -> {
            int byX = Double.compare(a[0], b[0]);
            return byX != 0 ? byX : Double.compare(a[1], b[1]);
        });
        return new double[] {
            points[0][0], points[0][1],
            points[3][0], points[3][1]
        };
    }

    private void addIntersections(
        double[][] points,
        int index,
        int[] square,
        double cx,
        double cy,
        double dx,
        double dy
    ) {
        double scale = square[2] / 2.0 / Math.max(Math.abs(dx), Math.abs(dy));
        points[index] = new double[] {cx - scale * dx, cy - scale * dy};
        points[index + 1] = new double[] {cx + scale * dx, cy + scale * dy};
    }
}

var cutSquares = function (square1, square2) {
  const center = (square) => [
    square[0] + square[2] / 2,
    square[1] + square[2] / 2,
  ];

  const [x1, y1] = center(square1);
  const [x2, y2] = center(square2);

  if (x1 === x2 && y1 === y2) {
    const bottom = Math.min(square1[1], square2[1]);
    const top = Math.max(
      square1[1] + square1[2],
      square2[1] + square2[2],
    );
    return [x1, bottom, x1, top];
  }

  const dx = x2 - x1;
  const dy = y2 - y1;
  const intersections = (square, cx, cy) => {
    const scale = square[2] / 2 / Math.max(Math.abs(dx), Math.abs(dy));
    return [
      [cx - scale * dx, cy - scale * dy],
      [cx + scale * dx, cy + scale * dy],
    ];
  };

  const points = [
    ...intersections(square1, x1, y1),
    ...intersections(square2, x2, y2),
  ];
  points.sort((a, b) => a[0] - b[0] || a[1] - b[1]);
  return [...points[0], ...points[points.length - 1]];
};
from typing import List


class Solution:
    def cutSquares(
        self, square1: List[int], square2: List[int]
    ) -> List[float]:
        x1 = square1[0] + square1[2] / 2
        y1 = square1[1] + square1[2] / 2
        x2 = square2[0] + square2[2] / 2
        y2 = square2[1] + square2[2] / 2

        if x1 == x2 and y1 == y2:
            bottom = min(square1[1], square2[1])
            top = max(
                square1[1] + square1[2],
                square2[1] + square2[2],
            )
            return [x1, bottom, x1, top]

        dx, dy = x2 - x1, y2 - y1

        def intersections(square, cx, cy):
            scale = square[2] / 2 / max(abs(dx), abs(dy))
            return [
                [cx - scale * dx, cy - scale * dy],
                [cx + scale * dx, cy + scale * dy],
            ]

        points = (
            intersections(square1, x1, y1)
            + intersections(square2, x2, y2)
        )
        points.sort()
        return points[0] + points[-1]
class Solution {
public:
    vector<double> cutSquares(vector<int>& square1, vector<int>& square2) {
        double x1 = square1[0] + square1[2] / 2.0;
        double y1 = square1[1] + square1[2] / 2.0;
        double x2 = square2[0] + square2[2] / 2.0;
        double y2 = square2[1] + square2[2] / 2.0;

        if (x1 == x2 && y1 == y2) {
            double bottom = min(square1[1], square2[1]);
            double top = max(
                square1[1] + square1[2],
                square2[1] + square2[2]
            );
            return {x1, bottom, x1, top};
        }

        double dx = x2 - x1;
        double dy = y2 - y1;
        vector<array<double, 2>> points;

        auto addIntersections = [&](const vector<int>& square,
                                      double cx, double cy) {
            double scale = square[2] / 2.0
                / max(abs(dx), abs(dy));
            points.push_back({cx - scale * dx, cy - scale * dy});
            points.push_back({cx + scale * dx, cy + scale * dy});
        };

        addIntersections(square1, x1, y1);
        addIntersections(square2, x2, y2);
        sort(points.begin(), points.end());
        return {
            points.front()[0], points.front()[1],
            points.back()[0], points.back()[1]
        };
    }
};
