01 · Problem

先看清账，而不是交易顺序

给定若干笔交易 transactions[i] = [fromᵢ, toᵢ, amountᵢ]，表示编号 fromᵢ 的人向编号 toᵢ 的人支付了 amountᵢ。请返回使所有人的债务结清所需的最少转账次数。新的结算交易可以与原交易不同，只需保持每个人的最终净收支一致。

官方示例 1

输入：transactions = [[0,1,10],[2,0,5]]

输出：2

净额为：0 号应付 5，1 号应收 10，2 号应付 5。需要两笔转账才能全部归零。

官方示例 2

输入：transactions = [[0,1,10],[1,0,1],[1,2,5],[2,0,5]]

输出：1

抵消历史流水后，只剩 0 号应付 4、1 号应收 4，因此一笔转账足够。

约束

  • 1 <= transactions.length <= 8
  • transactions[i].length == 3
  • 0 <= fromᵢ, toᵢ < 12
  • fromᵢ != toᵢ
  • 1 <= amountᵢ <= 100

Complete walkthrough

净额压缩 + 回溯配对

以下实现先把所有流水压缩为非零净额，再从第一个未结清的人出发，尝试与符号相反的人结算。剪枝让相同状态尽早收束。

核心洞察

  1. 对每笔 [from, to, amount]，令 balance[from] -= amount、balance[to] += amount。
  2. 净额为 0 的人已经平账，可直接删除。剩余数组之和必为 0。
  3. 固定第一个非零净额，只需尝试与它符号相反的净额配对；一次结算后继续处理下一个位置。
  4. 枚举所有可行配对，取使用转账数的最小值。

完整过程

  1. 构建哈希表，求每个人的净额。
  2. 过滤 0，得到 debt。
  3. 递归跳过已经归零的位置 start。
  4. 遍历后方与 debt[start] 异号的项，把前者的债务合并到后者。
  5. 递归求剩余部分，回溯恢复现场。
  6. 若本次配对恰好让对方也归零，这是当前层最理想的局部匹配，可停止尝试其他等价分支。

正确性证明

引理 1：净额压缩保持问题等价

每个人最终只关心总流入减总流出。将全部历史交易替换为同一组个人净额，不改变任何人的应收或应付，因此原问题与净额数组的结算问题等价。

引理 2：递归枚举了所有必要的首笔结算对象

设 start 是第一个非零项。任何完整方案中，它最终必须与至少一个异号净额发生资金转移；同号之间的转移不能直接减少两者绝对债务之和。循环逐一尝试所有异号对象，因此不会遗漏最优方案中可作为首个结算对象的人。

引理 3：合并操作正确表示一次转账

把 debt[start] 加到异号的 debt[i] 上，相当于在两人之间转移恰当金额，使 start 归零，未结清差额由 i 继续承担。总净额仍为 0，且计数恰好增加 1。

定理

递归对每个状态枚举所有可能的必要首步，并在子问题中取最小值；终止状态是全部净额为 0。由引理 1–3 及对子问题规模的归纳，算法返回恰好为最少转账次数。

复杂度

设过滤后非零净额人数为 m，原交易数为 T。

  • 建立净额：时间 O(T)，空间 O(m)。
  • 回溯最坏时间：O(m!)。
  • 递归栈：O(m)；不计哈希表与净额数组外，仅原地修改。

边界情况

  • 多笔交易完全抵消：非零列表为空，答案为 0。
  • 只有一对相反净额：一次转账完成。
  • 同一人参与多笔交易：必须先合并净额，不能按原流水贪心。
  • 不同配对产生相同状态：可跳过重复净额，进一步减少搜索。
  • 金额累计建议使用 64 位整数，避免扩展约束时溢出。

替代方案

子集状态压缩：预计算每个子集的净额和，再枚举和为 0 的子集划分。若最多能拆出 g 个互不相交的零和组，则答案为 m - g。直接枚举子集划分通常为 O(3^m) 时间、O(2^m) 空间。

贪心匹配：每次配最大债权人与最大债务人实现简单，但局部选择可能破坏更好的零和分组，不能保证最少次数。

常见错误

  • 把答案误解为最小转账金额，而不是最少转账次数。
  • 直接在原交易图上删除边，没有先压缩为个人净额。
  • 只配绝对值最大的两项，错误地假设贪心最优。
  • 回溯后没有恢复 debt[i]。
  • 没有限制异号配对，引入无意义分支。

面试追问

  • 为什么能忽略具体交易关系？ 因为题目允许重新安排结算对象，每个人的净额是唯一需要保持的不变量。
  • 为什么恰好抵消后可以 break？ 当前固定项和候选项同时归零，已经最大化本次转账消除的非零项数；其他候选只会留下更多未结清项。
  • 如何进一步去重？ 当前层用集合记录尝试过的候选净额，相同值只尝试一次。
  • 若人数扩大怎么办？ 可比较回溯、记忆化状态和子集 DP；实际选择取决于非零人数而非原交易数。

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int minTransfers(int[][] transactions) {
        Map<Integer, Long> balance = new HashMap<>();

        for (int[] transaction : transactions) {
            int from = transaction[0];
            int to = transaction[1];
            long amount = transaction[2];
            balance.merge(from, -amount, Long::sum);
            balance.merge(to, amount, Long::sum);
        }

        List<Long> debt = new ArrayList<>();
        for (long value : balance.values()) {
            if (value != 0) {
                debt.add(value);
            }
        }

        return settle(0, debt);
    }

    private int settle(int start, List<Long> debt) {
        while (start < debt.size() && debt.get(start) == 0) {
            start++;
        }
        if (start == debt.size()) {
            return 0;
        }

        int best = Integer.MAX_VALUE;
        long first = debt.get(start);

        for (int i = start + 1; i < debt.size(); i++) {
            long candidate = debt.get(i);
            if (first * candidate >= 0) {
                continue;
            }

            debt.set(i, candidate + first);
            best = Math.min(best, 1 + settle(start + 1, debt));
            debt.set(i, candidate);

            if (candidate + first == 0) {
                break;
            }
        }

        return best;
    }
}

var minTransfers = function(transactions) {
    const balance = new Map();

    for (const [from, to, amount] of transactions) {
        balance.set(from, (balance.get(from) || 0) - amount);
        balance.set(to, (balance.get(to) || 0) + amount);
    }

    const debt = [...balance.values()].filter((value) => value !== 0);

    function settle(start) {
        while (start < debt.length && debt[start] === 0) {
            start++;
        }
        if (start === debt.length) {
            return 0;
        }

        let best = Infinity;
        const first = debt[start];

        for (let i = start + 1; i < debt.length; i++) {
            const candidate = debt[i];
            if (first * candidate >= 0) {
                continue;
            }

            debt[i] = candidate + first;
            best = Math.min(best, 1 + settle(start + 1));
            debt[i] = candidate;

            if (candidate + first === 0) {
                break;
            }
        }

        return best;
    }

    return settle(0);
};

class Solution:
    def minTransfers(self, transactions: List[List[int]]) -> int:
        balance = defaultdict(int)

        for sender, receiver, amount in transactions:
            balance[sender] -= amount
            balance[receiver] += amount

        debt = [value for value in balance.values() if value != 0]

        def settle(start: int) -> int:
            while start < len(debt) and debt[start] == 0:
                start += 1
            if start == len(debt):
                return 0

            best = float("inf")
            first = debt[start]

            for i in range(start + 1, len(debt)):

                    continue

                debt[i] = candidate + first
                best = min(best, 1 + settle(start + 1))
                debt[i] = candidate

                if candidate + first == 0:

        return settle(0)
