Acquisition brief

题意

给定一个可能含有重复整数的数组 nums，返回它的所有不同子集（幂集）。结果中不能出现重复子集，返回顺序不限。

  • 1 ≤ nums.length ≤ 10
  • −10 ≤ nums[i] ≤ 10

Restricted curator notes

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误和四语言代码默认封存。

Core insight

排序，让重复值变成相邻同层候选

每次进入 dfs(start) 都先复制当前路径加入答案。随后从 start 枚举候选；若 i > start 且 nums[i] == nums[i-1]，说明相同值已经在这一层开过分支，直接跳过。

Why same level

同层去重，不是整条路径禁用

路径中的第二个相同值仍然合法，例如 [2,2]。被跳过的是同一父节点下，第二次用相同值作为“下一步”的重复分支。

Full process

完整过程

  1. 1. 升序排列数组，使相同数字相邻。
  2. 2. 进入递归节点时，把 path 的副本加入答案。
  3. 3. 从 start 开始枚举；同层重复候选跳过。
  4. 4. 选择 nums[i]，递归到 i + 1。
  5. 5. 返回后弹出末尾元素，恢复路径并尝试下一候选。

Complexity

时间

O(n · 2ⁿ)

辅助空间

O(n)

排序为 O(n log n)；输出本身最坏需要 O(n · 2ⁿ) 空间，不计入辅助空间。

Boundaries

  • 单元素仍包含空集与自身。
  • 全相同数组只产生长度 0…n 的 n+1 个子集。
  • 负数、0 与正数的处理完全一致。

Alternative

计数展开 / 结果集去重

可以按每个值的出现次数选择 0…count 个，也可以生成全部子集后放入集合。前者很优雅但代码不如标准回溯直观；后者浪费时间和空间，面试不推荐。

Interview follow-ups

  • 为什么判断必须写成 i > start？
  • 如果不能修改输入数组，如何处理？
  • 怎样按字典序输出，或只统计数量？

Common mistakes

  • 忘记排序，导致相同值不相邻。
  • 写成 i > 0，错误删除路径内合法重复值。
  • 把同一个可变 path 引用直接加入答案。
  • 递归返回后忘记 pop，污染后续分支。
class Solution {
    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> answer = new ArrayList<>();
        backtrack(nums, 0, new ArrayList<>(), answer);
        return answer;
    }

    private void backtrack(
        int[] nums,
        int start,
        List<Integer> path,
        List<List<Integer>> answer
    ) {
        answer.add(new ArrayList<>(path));

        for (int i = start; i < nums.length; i++) {
            if (i > start && nums[i] == nums[i - 1]) {
                continue;
            }
            path.add(nums[i]);
            backtrack(nums, i + 1, path, answer);
            path.remove(path.size() - 1);
        }
    }
}

 * @param {number[]} nums
 * @return {number[][]}

var subsetsWithDup = function (nums) {
    nums.sort((a, b) => a - b);
    const answer = [];
    const path = [];

    function backtrack(start) {
        answer.push([...path]);

        for (let i = start; i < nums.length; i++) {
            if (i > start && nums[i] === nums[i - 1]) {
                continue;
            }
            path.push(nums[i]);
            backtrack(i + 1);
            path.pop();
        }
    }

    backtrack(0);
    return answer;
};
class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        answer = []
        path = []

        def backtrack(start: int) -> None:
            answer.append(path.copy())

            for i in range(start, len(nums)):
                if i > start and nums[i] == nums[i - 1]:
                    continue
                path.append(nums[i])
                backtrack(i + 1)
                path.pop()

        backtrack(0)
        return answer
class Solution {
public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> answer;
        vector<int> path;
        backtrack(nums, 0, path, answer);
        return answer;
    }

private:
    void backtrack(
        const vector<int>& nums,
        int start,
        vector<int>& path,
        vector<vector<int>>& answer
    ) {
        answer.push_back(path);

        for (int i = start; i < nums.size(); i++) {
            if (i > start && nums[i] == nums[i - 1]) {
                continue;
            }
            path.push_back(nums[i]);
            backtrack(nums, i + 1, path, answer);
            path.pop_back();
        }
    }
};
