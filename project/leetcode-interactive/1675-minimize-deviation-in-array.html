1675.
数组的最小偏移量

每个数字都有自己的变化边界。你的任务不是穷举所有数组，而是在这些边界之间找到最窄的那段区间。

↓先读题，再进入交互实验

Function

minimumDeviation(nums)

Input scale

2 ≤ n ≤ 5 × 10⁴

Objective

最小化 max(nums) − min(nums)

01 / PROBLEM

规则很少，状态很多

给定由 n 个正整数组成的数组 nums。可以任选元素、执行任意次合法操作；返回最终数组可能达到的最小偏移量。

数组的偏移量定义为任意两个元素之间的最大差，也就是当前最大值与最小值之差。

偶数 → 除以 2

例如 [1,2,3,4] 中的 4 可以变成 2。

奇数 → 乘以 2

例如 [1,2,3,4] 中的 1 可以变成 2。

目标 → 缩短区间

允许不操作；寻找所有可达状态中最小的 max − min。

官方示例

EXAMPLE 01
输入：nums = [1,2,3,4]
输出：1

可变为 [1,2,3,2]，再变为 [2,2,3,2]，此时偏移量为 3 − 2 = 1。

EXAMPLE 02
输入：nums = [4,1,5,20,3]
输出：3

两次操作后可得到 [4,2,5,5,3]，此时偏移量为 5 − 2 = 3。

EXAMPLE 03
输入：nums = [2,10,8]
输出：3

约束

  • n == nums.length
  • 2 ≤ n ≤ 5 × 10⁴
  • 1 ≤ nums[i] ≤ 10⁹

04 / SOLUTION

准备好，再看答案

题解与代码默认收起，避免在读题和动手尝试之前直接看到关键策略。

最大堆：只收缩当前上界

先把每个数放到一个统一的“可向下变化”起点，再持续处理当前最大值。这样原本双向、分叉的操作空间会变成一条单调收缩路线。

核心洞察

奇数只能先乘 2，之后才可能被除 2；偶数则可以直接不断除 2。因此先把所有奇数乘 2，所有元素就都从各自可达的最大候选值出发，后续只需要考虑“把偶数减半”。

完整过程

  1. 遍历数组：奇数乘 2，偶数保持不变；把结果加入最大堆，同时记录全局最小值 minValue。
  2. 查看堆顶最大值 maxValue，用 maxValue − minValue 更新答案。
  3. 若最大值为奇数，它已不能再通过合法操作减小，停止。
  4. 否则将最大值除以 2，更新最小值并重新放回最大堆，继续循环。

正确性

覆盖性：规范化后，每个数的所有相关候选值恰好由连续减半得到。因为所有后续变化只会降低某个偶数，所以若存在更优区间，就必须降低当前最大值；降低其他元素既不能减小上界，还可能降低下界。算法逐次枚举这个唯一有希望的动作，并在每次动作前记录区间。当堆顶为奇数时，当前上界无法再降，任何继续操作都不能得到更小区间。因此记录到的最小值就是全局最优。

复杂度

设每个数最多可连续减半 k 次。总操作数为 O(nk)，每次堆操作为 O(log n)，故时间复杂度为 O(nk log n)。在本题数值范围内 k ≤ 31，常写作 O(n log M log n)；空间复杂度为 O(n)。

边界情况

全相等数组会得到 0；全奇数数组会先整体翻倍；包含 1 时，1 会规范化为 2；最大输入 10⁹ 翻倍为 2×10⁹，仍在 32 位有符号整数范围内，但跨语言移植时仍应留意整数类型。

替代方案

可使用有序多重集合代替最大堆，同时维护首尾元素。它更容易直接取得最小值和最大值，但常数更大，且必须正确处理重复值；核心贪心顺序不变。

四语言完整代码

import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public int minimumDeviation(int[] nums) {
        PriorityQueue<Integer> maxHeap =
            new PriorityQueue<>(Collections.reverseOrder());
        int minValue = Integer.MAX_VALUE;

        for (int value : nums) {
            int normalized = (value % 2 == 1) ? value * 2 : value;
            maxHeap.offer(normalized);
            minValue = Math.min(minValue, normalized);
        }

        int answer = Integer.MAX_VALUE;
        while (!maxHeap.isEmpty()) {
            int maxValue = maxHeap.poll();
            answer = Math.min(answer, maxValue - minValue);

            if (maxValue % 2 == 1) {
                break;
            }

            int reduced = maxValue / 2;
            minValue = Math.min(minValue, reduced);
            maxHeap.offer(reduced);
        }
        return answer;
    }
}

var minimumDeviation = function(nums) {
    const heap = [];

    const push = (value) => {
        heap.push(value);
        let index = heap.length - 1;
        while (index > 0) {
            const parent = Math.floor((index - 1) / 2);
            if (heap[parent] >= heap[index]) break;
            [heap[parent], heap[index]] = [heap[index], heap[parent]];
            index = parent;
        }
    };

    const pop = () => {
        const top = heap[0];
        const last = heap.pop();
        if (heap.length > 0) {
            heap[0] = last;
            let index = 0;
            while (true) {
                let largest = index;
                const left = index * 2 + 1;
                const right = left + 1;
                if (left < heap.length && heap[left] > heap[largest]) largest = left;
                if (right < heap.length && heap[right] > heap[largest]) largest = right;
                if (largest === index) break;
                [heap[index], heap[largest]] = [heap[largest], heap[index]];
                index = largest;
            }
        }
        return top;
    };

    let minValue = Infinity;
    for (const value of nums) {
        const normalized = value % 2 === 1 ? value * 2 : value;
        push(normalized);
        minValue = Math.min(minValue, normalized);
    }

    let answer = Infinity;
    while (heap.length > 0) {
        const maxValue = pop();
        answer = Math.min(answer, maxValue - minValue);
        if (maxValue % 2 === 1) break;

        const reduced = maxValue / 2;
        minValue = Math.min(minValue, reduced);
        push(reduced);
    }
    return answer;
};
from typing import List
import heapq


class Solution:
    def minimumDeviation(self, nums: List[int]) -> int:
        max_heap = []
        min_value = float("inf")

        for value in nums:
            normalized = value * 2 if value % 2 == 1 else value
            heapq.heappush(max_heap, -normalized)
            min_value = min(min_value, normalized)

        answer = float("inf")
        while max_heap:
            max_value = -heapq.heappop(max_heap)
            answer = min(answer, max_value - min_value)

            if max_value % 2 == 1:
                break

            reduced = max_value // 2
            min_value = min(min_value, reduced)
            heapq.heappush(max_heap, -reduced)

        return answer

            maxHeap.pop();

                break;
            }

            int reduced = maxValue / 2;
            minValue = min(minValue, reduced);
            maxHeap.push(reduced);
        }
        return answer;
    }

常见错误

  • 直接同时尝试“奇数翻倍”和“偶数减半”，导致状态空间爆炸。
  • 只维护最大堆却忘记在每次减半后更新全局最小值。
  • 先弹出并减半，再计算偏移量，从而漏掉规范化后的初始候选区间。
  • 堆顶变成奇数后仍继续处理其他数；此时不可降低的最大值已经封住上界。
  • 使用普通集合替代多重集合，错误吞掉重复数字。

面试追问

为什么要把奇数先乘 2，而不是保持原值？

这会把每个元素统一放到其可达候选链的高端。之后所有操作都只向下，搜索方向单调，当前最大值也成为唯一需要处理的元素。

为什么每轮只动最大值是安全的？

当前偏移量由最大值和最小值决定。若不降低最大值，操作其他元素不可能降低上界；若降低了最小值，反而可能让区间更宽。

能否改用最小堆，从低端向上扩张？

可以从每个数的最低可达值开始，逐步把最小值翻倍，但需要准确记录每个数的最高边界。最大堆方案更直接，因为规范化后“偶数可减半”的停止条件天然可见。

如果操作规则改成任意整数都可以乘 2 呢？

候选链可能无限向上，原题的有限单调边界被破坏；必须引入新的上界或证明最优解不会超过某个范围，原贪心不能直接照搬。
