奇偶树Even Odd Tree

一层一层读取二叉树：层号决定数值的奇偶性，也决定从左到右应该上升还是下降。

MEDIUM非付费题TreeBFS

Problem

题目要求

二叉树根节点位于第 0 层，之后逐层编号。给定 root，判断整棵树是否同时满足下面两组规则；满足返回 true，否则返回 false。

0,2,…
偶数下标层每个值必须是奇数，并且从左到右严格递增。
1,3,…
奇数下标层每个值必须是偶数，并且从左到右严格递减。

输入：root = [1,10,4,3,null,7,9,12,8,6,null,null,2]输出：true解释：各层为 [1]、[10,4]、[3,7,9]、[12,8,6,2]，均符合对应规则。

示例 2

输入：root = [5,4,2,3,3,7]输出：false解释：第 2 层 [3,3,7] 不是严格递增。

示例 5

Spoiler gate

想清楚规则之后，再看题解

先尝试回答：遍历到每一层时，只保存哪个信息，就足以判断这一层的顺序是否合法？

Solution

层序遍历 + 单层前值

用队列按层访问节点。每层只需记录前一个节点值，就能同时完成奇偶性与严格单调性的检查。

核心洞察

题目的约束以“层”为单位，因此广度优先搜索天然对齐问题结构。进入新的一层时重置 prev；扫描当前层时，每个值只和本层前一个值比较。

完整过程

  1. 把根节点放入队列。
    当前层号 level = 0。
  2. 冻结当前层大小。
    本轮只弹出队列此刻已有的 size 个节点，子节点进入下一层。
  3. 检查奇偶性。
    偶数层要求节点值为奇数；奇数层要求节点值为偶数。
  4. 检查严格单调性。
    偶数层要求 value > prev；奇数层要求 value < prev。首节点没有前值，不做顺序比较。
  5. 更新并推进。
    保存当前值为 prev，把非空子节点入队；一层结束后层号加一。
  6. 尽早结束。
    任一规则不满足立即返回 false；队列清空则返回 true。

正确性

层序遍历保证节点恰按层号递增、同层从左到右访问。对每个节点检查层号对应的奇偶规则，确保数值类型合法；再与前值比较，确保每一对相邻值满足严格单调关系。若所有节点都通过，则每层满足定义，整棵树是奇偶树；若某项失败，定义已被违反，返回 false 必然正确。

复杂度

每个节点恰好入队、出队一次，时间复杂度为 O(n)。队列在最宽一层可能存放 w 个节点，空间复杂度为 O(w)，最坏为 O(n)。

边界情况

单节点树；只有一侧子树；同层出现相等值；奇偶性正确但顺序错误；顺序看似正确但某个值奇偶性错误；节点数达到 10⁵。

替代方案

可以用深度优先搜索并为每层保存最后访问值，按“根、左、右”顺序递归即可维持同层从左到右。但树高可能达到 10⁵，递归有栈溢出风险；BFS 更直接稳妥。

四语言完整代码

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isEvenOddTree(TreeNode root) {
        java.util.Queue<TreeNode> queue = new java.util.ArrayDeque<>();
        queue.offer(root);
        int level = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            int previous = level % 2 == 0 ? Integer.MIN_VALUE : Integer.MAX_VALUE;

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                int value = node.val;

                if (level % 2 == 0) {
                    if (value % 2 == 0 || value <= previous) return false;
                } else {
                    if (value % 2 != 0 || value >= previous) return false;
                }

                previous = value;
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            level++;
        }
        return true;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {boolean}
 */
var isEvenOddTree = function(root) {
    const queue = [root];
    let head = 0;
    let level = 0;

    while (head < queue.length) {
        const size = queue.length - head;
        let previous = level % 2 === 0 ? -Infinity : Infinity;

        for (let i = 0; i < size; i++) {
            const node = queue[head++];
            const value = node.val;

            if (level % 2 === 0) {
                if (value % 2 === 0 || value <= previous) return false;
            } else {
                if (value % 2 !== 0 || value >= previous) return false;
            }

            previous = value;
            if (node.left !== null) queue.push(node.left);
            if (node.right !== null) queue.push(node.right);
        }
        level++;
    }
    return true;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional

class Solution:
    def isEvenOddTree(self, root: Optional[TreeNode]) -> bool:
        queue = deque([root])
        level = 0

        while queue:
            previous = float("-inf") if level % 2 == 0 else float("inf")

            for _ in range(len(queue)):
                node = queue.popleft()
                value = node.val

                if level % 2 == 0:
                    if value % 2 == 0 or value <= previous:
                        return False
                else:
                    if value % 2 == 1 or value >= previous:
                        return False

                previous = value
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

            level += 1

        return True
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isEvenOddTree(TreeNode* root) {
        std::queue<TreeNode*> queue;
        queue.push(root);
        int level = 0;

        while (!queue.empty()) {
            int size = static_cast<int>(queue.size());
            long long previous = level % 2 == 0 ? LLONG_MIN : LLONG_MAX;

            for (int i = 0; i < size; ++i) {
                TreeNode* node = queue.front();
                queue.pop();
                int value = node->val;

                if (level % 2 == 0) {
                    if (value % 2 == 0 || value <= previous) return false;
                } else {
                    if (value % 2 != 0 || value >= previous) return false;
                }

                previous = value;
                if (node->left != nullptr) queue.push(node->left);
                if (node->right != nullptr) queue.push(node->right);
            }
            ++level;
        }
        return true;
    }
};

面试追问

为什么冻结 size？

遍历当前层时会把子节点继续压入队列。先记录层大小，才能把本轮和下一轮清楚分开。

能否不用无穷哨兵？

可以。每层用布尔量标记首节点；从第二个节点开始再比较，避免依赖取值边界。

DFS 的空间一定更少吗？

不一定。DFS 使用 O(h) 递归栈和每层前值；退化树高度可达 n，还可能超出语言调用栈。

如何处理流式层数据？

只要能识别层边界，就可边读边校验，每层仅维护前值；无需保留整层数值。

常见错误

  • 只检查数值奇偶性，忘记严格递增或严格递减。
  • 把“奇偶层”误解为节点值的奇偶，而不是层下标的奇偶。
  • 允许相邻节点值相等；严格单调必须使用 <= / >= 判错。
  • JavaScript 用 shift() 反复删除数组头，导致潜在的额外移动成本；可使用头指针。
  • 跨层沿用 previous，没有在每一层开始时重置。
