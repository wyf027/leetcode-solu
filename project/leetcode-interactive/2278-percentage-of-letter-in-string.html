字母在字符串中的百分比

Percentage of Letter in String

一串字母，一个目标字符。它究竟占了多大比例？

打开官方题目 ↗
01 / 读题

你的任务

给定字符串 s 和字符 letter，求 s 中等于 letter 的字符占全部字符的百分比。结果向下取整，返回一个整数。

返回的是百分数的数值，例如 33；不是字符串 “33%”。请留意“向下取整”和“四舍五入”的区别。

参数与约束

  • s：长度满足 1 ≤ s.length ≤ 100 的字符串。
  • s 只包含小写英文字母。
  • letter：恰好一个小写英文字母。
  • 函数：percentageLetter(s, letter)，返回整数。

官方示例 1

输入：s = "foobar", letter = "o"
输出：33

6 个字符中有 2 个 “o”，占比约为 33.33%，向下取整后得到 33。

官方示例 2

输入：s = "jjjj", letter = "k"
输出：0

字符串里没有 “k”，所以它的占比为 0%。

04 / 独立题解

想好之后，再揭晓

包含推导、正确性说明与四种语言代码。

一次扫描，统计目标字符

核心洞察

字符的先后顺序不影响占比。只要知道目标字符出现次数 count 和总长度 n，答案就是 ⌊100 × count / n⌋。字符串已提供总长，因此扫描时只需要一个计数器。

完整过程

  1. 令 count = 0。
  2. 遍历 s 的每个字符：等于 letter 时，令 count 加一；否则不改变 count。
  3. 扫描结束后，先计算 count × 100，再除以总长度并向下取整。

以 s = "foobar", letter = "o" 为例，计数器依次是 0 → 1 → 2 → 2 → 2 → 2；最后得到 ⌊200 / 6⌋ = 33。

为什么正确

循环不变式：扫描完前 i 个字符后，count 恰好等于这 i 个字符中目标字母的数量。初始 i = 0 时，count = 0，成立。处理下一个字符时，只有匹配才加一，因此不变式继续成立。循环结束时 i = n，count 就是整个字符串的匹配数量。按百分比定义乘以 100 再除以 n，并向下取整，恰好得到题目要求的整数。

边界与复杂度

  • 没有匹配时结果为 0；全部匹配时为 100；长度为 1 时同样适用。
  • n 至少为 1，不存在除零；count 最大为 100，乘以 100 最大为 10000，四种实现的数值范围均足够。
  • 时间复杂度 O(n)，每个字符访问一次；额外空间 O(1)，只保留计数器等常数个变量。可视化的 DOM 空间不属于提交算法。

四种语言 · 完整提交代码

下面均对应官方 percentageLetter 方法签名；由 LeetCode 提供调用入口。

Java

class Solution {
    public int percentageLetter(String s, char letter) {
        int count = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == letter) count++;
        }
        return count * 100 / s.length();
    }
}

JavaScript

/**
 * @param {string} s
 * @param {character} letter
 * @return {number}
 */
var percentageLetter = function(s, letter) {
    let count = 0;
    for (const ch of s) {
        if (ch === letter) count++;
    }
    return Math.floor(count * 100 / s.length);
};

Python 3

class Solution:
    def percentageLetter(self, s: str, letter: str) -> int:
        count = 0
        for ch in s:
            if ch == letter:
                count += 1
        return count * 100 // len(s)

C++

#include <string>
using namespace std;

class Solution {
public:
    int percentageLetter(string s, char letter) {
        int count = 0;
        for (char ch : s) {
            if (ch == letter) ++count;
        }
        return count * 100 / static_cast<int>(s.size());
    }
};

替代方案

Python 可用 s.count(letter) * 100 // len(s)，C++ 可用 std::count 完成统计，复杂度相同。也可以建立 26 个字母的频次表，但单次查询不需要它；对同一字符串查询很多不同字母时，频次表才有价值。使用 split 或 filter 计数会创建额外数据，通常没有必要。

常见错误

  • 在 Java / C++ 中写成 count / n * 100：整数除法会过早丢掉小数，应先乘 100。
  • 用 round 四舍五入：例如 2/3 要返回 66，不是 67。
  • 只返回 count，或忘记乘 100；返回带 % 的字符串也不符合签名。
  • 扫描中途拿已扫描长度当最终分母；最终百分比的分母始终是整个 s 的长度。
  • 把字符串转成集合会丢失重复次数，无法计算占比。

面试追问

  • 同一个 s 有很多次查询？一次 O(n) 建立 26 个频次，之后每次 O(1) 返回答案。
  • 字符流不知道总长度？流式维护总数和匹配数，流结束后计算；大规模输入需要注意乘法溢出。
  • 为何整数除法等价于向下取整？这里分子非负、分母为正，Java / C++ 向零截断与向下取整相同。
  • 如果包含 Unicode？先明确“字符”按码点还是字素簇计数，再统一遍历和长度的定义；本题仅限小写英文字母。
