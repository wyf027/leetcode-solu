移动零 Move Zeroes

不改变非零元素的先后关系，把所有零移动到数组末尾。要求直接修改传入数组，不能复制出另一个数组。

Problem

给定整数数组 nums，将其中所有 0 移到末尾，同时保持每个非零元素的相对顺序。函数返回值为 void，结果通过修改 nums 得到。

进阶：能否尽量减少操作次数？

  • 1 <= nums.length <= 10^4
  • -2^31 <= nums[i] <= 2^31 - 1
  • 必须原地修改，不额外创建同规模数组

输出：[1,3,12,0,0]

Solution

双指针：让非零元素稳定靠左

一根指针负责读完整个数组，另一根指针维护下一个非零元素应落下的位置。

核心洞察

read 从左到右只走一次；遇到非零值，就把它放到 write 所在位置，再让 write 前进一步。按发现顺序安放，自然保持稳定性。

操作优化

当 read == write 时元素已经处于正确位置，不做自交换；只有前方出现过零时才真正交换。

完整过程

  1. 令 write = 0，表示下一个非零元素应该放置的下标。
  2. 令 read 从 0 到 nums.length - 1 扫描。
  3. 若 nums[read] == 0，不操作，继续扫描。
  4. 若 nums[read] != 0 且两指针不同，交换 nums[write] 与 nums[read]；随后 write++。
  5. 扫描结束时，前缀全是按原顺序排列的非零元素，余下位置全为零。

正确性证明

维护循环不变量：每轮处理 read 之前，区间 [0, write) 恰好包含原数组已扫描前缀中的全部非零元素，且相对顺序不变；区间 [write, read) 全为零。

若当前值为零，只扩大已扫描的零区，不变量保持。若当前值非零，它是已扫描顺序中的下一个非零值；将其交换到 write 后，它接在稳定前缀末尾，而被换到 read 的是零，再令 write++，不变量仍成立。循环结束时 read 已覆盖整个数组，因此稳定非零前缀之后只能是零，结论成立。

复杂度

时间复杂度 O(n)；只使用两个下标和一个交换临时变量，额外空间复杂度 O(1)。

边界情况

长度为 1、全零、无零、零在开头或末尾、负数与整数边界值，均由同一逻辑处理。

替代方案

可先把非零值依次覆盖到前缀，再把后缀填零，同样是 O(n) / O(1)；也可用额外数组，但不满足原地要求。

常见错误

删除再追加导致近似 O(n²)；交换后错误移动指针；把零视为字符串；返回新数组而没有修改原数组。

四语言完整代码

Java

class Solution {
    public void moveZeroes(int[] nums) {
        int write = 0;

        for (int read = 0; read < nums.length; read++) {
            if (nums[read] != 0) {
                if (read != write) {
                    int temp = nums[write];
                    nums[write] = nums[read];
                    nums[read] = temp;
                }
                write++;
            }
        }
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {void}
 */
var moveZeroes = function (nums) {
    let write = 0;

    for (let read = 0; read < nums.length; read++) {
        if (nums[read] !== 0) {
            if (read !== write) {
                [nums[write], nums[read]] =
                    [nums[read], nums[write]];
            }
            write++;
        }
    }
};

Python 3

from typing import List


class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        write = 0

        for read in range(len(nums)):
            if nums[read] != 0:
                if read != write:
                    nums[write], nums[read] = (
                        nums[read], nums[write]
                    )
                write += 1

C++

class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int write = 0;

        for (int read = 0; read < nums.size(); ++read) {
            if (nums[read] != 0) {
                if (read != write) {
                    swap(nums[write], nums[read]);
                }
                ++write;
            }
        }
    }
};
