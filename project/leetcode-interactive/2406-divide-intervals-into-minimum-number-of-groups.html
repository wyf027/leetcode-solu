2406. 将区间分为最少组数

Divide Intervals Into Minimum Number of Groups

把一组闭区间安排到尽可能少的组里。先理解“相交”，再探索如何分组。

打开官方题目 ↗

题意与输入

给定二维整数数组 intervals，其中 intervals[i] = [leftᵢ, rightᵢ] 表示包含两端点的区间。每个区间必须且只能属于一个组；同组任意两个区间不能包含公共数字。返回所需组数的最小值，返回类型为整数。

端点也算重叠：[1,5] 与 [5,8] 共享数字 5，不能放在同一组。

约束

  • 1 ≤ intervals.length ≤ 10⁵
  • intervals[i].length == 2
  • 1 ≤ leftᵢ ≤ rightᵢ ≤ 10⁶

官方示例 1

输入：intervals = [[5,10],[6,8],[1,5],[2,3],[1,10]]
输出：3

一种分法：第 1 组为 [1,5]、[6,8]；第 2 组为 [2,3]、[5,10]；第 3 组为 [1,10]。最少需要 3 组。

官方示例 2

输入：intervals = [[1,3],[5,6],[8,10],[11,13]]
输出：1

所有区间互不相交，可以全部放入一组。

题解 · 扫过所有变化点

核心洞察

答案等于某个位置上同时覆盖的区间数量的最大值。将每个闭区间 [l,r] 变为两个事件：在 l 加 1，在 r+1 减 1。按坐标排序，合并同坐标事件后累加，记录峰值。

这里利用整数端点：直到 r 仍有覆盖，到了 r+1 才撤销。不要在 r 就减 1，否则会把共享端点的区间误认为不相交。

完整过程
  1. 为每个 [l,r] 写入 (l,+1)、(r+1,−1)，共 2n 个事件。
  2. 按事件坐标升序排列；初始 active = 0，answer = 0。
  3. 取出当前坐标的所有事件，累加其变化量，再更新 active。此时 active 就是这个整数位置的覆盖数。
  4. 令 answer = max(answer,active)，继续处理下一个坐标，最终返回 answer。
示例 1 的合并变化依次是：x=1 加 2 → 覆盖 2；x=2 加 1 → 3；x=4 减 1 → 2；x=5 加 1 → 3；x=6 净变化 0 → 3（[1,5] 离开、[6,8] 进入）；x=9 减 1 → 2；x=11 减 2 → 0。峰值为 3。


正确性证明
覆盖计数不变式：处理坐标 x 的全部事件后，一个区间贡献 1 当且仅当 l ≤ x < r+1，即 l ≤ x ≤ r。前缀和因此精确表示当前覆盖数。覆盖只会在事件坐标改变，所以这些坐标足以捕获峰值 K。
下界：同时覆盖某点的 K 个区间两两相交，必须属于 K 个不同组，答案至少为 K。
上界：按左端点递增处理区间。若存在结束点严格小于当前左端点的组，就复用该组；否则新建组。新建第 g 组时，已有 g−1 组的末尾区间都覆盖当前左端点，再加当前区间，该点覆盖数至少为 g，因此 g ≤ K。总能用不超过 K 组完成。上下界相等，扫描得到的 K 就是最优答案。


边界与常见错误
  • 单点 [a,a] 仍是非空区间；事件位于 a 和 a+1。
  • 完全相同的 n 个区间需要 n 组；不能去重。
  • [1,2] 和 [3,4] 可以复用一组，而 [1,2] 和 [2,3] 不行。
  • 同坐标先聚合再记录峰值，避免临时事件顺序产生虚假峰值。
  • 最大结束点为 10⁶，r+1 可达 1000001；当前四语言数值类型都能容纳。
  • JavaScript 必须显式提供数值排序比较器；默认排序按字符串顺序。
  • 输入可乱序、嵌套；只看相邻原始区间，或者合并相交区间数量，都无法求组数。


复杂度
n 个区间产生 2n 个事件，排序时间 O(n log n)，聚合扫描 O(n)，总时间 O(n log n)，额外空间 O(n)。下面四份代码均使用新事件数组，不改变原始区间顺序。


替代方案
  • 最小堆：按左端点排序，维护各组末尾区间的右端点。堆顶 < l 才能复用组，最终堆大小为答案。时间 O(n log n)，空间 O(n)。如需返回实际分组，可在堆中附带组编号。
  • 稠密差分：建立大小约 10⁶+2 的数组，对 l 加 1、r+1 减 1 后求前缀和。时间 O(n+U)、空间 O(U)，U 为坐标范围；坐标大且稀疏时事件排序更节省空间。
  • 双指针：分别排序开始与结束端点；开始点等于结束点时先计入开始事件，因为区间是闭区间。时间 O(n log n)，空间 O(n)。

Java


import java.util.Arrays;

class Solution {
    public int minGroups(int[][] intervals) {
        int[][] events = new int[intervals.length * 2][2];
        int k = 0;
        for (int[] interval : intervals) {
            events[k++] = new int[]{interval[0], 1};
            events[k++] = new int[]{interval[1] + 1, -1};
        }
        Arrays.sort(events, (a, b) -> Integer.compare(a[0], b[0]));
        int active = 0, answer = 0, i = 0;
        while (i < events.length) {
            int x = events[i][0], delta = 0;
            while (i < events.length && events[i][0] == x) {
                delta += events[i++][1];
            }
            active += delta;
            answer = Math.max(answer, active);
        }
        return answer;
    }
}

        answer = Math.max(answer, active);
    }
    return answer;
};

C++


#include <algorithm>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int minGroups(vector<vector<int>>& intervals) {
        vector<pair<int, int>> events;
        events.reserve(intervals.size() * 2);
        for (const auto& interval : intervals) {
            events.emplace_back(interval[0], 1);
            events.emplace_back(interval[1] + 1, -1);
        }
        sort(events.begin(), events.end());
        int active = 0, answer = 0;
        size_t i = 0;
        while (i < events.size()) {
            int x = events[i].first, delta = 0;
            while (i < events.size() && events[i].first == x) {
                delta += events[i++].second;
            }
            active += delta;
            answer = max(answer, active);
        }
        return answer;
    }
};




面试追问
  • 需要输出每个区间的组号？用最小堆保存 (右端点,组号)，排序时保留原索引，复用或新建组后写回索引。
  • 端点是实数，还能使用 r+1 吗？不能；直接使用开始与结束事件，同位置先处理所有开始，更新峰值，再处理结束。
  • 换成半开区间 [l,r) 呢？右端点 r 就能释放资源；同位置先结束再开始，空区间需单独按新题意处理。
  • 在线插入和删除区间？静态排序不能直接维护每次答案；可讨论动态线段树维护覆盖增减与全局最大值。
