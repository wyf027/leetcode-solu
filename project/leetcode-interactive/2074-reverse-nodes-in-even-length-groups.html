01题目与规则

给定单链表的头节点 head。从头到尾将节点依次放入容量为 1、2、3、4、… 的非空组：第 1 个节点在第一组，第 2、3 个在第二组，第 4、5、6 个在第三组，以此类推。最后一组若节点不足，就由剩下的所有节点组成。

把实际节点数为偶数的每个组内的节点顺序反转，奇数长度组保持原样；各组之间的先后顺序不变。返回修改后的链表头节点。

参数与返回值

输入：head: ListNode
返回：ListNode，即处理后的头节点。

官方约束

节点个数：1 ≤ n ≤ 10⁵
节点值：0 ≤ Node.val ≤ 10⁵

05题解 · 先数清，再接线




核心洞察
计划组长 size 只决定扫描上限，实际组长 count 才决定是否反转。先从组首扫描至下一组首 after，再处理当前组。维护 before 指向已完成前缀的尾节点，用哑节点统一边界。


完整过程
  1. 建立 dummy → head，令 before = dummy，size = 1。
  2. 从 before.next 开始至多走 size 步或遇到 null，得到 count 和 after。
  3. count 为奇数：不改 next，仅让 before 前进 count 步。
  4. count 为偶数：保存旧组首 tail，令 cur = tail、prev = after。重复 count 次：保存 next = cur.next，执行 cur.next = prev，然后 prev = cur、cur = next。
  5. 此时 prev 为新组首；令 before.next = prev，把前缀接回。旧组首 tail 已成为组尾，因此更新 before = tail。
  6. size 加一；直到 before.next 为 null，返回 dummy.next。
以 N2 → N3 为例：先保存 N3，再将 N2.next 指向下一组；随后 N3.next 指向 N2，最后前一组尾部指向 N3。节点值完全不变。


正确性说明
外层不变式：每轮开始时，before 及之前的前缀已按规则处理，before.next 指向尚未处理的首节点，剩余节点顺序仍与输入一致。计数扫描精确取得下一组的实际节点数，不会跨越该组。
奇数组不改连接，移动 before 后不变式成立。偶数组内，执行 i 次反转后，前 i 个节点形成从 prev 到 after 的反向链，其余节点仍由 cur 和已保存的 next 可达。初始 prev = after 保证原组首变成尾部时直接连到后缀；count 次后全组反转。before.next = prev 将前缀接到新组首，再把 before 移到新组尾，恢复外层不变式。
每轮至少消耗一个节点，有限轮后处理完全部节点。因此返回的链表恰好反转所有偶数长度组，并保留其他顺序。


边界
  • n = 1：唯一的组是奇数，不反转。
  • 末组不足：按实际 count 判断；计划 3、实际 2 仍需反转。
  • 末组恰好完整：与普通组相同。
  • 重复值、0 和 100000：不影响判断，操作的是节点身份。
  • 空链表不在约束内；这四份实现也能自然返回空。
复杂度
时间 O(n)：每个节点在计数时访问一次，在移动或反转时再访问一次，总次数是线性的。
额外空间 O(1)：仅保存哑节点、若干指针和计数器。页面为支持上一步而保存快照，属于演示开销，不属于提交算法。


替代方案
把节点引用存入数组，按 1、2、3… 切分区间，对实际偶数长度区间倒序，再重连所有 next。时间 O(n)、额外空间 O(n)，实现直观但需要额外存储。若只交换值，虽然值序列可能相同，却没有真正反转节点；这里采用符合题意的指针重连。递归处理分组也可行，但会引入递归栈且没有必要。


常见错误
  • 用 size 的奇偶决定反转，漏掉不完整末组。
  • 没有先保存 cur.next，修改后丢失未处理后缀。
  • prev 初始化为 null 却忘记接回 after，导致链表截断。
  • 偶数组结束后将 before 设为新组首，下一轮分组错位；应设为旧组首。
  • 先反转再寻找组边界，边界已被修改；必须先计数。


面试追问
能只反转偶数编号组吗？不能，最后一组可能不足，组编号无法代表实际长度。
能先算总长度再决定组长吗？可以，取 min(size, remaining)，仍是 O(n) 时间、O(1) 空间。
为什么 prev 从 after 开始？第一次反向连接就让旧组首连上后缀，省去单独接尾。
如何推广到按其他条件反转？保留组边界扫描和重连逻辑，替换基于实际组属性的判断即可。

// ListNode 由 LeetCode 提供。
class Solution {
    public ListNode reverseEvenLengthGroups(ListNode head) {
        ListNode dummy = new ListNode(0, head);
        ListNode before = dummy;
        int size = 1;
        while (before.next != null) {
            ListNode after = before.next;
            int count = 0;
            while (count < size && after != null) {
                after = after.next;
                count++;
            }
            if (count % 2 == 0) {
                ListNode tail = before.next;
                ListNode cur = tail, prev = after;
                for (int i = 0; i < count; i++) {
                    ListNode next = cur.next;
                    cur.next = prev;
                    prev = cur;
                    cur = next;
                }
                before.next = prev;
                before = tail;
            } else {
                for (int i = 0; i < count; i++) before = before.next;
            }
            size++;
        }
        return dummy.next;
    }
}
