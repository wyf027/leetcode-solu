String Transforms Into Another String

把字符替换规则想成一张只有 26 个节点的有向图：难点不是逐字符修改，而是判断这张图是否自洽，以及环能否被拆开。

题目

给定两个长度相同、仅含小写英文字母的字符串 str1 和 str2。一次操作可以选择 str1 中当前存在的某个字符，并把它在整个字符串中的所有出现位置同时替换为另一个小写字母。判断能否通过若干次操作把 str1 变成 str2。

同一个源字符的所有位置必须始终一起变化，因此它不能同时对应两个不同的目标字符。

函数签名

canConvert(str1: string, str2: string): boolean

示例 1

输入：str1 = "aabcc", str2 = "ccdee"
输出：true
解释：可以建立 a → c、b → d、c → e 的一致映射。

示例 2

输入：str1 = "leetcode", str2 = "codeleet"
输出：false
解释：源字符 e 在对应位置需要变成 o、d、e 等不同字符，映射冲突。

约束

  • 1 ≤ str1.length = str2.length ≤ 10⁴
  • str1 与 str2 仅包含小写英文字母。

题解

核心洞察

扫描对应位置，为每个源字符记录唯一目标字符。如果同一源字符需要指向不同目标，立即失败。映射一致仍不够：当两串不相等且目标串用满 26 个字母时，没有临时字符可拆解转换环，因此失败。若两串完全相等，则无需操作，直接成功。

完整过程

  1. 若 str1 === str2，返回 true。
  2. 从左到右扫描，以哈希表记录 str1[i] → str2[i]；遇到冲突返回 false。
  3. 统计 str2 中不同字符数。少于 26 说明至少有一个未被目标占用的字母，可作为临时缓冲，依次拆环；返回 true。否则返回 false。

为什么正确

必要性：一次替换会同时影响某字符的全部出现位置，所以一个源字符只能有一个目标；有冲突必不可能。若非恒等转换的目标已占满全部字母，则任何循环映射都没有外部临时节点可用，先替换环中任一字符都会丢失其原值。

充分性：映射无冲突时，映射图中每个节点至多一条出边。非环路径可按目标到源的逆序完成。若目标未用满 26 个字母，取一个空闲字母保存环中某字符，断开环后依次转换，最后把临时字母转成目标；所有分量都能完成。

边界

  • 两串相同：即便使用了 26 个字母，也无需转换。
  • 多个源字符可以汇入同一目标字符，这是允许的。
  • 长度为 1、恒等映射和自环都自然涵盖。
  • 判断空闲字符要看目标串的不同字符数，而不是源串。

复杂度

时间复杂度 O(n)；映射和字符集合最多含 26 项，额外空间 O(1)（按固定字母表计）。

替代方案

可显式构造 26 节点图并做环检测，但最终仍须处理空闲字符，代码更长。数组映射比哈希表常数更小；哈希表表达更直接，也容易推广到更大字符集。

面试追问

  • 若字符集不是固定 26 个字母，条件如何改？答：目标使用的不同符号数必须小于字符集大小，除非两串相同。
  • 能否输出具体操作序列？答：对非环分量逆拓扑处理；每个环借助空闲字符拆开并记录替换步骤。
  • 为什么不要求映射一一对应？答：操作允许多个不同源字符最终合并到同一个目标字符。

常见错误

  • 只检查映射一致性，遗漏“26 个目标字符全部占满”的死环。
  • 把多个源映射到同一目标误判为冲突。
  • 先判断目标字符数为 26 就失败，忘了两串完全相等的特例。

四语言实现

Java
class Solution {
    public boolean canConvert(String str1, String str2) {
        if (str1.equals(str2)) return true;
        int[] map = new int[26];
        java.util.Arrays.fill(map, -1);
        boolean[] used = new boolean[26];
        int distinct = 0;
        for (int i = 0; i < str1.length(); i++) {
            int from = str1.charAt(i) - 'a';
            int to = str2.charAt(i) - 'a';
            if (map[from] != -1 && map[from] != to) return false;
            map[from] = to;
            if (!used[to]) { used[to] = true; distinct++; }
        }
        return distinct < 26;
    }
}
JavaScript
/**
 * @param {string} str1
 * @param {string} str2
 * @return {boolean}
 */
var canConvert = function(str1, str2) {
  if (str1 === str2) return true;
  const map = new Map();
  const targets = new Set();
  for (let i = 0; i < str1.length; i++) {
    const from = str1[i], to = str2[i];
    if (map.has(from) && map.get(from) !== to) return false;
    map.set(from, to);
    targets.add(to);
  }
  return targets.size < 26;
};
Python
class Solution:
    def canConvert(self, str1: str, str2: str) -> bool:
        if str1 == str2:
            return True
        mapping = {}
        for source, target in zip(str1, str2):
            if source in mapping and mapping[source] != target:
                return False
            mapping[source] = target
        return len(set(str2)) < 26
C++
class Solution {
public:
    bool canConvert(string str1, string str2) {
        if (str1 == str2) return true;
        vector<int> mapping(26, -1);
        unordered_set<char> targets;
        for (int i = 0; i < (int)str1.size(); ++i) {
            int from = str1[i] - 'a';
            int to = str2[i] - 'a';
            if (mapping[from] != -1 && mapping[from] != to) return false;
            mapping[from] = to;
            targets.insert(str2[i]);
        }
        return targets.size() < 26;
    }
};
