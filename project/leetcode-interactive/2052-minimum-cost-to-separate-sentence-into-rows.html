Minimum Cost to Separate Sentence Into Rows

让文字在固定宽度内换行。单词顺序不变，行末留白有成本，而最后一行享受豁免。你会把换行符放在哪里？

01 — THE PROBLEM

题意与输入输出

输入字符串 sentence 和整数 k。在单词之间选择换行位置，每行最多占 k 个字符（包括行内空格）。单词不能拆开、重排、遗漏或重复；一行相邻单词之间保留一个空格，行首行尾不含空格。

长度为 L 的非末行产生 (k − L)² 的成本。返回所有合法分行方案中，非末行成本之和的最小值。

最后一行的成本恒为 0。 它仍必须满足长度不超过 k 的限制。只有一行时，总成本就是 0。

官方参数形式：minimumCost(sentence: string, k: integer) → integer

约束

  • 1 ≤ sentence.length ≤ 5000，1 ≤ k ≤ 5000。
  • 每个单词长度均不超过 k。
  • 字符串仅含小写英文字母和空格。
  • 没有首尾空格；相邻单词恰由一个空格分隔。

02 — EXAMPLES

官方示例

示例 1

sentence = "i love leetcode"
k = 12
输出 = 36

分为「i love」「leetcode」。首行长度 6，成本 (12 − 6)² = 36；末行不计费。

示例 2

sentence = "apples and bananas taste great"
k = 7
输出 = 21

五个单词分别成行。成本为 1² + 4² + 0² + 2² = 21；最后的「great」免费。

示例 3

sentence = "a"
k = 5
输出 = 0

唯一一行也是最后一行，所以无需支付留白成本。

03 — SOLUTION LAB

后缀动态规划：让每一个换行点参与比较

核心洞察

一行必然是一段连续单词。确定第一行结束在 j 后，剩余问题只与后缀 j + 1 有关。令 dp[i] 表示从第 i 个单词开始排到末尾的最低成本，答案为 dp[0]。

L(i,j) = Σ len(word[t]) + (j − i), t ∈ [i,j] cost(i,j) = j == n − 1 ? 0 : (k − L(i,j))² dp[n] = 0 dp[i] = min { cost(i,j) + dp[j+1] | L(i,j) ≤ k }

从右向左计算 i，每次向右扩展 j；累加新单词长度，并在非首词前计入一个空格。超过 k 后直接停止扩展，因为再追加单词只会更长。

INTERACTIVE / ROW EXPLORER

换行候选 × 留白成本 × 后缀账本

绿色：当前状态 · 金色：依赖状态

每一步尝试一段连续单词，比较「当前行成本 + 已知后缀成本」。演示为浏览器内计算，未作为验证结果。为保证逐步回放轻量，演示输入限 80 字符、k ≤ 40；下方提交代码支持完整题目约束。

后缀账本：每格为 dp[下标]；∞ 表示尚未找到候选，不代表最终无解。

完整过程

  1. 按空格切词，得到 n 个单词；建立 n + 1 个状态。
  2. 令 dp[n] = 0，其余为无穷大。
  3. 依次计算 i = n − 1 … 0，令当前行长为 0。
  4. 枚举 j ≥ i，累加词长和必要空格；越界则退出内层循环。
  5. 若 j 是最后一个单词，本行费用取 0，否则取留白平方；用它加上 dp[j + 1] 更新 dp[i]。
  6. 返回 dp[0]。若要恢复排版，额外记录每次改进时的下一行起点。

正确性：对后缀长度归纳

空后缀没有行，dp[n] = 0 正确。假设所有比 i 更靠右的状态均已最优。

任意合法排版的第一行一定对应一个被枚举到的终点 j，其余部分必须排版后缀 j + 1。将剩余部分替换为 dp[j + 1] 对应的最优排版，不会增加成本；行费用也按是否末行准确计算。

因此，每个候选都能构造合法方案，而每个合法方案都有对应候选。取最小值恰得 dp[i] 的最优值。归纳至 i = 0，返回值正确。

边界与数值

  • 整句可装入一行：末行候选直接给出 0。
  • 恰好装满：留白为 0，也合法。
  • 单词长等于 k：单独成行即可；约束保证始终有解。
  • 单词间有 j − i 个空格，不是 j − i + 1 个。
  • Java / C++ 用 64 位中间值，避免大候选累加溢出；官方返回类型仍为整数。

返回值可放入 32 位整数：若整句长度 S ≤ k，答案为 0；否则 k < S ≤ 5000。考虑每行尽量填充的可行排版，每个非末行的留白小于下一词长度加 1，因此不超过下一词长度。留白总和不超过 S，总成本不超过 kS < 25,000,000。中间非最优候选不受这个最优值界约束。

复杂度与替代方案

时间 O(S + n²)：S 为字符数，切词 O(S)，最多考察 n(n + 1)/2 段；超宽提前停止通常减少枚举。

空间 O(S + n)：保存切词内容与 dp；单看 DP 辅助空间为 O(n)。

记忆化搜索可以表达同一递推，但最深递归为 O(n)，需留意 Python / JavaScript 的栈深限制。前缀 DP 也可做，须单独处理末行免费。暴力枚举换行方案约 O(2ⁿ)，不适合完整约束。

为什么贪心不可靠？

sentence = "aaa bb cc ddddd", k = 6。尽量填满会得到「aaa bb / cc / ddddd」，成本 0 + 16 = 16；改为「aaa / bb cc / ddddd」，成本 9 + 1 = 10。局部减少第一行留白，可能把更多留白推到下一行，平方费用让全局结果变差。

常见错误

  • 给最后一行加留白平方，导致单行输入不为 0。
  • 只按单词长度计宽，漏掉行内空格。
  • 因为末行免费而允许其超宽；宽度限制适用于所有行。
  • 从左到右计算后缀 dp，使用尚未求出的依赖。
  • 把换行位置视为可重排单词，改变题意。

面试追问

  • 如何输出具体排版？ 更新最小值时存 next[i] = j + 1，然后从 0 沿 next 恢复。
  • 末行也计费呢？ 删除 j == n − 1 的费用特判；dp[n] 仍为 0。
  • 若费用改为绝对值或其他函数？ 只要每行费用独立可加，沿用状态与枚举，把平方替换为新函数。
  • 为什么不加前缀和？ 每个起点按 j 顺序扩展时可直接累加行长；前缀和不会改变这里的渐进复杂度。

Java

import java.util.Arrays;

class Solution {
    public int minimumCost(String sentence, int k) {
        String[] words = sentence.split(" ");
        int n = words.length;
        long[] dp = new long[n + 1];
        Arrays.fill(dp, Long.MAX_VALUE / 4);
        dp[n] = 0;
        for (int i = n - 1; i >= 0; i--) {
            int length = 0;
            for (int j = i; j < n; j++) {
                length += words[j].length() + (j == i ? 0 : 1);
                if (length > k) break;
                long gap = k - length;
                long cost = j == n - 1 ? 0 : gap * gap;
                dp[i] = Math.min(dp[i], cost + dp[j + 1]);
            }
        }
        return (int) dp[0];
    }
}

JavaScript

/**
 * @param {string} sentence
 * @param {number} k
 * @return {number}
 */
var minimumCost = function(sentence, k) {
    const words = sentence.split(' ');
    const n = words.length;
    const dp = Array(n + 1).fill(Infinity);
    dp[n] = 0;
    for (let i = n - 1; i >= 0; i--) {
        let length = 0;
        for (let j = i; j < n; j++) {
            length += words[j].length + (j === i ? 0 : 1);
            if (length > k) break;
            const cost = j === n - 1 ? 0 : (k - length) ** 2;
            dp[i] = Math.min(dp[i], cost + dp[j + 1]);
        }
    }
    return dp[0];
};

Python

class Solution:
    def minimumCost(self, sentence: str, k: int) -> int:
        words = sentence.split(" ")
        n = len(words)
        dp = [float("inf")] * (n + 1)
        dp[n] = 0
        for i in range(n - 1, -1, -1):
            length = 0
            for j in range(i, n):
                length += len(words[j]) + (0 if j == i else 1)
                if length > k:
                    break
                cost = 0 if j == n - 1 else (k - length) ** 2
                dp[i] = min(dp[i], cost + dp[j + 1])
        return dp[0]

C++

#include <algorithm>
#include <limits>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int minimumCost(string sentence, int k) {
        istringstream input(sentence);
        vector<int> lengths;
        string word;
        while (input >> word) lengths.push_back((int)word.size());
        int n = (int)lengths.size();
        vector<long long> dp(n + 1,
            numeric_limits<long long>::max() / 4);
        dp[n] = 0;
        for (int i = n - 1; i >= 0; --i) {
            int length = 0;
            for (int j = i; j < n; ++j) {
                length += lengths[j] + (j == i ? 0 : 1);
                if (length > k) break;
                long long gap = k - length;
                long long cost = j == n - 1 ? 0 : gap * gap;
                dp[i] = min(dp[i], cost + dp[j + 1]);
            }
        }
        return (int)dp[0];
    }
};
