Second Minimum Time to Reach Destination

同步的红绿灯，相同的道路耗时。找出严格晚于最快到达时刻的那个最早时刻。

先理解交通规则，尝试独立思考。算法、交互推演与四语言代码收纳在底部折叠题解中。

01 / 题目说明

一座城市由一个无向连通图表示，共有 n 个节点，编号为 1…n。数组 edges 中每个元素 [uᵢ, vᵢ] 表示一条双向道路，没有自环或重复边。经过任意一条道路都恰好需要 time 分钟。

所有节点的交通灯同步变化，每隔 change 分钟在绿灯与红灯之间切换。出发时刻为 0，所有灯刚变绿。任何时刻都可进入节点，但只有绿灯时可以离开：绿灯不能主动等待，红灯必须等到下一次绿灯。

返回从节点 1 到节点 n 的第二短时间，即严格大于最短时间的最小到达时间。多个路线产生同一个最短时间，只算一个值。例如 [2, 2, 4] 的第二小值是 4。允许重复经过任何节点，包括起点与终点；到达终点时可以结束行程。

切换边界：[0, change) 为绿灯，[change, 2 × change) 为红灯。恰好在 change 时刻到达仍需等待才能离开；到达终点后如果结束行程，就不再等灯。

参数形式

secondMinimum(n, edges, time, change) → integer

完整约束

  • 2 ≤ n ≤ 10⁴
  • n − 1 ≤ edges.length ≤ min(2 × 10⁴, n × (n − 1) / 2)
  • edges[i].length = 2
  • 1 ≤ uᵢ, vᵢ ≤ n，且 uᵢ ≠ vᵢ
  • 没有重复边；每个节点都能从其他节点直接或间接到达。
  • 1 ≤ time, change ≤ 10³

04 / 题解 · 先数边，再看灯

核心洞察

所有道路耗时相同且信号灯同步，因此从时刻 0 出发，走过相同条数的边，就有相同的到达时间，与节点选择无关。令 T(k) 表示走完 k 条边的时刻：

T(0) = 0
q = floor(T(k) / change)
depart = q 为偶数 ? T(k) : (q + 1) × change
T(k + 1) = depart + time

每增加一条边，时间至少增加 time > 0，所以 T(k) 严格递增。第二小的不同边数恰好对应第二短时间。先用 BFS 求第二短边数，再模拟信号灯。

完整过程

  1. 建立双向邻接表。每个节点保存 first 和 second 两个不同边数，初始为无穷大；令 first[1] = 0，将 (1, 0) 入队。
  2. 从 FIFO 队列弹出 (u, d)，向所有邻居 v 尝试 nd = d + 1。
  3. 如果 v 的第一记录为空，填入 nd 并入队；否则仅当 nd 严格大于第一记录且第二记录为空时，填入第二记录并入队。重复长度直接跳过。
  4. 队列耗尽后取 second[n]。从时刻 0 出发模拟这么多条边：如果当前是红灯，先跳到下一次绿灯起点，再增加 time。
  5. 最后一条边走完直接返回累计时间，不在终点额外等灯。

由于 BFS 按非递减边数发现状态，首次填入的两个不同长度已经最优，无需替换旧记录。终点状态仍会扩展，因为题目允许再次离开终点。

正确性证明

时间只由边数决定：出发时间统一为 0。若经过 k 条边后的时刻相同，同步灯使下一次出发时刻相同，相同道路耗时又使下一次到达时刻相同。归纳可知所有 k 边行程的到达时间都是 T(k)。又因为每一步必然花费正时间，T 严格递增。

两个长度足够：BFS 队列的边数非递减，第一次发现节点的长度最小，随后第一个严格更大的长度就是第二小。同一节点同一长度的状态可以合并，因为可选后缀完全相同。到达某节点的第三种长度，可以被该节点前两种长度接上同一个后缀所超越，得到两个更短且不同长度的完整行程，因此第三种状态不可能是终点第二短行程所必需的。

答案存在且正确：连通性保证有最短路线；在该路线的一条边上额外往返一次，可构造比最短路线多两条边的合法行程。因此第二种长度存在。BFS 得到第二小边数后，严格递增的 T 将它映射为第二短时间。

边界与常见错误

  • 第二条路线可能与第一条路线耗时相同；要找第二个不同的值，不能简单统计终点出队次数而不去重。
  • 只有一个 visited 标记会丢掉第二记录。保存两个状态不代表路线中的节点最多只能经过两次。
  • 第二短不一定是最短加 1。二分图往往只能增加偶数条边，单边图需要走 3 条边才能第二次以不同时间到达。
  • 判断红灯用 floor(t / change) % 2，不是只看 t % change。恰在 change 时刻准备出发必须等完整红灯时段。
  • 绿灯不能主动等待来制造第二答案；等待只能发生在出发前，终点结束后不等灯。
  • 不能在第一次发现终点时返回；还要找到它的第二个不同长度。
  • JavaScript 使用头指针而非频繁 shift，避免队列搬移开销。

复杂度与整数范围

设 m 为边数，每个节点最多两个入队状态，每条邻接边最多随两个状态各扫描一次，时间 O(n + m)，空间 O(n + m)。最短路线至多 n − 1 条边，额外往返一次就得到至多 n + 1 条边的路线，因此第二短边数至多 n + 1，时间换算只需 O(n)。每步耗时不超过 time + change，总时间上界为 (n + 1) × (time + change) ≤ 20,002,000，32 位有符号整数足够。

替代方案

可用 Dijkstra 按到达时间维护每个节点的两个不同距离，松弛时先算等灯，再加道路耗时，通常为 O((n + m) log n)。本题的等权道路与同步灯让边数 BFS 更简洁。如果道路耗时不同，边数不再能决定时间；如果灯有不同相位，也需重新论证状态合并规则，不能直接沿用此解法。

面试追问

  • 可以提前退出吗？可以在首次填入 second[n] 时结束 BFS，后续候选边数不会更小。代码保留完整遍历便于讲解。
  • 如何恢复第二短路线？按 (节点, 距离记录编号) 保存前驱状态，沿终点第二状态回溯，不能只为一个节点保留一个父节点。
  • 第 k 短如何扩展？在同步等权条件下，为每个节点维护前 k 个不同边数并按层扩展，再做时间映射，状态数随 k 增长。
  • 为什么不能用第二条简单路径？题目允许重复经过节点，单边图的答案本身就需要往返，简单路径模型会漏解。

JavaScript

/**
 * @param {number} n
 * @param {number[][]} edges
 * @param {number} time
 * @param {number} change
 * @return {number}
 */
var secondMinimum = function(n, edges, time, change) {
    const graph = Array.from({ length: n + 1 }, () => []);
    for (const [u, v] of edges) {
        graph[u].push(v);
        graph[v].push(u);
    }
    const first = Array(n + 1).fill(Infinity);
    const second = Array(n + 1).fill(Infinity);
    first[1] = 0;
    const queue = [[1, 0]];
    for (let head = 0; head < queue.length; head++) {
        const [u, d] = queue[head];
        const nd = d + 1;
        for (const v of graph[u]) {
            if (first[v] === Infinity) {
                first[v] = nd;
                queue.push([v, nd]);
            } else if (nd > first[v] && second[v] === Infinity) {
                second[v] = nd;
                queue.push([v, nd]);
            }
        }
    }
    let elapsed = 0;
    for (let i = 0; i < second[n]; i++) {
        const phase = Math.floor(elapsed / change);
        if (phase % 2 === 1) elapsed = (phase + 1) * change;
        elapsed += time;
    }
    return elapsed;
};

Java

import java.util.*;

class Solution {
    public int secondMinimum(int n, int[][] edges, int time, int change) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
        for (int[] edge : edges) {
            graph.get(edge[0]).add(edge[1]);
            graph.get(edge[1]).add(edge[0]);
        }
        int[] first = new int[n + 1];
        int[] second = new int[n + 1];
        Arrays.fill(first, Integer.MAX_VALUE);
        Arrays.fill(second, Integer.MAX_VALUE);
        first[1] = 0;
        Deque<int[]> queue = new ArrayDeque<>();
        queue.addLast(new int[]{1, 0});
        while (!queue.isEmpty()) {
            int[] state = queue.removeFirst();
            int nd = state[1] + 1;
            for (int v : graph.get(state[0])) {
                if (first[v] == Integer.MAX_VALUE) {
                    first[v] = nd;
                    queue.addLast(new int[]{v, nd});
                } else if (nd > first[v] && second[v] == Integer.MAX_VALUE) {
                    second[v] = nd;
                    queue.addLast(new int[]{v, nd});
                }
            }
        }
        int elapsed = 0;
        for (int i = 0; i < second[n]; i++) {
            int phase = elapsed / change;
            if (phase % 2 == 1) elapsed = (phase + 1) * change;
            elapsed += time;
        }
        return elapsed;
    }
}

from collections import deque
from typing import List

class Solution:
    def secondMinimum(self, n: int, edges: List[List[int]],
                      time: int, change: int) -> int:
        graph = [[] for _ in range(n + 1)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        first = [float('inf')] * (n + 1)
        second = [float('inf')] * (n + 1)
        first[1] = 0
        queue = deque([(1, 0)])
        while queue:
            u, d = queue.popleft()
            nd = d + 1
            for v in graph[u]:
                if first[v] == float('inf'):
                    first[v] = nd
                    queue.append((v, nd))
                elif nd > first[v] and second[v] == float('inf'):
                    second[v] = nd
                    queue.append((v, nd))
        elapsed = 0
        for _ in range(second[n]):
            phase = elapsed // change
            if phase % 2 == 1:
                elapsed = (phase + 1) * change
            elapsed += time
        return elapsed

#include <vector>
#include <queue>
#include <utility>
#include <climits>
using namespace std;

class Solution {
public:
    int secondMinimum(int n, vector<vector<int>>& edges,
                      int time, int change) {
        vector<vector<int>> graph(n + 1);
        for (const auto& edge : edges) {
            graph[edge[0]].push_back(edge[1]);
            graph[edge[1]].push_back(edge[0]);
        }
        vector<int> first(n + 1, INT_MAX), second(n + 1, INT_MAX);
        first[1] = 0;
        queue<pair<int, int>> q;
        q.push({1, 0});
        while (!q.empty()) {
            auto [u, d] = q.front();
            q.pop();
            int nd = d + 1;
            for (int v : graph[u]) {
                if (first[v] == INT_MAX) {
                    first[v] = nd;
                    q.push({v, nd});
                } else if (nd > first[v] && second[v] == INT_MAX) {
                    second[v] = nd;
                    q.push({v, nd});
                }
            }
        }
        int elapsed = 0;
        for (int i = 0; i < second[n]; i++) {
            int phase = elapsed / change;
            if (phase % 2 == 1) elapsed = (phase + 1) * change;
            elapsed += time;
        }
        return elapsed;
    }
};
