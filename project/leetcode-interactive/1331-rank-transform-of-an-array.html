数组序号
转换

把每个数字换成它在所有不同数字中的相对位置：最小值从 1 开始，相等的值共享序号，而且不留下空档。

Rank Transform of an Array

Problem statement

题目要求

给定一个整数数组 arr，将数组中的每个元素替换为它排序后的序号，并返回转换后的数组。

  • 序号是从 1 开始的整数。
  • 元素越大，序号越大；相等元素必须拥有相同序号。
  • 每个元素的序号应尽可能小，因此不同值之间的序号连续。
函数形式：arrayRankTransform(arr: integer[]) → integer[]

约束

0 ≤ arr.length ≤ 105
−109 ≤ arr[i] ≤ 109

空数组也是合法输入，应返回空数组。

示例 1

输入：arr = [40,10,20,30]
输出：[4,1,2,3]

10、20、30、40 从小到大分别排在第 1、2、3、4 位。

示例 2

输入：arr = [100,100,100]
输出：[1,1,1]

相同元素共享同一序号。

示例 3

输入：arr = [37,12,28,9,100,56,80,5,12]
输出：[5,3,4,2,8,6,7,1,3]

Core insight

排序去重，再建立“值 → 序号”映射

一个值的最小合法序号，正好等于“比它小的不同值个数 + 1”。因此复制数组、排序并跳过重复值，就能按顺序分配 1、2、3…；最后按照原数组顺序查表即可。

[40,10,20,30] → 排序去重 [10,20,30,40] → 映射 {10:1,20:2,30:3,40:4} → [4,1,2,3]

完整过程

1
复制并排序。

不改变原数组的遍历顺序，得到所有值的非降序排列。

2
为不同值编号。

从左到右扫描排序结果，首次遇到某值时分配下一个连续序号。

3
按原顺序查表。

将每个原值替换为映射中的序号，生成答案。

正确性证明

引理：排序去重后的第 k 个值，恰有 k−1 个不同值比它小。

序号合法：算法给它分配 k。更大的值在去重序列中位置更靠后，所以序号更大；相等值查到同一个映射，因此序号相同。

序号最小：该值前面已有 k−1 个必须拥有更小序号的不同值，故它不可能取得小于 k 的合法序号。算法取得 k，已是最小。由此每个位置的替换都正确。

复杂度

时间：O(n log n)，主要来自排序；建表和生成答案均为 O(n)。

空间：O(n)，用于排序副本、映射和输出。

边界处理

  • 空数组直接得到空数组。
  • 全部相等时，唯一值的序号为 1。
  • 负数和大整数只参与比较，不影响映射逻辑。
  • 重复值出现多次，所有位置都查到相同序号。

四种语言实现

import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] arrayRankTransform(int[] arr) {
        int[] sorted = arr.clone();
        Arrays.sort(sorted);

        Map<Integer, Integer> rank = new HashMap<>();
        for (int value : sorted) {
            rank.putIfAbsent(value, rank.size() + 1);
        }

        int[] answer = new int[arr.length];
        for (int i = 0; i < arr.length; i++) {
            answer[i] = rank.get(arr[i]);
        }
        return answer;
    }
}
/**
 * @param {number[]} arr
 * @return {number[]}

var arrayRankTransform = function(arr) {
    const sorted = [...arr].sort((a, b) => a - b);
    const rank = new Map();

    for (const value of sorted) {
        if (!rank.has(value)) {
            rank.set(value, rank.size + 1);
        }
    }

    return arr.map(value => rank.get(value));
};
from typing import List

class Solution:
    def arrayRankTransform(self, arr: List[int]) -> List[int]:
        rank = {
            value: index + 1
            for index, value in enumerate(sorted(set(arr)))
        }
        return [rank[value] for value in arr]
class Solution {
public:
    vector<int> arrayRankTransform(vector<int>& arr) {
        vector<int> sorted = arr;
        sort(sorted.begin(), sorted.end());

        unordered_map<int, int> rank;
        for (int value : sorted) {
            if (!rank.count(value)) {
                rank[value] = static_cast<int>(rank.size()) + 1;
            }
        }

        vector<int> answer;
        answer.reserve(arr.size());
        for (int value : arr) {
            answer.push_back(rank[value]);
        }
        return answer;
    }
};

替代方案

有序集合：先把所有值放入有序集合，再按升序编号。思路相同，常数与语言容器实现有关。

排序下标：排序原下标，根据相邻值是否变化推进序号并直接写答案，可省去哈希映射，但实现更容易出现重复值判断错误。

计数数组：仅当值域很小且明确受限时才合适；本题值域达到 ±109，直接计数浪费空间。

面试追问

  • 如果输入是数据流，如何动态维护序号？可讨论平衡树与顺序统计树。
  • 能否原地完成？输出可以复用原数组，但排序副本或下标信息仍需额外空间。
  • 若值域只有 0…1000，如何做到线性时间？使用出现标记或计数数组。
  • 稳定排序是否必要？不必要，因为相等值共享序号。

常见错误

按排序下标直接加一

重复值会被错误地分配不同序号。

原地排序后忘记原顺序

答案必须对应原数组的每个位置。

每次线性查找序号

会退化到 O(n²)；应使用哈希映射。

JavaScript 默认排序

必须传入 (a, b) => a - b，否则会按字符串字典序排序。
