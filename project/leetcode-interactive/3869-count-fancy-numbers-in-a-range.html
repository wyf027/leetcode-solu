LeetCode 3869 · Hard · 数位 DP

统计区间内奇妙数的数目

一个数的数位严格递增或严格递减时是“好数”；若这个数本身是好数，或它的数位和是好数，则它是“奇妙数”。区间上界达到 10¹⁵，必须按数字前缀计数，不能逐个枚举。

推荐主线

数位 DP 同时携带当前位置、数位和、前一位、单调趋势、是否已开始和 tight 标记；到叶子时再判“原数好”或“数位和好”。

关键上界

r ≤ 10¹⁵，最多 16 位，数位和最多 144。状态空间很小，适合记忆化。

题意、示例与约束

示例 1

l = 8, r = 10

8、9 是一位好数；10 的 1 → 0 严格递减，答案为 3。

示例 2

l = 12340, r = 12341

12340 本身不单调，但数位和 10 严格递减；12341 的数位和是 11，答案为 1。

示例 3

l = 123456788, r = 123456788

原数末尾重复，数位和为 44 也不严格单调，答案 0。

约束

1 ≤ l ≤ r ≤ 10¹⁵。一位数自动是好数；等号会破坏严格单调。

交互分步可视化：趋势状态机

输入一个小于等于 10¹⁵ 的正整数。逐位推进可观察数位和与趋势如何变化；这个小型演示解释 DP 的一个前缀状态，而不是枚举整个区间。

题解（默认收起）

推导、边界和可提交代码按需展开。

核心洞察：把 count(r) − count(l − 1) 化成两个“≤ 上界”的数位 DP。前缀一旦已不可能严格单调，仍要继续，因为最终数位和可能是好数。

完整过程

  1. 预处理 good(s)：将 s 的十进制各位做严格递增或严格递减检查。
  2. 从高位到低位 DFS，状态为 (pos, sum, prev, trend, started, tight)；未开始前的 0 不参与趋势。
  3. 新数位与 prev 比较，更新为“单位/递增/递减/已坏”四种趋势之一。
  4. 末尾忽略全零；否则若趋势未坏，或 good(sum)，就计入一个答案。

边界

前导零不能和真实的 0 混淆；重复数位立即使严格趋势变坏；数位和的好数判定也包含一位和，例如 100 的和为 1。

复杂度

设位数 D ≤ 16、最大和 S ≤ 144。状态约为 O(D · S · 10 · 4 · 2)，每个状态枚举 10 个数位；空间相同。

替代方案、面试追问与常见错误

替代：可单独预生成严格单调原数，再对“数位和好”的补集做 DP；但容易与前者重叠，统一 DP 更稳。追问：若上界改为字符串，可保持同一 DP；若还限制模数，则把余数加入状态。常见错误：把相等当作单调、把前导 0 放进趋势、或在趋势坏掉后过早剪枝，都会漏掉“数位和是好数”的数字。

from functools import lru_cache
class Solution:
    def countFancy(self, l: int, r: int) -> int:
        def good(x):
            s = str(x)
            return len(s) == 1 or all(s[i] > s[i-1] for i in range(1,len(s))) or all(s[i] < s[i-1] for i in range(1,len(s)))
        def count(n):
            if n <= 0: return 0
            s = str(n)
            @lru_cache(None)
            def dfs(p, total, prev, st, started, tight):
                if p == len(s): return int(started and (st != 3 or good(total)))
                ans, hi = 0, int(s[p]) if tight else 9
                for d in range(hi + 1):
                    ns, np, nt, add = started, prev, st, 0
                    if not started:
                        if d != 0: ns, np, nt, add = 1, d, 0, d
                    else:
                        add, np = d, d
                        nt = (1 if d > prev else 2 if d < prev else 3) if st == 0 else (3 if (st == 1 and d <= prev) or (st == 2 and d >= prev) else st)
                    ans += dfs(p+1, total+add, np, nt, ns, tight and d == hi)
                return ans
            return dfs(0,0,10,0,0,True)
        morvaxelin = l
        return count(r) - count(morvaxelin - 1)
