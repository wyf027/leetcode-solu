统计道路上的碰撞次数

Count Collisions on a Road

一条无限长的道路，三种车辆状态。先弄清“碰撞次数”的计分方式，再探索哪些车最终会停下来。

01 / 题目

道路上有 n 辆车，从左到右编号为 0 … n − 1，初始位置互不相同。参数 directions 是长度为 n 的字符串，记录每辆车的初始状态：

← L向左行驶R →向右行驶■ S原地静止

所有移动车辆速度相同。两辆相向行驶的车相撞，计数增加 2；移动车辆撞上静止车辆，计数增加 1。发生碰撞的车辆都停在碰撞地点，之后不再移动。除此之外，车辆不会自行改变方向或状态。

返回最终的碰撞总次数。这里计的是题目定义的数值，并非单纯的事故场次数。

  • 参数：directions: string；返回：integer。
  • 1 ≤ directions.length ≤ 100000。
  • 每个字符只能为 L、R 或 S。

02 / 官方示例

示例 1

输入：directions = "RLRSLL"
输出：5

车 0 与车 1 相向碰撞，增加 2；车 2 撞上静止的车 3，增加 1；车 4 撞上车 3，增加 1；车 5 随后撞上已停下的车 4，再增加 1。合计 5。此处列举计数关系，不要求这些独立碰撞严格按列举顺序发生。

示例 2

输入：directions = "LLRR"
输出：0

左侧两辆车向左驶离，右侧两辆车向右驶离，同向车辆保持间距，因此没有碰撞。

05 / 独立题解

准备好后再展开推导与代码。

核心洞察：每辆从移动变为静止的车，贡献 1

相向碰撞让两辆移动车停下，题目加 2；撞上静止车只让一辆移动车停下，题目加 1。所以答案等于最终因碰撞停下的、初始移动的车辆数。每辆车最多贡献一次。

只有两类移动车能一直离开道路上的其他车辆：连续的前缀 L 和 连续的后缀 R。删除这两端后，剩余字符中的每个非 S 都贡献 1。

完整过程

  1. 设 left = 0，right = n − 1。
  2. 当区间非空且左端是 L，令 left++。
  3. 当区间非空且右端是 R，令 right--。
  4. 遍历闭区间 [left, right]，遇到 L 或 R 就把答案加 1；S 不计数。

以 LLRSLRR 为例，左端略过索引 0、1 的 L，右端略过索引 6、5 的 R，保留 RSL。按索引 2、3、4 扫描，计数依次为 1、1、2。

正确性证明

计数等价。题目每次增加的数值恰好等于本次第一次停止运动的车辆数，而停下的车辆不会恢复运动，因此统计这些车辆不会漏计或重复计数。

两侧车辆不会碰撞。前缀 L 的左侧只有相同速度的 L，它们间距不变且一直向左远离其余车辆。后缀 R 对称成立。

中间移动车必碰撞。对保留区间中的任意 R，考察从它开始的连续 R 段。该段不可能延伸到原串末尾，否则已被作为后缀删除。因此段后紧接 S 或 L：最右侧 R 会撞上静止车或迎面来车，产生静止障碍，其余 R 会依次撞上障碍。对任意 L，考察以它结尾的连续 L 段；该段前方必有 S 或 R，最左侧 L 先发生碰撞，其余 L 依次停下。故保留区间中所有移动车都贡献 1，静止车贡献 0，算法正确。

边界与复杂度

  • 全 L、全 R 或形如 LLRR：区间会变空，结果为 0。
  • 全 S 或只有一辆车：结果为 0。
  • 保留中间的 S：它们是障碍，不能在确定边界前直接删除。
  • 时间 O(n)，额外空间 O(1)。下面代码不创建子串；演示为支持回退保存快照，不代表提交算法的空间开销。

四语言完整提交代码

采用官方函数签名，均为待补验证的实现。

Java

class Solution {
    public int countCollisions(String directions) {
        int left = 0, right = directions.length() - 1;
        while (left <= right && directions.charAt(left) == 'L') left++;
        while (left <= right && directions.charAt(right) == 'R') right--;
        int answer = 0;
        for (int i = left; i <= right; i++) {
            if (directions.charAt(i) != 'S') answer++;
        }
        return answer;
    }
}

class Solution:
    def countCollisions(self, directions: str) -> int:
        left, right = 0, len(directions) - 1
        while left <= right and directions[left] == 'L':
            left += 1
        while left <= right and directions[right] == 'R':

                answer += 1
        return answer

C++

#include <string>
using namespace std;

class Solution {
public:
    int countCollisions(string directions) {
        int left = 0, right = static_cast<int>(directions.size()) - 1;
        while (left <= right && directions[left] == 'L') ++left;
        while (left <= right && directions[right] == 'R') --right;
        int answer = 0;
        for (int i = left; i <= right; ++i) {
            if (directions[i] != 'S') ++answer;
        }
        return answer;
    }
};

替代方案：一次从左到右扫描

维护待处理的右行车数量 pendingR 和左侧是否形成静止障碍。遇到 R 就累加；遇到 S 时结算全部 pendingR 并清零；遇到 L 时，若 pendingR > 0，结算 pendingR + 1 并建立障碍，否则仅在左侧有静止障碍时加 1。末尾未结算的 R 驶离。时间 O(n)、空间 O(1)，但分支更多。显式栈也能模拟，额外空间为 O(n)。

常见错误

  • 把一次迎面相撞只算 1：题目规定加 2。
  • 只统计相邻的 RL 或 RS：会漏掉 R 链和 L 链的后续碰撞。
  • 删除所有 L 和 R：只有连续前缀 L、连续后缀 R 可以排除。
  • 把剩余区间长度当答案：必须排除初始 S。
  • 直接求 right − left + 1 且不防空区间，或数组访问前不检查边界。

面试追问

为什么不需要具体坐标？所有移动车速度相同，先后顺序和方向足以决定谁最终被挡住；坐标只改变碰撞时间。

如果车辆速度不同呢？同向车辆可能追尾，前后缀规则失效，需要位置和速度信息，通常改用事件模拟。

能否流式处理？可以，用上述 pendingR 与静止障碍状态，一次扫描即可；输入结束时忽略未碰撞的 pendingR。

如果要输出真实碰撞时间或事故场次数？现有计数等价关系不够，且题目没有给出坐标，不能从 directions 唯一恢复这些信息。
