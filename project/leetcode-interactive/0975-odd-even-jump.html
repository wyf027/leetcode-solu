奇偶跳 Odd Even Jump

每一次跳跃都由“最接近当前值的合法目标”唯一确定。真正的难点，是高效找出两类下一跳，并从右向左回答哪些起点最终能到达终点。

HARD数组动态规划排序单调栈有序集合

题目

给定整数数组 arr，从索引 i 只能向更大的索引跳。第 1、3、5… 次是奇数跳：选择值不小于 arr[i] 的目标中数值最小者；若并列，取索引最小者。

第 2、4、6… 次是偶数跳：选择值不大于 arr[i] 的目标中数值最大者；若并列，同样取索引最小者。没有合法目标时停止。

若从某个起点经过零次或多次跳跃能到达最后一个索引，则它是好起点。返回好起点数量。

函数形式

oddEvenJumps(arr: integer[]) -> integer

约束与边界

  • 1 ≤ arr.length ≤ 20,000
  • 0 ≤ arr[i] < 100,000
  • 跳跃编号决定奇偶，并非数组索引。
  • 最后一个索引无需跳跃，本身一定是好起点。
  • 重复值必须按最小目标索引打破平局。

官方示例

输入：arr = [10,13,12,14,15] 输出：2

好起点是 3、4。

输入：arr = [2,3,1,1,4] 输出：3

好起点是 1、3、4；重复值 1 时优先索引 2。

输入：arr = [5,1,3,4,2] 输出：3

好起点是 1、2、4。

Solution · reveal on demand

题解：排序 + 单调栈 + 反向 DP

核心洞察

把问题拆成两层：先为每个索引预计算奇数跳目标 higher[i] 与偶数跳目标 lower[i]；再从右向左做两种状态的动态规划。

若把索引按 (arr[i], i) 升序排列，用单调递增索引栈扫描，弹栈时得到的当前索引，就是被弹索引的奇数跳目标。按 (-arr[i], i) 排列重复一次，便得到偶数跳目标。二元排序中的索引升序恰好落实了平局规则。

完整过程

  1. 排序索引：值升序、索引升序；用单调栈生成 higher。
  2. 再按值降序、索引升序排序；同样生成 lower。
  3. 定义 odd[i]：从 i 开始、下一跳为奇数跳时能否到终点；even[i] 同理。
  4. 终点两种状态都为真。从右向左：odd[i] = even[higher[i]]，even[i] = odd[lower[i]]。
  5. 统计所有 odd[i] 为真的索引。

正确性说明

下一跳正确：升序排列确保候选值最小，等值时索引升序确保目标索引最小。单调栈只在遇到更靠右的索引时建立边，因此目标满足 j > i，第一次弹出对应排序次序下的最优合法目标。降序版本对偶地得到偶数跳目标。

DP 正确：每次跳跃后奇偶性交替，所以从 i 的奇数状态成功，当且仅当其唯一奇数目标的偶数状态成功；偶数状态同理。所有边都向右，从终点向左计算时依赖已知。由反向归纳，全部状态正确，统计 odd 即为答案。

边界与复杂度

单元素答案为 1；没有下一跳时对应状态保持假；重复值依赖排序的索引次序。两次排序耗时 O(n log n)，单调栈与 DP 为 O(n)；空间 O(n)。

替代方案

也可从右向左维护有序映射：奇数跳查 ceiling key，偶数跳查 floor key，再用最新（也就是最小的右侧）索引覆盖相同值。Java 的 TreeMap 很自然；但四语言统一实现时，排序 + 单调栈更直接。

面试追问

  • 为什么等值时排序必须保持索引升序？
  • 若平局改取最大索引，排序和栈逻辑如何变化？
  • 能否在线处理数组追加？哪些预计算会失效？
  • 如何从布尔 DP 恢复某个好起点的完整路径？

常见错误

  • 把索引奇偶误当作跳跃次数奇偶。
  • 只比较值而忽略重复值下的最小索引规则。
  • 把 odd[i] 转移到 odd[next]，忘记状态必须交替。
  • 漏计无需跳跃就到达终点的最后一个索引。

完整代码

class Solution {
    public int oddEvenJumps(int[] arr) {
        int n = arr.length;
        int[] higher = next(arr, true), lower = next(arr, false);
        boolean[] odd = new boolean[n], even = new boolean[n];
        odd[n - 1] = even[n - 1] = true;
        int answer = 1;
        for (int i = n - 2; i >= 0; --i) {
            if (higher[i] != -1) odd[i] = even[higher[i]];
            if (lower[i] != -1) even[i] = odd[lower[i]];
            if (odd[i]) ++answer;
        }
        return answer;
    }

    private int[] next(int[] arr, boolean ascending) {
        Integer[] order = new Integer[arr.length];
        for (int i = 0; i < arr.length; ++i) order[i] = i;
        java.util.Arrays.sort(order, (a, b) -> {
            int byValue = Integer.compare(arr[a], arr[b]);
            if (!ascending) byValue = -byValue;
            return byValue != 0 ? byValue : Integer.compare(a, b);
        });
        int[] result = new int[arr.length];
        java.util.Arrays.fill(result, -1);
        int[] stack = new int[arr.length];
        int top = 0;
        for (int index : order) {
            while (top > 0 && stack[top - 1] < index) result[stack[--top]] = index;
            stack[top++] = index;
        }
        return result;
    }
}

var oddEvenJumps = function(arr) {
    const n = arr.length;
    const build = ascending => {
        const order = Array.from({length: n}, (_, i) => i).sort((a, b) =>
            (ascending ? arr[a] - arr[b] : arr[b] - arr[a]) || a - b);
        const next = Array(n).fill(-1), stack = [];
        for (const index of order) {
            while (stack.length && stack[stack.length - 1] < index) next[stack.pop()] = index;
            stack.push(index);
        }
        return next;
    };
    const higher = build(true), lower = build(false);
    const odd = Array(n).fill(false), even = Array(n).fill(false);
    odd[n - 1] = even[n - 1] = true;

class Solution:
    def oddEvenJumps(self, arr: List[int]) -> int:
        n = len(arr)

        def build(order):
            nxt = [-1] * n
            stack = []
            for index in order:
                while stack and stack[-1] < index:
                    nxt[stack.pop()] = index
                stack.append(index)
            return nxt

        higher = build(sorted(range(n), key=lambda i: (arr[i], i)))
        lower = build(sorted(range(n), key=lambda i: (-arr[i], i)))
        odd, even = [False] * n, [False] * n

class Solution {
public:
    int oddEvenJumps(vector<int>& arr) {
        int n = arr.size();
        auto build = [&](bool ascending) {
            vector<int> order(n), nxt(n, -1), stack;
            iota(order.begin(), order.end(), 0);
            sort(order.begin(), order.end(), [&](int a, int b) {
                if (arr[a] != arr[b]) return ascending ? arr[a] < arr[b] : arr[a] > arr[b];
                return a < b;
            });
            for (int index : order) {
                while (!stack.empty() && stack.back() < index) {
                    nxt[stack.back()] = index;
                    stack.pop_back();
                }
                stack.push_back(index);
            }
            return nxt;
        };
        vector<int> higher = build(true), lower = build(false);
        vector<char> odd(n), even(n);
        odd[n - 1] = even[n - 1] = 1;
        int answer = 1;
        for (int i = n - 2; i >= 0; --i) {
            if (higher[i] != -1) odd[i] = even[higher[i]];
            if (lower[i] != -1) even[i] = odd[lower[i]];
            answer += odd[i];
        }
        return answer;
    }
};
