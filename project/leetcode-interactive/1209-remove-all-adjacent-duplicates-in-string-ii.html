删除字符串中的所有相邻重复项 II

一串字符不断坍缩：每次移除恰好 k 个相邻且相同的字母，直到再也没有可消除的分组。

Remove All Adjacent Duplicates in String II删除会让原本分隔的左右片段重新相邻，因此一次操作可能触发下一次连锁消除。最终答案保证唯一。
01 / Problem

题目说明

给定字符串 s 和整数 k。一次操作可以选择 k 个连续、相等的字母并删除；被删除部分左右两侧会连接。重复操作直至无法继续，返回最后的字符串。

函数签名

removeDuplicates(s, k) → string

参数 s 是仅含小写英文字母的字符串，k 是每次触发删除的连续重复次数。

约束

  • 1 ≤ s.length ≤ 10⁵
  • 2 ≤ k ≤ 10⁴
  • s 只包含小写英文字母
示例 01
输入：s = "abcd", k = 2 输出："abcd"

没有满足条件的相邻重复项。

示例 02
输入：s = "deeedbbcccbdaa", k = 3 输出："aa"

依次消除 eee / ccc、bbb、ddd，最后留下 aa。

示例 03
输入：s = "pbbcggttciiippooaais", k = 2 输出："ps"

多个二连字符消失后继续产生新的相邻关系。

分组栈：只记字符与连续次数

核心洞察

从左到右处理字符。尚未被删除的结果中，真正影响下一个字符的只有末尾连续分组。因此用栈保存二元组 [字符, 次数]：新字符与栈顶相同就累加，否则新建分组；次数达到 k 时立即弹出该组。

k

弹出后，左侧旧栈顶会自然成为新的尾部。之后读入的字符可继续与它合并，所以连锁反应无需回头扫描，也无需特殊处理。

完整过程

  1. 创建空栈，每个元素记录 [char, count]。
  2. 依次读取 s 中的字符 ch。
  3. 若栈顶字符等于 ch，把栈顶计数加一；否则压入 [ch, 1]。
  4. 若栈顶计数等于 k，立刻弹出整个分组。
  5. 扫描结束后，将每个分组的字符重复对应次数并拼接，即为答案。

正确性证明

循环不变式

处理完前 i 个字符后，栈展开得到的字符串，恰好是该前缀执行所有可行的 k 倍删除后的最终结果；并且栈中每组计数都小于 k。

初始化

处理零个字符时栈为空，与空前缀的最终结果一致。

保持

加入新字符时，只有当前结果末尾的分组可能与它组成新的连续重复项。算法恰好合并同字符栈顶或创建新分组；若计数达到 k 就删除它。其余分组不受影响，因此不变式继续成立。

终止

扫描完整个字符串后，不变式说明栈的展开结果就是对整个 s 完成所有删除后的结果，且不存在长度达到 k 的分组。

边界与复杂度

时间复杂度O(n)每个字符入组一次，分组至多弹出一次。
空间复杂度O(n)最坏情况下每个字符各自成为一组。

边界情况

  • 没有任何分组达到 k：原字符串保持不变。
  • 整个字符串恰好被消除：返回空字符串。
  • k = 2：每对相邻相同字符都会触发删除。
  • 删除后跨边界合并：弹栈会自动暴露之前的尾部分组。
  • k 大于任一连续段长度：不会发生删除。

四语言完整代码

class Solution {
    public String removeDuplicates(String s, int k) {
        StringBuilder chars = new StringBuilder();
        int[] counts = new int[s.length()];

        for (char ch : s.toCharArray()) {
            chars.append(ch);
            int i = chars.length() - 1;
            counts[i] = i > 0 && chars.charAt(i - 1) == ch
                    ? counts[i - 1] + 1 : 1;
            if (counts[i] == k) {
                chars.delete(chars.length() - k, chars.length());
            }
        }
        return chars.toString();
    }
}
/** @param {string} s @param {number} k @return {string} */
var removeDuplicates = function(s, k) {
    const stack = [];

    for (const ch of s) {
        const top = stack[stack.length - 1];
        if (top && top[0] === ch) {
            top[1]++;
        } else {
            stack.push([ch, 1]);
        }

        if (stack[stack.length - 1][1] === k) {
            stack.pop();
        }
    }

    return stack.map(([ch, count]) => ch.repeat(count)).join('');
};
class Solution:
    def removeDuplicates(self, s: str, k: int) -> str:
        stack = []  # [character, count]

        for ch in s:
            if stack and stack[-1][0] == ch:
                stack[-1][1] += 1
            else:
                stack.append([ch, 1])

            if stack[-1][1] == k:
                stack.pop()

        return ''.join(ch * count for ch, count in stack)
class Solution {
public:
    string removeDuplicates(string s, int k) {
        vector<pair<char, int>> stack;

        for (char ch : s) {
            if (!stack.empty() && stack.back().first == ch) {
                ++stack.back().second;
            } else {
                stack.push_back({ch, 1});
            }

            if (stack.back().second == k) {
                stack.pop_back();
            }
        }

        string answer;
        for (const auto& [ch, count] : stack) {
            answer.append(count, ch);
        }
        return answer;
    }
};

替代方案与取舍

直接维护字符栈 + 位置计数

可以让字符逐个进入 StringBuilder 或数组，并为每个位置记录以该位置结尾的连续长度；达到 k 后删除末尾 k 个字符。Java 代码展示的就是这一变体，同样为线性复杂度，但概念上比分组栈多存一些位置。

反复查找并删除

每轮扫描完整字符串，发现长度为 k 的分组就删除并重新拼接。思路直观，但字符串复制和重复扫描可能退化到 O(n²)；在 10⁵ 的规模下不合适。

面试追问

  • 为什么删到 k 就立刻弹出？ 更长的相同段在题意下会在形成第 k 个字符时先被删除，不会保留到 k+1。
  • 如果每种字符有不同阈值？ 将固定的 k 改成按字符查询阈值，栈结构不变。
  • 如果输入是字符流？ 扫描阶段天然支持流式处理；只有最终输出需要保留未消除的栈内容。
  • 答案为什么与删除顺序无关？ 题目保证唯一；分组栈构造出按前缀完全归约的标准结果。

常见错误

  • 只做一轮删除，遗漏删除后形成的新相邻分组。
  • 栈顶计数达到 k 后清零却不弹出分组，破坏新的边界关系。
  • 最终只拼接字符而忘记按计数重复。
  • 使用频繁的字符串切片与拼接，导致二次复杂度。
  • 把“至少 k 个”误写成保留对 k 取模之前的整段；应在扫描过程中每到 k 个就消除。
