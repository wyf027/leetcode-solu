平均等待时间Average Waiting Time

一位厨师、一列按到达时间排序的顾客。读懂“到达、开工、完成、等待”之间的关系，再用交互时间线观察每份订单。

中等数组模拟非付费题
01 · Problem

题目描述

餐厅只有一位厨师。给定数组 customers，其中 customers[i] = [arrivalᵢ, timeᵢ]：

  • arrivalᵢ 是第 i 位顾客的到达时刻，所有到达时刻按非递减顺序排列；
  • timeᵢ 是完成这位顾客订单所需的制作时间。

顾客到达后提交订单。厨师空闲时立即开始下一份订单；同一时刻只能制作一份，并严格按输入顺序处理。顾客从到达起一直等到自己的订单完成。

返回所有顾客等待时间的平均值。答案与真实值的误差不超过 10⁻⁵ 即可。

约束

  • 1 <= customers.length <= 10⁵
  • 1 <= arrivalᵢ, timeᵢ <= 10⁴
  • arrivalᵢ <= arrivalᵢ₊₁

函数参数：customers: integer[][]
返回值：double

Example 01

连续排队

输入：customers = [[1,2],[2,5],[4,3]]
输出：5.00000

三位顾客分别在时刻 3、8、11 完成，等待时间是 2、6、7；平均值为 (2 + 6 + 7) / 3 = 5。

Example 02

包含空闲时段

输入：customers = [[5,2],[5,4],[10,3],[20,1]]
输出：3.25000

四位顾客的等待时间是 2、6、4、1。厨师在时刻 14 到 20 之间空闲，平均值为 13 / 4 = 3.25。

Solution · Simulation

一次扫描，维护厨师的时钟

核心洞察

处理当前顾客时，订单只能在“顾客到达”和“厨师空闲”两者中更晚的时刻开始。算出完成时刻后，用“完成时刻 − 到达时刻”累加这位顾客的完整等待时间。

finish = max(finish, arrival) + time
totalWait += finish - arrival

完整过程

  1. 令 finish = 0 表示厨师完成此前订单的时刻，totalWait = 0。
  2. 按输入顺序读取 [arrival, time]。
  3. 若厨师已空闲，就从 arrival 开始；否则从旧的 finish 开始。
  4. 更新完成时刻，并把 finish - arrival 加入总等待。
  5. 返回 totalWait / customers.length。

边界与数值

  • 只有一位顾客：等待时间就是制作时间。
  • 两单之间有空档：必须把厨师时钟推进到新顾客的到达时刻。
  • 多人同时到达：仍按数组顺序处理。
  • 最大累计量级可超过 32 位有符号整数的安全边缘；Java 使用 long，C++ 使用 long long。
  • 最后再做浮点除法，避免整数截断。

正确性证明

1
不变式。 每轮开始前，finish 恰好等于上一位已处理顾客订单的完成时刻，totalWait 恰好是所有已处理顾客等待时间之和。
2
保持。 当前订单不能早于顾客到达，也不能早于厨师完成前单，因此最早且实际的开工时刻是 max(finish, arrival)。加上制作时间得到真实完成时刻；完成时刻减到达时刻正是该顾客的等待时间。更新后二者继续满足不变式。
3
终止。 循环结束时所有顾客均已处理，所以 totalWait 是全部等待时间之和。除以顾客数得到题目要求的平均等待时间。

复杂度

时间：O(n)，每位顾客只访问一次。

额外空间：O(1)，只维护完成时刻和累计和。

替代方案

可以显式维护等待队列并逐单出队，也能得到正确答案，但输入本身已经按到达时刻排序，且厨师严格按输入顺序处理。队列不会提供额外信息，只会把额外空间提高到 O(n)。一次扫描更直接。

四语言完整代码

使用左右方向键可在代码标签间切换。代码容器可独立横向与纵向滚动。

class Solution {
    public double averageWaitingTime(int[][] customers) {
        long finish = 0;
        long totalWait = 0;

        for (int[] customer : customers) {
            int arrival = customer[0];
            int time = customer[1];
            finish = Math.max(finish, arrival) + time;
            totalWait += finish - arrival;
        }

        return (double) totalWait / customers.length;
    }
}

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    double averageWaitingTime(vector<vector<int>>& customers) {
        long long finish = 0;
        long long totalWait = 0;

        for (const auto& customer : customers) {
            const int arrival = customer[0];
            const int time = customer[1];
            finish = max(finish, static_cast<long long>(arrival)) + time;
            totalWait += finish - arrival;
        }

        return static_cast<double>(totalWait) / customers.size();
    }
};

常见错误

  • 把等待时间只算成开工减到达，漏掉制作时间。
  • 直接写 finish += time，忽略厨师空闲时应跳到新到达时刻。
  • 先除后加，造成整数除法或累计舍入误差。
  • 误以为需要按到达时刻重新排序；题目已保证非递减，且相同到达时刻仍遵循输入顺序。
