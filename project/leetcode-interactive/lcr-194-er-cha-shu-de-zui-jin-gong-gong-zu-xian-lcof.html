LCR 194 · Tree · DFS

二叉树的最近公共祖先

给定普通二叉树与节点 p、q，找深度最大的共同祖先；节点可以是自己的祖先。

题意回声室验证题解

Problem / 题意

递归返回的不是答案，就是一段待合流的回声

官方样例

root=[3,5,1,6,2,0,8,null,null,7,4]，p=5,q=1，输出 3。节点值唯一，两个节点不同且均存在。

示例 2：p=5,q=4 输出 5，因为节点可以是自己的祖先。

判断点

若左右子树各返回一个非空节点，当前根正好是首次汇合处；否则将唯一的非空结果继续上交。

Recursive Echo Chamber / 祖先回声室

后序回溯可视化：两条信号在哪里首次相遇？

准备让两条回声从目标节点返回。

粉色：目标；金色：已确认的 LCA。键盘可直接用 Enter 或 Space 触发按钮。

Solution / 题解

先思考，题解默认隐藏

Core Insight / 核心洞察

终止：空节点或命中 p/q 时直接返回。归并：左右回声都存在则返回根，否则返回非空一侧。

Full Process / 完整过程

  1. 递归左、右子树。
  2. 左右均非空，当前节点是 LCA。
  3. 只有一侧非空，说明两个目标都在该侧或该侧已得到答案。

Boundary / 边界

目标可能是另一个目标的祖先；命中目标必须立即返回。题目已保证目标都存在。

Complexity / 复杂度

时间 O(n)，递归栈 O(h)，链状树最坏 O(n)。

Alternatives / 替代方案

建立父指针并标记 p 的祖先，空间 O(n)，适合做参考对拍。

Interview Follow-ups / 面试追问

若节点不保证存在，返回值还需携带命中数，只有两个目标均命中才接受 LCA。

Common Mistakes / 常见错误

  • 错误使用 BST 的大小关系。
  • 左右都有结果时仍返回左或右。
  • 遗漏“目标就是祖先”。
  • 用值比较代替节点引用。

class Solution { TreeNode lowestCommonAncestor(TreeNode r, TreeNode p, TreeNode q) { if(r==null||r==p||r==q)return r; TreeNode l=lowestCommonAncestor(r.left,p,q), x=lowestCommonAncestor(r.right,p,q); return l!=null&&x!=null?r:l!=null?l:x; } }

class Solution:
 def lowestCommonAncestor(self,r,p,q):
  if not r or r is p or r is q: return r
  l=self.lowestCommonAncestor(r.left,p,q); x=self.lowestCommonAncestor(r.right,p,q)
  return r if l and x else l or x
