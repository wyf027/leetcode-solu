01

题目陈述

每移动一格，记作一次操作。

有 n 个盒子，二进制字符串 boxes 描述它们的初始状态：boxes[i] = '1' 表示第 i 个盒子里有一颗球，'0' 表示为空。

一次操作可以把一颗球从当前盒子移到相邻盒子，即从位置 i 移到满足 |i-j|=1 的位置 j。移动后，同一盒子可以容纳多颗球。

返回长度为 n 的数组 answer，其中 answer[i] 是把所有球移到第 i 个盒子所需的最少操作数。每个 answer[i] 都以原始 boxes 为起点独立计算。

函数签名

minOperations(boxes: string) → integer[]

关键语义

从位置 j 搬一颗球到位置 i，最少需要 |i-j| 步；不同小球的代价可以相加。

官方示例与约束

完整保留输入参数形式。

示例 1

输入：boxes = "110"
输出：[1,1,3]
解释：
目标 0：位置 1 的球左移 1 步。
目标 1：位置 0 的球右移 1 步。
目标 2：两颗球分别移动 2、1 步，共 3 步。

示例 2

输入：boxes = "001011"
输出：[11,8,5,4,3,4]

约束

  • n == boxes.length
  • 1 <= n <= 2000
  • boxes[i] 只能是 '0' 或 '1'

04

核心洞察

相邻目标之间的答案可以增量更新。

设从左向右走到位置 i 时，左侧（含当前位置）已有 leftBalls 颗球，之前把这些球推进到上一位置累计需要 leftMoves 步。目标右移一格后，每颗已见小球都要多走一步，所以：

leftMoves += leftBalls

从右向左做完全对称的一遍，把右侧小球的贡献加进答案。两次线性扫描就能得到每个目标位置的全部距离和。

完整过程

  1. 初始化
    答案数组全为 0，左侧球数与左侧代价均为 0。
  2. 从左向右
    在位置 i 先把当前左侧代价加到 answer[i]，再根据 boxes[i] 更新球数，最后让代价增加球数。
  3. 从右向左
    清零计数器，对称执行；本轮贡献继续累加到同一答案数组。
  4. 返回答案
    此时每个位置都包含其左、右两侧所有球的距离和。

正确性证明

左扫不变式：处理位置 i 前，moves 等于所有位于 [0,i-1] 的球移动到 i 的距离和。初始 i=0 时为空和，成立。处理完位置 i 后，目标向右移动一格，已见的每颗球距离均增加 1，因此执行 moves += balls 后，不变式对下一位置仍成立。

右扫由对称论证可得，计算所有位于当前位置右侧球的距离和。两部分覆盖全部球且互不遗漏；当前位置的球贡献为 0。因此相加正好是所有球到目标位置的最少操作数。

复杂度、边界与替代方案

复杂度

  • 时间：O(n)，两次线性扫描。
  • 额外空间：O(1)（不计必须返回的答案数组）。

边界

  • 只有一个盒子：答案必为 [0]。
  • 没有球：所有答案均为 0。
  • 球全在一端或每格都有球：递推仍无需特殊分支。

替代方案

直接枚举每个目标盒子，再遍历每颗球累加 |i-j|，容易理解但需要 O(n²) 时间。也可以显式维护前缀球数、前缀位置和与对应后缀数组，仍是 O(n)，但需要更多空间。

常见错误

  • 把前一个目标的移动结果当成下一目标的新初始状态。
  • 更新球数和记录当前代价的顺序写反。
  • 右扫覆盖答案，而不是累加贡献。

class Solution {
    public int[] minOperations(String boxes) {
        int n = boxes.length();
        int[] answer = new int[n];
        int balls = 0, moves = 0;

        for (int i = 0; i < n; i++) {
            answer[i] += moves;
            balls += boxes.charAt(i) - '0';
            moves += balls;
        }

        balls = 0;
        moves = 0;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] += moves;
            balls += boxes.charAt(i) - '0';
            moves += balls;
        }
        return answer;
    }
}

        n = len(boxes)

            balls += int(boxes[i])
            moves += balls

        balls = moves = 0
        for i in range(n - 1, -1, -1):

answer[i+1] = answer[i] + leftBalls - rightBalls
