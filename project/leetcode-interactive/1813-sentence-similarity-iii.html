Sentence Similarity III

一次插入，能让两句话相遇吗？先理解操作边界，再打开交互观察；完整题解在底部按需展开。

01 / 问题

给定两个字符串 sentence1、sentence2，每个句子由英语单词组成，单词间恰好一个空格，没有首尾空格。

你可以在其中一个句子的一个位置，插入一段连续的句子（允许为空），使它等于另一个句子。插入可以发生在句首、句尾或两个单词之间，不能拆开单词。可以做到则返回 true，否则返回 false。比较区分大小写。

Hello Jane 可以插入 my name is；Frog cool 不能靠拆开 Frog 变成 Frogs are cool。

约束

  • 1 ≤ sentence1.length, sentence2.length ≤ 100，长度按字符计。
  • 仅包含大小写英文字母与空格。
  • 单词由单个空格分隔，无首尾空格。

05 / 题解与实现

核心洞察：短句必须被两端覆盖

设短句数组 A 有 m 个词，长句 B 有 n 个词。一次插入只能留下一个连续的额外区间。因此 A 必须是 B 的一个前缀与一个后缀的拼接，而不只是它的子序列。

完整过程

  1. 按空格分词，按词数交换，使 m ≤ n。
  2. 从左扫描相同单词，得到公共前缀长度 p。
  3. 从右扫描相同单词，得到后缀长度 s，限制 s < m − p，避免重复覆盖。
  4. 若 p + s = m，返回 true；需要插入的是 B[p:n−s]（左闭右开）。否则返回 false。

示例 1：A=[My, Haley]，B=[My, name, is, Haley]。左端匹配 My 得 p=1，右端匹配 Haley 得 s=1，短句全部覆盖，插入 name is 即可。

正确性证明

充分性：若 p+s=m，短句的前 p 个词与长句前缀相同，剩余 s 个词与长句后缀相同。在短句索引 p 处插入 B[p:n−s]，两句就完全一致。

必要性：若合法插入发生在短句第 k 个词之后，前 k 个词必为公共前缀，后 m−k 个词必为公共后缀。最大公共前缀 p≥k，剩下的 m−p 个词仍属于该公共后缀，右端扫描一定能覆盖这些词。因此必有 p+s=m。

边界与常见错误

  • 两句相等：p=m，插入空句子即可。
  • 句首插入由后缀覆盖，句尾插入由前缀覆盖。
  • 同词数但内容不同，无法靠插入修复。
  • 重复词也适用；后缀不能越过前缀已匹配区。
  • 必须按词比较，Frog 与 Frogs 不相等，A 与 a 也不相等。
  • 不能只查子序列：a b 与 a x b y 需要两处插入。
  • 按词数判断长短，不要按字符长度交换。

复杂度

设两句总字符数为 L，分词与词比较总时间 O(L)，分词存储空间 O(L)。扫描指针额外空间为 O(1)。

替代方案

枚举短句的每个插入点，再检查两侧，最坏 O(mL) 时间，存在重复比较。也可直接移动原字符串的单词边界来节省分词存储，但实现更容易出错。

面试追问

  • 如何返回插入内容？输出 B[p:n−s] 与插入位置 p。
  • 允许任意多次插入？改为判断单词子序列。
  • 至多两段插入？考虑记录跳过区间数量的动态规划。

Java

class Solution {
    public boolean areSentencesSimilar(String sentence1, String sentence2) {
        String[] a = sentence1.split(" "), b = sentence2.split(" ");
        if (a.length > b.length) { String[] t = a; a = b; b = t; }
        int m = a.length, n = b.length, p = 0, s = 0;
        while (p < m && a[p].equals(b[p])) p++;
        while (s < m - p && a[m-1-s].equals(b[n-1-s])) s++;
        return p + s == m;
    }
}

var areSentencesSimilar = function(sentence1, sentence2) {
    let a = sentence1.split(" "), b = sentence2.split(" ");
    if (a.length > b.length) [a, b] = [b, a];
    const m = a.length, n = b.length;
    let p = 0, s = 0;
    while (p < m && a[p] === b[p]) p++;
    while (s < m-p && a[m-1-s] === b[n-1-s]) s++;
    return p + s === m;
};

C++

#include <string>
#include <vector>
#include <sstream>
#include <utility>
using namespace std;
class Solution {
public:
    bool areSentencesSimilar(string sentence1, string sentence2) {
        vector<string> a, b;
        string word;
        istringstream x(sentence1), y(sentence2);
        while (x >> word) a.push_back(word);
        while (y >> word) b.push_back(word);
        if (a.size() > b.size()) swap(a, b);
        int m = a.size(), n = b.size(), p = 0, s = 0;
        while (p < m && a[p] == b[p]) ++p;
        while (s < m-p && a[m-1-s] == b[n-1-s]) ++s;
        return p + s == m;
    }
};
