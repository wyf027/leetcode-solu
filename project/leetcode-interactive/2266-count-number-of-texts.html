统计打字方案数

一串按键，可能藏着几条不同的信息？

老式手机用重复按键选字母。现在字母之间的停顿丢失了，只剩数字串。你的任务是数出它可能对应的所有文字信息。

01 / 题目与规则

输入字符串 pressedKeys。要输入某个字母，需要连续按它所在的键，次数等于它在该键上的位置。例如 7777 → s，55 → k；信息 bob 对应 2266622。

接收方只看到了所有按键连成的字符串。返回可能的原始文字信息数量，对 1,000,000,007 取余。数字 0 和 1 不参与输入。

约束

  • 1 ≤ pressedKeys.length ≤ 100000
  • pressedKeys 只包含字符 '2' 到 '9'。

05 / 独立题解

准备好后，再展开推导与可提交代码。

核心洞察：固定最后一个字母

每个字母对应一段连续相同的数字，长度为 1–3；数字 7 和 9 允许长度 1–4。不同数字不能合并为一个字母。因此，一条文字信息唯一对应一种合法分段。

令 dp[i] 为前 i 个按键的解释数量，dp[0] = 1 表示空前缀只有一种分法。枚举末尾段长度 k，只要末尾 k 个数字相同且长度不超过按键容量，就加入 dp[i-k]。

dp[i] = Σ dp[i − k] (mod 1,000,000,007)
1 ≤ k ≤ limit，且 pressedKeys[i−k … i−1] 全部相同

完整过程

  1. 创建长度 n+1 的数组，初始化 dp[0]=1，其余为 0。
  2. 从左往右计算 i=1 到 n。根据第 i 个字符确定容量：7/9 为 4，其余为 3。
  3. 枚举 k=1 到容量。超出前缀，或新加入的字符与末尾不同，就停止。此前字符已经逐个检查过，因此可保证整个末尾段相同。
  4. 把 dp[i−k] 加入 dp[i]，每次加法后取模。最终返回 dp[n]。

例如 22233：dp 从 [1] 依次变为 [1,1,2,4,4,8]。处理第一个 3 时只能取一个 3；处理第二个 3 时，末段可为 3 或 33，得到 4+4=8。

正确性

用前缀长度归纳。空前缀初始化正确。假设所有更短前缀的计数正确，任何长度为 i 的合法解释都有唯一的最后一个字母，其耗键数 k 一定在枚举范围内，去掉后留下一个前 i−k 个按键的合法解释。反过来，给每个这样的前缀解释追加该字母，恰好得到一个合法解释。不同 k 对应的最后字母不同；相同 k 下的不同前缀也不会重复。因此枚举完整且互斥，求和正确。逐次取模保留最终余数。

边界与数值

  • 单字符结果为 1；空字符串不在输入范围内，dp[0] 只是递推基底。
  • 遇到数字变化立即停止向后扩段；不能把 23 当成一个字母。
  • 连续 2222 不能整体解释成一个字母，7777 可以。
  • Java 使用 long、C++ 使用 long long 保存计数。JavaScript 每次取模，相加始终小于 2×MOD，整数运算在 Number 安全范围内。

复杂度

每个位置最多检查 4 个末尾长度：时间 O(n)，空间 O(n)。四份代码均使用前缀数组，方便对应演示。

替代方案

按连续相同数字拆成若干段。长度为 m 的段可用三项或四项递推算分法，各段答案相乘取模。它也是 O(n) 时间；滚动保存递推最近 4 项可把额外空间降到 O(1)。前缀方案也可用长度 5 的环形数组复用状态。递归记忆化思路相同，但 n=10⁵ 时有调用栈风险。

常见错误

  • 所有按键都只允许 3 次，漏掉 s 和 z。
  • 只检查末尾两位，未确认整段同键。
  • dp[0] 初始化为 0，导致所有答案为 0。
  • 只统计连续段长度却直接相加；独立段之间应该相乘。
  • 最后才取模，累计值可能溢出。

面试追问

如何在线接收按键？ 保存最近 4 个计数与连续同键长度即可逐个更新。
如何返回一种原文？ 每个数字单独映射到按键第一个字母，总是可行。
若各键容量不同？ 用容量映射替换 3/4 判断。
为什么不枚举所有文字？ 结果数量可能指数增长，计数无需构造每条信息。

Java

class Solution {
    public int countTexts(String pressedKeys) {
        final long MOD = 1_000_000_007L;
        int n = pressedKeys.length();
        long[] dp = new long[n + 1];
        dp[0] = 1;
        for (int i = 1; i <= n; i++) {
            char c = pressedKeys.charAt(i - 1);
            int limit = (c == '7' || c == '9') ? 4 : 3;
            for (int k = 1; k <= limit && k <= i; k++) {
                if (pressedKeys.charAt(i - k) != c) break;
                dp[i] = (dp[i] + dp[i - k]) % MOD;
            }
        }
        return (int) dp[n];
    }
}

        }
    }
    return dp[n];
};

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int countTexts(string pressedKeys) {
        const long long MOD = 1000000007LL;
        int n = pressedKeys.size();
        vector<long long> dp(n + 1, 0);
        dp[0] = 1;
        for (int i = 1; i <= n; ++i) {
            char c = pressedKeys[i - 1];
            int limit = (c == '7' || c == '9') ? 4 : 3;
            for (int k = 1; k <= limit && k <= i; ++k) {
                if (pressedKeys[i - k] != c) break;
                dp[i] = (dp[i] + dp[i - k]) % MOD;
            }
        }
        return static_cast<int>(dp[n]);
    }
};
