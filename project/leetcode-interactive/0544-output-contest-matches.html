输出比赛匹配对

Output Contest Matches

MEDIUM · 付费题锦标赛首尾配对O(n log n) 输出构造

题目

给定一个正整数 n，表示编号为 1 到 n 的队伍。比赛采用淘汰制；为了让强队尽可能晚相遇，每一轮都把当前序列中排名最前与最后的队伍配成一组，再把第二个与倒数第二个配成一组，依此类推。

请返回完整的比赛匹配字符串。每一场用 (A,B) 表示，其中 A 和 B 既可以是队伍编号，也可以是上一轮形成的比赛。答案中不含空格。输入保证可以持续两两配对直到只剩一场。

函数签名

findContestMatch(n: integer) -> string

官方示例参数

示例 1

输入：n = 4

输出：((1,4),(2,3))

第一轮得到 (1,4)、(2,3)，第二轮将两组配对。

示例 2

输入：n = 8

输出：(((1,8),(4,5)),((2,7),(3,6)))

每轮均对当前列表执行首尾配对。

约束

  • n ≥ 2，且 n 是 2 的幂。
  • 队伍按种子编号 1..n，编号越小排名越高。
  • 返回值必须准确保留括号、逗号与配对嵌套关系。

题解：把比赛当作字符串队伍

核心洞察

一次配对完成后，诸如 (1,8) 的整场比赛就可以被当作“新队伍”。因此无需构造树：维护字符串列表，每轮让第 i 项与第 size-1-i 项组合，直到列表长度为 1。

完整过程

  1. 初始化列表为字符串 1, 2, ..., n。
  2. 新建下一轮列表，按顺序写入 "(" + left + "," + right + ")"。
  3. 用下一轮替换当前列表；只剩一个元素时返回它。

正确性证明

循环不变式：每轮开始时，列表按该轮的种子顺序保存每个尚存参赛实体的完整比赛表达式。初始化时每个实体就是单个队伍编号，不变式成立。构造下一轮时，第 i 个实体恰与倒数第 i 个实体配对，符合规则；生成的字符串完整表示该场比赛，且加入顺序就是下一轮的种子顺序，故不变式保持。列表最终只有一个实体，根据不变式，它完整表示决赛及所有子比赛，所以返回值正确。

边界与复杂度

  • n = 2 时只执行一轮，得到 (1,2)。
  • 括号层数为 log₂n；约束保证每轮长度为偶数。
  • 若计入字符串复制，时间为 O(n log n)，最终输出长度为 O(n)，辅助列表占 O(n)。

替代方案

可以递归地把数组区间映射成比赛树，也可以使用可变字符串树节点延迟序列化。递归更贴近括号结构，但迭代列表更短、更不易写错；延迟序列化可减少中间字符串复制，却增加实现复杂度。

面试追问

  • 如果 n 不是 2 的幂，如何加入轮空规则？
  • 怎样输出真实树结构，而不是字符串？
  • 若配对策略由外部排名动态决定，数据结构如何调整？

常见错误

  • 直接配对相邻元素，导致强队过早相遇。
  • 原地覆盖列表，破坏尚未读取的尾部元素。
  • 遗漏外层括号或插入额外空格。
  • 把复杂度误写为纯 O(n)，忽略不可变字符串的多轮复制。

class Solution {
    public String findContestMatch(int n) {
        java.util.List<String> round = new java.util.ArrayList<>();
        for (int i = 1; i <= n; i++) round.add(String.valueOf(i));
        while (round.size() > 1) {
            java.util.List<String> next = new java.util.ArrayList<>();
            for (int i = 0, j = round.size() - 1; i < j; i++, j--)
                next.add("(" + round.get(i) + "," + round.get(j) + ")");
            round = next;
        }
        return round.get(0);
    }
}

var findContestMatch = function(n) {
  let round = Array.from({ length: n }, (_, i) => String(i + 1));
  while (round.length > 1) {
    const next = [];
    for (let i = 0, j = round.length - 1; i < j; i++, j--)
      next.push(`(${round[i]},${round[j]})`);
    round = next;
  }
  return round[0];
};

    def findContestMatch(self, n: int) -> str:
        round_ = [str(i) for i in range(1, n + 1)]
        while len(round_) > 1:
            size = len(round_)
            round_ = [f"({round_[i]},{round_[size - 1 - i]})"
                      for i in range(size // 2)]
        return round_[0]
