01 / 问题与数据

给每所学校确定一条申请分数线

学校希望所有达到分数要求的学生都申请时，人数仍不超过容量；在此前提下，让可申请人数尽可能多。分数线只能取自 Exam 已记录的 score。若最优人数对应多个分数，选更低的分数；没有可确定的分数则返回 -1。

约束与输出契约

  • school_id 在 Schools 中唯一，score 在 Exam 中唯一。
  • Exam 的人数是累计达标人数，并非恰好考到该分数的人数。
  • 数据满足单调关系：scoreᵢ > scoreⱼ 时，student_countᵢ ≤ student_countⱼ。
  • 每所学校独立决策，不模拟学生在不同学校之间的分配。输出列为 school_id、score，行顺序任意。
  • 可获取的题面未列出表行数或数值范围的额外上下界；本页不虚构这些限制。

04 / 独立题解

准备好再看推导

核心思路、SQL 与四语言参考均默认折叠。

按学校保留可行档位，再选最低分

核心洞察

分数越低，达标人数只会增多或保持不变。因此，在人数不超过容量的所有已知档位中，最低的 score 一定允许最多的申请者；人数相同的分数也自然由最低分打破平局。这个等价关系依赖题目给出的单调性。

完整过程

  1. 从 Schools 出发，保留每一所学校。
  2. 将 e.student_count <= s.capacity 放入 LEFT JOIN 的 ON 条件，关联其全部可行档位。
  3. 按 school_id 分组，对关联档位取 MIN(score)。
  4. 无可行档位时，左连接留下空扩展行，MIN 得到 NULL，再由 COALESCE 转为 -1。

例如容量 99：975、966、844、749 都可行，而 744 对应 100 人超额。在可行集合中，749 是最低分，对应 76 人；844 虽有相同人数，但分数更高。

正确性证明

可行性：任何被连接的档位都满足人数 ≤ 容量，所以从中取出的分数不会超额。最优性：令 q 为可行集合中的最小分数。对任意其他可行分数 r，均有 q ≤ r；单调性给出 count(q) ≥ count(r)，故 q 达到最大可申请人数。若人数并列，q 又是其中最低分。完备性：左连接保留全部学校；集合为空时，没有已知档位能满足容量条件，输出 -1，恰好符合题意。

边界与常见错误

  • 人数恰好等于容量也可行，必须用 ≤，不能用 <。
  • 无匹配仍需输出学校。INNER JOIN 会漏学校；把容量条件放到 WHERE 中也可能删除左连接的空行。
  • 不要把 student_count 相加：各行是相互重叠的累计人数。
  • MAX(score) 会偏向更严格的分数，无法满足最多申请人数与最低分要求。
  • 同人数的不同分数需要继续比较；按高分向低分遍历时，不能遇到第一个可行项就停。
  • 不能凭空返回 976 等不在 Exam 中的分数，也不能根据未知档位推算人数。
  • 按学校分组，不按容量分组；两所容量相同的学校也要各有一行。
  • 空 Exam 时每个学校返回 -1；空 Schools 时输出空结果。不依赖输入行的排列顺序。

复杂度

令 S 为学校数，E 为 Exam 行数。朴素嵌套循环连接检查 O(S×E) 对数据；SQL 的实际执行成本由数据库计划、索引及数据分布决定。连接匹配结果最多有 S×E 行，若物化需要相应空间，不能保证 SQL 为常数空间。下方四语言参考直接逐校扫描：时间 O(S×E)，额外工作空间 O(1)，输出空间 O(S)。

替代方案

可对每所学校使用相关子查询 SELECT MIN(score) FROM Exam WHERE student_count <= s.capacity，外层 COALESCE 处理 NULL，表达同样的逻辑。内存处理中可按 score 升序排序，在不增的人数序列上二分第一个满足容量的位置，总时间 O(E log E + S log E)，需要保存排序数据。也可离线排序学校与档位后双指针扫描，但本题 SQL 无需引入这些步骤。

面试追问

  • 如果累计人数不单调？此时最低可行分不一定对应最多人数，应先最大化可行 student_count，再最小化 score，可用窗口排序表达。
  • 怎样讨论索引？student_count 相关索引可能帮助范围匹配，但匹配面很大时收益有限；需查看实际执行计划，不能凭索引存在就断言更快。
  • 多个学校会抢同一名学生吗？本题只计算独立申请门槛；加入学生偏好和唯一录取规则后，已变成另一种分配问题。

MySQL · 官方可提交查询

SELECT s.school_id, COALESCE(MIN(e.score), -1) AS score
FROM Schools AS s
LEFT JOIN Exam AS e
  ON e.student_count <= s.capacity
GROUP BY s.school_id;

public class Main {
    public static int[][] findCutoffScore(int[][] schools, int[][] exam) {
        int[][] result = new int[schools.length][2];
        for (int i = 0; i < schools.length; i++) {
            Integer best = null;
            for (int[] row : exam) {
                if (row[1] <= schools[i][1]) {
                    best = best == null ? row[0] : Math.min(best, row[0]);
                }
            }
            result[i][0] = schools[i][0];
            result[i][1] = best == null ? -1 : best;
        }
        return result;
    }
    public static void main(String[] args) {
        int[][] schools = {{11,151},{5,48},{9,9},{10,99}};
        int[][] exam = {{975,10},{966,60},{844,76},{749,76},{744,100}};
        System.out.println(Arrays.deepToString(findCutoffScore(schools, exam)));
    }
}

function findCutoffScore(schools, exam) {
  return schools.map(([schoolId, capacity]) => {
    let best = null;
    for (const [score, count] of exam) {
      if (count <= capacity) {
        best = best === null ? score : Math.min(best, score);
      }
    }
    return [schoolId, best ?? -1];
  });
}

def find_cutoff_score(schools, exam):
    result = []
    for school_id, capacity in schools:
        best = None
        for score, count in exam:
            if count <= capacity:
                best = score if best is None else min(best, score)
        result.append([school_id, -1 if best is None else best])
    return result

#include <algorithm>
#include <array>
#include <iostream>
#include <optional>
#include <vector>
using namespace std;

// 本地语义参考：输入行含义与页面中的两张表一致。
vector<array<int, 2>> findCutoffScore(
    const vector<array<int, 2>>& schools,
    const vector<array<int, 2>>& exam) {
    vector<array<int, 2>> result;
    for (const auto& school : schools) {
        optional<int> best;
        for (const auto& row : exam) {
            if (row[1] <= school[1]) {
                best = best ? min(*best, row[0]) : row[0];
            }
        }
        result.push_back({school[0], best.value_or(-1)});
    }
    return result;
}
int main() {
    vector<array<int, 2>> schools = {{11,151},{5,48},{9,9},{10,99}};
    vector<array<int, 2>> exam = {{975,10},{966,60},{844,76},{749,76},{744,100}};
    for (const auto& row : findCutoffScore(schools, exam)) {
        cout << row[0] << " " << row[1] << '\n';
    }
}
