Core insight

这是 1…26 的无零位表示

普通 26 进制的余数范围是 0…25，但 Excel 的单个字母表示 1…26，没有表示 0 的字符。每轮先执行 columnNumber--，把当前范围平移到 0…25，再用余数映射 A…Z。

得到的余数对应最低位，因此字母按从右到左的顺序产生。先追加到缓冲区，循环结束后整体反转，避免反复在字符串头部插入。

完整过程

  1. 01 / SHIFT

    先减 1，把 A…Z 对应的 1…26 平移为 0…25。

  2. 02 / PICK

    对 26 取余，余数 0…25 映射为 A…Z。

  3. 03 / CARRY

    整除 26 得到下一轮数字，继续确定更高位。

  4. 04 / REVERSE

    数字归零后反转收集的字母，得到最终标题。

关键边界

  • 1 → A：减一后余数 0。
  • 26 → Z：不能错误地产生 A0。
  • 27 → AA：第一轮取 A，商 1 再取 A。
  • 最大值 2³¹−1 只产生 7 个字母，不存在乘法溢出。

复杂度与替代方案

设标题长度为 k，则时间 O(k)=O(log₂₆ n)，用于结果的空间为 O(k)。

递归也可在回溯时自然按正序拼接，逻辑简洁但使用 O(k) 调用栈。反复在字符串头部插入可免反转，却可能造成 O(k²) 拷贝；本题 k 很小但不是通用好习惯。

普通进制误区

  • 直接 n % 26 会把 26 得到余数 0，却没有“零字母”。
  • 用 A 表示 0 而不先减一，会让 1 错映射为 B。
  • 忘记反转，28 会生成 BA 而不是 AB。
  • 循环条件写成 n ≥ 0 会多产生一位。

面试追问

为什么每轮都必须减一？

它把 1-based digit 转为普通余数需要的 0-based index，让 26 正确映射到 Z。

如何反向把标题转回数字？

从左到右执行 value = value × 26 + (letter−'A'+1)。

是否需要 64 位整数？

本方向只有减一、取模、除法，32 位输入不会溢出；反向转换若范围扩大则应使用更宽整数。

如何推广到任意字母表？

把 26 替换为字母表长度，并继续使用先减一的 1-based digit 模式。

class Solution {
    public String convertToTitle(int columnNumber) {
        StringBuilder reversed = new StringBuilder();
        while (columnNumber > 0) {
            columnNumber--;
            int remainder = columnNumber % 26;
            reversed.append((char) ('A' + remainder));
            columnNumber /= 26;
        }
        return reversed.reverse().toString();
    }
}

    const reversed = [];
    while (columnNumber > 0) {
        columnNumber -= 1;
        const remainder = columnNumber % 26;
        reversed.push(String.fromCharCode(65 + remainder));
        columnNumber = Math.floor(columnNumber / 26);
    }
    return reversed.reverse().join("");

class Solution:
    def convertToTitle(self, columnNumber: int) -> str:
        reversed_letters = []
        while columnNumber > 0:
            columnNumber -= 1
            columnNumber, remainder = divmod(columnNumber, 26)
            reversed_letters.append(chr(ord("A") + remainder))
        return "".join(reversed(reversed_letters))

class Solution {
public:
    string convertToTitle(int columnNumber) {
        string reversed;
        while (columnNumber > 0) {
            --columnNumber;
            int remainder = columnNumber % 26;
            reversed.push_back(static_cast<char>('A' + remainder));
            columnNumber /= 26;
        }
        reverse(reversed.begin(), reversed.end());
        return reversed;
    }
};
