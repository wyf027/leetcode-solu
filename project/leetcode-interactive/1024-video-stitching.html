Video Stitching — 用尽可能少的原始片段覆盖完整赛事时间轴。

区间覆盖可自由裁剪最少片段
Problem

题目描述

一场赛事持续 time 秒。clips[i] = [startᵢ, endᵢ] 表示第 i 个视频片段的起止时间，片段之间可以重叠、长度也可不同。

片段可在任意位置裁剪，例如 [0,7] 可拆成 [0,1] + [1,3] + [3,7]。返回覆盖完整区间 [0,time] 所需的最少原始片段数；无法覆盖时返回 -1。

官方示例

输入clips = [[0,2],[4,6],[8,10],[1,9],[1,5],[5,9]], time = 10输出3解释选取 [0,2]、[1,9]、[8,10]，裁剪重叠部分后覆盖 [0,10]。
输入clips = [[0,1],[1,2]], time = 5输出-1解释现有内容最远只到 2 秒，无法覆盖整场赛事。
输入clips = [[0,1],[6,8],[0,2],[5,6],[0,4],[0,3],[6,7],[1,3],[4,7],[1,4],[2,5],[2,6],[3,4],[4,5],[5,7],[6,9]], time = 9输出3解释选取 [0,4]、[4,7]、[6,9]。

约束

  • 1 ≤ clips.length ≤ 100
  • 0 ≤ startᵢ ≤ endᵢ ≤ 100
  • 1 ≤ time ≤ 100

Mission brief

先想三个问题

  1. 已覆盖到 x 时，哪些片段能接上？
  2. 一次必须消耗一个片段，应该把边界推到哪里？
  3. 所有候选都无法越过 x 意味着什么？
把它想成分层跳跃：每一轮候选对应一次选择。
Solution

贪心扫描：每次延伸到最远

核心洞察

排序后从左向右扫描。设 currentEnd 是已确认连续覆盖的最右位置；在所有起点 ≤ currentEnd 的片段中，找最大终点 nextEnd。本轮必须用一个片段时，就采用能到达 nextEnd 的选择。

完整过程

按起点升序排列片段。
扫描所有能接上当前边界的片段，更新本轮最远边界。
使用一个片段，把当前覆盖提交到本轮最远边界；若无法前进，返回 -1。
覆盖达到或越过 time 时返回选择次数。

正确性、边界与复杂度

贪心选择安全

任何下一片段都必须从当前覆盖范围内起步。最远候选包含较短候选可达的范围，因此用它替换最优方案中的当前选择，不会增加后续片段数。

最少性

每轮越过当前边界至少需要一个新片段；贪心用同样的一次选择到达最远处。逐轮交换后，存在一个最优方案与贪心选择一致，所以最终计数最小。

边界

  • 终点超过 time 时，一旦覆盖达标即可结束。
  • 零长度片段不会推动边界，会被自然忽略。
  • 若 nextEnd === currentEnd 且尚未达标，说明存在无法跨越的断层。

时间：O(n log n)（排序）＋ O(n)（扫描）。空间：依排序实现通常为 O(log n) 至 O(n)。

替代方案

可令 dp[t] 表示覆盖到 t 的最少片段数，按片段转移，复杂度约 O(n·time)；也可先汇总每个起点的最远终点，再像 Jump Game II 一样线性分层推进。

面试追问

  • 输入已排序时能否做到 O(n)？可以。
  • 每个片段成本不同怎么办？统一计数的贪心一般失效，考虑动态规划或最短路。
  • 如何恢复选择方案？更新最远边界时保存索引，提交一轮时记录它。

常见错误

  • 按长度排序，却没有保证片段能接上。
  • 看到每个可用片段都计数，而不是整轮只计一次。
  • 只比较相邻区间，漏掉更早开始但延伸更远的片段。
  • 未检测边界停滞，造成死循环。

四语言完整代码

import java.util.Arrays;
class Solution {
    public int videoStitching(int[][] clips, int time) {
        Arrays.sort(clips, (a, b) -> a[0] - b[0]);
        int i = 0, used = 0, currentEnd = 0, nextEnd = 0;
        while (currentEnd < time) {
            while (i < clips.length && clips[i][0] <= currentEnd) {
                nextEnd = Math.max(nextEnd, clips[i++][1]);
            }
            if (nextEnd == currentEnd) return -1;
            currentEnd = nextEnd;
            used++;
        }
        return used;
    }
}

            while i < len(clips) and clips[i][0] <= current_end:
