可移除字符的最大数目

Maximum Number of Removable Characters

删除有顺序，匹配有余地。哪些字符可以消失，而目标依然保留？

01 / 题目与规则

给定字符串 s、它的子序列 p，以及由互不重复的原始下标组成的数组 removable。选择一个整数 k，同时移除 removable 中前 k 个下标对应的字符。返回使 p 仍是剩余字符串子序列的最大 k。

子序列只要求字符按原来的相对顺序出现，可以不连续。所有下标从 0 开始，删除时始终以原字符串的下标为准。不能随意挑选 k 个位置，也不能重排 removable。

接口：maximumRemovals(s, p, removable) → integer，其中 0 ≤ k ≤ removable.length。

官方约束

  • 1 ≤ p.length ≤ s.length ≤ 105
  • 0 ≤ removable.length < s.length
  • 0 ≤ removable[i] < s.length
  • p 是 s 的子序列。
  • s 和 p 仅包含小写英文字母。
  • removable 的元素互不相同。

元数据说明

官方约束写的是 removable.length < s.length，但示例 3 取等号。此页原样保留该约束与示例，代码也支持长度相等。中文提示中的“子字符串”与英文题面不一致，按题目主体的“子序列”理解。

输出：2

输出：1

示例 3

输入：s = "abcab", p = "abc", removable = [0,1,2,3,4]
输出：0

第一次移除下标 0 后，剩余的 a 位于 c 后面，无法依次匹配 a、b、c。

05 / 独立题解

想好如何找出最大 k 后，再展开。

核心洞察：可行性是一个有序边界

令 check(k) 表示移除前 k 个位置后，p 是否仍可匹配。随着 k 增加，剩余字符只会减少：若 k 可行，那么比它小的 k 都可行；若 k 不可行，更大的 k 也不可行。可行性呈“真、真、…、假、假”的形式，因此可以二分寻找最后一个真。

完整过程

  1. 令 n = s.length、m = removable.length。建立长度 n 的删除轮次数组 time，默认填 m + 1，表示始终保留。
  2. 令 time[removable[t]] = t + 1。判断前 k 次删除时，time[i] ≤ k 的位置直接跳过。数组只构建一次，不实际修改 s。
  3. 检查一个 k：指针 i 从左到右扫描 s，j 指向 p 中下一个需要的字符。只有位置未被删除且 s[i] = p[j] 时，j 才前进一步。j 到达 p.length 表示可行。
  4. 搜索闭区间 [lo, hi] = [0, m]。取偏右中点 mid = lo + floor((hi - lo + 1) / 2)。可行时 lo = mid，不可行时 hi = mid - 1。
  5. lo = hi 时返回 lo。m = 0 时循环自然跳过。

示例 1 的二分轨迹

time = [3, 2, 4, 1, 4, 4]，其中 4 表示候选删除全部完成后仍保留。

  1. [0, 3] → mid = 2：跳过原始下标 1、3；在下标 0 匹配 a，下标 5 匹配 b。可行，lo = 2。
  2. [2, 3] → mid = 3：下标 0 也被跳过，只剩 ccb。找不到 a，不可行，hi = 2。
  3. 区间收敛到 2，返回 2。可在上方实验台分别选择 k = 2、3 逐步观察。

正确性说明

判定正确：扫描时贪心选择最早的可用匹配字符。任何合法匹配的第一个位置都不会早于贪心选中的位置；以此归纳，贪心为后续字符留下的空间至少和任何其他匹配一样多。因此存在子序列当且仅当 j 最终到达 p.length。

二分正确：初始 k = 0 可行，最优答案在 [0, m]。每轮保持 lo 可行且最优答案位于 [lo, hi]；mid 可行时丢弃更小的候选不会错过最大值，mid 不可行时利用单调性排除 [mid, hi]。偏右中点保证两元素区间也会缩小，终止时唯一候选即最大可行值。

复杂度

预处理 O(n + m)，每次判定 O(n)，二分 O(log(m + 1)) 次。总时间 O(n + m + n log(m + 1))，在 m ≤ n 下可写为 O(n log(m + 2))，涵盖 m = 0 的初始化成本；额外空间 O(n)。

边界处理

答案可能是 0 或 m；removable 可能为空；重复字符需要按出现次数匹配。p = s 时任何删除都会破坏匹配。匹配完 p 后应停止扫描，避免读取越界。

替代方案

  • 枚举每个 k 并扫描判定，时间 O(n(m + 1))，实现直观但不适合 105 的规模。
  • 二分时每轮创建布尔删除标记，再扫描匹配；时间量级相同，但反复填充标记。删除轮次数组避免重复构造。
  • 用集合保存前 k 个下标也能实现判定，但存在哈希与分配开销；下标连续时数组更直接。

常见错误

  • 删除一个字符后再按新下标删除下一个：下标含义已经错位。
  • 排序 removable：破坏题目指定的删除顺序。
  • 把子序列当成连续子串，或只比较字符计数：都忽略真正的顺序条件。
  • time 采用 1 开始计数却用 time[i] < k 判删除：边界偏一，正确条件是 ≤ k。
  • 使用向下取整中点却更新 lo = mid：区间只剩两个候选时可能死循环。

面试追问

为什么不用动态规划？这里只判断固定 p 是否是子序列，最早匹配的贪心就足够，无需维护二维状态。

怎样返回保留下来的匹配下标？得到最大 k 后再扫描一次，把每次 j 前进时的原始 i 收集起来，增加 O(|p|) 的输出空间。

若允许任意选择删除位置呢？原题已保证存在 p，只需保留一组匹配位置，其余都能删除，最大数量是 n − |p|；前缀删除限制正是本题的关键。

Java

import java.util.Arrays;

class Solution {
    public int maximumRemovals(String s, String p, int[] removable) {
        int n = s.length(), m = removable.length;
        int[] time = new int[n];
        Arrays.fill(time, m + 1);
        for (int t = 0; t < m; t++) time[removable[t]] = t + 1;
        int lo = 0, hi = m;
        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;
            if (check(s, p, time, mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }

    private boolean check(String s, String p, int[] time, int k) {
        int j = 0;
        for (int i = 0; i < s.length() && j < p.length(); i++) {
            if (time[i] > k && s.charAt(i) == p.charAt(j)) j++;
        }
        return j == p.length();
    }
}

from typing import List

class Solution:
    def maximumRemovals(self, s: str, p: str,
                        removable: List[int]) -> int:
        n, m = len(s), len(removable)
        time = [m + 1] * n
        for t, index in enumerate(removable):
            time[index] = t + 1

        def check(k: int) -> bool:
            j = 0
            for i, char in enumerate(s):
                if j == len(p):
                    break
                if time[i] > k and char == p[j]:
                    j += 1
            return j == len(p)

        lo, hi = 0, m
        while lo < hi:
            mid = lo + (hi - lo + 1) // 2
            if check(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo

class Solution {

    int maximumRemovals(string s, string p, vector<int>& removable) {
        int n = static_cast<int>(s.size());
        int m = static_cast<int>(removable.size());

        for (int t = 0; t < m; ++t) time[removable[t]] = t + 1;

        };
        int lo = 0, hi = m;
        while (lo < hi) {
            int mid = lo + (hi - lo + 1) / 2;
            if (check(mid)) lo = mid;
            else hi = mid - 1;
        }
        return lo;
    }
};
