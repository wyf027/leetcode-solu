题意与样例

给定带有 left、right 与 next 字段的二叉树。把每个 next 指向同层紧邻的右侧节点；若不存在，则保持为 null。初始时所有 next 均为 null。

官方样例 1

输入 root = [1,2,3,4,5,null,7]
输出 [1,#,2,3,#,4,5,7,#]

符号 # 表示一层通过 next 走到末尾。

官方样例 2

输入 root = []
输出 []

空树无需连接，直接返回 null 根节点。

约束

节点数在 [0, 6000] 内；节点值在 [-100, 100] 内。

进阶要求只使用常量级额外空间；递归栈可按题意不计入。

与第 116 题的差别

这里不是完美二叉树，不能假设兄弟节点、堂兄弟节点或下一层左端点一定存在，连接必须能越过空缺。

可见空格约定：若输入中出现字符串，普通空格会显示为 ␠；本题输入为树数组，没有字符串空格。

题解默认隐藏

先独立思考如何跨过空孩子，再展开核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码。

solution / dummy + tail

用当前层，装载下一层

面试最推荐：把已经连好的当前层当作免费队列，通过 next 横向扫描；用一个 dummy 头与 tail 尾指针把所有非空孩子依次接成下一层。每层结束后跳到 dummy.next。

核心洞察

当前层的 next 提供横向通道；dummy 只做下一层的哨兵，不属于树；tail 永远指向下一层链表最后一个已装载节点。

复杂度

每个节点至多被扫描一次、每条孩子边至多处理一次：时间 O(n)。只有 current、dummy、tail 三个指针：额外空间 O(1)。

完整过程

  1. SCAN从每层最左节点开始，沿当前层的 next 向右扫描。
  2. LOAD遇到非空左孩子或右孩子，就执行 tail.next = child，再移动 tail。
  3. DROP当前层结束后，让 current = dummy.next，重建 dummy/tail，进入下一层。
  4. STOPcurrent 为空时所有层均已连接，返回原始 root。

边界

  • 空树直接返回。
  • 单节点没有右侧邻居，next 保持 null。
  • 只有单侧孩子、跨父节点的大空洞都由 tail 的顺序追加自然处理。
  • 题目初始 next 为 null；若用于一般工程，应显式确保每层末尾 next 为 null。

替代方案取舍

BFS 队列：最直观，但额外空间为 O(w)，不满足进阶常量空间。

递归 DFS：按深度维护前驱节点，代码可短，但显式逻辑更难证明，实际调用栈为 O(h)。

常见错误

  • 照搬完美二叉树公式 right.next = current.next.left，遇到空孩子立即失效。
  • 一层结束后从 tail 开始，正确入口应是 dummy.next。
  • 只处理左孩子或先右后左，破坏同层从左到右顺序。
  • 忘记推进 current = current.next 导致死循环。

面试追问

为什么是 O(1)？ dummy 是单个临时节点，不随树宽增长；下一层链表直接复用节点自带的 next。

若 next 可能有脏值？ 每次完成下一层后显式写 tail.next = null。

不变量

扫描 current 前，dummy.next 到 tail 恰好包含已发现的下一层非空节点，顺序与它们在树中的从左到右顺序完全一致。

class Solution {
    public Node connect(Node root) {
        Node current = root;

        while (current != null) {
            Node dummy = new Node(0);
            Node tail = dummy;

            while (current != null) {
                if (current.left != null) {
                    tail.next = current.left;
                    tail = tail.next;
                }
                if (current.right != null) {
                    tail.next = current.right;
                    tail = tail.next;
                }
                current = current.next;
            }

            current = dummy.next;
        }

        return root;
    }
}
