按列翻转得到
最大值等行数

把每一行按“相对首位的差异”归一化：原行与其逐位取反会落入同一个桶，最大桶大小就是答案。

MEDIUMO(m × n)时间 · O(m × n) 键空间

题目

给定一个 m × n 的二进制矩阵 matrix。你可以选择任意数量的列；每选一列，就把该列的所有单元格同时翻转（0 ↔ 1）。求经过某种列翻转后，行内所有元素相等（全 0 或全 1）的行数最大值。

函数签名

maxEqualRowsAfterFlips(matrix: integer[][]) → integer

官方示例

输入：matrix = [[0,1],[1,1]]
输出：1
解释：不翻转时已有 1 行的值全部相等。
输入：matrix = [[0,1],[1,0]]
输出：2
解释：翻转第 1 列后，两行的行内值都相等。
输入：matrix = [[0,0,0],[0,0,1],[1,1,0]]
输出：2
解释：翻转前两列后，后两行的行内值都相等。

约束与观察

  • m == matrix.length
  • n == matrix[i].length
  • 1 ≤ m, n ≤ 300
  • matrix[i][j] 为 0 或 1

哈希表统计规范模式

核心洞察

若一行最终变成全 0，则所翻转列恰好对应这一行中值为 1 的位置；若最终变成全 1，则翻转列恰好对应值为 0 的位置。因此，两行能被同一方案同时变成行内相等，当且仅当它们完全相同或逐位相反。

01 · 对齐以每行第一位为基准
02 · 归一计算 row[j] XOR row[0]
03 · 计数哈希表取最大频次

例如 001 的键是 001；110 的键也是 001。它们互为反转，所以进入同一个桶。

完整过程

  1. 遍历每一行，读取首元素 first。
  2. 对每一列生成 row[j] XOR first。这样规范键的首位恒为 0。
  3. 用哈希表记录每个规范键的出现次数，同时更新最大值。
  4. 返回最大频次；对应桶内所有行可以由同一列翻转方案同时变成行内全相等。

正确性证明

引理：两行的规范键相同，当且仅当两行相同或互补。若首位相同，异或首位后逐位相等推出原行相同；若首位不同，则每一对应位也不同，故原行互补。反向显然成立。

充分性：同一桶中的行只存在某个模式及其互补模式。选择模式中为 1 的列翻转，模式行变成全 0，互补行变成全 1，全部有效。

必要性：若若干行能经同一组列翻转后行内相等，任意两行在翻转前只能逐位相同或逐位不同，因此它们规范键相同。故任何可行集合都不会跨桶，最大桶即最优答案。

复杂度与边界

扫描每个元素一次，时间复杂度 O(mn)。字符串键总长度最坏为 O(mn)；哈希表至多保存 m 个键。单行、单列、重复行、全互补行均自然适用。

四语言完整代码

Java
class Solution {
    public int maxEqualRowsAfterFlips(int[][] matrix) {
        java.util.Map<String, Integer> count = new java.util.HashMap<>();
        int answer = 0;
        for (int[] row : matrix) {
            StringBuilder key = new StringBuilder(row.length);
            for (int value : row) {
                key.append(value ^ row[0]);
            }
            String pattern = key.toString();
            int frequency = count.getOrDefault(pattern, 0) + 1;
            count.put(pattern, frequency);
            answer = Math.max(answer, frequency);
        }
        return answer;
    }
}

var maxEqualRowsAfterFlips = function(matrix) {
    const count = new Map();
    let answer = 0;
    for (const row of matrix) {
        const key = row.map(value => value ^ row[0]).join('');
        const frequency = (count.get(key) || 0) + 1;
        count.set(key, frequency);
        answer = Math.max(answer, frequency);
    }
    return answer;
};
Python
from typing import List

class Solution:
    def maxEqualRowsAfterFlips(self, matrix: List[List[int]]) -> int:
        counts = {}
        answer = 0
        for row in matrix:
            key = tuple(value ^ row[0] for value in row)
            counts[key] = counts.get(key, 0) + 1
            answer = max(answer, counts[key])
        return answer
C++
class Solution {
public:
    int maxEqualRowsAfterFlips(vector<vector<int>>& matrix) {
        unordered_map<string, int> count;
        int answer = 0;
        for (const auto& row : matrix) {
            string key;
            key.reserve(row.size());
            for (int value : row) {
                key.push_back(char('0' + (value ^ row[0])));
            }
            answer = max(answer, ++count[key]);
        }
        return answer;
    }
};

替代方案

可把每行编码为位串，并取 min(row, complement(row)) 作为键；逻辑等价但需要显式构造互补串。也可两两比较，复杂度会退化到 O(m²n)。

面试追问

若每行超过机器字长怎么办？使用字符串/元组键。若是 k 进制且目标仍是行内相等？规范化为每位与首位的模 k 差值。

常见错误

只统计完全相同行，漏掉互补行；把每行独立翻转，忽略列操作对所有行同时生效；直接用可变数组作哈希键；误把答案理解为最终完全相同的行。

一句话记忆

统一让每行“从 0 开始”：row XOR row[0]，再数相同模式。
