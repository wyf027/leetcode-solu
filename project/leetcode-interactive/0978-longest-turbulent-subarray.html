LeetCode 978 · MEDIUM · 数组 / 动态规划 / 滑动窗口

让比较符号
像海浪一样交替

最长湍流子数组 · Longest Turbulent Subarray。先观察相邻元素的比较方向，再逐步寻找最长的连续交替片段。

题目

给定整数数组 arr，请返回其中最长湍流连续子数组的长度。所谓“湍流”，是指子数组内每一对相邻元素的比较符号严格交替：<, >, <, >… 或 >, <, >, <…。相邻元素相等会中断湍流。

函数签名

maxTurbulenceSize(arr: integer[]) -> integer

约束

  • 1 <= arr.length <= 4 * 10⁴
  • 0 <= arr[i] <= 10⁹

官方示例

输入：arr = [9,4,2,10,7,8,8,1,9] 输出：5 解释：arr[1] > arr[2] < arr[3] > arr[4] < arr[5]
输入：arr = [4,8,12,16] 输出：2
输入：arr = [100] 输出：1

湍流扫描仪

每一步比较一对相邻元素。up 表示以当前位置结尾且最后一步上升的长度，down 表示最后一步下降的长度。

蓝柱：数组元素渐变柱：当前元素金色符号：当前比较
位置 i0
up1
down1
当前答案1

先想一想

相邻比较为上升时，新的上升序列必须接在旧的下降序列后面。
相邻比较为下降时，新的下降序列必须接在旧的上升序列后面。
相等时，两种连续状态都只能重新从长度 1 开始。

题解：双状态动态规划

核心洞察

只需关心“以当前元素结尾”的两种状态。若 arr[i] > arr[i-1]，则 up = down + 1，同时 down = 1；下降时对称；相等时两者归 1。遍历中持续更新最大值。

完整过程

  1. 初始化 up = down = answer = 1。
  2. 从下标 1 起比较相邻值。
  3. 依据上升、下降或相等更新两个状态。
  4. 用两个状态的最大值更新答案。

正确性说明

不变式：处理完下标 i 后，up（或 down）恰为以 i 结尾、末次比较上升（或下降）的最长湍流子数组长度。上升只能延长末次下降的合法序列，下降同理；相等无法属于任何长度大于 1 的湍流序列。由归纳法，不变式始终成立；答案取遍历中所有结尾状态的最大值，所以得到全局最优。

边界与复杂度

  • 单元素数组答案为 1；全相等数组也为 1。
  • 严格单调且长度大于 1 的数组答案为 2。
  • 时间复杂度 O(n)，额外空间复杂度 O(1)。

替代方案

可以先生成长度为 n-1 的比较符号数组，再求最长正负交替段；也可以维护滑动窗口左端点。两者仍为 O(n)，但双状态写法更紧凑。

面试追问

  • 若要求返回子数组本身：同时记录最佳右端点和长度。
  • 若数据以流式到达：仅保存前一个值、两个状态和答案即可在线计算。
  • 若允许删除一个元素：需要扩展状态，记录是否已经使用删除机会。

常见错误

  • 把“子数组”误当成可跳过元素的“子序列”。
  • 相等时没有同时把 up、down 重置为 1。
  • 更新一个状态后，又错误地使用已更新的值计算另一个状态。
  • 按下标奇偶判断，而没有直接依据相邻比较的交替性。

四语言完整代码

class Solution {
    public int maxTurbulenceSize(int[] arr) {
        int up = 1, down = 1, answer = 1;
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > arr[i - 1]) {
                up = down + 1;
                down = 1;
            } else if (arr[i] < arr[i - 1]) {
                down = up + 1;
                up = 1;
            } else {
                up = down = 1;
            }
            answer = Math.max(answer, Math.max(up, down));
        }
        return answer;
    }
}

from typing import List

class Solution:
    def maxTurbulenceSize(self, arr: List[int]) -> int:
        up = down = answer = 1
        for i in range(1, len(arr)):
            if arr[i] > arr[i - 1]:
                up, down = down + 1, 1
            elif arr[i] < arr[i - 1]:
                up, down = 1, up + 1
            else:
                up = down = 1
            answer = max(answer, up, down)
        return answer
