仓库里 II

仓库两侧都能进箱。你可以改变箱子的顺序，但矮房间会成为通道瓶颈。目标是让尽可能多的箱子各占一个房间。

Problem

题目描述

给你两个正整数数组 boxes 和 warehouse。每个箱子宽度均为 1，boxes[i] 表示箱子高度；仓库有 n 个从左到右编号为 0...n-1 的房间，warehouse[i] 表示对应房间高度。

  • 箱子不能叠放，每个房间至多放一个箱子。
  • 箱子的推入顺序可以任意调整。
  • 每个箱子可以从仓库左侧或右侧推入。
  • 若路径上的某个房间比箱子矮，箱子无法越过该房间；跟在它后面的箱子也会被挡住。

返回最多能放入仓库的箱子数量。

函数签名

maxBoxesInWarehouse(boxes, warehouse) → integer

约束

  • n == warehouse.length
  • 1 ≤ boxes.length, warehouse.length ≤ 10⁵
  • 1 ≤ boxes[i], warehouse[i] ≤ 10⁹
注意：“房间本身够高”不等于箱子一定能到达；入口到该房间之间的最低高度同样重要。
示例 1
输入：boxes = [1,2,2,3,4], warehouse = [3,4,1,2]
输出：4

可以利用左右入口绕开不同瓶颈，让四个较小箱子分别进入四个房间。

示例 2
输入：boxes = [3,5,5,2], warehouse = [2,1,3,4,5]
输出：3

只有一个房间能容纳高度 5 的箱子，因此两个高度 5 的箱子不可能都放入。

示例 3
输入：boxes = [1,2,3], warehouse = [1,2,3,4]
输出：3
示例 4
输入：boxes = [4,5,6], warehouse = [3,3,3,3,3]
输出：0

Solution

把路径限制变成房间容量

关键不在模拟推箱顺序，而在回答：每个房间从更有利的一侧进入时，最多允许多高的箱子抵达？

核心洞察

从左侧到达房间 i，箱子必须穿过 0..i，所以高度上限是前缀最小值；从右侧到达，则是后缀最小值。两侧任选其一，因此该房间的有效容量取两者较大值。

left[i] = min(warehouse[0..i]) right[i] = min(warehouse[i..n-1]) cap[i] = max(left[i], right[i])

得到所有 cap 后，问题就变成：每个房间放一个不超过容量的箱子，最多配对多少组。

完整过程

1
计算左侧瓶颈

从左向右维护最小房高。

2
合并右侧瓶颈

从右向左维护最小值，并用较大者更新每个房间的有效容量。

3
排序并双指针配对

箱子与容量都升序；若最小箱子能进当前最小房间就同时前进，否则跳过这个房间。

正确性说明

引理 1：有效容量刻画可达性。

高度不超过左侧前缀最小值的箱子能从左到达房间；高度不超过右侧后缀最小值的箱子能从右到达。选择更有利的一侧后，可达上限正是两者最大值。

引理 2：升序贪心不会损失最优解。

若当前最小箱子都高于当前最小容量，任何剩余箱子都放不进这个房间，跳过它是必然的；若能放入，用最小箱子占用最小可行容量，为更大的箱子保留更大容量，交换后不会减少配对数。

结论：算法对每个有效容量做出的放入或跳过选择都安全，因此得到的配对数就是最多可放入的箱子数。

预处理O(n)前缀与后缀瓶颈
总时间O(m log m + n log n)排序主导
额外空间O(n)有效容量数组；不计排序栈

边界、替代方案与常见错误

边界情况
  • 所有箱子都高于两个入口：答案为 0。
  • 箱子多于房间：答案最多为房间数。
  • 重复高度不影响排序配对。
  • 高度可达 10⁹，只比较大小，不做可能溢出的加法。
常见错误
  • 只比较箱子与房间原始高度，忽略途中的矮房间。
  • 只做前缀最小值，等价于错误地只允许左侧进入。
  • 容量不足时跳过箱子；升序时应跳过当前房间，因为更大的箱子更不可能放入。
  • 逐箱逐房间模拟，最坏退化为 O(mn)。
替代方案：也可将箱子降序，并在仓库当前两端之间进行贪心分配；它更贴近“从两侧放入”的直觉，但正确性与边界更容易写错。有效容量法更容易证明和迁移。

四语言完整代码

JavaLeetCode 提交格式
import java.util.Arrays;

class Solution {
    public int maxBoxesInWarehouse(int[] boxes, int[] warehouse) {
        int n = warehouse.length;
        int[] capacity = new int[n];

        int minHeight = Integer.MAX_VALUE;
        for (int i = 0; i < n; i++) {
            minHeight = Math.min(minHeight, warehouse[i]);
            capacity[i] = minHeight;
        }

        minHeight = Integer.MAX_VALUE;
        for (int i = n - 1; i >= 0; i--) {
            minHeight = Math.min(minHeight, warehouse[i]);
            capacity[i] = Math.max(capacity[i], minHeight);
        }

        Arrays.sort(boxes);
        Arrays.sort(capacity);

        int box = 0;
        for (int room = 0; room < n && box < boxes.length; room++) {
            if (boxes[box] <= capacity[room]) {
                box++;
            }
        }
        return box;
    }
}

from typing import List


class Solution:
    def maxBoxesInWarehouse(
        self, boxes: List[int], warehouse: List[int]
    ) -> int:
        n = len(warehouse)
        capacity = [0] * n

        min_height = float("inf")
        for i in range(n):
            min_height = min(min_height, warehouse[i])
            capacity[i] = min_height

        min_height = float("inf")
        for i in range(n - 1, -1, -1):
            min_height = min(min_height, warehouse[i])
            capacity[i] = max(capacity[i], min_height)

        boxes.sort()
        capacity.sort()

        box = 0
        for room_capacity in capacity:
            if box < len(boxes) and boxes[box] <= room_capacity:
                box += 1
        return box
C++LeetCode 提交格式
#include <algorithm>
#include <climits>
#include <vector>
using namespace std;

class Solution {
public:
    int maxBoxesInWarehouse(
        vector<int>& boxes,
        vector<int>& warehouse
    ) {
        int n = static_cast<int>(warehouse.size());
        vector<int> capacity(n);

        int minHeight = INT_MAX;
        for (int i = 0; i < n; ++i) {
            minHeight = min(minHeight, warehouse[i]);
            capacity[i] = minHeight;
        }

        minHeight = INT_MAX;
        for (int i = n - 1; i >= 0; --i) {
            minHeight = min(minHeight, warehouse[i]);
            capacity[i] = max(capacity[i], minHeight);
        }

        sort(boxes.begin(), boxes.end());
        sort(capacity.begin(), capacity.end());

        int box = 0;
        for (int room = 0;
             room < n && box < static_cast<int>(boxes.size());
             ++room) {
            if (boxes[box] <= capacity[room]) {
                ++box;
            }
        }
        return box;
    }
};

面试追问

  1. 为什么有效容量取 max，而不是 min？ 因为箱子只需从任意一侧成功到达，不必同时从两侧可达。
  2. 如果只能从左侧进入呢？ 只保留前缀最小值，然后与箱子升序配对，这就是本题的单入口版本。
  3. 能否不额外保存 right 数组？ 可以；先把前缀最小值写入 capacity，再从右向左用一个变量维护后缀最小值并原地合并。
  4. 为什么排序后容量不足时跳过房间？ 因为当前已是最小剩余箱子，它都放不下，其他箱子更放不下。
