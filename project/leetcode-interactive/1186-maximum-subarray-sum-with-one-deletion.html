删除一次得到子数组最大和

Maximum Subarray Sum with One Deletion

题号#1186
难度MEDIUM
主题数组 · 动态规划
目标连续且非空
01 / PROBLEM

先把规则读准确

函数：maximumSum(arr)

给定整数数组 arr，选择其中一个非空连续子数组。你可以不删除元素，也可以从所选子数组中删除至多一个元素；删除后仍必须至少保留一个元素。返回所有合法选择中，剩余元素之和的最大值。

删除发生在选定区间内部；结果中的元素不必在原数组中继续相邻，但它们必须来自同一个连续区间，并且最多只跨过一个被删元素。

三个关键词

  • 连续：先选一个子数组。
  • 可选：可以删除 0 次或 1 次。
  • 非空：不能把唯一元素删掉来获得 0。
EXAMPLE 01
输入
arr = [1,-2,0,3]
输出
4
解释
选择整个区间并删除 -2，留下 [1,0,3]。
EXAMPLE 02
输入
arr = [1,-2,-2,3]
输出
3
解释
直接选择 [3]，不必使用删除机会。
EXAMPLE 03
输入
arr = [-1,-1,-1,-1]
输出
-1
解释
答案必须非空；不能删除单元素区间后以空数组得到 0。

约束

  • 1 ≤ arr.length ≤ 10⁵
  • -10⁴ ≤ arr[i] ≤ 10⁴

03 / SOLUTION

准备好再揭开完整题解

核心洞察

每个位置只需要两种结尾状态

keep 表示以当前位置结尾且一次都没删除的最大和；drop 表示以当前位置结尾且已经删除恰好一个元素的最大和。

处理 x = arr[i] 时，keep 要么从 x 重新开始，要么接在旧 keep 后；drop 要么延续旧 drop 并加入 x，要么删除当前 x，直接继承旧 keep。

状态转移

newKeep = max(x, keep + x)

newDrop = max(drop + x, keep)

answer = max(answer, newKeep, newDrop)

右侧公式中的 keep 和 drop 都是更新前的旧值，因此代码里要先计算新值再整体覆盖。

完整过程

  1. 初始化。第一个元素必须保留：keep = arr[0]，答案也为它。drop 设为负无穷，表示不能把唯一元素删空。
  2. 从左到右扫描。对每个新元素同时计算 newKeep 与 newDrop，不要让已经更新的值污染另一条转移。
  3. 维护全局最优。删除是“至多一次”，所以每一步都要用未删除和已删除两种状态更新答案。
  4. 返回答案。所有状态都代表非空结果，全负数组自然会返回最大的那个负数，而不是错误的 0。

正确性证明

不变式：处理完下标 i 后，keep 是所有以 i 结尾、未删除元素的合法方案最大和；drop 是所有以扫描位置 i 为右端、恰好删除一次且结果非空的合法方案最大和。

基础：i = 0 时，只能保留 arr[0]；删除它会为空，故删除态不可达。

归纳：未删除方案只有“从当前元素开始”和“连接旧未删除方案”两类；已删除方案只有“旧删除态加入当前元素”和“删除当前元素、继承旧未删除态”两类。转移分别取两类最大值，因此穷尽且不遗漏。

结论：全局答案收集每个右端点的两种最优合法状态，所以它等于全部合法子数组方案的最大和。

边界情况

  • 长度为 1：不能删除唯一元素，直接返回它。
  • 全部为负数：返回最大单元素，不允许空数组贡献 0。
  • 删除无收益：答案来自 keep，即普通最大子数组。
  • 被删元素在所选区间末尾：由 newDrop = oldKeep 覆盖。

复杂度

时间：O(n)，每个元素处理一次。

空间：O(1)，只保存两个滚动状态和答案。

替代方案

前后缀 Kadane：分别计算“以 i 结尾”和“以 i 开头”的普通最大子数组和；删除 arr[i] 后可合并 left[i-1] + right[i+1]。同样是 O(n) 时间，但需要 O(n) 额外空间，直观地展示了“跨过一个元素”。

二维 DP：保存 dp[i][0/1] 最易讲解，但滚动变量已经包含所需全部历史信息，因此数组可以压缩掉。

Javaint maximumSum(int[] arr)
class Solution {
    public int maximumSum(int[] arr) {
        int keep = arr[0];
        int drop = Integer.MIN_VALUE / 2;
        int answer = arr[0];

        for (int i = 1; i < arr.length; i++) {
            int x = arr[i];
            int newDrop = Math.max(drop + x, keep);
            int newKeep = Math.max(x, keep + x);
            keep = newKeep;
            drop = newDrop;
            answer = Math.max(answer, Math.max(keep, drop));
        }
        return answer;
    }
}

from typing import List


class Solution:
    def maximumSum(self, arr: List[int]) -> int:
        keep = arr[0]
        drop = float("-inf")
        answer = arr[0]

        for x in arr[1:]:
            new_drop = max(drop + x, keep)
            new_keep = max(x, keep + x)
            keep, drop = new_keep, new_drop
            answer = max(answer, keep, drop)

        return answer

class Solution {

    int maximumSum(vector<int>& arr) {

05 / INTERVIEW NOTES

面试追问与常见错误

面试追问

如果必须删除恰好一次呢？

最终只用 drop 更新答案；但仍需谨慎处理长度为 1 时无合法结果的题意定义。

如果允许删除至多 k 次呢？

把删除次数扩成维度：dp[d] 表示已删除 d 次的结尾最优，倒序更新可做到 O(nk) 时间、O(k) 空间。

如何恢复具体区间和被删下标？

为每个胜出的转移同步记录起点、删除位置，并在全局答案更新时保存右端点；或使用二维 DP 数组保留父指针。

常见错误

  • 把初值设为 0，导致全负数组错误返回 0。
  • 先覆盖 keep，再用新值计算 drop。
  • 只统计“必须删除”的状态，漏掉不删除更优的答案。
  • 误把题目理解成可以删除整个单元素子数组。
  • 使用 Integer.MIN_VALUE 后直接加数，造成溢出；可使用安全哨兵或单独判不可达。
