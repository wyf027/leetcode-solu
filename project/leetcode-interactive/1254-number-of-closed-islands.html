LeetCode 1254中等DFS / BFS矩阵

Boundary first · count later

统计封闭岛屿的数目

先让所有能“逃到边界”的陆地沉入海中，再数剩下的陆地连通块。用交互网格看清这条分界线。

Problem

题目

给定一个仅由 0 和 1 组成的二维矩阵 grid：0 表示陆地，1 表示水域。岛屿是由上下左右四个方向连通的、极大的陆地集合。若一座岛屿在四周都被水域包围、没有任何陆地格能连到矩阵边界，它就是封闭岛屿。

任务：返回 grid 中封闭岛屿的数量。函数签名为 closedIsland(grid) -> integer。

约束

  • 1 <= grid.length, grid[0].length <= 100
  • 0 <= grid[i][j] <= 1
  • 相邻只计算上、下、左、右；对角线不连通。

              [1,0,0,0,0,1,0,1],

Before the answer

先想一想

① 什么导致“不封闭”？

某块陆地只要有一条四连通路径抵达边界，整座岛就不封闭。

② 能否直接数岛？

可以，但每次搜索都要额外记录是否碰边；先消除边界陆地会让计数阶段更纯粹。

③ 为什么只遍历一次量级？

每个陆地格最多被洪泛标记一次，所有搜索的总工作量仍是矩阵大小。

Solution

两阶段洪泛：先排除，再计数

核心洞察

“不封闭”等价于“与矩阵边界上的某个陆地格四连通”。因此可以把所有边界陆地作为起点，洪泛并标记整片边界连通陆地。剩余的每个 0 必然属于封闭岛；之后每遇到一个未标记的 0，答案加一并洪泛整座岛。

完整过程

  1. 遍历首行、末行、首列、末列；发现 0 就启动 DFS/BFS，将其连通区域改为 1（或使用独立 visited 标记）。
  2. 遍历整个矩阵。每当遇到仍为 0 的格子，说明发现一座尚未计数的封闭岛：答案加一。
  3. 从该格继续洪泛，将整座封闭岛改为 1，避免同一岛屿重复计数。
  4. 遍历完成后返回答案。

正确性证明

  1. 边界排除阶段恰好删除所有非封闭岛。非封闭岛至少包含一个边界陆地格，从这个格洪泛会覆盖整座岛；反过来，从边界陆地出发只能到达含边界格的岛，所以不会删除封闭岛。
  2. 计数阶段每次发现的都是封闭岛。边界连通陆地已全部删除，剩余陆地无法连接到边界，按定义均属于封闭岛。
  3. 每座封闭岛恰好计数一次。第一次遇到该岛的任一格时计数并洪泛全岛，之后该岛不再含未访问的 0；不同连通块不会在同次洪泛中混合。

由以上三点，算法返回且仅返回所有封闭岛的数量。

边界情况

  • 矩阵全是水：答案为 0。
  • 矩阵全是陆地：它连接边界，答案为 0。
  • 单行或单列：所有陆地都在边界，答案为 0。
  • 一个封闭岛内部可有水洞；陆地连通性不受洞影响。
  • 多个岛仅对角接触：仍是不同岛屿。

复杂度

  • 时间：O(mn)，每个格子只被常数次检查，陆地至多入栈一次。
  • 空间：O(mn)，最坏情况下显式栈保存大量格子；直接修改输入矩阵，不另设 visited 矩阵。

替代方案

也可对每座岛执行一次搜索并维护 isClosed；或用并查集加一个“虚拟边界节点”。前者一次扫描更直接，后者适合动态连通扩展，但常数和代码量更大。

class Solution {
    private int rows, cols;
    private int[][] grid;
    private static final int[][] DIRS = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    public int closedIsland(int[][] grid) {
        this.grid = grid;
        rows = grid.length;
        cols = grid[0].length;

        for (int r = 0; r < rows; r++) {
            flood(r, 0);
            flood(r, cols - 1);
        }
        for (int c = 0; c < cols; c++) {
            flood(0, c);
            flood(rows - 1, c);
        }

        int answer = 0;
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (grid[r][c] == 0) {
                    answer++;
                    flood(r, c);
                }
            }
        }
        return answer;
    }

    private void flood(int sr, int sc) {
        if (grid[sr][sc] != 0) return;
        java.util.ArrayDeque<int[]> stack = new java.util.ArrayDeque<>();
        stack.push(new int[]{sr, sc});
        grid[sr][sc] = 1;
        while (!stack.isEmpty()) {
            int[] cur = stack.pop();
            for (int[] d : DIRS) {
                int nr = cur[0] + d[0], nc = cur[1] + d[1];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                        && grid[nr][nc] == 0) {
                    grid[nr][nc] = 1;
                    stack.push(new int[]{nr, nc});
                }
            }
        }
    }
}

var closedIsland = function(grid) {
    const rows = grid.length;
    const cols = grid[0].length;
    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];

    function flood(sr, sc) {
        if (grid[sr][sc] !== 0) return;
        const stack = [[sr, sc]];
        grid[sr][sc] = 1;
        while (stack.length) {
            const [r, c] = stack.pop();
            for (const [dr, dc] of dirs) {
                const nr = r + dr;
                const nc = c + dc;
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                    && grid[nr][nc] === 0) {
                    grid[nr][nc] = 1;
                    stack.push([nr, nc]);
                }
            }
        }
    }

    for (let r = 0; r < rows; r++) {
        flood(r, 0);
        flood(r, cols - 1);
    }
    for (let c = 0; c < cols; c++) {
        flood(0, c);
        flood(rows - 1, c);
    }

    let answer = 0;
    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            if (grid[r][c] === 0) {
                answer++;
                flood(r, c);
            }
        }
    }
    return answer;
};

class Solution:
    def closedIsland(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

        def flood(sr: int, sc: int) -> None:
            if grid[sr][sc] != 0:
                return
            stack = [(sr, sc)]
            grid[sr][sc] = 1
            while stack:
                r, c = stack.pop()
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if (0 <= nr < rows and 0 <= nc < cols
                            and grid[nr][nc] == 0):
                        grid[nr][nc] = 1
                        stack.append((nr, nc))

        for r in range(rows):
            flood(r, 0)
            flood(r, cols - 1)

            flood(0, c)
            flood(rows - 1, c)

        answer = 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 0:
                    answer += 1
                    flood(r, c)
        return answer
class Solution {
public:
    int closedIsland(vector<vector<int>>& grid) {
        rows = grid.size();
        cols = grid[0].size();
        this->grid = &grid;

        for (int r = 0; r < rows; ++r) {
            flood(r, 0);
            flood(r, cols - 1);
        }
        for (int c = 0; c < cols; ++c) {
            flood(0, c);
            flood(rows - 1, c);
        }

        int answer = 0;
        for (int r = 0; r < rows; ++r) {
            for (int c = 0; c < cols; ++c) {
                if (grid[r][c] == 0) {
                    ++answer;
                    flood(r, c);
                }
            }
        }
        return answer;
    }

private:
    int rows, cols;
    vector<vector<int>>* grid;
    const int directions[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    void flood(int sr, int sc) {
        if ((*grid)[sr][sc] != 0) return;
        vector<pair<int, int>> stack = {{sr, sc}};
        (*grid)[sr][sc] = 1;
        while (!stack.empty()) {
            auto [r, c] = stack.back();
            stack.pop_back();
            for (const auto& d : directions) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols
                        && (*grid)[nr][nc] == 0) {
                    (*grid)[nr][nc] = 1;
                    stack.push_back({nr, nc});
                }
            }
        }
    }
};

面试追问

  • 不能修改输入怎么办？ 使用 boolean[][] visited，复杂度量级不变。
  • 为什么显式栈更稳？ 100 × 100 的长链可能导致部分语言递归栈溢出。
  • 若改成八方向相邻？ 只需补上四个对角方向，证明结构不变。
  • 若网格持续变化？ 需要重新思考动态连通；普通并查集擅长增加连接，不擅长删除。

常见错误

  • 把 1 当作陆地，与本题定义相反。
  • 只删除边界格，没有洪泛删除其整座连通岛。
  • 计数后未标记整座岛，导致重复计数。
  • 漏扫某条边，尤其是首列或末列。
  • 递归写法未考虑最坏深度。
  • 把对角接触误认为连通。
