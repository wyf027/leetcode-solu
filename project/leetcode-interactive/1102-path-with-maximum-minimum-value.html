得分最高的路径

Path With Maximum Minimum Value —— 不是追求路径总和，而是让路径上最弱的那一格尽可能强。下面先理解任务，再亲手推进一次“最大优先”的搜索。

MEDIUM矩阵优先队列Dijkstra 变体并查集

题目

给定一个由非负整数构成的 m × n 矩阵 grid。从左上角 (0,0) 出发，每一步只能向上、下、左、右移动，最终抵达右下角 (m-1,n-1)。一条路径的得分是这条路径经过的所有格子中的最小值。请返回所有可行路径能够取得的最大得分。

函数签名：maximumMinimumPath(grid: integer[][]): integer

示例 1
输入：grid = [[5,4,5],[1,2,6],[7,4,6]]
输出：4
解释：可沿 5 → 4 → 5 → 6 → 6 行走，路径最小值为 4。
示例 2
输入：grid = [[2,2,1,2,2,2],[1,2,2,2,1,2]]
输出：2
示例 3
输入：grid = [[3,4,6,3,4],[0,2,1,1,7],
 [8,8,3,2,7],[3,2,4,9,8],
 [4,1,2,0,0],[4,6,5,4,3]]
输出：3
约束
m == grid.length
n == grid[i].length
1 ≤ m, n ≤ 100
0 ≤ grid[i][j] ≤ 10⁹

题解：最大堆上的最宽路径

核心洞察：把普通最短路里的“距离相加”换成“沿途取最小”，把“选最小距离点”换成“选当前得分最大的点”。

完整过程

  1. 令 best[r][c] 表示目前找到的、从起点到该格的最大路径得分，起点为 grid[0][0]。
  2. 使用最大堆保存 (score,r,c)。每次弹出分数最大的状态；若它已落后于 best，跳过。
  3. 走向值为 v 的邻格后，新分数是 min(score,v)。只有它改善邻格的 best 才入堆。
  4. 终点第一次从最大堆弹出时立即返回。

正确性

引理：当格子 u 以堆顶分数 s 被首次有效弹出时，s 是起点到 u 的最优瓶颈值。反证：若存在得分大于 s 的路径，沿该路径找到第一个尚未确定的格子；它的前驱已经确定，并会把一个大于 s 的候选加入堆，因此应先于 u 弹出，矛盾。

定理：终点首次有效弹出时，根据引理，其分数就是所有起终点路径中最大可能的最小值，算法返回正确答案。

边界与复杂度

单格矩阵直接得到该格值；重复值、零值、单行和单列无需特殊分支。设格子数 V=mn，边数为 O(V)：时间 O(mn log(mn))，空间 O(mn)。

替代方案

  • 并查集：按格子值降序激活格子并合并相邻激活格；起终点首次连通时的激活值就是答案。排序主导，时间 O(mn log(mn))。
  • 二分答案 + BFS/DFS：检查只经过值不小于阈值的格子能否到达终点，时间 O(mn log U)。

面试追问

  • 如何还原具体路径？为每次有效松弛记录父节点，终点确定后回溯。
  • 为何不能普通 BFS？步数少不代表路径瓶颈大；需要按“当前最好得分”排序。
  • 并查集何时更自然？只需最终答案、且容易离线按权值激活时。

常见错误

  • 把路径得分写成和或最大值，而不是沿途最小值。
  • 使用最小堆，或在入堆时直接认定终点完成。
  • 只用布尔 visited 却在过早入队时标记，阻断后续更优松弛。
  • 比较器用减法处理大整数时忽略语言的溢出风险。

class Solution {
    public int maximumMinimumPath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] best = new int[m][n];
        for (int[] row : best) java.util.Arrays.fill(row, -1);
        java.util.PriorityQueue<int[]> pq = new java.util.PriorityQueue<>(
            (a, b) -> Integer.compare(b[0], a[0]));
        best[0][0] = grid[0][0]; pq.offer(new int[]{grid[0][0], 0, 0});
        int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!pq.isEmpty()) {
            int[] cur = pq.poll(); int score = cur[0], r = cur[1], c = cur[2];
            if (score != best[r][c]) continue;
            if (r == m - 1 && c == n - 1) return score;
            for (int[] x : d) {
                int nr = r + x[0], nc = c + x[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int ns = Math.min(score, grid[nr][nc]);
                if (ns > best[nr][nc]) { best[nr][nc] = ns; pq.offer(new int[]{ns,nr,nc}); }
            }
        }
        return -1;
    }
}

  const m = grid.length, n = grid[0].length;
  const best = Array.from({length:m}, () => Array(n).fill(-1));
  const heap = [];
  const push = x => { heap.push(x); let i=heap.length-1; while(i){let p=(i-1)>>1;if(heap[p][0]>=x[0])break;heap[i]=heap[p];i=p;}heap[i]=x; };
  const pop = () => { const top=heap[0], x=heap.pop(); if(heap.length){let i=0;while(i*2+1<heap.length){let c=i*2+1;if(c+1<heap.length&&heap[c+1][0]>heap[c][0])c++;if(heap[c][0]<=x[0])break;heap[i]=heap[c];i=c;}heap[i]=x;}return top; };
  best[0][0]=grid[0][0]; push([grid[0][0],0,0]);
  const dirs=[[1,0],[-1,0],[0,1],[0,-1]];

from typing import List
import heapq

class Solution:
    def maximumMinimumPath(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        best = [[-1] * n for _ in range(m)]
        best[0][0] = grid[0][0]
        heap = [(-grid[0][0], 0, 0)]
        for_pop = ((1, 0), (-1, 0), (0, 1), (0, -1))
        while heap:
            neg, r, c = heapq.heappop(heap)
            score = -neg
            if score != best[r][c]: continue
            if r == m - 1 and c == n - 1: return score
            for dr, dc in for_pop:
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    ns = min(score, grid[nr][nc])
                    if ns > best[nr][nc]:
                        best[nr][nc] = ns
                        heapq.heappush(heap, (-ns, nr, nc))
        return -1
