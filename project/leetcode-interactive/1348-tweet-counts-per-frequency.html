推文计数Tweet Counts Per Frequency

把任意查询区间按“分钟 / 小时 / 天”切成连续时间块，并回答指定推文在每个块中出现了多少次。

题号 1348非付费题区间端点均包含设计数据结构
Activity stream / second

记录的是离散时间点；查询返回的是从 startTime 锚定的一组计数。

Problem

题目要求

Inclusive interval

实现 TweetCounts 类。它接收“推文名 + 发布时间（秒）”的记录，并能在闭区间 [startTime, endTime] 内，按指定频率切块后返回每块的推文数。

频率对应的块长为：minute = 60 秒、hour = 3600 秒、day = 86400 秒。第一个块从 startTime 开始；最后一个块可能较短，但必须结束于 endTime。

  • TweetCounts()：初始化对象。
  • recordTweet(String tweetName, int time)：记录一次推文。
  • getTweetCountsPerFrequency(String freq, String tweetName, int startTime, int endTime)：返回各时间块的计数列表。
官方示例 
输入
["TweetCounts","recordTweet","recordTweet","recordTweet",
 "getTweetCountsPerFrequency","getTweetCountsPerFrequency",
 "recordTweet","getTweetCountsPerFrequency"]
[[],["tweet3",0],["tweet3",60],["tweet3",10],
 ["minute","tweet3",0,59],["minute","tweet3",0,60],
 ["tweet3",120],["hour","tweet3",0,210]]

输出
[null,null,null,null,[2],[2,1],null,[4]]

约束

  • 0 <= time, startTime, endTime <= 109
  • 0 <= endTime - startTime <= 104
  • recordTweet 与 getTweetCountsPerFrequency 的调用总数不超过 104。

    Solution

    有序时间戳 + 二分边界

    Sorted list

    核心洞察

    每个推文名都对应一列时间戳。只要让这列数据始终有序，每个时间块中的数量就等于两个二分位置之差，不必逐秒扫描。

    count([L, R]) = lowerBound(R + 1) − lowerBound(L)

    完整过程

    1. 用哈希表把 tweetName 映射到升序时间戳数组。
    2. 记录时二分找到插入位置，保持数组有序。
    3. 查询时根据频率得到块长 size。
    4. 从 startTime 起，每次取闭区间 [L, min(L+size-1,endTime)]。
    5. 用两次 lowerBound 求出块内元素个数。

    正确性证明

    1. 对每个推文名，二分插入不会改变已有元素的相对升序关系，因此任意时刻其时间戳数组都有序。
    2. 在有序数组中，lowerBound(L) 是第一个不小于 L 的位置；lowerBound(R+1) 是第一个大于 R 的位置。两者之间恰好包含所有落在闭区间 [L,R] 的记录。
    3. 查询从 startTime 开始，以固定块长连续推进，并把最后一块截到 endTime，所以这些块不重不漏地覆盖整个查询区间。
    4. 每块计数正确且所有块完整覆盖查询区间，故返回列表正确。

    复杂度

    设某推文已有 N 条记录，查询产生 B 个时间块。

    • 记录：二分查找 O(log N)；数组插入移动元素，最坏 O(N)。
    • 查询：每块两次二分，共 O(B log N)。
    • 空间：保存全部记录，O(N)（所有名称合计）。

    边界清单

    • startTime == endTime 时仍有一个块。
    • 块右端必须是 L + size - 1，且包含端点。
    • 最后一块长度可以小于频率对应的秒数。
    • 推文名从未出现时，每个块都返回 0。
    • 同一秒可以记录多条同名推文，必须全部计数。

    替代方案

    可用平衡树 / 有序映射保存“时间 → 次数”，记录可达 O(log N)；查询遍历区间内的不同时间点。也可先无序追加、查询时排序，但需要维护脏标记，否则重复排序开销较大。

    面试追问

    • 若记录量达到十亿级，如何按时间分片并做预聚合？
    • 若查询频率可自定义，怎样缓存热点区间？
    • 若需要删除推文，数组方案有什么代价？
    • 如何支持并发写入与一致性快照查询？

    常见错误

    • 把分块锚定到整分钟或 Unix 时间零点；本题必须锚定 startTime。
    • 把右边界当成开区间，漏掉恰好位于 endTime 的推文。
    • 用 (endTime-startTime)/size 计算块数而忘记加一。
    • 按秒创建长度接近 10^9 的数组；应只存实际发生的记录。

    import java.util.*;

class TweetCounts {
    private final Map<String, List<Integer>> times = new HashMap<>();

    public TweetCounts() {}

    public void recordTweet(String tweetName, int time) {
        List<Integer> list = times.computeIfAbsent(tweetName,
                                                    key -> new ArrayList<>());
        int index = lowerBound(list, time);
        list.add(index, time);
    }

    public List<Integer> getTweetCountsPerFrequency(
            String freq, String tweetName, int startTime, int endTime) {
        int size = freq.equals("minute") ? 60
                 : freq.equals("hour") ? 3600 : 86400;
        List<Integer> list = times.getOrDefault(tweetName,
                                                Collections.emptyList());
        List<Integer> answer = new ArrayList<>();

        for (int left = startTime; left <= endTime; left += size) {
            int right = Math.min(left + size - 1, endTime);
            answer.add(lowerBound(list, right + 1) - lowerBound(list, left));
        }
        return answer;
    }

    private int lowerBound(List<Integer> list, int target) {
        int left = 0, right = list.size();
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (list.get(mid) < target) left = mid + 1;
            else right = mid;
        }
        return left;
    }
}
    var TweetCounts = function() {
    this.times = new Map();
};

TweetCounts.prototype.lowerBound = function(list, target) {
    let left = 0, right = list.length;
    while (left < right) {
        const mid = left + Math.floor((right - left) / 2);
        if (list[mid] < target) left = mid + 1;
        else right = mid;
    }
    return left;
};

TweetCounts.prototype.recordTweet = function(tweetName, time) {
    if (!this.times.has(tweetName)) this.times.set(tweetName, []);
    const list = this.times.get(tweetName);
    list.splice(this.lowerBound(list, time), 0, time);
};

TweetCounts.prototype.getTweetCountsPerFrequency = function(
    freq, tweetName, startTime, endTime
) {
    const sizes = { minute: 60, hour: 3600, day: 86400 };
    const size = sizes[freq];
    const list = this.times.get(tweetName) || [];
    const answer = [];

    for (let left = startTime; left <= endTime; left += size) {
        const right = Math.min(left + size - 1, endTime);
        answer.push(this.lowerBound(list, right + 1) -
                    this.lowerBound(list, left));
    }
    return answer;
};
    from bisect import bisect_left, insort
from collections import defaultdict
from typing import List


class TweetCounts:
    def __init__(self):
        self.times = defaultdict(list)

    def recordTweet(self, tweetName: str, time: int) -> None:
        insort(self.times[tweetName], time)

    def getTweetCountsPerFrequency(
        self,
        freq: str,
        tweetName: str,
        startTime: int,
        endTime: int,
    ) -> List[int]:
        sizes = {"minute": 60, "hour": 3600, "day": 86400}
        size = sizes[freq]
        times = self.times[tweetName]
        answer = []

        for left in range(startTime, endTime + 1, size):
            right = min(left + size - 1, endTime)
            answer.append(
                bisect_left(times, right + 1) - bisect_left(times, left)
            )
        return answer
    class TweetCounts {
    unordered_map<string, vector<int>> times;

public:
    TweetCounts() = default;

    void recordTweet(string tweetName, int time) {
        auto& list = times[tweetName];
        list.insert(lower_bound(list.begin(), list.end(), time), time);
    }

    vector<int> getTweetCountsPerFrequency(
        string freq, string tweetName, int startTime, int endTime
    ) {
        int size = freq == "minute" ? 60
                 : freq == "hour" ? 3600 : 86400;
        const auto& list = times[tweetName];
        vector<int> answer;

        for (int left = startTime; left <= endTime; left += size) {
            int right = min(left + size - 1, endTime);
            auto first = lower_bound(list.begin(), list.end(), left);
            auto after = lower_bound(list.begin(), list.end(), right + 1);
            answer.push_back(static_cast<int>(after - first));
        }
        return answer;
    }
