Problem

题目描述

函数：intersection(nums1, nums2)

给定两个整数数组 nums1 和 nums2，返回它们的交集。结果中的每个元素必须只出现一次，返回顺序不限。

参数与返回值

nums1: integer[]，nums2: integer[]；返回 integer[]。即使输入中有重复数字，答案中同一数字也只能保留一个。

示例 1

输入：nums1 = [1,2,2,1], nums2 = [2,2]
输出：[2]

示例 2

输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
输出：[9,4]
解释：[4,9] 也符合要求。

约束

  • 1 <= nums1.length, nums2.length <= 1000
  • 0 <= nums1[i], nums2[i] <= 1000

Solution

准备好再查看题解

建议先说出：如何快速判断一个数是否属于另一个数组，以及怎样保证答案不重复。

核心洞察

哈希集合同时解决两个关键点：近似常数时间的成员判断，以及天然去重。先把 nums1 放入集合，再扫描 nums2；命中的数加入结果集合。

复杂度

设两数组长度分别为 m、n。期望时间复杂度 O(m+n)，额外空间复杂度 O(m)；若优先存较短数组，可降为 O(min(m,n))。

完整过程

  1. 遍历 nums1，建立哈希集合 seen。
  2. 建立空的结果集合 result。
  3. 遍历 nums2。若当前值属于 seen，将它加入 result。
  4. 把结果集合转换为数组返回；元素顺序无需固定。

正确性说明

  • 不会漏：任意属于两数组的值 x 已在 seen 中；扫描到 nums2 的 x 时必被加入结果。
  • 不会多：只有同时出现在 seen 与 nums2 中的值才会进入结果。
  • 不会重复：result 是集合，同一值被加入多次仍只保留一份。

因此返回数组恰好包含两个输入数组的全部不同交集元素。

边界情况

  • 两个数组完全没有共同元素：返回空数组。
  • 输入全部是同一个值：若双方都有该值，答案仍只含一个。
  • 一个数组远短于另一个：可为较短数组建集合以节省空间。
  • 题目允许任意顺序，不能把固定输出顺序当作正确性条件。

常见错误

  • 使用数组保存答案却没有去重，导致重复输出。
  • 把“交集”误写成“并集”，把未命中的值也加入结果。
  • 双重循环后直接追加，时间达到 O(mn)。
  • 测试时直接比较数组顺序，忽略题目允许任意顺序。

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int[] intersection(int[] nums1, int[] nums2) {
        Set<Integer> seen = new HashSet<>();
        for (int value : nums1) {
            seen.add(value);
        }

        Set<Integer> result = new HashSet<>();
        for (int value : nums2) {
            if (seen.contains(value)) {
                result.add(value);
            }
        }

        int[] answer = new int[result.size()];
        int index = 0;
        for (int value : result) {
            answer[index++] = value;
        }
        return answer;
    }
}

#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
        unordered_set<int> seen(nums1.begin(), nums1.end());
        unordered_set<int> result;

        for (int value : nums2) {
            if (seen.count(value) > 0) {
                result.insert(value);
            }
        }

        return vector<int>(result.begin(), result.end());
    }
};

替代方案

排序 + 双指针：分别排序两个数组，指针指向较小值的一侧并前进；相等时记录一次，然后跳过重复值。时间复杂度通常为 O(m log m + n log n)，若不计排序栈则额外空间可较低。

排序 + 二分：排序一个数组，再对另一个数组的不同值逐个二分查找。适合一侧已排序或需要复用查询结构的场景。
