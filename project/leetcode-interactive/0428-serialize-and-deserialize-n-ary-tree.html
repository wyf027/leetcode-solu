N 叉树

把任意分叉的树压成一条可传输的字符串，再仅凭这条字符串原样重建它。真正要保存的不是遍历顺序，而是每棵子树的边界。

树深度优先搜索广度优先搜索字符串

Problem

题意

设计一个无状态的 Codec。serialize(root) 接收一棵 N 叉树的根节点并返回字符串；deserialize(data) 接收该字符串并还原出结构、节点值及孩子次序完全相同的树。

序列化格式由你定义，不必与平台展示 N 叉树时使用的层序 null 分组格式相同。判定核心是 deserialize(serialize(root)) 与原树等价。

接口

class Codec {
    String serialize(Node root)
    Node deserialize(String data)
}

Node {
    int val
    List<Node> children
}

Contract

约束与语义

  • 节点总数在 [0, 10⁴] 范围内。
  • 0 ≤ Node.val ≤ 10⁴。
  • N 叉树高度不超过 1000。
  • 不得依赖成员变量、全局变量或静态变量在两次调用之间保存状态。
  • 孩子数组中的相对次序是树结构的一部分，必须保留。
0…N每个节点的孩子数
可逆字符串必须自描述

Spoiler gate

准备好再揭开完整题解

先想一想：仅有前序节点值时，为什么无法确定每棵子树在哪里结束？

Full solution

前序遍历 + 孩子数

核心洞察

每个节点只需额外记录一个整数：它有多少个直接孩子。按前序写出 (节点值, 孩子数)，随后紧跟每个孩子的完整编码。解码时，孩子数就是明确的子树边界。

示例树被编码为 1,3, 3,2, 5,0, 6,0, 2,0, 4,0。逗号只负责分词；真正保存结构的是每个值后面的孩子数。

完整过程

序列化：空树返回空串；否则写入当前节点值和 children.length。

按孩子数组顺序递归序列化每个孩子，最后一次性连接所有标记。

反序列化：维护局部下标，读两个标记得到节点值和孩子数。

递归构造恰好这么多棵子树并依次加入孩子数组，然后返回当前节点。

正确性证明

命题：对任意 N 叉树 T，本算法的 deserialize(serialize(T)) 与 T 相同。

基础情形：空树编码为空串，解码为空树；叶节点编码为 (val, 0)，解码读到 0 后不构造孩子，因此得到相同叶节点。

归纳步骤：假设所有规模小于当前树的子树都能正确往返。根节点的值和孩子数被首先、无歧义地读取；解码器随后按原顺序调用恰好 k 次。依据归纳假设，这 k 棵孩子子树逐一正确重建，故当前整棵树也正确重建。

唯一消费：每次递归固定先消费两个标记，再由孩子数确定后续递归次数；所有标记各归属唯一节点，不会跨越兄弟子树边界。

复杂度

  • 序列化时间 O(n)，反序列化时间 O(n)。
  • 输出字符串与分词数组占 O(n) 空间。
  • 递归调用栈占 O(h)，其中 h 为树高。

边界情况

空树

空字符串与 null 双向对应。

单节点 / 叶节点

孩子数 0 明确终止当前子树。

深链与宽树

递归栈受高度影响；单个节点可拥有大量孩子。

孩子顺序

必须按数组原顺序写入和还原。

多位数

必须用分隔符分词，不能逐字符读取。

状态隔离

下标和标记数组放在每次调用的局部作用域。

Java
/*
// Definition for a Node.
class Node {
    public int val;
    public List<Node> children;
    public Node() {}
    public Node(int val) { this.val = val; }
    public Node(int val, List<Node> children) {
        this.val = val;
        this.children = children;
    }
}
*/
class Codec {
    public String serialize(Node root) {
        if (root == null) return "";
        StringBuilder out = new StringBuilder();
        encode(root, out);
        out.setLength(out.length() - 1);
        return out.toString();
    }

    private void encode(Node node, StringBuilder out) {
        out.append(node.val).append(',')
           .append(node.children.size()).append(',');
        for (Node child : node.children) {
            encode(child, out);
        }
    }

    public Node deserialize(String data) {
        if (data == null || data.isEmpty()) return null;
        String[] tokens = data.split(",");
        int[] index = {0};
        return decode(tokens, index);
    }

    private Node decode(String[] tokens, int[] index) {
        int value = Integer.parseInt(tokens[index[0]++]);
        int childCount = Integer.parseInt(tokens[index[0]++]);
        List<Node> children = new ArrayList<>(childCount);
        Node node = new Node(value, children);
        for (int i = 0; i < childCount; i++) {
            children.add(decode(tokens, index));
        }
        return node;
    }
}

/**
 * // Definition for a Node.
 * function Node(val, children) {
 *     this.val = val;
 *     this.children = children;
 * }
 */
var Codec = function() {};

Codec.prototype.serialize = function(root) {
    if (root === null) return "";
    const tokens = [];

    function encode(node) {
        tokens.push(String(node.val));
        tokens.push(String(node.children.length));
        for (const child of node.children) {
            encode(child);
        }
    }

    encode(root);
    return tokens.join(",");
};

Codec.prototype.deserialize = function(data) {
    if (data === "") return null;
    const tokens = data.split(",").map(Number);
    let index = 0;

    function decode() {
        const value = tokens[index++];
        const childCount = tokens[index++];
        const children = [];
        const node = new Node(value, children);
        for (let i = 0; i < childCount; i++) {
            children.push(decode());
        }
        return node;
    }

    return decode();
};

Python
"""
# Definition for a Node.
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children if children is not None else []
"""

class Codec:
    def serialize(self, root: 'Node') -> str:
        if root is None:
            return ""

        tokens = []

        def encode(node):
            tokens.append(str(node.val))
            tokens.append(str(len(node.children)))
            for child in node.children:
                encode(child)

        encode(root)
        return ",".join(tokens)

    def deserialize(self, data: str) -> 'Node':
        if not data:
            return None

        tokens = iter(map(int, data.split(",")))

        def decode():
            value = next(tokens)
            child_count = next(tokens)
            children = [decode() for _ in range(child_count)]
            return Node(value, children)

        return decode()

C++
/*
// Definition for a Node.
class Node {
public:
    int val;
    vector<Node*> children;
    Node() {}
    Node(int _val) : val(_val) {}
    Node(int _val, vector<Node*> _children)
        : val(_val), children(_children) {}
};
*/
class Codec {
public:
    string serialize(Node* root) {
        if (root == nullptr) return "";
        string out;
        encode(root, out);
        out.pop_back();
        return out;
    }

    Node* deserialize(string data) {
        if (data.empty()) return nullptr;
        vector<int> tokens;
        string token;
        stringstream input(data);
        while (getline(input, token, ',')) {
            tokens.push_back(stoi(token));
        }
        size_t index = 0;
        return decode(tokens, index);
    }

private:
    void encode(Node* node, string& out) {
        out += to_string(node->val) + ",";
        out += to_string(node->children.size()) + ",";
        for (Node* child : node->children) {
            encode(child, out);
        }
    }

    Node* decode(const vector<int>& tokens, size_t& index) {
        int value = tokens[index++];
        int childCount = tokens[index++];
        vector<Node*> children;
        children.reserve(childCount);
        Node* node = new Node(value, children);
        for (int i = 0; i < childCount; ++i) {
            node->children.push_back(decode(tokens, index));
        }
        return node;
    }
};

替代方案

  • 括号语法：例如 1(3(5)(6))(2)(4)。直观，但需要处理转义、括号匹配与负号等词法细节。
  • 层序 + 分组分隔符：队列遍历并在每个父节点的孩子组后写特殊标记。也能达到 O(n)，但解码协议通常更冗长。
  • 父节点编号：为节点分配 ID，记录 (id, parentId, value)。适合流式或数据库场景，但本题中额外元数据较多。
  • 二进制编码：固定宽度或变长整数能减小体积，代价是可读性下降，并需定义字节序和版本。

常见错误

  • 只保存前序值，无法区分“下一个节点是孩子还是兄弟”。
  • 忘记保存孩子顺序，重建出同值但不同语义的树。
  • 用成员下标却未在每次 deserialize 前重置，破坏无状态要求。
  • 循环递归次数写成节点值或剩余标记数，而不是当前节点的孩子数。
  • 反复拼接不可变字符串，可能让序列化退化；应先收集标记再连接。
  • 未考虑高度 1000 对语言递归深度的影响；工程场景可改用显式栈。

面试追问

  • 如何让解码器拒绝截断数据、负孩子数或尾随多余标记？
  • 若节点值可以是字符串，如何设计长度前缀以避免分隔符冲突？
  • 如何加入版本号、校验和，并保持旧格式兼容？
