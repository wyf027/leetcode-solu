LeetCode 986 · Two Pointers

区间列表的交集

两列各自有序、内部互不相交的闭区间同时向前扫描。先观察它们如何相遇，再决定哪一个指针该离开。

中等数组双指针扫描线

题目

给定两个闭区间列表 firstList 与 secondList。每个列表内部的区间按起点递增排列，且两两不相交。返回两个列表覆盖范围的全部交集。

闭区间 [a,b] 包含两个端点；两个区间的重合部分可能为空，也可能是一个点（如 [5,5]）。

函数签名

intervalIntersection(firstList: integer[][], secondList: integer[][]) → integer[][]

约束

  • 0 ≤ firstList.length, secondList.length ≤ 1000
  • 两列表长度之和至少为 1
  • 0 ≤ start < end ≤ 10⁹
  • 同一列表相邻区间满足 endᵢ < startᵢ₊₁

核心洞察

当前区间 A=[a₁,a₂] 与 B=[b₁,b₂] 的潜在交集为 [max(a₁,b₁), min(a₂,b₂)]。只有左端点不大于右端点时，它才真实存在。

比较结束后，右端点更小的区间不可能再与对方当前区间或更早的区间产生新交集，因此移动它对应的指针；右端点相等时移动任意一个即可，代码中同时移动也正确。

完整过程

  1. 令 i=j=0，答案为空。
  2. 当两个指针都未越界，计算重叠候选边界。
  3. 若候选合法，加入答案。
  4. 移动结束更早的区间指针，重复直到某个列表扫描完成。

正确性证明

交集完整性：每轮直接计算当前两区间的最大起点与最小终点，所以若它们相交，恰好记录整个交集。

移动安全性：假设 A 更早结束。B 尚未结束，而后续 B 区间只会开始得更晚，因此 A 与 B 当前或后续未处理区间不可能还有尚未记录的部分；丢弃 A 不会漏解。

终止性：每轮至少有一个指针递增，最终某个列表耗尽。结合移动安全性，此时所有可能交集均已记录。

边界情况

  • 任一列表为空，答案为空。
  • 端点相触属于闭区间交集，例如 [1,5] 与 [5,8] 得到 [5,5]。
  • 完全包含时记录较短的区间，并推进更早结束的一方。
  • 数值可到 10⁹，四种语言的整数类型均足够。

复杂度

设两列表长度为 m,n。时间复杂度 O(m+n)，除返回结果外空间复杂度 O(1)。

替代方案

枚举所有区间对需要 O(mn)；将所有端点做通用扫描线也能完成，但会增加排序和事件处理成本，没有利用输入已排序且内部不相交的结构。

面试追问

  • 若列表内部可能重叠？先分别合并区间，再双指针扫描。
  • 若输入是流？只需保留两侧当前区间，结束更早的一侧继续读取。
  • 若区间是开区间？相交判定需改为 left < right，端点相等不再产生交集。

常见错误

  • 用严格小于判断闭区间，漏掉单点交集。
  • 按起点移动指针；正确依据是哪个区间更早结束。
  • 某列表耗尽后仍继续访问下标。
  • 把答案额外合并，改变题目要求的自然交集序列。

四种语言完整代码

class Solution {
    public int[][] intervalIntersection(int[][] firstList, int[][] secondList) {
        List<int[]> ans = new ArrayList<>();
        int i = 0, j = 0;
        while (i < firstList.length && j < secondList.length) {
            int left = Math.max(firstList[i][0], secondList[j][0]);
            int right = Math.min(firstList[i][1], secondList[j][1]);
            if (left <= right) ans.add(new int[]{left, right});
            if (firstList[i][1] < secondList[j][1]) i++;
            else if (firstList[i][1] > secondList[j][1]) j++;
            else { i++; j++; }
        }
        return ans.toArray(new int[ans.size()][]);
    }
}
