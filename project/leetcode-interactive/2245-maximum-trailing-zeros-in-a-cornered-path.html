转角路径的乘积中
最多能有几个尾随零

Maximum Trailing Zeros in a Cornered Path

一条路径，至多一次转向。寻找乘积末尾最长的一串 0。

免费题参数：grid返回：整数官方题目 ↗
01 / Read the rules

题目与边界

给定 m × n 的正整数矩阵 grid。选择一条由上下左右相邻格子构成的路径：先沿某一水平或竖直方向前进，可以转向一次，转向后只能沿与原来垂直的方向继续。全程不能重复访问格子，也可以不转向。

将路径上所有数相乘，返回所有合法路径中，乘积的十进制表示末尾连续 0 的最大数量。路径可以只包含一个格子。

合法形状

直线或 L 形；反向折返会重复访问格子，多次转弯不合法。

完整约束
  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 105
  • 1 ≤ m × n ≤ 105
  • 1 ≤ grid[i][j] ≤ 1000

官方示例

示例 1

输入：grid = [[23,17,15,3,20],
              [8,1,20,27,11],
              [9,4,6,2,21],
              [40,9,1,10,6],
              [22,7,4,5,3]]
输出：3

一条合法路径经过 15 → 20 → 6 → 1 → 10，乘积为 18000，有 3 个尾随零，且不存在更优路径。超过一次转弯或重复经过格子的路线均无效。

示例 2

输入：grid = [[4,3,2],
              [7,6,1],
              [8,8,8]]
输出：0

无论选择哪一条合法转角路径，其乘积都没有尾随零。

下方收录推导、逐步交互演示与四语言实现。展开后可用键盘 Tab 访问控件，Enter 或空格激活按钮。

题解：分解质因子，枚举拐点

核心洞察

10 = 2 × 5。如果路径上的数总共提供 A 个因子 2、B 个因子 5，那么尾随零数就是 min(A, B)。只累计指数，无须构造可能溢出的乘积。

每个格子贡献的指数都是非负数。把一条合法路径的两条臂延伸到矩阵边界，A 与 B 都不会减少。因此至少存在一条最优路径，其两条臂都延伸到了边界。每个拐点只需要比较左上、左下、右上、右下四种组合。

完整过程与前缀和约定

  1. 逐格分解得到因子 2、5 的个数，分别建立行、列前缀和。
  2. Rp[i][k] 表示第 i 行前 k 格的因子 p 总数；Cp[k][j] 表示第 j 列前 k 格的总数。下标从 0 开始。
  3. 枚举拐点 (i,j)，水平臂包含拐点，竖直臂排除拐点，确保它只计一次。
  4. 四种组合分别求 min(因子 2 总数, 因子 5 总数)，更新全局最大值。

正确性说明

  1. 计数等价：乘积的质因数指数等于各格指数之和。每一对 2 和 5 组成一个 10，故 min(A,B) 精确给出尾随零数。
  2. 延伸不劣：任意 L 形路径的两条臂向各自方向延伸至边界，仍至多转弯一次且不重复访问格子。因子总数只增不减，尾随零数不会降低。
  3. 枚举覆盖：每条延伸后的 L 形路径都对应某个拐点和四种方向组合之一。直线路径可先延长成整行或整列，再在边界端点选择退化臂，或补一条垂直臂，所得候选不劣于原路径。
  4. 候选合法：水平臂与竖直臂仅交于拐点，代码计数时排除竖直臂的拐点。每个候选都是真实合法路径，取最大值既不会低估也不会高估最优解。

边界与数值

  • 1 × 1：竖直臂为空，结果就是唯一格子的 min(v₂,v₅)。
  • 只有一行或一列：允许一条臂为空，扫描仍覆盖最优直线路径。
  • 值为 1：两个指数均为 0；缺少因子 2 或 5 的路径得分为 0。
  • 所有值都是正整数，分解循环不会遇到 0；若放宽为允许 0，必须先重新定义乘积为 0 时的尾随零语义。
  • 每格因子 2 最多 9 个、因子 5 最多 4 个；总指数在本题范围内可用 32 位整数保存，JavaScript Number 也能精确保存。

复杂度

设 V = max(grid[i][j])。分解因子的时间为 O(mn log V)，建表和扫描为 O(mn)，额外空间 O(mn)。本题 V ≤ 1000，分解次数有常数上限，通常记为时间 O(mn)、空间 O(mn)。每个候选只进行常数次前缀和查询。

替代方案

  • 四方向累计数组：直接存每格向左、右、上、下的因子和，组合时减去一次拐点。逻辑直观，时间与空间仍为 O(mn)，但存储常数更大。
  • 逐拐点向四周直接扫描：省去前缀数组，但最坏需要 O(mn(m+n)) 时间，不适合 105 个格子的上限。
  • 列总和加逐行滚动计数：维护当前列上方指数，以及当前行左侧指数，右侧与下侧由总和相减得到。可将额外空间降低到 O(n)，但索引与更新顺序更需谨慎。

常见错误

  • 把每个格子的尾随零直接相加：2 和 5 分居两格也能合成一个尾随零。
  • 直接连乘：即使单格最多 1000，路径乘积仍会快速溢出。
  • 拐点计两次或漏计：统一“水平包含，竖直排除”。
  • 只检查某一种 L 形朝向，或要求一定转弯：都会漏解。
  • 套用一般二维矩形前缀和：本题求的是两条线段的并集，并非整个矩形。

面试追问

  • 为何不用动态规划？至多一个拐点，形状只有四种；前缀和已能直接查询所有候选。
  • 推广到 B 进制？将 B 分解为 ∏pᵢeᵢ，尾随零数为 minᵢ⌊路径中 pᵢ 的总指数 / eᵢ⌋。
  • 如果必须恰好转弯一次？两条臂都需有拐点外的格子，必须过滤退化候选。
  • 允许两次转弯？四种 L 形不再覆盖，必须重新设计形状枚举和计数，不能直接复用正确性结论。

class Solution {
    public int maxTrailingZeros(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] r2 = new int[m][n + 1], r5 = new int[m][n + 1];
        int[][] c2 = new int[m + 1][n], c5 = new int[m + 1][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int x = grid[i][j], a = 0, b = 0;
                while (x % 2 == 0) { a++; x /= 2; }
                while (x % 5 == 0) { b++; x /= 5; }
                r2[i][j + 1] = r2[i][j] + a;
                r5[i][j + 1] = r5[i][j] + b;
                c2[i + 1][j] = c2[i][j] + a;
                c5[i + 1][j] = c5[i][j] + b;
            }
        }
        int answer = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                // 水平臂含拐点，竖直臂不含拐点。
                int[][] h = {
                    {r2[i][j + 1], r5[i][j + 1]},
                    {r2[i][n] - r2[i][j], r5[i][n] - r5[i][j]}
                };
                int[][] v = {
                    {c2[i][j], c5[i][j]},
                    {c2[m][j] - c2[i + 1][j], c5[m][j] - c5[i + 1][j]}
                };
                for (int[] a : h)
                    for (int[] b : v)
                        answer = Math.max(answer, Math.min(a[0] + b[0], a[1] + b[1]));
            }
        }
        return answer;
    }
}

var maxTrailingZeros = function(grid) {
    const m = grid.length, n = grid[0].length;
    const matrix = (r, c) => Array.from({length: r}, () => Array(c).fill(0));
    const r2 = matrix(m, n + 1), r5 = matrix(m, n + 1);
    const c2 = matrix(m + 1, n), c5 = matrix(m + 1, n);
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            let x = grid[i][j], a = 0, b = 0;
            while (x % 2 === 0) { a++; x /= 2; }
            while (x % 5 === 0) { b++; x /= 5; }
            r2[i][j + 1] = r2[i][j] + a;
            r5[i][j + 1] = r5[i][j] + b;
            c2[i + 1][j] = c2[i][j] + a;
            c5[i + 1][j] = c5[i][j] + b;
        }
    }
    let answer = 0;
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            // 水平臂包含拐点；竖直臂不包含拐点。
            const horizontal = [
                [r2[i][j + 1], r5[i][j + 1]],
                [r2[i][n] - r2[i][j], r5[i][n] - r5[i][j]]
            ];
            const vertical = [
                [c2[i][j], c5[i][j]],
                [c2[m][j] - c2[i + 1][j], c5[m][j] - c5[i + 1][j]]
            ];
            for (const [a, b] of horizontal)
                for (const [c, d] of vertical)
                    answer = Math.max(answer, Math.min(a + c, b + d));
        }
    }
    return answer;
};

Python

from typing import List

class Solution:
    def maxTrailingZeros(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        r2 = [[0] * (n + 1) for _ in range(m)]
        r5 = [[0] * (n + 1) for _ in range(m)]
        c2 = [[0] * n for _ in range(m + 1)]
        c5 = [[0] * n for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                x, a, b = grid[i][j], 0, 0
                while x % 2 == 0:
                    a += 1
                    x //= 2
                while x % 5 == 0:
                    b += 1
                    x //= 5
                r2[i][j + 1] = r2[i][j] + a
                r5[i][j + 1] = r5[i][j] + b
                c2[i + 1][j] = c2[i][j] + a
                c5[i + 1][j] = c5[i][j] + b
        answer = 0
        for i in range(m):
            for j in range(n):
                # 水平臂含拐点，竖直臂不含拐点。
                horizontal = (
                    (r2[i][j + 1], r5[i][j + 1]),
                    (r2[i][n] - r2[i][j], r5[i][n] - r5[i][j])
                )
                vertical = (
                    (c2[i][j], c5[i][j]),
                    (c2[m][j] - c2[i + 1][j], c5[m][j] - c5[i + 1][j])
                )
                for a, b in horizontal:
                    for c, d in vertical:
                        answer = max(answer, min(a + c, b + d))
        return answer

class Solution {
public:
    int maxTrailingZeros(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        vector<vector<int>> r2(m, vector<int>(n + 1)), r5 = r2;
        vector<vector<int>> c2(m + 1, vector<int>(n)), c5 = c2;
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                int x = grid[i][j], a = 0, b = 0;
                while (x % 2 == 0) { ++a; x /= 2; }
                while (x % 5 == 0) { ++b; x /= 5; }
                r2[i][j + 1] = r2[i][j] + a;
                r5[i][j + 1] = r5[i][j] + b;
                c2[i + 1][j] = c2[i][j] + a;
                c5[i + 1][j] = c5[i][j] + b;
            }
        }
        int answer = 0;
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                // 水平臂含拐点，竖直臂不含拐点。
                array<array<int, 2>, 2> h = {{
                    {r2[i][j + 1], r5[i][j + 1]},
                    {r2[i][n] - r2[i][j], r5[i][n] - r5[i][j]}
                }};
                array<array<int, 2>, 2> v = {{
                    {c2[i][j], c5[i][j]},
                    {c2[m][j] - c2[i + 1][j], c5[m][j] - c5[i + 1][j]}
                }};
                for (const auto& a : h)
                    for (const auto& b : v)
                        answer = max(answer, min(a[0] + b[0], a[1] + b[1]));
            }
        }
        return answer;
    }
};
