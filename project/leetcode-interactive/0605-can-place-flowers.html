种花问题

605. Can Place Flowers

先读题、再亲手走一遍花坛。完整题解独立收在页面底部，不会在首屏直接展开。

Problem

题目描述

一排花坛由整数数组 flowerbed 表示：0 是空地，1 是已有花朵。任意两朵花不能位于相邻地块。

给定还想种下的花朵数量 n，判断能否在不破坏“不相邻”规则的前提下种完：能则返回 true，否则返回 false。

示例 1

输入：flowerbed = [1,0,0,0,1], n = 1
输出：true

中间三个空位里可以安全选择中心位置。

示例 2

输入：flowerbed = [1,0,0,0,1], n = 2
输出：false

在相同花坛中，合法新增位置不足两个。

约束

  • 1 <= flowerbed.length <= 2 × 104
  • flowerbed[i] 只能是 0 或 1
  • 输入花坛中不存在相邻的两朵花
  • 0 <= n <= flowerbed.length

Greedy Solution

从左到右，能种就种

每次只需检查当前位置和左右邻居。若三者都空，就在当前位置种花，并立刻把数组改成 1。

核心洞察：在最靠左的可行位置种花，不会减少右侧未来可用位置；反而把当前花尽早安置，为右侧留下最大的连续空间。

完整过程

  1. 从索引 0 开始扫描整个 flowerbed。
  2. 若当前格已有花，直接跳过。
  3. 若当前格为空，再检查左邻与右邻。越界邻居按空地处理。
  4. 左右也都为空时，在当前格种花，计数加一，并更新数组。
  5. 一旦计数达到 n 就返回 true；扫描结束仍不足则返回 false。

正确性说明

合法性：算法只在当前格及其左右邻居均为空时种花，所以新种花不会与已有花或先前新种的花相邻。

最优性：考虑扫描到的最左可种位置 i。任何可行方案若没有选 i，其在 i 右侧选中的第一个位置都可以换成 i，不会影响更右侧位置。因此选择 i 不会使可种总数减少。重复此交换即可得到贪心方案，所以它能获得最大新增数量。

边界处理

  • n = 0：无需种花，直接为 true。
  • 数组长度为 1：空地可种一朵，已有花则不可。
  • 首尾位置：缺失的邻居视为空，不需要额外哨兵数组。
  • 成功种花后必须立即写回 1，让后续位置看到它。

时间复杂度

O(m)，其中 m = flowerbed.length。最坏情况下扫描一次数组。

空间复杂度

O(1) 额外空间；算法原地更新输入数组。

提前结束

当新增数量达到 n 时立即返回，实际扫描可能早于数组末尾结束。

替代方案：统计连续零段

也可以按已有花朵切分连续的 0 区间，再用公式计算每段容量。首段、尾段和两朵已有花之间的零段公式不同，边界更容易写错。原地贪心只使用统一的邻居判断，面试中通常更直接。

四语言完整代码

JavaLeetCode 提交格式
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        if (n == 0) {
            return true;
        }

        for (int i = 0; i < flowerbed.length; i++) {
            boolean currentEmpty = flowerbed[i] == 0;
            boolean leftEmpty = i == 0 || flowerbed[i - 1] == 0;
            boolean rightEmpty = i == flowerbed.length - 1
                    || flowerbed[i + 1] == 0;

            if (currentEmpty && leftEmpty && rightEmpty) {
                flowerbed[i] = 1;
                n--;
                if (n == 0) {
                    return true;
                }
            }
        }
        return false;
    }
}

            n--;
            if (n === 0) {
                return true;
            }
        }
    }
    return false;
};

            current_empty = flowerbed[i] == 0
            left_empty = i == 0 or flowerbed[i - 1] == 0
            right_empty = i == len(flowerbed) - 1 or flowerbed[i + 1] == 0

                flowerbed[i] = 1
                n -= 1
                if n == 0:
                    return True

        return False

class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {
        if (n == 0) {
            return true;
        }

        for (int i = 0; i < static_cast<int>(flowerbed.size()); ++i) {
            bool currentEmpty = flowerbed[i] == 0;
            bool leftEmpty = i == 0 || flowerbed[i - 1] == 0;
            bool rightEmpty = i == static_cast<int>(flowerbed.size()) - 1
                    || flowerbed[i + 1] == 0;

            if (currentEmpty && leftEmpty && rightEmpty) {
                flowerbed[i] = 1;
                --n;
                if (n == 0) {
                    return true;
                }
            }
        }
        return false;
    }
};

常见错误

  • 只检查原数组，种花后没有把当前位置更新为 1。
  • 直接访问 i - 1 或 i + 1，造成首尾越界。
  • 把“最多能种”误解为“必须恰好填满所有可种位置”。
  • 遗漏 n = 0，导致本应直接成功却继续扫描。
