距离至少为 K 的交替子序列的最大和

每个元素不是立刻可用：它要等到后方至少 k 个位置。将“延迟入场”与按值查询结合，便能在线求严格上升/下降的最佳前驱。

题意

从 nums 选一个子序列，相邻所选下标间距至少为 k；数值必须严格交替（< > <… 或 > < >…）。返回所选元素之和的最大值。

示例：nums = [3, 5, 4, 2, 4]，k = 1。答案为 14，可选 [3, 5, 2, 4]。

固定演示会显示“何时进入候选池”和当前转移方向；空格无语义，输入均用逗号分隔整数。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

题解：两种末尾方向 + 值域最大值

令 up[i] 表示以 nums[i] 结尾、最后一步上升的最大和，down[i] 类似。单点也可作为两种方向的起点。处理 i 时，只允许 j ≤ i-k。把恰好变得合法的 i-k 状态插入树：up 树用于查询大于当前值的前驱，down 树用于查询小于当前值的前驱。

up = x + max(down[v]) (v < x)；down = x + max(up[v]) (v > x)。若没有前驱，保留单点 x。

边界与复杂度

  • k = n 时没有两点可相连，答案是最大单点。
  • 严格比较：相等值不能转移。
  • 坐标压缩或直接用值域 [1, 100000] 的线段树均可。

时间：O(n log U)；空间：O(n + U)，其中 U 为不同值数量或值域大小。

替代方案 / 面试追问 / 常见错误

  • 值域较小时可以直接建固定线段树；一般数据推荐坐标压缩。
  • 若删掉间距约束，状态入场时刻就是当前步之前，DP 可进一步简化。
  • 不要在计算 i 前把 i 自身插入树，也不要把 </> 写成非严格比较。

class Solution {
  public long maxAlternatingSum(int[] nums, int k) {
    int n = nums.length; int[] a = nums.clone();
    java.util.Arrays.sort(a); int m = 0;
    for (int x : a) if (m == 0 || a[m - 1] != x) a[m++] = x;
    long[] up = new long[n], down = new long[n];
    Seg su = new Seg(m), sd = new Seg(m); long ans = 0;
    for (int i = 0; i < n; i++) {
      if (i >= k) { int p = lower(a, m, nums[i-k]) + 1; su.set(p, up[i-k]); sd.set(p, down[i-k]); }
      int p = lower(a, m, nums[i]) + 1;
      up[i] = Math.max(nums[i], nums[i] + sd.max(1, p - 1));
      down[i] = Math.max(nums[i], nums[i] + su.max(p + 1, m));
      ans = Math.max(ans, Math.max(up[i], down[i]));
    } return ans;
  }
  int lower(int[] a, int n, int x) { int l=0,r=n; while(l<r){int q=(l+r)>>>1;if(a[q]<x)l=q+1;else r=q;}return l; }

from bisect import bisect_left
class Solution:
    def maxAlternatingSum(self, nums: List[int], k: int) -> int:
        vals = sorted(set(nums)); m, n = len(vals), len(nums)
        class Seg:
            def __init__(self): self.t = [0] * (m * 4 + 5)
            def put(self, o, l, r, p, v):
                if l == r: self.t[o] = max(self.t[o], v); return
                q = (l + r) // 2
                if p <= q: self.put(o*2, l, q, p, v)
                else: self.put(o*2+1, q+1, r, p, v)
                self.t[o] = max(self.t[o*2], self.t[o*2+1])
            def get(self, o, l, r, L, R):
                if L > R: return 0
                if L <= l and r <= R: return self.t[o]
                q, z = (l+r)//2, 0
                if L <= q: z = self.get(o*2, l, q, L, R)
                if R > q: z = max(z, self.get(o*2+1, q+1, r, L, R))
                return z
        su, sd, up, down, ans = Seg(), Seg(), [0]*n, [0]*n, 0
        for i, x in enumerate(nums):
            if i >= k:
                p = bisect_left(vals, nums[i-k]) + 1; su.put(1,1,m,p,up[i-k]); sd.put(1,1,m,p,down[i-k])
            p = bisect_left(vals, x) + 1
            up[i] = max(x, x + sd.get(1,1,m,1,p-1)); down[i] = max(x, x + su.get(1,1,m,p+1,m)); ans = max(ans,up[i],down[i])
        return ans
