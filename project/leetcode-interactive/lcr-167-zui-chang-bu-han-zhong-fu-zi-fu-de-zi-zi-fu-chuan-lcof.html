招式拆解 I

给定连招序列 arr，返回其中连续且不含重复字符的最长片段长度。

字符串连续子串长度至多 40000

题意与示例

给定连招序列 arr，返回其中连续且不含重复字符的最长片段长度。字符可以是英文字母、数字、符号或空格。 

arr = "dbascDdad"
输出 = 6
arr = "pwwkew"
输出 = 3，最长片段是 "wke"

约束：0 <= arr.length <= 40000。必须是子串；"pwke" 不连续，不算答案。

题解：记录每个字符的最后位置

核心洞察

窗口为闭区间 [left, right]。每次读到 arr[right]，若该字符上次出现位置不在窗口左侧，就把 left 直接跳到它之后；否则左边界不动。这样每个下标最多被处理常数次。

完整过程

  1. 初始化 left = 0、答案为 0、哈希表记录字符最后位置。
  2. 右端依次扩张；发生窗口内重复时更新 left = last[ch] + 1。
  3. 更新该字符最后位置，拿 right - left + 1 刷新最大值。

边界与复杂度

空串答案是 0；连续三个相同字符答案是 1；空格也与普通字符一样参与重复判断。时间 O(n)，哈希表空间至多为字符集大小。

替代方案、追问与常见错误

也可用集合并逐步删除左端字符，但左边界会一步步移动。最后位置表能一次跳跃。追问：Unicode 代理对可改为按 code point 遍历。常见错误：用 left = last[ch] + 1 却没保证 last 在当前窗口内，导致 left 倒退。

可提交代码

class Solution {
    public int dismantlingAction(String arr) {
        Map<Character, Integer> last = new HashMap<>();
        int left = 0, best = 0;
        for (int right = 0; right < arr.length(); right++) {
            char ch = arr.charAt(right);
            if (last.containsKey(ch)) left = Math.max(left, last.get(ch) + 1);
            last.put(ch, right);
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}
