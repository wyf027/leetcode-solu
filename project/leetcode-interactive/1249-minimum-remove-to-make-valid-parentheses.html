移除无效的括号

在尽量保留原字符串的前提下，删掉最少数量的括号，让所有括号都能正确配对。字母始终保留，合法答案可能不唯一。

SignatureminRemoveToMakeValid(s)

Problem

题意

给定字符串 s，其中只包含 (、) 和小写英文字母。删除任意位置的最少数量括号，使剩余字符串成为有效括号字符串，并返回任意一个可行结果。

有效字符串可以是空串、纯小写字母串、两个有效串的拼接 AB，或由有效串外包一对括号得到的 (A)。

1 ≤ s.length ≤ 10⁵ s[i] ∈ {'(', ')', 'a'…'z'} 答案可能不唯一

官方示例

输入：s = "lee(t(c)o)de)" 输出："lee(t(c)o)de" 说明："lee(t(co)de)"、"lee(t(c)ode)" 也可接受。
输入：s = "a)b(c)d" 输出："ab(c)d"
输入：s = "))((" 输出："" 说明：空字符串也是有效的。

Core Insight

核心洞察：只删除“无法匹配”的括号

遇到右括号时立即判定

如果此前存在尚未匹配的左括号，就让它们配对；否则这个右括号不可能再被后面的字符补救，必须删除。

扫描结束后清理左括号

栈里剩余的左括号没有右括号可配对，也必须删除。字母从不影响平衡，全部保留。

完整过程

  1. 准备标记集合：用布尔数组（或集合）记录最终需要删除的索引；用栈保存尚未匹配的 ( 的索引。
  2. 从左向右扫描：字母跳过；遇到 ( 就把索引压栈。
  3. 处理 )：栈非空时弹出一个左括号完成配对；栈为空时将当前右括号标记删除。
  4. 清空残留：扫描结束后，栈中剩余的索引都是无法配对的左括号，将它们全部标记删除。
  5. 重建答案：再遍历一次原字符串，拼接所有未被标记的字符。

正确性

合法：保留的每个右括号都有一个更早且不同的左括号与之匹配；所有未匹配左括号最终被删除，因此任何前缀都不会右括号过多，整体左右数量也相等。

最少：扫描时栈为空的右括号在其左侧无可用左括号，任何合法结果都必须删掉它；扫描结束仍在栈中的左括号在其右侧无可用右括号，也必须删掉。算法只删除这些必删项。

边界情况

  • 全是字母：原样返回。
  • 全是同向括号：全部删除。
  • 原串已合法：删除集合为空。
  • 答案为空：返回空字符串。
  • 嵌套与并列结构可同时处理。

复杂度

时间：O(n)。扫描与重建各一次。

空间：O(n)。最坏情况下栈、删除标记和结果都与输入等长。

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String minRemoveToMakeValid(String s) {
        boolean[] removed = new boolean[s.length()];
        Deque<Integer> open = new ArrayDeque<>();

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == '(') {
                open.push(i);
            } else if (ch == ')') {
                if (open.isEmpty()) {
                    removed[i] = true;
                } else {
                    open.pop();
                }
            }
        }

        while (!open.isEmpty()) {
            removed[open.pop()] = true;
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            if (!removed[i]) {
                answer.append(s.charAt(i));
            }
        }
        return answer.toString();
    }
}

var minRemoveToMakeValid = function(s) {
    const removed = new Set();
    const open = [];

    for (let i = 0; i < s.length; i++) {
        if (s[i] === '(') {
            open.push(i);
        } else if (s[i] === ')') {
            if (open.length === 0) {
                removed.add(i);
            } else {
                open.pop();
            }
        }
    }

    for (const index of open) {
        removed.add(index);
    }

    const answer = [];
    for (let i = 0; i < s.length; i++) {
        if (!removed.has(i)) {
            answer.push(s[i]);
        }
    }
    return answer.join('');
};
class Solution:
    def minRemoveToMakeValid(self, s: str) -> str:
        removed = set()
        open_indices = []

        for i, ch in enumerate(s):
            if ch == "(":
                open_indices.append(i)
            elif ch == ")":
                if open_indices:
                    open_indices.pop()
                else:
                    removed.add(i)

        removed.update(open_indices)
        return "".join(
            ch for i, ch in enumerate(s)
            if i not in removed
        )

替代方案：两次字符串过滤

第一遍从左到右跳过多余的 )；第二遍从右到左跳过多余的 (。同样是 O(n) 时间，且可以不显式保存索引栈。

权衡：代码可能更短，但第二遍的方向、结果反转以及“究竟还要删除几个左括号”更容易写错。

面试追问

  • 如何证明每个被删括号都是“必删”的？
  • 若要求返回所有最短删除结果，为什么需要 BFS / 回溯与去重？
  • 能否只用计数器完成？若要精确重建，第二遍该怎么做？
  • 输入是流式字符时，哪些决定能在线完成，哪些不能？

常见错误

  • 只删多余右括号：扫描结束忘记删除栈中残留的左括号。
  • 用字符而非索引入栈：重复括号无法定位具体删除位置。
  • 边遍历边从字符串中删除：下标移动导致漏扫，且反复拼接可能退化到 O(n²)。
  • 误删字母：字母不参与括号平衡，始终应该保留。
  • 把某个固定输出当成唯一答案：题目允许多个最优合法字符串。
