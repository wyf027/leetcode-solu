保证文件名唯一

Making File Names Unique — 把“从 1 开始反复试”的朴素过程，压缩成一次沿着候选编号向前跳跃的哈希表状态机。

中等数组哈希表字符串非会员题

Problem

文件系统如何命名？

给定字符串数组 names，按顺序创建同名文件夹。如果某个名字已经存在，就在原始输入名末尾追加 (k)，其中 k 是使新名字不重复的最小正整数。返回每一步实际分配的名称。

函数签名

getFolderNames(names: string[]) → string[]

注意：kaido(1) 只是一个普通字符串。若它也重复，结果可能是 kaido(1)(1)。

约束

  • 1 ≤ names.length ≤ 5 × 10⁴
  • 1 ≤ names[i].length ≤ 20
  • 字符仅含小写字母、数字、圆括号
示例 1无冲突
输入：names = ["pes","fifa","gta","pes(2019)"]
输出：["pes","fifa","gta","pes(2019)"]
示例 2跳过已占用后缀
输入：names = ["gta","gta(1)","gta","avalon"]
输出：["gta","gta(1)","gta(2)","avalon"]
示例 3连续占用
输入：names = ["onepiece","onepiece(1)","onepiece(2)","onepiece(3)","onepiece"]
输出：["onepiece","onepiece(1)","onepiece(2)","onepiece(3)","onepiece(4)"]
示例 4同名重复
输入：names = ["wano","wano","wano","wano"]
输出：["wano","wano(1)","wano(2)","wano(3)"]
示例 5括号仍属于名字
输入：names = ["kaido","kaido(1)","kaido","kaido(1)"]
输出：["kaido","kaido(1)","kaido(2)","kaido(1)(1)"]

Solution

哈希表记录“下次从哪里找”

核心洞察

对每个已经出现的名字 x，映射表不只表示“它存在”，还保存下一次冲突时应从哪个 k 开始尝试。成功分配 x(k) 后，将 x 的起点推进到 k + 1，并把新名字 x(k) 也登记为已占用。

完整过程

  1. 建立哈希表 next 和结果数组 ans。
  2. 若输入名 name 不在表中，直接分配它，并记录 next[name] = 1。
  3. 若它已存在，从 next[name] 取出候选编号 k，构造 name(k)。
  4. 只要候选名仍被占用，就递增 k 并继续尝试。
  5. 找到空闲候选后，更新 next[name] = k + 1，再记录 next[candidate] = 1，最后写入答案。

正确性证明

不重复：未冲突时，哈希表证明原名尚未使用；冲突时，循环仅在候选不在哈希表后停止。因此每次加入答案的名字都未曾出现。

后缀最小：next[name] 之前的所有正整数，要么曾被检查并占用，要么曾被分配后推进了起点。循环从当前最小可能值逐个检查，因此第一个空闲候选使用的就是最小合法 k。

覆盖全部输入：算法按序处理每个元素，且两种情况都恰好追加一个名称，故结果长度与输入相同，并满足每一步的文件系统规则。

复杂度

时间 O(n)（均摊）每个后缀编号一旦被跨过，起点便向前推进；哈希查询均摊 O(1)。字符串构造成本按题目短字符串约束计入常数。
空间 O(n)映射表至多登记每个实际生成的唯一名称，答案也包含 n 个字符串。

边界与常见错误

  • 只有一个名称时，直接原样返回。
  • 输入本身含括号时不能解析或剥离后缀；整个字符串就是基础名称。
  • 找到候选后，既要更新原名的下一起点，也要登记新候选；漏掉后者会允许后续重复。
  • 不要每次都从 1 开始搜索，否则大量同名输入会退化为 O(n²)。
  • 先自增再构造候选容易跳过最小合法编号，应明确循环中 k 的含义。

替代方案与面试追问

替代：集合 + 每次从 1 枚举

实现简单且结果正确，但同一名称重复 n 次时会反复扫描旧后缀，最坏 O(n²)，不适合 5 × 10⁴ 的数据规模。

追问：能否用并查集式跳转？

可以把每个已占用候选指向下一个可能位置并路径压缩。本题用“基础名 → 下一编号”的映射已经足够直观；若后缀搜索规则更复杂，跳转结构更有价值。

追问：并发创建怎么办？

单机哈希表不提供原子性。真实文件系统需要原子创建、锁或唯一约束，并在冲突后重试，否则两个请求可能同时选择相同候选。

追问：哈希表最坏复杂度？

理论上碰撞可让操作退化；面试中通常按均摊 O(1) 分析。若需严格界限，可使用有序映射换取 O(log n) 查询。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public String[] getFolderNames(String[] names) {
        Map<String, Integer> next = new HashMap<>();
        String[] answer = new String[names.length];

        for (int i = 0; i < names.length; i++) {
            String name = names[i];
            if (!next.containsKey(name)) {
                answer[i] = name;
                next.put(name, 1);
                continue;
            }

            int k = next.get(name);
            String candidate = name + "(" + k + ")";
            while (next.containsKey(candidate)) {
                k++;
                candidate = name + "(" + k + ")";
            }

            answer[i] = candidate;
            next.put(name, k + 1);
            next.put(candidate, 1);
        }
        return answer;
    }
}

from typing import List


class Solution:
    def getFolderNames(self, names: List[str]) -> List[str]:
        next_suffix = {}
        answer = []

        for name in names:
            if name not in next_suffix:
                answer.append(name)
                next_suffix[name] = 1
                continue

            k = next_suffix[name]
            candidate = f"{name}({k})"
            while candidate in next_suffix:
                k += 1
                candidate = f"{name}({k})"

            answer.append(candidate)
            next_suffix[name] = k + 1
            next_suffix[candidate] = 1

        return answer
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> getFolderNames(vector<string>& names) {
        unordered_map<string, int> nextSuffix;
        vector<string> answer;
        answer.reserve(names.size());

        for (const string& name : names) {
            if (!nextSuffix.count(name)) {
                answer.push_back(name);
                nextSuffix[name] = 1;
                continue;
            }

            int k = nextSuffix[name];
            string candidate = name + "(" + to_string(k) + ")";
            while (nextSuffix.count(candidate)) {
                ++k;
                candidate = name + "(" + to_string(k) + ")";
            }

            answer.push_back(candidate);
            nextSuffix[name] = k + 1;
            nextSuffix[candidate] = 1;
        }
        return answer;
    }
};
