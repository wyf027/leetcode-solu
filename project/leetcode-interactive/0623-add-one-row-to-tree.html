Problem 623 · Add One Row to Tree

在二叉树中
增加一行

把一排新节点准确插入指定深度，同时保住原有左右子树的方向。先在下方亲手移动步骤，再决定是否展开题解。

01 · Problem

题意与规则

给定二叉树根节点 root、整数 val 与 depth，在深度 depth 插入一整行值为 val 的节点。根节点深度为 1。

插入时必须保持的结构

  • 对深度 depth - 1 的每个非空节点 cur，分别创建一个新左孩子和一个新右孩子，二者值均为 val。
  • cur 原来的左子树，接到新左孩子的左侧。
  • cur 原来的右子树，接到新右孩子的右侧。
  • 若 depth = 1，新建值为 val 的根节点，原树成为它的左子树。

约束

  • 树的节点数：[1, 10⁴]
  • 树的深度：[1, 10⁴]
  • -100 ≤ Node.val ≤ 100
  • -10⁵ ≤ val ≤ 10⁵
  • 1 ≤ depth ≤ 树深度 + 1

示例 1

输入：root = [4,2,6,3,1,5], val = 1, depth = 2
输出：[4,1,1,2,null,null,6,3,1,5]

示例 2

输入：root = [4,2,null,3,1], val = 1, depth = 3
输出：[4,2,null,1,1,3,null,null,1]

04 · Solution

题解：停在父层，再统一改指针

关键并不是抵达 depth，而是停在 depth - 1，这样才能保留旧孩子引用后再接入新节点。

核心洞察

用广度优先搜索逐层推进，队列到达目标父层后停止。对该层每个节点，先保存旧的左右孩子，再创建两个新节点，并把旧左孩子挂到新左节点的左侧、旧右孩子挂到新右节点的右侧。

为什么不能直接覆盖

若先写 cur.left = newNode 却没有保存旧左孩子，原左子树的入口就丢失了。顺序应始终是“保存旧引用 → 新建节点 → 重接旧引用 → 挂回父节点”。

完整过程

  1. 先处理 depth = 1。 新建根节点，把原树设为它的左孩子后直接返回。
  2. 队列从根开始。 按层推进到深度 depth - 1，不再继续向下。
  3. 逐个改造父层节点。 保存 oldLeft、oldRight，创建两个值为 val 的节点。
  4. 保持方向重接。 令新左节点的左孩子为 oldLeft，新右节点的右孩子为 oldRight。
  5. 返回原根。 除了插入位置的四条局部连接，其余结构均未变化。

正确性说明

父层定位正确：BFS 每轮只扩展当前一层，因此循环结束时，队列恰好包含深度 depth - 1 的所有非空节点。

局部结构正确：每个父节点得到两个值为 val 的新孩子，且旧左子树只成为新左节点的左子树、旧右子树只成为新右节点的右子树，完全符合插入规则。

整体结构正确：目标父层之外的连接没有被修改；目标父层中的每个节点都被处理一次，因此新行完整且原树无丢失。特殊情况 depth = 1 由新根分支直接满足。

边界情况

  • depth = 1：新节点成为根，只有左孩子连接原树。
  • depth = 树深度 + 1：在原叶子下方创建新行。
  • 单节点树：可能插到根上方，也可能插到根的下一层。
  • val 可为负数、0，或与已有节点值重复；算法不依赖值的唯一性。
  • 高度可能达到 10⁴，迭代 BFS 可避免递归调用栈过深。

复杂度

O(n)时间：最坏情况下访问插入层以上的全部 n 个节点。
O(w)空间：队列最多保存一层节点，w 为树的最大宽度。

四种语言完整代码

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode addOneRow(TreeNode root, int val, int depth) {
        if (depth == 1) {
            return new TreeNode(val, root, null);
        }

        java.util.ArrayDeque<TreeNode> queue = new java.util.ArrayDeque<>();
        queue.offer(root);

        for (int level = 1; level < depth - 1; level++) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            TreeNode oldLeft = node.left;
            TreeNode oldRight = node.right;

            node.left = new TreeNode(val, oldLeft, null);
            node.right = new TreeNode(val, null, oldRight);
        }
        return root;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @param {number} val
 * @param {number} depth
 * @return {TreeNode}
 */
var addOneRow = function(root, val, depth) {
    if (depth === 1) {
        return new TreeNode(val, root, null);
    }

    const queue = [root];
    let head = 0;

    for (let level = 1; level < depth - 1; level++) {
        const levelEnd = queue.length;
        while (head < levelEnd) {
            const node = queue[head++];
            if (node.left) queue.push(node.left);
            if (node.right) queue.push(node.right);
        }
    }

    const parentEnd = queue.length;
    while (head < parentEnd) {
        const node = queue[head++];
        const oldLeft = node.left;
        const oldRight = node.right;

        node.left = new TreeNode(val, oldLeft, null);
        node.right = new TreeNode(val, null, oldRight);
    }
    return root;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional


class Solution:
    def addOneRow(
        self,
        root: Optional[TreeNode],
        val: int,
        depth: int
    ) -> Optional[TreeNode]:
        if depth == 1:
            return TreeNode(val, root, None)

        queue = deque([root])
        for _ in range(1, depth - 1):
            for _ in range(len(queue)):
                node = queue.popleft()
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

        while queue:
            node = queue.popleft()
            old_left = node.left
            old_right = node.right
            node.left = TreeNode(val, old_left, None)
            node.right = TreeNode(val, None, old_right)

        return root
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* addOneRow(TreeNode* root, int val, int depth) {
        if (depth == 1) {
            return new TreeNode(val, root, nullptr);
        }

        std::queue<TreeNode*> queue;
        queue.push(root);

        for (int level = 1; level < depth - 1; ++level) {
            int size = static_cast<int>(queue.size());
            while (size-- > 0) {
                TreeNode* node = queue.front();
                queue.pop();
                if (node->left) queue.push(node->left);
                if (node->right) queue.push(node->right);
            }
        }

        while (!queue.empty()) {
            TreeNode* node = queue.front();
            queue.pop();
            TreeNode* oldLeft = node->left;
            TreeNode* oldRight = node->right;
            node->left = new TreeNode(val, oldLeft, nullptr);
            node->right = new TreeNode(val, nullptr, oldRight);
        }
        return root;
    }
};

替代方案：深度优先搜索

DFS 也可以：递归到当前深度为 depth - 1 时执行同样的指针重接。它的代码紧凑，额外空间为递归栈 O(h)；但本题树高可达 10⁴，某些语言可能发生栈溢出，因此迭代 BFS 更稳妥。

常见错误

  • 遍历到 depth 才处理，晚了一层。
  • 覆盖孩子指针前没有保存旧引用，导致子树丢失。
  • 把旧左子树接到新左节点的右侧，或把旧右子树接到新右节点的左侧。
  • 忘记单独处理 depth = 1。
  • BFS 处理父层时仍把新节点入队，造成层边界混乱。

面试追问

为什么 BFS 的队列空间不是固定 O(depth)？

队列保存的是一整层节点，层宽可能远大于深度，因此应记为 O(w)，其中 w 是最大层宽；最坏可达 O(n)。

能否原地完成？“原地”是否等于 O(1) 空间？

我们确实直接修改原树连接，但还需要遍历用的队列，因此辅助空间不是 O(1)。此外题目本身要求创建新节点，这些输出节点通常不计入辅助空间。

如果要在指定深度插入不同的值怎么办？

可以把固定的 val 替换为按父节点、左右方向或位置索引计算值的函数；遍历与重接结构不变，只改变新节点的构造参数。
