BFS / 层序遍历

二叉树的右视图

站在二叉树右侧，每层最右边的节点会进入视野。把树按层扫描，记录每一层最后访问的节点即可。

01 / PROBLEM

题意

给定一棵二叉树的根节点 root，返回从右侧能看到的节点值，按从上到下的顺序组成数组。

输入：root = [1,2,3,null,5,null,4]

输出：[1,3,4]

右侧看到的每一层最后一个节点：1 → 3 → 4。

约束

  • 节点总数在 0 到 100 之间。
  • 节点值在 -100 到 100 之间。
  • 空树的右视图是空数组。

    03 / WALKTHROUGH

    完整过程

    1. 1.

      根为空，立刻返回空数组；否则根节点进入队列。

    2. 2.

      记录当前队列长度，它恰好是这一层的节点数。

    3. 3.

      逐个出队，依次将左右孩子加入下一层队列。

    4. 4.

      本层最后一次出队的值，就是该层右视图节点。

    04 / INSIGHT

    核心洞察

    “右视图”不需要真的从右侧绘制树：只要按层从左到右处理，每层的最后一个节点天然就是右侧可见节点。BFS 的队列长度提供了清晰的层边界。

    复杂度

    每个节点入队、出队各一次：时间 O(n)。队列最多容纳最宽的一层：空间 O(w)，最坏 O(n)。

    替代方案

    DFS 先访问右子树，首次到达某个深度时记录节点，也可得到答案；递归栈空间为 O(h)。

    05 / PITFALLS & INTERVIEW

    边界、常见错误与面试追问

    • 空树：先判断 root == null，不要把空节点放入队列。
    • 层边界：循环次数必须在本层开始前固定；不能用会随孩子入队增长的队列长度作条件。
    • 左右顺序：本解法从左到右，因此记录 最后 一个；若 DFS 先右后左，则记录首次到达深度的节点。
    • 追问：左视图只需记录每层第一个节点；锯齿层序遍历则在偶数层反转输出顺序。

    06 / SUBMIT-READY CODE

    四语言官方签名代码

    Java

    class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        if (root == null) return ans;
        Queue<TreeNode> q = new LinkedList<>();
        q.offer(root);
        while (!q.isEmpty()) {
            int size = q.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = q.poll();
                if (node.left != null) q.offer(node.left);
                if (node.right != null) q.offer(node.right);
                if (i == size - 1) ans.add(node.val);
            }
        }
        return ans;
    }
}

  }

};

    Python

    from collections import deque

class Solution:
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        answer, queue = [], deque([root])
        while queue:
            for _ in range(len(queue)):
                node = queue.popleft()
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            answer.append(node.val)
        return answer

    C++

    class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        if (!root) return {};
        vector<int> ans;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int size = q.size();
            TreeNode* node = nullptr;
            while (size--) {
                node = q.front(); q.pop();
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            ans.push_back(node->val);
        }
        return ans;
    }
};
