节点序列的最大得分

Maximum Score of a Node Sequence

四个不同的节点，三条连续的边。找到分数总和最大的合法序列。

先理解规则与示例，再按需展开底部题解和交互实验。

01 / 题目与规则

给定有 n 个节点的无向图，编号为 0…n−1。数组 scores 长度为 n，scores[i] 是节点 i 的分数；edges[i] = [aᵢ, bᵢ] 表示两个节点之间有一条无向边。

选择一个恰好包含 4 个不同节点的有序序列，要求每两个相邻节点之间都有边。返回四个节点分数之和的最大值；如果不存在，返回 -1。不相邻的节点之间可以有额外的边。

参数：maximumScore(scores, edges) → 整数。边没有方向；序列不能重复使用节点。

官方示例 1

scores = [5,2,9,8,4]
edges = [[0,1],[1,2],[2,3],[0,2],[1,3],[2,4]]
输出 = 24

序列 [0,1,2,3] 的得分为 5+2+9+8=24，是最大值。[3,1,2,0] 与 [1,0,2,3] 也达到 24。[0,3,2,4] 不合法，因为 0 与 3 没有直接边。

官方示例 2

scores = [9,20,6,4,11,12]
edges = [[0,3],[5,3],[2,4],[1,3]]
输出 = -1

图由一个三叶星形分量和一个二节点分量组成。任何分量都无法选出四个不重复且依次相连的节点。

完整约束

  • n == scores.length，4 ≤ n ≤ 5 × 10⁴。
  • 1 ≤ scores[i] ≤ 10⁸。
  • 0 ≤ edges.length ≤ 5 × 10⁴，edges[i].length == 2。
  • 0 ≤ aᵢ, bᵢ ≤ n−1，aᵢ ≠ bᵢ。
  • 没有重边。

03 / 独立题解

准备好后展开：推导、交互演示与四语言代码。

核心洞察：固定中间边，两端只留前三名

将序列写成 a → u → v → b。枚举图中的每条边作为 u—v，然后从 u 的邻居选 a，从 v 的邻居选 b。候选需要满足 a ≠ v、b ≠ u、a ≠ b。

对一个端点来说，最多有两个节点因重复而被排除：另一个中间节点和另一侧端点。因此每个节点只需保留按分数从高到低排列的三个邻居编号，每条中间边只组合至多 3 × 3 次。

完整过程
  1. 为每个节点准备一个至多容纳三个邻居的列表。
  2. 遍历无向边 u—v，分别把 v 加入 u 的列表、把 u 加入 v 的列表。每次按分数排序，超过三个就删除最低分邻居。每次只排序至多四项。
  3. 再次遍历边 u—v，对两个列表做笛卡尔积；排除 a == v、b == u 或 a == b 的组合。
  4. 对合法组合计算四个分数之和，更新初始为 -1 的答案。遍历完成后返回答案。


正确性证明
候选合法性：候选列表保证 a—u 与 v—b 存在，中间边 u—v 本身存在；无自环保证 a≠u、b≠v、u≠v，再用三个排除条件就保证四个节点互异。因此每次计入答案的序列都合法。


前三名充分性：取任意最优序列 a—u—v—b。如果 a 不在 u 的前三邻居中，前三中至少一个节点 a′ 不等于 v 或 b，且分数不低于 a；替换后仍合法。如果 a 已在前三中则保持。再看 b：如果它不在 v 的前三邻居中，同样能找到 b′ 避开 u 与当前 a′，且分数不低于 b。替换后两端都在对应候选列表中，总分没有下降。邻居不足三个时全部保留，无需替换。


覆盖与最优性：每个合法序列都有一条中间边，所有边与所有保留端点组合都会被枚举。上面的替换论证说明枚举集合包含一个最优解；结合候选合法性，算法返回且仅返回最优得分。若没有合法候选，答案保持 -1。


复杂度与边界
令 n 为节点数，m 为边数。四份代码都采用增量维护前三名，单次操作为常数时间；预处理 O(n+m)，枚举至多 9m 组，总时间 O(n+m)，额外空间 O(n)（不计输入）。若改为对完整邻接表排序，时间上界会变为 O(n+m log n)，空间 O(n+m)。


  • 空图、星形图、只有三节点的连通分量不一定能形成四节点序列，应返回 -1。
  • 分数相同时可以任选三个不同邻居，不能把相同分数当作同一节点去重。
  • 无向边只作为中间边枚举一次即可，反转序列不会改变得分。
  • 最大总分为 4 × 10⁸，Java / C++ 的 32 位有符号整数与 JavaScript Number 都足够。


替代方案
深度为三条边的 DFS 可以作为小图的朴素思路，但高连接度图会产生大量重复搜索，粗略上界 O(nΔ³)。保存完整邻接表并排序后取前三也正确、容易写，但不如这里每次最多排序四项的方案节省空间和时间。


常见错误
  • 只取最高分的一个或两个邻居：遇到另一个中间节点和端点冲突时，可能漏解。例如 K4 中分数为 [100,90,80,70]，全图只保留前二会丢掉节点 3，无法构成四个不同节点。
  • 只判断 a≠b，忘了 a≠v、b≠u，会把重复经过中间节点的走法当作序列。
  • 给每条边只添加一个方向，破坏无向图的候选集合。
  • 把“长度 4”理解为四条边，或强制非相邻节点之间不能连边。


面试追问
  • 为什么是三个？端点最多有两个禁用节点，保留三个可以保证至少一个可用候选。
  • 如何返回实际路径？更新最大值时同时保存 [a,u,v,b]，额外空间仍为常数。
  • 长度改成五怎么办？本题的单条中间边分解与两节点排除证明不再直接适用，不能照搬“每边九次”的结论。
  • 如果允许负分？前三名替换证明仍成立，但答案须用负无穷与 found 标志区分负分最优解和不存在。

JavaScript
/**
 * @param {number[]} scores
 * @param {number[][]} edges
 * @return {number}
 */
var maximumScore = function(scores, edges) {
    const top = Array.from({length: scores.length}, () => []);
    function add(u, v) {
        top[u].push(v);
        top[u].sort((a, b) => scores[b] - scores[a]);
        if (top[u].length > 3) top[u].pop();
    }
    for (const [u, v] of edges) {
        add(u, v);
        add(v, u);
    }
    let ans = -1;
    for (const [u, v] of edges) {
        for (const a of top[u]) {
            for (const b of top[v]) {
                if (a !== v && b !== u && a !== b) {
                    ans = Math.max(ans,
                        scores[a] + scores[u] + scores[v] + scores[b]);
                }
            }
        }
    }
    return ans;
};


Java
import java.util.*;

class Solution {
    private void add(List<Integer> list, int v, int[] scores) {
        list.add(v);
        list.sort((a, b) -> Integer.compare(scores[b], scores[a]));
        if (list.size() > 3) list.remove(3);
    }

    public int maximumScore(int[] scores, int[][] edges) {
        List<List<Integer>> top = new ArrayList<>();
        for (int i = 0; i < scores.length; i++) {
            top.add(new ArrayList<>());
        }
        for (int[] e : edges) {
            add(top.get(e[0]), e[1], scores);
            add(top.get(e[1]), e[0], scores);
        }
        int ans = -1;
        for (int[] e : edges) {
            int u = e[0], v = e[1];
            for (int a : top.get(u)) {
                for (int b : top.get(v)) {
                    if (a != v && b != u && a != b) {
                        ans = Math.max(ans,
                            scores[a] + scores[u] + scores[v] + scores[b]);
                    }
                }
            }
        }
        return ans;
    }
}

            add(v, u)

                for b in top[v]:

        return ans


C++
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maximumScore(vector<int>& scores, vector<vector<int>>& edges) {
        vector<vector<int>> top(scores.size());
        auto add = [&](int u, int v) {
            top[u].push_back(v);
            sort(top[u].begin(), top[u].end(), [&](int a, int b) {
                return scores[a] > scores[b];
            });
            if (top[u].size() > 3) top[u].pop_back();
        };
        for (const auto& e : edges) {
            add(e[0], e[1]);
            add(e[1], e[0]);
        }
        int ans = -1;
        for (const auto& e : edges) {
            int u = e[0], v = e[1];
            for (int a : top[u]) {
                for (int b : top[v]) {
                    if (a != v && b != u && a != b) {
                        ans = max(ans, scores[a] + scores[u] + scores[v] + scores[b]);
                    }
                }
            }
        }
        return ans;
    }
};
