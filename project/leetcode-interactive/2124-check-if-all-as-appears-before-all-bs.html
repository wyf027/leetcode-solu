Check if All A's Appears Before All B's

一串只有两种字符的队列，是否遵守了先后顺序？

01 / 题目

给定字符串 s，其中只含小写字符 'a' 与 'b'。判断是否每个 'a' 的位置都早于每个 'b'：满足返回 true，否则返回 false。标题中的 A、B 指的是这两个小写字符。

参数：s（string）　返回：boolean　函数：checkString(s)

  • 1 ≤ s.length ≤ 100。
  • s[i] 只能是 'a' 或 'b'。

示例 1

输入：s = "aaabbb"
输出：true

示例 2

输入：s = "abab"
输出：false

示例 3

输入：s = "bbb"
输出：true

字符串中没有 a，不存在违反顺序的 a，因此条件成立。

04 / 想好之后，再看题解

先尝试描述你的判断规则。展开后可逐步观察字符通过顺序闸门。

核心洞察：见过 b 后，不能再遇到 a

合法字符串形如 a*b*，两段都可以为空。扫描时只需要一个布尔量 seenB 记住是否已经见过 b；一旦它为真，后面的 a 就是逆序证据。

完整过程

  1. 初始化 seenB = false，从左到右访问每个字符。
  2. 如果当前字符是 b，令 seenB = true，之后始终保持为真。
  3. 如果当前字符是 a 且 seenB 为真，立即返回 false。
  4. 遍历结束仍未发现逆序，返回 true。

以 s = "abab" 为例：下标 0 的 a 保持初始状态；下标 1 的 b 使标记变为 true；下标 2 的 a 与之前的 b 构成违规，立即返回 false，下标 3 无须读取。

为什么正确

循环不变式：在读取当前字符之前，seenB 当且仅当已扫描前缀中出现过 b；若尚未返回 false，前缀内不存在 b 在 a 之前的逆序。初始空前缀满足此性质。

读取 b 只更新标记，不会新增“较早 b、较晚 a”的配对；读取 a 时，如果标记为真就确实存在较早的 b，所以返回 false 必然正确。否则当前 a 不会构成逆序，不变式继续成立。扫描结束未拒绝意味着全串没有逆序配对，恰好满足题目条件，因此返回 true 正确。

边界与复杂度

  • 全 a、全 b 或长度为 1：均返回 true，不需要两类字符同时存在。
  • ba 是最短反例；合法分界是 ab。
  • 空串不属于官方输入范围；本页编辑器拒绝空串以及其他字符。
  • 时间复杂度 O(n)，最坏读取所有字符；额外空间 O(1)。演示保存轨迹用于回退，所用空间不属于提交算法。

替代方案

寻找相邻子串 "ba"：若存在则返回 false，否则为 true。任意一个较早 b 到较晚 a 的区间中，第一次从 b 段进入 a 的位置必有相邻 ba；反过来，相邻 ba 自然是逆序。JavaScript 可写 return !s.includes("ba");，固定长度模式的扫描时间 O(n)，额外空间 O(1)。

也可以比较最后一个 a 与第一个 b 的位置，但必须先处理某类字符不存在的情况。排序后比较会引入不必要的时间与空间开销。

常见错误

  • 只比较 a 和 b 的数量，忽略字符的位置。
  • 要求至少出现一个 a 和一个 b，误判全 a 或全 b。
  • 见到 b 就立即返回 true；后面仍可能有 a。
  • 遇到 a 把 seenB 清零，丢失前缀信息。
  • 把标题里的大写 A、B 直接写进字符比较，官方输入实际是小写。

面试追问

  • 输入是字符流怎么办？ 只保留 seenB 即可在线判断，遇到违规立即停止。
  • 如何返回一组违规下标？ 保存第一次 b 的下标，遇到后续 a 时返回这两个位置；演示的黄色虚线与红色块即为该证据。
  • 推广到 a、b、c 按序分段？ 给字符定义等级，保存已见最大等级；当前等级更小时拒绝。

四语言完整提交代码

采用官方 checkString 签名；均为待验证实现。

Java

class Solution {
    public boolean checkString(String s) {
        boolean seenB = false;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == 'b') {
                seenB = true;
            } else if (seenB) {
                return false;
            }
        }
        return true;
    }
}
