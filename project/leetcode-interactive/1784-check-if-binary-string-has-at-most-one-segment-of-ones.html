Problem

题目要求

给定一个不含前导零的二进制字符串 s。如果其中由连续 '1' 构成的字段至多有一个，返回 true；否则返回 false。

这里的“字段”指一段极大的连续 '1'：相邻的多个 '1' 属于同一字段，中间一旦被 '0' 隔开，就不能再合并。

Constraints

约束

  • 1 <= s.length <= 100
  • s[i] 只能是 '0' 或 '1'
  • s[0] == '1'，即无前导零

示例 1

输入：s = "1001"
输出：false
解释：存在两个长度为 1 的 '1' 字段。

示例 2

输入：s = "110"
输出：true
解释：只有一个连续的 '1' 字段。

Solution

一次扫描，寻找唯一禁区

核心洞察

答案为 false 当且仅当字符串中出现子串 "01"。 因为字符串保证以 '1' 开头：第一次读到 '0' 后，第一个 1 字段已经结束；此后若再读到 '1'，就必然开启第二个字段。

完整过程

  1. 从左向右查看相邻字符，初始时还处于第一个连续 1 字段。
  2. 若相邻字符是 '0'、'1'，说明 1 字段结束后又出现了新的 1，立即返回 false。
  3. 若扫描结束仍未出现 "01"，所有 1 都集中在开头的一段中，返回 true。

正确性证明

若算法返回 false

算法必然找到了相邻的 "01"。这个 1 前面已有至少一个 1（因为 s[0] = '1'），且中间存在 0，因此它属于第二个 1 字段，题目条件不成立。

若算法返回 true

字符串中不存在 "01"，所以一旦出现 0，后面不可能再出现 1。于是所有 1 连成开头的唯一字段，题目条件成立。

边界情况

  • 长度为 1 的 "1"：只有一个字段，返回 true。
  • 全为 1，如 "1111"：所有位在同一字段中。
  • 若干个 1 后全是 0，如 "111000"：仍只有一个 1 字段。
  • 最短冲突形态 "101"：末尾 1 开启第二个字段。

复杂度

时间 O(n)额外空间 O(1)

四语言完整实现

JavaLeetCode 提交格式
class Solution {
    public boolean checkOnesSegment(String s) {
        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i - 1) == '0'
                    && s.charAt(i) == '1') {
                return false;
            }
        }
        return true;
    }
}

替代方案

  • 内置字符串查找：直接判断 !s.includes("01")，极简但面试中最好说明其逻辑依据。
  • 字段计数：每当当前位为 1 且前一位不存在或为 0 时计数；更通用，但为本题多维护了状态。
  • 正则表达式：检查是否匹配 ^1+0*$；可读性和语言差异使其通常不是首选。

面试追问

  • 若不保证无前导零，"0011100" 应如何判断？
  • 如何统计恰好有多少个 1 字段，而不只是判断至多一个？
  • 输入若是无法一次装入内存的字符流，怎样保持 O(1) 额外空间？

常见错误

  • 只统计 1 的数量；"111" 有三个 1，却只有一个 1 字段。
  • 只检查是否包含 0；"1100" 包含 0，但仍满足条件。
  • 把要找的边界写成 "10"；"10" 只是第一个字段结束，真正违规的是结束后再次出现 1，也就是 "01"。
  • 访问 s[i - 1] 却从 i = 0 开始，造成越界或错误比较。
