Widest Pair of Indices With Equal Range Sum

在两列二进制数据中，找出一个尽可能长的共同区间，让这个区间内两列的总和相等。

先理解区间与宽度，再独立思考。交互推演和实现收在页面底部的题解中。

01 / 题意

给定长度相同、下标从 0 开始的二进制数组 nums1 和 nums2。选取同一对端点 0 ≤ i ≤ j < n，使两数组在闭区间 [i, j] 上的元素和相等。返回满足条件的最大宽度 j - i + 1；若不存在这样的非空区间，返回 0。

要求两段使用相同端点；元素不必逐项相同。宽度是区间元素个数，单个元素也能构成宽度为 1 的答案。

参数与约束

widestPairOfIndices(nums1: integer[], nums2: integer[]) → integer
n == nums1.length == nums2.length
1 ≤ n ≤ 100000
nums1[k], nums2[k] ∈ {0, 1}，其中 0 ≤ k < n

函数名和参数来自本地官方元数据。付费题面字段为空，题意采用独立转述；示例输出与约束参考公开题目资料，题目入口为LeetCode 官方页面。

示例 1 · 多元素区间

nums1 = [1,1,0,1]

输出 = 3

取 [1,3]，两段和都是 2，宽度为 3。全长区间的两段和不同。

04 / 独立题解

准备好后，展开核心思路、动态推演与四语言实现。

核心洞察：两次相同的累计差，夹住一段平衡区间

设 D[t] 表示前 t 个元素的两数组累计和之差，边界 t 的范围为 0 到 n，且 D[0] = 0。闭区间 [i,j] 合法等价于 D[j+1] - D[i] = 0，即两个边界的累计差相同。

D[t] = Σ (nums1[k] - nums2[k])，0 ≤ k < t
D[r] == D[l]  ⇔  [l, r-1] 两段和相等
宽度 = r - l

从左到右扫描右边界 r，只记录每个差值最早出现的边界 l。差值再次出现时，用 r - l 更新最大宽度。最早边界让左端尽量靠左，同一右端的区间因此最长。

完整过程

  1. 初始化差值 d = 0、答案 ans = 0、映射 first = {0 → 0}，保留空前缀。
  2. 扫描边界 r = 1…n，把 nums1[r-1] - nums2[r-1] 加到 d。
  3. 若 d 已出现，计算 r - first[d] 并更新答案；否则记录 first[d] = r。
  4. 旧记录永远不覆盖，扫描结束返回 ans。

累计差最早边界含义

正确性与边界

合法性：每个候选都由两个相同的 D 值构成，因此对应区间的差值和为 0，两数组在该区间上的和必然相等。

最优性：处理右边界 r 时，映射保留了每个差值在此前所有边界中的最小下标。对于任何以 r 结束的合法区间，其左边界都具有差值 D[r]；选择最小下标得到此右端的最大宽度。逐一处理全部右边界后，取最大值就是全局最优。

不变量与终止：初始化记录 D[0]，之后只在差值首次出现时插入，因此最早位置不变量始终成立。循环执行 n 次后终止；若从未遇到重复差值，答案保持为 0。

边界：n = 1 时元素相同返回 1，否则返回 0。全零或两数组完全相同返回 n。空前缀让从下标 0 开始的合法区间被正确发现。累计差可能为负数，映射键必须支持负值。

复杂度

哈希映射实现：期望时间 O(n)，额外空间 O(n)，至多保存 n+1 个差值。这里的 O(n) 时间依赖平均 O(1) 的哈希操作；二进制输入下差值落在 [-n,n]，也可用长度 2n+1 的偏移数组实现确定性 O(n) 时间。

替代方案

  • 逐个左端向右累加两段和：O(n²) 时间、O(1) 额外空间；适合小规模理解，n = 10⁵ 时不可取。
  • 把 n+1 个 (差值, 边界) 排序，每组取最大与最小边界：O(n log n) 时间、O(n) 空间。
  • 偏移数组存 first[d+n]：O(n) 时间和空间；用 -1 表示未出现，first[n] 初始化为 0。

常见错误

  • 覆盖最早边界，导致后续候选宽度变短。
  • 漏掉初始 {0 → 0}，错过从下标 0 开始的区间。
  • 混用元素下标和前缀边界：这里长度是 r-l，不是 r-l+1；对应元素区间是 [l,r-1]。
  • JavaScript 用真值判断位置是否存在，误把边界 0 当作不存在；应使用 Map.has。
  • 只比较逐项相等，忽略 1 与 0 可以跨位置抵消；或套用滑动窗口，而差值包含负数，没有所需的单调性。

面试追问

  • 如果返回具体端点？更新答案时同步保存 [first[d], r-1]，并明确并列答案的选择规则。
  • 如果两段和的差要求为 K？寻找历史差值 d-K 的最早边界。
  • 如果要求合法区间数量？记录差值出现次数，当前差值已有多少次，就新增多少个区间，再累加频次。
  • 如果元素为任意整数？累计差方法依然成立，但需关注整数溢出；Java/C++ 可使用 64 位整数，JavaScript 超安全整数范围需用 BigInt。

四语言完整实现

使用官方函数名 widestPairOfIndices；以下均采用前缀边界 0…n。代码未编译或执行。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int widestPairOfIndices(int[] nums1, int[] nums2) {
        Map<Integer, Integer> first = new HashMap<>();
        first.put(0, 0);
        int diff = 0, answer = 0;
        for (int r = 1; r <= nums1.length; r++) {
            diff += nums1[r - 1] - nums2[r - 1];
            if (first.containsKey(diff)) {
                answer = Math.max(answer, r - first.get(diff));
            } else {
                first.put(diff, r);
            }
        }
        return answer;
    }
}

class Solution:

        first = {0: 0}
        diff = answer = 0
        for r in range(1, len(nums1) + 1):
            diff += nums1[r - 1] - nums2[r - 1]
            if diff in first:
                answer = max(answer, r - first[diff])

        return answer

C++

#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int widestPairOfIndices(vector<int>& nums1, vector<int>& nums2) {
        unordered_map<int, int> first{{0, 0}};
        int diff = 0, answer = 0;
        for (int r = 1; r <= static_cast<int>(nums1.size()); ++r) {
            diff += nums1[r - 1] - nums2[r - 1];
            auto it = first.find(diff);
            if (it != first.end()) {
                answer = max(answer, r - it->second);
            } else {
                first.emplace(diff, r);
            }
        }
        return answer;
    }
};
