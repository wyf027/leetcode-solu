从字符串生成二叉树

Construct Binary Tree from String

MEDIUM · 付费题

题目

给定一个表示二叉树的字符串 s，构造并返回根节点。字符串先写节点的有符号整数值，随后可写一个或两个括号子串，依次表示左、右子树。空树由空字符串表示；若右子树存在而左子树为空，则左侧空括号 () 不能省略。

函数签名：TreeNode str2tree(string s)

示例

#输入输出（层序）说明
1s = "4(2(3)(1))(6(5))"[4,2,6,3,1,5]4 的两个子树分别以 2、6 为根。
2s = "4(2(3)(1))(6(5)(7))"[4,2,6,3,1,5,7]每个非叶节点都有两个子节点。
3s = "-4(2(3)(1))(6(5)(7))"[-4,2,6,3,1,5,7]节点值可以是负数。

约束

  • 0 ≤ s.length ≤ 3 × 10⁴
  • s 由数字、'('、')' 和负号 '-' 组成。
  • 输入格式合法；每个整数可由 1～若干位数字组成，负号只出现在数字开头。

题解：用下标完成递归下降解析

核心洞察

字符串本身就是树的前序序列：先出现根值，再出现至多两个括号包裹的子树。让一个全局下标始终指向尚未消费的字符；一次递归恰好读取一个完整节点子串。

完整过程

  1. 空串直接返回空节点。
  2. 读取可选负号与连续数字，创建当前节点。
  3. 若后续是左括号，跳过它；非空时递归构造左子树，再消费右括号。
  4. 再次用相同逻辑构造右子树。返回当前节点。

正确性

归纳证明：叶子节点只含整数，解析器正确创建它并停在该节点子串末尾。假设解析器能正确构造规模更小的子树；对于当前节点，它先准确读取根值，再按文法顺序递归解析括号中的左、右子树。由归纳假设两棵子树正确，挂接顺序也正确，因此当前整棵树正确。对根调用即得到目标树。

边界

  • 空字符串；单节点与多位数。
  • 负数；只有左子树。
  • 1()(2) 这种显式空左子树。
  • 极度偏斜的树可能使递归栈很深。

复杂度

每个字符至多消费常数次，时间 O(n)；除返回树外，递归栈为 O(h)，最坏 O(n)。

四语言实现

class Solution {
    private int i;
    public TreeNode str2tree(String s) {
        if (s == null || s.isEmpty()) return null;
        i = 0;
        return parse(s);
    }
    private TreeNode parse(String s) {
        int sign = 1, value = 0;
        if (s.charAt(i) == '-') { sign = -1; i++; }
        while (i < s.length() && Character.isDigit(s.charAt(i)))
            value = value * 10 + s.charAt(i++) - '0';
        TreeNode node = new TreeNode(sign * value);
        if (i < s.length() && s.charAt(i) == '(') {
            i++;
            if (s.charAt(i) != ')') node.left = parse(s);
            i++;
        }
        if (i < s.length() && s.charAt(i) == '(') {
            i++;
            if (s.charAt(i) != ')') node.right = parse(s);
            i++;
        }
        return node;
    }
}

class Solution {
    int i = 0;
    TreeNode* parse(const string& s) {
        int sign = 1, value = 0;
        if (s[i] == '-') sign = -1, ++i;
        while (i < s.size() && isdigit(s[i])) value = value * 10 + s[i++] - '0';
        auto* node = new TreeNode(sign * value);
        if (i < s.size() && s[i] == '(') {
            ++i;
            if (s[i] != ')') node->left = parse(s);
            ++i;
        }
        if (i < s.size() && s[i] == '(') {
            ++i;
            if (s[i] != ')') node->right = parse(s);
            ++i;
        }
        return node;
    }
public:

        if (s.empty()) return nullptr;

替代方案

可用栈扫描：遇到数字创建节点，依据栈顶节点尚缺的孩子进行挂接，右括号时弹栈。它避免语言递归深度限制，但空括号与多位负数的状态处理更繁琐。

面试追问

如何避免栈溢出？

用显式栈保存节点及其“下一次应接左还是右”的状态，把递归下降改成迭代状态机。

如何反向序列化？

前序输出值；存在任意孩子时输出左括号内容，右孩子存在时再输出右括号内容。右孩子存在而左孩子为空时必须输出 ()。

常见错误

  • 只读取一位数字，或漏掉负号。
  • 把第二个括号子串仍挂到左孩子。
  • 遇到 () 时错误地递归解析。
  • 递归返回后忘记消费配对的右括号。
