Amount of New Area Painted Each Day

每天绘制新区域的数量

同一条画布，每天一个区间。今天真正增加了多少颜色？

二维整数数组 → 每日新增长度 · 阅读 → 思考 → 展开推演

01 / 题目

把细长画布看成数轴。给定二维整数数组 paint，第 i 天处理 paint[i] = [startᵢ, endᵢ]，只给以前从未涂过的部分上色。返回长度为天数的整数数组 worklog，其中 worklog[i] 表示当天新涂的长度。

天数从 0 开始。用半开区间 [startᵢ,endᵢ) 表示涂色范围；公共端点没有长度，因此相邻区间没有重复面积。

先想一想：今天的范围如果被前几天的涂色共同覆盖，今天还会新增吗？

参数与约束

  • 1 ≤ paint.length ≤ 10⁵
  • paint[i].length = 2
  • 0 ≤ startᵢ < endᵢ ≤ 5 × 10⁴

函数：amountPainted(paint)
参数：paint: integer[][]
返回：integer[]

02 / 官方示例

示例 1 · 相邻再交叠

paint = [[1,4],[4,7],[5,8]]
输出 = [3,3,1]

前两天各新增 3；第 2 天只有 [7,8) 未涂，新增 1。

示例 2 · 填补空隙

paint = [[1,4],[5,8],[4,7]]
输出 = [3,3,1]

前两天各新增 3；第 2 天填上 [4,5)，新增 1。

示例 3 · 完全包含

paint = [[1,5],[2,4]]
输出 = [4,0]

第 0 天新增 4；第 1 天的范围全被覆盖，新增 0。

04 / 独立题解

准备好后，展开推演与四语言实现。

区间覆盖树：跳过已经完成的区域

核心洞察

每个整数单位段 [x,x+1) 长度都是 1。线段树节点管理 [lo,hi)，记录已涂总长度 covered。节点已满时直接跳过；今天完整包含节点时，新增量就是 hi − lo − covered，然后把它标为全满。

本题只有涂色，没有擦除。满节点以后永远提前返回，无需把满标记下传给子节点。子节点可能保留旧值，但不会被读到；部分覆盖节点才需要向下递归并汇总。

完整过程

  1. 令 U 为最大终点，根节点管理 [0,U)，覆盖数组初始为 0。
  2. 按天更新区间。无交集或节点已满，返回 0。
  3. 节点被今日范围完整包含，返回总长减已有覆盖，并把节点标满。
  4. 否则按中点分成左右半区，递归更新，新增量相加；用子节点覆盖量之和更新父节点。
  5. 根调用的返回值就是当天答案。

正确性

不变量：每个可访问节点的覆盖量准确；已满节点下的旧数据不被访问。

无交集不会涂到新区域；已满区间没有空白。完整包含时，总长减已涂量准确计数空白，赋满保持不变量。部分相交时，左右区间互不重叠且合起来为父区间，新增长度与覆盖长度都能相加。由递归归纳，根调用得到当天新增量；按输入顺序处理得到所有天的答案。

复杂度与边界

n 为天数，U = max(endᵢ) ≤ 50000。数组初始化 O(U)。连续区间更新只沿边界展开，完整节点提前返回，每天 O(log U)，总时间 O(U + n log U)；U = 1 时每天 O(1)。辅助空间 O(U)，递归栈 O(log U)，答案另占 O(n)。

  • 重复区间与被多段共同覆盖：新增 0。
  • 相邻区间只共享端点，不重叠。
  • 坐标 0、长度 1、终点 50000 均适用。
  • 单日新增不超过 50000，普通整数足够。

替代方案

  • 逐单位扫描：容易理解，但最坏 O(nU)。
  • 后继并查集：让已涂位置跳到下一处空白，每个单位只新涂一次，适合有限整数坐标。
  • 有序不交区间集合：维护已涂区间并集，适合稀疏坐标，需高效的有序容器。
  • 坐标压缩加线段树：把所有端点拆段，以真实端点差计算长度，适合巨大坐标。

常见错误

  • 将半开区间长度写成 r−l+1。
  • 排序天数或每天清空覆盖状态。
  • 完整包含时漏减已有覆盖。
  • 在检查满节点前读取其过时的子节点。
  • 新增擦除操作后仍省略下传。

面试追问

坐标到 10⁹？ 用端点压缩或动态线段树，长度仍取端点差。

支持擦除或任意区间查询？ 引入可下传的覆盖标记，本题单调涂色的简化不再通用。

为何不能逐个扣除历史区间？ 重叠部分会重复扣除，应维护历史并集。

Java

class Solution {
    private int[] covered;

    private int add(int node, int lo, int hi, int start, int end) {
        if (end <= lo || hi <= start || covered[node] == hi - lo)
            return 0;
        if (start <= lo && hi <= end) {
            int fresh = hi - lo - covered[node];
            covered[node] = hi - lo;
            return fresh;
        }
        int mid = lo + (hi - lo) / 2;
        int fresh = add(node * 2, lo, mid, start, end)
                  + add(node * 2 + 1, mid, hi, start, end);
        covered[node] = covered[node * 2] + covered[node * 2 + 1];
        return fresh;
    }

    public int[] amountPainted(int[][] paint) {
        int limit = 0;
        for (int[] interval : paint) limit = Math.max(limit, interval[1]);
        covered = new int[4 * limit + 5];
        int[] answer = new int[paint.length];
        for (int i = 0; i < paint.length; i++)
            answer[i] = add(1, 0, limit, paint[i][0], paint[i][1]);
        return answer;
    }
}

/**

var amountPainted = function(paint) {
    let limit = 0;
    for (const [, end] of paint) limit = Math.max(limit, end);
    const covered = new Int32Array(4 * limit + 5);

    function add(node, lo, hi, start, end) {
        if (end <= lo || hi <= start || covered[node] === hi - lo)
            return 0;
        if (start <= lo && hi <= end) {
            const fresh = hi - lo - covered[node];
            covered[node] = hi - lo;
            return fresh;
        }
        const mid = lo + Math.floor((hi - lo) / 2);
        const fresh = add(node * 2, lo, mid, start, end)
                    + add(node * 2 + 1, mid, hi, start, end);
        covered[node] = covered[node * 2] + covered[node * 2 + 1];
        return fresh;
    }
    return paint.map(([start, end]) => add(1, 0, limit, start, end));
};

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
    vector<int> covered;

    int add(int node, int lo, int hi, int start, int end) {
        if (end <= lo || hi <= start || covered[node] == hi - lo)
            return 0;
        if (start <= lo && hi <= end) {
            int fresh = hi - lo - covered[node];
            covered[node] = hi - lo;
            return fresh;
        }
        int mid = lo + (hi - lo) / 2;
        int fresh = add(node * 2, lo, mid, start, end)
                  + add(node * 2 + 1, mid, hi, start, end);
        covered[node] = covered[node * 2] + covered[node * 2 + 1];
        return fresh;
    }

public:
    vector<int> amountPainted(vector<vector<int>>& paint) {
        int limit = 0;
        for (const auto& interval : paint) limit = max(limit, interval[1]);
        covered.assign(4 * limit + 5, 0);
        vector<int> answer;
        answer.reserve(paint.size());
        for (const auto& interval : paint)
            answer.push_back(add(1, 0, limit, interval[0], interval[1]));
        return answer;
    }
};
