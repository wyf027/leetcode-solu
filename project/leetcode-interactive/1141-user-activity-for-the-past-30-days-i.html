01 · Problem

题意与数据表

准确转述

给定社交媒体网站的 Activity 活动表。统计截至 2019-07-27（包含当天）的连续 30 天内，每一天的活跃用户数。用户在某天只要发生至少一种有效活动，就算当天活跃一次。

四种活动 open_session、end_session、scroll_down、send_message 都有效。只返回有活跃用户的日期，结果顺序任意。

同一用户同一天可能出现多条活动，原表本身也可能包含重复行；题目要求的是“用户数”，不是“活动行数”。

  • 表中可能存在重复行。
  • 每个会话只属于一个用户。
  • activity_type 只能取题面列出的四个枚举值。
  • 官方元数据未提供额外的行数或数值范围，本文不补造范围。

05 · Solution

准备好再揭晓题解

题解包含 SQL 主方案、证明、复杂度、替代写法与四门通用语言的本地语义参考。

Revealed · Complete Guide

题解：先限定窗口，再按日去重计数

核心洞察

一条活动记录只回答“某用户在某天发生了一次活动”。真正需要计数的键是 (activity_date, user_id)。因此在日期窗口内，对每一天计算不同 user_id 的数量即可。

完整过程

  1. 保留 2019-06-28 到 2019-07-27 的行，两个端点都包含。
  2. 按 activity_date 分组。
  3. 组内使用 COUNT(DISTINCT user_id)，消除同一用户同日的多活动与重复行。
  4. 没有活动的日期不会形成分组，恰好符合输出要求。

官方可提交语言优先

MySQL、PostgreSQL 与 Pandas 是本题官方元数据列出的可提交语言；其余四份代码仅用于在本地用通用集合操作复现同一语义，不能作为本数据库题在 LeetCode 的对应语言提交。

SELECT
    activity_date AS day,
    COUNT(DISTINCT user_id) AS active_users
FROM Activity
WHERE activity_date BETWEEN '2019-06-28' AND '2019-07-27'
GROUP BY activity_date;
SELECT
    activity_date AS day,
    COUNT(DISTINCT user_id) AS active_users
FROM Activity
WHERE activity_date BETWEEN DATE '2019-06-28' AND DATE '2019-07-27'
GROUP BY activity_date;
import pandas as pd

def user_activity(activity: pd.DataFrame) -> pd.DataFrame:
    start = pd.Timestamp('2019-06-28')
    end = pd.Timestamp('2019-07-27')

    within_window = activity[
        activity['activity_date'].between(start, end, inclusive='both')
    ]

    return (
        within_window
        .groupby('activity_date', as_index=False)['user_id']
        .nunique()
        .rename(columns={
            'activity_date': 'day',
            'user_id': 'active_users'
        })
    )
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.HashMap;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Set;

public class UserActivityReference {
    public record Activity(
        int userId,
        int sessionId,
        LocalDate activityDate,
        String activityType
    ) {}

    public record DayCount(LocalDate day, int activeUsers) {}

    public static List<DayCount> userActivity(List<Activity> rows) {
        LocalDate start = LocalDate.of(2019, 6, 28);
        LocalDate end = LocalDate.of(2019, 7, 27);
        Map<LocalDate, Set<Integer>> usersByDay = new HashMap<>();

        for (Activity row : rows) {
            LocalDate day = row.activityDate();
            if (day.isBefore(start) || day.isAfter(end)) {
                continue;
            }
            usersByDay
                .computeIfAbsent(day, ignored -> new HashSet<>())
                .add(row.userId());
        }

        List<DayCount> answer = new ArrayList<>();
        for (Map.Entry<LocalDate, Set<Integer>> entry : usersByDay.entrySet()) {
            answer.add(new DayCount(entry.getKey(), entry.getValue().size()));
        }
        answer.sort(Comparator.comparing(DayCount::day));
        return answer;
    }
}
/**
 * Local semantic reference for the database problem.
 * @param {Array<{user_id:number, session_id:number,
 *   activity_date:string, activity_type:string}>} activity
 * @returns {Array<{day:string, active_users:number}>}
 */
function userActivity(activity) {
  const start = '2019-06-28';
  const end = '2019-07-27';
  const usersByDay = new Map();

  for (const row of activity) {
    const day = row.activity_date;
    if (day < start || day > end) continue;

    if (!usersByDay.has(day)) usersByDay.set(day, new Set());
    usersByDay.get(day).add(row.user_id);
  }

  return [...usersByDay.entries()]
    .sort(([dayA], [dayB]) => dayA.localeCompare(dayB))
    .map(([day, users]) => ({
      day,
      active_users: users.size
    }));
}
from dataclasses import dataclass
from datetime import date
from typing import Iterable

@dataclass(frozen=True)
class Activity:
    user_id: int
    session_id: int
    activity_date: date
    activity_type: str

def user_activity(rows: Iterable[Activity]) -> list[tuple[date, int]]:
    start = date(2019, 6, 28)
    end = date(2019, 7, 27)
    users_by_day: dict[date, set[int]] = {}

    for row in rows:
        if not start <= row.activity_date <= end:
            continue
        users_by_day.setdefault(row.activity_date, set()).add(row.user_id)

    return [
        (day, len(users))
        for day, users in sorted(users_by_day.items())
    ]
#include <algorithm>
#include <map>
#include <set>
#include <string>
#include <utility>
#include <vector>
using namespace std;

struct Activity {
    int userId;
    int sessionId;
    string activityDate; // ISO YYYY-MM-DD
    string activityType;
};

struct DayCount {
    string day;
    int activeUsers;
};

vector<DayCount> userActivity(const vector<Activity>& rows) {
    const string start = "2019-06-28";
    const string end = "2019-07-27";
    map<string, set<int>> usersByDay;

    for (const Activity& row : rows) {
        if (row.activityDate < start || row.activityDate > end) {
            continue;
        }
        usersByDay[row.activityDate].insert(row.userId);
    }

    vector<DayCount> answer;
    for (const auto& [day, users] : usersByDay) {
        answer.push_back({day, static_cast<int>(users.size())});
    }
    return answer;
}

正确性说明

  1. 日期条件只保留目标 30 天中的活动，因此所有被计数的用户日都在合法窗口内。
  2. 对某个日期分组后，DISTINCT user_id 让每个用户至多贡献 1，不受活动次数或重复行影响。
  3. 当天发生至少一条活动的用户必然在该组出现，且会贡献 1。因此计数既不遗漏也不重复，等于该日活跃用户数。

边界情况

  • 2019-06-28 和 2019-07-27 均应包含。
  • 同一用户同日多会话、多活动或完全重复行仍只计 1。
  • 窗口外活动必须排除。
  • 没有任何窗口内记录时，结果为空；无需补出 0。

复杂度

设表中共有 n 行。概念上扫描为 O(n)；分组与去重的实际代价由数据库执行计划、索引和哈希/排序策略决定。中间去重状态最多与窗口内不同的“日期—用户”对数量成正比。

替代方案

可以先在子查询中 SELECT DISTINCT activity_date, user_id，再按日期 COUNT(*)。语义更显式，但主方案更短。若查询终点来自参数，可用方言对应的日期减法动态计算开始日期。

面试追问

  • 若必须补齐活跃用户为 0 的日期，如何生成日期序列并左连接？
  • 若表达到亿级，怎样设计日期与用户相关的复合索引？
  • 若“活跃”只认可某两种 activity_type，应把过滤条件放在哪里？
  • 若需要滚动 30 天活跃用户而不是每日活跃用户，去重键会如何变化？

常见错误

  • 直接 COUNT(user_id)，把活动次数错当成用户数。
  • 使用 > '2019-06-28' 或 < '2019-07-27'，错误排除端点。
  • 按 session 计数；会话不是目标统计实体。
  • 额外生成全部 30 天并输出 0，违背示例说明。
  • 把窗口写成 2019-06-27 至 2019-07-27，实际包含 31 个自然日。
