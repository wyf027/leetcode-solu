1906. 查询差绝对值的最小值

Minimum Absolute Difference Queries

在一段区间中，寻找两个不同数值之间最小的距离。

官方题目 ↗

题目与约束

给定整数数组 nums 和查询数组 queries。每个 queries[i] = [lᵢ, rᵢ] 指定从 0 开始编号、两端都包含的连续子数组。对于每个查询，从子数组中选择两个数值不相等的元素，求差的绝对值的最小值。如果所有元素相同，结果是 -1。按查询顺序返回答案数组 ans。

必须满足两个位置 i < j 且 a[i] ≠ a[j]。例如 [5,2,3,7,2] 的答案是 1，不是重复元素产生的 0。|x| 在 x ≥ 0 时等于 x，否则等于 -x。

  • 2 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 100
  • 1 ≤ queries.length ≤ 2 × 10⁴
  • 0 ≤ lᵢ < rᵢ < nums.length

官方示例

示例 1

nums = [1,3,4,8]
queries = [[0,1],[1,2],[2,3],[0,3]]
输出 = [2,1,4,1]

四个区间分别为 [1,3]、[3,4]、[4,8]、[1,3,4,8]。对应最小差为 2、1、4、1，最后一项由 3 和 4 得到。

示例 2

nums = [4,5,2,2,7,10]
queries = [[2,3],[0,2],[0,5],[3,5]]
输出 = [-1,1,1,3]

[2,2] 中没有不同值，返回 -1；[4,5,2] 和整个数组都由 4 与 5 得到差 1；[2,7,10] 由 7 与 10 得到差 3。

先想一想

重复次数会影响答案吗？面对两万次区间查询，哪些信息值得提前保存？

题解 · 用值域换查询速度

核心洞察

数值仅有 1…100。每个查询只需判断每个值是否存在，再按数值顺序扫描相邻的不同值。重复次数不贡献合法的差 0。

完整过程

  1. pre[i][v] 表示 nums[0…i-1] 中 v 的出现次数，pre[0] 全为 0。
  2. 复制上一行，将当前元素的计数加一，建立前缀计数表。
  3. 区间 [l,r] 中 v 的数量为 pre[r+1][v] − pre[l][v]。
  4. 从 1 扫描到 100，正计数的值与上一个存在值作差，更新最小差。
  5. 若始终没有形成两个不同值，返回 -1。

交互 · 前缀差分扫描仪

使用官方示例 2。每步扫描一个值；格子显示“值 : 区间计数”。青色表示存在，黄色表示当前扫描值。

演示扫描完整的 1…100；可随时暂停。减少动态效果偏好下放慢自动播放。演示不代表四语言代码已验证。

正确性证明

前缀计数相减准确移除 l 之前的元素，保留闭区间 [l,r] 的计数，因此存在性判断正确。设区间不同值排序为 b₁ < … < bₖ。任意非相邻差 bⱼ−bᵢ 都是若干正相邻差之和，不小于其中最小的相邻差，故全局最优必能在相邻不同值之间找到。

扫描时 prev 始终是已扫描的最大存在值，best 始终是已扫描相邻差的最小值。遇到新存在值时更新其与 prev 的差，再更新 prev，保持不变式。扫描结束得到最小合法差；若不足两个不同值，哨兵未变化，返回 -1 正确。

边界与常见错误

  • 全部相等返回 -1；不能把重复值的差 0 当答案。
  • 闭区间要用 r+1，不要漏掉最后一个元素。
  • 每次查询重置 prev 和 best，仅在计数为正时更新 prev。
  • 比较按数值排序后的相邻值，不是数组相邻下标。
  • 前缀行必须复制，不能让多行引用同一个可变数组。
  • 1 与 100 的差为 99，用 101 作哨兵不会冲突。

复杂度

令 U=100，n 为数组长度，q 为查询数。建表 O(nU)，所有查询 O(qU)，合计 O((n+q)U)。辅助空间 O(nU)，输出另占 O(q)。Python 列表存在额外内存开销，应留意平台内存限制。

替代方案

每次截取区间、去重排序，最坏 O(qn log n)，实现简单但难以应对大量查询。每个值保存有序出现下标并二分判断存在，可用 O(n+U) 辅助空间，查询 O(U log n)。值域大时不宜直接建立宽前缀表。

面试追问

支持修改怎么办？可以为每个值维护树状数组。空间不足怎么办？改为出现下标列表与二分。为什么 best=1 可以提前结束？不同整数的正差下界为 1；下面代码保留完整扫描以便统一理解。

Java

class Solution {
    public int[] minDifference(int[] nums, int[][] queries) {
        int[][] pre = new int[nums.length + 1][101];
        for (int i = 0; i < nums.length; i++) {
            pre[i + 1] = pre[i].clone();
            pre[i + 1][nums[i]]++;
        }
        int[] ans = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int l = queries[i][0], r = queries[i][1];
            int prev = -1, best = 101;
            for (int v = 1; v <= 100; v++) {
                if (pre[r + 1][v] > pre[l][v]) {
                    if (prev != -1) best = Math.min(best, v - prev);
                    prev = v;
                }
            }
            ans[i] = best == 101 ? -1 : best;
        }
        return ans;
    }
}

 * @param {number[]} nums
 * @param {number[][]} queries

var minDifference = function(nums, queries) {
    const pre = [new Int32Array(101)];
    for (const x of nums) {
        const row = pre[pre.length - 1].slice();
        row[x]++;
        pre.push(row);
    }
    return queries.map(([l, r]) => {
        let prev = -1, best = 101;
        for (let v = 1; v <= 100; v++) {
            if (pre[r + 1][v] > pre[l][v]) {
                if (prev !== -1) best = Math.min(best, v - prev);
                prev = v;
            }
        }
        return best === 101 ? -1 : best;
    });
};

Python 3

from typing import List

class Solution:
    def minDifference(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        pre = [[0] * 101]
        for x in nums:
            row = pre[-1].copy()
            row[x] += 1
            pre.append(row)
        ans = []
        for l, r in queries:
            prev, best = -1, 101
            for v in range(1, 101):
                if pre[r + 1][v] > pre[l][v]:
                    if prev != -1:
                        best = min(best, v - prev)
                    prev = v
            ans.append(-1 if best == 101 else best)
        return ans

C++

#include <vector>
#include <array>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> minDifference(vector<int>& nums, vector<vector<int>>& queries) {
        vector<array<int, 101>> pre(nums.size() + 1);
        pre[0].fill(0);
        for (int i = 0; i < (int)nums.size(); ++i) {
            pre[i + 1] = pre[i];
            ++pre[i + 1][nums[i]];
        }
        vector<int> ans;
        for (const auto& q : queries) {
            int prev = -1, best = 101;
            for (int v = 1; v <= 100; ++v) {
                if (pre[q[1] + 1][v] > pre[q[0]][v]) {
                    if (prev != -1) best = min(best, v - prev);
                    prev = v;
                }
            }
            ans.push_back(best == 101 ? -1 : best);
        }
        return ans;
    }
};
