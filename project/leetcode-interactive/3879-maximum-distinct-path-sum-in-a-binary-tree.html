3879. 二叉树中的最大不同路径和

把二叉树看作无向图：从每个端点出发，沿着不重复值的简单路径扩张，收集最大的节点值总和。

题意

Premium / 付费题

给定二叉树 root。一条有效路径可从任意节点开始、在任意节点结束；路径上的相邻节点必须有边相连，且所有节点值必须两两不同。返回有效路径的最大节点值总和。

示例 1

root = [2, 2, 1]

输出：3。两枚 2 不能共存，选 2 → 1。

示例 2

root = [1, -2, 5, null, null, 3, 5]

输出：9。可选 1 → 5 → 3。

约束

1 ≤ 节点数 ≤ 1000
-1000 ≤ Node.val ≤ 1000

核心洞察：树边双向化，端点全枚举

树中任意两点的简单路径唯一。把父子关系补成双向邻接后，固定一个起点做 DFS；沿路维护值集合 seen，遇到已出现的值就停止扩张。每抵达一个节点，当前累加和都是一个合法候选答案。由于每一条有效路径至少会在它的某个端点作为起点被枚举到，最大值不会遗漏。

完整过程

  1. 一次 DFS 建无向邻接表，并收集所有节点。
  2. 依次把每个节点设为路径起点。
  3. 递归时跳过父节点和价值已在 seen 中的邻居。
  4. 进入前加入值、返回后删除值，保证分支隔离。

复杂度与边界

最多 n 个起点，每次 DFS 最多触及 n 个节点：时间 O(n²)，额外空间 O(n)（邻接、递归和集合）。全负数时单个最大节点仍是合法非空路径；重复值只限制同一路径，不禁止不同分支分别使用。

替代方案、追问与常见错误

  • 可枚举端点对并检查唯一树路径，但重建路径成本更高；本题 n ≤ 1000 时端点 DFS 更直接。
  • 追问：若节点数远大于 1000，需要结合值域、位集或更复杂的树上路径数据结构优化。
  • 不要套用经典最大路径和的单次树形 DP：不同值约束依赖整条已走路径的上下文。
  • 回溯时必须删除 seen 中的当前值，否则一个分支会污染另一个分支。
