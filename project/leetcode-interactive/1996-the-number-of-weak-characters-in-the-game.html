游戏中弱角色的数量

The Number of Weak Characters in the Game

攻击更高，防御也更高。两个条件必须由同一个对手满足。

01 / 理解任务

谁是弱角色？

输入二维整数数组 properties。每个 properties[i] = [attackᵢ, defenseᵢ] 表示一个角色的攻击值与防御值。若存在另一个角色 j，使 attackⱼ > attackᵢ 且 defenseⱼ > defenseᵢ，角色 i 就是弱角色。返回弱角色的数量，每个角色只计一次。

“严格大于”排除相等：攻击相同或防御相同的两个角色，不能仅凭另一项更高就形成支配关系。

参数与约束

  • properties: integer[][]；返回值：integer。
  • 2 ≤ properties.length ≤ 10⁵。
  • properties[i].length == 2。
  • 1 ≤ attackᵢ, defenseᵢ ≤ 10⁵。

官方示例

EXAMPLE 01
properties = [[5,5],[6,3],[3,6]]

输出：0

攻击与防御各有优劣，没有角色在两个属性上同时严格胜过另一个角色。

EXAMPLE 02
properties = [[2,2],[3,3]]

输出：1

[3,3] 的两项属性都严格高于 [2,2]，因此第一个角色是弱角色。

EXAMPLE 03
properties = [[1,5],[10,4],[4,3]]

输出：1

[10,4] 支配 [4,3]；[1,5] 的防御更高，不被其他角色支配。

02 / 解题实验室

排序后，用最大防御值完成扫描

按攻击降序、同攻击防御升序排列。扫描当前角色前，保存已扫描角色的最大防御 maxDefense。若当前防御 d < maxDefense，就找到一个能在两个维度严格胜出的对手。

关键在同攻击的升序：同一攻击组里先出现的角色防御不超过当前角色，不可能让 d < maxDefense 成立。因此一旦成立，提供更高防御的角色一定来自攻击更高的组。

完整过程

  1. 攻击较大的排前面；攻击相等时，防御较小的排前面。
  2. 初始化 maxDefense = 0，answer = 0。属性为正整数，因此 0 可作为初始值。
  3. 逐个扫描，若 d < maxDefense，答案加一。
  4. 更新 maxDefense = max(maxDefense, d)。
  5. 扫描结束返回 answer。

示例 3 排序为 [10,4] → [4,3] → [1,5]。先把最大防御更新为 4；处理 [4,3] 时 3 < 4，计数为 1；最后 5 不小于 4，把最大防御更新为 5，答案为 1。

正确性证明

循环不变量：扫描每个角色前，maxDefense 是已扫描前缀的最大防御，answer 是前缀中已正确判定的弱角色数量。初始前缀为空，两者为 0，成立。

不会误报：若 d < maxDefense，前缀中存在防御严格更高的角色。它的攻击至少等于当前攻击；但同攻击组内先出现的防御均不大于当前防御，故提供这个更高防御值的角色攻击必然严格更高，确实支配当前角色。

不会漏报：若当前角色被支配，支配者的攻击严格更高，必然已被扫描。其防御严格大于当前防御，所以前缀最大防御也严格大于当前防御，算法一定计数。

更新最大值后不变量继续成立。每个角色恰好被判定一次，结束时答案正确。

边界与常见错误

  • 所有攻击相同：答案是 0，同组不能互相支配。
  • 防御相等：使用 < 而非 <=。
  • 重复角色：分别计数，不能先去重。
  • 攻击和防御都降序会误报，例如 [5,7] 排在 [5,1] 前面。
  • 最大攻击与最大防御可能来自不同角色，不能分别取全局最大值后直接判断。
  • 只比较相邻角色会漏报，需要整个前缀的最大防御。
  • 代码会原地排序；若要保留输入顺序，先复制数组。

复杂度

设角色数为 n，排序 O(n log n)，扫描 O(n)，总时间 O(n log n)。

扫描只用计数和最大值，额外空间为 O(1)。整体空间还包含排序开销：C++ 通常为 O(log n) 栈空间；这里的 Java 对象数组排序与 Python 排序最坏需要 O(n) 辅助空间；JavaScript 取决于引擎，不能承诺整体 O(1)。演示页保存状态的空间不计入提交算法。

替代方案

  • 攻击分组：攻击降序排序，同一攻击组先统一用此前更高攻击组的最大防御判定，再一起更新最大值。组内无需规定防御顺序，时间 O(n log n)。
  • 值域后缀最大值：设攻击上界 U = 100000，保存每种攻击的最大防御，再求后缀最大值。对 [a,d] 查询攻击至少 a + 1 的最大防御是否大于 d。时间 O(n + U)，空间 O(U)。不能从 a 开始查询，否则会混入同攻击角色。
  • 暴力：逐个枚举其他角色，寻找支配者。时间 O(n²)，额外空间 O(1)，不适合十万角色。

面试追问

  • 返回弱角色原始下标？排序前附加原始编号，判弱时收集编号。
  • 返回一个支配者？额外保存产生最大防御的角色编号，判弱时该角色即为见证。
  • 第三种属性也必须严格更高？单个最大值无法表示剩余两维，通常需要排序配合树状数组等范围查询结构。
  • 为什么同攻击要升序？避免同组高防御角色提前进入最大值，制造攻击相等的假支配关系。

Java

import java.util.Arrays;

class Solution {
    public int numberOfWeakCharacters(int[][] properties) {
        Arrays.sort(properties, (a, b) ->
            a[0] == b[0] ? Integer.compare(a[1], b[1])
                         : Integer.compare(b[0], a[0]));
        int maxDefense = 0;
        int answer = 0;
        for (int[] p : properties) {
            if (p[1] < maxDefense) {
                answer++;
            }
            maxDefense = Math.max(maxDefense, p[1]);
        }
        return answer;
    }
}

var numberOfWeakCharacters = function(properties) {
    properties.sort((a, b) => b[0] - a[0] || a[1] - b[1]);
    let maxDefense = 0;
    let answer = 0;
    for (const [, defense] of properties) {
        if (defense < maxDefense) answer++;
        maxDefense = Math.max(maxDefense, defense);
    }
    return answer;
};

class Solution:
    def numberOfWeakCharacters(self, properties: List[List[int]]) -> int:
        properties.sort(key=lambda p: (-p[0], p[1]))
        max_defense = 0
        answer = 0
        for _, defense in properties:
            if defense < max_defense:
                answer += 1
            max_defense = max(max_defense, defense)

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int numberOfWeakCharacters(vector<vector<int>>& properties) {
        sort(properties.begin(), properties.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 if (a[0] != b[0]) return a[0] > b[0];
                 return a[1] < b[1];
             });
        int maxDefense = 0;
        int answer = 0;
        for (const auto& p : properties) {
            if (p[1] < maxDefense) ++answer;
            maxDefense = max(maxDefense, p[1]);
        }
        return answer;
    }
};
