验证回文串 II

给定一个非空字符串，最多删除一个字符，判断它能否成为回文串。第一次失配时，只有删左或删右两种选择。

题意

字符串长度范围为 1 ≤ s.length ≤ 10⁵，仅包含小写英文字母。返回是否能通过删除至多一个字符使其正读和反读相同。

"aba"
true：本身是回文
"abca"
true：删除 b 或 c
"abc"
false：删除一个字符仍不回文

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

交互实验室：首个失配

观察双指针从两端靠拢；失配后分别尝试跳过左字符与右字符。

输入字符串后开始双指针检查。

    核心思路：分叉只发生一次

    左右指针相等时继续收缩。第一次失配 s[left] !== s[right] 时，任何可行方案都必须删除其中一个字符，所以分别验证 [left + 1, right] 与 [left, right - 1] 是否回文；任一成立即可。之后不再需要继续分叉。

    过程与复杂度

    1. 用 left、right 从两端扫描。
    2. 相等则同时向中间移动。
    3. 首次失配时，检查删左或删右后的闭区间。
    4. 两种都失败则返回 false。

    时间 O(n)，额外空间 O(1)。

    可提交代码

    var validPalindrome = function(s) {
  const ok = (l, r) => { while (l < r) if (s[l++] !== s[r--]) return false; return true; };
  let l = 0, r = s.length - 1;
  while (l < r) { if (s[l] !== s[r]) return ok(l + 1, r) || ok(l, r - 1); l++; r--; }
  return true;
};
    class Solution:
    def validPalindrome(self, s: str) -> bool:
        def ok(left, right):
            while left < right:
                if s[left] != s[right]: return False
                left, right = left + 1, right - 1
            return True
        left, right = 0, len(s) - 1
        while left < right:
            if s[left] != s[right]: return ok(left + 1, right) or ok(left, right - 1)
            left, right = left + 1, right - 1
        return True
    class Solution {
    public boolean validPalindrome(String s) {

}

    验证要点

    • 长度 1 的字符串直接成立。
    • 本身回文，不使用删除机会。
    • 首个失配只需尝试删左、删右两条路径。
    • abc 验证两条路径都失败。
