LCR 014MEDIUM滑动窗口

字符串的排列

判断字符串 s2 中是否包含 s1 的某个排列：也就是是否存在一个长度相同、字符频次完全一致的连续子串。

题目转换

排列不关心字符的相对位置，只关心每个字符出现次数。因此在 s2 上维护一个固定长度为 |s1| 的窗口；窗口频次数组与模式串相同即命中。

示例

s1 = "ab"，s2 = "eidbaooo"，其中窗口 "ba" 是 "ab" 的排列。

核心洞察

窗口右移时，只有一个新字符加入、一个旧字符离开。无需重复统计整段字符串，只更新这两个计数并维护“不同计数”的数量。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

窗口演示台

限小写字母；逐步滑动固定窗口。

点击“开始扫描”初始化窗口。

解题过程

  1. 1. 统计 s1 的 26 个字符频次。
  2. 2. 让右边界扩张，把字符加入窗口。
  3. 3. 窗口超过 |s1| 时，左边界字符离开。
  4. 4. 当频次差异为零时，窗口即为一个排列。

边界、复杂度与替代

  • 长度：|s1| > |s2| 时必然返回 false。
  • 重复字母：必须按频次而非集合比较，如 "aab"。
  • 复杂度：时间 O(|s1| + |s2|)，空间 O(26)。
  • 替代：排序每个窗口可行，但每次排序要 O(k log k)，不如增量频次。

四语言实现

频次数组固定为 26。

面试追问与常见错误

面试追问

  • 如果字符集是 Unicode，如何替换 26 长度数组？
  • 如何返回第一个命中排列的起始下标？
  • 如何找所有异位词窗口？

常见错误

  • 把非连续子序列误当成子串。
  • 窗口左移后忘记减少旧字符计数。
  • 仅使用 Set，漏掉重复字符。

建立 need 和 window 频次数组；遍历右指针，窗口长度超过模式串即移除左字符。每当两个数组相等时返回 true；遍历结束仍未命中则返回 false。
