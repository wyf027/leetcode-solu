非递增顺序的
最小子序列

Minimum Subsequence in Non-Increasing Order

贪心数组排序非付费题

Problem brief

题意

给定整数数组 nums，选出一个子序列，使选中元素之和严格大于未选元素之和。若方案不止一个，先选择长度最小的；若长度仍相同，再选择元素总和最大的。最终按非递增顺序返回。

子序列可由原数组删除任意数量的元素得到，不要求连续。题目保证符合条件的最终答案唯一。

函数形式

minSubsequence(nums: integer[]) → list<integer>

约束

  • 1 <= nums.length <= 500
  • 1 <= nums[i] <= 100

Official examples

示例

Example 01
输入：nums = [4,3,10,9,8]
输出：[10,9]
解释：[10,9] 与 [10,8] 都达到最小长度，但 [10,9] 的总和更大。
Example 02
输入：nums = [4,4,7,6,7]
输出：[7,7,6]
解释：[7,7] 的和为 14，只与未选部分的和相等，并非严格大于；加入 6 后才满足条件。

Complete solution

贪心：从最大值开始拿

核心洞察

要用尽量少的元素让选中和超过剩余和，每次都应优先选当前最大的数。这样在选取数量相同的前提下，选中和最大、剩余和最小，也最早跨过严格不等式。

完整过程

  1. 计算数组总和 total。
  2. 把数组按非递增顺序排序。
  3. 从左到右累加到 selected，并把数字加入答案。
  4. 首次满足 selected > total - selected 时停止。

边界

  • 只有一个元素时，该元素本身即为答案。
  • 相等不满足条件，必须使用严格大于。
  • 重复值无需特殊处理；降序遍历自然保留非递增输出。

正确性证明

固定长度最优：对任意长度 k，数组中最大的 k 个元素拥有所有长度为 k 的子序列中的最大总和。

最小长度：若最大的前 k-1 个元素都不能满足条件，则其他任意 k-1 个元素的和只会更小，同样不能满足。因此算法首次成功时的长度最小。

同长度最大和：算法选择的正是该长度下最大的若干元素，所以在所有最短方案中总和最大；降序排序同时保证输出格式。

复杂度

排序耗时 O(n log n)，线性扫描耗时 O(n)；答案外的额外空间取决于排序实现，通常为 O(log n) 到 O(n)。

替代方案

由于 nums[i] ≤ 100，可用长度 101 的计数数组从 100 向下枚举，实现 O(n + 100) 时间与 O(100) 额外空间。但常规排序更直观、也更适合面试沟通。

面试追问

  • 如果允许负数？ 原题的正整数保证“多拿一个数”会让选中和增大；允许负数后仍需重新审视停止策略与是否必须选择非空子序列。
  • 如何避免修改输入？ 复制数组后排序，例如 JavaScript 使用 [...nums].sort(...)。
  • 为什么不需要回溯？ 对固定数量，最大元素集合支配其他选择；贪心有直接交换论证。

常见错误

  • 把判断写成 selected >= remaining，忽略“严格大于”。
  • 升序排序后直接返回，破坏非递增输出要求。
  • 只比较选中和与总和的一半却使用浮点数；直接比较 selected > total - selected 更清晰。
  • 满足条件后仍继续加入元素，使答案不再是最短。

Implementations

四种语言完整代码

JavaList<Integer>
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<Integer> minSubsequence(int[] nums) {
        Arrays.sort(nums);
        int total = 0;
        for (int num : nums) {
            total += num;
        }

        List<Integer> answer = new ArrayList<>();
        int selected = 0;
        for (int i = nums.length - 1; i >= 0; i--) {
            selected += nums[i];
            answer.add(nums[i]);
            if (selected > total - selected) {
                break;
            }
        }
        return answer;
    }
}

/**
 * @param {number[]} nums

var minSubsequence = function(nums) {
    nums.sort((a, b) => b - a);
    const total = nums.reduce((sum, num) => sum + num, 0);
    const answer = [];
    let selected = 0;

    for (const num of nums) {
        selected += num;
        answer.push(num);
        if (selected > total - selected) {
            break;
        }
    }
    return answer;
};
PythonList[int]
from typing import List


class Solution:
    def minSubsequence(self, nums: List[int]) -> List[int]:
        nums.sort(reverse=True)
        total = sum(nums)
        selected = 0
        answer = []

        for num in nums:
            selected += num
            answer.append(num)
            if selected > total - selected:
                break

        return answer

    vector<int> minSubsequence(vector<int>& nums) {
        sort(nums.begin(), nums.end(), greater<int>());
        int total = accumulate(nums.begin(), nums.end(), 0);
        int selected = 0;
        vector<int> answer;
