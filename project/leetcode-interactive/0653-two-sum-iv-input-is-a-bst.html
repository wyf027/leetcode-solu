Solution

中序遍历 + 双指针

核心洞察

二叉搜索树的中序遍历结果严格按节点出现顺序非递减。把所有节点值收集到数组后，问题就变成经典的有序数组两数之和：用左右指针根据当前和与 k 的大小关系单向收缩区间。

指针条件必须是 left < right，从结构上保证使用两个不同节点；即使两个节点值相同，也能被正确配对。

复杂度

O(n)
时间：遍历 + 双指针
O(n)
空间：有序数组；递归栈另为 O(h)

边界清单

  • 只有一个节点时，两个指针不会形成合法区间，返回 false。
  • 节点值和目标值都可能为负数，比较逻辑不受影响。
  • 相同值可以来自两个不同节点，例如两个值均为 3 且 k = 6。
  • 树可能退化成链；递归深度最坏为 O(n)，可改用显式栈中序遍历。

完整过程

中序收集
按“左子树 → 当前节点 → 右子树”遍历 BST，得到有序数组 values。
建立区间
令 left = 0，right = values.length - 1，保证候选节点互不相同。
比较当前和
若和等于 k，立即返回 true；若过小，左指针右移；若过大，右指针左移。
结束判断
当 left >= right 仍未命中，所有可能配对都已排除，返回 false。

正确性证明

  • 有序性：BST 的中序遍历产生非递减数组，因此指针两侧的大小关系确定。
  • 移动安全：若当前和小于 k，固定当前左值时，任何更小的右值只会让和更小，所以当前左值不可能参与答案，可安全舍弃；当前和大于 k 时同理可舍弃当前右值。
  • 完备性：每一步只排除不可能参与答案的一端，若答案存在，它会一直留在闭区间内，直至被两个指针指向。
  • 终止性：每步至少有一个指针向内移动，区间长度严格缩短；命中时返回 true，区间不足两个节点时返回 false。

四语言完整实现

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean findTarget(TreeNode root, int k) {
        List<Integer> values = new ArrayList<>();
        inorder(root, values);

        int left = 0;
        int right = values.size() - 1;
        while (left < right) {
            int sum = values.get(left) + values.get(right);
            if (sum == k) {
                return true;
            }
            if (sum < k) {
                left++;
            } else {
                right--;
            }
        }
        return false;
    }

    private void inorder(TreeNode node, List<Integer> values) {
        if (node == null) {
            return;
        }
        inorder(node.left, values);
        values.add(node.val);
        inorder(node.right, values);
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @param {number} k
 * @return {boolean}
 */
var findTarget = function(root, k) {
    const values = [];

    const inorder = (node) => {
        if (node === null) return;
        inorder(node.left);
        values.push(node.val);
        inorder(node.right);
    };

    inorder(root);
    let left = 0;
    let right = values.length - 1;

    while (left < right) {
        const sum = values[left] + values[right];
        if (sum === k) return true;
        if (sum < k) {
            left += 1;
        } else {
            right -= 1;
        }
    }
    return false;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def findTarget(self, root: Optional[TreeNode], k: int) -> bool:
        values = []

        def inorder(node: Optional[TreeNode]) -> None:
            if node is None:
                return
            inorder(node.left)
            values.append(node.val)
            inorder(node.right)

        inorder(root)
        left, right = 0, len(values) - 1

        while left < right:
            current_sum = values[left] + values[right]
            if current_sum == k:
                return True
            if current_sum < k:
                left += 1
            else:
                right -= 1

        return False
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool findTarget(TreeNode* root, int k) {
        vector<int> values;
        inorder(root, values);

        int left = 0;
        int right = static_cast<int>(values.size()) - 1;
        while (left < right) {
            int sum = values[left] + values[right];
            if (sum == k) {
                return true;
            }
            if (sum < k) {
                ++left;
            } else {
                --right;
            }
        }
        return false;
    }

private:
    void inorder(TreeNode* node, vector<int>& values) {
        if (node == nullptr) {
            return;
        }
        inorder(node->left, values);
        values.push_back(node->val);
        inorder(node->right, values);
    }
};

替代方案与取舍

通用树可用

DFS / BFS + 哈希集合

遍历每个节点前检查 k - node.val 是否已出现。时间 O(n)、空间 O(n)，实现直接，而且不依赖 BST 有序性；但没有利用题目给出的结构特征。

空间进阶

双 BST 迭代器

分别模拟正向与反向中序遍历，让两个迭代器从最小值和最大值向内推进。时间 O(n)、额外空间 O(h)，但实现更复杂，且要用节点身份判断是否相遇。

面试追问

能否做到 O(h) 额外空间？

可以。用两个栈分别实现升序与降序 BST 迭代器，只保留从根到当前节点的路径。

如果不是二叉搜索树怎么办？

中序序列不再有序，不能直接使用双指针；可改用哈希集合配合 DFS 或 BFS。

为什么不能只比较节点值来判断两个指针相遇？

不同节点可能具有相同值。进阶迭代器方案应比较节点身份；数组方案则用不同下标保证节点不同。

常见错误

  • 使用 left <= right，导致同一个节点被使用两次。
  • 当前和过小时误移动右指针，或当前和过大时误移动左指针。
  • 递归中序遍历漏掉空节点终止条件。
  • 看到两个值相等就误判为同一节点；应看下标或节点身份。
  • 在极度偏斜的树上忽略递归栈深度风险。
