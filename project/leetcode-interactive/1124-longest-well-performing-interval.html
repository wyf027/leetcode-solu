01 / PROBLEM

题目是什么？

先建立准确的问题模型，再讨论解法。

题意转述

给定整数数组 hours，其中 hours[i] 表示员工第 i 天工作的小时数。工作时间严格大于 8 小时的日子称为“劳累日”，其余日子称为“不劳累日”。

表现良好的时间段

一段连续日期中，劳累日的数量严格多于不劳累日的数量。

返回所有表现良好的连续时间段中的最大长度；如果不存在，返回 0。

官方参数形式
longestWPI(hours: integer[]) → integer

约束

  • 1 <= hours.length <= 104
  • 0 <= hours[i] <= 16
  • 判断阈值是严格大于 8；恰好 8 小时属于不劳累日。
示例 1
输入：hours = [9,9,6,0,6,6,9] 输出：3

解释：最长的表现良好时间段为 [9,9,6]。

示例 2
输入：hours = [6,6,6] 输出：0

解释：任意连续时间段都没有更多的劳累日。

03 / SOLUTION

前缀平衡 + 最早位置

线性时间，线性空间。

题解导航核心洞察完整过程正确性证明边界与错误四语言代码替代方案与追问

核心洞察

把劳累日记为 +1，不劳累日记为 -1。原问题等价于：寻找和严格大于 0 的最长连续子数组。

关键分岔
  • 若位置 i 的前缀和 score > 0，区间 [0, i] 全部有效，长度是 i + 1。
  • 否则，需要找到更早的前缀和 score - 1。两者相减恰为 1，因此中间区间的和为正。

为了让区间尽可能长，每个前缀和值只记录它第一次出现的位置。

完整过程

  1. 初始化 score = 0、answer = 0 和空映射 first。
  2. 从左到右扫描 hours。若当天工时大于 8，令 score += 1，否则令 score -= 1。
  3. 如果 score > 0，更新 answer = i + 1。
  4. 否则，若映射中存在 score - 1，用 i - first[score - 1] 更新答案。
  5. 若当前 score 从未出现，记录 first[score] = i。绝不覆盖旧位置。
prefix[i] - prefix[j] > 0 ⇔ prefix[j] < prefix[i]
分值每次只变化 ±1，所以最近的更小层级就是 score - 1。

正确性证明

引理 1：对任意区间，将劳累日计为 +1、不劳累日计为 −1 后，区间和大于 0 当且仅当劳累日数量严格多于不劳累日数量。

引理 2：若扫描到位置 i 时 score > 0，则前缀 [0,i] 有效，而且它是所有以 i 结尾区间中的最大可能长度。

引理 3：当 score <= 0 时，若此前出现过 score - 1，从其后一个位置到 i 的区间和为 1，必然有效。取该分值最早出现的位置，使所得区间最长。

完备性：任意最优有效区间若从 0 开始，由引理 2 被覆盖；若不从 0 开始，其左侧前缀分值严格小于右端前缀分值。由于前缀分值逐次变化 ±1，在到达右端分值之前必然经过 score - 1，算法记录的最早位置产生的区间不短于该最优区间。因此算法返回全局最长长度。

边界、复杂度与常见错误

复杂度：每个元素处理一次，时间复杂度 O(n)；映射最多保存 O(n) 个分值，空间复杂度 O(n)。

  • 空答案：所有天都不劳累时返回 0。
  • 全为劳累日：答案就是数组长度。
  • 阈值：hours[i] == 8 必须记为 −1。
  • 严格性：区间和等于 0 不算表现良好。
  • 索引差：映射保存的是前缀扫描到的数组下标，候选长度是 i - first[score - 1]。
  • 不要覆盖首次位置；覆盖后只会缩短未来候选区间。
  • 不要只在映射中找 score，那得到的是和为 0 的区间。

四语言完整代码

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int longestWPI(int[] hours) {
        Map<Integer, Integer> first = new HashMap<>();
        int score = 0;
        int answer = 0;

        for (int i = 0; i < hours.length; i++) {
            score += hours[i] > 8 ? 1 : -1;

            if (score > 0) {
                answer = i + 1;
            } else if (first.containsKey(score - 1)) {
                answer = Math.max(answer, i - first.get(score - 1));
            }

            first.putIfAbsent(score, i);
        }
        return answer;
    }
}

替代方案与面试追问

替代方案：单调栈。先构造长度为 n + 1 的前缀和数组，再建立前缀和严格递减的下标栈；从右向左扫描，当右侧前缀和大于栈顶前缀和时弹栈并更新距离。它同样是 O(n) 时间、O(n) 空间，但哈希表写法更短。

为什么只找 score - 1？因为分值每步变化恰为 ±1。若过去存在任意更小分值，那么在到达当前分值的路径上必然出现过当前分值减 1；使用其最早位置已经足够覆盖最长候选。

如果阈值改成可配置？只需把 hours[i] > 8 替换为 hours[i] > threshold，证明不变。

如果要求劳累日比不劳累日至少多 k 天？目标从区间和大于 0 变为区间和至少为 k，哈希表的单层查找不再直接覆盖所有情况，可考虑维护前缀最小结构或离线排序。
