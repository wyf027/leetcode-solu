划分数组的最少相邻交换次数

把每个数映射成 0 / 1 / 2，答案就是类别序列中的逆序对数。

O(n) 时间 · O(1) 额外空间

题意

给定 nums、a 与 b（a < b）。目标数组依次由三段连续区域组成：小于 a 的数、闭区间 [a, b] 的数、大于 b 的数；任一段可空。一次操作只能交换相邻元素，求最少交换次数（模 1_000_000_007）。

示例 1

nums = [1, 3, 2, 4, 5, 6]
a = 3, b = 4

输出：1。3 与 2 相邻交换一次。

示例 2

nums = [9, 7, 5, 3]
a = 4, b = 8

输出：5。

示例 3

nums = [3, 7, 5, 9]
a = 4, b = 8

输出：0。

约束：1 ≤ nums.length ≤ 10⁵，1 ≤ nums[i], a, b ≤ 10⁹。输入中的空格展示为 ␠；本页数组输入不含空格歧义。

题解

默认收起，先自行观察交互过程。

核心洞察：稳定分组只需消灭“类别逆序”

把 x < a 映射为类别 0，a ≤ x ≤ b 映射为 1，x > b 映射为 2。任何相邻交换每次只能消去一个逆序；按类别稳定地排列 0、1、2 恰好需要所有逆序各交换一次，因此最小答案等于类别逆序对数。组内元素无需互换。

完整过程

  1. 从左到右扫描。
  2. 遇到类别 0：它要跨过左侧所有类别 1 和 2，贡献 count1 + count2。
  3. 遇到类别 1：它要跨过左侧所有类别 2，贡献 count2，再令 count1++。
  4. 遇到类别 2：只令 count2++。
  5. 每次加法对 MOD 取模。

边界与复杂度

三段可以为空，所以全为同一类时答案为 0；边界值 a、b 均属于中间类别。原始答案可能接近 n(n-1)/2，Java/C++ 用 64 位整数。时间 O(n)，额外空间 O(1)。

替代方案与常见错误

冒泡模拟易理解但最坏 O(n²)；Fenwick 树可数一般逆序却是过度设计。常见错误是把 a/b 分到外侧、让同组元素互换、或忘记使用 long / 模数。

面试追问

若类别数变为 k，可维护每个较大类别出现次数（小 k）或用 Fenwick 树统计已见类别（大 k）。若交换成本不再都为 1，则不能直接把逆序数当作答案。
