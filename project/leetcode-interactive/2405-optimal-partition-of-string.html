子字符串的最优划分

Optimal Partition of String

将字符串完整切开，让每一段都没有重复字符。
你能让段数尽可能少吗？

阅读题目打开实验台测试与验证

01 / THE CHALLENGE

题目与输入约定

给定字符串 s，把它按原有顺序划分为若干个非空、连续的子字符串。每段内的字符不能重复，不同段之间可以出现相同字符。所有字符都必须恰好被覆盖一次，不能跳过、重排或重复使用。返回合法划分的最少段数。

官方示例 1

输入：s = "abacaba"
输出：4

可以划分为 ("a", "ba", "cab", "a")，也可以划分为 ("ab", "a", "ca", "ba")。这两种都使用 4 段，且不能得到更少的合法段数。

官方示例 2

输入：s = "ssssss"
输出：6

唯一合法划分是 ("s", "s", "s", "s", "s", "s")，共 6 段。

约束与函数接口

  • 1 ≤ s.length ≤ 100000。
  • s 只包含小写英文字母 a–z。
  • 函数：partitionString(s)；参数 s 为字符串，返回整数段数。

04 / THE EXPLANATION

独立题解

准备好后再展开，包含思路、证明和四种语言的完整实现。

核心洞察：每段延长到不能再延长

从左到右扫描，当前字符没有在当前段出现时直接加入；一旦重复，就必须在它之前结束当前段，再用这个字符开启新段。用集合记录当前段中的字母，而不是整个字符串的历史。

完整过程

  1. 因为字符串非空，初始化答案为 1，当前段集合为空。
  2. 读取字符 c。若集合已包含 c，段数加一并清空集合。
  3. 无论是否切段，都把 c 放入集合。重复字符归属新段，不能丢弃。
  4. 处理所有字符后返回答案。

对 s = "abacaba"：先装入 a, b；遇到 a 切成 ab | a；继续装入 c；下一个 a 触发切段，得到 ab | ac | a；装入 b；最后的 a 再切段，结果为 ab | ac | ab | a，共 4 段。

正确性：贪心边界始终不落后

设贪心第 k 段覆盖到的位置为 gₖ，任意合法划分的第 k 段覆盖到 pₖ，并令 g₀ = p₀ = 0。证明 gₖ ≥ pₖ。

第一段中，贪心取最长的无重复前缀，因此 g₁ ≥ p₁。归纳假设 gₖ₋₁ ≥ pₖ₋₁。如果贪心已经覆盖到 pₖ，结论自然成立；否则，从 gₖ₋₁ + 1 到 pₖ 是另一划分第 k 段的后缀，仍无重复，贪心至少可以延长到 pₖ。所以结论对下一段也成立。

任意合法方案使用 m 段覆盖全串时，贪心在至多 m 段内也能覆盖全串；同时贪心仅在冲突前切段，生成的每段都合法。因此贪心得到最少段数。

边界与复杂度

  • 单字符返回 1；全部不同返回 1；全部相同返回字符串长度。
  • 空字符串不在题目约束内，不额外改变官方接口语义。
  • 最多只有 26 种字母，每段长度不超过 26。每个字符只扫描一次，时间 O(n)，辅助空间 O(26) = O(1)。
  • 清空集合至多涉及 26 个元素，不会让本题变成平方时间。演示为展示历史会重复构造状态，其开销与提交代码不同。

替代方案

位掩码：用 26 位整数表示集合，bit = 1 << (c - 'a')；若 mask & bit 非零则切段并将 mask 清零，再执行 mask |= bit。同为 O(n) 时间、O(1) 空间。JavaScript 位运算使用 32 位有符号整数，本题只用第 0–25 位，足够容纳。

动态规划：令 dp[i] 为前 i 个字符的最少段数，向前枚举无重复后缀并更新 dp[i] = min(dp[j] + 1)。本题后缀最多 26 个字符，时间 O(26n)、空间 O(n)，可行但比贪心多存一张表。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int partitionString(String s) {
        Set<Character> seen = new HashSet<>();
        int parts = 1;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (seen.contains(c)) {
                parts++;
                seen.clear();
            }
            seen.add(c);
        }
        return parts;
    }
}

C++

#include <string>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int partitionString(string s) {
        unordered_set<char> seen;
        int parts = 1;
        for (char c : s) {
            if (seen.count(c)) {
                ++parts;
                seen.clear();
            }
            seen.insert(c);
        }
        return parts;
    }
};

常见错误

  • 只删除重复字母或保留窗口后缀：这里是完整分段，切段后必须清空上一段的全部字母。
  • 清空后忘记加入触发冲突的字符，后续将漏判重复。
  • 把答案初始化为 0，却只在冲突时计数，会漏掉第一段。
  • 使用全局字符集合，错误禁止不同段出现同一字母。
  • 把答案当作最大字符频率。"abacbc" 的最大频率为 2，但最少需要 3 段，字符顺序也影响结果。

面试追问

  • 如何返回划分本身？记录当前段起点，冲突时保存区间，结束后补最后一段；总输出字符数为 O(n)。
  • 能否流式处理？可以，只需保留当前集合和段数，不需要回退或保存完整字符串。
  • 字母表不再是 26 个小写字母？仍可用集合，空间改为 O(min(n, Σ))；Unicode 场景还应明确按码点还是用户感知字符处理。
  • 允许每段同一字符出现至多 k 次？用计数表替代集合，到第 k+1 次时开启新段；合法段的后缀仍合法，同一边界证明仍适用。
  • 每段有不同代价时还成立吗？最少段数的证明不自动覆盖加权代价，需要重新建模，可能使用动态规划。
