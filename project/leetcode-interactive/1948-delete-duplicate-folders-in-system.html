01 / Understand

题目与规则

输入二维字符串数组 paths。每项表示一个文件夹的绝对路径，例如 ["one","two","three"] 对应 /one/two/three。返回清理后仍存在的全部文件夹路径，顺序任意。

  • 两个文件夹必须拥有非空、相同的子文件夹集合，并且同名子文件夹的递归结构完全一致，才属于重复文件夹。
  • 被比较的文件夹本身可以名称不同、深度不同；它们内部对应的子文件夹名称必须相同。
  • 所有重复文件夹以及各自全部后代都要删除。空文件夹不会仅因同为空而单独判重。
只清理一次：先根据原始目录确定所有标记，再统一删除。删除后才变得重复的文件夹必须保留。

约束

  • 1 ≤ paths.length ≤ 2 × 10⁴
  • 1 ≤ paths[i].length ≤ 500
  • 1 ≤ paths[i][j].length ≤ 10
  • 1 ≤ 所有 paths[i][j] 字符串长度之和 ≤ 2 × 10⁵
  • 文件夹名称只含小写英文字母。
  • 路径互不重复。
  • 每个非根层级文件夹的父路径也包含在输入中。

05 / Deeper reasoning
准备好再看题解
先尝试解释：为什么空目录需要特殊处理？为什么删除必须分阶段？


题解 · 为内部结构分配唯一编号


核心洞察
当前目录的名称不进入自己的签名。签名是排序后的 (子目录名, 子目录结构 ID) 列表。先确定孩子的 ID，再确定父目录的 ID。
用完整签名作为字典键，相同签名复用整数 ID，不同签名分配不同 ID。空目录统一使用 0，但不计数；虚拟根不是输入目录，也不参与计数。字典会比较完整键，不依赖裸哈希值没有碰撞的假设。
完整过程
  1. 按路径建树，保存每个节点的创建顺序。
  2. 父节点一定先于孩子创建；逆序扫描即可自底向上处理。
  3. 跳过叶子，将直接孩子按名称排序，构造签名，分配 ID 并累计频次。
  4. 所有统计完成后冻结频次，不修改原树。
  5. 沿每条输入路径检查：只要经过非零且频次大于 1 的 ID，就丢弃该路径；否则保留。


正确性证明
结构归纳：叶子使用同一空结构 ID 0。假设孩子 ID 准确表示结构，那么两个非叶子的排序签名相同，当且仅当子目录名称集合相同、每对同名孩子的 ID 相同。根据归纳假设，这等价于对应子结构全部相同。因此每个 ID 都准确表示内部结构。
标记等价：只有非叶子计数，非零 ID 频次大于 1 恰好满足题意中的非空且重复条件。虚拟根不参与统计。
过滤等价：某路径应被删除，当且仅当自身或祖先被标记。逐段检查正好判断这一条件。全程使用原树的冻结频次，不重新计算，因此不会执行第二次删除。


边界与常见错误
  • 叶子 ID 0 不判重，否则空目录会被错误删除。
  • 不能把当前文件夹名称计入自身签名；/a 与 /c 也可以重复。
  • 不能只比较形状或大小；孩子名称也必须一致。
  • 集合无序，不能依赖输入顺序；需排序或使用有序映射。
  • 不能边统计边删除，也不能反复清理到不再重复。
  • 祖先被删时，自己的结构即使唯一也不能保留。
  • 单文件夹、全部叶子、全部顶层目录被删都自然覆盖。下方代码使用迭代方式，避免深度 500 的递归栈问题。


复杂度
设 N 为真实目录数，T 为输入路径段总数，L 为输入字符串总字符数，dᵥ 为各节点的孩子数。N ≤ T ≤ L，名称长度最多 10。
JavaScript / Python 哈希映射建树与路径过滤期望 O(L)。排序开销 O(Σ dᵥ log dᵥ) ≤ O(N log N)。Python 元组签名只含直接孩子，签名项总量 O(N)，所以期望时间 O(L + N log N)，辅助空间 O(N)，输出另计 O(T)。
Java / C++ 的孩子映射有序，每段查询或插入 O(log N)，输入处理上界 O(L log N)。JavaScript / Java / C++ 将整数编号编码到字符串，每个编号最多 O(log N) 位，全部签名字符占 O(N log N)；相应辅助空间 O(N log N)。JavaScript 期望总时间 O(L + N log N)，Java / C++ 上界 O(L log N + N log N)。输出复制另占 O(T)。这些估计对哈希表使用期望开销。


替代方案
直接拼接整棵子树的递归序列化字符串更直观，但深链上的后代内容会被重复复制。对一般 N 节点树，累计签名长度可能达 O(N²)。ID 驻留法只引用直接孩子。
也可用后序 DFS 替代逆创建顺序；递归需考虑语言栈限制。裸数字哈希较短，但必须考虑碰撞，完整键更容易证明正确。
面试追问
  • 反复清理怎么办？每轮在剩余树上重新计算结构，本题不需要。
  • 为什么逆序可行？每条边的父节点创建序号都小于孩子。
  • 可以保留一个副本吗？不能，所有副本都要删除。
  • 如何保证签名无歧义？JS 用 JSON、Python 用元组。Java / C++ 使用冒号与分号分隔，名称只有字母、编号只有数字，边界不会混淆。

/**
 * @param {string[][]} paths
 * @return {string[][]}
 */
var deleteDuplicateFolder = function(paths) {
    const children = [new Map()];
    for (const path of paths) {
        let cur = 0;
        for (const name of path) {
            if (!children[cur].has(name)) {
                children[cur].set(name, children.length);
                children.push(new Map());
            }
            cur = children[cur].get(name);
        }
    }
    const ids = Array(children.length).fill(0);
    const count = Array(children.length + 1).fill(0);
    const intern = new Map();
    for (let cur = children.length - 1; cur > 0; cur--) {
        if (!children[cur].size) continue;
        const entries = [...children[cur]].sort(([a], [b]) =>
            a < b ? -1 : a > b ? 1 : 0);
        const key = JSON.stringify(entries.map(([name, child]) =>
            [name, ids[child]]));
        if (!intern.has(key)) intern.set(key, intern.size + 1);
        ids[cur] = intern.get(key);
        count[ids[cur]]++;
    }
    return paths.filter(path => {
        let cur = 0;
        for (const name of path) {
            cur = children[cur].get(name);
            if (ids[cur] !== 0 && count[ids[cur]] > 1) return false;
        }
        return true;
    });
};
Java
import java.util.*;

class Solution {
    static class Node {
        Map<String, Node> children = new TreeMap<>();
        int id;
    }
    public List<List<String>> deleteDuplicateFolder(List<List<String>> paths) {
        Node root = new Node();
        List<Node> nodes = new ArrayList<>();
        nodes.add(root);
        for (List<String> path : paths) {
            Node cur = root;
            for (String name : path) {
                if (!cur.children.containsKey(name)) {
                    Node child = new Node();
                    cur.children.put(name, child);
                    nodes.add(child);
                }
                cur = cur.children.get(name);
            }
        }
        Map<String, Integer> intern = new HashMap<>();
        int[] count = new int[nodes.size() + 1];
        for (int i = nodes.size() - 1; i > 0; --i) {
            Node cur = nodes.get(i);
            if (cur.children.isEmpty()) continue;
            StringBuilder key = new StringBuilder();
            for (Map.Entry<String, Node> e : cur.children.entrySet())
                key.append(e.getKey()).append(':')
                   .append(e.getValue().id).append(';');
            String signature = key.toString();
            Integer id = intern.get(signature);
            if (id == null) {
                id = intern.size() + 1;
                intern.put(signature, id);
            }
            cur.id = id;
            count[id]++;
        }
        List<List<String>> answer = new ArrayList<>();
        for (List<String> path : paths) {
            Node cur = root;
            boolean keep = true;
            for (String name : path) {
                cur = cur.children.get(name);
                if (cur.id != 0 && count[cur.id] > 1) {
                    keep = false;
                    break;
                }
            }
            if (keep) answer.add(new ArrayList<>(path));
        }
        return answer;
    }
}
Python
from typing import List

class Solution:
    def deleteDuplicateFolder(self, paths: List[List[str]]) -> List[List[str]]:
        children = [{}]
        for path in paths:
            cur = 0
            for name in path:
                if name not in children[cur]:
                    children[cur][name] = len(children)
                    children.append({})
                cur = children[cur][name]

        ids = [0] * len(children)
        count = [0] * (len(children) + 1)
        intern = {}
        # Parents are created before children: reverse order is bottom-up.
        for cur in range(len(children) - 1, 0, -1):
            if not children[cur]:
                continue
            key = tuple((name, ids[child])
                        for name, child in sorted(children[cur].items()))
            if key not in intern:
                intern[key] = len(intern) + 1
            ids[cur] = intern[key]
            count[ids[cur]] += 1

        answer = []
        for path in paths:
            cur = 0
            for name in path:
                cur = children[cur][name]
                if ids[cur] != 0 and count[ids[cur]] > 1:
                    break
            else:
                answer.append(path[:])
        return answer
C++
#include <map>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
    struct Node {
        map<string, int> children;
        int id = 0;
    };
public:
    vector<vector<string>> deleteDuplicateFolder(vector<vector<string>>& paths) {
        vector<Node> nodes(1);
        for (const auto& path : paths) {
            int cur = 0;
            for (const string& name : path) {
                auto it = nodes[cur].children.find(name);
                if (it == nodes[cur].children.end()) {
                    int child = static_cast<int>(nodes.size());
                    nodes[cur].children.emplace(name, child);
                    nodes.emplace_back();
                    cur = child;
                } else {
                    cur = it->second;
                }
            }
        }
        unordered_map<string, int> intern;
        vector<int> count(nodes.size() + 1);
        for (int i = static_cast<int>(nodes.size()) - 1; i > 0; --i) {
            if (nodes[i].children.empty()) continue;
            string key;
            for (const auto& entry : nodes[i].children)
                key += entry.first + ":" + to_string(nodes[entry.second].id) + ";";
            auto it = intern.find(key);
            if (it == intern.end()) {
                int id = static_cast<int>(intern.size()) + 1;
                it = intern.emplace(key, id).first;
            }
            nodes[i].id = it->second;
            ++count[nodes[i].id];
        }
        vector<vector<string>> answer;
        for (const auto& path : paths) {
            int cur = 0;
            bool keep = true;
            for (const string& name : path) {
                cur = nodes[cur].children.at(name);
                int id = nodes[cur].id;
                if (id != 0 && count[id] > 1) {
                    keep = false;
                    break;
                }
            }
            if (keep) answer.push_back(path);
        }
        return answer;
    }
};
