Find the Longest Valid Obstacle Course at Each Position

每一个位置，都是一次终点。你可以跳过障碍，但必须保持原有顺序，并让选中的高度一路不下降。

先理解规则再手算示例最后展开题解

01 / THE CHALLENGE

题目要你计算什么？

给定从 0 开始编号的整数数组 obstacles，其中 obstacles[i] 是第 i 个障碍的高度。对每个 i，从区间 [0, i] 内挑选若干障碍，求一条必须以第 i 个障碍结束的最长有效路线。

  • 选择的下标必须递增，可以不连续。
  • 相邻选中障碍的高度必须满足：前一个 ≤ 后一个，相等允许。
  • 返回长度为 n 的数组 ans，其中 ans[i] 表示以 i 结束的最长路线长度。

注意区分“前 i + 1 个障碍里的最长路线”和“必须走到 i 的最长路线”。当前高度很低时，当前答案可以变小。

参数与约束

longestObstacleCourseAtEachPosition(obstacles: integer[]) → integer[]
n == obstacles.length
1 ≤ n ≤ 100000
1 ≤ obstacles[i] ≤ 10000000

示例 1 · 允许跨过更高的障碍

输入：obstacles = [1,2,3,2]
输出：[1,2,3,3]

i = 0、1、2 分别可选 [1]、[1,2]、[1,2,3]；i = 3 可跳过高度 3，选下标 [0,1,3]，得到 [1,2,2]，长度为 3。

示例 2 · 相等可以接上，降低可能重来

输入：obstacles = [2,2,1]
输出：[1,2,1]

i = 0 选 [2]；i = 1 选 [2,2]；i = 2 必须包含高度 1，只能选 [1]。长度依次为 1、2、1。

示例 3 · 最优路线不一定唯一

输入：obstacles = [3,1,5,6,4,2]
输出：[1,1,2,3,2,2]

六个终点分别可选 [3]、[1]、[3,5]、[3,5,6]、[3,4]、[1,2]。对应长度为 1、1、2、3、2、2；第三、四、五条也可以分别选 [1,5]、[1,5,6]、[1,4]。

INSIGHT / MINIMUM TAILS

同样长的路线，结尾越低越有用

维护数组 tails：tails[k] 是已处理前缀中，长度恰为 k + 1 的非递减子序列的最小结尾高度。它不是一条实际路线；不同槽位可以来自不同的下标选择。

当前高度为 x 时，寻找第一个 tails[p] > x 的位置 p。前 p 个槽位都 ≤ x，因此 x 能接在长度为 p 的路线后面，得到 ans[i] = p + 1。随后把 tails[p] 替换为 x；如果 p 等于数组长度，就追加 x。

关键是 upper bound：找第一个“严格大于”x 的位置。相等高度仍能延长路线，因此二分遇到 tails[mid] ≤ x 时要向右找。

完整过程

  1. 初始化空的 tails 和答案数组，按下标从左到右扫描，确保只使用过去的障碍。
  2. 对高度 x，在 tails 中设置半开区间 l = 0, r = tails.length。
  3. 当 l < r，取 mid = floor((l + r) / 2)。若 tails[mid] ≤ x，令 l = mid + 1；否则令 r = mid。
  4. 循环结束时 p = l。记录 ans[i] = p + 1，替换或追加 tails[p] = x。
  5. 继续处理下一个障碍，最终返回 ans。

最后一个 2 越过相等的 tails[1]，在原高度 3 的槽位停下。它把长度 3 的路线结尾降低到 2，当前答案仍是 3。

为什么一定正确？

不变量：每个槽位保存真实可达的最小结尾

未处理元素时 tails 为空，不变量成立。长度 k + 1 的非递减路线，去掉末尾就得到长度 k 的路线，其结尾不大于原结尾。所以长度越长，其最小结尾不会更小，tails 必然非递减，可以二分。

当前答案既可达，也无法更长

设 p 为第一个结尾大于 x 的下标。若 p > 0，存在长度 p、结尾为 tails[p−1] ≤ x 的旧路线，接上当前 x 即可得到长度 p + 1。若 p = 0，单独选择 x 得到长度 1。

若存在以 x 结束、长度超过 p + 1 的路线，去掉当前 x 后，旧前缀里就存在长度至少 p + 1 且结尾 ≤ x 的路线。这会要求 tails[p] ≤ x，与 p 的定义矛盾；若 p 位于末尾，则与旧前缀的最长长度矛盾。

更新仍然维护最小值

对长度 ≤ p 的路线，其旧最小结尾已 ≤ x，不能被 x 改善；长度 p + 1 的结尾可被降低为 x，或者新增长度；更长路线无法接上 x。只修改 tails[p] 正好维护全部槽位。归纳可知，每次记录的 ans[i] 都是所求最优值。

复杂度与边界

每个元素做一次 O(log n) 二分，总时间 O(n log n)；tails 最长为 n，额外空间 O(n)，返回数组还需要 O(n) 空间。

  • 单元素：搜索空数组，p = 0，答案为 [1]。
  • 全相等：每次都追加，答案依次为 1 到 n。
  • 严格下降：每次替换第一个槽位，答案全为 1。
  • 严格上升：每次追加，当前答案为 i + 1。
  • 高度达 10⁷、长度达 10⁵：32 位整数足够保存高度和答案，算法不按高度值分配数组。

Java

class Solution {
    public int[] longestObstacleCourseAtEachPosition(int[] obstacles) {
        int n = obstacles.length;
        int[] tails = new int[n];
        int[] ans = new int[n];
        int size = 0;
        for (int i = 0; i < n; i++) {
            int x = obstacles[i];
            int l = 0, r = size;
            while (l < r) {
                int mid = l + (r - l) / 2;
                if (tails[mid] <= x) l = mid + 1;
                else r = mid;
            }
            ans[i] = l + 1;
            tails[l] = x;
            if (l == size) size++;
        }
        return ans;
    }
}

    const ans = [];

    }
    return ans;
};

Python

from bisect import bisect_right
from typing import List

class Solution:
    def longestObstacleCourseAtEachPosition(
        self, obstacles: List[int]
    ) -> List[int]:
        tails = []
        ans = []
        for x in obstacles:
            p = bisect_right(tails, x)
            ans.append(p + 1)
            if p == len(tails):
                tails.append(x)
            else:
                tails[p] = x
        return ans

替代方案

直接动态规划 · 最直观的起点

dp[i] = 1 + max(dp[j])，条件为 j < i 且 obstacles[j] ≤ obstacles[i]；没有候选 j 时最大值按 0 处理。时间 O(n²)、空间 O(n)，适合说明状态含义，但在 n = 10⁵ 时不可取。

离散化 + 树状数组 / 线段树

将高度排序去重后映射为排名。对当前高度排名 rank，查询闭区间 [1, rank] 的最大路线长度，加 1 作为当前答案，再在 rank 处以 max 更新。重复高度必须包含在查询范围内。时间 O(n log n)、空间 O(n)；适合扩展为带权路线等需要更丰富聚合信息的问题。本题只求长度，tails 更简洁。

常见错误

  • 使用 lower bound / bisect_left：相等元素会替换旧位置，[2,2] 就会被误判为 [1,1]。
  • 输出 tails.length：这是前缀里的全局最长长度，不一定以当前 i 结束。[2,2,1] 的最后一项应为 1。
  • 把 tails 直接当作答案或一条路线：它是按长度分类的最小结尾摘要，未保存一条路线的完整下标链。
  • 先排序 obstacles：这会破坏原下标顺序，改变题目。
  • 先写入 x 再搜索：当前元素可能被自己使用，应先根据旧状态求位置再更新。
  • Python 使用 insort 插入：本题应替换或追加；一般位置插入既改变状态含义，也可能使时间退化。

面试追问

如果改成严格递增呢？

改找第一个 ≥ x 的位置，即 lower bound；只有旧结尾 < x 才可以接上。

如何恢复以指定位置结束的一条最长路线？

为每个长度保存最优结尾所在下标 tailIndex；处理 i 时，在覆盖前令 prev[i] = p > 0 ? tailIndex[p−1] : −1，然后更新 tailIndex[p] = i。从指定终点沿 prev 回溯并反转即可。若要输出所有终点的完整路线，输出量最坏会达 O(n²)。

能否在线处理，或支持删除？

追加障碍可以直接在线更新 tails，每次 O(log n)。任意删除会破坏旧状态，tails 摘要不足以直接撤销；需要另行设计数据结构或重新计算。
