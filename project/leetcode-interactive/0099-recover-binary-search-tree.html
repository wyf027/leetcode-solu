输入root = [3,␠1,␠4,␠null,␠null,␠2]

    Morris 中序定位两个错位节点

    核心洞察

    合法 BST 的中序序列严格递增。若两个值被交换，扫描时会出现一到两次 prev.val > current.val：第一次把 prev 记为 first，每一次都把 current 更新为 second，最后交换它们的值。

    为何选择 Morris

    显式栈容易写，但需要 O(h) 空间。Morris 临时把当前节点的中序前驱连回当前节点，因此能在遍历左子树后返回；拆线后结构完全恢复，只保留常数个指针。

    完整过程

    1. 若 current 没有左子树，直接把它当作中序访问点，再走向右子树。
    2. 否则找到左子树最右侧的 predecessor。若它的右指针为空，建立 predecessor → current 的临时线索并转向左子树。
    3. 若 predecessor.right 已指向 current，说明左子树访问完毕：先拆线，再访问 current，然后走向右子树。
    4. 每次访问都比较 prev 与 current；第一次逆序锁定 first=prev，任何逆序都更新 second=current。
    5. 遍历结束后交换 first.val 与 second.val，节点位置和真实边均不变。

    边界

    • 错位值相邻：只有一次逆序，second 仍能正确更新。
    • 错位值不相邻：出现两次逆序，first 保留第一次的较大值，second 更新为最后一次的较小值。
    • 节点值可触及 32 位边界：只比较节点值，不使用哨兵算术。
    • 所有临时线索都必须拆除，不能提前 return。

    复杂度

    时间 O(n)

    额外空间 O(1)

    每条真实边最多被 Morris 寻访常数次。

    替代方案

    显式栈中序：同样按逆序定位，代码更直观，空间 O(h)，面试先写它通常更稳。
    收集数组：最容易理解，但占 O(n) 空间且没有必要。

    面试追问

    • 为什么最多只有两次逆序？
    • 交换节点本身而非数值会怎样？
    • Morris 为什么不会永久破坏树？
    • 若不是“恰好两个值”被交换怎么办？

    常见错误

    • 每次逆序都覆盖 first，丢掉第一处较大值。
    • 只记录一次 second，无法处理非相邻错位。
    • 建立线索后仍访问 current，导致顺序错误。
    • 忘记拆除 predecessor.right，最终树出现环。
