最短独占单词缩写

给定目标词与字典，找出一个只属于目标词、并且长度最短的广义缩写。先理解“缩写为何冲突”，再按自己的节奏打开完整题解。

Problem

题意与规则

给定字符串 target 和字符串数组 dictionary。请返回 target 的一个最短独占缩写：它是目标词的合法广义缩写，却不能成为字典中任何单词的合法缩写。若有多个最短答案，返回任意一个。

  • 1广义缩写可把一个或多个互不重叠的连续片段替换为片段长度，例如 apple → a4。
  • 2相邻数字段应合并；数字表示跳过的字符数，不能表示空片段。
  • 3缩写“长度”按保留字母数 + 数字段数计算。例如 a32bc4 的长度为 4。
  • 4缩写解码后的总长度固定，因此不同长度的原词不会共享同一合法缩写。

约束

  • m == target.length
  • n == dictionary.length
  • 1 ≤ m ≤ 21
  • 0 ≤ n ≤ 1000
  • 1 ≤ dictionary[i].length ≤ 100
  • 所有单词仅含小写英文字母。
  • target 不在 dictionary 中。
官方参数形式：minAbbreviation(target, dictionary) → string
示例 1
Input
target = "apple" dictionary = ["blade"]
Output
"a4"

a4 与 4e 都是长度为 2 的可行答案，返回任意一个。

示例 2
Input
target = "apple" dictionary = ["blade", "plain", "amber"]
Output
"1p3"

保留第二个字符 p 后，三个字典词都无法匹配这个缩写。

Solution

位掩码 × 最小命中集合

核心洞察

用一个 m 位掩码 keep 描述缩写：第 i 位为 1 表示保留 target[i]，为 0 表示让数字段覆盖该位置。

对每个同长度字典词构造差异掩码 diff：第 i 位为 1 当且仅当该词与目标词在位置 i 不同。

缩写能排除 word ⇔ (keep & diff) != 0

只要保留至少一个二者不同的位置，字典词就无法匹配该缩写。问题因此转化为：寻找一个掩码，命中所有差异集合，同时让“保留字母数 + 连续 0 段数”最小。

完整过程

  1. 长度过滤：只保留长度等于目标词的字典词。
  2. 建立差异掩码：逐位置比较目标与字典词；若防御性地发现零掩码，说明目标本身在字典中，无解。
  3. 缩小可选位：把全部差异掩码按位或为 useful；从未产生差异的位置不可能帮助区分。
  4. 定向回溯：选一个尚未被当前 keep 命中的 diff。任何可行扩展都必须从这个 diff 里选至少一位，逐位分支不会漏解。
  5. 分支限界：若当前缩写长度已不优于最优答案，则剪枝；增加保留位不会让长度变小。
  6. 渲染：扫描目标词，1 位输出原字符，连续 0 位累积为数字。
长度定义：每个保留字符贡献 1，每段连续省略贡献 1；跳过 12 个字符依然只是一个数字段。

正确性证明

1
冲突判定充要。若 keep & diff != 0，至少一个被保留字符不同，字典词不能匹配。若交集为 0，所有保留字符相同，而省略段只约束长度，所以该词也能生成同一缩写。
2
搜索完备。对任一未命中的 diff，每个最终可行解都必须选择其中至少一位。算法遍历这些位形成的所有分支，因此不会漏掉可行解。
3
剪枝安全。从 keep 增加保留位只会保持或增加缩写长度，不会减少。当前已不优于最优值时，所有后代都不可能更优。
4
全局最优。所有可能改进答案的可行分支都会被访问，只有确定不能改进的分支被剪掉，所以最终记录的可行掩码拥有最小缩写长度。

复杂度与边界

预处理
O(n · m)
最坏搜索
O(2^m · n)
额外空间
O(2^m + n)

m ≤ 21。实际搜索通常更小，因为只枚举有区分力的位置，并使用定向分支、长度剪枝与状态去重。

边界

  • 字典为空或没有同长度词：直接返回数字 m。
  • 目标长度为 1 且没有同长冲突：答案是 "1"。
  • 重复字典词不影响正确性；可以对 diff 去重以优化。
  • 题目保证目标不在字典中；实现仍对零 diff 返回空字符串作为防御。

import java.util.*;

class Solution {
    private String target;
    private int m, useful, bestMask, bestLen;
    private int[] diffs;
    private final Set<Integer> seen = new HashSet<>();

    public String minAbbreviation(String target, String[] dictionary) {
        this.target = target;
        m = target.length();
        List<Integer> list = new ArrayList<>();

        for (String word : dictionary) {
            if (word.length() != m) continue;
            int diff = 0;
            for (int i = 0; i < m; i++) {
                if (target.charAt(i) != word.charAt(i)) diff |= 1 << i;
            }
            if (diff == 0) return "";
            list.add(diff);
            useful |= diff;
        }
        if (list.isEmpty()) return String.valueOf(m);

        diffs = list.stream().mapToInt(Integer::intValue).toArray();
        bestLen = m + 1;
        dfs(0);
        return bestLen == m + 1 ? "" : build(bestMask);
    }

    private void dfs(int keep) {
        if (!seen.add(keep) || abbrLen(keep) >= bestLen) return;

        int conflict = 0, fewest = Integer.MAX_VALUE;
        for (int diff : diffs) {
            if ((keep & diff) == 0) {
                int choices = Integer.bitCount(diff & useful);
                if (choices < fewest) {
                    fewest = choices;
                    conflict = diff;
                }
            }
        }
        if (conflict == 0) {
            bestLen = abbrLen(keep);
            bestMask = keep;
            return;
        }

        int bits = conflict & useful;
        while (bits != 0) {
            int bit = bits & -bits;
            dfs(keep | bit);
            bits -= bit;
        }
    }

    private int abbrLen(int keep) {
        int len = 0;
        for (int i = 0; i < m; i++) {
            if ((keep & (1 << i)) != 0) len++;
            else if (i == 0 || (keep & (1 << (i - 1))) != 0) len++;
        }
        return len;
    }

    private String build(int keep) {
        StringBuilder ans = new StringBuilder();
        int skipped = 0;
        for (int i = 0; i < m; i++) {
            if ((keep & (1 << i)) == 0) {
                skipped++;
            } else {
                if (skipped > 0) ans.append(skipped);
                skipped = 0;
                ans.append(target.charAt(i));
            }
        }
        if (skipped > 0) ans.append(skipped);
        return ans.toString();
    }
}

var minAbbreviation = function (target, dictionary) {
    const m = target.length;
    const diffs = [];
    let useful = 0;

    for (const word of dictionary) {
        if (word.length !== m) continue;
        let diff = 0;
        for (let i = 0; i < m; i++) {
            if (target[i] !== word[i]) diff |= 1 << i;
        }
        if (diff === 0) return "";
        diffs.push(diff);
        useful |= diff;
    }
    if (diffs.length === 0) return String(m);

    let bestMask = 0;
    let bestLen = m + 1;
    const seen = new Set();

    const abbrLen = (keep) => {
        let len = 0;
        for (let i = 0; i < m; i++) {
            if ((keep & (1 << i)) !== 0) len++;
            else if (i === 0 || (keep & (1 << (i - 1))) !== 0) len++;
        }
        return len;
    };

    const dfs = (keep) => {
        if (seen.has(keep) || abbrLen(keep) >= bestLen) return;
        seen.add(keep);

        let conflict = 0;
        let fewest = Infinity;
        for (const diff of diffs) {
            if ((keep & diff) === 0) {
                let bits = diff & useful;
                let choices = 0;
                while (bits !== 0) {
                    bits &= bits - 1;
                    choices++;
                }
                if (choices < fewest) {
                    fewest = choices;
                    conflict = diff;
                }
            }
        }
        if (conflict === 0) {
            bestLen = abbrLen(keep);
            bestMask = keep;
            return;
        }

        let bits = conflict & useful;
        while (bits !== 0) {
            const bit = bits & -bits;
            dfs(keep | bit);
            bits -= bit;
        }
    };

    const build = (keep) => {
        let ans = "";
        let skipped = 0;
        for (let i = 0; i < m; i++) {
            if ((keep & (1 << i)) === 0) {
                skipped++;
            } else {
                if (skipped > 0) ans += skipped;
                skipped = 0;
                ans += target[i];
            }
        }
        if (skipped > 0) ans += skipped;
        return ans;
    };

    dfs(0);
    return bestLen === m + 1 ? "" : build(bestMask);
};
from typing import List


class Solution:
    def minAbbreviation(self, target: str, dictionary: List[str]) -> str:
        m = len(target)
        diffs: List[int] = []
        useful = 0

        for word in dictionary:
            if len(word) != m:
                continue
            diff = 0
            for i, (a, b) in enumerate(zip(target, word)):
                if a != b:
                    diff |= 1 << i
            if diff == 0:
                return ""
            diffs.append(diff)
            useful |= diff

        if not diffs:
            return str(m)

        best_mask = 0
        best_len = m + 1
        seen: set[int] = set()

        def abbr_len(keep: int) -> int:
            length = 0
            for i in range(m):
                if keep & (1 << i):
                    length += 1
                elif i == 0 or keep & (1 << (i - 1)):
                    length += 1
            return length

        def dfs(keep: int) -> None:
            nonlocal best_mask, best_len
            if keep in seen or abbr_len(keep) >= best_len:
                return
            seen.add(keep)

            conflict = 0
            fewest = m + 1
            for diff in diffs:
                if keep & diff == 0:
                    choices = (diff & useful).bit_count()
                    if choices < fewest:
                        fewest = choices
                        conflict = diff

            if conflict == 0:
                best_len = abbr_len(keep)
                best_mask = keep
                return

            bits = conflict & useful
            while bits:
                bit = bits & -bits
                dfs(keep | bit)
                bits -= bit

        def build(keep: int) -> str:
            parts: List[str] = []
            skipped = 0
            for i, char in enumerate(target):
                if keep & (1 << i) == 0:
                    skipped += 1
                else:
                    if skipped:
                        parts.append(str(skipped))
                    skipped = 0
                    parts.append(char)
            if skipped:
                parts.append(str(skipped))
            return "".join(parts)

        dfs(0)
        return "" if best_len == m + 1 else build(best_mask)

using namespace std;

class Solution {
    string target;
    int m = 0, useful = 0, bestMask = 0, bestLen = 0;
    vector<int> diffs;
    unordered_set<int> seen;

    int abbrLen(int keep) const {
        int len = 0;
        for (int i = 0; i < m; ++i) {
            if (keep & (1 << i)) ++len;
            else if (i == 0 || (keep & (1 << (i - 1)))) ++len;
        }
        return len;
    }

    void dfs(int keep) {
        if (!seen.insert(keep).second || abbrLen(keep) >= bestLen) return;

        int conflict = 0, fewest = INT_MAX;
        for (int diff : diffs) {
            if ((keep & diff) == 0) {
                int choices = __builtin_popcount(diff & useful);
                if (choices < fewest) {
                    fewest = choices;
                    conflict = diff;
                }
            }
        }
        if (conflict == 0) {
            bestLen = abbrLen(keep);
            bestMask = keep;
            return;
        }

        int bits = conflict & useful;
        while (bits != 0) {
            int bit = bits & -bits;
            dfs(keep | bit);
            bits -= bit;
        }
    }

    string build(int keep) const {
        string ans;
        int skipped = 0;
        for (int i = 0; i < m; ++i) {
            if ((keep & (1 << i)) == 0) {
                ++skipped;
            } else {
                if (skipped > 0) ans += to_string(skipped);
                skipped = 0;
                ans.push_back(target[i]);
            }
        }
        if (skipped > 0) ans += to_string(skipped);
        return ans;
    }

public:
    string minAbbreviation(string target, vector<string>& dictionary) {
        this->target = target;
        m = static_cast<int>(target.size());

        for (const string& word : dictionary) {
            if (static_cast<int>(word.size()) != m) continue;
            int diff = 0;
            for (int i = 0; i < m; ++i) {
                if (target[i] != word[i]) diff |= 1 << i;
            }
            if (diff == 0) return "";
            diffs.push_back(diff);
            useful |= diff;
        }
        if (diffs.empty()) return to_string(m);

        bestLen = m + 1;
        dfs(0);
        return bestLen == m + 1 ? "" : build(bestMask);
    }
};

替代方案

  • 枚举全部保留掩码：最直接，逐一判断是否命中全部 diff；最坏仍为 2^m，常数通常更大。
  • 按缩写长度分层：优先队列先弹出较短候选，首个命中全部集合的状态即为最优；必须去重，且代价不能只看保留位数量。
  • Trie + 缩写 DFS：可沿字典 Trie 校验候选，但状态更复杂；m ≤ 21 时，差异位掩码更紧凑。

面试追问

  1. 为什么不同长度的词一定不冲突？请从缩写的解码总长度说明。
  2. 为什么不能只最小化保留字符数？数字段数量如何影响目标函数？
  3. 如何选择下一个未命中的 diff 加速搜索？可讨论“可选位最少优先”。
  4. 若目标长度超过机器整数位数，如何改用大整数、位集或分块数组？
  5. 若要求输出所有最短答案，如何修改更新、剪枝和去重？

常见错误

  • 把缩写长度当成渲染后的字符数，错误地认为数字 12 贡献 2。
  • 没有过滤不同长度字典词，增加无意义状态甚至误判。
  • 混淆位含义：keep 的 1 是保留，diff 的 1 是该位置不同。
  • 只按保留位个数比较；相同保留位数可能形成不同数量的数字段。
  • 用 keep | diff 判断；正确条件是交集 keep & diff。
  • 构造结果时忘记刷新末尾累计的省略计数。
