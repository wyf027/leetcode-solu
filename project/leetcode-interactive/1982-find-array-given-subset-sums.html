从子集的和还原数组

Find Array Given Subset Sums

你看到了所有组合留下的和，却不知道原来的数字。找出任意一个能够产生这些和的数组。

先读题并独立思考。算法推导、交互演示与四语言代码位于页面底部，默认收起。

01 / PROBLEM

题目说明

给定整数 n，表示未知整数数组的长度；给定数组 sums，其中以任意顺序存放该未知数组全部 2ⁿ 个子集的和。返回一个长度为 n 的整数数组，使其全部子集和与 sums 完全匹配。

子集由删除任意位置的元素得到，可以不删，也可以全部删除。空集的和为 0。不同下标选择即使得到相同的和，也需要分别计数，因此输入中的重复值不能合并。

题目保证至少有一组合法答案；答案可能不唯一，可以返回任意一组，元素顺序不限。

函数形式：recoverArray(n, sums) → 整数数组
匹配的是子集和的多重集合，既要数值一致，也要出现次数一致。

约束

  • 1 ≤ n ≤ 15
  • sums.length = 2ⁿ
  • −10⁴ ≤ sums[i] ≤ 10⁴
  • 输入保证至少存在一个正确答案。
02 / EXAMPLES

官方示例

示例 1 · 正负数与重复和

输入：n = 3, sums = [-3,-2,-1,0,0,1,2,3]
输出：[1,2,-3]

八个子集分别是 []、[1]、[2]、[1,2]、[-3]、[1,-3]、[2,-3]、[1,2,-3]，对应和为 0、1、2、3、−3、−2、−1、0。两次出现的 0 都必须保留。[−1,−2,3] 及这些答案的任意排列也符合要求。

示例 2 · 全零

输入：n = 2, sums = [0,0,0,0]
输出：[0,0]

四种下标选择都得到 0，还原数组只能为 [0,0]。

示例 3 · 零、负数与无序输入

输入：n = 4, sums = [0,0,5,5,4,-1,4,9,9,-1,4,3,4,8,3,8]
输出：[0,-1,4,5]

去掉元素 0 后，[-1,4,5] 的子集和为 [0,-1,4,5,3,4,9,8]；加入 0 使每一种下标选择产生的和再出现一次。

准备好继续了吗？

排序、配对，再由零确定符号

核心洞察：最小差值揭示绝对值

将当前子集和排序为 S。最小值来自选中所有负数；在这个最小基准上，加入一个正数或移除一个负数，增量都等于对应元素的绝对值。因此 d = S[1] − S[0] 是剩余元素中的最小绝对值。若有零，两项最小值相同，得到 d = 0。

选定这个绝对值后，所有和都可以配成 (x, x+d)。用计数表按从小到大顺序消费尚未使用的 x，同时消费一个 x+d，分别放入 L 和 H。必须先扣除 x，再扣除 x+d，这样 d=0 时也会消费两个不同的出现次数。

符号取决于空集所在的一半：
L 含 0 → 取 +d，继续处理 L。
L 不含 0 → 取 −d，继续处理 H。
两边都含 0 时选择 L 即可；题目允许不同的合法还原结果。

完整过程

  1. 仅开始时排序一次，建立空答案数组。
  2. 每轮读取最小两项之差 d，建立当前层的频次表。
  3. 从小到大扫描 S，跳过已用尽的数；每次取出 x 和 x+d，分别加入 L 与 H。两组自然保持有序。
  4. 检查 L 是否含 0。含 0 时记录 d 并选择 L；否则记录 −d 并选择 H。
  5. 每轮剩余子集和数量减半。记录 n 个元素后，当前层只剩 [0]，返回答案。

以示例 1 为例：第一轮 d=1，L=[−3,−1,0,2] 含 0，记录 1；第二轮 d=2，L=[−3,0] 含 0，记录 2；第三轮 d=3，L=[−3] 不含 0，H=[0] 含 0，记录 −3，得到 [1,2,−3]。

正确性：为什么不需要回溯？

1. 绝对值成立。设负数之和为 m。把原数组各元素替换成绝对值后，所有子集和形成多重集合 T，则原来的和正好为 m+T。T 的最小两项是 0 与最小绝对值（含零时两者均为 0），所以差值 d 一定对应一个元素的绝对值。

2. 配对完整。去掉一个绝对值为 d 的元素，其余绝对值的子集和为 U。于是 S=(m+U) ⊎ (m+U+d)。当 d>0 时，尚未消费的最小值不能充当右值，否则与它配对的更小左值应当更早被消费；所以它必须与 x+d 配对。归纳可得计数配对准确恢复 L=m+U 与 H=m+U+d。d=0 时，两组相同，逐次消费两个副本同样成立。

3. 含零分支总能继续。若 L 含零，说明 U 中存在一个子集和为 −m；将该子集对应元素改为负数，其余取正，即可构造子集和为 m+U 的剩余数组，配上 +d 恢复 S。若只有 H 含零，同理构造子集和为 m+d+U 的剩余数组，再配上 −d 恢复 S。因此零不仅是必要条件，也足以保证选择有效；两边含零时无需试探另一分支。

4. 终止与整体成立。每轮用一个合法元素把问题规模减半，且所选一半仍是某个剩余数组的全部子集和。经过 n 轮得到 [0]，倒推每轮的多重集合并集即可恢复原输入，因此返回数组合法。

边界与常见错误

  • d=0：不是死循环，当前层仍必须减半；同一个键的频次连续扣减两次。
  • 重复数、重复和：使用 Map / Counter，不能使用 Set，也不能按数值一次删除所有副本。
  • 全负数：差值仍为正，但零可能只在 H 中，要恢复 −d。
  • 两边均含 0：选择 L 合法，不必回溯，也不必恢复官方展示的那一组。
  • n=1：配对一次即可；不要在只剩一个和之后继续读 S[1]。
  • 排序：JavaScript 必须传数值比较器；后续组已排序，无需重复排序。
  • 整数范围：当前约束使用常规 32 位有符号整数足够；范围扩大时 Java/C++ 应评估 64 位。

复杂度

令 M=2ⁿ。初次排序耗时 O(M log M)=O(n·2ⁿ)。之后处理的总长度为 M+M/2+…+2=O(M)，在哈希操作平均 O(1) 的前提下，配对与零查询共 O(M)。总时间为 O(n·2ⁿ)，辅助空间为 O(2ⁿ)。代码采用迭代方式，不需要递归栈；哈希表的理论最坏退化不计入平均时间结论。

替代方案

先求绝对值再分配符号：把所有和减去最小和 m，获得非负数组的子集和，再用频次删除恢复绝对值；最后找出总和为 −m 的元素子集并取负。n≤15 时可以枚举符号子集，但通常比直接按零分组多一个阶段。

有序计数表：用 TreeMap / map 消除哈希平均复杂度假设；逐项操作多出对数因子，整体仍可控制在 O(M log M)，代码和常数开销更大。朴素枚举所有未知整数数组的空间太大，不适合作为主解。

JavaScript

/**
 * @param {number} n
 * @param {number[]} sums
 * @return {number[]}
 */
var recoverArray = function(n, sums) {
    let s = [...sums].sort((a, b) => a - b);
    const ans = [];
    while (ans.length < n) {
        const d = s[1] - s[0];
        const count = new Map();
        for (const x of s) count.set(x, (count.get(x) || 0) + 1);
        const low = [], high = [];
        for (const x of s) {
            if (count.get(x) === 0) continue;
            count.set(x, count.get(x) - 1);
            count.set(x + d, count.get(x + d) - 1);
            low.push(x);
            high.push(x + d);
        }
        if (low.includes(0)) {
            ans.push(d);
            s = low;
        } else {
            ans.push(-d);
            s = high;
        }
    }
    return ans;
};

Python

from typing import List
from collections import Counter

class Solution:
    def recoverArray(self, n: int, sums: List[int]) -> List[int]:
        s = sorted(sums)
        ans = []
        while len(ans) < n:
            d = s[1] - s[0]
            count = Counter(s)
            low, high = [], []
            for x in s:
                if count[x] == 0:
                    continue
                count[x] -= 1
                count[x + d] -= 1
                low.append(x)
                high.append(x + d)
            if 0 in low:
                ans.append(d)
                s = low
            else:
                ans.append(-d)
                s = high
        return ans

Java

import java.util.*;

class Solution {
    public int[] recoverArray(int n, int[] sums) {
        int[] s = sums.clone();
        Arrays.sort(s);
        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            int d = s[1] - s[0];
            Map<Integer, Integer> count = new HashMap<>();
            for (int x : s) count.merge(x, 1, Integer::sum);
            int[] low = new int[s.length / 2];
            int[] high = new int[s.length / 2];
            int k = 0;
            boolean hasZero = false;
            for (int x : s) {
                if (count.get(x) == 0) continue;
                count.put(x, count.get(x) - 1);
                count.put(x + d, count.get(x + d) - 1);
                low[k] = x;
                high[k++] = x + d;
                if (x == 0) hasZero = true;
            }
            ans[i] = hasZero ? d : -d;
            s = hasZero ? low : high;
        }
        return ans;
    }
}

C++

#include <algorithm>
#include <unordered_map>
#include <vector>
#include <utility>
using namespace std;

class Solution {
public:
    vector<int> recoverArray(int n, vector<int>& sums) {
        vector<int> s = sums, ans;
        sort(s.begin(), s.end());
        while (static_cast<int>(ans.size()) < n) {
            int d = s[1] - s[0];
            unordered_map<int, int> count;
            for (int x : s) ++count[x];
            vector<int> low, high;
            bool hasZero = false;
            for (int x : s) {
                if (count[x] == 0) continue;
                --count[x];
                --count[x + d];
                low.push_back(x);
                high.push_back(x + d);
                if (x == 0) hasZero = true;
            }
            ans.push_back(hasZero ? d : -d);
            s = hasZero ? std::move(low) : std::move(high);
        }
        return ans;
    }
};

面试追问

  • 为什么最小和不是 0？负元素可使非空子集比空集更小；最小和等于所有负元素之和。
  • 如果输入不保证有解？应额外检查长度、整数范围、零的存在、每次配对的可用频次，以及最终是否为 [0]；非法时返回明确错误。提交代码依赖官方保证。
  • 怎样核对非唯一答案？重新枚举候选数组的全部子集和，排序后与输入比较，并检查候选长度；这是待补验证工作，不是本页已经执行的结果。
  • 能否低于指数复杂度？仅完整读取输入就需要 Ω(2ⁿ)，优化目标在于避免额外枚举与重复排序。
