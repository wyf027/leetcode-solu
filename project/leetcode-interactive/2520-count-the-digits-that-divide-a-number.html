01 / 题目

按出现次数统计

给定整数 num，考察它十进制表示中的每一个数位。如果该数位的值能把 num 整除，就计入答案。返回符合条件的数位数量。

整除意味着余数为 0。同一个数字出现在不同位置时，每个位置都要单独计数。

约束
  • 1 ≤ num ≤ 109
  • num 的十进制数位中不包含 0。

官方示例

示例 1
输入：num = 7
输出：1

7 能被自己的唯一数位 7 整除。

示例 2
输入：num = 121
输出：2

两个 1 都满足条件；2 不满足，所以计数为 2。

示例 3
输入：num = 1248
输出：4

1、2、4、8 都能整除 1248。

04 / 独立题解

准备好了，再展开

核心洞察：原数固定，副本逐位缩短

用 x 保存 num 的副本。x % 10 取出当前末位 d；判断的是 num % d == 0。再令 x = floor(x / 10) 去掉末位。每个位置恰好被访问一次，重复数字自然会重复计数。

完整过程

  1. 初始化 x = num、count = 0。
  2. 只要 x > 0，取末位 d = x % 10。
  3. 若 num % d == 0，将 count 加一。
  4. 通过整数除法去掉 x 的末位，继续处理。
  5. x 变成 0 后返回 count。

以 num = 121 为例：x = 121 → 12 → 1 → 0，依次取到 1、2、1。原数除以它们的余数分别是 0、1、0，因此累计计数为 1 → 1 → 2。

正确性说明

循环不变式：每轮开始时，x 是原数去掉已处理末位后的前缀，count 恰好等于已处理位置中能整除原数的位置数量。初始化时没有处理任何位置，计数 0 正确。每轮取出一个尚未处理的位置，并且仅在它满足整除条件时加一，然后删除该末位，不变式继续成立。正整数通过整除 10 严格缩小，最终变成 0；此时所有位置均已处理，所以返回值正是所求。

边界与复杂度

  • 单个非零数位总能整除自身，返回 1。不同位置即便数字相同也必须分别计数。
  • 答案可能为 0，例如 23；合法输入无需处理除数为 0 的情况。
  • 10⁹ 本身含 0，不是合法输入。约束组合下最大合法值为 999999999。
  • 设十进制位数为 D = floor(log₁₀ num) + 1，时间 O(D)，额外空间 O(1)。这是四份算术实现的复杂度；交互轨迹额外存储了每一步。

四语言完整提交代码

Java

class Solution {
    public int countDigits(int num) {
        int count = 0;
        for (int x = num; x > 0; x /= 10) {
            int d = x % 10;
            if (num % d == 0) count++;
        }
        return count;
    }
}

JavaScript

/**
 * @param {number} num
 * @return {number}
 */
var countDigits = function(num) {
    let count = 0;
    for (let x = num; x > 0; x = Math.floor(x / 10)) {
        const d = x % 10;
        if (num % d === 0) count++;
    }
    return count;
};

Python 3

class Solution:
    def countDigits(self, num: int) -> int:
        x = num
        count = 0
        while x > 0:
            d = x % 10
            if num % d == 0:
                count += 1
            x //= 10
        return count

C++

替代方案

把 num 转成十进制字符串，逐字符转换成数字，再判断能否整除原数。写法直观，同样为 O(D) 时间，但存储字符串需要 O(D) 空间。本题直接取模与整除即可。

常见错误

  • 用逐渐缩短的 x 当被除数：必须始终判断原始 num。
  • 把数位放入集合去重：题目统计位置出现次数，不是不同数字的种类。
  • JavaScript 用 x /= 10 或 Python 用 x / 10：会留下小数，需要向下取整或使用 //。
  • 把条件反写为 d % num == 0：题意是原数能被数位整除。

面试追问

  • 如果允许 0？0 不能作除数，先判断 d != 0，再判断余数。
  • 改为 b 进制？使用 x % b 取位、x / b 的整数部分删位，整除判断仍针对原数。
  • 如果只统计不同的合格数字？用集合或 10 个标记去重；这是一个不同的计数目标。
  • 如果数字超出语言的整数精度？可用大整数，或逐字符计算原数对 1～9 的余数；JavaScript 当前约束在安全整数范围内。
