校园自行车分配 II

Campus Bikes II · 位掩码动态规划 / 最小权完美匹配

题目

校园中有 n 名工人和 m 辆自行车（n ≤ m）。工人 i 位于 workers[i]，自行车 j 位于 bikes[j]。请给每名工人恰好分配一辆互不重复的自行车，使曼哈顿距离总和最小，并返回这个最小值。

距离定义：|workerX-bikeX| + |workerY-bikeY|。

函数签名

assignBikes(workers: int[][], bikes: int[][]): int

约束

  • 1 ≤ workers.length ≤ bikes.length ≤ 10
  • 每个位置均为两个整数坐标。
  • 0 ≤ x, y < 1000
  • 工人位置两两不同，自行车位置两两不同。

标签：数组、回溯、动态规划、位运算、位掩码、二分图匹配。

官方示例（参数完整形式）

示例 1

输入：workers = [[0,0],[2,1]], bikes = [[1,2],[3,3]] 输出：6 解释：可分配为 worker 0 → bike 0（距离 3），worker 1 → bike 1（距离 3）。

示例 2

输入：workers = [[0,0],[1,1],[2,0]], bikes = [[1,0],[2,2],[2,1]] 输出：4 解释：一种最优分配的总距离为 4。

先探索：位掩码分配器

观察每一步如何把“下一个工人”分给一辆尚未使用的自行车。状态中的二进制位表示自行车是否已占用。

题解：用位掩码记住已使用的自行车

核心洞察

人数最多 10，虽然所有分配方案很多，但许多方案会到达同一个“已用自行车集合”。令 mask 表示该集合，已分配的工人数就是 popcount(mask)。因此状态无需额外记录工人编号。

完整过程

  1. 建立长度 2^m 的数组 dp，初始化为无穷大，令 dp[0]=0。
  2. 遍历掩码，令 i=popcount(mask)；若 i≥n，无需继续分配。
  3. 枚举每辆未使用的自行车 j，用工人 i 到自行车 j 的距离松弛 dp[mask | (1<<j)]。
  4. 答案是所有恰有 n 个置位状态中的最小值。

正确性证明

按已分配人数归纳。空状态费用为 0，显然最优。假设每个含 i 辆已用自行车的状态都记录了将前 i 名工人分配给该集合的最小费用。任何含 i+1 辆车的合法分配，都可唯一看作其最后为工人 i 选择某辆车，并从去掉该车的前驱状态转移而来。算法枚举了所有这样的前驱和末车，取最小值，故新状态也最优。归纳成立；最终对所有含 n 辆车的状态取最小值，得到全局最优分配。

边界与复杂度

单个工人、车比人多、距离为 0、多个方案同值都自然覆盖。时间复杂度 O(m·2^m)，空间复杂度 O(2^m)。

替代方案

记忆化 DFS 具有相同渐进复杂度，写法直观；回溯加剪枝在最坏情况下仍为排列级；匈牙利算法或最小费用流可处理更大的一般匹配，但在 m≤10 时实现成本更高。

面试追问

  • 为什么工人索引能由 mask 的置位数推出？
  • 如果工人和自行车达到数百个，应换成什么算法？
  • 如何恢复具体分配方案？（保存每次最优转移的前驱与所选车。）

常见错误

  • 把贪心“选择当前最近自行车”误认为全局最优。
  • 答案只读取某一个掩码；当自行车多于工人时应在所有置位数为 n 的掩码中取最小值。
  • 用异或添加自行车而未先确认该位未使用。

Java

class Solution {
    public int assignBikes(int[][] workers, int[][] bikes) {
        int m = bikes.length, size = 1 << m;
        int[] dp = new int[size];
        java.util.Arrays.fill(dp, Integer.MAX_VALUE / 2);
        dp[0] = 0;
        int answer = Integer.MAX_VALUE;
        for (int mask = 0; mask < size; mask++) {
            int i = Integer.bitCount(mask);
            if (i == workers.length) { answer = Math.min(answer, dp[mask]); continue; }
            for (int j = 0; j < m; j++) if ((mask & (1 << j)) == 0) {
                int d = Math.abs(workers[i][0] - bikes[j][0])
                      + Math.abs(workers[i][1] - bikes[j][1]);
                int next = mask | (1 << j);
                dp[next] = Math.min(dp[next], dp[mask] + d);
            }
        }
        return answer;
    }
}

JavaScript

var assignBikes = function(workers, bikes) {
  const size = 1 << bikes.length;
  const dp = new Array(size).fill(Infinity);
  dp[0] = 0;
  let answer = Infinity;
  for (let mask = 0; mask < size; mask++) {
    let count = 0;
    for (let x = mask; x; x >>= 1) count += x & 1;
    if (count === workers.length) { answer = Math.min(answer, dp[mask]); continue; }
    for (let j = 0; j < bikes.length; j++) if (!(mask & (1 << j))) {
      const d = Math.abs(workers[count][0] - bikes[j][0])
              + Math.abs(workers[count][1] - bikes[j][1]);
      const next = mask | (1 << j);
      dp[next] = Math.min(dp[next], dp[mask] + d);
    }
  }
  return answer;
};

Python

from typing import List

class Solution:
    def assignBikes(self, workers: List[List[int]], bikes: List[List[int]]) -> int:
        m = len(bikes)
        dp = [float("inf")] * (1 << m)
        dp[0] = 0
        answer = float("inf")
        for mask in range(1 << m):
            i = mask.bit_count()
            if i == len(workers):
                answer = min(answer, dp[mask])
                continue
            for j, bike in enumerate(bikes):
                if mask & (1 << j) == 0:
                    d = abs(workers[i][0] - bike[0]) + abs(workers[i][1] - bike[1])
                    nxt = mask | (1 << j)
                    dp[nxt] = min(dp[nxt], dp[mask] + d)
        return answer

C++

class Solution {
public:
    int assignBikes(vector<vector<int>>& workers,
                    vector<vector<int>>& bikes) {
        int m = bikes.size(), size = 1 << m;
        vector<int> dp(size, INT_MAX / 2);
        dp[0] = 0;
        int answer = INT_MAX;
        for (int mask = 0; mask < size; ++mask) {
            int i = __builtin_popcount((unsigned)mask);
            if (i == workers.size()) { answer = min(answer, dp[mask]); continue; }
            for (int j = 0; j < m; ++j) if (!(mask & (1 << j))) {
                int d = abs(workers[i][0] - bikes[j][0])
                      + abs(workers[i][1] - bikes[j][1]);
                int next = mask | (1 << j);
                dp[next] = min(dp[next], dp[mask] + d);
            }
        }
        return answer;
    }
};
