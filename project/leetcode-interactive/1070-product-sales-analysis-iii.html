产品销售分析 III

MEDIUMProduct Sales Analysis III找出每种产品首次销售年份的全部记录

题目

给定销售表 Sales。对每个 product_id 找出它出现的最早年份，并返回该产品在该年份的所有销售记录，列为 product_id、first_year、quantity、price。结果顺序不限。

同一产品在同一年可能有多条销售记录；因此不能只挑一行。

题解：分组最小值 + 回表匹配

核心洞察

“首次年份”是每个产品的分组最小值，但返回的是该年份的所有明细列。因此先计算每个产品的 MIN(year)，再用 product_id 与年份同时匹配原表。

完整过程

  1. 按 product_id 分组，得到每组最小 year。
  2. 把结果作为子查询，与 Sales 按产品编号及年份连接。
  3. 输出产品、首年、数量和价格；不按 sale_id 去重。

正确性说明

对子查询中的任一产品 p，MIN(year) 恰为它出现的最早年份。连接条件仅接受产品为 p 且年份等于该最小值的原表行，所以不会纳入后续年份；反过来，首年中的每条原表记录都满足连接条件，因而不会遗漏。故输出恰好是每种产品首年的全部销售记录。

边界与复杂度

  • 单个产品只有一条记录时，该行自然被保留。
  • 首年有多次销售时，全部保留。
  • 不同产品的首年可以相同，彼此不会混淆。
  • 在常见数据库执行计划下，时间约为 O(n) 到 O(n log n)，取决于分组、连接算法与索引；中间分组结果空间为 O(k)，k 为产品数。

官方可提交语言：SQL（MySQL）

SELECT s.product_id,
       s.year AS first_year,
       s.quantity,
       s.price
FROM Sales AS s
JOIN (
    SELECT product_id, MIN(year) AS first_year
    FROM Sales
    GROUP BY product_id
) AS f
  ON f.product_id = s.product_id
 AND f.first_year = s.year;

Java · 本地语义参考

import java.util.*;

class Solution {
    public List<int[]> salesAnalysis(int[][] sales) {
        Map<Integer, Integer> first = new HashMap<>();
        for (int[] row : sales) {
            first.merge(row[1], row[2], Math::min);
        }
        List<int[]> answer = new ArrayList<>();
        for (int[] row : sales) {
            if (row[2] == first.get(row[1])) {
                answer.add(new int[]{row[1], row[2], row[3], row[4]});
            }
        }
        return answer;
    }
}

JavaScript · 本地语义参考

function salesAnalysis(sales) {
  const first = new Map();
  for (const [, productId, year] of sales) {
    first.set(productId,
      Math.min(first.get(productId) ?? Infinity, year));
  }
  return sales
    .filter(([, productId, year]) => first.get(productId) === year)
    .map(([, productId, year, quantity, price]) =>
      [productId, year, quantity, price]);
}

Python · 本地语义参考

from typing import List

class Solution:
    def sales_analysis(self, sales: List[List[int]]) -> List[List[int]]:
        first = {}
        for _, product_id, year, _, _ in sales:
            first[product_id] = min(first.get(product_id, year), year)
        return [
            [product_id, year, quantity, price]
            for _, product_id, year, quantity, price in sales
            if year == first[product_id]
        ]

C++ · 本地语义参考

#include <algorithm>
#include <climits>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> salesAnalysis(vector<vector<int>>& sales) {
        unordered_map<int, int> first;
        for (const auto& row : sales) {
            if (!first.count(row[1])) first[row[1]] = INT_MAX;
            first[row[1]] = min(first[row[1]], row[2]);
        }
        vector<vector<int>> answer;
        for (const auto& row : sales) {
            if (row[2] == first[row[1]])
                answer.push_back({row[1], row[2], row[3], row[4]});
        }
        return answer;
    }
};

替代方案

可用窗口函数 RANK() OVER (PARTITION BY product_id ORDER BY year) 标记年份排名并筛选排名 1。必须用 RANK 或基于最小年份判断；若用 ROW_NUMBER，同一首年的多条记录只会留下其中一条。

面试追问

  • 为什么不能直接 GROUP BY product_id 后选择 quantity 和 price？因为非聚合列无法唯一对应，且会丢失首年的多条明细。
  • 什么索引有帮助？可考虑 (product_id, year) 复合索引，具体收益取决于数据库优化器与数据分布。
  • 如果只要每个产品一行怎么办？必须额外定义同年多行之间的确定性规则。

常见错误

  • 只按 year 连接，导致不同产品串行。
  • 把全表最小年份误当作每个产品的最小年份。
  • 使用 ROW_NUMBER() 丢掉同一首年的其他记录。
  • 错误地对最终列使用 DISTINCT，从而合并本应保留的销售条目。
