一场雨落在高低不平的二维地形上。哪些低洼处能留住水，哪些会沿边界流走？先读懂问题，再亲手推进水位。

Before the solution

先想一想：一个格子能存多少水，只看它四周紧邻格子的高度，够吗？地形最外圈会带来什么影响？

Problem

题目与约束

给定一个 m × n 的非负整数矩阵 heightMap，每个值表示二维高度图中一个单位格子的高度。计算降雨后，这个地形最多能容纳多少单位体积的水。

参数形式

trapRainWater(heightMap: integer[][]) → integer

输入：heightMap 是矩形二维数组；每个单元格的底面积视为 1。

输出：所有格子最终积水体积之和。

约束

  • m == heightMap.length
  • n == heightMap[i].length
  • 1 <= m, n <= 200
  • 0 <= heightMap[i][j] <= 2 × 104

官方示例 1

输入heightMap = [[1,4,3,1,3,2],[3,2,1,3,2,4],[2,3,3,2,3,1]]
输出4

解释：三个低洼格子分别容纳 1、2、1 单位水，总量为 4。

官方示例 2

输入heightMap = [[3,3,3,3,3],[3,2,2,2,3],[3,2,1,2,3],[3,2,2,2,3],[3,3,3,3,3]]
输出10

解释：外圈高度均为 3，内部八个高度为 2 的格子各存 1，中心高度为 1 的格子存 2。

Solution

优先队列上的边界洪水填充

把二维问题看成“海水从地图外部向内部漫入”：决定低洼格子上限的，不是局部最高墙，而是所有可通向边界的路径中最低的那道瓶颈。

核心洞察

最小堆里存的是当前已知“外部边界”。每次取出其中水位最低的格子，它就是尚未探索区域此刻能面对的最矮出口。

一维接雨水可以从左右两端夹逼；二维里边界不再是两个点，而是一整圈。因此，先把所有外圈格子加入最小堆。弹出水位最低的边界格子 (r, c, level) 后：

  • 若相邻格子高度低于 level，它能接 level - height 单位水；
  • 该邻格成为新边界时的有效水位为 max(level, height)；
  • 用访问标记保证每个格子只入堆一次。

完整过程

  1. 若行数或列数小于 3，不可能围成内部区域，直接返回 0。
  2. 将矩阵四条边上的格子去重后全部放入最小堆，同时标记为已访问。
  3. 反复弹出堆顶，即当前候选边界里有效水位最低的格子。
  4. 检查它的四个相邻格子；跳过越界或已访问位置，并在入堆前立刻标记访问。
  5. 累加 max(0, level - neighborHeight)，再以 max(level, neighborHeight) 作为邻格的新边界水位入堆。
  6. 最小堆清空时，所有格子的最终贡献都已确定，返回累加值。

正确性证明

不变量

堆中每个格子的 level 是已处理区域与未处理区域交界处的有效边界水位；所有未处理格子若想流向地图外部，必须穿过当前边界之一。

贪心安全性

取出的最小 level 是当前最低出口。在它相邻的未访问格子处，不可能存在尚未发现且更低的外部出口，否则那条路径必先穿过一个更低的候选边界，它应更早出堆，产生矛盾。

局部水量正确

若邻格更低，水只能涨到当前最低出口 level，贡献正是差值；若邻格更高，它自身成为新墙，不产生积水。两者统一为新的有效水位 max(level, height)。

终止与完备

每个格子在首次发现时标记，故最多入堆一次。矩阵连通且从整圈边界扩展，最终所有格子都会被访问，每个格子的积水贡献恰好计算一次。

边界情况

  • 少于 3 行或 3 列：没有非边界格子，答案必为 0。
  • 平坦地形或单调坡面：算法仍会遍历全部格子，但每次增量都是 0。
  • 多个盆地与嵌套高墙：堆中的有效水位会沿路径传播，无需单独识别盆地。
  • 边界重复：四个角可能被两条边同时枚举，必须用 visited 去重。
  • 数值范围：最大总体积不超过约 200 × 200 × 20000，题目给定范围内 32 位有符号整数可容纳；JavaScript 使用安全整数也没有问题。

复杂度

O(mn log(mn))每个格子最多入堆、出堆一次，堆操作为对数复杂度。
O(mn)访问矩阵与最小堆在最坏情况下都需要线性额外空间。

替代方案

  • 逐格寻找四方向最高墙：二维水会绕路泄露，四个方向的局部最大值不足以刻画通向边界的路径，通常不正确。
  • 按高度离线并查集：可以按水位逐层激活格子并维护与外部的连通性，但水量统计更复杂，面试实现成本明显更高。
  • 反复做可达性搜索：对每个候选水位运行 BFS 可以得到答案，但重复工作多，最坏复杂度远高于优先队列方案。

import java.util.PriorityQueue;

class Solution {
    public int trapRainWater(int[][] heightMap) {
        int rows = heightMap.length;
        int cols = heightMap[0].length;
        if (rows < 3 || cols < 3) return 0;

        boolean[][] visited = new boolean[rows][cols];
        PriorityQueue<int[]> minHeap =
            new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (r == 0 || r == rows - 1 || c == 0 || c == cols - 1) {
                    if (!visited[r][c]) {
                        visited[r][c] = true;
                        minHeap.offer(new int[] {heightMap[r][c], r, c});
                    }
                }
            }
        }

        int water = 0;
        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        while (!minHeap.isEmpty()) {
            int[] cell = minHeap.poll();
            int level = cell[0], row = cell[1], col = cell[2];

            for (int[] direction : directions) {
                int nextRow = row + direction[0];
                int nextCol = col + direction[1];
                if (nextRow < 0 || nextRow >= rows ||
                    nextCol < 0 || nextCol >= cols ||
                    visited[nextRow][nextCol]) {
                    continue;
                }

                visited[nextRow][nextCol] = true;
                int nextHeight = heightMap[nextRow][nextCol];
                water += Math.max(0, level - nextHeight);
                int nextLevel = Math.max(level, nextHeight);
                minHeap.offer(new int[] {nextLevel, nextRow, nextCol});
            }
        }
        return water;
    }
}
class MinHeap {
    constructor() {
        this.data = [];
    }

    get size() {
        return this.data.length;
    }

    push(item) {
        this.data.push(item);
        let index = this.data.length - 1;
        while (index > 0) {
            const parent = Math.floor((index - 1) / 2);
            if (this.data[parent][0] <= this.data[index][0]) break;
            [this.data[parent], this.data[index]] =
                [this.data[index], this.data[parent]];
            index = parent;
        }
    }

    pop() {
        const root = this.data[0];
        const last = this.data.pop();
        if (this.data.length > 0) {
            this.data[0] = last;
            let index = 0;
            while (true) {
                let smallest = index;
                const left = index * 2 + 1;
                const right = left + 1;
                if (left < this.data.length &&
                    this.data[left][0] < this.data[smallest][0]) {
                    smallest = left;
                }
                if (right < this.data.length &&
                    this.data[right][0] < this.data[smallest][0]) {
                    smallest = right;
                }
                if (smallest === index) break;
                [this.data[index], this.data[smallest]] =
                    [this.data[smallest], this.data[index]];
                index = smallest;
            }
        }
        return root;
    }
}

var trapRainWater = function(heightMap) {
    const rows = heightMap.length;
    const cols = heightMap[0].length;
    if (rows < 3 || cols < 3) return 0;

    const visited = Array.from({ length: rows }, () => Array(cols).fill(false));
    const heap = new MinHeap();

    for (let row = 0; row < rows; row++) {
        for (let col = 0; col < cols; col++) {
            if (row === 0 || row === rows - 1 || col === 0 || col === cols - 1) {
                if (!visited[row][col]) {
                    visited[row][col] = true;
                    heap.push([heightMap[row][col], row, col]);
                }
            }
        }
    }

    let water = 0;
    const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];

    while (heap.size > 0) {
        const [level, row, col] = heap.pop();
        for (const [dr, dc] of directions) {
            const nextRow = row + dr;
            const nextCol = col + dc;
            if (nextRow < 0 || nextRow >= rows ||
                nextCol < 0 || nextCol >= cols ||
                visited[nextRow][nextCol]) {
                continue;
            }

            visited[nextRow][nextCol] = true;
            const nextHeight = heightMap[nextRow][nextCol];
            water += Math.max(0, level - nextHeight);
            heap.push([Math.max(level, nextHeight), nextRow, nextCol]);
        }
    }
    return water;
};
from heapq import heappop, heappush
from typing import List


class Solution:
    def trapRainWater(self, heightMap: List[List[int]]) -> int:
        rows, cols = len(heightMap), len(heightMap[0])
        if rows < 3 or cols < 3:
            return 0

        visited = [[False] * cols for _ in range(rows)]
        min_heap = []

        for row in range(rows):
            for col in range(cols):
                if row in (0, rows - 1) or col in (0, cols - 1):
                    if not visited[row][col]:
                        visited[row][col] = True
                        heappush(min_heap, (heightMap[row][col], row, col))

        water = 0
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

        while min_heap:
            level, row, col = heappop(min_heap)
            for dr, dc in directions:
                next_row, next_col = row + dr, col + dc
                if not (0 <= next_row < rows and 0 <= next_col < cols):
                    continue
                if visited[next_row][next_col]:
                    continue

                visited[next_row][next_col] = True
                next_height = heightMap[next_row][next_col]
                water += max(0, level - next_height)
                next_level = max(level, next_height)
                heappush(min_heap, (next_level, next_row, next_col))

        return water

class Solution {
public:
    int trapRainWater(vector<vector<int>>& heightMap) {
        const int rows = static_cast<int>(heightMap.size());
        const int cols = static_cast<int>(heightMap[0].size());
        if (rows < 3 || cols < 3) return 0;

        using Cell = tuple<int, int, int>; // level, row, col
        priority_queue<Cell, vector<Cell>, greater<Cell>> minHeap;
        vector<vector<bool>> visited(rows, vector<bool>(cols, false));

        for (int row = 0; row < rows; ++row) {
            for (int col = 0; col < cols; ++col) {
                if (row == 0 || row == rows - 1 || col == 0 || col == cols - 1) {
                    if (!visited[row][col]) {
                        visited[row][col] = true;
                        minHeap.emplace(heightMap[row][col], row, col);
                    }
                }
            }
        }

        int water = 0;
        constexpr int directions[4][2] = {
            {1, 0}, {-1, 0}, {0, 1}, {0, -1}
        };

        while (!minHeap.empty()) {
            auto [level, row, col] = minHeap.top();
            minHeap.pop();

            for (const auto& direction : directions) {
                int nextRow = row + direction[0];
                int nextCol = col + direction[1];
                if (nextRow < 0 || nextRow >= rows ||
                    nextCol < 0 || nextCol >= cols ||
                    visited[nextRow][nextCol]) {
                    continue;
                }

                visited[nextRow][nextCol] = true;
                int nextHeight = heightMap[nextRow][nextCol];
                water += max(0, level - nextHeight);
                minHeap.emplace(max(level, nextHeight), nextRow, nextCol);
            }
        }
        return water;
    }
};

面试追问

  • 为什么不能只维护全局最高边界？因为最低出口决定当前水位上限；较高边界不能阻止水从较低出口流走。
  • 为什么入堆时就标记，而不是出堆时？入堆即标记可避免同一格子被多个已访问邻居重复加入，保持每格一次。
  • 能否返回每个格子的水深？可以，在发现邻格时记录 max(0, level - height) 到同形矩阵。
  • 如果支持八方向流动？只需把方向数组扩为八个方向；证明结构不变，但答案可能更小。
  • 如果边界部分封闭、部分可排水？只把可与外界交换的边界作为初始堆节点，其余封闭边界按普通墙处理。

常见错误

  • 把原始高度而不是 max(当前水位, 邻格高度) 放入堆，导致水位无法向盆地内部传播。
  • 使用最大堆，优先处理高墙，使低出口尚未确定时就错误计水。
  • 只加入第一行和最后一行，漏掉左右边界。
  • 弹出堆时才标记访问，造成大量重复入堆，甚至重复累计水量。
  • 套用一维的左右最大值公式，忽略水在二维平面上可以绕行泄露。
