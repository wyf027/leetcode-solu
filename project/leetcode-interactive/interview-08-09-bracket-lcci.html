01 / 题意校准

要制造什么？

官方题面没有单列约束范围；页面以题意、示例与可验证规则为准。

给定括号对数 n，生成所有由 n 个左括号和 n 个右括号组成的合法字符串；结果不得重复。

输入 n = 3
输出 ["((()))", "(()())", "(())()", "()(())", "()()()"]

Acceptance rule

长度
恰好 2 × n
前缀
左括号数 ≥ 右括号数
终点
两者都等于 n

Unique

每条决策路径唯一

同一位置只会选择一种括号，不需要集合去重。

Prefix

坏前缀无法被补救

右括号一旦超前，后面再加什么都不能让该前缀合法。

Output

答案数是 Catalan 数

输出规模本身就在增长，复杂度应按输出敏感方式表达。

Why this is safe

任何时刻都不允许 right > left。

这条局部不变量直接保证每个前缀合法；终点又保证左右数量相等，因此被验收的每个字符串都合法。

04 / 完整题解

回溯 + 前缀剪枝

核心洞察

01

只生成合法前缀

左括号未用完时可放 (；已有未闭合左括号时才可放 )。

02

状态只需三个量

path、left 与 right 足以决定下一步，没有重叠决策。

03

到长度 2n 即收货

合法前缀一路扩展到左右都用满，得到的必然是完整合法组合。

完整过程

  1. 1. 从 path = ""、left = 0、right = 0 开始。
  2. 2. 若 left < n，放入一个左括号并递归；返回后撤销。
  3. 3. 若 right < left，放入一个右括号并递归；返回后撤销。
  4. 4. 当 path.length === 2 * n，将当前字符串加入答案。
对 n = 3，搜索沿合法前缀展开，最终恰好验收 5 个字符串；无效前缀从未进入递归树。

复杂度

时间
O(Cₙ · n)

共有第 n 个 Catalan 数 Cₙ 个答案，每个答案长度为 2n，需要复制输出。

辅助空间
O(n)

递归深度与路径长度同阶；不计答案数组占用。

边界

  • • n = 1 只有 ["()"]。
  • • 若扩展定义允许 n = 0，数学上返回 [""]；官方题面未单列范围。
  • • 大 n 的瓶颈首先是输出规模，而非剪枝效率。

替代方案

  • • 枚举全部 22n 串再校验：直观但浪费。
  • • 动态规划按 (inside) + outside 组合：可行但更难避免重复与解释。
  • • 按 Catalan 递推构造：适合计数与理论推导。

常见错误

  • • 将右括号条件写成 right < n，生成非法前缀。
  • • 使用可变缓冲区后忘记撤销最后一个字符。
  • • 把时间复杂度误写为 O(2ⁿ)，忽略长度 2n 与输出复制。

面试追问

为什么不会重复？

每个结果对应唯一的逐位置决策序列；DFS 不会以另一条路径得到同一字符串。

如何只计算数量？

使用 Catalan 递推或组合公式，无需生成字符串；注意整数溢出。

如何改成迭代？

显式栈保存 (path, left, right)，按照期望顺序压入两个后继状态。

如何生成第 k 个组合？

预计算状态的合法补全数，像按字典序跳过整棵子树一样定位。

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> answer = new ArrayList<>();
        backtrack(n, 0, 0, new StringBuilder(), answer);
        return answer;
    }

    private void backtrack(int n, int left, int right,
                           StringBuilder path, List<String> answer) {
        if (path.length() == 2 * n) {
            answer.add(path.toString());
            return;
        }

        if (left < n) {
            path.append('(');
            backtrack(n, left + 1, right, path, answer);
            path.deleteCharAt(path.length() - 1);
        }

        if (right < left) {
            path.append(')');
            backtrack(n, left, right + 1, path, answer);
            path.deleteCharAt(path.length() - 1);
        }
    }
}

 * @param {number} n

var generateParenthesis = function (n) {
  const answer = [];

  function backtrack(path, left, right) {
    if (path.length === 2 * n) {
      answer.push(path);
      return;
    }

    if (left < n) {
      backtrack(path + "(", left + 1, right);
    }
    if (right < left) {
      backtrack(path + ")", left, right + 1);
    }
  }

  backtrack("", 0, 0);
  return answer;
};
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        answer = []

        def backtrack(path: list[str], left: int, right: int) -> None:
            if len(path) == 2 * n:
                answer.append("".join(path))
                return

            if left < n:
                path.append("(")
                backtrack(path, left + 1, right)
                path.pop()

            if right < left:
                path.append(")")
                backtrack(path, left, right + 1)
                path.pop()

        backtrack([], 0, 0)
        return answer
class Solution {
public:
    vector<string> generateParenthesis(int n) {
        vector<string> answer;
        string path;
        backtrack(n, 0, 0, path, answer);
        return answer;
    }

private:
    void backtrack(int n, int left, int right,
                   string& path, vector<string>& answer) {
        if (path.size() == static_cast<size_t>(2 * n)) {
            answer.push_back(path);
            return;
        }

        if (left < n) {
            path.push_back('(');
            backtrack(n, left + 1, right, path, answer);
            path.pop_back();
        }

        if (right < left) {
            path.push_back(')');
            backtrack(n, left, right + 1, path, answer);
            path.pop_back();
        }
    }
};
