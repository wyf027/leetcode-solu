Minimum Time For K Virus Variants to Spread

多个起点，同一片网格。寻找第一次有至少 K 种病毒相遇的那一天。

01 / READ THE PROBLEM

题意与输入约定

在无限整数网格上，points[i] = [xᵢ, yᵢ] 是第 i 种病毒在第 0 天的起点。每天，每种病毒从已感染位置向上、下、左、右扩散一格，并保留已有感染。同一个位置允许多种病毒同时存在，传播互不干扰；起点相同的两条记录也表示不同种类。

给定 points 和 k，返回最早使某个整数坐标包含至少 k 种病毒的天数，答案可以是 0。

函数契约

minDayskVariants(points, k) → integer
points: integer[][]
k: integer

每条 points 记录对应一种病毒，不能按坐标去重。

完整约束

  • n == points.length
  • 2 ≤ n ≤ 50
  • points[i].length == 2
  • 1 ≤ xᵢ, yᵢ ≤ 100
  • 2 ≤ k ≤ n

04 / SOLUTION LAB

独立题解

核心洞察：固定终点，比较到达时间

四方向走到 (x,y) 的最短路长是曼哈顿距离 |x−xᵢ| + |y−yᵢ|。它也是第 i 种病毒第一次到达该点的天数。将 n 个距离从小到大排序，该点首次拥有至少 k 种病毒的时间，恰好是第 k 小的距离。

T(x,y) = sorted([|x−xᵢ| + |y−yᵢ|])[k−1]
answer = min T(x,y)

把所有起点包在矩形 [minX,maxX] × [minY,maxY] 里。矩形外的点投影回矩形时，到每个起点的曼哈顿距离都不会增加。因此矩形内必有一个最优整数位置，至多枚举 100 × 100 个格点即可。实现直接排序；n ≤ 50，不必引入自定义堆。

完整过程

  1. 扫描 points，得到 minX、maxX、minY、maxY。
  2. 枚举包围盒内每个整数 (x,y)，为每一种病毒计算距离，重复起点仍各算一次。
  3. 升序排序，读取下标 k−1；它表示该位置最早满足条件的天数。
  4. 维护所有候选时间的最小值，遍历结束后返回。

以官方示例 3 为例：在 (3,2)，到三种病毒的距离依次为 1、2、6，第三小为 6；在 (4,2) 是 2、3、5，第三小为 5；在 (5,2) 是 3、4、4，第三小为 4。最左和最右起点相距 8，三种齐聚至少需要 4 天，而 (5,2) 达到此下界。

正确性证明

  1. 传播等价于距离阈值。每一天至多消除一个横向或纵向坐标差，因此到达至少需要曼哈顿距离那么多天；先横走再竖走可达到该长度。感染保留，所以第 t 天已到达当且仅当距离 ≤ t。
  2. 固定位置由第 k 小距离决定。设升序距离为 d₁…dₙ。t < dₖ 时少于 k 种到达；t = dₖ 时至少 k 种到达。距离相等不影响结论，因为种类按数组记录计数。
  3. 包围盒足够。对任意盒外整数点分别截断其 x、y 到盒内边界。每个起点都在盒内，截断使到每个起点的两维绝对差均不增，故第 k 小距离也不增，且投影仍为整数点。
  4. 全局最优。遍历了包含最优点的有限候选集合，并精确计算每个点的最早时间。取最小值即为原问题答案。

边界与常见错误

  • 同坐标不同病毒不能去重；第 0 天就可能达到 k 种。
  • 需要“至少 k 种”，不是只找 k 个不同坐标，也不是要求所有 n 种。
  • 相遇点不一定是起点；仅枚举 points 会漏解。
  • 只能在整数格点相遇。四个单位正方形顶点的连续中心不是合法位置：k=4 时答案为 2。
  • 不要用欧氏距离或切比雪夫距离；一天没有对角线传播。
  • 排序后取 k−1；JavaScript 必须使用数值比较器 (a,b) => a-b。
  • x 或 y 的范围可能只有一个值，循环仍需包含两个端点；不能以“所有病毒都首次在同一天到达”为条件。

复杂度与替代方案

令 A = (maxX−minX+1)(maxY−minY+1) ≤ 10⁴。四份代码都使用完整排序，时间 O(A · n log n)，距离数组及排序所需辅助空间合计 O(n)。坐标上限固定时可把 A 视为常数，但保留 A 更能说明实际代价。

  • 大小为 k 的最大堆：每个候选保留 k 个最短距离，时间 O(A · n log k)，空间 O(k)。可参考walkccc 的原创实现；本页选择完整排序以统一四种语言。
  • 距离计数：盒内最大曼哈顿距离为 198，可用 199 个计数桶寻找第 k 小值，时间 O(A · (n+199))。
  • 坐标扩大后的几何方案：二分天数，并将 u=x+y、v=x−y 转换后的覆盖正方形做重叠判定。还必须保证 u、v 同奇偶，否则反变换得到的不是整数格点。此方案需要额外实现，本页代码不使用。

面试追问

  • 坐标达到 10⁹ 时呢？包围盒枚举不再适用，需要基于 n 的候选几何或扫描线判定。
  • 要求输出汇合点呢？更新最小答案时同时记录 x、y；若有并列，再按指定规则选取。
  • 能否二分？可以，存在至少 k 种重合的可行性随天数单调。但本题直接取第 k 小值更简洁。
  • 只有 k=2 时？答案等于任意两种病毒起点曼哈顿距离的最小值除以 2 后向上取整；k>2 不能直接套用两两相遇。

Java

import java.util.Arrays;

class Solution {
    public int minDayskVariants(int[][] points, int k) {
        int minX = 100, maxX = 1, minY = 100, maxY = 1;
        for (int[] p : points) {
            minX = Math.min(minX, p[0]);
            maxX = Math.max(maxX, p[0]);
            minY = Math.min(minY, p[1]);
            maxY = Math.max(maxY, p[1]);
        }
        int answer = Integer.MAX_VALUE;
        int[] distances = new int[points.length];
        for (int x = minX; x <= maxX; x++) {
            for (int y = minY; y <= maxY; y++) {
                for (int i = 0; i < points.length; i++) {
                    distances[i] = Math.abs(x - points[i][0])
                                 + Math.abs(y - points[i][1]);
                }
                Arrays.sort(distances);
                answer = Math.min(answer, distances[k - 1]);
            }
        }
        return answer;
    }
}

var minDayskVariants = function(points, k) {
    let minX = 100, maxX = 1, minY = 100, maxY = 1;
    for (const [x, y] of points) {
        minX = Math.min(minX, x);
        maxX = Math.max(maxX, x);
        minY = Math.min(minY, y);
        maxY = Math.max(maxY, y);
    }
    let answer = Infinity;
    for (let x = minX; x <= maxX; x++) {
        for (let y = minY; y <= maxY; y++) {
            const distances = points.map(([px, py]) =>
                Math.abs(x - px) + Math.abs(y - py));
            distances.sort((a, b) => a - b);
            answer = Math.min(answer, distances[k - 1]);
        }
    }
    return answer;
};

class Solution:
    def minDayskVariants(self, points: List[List[int]], k: int) -> int:
        min_x = min(p[0] for p in points)
        max_x = max(p[0] for p in points)
        min_y = min(p[1] for p in points)
        max_y = max(p[1] for p in points)
        answer = 198
        for x in range(min_x, max_x + 1):
            for y in range(min_y, max_y + 1):
                distances = sorted(
                    abs(x - px) + abs(y - py)
                    for px, py in points
                )
                answer = min(answer, distances[k - 1])
        return answer

#include <algorithm>
#include <cstdlib>
#include <vector>
using namespace std;

class Solution {
public:
    int minDayskVariants(vector<vector<int>>& points, int k) {
        int minX = 100, maxX = 1, minY = 100, maxY = 1;
        for (const auto& p : points) {
            minX = min(minX, p[0]);
            maxX = max(maxX, p[0]);
            minY = min(minY, p[1]);
            maxY = max(maxY, p[1]);
        }
        int answer = 198;
        vector<int> distances(points.size());
        for (int x = minX; x <= maxX; ++x) {
            for (int y = minY; y <= maxY; ++y) {
                for (int i = 0; i < static_cast<int>(points.size()); ++i) {
                    distances[i] = abs(x - points[i][0])
                                 + abs(y - points[i][1]);
                }
                sort(distances.begin(), distances.end());
                answer = min(answer, distances[k - 1]);
            }
        }
        return answer;
    }
};
