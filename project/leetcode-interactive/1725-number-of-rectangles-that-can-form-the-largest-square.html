可以形成最大正方形的矩形数目

从不同长宽的矩形中裁出正方形：先理解每个矩形能提供什么，再回答“最大的那一种”能由多少个矩形得到。

Problem

题目说明

参数：int[][] rectangles

给定二维数组 rectangles，其中 rectangles[i] = [lᵢ, wᵢ] 表示第 i 个矩形的长和宽。

当边长 k 同时不超过矩形的长与宽时，可以从该矩形裁出一个边长为 k 的正方形。设所有矩形能够裁出的正方形中，最大边长为 maxLen。

返回能够裁出边长恰为 maxLen 的正方形的矩形数量。

示例 1

输入：rectangles = [[5,8],[3,9],[5,12],[16,5]]
输出：3
解释：各矩形可裁出的最大正方形边长为 [5,3,5,5]。
最大边长是 5，共有 3 个矩形可以做到。

示例 2

输入：rectangles = [[2,3],[3,7],[4,3],[3,7]]
输出：3

约束

  • 1 <= rectangles.length <= 1000
  • rectangles[i].length == 2
  • 1 <= lᵢ, wᵢ <= 10⁹
  • lᵢ != wᵢ

01 · Insight

核心洞察：每个矩形只留下短边

从长为 l、宽为 w 的矩形中，正方形的边长不能超过任一边，因此这个矩形能提供的最大正方形边长恰好是：

side = min(l, w)

题目于是转化为：计算所有 side 的最大值，并统计这个最大值出现了多少次。

02 · Process

一次扫描的完整过程

  1. 初始化 maxLen = 0、count = 0。
  2. 对当前矩形计算 side = min(length, width)。
  3. 若 side > maxLen，发现更大的候选：令 maxLen = side，并把计数重置为 1。
  4. 若 side == maxLen，当前矩形也能形成同样大的正方形，将 count 加一。
  5. 若 side < maxLen，当前矩形不影响答案。
  6. 扫描结束后返回 count。

03 · Correctness

正确性证明

引理：对矩形 [l, w]，能够裁出的最大正方形边长为 min(l, w)。因为更大的边长必然超过矩形的短边，无法容纳；而以短边为边长的正方形同时不超过长和宽，确实可以裁出。

循环不变式：处理完前 i 个矩形后，maxLen 是这 i 个矩形可裁出的最大正方形边长，count 是其中达到该边长的矩形数量。

初始时尚未处理矩形，不变式成立。处理新矩形时，算法分别对更大、相等、更小三种关系更新或保持状态，因此不变式继续成立。扫描全部矩形后，状态覆盖整个数组，所以 count 正是题目要求的数量。

结论：算法返回正确答案。

04 · Edges & Complexity

边界与复杂度

只有一个矩形

它自然提供全局最大正方形，答案为 1。

全部短边相同

每个矩形都计入，答案为数组长度。

最大值出现在开头

后续更小值不会误改计数。

边长达到 10⁹

只做比较和计数，四种语言中的整数类型均可安全表示。

时间复杂度O(n)

每个矩形恰好处理一次。

空间复杂度O(1)

只维护常数个变量。

class Solution {
    public int countGoodRectangles(int[][] rectangles) {
        int maxLen = 0;
        int count = 0;

        for (int[] rectangle : rectangles) {
            int side = Math.min(rectangle[0], rectangle[1]);

            if (side > maxLen) {
                maxLen = side;
                count = 1;
            } else if (side == maxLen) {
                count++;
            }
        }

        return count;
    }
}

06 · Alternatives

替代方案

两次扫描

第一遍求所有短边中的最大值，第二遍统计相等项。思路最直观，时间仍为 O(n)、空间为 O(1)，但会遍历两次。

映射后再求最大值

先生成短边数组，再求最大值和频次。表达简洁，但会额外使用 O(n) 空间，没有必要。

07 · Interview

面试追问

为什么计数要重置为 1？

出现更大边长时，之前统计的矩形都达不到新的最大值；当前矩形是新最大值的第一个贡献者。

能否流式处理？

可以。一次扫描只依赖当前矩形和两个状态量，无需保存历史数据。

若要求最大正方形面积？

计数逻辑不变，最终面积是 maxLen²；注意某些语言中的乘法溢出。

若矩形允许旋转？

答案不变，因为旋转只交换长宽，min(l, w) 不变。

08 · Pitfalls

常见错误

  • 使用长边 max(l, w) 作为正方形边长；正方形必须同时放进两个方向。
  • 遇到更大值时只更新 maxLen，却忘了把 count 重置为 1。
  • 把“可裁出某个正方形”误解为必须刚好裁完矩形；题目允许舍弃多余部分。
  • 统计原始矩形边长相同，而不是统计每个矩形的短边是否等于全局最大短边。
  • 为了排序而引入 O(n log n) 时间；本题只需一次线性扫描。
