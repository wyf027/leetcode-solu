图书整理 II

用两个只能从顶部取放图书的书堆，实现一个先到先取的整理队列。

简单

题意

请用两个栈实现一个队列，支持在队尾添加整数 appendTail(value)，以及删除并返回队首元素 deleteHead()。当队列为空时，删除操作返回 -1。

示例

["CQueue","appendTail","deleteHead","deleteHead"]
[[],[3],[],[]]

输出：[null, null, 3, -1]

约束

  • 调用次数不超过 10000 次。
  • appendTail 的值范围为 1 到 10000。
  • 所有操作均应符合队列的先进先出规则。

分步交互

先预测元素会去哪一摞，再看状态变化。题解保持隐藏，直到你主动打开。

第 1 步：新到的图书应直接压入哪一摞？

第 2 步：出队栈为空而需要取队首时，应该怎样做？

入队栈[3, 5]
出队栈[1]

题解：延迟搬运

洞察

栈的后进先出与队列相反；把入队栈整体倒到出队栈，就会把最早加入的元素翻到顶部。

过程

  1. 添加时压入入队栈。
  2. 删除时若出队栈非空，直接弹出。
  3. 否则将入队栈逐个弹出并压入出队栈。
  4. 两栈都空时返回 -1。

边界

连续删除会耗尽出队栈；空队列必须在搬运后再次判断，避免非法弹栈。

复杂度

单次搬运可能是 O(n)，但每个元素至多进出每个栈一次，均摊每个操作 O(1)，空间 O(n)。

替代方案

可直接使用语言自带队列；本题重点是理解受限栈操作如何组合出队列语义。

常见错误

每次删除都搬运全部元素，或忘记优先使用仍有元素的出队栈。

追问

如何用两个队列实现栈？如何为并发访问设计同步边界？

官方签名参考实现

// Java
class CQueue {
    Deque<Integer> in = new ArrayDeque<>();
    Deque<Integer> out = new ArrayDeque<>();
    public CQueue() {}
    public void appendTail(int value) { in.push(value); }
    public int deleteHead() {
        if (out.isEmpty()) while (!in.isEmpty()) out.push(in.pop());
        return out.isEmpty() ? -1 : out.pop();
    }
}
// JavaScript
var CQueue = function () { this.in = []; this.out = []; };
CQueue.prototype.appendTail = function (value) { this.in.push(value); };
CQueue.prototype.deleteHead = function () {
  if (!this.out.length) while (this.in.length) this.out.push(this.in.pop());
  return this.out.length ? this.out.pop() : -1;
};
# Python
class CQueue:
    def __init__(self): self.ins, self.out = [], []
    def appendTail(self, value: int) -> None: self.ins.append(value)
    def deleteHead(self) -> int:
        if not self.out:
            while self.ins: self.out.append(self.ins.pop())
        return self.out.pop() if self.out else -1
// C++
class CQueue {
    stack<int> in, out;
public:
    CQueue() {}
    void appendTail(int value) { in.push(value); }
    int deleteHead() {
        if (out.empty()) while (!in.empty()) out.push(in.top()), in.pop();
        if (out.empty()) return -1;
        int value = out.top(); out.pop(); return value;
    }
};
