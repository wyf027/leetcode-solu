训练计划 II

给定一个链表的头节点 head，返回倒数第 cnt 个节点。题目保证链表中节点的数量不少于 cnt。

双指针 链表 O(1) 空间

示例

输入：head = [1,2,3,4,5], cnt = 2
输出：[4,5]
说明：倒数第 2 个节点是值为 4 的节点。
输入：head = [7], cnt = 1
输出：[7]

约束

  • 链表节点数量为 n。
  • 1 ≤ cnt ≤ n，因此目标节点一定存在。
  • 节点值属于题目给定的数据范围；算法只依赖链表结构。

分步交互：保持 cnt 个节点的间距

点击“下一步”观察快慢指针。初始链表为 1 → 2 → 3 → 4 → 5，cnt = 2。

核心洞察

先让快指针前进 cnt 步。此后快、慢指针同步前进；快指针到达空指针时，慢指针恰好位于倒数第 cnt 个节点。

复杂度

每个指针最多走完整条链表：时间 O(n)；除两个指针外不分配额外存储：空间 O(1)。

完整过程

  1. 令 fast 与 slow 都从头节点出发。
  2. fast 单独走 cnt 步，建立固定间距。
  3. 只要 fast 不是空，两个指针同时后移一步。
  4. 循环结束时返回 slow。

边界情况

  • cnt = 1：返回尾节点。
  • cnt = n：快指针预走到空，返回头节点。
  • 单节点链表：两种情况都自然成立。

替代方案

先遍历计数得到长度 n，再走 n - cnt 步；同为 O(n)，但需要两次遍历。栈也可行，却会额外消耗 O(n) 空间。
