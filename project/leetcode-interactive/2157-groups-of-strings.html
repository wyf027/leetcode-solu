字符串分组

Groups of Strings

一次字母变换，牵起一条联系。沿着这些联系，字符串最终会聚成几组？

集合语义关系可传递免费题

01 / 题目

给定下标从 0 开始的字符串数组 words。每个字符串只含小写英文字母，且同一字符串内没有重复字母。判断关联时只看字母集合，字符排列顺序不影响关系。

对一个字符串的字母集合，恰好进行以下一种操作后得到另一个字符串的字母集合，则二者直接关联：

  • 添加一个字母。
  • 删除一个字母。
  • 替换一个字母，也允许替换成它自己。

直接关联的字符串必须归入同一组，关联链上的字符串也属于同一组；没有关联的字符串可独自成组。求满足这些条件的最大分组数，也就是关联图的连通分量数。

返回 [总组数, 最大组的字符串数量]。重复出现的字符串按不同数组元素计数。

参数与约束

  • groupStrings(words: string[]) → integer[2]
  • 1 ≤ words.length ≤ 2 × 10⁴
  • 1 ≤ words[i].length ≤ 26
  • 每个字符串只包含 a 到 z，其中每个字母最多出现一次。

02 / 示例一

输入：words = ["a","b","ab","cde"]
输出：[2,3]

a 与 b 可通过替换关联；a、b 都可通过添加一个字母得到 ab。前三个元素形成一组，cde 单独成组，共 2 组，最大组有 3 个元素。

03 / 示例二

输入：words = ["a","ab","abc"]
输出：[1,3]

a 与 ab 关联，ab 与 abc 关联，因此三个元素在同一组。a 与 abc 无须直接关联。

05 / 独立题解

先独立思考，再打开机制演示与完整实现。

把替换变成“删除后相同”

用 26 位整数表示字母集合，第 b 位表示字母 a + b 是否存在。每个数组位置是一个并查集节点，即使两个位置的掩码相同，也保留两份计数。

完整掩码表 exact

保存每种完整集合的代表下标。先合并相同集合；删除一个字母后命中这张表，就找到了删除 / 添加关系。

删除签名表 deleted

保存“某个词删去一个字母后”的集合及原词代表。如果两个词拥有相同删除签名，它们相同或只差一次替换，合并原词即可。签名本身无须出现在输入中。

交互实验 / 删除签名汇合站

逐步观察：原词 → 删除一个字母 → 查 exact / deleted → 合并原词。空集 ∅ 只是签名，不是新字符串节点。

完整过程

  1. 初始化 n 个并查集节点，组数为 n，最大组大小为 1；构造每个词的掩码。
  2. 先遍历所有完整掩码，建立 exact。遇到已存在的掩码，合并两个原始下标。这一步先完成，避免输入顺序影响添加 / 删除关系。
  3. 再次遍历每个词，只枚举其存在的字母 b。计算 d = mask ^ (1 << b)，这正好删除该字母。
  4. 若 exact 有 d，合并当前词与 exact[d]。若 deleted 有 d，合并当前词与 deleted[d]；否则登记当前词为该签名的代表。
  5. 仅在两棵不同树合并时，组数减 1，并按树大小更新最大组大小。返回两个统计值。

例如 ab 与 ac 分别删除 b、c 后都得到 a，即使 words 中没有 a，也可以通过 deleted[a] 汇合。删除签名是查找关系的键，不是加入图的节点。

正确性

不会错误合并：相同掩码对应相同集合，可以用“替换成自身”关联；命中 exact 的删除结果必然与原词差一个字母；两个原词共享删除签名时，都等于这个签名再加一个字母，因此要么集合相同，要么可用一次替换互达。

不会漏掉关联：相同集合由第一轮覆盖。添加与删除是一对逆操作，遍历较长词时会命中较短词的完整掩码。对于真正的替换关系，分别删去双方独有的字母会得到相同签名，后处理者会与该签名的代表合并。只保留一个代表已足够，因为同一签名下的所有词都会连到它。

得到所求分组：并查集维护已发现关联边的连通分量；所有关联都被覆盖，而且不会加入非法关联，所以最终分量就是题目要求的组。每个数组元素保留独立节点，根的 size 精确统计组内元素数。

复杂度与边界

设 n 为字符串数，L 为总字符数，Σ = 26。哈希表操作按均摊 O(1) 计，时间为 O(L + nΣ α(n))；并查集使用路径压缩和按大小合并，α 为反阿克曼函数。删除签名最多 L 个，额外空间为 O(n + L)，亦可写成 O(nΣ)。这些是哈希表平均性能下的分析。

  • 单元素时不发生合并，返回 [1,1]。
  • 单字母词删完得到 0。必须保留签名 0，使所有单字母词可以通过替换关联。
  • 同一个词、不同排列的词都属于相同集合，但数量不能去重。
  • 26 位掩码小于 2²⁶，Java / C++ 的 int 与 JavaScript 的 32 位位运算均可容纳。
  • 替换为已经存在的另一字母若导致集合大小减少，其结果仍由删除关系覆盖。

替代方案

直接枚举删除、添加及“删除一个存在位再添加一个不存在位”，并查询完整掩码表，也能配合并查集完成，时间约为 O(nΣ² α(n))，空间 O(n)。它更直观且省去删除签名表，但枚举替换的次数更多。两两比较集合再 BFS / DFS 需要 O(n²) 对比，在 n = 20000 时不合适。

常见错误

  • 只检查 XOR 是否有一个置位：会漏掉需要两个位变化的替换。
  • 直接要求 XOR 有两个置位就算替换：还必须保证两词集合大小相同；否则也可能是添加两个字母。
  • 把 exact 和 deleted 混成没有明确语义的单表，容易错把真实词与签名当成同一种关系。
  • 每次调用 union 都减少组数：同组重复合并应立即返回。
  • 用 if (map.get(d)) 判断存在：代表下标 0 会被当成假值，应使用 has / containsKey。

面试追问

为什么不是求两两直接关联的团？题目允许沿关联链归组，因此应求连通分量。能否不保存所有原始节点？可按唯一掩码建点并用出现次数作权重，但合并时必须累加词频。允许同一字符串重复字母怎么办？位掩码会丢失频数，应改成频率向量并重新定义编辑关系。字母表显著扩大呢？需要多字整数、位集或规范化集合键，并重新核算键的构造与哈希成本。

import java.util.*;

class Solution {
    private int[] parent, size;
    private int groups, largest;
    private int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    private void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (size[a] < size[b]) {
            int t = a; a = b; b = t;
        }
        parent[b] = a;
        size[a] += size[b];
        groups--;
        largest = Math.max(largest, size[a]);
    }
    public int[] groupStrings(String[] words) {
        int n = words.length;
        parent = new int[n]; size = new int[n];
        int[] masks = new int[n];
        groups = n; largest = 1;
        Map<Integer, Integer> exact = new HashMap<>();
        Map<Integer, Integer> deleted = new HashMap<>();
        for (int i = 0; i < n; i++) {
            parent[i] = i; size[i] = 1;
            for (char c : words[i].toCharArray())
                masks[i] |= 1 << (c - 'a');
        }
        for (int i = 0; i < n; i++) {
            Integer j = exact.putIfAbsent(masks[i], i);
            if (j != null) unite(i, j);
        }
        for (int i = 0; i < n; i++) {
            for (int b = 0; b < 26; b++) {
                if ((masks[i] & (1 << b)) == 0) continue;
                int d = masks[i] ^ (1 << b);
                Integer j = exact.get(d);
                if (j != null) unite(i, j);
                j = deleted.putIfAbsent(d, i);
                if (j != null) unite(i, j);
            }
        }
        return new int[]{groups, largest};
    }
}

var groupStrings = function(words) {
    const n = words.length;
    const parent = Array.from({length: n}, (_, i) => i);
    const size = Array(n).fill(1);
    let groups = n, largest = 1;
    function find(x) {
        while (parent[x] !== x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    function unite(a, b) {
        a = find(a); b = find(b);
        if (a === b) return;
        if (size[a] < size[b]) [a, b] = [b, a];
        parent[b] = a;
        size[a] += size[b];
        groups--;
        largest = Math.max(largest, size[a]);
    }
    const masks = words.map(word => {
        let mask = 0;
        for (const c of word) mask |= 1 << (c.charCodeAt(0) - 97);
        return mask;
    });
    const exact = new Map(), deleted = new Map();
    for (let i = 0; i < n; i++) {
        if (exact.has(masks[i])) unite(i, exact.get(masks[i]));
        else exact.set(masks[i], i);
    }
    for (let i = 0; i < n; i++) {
        for (let b = 0; b < 26; b++) {
            if ((masks[i] & (1 << b)) === 0) continue;
            const d = masks[i] ^ (1 << b);
            if (exact.has(d)) unite(i, exact.get(d));
            if (deleted.has(d)) unite(i, deleted.get(d));
            else deleted.set(d, i);
        }
    }
    return [groups, largest];
};

Python

from typing import List

class Solution:
    def groupStrings(self, words: List[str]) -> List[int]:
        n = len(words)
        parent = list(range(n))
        size = [1] * n
        groups, largest = n, 1

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def unite(a, b):
            nonlocal groups, largest
            a, b = find(a), find(b)
            if a == b:
                return
            if size[a] < size[b]:
                a, b = b, a
            parent[b] = a
            size[a] += size[b]
            groups -= 1
            largest = max(largest, size[a])

        masks = []
        for word in words:
            mask = 0
            for c in word:
                mask |= 1 << (ord(c) - ord('a'))
            masks.append(mask)

        exact, deleted = {}, {}
        for i, mask in enumerate(masks):
            if mask in exact:
                unite(i, exact[mask])
            else:
                exact[mask] = i
        for i, mask in enumerate(masks):
            for b in range(26):
                if not (mask & (1 << b)):
                    continue
                d = mask ^ (1 << b)
                if d in exact:
                    unite(i, exact[d])
                if d in deleted:
                    unite(i, deleted[d])
                else:
                    deleted[d] = i
        return [groups, largest]

C++

#include <vector>
#include <string>
#include <unordered_map>
#include <numeric>
#include <algorithm>
using namespace std;

class Solution {
    vector<int> parent, sz;
    int groups, largest;
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a;
        sz[a] += sz[b];
        --groups;
        largest = max(largest, sz[a]);
    }
public:
    vector<int> groupStrings(vector<string>& words) {
        int n = words.size();
        parent.resize(n); iota(parent.begin(), parent.end(), 0);
        sz.assign(n, 1); groups = n; largest = 1;
        vector<int> masks(n, 0);
        unordered_map<int, int> exact, deleted;
        for (int i = 0; i < n; ++i)
            for (char c : words[i]) masks[i] |= 1 << (c - 'a');
        for (int i = 0; i < n; ++i) {
            auto [it, inserted] = exact.emplace(masks[i], i);
            if (!inserted) unite(i, it->second);
        }
        for (int i = 0; i < n; ++i) {
            for (int b = 0; b < 26; ++b) {
                if ((masks[i] & (1 << b)) == 0) continue;
                int d = masks[i] ^ (1 << b);
                auto e = exact.find(d);
                if (e != exact.end()) unite(i, e->second);
                auto [it, inserted] = deleted.emplace(d, i);
                if (!inserted) unite(i, it->second);
            }
        }
        return {groups, largest};
    }
};
