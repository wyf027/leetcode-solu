每月交易 I

Monthly Transactions I — 把交易流按“月份 × 国家”折叠成一张清晰的月度报表。先理解数据，再决定如何聚合。

1 张表Transactions
2 个维度month × country
4 个指标count × amount
TRANSACTION PULSE2018.12 → 2019.01

01 / Brief

题目要求

给定交易表 Transactions，针对每一个月份与国家/地区的组合，统计：全部交易笔数、已批准交易笔数、全部交易总金额、已批准交易总金额。月份以 YYYY-MM 形式返回，结果行顺序不限。

字段类型含义规则
idint交易编号Primary Key
countryvarchar国家/地区分组维度
stateenum交易状态approved / declined
amountint交易金额参与求和
trans_datedate交易日期提取年月
  • 01id 是主键，每行代表一笔流入交易。
  • 02state 只可能是 approved 或 declined。
  • 03结果包含 6 列：两个维度与四个聚合指标。
  • 04输出允许任意顺序；官方题面未给出额外数值范围。

04 / Solution

一次分组，四个聚合

把日期格式化为月份，再以 (month, country) 分组。普通 COUNT / SUM 负责全部交易，条件表达式只让 approved 行进入另外两个指标。

核心洞察条件聚合不是第二次查询，而是在同一个分组中为每行生成 0 或金额。
STEP 01标准化月份

使用 DATE_FORMAT(trans_date, '%Y-%m')，让同月不同日期拥有相同键。

STEP 02建立复合分组

同时按 month 与 country 分组，避免把不同国家或不同月份混在一起。

STEP 03条件累加

approved 行贡献 1 和 amount；declined 行对批准指标贡献 0。

MySQL · 官方可提交答案
数据库题主答案
SELECT
    DATE_FORMAT(trans_date, '%Y-%m') AS month,
    country,
    COUNT(*) AS trans_count,
    SUM(CASE WHEN state = 'approved' THEN 1 ELSE 0 END) AS approved_count,
    SUM(amount) AS trans_total_amount,
    SUM(CASE WHEN state = 'approved' THEN amount ELSE 0 END) AS approved_total_amount
FROM Transactions
GROUP BY DATE_FORMAT(trans_date, '%Y-%m'), country;

正确性说明

  • 每行由月份与国家唯一映射到一个分组，既不会遗漏，也不会进入多个分组。
  • COUNT(*) 与 SUM(amount) 正好统计该组全部行与金额。
  • 两个 CASE 仅对 approved 行产生非零贡献，因此分别得到批准笔数与批准金额。
  • 所以每个输出分组的四个指标都与定义一致。

边界与细节

  • 某组没有 approved 时，ELSE 0 保证批准指标为 0，而非 NULL。
  • 跨年月份必须保留年份，不能只按 MONTH() 分组。
  • 结果顺序不作要求，无需 ORDER BY。
  • 日期格式化函数有数据库方言差异。

复杂度

扫描O(n)
分组状态O(g)
排序无强制

n 为交易行数，g 为不同“月份 × 国家”组合数；数据库执行计划可能使用哈希或排序聚合。

替代方案

  • MySQL 中可用 SUM(state = 'approved') 简写，但 CASE 更易迁移。
  • PostgreSQL 可用 COUNT(*) FILTER (WHERE ...)。
  • 也可先筛选批准交易再连接总交易聚合，但会增加扫描与查询复杂度。

常见错误

  • 只按月份分组，导致各国数据合并。
  • 用 COUNT(state = 'approved')；布尔结果非 NULL，拒绝行也会被计数。
  • 批准金额写成 COUNT(amount)，混淆笔数与金额。
  • SELECT 的月份表达式与 GROUP BY 不一致。

面试追问

  • 如何输出所有月份，即使某月没有交易？
  • 如何按时区换算后再归属月份？
  • 数据量极大时，应为日期与国家设计怎样的索引或分区？
  • 退款金额为负数时，业务口径是否仍可直接 SUM？

Java 17
本地语义参考
import java.time.LocalDate;
import java.util.*;

public class Main {
    record Tx(int id, String country, String state, int amount, LocalDate date) {}
    static class Agg {
        int transCount, approvedCount;
        long transTotal, approvedTotal;
    }
    static Map<String, Agg> aggregate(List<Tx> rows) {
        Map<String, Agg> result = new LinkedHashMap<>();
        for (Tx tx : rows) {
            String month = tx.date().toString().substring(0, 7);
            String key = month + "|" + tx.country();
            Agg a = result.computeIfAbsent(key, ignored -> new Agg());
            a.transCount++;
            a.transTotal += tx.amount();
            if (tx.state().equals("approved")) {
                a.approvedCount++;
                a.approvedTotal += tx.amount();
            }
        }
        return result;
    }
}
JavaScript (ES2022)
本地语义参考
function monthlyTransactions(rows) {
  const groups = new Map();
  for (const tx of rows) {
    const month = tx.trans_date.slice(0, 7);
    const key = `${month}|${tx.country}`;
    const agg = groups.get(key) ?? {
      month, country: tx.country, trans_count: 0,
      approved_count: 0, trans_total_amount: 0,
      approved_total_amount: 0
    };
    agg.trans_count += 1;
    agg.trans_total_amount += tx.amount;
    if (tx.state === "approved") {
      agg.approved_count += 1;
      agg.approved_total_amount += tx.amount;
    }
    groups.set(key, agg);
  }
  return [...groups.values()];
}

from collections import defaultdict

def monthly_transactions(rows):
    groups = defaultdict(lambda: {
        "trans_count": 0, "approved_count": 0,
        "trans_total_amount": 0, "approved_total_amount": 0
    })
    for tx in rows:
        key = (tx["trans_date"][:7], tx["country"])
        agg = groups[key]
        agg["trans_count"] += 1
        agg["trans_total_amount"] += tx["amount"]
        if tx["state"] == "approved":
            agg["approved_count"] += 1
            agg["approved_total_amount"] += tx["amount"]
    return [
        {"month": month, "country": country, **agg}
        for (month, country), agg in groups.items()
    ]
C++17
本地语义参考
#include <map>
#include <string>
#include <utility>
#include <vector>
using namespace std;

struct Transaction { int id; string country, state; long long amount; string date; };
struct Agg { int transCount = 0, approvedCount = 0; long long transTotal = 0, approvedTotal = 0; };

map<pair<string, string>, Agg> aggregate(const vector<Transaction>& rows) {
    map<pair<string, string>, Agg> groups;
    for (const auto& tx : rows) {
        auto key = make_pair(tx.date.substr(0, 7), tx.country);
        auto& a = groups[key];
        ++a.transCount;
        a.transTotal += tx.amount;
        if (tx.state == "approved") {
            ++a.approvedCount;
            a.approvedTotal += tx.amount;
        }
    }
    return groups;
}
