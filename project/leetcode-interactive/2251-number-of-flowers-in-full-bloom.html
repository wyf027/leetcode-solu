花期内花的数目

Number of Flowers in Full Bloom

✿ ── ✿ ───── ✿

每朵花有自己的开放时段。人们在不同时刻到达，你能为每位访客数出眼前盛开的花吗？

先理解时间与边界，再展开页面底部的题解实验室。

01 / Problem

题目与输入约定

给定从 0 开始编号的花期数组 flowers。其中 flowers[i] = [startᵢ, endᵢ] 表示第 i 朵花在这个闭区间内盛开：开始与结束时刻都算在花期内。

数组 people 表示各人的到达时刻。返回整数数组 answer，使 answer[i] 等于 people[i] 时刻正在盛开的花数。返回顺序必须与访客的输入顺序一致。

fullBloomFlowers(flowers: integer[][], people: integer[]) → integer[]
想一想：如果一朵花的花期是 [3, 3]，在时刻 3 到达的人能看到它吗？

完整约束

  • 1 ≤ flowers.length ≤ 5 × 10⁴
  • flowers[i].length = 2
  • 1 ≤ startᵢ ≤ endᵢ ≤ 10⁹
  • 1 ≤ people.length ≤ 5 × 10⁴
  • 1 ≤ people[i] ≤ 10⁹

官方示例

示例 1 · 交错的花期

flowers = [[1,6],[3,7],[9,12],[4,13]]
people = [2,3,7,11]
输出 = [1,2,2,2]

时刻 2：花 0；时刻 3：花 0、1；时刻 7：花 1、3；时刻 11：花 2、3。注意花 1 在结束时刻 7 仍然盛开。

示例 2 · 一瞬与重复到达

flowers = [[1,10],[3,3]]
people = [3,3,2]
输出 = [2,2,1]

前两位都在时刻 3 到达，能看到两朵花。最后一位在时刻 2 到达，只看到花期为 [1,10] 的花。

03 / Solution lab

准备好探索解法了吗？

展开后可逐步观察端点、二分区间与答案的形成。

双端点二分：已开始 − 已结束

核心洞察

时刻 t 盛开的花满足 start ≤ t ≤ end。先把所有 start ≤ t 的花纳入，再减掉 end < t 的花。因为每朵花满足 start ≤ end，已经结束的花一定也已经开始，不会误减尚未开放的花。

answer(t) = count(start ≤ t) − count(end < t)
          = upper_bound(starts, t) − lower_bound(ends, t)

upper_bound 返回第一个大于 t 的位置；lower_bound 返回第一个大于等于 t 的位置。位置就是前缀元素个数。两种边界不能混用，因为结束时刻仍然算盛开。

端点实验室 · 逐步收拢搜索范围

花期轴保留原始配对；下方端点数组独立排序。每一步展示一次二分比较，最后按访客原序填入答案。

键盘：Tab 选择控件，Enter / 空格操作；在演示面板内用 ← / → 单步移动。减少动态效果偏好下禁用自动播放，仍可单步探索。

starts · 开始时间

ends · 结束时间

浅绿：当前搜索范围 [lo, hi)；琥珀：mid；深绿：二分结束后计入的前缀。hi 是不包含的右边界，可以等于数组长度。

完整过程

  1. 从每个花期提取开始和结束时间，分别升序排序。无需保留排序后两数组之间的配对。
  2. 按 people 原顺序查询 t。对 starts 二分：若 starts[mid] ≤ t，令 lo = mid + 1；否则令 hi = mid。结束后 lo 是已开始数。
  3. 对 ends 二分：若 ends[mid] < t，令 lo = mid + 1；否则令 hi = mid。结束后 lo 是已结束数。
  4. 两者相减写入对应的 answer[i]，继续处理下一位。

示例 1：starts = [1,3,4,9]，ends = [6,7,12,13]。查询 7：已开始 3 朵，只结束 1 朵，得到 2；结束时间恰为 7 的花不能减掉。

正确性证明

定义 A(t) 为开始时间不晚于 t 的花集合，B(t) 为结束时间早于 t 的花集合。由 start ≤ end 得 B(t) ⊆ A(t)。一朵花属于 A(t) \ B(t) 当且仅当 start ≤ t 且 end ≥ t，因此正在盛开的花数恰为 |A(t)| − |B(t)|。

排序后谓词 start ≤ t 和 end < t 都呈现“真前缀、假后缀”。二分维护答案位置位于闭区间 [lo, hi]：mid 满足谓词时首个假位置在其右侧，否则在 mid 或其左侧；每次严格缩小搜索区间。lo = hi 时得到真前缀长度，分别等于 |A(t)| 与 |B(t)|。所以每项结果正确，原序查询保证输出顺序正确。

边界与复杂度

  • 单点 [t,t]：start 被计入，end 不被扣除，贡献 1。
  • 相同区间或相同端点：按元素次数计数，不能使用集合去重。
  • 重复访客直接得到相同结果；乱序访客仍按输入下标写回。
  • 最早开始前与最晚结束后都得到 0；时间可达 10⁹，不能按完整时间轴开数组。

令 m = flowers.length，n = people.length。时间复杂度 O(m log m + n log m)。端点数组辅助空间 O(m)，返回数组 O(n)，总额外空间 O(m+n)；排序的实现空间被该上界覆盖。

替代方案

  • 离线双指针：将访客连同原下标排序，分别推进 starts ≤ t 与 ends < t 的指针。时间 O(m log m + n log n)，需要恢复原序。
  • 事件差分：在 start 加 1，在 end+1 减 1，排序合并事件，求前缀和后查询。事件坐标可离散化；广义整数类型需注意 end+1 溢出。
  • 小顶堆：按到达时间扫访客，加入已经开始的花的结束时间，并弹出 end < t 的堆顶，堆大小即答案。适合同时维护活动区间，但此题仅计数，双二分更直接。
  • 直接扫描：每位访客遍历所有花，O(mn)，最大规模不适合，只适用于小数据语义参考。

常见错误

  • 把 end ≤ t 当作已经结束，漏掉闭区间右端点。
  • JavaScript 使用不带比较函数的 sort()，导致按字符串排序。
  • 二分使用 lo = mid，导致 lo 与 mid 相等时不前进。
  • 排序 people 后忘记保存原下标，返回顺序错乱。
  • 只计算“开始后”却忘记扣除已经结束，或对端点去重。

面试追问

  • 花期改为 [start,end)？扣除条件改为 end ≤ t，两边都用 upper_bound。
  • 每朵花有不同权重？将端点与权重一起排序，对权重做前缀和，用边界位置读取加权差。
  • 花期动态新增和删除？静态排序数组不适合频繁更新；可用离散坐标上的树状数组，或动态线段树维护差分事件。
  • 时间是实数？双二分仍适用；end+1 事件法不能直接照搬，要明确同坐标事件与查询的顺序。

/**
 * @param {number[][]} flowers
 * @param {number[]} people
 * @return {number[]}
 */
var fullBloomFlowers = function(flowers, people) {
    const starts = flowers.map(f => f[0]).sort((a, b) => a - b);
    const ends = flowers.map(f => f[1]).sort((a, b) => a - b);
    // inclusive: count values <= t; otherwise count values < t.
    function count(a, t, inclusive) {
        let lo = 0, hi = a.length;
        while (lo < hi) {
            const mid = lo + Math.floor((hi - lo) / 2);
            if (a[mid] < t || (inclusive && a[mid] === t)) {
                lo = mid + 1;
            } else {
                hi = mid;
            }
        }
        return lo;
    }
    return people.map(t => count(starts, t, true) - count(ends, t, false));
};
Java
import java.util.Arrays;

class Solution {
    public int[] fullBloomFlowers(int[][] flowers, int[] people) {
        int m = flowers.length;
        int[] starts = new int[m], ends = new int[m];
        for (int i = 0; i < m; i++) {
            starts[i] = flowers[i][0];
            ends[i] = flowers[i][1];
        }
        Arrays.sort(starts);
        Arrays.sort(ends);
        int[] answer = new int[people.length];
        for (int i = 0; i < people.length; i++) {
            answer[i] = count(starts, people[i], true)
                      - count(ends, people[i], false);
        }
        return answer;
    }

    private int count(int[] a, int t, boolean inclusive) {
        int lo = 0, hi = a.length;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (a[mid] < t || (inclusive && a[mid] == t)) {
                lo = mid + 1;
            } else {
                hi = mid;
            }
        }
        return lo;
    }
}
Python 3
from bisect import bisect_left, bisect_right
from typing import List

class Solution:
    def fullBloomFlowers(self, flowers: List[List[int]],
                         people: List[int]) -> List[int]:
        starts = sorted(start for start, end in flowers)
        ends = sorted(end for start, end in flowers)
        return [bisect_right(starts, t) - bisect_left(ends, t)
                for t in people]
C++
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> fullBloomFlowers(vector<vector<int>>& flowers,
                                 vector<int>& people) {
        vector<int> starts, ends;
        starts.reserve(flowers.size());
        ends.reserve(flowers.size());
        for (const auto& flower : flowers) {
            starts.push_back(flower[0]);
            ends.push_back(flower[1]);
        }
        sort(starts.begin(), starts.end());
        sort(ends.begin(), ends.end());
        vector<int> answer;
        answer.reserve(people.size());
        for (int t : people) {
            int begun = upper_bound(starts.begin(), starts.end(), t)
                        - starts.begin();
            int finished = lower_bound(ends.begin(), ends.end(), t)
                           - ends.begin();
            answer.push_back(begun - finished);
        }
        return answer;
    }
};
