LeetCode 2276 / Count Integers in Intervals

统计区间中的
整数数目

一次次加入区间，重叠的整数只算一次。

01 / 问题定义

从空的区间集合开始，设计 CountIntervals。支持加入一个闭区间，并随时返回至少被一个区间包含的不同整数个数。

  • CountIntervals()：初始化空集合。
  • void add(int left, int right)：加入闭区间 [left, right]。
  • int count()：返回所有区间的整数并集大小。
先想一想

如果同一个区间加入两次，答案会改变吗？如果左右端点相等，这个区间包含多少个整数？

数据范围

  • 1 ≤ left ≤ right ≤ 10⁹
  • add 和 count 合计最多调用 10⁵ 次。
  • 至少调用一次 count。

闭区间包含两个端点；统计的是整数个数，不是连续长度，也不是区间条数。

02 / 官方示例

输入 · 操作名与完整参数

["CountIntervals", "add", "add", "count", "add", "count"]
[[], [2, 3], [7, 10], [], [5, 8], []]

输出

[null, null, null, 6, null, 8]

按顺序理解

  1. 初始化；加入 [2,3] 与 [7,10]。
  2. 第一次统计得到 6：整数 2、3、7、8、9、10。
  3. 再加入 [5,8]，新增整数只有 5 和 6。
  4. 第二次统计得到 8：整数 2、3、5、6、7、8、9、10。7 和 8 不重复计算。

null 对应构造函数或没有返回值的 add 操作。

04 / 独立题解

准备好后，展开推导、交互实验和四语言实现。

按需展开的区间树

核心洞察：不必列举 10⁹ 个整数。把整个值域不断二分，每个节点只保存自己区间内已覆盖的整数数目；只有更新到达时才创建节点。这是动态开点线段树。

整段命中

若当前区间完全包含在新加入的区间中，将 sum 设为区间长度 hi-lo+1，直接返回。

满段剪枝

若 sum 已等于区间长度，后续加入操作无法增加覆盖，立即停止。无需向子节点传播标记。

部分命中

向有交集的左右子区间递归；返回时令父节点 sum 等于两侧之和，空子节点贡献 0。

完整过程

  1. 根节点代表 [1,10⁹]，初始 sum 为 0。
  2. add 的递归先排除无交集或已经全覆盖的节点。
  3. 若 [lo,hi] 被 [left,right] 完整包含，直接设置 sum。
  4. 否则取 mid = lo + floor((hi-lo)/2)，只创建和访问需要更新的子节点。
  5. 返回时合并左右 sum。count 直接读取根节点 sum。

示例的全局计数依次为 0 → 2 → 6 → 8。最后加入 [5,8] 时，已有的 7、8 不会再次贡献。可视化使用较小的根区间，递归分界点与完整值域不同，但计数语义一致。

正确性证明

不变量：每次 add 完成后，对仍需访问的节点，sum 恰好是它所代表区间内已覆盖的整数数量。满节点可独立代表整段，其后代的历史状态无需保持同步。

初始所有 sum 为 0，符合空集合。对于一次更新，无交集时覆盖不变；已满时并集也不变；被完全包含时该区间全部覆盖，赋值长度正确。剩余情况中，左右子区间互斥且完整划分父区间，递归正确更新两侧后相加，不会重复或遗漏。因此不变量经每次更新保持，根节点的 sum 就是整个并集的大小。

边界与数值

  • 单点 [x,x] 长度是 1。重复加入、加入已有区间内部的小段，都不增加计数。
  • 相邻区间 [1,2] 和 [3,4] 贡献 4；共享端点 [1,2] 和 [2,3] 贡献 3。
  • 加入 [1,10⁹] 后根立即全满，此后 add 可在根停止。
  • 最大答案 10⁹，Java/C++ 的 32 位有符号整数够用；JavaScript Number 可精确表示这里的整数。
  • 叶子有交集时必被完全包含，不会继续二分。树深约 30，递归深度可控。

复杂度

令 U = 10⁹，A 为 add 次数。每次 add 最坏 O(log U)，count 为 O(1)。连续区间在每层至多沿两条边界继续拆分，中间完整段立即停止，因此一次更新创建和访问 O(log U) 个节点。总空间上界 O(A log U)，递归栈 O(log U)。代码保留满节点的历史子树，以避免在一次覆盖操作里额外遍历释放大量节点。

替代方案

有序映射维护互不相交区间：找到可能重叠的前驱，删除所有重叠段并减去其长度，插入合并段并加上新长度。Java 可用 TreeMap，C++ 可用 map。单次合并 k 段通常按 O((k+1) log A) 计，某一次可能很慢；由于每个区间只会被删除一次，A 次更新总计可做到 O(A log A)，空间 O(A)。

JavaScript、Python 标准库没有同等的平衡有序映射接口，四份代码统一选择动态线段树，避免依赖第三方容器。排序数组插删仍需搬移元素，二分查找不能把总更新成本变成 O(log A)。若全部操作可离线获得，也可压缩端点，按原坐标间隙长度维护覆盖。

常见错误

  • 直接累加 right-left+1：把交集算了多次。
  • 把闭区间长度写成 right-left：单点变成 0。
  • 初始化 10⁹ 规模数组：空间不可接受。
  • 给满节点继续递归并从未同步的子节点重新求和：可能把正确的覆盖数覆盖成较小值。
  • 误以为必须 pushDown：本题只有覆盖、没有删除，满节点可以永久剪枝；加入删除操作后这个前提失效。

面试追问

  • 若支持删除？先区分删除某次加入的区间与直接清空某段；前者可用覆盖次数和覆盖长度，后者需要区间赋值懒标记。都不能沿用永久满段剪枝。
  • 若统计任意 [l,r] 内的数量？递归求交；遇到满节点直接返回交集长度，不依赖可能陈旧的子节点。
  • 若范围扩至 10¹⁸？Java/C++ 改为 64 位整数；JavaScript 使用 BigInt，并统一算术类型。
  • 为何不把区间展开到 Set？一个 add 就可能插入 10⁹ 个元素，与调用次数小无关。

四语言完整实现

Java
class CountIntervals {
    private static class Node {
        int sum;
        Node left, right;
    }
    private final Node root = new Node();
    public CountIntervals() {}
    public void add(int left, int right) {
        update(root, 1, 1_000_000_000, left, right);
    }
    private void update(Node n, int lo, int hi, int ql, int qr) {
        if (qr < lo || hi < ql || n.sum == hi - lo + 1) return;
        if (ql <= lo && hi <= qr) {
            n.sum = hi - lo + 1;
            return;
        }
        int mid = lo + (hi - lo) / 2;
        if (ql <= mid) {
            if (n.left == null) n.left = new Node();
            update(n.left, lo, mid, ql, qr);
        }
        if (qr > mid) {
            if (n.right == null) n.right = new Node();
            update(n.right, mid + 1, hi, ql, qr);
        }
        n.sum = (n.left == null ? 0 : n.left.sum)
              + (n.right == null ? 0 : n.right.sum);
    }
    public int count() { return root.sum; }
}

class CountIntervals {
    constructor() {
        this.root = { sum: 0, left: null, right: null };
    }
    add(left, right) {
        const update = (n, lo, hi) => {
            if (right < lo || hi < left || n.sum === hi - lo + 1) return;
            if (left <= lo && hi <= right) {
                n.sum = hi - lo + 1;
                return;
            }
            const mid = lo + Math.floor((hi - lo) / 2);
            if (left <= mid) {
                if (!n.left) n.left = { sum: 0, left: null, right: null };
                update(n.left, lo, mid);
            }
            if (right > mid) {
                if (!n.right) n.right = { sum: 0, left: null, right: null };
                update(n.right, mid + 1, hi);
            }
            n.sum = (n.left ? n.left.sum : 0) + (n.right ? n.right.sum : 0);
        };
        update(this.root, 1, 1000000000);
    }
    count() { return this.root.sum; }
}

class _Node:
    __slots__ = ('total', 'left', 'right')
    def __init__(self):
        self.total = 0
        self.left = None
        self.right = None

class CountIntervals:
    def __init__(self):
        self.root = _Node()

    def add(self, left: int, right: int) -> None:
        def update(node, lo, hi):
            if right < lo or hi < left or node.total == hi - lo + 1:
                return
            if left <= lo and hi <= right:
                node.total = hi - lo + 1
                return
            mid = (lo + hi) // 2
            if left <= mid:
                if node.left is None:
                    node.left = _Node()
                update(node.left, lo, mid)
            if right > mid:
                if node.right is None:
                    node.right = _Node()
                update(node.right, mid + 1, hi)
            node.total = ((node.left.total if node.left else 0)
                          + (node.right.total if node.right else 0))
        update(self.root, 1, 10**9)

    def count(self) -> int:
        return self.root.total

#include <memory>
using std::unique_ptr;
using std::make_unique;

class CountIntervals {
    struct Node {
        int sum = 0;
        unique_ptr<Node> left, right;
    };
    Node root;
    void update(Node& n, int lo, int hi, int ql, int qr) {
        if (qr < lo || hi < ql || n.sum == hi - lo + 1) return;
        if (ql <= lo && hi <= qr) {
            n.sum = hi - lo + 1;
            return;
        }
        int mid = lo + (hi - lo) / 2;
        if (ql <= mid) {
            if (!n.left) n.left = make_unique<Node>();
            update(*n.left, lo, mid, ql, qr);
        }
        if (qr > mid) {
            if (!n.right) n.right = make_unique<Node>();
            update(*n.right, mid + 1, hi, ql, qr);
        }
        n.sum = (n.left ? n.left->sum : 0)
              + (n.right ? n.right->sum : 0);
    }
public:
    CountIntervals() = default;
    void add(int left, int right) {
        update(root, 1, 1000000000, left, right);
    }
    int count() { return root.sum; }
};
