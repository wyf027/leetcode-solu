修改两个元素的最小分数Minimum Score by Changing Two Elements

给定整数数组 nums，你最多能修改两个元素。目标是让数组的“最大差值 + 最小差值”尽可能小。

先观察，再推导

题解被收在页面底部。先用三扇“保留窗口”观察：修改两个数后，哪些原值必须留下？

Problem

题意

最小得分

所有下标对 0 ≤ i < j < n 中，|nums[i] - nums[j]| 的最小值。

最大得分

所有下标对中绝对差的最大值，也就是当前数组最大值减最小值。

数组分数

最大得分与最小得分之和。你可以修改至多两个元素为任意整数，求能得到的最小分数。

其中 |x| 表示 x 的绝对值。

Official examples

示例

示例 1
输入
nums = [1,4,3]
输出
0

把 nums[1] 和 nums[2] 都改成 1，数组变成 [1,1,1]，最大差和最小差都为 0。

示例 2
输入
nums = [1,4,7,8,5]
输出
3

把前两个元素改成 6，得到 [6,6,7,8,5]。最小差为 0，最大差为 8 - 5 = 3，总分为 3。

约束

  • 3 ≤ nums.length ≤ 105
  • 1 ≤ nums[i] ≤ 109

准备好看题解了吗？

展开后会显示核心洞察、证明、复杂度、四种语言实现与面试追问。

核心洞察：分数最终只剩“保留区间的宽度”

排序后记数组为 a。修改两个元素时，可以把它们放进未修改元素的取值区间，并让其中至少一个修改值等于某个保留值，因此最小得分可以变成 0。此时只需最小化最大得分，也就是找一个包含 n - 2 个原元素的最窄区间。

完整过程

  1. 将 nums 升序排序为 a。
  2. 保留的 n - 2 个元素在最优解中一定能取为连续段；若中间跳过某个数而保留更外侧的数，把外侧换成中间数不会增大区间。
  3. 长度为 n - 2 的连续段只有三段：a[0…n-3]、a[1…n-2]、a[2…n-1]。
  4. 计算三段的宽度，取最小值。
min(a[n−1] − a[2], a[n−2] − a[1], a[n−3] − a[0])

正确性证明

引理 1：固定未修改元素后，把两个修改值都放在未修改元素的最小值与最大值之间，不会扩大最大差；让至少一个修改值等于保留值，可使最小差为 0。

引理 2：任意最优解保留至少 n - 2 个原元素。能覆盖这些元素的最小区间，对应排序数组中的连续段；选择恰好 n - 2 个不会更差。

结论：所有长度为 n - 2 的连续段只有上述三种。算法枚举全部可能并取最小宽度，因此得到全局最优分数。

边界与复杂度

  • n = 3 时，修改两个元素去匹配剩余元素，答案为 0；公式三项也都为 0。
  • 存在重复值时无需特殊处理，差值自然可能为 0。
  • 时间复杂度：O(n log n)，由排序主导。
  • 额外空间：取决于语言排序实现；算法本身只用 O(1) 额外变量。

四语言实现

import java.util.Arrays;

class Solution {
    public int minimizeSum(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        return Math.min(nums[n - 1] - nums[2],
                Math.min(nums[n - 2] - nums[1], nums[n - 3] - nums[0]));
    }
}

 * @param {number[]} nums
 * @return {number}
 */
var minimizeSum = function(nums) {
    const a = nums.slice().sort((x, y) => x - y);
    const n = a.length;
    return Math.min(a[n - 1] - a[2], a[n - 2] - a[1], a[n - 3] - a[0]);
};

替代方案

可以在线性时间维护最小的三个值和最大的三个值，再计算同样的三个候选差值，将时间降到 O(n)、额外空间保持 O(1)。不过实现更易出错；除非题目明确要求线性时间，排序版更短、更稳。

常见错误

  • 只比较“改两个最小值”和“改两个最大值”，漏掉一边改一个。
  • 继续单独优化最小差，没发现它总能被构造成 0。
  • 使用相邻差代替整个保留区间的最大值减最小值。
  • 下标错一位：三项分别是 [2,n-1]、[1,n-2]、[0,n-3]。

面试追问

为什么保留段一定连续？

若保留集合跳过了区间内部的元素，却保留了更外侧元素，用内部元素替换外侧元素不会扩大极差，所以存在一个同样好或更好的连续保留段。

如果允许修改 k 个元素呢？

排序后保留长度为 n-k 的连续段，枚举起点 0…k，取最小的 a[i+n-k-1]-a[i]；前提仍是能把最小差构造为 0。

能否不修改输入数组？

可以。JavaScript 与 Python 示例已复制或新建排序结果；Java/C++ 若需要保留输入，只需先复制数组再排序。
