两个有序数组的
第 K 小乘积

Kth Smallest Product of Two Sorted Arrays

先理解配对与排名，再展开底部题解。相同乘积来自不同下标对时，每一对都占一个名次。

01 / 题目

给定两个按非递减顺序排列的整数数组 nums1、nums2 和整数 k。从两个数组中各选择一个元素，将所有合法下标对 (i, j) 对应的乘积 nums1[i] × nums2[j] 按从小到大排列，返回其中第 k 个值。

数组下标从 0 开始，名次从 1 开始；不要求两元素的下标相同，也不对重复乘积去重。

参数与返回值

kthSmallestProduct(nums1: integer[], nums2: integer[], k: long) → long

约束

  • 1 ≤ nums1.length, nums2.length ≤ 5 × 10⁴
  • −10⁵ ≤ nums1[i], nums2[j] ≤ 10⁵
  • 1 ≤ k ≤ nums1.length × nums2.length
  • 两个数组均已按从小到大顺序排列，允许负数、零和重复值。

02 / 官方示例

示例 1 · 正数

nums1 = [2,5]
nums2 = [3,4]
k = 2
输出：8

前两项为 2×3=6、2×4=8，所以第 2 小为 8。

示例 2 · 重复与零

nums1 = [-4,-2,0,3]
nums2 = [2,4]
k = 6
输出：0

前六项为 −16、−8、−8、−4、0、0，分别来自 (−4,4)、(−4,2)、(−2,4)、(−2,2)、(0,2)、(0,4)。

示例 3 · 双侧混合符号

nums1 = [-2,-1,0,1,2]
nums2 = [-3,-1,2,4,5]
k = 3
输出：-6

前三项为 (−2)×5=−10、(−2)×4=−8、2×(−3)=−6。

05 / 题解：二分答案，按符号计数

核心洞察

不必生成最多 25 亿个乘积。定义 C(x) 为乘积不大于 x 的下标对数量。随着 x 增大，C(x) 只会增加或保持不变。第 k 小乘积恰好是满足 C(x) ≥ k 的最小整数 x。

一次计数怎样完成？

  • a > 0：序列 a × nums2[j] 非递减。二分第一个乘积大于 x 的位置 p，前 p 项合格。
  • a < 0：乘积序列非递增。二分第一个乘积不大于 x 的位置 p，后 m − p 项合格。
  • a = 0：x ≥ 0 时全部 m 项合格，否则为 0。代码将零并入非负分支，二分自动得到同样结果。

直接比较乘积，避免对负数除法时向上、向下取整的语言差异。每一行独立计数，再求和。

完整过程

  1. 令闭区间 [L,R] = [−10¹⁰,10¹⁰]，覆盖所有合法乘积。
  2. 当 L < R 时，取向下取整的中点 mid = L + floor((R−L)/2)。
  3. 逐行二分统计 C(mid)。若 C(mid) ≥ k，令 R = mid；否则令 L = mid + 1。
  4. 两端相遇时返回 L。不要在 C(mid) = k 时提前返回，因为计数可能在一段值域上相同。

乘积矩阵 / 阈值扫描实验室

绿色且带 ✓ 的格子表示乘积 ≤ 当前 mid。观察：负数行从右侧纳入，正数行从左侧纳入，零行整体变化。

教学演示用四个角的最小与最大乘积缩紧初始区间，以减少空白轮次；提交代码使用通用边界。矩阵仅为小样例显示，正式算法不构建矩阵。

为什么正确？

  1. 行计数正确。乘以非负数保持次序，合格集合是前缀；乘以负数翻转次序，合格集合是后缀。对应的二分查找恰好定位两类集合的边界。零行的全选或全不选也满足前缀性质。
  2. 总计数正确。每一行固定 nums1 的一个下标，列对应 nums2 的下标，各行覆盖所有合法配对且互不重复，因此行计数之和就是 C(x)，重复值仍被分别计入。
  3. 判定单调。如果某个乘积 ≤ x，那么对任何更大的阈值仍然满足，故 C(x) 非递减。
  4. 二分保留答案。设真实第 k 小值为 v。初始边界覆盖 v。C(mid) ≥ k 等价于 v ≤ mid，所以收右端不会丢掉 v；否则 v > mid，收左端也安全。区间严格缩小至一点，该点只能是 v。

复杂度

设 n = nums1.length，m = nums2.length，V = 2×10¹⁰+1 为初始整数值域大小。时间为 O(n log(m+1) log V)，外层最多约 35 轮；提交代码额外空间 O(1)。可将较短数组作为外层以减少循环，交换引用即可。

边界与数值范围

全负、全正、混合符号、零行以及 k 为 1 或 n×m 都使用同一判定。乘积绝对值最多 10¹⁰，计数最多 2.5×10⁹。Java / C++ 的乘法必须先提升到 64 位，计数也必须用 64 位；Python 整数自然支持。JavaScript Number 在此范围内精确，不需要 BigInt，但不能用 >>、|0 等 32 位运算处理中点、答案或总数。

替代方案

  • 枚举后排序：O(nm log(nm)) 时间、O(nm) 空间，适合手工小例子，无法应对本题规模。
  • 有序行 + 最小堆：正数行正向、负数行反向生成升序乘积，再进行 k 次弹出，约 O(n + k log(n+1)) 时间和 O(n) 空间；k 很小时可考虑，k 很大时不适合。
  • 按符号拆分 + 双指针计数：每个阈值可做到 O(n+m)，总时间 O((n+m) log V)，但需仔细处理负数绝对值顺序、零和跨符号配对，实现更复杂。

常见错误

  • 把负数行当作升序，或用 p 而不是 m−p 计入后缀。
  • 统计乘积 < mid 而不是 ≤ mid，造成名次偏移。
  • 对重复乘积去重，丢掉不同下标对。
  • Java / C++ 先执行 int 乘法再赋给 long，溢出已经发生。
  • 负数中点用向零截断，或把 R 更新为 mid−1 后套用闭区间下界模板。
  • 看到 C(mid)=k 就停止；例如产品 6、8、15、20 中，C(10)=2，但第 2 小是 8。

面试追问

为什么最终答案一定是实际乘积？ 在第 k 小值 v 之前最多只有 k−1 项，到了 v 才达到至少 k 项，最小可行阈值就是 v。

能提前停止计数吗？ 累加达到 k 即可返回“可行”，因为后续只会增加；演示为了显示完整计数，不提前停止。

如果数组无序呢？ 先排序再应用行二分，需要额外 O(n log n + m log m) 时间，且要说明是否允许修改原数组。

如何进一步压缩值域？ 双线性乘积在两个区间端点组合中取得极值，因此四个角乘积的最小值、最大值可以作为边界。

Java

class Solution {
    public long kthSmallestProduct(int[] nums1, int[] nums2, long k) {
        long left = -10_000_000_000L, right = 10_000_000_000L;
        while (left < right) {
            long mid = left + (right - left) / 2;
            if (count(nums1, nums2, mid) >= k) right = mid;
            else left = mid + 1;
        }
        return left;
    }

    private long count(int[] a, int[] b, long x) {
        long total = 0;
        for (int value : a) {
            int lo = 0, hi = b.length;
            if (value >= 0) {
                while (lo < hi) {
                    int mid = lo + (hi - lo) / 2;
                    if ((long) value * b[mid] <= x) lo = mid + 1;
                    else hi = mid;
                }
                total += lo;
            } else {
                while (lo < hi) {
                    int mid = lo + (hi - lo) / 2;
                    if ((long) value * b[mid] <= x) hi = mid;
                    else lo = mid + 1;
                }
                total += b.length - lo;
            }
        }
        return total;
    }
}

from typing import List

class Solution:
    def kthSmallestProduct(self, nums1: List[int],
                           nums2: List[int], k: int) -> int:
        def count(x: int) -> int:
            total = 0
            for a in nums1:
                lo, hi = 0, len(nums2)
                if a >= 0:
                    while lo < hi:
                        mid = (lo + hi) // 2
                        if a * nums2[mid] <= x:
                            lo = mid + 1
                        else:
                            hi = mid
                    total += lo
                else:
                    while lo < hi:
                        mid = (lo + hi) // 2
                        if a * nums2[mid] <= x:
                            hi = mid
                        else:
                            lo = mid + 1
                    total += len(nums2) - lo
            return total

        left, right = -10**10, 10**10
        while left < right:
            mid = left + (right - left) // 2
            if count(mid) >= k:
                right = mid
            else:
                left = mid + 1
        return left

        long long total = 0;
        int m = static_cast<int>(b.size());
        for (int value : a) {
            int lo = 0, hi = m;
            if (value >= 0) {
                while (lo < hi) {
                    int mid = lo + (hi - lo) / 2;
                    if (1LL * value * b[mid] <= x) lo = mid + 1;
                    else hi = mid;
                }
                total += lo;

                    int mid = lo + (hi - lo) / 2;
                    if (1LL * value * b[mid] <= x) hi = mid;
                    else lo = mid + 1;
                }
                total += m - lo;
            }
        }
        return total;
    }
