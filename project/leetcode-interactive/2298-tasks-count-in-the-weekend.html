A WEEK OF TASKS

周末任务计数

Tasks Count in the Weekend

MEDIUM数据库付费题 · 题意转述离线单文件

一张任务表，两类提交日。先理解数据，再观察每条任务的归属。

01 / 读题

需要统计什么？

给定表 Tasks，每行记录一个任务的编号、负责人编号和提交日期。返回一行统计：周六、周日提交的任务数量为 weekend_cnt，周一至周五提交的任务数量为 working_cnt。题目允许结果按任意顺序返回。

输入参数：Tasks 表
列名类型含义
task_idint任务编号，主键
assignee_idint负责人编号
submit_datedate提交日期

约束与统计口径

  • task_id 唯一；同一负责人或同一天可以有多项任务。
  • 工作日仅指周一至周五，不考虑法定节假日或调休。
  • 公开题面未给出行数、编号范围等数值上限，也未明确日期非空约束；这里不补造限制。
  • 输入是数据库表，无 Java 等算法题式签名。空表和 NULL 日期在下方作为扩展讨论。

题号、类型和示例依据本地官方元数据；题意及主键说明参考 公开题面资料。官方题目。

05 / 思考之后

把观察写成查询

准备好后展开思路、完整代码与边界讨论。

题解 · 单次扫描，条件计数

核心洞察

统计单位是任务行，不是负责人或日期。每个有效日期对应一个星期，每一行只给一个计数器贡献 1。没有分组维度，因此不需要 GROUP BY。

完整过程

  1. 用 WEEKDAY(submit_date) 取得星期编号：周一为 0，周日为 6。
  2. 5、6 对应周末，0～4 对应工作日。
  3. 分别构造两个 CASE：符合对应条件时返回 1，否则返回 NULL。
  4. COUNT 累加非 NULL 值，两列聚合输出一行。

星期编号依据：MySQL WEEKDAY 官方文档。条件 COUNT 使空表也自然返回两个 0。

正确性

对任一有效非空日期，其星期编号恰好落在 {0,1,2,3,4} 或 {5,6} 中；两集合互斥且覆盖一周，所以该行恰好被正确类别计数一次。处理前 k 行后，两个累加器分别等于这些行中的两类任务数。加入下一行只增加其所属类别，性质保持。遍历所有行后，得到所求总数。

边界

  • 同日或同一负责人有多项任务时，每行分别贡献，不去重；缺少某个星期的数据无需补齐。
  • 全为周末或全为工作日时，另一列为 0。空表时，本实现输出一行 (0,0)。
  • NULL 日期无法确定类别，本实现两列都不计入。题面没有明确此种输入的期望，真实业务应单独约定。

复杂度

按每行日期函数为常数成本计，扫描 n 行需要 O(n) 时间。两个累加器使用 O(1) 额外空间，不含表存储及数据库执行器开销。

替代方案

MySQL 可用 SUM(WEEKDAY(submit_date) IN (5,6)) 加总布尔值，另一个表达式统计工作日；空输入时 SUM 为 NULL，需要 COALESCE 包裹才能返回 0。两个独立筛选计数查询也可行，但重复读取表；按类别分组会得到多行，还要处理缺失类别并转换列。

常见错误

  • COUNT(条件) 会连 false / 0 一起计数，因为它们并非 NULL；CASE 不能写 ELSE 0。
  • 混淆 WEEKDAY 和 DAYOFWEEK：后者周日为 1、周六为 7。
  • DISTINCT 日期或负责人会合并不同任务；WHERE 仅保留周末会丢失工作日行。
  • 把节假日、调休混入题意；本题只依据一周中的日期类别。

面试追问

  • 按负责人统计？加上 assignee_id 和 GROUP BY；零任务负责人需要负责人表与左连接。
  • 支持节假日与调休？关联业务日历表，以业务标签替代固定星期判断。
  • 输入变成时间戳？先按业务时区转换为日期，避免午夜附近跨日。
  • 超大表反复统计？先确认日期筛选范围和汇总需求，再评估预聚合；日期索引本身不能免除全量总数统计的读取。

MySQL · 官方可提交语言

SELECT
    COUNT(CASE WHEN WEEKDAY(submit_date) IN (5, 6)
               THEN 1 END) AS weekend_cnt,
    COUNT(CASE WHEN WEEKDAY(submit_date) BETWEEN 0 AND 4
               THEN 1 END) AS working_cnt
FROM Tasks;

Java 17 · 本地语义参考

import java.time.LocalDate;
import java.util.List;

public class Main {
    record Task(int taskId, int assigneeId, LocalDate submitDate) {}
    record Counts(long weekend_cnt, long working_cnt) {}

    static Counts countTasks(List<Task> tasks) {
        long weekend = 0, working = 0;
        for (Task task : tasks) {
            if (task.submitDate() == null) continue;
            int day = task.submitDate().getDayOfWeek().getValue();
            if (day >= 6) weekend++;
            else working++;
        }
        return new Counts(weekend, working);
    }

    public static void main(String[] args) {
        var tasks = List.of(
            new Task(1, 1, LocalDate.parse("2022-06-13")),
            new Task(2, 6, LocalDate.parse("2022-06-14")),
            new Task(3, 6, LocalDate.parse("2022-06-15")),
            new Task(4, 3, LocalDate.parse("2022-06-18")),
            new Task(5, 5, LocalDate.parse("2022-06-19")),
            new Task(6, 7, LocalDate.parse("2022-06-19"))
        );
        System.out.println(countTasks(tasks));
    }
}

JavaScript · 本地语义参考

// 行格式：[task_id, assignee_id, submit_date]
function countTasks(tasks) {
  let weekend_cnt = 0, working_cnt = 0;
  for (const [, , date] of tasks) {
    if (date === null) continue;
    if (typeof date !== "string" || !/^\d{4}-\d{2}-\d{2}$/.test(date)) {
      throw new Error("日期必须为 YYYY-MM-DD");
    }
    const parsed = new Date(date + "T00:00:00Z");
    if (!Number.isFinite(parsed.getTime()) ||
        parsed.toISOString().slice(0, 10) !== date) {
      throw new Error("无效日期");
    }
    const day = parsed.getUTCDay(); // 周日=0，周六=6
    if (day === 0 || day === 6) weekend_cnt++;
    else working_cnt++;
  }
  return {weekend_cnt, working_cnt};
}
const tasks = [
  [1, 1, "2022-06-13"], [2, 6, "2022-06-14"],
  [3, 6, "2022-06-15"], [4, 3, "2022-06-18"],
  [5, 5, "2022-06-19"], [6, 7, "2022-06-19"]
];
console.log(countTasks(tasks));

from datetime import date


def count_tasks(tasks):
    weekend = working = 0
    for task_id, assignee_id, submit_date in tasks:
        if submit_date is None:
            continue
        day = date.fromisoformat(submit_date).weekday()  # 周一=0
        if day >= 5:
            weekend += 1
        else:
            working += 1
    return {"weekend_cnt": weekend, "working_cnt": working}

C++20 · 本地语义参考

#include <chrono>
#include <iostream>
#include <optional>
#include <stdexcept>
#include <vector>
using namespace std;
using namespace std::chrono;

struct Task {
    int task_id, assignee_id;
    optional<year_month_day> submit_date;
};
struct Counts { long long weekend_cnt, working_cnt; };

Counts countTasks(const vector<Task>& tasks) {
    Counts result{0, 0};
    for (const auto& task : tasks) {
        if (!task.submit_date) continue;
        if (!task.submit_date->ok()) throw invalid_argument("invalid date");
        unsigned day = weekday{sys_days{*task.submit_date}}.iso_encoding();
        if (day >= 6) ++result.weekend_cnt;
        else ++result.working_cnt;
    }
    return result;
}

int main() {
    vector<Task> tasks{
        {1, 1, year{2022}/6/13}, {2, 6, year{2022}/6/14},
        {3, 6, year{2022}/6/15}, {4, 3, year{2022}/6/18},
        {5, 5, year{2022}/6/19}, {6, 7, year{2022}/6/19}
    };
    auto result = countTasks(tasks);
    cout << result.weekend_cnt << " " << result.working_cnt << '\n';
}
