矩阵中的幻方

在一张最多 10 × 10 的数字网格里，数一数有多少个 3 × 3 区域同时满足数字唯一与八条线等和。

Problem

题目描述

grid → integer

3 × 3 幻方由 1 到 9 这九个互不相同的数字组成，并且三行、三列以及两条对角线上的数字之和全部相同。

给定一个整数矩阵 grid，返回其中 3 × 3 幻方子矩阵的数量。子矩阵必须由连续的三行和连续的三列构成。

注意：合法幻方内部只能出现 1 到 9，但输入网格中的数字可以达到 15。
示例 1
输入：grid = [[4,3,8,4],
              [9,5,1,9],
              [2,7,6,2]]
输出：1
解释：左侧 3 × 3 区域是幻方，右侧区域不是。
示例 2
输入：grid = [[8]]
输出：0
解释：网格不足 3 行、3 列，不存在候选区域。

约束

  • row == grid.length
  • col == grid[i].length
  • 1 <= row, col <= 10
  • 0 <= grid[i][j] <= 15

Solution

枚举窗口 + 逐项校验

清楚、直接、约束内足够快

核心洞察

候选很少最多只有 (row − 2)(col − 2) 个连续 3 × 3 窗口，可以逐个枚举。
数字条件不可省仅检查八条线等和不够；还必须保证九个数字恰好是 1 到 9 且互不相同。
目标和固定1 到 9 的总和是 45，三行等和，因此每行、每列、每条对角线都必须等于 15。

完整过程

  1. 若行数或列数小于 3，直接返回 0。
  2. 枚举每个可能的左上角 (r, c)，窗口覆盖 r..r+2 与 c..c+2。
  3. 用长度为 10 的布尔数组检查窗口中的每个数：必须位于 1..9，且不能重复。
  4. 分别计算三行、三列与两条对角线的和；任意一条不等于 15，就淘汰该窗口。
  5. 所有条件都通过时，答案加一。

正确性证明

充分性：算法计数的每个窗口都包含 1..9 的九个不同数字，且三行、三列和两条对角线之和均为 15，完全满足幻方定义，因此不会误计。

必要性：任意合法 3 × 3 幻方都对应某个被枚举到的左上角；其数字范围、唯一性与八条线等和检查必然全部通过，因此不会漏计。

综上，算法返回值恰好是网格内 3 × 3 幻方的数量。

边界情况

  • 网格任一维小于 3：没有候选窗口。
  • 出现 0、10..15：当前窗口立即失败。
  • 数字都在 1..9 但有重复：即使部分线之和相同，也不是幻方。
  • 多个窗口可能重叠：它们仍应独立判断、分别计数。

复杂度

时间：O(row × col)额外空间：O(1)

每个窗口只处理固定的 9 个格子与 8 条线，因此窗口校验是常数时间。

class Solution {
    public int numMagicSquaresInside(int[][] grid) {
        int rows = grid.length, cols = grid[0].length;
        int answer = 0;
        for (int r = 0; r + 2 < rows; r++)
            for (int c = 0; c + 2 < cols; c++)
                if (isMagic(grid, r, c)) answer++;
        return answer;
    }
    private boolean isMagic(int[][] g, int r, int c) {
        boolean[] seen = new boolean[10];
        for (int i = r; i < r + 3; i++) for (int j = c; j < c + 3; j++) {
            int v = g[i][j];
            if (v < 1 || v > 9 || seen[v]) return false;
            seen[v] = true;
        }
        for (int i = 0; i < 3; i++) {
            if (g[r+i][c] + g[r+i][c+1] + g[r+i][c+2] != 15) return false;
            if (g[r][c+i] + g[r+1][c+i] + g[r+2][c+i] != 15) return false;
        }
        return g[r][c] + g[r+1][c+1] + g[r+2][c+2] == 15
            && g[r][c+2] + g[r+1][c+1] + g[r+2][c] == 15;
    }
}

var numMagicSquaresInside = function(grid) {
    const isMagic = (r, c) => {
        const seen = Array(10).fill(false);
        for (let i = r; i < r + 3; i++) for (let j = c; j < c + 3; j++) {
            const v = grid[i][j];
            if (v < 1 || v > 9 || seen[v]) return false;
            seen[v] = true;
        }
        for (let i = 0; i < 3; i++) {
            if (grid[r+i][c] + grid[r+i][c+1] + grid[r+i][c+2] !== 15) return false;
            if (grid[r][c+i] + grid[r+1][c+i] + grid[r+2][c+i] !== 15) return false;
        }
        return grid[r][c] + grid[r+1][c+1] + grid[r+2][c+2] === 15
            && grid[r][c+2] + grid[r+1][c+1] + grid[r+2][c] === 15;
    };
    let answer = 0;
    for (let r = 0; r + 2 < grid.length; r++)
        for (let c = 0; c + 2 < grid[0].length; c++)
            if (isMagic(r, c)) answer++;
    return answer;
};
from typing import List

class Solution:
    def numMagicSquaresInside(self, grid: List[List[int]]) -> int:
        def is_magic(r: int, c: int) -> bool:
            seen = [False] * 10
            for i in range(r, r + 3):
                for j in range(c, c + 3):
                    value = grid[i][j]
                    if value < 1 or value > 9 or seen[value]:
                        return False
                    seen[value] = True
            for i in range(3):
                if sum(grid[r + i][c:c + 3]) != 15:
                    return False
                if sum(grid[r + k][c + i] for k in range(3)) != 15:
                    return False
            return (
                sum(grid[r+i][c+i] for i in range(3)) == 15
                and sum(grid[r+i][c+2-i] for i in range(3)) == 15
            )
        return sum(
            is_magic(r, c)
            for r in range(len(grid) - 2)
            for c in range(len(grid[0]) - 2)
        )
class Solution {
public:
    int numMagicSquaresInside(vector<vector<int>>& grid) {
        int answer = 0;
        for (int r = 0; r + 2 < grid.size(); ++r)
            for (int c = 0; c + 2 < grid[0].size(); ++c)
                if (isMagic(grid, r, c)) ++answer;
        return answer;
    }
private:
    bool isMagic(const vector<vector<int>>& g, int r, int c) {
        bool seen[10] = {};
        for (int i = r; i < r + 3; ++i) for (int j = c; j < c + 3; ++j) {
            int v = g[i][j];
            if (v < 1 || v > 9 || seen[v]) return false;
            seen[v] = true;
        }
        for (int i = 0; i < 3; ++i) {
            if (g[r+i][c] + g[r+i][c+1] + g[r+i][c+2] != 15) return false;
            if (g[r][c+i] + g[r+1][c+i] + g[r+2][c+i] != 15) return false;
        }
        return g[r][c] + g[r+1][c+1] + g[r+2][c+2] == 15
            && g[r][c+2] + g[r+1][c+1] + g[r+2][c] == 15;
    }
};

替代方案

可以利用所有 3 × 3 正规幻方都是洛书的旋转或镜像这一性质，把窗口外圈编码后与固定的 8 种序列比对。它的常数更小，但可读性较差，也更容易在方向和编码上出错。

  • 能否只检查中心与外圈顺序？
  • 若改为 n × n 幻方，复杂度和判定逻辑如何变化？

常见错误

只看和，不看唯一性：全是 5 的矩阵每条线都等和，却不是题目定义的幻方。
漏掉反对角线：主对角线与反对角线都必须检查。
窗口边界多走一步：左上角必须满足 r + 2 < rows 且 c + 2 < cols。
