Solution

分组计数后筛选最大值

核心洞察

答案只取决于 Project 表中每个 project_id 出现的次数。先聚合得到人数，再把人数等于全局最大人数的所有项目留下；“所有”意味着不能只用 ORDER BY ... LIMIT 1。

完整过程

  1. 按项目编号分组。
  2. 用 COUNT(employee_id) 计算每组人数。
  3. 子查询再次分组并按人数降序取最大人数。
  4. HAVING 仅保留人数等于最大值的组。
正确性：分组计数为每个项目产生其确切员工数。子查询选出的值是这些计数的最大值。外层 HAVING 当且仅当某项目计数等于该最大值时保留它，因此结果恰好包含全部且仅包含员工最多的项目。

边界情况

  • 只有一个项目：直接返回它。
  • 多个项目并列：全部返回。
  • 项目编号不连续：不影响分组。
  • 同一员工可属于不同项目：每个项目各计一次。

复杂度

设 Project 有 n 行、项目数为 p。概念上读取为 O(n)，维护分组为 O(p) 空间；数据库实际代价依执行计划、索引及哈希/排序聚合而定。

官方可提交语言：MySQL

SELECT project_id
FROM Project
GROUP BY project_id
HAVING COUNT(employee_id) = (
  SELECT COUNT(employee_id)
  FROM Project
  GROUP BY project_id
  ORDER BY COUNT(employee_id) DESC
  LIMIT 1
);

import java.util.*;

class Solution {
  public List<Integer> mostEmployees(int[][] project) {
    Map<Integer, Integer> count = new HashMap<>();
    int best = 0;
    for (int[] row : project) {
      int next = count.getOrDefault(row[0], 0) + 1;
      count.put(row[0], next);
      best = Math.max(best, next);
    }
    List<Integer> answer = new ArrayList<>();
    for (Map.Entry<Integer, Integer> e : count.entrySet())
      if (e.getValue() == best) answer.add(e.getKey());
    return answer;
  }
}
function mostEmployees(project) {
  const count = new Map();
  let best = 0;
  for (const [projectId] of project) {
    const next = (count.get(projectId) ?? 0) + 1;
    count.set(projectId, next);
    best = Math.max(best, next);
  }
  return [...count]
    .filter(([, total]) => total === best)
    .map(([projectId]) => projectId);
}
from collections import Counter
from typing import List

class Solution:
    def most_employees(self, project: List[List[int]]) -> List[int]:
        counts = Counter(project_id for project_id, _ in project)
        best = max(counts.values())
        return [project_id for project_id, total in counts.items()
                if total == best]

class Solution {
public:
  vector<int> mostEmployees(const vector<vector<int>>& project) {
    unordered_map<int, int> count;
    int best = 0;
    for (const auto& row : project) best = max(best, ++count[row[0]]);
    vector<int> answer;
    for (const auto& [id, total] : count)
      if (total == best) answer.push_back(id);
    return answer;
  }

替代方案

支持窗口函数时，可先聚合，再用 DENSE_RANK() OVER (ORDER BY COUNT(*) DESC) 排名并取第 1 名，表达并列语义更直观。MySQL 8 也可用 CTE 求 MAX(employee_count)。

面试追问

  • 为什么不需要连接 Employee？
  • 如何用窗口函数改写？
  • 若 Project 允许重复关系，应该用 COUNT 还是 COUNT DISTINCT？
  • 怎样设计索引帮助分组？

常见错误

  • LIMIT 1 直接返回单行，遗漏并列项目。
  • 无必要地连接 Employee，增加查询开销和出错面。
  • 在 WHERE 中使用聚合条件；聚合后的过滤应使用 HAVING。
  • 把员工经验年限求和或平均，偏离“员工数量”。
