Number of Valid Words for Each Puzzle

一张围绕“必须包含首字母”的七字母谜面制作的学习页。先理解判定规则，再用交互实验观察候选字母集合；完整题解保持折叠，留出独立思考空间。

Problem

题目描述

给定单词数组 words 和谜面数组 puzzles。对于某个谜面 puzzle，一个单词 word 是有效谜底，当且仅当：

  1. word 包含 puzzle 的第一个字母；
  2. word 中出现的每一种字母，都能在 puzzle 中找到。
返回数组 answer，其中 answer[i] 表示 words 中对 puzzles[i] 有效的单词数量。单词内同一字母出现多次不会要求谜面也重复出现该字母。

函数签名： findNumOfValidWords(words: string[], puzzles: string[]) → integer[]

words = ["aaaa","asas","able","ability","actt","actor","access"]
puzzles = ["aboveyz","abrodyz","abslute","absoryz","actresz","gaswxyz"]

Constraints

约束

  • 1 ≤ words.length ≤ 10⁵
  • 4 ≤ words[i].length ≤ 50
  • 1 ≤ puzzles.length ≤ 10⁴
  • puzzles[i].length == 7
  • words[i] 与 puzzles[i] 只包含小写英文字母。
  • 每个 puzzles[i] 内的字符互不重复。

Solution

位掩码频次 + 枚举谜面子集

核心洞察

有效性只关心字母是否出现，不关心次数和顺序。把 a...z 映射到二进制的第 0...25 位，一个单词即可压缩为 26 位掩码。先统计每种单词掩码的频次。

谜面恰有 7 个不同字母。任何有效单词的掩码必须是谜面掩码的子集，并且必须包含谜面的首字母。固定首字母，只枚举剩余 6 位的子集，一共恰好 2⁶ = 64 个。

完整过程

  1. 遍历 words，为每个单词构造去重位掩码并加入频次表。
  2. 对每个谜面，取首字母位 first，将其余 6 个字母组成 rest。
  3. 从 sub = rest 开始，用 sub = (sub - 1) & rest 依次枚举所有子集。
  4. 查询 freq[sub | first] 并累加；处理完 sub = 0 后结束。

为什么正确

引理 1：单词满足“每个字母都在谜面中”，当且仅当其掩码是谜面掩码的子集。位掩码恰好记录出现过的字母，所以两者等价。
引理 2：所有包含首字母的谜面子集，都可唯一表示为 first | sub，其中 sub 是其余 6 位的某个子集。枚举 64 个 sub 不重不漏。
结论：根据引理 1，所有有效单词的掩码必在枚举集合中；根据引理 2，每种有效掩码恰被查询一次。频次表保留了共享同一掩码的全部单词数量，因此累加结果就是每个谜面的有效单词数。

复杂度

设所有单词总字符数为 C，谜面数为 P。

时间：O(C + 64P)
空间：O(U)，U 为不同单词掩码数，至多 min(words.length, 2²⁶)。

边界处理

  • 重复字母只设置同一位。
  • 只含首字母的掩码对应 sub = 0，不能漏掉。
  • 频次可能为零，哈希表默认按 0 累加。
  • JavaScript 位运算是有符号 32 位，但这里只使用低 26 位，安全。

替代方案

也可按首字母建立 Trie，再限制搜索到谜面字母，但结构和常数更复杂。逐个单词检查每个谜面需要近似 O(WP)，在 10⁵ × 10⁴ 下不可行。

面试追问

  • 若谜面长度变成 20？ 枚举子集会到百万级，应考虑按首字母分桶后遍历较小一侧，或使用 SOS DP。
  • 为什么不丢弃字母数超过 7 的单词？ 可以丢弃以省空间，因为它不可能是任何七字母谜面的子集；不是正确性所必需。
  • 如何输出实际匹配单词？ 将频次表改为掩码到单词索引列表，但输出本身可能很大。

常见错误

  • 枚举完整谜面子集后再判断首字母，写法更绕且容易漏判。
  • while (sub > 0) 后忘记单独统计 first 掩码。
  • 把字母出现次数编码进状态，导致状态无谓膨胀。
  • 对子集递推表达式缺少括号，破坏运算优先级。

import java.util.*;

class Solution {
    public List<Integer> findNumOfValidWords(String[] words, String[] puzzles) {
        Map<Integer, Integer> frequency = new HashMap<>();
        for (String word : words) {
            int mask = 0;
            for (char ch : word.toCharArray()) {
                mask |= 1 << (ch - 'a');
            }
            // 超过 7 种字母的单词不可能匹配任何谜面。
            if (Integer.bitCount(mask) <= 7) {
                frequency.merge(mask, 1, Integer::sum);
            }
        }

        List<Integer> answer = new ArrayList<>(puzzles.length);
        for (String puzzle : puzzles) {
            int first = 1 << (puzzle.charAt(0) - 'a');
            int rest = 0;
            for (int i = 1; i < puzzle.length(); i++) {
                rest |= 1 << (puzzle.charAt(i) - 'a');
            }

            int count = 0;
            int sub = rest;
            while (true) {
                count += frequency.getOrDefault(sub | first, 0);
                if (sub == 0) break;
                sub = (sub - 1) & rest;
            }
            answer.add(count);
        }
        return answer;
    }
}

var findNumOfValidWords = function(words, puzzles) {
    const frequency = new Map();

    for (const word of words) {
        let mask = 0;
        for (const ch of word) {
            mask |= 1 << (ch.charCodeAt(0) - 97);
        }
        if (countBits(mask) <= 7) {
            frequency.set(mask, (frequency.get(mask) || 0) + 1);
        }
    }

    return puzzles.map((puzzle) => {
        const first = 1 << (puzzle.charCodeAt(0) - 97);
        let rest = 0;
        for (let i = 1; i < puzzle.length; i++) {
            rest |= 1 << (puzzle.charCodeAt(i) - 97);
        }

        let answer = 0;
        let sub = rest;
        while (true) {
            answer += frequency.get(sub | first) || 0;
            if (sub === 0) break;
            sub = (sub - 1) & rest;
        }
        return answer;
    });
};

function countBits(value) {
    let count = 0;
    while (value !== 0) {
        value &= value - 1;
        count++;
    }
    return count;
}

#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> findNumOfValidWords(
        vector<string>& words,
        vector<string>& puzzles
    ) {
        unordered_map<int, int> frequency;
        for (const string& word : words) {
            int mask = 0;
            for (char ch : word) {
                mask |= 1 << (ch - 'a');
            }
            if (__builtin_popcount(mask) <= 7) {
                ++frequency[mask];
            }
        }

        vector<int> answer;
        answer.reserve(puzzles.size());
        for (const string& puzzle : puzzles) {
            int first = 1 << (puzzle[0] - 'a');
            int rest = 0;
            for (int i = 1; i < 7; ++i) {
                rest |= 1 << (puzzle[i] - 'a');
            }

            int count = 0;
            int sub = rest;
            while (true) {
                auto it = frequency.find(sub | first);
                if (it != frequency.end()) count += it->second;
                if (sub == 0) break;
                sub = (sub - 1) & rest;
            }
            answer.push_back(count);
        }
        return answer;
    }
};
