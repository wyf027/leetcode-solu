Number of Ways to Divide a Long Corridor

一条长廊，若干座位与植物。

题目 · 先独立思考

给定从下标 0 开始、长度为 n 的字符串 corridor，其中 S 表示座位，P 表示植物。下标 0 左侧与下标 n − 1 右侧已经各有一道固定屏风。

你可以在相邻字符之间增设屏风：对每个 1 ≤ i ≤ n − 1，位置 i − 1 与 i 之间至多放一道。划分后每一段必须恰好有两个座位，植物数量不限。

任意一道新增屏风的位置不同，就算不同方案。返回合法方案数对 1,000,000,007 取余的结果；无解时返回 0。

参数与约束

  • numberOfWays(corridor: string) → integer
  • n == corridor.length
  • 1 ≤ n ≤ 100000
  • corridor[i] 只能为 'S' 或 'P'。

题解 · 配对固定，屏风位置可变

核心洞察

按出现顺序，第 1、2 个座位必须属于第一段，第 3、4 个必须属于第二段，以此类推。座位配对没有选择，选择只发生在相邻两对之间。

设上一对末座位下标为 a，下一对首座位下标为 b。中间有 b − a − 1 株植物，可以放屏风的缝隙数为 b − a。每个区间独立选择一道屏风，方案数就是所有区间缝隙数的乘积。

座位总数必须是正偶数，否则答案为 0。只有一对座位时不新增屏风，空乘积为 1。首尾植物不产生选择。

每个区间选一道屏风

按钮数字 b 表示放在下标 b 之前。左右端屏风固定，各区间选一个位置即可构成一种方案。



完整过程
  1. 初始化 seats = 0、prev = −1、ways = 1。
  2. 从左向右扫描，遇到植物直接跳过。
  3. 遇到座位先让 seats 加一。若它是第 3、5、7…个座位，则开启新配对，将 i − prev 乘入 ways 并取模。
  4. 每遇到一个座位都更新 prev = i，记录最近座位下标。
  5. 结束时，座位数为正偶数则返回 ways，否则返回 0。
示例 1：座位下标 [0,1,4,6]。读到下标 4 时乘入 4 − 1 = 3；最终座位数为 4，答案为 3。
正确性证明
  1. 必要配对：第一段只能包含最前两个座位，不能包含第三个。同理，第 k 段只能包含第 2k − 1、2k 个座位。
  2. 合法边界：相邻配对之间必须恰有一道屏风；零道会让一段含至少四座，两道会产生零座位段。屏风只能在上一对末座位 a 之后、下一对首座位 b 之前的 b − a 个缝隙中选择。
  3. 一一对应：每个区间选一个缝隙唯一确定合法划分，每种合法划分也唯一给出这些选择。区间互不相交，乘法原理成立。
  4. 实现不变式：扫描至新配对首座位时，prev 恰是上一对末座位；累乘加入且仅加入该区间因子。最终可行性检查排除零座位与奇数座位。


边界与复杂度
  • 零座位、奇数座位：返回 0。
  • 恰好两个座位：返回 1，头尾植物都留在这一段。
  • 配对紧挨时，间距为 1，仍有一个屏风位置。
  • 首尾植物不能单独切出零座位段。
  • 提交实现：时间 O(n)，额外空间 O(1)。
  • 交互演示保存回退状态，额外空间 O(n)，与提交实现不同。
替代方案
座位下标数组：收集 p，先检查座位总数，再累乘 p[2] − p[1]、p[4] − p[3]…；时间 O(n)，空间 O(n)，直观但多存数组。
三状态 DP：d0、d1、d2 表示最后未封闭段分别含 0、1、2 个座位的方案数，初始 (1,0,0)。每读字符前，可将 d2 通过新增屏风转入 d0。读 P 时新状态为 (d0+d2,d1,d2)，读 S 时为 (0,d0+d2,d1)，各项取模。末尾返回 d2；时间 O(n)，空间 O(1)，适合规则扩展。


四语言完整代码
采用官方提交签名。Java / C++ 使用 64 位中间乘积；Python 整数自动扩展。JavaScript 每次乘法前 ways < 1e9+7，间距 ≤ 1e5，乘积小于 1.01e14，低于 2⁵³，因此本题约束下 Number 能精确存储中间整数。


Java
class Solution {
    public int numberOfWays(String corridor) {
        final long MOD = 1_000_000_007L;
        long ways = 1;
        int seats = 0, prev = -1;
        for (int i = 0; i < corridor.length(); i++) {
            if (corridor.charAt(i) != 'S') continue;
            seats++;
            if (seats > 2 && seats % 2 == 1) {
                ways = ways * (i - prev) % MOD;
            }
            prev = i;
        }
        return seats > 0 && seats % 2 == 0 ? (int) ways : 0;
    }
}

C++
#include <string>
using namespace std;

class Solution {
public:
    int numberOfWays(string corridor) {
        const long long MOD = 1000000007LL;
        long long ways = 1;
        int seats = 0, prev = -1;
        for (int i = 0; i < static_cast<int>(corridor.size()); ++i) {
            if (corridor[i] != 'S') continue;
            ++seats;
            if (seats > 2 && seats % 2 == 1) {
                ways = ways * (i - prev) % MOD;
            }
            prev = i;
        }
        return seats > 0 && seats % 2 == 0 ? static_cast<int>(ways) : 0;
    }
};


常见错误
  • 乘植物数 k，漏掉一个缝隙：应乘 k+1。
  • 遇到每个座位都乘间距：只有第 3、5、7…个座位会开启新边界区间。
  • 更新 prev 后才求差，导致因子为 0。
  • 遗漏正偶数检查，让全植物输入返回 1。
  • 把头尾植物计为额外方案，切出零座位段。
  • Java / C++ 用 int 乘法导致溢出，应在乘法时就使用长整数。
面试追问
  • 每段 k 个座位？k 为正整数，总座位数须为正且能被 k 整除；在第 k+1、2k+1…个座位处乘与前一座位的间距。
  • 输入是字符流？维护当前位置、最近座位下标、座位数及累乘值，流结束做可行性检查。
  • 输出实际划分？每个区间任选一个缝隙，例如紧贴上一对末座位。
  • 一些缝隙禁止放屏风？将因子改为该区间允许的缝隙数，任何因子为零就无解。
