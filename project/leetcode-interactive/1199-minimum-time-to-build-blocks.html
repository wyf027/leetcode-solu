建造街区的
最短时间

Minimum Time to Build Blocks

LeetCode 1199 数组 贪心 数学 优先队列

Problem brief

任务说明

有若干街区需要建造，blocks[i] 表示第 i 个街区由一名工人独立完成所需的时间。最初只有一名工人。

  • 一名工人可以选择建造一个街区；完成后这名工人离开，不能继续承担其他街区。
  • 一名工人也可以花费 split 时间分裂成两名工人。
  • 不同工人的分裂与建造可以并行进行，所以总时间由最晚完成的分支决定。

目标：返回建完全部街区的最短时间。

Official signature

minBuildTime(blocks, split) → int

关键语义：一次分裂只让工人数增加 1；但多个分裂可以同时发生。

完整题解

核心洞察

任意方案都可看成一棵二叉树：内部节点是一次分裂，叶子是街区。叶子 i 的完成时刻为 blocks[i] + depth[i] × split，目标是让这些时刻的最大值最小。

把两个当前最短的分支 a ≤ b 放在同一次分裂下，其父分支耗时为 split + max(a, b) = split + b。因此可用最小堆反复合并两个最小值。

完整过程

  1. 将所有 blocks[i] 放进最小堆。
  2. 堆中多于一个元素时，取出最小的 a 与次小的 b。
  3. 把 b + split 放回堆；a 被 b 的较慢分支覆盖。
  4. 堆中唯一剩余值就是最短总时间。

正确性证明

  1. 树模型成立。每次分裂产生两个子工人，所以完整施工方案与以街区为叶子的满二叉树一一对应；一条根到叶的路径上，每个分裂都增加 split。
  2. 贪心选择安全。在某个最优树的最深层，存在一对兄弟分支。若这对不是当前耗时最小的两个分支，可把更小的分支与它们交换；更小值被放到不浅的位置不会增大任何根到叶路径的最大完成时间。因此存在一个最优方案让两个最小分支成为兄弟。
  3. 最优子结构。设两者为 a ≤ b。它们共用父分裂后，对上层而言等价为耗时 split + max(a,b) = split+b 的一个伪街区。收缩这对兄弟后，剩余问题与原问题形式相同。
  4. 归纳完成。每轮都可作出上述安全选择并把规模减一；直到只剩一个分支，因此算法得到全局最优值。

复杂度与边界

  • 时间：O(n log n)，共进行 n - 1 次堆合并。
  • 空间：O(n)，堆保存当前分支。
  • n = 1 时无需分裂，直接返回唯一耗时。
  • 重复耗时无需特殊处理；最小堆自然保留全部元素。
  • split 很大时仍必须为多个街区创造足够工人，算法会自动选择不平衡的树形以减少关键路径上的分裂。

替代方案

可将街区按耗时排序后做动态规划：状态描述处理若干街区、当前拥有若干工人时的最短完成时间。根据“建造”或“让全部现有工人并行分裂”转移，可做到约 O(n²)。

它更贴近官方提示，适合推导，但实现与状态边界更复杂；最小堆方法更短，且达到 O(n log n)。

面试追问

  • 为什么只把较大值加上 split？因为两个子分支并行，父分支完成时间取最大值。
  • 若每次分裂成本不同，局部合并是否仍成立？通常不成立，需要把时间或层级纳入状态。
  • 若一名工人能连续建造多个街区，模型会怎样变化？叶子不再是一人一块，问题将转为机器调度类模型。

常见错误

  • 把并行耗时写成 a + b + split；正确的是 max(a,b) + split。
  • 每轮合并最大的两个值，会让大街区承担更多层分裂，扩大关键路径。
  • 认为一个工人能建完一个街区后继续工作；题意规定其完成后离开。
  • 只计算需要多少名工人，却忽略不同分裂层数对应不同到达时间。

四语言完整代码

JavaPriorityQueue
import java.util.PriorityQueue;

class Solution {
    public int minBuildTime(int[] blocks, int split) {
        PriorityQueue<Integer> heap = new PriorityQueue<>();
        for (int time : blocks) {
            heap.offer(time);
        }

        while (heap.size() > 1) {
            heap.poll();
            int second = heap.poll();
            heap.offer(second + split);
        }

        return heap.poll();
    }
}
JavaScriptBinary min-heap
class MinHeap {
  constructor(values = []) {
    this.data = [];
    for (const value of values) this.push(value);
  }

  get size() { return this.data.length; }

  push(value) {
    const a = this.data;
    a.push(value);
    let i = a.length - 1;
    while (i > 0) {
      const p = Math.floor((i - 1) / 2);
      if (a[p] <= a[i]) break;
      [a[p], a[i]] = [a[i], a[p]];
      i = p;
    }
  }

  pop() {
    const a = this.data;
    const root = a[0];
    const last = a.pop();
    if (a.length > 0) {
      a[0] = last;
      let i = 0;
      while (true) {
        let smallest = i;
        const left = i * 2 + 1;
        const right = left + 1;
        if (left < a.length && a[left] < a[smallest]) smallest = left;
        if (right < a.length && a[right] < a[smallest]) smallest = right;
        if (smallest === i) break;
        [a[i], a[smallest]] = [a[smallest], a[i]];
        i = smallest;
      }
    }
    return root;
  }
}

var minBuildTime = function(blocks, split) {
  const heap = new MinHeap(blocks);
  while (heap.size > 1) {
    heap.pop();
    const second = heap.pop();
    heap.push(second + split);
  }
  return heap.pop();
};
Pythonheapq
from typing import List
import heapq


class Solution:
    def minBuildTime(self, blocks: List[int], split: int) -> int:
        heap = blocks[:]
        heapq.heapify(heap)

        while len(heap) > 1:
            heapq.heappop(heap)
            second = heapq.heappop(heap)
            heapq.heappush(heap, second + split)

        return heap[0]
C++priority_queue
#include <functional>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    int minBuildTime(vector<int>& blocks, int split) {
        priority_queue<int, vector<int>, greater<int>> heap;
        for (int time : blocks) {
            heap.push(time);
        }

        while (heap.size() > 1) {
            heap.pop();
            int second = heap.top();
            heap.pop();
            heap.push(second + split);
        }

        return heap.top();
    }
};
