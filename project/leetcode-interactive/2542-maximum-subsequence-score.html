2542 · 最大子序列的分数

Maximum Subsequence Score

挑选恰好 k 对元素，让「总和 × 最小值」尽可能大。

前往 LeetCode 原题 ↗

01 / 题目与规则

给定长度同为 n、下标从 0 开始的整数数组 nums1 和 nums2，以及正整数 k。选取恰好 k 个不同下标，两个数组都使用这些下标。所选下标按原顺序构成子序列，无须连续。

分数 = 所选 nums1 元素之和 × 所选 nums2 元素的最小值

返回所有合法选择中的最大分数。每个下标对应的两个值必须一起选，不能独立搭配。

约束

  • n == nums1.length == nums2.length
  • 1 ≤ n ≤ 10⁵
  • 0 ≤ nums1[i], nums2[j] ≤ 10⁵，对所有合法下标成立。
  • 1 ≤ k ≤ n

示例 1

nums1 = [1,3,3,2]
nums2 = [2,1,3,4]
k = 3
输出：12

四种下标组合的分数：

  • [0,1,2]：(1+3+3) × 1 = 7
  • [0,1,3]：(1+3+2) × 1 = 6
  • [0,2,3]：(1+3+2) × 2 = 12
  • [1,2,3]：(3+3+2) × 1 = 8

最大值为 12。

示例 2

nums1 = [4,2,3,1,1]
nums2 = [7,5,10,9,6]
k = 1
输出：30

只选下标 2，得到 3 × 10 = 30，是所有单个下标的最大分数。

03 / 排序，把最小值变成门槛

核心洞察：将每对 (nums1[i], nums2[i]) 按 nums2 降序排列。当扫描到乘数 b 时，已扫描元素的 nums2 都 ≥ b。于是可以在当前前缀中挑 nums1 最大的 k 个，用其总和 S 计算候选值 S × b。

用一个容量不超过 k 的小根堆保存这些 nums1：每次加入一个值，若数量超过 k，就删除最小值。同步维护堆中总和，只有凑齐 k 个才计算候选值。

精确理解：当前元素可能被移出堆，因此 b 不一定是堆中下标真正的最小 nums2。S × b 是一个安全的下界候选，不要把每一步都称为所选集合的真实分数；下面的证明说明它仍能找到全局最优。

完整过程
  1. 构建配对，保留 nums1 与 nums2 的对应关系；按第二项降序排序。
  2. 建立小根堆，并将总和 S、答案 ans 初始化为 0。
  3. 依次加入当前 nums1 值到堆中，将它加到 S。
  4. 堆大小超过 k 时，弹出最小值，并从 S 中减去它。
  5. 堆大小等于 k 时，以 S × 当前 nums2 更新 ans。
  6. 扫描结束返回 ans。
示例 1 的配对顺序为 (2,4)、(3,3)、(1,2)、(3,1)。第三步凑齐 3 个，S = 6，候选为 12；第四步移除 1，S = 8，候选为 8，答案仍为 12。


为什么正确
  1. 堆不变式：扫描每个前缀后，堆保留其中最大的 min(k, 前缀长度) 个 nums1。加入后若超容量，删除最小值，恰好保留最大的 k 个，所以归纳成立。
  2. 候选不超过全局最优：堆满时，其对应下标是一个合法集合，每个 nums2 ≥ 当前门槛 b。因为 S ≥ 0，该集合真实分数 ≥ S × b，而真实分数 ≤ 全局最优 OPT，所以每个候选 ≤ OPT。
  3. 一定覆盖最优：取任一最优集合，并考虑其下标在排序序列中最后被扫描到的时刻。此时 b 等于该集合最小 nums2，且该集合全部位于前缀中。堆保留最大的 k 个 nums1，因此 S 不小于最优集合的总和。又因 b ≥ 0，此时 S × b ≥ OPT。
  4. 候选最大值既不大于 OPT，又至少有一个候选不小于 OPT，因此返回值恰好是 OPT。相同 nums2 的任意排序不影响上述论证。


边界与数值范围
  • k = 1：等价于找最大 nums1[i] × nums2[i]。
  • k = n：全选，结果为总和乘全局最小值。
  • 零与重复值均合法，答案从 0 开始即可。
  • 总和最大 10¹⁰，答案最大 10¹⁵。Java 用 long；C++ 用 long long；Python 整数自动扩展；JavaScript Number 的安全整数上限约 9 × 10¹⁵，覆盖本题。
  • 排序只重排配对以便计算，最终任意下标集合按原顺序排列都能形成子序列。
复杂度与替代方案
排序 O(n log n)，维护堆 O(n log(k+1))，总时间 O(n log n)。配对数组 O(n)，堆 O(k)，总辅助空间 O(n)。
  • 枚举 k 个下标：O(C(n,k) × k)，只适合极小 n 的思路核对。
  • 有序多重集合维护最大的 k 个：同样需要排序与 O(log k) 更新，小根堆更直接。
  • 固定当前项一定入选：先用此前最大的 k−1 项与当前项计算，再更新前缀堆。该变体候选是精确分数，k = 1 需正确处理空堆。

Java
import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public long maxScore(int[] nums1, int[] nums2, int k) {
        int n = nums1.length;
        int[][] pairs = new int[n][2];
        for (int i = 0; i < n; i++) {
            pairs[i][0] = nums1[i];
            pairs[i][1] = nums2[i];
        }
        Arrays.sort(pairs, (a, b) -> Integer.compare(b[1], a[1]));
        PriorityQueue<Integer> heap = new PriorityQueue<>();
        long sum = 0, answer = 0;
        for (int[] pair : pairs) {
            heap.offer(pair[0]);
            sum += pair[0];
            if (heap.size() > k) sum -= heap.poll();
            if (heap.size() == k) {
                answer = Math.max(answer, sum * pair[1]);
            }
        }
        return answer;
    }
}


JavaScript
/**
 * @param {number[]} nums1
 * @param {number[]} nums2
 * @param {number} k
 * @return {number}
 */
var maxScore = function(nums1, nums2, k) {
    const pairs = nums1.map((a, i) => [a, nums2[i]]);
    pairs.sort((a, b) => b[1] - a[1]);
    const heap = [];
    function push(x) {
        let i = heap.length;
        heap.push(x);
        while (i > 0) {
            const p = Math.floor((i - 1) / 2);
            if (heap[p] <= x) break;
            heap[i] = heap[p];
            i = p;
        }
        heap[i] = x;
    }
    function pop() {
        const root = heap[0];
        const x = heap.pop();
        if (heap.length) {
            let i = 0;
            while (2 * i + 1 < heap.length) {
                let c = 2 * i + 1;
                if (c + 1 < heap.length && heap[c + 1] < heap[c]) c++;
                if (heap[c] >= x) break;
                heap[i] = heap[c];
                i = c;
            }
            heap[i] = x;
        }
        return root;
    }
    let sum = 0, answer = 0;
    for (const [a, b] of pairs) {
        push(a);
        sum += a;
        if (heap.length > k) sum -= pop();
        if (heap.length === k) answer = Math.max(answer, sum * b);
    }
    return answer;
};

from typing import List
import heapq

class Solution:
    def maxScore(self, nums1: List[int], nums2: List[int], k: int) -> int:
        pairs = sorted(zip(nums1, nums2), key=lambda p: p[1], reverse=True)
        heap = []
        total = answer = 0
        for a, b in pairs:
            heapq.heappush(heap, a)
            total += a
            if len(heap) > k:
                total -= heapq.heappop(heap)
            if len(heap) == k:
                answer = max(answer, total * b)
        return answer


C++
#include <algorithm>
#include <functional>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    long long maxScore(vector<int>& nums1, vector<int>& nums2, int k) {
        vector<pair<int, int>> pairs;
        for (int i = 0; i < (int)nums1.size(); ++i)
            pairs.emplace_back(nums2[i], nums1[i]);
        sort(pairs.rbegin(), pairs.rend());
        priority_queue<int, vector<int>, greater<int>> heap;
        long long sum = 0, answer = 0;
        for (const auto& p : pairs) {
            heap.push(p.second);
            sum += p.second;
            if ((int)heap.size() > k) {
                sum -= heap.top();
                heap.pop();
            }
            if ((int)heap.size() == k)
                answer = max(answer, sum * p.first);
        }
        return answer;
    }
};




常见错误
  • 分别排序两个数组：破坏下标对应关系。
  • 仅选择 nums1 最大的 k 个：忽略乘数变化。
  • 使用大根堆弹出最大值：丢掉应保留的贡献。
  • 堆未满 k 个就更新答案：违反必须恰好选 k 个。
  • 弹出时忘记从总和扣除。
  • Java / C++ 用 32 位存储总和，或先用 int 做乘法：溢出。
  • 认为当前 b 总是堆中实际最小 nums2：应使用下界证明。
面试追问
  • 允许负数还能用吗？不能直接套用；非负总和和非负门槛支撑了两个不等式，符号变化会破坏证明。
  • 如何返回下标？堆中存值和下标，记录最优门槛，再重放到对应步骤提取集合，避免每次复制 k 个下标。
  • 同门槛需要整批处理吗？不需要，扫描到最优集合最后一项时已覆盖所有必要元素。
  • 能省去排序吗？通用方案需要降序处理；有界值域可以考虑桶，但会增加实现与空间成本。
