标点像钉子一样留在原位；字母则跨过它们，完成一次有秩序的镜像交换。

EASY双指针字符串非付费题

01题目

给定字符串 s，把其中所有英文字母（含大小写）的出现顺序反转；任何非英文字母必须留在原下标。返回变换后的字符串。

  • 参数：s: string
  • 返回：string
  • 1 ≤ s.length ≤ 100
  • 字符的 ASCII 值在 [33, 122]；不含双引号或反斜杠。
先观察：连字符、数字和感叹号的位置不变。你能只移动字母完成反转吗？

04完整题解

核心洞察

若把非字母看作固定障碍，只需反转剩余字母序列。无需额外收集字母：让左右指针寻找两端下一对字母，原地交换即可。

完整过程

  1. 把字符串转成可修改的字符数组，令 left = 0、right = n - 1。
  2. 若左端不是英文字母，递增 left；若右端不是英文字母，递减 right。
  3. 两端都是字母时交换它们，然后两个指针同时向内移动。
  4. 当 left ≥ right，拼接数组并返回。

正确性

循环不变式：每轮开始时，区间外的字母已经处于最终反转位置，非字母始终未被移动。

跳过非字母不会改变它们的位置。两指针分别找到尚未处理的最左、最右字母；反转后的目标恰好要求它们互换。交换后两者进入最终位置，不变式继续成立。指针最终相遇或交错，所有字母均已正确安放，因此结果满足要求。

边界与复杂度

  • 全是非字母、只有一个字母：没有交换，原样返回。
  • 大小写都按字母处理，字符本身的大小写不改变。
  • 时间复杂度 O(n)；除语言中字符串转字符数组的空间外，额外空间 O(1)。

四种语言实现

JavaASCII 判断
class Solution {
    public String reverseOnlyLetters(String s) {
        char[] a = s.toCharArray();
        int left = 0, right = a.length - 1;
        while (left < right) {
            while (left < right && !isLetter(a[left])) left++;
            while (left < right && !isLetter(a[right])) right--;
            if (left < right) {
                char t = a[left]; a[left] = a[right]; a[right] = t;
                left++; right--;
            }
        }
        return new String(a);
    }
    private boolean isLetter(char c) {
        return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z');
    }
}
JavaScript双指针
/** @param {string} s @return {string} */
var reverseOnlyLetters = function(s) {
    const a = [...s];
    let left = 0, right = a.length - 1;
    const isLetter = c => /[a-zA-Z]/.test(c);
    while (left < right) {
        while (left < right && !isLetter(a[left])) left++;
        while (left < right && !isLetter(a[right])) right--;
        if (left < right) {
            [a[left], a[right]] = [a[right], a[left]];
            left++; right--;
        }
    }
    return a.join('');
};
Python 3内置判断
class Solution:
    def reverseOnlyLetters(self, s: str) -> str:
        chars = list(s)
        left, right = 0, len(chars) - 1
        while left < right:
            while left < right and not chars[left].isalpha():
                left += 1
            while left < right and not chars[right].isalpha():
                right -= 1
            if left < right:
                chars[left], chars[right] = chars[right], chars[left]
                left += 1
                right -= 1
        return ''.join(chars)
C++安全字符判断
class Solution {
public:
    string reverseOnlyLetters(string s) {
        int left = 0, right = static_cast<int>(s.size()) - 1;
        auto letter = [](unsigned char c) { return std::isalpha(c); };
        while (left < right) {
            while (left < right && !letter(s[left])) ++left;
            while (left < right && !letter(s[right])) --right;
            if (left < right) {
                std::swap(s[left], s[right]);
                ++left; --right;
            }
        }
        return s;
    }
};

替代方案

可先提取全部字母到栈，再从左到右回填字母位置。它更直观，同为 O(n) 时间，但需要 O(n) 额外空间。双指针更贴合本题原地交换的结构。

面试追问

  • 若“字母”包含完整 Unicode，应如何判断并避免拆散代理对或组合字符？
  • 若输入是只读流，无法随机访问，怎样权衡缓存与输出时机？
  • 能否证明每个字符最多被指针访问常数次？

常见错误

  • 直接反转整串，导致标点换位。
  • 只判断小写字母，遗漏 A–Z。
  • 交换后忘记同时移动两个指针，造成死循环。
  • C/C++ 直接把可能为负的 char 传给 isalpha；应先转为 unsigned char。
