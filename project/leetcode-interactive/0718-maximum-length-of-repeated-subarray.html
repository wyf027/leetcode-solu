关键不是“出现过多少个相同数字”，而是相同关系能否沿着同一方向连续延伸。

Problem

题目说明

给定两个整数数组 nums1 和 nums2，返回同时出现在两个数组中的最长公共连续子数组的长度。子数组必须连续；这与允许跳过元素的“子序列”不同。

函数与约束

函数接收两个整数数组，输出一个整数。只需要返回最长长度，不要求返回公共片段本身。

findLength(nums1: integer[], nums2: integer[]) → integer

约束

  • 1 <= nums1.length, nums2.length <= 1000
  • 0 <= nums1[i], nums2[i] <= 100
示例 1
输入： nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]
输出： 3
解释： 最长公共连续子数组是 [3,2,1]。
示例 2
输入： nums1 = [0,0,0,0,0], nums2 = [0,0,0,0,0]
输出： 5
解释： 两个数组整体就是相同的连续片段。

Solution

动态规划：延长共同后缀

把二维比较关系压缩成“连续后缀长度”。相等时只看左上角，不相等时清零，因此连续性被精确地保留下来。

核心洞察完整过程正确性复杂度四语言代码替代方案面试追问常见错误

核心洞察

定义 dp[i][j] 为：nums1 的前 i 个元素与 nums2 的前 j 个元素中，恰好分别以第 i、j 个元素结尾的最长公共连续子数组长度。

nums1[i−1] == nums2[j−1] ? dp[i−1][j−1] + 1 : 0

答案不是右下角，而是所有状态的最大值，因为最长公共片段可能在任意位置结束。

完整过程

  1. 建立长度为 nums2.length + 1 的一维数组 dp，初始全为 0。
  2. 从左到右枚举 nums1 的每个元素。
  3. 对 nums2 必须从右到左枚举：相等时令 dp[j] = dp[j-1] + 1，否则清零。
  4. 每次更新后，用 dp[j] 刷新全局最大值。
  5. 遍历完成后返回最大值。

正确性证明

引理：状态转移正确

若两个结尾元素不同，就不存在同时以它们结尾的非空公共连续子数组，所以状态为 0。若相同，去掉这个共同结尾后，剩余部分必须恰好以各自前一个元素结尾；最长长度是 dp[i-1][j-1]，加回当前元素得到 dp[i-1][j-1] + 1。

定理：算法返回全局最优解

任意公共连续子数组都有一对结束位置，因此它的长度会被对应状态记录；反之，每个正状态都来自逐元素相等的连续延伸，确实对应一个合法公共子数组。取所有状态最大值，既不会漏掉最优解，也不会产生非法答案。

边界与复杂度

  • 长度均至少为 1，无需处理空数组；实现仍可自然兼容空数组。
  • 完全不相交时所有状态均为 0，答案为 0。
  • 全部相同时，答案是较短数组的长度。
  • 重复值很多时不能提前停止，必须区分不同结束位置。
  • 时间：O(mn)；空间：O(n)，其中 n = nums2.length。
一维压缩的关键是让 j 逆序。这样读取的 dp[j-1] 仍属于上一行，而不是当前行刚更新的值。

class Solution {
    public int findLength(int[] nums1, int[] nums2) {
        int[] dp = new int[nums2.length + 1];
        int answer = 0;

        for (int i = 1; i <= nums1.length; i++) {
            for (int j = nums2.length; j >= 1; j--) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    dp[j] = dp[j - 1] + 1;
                    answer = Math.max(answer, dp[j]);
                } else {
                    dp[j] = 0;
                }
            }
        }
        return answer;
    }
}

替代方案

  • 二维 DP：状态最直观，时间 O(mn)，空间 O(mn)，适合先讲清楚再压缩。
  • 滑动对齐：枚举两数组的相对偏移量，在每次重叠区间内统计最长连续相等段；时间仍为 O(mn)，额外空间 O(1)。
  • 二分答案 + 滚动哈希：检查是否存在长度为 L 的公共子数组，期望时间约 O((m+n) log min(m,n))；必须处理哈希碰撞。

面试追问

  • 如果要求返回公共子数组本身？记录最大值更新时的结束位置，再切片返回。
  • 为什么不能用最长公共子序列的转移？因为子序列允许跳过元素，而本题不匹配时必须归零。
  • 怎样把空间降到较短数组长度？让较短数组充当一维 dp 的列即可。
  • 滚动哈希如何降低碰撞风险？使用双模数或 64 位哈希，并在命中后逐元素确认。

常见错误

把子数组写成子序列

不相等时使用相邻状态最大值会允许跳过元素，改变题意。

一维 DP 正序更新

会读到当前行的新值，相当于重复使用同一个 nums1[i-1]。

只返回最后一个状态

最长片段不一定以数组末尾结束，必须维护全局最大值。

不相等时忘记清零

公共片段要求连续，一次不匹配就必须截断当前后缀。
