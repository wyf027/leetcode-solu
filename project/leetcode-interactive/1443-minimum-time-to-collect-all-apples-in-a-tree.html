收集树上所有苹果的
最少时间

从节点 0 出发，在一棵无向树中收集全部苹果，最终还要回到起点。先通过可视化观察哪些树枝值得走，再决定如何计算最短耗时。

中等n ≤ 10⁵每条边 1 秒必须返回 0

01 / PROBLEM

题目描述

函数：minTime(n, edges, hasApple)

给定一棵由 n 个节点组成的无向树，节点编号为 0 到 n - 1。部分节点上有苹果。沿任意一条边行走需要 1 秒。

你从节点 0 出发，需要收集树上的所有苹果，并最终回到节点 0。返回完成任务所需的最少秒数。

edges[i] = [aᵢ, bᵢ] 表示节点 aᵢ 与 bᵢ 之间有一条边；hasApple[i] 表示节点 i 是否有苹果。

CONSTRAINTS

  • 1 ≤ n ≤ 10⁵
  • edges.length = n - 1
  • edges[i].length = 2
  • 0 ≤ aᵢ < bᵢ ≤ n - 1
  • hasApple.length = n
  • 输入保证 edges 构成一棵树

04 / SOLUTION

后序 DFS：只为“含苹果的子树”付费

核心洞察

把树以节点 0 为根。若某个子节点的整棵子树中至少有一个苹果，那么连接父子节点的边一定要走：从父节点进入该子树一次，再沿同一条边返回一次，贡献恰好 2 秒。反之，这条边完全不必走。

根节点即使有苹果，也不需要经过任何边；因此只累计各个非根节点对应的必要父边。

完整过程

  1. 根据 edges 建立双向邻接表。
  2. 从节点 0 开始 DFS，并携带父节点，避免沿无向边回头。
  3. 以后序顺序处理节点：先汇总所有孩子是否需要被访问。
  4. 若孩子自身有苹果，或孩子的后代需要访问，就为该父子边加 2 秒。
  5. 根节点汇总完成时，累计值就是答案。

正确性证明

必要性：对任意包含苹果的非根子树，连接它与父节点的唯一边是从根进入该子树的必经边。任务要求回到根，因此该边至少经过两次。
充分性：对所有包含苹果的子树边各走一次进入、一次返回，可以从根完成每个必要子树的深度优先往返，并收集全部苹果。
最优性：算法只选必要边，且每条必要边恰好走两次，达到上述下界，所以总时间最小。

边界情况

  • 没有任何苹果：没有必要边，答案为 0。
  • 只有根节点有苹果：无需移动，答案仍为 0。
  • 多个苹果共享祖先路径：共享边只计算一次往返。
  • 树退化成长度接近 10⁵ 的链：递归实现可能栈溢出，迭代后序更稳妥。

COMPLEXITY

时间复杂度O(n)
空间复杂度O(n)

替代方案

也可从苹果节点向根标记路径，最终统计标记边数乘 2；但逐个向上时若不在已标记节点处停止，可能退化为 O(n²)。也可以反复删除没有苹果的叶子，再将剩余边数乘 2。

常见错误

  • 无向图中忘记跳过父节点。
  • 按苹果数量乘 2，忽略共享路径。
  • 把根节点的苹果额外计费。
  • 只算去程，忘记必须返回 0。

面试追问

如果不要求回到根呢？

必要子树边通常走两次，但最终停留路径可少走一次；从往返答案中减去根到最远必要节点的距离。

如果边有不同权重呢？

判断逻辑不变，每条必要边贡献改为其权重的两倍。

怎样避免递归栈风险？

先用栈生成父节点和遍历顺序，再逆序聚合子树状态。

Java · 迭代后序O(n) / O(n)
class Solution {
    public int minTime(int n, int[][] edges, List<Boolean> hasApple) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }

        int[] parent = new int[n];
        Arrays.fill(parent, -2);
        parent[0] = -1;
        int[] order = new int[n];
        int size = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);
        while (!stack.isEmpty()) {
            int node = stack.pop();
            order[size++] = node;
            for (int next : graph.get(node)) {
                if (next == parent[node]) continue;
                parent[next] = node;
                stack.push(next);
            }
        }

        boolean[] needed = new boolean[n];
        int answer = 0;
        for (int i = n - 1; i > 0; i--) {
            int node = order[i];
            needed[node] = hasApple.get(node) || needed[node];
            if (needed[node]) {
                answer += 2;
                needed[parent[node]] = true;
            }
        }
        return answer;
    }
}
JavaScript · 迭代后序O(n) / O(n)
/**
 * @param {number} n
 * @param {number[][]} edges
 * @param {boolean[]} hasApple
 * @return {number}
 */
var minTime = function(n, edges, hasApple) {
    const graph = Array.from({ length: n }, () => []);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
    }

    const parent = new Array(n).fill(-2);
    const order = [];
    const stack = [0];
    parent[0] = -1;
    while (stack.length) {
        const node = stack.pop();
        order.push(node);
        for (const next of graph[node]) {
            if (next === parent[node]) continue;
            parent[next] = node;
            stack.push(next);
        }
    }

    const needed = hasApple.slice();
    let answer = 0;
    for (let i = order.length - 1; i > 0; i--) {
        const node = order[i];
        if (needed[node]) {
            answer += 2;
            needed[parent[node]] = true;
        }
    }
    return answer;
};
Python · 迭代后序O(n) / O(n)
from typing import List

class Solution:
    def minTime(
        self,
        n: int,
        edges: List[List[int]],
        hasApple: List[bool]
    ) -> int:
        graph = [[] for _ in range(n)]
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)

        parent = [-2] * n
        parent[0] = -1
        order = []
        stack = [0]
        while stack:
            node = stack.pop()
            order.append(node)
            for nxt in graph[node]:
                if nxt == parent[node]:
                    continue
                parent[nxt] = node
                stack.append(nxt)

        needed = hasApple[:]
        answer = 0
        for node in reversed(order[1:]):
            if needed[node]:
                answer += 2
                needed[parent[node]] = True
        return answer
C++ · 递归 DFSO(n) / O(n)
class Solution {
public:
    int minTime(int n, vector<vector<int>>& edges,
                vector<bool>& hasApple) {
        vector<vector<int>> graph(n);
        for (const auto& edge : edges) {
            graph[edge[0]].push_back(edge[1]);
            graph[edge[1]].push_back(edge[0]);
        }
        return dfs(0, -1, graph, hasApple);
    }

private:
    int dfs(int node, int parent,
            const vector<vector<int>>& graph,
            const vector<bool>& hasApple) {
        int cost = 0;
        for (int child : graph[node]) {
            if (child == parent) continue;
            int childCost = dfs(child, node, graph, hasApple);
            if (childCost > 0 || hasApple[child]) {
                cost += childCost + 2;
            }
        }
        return cost;
    }
};
