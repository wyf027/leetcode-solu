K 个不同整数的子数组

给定正整数数组 nums 和整数 k，返回恰好包含 k 种不同整数的连续子数组数量。

题意

“不同整数”指种类数；子数组必须连续。例如 [1,2,3,1,2] 含 3 种整数。函数为 subarraysWithKDistinct(nums, k)，返回一个整数。

约束
1 ≤ nums.length ≤ 2 × 10⁴
1 ≤ nums[i], k ≤ nums.length

先想一想

直接枚举约有 O(n²) 个候选。怎样把不容易维持的“恰好”变成滑动窗口擅长的单调条件？

exactly(k) = atMost(k) − atMost(k−1)

示例 1

输入：nums = [1,2,1,2,3], k = 2
输出：7
解释：[1,2]、[2,1]、[1,2]、[2,3]、
      [1,2,1]、[2,1,2]、[1,2,1,2]

示例 2

输入：nums = [1,2,1,3,4], k = 3
输出：3
解释：[1,2,1,3]、[2,1,3]、[1,3,4]

Solution

把“恰好”变成两个“至多”

核心洞察

令 F(t) 为不同整数不超过 t 种的子数组数量。恰好含 k 种的子数组被 F(k) 计入、但不被 F(k−1) 计入，所以答案是两者之差。

完整过程

  1. 右端点前进，将新值加入频次表。
  2. 若种类数超过 limit，移动左端点；某值频次降为 0 时删除它。
  3. 窗口合法后，以 right 结尾的合法子数组有 right−left+1 个。
  4. 分别求 limit=k 和 limit=k−1，再相减。

正确性

引理：收缩后，[left,right] 是以 right 结尾且满足限制的最长后缀窗口。所有起点 i≥left 均合法，所有 i<left 均不合法，故本轮贡献恰为 right−left+1。遍历所有 right 得到 F(limit)。而“至多 k”集合去掉“至多 k−1”集合，剩余恰为含 k 种的集合，因此算法正确。

边界与复杂度

  • k=1 时自然计算 F(0)=0。
  • 全为同一值或 k 超过实际种类数，无需特判。
  • 时间 O(n)，频次表空间 O(n)。

替代方案

可在一次遍历中同步维护两个窗口，直接累加两条左边界之差，复杂度相同但状态更多。枚举子数组为 O(n²)，无法适应 n=2×10⁴。

面试追问

  • 为什么合法窗口一次贡献 right−left+1？
  • 如何迁移到“恰好 k 个奇数”？
  • 一次维护双窗口与调用两次 atMost 的取舍是什么？

常见错误

  • 用一个窗口硬维护“恰好 k”，移动规则不单调。
  • 频次归零后未删除键。
  • 窗口长度少加 1，或没处理 limit=0。

四语言完整代码

class Solution {
    public int subarraysWithKDistinct(int[] nums, int k) {
        return atMost(nums, k) - atMost(nums, k - 1);
    }
    private int atMost(int[] nums, int limit) {
        Map<Integer, Integer> freq = new HashMap<>();
        int left = 0, answer = 0;
        for (int right = 0; right < nums.length; right++) {
            freq.put(nums[right], freq.getOrDefault(nums[right], 0) + 1);
            while (freq.size() > limit) {
                int v = nums[left++];
                freq.put(v, freq.get(v) - 1);
                if (freq.get(v) == 0) freq.remove(v);
            }
            answer += right - left + 1;
        }
        return answer;
    }
}
var subarraysWithKDistinct = function(nums, k) {
  const atMost = (limit) => {
    const freq = new Map();
    let left = 0, answer = 0;
    for (let right = 0; right < nums.length; right++) {
      freq.set(nums[right], (freq.get(nums[right]) || 0) + 1);
      while (freq.size > limit) {
        const v = nums[left++];
        freq.set(v, freq.get(v) - 1);
        if (freq.get(v) === 0) freq.delete(v);
      }
      answer += right - left + 1;
    }
    return answer;
  };
  return atMost(k) - atMost(k - 1);
};
class Solution:
    def subarraysWithKDistinct(self, nums: List[int], k: int) -> int:
        def at_most(limit: int) -> int:
            freq = {}
            left = answer = 0
            for right, value in enumerate(nums):
                freq[value] = freq.get(value, 0) + 1
                while len(freq) > limit:
                    removed = nums[left]
                    left += 1
                    freq[removed] -= 1
                    if freq[removed] == 0:
                        del freq[removed]
                answer += right - left + 1
            return answer
        return at_most(k) - at_most(k - 1)
class Solution {
    int atMost(const vector<int>& nums, int limit) {
        unordered_map<int, int> freq;
        int left = 0, answer = 0;
        for (int right = 0; right < nums.size(); ++right) {
            ++freq[nums[right]];
            while (freq.size() > limit) {
                int v = nums[left++];
                if (--freq[v] == 0) freq.erase(v);
            }
            answer += right - left + 1;
        }
        return answer;
    }
public:
    int subarraysWithKDistinct(vector<int>& nums, int k) {

    }
};
