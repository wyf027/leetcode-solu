制造字母异位词的
最小步骤数 II

Minimum Number of Steps to Make Two Strings Anagram II

两个字符串，只能追加字符。你能让它们拥有完全相同的字母和数量吗？

01 理解规则02 自己思考03 展开题解与实验室

题目与规则

给定字符串 s 和 t。每一步可选择其中一个字符串，在末尾追加一个字符。返回使两个字符串成为字母异位词所需的最少步骤数。

互为字母异位词，意味着每种字母的出现次数相同；原有顺序可以不同，也可以相同。这里的操作是追加，不能删除或替换原有字符。

参数与返回值

minSteps(s: string, t: string) → integer

  • 1 ≤ s.length, t.length ≤ 2 × 10⁵。
  • s 和 t 仅包含小写英文字母。
  • 两个字符串的长度不一定相等。

INSIGHT / 频次差

把每个字母缺少的数量补齐

顺序不影响异位词。对字母 c，令其在两串中的次数分别为 a 和 b。若 a > b，就在 t 中追加 a − b 个 c；若 b > a，就在 s 中追加 b − a 个 c。

answer = Σ |countS[c] − countT[c]|，c ∈ [a, z]
  1. 建立长度为 26 的整数数组 diff，初始值为 0。
  2. 遍历 s，让对应字母的 diff 加 1。
  3. 遍历 t，让对应字母的 diff 减 1。
  4. 将 26 个差值的绝对值相加，返回结果。

不需要真的生成追加后的字符串。正差值表示 t 缺少，负差值表示 s 缺少。两侧所需的操作都必须计入答案，不能把总和除以 2。

字母补齐台

逐字母结算

每个格子是一种出现过的字母。绿条为 s 的当前数量，棕条为 t 的当前数量；每点一次“下一步”，将一个字母补到两边一样多。该步可能代表多次追加操作。

仅接受 1～200000 个小写英文字母。编辑后点击“载入输入”；图中聚合数量，不逐个渲染字符。

为什么一定最少？

下界：每种字母都逃不开差额

对一个字母，最终两侧频次都必须是某个 k。由于只能追加，k ≥ max(a,b)。操作数为 (k − a) + (k − b)，至少为 |a − b|。一次操作只能追加一种字母，所以将各字母下界相加，就得到全局下界。

构造：恰好达到下界

对每种字母只给较少的一侧追加，使两侧都达到 max(a,b)。该字母恰好使用 |a − b| 次，且不会影响其他字母。所有字母处理完后，两串频次完全相同，构造达到全局下界，因此最优。

复杂度

设 n = s.length，m = t.length。时间为 O(n + m + 26)，即 O(n + m)；辅助空间为 O(26) = O(1)。代码不构造新字符串。

边界与常见错误

  • 已互为异位词：所有差值为 0，返回 0，即使字符顺序完全不同。
  • 长度不同：允许同时向两侧追加；不能只用长度差计算答案。
  • 字母集合不相交：原有每个字符都需要在另一侧补一个，答案为 n + m。
  • 重复字母：必须保留完整次数，不能用集合去重。
  • 只对正差求和：漏掉 s 缺少的字符；两侧都需要补齐。
  • 将绝对值之和除以 2：混淆了“替换”和“追加”。例如 s = "a"、t = "b" 必须追加 2 次。
  • 空串不在官方输入范围内。最大答案为 400000，Java/C++ 的 int 足够，JavaScript Number 也能精确表示。

替代方案

两张频次表更直观，但多存一份计数；哈希表适合更大的字符集。排序加双指针也能逐个配对相同字母、统计未配对字符，但耗时 O(n log n + m log m)，且排序空间取决于语言实现。

面试追问

  • 如何输出追加方案？正差 c 在 t 追加 diff[c] 次，负差 c 在 s 追加 −diff[c] 次。
  • 只能向 t 追加呢？必须对所有 c 满足 countS[c] ≥ countT[c]；否则无解。
  • 字符集扩展到 Unicode 呢？先明确按码点还是用户感知字符计数，再选对应遍历方式与哈希表。
  • 数据流输入呢？仍可一边读取一边更新 26 个计数，无需保存原串。

Java

class Solution {
    public int minSteps(String s, String t) {
        int[] diff = new int[26];
        for (int i = 0; i < s.length(); i++) {
            diff[s.charAt(i) - 'a']++;
        }
        for (int i = 0; i < t.length(); i++) {
            diff[t.charAt(i) - 'a']--;
        }
        int answer = 0;
        for (int d : diff) answer += Math.abs(d);
        return answer;
    }
}

Python 3

class Solution:
    def minSteps(self, s: str, t: str) -> int:
        diff = [0] * 26
        for c in s:
            diff[ord(c) - ord('a')] += 1
        for c in t:
            diff[ord(c) - ord('a')] -= 1
        return sum(abs(d) for d in diff)

C++

#include <string>
#include <cstdlib>
using namespace std;

class Solution {
public:
    int minSteps(string s, string t) {
        int diff[26] = {};
        for (char c : s) ++diff[c - 'a'];
        for (char c : t) --diff[c - 'a'];
        int answer = 0;
        for (int d : diff) answer += std::abs(d);
        return answer;
    }
};
