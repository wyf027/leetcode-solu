无人机方阵

无人机可以免费移动到任意位置，但改变灯光颜色有成本。给定 source 与 target 两幅颜色方阵，求至少需要多少架无人机切换颜色。

n,m ≤ 100；颜色编号 ≤ 10⁴。

题意与示例

由于位置可以任意调整，二维坐标不重要；真正需要比较的是两幅图中每种颜色各有多少架无人机。

示例 1

source = [[1,3],[5,4]], target = [[3,1],[6,5]]

输出：1

颜色 1、3、5 可直接复用；唯一多余的颜色 4 改成缺少的颜色 6。

示例 2

source = [[1,2,3],[3,4,5]], target = [[1,3,5],[2,3,4]]

输出：0

两边颜色多重集合完全相同，只移动位置即可。

题解：颜色频次差

核心洞察

相同颜色的无人机可以移动到 target 的任意同色位置，最多复用 min(sourceCount[c], targetCount[c]) 架。因此需切色的数量是所有 source 过剩颜色之和：Σ max(sourceCount[c]-targetCount[c],0)。

完整过程

  1. 遍历 source，每种颜色频次加一。
  2. 遍历 target，每种颜色频次减一。
  3. 累加所有正差；每架过剩无人机恰好改成一种缺少的颜色。

边界与复杂度

两幅图完全相同时答案 0；全无交集时答案 n×m；重复颜色按数量匹配。时间 O(nm)，使用定长数组时空间 O(C)，C=10⁴；哈希表版本空间 O(k)。

替代方案、追问与常见错误

排序后双指针也可做，但需要 O(nm log(nm))。若移动也有距离成本，问题将变成带颜色匹配的最小费用分配。常见错误：逐坐标比较、把正负差绝对值直接求和却忘记除以 2、忽略重复颜色。
