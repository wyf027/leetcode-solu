LCP 58. 积木拼接

六片二维积木能否经旋转、翻面后，恰好覆盖一个实心立方体的全部外壳？把“立方体的每个面”预先坐标化，问题就落在有限状态的搜索与占用检查上。

深度优先搜索三维模拟8 种朝向

题意

给定 6 片厚度均为 1 的方形积木，shapes[i] 是由 '0'/'1' 组成的二维字符串：'1' 表示该位置有积木。每片可以旋转或翻面。判断六片是否能拼成一个边长为 n 的实心立方体外壳，且相交边、顶点位置都必须完全吻合。

先快速剪枝：所有 '1' 的总数必须等于外壳体素数 n³ - (n-2)³。不等时直接返回 false。

核心建模

  1. 1. 用“起点 + 行方向 + 列方向”描述立方体的六个面。
  2. 2. 用 4 种旋转 × 是否行列互换，枚举一片的 8 种朝向。
  3. 3. DFS：第 x 片尝试放到尚未使用的每个面；只要新占用体素与既有体素无重叠，就递归下一片。

题解已折叠

题解：固定面坐标 + 回溯

不用在 DFS 里推导复杂的三维几何。预先列出六个面的原点、行方向和列方向；再将二维 (a,b) 映射为 origin + a·rowDir + b·colDir。对每个候选面与朝向先试放，若任一 '1' 映射到已占用体素则回退。

剪枝

外壳体素数是 n³-(n-2)³。总数不匹配立刻失败。

状态

used[6] 记录面；三维布尔数组记录已被积木占用的位置。

复杂度

最多枚举 6! · 8⁶ 个放置骨架，每次检查 O(n²)；实际由重叠剪枝迅速收缩。

边界、替代方案与追问

  • 翻面不是额外的三维旋转：在二维读取时交换行列即可覆盖。
  • 面之间共享棱和顶点，重叠检查正是“边缘完全吻合”的保证。
  • 替代方案可枚举每片的位掩码并做精确覆盖；坐标模拟更直观，也更适合面试讲解。
  • 常见错误：只检查面积、不检查交叠；或错误地把六个面当成互不共享体素的六张纸。

class Solution {
  int n; String[][] s; boolean[][][] used = new boolean[10][10][10]; boolean[] face = new boolean[6];
  int[][] base={{0,0,0},{0,0,1},{1,0,1},{0,0,1},{0,0,1},{0,1,1}};
  int[][] dir={{1,0,0,0,1,0},{1,0,0,0,1,0},{0,0,-1,0,1,0},{0,0,-1,0,1,0},{0,0,-1,1,0,0},{0,0,-1,1,0,0}};
  int[][] sb={{0,0},{0,1},{1,0},{1,1}}, sd={{1,1},{1,-1},{-1,1},{-1,-1}};
  boolean put(int x,int f,int r,int flip,int mod){ for(int a=0;a<n;a++)for(int b=0;b<n;b++){int i=base[f][0]*(n-1)+dir[f][0]*a+dir[f][3]*b,j=base[f][1]*(n-1)+dir[f][1]*a+dir[f][4]*b,k=base[f][2]*(n-1)+dir[f][2]*a+dir[f][5]*b; int u=sb[r][0]*(n-1)+sd[r][0]*(flip==1?b:a),v=sb[r][1]*(n-1)+sd[r][1]*(flip==1?a:b); if(s[x][u].charAt(v)=='1'){if(mod==0&&used[i][j][k])return false; used[i][j][k]=mod==1;}} return true; }
  boolean dfs(int x){if(x==6)return true;for(int f=0;f<6;f++)if(!face[f])for(int r=0;r<4;r++)for(int q=0;q<2;q++)if(put(x,f,r,q,0)){put(x,f,r,q,1);face[f]=true;if(dfs(x+1))return true;face[f]=false;put(x,f,r,q,-1);}return false;}
  public boolean composeCube(String[][] shapes){n=shapes[0].length;s=shapes;int cnt=0;for(String[] p:shapes)for(String row:p)for(char c:row.toCharArray())cnt+=c-'0';return cnt==n*n*n-(n-2)*(n-2)*(n-2)&&dfs(0);}
}

class Solution:
 def composeCube(self, s: List[List[str]]) -> bool:
  n=len(s[0]); used=[[[False]*n for _ in range(n)] for _ in range(n)]; face=[False]*6
  B=((0,0,0),(0,0,1),(1,0,1),(0,0,1),(0,0,1),(0,1,1)); D=((1,0,0,0,1,0),(1,0,0,0,1,0),(0,0,-1,0,1,0),(0,0,-1,0,1,0),(0,0,-1,1,0,0),(0,0,-1,1,0,0)); SB=((0,0),(0,1),(1,0),(1,1)); SD=((1,1),(1,-1),(-1,1),(-1,-1))
  def put(x,f,r,flip,mod):
   for a in range(n):
    for b in range(n):
     i=B[f][0]*(n-1)+D[f][0]*a+D[f][3]*b; j=B[f][1]*(n-1)+D[f][1]*a+D[f][4]*b; k=B[f][2]*(n-1)+D[f][2]*a+D[f][5]*b; u=SB[r][0]*(n-1)+SD[r][0]*(b if flip else a); v=SB[r][1]*(n-1)+SD[r][1]*(a if flip else b)
     if s[x][u][v]=='1':
      if mod==0 and used[i][j][k]: return False
      used[i][j][k]=mod==1
   return True
  def dfs(x):
   if x==6:return True
   for f in range(6):
    if not face[f]:
     for r in range(4):
      for q in range(2):
       if put(x,f,r,q,0):
        put(x,f,r,q,1);face[f]=True
        if dfs(x+1):return True
        face[f]=False;put(x,f,r,q,-1)
   return False
  return sum(row.count('1') for p in s for row in p)==n**3-(n-2)**3 and dfs(0)
