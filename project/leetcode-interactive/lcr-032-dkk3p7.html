有效的字母异位词

给定两个仅含小写字母的字符串 s 和 t，判断它们是否互为字母异位词：字符种类和每种字符出现次数都必须完全相同。

时间 O(n)空间 O(1)26 个计数槽

核心思路：抵消字符计数

  1. 1.长度不同，必定不是异位词。
  2. 2.扫描 s：对应字母的计数加一。
  3. 3.扫描 t：对应字母的计数减一；若出现负数，说明 t 多出了一个字符。
  4. 4.扫描结束没有负数，即每个字符恰好抵消。
为何是 O(1) 空间？ 字母表固定为 26 个小写英文字母，计数数组的大小不随输入增长。

边界与示例

示例
anagram 与 nagaram → true
反例
rat 与 car → false（c 无法抵消）
约束
字符串仅由小写英文字母组成；空串与空串互为异位词。

计数抵消实验室

输入小写字母，观察每个字符的净计数（s 加、t 减）。

等待输入

点击“运行抵消”开始。

验证清单

  • 先比较长度：ab 与 a 直接返回 false。
  • 重复字符：aacc 与 ccac 返回 false。
  • 相同字符不同顺序：listen 与 silent 返回 true。
  • 计数减到负数即可提前结束，无需继续扫描。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

以下四份代码均采用同一计数抵消策略，可直接提交。

Java

class Solution {
  public boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] count = new int[26];
    for (char c : s.toCharArray()) count[c - 'a']++;
    for (char c : t.toCharArray()) if (--count[c - 'a'] < 0) return false;
    return true;
  }
}

JavaScript

var isAnagram = function (s, t) {
  if (s.length !== t.length) return false;
  const count = Array(26).fill(0);
  for (const c of s) count[c.charCodeAt(0) - 97]++;
  for (const c of t) if (--count[c.charCodeAt(0) - 97] < 0) return false;
  return true;
};

Python

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t): return False
        count = [0] * 26
        for c in s: count[ord(c) - ord('a')] += 1
        for c in t:
            count[ord(c) - ord('a')] -= 1
            if count[ord(c) - ord('a')] < 0: return False
        return True

class Solution {
public:
  bool isAnagram(string s, string t) {
    if (s.size() != t.size()) return false;
    int count[26] = {};
    for (char c : s) ++count[c - 'a'];
    for (char c : t) if (--count[c - 'a'] < 0) return false;
    return true;
  }
};
