319.
灯泡开关

一排熄灭的灯，经历一轮又一轮有规律的切换。你的任务不是输出每盏灯的状态，而是计算最后仍然亮着的灯泡数量。

非付费题 输入规模至 10⁹ 返回整数
初始：全部关闭 逐轮切换 观察最终状态
Problem

题目说明

以下内容依据官方题面准确转述。灯泡从 1 开始编号，切换指“开变关、关变开”。

  1. 初始时有 n 个灯泡，全部处于关闭状态。
  2. 第 1 轮打开所有灯泡；第 2 轮切换每第 2 个灯泡；第 3 轮切换每第 3 个灯泡。
  3. 一般地，第 i 轮切换编号为 i, 2i, 3i, … 且不超过 n 的灯泡。
  4. 执行到第 n 轮后，返回亮着的灯泡数量。

Full Solution

从切换次数到完全平方数

不要模拟十亿轮。把视角从“每一轮操作哪些灯”切换为“某一盏灯一共被操作几次”。

核心洞察

编号为 k 的灯泡，只会在轮数 i 能整除 k 时被切换。因此，它的总切换次数恰好等于 k 的正因数个数。

普通正因数成对出现：若 d 整除 k，则与它配对的是 k / d。只有当两者相等时，配对会“重合”，因数个数才为奇数。

d = k / d ⇔ k = d²

所以最后亮着的，正是编号为完全平方数的灯泡：1, 4, 9, 16, …。

完整过程

  1. 固定观察第 k 盏灯，而不是固定某一轮。
  2. 它在所有 k 的正因数对应的轮次被切换。
  3. 初始为关闭：切换偶数次仍关闭，切换奇数次变为开启。
  4. 只有完全平方数拥有奇数个正因数。
  5. 不超过 n 的完全平方数共有 floor(sqrt(n)) 个。

正确性证明

引理：第 k 盏灯被切换的次数等于 k 的正因数个数。因为第 i 轮恰好切换所有编号为 i 倍数的灯，所以当且仅当 i | k 时，该灯在第 i 轮被切换。

判定：正因数通常以 (d, k/d) 成对出现；仅当 d = k/d，也就是 k 为完全平方数时，会留下一个不重复的因数，令因数总数为奇数。

结论：灯泡初始关闭，奇数次切换后开启。因此最终亮灯编号恰为所有不超过 n 的完全平方数，共 floor(sqrt(n)) 个，算法返回值正确。

边界与复杂度

  • n = 0：不存在灯泡，结果为 0。
  • n = 1：编号 1 是完全平方数，结果为 1。
  • n 不是完全平方数：向下取整，最后一个平方数不会越界。
  • n = 10⁹：平方根约为 31622.776，向下取整为 31622。
时间复杂度 O(1) · 空间复杂度 O(1)

这里把语言运行时的平方根运算视为常数时间；题目整数范围内可直接取整。

四语言完整实现

均遵循官方函数签名，直接返回平方根的整数部分。

Java
class Solution {
    public int bulbSwitch(int n) {
        return (int) Math.sqrt(n);
    }
}

/**

 * @return {number}
 */

    return Math.floor(Math.sqrt(n));

    }

面试追问

  • 为什么不能直接模拟？ 状态数组本身就需要 O(n) 空间，且总切换次数约为 n log n。
  • 浮点平方根安全吗？ 在本题 n <= 10⁹ 的范围内，各语言双精度足以可靠表示结果；若范围扩展到超大整数，可改用整数二分或整数平方根。
  • 若初始为开启呢？ 判定会反转：偶数次切换的灯最终开启，需要重新计数。
  • 若只执行 m 轮呢？ 第 k 盏灯只统计不超过 m 的因数，完全平方数结论不再直接成立。

常见错误

  • 把“第 i 轮切换 i 的倍数”误写为只切换第 i 盏灯。
  • 忘记灯泡初始为关闭，从而把奇偶结论写反。
  • 使用四舍五入而不是向下取整平方根。
  • 真的创建长度为 10⁹ 的数组，导致内存或时间超限。
  • 将答案误认为素数数量；关键是因数个数的奇偶性。
