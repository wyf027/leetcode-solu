Greedy scheduling / 字符调度

K 距离间隔
重排字符串Rearrange String k Distance Apart

把同一种字符想成需要冷却的任务：重新安排所有字符，使任意两个相同字符在结果中的下标差至少为 k。若无法安排，返回空字符串。

HARD 会员题 字符串 贪心 优先队列
01 / PROBLEM

先读题，不剧透路线

返回值不唯一：只要使用原字符串的全部字符，并满足距离条件，就都是合法答案。

题意转述

给定只含小写英文字母的字符串 s 和整数 k。你可以任意重排字符，目标是让每一种字符的相邻两次出现位置至少相隔 k。如果不存在这样的排列，返回 ""。

“距离”指下标之差。例如 abcabc 中两个 a 的位置为 0 和 3，距离为 3。

最大堆 + 冷却队列

让最难安置的高频字符优先落位，同时严格禁止它过早返回候选集合。

核心洞察

剩余次数越多的字符，未来越难塞进足够的间隔，所以每一步优先选择当前可用字符中频次最高者。刚使用的字符要冷却 k 个位置，到达可再次使用的时刻后才能回到最大堆。

readyAt = currentIndex + k

完整过程

  1. 统计每个字符频次，放入按剩余次数降序的最大堆。
  2. 在位置 i 开始前，把冷却队列中 readyAt ≤ i 的字符送回堆。
  3. 若堆为空而结果未满，说明当前没有合法字符，直接返回空串。
  4. 弹出高频字符写入结果；若仍有剩余，将其以 i + k 的解禁时刻入队。

正确性证明

合法性：字符在位置 i 使用后，直到位置 i+k 才会重新进入堆。因此同一字符任意相邻两次出现的下标差至少为 k。

完备性：在每个位置，算法从所有合法可选字符中取剩余频次最高者。若改选频次更低的字符，只会让更高频字符剩下更多副本、未来可用槽位不增，不可能改善可行性；交换这两个选择不会破坏当前合法性。因此存在合法排列时，可将某个合法排列逐步交换成算法的贪心前缀。

失败判定：若尚有字符但堆为空，它们全部仍处于最近 k-1 个位置的冷却期，当前槽位没有任何合法字符；任何排列都无法延续该前缀。结合贪心交换论证，此时原问题不可行。

边界情况

  • k = 0 或 k = 1：原串天然满足，可直接返回。
  • 只有一种字符：当长度大于 1 且 k > 1 时失败。
  • 返回答案不唯一；评测检查的是字符多重集与距离约束。
  • 长度可达 3 × 10⁵，不能枚举排列。

复杂度

令 n = s.length，字符集大小为 Σ。每个字符最多进出堆一次/出现，时间为 O(n log |Σ|)；本题 |Σ| = 26，近似线性。堆、计数与冷却队列共占 O(|Σ| + k)，队列中的不同冷却项不超过字符种类，因此在本题中可视为 O(|Σ|)。

替代方案

也可每轮固定挑选至多 k 个不同的高频字符，形成一个“块”，再将仍有剩余的字符放回堆。它同样正确，但按解禁时刻建队列更贴合调度语义，也更容易逐位置解释。

常见错误

  • 使用后立刻放回堆，导致相同字符连续出现。
  • 只检查相邻字符不同；当 k > 2 时远远不够。
  • 堆暂时为空就结束，却忘记用结果长度判断是否完成。
  • 把距离理解成“中间有 k 个字符”，造成 off-by-one。

Java可提交
import java.util.*;

class Solution {
    public String rearrangeString(String s, int k) {
        if (k <= 1) return s;

        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c - 'a']++;

        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> {
            if (a[0] != b[0]) return Integer.compare(b[0], a[0]);
            return Integer.compare(a[1], b[1]);
        });
        for (int i = 0; i < 26; i++) {
            if (count[i] > 0) heap.offer(new int[]{count[i], i});
        }

        // [remainingCount, charIndex, readyAt]
        Deque<int[]> cooldown = new ArrayDeque<>();
        StringBuilder answer = new StringBuilder();

        for (int index = 0; index < s.length(); index++) {
            while (!cooldown.isEmpty() && cooldown.peekFirst()[2] <= index) {
                int[] ready = cooldown.pollFirst();
                heap.offer(new int[]{ready[0], ready[1]});
            }
            if (heap.isEmpty()) return "";

            int[] current = heap.poll();
            answer.append((char) ('a' + current[1]));
            current[0]--;
            if (current[0] > 0) {
                cooldown.offerLast(new int[]{current[0], current[1], index + k});
            }
        }
        return answer.toString();
    }
}

class MaxHeap {
  constructor(compare) {
    this.data = [];
    this.compare = compare;
  }
  get size() { return this.data.length; }
  push(value) {
    const a = this.data;
    a.push(value);
    let i = a.length - 1;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (this.compare(a[p], a[i]) >= 0) break;
      [a[p], a[i]] = [a[i], a[p]];
      i = p;
    }
  }
  pop() {
    const a = this.data;
    const top = a[0];
    const last = a.pop();
    if (a.length) {
      a[0] = last;
      let i = 0;
      while (true) {
        let best = i;
        const left = i * 2 + 1;
        const right = left + 1;
        if (left < a.length && this.compare(a[left], a[best]) > 0) best = left;
        if (right < a.length && this.compare(a[right], a[best]) > 0) best = right;
        if (best === i) break;
        [a[i], a[best]] = [a[best], a[i]];
        i = best;
      }
    }
    return top;
  }
}

/**
 * @param {string} s
 * @param {number} k
 * @return {string}

var rearrangeString = function(s, k) {
  if (k <= 1) return s;

  const count = new Map();
  for (const ch of s) count.set(ch, (count.get(ch) || 0) + 1);
  const heap = new MaxHeap((a, b) =>
    a.count !== b.count ? a.count - b.count : b.ch.localeCompare(a.ch)
  );
  for (const [ch, amount] of count) heap.push({ ch, count: amount });

  const cooldown = [];
  let head = 0;
  const answer = [];

  for (let index = 0; index < s.length; index++) {
    while (head < cooldown.length && cooldown[head].readyAt <= index) {
      heap.push(cooldown[head++]);
    }
    if (heap.size === 0) return "";

    const current = heap.pop();
    answer.push(current.ch);
    current.count--;
    if (current.count > 0) {
      current.readyAt = index + k;
      cooldown.push(current);
    }
  }
  return answer.join("");
};
Python可提交
from collections import Counter, deque
import heapq


class Solution:
    def rearrangeString(self, s: str, k: int) -> str:
        if k <= 1:
            return s

        # (-remaining_count, character)
        heap = [(-amount, ch) for ch, amount in Counter(s).items()]
        heapq.heapify(heap)
        # (ready_at, negative_count, character)
        cooldown = deque()
        answer = []

        for index in range(len(s)):
            while cooldown and cooldown[0][0] <= index:
                _, negative_count, ch = cooldown.popleft()
                heapq.heappush(heap, (negative_count, ch))

            if not heap:
                return ""

            negative_count, ch = heapq.heappop(heap)
            answer.append(ch)
            negative_count += 1

            if negative_count < 0:
                cooldown.append((index + k, negative_count, ch))

        return "".join(answer)
C++可提交
#include <array>
#include <queue>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

class Solution {
public:
    string rearrangeString(string s, int k) {
        if (k <= 1) return s;

        array<int, 26> count{};
        for (char ch : s) ++count[ch - 'a'];

        // (remainingCount, negativeCharIndex) keeps ties deterministic.
        priority_queue<pair<int, int>> heap;
        for (int i = 0; i < 26; ++i) {
            if (count[i] > 0) heap.push({count[i], -i});
        }

        // (remainingCount, negativeCharIndex, readyAt)
        queue<tuple<int, int, int>> cooldown;
        string answer;
        answer.reserve(s.size());

        for (int index = 0; index < static_cast<int>(s.size()); ++index) {
            while (!cooldown.empty() && get<2>(cooldown.front()) <= index) {
                auto [remaining, negativeIndex, readyAt] = cooldown.front();
                cooldown.pop();
                heap.push({remaining, negativeIndex});
            }
            if (heap.empty()) return "";

            auto [remaining, negativeIndex] = heap.top();
            heap.pop();
            answer.push_back(static_cast<char>('a' - negativeIndex));
            --remaining;
            if (remaining > 0) {
                cooldown.push({remaining, negativeIndex, index + k});
            }
        }
        return answer;
    }
};

面试追问

从算法迁移到工程语义。

如果字符集不是 26 个小写字母？

用哈希表统计 Unicode code point，再让堆保存字符键。复杂度中的 |Σ| 变为实际不同字符数。

能否只用计数数组，不用堆？

字符集固定为 26 时，每一步扫描 26 项寻找最高频合法字符，总复杂度 O(26n)，也能通过；堆更适合大字符集。

如何验证返回串？

比较输入输出的字符频次；再记录每个字符上次出现下标，保证新下标之差不小于 k。

和 Task Scheduler 有何区别？

本题不能插入 idle，占用每一个位置；一旦当前没有合法字符就失败。Task Scheduler 通常允许空闲时间。
