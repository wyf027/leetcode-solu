黑白方格画

选 i 行、j 列，黑格数不是简单相加：行列交叉处被重复计算一次，要减去 i·j。

题意

白色画板有 n × n 个格子。任选若干整行与若干整列涂黑（行数、列数都可以为 0），问最终恰有 k 个黑格时，共有多少种不同的最终画面。

示例 1：n = 2, k = 2，输出 4。

可以只涂任意一行，或只涂任意一列，共四种画面。

限制

1 ≤ n ≤ 6，0 ≤ k ≤ n²。

判重语义

只看最终格子颜色；涂色操作顺序不构成新方案。

行列叠加实验台

在 4×4 棋盘中调整选中的行列数量。

组合计数公式

黑格数量

i·n + j·n − i·j

i 行贡献 i·n，j 列贡献 j·n，交叉的 i·j 格被算了两次。

选择方案

C(n,i)·C(n,j)

在 n 行中选择 i 行，在 n 列中选择 j 列。

全黑特判

k = n² → 1

选全行、选全列等多种操作得到同一张全黑画，只能计一次。

核心洞察与完整过程

枚举选中行数 i 与列数 j。若 i·n + j·n − i·j = k，就加入 C(n,i)C(n,j)。当 k=n² 时，不同的行列选择都会得到同一张全黑画，直接返回 1。

复杂度、替代方案与边界

双重枚举时间 O(n²)，空间 O(n²)（组合数表；也可滚动到 O(n)）。直接枚举行列子集需 O(4ⁿ)；虽然 n≤6 也能通过，但不如组合计数清晰。k=0 由 i=j=0 自然得到 1。

面试追问与常见错误

追问：为何只有全黑需要去重？当 i、j 都小于 n 时，白格恰是“未选行 × 未选列”，能唯一反推出所选行列；全黑时白格为空，无法反推。常见错误：忘减交叉区域、漏掉 0 行/0 列、没有特判全黑，或把操作顺序当作不同方案。 

class Solution {
  public int paintingPlan(int n, int k) {
    if (k == n * n) return 1;
    int[][] c = comb(n); int answer = 0;
    for (int rows = 0; rows <= n; rows++)
      for (int cols = 0; cols <= n; cols++)
        if (rows * n + cols * n - rows * cols == k) answer += c[n][rows] * c[n][cols];
    return answer;
  }
  private int[][] comb(int n) {
    int[][] c = new int[n + 1][n + 1];
    for (int i = 0; i <= n; i++) { c[i][0] = c[i][i] = 1; for (int j = 1; j < i; j++) c[i][j] = c[i-1][j-1] + c[i-1][j]; }
    return c;
  }
}
