快速公交

从 0 号站出发：向前一步耗时 inc，向后一步耗时 dec；公交 i 可把站点 x 直接送到 jump[i]×x，耗时 cost[i]。求抵达 target 的最短时间。

target ≤ 10⁹；允许先超过 target 再向后走；答案对 1,000,000,007 取模。

题意与示例

公交可无限次乘坐。虽然站点看似无限，逆向思考一趟倍率为 j 的最后公交：上车点只需考虑 floor(x/j)（落在目标左侧）和 ceil(x/j)（落在目标右侧）。

示例 1

target = 31, inc = 5, dec = 3, jump = [6], cost = [10]

输出：33

0→1→6→5→30→31，总耗时 5+10+3+10+5。

示例 2

target = 612, inc = 4, dec = 5, jump = [3,6,8,11,5,10,4], cost = [4,7,6,3,7,6,4]

输出：26

乘 3、11、3、6 的公交组合可快速抵达。

题解：从目标站逆推最后一趟公交

核心洞察

设 dfs(x) 为 0 到 x 的最短时间。最后不乘公交时是 x×inc。若最后乘倍率 j 的公交，令 q=floor(x/j), r=x mod j：可从 q 上车，落在 x-r 后向前走 r 步；也可从 q+1 上车，超过 x 后向后走 j-r 步。

状态转移

dfs(x)=min(x·inc, dfs(q)+cost+r·inc, dfs(q+1)+cost+(j-r)·dec)。第二个公交方案只在 r>0 时需要。jump≥2，因此子问题规模快速缩小；用哈希表记忆每个 x。

边界与复杂度

dfs(0)=0、dfs(1)=inc，避免 ceil 分支自环。中间最短时间可能达到 10¹⁵，必须用 64 位；只在最终返回时取模。状态数约 O(m log target)，每个状态枚举 m 辆公交，常写作 O(m² log target)，空间同状态数。

替代方案、追问与常见错误

可用 Dijkstra 搜索关键站点，但实现更重。若禁止超过 target，删除 ceil 分支即可。常见错误：只考虑整除、忽略向后步行、递归中提前取模破坏大小关系、用 int 保存 x×inc、忘记 memo。
