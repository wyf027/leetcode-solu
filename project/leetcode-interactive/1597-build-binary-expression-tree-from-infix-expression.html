01 / 题目

让树表达同一个算式

题意转述

给定一个表示算术表达式的字符串 s。操作数是单个数字，运算符包含 +、-、*、/，表达式中也可能出现括号。

请构造对应的二叉表达式树并返回根节点。叶子节点保存数字；非叶子节点保存运算符；每个运算符节点的左右子树分别代表它的左、右操作数。树必须遵守括号、乘除高于加减，以及同优先级从左到右结合的规则。

返回值不是计算结果。 返回的是一棵 TreeNode；不同但等价的代数变形并不满足要求，结构必须对应原表达式的运算次序。

官方参数形式

TreeNode expTree(string s)
参数
s：合法的中缀表达式字符串
返回
表达式树的根节点 TreeNode

约束

  • 1 ≤ s.length ≤ 100
  • s 由数字、四则运算符和圆括号组成。
  • 每个操作数恰好是一个数字。
  • 输入保证是合法表达式。
示例 1
输入
s = "3*4-2*5"
输出树（前缀记法）
(- (* 3 4) (* 2 5))

根为减号；两侧分别是 3*4 与 2*5。

示例 2
输入
s = "2-3/(5*2)+1"
输出树（前缀记法）
(+ (- 2 (/ 3 (* 5 2))) 1)

括号中的乘法先成树，除法再接入，最后按加减左结合。

示例 3
输入
s = "1+2+3+4+5"
输出树（前缀记法）
(+ (+ (+ (+ 1 2) 3) 4) 5)

同优先级运算符从左向右结合，因此树向左延伸。

03 / 完整题解

两只栈，把优先级变成父子关系

核心洞察

一个运算符何时可以安全地成为父节点？当它左侧的操作数已经完整，并且接下来不会再有优先级更高的运算把右侧内容抢走时。

用一个节点栈保存已经完成的数字或子树，用一个运算符栈保存尚未归约的运算符。读取新运算符时，先归约所有优先级不低于它的栈顶运算符；左括号充当边界，右括号则触发边界内的全部归约。这正是中缀转后缀过程与“由后缀式建树”的合并版本。

一次归约做什么

  1. 弹出运算符 op。
  2. 先弹出的节点是右孩子 right，后弹出的是左孩子 left。
  3. 创建 Node(op, left, right) 并压回节点栈。

左右顺序不能交换，减法与除法尤其会立刻暴露这个错误。

完整过程

  1. 遇到数字：创建叶节点并压入节点栈。
  2. 遇到左括号：直接压入运算符栈，建立新的优先级边界。
  3. 遇到右括号：反复归约直到栈顶是左括号，再丢弃这一对边界。
  4. 遇到运算符：只要栈顶不是左括号，且栈顶优先级大于或等于当前运算符，就先归约栈顶；随后压入当前运算符。“大于或等于”保证同级运算左结合。
  5. 扫描结束：归约剩余运算符。节点栈中唯一的节点就是答案根节点。

正确性说明

不变式：扫描任意前缀后，节点栈中的每棵树都准确表示该前缀中一段已经确定运算次序的子表达式；运算符栈保存尚不能归约的运算符，并按括号分段维持从低到高的待处理优先级。

数字入栈保持不变式。遇到新运算符时，所有优先级不低于它的旧运算符都必须更早执行（同级左结合），归约正好将它们的两个相邻表达式合成正确父子关系。括号限制归约范围。最终没有未来输入会改变次序，所以可全部归约；合法表达式恰好剩下一棵覆盖全部输入的树，故返回根正确。

边界情况

  • 只有一个数字：直接返回叶节点。
  • 多层括号：每个左括号都是独立边界。
  • 连续同级运算：使用 ≥ 归约，保持左结合。
  • 括号改变默认优先级：边界内先完成，再作为整体参与外层。
  • 节点出栈顺序：先右后左，不可颠倒。
O(n)时间；每个字符至多入栈、出栈一次
O(n)额外空间；两只栈与结果树

四语言实现

以下实现都采用“运算符栈 + 节点栈”的同一机制。在线提交环境通常已提供 Node 定义。

class Solution {
    public Node expTree(String s) {
        Deque<Node> nodes = new ArrayDeque<>();
        Deque<Character> ops = new ArrayDeque<>();

        for (char ch : s.toCharArray()) {
            if (Character.isDigit(ch)) {
                nodes.push(new Node(ch));
            } else if (ch == '(') {
                ops.push(ch);
            } else if (ch == ')') {
                while (ops.peek() != '(') reduce(nodes, ops);
                ops.pop();
            } else {
                while (!ops.isEmpty() && ops.peek() != '('
                        && priority(ops.peek()) >= priority(ch)) {
                    reduce(nodes, ops);
                }
                ops.push(ch);
            }
        }
        while (!ops.isEmpty()) reduce(nodes, ops);
        return nodes.pop();
    }

    private int priority(char op) {
        return (op == '+' || op == '-') ? 1 : 2;
    }

    private void reduce(Deque<Node> nodes, Deque<Character> ops) {
        Node right = nodes.pop();
        Node left = nodes.pop();
        Node root = new Node(ops.pop());
        root.left = left;
        root.right = right;
        nodes.push(root);
    }
}

 * function Node(val, left, right) {
 *   this.val = val;
 *   this.left = left ?? null;
 *   this.right = right ?? null;
 * }
 */
var expTree = function (s) {
    const nodes = [];
    const ops = [];
    const priority = (op) => (op === '+' || op === '-' ? 1 : 2);

    const reduce = () => {
        const op = ops.pop();
        const right = nodes.pop();
        const left = nodes.pop();
        nodes.push(new Node(op, left, right));
    };

    for (const ch of s) {
        if (/\d/.test(ch)) {
            nodes.push(new Node(ch));
        } else if (ch === '(') {
            ops.push(ch);
        } else if (ch === ')') {
            while (ops[ops.length - 1] !== '(') reduce();
            ops.pop();
        } else {
            while (
                ops.length &&
                ops[ops.length - 1] !== '(' &&
                priority(ops[ops.length - 1]) >= priority(ch)
            ) {
                reduce();
            }
            ops.push(ch);
        }
    }
    while (ops.length) reduce();
    return nodes.pop();
};

        ops = []

            return 1 if op in '+-' else 2

            op = ops.pop()
            right = nodes.pop()
            left = nodes.pop()
            nodes.append(Node(op, left, right))

            elif ch == '(':
                ops.append(ch)

                    reduce()

            reduce()

class Solution {
public:
    Node* expTree(string s) {
        stack<Node*> nodes;
        stack<char> ops;

        for (char ch : s) {
            if (isdigit(ch)) {
                nodes.push(new Node(ch));
            } else if (ch == '(') {
                ops.push(ch);
            } else if (ch == ')') {
                while (ops.top() != '(') reduce(nodes, ops);
                ops.pop();
            } else {
                while (!ops.empty() && ops.top() != '(' &&
                       priority(ops.top()) >= priority(ch)) {
                    reduce(nodes, ops);
                }
                ops.push(ch);
            }
        }
        while (!ops.empty()) reduce(nodes, ops);
        return nodes.top();
    }

private:
    int priority(char op) {
        return (op == '+' || op == '-') ? 1 : 2;
    }

    void reduce(stack<Node*>& nodes, stack<char>& ops) {
        char op = ops.top(); ops.pop();
        Node* right = nodes.top(); nodes.pop();
        Node* left = nodes.top(); nodes.pop();
        nodes.push(new Node(op, left, right));
    }
};

替代方案

递归下降 / Pratt Parser：可以按照优先级层级编写 parseExpression、parseTerm 与 parseFactor，在解析时直接生成树。代码可读性高，也容易扩展一元运算与多位数；但需要更细致的游标和语法边界处理。

先转后缀、再建树：逻辑最直观，但需要显式保存完整后缀序列；本题可以把两阶段合并，少一次遍历和中间存储。

面试追问

  • 如果操作数变成多位整数或变量名，词法分析应如何调整？
  • 如何支持右结合的幂运算 ^？比较条件要从 ≥ 改成什么？
  • 如何加入一元负号，并区分 -3 与二元减法？
  • 怎样从表达式树重新输出最少括号的中缀表达式？

常见错误

  • 只在栈顶优先级严格大于当前运算符时归约，错误地得到右结合。
  • 归约时把第一个弹出的节点当成左孩子。
  • 右括号处理后忘记弹出左括号。
  • 扫描结束后忘记清空剩余运算符。
  • 把表达式求值结果当成返回值，而不是返回树。

实现边界

本题官方约束是单个数字操作数，因此代码按字符扫描。若输入允许空格、多位整数、小数或标识符，应先做 token 化，不能直接把每个字符都当成独立操作数。
