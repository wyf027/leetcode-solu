字母异位词使用完全相同的字母及次数，只是排列不同。返回的组顺序、组内顺序都不受限制。

任务

GROUP BY SIGNATURE

给定字符串数组 strs，把互为字母异位词的字符串放进同一组，并返回所有分组。

Official example 01

输入
strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出（顺序仅作示意）
[["bat"], ["nat", "tan"], ["ate", "eat", "tea"]]

EXAMPLE 02

输入
strs = [""]
输出
[[""]]

EXAMPLE 03

输入
strs = ["a"]
输出
[["a"]]
1 ≤ strs.length ≤ 10⁴ 0 ≤ strs[i].length ≤ 100 仅含小写英文字母 允许空字符串 ""

The answer

计数指纹 + 哈希分组

MEMORY CARD

每个词统计 26 个字母
计数数组序列化为键
相同键追加到同一列表

eat → a1#e1#t1
tea → a1#e1#t1

Core insight

核心洞察

异位词的定义等价于“26 个小写字母的出现次数完全相同”。因此每个单词都能压缩成一个与顺序无关、与内容唯一对应的计数签名。哈希表把签名映射到字符串列表；扫描一个词只需 O(k)。

Full process

完整解题过程

  1. 1

    建立哈希表

    键是 26 位计数指纹，值是属于该指纹的所有原字符串。

  2. 2

    扫描每个字符串

    遇到字符 c，令 count[c - 'a']++。

  3. 3

    编码并入组

    Java/JS/C++ 用分隔符序列化，避免 [1,11] 与 [11,1] 混淆；Python 可直接用 tuple。

  4. 4

    收集哈希表的值

    所有列表就是答案，顺序任意。

边界情况

  • • 空字符串：26 位全 0，自成或合并到空串组。
  • • 重复字符串：每次都保留并追加，不能去重。
  • • 单字符：只有一个计数位为 1。
  • • 组顺序任意：测试比较时必须规范化。

复杂度

时间
O(NK)
空间
O(NK)

N 是字符串数量，K 是最大字符串长度；答案本身也需要保存所有字符。

替代方案与取舍

排序字符串作为键

代码最短、适用于任意字符集，时间 O(NK log K)。面试若先写出这一版通常完全可接受。

质数乘积

理论上可表示字母集合，但会溢出且受数值精度影响，不推荐作为工程或面试主解。

常见错误

  • • 直接把数组对象作为 JS Map 键，内容相同也不是同一引用。
  • • 序列化计数时不加分隔符，产生键碰撞。
  • • 忘记空字符串会得到全 0 指纹。
  • • 用 Set 去重，错误删除重复输入。

面试高频追问

  • • 字符集扩展到 Unicode？排序键或字符频次 Map。
  • • 为什么加分隔符？保证计数边界可解析，避免碰撞。
  • • 能流式处理吗？可以逐词入表，但最终仍要保存分组。
  • • 如何比较任意顺序答案？组内排序后再对分组排序。
