两个数组装着相同数量的元素，但顺序可能完全不同。你能否只靠任意多次“翻转一段连续区间”，把 arr 变成 target？

Problem

题目要求

给定两个长度相同的整数数组 target 和 arr。一次操作中，可以选择 arr 的任意非空连续子数组，并反转其中元素的顺序；操作次数不限。

若最终能让 arr 与 target 完全相同，返回 true；否则返回 false。

约束

  • 21 ≤ target.length ≤ 1000

输出true

依次翻转 [2,4,1]、[4,2]、[4,3]，可得到 target。

输出false

arr 中没有 9，无法得到 target。

核心洞察

任意相邻的两个元素都可以通过翻转长度为 2 的子数组来交换。相邻交换能够构造任意排列，因此只要 arr 和 target 拥有完全相同的元素及重复次数，就一定能把前者重排成后者。

可达 ⇔ 对任意整数 x，count(target, x) = count(arr, x)

完整过程

  1. 建立一个计数表。
  2. 遍历 target，对每个值的计数加一。
  3. 遍历 arr，对每个值的计数减一。
  4. 若所有计数都回到零，返回 true；只要存在非零计数，返回 false。

由于题目保证元素值在 1 到 1000 之间，可以直接使用长度 1001 的整数数组，避免哈希冲突和额外对象开销。

正确性证明

必要性

翻转只改变元素顺序，不会增加、删除或修改任何元素。因此如果 arr 能变为 target，那么每个值在两个数组中的出现次数必然相同。

充分性

若每个值出现次数相同，arr 就是 target 的一个排列。翻转任意长度为 2 的子数组等价于交换一对相邻元素；通过有限次相邻交换，可以把任意排列调整为目标排列。因此 arr 一定可以变为 target。

结论

算法返回 true 当且仅当两数组的元素多重集合相同，恰好等价于题目要求。

边界情况

  • 单元素：值相同则无需翻转；不同则永远不可达。
  • 已经相等：零次操作也被允许，结果为 true。
  • 大量重复值：不能只检查“是否出现”，必须比较出现次数。
  • 同和值：数组总和相同不代表元素组成相同，例如 [1,4] 与 [2,3]。

复杂度

设数组长度为 n，值域上限为 U（本题 U=1000）。计数需要 O(n)，扫描计数表需要 O(U)，总时间为 O(n+U)；计数数组空间为 O(U)。由于 U 固定，也可视为 O(n) 时间、O(1) 额外空间。

替代方案

  • 排序比较：分别排序后逐项比较，思路直接，时间 O(n log n)，通常会修改输入或需要复制数组。
  • 哈希表计数：适合值域很大或元素不是小整数的版本，期望 O(n) 时间，额外空间 O(k)。
  • 模拟翻转：逐位寻找目标值再翻转可构造具体操作序列，但最坏 O(n²)，判断可行性时没有必要。

class Solution {
    public boolean canBeEqual(int[] target, int[] arr) {
        int[] count = new int[1001];
        for (int value : target) {
            count[value]++;
        }
        for (int value : arr) {
            count[value]--;
        }
        for (int frequency : count) {
            if (frequency != 0) {
                return false;
            }
        }
        return true;
    }
}

class Solution:
    def canBeEqual(self, target: List[int], arr: List[int]) -> bool:
        count = [0] * 1001
        for value in target:
            count[value] += 1
        for value in arr:
            count[value] -= 1
        return all(frequency == 0 for frequency in count)
#include <array>
#include <vector>
using namespace std;

class Solution {
public:
    bool canBeEqual(vector<int>& target, vector<int>& arr) {
        array<int, 1001> count{};
        for (int value : target) {
            ++count[value];
        }
        for (int value : arr) {
            --count[value];
        }
        for (int frequency : count) {
            if (frequency != 0) {
                return false;
            }
        }
        return true;
    }
};

面试追问

  • 若必须输出翻转操作序列？ 从左到右固定位置 i，在后缀找到需要的值 j，翻转 [i,j] 将其送到 i；继续处理下一位。重复元素时任选一个可用位置。
  • 若值域不受限？ 改用哈希表维护频次差。
  • 为什么长度为 2 的翻转足够？ 它就是相邻交换，而相邻换位生成所有排列。
  • 能否提前返回？ 不能仅因中间出现负计数就返回 false；arr 后续仍可能包含对应值。完整核销后再判断。

常见错误

  • 只比较数组总和、最大值或去重后的集合。
  • 忘记重复元素必须逐个计数。
  • 误以为一次只能翻转固定长度，或认为翻转无法表达任意排列。
  • 排序方案直接修改了调用方仍需使用的输入数组。
  • 在核销 arr 的中途看到负数就提前判 false。
