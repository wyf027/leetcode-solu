扁平化嵌套列表迭代器

不用预先摊平全部数据：让 hasNext() 负责寻找下一枚整数，让栈只保存仍有工作要做的列表帧。

Problem

题目要求

给定一个整数嵌套列表 nestedList。其中每个元素要么是整数，要么仍是一个列表，而子列表中还可以继续包含整数或列表。请实现一个迭代器，按从左到右、深度优先的顺序遍历所有整数。

实现 NestedIterator：

  • NestedIterator(List<NestedInteger> nestedList)：使用嵌套列表初始化迭代器。
  • int next()：返回下一个整数。
  • boolean hasNext()：仍有整数可供遍历时返回 true，否则返回 false。
判定方式：评测程序会反复执行 while (iterator.hasNext()) result.add(iterator.next())；最终序列与预期扁平结果一致即正确。

约束

  • 1 <= nestedList.length <= 500
  • 嵌套列表中的整数值位于 [-106, 106]。

接口 NestedInteger 由评测环境提供；无需实现或猜测其内部结构。

Solution

惰性 DFS：让 hasNext 维护不变量

核心洞察

栈中每个帧记录一个列表和“下一个尚未处理元素”的下标。hasNext() 不只是询问：它会整理栈，直到栈顶帧指向一个整数，或确认所有帧都结束。

完整过程

栈顶帧耗尽就弹出；若游标指向子列表，先把父游标右移，再压入子列表帧；若指向整数则停止整理。next() 先调用 hasNext()，取出该整数并右移栈顶游标。

正确性

不变量：每次成功执行 hasNext() 后，栈顶恰好指向按 DFS 顺序尚未返回的第一个整数。下钻保持从左到右顺序；弹栈只移除已完成列表；next() 因而返回正确元素且不重复。

复杂度

设嵌套结构中整数与列表节点总数为 N，最大深度为 D。整个遍历总时间 O(N)，均摊每次操作 O(1)；单次 hasNext() 最坏可跨过多层空列表。额外空间 O(D)。

边界情况

注意空子列表、连续空列表、只有一个整数、极深嵌套、负数与边界值，以及调用方重复调用 hasNext() 而不调用 next() 的情形。

替代方案

构造时 DFS 预先生成一维数组，代码更直观，但初始化需要 O(N) 时间与整数数量级空间，不符合真正的惰性迭代。也可以用“元素栈”逆序压栈，空间上界仍可能更宽。

四语言完整代码

以下实现使用评测平台提供的 NestedInteger 接口。

public class NestedIterator implements Iterator<Integer> {
    private static class Frame {
        List<NestedInteger> list;
        int index;

        Frame(List<NestedInteger> list) {
            this.list = list;
            this.index = 0;
        }
    }

    private final Deque<Frame> stack = new ArrayDeque<>();

    public NestedIterator(List<NestedInteger> nestedList) {
        stack.push(new Frame(nestedList));
    }

    @Override
    public boolean hasNext() {
        while (!stack.isEmpty()) {
            Frame top = stack.peek();
            if (top.index == top.list.size()) {
                stack.pop();
                continue;
            }

            NestedInteger current = top.list.get(top.index);
            if (current.isInteger()) {
                return true;
            }

            top.index++;
            stack.push(new Frame(current.getList()));
        }
        return false;
    }

    @Override
    public Integer next() {
        if (!hasNext()) {
            throw new NoSuchElementException();
        }
        Frame top = stack.peek();
        return top.list.get(top.index++).getInteger();
    }
}
/**
 * @param {NestedInteger[]} nestedList
 */
var NestedIterator = function(nestedList) {
    this.stack = [{ list: nestedList, index: 0 }];
};

/**
 * @return {boolean}
 */
NestedIterator.prototype.hasNext = function() {
    while (this.stack.length > 0) {
        const top = this.stack[this.stack.length - 1];

        if (top.index === top.list.length) {
            this.stack.pop();
            continue;
        }

        const current = top.list[top.index];
        if (current.isInteger()) {
            return true;
        }

        top.index += 1;
        this.stack.push({ list: current.getList(), index: 0 });
    }
    return false;
};

/**
 * @return {number}
 */
NestedIterator.prototype.next = function() {
    if (!this.hasNext()) {
        throw new Error("No more integers");
    }
    const top = this.stack[this.stack.length - 1];
    const value = top.list[top.index].getInteger();
    top.index += 1;
    return value;
};
class NestedIterator:
    def __init__(self, nestedList: [NestedInteger]):
        # 每个帧保存 [列表, 下一待处理下标]
        self.stack = [[nestedList, 0]]

    def hasNext(self) -> bool:
        while self.stack:
            current_list, index = self.stack[-1]

            if index == len(current_list):
                self.stack.pop()
                continue

            current = current_list[index]
            if current.isInteger():
                return True

            self.stack[-1][1] += 1
            self.stack.append([current.getList(), 0])

        return False

    def next(self) -> int:
        if not self.hasNext():
            raise StopIteration

        current_list, index = self.stack[-1]
        value = current_list[index].getInteger()
        self.stack[-1][1] += 1
        return value
class NestedIterator {
private:
    struct Frame {
        const vector<NestedInteger>* list;
        size_t index;
    };

    vector<Frame> stack;

public:
    NestedIterator(vector<NestedInteger> &nestedList) {
        stack.push_back({&nestedList, 0});
    }

    bool hasNext() {
        while (!stack.empty()) {
            Frame &top = stack.back();

            if (top.index == top.list->size()) {
                stack.pop_back();
                continue;
            }

            const NestedInteger &current = (*top.list)[top.index];
            if (current.isInteger()) {
                return true;
            }

            top.index++;
            stack.push_back({&current.getList(), 0});
        }
        return false;
    }

    int next() {
        if (!hasNext()) {
            throw out_of_range("No more integers");
        }

        Frame &top = stack.back();
        return (*top.list)[top.index++].getInteger();
    }
};

面试追问

如果嵌套数据来自流，无法随机访问怎么办？可以把帧中的“列表 + 下标”换成子迭代器。若要求线程安全，需要如何约束 hasNext() 与 next() 的原子性？

常见错误

展开子列表前忘记推进父游标会造成死循环；让重复 hasNext() 消费整数会丢数据；只弹一层空列表会导致错误地返回 true。

接口约定

通常调用方只会在 hasNext() 为真后调用 next()。上面的实现仍主动处理耗尽状态，避免返回无意义值。
