Median of a Row Wise Sorted Matrix

矩阵观察室 · 42 / 100　｜　先理解题目，再打开推演与题解。

01 / PROBLEM

从多行数据中，找出正中间的数

给定整数矩阵 grid，大小为 m × n。每一行内部都按非递减顺序排列，全部元素的数量为奇数。把所有元素视为一个整体，返回它们按大小排列后位于中间位置的整数。相同数值按出现次数分别计入。

题目要求时间复杂度低于 O(m × n)。行与行之间没有大小关系，列也不保证有序。

matrixMedian(grid: integer[][]) → integer

官方示例 1

输入：grid = [[1,1,2],[2,3,3],[1,3,4]]
输出：2

整体排序为 [1,1,1,2,2,3,3,3,4]，共 9 个数，第 5 个是 2。

官方示例 2

输入：grid = [[1,1,3,3,4]]
输出：3

只有一行，共 5 个数，中间的第 3 个数是 3。

约束

  • m == grid.length，每行长度相同且 n == grid[i].length。
  • 1 ≤ m, n ≤ 500，且 m、n 均为奇数。
  • 1 ≤ grid[i][j] ≤ 10⁶。
  • 每行按非递减顺序排列，允许重复值。

04 / EDITORIAL

独立题解

准备好后展开：推导、边界与四语言实现。

核心洞察：寻找最早达到目标名次的值

令 N = m × n，目标名次 k = ⌊N/2⌋ + 1（从 1 开始）。定义 C(x) 为整个矩阵中小于等于 x 的元素数。随着 x 增大，C(x) 不会减小；中位数恰好是使 C(x) ≥ k 成立的最小整数。

每行已有序，所以用 upper bound 找到第一个大于 x 的下标；这个下标就是该行 ≤ x 的数量。再把各行数量相加。外层二分值域，内层二分每行的下标。

完整过程

  1. 扫描行首和行尾，令 lo 为最小行首，hi 为最大行尾。
  2. 在 lo < hi 时取 mid = lo + ⌊(hi − lo)/2⌋。
  3. 每行使用半开区间 [left, right) 查找第一个 > mid 的位置，累加得到 count。
  4. 若 count ≥ k，保留 [lo, mid]，即 hi = mid；否则保留 [mid + 1, hi]。
  5. 当 lo == hi，返回 lo。无需修改或展开矩阵。

示例 1：k = 5，初始 [1,4]。mid = 2 时各行贡献 3、1、1，总计 5，收缩为 [1,2]；mid = 1 时贡献 2、0、1，总计 3，收缩为 [2,2]，返回 2。

正确性

设整体排序后的第 k 个数为 a。若 x < a，最多只有 k−1 个元素 ≤ x；若 x ≥ a，则至少 k 个元素 ≤ x。因此谓词 C(x) ≥ k 的第一个真值就是 a。每行 upper bound 正确计算非递减前缀长度，故累加得到的 C(x) 正确。初始区间包含 a；谓词为真时 a ≤ mid，为假时 a > mid，两种更新都保留 a 且严格缩短整数区间。最终唯一剩余值就是中位数。

边界与复杂度

重复值必须全部计入；count 可以跳过 k，不能要求 count 恰好等于 k。单元素和全相等输入直接结束外层循环；单行可直接取中央元素作为可选优化；单列仍适用各行计数。题目范围内 N、计数及数值都适合 32 位整数。

令 V = 最大值 − 最小值 + 1。含初始化的严格时间上界可写为 O(m + m log(n+1) log(V+1))，通常记为 O(m log n log V)；辅助空间 O(1)（不包含输入和教学演示快照）。值域至多 10⁶，外层至多约 20 轮。题目要求避免逐项扫描；该方法利用行内有序性跳跃计数，但不能声称对所有退化维度都严格小于 mn，例如 n = 1 时仍需访问各行。

替代方案

  • 展开后排序：O(N log N) 时间、O(N) 额外空间，简单但不满足本题效率要求。
  • 把各行视作有序链，用最小堆归并至第 k 个：O(m + k log(m+1)) 时间、O(m) 空间；适合一般第 k 小且 k 很小的场景。
  • 值域很小时可建频次数组：O(N + V) 时间、O(V) 空间；需扫描全矩阵。

面试追问

  • 第 k 小怎么做？把目标名次换成 k，单调谓词不变。
  • 元素总数为偶数？分别求第 N/2 和 N/2+1 小，再按需求取平均，注意返回类型与求和溢出。
  • 允许负数？行端点确定值域的方法仍成立，固定正数边界不再合适。
  • 若值域极大或为实数？整数区间收缩不能原样照搬；考虑有序行归并或选择算法。

常见错误

  • 取“各行中位数的中位数”：测试用例 06 的行中位数为 2、4、6，中间是 4，而整体答案是 5。
  • 用 lower bound 统计 < mid，却仍套用 ≤ mid 的判定，导致重复值下名次错位。
  • count ≥ k 时令 hi = mid − 1：可能删掉唯一正确答案。
  • 假定列也有序，使用阶梯扫描计数；本题没有这种保证。
  • JavaScript 默认 sort 按字符串排序；若用排序作参考，必须提供 (a,b) => a-b。

Java

class Solution {
    public int matrixMedian(int[][] grid) {
        int n = grid[0].length;
        int k = grid.length * n / 2 + 1;
        int lo = Integer.MAX_VALUE, hi = Integer.MIN_VALUE;
        for (int[] row : grid) {
            lo = Math.min(lo, row[0]);
            hi = Math.max(hi, row[n - 1]);
        }
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            int count = 0;
            for (int[] row : grid) {
                int left = 0, right = n;
                while (left < right) {
                    int p = left + (right - left) / 2;
                    if (row[p] <= mid) left = p + 1;
                    else right = p;
                }
                count += left;
            }
            if (count >= k) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
}

Python

from bisect import bisect_right
from typing import List

class Solution:
    def matrixMedian(self, grid: List[List[int]]) -> int:
        k = len(grid) * len(grid[0]) // 2 + 1
        lo = min(row[0] for row in grid)
        hi = max(row[-1] for row in grid)
        while lo < hi:
            mid = lo + (hi - lo) // 2
            count = sum(bisect_right(row, mid) for row in grid)
            if count >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo
