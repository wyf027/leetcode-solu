判断对称二叉树

先观察镜像关系，再亲手描述比较顺序。首屏只给题意，不提前展开解法。

简单

题意

请判断一棵二叉树是否关于根节点轴对称。若左右两侧互为镜像，则返回 true；否则返回 false。

示例 1

输入：root = [6,7,7,8,9,9,8]

输出：true

两侧节点位置和值都呈镜像。

示例 2

输入：root = [1,2,2,null,3,null,3]

输出：false

相同的值不代表位置也镜像。

约束：节点数范围为 0 到 1000；节点值范围为 -1000 到 1000。

分步探索

先选择你的判断，再查看反馈；题解默认保持隐藏。

  1. 1. 如果两个待比较节点都为空，它们是否镜像？

  2. 2. 比较左右子树时，左侧的左孩子应与右侧的哪一个孩子配对？

题解：成对镜像比较

核心洞察

不要分别判断两棵子树“是否相同”；应把它们作为一对镜像节点比较：值相等，并交叉比较外侧与内侧孩子。

过程

  1. 从根的左右孩子开始配对。
  2. 两者都为空时，该对成立。
  3. 仅一个为空或值不同，立即失败。
  4. 递归比较左左对右右、左对右左。

边界

空树是对称的；单节点树也是对称的。结构不一致即使局部值相同，也不是镜像。

复杂度

时间 O(n)：每个节点最多检查一次。递归栈空间 O(h)，h 为树高；极端链状树为 O(n)。

替代方案

可用队列维护成对节点，按同样的交叉顺序迭代比较，避免递归调用栈。

常见错误

将左左与右左比较，或只比较节点值而遗漏空节点和结构。

追问

如何改成迭代实现？若树来自流式输入，怎样分层维护镜像配对？

以下代码使用当前题目常见的 isSymmetric(TreeNode root) 方法签名。 

// Java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        return root == null || mirror(root.left, root.right);
    }
    private boolean mirror(TreeNode a, TreeNode b) {
        if (a == null || b == null) return a == b;
        return a.val == b.val && mirror(a.left, b.right)
            && mirror(a.right, b.left);
    }
}
// JavaScript
var isSymmetric = function(root) {
  const mirror = (a, b) => {
    if (!a || !b) return a === b;
    return a.val === b.val && mirror(a.left, b.right)
      && mirror(a.right, b.left);
  };
  return !root || mirror(root.left, root.right);
};
# Python
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        def mirror(a, b):
            if not a or not b:
                return a is b
            return (a.val == b.val and mirror(a.left, b.right)
                    and mirror(a.right, b.left))
        return not root or mirror(root.left, root.right)
// C++
class Solution {
public:
    bool isSymmetric(TreeNode* root) {
        return !root || mirror(root->left, root->right);
    }
private:
    bool mirror(TreeNode* a, TreeNode* b) {
        if (!a || !b) return a == b;
        return a->val == b->val && mirror(a->left, b->right)
            && mirror(a->right, b->left);
    }
};
