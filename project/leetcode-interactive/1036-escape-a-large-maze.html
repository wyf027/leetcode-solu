逃离大迷宫

Escape a Large Maze · 在百万级坐标中识别有限障碍的围困。

题目

在坐标范围为 [0, 10⁶) 的百万乘百万网格中，给定封锁格列表 blocked、起点 source 与终点 target。每步只能向上、下、左、右移动一格，不得越界或进入封锁格。仅当存在从起点到终点的有效路径时返回 true。

函数签名
isEscapePossible(blocked: integer[][], source: integer[], target: integer[]) → boolean

示例 1

输入：blocked = [[0,1],[1,0]],
      source = [0,0], target = [0,2]
输出：false
解释：向北、向东被封锁；向南、向西越界。

示例 2

输入：blocked = [],
      source = [0,0], target = [999999,999999]
输出：true
解释：没有封锁格，可以到达目标。

约束

  • 0 ≤ blocked.length ≤ 200，且每个 blocked[i] 长度为 2
  • 所有坐标分量都满足 0 ≤ coordinate < 10⁶
  • source.length = target.length = 2 且 source != target
  • 题目保证起点和终点都不在封锁列表中

完整题解

核心洞察

最多只有 n ≤ 200 个障碍，它们能围出的最大有限区域不超过三角数 n(n-1)/2。因此从一点搜索时，只要访问格数严格超过该上界，就能断定该点未被障碍围住，而无需探索整个 10¹² 格网格。

完整过程

  1. 将所有封锁坐标放入哈希集合。
  2. 计算 limit = n(n-1)/2。
  3. 从 source 做一次有界 BFS：找到 target 或访问量超过 limit 即通过；队列提前耗尽则被困。
  4. 交换两端再做一次。两次都通过才返回 true，因为终点也可能被独立围住。

正确性

引理一：搜索到另一端时已有一条合法路径。
引理二：若访问数超过 n(n-1)/2，n 个障碍不足以封闭这么大的有限区域，搜索起点必然处于外部连通区域。
引理三：若越过上界前队列耗尽，所有可达边界均由障碍或网格边缘组成，该端被困。
结论：双向检查分别排除起点与终点被困；二者都位于外部连通区域时必然互相可达。反之任一端被困即不可达。

复杂度

令 B=n(n-1)/2。两次搜索的时间为 O(B)，空间为 O(B)；最大访问规模约两万。

边界情况

  • 无障碍时 limit 为 0，可快速判定。
  • 靠近网格边缘仍须检查坐标范围。
  • 坐标哈希编码必须避免碰撞。

替代方案、面试追问与常见错误

DFS 也可实现，但要注意递归深度；坐标压缩可做却更复杂。面试常追问：三角数上界如何构造？为何必须反向再搜？障碍上限移除后怎么办？常见错误是遍历整张图、只检查 source、把“达到阈值”误作“超过阈值”，或用过小乘数编码坐标造成冲突。

import java.util.*;
class Solution {
    static final int N = 1_000_000;
    public boolean isEscapePossible(int[][] blocked, int[] source, int[] target) {
        Set<Long> walls = new HashSet<>();
        for (int[] p : blocked) walls.add(key(p[0], p[1]));
        int limit = blocked.length * (blocked.length - 1) / 2;
        return search(source, target, walls, limit) && search(target, source, walls, limit);
    }
    boolean search(int[] start, int[] goal, Set<Long> walls, int limit) {
        Queue<int[]> q = new ArrayDeque<>(); Set<Long> seen = new HashSet<>();
        q.offer(start); seen.add(key(start[0], start[1]));
        int[][] d = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!q.isEmpty() && seen.size() <= limit) {
            int[] p=q.poll(); if (p[0]==goal[0] && p[1]==goal[1]) return true;
            for (int[] v:d) {
                int x=p[0]+v[0], y=p[1]+v[1]; long k=key(x,y);
                if (x>=0 && x<N && y>=0 && y<N && !walls.contains(k) && seen.add(k))
                    q.offer(new int[]{x,y});
            }
        }
        return seen.size() > limit;
    }
    long key(int x,int y){ return (long)x*N+y; }
}
var isEscapePossible = function(blocked, source, target) {
  const N=1_000_000, key=(x,y)=>x*N+y;
  const walls=new Set(blocked.map(p=>key(p[0],p[1])));
  const limit=blocked.length*(blocked.length-1)/2;
  const search=(start,goal)=>{
    const q=[start], seen=new Set([key(start[0],start[1])]); let head=0;
    const dirs=[[1,0],[-1,0],[0,1],[0,-1]];
    while(head<q.length && seen.size<=limit){
      const [x,y]=q[head++]; if(x===goal[0]&&y===goal[1]) return true;
      for(const [dx,dy] of dirs){
        const nx=x+dx,ny=y+dy,k=key(nx,ny);
        if(nx>=0&&nx<N&&ny>=0&&ny<N&&!walls.has(k)&&!seen.has(k)){
          seen.add(k); q.push([nx,ny]);
        }
      }
    }
    return seen.size>limit;
  };
  return search(source,target)&&search(target,source);
};

from typing import List
class Solution:
    def isEscapePossible(self, blocked: List[List[int]], source: List[int],
                         target: List[int]) -> bool:
        walls = set(map(tuple, blocked))
        limit = len(blocked) * (len(blocked) - 1) // 2
        def search(start, goal):
            q, seen = deque([tuple(start)]), {tuple(start)}
            while q and len(seen) <= limit:
                x, y = q.popleft()
                if [x, y] == goal: return True
                for dx, dy in ((1,0),(-1,0),(0,1),(0,-1)):
                    p = (x+dx, y+dy)
                    if 0<=p[0]<10**6 and 0<=p[1]<10**6 and p not in walls and p not in seen:
                        seen.add(p); q.append(p)
            return len(seen) > limit
        return search(source, target) and search(target, source)
