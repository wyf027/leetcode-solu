01 / READ THE PROBLEM

题意与输入约定

给定字符串二维数组 equations 与实数数组 values。第 i 个二元组 [Aᵢ, Bᵢ] 对应关系 Aᵢ / Bᵢ = values[i]。判断这些比值关系是否互相冲突：存在矛盾返回 true，否则返回 false。

比较两个数时，绝对差小于 10⁻⁵ 才视为相等。题目不设置刻意卡浮点精度的数据，双精度数足够。

checkContradictions(equations: string[][], values: double[]) → boolean

约束

  • 1 ≤ equations.length ≤ 100，且 values.length = equations.length。
  • 每个 equations[i] 恰有 2 个字符串。
  • 变量名长度为 1 至 5，只含小写英文字母。
  • 0.0 < values[i] ≤ 10.0，每个值最多两位小数。

题名、签名及示例输入来自本轮官方元数据；题面为空，语义与约束参考公开题面资料转述。官方题目需订阅查看。

02 / EXAMPLES

官方示例

示例 1 · 可以同时成立

equations = [["a","b"],["b","c"],["a","c"]]
values = [3,0.5,1.5]
输出：false

例如取 a = 3, b = 1, c = 2，三条关系都成立。

示例 2 · 关系不一致

equations = [["le","et"],["le","code"],["code","et"]]
values = [2,5,0.5]
输出：true

前两条关系要求 code / et = 0.4，与第三条给出的 0.5 不符。

04 / GO DEEPER

先想一想，再展开

怎样记住已知关系，并判断新关系是否冲突？

题解 · 为每个连通组建立共同标尺

使用带权并查集。除父节点外，维护 weight[x] = x / parent[x]。找到根并压缩路径后，它变成 x / root。两个变量处于同一组时，把它们相对于根的比值相除，就能得到变量间的比值。

核心洞察
不同组可以通过缩放整个组来接纳新关系；同一组已有确定比值，新关系必须与之相符。

交互实验 · 比值标尺与合并轨迹

完整过程与公式

  1. 将变量名映射为整数，初始各自为根，权重与集合大小都为 1。
  2. find(x) 先记住旧父节点，再递归找到根；将 x / oldParent 与 oldParent / root 相乘，同步压缩权重与父节点。
  3. 处理 a / b = v：先计算根 ra, rb，此时 wa = a / ra、wb = b / rb。
  4. 若根相同，比较 |wa / wb − v|。大于等于 10⁻⁵ 时返回 true。
  5. 否则按大小把小树接到大树。若 ra → rb，设 weight[ra] = v × wb / wa；若 rb → ra，设 weight[rb] = wa / (v × wb)。
  6. 全部处理完且没有矛盾，返回 false。
a / b = (a / ra) × (ra / rb) ÷ (b / rb) = v
所以 ra / rb = v × wb / wa
反向连接：rb / ra = wa / (v × wb)

正确性说明

不变量：权重沿父节点路径相乘，等于变量与根的比值，且符合此前接纳的关系。初始单点集合成立；路径压缩只是将同一路径上的比值相乘，不改变关系。

不同根：两组此前没有共同约束，合并公式确定一个相对尺度，既满足新方程，也不改变各组内部的比值。

相同根：已知关系把 a / b 确定为 wa / wb。新值与之不符就无法兼容，符合时无需修改集合。逐条归纳，首次不符时返回矛盾；全部兼容时，各组任选一个正数作为根的值，就可构造满足系统的赋值。此证明中的等式按精确算术理解，浮点判断按题目容差执行。

边界与常见错误

  • a / a 必须接近 1，首条自环也要比较。
  • 重复关系、倒数关系和长闭环均需要检查。
  • 不连通的组独立，不要强行固定所有变量为同一尺度。
  • 只压缩 parent、不更新 weight，会破坏比值。
  • 合并方向反转时，权重公式也要反转。
  • 浮点数不用 ==；严格“小于”对应矛盾分支的 ≥。
  • 比较两个比值之差；比较 wa − v × wb 会改变绝对误差尺度。

复杂度与替代方案

设方程数 E，变量数 V ≤ 2E。哈希映射平均常数时间；按大小合并加路径压缩，总时间 O(E α(V))，空间 O(V)。其中 α 为增长极慢的反阿克曼函数，find 的递归最大深度受按大小合并约束，为 O(log V)。

替代方案：建立带倒数边的图，用 DFS/BFS 为每个连通分量分配相对值，再逐条按原方向比较比值。时间、空间均为 O(V + E)。需要具体冲突路径时图更直观；并查集适合逐条增量接收方程。

面试追问

如何返回矛盾环？保存合并采用的原始边，再找冲突两端间的路径。如何删除方程？重新计算，或使用离线时间分治与可回滚并查集。值域极大怎么办？考虑对数权重，但需重新设计与原比值绝对误差一致的判断。

import java.util.*;

class Solution {
    private int[] parent, size;
    private double[] weight;

    private int find(int x) {
        if (parent[x] != x) {
            int old = parent[x];
            parent[x] = find(old);
            weight[x] *= weight[old];
        }
        return parent[x];
    }

    public boolean checkContradictions(List<List<String>> equations,
                                       double[] values) {
        Map<String, Integer> ids = new HashMap<>();
        for (List<String> pair : equations)
            for (String x : pair)
                if (!ids.containsKey(x)) ids.put(x, ids.size());
        int n = ids.size();
        parent = new int[n];
        size = new int[n];
        weight = new double[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            size[i] = 1;
            weight[i] = 1.0;
        }
        for (int i = 0; i < equations.size(); i++) {
            int a = ids.get(equations.get(i).get(0));
            int b = ids.get(equations.get(i).get(1));
            int ra = find(a), rb = find(b);
            double v = values[i];
            if (ra == rb) {
                if (Math.abs(weight[a] / weight[b] - v) >= 1e-5)
                    return true;
            } else if (size[ra] < size[rb]) {
                parent[ra] = rb;
                weight[ra] = v * weight[b] / weight[a];
                size[rb] += size[ra];
            } else {
                parent[rb] = ra;
                weight[rb] = weight[a] / (v * weight[b]);
                size[ra] += size[rb];
            }
        }
        return false;
    }
}

var checkContradictions = function(equations, values) {
    const ids = new Map();
    for (const pair of equations) for (const x of pair)
        if (!ids.has(x)) ids.set(x, ids.size);
    const n = ids.size;
    const parent = Array.from({length: n}, (_, i) => i);
    const weight = Array(n).fill(1), size = Array(n).fill(1);
    function find(x) {
        if (parent[x] !== x) {
            const old = parent[x];
            parent[x] = find(old);
            weight[x] *= weight[old];
        }
        return parent[x];
    }
    for (let i = 0; i < equations.length; i++) {
        const a = ids.get(equations[i][0]), b = ids.get(equations[i][1]);
        const ra = find(a), rb = find(b), v = values[i];

            if (Math.abs(weight[a] / weight[b] - v) >= 1e-5) return true;

            parent[ra] = rb;

            size[rb] += size[ra];
        } else {
            parent[rb] = ra;
            weight[rb] = weight[a] / (v * weight[b]);
            size[ra] += size[rb];
        }
    }
    return false;

from typing import List

class Solution:
    def checkContradictions(self, equations: List[List[str]],
                            values: List[float]) -> bool:
        ids = {}
        for pair in equations:
            for x in pair:
                if x not in ids:
                    ids[x] = len(ids)
        n = len(ids)
        parent = list(range(n))
        weight, size = [1.0] * n, [1] * n

        def find(x):
            if parent[x] != x:
                old = parent[x]
                parent[x] = find(old)
                weight[x] *= weight[old]
            return parent[x]

        for (a, b), v in zip(equations, values):
            a, b = ids[a], ids[b]
            ra, rb = find(a), find(b)
            if ra == rb:
                if abs(weight[a] / weight[b] - v) >= 1e-5:
                    return True
            elif size[ra] < size[rb]:
                parent[ra] = rb
                weight[ra] = v * weight[b] / weight[a]
                size[rb] += size[ra]
            else:
                parent[rb] = ra
                weight[rb] = weight[a] / (v * weight[b])
                size[ra] += size[rb]
        return False

#include <vector>
#include <string>
#include <unordered_map>
#include <numeric>
#include <functional>
#include <cmath>
using namespace std;

class Solution {
public:
    bool checkContradictions(vector<vector<string>>& equations,
                             vector<double>& values) {
        unordered_map<string, int> ids;
        for (const auto& pair : equations)
            for (const string& x : pair)
                if (!ids.count(x)) {
                    int id = static_cast<int>(ids.size());
                    ids.emplace(x, id);
                }
        int n = static_cast<int>(ids.size());
        vector<int> parent(n), size(n, 1);
        vector<double> weight(n, 1.0);
        iota(parent.begin(), parent.end(), 0);
        function<int(int)> find = [&](int x) {
            if (parent[x] != x) {
                int old = parent[x];
                parent[x] = find(old);
                weight[x] *= weight[old];
            }
            return parent[x];
        };
        for (int i = 0; i < static_cast<int>(equations.size()); ++i) {
            int a = ids.at(equations[i][0]), b = ids.at(equations[i][1]);
            int ra = find(a), rb = find(b);
            double v = values[i];
            if (ra == rb) {
                if (abs(weight[a] / weight[b] - v) >= 1e-5) return true;
            } else if (size[ra] < size[rb]) {
                parent[ra] = rb;
                weight[ra] = v * weight[b] / weight[a];
                size[rb] += size[ra];
            } else {
                parent[rb] = ra;
                weight[rb] = weight[a] / (v * weight[b]);
                size[ra] += size[rb];
            }
        }
        return false;
    }
};
