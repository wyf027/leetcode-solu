探险营地 集合去重导航台

把每次记录看作一张营地清单：历史集合保存已经认识的营地；本次记录内部也要去重。比较每次新增数量，数量相同自然保留更早的索引。

题意

字符串 expeditions[i] 用 -> 串联营地。第 0 条记录定义初始已知营地。对后续每条记录，统计此前所有记录均未出现过的不同营地数，返回新增最多且索引最小的记录；全为 0 时返回 -1。

可见字符：空格显示为 ␠（本题营地名不含空格）；字符串保留成对直引号。大小写敏感，所以 Leet 与 leet 是两个营地。

示例输入

expeditions = ["leet->code", "leet->code->Campsite->Leet", "leet->code->leet->courier"]

期望输出

1

原因

第 1 次新增 Campsite、Leet，共 2 个。

核心洞察

不要在一条记录内把同名营地重复计数：先把字符串拆分为临时集合 current，再将其中不在 known 的元素计作新增。比较后，把整条记录的不同营地并入 known，保证后续“此前”语义正确。

完整过程

  1. 把第 0 条记录拆分后加入 known。
  2. 从索引 1 开始，拆分并建立本次 current。
  3. 扫描 current，统计不在 known 的营地数。
  4. 若数量严格大于 best，更新答案；严格大于自动保持最小索引。
  5. 将 current 全部并入 known。

边界

  • 空字符串应拆成空集合，不产生空营地。
  • 同一记录重复出现只计 1 次。
  • 大小写严格区分。
  • 没有新增时答案保持 -1。

复杂度与替代方案

令所有字符串总长度为 L。拆分和集合操作总计 O(L) 时间，历史集合占 O(L) 空间。排序后去重会额外引入 O(k log k)，这里 HashSet 更直接。

面试追问与常见错误

若记录流持续到来，可保留 known 集合在线处理。常见错误是把 "".split("->") 当作含一个空营地、先合并后统计（导致新增永远为 0）、以及使用 >= 覆盖最小索引。

四语言可提交代码

// Java
class Solution {
  public int adventureCamp(String[] expeditions) {
    Set<String> known = camps(expeditions[0]);
    int ans = -1, best = 0;
    for (int i = 1; i < expeditions.length; i++) {
      Set<String> cur = camps(expeditions[i]); int add = 0;
      for (String s : cur) if (!known.contains(s)) add++;
      if (add > best) { best = add; ans = i; }
      known.addAll(cur);
    }
    return ans;
  }
  private Set<String> camps(String s) {
    return s.isEmpty() ? new HashSet<>() : new HashSet<>(Arrays.asList(s.split("->")));
  }
}
// JavaScript
var adventureCamp = function(expeditions) {
  const camps = s => s ? new Set(s.split("->")) : new Set();
  const known = camps(expeditions[0]);
  let ans = -1, best = 0;
  for (let i = 1; i < expeditions.length; i++) {
    const cur = camps(expeditions[i]);
    let add = 0; for (const x of cur) if (!known.has(x)) add++;
    if (add > best) [best, ans] = [add, i];
    for (const x of cur) known.add(x);
  }
  return ans;
};
# Python
class Solution:
    def adventureCamp(self, expeditions: List[str]) -> int:
        def camps(s): return set(s.split("->")) if s else set()
        known, ans, best = camps(expeditions[0]), -1, 0
        for i in range(1, len(expeditions)):
            cur = camps(expeditions[i])
            add = sum(x not in known for x in cur)
            if add > best: best, ans = add, i
            known |= cur
        return ans
// C++
class Solution {
 public:
  int adventureCamp(vector<string>& expeditions) {
    auto camps = [](const string& s) { unordered_set<string> r; size_t start = 0, p;
      while (start < s.size()) { p = s.find("->", start); r.insert(s.substr(start, p == string::npos ? string::npos : p - start));
        if (p == string::npos) break; start = p + 2; } return r; };
    auto known = camps(expeditions[0]); int ans = -1, best = 0;
    for (int i = 1; i < expeditions.size(); ++i) { auto cur = camps(expeditions[i]); int add = 0;
      for (auto &x : cur) if (!known.count(x)) ++add;
      if (add > best) best = add, ans = i;
      known.insert(cur.begin(), cur.end()); }
    return ans;
  }
};
