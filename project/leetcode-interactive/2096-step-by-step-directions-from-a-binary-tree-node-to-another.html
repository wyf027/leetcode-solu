Step-By-Step Directions From a Binary Tree Node to Another

把节点之间的移动，写成一串清楚的路标。

01 / 题目

给定二叉树根节点 root，树中有 n 个节点，节点值是 1 到 n 且互不重复。startValue 是起点的值，destValue 是另一个终点的值。返回从起点走到终点的最短路线，用大写方向字符组成字符串。

L → 左孩子
R → 右孩子
U → 父节点

参数与返回值

getDirections(root: TreeNode, startValue: integer, destValue: integer) → string

示例中的数组是二叉树层序表示，null 表示该位置没有节点。

约束

  • 节点数 2 ≤ n ≤ 10⁵。
  • 1 ≤ Node.val ≤ n，所有节点值互不相同。
  • 1 ≤ startValue, destValue ≤ n，两个节点都在树中。
  • startValue ≠ destValue。

02 / 官方示例

示例 1 · 跨越两侧

root = [5,1,2,3,null,6,4]
startValue = 3
destValue = 6

输出："UURL"

路线：3 → 1 → 5 → 2 → 6。先向上两次，再走向右孩子和左孩子。

示例 2 · 直接到左孩子

root = [2,1]
startValue = 2
destValue = 1

输出："L"

路线：2 → 1，只需向左一步。

题解 / 把两条根路径对齐

核心洞察

树中两点之间只有一条简单路径。根到起点的路径 A 与根到终点的路径 B，共同前缀恰好走到最近公共祖先（LCA）。删去这段前缀：A 剩余的每一步都变成 U，随后原样接上 B 的剩余方向。

答案 = U × (|A| − k) + B[k:]，其中 k 是最长公共前缀长度。

方向拼接台 · 双路径对齐

先还原两条根路径，再比较前缀，最后一边移动一边拼接方向。起点以 S 标记，终点以 T 标记，当前节点为深色实心。

根 → 起点 · A

根 → 终点 · B

完整过程

  1. 显式栈遍历树，记录每个节点的父节点，以及父节点指向它的 L / R 标签。
  2. 起点和终点分别沿父指针回到根。收集边标签并反转，得到根到节点的 A 和 B。
  3. 从左向右比较 A、B，找到第一个不同的位置 k；如果一个路径先结束，k 就是较短路径的长度。
  4. 输出 |A| − k 个 U，然后接上 B[k:]。

示例 1：A = LL，B = RL，k = 0，因此得到 UU + RL = UURL。共同前缀场景：A = LL，B = LR，删去开头的 L 后，结果为 UR。

正确性

路径还原：除根以外，每个节点只有一个父节点。逐步回溯并反转标签，得到且只得到根到该节点的方向序列。

公共前缀：根路径在分岔前经过同一批节点，分岔之后无法再次汇合，否则树会有环。因此最长公共前缀的末端正是 LCA。

最短性：从起点沿父边到 LCA，再沿 B 的后缀到终点，没有重复节点。树上简单路径唯一，任何绕行都需要额外边，故该路线最短。向上段均为 U，向下段保留原 L / R，方向也正确。

边界与复杂度

  • 起点就是 LCA：向上段为空，只输出向下方向。
  • 终点就是 LCA：B 的后缀为空，只输出 U。
  • 其中一个节点是根：对应根路径为空，前缀比较仍成立。
  • 最深可达 10⁵ 节点：四份实现均用显式栈，避免递归调用栈溢出。
  • 相同节点不在题目输入范围；该方法自然返回空串。

遍历 O(n)，还原和比较 O(h)，结果长度 ℓ ≤ n − 1。使用哈希映射时，平均时间 O(n)，额外空间 O(n)（包括父映射、方向映射与栈），答案占 O(ℓ)。哈希最坏情况不保证线性；利用值域可改成数组获得确定性线性访问。

替代方案

  • DFS 回溯维护路径：分别寻找 A、B，省去父映射。可用 O(h) 辅助空间；递归实现需留意深树栈限制，避免逐层复制整串。
  • 显式求 LCA：再找 LCA 到两点的路径，思路直接；单次查询整体仍为 O(n)。
  • 无向图 BFS：补父边后从起点搜索，记录前驱并还原，时间和空间均 O(n)，但树结构下不必做最短距离搜索。

面试追问

大量查询怎么办？预处理深度与倍增祖先，用 O(log n) 求 LCA，再花 O(ℓ) 输出方向；输出本身无法低于 O(ℓ)。节点值重复怎么办？用节点引用或唯一 ID 做索引，且输入必须能明确指定两个节点。

常见错误

  • 把向上的 L 改成 R：向上只能用 U，与原先是左孩子还是右孩子无关。
  • 删除公共后缀：要删除的是从根出发的公共前缀。
  • 回溯后忘记反转：收集标签顺序是节点到根，不能直接拿来比较。
  • 用字符串相加保存每个节点的完整路径：链状树可能产生 O(n²) 复制成本。
  • 把树当成二叉搜索树：节点值只用于定位，大小不决定孩子位置。
  • 认为父映射方案只用 O(h) 空间：映射保存整棵树，所以是 O(n)。

import java.util.*;

// TreeNode 由 LeetCode 提供，含 val、left、right。
class Solution {
    public String getDirections(TreeNode root, int startValue, int destValue) {
        Map<Integer, Integer> parent = new HashMap<>();
        Map<Integer, Character> direction = new HashMap<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        parent.put(root.val, 0);
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            if (node.left != null) {
                parent.put(node.left.val, node.val);
                direction.put(node.left.val, 'L');
                stack.push(node.left);
            }
            if (node.right != null) {
                parent.put(node.right.val, node.val);
                direction.put(node.right.val, 'R');
                stack.push(node.right);
            }
        }
        String a = path(startValue, parent, direction);
        String b = path(destValue, parent, direction);
        int k = 0;
        while (k < a.length() && k < b.length()
                && a.charAt(k) == b.charAt(k)) k++;
        StringBuilder answer = new StringBuilder();
        for (int i = k; i < a.length(); i++) answer.append('U');
        return answer.append(b.substring(k)).toString();
    }

    private String path(int v, Map<Integer, Integer> parent,
                        Map<Integer, Character> direction) {
        StringBuilder result = new StringBuilder();
        while (parent.get(v) != 0) {
            result.append(direction.get(v));
            v = parent.get(v);
        }
        return result.reverse().toString();
    }
}

/**

 * @param {TreeNode} root
 * @param {number} startValue
 * @param {number} destValue
 * @return {string}
 */
var getDirections = function(root, startValue, destValue) {
    const parent = new Map([[root.val, 0]]);
    const direction = new Map();
    const stack = [root];
    while (stack.length) {
        const node = stack.pop();
        if (node.left) {
            parent.set(node.left.val, node.val);
            direction.set(node.left.val, 'L');
            stack.push(node.left);
        }
        if (node.right) {
            parent.set(node.right.val, node.val);
            direction.set(node.right.val, 'R');
            stack.push(node.right);
        }
    }
    function path(v) {
        const letters = [];
        while (parent.get(v) !== 0) {
            letters.push(direction.get(v));
            v = parent.get(v);
        }
        return letters.reverse().join('');
    }
    const a = path(startValue), b = path(destValue);
    let k = 0;
    while (k < a.length && k < b.length && a[k] === b[k]) k++;
    return 'U'.repeat(a.length - k) + b.slice(k);
};

C++

#include <string>
#include <unordered_map>
#include <vector>
#include <algorithm>
using namespace std;

// TreeNode 由 LeetCode 提供，含 val、left、right。
class Solution {
public:
    string getDirections(TreeNode* root, int startValue, int destValue) {
        unordered_map<int, int> parent;
        unordered_map<int, char> direction;
        parent[root->val] = 0;
        vector<TreeNode*> stack{root};
        while (!stack.empty()) {
            TreeNode* node = stack.back();
            stack.pop_back();
            if (node->left) {
                parent[node->left->val] = node->val;
                direction[node->left->val] = 'L';
                stack.push_back(node->left);
            }
            if (node->right) {
                parent[node->right->val] = node->val;
                direction[node->right->val] = 'R';
                stack.push_back(node->right);
            }
        }
        auto path = [&](int v) {
            string result;
            while (parent.at(v) != 0) {
                result.push_back(direction.at(v));
                v = parent.at(v);
            }
            reverse(result.begin(), result.end());
            return result;
        };
        string a = path(startValue), b = path(destValue);
        size_t k = 0;
        while (k < a.size() && k < b.size() && a[k] == b[k]) ++k;
        return string(a.size() - k, 'U') + b.substr(k);
    }
};
