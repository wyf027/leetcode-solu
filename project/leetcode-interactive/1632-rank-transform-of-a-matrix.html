矩阵转换后的排名

让同行或同列的大小关系都成立，并把每个排名压到可能的最小值。难点不在排序，而在于：同值元素必须作为“连通分量”同步落位。

题号#1632
难度HARD
核心DSU
状态免费题

Problem

题意与规则

1

从 1 起步

返回同尺寸矩阵 answer，每格是原元素的整数排名，最小为 1。

2

守住相对大小

两格若同行或同列，原值的小于、等于、大于关系必须在排名中严格对应。

3

整体尽量小

满足全部关系的前提下，每个排名取尽可能小的值；题目保证结果唯一。

函数形式： matrixRankTransform(matrix)，输入 m × n 整数矩阵，返回 m × n 排名矩阵。

Examples

官方示例

示例 1 · 递增矩阵

输入：matrix = [[1,2],[3,4]]
输出：[[1,2],[2,3]]

左上角最小为 1；右下角必须同时高于同行与同列的两个 2，因此为 3。

示例 2 · 全部相等

输入：matrix = [[7,7],[7,7]]
输出：[[1,1],[1,1]]

所有相等元素通过行列连成一体，排名同步取最小值 1。

示例 3 · 重复与负数

输入：matrix = [[20,-21,14],
               [-19,4,19],
               [22,-47,24],
               [-19,4,19]]
输出：[[4,2,3],
       [1,3,4],
       [5,1,6],
       [1,3,4]]

约束

  • m == matrix.length
  • n == matrix[i].length
  • 1 <= m, n <= 500
  • -109 <= matrix[row][col] <= 109

Core insight

升序处理 + 同值并查集

01 / 排序按元素值升序分组，确保依赖它的更小元素已经完成。
02 / 连通对同一数值，把每个格子的“行节点”和“列节点”合并。
03 / 定级一个连通分量的排名是其中所有行/列现有最大排名的最大值 + 1。
04 / 同步当前数值全部算完后，再统一更新行列最大排名，避免同值互相抬高。

为什么是“行节点 + 列节点”？

格子 (r,c) 就是一条连接行 r 与列 c 的边。同值格子只要共享一行或一列，就会经由这些节点进入同一连通分量，因而必须取得相同排名。

为何不能逐格立即更新？

同值元素之间没有严格大小关系。若算完一格立刻提高 rowMax/colMax，后处理的同值格可能被错误地加 1；必须先快照计算，再批量提交。

Procedure

完整过程

  1. 建立 value → cells 映射，并按 value 升序遍历。
  2. 对当前 value 创建临时并查集；每个格子 (r,c) 合并节点 r 与 m+c。
  3. 按并查集根收集格子。每个分量的候选基线为所有涉及行的 rowMax 与列的 colMax 的最大值。
  4. 令整个分量排名为 baseline + 1，写入答案的对应格子。
  5. 当前 value 的所有分量排名都确定后，再用它们更新 rowMax 和 colMax。

Correctness

正确性说明

相等关系正确

同行或同列的同值格子会合并；传递相连的格子也在同一分量。算法给整个分量同一排名，满足相等约束。

严格大小正确

按值升序处理时，当前格子同行/同列的更小值已计入对应最大排名。取其最大值再加 1，必然严格更大。

排名最小

任何合法排名都必须大于相关行列中更小值的最大排名，因此至少是 baseline + 1；算法恰取该下界，不可能更小。

归纳结论：从最小 value 起，假设已处理值均合法且最小；上述三点保证当前 value 也合法且最小。依升序归纳，最终整个答案正确且逐格最小。

Boundaries

边界情况

  • 单行或单列：退化为保留相等关系的有序排名。
  • 全矩阵相等：所有格子可能连成一个分量，答案全为 1。
  • 相同值分成多个互不连通分量：它们可因各自行列历史不同而取得不同排名。
  • 负数与大整数：仅比较与映射，不依赖数值范围。
  • 至多 25 万格：避免构造全图边集，临时 DSU 只服务当前值。

Complexity

复杂度

时间：O(mn log(mn))，主要来自按不同值/格子排序；并查集合并近似线性。

空间：O(mn + m + n)，用于值到格子的映射、答案、行列状态与临时并查集。

若使用有序映射，遍历键的排序成本同阶；路径压缩与按秩合并的摊还代价为反阿克曼函数。

class Solution {
    public int[][] matrixRankTransform(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        TreeMap<Integer, List<int[]>> groups = new TreeMap<>();
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                groups.computeIfAbsent(matrix[r][c], k -> new ArrayList<>())
                      .add(new int[]{r, c});
            }
        }

        int[][] answer = new int[m][n];
        int[] rowMax = new int[m], colMax = new int[n];

        for (List<int[]> cells : groups.values()) {
            DSU dsu = new DSU(m + n);
            for (int[] cell : cells) dsu.union(cell[0], m + cell[1]);

            Map<Integer, Integer> rank = new HashMap<>();
            for (int[] cell : cells) {
                int root = dsu.find(cell[0]);
                int base = Math.max(rowMax[cell[0]], colMax[cell[1]]);
                rank.put(root, Math.max(rank.getOrDefault(root, 0), base + 1));
            }
            for (int[] cell : cells) {
                answer[cell[0]][cell[1]] = rank.get(dsu.find(cell[0]));
            }
            for (int[] cell : cells) {
                int value = answer[cell[0]][cell[1]];
                rowMax[cell[0]] = Math.max(rowMax[cell[0]], value);
                colMax[cell[1]] = Math.max(colMax[cell[1]], value);
            }
        }
        return answer;
    }

    private static class DSU {
        int[] parent, size;
        DSU(int n) {
            parent = new int[n]; size = new int[n];
            for (int i = 0; i < n; i++) { parent[i] = i; size[i] = 1; }
        }
        int find(int x) {
            if (parent[x] != x) parent[x] = find(parent[x]);
            return parent[x];
        }
        void union(int a, int b) {
            a = find(a); b = find(b);
            if (a == b) return;
            if (size[a] < size[b]) { int t = a; a = b; b = t; }
            parent[b] = a; size[a] += size[b];
        }
    }
}

var matrixRankTransform = function(matrix) {
    const m = matrix.length, n = matrix[0].length;
    const byValue = new Map();
    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            const value = matrix[r][c];
            if (!byValue.has(value)) byValue.set(value, []);
            byValue.get(value).push([r, c]);
        }
    }
    const values = [...byValue.keys()].sort((a, b) => a - b);
    const answer = Array.from({ length: m }, () => Array(n).fill(0));
    const rowMax = Array(m).fill(0), colMax = Array(n).fill(0);

    for (const value of values) {
        const cells = byValue.get(value);
        const parent = Array.from({ length: m + n }, (_, i) => i);
        const size = Array(m + n).fill(1);
        const find = x => {
            while (parent[x] !== x) {
                parent[x] = parent[parent[x]];
                x = parent[x];
            }
            return x;
        };
        const union = (a, b) => {
            a = find(a); b = find(b);
            if (a === b) return;
            if (size[a] < size[b]) [a, b] = [b, a];
            parent[b] = a; size[a] += size[b];
        };
        for (const [r, c] of cells) union(r, m + c);

        const componentRank = new Map();
        for (const [r, c] of cells) {
            const root = find(r);
            const rank = Math.max(rowMax[r], colMax[c]) + 1;
            componentRank.set(root, Math.max(componentRank.get(root) || 0, rank));
        }
        for (const [r, c] of cells) answer[r][c] = componentRank.get(find(r));
        for (const [r, c] of cells) {
            rowMax[r] = Math.max(rowMax[r], answer[r][c]);
            colMax[c] = Math.max(colMax[c], answer[r][c]);
        }
    }
    return answer;
};
from collections import defaultdict
from typing import List


class Solution:
    def matrixRankTransform(self, matrix: List[List[int]]) -> List[List[int]]:
        m, n = len(matrix), len(matrix[0])
        by_value = defaultdict(list)
        for r in range(m):
            for c in range(n):
                by_value[matrix[r][c]].append((r, c))

        answer = [[0] * n for _ in range(m)]
        row_max = [0] * m
        col_max = [0] * n

        for value in sorted(by_value):
            cells = by_value[value]
            parent = list(range(m + n))
            size = [1] * (m + n)

            def find(x: int) -> int:
                while parent[x] != x:
                    parent[x] = parent[parent[x]]
                    x = parent[x]
                return x

            def union(a: int, b: int) -> None:
                a, b = find(a), find(b)
                if a == b:
                    return
                if size[a] < size[b]:
                    a, b = b, a
                parent[b] = a
                size[a] += size[b]

            for r, c in cells:
                union(r, m + c)

            component_rank = defaultdict(int)
            for r, c in cells:
                root = find(r)
                candidate = max(row_max[r], col_max[c]) + 1
                component_rank[root] = max(component_rank[root], candidate)

            for r, c in cells:
                answer[r][c] = component_rank[find(r)]
            for r, c in cells:
                row_max[r] = max(row_max[r], answer[r][c])
                col_max[c] = max(col_max[c], answer[r][c])

        return answer
class Solution {
    struct DSU {
        vector<int> parent, size;
        explicit DSU(int n) : parent(n), size(n, 1) {
            iota(parent.begin(), parent.end(), 0);
        }
        int find(int x) {
            return parent[x] == x ? x : parent[x] = find(parent[x]);
        }
        void unite(int a, int b) {
            a = find(a); b = find(b);
            if (a == b) return;
            if (size[a] < size[b]) swap(a, b);
            parent[b] = a; size[a] += size[b];
        }
    };

public:
    vector<vector<int>> matrixRankTransform(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        map<int, vector<pair<int, int>>> byValue;
        for (int r = 0; r < m; ++r)
            for (int c = 0; c < n; ++c)
                byValue[matrix[r][c]].push_back({r, c});

        vector<vector<int>> answer(m, vector<int>(n));
        vector<int> rowMax(m), colMax(n);

        for (auto& [value, cells] : byValue) {
            DSU dsu(m + n);
            for (auto [r, c] : cells) dsu.unite(r, m + c);

            unordered_map<int, int> componentRank;
            for (auto [r, c] : cells) {
                int root = dsu.find(r);
                componentRank[root] = max(componentRank[root],
                                          max(rowMax[r], colMax[c]) + 1);
            }
            for (auto [r, c] : cells)
                answer[r][c] = componentRank[dsu.find(r)];
            for (auto [r, c] : cells) {
                rowMax[r] = max(rowMax[r], answer[r][c]);
                colMax[c] = max(colMax[c], answer[r][c]);
            }
        }
        return answer;
    }
};

Alternatives

替代方案

显式 DAG + 拓扑排序：可把同行/同列相邻的不同值连边，再求最长层级。但等值收缩、去重边及建图都更复杂，空间压力也更大。

每值用哈希父节点：可只为当前值出现的行列建 DSU，常数空间更小；实现略繁琐。固定 m+n 数组更直观，在本题上足够。

Common mistakes

常见错误

  • 相同值逐格处理，导致后面的同值被先前结果抬高。
  • 只合并直接相邻格子，漏掉经多次同行/同列形成的传递连通。
  • 分量排名只看某一格，而不是取整个分量涉及行列的最大基线。
  • 计算当前值时提前修改 rowMax/colMax。
  • 把“相同值”误解为全局同排名；不连通的同值分量可排名不同。

Interview follow-ups

面试追问

为什么同值分量必须在同一批次更新？

因为同值之间只要求排名相等，不允许因处理顺序产生严格递增。批次快照隔离了同一 value 内部的影响。

相同数值的所有格子排名都相同吗？

不一定。只有通过“同行或同列”传递连通的同值格子必须同排名；不同分量面对的历史行列基线可能不同。

如果值域很小，能否优化排序？

可以按值域桶排序，把排序部分降为与值域相关的线性扫描；但本题值域达到 ±10⁹，通用解仍用排序映射。

怎样证明 baseline + 1 是最小而不是仅仅可行？

所有涉及行列内的更小值都要求严格更低，所以当前分量必须高于其中最大排名；该下界正是 baseline + 1，而算法恰好达到它。
