最小面积矩形 II

Minimum Area Rectangle II · 几何 / 数组 / 哈希表 / 数学

从对角线的共同特征出发，探索任意旋转矩形。

题目

给定 X-Y 平面上互不相同的点数组 points，其中 points[i] = [xi, yi]。返回这些点能形成的任意矩形的最小面积；矩形边不必平行于坐标轴。不存在则返回 0。答案误差在 10^-5 内可接受。

官方示例

输入：points = [[1,2],[2,1],[1,0],[0,1]]
输出：2.00000
解释：四点组成旋转正方形，面积为 2。

输入：points = [[0,1],[2,1],[1,1],[1,0],[2,0]]
输出：1.00000
解释：[1,0]、[1,1]、[2,1]、[2,0] 组成面积为 1 的矩形。

输入：points = [[0,3],[1,2],[3,1],[1,3],[2,1]]
输出：0
解释：无法组成矩形。

约束

  • 1 ≤ points.length ≤ 50
  • points[i].length == 2
  • 0 ≤ xi, yi ≤ 4 × 10⁴
  • 所有点互不相同。

核心洞察与过程

矩形两条对角线长度相等且中点相同；反之，拥有这两个性质的两条线段，其四端点必组成矩形。枚举所有点对，用“两倍中点坐标 + 距离平方”作为哈希键分组。同组任取两条对角线，固定一条的端点 A、C 和另一条的端点 B，面积为 |AB| × |CB|，取最小值。

正确性

任意矩形的对角线互相平分且等长，故一定进入同组并被枚举（无遗漏）。同组两线段互相平分，四点构成平行四边形；其对角线又等长，所以它是矩形（无误报）。面积公式取两条相邻边乘积，因此最终最小值正确。

边界、复杂度与替代方案

少于四点、共线或无匹配分组返回 0。点对与空间为 O(n²)，组内组合最坏 O(n⁴)。替代方案是枚举三个点，以点积为 0 判定直角并哈希查找第四点 B+C-A，可达 O(n³) 时间、O(n) 空间。

面试追问与常见错误

  • 坐标和表示两倍中点，避免浮点哈希键。
  • 面积不是对角线乘积，而是相邻边乘积。
  • 不要只找轴对齐矩形，也不能只比较组内相邻记录。
  • 问到降维时可讲三点直角枚举。

Java

class Solution {
 public double minAreaFreeRect(int[][] p) {
  Map<String,List<int[]>> g=new HashMap<>();
  for(int i=0;i<p.length;i++) for(int j=i+1;j<p.length;j++){
   long dx=p[i][0]-p[j][0],dy=p[i][1]-p[j][1];
   String k=(p[i][0]+p[j][0])+","+(p[i][1]+p[j][1])+","+(dx*dx+dy*dy);
   g.computeIfAbsent(k,z->new ArrayList<>()).add(new int[]{i,j});
  }
  double ans=Double.MAX_VALUE;
  for(List<int[]> v:g.values()) for(int i=0;i<v.size();i++) for(int j=i+1;j<v.size();j++){
   int a=v.get(i)[0],c=v.get(i)[1],b=v.get(j)[0];
   ans=Math.min(ans,Math.hypot(p[a][0]-p[b][0],p[a][1]-p[b][1])*Math.hypot(p[c][0]-p[b][0],p[c][1]-p[b][1]));
  }
  return ans==Double.MAX_VALUE?0:ans;
 }
}

from collections import defaultdict
from math import hypot
class Solution:
 def minAreaFreeRect(self, p):
  g=defaultdict(list)
  for i in range(len(p)):
   for j in range(i+1,len(p)):
    dx,dy=p[i][0]-p[j][0],p[i][1]-p[j][1]
    g[(p[i][0]+p[j][0],p[i][1]+p[j][1],dx*dx+dy*dy)].append((i,j))
  ans=float('inf')
  for v in g.values():
   for i in range(len(v)):
    for j in range(i+1,len(v)):
     a,c=v[i]; b=v[j][0]
     d=lambda x,y:hypot(p[x][0]-p[y][0],p[x][1]-p[y][1])
     ans=min(ans,d(a,b)*d(c,b))
  return 0 if ans==float('inf') else ans
