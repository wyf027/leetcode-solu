Fisher–Yates 原地洗牌

核心洞察

把“生成随机排列”拆成一连串公平选择：从数组末端位置 i = n - 1 开始，在尚未锁定的前缀 [0, i] 中等概率挑选下标 j，交换 a[i] 与 a[j]。随后位置 i 永久锁定，继续处理 i - 1。

每次 shuffle() 都从原始数组的副本开始，这也让不同调用相互独立；reset() 则返回原始数组的副本，避免调用者修改内部状态。

完整过程

  1. 构造时复制 nums，保存为不可被外部引用直接修改的初始状态。
  2. 调用 shuffle() 时，再复制初始数组得到工作数组。
  3. 令 i 从 n - 1 递减到 1。
  4. 均匀生成 j ∈ [0, i]，交换工作数组的 i 与 j。
  5. 循环结束后返回工作数组；调用 reset() 时返回初始数组的新副本。

正确性证明

循环不变式：完成位置 i + 1 ... n - 1 的处理后，这些位置已经获得互不重复的随机元素，并且所有可能的有序选择等概率出现；剩余元素恰好位于前缀 [0, i]。

初始化：处理前，锁定后缀为空，不变式显然成立。

保持：当前轮从剩余 i + 1 个元素中等概率选择一个放到位置 i，每个元素被选中的概率都是 1 / (i + 1)。它从剩余集合中移除，前缀继续恰好包含其他未锁定元素，因此不变式保持。

终止：循环结束时只剩位置 0，其元素被唯一确定。任意指定排列出现的概率为 1/n × 1/(n-1) × ... × 1/1 = 1/n!，所以全部排列等概率。reset() 直接复制构造时保存的数组，因此必然恢复初始状态。

复杂度

  • 构造：时间 O(n)，空间 O(n)。
  • shuffle()：时间 O(n)，返回数组与工作副本占 O(n)。
  • reset()：为安全返回副本，时间与返回空间均为 O(n)。

边界情况

  • 长度为 1 时无需交换，唯一排列就是自身。
  • 负数、零和大整数不会影响下标随机化。
  • j = i 是合法选择，表示本轮元素原地保留。
  • 多次打乱必须始终以原始数组为起点。

四语言完整实现

Java 
import java.util.Random;

class Solution {
    private final int[] original;
    private final Random random;

    public Solution(int[] nums) {
        original = nums.clone();
        random = new Random();
    }

    public int[] reset() {
        return original.clone();
    }

    public int[] shuffle() {
        int[] result = original.clone();
        for (int i = result.length - 1; i > 0; i--) {
            int j = random.nextInt(i + 1);
            int temp = result[i];
            result[i] = result[j];
            result[j] = temp;
        }
        return result;
    }
}

Solution.prototype.shuffle = function() {
    const result = this.original.slice();

    for (let i = result.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));

Python 3 
from typing import List
import random


class Solution:
    def __init__(self, nums: List[int]):
        self.original = nums[:]

    def reset(self) -> List[int]:
        return self.original[:]

    def shuffle(self) -> List[int]:
        result = self.original[:]

        for i in range(len(result) - 1, 0, -1):
            j = random.randrange(i + 1)
            result[i], result[j] = result[j], result[i]

        return result

#include <algorithm>
#include <random>
#include <vector>
using namespace std;

class Solution {
private:
    vector<int> original;
    mt19937 generator;

public:
    Solution(vector<int>& nums)
        : original(nums), generator(random_device{}()) {}

    vector<int> reset() {
        return original;
    }

    vector<int> shuffle() {
        vector<int> result = original;

        for (int i = static_cast<int>(result.size()) - 1;
             i > 0; --i) {
            uniform_int_distribution<int> distribution(0, i);
            int j = distribution(generator);
            swap(result[i], result[j]);
        }

        return result;
    }
};

替代方案

  • 前向 Fisher–Yates：从左到右处理位置 i，每轮在 [i, n-1] 中等概率选 j 交换，同样正确。
  • 随机抽取并删除：反复从剩余列表中随机选择元素，逻辑直观，但数组删除会让总时间退化为 O(n²)。
  • 按随机键排序：通常为 O(n log n)，随机键碰撞和排序实现还可能引入偏差，不适合作为严谨答案。
  • 任意交换若干次：无法保证所有排列等概率；交换次数也不能自然给出精确均匀分布。

  • 如何从概率角度证明每个排列的概率恰为 1/n!？
  • 若要求可复现实验，如何注入或固定随机种子，同时保持生产调用的随机性？

  • 如何用卡方检验做分布的统计健康检查？为什么统计通过仍不能替代算法证明？

常见错误

  • 每次都从完整区间 [0, n-1] 选择交换位置，导致排列概率不均。
  • 把随机下标写成 [0, i)，漏掉 j = i 的合法情况。
  • 在上一次打乱结果上继续打乱，而不是从保存的原始数组副本开始。
  • reset() 返回内部数组引用，让调用者能够破坏后续状态。
  • 把某个随机示例输出当作唯一期望值；正确测试应检查排列合法性、恢复行为和统计性质。
