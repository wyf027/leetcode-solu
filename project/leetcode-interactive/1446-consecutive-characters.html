题意与边界

字符串的“能量”是：只包含一种字符的最长非空子字符串的长度。给定字符串 s，返回它的能量。

输入：s = "leetcode"
输出：2
解释：连续片段 "ee" 的长度为 2，且只包含字符 'e'。
示例 2 
输入：s = "abbcccddddeeeeedcba"
输出：5
解释：连续片段 "eeeee" 的长度为 5，且只包含字符 'e'。

约束

  • 1 <= s.length <= 500
  • s 只包含小写英文字母。
  • 函数签名：maxPower(s: string): integer

04 · 完整题解

准备好核对思路了吗？

题解默认收起。建议先用上方演示走完一个例子，并用一句话描述“什么时候累加、什么时候重置”。

一次扫描，记录当前连续长度

核心洞察

最长同字符片段必然由若干相邻且相等的字符构成。扫描到 s[i] 时，只需比较它与 s[i - 1]：相等就延长当前片段，不等就让当前长度回到 1；每一步都用当前长度更新全局最大值。

完整过程

  1. 字符串非空，因此把 current 与 best 都初始化为 1。
  2. 从下标 1 开始扫描。如果当前字符等于前一个字符，执行 current += 1。
  3. 如果两字符不同，旧片段已经结束，新片段只含当前字符，因此令 current = 1。
  4. 每轮执行 best = max(best, current)，扫描结束后返回 best。

正确性说明

循环不变量：处理完下标 i 后，current 等于“以 s[i] 结尾的同字符连续片段长度”，best 等于区间 s[0..i] 中所有同字符连续片段的最大长度。

初始时只有 s[0]，两者都为 1，不变量成立。向后一步时，相同字符只能延长末尾片段；不同字符只能新开长度为 1 的片段，所以 current 始终正确。随后取最大值使 best 仍覆盖已处理区间。循环结束时该区间就是整个字符串，因此 best 正是答案。

边界情况

  • 长度为 1：循环不执行，直接返回 1。
  • 所有字符相同：current 一直增长，答案为字符串长度。
  • 相邻字符均不同：current 每次重置，答案为 1。
  • 最长片段位于开头或末尾：每步更新 best，无需额外收尾。

复杂度

时间复杂度 O(n)；除输入外只使用常数个变量，空间复杂度 O(1)。

替代方案

分组计数：先把相邻相同字符划成组，再取最大组长。表达直观，但若显式保存全部组，空间会增至 O(n)。

双指针：让左指针标记一组起点，右指针向前寻找组尾，用 right - left 更新答案。复杂度同为 O(n) 时间、O(1) 空间，本质与滚动计数相同。

四种语言完整代码

Java

class Solution {
    public int maxPower(String s) {
        int current = 1;
        int best = 1;

        for (int i = 1; i < s.length(); i++) {
            if (s.charAt(i) == s.charAt(i - 1)) {
                current++;
            } else {
                current = 1;
            }
            best = Math.max(best, current);
        }

        return best;
    }
}

面试追问

  • 如果要返回最长片段本身？ 在刷新 best 时同步保存片段终点或起点。
  • 如果并列时取最早出现者？ 只在 current > best 时更新位置。
  • 如果输入是字符流？ 保存前一个字符、当前长度与最大值即可在线处理。
  • 如果忽略大小写？ 比较前先规范化字符，但要说明 Unicode 与区域规则。

常见错误

  • 把“子字符串”误解成不要求连续的“子序列”。
  • 从 0 开始扫描却访问 s[i - 1]，导致越界或错误比较。
  • 字符变化时把 current 重置为 0；当前字符本身已经形成长度为 1 的片段。
  • 只在字符变化时更新答案，忘记处理最长片段位于字符串末尾的情况。
  • 将 best 初始化为 0，虽可能被后续覆盖，却让单字符输入返回错误。
