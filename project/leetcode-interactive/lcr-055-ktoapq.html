LCR 055 · MEDIUM

二叉搜索树迭代器

用 O(h) 的辅助空间，把 BST 的中序遍历变成逐次取数的迭代器：每次 next() 都返回下一个最小值。

题意

实现 BSTIterator。构造函数接收一棵二叉搜索树根节点；next() 返回尚未访问的最小值，hasNext() 判断是否还有元素。

root = [7, 3, 15, null, null, 9, 20]

next() → 3

next() → 7

hasNext() → true

next() → 9

next() → 15

next() → 20

hasNext() → false

约束

节点数在 1 到 105 之间；节点值互不相同，范围为 [0, 106]；调用 next() 前保证有下一个元素。

交互实验室

栈顶始终是当前最小节点。点击“取下一个”后，弹出栈顶并把其右子树的整条左链压栈。

辅助栈（底 → 顶）

    已输出的中序序列

        核心洞察：延迟展开左链

        中序遍历顺序是“左、根、右”。初始化时只压入从根到最左节点的路径，因此栈顶就是最小值。取出一个节点后，若它有右孩子，再压入该右孩子及其最左路径；不需要预先保存全部 n 个值。

        完整过程

        1. 定义 pushLeft(node)：沿左指针连续压栈，直到空节点。
        2. 构造时执行 pushLeft(root)。
        3. next() 弹出栈顶，它就是当前最小值。
        4. 对弹出节点的右孩子执行 pushLeft(node.right)，为下一次取值准备候选。
        5. hasNext() 只需判断栈是否为空。

        复杂度：构造为 O(h)，其中 h 是树高；单次 next() 的均摊时间为 O(1)，每个节点至多入栈、出栈各一次；辅助空间 O(h)。常见误区：先完整中序遍历会用 O(n) 空间，不满足题意中的 O(h) 要求。

        可提交代码

        Java

        class BSTIterator {
    private final Deque<TreeNode> stack = new ArrayDeque<>();
    public BSTIterator(TreeNode root) { pushLeft(root); }
    private void pushLeft(TreeNode node) {
        while (node != null) { stack.push(node); node = node.left; }
    }
    public int next() {
        TreeNode node = stack.pop();
        pushLeft(node.right);
        return node.val;
    }
    public boolean hasNext() { return !stack.isEmpty(); }
}

        Python

        class BSTIterator:
    def __init__(self, root: Optional[TreeNode]):
        self.stack = []
        self._push_left(root)

    def _push_left(self, node):
        while node:
            self.stack.append(node)
            node = node.left

    def next(self) -> int:
        node = self.stack.pop()
        self._push_left(node.right)
        return node.val

    def hasNext(self) -> bool: return bool(self.stack)
