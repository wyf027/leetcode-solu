有些区间彼此相连，像岛链一样无法拆开。你能把所有区间放进两个组，并数清一共有多少种合法分法吗？

函数：countWays(ranges) 返回：integer 非付费题
Problem

题目描述

给定二维整数数组 ranges，其中 ranges[i] = [startᵢ, endᵢ] 表示一个包含两端点的闭区间。

请把全部区间分到两个组中（任一组可以为空），并同时满足：

  • 每个区间恰好属于一个组；
  • 任意两个有交集的区间必须属于同一组。

如果两个区间至少共享一个整数，它们就有交集。返回所有合法分组方案数，并对 10⁹ + 7 取模。两个组有编号，因此交换第 1 组和第 2 组会得到不同方案。

约束

011 ≤ ranges.length ≤ 10⁵
02ranges[i].length == 2
030 ≤ startᵢ ≤ endᵢ ≤ 10⁹
04区间包含左右端点

示例 1

输入：ranges = [[6,10],[5,15]]
输出：2
解释：两个区间有交集，必须同组。
可以都放入第 1 组，或都放入第 2 组。

示例 2

输入：ranges = [[1,3],[10,20],[2,5],[4,8]]
输出：4
解释：[1,3]、[2,5]、[4,8] 经交集相连，
必须整体同组；[10,20] 是另一整体。
两个整体各自选择第 1 组或第 2 组，共 4 种。

核心洞察

有交集的区间必须同组，而且这种关系具有传递性：即使 A 与 C 不直接重叠，只要 A 与 B、B 与 C 重叠，三者也必须在同一组。

把所有区间按左端点排序并合并，可得到 k 个互不相交的连通块。每个连通块独立选择第 1 组或第 2 组，所以答案是 2ᵏ mod (10⁹+7)。

完整过程

  1. 按左端点升序排列区间。
  2. 从左到右维护当前连通块能覆盖到的最远右端点 end。
  3. 若新区间的左端点 start > end，它与此前区间断开，新建一个连通块。
  4. 否则它属于当前块，并用右端点扩展 end。
  5. 扫描得到 k 后，迭代计算 2ᵏ 并取模。

正确性证明

1
扫描得到的每一块内部必须同组。
排序后，只要新区间左端点不超过当前最远右端点，它就与当前覆盖链相交；沿着交集链，整块所有区间必须同组。
2
不同块之间可以独立选择。
新块仅在 start > end 时产生，因此它与前一块没有公共整数，也不存在跨块的强制同组关系。
3
计数无重无漏。
每个块恰有两个组可选，且各块选择独立。选择向量与合法分组一一对应，所以总数恰为 2ᵏ。

复杂度与边界

  • 时间复杂度：O(n log n)，主要来自排序。
  • 额外空间：取决于语言排序实现；扫描本身为 O(1)。
  • 端点相等也算重叠，因此只有 start > end 才开启新块。
  • 单个区间形成一个块，答案为 2；两组都允许为空。
  • 相同区间、被完全包含的区间都不会增加块数。
  • 答案每次乘 2 后立即取模，避免大数溢出。

import java.util.Arrays;

class Solution {
    public int countWays(int[][] ranges) {
        final int MOD = 1_000_000_007;
        Arrays.sort(ranges, (a, b) -> Integer.compare(a[0], b[0]));

        int components = 0;
        int end = -1;
        for (int[] range : ranges) {
            if (range[0] > end) {
                components++;
                end = range[1];
            } else {
                end = Math.max(end, range[1]);
            }
        }

        long answer = 1;
        while (components-- > 0) {
            answer = answer * 2 % MOD;
        }
        return (int) answer;
    }
}

替代方案

并查集：把相交区间连接，再统计连通分量。直接两两判断会达到 O(n²)；仍需排序或扫描优化，因此不如直接合并简洁。

扫描线事件：记录端点事件并统计覆盖层数也能找出连通块，但闭区间在同一坐标的事件顺序容易出错，且事件数量翻倍。

  • 如果要求两个组都非空，需要减去哪些方案？

常见错误

  • 用 start >= end 判断断开：闭区间端点相同仍然重叠，应使用严格大于。
  • 只比较相邻原始区间：必须先排序，并持续维护整个当前块的最远右端点。
  • 把“交集”误解为只看直接重叠，忽略交集链的传递约束。
  • 认为两个组无编号而除以 2：题目中的两个组有区别，不能合并对称方案。
  • 先计算完整的 2ᵏ 再取模，导致定长整数溢出。
