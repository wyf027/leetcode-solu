交换字符串中的元素

Smallest String With Swaps —— 当交换关系形成网络，局部的自由移动会怎样改变整个字符串？

并查集图字符串排序

Problem

题目

把索引对视为允许反复使用的交换通道，求所有可达字符串中字典序最小的一个。

题意转述

给定字符串 s 和索引对数组 pairs。每个 [a, b] 表示可以交换位置 a 与 b 的字符，并且任意索引对都可以使用任意多次。

返回通过这些交换能够得到的、按字典序最小的字符串。索引从 0 开始。

s: string — 只含小写英文字母的原字符串
pairs: List<List<Integer>> — 可反复交换的索引对
return: string — 可达的最小字典序字符串

约束

  • 1 ≤ s.length ≤ 10⁵
  • 0 ≤ pairs.length ≤ 10⁵
  • 0 ≤ pairs[i][0], pairs[i][1] < s.length
  • s 仅包含小写英文字母

Examples

官方示例

示例 1
输入：s = "dcab", pairs = [[0,3],[1,2]]
输出："bacd"
解释：交换 0↔3 得到 "bcad"，
再交换 1↔2 得到 "bacd"。
示例 2
输入：s = "dcab",
      pairs = [[0,3],[1,2],[0,2]]
输出："abcd"
解释：交换 0↔3、0↔2、1↔2，
可依次得到 "bcad"、"acbd"、"abcd"。
示例 3
输入：s = "cba", pairs = [[0,1],[1,2]]
输出："abc"
解释：利用两条交换通道反复交换，
最终可得到 "abc"。

Solution

并查集：先确定自由交换的边界

核心洞察

把每个索引当作图上的点、每个交换对当作边。只要两个索引处在同一个连通分量，就能沿路径通过多次相邻交换，把分量内任意字符移动到任意位置。

为什么要排序？

不同连通分量互不影响。对每个分量，把索引升序、字符升序，再让最小字符占据最小索引，就能让最早出现差异的位置尽可能小。

Process

完整过程

合并索引

初始化并查集；遍历每个 [a,b]，执行 union(a,b)。路径压缩与按秩/按大小合并让操作接近常数时间。

收集分量字符

遍历所有索引 i，以 find(i) 的根为键，将字符 s[i] 加入对应分组。

分量内排序

分别排序每组字符。实现时可以升序排序并维护读取指针，也可降序排序后从数组尾部弹出最小字符。

从左到右重建

再次遍历索引。当前位置属于哪个根，就从该根的字符组中取出尚未使用的最小字符。拼接完成后即为答案。

Correctness

正确性说明

引理 1：分量内任意重排可达

连通分量中任意两点之间存在路径。沿路径交换可把目标字符送到目标位置；重复此操作即可实现任意排列。因此，同一分量内的字符可以自由分配。

引理 2：贪心填入最优

对一个分量的索引从小到大填入字符。若某位置没有使用剩余最小字符，那么把更小字符换到此处会让字符串在首个差异处更小，原方案不可能最优。

分量之间相互独立

没有边跨越两个不同分量，所以字符不能跨分量移动。每个分量的最优安排可以独立完成，不会破坏其他分量。

结论

算法在每个不可跨越的分量内取得字典序最小安排，并覆盖全部索引，因此重建出的字符串是所有可达字符串中的字典序最小者。

Complexity

复杂度与边界

时间复杂度O(n log n + m α(n))n 为字符串长度，m 为索引对数量；排序总成本至多 O(n log n)。
空间复杂度O(n)并查集、分组字符和答案都使用线性空间。

没有 pairs

每个索引自成分量，任何字符都不能移动，答案等于原字符串。

重复边 / 自环

重复合并同一集合不会改变结果；[i,i] 也无需特殊处理。

全部连通

所有字符可任意重排，答案就是将整个字符串升序排序。

class Solution {
    private int[] parent;
    private int[] size;

    public String smallestStringWithSwaps(String s, List<List<Integer>> pairs) {
        int n = s.length();
        parent = new int[n];
        size = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            size[i] = 1;
        }
        for (List<Integer> pair : pairs) {
            union(pair.get(0), pair.get(1));
        }

        Map<Integer, PriorityQueue<Character>> groups = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int root = find(i);
            groups.computeIfAbsent(root, k -> new PriorityQueue<>()).offer(s.charAt(i));
        }

        StringBuilder answer = new StringBuilder(n);
        for (int i = 0; i < n; i++) {
            answer.append(groups.get(find(i)).poll());
        }
        return answer.toString();
    }

    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    private void union(int a, int b) {
        int rootA = find(a), rootB = find(b);
        if (rootA == rootB) return;
        if (size[rootA] < size[rootB]) {
            int temp = rootA; rootA = rootB; rootB = temp;
        }
        parent[rootB] = rootA;
        size[rootA] += size[rootB];
    }
}

var smallestStringWithSwaps = function(s, pairs) {
    const n = s.length;
    const parent = Array.from({ length: n }, (_, i) => i);
    const size = Array(n).fill(1);

    function find(x) {
        if (parent[x] !== x) parent[x] = find(parent[x]);
        return parent[x];
    }
    function union(a, b) {
        let rootA = find(a), rootB = find(b);
        if (rootA === rootB) return;
        if (size[rootA] < size[rootB]) [rootA, rootB] = [rootB, rootA];
        parent[rootB] = rootA;
        size[rootA] += size[rootB];
    }

    for (const [a, b] of pairs) union(a, b);
    const groups = new Map();
    for (let i = 0; i < n; i++) {
        const root = find(i);
        if (!groups.has(root)) groups.set(root, []);
        groups.get(root).push(s[i]);
    }
    for (const chars of groups.values()) chars.sort().reverse();

    const answer = [];
    for (let i = 0; i < n; i++) answer.push(groups.get(find(i)).pop());
    return answer.join('');
};
class Solution:
    def smallestStringWithSwaps(self, s: str, pairs: List[List[int]]) -> str:
        n = len(s)
        parent = list(range(n))
        size = [1] * n

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a: int, b: int) -> None:
            root_a, root_b = find(a), find(b)
            if root_a == root_b:
                return
            if size[root_a] < size[root_b]:
                root_a, root_b = root_b, root_a
            parent[root_b] = root_a
            size[root_a] += size[root_b]

        for a, b in pairs:
            union(a, b)

        groups = collections.defaultdict(list)
        for i, char in enumerate(s):
            groups[find(i)].append(char)
        for chars in groups.values():
            chars.sort(reverse=True)

        answer = []
        for i in range(n):
            answer.append(groups[find(i)].pop())
        return ''.join(answer)
class Solution {
    vector<int> parent, size;

    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }

    void unite(int a, int b) {
        a = find(a);
        b = find(b);
        if (a == b) return;
        if (size[a] < size[b]) swap(a, b);
        parent[b] = a;
        size[a] += size[b];
    }

public:
    string smallestStringWithSwaps(string s, vector<vector<int>>& pairs) {
        int n = s.size();
        parent.resize(n);
        size.assign(n, 1);
        iota(parent.begin(), parent.end(), 0);
        for (const auto& pair : pairs) unite(pair[0], pair[1]);

        unordered_map<int, vector<char>> groups;
        for (int i = 0; i < n; ++i) groups[find(i)].push_back(s[i]);
        for (auto& [root, chars] : groups) {
            sort(chars.rbegin(), chars.rend());
        }

        string answer;
        answer.reserve(n);
        for (int i = 0; i < n; ++i) {
            auto& chars = groups[find(i)];
            answer.push_back(chars.back());
            chars.pop_back();
        }
        return answer;
    }
};

Trade-offs

替代方案与追问

DFS / BFS 建连通分量

可以先建邻接表，再用 DFS 或 BFS 找出各连通分量，随后排序。渐进复杂度同样可接受，但需要显式存储图；并查集更贴合“不断合并集合”的输入形式，代码也更集中。

26 个字符计数代替排序

因为字符只有 a-z，每个分量可维护长度 26 的频次数组，重建时取最小可用字符。时间可接近 O(n + mα(n) + 26k)，但实现略繁琐，k 为分量数。

面试追问：为什么路径能带来任意交换？

可用一条路径把字符逐边移动到目标点；交换具有可逆性，因此能构造分量内的任意置换。

面试追问：能否边 union 边维护答案？

合并会改变整个分量的字符集合与最优分配，在线维护成本更高；静态输入下先合并、后统一重建更直接。

面试追问：若支持新增交换对与查询？

并查集仍适合新增边，但要为每个根维护可合并的有序字符结构，并处理索引到字符的分配，设计会显著复杂。

面试追问：字典序贪心为何从左向右？

字典序由第一个不同位置决定，所以越小的索引优先级越高；先优化后面的字符无法弥补前面更大的字符。

Pitfalls

常见错误

  • 只允许直接给出的索引对交换，忽略“任意多次”使同一连通分量内的索引间接可达。
  • 把所有字符一起排序；字符不能跨越不同连通分量。
  • 分组时直接使用未经 find 的父节点，路径未压缩时会把同一集合误分成多组。
  • 字符升序排序却从数组尾部弹出，导致每次取到最大字符；方向与取值端必须配套。
  • 用 shift() 反复取数组头，JavaScript 中可能退化为平方时间；应逆序后 pop() 或使用指针。
