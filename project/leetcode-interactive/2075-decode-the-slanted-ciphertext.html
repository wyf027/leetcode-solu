解码斜向换位密码

Decode the Slanted Ciphertext

字符并没有消失，只是换了位置。给你密文和固定行数，找回唯一的原文。

先理解编码规则，再手动探索。完整推导与四语言代码位于页面底部，默认收起。

01问题与规则

将字符串 originalText 从矩阵顶行的第一列开始，沿左上到右下方向依次填入；一条斜线到达底部或右边界后，从顶行的下一列继续。矩阵行数固定为 rows，列数选到原文填入后最右列有原文字符。未填的位置全部补为空格，最后逐行从左到右连接，得到 encodedText。

输入 encodedText: string 和 rows: integer，返回 originalText: string。函数为 decodeCiphertext(encodedText, rows)。

原文末尾没有空格，但开头和中间可以有空格。题目保证密文有效，而且答案唯一。

约束

  • 0 ≤ encodedText.length ≤ 10⁶。
  • encodedText 只包含小写英文字母及普通空格 ' '。
  • 1 ≤ rows ≤ 1000。
  • 输入是某个不含尾随空格原文的有效编码，且只存在一个可能的原文。

05独立题解

准备好后，再打开推导与完整代码。

核心洞察：恢复读取顺序，不必真的建矩阵

设密文长度为 n，列数 cols = n / rows。密文是矩阵逐行展开的结果，所以坐标 (r, c) 的字符直接位于 encodedText[r * cols + c]。原文的填入顺序就是解码的读取顺序。

完整过程

  1. 根据长度和行数计算列数。空串时列数为 0，直接得到空结果。
  2. 依次选择顶行起点 start = 0, 1, …, cols - 1。
  3. 从 (0, start) 出发，每次令行列都加 1；只要 r < rows 且 start + r < cols，就收集 encodedText[r * cols + start + r]。
  4. 全部斜线读完，仅移除结果末尾的普通空格，保留前导及中间空格。

以示例 1 为例，cols = 12 / 3 = 4：起点 0 读到 cip，起点 1 读到 her，起点 2 和 3 只读到填充空格。合并得到 "cipher "，删除尾部填充即为 "cipher"。每条斜线在一维下标上步长为 cols + 1，但仍必须检查二维边界。

正确性

位置对应：按行展开时，前 r 行占 r * cols 个字符，故下标公式得到原矩阵的同一字符。

顺序对应：外层起点从左到右，内层行列同步递增，恰好重放编码时的填入顺序。每个被读取格子有唯一的 start = c - r，因此不会重复读取。原文所在格子全部在这些斜线上，所以不会遗漏原文。

去填充：原文写完后，该顺序中剩余格子均为空格。原文末尾没有空格，故删去读取结果的最长空格后缀恰好去掉填充，不会删掉原文。三点合起来证明返回值就是原文。

边界与复杂度

  • 空串：列数为 0，无循环，返回空串。
  • 单行：各斜线只有一格，顺序与密文一致。
  • 行数大于列数：斜线先碰到右边界，不能只检查行号。
  • 前导空格及单词间空格必须保留；不能使用去除两端空格的 trim() / strip()。
  • 令 n = encodedText.length，每格至多访问一次，时间 O(n)（空串为常数）；缓冲区与返回值占 O(n) 空间，坐标变量只需 O(1)。本实现没有额外矩阵。

替代方案

显式建立 rows × cols 字符矩阵更直观，时间仍为 O(n)，但多用一份 O(n) 存储。另一种写法是在收集字符时维护最后一个非空格的位置，最终截断到那里，可避免反向扫描；总体复杂度不变。不要直接按一维步长跳到字符串末尾，越过矩阵右边界会跳到错误格子。

常见错误

  • 把列数写成 rows 或把下标写成 c * rows + r，混淆了按行展开。
  • 遇到空格立即停止，导致丢失原文合法的中间空格。
  • 从左侧每一行也启动斜线，读入原编码未使用的左下三角填充。
  • 逐字符拼接不可变字符串，可能退化成平方时间；使用列表、字符数组或可变构建器。

面试追问

为什么可以只读上方斜线区域？编码只从顶行启动，所有原文格子均满足 c ≥ r。

如果原文允许尾部空格呢？空格无法与补位区分，需要额外保存原文长度或采用无歧义填充协议。

可以直接流式输出吗？需要随机访问密文中的位置；要去尾空格，可暂存连续空格计数，遇到下一个非空格再输出这些空格。末尾尚未输出的空格丢弃。

Java

class Solution {
    public String decodeCiphertext(String encodedText, int rows) {
        int cols = encodedText.length() / rows;
        StringBuilder result = new StringBuilder();
        for (int start = 0; start < cols; start++) {
            for (int r = 0; r < rows && start + r < cols; r++) {
                result.append(encodedText.charAt(r * cols + start + r));
            }
        }
        while (result.length() > 0 &&
               result.charAt(result.length() - 1) == ' ') {
            result.setLength(result.length() - 1);
        }
        return result.toString();
    }
}

/**
 * @param {string} encodedText
 * @param {number} rows
 * @return {string}
 */
var decodeCiphertext = function(encodedText, rows) {
    const cols = encodedText.length / rows;
    const result = [];
    for (let start = 0; start < cols; start++) {
        for (let r = 0; r < rows && start + r < cols; r++) {
            result.push(encodedText[r * cols + start + r]);
        }
    }
    while (result.length && result[result.length - 1] === ' ') {
        result.pop();
    }
    return result.join('');
};

Python

class Solution:
    def decodeCiphertext(self, encodedText: str, rows: int) -> str:
        cols = len(encodedText) // rows
        result = []
        for start in range(cols):
            for r in range(min(rows, cols - start)):
                result.append(encodedText[r * cols + start + r])
        return ''.join(result).rstrip(' ')

C++

#include <string>
using namespace std;

class Solution {
public:
    string decodeCiphertext(string encodedText, int rows) {
        int cols = static_cast<int>(encodedText.size()) / rows;
        string result;
        result.reserve(encodedText.size());
        for (int start = 0; start < cols; ++start) {
            for (int r = 0; r < rows && start + r < cols; ++r) {
                result.push_back(encodedText[r * cols + start + r]);
            }
        }
        while (!result.empty() && result.back() == ' ') {
            result.pop_back();
        }
        return result;
    }
};
