#1534EASY数组枚举

Count Good Triplets

统计好三元组

从数组中选择三个严格递增的下标，逐一检查三组数值之差。先在交互实验室里观察枚举过程，再决定是否展开完整题解。

Problem

题目描述

给定整数数组 arr 和三个整数 a、b、c，统计满足条件的三元组 (arr[i], arr[j], arr[k]) 数量。

一个三元组只有在下标与三个距离条件全部成立时才算“好”：

  • 0 ≤ i < j < k < arr.length
  • |arr[i] − arr[j]| ≤ a
  • |arr[j] − arr[k]| ≤ b
  • |arr[i] − arr[k]| ≤ c

其中 |x| 表示 x 的绝对值。返回好三元组的总数。

Contract

函数与约束

countGoodTriplets(arr, a, b, c) → integer

  • 3 ≤ arr.length ≤ 100
  • 0 ≤ arr[i] ≤ 1000
  • 0 ≤ a, b, c ≤ 1000
阅读提示：数组长度最多 100，直接枚举所有下标三元组已经足够。

官方示例

Example 01

四个好三元组

输入：arr = [3,0,1,1,9,7], a = 7, b = 2, c = 3
输出：4
解释：好三元组为 (3,0,1)、(3,0,1)、
      (3,1,1)、(0,1,1)。
      两个 (3,0,1) 来自不同下标。

Example 02

没有满足者

输入：arr = [1,1,2,2,3], a = 0, b = 0, c = 1
输出：0
解释：不存在同时满足全部三个距离条件的三元组。

Core insight

核心洞察

下标顺序 i < j < k 已经消除了重复组合。三层循环各选择一个下标，只有三个绝对值条件全部通过时，答案加一。

完整过程

  1. 固定 i
    从 0 枚举到 n−3，为后面两个下标留出位置。
  2. 选择 j
    从 i+1 枚举到 n−2，因此天然保证 i < j。
  3. 选择 k
    从 j+1 枚举到 n−1，因此每组三下标只出现一次。
  4. 同时验证
    计算三次绝对差，全部不超过各自阈值才令计数器加一。

正确性证明

完备性：任意合法下标三元组都满足某个 i、某个 j ∈ [i+1,n−2]、某个 k ∈ [j+1,n−1]，因此必被循环访问。

唯一性：每层循环的下界由前一层决定，同一组有序下标不会重复访问。

判定正确：程序使用题目给出的三个不等式作合取判断，所以只计入且计入全部好三元组。综上返回值正确。

边界与复杂度

  • 最短数组 n=3 时，恰好检查一次。
  • 阈值为 0 时，对应两个值必须相等。
  • 重复数值仍可能来自不同下标，应分别计数。
  • 大阈值可能让所有 C(n,3) 个组合通过。

时间：O(n³)；额外空间：O(1)。

Implementations

四种语言完整代码

JavaO(n³) · O(1)
class Solution {
    public int countGoodTriplets(int[] arr, int a, int b, int c) {
        int count = 0;
        for (int i = 0; i < arr.length - 2; i++) {
            for (int j = i + 1; j < arr.length - 1; j++) {
                for (int k = j + 1; k < arr.length; k++) {
                    if (Math.abs(arr[i] - arr[j]) <= a
                            && Math.abs(arr[j] - arr[k]) <= b
                            && Math.abs(arr[i] - arr[k]) <= c) {
                        count++;
                    }
                }
            }
        }
        return count;
    }
}

替代方案

可以固定中间下标 j，再统计左右两侧同时满足区间限制的配对；若引入值域前缀计数或数据结构，可在更大约束下优化。但本题 n≤100，额外结构会增加实现与证明成本，三重枚举更直接可靠。

面试追问

  • 若 n 达到 10⁵，怎样利用值域或离线统计优化？
  • 若阈值可为负数，能否提前返回 0？
  • 如何输出所有下标组合而不只是数量？
  • 怎样防止更大数值范围下减法溢出？

常见错误

  • 循环从 0 重新开始，导致下标不满足 i<j<k 或重复计数。
  • 只检查相邻两组差值，漏掉 |arr[i]−arr[k]|≤c。
  • 把 “≤” 写成 “<”，错误排除刚好等于阈值的组合。
  • 按数值去重；题目计数依据是下标，不同下标上的相同值应分别保留。
