键盘行Keyboard Row

给定一组英文单词，找出那些所有字母都能在美式键盘同一行完成输入的单词。大小写不影响字母所属的键盘行。

数组哈希表字符串非付费题

Problem

先读懂题目

函数接收字符串数组 words，返回其中仅使用美式键盘某一行字母即可输入的全部单词，并保持它们在原数组中的相对顺序。

准确题意

美式键盘的三行字母分别是：

  • 第一行：qwertyuiop
  • 第二行：asdfghjkl
  • 第三行：zxcvbnm

逐个判断 words 中的单词。若一个单词的每个字母都来自同一行，就把原单词放入返回数组。判断不区分大小写，所以 A 与 a 属于同一行。

函数形式： findWords(words: string[]): string[]

约束

1 <= words.length <= 20

至少一个单词，最多二十个。

1 <= words[i].length <= 100

每个单词均为非空字符串。

words[i] ∈ A-Z / a-z

字符只包含大小写英文字母。

Full solution

一张映射表，完成整组筛选

核心洞察

同一个单词合法，当且仅当它的每个字母映射到同一个“行编号”。因此无需模拟真实打字，只需比较行编号。

把 26 个小写字母映射为 1、2、3 三个行编号。对每个单词先转为小写，以首字母的行编号作为目标；随后只要发现任一字母的行编号不同，就可立刻淘汰该单词。

完整过程

  1. 建立从字母到键盘行的映射，例如字符串 "12210111011122000010020202" 的第 c - 'a' 位表示字母 c 所在行。
  2. 依次遍历输入数组中的每个单词。
  3. 把当前单词统一转为小写，读取首字母对应的行编号。
  4. 检查剩余字符；若某个字符不在目标行，立即停止检查当前单词。
  5. 若所有字符都在目标行，将原始单词加入答案，从而保留原大小写与相对顺序。

正确性证明

1
被加入的单词一定合法。

算法只会在每个字符的行编号都等于首字母行编号时加入单词。因此被加入单词的全部字符属于同一键盘行，符合题意。

2
所有合法单词一定会被加入。

若单词合法，则所有字符本就与首字母位于同一行，遍历期间不会触发冲突，最终必然被加入结果。

3
结论。

算法加入且仅加入所有合法单词，因此返回结果准确；遍历顺序与加入顺序一致，所以相对顺序也得到保留。

边界情况

  • 单字母单词：天然只属于一行，应保留。
  • 大小写混合：判断前统一小写，但答案中保留原字符串。
  • 首字符来自任意行：目标行不能写死，必须由当前单词首字母决定。
  • 全部淘汰或全部保留：结果数组可以为空，也可以与输入等长。
  • 非空保证：约束说明每个单词至少含一个字母，因此可安全读取首字母。

复杂度

设所有单词的字符总数为 S。

时间 O(S)

最坏情况下，每个字符恰好检查一次；发现冲突时还可提前结束。

额外空间 O(1)

字母映射大小固定为 26；不计返回数组及语言中大小写转换产生的临时字符串。

替代方案

  • 三个集合：建立三组字符集合，判断单词是否是任一集合的子集。表达直观，但会进行多次集合判断。
  • 位掩码：为三行分别建立 26 位掩码，再计算单词掩码是否被某一行掩码包含。适合继续扩展集合类问题，但本题略显重型。
  • 正则表达式：分别匹配三行字母，可写得很短，但不利于面试中说明复杂度和提前退出机制。

import java.util.ArrayList;
import java.util.List;

class Solution {
    public String[] findWords(String[] words) {
        String rows = "12210111011122000010020202";
        List<String> answer = new ArrayList<>();

        for (String word : words) {
            String lower = word.toLowerCase();
            char targetRow = rows.charAt(lower.charAt(0) - 'a');
            boolean valid = true;

            for (int i = 1; i < lower.length(); i++) {
                if (rows.charAt(lower.charAt(i) - 'a') != targetRow) {
                    valid = false;
                    break;
                }
            }

            if (valid) {
                answer.add(word);
            }
        }

        return answer.toArray(new String[0]);
    }
}

var findWords = function(words) {
    const rows = "12210111011122000010020202";
    const answer = [];

    for (const word of words) {
        const lower = word.toLowerCase();
        const targetRow = rows.charCodeAt(lower.charCodeAt(0) - 97);
        let valid = true;

        for (let i = 1; i < lower.length; i++) {
            if (rows.charCodeAt(lower.charCodeAt(i) - 97) !== targetRow) {
                valid = false;
                break;
            }
        }

        if (valid) {
            answer.push(word);
        }
    }

    return answer;
};
from typing import List


class Solution:
    def findWords(self, words: List[str]) -> List[str]:
        rows = "12210111011122000010020202"
        answer: List[str] = []

        for word in words:
            lower = word.lower()
            target_row = rows[ord(lower[0]) - ord("a")]
            valid = True

            for char in lower[1:]:
                if rows[ord(char) - ord("a")] != target_row:
                    valid = False
                    break

            if valid:
                answer.append(word)

        return answer
class Solution {
public:
    vector<string> findWords(vector<string>& words) {
        const string rows = "12210111011122000010020202";
        vector<string> answer;

        for (const string& word : words) {
            int targetRow = rows[tolower(word[0]) - 'a'];
            bool valid = true;

            for (char character : word) {
                char lower = static_cast<char>(tolower(character));
                if (rows[lower - 'a'] != targetRow) {
                    valid = false;
                    break;
                }
            }

            if (valid) {
                answer.push_back(word);
            }
        }

        return answer;
    }
};

面试追问

如果键盘布局由输入动态给出呢？

先用哈希表建立字符到行编号的映射，再复用相同扫描逻辑；预处理复杂度与键盘字符总数线性相关。

如何扩展到 Unicode 字符？

不要依赖 c - 'a' 的数组下标，改用按码点建立的映射，并明确大小写折叠规则。

怎样减少无效扫描？

遇到第一个跨行字符立即停止检查当前单词。本解法已经采用该短路策略。

能否原地返回？

可把合法单词稳定写回输入数组前部，再按有效长度截取；但通常会修改输入，不如新建答案数组清晰。

常见错误

  • 忘记统一大小写，导致 Alaska 被错误淘汰。
  • 直接返回小写后的单词，破坏了输入的原始形式。
  • 只比较相邻字符，却没有把每个字符与统一的目标行比较。
  • 找到合法行后使用集合去重，意外改变返回顺序或丢失重复单词。
  • 把三行长度写入判断逻辑；真正重要的是字母到行编号的映射。
