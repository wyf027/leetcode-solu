检查一个字符串是否包含所有长度为 K 的二进制子串

让一个长度固定的观察窗从左向右移动：每一次只看一段，最终判断所有可能的二进制编码是否都曾出现。

中等位运算哈希表字符串滚动哈希
Problem

题目描述

给定二进制字符串 s 和整数 k。如果每一个长度恰好为 k 的二进制字符串，都能在 s 中作为连续子串找到，返回 true；否则返回 false。

示例 1

输入：s = "00110110", k = 2
输出：true
解释：00、01、10、11 都能找到。

示例 2

输入：s = "0110", k = 1
输出：true
解释：长度为 1 的 0 和 1 都出现了。

示例 3

输入：s = "0110", k = 2
输出：false
解释：长度为 2 的二进制串 00 未出现。

约束

  • 1 <= s.length <= 5 * 105
  • s[i] 只能是 '0' 或 '1'
  • 1 <= k <= 20

Solution

滑动窗口 + 位掩码

核心洞察：长度为 k 的二进制串一共只有 2^k 种。把每个窗口当作一个 k 位整数，扫描时记录不同整数的数量；数量达到 2^k 就可提前返回。

完整过程

  1. 若窗口总数 n-k+1 小于 2^k，连“每种至少一次”都无法满足，直接返回 false。
  2. 准备大小为 2^k 的布尔数组，并用整数 value 表示当前窗口。
  3. 读入新字符时左移 value，加入新位，再与 (1<<k)-1 做按位与，自动丢弃窗口外的最高位。
  4. 窗口形成后标记 seen[value]；每遇到一个新值就减少待发现数量，归零时返回 true。

为什么正确

不变式：处理位置 i 后，value 的低 k 位恰好等于以 i 结尾、长度不超过 k 的二进制后缀。因为左移并加入 s[i] 会扩展后缀，而掩码只保留最低 k 位。

当 i >= k-1 时，该后缀就是一个完整的长度 k 窗口，因此算法恰好标记 s 中所有长度为 k 的子串，既不遗漏也不加入其他字符串。最终所有 2^k 个值均被标记，当且仅当题目要求成立。

时间复杂度

O(n)：每个字符只参与一次常数时间的位运算。

空间复杂度

O(2^k)：布尔数组记录所有可能编码；题目中 k ≤ 20。

边界情况

  • s.length < k：没有任何完整窗口。
  • n-k+1 < 2^k：窗口数量不足，可提前失败。
  • k = 1：只需检查 0 与 1。
  • 大量重复窗口：只在首次出现时更新计数。

替代方案

可以把每个 s.substring(i, i+k) 放进哈希集合，写法更直接，但会创建许多子串，时间与内存常数更高。在某些语言中，切片还可能带来 O(k) 的复制成本。

四语言完整代码

class Solution {
    public boolean hasAllCodes(String s, int k) {
        int total = 1 << k;
        int windows = s.length() - k + 1;
        if (windows < total) return false;

        boolean[] seen = new boolean[total];
        int mask = total - 1;
        int value = 0;
        int remaining = total;

        for (int i = 0; i < s.length(); i++) {
            value = ((value << 1) & mask) | (s.charAt(i) - '0');
            if (i >= k - 1 && !seen[value]) {
                seen[value] = true;
                if (--remaining == 0) return true;
            }
        }
        return false;
    }
}

 * @param {string} s
 * @param {number} k
 * @return {boolean}

var hasAllCodes = function(s, k) {
    const total = 1 << k;
    const windows = s.length - k + 1;
    if (windows < total) return false;

    const seen = new Uint8Array(total);
    const mask = total - 1;
    let value = 0;
    let remaining = total;

    for (let i = 0; i < s.length; i++) {
        value = ((value << 1) & mask) | Number(s[i]);
        if (i >= k - 1 && seen[value] === 0) {
            seen[value] = 1;
            remaining--;
            if (remaining === 0) return true;
        }
    }
    return false;
};

面试追问

为什么能提前剪枝？
长度 k 的不同编码有 2^k 个，而 s 只提供 n-k+1 个窗口。窗口总数更少时，不可能覆盖全部编码。

能否用固定空间？
若要精确判断已出现的每一种编码，通常需要 Ω(2^k) 位的信息；布尔位图已很接近信息下界。

常见错误

  • 把子序列误当作连续子串。
  • 循环从错误位置开始，漏掉第一个或最后一个窗口。
  • 忘记掩码，导致 value 保留窗口外的旧高位。
  • 每次见到重复编码也减少 remaining。
  • 用 Math.pow(2, k) 后混用浮点与位运算。
