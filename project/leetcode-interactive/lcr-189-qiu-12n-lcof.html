CORE INSIGHT

核心洞察：把“是否继续”藏进逻辑与

01 · 递归齿轮

当前齿轮贡献 target，并尝试唤醒编号小一号的齿轮，累积自然形成等差和。

02 · 短路离合

逻辑与左侧为零时，右侧不会执行。于是到达零号齿轮时，递归调用自动断开。

03 · 只用加法

返回值直接使用加法合并；不需要公式、乘法、循环或显式条件分支。

FULL WALKTHROUGH

完整过程：target = 5 的齿轮链

5 + sum(4)
4 + sum(3)
3 + sum(2)
2 + sum(1)
1 + sum(0)

当参数变为 0，0 && sum(-1) 的右侧不再被求值；调用栈依次返回 1、3、6、10、15。

复杂度与边界

时间：O(target)。
额外空间：O(target)，来自递归调用栈。
边界：target 为 1 时，短路链只返回 1；题目保证 target 为正且不超过 10000。

替代方案与面试追问

替代方案：若限制解除，可使用等差数列公式获得 O(1) 时间。面试追问：为什么不直接把递归写成显式分支？因为这正违反了本题对指令集的约束。常见错误：把 && 误写为按位与，或在题解中偷偷使用三元表达式。
