657. Robot Return to Origin

四个方向，一串指令，一次关于终点的判断。先读题，再亲手逐步移动机器人；完整解法被保留在页面底部。

字符串 模拟 非付费题 官方函数：judgeCircle(moves)
Problem

题目说明

一个机器人从二维平面的原点 (0, 0) 出发。给定字符串 moves，其中每个字符代表机器人依次执行的一次移动。

R 表示向右，L 表示向左，U 表示向上，D 表示向下；每次移动的距离相同，机器人的朝向不影响移动含义。

执行完全部指令后，如果机器人回到 (0, 0)，返回 true；否则返回 false。

U向上一步
D向下一步
L向左一步
R向右一步

约束

  • 1 <= moves.length <= 2 × 104
  • moves 只包含 'U'、'D'、'L' 和 'R'。
参数：moves: string
返回值：boolean
官方示例 01
输入
moves = "UD"
输出
true
解释
机器人先向上一步，再向下一步，最终回到起点。
官方示例 02
输入
moves = "LL"
输出
false
解释
机器人连续向左两步，终点位于原点左侧，因此没有返回原点。

Solution

一次遍历，记录二维位移

核心洞察

机器人是否回到原点，只取决于最终的水平位移和竖直位移。用 x、y 记录当前位置：右移让 x + 1，左移让 x - 1，上移让 y + 1，下移让 y - 1。

所有字符处理完后，恰好在 x == 0 && y == 0 时返回 true。

另一种等价理解

回到原点等价于两组动作分别抵消：

  • U 的数量等于 D 的数量；
  • L 的数量等于 R 的数量。

计数法与坐标模拟的本质完全相同，但坐标模拟更容易扩展到“返回最终位置”等追问。

完整过程

STEP 01

初始化当前位置 (x, y) = (0, 0)。

STEP 02

从左到右读取 moves 的每个字符。

STEP 03

根据方向，仅更新对应的一个坐标分量。

STEP 04

遍历结束，判断两个坐标是否都为零。

正确性证明

  1. 循环不变量：处理完前 i 个字符后，(x, y) 等于机器人执行这 i 次移动后的真实位置。
  2. 初始化：处理零个字符时，算法令 (x, y) = (0, 0)，与机器人起点一致。
  3. 保持：每种字符对坐标的更新，都与其定义的单位方向移动一致，因此处理下一字符后不变量仍成立。
  4. 终止：遍历结束时，坐标就是全部移动后的终点。算法仅当它为原点时返回真，所以返回结果正确。

边界与复杂度

  • 长度为 1 时，不可能被另一方向抵消，结果为 false。
  • 连续同方向、交错抵消和绕行路径都由同一更新规则覆盖。
  • 输入已保证字符合法，无需处理其他字符。
  • 最大长度为 20,000，整数坐标范围很小。
时间复杂度O(n)每个字符访问一次
空间复杂度O(1)只维护两个计数

四种语言代码

class Solution {
    public boolean judgeCircle(String moves) {
        int x = 0;
        int y = 0;

        for (char move : moves.toCharArray()) {
            switch (move) {
                case 'U':
                    y++;
                    break;
                case 'D':
                    y--;
                    break;
                case 'L':
                    x--;
                    break;
                case 'R':
                    x++;
                    break;
                default:
                    break;
            }
        }

        return x == 0 && y == 0;
    }
}

替代方案

四次计数：分别统计 U/D/L/R，最后比较相反方向的数量。它同样是 O(n) 时间、O(1) 空间，但需要四个计数器。

排序后抵消：排序或建立频次表也能得到答案，却引入不必要的处理；排序甚至会把时间提高到 O(n log n)。

常见错误

  • 只判断 U == D，忘记检查水平方向。
  • 把数组坐标系的“向上”误写成 y--。本题正负选择可以相反，但上下必须互为逆操作。
  • 中途回到原点就提前返回真；题目询问的是执行完全部动作后的终点。
  • 保存完整路径，导致使用本可避免的 O(n) 额外空间。

面试追问

如果还要返回机器人最终坐标，怎么改？

遍历逻辑不变，直接返回最终的 [x, y]，不再把它压缩成布尔值。

如果指令以数据流形式持续到达呢？

持续维护 x、y 即可，每收到一个字符就更新一次；任意时刻都能用常数时间回答当前位置和“是否在原点”。

如果加入斜向移动或每步不同距离呢？

把每条指令映射为位移向量 (dx, dy)，再累加到坐标。若距离也在指令中，就将方向向量乘以该距离。
