最长等差数列

Longest Arithmetic Subsequence

题目

给定整数数组 nums，返回其中最长等差子序列的长度。子序列可删除任意元素，但保留元素的原有相对顺序；若相邻元素之差始终相同，则它是等差序列。

函数签名

longestArithSeqLength(nums: integer[]) → integer

示例 1
输入：nums = [3,6,9,12]
输出：4
解释：整个数组公差为 3。
示例 2
输入：nums = [9,4,7,2,10]
输出：3
解释：[4,7,10] 是最长等差子序列。
示例 3
输入：nums = [20,1,15,3,10,5,8]
输出：4
解释：[20,15,10,5] 是最长等差子序列。
约束
  • 2 ≤ nums.length ≤ 1000
  • 0 ≤ nums[i] ≤ 500

差值轨迹实验室

观察每一对索引如何延长“以当前位置结尾、固定公差”的状态。

题解：按终点与公差记录最优长度

核心洞察

只知道“以 i 结尾”不够，因为不同公差不能互相延长。定义 dp[i][d] 为以索引 i 结尾、公差为 d 的最长等差子序列长度。枚举前驱 j < i，令 d = nums[i] - nums[j]。

完整过程

  1. 为每个终点建立一个“公差 → 长度”的映射。
  2. 遍历所有有序索引对 (j,i)。
  3. 若 dp[j][d] 存在，将它延长一位；否则当前两点首次形成长度 2 的等差序列。
  4. 用新长度更新 dp[i][d] 和全局答案。

正确性

归纳：处理到 i 时，所有更早终点的状态均已正确。任意以 i 结尾且公差为 d 的序列，其倒数第二个元素必在某个 j<i，且 nums[i]-nums[j]=d；删除末项后正是 dp[j][d] 表示的候选。算法枚举所有这样的 j 并取最大值，因此 dp[i][d] 正确。全局最大状态即最长等差子序列长度。

边界与复杂度

  • 两个元素总能组成长度 2 的等差序列。
  • 重复值对应公差 0，映射可以自然处理。
  • 负公差必须保留，不能取绝对值。
  • 时间复杂度 O(n²)，空间复杂度 O(n²)。

替代方案

由于本题数值范围为 0 到 500，公差落在 [-500,500]，可用长度 1001 的数组代替哈希表，常数更小但更依赖题目约束。按公差枚举再寻找前驱的方案也可构造，但通常不如二重循环 DP 直接。

面试追问

  • 如果只要求最长连续等差子数组，可否降到 O(n)？
  • 如何恢复一条实际的最长子序列？（额外记录前驱索引。）
  • 数值范围很大时，数组状态与哈希状态怎样权衡？

常见错误

  • 把子序列误写成连续子数组。
  • 状态只记录终点，不记录公差。
  • 新状态初始化为 1，而不是两点组成的 2。
  • 覆盖同一 (i,d) 状态时没有取最大值。

import java.util.*;

class Solution {
    public int longestArithSeqLength(int[] nums) {
        int n = nums.length, answer = 2;
        List<Map<Integer, Integer>> dp = new ArrayList<>();
        for (int i = 0; i < n; i++) dp.add(new HashMap<>());
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                int d = nums[i] - nums[j];
                int length = dp.get(j).getOrDefault(d, 1) + 1;
                dp.get(i).put(d, Math.max(dp.get(i).getOrDefault(d, 0), length));
                answer = Math.max(answer, dp.get(i).get(d));
            }
        }
        return answer;
    }
}
