Short Encoding of Words单词的压缩编码

把一组单词放进一个以 # 分隔的助记字符串，让每个单词都能从某个下标被完整读出；你的目标只是求最短长度。

先读题，再动手。 首屏只呈现问题本身。交互实验与默认收起的完整题解在下方。

Problem

题意

单词数组 words 的有效编码由一个助记字符串 s 和下标数组 indices 组成。

字符串 s 必须以 # 结尾。对每个 indices[i]，从该位置开始一直读到下一个 #（不包含它），所得子字符串必须恰好等于 words[i]。

返回所有有效编码中，最短助记字符串 s 的长度。

有效编码须同时满足

  • words.length == indices.length
  • s 的末尾是 #
  • 每个下标都能从 s 中解码出对应单词
minimumLengthEncoding(words: string[]): number

Official examples

官方示例

示例 1

输入words = ["time", "me", "bell"]
输出10

可以取 s = "time#bell#"、indices = [0, 2, 5]。从下标 0、2、5 分别读到下一个 #，会得到 time、me、bell。

示例 2

输入words = ["t"]
输出2

可以取 s = "t#"、indices = [0]，因此最短长度为 2。

Constraints

约束

1 ≤ words.length ≤ 2000单词数量
1 ≤ words[i].length ≤ 7单词长度
a–z仅含小写英文字母

Solution

题解：只为“不能被别人收进去”的单词付费

!

核心洞察

一个单词能共享另一个单词的编码，当且仅当它是后者的后缀。例如 me 是 time 的后缀，所以写下 time# 时，已经能从偏移量 2 读出 me。因此，先去重，再删掉所有“是其他单词后缀”的单词；剩余单词各贡献 长度 + 1。

完整过程

  1. 放进集合并去重。重复单词可以使用同一个起始下标，不应重复计算。
  2. 枚举每个单词的真后缀。对长度为 L 的单词，依次取 word.substring(1) 到 word.substring(L - 1)。
  3. 从集合删除这些后缀。被删除者可借用更长单词对应的那段编码。
  4. 统计剩余单词。每个剩余单词必须独立出现在参考串中，并在末尾跟一个 #。

正确性 · 被删除的单词无需额外空间

若单词 a 被删除，则存在另一个单词 b 以 a 结尾。在编码中写入 b# 后，从 b 内对应偏移开始读取，正好得到 a，所以它不必单独出现。

正确性 · 剩余单词必须付出长度 + 1

若剩余单词 w 不独立占据某个以 # 结尾的片段，它只能作为另一个片段中单词的后缀被读出，这与“它不是任何其他单词的后缀”矛盾。因此每个剩余单词至少贡献自身长度和一个分隔符。把它们直接串接即可达到该下界，算法最优。

复杂度

时间 O(n · L²)哈希集合平均情形；生成每个后缀本身最多复制 O(L) 个字符。
空间 O(n · L)集合最多保存所有去重后的单词。题目中 L ≤ 7。

边界情况

  • 单个单词：答案是其长度加 1。
  • 全部重复：去重后只计算一次。
  • 后缀链：如 time → me → e，只保留最长者。
  • 互不为后缀：所有单词都要计入。
  • 前缀不产生共享：time 不能靠 timer# 解码，因为分隔符前读到的是 timer。

替代方案 · 反向字典树

把每个单词反转后插入字典树。只有叶子对应的原单词不能被更长单词覆盖，累加这些叶子单词的 长度 + 1 即可。它把后缀关系转换为公共前缀关系，时间和空间都是总字符数级别，但实现更长。

四语言完整代码

import java.util.Arrays;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minimumLengthEncoding(String[] words) {
        Set<String> remaining = new HashSet<>(Arrays.asList(words));

        for (String word : words) {
            for (int i = 1; i < word.length(); i++) {
                remaining.remove(word.substring(i));
            }
        }

        int answer = 0;
        for (String word : remaining) {
            answer += word.length() + 1;
        }
        return answer;
    }
}

 * @param {string[]} words

var minimumLengthEncoding = function(words) {
    const remaining = new Set(words);

    for (const word of words) {
        for (let i = 1; i < word.length; i++) {
            remaining.delete(word.slice(i));
        }
    }

    let answer = 0;
    for (const word of remaining) {
        answer += word.length + 1;
    }
    return answer;
};
from typing import List


class Solution:
    def minimumLengthEncoding(self, words: List[str]) -> int:
        remaining = set(words)

        for word in words:
            for i in range(1, len(word)):
                remaining.discard(word[i:])

        return sum(len(word) + 1 for word in remaining)
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    int minimumLengthEncoding(vector<string>& words) {
        unordered_set<string> remaining(words.begin(), words.end());

        for (const string& word : words) {
            for (int i = 1; i < static_cast<int>(word.size()); ++i) {
                remaining.erase(word.substr(i));
            }
        }

        int answer = 0;
        for (const string& word : remaining) {
            answer += static_cast<int>(word.size()) + 1;
        }
        return answer;
    }
};

常见错误

  • 把“后缀”误写成“子串”；只有一直延伸到分隔符前的后缀才能共享。
  • 没有先去重，导致相同单词被多次计费。
  • 从位置 0 开始删后缀，把单词自身也删掉。
  • 只检查相邻单词，漏掉不相邻的后缀关系。
  • 统计时忘记每个保留单词后面的 #。

面试追问

  • 为什么是后缀，不是前缀？ 因为读取必须在下一个 # 前恰好结束。
  • 如何优化到总字符数级别？ 反转单词后建立字典树，只统计叶子。
  • 若需要构造 s 和 indices？ 先拼接所有保留单词并记录起点；被覆盖单词的起点等于覆盖者起点加长度差。
  • 哈希法何时更合适？ 当最大单词长度很小（本题仅 7）时，代码短且常数低。
