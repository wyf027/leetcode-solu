Core insight

每次搬一位，正好搬 32 次

最低位成为新尾位

结果先左移腾出一格，再把 n & 1 放进去；输入逻辑右移，继续处理下一位。

完整过程与循环不变量

  1. 初始化 result = 0。
  2. 重复 32 次，提取 bit = n & 1。
  3. 更新 result = (result << 1) | bit。
  4. 用逻辑右移令 n = n >>> 1。

完成第 k 次后，result 恰好保存原数最低 k 位的逆序。32 次后覆盖全部固定位宽。

边界与当前签名

  • n = 0 时 32 次搬运仍返回 0。
  • 不能在 n == 0 时提前停止，否则会丢失前导零对应的位置。
  • 当前约束保证 n 为偶数，所以反转后的最高位为 0，结果不会成为负数。
  • JavaScript 必须使用 >>> 保证逻辑右移。

复杂度与替代方案

位宽记作 b 时为 O(b) 时间、O(1) 空间；本题固定 32 位，因此也是常数时间。

可用掩码依次交换 1、2、4、8、16 位分组。若函数高频调用，可预计算 256 个字节的反转表，再查四个字节并拼接。

Java · LeetCode 可提交

Java 17 · 官方 int 签名
class Solution {
    public int reverseBits(int n) {
        int result = 0;
        for (int i = 0; i < 32; i++) {
            result = (result << 1) | (n & 1);
            n >>>= 1;
        }
        return result;
    }
}

常见错误

  • 只循环到 n 变成 0，漏掉固定 32 位中的零。
  • 先右移再取位，直接丢掉最低位。
  • JavaScript 使用算术右移 >>。
  • 沿用旧版无符号签名，忽略当前官方 int 契约。
