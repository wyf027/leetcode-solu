最大平均
通过率

把有限的优秀学生分到不同班级，让全校的班级平均通过率尽可能高。先理解目标，再进入分配实验。

题目说明

函数形式：maxAverageRatio(classes, extraStudents) → double

学校有若干班级，classes[i] = [passᵢ, totalᵢ] 表示第 i 个班级共有 totalᵢ 人，其中预计有 passᵢ 人通过考试。

另有 extraStudents 名一定能通过考试的学生。必须把每名额外学生安排到某个班级，使所有班级通过率的算术平均值最大。班级通过率为通过人数除以总人数。

maximize (1 / n) × Σ(passᵢ / totalᵢ)

返回可达到的最大平均通过率；与正确结果的误差不超过 10⁻⁵ 即可。

示例 1

输入：classes = [[1,2],[3,5],[2,2]],
      extraStudents = 2
输出：0.78333
解释：两名学生都分到第 1 个班级，
      (3/4 + 3/5 + 2/2) / 3 = 0.78333

示例 2

输入：classes = [[2,4],[3,9],[4,5],[2,10]],
      extraStudents = 4
输出：0.53485

约束

  • 1 ≤ classes.length ≤ 10⁵
  • classes[i].length == 2
  • 1 ≤ passᵢ ≤ totalᵢ ≤ 10⁵
  • 1 ≤ extraStudents ≤ 10⁵

题解：最大堆驱动的边际增益贪心

关键不是当前通过率最低的班级，而是“下一名学生能让哪个班级提升最多”。

核心洞察

给状态为 [p,t] 的班级加入一名必过学生，平均值中的分子增量取决于该班级通过率的增益：

gain(p,t) = (p+1)/(t+1) − p/t = (t−p) / (t(t+1))

所有班级在总平均值中的权重相同，因此每一步选择当前 gain 最大的班级。加入后该班变成 [p+1,t+1]，重新计算并放回最大堆。

完整过程

  1. 为每个班级计算下一名学生带来的边际增益。
  2. 把所有班级放入按增益降序排列的最大堆。
  3. 重复 extraStudents 次：弹出最大增益班级，令 p++、t++，再压回堆。
  4. 遍历最终状态，累加 p/t，再除以班级数。

正确性说明

边际收益递减：对固定班级，连续加入必过学生后，(t−p)/(t(t+1)) 的分子不变、分母增大，所以收益单调不增。

交换论证：若某一步把学生给了收益较小的班级 B，而当时 A 的收益更大，交换这次分配到 A 不会降低总通过率之和。随后各班收益只会递减，因此逐步取当前最大收益可以构造出不劣于任意分配顺序的方案。

经过全部分配后，贪心方案使通过率总和最大；班级数固定，平均值也随之最大。

复杂度与边界

  • 设班级数为 n、额外学生数为 k。
  • 建堆 O(n)；每次弹出和压入 O(log n)。
  • 总时间 O(n + k log n)，空间 O(n)。
  • p == t 时增益为 0；单班级仍按相同过程处理。
  • 使用浮点数累计结果；比较器必须让“增益最大”位于堆顶。

替代方案与取舍

逐次线性扫描：每名学生都遍历全部班级找最大增益，时间为 O(nk)，在 10⁵ 规模下不可行。

按当前通过率排序：错误。通过率更低不等于下一名学生带来的增益更大，班级规模也决定增益。

批量分配 / 二分阈值：可以研究按收益阈值批量确定每班人数，但推导和精度处理更复杂；本题约束下最大堆更直接稳妥。

面试追问

为什么不能给通过率最低的班？

因为目标看的是加入一人后的差值。比如大班级即使通过率低，一人的影响也可能很小。

为什么平均值里的除以 n 可以暂时忽略？

n 固定，最大化总和与最大化总和除以 n 等价。

怎样避免比较器写反？

先用两个手算增益验证堆顶；JavaScript 手写堆可明确让 greater(a,b) 表示 a 应在上方。

收益为什么递减？

加入必过学生后，t−p 不变，而 t(t+1) 变大。

常见错误

  • 按 p/t 排序，而不是按 (p+1)/(t+1) − p/t 排序。
  • 加入学生时只增加通过人数，忘记总人数也要增加。
  • 每轮取出后没有用新状态重新入堆。
  • 使用整数除法，导致通过率和增益被截断。
  • 最后返回通过率之和，忘记除以班级数。

四语言完整实现

均采用最大堆维护当前边际增益，函数签名与官方元数据一致。

Java

class Solution {
    public double maxAverageRatio(int[][] classes, int extraStudents) {
        java.util.PriorityQueue<double[]> heap = new java.util.PriorityQueue<>(
            (a, b) -> Double.compare(gain(b), gain(a))
        );

        for (int[] c : classes) {
            heap.offer(new double[]{c[0], c[1]});
        }

        while (extraStudents-- > 0) {
            double[] c = heap.poll();
            c[0]++;
            c[1]++;
            heap.offer(c);
        }

        double sum = 0.0;
        while (!heap.isEmpty()) {
            double[] c = heap.poll();
            sum += c[0] / c[1];
        }
        return sum / classes.length;
    }

    private static double gain(double[] c) {
        return (c[1] - c[0]) / (c[1] * (c[1] + 1.0));
    }
}

JavaScript

/**
 * @param {number[][]} classes
 * @param {number} extraStudents
 * @return {number}
 */
var maxAverageRatio = function(classes, extraStudents) {
    const gain = ([pass, total]) =>
        (total - pass) / (total * (total + 1));

    const heap = classes.map(([pass, total]) => [pass, total]);
    const greater = (i, j) => gain(heap[i]) > gain(heap[j]);

    const swap = (i, j) => {
        [heap[i], heap[j]] = [heap[j], heap[i]];
    };

    const siftDown = (index) => {
        while (true) {
            let best = index;
            const left = index * 2 + 1;
            const right = left + 1;
            if (left < heap.length && greater(left, best)) best = left;
            if (right < heap.length && greater(right, best)) best = right;
            if (best === index) return;
            swap(index, best);
            index = best;
        }
    };

    for (let i = Math.floor(heap.length / 2) - 1; i >= 0; i--) {
        siftDown(i);
    }

    while (extraStudents-- > 0) {
        heap[0][0]++;
        heap[0][1]++;
        siftDown(0);
    }

    const sum = heap.reduce((acc, [pass, total]) =>
        acc + pass / total, 0);
    return sum / heap.length;
};

Python 3

from typing import List
import heapq

class Solution:
    def maxAverageRatio(
        self, classes: List[List[int]], extraStudents: int
    ) -> float:
        def gain(p: int, t: int) -> float:
            return (t - p) / (t * (t + 1))

        heap = [(-gain(p, t), p, t) for p, t in classes]
        heapq.heapify(heap)

        for _ in range(extraStudents):
            _, p, t = heapq.heappop(heap)
            p += 1
            t += 1
            heapq.heappush(heap, (-gain(p, t), p, t))

        return sum(p / t for _, p, t in heap) / len(classes)

C++

class Solution {
public:
    double maxAverageRatio(vector<vector<int>>& classes,
                           int extraStudents) {
        using Class = pair<int, int>;
        auto gain = [](const Class& c) {
            long double p = c.first;
            long double t = c.second;
            return (t - p) / (t * (t + 1.0L));
        };
        auto cmp = [&](const Class& a, const Class& b) {
            return gain(a) < gain(b);
        };

        priority_queue<Class, vector<Class>, decltype(cmp)> heap(cmp);
        for (const auto& c : classes) {
            heap.push({c[0], c[1]});
        }

        while (extraStudents-- > 0) {
            auto [p, t] = heap.top();
            heap.pop();
            heap.push({p + 1, t + 1});
        }

        long double sum = 0.0L;
        while (!heap.empty()) {
            auto [p, t] = heap.top();
            heap.pop();
            sum += static_cast<long double>(p) / t;
        }
        return static_cast<double>(sum / classes.size());
    }
};
