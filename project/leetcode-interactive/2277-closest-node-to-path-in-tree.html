树中最接近路径的节点

Closest Node to Path in Tree

一条路径，一个树外视角：沿着树边走，路径上的哪个节点离指定节点最近？

先理解输入与目标，再亲手推进图示。完整推导与四语言代码收在页面底部，可按需展开。
01 / PROBLEM

任务与输入

给定一棵无向树，节点编号为 0 … n − 1。edges 中的每个二元组表示一条边。对每个查询 [start, end, node]，在 start 到 end 的唯一简单路径上，找出与 node 距离最小的节点。距离按经过的边数计算，端点也属于路径。

按查询顺序返回节点编号数组。参数形式：closestNode(n, edges, query) → integer[]。

约束

  • 1 ≤ n ≤ 1000。
  • edges.length = n − 1，每条边恰好有两个节点。
  • 边的两端编号在 [0, n − 1] 内，且不相同。
  • 1 ≤ query.length ≤ 1000，每个查询恰好三个整数。
  • start、end、node 都在 [0, n − 1] 内，可以相同。
  • 输入保证连通且无环，即一棵树。

读题提示

结果是节点编号，不是最短距离。要找的节点必须在指定路径上；指定的 node 本身不一定在路径上。

题意以自己的表述整理。官方元数据给出了函数签名和三组示例输入；付费题面为空，约束与示例输出由公开题目资料补齐。

04 / EDITORIAL

独立题解

核心洞察：先算距离，再限定候选

每次查询只需要两类信息：从目标 x 到所有点的距离，以及 s → t 路径上有哪些点。树中任意两点间只有一条简单路径，因此从 s 出发搜索时保存的父指针，可以从 t 一路回溯到 s，恰好枚举全部候选。

在 n、m ≤ 1000 的规模下，每次查询做两次 BFS 就足够直接：一次从 s 记录父节点，一次从 x 记录距离。无需存储所有点对的距离。

完整过程

  1. 用邻接表存储无向边，两个方向都要加入。
  2. 从 s 做 BFS，初始化 parent[s] = s，其他值为 −1。首次访问 v 时记录它的父节点。
  3. 从 x 做 BFS，初始化 dist[x] = 0，其他值为 −1；沿边首次访问 v 时设为 dist[u] + 1。
  4. 以 t 为起点沿父指针向 s 回溯。维护距离最小的节点 best，比较并包含 s 后结束。
  5. 追加 best，继续处理下一条查询。可视化先展示距离波纹，再展示已恢复的路径与回溯比较；这两次 BFS 的顺序不影响结果。

正确性证明

距离正确。 BFS 按边数递增扩展无权图；第一次访问节点 v 时已经取得从 x 到 v 的最短距离，故 dist 数组正确。

候选完整且合法。 从 s 搜索得到的父链连接每个节点与 s。树中简单路径唯一，所以从 t 回溯到 s 的节点集合恰好是题目指定的路径，没有遗漏，也没有多余节点。

最小值不变式。 每处理一个候选，best 都保存已处理节点中的距离最小者。结束时所有路径节点都已处理，因此返回节点满足目标。

为什么答案唯一？ x 到指定路径的首次汇入点 p 唯一，否则树中会出现环。到路径上任意 y 的路径都经过 p，因此 d(x,y) = d(x,p) + d(p,y)；当 y ≠ p 时严格更大。x 在路径上时 p = x。

边界与复杂度

  • s = t：路径只有一个节点，回溯循环仍比较该节点一次。
  • x 在路径上：其距离为 0，一定返回 x。
  • n = 1、空边数组：两个 BFS 都只处理节点 0。
  • 链状树：采用迭代队列，无递归栈溢出风险。
  • 设 m = query.length；建图 O(n)，每次查询 O(n)，总时间 O(n + mn)。邻接表、队列及临时数组占 O(n) 辅助空间，返回结果另占 O(m)。

替代方案

从每个节点 BFS 可预处理全部距离，时间和空间均为 O(n²)，再逐条枚举路径。也可用二进制提升预处理 LCA（最近公共祖先），对 s、t、x 的三个两两 LCA，取深度最大的一个作为树上三点的交汇点；预处理 O(n log n)、每条查询 O(log n)。查询更多时，后者更合适，但要证明交汇点性质并正确维护祖先表。

常见错误

  • 返回 dist[best]，而题目需要的是 best 的编号。
  • 在全树中直接取距离最小值，忘了限制到 s → t 路径。
  • 回溯写成 “当 u ≠ s 才处理”，漏掉起点。
  • 把 parent[s] 保持 −1，导致搜索重新进入根；这里设成 s 同时标记已访问。
  • 多次查询复用上一次的距离或父指针，未重新初始化。
  • 用 JavaScript 的 shift() 不断出队，带来额外搬移；使用递增的队头下标。

面试追问

边有正权怎么办？ 树仍只有唯一简单路径，从目标迭代遍历并累计权重即可，不需要 Dijkstra；交汇点结论在正权下依旧成立。零权边可能导致多个最优节点。

查询数量很大怎么办？ 转用 LCA 三点交汇法，将每条查询降为 O(log n)。若输入不再是一棵树，父链不再唯一代表指定的路径，唯一答案与交汇点证明也不能照搬。

Java

import java.util.*;

class Solution {
    public int[] closestNode(int n, int[][] edges, int[][] query) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
        }
        int[] answer = new int[query.length];
        for (int i = 0; i < query.length; i++) {
            int s = query[i][0], t = query[i][1], x = query[i][2];
            int[] parent = new int[n], dist = new int[n];
            Arrays.fill(parent, -1);
            Arrays.fill(dist, -1);
            ArrayDeque<Integer> q = new ArrayDeque<>();
            parent[s] = s;
            q.add(s);
            while (!q.isEmpty()) {
                int u = q.remove();
                for (int v : g.get(u)) {
                    if (parent[v] != -1) continue;
                    parent[v] = u;
                    q.add(v);
                }
            }
            dist[x] = 0;
            q.add(x);
            while (!q.isEmpty()) {
                int u = q.remove();
                for (int v : g.get(u)) {
                    if (dist[v] != -1) continue;
                    dist[v] = dist[u] + 1;
                    q.add(v);
                }
            }
            int best = t;
            for (int u = t; ; u = parent[u]) {
                if (dist[u] < dist[best]) best = u;
                if (u == s) break;
            }
            answer[i] = best;
        }
        return answer;
    }
}

/**
 * @param {number} n
 * @param {number[][]} edges
 * @param {number[][]} query
 * @return {number[]}
 */
var closestNode = function(n, edges, query) {
    const g = Array.from({ length: n }, () => []);
    for (const [u, v] of edges) {
        g[u].push(v);
        g[v].push(u);
    }
    return query.map(([s, t, x]) => {
        const parent = Array(n).fill(-1);
        const dist = Array(n).fill(-1);
        let q = [s];
        parent[s] = s;
        for (let head = 0; head < q.length; head++) {
            const u = q[head];
            for (const v of g[u]) {
                if (parent[v] !== -1) continue;
                parent[v] = u;
                q.push(v);
            }
        }
        q = [x];
        dist[x] = 0;
        for (let head = 0; head < q.length; head++) {
            const u = q[head];
            for (const v of g[u]) {
                if (dist[v] !== -1) continue;
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
        let best = t;
        for (let u = t; ; u = parent[u]) {
            if (dist[u] < dist[best]) best = u;
            if (u === s) break;
        }
        return best;
    });
};

Python

from collections import deque
from typing import List

class Solution:
    def closestNode(self, n: int, edges: List[List[int]],
                    query: List[List[int]]) -> List[int]:
        g = [[] for _ in range(n)]
        for u, v in edges:
            g[u].append(v)
            g[v].append(u)
        answer = []
        for s, t, x in query:
            parent = [-1] * n
            parent[s] = s
            q = deque([s])
            while q:
                u = q.popleft()
                for v in g[u]:
                    if parent[v] == -1:
                        parent[v] = u
                        q.append(v)
            dist = [-1] * n
            dist[x] = 0
            q = deque([x])
            while q:
                u = q.popleft()
                for v in g[u]:
                    if dist[v] == -1:
                        dist[v] = dist[u] + 1
                        q.append(v)
            best, u = t, t
            while True:
                if dist[u] < dist[best]:
                    best = u
                if u == s:
                    break
                u = parent[u]
            answer.append(best)
        return answer

C++

#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    vector<int> closestNode(int n, vector<vector<int>>& edges,
                            vector<vector<int>>& query) {
        vector<vector<int>> g(n);
        for (const auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        vector<int> answer;
        for (const auto& item : query) {
            int s = item[0], t = item[1], x = item[2];
            vector<int> parent(n, -1), dist(n, -1);
            queue<int> q;
            parent[s] = s;
            q.push(s);
            while (!q.empty()) {
                int u = q.front(); q.pop();
                for (int v : g[u]) {
                    if (parent[v] != -1) continue;
                    parent[v] = u;
                    q.push(v);
                }
            }
            dist[x] = 0;
            q.push(x);
            while (!q.empty()) {
                int u = q.front(); q.pop();
                for (int v : g[u]) {
                    if (dist[v] != -1) continue;
                    dist[v] = dist[u] + 1;
                    q.push(v);
                }
            }
            int best = t;
            for (int u = t; ; u = parent[u]) {
                if (dist[u] < dist[best]) best = u;
                if (u == s) break;
            }
            answer.push_back(best);
        }
        return answer;
    }
};
