Problem brief

题意转述

给定非空整数数组 nums。除一个数字只出现一次外，其余数字都出现两次。返回只出现一次的数字。

解法必须达到 O(n) 时间，并且只使用 O(1) 额外空间。

约束

1 ≤ nums.length ≤ 3 × 104；−3 × 104 ≤ nums[i] ≤ 3 × 104。

Interview solution

题解

先完成观察，再决定是否揭开原理与代码。

Core insight

让相同数字自己抵消

异或满足 a ⊕ a = 0、0 ⊕ x = x，并且交换顺序不会改变结果。所有成对数字都会归零，最终只留下唯一数字。

Full process

一次扫描，一个累积器

  1. 令答案变量 ans = 0。
  2. 依次执行 ans = ans ⊕ nums[i]。
  3. 扫描结束后返回 ans。

Complexity & edges

复杂度与边界

  • 时间：O(n)，每个数字处理一次。
  • 额外空间：O(1)，只保留一个累积器。
  • 单元素数组直接得到该元素；0 和负数同样适用。
  • 前提必须是“其余数字恰好出现两次”。

Alternatives

替代方案取舍

哈希计数也是 O(n) 时间，但需要 O(n) 空间；排序后配对需 O(n log n) 时间，若原地排序还会改变输入。面试中优先推荐异或，因为它同时满足两项硬约束。

Follow-ups

面试追问

  • 如果有两个数字各出现一次，怎样用低位分组？
  • 如果其余数字出现三次，为什么单纯异或失效？
  • JavaScript 的位运算为什么会转换为 32 位有符号整数？

Common mistakes

常见错误

  • 用集合增删却声称 O(1) 额外空间。
  • 把异或 ^ 误写成逻辑或或乘方。
  • 依赖相邻配对，却没有先排序。
  • 忽略题目出现次数的严格前提。
class Solution {
    public int singleNumber(int[] nums) {
        int answer = 0;
        for (int num : nums) {
            answer ^= num;
        }
        return answer;
    }
}
