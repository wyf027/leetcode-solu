准时抵达会议现场的
最小跳过休息次数

Minimum Skips to Arrive at Meeting On Time

路程是固定的，出发时刻却会改变。先亲手安排一趟行程，观察一次跳过如何影响后面的等待。

01 / 题目任务

官方题目 ↗

从时刻 0 出发，按顺序通过 dist 中的 n 条道路，始终以 speed 千米/小时行驶。第 i 条道路长 dist[i] 千米。除最后一条外，每走完一条道路，都要等到当前到达时刻向上取整后的整数小时，才能开始下一条；恰好在整数小时到达时，无需等待。

你可以跳过某些道路后的休息，立即继续出发。在不晚于 hoursBefore 小时到达终点的前提下，返回最少跳过次数；无论如何都来不及则返回 -1。最后一条道路之后无需休息。

参数与约束

  • minSkips(dist, speed, hoursBefore) → integer
  • n == dist.length，1 ≤ n ≤ 1000
  • 1 ≤ dist[i] ≤ 10⁵
  • 1 ≤ speed ≤ 10⁶
  • 1 ≤ hoursBefore ≤ 10⁷

02 / 官方示例

示例 1

dist = [1,3,2]
speed = 4
hoursBefore = 2
输出：1

不跳过时总耗时 2.5 小时。跳过第 1 条路后的休息，第 2 条路恰好在 1 小时处走完，最终 1.5 小时到达。

示例 2

dist = [7,3,5,5]
speed = 2
hoursBefore = 10
输出：2

不跳过时需 11.5 小时。跳过第 1、3 条路后的休息，分别在 3.5、5、7.5、10 小时处走完四条路，准时到达。

示例 3

dist = [7,3,5,5]
speed = 1
hoursBefore = 10
输出：-1

纯行驶时间已经是 20 小时，即使跳过全部休息，也超过 10 小时的期限。

05 / 推导与实现

先尝试解释：为什么跳过一次休息，会连带改变下一次的等待时间？准备好后再展开。

把时刻保存下来，比较每一种跳过次数

核心洞察：更早出发永远不会吃亏

相同道路进度、相同跳过次数下，只需保留最早的时刻。后续无论选择等待还是跳过，更早的时刻都不会变成更晚的时刻。这让指数数量的休息组合可以合并成动态规划状态。

不要累计小数小时。将时间乘以 speed，用整数 t 表示缩放后的时刻：走一条路就是加 dist[i]；整点等待就是把 t 向上补到 speed 的倍数。最后比较 hoursBefore × speed。

状态、转移与完整过程

  1. 定义 dp[k]：已经处理前 i 条道路及其后的休息，恰好跳过 k 次的最小缩放时刻。初始化 i = 0，dp[0] = 0，其余为无穷大。
  2. 只处理前 n − 1 条道路。对每个可达的 dp[k]，令 t = dp[k] + dist[i]。
  3. 保留休息：next[k] = min(next[k], floor((t + speed − 1) / speed) × speed)。
  4. 跳过休息：next[k + 1] = min(next[k + 1], t)。即使恰好整点，这个选择也可建模为消耗一次跳过；最小答案不会因此变差。
  5. 每轮使用全新的 next，防止当前道路被重复处理。最后统一加上末段路长，不再取整。
  6. 从 k = 0 向上扫描，第一个满足 dp[k] + dist[n − 1] ≤ hoursBefore × speed 的 k 就是答案。若总路长大于期限乘速度，可提前返回 −1。
round(t) = ⌊(t + speed − 1) / speed⌋ × speed

正确性证明

基础：未走任何道路时，只有零次跳过、时刻为零的状态可达，初始化正确。

归纳：假设 dp 对前 i 条道路正确。下一条道路之后只有保留休息和跳过休息两种选择，两个转移覆盖全部合法方案。加法和向上取整函数都单调不减，因此同样 i、k 下被舍弃的更晚时刻，不可能产生比保留状态更早的后继。取最小值后，next 仍给出每个跳过次数的最早时刻。

终止：处理 n − 1 个休息点后，所有方案再加相同末段路程即到达终点。按 k 递增返回首个不超时状态，就得到最小跳过次数；若没有可行状态则无解。

边界与数值安全

  • n = 1 时休息循环不执行，直接比较唯一道路的行驶时间。
  • 恰好到达整数小时，向上取整不会额外加一小时；恰好在期限到达也算成功。
  • 最多只有 n − 1 个休息点。全部跳过后仍超时，则一定无解。
  • 期限乘速度最大为 10¹³。Java 使用 long，C++ 使用 long long，并在乘法前提升类型。JavaScript 的 Number 在本题整数范围内精确，不使用 32 位位运算。
  • 无穷大状态不做转移。Python 可达值始终使用整数整除。

复杂度

第 i 轮处理 i + 1 个状态，总时间 O(n²)，两个长度为 n 的滚动数组占用 O(n) 额外空间。提前检查总路长耗时 O(n)。

替代方案与取舍

  • 枚举 n − 1 个休息点的全部组合，耗时 O(n·2ⁿ)，只适合极小规模的思考。
  • 二维 DP 保留所有行，时间 O(n²)、空间 O(n²)，便于保存父状态并恢复跳过位置。
  • 按同一状态定义做记忆化搜索也可得到 O(n²)，但有递归深度与函数调用开销。
  • “每次跳过当前等待最长的休息”不可靠：一次跳过会改变后续到达时刻，等待时间不是固定收益。例如示例 1 跳过第一处后，第二处等待也消失。

常见错误

  • 对每条路的独立耗时取整。应对累计到达时刻取整，跳过后的时刻可能不是整数。
  • 在最后一段之后取整，或允许跳过终点之后不存在的休息。
  • 使用浮点累加后直接 ceil，可能把理论整点误算成下一小时。
  • 原地正序更新 dp，把同一条路走了多次；采用新数组避免这种污染。
  • 把恰好 k 次的状态混成至多 k 次却不调整初始化与转移含义。

面试追问

如何输出实际跳过位置？保留二维最优值与来源，在最小可行终态逆向回溯；平局任选一条合法路径。

每段速度不同还能直接用整数距离缩放吗？不能直接使用同一个 speed。需要寻找统一时间单位或精确有理数表示，并重新评估数值范围。

能否只保存一个数组？可以按 k 递减，用旧 dp[k] 和旧 dp[k − 1] 写入新 dp[k]，但必须严谨处理不可达边界。这里使用两个数组保持转移清晰。

Java

import java.util.Arrays;

class Solution {
    public int minSkips(int[] dist, int speed, int hoursBefore) {
        int n = dist.length;
        long limit = (long) speed * hoursBefore;
        long total = 0;
        for (int d : dist) total += d;
        if (total > limit) return -1;
        long inf = Long.MAX_VALUE / 4;
        long[] dp = new long[n];
        Arrays.fill(dp, inf);
        dp[0] = 0;
        for (int i = 0; i < n - 1; i++) {
            long[] next = new long[n];
            Arrays.fill(next, inf);
            for (int k = 0; k <= i; k++) {
                if (dp[k] == inf) continue;
                long t = dp[k] + dist[i];
                long wait = (t + speed - 1) / speed * speed;
                next[k] = Math.min(next[k], wait);
                next[k + 1] = Math.min(next[k + 1], t);
            }
            dp = next;
        }
        for (int k = 0; k < n; k++) {
            if (dp[k] + dist[n - 1] <= limit) return k;
        }
        return -1;
    }
}

var minSkips = function(dist, speed, hoursBefore) {
    const n = dist.length, limit = speed * hoursBefore;
    if (dist.reduce((sum, d) => sum + d, 0) > limit) return -1;
    let dp = Array(n).fill(Infinity);
    dp[0] = 0;
    for (let i = 0; i < n - 1; i++) {
        const next = Array(n).fill(Infinity);
        for (let k = 0; k <= i; k++) {
            if (!Number.isFinite(dp[k])) continue;
            const t = dp[k] + dist[i];
            const wait = Math.floor((t + speed - 1) / speed) * speed;
            next[k] = Math.min(next[k], wait);
            next[k + 1] = Math.min(next[k + 1], t);
        }
        dp = next;
    }
    for (let k = 0; k < n; k++) {
        if (dp[k] + dist[n - 1] <= limit) return k;
    }
    return -1;
};

from typing import List

class Solution:
    def minSkips(self, dist: List[int], speed: int, hoursBefore: int) -> int:
        n = len(dist)
        limit = speed * hoursBefore
        if sum(dist) > limit:
            return -1
        dp = [float("inf")] * n
        dp[0] = 0
        for i in range(n - 1):
            nxt = [float("inf")] * n
            for k in range(i + 1):
                if dp[k] == float("inf"):
                    continue
                t = dp[k] + dist[i]
                wait = (t + speed - 1) // speed * speed
                nxt[k] = min(nxt[k], wait)
                nxt[k + 1] = min(nxt[k + 1], t)
            dp = nxt
        for k in range(n):
            if dp[k] + dist[-1] <= limit:
                return k
        return -1

C++

#include <vector>
#include <algorithm>
#include <numeric>
#include <limits>
using namespace std;

class Solution {
public:
    int minSkips(vector<int>& dist, int speed, int hoursBefore) {
        int n = dist.size();
        long long limit = 1LL * speed * hoursBefore;
        if (accumulate(dist.begin(), dist.end(), 0LL) > limit) return -1;
        const long long INF = numeric_limits<long long>::max() / 4;
        vector<long long> dp(n, INF);
        dp[0] = 0;
        for (int i = 0; i < n - 1; ++i) {
            vector<long long> next(n, INF);
            for (int k = 0; k <= i; ++k) {
                if (dp[k] == INF) continue;
                long long t = dp[k] + dist[i];
                long long wait = (t + speed - 1) / speed * speed;
                next[k] = min(next[k], wait);
                next[k + 1] = min(next[k + 1], t);
            }
            dp.swap(next);
        }
        for (int k = 0; k < n; ++k)
            if (dp[k] + dist.back() <= limit) return k;
        return -1;
    }
};
