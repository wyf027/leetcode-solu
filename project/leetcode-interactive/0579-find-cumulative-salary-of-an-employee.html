Find cumulative salary of an employee

查询员工的累计薪水

把每条工资记录放回真实月份轴，用一扇三个月宽的窗口观察累计值；最新月份只负责划定边界，不进入最终结果。

输入：Employee 表 输出：id / month / Salary 排序：id ↑，month ↓

01 · Problem

先把“最近三个月”说准确

给定员工按月份记录的薪水，计算每个在职月份与它之前两个自然月的薪水总和。缺失月份按 0 计；每位员工最新的工资月份不输出。

Input table

Employee

列名类型含义
idINT员工编号
monthINT2020 年月份
salaryINT当月薪水

(id, month) 是联合主键，因此同一员工同一月份最多一条记录。

Query contract

输入一张表，返回一张统一汇总表

  • 1只对员工实际出现过的月份生成结果行。
  • 2对结果月份 m，累加 m-2、m-1、m 三个自然月；缺失记录贡献 0。
  • 3排除每位员工的最大月份，再按 id ASC, month DESC 输出。
关键语义：这是按月份“值域”取窗口，不是简单取当前行及前两行。月份 4 后直接跳到月份 7 时，月份 7 不能把月份 4 的薪水带进来。

04 · Solution

准备好后，再展开完整题解

题解默认收起，避免首屏直接泄露实现。展开后包含 SQL 主解、证明、复杂度、多语言本地参考与面试追问。

Core insight

窗口必须按 month 的值域，而不是按相邻行

对员工和月份 m，目标集合严格是月份落在 [m-2, m] 的记录。SQL 窗口中的 RANGE BETWEEN 2 PRECEDING AND CURRENT ROW 恰好表达这个值域关系；ROWS 2 PRECEDING 在月份断档时会错误地拿到更早的两条记录。

同时先为每位员工标记 MAX(month)，累计计算完成后再过滤最新月，职责清楚且不会破坏窗口定义。

Complete process

  1. 按 id 分组，用窗口函数求出每位员工的最大月份。
  2. 仍按 id 分区、month 升序，用 2 个月的值域窗口计算三个月和。
  3. 只保留 month < max_month 的行，排除最新工资月份。
  4. 按题目要求执行 id ASC, month DESC 排序。

Correctness

正确性说明

引理 1：每个窗口只包含目标三个自然月

固定员工与结果月份 m。按 month 排序的 RANGE 2 PRECEDING 仅选择月份值满足 m-2 ≤ month ≤ m 的行；联合主键保证每月最多一条，因此其和正是当前月与前两个月薪水之和，缺月自然没有记录、等价于贡献 0。

引理 2：最终行集合恰好排除每位员工最新月份

max_month 是该员工所有记录中的最大月份。过滤条件 month < max_month 删除且只删除最大月份行；其余实际工作月份全部保留，缺失月份从未产生源行。

结论

由引理 1，每个保留行的累计薪水正确；由引理 2，输出行集合正确；最后的排序子句满足指定顺序，因此查询返回题目要求的完整结果。

Boundaries

边界情况

只有一个月份它也是最新月份，员工不会出现在输出中。
月份不连续缺月贡献 0；一定不能用“前两行”代替“前两个月”。
多个员工所有窗口与最大月份都必须按 id 分区，不能相互串联。

Complexity

复杂度

时间：通常 O(n log n)，主要来自按员工与月份排序空间：O(n)，用于窗口执行与中间结果

数据库执行器可能利用 (id, month) 主键顺序降低排序成本；具体计划取决于数据库版本、统计信息与物理索引。

可提交语言：MySQL 8.0值域窗口 + 最大月份标记
WITH marked AS (
    SELECT
        id,
        month,
        salary,
        MAX(month) OVER (PARTITION BY id) AS max_month
    FROM Employee
),
summed AS (
    SELECT
        id,
        month,
        SUM(salary) OVER (
            PARTITION BY id
            ORDER BY month
            RANGE BETWEEN 2 PRECEDING AND CURRENT ROW
        ) AS Salary,
        max_month
    FROM marked
)
SELECT id, month, Salary
FROM summed
WHERE month < max_month
ORDER BY id ASC, month DESC;

import java.util.*;

public class Main {
    static final class Row {
        final int id, month, salary;
        Row(int id, int month, int salary) {
            this.id = id;
            this.month = month;
            this.salary = salary;
        }
    }

    static final class Result {
        final int id, month, salary;
        Result(int id, int month, int salary) {
            this.id = id;
            this.month = month;
            this.salary = salary;
        }
        @Override public String toString() {
            return "(" + id + "," + month + "," + salary + ")";
        }
    }

    static List<Result> cumulativeSalary(List<Row> employee) {
        Map<Integer, List<Row>> groups = new TreeMap<>();
        for (Row row : employee) {
            groups.computeIfAbsent(row.id, key -> new ArrayList<>()).add(row);
        }

        List<Result> answer = new ArrayList<>();
        for (Map.Entry<Integer, List<Row>> entry : groups.entrySet()) {
            List<Row> rows = entry.getValue();
            rows.sort(Comparator.comparingInt(row -> row.month));
            int latest = rows.get(rows.size() - 1).month;
            Map<Integer, Integer> salaryByMonth = new HashMap<>();
            for (Row row : rows) salaryByMonth.put(row.month, row.salary);

            for (Row row : rows) {
                if (row.month == latest) continue;
                int sum = 0;
                for (int month = row.month - 2; month <= row.month; month++) {
                    sum += salaryByMonth.getOrDefault(month, 0);
                }
                answer.add(new Result(row.id, row.month, sum));
            }
        }

        answer.sort(Comparator
            .comparingInt((Result row) -> row.id)
            .thenComparing((a, b) -> Integer.compare(b.month, a.month)));
        return answer;
    }

    public static void main(String[] args) {
        List<Row> rows = Arrays.asList(
            new Row(1, 1, 20), new Row(2, 1, 20),
            new Row(1, 2, 30), new Row(2, 2, 30),
            new Row(3, 2, 40), new Row(1, 3, 40),
            new Row(3, 3, 60), new Row(1, 4, 60),
            new Row(3, 4, 70), new Row(1, 7, 90),
            new Row(1, 8, 90)
        );
        cumulativeSalary(rows).forEach(System.out::println);
    }
}

function cumulativeSalary(employee) {
  const groups = new Map();
  for (const row of employee) {
    if (!groups.has(row.id)) groups.set(row.id, []);
    groups.get(row.id).push(row);
  }

  const answer = [];
  for (const [id, rows] of groups) {
    rows.sort((a, b) => a.month - b.month);
    const latest = rows.at(-1).month;
    const salaryByMonth = new Map(
      rows.map(({ month, salary }) => [month, salary]),
    );

    for (const row of rows) {
      if (row.month === latest) continue;
      let sum = 0;
      for (let month = row.month - 2; month <= row.month; month += 1) {
        sum += salaryByMonth.get(month) ?? 0;
      }
      answer.push({ id, month: row.month, Salary: sum });
    }
  }

  return answer.sort((a, b) => a.id - b.id || b.month - a.month);
}

from collections import defaultdict
from dataclasses import dataclass


@dataclass(frozen=True)
class Row:
    id: int
    month: int
    salary: int


def cumulative_salary(employee: list[Row]) -> list[tuple[int, int, int]]:
    groups: dict[int, list[Row]] = defaultdict(list)
    for row in employee:
        groups[row.id].append(row)

    answer: list[tuple[int, int, int]] = []
    for employee_id, rows in groups.items():
        rows.sort(key=lambda row: row.month)
        latest = rows[-1].month
        salary_by_month = {row.month: row.salary for row in rows}

        for row in rows:
            if row.month == latest:
                continue
            total = sum(
                salary_by_month.get(month, 0)
                for month in range(row.month - 2, row.month + 1)
            )
            answer.append((employee_id, row.month, total))

    return sorted(answer, key=lambda row: (row[0], -row[1]))

#include <algorithm>
#include <iostream>
#include <map>
#include <tuple>
#include <vector>

using namespace std;

struct Row {
    int id;
    int month;
    int salary;
};

vector<tuple<int, int, int>> cumulativeSalary(const vector<Row>& employee) {
    map<int, vector<Row>> groups;
    for (const Row& row : employee) groups[row.id].push_back(row);

    vector<tuple<int, int, int>> answer;
    for (auto& [id, rows] : groups) {
        sort(rows.begin(), rows.end(), [](const Row& a, const Row& b) {
            return a.month < b.month;
        });

        const int latest = rows.back().month;
        map<int, int> salaryByMonth;
        for (const Row& row : rows) salaryByMonth[row.month] = row.salary;

        for (const Row& row : rows) {
            if (row.month == latest) continue;
            int sum = 0;
            for (int month = row.month - 2; month <= row.month; ++month) {
                auto it = salaryByMonth.find(month);
                if (it != salaryByMonth.end()) sum += it->second;
            }
            answer.emplace_back(id, row.month, sum);
        }
    }

    sort(answer.begin(), answer.end(), [](const auto& a, const auto& b) {
        if (get<0>(a) != get<0>(b)) return get<0>(a) < get<0>(b);
        return get<1>(a) > get<1>(b);
    });
    return answer;
}

int main() {
    vector<Row> employee = {
        {1,1,20}, {2,1,20}, {1,2,30}, {2,2,30},
        {3,2,40}, {1,3,40}, {3,3,60}, {1,4,60},
        {3,4,70}, {1,7,90}, {1,8,90}
    };

    for (const auto& [id, month, salary] : cumulativeSalary(employee)) {
        cout << id << ' ' << month << ' ' << salary << '\n';
    }
    return 0;
}

Alternative

自连接方案

旧版 MySQL 可让目标行 e1 连接同员工且月份位于 e1.month - 2 到 e1.month 的 e2，再分组求和；另连接每位员工的最大月份用于排除。优点是兼容无窗口函数的版本，缺点是连接产生的中间行更多、表达也更绕。

Common mistakes

常见错误

  • 写成 ROWS 2 PRECEDING，把“前两行”误当成“前两个月”。
  • 忘记按 id 分区，导致不同员工的薪水混入同一窗口。
  • 排除整张表的全局最大月份，而不是每位员工各自的最大月份。
  • 错误地为缺失月份补输出行；题目只要求员工实际工作过的月份。
  • 漏掉最终的月份降序，得到数值正确但顺序错误的结果。

Interview follow-ups

面试追问

  • 若窗口改为最近 12 个自然月？ 将值域边界改为 11 PRECEDING；其余结构不变。
  • 若要求输出缺失月份？ 先用日历表生成月份骨架，再左连接薪水并用 0 填充；此时输出行集合已改变。
  • 若同月可能多条工资？ 先按员工和月份预聚合，否则窗口会包含重复月份行并影响语义。
  • 怎样看执行计划？ 关注是否能利用 (id, month) 顺序、窗口排序成本以及 CTE 是否物化。
