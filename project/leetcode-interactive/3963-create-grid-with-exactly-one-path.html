构造恰好一条路径的网格

给定 m 行和 n 列，只能使用 .（可走）与 #（障碍）构造网格。从左上走到右下时只允许向右或向下，并且路径数量必须恰好为 1。

第一行全设为 .，最后一列全设为 .，其余格设为 #。路径被固定为：先一直向右，再一直向下。

题意与完整过程

输出任意一个合法 m × n 字符网格。把第 0 行全部开放，且把最后一列全部开放；其他位置封住。于是从 (0, 0) 出发，任何向下走都会撞到障碍（除非已经来到最后一列），所以只能先横向走到最右，再竖向走到底。

核心洞察

不必搜索或动态规划地“找”路径。直接消除所有分叉：首行只能向右，末列只能向下，因此每一步选择都唯一。

边界

m = 1 时整行都是唯一通路；n = 1 时整列都是唯一通路；m = n = 1 只有起终点这一个可走格。

复杂度

必须输出 m × n 个字符，所以时间与空间均为 O(mn)，这是输出规模的下界。

替代方案、追问与常见错误

也可以反过来开放首列和末行。追问“恰好 K 条路径”时通常需要组合构造或 DP。常见错误是开放整个边框：它会形成两条不同路线；或忘记在单行/单列时保持所有格可走。

题解：封住分叉，留下折线

对每个位置 (i, j)，若 i == 0 或 j == n - 1，写入 .；否则写入 #。这条“上边 + 右边”折线包含起点与终点，且不存在其他可进入的可走单元。
