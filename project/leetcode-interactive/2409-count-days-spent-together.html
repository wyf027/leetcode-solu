2409 · 统计共同度过的日子数

Count Days Spent Together · 把两段罗马行程放在同一张日历上。

官方题目 · 数学 / 字符串

01 / 题目

Alice 和 Bob 分别前往罗马。给定四个日期字符串 arriveAlice、leaveAlice、arriveBob、leaveBob，表示两人的到达日与离开日。到达和离开的当天都算在行程内。返回两人同时留在罗马的天数。

  • 日期都在同一个非闰年，格式严格为五字符 MM-DD。
  • 每个人的到达日期早于或等于自己的离开日期。
  • 所有日期均有效；不涉及跨年。非闰年各月天数为 [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]。

官方示例 1

arriveAlice = "08-15", leaveAlice = "08-18",
arriveBob = "08-16", leaveBob = "08-19"
输出：3

两人在 8 月 16、17、18 日同时在罗马，共 3 天。

官方示例 2

arriveAlice = "10-01", leaveAlice = "10-31",
arriveBob = "11-01", leaveBob = "12-31"
输出：0

两段行程没有共同日期。

04 / 独立题解

核心洞察：日期转换 + 闭区间求交

把日期转换为一年中的第几天，便能把日历问题化为整数区间问题。日序从 1 开始：day(MM-DD) = 前 MM−1 个月的天数之和 + DD。不需要年份、时区或日期库。

完整过程

  1. 解析四个日期。月份从 1 开始，而月份天数数组从下标 0 开始，仅累加当前月之前的月份。
  2. 得到 Alice 区间 [a₁, a₂] 与 Bob 区间 [b₁, b₂]。
  3. 共同起点 L = max(a₁, b₁)，共同终点 R = min(a₂, b₂)。
  4. 若 L > R，返回 0；否则返回 R − L + 1。合并为 max(0, R − L + 1)。

示例 1 中，8 月前有 212 天，四个日期依次成为 227、230、228、231。共同区间是 [228, 230]，所以有 230 − 228 + 1 = 3 天。

正确性

日序转换按真实月份长度累加，保持日期顺序，且相邻日期的日序相差 1。某日 d 同时属于两段行程，当且仅当 d ≥ a₁、d ≥ b₁、d ≤ a₂、d ≤ b₂，也就是 L ≤ d ≤ R。因此交集恰是 [L, R]；L > R 时为空，否则闭区间包含 R − L + 1 个整数，公式准确计算了所有共同日期。

边界与复杂度

  • 端点相同也算一天；两人分别在相邻两天离开、到达时算零天。
  • 完全包含、同日往返、二月到三月、全年行程均沿用相同公式。
  • 题目保证非闰年，因此二月固定 28 天；不接受 02-29，也不处理跨年行程。
  • 每个日期最多累加 11 个月，四次转换。固定 12 个月时，时间 O(1)，额外空间 O(1)；若推广到 M 个月，则当前写法时间 O(M)。

Java

class Solution {
    private int day(String date) {
        int[] days = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        int month = Integer.parseInt(date.substring(0, 2));
        int result = Integer.parseInt(date.substring(3, 5));
        for (int i = 0; i < month - 1; i++) result += days[i];
        return result;
    }

    public int countDaysTogether(String arriveAlice, String leaveAlice,
                                 String arriveBob, String leaveBob) {
        int left = Math.max(day(arriveAlice), day(arriveBob));
        int right = Math.min(day(leaveAlice), day(leaveBob));
        return Math.max(0, right - left + 1);
    }
}

    const right = Math.min(day(leaveAlice), day(leaveBob));
    return Math.max(0, right - left + 1);
};

替代方案

枚举一年中的 365 天，对每一天判断是否同时落在两个人的区间里。它更直观，推广到 D 天时需要 O(D) 时间，而区间求交无需逐日遍历。若要反复转换大量日期，可预存 12 个月的前缀和。

面试追问

  • 允许闰年怎么办？根据年份确定二月是 28 天还是 29 天。
  • 允许跨年怎么办？把带年份的日期映射为统一基准日以来的整数天数，再求交。
  • 有 n 人且每人一段行程？取所有到达日的最大值、离开日的最小值。
  • 每人有多段行程？先排序并合并各自重叠区间，再用双指针求两组区间的交集。

常见错误

  • 忘记 +1，导致同一天共同停留被算为 0。
  • 没有与 0 取最大值，使无交集得到负数。
  • 把月份差乘 30，或把 MMDD 数值相减；月份长度并不一致。
  • 把本月天数也加进日序，产生一个月的偏移。
  • 误把最早到达与最晚离开作为共同边界，算成了覆盖范围。
