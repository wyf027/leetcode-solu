防抖

把连续的“现在执行”收束成一次“稍后执行”。这一题考的不是复杂算法，而是对计时器生命周期的精确控制。

01 / PROBLEM

题目要求

函数 · 闭包 · 计时器

给定函数 fn 和毫秒数 t，返回它的防抖版本。每次调用返回函数时，应把这次执行推迟 t 毫秒；如果等待窗口内又发生调用，取消旧执行，并从新调用时刻重新计时。

真正执行时，应把最近一次调用收到的参数传给 fn。不得使用 lodash 的 _.debounce()。

提交签名（JavaScript）
var debounce = function(fn, t) { ... }

约束

  • 0 ≤ t ≤ 1000
  • 1 ≤ calls.length ≤ 10
  • 0 ≤ calls[i].t ≤ 1000
  • 0 ≤ calls[i].inputs.length ≤ 10

计时结果按题目描述的逻辑时刻表达；现实运行环境中的计时器可能有轻微调度误差。

05 / SOLUTION

题解：只保留一个闹钟

题解已展开

核心洞察：闭包里只需要保存一个计时器句柄。每次调用先取消旧计时器，再为最新参数设置一个新计时器。

完整过程

  1. 保存状态
    在返回函数外、debounce 调用内声明计时器句柄，让所有后续调用共享它。
  2. 取消旧任务
    每次收到调用时，对旧句柄执行取消操作；句柄为空或任务已完成也不影响逻辑。
  3. 安排新任务
    创建新的延时任务，在 t 毫秒后以最近一次的参数和调用上下文执行 fn。

正确性说明

不变量：任意一次返回函数调用结束后，至多存在一个仍有效的计时任务，而且它保存的是最近一次调用的参数。

结论：若 t 毫秒内有新调用，旧任务必先被取消；若没有新调用，唯一有效任务到期并执行。因此恰好满足防抖定义。

复杂度

每次调用的计时器操作为 O(1)；除最新参数外，额外状态为 O(1)。若计入参数副本，则空间为 O(k)。

边界情况

  • t = 0 仍是异步调度，不是同步执行。
  • 连续多次调用只保留最后一次参数。
  • JavaScript 实现应保留调用时的 this。
  • 执行完成后的计时器句柄无需参与下一轮判断。

替代方案

可用递增版本号让旧回调到期后自行失效，但旧计时器仍会被调度。直接取消旧计时器更省工作，也更贴合题意。

面试追问

  • 如何增加立即执行的 leading 模式？
  • 如何提供 cancel 与 flush？
  • 防抖与节流在触发语义上有何区别？

常见错误

  • 把计时器变量声明在返回函数内部，导致调用之间无法共享。
  • 忘记取消旧计时器，最终每次调用都执行。
  • 没有转交参数，或用箭头返回函数丢失动态 this。

JavaScript官方可提交
/**
 * @param {Function} fn
 * @param {number} t milliseconds
 * @return {Function}
 */
var debounce = function(fn, t) {
    let timer;

    return function(...args) {
        clearTimeout(timer);
        timer = setTimeout(() => fn.apply(this, args), t);
    };
};
Java本地语义参考
import java.util.Arrays;
import java.util.concurrent.Executors;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.ScheduledFuture;
import java.util.concurrent.TimeUnit;
import java.util.function.Consumer;

public final class Debouncer implements AutoCloseable {
    private final ScheduledExecutorService scheduler =
        Executors.newSingleThreadScheduledExecutor();
    private final Consumer<int[]> fn;
    private final long delayMs;
    private ScheduledFuture<?> pending;

    public Debouncer(Consumer<int[]> fn, long delayMs) {
        this.fn = fn;
        this.delayMs = delayMs;
    }

    public synchronized void call(int... args) {
        if (pending != null) pending.cancel(false);
        int[] latest = Arrays.copyOf(args, args.length);
        pending = scheduler.schedule(
            () -> fn.accept(latest), delayMs, TimeUnit.MILLISECONDS
        );
    }

    @Override
    public synchronized void close() {
        if (pending != null) pending.cancel(false);
        scheduler.shutdownNow();
    }
}
Python本地语义参考
from threading import Lock, Timer
from typing import Callable, Optional


class Debouncer:
    def __init__(self, fn: Callable[..., None], delay_ms: int):
        self.fn = fn
        self.delay = delay_ms / 1000
        self.timer: Optional[Timer] = None
        self.lock = Lock()

    def __call__(self, *args, **kwargs) -> None:
        with self.lock:
            if self.timer is not None:
                self.timer.cancel()
            self.timer = Timer(
                self.delay, self.fn, args=args, kwargs=kwargs
            )
            self.timer.daemon = True
            self.timer.start()

    def cancel(self) -> None:
        with self.lock:
            if self.timer is not None:
                self.timer.cancel()
                self.timer = None
C++17本地语义参考
#include <chrono>
#include <condition_variable>
#include <functional>
#include <mutex>
#include <thread>
#include <utility>
#include <vector>

class Debouncer {
    using Clock = std::chrono::steady_clock;
    using Millis = std::chrono::milliseconds;

    std::function<void(const std::vector<int>&)> fn_;
    Millis delay_;
    std::mutex mutex_;
    std::condition_variable cv_;
    std::thread worker_;
    std::vector<int> args_;
    Clock::time_point deadline_;
    unsigned long version_ = 0;
    bool pending_ = false;
    bool stopped_ = false;

    void run() {
        std::unique_lock<std::mutex> lock(mutex_);
        while (!stopped_) {
            cv_.wait(lock, [this] { return pending_ || stopped_; });
            if (stopped_) break;

            const auto version = version_;
            const auto deadline = deadline_;
            if (cv_.wait_until(lock, deadline, [this, version] {
                    return stopped_ || version_ != version;
                })) {
                continue;
            }

            auto latest = args_;
            pending_ = false;
            lock.unlock();
            fn_(latest);
            lock.lock();
        }
    }

public:
    Debouncer(std::function<void(const std::vector<int>&)> fn,
              int delayMs)
        : fn_(std::move(fn)), delay_(delayMs),
          worker_([this] { run(); }) {}

    void call(std::vector<int> args) {
        {
            std::lock_guard<std::mutex> lock(mutex_);
            args_ = std::move(args);
            deadline_ = Clock::now() + delay_;
            ++version_;
            pending_ = true;
        }
        cv_.notify_one();
    }

    ~Debouncer() {
        {
            std::lock_guard<std::mutex> lock(mutex_);
            stopped_ = true;
        }
        cv_.notify_one();
        if (worker_.joinable()) worker_.join();
    }
};
