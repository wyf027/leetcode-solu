将所有数字用字符替换

Replace All Digits with Characters

一个字母，一个数字：观察字符如何沿字母表移动。先读题并自己推演，再展开底部题解。

题目说明

输入字符串 s，下标从 0 开始。偶数下标存放小写英文字母，奇数下标存放一位数字。对每个奇数下标 i，把该数字替换为它前面的字母在字母表中向后移动该数字步之后的字符，返回替换后的字符串。

操作记为 shift(c, x)：例如 shift('a', 5) = 'f'，shift('x', 0) = 'x'。这个操作需要自行实现，并非内置函数。题目保证移动不会越过 'z'。

约束

  • 1 ≤ s.length ≤ 100。
  • 只包含小写英文字母和数字，且满足上述奇偶位置规则。
  • 所有奇数下标 i 均满足 shift(s[i-1], s[i]) ≤ 'z'。

官方示例 1

输入：s = "a1c1e1"
输出："abcdef"

下标 1、3、5：a 向后 1 步得到 b；c 向后 1 步得到 d；e 向后 1 步得到 f。

官方示例 2

输入：s = "a1b2c3d4e"
输出："abbdcfdhe"

下标 1、3、5、7：a+1→b，b+2→d，c+3→f，d+4→h；末尾的 e 保持原样。

题解 · 只处理奇数下标

核心洞察

每个数字只依赖左侧的偶数下标字母；这些字母始终不变。因此各个字符对互不影响，可以直接逐对替换。小写英文字母的字符编码连续，目标字符的编码就是前一个字母的编码加数字值。

完整过程

  1. 把字符串转换为可修改的字符数组（C++ 可直接修改 string）。
  2. 从 i = 1 开始，每次增加 2；将数字字符转成数值。
  3. 计算 字符编码(s[i-1]) + 数值(s[i])，转回字母并写入位置 i。
  4. 遍历结束后返回字符串。例如 a1b2：先把 1 替换成 b，得到 abb2，再把 2 替换成 d，得到 abbd。

正确性

循环不变式：处理下标 i 之前，所有更小的奇数下标均已正确替换，所有偶数下标保持原值。初始时没有待证明的已处理数字。每轮读取未变化的前置字母和当前原始数字，按定义生成正确字符，只改当前位置，因此不变式继续成立。循环结束时所有奇数下标已处理，偶数位置未变，故返回结果满足题意。

边界与复杂度

长度为 1 时循环不执行；位移 0 返回原字母；奇数长度的末尾字母不修改；抵达 z 合法且无需回绕。时间复杂度 O(n)。Java、JavaScript、Python 的字符数组占 O(n) 额外空间；C++ 在参数字符串内修改，循环辅助空间 O(1)，按值参数的复制及返回字符串仍可能占 O(n)。

四种语言

Java

class Solution {
    public String replaceDigits(String s) {
        char[] chars = s.toCharArray();
        for (int i = 1; i < chars.length; i += 2) {
            chars[i] = (char) (chars[i - 1] + (chars[i] - '0'));
        }
        return new String(chars);
    }
}

JavaScript

/**
 * @param {string} s
 * @return {string}
 */
var replaceDigits = function(s) {
    const chars = s.split('');
    for (let i = 1; i < chars.length; i += 2) {
        chars[i] = String.fromCharCode(
            chars[i - 1].charCodeAt(0) + Number(chars[i])
        );
    }
    return chars.join('');
};

Python 3

class Solution:
    def replaceDigits(self, s: str) -> str:
        chars = list(s)
        for i in range(1, len(chars), 2):
            chars[i] = chr(ord(chars[i - 1]) + int(chars[i]))
        return ''.join(chars)

C++

#include <string>
using namespace std;

class Solution {
public:
    string replaceDigits(string s) {
        for (int i = 1; i < static_cast<int>(s.size()); i += 2) {
            s[i] = static_cast<char>(s[i - 1] + (s[i] - '0'));
        }
        return s;
    }
};

替代方案

可按全部下标扫描：字母直接追加，数字转换后追加到结果缓冲区，同样 O(n) 时间和 O(n) 空间。也可查找字母表索引再移动，但本题编码计算更直接。避免在循环中反复拼接不可变字符串，以免产生大量复制。

常见错误

  • 把数字字符的编码直接相加：必须先减 '0' 或转成整数。
  • 把题目下标当成从 1 开始，错误修改偶数下标。
  • 跨字符对累加位移：每次都依赖紧邻的前一个原始字母。
  • 对结果取模 26：本题保证不越过 z，无需循环字母表。
  • 直接写 JavaScript 或 Python 字符串下标：应使用数组或列表。

面试追问

数字变成多位数怎么办？需要先解析连续数字，不能再每次跳 2。允许越过 z 呢？先明确是否报错或循环；若循环，以 a 为基准对 26 取模。可以流式处理吗？可以，只需保存前一个字母并逐项输出，输出之外的状态是 O(1)。
