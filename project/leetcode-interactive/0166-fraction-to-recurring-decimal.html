Core insight

相同余数之后，未来的数字序列必然相同

长除法的下一位只由当前余数决定：scaled = remainder × 10，数字是 scaled / divisor，新余数是 scaled % divisor。

用哈希表记录每个余数第一次对应的输出位置。余数变成 0 说明有限小数；某个余数再次出现，则从它的首次位置起就是循环节，在那里插入左括号并于末尾补右括号。

完整过程

  1. 01 / SIGN

    分子为 0 直接返回 "0"；否则先判断异号，再转为正的宽整数。

  2. 02 / INTEGER

    写出整数部分。余数为 0 时已经整除，立即返回。

  3. 03 / DIVIDE

    记录余数位置，余数乘 10，写下一位并更新余数。

  4. 04 / LOOP

    余数重复时，在其首次位置前插入 “(”，末尾追加 “)”。

边界与语言差异

  • 分子为 0 时先返回，避免输出负零。
  • 整除时不添加小数点；循环只包最短重复段。
  • Java/C++ 必须先扩为 64 位再取绝对值；abs(INT_MIN) 在 32 位会溢出。
  • JavaScript 的中间量不超过约 2.15×10¹⁰，仍处于 Number 安全整数范围；Python 整数无界。

复杂度与替代方案

若输出小数位数为 L，则时间 O(L)，哈希表和字符串占用 O(L)；官方保证最终字符串长度小于 10⁴。

把余数存在线性数组并每次搜索可省去哈希概念，但最坏会退化为 O(L²)。Floyd 判环能用常量额外状态找循环长度，却需要额外遍历才能定位并生成字符串。BigDecimal/浮点格式化会舍入，不能保证精确循环节。

常见错误

  • 记录数字而不是余数，无法唯一确定后续状态。
  • 在产出数字后才记录余数位置，导致左括号偏移一位。
  • 负号由商是否为负判断，碰到绝对值小于 1 时丢失负号。
  • 用浮点数转字符串，产生精度丢失或截断。

面试追问

为什么最多只有 divisor−1 种非零余数？

取模后的余数只可能落在 1…divisor−1。若一直不为 0，鸽巢原理保证某个余数终会重复。

如何判断一定是有限小数？

约分后分母的质因子只有 2 和 5 时有限；但构造精确字符串仍可直接运行同一长除法。

为什么哈希值要存输出位置？

重复余数不仅告诉我们存在环，还需要它首次对应的字符下标来放置左括号。

若题目允许任意精度整数呢？

算法不变，只需将除法、取模和哈希键换成大整数类型；JavaScript 可用 BigInt。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public String fractionToDecimal(int numerator, int denominator) {
        if (numerator == 0) return "0";

        StringBuilder result = new StringBuilder();
        if ((numerator < 0) ^ (denominator < 0)) result.append('-');

        long dividend = Math.abs((long) numerator);
        long divisor = Math.abs((long) denominator);
        result.append(dividend / divisor);
        long remainder = dividend % divisor;
        if (remainder == 0) return result.toString();

        result.append('.');
        Map<Long, Integer> firstPosition = new HashMap<>();
        while (remainder != 0) {
            if (firstPosition.containsKey(remainder)) {
                int position = firstPosition.get(remainder);
                result.insert(position, "(");
                result.append(')');
                break;
            }
            firstPosition.put(remainder, result.length());
            remainder *= 10;
            result.append(remainder / divisor);
            remainder %= divisor;
        }
        return result.toString();
    }
}

var fractionToDecimal = function (numerator, denominator) {
    if (numerator === 0) return "0";

    const negative = (numerator < 0) !== (denominator < 0);
    const dividend = Math.abs(numerator);
    const divisor = Math.abs(denominator);
    const integerPart = Math.floor(dividend / divisor);
    let result = `${negative ? "-" : ""}${integerPart}`;
    let remainder = dividend % divisor;
    if (remainder === 0) return result;

    result += ".";
    const firstPosition = new Map();
    while (remainder !== 0) {
        if (firstPosition.has(remainder)) {
            const position = firstPosition.get(remainder);
            result = `${result.slice(0, position)}(${result.slice(position)})`;
            break;
        }
        firstPosition.set(remainder, result.length);
        remainder *= 10;
        result += Math.floor(remainder / divisor);
        remainder %= divisor;
    }
    return result;
};

#include <unordered_map>
using namespace std;

class Solution {
public:
    string fractionToDecimal(int numerator, int denominator) {
        if (numerator == 0) return "0";

        long long dividend = numerator;
        long long divisor = denominator;
        bool negative = (dividend < 0) != (divisor < 0);
        if (dividend < 0) dividend = -dividend;
        if (divisor < 0) divisor = -divisor;

        string result = negative ? "-" : "";
        result += to_string(dividend / divisor);
        long long remainder = dividend % divisor;
        if (remainder == 0) return result;

        result.push_back('.');
        unordered_map<long long, size_t> firstPosition;
        while (remainder != 0) {
            auto found = firstPosition.find(remainder);
            if (found != firstPosition.end()) {
                result.insert(found->second, "(");
                result.push_back(')');
                break;
            }
            firstPosition[remainder] = result.size();
            remainder *= 10;
            result += to_string(remainder / divisor);
            remainder %= divisor;
        }
        return result;
    }
};
