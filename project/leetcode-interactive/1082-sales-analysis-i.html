1082. 销售分析 I

把每笔销售额归到销售员名下，再找出总销售额最高的销售员。真正需要留意的是：最高值可能并列。

EASY数据库付费题GROUP BY · HAVING

题意

给定商品表 Product 与销售记录表 Sales。请返回总销售额最高的全部销售员编号 seller_id；每条销售记录的销售额已经存放在 Sales.price 中。

输出允许任意顺序。若多个销售员的销售总额相同且都是最大值，必须全部返回。

表结构与约束

Product(product_id INT, product_name VARCHAR(10), unit_price INT)
Sales(seller_id INT, product_id INT, buyer_id INT, sale_date DATE, quantity INT, price INT)
  • product_id 标识商品；销售记录引用商品。
  • seller_id 标识销售员，同一销售员可有多笔记录。
  • price 是该条记录的总销售金额；按题意对它求和。
seller_total = SUM(Sales.price)

题解

核心洞察

题目只关心 Sales 中每位销售员的 price 总和，因此不需要连接 Product。先按 seller_id 聚合，再与“所有分组总额中的最大值”比较。

完整过程

  1. 使用 GROUP BY seller_id 形成每位销售员的一组记录。
  2. 对每组计算 SUM(price)。
  3. 子查询再次执行相同聚合，并取其中的 MAX(total)。
  4. 外层用 HAVING 保留总额等于最大值的所有组。

正确性

分组后，每个销售员恰对应一个组，SUM(price) 等于其全部销售记录金额之和。子查询的 MAX 是这些总额的全局最大值。外层保留且仅保留总额等于该最大值的组，所以结果恰好是全部最高销售员，包括并列者。

边界

  • 只有一位销售员时直接返回该销售员。
  • 多人并列第一时全部返回。
  • 同一销售员只有一笔或多笔记录都适用。

复杂度

设销售记录数为 n、销售员数为 k。逻辑扫描代价约为 O(n)，聚合状态为 O(k)；实际代价由数据库执行计划、索引和聚合实现决定。

替代方案

支持窗口函数的数据库可用 RANK() OVER (ORDER BY SUM(price) DESC)，再筛选排名 1。它更易扩展到“前 N 名”，但本题的最大值子查询更直观。

可提交 SQL

SELECT seller_id
FROM Sales
GROUP BY seller_id
HAVING SUM(price) = (
  SELECT MAX(total_price)
  FROM (
    SELECT SUM(price) AS total_price
    FROM Sales
    GROUP BY seller_id
  ) AS seller_totals
);

import java.util.*;

class Solution {
    public List<Integer> topSellers(int[][] sales) {
        Map<Integer, Long> totals = new HashMap<>();
        for (int[] row : sales)
            totals.merge(row[0], (long) row[5], Long::sum);
        long best = Collections.max(totals.values());
        List<Integer> answer = new ArrayList<>();
        for (var entry : totals.entrySet())
            if (entry.getValue() == best) answer.add(entry.getKey());
        return answer;
    }
}
function topSellers(sales) {
  const totals = new Map();
  for (const row of sales) {
    const sellerId = row[0], price = row[5];
    totals.set(sellerId, (totals.get(sellerId) ?? 0) + price);
  }
  const best = Math.max(...totals.values());
  return [...totals]
    .filter(([, total]) => total === best)
    .map(([sellerId]) => sellerId);
}
from collections import defaultdict

def top_sellers(sales: list[list[int]]) -> list[int]:
    totals = defaultdict(int)
    for row in sales:
        totals[row[0]] += row[5]
    best = max(totals.values())
    return [seller for seller, total in totals.items() if total == best]
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

vector<int> topSellers(const vector<vector<int>>& sales) {
    unordered_map<int, long long> totals;
    for (const auto& row : sales) totals[row[0]] += row[5];
    long long best = 0;
    for (const auto& [seller, total] : totals) best = max(best, total);
    vector<int> answer;
    for (const auto& [seller, total] : totals)
        if (total == best) answer.push_back(seller);
    return answer;
}

常见错误

  • 使用 ORDER BY ... LIMIT 1，漏掉并列第一。
  • 对 quantity 或 unit_price 重算，忽略题目已给出 Sales.price。
  • 无必要地连接 Product，增加复杂度。
  • 把聚合条件写进 WHERE；聚合后筛选应使用 HAVING。
