Find Resultant Array After Removing Anagrams

01 / 读懂规则

题目说明

给定从 0 开始编号的字符串数组 words。每一步选一个满足 0 < i < words.length 的下标；如果当前相邻的 words[i - 1] 与 words[i] 互为字母异位词，就删除右侧的 words[i]。持续操作，直到没有可删除的位置，返回剩余数组。

两个单词互为字母异位词，指每种字母出现的次数完全相同，只允许重新排列。例如 dacb 与 abdc。完全相同的字符串也满足条件。题目保证：选择删除位置的顺序不影响最终结果。

约束

  • 1 <= words.length <= 100
  • 1 <= words[i].length <= 10
  • words[i] 只包含小写英文字母。

官方示例 1

输入：words = ["abba","baba","bbaa","cd","cd"]
输出：["abba","cd"]

可依次删除当前下标 2 的 bbaa、下标 1 的 baba、下标 2 的 cd。得到 ["abba","cd"] 后，无法继续删除。

官方示例 2

输入：words = ["a","b","c","d","e"]
输出：["a","b","c","d","e"]

任意相邻两项都不是字母异位词，因此没有删除操作。

04 / 解法笔记
思考之后，再展开






核心洞察：每段相同指纹只留第一个


将一个单词的字符排序，得到它的“指纹”。两个词的指纹相等，当且仅当它们互为字母异位词。原数组的指纹可分成若干连续段；每段保留第一个原始单词即可，不能对整个数组做全局去重。


完整过程
  1. 创建空结果数组，令上一个保留词的指纹为空。
  2. 从左向右读取当前词，排序字符得到新指纹。
  3. 若新指纹与上一个保留词相同，跳过当前词；否则追加原始词，并更新指纹。
  4. 遍历结束后返回结果数组，保持词的原始拼写和顺序。


词        指纹    操作     已保留
abba      aabb    保留     [abba]
baba      aabb    跳过     [abba]
bbaa      aabb    跳过     [abba]
cd        cd      保留     [abba, cd]
cd        cd      跳过     [abba, cd]


正确性
循环不变式：处理完前 k 项后，结果恰好是该前缀每个连续指纹段的第一个词，记录的指纹属于最后一段。初始前缀为空，不变式成立。当前指纹相同，则它属于最后一段，跳过它相当于执行合法删除；指纹不同，则开始新段，必须保留。两种情况均保持不变式。
不同段的边界无法跨越：一段的第一个词不能通过同段的后续词被删除，不同段的首词也不互为异位词。因此各段至少留一个，段内除首词外都可删除。遍历结束时每段恰留首词且相邻结果不互为异位词，满足终止条件，也说明任意合法删除顺序的结果相同。


边界与常见错误
  • 只有一个词时直接保留；全是异位词时只保留第一个。
  • 相同字符串也互为异位词，不能只检查“拼写不同”。
  • 不能使用全局 Set 去重：["ab","cd","ba"] 三项都要保留。
  • 不能只比较字母集合：aab 与 abb 的字母次数不同。
  • 指纹只用于判断；向结果追加原始词，而不是排序后的词。
  • 直接删除数组时易因下标移动漏项；收集保留词可避免该问题。


复杂度
设 n 为单词数，m 为最大词长。排序指纹的时间为 O(n · m log(m + 1))，通常写作 O(nm log m)；每次排序和保存指纹需要 O(m) 辅助空间。返回数组还需 O(n) 个引用；C++ 等复制字符串的实现，返回内容占 O(nm) 空间。此题 m ≤ 10。


替代方案
用 26 个计数记录每个字母的出现次数，并与上一保留词的计数逐项比较。时间 O(n(m + 26))，除返回值外仅 O(26) 辅助空间。排序方案短且直观；计数方案在词更长时更合适。若序列化计数，必须加入分隔符，避免不同计数产生相同文本。


面试追问
  • 能否比较原数组的前一个词？可以，因为连续指纹段内所有词指纹相同；该思路也会保留每段首词。
  • 输入是流而不是数组呢？只需记住上一个保留指纹，就能逐词输出。
  • 如果允许删除异位词对中的任意一项？代表词可能改变，原题“保留每段第一个”的结论不再适用。
  • 如果字符不限于小写字母？可排序，或用字符到次数的映射；同时明确 Unicode 的字符单位。


Java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<String> removeAnagrams(String[] words) {
        List<String> result = new ArrayList<>();
        String previous = "";
        for (String word : words) {
            char[] chars = word.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);
            if (!key.equals(previous)) {
                result.add(word);
                previous = key;
            }
        }
        return result;
    }
}

/**
 * @param {string[]} words
 * @return {string[]}

var removeAnagrams = function(words) {
    const result = [];
    let previous = "";
    for (const word of words) {
        const key = word.split("").sort().join("");
        if (key !== previous) {
            result.push(word);
            previous = key;
        }
    }
    return result;
};


Python 3
from typing import List

class Solution:
    def removeAnagrams(self, words: List[str]) -> List[str]:
        result = []
        previous = ""
        for word in words:
            key = "".join(sorted(word))
            if key != previous:
                result.append(word)
                previous = key
        return result


C++
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> removeAnagrams(vector<string>& words) {
        vector<string> result;
        string previous;
        for (const string& word : words) {
            string key = word;
            sort(key.begin(), key.end());
            if (key != previous) {
                result.push_back(word);
                previous = key;
            }
        }
        return result;
    }
};
