01 / Assignment

题意与样例

根到叶路径必须从根节点开始，并在没有左右孩子的叶子节点结束；中途累加到目标值仍不能提前收录。

输入与输出

输入为二叉树根节点 root 和整数 targetSum。输出全部满足条件的节点值序列；没有有效路径时返回空列表。

可见空格约定：若输入包含字符串空格，将以 ␠ 显示；本题输入不含字符串。

官方样例 1

输入 root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出 [[5,4,11,2],[5,8,4,5]]
说明 两条根到叶路径的节点和均为 22

04 / Developed Answer

题解：DFS + 回溯

面试主线采用递归深搜：一条可复用的路径数组随搜索入栈、出栈；只有在叶子且剩余目标归零时，复制快照进入答案。

核心洞察

DFS 的递归调用栈天然对应“从根走到当前节点”的路线。进入节点时把值加入路径并扣减剩余目标；离开节点前删除末尾值，恢复父节点现场。命中时必须复制路径，否则后续回溯会改坏已保存结果。

完整过程

  1. 空节点直接返回。
  2. 把当前节点值加入 path，得到新的剩余目标。
  3. 若当前节点是叶子且剩余目标为 0，复制路径进答案。
  4. 否则依次搜索左、右子树。
  5. 返回父层之前执行 path.pop()，撤销选择。

边界

  • 空树返回空列表。
  • 单节点树需要同时满足“是叶子”和“值等于目标”。
  • 节点值可以为负，不能用“剩余目标小于 0”提前剪枝。
  • 路径中途等于目标但还不是叶子时，不能收录。
  • 最多 5000 个节点的极深链可能触发语言调用栈限制。

复杂度

时间 O(N + P) 访问每个节点；P 为复制到答案中的元素总数。
辅助空间 O(H) 递归栈与当前路径均不超过树高 H，不计输出。

替代方案取舍

可用显式栈保存“节点、剩余目标、路径副本”，避免递归深度风险，但每次扩展都复制路径，常数与代码量更大。也可用进入/退出事件模拟回溯，空间稳健却不如递归版直观。面试中优先写递归回溯，并主动指出极深树可换显式栈。

面试追问

  • 为什么结果中要加入 new ArrayList(path) 或 path.copy()？
  • 如果只问是否存在路径，怎样降为 O(H) 空间且提前结束？
  • 如果路径不要求从根开始，前缀和方案如何变化？
  • 怎样改写为显式栈以承受 5000 层退化树？

常见错误

  • 只判断累加和，不检查当前节点是否为叶子。
  • 把同一个可变 path 引用直接加入结果。
  • 忘记回溯 pop，导致兄弟分支继承旧节点。
  • 因为剩余值变负而剪枝，漏掉后续负数节点带来的有效路径。
  • 把输出写成节点对象列表，而不是节点值列表。

class Solution {
    private final List<List<Integer>> answer = new ArrayList<>();
    private final List<Integer> path = new ArrayList<>();

    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        dfs(root, targetSum);
        return answer;
    }

    private void dfs(TreeNode node, long remaining) {
        if (node == null) return;

        path.add(node.val);
        long next = remaining - node.val;

        if (node.left == null && node.right == null && next == 0) {
            answer.add(new ArrayList<>(path));
        } else {
            dfs(node.left, next);
            dfs(node.right, next);
        }

        path.remove(path.size() - 1);
    }
}
var pathSum = function (root, targetSum) {
  const answer = [];
  const path = [];

  const dfs = (node, remaining) => {
    if (node === null) return;

    path.push(node.val);
    const next = remaining - node.val;

    if (node.left === null && node.right === null && next === 0) {
      answer.push([...path]);
    } else {
      dfs(node.left, next);
      dfs(node.right, next);
    }

    path.pop();
  };

  dfs(root, targetSum);
  return answer;
};
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> List[List[int]]:
        answer = []
        path = []

        def dfs(node: Optional[TreeNode], remaining: int) -> None:
            if node is None:
                return

            path.append(node.val)
            next_remaining = remaining - node.val

            if node.left is None and node.right is None and next_remaining == 0:
                answer.append(path.copy())
            else:
                dfs(node.left, next_remaining)
                dfs(node.right, next_remaining)

            path.pop()

        dfs(root, targetSum)
        return answer
class Solution {
private:
    vector<vector<int>> answer;
    vector<int> path;

    void dfs(TreeNode* node, long long remaining) {
        if (node == nullptr) return;

        path.push_back(node->val);
        long long next = remaining - node->val;

        if (node->left == nullptr && node->right == nullptr && next == 0) {
            answer.push_back(path);
        } else {
            dfs(node->left, next);
            dfs(node->right, next);
        }

        path.pop_back();
    }

public:
    vector<vector<int>> pathSum(TreeNode* root, int targetSum) {
        dfs(root, targetSum);
        return answer;
    }
};
