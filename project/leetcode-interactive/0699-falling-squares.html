观察规则：区间按半开形式 [left, left + side) 理解。

只有内部存在公共长度才算水平相交；一个区间的右端点恰好等于另一个区间的左端点时， 两个方块只是擦边，不会形成堆叠。

Problem / 题目

题意与输入输出

给定二维整数数组 positions，其中 positions[i] = [leftᵢ, sideLengthᵢ]。第 i 个正方形边长为 sideLengthᵢ，左边缘对齐 x 坐标 leftᵢ。

准确转述

方块按数组顺序逐个从足够高处竖直下落，直到碰到 x 轴，或落在某个已固定方块的顶边上。 方块左右侧面仅接触不算落在其上。每个方块落稳后便不再移动。

返回整数数组 ans； ans[i] 是第 i 个方块落稳后，所有堆叠中的全局最高高度。

示例 1

输入：positions = [[1,2],[2,3],[6,1]]
输出：[2,5,5]
解释：
第 1 块落在 x 轴上，最高高度为 2。
第 2 块与第 1 块水平相交，落在其顶部，最高高度变为 5。
第 3 块独立落在 x 轴上；全局最高高度仍为 5。

示例 2

输入：positions = [[100,100],[200,100]]
输出：[100,100]
解释：
第 1 块落稳后高度为 100。
第 2 块的左边缘 x = 200 恰好接触第 1 块的右边缘，
仅擦边、不堆叠，因此两块高度都为 100。

约束

  • 1 ≤ positions.length ≤ 1000
  • 1 ≤ leftᵢ ≤ 10⁸
  • 1 ≤ sideLengthᵢ ≤ 10⁶

函数形式

fallingSquares(positions) → List<Integer>

positions: integer[][]
return:    list<integer>

容易忽略

  • 输出记录的是每一步的历史全局最高值。
  • 方块落稳后不会横向滑动，也不会再受后续方块影响。
  • 坐标值很大，但方块数量最多只有 1000。

Solution / 题解

坐标压缩 + 懒标记线段树

把巨大的坐标轴收缩成有限的小区间；每次先查询覆盖范围内的最高表面，再把整个范围赋成新顶面高度。

Core insight

真正需要维护的不是方块，而是“地表高度”

第 i 块覆盖半开区间 [left, right)。它的底面高度等于该区间当前表面高度的最大值； 新顶面高度就是 base + side。落稳后，这个覆盖区间的表面被统一改写为新顶面高度。

因此每一步只有两个区间操作：区间最大值查询与区间赋值。

完整过程

  1. 1

    收集每个方块的左端点 left 与右端点 left + side，排序去重。

  2. 2

    相邻坐标之间形成一个原子区间；方块 [l,r) 映射到索引 idx(l)..idx(r)-1。

  3. 3

    在线段树中查询该索引范围的最大高度，记为 base。

  4. 4

    计算 top = base + side，将整个索引范围赋值为 top。

  5. 5

    用 top 更新历史全局最高值并加入答案。

为什么用半开区间

方块覆盖 [l, l+s)。若 A 的右端点等于 B 的左端点，两区间交集为空，正好表达“仅侧边接触不算着陆”。

压缩后维护的是相邻端点之间的线段，而不是孤立坐标点，所以更新范围必须是 idx(l) 到 idx(r)-1。

时间 O(n log n) 排序 + n 次查询与更新
空间 O(n) 压缩坐标与线段树

正确性证明

  1. 引理 1：第 i 块的落脚高度等于其水平覆盖范围内、落下前地表高度的最大值。 因为它竖直下降，第一次接触必然发生在覆盖范围内最高的顶面；若范围内无方块，最大高度为 0，即 x 轴。
  2. 引理 2：第 i 块落稳后，其覆盖范围内的地表高度处处等于 base + side。方块顶边水平且完整覆盖该范围，并遮住原有的更低表面。
  3. 引理 3：坐标压缩不改变任意两个方块的相交关系。所有端点都被保留，相邻端点之间不会出现新的方块边界， 因而每个原子区间上的覆盖关系恒定。
  4. 归纳：初始所有原子区间高度为 0，线段树表示正确。假设前 i−1 步后表示正确， 第 i 步的区间最大值由引理 1 给出正确落脚高度，区间赋值由引理 2 得到正确新地表；由引理 3，压缩表示与原坐标一致。 因此第 i 步后仍正确。
  5. 结论：每步记录的历史最大顶面高度，就是题目要求的当前最高堆叠高度，所以算法返回正确答案。

边界情况

  • 只有一个方块：直接落在 x 轴上。
  • 仅端点接触：半开区间无重叠，不产生堆叠。
  • 完全包含：新方块会落在被覆盖范围内的最高顶面上。
  • 一个方块横跨多个不同高度：以范围最大高度作为整体底面。
  • 重复的左右端点：压缩坐标必须排序去重。
  • 最大可能堆叠高度为 1000 × 10⁶ = 10⁹，32 位有符号整数仍可容纳。

替代方案

  • O(n²) 动态规划：逐个检查所有旧方块是否与当前方块相交，取最大顶面。 在 n ≤ 1000 时足够直观，也可能通过，但无法体现更通用的区间维护能力。
  • 有序映射维护分段常数：按端点拆分区间、查询最大值并合并相邻同高段； 工程实现通常比压缩线段树更易出错。
  • 动态线段树：直接覆盖大坐标域，省去预先压缩；适合在线到达、无法提前看到所有坐标的扩展版本。

面试追问

  • 若方块在线流式到达，不能预先收集端点，怎样改成动态开点线段树？
  • 若支持撤销最近一次掉落，如何使用可持久化线段树保存版本？
  • 若需要返回每一步的完整轮廓，而不只是最高值，应该维护哪些分段信息？
  • 为什么这里需要“区间赋值”懒标记，而不是“区间加法”？

常见错误

  • 把端点相等误判为重叠，导致示例 2 错误堆叠。
  • 压缩坐标点后更新到 idx(r)，多覆盖了右端点之后的原子区间。
  • 把新区间高度设为 旧高度 + side 的逐点加法；正确操作是整段赋成 max + side。
  • 答案记录当前方块顶面，而忘记维护历史全局最高值。
  • 懒标记用 0 表示“无标记”，与合法高度 0 混淆；实现中应使用 −1 或空值。

Implementations

四种语言完整实现

四份代码均采用同一套“端点压缩 + 区间最大值查询 + 区间赋值”结构，函数签名与官方提交形式一致。

Java 
import java.util.*;

class Solution {
    private int[] tree;
    private int[] lazy;

    public List<Integer> fallingSquares(int[][] positions) {
        int n = positions.length;
        int[] coords = new int[n * 2];
        for (int i = 0; i < n; i++) {
            coords[i * 2] = positions[i][0];
            coords[i * 2 + 1] = positions[i][0] + positions[i][1];
        }
        Arrays.sort(coords);

        int unique = 0;
        for (int x : coords) {
            if (unique == 0 || coords[unique - 1] != x) {
                coords[unique++] = x;
            }
        }

        int intervals = Math.max(1, unique - 1);
        tree = new int[intervals * 4];
        lazy = new int[intervals * 4];
        Arrays.fill(lazy, -1);

        List<Integer> answer = new ArrayList<>();
        int globalMax = 0;

        for (int[] square : positions) {
            int left = lowerBound(coords, unique, square[0]);
            int right = lowerBound(coords, unique, square[0] + square[1]) - 1;
            int base = query(1, 0, intervals - 1, left, right);
            int top = base + square[1];
            update(1, 0, intervals - 1, left, right, top);
            globalMax = Math.max(globalMax, top);
            answer.add(globalMax);
        }
        return answer;
    }

    private int lowerBound(int[] values, int length, int target) {
        int low = 0;
        int high = length;
        while (low < high) {
            int mid = low + (high - low) / 2;
            if (values[mid] < target) {
                low = mid + 1;
            } else {
                high = mid;
            }
        }
        return low;
    }

    private void apply(int node, int value) {
        tree[node] = value;
        lazy[node] = value;
    }

    private void pushDown(int node) {
        if (lazy[node] != -1) {
            apply(node * 2, lazy[node]);
            apply(node * 2 + 1, lazy[node]);
            lazy[node] = -1;
        }
    }

    private void update(int node, int start, int end, int left, int right, int value) {
        if (left <= start && end <= right) {
            apply(node, value);
            return;
        }
        pushDown(node);
        int mid = start + (end - start) / 2;
        if (left <= mid) {
            update(node * 2, start, mid, left, right, value);
        }
        if (right > mid) {
            update(node * 2 + 1, mid + 1, end, left, right, value);
        }
        tree[node] = Math.max(tree[node * 2], tree[node * 2 + 1]);
    }

    private int query(int node, int start, int end, int left, int right) {
        if (left <= start && end <= right) {
            return tree[node];
        }
        pushDown(node);
        int mid = start + (end - start) / 2;
        int result = 0;
        if (left <= mid) {
            result = Math.max(result, query(node * 2, start, mid, left, right));
        }
        if (right > mid) {
            result = Math.max(result, query(node * 2 + 1, mid + 1, end, left, right));
        }
        return result;
    }
}

/**
 * @param {number[][]} positions
 * @return {number[]}
 */
var fallingSquares = function (positions) {
    const coords = [];
    for (const [left, side] of positions) {
        coords.push(left, left + side);
    }
    coords.sort((a, b) => a - b);
    const unique = coords.filter((value, index) => index === 0 || value !== coords[index - 1]);
    const index = new Map(unique.map((value, i) => [value, i]));
    const intervals = Math.max(1, unique.length - 1);

    const tree = new Array(intervals * 4).fill(0);
    const lazy = new Array(intervals * 4).fill(-1);

    const apply = (node, value) => {
        tree[node] = value;
        lazy[node] = value;
    };

    const pushDown = (node) => {
        if (lazy[node] !== -1) {
            apply(node * 2, lazy[node]);
            apply(node * 2 + 1, lazy[node]);
            lazy[node] = -1;
        }
    };

    const update = (node, start, end, left, right, value) => {
        if (left <= start && end <= right) {
            apply(node, value);
            return;
        }
        pushDown(node);
        const mid = Math.floor((start + end) / 2);
        if (left <= mid) update(node * 2, start, mid, left, right, value);
        if (right > mid) update(node * 2 + 1, mid + 1, end, left, right, value);
        tree[node] = Math.max(tree[node * 2], tree[node * 2 + 1]);
    };

    const query = (node, start, end, left, right) => {
        if (left <= start && end <= right) return tree[node];
        pushDown(node);
        const mid = Math.floor((start + end) / 2);
        let result = 0;
        if (left <= mid) result = Math.max(result, query(node * 2, start, mid, left, right));
        if (right > mid) result = Math.max(result, query(node * 2 + 1, mid + 1, end, left, right));
        return result;
    };

    const answer = [];
    let globalMax = 0;
    for (const [left, side] of positions) {
        const rangeLeft = index.get(left);
        const rangeRight = index.get(left + side) - 1;
        const base = query(1, 0, intervals - 1, rangeLeft, rangeRight);
        const top = base + side;
        update(1, 0, intervals - 1, rangeLeft, rangeRight, top);
        globalMax = Math.max(globalMax, top);
        answer.push(globalMax);
    }
    return answer;
};

from typing import List


class Solution:
    def fallingSquares(self, positions: List[List[int]]) -> List[int]:
        coords = sorted({x for left, side in positions for x in (left, left + side)})
        index = {value: i for i, value in enumerate(coords)}
        intervals = max(1, len(coords) - 1)

        tree = [0] * (intervals * 4)
        lazy = [-1] * (intervals * 4)

        def apply(node: int, value: int) -> None:
            tree[node] = value
            lazy[node] = value

        def push_down(node: int) -> None:
            if lazy[node] != -1:
                apply(node * 2, lazy[node])
                apply(node * 2 + 1, lazy[node])
                lazy[node] = -1

        def update(
            node: int,
            start: int,
            end: int,
            left: int,
            right: int,
            value: int,
        ) -> None:
            if left <= start and end <= right:
                apply(node, value)
                return
            push_down(node)
            mid = (start + end) // 2
            if left <= mid:
                update(node * 2, start, mid, left, right, value)
            if right > mid:
                update(node * 2 + 1, mid + 1, end, left, right, value)
            tree[node] = max(tree[node * 2], tree[node * 2 + 1])

        def query(node: int, start: int, end: int, left: int, right: int) -> int:
            if left <= start and end <= right:
                return tree[node]
            push_down(node)
            mid = (start + end) // 2
            result = 0
            if left <= mid:
                result = max(result, query(node * 2, start, mid, left, right))
            if right > mid:
                result = max(result, query(node * 2 + 1, mid + 1, end, left, right))
            return result

        answer = []
        global_max = 0
        for left, side in positions:
            range_left = index[left]
            range_right = index[left + side] - 1
            base = query(1, 0, intervals - 1, range_left, range_right)
            top = base + side
            update(1, 0, intervals - 1, range_left, range_right, top)
            global_max = max(global_max, top)
            answer.append(global_max)

        return answer

#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
private:
    vector<int> tree;
    vector<int> lazy;

    void apply(int node, int value) {
        tree[node] = value;
        lazy[node] = value;
    }

    void pushDown(int node) {
        if (lazy[node] != -1) {
            apply(node * 2, lazy[node]);
            apply(node * 2 + 1, lazy[node]);
            lazy[node] = -1;
        }
    }

    void update(int node, int start, int end, int left, int right, int value) {
        if (left <= start && end <= right) {
            apply(node, value);
            return;
        }
        pushDown(node);
        int mid = start + (end - start) / 2;
        if (left <= mid) {
            update(node * 2, start, mid, left, right, value);
        }
        if (right > mid) {
            update(node * 2 + 1, mid + 1, end, left, right, value);
        }
        tree[node] = max(tree[node * 2], tree[node * 2 + 1]);
    }

    int query(int node, int start, int end, int left, int right) {
        if (left <= start && end <= right) {
            return tree[node];
        }
        pushDown(node);
        int mid = start + (end - start) / 2;
        int result = 0;
        if (left <= mid) {
            result = max(result, query(node * 2, start, mid, left, right));
        }
        if (right > mid) {
            result = max(result, query(node * 2 + 1, mid + 1, end, left, right));
        }
        return result;
    }

public:
    vector<int> fallingSquares(vector<vector<int>>& positions) {
        vector<int> coords;
        coords.reserve(positions.size() * 2);
        for (const auto& square : positions) {
            coords.push_back(square[0]);
            coords.push_back(square[0] + square[1]);
        }
        sort(coords.begin(), coords.end());
        coords.erase(unique(coords.begin(), coords.end()), coords.end());

        unordered_map<int, int> index;
        for (int i = 0; i < static_cast<int>(coords.size()); ++i) {
            index[coords[i]] = i;
        }

        int intervals = max(1, static_cast<int>(coords.size()) - 1);
        tree.assign(intervals * 4, 0);
        lazy.assign(intervals * 4, -1);

        vector<int> answer;
        int globalMax = 0;
        for (const auto& square : positions) {
            int left = index[square[0]];
            int right = index[square[0] + square[1]] - 1;
            int base = query(1, 0, intervals - 1, left, right);
            int top = base + square[1];
            update(1, 0, intervals - 1, left, right, top);
            globalMax = max(globalMax, top);
            answer.push_back(globalMax);
        }
        return answer;
    }
};
