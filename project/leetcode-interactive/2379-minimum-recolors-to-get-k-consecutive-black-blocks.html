得到 K 个黑块的
最少涂色次数

Minimum Recolors to Get K Consecutive Black Blocks

让一段颜色排列达成连续目标。先读题、自己判断，再用下方实验台观察。

LeetCode 官方题目 ↗

01 / 任务说明

给定字符串 blocks 和整数 k。字符串的每一位表示一块积木，W 是白块，B 是黑块，下标从 0 开始。每次操作可以把任意一个白块涂黑。

返回最少操作次数，使排列中至少有一段连续的 k 个黑块。超过 k 个连续黑块也满足要求，其他位置的颜色没有限制。

官方示例 1

输入：blocks = "WBBWWBBWBW", k = 7
输出：3

把下标 0、3、4 的白块涂黑，可得到 BBBBBBBWBW，前 7 块全黑；少于 3 次无法达成目标。

官方示例 2

输入：blocks = "WBWBBBW", k = 2
输出：0

原排列已经含有连续 2 个黑块，因此不需要涂色。

约束与参数

  • n == blocks.length，1 ≤ n ≤ 100。
  • blocks[i] 只能是 W 或 B。
  • 1 ≤ k ≤ n。
  • 函数：minimumRecolors(blocks, k)，返回整数。

04 / 题解：定长滑动窗口

核心洞察

对于任意长度为 k 的连续区间，黑块不用动，每个白块恰好涂一次就能使区间全黑。因此，这个区间的代价就是白块数，答案是所有长度为 k 的区间中白块数的最小值。

完整过程

  1. 统计第一个区间 [0, k−1] 的白块数 white，用它初始化 best。
  2. 令新进入的右端下标 r 从 k 走到 n−1。若 blocks[r−k] 是 W，white 减 1；若 blocks[r] 是 W，white 加 1。
  3. 此时区间是 [r−k+1, r]，令 best = min(best, white)。
  4. 所有 n−k+1 个区间处理完后，返回 best。若 best 为 0，也可以提前返回。

示例 1 的区间依次是 [0,6]、[1,7]、[2,8]、[3,9]，白块数分别为 3、3、3、4，因此答案为 3。移入、移出都为 W 时，数量保持不变。

正确性说明

单段最优：一个长度为 k 的区间要全黑，原有的每个白块都必须被涂黑，所以操作数至少等于白块数；各涂一次就能实现这个下界。

计数不变式：初始化时 white 等于首段的白块数。每次右移只失去左端一个块并获得右端一个块，按颜色减、加后，white 仍恰好等于当前区间的白块数。

全局最优：任何满足目标的最终排列都含有某个长度为 k 的全黑区间，其所需操作数不可能低于该区间原有的白块数。算法枚举全部合法区间，并取这些代价的最小值；选择对应区间涂色即可达到该值，因此答案既是下界，也是可实现的最优值。

边界与复杂度

  • k = 1：存在 B 就返回 0，否则返回 1。
  • k = n：只有一个区间，返回整个字符串的白块数。
  • 全黑返回 0；全白返回 k；多个最优区间不影响最小次数。
  • 初始化 O(k)，滑动 O(n−k)，合计时间 O(n)；只保存计数和下标，额外空间 O(1)。下方 Python 实现不切片，不产生 O(k) 临时字符串。

替代方案

直接枚举每个区间并重新统计白块：时间 O((n−k+1)k)，额外空间 O(1)，容易理解但重复计算。前缀和记录前 i 位白块数，再用 prefix[l+k]−prefix[l] 得到区间代价：时间 O(n)，空间 O(n)，适合复用多次区间查询。本题一次扫描使用定长窗口即可。

常见错误

  • 只计算整串中有多少 B，忽略必须连续。
  • 把任务理解成把所有 W 涂黑；只需让一个目标段全黑。
  • 右移时忘记减掉离开的白块，或把离开下标写成 r−k+1。
  • 未计算首段，导致 k = n 时漏掉唯一候选。
  • 把 best 初始化成 0，导致所有输入都被错误地压成 0。

面试追问

  • 如何返回涂色位置？最小值严格变小时记录区间起点；扫描该段输出其中 W 的下标，额外输出空间 O(k)。
  • 白块的涂色成本不同呢？若每块成本非负，将计数换成区间内白块成本之和，仍可定长滑动。
  • 改为最多涂 m 次，求最长黑段？维护白块数不超过 m 的可变长度窗口。
  • 数据按流到来呢？用长度为 k 的队列记住将要移出的颜色，流式额外空间变成 O(k)。

Java

class Solution {
    public int minimumRecolors(String blocks, int k) {
        int white = 0;
        for (int i = 0; i < k; i++) {
            if (blocks.charAt(i) == 'W') white++;
        }
        int best = white;
        for (int r = k; r < blocks.length(); r++) {
            if (blocks.charAt(r - k) == 'W') white--;
            if (blocks.charAt(r) == 'W') white++;
            best = Math.min(best, white);
        }
        return best;
    }
}

class Solution:
    def minimumRecolors(self, blocks: str, k: int) -> int:
        white = 0
        for i in range(k):
            if blocks[i] == 'W':
                white += 1
        best = white
        for r in range(k, len(blocks)):
            if blocks[r - k] == 'W':
                white -= 1
            if blocks[r] == 'W':
                white += 1
            best = min(best, white)
        return best

C++

#include <algorithm>
#include <string>
using namespace std;

class Solution {
public:
    int minimumRecolors(string blocks, int k) {
        int white = 0;
        for (int i = 0; i < k; ++i) {
            if (blocks[i] == 'W') ++white;
        }
        int best = white;
        for (int r = k; r < static_cast<int>(blocks.size()); ++r) {
            if (blocks[r - k] == 'W') --white;
            if (blocks[r] == 'W') ++white;
            best = min(best, white);
        }
        return best;
    }
};
