01 / 任务说明

让三类记录依次出现

输入是数据库表 Genders。查询需返回 user_id, gender 两列，行的类别按 female → other → male 循环出现；只看任意一种类别时，它的用户 ID 必须从小到大排列。查询只返回排好序的结果，不要求修改原表。

输入表 Genders
列名类型含义
user_idINT用户唯一标识（主键）
genderENUMfemale、other、male 之一

约束与输入契约

  • user_id 为主键，不重复；每行表示一名用户。
  • gender 仅取 female、other、male。
  • 三种类别的记录数相等。
  • 所获题面资料未给出总行数和 ID 数值范围；不额外假设 ID 连续或从 1 开始。
  • 结果的行顺序是要求的一部分，不能任意返回。

04 / 独立题解

准备好再揭晓

包含逐步演示、SQL 与四语言语义参考。

核心洞察：每一行有两个排序坐标

用“组内名次”决定第几轮，用“类别序号”决定这一轮第几个。先按类别把 ID 升序编号，再按 (名次, 类别序号) 升序输出。类别序号固定为 female=0、other=1、male=2。这个二元排序键直接表达了轮流取行的规则。

三条轨道 · 按轮次合流

先观察原始记录，再看分组、组内排名和按轮次输出。每前进一步，只揭示一个阶段或取出一条记录。

完整过程
  1. 对 Genders 使用 ROW_NUMBER() OVER (PARTITION BY gender ORDER BY user_id)，得到组内名次 rn，从 1 开始。
  2. 使用 CASE 显式映射类别顺序，避免依赖字符串排序或 ENUM 内部顺序。
  3. 外层查询仅返回原始两列，并以 rn 为第一排序键、类别序号为第二排序键。
  4. 官方示例第一轮输出 3/female、1/other、4/male，第二轮输出 7/female、2/other、5/male，第三轮输出 9/female、6/other、8/male。


可提交 SQL · MySQL 8+
本题是数据库题；以下查询是主要提交形式，未执行验证。


SQL · ROW_NUMBER + CASE
WITH numbered AS (
    SELECT user_id, gender,
           ROW_NUMBER() OVER (
               PARTITION BY gender ORDER BY user_id
           ) AS rn
    FROM Genders
)
SELECT user_id, gender
FROM numbered
ORDER BY rn,
         CASE gender
             WHEN 'female' THEN 0
             WHEN 'other' THEN 1
             WHEN 'male' THEN 2
         END;


为什么正确
设每类有 m 行。主键唯一，因此对任意类别 g，其第 k 小的 ID 得到唯一名次 k。三类人数相等，故每个 k∈[1,m] 都恰有三条记录。按名次排序使第 k 轮完整出现在第 k+1 轮之前；轮内按类别序号排序使三行顺序恰为 female、other、male。对于固定类别，名次递增等价于 ID 递增。查询没有过滤或合并行，因此每条输入记录恰好输出一次，同时满足全部条件。


复杂度
设 n 为总行数。采用比较排序的常规实现，分组排序与最终排序合计 O(n log n) 时间；辅助空间通常 O(n)。SQL 实际内存、临时文件与耗时取决于数据库执行计划、索引和排序实现，不将其视为固定运行保证。
边界与前提
空表返回空结果；每类一行时只需一轮。ID 间有空缺不影响排名。三类数量不等不符合题目输入契约；这种情况下，查询仍按现有行的排序键输出，但不再保证每轮完整。重复主键或非法类别也不属于合法输入。


四语言完整代码 · 本地语义参考
下列函数接收用户记录，返回同样的有序记录序列。它们用“分组 → 升序 → 逐轮取行”实现相同语义；均不是本题 SQL 编辑器可直接提交的代码，Python 版本也不是 pandas 官方接口。调用方需满足上述输入契约。时间 O(n log n)，额外空间 O(n)，均不修改原输入。




Java · 本地语义参考（Java 8+）
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

public class Solution {
    public static final class User {
        public final int userId;
        public final String gender;
        public User(int userId, String gender) {
            this.userId = userId;
            this.gender = gender;
        }
    }

    public static List<User> arrangeTable(List<User> rows) {
        String[] order = {"female", "other", "male"};
        List<List<User>> groups = new ArrayList<>();
        for (String gender : order) {
            List<User> group = new ArrayList<>();
            for (User row : rows) {
                if (row.gender.equals(gender)) group.add(row);
            }
            group.sort(Comparator.comparingInt(u -> u.userId));
            groups.add(group);
        }
        List<User> result = new ArrayList<>();
        for (int i = 0; i < groups.get(0).size(); i++) {
            for (List<User> group : groups) result.add(group.get(i));
        }
        return result;
    }
}


JavaScript · 本地语义参考
// rows: Array<{user_id: number, gender: string}>
// Preconditions: unique integer IDs; three equally sized valid groups.
function arrangeTable(rows) {
  const groups = ["female", "other", "male"].map(gender =>
    rows.filter(row => row.gender === gender)
        .sort((a, b) => a.user_id - b.user_id)
  );
  const result = [];
  for (let i = 0; i < groups[0].length; i++) {
    for (const group of groups) result.push(group[i]);
  }
  return result;
}


Python 3 · 本地语义参考（非 pandas 提交接口）
def arrange_table(rows):
    """rows: list of dicts with user_id and gender.
    Requires unique IDs and equal counts for all three genders.
    Returns a newly ordered list without modifying rows.
    """
    groups = [
        sorted(
            (row for row in rows if row["gender"] == gender),
            key=lambda row: row["user_id"],
        )
        for gender in ("female", "other", "male")
    ]
    result = []
    for i in range(len(groups[0])):
        for group in groups:
            result.append(group[i])
    return result


C++17 · 本地语义参考
#include <algorithm>
#include <array>
#include <string>
#include <vector>

struct User {
    int user_id;
    std::string gender;
};

std::vector<User> arrangeTable(const std::vector<User>& rows) {
    const std::array<std::string, 3> order = {"female", "other", "male"};
    std::array<std::vector<User>, 3> groups;
    for (std::size_t g = 0; g < order.size(); ++g) {
        for (const auto& row : rows) {
            if (row.gender == order[g]) groups[g].push_back(row);
        }
        std::sort(groups[g].begin(), groups[g].end(),
                  [](const User& a, const User& b) {
                      return a.user_id < b.user_id;
                  });
    }
    std::vector<User> result;
    result.reserve(rows.size());
    for (std::size_t i = 0; i < groups[0].size(); ++i) {
        for (const auto& group : groups) result.push_back(group[i]);
    }
    return result;
}




替代方案
  • RANK：由于主键唯一，组内 ID 没有并列，RANK 与 ROW_NUMBER 的结果一致。ROW_NUMBER 更直接表达“第几条”。
  • 三份编号结果再 UNION ALL：分别处理三类，再合并并按轮次、类别排序也可行，但查询更重复。
  • 无窗口函数的相关计数：为每行统计同类中 ID 不大于它的数量作为名次；朴素实现可能 O(n²)，通常不如窗口函数清晰高效。
  • 单一数字排序键：可将二元键编码成 3*(rn-1)+类别序号；本题直接使用两个 ORDER BY 表达式更清晰。


常见错误
  • 只按 gender、user_id 排序：会把同类连在一起，不能轮流输出。
  • 只按 user_id 排序或用 user_id 取模：ID 的数值不表示轮次。
  • 窗口中漏写 PARTITION BY：变成全表编号，失去各类各自的名次。
  • 只在 CTE 中排序：中间查询顺序不是最终返回顺序，最外层仍需 ORDER BY。
  • 用字符串或 ENUM 默认顺序：可能得到 female、male、other，应使用显式 CASE。
  • 把辅助名次列一起返回：应只输出题目要求的 user_id、gender。


面试追问
  • 三类数量不同怎么办？先定义业务规则：跳过已耗尽的类别、截断到最短组，或补空值。现有二元排序等价于按轮次跳过缺项。
  • 扩展到任意 k 类？准备类别与优先级映射，仍按组内名次和优先级排序。
  • ID 不唯一怎么办？为窗口排序增加唯一且稳定的次序键，否则并列行的顺序未定义。
  • 索引是否能避免排序？复合索引 (gender, user_id) 可能帮助分组有序读取，但最终的跨组交错仍可能需要排序；需要查看实际执行计划。
