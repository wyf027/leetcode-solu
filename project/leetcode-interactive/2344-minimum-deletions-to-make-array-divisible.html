2344. 使数组可以被整除的最少删除次数

Minimum Deletions to Make Array Divisible

先理解删除规则，再打开题解探索。支持离线阅读与交互。

题目 / 保留一个合适的最小值

给定两个正整数数组 nums 与 numsDivide。你可以删除 nums 中任意位置的元素。删除后，剩余数组的最小元素必须整除 numsDivide 中的每一个元素。求最少删除多少个元素；无论怎样删除都无法满足条件时返回 -1。

“x 整除 y”表示 y % x == 0。剩余数组必须非空；不能修改 numsDivide，也不能凭空添加一个数。相同数值的不同元素分别计入删除次数。

函数参数与返回值

minOperations(nums, numsDivide) → integer；两个参数均为正整数数组，返回最少删除次数或 -1。

官方示例 1

输入：nums = [2,3,2,4,3]
      numsDivide = [9,6,9,3,15]
输出：2

删除两个值为 2 的元素，留下 [3,4,3]。最小值 3 能整除目标数组的所有元素；只删除一个元素仍会留下 2，因此至少需要两次删除。

官方示例 2

输入：nums = [4,3,6]
      numsDivide = [8,2,6,10]
输出：-1

nums 中没有元素能够整除目标数组中的所有值，无法通过删除达到目标。

约束

  • 1 ≤ nums.length, numsDivide.length ≤ 10⁵
  • 1 ≤ nums[i], numsDivide[i] ≤ 10⁹

题解 / 公约数与删除门槛

核心洞察

设 g = gcd(numsDivide)。一个正整数 x 能整除目标数组的所有数，当且仅当 g % x == 0。因此只需在 nums 中找到最小的、能整除 g 的元素 best，再删除所有小于 best 的元素。

注意：best 是 nums 中实际存在的元素；它可以是 g 的任意约数，不必等于 g。比 best 大的元素即使不能整除 g，也可以保留，因为题目只约束最小值。

完整过程：无需排序

  1. 从 g = 0 开始，遍历 numsDivide，以欧几里得算法更新 g。
  2. 遍历 nums。对于每个满足 g % x = 0 的元素，用它更新最小可行值 best。
  3. 若没有可行元素，返回 -1。
  4. 再次遍历 nums，统计 x < best 的元素个数并返回。

示例 1 中：g 依次为 9 → 3 → 3 → 3 → 3；最小可行值为 3；小于 3 的两个元素均为 2，答案为 2。

为什么正确

  1. 可行性等价。若 x 整除每个目标值，则 x 整除它们的最大公约数；反之，g 整除每个目标值，故 x 整除 g 时也整除每个目标值。
  2. 固定最小值的必要删除。若剩余最小值为 x，所有小于 x 的元素都必须删除，至少删除 count(v < x) 个。删除这些元素、保留 x 及所有更大元素，恰好达到这个下界。
  3. 选择最小可行值最优。best 是最小可行元素。任意其他可行 x ≥ best，满足 count(v < x) ≥ count(v < best)。因此 best 对应的删除次数全局最小。没有可行元素时，任何非空剩余数组的最小值都不合格，返回 -1 正确。

边界与复杂度

g = 1 时只有元素 1 可用；有 1 就无需删除，没有则无解。重复的较小元素按出现次数删除；所有等于 best 的元素保留。单元素 nums 若不满足整除关系，不能靠删空数组解决。

令 n = nums.length，m = numsDivide.length，M 为最大输入值。计算 GCD 的时间上界为 O(m log M)，两次扫描为 O(n)，总时间 O(m log M + n)，算法额外空间 O(1)，不修改输入。页面的演示轨迹单独保存步骤，不计入提交解法空间。

替代方案

将 nums 升序排序，找到第一个满足 g % nums[i] = 0 的位置 i，返回 i；找不到返回 -1。它更直观，但时间为 O(m log M + n log n)，排序可能修改原数组且额外空间取决于语言实现。逐个候选检查全部 numsDivide 的朴素方案需要 O(nm)，不适合 10⁵ 规模。

常见错误

  • 把整除方向写反：应是 g % x，不是 x % g。
  • 仅寻找等于 g 的元素：会漏掉 g 的其他约数。
  • 统计所有“不合格元素”：大于 best 的元素无需删除。
  • 对 nums 去重再计数：会漏掉重复元素的删除次数。
  • 无候选时返回 n：删空数组没有最小值，应返回 -1。

面试追问

  • 为什么不用排序？只需要最小可行值及其左侧数量，用两遍线性扫描即可。
  • 能否提前停止求 GCD？g 到达 1 后不会继续变化，可以直接结束该阶段。
  • 如果还要返回删除位置？找到 best 后收集所有 nums[i] < best 的下标，输出本身需要 O(k) 空间。
  • 如果每个删除有正成本？仍选最小可行值，最终累加所有更小元素的成本；候选越大，必须删除的集合只会扩大。

Java

class Solution {
    private int gcd(int a, int b) {
        while (b != 0) {
            int r = a % b;
            a = b;
            b = r;
        }
        return a;
    }

    public int minOperations(int[] nums, int[] numsDivide) {
        int g = 0;
        for (int x : numsDivide) g = gcd(g, x);
        int best = Integer.MAX_VALUE;
        for (int x : nums) {
            if (g % x == 0) best = Math.min(best, x);
        }
        if (best == Integer.MAX_VALUE) return -1;
        int answer = 0;
        for (int x : nums) if (x < best) answer++;
        return answer;
    }
}

/**

var minOperations = function(nums, numsDivide) {
    const gcd = (a, b) => {
        while (b !== 0) [a, b] = [b, a % b];
        return a;
    };
    let g = 0;
    for (const x of numsDivide) g = gcd(g, x);
    let best = Infinity;
    for (const x of nums) {
        if (g % x === 0) best = Math.min(best, x);
    }
    if (best === Infinity) return -1;
    let answer = 0;
    for (const x of nums) if (x < best) answer++;
    return answer;
};

Python 3

from typing import List
from math import gcd

class Solution:
    def minOperations(self, nums: List[int], numsDivide: List[int]) -> int:
        g = 0
        for x in numsDivide:
            g = gcd(g, x)
        best = None
        for x in nums:
            if g % x == 0 and (best is None or x < best):
                best = x
        if best is None:
            return -1
        return sum(x < best for x in nums)

#include <vector>

class Solution {
public:
    int minOperations(vector<int>& nums, vector<int>& numsDivide) {
        int g = 0;
        for (int x : numsDivide) g = gcd(g, x);
        int best = numeric_limits<int>::max();
        for (int x : nums) {
            if (g % x == 0) best = min(best, x);
        }
        if (best == numeric_limits<int>::max()) return -1;
        int answer = 0;
        for (int x : nums) if (x < best) ++answer;
        return answer;
    }
};
