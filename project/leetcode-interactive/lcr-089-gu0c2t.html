LCR 089·动态规划MEDIUM

打家劫舍

相邻房屋不能同时偷取，找出能获得的最高金额。

开始演示

题意

给定每间房的现金 nums，相邻房屋同晚不能被偷，返回不触发警报时的最高金额。

示例

输入：nums = [2,7,9,3,1]
输出：12
解释：偷取 2、9、1

约束

  • 0 <= nums.length <= 100
  • 0 <= nums[i] <= 400

核心洞察

对第 i 间房只有两种选择：不偷，继承前一间最优值；偷，获得 dp[i-2] + nums[i]。取较大者。

转移：dp[i] = max(dp[i-1], dp[i-2] + nums[i])

分步交互

依次计算 [2,7,9,3,1] 的最优金额。

完整过程

  1. 空数组返回 0，第一间房的最优值为它本身。
  2. 从左到右计算“偷当前房”与“不偷当前房”。
  3. 用两个变量保存前两步结果，避免整个 dp 数组。
  4. 最终变量即为最高金额。

边界

  • 长度为 0、1、2 要正确初始化。
  • 不能贪心地只选当前最大房屋。
  • 金额可以为 0。

复杂度

时间 O(n)，额外空间 O(1)。

替代方案

完整 dp 数组更利于展示每一步选择，但空间 O(n)。递归加记忆化也可行，迭代更简洁。

官方签名代码

class Solution {
    public int rob(int[] nums) {
        int prev2 = 0, prev1 = 0;
        for (int x : nums) { int cur = Math.max(prev1, prev2 + x); prev2 = prev1; prev1 = cur; }
        return prev1;
    }
}
var rob = function(nums) {
  let prev2 = 0, prev1 = 0;
  for (const x of nums) [prev2, prev1] = [prev1, Math.max(prev1, prev2 + x)];
  return prev1;
};
class Solution:
    def rob(self, nums: List[int]) -> int:
        prev2 = prev1 = 0
        for x in nums:
            prev2, prev1 = prev1, max(prev1, prev2 + x)
        return prev1
class Solution {
public:

追问与常见错误

追问

如果房屋首尾相邻？分别计算不偷第一间与不偷最后一间的两段区间，取最大值。

常见错误

  • 把相邻两间同时累加。
  • 未处理空数组。
  • 误用贪心选择当前最大金额。
