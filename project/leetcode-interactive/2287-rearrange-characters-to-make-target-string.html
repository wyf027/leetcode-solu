01 / 题目

每个字符只能用一次

给定两个从下标 0 开始的字符串 s 和 target。可以从 s 中取出字符并重新排列，拼成若干份与 target 完全相同的字符串。返回最多能拼成的份数。不同副本不能重复使用同一个源字符，没用上的字符可以留下。

官方示例 1

s = "ilovecodingonleetcode"
target = "code"

输出：2

下标 4、5、6、7 的字母和下标 17、18、19、20 的字母，可分别重排成一份 code，总共最多两份。

官方示例 2

s = "abcba"
target = "abc"

输出：1

下标 0、1、2 可组成一份 abc。剩余 a、b 无法再配上 c，也不能复用已取出的 c。

官方示例 3

s = "abbaccaddaeea"
target = "aaaaa"

输出：1

下标 0、3、6、9、12 提供五个 a，恰好拼成一份 aaaaa，不能再拼出第二份。

约束

  • 1 <= s.length <= 100
  • 1 <= target.length <= 10
  • s 与 target 仅包含小写英文字母。

题意与示例据随任务提供的官方元数据转述。官方题目 · 官方说明：本题与 1189「气球的最大数量」同类。

04 / 独立题解

先想一想，再对照思路

哪一种字母最先不够？目标中一个字母出现多次，会改变什么？

核心洞察：每种字母给出一个上限

记源串中字母 c 的次数为 have[c]，目标中需要的次数为 need[c]。只考虑目标需要的字母：一种字母最多支撑 floor(have[c] / need[c]) 份。所有字母必须同时够用，因此答案是这些上限的最小值。

answer = min floor(have[c] / need[c])，其中 need[c] > 0

完整过程

  1. 建立两个长度为 26 的数组，分别统计 s 与 target。
  2. 将答案初始化为 s 的长度。每份目标至少使用一个字符，这是合法上界。
  3. 遍历 26 个字母；跳过 need 为 0 的项，其余项用向下取整的商更新最小值。
  4. 返回最小值。若某个必需字母完全不存在，其商为 0，答案自然为 0。

示例 1：c、o、d、e 的供给分别为 2、4、2、4，每份各需要 1 个，上限分别是 2、4、2、4，最小值为 2。示例 3：a 的供给为 5，每份需要 5 个，因此只能形成 1 份。

正确性证明

上界：若能拼出 k 份，则对每个必需字母 c，都必须有 k × need[c] ≤ have[c]，所以 k 不超过任一字母的整除上限，更不超过最小值。

可达：设最小值为 K，则每种必需字母都有至少 K × need[c] 个。为 K 个副本各分配 need[c] 个该字母，不同字母的分配互不冲突，重排后恰好得到 K 份目标。因此这个上界可以达到，返回值最优。

边界与复杂度

缺少必需字母、目标比源串长时得到 0；单字符目标直接由对应频数决定；重复字母必须按需求次数分组；剩余字母不影响结果。官方保证目标非空，不需要定义空目标的副本数。

设 n = s.length、m = target.length。时间 O(n + m + 26)，通常记为 O(n + m)；两个固定数组占用 O(26) = O(1) 额外空间。

替代方案

可以每次尝试扣除一整份目标需要的字母，直到不足。正确性直观，但要反复检查和扣减；设能拼出 K 份，每轮扫 26 个字母则为 O(n + m + 26(K + 1))。也可二分份数，用所有字母是否足够作为可行性判断，但本题上限能直接整除求出，二分没有必要。

常见错误

  • 取最大值而不是最小值，忽略最短缺的字母。
  • 只检查字母是否存在，没有计算 target 内部重复次数。
  • 对 need 为 0 的项做除法；或误把不需要的字母当成限制。
  • JavaScript 忘记 Math.floor，返回小数。
  • 按子串或子序列匹配。重排允许忽略原有顺序。

面试追问

  • 支持任意字符？使用频次映射，明确按字节、Unicode 码点还是用户可见字符计数；空间变为 O(不同字符数)。
  • 需要返回具体副本？数量确定后可返回 K 份 target；若需要原下标，额外保存各字母的下标队列并逐份分配。
  • 字母有先后约束？当前证明不再适用，计数相同也未必能组成目标序列。
  • 有多个不同目标？它们会竞争字符，逐个独立取最小值不能决定全局最优组合。

Java

class Solution {
    public int rearrangeCharacters(String s, String target) {
        int[] have = new int[26];
        int[] need = new int[26];
        for (char c : s.toCharArray()) have[c - 'a']++;
        for (char c : target.toCharArray()) need[c - 'a']++;
        int answer = s.length();
        for (int i = 0; i < 26; i++) {
            if (need[i] > 0) {
                answer = Math.min(answer, have[i] / need[i]);
            }
        }
        return answer;
    }
}

var rearrangeCharacters = function(s, target) {
    const have = Array(26).fill(0);
    const need = Array(26).fill(0);
    for (const c of s) have[c.charCodeAt(0) - 97]++;
    for (const c of target) need[c.charCodeAt(0) - 97]++;
    let answer = s.length;
    for (let i = 0; i < 26; i++) {
        if (need[i] > 0) {
            answer = Math.min(answer,
                Math.floor(have[i] / need[i]));
        }
    }
    return answer;
};

        have = [0] * 26
        need = [0] * 26
        for c in s:
            have[ord(c) - ord('a')] += 1
        for c in target:
            need[ord(c) - ord('a')] += 1
        answer = len(s)
        for i in range(26):
            if need[i] > 0:

C++

#include <algorithm>
#include <string>
using namespace std;

class Solution {
public:
    int rearrangeCharacters(string s, string target) {
        int have[26] = {};
        int need[26] = {};
        for (char c : s) ++have[c - 'a'];
        for (char c : target) ++need[c - 'a'];
        int answer = static_cast<int>(s.size());
        for (int i = 0; i < 26; ++i) {
            if (need[i] > 0) {
                answer = min(answer, have[i] / need[i]);
            }
        }
        return answer;
    }
};
