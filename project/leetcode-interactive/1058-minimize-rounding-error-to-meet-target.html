最小化舍入误差
以满足目标

Minimize Rounding Error to Meet Target
MEDIUM付费题数组数学贪心

题意

给定以三位小数表示的价格数组 prices。每个价格必须独立地向下或向上取整，使取整后的整数总和恰好等于 target。

单项误差是原值与取整值之差的绝对值。返回所有误差之和的最小值，保留三位小数；无法达到目标时返回 "-1"。

官方签名：String minimizeError(String[] prices, int target)

完整示例

示例 1
输入：prices = ["0.700","2.800","4.900"], target = 8
输出："1.000"
解释：0 + 3 + 5 = 8，误差 0.700 + 0.200 + 0.100 = 1.000。
示例 2
输入：prices = ["1.500","2.500","3.500"], target = 10
输出："-1"
解释：全部向上取整，总和也只有 9。
示例 3
输入：prices = ["1.500","2.500","3.500"], target = 9
输出："1.500"

约束

  • 1 ≤ prices.length ≤ 500
  • 每项位于 [0.000, 1000.000]，且恰有三位小数。
  • 0 ≤ target ≤ 10⁶

题解 · 将上调机会交给最大的小数

核心洞察：先全部向下取整。若距离目标还差 k，就要从非整数中恰选 k 个向上取整。小数部分为 f 时，向下误差为 f，向上误差为 1-f；让较大的 f 向上更优。

完整过程

  1. 解析价格，累计向下取整总和 floorSum，收集所有非零小数部分。
  2. 计算 k = target - floorSum。若 k<0 或大于非整数数量，返回 "-1"。
  3. 小数部分降序排列，前 k 项向上，其余向下。
  4. 以千分整数累计误差，再格式化为三位小数。

正确性

可行性：每把一个非整数从向下改为向上，总和恰增 1，因此选 k 个后恰达目标。

交换论证：若方案将较小小数 a 向上、较大小数 b 向下（a<b），误差是 (1-a)+b；交换后是 a+(1-b)，减少 2(b-a)。消除所有逆序后，向上的必是最大的 k 个小数，因此算法最优。

边界、复杂度与替代方案

  • 整数不能提供“总和 +1”的选择；k=0 时全向下，k=m 时全向上。
  • 排序耗时 O(n log n)，额外空间 O(n)。
  • 动态规划可行但依赖目标规模；利用三位小数仅 999 种非零值，可用桶计数做到 O(n+1000)。

面试追问与常见错误

  • 追问：怎样用选择算法达到期望 O(n)？怎样证明桶计数的正确性？
  • 常见错误：漏判目标超过最大可达和；把最小小数向上；把整数算作可上调项；使用浮点累计导致格式边界偏差。

class Solution {
  public String minimizeError(String[] prices, int target) {
    int floorSum = 0;
    java.util.List<Integer> fs = new java.util.ArrayList<>();
    for (String s : prices) {
      int d = s.indexOf('.');
      floorSum += Integer.parseInt(s.substring(0, d));
      int f = Integer.parseInt(s.substring(d + 1));
      if (f != 0) fs.add(f);
    }
    int k = target - floorSum;
    if (k < 0 || k > fs.size()) return "-1";
    fs.sort(java.util.Collections.reverseOrder());
    int error = 0;
    for (int i = 0; i < fs.size(); i++)
      error += i < k ? 1000 - fs.get(i) : fs.get(i);
    return String.format(java.util.Locale.US, "%d.%03d", error / 1000, error % 1000);
  }
}
var minimizeError = function(prices, target) {
  let floorSum = 0;
  const fs = [];
  for (const price of prices) {
    const [whole, decimal] = price.split('.');
    floorSum += Number(whole);
    const f = Number(decimal);
    if (f !== 0) fs.push(f);
  }
  const k = target - floorSum;
  if (k < 0 || k > fs.length) return "-1";
  fs.sort((a, b) => b - a);
  const error = fs.reduce((sum, f, i) => sum + (i < k ? 1000 - f : f), 0);
  return Math.floor(error / 1000) + "." + String(error % 1000).padStart(3, "0");
};

      floorSum += stoi(s.substr(0, d));

      if (f) fs.push_back(f);
    }
    int k = target - floorSum;
    if (k < 0 || k > (int)fs.size()) return "-1";
    sort(fs.rbegin(), fs.rend());

    for (int i = 0; i < (int)fs.size(); ++i)
      error += i < k ? 1000 - fs[i] : fs[i];
    char out[32];
    snprintf(out, sizeof(out), "%d.%03d", error / 1000, error % 1000);
    return out;
  }
};
