二叉搜索树最近节点查询

Closest Nodes Queries in a Binary Search Tree

MEDIUM二叉搜索树· 两个方向的边界

给每个查询值，找到树中“不超过它的最大值”和“不小于它的最小值”。先读题，再展开推演。

01 / 题目

给定二叉搜索树根节点 root 和正整数数组 queries（长度为 n），按查询的原顺序返回二维数组 answer。

  • answer[i][0]：树中所有 ≤ queries[i] 的值里最大的一个；不存在时为 -1。
  • answer[i][1]：树中所有 ≥ queries[i] 的值里最小的一个；不存在时为 -1。

这是两侧的数值边界，不是按绝对差只选一个节点。若查询值恰好存在，两个答案都等于它。

官方示例 1

root = [6,2,13,1,4,9,15,null,null,null,null,null,null,14]
queries = [2,5,16]
输出：[[2,2],[4,6],[15,-1]]

查询 2 命中节点；5 位于 4 和 6 之间；16 大于树中最大值 15，右侧边界不存在。

官方示例 2

root = [4,null,9]
queries = [3]
输出：[[-1,4]]

3 小于树中最小值 4，因此左侧没有可选节点，右侧边界是 4。以上 root 使用层序表示，null 表示空子节点。

约束

  • 树中节点数量在 [2, 10⁵] 内。
  • 1 ≤ Node.val ≤ 10⁶。
  • n == queries.length，且 1 ≤ n ≤ 10⁵。
  • 1 ≤ queries[i] ≤ 10⁶。

03 / 题解与交互推演

准备好之后，再打开完整思路与四语言代码。

把树展开，让每次查询只寻找一个位置

核心洞察

BST 的中序遍历按“左子树 → 当前节点 → 右子树”访问，得到有序数组 a。对查询 q，找到第一个满足 a[p] ≥ q 的下标 p，两侧答案就都能确定。

  • p < m：右侧答案为 a[p]；否则为 -1。
  • 若 a[p] == q，左侧答案也为 q。
  • 否则，p > 0 时左侧答案为 a[p-1]，没有前驱则为 -1。

交互实验 / 树 → 有序序列 → 边界

完整过程

  1. 用显式栈迭代中序遍历：不断向左入栈，弹出并记录节点，再进入其右子树。避免深达 10⁵ 的递归调用栈。
  2. 每个查询令 lo = 0, hi = m；hi 是排除边界，可以等于数组长度。
  3. 取中点。若 a[mid] < q，令 lo = mid + 1；否则令 hi = mid。
  4. 当 lo == hi，得到插入位置，按是否精确命中取左右答案，按原查询顺序保存。

示例 q = 5：中序数组为 [1,2,4,6,9,13,14,15]；区间依次为 [0,8) → [0,4) → [3,4) → [3,3)。插入位置 3 的值是 6，前一项是 4，所以答案为 [4,6]。

正确性

有序性：BST 的左子树值不大于当前值，右子树值不小于当前值；归纳应用中序访问次序，得到非递减数组。

二分不变式：始终保证下标小于 lo 的元素都小于 q，下标大于等于 hi 的元素都大于等于 q。初始两边为空，性质成立。中点小于 q 时，排除的左段全部小于 q；否则，排除的右段全部大于等于 q。每步区间严格缩短，终止时 lo 就是第一个不小于 q 的位置。

答案：该位置是满足 ≥ q 的最小值；如果等于 q，它同时是 ≤ q 的最大值。若不等于 q，它的前一项就是满足 ≤ q 的最大值。数组外不存在候选，用 -1 表示。每个查询独立正确，因此完整数组正确。

边界与常见错误

  • 比最小值还小：p = 0，不可读取 a[-1]。
  • 比最大值还大：p = m，不可读取 a[m]。
  • 精确命中：返回 [q,q]，不能一律取前一项。
  • 树可能退化为链，不可把树高默认当成 log m。递归遍历可能栈溢出。
  • 不要用层序数组直接二分，也无需对已经有序的中序结果再次排序。
  • 不要混用闭区间和半开区间的更新规则；不要把“最近”理解成绝对差最小。

复杂度

令 m 为节点数，n 为查询数，h 为树高。遍历 O(m)，每次二分 O(log m)，总时间 O(m + n log m)。有序数组 O(m)、显式栈 O(h)，辅助空间 O(m)；若计入返回结果为 O(m + n)。

替代方案

  • 逐次沿 BST 寻找：遇到小于 q 的节点更新下界并向右走，大于 q 则更新上界并向左走。O(nh) 时间、O(1) 辅助空间；平衡树表现好，但退化树最坏 O(nm)。
  • 离线排序查询：记录查询原下标，排序后与中序数组双指针扫描，再还原顺序。O(m + n log n) 时间、O(m+n) 空间，适合批量查询。
  • 值域前驱/后继表：以最大值域 U 建表，时间 O(m+U+n)、空间 O(U)，用更多值域空间换 O(1) 单次查询。

面试追问

如果树频繁插入删除？静态数组维护成本高，可用支持前驱和后继的平衡有序集合。
如果查询仅一次？直接沿树搜索可以省去遍历和数组。
若允许相同节点值？非递减中序数组依然可用，lower_bound 会找第一个相等项，答案值仍为 [q,q]。

Java

import java.util.*;

// TreeNode 由 LeetCode 提供。
class Solution {
    public List<List<Integer>> closestNodes(TreeNode root, List<Integer> queries) {
        List<Integer> values = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {
                stack.push(cur);
                cur = cur.left;
            }
            cur = stack.pop();
            values.add(cur.val);
            cur = cur.right;
        }
        List<List<Integer>> answer = new ArrayList<>();
        int m = values.size();
        for (int q : queries) {
            int lo = 0, hi = m;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (values.get(mid) < q) lo = mid + 1;
                else hi = mid;
            }
            int upper = lo < m ? values.get(lo) : -1;
            int lower = upper == q ? q : (lo > 0 ? values.get(lo - 1) : -1);
            answer.add(Arrays.asList(lower, upper));
        }
        return answer;
    }
}

var closestNodes = function(root, queries) {
    const values = [], stack = [];
    let cur = root;
    while (cur || stack.length) {
        while (cur) {
            stack.push(cur);
            cur = cur.left;
        }
        cur = stack.pop();
        values.push(cur.val);
        cur = cur.right;
    }
    return queries.map(q => {
        let lo = 0, hi = values.length;
        while (lo < hi) {
            const mid = lo + Math.floor((hi - lo) / 2);
            if (values[mid] < q) lo = mid + 1;
            else hi = mid;
        }
        const upper = lo < values.length ? values[lo] : -1;
        const lower = upper === q ? q : (lo > 0 ? values[lo - 1] : -1);
        return [lower, upper];
    });
};

from typing import List, Optional
from bisect import bisect_left

# TreeNode 由 LeetCode 提供。
class Solution:
    def closestNodes(self, root: Optional[TreeNode], queries: List[int]) -> List[List[int]]:
        values, stack = [], []
        cur = root
        while cur is not None or stack:
            while cur is not None:
                stack.append(cur)
                cur = cur.left
            cur = stack.pop()
            values.append(cur.val)
            cur = cur.right
        answer = []
        for q in queries:
            p = bisect_left(values, q)
            upper = values[p] if p < len(values) else -1
            lower = q if upper == q else (values[p - 1] if p > 0 else -1)
            answer.append([lower, upper])
        return answer

#include <vector>
#include <stack>
#include <algorithm>
using namespace std;

// TreeNode 由 LeetCode 提供。
class Solution {
public:
    vector<vector<int>> closestNodes(TreeNode* root, vector<int>& queries) {
        vector<int> values;
        stack<TreeNode*> st;
        TreeNode* cur = root;
        while (cur || !st.empty()) {
            while (cur) {
                st.push(cur);
                cur = cur->left;
            }
            cur = st.top();
            st.pop();
            values.push_back(cur->val);
            cur = cur->right;
        }
        vector<vector<int>> answer;
        for (int q : queries) {
            int p = lower_bound(values.begin(), values.end(), q) - values.begin();
            int upper = p < (int)values.size() ? values[p] : -1;
            int lower = upper == q ? q : (p > 0 ? values[p - 1] : -1);
            answer.push_back({lower, upper});
        }
        return answer;
    }
};
