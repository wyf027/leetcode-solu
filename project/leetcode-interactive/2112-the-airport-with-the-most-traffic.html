最繁忙的机场

The Airport With the Most Traffic

一张航线表，两个端点。找出承接最多起降航班的机场。

先读数据与目标，独立思考后再展开底部题解和交互演示。

01 / 题目与数据契约

输入为关系表 Flights。每行记录一条有向航线，以及该方向上的航班数量。机场的流量是其出发航班数与到达航班数之和。查询流量最大的所有机场，返回单列 airport_id；出现并列时全部返回，结果顺序不限。

Flights 表结构

arrival_airportint到达机场 ID
flights_countint该方向航班数

04 / 准备好推演了吗？

展开后可查看双端贡献演示、SQL 与完整推导。

题解 / 双端贡献 → 汇总 → 取所有最大值

核心洞察：一行航线数据同时影响两个机场。将出发端与到达端投影成相同结构的贡献记录，保留所有记录后按机场求和，最后筛选最大流量。

航班贡献分拣台

每条航线分两步记账：先出发，后到达。最后一步才标记全部冠军。数字为浏览器演示状态，不是验证结果。

键盘：Tab 移动焦点，Enter 或空格操作按钮。减少动态效果偏好下不使用条形过渡，自动播放仍需主动启动。

完整过程

  1. 取出 (departure_airport, flights_count)，把机场列统一命名为 airport_id。
  2. 用 UNION ALL 追加到达端贡献；n 条航线得到 2n 条贡献记录。
  3. 按 airport_id 分组，对 flights_count 求和得到 totals。
  4. 找 totals 中的最大总量，用等值条件返回所有对应机场。

示例 1：贡献依次为 (1,+4)、(2,+4)、(2,+5)、(1,+5)、(2,+5)、(4,+5)。最终流量为 1→9、2→14、4→5。SQL 不依赖贡献行的处理顺序。

正确性证明

对任一机场 a，每条以 a 出发的航线恰好在第一组贡献中出现一次；每条到达 a 的航线恰好在第二组贡献中出现一次。其他航线不向 a 贡献。UNION ALL 不会删除数值相同但来自不同航线或不同端点的贡献，因此分组和正是 a 的出发量加到达量。

设全部机场总量的最大值为 M。最终谓词仅保留总量等于 M 的机场，故返回的每个机场都最繁忙；任何最繁忙机场都满足谓词，故不会漏掉并列答案。

边界与数值

  • 只有一条普通航线：两个端点并列。
  • 只出发或只到达的机场仍会进入贡献表。
  • 机场对互为反向时，两条记录均参与计算。
  • 空表是额外健壮性情形：SQL 返回空集，本地参考返回空数组。
  • 题面未明确自环条件；按出发量加到达量口径，自环对同一机场贡献两次。业务若要求按航班去重，应另行明确规则。
  • 总量可能大于单行 int，Java 使用 long，C++ 使用 long long，Python 使用整数，JavaScript 使用 BigInt。

复杂度

n 为航线行数，k 为出现过的机场数。散列表聚合模型下期望时间 O(n+k)，聚合状态空间 O(k)。若数据库物化贡献表，还需 O(n) 中间空间；若采用排序分组，时间可能为 O(n log n)。实际 SQL 成本取决于执行计划。

四语言参考实现使用映射，期望时间 O(n+k)，空间 O(k)，不为题目不要求的输出顺序额外排序。

替代方案与取舍

汇总后使用 DENSE_RANK() OVER (ORDER BY total DESC) 并筛选排名 1，也能保留全部并列；通常引入排序。分别聚合出发与到达后合并也可行，但需要处理仅出现在一侧的机场。这里统一贡献再聚合更直接。

常见错误

  • 使用 UNION 去重：不同航线可能产生相同的 (airport_id, flights_count)，删除它们会少算。
  • 只统计出发端，或使用 COUNT(*)：前者漏到达，后者数的是航线记录而非航班数量。
  • ORDER BY total DESC LIMIT 1 或 ROW_NUMBER() = 1：遗漏并列机场。
  • 直接连接出发明细和到达明细：多对多连接可能重复放大计数。

面试追问

为什么不是无向边去重？方向相反的航线是不同记录，两者各有航班数。如何取前 K 名且保留并列？先明确 K 个名次还是 K 行；前 K 个不同流量等级可用 DENSE_RANK ≤ K。如何做增量维护？新增航线向两个端点分别增加计数；修改与删除需扣除旧贡献，最大值需重新维护。

完整代码

MySQL 8 · 官方可提交语言

WITH traffic AS (
    SELECT departure_airport AS airport_id, flights_count
    FROM Flights
    UNION ALL
    SELECT arrival_airport AS airport_id, flights_count
    FROM Flights
), totals AS (
    SELECT airport_id, SUM(flights_count) AS total
    FROM traffic
    GROUP BY airport_id
)
SELECT airport_id
FROM totals
WHERE total = (SELECT MAX(total) FROM totals);

Java · 本地语义参考

import java.util.*;

public class Main {
    // 输入每行为 [departure_airport, arrival_airport, flights_count]
    public static List<Integer> busiest(int[][] flights) {
        Map<Integer, Long> totals = new HashMap<>();
        for (int[] f : flights) {
            totals.merge(f[0], (long) f[2], Long::sum);
            totals.merge(f[1], (long) f[2], Long::sum);
        }
        List<Integer> result = new ArrayList<>();
        if (totals.isEmpty()) return result;
        long best = Collections.max(totals.values());
        for (Map.Entry<Integer, Long> e : totals.entrySet())
            if (e.getValue() == best) result.add(e.getKey());
        return result;
    }
    public static void main(String[] args) {
        int[][] flights = {{1, 2, 4}, {2, 1, 5}, {2, 4, 5}};
        System.out.println(busiest(flights));
    }
}

JavaScript · 本地语义参考

// 输入每行为 [departure_airport, arrival_airport, flights_count]
// BigInt 累加；Number 类型的输入计数应处于安全整数范围。
function busiest(flights) {
    const totals = new Map();
    for (const [from, to, count] of flights) {
        const n = BigInt(count);
        totals.set(from, (totals.get(from) ?? 0n) + n);
        totals.set(to, (totals.get(to) ?? 0n) + n);
    }
    if (totals.size === 0) return [];
    let best = null;
    for (const total of totals.values())
        if (best === null || total > best) best = total;
    return [...totals].filter(([, total]) => total === best)
                      .map(([airport]) => airport);
}
console.log(busiest([[1, 2, 4], [2, 1, 5], [2, 4, 5]]));

Python · 本地语义参考（非 Pandas 提交接口）

def busiest(flights):
    """每行为 [departure_airport, arrival_airport, flights_count]。"""
    totals = {}
    for departure, arrival, count in flights:
        totals[departure] = totals.get(departure, 0) + count
        totals[arrival] = totals.get(arrival, 0) + count
    if not totals:
        return []
    best = max(totals.values())
    return [airport for airport, total in totals.items() if total == best]

C++ · 本地语义参考

#include <array>
#include <iostream>
#include <unordered_map>
#include <vector>
using namespace std;

vector<int> busiest(const vector<array<int, 3>>& flights) {
    unordered_map<int, long long> totals;
    for (const auto& f : flights) {
        totals[f[0]] += f[2];
        totals[f[1]] += f[2];
    }
    if (totals.empty()) return {};
    long long best = totals.begin()->second;
    for (const auto& entry : totals)
        if (entry.second > best) best = entry.second;
    vector<int> result;
    for (const auto& entry : totals)
        if (entry.second == best) result.push_back(entry.first);
    return result;
}
int main() {
    vector<array<int, 3>> flights = {{1, 2, 4}, {2, 1, 5}, {2, 4, 5}};
    for (int airport : busiest(flights)) cout << airport << ' ';
    cout << '\n';
}
