Problem brief

题意与官方样例

字符矩阵，不是整数矩阵

任务定义

给定 rows × cols 的二进制字符矩阵 matrix。返回完全由 "1" 构成的最大矩形面积。矩形的边必须与矩阵边界平行。

输入展示中的每个值都是字符串字符；例如 "1"，不是数字 1。

约束

  • rows == matrix.length
  • cols == matrix[i].length
  • 1 ≤ rows, cols ≤ 200
  • matrix[i][j] 只能是 "0" 或 "1"

matrix = [["0"]]

0

样例 3

输入

matrix = [["1"]]

输出

Core insight

把每一行当作地面，向上累计连续的 1

扫描到第 r 行时，令 heights[c] 表示从该单元格向上连续 "1" 的数量。若当前格是 "0"，高度立即归零。

于是，所有“底边落在第 r 行”的全 1 矩形，都等价于当前柱状图中的某个矩形。对每行运行一次柱状图最大矩形即可覆盖所有可能底边。

面试主线

  1. 1. 更新一维高度数组。
  2. 2. 用单调递增栈求当前柱状图最大面积。
  3. 3. 用末尾哨兵 0 清空剩余柱子。
  4. 4. 取所有行结果的最大值。

Full process

完整过程

  1. 高度更新："1" → heights[c] + 1，"0" → 0。
  2. 维护栈：栈中下标对应的高度保持非递减。
  3. 遇到更矮柱：不断弹出栈顶，让被弹柱子的右边界固定为当前位置前一格。
  4. 计算宽度：弹栈后新栈顶是左侧首个严格更矮柱，宽度为 i - stackTop - 1。
  5. 更新答案：候选面积为弹出高度乘宽度。

Bounds & complexity

边界与复杂度

  • 单个 0：高度始终为 0，答案为 0。
  • 单个 1：高度 1、宽度 1，答案为 1。
  • 连续 0：每个 0 都会切断竖向高度，不能跨越。
  • 时间：O(rows × cols)，每行每列最多入栈、出栈各一次。
  • 额外空间：O(cols)，高度数组与栈只依赖列数。

Alternatives

替代方案取舍

也可维护每行的 left / right / height 三组 DP 边界，时间同为 O(rows × cols)，但状态转移更容易写错。暴力枚举上下边界与宽度通常达到 O(rows² × cols²)，不适合约束上限。

Interview follow-ups

面试追问

  • 如何同时返回矩形的四个边界坐标？
  • 为何每个矩形一定会在其底边所在行被统计？
  • 相等高度使用 > 还是 >= 弹栈？
  • 若矩阵按数据流逐行到达，能否在线计算？

Common mistakes

常见错误

  • 把字符 "0" 当作假值；多数语言中非空字符串为真。
  • 遇到 0 时忘记把高度归零。
  • 弹栈后宽度误写成 i - stackTop。
  • 没有末尾哨兵，导致递增尾部从未结算。

class Solution {
    public int maximalRectangle(char[][] matrix) {
        int cols = matrix[0].length;
        int[] heights = new int[cols];
        int answer = 0;

        for (char[] row : matrix) {
            for (int c = 0; c < cols; c++) {
                heights[c] = row[c] == '1' ? heights[c] + 1 : 0;
            }
            answer = Math.max(answer, largestRectangle(heights));
        }
        return answer;
    }

    private int largestRectangle(int[] heights) {
        int[] stack = new int[heights.length + 1];
        int top = -1;
        int best = 0;

        for (int i = 0; i <= heights.length; i++) {
            int current = i == heights.length ? 0 : heights[i];
            while (top >= 0 && heights[stack[top]] > current) {
                int height = heights[stack[top--]];
                int left = top >= 0 ? stack[top] : -1;
                best = Math.max(best, height * (i - left - 1));
            }
            stack[++top] = i;
        }
        return best;
    }
}

function largestRectangle(heights) {
  const stack = [];
  let best = 0;

  for (let i = 0; i <= heights.length; i++) {
    const current = i === heights.length ? 0 : heights[i];
    while (stack.length && heights[stack.at(-1)] > current) {
      const height = heights[stack.pop()];
      const left = stack.length ? stack.at(-1) : -1;
      best = Math.max(best, height * (i - left - 1));
    }
    stack.push(i);
  }
  return best;
}
from typing import List


class Solution:
    def maximalRectangle(self, matrix: List[List[str]]) -> int:
        cols = len(matrix[0])
        heights = [0] * cols
        answer = 0

        for row in matrix:
            for c in range(cols):
                heights[c] = heights[c] + 1 if row[c] == "1" else 0
            answer = max(answer, self.largest_rectangle(heights))
        return answer

    def largest_rectangle(self, heights: List[int]) -> int:
        stack = []
        best = 0

        for i in range(len(heights) + 1):
            current = 0 if i == len(heights) else heights[i]
            while stack and heights[stack[-1]] > current:
                height = heights[stack.pop()]
                left = stack[-1] if stack else -1
                best = max(best, height * (i - left - 1))
            stack.append(i)
        return best
class Solution {
public:
    int maximalRectangle(vector<vector<char>>& matrix) {
        int cols = matrix[0].size();
        vector<int> heights(cols, 0);
        int answer = 0;

        for (const auto& row : matrix) {
            for (int c = 0; c < cols; ++c) {
                heights[c] = row[c] == '1' ? heights[c] + 1 : 0;
            }
            answer = max(answer, largestRectangle(heights));
        }
        return answer;
    }

private:
    int largestRectangle(const vector<int>& heights) {
        vector<int> stack;
        int best = 0;

        for (int i = 0; i <= static_cast<int>(heights.size()); ++i) {
            int current = i == heights.size() ? 0 : heights[i];
            while (!stack.empty() && heights[stack.back()] > current) {
                int height = heights[stack.back()];
                stack.pop_back();
                int left = stack.empty() ? -1 : stack.back();
                best = max(best, height * (i - left - 1));
            }
            stack.push_back(i);
        }
        return best;
    }
};
