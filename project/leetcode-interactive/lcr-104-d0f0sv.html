组合总和 Ⅳ

不同排列视为不同组合：用一维动态规划统计每个目标和的方案数。

题意

给定不含重复元素的正整数数组 nums 和目标整数 target，返回和为 target 的不同排列数。

示例

nums = [1,2,3], target = 4
输出：7

约束

1 ≤ nums.length ≤ 200；1 ≤ nums[i] ≤ 1000；0 ≤ target ≤ 1000。

分步交互

准备计算。
点击下一步观察 dp[0] 到 dp[4]。

洞察与过程

令 dp[s] 表示和为 s 的排列数，dp[0]=1。枚举目标和 s，再枚举可作为最后一个数的 num：dp[s]+=dp[s-num]，循环顺序保证排列不同会分别计数。

边界与复杂度

target 为 0 时答案为 1；注意整数范围。时间 O(target·n)，空间 O(target)。

替代与追问

递归记忆化等价；若组合不区分顺序，应改为外层枚举 nums。

常见错误

  • 交换循环顺序，误算成无序组合。
  • 没有初始化 dp[0]。
  • 让负数参与而未限制序列长度，导致无限方案。

四语言代码

Java

class Solution { public int combinationSum4(int[] nums,int target){int[] dp=new int[target+1];dp[0]=1;for(int s=1;s<=target;s++)for(int n:nums)if(s>=n)dp[s]+=dp[s-n];return dp[target];} }

class Solution:
 def combinationSum4(self, nums, target):
  dp=[0]*(target+1); dp[0]=1
  for s in range(1,target+1):
   for n in nums:
    if s>=n: dp[s]+=dp[s-n]
  return dp[target]
