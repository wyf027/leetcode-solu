角矩形的数量

把每一行里的两个 1 看作一条“横边”。同一对列再次出现时，之前的每条横边都能和它闭合成一个矩形。

数组数学动态规划矩阵
750
Number Of Corner Rectangles
函数：countCornerRectangles(grid)

01 · Problem

题目说明

给定一个只含 0 和 1 的 m × n 矩阵 grid，返回其中角矩形的数量。

角矩形由四个互不相同且值都为 1 的格子组成；四个格子落在两条不同的行、两条不同的列上，矩形边与网格轴平行。矩形内部的值不影响计数。

也就是选择 r₁ < r₂ 和 c₁ < c₂；若四个交点全为 1，就得到一个矩形。

函数签名

countCornerRectangles(grid: integer[][]): integer

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 200
  • grid[i][j] 为 0 或 1
  • 矩阵中 1 的总数在 [1, 6000] 内

官方示例（完整参数形式）

输入grid = [[1,0,0,1,0],[0,0,1,0,1],[0,0,0,1,0],[1,0,1,0,1]]
输出1
说明唯一矩形的四角位于第 1、3 行（从 0 开始）和第 2、4 列。
输入grid = [[1,1,1],[1,1,1],[1,1,1]]
输出9
说明任选两行有 3 种，任选两列也有 3 种，共 3 × 3 = 9 个。
输入grid = [[1,1,1,1]]
输出0
说明只有一行，无法选出两条不同的行。

03 · Solution

准备好看完整题解了吗？

核心洞察、证明、复杂度、四语言代码、替代方案与面试追问都在下面。

题解：统计每一对列的历史横边

观察

一个矩形 = 两行共享同一列对

当前行在列 c₁、c₂ 都为 1，就提供一条候选横边。此前每一条相同列对的横边，都能与它闭合。

状态

seen[c₁][c₂]

表示当前行之前，有多少已扫描的行同时在这两列为 1，也就是该列对已有多少条横边。

转移

先结算，再登记

先做 answer += seen[c₁][c₂]，再令计数加一。这个顺序不会让当前行和自己配对。

完整过程

  1. 建立 n × n 的计数表 seen，答案初始为 0。
  2. 从上到下遍历每一行，枚举该行所有值为 1 的列对 (left,right)，且 left < right。
  3. 把 seen[left][right] 加入答案，它正好等于能与当前横边闭合的历史横边数。
  4. 执行 seen[left][right]++，登记当前行。
  5. 全部扫描完后返回答案。
answer += seen[left][right]; seen[left][right]++;

正确性证明

不会漏计：任取合法矩形。扫描到其下边所在行时，上边已登记在对应列对的 seen 中，因此该矩形会加入答案。

不会重复：矩形只在扫描到其下边时被计数；两行两列唯一确定它，不会在其他列对再次出现。

结论：每个合法矩形被恰好计数一次，算法正确。

Time

时间复杂度

若第 r 行有 kᵣ 个 1，实际为 Σ C(kᵣ,2)；最坏 O(m·n²)。

Space

空间复杂度

列对计数表占 O(n²) 空间。

Implementations

四语言完整代码

Java · LeetCode 可提交形式
class Solution {
    public int countCornerRectangles(int[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;
        int[][] seen = new int[cols][cols];
        int answer = 0;

        for (int r = 0; r < rows; r++) {
            for (int left = 0; left < cols; left++) {
                if (grid[r][left] == 0) continue;
                for (int right = left + 1; right < cols; right++) {
                    if (grid[r][right] == 1) {
                        answer += seen[left][right];
                        seen[left][right]++;
                    }
                }
            }
        }
        return answer;
    }
}

 * @param {number[][]} grid

var countCornerRectangles = function(grid) {
    const rows = grid.length;
    const cols = grid[0].length;
    const seen = Array.from(
        { length: cols },
        () => Array(cols).fill(0)
    );
    let answer = 0;

    for (let r = 0; r < rows; r++) {
        for (let left = 0; left < cols; left++) {
            if (grid[r][left] === 0) continue;
            for (let right = left + 1; right < cols; right++) {
                if (grid[r][right] === 1) {
                    answer += seen[left][right];
                    seen[left][right] += 1;
                }
            }
        }
    }
    return answer;
};

from typing import List


class Solution:
    def countCornerRectangles(self, grid: List[List[int]]) -> int:
        rows = len(grid)
        cols = len(grid[0])
        seen = [[0] * cols for _ in range(cols)]
        answer = 0

        for r in range(rows):
            for left in range(cols):
                if grid[r][left] == 0:
                    continue
                for right in range(left + 1, cols):
                    if grid[r][right] == 1:
                        answer += seen[left][right]
                        seen[left][right] += 1

        return answer

class Solution {
public:
    int countCornerRectangles(vector<vector<int>>& grid) {
        int rows = static_cast<int>(grid.size());
        int cols = static_cast<int>(grid[0].size());
        vector<vector<int>> seen(cols, vector<int>(cols, 0));
        int answer = 0;

        for (int r = 0; r < rows; ++r) {
            for (int left = 0; left < cols; ++left) {
                if (grid[r][left] == 0) continue;
                for (int right = left + 1; right < cols; ++right) {
                    if (grid[r][right] == 1) {
                        answer += seen[left][right];
                        ++seen[left][right];
                    }
                }
            }
        }
        return answer;
    }
};

边界情况

  • 少于 2 行或少于 2 列：答案必为 0。
  • 某行少于 2 个 1：该行不产生列对。
  • 全 1 矩阵：答案为 C(m,2) × C(n,2)。
  • 矩形可以重叠、共享边或共享角，仍分别计数。

替代方案

枚举行对：对每两行统计共同为 1 的列数 k，贡献 C(k,2)，复杂度 O(m²n)。

位集：把每行压成 bitset，行对求交并计数，常数更低，但实现更复杂。

面试追问

  • 列数远大于行数时，是否转置矩阵？
  • 极稀疏矩阵怎样只枚举为 1 的列？
  • 如何支持逐行流式输入？
  • 改为统计正方形时，状态还要保存什么？

常见错误

  • 先登记再加答案，导致当前行与自己配对。
  • 误把矩形内部也要求为 1。
  • 同时枚举 (a,b) 与 (b,a)。
  • 只记是否出现，不记出现次数。
