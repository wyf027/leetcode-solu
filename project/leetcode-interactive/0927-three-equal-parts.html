927. 三等分

Three Equal Parts · 把一个 0/1 数组切成三个非空部分，让三段代表同一个二进制数。

困难时间 O(n)空间 O(1)前导零允许

题目

给定仅含 0 和 1 的数组 arr，返回任意下标 [i, j]，满足 i + 1 < j，且三段 arr[0..i]、arr[i+1..j-1]、arr[j..n-1] 都非空，并表示相同的二进制值。无解返回 [-1, -1]。

注意：整段数组构成二进制数；允许前导零，所以 [0,1,1] 与 [1,1] 的值相同，但尾部零会改变数值。

函数签名

threeEqualParts(arr: number[]): number[]

约束

  • 3 ≤ arr.length ≤ 3 × 10⁴
  • arr[i] 只能是 0 或 1

官方示例

输入：arr = [1,0,1,0,1] 输出：[0,3]
输入：arr = [1,1,0,1,1] 输出：[-1,-1]
输入：arr = [1,1,0,0,1] 输出：[0,2]

先想一想

三个相等的非零二进制数，各自拥有的 1 数量必然相同。真正棘手的是：第三段末尾有多少个零，前两段就必须能容纳多少个尾随零。

同步指针实验室

输入 3–24 位二进制串。演示器先统计 1，再定位三段第一个 1，最后让三根指针同步向右；任何不同即无解。

可输入 10101 或 [1,0,1,0,1]。
第一段第二段第三段白框：正在比较

机制地图

① 可分性总 1 数必须能被 3 整除；全零数组是特例。
② 锚点找到第 1、k+1、2k+1 个 1，它们必须是三份有效表示的起点。
③ 同步比较从三个锚点同时前进，直到第三根指针越过数组末尾。

完整题解

核心洞察

忽略前导零后，三个相等二进制数的有效位串必须完全一致。设数组共有 ones 个 1：若它不是 3 的倍数则无解；若为 0，任意合法非空切法都成立，可返回 [0, 2]。否则每段恰含 k = ones / 3 个 1。

完整过程

  1. 统计数组中 1 的数量，处理不可整除与全零情况。
  2. 扫描数组，记录第 1、k+1、2k+1 个 1 的位置 first、second、third。
  3. 从三个位置同时向右比较。只要第三指针还在数组内，三处元素必须相同。
  4. 若全部相同，第三段已经把有效后缀（包括必要尾随零）比较完；切点为 [first-1, second]。前两段开头多出的零自然成为前导零。

正确性

必要性：相等的非零二进制值拥有相同数量的 1，因此总数须被 3 整除，三段有效表示分别从三个锚点开始。第三段一直延伸到数组末尾，故其有效后缀是目标模板；前两段必须逐位与之相同。

充分性：同步比较成功时，三个锚点到对应结尾的位串一致。切点前的额外字符只能是零，即允许的前导零，因此三段数值相等且非空。

边界与复杂度

  • 全零：返回 [0,2]。
  • 1 的数量不能三等分：立即失败。
  • 第三段尾随零过多：同步比较会越过前一段边界或产生不一致。
  • 时间复杂度 O(n)，额外空间 O(1)。

替代方案

也可以先数出第三段尾随零，再显式检查前两段是否有足够间隔并比较三段。这同样是 O(n)，但边界公式更容易写错。把第三段作为模板并同步推进，代码更短，也把“尾随零必须一致”自然包含在比较中。

常见错误

  • 只让三段拥有相同数量的 1，却没有比较位序与尾随零。
  • 把前导零与尾随零混为一谈；前导零不影响值，尾随零会乘以 2。
  • 返回锚点本身，忘了题目返回的是第一段末尾和第三段开头。
  • 全零时返回的切点导致某一段为空。

面试追问

  • 为什么同步比较的终止条件只看第三指针？因为第三段固定延伸到数组末尾，它定义了完整模板长度。
  • 如果要分成 m 个相等部分？先要求 1 的总数被 m 整除，定位每份首个 1，再让 m 根指针同步比较。
  • 能否转成整数比较？数组长达 3×10⁴，会溢出；字符串/逐位比较才安全。

四语言完整代码

class Solution {
    public int[] threeEqualParts(int[] arr) {
        int ones = 0;
        for (int bit : arr) ones += bit;
        if (ones == 0) return new int[]{0, 2};
        if (ones % 3 != 0) return new int[]{-1, -1};

        int k = ones / 3, first = -1, second = -1, third = -1;
        int seen = 0;
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == 1) {
                seen++;
                if (seen == 1) first = i;
                else if (seen == k + 1) second = i;
                else if (seen == 2 * k + 1) third = i;
            }
        }
        while (third < arr.length) {
            if (arr[first] != arr[second] || arr[first] != arr[third])
                return new int[]{-1, -1};
            first++; second++; third++;
        }
        return new int[]{first - 1, second};
    }
}

class Solution:
    def threeEqualParts(self, arr: List[int]) -> List[int]:
        ones = sum(arr)
        if ones == 0:
            return [0, 2]
        if ones % 3:
            return [-1, -1]

        k = ones // 3
        first = second = third = -1
        seen = 0
        for i, bit in enumerate(arr):
            if bit == 1:
                seen += 1
                if seen == 1:
                    first = i
                elif seen == k + 1:
                    second = i
                elif seen == 2 * k + 1:
                    third = i

        while third < len(arr):
            if not (arr[first] == arr[second] == arr[third]):
                return [-1, -1]
            first += 1
            second += 1
            third += 1
        return [first - 1, second]
