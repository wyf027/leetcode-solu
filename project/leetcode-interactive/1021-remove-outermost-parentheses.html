删除最外层的括号

Remove Outermost Parentheses —— 先观察每个字符经过时的“深度”，再决定它属于外壳，还是应该留在答案里。

字符串括号序列一次扫描O(n)

题目

有效括号字符串可以由空串、给有效串包一层括号，或连接两个有效串得到。若一个非空有效串不能拆成两个非空有效串，它就是一个原语。

给定非空有效括号字符串 s，把它唯一分解为若干原语；删除每个原语最外侧的一对括号，再连接剩余部分并返回。

函数：removeOuterParentheses(s: string): string

约束

  • 1 ≤ s.length ≤ 10⁵
  • s[i] 只可能是 '(' 或 ')'
  • s 保证是有效括号字符串

官方示例

输入：s = "(()())(())"
输出："()()()"
分解："(()())" + "(())" → "()()" + "()"
输入：s = "(()())(())(()(()))"
输出："()()()()(())"
分解："(()())" + "(())" + "(()(()))"
输入：s = "()()"
输出：""
两个原语各自去掉外层后都为空串。

题解：深度就是边界

核心洞察

扫描时维护当前嵌套深度 depth。一个左括号若出现于深度 0，它是某个原语的最外层左括号；一个右括号若让深度降到 0，它是最外层右括号。只跳过这两类字符，其余全部保留。

完整过程

  1. 初始化 depth = 0 和空答案。
  2. 遇到 '('：先判断当前深度；仅当 depth > 0 时加入答案，再令深度加一。
  3. 遇到 ')'：先令深度减一；仅当新深度 > 0 时加入答案。
  4. 扫描结束后返回答案。

正确性说明

每个原语开始前深度必为 0，因此其第一个左括号恰好被跳过；原语内部字符处理时深度始终大于 0，因此全部保留；其最后一个右括号使深度恰好归零，也被跳过。所有原语按扫描顺序处理，所以输出正是每个原语去掉最外层后依次连接的结果。

边界与复杂度

  • "()"：结果为空。
  • 多个原语相邻：深度每次归零即自动划界。
  • 深度嵌套很大：只用整数，不需要栈。
  • 时间 O(n)；除返回字符串外额外空间 O(1)（构造答案通常计 O(n)）。

常见错误

  • 右括号在减深度之前判断，误保留外层右括号。
  • 只删除整串首尾，忽略多个原语。
  • 用切片反复拼接，导致不必要开销。
  • 把“原语”误解为最深层括号。

替代方案

可以用栈模拟括号层级，或先找到每个深度归零的位置再对子串去首尾；两者都为 O(n)，但深度计数更直接、额外状态更少。

面试追问

  • 若输入不保证有效，如何同时校验？扫描中深度不能为负，结尾必须为 0。
  • 能否流式处理？可以；只需保存深度并逐字符输出，右括号要先更新深度。
  • 为什么不需要显式找出原语？因为深度从 0 开始、回到 0 已隐式标记其边界。

四语言实现

class Solution {
    public String removeOuterParentheses(String s) {
        StringBuilder answer = new StringBuilder();
        int depth = 0;
        for (char ch : s.toCharArray()) {
            if (ch == '(') {
                if (depth > 0) answer.append(ch);
                depth++;
            } else {
                depth--;
                if (depth > 0) answer.append(ch);
            }
        }
        return answer.toString();
    }
}
