Implement Trie
(Prefix Tree)

让每个节点代表一个共享前缀。沿着字母边走到节点不等于一个单词结束；isEnd 这枚终点标记，才区分 app 与 apple。

题意：实现一棵会记住“终点”的字典树

实现 Trie 类：

  • Trie()：初始化。
  • insert(word)：插入单词。
  • search(word)：单词此前已插入才返回 true。
  • startsWith(prefix)：已有任一单词以此前缀开始就返回 true。
约束：word 与 prefix 长度为 1–2000，只含小写英文字母；三种方法合计最多调用 30,000 次。
官方样例 
operations = ["Trie","insert","search",
              "search","startsWith","insert","search"]
arguments  = [[],["apple"],["apple"],
              ["app"],["app"],["app"],["app"]]
output     = [null,null,true,false,true,null,true]

插入 apple 后，app 的路径存在，所以 startsWith("app") 是 true；但它尚未是单词终点，search("app") 是 false。

题解区域

默认收起。先观察“路径存在”与“单词已结束”的差异。

核心洞察

每个节点持有从该前缀继续的子边，以及 isEnd。插入逐字符按需创建边，最后把末节点标记为终点；查询完整单词要同时走完整条路和检查终点；前缀查询只需走完整条路。

  1. 从根开始遍历字符。
  2. 插入时缺边就创建；查询时缺边立刻失败。
  3. 完整查询额外检查最后节点的 isEnd。

复杂度与边界

  • 三种操作的时间都是 O(L)，L 为参数长度。
  • 空间与所有已插入单词的不同前缀数成正比。
  • 重复插入不改变集合语义。
  • 短词是长词的前缀时，两个节点状态必须独立：app 与 apple。

替代方案

哈希集合能 O(1) 平均时间完成精确查询，但 startsWith 需要扫描键；排序数组可二分前缀区间，却不适合频繁插入。Trie 把共同前缀压缩为共享路径，适合自动补全、词典和 Word Search II。

常见错误与追问

错误：把“节点存在”当作 search 成功；忘记只在插入的末端设置 isEnd；数组下标没有用 c - 'a'。

追问：要支持删除？清除终点，并回收没有孩子的链。要支持 Unicode？把 26 位数组换成 Map。

class Trie {
  private static class Node { Node[] next = new Node[26]; boolean end; }
  private final Node root = new Node();
  public void insert(String word) {
    Node p = root; for (char c : word.toCharArray()) { int i = c - 'a'; if (p.next[i] == null) p.next[i] = new Node(); p = p.next[i]; } p.end = true;
  }
  private Node walk(String s) { Node p = root; for (char c : s.toCharArray()) { p = p.next[c - 'a']; if (p == null) return null; } return p; }
  public boolean search(String word) { Node p = walk(word); return p != null && p.end; }
  public boolean startsWith(String prefix) { return walk(prefix) != null; }
}

class Node:
    def __init__(self):
        self.next = [None] * 26
        self.end = False
class Trie:
    def __init__(self): self.root = Node()
    def insert(self, word):
        p = self.root
        for c in word:
            i = ord(c) - ord("a")
            if not p.next[i]: p.next[i] = Node()
            p = p.next[i]
        p.end = True
    def _walk(self, s):
        p = self.root
        for c in s:
            p = p.next[ord(c) - ord("a")]
            if not p: return None
        return p
    def search(self, word): return bool((p := self._walk(word)) and p.end)
    def startsWith(self, prefix): return self._walk(prefix) is not None
class Trie {
  struct Node { Node* next[26]{}; bool end = false; };
  Node* root = new Node();
  Node* walk(const string& s) { Node* p = root; for (char c : s) { p = p->next[c - 'a']; if (!p) return nullptr; } return p; }
public:
  void insert(string word) { Node* p = root; for (char c : word) { int i = c - 'a'; if (!p->next[i]) p->next[i] = new Node(); p = p->next[i]; } p->end = true; }
  bool search(string word) { Node* p = walk(word); return p && p->end; }
  bool startsWith(string prefix) { return walk(prefix) != nullptr; }
};
