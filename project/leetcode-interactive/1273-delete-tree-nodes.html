删除树节点Delete Tree Nodes

一棵树、一些正负节点值，以及一个看似简单的删除规则。先读题并亲手推进演示；完整推导会留在页面底部，默认不展开。

0

关键条件：若某个节点所代表的整棵子树，其节点值总和为零，就删除这棵子树。

Problem

题目说明

参数形式：deleteTreeNodes(nodes, parent, value)

给定一棵以节点 0 为根的树，共有 nodes 个节点。parent[i] 表示节点 i 的父节点，value[i] 表示该节点的整数值；根节点用父节点 -1 表示。

删除所有节点值之和等于 0 的子树。一旦删除某棵子树，其中全部节点都不再计入答案。返回最终剩余的节点数量。

示例 1

输入：nodes = 7 parent = [-1,0,0,1,2,2,2] value = [1,-2,4,0,-2,-1,-1]

输出：2

节点 3 的和为 0；节点 2 所在子树的总和也为 0，最终只剩节点 0 与 1。

示例 2

输入：nodes = 7 parent = [-1,0,0,1,2,2,2] value = [1,-2,4,0,-2,-1,-2]

输出：6

节点 3 单独构成的子树和为 0，因此只删除该节点。

约束

  • 1 ≤ nodes ≤ 10⁴
  • parent.length == nodes
  • parent[0] == -1
  • 对 i > 0，父节点编号合法
  • value.length == nodes
  • -10⁵ ≤ value[i] ≤ 10⁵
  • 输入保证构成一棵合法树

Full solution

后序遍历，一次结算两份信息

核心洞察

父节点的子树总和必须等所有孩子都结算后才能确定，所以处理顺序应当是孩子先、父节点后。每个节点同时维护两项信息：原始子树总和 sum，以及执行删除规则后仍保留的节点数 kept。

若 sum == 0，把 kept 置为 0。零和子树即使被删除，对祖先总和的贡献仍是 0，因此总和可以自然向上累加。

  1. 根据 parent 构建孩子列表。
  2. 从根出发得到遍历序列，再逆序处理，形成迭代式后序。
  3. 初始化每个节点的 sum = value[i]、kept = 1。
  4. 处理节点时，若总和为 0 就清空其保留数；随后把总和与保留数贡献给父节点。
  5. 根节点的 kept 即答案。

正确性说明

归纳不变式：当节点 u 被处理时，它的所有孩子都已处理完；此时 sum[u] 等于以 u 为根的原始子树值之和，kept[u] 是其孩子按规则删除后，加上节点 u 的保留数。

叶节点显然满足。假设所有孩子满足不变式，把孩子总和与保留数加到 u 后，二者分别覆盖整棵子树。若总和为 0，题意要求删除整棵子树，令保留数为 0 正确；否则保留当前结果也正确。由树上的归纳，根节点结果正确。

时间复杂度O(n)每个节点入栈、结算各一次
空间复杂度O(n)孩子表、顺序与状态数组

边界情况

单节点树；根的总和为 0（答案为 0）；零值叶节点；一条长度接近 10⁴ 的链；正负值相互抵消；节点编号不按层序排列。实现使用迭代遍历，避免依赖递归栈深度。

Javalong 保存子树和
class Solution {
    public int deleteTreeNodes(int nodes, int[] parent, int[] value) {
        java.util.List<Integer>[] children = new java.util.ArrayList[nodes];
        for (int i = 0; i < nodes; i++) children[i] = new java.util.ArrayList<>();
        for (int i = 1; i < nodes; i++) children[parent[i]].add(i);

        int[] order = new int[nodes];
        int[] stack = new int[nodes];
        int orderSize = 0, stackSize = 0;
        stack[stackSize++] = 0;
        while (stackSize > 0) {
            int u = stack[--stackSize];
            order[orderSize++] = u;
            for (int child : children[u]) stack[stackSize++] = child;
        }

        long[] sum = new long[nodes];
        int[] kept = new int[nodes];
        for (int i = 0; i < nodes; i++) {
            sum[i] = value[i];
            kept[i] = 1;
        }

        for (int i = nodes - 1; i >= 0; i--) {
            int u = order[i];
            if (sum[u] == 0) kept[u] = 0;
            if (parent[u] != -1) {
                sum[parent[u]] += sum[u];
                kept[parent[u]] += kept[u];
            }
        }
        return kept[0];
    }
}
JavaScriptArray + iterative stack
/**
 * @param {number} nodes
 * @param {number[]} parent
 * @param {number[]} value
 * @return {number}
 */
var deleteTreeNodes = function(nodes, parent, value) {
    const children = Array.from({ length: nodes }, () => []);
    for (let i = 1; i < nodes; i++) children[parent[i]].push(i);

    const order = [];
    const stack = [0];
    while (stack.length) {
        const u = stack.pop();
        order.push(u);
        for (const child of children[u]) stack.push(child);
    }

    const sum = value.slice();
    const kept = Array(nodes).fill(1);
    for (let i = order.length - 1; i >= 0; i--) {
        const u = order[i];
        if (sum[u] === 0) kept[u] = 0;
        if (parent[u] !== -1) {
            sum[parent[u]] += sum[u];
            kept[parent[u]] += kept[u];
        }
    }
    return kept[0];
};
Pythonlist + reversed order
from typing import List


class Solution:
    def deleteTreeNodes(
        self, nodes: int, parent: List[int], value: List[int]
    ) -> int:
        children = [[] for _ in range(nodes)]
        for child in range(1, nodes):
            children[parent[child]].append(child)

        order = []
        stack = [0]
        while stack:
            node = stack.pop()
            order.append(node)
            stack.extend(children[node])

        subtree_sum = value[:]
        kept = [1] * nodes
        for node in reversed(order):
            if subtree_sum[node] == 0:
                kept[node] = 0
            par = parent[node]
            if par != -1:
                subtree_sum[par] += subtree_sum[node]
                kept[par] += kept[node]

        return kept[0]
C++long long 保存子树和
class Solution {
public:
    int deleteTreeNodes(int nodes, vector<int>& parent, vector<int>& value) {
        vector<vector<int>> children(nodes);
        for (int i = 1; i < nodes; ++i) children[parent[i]].push_back(i);

        vector<int> order;
        order.reserve(nodes);
        vector<int> stack = {0};
        while (!stack.empty()) {
            int u = stack.back();
            stack.pop_back();
            order.push_back(u);
            for (int child : children[u]) stack.push_back(child);
        }

        vector<long long> sum(value.begin(), value.end());
        vector<int> kept(nodes, 1);
        for (int i = nodes - 1; i >= 0; --i) {
            int u = order[i];
            if (sum[u] == 0) kept[u] = 0;
            if (parent[u] != -1) {
                sum[parent[u]] += sum[u];
                kept[parent[u]] += kept[u];
            }
        }
        return kept[0];
    }
};

替代方案

递归 DFS：函数返回 [子树和, 保留数]，写法更短，也直接对应归纳证明；但极深的链可能触及语言的递归栈限制。

按父子关系向上累加：若额外确认父节点编号总小于子节点编号，可从后向前扫描数组；但题目只保证是合法树，通用实现不应依赖这个未声明条件。

面试追问

Q：为什么删除内部零和子树不会改变祖先是否为零和？
A：它对祖先的数值贡献本来就是 0，删除前后祖先总和相同。

Q：若条件改为“子树和小于 0”呢？
A：删除会移除一个非零贡献，祖先总和随之改变；必须明确删除时序，当前的一次原始子树求和不再直接适用。

常见错误

  • 只删除零值节点。
    条件看的是整棵子树总和，不是单点值。
  • 在孩子未结算前判断父节点。
    父节点需要完整的后序信息。
  • 把已删零和子树从祖先总和中重复扣除。
    它的贡献为 0，无需再改祖先总和。
  • 默认 parent 数组天然就是后序。
    先构图并显式生成遍历顺序更稳妥。
