二叉树的后序遍历 双相栈帧

每个节点先以“展开”栈帧进入，再以“回收”栈帧返回；只有回收时才输出， 因此天然得到“左 → 右 → 根”。

任务边界

输入是二叉树根节点 root，返回节点值的后序序列。 节点数 0～100，节点值 −100～100；空树返回空数组。

Problem / 题意

按“左、右、根”访问所有节点

给定二叉树根节点，返回它的后序遍历结果。主线使用带访问标记的显式栈： 首次弹出时安排“根回收、右展开、左展开”，第二次弹出同一节点才输出。

官方示例 1
root = [1,null,2,3]

输出：[3,2,1]

官方示例 2
root = [1,2,3,4,5,null,8,null,null,6,7,9]

输出：[4,6,7,5,2,9,8,3,1]

关键边界
root = [1]

输出：[1]

核心洞察

栈帧分两相：先展开孩子，后回收根节点

后序遍历不能在第一次见到根时输出。首次弹出节点时依次压入“已访问根”、 右孩子、左孩子；左、右子树完成后，“已访问根”才会回到栈顶并输出。

完整过程

  1. 空树直接返回空列表。
  2. 将根节点以“未访问”栈帧压栈。
  3. 弹出未访问节点时，压入已访问根、右孩子、左孩子。
  4. 弹出已访问节点时输出它，直到栈空。

边界与复杂度

  • 空树返回 []；单节点返回自身值。
  • 极度倾斜树的栈空间为 O(n)。
  • 时间 O(n)，空间 O(h)，h 为树高。

替代方案取舍

递归写法更短，但会隐式占用调用栈；Morris 遍历可做到 O(1) 额外空间，却会临时修改树且更难解释。面试主线推荐显式栈。

常见错误

  • 首次见到节点就输出，会退化成前序遍历。
  • 压栈顺序写成根、左、右，弹栈执行顺序会完全相反。
  • 空 root 仍直接入栈，引发空指针。
  • 误用队列，得到层序遍历。

面试追问

为什么根要压两次？第一次安排子任务，第二次代表子树已完成。
递归复杂度如何算？时间 O(n)，隐式栈最坏 O(n)。
能否用两个栈？可以先得到根、右、左，再逆序，但多一次反转。 
public class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;
        Deque<TreeNode> nodes = new ArrayDeque<>();
        Deque<Boolean> visited = new ArrayDeque<>();
        nodes.push(root);
        visited.push(false);
        while (!nodes.isEmpty()) {
            TreeNode node = nodes.pop();
            boolean seen = visited.pop();
            if (seen) {
                result.add(node.val);
                continue;
            }
            nodes.push(node);
            visited.push(true);
            if (node.right != null) {
                nodes.push(node.right);
                visited.push(false);
            }
            if (node.left != null) {
                nodes.push(node.left);
                visited.push(false);
            }
        }
        return result;
    }
}
var postorderTraversal = function (root) {
  if (root === null) return [];
  const result = [];
  const stack = [[root, false]];
  while (stack.length > 0) {
    const [node, seen] = stack.pop();
    if (seen) {
      result.push(node.val);
      continue;
    }
    stack.push([node, true]);
    if (node.right !== null) stack.push([node.right, false]);
    if (node.left !== null) stack.push([node.left, false]);
  }
  return result;
};

public:
    vector<int> postorderTraversal(TreeNode* root) {
        if (root == nullptr) return {};
        vector<int> result;
        stack<pair<TreeNode*, bool>> frames;
        frames.push({root, false});
        while (!frames.empty()) {
            auto [node, seen] = frames.top();
            frames.pop();
            if (seen) {
                result.push_back(node->val);
                continue;
            }
            frames.push({node, true});
            if (node->right != nullptr) frames.push({node->right, false});
            if (node->left != nullptr) frames.push({node->left, false});
        }
        return result;
    }
