Nested List Weight Sum II

嵌套列表
加权和 II

给定一个由整数与嵌套列表组成的列表 nestedList。整数的深度是它被多少层列表包围；设所有整数的最大深度为 maxDepth，深度为 depth 的整数权重为 maxDepth - depth + 1。返回每个整数乘以自身权重后的总和。

示例与约束

示例 1

输入：nestedList = [[1,1],2,[1,1]]输出：8

最大深度为 2。四个 1 的权重为 1，整数 2 的权重为 2。

示例 2

输入：nestedList = [1,[4,[6]]]输出：17

1×3 + 4×2 + 6×1 = 17。

约束

  • 1 <= nestedList.length <= 50
  • 嵌套列表中整数的值在 [-100, 100] 范围内。
  • 任意整数的最大深度不超过 50。

Solution · Breadth-first accumulation

不先求最大深度，也能算反向权重

逐层遍历时，把“截至当前层遇到的全部整数之和”加入答案。浅层整数进入累计和更早，因此会被加入更多次；最深层整数只在最后一次被加入，恰好对应反向权重。

核心洞察

维护 unweighted：从第 1 层到当前层的所有整数之和；每处理完一层，执行 weighted += unweighted。

深度为 d 的整数从第 d 层开始，一直参与到第 maxDepth 层，共出现 maxDepth - d + 1 次，正好就是它的权重。

完整过程

  1. 令当前层为顶层元素，两个累计值均为 0。
  2. 扫描当前层：整数加入 unweighted；子列表元素加入下一层队列。
  3. 当前层结束后执行 weighted += unweighted。
  4. 切换到下一层，直到队列为空，返回 weighted。

正确性证明

  1. 层级不变式：处理完第 k 层后，unweighted 等于深度不超过 k 的全部整数之和。初始为 0；扫描新一层时只新增该层整数，因此不变式保持。
  2. 单个整数的贡献：任取值为 x、深度为 d 的整数。它在第 d, d+1, …, maxDepth 层结束时各被加入答案一次，共 maxDepth - d + 1 次。
  3. 结论：该整数贡献为 x × (maxDepth - d + 1)。对所有整数求和，正好得到题目定义的答案。

边界情况

  • 只有一层：所有权重均为 1。
  • 负数或 0：正常参与线性加法，不需特殊分支。
  • 空子列表：不产生下一层元素，也不贡献数值。
  • 链式深嵌套：迭代 BFS 不依赖递归栈。

复杂度

设整数与列表节点总数为 N，最宽一层节点数为 W。

  • 时间复杂度：O(N)，每个节点访问一次。
  • 空间复杂度：O(W)，最坏为 O(N)。

class Solution {
    public int depthSumInverse(List<NestedInteger> nestedList) {
        int unweighted = 0;
        int weighted = 0;
        List<NestedInteger> level = nestedList;

        while (!level.isEmpty()) {
            List<NestedInteger> nextLevel = new ArrayList<>();
            for (NestedInteger item : level) {
                if (item.isInteger()) {
                    unweighted += item.getInteger();
                } else {
                    nextLevel.addAll(item.getList());
                }
            }
            weighted += unweighted;
            level = nextLevel;
        }
        return weighted;
    }
}

替代方案

可以 DFS 两遍：第一遍求 maxDepth，第二遍按定义累加；也可以一次 DFS 记录各层的整数和，最后逆序计算权重。它们同样是 O(N)，但需要显式保存或先获得最大深度。

本题的 BFS 累计法直接利用“浅层贡献会跨越更多后续层”，无需预先知道最大深度。

面试追问

  • 如果权重变成 depth²，如何调整状态？
  • 输入是流式的、无法保留整层时，能否改用 DFS？
  • 嵌套深度远超递归栈限制时，哪种实现更稳健？
  • 如何证明一次累计等价于给浅层整数增加一份贡献？

常见错误

  • 把题 339 的普通深度权重直接套用。
  • 每层开始前就累加答案，导致最深层漏算。
  • 把子列表本身放入下一层，而没有展开其元素。
  • 遇到负数时错误清空累计和。
  • 把空子列表误认为数值节点。
  • DFS 求的是列表深度，而非整数的最大深度。
一句话记忆： 每层都把“到目前为止见过的整数总和”再加一次，浅层整数自然会被加更多次。
