打开转盘锁

每次旋转一个拨轮一格。把每一种密码看作图上的节点，BFS 自然找到最少旋转次数。

开始演示

题意

初始密码为 0000。每次可将四位密码中任意一位向上或向下旋转一格；给出禁用密码 deadends 与目标 target，返回到达目标的最少旋转次数，无法到达返回 -1。

示例

deadends = ["0201","0101","0102","1212","2002"]
target = "0202"
输出：6

约束

  • 1 <= deadends.length <= 500
  • target.length == 4，每位均为数字。
  • 转盘共有 104 个可能状态。

核心洞察

每次操作的代价相同，最短路径就是 BFS 的层数。访问过的状态不能再次入队，禁用状态也不能入队。

邻居：每个状态有 4 × 2 = 8 个候选邻居；9 向上转回 0，0 向下转回 9。

分步交互

从 0000 出发，观察 BFS 第一层生成的可达密码。

快捷键：Enter

完整过程

  1. 将禁用密码放入集合；若 0000 被禁用，直接返回 -1。
  2. 队列从 0000 开始，按层取出状态。
  3. 对每个拨轮生成向上、向下两个邻居；未访问且非禁用时入队。
  4. 第一次取到目标时，当前层数就是最短步数。

边界

  • 目标为 0000 时返回 0（前提是起点可用）。
  • 必须在入队时标记访问，避免同层重复入队。
  • 使用字符串能保留前导零，如 0009。

复杂度

状态数至多 104，时间 O(104 × 8)。

空间 O(104) 用于队列和访问集合。

替代方案

双向 BFS 同时从起点与目标扩展，通常能显著减少搜索范围；实现时仍需避开禁用状态并维护两侧访问集。

class Solution {
    public int openLock(String[] deadends, String target) {
        Set<String> bad = new HashSet<>(Arrays.asList(deadends));
        if (bad.contains("0000")) return -1;
        Queue<String> q = new ArrayDeque<>(); q.offer("0000");
        Set<String> seen = new HashSet<>(); seen.add("0000");
        for (int step = 0; !q.isEmpty(); step++) for (int n = q.size(); n > 0; n--) {
            String cur = q.poll(); if (cur.equals(target)) return step;
            for (String next : nexts(cur)) if (!bad.contains(next) && seen.add(next)) q.offer(next);
        } return -1;
    }
    private List<String> nexts(String s) { List<String> ans = new ArrayList<>(); for (int i = 0; i < 4; i++) { char[] a=s.toCharArray(); a[i]=(char)((a[i]-'0'+1)%10+'0'); ans.add(new String(a)); a=s.toCharArray(); a[i]=(char)((a[i]-'0'+9)%10+'0'); ans.add(new String(a)); } return ans; }
}

追问与常见错误

追问

为什么双向 BFS 更快？深度各减半，访问节点从约 bd 降到约 2bd/2。

常见错误

  • 忽略起点就是禁用状态。
  • 把字符串转整数后丢失前导零。
  • 在出队而非入队时才标记，导致队列膨胀。

测试与验证区

建议覆盖目标为起点、起点禁用、单步可达、多条同长度路径与不可达目标。
