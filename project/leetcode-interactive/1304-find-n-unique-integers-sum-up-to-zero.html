完整题解

核心思路、证明、实现与追问都藏在这里。

核心洞察：对每个正整数 i 同时放入 i 与 -i，二者之和天然为 0；如果 n 是奇数，再加入不会改变总和的 0。

完整过程

  1. 令 pairs = floor(n / 2)。
  2. 对 i = 1…pairs，把 i 和 -i 放入答案。
  3. 若 n 为奇数，再放入 0。
  4. 返回答案；题目接受任意满足条件的排列。

正确性证明

每一对 (i, -i) 的和为 0，因此所有数对的总和仍为 0。奇数情形额外加入的 0 不改变总和。正数之间互异、负数之间互异，正负数符号不同，0 也不属于任何数对，所以所有元素均不相同。偶数 n 产生 n 个元素；奇数 n 产生 n - 1 个配对元素再加 0，也恰好为 n 个。

边界与复杂度

  • n = 1：没有数对，仅返回 [0]。
  • n 为偶数：只需相反数对，不加入 0。
  • 时间复杂度：O(n)，必须写出 n 个结果。
  • 额外空间：不计返回数组为 O(1)；计入答案为 O(n)。

替代方案

也可以先写入 1, 2, …, n - 1，最后写入它们总和的相反数。该数是负数，不会与前面的正数重复，同样满足要求。不过相反数配对法的正确性更直观，也避免中间和随 n 增长。

面试追问

  • 为什么输出顺序不影响正确性？题目只约束个数、唯一性与总和。
  • 能否做到常数额外空间？可以，输出数组本身不计入额外空间时是 O(1)。
  • 若要求元素都非零怎么办？奇数 n 不可能：奇数个非零整数仍可能和为零，但简单配对需更一般构造，例如 n=3 可用 -3,1,2；需改用前 n-1 个正数加负总和。

常见错误

  • 把 0 加入偶数 n 的答案，导致数量多 1。
  • 循环到 n 而非 floor(n / 2)，导致返回过多元素。
  • 只检查总和，忽略“所有整数互不相同”。
  • 误以为必须返回与示例完全相同的数组。

四语言实现

class Solution {
    public int[] sumZero(int n) {
        int[] answer = new int[n];
        int index = 0;

        for (int value = 1; value <= n / 2; value++) {
            answer[index++] = value;
            answer[index++] = -value;
        }

        if (n % 2 == 1) {
            answer[index] = 0;
        }
        return answer;
    }
}
/**
 * @param {number} n
 * @return {number[]}
 */
var sumZero = function(n) {
    const answer = [];

    for (let value = 1; value <= Math.floor(n / 2); value++) {
        answer.push(value, -value);
    }

    if (n % 2 === 1) {
        answer.push(0);
    }
    return answer;
};
from typing import List


class Solution:
    def sumZero(self, n: int) -> List[int]:
        answer: List[int] = []

        for value in range(1, n // 2 + 1):
            answer.extend((value, -value))

        if n % 2 == 1:
            answer.append(0)
        return answer

public:
