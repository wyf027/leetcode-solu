困难贪心字符串 · 区间

LeetCode #1520

最多的不重叠
子字符串

先把字符的“影响范围”扩张成合法区间，再用最早结束的区间为答案腾出最多空间。动手走一遍，比背结论更有效。

Problem

题意

给定仅含小写英文字母的字符串 s。选出尽可能多的非空子字符串，使任意两个互不重叠；并且，只要某个选中子字符串含有字符 c，它就必须覆盖 c 在整个 s 中的所有出现位置。

若能选出的数量相同，返回总长度最小的那组。最小总长度的解唯一，返回顺序不限。

示例 1
输入：s = "adefaddaccc"
输出：["e","f","ccc"]

单独选择 e、f、ccc 可得到 3 段；选择更大的 adefadda 只会压缩后续空间。

示例 2
输入：s = "abbaccd"
输出：["d","bb","cc"]

["abba","cc","d"] 数量也是 3，但总长度更长，因此不是所求的唯一最短解。

约束

  • 1 <= s.length <= 10^5
  • s 只包含小写英文字母。

Solution

闭包区间 + 最早结束贪心

核心洞察

先记录每个字符的首次位置 first[c] 与末次位置 last[c]。合法子串一旦包含字符 c，就不得漏掉区间 [first[c], last[c]]。因此从某字符的首次位置 L 出发，右边界会被区间内遇到的字符不断推远，直至形成闭包。

扩张时若遇到字符 x 满足 first[x] < L，说明要完整包含 x 必须向左越过起点；以 L 开始的候选就无效。合法闭包按起点从左到右出现后，采用经典区间调度：总是保留结束位置更早的区间。实现时，新候选与上个已选区间不重叠就追加；若重叠，合法闭包的嵌套性质保证新候选更紧，可替换最后一个。

完整过程

  1. 两次信息在一次扫描中得到：26 个字母的首次、末次出现位置。
  2. 只在 i == first[s[i]] 时尝试构造候选。令 R = last[s[i]]，扫描 j = i..R。
  3. 若 first[s[j]] < i，候选无效；否则更新 R = max(R, last[s[j]])。
  4. 候选合法时：若 i > end，加入答案；否则用它替换最后一个答案。更新 end = R。
候选合法 ⇔ ∀ j ∈ [L,R]，first[s[j]] ≥ L；同时 R = max(last[s[j]]) 直到闭包稳定

正确性

引理 1：扩张成功得到的 [L,R] 合法。扫描覆盖区间中每种字符；其首次位置不在 L 左侧，末次位置又被 R 覆盖，所以所有出现都在区间内。

引理 2：每个最紧合法子串都能由其最左字符的首次位置构造出来；因此算法不会漏掉可能改善最优解的候选。

贪心：对重叠候选，保留结束更早者不会减少右侧还能选择的区间数；若数量相同，较短的内层区间也使总长度更小。反复交换后得到最大数量，且在该数量下总长度最小。

边界情况

  • 单字符或所有字符相同：答案就是整个字符串。
  • 所有字符互异：每个字符自身都是答案。
  • 闭包连锁扩张：一个字符的末次位置可能引入另一个字符，必须动态延长 R。
  • 扩张遇到首次位置在 L 左侧的字符：立即判无效，不能只扩大右边界。

复杂度

预处理 O(n)。最多从 26 个字符的首次位置扩张，每次至多扫描 n，即 O(26n) = O(n)；额外空间 O(26)（不计答案）。

替代方案

也可以先生成全部合法闭包区间，按右端点升序排序，再做标准区间调度。它更贴近教科书证明，复杂度为 O(n + k log k)，其中 k ≤ 26。在线替换写法省去显式排序。

面试追问

  • 为什么候选最多只有 26 个？因为只有字符首次出现的位置可作为最紧闭包的左端点。
  • 若字符集不再固定为 26 个小写字母？用哈希表保存 first / last，复杂度变为与不同字符数相关。
  • 为何替换最后一段而不是直接丢弃当前段？当前闭包在重叠结构中结束更早且更短，替换能保留数量并优化总长度。

常见错误

  • 只用每个字符最初的 [first,last]，忘记对区间内其他字符做传递闭包。
  • 遇到 first[x] < L 仍继续，生成违反“包含全部出现”的伪区间。
  • 对重叠候选一律跳过，没有用更早结束的新候选替换旧候选。
  • 复杂度误写为 O(n²)；固定小写字母表使起点最多 26 个。

class Solution {
    public List<String> maxNumOfSubstrings(String s) {
        int[] first = new int[26], last = new int[26];
        Arrays.fill(first, -1);
        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i) - 'a';
            if (first[c] == -1) first[c] = i;
            last[c] = i;
        }

        List<String> ans = new ArrayList<>();
        int end = -1;
        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i) - 'a';
            if (i != first[c]) continue;
            int right = expand(s, i, first, last);
            if (right == -1) continue;
            if (i > end) ans.add("");
            ans.set(ans.size() - 1, s.substring(i, right + 1));
            end = right;
        }
        return ans;
    }

    private int expand(String s, int left, int[] first, int[] last) {
        int right = last[s.charAt(left) - 'a'];
        for (int i = left; i <= right; i++) {
            int c = s.charAt(i) - 'a';
            if (first[c] < left) return -1;
            right = Math.max(right, last[c]);
        }
        return right;
    }
}

var maxNumOfSubstrings = function(s) {
    const first = Array(26).fill(-1);
    const last = Array(26).fill(-1);
    for (let i = 0; i < s.length; i++) {
        const c = s.charCodeAt(i) - 97;
        if (first[c] === -1) first[c] = i;
        last[c] = i;
    }

    const ans = [];
    let end = -1;
    for (let left = 0; left < s.length; left++) {
        const startChar = s.charCodeAt(left) - 97;
        if (left !== first[startChar]) continue;
        let right = last[startChar];
        let valid = true;
        for (let i = left; i <= right; i++) {
            const c = s.charCodeAt(i) - 97;
            if (first[c] < left) {
                valid = false;
                break;
            }
            right = Math.max(right, last[c]);
        }
        if (!valid) continue;
        if (left > end) ans.push("");
        ans[ans.length - 1] = s.slice(left, right + 1);
        end = right;
    }
    return ans;
};
from typing import List


class Solution:
    def maxNumOfSubstrings(self, s: str) -> List[str]:
        first = [-1] * 26
        last = [-1] * 26
        for i, ch in enumerate(s):
            c = ord(ch) - ord('a')
            if first[c] == -1:
                first[c] = i
            last[c] = i

        answer: List[str] = []
        end = -1
        for left, ch in enumerate(s):
            start_char = ord(ch) - ord('a')
            if left != first[start_char]:
                continue

            right = last[start_char]
            i = left
            valid = True
            while i <= right:
                c = ord(s[i]) - ord('a')
                if first[c] < left:
                    valid = False
                    break
                right = max(right, last[c])
                i += 1

            if not valid:
                continue
            if left > end:
                answer.append("")
            answer[-1] = s[left:right + 1]
            end = right
        return answer
class Solution {
public:
    vector<string> maxNumOfSubstrings(string s) {
        vector<int> first(26, -1), last(26, -1);
        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            int c = s[i] - 'a';
            if (first[c] == -1) first[c] = i;
            last[c] = i;
        }

        vector<string> answer;
        int end = -1;
        for (int left = 0; left < static_cast<int>(s.size()); ++left) {
            int startChar = s[left] - 'a';
            if (left != first[startChar]) continue;
            int right = last[startChar];
            bool valid = true;
            for (int i = left; i <= right; ++i) {
                int c = s[i] - 'a';
                if (first[c] < left) {
                    valid = false;
                    break;
                }
                right = max(right, last[c]);
            }
            if (!valid) continue;
            if (left > end) answer.emplace_back();
            answer.back() = s.substr(left, right - left + 1);
            end = right;
        }
        return answer;
    }
};
