Binary Search Tree to Greater Sum Tree

题目

给定二叉搜索树 root，将每个节点的值替换成原树中所有大于或等于该节点值的节点值之和，并返回根节点。BST 的左子树键值更小、右子树键值更大，两侧也都是 BST。

函数签名

bstToGst(root: TreeNode) -> TreeNode

示例 1

输入：root = [4,1,6,0,2,5,7,null,null,null,3,null,null,null,8] 输出：[30,36,21,36,35,26,15,null,null,null,33,null,null,null,8]

示例 2

输入：root = [0,null,1] 输出：[1,null,1]

约束

  • 节点数在 [1, 100] 内。
  • 0 ≤ Node.val ≤ 100。
  • 所有节点值互不相同。

题解：逆中序遍历

核心洞察

BST 的中序遍历是升序。反向采用右 → 根 → 左，就会从最大值走到最小值。维护累加和 sum：到达节点时先加入它的原值，再用 sum 覆盖节点，正好得到所有大于或等于当前值的键值之和。

完整过程

  1. 递归访问右子树。
  2. 执行 sum += node.val，再令 node.val = sum。
  3. 递归访问左子树，最终返回原根节点。

正确性

逆中序到达某节点时，比它大的节点已经且仅已被访问。因此累加器保存全部更大键值的和；加入当前原值后即为该节点的目标值。遍历覆盖每个节点，故整棵树转换正确，且结构不变。

复杂度与边界

时间 O(n)，递归栈 O(h)。单节点保持不变；倾斜树的递归深度可达 n；节点值为 0 时算法同样成立。

替代方案

显式栈迭代逆中序仍为 O(n) 时间、O(h) 空间，可规避深递归。收集中序数组再算后缀和更直观，但要 O(n) 额外空间。

常见错误

  • 误用左 → 根 → 右，算成较小值的前缀和。
  • 覆盖节点后才累加，丢失原值。
  • 每次递归都重新初始化累加器。
