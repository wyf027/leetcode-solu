验证图书取出顺序

先读题、再亲手推进。首屏不展示题解；下方的交互器会在你主动开始后逐步呈现过程。

题意

图书馆的一排图书将按 pushed 的顺序依次放入书车。请判断 popped 是否可能是该书车的一种取出顺序。

示例 1

pushed = [1,2,3,4,5]
popped = [4,5,3,2,1]

输出：true

示例 2

pushed = [1,2,3,4,5]
popped = [4,3,5,1,2]

输出：false

约束

  • 0 ≤ pushed.length ≤ 1000
  • 0 ≤ popped.length ≤ 1000
  • pushed 是 [0, 1000] 范围内的任意排列；两个数组长度相等。

题解与代码

洞察

书车只允许在顶部取书。按入库顺序逐本放入；只要顶部正好等于下一本期望取出的书，就立即取出。这样不会错过任何合法的取出时机。

过程

  1. 维护一个模拟书车与指向下一本目标取出书的指针。
  2. 遍历 pushed，每本书放入书车。
  3. 顶部匹配目标时持续取出，并移动目标指针。
  4. 最后目标指针到达末尾即为合法。

边界与常见错误

  • 空数组是合法顺序。
  • 匹配应使用 while，而非只取出一次。
  • 不能跳过书车顶部直接取更深处的书。

复杂度与替代方案

时间 O(n)，额外空间 O(n)。可用数组充当书车；无需回溯或枚举排列。

追问

若输入不保证是相同元素集合，应先校验长度与元素集合；本题约束已保证排列条件。 

// Java
class Solution {
    public boolean validateStackSequences(int[] pushed, int[] popped) {
        Deque<Integer> stack = new ArrayDeque<>(); int j = 0;
        for (int x : pushed) { stack.push(x); while (!stack.isEmpty() && stack.peek() == popped[j]) { stack.pop(); j++; } }
        return j == popped.length;
    }
}

class Solution {
public:
    bool validateStackSequences(vector<int>& pushed, vector<int>& popped) {

        for (int x : pushed) { st.push_back(x); while (!st.empty() && st.back() == popped[j]) { st.pop_back(); ++j; } }
