题目 · 同一顺序，两份排列

给定两个从下标 0 开始、长度同为 n 的整数数组 nums1 与 nums2，每个数组恰好包含一次 0 到 n − 1 的所有整数。选择三个互不相同的值 (x, y, z)，如果它们在两个数组中都按 x、y、z 的顺序出现，则称其为好三元组。返回这样的三元组总数。

pos1[x] < pos1[y] < pos1[z]
pos2[x] < pos2[y] < pos2[z]

比较的是出现位置，不要求 x < y < z，也不要求三个元素相邻。

约束

  • n == nums1.length == nums2.length
  • 3 ≤ n ≤ 100000
  • 0 ≤ nums1[i], nums2[i] ≤ n − 1
  • 两个数组均为 [0, 1, ..., n − 1] 的排列。

官方示例

EXAMPLE 01
nums1 = [2,0,1,3]
nums2 = [0,1,2,3]
输出 = 1

按 nums1 的顺序可取 (2,0,1)、(2,0,3)、(2,1,3)、(0,1,3)。只有 (0,1,3) 在 nums2 中也保持同样顺序。

EXAMPLE 02
nums1 = [4,0,1,3,2]
nums2 = [4,1,0,2,3]
输出 = 4

四个好三元组为 (4,0,3)、(4,0,2)、(4,1,3)、(4,1,2)。数值 4 可以排在三元组最前面。

独立题解

核心洞察 · 把两个顺序合成一个坐标系

记录 pos[v] 为值 v 在 nums2 中的下标。按 nums1 的顺序建立 a[i] = pos[nums1[i]]。现在 nums1 的顺序由 i 保证，nums2 的顺序由 a[i] 保证，目标变为统计 i < j < k 且 a[i] < a[j] < a[k] 的三元组。

固定中间下标 j。设左侧比 a[j] 小的数量为 L，右侧比 a[j] 大的数量为 R。任取一个左候选和一个右候选都能组成好三元组，因此贡献为 L × R。

p = a[j]
L = 已处理位置中小于 p 的数量
R = (n − 1 − p) − (j − L)
answer += L × R

全部位置中大于 p 的有 n − 1 − p 个；已经扫过 j 个元素，其中 j − L 个大于 p（排列没有重复值）。相减得到右侧候选数，所以仅需一棵树状数组。

完整过程

  1. 用一次遍历构造 nums2 的位置表 pos，树状数组初始全为 0。
  2. 从左到右读取 nums1[j]，得到 p。BIT 采用 1 下标，位置 p 的存储下标为 p + 1。
  3. 查询 sum(p)，它统计实际位置 [0, p − 1] 中已经出现的元素，得到严格小于 p 的 L。
  4. 计算 R 与 L × R，加到答案；然后执行 add(p + 1, 1)，使当前元素可作为后续中点的左候选。
  5. 全部处理完后返回总和。每次查询沿 k -= k & -k，更新沿 k += k & -k 跳转。

示例 1 的映射为 [2,0,1,3]。中点 j = 2 时，p = 1，L = 1，R = 1，对应值三元组 (0,1,3)，贡献 1；其他中点贡献均为 0。

正确性论证

  1. 映射等价：i < j < k 保证三个值在 nums1 中依次出现；映射值递增恰好保证其在 nums2 中依次出现。映射是双射，不会丢失或混淆元素。
  2. 循环不变式：处理 j 之前，BIT 恰好保存 nums1 下标 [0,j) 的映射位置频次。初始为空成立；查询后加入当前点，下一轮仍成立。因此前缀查询精确给出 L。
  3. R 精确：所有大于 p 的位置共有 n − 1 − p 个。前面 j 个位置互异且不等于 p，其中 L 个更小，故 j − L 个更大。剩下的恰好位于当前中点右侧。
  4. 不重不漏：每对左右候选给出一个合法三元组；每个合法三元组都有唯一的中点，因此恰被其 L × R 统计一次。求和即为答案。

边界与复杂度

j = 0 时 L = 0；j = n − 1 时 R = 0。p = 0 的空前缀返回 0，p = n − 1 时没有更大的位置。完全逆序答案为 0；两数组相同，任取三个位置均合法，答案为 C(n,3)。

时间 O(n log n)，额外空间 O(n)。位置表和树状数组各占线性空间，不必真正保存映射数组。最大答案为 C(100000,3) = 166661666700000，超过 32 位有符号整数；Java 用 long，C++ 用 long long，乘法前提升类型。Python int 自动扩容；JavaScript Number 的安全整数上限约 9 × 10¹⁵，本题最大结果在范围内。

Java

class Solution {
    public long goodTriplets(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int[] pos = new int[n];
        int[] bit = new int[n + 1];
        for (int i = 0; i < n; i++) pos[nums2[i]] = i;
        long answer = 0;
        for (int j = 0; j < n; j++) {
            int p = pos[nums1[j]], left = 0;
            for (int k = p; k > 0; k -= k & -k)
                left += bit[k];
            int right = n - 1 - p - (j - left);
            answer += (long) left * right;
            for (int k = p + 1; k <= n; k += k & -k)
                bit[k]++;
        }
        return answer;
    }
}

Python 3

from typing import List

class Solution:
    def goodTriplets(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        pos = [0] * n
        bit = [0] * (n + 1)
        for i, value in enumerate(nums2):
            pos[value] = i
        answer = 0
        for j, value in enumerate(nums1):
            p = pos[value]
            left = 0
            k = p
            while k > 0:
                left += bit[k]
                k -= k & -k
            right = n - 1 - p - (j - left)
            answer += left * right
            k = p + 1
            while k <= n:
                bit[k] += 1
                k += k & -k
        return answer

C++

#include <vector>
using namespace std;

class Solution {
public:
    long long goodTriplets(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        vector<int> pos(n), bit(n + 1, 0);
        for (int i = 0; i < n; ++i) pos[nums2[i]] = i;
        long long answer = 0;
        for (int j = 0; j < n; ++j) {
            int p = pos[nums1[j]], left = 0;
            for (int k = p; k > 0; k -= k & -k)
                left += bit[k];
            int right = n - 1 - p - (j - left);
            answer += 1LL * left * right;
            for (int k = p + 1; k <= n; k += k & -k)
                ++bit[k];
        }
        return answer;
    }
};

替代方案

  • 双向 BIT：从左到右求所有 L，从右到左求所有 R，然后求积之和；同为 O(n log n)，思路直观，但多一次扫描和数组存储。
  • 归并排序计数：分治统计每个位置左侧更小、右侧更大的数量，O(n log n)，需要认真维护原始下标。
  • 线段树：区间频次查询与单点更新，O(n log n)，本题只需前缀和，BIT 更简短。
  • 枚举中点并扫描两侧：O(n²) 时间、O(n) 位置表空间，只适合小规模；直接枚举三元组为 O(n³)。

常见错误

  • 比较元素的数值大小；本题约束的是位置顺序。
  • 把 R 写成 n − 1 − p，忘了减掉左侧已经出现的较大位置。
  • 把前缀查询和更新下标混用：查询 p，更新 p + 1；更新从 0 开始会无法前进。
  • 让当前点参与自己的候选计数；保持“先查询、再插入”的不变式更清晰。
  • 使用 32 位答案，或在 Java / C++ 中先做 int 乘法再转成 64 位。
  • 用有序数组插入配合二分，忽略插入元素仍可能花 O(n) 时间。

面试追问

  • 为什么只用一棵 BIT？排列使大于 p 的总数量可由 p 直接推出，右侧计数可由全集减去已处理部分。
  • 如果有重复值？当前值到唯一位置的映射不再成立，必须先明确匹配与三元组定义；不能直接套用该公式。
  • 推广到长度 k 的同序子序列？映射后用按长度分层的 BIT 动态规划，逐层统计严格递增子序列；通常 O(kn log n)，并重新评估数值上限。
  • 能否交换两数组？可以。好三元组定义对称，交换后答案不变，可以在后续验证阶段作为变形性质。
