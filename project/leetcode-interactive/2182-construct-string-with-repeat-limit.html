构造限制重复的字符串

Construct String With Repeat Limit

字符可以重排，也可以舍弃。如何在连续次数的限制下，让构造的字符串拥有最大的字典序？

01 / 题目

官方题目 ↗

给定字符串 s 和整数 repeatLimit。你可以使用 s 中已有的字符，任意调整顺序，构造一个新字符串。每种字符的使用次数不能超过它在 s 中的数量，而且相同字母连续出现的次数不能超过 repeatLimit。允许留下未使用的字符。

返回所有合法构造中字典序最大的字符串。比较两个字符串时，先看第一个不同的位置，字母越靠后越大；若短串是长串的前缀，则长串更大。

参数与约束

repeatLimitedString(s: string, repeatLimit: integer) → string

  • 1 ≤ repeatLimit ≤ s.length ≤ 105
  • s 仅由小写英文字母组成。

示例 1

输入：s = "cczazcc", repeatLimit = 3
输出："zzcccac"

用完所有字符，z、c、a 的最长连续段分别为 2、3、1。看似更大的 “zzcccca” 含有连续 4 个 c，违反限制。

示例 2

输入：s = "aababab", repeatLimit = 2
输出："bbabaa"

只使用部分字符，a 和 b 均最多连续出现 2 次。末尾不能再追加 a，因此剩下一个 a；“bbabaaa” 不合法。

04 / 独立题解

从限制出发，构造最优前缀。

核心洞察：优先使用当前最大的合法字符

字典序由最早不同的位置决定。只要最大剩余字符还能追加，就应先用它。达到上限后，插入一个最大的较小字符作为分隔，然后立即回到大字符。没有分隔字符时就结束，允许有剩余。

绿色表示本步使用的字母；琥珀色虚线表示被连续上限挡住的字母。推演每步取一个字符，与代码中的批量追加等价。教学输入限 80 个字符。

完整过程

  1. 统计 26 个小写字母的数量。令 i 指向最大非空字母，j 用于寻找比 i 小的分隔字母。
  2. 一次追加 min(count[i], repeatLimit) 个 i 对应字母。若它已耗尽，向下寻找新的最大字母。
  3. 若它还有库存，说明连续段已满。令 j = min(j, i - 1)，向下跳过空库存。
  4. 若 j 存在，追加一个 j 对应字母，扣减库存，再回到 i；否则结束。

示例 1：zz → zzccc → zzccca → zzcccac。插入 a 让 c 的连续计数重新开始。示例 2：bb → bba → bbab → bbabaa，末尾还剩一个 a，但已无分隔字符。

正确性：最优前缀的交换论证

固定已经构造的前缀，设 c 是当前可合法追加的最大剩余字母。任何选择较小字母的方案，都会在这一位置输给选择 c 的方案；任何直接停止的方案则是追加 c 后字符串的真前缀，也更小。由于允许丢弃字符，选择 c 后不必保证用完库存，因此总能得到一个合法结果。

所以每次选 c 都保持存在一个以当前前缀开头的最优解。连续选择最大字母直到达到上限，等价于批量追加；被限制时，最大的较小字母就是下一个最大合法选择。只插入一个分隔字符后，大字符重新合法，应立即使用。若不存在合法字符，则所有合法结果都无法延长该前缀，算法结束时得到字典序最大结果。

边界与复杂度

  • 仅有一种字母：最多保留 repeatLimit 个，其余舍弃。
  • repeatLimit = 1：不能出现相邻相同字符，分隔库存决定能否继续。
  • repeatLimit ≥ 所有频数：直接得到降序排列的全部字符。
  • 分隔字母会耗尽；i 和 j 只向下移动，不会漏掉更大的可用分隔字母，因为它们被跳过时库存已为零。

四语言代码统计与输出共 O(n + 26) 时间。两个指针各最多下降 26 次，循环的有效工作都会写出字符。计数和指针辅助空间 O(26)；输出及构造缓冲占 O(n)。演示为易读而逐字符扫描 26 个桶，O(26m) 时间；保存历史快照会占 O(m² + 26m) 空间，因此只接受 m ≤ 80 的教学输入。

Java

class Solution {
    public String repeatLimitedString(String s, int repeatLimit) {
        int[] count = new int[26];
        for (int k = 0; k < s.length(); k++) {
            count[s.charAt(k) - 'a']++;
        }
        StringBuilder out = new StringBuilder();
        int i = 25, j = 24;
        while (i >= 0) {
            if (count[i] == 0) {
                i--;
                continue;
            }
            int take = Math.min(count[i], repeatLimit);
            for (int k = 0; k < take; k++) {
                out.append((char) ('a' + i));
            }
            count[i] -= take;
            if (count[i] == 0) continue;
            j = Math.min(j, i - 1);
            while (j >= 0 && count[j] == 0) j--;
            if (j < 0) break;
            out.append((char) ('a' + j));
            count[j]--;
        }
        return out.toString();
    }
}

var repeatLimitedString = function(s, repeatLimit) {
    const count = Array(26).fill(0);
    for (const c of s) count[c.charCodeAt(0) - 97]++;
    const out = [];
    let i = 25, j = 24;
    while (i >= 0) {
        if (count[i] === 0) {
            i--;
            continue;
        }
        const take = Math.min(count[i], repeatLimit);
        out.push(String.fromCharCode(97 + i).repeat(take));
        count[i] -= take;
        if (count[i] === 0) continue;
        j = Math.min(j, i - 1);
        while (j >= 0 && count[j] === 0) j--;
        if (j < 0) break;
        out.push(String.fromCharCode(97 + j));
        count[j]--;
    }
    return out.join('');
};

class Solution:
    def repeatLimitedString(self, s: str, repeatLimit: int) -> str:
        count = [0] * 26
        for c in s:
            count[ord(c) - ord('a')] += 1
        out = []
        i, j = 25, 24
        while i >= 0:
            if count[i] == 0:
                i -= 1
                continue
            take = min(count[i], repeatLimit)
            out.append(chr(ord('a') + i) * take)
            count[i] -= take
            if count[i] == 0:
                continue

            while j >= 0 and count[j] == 0:
                j -= 1
            if j < 0:
                break
            out.append(chr(ord('a') + j))
            count[j] -= 1
        return ''.join(out)

C++

#include <algorithm>
#include <string>
using namespace std;

class Solution {
public:
    string repeatLimitedString(string s, int repeatLimit) {
        int count[26] = {};
        for (char c : s) count[c - 'a']++;
        string out;
        out.reserve(s.size());
        int i = 25, j = 24;
        while (i >= 0) {
            if (count[i] == 0) {
                i--;
                continue;
            }
            int take = min(count[i], repeatLimit);
            out.append(take, char('a' + i));
            count[i] -= take;
            if (count[i] == 0) continue;
            j = min(j, i - 1);
            while (j >= 0 && count[j] == 0) j--;
            if (j < 0) break;
            out.push_back(char('a' + j));
            count[j]--;
        }
        return out;
    }
};

替代方案

用最大堆维护“字母、剩余次数”，取最大字母组成一段，必要时取第二大字母分隔，再把剩余库存放回。对字符种类数 σ，时间 O(n log σ)、辅助空间 O(σ)，适合不固定为 26 种字符的场景。也可每次扫描 26 个计数桶选择最大合法字符，写法直观，时间 O(26n)。排序后维护字符段则需要 O(n log n) 的排序，固定字母表下计数更直接。

常见错误

  • 把限制理解成“总共最多使用 repeatLimit 次”：限制只针对连续段。
  • 为了用完字符，提前消耗大字符作为分隔：可能使更早位置变小。例如 “zzyyyyy”、上限 2，答案 “zzyy” 比更长的 “zyyzyy” 大。
  • 一次插入多个较小字母：一个分隔已足够，应尽快回到大字母。
  • 最大字母被限制后直接丢弃其剩余库存：先寻找分隔字母，后面可能继续使用。
  • 忽略无分隔字符的停止条件，或让 j 不小于 i：会导致超限或死循环。

面试追问

  • 必须用完所有字符呢？此时不能直接沿用本题贪心：需要先考虑可行性。频数最大的字母至少需要足够的其他字符将其分段，例如最大频数不能超过 repeatLimit ×（其他字符数 + 1）；构造时也必须避免让后缀不可完成。
  • 字符集很大呢？先明确字符比较规则，再用排序后的不同字符或最大堆维护库存，避免为整个 Unicode 范围开数组。
  • 每个字母的上限不同呢？仍可选择当前最大的合法字母，把批量取用的上限替换为该字母自己的正整数上限，证明仍利用允许丢弃字符。
  • 如何核对实现？后续可用短串枚举所有合法构造，取最大值作对照，并核对字符库存和最长连续段。本页未执行这些验证。
