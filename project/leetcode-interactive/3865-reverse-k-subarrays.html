反转 K 个子数组

把 nums 切成 k 个等长连续段，每段各自反转；段与段之间的位置不交换。

先固定段长 m = n / k，对每个半开区间 [start, start + m) 做原地反转。

推荐主线：模拟 + 相向双指针

每段左右指针向中间收缩，所有段合起来只访问每个元素常数次。

时间
O(n)
额外空间
O(1)

题意与约束

先分段，再逐段镜像

给定整数数组 nums 和整数 k。保证 nums.length 能被 k 整除。将数组划分为 k 个长度相等的连续子数组，反转每一段，返回结果数组。

  • 1 ≤ n = nums.length ≤ 1000
  • 1 ≤ nums[i] ≤ 1000
  • 1 ≤ k ≤ n，且 n % k = 0

示例：nums = [1, 2, 4, 3, 5, 6], k = 3。段长为 2，结果为 [2,1,3,4,6,5]。

易错点

段数不是段长

  1. 把 k 当成每段长度：本题段长是 n / k。
  2. 整数组反转：会改变段的先后次序，不符合题意。
  3. 右端点写成 start + m：最后一个下标是 start + m - 1。
  4. 额外拷贝：可行但需要 O(n) 空间。

核心洞察

每个元素只属于一个固定段

令 m = n / k。外层按 m 跳过每段；内层让 left = start 与 right = start + m - 1 相向交换。段互不重叠，故总交换次数不超过 n / 2。

完整过程

  1. 计算 n 和段长 m。
  2. 枚举起点：0、m、2m……。
  3. 在当前段中执行 left < right 的交换。
  4. 返回已原地修改的 nums。

边界、复杂度与替代方案

  • k = 1：整数组反转。
  • k = n：每段长度 1，数组不变。
  • 时间 O(n)，额外空间 O(1)。
  • 替代方案：新数组逐段倒序追加，时间 O(n)、空间 O(n)。

面试追问

如果每段长度不相等，应将区间边界作为输入；若不能修改输入，则新建输出数组。
