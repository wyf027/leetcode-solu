镜像频次距离

字母按 a ↔ z 镜像，数字按 0 ↔ 9 镜像。对每个实际出现过的字符，只把它与镜像字符组成的无序对计算一次，累计两端出现次数之差的绝对值。

推荐主线

先计 26 个字母、10 个数字的频次；只枚举 13 对字母和 5 对数字。每对只处理一次，自然避免双算。

为什么适合线性扫描

字符串很长，但字符宇宙固定为 36 个。扫字符串是 O(n)，配对阶段只有 18 次比较。

题意、示例与约束

示例

s = "ab1z9"

镜像对为 a/z、b/y、1/8、9/0；差分别为 0, 1, 1, 1，结果为 3。

s = "4m7n"，结果为 2。

约束

1 ≤ s.length ≤ 5 × 10^5。s 仅包含小写英文字母与数字。

字母表和数字集合长度都为偶数，因此本题没有自镜像字符。

交互分步可视化：一次只看一个镜像对

题解（默认收起）

推导、边界和可提交代码按需展开。

核心洞察：不需要为每个出现位置反复找镜像。频次数组收集信息后，字母只需比较 (0,25)…(12,13)，数字只需比较 (0,9)…(4,5)。

完整过程

  1. 分别建立大小为 26 与 10 的计数数组，扫描 s 填入频次。
  2. 对 i = 0..12 加上 |letters[i] - letters[25-i]|。
  3. 对 i = 0..4 加上 |digits[i] - digits[9-i]|。
  4. 返回总和。镜像双方永远落在同一个循环迭代中，所以不会重复计数。

边界

镜像端没出现时，其频次为 0；只有单种字符时也要算这份差。字符集合没有中心点，自镜像分支不是必需的。

复杂度

计数扫描 O(n)；18 对的比较是常数。额外空间 O(1)。

替代方案、面试追问与常见错误

替代：可用哈希表记录频次再配合已访问集合，但在固定字母数字集上数组更直接。追问：若字符集扩大到 Unicode，可改成哈希表加规范化的 pair key。常见错误：遍历所有出现字符直接累加，导致 a/z 与 z/a 双算；或者漏掉镜像端频次为 0 的配对。

可提交代码

class Solution {
    public int mirrorFrequency(String s) {
        int[] letters = new int[26];
        int[] digits = new int[10];
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) digits[c - '0']++;
            else letters[c - 'a']++;
        }
        int ans = 0;
        for (int i = 0; i < 13; i++) ans += Math.abs(letters[i] - letters[25 - i]);
        for (int i = 0; i < 5; i++) ans += Math.abs(digits[i] - digits[9 - i]);
        return ans;
    }
}

class Solution:
    def mirrorFrequency(self, s: str) -> int:
        letters = [0] * 26
        digits = [0] * 10
        for c in s:
            if c.isdigit():
                digits[ord(c) - ord('0')] += 1
            else:
                letters[ord(c) - ord('a')] += 1
        return sum(abs(letters[i] - letters[25 - i]) for i in range(13)) + sum(abs(digits[i] - digits[9 - i]) for i in range(5))
