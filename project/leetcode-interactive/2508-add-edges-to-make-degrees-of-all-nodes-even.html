题目 · 最多添加两条边

给定整数 n 和二维整数数组 edges，描述一个节点编号为 1…n 的无向图。每个 edges[i] = [aᵢ, bᵢ] 表示一条连接这两个节点的边。图可以不连通。

允许添加 0、1 或 2 条新边。不能连接节点自身，也不能添加图中已经存在的边。判断是否能使所有节点的度数都为偶数，可以则返回 true，否则返回 false。

节点的度数等于与它相连的边数；没有连边的节点度数为 0，也是偶数。

参数与返回值

isPossible(n, edges) → boolean
n: integer
edges: list<list<integer>>

约束

  • 3 ≤ n ≤ 10⁵
  • 2 ≤ edges.length ≤ 10⁵
  • edges[i].length == 2
  • 1 ≤ aᵢ, bᵢ ≤ n
  • aᵢ != bᵢ，原图中没有重边。

题解与交互实验室

核心洞察 · 每条边翻转两个端点

添加边 (u,v) 后，两端的度数各加 1，因此奇偶性各翻转一次。度数总和等于边数的两倍，所以奇数度节点的数量必为偶数。两条新边仅有 4 个端点出现次数，因此只需处理 0、2、4 个奇数度节点。

0 个：直接成功

原图已经满足要求，添加 0 条边即可。

2 个：直接连或绕一步

设为 a、b。如果它们未相连，直接添加 (a,b)。否则找不同于 a、b 且同时不与它们相连的 c，添加 (a,c)、(b,c)。c 增加 2 度，奇偶不变。

4 个：枚举三种配对

设为 a、b、c、d。只可能是 ab + cd、ac + bd、ad + bc。任一配对的两条边都不存在即可。

如果奇数度节点超过 4 个，则两条边无法让它们各翻转至少一次，返回 false。

完整过程
  1. 建立双向邻接集合 g。集合大小就是度数，同时支持查询两点间是否已经有边。
  2. 扫描节点 1…n，收集奇数度节点 odd。不要跳过孤立点，它们可能成为中间节点。
  3. 根据 odd 的长度选择 0、2、4 分支。公共非邻居扫描所有节点，四点分支显式枚举三种配对。
  4. 只查询原图，不必真的添加边：构造出的每个候选方案内部没有重复边，且已经检查与原图不冲突。
官方示例 1 中，度数为 [2,4,2,3,1]，奇数度节点是 4、5。添加 (4,5) 后度数变为 [2,4,2,4,2]。官方示例 2 可以添加 (1,3)、(2,4)。


正确性证明
必要性：每个原奇数度节点必须作为新边端点出现奇数次，原偶数度节点必须出现偶数次。最多两条边一共提供四次端点出现机会，故奇数度节点只能有 0、2、4 个。
两个奇数度节点：若只加一条边，端点必须恰为 a、b。若加两条不同边，a、b 各只能出现一次，剩下两次出现必须属于同一个偶数度节点 c，否则会制造新的奇数度节点。因此所有可行方案都被直接连边与公共非邻居枚举覆盖。
四个奇数度节点：四次端点出现必须分别分配给这四个节点，新增两条边构成它们的一组配对。固定 a 的搭档有三个选择，对应代码中的全部三种情况。
充分性：每个接受的方案都只用不存在的非自环边；每个奇数度节点增加 1 度，其他节点增加 0 或 2 度，故最终全为偶数。0 个奇数度节点无需操作。因此算法返回 true 当且仅当存在合法方案。


复杂度
设 m = edges.length。使用哈希集合，查询与插入按平均 O(1) 计，构图 O(n+m)，扫描奇数度节点及公共非邻居 O(n)，总时间 平均 O(n+m)，空间 O(n+m)。哈希集合不提供统一的最坏常数查询保证，具体退化表现依语言实现而定。


边界与常见错误
  • “至多”包括不加边；度数 0 是偶数，无须强行连接孤立节点。
  • 只有两个奇数度节点且它们已经相连，也不一定失败：可能存在公共非邻居。
  • 中间节点不能是 a 或 b；否则会产生自环。代码通过 u != v 排除。
  • 四个奇数度节点必须尝试三种配对，只尝试第一种会漏解。
  • 同一条无向边应双向存储；不要用 JavaScript 数组作为 Set 的值来按内容查询边。
  • 无需检查连通性。所有度数为偶数不代表整张图连通。


替代方案
可以用度数数组和全局边集合替代邻接集合，但要将无向边规范化为 (min,max)。JavaScript 可用字符串键，避免 32 位位运算截断。也可将邻接表排序后用二分查询，换取确定性的查询复杂度，但实现和排序成本更高。枚举所有缺失边及其两两组合需要最坏 O(n⁴) 次候选判断，不适合本题规模。


面试追问
  • 怎样返回具体方案？在成功分支返回空数组、一条边或两条边，而不是布尔值。
  • 怎样求最少添加几条？先检查 0 条，再检查直接连接两个奇数度节点，最后检查所有 2 条方案。
  • 若允许更多条边？奇数度节点数 ≤ 2k 仍只是必要条件。需要在原图的补图里寻找使这些节点为奇数度的边集，即 T-join 思路；本题的三种配对枚举不能直接推广。

JavaScript
/**
 * @param {number} n
 * @param {number[][]} edges
 * @return {boolean}
 */
var isPossible = function(n, edges) {
    const g = Array.from({length: n + 1}, () => new Set());
    for (const [u, v] of edges) {
        g[u].add(v);
        g[v].add(u);
    }
    const odd = [];
    for (let v = 1; v <= n; v++) {
        if (g[v].size % 2) odd.push(v);
    }
    const free = (u, v) => u !== v && !g[u].has(v);
    if (odd.length === 0) return true;
    if (odd.length === 2) {
        const [a, b] = odd;
        if (free(a, b)) return true;
        for (let c = 1; c <= n; c++) {
            if (free(a, c) && free(b, c)) return true;
        }
        return false;
    }
    if (odd.length === 4) {
        const [a, b, c, d] = odd;
        return (free(a, b) && free(c, d)) ||
               (free(a, c) && free(b, d)) ||
               (free(a, d) && free(b, c));
    }
    return false;
};


Java
import java.util.*;

class Solution {
    public boolean isPossible(int n, List<List<Integer>> edges) {
        List<Set<Integer>> g = new ArrayList<>();
        for (int i = 0; i <= n; i++) g.add(new HashSet<>());
        for (List<Integer> edge : edges) {
            int u = edge.get(0), v = edge.get(1);
            g.get(u).add(v);
            g.get(v).add(u);
        }
        List<Integer> odd = new ArrayList<>();
        for (int v = 1; v <= n; v++) {
            if (g.get(v).size() % 2 == 1) odd.add(v);
        }
        if (odd.isEmpty()) return true;
        if (odd.size() == 2) {
            int a = odd.get(0), b = odd.get(1);
            if (free(g, a, b)) return true;
            for (int c = 1; c <= n; c++) {
                if (free(g, a, c) && free(g, b, c)) return true;
            }
            return false;
        }
        if (odd.size() == 4) {
            int a = odd.get(0), b = odd.get(1);
            int c = odd.get(2), d = odd.get(3);
            return (free(g, a, b) && free(g, c, d)) ||
                   (free(g, a, c) && free(g, b, d)) ||
                   (free(g, a, d) && free(g, b, c));
        }
        return false;
    }

    private boolean free(List<Set<Integer>> g, int u, int v) {
        return u != v && !g.get(u).contains(v);
    }
}


Python
from typing import List

class Solution:
    def isPossible(self, n: int, edges: List[List[int]]) -> bool:
        g = [set() for _ in range(n + 1)]
        for u, v in edges:
            g[u].add(v)
            g[v].add(u)
        odd = [v for v in range(1, n + 1) if len(g[v]) % 2]

        def free(u: int, v: int) -> bool:
            return u != v and v not in g[u]

        if not odd:
            return True
        if len(odd) == 2:
            a, b = odd
            if free(a, b):
                return True
            return any(free(a, c) and free(b, c)
                       for c in range(1, n + 1))
        if len(odd) == 4:
            a, b, c, d = odd
            return ((free(a, b) and free(c, d)) or
                    (free(a, c) and free(b, d)) or
                    (free(a, d) and free(b, c)))
        return False


C++
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool isPossible(int n, vector<vector<int>>& edges) {
        vector<unordered_set<int>> g(n + 1);
        for (const auto& edge : edges) {
            int u = edge[0], v = edge[1];
            g[u].insert(v);
            g[v].insert(u);
        }
        vector<int> odd;
        for (int v = 1; v <= n; ++v) {
            if (g[v].size() % 2) odd.push_back(v);
        }
        auto free = [&](int u, int v) {
            return u != v && g[u].count(v) == 0;
        };
        if (odd.empty()) return true;
        if (odd.size() == 2) {
            int a = odd[0], b = odd[1];
            if (free(a, b)) return true;
            for (int c = 1; c <= n; ++c) {
                if (free(a, c) && free(b, c)) return true;
            }
            return false;
        }
        if (odd.size() == 4) {
            int a = odd[0], b = odd[1], c = odd[2], d = odd[3];
            return (free(a, b) && free(c, d)) ||
                   (free(a, c) && free(b, d)) ||
                   (free(a, d) && free(b, c));
        }
        return false;
    }
};
