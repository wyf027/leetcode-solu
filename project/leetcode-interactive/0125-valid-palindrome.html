Sealed analysis

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码默认封存。

Core insight

原地双指针

面试最推荐直接在原字符串上放置左右指针。左右各自跳过非字母数字字符；都停在有效字符后， 只比较它们的小写形式。不同则立即返回 false，相同则同时向中间收缩。

TIME

O(n)

SPACE

O(1)

Full process

完整过程

  1. 1. 初始化 left = 0、right = n - 1。
  2. 2. 左端遇到非字母数字字符就右移，右端同理左移。
  3. 3. 比较两个有效字符的小写形式；不同立即返回 false。
  4. 4. 相同则左右同时收缩，直到指针相遇或交错，返回 true。

边界

  • 清理后为空串：没有冲突，返回 true。
  • 单个有效字符：天然左右对称。
  • 数字不能忽略，也不参与大小写转换。
  • 连续多个符号必须由 while 持续跳过。

替代方案取舍

可以先生成只含小写字母数字的新字符串，再与反转结果比较；代码直观，但会分配 O(n) 额外空间。 面试中优先原地双指针，能清楚展示边界控制与空间意识。

常见错误

  • 只跳过空格，没有跳过标点等全部非字母数字字符。
  • 比较前忘记统一大小写。
  • 跳过字符后不再检查 left < right，导致越界。
  • 把数字当成应忽略字符。

面试追问

如果输入不是 ASCII？

需要按 Unicode 码点遍历，并明确字母数字判定与大小写折叠规则。

为什么是 O(1) 空间？

只维护两个下标和少量字符变量，没有构造随 n 增长的新容器。

能否流式处理？

单向流无法直接访问右端，通常需要缓存内容或借助可双向读取的存储。

class Solution {
    public boolean isPalindrome(String s) {
        int left = 0;
        int right = s.length() - 1;

        while (left < right) {
            while (left < right && !isAsciiAlphanumeric(s.charAt(left))) {
                left++;
            }
            while (left < right && !isAsciiAlphanumeric(s.charAt(right))) {
                right--;
            }
            if (toLowerAscii(s.charAt(left)) != toLowerAscii(s.charAt(right))) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }

    private boolean isAsciiAlphanumeric(char character) {
        return (character >= '0' && character <= '9')
            || (character >= 'a' && character <= 'z')
            || (character >= 'A' && character <= 'Z');
    }

    private char toLowerAscii(char character) {
        if (character >= 'A' && character <= 'Z') {
            return (char) (character + ('a' - 'A'));
        }
        return character;
    }
}

var isPalindrome = function (s) {
    const isAsciiAlphanumeric = (character) =>
        (character >= "0" && character <= "9") ||
        (character >= "a" && character <= "z") ||
        (character >= "A" && character <= "Z");

    let left = 0;
    let right = s.length - 1;

    while (left < right) {
        while (left < right && !isAsciiAlphanumeric(s[left])) left++;
        while (left < right && !isAsciiAlphanumeric(s[right])) right--;
        if (s[left].toLowerCase() !== s[right].toLowerCase()) return false;
        left++;
        right--;
    }
    return true;
};

class Solution {
public:
    bool isPalindrome(string s) {
        int left = 0;
        int right = static_cast<int>(s.size()) - 1;

        while (left < right) {
            while (left < right && !isAsciiAlphanumeric(s[left])) ++left;
            while (left < right && !isAsciiAlphanumeric(s[right])) --right;
            if (toLowerAscii(s[left]) != toLowerAscii(s[right])) return false;
            ++left;
            --right;
        }
        return true;
    }

private:
    bool isAsciiAlphanumeric(char character) {
        return (character >= '0' && character <= '9')
            || (character >= 'a' && character <= 'z')
            || (character >= 'A' && character <= 'Z');
    }

    char toLowerAscii(char character) {
        if (character >= 'A' && character <= 'Z') {
            return static_cast<char>(character + ('a' - 'A'));
        }
        return character;
    }
};
