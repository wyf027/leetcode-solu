Problem Brief

题意

给定一棵二叉树，创建包含每个深度全部节点的链表。若树共有 D 层，则返回包含 D 条链表的数组；同一层节点保持从左到右的顺序。

官方样例

输入
tree = [1,␠2,␠3,␠4,␠5,␠null,␠7,␠8]
输出
[[1],␠[2,␠3],␠[4,␠5,␠7],␠[8]]

Return Contract

  • 空树返回空数组。
  • 每条链表只包含同一深度的节点值。
  • 官方页面未单列数值或节点数量范围。

可见空格约定：输入与输出代码中的 ␠ 表示一个普通空格，便于核对完整参数；null 表示缺失节点。

Sealed Dispatch Manual

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码默认隐藏。

Core Insight

核心洞察：冻结本层长度，再开始出队

队列中既可能有当前层节点，也会陆续加入下一层孩子。进入一轮循环时先记录 levelSize = queue.length， 本轮只弹出这固定数量的节点；它们天然保持从左到右的顺序，直接用 dummy 与 tail 串成链表即可。

完整过程

  1. 01

    若 tree 为空，直接返回空数组；否则根节点入队。

  2. 02

    记录当前队列长度 levelSize，并为本层新建 dummy / tail。

  3. 03

    连续出队 levelSize 次，追加 ListNode，并把非空孩子入队。

  4. 04

    保存 dummy.next；队列为空时，所有深度编组完成。

边界

  • 空树不能向结果放入一条空链表。
  • 只有一个节点时，返回长度为 1 的链表数组。
  • 斜树每层只有一个节点，仍需创建多条独立链表。
  • 孩子入队顺序必须先左后右，才能保持题目顺序。

复杂度

时间
O(n)
辅助队列
O(w)
输出链表
O(n)

n 为节点数，w 为二叉树最大层宽；返回值本身占用的节点不计入辅助空间时，额外空间为 O(w)。

替代方案

DFS 携带 depth，按深度维护 head / tail 数组也能 O(n) 完成；但 BFS 的层边界与输出结构完全一致，面试解释更短，也不承受深树递归栈风险。

面试追问

  • 如果只返回第 k 层，如何提前停止？
  • 如何用 DFS 保持同层从左到右？
  • 能否复用原树节点作为链表节点？为什么通常不应这样做？

常见错误

  • 在 for 循环中直接使用不断增长的 queue.length。
  • 所有深度共用同一个 dummy 或 tail。
  • 忘记返回 dummy.next，误把哨兵节点放进答案。
  • 把右孩子先入队，破坏同层顺序。

class Solution {
    public ListNode[] listOfDepth(TreeNode tree) {
        if (tree == null) return new ListNode[0];

        List<ListNode> answer = new ArrayList<>();
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(tree);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            ListNode dummy = new ListNode(0);
            ListNode tail = dummy;

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                tail.next = new ListNode(node.val);
                tail = tail.next;

                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            answer.add(dummy.next);
        }
        return answer.toArray(new ListNode[0]);
    }
}
var listOfDepth = function (tree) {
  if (tree === null) return [];

  const answer = [];
  const queue = [tree];
  let front = 0;

  while (front < queue.length) {
    const levelSize = queue.length - front;
    const dummy = new ListNode(0);
    let tail = dummy;

    for (let i = 0; i < levelSize; i += 1) {
      const node = queue[front++];
      tail.next = new ListNode(node.val);
      tail = tail.next;

      if (node.left !== null) queue.push(node.left);
      if (node.right !== null) queue.push(node.right);
    }
    answer.push(dummy.next);
  }
  return answer;
};

class Solution {
public:
    vector<ListNode*> listOfDepth(TreeNode* tree) {
        if (tree == nullptr) return {};

        vector<ListNode*> answer;
        queue<TreeNode*> nodes;
        nodes.push(tree);

        while (!nodes.empty()) {
            int levelSize = static_cast<int>(nodes.size());
            ListNode dummy(0);
            ListNode* tail = &dummy;

            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = nodes.front();
                nodes.pop();
                tail->next = new ListNode(node->val);
                tail = tail->next;

                if (node->left != nullptr) nodes.push(node->left);
                if (node->right != nullptr) nodes.push(node->right);
            }
            answer.push_back(dummy.next);
        }
        return answer;
    }
};
