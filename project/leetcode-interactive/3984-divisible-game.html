可整除游戏

两位玩家轮流从当前正整数 n 中减去一个满足 1 ≤ x < n 且 n % x = 0 的正因数。不能操作的人输。判断 Alice 是否必胜。

规则
每次只能减真因数
目标
让对手面对 1
结论
n 为偶数时 Alice 必胜

题意与示例

从一个正整数开始。可选操作是减去它的一个真因数；例如 6 可以减 1、2、3，不能减 6。若当前值为 1，没有合法操作。

输入 一个取胜过程 输出
n = 2 减 x = 1，留下 1 true
n = 3 只能减 1，留下 2 给对手 false

约束

1 ≤ n ≤ 1000。范围很小，DP 可行；但面试中更推荐识别奇偶不变量。

题解：奇偶性就是完整状态

核心洞察

1 是必败态。若 n 是偶数，减去 1 后把奇数交给对手。若 n 是奇数，任何真因数都是奇数（奇数没有偶因数），所以 n − x 是偶数，必把赢态交给对手。因此偶数必胜、奇数必败。

完整过程

  1. 基例：n = 1，无路可走，输。
  2. 偶数 n：选择 x = 1，得到奇数。
  3. 奇数 n：所有合法 x 都是奇数，结果必为偶数。
  4. 归纳得出 n % 2 === 0。

边界与复杂度

n = 1 返回 false；n = 2 返回 true。时间 O(1)，空间 O(1)。

替代方案

DP：令 dp[i] 表示 i 是否必胜，枚举每个真因数 x，若 dp[i - x] 为假则 i 必胜。它是验证规律的好工具，但时间约 O(n√n)，不如奇偶结论简洁。

面试追问

若把“真因数”改成任意小于 n 的数，或改变可减集合，奇偶规律可能失效；应重新写状态转移并检查不变量。

常见错误

  • 把 n 自己当成可减因数。
  • 误以为奇数可减偶因数。
  • 用递归搜索却没有记忆化。
