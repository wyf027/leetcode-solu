LCP 71 · 集水器

把每个方格拆成上、下、左、右四个区域；从底向上扫描，分别回答“能否向下流走”和“最初是否进过水”。

shape = “l” / “r” / “.”每个方格体积 = 2O(nm α(nm))

题意

矩阵 shape 的每个字符是一块斜隔板："l" 从左上到右下，"r" 从左下到右上，"." 没有隔板。整个装置先浸在水中：内部完全封闭的腔体从一开始就是空气；其余位置有水。竖直取出后，水不能穿过隔板、却会从能抵达左右或下边界的通路流走。返回最终剩余水量。

示例： shape = ["....rl", "l.lr.r", ".l..r.", "..lr.."]，答案为 18。字符串中的空格不存在；若输入包含空格，页面会把它显示为 ␠，以免视觉歧义。

为什么不能只做一次洪泛？

有些区域虽然围住了、不会向下漏水，却是装置内部的密闭空气腔，起初没有水。答案必须同时满足：取出后能留水，并且初始时连接过顶部外部水域。

核心洞察

  1. 每格拆成 u,d,l,r 四个扇区；斜板只把同侧的两个扇区连起来。
  2. 自底向上合并：当前行的左右边界及下方已经确定，若一个扇区不连外界，便可记为“能留水”。
  3. 扫描结束后把最上边界接到超级汇点。一个候选扇区也接到该汇点，说明它原本在外部水域；否则它是密闭空气腔。
  4. 四扇区模型每个真实半方格会计两次，因此候选计数除以 2。

复杂度与边界

最多 50 × 50 × 4 个节点。并查集总时间 O(nm α(nm))，空间 O(nm)。边界需要额外的左右列和最下一行；把数组默认节点 0 当超级汇点，便可统一处理泄水边界。

替代方案与常见错误

也可建立半三角形面图再做两次连通性搜索，但实现更易漏掉对角板的两侧。常见错误是把内部空气腔当水、只从顶向下判断、或把 l 与 r 的连接方向写反。

完整过程

扫到第 i 行时，尚未连接 i−1 行，所以组件若已能到左、右、下边界，取出时必会漏水；反之记录为候选。最后再以顶部外界过滤候选，即可剔除起初从未进水的封闭区域。

面试追问

若每个三角形的体积不同，可以在并查集根上维护体积并在最终组件条件成立时累加；若板能移动，则需改为离线动态连通性或按操作逆序并查集。
