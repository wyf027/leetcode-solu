等式方程的可满足性

Satisfiability of Equality Equations

并查集图数组字符串

题目

给定字符串数组 equations。每个字符串长度为 4，形式为 "x==y" 或 "x!=y"，其中两端均为小写英文字母表示的单字母变量。判断是否存在一组整数赋值，使所有方程同时成立。

函数：boolean equationsPossible(string[] equations)

示例 1
输入：equations = ["a==b","b!=a"]
输出：false
解释：a 与 b 既要相等又要不等，矛盾。
示例 2
输入：equations = ["b==a","a==b"]
输出：true
解释：例如令 a = b = 1。
示例 3
输入：equations = ["a==b","b==c","a==c"]
输出：true
示例 4
输入：equations = ["a==b","b!=c","c==a"]
输出：false
示例 5
输入：equations = ["c==c","b==d","x!=z"]
输出：true

约束

  • 1 <= equations.length <= 500
  • equations[i].length == 4
  • 第 0、3 位为小写字母；第 1 位为 = 或 !；第 2 位为 =。

关系实验室

观察算法先把所有“相等”关系连成集合，再逐条检查“不等”关系。当前演示：["a==b","b==c","a!=c"]。

输入["a==b","b==c","a!=c"]期望输出false实际输出待补验证状态待补验证

题解：把相等看作连通

核心洞察

== 具有传递性：若 a==b 且 b==c，则 a、b、c 必须同值。先用并查集合并所有等式的两端；随后若某条不等式两端已有相同根，约束便矛盾。

完整过程

  1. 初始化 26 个集合，每个字母自成一组。
  2. 第一次遍历，只处理 ==，合并两端集合。
  3. 第二次遍历，只处理 !=；若两端根相同，立即返回 false。
  4. 检查完仍无冲突，返回 true。

正确性

充分性：若没有不等式落在同一集合内，可给每个集合分配一个不同整数。集合内所有等式成立，不同集合间的所有已声明不等式也成立。

必要性：并查集中的两个变量由一条等式链连接，任何可行赋值都必须令它们相等。因此，只要不等式两端同根，任何赋值都会违反该不等式。算法返回 false 当且仅当约束不可满足。

边界

  • a!=a 必然冲突；a==a 不改变集合。
  • 无等式时，每个变量独立；重复方程不影响结论。
  • 必须先合并全部等式，再检查不等式，避免输入顺序干扰。

复杂度

设方程数为 n。并查集带路径压缩和按秩合并，时间为 O(n α(26))，在本题中近似 O(n)；空间为 O(26)。

替代方案

也可把等式建成无向图，对每个连通分量 DFS/BFS 染色，再检查不等式，时间 O(n+26)、空间 O(n+26)。并查集更直接，也便于在线合并。

面试追问

  • 变量不止 26 个时，用哈希表动态创建并查集节点。
  • 若要输出一组赋值，可按根编号，将每个根映射到不同整数。
  • 若关系可撤销，可讨论回滚并查集；本题无需撤销。

常见错误

  • 按输入顺序立刻检查不等式，漏掉后续等式带来的传递冲突。
  • 只比较直接等式，不计算传递闭包。
  • find 未递归/迭代到根，或字符索引换算错误。

Java

class Solution {
    private final int[] parent = new int[26];
    private final int[] rank = new int[26];
    private int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    private void union(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return;
        if (rank[ra] < rank[rb]) parent[ra] = rb;
        else { parent[rb] = ra; if (rank[ra] == rank[rb]) rank[ra]++; }
    }
    public boolean equationsPossible(String[] equations) {
        for (int i = 0; i < 26; i++) parent[i] = i;
        for (String e : equations) if (e.charAt(1) == '=')
            union(e.charAt(0) - 'a', e.charAt(3) - 'a');
        for (String e : equations) if (e.charAt(1) == '!' &&
            find(e.charAt(0) - 'a') == find(e.charAt(3) - 'a')) return false;
        return true;
    }
}

JavaScript

var equationsPossible = function(equations) {
  const parent = Array.from({ length: 26 }, (_, i) => i);
  const rank = Array(26).fill(0);
  const find = x => {
    if (parent[x] !== x) parent[x] = find(parent[x]);
    return parent[x];
  };
  const union = (a, b) => {
    let ra = find(a), rb = find(b);
    if (ra === rb) return;
    if (rank[ra] < rank[rb]) [ra, rb] = [rb, ra];
    parent[rb] = ra;
    if (rank[ra] === rank[rb]) rank[ra]++;
  };
  for (const e of equations) if (e[1] === '=') union(e.charCodeAt(0)-97, e.charCodeAt(3)-97);
  for (const e of equations) if (e[1] === '!' && find(e.charCodeAt(0)-97) === find(e.charCodeAt(3)-97)) return false;
  return true;
};

Python

class Solution:
    def equationsPossible(self, equations: List[str]) -> bool:
        parent = list(range(26))
        rank = [0] * 26
        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]
        def union(a, b):
            ra, rb = find(a), find(b)
            if ra == rb: return
            if rank[ra] < rank[rb]: ra, rb = rb, ra
            parent[rb] = ra
            if rank[ra] == rank[rb]: rank[ra] += 1
        for e in equations:
            if e[1] == '=': union(ord(e[0])-97, ord(e[3])-97)
        return all(e[1] != '!' or find(ord(e[0])-97) != find(ord(e[3])-97) for e in equations)

C++

class Solution {
    int parent[26], rankv[26]{};
    int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }
    void unite(int a, int b) {
        a = find(a); b = find(b); if (a == b) return;
        if (rankv[a] < rankv[b]) swap(a, b);
        parent[b] = a;
        if (rankv[a] == rankv[b]) rankv[a]++;
    }
public:
    bool equationsPossible(vector<string>& equations) {
        iota(parent, parent + 26, 0);
        for (auto& e : equations) if (e[1] == '=') unite(e[0]-'a', e[3]-'a');
        for (auto& e : equations) if (e[1] == '!' && find(e[0]-'a') == find(e[3]-'a')) return false;
        return true;
    }
};
