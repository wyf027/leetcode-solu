LCR 060 · MEDIUM

前 K 个高频元素

给定整数数组 nums 和整数 k，返回出现频率前 k 高的元素。答案顺序可以任意。

开始推演

题意

不是把数组排序后取前 k 个数，而是先统计每个数出现多少次，再找频率最高的 k 个不同元素。

示例

输入：nums = [1,1,1,2,2,3], k = 2
输出：[1,2]

约束

  • 1 <= nums.length <= 10⁵
  • -10⁴ <= nums[i] <= 10⁴
  • k 在不同元素数量的有效范围内

先想一想

  1. 怎样在一次扫描后得到每个元素的出现次数？
  2. 频率的最大值会超过数组长度吗？
  3. 为何可以用“频率作下标”的桶避开比较排序？

交互推演：计数 + 桶

准备统计示例数组中的频率。

① 频率表

② 频率桶

③ 从高到低取 k 个

桶排序：线性时间找答案

核心步骤

用哈希表统计频率；创建长度为 n + 1 的桶数组，把元素放入对应频率的桶；最后从频率 n 向下扫描，收集到 k 个元素即停止。

复杂度与边界

统计、入桶和倒序扫描总计 O(n) 时间，空间 O(n)。并列频率时返回顺序不重要；不要把桶下标误写成元素值，也不要继续扫描到已收集够 k 个之后。

四语言代码

class Solution {
  public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> count = new HashMap<>();
    for (int x : nums) count.merge(x, 1, Integer::sum);
    List<Integer>[] buckets = new List[nums.length + 1];
    for (var entry : count.entrySet()) {
      int f = entry.getValue();
      if (buckets[f] == null) buckets[f] = new ArrayList<>();
      buckets[f].add(entry.getKey());
    }
    int[] answer = new int[k]; int i = 0;
    for (int f = nums.length; f >= 0 && i < k; f--)
      if (buckets[f] != null) for (int x : buckets[f]) { answer[i++] = x; if (i == k) break; }
    return answer;
  }
}
var topKFrequent = function (nums, k) {
  const count = new Map();
  for (const x of nums) count.set(x, (count.get(x) || 0) + 1);
  const buckets = Array.from({ length: nums.length + 1 }, () => []);
  for (const [x, freq] of count) buckets[freq].push(x);
  const answer = [];
  for (let freq = nums.length; freq >= 0 && answer.length < k; freq--)
    answer.push(...buckets[freq]);
  return answer.slice(0, k);
};
from collections import Counter

class Solution:
    def topKFrequent(self, nums: List[int], k: int) -> List[int]:
        count = Counter(nums)
        buckets = [[] for _ in range(len(nums) + 1)]
        for value, freq in count.items():
            buckets[freq].append(value)
        answer = []
        for freq in range(len(nums), -1, -1):
            answer.extend(buckets[freq])
            if len(answer) >= k:
                return answer[:k]
class Solution {
 public:
  vector<int> topKFrequent(vector<int>& nums, int k) {
    unordered_map<int, int> count;
    for (int x : nums) ++count[x];
    vector<vector<int>> buckets(nums.size() + 1);
    for (auto& [value, freq] : count) buckets[freq].push_back(value);
    vector<int> answer;
    for (int f = nums.size(); f >= 0 && answer.size() < k; --f)
      for (int x : buckets[f]) { answer.push_back(x); if (answer.size() == k) break; }
    return answer;
  }
