反转单词前缀

Reverse Prefix of Word

从左到右，找到第一次相遇的位置。你能准确圈出需要翻转的那一段吗？

官方题目 ↗

01 / 读懂规则

题目要求

给定从下标 0 开始的字符串 word 和字符 ch。找到 ch 在 word 中第一次出现的位置，将从开头到该位置的字符顺序反转，包括这个字符本身；其后的字符保持原样。如果找不到 ch，返回原字符串。

参数与返回：reversePrefix(word: string, ch: character) → string

  • 1 ≤ word.length ≤ 250。
  • word 仅包含小写英文字母。
  • ch 是一个小写英文字母。

观察输入与输出

示例 1

输入：word = "abcdefd", ch = "d"
输出："dcbaefd"

示例 3

输入：word = "abcd", ch = "z"
输出："abcd"

字符串中没有 z，因此返回原字符串。

05 / 独立题解
先想一想，再揭开答案






核心洞察：固定边界，成对交换


先在原词中找到 ch 第一次出现的位置 k，就确定了唯一需要反转的区间 [0, k]。区间外全部不动。区间内原位置 j 的字符应到达 k − j，因此可以用两个指针从两端向内交换。


完整过程


  1. 从左到右查找 ch，遇到第一个匹配就停止，记录 k。
  2. 若不存在匹配，直接返回 word。
  3. 将字符串转为可修改的字符数组，令 left = 0、right = k。
  4. 当 left < right 时交换两端字符，然后令 left++、right--。
  5. 指针相遇或交错后结束，组装并返回字符串。


word = "abcdefd", ch = "d"
定位：k = 3，前缀 abcd，后缀 efd
交换 0 与 3：dbcaefd
交换 1 与 2：dcbaefd
指针交错，结束。


为什么正确


扫描按下标递增顺序进行，在第一个相等处停止，因此找到的 k 正是题目要求的边界。交换循环开始时，区间 [left, right] 外、原前缀内的字符均已位于最终反转位置，而下标大于 k 的后缀始终未变。


每次交换 left 与 right，由于两者之和始终为 k，两个字符都被放到正确的镜像位置。指针向内移动后不变式继续成立。终止时至多剩一个中央字符，它的镜像就是自身，故整个前缀反转完成。找不到目标时返回原词，亦符合定义。


边界与复杂度


  • k = 0：反转长度为 1，不发生交换。
  • k = n − 1：反转整个字符串。
  • 重复出现的目标：只以第一次出现为界。
  • 奇数长度前缀：中间字符不需要移动；未命中时不反转。
  • 令 n = word.length。查找最多 O(n)，交换最多 O(n)，总时间 O(n)。Java / JavaScript / Python 的数组及结果字符串占 O(n) 空间。
  • C++ 在传入的字符串副本上修改，函数体的辅助空间 O(1)；若把按值传参的字符串副本及返回结果也计入存储，则为 O(n)。


四语言完整代码
均按官方函数签名提供，适用于 LeetCode 提交环境；本轮未执行。


Java
class Solution {
    public String reversePrefix(String word, char ch) {
        int k = word.indexOf(ch);
        if (k == -1) return word;
        char[] chars = word.toCharArray();
        for (int left = 0, right = k; left < right; left++, right--) {
            char temp = chars[left];
            chars[left] = chars[right];
            chars[right] = temp;
        }
        return new String(chars);
    }
}


JavaScript
/**
 * @param {string} word
 * @param {character} ch
 * @return {string}
 */
var reversePrefix = function(word, ch) {
    const k = word.indexOf(ch);
    if (k === -1) return word;
    const chars = word.split('');
    for (let left = 0, right = k; left < right; left++, right--) {
        [chars[left], chars[right]] = [chars[right], chars[left]];
    }
    return chars.join('');
};


Python
class Solution:
    def reversePrefix(self, word: str, ch: str) -> str:
        k = word.find(ch)
        if k == -1:
            return word
        chars = list(word)
        left, right = 0, k
        while left < right:
            chars[left], chars[right] = chars[right], chars[left]
            left += 1
            right -= 1
        return ''.join(chars)


C++
#include <string>
#include <utility>
using namespace std;

class Solution {
public:
    string reversePrefix(string word, char ch) {
        auto k = word.find(ch);
        if (k == string::npos) return word;
        for (int left = 0, right = static_cast<int>(k);
             left < right; ++left, --right) {
            swap(word[left], word[right]);
        }
        return word;
    }
};


替代方案


切片反转再拼接更简短。例如 Python 在 k = word.find(ch) 后返回 word[:k + 1][::-1] + word[k + 1:]；这里 k = -1 时空前缀加完整后缀，恰好返回原词。C++ 可在找到目标后调用 std::reverse(word.begin(), word.begin() + k + 1)，需要头文件 <algorithm>。栈也能倒序输出前缀，但增加 O(k + 1) 存储，本题无需额外栈。


常见错误


  • 用最后一次出现的位置，或遇到匹配后继续覆盖边界。
  • 把目标字符排除在外：切片右端应为 k + 1。
  • 直接反转整个单词，破坏了后缀。
  • 忘记处理未命中的 -1 / string::npos。
  • 直接修改 JavaScript / Python 字符串；应先转数组或列表。
  • 把 C++ 按值传参的复制存储与循环本身的辅助空间混为一谈。


面试追问


如果反转到第 t 次出现呢？扫描时计数，到第 t 次命中固定边界，其余过程相同；不足 t 次时先明确业务约定。


如果输入已经是可修改数组呢？直接交换，无需整串副本，辅助空间可降到 O(1)。


如果包含 emoji 或组合字符呢？当前题目只包含小写英文字母。扩展题需要先约定按字节、码点还是字素簇反转；用户可见字符通常要按字素簇分割，不能直接套用 UTF-16 下标。


学习提醒：先确定反转的闭区间，再考虑实现。这里最容易错的是“第一次”和“包含目标字符”。
