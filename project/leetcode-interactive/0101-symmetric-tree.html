题意与约束

给定二叉树根节点 root，判断这棵树是否以根为中心轴左右镜像。下面是对官方题意、样例与约束的准确转述。

官方样例 1 · 能完全重合

输入 root␠=␠[1,2,2,3,4,4,3]
输出 true

根的两侧结构和值互为镜像；折叠后每一对节点都重合。

官方样例 2 · 结构错位

输入 root␠=␠[1,2,2,null,3,null,3]
输出 false

左外侧为空而右外侧有节点，即使两个 3 的值相同，位置也不能镜像。

约束

  • 树中节点数为 [1, 1000]。
  • -100 <= Node.val <= 100。
  • 进阶：分别用递归和迭代方法完成。

先建立判断标准

若拿左子树中的节点 a 与右子树中的节点 b 比较，下一层必须比较 a.left ↔ b.right 和 a.right ↔ b.left。

标记说明：␠ 表示一个可见空格；数组中的逗号后未省略任何参数内容。

核心洞察 · 比较镜像位置

推荐递归，因为递归参数天然表达“待比较的一对位置”。比较 left 与 right 时，不是同向深入，而是交叉深入：外侧配外侧、内侧配内侧。

三个终止条件

  1. 两个节点都为空：这对镜像成立。
  2. 仅一个为空：结构不对称。
  3. 节点值不同：数值不对称。

完整过程

  1. 空树在通用定义下对称；本题约束至少有一个节点。
  2. 从 mirror(root.left, root.right) 开始。
  3. 先处理空节点和数值不等，尽早返回。
  4. 递归检查 left.left ↔ right.right。
  5. 递归检查 left.right ↔ right.left。
  6. 两支都为真时，这一对才为真。

边界与常见错误

  • 单节点树必然对称。
  • 只比较值、不比较空位，会漏掉结构错位。
  • 写成左左对右左，会退化成“相同树”而非镜像。
  • 不要用中序遍历回文判断；不同结构可能产生相同序列。
  • 递归深度最坏为 1000，生产环境可用迭代规避栈限制。

复杂度

O(n)每个节点最多比较一次
O(h)递归栈；h 为树高

替代方案取舍

迭代法在队列中一次压入一对镜像节点，逻辑同样清晰，额外空间最坏为 O(n)。面试首选递归以突出镜像递推式；若面试官追问栈溢出，再写迭代版。

面试追问

  • 如何改成迭代？队列每次弹出两个节点，并交叉压入孩子。
  • 能否原地完成？树本身无需修改，但遍历状态仍需栈或队列。
  • 如何定位首个错误？让函数返回失败路径，而不只是布尔值。
  • N 叉树怎么办？成对比较首尾孩子，并向中间收拢。

一句话记忆

左的左对右的右，左的右对右的左。 把这句话写成两个递归调用即可。 

class Solution {
    public boolean isSymmetric(TreeNode root) {
        return isMirror(root.left, root.right);
    }

    private boolean isMirror(TreeNode left, TreeNode right) {
        if (left == null && right == null) {
            return true;
        }
        if (left == null || right == null || left.val != right.val) {
            return false;
        }
        return isMirror(left.left, right.right)
                && isMirror(left.right, right.left);
    }
}
var isSymmetric = function (root) {
    function isMirror(left, right) {
        if (left === null && right === null) {
            return true;
        }
        if (left === null || right === null || left.val !== right.val) {
            return false;
        }
        return (
            isMirror(left.left, right.right) &&
            isMirror(left.right, right.left)
        );
    }

    return isMirror(root.left, root.right);
};
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:

            if left is None and right is None:
