Make Array Non-decreasing or Non-increasing

每次只改变一个数的一个单位。让整段序列朝同一个方向排列，需要付出多少代价？先判断目标，再决定怎样调整。

01 / PROBLEM

题意与输入

给定从下标 0 开始的整数数组 nums。一次操作可选择任意有效下标 i，令 nums[i] 加 1 或减 1。求使整个数组非递减或非递增所需的最少操作次数。元素位置保持不变，允许相邻元素相等。

两个方向，满足其一即可

非递减：每个相邻位置满足 a[i] ≤ a[i+1]。

非递增：每个相邻位置满足 a[i] ≥ a[i+1]。

参数、返回值与约束

  • convertArray(nums: integer[]) → integer
  • 1 ≤ nums.length ≤ 1000
  • 0 ≤ nums[i] ≤ 1000

进阶：能否做到 O(n log n) 时间？

04 / SOLUTION LAB

把两种方向化成同一个问题

先求非递减的最小代价。对所有元素取负后再求一次，得到原数组非递增的最小代价。答案是两者中的较小值。

核心工具：最大堆。它保存代价函数的“折点”，不是已经确定的目标数组。

交互 · 折点堆的双向扫描

核心洞察与完整过程

  1. 固定目标数组 b，最小代价为 Σ |nums[i] − b[i]|。目标只需满足单调性，允许相等。
  2. 对当前方向，把每个值乘以 sign（+1 或 −1）。清空最大堆和 cost。
  3. 依次读 x，先放入两份 x，再弹出最大值 m，令 cost 加上 m − x。因为堆里刚放入 x，所以 m ≥ x，增量不会为负。
  4. 当旧最大值不大于 x，弹出的就是一份 x，代价不变，相当于只插入一次。否则，一份旧的最大折点被降低到 x，同时为新位置保留一份 x。
  5. 每遍最后的 cost 是该方向最小值。两遍结果取最小；不需要修改 nums。

示例轨迹：nums = [3,2,4,5,0]

非递减方向累计代价为 0 → 1 → 1 → 1 → 6。非递增方向扫描 −3, −2, −4, −5, 0，累计代价为 0 → 0 → 2 → 4 → 4。因此答案为 min(6,4) = 4。

看到最后的 0 时，非递减堆只移除一个最大值 5，增量为 5。不能把堆里所有大于 0 的值都弹掉；那些折点仍编码着未来选择的代价。

正确性 · 用代价函数解释“只弹一次”

定义 Fᵢ(t)：将前 i 个数变成非递减序列，且所有结果都 ≤ t 时的最小代价。空前缀 F₀(t)=0。读入 x 后：

Fᵢ(t) = min over y ≤ t { Fᵢ₋₁(y) + |y − x| }

维护不变式：Fᵢ(t) = C + Σₕ∈H max(h − t, 0)。其中 H 为堆的多重集合，C 为无上界限制时的最小代价。函数由若干斜率为 −1 的折线片段组成，最大折点控制最右侧下降区间。

设旧堆的最大值为 M。若堆为空或 M ≤ x，新增的绝对值项只留下位于 x 的下降折点；C 不变，H 插入 x。若 M > x，在 x 到 M 之间，新绝对值项的 +1 斜率抵消旧函数最右侧的一层下降斜率；取前缀最小后，最大折点 M 被移走，新增两份 x，而最低代价增加 M − x。

两种情况都等价于：把 x 放入两次，移除新堆最大值 m，令 C 加上 m − x。因此归纳地保持上述表示。t 足够大时所有 max 项为 0，故 C 正是该前缀无上界限制的最优值。

最后，取负是一一对应：b 非递增当且仅当 −b 非递减，且 |a − b| = |−a − (−b)|。两遍分别求出两个合法目标集合的最优值，取较小者即整体最优。

复杂度、边界与替代方案

  • 时间 O(n log n)，空间 O(n)：每个元素两次插入、一次移除，共两遍，堆大小不超过 n+1 的临时上界。
  • 单元素、全相等以及任一方向已经单调，答案均为 0。值为 0 可直接取负，无需特殊分支。
  • 原约束下把全部元素改为 0 的代价不超过 10⁶，32 位有符号整数足够；扩展到更大值域时，Java / C++ 应改用 64 位累计值。
  • 替代方案：值域 DP。dp[v] 表示当前结尾取 v 的最小代价；转移为 new[v] = min(dp[u], u ≤ v) + |x−v|。用前缀最小值把单层计算降为 O(V)，V=1001，总时间 O(nV)、空间 O(V)。第二遍可反转输入来复用非递减计算。
  • DP 只枚举 0～1000 足够：将任何目标值截断到该范围，会保持单调性且不会增加与原值的距离。大值域时可压缩到原数组出现的值，最坏 O(n²)。

常见错误

  • 把“非递减”当作“严格递增”；相等是允许的。
  • 只求一个方向，或把排序后的数组与原数组逐项相减；排序固定了目标多重集合，可能错过更优目标。
  • 只插入 x 一次又无条件弹出一次，使堆丢失每个位置贡献的折点。
  • 把最大堆当作最终目标，或用 while 消除所有较大值；它保存的是函数状态。
  • Java PriorityQueue 默认是最小堆；Python 需要用负数模拟最大堆。算法取负与堆取负是不同层次。

面试追问

如何输出目标数组？ 值域 DP 保存每层的前驱选择再回溯最直接，需额外 O(nV) 空间；当前堆版本只返回成本，不能直接把堆排序当作目标。

若每个位置有不同修改权重？ DP 的绝对值代价乘以权重仍成立；堆的折点需要带权斜率，不能原样套用“两次入堆”。

若要求严格单调？ 整数严格递增可令 c[i]=b[i]−i，将输入改为 nums[i]−i 后求非递减；严格递减可先取负再做同样变换，值域界也要同步调整。

Java

import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public int convertArray(int[] nums) {
        return Math.min(cost(nums, 1), cost(nums, -1));
    }

    private int cost(int[] nums, int sign) {
        PriorityQueue<Integer> heap =
            new PriorityQueue<>(Collections.reverseOrder());
        int total = 0;
        for (int value : nums) {
            int x = sign * value;
            heap.offer(x);
            heap.offer(x);
            total += heap.poll() - x;
        }
        return total;
    }
}

JavaScript

/** @param {number[]} nums @return {number} */
var convertArray = function(nums) {
    function cost(sign) {
        const heap = [];
        function push(x) {
            let i = heap.length;
            heap.push(x);
            while (i > 0) {
                const p = (i - 1) >> 1;
                if (heap[p] >= x) break;
                heap[i] = heap[p];
                i = p;
            }
            heap[i] = x;
        }
        function pop() {
            const top = heap[0];
            const last = heap.pop();
            if (heap.length === 0) return top;
            let i = 0;
            while (2 * i + 1 < heap.length) {
                let child = 2 * i + 1;
                if (child + 1 < heap.length &&
                    heap[child + 1] > heap[child]) child++;
                if (heap[child] <= last) break;
                heap[i] = heap[child];
                i = child;
            }
            heap[i] = last;
            return top;
        }
        let total = 0;
        for (const value of nums) {
            const x = value * sign;
            push(x);
            push(x);
            total += pop() - x;
        }
        return total;
    }
    return Math.min(cost(1), cost(-1));
};

Python

from typing import List
import heapq

class Solution:
    def convertArray(self, nums: List[int]) -> int:
        def cost(sign: int) -> int:
            heap = []
            total = 0
            for value in nums:
                x = sign * value
                # Negated keys simulate a max heap.
                heapq.heappush(heap, -x)
                heapq.heappush(heap, -x)
                maximum = -heapq.heappop(heap)
                total += maximum - x
            return total

        return min(cost(1), cost(-1))

#include <algorithm>
#include <queue>
#include <vector>

class Solution {
    int cost(const vector<int>& nums, int sign) {
        priority_queue<int> heap;
        int total = 0;
        for (int value : nums) {
            int x = sign * value;
            heap.push(x);
            heap.push(x);
            total += heap.top() - x;
            heap.pop();
        }
        return total;
    }
public:
    int convertArray(vector<int>& nums) {
        return min(cost(nums, 1), cost(nums, -1));
