Middle of the Linked List · 非付费题

Problem

题目说明

给定一个单链表的头结点 head，返回链表的中间结点。返回的是该结点本身，因此展示结果时会看到从中间结点开始的整段后缀链表。

偶数长度规则：若链表有两个中间结点，返回其中第二个。

函数签名

middleNode(head: ListNode) → ListNode

约束

  • 链表结点数在 [1, 100] 内。
  • 1 ≤ Node.val ≤ 100。

示例 1 · 奇数长度

输入：head = [1,2,3,4,5]
输出：[3,4,5]
解释：唯一中间结点的值为 3。

示例 2 · 偶数长度

输入：head = [1,2,3,4,5,6]
输出：[4,5,6]
解释：两个中间结点为 3 和 4，返回第二个。

Pointer Lab

让两名跑者一起出发

慢指针每轮走 1 步，快指针每轮走 2 步。观察快指针抵达边界时，慢指针停在哪里。

键盘提示：聚焦按钮后可用 Enter 或 Space 操作。系统启用“减少动态效果”时，自动播放会放慢。

Solution

准备好看完整题解了吗？

这里会展开推导、证明与四种语言实现。

核心洞察

让 slow 一次走一步，让 fast 一次走两步。当 fast 无法再走完整的两步时，slow 已走了链表长度的一半（向下取整），正好位于题目要求的中间结点。

循环条件使用 fast != null && fast.next != null，既避免访问空指针，也自然保证偶数长度时落在第二个中点。

完整过程

  1. slow 与 fast 都从 head 出发。
  2. 只要快指针及其下一个结点存在，就执行一轮移动。
  3. slow = slow.next，同时 fast = fast.next.next。
  4. 循环结束后直接返回 slow。

正确性证明

设链表长度为 n。每完成一轮，慢指针走 1 条边、快指针走 2 条边。

  • 若 n = 2k+1，循环执行 k 轮，慢指针位于下标 k，即唯一中点。
  • 若 n = 2k，循环执行 k 轮，慢指针位于下标 k，即两个中点中的第二个。

两种长度均返回题目要求的结点，因此算法正确。

边界与复杂度

  • 单结点：循环不执行，直接返回头结点。
  • 双结点：执行一轮，返回第二个结点。
  • 时间：O(n)，快指针最多遍历整条链。
  • 额外空间：O(1)，只维护两个指针。

四语言实现

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode middleNode(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }
}
/**
 * Definition for singly-linked list.
 * function ListNode(val, next) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.next = (next === undefined ? null : next);
 * }
 */
/** @param {ListNode} head @return {ListNode} */
var middleNode = function(head) {
    let slow = head;
    let fast = head;
    while (fast !== null && fast.next !== null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow;
};

class Solution:

        slow = fast = head
        while fast is not None and fast.next is not None:
            slow = slow.next

 * Definition for singly-linked list.

 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(nullptr) {}
 * };

public:

            fast = fast->next->next;

};

替代方案

先计数再定位：第一次遍历求长度 n，第二次前进 ⌊n/2⌋ 步。它同样是 O(n) 时间、O(1) 空间，但需要两趟遍历。

数组保存结点：把所有结点存入数组后取 nodes[n/2]，思路直接，但需要 O(n) 额外空间。

面试追问

  • 若要求返回两个中点中的第一个，循环条件应如何改变？
  • 快慢指针为什么还能用于检测链表环？
  • 能否寻找链表的三分之一位置？如何设计不同速度？

常见错误

  • 只判断 fast != null，随后访问 fast.next.next 导致空指针。
  • 偶数长度时错误地返回第一个中点。
  • 误以为要返回中点的值；官方签名要求返回结点。
  • 为了计数而修改或断开原链表。

记忆锚点

快指针跑完全程，慢指针恰好跑半程。终点不是答案，快指针只是替慢指针丈量距离。
