785. 判断二分图

把一张无向图分成两个互不“内连”的阵营。先读题，再在实验台里逐步观察节点如何入队、分组，以及一条冲突边怎样让方案失效。

无向图广度优先搜索深度优先搜索图着色

Problem brief

题目描述

有一个包含 n 个节点的无向图，节点编号为 0 到 n - 1。输入二维数组 graph，其中 graph[u] 列出与节点 u 相邻的所有节点。

请判断能否把全部节点划分到两个独立集合 A 和 B 中，使每一条边的两个端点分属不同集合。能则返回 true，否则返回 false。

二分图：图中每条边都跨越两个集合，不允许边的两个端点落在同一集合。

输入图保证

  • 没有自环，也没有重复边。
  • 邻接关系对称：若 v 在 graph[u] 中，则 u 也在 graph[v] 中。
  • 图不一定连通，可能包含多个互不相连的连通分量。

Contract

函数与约束

函数签名

isBipartite(graph) → boolean
  • graph.length == n
  • 1 <= n <= 100
  • 0 <= graph[u].length < n
  • 0 <= graph[u][i] <= n - 1
  • graph[u] 不包含 u
  • graph[u] 中的值互不相同
  • 无向边在邻接表中双向出现
返回值：当且仅当整个图是二分图时返回 true。

Complete solution

完整题解：BFS 二着色

核心洞察

把两个集合看成两种颜色。任选一个尚未访问的节点着为颜色 0；沿每条边传播时，相邻节点必须使用相反颜色。若某条边连接了两个同色节点，二分条件立即被破坏。由于图可能不连通，需要从每个尚未着色的节点启动一次遍历。

完整过程

  1. 建立颜色数组。
    令 color[i] = -1 表示未着色，0 和 1 表示两个集合。
  2. 覆盖所有连通分量。
    从 0 到 n−1 枚举节点；只有遇到未着色节点时，才把它设为 0 并加入队列。
  3. 按层扩散。
    取出队首节点 u，逐个检查邻居 v。若 v 未着色，则赋值为 color[u] ^ 1 并入队。
  4. 检测矛盾。
    若 v 已着色且 color[v] == color[u]，当前边两端同色，直接返回 false。
  5. 完成判定。
    所有分量都遍历完且未发现冲突，返回 true。

正确性证明

引理：遍历保持边的异色约束

当访问边 (u, v) 时，若 v 未着色，算法把 v 设为 u 的相反颜色；若 v 已着色，算法显式检查两者是否异色。因此算法继续运行时，所有已检查边均连接异色端点。

冲突时返回 false 正确

若边 (u, v) 两端同色，当前遍历中从起点到 u、v 的颜色奇偶关系已经确定。这条边要求二者异色，与既有关系矛盾，对应一个奇环，所以该连通分量不可能二分。

无冲突时返回 true 正确

遍历结束后，每条边都已被检查且两端异色。把颜色 0 的节点作为 A、颜色 1 的节点作为 B，则两个集合内部都没有边，得到合法二分。

覆盖性

外层循环为每个未着色节点启动遍历，因此每个连通分量、每个节点及每条边都会被处理，不会漏掉非连通部分中的冲突。

复杂度

TIME

O(V + E)

每个节点最多入队一次；无向图邻接表中的每条边会从两个方向各检查一次。

SPACE

O(V)

颜色数组与 BFS 队列最多各保存与节点数同阶的数据。

边界情况

  • 只有一个节点或完全没有边：总能二分。
  • 多个连通分量：必须对每个未着色节点重新启动遍历。
  • 偶数环：可以交替着色；奇数环：最后一条边会连接同色节点。
  • 树：不存在环，始终可以按层次奇偶二分。
  • 孤立节点可以放入任意集合，不影响结果。

import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Queue;

class Solution {
    public boolean isBipartite(int[][] graph) {
        int n = graph.length;
        int[] color = new int[n];
        Arrays.fill(color, -1);

        for (int start = 0; start < n; start++) {
            if (color[start] != -1) continue;

            Queue<Integer> queue = new ArrayDeque<>();
            color[start] = 0;
            queue.offer(start);

            while (!queue.isEmpty()) {
                int u = queue.poll();
                for (int v : graph[u]) {
                    if (color[v] == -1) {
                        color[v] = color[u] ^ 1;
                        queue.offer(v);
                    } else if (color[v] == color[u]) {
                        return false;
                    }
                }
            }
        }
        return true;
    }
}

var isBipartite = function(graph) {
    const n = graph.length;
    const color = new Array(n).fill(-1);

    for (let start = 0; start < n; start++) {
        if (color[start] !== -1) continue;

        const queue = [start];
        let head = 0;
        color[start] = 0;

        while (head < queue.length) {
            const u = queue[head++];
            for (const v of graph[u]) {
                if (color[v] === -1) {
                    color[v] = color[u] ^ 1;
                    queue.push(v);
                } else if (color[v] === color[u]) {
                    return false;
                }
            }
        }
    }
    return true;
};
from collections import deque
from typing import List


class Solution:
    def isBipartite(self, graph: List[List[int]]) -> bool:
        n = len(graph)
        color = [-1] * n

        for start in range(n):
            if color[start] != -1:
                continue

            queue = deque([start])
            color[start] = 0

            while queue:
                u = queue.popleft()
                for v in graph[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        queue.append(v)
                    elif color[v] == color[u]:
                        return False

        return True

替代方案

DFS

递归或显式栈着色

规则完全相同，只把队列换成深度优先过程。复杂度仍为 O(V + E)；递归实现要考虑语言的调用栈上限。

DSU

并查集约束

对每个节点，把它的所有邻居合并为同一组，并确认节点本身不与邻居同组。可行，但在这道邻接表题里不如二着色直观。

面试追问

  • 如何返回具体划分？ 遍历结束后按 color 值收集两个节点列表。
  • 如何给出失败证据？ 保存 BFS 父节点；发现同色边时回溯两条父链，重建一个奇环。
  • 动态图持续加边怎么办？ 可研究带奇偶关系的并查集，维护端点之间的异色约束。
  • 输入是边列表怎么办？ 先用 O(V + E) 空间构造邻接表，再执行相同算法。

常见错误

  • 只从节点 0 遍历，漏掉非连通分量。
  • 用默认值 0 同时表示“未访问”和“A 组”，导致状态混淆。
  • 给未着色邻居分色后忘记入队，后续边没有被检查。
  • 只检查新节点，不检查已着色邻居是否与当前节点同色。
  • 看到环就返回 false；真正导致失败的是奇环，偶数环可以二分。
