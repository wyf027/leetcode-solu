一棵有根树混入了一条有向边。你的任务不是随便断开一个环，而是找出那条同时满足父节点规则、连通性，以及“答案取输入中最后出现者”的边。

Problem

题意与输入

有根树中恰有一个根没有父节点，其余每个节点恰有一个父节点，并且所有节点都能从根到达。

任务转述

给定节点编号为 1…n 的有向图。它原本是一棵有 n 个节点的有根树，后来额外加入了一条此前不存在、且两端不同的有向边。

edges[i] = [uᵢ, vᵢ] 表示父节点 uᵢ 指向子节点 vᵢ。请返回一条应删除的边，使余下的 n-1 条边重新构成包含全部节点的有根树；如果有多个合法选择，返回在 edges 中位置最靠后的那一条。

findRedundantDirectedConnection(edges: integer[][]) → integer[]

约束

  • n == edges.length
  • 3 ≤ n ≤ 1000
  • edges[i].length == 2
  • 1 ≤ uᵢ, vᵢ ≤ n
  • uᵢ != vᵢ

示例 1

输入edges = [[1,2],[1,3],[2,3]]
输出[2,3]

节点 3 同时收到来自 1 和 2 的入边；删除后出现的那条边即可恢复有根树。

示例 2

输入edges = [[1,2],[2,3],[3,4],[4,1],[1,5]]
输出[4,1]

四个节点构成有向环；移除输入中最后出现的可删除环边。

Solution unlocked

题解：先定候选，再判环

难点不是并查集本身，而是有向树可能同时违反“每个非根节点一个父亲”和“无环”两条规则。

核心洞察

原图由有根树加一条边得到，因此异常只会落入以下三种结构。先扫描所有边定位唯一可能的入度 2 节点；若存在，记它的较早入边为 A、较晚入边为 B。随后临时跳过 B，用并查集检查剩余边是否仍出现无向连通意义上的环。

CASE 01

没有入度 2

只有环。并查集中第一次连接两个已连通节点的边，就是输入顺序中最靠后的可删除环边。

CASE 02

入度 2，跳 B 后无环

B 正是额外边；移除 B 后，每个非根节点只有一个父亲且整体连通。

CASE 03

入度 2，跳 B 后仍有环

B 不在残留环中，环必然经过 A；应移除较早的入边 A。

完整过程

  1. 登记父节点。 从前向后扫描 [u,v]。若 v 尚无父节点，记录 parentOf[v]=u；否则得到 A=[parentOf[v],v] 与 B=[u,v]。
  2. 建立并查集。 把每个节点初始化为独立集合。若存在 B，在本轮合并中跳过 B；没有入度冲突则不跳边。
  3. 逐边合并端点。 对每条未跳过的 [u,v]，若 find(u)==find(v)，说明加入该边会闭合环。
  4. 根据分支返回。 遇到环且存在 A 时返回 A；遇到环但没有 A 时返回当前边；所有边都合并成功则返回 B。

正确性证明

引理 1：若存在入度 2 节点，答案必在 A、B 中。

原始有根树中每个非根节点恰有一个父节点。额外边只会让其终点多出一个父节点，因此要恢复该性质，必须删除指向该节点的两条边之一。

引理 2：跳过 B 后无环时，删除 B 正确。

剩余 n-1 条边无环；它们来自原连通树加边再删边，并且所有节点入度至多 1。此时无环的 n 节点、n-1 条边结构连通并具有唯一根，所以构成有根树。由引理 1，应删除 B。

引理 3：跳过 B 后仍有环时，删除 A 正确。

残留环不含已跳过的 B。根据引理 1 答案只能是 A 或 B，而删除 B 仍不能消环，因此环必含 A，删除 A 才能同时消除环与双父冲突。

引理 4：没有入度 2 时，并查集发现的边正确。

异常只剩一个环。按输入顺序合并时，环中最后出现的边连接两个已连通端点；它也是所有可删除环边中输入位置最靠后的，符合题目的择后规则。

定理。

算法覆盖是否存在入度 2、跳边后是否存在环的全部情况，并在每一分支返回唯一满足恢复有根树与择后规则的边，因此算法正确。

边界与复杂度

时间 O(n α(n)) 空间 O(n) n = edges.length

需要特别覆盖：根节点落入环、双父节点位于环上、额外边只造成双父但不成环，以及没有双父时的长环。并查集按秩合并并路径压缩，α(n) 可视为极小常数。

class Solution {
    public int[] findRedundantDirectedConnection(int[][] edges) {
        int n = edges.length;
        int[] parentOf = new int[n + 1];
        int firstIndex = -1;
        int secondIndex = -1;

        // 找到指向同一节点的两条边 A、B。
        for (int i = 0; i < n; i++) {
            int v = edges[i][1];
            if (parentOf[v] == 0) {
                parentOf[v] = i + 1; // 加 1，避免与未登记的 0 混淆
            } else {
                firstIndex = parentOf[v] - 1;
                secondIndex = i;
                break;
            }
        }

        UnionFind uf = new UnionFind(n);
        for (int i = 0; i < n; i++) {
            if (i == secondIndex) continue;
            int u = edges[i][0];
            int v = edges[i][1];
            if (!uf.union(u, v)) {
                return firstIndex == -1 ? edges[i] : edges[firstIndex];
            }
        }

        return edges[secondIndex];
    }

    private static class UnionFind {
        private final int[] parent;
        private final int[] rank;

        UnionFind(int n) {
            parent = new int[n + 1];
            rank = new int[n + 1];
            for (int i = 1; i <= n; i++) parent[i] = i;
        }

        int find(int x) {
            if (parent[x] != x) parent[x] = find(parent[x]);
            return parent[x];
        }

        boolean union(int a, int b) {
            int rootA = find(a);
            int rootB = find(b);
            if (rootA == rootB) return false;
            if (rank[rootA] < rank[rootB]) {
                parent[rootA] = rootB;
            } else if (rank[rootA] > rank[rootB]) {
                parent[rootB] = rootA;
            } else {
                parent[rootB] = rootA;
                rank[rootA]++;
            }
            return true;
        }
    }
}

/**
 * @param {number[][]} edges

var findRedundantDirectedConnection = function(edges) {
    const n = edges.length;
    const parentOf = Array(n + 1).fill(-1);
    let firstIndex = -1;
    let secondIndex = -1;

    for (let i = 0; i < n; i++) {
        const v = edges[i][1];
        if (parentOf[v] === -1) {
            parentOf[v] = i;
        } else {
            firstIndex = parentOf[v];
            secondIndex = i;
            break;
        }
    }

    const parent = Array.from({ length: n + 1 }, (_, i) => i);
    const rank = Array(n + 1).fill(0);

    const find = (x) => {
        if (parent[x] !== x) parent[x] = find(parent[x]);
        return parent[x];
    };

    const union = (a, b) => {
        let rootA = find(a);
        let rootB = find(b);
        if (rootA === rootB) return false;
        if (rank[rootA] < rank[rootB]) [rootA, rootB] = [rootB, rootA];
        parent[rootB] = rootA;
        if (rank[rootA] === rank[rootB]) rank[rootA]++;
        return true;
    };

    for (let i = 0; i < n; i++) {
        if (i === secondIndex) continue;
        const [u, v] = edges[i];
        if (!union(u, v)) {
            return firstIndex === -1 ? edges[i] : edges[firstIndex];
        }
    }

    return edges[secondIndex];
};

from typing import List


class Solution:
    def findRedundantDirectedConnection(
        self, edges: List[List[int]]
    ) -> List[int]:
        n = len(edges)
        parent_of = [-1] * (n + 1)
        first_index = -1
        second_index = -1

        for i, (_, v) in enumerate(edges):
            if parent_of[v] == -1:
                parent_of[v] = i
            else:
                first_index = parent_of[v]
                second_index = i
                break

        parent = list(range(n + 1))
        rank = [0] * (n + 1)

        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(a: int, b: int) -> bool:
            root_a, root_b = find(a), find(b)
            if root_a == root_b:
                return False
            if rank[root_a] < rank[root_b]:
                root_a, root_b = root_b, root_a
            parent[root_b] = root_a
            if rank[root_a] == rank[root_b]:
                rank[root_a] += 1
            return True

        for i, (u, v) in enumerate(edges):
            if i == second_index:
                continue
            if not union(u, v):
                return edges[i] if first_index == -1 else edges[first_index]

        return edges[second_index]

class Solution {
public:
    vector<int> findRedundantDirectedConnection(vector<vector<int>>& edges) {
        int n = static_cast<int>(edges.size());
        vector<int> parentOf(n + 1, -1);
        int firstIndex = -1;
        int secondIndex = -1;

        for (int i = 0; i < n; ++i) {
            int v = edges[i][1];
            if (parentOf[v] == -1) {
                parentOf[v] = i;
            } else {
                firstIndex = parentOf[v];
                secondIndex = i;
                break;
            }
        }

        parent.resize(n + 1);
        rank.assign(n + 1, 0);
        iota(parent.begin(), parent.end(), 0);

        for (int i = 0; i < n; ++i) {
            if (i == secondIndex) continue;
            int u = edges[i][0];
            int v = edges[i][1];
            if (!unite(u, v)) {
                return firstIndex == -1 ? edges[i] : edges[firstIndex];
            }
        }

        return edges[secondIndex];
    }

private:
    vector<int> parent;
    vector<int> rank;

    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }

    bool unite(int a, int b) {
        int rootA = find(a);
        int rootB = find(b);
        if (rootA == rootB) return false;
        if (rank[rootA] < rank[rootB]) swap(rootA, rootB);
        parent[rootB] = rootA;
        if (rank[rootA] == rank[rootB]) ++rank[rootA];
        return true;
    }
};

替代方案、追问与常见错误

替代方案与面试追问

  • 可以对每一条边尝试删除，再用入度统计与 DFS/BFS 验证是否为有根树，但复杂度会上升到 O(n²)。
  • 追问：为什么把有向边的两个端点放进无向并查集仍能判环？因为父节点冲突已经单独处理，剩余结构中一条边闭合底层无向环，正对应有向树结构失败。
  • 追问：如何不用递归实现 find？先向上找到根，再沿路径二次遍历压缩父指针。
  • 追问：若不保证“树加一条边”，三分支结论还成立吗？不成立；可能出现多个冲突和多个环，需要完整的有向图校验。

常见错误

  • 直接套用 684 的无向环逻辑，漏掉“同一节点两个父亲但没有环”的情况。
  • 发现入度 2 就无条件返回 B；若跳过 B 后仍有环，真正答案是 A。
  • 修改 edges 本身来标记跳边，导致输入被污染或返回错误引用；记录索引更安全。
  • 候选边顺序写反。A 必须是先出现的父边，B 是后出现的父边，择后规则依赖这个顺序。
  • 并查集初始化遗漏节点 n，或把编号从 1 开始的问题误写成长度 n 的数组。
