LCR 071中等 MEDIUM

按权重随机选择

给定正整数权重数组，按权重比例随机返回下标。

交互演示

题意、示例与约束

输入：w = [1,3]

含义：下标 0 的概率 1/4，下标 1 的概率 3/4。

  • 1 ≤ w.length ≤ 10⁴。
  • 每个权重为正整数。
  • pickIndex 会被调用多次，应让单次查询尽量快。

分步交互：前缀和定位

w=[1,3,2] 的前缀和为 [1,4,6]；随机整数落在对应区间即选中该下标。

核心洞察与过程

将第 i 个权重映射到长度为 w[i] 的连续整数区间。前缀和数组严格递增，随机生成 [1,total] 的整数 x 后，二分寻找第一个不小于 x 的前缀和，其下标就是答案。

  1. 1. 预处理
    构建前缀和。
  2. 2. 随机
    生成 1 到 total。
  3. 3. 二分
    找 lower bound。
  4. 4. 返回
    对应下标。

边界、复杂度、替代与错误

边界：单元素必返回 0；随机区间必须含两端。
复杂度：初始化 O(n)，每次选择 O(log n)，空间 O(n)。
替代：线性扫描每次 O(n)；大量采样可用 Alias Method 达到 O(1)。
追问：如何支持动态修改权重？可用树状数组。
常见错误：随机范围从 0 开始却使用错误二分；返回第一个大于而非大于等于 x；未用前缀和。
