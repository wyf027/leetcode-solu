1155. 掷骰子等于目标和的方法数

Number of Dice Rolls With Target Sum · 用可视化观察“增加一枚骰子”如何转移计数。

题目

有 n 个相同的骰子，每个骰子的点数为 1..k。求所有有序投掷结果中，点数总和恰好为 target 的方案数；答案对 1,000,000,007 取模。

函数：numRollsToTarget(n, k, target) → integer

示例 1

输入：n = 1, k = 6, target = 3
输出：1
解释：只有投出 3 这一种方案。

示例 2

输入：n = 2, k = 6, target = 7
输出：6
解释：1+6、2+5、3+4、4+3、5+2、6+1。

示例 3

输入：n = 30, k = 30, target = 500
输出：222616187
解释：结果对 10^9 + 7 取模。

约束

  • 1 ≤ n, k ≤ 30
  • 1 ≤ target ≤ 1000

状态转移实验室

固定演示 n=3, k=4, target=7。第 d 步展示恰好使用 d 枚骰子时，各个和的方案数。先观察变化，再决定是否查看题解。

可达状态金色边框：目标和 7

测试与验证

题解：一维动态规划

核心洞察

方案的最后一枚骰子必然取某个点数 face ∈ [1,k]。若当前总和为 sum，移除它后，前面的骰子必须组成 sum-face。因此不同末尾点数对应的方案互不重叠，可以直接相加。

完整过程

  1. 令 dp[s] 表示处理完当前枚数后，总和为 s 的方案数；空序列初始化为 dp[0]=1。
  2. 每加入一枚骰子，新建全零数组 next，枚举旧和与点数，把 dp[sum] 累加到 next[sum+face]。
  3. 重复 n 次并返回 dp[target]。每次累加取模。

正确性证明

不变式：第 d 轮后，dp[s] 等于用恰好 d 枚骰子得到和 s 的方案数。初始时空投掷仅能得到和 0，命题成立。归纳地，每个长度为 d+1、和为 s 的方案都能唯一拆成一个长度为 d、和为 s-face 的前缀和最后点数 face；转移恰好枚举所有唯一拆分，既不遗漏也不重复。故最终 dp[target] 正确。

边界与复杂度

若 target<n 或 target>n·k 可直接返回 0。时间复杂度 O(n·target·k)，空间复杂度 O(target)。

替代方案

二维 DP 更直观但需 O(n·target) 空间；前缀和可将每轮转移优化到 O(target)，总时间 O(n·target)，但窗口边界更容易写错。递归记忆化表达自然，仍有函数调用开销。

面试追问

  • 如何用滑动窗口把内层枚举点数消掉？
  • 如果不同骰子的面数不同，状态和转移如何变化？
  • 为什么必须使用新数组，不能按任意顺序原地更新？

常见错误

  • 把骰子视为无序，错误地合并 (1,6) 与 (6,1)。
  • 初始化成 dp[1]=1，而不是空前缀 dp[0]=1。
  • 原地正序更新，导致同一轮重复使用骰子。
  • 忘记剪枝上界或取模，造成越界或溢出。

四语言完整代码

class Solution {
    public int numRollsToTarget(int n, int k, int target) {
        final int MOD = 1_000_000_007;
        if (target < n || target > n * k) return 0;
        int[] dp = new int[target + 1]; dp[0] = 1;
        for (int d = 0; d < n; d++) {
            int[] next = new int[target + 1];
            for (int s = 0; s <= target; s++) for (int f = 1; f <= k && s + f <= target; f++)
                next[s + f] = (next[s + f] + dp[s]) % MOD;
            dp = next;
        }
        return dp[target];
    }
}

class Solution:
    def numRollsToTarget(self, n: int, k: int, target: int) -> int:
        MOD = 10**9 + 7
        if target < n or target > n * k: return 0
        dp = [1] + [0] * target
        for _ in range(n):
            nxt = [0] * (target + 1)
            for s in range(target + 1):
                for face in range(1, min(k, target - s) + 1):
                    nxt[s + face] = (nxt[s + face] + dp[s]) % MOD
            dp = nxt
        return dp[target]
class Solution {
public:
    int numRollsToTarget(int n, int k, int target) {
        const int MOD = 1000000007;
        if (target < n || target > n * k) return 0;
        vector<int> dp(target + 1); dp[0] = 1;
        for (int d = 0; d < n; ++d) {
            vector<int> next(target + 1);
            for (int s = 0; s <= target; ++s)
                for (int f = 1; f <= k && s + f <= target; ++f)
                    next[s + f] = (next[s + f] + dp[s]) % MOD;
            dp.swap(next);
        }
        return dp[target];
    }
};
