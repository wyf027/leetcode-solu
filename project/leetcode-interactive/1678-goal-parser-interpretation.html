解析器

读懂一种只有三种符号的微型语言：按原顺序解释每个片段，并返回最终拼接的字符串。

EASY字符串非付费题Goal Parser Interpretation

01 · Problem

题目要求

给定字符串 command，它完全由 "G"、"()" 和 "(al)" 按任意顺序拼接而成。Goal 解析器会按下面的规则解释每个片段，再保持原顺序连接结果并返回。

"G"→"G"
"()"→"o"
"(al)"→"al"

02 · Examples

官方示例

示例 1
输入：command = "G()(al)"
输出："Goal"
解释：G → G，() → o，(al) → al
示例 2
输入：command = "G()()()()(al)"
输出："Gooooal"
示例 3
输入：command = "(al)G(al)()()G"
输出："alGalooG"

约束

  • 1 <= command.length <= 100
  • command 只由合法片段 "G"、"()"、"(al)" 组成。

04 · Solution

准备好看题解了吗？

建议先在上面的解析磁带里走完一个示例，再展开完整思路、证明和四种语言实现。

Complete Walkthrough

一次扫描，按首字符判断片段

核心洞察

合法输入只含三类片段。当前位置若为 G，片段已确定；若为左括号，只需再看下一个字符：右括号表示 ()，否则一定是 (al)。

完整过程

  1. 用指针 i 从左向右扫描。
  2. 遇到 G，写入 G 并前进 1。
  3. 遇到 ()，写入 o 并前进 2。
  4. 否则写入 al 并前进 4。
  5. 指针到达末尾后返回累计结果。

边界情况

  • 最短合法输入，如 G 或 ()。
  • 只包含同一种片段，如 GGG。
  • 以 (al) 开头或结尾。
  • 长度达到 100；算法仍只扫描一次。

复杂度

设 n = command.length。扫描耗时 O(n)；除返回字符串外，额外空间为 O(1)。若计入返回值，空间为 O(n)。

正确性说明

循环不变量：每轮开始时，结果串恰好是 command[0..i) 中所有完整片段的正确解释。

初始化：i = 0、结果为空，不变量成立。保持：合法输入保证当前位置只可能开始三种片段；分支准确识别它，追加规定解释，并让 i 越过整个片段，因此不变量继续成立。终止：当 i = n，全部片段均已解释，所以结果就是整个命令的解释。

替代方案

可以连续调用字符串替换：先把 "()" 替换成 "o"，再把 "(al)" 替换成 "al"。代码更短，但通常会产生中间字符串；单次扫描更直接地体现解析过程。

面试追问

  • 如果词法片段增多且存在共同前缀，如何使用 Trie？
  • 如果输入可能非法，如何返回错误位置？
  • 若输入来自字符流，怎样做到在线解析？

常见错误

  • 遇到左括号后只前进 1，导致重复读取。
  • 用 command[i + 1] 判断，却忘记题目已保证输入合法。
  • 替换顺序或正则转义写错，把括号当作元字符。

选择实现

下面四份代码均采用一次扫描。Java 与 C++ 使用可变字符串缓冲区；JavaScript 用数组收集；Python 用列表后统一连接，避免频繁复制。

四语言完整代码

class Solution {
    public String interpret(String command) {
        StringBuilder answer = new StringBuilder();
        int i = 0;

        while (i < command.length()) {
            if (command.charAt(i) == 'G') {
                answer.append('G');
                i += 1;
            } else if (command.charAt(i + 1) == ')') {
                answer.append('o');
                i += 2;
            } else {
                answer.append("al");
                i += 4;
            }
        }
        return answer.toString();
    }
}

var interpret = function(command) {
    const answer = [];

    while (i < command.length) {
        if (command[i] === 'G') {
            answer.push('G');
            i += 1;
        } else if (command[i + 1] === ')') {
            answer.push('o');
            i += 2;
        } else {
            answer.push('al');
            i += 4;
        }
    }
    return answer.join('');
};
