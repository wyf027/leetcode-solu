构造奇偶一致的数组 II

别把每个位置当作独立操作：最小元素没有更小的数可减，它的奇偶性就是整题的锚点。

题意

给定互不相同的正整数数组 nums1。每个位置可以保留原值，或减去一个更小的数组元素（差必须至少为 1）。问能否令新数组全部为奇数，或全部为偶数。

示例 1

nums1 = [1, 4, 7]

可构成 [1, 3, 7]，结果为 true。

示例 2

nums1 = [2, 3]

最小值为偶且有奇数，结果为 false。

约束：2 ≤ nums1.length ≤ 10⁵；元素互不相同；1 ≤ nums1[i] ≤ 10⁹。

最小值锚点

输入 nums1 = [1, 4, 7]

    题解：只需看最小值

    核心洞察

    最小元素无法执行减法，因此它的奇偶性固定。若最小值是奇数，任一偶数都可减去该最小值变成奇数；奇数直接保留。若最小值是偶数，目标只能是偶数；一旦存在奇数，其中最小的奇数没有更小奇数可减，无法改变奇偶性。

    结论与复杂度

    min(nums1) 为奇数时可行；否则只有全体偶数时可行。扫描一次即可，时间 O(n)，额外空间 O(1)。

    边界、替代方案与追问

    • 数组长度为 2 时结论同样成立。
    • 不要枚举所有 j：值域很大，枚举会退化为 O(n²)。
    • 若允许减去任意正数，锚点不再成立，需要重新分析可达性。
    • 常见错误：只看奇偶数量；真正的限制来自“最小元素没有可减对象”。

    四语言可提交代码

    Java 
    class Solution { public boolean uniformArray(int[] nums1) { int min = Integer.MAX_VALUE; for (int v : nums1) min = Math.min(min, v); if ((min & 1) == 1) return true; for (int v : nums1) if ((v & 1) == 1) return false; return true; } }
    JavaScript 
    var uniformArray = function(nums1) { const min = Math.min(...nums1); return min % 2 === 1 || nums1.every(value => value % 2 === 0); };
    Python 
    class Solution:
    def uniformArray(self, nums1: list[int]) -> bool:
        minimum = min(nums1)
        return minimum % 2 == 1 or all(value % 2 == 0 for value in nums1)

    class Solution { public: bool uniformArray(vector<int>& nums1) { int minimum = *min_element(nums1.begin(), nums1.end()); return minimum % 2 == 1 || all_of(nums1.begin(), nums1.end(), [](int x) { return x % 2 == 0; }); } };
