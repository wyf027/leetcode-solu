最大方阵和

Maximum Matrix Sum

每次翻转两个相邻数字。你能让整个方阵的和变得多大？

先探索合法操作，再展开页面底部的推导与代码。

01 / 题目与规则

给定整数方阵 matrix，大小为 n × n。每次可以选中两个共享一条边的格子，同时将它们的数值乘以 -1。操作可以执行零次或任意多次，求最终所有元素之和的最大值。

只有上下、左右相邻合法；对角线不算相邻。操作不移动格子，也不改变数值的绝对值。返回最大和，无需返回操作序列。

  • n == matrix.length == matrix[i].length
  • 2 ≤ n ≤ 250
  • -10⁵ ≤ matrix[i][j] ≤ 10⁵

参数：matrix: integer[][]；返回：长整数。题意、示例及约束据本轮官方元数据转述。官方题目 ↗

官方示例 1

输入：matrix = [[1,-1],[-1,1]]
输出：4

先翻转第一行两格，再翻转第一列两格，四个元素都变成 1，和为 4。

官方示例 2

输入：matrix = [[1,2,3],[-1,-2,-3],[1,2,3]]
输出：16

翻转第二行最后两格，第二行变为 [-1,2,3]，总和为 16。

04 / 推导与参考代码

准备好后再展开：核心思路、证明与四语言实现。

核心洞察：连通路径与符号的奇偶性

记所有元素绝对值之和为 S、负数个数为 k、全局最小绝对值为 m。答案是 k 为偶数 ? S : S - 2m。若有零，m = 0，这条公式仍然成立。

每个元素的绝对值不变，因此 S 是总和的上界。没有零时，一次翻转同时改变两个符号，负数个数变化只能是 -2、0 或 2，所以其奇偶性不变。两个负数可以通过路径消去；若负数总数为奇数，最终至少留下一个负号，把它放在绝对值最小的格子上损失最小。

完整过程

  1. 初始化 sum = 0、minAbs = +∞、negativeCount = 0。
  2. 扫描每个数 x，累加 |x|，维护最小绝对值，并在 x < 0 时增加负数计数。
  3. 若计数为偶数返回绝对值总和；否则返回 sum - 2 × minAbs。

示例 2：S = 18、k = 3、m = 1，因此答案为 18 - 2 = 16。示例 [[-5,2],[3,4]] 中应让正数 2 承担负号：翻转第一行后成为 [[5,-2],[3,4]]，和为 10。最小绝对值必须在全矩阵中寻找。

正确性证明

  1. 路径引理。方阵按公共边连接后是连通图。任选两个不同格子，取一条简单路径，沿路径依次翻转每条边。内部格子被翻转两次，恢复原值；只有两个端点被翻转一次。因此即使两个负数不相邻，也能只改变这两个端点的符号。
  2. 偶数个负数。将负数两两配对，对每对执行路径操作，即可全部变为非负，得到上界 S，故最优。
  3. 奇数个负数且无零。奇偶性不变，至少一个数为负。总和等于 S 减去所有负数绝对值之和的两倍，故不超过 S - 2m。先成对消去负号，剩下的负号若不在最小绝对值格子上，用路径操作把它转移过去，即达到该上界。
  4. 存在零。成对处理负号后，若还剩一个负数，让它与零作为路径端点。负数变正，而零翻转后仍为零，可得到 S。此时 m = 0，公式也返回 S。注意：有零时，数值上统计的负数个数奇偶性可能改变。

边界与数值范围

  • 零不计为负数；多个零、全零都无需分支处理。
  • 全部为正时允许不执行任何操作；全部为负仍按数量奇偶处理。
  • 题目保证是方阵且 n ≥ 2，提交代码无需处理空矩阵或非方阵。
  • 绝对值总和最大为 250² × 100000 = 6250000000。Java 用 long，C++ 用 long long；JavaScript Number 可精确表示该范围内的整数，Python 整数自动扩展。

复杂度

扫描 n² 个元素，时间 O(n²)，仅使用三个统计量，额外空间 O(1)，不修改输入。页面为演示保存历史矩阵，其空间开销不属于提交算法。

替代方案

可以显式沿路径搬运负号并模拟操作，但只求最大和时没有必要。逐对寻找路径的朴素实现可能需要 O(n³) 次边操作，还要维护操作状态。枚举全部符号状态是指数级方案，只适合很小的矩阵用于独立对照，不适合 n = 250。排序绝对值也能找最小值，但会引入多余的存储和排序时间。

常见错误

  • 只减去 m：从 +m 变成 -m，实际损失为 2m。
  • 只在原来的负数中找最小绝对值，忽略负号可以转移到原来的正数上。
  • 认为只能消去直接相邻的负数，遗漏路径引理。
  • 宣称含零时负数个数的奇偶性也绝对不变；零正是可以消去最后一个负号的特殊端点。
  • 使用 32 位累加器，或让 JavaScript 的总和参与位运算而发生 32 位截断。

面试追问

  • 如果网格不连通呢？每个连通分量独立统计 S、k、m，再把各分量最优和相加。
  • 矩形矩阵是否成立？成立，关键条件是格子图连通，并不依赖边长相等。
  • 如果要求输出操作序列？选择生成树，从叶子向根处理负号；奇数且无零时把最小绝对值格子作为根，存在零时可把零作为根。需要额外记录操作与树结构。
  • 如果要求最少操作次数？本题公式只决定最大和，无法直接给出最短操作序列，需要额外优化路径与配对方式。

Java

class Solution {
    public long maxMatrixSum(int[][] matrix) {
        long sum = 0;
        int minAbs = Integer.MAX_VALUE;
        int negatives = 0;
        for (int[] row : matrix) {
            for (int x : row) {
                int value = Math.abs(x);
                sum += value;
                minAbs = Math.min(minAbs, value);
                if (x < 0) negatives++;
            }
        }
        return negatives % 2 == 0 ? sum : sum - 2L * minAbs;
    }
}

Python 3

from typing import List

class Solution:
    def maxMatrixSum(self, matrix: List[List[int]]) -> int:
        total = 0
        min_abs = abs(matrix[0][0])
        negatives = 0
        for row in matrix:
            for x in row:
                value = abs(x)
                total += value
                min_abs = min(min_abs, value)
                if x < 0:
                    negatives += 1
        return total if negatives % 2 == 0 else total - 2 * min_abs

#include <algorithm>
#include <climits>
#include <cstdlib>
#include <vector>
using namespace std;

class Solution {
public:
    long long maxMatrixSum(vector<vector<int>>& matrix) {
        long long sum = 0;
        int minAbs = INT_MAX, negatives = 0;
        for (const auto& row : matrix) {
            for (int x : row) {
                int value = abs(x);
                sum += value;
                minAbs = min(minAbs, value);
                if (x < 0) ++negatives;
            }
        }
        return negatives % 2 == 0 ? sum : sum - 2LL * minAbs;
    }
};
