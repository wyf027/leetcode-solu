Problem

题意与输入约束

函数签名：minElements(nums, limit, goal)，返回需要添加的最少元素数量。

给定整数数组 nums，以及整数 limit 和 goal。数组满足：任意元素 nums[i] 的绝对值都不超过 limit。

你可以向数组中添加整数，但新元素同样必须满足绝对值不超过 limit。请返回使数组全部元素之和恰好等于 goal 所需添加的最少元素个数。

示例 1

输入：nums = [1,-1,1], limit = 3, goal = -4
输出：2
解释：添加 -2 和 -3 后，
1 - 1 + 1 - 2 - 3 = -4。

示例 2

输入：nums = [1,-10,9,1], limit = 100, goal = 0
输出：1

约束

  • 1 <= nums.length <= 105
  • 1 <= limit <= 106
  • -limit <= nums[i] <= limit
  • -109 <= goal <= 109

参数

nums: integer[]

limit: integer

goal: integer

return: integer

Greedy proof

用最大贡献填平总和缺口

先把原数组压缩成一个总和，问题便只剩下：用最少的、绝对值不超过 limit 的整数凑出差值。

answer = ceil(|goal - sum(nums)| / limit)

核心洞察与完整过程

  1. 遍历 nums，得到当前总和 sum。
  2. 计算还需要补上的带符号差值 gap = goal - sum。
  3. 一个合法新元素对缺口绝对值的最大贡献是 limit。
  4. 因此把 |gap| 按每份最多 limit 切分，所需份数就是向上取整。

整数写法为 (|gap| + limit - 1) / limit。实际不必构造这些新增元素。

复杂度

时间：O(n)，只需累计一次数组。

空间：O(1)，不计输入。

边界

  • gap = 0 时答案为 0。
  • 目标可在当前和左侧或右侧，取绝对值统一处理。
  • 数组和可能超过 32 位范围；Java/C++ 应使用 64 位整数。

正确性证明

下界：设缺口绝对值为 D。每个新增元素绝对值至多为 limit，所以添加 k 个元素最多弥补 k × limit。若要覆盖 D，必有 k ≥ ceil(D / limit)。

可达：沿缺口方向，先添加若干个绝对值为 limit 的元素，最后添加一个绝对值不超过 limit 的余数（余数为 0 时省略）。恰好使用 ceil(D / limit) 个元素并补齐缺口。

构造达到下界，因此公式给出的数量最少。

替代方案与常见错误

  • 逐个模拟：反复用 limit 减缺口也能得到答案，但差值大时会退化，应直接除法计算。
  • 只看 goal：忘记先减去现有数组和，会把已经完成的贡献丢掉。
  • 使用 floor：有余数时还需要一个元素，必须向上取整。
  • 整型溢出：nums 的总和最高可到约 1011。
  • 误以为只能添加 ±limit：最后一个元素可以是范围内的任意整数。

四种语言完整代码

Java

class Solution {
    public int minElements(int[] nums, int limit, int goal) {
        long sum = 0L;
        for (int num : nums) {
            sum += num;
        }

        long gap = Math.abs((long) goal - sum);
        return (int) ((gap + limit - 1L) / limit);
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @param {number} limit
 * @param {number} goal
 * @return {number}
 */
var minElements = function(nums, limit, goal) {
    let sum = 0;
    for (const num of nums) {
        sum += num;
    }

    const gap = Math.abs(goal - sum);
    return Math.ceil(gap / limit);
};

C++

#include <cstdlib>
#include <numeric>
#include <vector>
using namespace std;

class Solution {
public:
    int minElements(vector<int>& nums, int limit, int goal) {
        long long sum = accumulate(nums.begin(), nums.end(), 0LL);
        long long gap = llabs((long long) goal - sum);
        return (int) ((gap + limit - 1) / limit);
    }
};

面试追问

为什么贪心使用最大绝对值一定最优？

因为优化目标只与元素个数有关，每个元素的最大有效贡献固定为 limit。尽量用满单个元素的容量才能达到理论下界，最后用一个余数精确收尾。

如果新增元素只能取 ±limit，会发生什么？

不再总是可达。差值必须是 limit 的整数倍；若可达，答案是 |gap| / limit，否则不存在解。

JavaScript 的 Number 是否安全？

本题数组和的数量级约为 10^11，远小于 Number 的最大安全整数约 9×10^15，因此在官方约束内可精确表示整数计算。
