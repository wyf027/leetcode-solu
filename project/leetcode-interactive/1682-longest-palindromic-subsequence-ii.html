Longest Palindromic Subsequence II

在普通回文子序列上再加两道闸门：长度必须为偶数，且除正中间那一对外，相邻字符不能相同。

Problem brief

先定义“好回文”

如果一个字符串同时满足下面四点，就称它为好回文子序列：

  • 它是原字符串 s 的子序列，允许删去字符但不能改变剩余字符的顺序；
  • 它正读与反读相同；
  • 长度为偶数；
  • 任意相邻字符不能相同，唯一例外是正中间的两个字符。

给定字符串 s，返回其中最长好回文子序列的长度。函数形式为 int longestPalindromeSubseq(string s)。

辨析：abba 合法；bcb 长度为奇数；bbbb 的非中央位置出现相同相邻字符，因此不合法。

Contract

约束与返回值

  • 1 <= s.length <= 250
  • s 仅含小写英文字母
  • 返回类型：integer
  • 官方参数：s: string

Complete editorial

题解：区间 × 外层字符

核心洞察

普通最长回文子序列只需区间 (i, j)；本题还要知道“新放入的一对是否会与既有外层相邻”。因此多记一维 prev，表示当前已构造回文最内侧、也就是下一对将紧邻的字符。

dfs(i, j, prev) = 区间 [i, j] 内、内邻字符不能为 prev 的最大长度

为什么天然是偶数？

每次只从区间两端加入一对相同字符，贡献恒为 2；当区间不足两个字符时贡献 0。所以所有可达答案都是偶数，正中间那一对相同字符正好由最后一次配对产生。

完整过程

1

定义边界

若 i >= j，区间里无法再拿出一对字符，返回 0。

2

尝试配对

当 s[i] == s[j] 且该字符不等于 prev，把它们放在当前回文的内侧，得到 2 + dfs(i + 1, j - 1, s[i])。

3

无法配对就丢一端

否则，最优子序列不可能同时使用这两个端点作为新的一对；分别跳过左端或右端，取 max(dfs(i + 1, j, prev), dfs(i, j - 1, prev))。

4

记忆化

i、j 各有 O(n) 种，prev 有 26 个字母加一个初始哨兵，共 27 种。缓存每个状态，避免指数级重复搜索。

正确性证明

归纳命题：dfs(i,j,prev) 等于区间 [i,j] 中、下一层相邻字符不得为 prev 的最长好回文长度。

基础情形：i >= j 时凑不出偶数长度的非空回文，返回 0 正确。

归纳步骤：若两端字符相同且不与 prev 冲突，把它们作为新的一对不会破坏回文、偶数长度或相邻约束，内部最优值由更短区间的归纳假设给出。否则这两个端点不能共同形成当前合法外对，任一可行最优解至少舍弃其中一端；两种子问题覆盖全部可能，取最大值即为最优。

因此从初始哨兵 26 调用 dfs(0,n-1,26) 得到全局答案。

复杂度与边界

  • 时间复杂度：O(26 · n²)，常写为 O(n²)。
  • 空间复杂度：O(27 · n²)，另有最多 O(n) 递归栈。
  • n = 1 时答案为 0。
  • 全为同一字符时最多只能取中央一对，答案为 2（若长度至少 2）。
  • 初始 prev 必须用字母表外的哨兵，否则会错误禁用一种外层字符。

import java.util.Arrays;

class Solution {
    private String s;
    private int[][][] memo;

    public int longestPalindromeSubseq(String s) {
        this.s = s;
        int n = s.length();
        memo = new int[n][n][27];
        for (int[][] plane : memo) {
            for (int[] row : plane) {
                Arrays.fill(row, -1);
            }
        }
        return dfs(0, n - 1, 26);
    }

    private int dfs(int i, int j, int prev) {
        if (i >= j) return 0;
        if (memo[i][j][prev] != -1) return memo[i][j][prev];

        int answer;
        int current = s.charAt(i) - 'a';
        if (s.charAt(i) == s.charAt(j) && current != prev) {
            answer = 2 + dfs(i + 1, j - 1, current);
        } else {
            answer = Math.max(
                dfs(i + 1, j, prev),
                dfs(i, j - 1, prev)
            );
        }
        return memo[i][j][prev] = answer;
    }
}

var longestPalindromeSubseq = function(s) {
    const n = s.length;
    const memo = Array.from({ length: n }, () =>
        Array.from({ length: n }, () => Array(27).fill(-1))
    );

    function dfs(i, j, prev) {
        if (i >= j) return 0;
        if (memo[i][j][prev] !== -1) return memo[i][j][prev];

        const current = s.charCodeAt(i) - 97;
        let answer;
        if (s[i] === s[j] && current !== prev) {
            answer = 2 + dfs(i + 1, j - 1, current);
        } else {
            answer = Math.max(
                dfs(i + 1, j, prev),
                dfs(i, j - 1, prev)
            );
        }
        memo[i][j][prev] = answer;
        return answer;
    }

    return dfs(0, n - 1, 26);
};
from functools import cache

class Solution:
    def longestPalindromeSubseq(self, s: str) -> int:
        @cache
        def dfs(i: int, j: int, prev: int) -> int:
            if i >= j:
                return 0

            current = ord(s[i]) - ord('a')
            if s[i] == s[j] and current != prev:
                return 2 + dfs(i + 1, j - 1, current)

            return max(
                dfs(i + 1, j, prev),
                dfs(i, j - 1, prev),
            )

        return dfs(0, len(s) - 1, 26)

class Solution {
private:
    int memo[251][251][27];
    string s;

    int dfs(int i, int j, int prev) {
        if (i >= j) return 0;
        int& answer = memo[i][j][prev];
        if (answer != -1) return answer;

        int current = s[i] - 'a';
        if (s[i] == s[j] && current != prev) {
            answer = 2 + dfs(i + 1, j - 1, current);
        } else {
            answer = max(
                dfs(i + 1, j, prev),
                dfs(i, j - 1, prev)
            );
        }
        return answer;
    }

public:
    int longestPalindromeSubseq(string s) {
        this->s = std::move(s);
        memset(memo, -1, sizeof(memo));
        return dfs(0, this->s.size() - 1, 26);
    }
};

替代方案

可按区间长度自底向上填三维 DP，避免递归栈；状态数量和渐进复杂度不变，但遍历顺序与初始化更繁琐。

面试追问

若字符集不止 26 个，可将 prev 做坐标压缩；若要恢复具体子序列，可在状态中记录选择并从根状态回溯。

常见错误

误做成普通 LPS；忘记偶数限制；只检查原串相邻字符；把 prev 理解成区间外原串字符；初始哨兵与合法字母冲突。
