Sort the Students by Their Kth Score

一张成绩单，一场指定考试。学生的最终位置应该如何变化？
先读题并尝试思考，再用下方演示观察每一步。

01 / Problem

题目说明

给定一个 m × n 的整数矩阵 score。每一行是一位学生，每一列是一场考试，score[i][j] 是学生 i 在考试 j 的得分。矩阵中的所有整数互不相同。

另给定整数 k，请按照第 k 列的得分从高到低调整学生顺序，返回调整后的矩阵。每位学生的所有成绩应保持对应关系。

所有下标从 0 开始：k = 2 指第 3 场考试。函数形式：sortTheStudents(score, k) → 二维整数数组。

约束

  • m == score.length
  • n == score[i].length
  • 1 ≤ m, n ≤ 250
  • 1 ≤ score[i][j] ≤ 10⁵
  • 整个矩阵中的整数互不相同。
  • 0 ≤ k < n
官方题目 ↗

官方示例

示例 1
score = [[10,6,9,1],[7,5,11,2],[4,8,3,15]]
k = 2

输出

[[7,5,11,2],[10,6,9,1],[4,8,3,15]]

考试 2 的分数依次为 9、11、3，故学生原下标的最终顺序是 1、0、2。

示例 2
score = [[3,4],[5,6]]
k = 0

输出

[[5,6],[3,4]]

考试 0 中，学生 1 的 5 分高于学生 0 的 3 分，因此学生 1 排在前面。

04 / Editorial

独立题解

准备好后再展开：包含思路、证明、四种语言代码与面试延伸。

核心洞察：比较一列，移动整行

每一行是一个不可拆散的学生记录。决定前后顺序的唯一信息是 score[i][k]。不需要计算总分，也不能在行内部排序。

这里用与交互演示完全一致的选择排序：在尚未确定位置的学生中找到第 k 列得分最高者，把整行放到当前最前的位置。它对应官方提示，且在最多 250 名学生时只需至多 31,125 次分数比较。日常提交也可直接使用库排序，见下方替代方案。

完整过程

  1. 从位置 i = 0 开始，先令最高分候选 best = i。
  2. 用 j 遍历 i + 1 到 m - 1。如果 score[j][k] > score[best][k]，更新 best = j。
  3. 扫描结束，交换 score[i] 和 score[best] 两个完整行记录。
  4. 位置 i 确定，继续处理位置 i + 1。最后一行自然归位。

示例 1：第 0 轮比较 9、11、3，选中原学生 1 并与首行交换；第 1 轮比较剩余的 9、3，不必换位；最终指定列为 11、9、3。

正确性证明

内层不变式：扫描到 j 后，best 指向区间 [i, j] 中第 k 列分数最大的一行。初始只有 i 成立；每次仅当新分数更高时更新 best，故仍成立。扫描结束时 best 是整个未处理后缀的最大值。

外层不变式：开始第 i 轮时，前 i 行已经是全体学生中第 k 列得分最高的 i 位，且按降序排列。初始前缀为空；将剩余最大者交换到 i 后，新前缀仍满足该性质，且原前缀不被改变。处理完前 m − 1 个位置，最后一行必然最小。只交换整行还保证学生成绩完整，因此返回矩阵满足要求。

边界与复杂度

  • m = 1：外层循环不执行，原矩阵直接返回。n = 1、k = 0 或 k = n − 1 都无需特殊分支。
  • 所有分数互不相同，因此不存在同分排名。已降序时仍会比较，交换可跳过。
  • 时间 O(m²)：比较 m(m − 1)/2 次，每次只读取一个指定列的整数。
  • 额外空间 O(1)：下面均原地交换行引用或行容器，不逐元素复制 n 个成绩。C++ 的按值返回可能产生 O(mn) 的返回矩阵副本；这属于返回结果存储/成本，计入时总时间为 O(m² + mn)、空间为 O(mn)。其余语言返回原矩阵对象。
  • 以下四份实现都会调整输入矩阵的行顺序；若需保留原始行顺序，先复制外层容器。

Java · 可提交

class Solution {
    public int[][] sortTheStudents(int[][] score, int k) {
        for (int i = 0; i < score.length - 1; i++) {
            int best = i;
            for (int j = i + 1; j < score.length; j++) {
                if (score[j][k] > score[best][k]) best = j;
            }
            if (best != i) {
                int[] row = score[i];
                score[i] = score[best];
                score[best] = row;
            }
        }
        return score;
    }
}

JavaScript · 可提交

/**
 * @param {number[][]} score
 * @param {number} k
 * @return {number[][]}
 */
var sortTheStudents = function(score, k) {
    for (let i = 0; i < score.length - 1; i++) {
        let best = i;
        for (let j = i + 1; j < score.length; j++) {
            if (score[j][k] > score[best][k]) best = j;
        }
        if (best !== i) {
            [score[i], score[best]] = [score[best], score[i]];
        }
    }
    return score;
};

Python 3 · 可提交

from typing import List

class Solution:
    def sortTheStudents(self, score: List[List[int]], k: int) -> List[List[int]]:
        for i in range(len(score) - 1):
            best = i
            for j in range(i + 1, len(score)):
                if score[j][k] > score[best][k]:
                    best = j
            if best != i:
                score[i], score[best] = score[best], score[i]
        return score

C++ · 可提交

#include <vector>
#include <utility>
using namespace std;

class Solution {
public:
    vector<vector<int>> sortTheStudents(vector<vector<int>>& score, int k) {
        int m = static_cast<int>(score.size());
        for (int i = 0; i < m - 1; ++i) {
            int best = i;
            for (int j = i + 1; j < m; ++j) {
                if (score[j][k] > score[best][k]) best = j;
            }
            if (best != i) swap(score[i], score[best]);
        }
        return score;
    }
};

替代方案：使用标准排序

直接按照每行的第 k 个数降序排列，通常只需 O(m log m) 次比较，代码更短。演示中的选择排序步骤不代表库函数内部实现。

// Java（需 import java.util.Arrays;）
Arrays.sort(score, (a, b) -> Integer.compare(b[k], a[k]));

// JavaScript
score.sort((a, b) => b[k] - a[k]);

# Python
score.sort(key=lambda row: row[k], reverse=True)

// C++（需 #include <algorithm>）
sort(score.begin(), score.end(), [k](const auto& a, const auto& b) {
    return a[k] > b[k];
});

库排序额外空间取决于语言：Java 对象数组排序和 Python 排序可能使用 O(m) 辅助空间，C++ std::sort 通常使用 O(log m) 栈空间；JavaScript 的排序时间与空间由引擎实现决定，不能从语言接口保证具体界限。只比较第 k 列即可，不必复制或比较整行。

常见错误

  • 把 k 当作从 1 开始：错误访问 k − 1 列。
  • 仅排序第 k 列或分别排序每行：破坏了学生与成绩的关联。
  • 方向写反：要求高分在前；C++ 比较器使用 >，不是 <。
  • JavaScript 比较器返回布尔值：应返回正、负或 0。
  • 每轮未重设 best = i：可能将已归位行重新纳入选择。
  • 说选择排序是 O(m log m)：它即使面对已排序输入仍做 O(m²) 次比较。

面试追问

  • 如果分数可以相同？本题无同分；若要求同分保留原顺序，应使用稳定排序或显式以原始下标为第二关键字。交换式选择排序一般不稳定。
  • 只要最高的 r 位学生？可以用大小为 r 的最小堆，O(m log r) 筛选，再用 O(r log r) 排序输出。
  • 学生数很大时？改用 O(m log m) 的比较排序；若需要多次按不同列查看，可排序行下标，保持原矩阵不动。
  • 如何不修改输入？Java / JavaScript / Python 复制外层行引用即可保持原行顺序；如果还会修改单元格，则需复制每行。C++ 可对下标排序，避免复制整个矩阵。
