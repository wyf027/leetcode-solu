题解 · 一张表，两个角色

核心洞察

一场比赛是有方向的二元组（主队，客队）。把 Teams 分别看成主队表与客队表，自连接得到所有配对，再去掉两侧名称相同的行即可。

可提交答案 · SQL

以官方元数据包含的 MySQL 语言为主。标准 CROSS JOIN 与不等比较同样适用于 PostgreSQL、SQL Server、Oracle 的本题查询。

SELECT h.team_name AS home_team,
       a.team_name AS away_team
FROM Teams AS h
CROSS JOIN Teams AS a
WHERE h.team_name <> a.team_name;

完整过程

  1. 为同一张 Teams 表指定别名 h 和 a，分别承担主队与客队角色；不创建物理副本。
  2. CROSS JOIN 在逻辑上枚举 n × n 个有序配对。
  3. 用名称不等条件排除 n 个自身配对，剩余 n(n−1) 场比赛。
  4. 选择并重命名两列，得到题目要求的输出结构，不必排序。

三队示例中，先考虑 Leetcode FC 的三个客队候选：自身配对排除，另两场保留；随后对 Ahly SC 和 Real Madrid 重复，共保留六场。数据库实际执行顺序由优化器决定，矩阵扫描仅是逻辑教学顺序。

正确性

  • 合法性：每个保留行的两队都来自输入，且名称不同，所以不会产生自我比赛。
  • 完整性：任取不同球队 x、y，笛卡尔积必含 (x,y) 和 (y,x)，两者都满足过滤条件。
  • 唯一性：球队名称唯一，因此每个有序配对只出现一次。三点共同保证结果恰好是全部所需比赛。

边界与复杂度

空表或一支球队输出零行；两支球队输出两行。不要限制主队名称小于客队名称，否则只剩一半比赛。球队名称比较遵循数据库的字符排序规则；参考代码使用语言本身的字符串相等语义，并假设输入符合唯一球队契约。

设 n 为球队数。逻辑枚举时间 O(n²)，输出行数为 n(n−1)，显式返回全部行本身需要二次规模。参考实现保存结果需要 O(n²) 空间，除结果外的循环辅助空间为 O(1)。SQL 的实际时间、工作内存、是否物化取决于执行计划，不能无条件宣称 SQL 只占 O(1) 内存。

替代方案

INNER JOIN Teams AS a ON h.team_name <> a.team_name 与这里的 CROSS JOIN 加 WHERE 表达相同关系。先取无序配对再 UNION ALL 交换主客队也可实现，但表达更长。DISTINCT、ORDER BY 和递归都不是本题必需操作。

常见错误

  • 只用 CROSS JOIN：包含自己对自己的比赛。
  • 使用 <：丢失主客场互换后的另一场。
  • 按球队聚合计数：返回数量，未返回比赛明细。
  • 不设置列别名：输出列名与要求不符。
  • 把未执行的演示当作数据库验证：演示只解释逻辑。

面试追问

  • 只问比赛总数？ 对球队计数后计算 n(n−1)，无需生成明细，注意整数乘法溢出。
  • 每两队只打一场？ 用稳定的唯一标识排序保留一个方向；若按名称比较，要明确排序规则。
  • 要安排轮次、日期或场地冲突？ 那是进一步的赛程调度问题，当前查询只返回对阵关系。
  • 名称允许重复或缺失？ 应先明确球队的非空唯一 ID，以 ID 区分身份，名称仅作为展示字段。

Java · 本地语义参考

以下四份代码是完整可独立使用的本地示例，不是本题官方可提交的四语言签名。输入为唯一且非空的球队名称序列，输出按 [home_team, away_team] 表示。

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class Main {
    public static List<List<String>> findAllMatches(List<String> teams) {
        List<List<String>> result = new ArrayList<>();
        for (String home : teams) {
            for (String away : teams) {
                if (!home.equals(away)) {
                    result.add(Arrays.asList(home, away));
                }
            }
        }
        return result;
    }

    public static void main(String[] args) {
        List<String> teams = Arrays.asList("Leetcode FC", "Ahly SC", "Real Madrid");
        System.out.println(findAllMatches(teams));
    }
}

function findAllMatches(teams) {
    const result = [];

        for (const away of teams) {
            if (home !== away) result.push([home, away]);
        }
    }
    return result;
}

#include <iostream>
#include <string>
#include <utility>
#include <vector>

std::vector<std::pair<std::string, std::string>>
findAllMatches(const std::vector<std::string>& teams) {
    std::vector<std::pair<std::string, std::string>> result;
    for (const auto& home : teams) {
        for (const auto& away : teams) {
            if (home != away) result.emplace_back(home, away);
        }
    }
    return result;
}

int main() {
    const std::vector<std::string> teams = {
        "Leetcode FC", "Ahly SC", "Real Madrid"
    };
    for (const auto& match : findAllMatches(teams)) {
        std::cout << match.first << " | " << match.second << '\n';
    }
    return 0;
}
