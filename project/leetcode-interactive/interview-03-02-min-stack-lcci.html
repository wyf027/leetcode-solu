Problem / 题意

普通栈，多一个常数时间的最低点

push · pop · top · getMin

设计 MinStack：除常规 push(x)、 pop() 与 top() 外，还要支持 getMin() 返回栈内最小元素。题目要求 push、pop 和最小值查询均为 O(1)。

官方示例 · 输入过程
minStack = new MinStack()
x = -2 → push(x)
x = 0 → push(x)
x = -3 → push(x)
getMin() → pop() → top() → getMin()

first getMin = -3
top = 0
second getMin = -2

核心洞察

每个节点记住自己的子栈最小值

主栈不只存 value，还存 currentMin：从栈底到当前节点的最小值。这样栈顶这条记录同时回答 top() 与 getMin()。

复杂度

四个操作全部 O(1)

每次 push 只比较一次并压入一个二元组；pop、top、getMin 都只访问栈顶。n 个元素占 O(n) 空间，每层多存一个整数。

完整过程

  1. 空栈 push(x) 时记录 (x, x)。
  2. 非空 push(x) 时记录 (x, min(x, 栈顶.currentMin))。
  3. pop() 删除完整二元组，旧深度的最小值自然恢复。
  4. top() 读 value；getMin() 读 currentMin。

边界

  • 重复最小值无需特殊分支，每层的 currentMin 都会保留。
  • 负数和 32 位极值只做比较，不做算术，不会溢出。
  • 题目示例只在非空栈上调用 pop、top、getMin。
  • 首次压栈不能读取不存在的旧最小值。

替代方案

双栈也能同步保存值与前缀最小值；稀疏最小栈更省常数，但相等最小值与同步弹出更容易写错。

面试追问

若只存一个全局 min，弹出最小值后怎么办？必须有历史，因此把历史绑定到节点最直观。

常见错误

push 之后才读取旧 min；只在更小时更新；pop 后扫描整个栈。这三种都会破坏正确性或 O(1) 要求。 

class MinStack {
    private final java.util.Deque<int[]> stack = new java.util.ArrayDeque<>();

    public MinStack() {}

    public void push(int x) {
        int currentMin = stack.isEmpty() ? x : Math.min(x, stack.peek()[1]);
        stack.push(new int[] {x, currentMin});
    }

    public void pop() {
        stack.pop();
    }

    public int top() {
        return stack.peek()[0];
    }

    public int getMin() {
        return stack.peek()[1];
    }
}
var MinStack = function () {
    this.stack = [];
};

MinStack.prototype.push = function (x) {
    const currentMin = this.stack.length
        ? Math.min(x, this.stack[this.stack.length - 1][1])
        : x;
    this.stack.push([x, currentMin]);
};

MinStack.prototype.pop = function () {
    this.stack.pop();
};

MinStack.prototype.top = function () {
    return this.stack[this.stack.length - 1][0];
};

MinStack.prototype.getMin = function () {
    return this.stack[this.stack.length - 1][1];

class MinStack:
    def __init__(self):
        self.stack = []

    def push(self, x: int) -> None:
        current_min = min(x, self.stack[-1][1]) if self.stack else x
        self.stack.append((x, current_min))

    def pop(self) -> None:
        self.stack.pop()

    def top(self) -> int:
        return self.stack[-1][0]

    def getMin(self) -> int:
        return self.stack[-1][1]
class MinStack {
private:
    std::vector<std::pair<int, int>> stack;

public:
    MinStack() = default;

    void push(int x) {
        int currentMin = stack.empty() ? x : std::min(x, stack.back().second);
        stack.push_back({x, currentMin});
    }

    void pop() {
        stack.pop_back();
    }

    int top() {
        return stack.back().first;
    }

    int getMin() {
        return stack.back().second;
    }
};
