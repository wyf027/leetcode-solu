花括号展开 II

1096 · Brace Expansion II

把表达式看成一台“集合计算器”：逗号执行并集，相邻表达式执行笛卡尔积后拼接。先亲手观察它怎样逐层归约，再决定是否打开完整题解。

题目

表达式由小写字母、花括号和逗号组成，并表示一个字符串集合。单个字母表示只含自身的集合；花括号内以逗号分隔的表达式表示集合并集；两个表达式直接相邻则表示从两边各取一个字符串并连接。嵌套规则相同。请返回表达式表示的所有不同字符串，并按字典序升序排列。

原子

R(x) = {x}

一个字母就是一个单元素集合。

并集 · 低优先级

R({a,b}) = R(a) ∪ R(b)

逗号分隔备选项，重复值只保留一次。

连接 · 高优先级

R(e₁e₂) = {a+b}

对两集合做笛卡尔积，并连接每一对字符串。

函数签名

braceExpansionII(expression: string) → list<string>

官方示例 1

输入：expression = "{a,b}{c,{d,e}}"
输出：["ac","ad","ae","bc","bd","be"]

官方示例 2

输入：expression = "{{a,z},a{b,c},{ab,z}}"
输出：["a","ab","ac","z"]
解释：最终结果中每个不同字符串只出现一次。

约束

  • 1 ≤ expression.length ≤ 60
  • expression[i] 是 {、}、, 或小写英文字母。
  • 输入保证是符合上述语法的有效表达式。

递归下降：让语法直接变成代码

核心洞察

在同一层中，逗号的优先级低于相邻连接。维护两个集合：sum 收集已经完成的并集分支，product 保存当前分支的连续连接结果。遇到逗号或本层结束时，再把 product 并入 sum。

完整过程

  1. 从当前位置解析一层，初始 sum = ∅、product = {""}。
  2. 字母形成单元素集合；遇到 { 时递归解析内部集合。
  3. 将当前原子集合与 product 做笛卡尔积连接。
  4. 遇到逗号，把当前乘积并入 sum，并将乘积重置为 {""}。
  5. 遇到右花括号或字符串结尾，合并最后一支并返回。
  6. 最外层结果排序后输出。

为什么正确

对解析层级与扫描到的原子数做归纳。基础情形中，字母返回其单元素集合。归纳步骤中，递归调用按假设正确得到花括号子表达式集合；连续原子通过笛卡尔积产生且仅产生所有连接组合，逗号则把互斥分支做集合并集。集合自动去重。于是每层恰好计算该层语法所表示的集合，最外层排序不改变集合内容，因此返回结果正确。

边界

  • 没有花括号、只有连续字母。
  • 深层嵌套与连续多个连接项。
  • 不同分支产生同一字符串，必须去重。
  • 花括号关闭前的最后一支没有逗号，也必须合并。

复杂度

设最终及中间产生的不同字符串总字符量为 S，集合运算约为 O(S)；最终有 K 个答案，排序额外为 O(K log K) 次字符串比较。空间为保存中间/最终集合的 O(S)，递归深度不超过表达式长度。

替代方案

可用两个栈完成迭代解析：一个栈存集合，一个栈存运算符，并为连接设置高于并集的优先级。也可反复找到最内层花括号再展开，但容易制造大量临时字符串，结构也不如递归下降清晰。

常见错误

  • 看到逗号就立刻返回，丢失同层后续分支。
  • 将并集与连接设成相同优先级。
  • 用列表而非集合，导致重复答案。
  • 漏掉空串单位元，第一次连接得到空集合。
  • 只在末尾排序，却没有先去重。

面试追问

  • 如果表达式长度更大，如何避免中间集合爆炸？可讨论惰性生成、Trie 与输出规模下界。
  • 如何改成支持转义字符或多字符原子？让词法分析与语法分析分层。
  • 能否迭代实现？可用运算符优先级栈模拟递归。

class Solution {
    private int i;

    public List<String> braceExpansionII(String expression) {
        i = 0;
        List<String> answer = new ArrayList<>(parse(expression));
        Collections.sort(answer);
        return answer;
    }

    private Set<String> parse(String s) {
        Set<String> sum = new HashSet<>();
        Set<String> product = new HashSet<>();
        product.add("");

        while (i < s.length() && s.charAt(i) != '}') {
            char ch = s.charAt(i);
            if (ch == ',') {
                sum.addAll(product);
                product = new HashSet<>();
                product.add("");
                i++;
                continue;
            }

            Set<String> atom;
            if (ch == '{') {
                i++;
                atom = parse(s);
                i++; // 跳过 }
            } else {
                atom = Set.of(String.valueOf(ch));
                i++;
            }
            product = multiply(product, atom);
        }
        sum.addAll(product);
        return sum;
    }

    private Set<String> multiply(Set<String> a, Set<String> b) {
        Set<String> result = new HashSet<>();
        for (String x : a)
            for (String y : b)
                result.add(x + y);
        return result;
    }
}

var braceExpansionII = function(expression) {
    let i = 0;

    const multiply = (a, b) => {
        const result = new Set();
        for (const x of a) for (const y of b) result.add(x + y);
        return result;
    };

    const parse = () => {
        const sum = new Set();
        let product = new Set([""]);

        while (i < expression.length && expression[i] !== "}") {
            if (expression[i] === ",") {
                for (const word of product) sum.add(word);
                product = new Set([""]);
                i++;
                continue;
            }

            let atom;
            if (expression[i] === "{") {
                i++;
                atom = parse();
                i++; // 跳过 }
            } else {
                atom = new Set([expression[i++]]);
            }
            product = multiply(product, atom);
        }
        for (const word of product) sum.add(word);
        return sum;
    };

    return [...parse()].sort();
};
from typing import List, Set

class Solution:
    def braceExpansionII(self, expression: str) -> List[str]:
        i = 0

        def multiply(a: Set[str], b: Set[str]) -> Set[str]:
            return {x + y for x in a for y in b}

        def parse() -> Set[str]:
            nonlocal i
            union, product = set(), {""}

            while i < len(expression) and expression[i] != "}":
                if expression[i] == ",":
                    union |= product
                    product = {""}
                    i += 1
                    continue

                if expression[i] == "{":
                    i += 1
                    atom = parse()
                    i += 1  # 跳过 }
                else:
                    atom = {expression[i]}
                    i += 1
                product = multiply(product, atom)

            return union | product

        return sorted(parse())
class Solution {
    int i = 0;

    set<string> multiply(const set<string>& a,
                         const set<string>& b) {
        set<string> result;
        for (const string& x : a)
            for (const string& y : b)
                result.insert(x + y);
        return result;
    }

    set<string> parse(const string& s) {
        set<string> sum, product{""};
        while (i < (int)s.size() && s[i] != '}') {
            if (s[i] == ',') {
                sum.insert(product.begin(), product.end());
                product = {""};
                ++i;
                continue;
            }

            set<string> atom;
            if (s[i] == '{') {
                ++i;
                atom = parse(s);
                ++i; // 跳过 }
            } else {
                atom = {string(1, s[i++])};
            }
            product = multiply(product, atom);
        }
        sum.insert(product.begin(), product.end());
        return sum;
    }

public:
    vector<string> braceExpansionII(string expression) {
        i = 0;
        set<string> result = parse(expression);
        return vector<string>(result.begin(), result.end());
    }
};
