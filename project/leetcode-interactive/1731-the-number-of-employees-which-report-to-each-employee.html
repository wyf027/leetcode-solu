下属员工数量

从一张自关联的员工表中，找出所有经理，统计直属员工人数与平均年龄，并按员工编号排序。

Problem brief

题目与数据契约

任务

给定 Employees(employee_id, name, reports_to, age)。若至少有一名员工的 reports_to 等于某员工的 employee_id，该员工就是经理。返回每位经理的编号、姓名、直属员工数，以及直属员工平均年龄四舍五入后的整数。

输出列必须为 employee_id、name、reports_count、average_age，并按 employee_id 升序排列。这里只统计直属关系，不递归统计更深层级。

约束：employee_id 是唯一值；reports_to 可为 NULL，表示不向任何人汇报；字段类型以右侧表结构为准。官方题面未给出额外的数值范围。

Solution

自连接，让同一张表扮演两种角色

核心洞察

把 Employees 使用两次：别名 m 表示候选经理，别名 e 表示直属员工。当 m.employee_id = e.reports_to 时，一条真实的直属汇报关系就被连接出来。

使用内连接会自然淘汰“无人向其汇报”的员工；随后按经理分组，对员工行计数并对员工年龄求平均值。

一句话查询骨架

经理 m JOIN 下属 e → GROUP BY 经理 → COUNT(e) + ROUND(AVG(age)) → SORT

平均年龄来自 e.age，不是经理自己的 m.age。

完整过程

1

建立直属关系

同表内连接，连接条件是经理编号等于员工的 reports_to。

2

按经理聚合

用经理的唯一编号和姓名分组，每组恰好包含其所有直属员工。

3

计算两个指标

COUNT(e.employee_id) 得人数；ROUND(AVG(e.age)) 得四舍五入平均年龄。

4

按编号排序

ORDER BY m.employee_id 满足结果顺序要求。

正确性说明

关系完备性：对任意直属员工 e，其 reports_to 指向经理 m 时，连接条件成立，因此该员工会且只会进入经理 m 的组。
经理筛选：内连接只保留至少匹配一名员工的 m，与题目对“经理”的定义完全一致。
聚合正确性：每组成员恰为该经理的全部直属员工，所以行数就是直属员工数，组内 e.age 的平均值就是所求平均年龄；ROUND 完成取整。

边界与复杂度

  • reports_to IS NULL 的员工不会作为下属匹配任何经理。
  • 没有下属的员工不出现在结果中。
  • 一个下属对应一位直属经理，不会跨组重复计数。
  • 平均值为非整数时由数据库 ROUND 四舍五入。

复杂度：以数据库执行计划为准。概念上，若连接键有索引，可近似看作扫描员工并分组，时间 O(n)，聚合空间 O(k)，其中 k 为经理数；最终排序另需 O(k log k)。无合适索引时连接代价可能更高。

官方可提交语言 · MySQL

MySQL 8+LeetCode 可提交
SELECT
    m.employee_id,
    m.name,
    COUNT(e.employee_id) AS reports_count,
    ROUND(AVG(e.age)) AS average_age
FROM Employees AS m
JOIN Employees AS e
    ON m.employee_id = e.reports_to
GROUP BY m.employee_id, m.name
ORDER BY m.employee_id;

Java本地语义参考
输入员工列表，返回按 employeeId 升序排列的汇总。
import java.util.*;

class SolutionReference {
    record Employee(int id, String name, Integer reportsTo, int age) {}
    record Summary(int employeeId, String name,
                   int reportsCount, int averageAge) {}

    static List<Summary> summarize(List<Employee> employees) {
        Map<Integer, Employee> byId = new HashMap<>();
        Map<Integer, List<Integer>> ages = new HashMap<>();
        for (Employee e : employees) byId.put(e.id(), e);

        for (Employee e : employees) {
            if (e.reportsTo() != null) {
                ages.computeIfAbsent(e.reportsTo(), k -> new ArrayList<>())
                    .add(e.age());
            }
        }

        List<Summary> result = new ArrayList<>();
        for (Map.Entry<Integer, List<Integer>> entry : ages.entrySet()) {
            Employee manager = byId.get(entry.getKey());
            if (manager == null) continue;
            List<Integer> values = entry.getValue();
            long sum = 0;
            for (int age : values) sum += age;
            int average = (int) Math.floor((double) sum / values.size() + 0.5);
            result.add(new Summary(manager.id(), manager.name(),
                                   values.size(), average));
        }
        result.sort(Comparator.comparingInt(Summary::employeeId));
        return result;
    }
}
JavaScript本地语义参考
对象字段：employee_id、name、reports_to、age。
function summarizeEmployees(employees) {
  const byId = new Map(
    employees.map((employee) => [employee.employee_id, employee])
  );
  const groups = new Map();

  for (const employee of employees) {
    if (employee.reports_to === null) continue;
    const ages = groups.get(employee.reports_to) ?? [];
    ages.push(employee.age);
    groups.set(employee.reports_to, ages);
  }

  return [...groups.entries()]
    .filter(([managerId]) => byId.has(managerId))
    .map(([managerId, ages]) => {
      const manager = byId.get(managerId);
      const sum = ages.reduce((total, age) => total + age, 0);
      return {
        employee_id: managerId,
        name: manager.name,
        reports_count: ages.length,
        average_age: Math.floor(sum / ages.length + 0.5)
      };
    })
    .sort((a, b) => a.employee_id - b.employee_id);
}
Python本地语义参考
纯 Python 列表版；官方另支持 Pandas 提交。
from collections import defaultdict
from math import floor
from typing import Any


def summarize_employees(
    employees: list[dict[str, Any]],
) -> list[dict[str, Any]]:
    by_id = {row["employee_id"]: row for row in employees}
    ages: dict[int, list[int]] = defaultdict(list)

    for employee in employees:
        manager_id = employee["reports_to"]
        if manager_id is not None:
            ages[manager_id].append(employee["age"])

    result = []
    for manager_id, report_ages in ages.items():
        manager = by_id.get(manager_id)
        if manager is None:
            continue
        average = floor(sum(report_ages) / len(report_ages) + 0.5)
        result.append({
            "employee_id": manager_id,
            "name": manager["name"],
            "reports_count": len(report_ages),
            "average_age": average,
        })

    return sorted(result, key=lambda row: row["employee_id"])
C++本地语义参考
使用 optional 表示可为空的 reports_to。
#include <algorithm>
#include <cmath>
#include <optional>
#include <string>
#include <unordered_map>
#include <vector>

struct Employee {
    int id;
    std::string name;
    std::optional<int> reportsTo;
    int age;
};

struct Summary {
    int employeeId;
    std::string name;
    int reportsCount;
    int averageAge;
};

std::vector<Summary> summarizeEmployees(
    const std::vector<Employee>& employees
) {
    std::unordered_map<int, const Employee*> byId;
    std::unordered_map<int, std::vector<int>> ages;
    for (const auto& employee : employees) byId[employee.id] = &employee;
    for (const auto& employee : employees) {
        if (employee.reportsTo) ages[*employee.reportsTo].push_back(employee.age);
    }

    std::vector<Summary> result;
    for (const auto& [managerId, values] : ages) {
        if (!byId.count(managerId)) continue;
        long long sum = 0;
        for (int age : values) sum += age;
        int average = static_cast<int>(std::floor(
            static_cast<double>(sum) / values.size() + 0.5
        ));
        result.push_back({managerId, byId[managerId]->name,
                          static_cast<int>(values.size()), average});
    }
    std::sort(result.begin(), result.end(),
              [](const Summary& a, const Summary& b) {
                  return a.employeeId < b.employeeId;
              });
    return result;
}

替代方案

相关子查询：可以为每位员工分别统计其下属，但表达更冗长，也可能重复扫描数据。

先聚合再连接：先按 reports_to 计算人数与平均年龄，再连接回 Employees 取经理姓名；逻辑同样正确，适合把“指标计算”和“维度补全”拆开。

窗口函数：能在明细行上附加分组指标，但还需去重，解决本题并不比 GROUP BY 简洁。

面试追问

  • 如果要统计所有层级的间接下属，如何用递归 CTE？
  • 如果一名员工能同时向多位经理汇报，表结构应如何规范化？
  • 数据量很大时，应给哪些列建立索引？
  • 不同数据库对 ROUND(38.5) 的规则是否一致？
  • 若经理记录缺失，但下属仍引用其编号，应该保留还是丢弃？

常见错误

  • 用 m.age 求平均，算成经理自己的年龄。
  • 使用左连接却没有过滤零下属员工，违反经理定义。
  • COUNT(*) 配合左连接时把空连接行也计为 1。
  • 递归计算所有下属，而题目只要求直属员工。
  • 遗漏 ROUND 或 ORDER BY employee_id。

索引思考

主键或唯一索引通常覆盖 employee_id。为 reports_to 建立索引可帮助数据库更快定位某位经理的直属员工。

不过索引是否生效、采用哈希连接还是其他策略，都应由真实数据规模与执行计划判断。
