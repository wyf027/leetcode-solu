递增顺序搜索树Increasing Order Search Tree

把二叉搜索树“梳”成一条只向右延伸的有序链。先观察结构如何变化，再决定是否打开完整题解。

题目

EASY

任务

给定二叉搜索树根节点 root，按中序顺序重新排列节点：原树最左侧节点成为新根；每个节点的左指针都为空，右指针指向序列中的下一个节点。

函数签名：increasingBST(root: TreeNode): TreeNode

约束

  • 节点数在 [1, 100] 内。
  • 0 <= Node.val <= 1000。
  • 输入是一棵二叉搜索树。

完整题解

中序遍历 + 尾指针

核心洞察

二叉搜索树的中序遍历结果天然递增。维护虚拟头节点 dummy 和链尾 tail；访问节点时令 node.left = null，再将 tail.right 指向它并推进链尾。

完整过程

  1. 创建虚拟头节点，令 tail = dummy。
  2. 对原树执行“左—根—右”的中序遍历。
  3. 访问节点时清空其左指针，并接到 tail.right。
  4. 更新 tail，遍历结束后返回 dummy.right。

复杂度

时间 O(n)；递归栈空间 O(h)，其中 h 是树高。除递归栈外只使用常数指针。

正确性说明

顺序：BST 的中序遍历按非递减次序访问节点，因此接入右链的值有序。

结构：每个被访问节点都执行 left = null；此前链尾的右指针只指向当前节点，所以最终只有一条向右链。

完整性：中序遍历恰好访问每个节点一次，故原树节点不丢失、不重复。由此返回的 dummy.right 满足全部要求。

边界

  • 单节点：清空左指针后直接返回该节点。
  • 完全左斜树：递归深度达到 n，输出反转为递增右链。
  • 完全右斜树：节点顺序不变，但仍会逐个规范左指针。

替代方案

可以先中序收集节点到数组，再二次连接，逻辑直观但需 O(n) 额外空间；也可用显式栈把递归改写为迭代。

四语言实现

均复用原节点
Java
class Solution {
    private TreeNode tail;

    public TreeNode increasingBST(TreeNode root) {
        TreeNode dummy = new TreeNode(0);
        tail = dummy;
        inorder(root);
        return dummy.right;
    }

    private void inorder(TreeNode node) {
        if (node == null) return;
        inorder(node.left);
        node.left = null;
        tail.right = node;
        tail = node;
        inorder(node.right);
    }
}

Python
class Solution:
    def increasingBST(
        self, root: Optional[TreeNode]
    ) -> Optional[TreeNode]:
        dummy = TreeNode(0)
        tail = dummy

        def inorder(node):
            nonlocal tail
            if node is None:
                return
            inorder(node.left)
            node.left = None
            tail.right = node
            tail = node
            inorder(node.right)

        inorder(root)
        return dummy.right
C++
class Solution {
    TreeNode* tail;

    void inorder(TreeNode* node) {
        if (node == nullptr) return;
        inorder(node->left);
        node->left = nullptr;
        tail->right = node;
        tail = node;
        inorder(node->right);
    }

public:
    TreeNode* increasingBST(TreeNode* root) {
        TreeNode dummy(0);
        tail = &dummy;
        inorder(root);
        return dummy.right;
    }
};

常见错误

  • 先改写 node.right，却没有保存原右子树，导致后续节点丢失。
  • 忘记清空 node.left，输出不再是纯右链。
  • 返回 dummy 而非 dummy.right。
  • 把遍历顺序写成先序，得到的链并非递增。
