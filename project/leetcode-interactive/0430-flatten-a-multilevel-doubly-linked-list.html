扁平化多级双向链表

Flatten a Multilevel Doubly Linked List

中等 深度优先搜索 链表 双向链表
每个节点有三条连接
prev←N→next
另有 child 指针，可以进入下一层链表。
Problem

题意与目标

官方元数据 · 非付费题

给定一个多级双向链表。每个节点除了 prev 和 next，还可能用 child 指向另一条同构的双向链表；子链表本身也可能继续拥有子链表。

请从第一层头节点 head 出发，把所有节点改造成一条单层双向链表。若节点 curr 有子链表，整条子链表应插在 curr 与原来的 curr.next 之间。

返回要求：返回扁平化后的原头节点；每个节点的 child 都必须为 null，同时 prev / next 要保持双向一致。
flatten(head: Node | null) → Node | null

结构规则

  1. 1节点值保持不变，复用原节点。
  2. 2子链表紧跟在父节点之后。
  3. 3子链表处理完，再回到父节点原后继。
  4. 4最终头节点的 prev 为 null。

Solution

迭代 DFS：用栈保存尚未回去的 next

核心洞察

目标次序等同于对多级结构做“节点 → child → 原 next”的先序遍历。栈是最直接的回程记录：弹出当前节点后，先压入原 next，再压入 child；由于后进先出，child 会优先被处理。

始终维护的关系

已弹出的节点已经连成正确前缀；prev 指向前缀尾；栈从顶到底保存后续应访问的节点。

完整过程

  1. 空链表直接返回 null；否则把 head 压栈，并令前缀尾 prev = null。
  2. 弹出 curr。若已有前缀尾，就设置 prev.next = curr 与 curr.prev = prev。
  3. 先压入 curr.next，再压入 curr.child，从而让 child 成为下一次弹出的节点。
  4. 清空 curr.child，再令 prev = curr。栈空时，所有节点恰好接入一次。
  5. 最后确保 head.prev = null，返回原头节点。

正确性：访问顺序

每次把原 next 先压栈、child 后压栈，所以若 child 存在，它必定在原 next 前被弹出；递归嵌套也遵守同一规则。因此访问次序正是题目要求的先序扁平次序。

正确性：双向连接

每个新弹出的节点都同时更新前一个节点的 next 和自身的 prev。归纳可知整个已生成前缀始终双向一致，最终覆盖全部节点。

正确性：child 清空

每个可达节点只弹出一次，并在弹出时无条件把 child 设为 null，所以结束后不存在残留 child 指针。

终止性

有限的每个节点至多因一条入边被压栈一次；每轮弹出一个节点，且不会创造新节点，因此栈最终为空，算法终止。

复杂度

时间 O(n)额外空间 O(d)，最坏 O(n)

n 是节点总数；d 可理解为遍历时同时挂起的层级回程数量，极端深链时达到 n。

边界情况

空链表

立即返回 null，不要访问 head 字段。

只有一个节点

节点保持不变，child 为空，prev 仍为空。

没有任何 child

结果顺序与原链表相同，但连接过程仍然有效。

连续深层 child

栈保存每层原 next；若没有原 next，则不会压入空值。

替代方案对比

方案机制优势代价 / 风险
迭代 DFS + 栈保存原 next，优先处理 child流程显式，不依赖语言递归上限需要额外栈
递归返回尾节点递归扁平 child，并把尾部接回 next贴合链表拼接语义深层嵌套可能栈溢出

class Solution {
    public Node flatten(Node head) {
        if (head == null) {
            return null;
        }

        java.util.Deque<Node> stack = new java.util.ArrayDeque<>();
        stack.push(head);
        Node prev = null;

        while (!stack.isEmpty()) {
            Node curr = stack.pop();

            if (prev != null) {
                prev.next = curr;
                curr.prev = prev;
            }

            if (curr.next != null) {
                stack.push(curr.next);
            }
            if (curr.child != null) {
                stack.push(curr.child);
                curr.child = null;
            }

            prev = curr;
        }

        head.prev = null;
        return head;
    }
}

class Solution {
public:
    Node* flatten(Node* head) {
        if (head == nullptr) {
            return nullptr;

        std::stack<Node*> pending;
        pending.push(head);
        Node* prev = nullptr;

        while (!pending.empty()) {
            Node* curr = pending.top();
            pending.pop();

            if (prev != nullptr) {
                prev->next = curr;
                curr->prev = prev;
            }

            if (curr->next != nullptr) {
                pending.push(curr->next);
            }
            if (curr->child != nullptr) {
                pending.push(curr->child);
                curr->child = nullptr;
            }

            prev = curr;
        }

        head->prev = nullptr;
        return head;
    }
};

常见错误

×

压栈顺序反了：先压 child 再压 next，会导致 next 先弹出，破坏题目要求的次序。

×

只更新 next：遗漏 curr.prev = prev 后，结果不是合法的双向链表。

×

忘记清空 child：虽然 next 次序看似正确，但仍不满足返回结构的完整要求。

×

先改写 curr.next 再保存：会丢失父层原后继，之后无法恢复。

面试追问

能否做到显式 O(1) 空间？

可以原地把 child 插入并寻找其尾节点，但朴素实现可能因重复扫描而退化到 O(n²)；需说明时间与空间取舍。

如何验证双向一致性？

从头沿 next 前进，逐节点检查 node.next.prev === node；再从尾沿 prev 反向检查值序列。

递归函数为何常返回尾节点？

父层需要知道扁平化 child 的末尾，才能 O(1) 地接回原 next；返回尾节点可避免再次线性寻找。

若结构可能有环怎么办？

原题默认合法无环；扩展场景需要用访问集合检测重复节点，否则 DFS 可能永不终止。
