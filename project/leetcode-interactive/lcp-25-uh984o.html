古董键盘

26 个按键各最多按 k 次。逐个加入按键时，选择它出现的次数，并用组合数决定插入已有字符串的位置。

状态

dp[key][length]

处理前 key 个按键，组成长度 length 的合法字符串数。新按键出现 take 次，插入位置数是 C(length, take)。

转移

dp[i][len] += dp[i-1][len-take] × C(len,take)

其中 0 ≤ take ≤ min(k, len)；答案为 dp[26][n]，所有计算取模 1e9+7。

为何需要组合数

同一种新字符的多个副本不可区分；先固定数量，再从最终长度中选择这些副本的位置，恰好避免重复计数。

复杂度

O(26 × n × k) 时间，O(26 × n) 空间

Java

class Solution {
 public int keyboard(int k, int n) {
  int mod=1_000_000_007; long[][] c=new long[n+1][n+1],dp=new long[27][n+1];
  for(int i=0;i<=n;i++){c[i][0]=c[i][i]=1;for(int j=1;j<i;j++)c[i][j]=(c[i-1][j-1]+c[i-1][j])%mod;}
  dp[0][0]=1;
  for(int i=1;i<=26;i++)for(int len=0;len<=n;len++)for(int take=0;take<=Math.min(k,len);take++)dp[i][len]=(dp[i][len]+dp[i-1][len-take]*c[len][take])%mod;
  return (int)dp[26][n];
 }
}

Python

class Solution:
 def keyboard(self, k, n):
  mod=10**9+7; c=[[0]*(n+1) for _ in range(n+1)]; dp=[[0]*(n+1) for _ in range(27)]
  for i in range(n+1):
   c[i][0]=c[i][i]=1
   for j in range(1,i): c[i][j]=(c[i-1][j-1]+c[i-1][j])%mod
  dp[0][0]=1
  for i in range(1,27):
   for length in range(n+1):
    for take in range(min(k,length)+1): dp[i][length]=(dp[i][length]+dp[i-1][length-take]*c[length][take])%mod
  return dp[26][n]
