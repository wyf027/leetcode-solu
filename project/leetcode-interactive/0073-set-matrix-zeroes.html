PROBLEM BRIEF

题意转述

给定一个 m × n 整数矩阵。只要某个位置原本为 0，它所在的整行与整列最终都必须变为 0；修改需要直接发生在原矩阵中。

官方样例 1

输入

matrix = [[1,1,1],[1,0,1],[1,1,1]]

输出

[[1,0,1],[0,0,0],[1,0,1]]

官方样例 2

输入

matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]

输出

[[0,0,0,0],[0,4,5,0],[0,3,1,0]]

约束：1 ≤ m,n ≤ 200；matrix[i][j] 位于 32 位有符号整数范围。输入没有字符串参数，因此无需空格可视化。

核心洞察

额外的行集合与列集合，本质上各需要 m、n 个布尔位。矩阵已有第一列与第一行，正好可以复用为这些标记；再用两个布尔量记住它们自身原来是否含零。

完整过程

  1. 先扫描首行、首列，保存它们原本是否需要置零。
  2. 扫描内部；遇到零就把对应行首与列首写成零。
  3. 依据首行首列的标记清理内部。
  4. 最后按两个布尔量处理首行和首列。

边界与正确性

  • 1 × 1、单行与单列仍适用。
  • 内部阶段必须从索引 1 开始，避免破坏控制总线。
  • 先写完所有标记，再置零；否则新零会被误当作原始零传播。
  • 负数和极值只参与“是否等于零”的判断。

复杂度

时间 O(mn)：常数次遍历矩阵。

额外空间 O(1)：仅两个布尔标记。

替代方案取舍

两个集合记录行列最易解释，空间 O(m+n)，适合先写出正确版本；复制矩阵需要 O(mn)。面试主线推荐首行首列标记法，因为满足进阶要求且代码仍然稳定。

常见错误

  • 扫描到零时立即清整行整列，造成级联污染。
  • 只用 matrix[0][0] 同时代表首行和首列，丢失一个状态。
  • 先处理首行首列，再用它们清内部，导致标记被提前覆盖。

class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        boolean firstRowZero = false, firstColZero = false;
        for (int j = 0; j < n; j++) if (matrix[0][j] == 0) firstRowZero = true;
        for (int i = 0; i < m; i++) if (matrix[i][0] == 0) firstColZero = true;
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;
            }
        }
        if (firstRowZero) for (int j = 0; j < n; j++) matrix[0][j] = 0;
        if (firstColZero) for (int i = 0; i < m; i++) matrix[i][0] = 0;
    }
}

    }
