2109. 向字符串添加空格

Adding Spaces to a String

空格加在哪里？先盯住原字符串的下标，想清楚“字符之前”意味着什么。

01 / 题目

官方题目 ↗

给定字符串 s 和整数数组 spaces。它们都使用从 0 开始的下标。对 spaces 中的每个位置，在 原字符串对应字符的前面添加一个空格，返回最终字符串。插入操作不会改变数组所指的原始位置。

例如 s = "EnjoyYourCoffee", spaces = [5,9]，在原下标 5 的 Y 和原下标 9 的 C 前加空格，得到 "Enjoy Your Coffee"。

官方示例 1

输入：s = "LeetcodeHelpsMeLearn"
      spaces = [8,13,15]
输出："Leetcode Helps Me Learn"

原下标 8、13、15 分别是 H、M、L。

官方示例 2

输入：s = "icodeinpython"
      spaces = [1,5,7,9]
输出："i code in py thon"

依次在 c、i、p、t 前加入空格。

官方示例 3

输入：s = "spacing"
      spaces = [0,1,2,3,4,5,6]
输出：" s p a c i n g"

首字符前也能加空格，结果包含开头空格。

约束与接口

  • 1 ≤ s.length ≤ 3 × 10⁵，s 仅包含大小写英文字母。
  • 1 ≤ spaces.length ≤ 3 × 10⁵。
  • 0 ≤ spaces[i] ≤ s.length − 1。
  • spaces 中的值严格递增，因此无重复且元素个数不超过 s.length。

函数：addSpaces(s: string, spaces: integer[]) → string

04 / 独立题解
准备好后再展开思路、证明与四语言实现。




核心洞察：读原串，写新串


spaces 已经严格递增。让 i 扫描原串，让 j 指向下一个需要加空格的原下标。每次处理 s[i]，先判断 i 是否等于 spaces[j]；相等则先写入空格并移动 j，然后无条件写入 s[i]。i 的含义始终是原串位置，因此不需要计算插入后的偏移。


完整过程
  1. 创建输出缓冲区，令 j = 0。
  2. 按 i = 0…n−1 顺序读取原串字符。
  3. 当 j < m 且 i = spaces[j]，追加一个空格并令 j++。
  4. 追加 s[i]。处理完所有原字符后，将缓冲区合并为字符串。


例如 s = "abc", spaces = [0,2]：i = 0 时先写空格再写 a，得到 " a"；i = 1 时只写 b，得到 " ab"；i = 2 时先写空格再写 c，得到 " ab c"。输出增加了长度，原串的 i 完全不受影响。


正确性证明 · 循环不变量


处理原下标 i 之前，输出恰好是原串前缀 s[0:i] 按要求加空格后的结果，j 恰好等于 spaces 中小于 i 的下标个数。


初始 i = 0 时，空前缀、空输出与 j = 0 满足不变量。因为 spaces 严格递增，未处理的最小插入位置是 spaces[j]。若它等于 i，算法只在 s[i] 前添加一次空格并移动 j；否则 i 不需要空格。随后写入 s[i]，原字符顺序保持不变，不变量扩展到 i + 1。循环终止时 i = n，所有合法插入下标均小于 n，因此所有字符与要求的空格都已正确写入。


边界与常见错误
  • spaces[0] 可以是 0：必须保留开头空格，不能使用 trim / strip。
  • spaces 的最后一个值可以是 n−1：空格位于末字符之前，不能加在末尾。
  • 连续下标表示在连续原字符之前分别加空格，不会产生连续两个空格。
  • j 到达 m 后仍要继续写原字符；读取 spaces[j] 前先检查边界。
  • 直接从左到右在原串插入却继续使用原下标，会发生位置偏移。
  • 循环中反复拼接不可变字符串，最坏会产生二次复制。使用缓冲区并一次合并。
  • 空串、空数组不属于本题输入范围；演示器拒绝这些输入。原串仅含英文字母，各语言字符索引语义一致。


复杂度
设 n = s.length，m = spaces.length。每个原字符与每个空格只追加一次，最终输出长度 n + m。时间 O(n + m)，因 m ≤ n 也可记为 O(n)。下列实现的缓冲区占用 O(n + m) 空间；两个指针本身只占 O(1)。不要把包含缓冲区的完整实现写成 O(1) 空间。


Java
class Solution {
    public String addSpaces(String s, int[] spaces) {
        StringBuilder out = new StringBuilder(s.length() + spaces.length);
        int j = 0;
        for (int i = 0; i < s.length(); i++) {
            if (j < spaces.length && i == spaces[j]) {
                out.append(' ');
                j++;
            }
            out.append(s.charAt(i));
        }
        return out.toString();
    }
}


JavaScript
/**
 * @param {string} s
 * @param {number[]} spaces

var addSpaces = function(s, spaces) {
    const out = [];
    let j = 0;
    for (let i = 0; i < s.length; i++) {
        if (j < spaces.length && i === spaces[j]) {
            out.push(' ');
            j++;
        }
        out.push(s[i]);
    }
    return out.join('');
};


Python 3
from typing import List

class Solution:
    def addSpaces(self, s: str, spaces: List[int]) -> str:
        out = []
        j = 0
        for i, ch in enumerate(s):
            if j < len(spaces) and i == spaces[j]:
                out.append(' ')
                j += 1
            out.append(ch)
        return ''.join(out)


C++
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string addSpaces(string s, vector<int>& spaces) {
        string out;
        out.reserve(s.size() + spaces.size());
        size_t j = 0;
        for (size_t i = 0; i < s.size(); ++i) {
            if (j < spaces.size() && i == static_cast<size_t>(spaces[j])) {
                out.push_back(' ');
                ++j;
            }
            out.push_back(s[i]);
        }
        return out;
    }
};


替代方案
  • 分段切片后以空格连接：按 spaces 切出各段，最后补上后缀，再 join。首位置是 0 时保留第一个空片段，自然得到开头空格。总复制量 O(n + m)。
  • 哈希集合：将位置放入集合，扫描时查询，期望 O(n + m) 时间，但多用了集合空间，且没有利用数组已经有序的条件。
  • 倒序原地插入：倒着插入可避免下标漂移，但普通连续容器每次仍可能搬移后缀，最坏 O(nm)。若有预先扩容的可写字符缓冲区，可从尾部双指针填充实现线性时间。


面试追问
  • 如果 spaces 无序？先排序，时间增加 O(m log m)；重复位置需要先明确是否插入多个空格。
  • 如何处理超长输入流？维护原字符计数与有序插入位置迭代器，直接流式写出，避免保留整份结果。
  • 如果允许末尾插空格？当前约束不允许 n；扩展规格后在字符循环结束时补处理该位置。
  • 能否低于线性时间？显式返回长度 n + m 的新字符串，光写结果就需要 Ω(n + m) 时间。
