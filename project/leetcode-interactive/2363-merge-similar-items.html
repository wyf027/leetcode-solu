合并相似的物品

Merge Similar Items

两份物品清单，同一种价值。把重量汇成一份有序的结果。

输入：两个二维整数数组输出：按价值升序的二维数组

先理解输入与目标，再展开底部题解。算法过程与代码默认收起。

01 / 题目要求

给定 items1 和 items2。每个元素为 [value, weight]，依次表示一件物品的价值和重量。同一个数组内不会出现重复价值，但两个数组之间可以出现相同价值。

返回 ret：每个出现过的价值只保留一行 [value, 总重量]，总重量包含两份清单中这个价值对应的所有重量；结果按 value 从小到大排列。

约束（官方元数据）

  • 1 ≤ items1.length, items2.length ≤ 1000。
  • 两个数组中的每个元素都恰好包含 2 个整数。
  • 1 ≤ value, weight ≤ 1000。
  • items1 内价值唯一；items2 内价值也唯一。

02 / 官方示例

示例 1 · 部分重合

输入：items1 = [[1,1],[4,5],[3,8]]
      items2 = [[3,1],[1,5]]
输出：[[1,6],[3,9],[4,5]]

价值 1 的重量为 1 + 5 = 6；价值 3 为 8 + 1 = 9；价值 4 仅出现一次，重量仍为 5。

示例 2 · 价值全部重合

输入：items1 = [[1,1],[3,2],[2,3]]
      items2 = [[2,1],[3,2],[1,3]]
输出：[[1,4],[2,4],[3,4]]

价值 1、2、3 的总重量分别为 1 + 3、3 + 1、2 + 2，均为 4。

示例 3 · 新价值加入

输入：items1 = [[1,3],[2,2]]
      items2 = [[7,1],[2,2],[1,4]]
输出：[[1,7],[2,4],[7,1]]

价值 1 的总重量为 7，价值 2 为 4，价值 7 为 1；结果按价值升序排列。

04 / 独立题解

准备好后，再打开思路、互动过程与四语言代码。

核心洞察：价值就是货架编号

价值范围只有 1～1000。准备长度为 1001 的数组 total，让 total[v] 记录价值 v 的总重量。两份清单都只做一次累加，最后从编号 1 扫到 1000，输出有货的货架。这既完成合并，也自然满足升序要求。

完整过程
  1. 建立 total[0…1000]，全部初始化为 0，编号 0 不使用。
  2. 遍历 items1 的每个 [v,w]，令 total[v] += w。
  3. 同样遍历 items2，累加到同一数组。
  4. 按 v = 1…1000 扫描；若 total[v] > 0，加入 [v,total[v]]。
  5. 返回结果，不改变原输入。


正确性证明
不变量：处理任意数量的物品后，total[v] 等于已处理物品中价值为 v 的重量之和。初始无物品，数组为 0，成立；处理 [v,w] 只将 w 加到对应位置，仍成立。遍历结束时，它就是两份清单中每种价值的总重量。
重量严格为正，所以 total[v] > 0 当且仅当 v 出现过。扫描每个 v 一次保证结果无遗漏、无重复；递增扫描保证输出按价值升序。因此结果满足全部要求。


边界与复杂度
无重合时每件物品保留；全重合时分别求和；输入无序不影响结果。价值 1000 必须可访问，所以数组长度为 1001。每种价值在每组至多一次，总重量至多 2000。
令 n、m 为输入长度，U = 1000，k 为不同价值数。时间 O(n + m + U)；辅助空间 O(U)，输出空间 O(k)。固定本题 U 时，辅助空间也可描述为常数。


替代方案
哈希表累加后排序键：平均时间 O(n + m + k log k)，辅助空间 O(k)，适合价值很大、很稀疏的情况。有序映射直接维护键序，每次更新 O(log k)。
若两份输入已经按价值排序，可用双指针归并，时间 O(n + m)、除输出外 O(1) 空间。本题没有保证输入有序，直接归并会出错；先排序则需额外排序时间。




常见错误
  • 按重量分组，或将两个 value 相加：分组依据是 value，相加的是 weight。
  • 使用赋值 total[v] = w，覆盖另一份清单已有的重量。
  • 只输出两份清单的交集，漏掉只在其中一份出现的价值。
  • 假设输入有序，或哈希表遍历顺序天然有序。
  • 使用长度 1000 的数组，或扫描到 v < 1000，漏掉价值上界。


面试追问
  • 价值达到 10⁹ 呢？ 换成哈希表累加，再对实际出现的键排序。
  • 一组里也允许价值重复呢？ 累加法仍正确，但最大总重量要按新的数量约束估算。
  • 重量允许 0 或负数呢？ 用独立的出现标记或映射保留已出现的价值，不能以总重量大于 0 判断是否出现。
  • 有很多份清单呢？ 依次入库即可，不变量不变；时间取决于物品总数与价值范围。

Java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> mergeSimilarItems(int[][] items1, int[][] items2) {
        int[] total = new int[1001];
        for (int[] item : items1) total[item[0]] += item[1];
        for (int[] item : items2) total[item[0]] += item[1];
        List<List<Integer>> result = new ArrayList<>();
        for (int v = 1; v <= 1000; v++) {
            if (total[v] > 0) result.add(Arrays.asList(v, total[v]));
        }
        return result;
    }
}

Python
from typing import List

class Solution:
    def mergeSimilarItems(self, items1: List[List[int]],
                          items2: List[List[int]]) -> List[List[int]]:
        total = [0] * 1001
        for v, w in items1:
            total[v] += w
        for v, w in items2:
            total[v] += w
        return [[v, total[v]] for v in range(1, 1001) if total[v] > 0]
