Problem

题目说明

函数：networkDelayTime(times, n, k)

有 n 个网络节点，编号为 1 到 n。数组 times 描述信号在有向边上的传递时间，其中 times[i] = [uᵢ, vᵢ, wᵢ] 表示信号从节点 uᵢ 传到节点 vᵢ 需要 wᵢ 个时间单位。

信号从节点 k 发出。请返回让所有节点都收到信号所需的最短时间；如果存在无法从 k 到达的节点，返回 -1。

先想一想：每个节点第一次“收到信号”的最早时刻由什么决定？全网完成传播的时刻又对应这些时刻中的哪个值？

示例 01

输入：
times = [[2,1,1],[2,3,1],[3,4,1]],
n = 4, k = 2
输出：2

示例 02

输入：
times = [[1,2,1]],
n = 2, k = 1
输出：1

示例 03

输入：
times = [[1,2,1]],
n = 2, k = 2
输出：-1

约束

  • 1 <= k <= n <= 100
  • 1 <= times.length <= 6000
  • times[i].length == 3
  • 1 <= uᵢ, vᵢ <= n
  • uᵢ != vᵢ
  • 0 <= wᵢ <= 100
  • 所有有向节点对 (uᵢ, vᵢ) 互不相同，不含重复边。

Solution

Dijkstra：按最早到达时间扩散

非负边权最短路
核心洞察：每个节点收到信号的最早时刻，就是从起点 k 到它的最短路径长度。当所有节点均可达时，最后收到信号的节点决定答案，因此返回全部最短距离中的最大值。

Process

完整过程

  1. 把 times 建成邻接表：每个源节点对应一组 (目标, 权重)。
  2. 将所有最短距离初始化为无穷大，仅令 dist[k] = 0。
  3. 用最小堆保存候选状态 (当前距离, 节点)，先压入 (0, k)。
  4. 每次弹出距离最小的候选。若它比数组中记录的距离更大，说明这是过期状态，直接跳过。
  5. 枚举该节点的出边。若经当前节点到邻居的距离更短，就更新距离并把新状态压入堆。
  6. 堆清空后检查全部节点：有无穷大则返回 -1，否则返回最大最短距离。

Why it works

正确性证明

  • 引理 1：弹出的最小有效距离可以被最终确认。假设最小堆弹出节点 u 的有效距离 d。若另有更短路径到达 u，这条路径上第一个尚未确认的节点之前必有一个已确认节点，它会把一个小于 d 的候选加入堆，与当前弹出项最小矛盾。非负边权保证路径继续延伸时距离不会变小。
  • 引理 2：松弛不会漏掉更短路径。每当某节点以最短距离被处理，算法都会枚举它的全部出边。任何从 k 出发的路径都由这些边依次组成，因此路径前缀被确认后，下一段对应的候选一定会被考虑。
  • 结论：dist[v] 是每个可达节点的最短到达时间。由引理 1，确认值不会再被改小；由引理 2，所有可能改善距离的路径都会被考虑。所以最终有限的 dist[v] 恰为最短路径长度。若有节点距离无限，则它不可达；否则最晚收到信号的时刻即 max(dist)。

Complexity

复杂度

设节点数为 V = n，边数为 E = times.length。

时间：O((V + E) log V)，常简写为 O(E log V)。

空间：O(V + E)，用于邻接表、距离数组和堆。

Edges

边界处理

  • n = 1 时起点就是唯一节点，答案为 0。
  • 存在不可达节点时返回 -1。
  • 边权可以为 0；Dijkstra 仍然成立，因为边权非负。
  • 有向边不可反向使用，邻接表只记录 u → v。
  • 堆内可能存在过期项，必须与当前 dist 比较并跳过。

Alternatives

替代方案

Bellman–Ford：实现直观、能处理负权边，时间 O(VE)；本题边权非负，效率不如 Dijkstra。

Floyd–Warshall：求所有点对最短路，时间 O(V³)、空间 O(V²)；本题只需要单源结果，计算过多。

朴素 Dijkstra：不用堆、每轮扫描节点，时间 O(V² + E)；当图很稠密或 V 很小时也可接受。

import java.util.*;

class Solution {
    public int networkDelayTime(int[][] times, int n, int k) {
        List<int[]>[] graph = new ArrayList[n + 1];
        for (int i = 1; i <= n; i++) {
            graph[i] = new ArrayList<>();
        }
        for (int[] edge : times) {
            graph[edge[0]].add(new int[]{edge[1], edge[2]});
        }

        int[] dist = new int[n + 1];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[k] = 0;

        PriorityQueue<int[]> heap =
            new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        heap.offer(new int[]{0, k});

        while (!heap.isEmpty()) {
            int[] current = heap.poll();
            int distance = current[0];
            int node = current[1];
            if (distance != dist[node]) {
                continue;
            }

            for (int[] edge : graph[node]) {
                int next = edge[0];
                int candidate = distance + edge[1];
                if (candidate < dist[next]) {
                    dist[next] = candidate;
                    heap.offer(new int[]{candidate, next});
                }
            }
        }

        int answer = 0;
        for (int node = 1; node <= n; node++) {
            if (dist[node] == Integer.MAX_VALUE) {
                return -1;
            }
            answer = Math.max(answer, dist[node]);
        }
        return answer;
    }
}
class MinHeap {
    constructor() {
        this.data = [];
    }

    push(item) {
        this.data.push(item);
        let index = this.data.length - 1;
        while (index > 0) {
            const parent = Math.floor((index - 1) / 2);
            if (this.data[parent][0] <= this.data[index][0]) break;
            [this.data[parent], this.data[index]] =
                [this.data[index], this.data[parent]];
            index = parent;
        }
    }

    pop() {
        if (this.data.length === 1) return this.data.pop();
        const result = this.data[0];
        this.data[0] = this.data.pop();
        let index = 0;

        while (true) {
            let smallest = index;
            const left = index * 2 + 1;
            const right = left + 1;
            if (left < this.data.length &&
                this.data[left][0] < this.data[smallest][0]) {
                smallest = left;
            }
            if (right < this.data.length &&
                this.data[right][0] < this.data[smallest][0]) {
                smallest = right;
            }
            if (smallest === index) break;
            [this.data[smallest], this.data[index]] =
                [this.data[index], this.data[smallest]];
            index = smallest;
        }
        return result;
    }

    get size() {
        return this.data.length;
    }
}

 * @param {number[][]} times

var networkDelayTime = function(times, n, k) {
    const graph = Array.from({ length: n + 1 }, () => []);
    for (const [from, to, weight] of times) {
        graph[from].push([to, weight]);
    }

    const dist = new Array(n + 1).fill(Infinity);
    dist[k] = 0;
    const heap = new MinHeap();
    heap.push([0, k]);

    while (heap.size > 0) {
        const [distance, node] = heap.pop();
        if (distance !== dist[node]) continue;

        for (const [next, weight] of graph[node]) {
            const candidate = distance + weight;
            if (candidate < dist[next]) {
                dist[next] = candidate;
                heap.push([candidate, next]);
            }
        }
    }

    let answer = 0;
    for (let node = 1; node <= n; node++) {
        if (dist[node] === Infinity) return -1;
        answer = Math.max(answer, dist[node]);
    }
    return answer;
};
from typing import List
import heapq


class Solution:
    def networkDelayTime(
        self, times: List[List[int]], n: int, k: int
    ) -> int:
        graph = [[] for _ in range(n + 1)]
        for source, target, weight in times:
            graph[source].append((target, weight))

        dist = [float("inf")] * (n + 1)
        dist[k] = 0
        heap = [(0, k)]

        while heap:
            distance, node = heapq.heappop(heap)
            if distance != dist[node]:
                continue

            for neighbor, weight in graph[node]:
                candidate = distance + weight
                if candidate < dist[neighbor]:
                    dist[neighbor] = candidate
                    heapq.heappush(heap, (candidate, neighbor))

        answer = max(dist[1:])
        return -1 if answer == float("inf") else answer

class Solution {
public:
    int networkDelayTime(vector<vector<int>>& times, int n, int k) {
        vector<vector<pair<int, int>>> graph(n + 1);
        for (const auto& edge : times) {
            graph[edge[0]].push_back({edge[1], edge[2]});
        }

        const int INF = 1'000'000'000;
        vector<int> dist(n + 1, INF);
        dist[k] = 0;

        using State = pair<int, int>; // {distance, node}
        priority_queue<State, vector<State>, greater<State>> heap;
        heap.push({0, k});

        while (!heap.empty()) {
            auto [distance, node] = heap.top();
            heap.pop();
            if (distance != dist[node]) {
                continue;
            }

            for (const auto& [neighbor, weight] : graph[node]) {
                int candidate = distance + weight;
                if (candidate < dist[neighbor]) {
                    dist[neighbor] = candidate;
                    heap.push({candidate, neighbor});
                }
            }
        }

        int answer = 0;
        for (int node = 1; node <= n; node++) {
            if (dist[node] == INF) {
                return -1;
            }
            answer = max(answer, dist[node]);
        }
        return answer;
    }
};

Interview follow-ups

面试追问与常见错误

为什么答案不是距离之和？

信号会沿多条路径同时传播，所有节点都收到的时刻取决于最晚的那个节点，因此是最短距离的最大值。

为什么不能用普通 BFS？

普通 BFS 只保证“边数最少”，而本题每条边耗时不同；必须比较累计权重。只有所有边权相同才可直接 BFS。

堆中的重复节点要删除吗？

不必主动删除。更新后压入新状态，弹出时用 distance != dist[node] 过滤过期项，代码更简洁。

如果允许负权边怎么办？

Dijkstra 的贪心确认不再成立，应改用 Bellman–Ford；若还可能有负环，则需要额外检测。

常见错误：把图当成无向图

[u,v,w] 只表示 u → v。误加反向边会把本来不可达的节点变成可达。

常见错误：只统计已弹出节点数

堆里有过期重复项。若用计数优化，应只在节点第一次以有效最短距离确认时计数。
