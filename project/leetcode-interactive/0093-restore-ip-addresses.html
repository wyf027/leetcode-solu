第 93 题完整题解

Core insight

只决定下一段在哪里结束

每层固定生成一个地址段，尝试长度 1、2、3。候选段合法才进入下一层；当正好得到四段且用完全部字符时收集答案。搜索深度恒为 4。

关键剪枝：剩余字符数必须落在“剩余段数”到“剩余段数 × 3”之间，否则当前分支不可能完成。

Complete process

完整过程

  1. 1. 用 index 记录尚未处理的起点，用列表保存已选地址段。
  2. 2. 先根据剩余字符数和剩余段数做上下界剪枝。
  3. 3. 从当前起点尝试 1–3 位；多位且首位为 0 时立即停止继续加长。
  4. 4. 数值超过 255 时停止加长；否则加入路径、递归、再撤销选择。
  5. 5. 四段与字符串同时结束时，用点号连接并记录。

Edges

边界条件

  • 长度小于 4 或大于 12：不可能组成合法地址，可直接返回空数组。
  • "0" 合法，"00"、"01" 不合法。
  • 255 合法，256 起越界。
  • 得到四段但仍有字符，或字符用尽但不足四段，都不能收集。
  • 结果顺序不限，但每个地址只能由原字符串连续切分得到。

Complexity

复杂度与替代方案

最多四层、每层最多三个选择，搜索节点上界为 O(3⁴)；IPv4 规格固定，因此可视为常数时间。递归路径最多四段，辅助空间 O(4)，不计输出。

替代方案是用三重循环枚举三个点的位置，代码没有递归，但边界判断分散。面试更推荐回溯：结构清晰、剪枝自然，也更容易推广到“固定段数的字符串切分”。

Interview follow-ups

面试追问

  • 为什么长度大于 12 能直接返回？四段各至多三位。
  • 为什么遇到前导零或大于 255 可以 break？继续扩展只会更长，仍然非法。
  • 如何避免频繁解析字符串？在扩展右端点时增量计算 value = value × 10 + digit。
  • 如何改为迭代？枚举三个切点，复用同一个段合法性函数。

Common mistakes

常见错误

  • 只判断数值小于等于 255，漏掉多位前导零。
  • 路径加入后忘记撤销，导致不同分支互相污染。
  • 只判断已有四段，没有同时判断是否用完字符串。
  • 剩余字符边界写错，误剪掉合法分支或搜索大量无效分支。
  • 在循环内每次都解析长子串，却没有在超过 255 后停止。

import java.util.ArrayList;
import java.util.List;

class Solution {
    private final List<String> answer = new ArrayList<>();

    public List<String> restoreIpAddresses(String s) {
        if (s.length() < 4 || s.length() > 12) {
            return answer;
        }
        backtrack(s, 0, new ArrayList<>());
        return answer;
    }

    private void backtrack(String s, int index, List<String> parts) {
        int remainingChars = s.length() - index;
        int remainingParts = 4 - parts.size();
        if (remainingChars < remainingParts || remainingChars > remainingParts * 3) {
            return;
        }
        if (parts.size() == 4) {
            answer.add(String.join(".", parts));
            return;
        }

        int value = 0;
        for (int end = index; end < Math.min(index + 3, s.length()); end++) {
            if (end > index && s.charAt(index) == '0') {
                break;
            }
            value = value * 10 + (s.charAt(end) - '0');
            if (value > 255) {
                break;
            }
            parts.add(s.substring(index, end + 1));
            backtrack(s, end + 1, parts);
            parts.remove(parts.size() - 1);
        }
    }
}

var restoreIpAddresses = function (s) {
    const answer = [];
    if (s.length < 4 || s.length > 12) return answer;

    const parts = [];
    const backtrack = (index) => {
        const remainingChars = s.length - index;
        const remainingParts = 4 - parts.length;
        if (
            remainingChars < remainingParts ||
            remainingChars > remainingParts * 3
        ) {
            return;
        }
        if (parts.length === 4) {
            answer.push(parts.join("."));
            return;
        }

        let value = 0;
        for (let end = index; end < Math.min(index + 3, s.length); end++) {
            if (end > index && s[index] === "0") break;
            value = value * 10 + Number(s[end]);
            if (value > 255) break;
            parts.push(s.slice(index, end + 1));
            backtrack(end + 1);
            parts.pop();
        }
    };

    backtrack(0);
    return answer;
};
from typing import List


class Solution:
    def restoreIpAddresses(self, s: str) -> List[str]:
        answer: List[str] = []
        if len(s) < 4 or len(s) > 12:
            return answer

        parts: List[str] = []

        def backtrack(index: int) -> None:
            remaining_chars = len(s) - index
            remaining_parts = 4 - len(parts)
            if not remaining_parts <= remaining_chars <= remaining_parts * 3:
                return
            if len(parts) == 4:
                answer.append(".".join(parts))
                return

            value = 0
            for end in range(index, min(index + 3, len(s))):
                if end > index and s[index] == "0":
                    break
                value = value * 10 + int(s[end])
                if value > 255:
                    break
                parts.append(s[index : end + 1])
                backtrack(end + 1)
                parts.pop()

        backtrack(0)
        return answer
class Solution {
public:
    vector<string> restoreIpAddresses(string s) {
        vector<string> answer;
        if (s.size() < 4 || s.size() > 12) {
            return answer;
        }
        vector<string> parts;
        backtrack(s, 0, parts, answer);
        return answer;
    }

private:
    void backtrack(const string& s, int index, vector<string>& parts,
                   vector<string>& answer) {
        int remainingChars = static_cast<int>(s.size()) - index;
        int remainingParts = 4 - static_cast<int>(parts.size());
        if (remainingChars < remainingParts || remainingChars > remainingParts * 3) {
            return;
        }
        if (parts.size() == 4) {
            string address;
            for (int i = 0; i < 4; i++) {
                if (i > 0) address += '.';
                address += parts[i];
            }
            answer.push_back(address);
            return;
        }

        int value = 0;
        for (int end = index; end < min(index + 3, static_cast<int>(s.size())); end++) {
            if (end > index && s[index] == '0') break;
            value = value * 10 + (s[end] - '0');
            if (value > 255) break;
            parts.push_back(s.substr(index, end - index + 1));
            backtrack(s, end + 1, parts, answer);
            parts.pop_back();
        }
    }
};
