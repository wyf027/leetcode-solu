删除字符串中的所有
相邻重复项

Remove All Adjacent Duplicates In String

栈字符串非付费题

题目

给定一个仅由小写英文字母组成的字符串 s。一次删除操作会选中两个相邻且相同的字母并将它们删除。

反复执行这样的操作，直到不存在可删除的相邻重复项，返回最终字符串。题目保证最终答案唯一。

函数签名

removeDuplicates(s: string): string

约束

  • 1 <= s.length <= 105
  • s 仅包含小写英文字母。

先想一想

一次消除可能让原本不相邻的字母靠在一起，并触发新的消除。

怎样保存“当前尚未消除的结果”，并只检查它的末尾？

O(n)

可以做到只扫描一次。具体方法留在页面底部的题解中。

题解：用栈保存未消除的前缀

核心洞察

扫描到新字符时，真正可能与它形成重复项的只有当前结果的最后一个字符。把当前结果当作栈：若栈顶等于新字符就弹出，否则把新字符压入。扫描结束后，栈中字符按原顺序组成答案。

完整过程

  1. 创建空栈。
  2. 从左到右遍历 s。
  3. 若栈非空且栈顶等于当前字符，弹出栈顶，表示这对相邻重复项被删除。
  4. 否则压入当前字符。
  5. 把栈连接成字符串并返回。

正确性

循环不变式：处理完前 i 个字符后，栈恰好等于该前缀完成所有相邻重复项删除后的结果。

初始时空前缀对应空栈，不变式成立。加入新字符时，前缀内部已无可消除项，因此唯一可能的新重复项位于栈顶与新字符之间；相同则弹出，不同则压入。两种操作都得到新前缀完全消除后的结果。不变式得以保持。遍历结束时，栈就是整个字符串的最终结果。

边界情况

  • 单字符：直接保留。
  • 没有相邻重复项：原样返回。
  • 连续偶数个相同字符：全部抵消。
  • 连续奇数个相同字符：留下一个。
  • 连锁消除：如 abba，删除 bb 后新的 aa 继续消除。

复杂度

每个字符至多入栈一次、出栈一次，时间复杂度为 O(n)；栈最多保存 n 个字符，空间复杂度为 O(n)。

替代方案

可以反复查找并删除相邻重复项，但字符串删除会搬移内容，最坏可能退化到 O(n²)。也可以用可变字符数组原地模拟栈，写指针就是栈顶位置，本质仍是同一策略。

面试追问

  • 若每次要删除连续 k 个相同字符，可在栈中保存“字符 + 连续计数”。
  • 若输入是字符流，可以逐字符处理；但在流结束前，栈内结果仍可能被后续字符抵消。
  • 答案为什么唯一？栈算法为每个前缀构造了确定的归约结果，不受删除顺序影响。

常见错误

  • 只做一轮相邻比较，遗漏删除后产生的新相邻项。
  • 比较当前字符与原字符串前一位，而不是与“当前结果”的末尾比较。
  • 频繁拼接不可变字符串，导致不必要的性能开销。
  • 弹栈后又把同一个当前字符压入，抵消操作应当直接结束本轮。

四种语言实现

class Solution {
    public String removeDuplicates(String s) {
        StringBuilder stack = new StringBuilder();
        for (char ch : s.toCharArray()) {
            int size = stack.length();
            if (size > 0 && stack.charAt(size - 1) == ch) {
                stack.deleteCharAt(size - 1);
            } else {
                stack.append(ch);
            }
        }
        return stack.toString();
    }
}

var removeDuplicates = function(s) {
    const stack = [];
    for (const ch of s) {
        if (stack.length > 0 && stack[stack.length - 1] === ch) {
            stack.pop();
        } else {
            stack.push(ch);
        }
    }
    return stack.join('');
};

public:

            if (!stack.empty() && stack.back() == ch) {
                stack.pop_back();
            } else {
                stack.push_back(ch);
