题目转述

交互接口隐藏了网格本身。坐标只是我们在探索过程中建立的内部地图，并不是输入参数。

任务

机器人位于一个未知二维网格的起点。可通行格之间可以上下左右移动，墙不可进入；网格中有且只有一个目标。你只能通过 GridMaster 询问某方向能否移动、实际移动，以及当前位置是否为目标。返回从起点到目标的最少移动次数；若不可达，返回 -1。

交互接口

boolean canMove(char direction) void move(char direction) boolean isTarget()

方向字符为 'U'、'D'、'L'、'R'。评测器持有隐藏网格；你的提交只实现 findShortestPath(GridMaster master)。

约束

  • 1 ≤ m, n ≤ 500
  • 概念网格单元为 -1 / 0 / 1 / 2：墙、空地、起点、目标。
  • 恰有一个起点和一个目标；起点不等于目标。
  • 只能调用交互接口感知和移动，不能直接读取网格。

关键困难

一次 DFS 可以发现目标，却不能保证第一次碰到目标时走的是最短路；一次 BFS 又无法直接扩展未知邻居，因为移动机器人会改变其真实位置。两种职责需要拆开。

示例 1相邻即到达
输入：grid = [[1,2],[-1,0]] 输出：1 说明：从起点向右一步到目标。
示例 2绕行两步
输入：grid = [[0,0,-1],[1,1,1],[2,0,0]] 输出：2 说明：目标距起点的最短路为两步。
示例 3目标不可达
输入：grid = [[-1,0],[0,2]] 输出：-1 说明：起点与目标之间没有可通行路径。

完整题解

把“控制真实机器人”和“计算抽象最短路”分成两个不会互相干扰的阶段。

核心洞察：DFS 负责把所有可达格映射到相对坐标，并通过反向移动保持真实位置一致；BFS 负责在静态地图上求最短路。

完整过程

  1. 规定起点坐标为 (0,0)，用集合记录可达坐标。
  2. DFS 枚举四个方向。若邻居未访问且 canMove 为真，就调用 move 前往邻居。
  3. 到达新格后记录坐标；若 isTarget() 为真，保存目标坐标。
  4. 递归结束时沿相反方向 move，让机器人退回父格。这是物理位置与递归状态一致的关键。
  5. 若探索后没找到目标，返回 -1；否则在可达坐标集合上从 (0,0) 做普通 BFS。
  6. BFS 第一次弹出目标坐标时，其层数就是最短移动次数。

为什么正确

引理 1 · 建图完整

DFS 对每个已发现格检查四个方向。所有能从起点到达的格，都可沿某条可行路径被逐步发现；访问集合只去重，不会漏掉可达格。每次递归后的反向移动保证下一次检查仍从正确父格开始。

引理 2 · BFS 最短

建图中的每条边代表一次合法移动，权重均为 1。BFS 按距离从小到大访问坐标，所以目标第一次出队时，没有更短的未处理路径。

结论

若目标可达，DFS 一定将它纳入地图，BFS 返回其最短距离；若目标不可达，DFS 不会发现它并返回 -1。因此算法总是返回正确答案。

复杂度与边界

设从起点可达的格子数为 V。DFS 和 BFS 都检查每格四个方向，时间复杂度为 O(V)；地图、访问集合、队列与递归栈共需 O(V) 空间。

  • 目标被墙完全隔开：探索结束后直接返回 -1。
  • 狭长通道：递归 DFS 可能很深，工程环境可改成显式栈；提交版本通常采用递归写法。
  • 必须先把坐标标为已访问，再递归，避免环路。
  • 目标坐标一旦找到仍可继续建完整可达图；这样逻辑最简单且边界稳定。

替代方案与追问

能否边探索边 BFS？ 直接做很麻烦：BFS 队列中的坐标与机器人的唯一真实位置不一致，要反复导航到不同前沿，容易引入额外路径规划。先建图再 BFS 更清晰。

能否 DFS 找到目标就返回深度？ 不能。DFS 首次抵达目标的路径不保证最短。

坐标数组为什么可开到约 1001×1001？ 单边最多跨越约 500 格，可将起点放在中间；哈希集合则无需预设偏移。

若边有权重呢？ 建图方式不变，第二阶段把 BFS 替换为 Dijkstra。

常见错误

回溯时忘记 move(反方向)用 DFS 深度冒充最短路坐标方向与反向表不一致目标不可达时仍启动 BFSBFS 入队后才去重导致重复把隐藏 grid 当成函数参数

class Solution {
    private final char[] dir = {'U', 'D', 'L', 'R'};
    private final char[] back = {'D', 'U', 'R', 'L'};
    private final int[][] delta = {{-1,0},{1,0},{0,-1},{0,1}};
    private final Set<String> open = new HashSet<>();
    private int[] target = null;

    public int findShortestPath(GridMaster master) {
        open.add(key(0, 0));
        explore(master, 0, 0);
        if (target == null) return -1;

        Queue<int[]> queue = new ArrayDeque<>();
        Set<String> seen = new HashSet<>();
        queue.offer(new int[]{0, 0, 0});
        seen.add(key(0, 0));

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            if (cur[0] == target[0] && cur[1] == target[1]) return cur[2];
            for (int[] d : delta) {
                int nx = cur[0] + d[0], ny = cur[1] + d[1];
                String k = key(nx, ny);
                if (open.contains(k) && seen.add(k)) {
                    queue.offer(new int[]{nx, ny, cur[2] + 1});
                }
            }
        }
        return -1;
    }

    private void explore(GridMaster master, int x, int y) {
        if (master.isTarget()) target = new int[]{x, y};
        for (int i = 0; i < 4; i++) {
            int nx = x + delta[i][0], ny = y + delta[i][1];
            String k = key(nx, ny);
            if (!open.contains(k) && master.canMove(dir[i])) {
                open.add(k);
                master.move(dir[i]);
                explore(master, nx, ny);
                master.move(back[i]);
            }
        }
    }

    private String key(int x, int y) { return x + "," + y; }
}
JAVASCRIPT
var findShortestPath = function(master) {
  const dirs = [['U', -1, 0, 'D'], ['D', 1, 0, 'U'],
                ['L', 0, -1, 'R'], ['R', 0, 1, 'L']];
  const key = (x, y) => `${x},${y}`;
  const open = new Set([key(0, 0)]);
  let target = null;

  function explore(x, y) {
    if (master.isTarget()) target = [x, y];
    for (const [move, dx, dy, back] of dirs) {
      const nx = x + dx, ny = y + dy, nextKey = key(nx, ny);
      if (!open.has(nextKey) && master.canMove(move)) {
        open.add(nextKey);
        master.move(move);
        explore(nx, ny);
        master.move(back);
      }
    }
  }

  explore(0, 0);
  if (target === null) return -1;

  const queue = [[0, 0, 0]];
  const seen = new Set([key(0, 0)]);
  for (let head = 0; head < queue.length; head++) {
    const [x, y, distance] = queue[head];
    if (x === target[0] && y === target[1]) return distance;
    for (const [, dx, dy] of dirs) {
      const nx = x + dx, ny = y + dy, nextKey = key(nx, ny);
      if (open.has(nextKey) && !seen.has(nextKey)) {
        seen.add(nextKey);
        queue.push([nx, ny, distance + 1]);
      }
    }
  }
  return -1;
};
PYTHON 3
from collections import deque

class Solution:
    def findShortestPath(self, master: 'GridMaster') -> int:
        directions = [
            ('U', -1, 0, 'D'), ('D', 1, 0, 'U'),
            ('L', 0, -1, 'R'), ('R', 0, 1, 'L')
        ]
        open_cells = {(0, 0)}
        target = None

        def explore(x: int, y: int) -> None:
            nonlocal target
            if master.isTarget():
                target = (x, y)

            for move, dx, dy, back in directions:
                neighbor = (x + dx, y + dy)
                if neighbor not in open_cells and master.canMove(move):
                    open_cells.add(neighbor)
                    master.move(move)
                    explore(*neighbor)
                    master.move(back)

        explore(0, 0)
        if target is None:
            return -1

        queue = deque([(0, 0, 0)])
        seen = {(0, 0)}
        while queue:
            x, y, distance = queue.popleft()
            if (x, y) == target:
                return distance
            for _, dx, dy, _ in directions:
                neighbor = (x + dx, y + dy)
                if neighbor in open_cells and neighbor not in seen:
                    seen.add(neighbor)
                    queue.append((neighbor[0], neighbor[1], distance + 1))
        return -1
C++
class Solution {
    vector<char> dir{'U', 'D', 'L', 'R'};
    vector<char> back{'D', 'U', 'R', 'L'};
    vector<pair<int,int>> delta{{-1,0},{1,0},{0,-1},{0,1}};
    set<pair<int,int>> open;
    pair<int,int> target;
    bool found = false;

    void explore(GridMaster &master, int x, int y) {
        if (master.isTarget()) {
            target = {x, y};
            found = true;
        }
        for (int i = 0; i < 4; ++i) {
            int nx = x + delta[i].first, ny = y + delta[i].second;
            if (!open.count({nx, ny}) && master.canMove(dir[i])) {
                open.insert({nx, ny});
                master.move(dir[i]);
                explore(master, nx, ny);
                master.move(back[i]);
            }
        }
    }

public:
    int findShortestPath(GridMaster &master) {
        open.insert({0, 0});
        explore(master, 0, 0);
        if (!found) return -1;

        queue<tuple<int,int,int>> q;
        set<pair<int,int>> seen{{0, 0}};
        q.push({0, 0, 0});
        while (!q.empty()) {
            auto [x, y, distance] = q.front();
            q.pop();
            if (make_pair(x, y) == target) return distance;
            for (auto [dx, dy] : delta) {
                pair<int,int> next{x + dx, y + dy};
                if (open.count(next) && !seen.count(next)) {
                    seen.insert(next);
                    q.push({next.first, next.second, distance + 1});
                }
            }
        }
        return -1;
    }
};
