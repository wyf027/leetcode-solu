周内每天的销售情况

把订单明细整理成一张“类别 × 星期”的周报：每个类别一行，Monday 到 Sunday 各占一列，即使某天没有销量也要明确显示为 0。

Sales by Day of the Week · 本页先呈现题目与实验台，题解默认收起。

01 / PROBLEM

题意

给定订单表 Orders 和商品表 Items。请统计每个商品类别在一周七天中分别被订购的总件数。

  • 结果必须包含 Items 中出现的每一个类别，包括完全没有订单的类别。
  • 输出列依次为 Category、Monday、…、Sunday。
  • 某类别在某天没有销量时输出 0。
  • 结果按 Category 升序排列。
提交形式：这是一道数据库题，官方评测入口要求编写查询，而不是实现普通函数。

约束与数据语义

  • Orders 的联合主键为 (order_id, item_id)。
  • Items.item_id 是主键，订单中的 item_id 用于关联商品。
  • order_date 表示下单日期，quantity 表示订购件数。
  • item_category 表示商品所属类别。
本轮官方付费元数据没有提供额外的数值范围；本页不虚构行数、日期或数量上下界。

05 / SOLUTION

题解

保全集合

从 Items 出发做左连接，保证没有订单的类别仍然存在。

条件聚合

对七个星期值分别判断，匹配时累加 quantity，否则累加 0。

透视成列

按类别分组后，七个条件和自然形成 Monday 到 Sunday 七列。

完整过程

  1. 以 Items 为保留侧，将每个商品与订单按 item_id 左连接。
  2. 使用 WEEKDAY(order_date) 将日期映射为 0（星期一）到 6（星期日）。
  3. 对每个星期使用一个 SUM(CASE WHEN ...) 条件和。
  4. 按 item_category 分组，再按类别升序输出。

边界

  • 类别完全没有订单：左连接产生空订单侧，七个 CASE 都贡献 0。
  • 同一类别同一天多笔订单：SUM 会全部累加。
  • 同一星期跨多个自然周：按星期编号归到同一列。
  • 多个商品属于同一类别：分组键是类别，不是商品。

官方提交语言 · MySQL

SELECT
    i.item_category AS Category,
    SUM(CASE WHEN WEEKDAY(o.order_date) = 0 THEN o.quantity ELSE 0 END) AS Monday,
    SUM(CASE WHEN WEEKDAY(o.order_date) = 1 THEN o.quantity ELSE 0 END) AS Tuesday,
    SUM(CASE WHEN WEEKDAY(o.order_date) = 2 THEN o.quantity ELSE 0 END) AS Wednesday,
    SUM(CASE WHEN WEEKDAY(o.order_date) = 3 THEN o.quantity ELSE 0 END) AS Thursday,
    SUM(CASE WHEN WEEKDAY(o.order_date) = 4 THEN o.quantity ELSE 0 END) AS Friday,
    SUM(CASE WHEN WEEKDAY(o.order_date) = 5 THEN o.quantity ELSE 0 END) AS Saturday,
    SUM(CASE WHEN WEEKDAY(o.order_date) = 6 THEN o.quantity ELSE 0 END) AS Sunday
FROM Items AS i
LEFT JOIN Orders AS o
    ON o.item_id = i.item_id
GROUP BY i.item_category
ORDER BY i.item_category;

正确性证明

1
类别不丢失。

左连接保留每一条商品记录。因此 Items 中每个类别至少有一条连接结果，即使订单侧全部为 NULL。

2
单个星期列正确。

固定一个类别 C 和星期 d。对应的 CASE 只在订单属于 C 且日期的 WEEKDAY 等于 d 时返回数量，其余连接行返回 0；SUM 因而恰好得到 C 在 d 的全部销量。

3
整张周报正确。

上述结论同时适用于七个星期列；GROUP BY 为每个类别生成唯一一行，ORDER BY 再给出要求的类别顺序，所以最终结果满足全部要求。

复杂度

设连接后的有效扫描规模为 N，类别数为 C。

  • 聚合扫描：期望 O(N)。
  • 按类别排序：O(C log C)。
  • 聚合状态空间：O(C)。

实际连接代价取决于数据库索引与执行计划。

替代方案

  • 用 DAYOFWEEK 也可实现，但其编号为 Sunday=1，需要格外注意映射。
  • 先在子查询中按类别和星期聚合，再用七次条件聚合透视；更便于复用，但本题略显冗长。
  • 动态 PIVOT 适合星期列不固定的报表；本题列固定，静态条件聚合更直接。

import java.time.DayOfWeek;
import java.time.LocalDate;
import java.util.*;

public class SalesByDay {
    record Order(int orderId, int customerId, LocalDate date,
                 String itemId, int quantity) {}
    record Item(String itemId, String name, String category) {}

    public static Map<String, int[]> report(
            List<Order> orders, List<Item> items) {
        Map<String, String> categoryByItem = new HashMap<>();
        Map<String, int[]> totals = new TreeMap<>();

        for (Item item : items) {
            categoryByItem.put(item.itemId(), item.category());
            totals.computeIfAbsent(item.category(), key -> new int[7]);
        }
        for (Order order : orders) {
            String category = categoryByItem.get(order.itemId());
            if (category == null) continue;
            DayOfWeek day = order.date().getDayOfWeek();
            totals.get(category)[day.getValue() - 1] += order.quantity();
        }
        return totals;
    }
}
function salesByDay(orders, items) {
  const categoryByItem = new Map();
  const totals = new Map();

  for (const item of items) {
    categoryByItem.set(String(item.item_id), item.item_category);
    if (!totals.has(item.item_category)) {
      totals.set(item.item_category, Array(7).fill(0));
    }
  }

  for (const order of orders) {
    const category = categoryByItem.get(String(order.item_id));
    if (!category) continue;
    const date = new Date(order.order_date + "T00:00:00Z");
    const mondayFirst = (date.getUTCDay() + 6) % 7;
    totals.get(category)[mondayFirst] += order.quantity;
  }

  return [...totals.entries()]
    .sort(([a], [b]) => a.localeCompare(b))
    .map(([Category, days]) => ({
      Category, Monday: days[0], Tuesday: days[1], Wednesday: days[2],
      Thursday: days[3], Friday: days[4], Saturday: days[5], Sunday: days[6]
    }));
}
from collections import defaultdict
from datetime import date

def sales_by_day(orders: list[dict], items: list[dict]) -> list[dict]:
    category_by_item = {}
    totals = defaultdict(lambda: [0] * 7)

    for item in items:
        item_id = str(item["item_id"])
        category = item["item_category"]
        category_by_item[item_id] = category
        totals[category]  # 保留零订单类别

    for order in orders:
        category = category_by_item.get(str(order["item_id"]))
        if category is None:
            continue
        day = date.fromisoformat(order["order_date"]).weekday()
        totals[category][day] += order["quantity"]

    names = ["Monday", "Tuesday", "Wednesday", "Thursday",
             "Friday", "Saturday", "Sunday"]
    return [
        {"Category": category, **dict(zip(names, totals[category]))}
        for category in sorted(totals)
    ]
#include <array>
#include <chrono>
#include <map>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Order { int orderId, customerId; string date, itemId; int quantity; };
struct Item { string itemId, name, category; };

map<string, array<int, 7>> salesByDay(
        const vector<Order>& orders, const vector<Item>& items) {
    unordered_map<string, string> categoryByItem;
    map<string, array<int, 7>> totals;
    for (const auto& item : items) {
        categoryByItem[item.itemId] = item.category;
        totals.try_emplace(item.category, array<int, 7>{});
    }
    for (const auto& order : orders) {
        auto found = categoryByItem.find(order.itemId);
        if (found == categoryByItem.end()) continue;
        int y, m, d;
        sscanf(order.date.c_str(), "%d-%d-%d", &y, &m, &d);
        chrono::year_month_day ymd{chrono::year{y}, chrono::month{unsigned(m)},
                                   chrono::day{unsigned(d)}};
        unsigned sundayFirst = chrono::weekday{chrono::sys_days{ymd}}.c_encoding();
        int mondayFirst = (sundayFirst + 6) % 7;
        totals[found->second][mondayFirst] += order.quantity;
    }
    return totals;
}

常见错误

  • 使用内连接，导致 T-Shirt 这类零订单类别消失。
  • 把 DAYOFWEEK 的 1 当作星期一；MySQL 中它表示星期日。
  • CASE 不写 ELSE 0，再错误处理 NULL。
  • 按商品而非类别分组，得到多行重复类别。
  • 只聚合已有星期，无法形成稳定的七列输出。
