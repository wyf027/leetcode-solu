Word Search II：在字符棋盘中找出字典的全部单词。每步只能上下左右移动，同一格在一条单词路径中不能重复使用。

前缀树共享搜索回溯恢复现场命中即去重

题意

一次 DFS 同时服务所有单词

给定 m × n 小写字母棋盘与互不重复的单词列表，返回棋盘中出现的所有单词。相邻只含水平/垂直方向，单词内同一个格不能复用。

输入：board = [["o","a","a","n"],["e","t","a","e"],["i","h","k","r"],["i","f","l","v"]]

words = ["oath","pea","eat","rain"]

输出：["eat", "oath"]

字符串使用成对直引号；空格若出现，写作可见符号 ␠。

核心洞察

不是逐词搜，而是沿前缀一起走

把 words 建成 Trie。DFS 走到一个格，只要当前前缀不在 Trie，就立刻剪枝；走到终止节点，就记录单词并清空该终止标记，避免重复答案。

为什么优于逐词 DFS？
有共同前缀的单词共享棋盘搜索路径，失败前缀不会继续扩展。

题解：Trie + 回溯

先插入全部单词。以每个格为 DFS 起点：若格子字符不在当前节点 children，立刻返回；标记访问、递归四邻格、最后恢复。若节点带 word，则加入结果并设为空以去重。

完整过程

  1. 每个 word 插入 Trie。
  2. 从每格启动并匹配根节点的 child。
  3. 用临时标记阻止同一路径复用格子。
  4. 发现 word 后收集、去重并回溯。

复杂度与边界

Trie 空间为所有单词总字符数。DFS 的最坏分支近似 O(mn·4^L)，但前缀剪枝显著减少实际搜索。注意 1×1、无匹配、公共前缀和单词嵌套。

替代方案取舍

逐个单词 DFS 代码短，但重复扫描共同前缀；Trie 是本题规模（最多 30,000 个词）下的面试推荐方案。

常见错误 / 追问

忘记回溯会污染下一条路径；只用 Set 去重却不清终止标记会重复工作。追问：如何再剪枝？可在 child 为空后从父节点删除它。
