找出 3 位偶数

Finding 3-Digit Even Numbers

三张数字卡片，能拼出多少个不同的三位偶数？先独立思考，再展开下方题解。

题目

给定整数数组 digits，每个元素都在 0 到 9 之间，数字可以重复。从中选择三个不同下标的元素，以任意顺序拼成整数。找出所有满足以下条件的结果：

  • 必须是三位数，百位不能为 0。
  • 必须是偶数。
  • 同一个数组元素只能使用一次；相同数字的可用次数取决于它在数组中出现的次数。

返回所有结果组成的数组，要求去重并按数值递增排序。

参数：digits: integer[]　返回：integer[]　函数：findEvenNumbers(digits)

约束

  • 3 <= digits.length <= 100
  • 0 <= digits[i] <= 9

官方示例

示例 1 · 包含零

输入：digits = [2,1,3,0]
输出：[102,120,130,132,210,230,302,310,312,320]

这些数恰好覆盖所有合法结果；前导零和奇数均不允许。

示例 2 · 重复数字

输入：digits = [2,2,8,8,2]
输出：[222,228,282,288,822,828,882]

2 最多使用三次，8 最多使用两次。例如 288 合法，888 不合法。

示例 3 · 无法构造

输入：digits = [3,7,5]
输出：[]

没有偶数数字可放在个位，因此答案为空。

核心洞察：检查数字是否够用

合法答案只能落在 100, 102, …, 998 这 450 个数中。与其排列输入下标，不如直接按递增顺序检查每个候选数。

用 count[d] 记录数字 d 的库存，再用 need[d] 记录候选数对 d 的需求。仅当所有数字都满足 need[d] <= count[d] 时收录候选。不同候选独立检查，库存不会被前一个答案消耗。

完整过程

  1. 扫描 digits，统计十种数字的出现次数。
  2. 从 100 到 998，每次增加 2，得到当前候选 x。
  3. 拆出百位 x / 100 的整数部分、十位 floor(x / 10) % 10 和个位 x % 10，累加进全新的 need 数组。
  4. 比较十种数字的需求与库存。任意一种不足就跳过，否则加入答案。
  5. 候选处理完毕后直接返回答案，不需要排序或集合去重。

例如 digits = [2,1,3,0]：100 需要两个 0，而库存只有一个，跳过；102 各需要一个 1、0、2，收录。随后检查 104，因没有 4 而跳过。

正确性说明

合法性：枚举的数都是没有前导零的三位偶数。如果每种数字的需求不超过库存，就能为每个数位选出不同的对应数组元素，所以收录的每个数都可构造。

完整性：任一合法答案都在 100～998 的偶数序列中，必然被枚举。因为它可由输入中的三个元素构造，各数字的需求必不超过库存，因此不会被漏掉。

唯一且有序：每个候选只访问一次，且访问顺序严格递增，因此答案天然不重复、递增排列。

循环不变式：处理当前候选前，答案恰好包含所有已访问候选中的合法值。一次库存判断恰当地收录或跳过当前值，从而保持该性质。

边界与复杂度

  • 全为奇数：没有候选能满足个位需求。
  • 全零：缺少非零百位，答案为空。
  • 重复数字：例如 222 必须有至少三个 2。
  • 零可用于十位和个位，不能用于百位。

设 n 为数组长度，R 为结果数。时间为 O(n + 450 × 10)，在本题固定范围下即 O(n)。辅助空间 O(10) = O(1)；返回数组为 O(R)，且 R ≤ 450。

替代方案

枚举三个下标：选择互不相同的 i、j、k，再判断百位、偶数条件，用集合去重并排序。时间 O(n³ + R log R)，空间 O(R)；输入重复多时有大量重复工作。

按数位构造：百位枚举 1～9，十位 0～9，个位 0、2、4、6、8，逐位扣减库存并恢复。候选也只有 450 个，但必须小心恢复计数。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] findEvenNumbers(int[] digits) {
        int[] count = new int[10];
        for (int d : digits) count[d]++;
        List<Integer> answer = new ArrayList<>();
        for (int x = 100; x < 1000; x += 2) {
            int[] need = new int[10];
            need[x / 100]++;
            need[x / 10 % 10]++;
            need[x % 10]++;
            boolean ok = true;
            for (int d = 0; d < 10; d++) {
                if (need[d] > count[d]) {
                    ok = false;
                    break;
                }
            }
            if (ok) answer.add(x);
        }
        int[] result = new int[answer.size()];
        for (int i = 0; i < result.length; i++) {
            result[i] = answer.get(i);
        }
        return result;
    }
}

JavaScript

/**
 * @param {number[]} digits
 * @return {number[]}
 */
var findEvenNumbers = function(digits) {
    const count = Array(10).fill(0);
    for (const d of digits) count[d]++;
    const answer = [];
    for (let x = 100; x < 1000; x += 2) {
        const need = Array(10).fill(0);
        need[Math.floor(x / 100)]++;
        need[Math.floor(x / 10) % 10]++;
        need[x % 10]++;
        if (need.every((amount, d) => amount <= count[d])) {
            answer.push(x);
        }
    }
    return answer;
};

Python

from typing import List

class Solution:
    def findEvenNumbers(self, digits: List[int]) -> List[int]:
        count = [0] * 10
        for d in digits:
            count[d] += 1
        answer = []
        for x in range(100, 1000, 2):
            need = [0] * 10
            need[x // 100] += 1
            need[x // 10 % 10] += 1
            need[x % 10] += 1
            if all(need[d] <= count[d] for d in range(10)):
                answer.append(x)
        return answer

            ++need[x / 100];
            ++need[x / 10 % 10];
            ++need[x % 10];

                if (need[d] > count[d]) {
                    ok = false;
                    break;
                }

        }
        return answer;
    }
};

常见错误

  • 只判断数字“是否存在”：两个 2 无法构造 222，必须统计数量。
  • 每个候选沿用上一次 need：需求计数必须重新清零。
  • 收录一个答案就永久扣除库存：各答案是独立的构造方案。
  • 通过字符串允许“012”：它不是三位整数。
  • 按下标构造后忘记去重，或 JavaScript 使用默认字符串排序：应使用集合及 sort((a,b) => a-b)。本方案不需要这两步。

面试追问

为什么不排序输入？只关心每个数字的数量，原有顺序不影响构造；计数即可。

扩大到 k 位数怎么办？候选空间随 k 指数增长，不能继续把它视为常数。可以按位回溯，利用剩余库存和首尾约束提前剪枝；若只求数量，可考虑以剩余计数为状态的记忆化搜索。

如何减少重复数字引起的工作？按数值候选枚举或按数字频次构造，避免遍历不同下标但数值相同的排列。
