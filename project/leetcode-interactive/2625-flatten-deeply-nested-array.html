嵌套数组

给定多维数组与最大展开深度，返回按深度规则扁平化后的数组。先读题并操作“深度闸门”，题解不会在首屏提前出现。

Problem

题意

多维数组中的每一项可以是整数，也可以是另一个多维数组。不要使用 JavaScript 内置的 Array.flat。

任务

实现 flat(arr, n)：只展开当前深度严格小于 n 的子数组。最外层数组中各元素的深度视为 0；达到深度上限的子数组作为一个整体保留。

参数与返回值

arr
由整数或嵌套数组组成的多维数组。
n
允许展开的深度，取值为 0…1000。
return
按深度规则得到的新数组。

Core Insight

核心洞察：把递归调用栈显式化

用一个后进先出的栈保存“值 + 当前深度”。弹出整数时直接加入结果；弹出数组且深度小于 n 时，把它的子项按逆序压栈；否则把整个数组原样加入结果。逆序压栈保证最终处理顺序仍是从左到右。

完整过程

  1. 将 arr 的顶层元素逆序压栈，并标记深度为 0。
  2. 弹出栈顶；如果是整数，就追加到结果数组。
  3. 如果是数组且 depth < n，将其子项逆序压栈，深度加 1。
  4. 如果是数组且已达到深度上限，就把该数组整体追加到结果。
  5. 栈为空时返回结果。

正确性证明

  1. 顺序不变：每个被展开数组的子项逆序入栈、正序出栈，因此相对顺序与原数组一致。
  2. 深度规则正确：仅当当前项是数组且 depth < n 时展开；否则整体保留，恰好符合题意。
  3. 无遗漏无重复：每个可达项只会被压栈并弹出一次；弹出后要么进入结果，要么由其全部子项替代。
  4. 终止：输入节点有限，每次循环都会弹出一个节点，且只会加入其尚未处理的有限子项，所以最终栈为空。

复杂度

时间：O(V)，V 为实际访问的整数与数组节点数，最坏访问全部节点。

额外空间：O(V)，包括显式栈与返回结果；不计结果时栈最坏为 O(V)。

边界情况

  • n = 0：所有子数组原样保留。
  • 空数组：返回空数组。
  • 只有整数：结果与输入元素一致。
  • 深度大于实际最大深度：完全扁平化。

替代方案

递归 DFS 更直观，但嵌套深度达到 1000 时可能触及部分运行时的调用栈限制。队列也能遍历，却不如栈自然地维持原始顺序。题目明确禁止直接调用 Array.flat。

JavaScript

官方签名
/**
 * @param {Array} arr
 * @param {number} n
 * @return {Array}
 */
var flat = function (arr, n) {
  const stack = [];
  const result = [];

  for (let i = arr.length - 1; i >= 0; i--) {
    stack.push([arr[i], 0]);
  }

  while (stack.length) {
    const [value, depth] = stack.pop();

    if (Array.isArray(value) && depth < n) {
      for (let i = value.length - 1; i >= 0; i--) {
        stack.push([value[i], depth + 1]);
      }
    } else {
      result.push(value);
    }
  }

  return result;
};

Java

本地语义参考
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    private record Item(Object value, int depth) {}

    public List<Object> flat(List<?> arr, int n) {
        Deque<Item> stack = new ArrayDeque<>();
        List<Object> result = new ArrayList<>();

        for (int i = arr.size() - 1; i >= 0; i--) {
            stack.push(new Item(arr.get(i), 0));
        }

        while (!stack.isEmpty()) {
            Item item = stack.pop();
            if (item.value() instanceof List<?> list && item.depth() < n) {
                for (int i = list.size() - 1; i >= 0; i--) {
                    stack.push(new Item(list.get(i), item.depth() + 1));
                }
            } else {
                result.add(item.value());
            }
        }

        return result;
    }
}

Python

本地语义参考
class Solution:
    def flat(self, arr: list, n: int) -> list:
        stack = [(value, 0) for value in reversed(arr)]
        result = []

        while stack:
            value, depth = stack.pop()
            if isinstance(value, list) and depth < n:
                stack.extend((child, depth + 1) for child in reversed(value))
            else:
                result.append(value)

        return result

C++

本地语义参考
#include <utility>
#include <variant>
#include <vector>

struct Node {
    std::variant<int, std::vector<Node>> value;
};

class Solution {
public:
    std::vector<Node> flat(const std::vector<Node>& arr, int n) {
        std::vector<std::pair<Node, int>> stack;
        std::vector<Node> result;

        for (auto it = arr.rbegin(); it != arr.rend(); ++it) {
            stack.push_back({*it, 0});
        }

        while (!stack.empty()) {
            auto [node, depth] = std::move(stack.back());
            stack.pop_back();

            if (auto children = std::get_if<std::vector<Node>>(&node.value);
                children && depth < n) {
                for (auto it = children->rbegin(); it != children->rend(); ++it) {
                    stack.push_back({*it, depth + 1});
                }
            } else {
                result.push_back(std::move(node));
            }
        }

        return result;
    }
};

常见错误

  • 把条件写成 depth <= n，多展开一层。
  • 子项正序入栈，导致输出顺序被反转。
  • 遇到深度上限时丢弃数组外壳，而不是整体保留。
  • 直接使用 Array.flat，违反题目要求。
  • 把最外层元素错误地从深度 1 开始计数。

面试追问

为什么选择显式栈而不是递归？

显式栈不依赖语言调用栈，能更稳妥地处理最大深度 1000 的输入。

怎样做到惰性输出？

把“追加到结果”改成生成器的 yield；栈与深度判断保持不变，可逐项消费。

如何完整保留输入对象而不修改它？

该实现只读取数组并创建新结果；未展开的子数组按引用保留。若要求深拷贝，需要另行明确复制语义。
