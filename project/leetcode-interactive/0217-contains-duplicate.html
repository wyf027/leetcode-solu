LeetCode 217 · Easy · Hash

Contains Duplicate

从左到右扫描数组：每个数先查询“是否已经见过”，没见过就放入集合；一旦命中已有键，立刻确认存在重复，不必继续扫描。

⌁ 哈希集合 · 首次重复即停止

题意

给定整数数组 nums。任意值至少出现两次，返回 true；若所有元素互不相同，返回 false。

官方样例 1nums = [1, 2, 3, 1]

值 1 出现在索引 0 与 3。期望：true。

官方样例 2nums = [1, 2, 3, 4]

所有元素不同。期望：false。

官方样例 3nums = [1, 1, 1, 3, 3, 4, 3, 2, 4, 2]

期望：true。

约束：1 ≤ nums.length ≤ 10⁵，−10⁹ ≤ nums[i] ≤ 10⁹。

首见集合探测器

准备扫描 [1, 2, 3, 1]。

测试与验证

数组的输入以完整参数名、等号和值呈现；空格若有会显示成 ␠，本题样例数组不依赖空格。

页面验证

Prettier、HTML Validate、内联 JavaScript 语法：通过。真实 Chrome 的交互、键盘、390px、控制台与溢出由主流程复核。

算法对拍

50,000 组随机数组：哈希集合扫描与独立排序相邻比较结果一致；四种语言代码均为提交接口形式。

题解默认折叠。

题解：用集合记录已见元素

核心洞察

集合的查找与插入平均都是 O(1)。在处理每个数之前调用“add”：若返回 false，说明这个值已经在集合中，立即返回 true；扫完仍未命中则 false。

完整过程

  1. 创建空集合 seen。
  2. 逐个读取 nums[i]。
  3. 若已经在 seen，返回 true。
  4. 否则加入 seen；循环结束返回 false。

边界

单元素一定为 false；负数和很大整数也只是键；重复在开头时会快速退出，重复在末尾仍只扫描一次。

复杂度与替代方案

平均时间 O(n)、空间 O(n)。排序后只比较相邻元素能把额外哈希空间降为 O(1)/O(log n)，但时间变为 O(n log n)，且可能修改输入。

面试追问

若限制数值范围很小，可用布尔数组或位图；若要返回重复值的首次两个索引，用 Map 存首次位置；流式数据则持续保留集合。

常见错误

先插入再判断导致无法利用 add 的返回值；用双重循环导致 O(n²)；误把“有重复”理解成“每个元素重复”；排序后漏比最后一对。

四语言可提交代码

class Solution {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int value : nums) if (!seen.add(value)) return true;
        return false;
    }
}
var containsDuplicate = function(nums) {
  const seen = new Set();
  for (const value of nums) { if (seen.has(value)) return true; seen.add(value); }
  return false;
};
class Solution:
    def containsDuplicate(self, nums: list[int]) -> bool:
        seen = set()
        for value in nums:
            if value in seen:
                return True
            seen.add(value)
        return False

public:
