柯里化，
Curry

把一次完整调用拆成若干次自由分组的调用。你需要返回一个新函数，让它在参数尚未凑齐时仍可继续调用，并在恰当时刻给出原函数的结果。

MEDIUM付费题闭包 · 高阶函数官方语言：JavaScript / TypeScript
Problem

题意

给定函数 fn，返回它的柯里化版本。每次调用可传入不超过原函数所需总数的一部分参数；参数齐全后，返回值应与直接调用 fn 相同。

允许任意分组：若 sum(a, b, c) 接收三个参数，那么 curriedSum(1)(2)(3)、curriedSum(1, 2)(3)、curriedSum(1)(2, 3) 与 curriedSum(1, 2, 3) 都应得到相同结果；空调用也可以出现。

约束

  • 1 <= inputs.length <= 1000
  • 0 <= inputs[i][j] <= 105
  • 0 <= fn.length <= 1000
  • inputs.flat().length === fn.length
  • 函数参数均显式定义。
  • 若 fn.length > 0，则 inputs 的最后一个数组非空。
  • 若 fn.length === 0，则 inputs.length === 1。

核心洞察

函数的声明参数个数可由 fn.length 得到。每次收到参数后，把它们与此前参数合并：数量不足就返回仍可调用的函数；数量达到目标就调用原函数。

完整过程

  1. curry(fn) 返回内部函数 curried。
  2. curried 接收当前累计的全部参数。
  3. 若数量至少为 fn.length，保留当前 this 并执行 fn。
  4. 否则预先绑定已有参数，返回下一棒函数。

正确性

不变式：每次进入 curried 时，参数序列按调用顺序恰好包含此前所有分组传入的参数。参数不足时，返回函数保存该序列，因此不变式延续；参数达到 fn.length 时，以完整且顺序一致的参数调用 fn，故返回值与直接调用相同。

复杂度

设总参数数为 n、调用分组数为 k。不计 fn 自身，累计参数复制总成本为 O(nk)，逐个传参时最坏 O(n²)；保存参数占 O(n) 空间。

边界

  • 空调用：不会增加参数，仍返回可继续调用的函数。
  • 零参数函数：fn.length === 0，首次空调用立即执行。
  • 参数成组传入：一次可补齐多个参数。
  • 默认参数 / 剩余参数：真实工程中 fn.length 的含义可能与业务期望参数数不同；本题保证参数显式定义。
  • 调用上下文：apply 与 bind 让普通函数的 this 得到保留。

JavaScript

官方可提交
/**
 * @param {Function} fn
 * @return {Function}
 */
var curry = function(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn.apply(this, args);
    }
    return curried.bind(this, ...args);
  };
};

/**
 * function sum(a, b) { return a + b; }
 * const curriedSum = curry(sum);
 * curriedSum(1)(2); // 3
 */

Python

本地语义参考
from collections.abc import Callable
from typing import Any


def curry(fn: Callable[..., Any]) -> Callable[..., Any]:
    arity = fn.__code__.co_argcount

    def curried(*args: Any) -> Any:
        if len(args) >= arity:
            return fn(*args)
        return lambda *more: curried(*args, *more)

    return curried


def sum3(a: int, b: int, c: int) -> int:
    return a + b + c


curried_sum = curry(sum3)
result = curried_sum(1)(2, 3)  # 6

Java

本地语义参考 · 整数版
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.function.Function;

public class CurryReference {
  static final class Curried {
    private final Function<List<Integer>, Integer> fn;
    private final int arity;
    private final List<Integer> args;

    Curried(Function<List<Integer>, Integer> fn,
            int arity, List<Integer> args) {
      this.fn = fn;
      this.arity = arity;
      this.args = args;
    }

    Object call(Integer... next) {
      List<Integer> all = new ArrayList<>(args);
      all.addAll(Arrays.asList(next));
      return all.size() >= arity
          ? fn.apply(all)
          : new Curried(fn, arity, all);
    }
  }

  static Curried curry(
      Function<List<Integer>, Integer> fn, int arity) {
    return new Curried(fn, arity, List.of());
  }

  public static void main(String[] args) {
    Curried sum = curry(xs -> xs.stream()
        .mapToInt(Integer::intValue).sum(), 3);
    Curried afterOne = (Curried) sum.call(1);
    int result = (Integer) afterOne.call(2, 3); // 6
    System.out.println(result);
  }
}

C++

本地语义参考 · 整数版
#include <any>
#include <functional>
#include <iostream>
#include <memory>
#include <utility>
#include <vector>

class Curried {
 public:
  using Fn = std::function<int(const std::vector<int>&)>;

  Curried(Fn fn, std::size_t arity,
          std::vector<int> args = {})
      : fn_(std::move(fn)), arity_(arity),
        args_(std::move(args)) {}

  std::any call(std::vector<int> next = {}) const {
    auto all = args_;
    all.insert(all.end(), next.begin(), next.end());
    if (all.size() >= arity_) return fn_(all);
    return std::make_shared<Curried>(fn_, arity_, all);
  }

 private:
  Fn fn_;
  std::size_t arity_;
  std::vector<int> args_;
};

int main() {
  Curried sum([](const std::vector<int>& xs) {
    int total = 0;
    for (int x : xs) total += x;
    return total;
  }, 3);

  auto next = std::any_cast<std::shared_ptr<Curried>>(
      sum.call({1}));
  int result = std::any_cast<int>(next->call({2, 3}));
  std::cout << result << '\n'; // 6
}

替代方案

可以用递归闭包保存 args，也可以维护可变数组以降低重复复制。后者更快，但复用同一个“半成品函数”时容易共享状态；本解用不可变累积换取分支调用安全。

常见错误

  • 只检查本次参数数，而不是累计参数数。
  • 空调用时错误执行原函数或丢掉历史参数。
  • 把条件写成严格大于，导致刚好凑齐时仍返回函数。
  • 用共享可变数组，令多个分支互相污染。
  • 忽略零参数函数与 this 上下文。

面试追问

Q1

如何支持默认参数或 rest 参数？可让调用者显式传入目标 arity，不再只依赖 fn.length。

Q2

如何支持占位符？需要记录参数槽位，并在后续调用中优先填补空槽。

Q3

如何优化复制成本？可使用持久化链表或受控可变缓冲区，并明确是否允许分支复用。
