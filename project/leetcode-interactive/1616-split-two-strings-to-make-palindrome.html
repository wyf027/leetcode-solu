1616. 分割两个字符串得到回文串

Split Two Strings to Make Palindrome

MEDIUM非付费题O(n) 目标

Problem

题意

给定两个长度相同的字符串 a 和 b。选择同一个分割下标，把两串分别拆成前缀与后缀。判断是否存在一种分割，使 aPrefix + bSuffix 或 bPrefix + aSuffix 成为回文串。

分割边界也合法：前缀或后缀允许为空，所以完全取 a 或完全取 b 也是候选。

函数形式

checkPalindromeFormation(a: string, b: string): boolean

Limits

约束

  • 1 <= a.length, b.length <= 105
  • a.length == b.length
  • a、b 只含小写英文字母

关键定义

回文串从左向右与从右向左读完全一致；x + y 表示字符串拼接。

Official examples

示例

示例 1
输入：a = "x", b = "y"
输出：true
解释：分割可在边界；单字符 "y" 是回文串。
示例 2
输入：a = "xbdef", b = "xecab"
输出：false
示例 3
输入：a = "ulacfd", b = "jizalu"
输出：true
解释：在下标 3 处分割：
aPrefix = "ula", aSuffix = "cfd"
bPrefix = "jiz", bSuffix = "alu"
aPrefix + bSuffix = "ula" + "alu" = "ulaalu"，它是回文串。

题解：交叉双指针 + 区间回文

核心洞察

尝试一种拼接方向时，只需让左串的左端与右串的右端持续匹配。首次不相等后，外层已经确定，剩余区间必须全部取自同一条原串。

两个方向

分别检查 a 前缀 + b 后缀 与 b 前缀 + a 后缀。任一方向可行即返回 true。

一次线性扫描

每个方向的指针只向中心移动；剩余窗口至多再扫描一次，因此总复杂度仍为线性。

完整过程

  1. 定义 check(x, y)，令 i = 0、j = n - 1。
  2. 当 i < j 且 x[i] == y[j] 时，两指针同时向中心移动。这些字符可由 x 的前缀和 y 的后缀提供。
  3. 如果指针相遇或交错，外侧交叉匹配已覆盖整个串，该方向直接成功。
  4. 若在区间 [i, j] 首次失配，分割点只能让中间全部来自 x 或全部来自 y。检查 x[i..j]、y[i..j] 是否至少一个为回文。
  5. 返回 check(a, b) || check(b, a)。

正确性证明

引理：对固定方向 x 前缀 + y 后缀，交叉扫描第一次失配于 i, j 后，存在合法回文拼接，当且仅当 x[i..j] 或 y[i..j] 是回文。

证明：在失配前，所有外层位置都已有 x[k] = y[n-1-k]，不会妨碍回文。分割边界若落在剩余窗口左侧，中间完整取自 y；若落在窗口右侧，中间完整取自 x。因为失配位置不能跨串互相配对，中间必须由其中一串自身构成回文；反之，若任一剩余区间是回文，把边界放在相应一侧，与已匹配外层组合即可得到回文。

定理：算法检查两个可能的拼接方向，并依据引理准确判定每个方向，故返回值当且仅当题目要求的某种拼接能形成回文。

边界情况

  • 长度为 1：指针一开始就相遇，必为 true。
  • a 或 b 本身是回文：允许空前缀/后缀，所以可行。
  • 首次比较就失配：直接检查两条完整字符串是否有一条是回文。
  • 奇数长度：中心单字符天然满足回文；偶数长度：指针交错即完成。

复杂度

时间：O(n)。两个方向各进行常数次线性指针扫描。

空间：O(1)，不创建子串，只使用下标。

替代方案

枚举所有分割点并构造拼接串需要 O(n²) 时间，且产生额外字符串；滚动哈希可以做到近线性判定，但实现更复杂、存在哈希碰撞风险，并非本题最简选择。

面试追问

  • 为什么首次失配后只需检查两个同串区间？
  • 怎样避免切片产生的额外 O(n) 空间？
  • 如果两串长度不同，题目定义和算法需要如何调整？
  • 能否返回一个可行分割下标，而不仅是布尔值？

常见错误

  • 只检查 check(a, b)，漏掉反向拼接。
  • 失配后继续跨串比较，而不是检查同一串的剩余区间。
  • 遗漏空前缀或空后缀的合法分割。
  • 使用 substring / 切片反复复制，隐藏额外开销。
  • 回文判断循环写成边界不正确的 left <= right 并错误访问下标。
