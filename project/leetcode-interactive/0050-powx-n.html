CORE INSIGHT

核心洞察

将指数写成二进制：10 = 1010₂ = 2 + 8，因此 x¹⁰ = x² × x⁸。逐位扫描时，第 i 位为 1 才把 x^(2ⁱ) 乘入答案。

LOOP INVARIANT

循环不变量

始终保持 result × base^exponent 等于归一化后的原目标值。若最低位为 1 则累乘；随后 base 平方、exponent 右移。

FULL WALKTHROUGH

完整解题过程

NORMALIZE

用 64 位保存 n；负指数先把 x 取倒数，再对 n 取反。

READ BIT

读取最低位。为 1 时执行 result *= base。

SQUARE

base *= base，依次得到 x、x²、x⁴、x⁸。

SHIFT

exponent 右移，归零时返回 result。

边界情况

  • n = 0：返回 1。
  • n < 0：转成 (1/x)^(-n)。
  • n = -2³¹：先提升到 64 位，避免取反溢出。
  • x = -1 / 1：统一逻辑即可。

复杂度

时间 O(log |n|)

空间 O(1)

替代方案

递归快速幂同为 O(log |n|)，表达简洁但使用调用栈。面试主线推荐迭代版：状态清晰且空间 O(1)。

常见错误

  • 连乘 |n| 次，退化为 O(|n|)。
  • 在 32 位 int 中执行 -n，MIN_VALUE 溢出。
  • 负指数忘记先对 x 取倒数。
  • 浮点测试使用严格相等。

面试高频追问

为什么每轮平方？
下一二进制位的权重从 2ⁱ 变成 2ⁱ⁺¹。
如何证明？
使用 result × base^exponent 的循环不变量。
能否递归？
可以，但需要 O(log |n|) 调用栈。

class Solution {
    public double myPow(double x, int n) {
        long exponent = n;
        if (exponent < 0) {
            x = 1.0 / x;
            exponent = -exponent;
        }
        double result = 1.0;
        while (exponent > 0) {
            if ((exponent & 1) == 1) result *= x;
            x *= x;
            exponent >>= 1;
        }
        return result;
    }
}
