探测环

当搜索路径再次碰到一个已访问的同字符格子——而它又不是刚刚走来的父节点——一个合法环便闭合了。

中等深度优先搜索广度优先搜索并查集矩阵

题目

给定一个 m × n 的字符网格 grid，判断其中是否存在完全由同一字符组成的环。

  • 每一步只能向上、下、左、右移动到相邻且字符相同的格子。
  • 环从某个格子出发并回到该格子，路径长度至少为 4。
  • 不能把立即退回上一步所在格子当成环；例如 (1,1) → (1,2) → (1,1) 不合法。

返回值：存在任意合法同字符环时返回 true，否则返回 false。

官方示例

完整参数形式

示例 1 · 外环与内环

输入：grid = [["a","a","a","a"],
 ["a","b","b","a"],
 ["a","b","b","a"],
 ["a","a","a","a"]]
输出：true
解释：网格中存在两个合法环。

输入：grid = [["c","c","c","a"],
 ["c","d","c","c"],
 ["c","c","e","c"],
 ["f","c","c","c"]]
输出：true
解释：字符 c 形成一个合法环。

示例 3 · 无环

输入：grid = [["a","b","b"],
 ["b","z","b"],
 ["b","b","a"]]
输出：false

准备好拆解算法了吗？

先尝试用上方演示回答：为什么必须保存父节点？

Solution

DFS + 父节点：识别“回到旧路”，排除“原路退回”

核心洞察：同字符格子与四向相邻关系构成无向图。搜索时若看到一个已访问邻居，且它不是当前格的父节点，则该连通分量必然含环。

完整过程

  1. 建立与网格等大的 visited。
  2. 逐格扫描；遇到未访问格子，就开始一次 DFS。
  3. 递归参数携带当前位置和父坐标，只沿同字符四邻格移动。
  4. 未访问邻居继续递归；已访问且非父节点的邻居说明出现环。
  5. 所有连通分量都未命中条件，返回 false。

正确性证明

充分性：当前格与已访问的非父邻居在 DFS 树中已有路径，再加入当前检查的边便形成闭环。四邻接网格是二分图，不存在奇环，所以环长至少为 4。

必要性：若同字符环存在，DFS 沿环搜索时最终会检查到一条连接两个已访问节点的非树边；它不是父子原路边，算法必然报告环。

边界情况

  • 单行或单列网格无法形成环。
  • 所有字符互异时，每个分量只有一格。
  • 两个相邻同字符格子的往返会被父节点判断排除。
  • 必须遍历所有分量，不能只从 (0,0) 出发。
  • 递归深度最坏为 m × n，栈受限时可用 BFS 或显式栈。

复杂度

每个格子至多首次访问一次，每次检查四个方向。

时间：O(mn)
额外空间：O(mn)

替代方案

BFS：队列元素携带父坐标，判环条件相同。并查集：扫描时只连接右、下方同字符邻居；连接前若两端已在同一集合，就发现环。复杂度近似线性，但表达不如 DFS 直接。

四语言完整实现

class Solution {
    private char[][] grid;
    private boolean[][] seen;
    private int m, n;
    private final int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

    public boolean containsCycle(char[][] grid) {
        this.grid = grid;
        m = grid.length; n = grid[0].length;
        seen = new boolean[m][n];
        for (int r = 0; r < m; r++)
            for (int c = 0; c < n; c++)
                if (!seen[r][c] && dfs(r, c, -1, -1)) return true;
        return false;
    }

    private boolean dfs(int r, int c, int pr, int pc) {
        seen[r][c] = true;
        for (int[] d : dirs) {
            int nr = r + d[0], nc = c + d[1];
            if (nr < 0 || nr >= m || nc < 0 || nc >= n ||
                grid[nr][nc] != grid[r][c]) continue;
            if (!seen[nr][nc]) {
                if (dfs(nr, nc, r, c)) return true;
            } else if (nr != pr || nc != pc) {
                return true;
            }
        }
        return false;
    }
}

var containsCycle = function(grid) {
  const m = grid.length, n = grid[0].length;
  const seen = Array.from({ length: m }, () => Array(n).fill(false));
  const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];

  function dfs(r, c, pr, pc) {
    seen[r][c] = true;
    for (const [dr, dc] of dirs) {
      const nr = r + dr, nc = c + dc;
      if (nr < 0 || nr >= m || nc < 0 || nc >= n ||
          grid[nr][nc] !== grid[r][c]) continue;
      if (!seen[nr][nc]) {
        if (dfs(nr, nc, r, c)) return true;
      } else if (nr !== pr || nc !== pc) {
        return true;
      }
    }
    return false;
  }

  for (let r = 0; r < m; r++)
    for (let c = 0; c < n; c++)
      if (!seen[r][c] && dfs(r, c, -1, -1)) return true;
  return false;
};
from typing import List

class Solution:
    def containsCycle(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        seen = [[False] * n for _ in range(m)]
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

        def dfs(r: int, c: int, pr: int, pc: int) -> bool:
            seen[r][c] = True
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if not (0 <= nr < m and 0 <= nc < n):
                    continue
                if grid[nr][nc] != grid[r][c]:
                    continue
                if not seen[nr][nc]:
                    if dfs(nr, nc, r, c):
                        return True
                elif (nr, nc) != (pr, pc):
                    return True
            return False

        for r in range(m):
            for c in range(n):
                if not seen[r][c] and dfs(r, c, -1, -1):
                    return True
        return False

常见错误

  • 见到任何已访问邻居就判环，误把父节点当回边。
  • 用“上一个字符”代替父坐标，无法标识具体节点。
  • 只从 (0,0) 搜索，遗漏其他分量。
  • 为每个起点重建访问数组，导致复杂度恶化。
  • 把斜向相邻也当作边，改变了题意。
