按符号重排数组

Rearrange Array Elements by Sign

正负交替只是第一步。你还需要让同一符号的数字，保留原来的先后关系。

官方题目 ↗

题目任务

给定从下标 0 开始的整数数组 nums，它的长度为偶数，正数与负数的数量相等。返回一个由这些元素重排得到的数组，满足：

  1. 首个元素是正数。
  2. 相邻两个元素的符号不同。
  3. 所有正数之间、所有负数之间的相对顺序分别保持不变。

不要求原地修改，可以新建返回数组。函数参数为 nums: integer[]，返回值为 integer[]。

约束

  • 2 ≤ nums.length ≤ 2 × 10⁵，且长度为偶数。
  • 1 ≤ |nums[i]| ≤ 10⁵，没有 0。
  • 正整数和负整数各占一半。

官方示例

示例 1

输入：nums = [3,1,-2,-5,2,-4]
输出：[3,-2,1,-5,2,-4]

正数的顺序为 3、1、2；负数的顺序为 -2、-5、-4。输出同时保留这两种顺序，并从正数开始交替。

示例 2

输入：nums = [-1,1]
输出：[1,-1]

只有一正一负，正数必须放在第一位。

除了正负交替，怎样判断一个重排结果是否真的保留了顺序？试着手写示例，再展开推导与交互演示。

题解 · 两条保序写入轨道

核心洞察

正数开头且正负交替，意味着正数只能占下标 0、2、4…，负数只能占下标 1、3、5…。从左到右读取输入，让每个数字写到它所属符号的下一个空位，就能自然保序。

交互实验 · 符号分流器

绿色 + 正数 / 红色 − 负数

保持偶数长度、正负各半、无 0，整数绝对值不超过 100000。完整解法支持题目规定的 200000 个元素。

按钮支持 Tab、Enter、空格。自动播放每 1.2 秒一步；减少动态效果偏好下每 2.4 秒一步。

① 输入带 · 从左到右

② 正数轨道 → 偶数位

② 负数轨道 → 奇数位

③ 合流 · 结果数组

完整过程

  1. 新建长度为 n 的数组 ans，令 p = 0、q = 1。
  2. 依次读取 nums 中的 x。若 x > 0，写入 ans[p]，p += 2；否则写入 ans[q]，q += 2。
  3. 所有元素处理结束后返回 ans。

示例 1 的写入目的地依次是：3 → 0，1 → 2，-2 → 1，-5 → 3，2 → 4，-4 → 5。最终得到 [3,-2,1,-5,2,-4]。

正确性 · 循环不变式

处理前 k 个输入后，已遇到的正数按原顺序填满前若干偶数位，负数按原顺序填满前若干奇数位；p、q 分别指向各轨道的下一个空位。

初始两轨都为空，不变式成立。每轮只向所属轨道末尾追加 x，因此不改变旧元素顺序，也不会覆盖另一轨道。正负各有 n/2 个，所有写入下标都有效。终止时每个位置恰好写入一次，偶数位正、奇数位负，因此从正数开头、符号交替且同号保序。

边界与复杂度

长度 2、输入已交替、某符号集中在一段、重复元素以及 ±100000 均按同样规则处理。无需排序，也无需对数值取绝对值。

时间 O(n)：遍历一次，每次常数操作。空间 O(n)：新建结果数组；若不计返回数组，辅助空间为 O(1)。末尾 p = n、q = n + 1 是哨兵位置，不再用于访问。

替代方案

先将正数、负数分别收集到两个数组，再交替合并，时间 O(n)、空间 O(n)，思路直观但多存两份分组。直接奇偶位写入省去分组数组。

若必须原地且保序，可反复找到所需符号并旋转区间，使用 O(1) 额外空间，但简单实现最坏 O(n²)。本题不要求原地，无需承担该代价。

常见错误

  • 按数值排序：破坏同号相对顺序。
  • 随意交换相反符号元素：可能使同号元素越过彼此。
  • p、q 每次只加 1：导致轨道重叠。
  • 在输入数组上直接写入：可能覆盖尚未读取的元素。
  • 用输入下标的奇偶决定符号：输入没有交替保证。

面试追问

结果唯一吗？唯一。第 k 个正数只能放在第 k 个偶数位，第 k 个负数只能放在第 k 个奇数位。

正负数量不等呢？当前契约不覆盖这种输入。若仍强制正数开头且严格交替，正数数量只能等于负数数量或比它多 1；其他情况需重新定义剩余元素的放置规则。

允许 0 呢？必须先定义 0 的分组语义，不能直接把它视作负数。

Java

class Solution {
    public int[] rearrangeArray(int[] nums) {
        int[] ans = new int[nums.length];
        int p = 0, q = 1;
        for (int x : nums) {
            if (x > 0) {
                ans[p] = x;
                p += 2;
            } else {
                ans[q] = x;
                q += 2;
            }
        }
        return ans;
    }
}
