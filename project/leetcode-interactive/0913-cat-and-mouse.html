猫和老鼠

把每个“老鼠位置 × 猫位置 × 轮到谁”视为一个局面，从已知胜负的终局向前反推。先观察游戏规则与状态传播，再按需展开完整题解。

困难图拓扑排序极小化极大动态规划非付费题

题目

两名玩家在无向图上轮流移动。老鼠从节点 1 先手，猫从节点 2 后手，节点 0 是洞。行动时必须沿一条相邻边移动，但猫不能进入洞。

老鼠到达节点 0 时老鼠胜；猫与老鼠处于同一节点时猫胜；若同一组“双方位置与当前行动方”再次出现，则平局。双方均采用最优策略，返回 1（老鼠胜）、2（猫胜）或 0（平局）。

函数签名： catMouseGame(graph: integer[][]): integer

示例 1

输入：graph = [[2,5],[3],[0,4,5],[1,4,5],[2,3],[0,2,3]]
输出：0

示例 2

输入：graph = [[1,3],[0],[3],[0,2]]
输出：1

约束

  • 3 <= graph.length <= 50
  • 1 <= graph[i].length < graph.length
  • 0 <= graph[i][j] < graph.length
  • graph[i][j] != i
  • 每个邻接表 graph[i] 中的节点互不相同。
  • 猫和老鼠始终都有合法移动。

    题解：从终局反推的拓扑博弈

    核心洞察

    状态写作 (m,c,t)，其中 t=0 表示老鼠行动，t=1 表示猫行动。状态总数至多 2n²。先把“鼠在洞里”和“猫鼠同点”染成已知胜负，再用队列向父状态传播。

    何时能给父状态定性？

    • 父状态的行动方若能一步走到自己的获胜状态，立即判胜。
    • 否则删去这个已确定但不利的选择；当所有合法选择都不利时，父状态判负。
    • 最终仍未染色的状态属于可循环区域，结果为平局。

    完整过程

    1. 为每个状态记录颜色：0 未知、1 鼠胜、2 猫胜。
    2. 记录出度：鼠回合是 graph[m].length；猫回合排除通向 0 的边。
    3. 所有 (0,c,t) 入队并标为鼠胜；所有 (m,m,t) 入队并标为猫胜。
    4. 弹出已知状态，枚举一步之前可能到达它的父状态。若当前结果对父状态行动者有利，父状态立即继承；否则父状态出度减一，减到 0 时判为对手胜。
    5. 返回初始状态 (1,2,0) 的颜色。

    正确性证明

    引理 1：初始化状态的颜色正确，因为它们已满足题目规定的直接终局。引理 2：若行动方存在一个已知的己方获胜后继，那么选择该步即可强制获胜；算法据此染色正确。引理 3：若一个状态的每个合法后继都已证明是对手胜，则行动方无论怎样移动都会输；出度归零时的染色正确。由队列归纳，所有被染色状态的结论都正确。未染色状态既没有通向己方必胜状态的选择，也未被证明所有选择必败，最优双方可以留在未决环中重复状态，因此为平局。故初始状态的返回值正确。

    边界与复杂度

    • 猫的出度和父状态枚举都必须排除节点 0。
    • 终局初始化中 m=0 与 m=c 不应制造矛盾；只对猫位置 c≥1 建立合法状态。
    • 每个状态至多按相关邻边处理，时间 O(n³)，空间 O(n²)。

    替代方案

    可用带步数上限 2n² 的记忆化 minimax，将超过上限视为平局，较直观但状态多一维且证明更绕。逆向拓扑法直接刻画必胜/必败吸引域，通常更稳定。

    面试追问

    • 为什么未染色就是平局？尝试用有限状态图与闭合环说明。
    • 若猫允许进洞，出度和父状态生成应如何变化？
    • 如何推广到有向图或三个行动者？

    常见错误

    • 只用 (mouse,cat) 判重，漏掉行动方。
    • 猫回合的 degree 未减去通往 0 的边。
    • 把“存在一个对手胜后继”误判为当前必败；必败需要所有选择都输。
    • 用普通 BFS 模拟真实走法，无法表达双方最优策略。

    import java.util.*;

class Solution {
  public int catMouseGame(int[][] graph) {
    int n = graph.length;
    int[][][] color = new int[n][n][2];
    int[][][] degree = new int[n][n][2];
    ArrayDeque<int[]> q = new ArrayDeque<>();
    for (int m = 0; m < n; m++) for (int c = 1; c < n; c++) {
      degree[m][c][0] = graph[m].length;
      degree[m][c][1] = graph[c].length;
      for (int v : graph[c]) if (v == 0) degree[m][c][1]--;
    }
    for (int c = 1; c < n; c++) for (int t = 0; t < 2; t++) {
      color[0][c][t] = 1; q.offer(new int[]{0,c,t,1});
    }
    for (int m = 1; m < n; m++) for (int t = 0; t < 2; t++) {
      color[m][m][t] = 2; q.offer(new int[]{m,m,t,2});
    }
    while (!q.isEmpty()) {
      int[] s = q.poll(); int m=s[0], c=s[1], turn=s[2], win=s[3];
      if (turn == 0) {
        for (int pc : graph[c]) { if (pc == 0 || color[m][pc][1] != 0) continue; update(color,degree,q,m,pc,1,win); }
      } else {
        for (int pm : graph[m]) { if (color[pm][c][0] != 0) continue; update(color,degree,q,pm,c,0,win); }
      }
    }
    return color[1][2][0];
  }
  private void update(int[][][] color,int[][][] degree,ArrayDeque<int[]> q,int m,int c,int t,int childWin) {
    int moverWin = t == 0 ? 1 : 2;
    if (childWin == moverWin) { color[m][c][t]=childWin; q.offer(new int[]{m,c,t,childWin}); }
    else if (--degree[m][c][t] == 0) { int win=3-moverWin; color[m][c][t]=win; q.offer(new int[]{m,c,t,win}); }
  }
}

var catMouseGame = function(graph) {
  const n=graph.length, color=Array.from({length:n},()=>Array.from({length:n},()=>[0,0]));
  const degree=Array.from({length:n},()=>Array.from({length:n},()=>[0,0])), q=[];
  for(let m=0;m<n;m++) for(let c=1;c<n;c++) {
    degree[m][c][0]=graph[m].length;
    degree[m][c][1]=graph[c].reduce((s,v)=>s+(v!==0),0);
  }
  for(let c=1;c<n;c++) for(let t=0;t<2;t++){color[0][c][t]=1;q.push([0,c,t,1]);}
  for(let m=1;m<n;m++) for(let t=0;t<2;t++){color[m][m][t]=2;q.push([m,m,t,2]);}
  const setParent=(m,c,t,win)=>{
    if(color[m][c][t]) return;
    const mover=t===0?1:2;
    if(win===mover){color[m][c][t]=win;q.push([m,c,t,win]);}
    else if(--degree[m][c][t]===0){const w=3-mover;color[m][c][t]=w;q.push([m,c,t,w]);}
  };
  for(let head=0;head<q.length;head++){
    const [m,c,t,win]=q[head];
    if(t===0) for(const pc of graph[c]) { if(pc!==0) setParent(m,pc,1,win); }
    else for(const pm of graph[m]) setParent(pm,c,0,win);
  }
  return color[1][2][0];
};
    from collections import deque
from typing import List

class Solution:
    def catMouseGame(self, graph: List[List[int]]) -> int:
        n = len(graph)
        color = [[[0, 0] for _ in range(n)] for _ in range(n)]
        degree = [[[0, 0] for _ in range(n)] for _ in range(n)]
        q = deque()
        for m in range(n):
            for c in range(1, n):
                degree[m][c][0] = len(graph[m])
                degree[m][c][1] = sum(v != 0 for v in graph[c])
        for c in range(1, n):
            for t in range(2):
                color[0][c][t] = 1
                q.append((0, c, t, 1))
        for m in range(1, n):
            for t in range(2):
                color[m][m][t] = 2
                q.append((m, m, t, 2))
        while q:
            m, c, turn, winner = q.popleft()
            parents = ((m, pc, 1) for pc in graph[c] if pc != 0) if turn == 0 \
                      else ((pm, c, 0) for pm in graph[m])
            for pm, pc, pt in parents:
                if color[pm][pc][pt]:
                    continue
                mover = 1 if pt == 0 else 2
                if winner == mover:
                    color[pm][pc][pt] = winner
                    q.append((pm, pc, pt, winner))
                else:
                    degree[pm][pc][pt] -= 1
                    if degree[pm][pc][pt] == 0:
                        color[pm][pc][pt] = 3 - mover
                        q.append((pm, pc, pt, 3 - mover))
        return color[1][2][0]

class Solution {
public:
  int catMouseGame(vector<vector<int>>& graph) {
    int n=graph.size();
    vector color(n, vector(n, array<int,2>{0,0}));
    vector degree(n, vector(n, array<int,2>{0,0}));
    queue<array<int,4>> q;
    for(int m=0;m<n;m++) for(int c=1;c<n;c++) {
      degree[m][c][0]=graph[m].size();
      for(int v:graph[c]) if(v!=0) degree[m][c][1]++;
    }
    for(int c=1;c<n;c++) for(int t=0;t<2;t++){color[0][c][t]=1;q.push({0,c,t,1});}
    for(int m=1;m<n;m++) for(int t=0;t<2;t++){color[m][m][t]=2;q.push({m,m,t,2});}
    auto update=[&](int m,int c,int t,int win){
      if(color[m][c][t]) return;
      int mover=t==0?1:2;
      if(win==mover){color[m][c][t]=win;q.push({m,c,t,win});}
      else if(--degree[m][c][t]==0){int w=3-mover;color[m][c][t]=w;q.push({m,c,t,w});}
    };
    while(!q.empty()){
      auto [m,c,t,win]=q.front();q.pop();
      if(t==0) for(int pc:graph[c]) {if(pc!=0) update(m,pc,1,win);}
      else for(int pm:graph[m]) update(pm,c,0,win);
    }
    return color[1][2][0];
  }
};
