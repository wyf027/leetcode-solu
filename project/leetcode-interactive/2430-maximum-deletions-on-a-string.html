Maximum Deletions on a String

每次只能从开头动手。你能把一串字母，拆成尽可能多次合法删除吗？先读规则，再尝试推演。

01 / 题目与规则

给定只含小写英文字母的字符串 s。每次操作任选一种方式：

  1. 直接删除当前剩余的整个字符串。
  2. 选择长度 k，满足 1 ≤ k ≤ ⌊当前长度 / 2⌋。只有当前开头的 k 个字符，与紧接着的 k 个字符完全相同时，才能删除第一段。

求清空字符串最多能执行几次操作。相同的片段必须相邻，不能跳过中间字符。

ab | ab | c → ab | c

两段相邻的「ab」相等，因此可以删除前一个「ab」；不是把两个片段一起删除。

参数：s: string返回：integer范围：1 ≤ s.length ≤ 4000字符仅为 a–z

02 / 官方示例

示例 1 · 相邻是关键

输入：s = "abcabcdabc"
输出：2

先删除开头「abc」，得到「abcdabc」，再删除全部。此时开头「abc」后紧接着的是「dab」，所以不能继续按长度 3 删除。最多 2 次。

示例 2 · 删除长度可以变化

输入：s = "aaabaab"
输出：4

「aaabaab」→「aabaab」→「aab」→「ab」→ 空串。依次删除长度 1、3、1，最后删掉全部，共 4 次且为最大值。

示例 3 · 尽量多的操作

输入：s = "aaaaa"
输出：5

每次删除一个「a」，最后一个字符使用“删除全部”，共 5 次。

04 / 题解 · 后缀决策 + 滚动 LCP

核心洞察

每次删前缀，余下的一定是原串的某个后缀。用 dp[i] 表示清空 s[i…n) 的最大操作数。无需真的修改字符串，只需移动后缀起点。

任何非空后缀都可以一次删完，所以 dp[i] = 1 起步。枚举删除长度 k：若 i + 2k ≤ n 且 s[i…i+k) = s[i+k…i+2k)，第一步后剩下后缀 i+k，得到候选 1 + dp[i+k]。

dp[n] = 0
 dp[i] = max(1, 1 + dp[i+k] 对所有合法 k)
从 i = n-1 到 0 计算，答案为 dp[0]。

如何快速判断相等？

LCP(i,j) 是从 i 和 j 出发的两个后缀的最长公共前缀长度。字符相等时，它等于 1 + LCP(i+1,j+1)，否则为 0。令 j=i+k，合法条件就是 LCP(i,j) ≥ k 并且 j+k ≤ n。

只保存一行 lcp[j]。外层 i 从右往左，内层 j 从左往右：写入当前位置时，右边的 lcp[j+1] 还没被覆盖，仍代表上一行。每行必须更新所有 j > i，包括当前不能构成两个等长块的位置，因为前面的行仍会用到这些值。

完整过程

  1. 分配长度 n+1 的 dp 与 lcp，初始为 0。
  2. 倒序选后缀起点 i，把 dp[i] 置为 1。
  3. 正序枚举第二段起点 j，先更新 lcp[j]，再检查长度 k=j-i 是否合法。
  4. 合法就尝试 dp[i] = max(dp[i], 1+dp[j])。
  5. 所有后缀计算完后，返回 dp[0]。

06 / 正确性、边界与代价

正确性证明

先证明比较可靠：若首字符不同，公共前缀为 0；否则去掉这一对相同字符后，余下公共前缀为 LCP(i+1,j+1)，加 1 即得递推。滚动数组按正序更新 j，保留所需上一行值，所以计算出的 LCP 精确。

再对后缀长度归纳。单字符只能整串删除，答案为 1。假定更短后缀的 dp 正确；当前最优方案第一步要么删全部，贡献 1，要么删某个合法长度 k，贡献 1+dp[i+k]。算法覆盖了所有这类第一步，没有加入非法操作；取最大值得到当前后缀最优解。倒序计算满足归纳前提，因此 dp[0] 正确。

边界

  • 长度 1：内层循环为空，直接返回 1。
  • 没有合法的相邻重复前缀：保留基线 1。
  • 全部相同：每次删一个，最多 n 次，因为一次至少删掉一个字符。
  • 奇数长度：只枚举能容纳两段的 k，剩余尾巴可以留给后续操作。
  • 末尾空后缀的 dp 为 0；“删除全部”只计一次，不继续对空串操作。

复杂度

每个 (i,j) 只做常数时间比较和转移，共 n(n−1)/2 对。时间 O(n²)，辅助空间 O(n)；返回的是次数，不额外保存删除路径。n=4000 时约 800 万对位置。

替代方案

  • 完整二维 LCP 表 + 同一 dp：同为 O(n²) 时间，但空间 O(n²)，更直观，存储开销更大。
  • 为每个后缀计算 Z 数组：可同样做到 O(n²) 时间、O(n) 辅助空间，字符串匹配实现更复杂。
  • 滚动哈希 + dp：O(n²) 时间，可减少存储，但哈希相等存在碰撞风险；这里使用精确 LCP。
  • 每次切片逐字符比较：最坏 O(n³) 时间；递归枚举而不记忆状态会重复搜索。

常见错误

  • 找后面任意相同片段，忽略必须紧接当前前缀。
  • 把“最大操作数”写成求最少；最少永远是一次删完。
  • 把滚动行的 j 倒序更新，导致读取到当前行，污染 LCP。
  • 遇到当前 j 的前缀不合法就结束枚举，漏掉更长的合法前缀。
  • 只更新当前合法长度范围内的 LCP，破坏后续行需要的状态。
  • 只取第一个合法 k 却不给出贪心证明；动态规划会比较全部候选。

面试追问

如何还原操作？更新最优值时记录 next[i]=j，基线用“删全部”标记；从 0 沿指针走。为什么空间能滚动？LCP 只依赖下一行，且下一行的右侧尚未覆盖。如果 n 大很多？本方案仍有二次枚举瓶颈；仅改相等查询结构不足以降低总时间，需要进一步利用可删除前缀的结构。

07 / 四语言完整实现

采用相同的滚动 LCP + 后缀 dp，签名对应官方提交入口。代码仅生成，尚未执行验证。

Java

class Solution {
    public int deleteString(String s) {
        int n = s.length();
        int[] dp = new int[n + 1];
        int[] lcp = new int[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            dp[i] = 1;
            for (int j = i + 1; j < n; j++) {
                lcp[j] = s.charAt(i) == s.charAt(j)
                    ? lcp[j + 1] + 1 : 0;
                int k = j - i;
                if (j + k <= n && lcp[j] >= k) {
                    dp[i] = Math.max(dp[i], 1 + dp[j]);
                }
            }
        }
        return dp[0];
    }
}

#include <algorithm>
#include <string>
#include <vector>

class Solution {
public:
    int deleteString(string s) {
        int n = static_cast<int>(s.size());
        vector<int> dp(n + 1), lcp(n + 1);
        for (int i = n - 1; i >= 0; --i) {
            dp[i] = 1;
            for (int j = i + 1; j < n; ++j) {

                int k = j - i;
                if (j + k <= n && lcp[j] >= k) {
                    dp[i] = max(dp[i], 1 + dp[j]);
                }
            }
        }
        return dp[0];
    }
};
