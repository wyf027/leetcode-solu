Problem / 题意

把 N 位皇后安全放入棋盘

给定一个 N × N 棋盘，返回所有合法摆法。任意两位皇后不能处在同一行、同一列，也不能处在任意同一条对角线上。

输入与输出

  • 输入整数 n，代表棋盘边长与皇后数量。
  • 每个解由 n 个长度为 n 的字符串组成。
  • "Q" 表示皇后，"." 表示空格。

官方示例（完整参数格式）

输入 n = 4 输出 [[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]

合法性的三条扫描线

  • 同一列：列号 col 相同。
  • 主对角线：row - col 相同。
  • 副对角线：row + col 相同。

可见字符说明

本题输入没有字符串与空格。输出中的棋盘行保留成对直引号；"." 只是空棋格，不代表空格字符，因此无需使用 ␠ 替代。

Recommended / 面试推荐

逐行回溯 + 三组布尔占用表

“每行恰好一个皇后”天然消除了行冲突；剩余三类冲突都能用 O(1) 查询，因此搜索树只保留合法分支。

核心洞察：坐标压缩成通道编号

位置 (row, col) 只需查询 cols[col]、diagA[row-col+n-1] 与 diagB[row+col]。三者都空闲才可落子。

为什么必须撤销

某个分支探索完后，棋盘与三组占用表必须恢复到进入分支前的状态。否则下一列会继承并不存在的皇后，产生错误剪枝。

01

固定当前行

递归参数 row 表示下一位皇后必须放置的行，因此不需要额外记录行占用。

02

从左到右尝试列

依次扫描 col = 0..n-1，跳过任一通道已占用的位置。

03

落子并递归

把棋盘格改成 "Q"，同步占用三条通道，再搜索下一行。

04

记录完整解

当 row === n，复制当前棋盘。必须复制，不能把仍会继续修改的同一对象直接存入答案。

05

撤销并尝试下一列

恢复棋盘与三条通道，这一步把搜索状态送回父节点，继续枚举其他合法摆法。

Boundary / 边界与复杂度

搜索树有多大？

三组占用表让冲突判断降为 O(1)，但答案数量本身仍可能快速增长。

O(n!) 时间上界：逐行选择尚未占用的列，实际会被对角线剪枝显著减少。
O(n²) 工作空间：棋盘占 O(n²)，三组占用表与递归栈占 O(n)；不计输出。
n = 1 唯一解为 [["Q"]]；n = 2、n = 3 均无解。

替代方案

  • 集合 Set：语义直观，但布尔数组常数更小。
  • 位掩码：用位运算压缩列与对角线，适合只求数量或追求极致性能。
  • 全排列后验证：先消除行列冲突，再检查对角线；会枚举大量必然失败的排列。

常见错误

  • 把对角线只理解为棋盘中央的两条。
  • row-col 可能为负，却直接用作数组下标。
  • 回溯时漏掉棋盘或某一组占用表的撤销。
  • 记录答案时没有深拷贝当前棋盘。

面试追问

  • 如果只求解的数量，如何避免构造字符串？
  • 如何用位掩码表示可用列，并取出最低位候选？
  • 能否利用镜像对称减少首行搜索？
  • 为什么逐行策略已经自动保证“每行不冲突”？

回答模板

“我会逐行回溯。每次用列、row-col 与 row+col 三组占用表 O(1) 判断冲突；落子后递归，返回时完整撤销。到达第 n 行时复制棋盘加入答案。”

Code / 可提交代码

四种语言，同一条搜索轨迹

四份实现都按列从左到右枚举，因此输出顺序与页面测试保持一致。 

import java.util.*;

class Solution {
    private final List<List<String>> answer = new ArrayList<>();
    private char[][] board;
    private boolean[] cols;
    private boolean[] diagA;
    private boolean[] diagB;
    private int n;

    public List<List<String>> solveNQueens(int n) {
        this.n = n;
        board = new char[n][n];
        for (char[] row : board) {
            Arrays.fill(row, '.');
        }
        cols = new boolean[n];
        diagA = new boolean[2 * n - 1];
        diagB = new boolean[2 * n - 1];
        dfs(0);
        return answer;
    }

    private void dfs(int row) {
        if (row == n) {
            List<String> solution = new ArrayList<>();
            for (char[] line : board) {
                solution.add(new String(line));
            }
            answer.add(solution);
            return;
        }

        for (int col = 0; col < n; col++) {
            int a = row - col + n - 1;
            int b = row + col;
            if (cols[col] || diagA[a] || diagB[b]) {
                continue;
            }

            board[row][col] = 'Q';
            cols[col] = diagA[a] = diagB[b] = true;
            dfs(row + 1);
            cols[col] = diagA[a] = diagB[b] = false;
            board[row][col] = '.';
        }
    }
}
var solveNQueens = function (n) {
    const answer = [];
    const board = Array.from({ length: n }, () => Array(n).fill("."));
    const cols = Array(n).fill(false);
    const diagA = Array(2 * n - 1).fill(false);
    const diagB = Array(2 * n - 1).fill(false);

    function dfs(row) {
        if (row === n) {
            answer.push(board.map((line) => line.join("")));
            return;
        }

        for (let col = 0; col < n; col++) {
            const a = row - col + n - 1;
            const b = row + col;
            if (cols[col] || diagA[a] || diagB[b]) continue;

            board[row][col] = "Q";
            cols[col] = diagA[a] = diagB[b] = true;
            dfs(row + 1);
            cols[col] = diagA[a] = diagB[b] = false;
            board[row][col] = ".";
        }
    }

    dfs(0);
    return answer;
};

        answer: List[List[str]] = []
        board = [["."] * n for _ in range(n)]
        cols = [False] * n
        diag_a = [False] * (2 * n - 1)
        diag_b = [False] * (2 * n - 1)

        def dfs(row: int) -> None:
            if row == n:
                answer.append(["".join(line) for line in board])
