完全相等的
JSON 对象JSON Deep Equal

给定两个由 JSON.parse 得到的值，判断它们是否在结构与每个对应值上完全相等。对象键的排列顺序不影响结果，数组顺序则必须一致。

01 · Problem

题意与判定规则

函数签名：areDeeplyEqual(o1, o2): boolean

01

基本值

两个值都是基本类型时，仅当它们通过 JavaScript 严格相等比较 === 时，才算完全相等。

02

数组

长度必须相同；同一索引上的元素还要递归地完全相等。因此数组的元素顺序不可交换。

03

对象

键集合必须相同，并且每个键对应的值都递归地完全相等；对象键出现的先后顺序无关。

约束

  • 1 ≤ JSON.stringify(o1).length ≤ 105
  • 1 ≤ JSON.stringify(o2).length ≤ 105
  • maxNestingDepth ≤ 1000
  • o1 与 o2 都是有效 JSON 值，即可以来自 JSON.parse。
  • 不得使用 Lodash 的 _.isEqual()。

JSON 值只涉及对象、数组、字符串、数字、布尔值与 null，无需处理函数、undefined、循环引用、Map 或 Date。

04 · Solution

准备好再揭晓

题解默认收起。建议先在纸上写出对象、数组、基本值三种分支，再展开核对。

Core insight

核心洞察

  • 把 JSON 看成一棵树：对象键与数组索引是边，基本值是叶子。
  • 每次递归先确认两侧属于同一种结构，再比较当前层规模，最后进入对应子节点。
  • 发现类型、键、长度或叶子值不同就立即返回 false，无需继续扫描。

Process

完整过程

1

若引用或基本值严格相等，直接返回 true。

2

若只有一侧是 null、只有一侧不是对象，或数组身份不同，返回 false。

3

数组先比长度，再按索引递归比较全部元素。

4

对象先比键数，再确认每个键存在于另一侧，并递归比较对应值。

Correctness

正确性说明

对 JSON 树高度作归纳。高度为 0 时，节点是基本值，严格相等比较与定义一致。假设算法能正确判断所有更低的子树；对当前数组，算法检查长度并逐个判断同索引子树，因此恰好覆盖数组定义；对当前对象，算法检查相同键集合并判断每个对应子树，因此恰好覆盖对象定义。三种类型互斥，所以算法对任意有效 JSON 值都返回且仅返回正确结果。

Edges & complexity

边界与复杂度

  • null 在 JavaScript 中的 typeof 是 "object"，必须单独处理。
  • 数组也是对象，必须用 Array.isArray 区分 [] 与 {}。
  • 对象键序忽略，数组元素顺序保留；数字 1 与字符串 "1" 不相等。
  • 空数组只与空数组相等，空对象只与空对象相等。
时间O(n)
额外空间O(n)

其中 n 是两棵 JSON 树的节点与键总量。空间包括递归栈和当前对象键数组；递归栈深度为 O(h)。

Alternatives

替代方案

  • 直接 stringify：对象键序不同会产生不同字符串，不能直接使用。
  • 排序键后 stringify：可以构造规范化副本，但多一次遍历、排序与完整字符串分配；本题递归短路更直接。
  • 显式栈：可规避极深数据导致的调用栈限制，代价是代码更长；当运行时递归深度不足时再采用。

/**
 * @param {any} o1
 * @param {any} o2
 * @return {boolean}
 */
var areDeeplyEqual = function (o1, o2) {
  if (o1 === o2) return true;
  if (o1 === null || o2 === null) return false;
  if (typeof o1 !== "object" || typeof o2 !== "object") return false;

  const a1 = Array.isArray(o1);
  const a2 = Array.isArray(o2);
  if (a1 !== a2) return false;

  if (a1) {
    if (o1.length !== o2.length) return false;
    return o1.every((value, i) => areDeeplyEqual(value, o2[i]));
  }

  const keys1 = Object.keys(o1);
  const keys2 = Object.keys(o2);
  if (keys1.length !== keys2.length) return false;

  return keys1.every(
    key => Object.prototype.hasOwnProperty.call(o2, key)
      && areDeeplyEqual(o1[key], o2[key])
  );
};
import java.math.BigDecimal;
import java.util.List;
import java.util.Map;

// 本地语义参考：JSON 数字建议由解析器统一读取为 BigDecimal。
class Solution {
    public static boolean areDeeplyEqual(Object o1, Object o2) {
        if (o1 == o2) return true;
        if (o1 == null || o2 == null) return false;

        if (o1 instanceof BigDecimal a && o2 instanceof BigDecimal b) {
            return a.compareTo(b) == 0;
        }
        if (o1 instanceof String || o1 instanceof Boolean) {
            return o1.getClass() == o2.getClass() && o1.equals(o2);
        }

        if (o1 instanceof List<?> a && o2 instanceof List<?> b) {
            if (a.size() != b.size()) return false;
            for (int i = 0; i < a.size(); i++) {
                if (!areDeeplyEqual(a.get(i), b.get(i))) return false;
            }
            return true;
        }

        if (o1 instanceof Map<?, ?> a && o2 instanceof Map<?, ?> b) {
            if (a.size() != b.size()) return false;
            for (Map.Entry<?, ?> entry : a.entrySet()) {
                Object key = entry.getKey();
                if (!b.containsKey(key)
                        || !areDeeplyEqual(entry.getValue(), b.get(key))) {
                    return false;
                }
            }
            return true;
        }

        return false;
    }
}
from typing import Any


# 本地语义参考：兼容 Python json.loads 产生的 int / float。
def are_deeply_equal(o1: Any, o2: Any) -> bool:
    number1 = isinstance(o1, (int, float)) and not isinstance(o1, bool)
    number2 = isinstance(o2, (int, float)) and not isinstance(o2, bool)
    if number1 or number2:
        return number1 and number2 and o1 == o2

    if type(o1) is not type(o2):
        return False
    if isinstance(o1, list):
        return len(o1) == len(o2) and all(
            are_deeply_equal(a, b) for a, b in zip(o1, o2)
        )
    if isinstance(o1, dict):
        return o1.keys() == o2.keys() and all(
            are_deeply_equal(o1[key], o2[key]) for key in o1
        )
    return o1 == o2
#include <nlohmann/json.hpp>

using json = nlohmann::json;

// 本地语义参考：使用 nlohmann/json 表示任意 JSON 值。
bool areDeeplyEqual(const json& o1, const json& o2) {
    if (o1.is_number() || o2.is_number()) {
        return o1.is_number() && o2.is_number()
            && o1.get<double>() == o2.get<double>();
    }
    if (o1.type() != o2.type()) return false;

    if (o1.is_array()) {
        if (o1.size() != o2.size()) return false;
        for (std::size_t i = 0; i < o1.size(); ++i) {
            if (!areDeeplyEqual(o1[i], o2[i])) return false;
        }
        return true;
    }

    if (o1.is_object()) {
        if (o1.size() != o2.size()) return false;
        for (auto it = o1.begin(); it != o1.end(); ++it) {
            if (!o2.contains(it.key())
                    || !areDeeplyEqual(it.value(), o2.at(it.key()))) {
                return false;
            }
        }
        return true;
    }

    return o1 == o2;
}

Common mistakes

常见错误

  • 只比较对象键数量，却没检查键名是否真的相同。
  • 把 null 当普通对象继续读取键。
  • 把数组当对象，导致忽略了数组与普通对象的类型差异。
  • 对对象直接 JSON.stringify，错误地把键序算作差异。
  • 使用宽松相等 ==，让 1 与 "1" 混为一谈。

Takeaway

一句话记忆

先比类型与当前层规模，再沿相同键或索引递归；第一处差异就是答案。
