LCR 098 · MEDIUM · 动态规划

不同路径

机器人只能向右或向下移动。计算从网格左上角走到右下角一共有多少种路线。

交互演示

题意

给定 m 行、n 列网格，机器人从 (0,0) 到 (m-1,n-1)，每步只能下或右，返回路径数。

约束

m、n 为正整数；答案保证在 32 位有符号整数范围。

示例

m=3, n=7 → 28

首行与首列只有一条路线；其余格子的路线数来自上方与左方之和。

分步交互：填充 DP 表

核心洞察与过程

到达格子 (i,j) 的最后一步不是从上方来，就是从左方来，因此 dp[i][j]=dp[i-1][j]+dp[i][j-1]。先将首行首列初始化为 1，然后逐行填表。用一维数组时，dp[j] 是上方，dp[j-1] 是左方。

边界、复杂度与替代方案

单行或单列答案为 1。二维 DP 时间 O(mn)、空间 O(mn)，一维优化空间 O(n)。也可使用组合数 C(m+n-2,m-1)，但要注意中间乘积溢出。

追问与常见错误

有障碍物时将障碍格设为 0；常见错误是忘记初始化首行首列，或把可达路径误当成最短路径。

官方签名代码

// Java
class Solution { public int uniquePaths(int m,int n){int[] d=new int[n];Arrays.fill(d,1);for(int i=1;i<m;i++)for(int j=1;j<n;j++)d[j]+=d[j-1];return d[n-1];} }
// JavaScript
var uniquePaths=function(m,n){const d=Array(n).fill(1);for(let i=1;i<m;i++)for(let j=1;j<n;j++)d[j]+=d[j-1];return d[n-1];};
# Python
class Solution:
 def uniquePaths(self,m:int,n:int)->int:
  d=[1]*n
  for _ in range(1,m):
   for j in range(1,n): d[j]+=d[j-1]
  return d[-1]
// C++
class Solution { public: int uniquePaths(int m,int n){vector<int> d(n,1);for(int i=1;i<m;i++)for(int j=1;j<n;j++)d[j]+=d[j-1];return d.back();} };
