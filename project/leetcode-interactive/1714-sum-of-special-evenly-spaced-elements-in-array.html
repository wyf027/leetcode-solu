数组中特殊等间距元素的和Sum Of Special Evenly-Spaced Elements In Array

从起点出发，按固定步长跨过数组。单次查询并不难，真正的挑战是：当查询多达 15 万次时，怎样不把同样的路反复走完？

0-indexed取模 1,000,000,007n ≤ 50,000queries ≤ 150,000

Problem

先把查询说清楚

以下内容依据本题官方元数据与公开题目信息转述；不复刻付费题面原文。

给定一个长度为 n 的非负整数数组 nums，以及若干查询 queries。每个查询是完整参数对 [x, y]：从下标 x 开始，每次向右移动 y 个位置，把仍在数组范围内的元素相加。

answer(x, y) = nums[x] + nums[x+y] + nums[x+2y] + …，仅保留下标小于 n 的项

对每个查询分别得到一个和，并对 1,000,000,007 取模。返回值顺序必须与查询顺序一致。

  • 输入：solve(int[] nums, int[][] queries)
  • 输出：int[]，其中第 i 项对应 queries[i]
  • 命中条件：x ≤ j < n 且 (j - x) % y == 0

约束

  • n == nums.length
  • 1 ≤ n ≤ 5 × 10⁴
  • 0 ≤ nums[i] ≤ 10⁹
  • 1 ≤ queries.length ≤ 1.5 × 10⁵
  • 0 ≤ xᵢ < n
  • 1 ≤ yᵢ ≤ 5 × 10⁴

示例 1

输入nums = [0,1,2,3,4,5,6,7] queries = [[0,3],[5,1],[4,2]]
输出[9,18,10]
解释依次访问下标 0→3→6、5→6→7、4→6。

示例 2

输入nums = [100,200,101,201,102,202,103,203] queries = [[0,7]]
输出[303]
解释查询 [0,7] 命中下标 0 与 7，即 100 + 203。

Sqrt decomposition

小步长预处理，大步长直接走

关键不在于把某一次查询做得神奇，而在于利用“步长越小，轨迹越长；步长越大，轨迹越短”的互补关系，把总工作量压到平方根级别。

核心洞察

1

设分界 B ≈ √n

当 y ≥ B，每条轨迹最多经过约 n/B 个元素，直接累加足够快。

2

复用小步长

当 y < B，同一个步长会形成大量重叠后缀。为该 y 计算一次动态规划，即可 O(1) 回答所有同步长查询。

3

按步长离线分组

只为实际出现的小步长建表；答完该组便释放数组，将额外空间从 O(n√n) 降为 O(n + q)。

完整过程

  1. 令 MOD = 1,000,000,007，B = floor(√n) + 1。
  2. 扫描查询。若 y ≥ B，沿 x, x+y, ... 直接求和并取模。
  3. 若 y < B，把查询编号放进按 y 分组的桶中。
  4. 对每个非空的小步长桶，从右向左计算一维数组 dp：
dp[i] = (nums[i] + (i + y < n ? dp[i + y] : 0)) mod MOD

于是查询 [x,y] 的答案就是 dp[x]。处理完这个 y 后，一维 dp 可复用给下一个步长。

正确性证明

引理 1：固定小步长 y 时，dp[i] 等于从 i 开始、间隔 y 的所有合法元素之和（模 MOD）。

从右向左归纳。若 i+y ≥ n，轨迹只有 nums[i]，公式成立；否则轨迹由首项 nums[i] 与从 i+y 开始的轨迹组成。后者按归纳假设等于 dp[i+y]，故递推式成立。

引理 2：大步长分支枚举的下标集合恰好是查询要求的集合。循环从 x 开始，每次加 y，因此所有枚举下标满足条件；任意满足条件的下标都可写成 x+ky，故不会漏掉。

结论：每个查询要么由引理 1 的 dp[x] 回答，要么由引理 2 的直接枚举回答，两类覆盖全部合法步长，所以算法返回的每项均正确。

复杂度

  • 小步长：至多 B-1 组，每组 O(n)，合计 O(nB)。
  • 大步长：每次 O(n/B)，合计 O(qn/B)。
  • 取 B≈√n：总时间 O((n+q)√n)。
  • 分组、答案与复用的 dp：空间 O(n+q)。

边界处理

  • x 本身始终合法，答案不会来自空集合。
  • y ≥ n 时只访问 nums[x]。
  • nums[i] 可为 0；不能用数值真假判断是否访问。
  • 每次加法及时取模；Java/C++ 使用 64 位中间值。

替代方案

  • 每次暴力：O(Σ n/y)，当大量查询的 y=1 时会超时。
  • 保存所有小步长表：查询简单，但空间 O(n√n)；本题可用，离线分组更节省。
  • 按需记忆化：仅缓存出现过的 (x,y)；重复完全相同查询时有利，却无法充分复用不同起点的同一步长。

面试追问

  1. 为什么最优分界在 √n 附近？令两部分的量级平衡即可。
  2. 若查询在线到达怎么办？可保留所有小步长 DP 表，换取 O(1) 小步长响应。
  3. 若数组会更新怎么办？静态 DP 失效；可讨论按步长维护结构、分块重建或时间维度批处理。
  4. 如果内存很宽裕，怎样用空间换常数？一次性建立 dp[y][i]。

常见错误

  • 把题目误读为连续区间求和，忽略了固定步长。
  • 只按 y 的奇偶或余数分类，却没有建立“从起点到结尾”的后缀关系。
  • 阈值分支写成不一致的 < B / ≤ B，导致遗漏或数组越界。
  • 在 JavaScript 中先累积极大总和、最后才取模；应在循环中取模，避免超过安全整数范围。
  • 预处理完一个小步长后复用同一数组却未完全从右向左覆盖。

四语言完整代码

四份实现均采用“查询分组 + 单个 DP 数组复用”的同一算法，函数名与官方元数据中的 solve 保持一致。

JavaLeetCode 提交形式
import java.util.*;

class Solution {
    private static final int MOD = 1_000_000_007;

    public int[] solve(int[] nums, int[][] queries) {
        int n = nums.length;
        int block = (int) Math.sqrt(n) + 1;
        int[] answer = new int[queries.length];

        List<List<Integer>> groups = new ArrayList<>(block);
        for (int y = 0; y < block; y++) groups.add(new ArrayList<>());

        for (int qi = 0; qi < queries.length; qi++) {
            int x = queries[qi][0], y = queries[qi][1];
            if (y < block) {
                groups.get(y).add(qi);
            } else {
                long sum = 0;
                for (int i = x; i < n; i += y) sum = (sum + nums[i]) % MOD;
                answer[qi] = (int) sum;
            }
        }

        int[] dp = new int[n];
        for (int y = 1; y < block; y++) {
            if (groups.get(y).isEmpty()) continue;
            for (int i = n - 1; i >= 0; i--) {
                long value = nums[i];
                if (i + y < n) value += dp[i + y];
                dp[i] = (int) (value % MOD);
            }
            for (int qi : groups.get(y)) answer[qi] = dp[queries[qi][0]];
        }
        return answer;
    }
}
JavaScriptLeetCode 提交形式
/**
 * @param {number[]} nums
 * @param {number[][]} queries
 * @return {number[]}
 */
var solve = function(nums, queries) {
    const MOD = 1_000_000_007;
    const n = nums.length;
    const block = Math.floor(Math.sqrt(n)) + 1;
    const answer = new Array(queries.length).fill(0);
    const groups = Array.from({ length: block }, () => []);

    for (let qi = 0; qi < queries.length; qi++) {
        const [x, y] = queries[qi];
        if (y < block) {
            groups[y].push(qi);
        } else {
            let sum = 0;
            for (let i = x; i < n; i += y) sum = (sum + nums[i]) % MOD;
            answer[qi] = sum;
        }
    }

    const dp = new Uint32Array(n);
    for (let y = 1; y < block; y++) {
        if (groups[y].length === 0) continue;
        for (let i = n - 1; i >= 0; i--) {
            let value = nums[i];
            if (i + y < n) value += dp[i + y];
            dp[i] = value % MOD;
        }
        for (const qi of groups[y]) answer[qi] = dp[queries[qi][0]];
    }
    return answer;
};
Python 3LeetCode 提交形式
from math import isqrt
from typing import List

class Solution:
    def solve(self, nums: List[int], queries: List[List[int]]) -> List[int]:
        MOD = 1_000_000_007
        n = len(nums)
        block = isqrt(n) + 1
        answer = [0] * len(queries)
        groups = [[] for _ in range(block)]

        for qi, (x, y) in enumerate(queries):
            if y < block:
                groups[y].append(qi)
            else:
                total = 0
                for i in range(x, n, y):
                    total = (total + nums[i]) % MOD
                answer[qi] = total

        dp = [0] * n
        for y in range(1, block):
            if not groups[y]:
                continue
            for i in range(n - 1, -1, -1):
                dp[i] = (nums[i] + (dp[i + y] if i + y < n else 0)) % MOD
            for qi in groups[y]:
                answer[qi] = dp[queries[qi][0]]

        return answer

class Solution {
public:
    vector<int> solve(vector<int>& nums, vector<vector<int>>& queries) {
        const int MOD = 1'000'000'007;
        int n = nums.size();
        int block = static_cast<int>(sqrt(n)) + 1;
        vector<int> answer(queries.size());
        vector<vector<int>> groups(block);

        for (int qi = 0; qi < (int)queries.size(); ++qi) {
            int x = queries[qi][0], y = queries[qi][1];
            if (y < block) {
                groups[y].push_back(qi);
            } else {
                long long sum = 0;
                for (int i = x; i < n; i += y) sum = (sum + nums[i]) % MOD;
                answer[qi] = static_cast<int>(sum);
            }
        }

        vector<int> dp(n);
        for (int y = 1; y < block; ++y) {
            if (groups[y].empty()) continue;
            for (int i = n - 1; i >= 0; --i) {
                long long value = nums[i];
                if (i + y < n) value += dp[i + y];
                dp[i] = static_cast<int>(value % MOD);
            }
            for (int qi : groups[y]) answer[qi] = dp[queries[qi][0]];
        }
        return answer;
    }
};
