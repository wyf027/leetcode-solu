LCR 093 · MEDIUM

最长的斐波那契子序列的长度

严格递增数组中，寻找最长的斐波那契式子序列长度：从第三项起，每一项等于前两项之和；不存在则返回 0。

开始推演

首屏只展示问题；题解默认隐藏。

题意

子序列不要求连续，但必须保持原数组的相对顺序。因数组严格递增，可用值快速定位某个和是否存在。

示例 1

输入：arr = [1,2,3,4,5,6,7,8]
输出：5
解释：[1,2,3,5,8]

示例 2

输入：arr = [1,3,7,11,12,14,18]
输出：3
解释：[1,11,12]、[3,11,14] 或 [7,11,18]

约束

  • 3 <= arr.length <= 1000
  • 1 <= arr[i] < arr[i + 1] <= 10⁹

先想一想

  1. 1固定结尾两项时，上一项应该是什么？
  2. 2如何避免为每个候选值线性查找下标？
  3. 3为什么长度不足 3 时要返回 0？

INTERACTIVE WALKTHROUGH

分步推演：[1, 2, 3, 5, 8]

第 1 / 3 步

1+2=3→5→8

选择结尾对 (2, 3)，计算前驱 3 - 2 = 1

第 1 步：状态定义

令 dp[i][j] 表示以 arr[i]、arr[j] 结尾的最长斐波那契式子序列长度，初始为 2。

第 2 步：寻找前驱

固定 i < j，所需前驱值为 arr[j] - arr[i]。通过哈希表取得其下标 k，且 k 必须小于 i。

第 3 步：转移并记录答案

存在 k 时，dp[i][j] = dp[k][i] + 1。最终只有长度至少 3 的序列才有效。

SOLUTION

哈希表 + 二维动态规划

洞察与过程

对每个结尾对 (i, j)，唯一的前驱值是 arr[j] - arr[i]。值到下标的映射把查找降为 O(1)，从而可完成二维状态转移。

边界与复杂度

只有 k < i 且前驱值存在才可延长。时间 O(n²)，空间 O(n²)；若最大长度小于 3，返回 0。

替代与追问

可用二分查找替代哈希表，但会变为 O(n² log n)。追问：若数组不再严格递增，值到唯一下标的假设失效，需要保留多个位置。

常见错误

  • 未检查前驱下标 k < i。
  • 把默认长度 2 误当成有效结果。
  • 使用 arr[i] - arr[j]，导致前驱方向颠倒。

四语言代码

class Solution { public int lenLongestFibSubseq(int[] arr) { int n=arr.length, ans=0; Map<Integer,Integer> pos=new HashMap<>(); int[][] dp=new int[n][n]; for(int i=0;i<n;i++) pos.put(arr[i],i); for(int i=0;i<n;i++) for(int j=i+1;j<n;j++){ int k=pos.getOrDefault(arr[j]-arr[i],-1); dp[i][j]=(k>=0&&k<i)?dp[k][i]+1:2; ans=Math.max(ans,dp[i][j]); } return ans>=3?ans:0; } }
var lenLongestFibSubseq = function(arr) { const pos=new Map(arr.map((v,i)=>[v,i])), dp=Array.from({length:arr.length},()=>Array(arr.length).fill(2)); let ans=0; for(let i=0;i<arr.length;i++) for(let j=i+1;j<arr.length;j++){ const k=pos.get(arr[j]-arr[i]); if(k!==undefined&&k<i) dp[i][j]=dp[k][i]+1; ans=Math.max(ans,dp[i][j]); } return ans>=3?ans:0; };
class Solution:
    def lenLongestFibSubseq(self, arr: List[int]) -> int:
        pos = {x:i for i,x in enumerate(arr)}; dp = [[2]*len(arr) for _ in arr]; ans = 0
        for i in range(len(arr)):
            for j in range(i+1, len(arr)):
                k = pos.get(arr[j]-arr[i], -1)
                if k < i: dp[i][j] = dp[k][i] + 1
                ans = max(ans, dp[i][j])
        return ans if ans >= 3 else 0
class Solution { public: int lenLongestFibSubseq(vector<int>& a) { int n=a.size(), ans=0; unordered_map<int,int> p; vector dp(n, vector<int>(n,2)); for(int i=0;i<n;i++)p[a[i]]=i; for(int i=0;i<n;i++)for(int j=i+1;j<n;j++){int k=p.count(a[j]-a[i])?p[a[j]-a[i]]:-1; if(k>=0&&k<i)dp[i][j]=dp[k][i]+1; ans=max(ans,dp[i][j]);} return ans>=3?ans:0;} };
