01 / 题目

给定正整数数组 nums。对原数组中的每个数，把十进制数位顺序倒过来，将得到的整数追加到数组末尾。追加的数不再参与本轮操作。返回最终数组中不同整数的数量。

反转按整数解释：例如 120 → 021 → 21，前导零不保留。

官方示例 1

输入：nums = [1,13,10,12,31]
输出：6

追加 [1,31,1,21,13] 后得到 [1,13,10,12,31,1,31,1,21,13]，不同整数是 1、10、12、13、21、31。

官方示例 2

输入：nums = [2,2,2]
输出：1

追加 [2,2,2] 后得到 [2,2,2,2,2,2]，不同整数只有 2。

约束与接口

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁶
  • 参数：整数数组 nums；返回值：整数。

04 / 独立题解

准备好后再展开，包含推导与四语言实现。

核心洞察：保留值，而不是出现次数

答案是原数集合与反转数集合的并集大小：|{x : x ∈ nums} ∪ {reverse(x) : x ∈ nums}|。把每个原数和它的反转数都放入哈希集合，集合会自动消除重复，无需真的扩充数组。

完整过程

  1. 建立空集合 seen，只遍历原数组。
  2. 先将当前原数加入 seen，再令工作副本 x 等于原数、rev = 0。
  3. 只要 x > 0，执行 digit = x % 10，rev = rev × 10 + digit，x = ⌊x / 10⌋。
  4. x 变为 0 后，将 rev 放入 seen；处理下一个原数。
  5. 返回 seen 的元素个数。

例如 120：先取 0，rev = 0；再取 2，rev = 2；最后取 1，rev = 21。示例 1 中，(1,1)、(13,31)、(10,1)、(12,21)、(31,13) 依次加入集合，大小依次为 1、3、4、6、6。演示台也按这一顺序收集。

正确性

反转循环：每轮删除 x 的末位，并将该位追加到 rev 右侧。因此处理 k 位后，rev 恰好是原数最后 k 位按相反顺序组成的整数；终止时所有数位都已处理，rev 就是正确的反转值。

集合不变量：处理完前 i 个原数后，seen 恰好包含这 i 个原数及其反转值。初始空集合满足条件；每轮只加入下一原数和正确的反转值，保持不变量。全部处理后，seen 等于最终数组的不同值集合，其大小即答案。

边界与数值安全

  • 单数位、回文数反转后不变，只保留一次。
  • 尾零丢失是整数语义，例如 100 → 1，不把 "001" 当作不同值。
  • 多个原数可能反转成同一个数，或反转成原数组已有的数。
  • 输入最大为 10⁶；10⁶ 的反转为 1，其余最多六位，所以反转结果也在 32 位有符号整数范围内。
  • 结果介于原数组不同值数量与 2n 之间。题目保证数组非空且元素为正数。

复杂度

令 n 为数组长度，D 为最大十进制位数。每个数字最多拆 D 位，哈希集合插入平均 O(1)，总平均时间 O(nD)，也可写作 O(n log M)，其中 M ≥ 2 表示数值上界。本题 D ≤ 7，可视为 O(n)。集合最多保存 2n 个整数，额外空间 O(n)；单个反转过程 O(1)。此时间结论基于通常的哈希平均性能。

替代方案

  • 字符串反转：转字符串、倒序、再转整数，较直观；时间仍为 O(nD)，每次转换产生 O(D) 临时空间。
  • 排序去重：保存原数与反转数共 2n 项，排序后数相邻变化，时间 O(nD + n log n)，额外保存数组 O(n)。
  • 布尔标记表：利用本题数值上界，以值作下标标记；时间 O(nD + M)，空间 O(M)，适合值域小且固定的场景。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int countDistinctIntegers(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int num : nums) {
            seen.add(num);
            int x = num, rev = 0;
            while (x > 0) {
                rev = rev * 10 + x % 10;
                x /= 10;
            }
            seen.add(rev);
        }
        return seen.size();
    }
}

var countDistinctIntegers = function(nums) {
    const seen = new Set();
    for (const num of nums) {
        seen.add(num);
        let x = num, rev = 0;
        while (x > 0) {
            rev = rev * 10 + x % 10;
            x = Math.floor(x / 10);
        }
        seen.add(rev);
    }
    return seen.size;
};

from typing import List

class Solution:
    def countDistinctIntegers(self, nums: List[int]) -> int:
        seen = set()
        for num in nums:
            seen.add(num)
            x, rev = num, 0
            while x > 0:
                rev = rev * 10 + x % 10
                x //= 10
            seen.add(rev)
        return len(seen)

#include <vector>

class Solution {
public:
    int countDistinctIntegers(vector<int>& nums) {
        unordered_set<int> seen;
        for (int num : nums) {
            seen.insert(num);
            int x = num, rev = 0;
            while (x > 0) {
                rev = rev * 10 + x % 10;
                x /= 10;
            }
            seen.insert(rev);
        }
        return static_cast<int>(seen.size());
    }
};

常见错误

  • 只收集反转值，漏掉原数；例如 [10] 的答案是 2。
  • 认为答案恒为 2n，忽略重复、回文和相互反转。
  • 把反转字符串直接作为集合键，使 "01" 与整数 1 无法合并。
  • JavaScript 除以 10 未向下取整，或 Python 用 / 产生浮点数。
  • 边遍历边向同一数组追加，导致处理范围扩大。保留原数组，只维护集合。

面试追问

流式输入怎么办？每读到一个数就插入原值和反转值，最后返回集合大小，不必保存整条输入流。

允许任意大整数怎么办？采用大整数或规范化十进制字符串，并重新计算位数相关时间与空间成本。

再次反转一定还原吗？不一定，10 → 1 → 1；尾零信息丢失。题目只要求操作原数一次，不能擅自改成反复处理追加元素。
