Problem

题意

给定 schedule，其中 schedule[i] 是第 i 位员工的一组工作区间。每位员工的区间已经按起点排序，且彼此不重叠。请返回所有员工都没有工作的、长度为正且边界有限的公共空闲区间，并按时间递增排列。

参数形式：schedule: List<List<Interval>>，其中 Interval 含整数属性 start 与 end；返回 List<Interval>。区间对象在题目平台中不是普通二维数组。

示例 1

输入：schedule = [[[1,2],[5,6]],[[1,3]],[[4,10]]]
输出：[[3,4]]

三位员工在 [3,4] 都未工作；两端向无穷延伸的区域不计入答案。

示例 2

输入：schedule = [[[1,3],[6,7]],[[2,4]],[[2,5],[9,12]]]
输出：[[5,6],[7,9]]

输出只包含有限、严格正长度的共同空档。

员工数 / 每人区间数
1 ≤ schedule.length, schedule[i].length ≤ 50
区间边界
0 ≤ start < end ≤ 108
输入保证
每位员工的区间有序且不重叠

Full solution

排序后合并所有工作区间

核心洞察：不必逐人求空闲时间。把所有人的工作区间放到同一条时间轴，按起点排序并维护此前工作的最远终点；若下一个起点严格大于该终点，中间便没有任何工作区间覆盖，正是全员共同空闲时间。

完整过程

  1. 扁平化 schedule，收集总计 N 个工作区间。
  2. 按 start 升序排序；起点相同的先后不影响结论。
  3. 令 prevEnd 为第一个区间的终点。依次读取后续区间 [start,end]。
  4. 若 start > prevEnd，记录空档 [prevEnd,start]；随后令 prevEnd = end。
  5. 否则区间相交或相接，将 prevEnd 更新为 max(prevEnd,end)。

正确性证明

不变式：处理完排序后的前 k 个区间后，prevEnd 是与当前合并块连通的所有已处理区间的最远终点，答案恰含该块之前所有有限的未覆盖空档。

保持：下一区间若从 prevEnd 之前或恰好开始，它与当前块相交或相接，取较大终点即可；若从其后开始，由排序可知没有尚未处理的区间会更早开始，因此 (prevEnd,start) 无任何工作覆盖，且边界长度为正，必须加入答案。

终止：全部区间处理完后，所有相邻合并块间的空档均已且仅已记录；第一块之前和最后一块之后的无限区域从未加入，故返回值正是题目所求。

边界与复杂度

  • 区间相接时 start == prevEnd，空档长度为零，不加入。
  • 某区间被当前合并块完全包含时，不能让 prevEnd 变小。
  • 只有一段连续覆盖时，返回空数组。
  • 忽略最左和最右的无限空闲区域。

时间：O(N log N)，排序占主导。

空间：O(N) 用于扁平数组与排序（不计返回值；具体语言的排序栈可能不同）。

替代方案

最小堆多路归并：每位员工的区间本来就有序，可把每人的首区间放进按起点排序的最小堆；每弹出一个区间，再压入同一员工的下一个区间。时间仍为 O(N log K)，辅助空间 O(K)，其中 K 是员工数。它避免一次性扁平化，适合流式或总区间很多的场景，但实现更复杂。

面试追问

  • 为什么是严格大于？因为题目只接受正长度空闲区间，相接点不构成区间。
  • 如果输入无序或同一员工区间重叠？全局排序合并方案仍然有效，只要区间端点合法。
  • 怎样降低额外空间？利用每位员工已有序的性质做最小堆多路归并。
  • 若要求至少 M 位员工空闲？改用带开闭事件的扫描线，维护某时刻的在岗人数，并注意同坐标事件顺序。

常见错误

  • 只比较相邻原始区间的终点，遗漏被更早长区间覆盖的情况；必须维护最远终点。
  • 用 >= 判断空档，把零长度的接触点错误加入答案。
  • 对每位员工先取空闲区间，却忘记无穷边界和多集合求交，徒增复杂度。
  • 返回二维数字数组而不是平台要求的 Interval 对象。

Java

/*
// Definition for an Interval.
class Interval {
    public int start;
    public int end;
    public Interval() {}
    public Interval(int start, int end) {
        this.start = start;
        this.end = end;
    }
}
*/
class Solution {
    public List<Interval> employeeFreeTime(
            List<List<Interval>> schedule) {
        List<Interval> intervals = new ArrayList<>();
        for (List<Interval> employee : schedule) {
            intervals.addAll(employee);
        }

        intervals.sort(Comparator.comparingInt(a -> a.start));
        List<Interval> answer = new ArrayList<>();
        int prevEnd = intervals.get(0).end;

        for (int i = 1; i < intervals.size(); i++) {
            Interval current = intervals.get(i);
            if (current.start > prevEnd) {
                answer.add(new Interval(prevEnd, current.start));
                prevEnd = current.end;
            } else {
                prevEnd = Math.max(prevEnd, current.end);
            }
        }
        return answer;
    }
}

JavaScript

/**
 * // Definition for an Interval.
 * function Interval(start, end) {
 *   this.start = start;
 *   this.end = end;
 * }
 *
 * @param {Interval[][]} schedule
 * @return {Interval[]}
 */
var employeeFreeTime = function (schedule) {
  const intervals = [];
  for (const employee of schedule) {
    for (const interval of employee) {
      intervals.push(interval);
    }
  }

  intervals.sort((a, b) => a.start - b.start);
  const answer = [];
  let prevEnd = intervals[0].end;

  for (let i = 1; i < intervals.length; i += 1) {
    const current = intervals[i];
    if (current.start > prevEnd) {
      answer.push(new Interval(prevEnd, current.start));
      prevEnd = current.end;
    } else {
      prevEnd = Math.max(prevEnd, current.end);
    }
  }
  return answer;
};

C++

/*
// Definition for an Interval.
class Interval {
public:
    int start;
    int end;
    Interval() {}
    Interval(int _start, int _end)
        : start(_start), end(_end) {}
};
*/
class Solution {
public:
    vector<Interval> employeeFreeTime(
        vector<vector<Interval>> schedule
    ) {
        vector<Interval> intervals;
        for (const auto& employee : schedule) {
            intervals.insert(
                intervals.end(), employee.begin(), employee.end()
            );
        }

        sort(intervals.begin(), intervals.end(),
             [](const Interval& a, const Interval& b) {
                 return a.start < b.start;
             });

        vector<Interval> answer;
        int prevEnd = intervals.front().end;
        for (size_t i = 1; i < intervals.size(); ++i) {
            const Interval& current = intervals[i];
            if (current.start > prevEnd) {
                answer.emplace_back(prevEnd, current.start);
                prevEnd = current.end;
            } else {
                prevEnd = max(prevEnd, current.end);
            }
        }
        return answer;
    }
};
