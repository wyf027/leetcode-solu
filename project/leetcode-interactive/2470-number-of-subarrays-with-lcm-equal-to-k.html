题目与示例

给定整数数组 nums 和整数 k，返回有多少个连续、非空子数组，其所有元素的最小公倍数等于 k。最小公倍数是能被这些元素分别整除的最小正整数。不同起止位置分别计数。

官方示例 1

输入：nums = [3,6,2,7,1], k = 6
输出：4

符合条件的区间（下标从 0 开始）：[0,1] → [3,6]、[0,2] → [3,6,2]、[1,1] → [6]、[1,2] → [6,2]。

官方示例 2

输入：nums = [3], k = 2
输出：0

唯一的非空子数组 [3] 的最小公倍数为 3，因此没有符合条件的区间。

约束：1 ≤ nums.length ≤ 1000；1 ≤ nums[i], k ≤ 1000。

参数：subarrayLCM(nums, k)，返回整数计数。

04 / SOLUTION

独立题解

准备好后，展开推导与四语言代码。

枚举左端点，向右合并 LCM

核心洞察：固定左端点 i，维护 L = lcm(nums[i..j])。新元素加入时只需要更新 L = L / gcd(L, nums[j]) × nums[j]，无须重新扫描整个区间。以 1 初始化，因为 lcm(1, x) = x。

随着区间扩张，新 LCM 一定是旧 LCM 的倍数。若 k % L ≠ 0，以后也不可能得到 k，可以直接结束这一左端点的枚举。这个判断比仅判断 L > k 更强：例如 L=4、k=6，虽然 4<6，但 4 无法整除 6。

完整过程

  1. 答案初始化为 0；依次选择 i=0…n−1。
  2. 每个 i 开始时令 L=1，然后枚举 j=i…n−1。
  3. 用欧几里得算法求 gcd，再计算新的 LCM，先除后乘。
  4. 若 k 不能被 L 整除，break；否则若 L=k，答案加 1。
  5. 命中后继续扩展，可能还有有效区间；最后返回总数。

示例 1：i=0 时 L 依次为 3、6、6、42，计数两次，在 42 处停止；i=1 时为 6、6、42，再计数两次；i=2 时为 2、14，不计数；i=3 时为 7，立即停止；i=4 时为 1，不计数。总计 4。

正确性证明

不变式：每次更新后，L 恰好是区间 [i,j] 的最小公倍数。初始 L=1，加入 nums[i] 后成立；若对上一区间成立，LCM 的结合律保证合并 nums[j] 后仍成立。

剪枝安全：若当前 L 不能整除 k，而某个更长区间的 LCM 恰为 k，则该更长区间的公倍数 k 必须也是当前所有元素的公倍数，因此当前 L 必须整除 k，矛盾。

完整且不重复：每个非空子数组由唯一的 (i,j) 标识。未被剪枝的区间逐一判断，且仅在 L=k 时计数；被剪枝的区间不可能有效。因此算法恰好统计全部有效子数组。

边界与数值范围

  • 单元素区间也参与计算；空区间不计数。
  • k=1 时，仅由连续的 1 构成的区间有效；长度 m 的连续段贡献 m(m+1)/2。
  • 当 L=k 时不能停止：后续元素若整除 k，LCM 仍等于 k。
  • 每次继续迭代前 L 都整除 k，所以 L≤1000；下一次计算最多到 10⁶，随即检查剪枝。四份代码在本题范围内均可安全表示，Java / C++ 另以 64 位中间变量计算。
  • 最大答案为 1000×1001/2=500500，32 位有符号整数足够。

复杂度

设 n 为数组长度，M=max(k, max(nums))。最多枚举 n(n+1)/2 个区间，每次 gcd 用 O(log M) 时间，故最坏时间 O(n² log M)，额外空间 O(1)。演示保存帧用于回退，额外空间不属于提交算法。

替代方案与取舍

直接枚举每个区间再重算 LCM 需要 O(n³ log M)。本题 n≤1000，增量枚举已经足够。更大 n 可按右端点维护“不同 LCM → 区间数”的映射，合并相同状态并丢弃不能整除 k 的状态；若活跃状态数为 D，复杂度为 O(nD log M)、空间 O(D)。所有保留状态都是 k 的因子，故 D 不超过 k 的因子个数。

常见错误

  • 把子数组当成任意子序列，跳过了中间元素。
  • 用乘积替代 LCM，重复质因子会被多算。
  • 命中 k 后立刻 break，漏掉继续扩展仍等于 k 的区间。
  • 写成 L % k 而非 k % L，剪枝方向相反。
  • 每次换左端点时忘记把 L 重置为 1。
  • 不剪枝而不断累乘，在超出本题受控范围后溢出。

面试追问

为什么常规滑动窗口不直接适用？加入元素后 LCM 可增大，但移除元素时不能仅凭当前 LCM 逆推出剩余 LCM；要额外维护质因子指数及频数。固定左端点枚举更直接。

如果 n 达到 10⁵？改用上述按右端点压缩的 LCM 计数映射。若允许 0 或负数？必须先重新约定 LCM 语义并处理 0，当前实现仅适用于题目给定的正整数。

Java

class Solution {
    private long gcd(long a, long b) {
        while (b != 0) {
            long t = a % b;
            a = b;
            b = t;
        }
        return a;
    }

    public int subarrayLCM(int[] nums, int k) {
        int answer = 0;
        // ponytail: quadratic enumeration for n <= 1000; compress LCM states for larger n.
        for (int i = 0; i < nums.length; i++) {
            long lcm = 1;
            for (int j = i; j < nums.length; j++) {
                lcm = lcm / gcd(lcm, nums[j]) * nums[j];
                if (k % lcm != 0) break;
                if (lcm == k) answer++;
            }
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var subarrayLCM = function(nums, k) {
    const gcd = (a, b) => {
        while (b !== 0) [a, b] = [b, a % b];
        return a;
    };
    let answer = 0;
    // ponytail: quadratic enumeration for n <= 1000; compress LCM states for larger n.
    for (let i = 0; i < nums.length; i++) {
        let lcm = 1;
        for (let j = i; j < nums.length; j++) {
            lcm = lcm / gcd(lcm, nums[j]) * nums[j];
            if (k % lcm !== 0) break;
            if (lcm === k) answer++;
        }
    }
    return answer;
};

from typing import List
from math import gcd

class Solution:
    def subarrayLCM(self, nums: List[int], k: int) -> int:
        answer = 0
        # ponytail: quadratic for n <= 1000; compress LCM states for larger n.
        for i in range(len(nums)):
            lcm = 1
            for j in range(i, len(nums)):
                lcm = lcm // gcd(lcm, nums[j]) * nums[j]
                if k % lcm != 0:
                    break
                if lcm == k:
                    answer += 1
        return answer

C++

#include <vector>
#include <numeric>
using namespace std;

class Solution {
public:
    int subarrayLCM(vector<int>& nums, int k) {
        int answer = 0;
        // ponytail: quadratic for n <= 1000; compress LCM states for larger n.
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            long long lcm = 1;
            for (int j = i; j < static_cast<int>(nums.size()); ++j) {
                lcm = lcm / gcd(lcm, static_cast<long long>(nums[j])) * nums[j];
                if (k % lcm != 0) break;
                if (lcm == k) ++answer;
            }
        }
        return answer;
    }
};
