题目转述

给定患者表，疾病代码保存在一个由空格分隔的字符串中。请找出至少有一个疾病代码以 DIAB1 开头的患者，并返回其 ID、姓名和完整疾病字符串；结果顺序任意。

题解：匹配字符串开头或空格后的前缀

核心洞察

一个有效疾病代码只能从整串开头，或某个空格的后一位开始。因此只需覆盖两个模式：conditions LIKE 'DIAB1%' 与 conditions LIKE '% DIAB1%'。第二个模式中的前导空格保证 DIAB1 位于代码边界，避免把 XDIAB100 误判为命中。

完整过程

检查串首。 若整串以 DIAB1 开头，首个疾病代码匹配。
检查后续代码。 搜索“空格 + DIAB1”，以定位后续任意一个代码的开头。
组合条件。 两种情况用 OR 相连，选择题目要求的三列；无需排序。

正确性说明

充分性：若查询返回某行，则它满足两个模式之一。第一种令 DIAB1 位于首个代码开头；第二种令 DIAB1 位于空格后的某个代码开头，所以患者确有目标疾病。必要性：若患者存在以 DIAB1 开头的疾病代码，该代码若为第一个，就满足第一种模式；否则其前方必有分隔空格，满足第二种模式。因此所有且仅有目标患者被返回。

边界情况

  • 空 conditions 不匹配。
  • DIAB1 本身与 DIAB100 都匹配，因为要求是前缀。
  • XDIAB100 不匹配，因为 DIAB1 不在代码开头。
  • 目标代码在首位、末位或中间均能匹配。

复杂度

设患者数为 n，单个 conditions 最大长度为 L。常规字符串扫描时间为 O(nL)，查询额外空间为 O(1)（不计结果集）。以通配符开头的模式通常不能直接利用普通 B-tree 前缀索引。

官方可提交方案 · MySQL

MySQL官方语言
SELECT patient_id, patient_name, conditions
FROM Patients
WHERE conditions LIKE 'DIAB1%'
   OR conditions LIKE '% DIAB1%';

Java本地语义参考
import java.util.*;

public class Main {
    record Patient(int id, String name, String conditions) {}

    static List<Patient> findPatients(List<Patient> rows) {
        List<Patient> answer = new ArrayList<>();
        for (Patient p : rows) {
            String s = p.conditions();
            if (s.startsWith("DIAB1") || s.contains(" DIAB1")) {
                answer.add(p);
            }
        }
        return answer;
    }

    public static void main(String[] args) {
        List<Patient> rows = List.of(
            new Patient(1, "Daniel", "YFEV COUGH"),
            new Patient(3, "Bob", "DIAB100 MYOP"),
            new Patient(4, "George", "ACNE DIAB100")
        );
        findPatients(rows).forEach(System.out::println);
    }
}

from dataclasses import dataclass

@dataclass(frozen=True)
class Patient:
    patient_id: int
    patient_name: str
    conditions: str

def find_patients(patients: list[Patient]) -> list[Patient]:
    return [
        patient for patient in patients
        if patient.conditions.startswith("DIAB1")
        or " DIAB1" in patient.conditions
    ]

rows = [
    Patient(1, "Daniel", "YFEV COUGH"),
    Patient(3, "Bob", "DIAB100 MYOP"),
    Patient(4, "George", "ACNE DIAB100"),
]
print(find_patients(rows))
C++本地语义参考
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Patient {
    int patientId;
    string patientName;
    string conditions;
};

vector<Patient> findPatients(const vector<Patient>& rows) {
    vector<Patient> answer;
    for (const Patient& p : rows) {
        bool atStart = p.conditions.rfind("DIAB1", 0) == 0;
        bool afterSpace = p.conditions.find(" DIAB1") != string::npos;
        if (atStart || afterSpace) answer.push_back(p);
    }
    return answer;
}

int main() {
    vector<Patient> rows = {
        {1, "Daniel", "YFEV COUGH"},
        {3, "Bob", "DIAB100 MYOP"},
        {4, "George", "ACNE DIAB100"}
    };
    for (const Patient& p : findPatients(rows))
        cout << p.patientId << ' ' << p.patientName << '\n';
}

替代方案

MySQL 也可用正则 conditions REGEXP '(^| )DIAB1'，它更直接表达“开头或空格后”的边界，但不同数据库的正则语法与性能行为并不完全一致。两个 LIKE 条件更贴近本题约束，也更容易跨常见 SQL 方言理解。若数据模型可重构，规范化为“患者—疾病代码”关联表会让查询与索引更自然。

常见错误

  • 写成 LIKE '%DIAB1%'，误收 XDIAB100。
  • 只检查 LIKE 'DIAB1%'，漏掉目标代码不在首位的患者。
  • 写成等于 DIAB1，漏掉 DIAB100、DIAB199 等合法前缀。
  • 擅自按 ID 排序；虽然不影响正确性，却不是题目要求。
