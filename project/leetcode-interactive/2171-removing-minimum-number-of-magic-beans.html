拿出最少数目的
魔法豆

Removing Minimum Number of Magic Beans

只拿出，不放回。让所有非空袋子里的豆子一样多，付出最小的代价。

前往官方题目 ↗先读题与思考，再展开底部题解。

01 / 题目

给定正整数数组 beans，beans[i] 是第 i 个袋子中的豆子数。你可以从任意袋子取出任意数量的豆子，也可以一个都不取。取出的豆子不能放回或转移到其他袋子。

操作结束后，所有仍非空的袋子必须有相同数量的豆子；空袋子不参与比较。返回需要取出的豆子总数的最小值。

参数与返回值

minimumRemoval(beans)：参数为正整数数组，返回最少移除数（可能超过 32 位整数）。

约束

  • 1 ≤ beans.length ≤ 10⁵
  • 1 ≤ beans[i] ≤ 10⁵

02 / 官方示例

示例 1

输入：beans = [4,1,6,5]
输出：4

把第 2 个袋子清空，再从第 3、4 个袋子分别取出 2、1 颗，最终得到 [4,0,4,4]。总共取出 1 + 2 + 1 = 4 颗，这是最小值。

示例 2

输入：beans = [2,10,3,2]
输出：7

将第 1、3、4 个袋子清空，得到 [0,10,0,0]。总共取出 2 + 3 + 2 = 7 颗，这是最小值。只剩一个非空袋子也满足要求。

05 / 独立题解

包含交互推演、证明与四语言代码

核心洞察：移除最少 = 保留最多

先按升序排列为 a，原总数为 S。若选择共同豆数 t = a[i]，所有小于 t 的袋子只能清空，其他袋子都可以留下 t 颗。

在每个不同数值第一次出现的位置，剩余袋子正好有 n − i 个。因此保留数是矩形面积 a[i] × (n − i)，移除数是 S − a[i] × (n − i)。找最大的保留面积即可。

完整过程

  1. 求总和 S，将数组按数值升序排序。
  2. 令答案初值为 S，从左到右枚举下标 i。
  3. 计算 S − a[i] × (n − i)，用它更新答案。
  4. 遍历结束返回最小值。

例如 [4,1,6,5] 排序后为 [1,4,5,6]，总数 16。目标值依次为 1、4、5、6，保留数分别为 4、12、10、6，移除数分别为 12、4、6、10，答案为 4。

代码为简洁会遍历重复值：重复值的后续位置相当于额外清空几个同值袋子，仍是合法方案，但保留数更少，所以不会优于第一次出现的位置。

正确性证明

  1. 固定目标时的最优方案。对于最终共同豆数 t > 0，原本少于 t 的袋子无法补豆，只能清空；原本不少于 t 的袋子保留 t 颗比清空更好。因此应保留所有能达到 t 的袋子。
  2. 只需考察原数组中的值。若 t 不是原有豆数，取不小于 t 的最小原有值 v。将目标提高到 v，不会失去任何当前可保留的袋子，却能保留更多豆子。因此至少有一个最优目标属于原数组。
  3. 枚举覆盖最优目标。排序后，目标 v 第一次出现于 i，能保留的袋子恰好组成后缀，保留总数为 v × (n − i)。遍历包括所有这样的 i，且每个枚举方案均合法，故最小移除数正是全局最优值。

全清空也合法，但输入全为正整数，总能至少保留一个袋子，所以全清空不会是最优解。

边界与复杂度

  • 单个袋子或全部相等时，答案为 0；最优方案可以只保留一个袋子。
  • 总和及乘积最大达到 10¹⁰。Java 用 long，C++ 用 long long，并在乘法前提升类型。
  • JavaScript 的 Number 能精确表示本题范围内的整数，Python 整数自动扩展。
  • 时间复杂度 O(n log n)，排序后扫描 O(n)。算法扫描额外空间 O(1)；含排序实现，Java/C++ 通常需要 O(log n) 栈空间，Python 最坏 O(n)，JavaScript 依引擎而定，常见实现为 O(n)。
  • 四份代码均对输入数组原地排序；若调用方要求保留顺序，先复制数组，另需 O(n) 空间。

替代方案

值域上限为 U = 10⁵，可以统计每个值的频次，再从大到小维护“至少为 t”的袋子数，最大化 t × count。时间 O(n + U)，空间 O(U)；当值域小且固定时有优势。也可用排序加前缀和计算清空左侧和削减右侧的代价，但本题直接用总和减保留数更简洁。

Java

import java.util.Arrays;

class Solution {
    public long minimumRemoval(int[] beans) {
        Arrays.sort(beans);
        long total = 0;
        for (int x : beans) total += x;
        long answer = total;
        for (int i = 0; i < beans.length; i++) {
            long kept = (long) beans[i] * (beans.length - i);
            answer = Math.min(answer, total - kept);
        }
        return answer;
    }
}

var minimumRemoval = function(beans) {
    beans.sort((a, b) => a - b);
    const total = beans.reduce((sum, x) => sum + x, 0);
    let answer = total;
    for (let i = 0; i < beans.length; i++) {
        answer = Math.min(answer,
            total - beans[i] * (beans.length - i));
    }
    return answer;
};

from typing import List

class Solution:
    def minimumRemoval(self, beans: List[int]) -> int:
        beans.sort()
        total = sum(beans)
        answer = total
        n = len(beans)

常见错误

  • 把目标设为平均数或中位数：本题允许清空袋子，且只能减少，不是一般的双向调整问题。
  • 把所有袋子都削到最小值：可能保留一个较大的后缀更划算。
  • 使用 n − i − 1：下标 i 的袋子也在保留范围内。
  • JavaScript 直接 sort()：默认按字符串排序，必须提供数值比较器。
  • Java/C++ 在乘积溢出后才转成 64 位：提升类型必须发生在乘法前。
  • 误将移除的豆子放入小袋子：题目禁止转移和放回。

面试追问

  • 如何返回具体操作？记住最优目标 t，再按原顺序输出：原值小于 t 的袋子移除全部，否则移除 beans[i] − t。
  • 至少保留 k 个非空袋子？只考察能留下至少 k 个袋子的候选，即排序后首次出现位置满足 n − i ≥ k。
  • 为何不用二分答案？目标豆数增大时，可保留袋数阶梯式下降，保留总数不单调；直接枚举候选即可。
  • 输入不能修改怎么办？复制后排序，或使用频次数组；明确额外空间成本。
