一串数字里，有些声音反复出现，有些只响一次。你的任务，是找出只出现一次的数字中最大的那个。

Largest Unique Number

EASY 数组 哈希表 排序

01 / Problem

先把任务说清楚

给定一个整数数组 nums。如果某个整数在数组中恰好出现一次，就称它为 唯一数。

返回数组中最大的唯一数；如果不存在唯一数，返回 -1。

示例 1

输入 nums = [5,7,3,9,4,9,8,3,1]
输出 8
说明 唯一数为 5、7、4、8、1，最大是 8。

示例 2

输入 nums = [9,9,8,8]
输出 -1
说明 没有任何数字只出现一次。

函数契约

largestUniqueNumber(nums: integer[]) → integer

约束

  • 1 <= nums.length <= 2000
  • 0 <= nums[i] <= 1000

交互演示为保证可读性，最多接收 20 个符合官方取值范围的整数。

03 / Solution

先亲手走一遍，再看完整题解

题解默认收起，展开后包含证明、四种语言代码、替代方案与面试追问。

Frequency First

频次统计 + 从大到小查找

时间 O(n + U) · 空间 O(U)

核心洞察

“唯一”只取决于出现次数，“最大”只取决于查找顺序。先把这两个条件拆开：统计频次，再从允许的最大值向下寻找第一个频次为 1 的值。

完整过程

  1. 建立长度为 1001 的频次数组 freq。
  2. 遍历 nums，执行 freq[x]++。
  3. 从 1000 递减到 0，首次遇到 freq[x] == 1 就返回 x。
  4. 扫描结束仍未命中，则返回 -1。

边界与复杂度

  • 单元素数组：该元素本身就是答案，包括 0。
  • 全部重复：扫描不到频次 1，返回 -1。
  • 最大值重复：必须继续向更小值寻找，不能直接返回最大元素。
  • U = 1001，时间 O(n + U)，空间 O(U)。

替代方案

可先排序，再按连续分组判断出现次数，从右向左找到第一个长度为 1 的组。它更通用，但时间为 O(n log n)，且可能修改输入数组。若数值范围未知，可用哈希表统计后遍历键集合。

正确性证明

对任意值 x，第一次遍历后 freq[x] 等于 x 在输入数组中的出现次数，因此 freq[x] == 1 当且仅当 x 是唯一数。

第二次遍历严格按 1000 到 0 的降序检查所有可能值。算法返回的第一个频次为 1 的值 r 是唯一数；所有大于 r 的值都已被检查且频次不为 1，所以不存在比 r 更大的唯一数。因此 r 正是最大唯一数。若没有返回，则所有可能值的频次都不为 1，返回 -1 正确。

四种语言实现

class Solution {
    public int largestUniqueNumber(int[] nums) {
        int[] freq = new int[1001];

        for (int value : nums) {
            freq[value]++;
        }

        for (int value = 1000; value >= 0; value--) {
            if (freq[value] == 1) {
                return value;
            }
        }

        return -1;
    }
}

class Solution:
    def largestUniqueNumber(self, nums: List[int]) -> int:
        freq = [0] * 1001

        for value in nums:
            freq[value] += 1

        for value in range(1000, -1, -1):
            if freq[value] == 1:
                return value

        return -1

面试追问与常见错误

如果数值范围扩大到任意 32 位整数？ 改用哈希表保存频次，再在所有频次为 1 的键中取最大值。
能否只遍历一次输入？ 频次统计必须看完整个数组；可以边统计边维护候选集合，但结构和更新逻辑更复杂。
错误：把“最大值”当成“最大唯一数” 数组最大值可能重复，必须先确认它的频次恰好为 1。
错误：用集合去重后直接取最大 集合只保留是否出现，丢失出现次数，无法区分出现一次和出现多次。
错误：忘记合法值 0 逆序扫描应包含 0；循环条件必须是 value >= 0。
错误：没有唯一数时返回 0 0 本身是合法数组元素；题目指定的失败返回值是 -1。
