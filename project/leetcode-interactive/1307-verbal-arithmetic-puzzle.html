Verbal Arithmetic Puzzle

HARD 数组数学字符串回溯

Problem

题意

给定字符串数组 words 表示等式左侧的若干加数，字符串 result 表示右侧的和。判断能否给每个大写字母分配一个十进制数字，使整个加法等式成立。

  • 每个字母对应一个 0～9 的数字，同一个字母始终取同一数字。
  • 不同字母不能对应相同数字。
  • 长度大于 1 的单词不能以数字 0 开头。
  • 所有 words 表示的整数之和必须等于 result。

函数形式：isSolvable(words: string[], result: string): boolean

Limits

约束

  • 2 ≤ words.length ≤ 5
  • 1 ≤ words[i].length, result.length ≤ 7
  • 所有字符串只含大写英文字母。
  • 等式中不同字母的数量至多为 10。
返回值：存在任一合法映射时返回 true，否则返回 false。

Full solution

列优先回溯

核心洞察

若直接给至多 10 个字母排列数字，搜索接近 10!。竖式加法却让我们在每一列结束时立即检查结果位：左侧本列总和的个位必须等于结果字母，十位成为下一列进位。冲突越早暴露，剪枝越强。

必要预检

若结果长度小于最长加数，或比最长加数多 2 位及以上，则不可能成立。先记录所有多字符单词的首字母，它们不能映射到 0；不同字母超过 10 也直接失败。

状态设计

dfs(col, row, sum) 表示正在处理从右向左第 col 列、该列第 row 个加数，sum 已含上一列进位和本列已处理数字。映射表与数字占用表在回溯中原地维护。

剪枝时机

处理完一列的所有加数后，目标字母只能等于 sum % 10。若该数字已被别的字母占用、与既有映射冲突，或会让首字母为 0，就立刻回退。

完整过程

  1. 统计最长加数长度、不同字母与不可为零的首字母，执行长度及字符数预检。
  2. 从个位列开始，依次处理每个加数；超出当前列长度的加数直接跳过。
  3. 当前字母已有映射时，把对应数字加入 sum；否则尝试尚未使用且满足前导零规则的数字。
  4. 本列加数处理完后，用 sum % 10 强制约束结果字母，再携带 floor(sum / 10) 进入下一列。
  5. 所有结果列都处理结束时，仅当剩余进位为 0 才成功；失败分支撤销映射并尝试下一数字。

正确性证明

不变式：每次进入某列时，所有更低位都满足竖式加法，且 sum 的初值正是低一列产生的进位。处理加数时，算法枚举当前未映射字母的全部合法数字，因此不会遗漏任何合法映射；数字占用表和首字母约束确保每个枚举都满足题目规则。列末强制结果位等于总和个位，并把商传给下一列，所以成功到达终点的映射必使每一列成立，进而整个等式成立。反过来，任一合法解在每个枚举点都对应算法的一个分支，且不会被合法性剪枝删除，因此最终一定能被搜索到。故算法返回值正确。

复杂度

设不同字母数为 K ≤ 10。最坏时间复杂度为数字排列数量级 O(10! / (10-K)!)，列约束通常会大幅提前剪枝；每次递归只做常数工作。映射、占用和递归栈的额外空间为 O(K + L·W)，其中 L ≤ 7、W ≤ 5，在题目范围内可视为常数。

边界情况

  • 单字母单词允许映射为 0，多字母单词不允许。
  • 结果长度只能等于最长加数长度或多 1。
  • 结果字母可能已经在本列加数中被赋值，必须校验而不能覆盖。
  • 重复出现的同一加数仍要逐次计入本列总和。
  • 最后一列后仍有进位则当前分支失败。

替代方案

可以先按字母对总和的线性贡献构造方程，再按贡献绝对值从大到小枚举数字；这种写法可能更短，但进位约束不显式、剪枝设计更难解释。也可以使用约束满足（CSP）/整数规划求解器，但不适合 LeetCode 提交环境。列优先 DFS 最贴合手算加法机制。

面试追问

  • 为什么从低位向高位比按字母顺序枚举更容易剪枝？
  • 若进制从 10 改为 B，哪些数组大小与取模逻辑需要变化？
  • 能否按列中未赋值字母出现次数排序来优化分支？
  • 如何返回一组具体映射，而不只是布尔值？

常见错误

  • 把所有首字母都禁止为 0，误伤长度为 1 的单词。
  • 列末给结果字母赋值时忘记检查数字是否已占用。
  • 回溯后只清映射、不清数字占用，或反之。
  • 用浮点数拼接完整整数再求和，忽略语言数值精度。
  • 列索引方向与字符串索引方向写反。

JavaLeetCode
import java.util.Arrays;

class Solution {
    private String[] words;
    private String result;
    private int maxLen;
    private final int[] map = new int[26];
    private final boolean[] used = new boolean[10];
    private final boolean[] leading = new boolean[26];

    public boolean isSolvable(String[] words, String result) {
        this.words = words;
        this.result = result;
        Arrays.fill(map, -1);

        boolean[] seen = new boolean[26];
        int distinct = 0;
        for (String word : words) {
            maxLen = Math.max(maxLen, word.length());
            if (word.length() > 1) leading[word.charAt(0) - 'A'] = true;
            for (char ch : word.toCharArray()) {
                int id = ch - 'A';
                if (!seen[id]) { seen[id] = true; distinct++; }
            }
        }
        if (result.length() > 1) leading[result.charAt(0) - 'A'] = true;
        for (char ch : result.toCharArray()) {
            int id = ch - 'A';
            if (!seen[id]) { seen[id] = true; distinct++; }
        }
        if (distinct > 10 || result.length() < maxLen ||
            result.length() > maxLen + 1) return false;
        return dfs(0, 0, 0);
    }

    private boolean dfs(int col, int row, int sum) {
        if (col == result.length()) return sum == 0;

        if (row == words.length) {
            int id = result.charAt(result.length() - 1 - col) - 'A';
            int digit = sum % 10;
            if (map[id] != -1) {
                return map[id] == digit && dfs(col + 1, 0, sum / 10);
            }
            if (used[digit] || (digit == 0 && leading[id])) return false;
            map[id] = digit;
            used[digit] = true;
            if (dfs(col + 1, 0, sum / 10)) return true;
            map[id] = -1;
            used[digit] = false;
            return false;
        }

        String word = words[row];
        if (col >= word.length()) return dfs(col, row + 1, sum);
        int id = word.charAt(word.length() - 1 - col) - 'A';
        if (map[id] != -1) return dfs(col, row + 1, sum + map[id]);

        for (int digit = 0; digit <= 9; digit++) {
            if (used[digit] || (digit == 0 && leading[id])) continue;
            map[id] = digit;
            used[digit] = true;
            if (dfs(col, row + 1, sum + digit)) return true;
            map[id] = -1;
            used[digit] = false;
        }
        return false;
    }
}

/**
 * @param {string[]} words
 * @param {string} result
 * @return {boolean}
 */
var isSolvable = function(words, result) {
    const map = new Int8Array(26);
    map.fill(-1);
    const used = new Array(10).fill(false);
    const leading = new Array(26).fill(false);
    const seen = new Array(26).fill(false);
    let distinct = 0;
    let maxLen = 0;

    const visit = (ch) => {
        const id = ch.charCodeAt(0) - 65;
        if (!seen[id]) { seen[id] = true; distinct++; }
    };
    for (const word of words) {
        maxLen = Math.max(maxLen, word.length);
        if (word.length > 1) leading[word.charCodeAt(0) - 65] = true;
        for (const ch of word) visit(ch);
    }
    if (result.length > 1) leading[result.charCodeAt(0) - 65] = true;
    for (const ch of result) visit(ch);
    if (distinct > 10 || result.length < maxLen ||
        result.length > maxLen + 1) return false;

    function dfs(col, row, sum) {
        if (col === result.length) return sum === 0;

        if (row === words.length) {
            const id = result.charCodeAt(result.length - 1 - col) - 65;
            const digit = sum % 10;
            if (map[id] !== -1) {
                return map[id] === digit &&
                    dfs(col + 1, 0, Math.floor(sum / 10));
            }
            if (used[digit] || (digit === 0 && leading[id])) return false;
            map[id] = digit;
            used[digit] = true;
            if (dfs(col + 1, 0, Math.floor(sum / 10))) return true;
            map[id] = -1;
            used[digit] = false;
            return false;
        }

        const word = words[row];
        if (col >= word.length) return dfs(col, row + 1, sum);
        const id = word.charCodeAt(word.length - 1 - col) - 65;
        if (map[id] !== -1) return dfs(col, row + 1, sum + map[id]);

        for (let digit = 0; digit <= 9; digit++) {
            if (used[digit] || (digit === 0 && leading[id])) continue;
            map[id] = digit;
            used[digit] = true;
            if (dfs(col, row + 1, sum + digit)) return true;
            map[id] = -1;
            used[digit] = false;
        }
        return false;
    }
    return dfs(0, 0, 0);
};

from typing import List


class Solution:
    def isSolvable(self, words: List[str], result: str) -> bool:
        mapping = [-1] * 26
        used = [False] * 10
        leading = [False] * 26
        seen = set()
        max_len = max(map(len, words))

        for word in words:
            if len(word) > 1:
                leading[ord(word[0]) - ord('A')] = True
            seen.update(word)
        if len(result) > 1:
            leading[ord(result[0]) - ord('A')] = True
        seen.update(result)

        if (len(seen) > 10 or len(result) < max_len or
                len(result) > max_len + 1):
            return False

        def dfs(col: int, row: int, total: int) -> bool:
            if col == len(result):
                return total == 0

            if row == len(words):
                idx = ord(result[-1 - col]) - ord('A')
                digit = total % 10
                if mapping[idx] != -1:
                    return (mapping[idx] == digit and
                            dfs(col + 1, 0, total // 10))
                if used[digit] or (digit == 0 and leading[idx]):
                    return False
                mapping[idx] = digit
                used[digit] = True
                if dfs(col + 1, 0, total // 10):
                    return True
                mapping[idx] = -1
                used[digit] = False
                return False

            word = words[row]
            if col >= len(word):
                return dfs(col, row + 1, total)
            idx = ord(word[-1 - col]) - ord('A')
            if mapping[idx] != -1:
                return dfs(col, row + 1, total + mapping[idx])

            for digit in range(10):
                if used[digit] or (digit == 0 and leading[idx]):
                    continue
                mapping[idx] = digit
                used[digit] = True
                if dfs(col, row + 1, total + digit):
                    return True
                mapping[idx] = -1
                used[digit] = False
            return False

        return dfs(0, 0, 0)

class Solution {
    vector<string> words;
    string result;
    int maxLen = 0;
    int mapping[26];
    bool used[10]{};
    bool leading[26]{};

    bool dfs(int col, int row, int sum) {
        if (col == static_cast<int>(result.size())) return sum == 0;

        if (row == static_cast<int>(words.size())) {
            int id = result[result.size() - 1 - col] - 'A';
            int digit = sum % 10;
            if (mapping[id] != -1) {
                return mapping[id] == digit && dfs(col + 1, 0, sum / 10);
            }
            if (used[digit] || (digit == 0 && leading[id])) return false;
            mapping[id] = digit;
            used[digit] = true;
            if (dfs(col + 1, 0, sum / 10)) return true;
            mapping[id] = -1;
            used[digit] = false;
            return false;
        }

        const string& word = words[row];
        if (col >= static_cast<int>(word.size())) {
            return dfs(col, row + 1, sum);
        }
        int id = word[word.size() - 1 - col] - 'A';
        if (mapping[id] != -1) return dfs(col, row + 1, sum + mapping[id]);

        for (int digit = 0; digit <= 9; digit++) {
            if (used[digit] || (digit == 0 && leading[id])) continue;
            mapping[id] = digit;
            used[digit] = true;
            if (dfs(col, row + 1, sum + digit)) return true;
            mapping[id] = -1;
            used[digit] = false;
        }
        return false;
    }

public:
    bool isSolvable(vector<string>& inputWords, string inputResult) {
        words = inputWords;
        result = inputResult;
        fill(begin(mapping), end(mapping), -1);
        bool seen[26]{};
        int distinct = 0;

        for (const string& word : words) {
            maxLen = max(maxLen, static_cast<int>(word.size()));
            if (word.size() > 1) leading[word.front() - 'A'] = true;
            for (char ch : word) {
                int id = ch - 'A';
                if (!seen[id]) { seen[id] = true; distinct++; }
            }
        }
        if (result.size() > 1) leading[result.front() - 'A'] = true;
        for (char ch : result) {
            int id = ch - 'A';
            if (!seen[id]) { seen[id] = true; distinct++; }
        }
        if (distinct > 10 || static_cast<int>(result.size()) < maxLen ||
            static_cast<int>(result.size()) > maxLen + 1) return false;
        return dfs(0, 0, 0);
    }
};
