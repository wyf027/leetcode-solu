05 / Solution

题解：投影新的座位号

不修改原表，只在查询结果中为每名学生计算交换后的 id。

核心洞察

连续编号天然把学生分成 (1,2)、(3,4)……。奇数 id 通常向后移动一位，偶数 id 向前移动一位；唯一例外是“总人数为奇数时的最大 id”。

odd & id = max(id) → id ｜ odd → id + 1 ｜ even → id - 1

完整过程

  1. 用子查询得到 MAX(id)，用于识别可能未配对的末位。
  2. 若当前 id 为奇数且等于最大 id，保留原 id。
  3. 否则，奇数 id 加 1；偶数 id 减 1。
  4. 将计算值命名为 id，最后按它升序排序。

正确性证明

对任意完整相邻对 (2k−1, 2k)，规则把前者映射到 2k，把后者映射到 2k−1，恰好交换这一对且不影响其他对。若人数为奇数，最大 id 是唯一未配对奇数，第一条分支将其保持不变。完整对互不重叠，且末位也不会与其他 id 冲突，因此每名学生恰好出现一次；最终排序保证返回表按 id 升序。

边界与复杂度

  • 单人：id 1 同时为奇数和最大值，保持不变。
  • 偶数人数：最大 id 为偶数，所有学生都进入完整配对。
  • 时间：逻辑投影为 O(n)；结果排序通常为 O(n log n)，数据库也可能利用索引优化。
  • 额外空间：查询逻辑为 O(1)，不计数据库执行排序所需空间。

MySQL官方可提交语言 
SELECT
    CASE
        WHEN MOD(id, 2) = 1
             AND id = (SELECT MAX(id) FROM Seat) THEN id
        WHEN MOD(id, 2) = 1 THEN id + 1
        ELSE id - 1
    END AS id,
    student
FROM Seat
ORDER BY id ASC;
Java本地语义参考 · 非 SQL 提交 
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

public class Solution {
    public static final class Seat {
        public final int id;
        public final String student;

        public Seat(int id, String student) {
            this.id = id;
            this.student = student;
        }
    }

    public static List<Seat> exchangeSeats(List<Seat> rows) {
        List<Seat> sorted = new ArrayList<>(rows);
        sorted.sort(Comparator.comparingInt(seat -> seat.id));

        List<Seat> result = new ArrayList<>(sorted.size());
        for (int i = 0; i < sorted.size(); i += 2) {
            Seat first = sorted.get(i);
            if (i + 1 == sorted.size()) {
                result.add(new Seat(first.id, first.student));
                break;
            }

            Seat second = sorted.get(i + 1);
            result.add(new Seat(first.id, second.student));
            result.add(new Seat(second.id, first.student));
        }
        return result;
    }
}
JavaScript本地语义参考 · 非 SQL 提交 
function exchangeSeats(rows) {
  const sorted = [...rows].sort((a, b) => a.id - b.id);
  const result = [];

  for (let i = 0; i < sorted.length; i += 2) {
    const first = sorted[i];
    const second = sorted[i + 1];

    if (!second) {
      result.push({ id: first.id, student: first.student });
      break;
    }

    result.push({ id: first.id, student: second.student });
    result.push({ id: second.id, student: first.student });
  }

  return result;
}

from typing import TypedDict


class Seat(TypedDict):
    id: int
    student: str


def exchange_seats(rows: list[Seat]) -> list[Seat]:
    sorted_rows = sorted(rows, key=lambda row: row["id"])
    result: list[Seat] = []

    for index in range(0, len(sorted_rows), 2):
        first = sorted_rows[index]
        if index + 1 == len(sorted_rows):
            result.append(first.copy())
            break

        second = sorted_rows[index + 1]
        result.append({"id": first["id"], "student": second["student"]})
        result.append({"id": second["id"], "student": first["student"]})

    return result
C++本地语义参考 · 非 SQL 提交 
#include <algorithm>
#include <string>
#include <vector>

struct Seat {
    int id;
    std::string student;
};

std::vector<Seat> exchangeSeats(std::vector<Seat> rows) {
    std::sort(rows.begin(), rows.end(),
              [](const Seat& a, const Seat& b) {
                  return a.id < b.id;
              });

    std::vector<Seat> result;
    result.reserve(rows.size());

    for (std::size_t i = 0; i < rows.size(); i += 2) {
        if (i + 1 == rows.size()) {
            result.push_back(rows[i]);
            break;
        }

        result.push_back({rows[i].id, rows[i + 1].student});
        result.push_back({rows[i + 1].id, rows[i].student});
    }

    return result;
}

替代方案

  • 窗口函数：用 LAG(student) 与 LEAD(student) 为每个座位选择相邻学生，表达直观，但不同数据库的函数支持和空值处理需留意。
  • 自连接：依据奇偶关系连接目标座位，可完成交换，但连接条件与末位回退更繁琐。
  • 位运算技巧：连续正整数可用异或推导相邻编号，但 SQL 可读性差，面试中通常不如 CASE 清楚。

常见错误

  • 无条件让所有奇数 id 加 1，导致奇数人数时生成不存在的末位座位。
  • 只交换 student 却忘记最终结果必须按 id 升序。
  • 用 COUNT(*) 代替最大 id，却忽略该等价关系依赖“从 1 连续编号”的题设。
  • 直接更新原表；题目只要求返回查询结果，无需产生持久化副作用。

面试追问

  • 如果 id 不连续，如何按排序后的相邻行交换？
  • 如果需要每三人循环换座，映射规则如何推广？
  • 窗口函数方案如何处理只有一行或末行没有 LEAD 的情况？
  • 数据库在 ORDER BY 上何时能利用主键索引，何时仍可能排序？

一句话复盘

把“换人”转化成“重新投影 id”：完整配对中奇数加一、偶数减一，单独保护奇数人数的最大 id，再排序返回。
