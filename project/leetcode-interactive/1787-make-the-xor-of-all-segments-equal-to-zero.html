使所有区间的异或结果为零

Make the XOR of All Segments Equal to Zero

HARD数组位运算动态规划计数
Problem brief

先把目标说清楚

给定整数数组 nums 和整数 k。长度为 k 的区间 [left, right] 的异或值，是其中全部元素连续异或的结果。你可以把数组中的元素改成任意整数，请返回最少需要修改多少个元素，才能让每一个长度为 k 的区间异或值都等于 0。

函数形式： minChanges(nums, k) → integer

官方示例

示例 01输出 3
输入：nums = [1,2,0,3,0], k = 1
输出：3

可将数组改成 [0,0,0,0,0]，原来的三个非零元素需要修改。

示例 02输出 3
输入：nums = [3,4,5,2,1,7,3,4,7], k = 3
输出：3

可改成 [3,4,7,3,4,7,3,4,7]，修改原数组中的 5、2、1。

示例 03输出 3
输入：nums = [1,2,4,1,2,5,1,2,6], k = 3
输出：3

可将第三、六、九个元素统一改为 3，得到 [1,2,3,1,2,3,1,2,3]。

约束

  • 1 ≤ k ≤ nums.length ≤ 2000
  • 0 ≤ nums[i] < 2¹⁰

Complete solution

分组计数 + 异或动态规划

核心洞察：每条余数轨道最终必须是常数

设两个相邻的长度 k 区间异或都为零。两式再异或一次，中间重复的元素全部抵消，只剩 nums[i] XOR nums[i+k] = 0，所以 nums[i] = nums[i+k]。因此下标对 k 取模相同的元素属于同一组，每组最后必须选定一个公共值。

全局约束

只要第一个长度为 k 的区间异或为零，且每条轨道内部相等，后续区间就都会为零。于是问题变成：为 k 个组各选一个值，使这些值的异或为零，并让总修改次数最少。

完整过程

按下标模 k 分组

第 i 组包含所有满足 index % k = i 的元素。统计组大小 size 和每个值的出现次数 freq[value]。

定义状态

dp[x] 表示已经处理完前若干组，所选公共值的累计异或为 x 时，最少修改多少个原数组元素。初始只有 dp[0] = 0。

转移一个组

若本组选择值 v，本组代价是 size - freq[v]，新异或为 x XOR v。枚举本组实际出现过的值；对于未出现的任意值，其代价都是 size，可用 min(dp) + size 一次初始化全部新状态。

读取答案

处理完全部 k 组后，合法方案必须让组公共值的总异或为零，因此答案是 dp[0]。

正确性证明

  1. 必要性：任意相邻两个合法窗口异或，得到 nums[i] = nums[i+k]，所以每组必须统一。
  2. 充分性：每组统一后，每个长度为 k 的窗口恰好包含每组一个元素；若组值总异或为零，则所有窗口异或均为零。
  3. 最优子结构：转移枚举当前组的所有可能公共值，并将其精确修改代价加入此前最优状态，因此 dp 不漏掉任何可行选择。
  4. 结论：dp[0] 覆盖全部且仅覆盖合法最终方案，并取其中最小修改数。

复杂度与边界

令 U = 2¹⁰ = 1024。时间复杂度为 O(n·U)，空间复杂度为 O(U)。

  • k = 1：唯一组值必须为 0。
  • k = n：只有整个数组这一个窗口，但分组仍然成立。
  • 组大小可能不同，必须逐组计算实际 size。
  • 状态范围固定为 [0, 1023]，因为输入均小于 2¹⁰。

替代方案

可以对每组枚举全部 1024 个值，再对全部旧异或状态转移，复杂度约为 O(k·U²)，在本题规模下通常过慢。也可以把目标改写为“最大化保留元素数”，本质仍是同一个分组 DP。

常见错误

  • 只让每个窗口各自异或为零，却没有利用相邻窗口抵消。
  • 误以为每组都选频率最高值即可；这些局部最优值的总异或可能不为零。
  • 遗漏“选择本组从未出现过的值”这一类转移。
  • 用固定的 ceil(n/k) 代替每组真实大小。

面试追问

  • 为什么值域只有 1024？ 小于 2¹⁰ 的数进行异或，结果仍在 [0,1023]。
  • 为什么基线能一次覆盖未出现值？ 对任意目标异或 y 和最优旧状态 x，总能选择 v=x XOR y 到达它；若不保留组内元素，代价就是整组大小。
  • 能恢复具体修改方案吗？ 可以为每层状态保存前驱异或与所选组值，再从最终状态 0 逆推。
  • 若目标窗口异或是固定值 t 呢？ 相邻窗口仍推出轨道相等，只需把最终组值异或目标从 0 改为 t。

import java.util.*;

class Solution {
    public int minChanges(int[] nums, int k) {
        final int U = 1 << 10;
        final int INF = 1_000_000_000;
        int[] dp = new int[U];
        Arrays.fill(dp, INF);
        dp[0] = 0;

        for (int group = 0; group < k; group++) {
            Map<Integer, Integer> freq = new HashMap<>();
            int size = 0;
            for (int i = group; i < nums.length; i += k) {
                freq.merge(nums[i], 1, Integer::sum);
                size++;
            }

            int bestPrevious = INF;
            for (int cost : dp) bestPrevious = Math.min(bestPrevious, cost);

            int[] next = new int[U];
            Arrays.fill(next, bestPrevious + size);

            for (int xor = 0; xor < U; xor++) {
                for (Map.Entry<Integer, Integer> entry : freq.entrySet()) {
                    int value = entry.getKey();
                    int kept = entry.getValue();
                    int nextXor = xor ^ value;
                    next[nextXor] = Math.min(
                        next[nextXor], dp[xor] + size - kept
                    );
                }
            }
            dp = next;
        }
        return dp[0];
    }
}

var minChanges = function(nums, k) {
    const U = 1 << 10;
    const INF = 1_000_000_000;
    let dp = new Int32Array(U);
    dp.fill(INF);
    dp[0] = 0;

    for (let group = 0; group < k; group++) {
        const freq = new Map();
        let size = 0;
        for (let i = group; i < nums.length; i += k) {
            freq.set(nums[i], (freq.get(nums[i]) || 0) + 1);
            size++;
        }

        let bestPrevious = INF;
        for (const cost of dp) bestPrevious = Math.min(bestPrevious, cost);

        const next = new Int32Array(U);
        next.fill(bestPrevious + size);

        for (let xor = 0; xor < U; xor++) {
            for (const [value, kept] of freq) {
                const nextXor = xor ^ value;
                next[nextXor] = Math.min(
                    next[nextXor], dp[xor] + size - kept
                );
            }
        }
        dp = next;
    }
    return dp[0];
};
from collections import Counter
from typing import List


class Solution:
    def minChanges(self, nums: List[int], k: int) -> int:
        universe = 1 << 10
        infinity = 10**9
        dp = [infinity] * universe
        dp[0] = 0

        for group in range(k):
            values = nums[group::k]
            freq = Counter(values)
            size = len(values)

            # Choosing a value absent from this group changes every element.
            next_dp = [min(dp) + size] * universe

            for xor, previous_cost in enumerate(dp):
                for value, kept in freq.items():
                    next_xor = xor ^ value
                    next_dp[next_xor] = min(
                        next_dp[next_xor],
                        previous_cost + size - kept,
                    )
            dp = next_dp

        return dp[0]
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int minChanges(vector<int>& nums, int k) {
        constexpr int U = 1 << 10;
        constexpr int INF = 1'000'000'000;
        vector<int> dp(U, INF);
        dp[0] = 0;

        for (int group = 0; group < k; ++group) {
            unordered_map<int, int> freq;
            int size = 0;
            for (int i = group; i < static_cast<int>(nums.size()); i += k) {
                ++freq[nums[i]];
                ++size;
            }

            int bestPrevious = *min_element(dp.begin(), dp.end());
            vector<int> next(U, bestPrevious + size);

            for (int xorValue = 0; xorValue < U; ++xorValue) {
                for (const auto& [value, kept] : freq) {
                    int nextXor = xorValue ^ value;
                    next[nextXor] = min(
                        next[nextXor], dp[xorValue] + size - kept
                    );
                }
            }
            dp.swap(next);
        }
        return dp[0];
    }
};
