LCR 110 · MEDIUM

所有可能的路径

给定一个有 n 个节点的有向无环图，节点编号为 0 到 n - 1。找出从节点 0 到节点 n - 1 的所有路径，并以节点序列返回。

DFS回溯有向图

示例

输入：graph = [[1,2],[3],[3],[]]
输出：[[0,1,3],[0,2,3]]

从 0 分别经过 1、2，都能到达终点 3。

约束

  • 2 ≤ graph.length ≤ 15
  • graph[i] 包含节点 i 的所有出边。
  • 图是有向无环图，答案路径数由题目保证可处理。

分步交互：DFS 入栈与回溯

演示图为 0 → {1, 2}，1 → 3，2 → 3。每一步展示当前递归路径；抵达终点便收集一条完整路径。

核心洞察

从 0 深度优先搜索。路径数组保存当前递归分支；到达终点时复制这份数组加入答案。返回上一层时弹出末尾节点，保证相邻分支互不污染。

复杂度

设所有输出路径总长度为 P，生成答案至少需要 O(P) 时间。递归栈和当前路径最多 O(n)，返回答案的空间不计入辅助空间。

完整过程

  1. 建立答案集合和初始路径 [0]。
  2. 访问当前节点；若它是终点，复制当前路径加入答案。
  3. 否则依次枚举所有出边，把相邻节点加入路径后继续 DFS。
  4. 递归返回后删除刚加入的节点，完成回溯。

边界情况

  • 只有一条路径时，答案仍是二维数组。
  • 节点 0 可能直接连向终点。
  • 中间节点可以没有出边，此分支自然不产生答案。

替代方案

显式栈可改写递归 DFS，但需要自行维护迭代器与路径回退。BFS 可枚举路径，却会同时保存大量前缀，通常不如回溯直接。

追问与常见错误

          
追问

          
    
            
  • 有环图需增加当前路径集合防止无限递归。
    • 
            
  • 若只求路径数，可不保存完整答案而累加计数。
    • 
          

          
常见错误

          
    
            
  • 将同一个 path 引用直接放进答案，后续回溯会改写结果。
    • 
            
  • 递归返回后漏掉 pop，导致节点串入下一条路径。
    • 
            
  • 把到达终点当成继续向下搜索。
