01 / 题意与约束

恰好一次编辑，不是至多一次

给定字符串 s 与 t，若能对 s 恰好执行一次插入、删除或替换得到 t，返回 true，否则返回 false。

  • • 插入一个字符。
  • • 删除一个字符。
  • • 把一个字符替换成不同字符。

04 / INTERVIEW SOLUTION

题解

洞察、过程、边界、复杂度、替代方案与四语言代码默认隐藏。

CORE INSIGHT

把短串放在前面，只处理一种长度方向

若长度差超过 1 直接失败。扫描到第一处不同时消耗唯一编辑：等长时两指针都跳过一个字符，差一时只跳过长串字符。后续再不同就失败；尾部剩一个字符也算一次编辑。

COMPLETE PROCESS

  1. 1. 若 s 更长则交换，使 s 始终不长于 t。
  2. 2. 长度差大于 1 返回 false。
  3. 3. 相同字符同步前进；首次不同根据长度决定替换或插入。
  4. 4. 扫描结束后把尾部剩余字符计为一次编辑，最终要求 edits === 1。

BOUNDARIES

  • • 两个空串或完全相同：0 次编辑，false。
  • • 空串与单字符：一次插入，true。
  • • 长度差超过 1：无论内容如何都 false。
  • • 大小写敏感："a" 与 "A" 是一次替换。

COMPLEXITY

时间

O(min(m,n))

额外空间

O(1)

替代方案取舍

完整编辑距离动态规划能处理任意次数编辑，但需要 O(mn) 时间，本题只问是否恰好一次，属于明显过度设计。切片比较写法简短，却可能分配新字符串；双指针保持 O(1) 额外空间，更适合面试解释。

面试追问与常见错误

  • • 为什么相同字符串为 false？题目要求恰好一次。
  • • 错误：只看长度差，忽略同长串可能需要两次替换。
  • • 错误：第一次不同时两个指针总是一起移动，插入场景会错位。
  • • 错误：循环结束后忘记把长串尾部剩余字符计为编辑。
class Solution {
    public boolean isOneEditDistance(String s, String t) {
        if (s.length() > t.length()) return isOneEditDistance(t, s);
        if (t.length() - s.length() > 1) return false;

        int i = 0, j = 0, edits = 0;
        while (i < s.length() && j < t.length()) {
            if (s.charAt(i) == t.charAt(j)) {
                i++;
                j++;
            } else {
                if (++edits > 1) return false;
                if (s.length() == t.length()) i++;
                j++;
            }
        }
        if (i < s.length() || j < t.length()) edits++;
        return edits == 1;
    }
}
