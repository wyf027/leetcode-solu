区间和的个数

在多达 100,000 个数中，统计落入闭区间的连续子数组和。先读懂问题，再亲手推进一次计数过程；完整解法保持折叠。

数组前缀和分治归并排序非付费题

Problem

题目说明

给定整数数组 nums 和整数 lower、upper，返回数组中区间和位于闭区间 [lower, upper] 内的连续子数组数量。

区间和 S(i, j) 是 nums[i] + nums[i+1] + … + nums[j]，其中 0 ≤ i ≤ j < nums.length。函数形式为：

countRangeSum(nums, lower, upper) → integer
示例 1
输入：nums = [-2,5,-1], lower = -2, upper = 2
输出：3
解释：区间 [0,0]、[2,2]、[0,2]
      的和依次为 -2、-1、2。
示例 2
输入：nums = [0], lower = 0, upper = 0
输出：1

约束

  • 1 ≤ nums.length ≤ 10⁵
  • −2³¹ ≤ nums[i] ≤ 2³¹ − 1
  • −10⁵ ≤ lower ≤ upper ≤ 10⁵
  • 答案保证能用 32 位整数表示。
注意数值范围：
答案虽为 32 位整数，前缀和仍可能远超 32 位有符号整数。

Solution

前缀和 + 归并排序计数

把连续区间和转换成前缀和之差，再在归并过程中用两个单调指针批量统计合法差值。

转换S(i,j) = P[j+1] − P[i]，问题成为统计满足差值范围的前缀和下标对。
有序性递归处理左右两半后，两半分别有序；固定左值时，右半合法值形成一个连续窗口。
线性合并两个右指针都只向前移动，每层计数与归并都是线性，总复杂度为 O(n log n)。

核心洞察

定义 P[0] = 0，P[k+1] = P[k] + nums[k]。区间 [i, j] 的和等于 P[j+1] − P[i]。于是要统计下标对 i < j，满足：

lower ≤ P[j] − P[i] ≤ upper

对前缀和数组按下标区间分治。所有合法对分为三类：完全在左半、完全在右半、横跨左右两半。前两类递归统计；只需在两个已排序的半区间之间统计跨区间对。

完整过程

  1. 构造长度为 n + 1 的 64 位前缀和数组。
  2. 递归处理半开区间 [lo, hi)；长度不超过 1 时返回 0。
  3. 递归统计左右两半的答案，此时左右两半各自已经排序。
  4. 对左半的每个值 x，维护右半两个指针 start、end：start 指向第一个满足 P[start] − x ≥ lower 的位置，end 指向第一个满足 P[end] − x > upper 的位置。因此新增 end − start 个合法对。
  5. 用标准归并把两个有序半区间合为整体有序区间，并返回三类答案之和。

正确性证明

  • 区间与前缀和对一一对应。每个非空连续区间 [i, j] 唯一对应 (P[i], P[j+1])；反之每个 i < j 的前缀和对唯一对应区间 [i, j−1]，且两者的数值相等。
  • 跨半区间计数无遗漏且无重复。右半已排序。固定左值 x 时，差值落入闭区间等价于右值落入 [x+lower, x+upper]。两个边界指针精确夹住这一连续段，所以计数为 end−start。
  • 分治覆盖全部合法对。任意下标对必然恰好属于左半内部、右半内部或横跨两半之一。三类互斥，递归统计前两类、本层统计第三类，因此总数准确。
  • 归纳结论。长度不超过 1 时没有合法对且区间天然有序。假设两个子区间的答案与排序均正确，根据前两条本层跨区间答案正确，归并后整体也有序，故任意规模都成立。

边界处理

  • P[0] = 0 不能省略，否则从下标 0 开始的区间无法被统一统计。
  • lower == upper 时两个窗口边界仍然有效，统计恰好等于目标值的区间。
  • 数组元素可达 32 位边界，前缀和必须使用 Java long、C++ long long；JavaScript 的题目范围仍在安全整数范围内。
  • 重复前缀和值代表不同下标，必须按出现次数分别计数，不能去重。
  • 空的递归区间不会出现；长度为 1 的前缀和区间答案为 0。

复杂度

前缀和数组长度为 n+1。每一层对所有元素做常数次指针扫描和归并，共 O(n)；递归深度 O(log n)，因此时间复杂度为 O(n log n)。辅助数组和递归栈占用 O(n) 空间。

Java 
class Solution {
    private long[] temp;

    public int countRangeSum(int[] nums, int lower, int upper) {
        long[] prefix = new long[nums.length + 1];
        for (int i = 0; i < nums.length; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        temp = new long[prefix.length];
        return (int) sortAndCount(prefix, 0, prefix.length, lower, upper);
    }

    private long sortAndCount(long[] prefix, int lo, int hi,
                              long lower, long upper) {
        if (hi - lo <= 1) return 0;

        int mid = lo + (hi - lo) / 2;
        long count = sortAndCount(prefix, lo, mid, lower, upper)
                   + sortAndCount(prefix, mid, hi, lower, upper);

        int start = mid;
        int end = mid;
        for (int left = lo; left < mid; left++) {
            while (start < hi && prefix[start] - prefix[left] < lower) {
                start++;
            }
            while (end < hi && prefix[end] - prefix[left] <= upper) {
                end++;
            }
            count += end - start;
        }

        int i = lo, j = mid, k = lo;
        while (i < mid && j < hi) {
            temp[k++] = prefix[i] <= prefix[j] ? prefix[i++] : prefix[j++];
        }
        while (i < mid) temp[k++] = prefix[i++];
        while (j < hi) temp[k++] = prefix[j++];
        System.arraycopy(temp, lo, prefix, lo, hi - lo);
        return count;
    }
}

var countRangeSum = function(nums, lower, upper) {
    const prefix = new Array(nums.length + 1).fill(0);
    for (let i = 0; i < nums.length; i++) {
        prefix[i + 1] = prefix[i] + nums[i];
    }
    const temp = new Array(prefix.length);

    function sortAndCount(lo, hi) {
        if (hi - lo <= 1) return 0;
        const mid = lo + Math.floor((hi - lo) / 2);
        let count = sortAndCount(lo, mid) + sortAndCount(mid, hi);

        let start = mid;
        let end = mid;
        for (let left = lo; left < mid; left++) {
            while (start < hi && prefix[start] - prefix[left] < lower) {
                start++;
            }
            while (end < hi && prefix[end] - prefix[left] <= upper) {
                end++;
            }
            count += end - start;
        }

        let i = lo;
        let j = mid;
        let k = lo;
        while (i < mid && j < hi) {
            temp[k++] = prefix[i] <= prefix[j] ? prefix[i++] : prefix[j++];
        }
        while (i < mid) temp[k++] = prefix[i++];
        while (j < hi) temp[k++] = prefix[j++];
        for (let p = lo; p < hi; p++) prefix[p] = temp[p];
        return count;
    }

    return sortAndCount(0, prefix.length);

from typing import List


class Solution:
    def countRangeSum(
        self, nums: List[int], lower: int, upper: int
    ) -> int:
        prefix = [0]
        for value in nums:
            prefix.append(prefix[-1] + value)

        temp = [0] * len(prefix)

        def sort_and_count(lo: int, hi: int) -> int:
            if hi - lo <= 1:
                return 0

            mid = lo + (hi - lo) // 2
            count = sort_and_count(lo, mid) + sort_and_count(mid, hi)

            start = mid
            end = mid
            for left in range(lo, mid):
                while start < hi and prefix[start] - prefix[left] < lower:
                    start += 1
                while end < hi and prefix[end] - prefix[left] <= upper:
                    end += 1
                count += end - start

            i, j, k = lo, mid, lo
            while i < mid and j < hi:
                if prefix[i] <= prefix[j]:
                    temp[k] = prefix[i]
                    i += 1
                else:
                    temp[k] = prefix[j]
                    j += 1
                k += 1
            while i < mid:
                temp[k] = prefix[i]
                i += 1
                k += 1
            while j < hi:
                temp[k] = prefix[j]
                j += 1
                k += 1
            prefix[lo:hi] = temp[lo:hi]
            return count

        return sort_and_count(0, len(prefix))
C++ 
class Solution {
public:
    int countRangeSum(vector<int>& nums, int lower, int upper) {
        vector<long long> prefix(nums.size() + 1, 0);
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        vector<long long> temp(prefix.size());
        return static_cast<int>(
            sortAndCount(prefix, temp, 0, prefix.size(), lower, upper)
        );
    }

private:
    long long sortAndCount(vector<long long>& prefix,
                           vector<long long>& temp,
                           int lo, int hi,
                           long long lower, long long upper) {
        if (hi - lo <= 1) return 0;

        int mid = lo + (hi - lo) / 2;
        long long count = sortAndCount(prefix, temp, lo, mid, lower, upper)
                        + sortAndCount(prefix, temp, mid, hi, lower, upper);

        int start = mid;
        int end = mid;
        for (int left = lo; left < mid; ++left) {
            while (start < hi &&
                   prefix[start] - prefix[left] < lower) {
                ++start;
            }
            while (end < hi &&
                   prefix[end] - prefix[left] <= upper) {
                ++end;
            }
            count += end - start;
        }

        int i = lo, j = mid, k = lo;
        while (i < mid && j < hi) {
            temp[k++] = prefix[i] <= prefix[j] ? prefix[i++] : prefix[j++];
        }
        while (i < mid) temp[k++] = prefix[i++];
        while (j < hi) temp[k++] = prefix[j++];
        copy(temp.begin() + lo, temp.begin() + hi, prefix.begin() + lo);
        return count;
    }
};

替代方案

  • 离散化 + 树状数组：按顺序扫描前缀和，用二分定位所需值域并查询历史前缀和频次，时间 O(n log n)、空间 O(n)；值域边界与离散化细节更多。
  • 平衡搜索树 / 有序多重集合：若结构支持秩查询，可以统计某区间内已有值的数量；普通集合只会查存在性，不足以处理重复值和排名。
  • 暴力枚举：用前缀和可把单个区间求和降到 O(1)，但仍有 O(n²) 个区间，只适合小规模校验思路。

面试追问

为什么指针不会回退？

左半按升序遍历，目标窗口 [x+lower, x+upper] 的两端随 x 单调不减；右半也有序，所以两个边界只向右移动。

为什么归并不能省？

父层要依赖两个已排序子区间做线性窗口计数。若不把本层合并成有序区间，父层条件不再成立。

能否在线处理不断到来的元素？

可以考虑带秩统计的平衡树或离散化后的树状数组；若值域动态未知，需要动态有序结构或预先收集查询。

如何处理严格开区间？

调整两条 while 的比较符号即可。闭区间本题使用“第一个差值 ≥ lower”和“第一个差值 > upper”作为两端。

常见错误

  • 前缀和使用 32 位整数，导致累加溢出。
  • 把右边界写成第一个 ≥ upper，错误排除了差值正好等于 upper 的情况。
  • 原地归并时过早覆盖尚未读取的数据；应使用共享辅助数组。
  • 对子数组求和仍逐段累加，退化为 O(n³) 或 O(n²)。
  • 对前缀和全局排序后丢失原下标先后关系，误把 i ≥ j 的对也算入答案。
