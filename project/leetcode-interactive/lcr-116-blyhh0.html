省份数量

把相连的城市看成一个整体。无论连通关系经过多少中间城市，都只算作同一个省份。

题意

有 n 个城市，isConnected[i][j] 为 1 表示城市 i 和 j 直接相连。城市通过直接或间接连接形成省份，求省份的数量。

示例

输入：[[1,1,0],[1,1,0],[0,0,1]]

输出：2

解释：城市 0 和 1 属于同一省份，城市 2 单独构成一个省份。

约束

  • 1 <= n <= 200
  • isConnected.length == n 且每行长度为 n。
  • 矩阵对称，且每个城市都与自身相连。

核心洞察

每个省份恰好对应图中的一个连通分量。遍历所有城市，遇到尚未访问的城市时，省份数加一，并用 DFS 或 BFS 标记其可达城市。

过程

  1. 准备 visited 数组。
  2. 逐个检查城市是否已访问。
  3. 对新城市执行 DFS，沿矩阵中值为 1 的边继续访问。

边界

单个城市返回 1；没有直接相连的多个城市各自是一省；不要只统计直接边，否则会遗漏间接连通的城市。

复杂度

邻接矩阵需检查 n×n 个位置，时间 O(n²)。visited 数组与递归/队列最多 O(n) 额外空间。

替代方案

并查集也可以合并所有直接相连的城市，最后统计根节点数量；在需要不断加入边、反复查询连通性时尤其合适。

常见错误

  • 没有在递归一开始标记 visited，造成重复访问。
  • 只看上三角或只计算值为 1 的数量，而没有按分量计数。
  • 把“城市数”当作“省份数”。

参考实现

Java

class Solution {
    public int findCircleNum(int[][] isConnected) {
        boolean[] visited = new boolean[isConnected.length];
        int provinces = 0;
        for (int city = 0; city < isConnected.length; city++) {
            if (!visited[city]) { dfs(isConnected, visited, city); provinces++; }
        }
        return provinces;
    }
    private void dfs(int[][] graph, boolean[] visited, int city) {
        visited[city] = true;
        for (int next = 0; next < graph.length; next++)
            if (graph[city][next] == 1 && !visited[next]) dfs(graph, visited, next);
    }
}

var findCircleNum = function(isConnected) {
  const visited = Array(isConnected.length).fill(false);
  const dfs = (city) => {
    visited[city] = true;
    for (let next = 0; next < isConnected.length; next++)
      if (isConnected[city][next] && !visited[next]) dfs(next);
  };
  let provinces = 0;
  for (let city = 0; city < isConnected.length; city++)
    if (!visited[city]) { dfs(city); provinces++; }
  return provinces;
};

Python

class Solution:
    def findCircleNum(self, isConnected: List[List[int]]) -> int:
        seen = set()
        def dfs(city: int) -> None:
            seen.add(city)
            for nxt, linked in enumerate(isConnected[city]):
                if linked and nxt not in seen:
                    dfs(nxt)
        provinces = 0
        for city in range(len(isConnected)):
            if city not in seen:
                dfs(city)
                provinces += 1
        return provinces

C++

class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size(), provinces = 0;
        vector<bool> visited(n);
        function<void(int)> dfs = [&](int city) {
            visited[city] = true;
            for (int next = 0; next < n; ++next)
                if (isConnected[city][next] && !visited[next]) dfs(next);
        };
        for (int city = 0; city < n; ++city)
            if (!visited[city]) { dfs(city); ++provinces; }
        return provinces;
    }
};
