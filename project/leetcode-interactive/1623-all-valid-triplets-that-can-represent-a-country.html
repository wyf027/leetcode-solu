三人国家代表队

All Valid Triplets That Can Represent a Country

#1623 🔒 付费题 数据库 结果顺序不限

Problem

题意转述

官方题面为空 · 基于元数据与公开信息整理

一个国家有三所学校。现在要从 SchoolA、SchoolB、SchoolC 各选择一名学生组成代表队。输出中三列依次为 member_A、member_B、member_C，分别对应三所学校被选中的学生姓名。

有效条件：三人的 student_id 必须两两不同，并且 student_name 也必须两两不同。结果可按任意顺序返回。

student_id INT
student_name VARCHAR(20)

student_id INT
student_name VARCHAR(20)

约束

  • 三张表都包含 student_id 与 student_name 两列。
  • 在每张表内部，student_id 是主键，student_name 互不相同。
  • 不同学校之间可能出现相同学号或相同姓名，因此必须跨表检查。
  • 输出只需要学生姓名，列名固定为 member_A、member_B、member_C。

题解：三表 CROSS JOIN + 六个两两不等条件

核心洞察

先对三张学校表做笛卡尔积，得到“从每校各选一人”的全部候选。随后对三对成员 (A,B)、(A,C)、(B,C) 分别检查学号与姓名，共六个不等条件。最后只投影三个姓名并设置题目要求的别名。

完整过程

  1. 给三张表设置短别名 a、b、c。
  2. 使用 CROSS JOIN 生成全部 |A| × |B| × |C| 个候选三元组。
  3. 在 WHERE 中排除任意一对学号相同的候选。
  4. 再排除任意一对姓名相同的候选。
  5. 选择三人的姓名，依次命名为 member_A、member_B、member_C。

官方可提交语言：MySQL

SELECT
    a.student_name AS member_A,
    b.student_name AS member_B,
    c.student_name AS member_C
FROM SchoolA AS a
CROSS JOIN SchoolB AS b
CROSS JOIN SchoolC AS c
WHERE a.student_id <> b.student_id
  AND a.student_id <> c.student_id
  AND b.student_id <> c.student_id
  AND a.student_name <> b.student_name
  AND a.student_name <> c.student_name
  AND b.student_name <> c.student_name;

正确性说明

完备性：CROSS JOIN 枚举了从 A、B、C 三校各取一人的每一种组合，因此任何可能的有效代表队一定被枚举。

可靠性：对三对成员分别施加学号不等和姓名不等条件，所以保留下来的每个组合都满足学号两两不同、姓名两两不同。

综上，查询返回且仅返回所有有效三人代表队。

边界情况

  • 任一学校为空：笛卡尔积为空，结果自然为空。
  • 姓名不同但学号相同：仍须淘汰。
  • 学号不同但姓名相同：仍须淘汰。
  • 题目未要求排序，不应额外依赖输出顺序。

复杂度

设三表行数分别为 n、m、k。逻辑上检查 nmk 个候选，时间复杂度为 O(nmk)；除数据库执行计划和结果集外，查询本身只使用常数额外空间。输出在最坏情况下也可达到 Θ(nmk)。

替代方案

可以用逗号连接语法 FROM SchoolA a, SchoolB b, SchoolC c，或用带条件的 INNER JOIN 逐层过滤。显式 CROSS JOIN 更直接表达“先枚举，再筛选”，也不易把连接条件误认为表之间的主外键关系。

面试追问

  • 为什么要六个条件？三人共有三对关系，每对都要同时检查 ID 与姓名。
  • 能否只写 a.id <> b.id AND b.id <> c.id？不能，它没有排除 a.id = c.id。
  • 如果字段允许 NULL 呢？NULL <> value 的结果是 UNKNOWN；需先明确业务语义，再用 IS NULL 或空值安全比较补充规则。
  • 怎样优化大表？可把不等条件放进分层 JOIN 以尽早缩小中间结果，但所有有效输出本身仍可能是立方级。

常见错误

  • 只检查姓名或只检查学号，漏掉另一类冲突。
  • 只比较相邻的 A-B、B-C，忘记 A-C。
  • 使用 DISTINCT 代替业务筛选；它只能去掉重复输出行，无法验证成员身份。
  • 返回学生 ID 或错误的列别名，不符合输出契约。

import java.util.ArrayList;
import java.util.List;

public class Solution {
    public record Student(int studentId, String studentName) {}
    public record Triplet(String memberA, String memberB, String memberC) {}

    public static List<Triplet> findValidTriplets(
            List<Student> schoolA,
            List<Student> schoolB,
            List<Student> schoolC) {
        List<Triplet> result = new ArrayList<>();

        for (Student a : schoolA) {
            for (Student b : schoolB) {
                if (a.studentId() == b.studentId()
                        || a.studentName().equals(b.studentName())) {
                    continue;
                }
                for (Student c : schoolC) {
                    boolean idConflict = a.studentId() == c.studentId()
                            || b.studentId() == c.studentId();
                    boolean nameConflict = a.studentName().equals(c.studentName())
                            || b.studentName().equals(c.studentName());
                    if (!idConflict && !nameConflict) {
                        result.add(new Triplet(
                                a.studentName(), b.studentName(), c.studentName()));
                    }
                }
            }
        }
        return result;
    }
}
/**
 * @param {{student_id:number, student_name:string}[]} schoolA
 * @param {{student_id:number, student_name:string}[]} schoolB
 * @param {{student_id:number, student_name:string}[]} schoolC
 * @returns {{member_A:string, member_B:string, member_C:string}[]}
 */
function findValidTriplets(schoolA, schoolB, schoolC) {
  const result = [];

  for (const a of schoolA) {
    for (const b of schoolB) {
      if (a.student_id === b.student_id ||
          a.student_name === b.student_name) continue;

      for (const c of schoolC) {
        const idConflict = c.student_id === a.student_id ||
          c.student_id === b.student_id;
        const nameConflict = c.student_name === a.student_name ||
          c.student_name === b.student_name;

        if (!idConflict && !nameConflict) {
          result.push({
            member_A: a.student_name,
            member_B: b.student_name,
            member_C: c.student_name
          });
        }
      }
    }
  }
  return result;
}
from dataclasses import dataclass
from typing import List


@dataclass(frozen=True)
class Student:
    student_id: int
    student_name: str


@dataclass(frozen=True)
class Triplet:
    member_A: str
    member_B: str
    member_C: str


def find_valid_triplets(
    school_a: List[Student],
    school_b: List[Student],
    school_c: List[Student],
) -> List[Triplet]:
    result: List[Triplet] = []

    for a in school_a:
        for b in school_b:
            if (a.student_id == b.student_id or
                    a.student_name == b.student_name):
                continue

            for c in school_c:
                ids_are_distinct = len({
                    a.student_id, b.student_id, c.student_id
                }) == 3
                names_are_distinct = len({
                    a.student_name, b.student_name, c.student_name
                }) == 3
                if ids_are_distinct and names_are_distinct:
                    result.append(Triplet(
                        a.student_name, b.student_name, c.student_name
                    ))

    return result

struct Student {

    string studentName;

struct Triplet {
    string memberA;
    string memberB;
    string memberC;

vector<Triplet> findValidTriplets(
        const vector<Student>& schoolA,
        const vector<Student>& schoolB,
        const vector<Student>& schoolC) {
    vector<Triplet> result;

    for (const Student& a : schoolA) {
        for (const Student& b : schoolB) {
            if (a.studentId == b.studentId ||
                    a.studentName == b.studentName) {
                continue;
            }
            for (const Student& c : schoolC) {
                const bool idConflict = a.studentId == c.studentId ||
                    b.studentId == c.studentId;
                const bool nameConflict = a.studentName == c.studentName ||
                    b.studentName == c.studentName;

                if (!idConflict && !nameConflict) {
                    result.push_back({
                        a.studentName, b.studentName, c.studentName
                    });
                }
            }
        }
    }
    return result;
}
