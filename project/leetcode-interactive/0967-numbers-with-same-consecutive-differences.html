连续差相同的数字

Numbers With Same Consecutive Differences

MEDIUM

把数字看成一条逐位生长的路径。

题目

给定整数 n 和 k，返回所有恰好由 n 位组成，且任意相邻两位数字的绝对差都等于 k 的非负整数。结果顺序不限，且多位数不能有前导零。

示例 1
输入：n = 3, k = 7
输出：[181,292,707,818,929]
解释：070 含前导零，因此无效。
示例 2
输入：n = 2, k = 1
输出：[10,12,21,23,32,34,43,45,54,
      56,65,67,76,78,87,89,98]
示例 3
输入：n = 2, k = 0
输出：[11,22,33,44,55,66,77,88,99]
示例 4
输入：n = 2, k = 2
输出：[13,20,24,31,35,42,46,53,57,
      64,68,75,79,86,97]

约束

  • 2 ≤ n ≤ 9
  • 0 ≤ k ≤ 9
交互可视化 · n = 3, k = 7

数字分叉生长器

观察路径 1 → 8 → 1：每一步只检查末位加减 k，并丢弃超出 0…9 的候选。

使用上一步和下一步按钮浏览构造过程。

先自己想一想

若当前末位是 d，下一位最多有哪些候选？为什么 k = 0 时必须去重？

完整题解

核心洞察

从首位 1…9 出发。当前数字末位为 d 时，下一位只可能是 d-k 或 d+k；候选必须落在 0…9。当 k=0 时两个候选相同，只加入一次。

完整过程

  1. 把 1 到 9 放入当前层，天然排除前导零。
  2. 重复扩展 n-1 层；取每个数的末位，尝试两个合法候选。
  3. 每加入一位，用 num * 10 + nextDigit 得到新数。
  4. 第 n 层即为答案。

正确性证明

可靠性：初始首位非零；每次加入的位都在 0…9，且与原末位的差为 k，所以生成的每个数均合法。完备性：任意合法 n 位数的首位属于 1…9；其后每位必为前一位加 k 或减 k，算法在每层枚举所有合法选择，因此该数对应的路径不会遗漏。由两者可知算法恰好生成全部答案。

边界情况

  • k = 0：只扩展一次，避免重复。
  • k = 9：可行路径很少，例如 90、909。
  • 候选为 0 是允许的，只要它不是首位。

复杂度

最多有 9 个起点，每层最多二分，时间与输出规模一致，为 O(9·2^(n-1))；分层 BFS 的额外空间为 O(9·2^(n-1))。实际因数字边界会剪枝。

四语言实现

class Solution {
    public int[] numsSameConsecDiff(int n, int k) {
        List<Integer> cur = new ArrayList<>();
        for (int d = 1; d <= 9; d++) cur.add(d);
        for (int len = 1; len < n; len++) {
            List<Integer> next = new ArrayList<>();
            for (int num : cur) {
                int last = num % 10;
                if (last + k <= 9) next.add(num * 10 + last + k);
                if (k != 0 && last - k >= 0) next.add(num * 10 + last - k);
            }
            cur = next;
        }
        return cur.stream().mapToInt(Integer::intValue).toArray();
    }
}

                if (last + k <= 9) next.push_back(num * 10 + last + k);

替代方案

可用 DFS / 回溯，从每个首位递归生成后续位；空间可降为递归深度 O(n)（不计输出），逻辑与 BFS 相同。也能枚举所有 n 位数逐个检查，但搜索空间达到 9·10^(n-1)，没有利用局部约束。

面试追问

  • 若数字长度很大，无法放入整数类型怎么办？——用字符串维护路径。
  • 如何按升序返回？——最终排序，或严格控制分支访问次序。
  • 若允许首位为 0？——起始层加入 0，并明确返回的是定长字符串还是整数。

常见错误

  • 忘记取绝对差，同时只考虑加 k。
  • k=0 时加入两次同一后继。
  • 从 0 开始生成，产生伪 n 位数。
  • 把边界写成严格不等，漏掉数字 0 或 9。
