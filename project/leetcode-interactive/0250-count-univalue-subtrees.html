统计同值子树
Count Univalue Subtrees

每个节点等左右子树先报告“是否全同值”，再决定自己能否成为一棵同值子树。

题意

给定二叉树根节点 root，返回同值子树数量。同值子树是指该子树中的所有节点具有相同值。

约束
节点数量为 0 到 1000；−1000 ≤ Node.val ≤ 1000。

样例（公开题面转述）

输入root = [5, 1, 5, 5, 5, null, 5]输出4
输入root = []输出0
输入root = [5, 5, 5, 5, 5, null, 5]输出6

题解：后序 DFS 返回“这一棵是否同值”

函数 dfs(node) 返回布尔值：以 node 为根的子树是否同值。空节点视为 true；递归获得左右结果后，只有左右都同值且存在的孩子值都等于 node.val 时，当前子树才同值并使计数加一。

  1. 空节点返回 true，作为不限制父节点的中性条件。
  2. 先递归左右孩子——这是后序遍历。
  3. 任一孩子子树失败，或孩子根值不同于当前值，则返回 false。
  4. 否则当前子树成立，计数加一并返回 true。
为什么只比较孩子根值？左右递归已经保证孩子子树内部所有值统一；再保证孩子根等于当前根，就可推出整棵树值相同。

完整过程

样例中三个值为 5 的叶子先各计数一次；左子树根 1 的孩子为 5，因此它不统一；右子树根 5 与右孩子 5 构成第四棵；根 5 因左子树失败而不计数。

边界与复杂度

空树为 0；单个节点必为一棵同值子树；单侧孩子同样按存在的孩子比较。每个节点仅访问一次：时间 O(n)，递归栈 O(h)，最坏 O(n)。

替代方案

可让 DFS 同时返回“是否同值”和子树计数的结构体，避免闭包/成员变量；可读性更显式，但状态较多。后序布尔返回值是面试中最简洁的主线。

面试追问

若树很深，可改显式栈模拟后序遍历；若只判断根树是否同值，遇到第一处不等可短路，但本题仍须继续遍历以统计所有小子树。

常见错误

  • 在进入节点前就判断，尚未获得子树是否同值的信息。
  • 只比较左右孩子值，忘记确认它们各自子树内部已统一。
  • 把 null 当 false，导致只有一个孩子的同值子树被错误排除。
