赛车 Race Car

只有油门与换向，却要在无限数轴上寻找最短指令。先读懂赛车的状态变化，再到试驾台逐拍观察位置与速度。

01 · Briefing

题目说明

以下内容依据官方元数据准确转述，保留完整参数形式、示例与约束。

赛车从无限数轴的 position = 0 出发，初始速度为 speed = +1，允许驶入负坐标。指令序列只包含 A 与 R。

A

Accelerate · 加速

position += speed

speed *= 2

R

Reverse · 换向

正速度变为 -1，负速度变为 +1。

位置保持不变。

例如执行 AAR 后，位置依次为 0 → 1 → 3 → 3，速度依次为 1 → 2 → 4 → -1。

给定整数 target，返回恰好到达该位置所需的最短指令序列长度。

约束：1 <= target <= 104
示例 1 
输入：target = 3
输出：2
解释：最短指令序列为 "AA"。
位置：0 → 1 → 3
示例 2 
输入：target = 6
输出：5
解释：最短指令序列为 "AAARA"。
位置：0 → 1 → 3 → 7 → 7 → 6

Function signature

racecar(target: integer) → integer

只返回长度，不要求返回具体指令串。

    04 · Spoiler Gate

    准备好看题解了吗？

    题解会揭示状态压缩后的动态规划结构、两类最优路径、正确性论证与四种语言实现。建议先在上方试驾几组指令。

    Editorial · Dynamic Programming

    用完整加速段切分最短路径

    关键不是枚举每一个位置与速度，而是观察：每次换向之前，都可以把连续的 A 看成一个完整加速段。

    核心洞察

    连续执行 n 次 A 后，赛车会到达 2^n - 1，速度为 2^n。 对任意目标 t，取最小的 n 使 2^n - 1 ≥ t，首段只有三种有意义的结果：恰好命中、越过后回头、或提前一层回头再修正。

    状态定义

    dp[t] 表示从位置 0、速度 +1 出发，到达正目标 t 的最短指令数。 由于数轴左右对称，从某点以标准单位速度处理一段距离时，只需复用该距离的 dp 值。

    dp[0] = 0

    情况一：恰好命中或越过

    令 full = 2^n - 1。若 full == t，答案就是 n。 否则先用 n 个 A 到达 full，再用一个 R 调头，剩余距离为 full - t。

    dp[t] = n + 1 + dp[full - t]

    情况二：未到目标就回头

    先执行 n - 1 个 A 到达 near = 2^(n-1) - 1，R 后向左执行 m 个 A，再 R 转回右侧。 其中 0 ≤ m ≤ n - 2，向左距离为 back = 2^m - 1。

    remaining = t - (near - back) candidate = (n-1) + 1 + m + 1 + dp[remaining]

    完整过程

    1. 令 dp[0] = 0，从 1 到 target 递推。
    2. 为当前 t 找到最小 n，使 2^n - 1 ≥ t。
    3. 若恰好命中，直接记录 n。
    4. 先计算越过后回头的方案。
    5. 枚举提前回头方案中的 m，用所有候选值更新最小值。

    正确性说明

    对 t 归纳。设所有小于 t 的 dp 值均已正确。最短方案的第一段连续 A 若达到 t，则属于恰好命中；若越过 t，继续 A 只会离目标更远，因此第一次换向可视为在 full 处发生；若未越过，则第一段最多为 n-1 个 A，换向后连续向左的 A 数 m 必小于 n-1，否则会退回原点或更左，删去这段往返不会更差。

    因而最优解必被“越过后回头”或某个“提前回头”候选覆盖。每个候选的剩余距离都小于 t，可由归纳假设得到最优代价；取所有候选最小值即为 dp[t] 的最优值。

    复杂度与边界

    • 时间复杂度：O(target · log target)。
    • 空间复杂度：O(target)。
    • target = 1 时，一次 A 直接命中。
    • 当 target 本身是 2^n - 1 时，无需换向。
    • 题目上界 104，整数位移在四份实现的普通整型范围内。

    替代方案

    可以对 (position, speed) 做 BFS：按层扩展 A 与 R，第一个到达 target 的层数就是答案。它直观且便于构造具体指令，但必须裁剪位置与速度范围，状态量也明显大于本题的距离 DP。A* 可加入到目标的估价函数，工程复杂度更高。

    面试追问

    • 如果要求返回一条最短指令串，如何记录决策并回溯？
    • BFS 的安全边界应该如何证明，而不是凭经验设置？
    • 若 R 会保留速度绝对值而只翻转符号，状态与转移会怎样变化？
    • 能否用记忆化搜索表达同一递推？递归终止性如何保证？

    常见错误

    • 把 R 写成移动一步；实际上 R 只改变速度，不改变位置。
    • 提前回头时漏掉第二个 R，导致剩余路程方向错误。
    • m 枚举到 n-1，产生无收益的整段回退并破坏“小于 t”的递推关系。
    • 误把连续 n 次 A 的位置写成 2^n，正确值是 2^n - 1。

    Implementations

    四语言完整代码

    四份实现均遵循官方函数签名，并使用同一套自底向上的动态规划递推。

    JavaSolution.racecar
    class Solution {
    public int racecar(int target) {
        int[] dp = new int[target + 1];

        for (int t = 1; t <= target; t++) {
            int n = 1;
            while ((1 << n) - 1 < t) {
                n++;
            }

            int full = (1 << n) - 1;
            if (full == t) {
                dp[t] = n;
                continue;
            }

            dp[t] = n + 1 + dp[full - t];
            int near = (1 << (n - 1)) - 1;

            for (int m = 0; m <= n - 2; m++) {
                int back = (1 << m) - 1;
                int remaining = t - (near - back);
                int candidate = (n - 1) + 1 + m + 1
                        + dp[remaining];
                dp[t] = Math.min(dp[t], candidate);
            }
        }

        return dp[target];
    }
}
