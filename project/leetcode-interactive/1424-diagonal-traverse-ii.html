1424非付费题Diagonal Traverse II

对角线遍历 不是矩形，也有规律。

在参差不齐的二维列表中，沿左下到右上的方向逐条收集元素。先观察每个格子的坐标规律，再决定怎样把它们排成答案。

题目接口

输入一个不规则二维整数列表

findDiagonalOrder(nums: List<List<Integer>>) → int[]
难度中等
元素总数≤ 10⁵
目标复杂度O(N)
Problem

题意与约束

先理解规则，再打开题解。

准确转述

给定二维整数列表 nums。每一行长度可以不同，但都至少含有一个元素。请按对角线顺序返回全部数字：先处理坐标和较小的对角线；同一条对角线内，从行号较大的格子走向行号较小的格子，也就是从左下到右上。

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i].length ≤ 10⁵
  • 1 ≤ nums[i][j] ≤ 10⁹
  • nums 中的元素总数不超过 10⁵

Solution

按坐标和分桶

O(N) 时间 · O(N) 空间
r+c

核心洞察

坐标为 (r, c) 的元素属于编号 d = r + c 的对角线。同一条对角线里的 d 完全相同；答案按 d 从小到大排列。

逐行收集

从上到下扫描每一行，把 nums[r][c] 加入桶 buckets[r+c]。这样每个桶里的行号天然从小到大。

桶内逆序

题目要求同一条对角线从左下到右上，也就是行号从大到小。因此取出每个桶时逆序追加。

依次拼接

从 d = 0 开始依次展开所有桶，得到最终答案。每个元素只被加入和取出各一次。

Correctness

正确性证明

01 / 归属

不会放错对角线

每个元素只进入下标为 r+c 的桶。坐标和相等当且仅当两个位置位于本题定义的同一条对角线上。

02 / 桶间

对角线顺序正确

按桶编号递增输出，意味着先输出较小的坐标和，恰好符合题目从左上向右下推进对角线的顺序。

03 / 桶内

方向正确且完整

逐行扫描使桶内行号递增；逆序取桶使行号递减，即从左下到右上。所有元素各出现一次，因此结果完整且无重复。

Complexity & Edges

复杂度与边界

设全部元素数为 N。建桶与展开都遍历每个元素一次，时间复杂度 O(N)；桶和答案占用 O(N) 额外空间。

只有一行每行只有一个数行长极不均匀总元素 10⁵大整数值
Alternative

替代方案

排序：为每个元素记录 (r+c, -r, value) 并排序，写法直观，但时间为 O(N log N)。

队列：按遍历前沿维护每行的下一个元素，可做到 O(N)，但去重入队与边界处理更绕。分桶法更容易证明和实现。

class Solution {
    public int[] findDiagonalOrder(List<List<Integer>> nums) {
        int total = 0;
        List<List<Integer>> buckets = new ArrayList<>();

        for (int r = 0; r < nums.size(); r++) {
            total += nums.get(r).size();
            for (int c = 0; c < nums.get(r).size(); c++) {
                int d = r + c;
                while (buckets.size() <= d) {
                    buckets.add(new ArrayList<>());
                }
                buckets.get(d).add(nums.get(r).get(c));
            }
        }

        int[] answer = new int[total];
        int index = 0;
        for (List<Integer> bucket : buckets) {
            for (int i = bucket.size() - 1; i >= 0; i--) {
                answer[index++] = bucket.get(i);
            }
        }
        return answer;
    }
}

var findDiagonalOrder = function(nums) {
    const buckets = [];

    for (let r = 0; r < nums.length; r++) {
        for (let c = 0; c < nums[r].length; c++) {
            const d = r + c;
            if (!buckets[d]) buckets[d] = [];
            buckets[d].push(nums[r][c]);
        }
    }

    const answer = [];
    for (const bucket of buckets) {
        for (let i = bucket.length - 1; i >= 0; i--) {
            answer.push(bucket[i]);
        }
    }
    return answer;
};
class Solution:
    def findDiagonalOrder(self, nums: List[List[int]]) -> List[int]:
        buckets = []

        for r, row in enumerate(nums):
            for c, value in enumerate(row):
                d = r + c
                while len(buckets) <= d:
                    buckets.append([])
                buckets[d].append(value)

        answer = []
        for bucket in buckets:
            answer.extend(reversed(bucket))
        return answer
class Solution {
public:
    vector<int> findDiagonalOrder(vector<vector<int>>& nums) {
        vector<vector<int>> buckets;
        int total = 0;

        for (int r = 0; r < nums.size(); ++r) {
            total += nums[r].size();
            for (int c = 0; c < nums[r].size(); ++c) {
                int d = r + c;
                if (d == buckets.size()) buckets.push_back({});
                buckets[d].push_back(nums[r][c]);
            }
        }

        vector<int> answer;
        answer.reserve(total);
        for (const auto& bucket : buckets) {
            for (auto it = bucket.rbegin(); it != bucket.rend(); ++it) {
                answer.push_back(*it);
            }
        }
        return answer;
    }
};

Common Mistakes

常见错误

  • 把题目当作规则矩阵，直接访问不存在的列。
  • 只按 r+c 分组，却忘记桶内需要逆序。
  • 用每行最大长度预分配二维空间，造成不必要的内存浪费。
  • 误写成 LeetCode 498 的交替方向遍历；本题每条对角线方向固定。
  • 只用 nums.length² 分析复杂度，忽略真正的规模是元素总数 N。
