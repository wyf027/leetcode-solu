推理二叉树

从前序遍历与中序遍历中重建唯一的二叉树。先动手观察，再按需打开题解。

题意

给定二叉树的前序遍历 preorder 和中序遍历 inorder，构建二叉树并返回根节点。输入不含重复元素。

示例

preorder = [3,9,20,15,7]
inorder = [9,3,15,20,7]
输出：[3,9,20,null,null,15,7]

约束

节点数范围 [0, 5000]；每个值唯一；-3000 ≤ val ≤ 3000。

分步交互

准备观察根节点的定位。

前序的第一个元素一定是当前子树根；在中序中找到它，左右两侧分别就是左右子树。

[3, 9, 20, 15, 7]

inorder

点击“下一步”开始。

核心洞察

前序确定根的出现顺序；中序确定左右子树边界。预先用哈希表记录中序下标，可避免每次线性搜索。

过程

  1. 取前序指针指向的值作为根。
  2. 查表得到根在中序区间的位置。
  3. 递归构建左区间，再构建右区间。

边界与复杂度

区间为空时返回空；指针恰好消费每个节点。时间 O(n)，哈希表与递归栈空间 O(n)。

替代与追问

不建表会退化至 O(n²)；可追问后序加中序、重复值时为何不能唯一重建。

常见错误

  • 把中序根位置包含在子问题中，造成无限递归。
  • 先构建右子树，破坏前序消费顺序。
  • 未使用区间边界而复制数组，产生不必要的空间与时间消耗。

Python

class Solution:
    def buildTree(self, preorder, inorder):
        pos = {v:i for i,v in enumerate(inorder)}; p = 0
        def build(l, r):
            nonlocal p
            if l > r: return None
            v = preorder[p]; p += 1; m = pos[v]
            node = TreeNode(v); node.left = build(l,m-1); node.right = build(m+1,r)
            return node
        return build(0, len(inorder)-1)
