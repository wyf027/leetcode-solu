每段建筑物的平均高度

Average Height of Buildings in Each Segment

同一条街，多座建筑。怎样用最少的区间描述它们的平均高度？

A · h=2
B · h=4
街道起点 →区间右端点不计入建筑

先理解输入与输出，再按需打开页面底部题解。

题意与规则

给定二维整数数组 buildings，每项 [start, end, height] 表示一栋高度为 height、覆盖数轴 [start, end) 的建筑。某个位置可能被多栋建筑覆盖。

返回二维整数数组 street。每项 [left, right, average] 表示该半开区间内，所有覆盖建筑的高度之和除以建筑数量后向下取整的结果恒为 average。不要包含没有建筑的位置；区间互不重叠，数量应尽可能少。返回顺序不限。

平均的是建筑高度，不是最高建筑，也不是按建筑宽度加权。左右相接、取整后均值相同的区间需要合并；空白街道不能跨越。

函数契约

averageHeightOfBuildings(buildings: integer[][]) → integer[][]

约束

  • 1 ≤ buildings.length ≤ 10⁵
  • buildings[i].length == 3
  • 0 ≤ startᵢ < endᵢ ≤ 10⁸
  • 1 ≤ heightᵢ ≤ 10⁵

官方示例

01 · 两座建筑相交

输入：buildings = [[1,4,2],[3,9,4]]
输出：[[1,3,2],[3,4,3],[4,9,4]]

中间 [3,4) 同时覆盖两栋，均值为 3；两侧分别只有一栋。

02 · 覆盖变化，均值未变

输入：buildings = [[1,3,2],[2,5,3],[2,8,3]]
输出：[[1,3,2],[3,8,3]]

[2,3) 的均值为 ⌊8/3⌋=2，因此与前段连起来；[3,8) 的均值始终是 3。

03 · 相同高度也不能跨空白合并

输入：buildings = [[1,2,1],[5,6,1]]
输出：[[1,2,1],[5,6,1]]

[2,5) 没有建筑，不输出；两段保持分离。

题解 · 只在建筑端点停下

核心洞察

相邻两个不同建筑端点之间，覆盖建筑的集合不会变化。把每栋建筑变为“开始：高度 +h、数量 +1”和“结束：高度 −h、数量 −1”两个事件。排序后维护高度总和 S 与建筑数 C，即可得到整段的 ⌊S/C⌋。

完整过程
  1. 生成 2n 个事件 [坐标, 高度变化, 数量变化]，按坐标升序排列。
  2. 在坐标 x，一次处理完所有同坐标事件。这样 S、C 对应从 x 开始的半开区间。
  3. 若后面还有端点 y 且 C > 0，计算 a=⌊S/C⌋，得到 [x,y,a]；C=0 时跳过空白。
  4. 若最后一段右端点等于 x 且平均高度等于 a，就延长到 y，否则添加新段。直到事件耗尽。


正确性证明
状态不变式：在 x 处理完所有事件后，每栋满足 start≤x<end 的建筑恰好贡献一次高度和计数。开始事件加入它，结束事件移除它，所以 S 和 C 精确描述当前覆盖集合。
段值正确：在下一个端点 y 前没有任何建筑改变覆盖状态，故 [x,y) 的均值恒为 ⌊S/C⌋；C=0 恰好表示不应输出的空白。
段数最少：算法合并所有相邻且均值相同的小段。剩下的每道边界，要么两侧均值不同，要么夹着空白，都不能被合法区间跨越。因此结果正确且段数最少。


边界与常见错误
  • 同一点可同时有多个开始和结束事件，必须整组处理，不能生成零长度片段。
  • 合并比较取整后的平均数，而不是原始分数或覆盖集合。
  • 合并同时要求端点相接，否则会错误填上没有建筑的街道。
  • C=0 时跳过，避免除零。题目高度均为正数，因此整数除法等价于向下取整。
  • 总高度可达 10¹⁰：Java 用 long，C++ 用 long long。JavaScript Number 在此范围内可精确表示整数，不要使用会转为 32 位的位运算取整。
  • 建筑可无序、重叠或重复；每条记录都是独立建筑，重复项也要计数。


复杂度与替代方案
n 栋建筑产生 2n 个事件。排序 O(n log n)，扫描 O(n)；辅助空间 O(n)，输出至多 O(n) 段。若改为有序映射聚合同坐标事件，复杂度相同；坐标压缩＋两份差分数组也可实现。逐整数位置遍历依赖坐标上界 10⁸，不适合这里；堆可维护活跃建筑，但求和与计数用事件增减已足够。


面试追问
  • 均值改为精确分数？用约分分数或交叉相乘比较，注意乘积溢出。
  • 改为最高高度或中位数？两个累加器不够，需要支持删除的有序集合、堆或次序统计结构。
  • 在线增加、删除建筑？静态排序不能直接处理任意更新，需要按查询需求设计区间数据结构；本题静态扫描即可。


Java
import java.util.*;

class Solution {
    public int[][] averageHeightOfBuildings(int[][] buildings) {
        int[][] events = new int[buildings.length * 2][3];
        int k = 0;
        for (int[] b : buildings) {
            events[k++] = new int[]{b[0], b[2], 1};
            events[k++] = new int[]{b[1], -b[2], -1};
        }
        Arrays.sort(events, Comparator.comparingInt(e -> e[0]));
        List<int[]> ans = new ArrayList<>();
        long sum = 0;
        int count = 0, i = 0;
        while (i < events.length) {
            int x = events[i][0];
            while (i < events.length && events[i][0] == x) {
                sum += events[i][1];
                count += events[i][2];
                i++;
            }
            if (i == events.length || count == 0) continue;
            int y = events[i][0], avg = (int) (sum / count);
            int[] last = ans.isEmpty() ? null : ans.get(ans.size() - 1);
            if (last != null && last[1] == x && last[2] == avg) {
                last[1] = y;
            } else {
                ans.add(new int[]{x, y, avg});
            }
        }
        return ans.toArray(new int[ans.size()][]);
    }
}

/**
 * @param {number[][]} buildings
 * @return {number[][]}

var averageHeightOfBuildings = function(buildings) {
    const events = [];
    for (const [l, r, h] of buildings) {
        events.push([l, h, 1], [r, -h, -1]);
    }
    events.sort((a, b) => a[0] - b[0]);
    const ans = [];
    let sum = 0, count = 0, i = 0;
    while (i < events.length) {
        const x = events[i][0];
        while (i < events.length && events[i][0] === x) {
            sum += events[i][1];
            count += events[i][2];
            i++;
        }
        if (i === events.length || count === 0) continue;
        const y = events[i][0], avg = Math.floor(sum / count);
        const last = ans[ans.length - 1];
        if (last && last[1] === x && last[2] === avg) {
            last[1] = y;
        } else {
            ans.push([x, y, avg]);
        }
    }
    return ans;
};


Python
from typing import List

class Solution:
    def averageHeightOfBuildings(self, buildings: List[List[int]]) -> List[List[int]]:
        events = []
        for left, right, height in buildings:
            events.append((left, height, 1))
            events.append((right, -height, -1))
        events.sort()
        ans = []
        total = count = i = 0
        while i < len(events):
            x = events[i][0]
            while i < len(events) and events[i][0] == x:
                total += events[i][1]
                count += events[i][2]
                i += 1
            if i == len(events) or count == 0:
                continue
            y = events[i][0]
            avg = total // count
            if ans and ans[-1][1] == x and ans[-1][2] == avg:
                ans[-1][1] = y
            else:
                ans.append([x, y, avg])
        return ans


C++
#include <algorithm>
#include <array>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> averageHeightOfBuildings(vector<vector<int>>& buildings) {
        vector<array<int, 3>> events;
        for (const auto& b : buildings) {
            events.push_back({b[0], b[2], 1});
            events.push_back({b[1], -b[2], -1});
        }
        sort(events.begin(), events.end());
        vector<vector<int>> ans;
        long long sum = 0;
        int count = 0;
        size_t i = 0;
        while (i < events.size()) {
            int x = events[i][0];
            while (i < events.size() && events[i][0] == x) {
                sum += events[i][1];
                count += events[i][2];
                ++i;
            }
            if (i == events.size() || count == 0) continue;
            int y = events[i][0], avg = static_cast<int>(sum / count);
            if (!ans.empty() && ans.back()[1] == x && ans.back()[2] == avg) {
                ans.back()[1] = y;
            } else {
                ans.push_back({x, y, avg});
            }
        }
        return ans;
    }
};
