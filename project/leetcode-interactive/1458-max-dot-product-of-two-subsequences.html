两个子序列的最大点积

从两组数中各挑出一个保持相对顺序、长度相同且非空的子序列，让对应元素乘积之和尽可能大。

Problem

题意与规则

给定整数数组 nums1 与 nums2，分别选择长度相同的非空子序列。把两个子序列中同一位置的数字相乘并求和，返回所有合法选择中的最大值。

什么是子序列？

可以删除原数组中的任意元素，但保留下来的元素不能改变相对顺序。例如 [2,3,5] 是 [1,2,3,4,5] 的子序列。

点积如何计算？

若两个所选子序列为 a、b，共同长度为 k，则点积为 Σ a[i] × b[i]（0 ≤ i < k）。

Complete solution

动态规划：让“必须非空”进入状态

核心洞察

每次处理一对末尾元素时，最优答案只有四类来源：单独用当前乘积开启子序列；把当前乘积接到更短的合法答案后；跳过 nums1 当前元素；或跳过 nums2 当前元素。

关键是不能把空子序列当成答案。状态初值使用负无穷，而不是 0；这样全为负数的场景也会保留真正的最大负值。

状态与转移

令 dp[i][j] 表示只使用两个数组前 i、前 j 个元素，能够形成的两个等长非空子序列的最大点积。令 p = nums1[i−1] × nums2[j−1]。

dp[i][j] = max(p, dp[i−1][j−1] + p, dp[i−1][j], dp[i][j−1])

完整过程

  1. 建立 (m+1) × (n+1) 的表，所有位置初始化为负无穷；第 0 行与第 0 列代表无法组成非空配对。
  2. 枚举每个 i = 1..m 与 j = 1..n，计算当前乘积 p。
  3. 用 p 单独开始，或从左上角状态继续配对；同时与“跳过一侧当前元素”的两个状态比较。
  4. 填完表后，dp[m][n] 已覆盖所有在完整数组内的合法选择，即为答案。

正确性证明

归纳命题：每个 dp[i][j] 都等于两个前缀内等长非空子序列的最大点积。

基础：i=0 或 j=0 时无法各选至少一个元素，设为负无穷准确表示不合法。

归纳：任取前缀内的最优解。若它同时使用两个末尾元素，则它要么只有这一对（值为 p），要么去掉这一对后是左上前缀内的合法解（值至多为 dp[i−1][j−1]+p）。若没有同时使用两个末尾元素，则至少跳过其中一个，答案至多为上方或左方状态。转移枚举了四类并都能构造出合法解，因此取最大值恰为最优值。

结论：归纳成立，最终状态给出全数组上的正确答案。

边界与复杂度

  • 两数组任一长度为 1：仍可由“单独开启”分支得到合法答案。
  • 所有乘积都为负：负无穷初始化防止空选择伪造 0。
  • 含 0：0 可以成为合法答案，但只有在确实选择了一对 0 乘积时。
  • 时间复杂度：O(mn)。
  • 空间复杂度：二维实现为 O(mn)；滚动数组可降为 O(n)。

class Solution {
    public int maxDotProduct(int[] nums1, int[] nums2) {
        int m = nums1.length, n = nums2.length;
        int negInf = Integer.MIN_VALUE / 4;
        int[][] dp = new int[m + 1][n + 1];

        for (int i = 0; i <= m; i++) {
            java.util.Arrays.fill(dp[i], negInf);
        }

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                int product = nums1[i - 1] * nums2[j - 1];
                int pair = Math.max(product, dp[i - 1][j - 1] + product);
                dp[i][j] = Math.max(pair,
                        Math.max(dp[i - 1][j], dp[i][j - 1]));
            }
        }
        return dp[m][n];
    }
}

替代方案

滚动数组：只保留上一行和当前行，将空间降为 O(n)。更新当前行时仍需保留左方值和上一行左上值；实现更省空间，但更容易写错覆盖顺序。

记忆化搜索：用 (i,j,started) 描述位置与是否已经选择。逻辑直观，但状态更多、递归开销更高；在长度 500 时迭代 DP 更稳妥。

常见错误

错误 1：允许空答案。
把整张表初始化为 0 会让示例 3 错误返回 0。必须用负无穷表示“不存在非空选择”。
错误 2：只写左上转移。
最优子序列未必使用当前元素，还必须允许分别跳过 nums1[i−1] 或 nums2[j−1]。
错误 3：遗漏单独开启。
若只计算 dp[i−1][j−1]+p，就无法从不合法边界开始形成第一对。
错误 4：混淆子数组。
子序列不要求连续，但相对顺序不能变化，不能把数组排序后再配对。
