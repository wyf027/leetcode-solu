01 / 题意与数据契约

从积分变动，得到名次变动

给定球队原积分表 TeamPoints 和积分增量表 PointsChange。每队的新积分是原积分加上对应增量。旧榜和新榜都按积分降序排列；积分相同则按国家名称的字典序升序排列，名次从 1 开始。

返回每队的 team_id、name 和 rank_diff。名次变化定义为「原名次 − 新名次」：正数代表上升，负数代表下降，0 代表不变。结果顺序任意。

TeamPoints

字段类型含义
team_idINT球队 ID
nameVARCHAR(100)国家名称
pointsINT原积分

PointsChange

字段类型含义
team_idINT球队 ID
points_changeINT积分增量

约束

  • 两张表中的 team_id 各自唯一；不同球队代表不同国家。
  • TeamPoints 中每个 ID 都出现在 PointsChange 中。
  • points_change 可以为正数、负数或 0。
  • 公开题面没有列出行数、积分和增量的具体上下限；不额外假设数值范围。字段类型及名称长度来自官方建表元数据。

05 / 独立题解

准备好了，再揭开思路

核心洞察、正确性与五份完整实现。

两次确定名次，按球队对齐相减

核心洞察

积分变动是每队的独立属性，名次变动却依赖全体球队。保留旧积分和新积分，按完整规则分别排名，再按同一 ID 对齐即可。

完整过程

  1. 按 team_id 连接两表，确保增量归属正确。
  2. 按 points 降序、name 升序生成旧名次。
  3. 按 points + points_change 降序、name 升序生成新名次。
  4. 输出同一行的旧名次减新名次，无须执行 UPDATE。

旧榜：Senegal → Croatia → Algeria → New Zealand。新榜：Senegal → Algeria → Croatia → New Zealand。Algeria：3 − 2 = +1；Croatia：2 − 3 = −1。

正确性

由唯一 ID 和完整覆盖约束，连接后每队恰好一行且使用自己的增量，所以新积分准确。两个窗口排序分别等同于旧榜、新榜的官方比较规则。国家名称不同，完整排序键无并列，因此编号就是唯一名次。逐行相减满足变化量定义，且每队恰输出一次，故结果完整、无重复且数值正确。

边界与常见错误

  • 同分需比较名称，两次排序都不能漏掉 name ASC；不能用 ID 代替。
  • 差值为旧减新，涨分不保证升名次。全零增量或单队时名次保持不变。
  • 不要 PARTITION BY team_id，否则每队的分区只有一行，全部排第 1。
  • MySQL 窗口编号显式转 SIGNED 再相减，允许得到负数。
  • 题目保证唯一且覆盖，所以无需汇总变更或用默认 0 补缺失值；现实业务若不满足，必须先定义处理规则。
  • 本地四语言按普通字符串字典序演示。数据库 collation 可能对大小写、重音和 Unicode 使用不同规则，跨环境应统一比较语义。
  • 空输入若被允许，自然返回空结果；题面未明确给出最小行数。积分计算应使用足够宽的整数类型。

复杂度

设 TeamPoints 有 n 行、PointsChange 有 m 行。常见哈希或索引连接加两次排序的估计时间为 O(m + n log n)，辅助空间 O(m + n)。当两表均为同样的 n 支球队时，可简写为 O(n log n) 时间、O(n) 空间。SQL 实际成本由执行计划、索引、排序落盘决定；四语言参考使用排序副本和映射。

替代方案

完整排序键唯一时，RANK、DENSE_RANK 与 ROW_NUMBER 的结果相同。可以分别用两个 CTE 生成榜单后按 ID 连接。无窗口函数时，统计比当前球队更靠前的队数再加 1 也正确，但朴素相关比较为 O(n²)。

面试追问

  • 同分必须并列怎么办？ 去掉名称作为排位依据，再根据是否跳号选择 RANK 或 DENSE_RANK，属于规则变更。
  • 同队有多条变更怎么办？ 先按 ID 汇总增量，避免连接后重复球队。
  • 缺失变更怎么办？ 先确认是否视作 0；若是，才使用 LEFT JOIN 和 COALESCE。
  • 大表如何优化？ 先分析执行计划。ID 索引帮助连接，新积分的表达式排序通常仍需工作空间，不能仅凭索引承诺消除排序。

MySQL 8 · 官方可提交语言

SELECT
    t.team_id,
    t.name,
    CAST(ROW_NUMBER() OVER (
        ORDER BY t.points DESC, t.name ASC
    ) AS SIGNED)
    - CAST(ROW_NUMBER() OVER (
        ORDER BY t.points + c.points_change DESC, t.name ASC
    ) AS SIGNED) AS rank_diff
FROM TeamPoints AS t
JOIN PointsChange AS c ON t.team_id = c.team_id;

Java · 本地语义参考

import java.util.*;

public class Solution {
    public record Team(int id, String name, long points) {}
    public record Change(int id, long delta) {}
    public record Result(int team_id, String name, int rank_diff) {}

    // Java 17+；输入遵守唯一性与更新覆盖约束。
    public static List<Result> globalRankings(
            List<Team> teams, List<Change> changes) {
        Map<Integer, Long> delta = new HashMap<>();
        for (Change c : changes) delta.put(c.id(), c.delta());
        List<Team> before = new ArrayList<>(teams);
        List<Team> after = new ArrayList<>(teams);
        before.sort(Comparator.comparingLong(Team::points)
            .reversed().thenComparing(Team::name));
        after.sort(Comparator.<Team>comparingLong(
            t -> t.points() + delta.get(t.id()))
            .reversed().thenComparing(Team::name));
        Map<Integer, Integer> oldRank = new HashMap<>();
        for (int i = 0; i < before.size(); i++)
            oldRank.put(before.get(i).id(), i + 1);
        List<Result> result = new ArrayList<>();
        for (int i = 0; i < after.size(); i++) {
            Team t = after.get(i);
            result.add(new Result(t.id(), t.name(),
                oldRank.get(t.id()) - (i + 1)));
        }
        return result;
    }
}

JavaScript · 本地语义参考

// teams: [{team_id, name, points}]
// changes: [{team_id, points_change}]
// 前提：ID 唯一、更新齐全，积分及其和为安全整数。
function globalRankings(teams, changes) {
  const delta = new Map(changes.map(c => [c.team_id, c.points_change]));
  const byName = (a, b) =>
    a.name < b.name ? -1 : a.name > b.name ? 1 : 0;
  const before = [...teams].sort((a, b) =>
    b.points - a.points || byName(a, b));
  const after = [...teams].sort((a, b) =>
    (b.points + delta.get(b.team_id)) -
    (a.points + delta.get(a.team_id)) || byName(a, b));
  const oldRank = new Map(before.map((t, i) => [t.team_id, i + 1]));
  return after.map((t, i) => ({
    team_id: t.team_id, name: t.name,
    rank_diff: oldRank.get(t.team_id) - (i + 1)
  }));
}

Python · 本地语义参考

def global_rankings(teams, changes):
    """字典列表输入；ID 唯一，每队都有对应更新。"""
    delta = {c["team_id"]: c["points_change"] for c in changes}
    before = sorted(teams, key=lambda t: (-t["points"], t["name"]))
    after = sorted(teams, key=lambda t: (
        -(t["points"] + delta[t["team_id"]]), t["name"]))
    old_rank = {t["team_id"]: i for i, t in enumerate(before, 1)}
    return [
        {"team_id": t["team_id"], "name": t["name"],
         "rank_diff": old_rank[t["team_id"]] - i}
        for i, t in enumerate(after, 1)
    ]

C++ · 本地语义参考

#include <algorithm>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Team { int team_id; string name; long long points; };
struct Change { int team_id; long long points_change; };
struct Result { int team_id; string name; int rank_diff; };

// 唯一 ID、更新齐全；积分及和在 long long 范围内。
vector<Result> globalRankings(const vector<Team>& teams,
                             const vector<Change>& changes) {
    unordered_map<int, long long> delta;
    for (const auto& c : changes) delta[c.team_id] = c.points_change;
    auto before = teams, after = teams;
    sort(before.begin(), before.end(), [](const Team& a, const Team& b) {
        return a.points != b.points ? a.points > b.points : a.name < b.name;
    });
    sort(after.begin(), after.end(), [&](const Team& a, const Team& b) {
        auto pa = a.points + delta.at(a.team_id);
        auto pb = b.points + delta.at(b.team_id);
        return pa != pb ? pa > pb : a.name < b.name;
    });
    unordered_map<int, int> oldRank;
    for (int i = 0; i < static_cast<int>(before.size()); ++i)
        oldRank[before[i].team_id] = i + 1;
    vector<Result> result;
    for (int i = 0; i < static_cast<int>(after.size()); ++i) {
        const auto& t = after[i];
        result.push_back({t.team_id, t.name, oldRank.at(t.team_id) - (i + 1)});
    }
    return result;
}
