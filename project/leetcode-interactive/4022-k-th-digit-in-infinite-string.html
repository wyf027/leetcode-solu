无限字符串里第 K 个数字

不构造无限串：先定位 10 个数为一组的块，再在块内还原方向与字符。

题意

把正整数按块拼接：块 b 含 10b…10b+9。偶数块升序、奇数块降序。开头是 123456789 191817… 202122… 393837…。返回第 k 个字符（从 1 开始）。

约束：1 ≤ k ≤ 10¹⁵。首块只写 1…9，不写前导 0。

隐藏题解：三步定位
  1. 先消费开头的 9 个一位数字。
  2. 之后，d 位数对应的块数量为 9 × 10^(d-2)；每块固定贡献 10d 个字符。
  3. 块内偏移给出第几个数与该数的第几个字符；奇数块把编号 t 映射成 9-t。

交互定位器

按 Enter 或点击按钮计算；不依赖网络。

准备就绪。

过程示例：k = 15

阶段 计算 结论
首块 15 − 9 = 6 进入两位数块
块 每块 10 × 2 = 20 位，偏移 6 b = 1（奇数块）
块内 t = ⌊5 / 2⌋ = 2，字符下标 1 奇数块第 2 个数为 19 − 2 = 17，取 7

洞察、边界与复杂度

  • 方向只改变块内的数序，不改变块的长度；定位可先忽略方向。
  • 边界：k ≤ 9 直接返回 k；块边界的偏移要先转为 0-based。
  • 复杂度：最多遍历 15 个位数层，时间 O(log₁₀k)，额外空间 O(1)。
  • 替代：二分块号也可行，但必须编写“前缀总长度”函数；分位数枚举更短、更不易溢出。

常见错误

  • 把 k 当 0-based，导致每个边界错一位。
  • 遗漏首块没有 0，误按 10 位扣除。
  • 奇数块仍用 10b+t，忘记反转为 10b+9-t。

可追问

若每块大小改为 M，如何泛化？若每个块还要按任意置换输出，哪一步需要替换？能否同时返回对应的整数与块号？

测试清单

快速生成模式：UI、算法对拍、四语言编译和交互验收待补

  • k=1 → 1：首字符。
  • k=4 → 4：题例。
  • k=11 → 9：进入反向块的首个数 19。
  • k=15 → 7：题例，块内反向。
  • k=9 → 9、k=10 → 1：首块与块 1 的交界。
  • k=10¹⁵：只验证范围与 64 位计算，不生成字符串。

JavaScript 使用 BigInt；Java/C++ 使用 long，Python 整数可自动扩展。

四种语言实现

Java 
class Solution {
  public int kthDigit(long k) {
    if (k <= 9) return (int) k;
    k -= 9; long start = 1, count = 9; int d = 2;
    while (k > count * 10 * d) { k -= count * 10 * d; start += count; count *= 10; d++; }
    long block = start + (k - 1) / (10 * d), in = (k - 1) % (10 * d);
    long n = 10 * block + (block % 2 == 0 ? in / d : 9 - in / d);
    return Long.toString(n).charAt((int)(in % d)) - '0';
  }
}
JavaScript 
function kthDigit(k) {
  k = BigInt(k); if (k <= 9n) return Number(k);
  k -= 9n; let start = 1n, count = 9n, d = 2n;
  while (k > count * 10n * d) { k -= count * 10n * d; start += count; count *= 10n; d++; }
  const block = start + (k - 1n) / (10n * d), inside = (k - 1n) % (10n * d);
  const n = 10n * block + (block % 2n === 0n ? inside / d : 9n - inside / d);
  return Number(n.toString()[Number(inside % d)]);
}

class Solution { public:
  int kthDigit(long long k) {
    if (k <= 9) return k; k -= 9;
    long long start=1, count=9; int d=2;
    while (k > count*10*d) k -= count*10*d, start += count, count *= 10, ++d;
    long long block=start+(k-1)/(10*d), in=(k-1)%(10*d);
    long long n=10*block+(block%2==0 ? in/d : 9-in/d);
    return to_string(n)[in%d]-'0';
  }
