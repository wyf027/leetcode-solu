难度 · Medium 非付费题 数组 前缀和 滑动窗口

Problem

题目说明

给定整数数组 nums 和整数 x。一次操作可以移除当前数组最左端或最右端的一个元素，并把该元素的值从 x 中减去；移除会改变后续可操作的数组。

如果能够让 x 恰好变为 0，返回所需的最少操作次数；如果做不到，返回 -1。

minOperations(nums: integer[], x: integer) -> integer

约束

  • 1 <= nums.length <= 10^5
  • 1 <= nums[i] <= 10^4
  • 1 <= x <= 10^9

数组元素均为正整数；答案要求“恰好”为 0。

示例 1

输入nums = [1,1,4,2,3], x = 5

输出2

移除最右侧的 3 和 2，两次操作后 x 恰好变为 0。

示例 2

输入nums = [5,6,7,8,9], x = 4

输出-1

无论从哪一端开始，都无法让 x 恰好变为 0。

示例 3

输入nums = [3,2,20,1,1,3], x = 10

输出5

移除左侧两个元素与右侧三个元素，共 5 次。

Core Insight

把“移除两端”反过来看

所有被移除的元素必然构成一个前缀和一个后缀；没有被移除的元素则是一段连续的中间子数组。设数组总和为 total，移除元素之和必须为 x，因此被保留下来的连续子数组之和必须为 total - x。

最少移除次数 = n - 和为 (total - x) 的最长连续子数组长度

由于 nums[i] 全是正数，窗口右端扩展时区间和只会增大，左端收缩时只会减小，因此可以在线性时间内用滑动窗口寻找最长目标区间。

完整过程

  1. 计算 target = total - x。
  2. 若 target < 0，数组总和还不够减去 x，直接返回 -1。
  3. 若 target == 0，只能不保留任何元素，返回 n。
  4. 令左右指针都从数组左端开始；右指针逐个加入元素。
  5. 当窗口和大于 target 时，不断右移左指针并减去离开的元素。
  6. 窗口和等于 target 时，更新最长长度。扫描结束后返回 n - maxLength；从未命中则返回 -1。

示例 1 复盘

total = 11，所以保留区间的目标和是 11 - 5 = 6。

扫描得到最长区间 [1,1,4]，长度为 3；数组长度为 5，因此答案是 5 - 3 = 2。

复杂度
时间 O(n)：每个元素最多进入、离开窗口各一次。
额外空间 O(1)。

关键边界

  • x > total：返回 -1。
  • x == total：移除全部 n 个元素。
  • 不存在目标和窗口：返回 -1。
  • 整个数组就是目标窗口：答案为 0；不过本题 x 至少为 1，因此实际不会发生。

正确性证明

  1. 等价性：任意合法操作最终移除一个前缀和一个后缀，它们之间剩下连续子数组。移除和为 x 当且仅当剩余和为 total - x。
  2. 最优性转换：操作数等于 n 减去剩余子数组长度。因此最小化操作数，等价于最大化目标和连续子数组的长度。
  3. 窗口完备性：所有元素为正。对每个右端点，若窗口和过大，左端只能右移；这个过程不会错过以该右端点结尾的目标和窗口。命中时记录最长长度，扫描后得到全局最长合法窗口。
  4. 结论：算法返回 n 减去该最长长度，所以得到最少操作数；若不存在合法窗口，则原问题也无解。

替代方案

前缀和 + 哈希表：记录每个前缀和首次出现的位置，再查找差值以获得最长目标和子数组。它适用于包含负数的推广版本，时间 O(n)、空间 O(n)。

枚举左侧 + 二分右侧：利用正数前缀和的单调性搜索互补后缀，通常为 O(n log n)，不如本题的 O(n) 滑窗直接。

常见错误
贪心地每次删除较大的一端并不正确；局部选择无法保证最终恰好凑出 x。还要避免只检查前缀或只检查后缀。

/**
 * @param {number[]} nums
 * @param {number} x
 * @return {number}
 */
var minOperations = function(nums, x) {
    const total = nums.reduce((sum, value) => sum + value, 0);
    const target = total - x;

    if (target < 0) return -1;
    if (target === 0) return nums.length;

    let left = 0;
    let windowSum = 0;
    let maxLength = -1;

    for (let right = 0; right < nums.length; right++) {
        windowSum += nums[right];

        while (left <= right && windowSum > target) {
            windowSum -= nums[left++];
        }

        if (windowSum === target) {
            maxLength = Math.max(maxLength, right - left + 1);
        }
    }

    return maxLength === -1 ? -1 : nums.length - maxLength;
};

Interview Follow-ups

面试追问

如果数组中允许负数呢？

滑动窗口失去单调性。改用前缀和 + 哈希表寻找和为 target 的最长子数组。

为什么记录最长而不是最短？

保留越多，移除越少；操作数等于 n 减去保留长度。

能直接模拟两端选择吗？

可以枚举前缀并匹配后缀，但要维护查找结构；反向转化后的滑窗更简洁。

如何处理 target 为 0？

正数数组没有非空零和区间，只能保留空区间，因此需要移除全部元素。
