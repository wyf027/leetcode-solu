Problem brief

三只接口，一条铁律

实现整数减法、乘法和除法；程序只允许使用加法运算符与逻辑运算符，可以出现正负常量，禁止位运算。 输入保证有效，除数不会为 0；同一用例中的方法调用不超过 1000 次。

Operations 需要支持

构造函数不接收参数，三个公开方法均接收两个 32 位整数并返回整数结果。

  • minus(a, b)返回 a − b
  • multiply(a, b)返回 a × b
  • divide(a, b)返回向 0 截断的 a ÷ b

题解

核心洞察、完整过程、边界、复杂度、替代方案与四语言代码默认收起。

Core insight

把禁用运算拆成可复用脉冲

1

先造一个安全取反器

对正数使用负步长，对负数使用正步长；步长每次用自身相加翻倍，再从大到小贪心拼出相反数。 全程不直接写变量的负号，因此能安全处理最小 32 位整数。

2

乘法是选中若干倍增项

同时生成 x, x+x, 4x… 和计数 1, 2, 4…， 由大到小选取计数不超过乘数的项，把对应加数累加即可。

3

除法是消耗若干倍增块

生成除数的倍增块，维护已消耗量；从大到小尝试加入，不超过被除数就接受，并把对应倍数加入商。 未被消耗的部分自然就是余数。

4

最后统一恢复符号

主计算都在非负绝对值上进行，异号时仅对最终结果调用一次取反器。除法只累计完整块，因此自动向 0 截断。

Full process

完整过程

  1. 01
    negate(value)先按输入符号选择常量步长 1 或 -1，建立不越过 0 的倍增表。
  2. 02
    由大到小消耗尝试把每个步长加到原值；仍未跨过 0 就接受，同时把该步长加入结果。
  3. 03
    minus(a, b)直接返回 a + negate(b)，减法已经降解成一次取反与一次加法。
  4. 04
    multiply(a, b)取两数的非负大小，用较小者控制倍增表长度，再按计数贪心选项。
  5. 05
    divide(a, b)把除数与对应倍数同步翻倍，由大到小加入“已消耗量”和“商”。
  6. 06
    恢复符号若两个输入异号，对乘积或商调用 negate；否则直接返回。

边界条件

  • 任一乘数为 0，乘积立即为 0。
  • 被除数绝对值小于除数绝对值，商为 0。
  • 除法分母由题目保证不为 0。
  • 中间值使用更宽整数，取反 -2147483648 不溢出。
  • 除法只接收完整倍增块，负数结果自然向 0 截断。

常见错误

  • 直接写 -value，偷偷使用了题目禁止的运算。
  • 把最小整数转成正 32 位整数，立刻溢出。
  • 除法对负数使用向下取整，误把 5 / -2 算成 -3。
  • 乘法逐次累加，极值和 1000 次调用下会超时。
  • 使用移位或按位与判断奇偶，违反禁用位运算的限制。

替代方案

最朴素方案是循环加 1 或 -1，但一次操作可能需要十亿级循环；递归减半通常会借用除法或移位。 倍增表只用加法，却仍把核心步骤压到对数级，是面试中最稳妥的主线。

面试追问

  • 若连数组也不能用，如何用递归保存倍增层级？
  • 若结果需要饱和到 32 位范围，应在哪一步判断？
  • 如何把倍增表缓存起来，优化同一对象的 1000 次调用？
  • 为什么“只接受完整除数块”恰好得到向 0 截断？

import java.util.ArrayList;
import java.util.List;

class Operations {
    public Operations() {}

    private long negate(long value) {
        if (value == 0) return 0;
        boolean positive = value > 0;
        List<Long> steps = new ArrayList<>();
        long step = positive ? -1 : 1;

        while (true) {
            steps.add(step);
            long doubled = step + step;
            long candidate = value + doubled;
            if (positive ? candidate < 0 : candidate > 0) break;
            step = doubled;
        }

        long result = 0;
        for (int i = steps.size() + -1; i >= 0; i += -1) {
            long candidate = value + steps.get(i);
            if (positive ? candidate >= 0 : candidate <= 0) {
                value = candidate;
                result += steps.get(i);
            }
        }
        return result;
    }

    private long magnitude(long value) {
        return value < 0 ? negate(value) : value;
    }

    public int minus(int a, int b) {
        return (int) (a + negate(b));
    }

    public int multiply(int a, int b) {
        if (a == 0 || b == 0) return 0;
        long left = magnitude(a);
        long right = magnitude(b);
        if (left < right) {
            long temp = left;
            left = right;
            right = temp;
        }

        List<Long> addends = new ArrayList<>();
        List<Long> counts = new ArrayList<>();
        long addend = left;
        long count = 1;
        while (count <= right) {
            addends.add(addend);
            counts.add(count);
            count += count;
            addend += addend;
        }

        long used = 0;
        long result = 0;
        for (int i = counts.size() + -1; i >= 0; i += -1) {
            if (used + counts.get(i) <= right) {
                used += counts.get(i);
                result += addends.get(i);
            }
        }
        return (int) ((a < 0) != (b < 0) ? negate(result) : result);
    }

    public int divide(int a, int b) {
        long dividend = magnitude(a);
        long divisor = magnitude(b);
        if (dividend < divisor) return 0;

        List<Long> chunks = new ArrayList<>();
        List<Long> multiples = new ArrayList<>();
        long chunk = divisor;
        long multiple = 1;
        while (chunk <= dividend) {
            chunks.add(chunk);
            multiples.add(multiple);
            chunk += chunk;
            multiple += multiple;
        }

        long used = 0;
        long quotient = 0;
        for (int i = chunks.size() + -1; i >= 0; i += -1) {
            if (used + chunks.get(i) <= dividend) {
                used += chunks.get(i);
                quotient += multiples.get(i);
            }
        }
        return (int) ((a < 0) != (b < 0) ? negate(quotient) : quotient);
    }
}
