迷宫 The Maze

球不会停在你松手的位置。它会一直滚到墙前——真正需要判断的是：终点能否成为某一次滚动的停止点。

题号 490 MEDIUM 付费题 DFS · BFS · Array · Matrix
Problem

题意

给定一个 m × n 的二进制迷宫：0 表示空地，1 表示墙。一个球从 start 出发，每次可以选择上、下、左、右一个方向；一旦开始滚动，它会持续前进，直到下一步将撞墙或越界时才停下，然后才能重新选择方向。

判断球是否能够恰好停在 destination。即使球途中经过终点，只要不能在那里停住，也不算到达。

函数形式：hasPath(maze, start, destination) → boolean

Constraints

约束

  • m == maze.length
  • n == maze[i].length
  • 1 ≤ m, n ≤ 100
  • maze[i][j] ∈ {0, 1}
  • start.length == 2
  • destination.length == 2
  • 0 ≤ row < m
  • 0 ≤ col < n
  • 起点与终点均为空地
  • 起点与终点初始不同
  • 迷宫至少有两个空格
边界即墙：滚动下一步越界时，球停在当前格。

Solution

准备好再揭晓

核心方法、证明、复杂度与四语言代码默认收起。

Core insight

把“空格”变成“停止点图”

普通迷宫把相邻空格当作一步；本题的一步却是“沿某个方向一直滚到尽头”。因此，搜索状态应是球停住的位置。从每个状态向四个方向模拟滚动，得到至多四个新的停止点，再在这些停止点上做图搜索。

状态停止位置 (r, c)

球只有停下后才能改变方向。

转移滚到墙前

逐格前进，越界或撞墙前停住。

目标终点被停靠

途中经过终点并不等于到达。

Process

完整过程

  1. 把起点加入队列，并在 visited 中标记。
  2. 取出一个停止点；若它等于终点，立即返回 true。
  3. 对上、下、左、右分别模拟：只要下一格合法且为空，就继续滚动。
  4. 滚动结束得到新的停止点；若未访问，将其标记并加入队列。
  5. 队列耗尽仍未到达终点，返回 false。
Correctness

正确性证明

引理：从任一停止点和任一方向出发，模拟得到的位置，恰好是该方向上球能进行下一次决策的唯一位置。因为球在撞墙或越界前不能改变方向。

完备性：任意合法路线都由若干次“停止点到停止点”的滚动组成。搜索会从每个已达停止点枚举四个方向，因此会生成这条路线中的每一条边，所有可达停止点最终都会被访问。

可靠性：搜索加入的每个状态都由一次合法滚动产生，所以所有访问到的停止点都真实可达。算法仅在终点本身成为访问状态时返回真，故不会把“仅经过终点”误判为到达。

结论：算法返回 true 当且仅当球能够停在终点。

Complexity & edges

复杂度与边界

至多有 m·n 个停止状态。每个状态向四个方向滚动，每次最多走 O(max(m,n)) 格：

  • 时间：O(m·n·max(m,n))
  • 空间：O(m·n)

需要特别处理：起点四面被墙包围、终点只能被经过却不能停下、单行或单列迷宫，以及某方向零步移动仍回到原位置。visited 会阻止零步状态反复入队。

Alternatives

替代方案与追问

可以改用 DFS

BFS 与 DFS 在“只判断可达性”时都正确。DFS 可递归或显式栈实现；递归写法更短，但最坏可能有 m·n 层调用，面试中通常显式栈更稳妥。

预计算滚动终点

若同一迷宫有多次查询，可预先为每个空格计算四个方向的停止点，减少重复扫描，以额外空间换取查询速度。

面试追问

  • 若要求最短滚动距离：边有不同权重，应使用 Dijkstra（Maze II）。
  • 若球遇到洞会在途中掉入：模拟滚动时必须先判断洞（Maze III）。
  • 若有大量起终点查询：讨论转移预处理或连通性缓存。

常见错误

  • 把相邻空格直接入队，忽略球不能中途停下。
  • 看到滚动轨迹经过终点就返回真。
  • 滚过墙后再回退时出现下标越界。
  • 出队才标记，导致同一停止点重复入队。

import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public boolean hasPath(int[][] maze, int[] start, int[] destination) {
        int rows = maze.length;
        int cols = maze[0].length;
        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        boolean[][] visited = new boolean[rows][cols];
        Queue<int[]> queue = new ArrayDeque<>();

        queue.offer(new int[]{start[0], start[1]});
        visited[start[0]][start[1]] = true;

        while (!queue.isEmpty()) {
            int[] current = queue.poll();
            if (current[0] == destination[0]
                    && current[1] == destination[1]) {
                return true;
            }

            for (int[] direction : directions) {
                int row = current[0];
                int col = current[1];

                while (canMove(maze, row + direction[0], col + direction[1])) {
                    row += direction[0];
                    col += direction[1];
                }

                if (!visited[row][col]) {
                    visited[row][col] = true;
                    queue.offer(new int[]{row, col});
                }
            }
        }
        return false;
    }

    private boolean canMove(int[][] maze, int row, int col) {
        return row >= 0 && row < maze.length
                && col >= 0 && col < maze[0].length
                && maze[row][col] == 0;
    }
}
/**
 * @param {number[][]} maze
 * @param {number[]} start
 * @param {number[]} destination
 * @return {boolean}
 */
var hasPath = function (maze, start, destination) {
    const rows = maze.length;
    const cols = maze[0].length;
    const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    const visited = Array.from({ length: rows }, () => Array(cols).fill(false));
    const queue = [[start[0], start[1]]];
    let head = 0;

    visited[start[0]][start[1]] = true;

    while (head < queue.length) {
        const [currentRow, currentCol] = queue[head++];
        if (currentRow === destination[0] && currentCol === destination[1]) {
            return true;
        }

        for (const [deltaRow, deltaCol] of directions) {
            let row = currentRow;
            let col = currentCol;

            while (
                row + deltaRow >= 0 && row + deltaRow < rows &&
                col + deltaCol >= 0 && col + deltaCol < cols &&
                maze[row + deltaRow][col + deltaCol] === 0
            ) {
                row += deltaRow;
                col += deltaCol;
            }

            if (!visited[row][col]) {
                visited[row][col] = true;
                queue.push([row, col]);
            }
        }
    }
    return false;
};
from collections import deque
from typing import List


class Solution:
    def hasPath(
        self,
        maze: List[List[int]],
        start: List[int],
        destination: List[int]
    ) -> bool:
        rows, cols = len(maze), len(maze[0])
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
        queue = deque([(start[0], start[1])])
        visited = {(start[0], start[1])}

        while queue:
            current_row, current_col = queue.popleft()
            if [current_row, current_col] == destination:
                return True

            for delta_row, delta_col in directions:
                row, col = current_row, current_col
                while (
                    0 <= row + delta_row < rows
                    and 0 <= col + delta_col < cols
                    and maze[row + delta_row][col + delta_col] == 0
                ):
                    row += delta_row
                    col += delta_col

                if (row, col) not in visited:
                    visited.add((row, col))
                    queue.append((row, col))

        return False
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    bool hasPath(
        vector<vector<int>>& maze,
        vector<int>& start,
        vector<int>& destination
    ) {
        const int rows = static_cast<int>(maze.size());
        const int cols = static_cast<int>(maze[0].size());
        const int directions[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        vector<vector<bool>> visited(rows, vector<bool>(cols, false));
        queue<pair<int, int>> pending;

        pending.push({start[0], start[1]});
        visited[start[0]][start[1]] = true;

        while (!pending.empty()) {
            auto [currentRow, currentCol] = pending.front();
            pending.pop();

            if (currentRow == destination[0] && currentCol == destination[1]) {
                return true;
            }

            for (const auto& direction : directions) {
                int row = currentRow;
                int col = currentCol;
                while (
                    row + direction[0] >= 0 && row + direction[0] < rows &&
                    col + direction[1] >= 0 && col + direction[1] < cols &&
                    maze[row + direction[0]][col + direction[1]] == 0
                ) {
                    row += direction[0];
                    col += direction[1];
                }

                if (!visited[row][col]) {
                    visited[row][col] = true;
                    pending.push({row, col});
                }
            }
        }
        return false;
    }
};
