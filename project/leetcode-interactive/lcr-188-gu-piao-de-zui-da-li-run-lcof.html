买卖芯片的最佳时机

给定每天的芯片价格 prices，只能完成一次买入和一次卖出。买入必须早于卖出，求能获得的最大收益；没有正收益时返回 0。

interview solution

完整题解

核心洞察

卖出日固定时，最好的买入日一定是它之前价格最低的那天。因此不需要枚举所有 (buy, sell) 对；从左到右维护一个 minPrice，每一天只计算一次候选收益。

完整过程

  1. 令 minPrice = prices[0]，best = 0。
  2. 依次把当天价格作为卖出价，计算 price - minPrice。
  3. 用候选收益更新 best。
  4. 再用当天价格更新 minPrice，供未来卖出日使用。

边界

  • 只有一天：没有未来卖出日，答案为 0。
  • 单调下降：所有候选收益为负，best 保持 0。
  • 最低价在最后一天：它只能更新最低价，不能形成交易。

复杂度

每个价格只访问一次：时间 O(n)。只维护三个标量：额外空间 O(1)。

替代方案

双重循环枚举买卖日可作为暴力校验，时间是 O(n²)；它清楚但会在长数组上超时。

面试追问

若允许多笔交易，状态不再是一个最低价：应累加所有上升区间，或改用交易状态 DP。若允许一次交易但要返回买卖日，可同时保存最低价所在下标和最优交易的两端下标。

常见错误

  • 先更新 minPrice 再计算收益，会错误允许同日买卖（虽收益为 0，但逻辑边界不清）。
  • 把答案初始化成极小值，会在单调下降数组中返回负数。
  • 把本题误写成可多次交易，累计每个上升差值会得到错误答案。

四语言实现

var bestTiming = function (prices) {
  if (prices.length === 0) return 0;
  let minPrice = prices[0];
  let best = 0;
  for (let i = 1; i < prices.length; i += 1) {
    best = Math.max(best, prices[i] - minPrice);
    minPrice = Math.min(minPrice, prices[i]);
  }
  return best;
};
from typing import List

class Solution:
    def bestTiming(self, prices: List[int]) -> int:
        if not prices:
            return 0
        min_price = prices[0]
        best = 0
        for price in prices[1:]:
            best = max(best, price - min_price)
            min_price = min(min_price, price)
        return best
class Solution {
  public int bestTiming(int[] prices) {
    if (prices.length == 0) return 0;
    int minPrice = prices[0], best = 0;
    for (int i = 1; i < prices.length; i++) {
      best = Math.max(best, prices[i] - minPrice);
      minPrice = Math.min(minPrice, prices[i]);
    }
    return best;
  }
}
class Solution {
public:
  int bestTiming(vector<int>& prices) {
    if (prices.empty()) return 0;
    int minPrice = prices[0], best = 0;
    for (int i = 1; i < prices.size(); ++i) {
      best = max(best, prices[i] - minPrice);
      minPrice = min(minPrice, prices[i]);
    }
    return best;
  }
};
