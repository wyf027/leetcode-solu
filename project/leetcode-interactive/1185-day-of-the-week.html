Day of the Week

给定一个有效日期，返回它对应的英文星期名称。先读懂问题，再用下方的日期偏移实验室亲手走完每一步；完整题解保持折叠。

7

Problem

题目说明

官方函数：dayOfTheWeek(day, month, year)

输入三个整数 day、month、year，分别表示日、月、年。请返回该日期在一周中对应的英文名称。

返回值必须是 Sunday、Monday、Tuesday、Wednesday、Thursday、Friday、Saturday 之一。

已知锚点：1971 年 1 月 1 日是 Friday。

约束

  • 日期一定有效。
  • 1971 ≤ year ≤ 2100。
  • 参数形式：(day: integer, month: integer, year: integer) → string。
有效公历日期固定英文输出
示例 1
输入：day = 31, month = 8, year = 2019
输出："Saturday"
示例 2
输入：day = 18, month = 7, year = 1999
输出："Sunday"
示例 3
输入：day = 15, month = 8, year = 1993
输出："Sunday"

Editorial

完整题解

核心推导、证明、复杂度与四语言代码均收纳在这里。

核心洞察

星期每 7 天循环。以 1971-01-01（Friday，索引 5）为锚点，统计从锚点到目标日期之前经过的总天数 offset，答案索引就是 (5 + offset) % 7。

完整过程

  1. 累加 1971 到 year - 1 的完整年份；平年 365 天，闰年 366 天。
  2. 累加目标年中 1 月到 month - 1 的完整月份；闰年二月为 29 天。
  3. 加入当月已经过去的 day - 1 天。
  4. 将总偏移与 Friday 的索引相加，再对 7 取模。
offset = 完整年份天数 + 完整月份天数 + (day - 1)
answer = weekdays[(5 + offset) % 7]

正确性证明

引理 1：前三次累加恰好覆盖从 1971-01-01 到目标日期前一天的每一天，且不重不漏，因此得到精确的日期偏移。

引理 2：每经过一天，星期索引增加 1；每 7 天回到同一星期，所以偏移 offset 后的索引为 (5 + offset) mod 7。

结论：由两个引理，算法返回的英文名称正是目标日期对应的星期。

边界与复杂度

  • 锚点当天：偏移为 0，应返回 Friday。
  • 闰年规则：能被 400 整除，或能被 4 整除但不能被 100 整除。
  • 世纪边界：2000 是闰年，2100 不是闰年。
  • 年循环最多遍历 129 次，因此在本题范围内近似常数。
  • 时间复杂度 O(year - 1971 + month)，按题目上限可视为 O(1)；空间复杂度 O(1)。

替代方案与面试追问

替代方案：可使用 Zeller 同余等公式直接计算，时间复杂度严格为 O(1)，但公式难记且容易出现月份、年份调整错误。标准日期库也能求解，不过面试通常希望展示日历规则。

追问：如果日期范围扩展到 1971 年之前怎么办？可以选更早锚点，或使用能处理负数取模的封装。

追问：如何避免逐年遍历？利用 400 年公历周期共有 146097 天，或计算区间内闰年数量。

常见错误

  • 把目标日计入偏移，写成 day 而不是 day - 1，产生一天偏差。
  • 只用“能被 4 整除”判断闰年，忽略 100 与 400 的世纪规则。
  • 月份数组使用 0 基索引，却把 month 当作需要全部累加的月份数量。
  • 星期数组顺序与锚点索引不一致。
JavaLeetCode
class Solution {
    private boolean isLeap(int year) {
        return year % 400 == 0 || (year % 4 == 0 && year % 100 != 0);
    }

    public String dayOfTheWeek(int day, int month, int year) {
        String[] weekdays = {
            "Sunday", "Monday", "Tuesday", "Wednesday",
            "Thursday", "Friday", "Saturday"
        };
        int[] monthDays = {31, 28, 31, 30, 31, 30,
                           31, 31, 30, 31, 30, 31};
        int offset = 0;
        for (int y = 1971; y < year; y++) {
            offset += isLeap(y) ? 366 : 365;
        }
        for (int m = 1; m < month; m++) {
            offset += monthDays[m - 1];
            if (m == 2 && isLeap(year)) offset++;
        }
        offset += day - 1;
        return weekdays[(5 + offset) % 7];
    }
}
