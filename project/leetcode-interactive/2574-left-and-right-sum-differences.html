左右元素和的差值

Left and Right Sum Differences

下标从 0 开始 返回 int[] 非付费题

Problem

题目描述

函数：leftRightDifference(nums)

给定一个下标从 0 开始、长度为 n 的整数数组 nums。对每个位置 i，分别统计它左侧和右侧的元素和。

  • leftSum[i]：所有下标小于 i 的元素之和；左侧为空时取 0。
  • rightSum[i]：所有下标大于 i 的元素之和；右侧为空时取 0。

Return

answer[i] = | leftSum[i] − rightSum[i] |

返回长度同为 n 的整数数组 answer。

示例 1

输入：nums = [10,4,8,3]
输出：[15,1,11,22]
解释：
leftSum  = [0,10,14,22]
rightSum = [15,11,3,0]
answer   = [|0-15|,|10-11|,|14-3|,|22-0|]
         = [15,1,11,22]

示例 2

输入：nums = [1]
输出：[0]
解释：
leftSum  = [0]
rightSum = [0]
answer   = [|0-0|] = [0]

约束

  • 1 ≤ nums.length ≤ 1000
  • 1 ≤ nums[i] ≤ 105

Solution

准备好看完整题解了吗？

先尝试从扫描台中找到不重复计算右侧和的方法，再展开核心洞察、证明与四种语言实现。

O(n) Time · O(1) Extra Space

一次扫描：维护左和，推导右和

核心洞察

先求数组总和 total。扫描到元素 nums[i] 时，若 left 是其左侧之和，则右侧之和无需重新遍历：

right = total − left − nums[i]

记录 |left − right| 后，再把当前元素加入 left，游标即可前进。

完整过程

  1. 累加所有元素得到 total。
  2. 初始化 left = 0。
  3. 对每个 nums[i]，计算 right = total - left - nums[i]。
  4. 写入答案 abs(left - right)。
  5. 执行 left += nums[i]，继续扫描。

正确性证明

循环不变量：处理下标 i 之前，变量 left 恰好等于 nums[0..i-1] 的元素和。

初始化：i = 0 时左侧为空，left = 0，不变量成立。

保持：总和减去左侧和与当前元素，剩余部分恰为 nums[i+1..n-1]，因此当前答案正确。随后把 nums[i] 加入 left，下一轮不变量仍成立。

终止：循环覆盖全部下标，所以答案数组的每一项都正确。

边界与复杂度

时间O(n)求总和 + 一次扫描
额外空间O(1)不计返回数组
  • 单元素数组：左右均为空，答案为 0。
  • 首元素：left = 0。
  • 末元素：推导得到 right = 0。
  • 最大总和为 108，题目约束下 32 位有符号整数足够。

Implementations

四种语言完整代码

JavaLeetCode 可提交
class Solution {
    public int[] leftRightDifference(int[] nums) {
        int total = 0;
        for (int num : nums) total += num;

        int[] answer = new int[nums.length];
        int left = 0;
        for (int i = 0; i < nums.length; i++) {
            int right = total - left - nums[i];
            answer[i] = Math.abs(left - right);
            left += nums[i];
        }
        return answer;
    }
}

/**
 * @param {number[]} nums
 * @return {number[]}

var leftRightDifference = function(nums) {
    const total = nums.reduce((sum, num) => sum + num, 0);
    let left = 0;

    return nums.map(num => {
        const right = total - left - num;
        const difference = Math.abs(left - right);
        left += num;
        return difference;
    });
};

C++LeetCode 可提交
class Solution {
public:
    vector<int> leftRightDifference(vector<int>& nums) {
        int total = accumulate(nums.begin(), nums.end(), 0);
        vector<int> answer;
        answer.reserve(nums.size());
        int left = 0;

        for (int num : nums) {
            int right = total - left - num;
            answer.push_back(abs(left - right));
            left += num;
        }
        return answer;
    }
};

替代方案

  • 暴力枚举：每个位置分别向左右累加，时间 O(n²)，直观但重复计算。
  • 两个辅助数组：预先构造完整的 leftSum 与 rightSum，时间 O(n)、额外空间 O(n)。
  • 原地复用返回数组：可把答案数组暂作前缀和，但并不会改善渐进复杂度，且可读性更差。

面试追问

  • 如果元素允许负数，方法是否仍成立？成立，等式不依赖正数性质。
  • 如果输入是单向数据流？需要先知道总和，因此至少两遍读取；若无法重放，则必须缓存数据。
  • 如果数值范围更大？Java/C++ 应把累计值升级为 64 位整数。
  • 能否真正一遍且不预先求总和？不能在未知未来元素时确定当前右侧和。

常见错误

  • 先执行 left += nums[i]，误把当前元素算入左侧。
  • 计算右和时只减去 left，忘记再减当前元素。
  • 遗漏绝对值，得到带符号的左右差。
  • 把结果数组算作额外空间，误写空间复杂度为 O(n)。

记忆口诀

右 = 总 − 左 − 当前

先记差，再把当前交给左边。整个扫描过程中，每个元素只参与常数次运算。
