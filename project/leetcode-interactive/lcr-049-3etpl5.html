LCR 049 · MEDIUM

求根节点到叶节点数字之和

每个根到叶路径都是一个数字：走到下一层就把当前数乘 10 再加上节点值，累加所有叶节点处的结果。

题意

给定只含数字 0 到 9 的二叉树。每条从根到叶的路径拼成一个数，求全部路径数字之和。

示例

root = [1,2,3]
路径：1 → 2，数字 12
路径：1 → 3，数字 13
输出：25

约束

节点数范围为 1 到 1000；节点值为 0 到 9。题目保证答案在 32 位整数范围内。

交互实验室

以层序数组输入树，null 表示空节点。逐步查看 DFS 如何更新当前路径数字与总和。

载入示例后开始观察。

    内置算法验证

    已执行：浏览器内 JavaScript 的固定用例对拍。延后：真实浏览器交互验收、四种语言的编译运行，以及依赖网络的 Tailwind CDN 加载验证；这些尚未在本页中执行或声称通过。

    核心洞察

    不需要保存字符串路径。到达节点 node 时，新的路径数字就是 value = prefix * 10 + node.val。若它是叶节点，直接把 value 加进答案；否则递归处理左右孩子。

    完整过程

    1. 从根节点以当前路径数字 0 开始深度优先遍历。
    2. 每走到一个节点，按十进制追加该节点值。
    3. 叶节点没有左右孩子，它代表一条完整路径，加入当前数字。
    4. 非叶节点继续向左右子树传递更新后的数字。

    边界与常见错误

    • 空树应返回 0。
    • 只在叶节点累加，不能在每个节点累加前缀。
    • 更新顺序是 prefix * 10 + val，不能反过来。

    复杂度：每个节点访问一次，时间 O(n)；递归栈最坏 O(h)，其中 h 为树高。

    可提交代码

    Java

    class Solution {
    public int sumNumbers(TreeNode root) {
        return dfs(root, 0);
    }
    private int dfs(TreeNode node, int prefix) {
        if (node == null) return 0;
        int value = prefix * 10 + node.val;
        if (node.left == null && node.right == null) return value;
        return dfs(node.left, value) + dfs(node.right, value);
    }
}

    var sumNumbers = function (root) {
  const dfs = (node, prefix) => {
    if (!node) return 0;
    const value = prefix * 10 + node.val;

    return dfs(node.left, value) + dfs(node.right, value);
  };
  return dfs(root, 0);
};
