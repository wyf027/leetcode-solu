交换字符使得字符串相同

两行只由 x 与 y 组成的字符串。每次只能跨行交换一个字符——能否相同，最少又要几次？先观察规则，再走进实验室。

阅读题目 函数：minimumSwap(s1, s2)

01 · Problem

题目说明

给定两个长度相同的字符串 s1 和 s2，它们只含字符 'x' 与 'y'。一次操作可以从两个不同的字符串中各选一个位置，交换 s1[i] 与 s2[j]。

请返回使两个字符串完全相同所需的最少交换次数；如果无法做到，返回 -1。

操作边界：不允许交换同一字符串内的两个字符，例如不能直接交换 s1[i] 与 s1[j]。

约束与签名

  • 1 <= s1.length, s2.length <= 1000
  • s1.length == s2.length
  • s1、s2 仅包含 'x'、'y'
minimumSwap(s1: string, s2: string): integer

示例 1

输入：s1 = "xx", s2 = "yy"
输出：1

交换 s1[0] 与 s2[1]，得到两行均为 "yx"。

示例 2

输入：s1 = "xy", s2 = "yx"
输出：2

先交换 s1[0] 与 s2[0]，得到 "yy" / "xx"；再交换 s1[0] 与 s2[1]，得到两行均为 "xy"。

示例 3

输入：s1 = "xx", s2 = "xy"
输出：-1

不存在能让两个字符串相同的跨字符串交换序列。

04 · Editorial

完整题解

洞察、证明、边界、代码与面试追问集中于此，默认收起。

核心洞察

相同位置无需处理。不同位置只有两类：xy（s1 为 x、s2 为 y）和 yx。记数量为 a、b。

  • 两个同类错位可用 1 次交换一起消除，因此贡献 a / 2 与 b / 2（向下取整）。
  • 若 a、b 都为奇数，最后各剩一个异类错位，需要 2 次交换。
  • 若 a + b 为奇数，总字符数中某个字符的数量为奇数，不可能让两行相同。
公式：(a + b) % 2 ? -1 : floor(a/2) + floor(b/2) + 2 * (a%2)

完整过程

  1. 同步扫描 s1 和 s2。
  2. 跳过相同位置；按方向累计 xy 或 yx。
  3. 若错位总数是奇数，返回 -1。
  4. 否则成对处理同类错位；如两类都剩一个，再加 2。

示例 2："xy" / "yx" 各有一个 xy 与 yx，无法用一次交换同时修好，但两次可完成，所以答案为 2。

正确性证明

可行性：每两个同类错位，交叉交换其中两个相同方向的字符即可同时匹配，代价 1；剩余的一对异类错位可按题目示例 2 的方式用 2 次完成。因此公式给出的次数一定可构造。

最优性：一次交换至多同时消除两个错位。同类的一对恰好用一次，已达下界；一个 xy 与一个 yx 无法通过一次跨行交换同时变为匹配，至少需两次。各部分均达到必要下界，故总次数最小。

不可行情形：一次交换不改变两个字符串合计的 x、y 数量。若错位总数为奇数，则合计的某类字符无法平均分到两行，必然无解。

边界与复杂度

  • 两串已相同：a = b = 0，返回 0。
  • 只有一个错位：错位总数为奇数，返回 -1。
  • 两类计数都为奇数：不要只加 1，应额外加 2。
  • 长度上限 1000，一次线性扫描足够。

时间复杂度：O(n)；空间复杂度：O(1)。

四语言完整代码

class Solution {
    public int minimumSwap(String s1, String s2) {
        int xy = 0, yx = 0;
        for (int i = 0; i < s1.length(); i++) {
            if (s1.charAt(i) == s2.charAt(i)) continue;
            if (s1.charAt(i) == 'x') xy++;
            else yx++;
        }
        if ((xy + yx) % 2 == 1) return -1;
        return xy / 2 + yx / 2 + 2 * (xy % 2);
    }
}

替代方案

可以显式收集所有错位下标并模拟交换，但需要额外空间且更容易写错。由于答案只由两类错位的数量决定，计数法更短、更直接。

面试追问

  • 为什么异类剩余对必须是 2 次，而不是 1 次？
  • 如果字符集不止 x/y，计数模型如何变化？
  • 如果允许同一字符串内部交换，答案会怎样改变？

常见错误

  • 把 (xy % 2) * 2 误写成只加 1。
  • 只判断 xy 或 yx 的奇偶，而漏掉总错位数。
  • 模拟了题目不允许的同串交换。
