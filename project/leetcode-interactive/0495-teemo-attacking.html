Mission briefing

题目描述

先准确理解“含端点的秒数区间”和“再次攻击会重置计时器”这两个条件。

提莫用带毒攻击命中艾希。若在第 t 秒攻击，中毒状态会覆盖完整的 duration 秒，即闭区间 [t, t + duration - 1]。

如果毒素尚未结束就再次受到攻击，计时器会从新攻击时刻重置；新毒素效果在该次攻击后的 duration 秒结束。

给定按非递减顺序排列的整数数组 timeSeries，其中 timeSeries[i] 是第 i 次攻击发生的秒数；再给定整数 duration。返回艾希处于中毒状态的总秒数。

  • 1 <= timeSeries.length <= 104
  • 0 <= timeSeries[i], duration <= 107
  • timeSeries 按非递减顺序排列

输入：timeSeries = [1,4], duration = 2
输出：4
解释：第 1 次覆盖第 1、2 秒；
第 2 次覆盖第 4、5 秒。
共中毒 4 秒。

输出：3

覆盖第 2、3 秒。共中毒 3 秒。

Solution

逐段计算新增覆盖

核心洞察：每次攻击都会贡献一段长度为 duration 的区间；但除最后一次攻击外，只需统计它在“下一次攻击到来前”实际占据的秒数，即 min(相邻攻击间隔, duration)。

完整过程

  1. 若数组为空则返回 0；本题约束下数组至少有一个元素。
  2. 遍历每对相邻攻击 timeSeries[i - 1] 与 timeSeries[i]。
  3. 前一次攻击在下一次攻击前最多贡献二者间隔，且自身效果最多持续 duration 秒，所以累加二者较小值。
  4. 最后一次攻击没有后续攻击截断，单独加上完整的 duration。

正确性说明

把总中毒时间按“每次攻击开始、下一次攻击到来之前”切成互不重叠的段。对非最后一次攻击，该段的长度既不能超过下一次攻击的到达间隔，也不能超过毒素自身持续时间，所以恰为两者最小值。最后一段长度恰为 duration。这些段无重复且覆盖全部中毒秒数，因此求和就是答案。

边界与复杂度

  • duration = 0：每段贡献均为 0。
  • 重复时刻：间隔为 0，不会重复计数。
  • 单次攻击：答案直接为 duration。
  • 时间复杂度：O(n)。
  • 额外空间：O(1)。

替代方案

也可以维护当前合并区间的左右端点：若新区间相交就延长右端点，否则结算旧区间并开启新区间。这个区间合并写法同样是 O(n)，但变量更多；本题使用相邻间隔求贡献更短、更贴合有序输入。

面试追问

  • 如果 timeSeries 无序怎么办？先排序，复杂度变为 O(n log n)。
  • 如果每次攻击持续时间不同怎么办？需维护当前最远结束时刻，或执行通用区间合并。
  • 若时间是连续实数呢？把“秒格计数”改为半开区间长度，合并逻辑仍成立。

常见错误

  • 每次都加 duration，忽略重叠。
  • 把闭区间长度误算成右端点减左端点，漏掉 1 秒。
  • 只处理相邻间隔，却忘记补上最后一次完整攻击。
  • 用集合枚举每一秒，时间和空间随时间值膨胀。

四语言完整实现

Java

class Solution {
    public int findPoisonedDuration(int[] timeSeries, int duration) {
        if (timeSeries.length == 0) {
            return 0;
        }

        int total = 0;
        for (int i = 1; i < timeSeries.length; i++) {
            int gap = timeSeries[i] - timeSeries[i - 1];
            total += Math.min(gap, duration);
        }
        return total + duration;
    }
}
