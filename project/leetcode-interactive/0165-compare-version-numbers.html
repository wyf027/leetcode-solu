题意与参数

版本字符串由点号分隔的一个或多个修订段组成。修订值忽略前导零；若一侧缺少对应修订段，则该段按 0 处理。返回 -1、1 或 0 表示小于、大于或相等。

准备查看完整题解？

核心洞察、逐段推导、溢出边界、复杂度、split 替代方案、追问、错误清单与四语言代码都在下方。

核心洞察：逐段扫描，不把修订值塞进整数

为两个字符串各维护一个游标。每轮读取点号前的修订段，跳过前导零，再按有效数字长度比较；长度相同才逐字符比较。这样既保留双指针的 O(1) 额外空间，也能自然处理超长修订段，避免 parseInt、Integer.parseInt 等整数溢出。

先去前导零

"00042" → "42"

再比长度

"99" < "100"

同长逐字符

"123" < "124"

复杂度

TIME
O(n + m)
两个游标只向右移动，每个字符至多访问常数次。
SPACE
O(1)
比较直接发生在原字符串索引上，不创建修订数组。

完整过程

  1. 1

    定位修订边界

    分别从两个游标向右扫描，直到点号或字符串末尾。

  2. 2

    跳过前导零

    把有效起点推进到首个非零字符；全零段的有效长度为 0。

  3. 3

    比较有效数字

    长度不同即可判定；长度相同则从左到右逐字符比较。

  4. 4

    越过点号继续

    当前段相等时移动到下一段；一侧结束后，缺失段按 0 参与比较。

边界与不变量

前导零：001 与 1 的有效数字相同。
不同段数：短版本耗尽后的每个缺失段都视作 0。
全零段：跳过所有零后有效长度为 0，与缺失段等价。
超长修订：长度加逐字符比较不依赖机器整数范围。
关键不变量：进入下一轮前，已经扫描过的全部修订段都相等。

替代方案：split 后逐段比较

可先对两个字符串执行 split('.')，再按相同规则比较对应段。它更短、更直观，时间仍为 O(n + m)，但会创建修订数组和子串，额外空间为 O(n + m)。若随后直接转 32 位整数，还会失去对超长修订段的稳健性。

面试追问

为什么去零后先比较长度？

十进制非负整数没有前导零时，位数更多的一定更大；这样无需数值解析。

官方保证 32 位可存，为什么仍避免 parseInt？

字符比较保持同样复杂度和常数空间，同时让解法对放宽后的输入边界仍然正确，面试中更容易说明安全性。

这能直接比较语义化版本吗？

不能。SemVer 还包含预发布标识和构建元数据，本题只定义纯数字点分修订段。

常见错误

整体字典序

"1.10" 会被误判小于 "1.2"。

转成浮点数

点号不是小数点，1.0.1 也不是合法浮点数。

忽略缺失段

1 与 1.0.0 必须判为相等。

整数溢出

扩展边界下，超长修订段不能安全塞入固定宽度整数。

class Solution {
    public int compareVersion(String version1, String version2) {
        int i = 0;
        int j = 0;

        while (i < version1.length() || j < version2.length()) {
            int end1 = i;
            while (end1 < version1.length() && version1.charAt(end1) != '.') {
                end1++;
            }
            int end2 = j;
            while (end2 < version2.length() && version2.charAt(end2) != '.') {
                end2++;
            }

            int start1 = i;
            while (start1 < end1 && version1.charAt(start1) == '0') {
                start1++;
            }
            int start2 = j;
            while (start2 < end2 && version2.charAt(start2) == '0') {
                start2++;
            }

            int length1 = end1 - start1;
            int length2 = end2 - start2;
            if (length1 != length2) {
                return length1 < length2 ? -1 : 1;
            }
            for (int offset = 0; offset < length1; offset++) {
                char digit1 = version1.charAt(start1 + offset);
                char digit2 = version2.charAt(start2 + offset);
                if (digit1 != digit2) {
                    return digit1 < digit2 ? -1 : 1;
                }
            }

            i = end1 < version1.length() ? end1 + 1 : end1;
            j = end2 < version2.length() ? end2 + 1 : end2;
        }

        return 0;
    }
}
var compareVersion = function (version1, version2) {
  let i = 0;
  let j = 0;

  while (i < version1.length || j < version2.length) {
    let end1 = i;
    while (end1 < version1.length && version1[end1] !== ".") end1++;
    let end2 = j;
    while (end2 < version2.length && version2[end2] !== ".") end2++;

    let start1 = i;
    while (start1 < end1 && version1[start1] === "0") start1++;
    let start2 = j;
    while (start2 < end2 && version2[start2] === "0") start2++;

    const length1 = end1 - start1;
    const length2 = end2 - start2;
    if (length1 !== length2) return length1 < length2 ? -1 : 1;

    for (let offset = 0; offset < length1; offset++) {
      if (version1[start1 + offset] !== version2[start2 + offset]) {
        return version1[start1 + offset] < version2[start2 + offset] ? -1 : 1;
      }
    }

    i = end1 < version1.length ? end1 + 1 : end1;
    j = end2 < version2.length ? end2 + 1 : end2;
  }

  return 0;
};
