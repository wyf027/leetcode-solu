Strobogrammatic Number II

把一个数字旋转 180° 后仍保持不变，必须由可互换的数字对构成：0↔0、1↔1、8↔8、6↔9、9↔6。从中心向两侧递归装配即可。

↻ 递归构造 · 中心向外配对

题意

给定整数 n，返回所有长度为 n 的旋转对称数字。结果可按任意顺序返回，且长度大于 1 时不能有前导 0。

官方样例 1n = 2

期望输出（顺序可不同）：["11", "69", "88", "96"]。

官方样例 2n = 1

期望输出（顺序可不同）：["0", "1", "8"]。

约束：1 ≤ n ≤ 14。本题为 LeetCode Premium；题面与样例按公开题目资料核实。

180° 镜像装配台

准备从 n = 3 的中心字符开始装配。

题解默认折叠。

题解：从中心递归扩展

核心洞察

长度为偶数的中心是空串，长度为奇数的中心只能是 0、1 或 8。每一轮在两侧套上五种合法对；最外层跳过 0...0，从而杜绝前导零。

完整过程

  1. 根据 n 的奇偶得到基础中心集合。
  2. 每轮对每个已有中间串套入 5 个翻转对。
  3. 若即将成为最外层，只允许 4 个非零开头对。
  4. 扩展至长度 n，返回收集结果。

边界

n=1 可以返回 0；n>1 时 00 不可作为外层；空中心仅用于内部构造，不是最终 n≥1 的答案。

复杂度与替代方案

输出本身有指数数量，时间 O(n·A(n))，A(n) 为答案数；额外递归构造空间 O(n·A(n))（含输出）。也可 DFS 直接填充字符数组，常数更低。

面试追问

若只判断一个数是否旋转对称，用双指针和映射即可；若生成固定长度且需要有序输出，要明确字典序和遍历对的顺序。

常见错误

误把 2/5 当成配对；允许最外层 00；奇数长度中心放入 6 或 9；把字符串当整数导致丢失内部或单字符 0。

class Solution {
    public List<String> findStrobogrammatic(int n) { return build(n, n); }
    private List<String> build(int len, int total) {
        if (len == 0) return new ArrayList<>(List.of(""));
        if (len == 1) return new ArrayList<>(List.of("0", "1", "8"));
        List<String> middle = build(len - 2, total), answer = new ArrayList<>();
        for (String s : middle) { if (len != total) answer.add("0" + s + "0"); answer.add("1" + s + "1"); answer.add("6" + s + "9"); answer.add("8" + s + "8"); answer.add("9" + s + "6"); }
        return answer;
    }
}
var findStrobogrammatic = function(n) {
  const build = len => {
    if (len === 0) return [""];
    if (len === 1) return ["0", "1", "8"];
    const middle = build(len - 2), out = [];
    for (const s of middle) { if (len !== n) out.push("0" + s + "0"); out.push("1" + s + "1", "6" + s + "9", "8" + s + "8", "9" + s + "6"); }
    return out;
  };
  return build(n);
};
class Solution:
    def findStrobogrammatic(self, n: int) -> list[str]:
        def build(length: int) -> list[str]:
            if length == 0: return [""]
            if length == 1: return ["0", "1", "8"]
            result = []
            for middle in build(length - 2):
                if length != n: result.append("0" + middle + "0")
                result += ["1" + middle + "1", "6" + middle + "9", "8" + middle + "8", "9" + middle + "6"]
            return result
        return build(n)
