Most Frequent Number Following Key In an Array

只看紧邻的下一个位置。先理解什么算一次出现，再动手观察数据。

官方题目 ↗

01 / 题目与约束

给定从下标 0 开始的整数数组 nums，以及在数组中出现过的整数 key。对每个不同的整数 target，统计它紧跟在 key 后面出现的次数，返回次数最多的那个数字。题目保证最终答案唯一。

一次有效出现必须同时满足：0 ≤ i ≤ nums.length − 2、nums[i] == key、nums[i + 1] == target。这里的“之后”指相邻位置，不是后面任意位置。

  • 2 ≤ nums.length ≤ 1000
  • 1 ≤ nums[i] ≤ 1000
  • key 在 nums 中出现过。
  • 测试数据保证答案唯一。

官方示例 1

输入：nums = [1,100,200,1,100], key = 1
输出：100

下标 1 和 4 的 100 都紧跟着 1，共出现两次；没有其他数字符合条件。

官方示例 2

输入：nums = [2,2,2,2,3], key = 2
输出：2

下标 1、2、3 的 2 各贡献一次；下标 4 的 3 贡献一次，所以返回 2。

04 / 独立题解

先自行思考：哪些位置应该参与计数？连续出现的 key 应如何处理？

核心洞察：只给有效相邻对的右端计票

用长度 1001 的计数数组 count。如果 nums[i] == key，就对 count[nums[i+1]] 加一。每次加一后，若它超过当前最高次数，就更新答案。计数的是 key 的后继，不是整个数组中的频率。

完整过程

  1. 初始化计数数组、最高次数 best = 0 和答案 answer = 0。
  2. 从 i = 0 扫描到 n − 2，保留数组原始顺序。
  3. 左端不是 key 就跳过；否则令 target = nums[i+1]，其计数加一。
  4. 当新计数严格大于 best 时更新 best 和 answer，最后返回 answer。

示例 2 的四个窗口依次为 (2,2)、(2,2)、(2,2)、(2,3)：数字 2 的计数增长到 3，数字 3 的计数为 1。相邻窗口可以重叠。

正确性

循环不变式：处理完前 k 个相邻对后，count[t] 等于这些相邻对中左端为 key 且右端为 t 的数量，best 为全部计数中的最大值，answer 在 best 非零时指向达到该值的数字。开始时未处理任何对，所有计数为零。不符合条件时不改计数；符合条件时仅对应右端计数增加，只有该数字可能超过旧最大值，因此一次比较足以维持不变式。遍历结束后，每个合法下标都恰好被处理一次，且答案唯一，所以 answer 就是所求数字。

边界与前提

  • 最后一个位置没有右邻居，循环条件必须是 i + 1 < nums.length。
  • key 可以紧跟自己，不能跳过重复数字或一次跳两格。
  • 临时并列时保留当前答案即可，最终答案唯一；若输入允许并列，应另外约定规则。
  • 有效题目输入存在可确定的后继答案。若自定义输入中 key 只在末尾且没有有效后继，演示会拒绝它；代码按官方合法输入前提实现。

复杂度

令 n 为数组长度，U = 1000 为值域上限。时间为 O(n + U)，空间为 O(U)。在题目固定值域下可写成时间 O(n)、额外空间 O(1)。

替代方案

用哈希表按需记录后继数字，适用于值域很大或存在负数的变体；期望时间 O(n)，空间 O(d)，d 为不同后继数字数量。也可以枚举所有候选值并反复扫描数组，但需要 O(n²) 时间，不如一次计数直接。排序会破坏原有相邻关系。

四语言完整提交代码

以下实现使用固定计数数组，函数签名与官方一致；尚未执行验证。

Java

class Solution {
    public int mostFrequent(int[] nums, int key) {
        int[] count = new int[1001];
        int answer = 0, best = 0;
        for (int i = 0; i + 1 < nums.length; i++) {
            if (nums[i] != key) continue;
            int target = nums[i + 1];
            count[target]++;
            if (count[target] > best) {
                best = count[target];
                answer = target;
            }
        }
        return answer;
    }
}

Python

from typing import List

class Solution:
    def mostFrequent(self, nums: List[int], key: int) -> int:
        count = [0] * 1001
        answer = best = 0
        for i in range(len(nums) - 1):
            if nums[i] != key:
                continue
            target = nums[i + 1]
            count[target] += 1
            if count[target] > best:
                best = count[target]
                answer = target
        return answer

C++

#include <vector>
using namespace std;

class Solution {
public:
    int mostFrequent(vector<int>& nums, int key) {
        int count[1001] = {};
        int answer = 0, best = 0;
        for (int i = 0; i + 1 < static_cast<int>(nums.size()); ++i) {
            if (nums[i] != key) continue;
            int target = nums[i + 1];
            ++count[target];
            if (count[target] > best) {
                best = count[target];
                answer = target;
            }
        }
        return answer;
    }
};

面试追问

  • 若输入是数据流？保存前一个数；前一个数等于 key 时，为新读入的数计数。
  • 若要求回答多个不同 key？预处理每种左端数字对应的后继计数表，再记录各自最多的后继。
  • 若并列取最小数字？更新条件加入“计数相等且 target 更小”。

常见错误

  • 把 nums 中所有数字都计数，遗漏左端必须是 key 的条件。
  • 把 key 后的所有位置计入，而非只取紧邻位置。
  • 把最高次数作为返回值；实际要返回数字 target。
  • 数组开成长度 1000，使数值 1000 越界。
  • 去重、排序或跳过重叠窗口，改变题目的相邻出现次数。
