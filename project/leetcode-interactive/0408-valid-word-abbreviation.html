Valid Word Abbreviation

Problem

题意

给定一个只含小写英文字母的单词 word，以及一个由小写字母和数字构成的缩写 abbr。数字表示在原单词中跳过的连续字符数量；缩写中的数字不能以 0 开头。

判断 abbr 是否能够完整、无冲突地表示 word。只有两者都恰好匹配到末尾时，结果才为真。

Example 1

输入
word = "internationalization", abbr = "i12iz4n"
输出
true
说明
i 后跳过 12 个字符，再匹配 i、z，跳过 4 个字符，最后匹配 n。

Example 2

输入
word = "apple", abbr = "a2e"
输出
false
说明
跳过两个字符后到达第二个 l，它与缩写中的 e 不匹配。

函数签名

boolean validWordAbbreviation(string word, string abbr)

约束

  • 1 <= word.length <= 20
  • 1 <= abbr.length <= 10
  • word 仅含小写英文字母。
  • abbr 仅含小写英文字母和数字，数字值可存入 32 位整数。

Deep Dive

双指针一次扫描

核心洞察

用 i 指向 word，用 j 指向 abbr。遇到字母就逐个相等匹配；遇到数字就完整解析连续数字，并让 i 前进相应距离。任何前导零、越界或字母冲突都立即失败。

复杂度

O(n + m) / O(1)

时间扫描两个字符串各一次；额外空间仅使用游标与当前数字。

完整过程

1. 建立两个游标

令 i = 0、j = 0，分别表示尚未消费的起点。

2. 处理缩写字母

若 abbr[j] 是字母，要求它等于 word[i]，然后两个游标各前进一步。

3. 处理完整数字

若是数字，先拒绝 0 开头，再把连续数字合并为跳过量 skip，令 i += skip。

4. 检查精确结束

循环结束后必须同时满足 i == word.length 和 j == abbr.length。

正确性说明

保持不变式：每轮开始时，word[0..i) 恰好由 abbr[0..j) 表示。字母分支只在字符相等时同步推进，因此不变式继续成立；数字分支把一个合法正整数解释为精确跳过量，同样保持对应关系。算法只在发生非法表示时返回假；若最终两个游标同时到达末尾，不变式便说明整个缩写恰好表示整个单词，因此返回真是充分且必要的。

边界情况

  • "0"、"01" 等前导零数字无效。
  • 跳过量超过单词剩余长度时无效。
  • 缩写先结束但单词仍有字符，或反之，均无效。
  • 数字可以连续多位，例如 12 必须整体解析，不能看成 1 和 2。
  • 完全由数字组成的缩写，只在数字恰好等于单词长度时有效。

Java

Solution.java
class Solution {
    public boolean validWordAbbreviation(String word, String abbr) {
        int i = 0;
        int j = 0;

        while (i < word.length() && j < abbr.length()) {
            char current = abbr.charAt(j);

            if (Character.isDigit(current)) {
                if (current == '0') {
                    return false;
                }

                int skip = 0;
                while (j < abbr.length()
                        && Character.isDigit(abbr.charAt(j))) {
                    skip = skip * 10 + (abbr.charAt(j) - '0');
                    j++;
                }
                i += skip;
            } else {
                if (word.charAt(i) != current) {
                    return false;
                }
                i++;
                j++;
            }
        }

        return i == word.length() && j == abbr.length();
    }
}

JavaScript

solution.js
/**
 * @param {string} word
 * @param {string} abbr
 * @return {boolean}
 */
var validWordAbbreviation = function(word, abbr) {
    let i = 0;
    let j = 0;

    while (i < word.length && j < abbr.length) {
        const current = abbr[j];

        if (current >= '0' && current <= '9') {
            if (current === '0') {
                return false;
            }

            let skip = 0;
            while (j < abbr.length
                    && abbr[j] >= '0' && abbr[j] <= '9') {
                skip = skip * 10 + Number(abbr[j]);
                j++;
            }
            i += skip;
        } else {
            if (word[i] !== current) {
                return false;
            }
            i++;
            j++;
        }
    }

    return i === word.length && j === abbr.length;
};

class Solution:
    def validWordAbbreviation(self, word: str, abbr: str) -> bool:
        i = 0
        j = 0

        while i < len(word) and j < len(abbr):
            current = abbr[j]

            if current.isdigit():
                if current == "0":
                    return False

                skip = 0
                while j < len(abbr) and abbr[j].isdigit():
                    skip = skip * 10 + int(abbr[j])
                    j += 1
                i += skip
            else:
                if word[i] != current:
                    return False
                i += 1
                j += 1

        return i == len(word) and j == len(abbr)

solution.cpp
class Solution {
public:
    bool validWordAbbreviation(string word, string abbr) {
        int i = 0;
        int j = 0;

        while (i < static_cast<int>(word.size())
                && j < static_cast<int>(abbr.size())) {
            char current = abbr[j];

            if (isdigit(static_cast<unsigned char>(current))) {
                if (current == '0') {
                    return false;
                }

                int skip = 0;
                while (j < static_cast<int>(abbr.size())
                        && isdigit(static_cast<unsigned char>(abbr[j]))) {
                    skip = skip * 10 + (abbr[j] - '0');
                    ++j;
                }
                i += skip;
            } else {
                if (word[i] != current) {
                    return false;
                }
                ++i;
                ++j;
            }
        }

        return i == static_cast<int>(word.size())
            && j == static_cast<int>(abbr.size());
    }
};

替代方案

可以先展开缩写再比较，但会构造额外字符串；若跳过量很大还可能无意义地扩张空间。双指针更直接，也保留常数额外空间。

面试追问

如果输入以流的形式到达，如何只保留常数状态？如果数字可能超出整数范围，如何在不溢出的情况下提前判定越界？

常见错误

漏判前导零、只读取一个数字位、只检查缩写结束而没检查单词结束，以及跳过后越界仍返回真。
