01 / PROBLEM

任务与规则

给定 m × n 整数矩阵 grid：0 表示草地，1 表示初始火源，2 表示墙。你从左上角 (0,0) 出发，目标是右下角 (m−1,n−1) 的安全屋。

可以先在起点等待若干分钟，等待期间火仍会扩散。出发后，每分钟先向上、下、左、右的相邻草地移动一格，然后火向所有非墙的相邻格扩散。人和火都不能穿墙，也不能斜走。

函数 maximumMinutes(grid) 返回仍能安全抵达终点的最大等待分钟数。即刻出发也不可行时返回 −1；无论等待多久都能逃生时返回 1000000000。

特殊规则：抵达安全屋后，火在同一分钟随后到达安全屋，仍算成功。普通格没有此例外。

完整约束

  • m == grid.length，n == grid[i].length
  • 2 ≤ m, n ≤ 300
  • 4 ≤ m × n ≤ 2 × 10⁴
  • grid[i][j] 只能是 0、1、2。
  • grid[0][0] == grid[m−1][n−1] == 0

05 / SOLUTION

准备好揭开解法了吗？

先尝试比较等待 0、3、4 分钟的变化。完整推导与四语言代码收在这里。

多源 BFS + 二分等待时间

核心洞察

火的扩散不受人的移动影响。先求火最早到达每格的时刻 fire[r][c]，动态火势便成为静态的“到达截止时间”。所有初始火源同时入队做 BFS；无法被火到达的格子记为无穷大。

普通格：人的到达时刻 t < fire[r][c]。

安全屋：人的到达时刻 t ≤ fire[m−1][n−1]。

起点等待结束：wait < fire[0][0]。

完整过程

  1. 多源 BFS 计算 fire。火源时刻为 0，墙不进入队列。
  2. 定义 can(wait)：若起点已着火则失败；否则从 (0,0,wait) 出发 BFS，每步时刻加 1，只进入符合截止时间的草地。
  3. 若 can(0) 为假，返回 −1。令 N=mn，若 can(N) 为真，返回 10⁹。
  4. 否则维护 lo=0 可行、hi=N 不可行。取中点 mid，可行时提高 lo，不可行时降低 hi，直到相邻，返回 lo。

示例 1 可以从起点沿左侧到达底行，再向右进入安全屋。等 3 分钟仍能及时经过沿途格子；等 4 分钟会在关键普通格与火同刻到达，因此失败。

正确性

  1. 火时刻准确：网格的每条边耗时为 1，多源 BFS 逐层确定距离任意火源的最短距离，正是火的最早到达时刻。
  2. 判定充要：只有满足到达时间限制的草地才入队，找到的路线必定安全。任意安全路线的每一步也都满足这些限制，不会被错误过滤。BFS 首次到达某格就是最早时刻，后到不会更安全，故每格只需访问一次。
  3. 单调性：等待 w 可行时，提前出发沿同一路线只会更早到达，因此所有更小等待也可行。二分维持“左端可行、右端不可行”，最终得到最大可行整数。
  4. 无限等待：火若能到达一格，最短路线不会重复节点，至多 N−1 步。等 N 分钟仍可通行的路线必然全由永不着火的格子组成，故可任意等待。反之无限等待当然也允许等 N 分钟。

边界与常见错误

  • 终点允许相等，普通格严格小于；不能把全部判断统一成同一种不等式。
  • 等待期间火会扩散，必须检查起点是否安全。
  • 多个火源需要同时入队，不能只计算其中一个火源。
  • 每次 can 使用新的 visited；最早到达后无需再次访问。
  • 没有火源但被墙阻断时仍是 −1；不能仅凭终点不着火就判断无限等待。
  • 不要模拟等待 10⁹ 分钟。Java / C++ 使用 10⁹ 作为无穷哨兵，实际判定的等待不超过 N，到达时刻小于 2N，不会触及哨兵或溢出。

复杂度

令 N=mn。火 BFS 为 O(N)，每次可行性 BFS 为 O(N)，二分进行 O(log N) 次。总时间 O(mn log(mn))，额外空间 O(mn)。下面的实现均不修改输入。

替代方案

从安全屋反向传播“最晚安全到达时刻”，使用最大堆。普通格上限为 fire−1，安全屋上限为 fire；经过后继格得到的候选值是后继最晚时刻减 1，再与当前格上限取最小。对所有后继取最大，时间 O(N log N)，需谨慎处理无穷值。枚举每个等待时间再 BFS 更直观，但最坏 O(N²)。

面试追问

  • 怎样输出路线？找到最大等待后再 BFS 一次，记录前驱，抵达终点后回溯。
  • 若每次移动耗时不同？非负权情况下使用 Dijkstra 求最早到达时刻，仍按相应截止时间过滤；火速变化时也需调整火的到达时间计算。
  • 中途等待有用吗？火只会扩散，提前到达同一格不会更差，所以中途停留无法改善可行性。
  • 能否只比较终点时间差？沿途普通格也有截止时间，且条件更严格，只比较终点会漏掉瓶颈。

/** @param {number[][]} grid @return {number} */
var maximumMinutes = function(grid) {
    const m=grid.length, n=grid[0].length, N=m*n;
    const dirs=[[1,0],[-1,0],[0,1],[0,-1]];
    const fire=Array.from({length:m},()=>Array(n).fill(Infinity));
    const q=[];
    for(let r=0;r<m;r++) for(let c=0;c<n;c++) {
        if(grid[r][c]===1) { fire[r][c]=0; q.push([r,c]); }
    }
    for(let h=0;h<q.length;h++) {
        const [r,c]=q[h];
        for(const [dr,dc] of dirs) {
            const x=r+dr, y=c+dc;
            if(x<0 || x>=m || y<0 || y>=n || grid[x][y]===2 || fire[x][y]!==Infinity) continue;
            fire[x][y]=fire[r][c]+1; q.push([x,y]);
        }
    }
    function can(wait) {
        if(wait>=fire[0][0]) return false;
        const seen=Array.from({length:m},()=>Array(n).fill(false));
        const q=[[0,0,wait]]; seen[0][0]=true;
        for(let h=0;h<q.length;h++) {
            const [r,c,t]=q[h];
            for(const [dr,dc] of dirs) {
                const x=r+dr, y=c+dc, nt=t+1;
                if(x<0 || x>=m || y<0 || y>=n || grid[x][y]!==0 || seen[x][y]) continue;
                const goal=x===m-1 && y===n-1;
                if(goal ? nt>fire[x][y] : nt>=fire[x][y]) continue;
                if(goal) return true;
                seen[x][y]=true; q.push([x,y,nt]);
            }
        }
        return false;
    }
    if(!can(0)) return -1;
    if(can(N)) return 1000000000;
    let lo=0, hi=N;
    while(lo+1<hi) {
        const mid=Math.floor((lo+hi)/2);
        if(can(mid)) lo=mid; else hi=mid;
    }
    return lo;
};

Python

from typing import List
from collections import deque

class Solution:
    def maximumMinutes(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        N = m * n
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))
        fire = [[float('inf')] * n for _ in range(m)]
        q = deque()
        for r in range(m):
            for c in range(n):
                if grid[r][c] == 1:
                    fire[r][c] = 0
                    q.append((r, c))
        while q:
            r, c = q.popleft()
            for dr, dc in dirs:
                x, y = r + dr, c + dc
                if (0 <= x < m and 0 <= y < n and grid[x][y] != 2
                        and fire[x][y] == float('inf')):
                    fire[x][y] = fire[r][c] + 1
                    q.append((x, y))

        def can(wait):
            if wait >= fire[0][0]:
                return False
            seen = {(0, 0)}
            q = deque([(0, 0, wait)])
            while q:
                r, c, t = q.popleft()
                for dr, dc in dirs:
                    x, y, nt = r + dr, c + dc, t + 1
                    if not (0 <= x < m and 0 <= y < n):
                        continue
                    if grid[x][y] != 0 or (x, y) in seen:
                        continue
                    goal = x == m - 1 and y == n - 1
                    if (nt > fire[x][y]) if goal else (nt >= fire[x][y]):
                        continue
                    if goal:
                        return True
                    seen.add((x, y))
                    q.append((x, y, nt))
            return False

        if not can(0):
            return -1
        if can(N):
            return 10**9
        lo, hi = 0, N
        while lo + 1 < hi:
            mid = (lo + hi) // 2
            if can(mid):
                lo = mid
            else:
                hi = mid
        return lo

Java

import java.util.*;

class Solution {
    private int m, n;
    private int[][] grid, fire;
    private final int[][] dirs={{1,0},{-1,0},{0,1},{0,-1}};
    private static final int INF=1_000_000_000;

    public int maximumMinutes(int[][] grid) {
        this.grid=grid;
        m=grid.length; n=grid[0].length;
        fire=new int[m][n];
        ArrayDeque<int[]> q=new ArrayDeque<>();
        for(int r=0;r<m;r++) {
            Arrays.fill(fire[r], INF);
            for(int c=0;c<n;c++) {
                if(grid[r][c]==1) {
                    fire[r][c]=0; q.offer(new int[]{r,c});
                }
            }
        }
        while(!q.isEmpty()) {
            int[] p=q.poll();
            for(int[] d:dirs) {
                int x=p[0]+d[0], y=p[1]+d[1];
                if(x<0 || x>=m || y<0 || y>=n || grid[x][y]==2 || fire[x][y]!=INF) continue;
                fire[x][y]=fire[p[0]][p[1]]+1;
                q.offer(new int[]{x,y});
            }
        }
        int N=m*n;
        if(!can(0)) return -1;
        if(can(N)) return INF;
        int lo=0, hi=N;
        while(lo+1<hi) {
            int mid=lo+(hi-lo)/2;
            if(can(mid)) lo=mid; else hi=mid;
        }
        return lo;
    }
    private boolean can(int wait) {
        if(wait>=fire[0][0]) return false;
        boolean[][] seen=new boolean[m][n];
        ArrayDeque<int[]> q=new ArrayDeque<>();
        q.offer(new int[]{0,0,wait}); seen[0][0]=true;
        while(!q.isEmpty()) {
            int[] p=q.poll();
            for(int[] d:dirs) {
                int x=p[0]+d[0], y=p[1]+d[1], t=p[2]+1;
                if(x<0 || x>=m || y<0 || y>=n || grid[x][y]!=0 || seen[x][y]) continue;
                boolean goal=x==m-1 && y==n-1;
                if(goal ? t>fire[x][y] : t>=fire[x][y]) continue;
                if(goal) return true;
                seen[x][y]=true; q.offer(new int[]{x,y,t});
            }
        }
        return false;
    }
}

#include <vector>
#include <queue>
#include <array>
#include <utility>
using namespace std;

class Solution {
public:
    int maximumMinutes(vector<vector<int>>& grid) {
        int m=grid.size(), n=grid[0].size(), N=m*n;
        const int INF=1000000000;
        const int dirs[4][2]={{1,0},{-1,0},{0,1},{0,-1}};
        vector<vector<int>> fire(m, vector<int>(n, INF));
        queue<pair<int,int>> q;
        for(int r=0;r<m;++r) for(int c=0;c<n;++c) {
            if(grid[r][c]==1) { fire[r][c]=0; q.push({r,c}); }
        }
        while(!q.empty()) {
            auto [r,c]=q.front(); q.pop();
            for(auto& d:dirs) {
                int x=r+d[0], y=c+d[1];
                if(x<0 || x>=m || y<0 || y>=n || grid[x][y]==2 || fire[x][y]!=INF) continue;
                fire[x][y]=fire[r][c]+1; q.push({x,y});
            }
        }
        auto can = [&](int wait) -> bool {
            if(wait>=fire[0][0]) return false;
            vector<vector<bool>> seen(m, vector<bool>(n, false));
            queue<array<int,3>> pq;
            pq.push({0,0,wait}); seen[0][0]=true;
            while(!pq.empty()) {
                auto p=pq.front(); pq.pop();
                for(auto& d:dirs) {
                    int x=p[0]+d[0], y=p[1]+d[1], t=p[2]+1;
                    if(x<0 || x>=m || y<0 || y>=n || grid[x][y]!=0 || seen[x][y]) continue;
                    bool goal=x==m-1 && y==n-1;
                    if(goal ? t>fire[x][y] : t>=fire[x][y]) continue;
                    if(goal) return true;
                    seen[x][y]=true; pq.push({x,y,t});
                }
            }
            return false;
        };
        if(!can(0)) return -1;
        if(can(N)) return INF;
        int lo=0, hi=N;
        while(lo+1<hi) {
            int mid=lo+(hi-lo)/2;
            if(can(mid)) lo=mid; else hi=mid;
        }
        return lo;
    }
};
