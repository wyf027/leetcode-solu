PARSING / BOOLEAN EXPRESSION

解析布尔表达式

把嵌套语法看成一台袖珍求值机：逐字符入栈，每遇到右括号，就让最内层表达式立即“坍缩”为一个真值。

题目

给定字符串 expression，它表示一个合法的布尔表达式，返回表达式的布尔结果。

表达式语法

  • t 为 true，f 为 false。
  • !(subExpr) 对内部结果取反。
  • &(e₁,e₂,…,eₙ) 对一个或多个子表达式求逻辑与。
  • |(e₁,e₂,…,eₙ) 对一个或多个子表达式求逻辑或。

函数与约束

parseBoolExpr(expression: string): boolean
  • 1 ≤ expression.length ≤ 2 × 10⁴
  • 字符只来自 ( ) & | ! t f ,。
  • 输入保证符合上述文法。

官方示例

示例 1
输入：expression = "&(|(f))"
输出：false
解释：|(f) → f，再由 &(f) → f。
示例 2
输入：expression = "|(f,f,f,t)"
输出：true
解释：OR 的操作数中存在 true。
示例 3
输入：expression = "!(&(f,t))"
输出：true
解释：&(f,t) → f，随后 !(f) → t。

题解：用栈即时归约

核心洞察：右括号意味着最内层操作数已经完整出现。弹出这一组真值及其运算符，并将整个子表达式压缩为一个 t 或 f。

完整过程

  1. 从左到右扫描，跳过逗号和左括号。
  2. 将真值和运算符压栈。
  3. 遇到 )，弹出连续真值并统计是否见过真、假。
  4. 弹出运算符：! 翻转；& 在没有假值时为真；| 在存在真值时为真。
  5. 结果压回栈；扫描结束后返回栈顶。

正确性

不变式：任意已扫描前缀中，已闭合的子表达式在栈里均由其准确真值替代，未闭合部分保持原顺序。遇到右括号时，合法语法保证栈顶的连续真值正是最内层表达式的全部操作数；按对应布尔定义归约后，新字符与该子表达式等价，所以不变式保持。最终整个表达式被等价替换为栈顶真值，答案正确。

复杂度

时间 O(n)，每个有效字符至多进出栈一次；空间 O(n)，用于显式栈。

边界情况

  • 单值 t 或 f 不触发归约。
  • 连续嵌套取反，如 !(!(t))。
  • 大量操作数只需记录是否出现真或假，无需构造语法树。
  • 长度可达 20,000，显式栈避免递归深度风险。

class Solution {
    public boolean parseBoolExpr(String expression) {
        java.util.Deque<Character> st = new java.util.ArrayDeque<>();
        for (char ch : expression.toCharArray()) {
            if (ch == ',' || ch == '(') continue;
            if (ch != ')') { st.push(ch); continue; }
            boolean hasT = false, hasF = false;
            while (st.peek() == 't' || st.peek() == 'f') {
                char v = st.pop(); hasT |= v == 't'; hasF |= v == 'f';
            }
            char op = st.pop();
            boolean v = op == '!' ? hasF : op == '&' ? !hasF : hasT;
            st.push(v ? 't' : 'f');
        }
        return st.peek() == 't';
    }
}

var parseBoolExpr = function(expression) {
    const st = [];
    for (const ch of expression) {
        if (ch === ',' || ch === '(') continue;
        if (ch !== ')') { st.push(ch); continue; }
        let hasT = false, hasF = false;
        while (st.at(-1) === 't' || st.at(-1) === 'f') {
            const v = st.pop();
            hasT ||= v === 't'; hasF ||= v === 'f';
        }
        const op = st.pop();
        const v = op === '!' ? hasF : op === '&' ? !hasF : hasT;
        st.push(v ? 't' : 'f');
    }
    return st[0] === 't';
};

替代方案

递归下降：按文法递归解析单值或括号参数，结构直观，但最坏 O(n) 调用深度可能超限。

反复字符串替换：寻找最内层括号再替换会产生大量搬移，可能退化为 O(n²)。

常见错误

  • 将左括号入栈后，归约时却忘记弹出。
  • 只用最后一个操作数决定 AND/OR，而非检查整组。
  • 忘记跳过逗号，使其混入操作数。
  • 将 ! 写成对计数取反，而非翻转唯一布尔值。
