1916 · 统计为蚁群构筑房间的不同顺序

Count Ways to Build Rooms in an Ant Colony

先探索建造限制，再展开底部的数学解释。

题意与约束

给定 prevRoom，共 n 个房间，编号 0 到 n−1。房间 0 已建成，prevRoom[0] = -1。建造房间 i 前必须先建好它的父房间 prevRoom[i]，并将两者直接连接。每次只能建一间，可在已连接的已建房间间移动。计划保证最终每间房间都能从 0 到达。

计算完成所有房间的合法建造顺序数，返回对 1,000,000,007 取模的结果。展示顺序时把已建房间 0 写在开头，不额外计数。

  • n == prevRoom.length
  • 2 ≤ n ≤ 100000
  • prevRoom[0] == -1
  • 每个 1 ≤ i < n 都满足 0 ≤ prevRoom[i] < n
  • 最终所有房间从 0 可达；父编号不一定小于子编号。

题解 · 子树内部有序，子树之间交错

核心洞察

父子关系构成以 0 为根的树。令 s[u] 为包含 u 的子树大小，f[u] 为该子树的合法顺序数。固定 u 在最前面，孩子子树各自保留内部顺序，不同子树可以任意交错。

f[u] = (s[u]−1)! × ∏( f[v] / s[v]! )   （v 为 u 的孩子）
展开并消去阶乘：
f[0] = (n−1)! / ∏ s[u]                  （u ≠ 0）

这里的除法是模逆元。设 D = ∏ s[u] mod P，P = 10⁹+7；答案为 (n−1)! × D^(P−2) mod P。

交错槽位实验

示例 2：链 A = [1,3]，链 B = [2,4]。从四个位置中选两个放 A，其余放 B。每条链的内部顺序保持不变，得到 C(4,2)=6 种交错。使用选择框查看每一种分配。

完整过程

  1. 统计每个节点尚未处理的孩子数 left，令所有 s 初始为 1。
  2. 将叶节点入队。弹出 u 时，所有孩子已经汇总完毕，因此 s[u] 已确定。
  3. 若 u 不是根，将 s[u] 乘入分母 D，并加到父节点大小。父节点最后一个孩子处理完后入队。
  4. 计算 (n−1)!，用快速幂计算 D 的逆元，得到答案。

示例 2 的子树大小为 [5,2,2,1,1]；D=4，答案 4!/4=6。队列从叶向根处理，避免长度 100000 的链造成递归栈溢出。

正确性证明

对树的高度归纳。叶节点只有一种顺序，公式给出 0!=1。对非叶节点，根必须最先出现。随后按孩子子树的大小分配位置，有 (s[u]−1)! / ∏s[v]! 种；每个孩子在其位置中填入任一种合法顺序，乘上 ∏f[v]。任何合法序列唯一对应一组位置分配和孩子序列，所以既无遗漏也不重复。

递归展开时，每个非根节点的 (s[u]−1)! 与父式中的 s[u]! 相除，恰好剩下 1/s[u]，得到最终公式。队列只在孩子全部处理后处理父亲，因此计算的 s 与真实子树大小一致。所有 s[u] 小于 P，分母不为零，费马小定理保证模逆合法。

边界与常见错误

  • 链状树：只有一种顺序；星形树：(n−1)! 种。
  • 根已经建好，应使用 (n−1)! 并排除根大小；也可一致使用 n! / ∏所有节点大小。
  • 不能只乘孩子方案数：还需要交错位置的组合数。
  • 不能按编号倒序假装后序遍历；父编号可能比子编号大。
  • 模运算不能使用普通整数除法。Java/C++ 中间乘积用 64 位整数；JavaScript 必须用 BigInt，Number 的乘积可能丢精度。
  • 不要用深递归，也不要在 JavaScript 中反复 shift 队列；使用头指针。

复杂度与替代方案

时间 O(n + log P)，空间 O(n)。固定模数时通常记作 O(n) 时间。替代方案是直接实现树形 DP：预处理阶乘与逆阶乘，自底向上按多项式系数合并，复杂度相同但数组更多。小规模可回溯枚举所有可建房间，最坏阶乘级，仅适合解释或少量房间。

面试追问

如果变成任意 DAG？树上的子树不再独立，当前乘法公式失效。若每次能同时建多间？需要先定义顺序是批次还是时间安排，不能直接套用本题计数。若模数不是质数？费马逆元不再通用，要处理分母与模数的公因子。

import java.util.*;
class Solution {
    static final long MOD = 1_000_000_007L;
    long pow(long a, long b) {
        long r = 1;
        while (b > 0) {
            if ((b & 1) != 0) r = r * a % MOD;
            a = a * a % MOD;
            b >>= 1;
        }
        return r;
    }
    public int waysToBuildRooms(int[] prevRoom) {
        int n = prevRoom.length;
        int[] left = new int[n], size = new int[n];
        Arrays.fill(size, 1);
        for (int i = 1; i < n; i++) left[prevRoom[i]]++;
        ArrayDeque<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < n; i++) if (left[i] == 0) q.add(i);
        long den = 1, fact = 1;
        while (!q.isEmpty()) {
            int u = q.remove();
            if (u == 0) continue;
            den = den * size[u] % MOD;
            int parent = prevRoom[u];
            size[parent] += size[u];
            if (--left[parent] == 0) q.add(parent);
        }
        for (int i = 2; i < n; i++) fact = fact * i % MOD;
        return (int)(fact * pow(den, MOD - 2) % MOD);
    }
}

/** @param {number[]} prevRoom @return {number} */
var waysToBuildRooms = function(prevRoom) {
    const MOD = 1000000007n, n = prevRoom.length;
    const left = new Int32Array(n), size = new Int32Array(n).fill(1);
    for (let i = 1; i < n; i++) left[prevRoom[i]]++;
    const q = [];
    for (let i = 0; i < n; i++) if (left[i] === 0) q.push(i);
    let den = 1n, fact = 1n;
    for (let head = 0; head < q.length; head++) {
        const u = q[head];
        if (u === 0) continue;
        den = den * BigInt(size[u]) % MOD;
        const parent = prevRoom[u];
        size[parent] += size[u];
        if (--left[parent] === 0) q.push(parent);
    }
    for (let i = 2; i < n; i++) fact = fact * BigInt(i) % MOD;
    let base = den, exp = MOD - 2n, inv = 1n;
    while (exp > 0n) {
        if (exp & 1n) inv = inv * base % MOD;
        base = base * base % MOD;
        exp >>= 1n;
    }
    return Number(fact * inv % MOD);
};

Python

from typing import List
from collections import deque

class Solution:
    def waysToBuildRooms(self, prevRoom: List[int]) -> int:
        mod = 10**9 + 7
        n = len(prevRoom)
        left, size = [0] * n, [1] * n
        for i in range(1, n):
            left[prevRoom[i]] += 1
        q = deque(i for i in range(n) if left[i] == 0)
        den = fact = 1
        while q:
            u = q.popleft()
            if u == 0:
                continue
            den = den * size[u] % mod
            parent = prevRoom[u]
            size[parent] += size[u]
            left[parent] -= 1
            if left[parent] == 0:
                q.append(parent)
        for i in range(2, n):
            fact = fact * i % mod
        return fact * pow(den, mod - 2, mod) % mod

C++

#include <vector>
#include <queue>
using namespace std;
class Solution {
    static constexpr long long MOD = 1000000007;
    long long power(long long a, long long b) {
        long long r = 1;
        while (b) {
            if (b & 1) r = r * a % MOD;
            a = a * a % MOD;
            b >>= 1;
        }
        return r;
    }
public:
    int waysToBuildRooms(vector<int>& prevRoom) {
        int n = prevRoom.size();
        vector<int> left(n), size(n, 1);
        for (int i = 1; i < n; ++i) ++left[prevRoom[i]];
        queue<int> q;
        for (int i = 0; i < n; ++i) if (!left[i]) q.push(i);
        long long den = 1, fact = 1;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            if (u == 0) continue;
            den = den * size[u] % MOD;
            int parent = prevRoom[u];
            size[parent] += size[u];
            if (--left[parent] == 0) q.push(parent);
        }
        for (int i = 2; i < n; ++i) fact = fact * i % MOD;
        return fact * power(den, MOD - 2) % MOD;
    }
};
