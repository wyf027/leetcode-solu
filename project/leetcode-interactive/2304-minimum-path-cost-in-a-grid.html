网格中的最小路径代价

Minimum Path Cost in a Grid

每一行只选一个落点。除了格子的数值，跨行的那一步也要付费。

打开官方题目 ↗

01 / 题目与规则

给定下标从 0 开始、大小为 m × n 的整数矩阵 grid。其中的值互不相同，恰好来自 0 … m*n-1。从第一行任意格子出发，每一步只能进入下一行的任意一列，直到最后一行。

moveCost 大小为 (m*n) × n。从值为 v 的格子移到下一行第 j 列，需要支付 moveCost[v][j]。这里第一个索引是出发格的值，第二个索引是落点的列号。最后一行不会再产生移动费用。

一条路径的总代价 = 经过的所有格子值之和 + 每次移动费用之和。返回所有合法路径中的最小总代价。

参数：minPathCost(grid: integer[][], moveCost: integer[][]) → integer

约束

  • m == grid.length，n == grid[i].length。
  • 2 ≤ m, n ≤ 50。
  • grid 包含 0 到 m*n-1 的不同整数。
  • moveCost.length == m*n，moveCost[i].length == n。
  • 1 ≤ moveCost[i][j] ≤ 100。

02 / 官方示例

示例 1

grid = [[5,3],[4,0],[2,1]]
moveCost = [[9,8],[1,5],[10,12],[18,6],[2,4],[14,3]]

输出：17

路径 5 → 0 → 1。格子值之和为 6，两次移动费分别为 3、8，总计 6 + 3 + 8 = 17。

示例 2

grid = [[5,1,2],[4,0,3]]
moveCost = [[12,10,15],[20,23,8],[21,7,1],[8,1,13],[9,10,25],[5,3,2]]

输出：6

路径 2 → 3。格子值之和为 5，移动费为 1，总计 5 + 1 = 6。

04 / 独立题解

先思考：进入同一个格子的两条路径，后续可选择的道路有什么不同？展开后可查看逐步演示、推导与四种语言实现。

核心洞察：只保留到每个格子的最小代价

到达同一个格子后，下一步的费用只取决于当前格子值和目标列，与之前走过的路径无关。因此，较贵的前缀永远不会优于较便宜的前缀。

定义 dp[r][j] 为从第一行出发，到达第 r 行第 j 列的最小总代价，已经包含当前格子值。

dp[0][j] = grid[0][j]
dp[r][j] = min over k (
    dp[r-1][k] + moveCost[grid[r-1][k]][j] + grid[r][j]
)
answer = min(dp[m-1])

按行推进，每个目标列都比较上一行所有来源列。下一行只依赖上一行，可以用两个长度为 n 的数组滚动保存。

跨行报价台

每一步是一条候选边：用黄色来源的累计费用，给青色目标报价。数字下方展示当前最优累计费用；∞ 表示尚未收到报价。演示计算不代表已执行验证。

完整过程
  1. 第一行可以任选起点，初始费用就是各格子自身的值。
  2. 处理下一行时，新建全部为无穷大的 next 数组。
  3. 枚举目标列 j，再枚举来源列 k，计算“来源最优费用 + 移动费 + 目标格子值”，更新 next[j]。
  4. 整行完成后令 dp = next，继续处理后续行。
  5. 最后返回末行所有累计费用的最小值。
示例 1：初始 [5,3]；第二行为 [23,8]（到 0 可由 5 支付 3 到达）；第三行为 [19,17]。最终取 17。


为什么正确
基础：第一行没有移动，抵达每个格子的最低代价等于自身数值。
归纳：假设上一行每个状态都是最优值。任何到达当前格子 j 的合法路径，倒数第二个格子必在上一行某列 k。把其前缀替换为该 k 的最优路径不会增大费用。枚举全部 k 并取最小值，既覆盖每条路径的最后一步，也能由一个真实最优前缀加上这一步实现，因此得到的当前状态恰为最优。
终止：每条合法路径都停在末行某列，取末行最小状态就是全局最优代价。


复杂度与数值边界
时间 O(mn²)；滚动数组辅助空间 O(n)。每条路径至多包含 m 个值和 m−1 次移动，总代价不超过 50×2499 + 49×100 = 129850，32 位有符号整数足够。实现用 10⁹ 作哨兵的语言也不会在本题范围内溢出。


边界与常见错误
  • 最小规模是 2×2；零是合法格子值，不能把 0 当成未访问。
  • 起点、终点都可以在任意列，不能固定左上角或右下角。
  • 费用应查 moveCost[grid[r-1][k]][j]，不要用来源列 k 或目标格子值索引。
  • 不要重复加入来源格子值；它已经包含在 dp 中。
  • 不能原地覆盖上一行 dp，否则会混用两行状态。
  • 最后一行的 moveCost 条目不读取；并列最优任选其一即可。


替代方案
保存完整二维 DP 同样需要 O(mn²) 时间，空间 O(mn)，适合回溯路径。记忆化搜索也可实现相同状态，但有递归栈开销。把网格当成按行分层的有向无环图，其拓扑最短路就是本方法；通用 Dijkstra 的优先队列没有必要。穷举全部路径有 nᵐ 条候选，只能用于很小的实例。


面试追问
  • 如何返回具体路径？在每个状态记下获胜来源列，选出末行最优列后倒推，额外 O(mn) 空间。
  • 出现负费用还成立吗？仍成立，因为只能向下一行移动，没有环；需重新考虑数值范围和哨兵。
  • 可以贪心吗？不能。示例 1 第一行最小值 3 并非最佳起点；当前便宜不代表后续费用低。
  • 能否普遍降为 O(mn)？任意费用表下，每个目标列需比较全部来源；只有费用具备额外结构时才可能进一步优化。

Java
import java.util.Arrays;

class Solution {
    public int minPathCost(int[][] grid, int[][] moveCost) {
        int m = grid.length, n = grid[0].length;
        int[] dp = grid[0].clone();
        for (int r = 1; r < m; r++) {
            int[] next = new int[n];
            Arrays.fill(next, 1_000_000_000);
            for (int j = 0; j < n; j++) {
                for (int k = 0; k < n; k++) {
                    int cost = dp[k] + moveCost[grid[r - 1][k]][j]
                               + grid[r][j];
                    next[j] = Math.min(next[j], cost);
                }
            }
            dp = next;
        }
        int answer = dp[0];
        for (int cost : dp) answer = Math.min(answer, cost);
        return answer;
    }
}

        dp = grid[0][:]

            next_dp = [10**9] * n
