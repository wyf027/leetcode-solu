有效的正方形

Valid Square — 四个散落在二维平面上的点，究竟能不能围成一个边长大于零、四边等长且四角均为直角的正方形？

输入无序 二维坐标 返回 boolean
Problem

题目描述

给定二维空间中四个点 p1、p2、p3、p4 的坐标。如果它们能够构成一个有效的正方形，返回 true；否则返回 false。

每个点以 [xi, yi] 表示，四个点的输入顺序任意。有效正方形必须有四条长度相等且大于零的边，并有四个 90° 角。

函数签名： validSquare(p1, p2, p3, p4) → boolean
Limits

约束

  • p1.length == p2.length == p3.length == p4.length == 2
  • -10⁴ <= xi, yi <= 10⁴

坐标差的平方和在常见 32 位有符号整数范围内；实现时仍应留意语言的数值类型。

Solution

六个距离，一次排序

核心洞察：四个点一共形成 6 组两两距离。若构成正方形，排序后的平方距离必为 s, s, s, s, 2s, 2s，并且 s > 0。

完整过程

  1. 枚举四个点的所有两两组合，得到恰好 6 个平方距离。
  2. 将 6 个平方距离按非递减顺序排序。
  3. 检查最小距离大于 0，排除点重合和退化图形。
  4. 检查前 4 个距离全部相等，它们对应四条边。
  5. 检查后 2 个距离相等，并且等于边长平方的 2 倍。

为什么使用平方距离？

两点 (x1,y1)、(x2,y2) 的平方距离是 (x1-x2)² + (y1-y2)²。比较大小与相等性时不必开平方，既避免浮点误差，也更简单。

正方形对角线由勾股定理满足 d² = s² + s² = 2s²。

正确性证明

  • 1必要性：若四点构成正方形，则四条边等长且非零；两条对角线等长。由勾股定理，每条对角线的平方长度都是边长平方的 2 倍，所以排序结果满足判定式。
  • 2充分性：若 6 个平方距离是四个相同正数 s 与两个相同的 2s，最远的两组点对是两条等长对角线；其余四组是等长边。两条对角线互相平分，且每个由两条边构成的角满足勾股定理，因此四角均为直角，四点构成非退化正方形。
  • 3结论：算法返回 true 当且仅当四点构成有效正方形。

边界情况

  • 两个或更多点重合：最小平方距离为 0，必须返回 false。
  • 四点共线：不能形成四个相同的正边长与两条合规对角线。
  • 菱形但非正方形：四边虽相等，两条对角线通常不等。
  • 矩形但非正方形：两条对角线相等，但四条边不全等。
  • 负坐标、旋转形状和无序输入：平方距离方法不受影响。

复杂度

时间：O(1)。只计算固定的 6 个距离并排序固定长度数组；若按一般形式书写，排序是 O(6 log 6)。

空间：O(1)，仅保存 6 个距离。

常见错误

  • 只检查四边相等，误把非直角菱形当成正方形。
  • 忘记检查最小距离大于 0，让重合点通过。
  • 假设输入已经沿正方形边界排序。
  • 用开平方后的浮点数直接比较相等。
  • 只检查两条对角线相等，误把普通矩形当成正方形。

Java · 官方提交签名
import java.util.Arrays;

class Solution {
    public boolean validSquare(int[] p1, int[] p2,
                               int[] p3, int[] p4) {
        int[][] points = {p1, p2, p3, p4};
        long[] distances = new long[6];
        int index = 0;

        for (int i = 0; i < 4; i++) {
            for (int j = i + 1; j < 4; j++) {
                distances[index++] = squaredDistance(points[i], points[j]);
            }
        }

        Arrays.sort(distances);
        return distances[0] > 0
            && distances[0] == distances[1]
            && distances[1] == distances[2]
            && distances[2] == distances[3]
            && distances[4] == distances[5]
            && distances[4] == 2 * distances[0];
    }

    private long squaredDistance(int[] a, int[] b) {
        long dx = (long) a[0] - b[0];
        long dy = (long) a[1] - b[1];
        return dx * dx + dy * dy;
    }
}

var validSquare = function(p1, p2, p3, p4) {
    const points = [p1, p2, p3, p4];
    const distances = [];

    const squaredDistance = (a, b) => {
        const dx = a[0] - b[0];
        const dy = a[1] - b[1];
        return dx * dx + dy * dy;
    };

    for (let i = 0; i < 4; i++) {
        for (let j = i + 1; j < 4; j++) {
            distances.push(squaredDistance(points[i], points[j]));
        }
    }

    distances.sort((a, b) => a - b);
    return distances[0] > 0
        && distances[0] === distances[1]
        && distances[1] === distances[2]
        && distances[2] === distances[3]
        && distances[4] === distances[5]
        && distances[4] === 2 * distances[0];
};

C++ · 官方提交签名
class Solution {
public:
    bool validSquare(vector<int>& p1, vector<int>& p2,
                     vector<int>& p3, vector<int>& p4) {
        vector<vector<int>*> points = {&p1, &p2, &p3, &p4};
        vector<long long> distances;

        for (int i = 0; i < 4; ++i) {
            for (int j = i + 1; j < 4; ++j) {
                distances.push_back(squaredDistance(*points[i], *points[j]));
            }
        }

        sort(distances.begin(), distances.end());
        return distances[0] > 0
            && distances[0] == distances[1]
            && distances[1] == distances[2]
            && distances[2] == distances[3]
            && distances[4] == distances[5]
            && distances[4] == 2 * distances[0];
    }

private:
    long long squaredDistance(const vector<int>& a,
                              const vector<int>& b) {
        long long dx = static_cast<long long>(a[0]) - b[0];
        long long dy = static_cast<long long>(a[1]) - b[1];
        return dx * dx + dy * dy;
    }
};

替代方案与面试追问

方向做法取舍 / 追问
从单点出发任选一个点，计算它到另外三点的距离；应出现两条相等短边和一条两倍平方距离的对角线，再验证剩余关系。可做到固定比较，但分支更多，更容易漏掉退化情况。
向量与点积先确定相邻点顺序，再检查相邻边等长、点积为 0。面试官可能追问：输入无序时如何稳定找到相邻点？
距离计数用映射统计 6 个平方距离的频次：应恰有两个键，频次为 4 和 2，且较大值是较小值的 2 倍。表达直观，但引入映射；仍要单独排除距离 0。
数值安全在坐标范围扩大时使用 64 位整数或更宽类型保存差值与平方和。追问：若坐标是浮点数，应使用怎样的容差策略？
