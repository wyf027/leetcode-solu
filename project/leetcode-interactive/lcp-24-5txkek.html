数字游戏 双堆中位数工作台

目标等差数组可以写成 x+i。令 a[i]=nums[i]-i，每个前缀只需选择一个 x，使绝对偏差和最小；最优 x 是中位数。

题意

对每个前缀 nums[0..i]，加减单个数字，使最终满足相邻差为 1，返回最少操作次数（模 1,000,000,007）。

输入

nums = [3,4,5,1,6,7]

输出

[0,0,0,5,6,7]

变换

a[i] = nums[i] - i

参数完整显示为 nums = [...]；空格若出现会显示为 ␠。

双堆不变量

  • 大根堆 left 保存较小半边，堆顶就是下中位数。
  • 小根堆 right 保存较大半边。
  • 维护 sumLeft、sumRight，用公式 O(1) 求偏差和。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

推导与过程

            
    
              
  1. 
                若最终前缀为 [x,x+1,...]，第 i 项代价是
                |nums[i]-(x+i)|=|a[i]-x|。
              
    2. 
              
  2. 绝对距离和由中位数最小。
    3. 
              
  3. 
                每插入一个 a[i]，放入双堆并平衡，使 left 大小等于 right 或多 1。
              
    4. 
              
  4. 
                令 m=left.top，答案为
                m*left.size-sumLeft + sumRight-m*right.size。
              
    5. 
            

          

          

            

              
边界与复杂度

              

                单元素答案 0；重复值自然适用；数值和应使用 64
                位。每个元素入堆、出堆 O(log n)，共 O(n log n) 时间和 O(n)
                空间。
              

            

            

              
替代方案与错误

              

                可用有序多重集合或 Fenwick 树维护中位数。常见错误：忘记减
                i、取均值而非中位数、没有同步维护两侧和、在取模前使用 32
                位整数溢出。

// Java
class Solution { public int[] numsGame(int[] nums) { int n=nums.length,MOD=1000000007; int[] ans=new int[n]; PriorityQueue<Integer>l=new PriorityQueue<>((a,b)->b-a),r=new PriorityQueue<>(); long sl=0,sr=0; for(int i=0;i<n;i++){int x=nums[i]-i;if(l.isEmpty()||x<=l.peek()){l.offer(x);sl+=x;}else{r.offer(x);sr+=x;}if(l.size()<r.size()){int v=r.poll();sr-=v;l.offer(v);sl+=v;}if(l.size()>r.size()+1){int v=l.poll();sl-=v;r.offer(v);sr+=v;}long m=l.peek(),v=m*l.size()-sl+sr-m*r.size();ans[i]=(int)(v%MOD);}return ans;} }

# Python
class Solution:
 def numsGame(self,nums):
  import heapq
  L=[];R=[];sl=sr=0;ans=[];MOD=10**9+7
  for i,v in enumerate(nums):
   x=v-i
   if not L or x<=-L[0]:heapq.heappush(L,-x);sl+=x
   else:heapq.heappush(R,x);sr+=x
   if len(L)<len(R):z=heapq.heappop(R);sr-=z;heapq.heappush(L,-z);sl+=z
   if len(L)>len(R)+1:z=-heapq.heappop(L);sl-=z;heapq.heappush(R,z);sr+=z
   m=-L[0];ans.append((m*len(L)-sl+sr-m*len(R))%MOD)
  return ans
