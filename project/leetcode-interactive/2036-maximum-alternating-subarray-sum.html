最大交替子数组和

Maximum Alternating Subarray Sum

MEDIUM 付费题 · 数组

选中一段连续区间，从它的第一个数开始，依次加、减、加、减。你能找到最大的结果吗？

01 / 题目

给定整数数组 nums，选择一个非空连续子数组 nums[l..r]，其交替和为 nums[l] − nums[l+1] + nums[l+2] − …。返回所有选择中最大的交替和。每段的首项总是加号，与它在原数组中的下标奇偶无关。

maximumAlternatingSubarraySum(nums: integer[]) → long

约束：1 ≤ nums.length ≤ 10⁵；−10⁵ ≤ nums[i] ≤ 10⁵。

官方示例 1

输入：nums = [3,-1,1,2]
输出：5

选择 [3,−1,1]，得到 3 − (−1) + 1 = 5。

官方示例 2

输入：nums = [2,2,2,2,2]
输出：2

选择任意奇数长度的连续区间，交替和为 2。

官方示例 3

输入：nums = [1]
输出：1

唯一的非空区间就是 [1]。

04 / 题解：记录末项的符号
核心洞察
一个以当前位置结尾的区间，下一步如何扩展，只取决于它的长度奇偶。用 P 表示奇数长度（末项加号）的最大交替和，用 M 表示偶数长度（末项减号）的最大交替和。二者都必须是以当前下标结尾的非空区间。
newP = max(x, oldM + x)
newM = oldP - x
answer = max(answer, newP, newM)
完整过程
  1. 初始化 P = nums[0]，M = −∞，answer = P。第一项只有一个长度为 1 的区间。
  2. 从第二个元素 x 开始，新 P 可由 x 单独开始，或由旧 M 加上 x；新 M 只能由旧 P 减去 x。
  3. 先计算两个新状态，再同时替换旧状态。把两个新值都计入全局答案。
nums = [3,-1,1,2]
下标   x     P     M       全局答案
0      3     3     −∞      3
1     -1    -1      4      4
2      1     5     -2      5
3      2     2      3      5
正确性
对结尾下标归纳。初始状态准确覆盖唯一的单元素区间。任意奇数长度区间要么长度为 1，要么删去末项后是以相邻前一位置结尾的偶数长度区间；任意偶数长度区间删去末项后必为奇数长度区间。转移枚举了这两类的全部可能，没有跳过元素，因此保持连续性。取各结尾的两类最优值之最大值，便覆盖所有非空连续区间。
边界与复杂度
长度为 1 时返回原值，不能默认返回 0。全负数也可能通过减负数得到正结果，例如 [−3,−10] 的值是 7，而 [−10,−2] 的值是 −8。最大绝对和不超过 10¹⁰：Java 使用 long，C++ 使用 long long；JavaScript 的 Number 可精确表示这个范围的整数，Python 整数无需额外处理。时间 O(n)，额外空间 O(1)。代码用 −10¹⁸ 或负无穷表示不可达状态，远离有效值范围。
替代方案
枚举左端点并逐个延长右端点，增量维护交替和，时间 O(n²)、空间 O(1)，正是上方演示的方式。也可以构造全局交替前缀和：令 S[k] 为前 k 项按原下标偶加奇减的和。左端点 l 为偶数时区间值为 S[r+1]−S[l]；为奇数时为 S[l]−S[r+1]。扫描右端点，分别维护此前偶数 l 的最小前缀和、奇数 l 的最大前缀和，可得 O(n) 解法；必须先查询再加入新前缀以排除空区间。
常见错误
  • 把子数组当成子序列，允许跳过元素。
  • 按原数组下标固定符号，忘记每个区间都从加号开始。
  • 只记录 P，漏掉以减号结束的最优区间。
  • 更新 P 后再用新 P 计算 M，错误地重复使用当前元素。
  • 初始化答案为 0 或使用 32 位累计值。
面试追问
如何返回区间？给 P、M 各保存起点，在重启 P 时设为当前下标，扩展时继承对应旧起点；刷新全局答案时记录左右端点。若并列，按约定选择最短或最靠左区间。如何处理数据流？保留 P、M 和全局答案即可。若限定长度范围，可尝试按前缀奇偶维护滑动窗口最值。


Java
class Solution {
    public long maximumAlternatingSubarraySum(int[] nums) {
        long p = nums[0], m = -1_000_000_000_000_000_000L;
        long ans = p;
        for (int i = 1; i < nums.length; i++) {
            long x = nums[i];
            long np = Math.max(x, m + x);
            long nm = p - x;
            p = np;
            m = nm;
            ans = Math.max(ans, Math.max(p, m));
        }
        return ans;
    }
}

Python
from typing import List

class Solution:
    def maximumAlternatingSubarraySum(self, nums: List[int]) -> int:
        p, m = nums[0], -10**18
        ans = p
        for i in range(1, len(nums)):
            x = nums[i]
            p, m = max(x, m + x), p - x
            ans = max(ans, p, m)
        return ans
