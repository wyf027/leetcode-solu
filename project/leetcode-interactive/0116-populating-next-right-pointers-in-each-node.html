给定一棵完美二叉树，把每个端口的 next 跳线接到同层右侧相邻端口；最右端保持 null。

完美二叉树 逐层横向接线 O(1) 额外空间

Input / Output contract

题意与样例

完美二叉树的每个非叶节点都有两个孩子，且所有叶节点在同一层。输出序列用 # 标记每层链表结尾。

官方样例 1 3 LEVELS

输入root = [1,2,3,4,5,6,7]
输出[1,#,2,3,#,4,5,6,7,#]
解释同层节点依次通过 next 相连，每层末尾指向 null。

官方样例 2 EMPTY

输入root = []
输出[]
解释空树没有需要连接的节点，直接返回 null。

可见字符约定：字符串保留成对直引号；如输入含空格，用 ␠ 表示。本题输入是树的层序数组，不含字符串空格。

Sealed routing protocol

题解默认隐藏

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码均在此区域。

核心洞察

上一层的 next 链就是当前层的免费“队列”。处理父节点时，只需要完成两种固定跳线。

left.next = right
right.next = current.next?.left

为什么成立

完美二叉树保证每个父节点都有左右孩子。兄弟连接始终存在；跨父节点连接只在父节点右侧还有相邻节点时存在，并且目标必然是相邻父节点的左孩子。

完整过程

  1. 令 leftmost = root 表示当前层最左节点。
  2. 沿当前层已有的 next 从左到右扫描父节点。
  3. 连接同一父节点的左右孩子。
  4. 若当前父节点有右邻居，再连接跨父节点的两个孩子。
  5. 整层完成后令 leftmost = leftmost.left 下沉。

边界

  • 空树直接返回 null。
  • 单节点树没有孩子，循环不进入。
  • 每层最右节点的 next 保持 null。
  • 节点值可重复或为负，算法只依赖结构。

复杂度

时间 O(n)：每个非叶节点处理一次。
额外空间 O(1)：只维护 leftmost 与 current 两个指针。

替代方案取舍

  • BFS 队列最直观，但最宽层需要 O(n) 空间。
  • 递归能写出对称连接，调用栈为 O(h)。
  • 本题利用完美树结构，迭代常量空间最符合追问。

常见错误

  • 只连接兄弟节点，遗漏 5 → 6 这类跨父连接。
  • 未判断 current.next 就访问其左孩子。
  • 在下一层尚未接完时提前下沉。
  • 把第 116 题的完美树假设直接用于任意二叉树的第 117 题。

面试追问

  • 为什么可以不用队列遍历下一层？
  • 跨父连接的目标为什么一定是 current.next.left？
  • 若树不完美，如何用虚拟头节点推广到第 117 题？
  • 递归方案是否满足严格 O(1) 额外空间？

class Solution {
    public Node connect(Node root) {
        if (root == null) return null;

        Node leftmost = root;
        while (leftmost.left != null) {
            Node current = leftmost;
            while (current != null) {
                current.left.next = current.right;
                if (current.next != null) {
                    current.right.next = current.next.left;
                }
                current = current.next;
            }
            leftmost = leftmost.left;
        }
        return root;
    }
}
