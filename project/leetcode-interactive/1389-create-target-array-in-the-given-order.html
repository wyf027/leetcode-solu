Create Target Array in the Given Order

按既定顺序创建目标数组

把一对对“数值 + 插入位置”交给空数组，观察后面的元素如何为新成员让出位置。先动手走一遍，再决定是否展开题解。

题目

函数：createTargetArray(nums, index)

给定两个等长整数数组 nums 和 index。目标数组 target 初始为空。从左到右处理每个下标 i，把 nums[i] 插入当前 target 的 index[i] 位置；原来位于该位置及其右侧的元素依次右移。处理完全部元素后，返回 target。题目保证每次插入位置都合法。

示例 1

nums = [0,1,2,3,4]
index = [0,1,2,2,1]

输出：[0,4,1,3,2]

依次得到 [0] → [0,1] → [0,1,2] → [0,1,3,2] → [0,4,1,3,2]。

示例 2

nums = [1,2,3,4,0]
index = [0,1,2,3,0]

输出：[0,1,2,3,4]

最后把 0 插到位置 0，已有的四个元素整体右移。

示例 3

nums = [1]
index = [0]

输出：[1]

空数组唯一合法的插入位置是 0。

约束

  • 1 <= nums.length, index.length <= 100
  • nums.length == index.length
  • 0 <= nums[i] <= 100
  • 0 <= index[i] <= i

读题检查

这里的“插入”不是覆盖。位置上已有的值会向右移动；index[i] == i 表示追加到当前末尾。

Solution

题解：按顺序模拟插入

O(n²) 时间 · O(n) 空间

快速跳转

核心洞察完整过程正确性边界复杂度替代方案四语言代码面试追问常见错误

核心洞察

题目直接描述了一个确定的构造过程。维护动态数组 target，按 i = 0..n-1 依次在位置 index[i] 插入 nums[i] 即可。约束 index[i] <= i 恰好保证：第 i 步开始时数组长度为 i，插入位置一定在 [0, i] 内。

完整过程

  1. 创建空的 target。
  2. 从左到右遍历 nums 与 index。
  3. 把 nums[i] 插入 target[index[i]]：该位置及右侧元素整体向右移动一格。
  4. 所有元素处理完毕后返回 target。

示例 1 跟踪

i=0: insert(0, 0) → [0]
i=1: insert(1, 1) → [0,1]
i=2: insert(2, 2) → [0,1,2]
i=3: insert(2, 3) → [0,1,3,2]
i=4: insert(1, 4) → [0,4,1,3,2]

正确性证明

循环不变式：处理完下标 0..i-1 后，target 与题目规则处理这前 i 对数据得到的数组完全一致。

  • 初始化：尚未处理任何元素时，算法与题目都令 target 为空，不变式成立。
  • 保持：假设第 i 步前不变式成立。算法把 nums[i] 插到 index[i]，与题目本步规则相同；因此处理后数组也相同。
  • 终止：循环结束时已处理全部 n 对数据。由不变式，返回的 target 就是题目要求的目标数组。

边界情况

  • 只有一个元素：只能插入位置 0。
  • index[i] == 0：新元素成为数组头部。
  • index[i] == i：新元素追加到末尾。
  • 多个相同数值：按位置操作，不受值是否重复影响。
  • 最大长度 100：直接模拟足够简洁且性能充足。

复杂度

时间 O(n²)：动态数组在中间插入时，最坏要移动 O(n) 个元素；执行 n 次插入，总计 O(n²)。

空间 O(n)：返回数组保存 n 个元素。若不计返回值之外的额外空间，部分语言的容器操作可视为 O(1) 辅助变量，但底层扩容仍可能申请容量。

替代方案

链表插入

找到第 k 个位置仍需 O(k) 遍历，总体还是 O(n²)，而且实现更复杂、缓存局部性更差；本题没有优势。

高级序列结构

隐式 Treap 等可把按位置插入降到 O(log n)，总体 O(n log n)，但远超 n ≤ 100 的需要。面试中可作为扩展讨论。

JavaArrayList.add(index, value)
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] createTargetArray(int[] nums, int[] index) {
        List<Integer> target = new ArrayList<>();
        for (int i = 0; i < nums.length; i++) {
            target.add(index[i], nums[i]);
        }

        int[] answer = new int[nums.length];
        for (int i = 0; i < target.size(); i++) {
            answer[i] = target.get(i);
        }
        return answer;
    }
}

var createTargetArray = function(nums, index) {

from typing import List

class Solution:
    def createTargetArray(self, nums: List[int], index: List[int]) -> List[int]:
        target = []
        for value, position in zip(nums, index):
            target.insert(position, value)
        return target
C++vector.insert(begin + index, value)
class Solution {
public:
    vector<int> createTargetArray(vector<int>& nums, vector<int>& index) {
        vector<int> target;
        target.reserve(nums.size());

        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            target.insert(target.begin() + index[i], nums[i]);
        }
        return target;
    }
};

面试追问

  • 如果 n 达到 10⁵？考虑支持按秩插入的平衡树、隐式 Treap 或其他序列数据结构，将单次插入降为 O(log n)。
  • 为什么 index[i] 一定合法？第 i 步前长度恰为 i，而约束给出 0 ≤ index[i] ≤ i。
  • 能否原地修改 nums？可以手动右移并复用 nums 作为缓冲区，但接口语义和可读性更差，时间复杂度不变。
  • 插入和覆盖有什么差别？覆盖不改变长度；插入会保留原元素并使后缀右移。

常见错误

  • 写成 target[index[i]] = nums[i]，误把插入当覆盖。
  • JavaScript 使用 splice(index, 1, value)，删除了原元素；删除数量必须是 0。
  • 从右向左处理输入，破坏题目规定的时间顺序。
  • C++ 忘记用 begin() + index[i] 构造插入迭代器。
  • 声称时间 O(n)，忽略动态数组中间插入引发的元素移动。
