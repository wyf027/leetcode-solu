2207. 字符串中最多数目的子序列

Maximize Number of Subsequences in a String

只插入一个字符，能产生多少对有序匹配？先移动插入点，观察子序列如何变化。

01 / 题意

保留顺序，允许跳过字符

给定从 0 开始索引的小写字符串 text，以及长度恰好为 2 的小写字符串 pattern。你必须恰好插入一次：选 pattern[0] 或 pattern[1]，放在 text 的任意间隙，包括开头和末尾。返回插入后等于 pattern 的子序列数量的最大值。

子序列不要求连续，只要求相对顺序不变。本题按不同的下标对 i < j 计数，即使字符相同，不同位置仍算不同选择。

官方示例 1

输入：text = "abdcdbc", pattern = "ac"
输出：4

在原下标 1 与 2 之间插入 a，得到 abadcdbc；其中两处 a 都能与后面的两处 c 配对，共 4 对。最优答案为 4。

官方示例 2

输入：text = "aabb", pattern = "ab"
输出：6

插入 a 得到 aaabb，可以选 3 处 a 和 2 处 b，共 6 对；aabbb 也能达到 6 对。

约束：1 ≤ text.length ≤ 10⁵；pattern.length = 2；两个字符串均只含小写英文字母。

04 / 题解

一次计数，加上最大新增量

核心洞察

记 a = pattern[0]、b = pattern[1]。插入字符不会破坏任何已有下标对。新产生的每个下标对都必须包含新字符，因此只需要计算已有数量和最多能新增多少。

  • 插入 a：只能与右侧的 b 配对。把 a 放在开头，可匹配全部 b，新增 countB。
  • 插入 b：只能与左侧的 a 配对。把 b 放在末尾，可匹配全部 a，新增 countA。
  • 所以答案是 base + max(countA, countB)。

完整过程：从左向右累计

  1. 初始化 countA = countB = base = 0。
  2. 遇到 b 时，将此前 a 的个数 countA 加到 base，然后增加 countB。
  3. 再检查当前字符是否为 a；若是则增加 countA。两个判断必须独立。
  4. 扫描完成后，将较大的字符总数加到已有配对数上。

示例 1 中，两个 c 各自遇到一个此前的 a，因此 base = 1 + 1 = 2；countA = 1、countB = 2。在开头插入 a 新增 2 对，答案为 4。

正确性证明

计数不变量：处理当前位置前，countA 等于此前所有 a 的个数，base 等于已处理前缀中合法下标对的数量。若当前字符为 b，以此位置为第二个下标的合法对恰好有 countA 个；其余情况下没有新增对。每个合法对在处理其第二个下标时恰好计数一次，故扫描结果正确。

最优性：当 a 与 b 不同时，任意插入 a 的方案新增量不超过全部 b 的数量，任意插入 b 的方案新增量不超过全部 a 的数量。开头插入 a 和末尾插入 b 分别达到这两个上界，取较大者便是全局最优。

a = b 时：若目标字符出现 k 次，原有 k(k−1)/2 对；插入后出现 k+1 次，增加恰好 k 对，与插入位置无关。两个计数器都等于 k，上述公式仍成立。先累加配对、再增加 countA，可避免把当前字符与自身配对。

边界与数值范围

  • 两个目标字符都没有出现时，一次插入仍不能组成长度为 2 的子序列，结果为 0。
  • 只有其中一种出现时，通过插入另一种即可形成对应数量的配对。
  • text 长度为 1 时，答案可能为 0 或 1；代码不需要特判。
  • 最多 C(100001, 2) = 5,000,050,000 对，超过 32 位有符号整数。Java 用 long，C++ 用 long long；Python 整数和 JavaScript Number 均能精确容纳该范围。

复杂度

时间 O(n)，额外空间 O(1)。下面 Java 使用 charAt，避免 toCharArray 带来的额外数组。实验室为展示所有配对采用 O(m²) 枚举，它不是提交算法。

四语言完整提交代码

Java

class Solution {
    public long maximumSubsequenceCount(String text, String pattern) {
        char a = pattern.charAt(0), b = pattern.charAt(1);
        long countA = 0, countB = 0, base = 0;
        for (int i = 0; i < text.length(); i++) {
            char c = text.charAt(i);
            if (c == b) {
                base += countA;
                countB++;
            }
            if (c == a) countA++;
        }
        return base + Math.max(countA, countB);
    }
}

JavaScript

var maximumSubsequenceCount = function(text, pattern) {
    const [a, b] = pattern;
    let countA = 0, countB = 0, base = 0;
    for (const c of text) {
        if (c === b) {
            base += countA;
            countB++;
        }
        if (c === a) countA++;
    }
    return base + Math.max(countA, countB);
};

Python

class Solution:
    def maximumSubsequenceCount(self, text: str, pattern: str) -> int:
        a, b = pattern
        count_a = count_b = base = 0
        for c in text:
            if c == b:
                base += count_a
                count_b += 1
            if c == a:
                count_a += 1
        return base + max(count_a, count_b)

C++

#include <algorithm>
#include <string>
using namespace std;

class Solution {
public:
    long long maximumSubsequenceCount(string text, string pattern) {
        char a = pattern[0], b = pattern[1];
        long long countA = 0, countB = 0, base = 0;
        for (char c : text) {
            if (c == b) {
                base += countA;
                ++countB;
            }
            if (c == a) ++countA;
        }
        return base + max(countA, countB);
    }
};

替代方案

可以为每个间隙统计左侧 a 和右侧 b，枚举插入字符的新增量。前后缀数组实现为 O(n) 时间、O(n) 空间；维护左右计数也能做到 O(1) 额外空间，但端点上界直接消除了枚举。暴力枚举每个间隙、每次重新扫描计数为 O(n²)，适合小输入理解，不适合 10⁵ 长度。

常见错误

  • 把子序列当作连续子串，遗漏跨字符的匹配。
  • 先增加 countA 再累计 base：当 a = b 时会把一个下标重复使用。
  • 把两个 if 写成 if / else if：a = b 时无法同时更新两个角色。
  • 把 countA 与 countB 都加进答案，相当于用了两次插入。
  • 忽略已有配对数，或用 32 位整数存答案。

面试追问

如何返回一种插入方案？countB ≥ countA 时在开头插入 a，否则在末尾插入 b；相等时任选。pattern 长度大于 2 呢？新增字符可能承担中间角色，其贡献取决于左右部分子序列的组合，不能直接沿用端点结论，可考虑前后缀动态规划。允许多次插入呢？新字符之间也能组成配对，单次增量不再独立，需要分析字符分配与位置。
