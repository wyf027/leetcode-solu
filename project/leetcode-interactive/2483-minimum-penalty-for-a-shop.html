商店的最少代价

Minimum Penalty for a Shop

给一天的营业画一条分界线：什么时候关门，才最划算？

LeetCode 官方题目 ↗

01 / 题目

给定字符串 customers，记录从第 0 小时开始的顾客到访情况。Y 表示这一小时有顾客，N 表示没有顾客。

选择整数关门时间 j ∈ [0, n]，其中 n = customers.length。开门但无人到访的每个小时增加 1 代价；关门却有顾客到访的每个小时也增加 1 代价。

返回使总代价最小的最早关门时间。

第 j 小时已经关门。开门区间是 [0, j)，关门区间是 [j, n)。j = 0 表示从不营业，j = n 表示营业到日志结束。

输入与约束

  • 参数：customers: string
  • 返回：整数关门时间
  • 1 ≤ customers.length ≤ 10⁵
  • 字符仅包含大写 Y 和 N

先理解计费规则，再拖动营业边界。推导与四语言实现收在页面底部。

02 / 官方示例

示例 1

输入：customers = "YYNY"
输出：2

在 0、1、2、3、4 时关门，代价依次为 3、2、1、2、1。时间 2 和 4 都能取得最低代价，选择更早的 2。

示例 2

输入：customers = "NNNNN"
输出：0

没有顾客到访，直接关门最合适。

示例 3

输入：customers = "YYYY"
输出：4

每个小时都有顾客，应在全部营业结束后关门。

05 / 独立题解

准备好后，展开推导与可提交代码。

核心洞察：只有一个小时改变了归属

令 P(j) 为第 j 小时关门的代价，则 P(j) = [0,j) 中 N 的数量 + [j,n) 中 Y 的数量。j 从 0 递增到 n，每次只有 customers[j] 从关门侧移动到开门侧。

  • 该字符为 Y：原来漏接顾客的 1 代价消失，代价减 1。
  • 该字符为 N：新产生无人营业的 1 代价，代价加 1。

完整过程

  1. 统计所有 Y，得到从未开门时的代价 P(0)。初始化最小代价为 P(0)，答案为 0。
  2. 从左到右遍历 i = 0…n−1。遇 Y 减 1，遇 N 加 1，得到 P(i+1)。
  3. 仅在当前代价严格小于历史最小值时，将答案更新为 i+1。
  4. 返回答案。相等时不更新，保留更早的时间。

对 YYNY：初始代价 3；跨过 Y、Y、N、Y 后依次变成 2、1、2、1。答案先变成 1，再变成 2，最后的平局不更新。

正确性证明

代价不变量：初始 penalty 为全部 Y 的数量，恰好是 P(0)。假设循环前为 P(i)，跨过第 i 小时后，只有这一小时的营业状态变化。Y 的贡献从 1 变 0，N 的贡献从 0 变 1，因此更新后恰好为 P(i+1)。归纳可知每个候选时间的代价都被正确计算。

最优性不变量：处理到 j 时，best 是 0…j 的最小代价，answer 是其中最早取得最小值的时间。严格改进才替换、相等保留旧答案，维持这一性质。循环覆盖 0…n，所以返回全局最优且最早的时间。

边界与复杂度

  • 全 N 返回 0；全 Y 返回 n；长度 1 也适用。
  • 关门时间有 n+1 个，不能漏掉 0 或 n。
  • 代价处于 0…n，四语言所用整数范围均足够。
  • 两次线性扫描，时间 O(n)；仅存计数与答案，额外空间 O(1)。

替代方案

前缀 N 计数与后缀 Y 计数数组可以直接求出全部 P(j)，时间 O(n)、空间 O(n)，更便于展示每个位置的组成。逐个关门时间重新扫描日志则是 O(n²)，不适合 10⁵ 长度。

也可将 Y 记作 +1、N 记作 −1，维护前缀得分：P(j) = 总 Y 数 − 前缀得分(j)。寻找最早的最大前缀得分即可，无需预先统计总 Y，实现单次扫描和 O(1) 空间；空前缀得分 0 必须参与比较。

常见错误

  • 使用 ≤ 更新最优答案，导致返回最晚的平局时间。
  • 将更新后的答案写成 i，而不是 i+1。
  • 把第 j 小时仍算作营业，造成区间偏移。
  • 只统计开门侧的 N，遗漏关门侧的 Y。

面试追问

  • 两类代价分别为 a、b？初始化为 b × 总 Y；跨 Y 减 b，跨 N 加 a。
  • 需要返回全部最优时间？遇到更小值清空列表，相等时追加时间。
  • 日志以流形式到达？用前缀得分方案，持续维护最早最大前缀。
  • 允许多次开关店？单条分界线假设失效；需根据开关次数或切换成本设计状态转移。

Java

class Solution {
    public int bestClosingTime(String customers) {
        int penalty = 0;
        for (int i = 0; i < customers.length(); i++) {
            if (customers.charAt(i) == 'Y') penalty++;
        }
        int best = penalty, answer = 0;
        for (int i = 0; i < customers.length(); i++) {
            penalty += customers.charAt(i) == 'Y' ? -1 : 1;
            if (penalty < best) {
                best = penalty;
                answer = i + 1;
            }
        }
        return answer;
    }
}

var bestClosingTime = function(customers) {

    for (const c of customers) {
        if (c === 'Y') penalty++;
    }
    let best = penalty, answer = 0;
    for (let i = 0; i < customers.length; i++) {
        penalty += customers[i] === 'Y' ? -1 : 1;
        if (penalty < best) {
            best = penalty;
            answer = i + 1;
        }
    }
    return answer;
};

Python

class Solution:
    def bestClosingTime(self, customers: str) -> int:
        penalty = customers.count('Y')
        best = penalty
        answer = 0
        for i, c in enumerate(customers):
            penalty += -1 if c == 'Y' else 1
            if penalty < best:
                best = penalty
                answer = i + 1
        return answer

C++

#include <string>
using namespace std;

class Solution {
public:
    int bestClosingTime(string customers) {
        int penalty = 0;
        for (char c : customers) {
            if (c == 'Y') ++penalty;
        }
        int best = penalty, answer = 0;
        for (int i = 0; i < static_cast<int>(customers.size()); ++i) {
            penalty += customers[i] == 'Y' ? -1 : 1;
            if (penalty < best) {
                best = penalty;
                answer = i + 1;
            }
        }
        return answer;
    }
};
