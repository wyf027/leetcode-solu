打折购买糖果的最小开销

Minimum Cost of Buying Candies With Discount

买两颗，送一颗。但赠品有价格门槛。怎样拿走全部糖果，又让账单最小？

查看 LeetCode 原题 ↗

01 / 理解规则

题意与约束

给定从下标 0 开始的整数数组 cost，其中 cost[i] 是第 i 颗糖果的价格。每购买两颗糖果，可以额外免费取得一颗糖果；赠品价格必须不超过这两颗付费糖果中较便宜的一颗。

每颗糖果只取得一次，每对付费糖果最多支持一颗赠品。你可以自由选择购买组合，求拿走所有糖果需要支付的最小总金额，返回一个整数。

规则示意：付费糖果为 2 和 3 时，可以赠送价格为 1 的糖果，不能赠送价格为 4 的糖果。
  • 1 <= cost.length <= 100
  • 1 <= cost[i] <= 100

官方示例 · 完整参数

示例 1

输入：cost = [1,2,3]
输出：5

支付 2 + 3，价格为 1 的糖果免费。若支付 1 和 3，价格为 2 的糖果不符合赠品门槛。

示例 2

输入：cost = [6,5,7,9,2,2]
输出：23

支付 9 和 7，赠送 6；支付 5 和 2，赠送另一个 2。总开销是 9 + 7 + 5 + 2 = 23。

示例 3

输入：cost = [5,5]
输出：10

只有两颗糖果，没有第三颗可以赠送，因此两颗都要付款。

先处理昂贵糖果，每三颗形成一组

核心洞察

总价固定，最小化付款等价于最大化赠品总价。将价格从大到小排列，每连续三颗中支付前两颗，第三颗免费。剩下不足三颗时全部付费。

完整过程

  1. 按价格降序排序，记数组为 a。
  2. 从下标 i = 0 开始遍历。如果 i % 3 = 2，当前糖果免费；否则计入答案。
  3. 返回付款总和。例如 [9,7,6,5,2,2] 分成 [9,7,6] 和 [5,2,2]，分别支付 16 和 7，总计 23。

为什么一定最优？

可行性：每组三颗满足 a ≥ b ≥ c，因此付费 a 和 b 后，c ≤ min(a,b)，可以合法赠送。尾部一颗或两颗直接付费。

最优性：把任意方案的赠品按价格降序记为 f₁、f₂、…、fₘ。对前 k 颗赠品，必须有 2k 颗互不重复的付费糖果，价格均不低于 fₖ。连同这 k 颗赠品，至少有 3k 颗糖果的价格不低于 fₖ。因此 fₖ 不超过全部糖果降序排列的第 3k 项。

赠品数量 m 最多为 ⌊n/3⌋。任意方案的优惠总额不超过第 3、6、9、… 项的和；价格均为正，少拿赠品不会突破这个上界。我们的分组恰好取得这些位置的糖果，达到上界，所以付款最少。相同价格也满足上述非严格不等式。

边界与复杂度

  • n = 1 或 2：不存在完整三元组，全部付费。
  • n % 3 为 1 或 2：尾部全部付款；价格相同可正常赠送。
  • 金额不超过所有价格之和 10000，四种语言的常规整数表示足够。
  • 比较排序时间 O(n log n)，遍历 O(n)。扫描额外空间 O(1)；总辅助空间取决于排序实现，保守按 O(n) 计（Python / JavaScript）；Java / C++ 通常为 O(log n) 排序栈。
  • 以下代码均排序原数组。若需要保留输入，先复制数组，会增加 O(n) 空间。

替代方案

价格仅为 1–100，可用长度 101 的计数数组，从 100 向 1 扫描，每遇到第三颗便跳过付款。时间 O(n + U)、空间 O(U)，U = 100。比较排序更直接；穷举分组只适合极小规模的思路探索。

常见错误

  • 认为任意买两颗就能送最贵的一颗，忽略赠品上限。
  • 降序排列却跳过每组第一颗，导致赠品比付费糖果贵。
  • 从升序数组左端分组，浪费了让更贵糖果免费的机会。
  • JavaScript 使用无比较器的 sort()，按字符串而非数值排序。
  • 把同价糖果去重，或让同一对付费糖果支持多次赠送。

面试追问

改成买 k 送一呢？若赠品必须不贵于全部 k 颗付费糖果，降序后每 k+1 颗跳过末尾一颗；证明中的 3k 计数相应改为每个赠品需要 k+1 颗糖果。如何返回具体方案？排序时携带原下标，再输出每组三颗的付款和赠品下标。若赠品条件改变？须重新建立可行性和优惠上界，不能直接套用当前分组。

Java

import java.util.Arrays;

class Solution {
    public int minimumCost(int[] cost) {
        Arrays.sort(cost);
        int total = 0;
        for (int i = cost.length - 1, rank = 0; i >= 0; i--, rank++) {
            if (rank % 3 != 2) total += cost[i];
        }
        return total;
    }
}

JavaScript

/**
 * @param {number[]} cost
 * @return {number}
 */
var minimumCost = function(cost) {
    cost.sort((a, b) => b - a);
    let total = 0;
    for (let i = 0; i < cost.length; i++) {
        if (i % 3 !== 2) total += cost[i];
    }
    return total;
};

Python 3

from typing import List

class Solution:
    def minimumCost(self, cost: List[int]) -> int:
        cost.sort(reverse=True)
        total = 0
        for i, price in enumerate(cost):
            if i % 3 != 2:
                total += price
        return total

C++

#include <algorithm>
#include <functional>
#include <vector>
using namespace std;

class Solution {
public:
    int minimumCost(vector<int>& cost) {
        sort(cost.begin(), cost.end(), greater<int>());
        int total = 0;
        for (int i = 0; i < static_cast<int>(cost.size()); ++i) {
            if (i % 3 != 2) total += cost[i];
        }
        return total;
    }
};
