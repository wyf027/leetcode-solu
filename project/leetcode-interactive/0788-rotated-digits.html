旋转数字Rotated Digits

逐位旋转一个数字：有些数字保持原样，有些变成另一位，还有些会让整个数失效。你的任务是统计区间 [1, n] 中旋转后仍有效、且发生变化的整数数量。

01 · Problem

题目拆封

这里先把规则讲清楚，不提前给出统计方法。每一位都必须旋转，不能选择跳过某一位。

准确题意

给定正整数 n。对任意整数 x，将它的每一位数字分别旋转 180°。若旋转后的每一位仍是十进制数字，并且组成的新数与 x 不同，则称 x 为好数。

返回闭区间 [1, n] 中好数的数量。旋转只改变每一位的取值，不交换各位的位置。

约束

1 ≤ n ≤ 104

0 · 1 · 8旋转后仍是自身
2↔5 · 6↔9旋转后发生改变
3 · 4 · 7旋转后不是数字

示例 1

输入：n = 10
输出：4
解释：2、5、6、9 是好数；
1 和 10 旋转后不变。

示例 2

输入：n = 1
输出：0

示例 3

输入：n = 2
输出：1

04 · Solution

枚举 + 数位分类

由于 n ≤ 10⁴，逐个检查区间内的整数已经足够快。关键不是显式构造旋转后的数，而是判断各位所属的类别。

合法 + 改变

一个数是好数，当且仅当它不含 3、4、7，并且至少含有一位 2、5、6、9。前者保证旋转结果有效，后者保证结果不同。

核心过程

  1. 枚举 x = 1…n。
  2. 用取模与整除逐位读取 x。
  3. 遇到 3/4/7，立即判定为无效。
  4. 遇到 2/5/6/9，记录“发生过改变”。
  5. 所有位检查结束后，同时满足“有效”和“发生改变”才计数。

正确性证明

  1. 有效性的必要与充分条件。 只有 0、1、2、5、6、8、9 旋转后仍是数字。因此算法只要发现 3、4、7 就拒绝；若没有发现，则每一位都可旋转，整个数有效。
  2. 发生改变的必要与充分条件。 0、1、8 旋转后保持原值，而 2、5、6、9 会变成不同数字。因此在数有效的前提下，旋转结果与原数不同，当且仅当至少出现一位改变类数字。
  3. 计数结论。 算法对 [1,n] 中每个整数恰好检查一次，并且由前两步可知，它只对且对所有好数加一，所以最终计数正确。
时间复杂度O(n log n)每个整数最多检查其十进制位数。
空间复杂度O(1)只使用常数个状态变量。

边界与细节

  • n = 1 时没有改变类数字，答案为 0。
  • 数字 0 本身可旋转且保持不变；它出现在 10、20 等数中时不会导致无效。
  • 10 的两位都有效，但都保持原值，所以不是好数。
  • 一旦遇到无效位即可提前结束，无需继续扫描剩余数位。

替代方案：数位动态规划

若把 n 扩大到非常长的十进制字符串，可以按最高位到最低位做数位 DP，状态包含当前位置、是否贴合上界、是否已经开始数字、是否出现改变类数字。这个方案可做到与位数近似线性，但对本题 10⁴ 的上界而言，枚举更短、更直观，也更不易出错。

四语言完整实现

JavaLeetCode 提交格式
class Solution {
    public int rotatedDigits(int n) {
        int answer = 0;
        for (int value = 1; value <= n; value++) {
            if (isGood(value)) {
                answer++;
            }
        }
        return answer;
    }

    private boolean isGood(int value) {
        boolean changed = false;

        while (value > 0) {
            int digit = value % 10;
            if (digit == 3 || digit == 4 || digit == 7) {
                return false;
            }
            if (digit == 2 || digit == 5 || digit == 6 || digit == 9) {
                changed = true;
            }
            value /= 10;
        }

        return changed;
    }
}
JavaScriptLeetCode 提交格式
/**
 * @param {number} n
 * @return {number}
 */
var rotatedDigits = function(n) {
    let answer = 0;

    for (let value = 1; value <= n; value++) {
        let current = value;
        let valid = true;
        let changed = false;

        while (current > 0) {
            const digit = current % 10;

            if (digit === 3 || digit === 4 || digit === 7) {
                valid = false;
                break;
            }
            if (digit === 2 || digit === 5 || digit === 6 || digit === 9) {
                changed = true;
            }

            current = Math.floor(current / 10);
        }

        if (valid && changed) {
            answer++;
        }
    }

    return answer;
};

                return false;
            }
            if (digit == 2 || digit == 5 || digit == 6 || digit == 9) {
                changed = true;

};

面试追问

为什么不用真的构造旋转后的整数？

题目只要求判断“有效且不同”。记录是否出现改变类数字，就已经包含了“不同”这一信息，避免了额外计算。

如果 n 有 10100 那么大呢？

改用数位 DP，把 n 当字符串处理；枚举所有整数将不可行。

能否用集合简化代码？

可以用无效集合和改变集合查询。数组或 switch 也可，重点是保持两类语义分离。

最常见错误是什么？

只检查数字是否有效，却忘了结果必须与原数不同；另一个错误是把旋转误写成反转各位顺序。
