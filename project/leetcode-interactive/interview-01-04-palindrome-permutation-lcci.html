PARITY CIRCUIT / ODD-COUNT SIGNAL

回文排列

不要枚举排列。把每个字符的出现次数压缩成一盏“奇偶灯”：亮灯代表目前为奇数次。最后亮着的灯不超过一盏，就能重排成回文串。

题意 / WHAT TO DECIDE

能否把字符重排成某个回文串？

给定字符串 s，判断它是否是某个回文串的排列。回文从前、后读都一样；排列只改变字符顺序，不增删字符。

官方示例

s = "tactcoa"

期望输出：true，例如可重排为 "tacocat"。

约束：官方当前公开题面未给出数值边界。解法按任意可遍历字符串设计；下面的主线使用字符奇偶集合。

判定法则 / INVARIANT

偶数长度

所有字符必须成对出现：亮灯数 = 0。

奇数长度

仅允许一个中心字符单着：亮灯数 = 1。

统一起来：奇数频次的不同字符数 ≤ 1。每读到一个字符，就翻转它对应灯的开关。

题解 / RECOMMENDED

用集合维护“奇数频次”

核心洞察

回文的两侧都由成对字符组成；只有中间位置可以容纳一个未配对字符。因此只需知道每个频次的奇偶性。字符再次出现时，从集合删除；首次或第三次出现时，加入集合。

完整过程

  1. 建一个空集合 odd。
  2. 遍历每个字符：在集合里就删除，不在就加入。
  3. 遍历结束，odd.size ≤ 1 即为 true。

边界

空串、单字符都成立；两个以上不同字符为奇数次则失败。字符比较区分大小写，空格也是普通字符。

复杂度

时间 O(n)；空间 O(k)，k 为不同字符数。

替代方案

可先计数再数奇数，或在字符域受限时用位掩码；排序后扫描也可行，但需 O(n log n)。

常见错误

  • 误以为奇数长度必须恰好一个奇数频次；空串和偶长回文允许 0 个。
  • 只统计总长度奇偶，没有统计每种字符的奇偶。
  • 直接生成所有排列，复杂度会爆炸。
