Maximum Good People Based on Statements

谁说的每句话都可信？在彼此的陈述中，寻找能够同时成立的身份安排。

先读规则并独立思考，推演工具和完整题解收在页面底部。

01 / 题目与规则

有 n 个人，编号为 0 到 n − 1，每个人是好人或坏人。好人的每一条陈述都为真；坏人可以说真话，也可以说假话。给定 n × n 整数矩阵 statements，返回与陈述规则相容的身份安排中，好人的最大数量。

0 · 认为是坏人

statements[i][j] = 0：i 说 j 是坏人。

1 · 认为是好人

statements[i][j] = 1：i 说 j 是好人。

2 · 未表态

statements[i][j] = 2：i 未对 j 作出陈述。

坏人并非必须撒谎。即使一个坏人的话碰巧全是真话，也不违背规则。

完整约束

  • n == statements.length == statements[i].length
  • 2 ≤ n ≤ 15
  • statements[i][j] 的值为 0、1 或 2。
  • statements[i][i] == 2，每个人不对自己作陈述。

02 / 官方示例

示例 1

输入：statements = [[2,1,2],[1,2,2],[2,0,2]]
输出：2

0 认为 1 是好人，1 认为 0 是好人，2 认为 1 是坏人。令 0、1 为好人，2 为坏人可以相容；三人全好则与 2 的陈述冲突，故最大为 2。

示例 2

输入：statements = [[2,0],[0,2]]
输出：1

两人都说对方是坏人。任意一人是好人、另一人是坏人时都成立；两人全好时矛盾，故最大为 1。

04 / 解题工作台

准备好后，展开推演与四语言实现。

核心洞察 · 先假设身份，再核对证词

n ≤ 15，身份安排总共只有 2ⁿ ≤ 32768 种。用整数 mask 表示安排，第 i 位为 1 表示 i 是好人，为 0 表示坏人。只核对好人所在行的非 2 陈述；坏人所在行不施加约束。

对每个好人 i 和每个有效陈述 j，必须满足 statements[i][j] == ((mask >> j) & 1)。合法安排中取 1 位数的最大值。

完整过程

  1. answer = 0，枚举 mask 从 0 到 (1 << n) − 1，包括全坏安排。
  2. 检查人物 i，第 i 位为 0 则跳过整行。
  3. 对好人 i 遍历 j，值为 2 则跳过，否则与第 j 位比较。
  4. 任意陈述不一致，立即淘汰整个 mask。
  5. 全部核对一致时，统计好人数并更新 answer。
  6. 枚举结束，返回最大值。

示例 1 中 mask = 011 表示人物 0、1 好，人物 2 坏；0、1 的相互认可成立，2 的陈述不约束身份。mask = 111 则因人物 2 声称人物 1 为坏人而不合法。

正确性证明

完备性：每人两个身份，每种身份安排唯一对应一个 n 位 mask。遍历所有 mask 覆盖全部可能安排。

判定充要性：若好人的任一有效陈述与身份不符，安排违反真话规则；若所有好人的有效陈述相符，则好人的规则满足，坏人又允许真假任意，所以安排合法。

最优性：answer 始终保存已枚举合法安排的最大好人数。合法安排更新最大值，非法安排不更新。枚举完毕后得到所有合法安排中的最大值。

边界与复杂度

  • 没有陈述时所有人都可为好人，返回 n。
  • 全坏安排永远合法；答案可能为 0，无需返回 −1。
  • 对角线均为 2，直接跳过；陈述不保证对称。
  • 时间 O(2ⁿ · n²)：每个安排至多检查 n² 个元素，计数 O(n) 不改变上界。
  • 额外空间 O(1)：提交代码只使用标量变量，不计输入矩阵。
  • 可视化为了回放保存步骤，所需空间不属于提交算法。

替代方案与面试追问

行掩码优化：预处理 good[i] 和 bad[i]，分别记录 i 指认为好和坏的人员。若 i 是好人，检查 (mask & good[i]) == good[i] 且 (mask & bad[i]) == 0。本题固定整型位宽内，预处理 O(n²)，枚举 O(2ⁿ · n)，额外空间 O(n)。

回溯剪枝：逐个分配身份，在已确定的身份间发现矛盾即可剪枝。需要区分未分配的人，最坏仍是指数级，直接枚举更简单。

为什么不能按票数贪心？陈述者可能为坏人，多数支持无法保证真实，局部认可关系不足以决定全局身份。

如何返回好人列表？更新最大值时保存 bestMask，最后提取其中置 1 的人员编号。

n 更大怎么办？利用陈述的蕴含关系剪枝，或考虑布尔约束优化求解；全枚举和固定字长位运算都不能无限扩展。

常见错误

  • 将坏人的陈述全取反：坏人允许说真话。
  • 把 2 当成一种身份：它只是未表态。
  • 反转 i、j：i 是说话者，j 是被评价者。
  • 第一个合法安排就返回：合法不代表最优。
  • 发现冲突后仍更新答案：冲突会淘汰整个安排。
  • 把单向陈述当作无向关系，直接合并所谓互信组。

四语言完整实现

Java

class Solution {
    public int maximumGood(int[][] statements) {
        int n = statements.length, answer = 0;
        for (int mask = 0; mask < (1 << n); mask++) {
            boolean valid = true;
            for (int i = 0; i < n && valid; i++) {
                if (((mask >> i) & 1) == 0) continue;
                for (int j = 0; j < n; j++) {
                    int s = statements[i][j];
                    if (s != 2 && s != ((mask >> j) & 1)) {
                        valid = false;
                        break;
                    }
                }
            }
            if (valid) answer = Math.max(answer, Integer.bitCount(mask));
        }
        return answer;
    }
}

    return answer;
};

from typing import List

class Solution:
    def maximumGood(self, statements: List[List[int]]) -> int:
        n = len(statements)
        answer = 0
        for mask in range(1 << n):
            valid = True
            count = 0
            for i in range(n):
                if not ((mask >> i) & 1):
                    continue
                count += 1
                for j in range(n):
                    s = statements[i][j]
                    if s != 2 and s != ((mask >> j) & 1):
                        valid = False
                        break
                if not valid:
                    break
            if valid:
                answer = max(answer, count)
        return answer
