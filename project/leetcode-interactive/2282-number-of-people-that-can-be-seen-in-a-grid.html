01 / Problem

题意：只计算右方和下方

给定一个从 0 开始编号的 m × n 正整数矩阵 heights。格子 (i, j) 站着一个身高为 heights[i][j] 的人。请返回同样大小的矩阵 answer，记录每个人能看到的总人数。

  • 目标必须位于观察者的同一行右侧，或同一列下方。
  • 两人之间的所有人都必须严格矮于两端的每个人，即中间最大高度 < 两端高度的较小值。
  • 相邻的人之间没有障碍，因此一定可见。不看左方、上方或对角线，也不计自己。

参数与返回值

seePeople(heights: integer[][]) → integer[][]

约束

  • m = heights.length，1 ≤ m ≤ 400
  • n = heights[i].length，1 ≤ n ≤ 400
  • 1 ≤ heights[i][j] ≤ 10⁵
  • 每行长度相同；高度允许重复。

04 / Your next move

先想一想：等高的人会挡住谁？

准备好后，展开推导、逐步观察台与四语言实现。

题解 · 把网格拆成两种单向视野

核心洞察

每一行的右视野、每一列的下视野互不重叠，分别计数后相加。对一条线从末端向前扫描，用从栈底到栈顶高度严格递减的栈保留后方可能被看见的人。

  1. 设当前高度为 h。持续弹出比 h 小的栈顶，每弹出一个，当前人数加 1。
  2. 如果栈还不空，当前还能看到一个不低于自己的栈顶，人数再加 1；它挡住了更远的候选。
  3. 若这个栈顶恰好等于 h，将旧的等高项弹出，这次不再计数。因为新的人更靠近未来的观察者，旧等高项永远会被新人遮住。
  4. 将当前人压栈。处理完一行或一列就清空栈，换下一条线。

不能把等高项全留在栈里。例如 [5,2,2,4] 中，5 只能看到较近的 2 和 4，不能同时看到两个 2。

完整过程与正确性

用 [5, 2, 2, 4] 串起过程

从右向左：4 入栈，计数 0；右侧 2 看到 4，计数 1；左侧 2 看到右侧 2，计数 1，然后用自己替换旧等高项；最后 5 依次弹出较近的 2 和 4，计数 2。得到 [2,1,1,0]。

不变量：栈为什么只留下有效候选？

处理当前位置之前，栈里的候选按距离由近到远（栈顶到栈底）高度严格上升。被删除的人已经被一个更近且不矮的人遮住，对后续更靠前的观察者都不可能重新变得可见。

当前人能看到所有被弹出的较矮候选：它们之前更近的候选都更矮，满足中间高度严格小于两端。遇到第一个不矮于自己的候选时，它本身可见，但会挡住所有更远的人，所以只多计 1。等高替换只删除未来必被遮住的旧人，且不重复计数。压入当前人后，严格递减的不变量继续成立。

空后缀显然满足不变量，因此逆序归纳可得每条线上的计数正确。行与列的目标集合互不重叠，两次结果相加即为每个格子的答案。

复杂度

每个位置在每次方向扫描中至多入栈一次、出栈一次，时间 O(mn)。辅助空间 O(max(m,n))，包括一条线和栈；返回矩阵占 O(mn)，计入输出后的总空间为 O(mn)。

边界与常见错误

  • 1 × 1 返回 [[0]]；最后一行没有下方贡献，最后一列没有右方贡献。
  • 严格递增或递减的单条线，每个人只能看见紧邻的下一个。
  • 所有人同高时，也只能看见紧邻的人；不能把“严格小于”改成“小于等于”。
  • 不保留重复高度；等高旧项弹出时不再次加 1。
  • 每条线要重置栈；列结果必须加到行结果上，不能覆盖。
  • 不能累加被弹出者自己的答案。它看到的人可能被它自己挡住。

替代方案

直接从每个格子向右和向下扫描，维护中间最大高度，按定义判断；每个方向遇到不低于观察者的人后即可停止。时间 O(mn(m+n))、辅助空间 O(1)，易于解释但大矩阵成本高。也可以按相反方向扫描、给栈中观察者更新答案，不过需要额外注意等高遮挡；本页使用逆序计数让结果归属更直观。

面试追问

  • 增加左、上两个方向？ 对每行、每列再各做一次反向扫描，将四个互不重叠的方向相加，仍是 O(mn)。
  • 要返回可见者坐标？ 栈中保存索引，在“弹出计数”和“剩余栈顶计数”时记录对应坐标。
  • 允许在线修改高度？ 此算法用于静态输入，不能直接维护任意更新；需要根据查询频率重新选择数据结构或局部重算策略。

Java

class Solution {
    private int[] count(int[] line) {
        int n = line.length, top = 0;
        int[] stack = new int[n], result = new int[n];
        for (int i = n - 1; i >= 0; --i) {
            int h = line[i];
            while (top > 0 && stack[top - 1] < h) {
                --top;
                ++result[i];
            }
            if (top > 0) {
                ++result[i];
                if (stack[top - 1] == h) --top;
            }
            stack[top++] = h;
        }
        return result;
    }

    public int[][] seePeople(int[][] heights) {
        int m = heights.length, n = heights[0].length;
        int[][] answer = new int[m][];
        for (int i = 0; i < m; ++i) answer[i] = count(heights[i]);
        int[] column = new int[m];
        for (int j = 0; j < n; ++j) {
            for (int i = 0; i < m; ++i) column[i] = heights[i][j];
            int[] down = count(column);
            for (int i = 0; i < m; ++i) answer[i][j] += down[i];
        }
        return answer;
    }
}

/**
 * @param {number[][]} heights
 * @return {number[][]}
 */
var seePeople = function(heights) {
    function count(line) {
        const result = Array(line.length).fill(0), stack = [];
        for (let i = line.length - 1; i >= 0; --i) {
            const h = line[i];
            while (stack.length && stack[stack.length - 1] < h) {
                stack.pop();
                ++result[i];
            }
            if (stack.length) {
                ++result[i];
                if (stack[stack.length - 1] === h) stack.pop();
            }
            stack.push(h);
        }
        return result;
    }
    const m = heights.length, n = heights[0].length;
    const answer = heights.map(count);
    for (let j = 0; j < n; ++j) {
        const down = count(heights.map(row => row[j]));
        for (let i = 0; i < m; ++i) answer[i][j] += down[i];
    }
    return answer;
};

Python

from typing import List

class Solution:
    def seePeople(self, heights: List[List[int]]) -> List[List[int]]:
        def count(line: List[int]) -> List[int]:
            result = [0] * len(line)
            stack = []
            for i in range(len(line) - 1, -1, -1):
                h = line[i]
                while stack and stack[-1] < h:
                    stack.pop()
                    result[i] += 1
                if stack:
                    result[i] += 1
                    if stack[-1] == h:
                        stack.pop()
                stack.append(h)
            return result

        m, n = len(heights), len(heights[0])
        answer = [count(row) for row in heights]
        for j in range(n):
            down = count([heights[i][j] for i in range(m)])
            for i in range(m):
                answer[i][j] += down[i]
        return answer

C++

#include <vector>
using namespace std;

class Solution {
    vector<int> count(const vector<int>& line) {
        int n = static_cast<int>(line.size());
        vector<int> result(n, 0), stack;
        for (int i = n - 1; i >= 0; --i) {
            int h = line[i];
            while (!stack.empty() && stack.back() < h) {
                stack.pop_back();
                ++result[i];
            }
            if (!stack.empty()) {
                ++result[i];
                if (stack.back() == h) stack.pop_back();
            }
            stack.push_back(h);
        }
        return result;
    }
public:
    vector<vector<int>> seePeople(vector<vector<int>>& heights) {
        int m = heights.size(), n = heights[0].size();
        vector<vector<int>> answer(m);
        for (int i = 0; i < m; ++i) answer[i] = count(heights[i]);
        vector<int> column(m);
        for (int j = 0; j < n; ++j) {
            for (int i = 0; i < m; ++i) column[i] = heights[i][j];
            vector<int> down = count(column);
            for (int i = 0; i < m; ++i) answer[i][j] += down[i];
        }
        return answer;
    }
};
