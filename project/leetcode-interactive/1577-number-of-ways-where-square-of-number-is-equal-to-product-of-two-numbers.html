数的平方等于
两数乘积的方法数

在两个数组之间寻找一种对称关系：一侧选一个数并平方，另一侧选一对下标不同的数并相乘。

Number of Ways Where Square of Number Is Equal to Product of Two Numbers非会员题
Problem

题意

给定两个整数数组 nums1 和 nums2，统计下面两类三元组的总数。

两类三元组

类型 1：选择 nums1 中的下标 i，以及 nums2 中满足 j < k 的两个下标，使：

nums1[i]² = nums2[j] × nums2[k]

类型 2：交换两个数组的角色，选择 nums2 中的下标 i，以及 nums1 中满足 j < k 的两个下标，使：

nums2[i]² = nums1[j] × nums1[k]
下标决定三元组是否不同。即使数值重复，只要选择的下标不同，就应分别计数。

约束与签名

  • 1 ≤ nums1.length, nums2.length ≤ 1000
  • 1 ≤ nums1[i], nums2[i] ≤ 10⁵
  • numTriplets(nums1, nums2) → integer
Examples

输出：1

示例 3

输入：nums1 = [4,7,9,11,23],
      nums2 = [3,5,1024,12,18]

Solution

准备好查看完整题解了吗？

先尝试把“平方值”和“数对乘积”放进同一种可计数的数据结构，再展开答案。

Core Insight

将三元组拆成“值频次 × 数对”

先统计一侧每个元素平方后的频次，再枚举另一侧所有满足 j < k 的数对；数对乘积出现时，一次性加入相同平方值的频次。

01 / SQUARE

记录平方频次

对数组 A 中每个值 x，令 squareFreq[x²]++。重复元素自然形成多次可选下标。

02 / PAIR

枚举唯一数对

在数组 B 中枚举所有 j < k，每一对下标恰好访问一次，计算乘积 B[j] × B[k]。

03 / MATCH

按值批量计数

若乘积为 p，就加入 squareFreq[p]。最后交换 A、B 再做一次，覆盖两种类型。

完整过程

  1. 实现 count(squaredSide, pairSide)。
  2. 建立 squaredSide 的平方频次表。
  3. 双层循环枚举 pairSide 中全部 j < k。
  4. 把当前乘积对应的平方频次加入结果。
  5. 返回 count(nums1, nums2) + count(nums2, nums1)。

复杂度与边界

  • 时间：O(n² + m²)。
  • 空间：O(n + m)，分别由平方频次表决定。
  • 数组长度小于 2 时，该侧无法组成数对，循环自然贡献 0。
  • 最大平方或乘积为 10¹⁰；Java/C++ 必须用 64 位整数。JavaScript 的安全整数范围可以精确表示它。

正确性证明

  1. 平方侧计数准确：对任意值 p，squareFreq[p] 等于平方为 p 的下标 i 数量。
  2. 数对侧无重无漏：双层循环只枚举 j < k，因此每个合法下标对恰好出现一次。
  3. 单类答案准确：对每个数对乘积 p，加入的 squareFreq[p] 恰是能与该数对组成合法三元组的全部 i。
  4. 总答案准确：两次调用分别统计类型 1 与类型 2；两类定义互斥地按角色划分，二者之和即题目所求。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numTriplets(int[] nums1, int[] nums2) {
        return count(nums1, nums2) + count(nums2, nums1);
    }

    private int count(int[] squaredSide, int[] pairSide) {
        Map<Long, Integer> squareFreq = new HashMap<>();
        for (int value : squaredSide) {
            long square = (long) value * value;
            squareFreq.put(square, squareFreq.getOrDefault(square, 0) + 1);
        }

        int answer = 0;
        for (int j = 0; j < pairSide.length; j++) {
            for (int k = j + 1; k < pairSide.length; k++) {
                long product = (long) pairSide[j] * pairSide[k];
                answer += squareFreq.getOrDefault(product, 0);
            }
        }
        return answer;
    }
}

var numTriplets = function(nums1, nums2) {
    const count = (squaredSide, pairSide) => {
        const squareFreq = new Map();
        for (const value of squaredSide) {
            const square = value * value;
            squareFreq.set(square, (squareFreq.get(square) || 0) + 1);
        }

        let answer = 0;
        for (let j = 0; j < pairSide.length; j++) {
            for (let k = j + 1; k < pairSide.length; k++) {
                const product = pairSide[j] * pairSide[k];
                answer += squareFreq.get(product) || 0;
            }
        }
        return answer;
    };

    return count(nums1, nums2) + count(nums2, nums1);
};
from collections import Counter
from typing import List


class Solution:
    def numTriplets(self, nums1: List[int], nums2: List[int]) -> int:
        def count(squared_side: List[int], pair_side: List[int]) -> int:
            square_freq = Counter(value * value for value in squared_side)
            answer = 0

            for j in range(len(pair_side)):
                for k in range(j + 1, len(pair_side)):
                    product = pair_side[j] * pair_side[k]
                    answer += square_freq[product]

            return answer

        return count(nums1, nums2) + count(nums2, nums1)
class Solution {
public:
    int numTriplets(vector<int>& nums1, vector<int>& nums2) {
        return count(nums1, nums2) + count(nums2, nums1);
    }

private:
    int count(const vector<int>& squaredSide,
              const vector<int>& pairSide) {
        unordered_map<long long, int> squareFreq;
        for (long long value : squaredSide) {
            ++squareFreq[value * value];
        }

        int answer = 0;
        for (int j = 0; j < static_cast<int>(pairSide.size()); ++j) {
            for (int k = j + 1; k < static_cast<int>(pairSide.size()); ++k) {
                long long product = 1LL * pairSide[j] * pairSide[k];
                auto it = squareFreq.find(product);
                if (it != squareFreq.end()) answer += it->second;
            }
        }
        return answer;
    }
};

替代方案

也可以先统计一侧所有数对的乘积频次，再枚举另一侧每个平方值并查表；复杂度同样是 O(n² + m²)，但乘积表最多包含平方级数量的不同键。还可以对数组排序后针对每个平方使用双指针，但重复值计数更容易写错，整体也需要对每个目标重复扫描。

面试追问

  • 若数组长度扩展到 10⁵，值域或重复度能否被利用？
  • 如何用值频次与因数枚举降低重复数据下的成本？
  • 为什么 Java/C++ 的乘法要先提升到 64 位？
  • 若允许负数与 0，算法和证明需要修改吗？

常见错误

  • 枚举 j != k 导致同一数对按两个顺序重复计数；应固定 j < k。
  • 用值去重，漏掉重复元素产生的不同下标组合。
  • 只统计类型 1，忘记交换数组再统计类型 2。
  • Java/C++ 先用 32 位整数完成乘法，再赋给 64 位变量，溢出已经发生。
  • 把平方频次写成集合，丢失同一平方对应的下标数量。
