核心洞察

普通加一只会受连续的尾部 9 影响。从最低位向左检查：遇到非 9，直接加一并结束；遇到 9，把它变成 0，进位继续。若所有位都是 9，最终在最前面补一个 1。

WHY THIS ROUTE

替代方案取舍

  • 转成整数：最多 100 位，会溢出，不能使用。
  • 新建结果数组：逻辑可行，但通常多用 O(n) 空间。
  • 原地逆序扫描：代码短、额外空间 O(1)，面试最推荐。

FULL PROCEDURE

完整过程

  1. 从索引 n - 1 开始向左扫描。
  2. 当前位小于 9：加一后立即返回；否则写 0 并继续。
  3. 循环结束说明全是 9，返回长度 n + 1、首位为 1 的数组。

边界

  • 单个非 9：[1] → [2]。
  • 单个 9：[9] → [1,0]。
  • 连续尾 9：[1,9,9] → [2,0,0]。
  • 全部为 9：结果数组长度增加 1。

复杂度

Time
O(n)
Extra space
O(1)

最坏情况扫描全部 n 位；除返回全 9 时所需的新数组外，原地算法只使用常数额外变量。

面试追问

  • 如果不能修改输入？先复制数组，空间变为 O(n)。
  • 如果加的不是 1？使用 carry = k，逐位计算和与商。
  • 如果数组是小端序？从索引 0 向右传播进位。
  • 为什么可以提前返回？非 9 位吸收进位后，更高位不再变化。

常见错误

  • 从最高位开始加，错误传播进位方向。
  • 遇到 9 只写 0，却忘记继续向左处理。
  • 全 9 时忘记新增最高位 1。
  • 把 100 位数组转换成语言内置整数导致溢出。

class Solution {
    public int[] plusOne(int[] digits) {
        for (int i = digits.length - 1; i >= 0; i--) {
            if (digits[i] < 9) {
                digits[i]++;
                return digits;
            }
            digits[i] = 0;
        }

        int[] result = new int[digits.length + 1];
        result[0] = 1;
        return result;
    }
}

class Solution {
public:
    std::vector<int> plusOne(std::vector<int>& digits) {
        for (int i = static_cast<int>(digits.size()) - 1; i >= 0; --i) {
