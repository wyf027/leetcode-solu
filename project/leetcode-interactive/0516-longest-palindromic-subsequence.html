题号 516 非付费题 字符串 返回整数
Problem

题目要求

给定字符串 s，返回其中最长回文子序列的长度。

准确转述

你可以从 s 中删除任意数量的字符（也可以一个都不删）， 但保留下来的字符必须维持原来的先后次序。目标是让它们构成回文，并求可达到的最大长度。

子序列不要求在原字符串中连续；回文要求从左向右与从右向左读取完全一致。

函数形式
longestPalindromeSubseq(s: string) -> integer

约束

  • 1 <= s.length <= 1000
  • s 仅由小写英文字母组成。
关键辨析

子串必须连续，子序列不必连续。本题问的是后者。

示例 1

官方示例 
输入：s = "bbbab"
输出：4
解释：一种最长回文子序列是 "bbbb"。

示例 2

官方示例 
输入：s = "cbbd"
输出：2
解释：一种最长回文子序列是 "bb"。

Full Solution

区间动态规划

两端字符的关系决定当前区间如何缩小；把所有短区间先算好，长区间便能复用这些结果。

核心洞察

令 dp[i][j] 表示闭区间 s[i..j] 的最长回文子序列长度。区间两端相同，就能把它们同时接到内部区间答案两侧；两端不同， 则至少舍弃其中一端，取两个子区间的较优值。 

dp[i][i] = 1

s[i] == s[j]:
  dp[i][j] = dp[i + 1][j - 1] + 2

s[i] != s[j]:
  dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])

完整过程

  1. 建立 n × n 状态表，把所有 dp[i][i] 初始化为 1。
  2. 按区间长度从 2 到 n 枚举，确保转移依赖的更短区间已经计算。
  3. 若两端字符相同，使用内部区间加 2；长度为 2 时内部为空，直接得到 2。
  4. 若两端不同，在舍弃左端与舍弃右端的两个状态中取最大值。
  5. 返回覆盖整个字符串的 dp[0][n - 1]。

正确性证明

状态含义。对任意 i ≤ j，dp[i][j] 记录且只记录区间 s[i..j] 内的最优长度。

基础情形。当 i = j 时，唯一字符本身构成长度为 1 的回文，初始化正确。

两端相同。若 s[i] = s[j]，内部区间的任一最优回文两侧加上这两个相同字符，会得到长度 dp[i+1][j-1] + 2 的回文。反过来，总能选择一个包含这对边界字符的最优解：若某最优解未同时使用两端，把它的首尾字符替换为更外侧这对相同字符不会缩短。因此该转移得到最优值。

两端不同。任意回文子序列不可能同时以这两个不同字符为首尾，所以它至少不使用 s[i] 或不使用 s[j]。所有候选因此落在 s[i+1..j] 或 s[i..j-1] 中，取两者最大值恰为最优。

归纳与结论。按区间长度递增计算时，所有转移依赖均已正确。由区间长度归纳，整张表正确，最终 dp[0][n-1] 就是原问题答案。

边界情况

  • 单字符：答案为 1。
  • 全部字符相同：答案为字符串长度。
  • 所有字符互不相同：答案为 1。
  • 长度为 2 且两字符相同：内部区间为空，答案直接为 2。
  • 本题约束保证字符串非空；若迁移到允许空串的场景，应先返回 0。

复杂度

时间 O(n²)：每个上三角状态只计算一次。

空间 O(n²)：二维表保存所有区间结果。

利用状态只依赖相邻层的特点，可进一步压缩到 O(n) 空间，但更新顺序更容易写错。

替代方案对比

四语言完整代码

均采用同一套二维区间动态规划，符合官方函数签名。

class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];

        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = dp[i + 1][j - 1] + 2;
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[0][n - 1];
    }
}

常见错误

  • 把“子序列”误写成“子串”，只检查连续区间。
  • 没有先初始化单字符状态，导致转移缺少基础值。
  • 以错误顺序枚举 i、j，读取了尚未计算的状态。
  • 两端相同时仍只取左右子区间最大值，漏掉同时选取两端的收益。
  • 空间压缩时覆盖了本轮仍需使用的旧值。
