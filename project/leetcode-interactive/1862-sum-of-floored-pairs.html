向下取整数对和

Sum of Floored Pairs

每个元素都能成为分子，也能成为分母。将所有有序下标对的整数商汇总。

数组数学非付费题离线阅读

01 / 题目

给定正整数数组 nums，计算所有满足 0 ≤ i, j < nums.length 的下标对对应的 ⌊nums[i] / nums[j]⌋，将它们相加后对 1,000,000,007 取模并返回。

向下取整表示不超过该商的最大整数。下标对有顺序，i = j 也包含在内；数值相同但下标不同的元素仍分别计数。

官方示例 1

输入：nums = [2,5,9]
输出：10

三个自身相除的结果均为 1；5 / 2、9 / 2、9 / 5 向下取整分别为 2、4、1，其余三个商为 0。总和为 10。

官方示例 2

输入：nums = [7,7,7,7,7,7,7]
输出：49

共有 7 × 7 个有序下标对，每项结果都是 1，因此和为 49。

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁵

03 / 题解：把相同的商装进一个区间

核心洞察

固定分母值 d，整数商为 k 的分子恰好落在 [k·d, (k+1)·d−1]。我们只需知道每段有多少个元素，不必逐对计算。

贡献 = k × (pre[min(M,(k+1)d−1)] − pre[kd−1]) × freq[d]

freq[v] 表示值 v 出现的次数；pre[t] 表示不大于 t 的元素总数，M = max(nums)。商为 0 的区间无需累加。

完整过程

  1. 扫描数组得到最大值 M，再统计频次数组。
  2. 构造前缀和，使任意闭区间的元素数量可在 O(1) 时间求出。
  3. 枚举出现过的分母 d。让左端点依次为 d、2d、3d…，右端点为 min(M, 左端点 + d − 1)。
  4. 区间中的所有分子都贡献相同商 k，乘以区间元素数量与分母频次，加入答案并取模。

以 [2,5,9] 为例：分母 2 的商区间依次产生 1、2、0、4，合计 7；分母 5 产生 2；分母 9 产生 1；总计 10。

为什么正确

对正整数 d，⌊x/d⌋ = k 等价于 kd ≤ x ≤ (k+1)d−1。这些区间互不相交，并覆盖所有不小于 d 的分子。因此，每个非零贡献恰好进入一个区间。前缀和差准确统计区间内的下标数量，乘以 freq[d] 后，计入了所有选择分母下标的方式。枚举所有出现过的 d 后，每个有序下标对均恰好被计入一次或因商为 0 被省略；自身配对和重复值也已包含。逐步取模保持最终答案的同余关系。

边界与数值安全

  • 单元素的结果为 1；全部值相同的结果为 n² mod MOD。
  • 当 d = M 时仍处理 [M,M]，不能漏掉自身配对。
  • 最后一个区间必须截到 M；pre[0] = 0，查询 left = 1 时合法。
  • Java 和 C++ 必须在乘法之前提升为 64 位。Python 整数无需担心溢出。
  • JavaScript 中，单项乘积不超过 n²M ≤ 10¹⁵；每次取模后再累加仍小于 2⁵³−1，因此 Number 的整数精度足够。避免位运算截断及对十万元素使用展开参数 Math.max(...nums)。

复杂度

构造频次和前缀和为 O(n + M)。区间枚举至多 ∑(d=1..M) ⌊M/d⌋ = O(M log M)，只处理存在的分母会进一步减少工作量。总时间 O(n + M log M)，额外空间 O(M)。

替代方案

直接枚举所有有序下标对为 O(n²) 时间、O(1) 额外空间，适合理解定义但不适合本题规模。排序后对每个分母的商区间用二分查数量，可减少稠密计数数组需求，但增加排序和每段查询的对数开销，区间枚举仍受数值范围影响。本题值域只有 10⁵，频次与前缀和更直接。

常见错误

  • 当成无序对，只算 i < j，或者把答案除以 2。
  • 对不同分母值只算一次却忘了乘 freq[d]。
  • 把右端点写成 (k+1)d，令下一个商的首值被重复计入。
  • 前缀差写成 pre[right] − pre[left]，丢掉左端点。
  • 在 int 乘法完成后才转 long，溢出早已发生。

面试追问

若值域变成 10⁹？ 稠密数组不可行，需结合 n 和不同值数量讨论排序、二分或稀疏枚举；单纯坐标压缩无法保持除法区间端点。

若要求 i ≠ j？ 每个自身配对的贡献都是 1，从原结果减去 n 后规范化取模。

若输入允许 0？ 必须先明确分母为零的业务定义，当前算法依赖所有元素严格为正。

Java

class Solution {
    public int sumOfFlooredPairs(int[] nums) {
        final long MOD = 1_000_000_007L;
        int m = 0;
        for (int x : nums) m = Math.max(m, x);
        int[] freq = new int[m + 1];
        int[] pre = new int[m + 1];
        for (int x : nums) freq[x]++;
        for (int x = 1; x <= m; x++) pre[x] = pre[x - 1] + freq[x];
        long ans = 0;
        for (int d = 1; d <= m; d++) {
            if (freq[d] == 0) continue;
            for (int left = d, k = 1; left <= m; left += d, k++) {
                int right = Math.min(m, left + d - 1);
                int count = pre[right] - pre[left - 1];
                ans = (ans + (long) freq[d] * k * count) % MOD;
            }
        }
        return (int) ans;
    }
}

Python

from typing import List

class Solution:
    def sumOfFlooredPairs(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        m = max(nums)
        freq = [0] * (m + 1)
        pre = [0] * (m + 1)
        for x in nums:
            freq[x] += 1
        for x in range(1, m + 1):
            pre[x] = pre[x - 1] + freq[x]
        ans = 0
        for d in range(1, m + 1):
            if freq[d] == 0:
                continue
            for left in range(d, m + 1, d):
                k = left // d
                right = min(m, left + d - 1)
                count = pre[right] - pre[left - 1]
                ans = (ans + freq[d] * k * count) % MOD
        return ans

C++

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int sumOfFlooredPairs(vector<int>& nums) {
        const long long MOD = 1000000007LL;
        int m = *max_element(nums.begin(), nums.end());
        vector<int> freq(m + 1), pre(m + 1);
        for (int x : nums) ++freq[x];
        for (int x = 1; x <= m; ++x) pre[x] = pre[x - 1] + freq[x];
        long long ans = 0;
        for (int d = 1; d <= m; ++d) {
            if (freq[d] == 0) continue;
            for (int left = d, k = 1; left <= m; left += d, ++k) {
                int right = min(m, left + d - 1);
                int count = pre[right] - pre[left - 1];
                ans = (ans + 1LL * freq[d] * k * count) % MOD;
            }
        }
        return static_cast<int>(ans);
    }
};
