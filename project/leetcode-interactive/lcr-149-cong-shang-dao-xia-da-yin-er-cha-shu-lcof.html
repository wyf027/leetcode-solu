二叉树广度优先搜索队列

题意

某公司举办晚会，现场树上装饰的彩灯呈二叉树结构。给定二叉树的根节点 root，请按从上到下的顺序返回每个节点的值。

示例 1

输入：root = [3,9,20,null,null,15,7]

输出：[3,9,20,15,7]

示例 2

输入：root = []

输出：[]

约束

  • 节点总数范围：0 ≤ 节点个数 ≤ 1000
  • 节点值范围：-1000 ≤ Node.val ≤ 1000

提示：题目要求的是一维结果，按层访问时不必额外分组。

尚未解锁步骤

观察顺序

从上到下意味着：根先于下一层；同一层中，左侧节点先于右侧节点。

维护待访问点

把已发现但尚未访问的节点按发现先后保留下来。访问一个节点时，再按左、右顺序登记它的孩子。

形成输出

每次访问就记录节点值；待访问集合为空时，记录顺序即为所求数组。

题解与参考实现

核心洞察

先进先出的队列恰好保持节点的发现顺序，因此自然得到从上到下、从左到右的访问次序。

过程

  1. 空树直接返回空数组。
  2. 根节点入队。
  3. 循环取出队首，记录其值。
  4. 按左、右顺序将非空孩子入队。

边界

空树、只有根节点、单边退化树都应正确处理；不能把空孩子加入队列。

复杂度

时间 O(n)；队列最坏占用 O(n) 空间，结果数组不计入辅助空间时亦如此。

替代思路

可以用递归按深度收集节点，但还要保证同层的左右访问顺序，并不比队列直接。栈的 LIFO 特性则不符合本题顺序。 

// Java
class Solution {
    public int[] decorateRecord(TreeNode root) {
        if (root == null) return new int[0];
        Queue<TreeNode> queue = new LinkedList<>();
        List<Integer> ans = new ArrayList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode node = queue.poll(); ans.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        return ans.stream().mapToInt(Integer::intValue).toArray();
    }
}

常见错误

用栈却未反转孩子入栈顺序；或 JavaScript 反复 shift()，导致额外线性移动成本。

追问

若要按层分组，需要在每轮固定当前队列长度；若要求锯齿顺序，再按层调整记录方向。
