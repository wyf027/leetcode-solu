旋转矩阵

不用新矩阵。每一圈取四个对应位置，让值沿顺时针方向走一格；所有圈完成后，图像恰好旋转 90°。

面试题 01.07中等数组 · 矩阵 · 原地

题意与约束

来自 LeetCode CN 官方题面（题目 ID 100185，查询于 2026-08-11）。

要做什么？

给定一幅由 N × N 矩阵表示的图像，原地将它顺时针旋转 90 度。函数签名为 rotate(matrix)，直接修改 matrix，不返回新矩阵。

官方约束

  • 形状：matrix 是 N × N 方阵。
  • 空间：题面追问能否不占额外内存；本页主解使用 O(1) 额外空间。
  • 边界：官方本题面未单列 N 或元素数值范围；单元素矩阵应保持不变。

四点轮换实验台

每次“下一组”仅执行一个四点环。高亮顺序：上 → 右 → 下 → 左 → 上。

演示大小不代表题目额外限制。

准备：选择“下一组”，观察四个位置如何原地交换。

题解

默认隐藏；四个版本都采用相同的原地四点轮换。

核心洞察与过程

主解从始至终都是“逐层 + 四点轮换”，代码与演示保持一致。

一个位置要去哪？

坐标 (row, col) 顺时针旋转后到 (col, n - 1 - row)。一圈里的上、右、下、左四点正好组成一个长度为 4 的环。

完整过程

  1. 第 layer 圈的边界是 first = layer、last = n - 1 - layer。
  2. 只遍历该圈上边的 first..last-1，避免重复。
  3. 把左 → 上、下 → 左、右 → 下、暂存上 → 右。

边界

单元素矩阵不变；奇数边长的中心点不属于任何四点环。方阵之外无法在原数组中完成 90° 旋转。

复杂度

O(n²)每个格子至多参与一次轮换
O(1)只使用一个临时变量

Java

class Solution {
  public void rotate(int[][] matrix) {
    int n = matrix.length;
    for (int layer = 0; layer < n / 2; layer++) {
      int first = layer, last = n - 1 - layer;
      for (int col = first; col < last; col++) {
        int offset = col - first;
        int top = matrix[first][col];
        matrix[first][col] = matrix[last - offset][first];
        matrix[last - offset][first] = matrix[last][last - offset];
        matrix[last][last - offset] = matrix[col][last];
        matrix[col][last] = top;
      }
    }
  }
}

替代方案、追问与常见错误

替代方案

转置再逐行反转同样是 O(n²) 时间、O(1) 额外空间，代码更直观；但本页推荐四点轮换，因为它直接对应旋转映射与每圈的四元环。新建答案矩阵虽直观，却不满足原地要求。

面试追问

  • 逆时针 90°？把搬运方向反过来。
  • 180°？可交换中心对称的元素，或顺时针转两次。
  • 不是方阵？原数组不能原地完成 90° 旋转，因为形状会从 m × n 变为 n × m。

错误 1：循环边界多走一步

列循环必须是 col < last，不是 <= last。右上角已经在同一轮换中出现，重复处理会破坏数据。

错误 2：覆盖后才读取

若不先保存 top，上方旧值会被左侧值覆盖。必须先暂存，再按左、下、右、上顺序搬运。
