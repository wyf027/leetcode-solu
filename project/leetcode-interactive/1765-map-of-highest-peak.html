Problem

题目

给定一个 m × n 的整数矩阵 isWater。值为 1 的格子是水域，值为 0 的格子是陆地。请给每个格子安排一个非负整数高度，满足：

  • 所有水域格子的高度必须是 0；
  • 共享一条边的两个格子，高度差的绝对值至多为 1；
  • 在满足前两项的前提下，让整张地图中的最高高度尽可能大。

返回高度矩阵 height。如果存在多种可行方案，可返回任意一种。

函数形式：
highestPeak(isWater: integer[][]) -> integer[][]

约束

  • m == isWater.length
  • n == isWater[i].length
  • 1 ≤ m, n ≤ 1000
  • isWater[i][j] 为 0 或 1
  • 矩阵中至少有一个水域格子

相邻仅指上、右、下、左四个方向；对角线不算相邻。

示例 1

2 × 2
输入
isWater = [[0,1],[0,0]]
输出
[[1,0],[2,1]]
解释水域高度为 0；其余格子的安排符合相邻高度差限制。

示例 2

3 × 3
输入
isWater = [[0,0,1],[1,0,0],[0,0,0]]
输出
[[1,1,0],[0,1,1],[1,2,2]]
解释所有合法安排中，最高可行高度为 2；满足规则且最高值为 2 的方案均可接受。

Solution

多源广度优先搜索

核心洞察

任意格子的高度都不能超过它到最近水域的曼哈顿距离：沿着通往水域的最短路径，每走一步高度最多变化 1，而终点水域高度固定为 0。于是，把每个格子的高度直接设成“到最近水域的距离”，就同时满足约束并达到可取上界。

完整过程

  1. 建立高度矩阵，先填入 -1 表示未访问。
  2. 把所有水域同时放入队列，并将其高度设为 0。
  3. 按层弹出队首，检查四个邻格；未访问邻格的高度为当前高度加 1，并进入队尾。
  4. 队列清空后，每个格子都得到它离最近水域的距离。

正确性证明

引理 1：多源 BFS 首次访问格子 x 时记录的层数，等于 x 到最近水域的最短距离。因为所有水域同时作为第 0 层，BFS 按路径长度递增访问。

引理 2：令每格高度等于其最近水域距离，水域高度为 0；任意相邻两格到同一集合的最短距离之差至多为 1，因此相邻高度差满足要求。

最优性：任取格子并沿最短路径走向最近水域。每一步高度最多下降 1，水域高度为 0，所以该格高度不可能超过路径长度。算法在每个格子都取到了这个上界，尤其在最远格子取得全局最大可能高度。因此返回方案合法且最优。

复杂度

时间：O(mn)，每个格子最多入队一次。

空间：O(mn)，高度矩阵与队列均可能容纳全部格子。

边界情况

  • 只有一行或一列；
  • 所有格子都是水域；
  • 唯一水域位于角落；
  • 水域密集、多个波前同时抵达同一格；
  • 1000 × 1000 的最大矩阵。

替代方案

可以做两趟动态规划：先从左上到右下，再从右下到左上，更新到最近水域的曼哈顿距离。它同样可达 O(mn)，但初始化无穷值与扫描方向更容易写错。逐个陆地寻找水域会退化到 O((mn)²)；Dijkstra 能做但没有必要，因为每条边权都相同。

常见错误

  • 只从一个水域开始 BFS；
  • 把对角线当作相邻方向；
  • 入队时不标记，导致同一格重复入队；
  • 用递归 DFS，在大矩阵上爆栈且无法自然保证最短层数；
  • 误以为要枚举所有合法高度方案。

面试追问

  • 为什么是多源而不是逐个水域 BFS？ 多源队列把所有水域视为同一个超级源点，一次遍历就得到最近距离。
  • 如果八方向相邻呢？ 把方向数组扩为八个方向，得到切比雪夫距离下的层数。
  • 如果相邻移动代价不同呢？ 普通 BFS 不再适用，应根据权重使用 0-1 BFS 或 Dijkstra。
  • 能否原地复用输入？ 可以重新编码未访问陆地，但可读性与输入语义会变差；面试中应说明取舍。

import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Queue;

class Solution {
    public int[][] highestPeak(int[][] isWater) {
        int m = isWater.length;
        int n = isWater[0].length;
        int[][] height = new int[m][n];
        for (int[] row : height) Arrays.fill(row, -1);

        Queue<int[]> queue = new ArrayDeque<>();
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (isWater[r][c] == 1) {
                    height[r][c] = 0;
                    queue.offer(new int[]{r, c});
                }
            }
        }

        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            for (int[] direction : directions) {
                int nr = cell[0] + direction[0];
                int nc = cell[1] + direction[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n
                        || height[nr][nc] != -1) continue;
                height[nr][nc] = height[cell[0]][cell[1]] + 1;
                queue.offer(new int[]{nr, nc});
            }
        }
        return height;
    }
}

var highestPeak = function(isWater) {
    const m = isWater.length;
    const n = isWater[0].length;
    const height = Array.from({ length: m }, () => Array(n).fill(-1));
    const queue = [];

    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            if (isWater[r][c] === 1) {
                height[r][c] = 0;
                queue.push([r, c]);
            }
        }
    }

    const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    let head = 0;
    while (head < queue.length) {
        const [r, c] = queue[head++];
        for (const [dr, dc] of directions) {
            const nr = r + dr;
            const nc = c + dc;
            if (nr < 0 || nr >= m || nc < 0 || nc >= n
                || height[nr][nc] !== -1) continue;
            height[nr][nc] = height[r][c] + 1;
            queue.push([nr, nc]);
        }
    }
    return height;
};
from collections import deque
from typing import List


class Solution:
    def highestPeak(self, isWater: List[List[int]]) -> List[List[int]]:
        m, n = len(isWater), len(isWater[0])
        height = [[-1] * n for _ in range(m)]
        queue = deque()

        for r in range(m):
            for c in range(n):
                if isWater[r][c] == 1:
                    height[r][c] = 0
                    queue.append((r, c))

        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
        while queue:
            r, c = queue.popleft()
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if not (0 <= nr < m and 0 <= nc < n):
                    continue
                if height[nr][nc] != -1:
                    continue
                height[nr][nc] = height[r][c] + 1
                queue.append((nr, nc))

        return height
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> highestPeak(vector<vector<int>>& isWater) {
        int m = isWater.size();
        int n = isWater[0].size();
        vector<vector<int>> height(m, vector<int>(n, -1));
        queue<pair<int, int>> cells;

        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                if (isWater[r][c] == 1) {
                    height[r][c] = 0;
                    cells.push({r, c});
                }
            }
        }

        const int directions[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!cells.empty()) {
            auto [r, c] = cells.front();
            cells.pop();
            for (const auto& direction : directions) {
                int nr = r + direction[0];
                int nc = c + direction[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n
                    || height[nr][nc] != -1) continue;
                height[nr][nc] = height[r][c] + 1;
                cells.push({nr, nc});
            }
        }
        return height;
    }
};
