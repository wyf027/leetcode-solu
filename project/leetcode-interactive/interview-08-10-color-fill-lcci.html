题意 · Four-neighbor region

只染四向连通的同色区域

图像由二维整数数组 image 表示。从 (sr, sc) 出发，把所有与起点颜色相同、且通过上、下、左、右相连的像素改为 newColor。

官方示例

输入 image = [[1,1,1],[1,1,0],[1,0,1]], sr = 1, sc = 1, newColor = 2
输出 [[2,2,2],[2,2,0],[2,0,1]]

右下角的 1 与起点仅对角相邻，不属于四向连通区域，因此保持不变。

约束

  • 1 <= image.length, image[0].length <= 50
  • 起点坐标一定在图像范围内。
  • 0 <= image[i][j], newColor <= 65535
  • 连通方向只有上、下、左、右，不含对角线。

    Solution · Iterative BFS

    入队即染色，就是访问标记

    记录起点原色。若原色已经等于新色，直接返回；否则从起点开始，用队列逐层扩张所有同色四邻居。

    核心洞察

    二维图像可以看成图：每个像素是节点，上下左右是边。需要填充的正是从起点可达、且颜色等于 oldColor 的连通分量。

    发现同色邻居 → 立即改色 → 再入队

    改色承担了 visited 的职责；同一像素不会再次满足原色条件，因此无需额外布尔数组。

    完整过程

    1. 保存 oldColor = image[sr][sc]。
    2. 若 oldColor == newColor，原图直接返回。
    3. 先把起点改成新色，再把起点放入队列。
    4. 反复取出队首，检查四个方向。
    5. 对范围内且仍为原色的邻居，立即改色并入队。
    6. 队列清空时，整个连通区域已经处理完毕。

    边界

    • 原色等于新色必须提前返回，否则会反复访问。
    • 每次读矩阵前先判断行列范围。
    • 对角相邻不属于连通边。
    • 一行、一列、单像素图像都适用同一流程。

    复杂度

    设图像为 m × n。每个像素最多入队一次，时间为 O(mn)；队列最坏保存整个区域，额外空间为 O(mn)。

    替代方案

    递归 DFS 代码更短，也能用“改色”充当访问标记；但 Python 等语言在大连通区域可能触及递归深度限制。显式栈 DFS 同样安全。面试主线选 BFS，便于解释队列前沿和最坏空间。

    面试追问

    • 若允许八方向连通，怎样改方向数组？
    • 若只允许颜色差不超过阈值，判断条件如何改变？
    • 怎样返回被修改的像素数量或边界框？
    • 超大图像分块存储时，队列如何跨块工作？

    常见错误

    • 出队时才染色，导致同一邻居被重复入队。
    • 忘记处理 oldColor == newColor。
    • 把对角线也当成相邻像素。
    • 先访问 image[nr][nc] 再检查越界。

    为什么不需要 visited

    本题只会扩张原色节点。一旦发现节点就将其改成新色，它便不再满足原色条件。这一原地标记既减少空间，也保持逻辑清晰；前提是原色和新色不同。
