Search space / Scheduling

完成所有工作的
最短时间

把每份不可拆分的工作交给一位工人。目标不是让总时间变少，而是让最忙的那个人尽可能早地结束。

先想一想：如果预先猜一个最大工作时间，怎样判断它是否做得到？

01 / Problem

题目说明

位运算 · 数组 · 动态规划 · 回溯 · 位掩码

准确转述

给定整数数组 jobs，其中 jobs[i] 表示第 i 项工作所需的时间。现在有 k 位工人，每项工作必须且只能完整地分配给一位工人。

一位工人的工作时间等于分配给他的全部工作耗时之和。请在所有合法分配中，最小化工人工作时间的最大值，并返回这个最小值。

函数
minimumTimeRequired(jobs, k)
参数
jobs: integer[]，k: integer
返回
integer，最小可能的最大工作时间

约束与语义

  • 1 ≤ k ≤ jobs.length ≤ 12
  • 1 ≤ jobs[i] ≤ 10⁷
  • 工作不可拆分，也不能被多位工人同时处理。
  • 允许工人没有被分配工作。

官方示例 1

输入
jobs = [3,2,3], k = 3
输出
3

三项工作可以分别交给三位工人，最忙工人的耗时为 3。

官方示例 2

输入
jobs = [1,2,4,7,8], k = 2
输出
11

一种最优分配为 {1,2,8} 与 {4,7}，两位工人的耗时都为 11。

04 / Solution

二分答案 + 降序回溯判定

核心洞察

如果最大工作时间限制为 T 时可以完成所有工作，那么任何更大的限制也一定可行。因此答案具有单调性：在 [max(jobs), sum(jobs)] 上二分 T，再用回溯判断每份工作能否放入某位工人的剩余容量。

完整过程

  1. 将工作按耗时从大到小排序，让最难安置的工作最先进入搜索。
  2. 二分候选上限 T，下界是最长单项工作，上界是全部工作总和。
  3. 维护长度为 k 的负载数组，从当前工作开始尝试放到每位不会超出 T 的工人名下。
  4. 若后续工作均能放下，说明 T 可行，收缩右边界；否则提高左边界。
  5. 当左右边界相遇时，该值就是最小可行的最大工作时间。

两条关键剪枝

  • 跳过同负载工人：若两位工人当前负载相同，把当前工作交给其中任何一位产生的后续状态等价，只搜索一次。
  • 空桶失败即停止：若工作放进一位空闲工人后仍找不到解，再换另一位空闲工人只是交换工人编号，无需重复。
feasible(T) = 是否存在分配，使每位工人的 load ≤ T

正确性说明

判定完整性：回溯对每项工作枚举所有不超出 T 的非等价工人负载。跳过的仅是工人编号互换形成的对称状态，所以只要存在合法分配，搜索就能到达一个合法叶节点。

单调性：若限制 T 可行，同一分配在任意 T′ ≥ T 下仍然可行；若 T 不可行，则任何更小限制也不可行。

二分结论：二分始终保留最小可行值，并最终让左右边界相等，因此返回值正是所有分配中最大工作时间的最小可能值。

复杂度与边界

设 n = jobs.length，S = sum(jobs)。每次判定的朴素上界为 O(kⁿ)，二分进行 O(log S) 次，因此时间上界为 O(kⁿ log S)；排序另需 O(n log n)。剪枝会显著减少实际状态数。递归与负载数组的额外空间为 O(n + k)。

  • k = 1 时答案是所有工作之和。
  • k = n 时答案是最长工作耗时。
  • 大量相同耗时或相同负载时，对称剪枝尤其重要。

JavaminimumTimeRequired
import java.util.Arrays;

class Solution {
    public int minimumTimeRequired(int[] jobs, int k) {
        Arrays.sort(jobs);
        reverse(jobs);

        int left = jobs[0];
        int right = 0;
        for (int job : jobs) {
            right += job;
        }

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (canFinish(jobs, new int[k], 0, mid)) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

    private boolean canFinish(int[] jobs, int[] loads, int index, int limit) {
        if (index == jobs.length) {
            return true;
        }

        int job = jobs[index];
        for (int worker = 0; worker < loads.length; worker++) {
            if (loads[worker] + job > limit) {
                continue;
            }
            if (worker > 0 && loads[worker] == loads[worker - 1]) {
                continue;
            }

            loads[worker] += job;
            if (canFinish(jobs, loads, index + 1, limit)) {
                return true;
            }
            loads[worker] -= job;

            if (loads[worker] == 0) {
                break;
            }
        }
        return false;
    }

    private void reverse(int[] nums) {
        for (int left = 0, right = nums.length - 1; left < right; left++, right--) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
        }
    }
}

/**
 * @param {number[]} jobs
 * @param {number} k
 * @return {number}
 */
var minimumTimeRequired = function(jobs, k) {
    jobs.sort((a, b) => b - a);

    let left = jobs[0];
    let right = jobs.reduce((sum, job) => sum + job, 0);

    const canFinish = (limit) => {
        const loads = new Array(k).fill(0);

        const dfs = (index) => {
            if (index === jobs.length) {
                return true;
            }

            const job = jobs[index];
            const seenLoads = new Set();

            for (let worker = 0; worker < k; worker++) {
                if (loads[worker] + job > limit) {
                    continue;
                }
                if (seenLoads.has(loads[worker])) {
                    continue;
                }
                seenLoads.add(loads[worker]);

                loads[worker] += job;
                if (dfs(index + 1)) {
                    return true;
                }
                loads[worker] -= job;

                if (loads[worker] === 0) {
                    break;
                }
            }
            return false;
        };

        return dfs(0);
    };

    while (left < right) {
        const mid = left + Math.floor((right - left) / 2);
        if (canFinish(mid)) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left;
};

from typing import List


class Solution:
    def minimumTimeRequired(self, jobs: List[int], k: int) -> int:
        jobs.sort(reverse=True)
        left, right = jobs[0], sum(jobs)

        def can_finish(limit: int) -> bool:
            loads = [0] * k

            def dfs(index: int) -> bool:
                if index == len(jobs):
                    return True

                job = jobs[index]
                seen_loads = set()

                for worker in range(k):
                    if loads[worker] + job > limit:
                        continue
                    if loads[worker] in seen_loads:
                        continue
                    seen_loads.add(loads[worker])

                    loads[worker] += job
                    if dfs(index + 1):
                        return True
                    loads[worker] -= job

                    if loads[worker] == 0:
                        break

                return False

            return dfs(0)

        while left < right:
            mid = (left + right) // 2
            if can_finish(mid):
                right = mid
            else:
                left = mid + 1

        return left
C++minimumTimeRequired
class Solution {
public:
    int minimumTimeRequired(vector<int>& jobs, int k) {
        sort(jobs.rbegin(), jobs.rend());

        int left = jobs.front();
        int right = accumulate(jobs.begin(), jobs.end(), 0);

        while (left < right) {
            int mid = left + (right - left) / 2;
            vector<int> loads(k, 0);

            if (canFinish(jobs, loads, 0, mid)) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

private:
    bool canFinish(
        const vector<int>& jobs,
        vector<int>& loads,
        int index,
        int limit
    ) {
        if (index == static_cast<int>(jobs.size())) {
            return true;
        }

        int job = jobs[index];
        unordered_set<int> seenLoads;

        for (int worker = 0; worker < static_cast<int>(loads.size()); worker++) {
            if (loads[worker] + job > limit) {
                continue;
            }
            if (seenLoads.count(loads[worker])) {
                continue;
            }
            seenLoads.insert(loads[worker]);

            loads[worker] += job;
            if (canFinish(jobs, loads, index + 1, limit)) {
                return true;
            }
            loads[worker] -= job;

            if (loads[worker] == 0) {
                break;
            }
        }
        return false;
    }
};

替代方案

  • 直接回溯最小化答案：维护当前最优上界并尝试所有分配，写法直观；配合降序与对称剪枝也能通过，但“可行性”的单调结构不如二分方案明显。
  • 状态压缩 DP：预计算每个工作子集的耗时，再做“前若干工人完成某子集”的动态规划，状态更稳定，但通常需要约 O(k·3ⁿ) 的转移。

面试追问

  • 为什么按降序安排工作不会改变答案，却能加速搜索？
  • 如何严谨证明“相同负载的工人只试一个”不会漏解？
  • 如果工作可以拆分，问题会怎样简化？
  • 若 n 增大到 30，当前方法的瓶颈在哪里？

常见错误

  • 使用贪心“每次交给当前最空闲工人”，它能给出较好方案，但不保证全局最优。
  • 二分下界从 0 开始，虽然可能仍正确，却浪费了大量不可能的判定。
  • 回溯完成后忘记恢复工人负载，污染后续分支。
  • 对称剪枝条件写错，跳过负载不同的工人，从而漏掉合法分配。

复盘清单

  • 看到“最小化最大值”，先检查答案是否具有单调性。
  • 判定函数里，优先处理约束最紧的元素。
  • 辨认仅由无意义编号差异造成的等价状态。
  • 分别说明判定正确性、单调性和二分收敛性。
