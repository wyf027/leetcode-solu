人口最多的年份

Maximum Population Year

同一年出生与离世交错时，如何确定最早的人口高峰？先读清年份边界，再尝试自己的方法。

01 / 题目

给定二维整数数组 logs，每条记录 logs[i] = [birth_i, death_i] 表示一个人的出生年份与死亡年份。年份 x 的人口，是满足 birth_i ≤ x < death_i 的人数。

出生当年计入，死亡当年不计入。返回人口数量最大时对应的最早年份；若有多个年份并列，选年份最小的那个。

参数：logs: int[][]　返回：int（年份）

官方示例 1

输入：logs = [[1993,1999],[2000,2010]]
输出：1993

最高人口为 1；第一次达到这一人数的年份为 1993。

官方示例 2

输入：logs = [[1950,1961],[1960,1971],[1970,1981]]
输出：1960

1960 和 1970 的人口都是 2，这是最大值；选择较早的 1960。

约束

  • 1 ≤ logs.length ≤ 100
  • 1950 ≤ birth_i < death_i ≤ 2050

04 / 题解：在年份边界记录人口变化

一次生命区间 [birth, death) 只会在两个时刻改变人口：出生年 +1，死亡年 −1。把这些变化累加，就能恢复每一年的人口。

核心洞察与完整过程

  1. 用长度 101 的数组 diff 对应 1950 至 2050。初始化全为 0。
  2. 对每条记录，令 diff[birth - 1950] += 1，diff[death - 1950] -= 1。同年出生与死亡的变化先合并。
  3. 从 1950 扫描到 2049，先执行 current += diff[year - 1950]，再比较人数。2050 仅作为死亡边界槽位，无须作为候选年份。
  4. 仅当 current > best 时更新答案。按时间升序扫描时，相等不更新即可保留最早年份。

非零年份变化

大量输入时条带只显示前 12 人；人口统计与事件计算使用全部记录。净变化为 0 的年份不显示卡片，但仍会逐年扫描。

用官方示例 2 走一遍

1950 年 +1，当前人口为 1；1960 年 +1，人口变成 2，答案更新为 1960；1961 年 −1，人口回到 1；1970 年 +1，再次达到 2，但不更新答案；1971 年 −1。1981 年最后一人死亡，人口归零。于是答案为 1960。

正确性论证

人口不变式：扫描完年份 x 的变化后，累计值等于所有出生年份不晚于 x 的人数，减去所有死亡年份不晚于 x 的人数。因此每人贡献恰好为 1（当 birth ≤ x < death）或 0，累计值就是题目定义的人口。

最优答案不变式：每步记录的是已扫描年份中的最高人口及其最早年份。更大人数出现时更新；相同人数出现时保留旧答案，而旧年份一定更早。扫描覆盖全部可能有人存活的年份，最终记录就是全局最早峰值。

边界与常见错误

  • 死亡年不计入：应在 death 减 1，不能在 death + 1 减 1。
  • 必须先累加本年变化，再比较人口，否则会错移一年。
  • 更新条件应为严格大于，使用大于等于会返回较晚的并列年份。
  • 2050 可能出现在死亡端点，数组必须容纳索引 100；答案最大为 2049。
  • 同年出生与死亡应合并后再计算当年人口，不能把临时事件处理中的人数当作峰值。
  • 输入非空且每人至少计入一年，最大人口至少为 1；重复区间表示不同的人，不能去重。

复杂度

设人数为 n，年份范围大小为 R：时间 O(n + R)，空间 O(R)。本题 R 固定为 101，因此也可写为时间 O(n)、额外空间 O(1)。

替代方案

直接逐年枚举并遍历所有人，用区间条件统计人数：时间 O(nR)、额外空间 O(1)，在本题小范围内也足够。若年份跨度很大，改用有序事件扫描：记录出生 +1、死亡 −1，按年份排序并合并同年事件；时间 O(n log n)、空间 O(n)。

面试追问

  • 年份可达 10⁹？使用排序事件或坐标压缩，人口只会在端点发生变化，无需扫描空白年份。
  • 要返回所有高峰年份？按年扫描时收集并列年份；范围很大时用事件之间的半开区间表示答案。
  • 持续插入生命区间后立即查询？可考虑对人口区间加 1 的线段树，节点维护最大人数及最早位置；这是动态问题，静态题无需这一结构。

Java

class Solution {
    public int maximumPopulation(int[][] logs) {
        int[] diff = new int[101];
        for (int[] log : logs) {
            diff[log[0] - 1950]++;
            diff[log[1] - 1950]--;
        }
        int current = 0, best = 0, answer = 1950;
        for (int i = 0; i < 100; i++) {
            current += diff[i];
            if (current > best) {
                best = current;
                answer = 1950 + i;
            }
        }
        return answer;
    }
}

#include <vector>
using std::vector;

class Solution {
public:
    int maximumPopulation(vector<vector<int>>& logs) {
        int diff[101] = {};
        for (const auto& log : logs) {
            ++diff[log[0] - 1950];
            --diff[log[1] - 1950];
        }
        int current = 0, best = 0, answer = 1950;
        for (int i = 0; i < 100; ++i) {
            current += diff[i];
            if (current > best) {
                best = current;
                answer = 1950 + i;
            }
        }
        return answer;
    }
};
