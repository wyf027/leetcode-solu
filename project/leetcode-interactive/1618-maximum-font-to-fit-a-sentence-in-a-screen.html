找出适应屏幕的最大字号

一行文字，一块有限的屏幕，一组有序字号。在宽与高的双重限制里，找出最大的合法选择。

MEDIUM付费题数组字符串二分查找
01 / PROBLEM

选择能完整显示的一档字号

文字只能占一行。宽度取每个字符宽度之和，高度由该字号的统一字符高度决定。

给定字符串 text、屏幕宽度 w、屏幕高度 h，以及按严格升序排列的可用字号数组 fonts。另有只读接口 FontInfo，可查询某字号下字符的宽度与字符高度。

fits(size) ⇔ Σ getWidth(size, text[i]) ≤ w
　　　　　　且 getHeight(size) ≤ h

相同参数的查询总会得到相同结果。字号增大时，每个字符的宽度和整体高度都不会减小。返回能让整段文字完整落在屏幕内的最大可用字号；若最小字号也放不下，返回 -1。

完整函数形式：maxFont(text, w, h, fonts, fontInfo) → int

Provided API

getWidth(fontSize, ch)返回字符 ch 在指定字号下的宽度，单次调用 O(1)。
getHeight(fontSize)返回指定字号下任意字符的高度，单次调用 O(1)。
单调保证字号变大时宽、高不减，因此适配状态是一段 true，随后是一段 false。

EXAMPLE 01

输入：text = "helloworld",
w = 80, h = 20,
fonts = [6,8,10,12,14,16,18,24,36]
输出：6

EXAMPLE 02

输入：text = "leetcode",
w = 1000, h = 50,
fonts = [1,2,4]
输出：4

EXAMPLE 03

输入：text = "easyquestion",
w = 100, h = 100,
fonts = [10,15,20,25]
输出：-1
  • 1 ≤ text.length ≤ 50,000
  • text 只包含小写英文字母
  • 1 ≤ w ≤ 10⁷
  • 1 ≤ h ≤ 10⁴
  • 1 ≤ fonts.length ≤ 10⁵
  • 1 ≤ fonts[i] ≤ 10⁵
  • fonts 严格升序且无重复值

03 / SOLUTION

在单调答案上找“最后一个 true”

把排版问题压缩成布尔谓词：某个字号能否同时通过高度与宽度检查。

01

先判高度

若 getHeight(size) > h，立即失败，无须做字符宽度查询。

02

压缩重复字符

统计 26 个字母的频次。一次检查最多查询 26 种字符，不必遍历整段文字。

03

保留右侧答案

使用上中位数；适配令 left = mid，失败令 right = mid - 1。

完整过程

  1. 扫描 text，建立 26 个小写字母的频次表。
  2. 定义 fits(size)：先检查高度；再累加“出现次数 × 单字符宽度”。总宽一旦超过 w 就提前失败。
  3. 在 fonts 的下标区间二分。宽、高随字号单调不减，所以适配结果只会从 true 变为 false。
  4. 区间收敛后检查 fonts[left]；通过则返回它，否则返回 -1。

复杂度

设 n 为文本长度、m 为字号数、Σ = 26。

时间：O(n + Σ log m)
空间：O(Σ) = O(1)
API 调用：O(Σ log m)

不做频次压缩的常规写法为 O(n log m)，仍然正确，但接口调用更多。

正确性证明

  1. 谓词正确：fits(size) 验证唯一高度和全部字符的宽度总和，所以它为 true 当且仅当该字号可完整显示。
  2. 单调性：字号增大时宽、高不减。某字号失败，则更大字号都失败；某字号通过，则更小字号都通过。
  3. 不变量：每轮都保留“可能成为最后一个适配字号”的下标。通过时向右收缩，失败时舍弃中点及右侧。
  4. 结论：最终候选通过时，它右侧均失败，故为最大答案；若候选失败，则连最小字号都失败，答案为 -1。

关键边界

  • 只有一个可用字号
  • 最小字号也放不下
  • 所有字号均放得下
  • 宽度或高度恰好贴边
  • 高度先失败时跳过宽度查询
  • Java/C++ 用更宽整数累计总宽

四语言完整实现

均使用字符频次压缩。FontInfo 由评测系统提供，不应自行实现。

/**
 * FontInfo 由评测系统提供：
 * int getWidth(int fontSize, char ch)
 * int getHeight(int fontSize)
 */
class Solution {
    public int maxFont(String text, int w, int h,
                       int[] fonts, FontInfo fontInfo) {
        int[] count = new int[26];
        for (char ch : text.toCharArray()) {
            count[ch - 'a']++;
        }

        int left = 0, right = fonts.length - 1;
        while (left < right) {
            int mid = left + (right - left + 1) / 2;
            if (fits(fonts[mid], count, w, h, fontInfo)) {
                left = mid;
            } else {
                right = mid - 1;
            }
        }
        return fits(fonts[left], count, w, h, fontInfo)
                ? fonts[left] : -1;
    }

    private boolean fits(int size, int[] count, int w, int h,
                         FontInfo fontInfo) {
        if (fontInfo.getHeight(size) > h) return false;
        long width = 0;
        for (int i = 0; i < 26; i++) {
            if (count[i] == 0) continue;
            width += (long) count[i]
                    * fontInfo.getWidth(size, (char) ('a' + i));
            if (width > w) return false;
        }
        return true;
    }
}
/**
 * @param {string} text
 * @param {number} w
 * @param {number} h
 * @param {number[]} fonts
 * @param {FontInfo} fontInfo
 * @return {number}
 */
var maxFont = function (text, w, h, fonts, fontInfo) {
    const count = new Array(26).fill(0);
    for (const ch of text) {
        count[ch.charCodeAt(0) - 97]++;
    }

    const fits = (size) => {
        if (fontInfo.getHeight(size) > h) return false;
        let width = 0;
        for (let i = 0; i < 26; i++) {
            if (count[i] === 0) continue;
            width += count[i]
                * fontInfo.getWidth(size, String.fromCharCode(97 + i));
            if (width > w) return false;
        }
        return true;
    };

    let left = 0;
    let right = fonts.length - 1;
    while (left < right) {
        const mid = left + Math.floor((right - left + 1) / 2);
        if (fits(fonts[mid])) left = mid;
        else right = mid - 1;
    }
    return fits(fonts[left]) ? fonts[left] : -1;
};

/**
 * FontInfo 由评测系统提供：
 * int getWidth(int fontSize, char ch);
 * int getHeight(int fontSize);
 */
class Solution {
public:
    int maxFont(string text, int w, int h,
                vector<int>& fonts, FontInfo fontInfo) {
        array<int, 26> count{};
        for (char ch : text) ++count[ch - 'a'];

        auto fits = [&](int size) -> bool {
            if (fontInfo.getHeight(size) > h) return false;
            long long width = 0;
            for (int i = 0; i < 26; ++i) {
                if (count[i] == 0) continue;
                width += 1LL * count[i]
                       * fontInfo.getWidth(size, char('a' + i));
                if (width > w) return false;
            }
            return true;
        };

        int left = 0;
        int right = static_cast<int>(fonts.size()) - 1;
        while (left < right) {
            int mid = left + (right - left + 1) / 2;
            if (fits(fonts[mid])) left = mid;
            else right = mid - 1;
        }
        return fits(fonts[left]) ? fonts[left] : -1;
    }
};

替代方案

从大到小线性扫描

找到第一个适配字号即可返回，但最坏检查全部 m 个字号；m 达到 10⁵ 时不如二分。

不做字符频次压缩

每次直接遍历 text，复杂度 O(n log m)，逻辑仍正确。频次表能将每轮最多 50,000 次接口调用降到 26 次。

面试追问

如果允许自动换行？

适配谓词要模拟换行并累计行数与总高。只要更大字号仍不可能恢复适配，二分框架依然成立。

如果 fonts 无序？

先排序去重后再二分，或线性扫描并维护最大合法字号。排序需要 O(m log m)。

为什么用上中位数？

通过时保留 mid 并继续向右。下中位数可能让二元素区间的 left 原地不动；上中位数确保收缩。

常见错误

  • 把文本总宽误写成最大单字符宽度
  • 忘记文字只能显示为一行
  • 只检查宽度，漏掉高度
  • 用严格小于，错过恰好贴边
  • 二分边界更新跳过正确答案
  • 默认答案存在，忘记返回 -1
  • 累计总宽时使用可能溢出的窄整数
