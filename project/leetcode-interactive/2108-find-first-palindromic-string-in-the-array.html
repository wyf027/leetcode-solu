示例 3

输出：""

两个字符串都不是回文，因此返回空字符串。

04 / 独立题解

先尝试自己的方法，再展开推导和四语言代码。

核心洞察：按顺序找，用两端检验

“第一个”要求保留数组顺序。一旦某个单词满足条件，立即返回它。判断一个单词时，比较对称位置即可：左指针从 0 开始，右指针从长度减 1 开始；不同就淘汰，相同就向中间移动。

完整过程

  1. 依次取出每个单词，初始化 l = 0, r = word.length - 1。
  2. 当 l < r 且两端字符相同时，执行 l++、r--。
  3. 循环停止后，若 l ≥ r，所有需要检查的字符对都相等，返回该单词。
  4. 否则该单词存在不等的对称字符，继续下一个。
  5. 全部遍历后仍未命中，返回 ""。

示例 1 中，abc 的 a/c 不同，car 的 c/r 不同；ada 的 a/a 相同，指针到中间 d 时停止，因此返回 ada，后面不再检查。

正确性

内层不变式：每次比较前，区间 [l,r] 外侧的所有对称字符对均已确认相等。初始外侧为空，命题成立；一次相等比较后收缩区间，命题仍成立。如果发现不相等字符对，按回文定义该词必非回文。如果指针相遇或交错，全部对称字符对已确认相等，故该词是回文。

外层不变式：处理下标 i 前，所有更早的单词都已判定不是回文。因此第一次被内层确认的单词必为第一个回文。若遍历完毕未找到，所有单词都非回文，返回空字符串符合题意。

终止性：每次内层成功比较使剩余区间缩短 2；失配立即结束。外层每次前进一项，且数组有限，算法终止。

边界与复杂度

单字符无需比较就是回文；偶数长度以指针交错结束，奇数长度以相遇结束；首项命中立即返回；无命中返回空字符串。空数组和空单词不在官方输入范围内。

设 N 为单词数、M 为最大词长、S 为所有单词长度之和。最坏时间 O(S)，也可写成 O(NM)；双指针额外空间 O(1)，不计返回值及输入。每词最多比较 ⌊长度/2⌋ 对。可视化保存历史帧的空间不属于提交算法。

替代方案

逐个反转字符串，判断反转结果是否等于原串。更直观，最坏时间仍是 O(S)，但每次构造反转串需要 O(M) 额外空间；双指针无需新字符串，而且一旦失配即可结束。

常见错误

  • 排序后再找，破坏“第一个”的原始顺序。
  • 只比较首尾一对，漏掉 abca 这种内部失配。
  • 找到后仍覆盖答案，最后返回了最后一个回文。
  • 右指针初始化为长度而非长度减 1，造成越界。
  • 未命中时返回 null 或 false；正确返回值是空字符串。

面试追问

输入改为流？仍按到达顺序检查，找到即停，无需保存全部单词。允许 Unicode 或忽略标点大小写？先明确字符单位和归一化规则，当前小写英文字母假设不再足够。求所有回文？把立即返回改成收集，输出空间随命中数量增长。

Java · 官方签名

class Solution {
    public String firstPalindrome(String[] words) {
        for (String word : words) {
            int l = 0, r = word.length() - 1;
            while (l < r && word.charAt(l) == word.charAt(r)) {
                l++;
                r--;
            }
            if (l >= r) return word;
        }
        return "";
    }
}

/**

var firstPalindrome = function(words) {
    for (const word of words) {
        let l = 0, r = word.length - 1;
        while (l < r && word[l] === word[r]) {
            l++;
            r--;
        }
        if (l >= r) return word;
    }
    return "";
};

Python 3 · 官方签名

from typing import List

class Solution:
    def firstPalindrome(self, words: List[str]) -> str:
        for word in words:
            l, r = 0, len(word) - 1
            while l < r and word[l] == word[r]:
                l += 1
                r -= 1
            if l >= r:
                return word
        return ""

C++ · 官方签名

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string firstPalindrome(vector<string>& words) {
        for (const string& word : words) {
            int l = 0, r = static_cast<int>(word.size()) - 1;
            while (l < r && word[l] == word[r]) {
                ++l;
                --r;
            }
            if (l >= r) return word;
        }
        return "";
    }
};
