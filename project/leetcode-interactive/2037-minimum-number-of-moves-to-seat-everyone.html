使每位学生都有座位的
最少移动次数

Minimum Number of Moves to Seat Everyone

一条数轴，一组座位，一群学生。怎样安排，才能让所有人走过的总步数最少？

打开官方题目 ↗

01 / 题目与规则

给定两个长度均为 n 的整数数组：seats[i] 表示第 i 个空座位在数轴上的位置，students[j] 表示第 j 位学生的位置。

每次操作可以让任意一名学生向左或向右移动 1 个单位。为每位学生分配一个不同的座位，返回所有学生需要的最少总移动次数，返回值是整数。

同一坐标可以有多个座位，也可以有多名学生。座位身份必须不同，坐标可以相同；座位本身不能移动。

参数与约束

  • n == seats.length == students.length
  • 1 ≤ n ≤ 100
  • 1 ≤ seats[i], students[j] ≤ 100

函数：minMovesToSeat(seats, students) → integer

02 / 官方示例

示例 1

seats = [3,1,5], students = [2,7,4]
输出：4

按学生原始顺序，可以分别走 2 → 1、7 → 5、4 → 3，总步数为 1 + 2 + 1 = 4。

示例 2

seats = [4,1,5,9], students = [1,3,2,6]
输出：7

一种最优安排是 1 → 1、3 → 4、2 → 5、6 → 9，总步数为 0 + 1 + 3 + 3 = 7。最优安排可以不唯一。

示例 3

seats = [2,2,6,6], students = [1,3,2,6]
输出：4

位置 2 和 6 各有两个独立座位。安排 1 → 2、3 → 6、2 → 2、6 → 6，共 1 + 3 + 0 + 0 = 4 步。

04 / 独立题解

先自己思考，再展开推导、交互与四语言代码。

排序后，让同一名次的人与座位配对

沿数轴从左到右排列学生与座位。最左边的学生配最左边的座位，依次向右，累加每对坐标的绝对差。无需模拟一格一格走路。

每一步固定一对相同排名的学生与座位。圆形表示学生，方形表示座位；横线长度表示这一次的距离。重合的坐标会分行展示，不会丢失座位。

完整过程

  1. 将 seats 和 students 分别按数值升序排序。
  2. 从下标 0 开始，将 students[i] 分配给 seats[i]。
  3. 将 abs(seats[i] - students[i]) 加到答案中。
  4. 遍历完所有下标，返回累计值。

例如示例 1：座位变为 [1,3,5]，学生变为 [2,4,7]，各对距离是 1、1、2，合计 4。

正确性：交叉配对可以消除

设两个学生的位置满足 a ≤ b，两个座位的位置满足 x ≤ y。顺序配对的代价不超过交叉配对：

|a - x| + |b - y| ≤ |a - y| + |b - x|

证明该不等式：函数 f(t) = |t - x| - |t - y| 在 t ≤ x 时为 x − y，在 x 到 y 之间为 2t − x − y，在 t ≥ y 时为 y − x，因此单调不减。由 a ≤ b 得到 f(a) ≤ f(b)，移项即为上式。

把任意最优分配按学生位置排列。只要其座位顺序存在逆序，就交换这两位学生的座位，总代价不会变大，并可通过相邻逆序交换逐步消除所有逆序。最终得到按排序下标逐一对应的方案，其代价仍最优。每个座位下标恰好使用一次，因此方案也满足一人一座。

边界与复杂度

  • n = 1：直接返回两个位置的差的绝对值。
  • 重复位置保留全部元素；不同下标对应不同的人或座位，不可去重。
  • 同位置配对贡献 0；所有配对的总移动次数至多 100 × 99 = 9900，常规整数类型足够。
  • 主算法时间为 O(n log n)，求和为 O(n)。下方代码均复制输入后排序，不改动调用方数组，额外空间为 O(n)，包含排序时可能使用的辅助存储。

替代方案：统计跨边界的人数差

坐标范围只有 1 到 100，可以统计每个位置的学生数量减座位数量。沿坐标累加为 balance。对每条边界 x → x+1（x = 1…99），至少有 |balance| 名学生必须跨越它，累计这些绝对值就是答案。顺序配对恰能实现这种最少运输量。时间 O(n + U)，空间 O(U)，这里 U = 100；坐标范围很大时，排序方案更直接。

常见错误

  • 按输入顺序配对，忽略了位置顺序。
  • 每次给当前学生挑最近的空座位：如 seats = [1,5]、students = [4,6]，先让 4 去 5 会总共走 6 步，而 4 去 1、6 去 5 只需 4 步。
  • 用集合去重，误把同坐标的多个座位当成一个。
  • 忘记取绝对值，正负距离互相抵消。
  • JavaScript 直接调用无比较器的 sort()，导致按字符串而非数值排序。

面试追问

怎样返回具体安排？ 排序时保存原始下标，按排名匹配并输出原始学生与座位编号。座位比学生多怎么办？ 简单同下标配对不再充分，可对排序后的两个序列做“跳过座位 / 匹配座位”的动态规划。每位学生每步成本不同呢？ 上面的交换不等式不能直接用于加权代价，需要重新证明或使用其他分配算法。

四语言可提交代码

遵循官方函数名与参数形式；使用复制后排序，便于调用方保留原始输入。以下代码均未运行验证。

Java

import java.util.Arrays;

class Solution {
    public int minMovesToSeat(int[] seats, int[] students) {
        int[] a = seats.clone();
        int[] b = students.clone();
        Arrays.sort(a);
        Arrays.sort(b);
        int moves = 0;
        for (int i = 0; i < a.length; i++) {
            moves += Math.abs(a[i] - b[i]);
        }
        return moves;
    }
}

var minMovesToSeat = function(seats, students) {
    const a = [...seats].sort((x, y) => x - y);
    const b = [...students].sort((x, y) => x - y);
    let moves = 0;
    for (let i = 0; i < a.length; i++) {
        moves += Math.abs(a[i] - b[i]);
    }
    return moves;
};

Python 3

from typing import List

class Solution:
    def minMovesToSeat(self, seats: List[int], students: List[int]) -> int:
        a = sorted(seats)
        b = sorted(students)
        return sum(abs(x - y) for x, y in zip(a, b))

C++

#include <algorithm>
#include <cstdlib>
#include <vector>
using namespace std;

class Solution {
public:
    int minMovesToSeat(vector<int>& seats, vector<int>& students) {
        vector<int> a = seats, b = students;
        sort(a.begin(), a.end());
        sort(b.begin(), b.end());
        int moves = 0;
        for (int i = 0; i < static_cast<int>(a.size()); ++i) {
            moves += abs(a[i] - b[i]);
        }
        return moves;
    }
};
