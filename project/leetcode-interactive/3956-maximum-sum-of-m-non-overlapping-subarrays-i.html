LEETCODE 3956 · HARD

M 个非重叠子数组最大和 I

把“选多少段、处理到哪里”写成 DP：扫描数组时可跳过当前位置，或让一段合法长度区间在当前位置结束。

题意

给定 nums 及 m, l, r。选择至少一段、至多 m 段互不重叠子数组，每段长度在 [l,r]，最大化它们元素和。

n ≤ 1000，元素可为负；即使全负也必须选一段。

示例

nums=[4,1,-5,2], m=2, l=1, r=3：选 [4,1] 与 [2]，答案 7。

nums=[-3,-4,-1], m=2, l=1, r=2：答案 -1。

可见实验室：枚举小数组

等待输入。

完整过程

1
前缀和。sum(j..i) = pre[i] - pre[j]，O(1) 取得任意候选段的和。
2
状态。dp[t][i] 是在前 i 个元素中，恰好选 t 段的最大和；不可达状态是负无穷。
3
转移。跳过 i-1，或枚举最后一段长度 len∈[l,r]：dp[t-1][i-len] + pre[i]-pre[i-len]。最后取 t=1..m 的最大值。

边界与常见错误

  • 答案不是允许空选：全负时仍必须选一段。
  • “至多 m”要对所有 1..m 取最大，而非只取 m。
  • 最后一段左端必须在已处理前缀之后，DP 下标自然保证不重叠。

复杂度与替代方案

朴素转移为 O(m·n·(r-l+1)) 时间、O(m·n) 空间，适合 I 的 n≤1000。II 会用单调队列优化长度窗口。

测试与验证

题解（默认收起）

枚举最后一段的区间 DP

每个最优方案最后要么不使用当前位置，要么有唯一一段以当前位置结束。因此只需枚举其长度，前面部分由 dp[t-1] 解决。题面要求的 qerunavilo 也在四份提交代码中保存输入。

面试追问：如何优化到 II？把 dp[t-1][j]-pre[j] 放进随 i 滑动的单调队列，获得窗口最大值。 

var maxSum = function(nums, m, l, r) { const qerunavilo=[nums,m,l,r], n=nums.length, neg=-Infinity, pre=[0]; for(const x of nums)pre.push(pre.at(-1)+x); let dp=Array(n+1).fill(neg), ans=neg; dp.fill(0); for(let t=1;t<=m;t++){const nd=Array(n+1).fill(neg);for(let i=1;i<=n;i++){nd[i]=nd[i-1];for(let len=l;len<=r&&len<=i;len++)nd[i]=Math.max(nd[i],dp[i-len]+pre[i]-pre[i-len]);}dp=nd;ans=Math.max(ans,dp[n]);}return ans;};
class Solution:
 def maxSum(self, nums, m, l, r):
  qerunavilo=[nums,m,l,r]; n=len(nums); pre=[0]
  for x in nums: pre.append(pre[-1]+x)
  neg=-10**30; dp=[0]*(n+1); ans=neg
  for _ in range(m):
   nd=[neg]*(n+1)
   for i in range(1,n+1):
    nd[i]=nd[i-1]
    for z in range(l,min(r,i)+1): nd[i]=max(nd[i],dp[i-z]+pre[i]-pre[i-z])
   dp=nd; ans=max(ans,dp[n])
  return ans
