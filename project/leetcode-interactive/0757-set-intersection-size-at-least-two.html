01 · Problem

题意与约束

给定二维整数数组 intervals，其中 intervals[i] = [startᵢ, endᵢ] 表示从 startᵢ 到 endᵢ 的所有整数，两个端点都包含在区间内。

我们要构造一个整数数组 nums：对输入中的每个区间，nums 中都至少有两个不同整数落在该区间内。返回这样的 nums 所能达到的最小元素个数。

换句话说：每个区间都需要被至少两个“选中点”覆盖；同一个选中点可以同时服务多个区间。

约束

  • 1 ≤ intervals.length ≤ 3000
  • intervals[i].length == 2
  • 0 ≤ startᵢ < endᵢ ≤ 10⁸

函数参数：intervals: integer[][]
返回：integer

05 · Solution

准备好揭晓最优策略了吗？

展开后将看到核心洞察、严格证明、复杂度、边界、替代方案、面试追问、常见错误与四种语言的完整实现。

Answer revealed

贪心：把新增点尽量放到右侧

核心洞察

按区间右端点从小到大处理；右端点相同时，让左端点更大的区间先处理。对当前区间 [l, r]，若必须补点，就选当前允许范围内尽量靠右的整数。

靠右的点已经满足当前区间，同时更可能落入尚未处理、右端点不小于 r 的区间。只需维护已选集合中最大的两个点 second < last，就能判断当前区间已有 0、1 或至少 2 个命中。

排序细节

使用 end ↑, start ↓。相同右端点下，先满足更“紧”的区间，能保证后处理的宽区间自然继承这些点。

完整过程

  1. 将所有区间按右端点升序排序；右端点相同则按左端点降序。
  2. 令 second、last 表示当前已选集合中最大的两个点，初始均为 -1；答案 answer = 0。
  3. 遍历当前区间 [l, r]：
    • 若 l > last，当前区间没有已选点：新增 r - 1 和 r，答案加 2。
    • 否则若 l > second，当前区间恰有一个已选点 last：新增 r，答案加 1，并更新两个最大点。
    • 否则，second 与 last 都位于当前区间，不做修改。
  4. 遍历结束后返回 answer。

正确性证明

引理：处理当前区间时，若必须补一个或两个点，把它们放在可选位置的最右侧，不会比任意最优解更差。

设某个可行最优解为当前区间选了更靠左的补点。把这些补点向右替换为算法选择的 r（以及需要两个点时的 r-1）。当前区间仍被覆盖。由于后续区间的右端点都不小于 r，且所有待替换点不会比新点更靠右，凡是后续区间能使用旧补点的位置，都可通过选择当前最右补点得到不劣的覆盖；相同右端点下先处理左端点更大的区间保证这一替换仍落在后续较宽区间内。

归纳：假设处理前若干区间后，算法的选择能扩展成一个全局最优解。对下一个区间，若已有两个点则无需新增；否则由引理，可把某个最优解需要补的点替换为算法的最右选择，而不增加点数。归纳成立。最终所有区间均至少被命中两次，且点数最少。

复杂度与边界

  • 时间复杂度：O(n log n)，排序占主导；扫描为 O(n)。
  • 额外空间：若忽略排序实现所需空间，扫描阶段为 O(1)。
  • 最短合法区间：当 r = l + 1 时，新增 r-1 与 r 正好是两个不同整数。
  • 端点可为 0：初始化为 -1 安全，因为所有左端点均非负。
  • 重复或嵌套区间：排序规则仍然适用，已覆盖时不会重复计数。
  • 大端点：10⁸ 在四种语言的常用整数范围内。

替代方案

可以维护完整有序集合，并为每个区间统计命中数，再补最右点。思路直观，但需要平衡树或额外扫描，常数和实现复杂度都更高。只维护最大的两个已选点，是利用了“每个区间只要求两个点”这一特性。

面试追问

  • 如果每个区间要求至少 k 个点，如何推广？
  • 为什么相同右端点必须按左端点降序？
  • 若区间是开区间或实数区间，策略需怎样变化？
  • 如何返回具体的最小集合，而不仅是大小？

常见错误

  • 相同右端点仍按左端点升序。
  • 缺两个点时误选 l、l+1，降低复用机会。
  • 恰缺一个点时没有正确移动 second = last。
  • 只统计交叠区间数量，没有统计集合中不同整数。

四语言完整实现

import java.util.Arrays;

class Solution {
    public int intersectionSizeTwo(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> {
            if (a[1] != b[1]) {
                return Integer.compare(a[1], b[1]);
            }
            return Integer.compare(b[0], a[0]);
        });

        int second = -1;
        int last = -1;
        int answer = 0;

        for (int[] interval : intervals) {
            int left = interval[0];
            int right = interval[1];

            if (left > last) {
                second = right - 1;
                last = right;
                answer += 2;
            } else if (left > second) {
                second = last;
                last = right;
                answer += 1;
            }
        }

        return answer;
    }
}
