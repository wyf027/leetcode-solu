交替合并字符串
Merge Strings Alternately

两条字符轨道轮流向前一步：先取 word1，再取 word2；某条轨道结束后，另一条继续抵达终点。

#1768EASYTwo PointersString
01 / PROBLEM

题目要求

给定两个仅含小写英文字母的字符串 word1 和 word2。从 word1 开始，依次交替取出两个字符串中的字符，组成一个新字符串。

如果其中一个字符串先被取完，就把另一个字符串尚未取出的字符按原顺序追加到结果末尾。返回合并后的字符串。

函数形式： mergeAlternately(word1: string, word2: string) → string

约束

  • 1 <= word1.length, word2.length <= 100
  • word1 和 word2 均只包含小写英文字母。
示例 1 · 等长
输入：word1 = "abc", word2 = "pqr"
输出："apbqcr"
解释：a→p→b→q→c→r
示例 2 · word2 更长
输入：word1 = "ab", word2 = "pqrs"
输出："apbqrs"
解释：交替得到 apbq，再追加 rs
示例 3 · word1 更长
输入：word1 = "abcd", word2 = "pq"
输出："apbqcd"
解释：交替得到 apbq，再追加 cd

04 / DEEP DIVE

题解：一个下标，两次尝试

01 · CORE

核心洞察

同一轮的下标 i 对应两次候选追加：若 word1[i] 存在就追加，再判断 word2[i]。

02 · LOOP

完整过程

令循环次数等于两字符串最大长度。每轮保持先 word1、后 word2 的顺序，各自越界时跳过。

03 · RESULT

自然处理余量

较短字符串越界后，较长字符串的字符仍会在后续轮次被追加，无需单独拼接尾巴。

正确性证明

循环不变式：第 i 轮开始前，结果已按题目要求包含两个字符串下标小于 i 的全部字符，而且每个下标都保持先 word1 后 word2。

初始化：第 0 轮前结果为空，尚无应加入的字符，不变式成立。

保持：第 i 轮先在存在时加入 word1[i]，再在存在时加入 word2[i]，恰好补齐下标 i 应贡献的字符，同时不会越界，因此下轮前不变式继续成立。

终止：循环执行到最大长度后，两个字符串的每个合法下标都已处理。由不变式可知结果既保持交替顺序，也完整包含较长字符串的剩余字符，故算法正确。

时间复杂度
O(n + m)

每个输入字符恰好进入结果一次。

额外空间复杂度
O(n + m)

返回字符串需要这些空间；不计输出时，辅助空间为 O(1)。

边界情况

  • 两个字符串都只有一个字符：结果长度为 2。
  • 两个字符串等长：每轮都会追加两个字符。
  • word1 更长：后续轮次只追加 word1。
  • word2 更长：后续轮次只追加 word2。

替代方案

也可以维护两个独立指针并在 while (i < n || j < m) 中分别判断，语义直观；但两指针始终同步递增，本题用一个共享下标更简洁。还可以先处理公共前缀，再一次性追加剩余切片，不过会把逻辑拆成两段。

class Solution {
    public String mergeAlternately(String word1, String word2) {
        StringBuilder merged = new StringBuilder(
            word1.length() + word2.length()
        );
        int limit = Math.max(word1.length(), word2.length());

        for (int i = 0; i < limit; i++) {
            if (i < word1.length()) {
                merged.append(word1.charAt(i));
            }
            if (i < word2.length()) {
                merged.append(word2.charAt(i));
            }
        }
        return merged.toString();
    }
}

var mergeAlternately = function(word1, word2) {
    const merged = [];
    const limit = Math.max(word1.length, word2.length);

    for (let i = 0; i < limit; i++) {
        if (i < word1.length) merged.push(word1[i]);
        if (i < word2.length) merged.push(word2[i]);
    }
    return merged.join("");
};

public:
    string mergeAlternately(string word1, string word2) {
        string merged;
        merged.reserve(word1.size() + word2.size());
        const int limit = max(word1.size(), word2.size());

            if (i < word1.size()) merged.push_back(word1[i]);
            if (i < word2.size()) merged.push_back(word2[i]);

COMMON MISTAKES

常见错误

  • 循环只到较短长度，漏掉剩余字符。
  • 每轮先加入 word2，违反起始顺序。
  • 条件写成 &&，任一耗尽就提前停止。
  • 在循环中频繁创建临时字符串。
