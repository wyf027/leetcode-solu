LEETCODE / 1824 / 三跑道挑战

最少侧跳次数

Minimum Sideway Jumps MEDIUM

沿路前进不计次数，换道才计一次。先理解规则，再展开解题实验室。

题意

道路有三条跑道与编号 0 到 n 的 n + 1 个位置。青蛙从位置 0 的跑道 2 出发，目标是到达位置 n 的任意跑道。参数 obstacles 是整数数组：obstacles[i] = k 表示位置 i 的跑道 k 有障碍，0 表示此位置没有障碍；每个位置最多一个障碍。

  • 前进：只能沿当前跑道从 i 到 i + 1，且落点不能有障碍。
  • 侧跳：位置不变，跳到任意另一条无障碍跑道，计 1 次。跑道 1 和 3 之间也只需一次，允许越过中间跑道的障碍。
  • 位置 0 和 n 都没有障碍。返回所需的最少侧跳次数。

约束

  • obstacles.length == n + 1
  • 1 ≤ n ≤ 5 × 10⁵
  • 0 ≤ obstacles[i] ≤ 3
  • obstacles[0] == obstacles[n] == 0

题解 · 三个数，逐列推进

核心洞察：不用挑选一条路径并反复后悔。同时维护到当前位置三条跑道的最小侧跳次数，就保留了未来可能需要的全部选择。

交互：先封路，再换道

每个位置拆为两帧：① 前进并把受阻跑道置为 ∞；② 在当前位置用一次侧跳松弛其他跑道。卡片数字是各自路径的最优代价，并不代表三只青蛙。蓝框标记当前列，× 是障碍。

状态与完整过程

dp[j] 表示到达当前位置、位于跑道 j + 1 时的最少侧跳次数，包含在当前位置完成的侧跳。起点为 [1, 0, 1]：跑道 2 不需侧跳，另外两条各需一次。

  1. 依次处理位置 i = 1…n。若该位置有障碍，先把对应 dp 设为 ∞。其余值代表沿跑道前进的代价。
  2. 固定 best = min(dp)，它是当前列可以站立的最小代价。
  3. 对无障碍跑道 j 更新 dp[j] = min(dp[j], best + 1)。要么保持原路线，要么从最便宜的跑道侧跳一次。
  4. 终点可以落在任意跑道，所以返回 min(dp)。

示例 1 每列完成换道后的状态依次为 [1,0,1] → [∞,0,1] → [2,∞,1] → [2,3,∞] → [2,3,3]，答案为 2。

为什么正确

归纳不变式：处理完位置 i 后，每个 dp 都是到达该位置对应跑道的最优代价。起点初始化符合定义。进入新位置时，只能从上一位置的同一跑道前进，因此无障碍跑道继承旧值，有障碍跑道不可达。之后的侧跳可以直接到任意无障碍跑道，连续两次或更多次侧跳不会优于直接跳一次。因此，最优路径要么不侧跳，要么从当前最小代价的可达跑道侧跳一次，更新式穷尽所有有效选择。即使 best 来自目标跑道，best + 1 也不会改善原值。更新后不变式成立，最终三条跑道取最小值即为答案。

边界与复杂度

  • n = 1 或跑道 2 始终畅通：答案为 0。
  • 第一个非起点位置挡住跑道 2：必须在位置 0 侧跳，初始两侧的 1 已覆盖这一情况。
  • 每列最多一个障碍，始终至少有两条可用跑道，因此至少存在一条路线。
  • 时间 O(n)，额外空间 O(1)。演示保存所有帧，空间 O(n)，不是提交算法的空间消耗。
  • 有限哨兵选 10⁹，远大于最多 O(n) 次侧跳；加 1 不会造成 32 位整数溢出。

替代方案

可以保存完整 dp[i][lane] 表，用 O(n) 空间记录状态与前驱，便于还原路径。也可以把位置和跑道视为顶点，前进边权 0、侧跳边权 1，使用 0-1 BFS，时间与空间都是 O(n)，但本题按位置递推更直接。贪心也可在被迫换道时选择下一障碍更远的跑道，需要额外的交换论证与谨慎的扫描实现。

常见错误

  • 先求 best 再封障碍：会让不可达跑道参与转移。
  • 只初始化跑道 2 而不给起点换道机会：漏掉提前侧跳。
  • 把跑道 1 到 3 算成两次：侧跳不要求相邻。
  • 把前进计为跳数，或只返回终点跑道 2 的代价。
  • 遇到下一列障碍才在该障碍格换道：不能站到障碍上，必须保留此前的其他状态。

面试追问

如何输出路线？保存每个状态的前驱，终点选最小值再回溯。若侧跳只允许相邻跑道？一次 best + 1 不再有效，需要按跑道邻接关系计算转移。若有 k 条跑道且任意换道代价都是 1？每列取最小值后统一松弛，时间 O(nk)、空间 O(k)。若侧跳代价不相同？应根据边权结构采用更一般的最短路或列内转移。

Java

class Solution {
    public int minSideJumps(int[] obstacles) {
        final int INF = 1_000_000_000;
        int[] dp = {1, 0, 1};
        for (int i = 1; i < obstacles.length; i++) {
            int blocked = obstacles[i] - 1;
            if (blocked >= 0) dp[blocked] = INF;
            int best = Math.min(dp[0], Math.min(dp[1], dp[2]));
            for (int j = 0; j < 3; j++) {
                if (j != blocked) dp[j] = Math.min(dp[j], best + 1);
            }
        }
        return Math.min(dp[0], Math.min(dp[1], dp[2]));
    }
}

from typing import List

class Solution:
    def minSideJumps(self, obstacles: List[int]) -> int:
        dp = [1, 0, 1]
        for i in range(1, len(obstacles)):
            blocked = obstacles[i] - 1
            if blocked >= 0:
                dp[blocked] = 10**9
            best = min(dp)
            for j in range(3):
                if j != blocked:
                    dp[j] = min(dp[j], best + 1)
        return min(dp)

class Solution {

    int minSideJumps(vector<int>& obstacles) {
        const int INF = 1000000000;
        int dp[3] = {1, 0, 1};
        for (int i = 1; i < (int)obstacles.size(); ++i) {
            int blocked = obstacles[i] - 1;
            if (blocked >= 0) dp[blocked] = INF;

            for (int j = 0; j < 3; ++j) {
                if (j != blocked) dp[j] = min(dp[j], best + 1);
            }
        }
        return min({dp[0], dp[1], dp[2]});
    }
};
