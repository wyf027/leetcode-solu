Problem

题目描述

给你一个整数数组 arr。如果一个数列中，任意相邻两项的差都等于同一个常数，那么它就是等差数列。

你可以任意重新排列数组元素。若存在一种排列能够形成等差数列，返回 true；否则返回 false。

函数参数与返回值

canMakeArithmeticProgression(arr: integer[]) -> boolean

示例 1

输入：arr = [3,5,1]
输出：true
解释：可重排为 [1,3,5] 或 [5,3,1]，相邻差分别恒为 2 或 -2。

示例 2

输入：arr = [1,2,4]
输出：false
解释：不存在一种重排方式能得到等差数列。

约束

2 <= arr.length <= 1000
-106 <= arr[i] <= 106

Full Solution

排序后，相邻差必须全部一致

核心洞察

如果一组数能组成等差数列，那么把它们按升序排列后也必然是一个公差非负的等差数列。升序排列把所有可能的重排压缩成唯一的规范顺序，因此只需检查这个顺序中每一对相邻元素的差。

完整过程

  1. 将 arr 按数值升序排序。
  2. 用前两项确定候选公差 d = arr[1] - arr[0]。
  3. 从下标 2 开始，检查 arr[i] - arr[i-1] 是否等于 d。
  4. 只要出现一次不相等就返回 false；全部一致则返回 true。

边界情况

  • 只有两个元素时，总能形成等差数列。
  • 所有元素相同，公差为 0，结果为 true。
  • 负数、0、正数可以混合；排序与减法逻辑不变。
  • 重复元素若不是全部按公差 0 排列，通常会产生不一致的相邻差。

正确性证明

  1. 必要性：假设原数组能重排为公差为 d 的等差数列。若 d < 0，把该数列反转即可得到公差 -d > 0 的升序数列；若 d = 0，各项相等。于是数组的升序结果相邻差必然全部相同。
  2. 充分性：算法在升序数组中验证每个相邻差都等于同一个 d。因此该升序数组本身就满足等差数列定义，也就是原数组的一种合法重排。
  3. 结论：算法返回 true 当且仅当数组能够重新排列成等差数列。
时间复杂度O(n log n)排序主导；扫描为 O(n)
空间复杂度O(log n) 或 O(n)取决于语言排序实现；不计排序栈时可视为 O(1) 额外变量

替代方案：O(n) 哈希定位

先求最小值、最大值。若 (max-min) 不能被 n-1 整除，则不可能；否则公差确定为 d，再验证每个数是否恰好落在 min + k*d 的位置并且不重复。它能做到 O(n) 时间与 O(n) 空间，但需要谨慎处理 d = 0、整除和重复位置。对于本题最多 1000 个元素，排序法更短、更稳、更适合面试表达。

四语言完整代码

Java · 官方可提交形式
import java.util.Arrays;

class Solution {
    public boolean canMakeArithmeticProgression(int[] arr) {
        Arrays.sort(arr);
        int difference = arr[1] - arr[0];

        for (int i = 2; i < arr.length; i++) {
            if (arr[i] - arr[i - 1] != difference) {
                return false;
            }
        }
        return true;
    }
}

/**
 * @param {number[]} arr
 * @return {boolean}

var canMakeArithmeticProgression = function(arr) {
    arr.sort((a, b) => a - b);
    const difference = arr[1] - arr[0];

    for (let i = 2; i < arr.length; i++) {
        if (arr[i] - arr[i - 1] !== difference) {
            return false;
        }
    }
    return true;
};

from typing import List


class Solution:
    def canMakeArithmeticProgression(self, arr: List[int]) -> bool:
        arr.sort()
        difference = arr[1] - arr[0]

        for i in range(2, len(arr)):
            if arr[i] - arr[i - 1] != difference:

        return True
C++ · 官方可提交形式
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    bool canMakeArithmeticProgression(vector<int>& arr) {
        sort(arr.begin(), arr.end());
        int difference = arr[1] - arr[0];

        for (int i = 2; i < static_cast<int>(arr.size()); ++i) {
            if (arr[i] - arr[i - 1] != difference) {
                return false;
            }
        }
        return true;
    }
};

常见错误

  • JavaScript 使用默认 sort()，导致按字符串字典序排序；必须传入 (a,b) => a-b。
  • 只比较最大值和最小值，忽略中间元素可能破坏等差关系。
  • 排序后只检查一两段差，没有扫描全部相邻对。
  • 误认为数组原顺序必须已经是等差数列，忘记题目允许重排。

面试追问

能否做到 O(n) 时间？
可以。用最小值、最大值推导公差，再用哈希集合验证所有理论位置；代价是 O(n) 空间和更多边界处理。
为什么排序后的顺序足够？
任何公差不为 0 的等差数列都是严格单调的；按升序规范化后，合法排列只有这一种数值顺序。公差为 0 时所有值相等，升序同样成立。
如果输入可能溢出怎么办？
本题数值范围使 32 位整数减法安全。若范围扩大，Java/C++ 中应先提升到 64 位再计算差。
