Unique Length-3 Palindromic Subsequences

先读题、尝试构造，再展开推导。相同的字符序列，无论选了哪几个下标，都只算一次。

01 / THE CHALLENGE

题目与输入输出

给定字符串 s，统计其中能作为子序列出现的、长度恰好为 3 的不同回文字符串数量，返回一个整数。

回文从左往右和从右往左读相同。子序列允许删除字符，但必须保留所选字符在原串中的先后顺序，不要求连续。例如 ace 是 abcde 的子序列。

  • 相同字符串只计数一次；下标选择不同并不会产生新的答案。
  • 参数：s: string；返回值：integer。
  • 约束：3 ≤ s.length ≤ 10⁵。
  • s 只包含小写英文字母 a–z。

输出：3

示例 3

04 / EXPLAINED

准备好看推导了吗？

展开后可使用逐步演示，并阅读四语言实现。

核心洞察：固定两端，收集中间

长度为 3 的回文只能是 x y x。它由外侧字符 x 和中间字符 y 唯一确定，因此最多有 26 × 26 = 676 种。

固定 x，只需找到它第一次出现的位置 L 和最后一次出现的位置 R。在严格开区间 (L, R) 内，每一种不同字符 y 都贡献一个回文。把 26 个外侧字符的贡献相加即可。

完整过程

  1. 枚举外侧字符 x = a…z，查找首次位置 L 与末次位置 R。
  2. 若字符不存在，或 R - L < 2，该组无合法中间位置，跳过。
  3. 创建空集合，只扫描 L + 1 到 R - 1，将遇到的字符加入集合。
  4. 将集合大小累加到答案。换一个外侧字符时重新创建集合。
  5. 所有外侧字符处理完成后返回答案。

例如 aabca 的外侧字符为 a 时，端点是 0 和 4，中间字符依次为 a、b、c，得到 aaa、aba、aca；其余外侧字符不能提供两个有效端点。

正确性说明

可靠性：每个被收集的字符 y 都有位置 L < j < R，而两端字符均为 x，所以对应的 xyx 一定是合法回文子序列。

完备性：若存在合法回文的下标 i < j < k 且两端为 x，则首次位置 L ≤ i、末次位置 R ≥ k，于是 L < j < R。它的中间字符必被扫描到。

唯一性：同一组中用集合消除重复的 y；不同组的外侧字符不同，得到的回文也不同。因此每个合法的不同回文恰好计数一次。

边界与复杂度

  • 只出现一次的字符、两个相邻的相同字符，都没有有效中间位置。
  • 允许 x = y，但至少需要三个不同位置，例如 aaa。
  • 大量重复字符仍只贡献不同序列，不是下标组合数。
  • 时间 O(26n)，固定 26 字母时为 O(n)。每个字母的首尾查找与内部扫描都是线性的。
  • 额外空间 O(26)，固定字母表时为 O(1)。以下代码逐字符加入集合，不创建长度为 n 的子串。演示保存步骤快照的空间不属于提交算法。

替代方案

按中间位置枚举：维护左侧出现集合和右侧字符计数，寻找两侧都存在的字符，把 (外侧字符, 中间字符) 放入全局集合去重。时间同为 O(26n)，需要维护更多状态，也可用 26 位掩码加速。

三重循环枚举下标的暴力法是 O(n³)，只适合非常短的字符串。为 26 个字母建立前缀计数也能查询端点间是否存在某字符，但会消耗 O(26n) 空间，本题单次统计无需这样做。

常见错误

  • 误把子序列当作连续子串，只检查长度为 3 的窗口。
  • 统计合法下标三元组，导致同一个回文重复计数。
  • 把端点包含在中间范围内，使 aab 被错算。
  • 只用前两次出现的位置，遗漏更远端点之间的中间字符。
  • 换外侧字符时没有清空集合，或禁止中间字符与端点相同。

面试追问

  • 为什么最外端点足够？任意有效端点之间的中间位置，都被最外端点的开区间包含。
  • 如何列出回文？扫描集合中的每个 y，构造 xyx；结果最多 676 项。
  • 字母表扩大怎么办？若有 σ 个不同字符，本方法时间为 O(σn)、集合空间为 O(σ)；大字母表时需重新评估复杂度。
  • 长度改成 5 呢？内部需要计数不同的长度 3 回文，单个字符集合不再足够，不能直接套用本算法。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int countPalindromicSubsequence(String s) {
        int answer = 0;
        for (char x = 'a'; x <= 'z'; x++) {
            int left = s.indexOf(x);
            int right = s.lastIndexOf(x);
            if (left == -1 || right - left < 2) continue;
            Set<Character> middle = new HashSet<>();
            for (int i = left + 1; i < right; i++) {
                middle.add(s.charAt(i));
            }
            answer += middle.size();
        }
        return answer;
    }
}

        const x = String.fromCharCode(97 + c);
        const left = s.indexOf(x);

        answer += middle.size;
    }
    return answer;
};

class Solution:
    def countPalindromicSubsequence(self, s: str) -> int:
        answer = 0
        for x in "abcdefghijklmnopqrstuvwxyz":
            left = s.find(x)
            right = s.rfind(x)
            if left == -1 or right - left < 2:
                continue
            middle = set()
            for i in range(left + 1, right):
                middle.add(s[i])
            answer += len(middle)
        return answer

C++

#include <string>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int countPalindromicSubsequence(string s) {
        int answer = 0;
        for (char x = 'a'; x <= 'z'; ++x) {
            auto left = s.find(x);
            if (left == string::npos) continue;
            auto right = s.rfind(x);
            if (right - left < 2) continue;
            unordered_set<char> middle;
            for (size_t i = left + 1; i < right; ++i) {
                middle.insert(s[i]);
            }
            answer += static_cast<int>(middle.size());
        }
        return answer;
    }
};
