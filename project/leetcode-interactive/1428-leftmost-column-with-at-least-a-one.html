Top-right staircase walk

至少有一个 1 的
最左端列

从右上角出发：看到 1 就向左压缩答案，看到 0 就向下跳过整行。每次查询都淘汰一行或一列。

Problem

题目转述

给定一个只能通过接口访问的二进制矩阵 BinaryMatrix。矩阵每一行都按非递减顺序排列，也就是若一行含有 1，那么所有 1 都位于这一行的右侧。

接口提供 get(row, col) 读取单元格，以及 dimensions() 获得 [rows, cols]。请返回至少包含一个 1 的最左列下标；若矩阵中没有 1，返回 -1。算法应控制接口查询次数。

官方示例（完整参数形式）

输入：BinaryMatrix = [[0,0],[1,1]]
输出：0
解释：第 0 列含有 1，且已经是最左列。
输入：BinaryMatrix = [[0,0],[0,1]]
输出：1
解释：只有第 1 列含有 1。
输入：BinaryMatrix = [[0,0],[0,0]]
输出：-1
解释：矩阵中不存在 1。

约束与接口

  • 1 <= rows, cols <= 100
  • BinaryMatrix.get(row, col) 的返回值为 0 或 1
  • 每一行均按非递减顺序排列
  • 提交答案通常不得调用 get 超过 1000 次
  • 只实现 leftMostColumnWithOne(BinaryMatrix binaryMatrix)，无需实现平台提供的接口

完整题解

Full solution

把搜索空间走成一条阶梯

核心洞察

站在右上角 (0, cols - 1)：若值为 0，则当前行左侧全为 0，可以整行排除并下移；若值为 1，则当前列可作为答案，并继续左移寻找更小列号。

完整过程

  1. 读取矩阵尺寸，令 row = 0、col = cols - 1。
  2. 当坐标仍在矩阵内，查询当前位置。
  3. 读到 1：记录 col 并左移；读到 0：下移。
  4. 越界后返回最后记录的列号；从未记录则返回 -1。

正确性证明

循环不变式：每一步开始时，当前坐标右上方之外被排除的区域不可能包含比候选值更优的答案。

读到 0 时，行有序性说明其左侧也全为 0，因此下移不会漏解。读到 1 时，当前列确实含 1，故可更新答案；继续左移是唯一可能找到更小列号的方向。循环结束时，要么越过最后一行且所有剩余行已排除，要么越过最左列且已经找到第 0 列。因此返回值恰为最左含 1 的列，或在不存在 1 时为 -1。

复杂度与边界

指针最多向下 rows 次、向左 cols 次，因此查询次数与时间复杂度均为 O(rows + cols)；额外空间为 O(1)。

全零矩阵会一路向下并返回 -1；全一矩阵会一路向左并返回 0；单行、单列同样由循环边界自然覆盖。

替代方案

可以对每一行二分查找第一个 1，再取最小列号，时间为 O(rows · log cols)、空间为 O(1)。它容易想到，但没有利用跨行共享的“当前最优列界限”，查询次数通常多于阶梯搜索。

四语言完整代码

/**
 * // This is the BinaryMatrix's API interface.
 * // You should not implement it, or speculate about its implementation.
 * interface BinaryMatrix {
 *     public int get(int row, int col);
 *     public List<Integer> dimensions();
 * }
 */

class Solution {
    public int leftMostColumnWithOne(BinaryMatrix binaryMatrix) {
        List<Integer> size = binaryMatrix.dimensions();
        int rows = size.get(0);
        int cols = size.get(1);
        int row = 0;
        int col = cols - 1;
        int answer = -1;

        while (row < rows && col >= 0) {
            if (binaryMatrix.get(row, col) == 1) {
                answer = col;
                col--;
            } else {
                row++;
            }
        }
        return answer;
    }
}

/**
 * @param {BinaryMatrix} binaryMatrix

 */
var leftMostColumnWithOne = function(binaryMatrix) {
    const [rows, cols] = binaryMatrix.dimensions();
    let row = 0;
    let col = cols - 1;
    let answer = -1;

    while (row < rows && col >= 0) {
        if (binaryMatrix.get(row, col) === 1) {
            answer = col;
            col -= 1;
        } else {
            row += 1;
        }
    }
    return answer;
};

面试追问

  • 为什么必须从右上角或左下角开始，而不是左上角？
  • 若每列也有序，能否进一步利用这一性质？
  • 若接口调用代价远高于本地计算，二分与阶梯法如何比较？
  • 如何证明查询次数严格不超过 rows + cols？

常见错误

  • 把 dimensions() 的行列顺序写反。
  • 读到 1 后只更新答案却没有左移，造成死循环。
  • 读到 0 时左移，错误排除仍可能含 1 的其他行。
  • 没有保存候选答案，越过左边界后错误返回 -1。
  • 直接访问底层矩阵，违背交互题接口约束。
