猴子碰撞的方法数

一圈顶点、每点一只猴子、一次同步移动。先观察碰撞如何发生，再决定怎样统计所有可能。

01 / Problem

题目说明

一个正凸 n 边形的顶点按顺时针编号为 0 到 n - 1，每个顶点恰有一只猴子。所有猴子同时且只移动一次：顶点 i 上的猴子可以前往顺时针相邻点 (i + 1) % n，也可以前往逆时针相邻点 (i - 1 + n) % n。

若移动后至少两只猴子位于同一顶点，或两只猴子在同一条边上相交，就算发生碰撞。请返回至少发生一次碰撞的移动方案数，并对 10⁹ + 7 取模。

示例 1

输入：n = 3
输出：6
解释：总共有 8 种移动方式，其中 6 种至少发生一次碰撞。

示例 2

输入：n = 4
输出：14
解释：可以证明，共有 14 种会发生碰撞的移动方式。
约束：3 <= n <= 10⁹。参数形式为 monkeyMove(n: integer) -> integer。

Revealed / Full Solution

补集计数 + 快速幂

核心洞察

  1. 每只猴子只有顺时针或逆时针两种选择，因此所有移动方案共有 2ⁿ 种。
  2. 不发生碰撞的方案只有两种：所有猴子都顺时针，或所有猴子都逆时针；此时队形只是整体旋转一格。
  3. 所以答案是 (2ⁿ - 2) mod (10⁹ + 7)。指数最大为 10⁹，必须用二进制快速幂。

完整过程

① 数全集

每个顶点独立二选一，乘法原理得到 2ⁿ。

② 数补集

只需排除两个完全同向、不会碰撞的方案。

③ 快速取模

不断平方底数、折半指数，在对数轮次内算出幂。

正确性证明

引理 1：两种全同向方案都不会碰撞。所有猴子分别整体顺时针或逆时针平移一格，每个目的顶点仍只有一只猴子，且同一条边上的运动方向一致。

引理 2：任意非全同向方案都会碰撞。把每个顶点的选择视为环形二进制序列；只要序列中两种方向都出现，沿环必能找到一对相邻顶点，其左侧猴子顺时针、右侧猴子逆时针。两只猴子会沿它们之间的同一条边相向移动并相交。

结论：由引理 1 和引理 2，不碰撞方案恰好有 2 种。所有 2ⁿ 种方案减去这 2 种，算法返回的就是至少发生一次碰撞的方案数；取模不改变模意义下的结果。

边界与复杂度

  • n = 3：最小多边形，结果为 8 - 2 = 6。
  • 减法前加一次模数，避免某些语言产生负余数。
  • 时间复杂度 O(log n)；额外空间复杂度 O(1)。

四种语言完整代码

class Solution {
    private static final long MOD = 1_000_000_007L;

    public int monkeyMove(int n) {
        long base = 2;
        long result = 1;
        int exponent = n;

        while (exponent > 0) {
            if ((exponent & 1) == 1) {
                result = result * base % MOD;
            }
            base = base * base % MOD;
            exponent >>= 1;
        }

        return (int) ((result - 2 + MOD) % MOD);
    }
}

 * @param {number} n
 * @return {number}
 */
var monkeyMove = function(n) {
    const MOD = 1000000007n;
    let base = 2n;
    let exponent = BigInt(n);
    let result = 1n;

    while (exponent > 0n) {
        if (exponent & 1n) result = result * base % MOD;
        base = base * base % MOD;
        exponent >>= 1n;
    }

    return Number((result - 2n + MOD) % MOD);
};

public:
    int monkeyMove(int n) {
        constexpr long long MOD = 1'000'000'007;
        long long base = 2;
        long long result = 1;

        while (n > 0) {
            if (n & 1) result = result * base % MOD;
            base = base * base % MOD;
            n >>= 1;

替代方案

快速幂也可以递归实现：根据指数奇偶，把问题缩小为一半指数。但迭代版只维护三个变量，没有递归栈，更直接。逐个枚举 2ⁿ 种移动方案只适用于极小输入，无法满足本题约束。

面试追问

为什么混合方向一定碰撞？

因为环形方向序列中只要同时存在两种值，就必有一次从顺时针到逆时针的相邻过渡，这对猴子会在公共边上相向而行。

如果每只猴子可以不动呢？

安全方案结构会改变，不能再直接减 2；需要重新刻画局部冲突并对环做状态计数。

为何 JavaScript 使用 BigInt？

乘法中间值可能超过 Number 的安全整数范围；BigInt 能保证模乘精确。

能否直接调用幂函数？

只有支持“带模快速幂”的接口才合适，例如 Python 的三参数 pow。

常见错误

  • 只检查移动后的顶点是否重合，漏掉两只猴子在边上交换位置时的相交。
  • 先计算普通的 2 ** n 再取模，导致溢出或超大整数开销。
  • 直接写 (power - 2) % MOD，却忽略部分语言的负余数语义。
  • 把“不碰撞”误认为有多种交错排列；任何混合方向都会在某个方向边界产生相向移动。
