面试题 01.03 简单 · 字符串 · 双指针

IN-PLACE ENCODING BENCH

URL化

从字符串的尾部倒着写：每遇到一个空格，就一次性腾出三个位置并写入 %20。

本题核心

读指针不踩写指针

先统计空格，再让读、写两个指针从右向左移动。

题意

把真实内容里的空格改成 %20

给定字符串 S 与它的真实长度 length。字符串尾部预留了足够的空位；只处理前 length 个字符，返回替换所有空格后的字符串。

示例 1

S = "Mr␠John␠Smith␠␠␠␠"
length = 13
输出："Mr%20John%20Smith"

示例 2

S = "␠␠␠␠␠␠␠␠␠␠␠␠␠␠␠"
length = 5
输出："%20%20%20%20%20"

说明：␠ 是可见空格符，便于区分真实内容与尾部预留空间。字符串长度范围为 [0, 500000]。

读图方式

一条“倒车”路线

  1. ① 数空格。结果长度 = length + 2 × 空格数。
  2. ② 读指针 i。从真实末尾 length - 1 出发。
  3. ③ 写指针 j。从新字符串末尾出发，永远不覆盖尚未读取的字符。

为什么不从前往后？

空格会扩成 3 个字符，前向原地写入会不断搬移后缀；反向写则每个字符只处理一次。

核心洞察

设真实字符串有 spaces 个空格，最终长度为 length + 2 × spaces。从右向左读取 i：普通字符写到 j；空格则倒序写 0、2、%。写位置永远在读位置右侧，不会污染未读取部分。

完整过程

  1. 扫描前 length 个字符，统计空格数。
  2. 创建或使用足够长的缓冲区，令 i = length - 1、j = length + 2 × spaces - 1。
  3. 当 i ≥ 0 时从右到左写入；空格扩展为 %20。

边界与复杂度

  • 空串：length = 0，返回空串。
  • 全空格：每个真实字符都扩展，不能误把尾部预留空间算入。
  • 无空格：最终长度不变，倒序复制仍正确。
  • 时间：O(length)；额外空间：字符数组原地写为 O(1)，返回字符串实现通常需输出缓冲 O(length)。

替代方案、追问与常见错

替代：语言有 replace 时可直接替换，但无法展示原地操作能力。
追问：如果预留空间不足？先计算新长度并分配更大数组。
常见错：扫描整个 S 而非前 length 个字符；从前向后原地挪动；写 %20 时顺序颠倒。

class Solution {
    public String replaceSpaces(String S, int length) {
        int spaces = 0;
        for (int i = 0; i < length; i++) {
            if (S.charAt(i) == ' ') spaces++;
        }
        char[] ans = new char[length + spaces * 2];
        int i = length - 1, j = ans.length - 1;
        while (i >= 0) {
            char c = S.charAt(i--);
            if (c == ' ') {
                ans[j--] = '0'; ans[j--] = '2'; ans[j--] = '%';
            } else {
                ans[j--] = c;
            }
        }
        return new String(ans);
    }
}

var replaceSpaces = function (S, length) {
  let spaces = 0;
  for (let i = 0; i < length; i++) if (S[i] === " ") spaces++;
  const ans = Array(length + spaces * 2);
  let i = length - 1, j = ans.length - 1;
  while (i >= 0) {
    if (S[i] === " ") {
      ans[j--] = "0";
      ans[j--] = "2";
      ans[j--] = "%";
    } else {
      ans[j--] = S[i];
    }
    i--;
  }
  return ans.join("");

class Solution:
    def replaceSpaces(self, S: str, length: int) -> str:
        spaces = sum(c == " " for c in S[:length])
        ans = [""] * (length + spaces * 2)
        i, j = length - 1, len(ans) - 1
        while i >= 0:
            if S[i] == " ":
                ans[j], ans[j - 1], ans[j - 2] = "0", "2", "%"
                j -= 3
            else:
                ans[j] = S[i]
                j -= 1
            i -= 1
        return "".join(ans)
class Solution {
public:
    string replaceSpaces(string S, int length) {
        int spaces = 0;
        for (int i = 0; i < length; ++i) spaces += S[i] == ' ';
        string ans(length + spaces * 2, ' ');
        int j = static_cast<int>(ans.size()) - 1;
        for (int i = length - 1; i >= 0; --i) {
            if (S[i] == ' ') ans[j--] = '0', ans[j--] = '2', ans[j--] = '%';
            else ans[j--] = S[i];
        }
        return ans;
    }
