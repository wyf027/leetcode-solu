题目

给定一个二进制字符串 s，统计其中所有字符均为 1 的连续子字符串数量。答案可能很大，返回结果对 109 + 7 取模后的值。

参数形式
numSub(s: string) → integer

约束

  • 1 ≤ s.length ≤ 105
  • s[i] 只可能是 '0' 或 '1'
  • 结果模数：1,000,000,007

题解：把连续长度直接加入答案

核心洞察

扫描到一个 1 时，若当前连续段长度变为 run，那么恰好新增 run 个以当前位置结尾的合法子串。它们的长度分别为 1..run。

扫描到 0 时，任何以它结尾的子串都不合法，因此令 run = 0。

完整过程

  1. 初始化 run = 0、answer = 0。
  2. 遇到 1 就递增 run；遇到 0 就清零。
  3. 把当前 run 加入答案，并及时取模。
  4. 扫描结束后返回答案。

正确性证明

循环不变量：处理完位置 i 后，run 等于以 i 结尾的全 1 子串数量，answer 等于前缀 s[0..i] 中全部全 1 子串数量。

保持：若 s[i] = 0，以它结尾的合法子串数为 0，清零正确；若 s[i] = 1，前一步的每个全 1 后缀都可追加当前字符，另有当前字符自身，所以数量从旧 run 变为 run + 1。把该数加入答案，正好计入所有且仅有以 i 结尾的新子串。

终止：每个合法子串都有唯一结束位置，因此扫描完所有位置后，它恰好被计数一次，算法返回值正确。

复杂度与边界

  • 时间复杂度：O(n)
  • 额外空间：O(1)
  • 全是 0：答案保持 0。
  • 全是 1：答案为 n(n+1)/2 后取模。
  • 长度可达 105，使用足够宽的整数并及时取模。

替代方案

也可以把字符串按 0 分成若干连续 1 段。长度为 k 的段贡献 k(k+1)/2。这个公式同样是线性的，但逐字符累加更自然，也避免乘法中间值带来的溢出顾虑。

四语言完整代码

Java · 官方提交签名
class Solution {
    public int numSub(String s) {
        final long MOD = 1_000_000_007L;
        long run = 0;
        long answer = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '1') {
                run++;
            } else {
                run = 0;
            }
            answer = (answer + run) % MOD;
        }
        return (int) answer;
    }
}
JavaScript · 官方提交签名
/**
 * @param {string} s
 * @return {number}
 */
var numSub = function(s) {
    const MOD = 1_000_000_007;
    let run = 0;
    let answer = 0;

    for (const char of s) {
        run = char === '1' ? run + 1 : 0;
        answer = (answer + run) % MOD;
    }
    return answer;
};

C++ · 官方提交签名
class Solution {
public:
    int numSub(string s) {
        static constexpr long long MOD = 1'000'000'007LL;
        long long run = 0;
        long long answer = 0;

        for (char c : s) {
            run = (c == '1') ? run + 1 : 0;
            answer = (answer + run) % MOD;
        }
        return static_cast<int>(answer);
    }
};

常见错误

  • 只统计连续 1 段的长度，漏掉更长子串。
  • 遇到 0 时忘记把连续长度清零。
  • 先计算所有结果、最后才取模，导致窄整数溢出。
  • 枚举每个子串，时间复杂度退化为 O(n²) 或更高。
