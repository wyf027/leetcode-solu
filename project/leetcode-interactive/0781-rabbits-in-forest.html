森林中的兔子

Rabbits in Forest · 从零散回答中，还原森林可能拥有的最小规模。

Problem

先理解问题，不急着看答案

森林里有数量未知的兔子。你询问了 n 只兔子，并把它们的回答记录为整数数组 answers。对第 i 只兔子而言，answers[i] 表示它看到的“除自己以外、与自己颜色相同的兔子数”。

给定 answers，返回与所有回答相容的森林兔子总数的最小值。

注意：并非森林中的每只兔子都接受了询问；不同颜色的兔子也可能给出相同数字。

函数契约

输入：answers: integer[]
输出：integer
函数：numRabbits(answers)

约束

  • 1 <= answers.length <= 1000
  • 0 <= answers[i] < 1000
官方示例 1
输入：answers = [1,1,2]
输出：5
解释：两只回答 1 的兔子可以同色；
回答 2 的兔子属于另一个至少有 3 只兔子的颜色组，
其中另有 2 只未被询问。因此最少为 2 + 3 = 5。
官方示例 2
输入：answers = [10,10,10]
输出：11

Solution · Spoiler

完整题解

先独立思考；需要时再展开贪心推导、证明与四种语言代码。

核心洞察

若一只兔子回答 x，它所在的颜色组总大小就必须是 x + 1。设回答 x 一共出现 c 次；同一颜色组最多容纳其中 x + 1 只，因此至少要开出若干个完整组。

贡献 = ceil(c / (x + 1)) × (x + 1)

对每种不同回答分别计算，再把贡献相加即可。为了让总数最小，每个组都尽量装满被询问的兔子。

完整过程

  1. 用哈希表统计每个回答值 x 的出现次数 c。
  2. 该回答对应的颜色组容量为 g = x + 1。
  3. 需要的组数是 (c + g - 1) / g 的向下取整，也就是 ceil(c / g)。
  4. 把“组数 × 每组容量”累加到答案。
示例：x = 2 表示每组必须有 3 只。若有 4 只兔子都回答 2，一个组装不下，必须开两个 3 只的颜色组，贡献为 6。

正确性证明

引理 1：回答 x 的兔子所在颜色组恰有 x + 1 只。因为回答只数不包含它自己。

引理 2：若回答 x 出现 c 次，至少需要 ceil(c / (x + 1)) 个对应颜色组。一个颜色组最多容纳 x + 1 个这样的已询问者，少于该组数便装不下全部 c 只。

可达性：把这些兔子依次放入上述数量的组，每组容量补足到 x + 1；缺少的位置由未被询问的同色兔子填入，即可满足全部回答。

结论：算法对每个回答值取得独立下界且能构造达到它的方案，求和后就是全局最小兔子数。

边界与复杂度

  • x = 0：颜色组大小为 1，每只回答 0 的兔子都单独贡献 1。
  • c 恰好整除 x + 1：没有补位兔子。
  • c < x + 1：仍必须计入一个完整颜色组。
  • 不同回答值一定不能属于同一个颜色组，必须分开计算。

时间复杂度：O(n)；空间复杂度：O(k)，其中 k 是不同回答值数量，且 k ≤ n。

替代方案：排序后分段

也可以先排序，再从左到右处理相同回答。每遇到一个尚未覆盖的回答 x，直接贡献 x + 1，并跳过接下来最多 x 个相同回答。

它只需常数级额外状态，但排序使时间复杂度变为 O(n log n)。哈希计数通常更直接。

面试追问与常见错误

  • 为何不能只算 x + 1？ 相同回答的数量可能超过一个颜色组容量。
  • 为何同一个数字可对应多种颜色？ 回答只透露组大小，不透露真实颜色。
  • 错误：把贡献写成 c + x；这只适用于恰好一个组且会在跨组时失效。
  • 错误：使用普通除法后截断，漏掉最后未装满但必须完整计数的组。
  • 追问：若要构造一种颜色分配，可在计数时为每组生成标识，并补齐匿名成员。

四种语言实现

Java · HashMap 计数LeetCode 可提交
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numRabbits(int[] answers) {
        Map<Integer, Integer> frequency = new HashMap<>();
        for (int answer : answers) {
            frequency.merge(answer, 1, Integer::sum);
        }

        int total = 0;
        for (Map.Entry<Integer, Integer> entry : frequency.entrySet()) {
            int groupSize = entry.getKey() + 1;
            int count = entry.getValue();
            int groups = (count + groupSize - 1) / groupSize;
            total += groups * groupSize;
        }
        return total;
    }
}
JavaScript · Map 计数LeetCode 可提交
/**
 * @param {number[]} answers
 * @return {number}
 */
var numRabbits = function(answers) {
    const frequency = new Map();
    for (const answer of answers) {
        frequency.set(answer, (frequency.get(answer) || 0) + 1);
    }

    let total = 0;
    for (const [answer, count] of frequency) {
        const groupSize = answer + 1;
        const groups = Math.ceil(count / groupSize);
        total += groups * groupSize;
    }
    return total;
};
Python · Counter 计数LeetCode 可提交
from collections import Counter
from typing import List


class Solution:
    def numRabbits(self, answers: List[int]) -> int:
        total = 0
        for answer, count in Counter(answers).items():
            group_size = answer + 1
            groups = (count + group_size - 1) // group_size
            total += groups * group_size
        return total
C++ · unordered_map 计数LeetCode 可提交
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int numRabbits(vector<int>& answers) {
        unordered_map<int, int> frequency;
        for (int answer : answers) {
            ++frequency[answer];
        }

        int total = 0;
        for (const auto& [answer, count] : frequency) {
            int groupSize = answer + 1;
            int groups = (count + groupSize - 1) / groupSize;
            total += groups * groupSize;
        }
        return total;
    }
};
