题目

给定一个非负整数 num，返回把它变成 0 所需的操作次数。每一步必须遵循：当前数字为偶数时除以 2；为奇数时减去 1。

示例 1

输入：num = 14
输出：6
解释：14 → 7 → 6 → 3 → 2 → 1 → 0

示例 2

输入：num = 8
输出：4
解释：8 → 4 → 2 → 1 → 0

示例 3

输入：num = 123
输出：12
约束：0 <= num <= 106。函数签名接收一个整数 num，返回整数步数。

完整题解

核心洞察

题目已经唯一决定了每个正数的下一状态，因此直接模拟即可：偶数右移一位（等价于除以 2），奇数减一。每次操作都会让数严格变小，最终一定到达 0。

完整过程

  1. 初始化计数器 steps = 0。
  2. 当 num > 0 时判断奇偶：偶数令 num /= 2，奇数令 num -= 1。
  3. 每次变换后将 steps 加一；循环结束后返回它。

正确性说明

循环不变式：每轮开始时，steps 等于从初始值到当前 num 已执行的合法操作数。初始时尚未操作，该命题成立。循环体严格按题意执行当前数唯一允许的操作，并把计数加一，因此不变式继续成立。由于正数经减一或除二后都会变小，循环最终在 num = 0 时终止；此时根据不变式，steps 正是把初始数字变为 0 所需的操作次数。

边界情况

  • num = 0：循环一次也不执行，返回 0。
  • num = 1：奇数减一，一步到 0。
  • 2 的幂：连续除二，最后从 1 减到 0。
  • 上界 10^6 很小；四种语言的普通整数类型都足够。

复杂度

数字的二进制位数每经过至多两次操作就减少一位，因此时间复杂度为 O(log num)；只使用常数个变量，空间复杂度为 O(1)。当 num = 0 时可视为常数时间。

替代方案：统计二进制位

对正数而言，每个二进制 1 最终需要一次减一；除最高位外，每跨过一个二进制位需要一次除二。因此答案也可写为 popcount(num) + bitLength(num) - 1。该方法同样是 O(log num)，但模拟更直接、更不易写错。

面试追问

  • 如何不用取模判断奇偶？检查 num & 1。
  • 为什么右移等价于除以 2？对非负整数，二进制右移一位会丢弃最低位，结果等于向下取整除以 2；偶数最低位为 0，所以恰好整除。
  • 能否 O(1) 得到答案？若机器提供固定宽度的位长与 popcount 指令，可以常数条机器指令组合；从一般算法模型看，读取有效二进制位仍按 O(log num) 描述。

常见错误

  • 把奇数也除以 2，或把偶数写成减一。
  • 先增加或遗漏步数，导致结果差 1。
  • 使用 while (num >= 0)，在 0 处无法结束。
  • 忽略输入 0，错误套用正数的位长公式。

四种语言实现

Java官方签名
class Solution {
    public int numberOfSteps(int num) {
        int steps = 0;
        while (num > 0) {
            if ((num & 1) == 0) {
                num /= 2;
            } else {
                num -= 1;
            }
            steps++;
        }
        return steps;
    }
}
