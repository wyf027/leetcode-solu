01 / 理解任务

选中一个 1，同时清除它所在的行和列

给你一个 m × n 的二进制矩阵 grid。每次操作选择一个当前值为 1 的位置 (i, j)，把第 i 行与第 j 列的所有格子设为 0。返回将矩阵中所有 1 清除所需的最少操作次数。

注意标题中的“翻转”：本题实际操作是行、列同时置零，不是 0 与 1 互换。不能选择值为 0 的交点。下标从 0 开始。

参数与返回值

removeOnes(grid: integer[][]) → integer

输入是一整个矩阵，返回最小操作数；没有 1 时返回 0。

官方约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 15
  • 1 ≤ m × n ≤ 15
  • grid[i][j] ∈ {0, 1}

官方示例

示例 1
输入：grid = [[1,1,1],[1,1,1],[0,1,0]]
输出：2

先选择 (1,1)，再选择 (0,0)，两次后全零。

示例 2
输入：grid = [[0,1,0],[1,0,1],[0,1,0]]
输出：2

选择 (1,0)，再选择 (2,1) 即可。中心 (1,1) 为 0，不能作为操作交点。

示例 3
输入：grid = [[0,0],[0,0]]
输出：0

矩阵已经全零，无须操作。

04 / 独立题解

准备好揭开解法了吗？

展开后可阅读推导、正确性与四种语言的完整实现。

位压缩 + 记忆化搜索

核心洞察

格子总数 K = m × n 最多只有 15。将每个格子的 0/1 状态存进整数的一位，就能用一个整数表示整个矩阵。任意历史，只要剩下的矩阵相同，后续最少操作数就相同，所以可以缓存结果。

从矩阵到状态

位置 (r,c) 对应第 p = r × n + c 位。初始状态 start 只在原矩阵为 1 的位置置位。预计算 clear[p]，它包含位置 p 所在行与列的所有位。选择一个当前为 1 的位置 p，转移为 next = state & ~clear[p]。

例如示例 1，按高位到低位打印，初始状态为 010111111。选 (1,1) 后变为 000000101，再选 (0,0) 后变成 000000000。实验台的金色十字正对应 clear[p]；零格子也在范围内，但不会变回 1。

完整过程与递推

  1. 扫描输入，建立初始状态，并为每个位置预计算清除掩码。
  2. 定义 dfs(state)：从该剩余状态到全零的最少操作数。
  3. 全零时 dfs(0) = 0；已求过的状态直接读取缓存。
  4. 枚举所有当前为 1 的位置 p，计算 1 + dfs(state & ~clear[p])。
  5. 取所有合法选择的最小值并缓存，返回 dfs(start)。

实验台的行优先自动选择仅演示合法转移；求最优时必须比较所有合法选择，不能把一条自动播放轨迹当作最优证明。

正确性证明

对 state 中 1 的个数归纳。没有 1 时，0 次操作显然最优。对非零 state，任意合法方案的第一步都必须选中一个当前为 1 的位置 p，而递推枚举了所有这类位置。掩码恰好清掉该行、该列，得到的 next 是真实操作结果，且至少减少一个 1。由归纳假设，dfs(next) 给出该分支的最优后续代价。因此取所有 1 + dfs(next) 的最小值，既不会漏掉最优方案，也不会计入非法方案。缓存仅复用相同状态，不改变结果。

边界与复杂度

全零返回 0；单格 1 返回 1；单行或单列只要存在 1 就返回 1；同一格的行列交点在掩码中按位或合并，不重复计数。输入 grid 不被修改。

预计算掩码耗时 O(K²)，状态最多 2ᴷ 个，每个状态扫描 K 个位置，总时间上界 O(K² + K·2ᴷ)，空间 O(2ᴷ + K)。递归深度至多 K；由于每步消除一个尚有 1 的行和列，也可收紧到 min(m,n)。这里的时间界是保守上界，许多状态不可达。JavaScript 的 32 位位运算足够容纳 15 位。

替代方案

BFS：从初始状态按操作数逐层搜索，每条边都是一次操作，第一次到达 0 的层数就是答案。用 visited 合并重复状态，时间和空间上界与此处相同；适合保存父节点并还原操作路径。原矩阵回溯：每次复制矩阵再递归，思路直观，但复制成本与重复状态更多。位压缩使状态复制、比较和缓存都更简单。

常见错误

  • 把置零写成异或，会错误地把 0 变成 1。
  • 按原始 grid 判断选点合法性；应按当前 state 判断。
  • 允许选中 0 的交点；示例 2 会因此被误算为 1 次。
  • 只枚举第一处 1 或直接选择清除最多的位置，没有最优性保证。
  • 使用 state | ~clear[p]，或将行、列当成两次操作。
  • 跨不同矩阵尺寸复用缓存：相同整数在不同列数下代表不同矩阵。

面试追问

  • 如何输出方案？缓存最优值时同时记录获胜位置，从 start 沿 next 走到 0。
  • 操作有不同费用？将递推中的 1 换成选点费用，仍可利用严格减少的状态进行记忆化；带权搜索时不能直接用普通 BFS。
  • 为什么不能直接用二分图最小点覆盖？本题每次必须选择一条当前存在的边，成对删除其行、列端点，与任意单选顶点的操作集合不同。
  • 若 K 大幅增加？2ᴷ 空间会成为瓶颈，需要利用额外结构或重新设计算法，不能仅把整数换成大整数就解决规模问题。

Java

import java.util.Arrays;

class Solution {
    private int k;
    private int[] clear, memo;

    public int removeOnes(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        k = m * n;
        clear = new int[k];
        memo = new int[1 << k];
        Arrays.fill(memo, -1);
        memo[0] = 0;
        int start = 0;
        for (int p = 0; p < k; p++) {
            if (grid[p / n][p % n] == 1) start |= 1 << p;
            for (int q = 0; q < k; q++) {
                if (p / n == q / n || p % n == q % n)
                    clear[p] |= 1 << q;
            }
        }
        return dfs(start);
    }

    private int dfs(int state) {
        if (memo[state] != -1) return memo[state];
        int best = k;
        for (int p = 0; p < k; p++) {
            if ((state & (1 << p)) != 0)
                best = Math.min(best, 1 + dfs(state & ~clear[p]));
        }
        return memo[state] = best;
    }
}

/**
 * @param {number[][]} grid
 * @return {number}
 */
var removeOnes = function(grid) {
    const m = grid.length, n = grid[0].length, k = m * n;
    const clear = Array(k).fill(0);
    const memo = Array(1 << k).fill(-1);
    memo[0] = 0;
    let start = 0;
    for (let p = 0; p < k; p++) {
        if (grid[Math.floor(p / n)][p % n] === 1)
            start |= 1 << p;
        for (let q = 0; q < k; q++) {
            if (Math.floor(p / n) === Math.floor(q / n) || p % n === q % n)
                clear[p] |= 1 << q;
        }
    }
    function dfs(state) {
        if (memo[state] !== -1) return memo[state];
        let best = k;
        for (let p = 0; p < k; p++) {
            if (state & (1 << p))
                best = Math.min(best, 1 + dfs(state & ~clear[p]));
        }
        return memo[state] = best;
    }
    return dfs(start);
};

Python

from functools import lru_cache
from typing import List

class Solution:
    def removeOnes(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        k = m * n
        clear = [0] * k
        start = 0
        for p in range(k):
            if grid[p // n][p % n] == 1:
                start |= 1 << p
            for q in range(k):
                if p // n == q // n or p % n == q % n:
                    clear[p] |= 1 << q

        @lru_cache(None)
        def dfs(state: int) -> int:
            if state == 0:
                return 0
            best = k
            for p in range(k):
                if state & (1 << p):
                    best = min(best, 1 + dfs(state & ~clear[p]))
            return best

        return dfs(start)
