Implement Stack using Queues
队列旋转成栈

队列先进先出，栈后进先出。秘诀是每次压入新元素后，立即把原来的队首元素依次移到队尾：新元素便被旋转到队首，后续 top/pop 都是 O(1)。

题意

只使用队列的标准操作（队尾入队、队首查看/出队、大小、是否为空）实现后进先出（LIFO）栈。实现 MyStack 的 push、pop、top 与 empty。

官方样例
["MyStack", "push", "push", "top", "pop", "empty"]
[[], [1], [2], [], [], []]
输出：[null, null, null, 2, 2, false]

约束：1 ≤ x ≤ 9；最多 100 次操作；所有 pop 与 top 调用均有效。

题解：一个队列，push 时旋转

single queue

核心洞察

入队 x 前队列已有 k 个元素。先把 x 放到队尾，再做 k 次“队首出队并入队”。最终 x 从队尾转到队首，而其余元素保持相对次序，因此队首恰好是栈顶。

完整过程

  1. push(x)：先 enqueue x。
  2. 记录原大小 k，重复 k 次 dequeue 后 enqueue。
  3. top() 直接 peek 队首。
  4. pop() 直接 dequeue 队首。

边界与复杂度

空栈时 empty() 为 true；题目保证 pop/top 有效。队列中只维护一个方向：左边为队首。

push：O(n)
pop / top / empty：O(1)
空间：O(n)

替代方案取舍

两队列方案可在 push 时让新队列先接收 x，再倒入旧队列，也能让 pop/top O(1)，但多一份队列状态。本题追问允许用一个队列，旋转方案更精炼。

常见错误

  • 把旋转次数写成新长度，导致新元素又被转走。
  • 在旋转前读取 size：应保存入队前大小。
  • 把队尾当栈顶，却调用队首的 pop/top。
  • 用 Array.shift() 直接模拟队列但不了解其语言层复杂度；面试中说明 Queue/Deque 语义。

面试追问

能让 push O(1) 吗？ 可以把旋转延后到 pop/top，但它们将变为 O(n)。
为什么单队列足够？ 旋转操作正好能把队列的 FIFO 顺序重新排列为栈的 LIFO 顺序。

class MyStack {
    private final java.util.Queue<Integer> queue = new java.util.ArrayDeque<>();
    public MyStack() {}
    public void push(int x) {
        int size = queue.size();
        queue.offer(x);
        while (size-- > 0) queue.offer(queue.poll());
    }
    public int pop() { return queue.poll(); }
    public int top() { return queue.peek(); }
    public boolean empty() { return queue.isEmpty(); }
}
var MyStack = function () { this.queue = []; };
MyStack.prototype.push = function (x) {
  const size = this.queue.length;
  this.queue.push(x);
  for (let i = 0; i < size; i++) this.queue.push(this.queue.shift());
};
MyStack.prototype.pop = function () { return this.queue.shift(); };
MyStack.prototype.top = function () { return this.queue[0]; };
MyStack.prototype.empty = function () { return this.queue.length === 0; };
from collections import deque

class MyStack:
    def __init__(self):
        self.queue = deque()
    def push(self, x: int) -> None:
        size = len(self.queue)
        self.queue.append(x)
        for _ in range(size):
            self.queue.append(self.queue.popleft())
    def pop(self) -> int: return self.queue.popleft()
    def top(self) -> int: return self.queue[0]
    def empty(self) -> bool: return not self.queue
class MyStack {
    std::queue<int> q;
public:
    MyStack() {}
    void push(int x) {
        int size = q.size(); q.push(x);
        while (size--) { q.push(q.front()); q.pop(); }
    }
    int pop() { int x = q.front(); q.pop(); return x; }
    int top() { return q.front(); }
    bool empty() { return q.empty(); }
};
