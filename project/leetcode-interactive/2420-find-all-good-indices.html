2420. 找到所有好下标

Find All Good Indices

一个位置，两侧窗口。观察它左右的走势，找出满足条件的下标。

官方题目 ↗

题目说明

给定从 0 开始编号的整数数组 nums，长度为 n，以及正整数 k。只考虑 k ≤ i < n − k 的位置。

  • 左侧紧邻的 k 个数，即 nums[i−k … i−1]，必须非递增：从左往右，每个数都不大于前一个数。
  • 右侧紧邻的 k 个数，即 nums[i+1 … i+k]，必须非递减：从左往右，每个数都不小于前一个数。

两个条件同时满足时，i 是好下标。返回所有好下标，按升序排列。nums[i] 本身不参与两侧比较；相邻元素允许相等。

官方示例 1

输入：nums = [2,1,1,1,3,4,1], k = 2
输出：[2,3]

i = 2：左侧 [2,1]，右侧 [1,3]；i = 3：左侧 [1,1]，右侧 [3,4]，都满足条件。i = 4 的右侧 [4,1] 出现下降，因此不满足。

官方示例 2

输入：nums = [2,1,1,2], k = 2
输出：[]

要求 2 ≤ i < 2，没有可选位置。

约束与参数

  • n == nums.length，3 ≤ n ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁶
  • 1 ≤ k ≤ ⌊n / 2⌋
  • 函数：goodIndices(nums, k)；返回整数下标列表。

题解 · 把窗口条件变成连续段长度

核心洞察

相邻候选位置的窗口高度重叠。逐个扫描 k 个元素会重复比较；只要知道某处连续保持单调的长度，就能一次判断整个窗口。

  • L[j]：以 j 结尾的最长连续非递增段长度。若 nums[j−1] ≥ nums[j]，则 L[j] = L[j−1] + 1，否则为 1。
  • R[j]：以 j 开头的最长连续非递减段长度。若 nums[j] ≤ nums[j+1]，则 R[j] = R[j+1] + 1，否则为 1。

好下标 i ⇔ L[i−1] ≥ k 且 R[i+1] ≥ k。

完整过程

  1. 初始化两个长度为 n 的数组，所有值为 1，表示单个元素构成合法段。
  2. 从左向右计算 L，只有相邻关系允许时才延长，否则从当前元素重新开始。
  3. 从右向左计算 R，这样 R[j+1] 已经可用。
  4. 从 k 扫描到 n−k−1，读取两个邻接位置的段长度；满足条件就将 i 加入答案。
nums = [2,1,1,1,3,4,1], k = 2
L    = [1,2,3,4,1,1,2]
R    = [1,5,4,3,2,1,1]
i=2: L[1]=2, R[3]=3 → 收集 2
i=3: L[2]=3, R[4]=2 → 收集 3
i=4: L[3]=4, R[5]=1 → 跳过
答案 = [2,3]

正确性证明

连续段记录正确：以 j 结尾的非递增段若能包含 j−1，必须满足 nums[j−1] ≥ nums[j]。满足时，接在 j−1 的最长合法段后即可多得到一个元素；不满足时，任何跨过这对元素的段都不合法，只能保留 j 本身。由左到右归纳可得 L 正确。R 的证明对称，采用从右到左归纳。

判断充分且必要：左侧窗口恰好是以 i−1 结尾的 k 个连续元素；它非递增，当且仅当 L[i−1] 至少为 k。右侧窗口非递减，当且仅当 R[i+1] 至少为 k。两个条件取交集，正好对应定义。扫描涵盖全部合法候选且按下标递增，因此不会遗漏、误收或乱序。

边界与常见错误

  • k = 1 时，单元素窗口天然合法，答案就是 1 到 n−2。
  • n = 2k 时，没有候选；n = 2k+1 时，仅 i = k 可选。
  • 非递增/非递减允许相等，不能写成严格大于或小于。
  • 查询 L[i−1] 和 R[i+1]，不能把中心 nums[i] 算进窗口。
  • 段长度按元素计数，初始化为 1；若改成相邻边计数，阈值也必须改成 k−1。
  • R 从右往左计算，但单调关系仍按原数组从左往右定义。
  • 记录必须是连续段，子序列长度无法判断本题窗口。

复杂度与替代方案

三次线性扫描，时间 O(n)；L 和 R 占辅助空间 O(n)，答案另占 O(n)。

朴素做法逐个检查两侧窗口，时间 O(nk)，额外工作空间 O(1)。也可以对“左侧出现上升”和“右侧出现下降”的违规相邻对做前缀计数，窗口中违规数为 0 即合法，时间和空间仍为 O(n)。进一步维护两个滑动窗口的违规对计数，可做到 O(n) 时间、O(1) 辅助空间，但要仔细处理进入和移出的边。

面试追问

  • 如何少存一个数组？预计算 R；从左到右扫描时用单个变量维护以 i−1 结尾的非递增长度。
  • 严格单调版本怎么改？把延长段的 ≥、≤ 分别改为 >、<；k = 1 的判断仍然成立。
  • 左右窗口长度不同？用 a、b 分别作为阈值，候选范围改为 a ≤ i < n−b。
  • 数组有在线修改怎么办？静态段长度会连锁失效；可以改为维护相邻对违规标记，用树状数组支持单点更新与区间计数。当前题无需引入该结构。

Java

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<Integer> goodIndices(int[] nums, int k) {
        int n = nums.length;
        int[] left = new int[n], right = new int[n];
        Arrays.fill(left, 1);
        Arrays.fill(right, 1);
        for (int j = 1; j < n; j++) {
            if (nums[j - 1] >= nums[j]) left[j] = left[j - 1] + 1;
        }
        for (int j = n - 2; j >= 0; j--) {
            if (nums[j] <= nums[j + 1]) right[j] = right[j + 1] + 1;
        }
        List<Integer> answer = new ArrayList<>();
        for (int i = k; i < n - k; i++) {
            if (left[i - 1] >= k && right[i + 1] >= k) answer.add(i);
        }
        return answer;
    }
}

Python 3

from typing import List

class Solution:
    def goodIndices(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        left, right = [1] * n, [1] * n
        for j in range(1, n):
            if nums[j - 1] >= nums[j]:
                left[j] = left[j - 1] + 1
        for j in range(n - 2, -1, -1):
            if nums[j] <= nums[j + 1]:
                right[j] = right[j + 1] + 1
        answer = []
        for i in range(k, n - k):
            if left[i - 1] >= k and right[i + 1] >= k:
                answer.append(i)
        return answer

class Solution {

    vector<int> goodIndices(vector<int>& nums, int k) {
        int n = nums.size();
        vector<int> left(n, 1), right(n, 1), answer;
        for (int j = 1; j < n; ++j) {
            if (nums[j - 1] >= nums[j]) left[j] = left[j - 1] + 1;
        }
        for (int j = n - 2; j >= 0; --j) {
            if (nums[j] <= nums[j + 1]) right[j] = right[j + 1] + 1;
        }
        for (int i = k; i < n - k; ++i) {
            if (left[i - 1] >= k && right[i + 1] >= k) answer.push_back(i);
        }
        return answer;
    }
};
