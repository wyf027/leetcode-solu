添加一个点后可激活的最大点数

坐标二分图 · 连通块

给定互不重复的坐标点；被激活的点会沿着相同 x 或相同 y 继续传播。任选一个尚不存在的整数坐标作为起点，求最终最多能激活多少点（新点也计入）。

Interactive map

新点把两个坐标连通块接起来

第 0 / 3 步

观察两个独立的坐标连通块。

题意与示例

例 1：points = [[1,1], [1,2], [2,2]] 加入 (1,3) 后，答案为 4。

例 2：points = [[2,2], [1,1], [3,3]] 加入 (1,2)，可连接两个单点块，答案为 3。

约束：1 ≤ points.length ≤ 10⁵；坐标在 [-10⁹, 10⁹]，且原坐标两两不同。

核心洞察

  1. 把每个不同的 x 与 y 看成二分图的顶点；每个原点 (x,y) 是一条边。
  2. 同一连通块中的边会因“同 x / 同 y”规则全部互相传播，因此一个块的贡献就是它包含的原始点数。
  3. 新点 (x,y) 恰好能拿一个 x 块与一个 y 块相连；两个不同块之间原本不可能已有该点，所以一定合法。
  4. 因此只需找边数最多的两个连通块，答案是它们之和加上新点本身；只有一个块时同理为该块大小加一。

复杂度与边界

坐标压缩后并查集处理 n 条边：时间 O(n α(n))，空间 O(n)。即使所有点在一个块中，也总能选一个未出现的整数坐标连到该块；只有单点时答案为 2。

替代方案与常见错误

可以 DFS 二分图求块大小，但哈希映射 + 并查集更直接。不要只统计 x 或 y 的频次：传播会跨坐标反复扩张；也不要误把“最多两块”理解成可以挑两条边，新点连接的是两个坐标侧顶点。

完整过程

对每个点先为它的 x、y 分配压缩编号，然后 union(x,y)。再次遍历所有点，把每条边归入其根并累计。维护最大和次大组件边数即可。

面试追问

若允许加 k 个点，问题转化为用 k 条新边合并组件，应按组件大小贪心选择可连接的块，并注意坐标侧可用性约束。 

import java.util.*;
class Solution {
  public int maxPoints(int[][] points) {
    Map<Long,Integer> id = new HashMap<>(); int m = 0;
    for (int[] p : points) { long a = ((long)p[0]<<1); long b = ((long)p[1]<<1)|1;
      if (!id.containsKey(a)) id.put(a,m++); if (!id.containsKey(b)) id.put(b,m++); }
    int[] parent = new int[m], sz = new int[m]; for(int i=0;i<m;i++) parent[i]=i;
    for (int[] p : points) union(parent,id.get((long)p[0]<<1),id.get(((long)p[1]<<1)|1));
    for (int[] p : points) sz[find(parent,id.get((long)p[0]<<1))]++;
    int a=0,b=0; for(int v:sz) if(v>a){b=a;a=v;} else if(v>b)b=v; return a+b+1;
  }
  int find(int[] p,int x){return p[x]==x?x:(p[x]=find(p,p[x]));}
  void union(int[] p,int a,int b){a=find(p,a);b=find(p,b);if(a!=b)p[a]=b;}
}

class Solution:
    def maxPoints(self, points: List[List[int]]) -> int:
        ids = {}; add = lambda k: ids.setdefault(k, len(ids))
        for x, y in points: add((0, x)); add((1, y))
        p = list(range(len(ids)))
        def find(x):
            while p[x] != x: p[x], x = p[p[x]], p[x]
            return x
        for x, y in points:
            a, b = find(ids[0,x]), find(ids[1,y])
            if a != b: p[a] = b
        cnt = [0] * len(p)
        for x, _ in points: cnt[find(ids[0,x])] += 1
        first = second = 0
        for v in cnt:
            if v > first: first, second = v, first
            elif v > second: second = v
        return first + second + 1
