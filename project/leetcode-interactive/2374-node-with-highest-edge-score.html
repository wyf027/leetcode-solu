2374. 边积分最高的节点

Node With Highest Edge Score · 一条出边，会把分数送给谁？

先阅读题目，再手动探索。完整推导与代码收纳在页面底部。

01 / 题目

有向图包含 n 个节点，编号为 0 到 n − 1。每个节点恰好发出一条边。参数 edges 是长度为 n 的整数数组：edges[i] 表示节点 i 指向的节点。

某个节点的边积分，是所有直接指向它的节点的编号之和。请返回边积分最大的节点编号；如果并列，返回编号最小的节点。

留意：“编号之和”与“入边数量”不同。没有入边的节点，边积分为 0。

参数与返回值

edgeScore(edges: integer[]) → integer

约束

  • n == edges.length
  • 2 ≤ n ≤ 10⁵
  • 0 ≤ edges[i] < n
  • edges[i] != i，不存在自环。

02 / 官方示例

示例 1

输入：edges = [1,0,0,0,0,7,7,5]
输出：7

节点 0 收到编号 1、2、3、4，积分为 10；节点 1 收到编号 0，积分为 0；节点 5 收到编号 7，积分为 7；节点 7 收到编号 5、6，积分为 11。其余节点积分为 0，因此返回 7。

示例 2

输入：edges = [2,0,0,2]
输出：0

节点 0 的积分为 1 + 2 = 3；节点 2 的积分为 0 + 3 = 3；其余节点积分为 0。最高积分并列时取较小编号，返回 0。

05 / 独立题解

准备好后再展开，查看从积分定义到四种语言实现的完整过程。

按终点累加，按编号选择

核心洞察

每个源节点 i 恰好贡献一次，贡献值是 i，接收位置是 edges[i]。因此只需 score[edges[i]] += i。不用沿路径继续传播，也不用识别图中的环。

完整过程

  1. 创建长度为 n、初始全为 0 的积分数组 score。
  2. 按 i 从 0 到 n − 1 遍历，把 i 加到 score[edges[i]]。
  3. 令 best = 0，按节点编号从 1 到 n − 1 扫描。只有 score[v] 严格大于 score[best] 才替换 best。
  4. 返回 best。因为扫描顺序递增，相同积分时保留的编号自然更小。

示例 1 累加后为 [10,0,0,0,0,7,0,11]。比较到节点 7 时，以 11 超过 10，答案变成 7。示例 2 得到 [3,0,3,0]，节点 2 只是追平节点 0，答案仍为 0。

正确性证明

累加不变式：处理完源节点 0 到 k − 1 后，score[v] 恰好等于这些源节点中指向 v 的编号之和。初始未处理任何边，所有和为 0；处理第 k 条边只给 edges[k] 加 k，正好补上该贡献，所以不变式保持。处理所有源节点后，score 就是定义中的完整边积分。

选择不变式：扫描到节点 v 后，best 是已扫描节点中积分最高且编号最小的节点。新节点严格更高才替换，积分相同时先扫描者编号更小，因此不变式保持。最终扫描覆盖全部节点，返回值满足两个选择条件。

边界与数值范围

  • 节点 0 的边存在，但贡献为 0；入边数较多不一定积分较高。
  • 无入边节点维持 0，最小规模 n = 2 同样适用。
  • 有环或多个连通部分不影响独立求和，不需要 visited。
  • 单节点积分最多可到 n(n − 1)/2；n = 100000 时为 4,999,950,000，超出有符号 32 位整数。Java 使用 long，C++ 使用 long long。
  • JavaScript Number 的精确整数范围足够本题；Python int 可自动扩展。

复杂度

累加 n 次、选择 n 次：时间 O(n)；积分数组占用 O(n) 额外空间。不会改变输入数组。

替代方案

  • 用哈希表记录各终点积分：同样需要线性预期时间，但连续编号直接使用数组更简单。
  • 为每个目标重新扫描所有边：O(n²) 时间、O(1) 额外空间，仅适合很小的输入。
  • 累加时同步维护 best：可少一次扫描，但每次更新必须同时比较“更高积分”或“积分相同且编号更小”。源节点顺序不等于目标编号顺序。
  • 将节点按积分降序、编号升序排序也能得到答案，但 O(n log n) 没有必要。

常见错误

  • 累加 1：算成入度，丢失源节点权重。
  • 累加到 score[i] 或累加 edges[i]：把方向或权重弄反。
  • 升序选答案时使用 ≥：会让编号更大的节点覆盖并列答案。
  • 使用 DFS 传递累计积分：题目只看直接入边。
  • Java / C++ 用 int 存积分：大输入可能溢出。

面试追问

如果每个源节点有权重 w[i]？将贡献 i 改为 w[i]，并重新核对数值范围。如果允许自环？同样累加即可；本题约束禁止自环。如果边会动态改向？旧目标减去 i、新目标加上 i；频繁查询最大值可用维护“积分、编号”的有序结构，并处理旧记录更新。

Java

class Solution {
    public int edgeScore(int[] edges) {
        int n = edges.length;
        long[] score = new long[n];
        for (int i = 0; i < n; i++) {
            score[edges[i]] += i;
        }
        int best = 0;
        for (int v = 1; v < n; v++) {
            if (score[v] > score[best]) best = v;
        }
        return best;
    }
}

Python 3

from typing import List

class Solution:
    def edgeScore(self, edges: List[int]) -> int:
        score = [0] * len(edges)
        for i, target in enumerate(edges):
            score[target] += i
        best = 0
        for v in range(1, len(edges)):
            if score[v] > score[best]:
                best = v
        return best

        vector<long long> score(n, 0);

            score[edges[i]] += i;
        }
        int best = 0;
        for (int v = 1; v < n; ++v) {
            if (score[v] > score[best]) best = v;
        }
        return best;
    }
