铺瓷砖Tiling a Rectangle with the Fewest Squares

一张矩形施工图，一组整数边长的正方形。目标不是找到一种铺法，而是证明没有更省的铺法。

题号 #1240 函数 tilingRectangle(n, m) 范围 1 ≤ n, m ≤ 13

01 / Brief

非付费题

给定一个尺寸为 n × m 的矩形。请使用若干个边长为整数的正方形将它完整铺满；正方形之间不能重叠，也不能超出矩形边界。

A

固定自然落点

C

05 / Full solution

天际线状态 + 回溯剪枝

核心洞察

把矩形看成 m 根宽度为 1 的柱子，heights[c] 表示第 c 列从底部起已经铺了多高。于是二维剩余形状被压缩成一个长度为 m 的数组。

state = [h₀, h₁, …, hₘ₋₁], 0 ≤ hᵢ ≤ n

为什么选“最低且最靠左”

找到最小高度 minH 第一次出现的位置 left。覆盖该处第一个空单元的正方形，左下角必定就在这里；否则会越界、留下空洞或与已铺区域重叠。

完整过程

  1. 初始化所有列高为 0，答案上界设为 n × m（全用 1×1）。
  2. 若已用数量不小于当前最优答案，立即返回。
  3. 将列高数组序列化；若同一状态过去曾用更少或相同数量到达，剪掉当前分支。
  4. 寻找最低且最靠左的列。若最低高度已经等于 n，矩形铺满，用当前数量更新答案。
  5. 从该位置向右统计“高度同为 minH”的连续列，同时不能超过顶部，由此得到最大可放边长。
  6. 按边长从大到小放置正方形：对应若干列同时加上边长，递归后再减回，恢复现场。

正确性证明

状态不变式：每个状态恰好表示各列底部连续铺满至对应高度，已铺区域无重叠且不越界。

完备性：对任一未完成状态，最低且最靠左空单元必须被某块正方形覆盖。该正方形不可能向左延伸，也只能横跨高度等于 minH 的连续列。算法枚举所有合法边长，因此不会漏掉任何可行铺法。

最优性：每条完整铺法对应搜索树中的一条路径；算法检查全部未被安全剪枝的路径并取最小计数。计数上界剪枝不可能改善答案；同状态记忆化只舍弃使用数量不优的前缀。因此最终值就是全局最小值。

边界与复杂度

  • n = m 时答案为 1，通用搜索也能得到。
  • 有一边为 1 时，只能使用 1×1，答案为另一边长度。
  • 交换 n、m 不改变答案；实现可将较短边作为列数以减少状态。
  • 最坏时间为指数级。按列高状态给出宽松上界约 O(m·(n+1)^m)；空间约 O((n+1)^m + m)。实际剪枝会大幅减少访问状态。

替代方案

  • 逐格占用位掩码：选择首个空格并尝试方块，概念直接，但 13×13 需要跨多个整数管理位集。
  • 轮廓 DP：适合固定扫描线的铺砖题；本题方块尺寸可变，仍需枚举与搜索。
  • 精确覆盖 / Algorithm X：可把每个候选正方形视为集合，但目标是最少集合而非普通精确覆盖，建模和剪枝更重。

常见错误

  • 只用欧几里得式贪心；对一般尺寸并不保证最优。
  • 枚举落点却不固定首个空位，导致同一铺法产生大量排列。
  • 回溯后忘记恢复所有受影响列的高度。
  • 记忆化只记录“访问过”，却不比较到达该状态已经使用的方块数。
  • 把复杂度误写成多项式；剪枝有效不等于最坏情况不再指数增长。

面试追问

  1. 为什么可以只维护列高，而不会漏掉内部空洞？ 因为每次只在最低轮廓上向上放置，状态不变式保证每列从底部连续铺满。
  2. 为什么大方块优先只是优化而非正确性条件？ 所有边长最终都会枚举；顺序只影响多快找到较好上界。
  3. 如何进一步优化？ 令列数为 min(n,m)，加入剩余面积下界、对称状态规范化，或把高度编码进定长整数。
  4. 如果要返回具体方案？ 更新 best 时复制当前路径；每次递归记录方块左下角与边长。
import java.util.*;

class Solution {
    private int rows;
    private int cols;
    private int best;
    private Map<String, Integer> seen;

    public int tilingRectangle(int n, int m) {
        // 用较短边做列，减少列高状态的维度。
        rows = Math.max(n, m);
        cols = Math.min(n, m);
        best = rows * cols;
        seen = new HashMap<>();
        dfs(new int[cols], 0);
        return best;
    }

    private void dfs(int[] heights, int used) {
        if (used >= best) return;

        String key = Arrays.toString(heights);
        Integer oldUsed = seen.get(key);
        if (oldUsed != null && oldUsed <= used) return;
        seen.put(key, used);

        int minHeight = rows;
        int left = -1;
        for (int c = 0; c < cols; c++) {
            if (heights[c] < minHeight) {
                minHeight = heights[c];
                left = c;
            }
        }

        if (minHeight == rows) {
            best = used;
            return;
        }

        int maxSize = 0;
        while (left + maxSize < cols
                && heights[left + maxSize] == minHeight
                && minHeight + maxSize + 1 <= rows) {
            maxSize++;
        }

        for (int size = maxSize; size >= 1; size--) {
            for (int c = left; c < left + size; c++) {
                heights[c] += size;
            }
            dfs(heights, used + 1);
            for (int c = left; c < left + size; c++) {
                heights[c] -= size;
            }
        }
    }
}

var tilingRectangle = function(n, m) {
    const rows = Math.max(n, m);
    const cols = Math.min(n, m);
    const heights = new Array(cols).fill(0);
    const seen = new Map();
    let best = rows * cols;

    function dfs(used) {
        if (used >= best) return;

        const key = heights.join(',');
        if (seen.has(key) && seen.get(key) <= used) return;
        seen.set(key, used);

        let minHeight = rows;
        let left = -1;
        for (let c = 0; c < cols; c++) {
            if (heights[c] < minHeight) {
                minHeight = heights[c];
                left = c;
            }
        }

        if (minHeight === rows) {
            best = used;
            return;
        }

        let maxSize = 0;
        while (
            left + maxSize < cols &&
            heights[left + maxSize] === minHeight &&
            minHeight + maxSize + 1 <= rows
        ) {
            maxSize++;
        }

        for (let size = maxSize; size >= 1; size--) {
            for (let c = left; c < left + size; c++) {
                heights[c] += size;
            }
            dfs(used + 1);
            for (let c = left; c < left + size; c++) {
                heights[c] -= size;
            }
        }
    }

    dfs(0);
    return best;
};
class Solution:
    def tilingRectangle(self, n: int, m: int) -> int:
        rows = max(n, m)
        cols = min(n, m)
        heights = [0] * cols
        seen = {}
        best = rows * cols

        def dfs(used: int) -> None:
            nonlocal best
            if used >= best:
                return

            state = tuple(heights)
            if state in seen and seen[state] <= used:
                return
            seen[state] = used

            min_height = min(heights)
            if min_height == rows:
                best = used
                return

            left = heights.index(min_height)
            max_size = 0
            while (
                left + max_size < cols
                and heights[left + max_size] == min_height
                and min_height + max_size + 1 <= rows
            ):
                max_size += 1

            for size in range(max_size, 0, -1):
                for c in range(left, left + size):
                    heights[c] += size
                dfs(used + 1)
                for c in range(left, left + size):
                    heights[c] -= size

        dfs(0)
        return best
#include <algorithm>
#include <climits>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
private:
    int rows = 0;
    int cols = 0;
    int best = INT_MAX;
    unordered_map<string, int> seen;

    string encode(const vector<int>& heights) {
        string key;
        for (int height : heights) {
            key += to_string(height);
            key.push_back(',');
        }
        return key;
    }

    void dfs(vector<int>& heights, int used) {
        if (used >= best) return;

        string key = encode(heights);
        auto it = seen.find(key);
        if (it != seen.end() && it->second <= used) return;
        seen[key] = used;

        int minHeight = rows;
        int left = -1;
        for (int c = 0; c < cols; c++) {
            if (heights[c] < minHeight) {
                minHeight = heights[c];
                left = c;
            }
        }

        if (minHeight == rows) {
            best = used;
            return;
        }

        int maxSize = 0;
        while (left + maxSize < cols
               && heights[left + maxSize] == minHeight
               && minHeight + maxSize + 1 <= rows) {
            maxSize++;
        }

        for (int size = maxSize; size >= 1; size--) {
            for (int c = left; c < left + size; c++) {
                heights[c] += size;
            }
            dfs(heights, used + 1);
            for (int c = left; c < left + size; c++) {
                heights[c] -= size;
            }
        }
    }

public:
    int tilingRectangle(int n, int m) {
        rows = max(n, m);
        cols = min(n, m);
        best = rows * cols;
        seen.clear();
        vector<int> heights(cols, 0);
        dfs(heights, 0);
        return best;
    }
};
