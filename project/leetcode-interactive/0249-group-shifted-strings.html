249. 变位字符串分组

将所有能通过统一循环位移互相得到的字符串分到同一组。关键不在绝对字符，而在相邻字符的模 26 差值模式。

哈希表字符串循环差分分组

题意

若将字符串所有字符统一向后移动同一数量（z 后回到 a），可使两个字符串相同，则它们属于同一组。将 strings 中所有字符串分组，返回任意顺序的分组。

官方样例

输入strings = ["abc","bcd","acef","xyz","az","ba","a","z"]
输出[["abc","bcd","xyz"],["acef"],["az","ba"],["a","z"]]

关键循环位移

输入strings = ["az","ba"]
输出[["az","ba"]]

z → a 仍算移动 1。

约束：字符串只含小写英文字母；单个字符串及列表均可为空或含重复项，输出组与组内顺序均可任意。

交互：提取循环差分签名

对相邻字符计算 (next - current + 26) % 26。abc、bcd、xyz 都得到相同签名 [1,1]。

键盘：← / →；Space 播放

测试与验证

数组、期望输出和实际输出独立显示；分组顺序按规范可不同。

题解：相邻差分作为哈希键

核心洞察

统一位移会给每个字符加相同偏移，故相邻字符的差不变。用每一对相邻字符的模 26 差值拼成键；长度为 1 的字符串都有空键，自然同组。

完整过程

  1. 对每个字符串建立差分 key。
  2. 第 i 位为 (s[i] - s[i-1] + 26) % 26。
  3. 以 key 为键，把字符串追加到哈希表桶。
  4. 返回所有桶。

边界与复杂度

长度 1：差分数组为空，因此 a、z 同组。

跨越 z：加 26 再取模，az 的差为 25，ba 的差也是 25。

重复字符串：会保留多次。

复杂度：总字符数为 L，时间 O(L)，哈希表额外空间 O(L)。

替代方案

也可以把首字符平移到 a 后得到规范化字符串；差分签名更直接表达“不随统一位移改变”的不变量。

常见错误：未处理 z 到 a 的回绕，直接相减会得到负数；或把原字符串排序，排序会破坏字符位置关系。

面试追问

若字符集不是 26 个字母？将模数改为字符集大小。若允许大小写混合，应先明确它们是否属于同一循环字母表。

四语言可提交代码

import java.util.*;

class Solution {
  public List<List<String>> groupStrings(String[] strings) {
    Map<String, List<String>> groups = new HashMap<>();
    for (String s : strings) {
      StringBuilder key = new StringBuilder();
      for (int i = 1; i < s.length(); i++) key.append((s.charAt(i) - s.charAt(i - 1) + 26) % 26).append(',');
      groups.computeIfAbsent(key.toString(), k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(groups.values());
  }
}
var groupStrings = function(strings) {
  const groups = new Map();
  for (const s of strings) {
    const key = Array.from({ length: s.length - 1 }, (_, i) => (s.charCodeAt(i + 1) - s.charCodeAt(i) + 26) % 26).join(',');
    if (!groups.has(key)) groups.set(key, []);
    groups.get(key).push(s);
  }
  return [...groups.values()];
};
from collections import defaultdict
from typing import List

class Solution:
    def groupStrings(self, strings: List[str]) -> List[List[str]]:
        groups = defaultdict(list)
        for s in strings:
            key = tuple((ord(s[i]) - ord(s[i - 1]) + 26) % 26 for i in range(1, len(s)))
            groups[key].append(s)
        return list(groups.values())
