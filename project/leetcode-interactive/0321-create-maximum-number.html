最大数

从两列数字里拿走恰好 k 个；每列内部的先后次序不能改变。怎样让最后拼出的数字在字典序上尽可能大？

Problem

题意与参数

给定两个整数数组 nums1 和 nums2，长度分别为 m、n。每个数组按顺序记录一个数的各位数字；再给定整数 k。

从两个数组中一共选出 k 位，组成字典序最大的长度为 k 的数字数组。来自同一原数组的数字必须保持原有相对顺序。

函数形式

maxNumber(nums1: integer[], nums2: integer[], k: integer) -> integer[]

Constraints

  • m == nums1.length
  • n == nums2.length
  • 1 <= m, n <= 500
  • 0 <= nums1[i], nums2[i] <= 9
  • 1 <= k <= m + n
  • 两个数组均无前导零

标签

数组 · 贪心 · 单调栈 · 双指针 · 栈

Solution

枚举分配，单调栈取数，字典序归并

难点并不是某个孤立技巧，而是把“跨两个数组选 k 位”拆成一组可比较的确定候选。

核心洞察

  1. 先固定分配：假设从 nums1 取 i 位，那么必须从 nums2 取 k-i 位。枚举所有可行的 i。
  2. 每列单独最优：在一个数组中保持次序选定长度的最大子序列，可用“允许删除若干位”的单调栈贪心。
  3. 归并看完整后缀：两条子序列头部相等时，不能随便选一边；应比较两边剩余后缀的字典序，把更大的后缀的首位放入答案。
  4. 候选取最大：每种分配产生一个长度为 k 的候选，保留字典序最大的那个。

完整过程

可行的 i 范围不是简单的 0..k，还要保证两边不越界：

max(0, k - n) <= i <= min(k, m)

1. 从单个数组取长度 t 的最大子序列

最多允许删除 drop = length - t 个数字。顺序扫描当前数字 x；只要栈顶比 x 小且仍有删除额度，就弹出栈顶。再压入 x。扫描结束后截取前 t 位。

例如 [3,4,6,5] 取 2 位：看到 4 时删 3，看到 6 时删 4，最终得到 [6,5]。

2. 归并两条最优子序列

若当前首位不同，取较大者；若相同，就逐位比较剩余后缀，直到出现不同数字或某一边耗尽。字典序更大的后缀优先。

这个规则解决了诸如 [6,7] 与 [6,0,4] 的抉择：第一位同为 6，但前者后续 7 更大，所以先取左侧的 6。

3. 比较全部分配方案

示例 1 中枚举从 nums1 取 0 到 4 位。关键分配 i=2 得到 [6,5] 和 [9,8,3]，按后缀归并得到 [9,8,6,5,3]；它大于其他分配的候选。

正确性证明

引理一：单调栈返回固定长度的最大子序列

当扫描到数字 x，若栈顶 y < x 且仍可删除 y，用更靠后的 x 替换 y 会让首次不同位置变大，同时不破坏相对顺序与最终长度可行性，因此任何最优解都可作此交换而不变差。重复弹栈直到不能改进，得到字典序最大的可行前缀；归纳到扫描结束，即得到固定长度的最大子序列。

引理二：后缀比较的归并产生两条子序列的最大交错序列

每一步若一侧剩余后缀字典序更大，则任何以另一侧首位开头的交错方案，都不会优于先取较大后缀首位的方案：首位不同时结论立即成立；首位相同时，决定大小的仍是之后第一个不同位置。取走该首位后，问题缩小为相同形式，故可归纳。

定理：算法返回全局最优答案

任意合法答案都对应唯一的取数数量分配 i 与 k-i。对这一分配，引理一给出两侧各自最优子序列，引理二给出它们的最优交错结果，因此该候选不劣于同分配下的任何答案。算法枚举所有可行分配并取最大值，所以覆盖并达到全局最优。

边界情况

  • k = 1：所有分配仍适用，答案是两数组可选数字中的最大值。
  • k = m+n：两边必须全部取出，核心只剩后缀字典序归并。
  • 一边分配 0 位：最大子序列函数需允许返回空数组。
  • 大量相同数字：归并必须比较完整剩余后缀，不能仅比较当前位。
  • 数字含 0：0 是合法数位；算法不能把它当作“空”或哨兵。

复杂度

设有效分配数为 S。每次分配的两次取子序列耗时 O(m+n)；朴素后缀比较的归并最坏耗时 O(k²)；候选比较耗时 O(k)。因此总时间为 O(S · (m+n+k²))，其中 S <= min(k,m,n)+1。除返回值和候选数组外，辅助空间为 O(m+n+k)，实际保存的工作序列规模为线性。

替代方案

  • 记忆化后缀比较：可缓存某对下标的比较结果，减少大量相等数字带来的重复扫描，但实现和空间成本更高。
  • 后缀排名 / LCP：对每次归并的两序列构建排名或最长公共前缀结构，使比较更快；本题长度上限 500，通常没有必要。
  • 动态规划：直接描述“两数组取若干位的最大答案”状态直观但状态与序列存储庞大，比较成本也高，不如贪心分解简洁。

面试追问

  1. 为什么取固定长度子序列时，删除较小栈顶一定安全？请给出交换论证。
  2. 若归并时两个当前数字相等，只比较下一位是否足够？如何构造反例？
  3. 当数组规模扩大到十万，如何优化后缀比较？
  4. 如果数字允许重排，问题会退化成什么？如果要求两数组交替取数，又该如何建模？

常见错误

  • 只取两个数组中最大的 k 个数字，忽略相对顺序。
  • 只尝试一种分配，没有枚举从 nums1 取多少位。
  • 归并遇到相同首位时固定选左边，导致长公共前缀下出错。
  • 单调栈忘记限制删除额度，造成剩余数字不足以填满目标长度。
  • 候选比较只比较局部，或在一种语言中用引用复用导致最优答案被后续修改。

Java

class Solution {
    public int[] maxNumber(int[] nums1, int[] nums2, int k) {
        int m = nums1.length, n = nums2.length;
        int[] best = new int[k];

        int from = Math.max(0, k - n);
        int to = Math.min(k, m);
        for (int take1 = from; take1 <= to; take1++) {
            int[] a = pickMax(nums1, take1);
            int[] b = pickMax(nums2, k - take1);
            int[] candidate = merge(a, b);
            if (greater(candidate, 0, best, 0)) {
                best = candidate;
            }
        }
        return best;
    }

    private int[] pickMax(int[] nums, int length) {
        int[] stack = new int[length];
        int top = 0;
        int drop = nums.length - length;
        for (int digit : nums) {
            while (top > 0 && drop > 0 && stack[top - 1] < digit) {
                top--;
                drop--;
            }
            if (top < length) {
                stack[top++] = digit;
            } else {
                drop--;
            }
        }
        return stack;
    }

    private int[] merge(int[] a, int[] b) {
        int[] result = new int[a.length + b.length];
        int i = 0, j = 0;
        for (int p = 0; p < result.length; p++) {
            result[p] = greater(a, i, b, j) ? a[i++] : b[j++];
        }
        return result;
    }

    private boolean greater(int[] a, int i, int[] b, int j) {
        while (i < a.length && j < b.length && a[i] == b[j]) {
            i++;
            j++;
        }
        return j == b.length || (i < a.length && a[i] > b[j]);
    }
}

/**
 * @param {number[]} nums1
 * @param {number[]} nums2
 * @param {number} k
 * @return {number[]}
 */
var maxNumber = function(nums1, nums2, k) {
    const pickMax = (nums, length) => {
        const stack = [];
        let drop = nums.length - length;
        for (const digit of nums) {
            while (drop > 0 && stack.length > 0 &&
                   stack[stack.length - 1] < digit) {
                stack.pop();
                drop--;
            }
            stack.push(digit);
        }
        return stack.slice(0, length);
    };

    const greater = (a, i, b, j) => {
        while (i < a.length && j < b.length && a[i] === b[j]) {
            i++;
            j++;
        }
        return j === b.length || (i < a.length && a[i] > b[j]);
    };

    const merge = (a, b) => {
        const result = [];
        let i = 0;
        let j = 0;
        while (i < a.length || j < b.length) {
            if (greater(a, i, b, j)) {
                result.push(a[i++]);
            } else {
                result.push(b[j++]);
            }
        }
        return result;
    };

    let best = Array(k).fill(0);
    const from = Math.max(0, k - nums2.length);
    const to = Math.min(k, nums1.length);
    for (let take1 = from; take1 <= to; take1++) {
        const a = pickMax(nums1, take1);
        const b = pickMax(nums2, k - take1);
        const candidate = merge(a, b);
        if (greater(candidate, 0, best, 0)) best = candidate;
    }
    return best;
};

Python

from typing import List


class Solution:
    def maxNumber(
        self, nums1: List[int], nums2: List[int], k: int
    ) -> List[int]:
        def pick_max(nums: List[int], length: int) -> List[int]:
            stack: List[int] = []
            drop = len(nums) - length
            for digit in nums:
                while drop and stack and stack[-1] < digit:
                    stack.pop()
                    drop -= 1
                stack.append(digit)
            return stack[:length]

        def greater(
            a: List[int], i: int, b: List[int], j: int
        ) -> bool:
            while i < len(a) and j < len(b) and a[i] == b[j]:
                i += 1
                j += 1
            return j == len(b) or (i < len(a) and a[i] > b[j])

        def merge(a: List[int], b: List[int]) -> List[int]:
            result: List[int] = []
            i = j = 0
            while i < len(a) or j < len(b):
                if greater(a, i, b, j):
                    result.append(a[i])
                    i += 1
                else:
                    result.append(b[j])
                    j += 1
            return result

        best = [0] * k
        start = max(0, k - len(nums2))
        end = min(k, len(nums1))
        for take1 in range(start, end + 1):
            a = pick_max(nums1, take1)
            b = pick_max(nums2, k - take1)
            candidate = merge(a, b)
            if greater(candidate, 0, best, 0):
                best = candidate
        return best

C++

class Solution {
public:
    vector<int> maxNumber(vector<int>& nums1,
                          vector<int>& nums2, int k) {
        vector<int> best(k, 0);
        int from = max(0, k - static_cast<int>(nums2.size()));
        int to = min(k, static_cast<int>(nums1.size()));

        for (int take1 = from; take1 <= to; ++take1) {
            vector<int> a = pickMax(nums1, take1);
            vector<int> b = pickMax(nums2, k - take1);
            vector<int> candidate = mergeMax(a, b);
            if (greater(candidate, 0, best, 0)) {
                best = move(candidate);
            }
        }
        return best;
    }

private:
    vector<int> pickMax(const vector<int>& nums, int length) {
        vector<int> stack;
        int drop = static_cast<int>(nums.size()) - length;
        for (int digit : nums) {
            while (drop > 0 && !stack.empty() && stack.back() < digit) {
                stack.pop_back();
                --drop;
            }
            stack.push_back(digit);
        }
        stack.resize(length);
        return stack;
    }

    bool greater(const vector<int>& a, int i,
                 const vector<int>& b, int j) {
        while (i < static_cast<int>(a.size()) &&
               j < static_cast<int>(b.size()) && a[i] == b[j]) {
            ++i;
            ++j;
        }
        return j == static_cast<int>(b.size()) ||
               (i < static_cast<int>(a.size()) && a[i] > b[j]);
    }

    vector<int> mergeMax(const vector<int>& a,
                         const vector<int>& b) {
        vector<int> result;
        result.reserve(a.size() + b.size());
        int i = 0, j = 0;
        while (i < static_cast<int>(a.size()) ||
               j < static_cast<int>(b.size())) {
            if (greater(a, i, b, j)) {
                result.push_back(a[i++]);
            } else {
                result.push_back(b[j++]);
            }
        }
        return result;
    }
};
