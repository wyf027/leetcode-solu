05 / 独立题解

展开后阅读推导、SQL 与四种语言的参考实现。

从招聘优先级，到分组前缀和

核心洞察

目标是按 (Senior 人数, Junior 人数) 的字典序最大化，不是单独最大化总人数。同一类别每个人都贡献 1 人，因此先选更便宜的人不会变差。Senior 选最便宜的可负担前缀，在人数最多的同时留下最大余额，再处理 Junior。

完整过程

  1. 按 experience 分组，每组按 salary、employee_id 升序排列，编号用于打破同薪并列。
  2. 用显式 ROWS 窗口逐行累加 salary，得到 cost，即录用该组前若干人的总薪资。
  3. 数出 Senior 中 cost ≤ 70000 的行。可录用行中最大的 cost 是 Senior 总开支。
  4. 没有可录用 Senior 时，MAX 为 NULL，用 COALESCE 置为 0。Junior 额度为 70000 减 Senior 开支。
  5. 数出 Junior 中 cost 不超过余额的行。两条不带 GROUP BY 的 COUNT 查询保证每个类别都返回一行，空组人数为 0；UNION ALL 合并结果。

示例 1：Senior 累计 20000 → 40000 → 90000，录用前两人，余额 30000。Junior 累计 10000 → 20000 → 60000，录用前两人，最终余额 10000。示例 2：Senior 最低也要 80000，开支为 0；Junior 三人共 60000，可全部录用。

正确性：交换论证

令同类薪资为 a₁ ≤ … ≤ aₘ。任意 k 人的总薪资都不小于最小 k 项的前缀和：若选了更贵的人却漏掉更便宜的人，交换后人数不变且成本不增加。因此，若最便宜的 k+1 人也超预算，任意 k+1 人都不可行；最长可负担前缀的人数最优。

先对 Senior 应用该结论得到最大 Senior 人数。此方案也是该人数下的最低开支方案，余额不小于其他同人数方案。再对 Junior 应用相同结论，Junior 人数也达到最大，故满足两阶段优先目标。非负薪资使累计和单调；若允许负薪资，提前停止的论证需要重做。

边界与复杂度

  • 恰好等于额度时应录用，必须用 ≤，不能用 <。
  • 空表、缺失类别、全部 Senior 超预算，均保留两行输出。
  • 同薪人员可能只能录用部分。默认 RANGE 可能将同薪行一起累计，显式 ROWS 加唯一编号排序可避免这个问题。
  • Senior 用光预算时，正薪 Junior 无法录用；若存在零薪候选人，仍可录用。
  • 总行数 n：排序通常 O(n log n)，窗口和计数 O(n)，中间结果或排序空间通常 O(n)；实际资源消耗依赖数据库执行计划。四语言参考实现都是 O(n log n) 时间、O(n) 额外空间。

替代方案

本地程序可以分别排序两类薪资，再依次扣减预算，直到下一人无法负担。SQL 可用比较 (salary, employee_id) 的相关子查询模拟前缀和，但可能达到 O(n²)。同类人员收益都为 1，无须一般背包动态规划。

面试追问

  • 要输出员工 ID？复用前缀筛选并返回对应行，同薪时以编号保证结果可重复。
  • 预算被反复查询？预先保存两类有序前缀和，每次通过二分定位可负担前缀。
  • 每个人的收益不同？按薪资排序不再保证最优，可能需要背包等优化算法。
  • 有更多经验级别？先明确各级优先序，再逐级最大化人数并传递余额。

常见错误

把所有候选人混合排序会丢失 Senior 优先级；两类各用 70000 会重复花预算；用 MAX(salary) 代替 MAX(cost) 会低估总开支；未处理 NULL 会让 Junior 比较失效；直接按类别 GROUP BY 可能漏掉零人数类别。

MySQL 8+ · 主提交解法

WITH ranked AS (
    SELECT employee_id, experience, salary,
           SUM(salary) OVER (
               PARTITION BY experience
               ORDER BY salary, employee_id
               ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
           ) AS cost
    FROM Candidates
), senior_budget AS (
    SELECT COALESCE(MAX(cost), 0) AS spent
    FROM ranked
    WHERE experience = 'Senior' AND cost <= 70000
)
SELECT 'Senior' AS experience, COUNT(*) AS accepted_candidates
FROM ranked
WHERE experience = 'Senior' AND cost <= 70000
UNION ALL
SELECT 'Junior' AS experience, COUNT(*) AS accepted_candidates
FROM ranked
WHERE experience = 'Junior'
  AND cost <= 70000 - (SELECT spent FROM senior_budget);

Java · 本地语义参考

Java 8+ 完整 Main 类，返回数组顺序为 Senior、Junior。

import java.util.*;

public class Main {
    static class Candidate {
        int id;
        String experience;
        long salary;
        Candidate(int id, String experience, long salary) {
            this.id = id;
            this.experience = experience;
            this.salary = salary;
        }
    }
    static int[] countHires(List<Candidate> candidates) {
        long remaining = 70000;
        int[] counts = new int[2];
        String[] types = {"Senior", "Junior"};
        for (int i = 0; i < 2; i++) {
            List<Long> salaries = new ArrayList<>();
            for (Candidate c : candidates)
                if (c.experience.equals(types[i])) salaries.add(c.salary);
            Collections.sort(salaries);
            for (long salary : salaries) {
                if (salary > remaining) break;
                remaining -= salary;
                counts[i]++;
            }
        }
        return counts;
    }
    public static void main(String[] args) {
        List<Candidate> candidates = Arrays.asList(
            new Candidate(1,"Junior",10000), new Candidate(9,"Junior",10000),
            new Candidate(2,"Senior",20000), new Candidate(11,"Senior",20000),
            new Candidate(13,"Senior",50000), new Candidate(4,"Junior",40000));
        int[] result = countHires(candidates);
        System.out.println("Senior: " + result[0]);
        System.out.println("Junior: " + result[1]);
    }
}

function countHires(candidates) {
  let remaining = 70000;
  return ['Senior', 'Junior'].map(experience => {
    const salaries = candidates.filter(c => c[1] === experience)
      .map(c => c[2]).sort((a, b) => a - b);
    let accepted_candidates = 0;
    for (const salary of salaries) {
      if (salary > remaining) break;
      remaining -= salary;
      accepted_candidates++;
    }
    return { experience, accepted_candidates };
  });
}

def count_hires(candidates):
    remaining = 70000
    result = []
    for experience in ('Senior', 'Junior'):
        salaries = sorted(row[2] for row in candidates
                          if row[1] == experience)
        accepted = 0
        for salary in salaries:
            if salary > remaining:
                break
            remaining -= salary
            accepted += 1
        result.append({'experience': experience,
                       'accepted_candidates': accepted})
    return result

#include <algorithm>
#include <array>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Candidate { int id; string experience; long long salary; };
array<int, 2> countHires(const vector<Candidate>& candidates) {
    long long remaining = 70000;
    array<int, 2> counts{0, 0};
    const array<string, 2> types{"Senior", "Junior"};
    for (int i = 0; i < 2; ++i) {
        vector<long long> salaries;
        for (const auto& c : candidates)
            if (c.experience == types[i]) salaries.push_back(c.salary);
        sort(salaries.begin(), salaries.end());
        for (long long salary : salaries) {
            if (salary > remaining) break;
            remaining -= salary;
            ++counts[i];
        }
    }
    return counts;
}
int main() {
    vector<Candidate> candidates{{1,"Junior",10000},{9,"Junior",10000},
        {2,"Senior",20000},{11,"Senior",20000},
        {13,"Senior",50000},{4,"Junior",40000}};
    auto result = countHires(candidates);
    cout << "Senior: " << result[0] << '\n';
    cout << "Junior: " << result[1] << '\n';
}
