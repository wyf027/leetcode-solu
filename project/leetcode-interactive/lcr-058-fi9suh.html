我的日程安排表 I

设计一个日程表，在每次预订时拒绝与既有日程重叠的半开区间。

开始演示

题意

实现 MyCalendar。book(startTime, endTime) 尝试添加区间 [startTime, endTime)；不与任何已预订日程重叠则返回 true，否则返回 false。

示例

MyCalendar();
book(10, 20) → true
book(15, 25) → false
book(20, 30) → true

约束

  • 调用 book 最多 1000 次。
  • 0 <= startTime < endTime <= 109
  • 区间为左闭右开，[10,20) 和 [20,30) 不重叠。

核心洞察

两个半开区间 [start,end) 与 [s,e) 不重叠，当且仅当 end <= s 或 start >= e。 只要存在一个日程不满足这两个条件，本次预订就必须拒绝。

边界：结束时刻恰好等于下一场开始时刻可以预订；比较应使用 <= 和 >=。

交互预订器

输入一个半开时间区间，观察冲突判定。

0100

已接受的预订

    解题过程

    1. 维护一个数组，保存每个成功预订的 [start, end)。
    2. 新预订到来时，逐一检查所有已有区间。
    3. 若任意区间满足 start < e && end > s，两者重叠，返回 false。
    4. 没有冲突时写入数组并返回 true。

    复杂度

    单次预订时间 O(n)，额外空间 O(n)。题目的 n 最多为 1000，足够直接。

    可扩展方向

    调用更多时可按开始时间排序后用二分定位相邻区间；本题不需要更复杂的树结构。

    官方签名代码

    class MyCalendar {
    private final List<int[]> bookings = new ArrayList<>();

    public boolean book(int startTime, int endTime) {
        for (int[] booking : bookings) {
            if (startTime < booking[1] && endTime > booking[0]) return false;
        }
        bookings.add(new int[]{startTime, endTime});
        return true;
    }
}
    var MyCalendar = function () {
  this.bookings = [];
};

MyCalendar.prototype.book = function (startTime, endTime) {
  for (const [start, end] of this.bookings) {
    if (startTime < end && endTime > start) return false;
  }
  this.bookings.push([startTime, endTime]);
  return true;
};
    class MyCalendar:
    def __init__(self):
        self.bookings = []

    def book(self, startTime: int, endTime: int) -> bool:
        for start, end in self.bookings:
            if startTime < end and endTime > start:
                return False
        self.bookings.append((startTime, endTime))
        return True
    class MyCalendar {
    vector<pair<int, int>> bookings;

public:
    bool book(int startTime, int endTime) {
        for (const auto& [start, end] : bookings) {
            if (startTime < end && endTime > start) return false;
        }
        bookings.emplace_back(startTime, endTime);
        return true;
    }
};

    常见错误

    • 把端点相接误判为冲突：[10,20) 和 [20,30) 应同时成功。
    • 只检查新日程的开始点是否落入旧日程，漏掉“新日程完整覆盖旧日程”的重叠。
    • 冲突时仍写入日程表，导致后续结果错误。
