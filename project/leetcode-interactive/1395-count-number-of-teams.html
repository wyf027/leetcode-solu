01 · 题目简报

组建合法作战单位

有 n 名士兵排成一列，每名士兵拥有一个互不相同的评分 rating[i]。请从中选择下标为 i、j、k 的三名士兵。

合法条件
0 ≤ i < j < k < n，并且评分满足 rating[i] < rating[j] < rating[k] 或 rating[i] > rating[j] > rating[k]。

返回所有合法选择的数量。同一名士兵可以出现在不同的作战单位中。

函数签名numTeams(rating)
参数rating: integer[]
返回integer
标签数组 · 动态规划 · 树状数组 · 线段树
02 · 官方示例

输入与输出

EXAMPLE 01
输入 rating = [2,5,3,4,1]
输出 3
解释 (2,3,4)、(5,4,1)、(5,3,1)
EXAMPLE 02
输入 rating = [2,1,3]
输出 0
解释 不存在满足条件的三人组合
EXAMPLE 03
输入 rating = [1,2,3,4]
输出 4

约束

  • n == rating.length
  • 3 ≤ n ≤ 1000
  • 1 ≤ rating[i] ≤ 105
  • rating 中的所有整数互不相同。

05 · 完整题解

把每名士兵当作中点

核心洞察

固定中间下标 j 后，合法三元组只取决于左侧、右侧分别有多少评分比 rating[j] 小或大。每个左侧候选都能与相反方向的右侧候选配对。

贡献(j) = leftLess × rightGreater + leftGreater × rightLess

枚举所有 j 并相加，即可覆盖所有合法三元组。

完整过程

  1. 依次把下标 j = 0 ... n-1 作为中间士兵。
  2. 扫描 j 左边，统计 leftLess 与 leftGreater。
  3. 扫描 j 右边，统计 rightLess 与 rightGreater。
  4. 把两类方向一致的配对数量加入答案。

正确性证明

完备性：任意合法三元组都有唯一的中间下标 j。递增三元组的左端必在 leftLess 中、右端必在 rightGreater 中；递减三元组同理落入另一乘积，因此一定会被计数。

无重复性：每个三元组的中间下标唯一；固定 j 后，左右端点也对应唯一一次笛卡尔积配对。因此没有三元组被重复计数。

所以累加所有中点贡献，结果恰好等于合法作战单位总数。

复杂度与边界

时间复杂度：O(n²)。每个中点最多扫描整个数组。

空间复杂度：O(1)，只维护计数器。

  • n = 3 时，结果只能是 0 或 1。
  • 严格单调数组的答案为 C(n,3)。
  • 评分互不相同，因此无需处理相等关系。

四语言完整代码

JavaLeetCode 可提交
class Solution {
    public int numTeams(int[] rating) {
        int answer = 0;
        for (int j = 0; j < rating.length; j++) {
            int leftLess = 0, leftGreater = 0;
            int rightLess = 0, rightGreater = 0;

            for (int i = 0; i < j; i++) {
                if (rating[i] < rating[j]) leftLess++;
                else leftGreater++;
            }
            for (int k = j + 1; k < rating.length; k++) {
                if (rating[k] < rating[j]) rightLess++;
                else rightGreater++;
            }

            answer += leftLess * rightGreater
                    + leftGreater * rightLess;
        }
        return answer;
    }
}

from typing import List

class Solution:
    def numTeams(self, rating: List[int]) -> int:
        answer = 0

        for j, middle in enumerate(rating):
            left_less = left_greater = 0
            right_less = right_greater = 0

            for i in range(j):
                if rating[i] < middle:
                    left_less += 1
                else:
                    left_greater += 1

            for k in range(j + 1, len(rating)):
                if rating[k] < middle:
                    right_less += 1
                else:
                    right_greater += 1

            answer += (left_less * right_greater
                       + left_greater * right_less)

        return answer

替代方案

可使用坐标压缩配合树状数组，分别从左、右预处理小于/大于计数，将时间降到 O(n log n)，空间为 O(n)。在本题 n ≤ 1000 时，O(n²) 更直接。

面试追问
  • 若评分允许重复，严格不等关系如何维护？
  • 若队伍大小变成 m，如何用动态规划计数？
  • 怎样用树状数组把复杂度降到 O(n log n)？
常见错误
  • 只统计递增队伍，漏掉递减队伍。
  • 忽略下标顺序，只对评分排序。
  • 把左右两边同方向相乘，配对公式写反。
  • 三重循环边界导致重复或遗漏。
