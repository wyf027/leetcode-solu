Problem brief

题意

给定一个合法的算术表达式字符串 s。表达式只含非负整数、 +、-、*、/ 与空格，不含括号。 请按照通常的乘除优先级计算结果。整数除法直接截去小数部分，即向零取整；不能调用 eval 一类直接求值接口。

官方样例 1

输入s = "3+2*2"
输出7

官方样例 2

输入s = "␠3/2␠"
输出1

官方样例 3

输入s = "␠3+5␠/␠2␠"
输出5

符号 ␠ 表示一个可见化的空格；真实输入中该位置仍是普通空格。 题目保证表达式合法。

Interview solution

题解

核心洞察、完整过程、边界、复杂度、替代方案、追问、易错点和四语言代码默认隐藏。

Core insight

核心洞察：把加减当成“结算点”

维护 total（已经完成的低优先级部分）、term（仍可能继续乘除的当前项）、 num（正在读取的整数）和 op（等待作用于 num 的前一个运算符）。 遇到新运算符时，才执行旧 op：加减先把旧 term 结算进 total，乘除只改写 term。扫描末尾补一个哨兵运算符触发最后一次调度。

1 · 读数字

num = num × 10 + digit，支持多位整数。

2 · 跳空格

空格不结束数字，也不触发计算。

3 · 调度旧 op

新符号到达时执行旧符号，保住运算优先级。

4 · 收尾

返回 total + term。

Full walkthrough

完整过程

触发 旧 op 动作 状态
+ + 结算旧项，建立 3 total=0, term=3
/ + 结算 3，建立 5 total=3, term=5
END / term = trunc(5/2) total=3, term=2
返回 — total + term 5
Boundaries

边界

  • 表达式只有一个整数：哨兵负责提交它。
  • 首个数字前、数字与算符之间、末尾均可能有空格。
  • 中间项可能为负；除法必须向零截断，Python 的 // 不能直接替代。
  • 多位数必须逐位累积；题目保证表达式合法且不会出现非法除零。
Complexity

复杂度

每个字符只访问一次，时间复杂度 O(n)；仅维护四个标量寄存器， 额外空间 O(1)。四份实现使用足够宽的整数类型承接中间结果。

替代方案取舍

通用栈同样能在 O(n) 内解决，扩展括号或更多运算符更自然，但本题会占 O(n) 空间。 双寄存器正好利用“只有两级优先级”的结构，面试中更简洁。

常见错误

  • 看到当前符号就立即执行当前符号，而不是前一个 op。
  • 漏掉末尾提交，或把空格误当作数字结束。
  • Python 用 // 处理负数，得到向下取整。

面试追问

  • 若加入括号，如何改成双栈或递归下降？
  • 若加入一元负号，需要如何区分二元减法？
  • 若要求溢出检测，应在哪一步校验？

class Solution {
    public int calculate(String s) {
        long total = 0;
        long term = 0;
        long num = 0;
        char op = '+';

        for (int i = 0; i <= s.length(); i++) {
            char ch = i < s.length() ? s.charAt(i) : '+';
            if (Character.isDigit(ch)) {
                num = num * 10 + (ch - '0');
            } else if (ch != ' ') {
                if (op == '+') {
                    total += term;
                    term = num;
                } else if (op == '-') {
                    total += term;
                    term = -num;
                } else if (op == '*') {
                    term *= num;
                } else {
                    term /= num;
                }
                op = ch;
                num = 0;
            }
        }
        return (int) (total + term);
    }
}

var calculate = function (s) {
  let total = 0;
  let term = 0;
  let num = 0;
  let op = "+";

  for (let i = 0; i <= s.length; i += 1) {
    const ch = i < s.length ? s[i] : "+";
    if (ch >= "0" && ch <= "9") {
      num = num * 10 + Number(ch);
    } else if (ch !== " ") {
      if (op === "+") {
        total += term;
        term = num;
      } else if (op === "-") {
        total += term;
        term = -num;
      } else if (op === "*") {
        term *= num;
      } else {
        term = Math.trunc(term / num);
      }
      op = ch;
      num = 0;
    }
  }
  return total + term;
};
