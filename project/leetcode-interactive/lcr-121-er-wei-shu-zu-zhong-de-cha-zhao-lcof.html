寻找目标值 - 二维数组

在每行从左到右递增、每列从上到下递增的二维数组中，判断目标值 target 是否存在。

开始交互演示

题意、示例与约束

输入：plant = [[1,4,7],[2,5,8],[3,6,9]], target = 5

输出：true

输入：plant = [[1,4,7],[2,5,8],[3,6,9]], target = 10

输出：false

  • 行数、列数均可为 0。
  • 每一行递增，每一列递增。
  • 元素和目标值在 32 位整数范围内。

分步交互：右上角排除法

从右上角出发：值太大则向左，值太小则向下，每次排除一整行或一整列。

核心洞察

右上角元素左侧都更小、下侧都更大，因此它与目标的比较能决定一个方向：若当前值大于 target，当前列从该点向下都更大，安全左移；若更小，当前行从该点向左都更小，安全下移。

完整过程

  1. 1. 起点
    row=0，col=最后一列。
  2. 2. 相等
    找到目标，立刻返回 true。
  3. 3. 太大
    col--，排除当前列。
  4. 4. 太小
    row++，排除当前行。

边界与复杂度

  • 空矩阵或空行：立即返回 false。
  • 单行、单列仍适用同一循环。
  • 时间 O(m+n)，空间 O(1)。

替代方案、追问与常见错误

替代：逐行二分为 O(m log n)，暴力扫描 O(mn)；右上角法更优。
追问：如果每行有序但列无序怎么办？若矩阵允许重复元素，排除逻辑是否仍成立？
常见错误：从左上角开始无法决定唯一方向；没有处理空矩阵；比较后同时移动行和列，跳过潜在答案。

官方签名代码

// Java
class Solution {
  public boolean findTargetIn2DPlants(int[][] plant, int target) {
    if (plant.length == 0 || plant[0].length == 0) return false;
    int r = 0, c = plant[0].length - 1;
    while (r < plant.length && c >= 0) {
      if (plant[r][c] == target) return true;
      if (plant[r][c] > target) c--; else r++;
    }
    return false;
  }
}
// JavaScript
var findTargetIn2DPlants = function(plant, target) {
  if (!plant.length || !plant[0].length) return false;
  let r = 0, c = plant[0].length - 1;
  while (r < plant.length && c >= 0) {
    if (plant[r][c] === target) return true;
    plant[r][c] > target ? c-- : r++;
  }
  return false;
};
# Python
class Solution:
    def findTargetIn2DPlants(self, plant, target):
        if not plant or not plant[0]: return False
        r, c = 0, len(plant[0]) - 1
        while r < len(plant) and c >= 0:
            if plant[r][c] == target: return True
            if plant[r][c] > target: c -= 1
            else: r += 1
        return False
// C++
class Solution {
public:
  bool findTargetIn2DPlants(vector<vector<int>>& plant, int target) {
    if (plant.empty() || plant[0].empty()) return false;
    int r = 0, c = plant[0].size() - 1;
    while (r < plant.size() && c >= 0) {
      if (plant[r][c] == target) return true;
      plant[r][c] > target ? --c : ++r;
    }
    return false;
  }
};
