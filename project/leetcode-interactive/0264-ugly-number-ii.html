Ugly Number II
三指针丑数工厂

丑数的质因子只含 2、3、5。维护三个指针，分别生成已知丑数乘以 2、3、5 的候选；每轮取最小候选，并让所有产生它的指针前进，避免重复。

题意

丑数是质因子只包含 2、3、5 的正整数。给定 n，返回第 n 个丑数。

官方样例
n = 10
输出：12；序列是 1、2、3、4、5、6、8、9、10、12。

约束：1 ≤ n ≤ 1690

交互：三条生产线

已生成前几个丑数；颜色表示本轮产生最小候选的指针。

三个指针 p2、p3、p5 都从索引 0 出发。

候选：2×1、3×1、5×1。
p2=0，p3=0，p5=0。

题解：合并三个有序序列

O(n)

核心洞察

所有丑数可由更小丑数乘以 2、3 或 5 得到。dp 已有序，因而 2×dp[p2]、3×dp[p3]、5×dp[p5] 是三条有序生产线；取最小即可合并。

完整过程

  1. dp[0]=1，三个指针为 0。
  2. 取三个候选最小值作为下一个 dp。
  3. 候选等于该值的每条线都前进。
  4. 生成 n 个值后返回 dp[n-1]。

边界与复杂度

n=1 返回 1。候选相同（如 2×3 与 3×2 都生成 6）时必须同时前进，才不会输出重复值。

时间：O(n)
空间：O(n)

替代方案取舍

最小堆 + 去重集合可做但为 O(n log n) 且更占内存。因子固定只有 2、3、5，三指针 DP 更快也更直接。

常见错误

  • 只推进一个最小候选指针，导致重复 6、10、12。
  • 把 dp[0] 忘成 1。
  • 返回 dp[n] 造成越界。
  • 用 int 计算更大变体时忽略溢出；本题 1690 范围安全。

面试追问

若因子集合扩展？ 对 k 个质因子维护 k 个指针，或改用最小堆。
为什么不需要去重 set？ 相等候选同步推进已经消除了重复。

class Solution { public int nthUglyNumber(int n) { int[] dp = new int[n]; dp[0] = 1; int p2=0,p3=0,p5=0; for(int i=1;i<n;i++){int next=Math.min(2*dp[p2],Math.min(3*dp[p3],5*dp[p5]));dp[i]=next;if(next==2*dp[p2])p2++;if(next==3*dp[p3])p3++;if(next==5*dp[p5])p5++;}return dp[n-1];} }

class Solution:
    def nthUglyNumber(self, n: int) -> int:
        dp = [1] * n; p2 = p3 = p5 = 0
        for i in range(1, n):
            dp[i] = min(2*dp[p2], 3*dp[p3], 5*dp[p5])
            if dp[i] == 2*dp[p2]: p2 += 1
            if dp[i] == 3*dp[p3]: p3 += 1
            if dp[i] == 5*dp[p5]: p5 += 1
        return dp[-1]
