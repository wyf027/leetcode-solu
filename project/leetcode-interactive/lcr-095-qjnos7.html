最长公共子序列

在不改变字符相对顺序的前提下，找两个字符串共有的最长子序列长度。

中等

题意

给定字符串 text1 和 text2，返回它们最长公共子序列的长度。子序列通过删除若干字符得到，剩余字符的相对顺序不能改变。

示例

text1 = "abcde"
text2 = "ace"

输出：3（"ace"）

约束

  • 两个字符串长度均为 1 到 1000。
  • 仅由小写英文字母组成。
  • 只要求最长长度，不要求还原序列。

分步交互

从两个前缀开始想：最后一个字符相同与不相同，转移规则不同。

若 text1[i - 1] 与 text2[j - 1] 相同，dp[i][j] 如何转移？

若两个末尾字符不同，哪种状态更可靠？

dp[2][2]：比较 'b' 和 'c'

题解：前缀动态规划

洞察

dp[i][j] 表示 text1 前 i 个字符和 text2 前 j 个字符的最长公共子序列。末尾字符是否相同恰好给出完整的分类。

过程

  1. 建立 (m+1)×(n+1) 的 0 初始化表。
  2. 双层遍历所有前缀组合。
  3. 相同则取左上角加一。
  4. 不同则取上方与左方最大值。

边界

空前缀的结果是 0；下标 i、j 从 1 开始能避免处理首字符时的越界。

复杂度

时间 O(mn)，二维表空间 O(mn)；只求长度时可滚动数组优化为 O(n)。

替代方案

滚动一维数组节省空间，但更新顺序必须保留左上角旧值。

常见错误

将子序列与连续子串混淆；字符不同时错误地沿对角线转移。

追问

如何回溯出实际序列？怎样实现 O(n) 空间版本？

官方签名参考实现

// Java
class Solution { public int longestCommonSubsequence(String text1, String text2) { int m=text1.length(),n=text2.length(); int[][] dp=new int[m+1][n+1]; for(int i=1;i<=m;i++) for(int j=1;j<=n;j++) dp[i][j]=text1.charAt(i-1)==text2.charAt(j-1)?dp[i-1][j-1]+1:Math.max(dp[i-1][j],dp[i][j-1]); return dp[m][n]; } }
// JavaScript
var longestCommonSubsequence = function(text1, text2) { const dp=Array.from({length:text1.length+1},()=>Array(text2.length+1).fill(0)); for(let i=1;i<=text1.length;i++) for(let j=1;j<=text2.length;j++) dp[i][j]=text1[i-1]===text2[j-1]?dp[i-1][j-1]+1:Math.max(dp[i-1][j],dp[i][j-1]); return dp[text1.length][text2.length]; };
# Python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        dp = [[0] * (len(text2) + 1) for _ in range(len(text1) + 1)]
        for i, a in enumerate(text1, 1):
            for j, b in enumerate(text2, 1):
                dp[i][j] = dp[i-1][j-1]+1 if a == b else max(dp[i-1][j], dp[i][j-1])
        return dp[-1][-1]
// C++
