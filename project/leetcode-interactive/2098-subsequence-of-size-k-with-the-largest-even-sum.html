04 / 独立题解

展开后查看完整思路、交换实验和四语言代码。

先达到最大和，再修正奇偶性

核心洞察

任意 k 个位置按原下标排列都能形成子序列。只求和时，可以先排序选择最大的 k 个数，记它们的和为 S。S 是所有选择的上界；若它已经为偶数，直接返回。

若 S 为奇数，交换一个已选元素和一个未选元素，并让两者奇偶性不同，即可翻转总和的奇偶性。只比较两条路：移出最小偶数、移入最大奇数，以及移出最小奇数、移入最大偶数。

完整过程

  1. 复制数组并升序排序，选择最后 k 个元素。
  2. 累计 S，记录已选区各奇偶性的最小值 low，以及未选区各奇偶性的最大值 high。
  3. S 为偶数则返回 S；否则计算两类可行候选 S - low[p] + high[1-p]。
  4. 取候选最大值；两类都缺少交换元素时返回 -1。

交换实验室 / 奇偶两条通道

初始数据让两条路都可行。数字卡同时标记奇偶性和原下标；描边代表当前已选。两种交换分别从同一个初始选择出发。

正确性：为什么一次交换足够？

设 A 是最大的 k 个数构成的选择。对于任意其他选择 B，把 A 中移出的元素和 B 中加入的元素一一配对。由于 A 取的是最大 k 个数，每一对交换的损失都非负。

当 A 的和为奇数而 B 的和为偶数时，总损失为奇数，所以至少一对交换的损失是奇数，也就是该对元素奇偶性不同。单独执行这一对交换就能得到偶数和，其损失不大于所有交换的总损失，因此结果不小于 B。

固定移出元素的奇偶性，移出该类最小值、移入相反类最大值会使损失最小。比较两种移出奇偶性，就覆盖了最优单次交换，也就得到全局最优解。若两类交换均不存在，必要的异奇偶配对不可能存在，因此无解。

边界与常见错误

  • k = n：没有可换入元素，总和为奇数时只能返回 -1。
  • k = 1：结果是最大偶数；全奇数时无解。0 是合法偶数，不能用 0 标记不存在。
  • 重复数不能去重。全奇数数组在 k 为偶数时仍可行。
  • 必须恰好选择 k 个；只删除一个奇数会破坏长度要求。
  • 不能只考虑「奇换偶」；「偶换奇」可能损失更小。
  • 总和可达 10¹⁰，Java 使用 long，C++ 使用 long long。JavaScript Number 可精确表示本题总和，但不要对总和用 32 位位运算。
  • JavaScript sort 必须传数值比较器。若要返回实际子序列，需恢复原下标顺序。

复杂度

排序 O(n log n)，扫描 O(n)。下面四份实现都复制输入数组，额外空间 O(n)，两组极值只占 O(1)。如果允许原地排序，额外空间取决于语言的排序实现。

替代方案

按奇偶分组并降序排序，建立两组前缀和。枚举所选奇数数量 j = 0, 2, 4, …，只在奇数组能提供 j 个、偶数组能提供 k − j 个时比较前缀和。时间 O(n log n + k)，空间 O(n)，可行性更直观。

也可用 dp[count][parity] 保存恰好选 count 个元素的最大和，按选择数量倒序更新。时间 O(nk)、空间 O(k)，不适合本题最大规模，但方便扩展额外约束。

面试追问

  • 要返回子序列？排序时携带原下标，完成交换后按原下标输出。
  • 能比排序更快吗？选择算法划分最大 k 个数，再扫描极值；随机快速选择平均 O(n)，需说明最坏情况和重复值处理。
  • 如果允许负数？交换证明仍成立，但 -1 不能再作为通用不存在标记，返回协议也需重新约定。
  • 改为被 m 整除？一次交换的奇偶证明不能直接推广，可考虑按数量与模 m 余数做动态规划。

Java

import java.util.Arrays;

class Solution {
    public long largestEvenSum(int[] nums, int k) {
        int[] a = nums.clone();
        Arrays.sort(a);
        int n = a.length;
        int[] low = {Integer.MAX_VALUE, Integer.MAX_VALUE};
        int[] high = {-1, -1};
        long sum = 0;
        for (int i = 0; i < n; i++) {
            int x = a[i], p = x % 2;
            if (i >= n - k) {
                sum += x;
                low[p] = Math.min(low[p], x);
            } else {
                high[p] = Math.max(high[p], x);
            }
        }
        if (sum % 2 == 0) return sum;
        long ans = -1;
        for (int p = 0; p < 2; p++) {
            if (low[p] != Integer.MAX_VALUE && high[1-p] != -1)
                ans = Math.max(ans, sum - low[p] + high[1-p]);
        }
        return ans;
    }
}

class Solution:
    def largestEvenSum(self, nums: List[int], k: int) -> int:
        a = sorted(nums)
        low = [float("inf"), float("inf")]
        high = [-1, -1]
        total = 0
        for i, x in enumerate(a):
            p = x % 2
            if i >= len(a) - k:
                total += x
                low[p] = min(low[p], x)
            else:
                high[p] = max(high[p], x)
        if total % 2 == 0:
            return total
        ans = -1
        for p in range(2):
            if low[p] != float("inf") and high[1-p] != -1:
                ans = max(ans, total - low[p] + high[1-p])
        return ans
