各位数字之和

Sum of Digits of String After Convert

字符串模拟先观察规则，再展开题解。

01 / 题目

输入小写英文字母字符串 s 和整数 k。把每个字母换成它在字母表中的序号（a → 1，b → 2，…，z → 26），按原顺序拼接。然后把当前数替换为它的十进制各位数字之和，共执行 k 轮求和，返回最终整数。

字母转成数字的过程不计入 k；k 只统计“各位数字求和”的次数。

参数与返回值

getLucky(s: string, k: integer) → integer

约束

  • 1 ≤ s.length ≤ 100
  • 1 ≤ k ≤ 10
  • s 仅含小写英文字母。

官方示例

示例 1

s = "iiii", k = 1

输出：36

i → 9；拼成 9999。第一轮：9 + 9 + 9 + 9 = 36。

示例 2

s = "leetcode", k = 2

输出：6

映射为 12, 5, 5, 20, 3, 15, 4, 5；拼成 12552031545。第一轮得到 33，第二轮 3 + 3 = 6。

示例 3

s = "zbax", k = 2

输出：8

映射为 26, 2, 1, 24；拼成 262124。第一轮得到 17，第二轮 1 + 7 = 8。

04 / 独立题解

准备好后，再查看推导与四语言实现。

核心洞察：跳过大整数拼接

求拼接后整数的数位和，等价于把每个字母序号的数位和相加。序号 v 在 1 到 26 之间，其贡献恰好是 ⌊v / 10⌋ + v % 10。例如 z → 26 贡献 8，而不是 26。

完整过程

  1. 遍历 s，令 v = 字母 - 'a' + 1，将序号的十位与个位加入 total。这已经完成第 1 轮求和。
  2. 再执行 k - 1 轮。每轮令 next = 0；不断取 total % 10 加到 next，再用整除 10 去掉末位。
  3. 本轮结束时用 next 替换 total。完成指定轮数后返回 total。

以 s = "zbax", k = 2 为例：首轮直接累加 (2 + 6) + 2 + 1 + (2 + 4) = 17；剩下一轮得到 1 + 7 = 8。演示区保留完整数位是为了观察规则；提交代码不需要保存这些数位。

正确性

首先，拼接不会改变任一序号内部的数字，也不会额外引入数字。因此逐个序号求数位和再相加，与完整拼接串的第 1 轮求和相等。其次，每轮内循环每次取出一个末位并删除它，next 始终等于已删除数位之和；结束时所有数位恰好被处理一次，next 就是当前整数的数位和。以第 1 轮为归纳起点，后续每轮都保持 total 等于题目规定的该轮结果。再执行 k − 1 轮后返回的就是第 k 轮结果。

边界与复杂度

  • k = 1 时直接返回首轮结果；结果可以是多位数，例如 36。
  • a 的序号是 1；j、t 的序号中有 0，它们的零位贡献为 0。
  • 最大单个贡献为 10（s → 19），所以首轮 total ≤ 10n ≤ 1000，不会产生大整数问题。
  • 单位数再次求和不变，可提前退出，也可按代码继续执行剩余轮数。
  • 设 n = s.length。通用保守时间界为 O(n + k log(n + 1))，额外空间 O(1)。在本题 n ≤ 100 的约束下，首轮后每轮最多处理 4 位，可写为 O(n + k)。这里指提交代码，演示保留步骤快照会额外占用空间。

替代方案

可以把每个序号作为字符串拼接，再逐字符累加，之后重复转换。这种方法更贴近题意，但需 O(n) 额外空间；不要将最长 200 位的拼接串直接转为普通数值类型。数字根公式只能描述反复求和至稳定的结果，不能直接替代固定 k 轮，例如 "iiii", k = 1 应返回 36，而不是 9。

常见错误

  • 把所有字母的序号直接相加，忘记两位数还需拆成数位。
  • 把字母映射算进 k，或已完成首轮后又额外执行 k 轮。
  • 一直求和到个位数，忽略指定轮数。
  • 每轮忘记将 next 清零；JavaScript 使用 / 后忘记向下取整。
  • 把拼接串转成 Number / int，导致精度丢失或溢出。

面试追问

如果 k 极大？在 total < 10 时提前结束，因为之后不变。如果 s 来自流？每次只累加新字母的数位贡献，不必保存整个输入。如果序号不止两位？对序号执行通用取余整除循环，不能继续使用仅拆十位与个位的公式。

Java

class Solution {
    public int getLucky(String s, int k) {
        int total = 0;
        for (int i = 0; i < s.length(); i++) {
            int v = s.charAt(i) - 'a' + 1;
            total += v / 10 + v % 10;
        }
        for (int round = 1; round < k; round++) {
            int next = 0;
            while (total > 0) {
                next += total % 10;
                total /= 10;
            }
            total = next;
        }
        return total;
    }
}

JavaScript

/**
 * @param {string} s
 * @param {number} k
 * @return {number}
 */
var getLucky = function(s, k) {
    let total = 0;
    for (const ch of s) {
        const v = ch.charCodeAt(0) - 96;
        total += Math.floor(v / 10) + v % 10;
    }
    for (let round = 1; round < k; round++) {
        let next = 0;
        while (total > 0) {
            next += total % 10;
            total = Math.floor(total / 10);
        }
        total = next;
    }
    return total;
};

class Solution:
    def getLucky(self, s: str, k: int) -> int:
        total = 0
        for ch in s:
            v = ord(ch) - ord('a') + 1
            total += v // 10 + v % 10
        for _ in range(k - 1):
            next_sum = 0
            while total > 0:
                next_sum += total % 10
                total //= 10
            total = next_sum
        return total

#include <string>

class Solution {

    int getLucky(string s, int k) {
        int total = 0;
        for (char ch : s) {
            int v = ch - 'a' + 1;
            total += v / 10 + v % 10;
        }
        for (int round = 1; round < k; ++round) {
            int next = 0;
            while (total > 0) {
                next += total % 10;
                total /= 10;
            }
            total = next;
        }
        return total;
    }
};
