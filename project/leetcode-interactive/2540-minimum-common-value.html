最小公共值

Minimum Common Value

两列有序数字，寻找它们最早的交点。

01 / 读题

在两个数组中都出现

给定按非降序排列的整数数组 nums1 和 nums2，返回它们共有的最小整数。如果没有任何公共整数，返回 -1。同一个值只要在两边各出现至少一次，就算公共值，重复次数不影响答案。

官方示例 1

nums1 = [1,2,3]
nums2 = [2,4]

输出：2

两边共有的最小值是 2。

官方示例 2

nums1 = [1,2,3,6]
nums2 = [2,3,4,5]

输出：2

公共值有 2 和 3，其中最小的是 2。

约束

  • 1 ≤ nums1.length, nums2.length ≤ 105
  • 1 ≤ nums1[i], nums2[j] ≤ 109
  • 两个数组均已按非降序排列，允许重复元素。

函数：getCommon(nums1, nums2) → 整数

04 / 独立题解

想清楚后，再揭晓

展开查看思路、证明与四种语言的完整实现。

核心洞察：只移动较小的一边

用 i、j 分别指向两列当前最小的未处理值。若 nums1[i] < nums2[j]，那么 nums2 后面的数只会更大，不可能与 nums1[i] 相等，因此可以安全地丢弃 nums1[i]。反过来同理。相等时直接返回。

完整过程

  1. 令 i = 0, j = 0，从两个数组的开头出发。
  2. 只要两个指针都没有越界，就比较当前两个值。
  3. 相等：返回该值；左边小：i++；右边小：j++。
  4. 任意一个数组耗尽仍未相等，返回 -1。

以 [1,3,5,8] 与 [2,4,5,9] 为例，比较顺序为 (1,2) → (3,2) → (3,4) → (5,4) → (5,5)。依次排除 1、2、3、4，首次相等于 5。

正确性：排除不会丢掉答案

不变量：每次比较前，所有尚可能成为公共值的匹配，都保留在两个未处理后缀中。初始后缀就是完整数组，显然成立。

设当前左值 x 小于右值 y。右后缀中每个值都 ≥ y > x，所以 x 不可能与右后缀匹配；此前排除的值也已被证明不能构成答案。因此移动左指针不会丢失公共值。不变量得以保持。右值较小时完全对称。

当 x = y 时，它们是各自未处理后缀的最小值。已排除部分不含答案，剩余部分又不含比它更小的值，因此首次相等的值就是全局最小公共值。若任一后缀为空，则不存在剩余匹配，只能返回 -1。每轮至少一个指针前进，因此算法必然终止。

边界与复杂度

  • 重复值不需预先去重；相等立即返回，重复次数无关。
  • 单元素数组、首项相等、末项才相等、完全无交集均由同一循环处理。
  • 题目不允许空数组；循环条件也自然支持空数组并返回 -1。
  • 值上界为 109，四份实现的数值类型都足够，不需要做加法或乘法。

设两数组长度分别为 m、n。最坏时间为 O(m + n)，额外空间为 O(1)；若第一项就相等，时间为 O(1)。代码不修改输入。交互页面为回放保存步骤，属于演示开销，不计入算法的 O(1) 空间。

替代方案

  • 哈希集合：把一边放入集合，按升序遍历另一边，第一次命中即可返回。期望 O(m+n) 时间，O(m) 额外空间；本题已有序，双指针更省空间。
  • 二分查找：按升序遍历较短数组，在较长数组中二分寻找每个值。时间 O(min(m,n) · log max(m,n))，额外空间 O(1)，适合长度差距很大的情况。

常见错误

  • 移动较大值的指针：可能跳过本能与较小序列后续元素匹配的值。
  • 不相等时同时移动两个指针：例如 [1,2] 和 [2,3] 会错过公共值 2。
  • 循环使用逻辑“或”：一个指针耗尽后仍读数组，会越界。
  • 发现相等还继续覆盖结果：可能最终得到较大的公共值。
  • 忽略有序前提：未排序数组不能直接用这个排除逻辑。

面试追问

  • 数组无序怎么办？可用集合并扫描所有匹配取最小值，或先排序再用双指针，明确排序是否允许修改输入。
  • 要求所有不重复公共值？相等时记录并跳过两边该值的重复项，然后继续。
  • 输入是有序数据流？每个流只保留一个当前值，推进较小的流，仍可常量空间处理。
  • 长度极不均衡？比较线性扫描和对短数组逐项二分的成本；二分需要可随机访问的长数组。

Java

class Solution {
    public int getCommon(int[] nums1, int[] nums2) {
        int i = 0, j = 0;
        while (i < nums1.length && j < nums2.length) {
            if (nums1[i] == nums2[j]) return nums1[i];
            if (nums1[i] < nums2[j]) i++;
            else j++;
        }
        return -1;
    }
}
