查询无效交易Invalid Transactions

给你一组格式为 name,time,amount,city 的交易记录。找出所有金额异常，或与同名异地交易在 60 分钟内发生关联的记录；返回顺序不限。

Problem brief

何时判为可能无效？

每条记录只要命中任意一条规则，就必须进入结果；两条规则是“或”的关系。

$

金额越界

交易金额严格超过 1000。金额恰好为 1000 不命中此规则。

Δ

同名、异地、近时

存在另一笔同名交易，城市不同，并且时间差绝对值 ≤ 60 分钟；边界 60 分钟也算。

Solution

两两核验，标记原记录

先解析，再把每一种无效来源合并进同一个布尔标记数组。

核心洞察

一条交易的无效性是“存在性”判断。金额规则只依赖自身；城市规则需要找到至少一条满足三个条件的伙伴。数据规模最多 1000，直接检查所有交易对足够清楚，也与约束匹配。

关键细节：一对交易命中关联规则时，两端都要标记，而不是只标记后出现的一条。

完整过程

  1. 拆出姓名、时间、金额、城市，同时保留原字符串和下标。
  2. 金额大于 1000 时标记当前下标。
  3. 枚举每一对 i < j；若同名、异地且时间差不超过 60，同时标记 i、j。
  4. 按原数组顺序收集所有被标记记录。

正确性证明

  1. 金额规则无遗漏。算法逐条检查所有记录，金额大于 1000 的记录必被标记。
  2. 关联规则无遗漏。任意两条不同记录都对应唯一一组 i < j；满足三个条件时，两端同时被标记。
  3. 没有误报。标记只发生在金额规则成立或关联规则三个条件同时成立时，恰好对应题目定义。
  4. 因此最终集合与全部可能无效交易完全一致。

边界与复杂度

  • 金额等于 1000 不命中；使用 > 1000。
  • 时间差等于 60 仍命中；使用 ≤ 60。
  • 同名同城不会触发关联规则，即使时间相同。
  • 重复字符串仍是不同数组记录，应按下标标记。
时间O(n²)
额外空间O(n)

替代方案

可以按姓名分组后按时间排序，只在同名组的时间窗口内比较城市。它减少不同姓名间的无关比较，但同名记录密集时最坏情况仍可能是 O(n²)。在 n ≤ 1000 时，直接两两比较更清楚、稳妥。

面试追问

  • 若输入是持续到来的流，如何维护最近 60 分钟的同名交易？
  • 若结果要求去重，应按数组下标还是字符串值？两者语义有何差别？
  • 若时间上界取消，怎样用分组排序或滑动窗口改善平均表现？
Pitfalls

常见错误

把“超过 1000”误写成“大于等于 1000”。
忘记对时间差取绝对值，只检查一个方向。
交易对命中后只标记其中一端。
只要同名异地就标记，遗漏 60 分钟限制。
使用字符串集合，意外合并输入里的重复记录。
返回重新拼接的字符串而非原字符串，引入格式差异。

四语言完整代码

均采用 O(n²) 两两标记思路，并保留官方可提交函数签名。

JavaLeetCode 提交格式
import java.util.*;

class Solution {
    public List<String> invalidTransactions(String[] transactions) {
        int n = transactions.length;
        String[] names = new String[n];
        int[] times = new int[n];
        int[] amounts = new int[n];
        String[] cities = new String[n];
        boolean[] invalid = new boolean[n];

        for (int i = 0; i < n; i++) {
            String[] parts = transactions[i].split(",");
            names[i] = parts[0];
            times[i] = Integer.parseInt(parts[1]);
            amounts[i] = Integer.parseInt(parts[2]);
            cities[i] = parts[3];
            if (amounts[i] > 1000) invalid[i] = true;
        }

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (names[i].equals(names[j])
                        && !cities[i].equals(cities[j])
                        && Math.abs(times[i] - times[j]) <= 60) {
                    invalid[i] = true;
                    invalid[j] = true;
                }
            }
        }

        List<String> answer = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (invalid[i]) answer.add(transactions[i]);
        }
        return answer;
    }
}
JavaScriptLeetCode 提交格式
/**
 * @param {string[]} transactions
 * @return {string[]}
 */
var invalidTransactions = function(transactions) {
    const parsed = transactions.map((raw) => {
        const [name, time, amount, city] = raw.split(',');
        return { name, time: Number(time), amount: Number(amount), city };
    });
    const invalid = parsed.map((tx) => tx.amount > 1000);

    for (let i = 0; i < parsed.length; i++) {
        for (let j = i + 1; j < parsed.length; j++) {
            const a = parsed[i];
            const b = parsed[j];
            if (a.name === b.name
                    && a.city !== b.city
                    && Math.abs(a.time - b.time) <= 60) {
                invalid[i] = true;
                invalid[j] = true;
            }
        }
    }
    return transactions.filter((_, index) => invalid[index]);
};
Python 3LeetCode 提交格式
from typing import List


class Solution:
    def invalidTransactions(self, transactions: List[str]) -> List[str]:
        parsed = []
        for raw in transactions:
            name, time, amount, city = raw.split(",")
            parsed.append((name, int(time), int(amount), city))

        invalid = [tx[2] > 1000 for tx in parsed]

        for i in range(len(parsed)):
            for j in range(i + 1, len(parsed)):
                name_i, time_i, _, city_i = parsed[i]
                name_j, time_j, _, city_j = parsed[j]
                if (name_i == name_j
                        and city_i != city_j
                        and abs(time_i - time_j) <= 60):
                    invalid[i] = True
                    invalid[j] = True

        return [
            raw
            for index, raw in enumerate(transactions)
            if invalid[index]
        ]
C++LeetCode 提交格式
class Solution {
    struct Tx {
        string name;
        int time;
        int amount;
        string city;
    };

    Tx parse(const string& raw) {
        vector<string> parts;
        string part;
        stringstream input(raw);
        while (getline(input, part, ',')) parts.push_back(part);
        return {parts[0], stoi(parts[1]), stoi(parts[2]), parts[3]};
    }

public:
    vector<string> invalidTransactions(vector<string>& transactions) {
        int n = static_cast<int>(transactions.size());
        vector<Tx> parsed;
        vector<bool> invalid(n, false);
        parsed.reserve(n);

        for (int i = 0; i < n; ++i) {
            parsed.push_back(parse(transactions[i]));
            if (parsed.back().amount > 1000) invalid[i] = true;
        }

        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                if (parsed[i].name == parsed[j].name
                        && parsed[i].city != parsed[j].city
                        && abs(parsed[i].time - parsed[j].time) <= 60) {
                    invalid[i] = true;
                    invalid[j] = true;
                }
            }
        }

        vector<string> answer;
        for (int i = 0; i < n; ++i) {
            if (invalid[i]) answer.push_back(transactions[i]);
        }
        return answer;
    }
};
