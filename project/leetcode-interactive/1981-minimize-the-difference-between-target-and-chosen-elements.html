最小化目标值
与所选元素的差

Minimize the Difference Between Target and Chosen Elements

每一行，做一次选择。最终的总和，能离目标多近？

前往官方题目 ↗

01 / 题目

给定一个 m × n 的整数矩阵 mat 和整数 target。你必须从每一行恰好选出一个元素，将这 m 个元素相加得到 sum。返回所有合法选择中最小的 |sum − target|。

不同的行可以选择不同列；返回的是差值，不是总和，也不是选择方案。

参数与约束

  • mat: integer[][]，target: integer，返回 integer。
  • m == mat.length，n == mat[i].length。
  • 1 ≤ m, n ≤ 70。
  • 1 ≤ mat[i][j] ≤ 70。
  • 1 ≤ target ≤ 800。

02 / 官方示例

示例 1 · 恰好命中

mat = [[1,2,3],[4,5,6],[7,8,9]]
target = 13
输出：0

各行分别选 1、5、7，总和为 13，绝对差为 0。

示例 2 · 每行只有一个候选

mat = [[1],[2],[3]]
target = 100
输出：94

只能选 1、2、3，总和为 6，因此返回 |6 − 100| = 94。

示例 3 · 单行选择

mat = [[1,2,9,8,7]]
target = 6
输出：1

选择 7，与目标 6 相差 1。

04 / 独立题解

准备好后，再展开推导与交互实验。

核心洞察：保留“和”，合并重复路径

选择路径可能有 n 的 m 次方种，但每个元素最多为 70，总和最多为 S = 70m ≤ 4900。处理完相同行数后，只要总和相同，之后可选的行也相同，所以不必区分之前的选择路径。

用 dp[s] 表示：从已处理的每行恰好选择一个元素后，能否得到总和 s。初始只有 dp[0] = true。每处理一行，创建一个全新的空状态；对旧状态中的每个和 s，以及本行每个值 x，标记 next[s + x] = true。整行完成后才用 next 替换 dp。

完整过程

  1. 设 S = 70m，分配长度 S + 1 的布尔数组，仅让 dp[0] 为真。
  2. 逐行创建空 next；枚举所有可达 s，再枚举该行的每个值 x，将 s + x 加入 next。
  3. 用 next 替换 dp，确保每行只贡献一个元素，而且没有任何行被跳过。
  4. 所有行处理完，再遍历最终可达和，求最小 |s − target|。

示例 1 的层次：{0} → {1,2,3} → {5,6,7,8,9} → {12,13,14,15,16,17,18}。最终包含 13，因此答案为 0。

正确性证明

不变式：处理完前 i 行后，dp 恰好记录从这 i 行中各选一个元素能得到的所有总和。

初始：未处理任何行时，空选择的和是 0，只有 dp[0] 为真，成立。

保持：旧状态 s 来自前 i 行的合法选择，将下一行任一元素 x 加入就得到合法总和 s + x，所以不会引入非法状态。反过来，任意前 i + 1 行的合法选择都可拆成前 i 行的和 s 与最后一行的值 x；归纳假设保证 s 已被记录，转移也必会记录 s + x，所以不会遗漏。

终止：处理完 m 行后，dp 恰好覆盖所有合法总和，取这些总和与目标的最小绝对差，就是题目要求的最优值。

边界与复杂度

  • 单行退化为寻找距离 target 最近的元素；单列只有一种合法总和。
  • 重复值只会重复标记同一个状态，不影响正确性。
  • 目标可能在所有总和之外；必须允许最终总和大于 target。
  • 最大总和为 4900，数组必须含下标 4900，即长度 S + 1。
  • 令 S = 70m。时间为 O(mnS)，包含每行的扫描与转移；滚动数组额外空间为 O(S)。四份代码使用同一算法。

替代方案

集合 DP 可直接维护 {s + x}，只遍历可达状态，代码简洁但有哈希开销。位集可用移位与按位或合并状态，通常更快；大整数移位的成本仍随位数增长，不能当作 O(1)。暴力 DFS 有 O(n^m) 条路径，适合解释或很小的输入。

因为值全为正，还可保留所有不超过 target 的状态，并只保留超过 target 的最小状态：任意更大的超目标和在加入相同后续选择后仍更差。这需要额外的支配关系证明，本页代码保留完整状态以便直观理解。

常见错误

  • 在原数组中不断追加状态，导致同一行被选多次；应使用全新的 next。
  • 把旧 dp 合并进 next，等于允许跳过当前行。
  • 只保留 ≤ target 的总和；例如 [[7]]、target = 6 会丢掉唯一合法答案。
  • 每行贪心选当前最接近目标的数；后续还有必须选的正数。
  • 中途发现总和等于 target 就返回 0；尚未处理的行仍必须贡献元素。

面试追问

  • 如何恢复选择方案？ 为每层第一次到达的状态记录前驱总和及列号，再从最优终点回溯，空间上升为 O(mS)。
  • 有负数怎么办？ 用集合或带偏移的数组维护可达和，重新计算范围；正数前提下的超目标剪枝不再成立。
  • 只求是否命中 target 呢？ 最后一层检查 dp[target]；在本题正数条件下可丢弃超过 target 的状态。
  • 如何降低常数？ 去重每行元素、缩小每层遍历范围，或使用位集；先保持每行独立转移的语义。

Java

class Solution {
    public int minimizeTheDifference(int[][] mat, int target) {
        int limit = 70 * mat.length;
        boolean[] dp = new boolean[limit + 1];
        dp[0] = true;
        for (int[] row : mat) {
            boolean[] next = new boolean[limit + 1];
            for (int s = 0; s <= limit; s++) {
                if (!dp[s]) continue;
                for (int x : row) {
                    if (s + x <= limit) next[s + x] = true;
                }
            }
            dp = next;
        }
        int answer = Integer.MAX_VALUE;
        for (int s = 0; s <= limit; s++) {
            if (dp[s]) answer = Math.min(answer, Math.abs(s - target));
        }
        return answer;
    }
}

Python

from typing import List

class Solution:
    def minimizeTheDifference(self, mat: List[List[int]], target: int) -> int:
        limit = 70 * len(mat)
        dp = [False] * (limit + 1)
        dp[0] = True
        for row in mat:
            nxt = [False] * (limit + 1)
            for s in range(limit + 1):
                if not dp[s]:
                    continue
                for x in row:
                    if s + x <= limit:
                        nxt[s + x] = True
            dp = nxt
        return min(abs(s - target) for s in range(limit + 1) if dp[s])

C++

#include <vector>
#include <algorithm>
#include <cstdlib>
#include <climits>
using namespace std;

class Solution {
public:
    int minimizeTheDifference(vector<vector<int>>& mat, int target) {
        int limit = 70 * static_cast<int>(mat.size());
        vector<bool> dp(limit + 1, false);
        dp[0] = true;
        for (const auto& row : mat) {
            vector<bool> next(limit + 1, false);
            for (int s = 0; s <= limit; ++s) {
                if (!dp[s]) continue;
                for (int x : row) {
                    if (s + x <= limit) next[s + x] = true;
                }
            }
            dp.swap(next);
        }
        int answer = INT_MAX;
        for (int s = 0; s <= limit; ++s) {
            if (dp[s]) answer = min(answer, abs(s - target));
        }
        return answer;
    }
};
