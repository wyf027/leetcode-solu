找出数组的串联值

Find the Array Concatenation Value

数组 双指针 模拟
01 先读题

从两端向中间，依次拼起来

下面只描述规则，不提前揭示实现方式。先用示例建立对“串联”的直觉。

给定一个下标从 0 开始的整数数组 nums。

两个数字的串联，是把它们的十进制数字依次接在一起形成的新数字。例如， 15 与 49 串联后得到 1549。

串联值初始为 0。当数组至少还有两个元素时，取首元素和尾元素，按“首在前、尾在后”串联，将结果累加到串联值，并移除这两个元素。如果最后只剩一个元素，就直接把它加到串联值。

重复操作直到数组为空，返回最终串联值。

约束

  • 1 <= nums.length <= 1000
  • 1 <= nums[i] <= 104

示例 1

输入 nums = [7,52,2,4]
输出 596
解释 7 ⧺ 4 = 74，52 ⧺ 2 = 522，总和为 74 + 522 = 596。

示例 2

输入 nums = [5,14,13,8,12]
输出 673
解释 5 ⧺ 12 = 512，14 ⧺ 8 = 148，中间剩下 13；总和为 512 + 148 + 13 = 673。

    准备好再揭晓

    Solution · Two Pointers

    双指针同步收拢

    数组的移除顺序已经由题目固定，因此无需真的删除元素：用两个下标表示尚未处理的左右边界即可。

    ✦

    核心洞察

    令 left 指向首端、right 指向尾端。当 left < right 时，把两个数转成十进制字符串后拼接，再转回整数累加；两指针同时向中间移动。若最终 left === right，只累加中间元素。

    完整过程

    1. 初始化 left = 0、right = nums.length - 1、answer = 0。
    2. 当 left < right，计算 nums[left] ⧺ nums[right] 并累加。
    3. 执行 left++ 与 right--，继续处理下一层。
    4. 若两指针在一个元素相遇，将该元素直接加入答案。
    5. 返回 answer。

    边界处理

    • 只有一个元素：循环不进入，直接累加中心元素。
    • 偶数长度：所有元素恰好成对，循环后 left > right。
    • 奇数长度：最后 left === right，中心元素不能遗漏。
    • 方向固定：必须是左元素在前、右元素在后，次序不可交换。

    正确性证明

    循环不变式：每次循环开始前，answer 恰好等于题目规则对数组最外侧、已经处理过的所有元素产生的串联值之和；区间 [left, right] 恰好包含所有尚未处理的元素。

    初始时尚未处理任何元素，answer = 0，不变式成立。一次循环把当前首尾元素按规定顺序串联并累加，再将左右边界各向内移动一格，因此新答案与新未处理区间仍满足不变式。循环结束时：若区间为空，所有元素均已按规则处理；若只剩中心元素，额外将它直接累加也与题目规则一致。故返回值必为数组的串联值。

    时间复杂度O(n)，每个元素只处理一次
    额外空间O(1)，忽略短字符串转换空间

    替代方案

    可以纯数学计算串联值：若右侧数字 b 有 d 位，则串联结果为 a × 10^d + b。它避免字符串转换，但必须正确计算位数；在本题范围内，两种方式都足够高效。

    也可真的维护队列并反复删除两端，但没有必要复制或搬移数组；双指针更直接。

    常见错误

    • 把尾元素放在前面，算成 right ⧺ left。
    • 奇数长度时漏掉中间元素，或重复累加它。
    • 循环条件写成 left <= right，却仍按一对元素处理中心位置。
    • 在 JavaScript 中使用 + 拼接后忘记转回数值。

    面试追问

    • 如果元素允许为 0，数学位数计算应如何处理？
    • 如果数字非常长、超过 64 位整数范围，应使用什么表示？
    • 如何在不做字符串转换的前提下完成串联？
    • 若每次取的是当前最小值与最大值，数据结构应怎样变化？

    数学版本提示

    对正整数 b，可以循环乘 10 得到最小的 power，使 power > b，随后计算 a × power + b。题目保证 nums[i] >= 1，无需额外处理零位数。

    四语言完整实现

    Java

    官方签名
    class Solution {
    public long findTheArrayConcVal(int[] nums) {
        int left = 0;
        int right = nums.length - 1;
        long answer = 0;

        while (left < right) {
            String joined = String.valueOf(nums[left])
                    + nums[right];
            answer += Long.parseLong(joined);
            left++;
            right--;
        }

        if (left == right) {
            answer += nums[left];
        }
        return answer;
    }
}
