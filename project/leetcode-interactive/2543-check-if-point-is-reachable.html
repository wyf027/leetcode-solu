(2x, y)

(x, 2y)

从路径搜索，到数的共同结构

核心洞察

令 g = gcd(targetX, targetY)。可到达的充要条件是 g 是 2 的非负整数次幂，包括 1 = 2⁰。也就是：不断除去 g 中的因子 2，最后必须只剩 1。

减法保留最大公约数；单个坐标翻倍只可能让公约数保持不变或翻倍。因此，真正始终不变的是公约数的奇数部分。

交互 / 余数压缩机 → 因子剥离机

逐帧展示欧几里得取余，再逐次除去因子 2。条形长度按当前帧最大值归一化；这是判定算法的状态，不是网格上的移动路径。

完整算法过程

  1. 用欧几里得算法计算 g：重复 (a, b) ← (b, a % b)，直到 b 为 0，此时 a 即最大公约数。
  2. 只要 g 为偶数，就令 g ← g / 2。
  3. 返回 g == 1。例如 (6, 9) 得到 3，返回 false；(4, 7) 得到 1，返回 true；(12, 20) 得到 4 → 2 → 1，返回 true。

正确性 · 为什么既必要又充分？

必要性。对每个奇素数 p，记录两个坐标中 p 的公共指数，即两者指数的较小值。减去另一个坐标保持 gcd；一个坐标乘 2 不改变任何奇素数指数。因此 gcd 的奇数部分不变。起点的 gcd 为 1，所以目标 gcd 不能含任何奇素因子。即便路径经过零或负数，这个结论对坐标绝对值的 gcd 仍成立。

充分性。反向看合法移动：可以给一个坐标加上另一个坐标，或把偶数坐标除以 2。设目标 gcd 的奇数部分为 1。先把两个坐标各自除去所有因子 2，得到正奇数 a、b，且 gcd(a,b)=1。

若 a=b，则互质性说明 a=b=1。否则不妨 a>b，先反向加法得到 (a+b,b)，再把第一个坐标除以 2，得到 ((a+b)/2,b)。新坐标严格小于 a；继续除去它的因子 2，仍保持正数和互质性。对另一侧较大的情况同理。每轮坐标和严格下降，所以有限轮后必到达 (1,1)。把这些反向步骤倒过来，就是从起点到目标的合法原方向路径。

实现对应。取余循环保持 gcd，且非零余数严格变小，因此终止并求出 g；因子剥离恰好留下其奇数部分。最终判定与充要条件完全一致。

边界与复杂度

  • g=1 已满足条件，剥离循环执行零次；起点无需移动。
  • 相等坐标 (k,k) 可达当且仅当 k 是 2 的幂；两个坐标都是偶数并不足够。
  • 输入始终为正，g 不会为 0。不要把这段剥离循环直接用于 (0,0)，否则不会终止。
  • 令 M=max(targetX,targetY)。总时间 O(log M)，额外空间 O(1)。这里按固定宽度整数运算计费。
  • 主算法不计算坐标和或倍增，不会产生超出输入范围的中间整数。JavaScript 的 Number 能精确表示本题范围内的整数。

替代方案

求出 g 后，可用 (g & (g - 1)) == 0 判定 2 的幂（需保证 g>0）。本题 g≤10⁹，JavaScript 的 32 位位运算也适用；扩展到更大整数时应改用 BigInt 或连续除 2。还可按充分性证明做反向归约，适合构造路径；只要布尔结果时，gcd 更直接。无限网格上的 BFS 缺少自然边界，既费空间又难以可靠判定不可达。

Java

class Solution {
    public boolean isReachable(int targetX, int targetY) {
        int a = targetX, b = targetY;
        while (b != 0) {
            int r = a % b;
            a = b;
            b = r;
        }
        while (a % 2 == 0) a /= 2;
        return a == 1;
    }
}

常见错误

  • 只判断 gcd==1，遗漏 gcd=2、4、8 等可达目标。
  • 认为任意偶数 gcd 都可以，遗漏其中的奇因子，如 gcd=6。
  • 反向使用减法证明可达；原方向减法的逆操作实际是加法。
  • 只证明必要性就直接下结论；必须说明所有 gcd 为 2 的幂的目标都能构造路径。
  • 用浮点对数判断 2 的幂，给边界带来不必要的舍入风险。

面试追问

需要返回实际路径？记录充分性证明中的反向加法和除 2，然后逆序、逐步求逆；若要求最短路径，当前判定和构造均不保证最短。

翻倍改为乘某个素数 p？可以继续研究 gcd 去除 p 因子后的不变量，但充分性需要重新证明，不能照搬二进制情形的奇数相加再除 2。

目标扩展到 10¹⁸？使用足够宽的整数表示；JavaScript 用 BigInt，并统一常量为 0n、1n、2n，避免与 Number 混算。
