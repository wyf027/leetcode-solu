子数组最大平均数 I

给定整数数组 nums 和整数 k，在所有长度恰好为 k 的连续子数组中，返回最大的平均数。答案误差小于 10-5 即可。

01 · Problem

题目说明

这里的“子数组”必须连续，而且长度必须正好等于 k。

任务

给你一个含 n 个整数的数组 nums 与一个整数 k。找出平均值最大的、长度恰好为 k 的连续片段，返回这个最大平均值。

返回值是平均数，而不是子数组本身或它的起止下标。允许的计算误差小于 10-5。

约束

  • n == nums.length
  • 1 ≤ k ≤ n ≤ 105
  • -104 ≤ nums[i] ≤ 104

示例 1

输入：nums = [1,12,-5,-6,50,3], k = 4
输出：12.75000
解释：(12 - 5 - 6 + 50) / 4
     = 51 / 4
     = 12.75

示例 2

输入：nums = [5], k = 1
输出：5.00000

04 · Solution

滑动窗口：只更新变化的两端

窗口长度固定，所以比较平均数等价于比较窗口和；遍历结束后只做一次除法。

核心洞察

相邻两个长度为 k 的窗口，重叠了 k - 1 个元素。右移一格时，无需重新累加全部元素：从当前和减去左端离开的数，再加上右端新进入的数即可。

完整过程

  1. 求前 k 项之和，作为 windowSum 与 maxSum。
  2. 令右端从下标 k 开始向后移动。
  3. 执行 windowSum += nums[right] - nums[right-k]。
  4. 用新的 windowSum 更新 maxSum。
  5. 返回 maxSum / k。

正确性证明

初始化正确。 第一次计算的和覆盖且仅覆盖下标 0..k-1，即第一个合法窗口。

转移正确。 假设当前和对应窗口 [i-k, i-1]。减去 nums[i-k]、加上 nums[i] 后，和恰好对应下一个窗口 [i-k+1, i]。

覆盖完整。 右端下标从 k 遍历到 n-1，连同初始窗口，所有 n-k+1 个合法窗口各被考察一次。

结论。 maxSum 是所有合法窗口和的最大值。因 k > 0 且所有窗口长度相同，除以 k 后仍保持大小关系，因此返回值就是最大平均数。

边界情况

  • k = 1：答案就是数组最大元素。
  • k = n：只有一个合法窗口。
  • 全为负数：maxSum 必须从首个窗口初始化，不能写成 0。
  • 大数值：约束下窗口和绝对值至多 10⁹，四种实现使用的整数范围足够。

复杂度

时间：O(n)。每个元素最多常数次参与加减。

额外空间：O(1)。只维护窗口和与最大和。

替代方案

可以先构造前缀和，再用 prefix[i+k] - prefix[i] 得到每个窗口和，时间同为 O(n)，但额外空间为 O(n)。若每次重算 k 项，则最坏时间为 O(nk)。

面试追问

  • 若窗口长度不是固定值，问题会如何变化？
  • 若数据以流的方式到达，怎样保存最近 k 项？
  • 为何本题不需要对答案做二分？

常见错误

  • 把“长度等于 k”误读成“长度至少为 k”。
  • 移动窗口时减错下标；右端为 i 时应移出 i-k。
  • 使用整数除法导致小数部分丢失。
  • 用 0 初始化最大和，使全负数组得到错误结果。
  • 在每个窗口内重新累加，忽略 n = 10⁵ 时的时间开销。

05 · Implementations

四种语言完整实现

四份代码都遵循同一不变量：windowSum 始终等于当前长度为 k 的窗口和。

Java

O(n) / O(1)
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        long windowSum = 0;
        for (int i = 0; i < k; i++) {
            windowSum += nums[i];
        }

        long maxSum = windowSum;
        for (int right = k; right < nums.length; right++) {
            windowSum += nums[right] - nums[right - k];
            maxSum = Math.max(maxSum, windowSum);
        }

        return (double) maxSum / k;
    }
}

Python 3

O(n) / O(1)
from typing import List


class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        window_sum = sum(nums[:k])
        max_sum = window_sum

        for right in range(k, len(nums)):
            window_sum += nums[right] - nums[right - k]
            max_sum = max(max_sum, window_sum)

        return max_sum / k

C++

O(n) / O(1)
class Solution {
public:
    double findMaxAverage(vector<int>& nums, int k) {
        long long windowSum = 0;
        for (int i = 0; i < k; ++i) {
            windowSum += nums[i];
        }

        long long maxSum = windowSum;
        for (int right = k; right < nums.size(); ++right) {
            windowSum += nums[right] - nums[right - k];
            maxSum = max(maxSum, windowSum);
        }

        return static_cast<double>(maxSum) / k;
    }
};
