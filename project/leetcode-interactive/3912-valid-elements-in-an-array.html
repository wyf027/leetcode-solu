数组中的有效元素

一次从左、一次从右：只要某个元素是任一方向上的严格新最大值，它就应保留在原来的相对顺序中。

题意

给定整数数组 nums。若 nums[i] 严格大于它左边的全部元素，或严格大于它右边的全部元素，则它有效。首尾元素总是有效。按原顺序返回所有有效元素。

示例 1

nums = [1,2,4,2,3,2]

输出 [1,2,4,3,2]

示例 2

nums = [5,5,5,5]

输出 [5,5]

约束

1 ≤ n ≤ 100
1 ≤ nums[i] ≤ 100

读题要点

  • 严格大于：相同值不算新的最大值。
  • “至少一边”是并集：左侧通过或右侧通过即可。
  • 输出要保留原序，因此最终从左到右收集。

核心洞察

从左到右维护扫描过元素的最大值。当前值大于它，便是左侧条件成立；从右到左同理。两个扫描写入同一个布尔数组，最后一次正向遍历输出即可。

完整过程

  1. 初始化 valid 为 false，左最大值为负无穷。
  2. 左扫：若 nums[i] > leftMax，标记；随后更新最大值。
  3. 右扫：按相同规则与右最大值比较。
  4. 正向收集被标记的数。

边界与复杂度

长度为 1 时左右扫描都会标记同一元素。重复元素不能越过相等的最大值，比较必须是 >。时间 O(n)，额外空间 O(n)；也可先存后缀最大值再前扫。

替代方案、面试追问与常见错误

替代
先构造后缀最大值数组，随后一趟正扫判定；逻辑直观但同为 O(n) 空间。

追问
若只需计数，可不保留答案数组；若要求流式输出，右侧条件使得必须延迟或预处理。

易错
把严格比较写成 ≥，或只记录左侧条件，都会错误保留重复值。

可提交代码

Java 

class Solution {
    public List<Integer> findValidElements(int[] nums) {
        int n = nums.length, left = Integer.MIN_VALUE, right = Integer.MIN_VALUE;
        boolean[] valid = new boolean[n];
        for (int i = 0; i < n; i++) { if (nums[i] > left) valid[i] = true; left = Math.max(left, nums[i]); }
        for (int i = n - 1; i >= 0; i--) { if (nums[i] > right) valid[i] = true; right = Math.max(right, nums[i]); }
        List<Integer> ans = new ArrayList<>();
        for (int i = 0; i < n; i++) if (valid[i]) ans.add(nums[i]);
        return ans;
    }
}

var findValidElements = function(nums) {
  const ok = Array(nums.length).fill(false); let left = -Infinity, right = -Infinity;
  for (let i = 0; i < nums.length; i++) { if (nums[i] > left) ok[i] = true; left = Math.max(left, nums[i]); }
  for (let i = nums.length - 1; i >= 0; i--) { if (nums[i] > right) ok[i] = true; right = Math.max(right, nums[i]); }
  return nums.filter((_, i) => ok[i]);
};

Python 

class Solution:
    def findValidElements(self, nums: list[int]) -> list[int]:
        ok = [False] * len(nums)
        left = float('-inf')
        for i, value in enumerate(nums):
            if value > left: ok[i] = True
            left = max(left, value)
        right = float('-inf')
        for i in range(len(nums) - 1, -1, -1):
            if nums[i] > right: ok[i] = True
            right = max(right, nums[i])
        return [value for i, value in enumerate(nums) if ok[i]]
