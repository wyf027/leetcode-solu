使字符串中不同字符的数目相等

Make Number of Distinct Characters Equal

两个字符串，一次交换。你能让它们拥有相同数量的字符种类吗？

打开官方题目 ↗

01 / 题目

给定两个从下标 0 开始的字符串 word1 和 word2。选择 0 ≤ i < word1.length、0 ≤ j < word2.length，交换 word1[i] 与 word2[j]。

判断是否存在一种选择，使两个字符串在恰好交换一次后，不同字符的数量相等。存在则返回 true，否则返回 false。比较的是字符种类数，不是长度，也不是每种字符的出现次数。

先自己想一想：交换两个相同的字母，算不算完成了一次操作？

约束

  • 1 ≤ word1.length, word2.length ≤ 10⁵
  • 两个字符串都只包含小写英文字母。

官方示例

输入：word1 = "ac", word2 = "b"
输出：false

无论怎样交换，前者都含 2 种字符，后者都含 1 种。

输入：word1 = "abcc", word2 = "aab"
输出：true

交换 i = 2 与 j = 0，得到 word1 = "abac"、word2 = "cab"，各含 3 种字符。

输入：word1 = "abcde", word2 = "fghij"
输出：true

交换任意一对位置后，两边依然各含 5 种字符。

04 / 独立题解

准备好后再展开，查看推导与四种语言实现。

枚举交换的字母，而非位置

核心洞察

相同字母的不同位置，对字符种类数产生的影响相同。因此先统计两边 26 个字母的频次，再枚举至多 26 × 26 对字母。只枚举在各自字符串里实际存在的字母。

完整过程

  1. 构造频次数组 a、b，统计非零项数量 d1、d2。
  2. 选择 word1 中的字母 x 和 word2 中的字母 y；如果 a[x] = 0 或 b[y] = 0，跳过。
  3. 若 x = y，字符串内容不变，但确实完成一次交换；只有 d1 = d2 才成功。
  4. 若 x ≠ y：移出最后一个 x 会让 word1 少一种；原本没有 y 则加入 y 会多一种。word2 同理。
  5. 计算新的种类数，相等即返回 true；所有合法字母对都不成功则返回 false。
当 x ≠ y 时（[条件] 表示成立为 1，否则为 0）：
newD1 = d1 - [a[x] == 1] + [a[y] == 0]
newD2 = d2 - [b[y] == 1] + [b[x] == 0]

例如 abcc / aab 交换 c 与 a：word1 的 c 还有一个、a 早已存在，所以仍为 3 种；word2 的 a 还有一个、c 是新字母，所以从 2 种增为 3 种。

正确性说明

覆盖性：任意合法下标交换对应某个实际存在的字母对 (x, y)。枚举会访问该字母对，同字母的各个位置不会改变频次变化，因此不遗漏可行操作。

准确性：x ≠ y 时，移出字母仅在原频次为 1 时消失，移入字母仅在原频次为 0 时新增；两个变化作用于不同字母，可以相加。x = y 时使用独立分支，保证种类数保持原值。

结论：返回 true 时一定存在合法的一次交换；若全部枚举结束仍未找到相等值，覆盖性保证不存在可行操作，因此返回 false 正确。

边界与常见错误

  • 恰好一次：不能看到初始种类相等就返回 true，例如 a / bb。
  • 交换相同字符合法，不要直接跳过 x = y；也不要套用不同字母的增减式。
  • 必须跳过频次为零的选出字母，否则枚举了不存在的操作。
  • 频次大于 1 时移走一个不会让种类数减少。
  • 若模拟修改数组，每轮必须还原。下面的实现直接算增量，不修改原始统计。
  • 字符串长度可以不同；比较种类数，无需比较长度。

复杂度

设字符串长度为 n、m，字母表大小为 Σ = 26。时间 O(n + m + Σ²)，额外空间 O(Σ)。固定小写字母表下，分别为 O(n + m) 与 O(1)。

替代方案

可以对每个字母对实际增减频次数组，重新扫描 26 个字母统计种类，再恢复数组。时间为 O(n + m + Σ³)，也能处理固定字母表，但恢复操作更容易出错。直接枚举下标并重建集合需要 O(nm(n+m)) 时间，不适合长度上界。

面试追问

  • 字符集扩大到 Unicode？使用字典统计，只枚举两个实际字符集合的笛卡尔积，时间 O(n + m + k1k2)，空间 O(k1 + k2)。
  • 需要返回下标？统计时顺便保存每个字母的一个出现位置，找到字母对后返回对应下标。
  • 种类数差大于 2 能直接拒绝吗？可以。单边一次最多变化 1，两边之差最多变化 2；但差不大于 2 只是必要条件。
  • 允许至多一次呢？初始种类数相等可以直接返回 true，否则继续枚举一次交换。

Java

class Solution {
    public boolean isItPossible(String word1, String word2) {
        int[] a = new int[26], b = new int[26];
        for (char c : word1.toCharArray()) a[c - 'a']++;
        for (char c : word2.toCharArray()) b[c - 'a']++;
        int d1 = 0, d2 = 0;
        for (int i = 0; i < 26; i++) {
            if (a[i] > 0) d1++;
            if (b[i] > 0) d2++;
        }
        for (int x = 0; x < 26; x++) {
            if (a[x] == 0) continue;
            for (int y = 0; y < 26; y++) {
                if (b[y] == 0) continue;
                if (x == y) {
                    if (d1 == d2) return true;
                    continue;
                }
                int n1 = d1 - (a[x] == 1 ? 1 : 0) + (a[y] == 0 ? 1 : 0);
                int n2 = d2 - (b[y] == 1 ? 1 : 0) + (b[x] == 0 ? 1 : 0);
                if (n1 == n2) return true;
            }
        }
        return false;
    }
}

JavaScript

/**
 * @param {string} word1
 * @param {string} word2
 * @return {boolean}
 */
var isItPossible = function(word1, word2) {
    const a = Array(26).fill(0), b = Array(26).fill(0);
    for (const c of word1) a[c.charCodeAt(0) - 97]++;
    for (const c of word2) b[c.charCodeAt(0) - 97]++;
    const d1 = a.filter(v => v > 0).length;
    const d2 = b.filter(v => v > 0).length;
    for (let x = 0; x < 26; x++) {
        if (!a[x]) continue;
        for (let y = 0; y < 26; y++) {
            if (!b[y]) continue;
            if (x === y) {
                if (d1 === d2) return true;
                continue;
            }
            const n1 = d1 - (a[x] === 1) + (a[y] === 0);
            const n2 = d2 - (b[y] === 1) + (b[x] === 0);
            if (n1 === n2) return true;
        }
    }
    return false;
};

class Solution:
    def isItPossible(self, word1: str, word2: str) -> bool:
        a, b = [0] * 26, [0] * 26
        for c in word1:
            a[ord(c) - ord('a')] += 1
        for c in word2:
            b[ord(c) - ord('a')] += 1
        d1 = sum(v > 0 for v in a)
        d2 = sum(v > 0 for v in b)
        for x in range(26):
            if a[x] == 0:
                continue
            for y in range(26):
                if b[y] == 0:
                    continue
                if x == y:
                    if d1 == d2:
                        return True
                    continue
                n1 = d1 - (a[x] == 1) + (a[y] == 0)
                n2 = d2 - (b[y] == 1) + (b[x] == 0)
                if n1 == n2:
                    return True
        return False

                int n2 = d2 - (b[y] == 1) + (b[x] == 0);

            }
        }
