01 题目说明

给定字符串 s，重新排列其中的字符，使任意两个相邻字符都不相同。若存在方案，返回任意一种合法排列；若无法做到，返回空字符串 ""。

reorganizeString(s: string) → string

约束

  • 1 <= s.length <= 500
  • s 只包含小写英文字母。
  • 答案不唯一，任意合法排列都可接受。

输出："aba"

Solution unlocked

贪心调度：让最紧张的字符先落位

使用计数表记录库存，用最大堆持续取出剩余次数最多的字符；刚放置的字符暂缓一轮再回到堆中，从机制上禁止相邻重复。

核心洞察

出现最多的字符最难安置，应该优先消耗。若它出现 m 次，其余字符总数必须提供至少 m - 1 个隔板，因此可行条件是 m <= ceil(n / 2)。

最大堆负责“优先消耗”，暂存位负责“本轮不可复用”。两个部件共同把全局约束转为每一步的局部安全选择。

完整过程

  1. 统计 26 个小写字母的出现次数，并检查最大频次是否超过 (n + 1) / 2。
  2. 把所有出现过的字符放入最大堆，按剩余次数从大到小排序。
  3. 每轮从堆顶取一个字符追加到答案，并将其剩余次数减一。
  4. 把上一轮暂存且仍有库存的字符放回堆，再把本轮字符设为新的暂存字符。
  5. 堆清空后，若答案长度等于原串长度则返回答案，否则返回空串。

正确性证明

引理 1：输出中不会产生相邻相同字符。

刚追加的字符会被移出堆并暂存到下一轮选择完成之后。在下一次选取堆顶时，它不在候选集合中，所以连续两次不可能选择同一字符。

引理 2：若可行条件成立，算法会用完所有字符。

最大频次不超过 ceil(n / 2) 时，最高频字符之间有足够的其他字符作为隔板。算法总是优先消耗当前最高频字符，不会把更紧张的库存拖到最后；暂存机制只延迟一轮，不会丢弃字符。

结论

由引理 1，构造出的相邻字符均不同；由引理 2，所有字符都被使用且计数保持不变。因此算法在有解时返回合法重排，无解时返回空串。

边界与复杂度

  • 长度为 1：原字符串本身就是答案。
  • 只有一种字符且长度大于 1：最大频次检查直接判无解。
  • 刚好达到上界：最高频字符会占据首尾交错位置，仍可构造。
  • 答案不唯一：不要把输出与某个固定字符串做唯一性比较。
时间 O(n log k) k <= 26，在本题中近似 O(n)。
空间 O(k) 不计返回字符串；计数表与堆最多容纳 26 项。

import java.util.PriorityQueue;

class Solution {
    public String reorganizeString(String s) {
        int[] frequency = new int[26];
        int maxFrequency = 0;

        for (char ch : s.toCharArray()) {
            int index = ch - 'a';
            frequency[index]++;
            maxFrequency = Math.max(maxFrequency, frequency[index]);
        }

        if (maxFrequency > (s.length() + 1) / 2) {
            return "";
        }

        PriorityQueue<int[]> maxHeap = new PriorityQueue<>(
            (a, b) -> a[0] != b[0]
                ? Integer.compare(b[0], a[0])
                : Integer.compare(a[1], b[1])
        );

        for (int i = 0; i < 26; i++) {
            if (frequency[i] > 0) {
                maxHeap.offer(new int[] { frequency[i], i });
            }
        }

        StringBuilder answer = new StringBuilder();
        int[] previous = new int[] { 0, -1 };

        while (!maxHeap.isEmpty()) {
            int[] current = maxHeap.poll();
            answer.append((char) ('a' + current[1]));
            current[0]--;

            if (previous[0] > 0) {
                maxHeap.offer(previous);
            }
            previous = current;
        }

        return answer.length() == s.length() ? answer.toString() : "";
    }
}
class MaxHeap {
    constructor() {
        this.data = [];
    }

    isEmpty() {
        return this.data.length === 0;
    }

    higherPriority(a, b) {
        return a.count !== b.count
            ? a.count > b.count
            : a.char < b.char;
    }

    push(item) {
        this.data.push(item);
        let index = this.data.length - 1;

        while (index > 0) {
            const parent = Math.floor((index - 1) / 2);
            if (!this.higherPriority(this.data[index], this.data[parent])) break;
            [this.data[index], this.data[parent]] = [this.data[parent], this.data[index]];
            index = parent;
        }
    }

    pop() {
        const top = this.data[0];
        const last = this.data.pop();
        if (this.data.length === 0) return top;

        this.data[0] = last;
        let index = 0;

        while (true) {
            let best = index;
            const left = index * 2 + 1;
            const right = index * 2 + 2;

            if (left < this.data.length &&
                this.higherPriority(this.data[left], this.data[best])) {
                best = left;
            }
            if (right < this.data.length &&
                this.higherPriority(this.data[right], this.data[best])) {
                best = right;
            }
            if (best === index) break;

            [this.data[index], this.data[best]] = [this.data[best], this.data[index]];
            index = best;
        }

        return top;
    }
}

var reorganizeString = function(s) {
    const frequency = new Array(26).fill(0);
    let maxFrequency = 0;

    for (const char of s) {
        const index = char.charCodeAt(0) - 97;
        frequency[index]++;
        maxFrequency = Math.max(maxFrequency, frequency[index]);
    }

    if (maxFrequency > Math.floor((s.length + 1) / 2)) return "";

    const heap = new MaxHeap();
    for (let i = 0; i < 26; i++) {
        if (frequency[i] > 0) {
            heap.push({ count: frequency[i], char: String.fromCharCode(97 + i) });
        }
    }

    const answer = [];
    let previous = null;

    while (!heap.isEmpty()) {
        const current = heap.pop();
        answer.push(current.char);
        current.count--;

        if (previous && previous.count > 0) heap.push(previous);
        previous = current;
    }

    return answer.length === s.length ? answer.join("") : "";
};
from collections import Counter
import heapq


class Solution:
    def reorganizeString(self, s: str) -> str:
        frequency = Counter(s)
        if max(frequency.values()) > (len(s) + 1) // 2:
            return ""

        max_heap = [(-count, char) for char, count in frequency.items()]
        heapq.heapify(max_heap)

        answer = []
        previous_count = 0
        previous_char = ""

        while max_heap:
            negative_count, char = heapq.heappop(max_heap)
            answer.append(char)
            negative_count += 1

            if previous_count < 0:
                heapq.heappush(max_heap, (previous_count, previous_char))

            previous_count = negative_count
            previous_char = char

        return "".join(answer) if len(answer) == len(s) else ""
#include <array>
#include <queue>
#include <string>
#include <utility>

using namespace std;

class Solution {
public:
    string reorganizeString(string s) {
        array<int, 26> frequency{};
        int maxFrequency = 0;

        for (char ch : s) {
            maxFrequency = max(maxFrequency, ++frequency[ch - 'a']);
        }

        if (maxFrequency > (static_cast<int>(s.size()) + 1) / 2) {
            return "";
        }

        priority_queue<pair<int, char>> maxHeap;
        for (int i = 0; i < 26; ++i) {
            if (frequency[i] > 0) {
                maxHeap.push({frequency[i], static_cast<char>('a' + i)});
            }
        }

        string answer;
        pair<int, char> previous = {0, '#'};

        while (!maxHeap.empty()) {
            auto current = maxHeap.top();
            maxHeap.pop();

            answer.push_back(current.second);
            --current.first;

            if (previous.first > 0) {
                maxHeap.push(previous);
            }
            previous = current;
        }

        return answer.size() == s.size() ? answer : "";
    }
};

替代方案：按偶数位再奇数位填充

先把出现最多的字符放到下标 0, 2, 4, ...，偶数位用完后继续放到 1, 3, 5, ...。在 26 个小写字母的固定字符集下，可做到 O(n) 时间。

这种写法更短，但“为何跨越偶数位边界后仍安全”更容易写错或解释不清；最大堆方案更通用，也更适合扩展到任意字符集。

常见错误

  • 只比较当前字符与答案末尾，然后随便找替代字符，导致后续高频字符无处可放。
  • 把刚取出的字符立即放回堆，下一轮仍可能再次取到它。
  • 忽略无解条件，最后返回了长度不足的部分答案。
  • 测试时要求唯一输出；本题可能有多个合法答案，应验证字符计数和相邻约束。
  • 复杂度写成 O(n log n)，却忽略堆中最多只有不同字符数 k 项。

面试追问

如果字符集不止 26 个小写字母呢？ 使用哈希表计数，堆大小改为不同字符数 k，复杂度仍是 O(n log k)。
如果要求相同字符至少间隔 k 个位置呢？ 把单个暂存位扩展为长度为 k 的冷却队列；字符冷却满 k 轮后才重新进入最大堆。
为什么优先放最高频字符？ 高频字符的合法位置最紧张。若延迟处理，低频字符会被提前耗尽，最后只剩相同字符连续堆积。
如何验证返回值而不依赖固定答案？ 检查三件事：长度相同、各字符计数相同、每一对相邻字符不同；无解时再核对最大频次条件。
