1545 · MEDIUM找出第 N 个二进制字符串中的第 K 位

一条字符串不断复制、翻转、倒置。目标不是把它全部展开，而是精准定位其中一位。

中等 非会员题 findKthBit(n, k) → char

生成规则

Sᵢ = Sᵢ₋₁ + "1" + reverse(invert(Sᵢ₋₁))
左侧保留上一层
正中央永远插入 1
右侧是左侧的反转 + 取反

Problem

题目说明

Solution

递归定位，不生成字符串

核心洞察

Sₙ 的长度为 2ⁿ - 1，中点位置为 2ⁿ⁻¹。左半就是 Sₙ₋₁；右半的每个位置都能镜像回左半，但答案要取反。

所以每次只需比较 k 与中点：在左侧就原样进入上一层；在中点直接得到 1；在右侧则映射为 2ⁿ - k，进入上一层后把结果翻转。

完整过程

  1. 若 n = 1，唯一字符是 0。
  2. 计算当前层中点 mid = 2ⁿ⁻¹。
  3. 若 k = mid，返回 1。
  4. 若 k < mid，递归查询 Sₙ₋₁ 的第 k 位。
  5. 若 k > mid，其镜像位置是 2ⁿ - k；递归查询后取反。

示例：n = 4, k = 11

(4,11) → invert(3,5) → invert(invert(2,3)) → invert(1,1) → invert(0) = 1

正确性证明

命题：递归函数返回 Sₙ 的第 k 位。

基础情形：n = 1 时，S₁ = "0"，函数返回 0，正确。

归纳步骤：假设函数能正确查询 Sₙ₋₁。当目标在左半时，该部分与 Sₙ₋₁ 完全相同；在中点时，根据定义该位为 1；在右半时，定义保证它等于左半镜像位置的取反，映射位置为 2ⁿ - k。三种位置都返回正确字符，因此命题对第 n 层成立。

边界处理

  • n = 1, k = 1 由基础情形处理。
  • k = mid 必须在左右分支之前判断。
  • 最左与最右位置都能在每次递归后落入合法的上一层范围。
  • n ≤ 20，位移与长度均在常见 32 位整数安全范围内。

复杂度与替代方案

时间复杂度O(n)每层只做常数次计算。
空间复杂度O(n)递归调用栈；迭代写法可降至 O(1)。

替代方案

直接构造：严格按定义生成 S₁…Sₙ，再读取第 k 位。思路直观，但时间和空间都会增长到 O(2ⁿ)。在本题 n≤20 时可能通过，却没有利用结构。

迭代折返：用一个布尔变量记录累计取反次数，持续把右半位置映射到上一层。它保持 O(n) 时间并将额外空间降为 O(1)。

四语言完整代码

class Solution {
    public char findKthBit(int n, int k) {
        if (n == 1) {
            return '0';
        }

        int mid = 1 << (n - 1);
        if (k == mid) {
            return '1';
        }
        if (k < mid) {
            return findKthBit(n - 1, k);
        }

        char mirrored = findKthBit(n - 1, (1 << n) - k);
        return mirrored == '0' ? '1' : '0';
    }
}
/**
 * @param {number} n
 * @param {number} k
 * @return {character}
 */
var findKthBit = function(n, k) {
    if (n === 1) {
        return '0';
    }

    const mid = 2 ** (n - 1);
    if (k === mid) {
        return '1';
    }
    if (k < mid) {
        return findKthBit(n - 1, k);
    }

    const mirrored = findKthBit(n - 1, 2 ** n - k);
    return mirrored === '0' ? '1' : '0';
};

面试追问与常见错误

如何改成 O(1) 额外空间？

循环更新 n 和 k，并用布尔值记录是否累计取反。落到基础位或中点后，再依据该布尔值决定最终字符。

为什么镜像位置是 2ⁿ - k？

当前串长度为 2ⁿ-1。以 1 为起点的左右镜像位置之和为 length+1，即 2ⁿ。

能否从 k 的二进制直接推导？

可以进一步研究该序列与纸张折叠/格雷码式位模式的关系，但递归镜像法更直接，也更容易证明。

常见错误

  • 把中点写成 (2ⁿ - 1) / 2，少了 1；正确的一基中点是 2ⁿ⁻¹。
  • 右半只做镜像却忘记取反，或先取反 k 而不是取反返回的字符。
  • 把位置当作零基下标，导致镜像公式整体偏一。
  • 完整构造长字符串，使本来只需 O(n) 的定位变成指数规模。
