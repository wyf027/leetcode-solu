Problem

题意

给定单链表头节点 head，以及满足 left ≤ right 的两个位置。将从第 left 个节点到第 right 个节点这一段原地反转，返回处理后的链表头。

位置从 1 开始计数；进阶要求是在一次遍历内完成。

官方样例 1 · 输入

head = [1,2,3,4,5] left = 2 right = 4

输出

[1,4,3,2,5]

官方样例 2 · 输入

head = [5] left = 1 right = 1

输出

[5]

题解

Core insight

固定锚点，反复头插

让 prev 永远停在反转区间前一个节点，curr 永远是反转后区间的尾节点。每轮摘下 curr.next，把它插到 prev 后面。

Loop invariant

已移动节点按逆序聚集在 prev 后；curr 仍连接尚未处理的下一节点。

1. 用 dummy 消除头节点特判

让虚拟节点指向 head，随后把 prev 前进 left - 1 次。即使 left = 1，prev 也有合法位置。

2. curr 锚定区间首节点

curr = prev.next。它的值不变，但随着头插进行，会逐步成为反转区间尾节点。

3. 执行 right - left 次头插

依次执行 move = curr.next、越过 move、把 move 接到 prev 后，最后让 prev 指向 move。

4. 返回 dummy.next

整个过程只重连指针，不创建或删除真实链表节点。

边界

  • left = right：循环 0 次，链表不变。
  • left = 1：dummy 负责接住新头。
  • right = n：curr 最终正确指向 null。
  • 单节点链表天然覆盖。

复杂度

prev 最多前进 left - 1 步，头插执行 right - left 次，总时间 O(n)；仅使用常数个指针，额外空间 O(1)。

替代方案

也可先找到区间两端，再用标准链表反转后重新拼接；逻辑直观，但连接边界更多。递归法表达优雅，却使用 O(n) 调用栈。面试优先头插法。

面试追问

  1. 为什么循环 right - left 次？
    区间有 k 个节点，只需把后 k - 1 个依次搬到首位。
  2. 为什么 curr 不前进？
    每次摘掉 curr.next 后，curr 自动成为缩短后的未处理段之前的尾节点。
  3. 如何扩展到 K 个一组反转？
    先确认剩余节点数，再以分组边界重复同样的局部重连思想。

常见错误

  • 没有 dummy，导致 left = 1 时无法连接新头。
  • 先覆盖 curr.next，却没有保存 move，丢失后续链表。
  • 循环写成区间长度次，多搬一次造成空指针。
  • 用值交换代替节点反转，违反链表结构操作的题意。

class Solution {
    public ListNode reverseBetween(ListNode head, int left, int right) {
        ListNode dummy = new ListNode(0, head);
        ListNode prev = dummy;

        for (int i = 1; i < left; i++) {
            prev = prev.next;
        }

        ListNode curr = prev.next;
        for (int i = 0; i < right - left; i++) {
            ListNode move = curr.next;
            curr.next = move.next;
            move.next = prev.next;
            prev.next = move;
        }

        return dummy.next;
    }
}
