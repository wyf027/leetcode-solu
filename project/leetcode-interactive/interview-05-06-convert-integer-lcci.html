约束与补码

  • -2147483648 ≤ A, B ≤ 2147483647。
  • 负数必须按 32 位二进制补码处理，不能用“取绝对值”代替。
  • 最多 32 位不同，因此答案范围是 [0, 32]。

    核心洞察

    异或定位，Kernighan 计数

    A ^ B 只在不同位上产生 1。对非零 x 执行 x & (x - 1)，恰好清除最低位的 1；执行次数就是答案。

    完整过程

    1. 1. 计算 32 位差异图 x = A ^ B。
    2. 2. 当 x != 0 时，执行 x &= x - 1。
    3. 3. 每清除一个 1，计数加一。
    4. 4. x == 0 时，全部差异位已统计。

    边界

    A == B 返回 0；-1 与 0 相差 32 位；极值也按 32 位补码处理。

    复杂度

    若差异位有 k 个，时间 O(k)，最坏 32 次；空间 O(1)。

    替代方案

    固定扫描 32 位是 O(32)；内置 popcount 更短，但面试中常要求解释原理。

    常见错误

    Python 忘记 32 位掩码；C++ 对负的 signed 值做减一导致未定义行为；只数正数位。

    面试追问

    为何能清最低位 1？

    x - 1 会翻转最低位 1 及其右侧，和原值相与只消掉那一位。

    负数为什么危险？

    Python 整数无限精度；C++ signed 溢出未定义，因此要显式限制为 uint32。

    能一行完成吗？

    生产代码可用 bitCount/popcount，面试主线用手写循环展示理解。

    class Solution {
    public int convertInteger(int A, int B) {
        int x = A ^ B;
        int count = 0;
        while (x != 0) {
            x &= x - 1;
            count++;
        }
        return count;
    }
}

var convertInteger = function (A, B) {
    let x = (A ^ B) >>> 0;
    let count = 0;
    while (x !== 0) {
        x = (x & (x - 1)) >>> 0;
        count++;
    }
    return count;
};
