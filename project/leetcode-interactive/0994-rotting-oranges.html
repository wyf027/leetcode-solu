腐烂的橘子

Rotting Oranges · 先观察传播，再决定如何计算最短时间。

题目

给定 m × n 网格 grid：0 表示空格，1 表示新鲜橘子，2 表示腐烂橘子。每过一分钟，与腐烂橘子在上、下、左、右方向相邻的新鲜橘子都会腐烂。返回让网格中不再有新鲜橘子的最少分钟数；若无法做到，返回 -1。

官方示例

示例 1
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4
示例 2
输入：grid = [[2,1,1],[0,1,1],[1,0,1]]
输出：-1
左下角橘子无法通过四方向传播触达。
示例 3
输入：grid = [[0,2]]
输出：0
第 0 分钟就没有新鲜橘子。

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 10
  • grid[i][j] 只可能是 0、1、2

函数签名

orangesRotting(grid: integer[][]): integer

题解：多源广度优先搜索

核心洞察

所有初始腐烂橘子会在同一时刻向外传播。把它们同时放入队列，相当于一次拥有多个起点的 BFS；队列的每一层恰好对应一分钟。这样第一次到达某个新鲜橘子的时刻，就是它能腐烂的最早时刻。

完整过程

  1. 扫描网格：统计新鲜橘子，并把全部腐烂橘子入队。
  2. 只要队列非空且仍有新鲜橘子，就按当前队列长度处理一整层。
  3. 对每个腐烂橘子的四个邻格：若是新鲜橘子，将其标为腐烂、减少计数并入队。
  4. 每处理完一层，分钟数加一。结束后若新鲜计数仍大于零返回 -1，否则返回分钟数。

正确性

层次不变式：第 t 层队列包含所有恰好能在第 t 分钟腐烂的橘子。初始层在第 0 分钟成立；若第 t 层成立，它能且只能让四邻的新鲜橘子在第 t+1 分钟腐烂，因此下一层也成立。BFS 按层首次访问即为最短传播时间。队列耗尽后仍新鲜的橘子不可达，所以返回 -1 正确。

边界与复杂度

  • 没有新鲜橘子：直接返回 0。
  • 没有初始腐烂橘子但存在新鲜橘子：返回 -1。
  • 空格会阻断路径；对角线不相邻。
  • 时间复杂度 O(mn)，每格至多入队一次；空间复杂度 O(mn)。

替代方案

可以反复全图扫描并同步更新，但最坏会产生多轮 O(mn) 扫描；也可记录每格时间的多源最短路，本质仍是无权图 BFS。DFS 不天然保证最早到达时间。

面试追问

  • 若每条传播边耗时不同：使用 Dijkstra。
  • 若允许八方向传播：替换方向数组。
  • 若不能修改输入：额外维护访问矩阵。
  • 如何返回每个橘子的腐烂时间：队列中携带时间或写入距离矩阵。

常见错误

  • 逐个起点分别 BFS，既重复计算又破坏“同时传播”的语义。
  • 在每个节点而非每一层增加分钟数。
  • 新鲜橘子入队时未立刻标记，导致重复入队。
  • 无新鲜橘子时错误返回 1；传播结束后忘记检查残留新鲜橘子。

四语言完整代码

import java.util.*;

class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length, fresh = 0, minutes = 0;
        Queue<int[]> queue = new ArrayDeque<>();
        for (int r = 0; r < m; r++) for (int c = 0; c < n; c++) {
            if (grid[r][c] == 2) queue.offer(new int[]{r, c});
            else if (grid[r][c] == 1) fresh++;
        }
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!queue.isEmpty() && fresh > 0) {
            int size = queue.size();
            while (size-- > 0) {
                int[] cur = queue.poll();
                for (int[] d : dirs) {
                    int nr = cur[0] + d[0], nc = cur[1] + d[1];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n || grid[nr][nc] != 1) continue;
                    grid[nr][nc] = 2; fresh--; queue.offer(new int[]{nr, nc});
                }
            }
            minutes++;
        }
        return fresh == 0 ? minutes : -1;
    }
}

var orangesRotting = function(grid) {
  const m = grid.length, n = grid[0].length, queue = [];
  let fresh = 0, head = 0, minutes = 0;
  for (let r = 0; r < m; r++) for (let c = 0; c < n; c++) {
    if (grid[r][c] === 2) queue.push([r, c]);
    else if (grid[r][c] === 1) fresh++;
  }
  const dirs = [[1,0],[-1,0],[0,1],[0,-1]];
  while (head < queue.length && fresh > 0) {
    const end = queue.length;
    while (head < end) {
      const [r, c] = queue[head++];
      for (const [dr, dc] of dirs) {
        const nr = r + dr, nc = c + dc;
        if (nr < 0 || nr >= m || nc < 0 || nc >= n || grid[nr][nc] !== 1) continue;
        grid[nr][nc] = 2; fresh--; queue.push([nr, nc]);
      }
    }
    minutes++;
  }
  return fresh === 0 ? minutes : -1;
};
from collections import deque
from typing import List

class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        queue, fresh, minutes = deque(), 0, 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 2: queue.append((r, c))
                elif grid[r][c] == 1: fresh += 1
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
        while queue and fresh:
            for _ in range(len(queue)):
                r, c = queue.popleft()
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                        grid[nr][nc] = 2
                        fresh -= 1
                        queue.append((nr, nc))
            minutes += 1
        return minutes if fresh == 0 else -1
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size(), fresh = 0, minutes = 0;
        queue<pair<int,int>> q;
        for (int r = 0; r < m; ++r) for (int c = 0; c < n; ++c) {
            if (grid[r][c] == 2) q.push({r, c});
            else if (grid[r][c] == 1) ++fresh;
        }
        int dirs[5] = {1, 0, -1, 0, 1};
        while (!q.empty() && fresh > 0) {
            int size = q.size();
            while (size--) {
                auto [r, c] = q.front(); q.pop();
                for (int k = 0; k < 4; ++k) {
                    int nr = r + dirs[k], nc = c + dirs[k + 1];
                    if (nr < 0 || nr >= m || nc < 0 || nc >= n || grid[nr][nc] != 1) continue;
                    grid[nr][nc] = 2; --fresh; q.push({nr, nc});
                }
            }
            ++minutes;
        }
        return fresh == 0 ? minutes : -1;
    }
};
