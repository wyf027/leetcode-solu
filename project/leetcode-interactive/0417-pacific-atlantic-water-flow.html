太平洋大西洋
水流问题

一座岛，两个海洋。雨水只能顺着不升高的方向流动——哪些格子拥有同时抵达两侧海岸的路径？先理解规则，再亲手观察水流边界。

Problem

题目转述

给定一个 m × n 整数矩阵 heights，其中 heights[r][c] 是格子 (r, c) 的海拔。岛屿的上边界和左边界紧邻太平洋，下边界和右边界紧邻大西洋。

雨水可以从当前格子流向上、下、左、右相邻格子，但相邻格子的高度必须小于或等于当前高度。边界格子的水可以直接流入与它相邻的海洋。

返回所有能让雨水同时流到太平洋与大西洋的坐标 [r, c]。答案坐标的顺序不作要求。

先停一下：如果从每个格子分别模拟水流，最坏情况下会重复遍历多少区域？有没有办法从海岸线观察同一件事？题解仍在页面底部折叠着。

Solution

从海洋反向爬坡

核心洞察

正向看，水从高处流向不更高的相邻格；反向看，如果从海岸出发，就只能走向高度大于或等于当前格的相邻格。这样一次搜索就能收集所有可以顺流抵达该海洋的格子。

分别从太平洋边界和大西洋边界做多源 BFS，最后取两个可达集合的交集。

为什么多源

同一海洋接触多条边界。把所有海岸格一开始同时入队，相当于给搜索设置多个起点；每个格子只需进入一次该海洋的队列，避免从每个起点重复搜索。

边角会同时属于同一海洋的两条边，入队前用访问标记去重即可。

完整过程

  1. 建立太平洋起点。 将第 0 行与第 0 列所有格子作为多源 BFS 的初始队列，并标记为太平洋可达。
  2. 建立大西洋起点。 将最后一行与最后一列所有格子作为另一轮多源 BFS 的初始队列，并标记为大西洋可达。
  3. 逆向扩展。 对当前格子的四邻域，如果邻格未访问且高度不低于当前格，就将邻格标为可达并入队。这正好对应水可从邻格顺流回到当前格。
  4. 求交集。 扫描矩阵，凡是同时被两次搜索访问的格子，都加入答案。

正确性证明

引理：一次从海洋边界出发的逆向搜索访问格子 x，当且仅当水能从 x 流到该海洋。

充分性：搜索沿着不下降的高度从海岸走到 x。反转这条路径后，高度不升，因此水能从 x 顺流到海岸。

必要性：若水能从 x 沿不升路径到海岸，反转路径就是从海岸到 x 的不降路径；逆向搜索必能逐段访问 x。

因此，两轮搜索集合的交集恰好包含且仅包含能流到两个海洋的格子，算法正确。

复杂度与边界

时间：O(mn)。每轮 BFS 中每个格子至多入队一次，最后再线性扫描一次。

空间：O(mn)，用于两个访问矩阵与最坏情况下容纳所有格子的队列。

  • 1 × 1：唯一格子属于两个集合。
  • 单行或单列：每个格子都同时贴着上下或左右两侧海洋。
  • 等高平台：等高移动合法，平台可能整体连通。
  • 高度为 0 或 10^5：比较操作不受影响。

替代方案

多源 DFS：将 BFS 的队列换成递归或显式栈，搜索判定完全相同，复杂度仍为 O(mn)。但最多 40,000 个格子时，递归 DFS 在部分语言中可能栈溢出；迭代 BFS 更稳妥。

从每格正向搜索：概念直观，但会反复探索相同区域，朴素最坏复杂度可达 O((mn)^2)。即使做记忆化，双目标状态的传播和环处理也更复杂，不如逆向搜索直接。

import java.util.*;

class Solution {
    private static final int[][] DIRS = {
        {1, 0}, {-1, 0}, {0, 1}, {0, -1}
    };

    public List<List<Integer>> pacificAtlantic(int[][] heights) {
        int m = heights.length;
        int n = heights[0].length;
        boolean[][] pacific = new boolean[m][n];
        boolean[][] atlantic = new boolean[m][n];
        Deque<int[]> pacificQueue = new ArrayDeque<>();
        Deque<int[]> atlanticQueue = new ArrayDeque<>();

        for (int r = 0; r < m; r++) {
            add(r, 0, pacific, pacificQueue);
            add(r, n - 1, atlantic, atlanticQueue);
        }
        for (int c = 0; c < n; c++) {
            add(0, c, pacific, pacificQueue);
            add(m - 1, c, atlantic, atlanticQueue);
        }

        bfs(heights, pacific, pacificQueue);
        bfs(heights, atlantic, atlanticQueue);

        List<List<Integer>> answer = new ArrayList<>();
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (pacific[r][c] && atlantic[r][c]) {
                    answer.add(Arrays.asList(r, c));
                }
            }
        }
        return answer;
    }

    private void add(int r, int c, boolean[][] seen, Deque<int[]> queue) {
        if (!seen[r][c]) {
            seen[r][c] = true;
            queue.offer(new int[]{r, c});
        }
    }

    private void bfs(int[][] heights, boolean[][] seen, Deque<int[]> queue) {
        int m = heights.length;
        int n = heights[0].length;
        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            for (int[] d : DIRS) {
                int nr = cell[0] + d[0];
                int nc = cell[1] + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n || seen[nr][nc]) {
                    continue;
                }
                if (heights[nr][nc] >= heights[cell[0]][cell[1]]) {
                    seen[nr][nc] = true;
                    queue.offer(new int[]{nr, nc});
                }
            }
        }
    }
}

from collections import deque
from typing import List


class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        rows, cols = len(heights), len(heights[0])

        def search(starts: List[tuple[int, int]]) -> List[List[bool]]:
            seen = [[False] * cols for _ in range(rows)]
            queue = deque()

            for r, c in starts:
                if not seen[r][c]:
                    seen[r][c] = True
                    queue.append((r, c))

            while queue:
                r, c = queue.popleft()
                for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    nr, nc = r + dr, c + dc
                    if not (0 <= nr < rows and 0 <= nc < cols):
                        continue
                    if seen[nr][nc] or heights[nr][nc] < heights[r][c]:
                        continue
                    seen[nr][nc] = True
                    queue.append((nr, nc))
            return seen

        pacific_starts = (
            [(r, 0) for r in range(rows)]
            + [(0, c) for c in range(cols)]
        )
        atlantic_starts = (
            [(r, cols - 1) for r in range(rows)]
            + [(rows - 1, c) for c in range(cols)]
        )

        pacific = search(pacific_starts)
        atlantic = search(atlantic_starts)

        return [
            [r, c]
            for r in range(rows)
            for c in range(cols)
            if pacific[r][c] and atlantic[r][c]
        ]
class Solution {
public:
    vector<vector<int>> pacificAtlantic(vector<vector<int>>& heights) {
        int m = heights.size();
        int n = heights[0].size();
        vector<vector<bool>> pacific(m, vector<bool>(n, false));
        vector<vector<bool>> atlantic(m, vector<bool>(n, false));
        queue<pair<int, int>> pacificQueue;
        queue<pair<int, int>> atlanticQueue;

        auto add = [](int r, int c, vector<vector<bool>>& seen,
                      queue<pair<int, int>>& q) {
            if (!seen[r][c]) {
                seen[r][c] = true;
                q.push({r, c});
            }
        };

        for (int r = 0; r < m; ++r) {
            add(r, 0, pacific, pacificQueue);
            add(r, n - 1, atlantic, atlanticQueue);
        }
        for (int c = 0; c < n; ++c) {
            add(0, c, pacific, pacificQueue);
            add(m - 1, c, atlantic, atlanticQueue);
        }

        bfs(heights, pacific, pacificQueue);
        bfs(heights, atlantic, atlanticQueue);

        vector<vector<int>> answer;
        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                if (pacific[r][c] && atlantic[r][c]) {
                    answer.push_back({r, c});
                }
            }
        }
        return answer;
    }

private:
    void bfs(const vector<vector<int>>& heights,
             vector<vector<bool>>& seen,
             queue<pair<int, int>>& q) {
        int m = heights.size();
        int n = heights[0].size();
        const int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        while (!q.empty()) {
            auto [r, c] = q.front();
            q.pop();
            for (const auto& d : dirs) {
                int nr = r + d[0];
                int nc = c + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n || seen[nr][nc]) {
                    continue;
                }
                if (heights[nr][nc] >= heights[r][c]) {
                    seen[nr][nc] = true;
                    q.push({nr, nc});
                }
            }
        }
    }
};

常见错误

  • 逆向搜索仍使用 neighbor <= current，把方向条件写反。
  • 漏掉等号，使等高平台无法连通。
  • 只把四个角入队，而不是两条完整海岸线。
  • 出队时才标记访问，造成同一格重复入队。
  • 用数组 shift() 实现 JavaScript 队列，带来额外搬移开销。
  • 假定答案必须按某个特定顺序返回。
