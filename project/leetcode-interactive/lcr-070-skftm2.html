有序数组中的单一元素

其余数字恰好出现两次，并且相邻成对。单一元素之前，每一对从偶数下标开始；它之后，配对整体右移一格。二分寻找这条规律第一次断开的地方。

SINGLE4

Invariant 01

偶数下标是配对起点

在答案左侧，nums[0] == nums[1]、nums[2] == nums[3]……都成立。

Invariant 02

先把 mid 对齐为偶数

若 mid 是奇数就减一；只比较 mid 与 mid + 1。

Invariant 03

相等向右，不等保留 mid

相等说明断点在右侧；不等说明单一元素位于当前配对之前或就是 mid。

Core idea

把“单一元素”变成真假分界

定义谓词：偶数下标 i 是否满足 nums[i] == nums[i + 1]？答案左侧为真，答案处及右侧为假。二分找第一个假位置。

Complexity

每轮丢弃一半配对

时间 O(log n)：二分收缩区间。
空间 O(1)：只保存左右边界与中点。

三步写出正确二分

  1. 1. 选中点

    取 mid = left + (right - left) / 2。

  2. 2. 对齐偶数

    若 mid 为奇数，执行 mid--。

  3. 3. 判断配对

    相等则 left = mid + 2，否则 right = mid。

边界与错误

  • • 数组长度必为奇数，单元素可在首尾。
  • • right 保持闭区间，不能在不等时写成 mid - 1。
  • • 不要把奇数 mid 与右邻居比较，会破坏统一配对方向。

面试追问

为什么可以跳过两个位置？
相等的一对不可能包含答案，答案只能在其右侧。
有三次或更多重复怎么办？
必须重建下标模规律；这里的偶偶配对只适用于“其余恰好两次”。

class Solution {
    public int singleNonDuplicate(int[] nums) {
        int left = 0, right = nums.length - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if ((mid & 1) == 1) mid--;
            if (nums[mid] == nums[mid + 1]) left = mid + 2;
            else right = mid;
        }
        return nums[left];
    }
}
