Find Numbers with Even Number of Digits

统计位数为偶数的数字

给定一个整数数组 nums，返回其中数位个数为偶数的数字数量。先亲手观察数组，再决定如何实现。

题目说明

输入、输出与样例

函数形式：findNumbers(nums: integer[]) → integer

任务：逐个查看 nums 中的正整数；如果一个数字包含偶数个十进制数位，就把它计入答案。

示例 1

输入：nums = [12,345,2,6,7896]
输出：2
解释：12 有 2 位，7896 有 4 位；二者位数为偶数。

示例 2

输入：nums = [555,901,482,1771]
输出：1
解释：只有 1771 含有偶数个数位。

约束

  • 1 ≤ nums.length ≤ 500
  • 1 ≤ nums[i] ≤ 105

独立题解区

建议先完成一次手动扫描，并想一想：怎样得到每个数字的位数？

完整题解

用除以 10 统计数位

核心洞察：正整数每整除一次 10，就去掉最右侧一位。重复到数字变为 0，执行次数就是十进制位数；位数能被 2 整除时计数。

完整过程

  1. 初始化答案 answer = 0。
  2. 对数组中的每个数字，用临时变量反复整除 10，并累计位数。
  3. 如果位数为偶数，让答案加 1。
  4. 遍历结束后返回答案。

正确性说明

对任意正整数 x，每次执行整数除法 x / 10 都恰好删除其十进制表示的末位。因此，循环结束时累计次数恰好等于原数字的数位个数。算法只在该次数为偶数时增加答案，所以每个符合条件的数字被计一次，其余数字不计；最终答案正确。

复杂度

设数组长度为 n，最大数字有 d 位。时间复杂度为 O(n·d)，额外空间复杂度为 O(1)。

边界情况

  • 单元素数组也必须正常计数。
  • 1 只有一位，不计入答案。
  • 100000 有六位，应计入答案。
  • 本题输入均为正整数，不需要处理负号或零。

替代方案

字符串法：把数字转成字符串，再检查长度奇偶。写法直观，但每个数字会创建字符串。

区间法：在本题约束内，偶数位数字只会落在 [10,99]、[1000,9999] 或恰好为 100000。速度快，但依赖题目上界，通用性较差。

class Solution {
    public int findNumbers(int[] nums) {
        int answer = 0;
        for (int num : nums) {
            int digits = 0;
            int value = num;
            while (value > 0) {
                value /= 10;
                digits++;
            }
            if (digits % 2 == 0) {
                answer++;
            }
        }
        return answer;
    }
}

var findNumbers = function(nums) {
    let answer = 0;
    for (const num of nums) {
        let digits = 0;
        let value = num;
        while (value > 0) {
            value = Math.floor(value / 10);
            digits++;
        }
        if (digits % 2 === 0) {
            answer++;
        }
    }
    return answer;
};

常见错误

  • 把“数字是偶数”误读成“数字的位数是偶数”。
  • 整除循环直接修改数组元素，造成不必要的副作用。
  • 用浮点对数计算位数，却忽略精度和边界问题。
  • 漏掉上界 100000 是六位数。
