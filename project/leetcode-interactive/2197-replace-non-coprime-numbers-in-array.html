Replace Non-Coprime Numbers in Array

相邻的两个数有共同因子，就把它们合成最小公倍数。
重复这个过程，直到每一对邻居都互质。最终会留下什么？

先理解规则，再自行思考。算法、交互实验与代码均在底部的折叠题解中。

官方题目 ↗

01 / 题目与规则

给定整数数组 nums。任选两个相邻且满足 GCD(x,y) > 1 的数，删除它们，在原位置放入 LCM(x,y)。持续操作，直到不存在这样的相邻数，返回最终数组。

GCD 为最大公约数，LCM 为最小公倍数。题目保证：任意合法替换顺序都得到相同终态，且最终数组的每个值都不超过 10⁸。

参数形式

replaceNonCoprimes(nums)
参数：nums: integer[]
返回：integer[]，保持剩余块的顺序。

完整约束

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁵
  • 最终数组中所有值 ≤ 10⁸

02 / 官方示例

示例 1

输入：nums = [6,4,3,2,7,6,2]
输出：[12,7,6]

一种合法过程：
(6,4) → 12，得到 [12,3,2,7,6,2]
(12,3) → 12，得到 [12,2,7,6,2]
(12,2) → 12，得到 [12,7,6,2]
(6,2) → 6，得到 [12,7,6]

相邻数均互质，停止。其他合法顺序也有相同结果。

示例 2

输入：nums = [2,2,1,1,3,3,3]
输出：[2,1,1,3]

一种合法过程：
右端两个 3 → 3，得到 [2,2,1,1,3,3]
剩下两个 3 → 3，得到 [2,2,1,1,3]
两个 2 → 2，得到 [2,1,1,3]

相邻数均互质，停止。1 与任何正整数互质，包括另一个 1。

04 / 独立题解

展开核心思路、可视化与四语言实现。

核心洞察：新值可能一路向左合并

用栈存放已经处理好的前缀，保证栈内相邻数互质。读入新数 x 时，唯一可能违反规则的是它与栈顶的边界。若 GCD 大于 1，就弹出栈顶，将二者的 LCM 作为新 x，再和新的栈顶比较。

[6,35,10] 是关键反例：6 与 35 原本互质，35 与 10 合成 70 后，70 又能与 6 合成 210。所以必须反复向左检查，不能只合并一次。

完整过程

  1. 建立空栈，按原顺序读取元素作为 x。
  2. 栈非空时，计算 g = gcd(stack.top, x)。
  3. 若 g 为 1，停止；否则弹出栈顶 a，令 x = (a / g) * x，继续向左检查。
  4. 将最终的 x 入栈。全部读完后返回栈。

正确性：前缀不变式

每轮读入前，栈是已读前缀经过合法合并得到的数组，且内部相邻元素互质。空栈显然成立。循环中仅合并相邻且 GCD 大于 1 的栈顶和当前块，每一步都合法，并保持原顺序。剩余栈内部边界不变，只有新块与栈顶的边界需要重新检查。

当循环停止时，栈空或该边界互质；将 x 入栈便恢复不变式。遍历结束后，整个数组不存在可合并的相邻元素，因此得到一个合法终态。根据题目给定的终态唯一性，该终态就是答案。

复杂度与整数安全

设 n 为长度、M 为过程中最大值。每个输入入栈一次，每个栈项最多弹出一次，成功合并最多 n−1 次；每轮读入最多再有一次失败比较。GCD 使用欧几里得算法，耗时 O(log M)，总时间 O(n log M)，栈空间 O(n)。

中间块的值整除它最终所属块的值，因此中间值也不超过 10⁸。LCM 应先除后乘，避免无用的大乘积。Java / C++ 用宽整数完成乘法；JavaScript 先除后乘时结果不超过 10⁸，可用 Number 精确表示。不要用位运算代替数值运算。

边界与常见错误

  • 单元素直接保留；相同且大于 1 的数可以合并，两个 1 不能合并。
  • 1 是隔断，不能跨过 1 合并两端。
  • 只能合并相邻元素，不能排序，也不能直接求全数组 LCM。
  • 必须使用 while；更新 x 后重新求 GCD，不能只用一次 if。
  • 非互质是 GCD 大于 1，不等价于两个数相同或都是偶数。

替代方案

每次从头扫描、删除一对再重扫，最坏可达 O(n² log M)，数组删除还有搬移成本。双向链表配合待处理边界队列也可做局部合并，但维护更复杂。用原数组和写指针模拟栈，可节省为 O(1) 额外工作空间（不含返回值），代价是修改输入。

面试追问

  • 双层循环为什么不是平方级？ 每次成功循环都弹出一个栈项，累计弹出次数线性。
  • 能否立刻输出已处理前缀？ 一般不能，未来值可能触发连锁回退；遇到 1 则形成永久隔断。
  • 去掉最终值上界？ LCM 可能很大，需要大整数，并计入大整数运算成本。
  • 如何理解终态唯一？ 不相交的两次合并可以交换。若 (a,b) 与 (b,c) 都可合并，两条路径都能进一步合成 lcm(a,b,c)。每步缩短数组，局部冲突可汇合，所以最终结果唯一。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    private int gcd(int a, int b) {
        while (b != 0) {
            int r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
    public List<Integer> replaceNonCoprimes(int[] nums) {
        List<Integer> stack = new ArrayList<>();
        for (int value : nums) {
            int x = value;
            while (!stack.isEmpty()) {
                int a = stack.get(stack.size() - 1);
                int g = gcd(a, x);
                if (g == 1) break;
                stack.remove(stack.size() - 1);
                x = (int) ((long) (a / g) * x);
            }
            stack.add(x);
        }
        return stack;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number[]}
 */
var replaceNonCoprimes = function(nums) {
    const gcd = (a, b) => {
        while (b !== 0) [a, b] = [b, a % b];
        return a;
    };
    const stack = [];
    for (let x of nums) {
        while (stack.length) {
            const a = stack[stack.length - 1];
            const g = gcd(a, x);
            if (g === 1) break;
            stack.pop();
            x = (a / g) * x;
        }
        stack.push(x);
    }
    return stack;
};

Python 3

from math import gcd
from typing import List

class Solution:
    def replaceNonCoprimes(self, nums: List[int]) -> List[int]:
        stack = []
        for x in nums:
            while stack:
                g = gcd(stack[-1], x)
                if g == 1:
                    break
                x = (stack.pop() // g) * x
            stack.append(x)
        return stack

C++

#include <vector>
#include <numeric>
using namespace std;

class Solution {
public:
    vector<int> replaceNonCoprimes(vector<int>& nums) {
        vector<int> stack;
        for (int x : nums) {
            while (!stack.empty()) {
                int a = stack.back();
                int g = gcd(a, x);
                if (g == 1) break;
                stack.pop_back();
                x = static_cast<int>(1LL * (a / g) * x);
            }
            stack.push_back(x);
        }
        return stack;
    }
};
