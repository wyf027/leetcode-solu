街上最亮的位置

Brightest Position on Street

路灯交叠，哪里最亮？如果答案不止一个，选择街道最左边的那个位置。

01 / 题目

给定二维整数数组 lights，每一项 [position, range] 表示路灯的位置与照明半径。它照亮闭区间 [position − range, position + range]。一个位置的亮度是覆盖它的路灯数量。返回亮度最大的位置；有多个答案时，返回最小坐标。

brightestPosition(lights: integer[][]) → integer

约束

  • 1 ≤ lights.length ≤ 10⁵
  • lights[i].length = 2
  • −10⁸ ≤ positionᵢ ≤ 10⁸
  • 0 ≤ rangeᵢ ≤ 10⁸

思考：最亮的位置一定是某一盏路灯所在的坐标吗？

02 / 官方示例

示例 1

输入：lights = [[-3,2],[1,2],[3,3]]
输出：-1

三盏灯覆盖 [−5,−1]、[−1,3]、[0,6]。最大亮度为 2，最左侧达到这一亮度的坐标是 −1。

示例 2

输入：lights = [[1,0],[0,1]]
输出：1

坐标 1 被两盏灯覆盖。半径为 0 的灯仍照亮自身位置。

示例 3

输入：lights = [[1,2]]
输出：-1

区间 [−1,3] 内亮度都是 1，选择最左端 −1。

题解 / 稀疏差分扫描线

核心洞察

亮度只会在区间边界附近变化。将每盏灯的闭区间写成 [L,R]，在 L 记 +1，在 R+1 记 −1。对事件按坐标排序并合并同点变化，再求前缀和。

街道即使看作连续数轴，所有区间端点仍是整数，最左最大亮度必在整数左端点取得。因此求整数位置上的最左最亮点就足够。R+1 差分与下方图示均描述整数坐标上的亮度。

完整过程

  1. 计算 L=position−range、R=position+range。
  2. 累加 delta[L]+=1 与 delta[R+1]−=1。
  3. 递增扫描不同事件坐标 x，先执行 current+=delta[x]。
  4. 仅当 current>best，保存 best=current、answer=x。
  5. 相等时不更新，最终返回最早取得最大亮度的位置。

正确性

对任一整数 x，一盏灯的两个事件前缀和在 L≤x≤R 时恰好为 1，其余时候为 0。将所有路灯的贡献相加，就得到真实亮度。相邻事件间的整数位置亮度不变，最左位置为左侧事件坐标，所以扫描所有事件足以覆盖最优候选。扫描顺序递增，只有更大亮度才更新，保证并列时保留最小坐标。

边界与常见错误

  • 零半径依然覆盖一个位置；多个相同路灯要累加。
  • 闭区间在 R+1 才结束，不能在 R 减一。
  • 同坐标事件先合并，再比较最大值，避免读取临时亮度。
  • 用 ≥ 更新会覆盖更靠左的正确答案。
  • JavaScript 必须数值排序，不能依赖默认字符串排序。
  • 坐标可为负且跨度大，不能直接分配按坐标索引的数组。
  • 事件坐标范围为 [−2×10⁸,2×10⁸+1]，当前约束下 32 位整数足够；扩展范围后应使用 64 位。

复杂度

n 盏灯至多产生 2n 个事件，总时间 O(n log n)，额外空间 O(n)。四份实现均不修改输入。

替代方案

按左端点排序，用最小堆保存还有效的右端点。处理一个左端点时，弹出所有严格小于它的右端点，再加入新区间；堆大小即该位置亮度。仍为 O(n log n) 时间。只有坐标范围很小时才适合稠密差分数组。

面试追问

  • 路灯有权重：将事件 ±1 换成 ±weight。
  • 实数端点：不能用 R+1，应分别处理同点开始、查询和结束事件。
  • 动态增删灯：考虑坐标压缩与维护区间加、最大值及最左位置的线段树。
  • 返回所有最亮整数段：检查每个 [x,nextX−1]，筛选最大亮度段，再合并相邻区间。

Java

import java.util.Map;
import java.util.TreeMap;

class Solution {
    public int brightestPosition(int[][] lights) {
        TreeMap<Integer, Integer> delta = new TreeMap<>();
        for (int[] light : lights) {
            int left = light[0] - light[1];
            int after = light[0] + light[1] + 1;
            delta.merge(left, 1, Integer::sum);
            delta.merge(after, -1, Integer::sum);
        }
        int current = 0, best = 0, answer = 0;
        for (Map.Entry<Integer, Integer> event : delta.entrySet()) {
            current += event.getValue();
            if (current > best) {
                best = current;
                answer = event.getKey();
            }
        }
        return answer;
    }
}

/** @param {number[][]} lights @return {number} */
var brightestPosition = function(lights) {
    const delta = new Map();
    for (const [p, r] of lights) {
        const left = p - r, after = p + r + 1;
        delta.set(left, (delta.get(left) || 0) + 1);
        delta.set(after, (delta.get(after) || 0) - 1);
    }
    let current = 0, best = 0, answer = 0;
    const points = [...delta.keys()].sort((a, b) => a - b);
    for (const x of points) {
        current += delta.get(x);
        if (current > best) {
            best = current;
            answer = x;
        }
    }
    return answer;
};

Python

from typing import List

class Solution:
    def brightestPosition(self, lights: List[List[int]]) -> int:
        delta = {}
        for position, radius in lights:
            left = position - radius
            after = position + radius + 1
            delta[left] = delta.get(left, 0) + 1
            delta[after] = delta.get(after, 0) - 1
        current = best = answer = 0
        for x in sorted(delta):
            current += delta[x]
            if current > best:
                best = current
                answer = x
        return answer

C++

#include <vector>
#include <map>
using namespace std;

class Solution {
public:
    int brightestPosition(vector<vector<int>>& lights) {
        map<int, int> delta;
        for (const auto& light : lights) {
            ++delta[light[0] - light[1]];
            --delta[light[0] + light[1] + 1];
        }
        int current = 0, best = 0, answer = 0;
        for (const auto& event : delta) {
            current += event.second;
            if (current > best) {
                best = current;
                answer = event.first;
            }
        }
        return answer;
    }
};
