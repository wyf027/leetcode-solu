Largest Divisible Subset

从一组互不相同的正整数中，找出一个尽可能大的子集，使其中任意两个数总有一个可以整除另一个。若答案不唯一，返回任意一个即可。

输入：nums: integer[] 输出：list<integer> 非付费题

Problem

题目要求

给定由无重复正整数组成的数组 nums，返回元素数量最多的子集 answer。对于子集中的每一对元素 answer[i] 与 answer[j]，至少满足以下一个条件：

  • answer[i] % answer[j] == 0
  • answer[j] % answer[i] == 0

若存在多个最大子集，可以返回其中任意一个；答案中的元素顺序不作要求。

Examples

官方示例

示例 1

输入：nums = [1,2,3]
输出：[1,2]
解释：[1,3] 也会被视为正确答案。

示例 2

输入：nums = [1,2,4,8]
输出：[1,2,4,8]

Constraints

数据范围

  • 1 <= nums.length <= 1000
  • 1 <= nums[i] <= 2 × 10⁹
  • nums 中的整数两两不同
  • 所有元素均为正整数

Solution

排序 + 动态规划 + 前驱回溯

核心洞察

先把数组升序排列。若已有一条整除链以较小数 a[j] 结尾，而 a[i] % a[j] == 0，那么 a[i] 不仅能被末尾整除，也能被链上所有更早的数整除。这来自整除关系的传递性。

状态定义

dp[i]：以排序后 a[i] 结尾的最长整除链长度。

parent[i]：该最优链中 a[i] 的前一个下标，用于恢复具体答案。

转移：若 a[i] % a[j] == 0 且 dp[j] + 1 > dp[i]，就用 j 更新 i。

完整过程

  1. 复制并升序排序 nums。
  2. 令每个 dp[i] = 1、parent[i] = -1，表示每个数单独成链。
  3. 按从小到大枚举终点 i；再枚举所有 j < i。
  4. 当 a[i] 能被 a[j] 整除时，尝试由 j 的最优链转移到 i。
  5. 记住全局最长链的终点，从该下标沿 parent 一直回溯到 -1，得到答案。

为什么正确

引理 1：若升序整除链的末尾为 x，且更大的数 y 满足 y % x == 0，则把 y 接到链尾后仍是合法整除子集。因为链中任意元素 z 都整除 x，而 x 整除 y，由传递性可知 z 整除 y。

引理 2：处理完下标 i 后，dp[i] 等于所有以 a[i] 结尾的整除链的最大长度。长度为 1 的链由初始化覆盖；任何更长的合法链都有某个倒数第二项 a[j]，其中 j < i 且 a[i] % a[j] == 0。算法枚举全部这样的 j，并选取最大 dp[j] + 1。

结论：任一非空最优解都有一个最大元素作为终点。算法比较所有终点的 dp，因此选出的全局终点对应最大长度；沿记录的前驱回溯得到的每次转移都满足整除条件，所以恢复出的集合既合法又最大。

复杂度

  • 排序：O(n log n)
  • 双层转移：O(n²)
  • 回溯：O(n)
  • 总时间：O(n²)
  • 额外空间：O(n)

边界情况

  • 仅一个元素时直接得到该元素。
  • 没有两数可整除时，任意单元素都是最大解。
  • 所有数构成一条链时，答案包含全部元素。
  • 多个同长度答案时无需固定选择。
  • 值可达 2 × 10⁹，但只做取模，不做乘法。

常见错误

  • 不排序就只检查链尾，传递性依据会失效。
  • 只记录长度而忘记前驱，无法恢复具体子集。
  • 更新 dp 时没有同步更新 parent。
  • 误以为答案必须按输入顺序或升序返回。
  • 用贪心选择第一个可整除数，可能错过更长链。

Implementations

四语言完整代码

均遵循官方函数签名；返回链的顺序可能从大到小，仍满足题目要求。

Java 
class Solution {
    public List<Integer> largestDivisibleSubset(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;
        int[] dp = new int[n];
        int[] parent = new int[n];
        Arrays.fill(dp, 1);
        Arrays.fill(parent, -1);

        int bestEnd = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[i] % nums[j] == 0 && dp[j] + 1 > dp[i]) {
                    dp[i] = dp[j] + 1;
                    parent[i] = j;
                }
            }
            if (dp[i] > dp[bestEnd]) {
                bestEnd = i;
            }
        }

        List<Integer> answer = new ArrayList<>();
        for (int i = bestEnd; i != -1; i = parent[i]) {
            answer.add(nums[i]);
        }
        return answer;
    }
}

var largestDivisibleSubset = function(nums) {
    const sorted = [...nums].sort((a, b) => a - b);
    const n = sorted.length;
    const dp = new Array(n).fill(1);
    const parent = new Array(n).fill(-1);
    let bestEnd = 0;

    for (let i = 0; i < n; i++) {
        for (let j = 0; j < i; j++) {
            if (sorted[i] % sorted[j] === 0 && dp[j] + 1 > dp[i]) {
                dp[i] = dp[j] + 1;
                parent[i] = j;
            }
        }
        if (dp[i] > dp[bestEnd]) {
            bestEnd = i;
        }
    }

    const answer = [];
    for (let i = bestEnd; i !== -1; i = parent[i]) {
        answer.push(sorted[i]);
    }
    return answer;
};
Python 
class Solution:
    def largestDivisibleSubset(self, nums: List[int]) -> List[int]:
        nums = sorted(nums)
        n = len(nums)
        dp = [1] * n
        parent = [-1] * n
        best_end = 0

        for i in range(n):
            for j in range(i):
                if nums[i] % nums[j] == 0 and dp[j] + 1 > dp[i]:
                    dp[i] = dp[j] + 1
                    parent[i] = j
            if dp[i] > dp[best_end]:
                best_end = i

        answer = []
        current = best_end
        while current != -1:
            answer.append(nums[current])
            current = parent[current]
        return answer

                    dp[i] = dp[j] + 1;
                    parent[i] = j;

                bestEnd = i;
            }
        }

        vector<int> answer;

        }
        return answer;

替代方案

  • 整除 DAG 最长路：将每个数视为结点，整除关系视为有向边，本质仍是在排序后的 DAG 上做最长路 DP。
  • 回溯枚举：可枚举所有子集，但最坏需要指数时间，只适合极小输入。
  • 按因子查状态：可枚举每个值的因子并用哈希表找前驱；大值的因数分解成本和实现复杂度更高，在 n ≤ 1000 时不如 O(n²) 稳妥。
