MEDIUM会员题2345

寻找可见山的数量

Finding the Number of Visible Mountains

哪些山峰，真正露在群山之外？
先理解可见规则，再展开下方的推演。

01 / 读题

看的是山峰，而非露出的山体

输入二维整数数组 peaks，第 i 项 [xᵢ, yᵢ] 指定一座山的顶点。每座山都是底边落在 x 轴上的等腰直角三角形，左右两条斜边的斜率分别为 +1 和 −1。

如果一座山的顶点落入任何另一座山的内部或边界，它就不可见；否则可见。返回可见山的数量。同坐标的山仍是不同山，不能先去重再计数。

返回形式：visibleMountains(peaks) → integer。可见性与绘图的前后层级无关，完全由几何包含关系决定。

官方示例 1

输入：peaks = [[2,2],[6,3],[5,4]]
输出：2

山 0 与山 2 可见；山 1 的顶点 (6,3) 正好落在山 2 的斜边上，因此不可见。

官方示例 2

输入：peaks = [[1,3],[1,3]]
输出：0

两座山完全重合。各自的顶点都位于另一座山的边界，两座都不计入答案。

约束

  • 1 ≤ peaks.length ≤ 10⁵
  • peaks[i].length == 2
  • 1 ≤ xᵢ, yᵢ ≤ 10⁵

03 / 深入推演

准备好再看题解

包含可操作的山形与区间同步演示、证明及四语言实现。

核心洞察：将山峰投影成区间

山峰 (x,y) 的底边是 [L,R] = [x−y,x+y]。所有山的斜率相同，因此山 A 遮住山 B 的峰顶，恰好等价于 A 的底边区间包含 B 的底边区间。

A 遮住 B ⇔ yA − |xB − xA| ≥ yB
          ⇔ xA − yA ≤ xB − yB 且 xA + yA ≥ xB + yB
          ⇔ LA ≤ LB 且 RA ≥ RB

按 L 升序、L 相同时按 R 降序排列。扫描时，前面所有区间的 L 都不大于当前 L，所以只需记录前缀最大的右端点 maxRight。相同区间连续分组处理：组内数量大于 1 时，整组互相遮挡。

完整过程

  1. 构造每座山的底边区间 [x−y,x+y]，保留重复项。
  2. 按左端点升序、右端点降序排序；初始化答案为 0，maxRight 为负无穷。
  3. 从 i 开始找到连续相同区间的结尾 j，组内有 j−i 座山。
  4. 仅当 R > maxRight 且组大小等于 1 时，答案加一。
  5. 无论本组是否计数，都更新 maxRight = max(maxRight,R)，然后令 i = j。

示例 1：排序得到 [0,4]、[1,9]、[3,9]。前两组分别将最大右端点推进至 4 和 9；第三组的右端点等于 9，落在已有山的边界，因此不计数，最终为 2。

正确性证明

循环不变量：每轮开始时，maxRight 是此前所有已处理区间的最大右端点，答案等于已处理组中最终可见的山数。初始前缀为空，不变量成立。

若 R ≤ maxRight，存在先前区间左端点不大于 L、右端点不小于 R，因此当前山被遮挡。若 R > maxRight，没有先前区间能遮住它；后续不同区间要么左端点更大，要么同左端点而右端点更小，也不能包含它。同区间组内若有多座则彼此遮挡，否则这一座可见。

每轮按上述规则计数并更新前缀最大值，不变量持续成立。所有分组处理完成时，答案就是全部可见山数。

边界与常见错误

  • 重复不能计一个：完全相同的两座山答案是 0；先去重会丢掉这个语义。
  • 不可见也要更新最大值：重复大山自身不可见，但仍能遮挡后续小山。
  • 相等算遮挡：判断可见使用严格 R > maxRight，不能用 ≥。
  • 同 L 必须让大 R 在前：否则小山可能被过早计入。
  • 区间相交不等于包含：[0,4] 与 [2,6] 对应的两座山都可见。
  • 负端点正常：L 可以低至 −99999，R 最高为 200000；所有端点及计数均在 32 位有符号整数范围内。

复杂度

排序 O(n log n)，分组扫描 O(n)，总时间 O(n log n)。四份实现都构造区间数组，总额外空间 O(n)；不依赖排序内部具体空间实现。

替代方案

  • 直接检查每个顶点是否落入其他山：O(n²) 时间、O(1) 额外空间，便于小规模理解，但不适合 10⁵ 座山。
  • 用哈希表记录区间频次，再做排序扫描：同样 O(n log n) 时间、O(n) 空间；连续分组可省去哈希表。
  • 按峰顶横坐标排序并维护单调栈也可解；要处理弹栈与重复语义。这里只需最大右端点，使用一个标量更直接。

面试追问

  • 如果要返回编号？构造区间时携带原始下标，唯一且可见的分组输出其下标。
  • 重复山改成只计一座？保留分组，R > maxRight 时计一，不再要求组大小等于 1。
  • 输入已按区间规则有序？省去排序，扫描为 O(n) 时间。
  • 允许山有不同斜率？底边包含不再足以表达峰顶遮挡，需要重新建立几何判定，不能直接套用本算法。

四语言完整代码

Java

import java.util.Arrays;

class Solution {
    public int visibleMountains(int[][] peaks) {
        int n = peaks.length;
        int[][] a = new int[n][2];
        for (int i = 0; i < n; i++) {
            a[i][0] = peaks[i][0] - peaks[i][1];
            a[i][1] = peaks[i][0] + peaks[i][1];
        }
        Arrays.sort(a, (u, v) -> u[0] == v[0]
            ? Integer.compare(v[1], u[1])
            : Integer.compare(u[0], v[0]));
        int answer = 0, maxRight = Integer.MIN_VALUE;
        for (int i = 0; i < n; ) {
            int j = i + 1;
            while (j < n && a[j][0] == a[i][0]
                         && a[j][1] == a[i][1]) j++;
            if (a[i][1] > maxRight && j == i + 1) answer++;
            maxRight = Math.max(maxRight, a[i][1]);
            i = j;
        }
        return answer;
    }
}

/**
 * @param {number[][]} peaks
 * @return {number}

var visibleMountains = function(peaks) {
    const a = peaks.map(([x, y]) => [x - y, x + y]);
    a.sort((u, v) => u[0] - v[0] || v[1] - u[1]);
    let answer = 0, maxRight = -Infinity;
    for (let i = 0; i < a.length; ) {
        let j = i + 1;
        while (j < a.length && a[j][0] === a[i][0]
                            && a[j][1] === a[i][1]) j++;
        if (a[i][1] > maxRight && j === i + 1) answer++;
        maxRight = Math.max(maxRight, a[i][1]);
        i = j;
    }
    return answer;
};

from typing import List

class Solution:
    def visibleMountains(self, peaks: List[List[int]]) -> int:
        a = sorted(((x - y, x + y) for x, y in peaks),
                   key=lambda t: (t[0], -t[1]))
        answer = 0
        max_right = float("-inf")
        i = 0
        while i < len(a):
            j = i + 1
            while j < len(a) and a[j] == a[i]:
                j += 1
            if a[i][1] > max_right and j == i + 1:
                answer += 1
            max_right = max(max_right, a[i][1])
            i = j
        return answer

C++

#include <algorithm>
#include <climits>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int visibleMountains(vector<vector<int>>& peaks) {
        vector<pair<int, int>> a;
        a.reserve(peaks.size());
        for (const auto& p : peaks)
            a.emplace_back(p[0] - p[1], p[0] + p[1]);
        sort(a.begin(), a.end(), [](const auto& u, const auto& v) {
            return u.first != v.first ? u.first < v.first
                                     : u.second > v.second;
        });
        int answer = 0, maxRight = INT_MIN;
        int n = static_cast<int>(a.size());
        for (int i = 0; i < n; ) {
            int j = i + 1;
            while (j < n && a[j] == a[i]) ++j;
            if (a[i].second > maxRight && j == i + 1) ++answer;
            maxRight = max(maxRight, a[i].second);
            i = j;
        }
        return answer;
    }
};
