比较双调部分的和

把双调数组在峰顶切成两段。峰值属于两段，所以不是普通的左右互斥分割；本页用一趟扫描把这件事摊开。

题意

给定严格先增后减的 nums。上升部分是从开头到峰值（含峰值），下降部分是从峰值到结尾（也含峰值）。比较两段总和：

  • 上升部分较大，返回 0；
  • 下降部分较大，返回 1；
  • 相等，返回 -1。
示例
nums = [1, 3, 2, 1]
峰值为 3；上升和 1 + 3 = 4，下降和 3 + 2 + 1 = 6，结果为 1。

约束：3 <= nums.length <= 10^5，1 <= nums[i] <= 10^9；数组保证为双调数组。和须用 64 位整数保存。

题解：把峰值只算一次“移动”

令 right 先等于整个数组的总和，left 从 nums[0] 开始。只要相邻元素仍在上升，就把新元素加入 left，并把前一个元素从 right 移走。到第一次下降时：left 正好是上升段（含峰），right 正好是下降段（含峰）。

正确性要点
每一步前一个元素已经确定不在下降段；峰值不会被移走，因为下降出现时循环先停止。因此两边都保留峰值。

复杂度与边界

  • 时间 O(n)，空间 O(1)。
  • 峰值靠近两端时同样成立；题目保证严格双调。
  • 最大总和可达 10^14，Java/C++ 使用 long / long long。

替代方案、面试追问与常见错误

替代方案是先找峰值再分别求和，仍为 O(n)，但多一次遍历。追问：若数组不保证双调，先验证趋势或定义峰的选择规则。常见错误：把峰值只算到一侧；在下降边界把峰值从 right 中扣掉；用 32 位整型累计总和。

class Solution {
    public int compareBitonicSums(int[] nums) {
        long left = nums[0], right = 0;
        for (int x : nums) right += x;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i - 1] > nums[i]) break;
            left += nums[i];
            right -= nums[i - 1];
        }
        if (left == right) return -1;
        return left > right ? 0 : 1;
    }
}

var compareBitonicSums = function (nums) {
  let left = nums[0];
  let right = nums.reduce((sum, x) => sum + x, 0);
  for (let i = 1; i < nums.length; i++) {
    if (nums[i - 1] > nums[i]) break;
    left += nums[i];
    right -= nums[i - 1];
  }
  return left === right ? -1 : left > right ? 0 : 1;
};
