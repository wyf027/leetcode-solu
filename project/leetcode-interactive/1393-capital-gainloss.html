股票的
资本损益

把每笔交易先变成带正负号的现金流，再按股票归集。先用交互流水账观察结果；题解默认收起。

Problem

题意

给定 Stocks 表，每行记录一只股票某天的买入或卖出价格。请计算每只股票经过一次或多次完整买卖后的总资本收益或损失，并以任意顺序返回 stock_name 与 capital_gain_loss。

列名类型含义
stock_namevarchar(15)股票名称
operationenum('Sell','Buy')交易方向
operation_dayint操作日
priceint成交价格
约束与保证：(stock_name, operation_day) 是主键；每次卖出之前都有对应买入，每次买入之后都有对应卖出。官方题面未列出额外数值范围。

Deep dive

完整题解

默认隐藏，准备好后再展开。

核心洞察

无需显式配对每次买卖。对同一股票而言，资本损益就是所有卖出价之和减去所有买入价之和。把每行映射成带符号金额：Sell → +price，Buy → −price，最后按 stock_name 求和即可。

完整过程

  1. 用 CASE 判断交易方向。
  2. 卖出返回原价，买入返回相反数。
  3. 按股票名称 GROUP BY。
  4. 用 SUM 得到每只股票的净现金流，即资本损益。

正确性证明

固定任意股票 s。每次完整交易对资本损益的贡献为 sell_price - buy_price。算法把对应买入行贡献记作 -buy_price，卖出行贡献记作 +sell_price，二者之和完全相同。对 s 的全部行求和，依据加法结合律，等于所有完整交易贡献之和。因此每个分组得到的值恰是该股票的总资本损益；对所有股票分组后结论成立。

边界情况

  • 只有一对买卖：直接得到价差。
  • 多次交易：无需依赖输入顺序。
  • 亏损：总和自然为负。
  • 盈亏抵消：结果可以为 0。
  • 多股票交错：分组保证互不影响。

复杂度

数据库需扫描 n 行；逻辑时间为 O(n)。分组聚合的额外空间通常为 O(k)，其中 k 是不同股票数；具体执行计划由数据库决定。

替代方案

也可分别聚合买入与卖出后再连接，但需要更多表达式和一次连接；使用条件聚合更直接。显式按日期配对则属于不必要的复杂化。

官方可提交方案 · MySQL

SELECT
    stock_name,
    SUM(CASE
            WHEN operation = 'Sell' THEN price
            ELSE -price
        END) AS capital_gain_loss
FROM Stocks
GROUP BY stock_name;

本题是数据库题，LeetCode 官方提交语言为 SQL（另支持 Pandas）。以下 Java、JavaScript、Python、C++ 代码仅在本地用等价的行记录模拟聚合，不能作为本题的 LeetCode 通用语言提交。

import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

class Solution {
    record Trade(String stockName, String operation, int day, int price) {}

    public Map<String, Long> capitalGainLoss(List<Trade> stocks) {
        Map<String, Long> result = new LinkedHashMap<>();
        for (Trade trade : stocks) {
            long signedPrice = trade.operation().equals("Sell")
                    ? trade.price() : -trade.price();
            result.merge(trade.stockName(), signedPrice, Long::sum);
        }
        return result;
    }
}
function capitalGainLoss(stocks) {
  const result = new Map();
  for (const { stockName, operation, price } of stocks) {
    const signedPrice = operation === "Sell" ? price : -price;
    result.set(stockName, (result.get(stockName) ?? 0) + signedPrice);
  }
  return result;
}
from collections import defaultdict
from dataclasses import dataclass

@dataclass(frozen=True)
class Trade:
    stock_name: str
    operation: str
    day: int
    price: int

def capital_gain_loss(stocks: list[Trade]) -> dict[str, int]:
    result: dict[str, int] = defaultdict(int)
    for trade in stocks:
        signed_price = trade.price if trade.operation == "Sell" else -trade.price
        result[trade.stock_name] += signed_price
    return dict(result)

面试追问

  • 为什么不需要按日期匹配买入与卖出？
  • 若允许持仓数量不同，表结构和公式如何改变？
  • 若存在手续费，应该在哪一层扣除？
  • 如何只统计某个日期区间内已闭合的交易？

常见错误

  • 把买入也当成正数相加。
  • 按 operation 一起分组，导致每只股票被拆成两行。
  • 用 ABS，从而丢失亏损符号。
  • 误以为必须自连接来配对每笔交易。
  • 依赖结果顺序，但题目明确允许任意顺序。
