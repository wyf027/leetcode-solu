LCR 051 · Hard · Tree DP

树上能量汇流台 Binary Tree Maximum Path Sum

一条合法路径可以从树中任意节点出发、在任意节点结束，但不能重复经过节点。 每棵子树只向父节点上送一条支路；左右两条支路只能在当前节点汇合一次，形成候选完整路径。

Confluence protocol

一条上行臂，一次双臂汇流。

down = val + max(0, L, R) through = val + max(0, L) + max(0, R)

负贡献直接断开；答案必须来自至少一个真实节点，不能把空路径当成 0。

01 · Mission brief

题意校准

路径是相邻节点序列，同一节点至多出现一次；它至少包含一个节点，也不要求经过根节点。

官方样例 1

左右子节点都能给根节点提供正增益，因此最优路径在根节点汇流。

root = [1,2,3] 期望输出 = 6

官方样例 2

根节点 -10 不必进入答案；最优路径可完全位于右子树。

root = [-10,9,20,null,null,15,7] 期望输出 = 42

约束

  • 节点数：1 ≤ n ≤ 3 × 10⁴
  • 节点值：-1000 ≤ Node.val ≤ 1000
  • 输入采用 LeetCode 层序数组格式，null 表示缺失节点。

易混点

路径可以在某个节点同时接入左右子树，但向父节点返回时不能再携带两条分支，否则会产生三叉路径。

本题没有字符串输入；因此不涉及空格可视化。若出现字符串，本系列统一以 ␠ 表示空格。

    Solution dossier

    题解

    推荐思路：后序 DFS + 树形动态规划；实现采用显式栈，规避最深 3 × 10⁴ 层的递归栈风险。

    核心洞察

    对节点 x，子问题要回答两个不同问题：一是“从 x 出发向下，最多能拿到多少”（返回给父节点）；二是“以 x 为最高汇合点的完整路径是多少”（只用于更新全局答案）。

    down(x)

    只能选择左臂或右臂中的较大者，因为父节点再接入时必须保持为一条简单路径。

    through(x)

    可以同时接入左右两臂；它在 x 处闭合，不能作为整体继续向父节点上送。

    完整过程

    1. 按后序遍历处理节点，确保左右孩子的最大上行增益已知。
    2. 把负增益截断为 0：接上一条负支路只会让路径更差。
    3. 计算 through = val + left + right 并更新全局最大值。
    4. 保存 down = val + max(left, right)，供父节点使用。
    5. 所有节点处理完毕后，全局最大值就是答案。

    边界与不变量

    • 全负树：答案必须是最大的单个节点值，因此全局答案初始化为负无穷，而不是 0。
    • 单节点：左右增益均为 0，through 与 down 都等于节点值。
    • 最优路径不经过根：每个节点都会独立尝试成为汇合点，全局变量会保留右子树内部的最优值。
    • 链状树：每个节点至多保留一条子链；显式栈避免 3 × 10⁴ 层递归溢出。

    复杂度与替代方案

    推荐：后序 DP

    时间 O(n)，映射存储每个节点的上行增益，空间 O(n)。递归写法在平衡树上空间 O(h)，但极深树有调用栈风险。

    替代：枚举端点

    从每个节点搜索所有路径，最坏 O(n²)，重复计算多，不适合面试主线。

    替代：纯递归 DFS

    代码最短、推导最直观；若面试官允许忽略语言栈限制，可直接递归实现相同转移。

    为何不是根到叶 DP

    本题端点任意，最优路径可能在某节点左右两侧闭合，不能只维护根到叶路径。

    面试追问

    • 如何恢复具体路径？ 除了增益，再保存被选择的子节点；全局更新时记录汇合点与两条下行链。
    • 如果必须从叶到叶？ 只有左右子树都存在叶时才能用 through 更新答案，返回值仍是最大根到叶和。
    • 如果节点值会溢出 int？ 把状态和答案改为 64 位整数；当前约束下最坏绝对值不超过 3 × 10⁷，int 足够。
    • 能否做到 O(h) 辅助空间？ 递归可按树高使用栈，但最坏 h=n；Morris 后序能压到 O(1)，实现复杂且会临时改树。

    常见错误

    • 把左右两臂合成的 through 返回给父节点，造成三叉路径。
    • 把答案初始化为 0，导致全负树错误返回空路径。
    • 没有把负子树贡献截断为 0。
    • 只在根节点计算答案，漏掉完全位于某棵子树内部的最优路径。
    • 在极深树上直接递归，却没有评估语言调用栈上限。

    class Solution {
    public int maxPathSum(TreeNode root) {
        java.util.Map<TreeNode, Integer> gain = new java.util.IdentityHashMap<>();
        java.util.Deque<Object[]> stack = new java.util.ArrayDeque<>();
        stack.push(new Object[] {root, false});
        int best = Integer.MIN_VALUE;

        while (!stack.isEmpty()) {
            Object[] item = stack.pop();
            TreeNode node = (TreeNode) item[0];
            boolean visited = (boolean) item[1];
            if (node == null) continue;

            if (!visited) {
                stack.push(new Object[] {node, true});
                if (node.right != null) stack.push(new Object[] {node.right, false});
                if (node.left != null) stack.push(new Object[] {node.left, false});
                continue;
            }

            int left = Math.max(0, gain.getOrDefault(node.left, 0));
            int right = Math.max(0, gain.getOrDefault(node.right, 0));
            best = Math.max(best, node.val + left + right);
            gain.put(node, node.val + Math.max(left, right));
        }
        return best;
    }
}

            if (node.right !== null) stack.push([node.right, false]);

        best = Math.max(best, node.val + left + right);
        gain.set(node, node.val + Math.max(left, right));
    }
    return best;

    class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        gain = {}
        stack = [(root, False)]
        best = float("-inf")

        while stack:
            node, visited = stack.pop()
            if node is None:
                continue

            if not visited:
                stack.append((node, True))
                if node.right is not None:
                    stack.append((node.right, False))
                if node.left is not None:
                    stack.append((node.left, False))
                continue

            left = max(0, gain.get(node.left, 0))
            right = max(0, gain.get(node.right, 0))
            best = max(best, node.val + left + right)
            gain[node] = node.val + max(left, right)

        return best
