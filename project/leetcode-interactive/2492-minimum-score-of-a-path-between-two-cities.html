2492. 两个城市间路径的最小分数

Minimum Score of a Path Between Two Cities

一条路径的分数，取决于其中最短的一段路。你能让这个分数尽可能小吗？

先理解规则，再展开底部题解与逐边交互演示。

01题意与规则

有 n 座城市，编号为 1 到 n。数组 roads 中每个元素 [aᵢ, bᵢ, distanceᵢ] 表示一条连接城市 aᵢ、bᵢ 的双向道路，其距离为 distanceᵢ。整张图可能不连通。

一条路径的分数是该路径经过的所有道路距离的最小值。返回从城市 1 到城市 n 的所有允许路径中，最小的分数。

允许重复经过同一条道路，也允许多次经过城市 1 和 n。输入保证 1 与 n 之间至少存在一条路径。这里的分数不是道路距离之和。

参数与返回值

minScore(n, roads) → integer，其中 n 为整数，roads 为整数二维数组。

完整约束

  • 2 ≤ n ≤ 10⁵
  • 1 ≤ roads.length ≤ 10⁵
  • roads[i].length == 3
  • 1 ≤ aᵢ, bᵢ ≤ n，且 aᵢ ≠ bᵢ
  • 1 ≤ distanceᵢ ≤ 10⁴
  • 没有重复边。
  • 城市 1 与城市 n 之间至少有一条路径。

02官方示例

示例 1

n = 4
roads = [[1,2,9],[2,3,6],[2,4,5],[1,4,7]]

输出：5

可走 1 → 2 → 4，分数为 min(9, 5) = 5。不存在分数更小的路径。

示例 2

n = 4
roads = [[1,2,2],[1,3,4],[3,4,7]]

输出：2

可走 1 → 2 → 1 → 3 → 4，分数为 min(2, 2, 4, 7) = 2；同一道路可以往返经过。

04题解 · 找到可达范围内的最小边

核心洞察

答案就是城市 1 所在连通分量中，所有道路的最小距离。因为可以重复走路，所以最小边即使在通往终点的支路上，也可以先绕过去经过它，再前往终点。

完整过程 · BFS

  1. 建立双向邻接表，每条道路存入两个端点的列表。
  2. 把城市 1 入队并标记已发现，答案初始化为无穷大。
  3. 每次取出队首城市，检查它的每条邻接边，立即用边权更新答案。
  4. 如果相邻城市尚未发现，则标记并入队。已发现的城市不重复入队，但对应的边仍参与取最小值。
  5. 队列处理完毕后返回答案，不因发现终点而提前停止。

逐边扫描器 · 队列与最小值同步变化

蓝绿色节点：已发现；橙色粗线：当前扫描边；绿色粗线：当前最小边；灰色虚线：尚未扫描。双向道路会从两个方向各扫描一次。

正确性证明

设 C 是包含城市 1 的连通分量，m 是 C 内最小边权。题目保证 n 也在 C 中。

  1. 下界：任意从 1 到 n 的路径只能使用 C 内的边，每条边的权值均不小于 m，因此路径分数不小于 m。
  2. 可达到：取一条权值为 m 的边 (u, v)。由于 C 连通，可以从 1 到 u，经过 (u, v)，再从 v 到 n；允许重复经过城市和道路，因此这个道路序列合法。它包含权值 m，且没有小于 m 的边，故分数恰为 m。
  3. 遍历覆盖：BFS 从 1 开始，且每个首次发现的城市都入队，最终恰好扫描 C 内全部城市的全部邻接边。维护的最小值即 m，所以返回正确答案。

边界与复杂度

令 E = roads.length。建立邻接表和遍历的总时间为 O(n + E)，空间为 O(n + E)。每条无向边扫描两次只增加常数。n = 2、链状图、环、等权边都适用。孤立城市及其他连通块不参与答案。长链使用迭代队列，避免递归深度风险。

替代方案

  • 迭代 DFS：把队列换成栈，同样访问整个连通分量，并对所有邻接边更新最小值，复杂度相同。
  • 并查集：先合并所有道路两端，再扫描 roads，对与 1 同根的边取最小值。带路径压缩、按大小合并时，时间 O(n + E α(n))，额外空间 O(n)。无需排序。

常见错误

  • 对整张图取最小边：最小边可能在另一个连通块。
  • 只在相邻节点未访问时更新答案：会遗漏连接两个已发现城市的非树边。
  • 到达 n 就停止：某条尚未扫描的支路可能拥有更小边。
  • 计算最短路或最大瓶颈：本题是让路径上的最小边尽量小，不是最小距离和，也不是让最小边尽量大。
  • JavaScript 用 shift() 出队：反复移动元素可能恶化性能，应使用递增头下标。

面试追问

  • 如何输出一条达到答案的路线？保存最小边 (u, v)，再找 1 到 u 和 v 到 n 的路线，将它们与该边连接；重复节点和道路合法。
  • 若禁止重复经过城市呢？连通分量最小边的结论失效。示例 2 的边 1—2 是支路，简单路径 1→3→4 无法使用它，分数为 4。
  • 若目标是最大化路径最小边？变成最大瓶颈路径，可使用最大生成树或按边权降序合并的并查集。
  • 若不保证 1 与 n 连通？遍历后检查 n 是否被发现，并根据新接口约定返回无解标记；当前题目无需这个分支。

Java

import java.util.*;

class Solution {
    public int minScore(int n, int[][] roads) {
        List<List<int[]>> graph = new ArrayList<>();
        for (int i = 0; i <= n; i++) graph.add(new ArrayList<>());
        for (int[] r : roads) {
            graph.get(r[0]).add(new int[]{r[1], r[2]});
            graph.get(r[1]).add(new int[]{r[0], r[2]});
        }
        boolean[] seen = new boolean[n + 1];
        ArrayDeque<Integer> queue = new ArrayDeque<>();
        queue.addLast(1);
        seen[1] = true;
        int answer = Integer.MAX_VALUE;
        while (!queue.isEmpty()) {
            int u = queue.removeFirst();
            for (int[] edge : graph.get(u)) {
                answer = Math.min(answer, edge[1]);
                int v = edge[0];
                if (!seen[v]) {
                    seen[v] = true;
                    queue.addLast(v);
                }
            }
        }
        return answer;
    }
}

var minScore = function(n, roads) {
    const graph = Array.from({ length: n + 1 }, () => []);
    for (const [a, b, w] of roads) {
        graph[a].push([b, w]);
        graph[b].push([a, w]);
    }
    const seen = new Uint8Array(n + 1);
    const queue = [1];
    seen[1] = 1;
    let answer = Infinity;
    for (let head = 0; head < queue.length; head++) {
        const u = queue[head];
        for (const [v, w] of graph[u]) {
            answer = Math.min(answer, w);
            if (!seen[v]) {
                seen[v] = 1;
                queue.push(v);
            }
        }
    }
    return answer;
};

Python 3

from typing import List
from collections import deque

class Solution:
    def minScore(self, n: int, roads: List[List[int]]) -> int:
        graph = [[] for _ in range(n + 1)]
        for a, b, w in roads:
            graph[a].append((b, w))
            graph[b].append((a, w))
        seen = [False] * (n + 1)
        seen[1] = True
        queue = deque([1])
        answer = float("inf")
        while queue:
            u = queue.popleft()
            for v, w in graph[u]:
                answer = min(answer, w)
                if not seen[v]:
                    seen[v] = True
                    queue.append(v)
        return int(answer)

C++

#include <vector>
#include <queue>
#include <utility>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int minScore(int n, vector<vector<int>>& roads) {
        vector<vector<pair<int, int>>> graph(n + 1);
        for (const auto& r : roads) {
            graph[r[0]].push_back({r[1], r[2]});
            graph[r[1]].push_back({r[0], r[2]});
        }
        vector<bool> seen(n + 1, false);
        queue<int> q;
        q.push(1);
        seen[1] = true;
        int answer = INT_MAX;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (const auto& edge : graph[u]) {
                int v = edge.first, w = edge.second;
                answer = min(answer, w);
                if (!seen[v]) {
                    seen[v] = true;
                    q.push(v);
                }
            }
        }
        return answer;
    }
};
