通过门的时间

Time Taken to Cross the Door

一扇门，两个方向，每秒仅一人。
当两边同时等待，谁该先走？关键在于上一秒。

队列数组模拟离线交互笔记

01 / 题目与规则

有 n 个人，编号为 0 到 n − 1。两个数组 arrival 和 state 分别表示到达门口的时间和通行方向：arrival[i] 是第 i 人到达的秒数；state[i] = 0 表示进入，state[i] = 1 表示离开。到达时间已按非递减顺序排列。

每秒至多一人通过，可以在到达的这一秒通过，也可以等待。当有人等待时，按以下规则安排：

  1. 若上一秒无人使用门，两边都有人时让离开的人先走。
  2. 若上一秒有人进入，两边都有人时继续让进入的人先走。
  3. 若上一秒有人离开，两边都有人时继续让离开的人先走。
  4. 同一方向有多人等待，编号最小者先走；只有一边有人时就让那一边通过。

返回长度为 n 的 answer，其中 answer[i] 是第 i 人实际通过门的秒数，按原编号排列。

约束

  • n == arrival.length == state.length
  • 1 ≤ n ≤ 10⁵
  • 0 ≤ arrival[i] ≤ n
  • arrival 非递减
  • state[i] ∈ {0, 1}

官方示例 1

输入：arrival = [0,1,1,2,4]
      state   = [0,1,0,0,1]
输出：[0,3,1,2,4]

t = 0 到 4 依次通过的人为 0、2、3、1、4。t = 1 和 2 都沿用上一秒的进入优先。

官方示例 2

输入：arrival = [0,0,0]
      state   = [1,0,1]
输出：[0,2,1]

开始时离开优先，编号 0 先于 2；两人依次离开后，编号 1 在 t = 2 进入。

04 / 独立题解

准备好后再展开：思路、证明与四语言实现。

双队列 + 上一秒的方向

核心洞察

只需知道每个方向当前最小的等待编号，以及上一秒门的使用情况。按编号扫描已到达的人，放入对应队列；由于 arrival 已有序，每个队列天然保持编号递增，无需排序或堆。

用 pref 表示两边都有人时的优先方向：初始为 1，空闲后也是 1；有人通过后设置成他的方向。只有一边有人则直接选择它。这是将“上一秒空闲”和“上一秒离开”合并成等价决策状态。

完整过程

  1. 初始化时间 t = 0、未到达指针 i = 0、pref = 1、两个等待队列与答案数组。
  2. 若两队列都空，且下一人的 arrival[i] > t，把 t 跳至该时间，并将 pref 置为 1。
  3. 把所有 arrival[i] ≤ t 的人按编号加入 state[i] 指定的队列。
  4. 若优先队列非空就选它；否则选另一队列。队首出队，记 answer[id] = t，并更新 pref。
  5. 时间增加一秒，重复直到扫描完所有人且两个队列均为空。

关键：只有 arrival[i] > t 才出现真实空闲。若 arrival[i] == t，即使入队前两队列为空，上一秒仍可能刚有人通过，不能重置 pref。

示例 1 的决策过程

正确性证明

循环每次选人前保持两个不变量：队列恰好包含已到达且尚未通过的对应方向人员，按编号递增；pref 恰好表示题目规则在两边同时等待时要求的方向。

初始队列为空，未使用的门优先离开，成立。若时间跳跃，被跳过的秒没有人等待，因此不会遗漏通行，且重置优先离开符合规则。随后按编号补入全部到达者，保持队列不变量。按 pref 选非空队列或退到另一边，符合方向规则；取队首符合最小编号规则。记录时间、移除该人并更新 pref 后，下一轮不变量继续成立。每轮恰好一人通过，最终所有人恰好获得一次正确的通行时间。

边界与复杂度

  • 单人、只有一个方向：另一队列为空时直接通过。
  • 同秒到达：必须先全部入队，再选择通过者。
  • 等待者可能比刚到达者早很多，但跨方向不能单纯比较等待时长。
  • 时间连续时保留方向；真实空闲后恢复离开优先。
  • 最后一个人通过后停止，不需要再模拟空闲秒。

时间 O(n)，空间 O(n)：每人入队、出队各一次；空档直接跳过。JavaScript 使用数组与头指针，避免 shift() 搬移元素。答案 O(n)，队列辅助空间也为 O(n)。本题 arrival[i] ≤ n，最终通行时间至多 2n − 1，32 位整数足够。

替代方案

逐秒模拟同样可行：本题最大到达时间不超过 n，总秒数仍为 O(n)。事件跳跃的好处是在到达时间范围扩大时仍保持线性。也可分别用两个指针扫描下一位进入者和离开者，利用有序输入把额外队列空间降为 O(1)（不计答案），但就绪与跳时判断更绕。堆能实现选择，却引入不必要的 O(log n) 操作。

常见错误

  • 把 0、1 的含义反过来，或把初始优先方向设为进入。
  • 只要队列空就重置方向，破坏连续通行。
  • 在本秒人员到齐前选人，遗漏同秒的竞争者。
  • 用一个总 FIFO 队列，错误地让另一方向的早到者总是先走。
  • 按通行顺序追加答案，丢失原人员编号。
  • 声称使用 JavaScript shift() 的实现必为 O(n)，忽略数组前移成本。

面试追问

  • arrival 未排序呢？先按到达时间排事件，同方向等待者用按原编号的小根堆；仅按到达顺序排队不能保证最小原编号优先。
  • 到达时间变为 10⁹ 呢？保留空队列时的事件跳跃，并重新评估时间整数范围。
  • 某一方向会饿死吗？有限输入最终都会完成，但持续同方向的无限在线流可能使另一边一直等待；若引入公平策略，规则和算法必须相应调整。
  • 每人通行耗时不同呢？先澄清门占用区间、结束时刻与“上一秒使用”的语义，再围绕完成事件进行模拟。

Java

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] timeTaken(int[] arrival, int[] state) {
        int n = arrival.length;
        int[] answer = new int[n];
        Deque<Integer> enter = new ArrayDeque<>();
        Deque<Integer> exit = new ArrayDeque<>();
        int i = 0, t = 0, pref = 1;
        while (i < n || !enter.isEmpty() || !exit.isEmpty()) {
            if (enter.isEmpty() && exit.isEmpty()
                    && i < n && arrival[i] > t) {
                t = arrival[i];
                pref = 1;
            }
            while (i < n && arrival[i] <= t) {
                (state[i] == 0 ? enter : exit).addLast(i);
                i++;
            }
            int d = pref;
            if ((d == 0 ? enter : exit).isEmpty()) d ^= 1;
            int id = (d == 0 ? enter : exit).removeFirst();
            answer[id] = t++;
            pref = d;
        }
        return answer;
    }
}

/**
 * @param {number[]} arrival
 * @param {number[]} state
 * @return {number[]}

var timeTaken = function(arrival, state) {
    const n = arrival.length;
    const q = [[], []], head = [0, 0];
    const answer = new Array(n);
    let i = 0, t = 0, pref = 1;
    while (i < n || head[0] < q[0].length || head[1] < q[1].length) {
        if (head[0] === q[0].length && head[1] === q[1].length
                && i < n && arrival[i] > t) {
            t = arrival[i];
            pref = 1;
        }
        while (i < n && arrival[i] <= t) {
            q[state[i]].push(i);
            i++;
        }
        let d = pref;
        if (head[d] === q[d].length) d ^= 1;
        const id = q[d][head[d]++];
        answer[id] = t++;
        pref = d;
    }
    return answer;
};

Python

from collections import deque
from typing import List

class Solution:
    def timeTaken(self, arrival: List[int], state: List[int]) -> List[int]:
        n = len(arrival)
        q = [deque(), deque()]
        answer = [0] * n
        i, t, pref = 0, 0, 1
        while i < n or q[0] or q[1]:
            if not q[0] and not q[1] and i < n and arrival[i] > t:
                t = arrival[i]
                pref = 1
            while i < n and arrival[i] <= t:
                q[state[i]].append(i)
                i += 1
            d = pref if q[pref] else 1 - pref
            person = q[d].popleft()
            answer[person] = t
            pref = d
            t += 1
        return answer

C++

#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    vector<int> timeTaken(vector<int>& arrival, vector<int>& state) {
        int n = arrival.size();
        vector<int> answer(n);
        queue<int> q[2];
        int i = 0, t = 0, pref = 1;
        while (i < n || !q[0].empty() || !q[1].empty()) {
            if (q[0].empty() && q[1].empty()
                    && i < n && arrival[i] > t) {
                t = arrival[i];
                pref = 1;
            }
            while (i < n && arrival[i] <= t) {
                q[state[i]].push(i);
                ++i;
            }
            int d = q[pref].empty() ? 1 - pref : pref;
            int id = q[d].front();
            q[d].pop();
            answer[id] = t++;
            pref = d;
        }
        return answer;
    }
};
