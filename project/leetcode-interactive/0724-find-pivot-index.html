Find Pivot Index

找一个下标，让它左侧的所有数字之和，恰好等于右侧的所有数字之和。先别急着看答案：带着“左右如何保持平衡”这个问题，走进下面的数组实验室。

01 · Problem

题目要求

给定一个整数数组 nums，数组的中心下标是这样一个下标：严格位于它左侧的全部元素之和，等于严格位于它右侧的全部元素之和。

下标自身对应的元素不计入左右任意一边。如果中心位于数组最左端，左侧和按 0 计算；位于最右端时，右侧和也按 0 计算。

返回规则：若有多个中心下标，返回最靠左的一个；若不存在，返回 -1。

函数与约束

pivotIndex(nums: integer[]) → integer

  • 1 ≤ nums.length ≤ 10⁴
  • -1000 ≤ nums[i] ≤ 1000
  • nums 可以包含负数与零

寻找数组的中心下标题解

Core insight

用总和省掉重复计算

已知数组总和 total 和当前下标左侧和 left，那么当前下标右侧和无需再次遍历： right = total − left − nums[i]

因此只需先求一次总和，再从左向右扫描。每到一个下标，先判断左右是否相等；若不相等，再把当前元素加入 left，继续前进。按从左到右的顺序首次命中，自然就是最靠左的中心下标。

完整过程

  1. 遍历数组，计算全部元素之和 total。
  2. 令 left = 0，表示下标 0 左侧为空。
  3. 对每个下标 i，计算 right = total - left - nums[i]。
  4. 若 left == right，立即返回 i。
  5. 否则执行 left += nums[i]，扫描下一个下标。
  6. 扫描结束仍未命中，返回 -1。

正确性说明

循环不变量：每次检查下标 i 之前，变量 left 恰好等于 nums[0...i-1] 的元素和。

  • 初始化：当 i = 0 时，左侧没有元素，left = 0，不变量成立。
  • 保持：若下标 i 不是中心，下轮开始前加入 nums[i]，于是 left 正好变成下标 i + 1 左侧元素和。
  • 命中：total - left - nums[i] 排除了左侧与当前元素，正是右侧和。相等时，i 满足定义。
  • 最左性与终止：扫描顺序从左到右，首次返回必为最左答案；若所有下标都不满足，返回 -1 正确。

边界情况

  • 单元素数组：左右都为空，答案为 0。
  • 中心在首尾：空的一侧按 0 计算，不能跳过首尾下标。
  • 包含负数：不能使用“和只会递增”的双指针假设；总和公式仍然成立。
  • 多个中心：命中后立即返回，保证结果最靠左。
  • 全为零：每个位置都平衡，应返回 0。

复杂度

时间O(n)求和 + 扫描
额外空间O(1)仅用常量变量

替代方案

左右前缀数组：分别保存每个下标的左侧和、右侧和，再逐项比较。思路直观，但会使用 O(n) 额外空间。

每个位置重新求和：实现简单，却会重复遍历，最坏时间为 O(n²)，不适合长度达到 10⁴ 的输入。

面试追问

  • 如何返回所有中心下标，而不是最左一个？
  • 如果数据以流的形式到达，何时才能确认答案？
  • 整数范围更大时，语言中应选择什么数值类型？
  • 为什么有负数时不能依据大小关系移动左右指针？

常见错误

  • 右侧和忘记减去当前元素。
  • 先更新 left 再比较，导致当前元素被算入左侧。
  • 忽略数组首尾的合法性。
  • 找到平衡点后继续扫描，返回了最右答案。
Implementations

四种语言完整代码

Java · 官方签名
class Solution {
    public int pivotIndex(int[] nums) {
        int total = 0;
        for (int value : nums) {
            total += value;
        }

        int left = 0;
        for (int i = 0; i < nums.length; i++) {
            int right = total - left - nums[i];
            if (left == right) {
                return i;
            }
            left += nums[i];
        }
        return -1;
    }
}

/**
 * @param {number[]} nums

var pivotIndex = function(nums) {
    const total = nums.reduce((sum, value) => sum + value, 0);
    let left = 0;

    for (let i = 0; i < nums.length; i++) {
        const right = total - left - nums[i];
        if (left === right) {
            return i;
        }
        left += nums[i];
    }
    return -1;
};
Python 3 · 官方签名
from typing import List


class Solution:
    def pivotIndex(self, nums: List[int]) -> int:
        total = sum(nums)
        left = 0

        for index, value in enumerate(nums):
            right = total - left - value
            if left == right:
                return index
            left += value

        return -1
C++ · 官方签名
class Solution {
public:
    int pivotIndex(vector<int>& nums) {
        int total = 0;
        for (int value : nums) {
            total += value;
        }

        int left = 0;
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            int right = total - left - nums[i];
            if (left == right) {
                return i;
            }
            left += nums[i];
        }
        return -1;
    }
};
