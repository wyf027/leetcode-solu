Problem 1697 · Graph Query

检查边长度限制的路径是否存在Checking Existence of Edge Length Limited Paths

当每次查询都给出一条不同的“边长红线”，如何判断两个点之间是否仍然连通？先读题、观察图，再决定怎样避免重复搜索。

HARD

01 / Statement

题目描述

给定一个含 n 个节点的无向图。edgeList[i] = [uᵢ, vᵢ, disᵢ] 表示节点 uᵢ 与 vᵢ 之间有一条长度为 disᵢ 的边；同一对节点之间可能存在多条边。

每个查询 queries[j] = [pⱼ, qⱼ, limitⱼ] 要求判断：是否存在一条从 pⱼ 到 qⱼ 的路径，使路径上的每一条边的长度都严格小于 limitⱼ。

返回与 queries 等长的布尔数组 answer，其中第 j 项表示对应查询能否满足条件。

示例 1 
输入：
n = 3
edgeList = [[0,1,2],[1,2,4],[2,0,8],[1,0,16]]
queries = [[0,1,2],[0,2,5]]

输出： [false,true]

解释：
查询 [0,1,2]：边长必须严格小于 2，答案为 false。
查询 [0,2,5]：可走 0 → 1 → 2，边长 2、4 都小于 5。
示例 2 
输入：
n = 5
edgeList = [[0,1,10],[1,2,5],[2,3,9],[3,4,13]]
queries = [[0,4,14],[1,4,13]]

输出： [true,false]

解释：
限制 14 时四条边均可用；限制 13 时长度 13 的边不可用，
因为条件是严格小于 limit。

约束

  • 2 ≤ n ≤ 10⁵
  • 1 ≤ edgeList.length, queries.length ≤ 10⁵
  • edgeList[i].length == 3
  • queries[j].length == 3
  • 0 ≤ uᵢ, vᵢ, pⱼ, qⱼ ≤ n - 1
  • uᵢ != vᵢ 且 pⱼ != qⱼ
  • 1 ≤ disᵢ, limitⱼ ≤ 10⁹
  • 同一对节点之间可能有多条边

Solution

离线排序 + 并查集

核心洞察

对查询 [p, q, limit]，我们只关心权重严格小于 limit 的边所组成的子图中，p 与 q 是否连通。随着 limit 递增，可用边只会增加，不会删除。

因此先把边按权重升序排序，再把查询按限制升序离线处理。维护一个边指针：对当前查询，把所有 weight < limit 的边加入并查集；此时只需判断两个端点的根是否相同。查询的原始下标随查询一起排序，用它把答案放回原顺序。

完整过程

  1. 将 edgeList 按第三项边权从小到大排序。
  2. 为每个查询附加原始下标，形成 [p, q, limit, index]，再按 limit 升序排序。
  3. 初始化并查集：每个节点独立；令边指针 i = 0。
  4. 依次处理排好序的查询。在回答之前，不断合并所有满足 edgeList[i][2] < limit 的边。
  5. 若 find(p) == find(q)，则该查询为 true，否则为 false；写入 answer[index]。

正确性证明

并查集中的边恰好合法。

处理限制为 limit 的查询前，算法只加入权重严格小于该限制的边。按边权排序和单调指针保证不会遗漏任何更小的边，也不会提前加入等于或大于限制的边。

同一集合蕴含存在合法路径。

并查集的每次合并都对应一条合法边。如果 p 与 q 同根，则两者通过这些已加入的边连通，得到一条每条边都严格小于限制的路径。

存在合法路径蕴含同一集合。

若存在合法路径，路径上所有边的权重都小于限制，所以处理该查询前它们必然全部已被加入。沿路径的连续合并会使两端点同根。

结论。

两方向同时成立，因此算法对每个查询给出的布尔值都正确；按保存的原下标回填，最终数组顺序也正确。

复杂度

O(E log E + Q log Q)排序占主导；并查集总操作近似线性，为 O((E+Q) α(n))。
O(n + Q)并查集与带原下标的查询/答案；若计入排序副本，可写 O(n + E + Q)。

边界与常见错误

必须留意

  • 条件是严格小于：循环必须写 edgeWeight < limit，不能写 <=。
  • 同一对节点可有重边；无需去重，按权重依次合并即可。
  • 查询被重排后，必须用原始下标回填答案。
  • 路径不要求简单，也不要求总长度小于限制；限制针对每一条边。

实现细节

  • 路径压缩配合按大小/秩合并，避免并查集退化。
  • 比较器应按数值比较；JavaScript 不要使用默认字典序排序。
  • 无需为每个查询重新构图或 DFS，这会在 10⁵ 规模下超时。
  • 所有边都处理完后，剩余查询仍可直接用当前集合回答。

替代方案

最小生成森林 + 倍增。 任意两点之间，使路径最大边权最小的路径可由最小生成森林给出。先构建森林，再用 LCA/倍增查询路径最大边权，与 limit 比较。它适合图固定且在线到达的大量查询，但实现和常数都更复杂。

每次 BFS/DFS。 过滤掉不合法边再搜索，单次可达 O(E + n)，仅适合数据很小或查询极少，不满足本题上限。

面试追问

  • 如果查询必须在线回答？ 可用最小生成森林 + 路径最大边权查询；也可根据数据特点考虑可持久化并查集。
  • 为什么不能按原顺序处理查询？ 限制可能忽大忽小，并查集只能方便地加边，不能回滚删除；排序让状态单调增长。
  • 如果条件改成 ≤ limit？ 只需把加边条件改成 edgeWeight ≤ limit，证明同步替换严格关系。
  • 如果还要返回一条具体路径？ 普通并查集只能回答连通性，需要保留森林结构并另行搜索/构建可恢复路径的数据结构。

Java · LeetCode 可提交DSU + offline sort
import java.util.Arrays;

class Solution {
    public boolean[] distanceLimitedPathsExist(
            int n, int[][] edgeList, int[][] queries) {
        Arrays.sort(edgeList, (a, b) -> Integer.compare(a[2], b[2]));

        int q = queries.length;
        int[][] ordered = new int[q][4];
        for (int i = 0; i < q; i++) {
            ordered[i][0] = queries[i][0];
            ordered[i][1] = queries[i][1];
            ordered[i][2] = queries[i][2];
            ordered[i][3] = i;
        }
        Arrays.sort(ordered, (a, b) -> Integer.compare(a[2], b[2]));

        UnionFind uf = new UnionFind(n);
        boolean[] answer = new boolean[q];
        int edgeIndex = 0;

        for (int[] query : ordered) {
            int limit = query[2];
            while (edgeIndex < edgeList.length
                    && edgeList[edgeIndex][2] < limit) {
                uf.union(edgeList[edgeIndex][0], edgeList[edgeIndex][1]);
                edgeIndex++;
            }
            answer[query[3]] = uf.find(query[0]) == uf.find(query[1]);
        }
        return answer;
    }

    private static class UnionFind {
        private final int[] parent;
        private final int[] size;

        UnionFind(int n) {
            parent = new int[n];
            size = new int[n];
            for (int i = 0; i < n; i++) {
                parent[i] = i;
                size[i] = 1;
            }
        }

        int find(int x) {
            if (parent[x] != x) parent[x] = find(parent[x]);
            return parent[x];
        }

        void union(int a, int b) {
            int rootA = find(a), rootB = find(b);
            if (rootA == rootB) return;
            if (size[rootA] < size[rootB]) {
                int temp = rootA;
                rootA = rootB;
                rootB = temp;
            }
            parent[rootB] = rootA;
            size[rootA] += size[rootB];
        }
    }
}

/**
 * @param {number} n
 * @param {number[][]} edgeList
 * @param {number[][]} queries
 * @return {boolean[]}
 */
var distanceLimitedPathsExist = function (n, edgeList, queries) {
    edgeList.sort((a, b) => a[2] - b[2]);
    const ordered = queries
        .map(([p, q, limit], index) => [p, q, limit, index])
        .sort((a, b) => a[2] - b[2]);

    const parent = Array.from({ length: n }, (_, i) => i);
    const size = new Array(n).fill(1);

    function find(x) {
        while (parent[x] !== x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }

    function union(a, b) {
        let rootA = find(a);
        let rootB = find(b);
        if (rootA === rootB) return;
        if (size[rootA] < size[rootB]) [rootA, rootB] = [rootB, rootA];
        parent[rootB] = rootA;
        size[rootA] += size[rootB];
    }

    const answer = new Array(queries.length).fill(false);
    let edgeIndex = 0;
    for (const [p, q, limit, originalIndex] of ordered) {
        while (edgeIndex < edgeList.length && edgeList[edgeIndex][2] < limit) {
            union(edgeList[edgeIndex][0], edgeList[edgeIndex][1]);
            edgeIndex++;
        }
        answer[originalIndex] = find(p) === find(q);
    }
    return answer;
};
Python 3 · LeetCode 可提交DSU + offline sort
from typing import List


class Solution:
    def distanceLimitedPathsExist(
        self,
        n: int,
        edgeList: List[List[int]],
        queries: List[List[int]],
    ) -> List[bool]:
        edgeList.sort(key=lambda edge: edge[2])
        ordered = sorted(
            ((p, q, limit, index)
             for index, (p, q, limit) in enumerate(queries)),
            key=lambda query: query[2],
        )

        parent = list(range(n))
        size = [1] * n

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a: int, b: int) -> None:
            root_a, root_b = find(a), find(b)
            if root_a == root_b:
                return
            if size[root_a] < size[root_b]:
                root_a, root_b = root_b, root_a
            parent[root_b] = root_a
            size[root_a] += size[root_b]

        answer = [False] * len(queries)
        edge_index = 0
        for p, q, limit, original_index in ordered:
            while (edge_index < len(edgeList)
                   and edgeList[edge_index][2] < limit):
                u, v, _ = edgeList[edge_index]
                union(u, v)
                edge_index += 1
            answer[original_index] = find(p) == find(q)

        return answer
C++ · LeetCode 可提交DSU + offline sort
#include <algorithm>
#include <array>
#include <numeric>
#include <vector>
using namespace std;

class Solution {
    class UnionFind {
        vector<int> parent;
        vector<int> size;

    public:
        explicit UnionFind(int n) : parent(n), size(n, 1) {
            iota(parent.begin(), parent.end(), 0);
        }

        int find(int x) {
            if (parent[x] != x) parent[x] = find(parent[x]);
            return parent[x];
        }

        void unite(int a, int b) {
            a = find(a);
            b = find(b);
            if (a == b) return;
            if (size[a] < size[b]) swap(a, b);
            parent[b] = a;
            size[a] += size[b];
        }
    };

public:
    vector<bool> distanceLimitedPathsExist(
        int n,
        vector<vector<int>>& edgeList,
        vector<vector<int>>& queries
    ) {
        sort(edgeList.begin(), edgeList.end(),
             [](const auto& a, const auto& b) { return a[2] < b[2]; });

        vector<array<int, 4>> ordered;
        ordered.reserve(queries.size());
        for (int i = 0; i < static_cast<int>(queries.size()); ++i) {
            ordered.push_back({queries[i][0], queries[i][1], queries[i][2], i});
        }
        sort(ordered.begin(), ordered.end(),
             [](const auto& a, const auto& b) { return a[2] < b[2]; });

        UnionFind uf(n);
        vector<bool> answer(queries.size(), false);
        int edgeIndex = 0;

        for (const auto& query : ordered) {
            while (edgeIndex < static_cast<int>(edgeList.size())
                   && edgeList[edgeIndex][2] < query[2]) {
                uf.unite(edgeList[edgeIndex][0], edgeList[edgeIndex][1]);
                ++edgeIndex;
            }
            answer[query[3]] = uf.find(query[0]) == uf.find(query[1]);
        }
        return answer;
    }
};
