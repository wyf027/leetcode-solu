Last Moment Before All Ants Fall Out of a Plank

中等数组模拟脑筋急转弯

题目描述

速度恒为 1 单位 / 秒

一块木板长 n 个单位，若干只蚂蚁从整数位置出发。left 记录初始向左移动的蚂蚁位置，right 记录初始向右移动的蚂蚁位置。

两只方向相反的蚂蚁相遇时，会立刻同时转向且不耗时；蚂蚁到达木板端点时立即掉下。返回最后一只蚂蚁掉下木板的时刻。

函数形式：getLastMoment(n, left, right) → integer

约束

  • 1 ≤ n ≤ 10⁴
  • 0 ≤ left.length ≤ n + 1
  • 0 ≤ left[i] ≤ n
  • 0 ≤ right.length ≤ n + 1
  • 0 ≤ right[i] ≤ n
  • 1 ≤ left.length + right.length ≤ n + 1
  • left 与 right 中所有位置互不重复，且一个位置只属于其中一个数组。

解题区

题解：交换身份，轨迹不变

核心洞察：两只相同速度的蚂蚁碰撞并同时掉头，从“位置轨迹”上看，等价于它们彼此穿过、继续沿原方向走。我们并不关心每只蚂蚁的身份，因此完全不需要模拟碰撞。

完整过程

  1. 对每个初始向左的位置 x，它沿等价轨迹到左端所需时间是 x。
  2. 对每个初始向右的位置 x，它到右端所需时间是 n - x。
  3. 所有轨迹消失的最晚时刻，就是上述时间的最大值。
answer = max( max(left), max(n - x for x in right) )

正确性证明

引理：相同速度、相反方向的两只蚂蚁相遇后交换方向，与它们直接穿过对方产生的无身份轨迹完全一致。

结论：将所有碰撞替换为穿过，不改变任何时刻板上蚂蚁的位置集合，也不改变掉落时刻集合。每条向左轨迹用时 x，每条向右轨迹用时 n-x；取最大值恰是最后一次掉落时刻。因此算法正确。

复杂度

只扫描两个数组一次。

  • 时间复杂度：O(L + R)
  • 额外空间：O(1)

其中 L、R 分别为两个数组的长度。

边界情况

  • 某个数组为空时，只扫描另一个数组。
  • 蚂蚁初始就在端点且朝外，掉落时间为 0。
  • 只有一只蚂蚁时，答案就是它面向端点的距离。
  • 最大规模也只需线性扫描，不发生整数溢出。

替代方案

可以按时间或碰撞事件做物理模拟，但需要维护身份、方向、相遇与掉落，复杂且容易处理错同时事件。轨迹等价法直接去掉了所有碰撞事件，是更简洁也更强的建模。

面试追问

  • 若每只蚂蚁速度不同，穿越等价还成立吗？
  • 若碰撞会暂停一秒，应如何建模事件？
  • 若要求最后掉落蚂蚁的原始编号，为什么仅看轨迹不够？
  • 如何把结论推广到连续坐标？

常见错误

  • 真的逐秒模拟，既慢又难维护碰撞。
  • 向右蚂蚁误用位置 x，正确距离是 n-x。
  • 数组为空时直接调用不安全的最大值函数。
  • 把“到端点”后的下一秒才算掉落。

Java官方签名
class Solution {
    public int getLastMoment(int n, int[] left, int[] right) {
        int answer = 0;

        for (int position : left) {
            answer = Math.max(answer, position);
        }
        for (int position : right) {
            answer = Math.max(answer, n - position);
        }

        return answer;
    }
}
