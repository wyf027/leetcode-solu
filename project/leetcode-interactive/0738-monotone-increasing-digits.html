贪心：从右向左修复第一个下降

核心洞察

把 n 写成数位数组。若所有相邻数位都不下降，答案就是 n。一旦发现左边数位大于右边数位，要得到不超过原数的最大合法数，必须让某个较高位变小。

最优修复是：将造成下降的左侧数位减 1，并把它右侧的所有数位最终填成 9。减 1 是对高位最小的损失，而后缀填 9 则在这个新前缀下把数值推到最大。

为什么要从右向左？ 修改右侧关系后，左边可能出现新的下降。例如 332 先变为 322，又必须继续修复成 222，最终得到 299。

完整过程

  1. 把 n 转为字符数组 digits。
  2. 令标记 marker = digits.length，表示当前还没有需要填 9 的后缀。
  3. 从最后一位向左扫描索引 i。如果 digits[i - 1] > digits[i]，将 digits[i - 1] 减 1，并令 marker = i。
  4. 扫描结束后，将 marker 到末尾的所有数位改为 9。
  5. 把数位数组转回整数并返回；可能出现的前导 0 会在数值转换时自然消失。

正确性证明

引理 1：结果不超过 n。
若未发生修改，结果等于 n。若发生修改，最左侧被修改的数位比 n 对应位小 1；无论其后放什么数位，整个结果都严格小于 n。
引理 2：结果数位单调不下降。
从右向左扫描会持续消除前缀中的下降关系。最终标记位置之前的相邻数位均不下降；标记位置起全部为 9，而前一位至多为 9，所以拼接处及后缀也合法。
引理 3：不存在更大的合法结果。
在最左侧必须降低的位置，任何不超过 n 的合法数都不能保留原数位；算法只减 1，保留了最大的可行前缀。前缀一旦确定，后缀全部取 9 显然最大。

结论：由三个引理，算法返回的数不超过 n、满足数位单调递增，且在所有此类数中最大。

边界与复杂度

  • n = 0：单个数位天然合法，返回 0。
  • 已经单调：如 1234 或 999，标记不移动，原样返回。
  • 首位触发修改：如 10 或 1000，字符结果可能以 0 开头，转成整数后得到 9 或 999。
  • 相等数位连锁：如 332，必须继续向左扫描，不能在首次修改后停止。
  • 上界 109：输入 1000000000，答案为 999999999。
时间复杂度O(d)d 为 n 的十进制位数
空间复杂度O(d)字符数组；约束固定时也可视为 O(1)

替代方案

逐位构造 / 回溯

从高位开始，为每一位选择不小于前一位、又不突破 n 上界的最大数字。如果某位无法继续，就回退前一位再填充最大后缀。它能得到正确结果，但状态与回退逻辑比一次反向扫描更复杂。

数位 DP

用“当前位置、上一位、是否贴紧上界”等状态搜索最大值。适合同时加入数位和、禁用数字等复杂限制；本题只有单调约束，数位 DP 明显偏重。

向下枚举

从 n 开始逐个检查虽然直观，但在 109 范围内最坏情况代价过高，不适合作为提交解法。

面试追问与常见错误

可能的追问

  • 如果要求数位严格递增，贪心修复与最大后缀应如何改变？
  • 如果数制改成 B 进制，算法哪些部分可以复用？
  • 能否不使用字符串？可以用数学拆位，但实现通常更绕，复杂度量级不变。
  • 为什么不能从左向右看到下降就立刻结束？因为减位后可能破坏它与更左侧数位的关系。

常见错误

  • 只修复一次，漏掉 332 → 322 之后仍存在的下降。
  • 把后缀立刻改成 9 后继续比较，导致比较对象被污染；更稳妥的做法是先记录 marker，扫描完再统一填 9。
  • 使用 >= 判断下降，错误地把相等数位当作非法。
  • 忘记将字符串结果转为整数，因而在 10 上返回字符串 "09"。

class Solution {
    public int monotoneIncreasingDigits(int n) {
        char[] digits = String.valueOf(n).toCharArray();
        int marker = digits.length;

        for (int i = digits.length - 1; i > 0; i--) {
            if (digits[i - 1] > digits[i]) {
                digits[i - 1]--;
                marker = i;
            }
        }

        for (int i = marker; i < digits.length; i++) {
            digits[i] = '9';
        }
        return Integer.parseInt(new String(digits));
    }
}

var monotoneIncreasingDigits = function(n) {
    const digits = String(n).split('');
    let marker = digits.length;

    for (let i = digits.length - 1; i > 0; i--) {
        if (digits[i - 1] > digits[i]) {
            digits[i - 1] = String(Number(digits[i - 1]) - 1);
            marker = i;
        }
    }

    for (let i = marker; i < digits.length; i++) {
        digits[i] = '9';
    }
    return Number(digits.join(''));
};
class Solution:
    def monotoneIncreasingDigits(self, n: int) -> int:
        digits = list(str(n))
        marker = len(digits)

        for i in range(len(digits) - 1, 0, -1):
            if digits[i - 1] > digits[i]:
                digits[i - 1] = str(int(digits[i - 1]) - 1)
                marker = i

        for i in range(marker, len(digits)):
            digits[i] = '9'

        return int(''.join(digits))
