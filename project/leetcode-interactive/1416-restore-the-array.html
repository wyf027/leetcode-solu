恢复数组

空格消失以后，一串数字还能被还原成多少个合法整数数组？每个数字必须落在 [1, k]，每一段都不能有前导零。

输入s, k
输出方案数 mod 10⁹+7
规模|s| ≤ 100,000

Problem

被擦掉的分隔符

准确转述官方题意，不预先展开解法。

一个程序原本要输出整数数组，却遗漏了所有空格，最终只留下由数字组成的字符串 s。已知原数组中的每个整数都位于 [1, k]，并且任何整数都不能含前导零。

请返回有多少个不同数组，在去掉元素之间的空格后恰好得到 s。答案可能很大，需对 10⁹ + 7 取模。

函数签名
numberOfArrays(s: string, k: integer) → integer

每一段都要过两关

  • 表示的整数至少为 1，且不超过 k。
  • 多位数不能以字符 0 开头。

Solution

从后往前连接合法后缀

动态规划把“枚举所有切分”压缩成“统计每个后缀的方案数”。

核心洞察

令 dp[i] 表示子串 s[i…n-1] 的合法恢复方案数。若从 i 开始取出的第一段是 s[i…j]，且其数值在 [1,k]，那么后续可以有 dp[j+1] 种恢复方式。把所有合法第一段对应的后缀方案数相加即可。

dp[i] = Σ dp[j + 1]，其中 value(s[i…j]) ≤ k 且 s[i] ≠ '0'

边界 dp[n] = 1 表示“字符串已经恰好切完”有一种完成方式。由于 k ≤ 10⁹，每个起点最多尝试 digits(k) 个字符。

完整过程

  1. 建立状态。
    创建长度为 n+1 的数组，设 dp[n]=1。
  2. 倒序扫描起点。
    从 i=n-1 到 0。若 s[i]='0'，保持 dp[i]=0。
  3. 扩展当前数字。
    逐位执行 value=value×10+digit；一旦 value>k 就停止。
  4. 合并后缀答案。
    每发现一个合法数字，就把 dp[j+1] 加入 dp[i] 并取模。
  5. 返回答案。
    dp[0] 覆盖从开头出发的全部合法切分。

正确性证明

命题：对每个 i，dp[i] 等于后缀 s[i…n-1] 的合法恢复方案数。

基础情形：i=n 时后缀为空，表示切分已经完成，恰有一种完成方式，所以 dp[n]=1。

归纳步骤：假设所有大于 i 的状态正确。任何从 i 开始的合法方案都有唯一第一段 s[i…j]，剩余部分有 dp[j+1] 种方案。反过来，合法第一段与任一合法后缀方案都拼成唯一完整方案。不同第一段的方案互不重叠，求和正好得到全部方案。

结论：倒序归纳可知 dp[0] 即所求。

复杂度

时间：O(n · log₁₀k)，每个起点最多扩展 digits(k) 位。

空间：O(n)，用于动态规划数组。

边界情况

  • 当前位置是 0：不能作为新数字开头。
  • 某段刚好等于 k：合法，应计入。
  • k 只有一位：每个字符最多独立成段。
  • 末尾含零：只能与前面的非零字符组成合法数。
  • 答案巨大：每次加法后取模。

替代方案与取舍

前向动态规划：令 ways[i] 表示前 i 个字符的切分数，从每个可达位置向后扩展，复杂度相同。后缀定义更贴合“选第一段，再接剩余方案”的证明。

记忆化搜索：转移直观，却可能产生深达 10⁵ 的递归栈。

空间压缩：状态仅依赖后方有限个位置，可以使用长度约为 digits(k)+1 的循环缓冲区降至 O(log k) 空间，但索引维护更复杂。

四语言完整代码

Java
class Solution {
    private static final int MOD = 1_000_000_007;
    public int numberOfArrays(String s, int k) {
        int n = s.length();
        int maxDigits = String.valueOf(k).length();
        long[] dp = new long[n + 1];
        dp[n] = 1;
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == '0') continue;
            long value = 0;
            for (int j = i; j < n && j - i < maxDigits; j++) {
                value = value * 10 + (s.charAt(j) - '0');
                if (value > k) break;
                dp[i] = (dp[i] + dp[j + 1]) % MOD;
            }
        }
        return (int) dp[0];
    }
}

        dp = [0] * (n + 1)

        for i in range(n - 1, -1, -1):

C++
class Solution {
public:
    int numberOfArrays(string s, int k) {
        static constexpr int MOD = 1'000'000'007;
        int n = static_cast<int>(s.size());
        int maxDigits = to_string(k).size();
        vector<long long> dp(n + 1, 0);
        dp[n] = 1;
        for (int i = n - 1; i >= 0; --i) {
            if (s[i] == '0') continue;
            long long value = 0;
            for (int j = i; j < n && j - i < maxDigits; ++j) {
                value = value * 10 + (s[j] - '0');
                if (value > k) break;
                dp[i] = (dp[i] + dp[j + 1]) % MOD;
            }
        }
        return static_cast<int>(dp[0]);
    }
};

面试追问

  • 为什么 value>k 后可以直接停止？
  • 如何改写为前向 DP？
  • 怎样用循环数组压缩空间？
  • 若 k 有数千位，如何避免转成整数？

常见错误

  • 把字符 '0' 当作合法数字。
  • 遗漏 dp[n]=1。
  • 解析过长子串造成溢出。
  • 只在最终返回时取模。
  • 忽略递归深度风险。
