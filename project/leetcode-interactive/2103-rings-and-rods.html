01 / 问题

从颜色位置对，还原环的分布

给定字符串 rings，长度是 2n。每两个字符描述一个环：第一个字符是颜色（R 红、G 绿、B 蓝），第二个字符是杆号（0 至 9）。返回同时拥有三种颜色的杆的数量。相同颜色的环可以重复出现。

例如 rings = "R3G2B1" 表示红环放在杆 3、绿环放在杆 2、蓝环放在杆 1。参数只有 rings，n 是环数；返回值为整数。

官方示例 1

rings = "B0B6G0R6R0R6G9"

输出：1

杆 0 有红、绿、蓝；杆 6 的三个环只有红、蓝；杆 9 只有一个绿环。只有杆 0 满足条件。

官方示例 2

rings = "B0R0G0R9R0B0G0"

输出：1

杆 0 的六个环包含全部三色；杆 9 只有一个红环，因此结果仍为 1。

官方示例 3

rings = "G4"

输出：0

只有一个绿色环，没有杆能集齐三色。

约束

  • rings.length == 2 * n，且 1 ≤ n ≤ 100。
  • 下标从 0 开始：偶数下标字符只能为 R、G、B。
  • 奇数下标字符只能为数字 0 至 9。

04 / 独立题解

把观察变成算法

准备好后，展开思路、证明与四语言代码。

核心洞察：只关心颜色是否存在

每根杆无需保存所有环，只需记住红、绿、蓝是否出现。把三种颜色映射到三个独立二进制位：R → 001 (1)、G → 010 (2)、B → 100 (4)。用长度为 10 的数组保存各杆的掩码。

放入颜色为 c、杆号为 r 的环时，执行 mask[r] |= bit[c]。按位或只把对应位设为 1，重复颜色不会改变已有记录。三色齐全等价于掩码为 111₂ = 7。

完整过程

  1. 初始化 10 根杆的掩码为 0。
  2. 以步长 2 遍历 rings，从 rings[i] 读取颜色，从 rings[i + 1] 读取并转换杆号。
  3. 把颜色位按位或进相应杆的掩码。
  4. 遍历 10 个掩码，统计等于 7 的数量并返回。

示例 1 的状态轨迹

B0：杆 0 = 100 → B6：杆 6 = 100 → G0：杆 0 = 110 → R6：杆 6 = 101 → R0：杆 0 = 111 → R6：杆 6 仍为 101 → G9：杆 9 = 010。

只有杆 0 的掩码是 7，结果为 1。可视化中的三个颜色标记正好对应这三个二进制位。

正确性证明

循环不变式：处理前 k 个环后，对每根杆 r，mask[r] 的某颜色位为 1，当且仅当前 k 个环中至少存在一个该颜色的环被放在杆 r 上。

初始未处理任何环，所有掩码为 0，不变式成立。处理下一个环时，仅把该杆的对应颜色位设为 1；其他杆与其他颜色位保持不变，因此不变式继续成立。全部环处理完毕后，掩码为 7 当且仅当该杆拥有全部三色。最终每根杆恰好检查一次，统计结果就是所求数量。

边界与复杂度

  • 只有一个环、三色分散、某根杆无环：均不会错误计入。
  • 同杆同色重复出现：按位或是幂等的，计数不会增加。
  • 杆号 0 和 9 都直接映射到合法数组下标；最终答案在 0–10 之间。
  • 设 n 为环数，时间 O(n + 10) = O(n)，额外空间 O(10) = O(1)。四份提交代码遵循官方合法输入约束；演示输入另有格式校验。

替代方案

可以给每根杆维护一个颜色集合，最后统计集合大小为 3 的杆；也可以用 10 × 3 的布尔数组，语义更加直观。逐杆扫描整个字符串也可行，时间是 O(10n)，本题仍为 O(n)，但会重复读取输入。位掩码用一个小整数表达同样的信息。

常见错误

  • 把环数达到 3 当作颜色齐全：三个红环也只有一种颜色。
  • 用加法或异或替代按位或：重复颜色会产生进位或把位翻转掉。
  • 步长写成 1，导致把杆号当颜色；或忘记将数字字符转换为整数。
  • 每次遇到 mask == 7 都增加答案，会把已经齐全的杆重复计数。末尾统一统计最直接。

面试追问

能边扫描边更新答案吗？ 可以，只在该杆掩码从非 7 变为 7 时增加答案。

如果支持移除环？ 仅有存在位不够，需要维护每根杆每种颜色的数量；数量变为 0 才清除对应位。

杆号和颜色数不固定呢？ 稀疏杆号用映射保存状态；少量颜色仍可用掩码，颜色很多时用集合或位集合。JavaScript 普通位运算是 32 位，需要关注可用位数。

Java

class Solution {
    public int countPoints(String rings) {
        int[] masks = new int[10];
        for (int i = 0; i < rings.length(); i += 2) {
            char color = rings.charAt(i);
            int bit = color == 'R' ? 1 : color == 'G' ? 2 : 4;
            int rod = rings.charAt(i + 1) - '0';
            masks[rod] |= bit;
        }
        int answer = 0;
        for (int mask : masks) {
            if (mask == 7) answer++;
        }
        return answer;
    }
}

JavaScript

/**
 * @param {string} rings
 * @return {number}
 */
var countPoints = function(rings) {
    const masks = Array(10).fill(0);
    const bits = { R: 1, G: 2, B: 4 };
    for (let i = 0; i < rings.length; i += 2) {
        masks[Number(rings[i + 1])] |= bits[rings[i]];
    }
    return masks.filter(mask => mask === 7).length;
};

Python 3

class Solution:
    def countPoints(self, rings: str) -> int:
        masks = [0] * 10
        bits = {'R': 1, 'G': 2, 'B': 4}
        for i in range(0, len(rings), 2):
            masks[int(rings[i + 1])] |= bits[rings[i]]
        return sum(mask == 7 for mask in masks)

C++

#include <string>
using namespace std;

class Solution {
public:
    int countPoints(string rings) {
        int masks[10] = {};
        for (int i = 0; i < static_cast<int>(rings.size()); i += 2) {
            char color = rings[i];
            int bit = color == 'R' ? 1 : color == 'G' ? 2 : 4;
            masks[rings[i + 1] - '0'] |= bit;
        }
        int answer = 0;
        for (int mask : masks) {
            if (mask == 7) ++answer;
        }
        return answer;
    }
};
