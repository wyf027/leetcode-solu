恢复空格 把被擦掉的边界找回来

文章只剩连续的小写字母。你手里有一本字典，需要重新切分句子，让无法归入任何字典词的字符尽可能少；最终只返回这个最小数量。

校对任务单

  1. ① 从当前位置向左查反向字典树
  2. ② 用 dp 记录每个前缀的最少漏字
  3. ③ 识别单词时把整段漏字成本降为 0
01 / Problem brief

题意

难度：中等

给定字符串数组 dictionary 与字符串 sentence。允许在句子中任意插入空格，使字典之外的字符数量最少，返回该最小数量。

本题不要求输出切分方案；演示中的分词标记只用于解释最优状态如何产生。

官方样例

输入
dictionary = ["looked","just","like","her","brother"], sentence = "jesslookedjustliketimherbrother"
输出
7
解释
可识别 looked、just、like、her、brother；jess 与 tim 共 7 个字符未识别。
0 ≤ n ≤ 1000

n 为 sentence 长度

Σ |word| ≤ 150000

字典字符总量

a–z

所有字符串仅含小写字母

格式说明：若字符串含空格，本页统一用 ␠ 显示可见空格；本题输入本身不含空格。

04 / Spoiler gate

题解

核心洞察、完整过程、边界、复杂度与四语言代码都收在这里。先亲手走几步，再揭开校对规则。

核心洞察

答案属于前缀，匹配从右向左

定义 dp[i] 为句子前 i 个字符的最少未识别数。第 i 个字符先按“不认识”处理，得到 dp[i - 1] + 1；随后从 i - 1 向左沿反向字典树扫描。每遇到完整单词，就能用单词左侧前缀的答案更新当前值。

状态转移

dp[0] = 0

dp[i] = dp[i - 1] + 1

若 sentence[j..i-1] 在字典中：

dp[i] = min(dp[i], dp[j])

完整过程

  1. 1. 把字典中的每个词倒序插入 Trie。
  2. 2. 逐个确定前缀终点 i，默认当前字符未识别。
  3. 3. 从 i - 1 向左走 Trie，边不存在就停止。
  4. 4. 命中单词结尾时，用 dp[j] 更新；若降到 0 可提前结束。

边界

  • 空句子直接得到 0。
  • 空字典时答案为句长。
  • 重叠词由 dp 自动择优。
  • 重复字典词不影响结果。

复杂度

设字典总字符数为 S，最长单词长度为 L，句长为 n。时间 O(S + nL)，最坏可写为 O(S + n²)；空间 O(S + n)。

替代方案

哈希集合 + DP 更短，但会枚举大量子串；滚动哈希要处理碰撞；AC 自动机适合更大规模多模式匹配，本题面试中实现成本偏高。

面试追问

  • 如何恢复具体切分方案？
  • 字典动态变化如何支持？
  • 若要按词频打分如何改状态？

常见错误

  • • 把 dp[i] 误解成以 i 开头的后缀答案，造成下标混乱。
  • • 命中单词时使用 dp[j - 1]，实际应使用单词左端之前的前缀 dp[j]。
  • • 正向 Trie 却从右向左扫描，导致永远无法匹配。
  • • 每次复制 substring，隐藏的 O(n³) 成本被忽略。

class Solution {
    private static class Node {
        Node[] next = new Node[26];
        boolean end;
    }

    public int respace(String[] dictionary, String sentence) {
        Node root = new Node();
        for (String word : dictionary) {
            Node node = root;
            for (int i = word.length() - 1; i >= 0; i--) {
                int c = word.charAt(i) - 'a';
                if (node.next[c] == null) node.next[c] = new Node();
                node = node.next[c];
            }
            node.end = true;
        }

        int n = sentence.length();
        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            dp[i] = dp[i - 1] + 1;
            Node node = root;
            for (int j = i - 1; j >= 0; j--) {
                int c = sentence.charAt(j) - 'a';
                if (node.next[c] == null) break;
                node = node.next[c];
                if (node.end) dp[i] = Math.min(dp[i], dp[j]);
                if (dp[i] == 0) break;
            }
        }
        return dp[n];
    }
}
var respace = function (dictionary, sentence) {
    const root = {};
    for (const word of dictionary) {
        let node = root;
        for (let i = word.length - 1; i >= 0; i--) {
            node[word[i]] ??= {};
            node = node[word[i]];
        }
        node.end = true;
    }

    const dp = Array(sentence.length + 1).fill(0);
    for (let i = 1; i <= sentence.length; i++) {
        dp[i] = dp[i - 1] + 1;
        let node = root;
        for (let j = i - 1; j >= 0; j--) {
            node = node[sentence[j]];
            if (!node) break;
            if (node.end) dp[i] = Math.min(dp[i], dp[j]);
            if (dp[i] === 0) break;
        }
    }
    return dp[sentence.length];
};
class Solution:
    def respace(self, dictionary: List[str], sentence: str) -> int:
        root = {}
        for word in dictionary:
            node = root
            for char in reversed(word):
                node = node.setdefault(char, {})
            node["#"] = True

        dp = [0] * (len(sentence) + 1)
        for i in range(1, len(sentence) + 1):
            dp[i] = dp[i - 1] + 1
            node = root
            for j in range(i - 1, -1, -1):
                if sentence[j] not in node:
                    break
                node = node[sentence[j]]
                if "#" in node:
                    dp[i] = min(dp[i], dp[j])
                if dp[i] == 0:
                    break
        return dp[-1]
class Solution {
    struct Node {
        array<int, 26> next{};
        bool end = false;
    };

public:
    int respace(vector<string>& dictionary, string sentence) {
        vector<Node> trie(1);
        for (const string& word : dictionary) {
            int node = 0;
            for (auto it = word.rbegin(); it != word.rend(); ++it) {
                int c = *it - 'a';
                if (trie[node].next[c] == 0) {
                    trie[node].next[c] = trie.size();
                    trie.emplace_back();
                }
                node = trie[node].next[c];
            }
            trie[node].end = true;
        }

        int n = sentence.size();
        vector<int> dp(n + 1);
        for (int i = 1; i <= n; ++i) {
            dp[i] = dp[i - 1] + 1;
            int node = 0;
            for (int j = i - 1; j >= 0; --j) {
                int c = sentence[j] - 'a';
                node = trie[node].next[c];
                if (node == 0) break;
                if (trie[node].end) dp[i] = min(dp[i], dp[j]);
                if (dp[i] == 0) break;
            }
        }
        return dp[n];
    }
};
