气温变化趋势

两地每天的绝对气温可以不同；只要相邻两天的升、降或不变方向相同，这一天就属于同一段相同趋势。求最长连续天数。

输入
temperatureA, temperatureB
输出
最长连续相同趋势天数
限制
2 ≤ n ≤ 100

题意与示例

对每个相邻日对 i - 1 → i，把变化归一化为 降温 −、不变 0 或 升温 +。两地对应符号相同，就延长连续段；不同则从 0 重新开始。

示例：A = [21, 18, 18, 18, 31]

B = [34, 32, 16, 16, 17]

趋势 A：−, 0, 0, +；趋势 B：−, −, 0, +。

末尾的 0、+ 连续匹配，答案为 2。

趋势对照仪

逐日推进：绿色表示方向一致；珊瑚色表示连续段被打断。

交互步骤

  1. 1. 只看方向

    比较相邻值，获得 −1、0、1，而非比较气温大小。

  2. 2. 同步比较

    同一天的两个方向相等，当前连续段加一。

  3. 3. 维护答案

    每步更新最大值；不相等时连续段清零。

核心洞察

“趋势相同”是对每个相邻日对的符号比较。若 n 天中有 k 个连续匹配的变化，则题目要求的连续趋势天数正是 k；题目示例按变化次数计数，首日没有趋势。

完整过程

best = run = 0
for i from 1 to n - 1:
  a = sign(A[i] - A[i - 1])
  b = sign(B[i] - B[i - 1])
  if a == b: run += 1; best = max(best, run)
  else:      run = 0

边界与复杂度

  • 连续相同的温度对应趋势 0，必须当作有效方向。
  • 全部不匹配时返回 0。
  • 只有两个日期时，最多只有一次变化。
  • 时间 O(n)，额外空间 O(1)。

替代方案与追问

可先构建两个长度 n−1 的趋势数组，再做最长相同连续段；更直观但额外使用 O(n) 空间。追问：如果允许缺失数据，应先定义缺失日是否能跨越连接，不能直接沿用本题连续性。

常见错误

  • 把 A[i] 与 B[i] 的温度高低当作趋势；正确比较对象是各自的相邻差。
  • 忽略相等：差值为 0 也是一种趋势。
  • 不匹配后把 run 设为 1；当前变化并未匹配，应设为 0。

class Solution {
    public int temperatureTrend(int[] temperatureA, int[] temperatureB) {
        int best = 0, run = 0;
        for (int i = 1; i < temperatureA.length; i++) {
            int a = Integer.compare(temperatureA[i], temperatureA[i - 1]);
            int b = Integer.compare(temperatureB[i], temperatureB[i - 1]);
            if (a == b) best = Math.max(best, ++run);
            else run = 0;
        }
        return best;
    }
}
