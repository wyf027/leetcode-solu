812. 最大三角形面积

Largest Triangle Area。先读题，再亲手移动步骤观察每组三点形成的面积变化；完整解法会留到页面底部，由你决定何时揭晓。

开始读题 进入几何探索

Problem

题目

给定 X-Y 平面上的点数组 points，其中 points[i] = [xᵢ, yᵢ]。从中选择任意三个不同的点组成三角形，返回所有可组成三角形中的最大面积。答案与真实值的误差不超过 10⁻⁵ 即可接受。

示例 1

输入：points = [[0,0],[0,1],[1,0],[0,2],[2,0]]
输出：2.00000
解释：选择 [0,0]、[0,2]、[2,0]，得到面积为 2 的三角形。

示例 2

输入：points = [[1,0],[0,0],[0,1]]
输出：0.50000

约束

  • 3 <= points.length <= 50
  • -50 <= xᵢ, yᵢ <= 50
  • 所有给定的点互不相同。

Solution

完整题解

枚举每组三点，并用二维叉积的绝对值计算三角形面积。

核心洞察

点数最多 50，三点组合数至多为 C(50, 3) = 19,600，直接检查所有三点组合非常轻量。面积无需求边长或使用海伦公式；二维叉积能直接得到平行四边形的有向面积，其绝对值的一半就是三角形面积。

area = |(Bx − Ax)(Cy − Ay) − (By − Ay)(Cx − Ax)| / 2

完整过程

  1. 设答案 ans = 0。
  2. 用三个递增下标 i < j < k 枚举每组三点，确保每个组合恰好出现一次。
  3. 把三点代入叉积面积公式。
  4. 用当前面积更新最大值，全部枚举结束后返回最大值。

边界情况

  • 恰好三个点：只计算唯一的一个组合。
  • 三点共线：叉积为 0，面积也为 0。
  • 存在负坐标：差值和叉积公式仍然适用。
  • 点的顺序相反：叉积符号相反，取绝对值后面积一致。
  • 所有点都共线：每个候选面积均为 0，最终返回 0。

正确性证明

引理：对任意三点 A、B、C，向量 AB 与 AC 的二维叉积绝对值等于它们张成的平行四边形面积，因此公式所求值恰好是三角形 ABC 的面积。

完备性：三重循环遍历所有满足 i < j < k 的下标组合。任意三个不同点都有唯一的一组递增下标，所以每个可形成的三角形被计算一次且不会遗漏。

最优性：算法每次都将已计算三角形的面积与当前最大值比较。循环结束时，最大值覆盖了所有候选三角形，因此返回值就是能形成的最大三角形面积。

复杂度

时间复杂度：O(n³)。共有 O(n³) 个三点组合，每个组合的计算是 O(1)。

空间复杂度：O(1)，只使用若干数值变量。

替代方案

最大面积三角形的顶点一定在凸包上，可以先用单调链在 O(n log n) 内求凸包，再枚举凸包上的三点，复杂度为 O(n log n + h³)，其中 h 是凸包点数。若内部点很多，这能减少枚举；但本题 n ≤ 50，直接枚举更短、更清晰，也足够快。

四种语言完整代码

Javadouble

class Solution {
    public double largestTriangleArea(int[][] points) {
        double answer = 0.0;
        int n = points.length;

        for (int i = 0; i < n - 2; i++) {
            for (int j = i + 1; j < n - 1; j++) {
                for (int k = j + 1; k < n; k++) {
                    answer = Math.max(
                        answer,
                        area(points[i], points[j], points[k])
                    );
                }
            }
        }
        return answer;
    }

    private double area(int[] a, int[] b, int[] c) {
        long cross = (long) (b[0] - a[0]) * (c[1] - a[1])
                   - (long) (b[1] - a[1]) * (c[0] - a[0]);
        return Math.abs(cross) / 2.0;
    }
}

            }
        }
    }
    return answer;

C++double

class Solution {
public:
    double largestTriangleArea(vector<vector<int>>& points) {
        double answer = 0.0;
        int n = static_cast<int>(points.size());

        for (int i = 0; i < n - 2; ++i) {
            for (int j = i + 1; j < n - 1; ++j) {
                for (int k = j + 1; k < n; ++k) {
                    answer = max(
                        answer,
                        area(points[i], points[j], points[k])
                    );
                }
            }
        }
        return answer;
    }

private:
    double area(const vector<int>& a,
                const vector<int>& b,
                const vector<int>& c) {
        long long cross =
            1LL * (b[0] - a[0]) * (c[1] - a[1])
            - 1LL * (b[1] - a[1]) * (c[0] - a[0]);
        return abs(cross) / 2.0;
    }
};

面试追问

  • 为什么不用海伦公式？ 叉积只需整数加减乘，步骤更少，也避免开方与边长误差。
  • 为什么顶点一定在凸包上？ 若某顶点在凸包内部，沿该顶点对应的高方向移动到凸包边界，不会让底边对应的面积变小。
  • 点数非常大怎么办？ 先求凸包，再研究旋转卡壳等更高级的最大三角形算法。
  • 如何返回顶点而不是面积？ 更新最大面积时同步记录三个下标即可。

常见错误

  • 忘记对叉积取绝对值，导致点的顺序影响答案。
  • 忘记除以 2，返回了平行四边形面积。
  • 循环下标没有保持递增，重复枚举或漏掉组合。
  • 在更大坐标范围中用窄整数类型乘法，造成溢出。
  • 把浮点答案强制格式化后再参与比较，提前损失精度。
