特殊等价
字符串组

交换从不跨越下标的奇偶边界。先观察这种操作留下了什么，再决定如何给每个字符串制作一枚“指纹”。

Problem

题目转述

给定一个等长小写字符串数组 words。一次操作可以在某个字符串内交换任意两个偶数下标字符，或者交换任意两个奇数下标字符。经过任意次操作能够变成彼此的字符串称为特殊等价。返回数组中最大特殊等价类别的数量。

关键操作边界：下标从 0 开始；偶数位字符只能在偶数位之间重排，奇数位同理。
示例 1 
输入：words = ["abcd","cdab","cbad","xyzz","zzxy","zzyx"]
输出：3
解释：["abcd","cdab","cbad"]、["xyzz","zzxy"]、["zzyx"]
      分别构成三个最大特殊等价组。
示例 2 
输入：words = ["abc","acb","bac","bca","cab","cba"]
输出：3
解释：["abc","cba"]、["acb","bca"]、["bac","cab"]。
Contract

输入约束

函数numSpecialEquivGroups
参数words: string[]
返回integer
数组长度1 … 1000
字符串长度1 … 20
字符范围a … z

所有字符串长度相同；题目不要求输出各组成员。

Observe

先带走三点观察

1

跨轨道不可达

偶数下标字符无论怎样交换，都不会跑到奇数下标。

2

轨道内任意重排

允许交换任意一对同奇偶位置，因此同一轨道可实现任意排列。

3

分类只需要指纹

若两个轨道的字符多重集合分别相同，两个字符串就在同一组。

Try mentally

一眼辨别

zzxy 的偶数位是 z,x，奇数位是 z,y。排序后得到 xz | yz。

xyzz 的偶数位是 x,z，奇数位是 y,z，签名同样是 xz | yz，所以同组。

zzyx 则得到 yz | xz。两个部分不能互换，所以它属于另一组。

Solution

规范化签名 + 哈希集合

核心洞察

允许的交换保持两个不变量：偶数下标上的字符多重集合、奇数下标上的字符多重集合。反过来，只要两个字符串的这两个多重集合分别相同，就能各自在轨道内通过若干交换排成相同顺序。因此，这两个多重集合完整刻画了特殊等价关系。

完整过程

  1. 遍历每个字符串，把下标为偶数的字符放入 even，其余放入 odd。
  2. 分别排序，得到与原排列无关的规范表示。
  3. 用不会混淆边界的分隔符拼接为 sortedEven + "#" + sortedOdd。
  4. 把签名加入集合；最终集合大小就是组数。

正确性证明

  1. 必要性：一次合法交换只发生在同奇偶性的两个下标间，所以偶数位和奇数位各自的字符多重集合不变。若两字符串特殊等价，它们的两部分排序结果必然分别相同，签名相同。
  2. 充分性：若签名相同，则两字符串的偶数位字符多重集合相同、奇数位字符多重集合也相同。任意排列都能由交换得到，故可分别重排两条轨道，使两个字符串每个位置都相同，因此它们特殊等价。
  3. 计数：由前两点，签名相同当且仅当特殊等价。集合中不同签名的数量恰好等于等价类数量，即题目所求。

复杂度

设字符串数量为 n、统一长度为 m。每个字符串排序两段总计 O(m log m)，整体时间 O(nm log m)；保存签名需要 O(nm) 空间。由于字符仅有 26 种，也可计数到 O(nm) 时间。

边界情况

  • 长度为 1：奇数轨道为空，字符本身决定类别。
  • 所有字符串相同：集合始终只有一个签名。
  • 重复字符：必须保留出现次数，不能只用普通字符集合。
  • 奇数长度：偶数轨道会比奇数轨道多一个字符，不影响方法。

替代方案

为两条轨道分别维护 26 位频次数组，把 52 个计数编码为键。它避免排序，时间降为 O(nm)，但实现略长。也可以把排序后的偶数段和奇数段组成结构化键；多数语言里字符串键更方便。

面试追问

  • 为什么“任意两点交换”能产生任意排列？ 任意排列都能分解成若干换位；也可逐位置把目标字符换到位。
  • 若允许交换下标模 3 相同的位置呢？ 建立三条轨道，分别排序或计数，再合成签名。
  • 如何避免字符串分隔冲突？ 小写字母输入可安全使用 #；通用输入可编码长度或使用结构化序列化。

常见错误

  • 把整个字符串排序，会错误地允许字符跨奇偶轨道移动。
  • 只比较字符种类而忽略频次，例如两个 a 和一个 a 不等价。
  • 直接拼接两段却没有边界标记，在长度不固定的推广题中可能碰撞。
  • 实际模拟交换，状态空间巨大且完全没有必要。

四语言完整代码

import java.util.*;

class Solution {
    public int numSpecialEquivGroups(String[] words) {
        Set<String> signatures = new HashSet<>();
        for (String word : words) {
            char[] even = new char[(word.length() + 1) / 2];
            char[] odd = new char[word.length() / 2];
            int e = 0, o = 0;
            for (int i = 0; i < word.length(); i++) {
                if ((i & 1) == 0) even[e++] = word.charAt(i);
                else odd[o++] = word.charAt(i);
            }
            Arrays.sort(even);
            Arrays.sort(odd);
            signatures.add(new String(even) + "#" + new String(odd));
        }
        return signatures.size();
    }
}

var numSpecialEquivGroups = function(words) {
    const signatures = new Set();
    for (const word of words) {
        const even = [];
        const odd = [];
        for (let i = 0; i < word.length; i++) {
            (i % 2 === 0 ? even : odd).push(word[i]);
        }
        even.sort();
        odd.sort();
        signatures.add(even.join('') + '#' + odd.join(''));
    }
    return signatures.size;
};
from typing import List

class Solution:
    def numSpecialEquivGroups(self, words: List[str]) -> int:
        signatures = set()
        for word in words:
            even = ''.join(sorted(word[0::2]))
            odd = ''.join(sorted(word[1::2]))
            signatures.add(even + '#' + odd)
        return len(signatures)
#include <algorithm>

class Solution {
public:
    int numSpecialEquivGroups(vector<string>& words) {
        unordered_set<string> signatures;
        for (const string& word : words) {
            string even, odd;
            for (int i = 0; i < static_cast<int>(word.size()); ++i) {
                if (i % 2 == 0) even.push_back(word[i]);
                else odd.push_back(word[i]);
            }
            sort(even.begin(), even.end());
            sort(odd.begin(), odd.end());
            signatures.insert(even + "#" + odd);
        }
        return static_cast<int>(signatures.size());
    }
};
