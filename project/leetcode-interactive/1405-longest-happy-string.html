最长快乐字符串

给三种字符分配座位：每种字符数量有限，而且任何字符都不能连续出现三次。目标不是用完所有字符，而是让合法字符串尽可能长。

中等非付费题函数：longestDiverseString(a, b, c)

题目

返回任意一种最长答案

字符串 s 只由 'a'、'b'、'c' 组成。若它不包含 "aaa"、"bbb" 或 "ccc" 作为连续子串，就称为快乐字符串。

给定整数 a、b、c，构造尽可能长的快乐字符串，其中三种字符的使用次数分别不超过对应参数。最长答案不唯一时可以返回任意一个；若无法构造则返回空字符串。

输出判定：样例给出的字符串只是合法答案之一。评测关注长度最优、数量不超限且无三个相同字符连续。

参数与约束

  • 0 ≤ a, b, c ≤ 100
  • a + b + c > 0
  • 返回类型：string

子串指原字符串中一段连续的字符序列。

官方示例

示例 1
输入：a = 1, b = 1, c = 7
输出："ccaccbcc"
解释："ccbccacc" 也是正确答案。
示例 2
输入：a = 2, b = 2, c = 1
输出："aabbc"
示例 3

输出："aabaa"

Solution

贪心 + 最大堆

时间 O(a+b+c)

核心洞察

RULE 01

优先消耗最多的字符

每一步尽量取剩余数量最大的字符，避免它在后面堆积到无法安放。

RULE 02

连续两个就临时避让

若最高频字符会组成三个连续字符，就改取当前第二多的字符作隔板。

RULE 03

没有隔板即可停止

最高频字符被尾部阻塞且没有第二种字符时，任何继续拼接都会非法。

完整过程

  1. 把数量大于 0 的字符及其剩余次数放进最大堆。
  2. 取出剩余次数最多的字符 x。
  3. 若结果末尾已经是两个 x，则再取第二多的字符 y。若不存在 y，构造结束；否则追加 y，递减后放回堆，并把 x 原样放回。
  4. 若 x 不受尾部限制，直接追加 x，递减后按需放回堆。
  5. 重复以上步骤，直到堆空或无法合法追加。

为什么正确

  1. 始终合法：算法只会在待选字符与结果末尾两个字符相同时避让，所以每次追加后都不可能出现三个相同字符连续；每次使用也会同步减少库存，因此不会超量。
  2. 贪心选择不吃亏：在所有当前可追加的字符中，先消耗剩余最多者，可使各字符库存尽量平衡。若最多者被尾部两个同字符阻塞，那么下一位必须是其他字符；选其中剩余最多者同样最不容易制造新的库存偏斜。这一选择可与任意最优构造的下一次同类选择交换，而不减少可完成长度。
  3. 停止即最优：算法只有两种结束：库存全空，显然已经使用了全部字符；或唯一剩余字符与当前末尾两个字符相同。后一种情况下不存在任何合法的下一字符，所以任何拥有相同已用库存的构造都不能再延长。结合每步的安全贪心交换，所得字符串长度最大。

复杂度

设答案长度为 n，每加入一个字符至多进行常数次堆操作。堆中最多只有 3 个元素，因此时间复杂度为 O(n log 3) = O(n)，额外空间复杂度为 O(3) = O(1)（不计返回字符串）。

边界情况

  • 只有一种字符：最多只能放入两个，例如 (5,0,0) → "aa"。
  • 某一字符极多：其他字符充当隔板，剩余过多的主字符允许不用完。
  • 数量接近：贪心通常可以用完所有字符，但答案顺序可能与样例不同。
  • 某个计数为 0：不把该字符放入堆即可，无需特殊分支。

四语言完整代码

class Solution {
    private static class Node {
        char ch;
        int count;

        Node(char ch, int count) {
            this.ch = ch;
            this.count = count;
        }
    }

    public String longestDiverseString(int a, int b, int c) {
        java.util.PriorityQueue<Node> heap =
            new java.util.PriorityQueue<>((x, y) -> y.count - x.count);
        if (a > 0) heap.offer(new Node('a', a));
        if (b > 0) heap.offer(new Node('b', b));
        if (c > 0) heap.offer(new Node('c', c));

        StringBuilder answer = new StringBuilder();
        while (!heap.isEmpty()) {
            Node first = heap.poll();
            int n = answer.length();
            boolean blocked = n >= 2
                && answer.charAt(n - 1) == first.ch
                && answer.charAt(n - 2) == first.ch;

            if (blocked) {
                if (heap.isEmpty()) break;
                Node second = heap.poll();
                answer.append(second.ch);
                if (--second.count > 0) heap.offer(second);
                heap.offer(first);
            } else {
                answer.append(first.ch);
                if (--first.count > 0) heap.offer(first);
            }
        }
        return answer.toString();
    }
}

var longestDiverseString = function(a, b, c) {
    const heap = [];

    const push = (item) => {
        heap.push(item);
        let i = heap.length - 1;
        while (i > 0) {
            const p = Math.floor((i - 1) / 2);
            if (heap[p][0] >= heap[i][0]) break;
            [heap[p], heap[i]] = [heap[i], heap[p]];
            i = p;
        }
    };

    const pop = () => {
        const top = heap[0];
        const last = heap.pop();
        if (heap.length > 0) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let best = i;
                const left = i * 2 + 1;
                const right = left + 1;
                if (left < heap.length && heap[left][0] > heap[best][0]) best = left;
                if (right < heap.length && heap[right][0] > heap[best][0]) best = right;
                if (best === i) break;
                [heap[i], heap[best]] = [heap[best], heap[i]];
                i = best;
            }
        }
        return top;
    };

    if (a > 0) push([a, 'a']);
    if (b > 0) push([b, 'b']);
    if (c > 0) push([c, 'c']);

    const answer = [];
    while (heap.length > 0) {
        const first = pop();
        const n = answer.length;
        const blocked = n >= 2 && answer[n - 1] === first[1]
            && answer[n - 2] === first[1];

        if (blocked) {
            if (heap.length === 0) break;
            const second = pop();
            answer.push(second[1]);
            second[0]--;
            if (second[0] > 0) push(second);
            push(first);
        } else {
            answer.push(first[1]);
            first[0]--;
            if (first[0] > 0) push(first);
        }
    }
    return answer.join('');
};
from heapq import heappop, heappush


class Solution:
    def longestDiverseString(self, a: int, b: int, c: int) -> str:
        heap = []
        for count, ch in ((a, "a"), (b, "b"), (c, "c")):
            if count > 0:
                heappush(heap, (-count, ch))

        answer = []
        while heap:
            count1, ch1 = heappop(heap)
            blocked = (
                len(answer) >= 2
                and answer[-1] == ch1
                and answer[-2] == ch1
            )

            if blocked:
                if not heap:
                    break
                count2, ch2 = heappop(heap)
                answer.append(ch2)
                count2 += 1
                if count2 < 0:
                    heappush(heap, (count2, ch2))
                heappush(heap, (count1, ch1))
            else:
                answer.append(ch1)
                count1 += 1
                if count1 < 0:
                    heappush(heap, (count1, ch1))

        return "".join(answer)
class Solution {
public:
    string longestDiverseString(int a, int b, int c) {
        priority_queue<pair<int, char>> heap;
        if (a > 0) heap.push({a, 'a'});
        if (b > 0) heap.push({b, 'b'});
        if (c > 0) heap.push({c, 'c'});

        string answer;
        while (!heap.empty()) {
            auto [count1, ch1] = heap.top();
            heap.pop();
            int n = answer.size();
            bool blocked = n >= 2 && answer[n - 1] == ch1
                && answer[n - 2] == ch1;

            if (blocked) {
                if (heap.empty()) break;
                auto [count2, ch2] = heap.top();
                heap.pop();
                answer.push_back(ch2);
                if (--count2 > 0) heap.push({count2, ch2});
                heap.push({count1, ch1});
            } else {
                answer.push_back(ch1);
                if (--count1 > 0) heap.push({count1, ch1});
            }
        }
        return answer;
    }
};

替代方案

因为只有三种字符，也可以不用真正的堆：每轮把三个 (count, char) 按剩余数量排序，再执行同样的选择，代码更短且复杂度仍为 O(n)。还可以尝试按两枚主字符加一枚隔板成组拼接，但分支与边界更多，扩展到更多字符时也不如最大堆自然。

面试追问

  • 若字符种类扩展到 k 种？继续使用最大堆，时间复杂度变为 O(n log k)。
  • 若不允许连续出现 m 个相同字符？把“检查末尾两个”推广为检查末尾 m-1 个。
  • 怎样先计算最长长度？若最大库存为 M、其余总和为 R，主字符最多能放入 2(R+1) 个，因此长度上界为 R + min(M, 2(R+1))。
  • 为何不能总取数量最多者？若忽略连续限制，会直接形成三个相同字符，之后再补救可能已经无法保持前缀合法。

常见错误

  • 发现最高频字符被阻塞时直接结束，却忘记尝试第二高频字符。
  • 取出两个堆元素后，遗漏把尚有库存的元素放回。
  • 强求用完全部字符；题目只要求每种字符“不超过”给定次数。
  • 把样例输出当成唯一答案，用字符串全等而非合法性与最优长度判断。
  • 只比较结果最后一个字符，错误地禁止合法的连续两个相同字符。
