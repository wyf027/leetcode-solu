查找成绩处于中游的学生

找出参加过考试、并且在每一场参加的考试中都从未取得最低分或最高分的学生。先理解“任何一次极值都会淘汰”，再展开题解。

Find the Quiet Students in All Exams按 student_id 排序
Quiet ≠ 没参加

“中游学生”必须至少参加过一场考试。一场都没参加的学生不能进入结果；若某场只有一名考生，他同时是最高分与最低分，也会被排除。

Problem

题意与数据模型

准确转述，不含题解

任务

学校用 Student 保存学生，用 Exam 保存每次考试中每位参与者的分数。若一名学生至少参加过一次考试，并且在其参加的每一场考试里都既不是最低分、也不是最高分，则称其为“中游学生”。

返回所有中游学生的 student_id 与 student_name，按 student_id 升序排列。同分并列也算极值：只要分数等于该场最低分或最高分，就不符合条件。

输出： (student_id, student_name)，仅包含参加过考试且从未触碰任一场极值的学生。

完整约束与语义

  • Student.student_id 唯一标识学生。
  • Exam 每行表示某学生在某场考试的唯一成绩。
  • Exam.student_id 对应 Student.student_id。
  • 并列最高或最低的所有学生都要排除。
  • 没有参加任何考试的学生不返回。
  • 单人考试的考生同时命中两端极值。
  • 结果按 student_id 升序排列。

Solution

按考试排名，再按学生排除

窗口函数
01

局部标记

在每个 exam_id 分区内，分别按分数升序和降序做 RANK()。任一排名为 1，就触碰了极值。

02

全局否定

按学生分组，只保留所有成绩行的升序排名与降序排名都大于 1 的学生。

03

自然排除缺考

候选集合来自 Exam，从未参加考试的学生没有分组，不会误入结果。

完整过程

  1. 以 exam_id 分区，计算最低端排名 low_rank 和最高端排名 high_rank。
  2. RANK() 让所有并列最低/最高分都获得排名 1。
  3. 按 student_id 聚合，只保留 MIN(low_rank) > 1 且 MIN(high_rank) > 1 的学生。
  4. 连接 Student 取得姓名，最后按学生编号排序。

正确性证明

极值标记完备。 每场考试的所有最低分记录在升序 RANK() 中均为 1；所有最高分记录在降序排名中均为 1；非极值记录的两个排名都大于 1。
保留者一定正确。 若学生通过两个最小排名条件，则他的每条成绩在两种排名中都大于 1，所以从未处于任何一场考试的两端。
正确者一定保留。 若学生参加过考试且从未处于极值，他每条成绩的两个排名都大于 1，分组后的两个最小值仍大于 1。
缺考者不会混入。 分组只遍历 Exam；零考试学生没有成绩行。结果因此恰好是全部中游学生。

复杂度

设成绩行数为 N。窗口排序通常为 O(N log N)，之后的聚合和连接约为 O(N)；窗口结果需要约 O(N) 额外空间。实际代价取决于索引和执行计划。

边界条件

  • 并列极值：所有并列者都排除。
  • 单人考试：两种排名均为 1。
  • 参加多场：任意一次触碰极值即排除。
  • 零考试学生：不在候选聚合中。

WITH RankedScores AS (
    SELECT
        student_id,
        RANK() OVER (
            PARTITION BY exam_id ORDER BY score ASC
        ) AS low_rank,
        RANK() OVER (
            PARTITION BY exam_id ORDER BY score DESC
        ) AS high_rank
    FROM Exam
),
QuietStudents AS (
    SELECT student_id
    FROM RankedScores
    GROUP BY student_id
    HAVING MIN(low_rank) > 1
       AND MIN(high_rank) > 1
)
SELECT s.student_id, s.student_name
FROM Student AS s
JOIN QuietStudents AS q
  ON q.student_id = s.student_id
ORDER BY s.student_id;

import java.util.*;

public class QuietStudents {
  record Student(int id, String name) {}
  record Exam(int examId, int studentId, int score) {}

  static List<Student> solve(List<Student> students, List<Exam> exams) {
    Map<Integer, int[]> range = new HashMap<>();
    Set<Integer> took = new HashSet<>();
    for (Exam e : exams) {
      took.add(e.studentId());
      range.compute(e.examId(), (id, r) -> {
        if (r == null) return new int[]{e.score(), e.score()};
        r[0] = Math.min(r[0], e.score());
        r[1] = Math.max(r[1], e.score());
        return r;
      });
    }
    Set<Integer> bad = new HashSet<>();
    for (Exam e : exams) {
      int[] r = range.get(e.examId());
      if (e.score() == r[0] || e.score() == r[1]) bad.add(e.studentId());
    }
    return students.stream()
        .filter(s -> took.contains(s.id()) && !bad.contains(s.id()))
        .sorted(Comparator.comparingInt(Student::id))
        .toList();
  }
}
本地语义参考完整 JavaScript
function findQuietStudents(students, exams) {
  const ranges = new Map();
  const took = new Set();
  for (const { exam_id, student_id, score } of exams) {
    took.add(student_id);
    const r = ranges.get(exam_id) || { min: score, max: score };
    r.min = Math.min(r.min, score);
    r.max = Math.max(r.max, score);
    ranges.set(exam_id, r);
  }
  const bad = new Set();
  for (const { exam_id, student_id, score } of exams) {
    const { min, max } = ranges.get(exam_id);
    if (score === min || score === max) bad.add(student_id);
  }
  return students
    .filter(({ student_id }) => took.has(student_id) && !bad.has(student_id))
    .sort((a, b) => a.student_id - b.student_id);
}

def find_quiet_students(students, exams):
    ranges = {}
    took = set()
    for exam in exams:
        exam_id, sid, score = (
            exam["exam_id"], exam["student_id"], exam["score"]
        )
        took.add(sid)
        if exam_id not in ranges:
            ranges[exam_id] = [score, score]
        else:
            ranges[exam_id][0] = min(ranges[exam_id][0], score)
            ranges[exam_id][1] = max(ranges[exam_id][1], score)

    bad = set()
    for exam in exams:
        low, high = ranges[exam["exam_id"]]
        if exam["score"] == low or exam["score"] == high:
            bad.add(exam["student_id"])

    return sorted(
        (s for s in students if s["student_id"] in took
         and s["student_id"] not in bad),
        key=lambda s: s["student_id"],
    )

#include <algorithm>
#include <climits>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

struct Student { int id; string name; };
struct Exam { int examId; int studentId; int score; };

vector<Student> solve(const vector<Student>& students,
                      const vector<Exam>& exams) {
  unordered_map<int, pair<int, int>> range;
  unordered_set<int> took, bad;
  for (const auto& e : exams) {
    took.insert(e.studentId);
    if (!range.count(e.examId)) range[e.examId] = {INT_MAX, INT_MIN};
    range[e.examId].first = min(range[e.examId].first, e.score);
    range[e.examId].second = max(range[e.examId].second, e.score);
  }
  for (const auto& e : exams) {
    auto [low, high] = range[e.examId];
    if (e.score == low || e.score == high) bad.insert(e.studentId);
  }
  vector<Student> answer;
  for (const auto& s : students)
    if (took.count(s.id) && !bad.count(s.id)) answer.push_back(s);
  sort(answer.begin(), answer.end(),
       [](const Student& a, const Student& b) { return a.id < b.id; });
  return answer;
}

替代方案

NOT EXISTS： 先找所有触碰每场 MIN(score) 或 MAX(score) 的学生，再从参与者中反连接排除。表达直观，但相关子查询可能重复扫描。

预聚合： 先按考试计算最小/最大值，连接回成绩表后按学生聚合；适用于没有窗口函数的旧数据库。

面试追问

  • 为什么不用 ROW_NUMBER()？它只会标记并列极值中的一人。
  • 能否用集合差？可以：参与者减去全部极值学生。
  • 什么索引可能有帮助？可考虑 Exam(exam_id, score, student_id)，最终以执行计划为准。

常见错误

  • 把“每场都不是极值”误写成“至少一场不是极值”。
  • 用 ROW_NUMBER() 漏掉并列极值。
  • 左连接后把零考试学生当成“从未失败”。
  • 寻找全局极值，而不是按 exam_id 分区。
  • 忘记结果排序。
