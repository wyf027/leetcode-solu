乘积为偶数的子数组数

Number of Subarrays Having Even Product

观察连续区间，计算满足条件的数量。先独立思考，再打开下方的交互题解。

01 / PROBLEM

题目与输入约定

给定一个从下标 0 开始的正整数数组 nums，统计其中元素乘积为偶数的非空连续子数组个数，并返回这个计数。不同起点或终点的区间分别计数。

参数：nums: integer[]；函数：evenProduct(nums)；返回：长整数计数。

  • 1 ≤ nums.length ≤ 100000
  • 1 ≤ nums[i] ≤ 100000

官方示例 1

输入：nums = [9,6,7,13]
输出：6

符合要求的下标区间为 [0,1]、[0,2]、[0,3]、[1,1]、[1,2]、[1,3]，共 6 个。

官方示例 2

输入：nums = [7,3,5]
输出：0

所有非空连续区间的乘积都是奇数，因此计数为 0。

题意为转述。官方元数据的题面为空；题名、签名和示例输入取自本次元数据，示例输出与约束参考公开题目整理。来源：LeetCode 原题 · 公开题目整理。

03 / SOLUTION

准备好后，再看推导

包含交互演示、正确性证明与四语言实现。

核心洞察：只需要最近一个偶数

整数乘积为偶数，当且仅当其中至少一个因子为偶数。无需计算实际乘积。

固定右端点 r，设目前最近的偶数下标为 last。左端点可以选 0…last，共 last + 1 个；没有遇到偶数时令 last = -1，贡献自然为 0。

交互实验 · 右端点扫描与起点闸门

金色外框表示当前右端点；底部粗线表示偶数；浅绿色格子表示最近的偶数。每前进一步，观察哪些起点能通过“乘积为偶数”的闸门。

完整过程

  1. 初始化 last = -1 与 ans = 0。
  2. 从左向右访问每个下标 r。若 nums[r] 为偶数，先令 last = r。
  3. 把 last + 1 加入答案。遇到奇数时，最近偶数不变，合法起点数量也不变。
  4. 遍历结束后返回答案。

示例 [9,6,7,13] 中，last 依次为 -1,1,1,1，新增数量依次为 0,2,2,2，答案为 6。

正确性证明

不变式：处理完下标 r 的更新后，last 是区间 [0,r] 最右侧的偶数下标，若不存在则为 -1。初始成立；当前为偶数时覆盖为 r，否则沿用，所以始终成立。
本步计数：若左端点 l ≤ last，区间 [l,r] 包含该偶数，乘积必为偶数；若 l > last，最近偶数之后全是奇数，乘积必为奇数。因此合法起点恰好为 0 到 last，本步贡献恰好为 last + 1。
完整且无重复：每个非空子数组都有唯一右端点。逐个右端点相加，覆盖所有合法子数组，且不会重复统计。因此返回值正确。

边界与复杂度

  • 全奇数：last 一直为 -1，答案为 0。全偶数：每步新增 r + 1，总计 n(n + 1)/2。
  • 首个偶数出现前贡献为 0；连续偶数会让 last 连续向右更新。长度为 1 时由该元素奇偶性决定答案。
  • 时间 O(n)，额外空间 O(1)。演示为了回退保存或重算显示状态，其显示成本不计入解法空间。
  • n = 100000 时答案最大 5000050000，超过 32 位有符号整数。Java 用 long，C++ 用 long long；Python 整数无此溢出；JavaScript Number 在此范围内可精确表示。

替代方案

补集法：总子数组数减去全奇数子数组数。扫描时维护以当前位置结尾的连续奇数长度 odd；遇到奇数 odd++，遇到偶数 odd = 0，再累加 odd 得到全奇数区间数。时间 O(n)、空间 O(1)，也可按奇数段长度 L 累加 L(L+1)/2。

动态规划写法：维护当前右端点的合法区间数量 count，遇到偶数令 count = r + 1，遇到奇数保留 count，再累加。它与 last + 1 等价。枚举所有区间的朴素做法为 O(n²)，不适合完整约束。

常见错误

  • 直接连乘导致溢出；本题只依赖奇偶性。
  • last 初始化为 0，错误统计首个偶数之前的区间。
  • 累加 last 而非 last + 1，遗漏下标 0 这个合法起点。
  • 先累加再更新 last，漏掉当前元素为偶数时的新区间。
  • 只数偶数元素或非连续子序列，混淆统计对象。

面试追问

  • 输入流如何处理？保留位置、last、累计答案即可，每来一个数 O(1) 更新。
  • 若允许 0 或负数呢？“包含偶数”仍然等价，0 也是偶数，取模判断不变；但这超出原题输入约束。
  • 若要求乘积可被 4 整除呢？仅知道最后一个偶数不够，需要跟踪因子 2 的累计数量：一个 4 的倍数或两个含至少一个 2 因子的数均可能达标。
  • 若要求乘积为奇数？累加每个位置结尾的连续奇数长度，即补集法中被减去的部分。

四语言完整提交代码

Java

class Solution {
    public long evenProduct(int[] nums) {
        long ans = 0;
        int last = -1;
        for (int r = 0; r < nums.length; r++) {
            if (nums[r] % 2 == 0) last = r;
            ans += last + 1;
        }
        return ans;
    }
}
