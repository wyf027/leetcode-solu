BRIEF / 题意转述

找到所有不重复装箱方案

给定互不相同的正整数数组 candidates 和正整数 target，找出所有元素和等于 target 的组合。每个候选数可以重复选择无限次，组合顺序不计入区别。

去重关键：路径始终保持非递减。下一层只从当前下标开始选，因此会生成 [2,2,3]，不会再生成 [2,3,2]。

约束：1 ≤ candidates.length ≤ 30；2 ≤ candidates[i] ≤ 40；元素互不相同；1 ≤ target ≤ 40；答案数少于 150。

CORE INSIGHT

把排列树压成非递减组合树

状态定义

dfs(start, remaining)：当前路径已经确定，只能从 start 及其右侧候选数继续选，还差 remaining 达标。

两个出口

remaining == 0：复制路径加入答案；排序后遇到 candidate > remaining：后面都更大，直接 break。

FULL PROCESS

完整解题过程

  1. 1

    排序 candidates。这样 candidate 超过 remaining 时可以提前停止，也让输出天然非递减。

  2. 2

    从 start 枚举。选择 candidates[i] 并压入 path。

  3. 3

    递归仍传 i。同一个数字还可继续使用；remaining 减去它。

  4. 4

    撤销选择。递归返回后 pop，恢复现场并尝试下一个候选数。

TIME

O(NT/M)

粗略上界：N 为候选数个数，T 为 target，M 为最小候选数；实际与有效/被剪枝节点数相关。

SPACE

O(T/M)

不计返回结果，递归深度与 path 最大长度受最小候选数限制。

OUTPUT

O(S)

S 是所有答案元素总数；保存输出本身不可省略。

PRUNE

排序后 break

当前数字已超出 remaining，后续更大数字无需继续尝试。

EDGE CASES

边界情况

  • • 最小候选数大于 target：根节点直接剪枝，返回空数组。
  • • 某个候选数等于 target：单元素组合直接加入答案。
  • • 只有一个候选数：target 能整除它才有答案。
  • • candidates 原始无序：先排序，不影响组合语义。
  • • 保存答案必须复制 path，不能保存同一个可变引用。

ALTERNATIVES

替代方案取舍

主推：回溯 + start

直接枚举答案，状态清楚、去重自然，最适合面试表达。

动态规划构造组合

可以按总和累计组合，但存储和去重更重，讲解成本高，不如回溯直观。

暴力排列

会重复生成 [2,2,3]、[2,3,2] 等排列，之后再用集合去重，浪费搜索与内存。

INTERVIEW FOLLOW-UPS

面试高频追问

为什么递归传 i 而不是 i + 1？
本题允许同一数字无限次使用；传 i 保留再次选当前数的权利。
start 如何去重？
路径只会选择当前下标及右侧，组合始终非递减，同一多重集合只有一种顺序。
如果每个数只能使用一次？
递归改传 i + 1；若输入还可能重复，需要同层跳过重复值，这就是第 40 题。
为什么答案要复制 path？
path 会持续 push/pop；直接保存引用会让所有答案随路径一起变化。

COMMON MISTAKES

常见错误

  • ✕ 每层从 0 开始枚举，导致同一组合产生多种排列。
  • ✕ 递归传 i + 1，错误地禁止候选数重复使用。
  • ✕ 忘记 pop，后续分支混入上一分支的选择。
  • ✕ remaining == 0 后仍继续递归，产生无意义搜索。
  • ✕ 未排序却使用 candidate > remaining 时 break，可能漏解。
  • ✕ Java/JS 将 path 引用直接放入答案，没有复制。
