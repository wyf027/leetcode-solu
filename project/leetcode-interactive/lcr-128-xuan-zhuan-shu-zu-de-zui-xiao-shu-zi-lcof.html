库存管理 I

一组原本递增的库存编号被从某处旋转。无需恢复完整顺序，利用左右端点与中点的关系即可找到最小编号。

开始演示

题意

给定数组 stock，它由一个非递减数组旋转得到。请返回其中的最小元素。数组中可能存在重复数字。

约束

  • • 1 ≤ stock.length ≤ 5000
  • • 每个库存编号均为整数。
  • • 原数组非递减，旋转次数可以是 0。

示例

[3,4,5,1,2]

返回 1

[2,2,2,0,1]

返回 0

[1,2,3]

返回 1

分步交互：缩小候选区间

输入以英文逗号分隔的旋转数组；“下一步”会执行一次二分判断。

核心洞察

比较 stock[mid] 和 stock[right]：若中点更大，最小值一定在右半段，令 left = mid + 1；若更小，中点可能就是最小值，令 right = mid。相等时无法判断旋转点在哪一边，只能安全地令 right--。

完整过程

  1. 1. 初始化 left = 0、right = n - 1。
  2. 2. 当 left < right，取中点 mid。
  3. 3. 根据中点与右端值的大小关系保留仍可能含最小值的一半。
  4. 4. 区间收敛时，stock[left] 即答案。

边界条件

  • • 只有一个元素：直接返回它。
  • • 未旋转数组：不断向左收缩。
  • • 全部相同：每次右端左移，仍正确。
  • • 必须保留 mid，不能在较小时写成 right = mid - 1。

复杂度

无重复元素时为 O(log n)；重复元素会触发 right--，最坏为 O(n)。额外空间始终为 O(1)。

替代方案

线性扫描最简单且同样正确，但放弃了数组旋转结构带来的对数级加速。

追问与常见错误

追问

若题目保证没有重复值，可以删去相等分支，复杂度稳定为 O(log n)。

常见错误

相等时直接移动左端会丢掉最小值；中点较小时排除 mid 也会漏解。

官方签名代码

// Java
class Solution {
  public int inventoryManagement(int[] stock) {
    int left = 0, right = stock.length - 1;
    while (left < right) {
      int mid = left + (right - left) / 2;
      if (stock[mid] > stock[right]) left = mid + 1;
      else if (stock[mid] < stock[right]) right = mid;
      else right--;
    }
    return stock[left];
  }
}
// JavaScript
var inventoryManagement = function(stock) {
  let left = 0, right = stock.length - 1;
  while (left < right) {
    const mid = left + Math.floor((right - left) / 2);
    if (stock[mid] > stock[right]) left = mid + 1;
    else if (stock[mid] < stock[right]) right = mid;
    else right--;
  }
  return stock[left];
};
