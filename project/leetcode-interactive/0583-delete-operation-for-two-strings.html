题解：保留最长的共同骨架

!

核心洞察

删除结束后，两串保留下来的相同结果一定是它们的公共子序列。为了让删除次数最少，应让保留部分尽可能长，也就是寻找最长公共子序列（LCS）。

最少删除次数 = m + n - 2 × LCS(word1, word2)

完整过程

  1. 令 dp[i][j] 表示 word1[0..i) 与 word2[0..j) 的 LCS 长度。
  2. 空前缀没有可保留字符，因此 dp[0][j] = dp[i][0] = 0。
  3. 若末尾字符相同，把它接在更短前缀的 LCS 后：dp[i][j] = dp[i-1][j-1] + 1。
  4. 若末尾字符不同，至少舍弃一侧末尾：dp[i][j] = max(dp[i-1][j], dp[i][j-1])。
  5. 设最终 LCS 长度为 L，两串分别删除 m-L 与 n-L 个字符。

正确性证明

引理：上述状态转移能得到每对前缀的最长公共子序列长度。若末尾字符相同，存在最优解包含该字符，问题缩为两个更短前缀；若不同，任一公共子序列不可能同时使用两个不同末尾，必落在去掉其中一侧末尾的两个子问题之一。

定理：设任意合法最终字符串长度为 k，它是两串公共子序列，所以 k ≤ LCS，删除数至少为 m+n-2×LCS。保留任一 LCS 并删去其余字符恰好达到该值，故算法最优。

边界与复杂度

  • 两串相同：LCS 等于串长，答案为 0。
  • 无公共字符：LCS 为 0，需要删光两串。
  • 长度为 1 时同样由通用转移覆盖。
  • 时间复杂度：O(mn)。
  • 滚动数组空间复杂度：O(n)；可让 n 取较短字符串长度，优化为 O(min(m,n))。

替代方案与面试追问

  • 直接删除 DP：del[i][j] 表示两前缀变相同的最少删除数；相等取左上，不等取 1 + min(上, 左)。
  • 追问：恢复具体删除方案？保留二维表并从右下角回溯，得到一条 LCS，再标记两串中未被匹配的位置。
  • 追问：字符带不同删除成本？改用加权删除 DP；普通 LCS 长度公式不再直接适用。
  • 追问：为何不能排序？子序列必须保持原相对顺序，排序会破坏题意。

常见错误

  • 把最长公共子序列误写成最长公共子串，错误地要求字符连续。
  • 一维滚动时从左向右更新，却没有保存左上角旧值，导致状态被覆盖。
  • 答案漏乘 2：LCS 中的每个保留字符同时存在于两串。
  • JavaScript 使用共享引用初始化二维数组，例如 Array(m).fill(Array(n).fill(0))。

为什么一维滚动成立

处理第 i 行时，dp[j] 更新前仍是“上方”，更新后成为“当前行”；dp[j-1] 是“左侧”，额外变量 prevDiagonal 保存更新前的“左上方”。因此三类依赖都完整保留。

四语言完整代码

Java · 官方提交签名
class Solution {
    public int minDistance(String word1, String word2) {
        // 让 word2 成为较短串，可进一步压缩常数空间。
        if (word1.length() < word2.length()) {
            String temp = word1;
            word1 = word2;
            word2 = temp;
        }

        int m = word1.length();
        int n = word2.length();
        int[] dp = new int[n + 1];

        for (int i = 1; i <= m; i++) {
            int prevDiagonal = 0;
            for (int j = 1; j <= n; j++) {
                int oldTop = dp[j];
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[j] = prevDiagonal + 1;
                } else {
                    dp[j] = Math.max(dp[j], dp[j - 1]);
                }
                prevDiagonal = oldTop;
            }
        }

        int lcs = dp[n];
        return m + n - 2 * lcs;
    }
}

/**
 * @param {string} word1
 * @param {string} word2
 * @return {number}
 */
var minDistance = function (word1, word2) {
    if (word1.length < word2.length) {
        [word1, word2] = [word2, word1];
    }

    const m = word1.length;
    const n = word2.length;
    const dp = new Array(n + 1).fill(0);

    for (let i = 1; i <= m; i++) {
        let prevDiagonal = 0;
        for (let j = 1; j <= n; j++) {
            const oldTop = dp[j];
            if (word1[i - 1] === word2[j - 1]) {
                dp[j] = prevDiagonal + 1;
            } else {
                dp[j] = Math.max(dp[j], dp[j - 1]);
            }
            prevDiagonal = oldTop;
        }
    }

    const lcs = dp[n];
    return m + n - 2 * lcs;
};

class Solution {
public:
    int minDistance(string word1, string word2) {
        if (word1.size() < word2.size()) {
            swap(word1, word2);
        }

        const int m = static_cast<int>(word1.size());
        const int n = static_cast<int>(word2.size());
        vector<int> dp(n + 1, 0);

        for (int i = 1; i <= m; ++i) {
            int prevDiagonal = 0;
            for (int j = 1; j <= n; ++j) {
                int oldTop = dp[j];
                if (word1[i - 1] == word2[j - 1]) {
                    dp[j] = prevDiagonal + 1;
                } else {
                    dp[j] = max(dp[j], dp[j - 1]);
                }
                prevDiagonal = oldTop;
            }
        }

        const int lcs = dp[n];
        return m + n - 2 * lcs;
    }
};
