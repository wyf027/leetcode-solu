Problem brief

规则很短，选择会互相影响

给定整数数组 nums，其中每个元素代表一个气球上的数字。戳破全部气球，并最大化获得的硬币总数。

题意转述

气球按当前顺序排列。戳破当前的第 i 个气球时，收益等于它与此刻左右相邻气球数字的乘积：

left × nums[i] × right

如果左侧或右侧已经越过数组边界，就把该侧数字视为 1。气球被戳破后会从序列中消失，剩余气球重新成为邻居。返回能得到的最大硬币数。

约束

  • n == nums.length
  • 1 <= n <= 300
  • 0 <= nums[i] <= 100

函数形式：

maxCoins(nums: integer[]) -> integer

示例 1

输入：nums = [3,1,5,8]
输出：167
解释：
[3,1,5,8] → [3,5,8] → [3,8] → [8] → []
3×1×5 + 3×5×8 + 1×3×8 + 1×8×1 = 167

示例 2

输入：nums = [1,5]
输出：10

Complete solution

区间动态规划：逆转决策方向

核心洞察

直接决定“第一个戳谁”很难，因为它会让左右邻居不断变化。反过来，若决定开区间 (L, R) 中最后戳破的是 K，那么那一刻 K 的邻居一定是边界 L 与 R。

在数组两端补上数字 1。设 dp[L][R] 为戳完开区间 (L, R) 中全部气球能得到的最大硬币数。

完整过程

  1. 构造 balloons = [1] + nums + [1]。
  2. 按区间跨度从小到大枚举边界 L, R。
  3. 枚举 K ∈ (L, R)，把它当作该区间最后戳破的气球。
  4. 组合左右子区间最优值与最后一步收益，取最大值。
  5. 答案为 dp[0][n+1]。

状态转移

dp[L][R] = max(
  dp[L][K] + dp[K][R] + balloons[L] × balloons[K] × balloons[R]
)  其中 L < K < R

正确性说明

完备性：任意戳破方案在区间 (L, R) 中都有唯一一个最后被戳破的气球 K。在它之前，左侧 (L, K) 与右侧 (K, R) 的气球都已被戳完，而且两侧互不影响。

最优子结构：若某个全局最优方案的左侧或右侧子方案不是对应子区间的最优方案，就可以替换为更优子方案，得到更大的总收益，与全局最优矛盾。

归纳：空区间收益为 0。按跨度递增计算时，转移依赖的两个子区间跨度都更小，已得到最优值。枚举所有可能的最后气球并取最大值，便得到当前区间最优值。最终 dp[0][n+1] 覆盖全部原始气球。

边界与复杂度

  • 单个气球：答案为该数字本身。
  • 数字为 0：转移仍然成立，不需要特殊分支。
  • 两端补 1 后，所有越界情况都被统一处理。
  • 时间复杂度：O(n³)。
  • 空间复杂度：O(n²)。
  • 在官方约束下最大量级约为 n × 100³，32 位有符号整数可容纳。

替代方案

记忆化搜索：状态与递推完全相同，递归求解 solve(L, R)。思路更直观，但存在递归开销与栈深度问题。

枚举戳破顺序：共有 n! 种顺序，只适合极小规模或用来构造对拍基准，无法通过 n = 300。

面试追问

  • 如何恢复一种最优戳破顺序？额外记录每个区间取得最大值时的 K，递归先恢复左右区间，再输出 K。
  • 为什么按区间长度递增？因为 dp[L][R] 依赖跨度更小的 dp[L][K] 与 dp[K][R]。
  • 若允许负数怎么办？递推仍可用，但非空区间初值不能设为 0，应初始化为负无穷。

常见错误

  • 从“第一个戳破”出发，导致邻居状态无法独立描述。
  • 混淆开区间与闭区间，漏掉 K = L + 1 或边界答案。
  • 区间遍历顺序错误，在子状态尚未完成时就读取它。
  • 忘记在两端补 1，写出大量易错边界判断。
  • 返回 dp[1][n]，而不是补边界后的 dp[0][n+1]。

Java 
class Solution {
    public int maxCoins(int[] nums) {
        int n = nums.length;
        int[] balloons = new int[n + 2];
        balloons[0] = 1;
        balloons[n + 1] = 1;
        for (int i = 0; i < n; i++) {
            balloons[i + 1] = nums[i];
        }

        int[][] dp = new int[n + 2][n + 2];
        for (int gap = 2; gap < n + 2; gap++) {
            for (int left = 0; left + gap < n + 2; left++) {
                int right = left + gap;
                for (int last = left + 1; last < right; last++) {
                    int coins = dp[left][last]
                            + dp[last][right]
                            + balloons[left] * balloons[last] * balloons[right];
                    dp[left][right] = Math.max(dp[left][right], coins);
                }
            }
        }
        return dp[0][n + 1];
    }
}

var maxCoins = function(nums) {
    const balloons = [1, ...nums, 1];
    const size = balloons.length;
    const dp = Array.from(
        { length: size },
        () => Array(size).fill(0)
    );

    for (let gap = 2; gap < size; gap++) {
        for (let left = 0; left + gap < size; left++) {
            const right = left + gap;
            for (let last = left + 1; last < right; last++) {
                const coins = dp[left][last]
                    + dp[last][right]
                    + balloons[left] * balloons[last] * balloons[right];
                dp[left][right] = Math.max(dp[left][right], coins);
            }
        }
    }
    return dp[0][size - 1];
};
Python 
from typing import List


class Solution:
    def maxCoins(self, nums: List[int]) -> int:
        balloons = [1] + nums + [1]
        size = len(balloons)
        dp = [[0] * size for _ in range(size)]

        for gap in range(2, size):
            for left in range(0, size - gap):
                right = left + gap
                for last in range(left + 1, right):
                    coins = (
                        dp[left][last]
                        + dp[last][right]
                        + balloons[left] * balloons[last] * balloons[right]
                    )
                    dp[left][right] = max(dp[left][right], coins)

        return dp[0][size - 1]
C++ 
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maxCoins(vector<int>& nums) {
        const int n = static_cast<int>(nums.size());
        vector<int> balloons(n + 2, 1);
        for (int i = 0; i < n; ++i) {
            balloons[i + 1] = nums[i];
        }

        vector<vector<int>> dp(n + 2, vector<int>(n + 2, 0));
        for (int gap = 2; gap < n + 2; ++gap) {
            for (int left = 0; left + gap < n + 2; ++left) {
                const int right = left + gap;
                for (int last = left + 1; last < right; ++last) {
                    const int coins = dp[left][last]
                        + dp[last][right]
                        + balloons[left] * balloons[last] * balloons[right];
                    dp[left][right] = max(dp[left][right], coins);
                }
            }
        }
        return dp[0][n + 1];
    }
};
