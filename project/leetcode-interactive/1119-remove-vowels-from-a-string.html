删去字符串中的元音

Remove Vowels from a String

EASY付费题字符串线性扫描

题目描述

给定一个仅含小写英文字母的字符串 s，删除其中所有元音字母 a、e、i、o、u，返回剩余字符按原顺序组成的新字符串。

函数签名

removeVowels(s: string): string

约束

  • 1 ≤ s.length ≤ 1000
  • s 仅由小写英文字母组成。

官方示例（完整参数形式）

示例 1
输入：s = "leetcodeisacommunityforcoders"
输出："leetcdiscmmntyfrcdrs"
示例 2
输入：s = "aeiou"
输出：""

题解：一次线性扫描

核心洞察：输出只取决于每个字符是否属于固定集合 {a,e,i,o,u}。按顺序保留非元音，就天然维持了相对顺序。

完整过程

  1. 准备元音集合或等价的成员判断。
  2. 从左到右遍历 s。
  3. 若当前字符不是元音，将它追加到结果；否则跳过。
  4. 遍历结束后返回结果字符串。

正确性说明

对任意位置 i，算法仅当 s[i] 不是元音时追加它，因此结果不含元音；所有非元音都会被追加一次，且遍历顺序与原串一致，因此既没有遗漏，也保持相对顺序。故返回值正是删除全部元音后的字符串。

边界情况

  • 全是元音：结果为空字符串。
  • 没有元音：原样返回。
  • 长度为 1：根据该字符是否为元音得到空串或其自身。
  • 重复字符：逐个独立判断，不受影响。

复杂度

时间复杂度 O(n)；用于输出的空间为 O(n)。若不计返回值，各实现的额外辅助空间可视为 O(1)（固定大小的元音集合）。

替代方案

可用正则表达式一次替换所有元音，代码更短；但线性扫描更直观、跨语言一致，也更便于解释分配行为。还可用五次字符比较替代集合查找。

面试追问

  • 如果输入含大写字母，如何兼容且保留原始大小写？
  • 如果“元音”由 Unicode 或语言区域规则定义，固定五字符集合为何不足？
  • 如何在流式输入上处理而不保存整个源字符串？

常见错误

  • 把 y 误当作本题元音。
  • 原地删除时移动下标，导致连续元音被跳过。
  • 使用 Java 的 String 循环拼接造成不必要的重复复制。

四语言完整代码

Java

class Solution {
    public String removeVowels(String s) {
        StringBuilder answer = new StringBuilder();
        for (char c : s.toCharArray()) {
            if ("aeiou".indexOf(c) == -1) {
                answer.append(c);
            }
        }
        return answer.toString();
    }
}

JavaScript

/**
 * @param {string} s
 * @return {string}
 */
var removeVowels = function(s) {
    const vowels = new Set(['a', 'e', 'i', 'o', 'u']);
    const answer = [];
    for (const char of s) {
        if (!vowels.has(char)) answer.push(char);
    }
    return answer.join('');
};

Python

class Solution:
    def removeVowels(self, s: str) -> str:
        vowels = set("aeiou")
        return "".join(char for char in s
                       if char not in vowels)

C++

class Solution {
public:
    string removeVowels(string s) {
        string answer;
        for (char c : s) {
            if (string("aeiou").find(c) == string::npos) {
                answer.push_back(c);
            }
        }
        return answer;
    }
};
