相对名次

Relative Ranks

一场比赛，一组互不相同的分数。把排名重新映射回每位运动员原来的位置，让奖牌与名次各归其主。

题号 506 非付费题 数组 · 排序 · 堆
01 / Problem

题目描述

得分决定比赛名次，但返回值必须保持运动员的原始顺序。

给定长度为 n 的整数数组 score，其中 score[i] 表示第 i 位运动员的得分，且所有得分互不相同。

得分越高，名次越靠前。请返回长度为 n 的字符串数组 answer，其中 answer[i] 是第 i 位运动员获得的奖牌名称或名次编号。

  • 第 1 名："Gold Medal"
  • 第 2 名："Silver Medal"
  • 第 3 名："Bronze Medal"
  • 第 4 至第 n 名：对应名次的十进制字符串

函数契约

findRelativeRanks(score: integer[]) → string[]

约束

  • n == score.length
  • 1 ≤ n ≤ 10⁴
  • 0 ≤ score[i] ≤ 10⁶
  • score 中的值互不相同
EXAMPLE 01
输入参数score = [5,4,3,2,1]
输出["Gold Medal","Silver Medal","Bronze Medal","4","5"]
说明五人的名次依次是第 1、2、3、4、5 名。
EXAMPLE 02
输入参数score = [10,3,8,9,4]
输出["Gold Medal","5","Bronze Medal","Silver Medal","4"]
说明原位置对应的名次依次是第 1、5、3、2、4 名。

03 / Solution

准备好看题解了吗？

先自己想一想：怎样既按分数确定名次，又把名次放回原来的运动员位置？

Solution Unlocked

排序下标，再按原位回填

关键不在于移动分数，而在于保留每个分数属于哪位运动员。

核心洞察

建立下标数组 [0, 1, ..., n-1]，按对应分数从高到低排序。排序后第 rank - 1 个下标，就是第 rank 名运动员在原数组中的位置。

完整过程

  1. 创建包含全部原下标的数组。
  2. 依据 score[index] 降序排列下标。
  3. 从第 1 名遍历至第 n 名。
  4. 前三名写入奖牌名称，其余写入名次数字。
  5. 写入位置始终使用运动员的原下标。

边界情况

  • 只有 1 或 2 位运动员时，只会出现已有名次对应的奖牌。
  • 得分可以为 0，不影响降序比较。
  • 得分互不相同，因此不需要定义并列名次。
  • 名次必须转换为字符串，不能返回数字。

替代方案与面试追问

  • 最大堆：保存“分数 + 原下标”，逐个弹出并赋名次，复杂度同为 O(n log n)。
  • 计数映射：利用分数上界可做到 O(n + U)，但需 O(U) 额外空间，通常不如排序简洁。
  • 若允许并列：需先明确稠密排名、竞赛排名等规则，当前方案不能直接套用。

正确性证明

引理：下标数组按对应分数降序排列后，其第 k 个元素所指向的运动员恰为第 k + 1 名。因为所有得分互不相同，降序中的每个位置都唯一对应第几高的分数。

回填：算法为排序后第 k 个下标写入第 k + 1 名的标签；该下标就是运动员在输入中的原位置，所以标签被写入正确的 answer[i]。

结论：每个运动员被排序数组恰好包含一次，算法为其写入且仅写入一次正确名次，因此返回数组完全正确。

时间 O(n log n)，由排序主导
空间 O(n)，用于下标与答案

常见错误

  • 直接排序 score 后丢失原始位置。
  • 把前三名判断写成分数阈值，而不是排序后的名次。
  • 比较器方向写反，导致最低分获得金牌。
  • Java 使用 int[] 下标并试图传给需要对象的比较排序；应使用 Integer[]。

Solution.javaindex sort
import java.util.Arrays;

class Solution {
    public String[] findRelativeRanks(int[] score) {
        int n = score.length;
        Integer[] indices = new Integer[n];
        for (int i = 0; i < n; i++) {
            indices[i] = i;
        }

        Arrays.sort(indices, (a, b) -> Integer.compare(score[b], score[a]));

        String[] answer = new String[n];
        String[] medals = {"Gold Medal", "Silver Medal", "Bronze Medal"};
        for (int rank = 0; rank < n; rank++) {
            int originalIndex = indices[rank];
            answer[originalIndex] = rank < 3
                    ? medals[rank]
                    : String.valueOf(rank + 1);
        }
        return answer;
    }
}

/**
 * @param {number[]} score
 * @return {string[]}

var findRelativeRanks = function(score) {
    const indices = score.map((_, index) => index);
    indices.sort((a, b) => score[b] - score[a]);

    const medals = ["Gold Medal", "Silver Medal", "Bronze Medal"];
    const answer = new Array(score.length);

    indices.forEach((originalIndex, rank) => {
        answer[originalIndex] = rank < 3
            ? medals[rank]
            : String(rank + 1);
    });

    return answer;
};
solution.pyindex sort
from typing import List

class Solution:
    def findRelativeRanks(self, score: List[int]) -> List[str]:
        indices = sorted(range(len(score)), key=lambda i: score[i], reverse=True)
        medals = ["Gold Medal", "Silver Medal", "Bronze Medal"]
        answer = [""] * len(score)

        for rank, original_index in enumerate(indices):
            answer[original_index] = (
                medals[rank] if rank < 3 else str(rank + 1)
            )

        return answer

class Solution {
public:
    vector<string> findRelativeRanks(vector<int>& score) {
        int n = score.size();
        vector<int> indices(n);
        iota(indices.begin(), indices.end(), 0);

        sort(indices.begin(), indices.end(), [&](int a, int b) {
            return score[a] > score[b];
        });

        vector<string> medals = {"Gold Medal", "Silver Medal", "Bronze Medal"};
        vector<string> answer(n);
        for (int rank = 0; rank < n; rank++) {
            int originalIndex = indices[rank];
            answer[originalIndex] = rank < 3
                    ? medals[rank]
                    : to_string(rank + 1);
        }
        return answer;
    }
};
