学生编号

Find the Student that Will Replace the Chalk

一盒粉笔，一圈学生。轮到谁时，粉笔第一次不够用？
先读规则并自己推演，再按需展开底部题解。

01 / 题目与规则

有 n 位学生，编号从 0 到 n − 1。老师按编号循环点名，最后一位之后重新轮到 0 号。数组 chalk 表示每位学生每次答题需要消耗的粉笔数，最初有 k 支。

轮到学生 i 时，若剩余数量严格小于 chalk[i]，他就需要补充粉笔，返回该学生的编号。若刚好够用，照常消耗，继续轮到下一位。

参数：chalk: integer[]，k: integer → integer；函数名 chalkReplacer。

官方示例 1

输入：chalk = [5,1,5], k = 22
输出：0

按 0、1、2、0、1、2 的顺序使用后，剩余数量依次为 17、16、11、6、5、0。再次轮到 0 号时，需要 5 支却没有粉笔，返回 0。

官方示例 2

输入：chalk = [3,4,1,2], k = 25
输出：1

前八次使用后的剩余量依次为 22、18、17、15、12、8、7、5。0 号再用 3 支，剩余 2 支；1 号需要 4 支，返回 1。

约束

  • chalk.length == n
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ chalk[i] ≤ 10⁵
  • 1 ≤ k ≤ 10⁹

04 / 独立题解

准备好后，展开思路与实现。

跳过完整轮次，再找第一次不足

核心洞察

一圈总共消耗 S = sum(chalk) 支。只要有至少 S 支，就一定能完整走过这一圈；走完仍从 0 号开始。因此用 r = k % S 一次跳过所有完整轮次，然后只处理最后不足一圈的部分。

完整过程

  1. 遍历 chalk 求总和 S，使用可容纳 10¹⁰ 的类型。
  2. 令剩余量 r = k % S，满足 0 ≤ r < S。
  3. 依次检查每个学生：若 r < chalk[i]，返回 i；否则扣除 chalk[i]。

示例 2：S = 10，25 % 10 = 5。0 号使用 3 支，剩余 2 支；2 < 4，故返回 1。示例 1 的余数为 0，第一位学生就需要补充。

正确性证明

整圈等价：所有 chalk[i] 都为正数。若一圈开始时剩余至少 S，则在任意学生前，剩余量至少为该学生到圈末的总需求，因此这一圈没人缺粉笔。跳过 ⌊k/S⌋ 圈后，当前学生仍为 0，剩余为 k % S，后续过程与原过程相同。

扫描不变式：检查 i 时，r 等于最后一圈开始的剩余量减去前 i 个学生的需求，且前 i 个学生均已成功答题。若 r 小于当前需求，i 正是第一个失败者；否则扣除后，不变式对下一位成立。由于初始 r < S，不可能让整圈全部成功，所以必然返回且返回值正确。

边界与常见错误

  • 比较必须用 <，不能用 <=；恰好够用时应交给下一位。
  • 余数为 0 时返回 0。原始输入 k ≥ 1，但取模结果允许为 0。
  • 编号从 0 开始，不要返回 i + 1。
  • n = 1 时，无论经过多少圈，答案总为 0。
  • S 最大为 10¹⁰。Java 使用 long，C++ 使用 long long，避免 int 累加溢出。JavaScript Number 可精确表示这里的整数；Python 整数无需单独扩容。
  • 无需模拟十亿次扣减，也不要把数组排序：原始学生顺序决定答案。

复杂度与替代方案

两次线性遍历，时间 O(n)；只存总和与余数，额外空间 O(1)。

直接循环模拟最坏需要约 k 次成功答题（每次至少消耗 1），为 O(k)，k 可达 10⁹。也可以预计算递增前缀和 P，在取模后寻找第一个 P[i] > r：预处理 O(n) 时间和空间，单次二分 O(log n)。单次查询仍受预处理 O(n) 支配；同一 chalk 上大量查询时更合适。

面试追问

  • 多次查询不同 k？复用总和与前缀和，每次先取模，再二分首个严格大于余数的位置。
  • 学生消耗经常更新？可用树状数组维护总和，并按剩余量查找前缀位置；更新和查询均 O(log n)。
  • 允许消耗为 0？只要总和仍为正，扫描仍可用；总和为 0 时永远不缺粉笔，需要另行定义返回规则，原题排除了这种情况。

Java

class Solution {
    public int chalkReplacer(int[] chalk, int k) {
        long sum = 0;
        for (int amount : chalk) sum += amount;
        long remaining = k % sum;
        for (int i = 0; i < chalk.length; i++) {
            if (remaining < chalk[i]) return i;
            remaining -= chalk[i];
        }
        return -1; // 按题目约束不会到达
    }
}

from typing import List

class Solution:
    def chalkReplacer(self, chalk: List[int], k: int) -> int:
        remaining = k % sum(chalk)
        for i, amount in enumerate(chalk):
            if remaining < amount:
                return i
            remaining -= amount
        return -1  # 按题目约束不会到达

#include <vector>
using namespace std;

class Solution {
public:
    int chalkReplacer(vector<int>& chalk, int k) {
        long long sum = 0;
        for (int amount : chalk) sum += amount;
        long long remaining = k % sum;
        for (int i = 0; i < static_cast<int>(chalk.size()); ++i) {
            if (remaining < chalk[i]) return i;
            remaining -= chalk[i];
        }
        return -1; // 按题目约束不会到达
    }
};
