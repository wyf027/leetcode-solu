贪吃蛇

Design Snake Game

在一个 height × width 的棋盘上设计贪吃蛇。蛇从左上角 (0, 0) 出发，食物按给定顺序出现；每次移动后返回当前得分，撞墙或撞到自身则返回 -1。

接口： SnakeGame(width, height, food) 初始化；move(direction) 接受 U / D / L / R 并返回整数。

题意与接口

实现 SnakeGame 类，在 height 行、width 列的棋盘上维护一条蛇。行号自上向下、列号自左向右，均从 0 开始。蛇的初始身体只有 (0,0)。

  • SnakeGame(int width, int height, int[][] food)：保存棋盘尺寸和食物列表。只有当前食物被吃掉后，下一个食物才会出现。
  • int move(String direction)：让蛇头向 U、D、L 或 R 移动一格。
  • 若新蛇头越界或与移动后的蛇身重合，游戏结束并返回 -1；否则返回得分。吃到当前食物时蛇尾不移动，蛇长和得分都增加 1。

官方示例（完整参数形式）

输入
["SnakeGame", "move", "move", "move", "move", "move", "move"]
[[3, 2, [[1, 2], [0, 1]]], ["R"], ["D"], ["R"], ["U"], ["L"], ["U"]]
输出
[null, 0, 0, 1, 1, 2, -1]

解释：棋盘宽 3、高 2。蛇依次右、下、右移动并吃到 (1,2)；随后上、左并吃到 (0,1)；最后再向上越界，返回 -1。

约束

  • 1 ≤ width, height ≤ 10⁴
  • 1 ≤ food.length ≤ 50，且每个位置均为合法的 [row, col]
  • 0 ≤ row < height，0 ≤ col < width
  • direction 为单个字符，且属于 U、D、L、R
  • 对 move 的调用次数不超过 10⁴

关键语义提醒：未吃到食物时，蛇尾会先离开。因此，新蛇头移动到“本步刚刚腾出的旧蛇尾位置”是合法的。

完整题解

核心洞察

一次移动只改变蛇的两端：蛇头新增一个位置；若没吃到食物，蛇尾删除一个位置。需要同时满足两种操作：按顺序删除旧尾，以及近似常数时间判断新头是否撞到身体。因此组合使用“队列/双端队列 + 哈希集合”：

  • 双端队列按尾到头保存每个身体坐标，负责维护顺序。
  • 哈希集合保存所有被占用坐标，负责快速碰撞查询。
  • 食物指针只向前移动；其数值恰好等于当前得分。

完整过程

  1. 根据方向计算新蛇头 (nr, nc)，若越界，标记游戏结束并返回 -1。
  2. 判断新蛇头是否等于当前食物。若相等，本步增长，不删除蛇尾；否则先从队列和集合中删除旧蛇尾。
  3. 在上述尾部处理之后查询集合。若新蛇头仍在集合中，说明确实撞到身体，返回 -1。
  4. 将新蛇头加入队尾与集合。若吃到食物，再推进食物指针。
  5. 返回食物指针，也就是累计得分。

正确性证明

不变式：每次合法移动结束后，队列从尾到头恰好记录蛇身的连续顺序，集合恰好包含队列中的全部坐标，食物指针恰好等于已吃食物数量。

初始化：队列与集合都只含 (0,0)，食物指针为 0，不变式成立。

保持：若本步不进食，旧尾先从两种结构中移除，恰好模拟整条蛇前进一格；若进食，尾部保留，恰好模拟长度增加。随后若新头仍在集合中，它与移动后的身体重合，判定自撞正确；否则将新头同时加入队列和集合，两种结构再次完全一致。进食时且仅进食时指针加 1，所以它始终等于得分。

终止与返回：越界或自撞时返回 -1，与规则一致；所有合法移动返回已吃食物数。故算法对每次调用都返回正确结果。

边界情况

  • 1 × 1 棋盘：任何方向都会立刻越界。
  • 移动到旧尾位置：只要本步不进食就是合法，因此必须先删尾再判自撞。
  • 吃到食物：不能删除尾巴，否则长度不会增加。
  • 食物已经吃完：后续移动都按普通不增长移动处理。
  • 游戏已结束：实现保存结束状态，后续调用稳定返回 -1。

复杂度

设蛇当前长度为 L。每次 move 的队列和哈希操作平均为 O(1)；队列与集合占用 O(L) 空间。哈希表在极端碰撞下的理论最坏时间取决于语言实现。

替代方案

  • 仅用队列：维护身体容易，但每步检测自撞需扫描，单次为 O(L)。
  • 二维布尔棋盘：碰撞为 O(1)，但当宽高都接近 10⁴ 时会浪费大量空间。
  • 有序集合：可完成占用判断，但通常是 O(log L)，且仍需队列维护尾部顺序。

面试追问

  • 如何支持障碍物？增加独立障碍集合，并在插入新头前查询。
  • 如何支持撤销？为每次移动记录尾部删除、头部新增、进食与结束状态的差量日志。
  • 如何多人联机？需要明确同一 tick 的并发移动、头对头碰撞和确定性结算顺序。
  • 如何避免坐标字符串开销？将 (r,c) 编码为整数 r × width + c。

常见错误

  • 在删除旧尾之前判断自撞，错误拒绝“进入旧尾”的合法移动。
  • 吃到食物后仍删除蛇尾，导致长度和占用集合不一致。
  • 把构造参数误写成 (height, width)，从而交换边界。
  • 只更新队列或只更新集合，产生幽灵身体或漏判碰撞。
  • 游戏结束后仍继续修改内部状态。

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashSet;
import java.util.Set;

class SnakeGame {
    private final int width;
    private final int height;
    private final int[][] food;
    private int foodIndex = 0;
    private boolean gameOver = false;
    private final Deque<int[]> body = new ArrayDeque<>();
    private final Set<Long> occupied = new HashSet<>();

    public SnakeGame(int width, int height, int[][] food) {
        this.width = width;
        this.height = height;
        this.food = food;
        body.offerLast(new int[]{0, 0});
        occupied.add(encode(0, 0));
    }

    public int move(String direction) {
        if (gameOver) return -1;

        int[] head = body.peekLast();
        int row = head[0];
        int col = head[1];
        switch (direction.charAt(0)) {
            case 'U': row--; break;
            case 'D': row++; break;
            case 'L': col--; break;
            case 'R': col++; break;
            default: throw new IllegalArgumentException("Invalid direction");
        }

        if (row < 0 || row >= height || col < 0 || col >= width) {
            gameOver = true;
            return -1;
        }

        boolean eating = foodIndex < food.length
                && food[foodIndex][0] == row
                && food[foodIndex][1] == col;

        if (!eating) {
            int[] tail = body.pollFirst();
            occupied.remove(encode(tail[0], tail[1]));
        }

        long key = encode(row, col);
        if (occupied.contains(key)) {
            gameOver = true;
            return -1;
        }

        body.offerLast(new int[]{row, col});
        occupied.add(key);
        if (eating) foodIndex++;
        return foodIndex;
    }

    private long encode(int row, int col) {
        return (long) row * width + col;
    }
}

var SnakeGame = function(width, height, food) {
    this.width = width;
    this.height = height;
    this.food = food;
    this.foodIndex = 0;
    this.body = [[0, 0]]; // tail ... head
    this.tailIndex = 0;
    this.occupied = new Set(["0,0"]);
    this.gameOver = false;
};

SnakeGame.prototype.move = function(direction) {
    if (this.gameOver) return -1;

    const head = this.body[this.body.length - 1];
    let row = head[0];
    let col = head[1];
    if (direction === "U") row--;
    else if (direction === "D") row++;
    else if (direction === "L") col--;
    else if (direction === "R") col++;

    if (row < 0 || row >= this.height || col < 0 || col >= this.width) {
        this.gameOver = true;
        return -1;
    }

    const eating = this.foodIndex < this.food.length
        && this.food[this.foodIndex][0] === row
        && this.food[this.foodIndex][1] === col;

    if (!eating) {
        const tail = this.body[this.tailIndex++];
        this.occupied.delete(tail[0] + "," + tail[1]);
    }

    const key = row + "," + col;
    if (this.occupied.has(key)) {
        this.gameOver = true;
        return -1;
    }

    this.body.push([row, col]);
    this.occupied.add(key);
    if (eating) this.foodIndex++;
    return this.foodIndex;
};

from collections import deque
from typing import List


class SnakeGame:
    def __init__(self, width: int, height: int, food: List[List[int]]):
        self.width = width
        self.height = height
        self.food = food
        self.food_index = 0
        self.body = deque([(0, 0)])  # tail ... head
        self.occupied = {(0, 0)}
        self.game_over = False

    def move(self, direction: str) -> int:
        if self.game_over:
            return -1

        row, col = self.body[-1]
        dr, dc = {
            "U": (-1, 0),
            "D": (1, 0),
            "L": (0, -1),
            "R": (0, 1),
        }[direction]
        row += dr
        col += dc

        if row < 0 or row >= self.height or col < 0 or col >= self.width:
            self.game_over = True
            return -1

        eating = (
            self.food_index < len(self.food)
            and self.food[self.food_index] == [row, col]
        )

        if not eating:
            tail = self.body.popleft()
            self.occupied.remove(tail)

        if (row, col) in self.occupied:
            self.game_over = True
            return -1

        self.body.append((row, col))
        self.occupied.add((row, col))
        if eating:
            self.food_index += 1
        return self.food_index

#include <deque>
#include <stdexcept>
#include <string>
#include <unordered_set>
#include <utility>
#include <vector>
using namespace std;

class SnakeGame {
private:
    int width;
    int height;
    vector<vector<int>> food;
    int foodIndex = 0;
    bool gameOver = false;
    deque<pair<int, int>> body;
    unordered_set<long long> occupied;

    long long encode(int row, int col) const {
        return static_cast<long long>(row) * width + col;
    }

public:
    SnakeGame(int width, int height, vector<vector<int>>& food)
        : width(width), height(height), food(food) {
        body.push_back({0, 0});
        occupied.insert(encode(0, 0));
    }

    int move(string direction) {
        if (gameOver) return -1;

        auto [row, col] = body.back();
        if (direction == "U") --row;
        else if (direction == "D") ++row;
        else if (direction == "L") --col;
        else if (direction == "R") ++col;
        else throw invalid_argument("Invalid direction");

        if (row < 0 || row >= height || col < 0 || col >= width) {
            gameOver = true;
            return -1;
        }

        bool eating = foodIndex < static_cast<int>(food.size())
            && food[foodIndex][0] == row
            && food[foodIndex][1] == col;

        if (!eating) {
            auto tail = body.front();
            body.pop_front();
            occupied.erase(encode(tail.first, tail.second));
        }

        long long key = encode(row, col);
        if (occupied.count(key)) {
            gameOver = true;
            return -1;
        }

        body.push_back({row, col});
        occupied.insert(key);
        if (eating) ++foodIndex;
        return foodIndex;
    }
};
