雇佣 K 名工人的
最低成本

每个人都有自己的质量与最低工资。请选出恰好 K 人，并用统一的“每单位质量价格”公平支付，让总成本尽可能低。

题目

Minimum Cost to Hire K Workers

工资组规则

有 n 名工人，quality[i] 表示第 i 人的工作质量，wage[i] 是其最低期望工资。请选择恰好 k 人，并满足：

  1. 组内所有人的实际工资必须与其质量成正比。
  2. 每个人的实际工资不能低于自己的最低期望工资。

返回满足条件所需的最小总金额；与正确答案的误差在 10^-5 内可接受。

示例 1 输入：quality = [10,20,5], wage = [70,50,30], k = 2 输出：105.00000 解释：向 0 号工人支付 70，向 2 号工人支付 35。
示例 2 输入：quality = [3,1,10,10,1], wage = [4,8,2,2,7], k = 3 输出：30.66667 解释：向 0 号工人支付 4，向 2、3 号工人各支付 13.33333。

参数与约束

n == quality.length == wage.length
1 <= k <= n <= 10^4
1 <= quality[i], wage[i] <= 10^4
mincostToHireWorkers(quality, wage, k) → double

题解：比例排序 + 最大堆

从“谁决定单价”切入

核心洞察

若整组按每单位质量 r 元支付，工人 i 得到 quality[i] × r。满足其最低工资要求，必须有：

r ≥ wage[i] / quality[i]

对任意选定组，真正决定统一单价的是组内最大的 wage / quality。固定这个最大比例 r 后，总成本是 r × 组内质量总和。所以依次把每个比例当作上限，在比例不超过它的工人中保留质量最小的 K 人。

完整过程

  1. 计算每人的 wage[i] / quality[i]，按比例升序排列。
  2. 从左到右扫描，将当前质量加入最大堆，并累加质量和。
  3. 若堆大小超过 k，弹出最大的质量，使堆中始终是当前前缀内质量和最小的 K 人。
  4. 堆大小等于 k 时，用 质量和 × 当前比例 更新答案。

正确性证明

1
单价下界。比例支付使组内单位质量工资相同。要满足所有最低工资，该单价至少等于组内最大的 wage[i]/quality[i]。
2
固定比例的最优组。扫描到比例 r 时，所有已扫描工人都能按 r 合法支付。成本与质量和成正比，最大堆删除最大质量后，留下的正是质量和最小的 K 人。
3
覆盖全局最优。任意最优组都有一名工人给出组内最大比例。扫描到他时，该组成员均已出现；算法选出的 K 人质量和不会更大，因此当步成本不会更差。遍历所有比例取最小值即为全局最优。

边界情况

  • k = 1：答案等于所有最低工资中的最小值。
  • k = n：只能选择所有工人，由最大比例决定单价。
  • 比例相同不影响正确性；最终金额用浮点数。
  • 质量和在 Java/C++ 中使用足够大的整数类型。

复杂度

排序为 O(n log n)；每人入堆一次、至多出堆一次，堆操作为 O(log k)。总时间 O(n log n)，额外空间 O(n + k)（计入排序数组）。

替代方案

对每个可能比例重新排序选择 K 人会达到约 O(n² log n)。也能用平衡树维护质量集合，但最大堆只需定位并删除最大质量，更直接。

四种语言实现

class Solution {
    public double mincostToHireWorkers(int[] quality, int[] wage, int k) {
        int n = quality.length;
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (a, b) -> Double.compare(
            (double) wage[a] / quality[a],
            (double) wage[b] / quality[b]
        ));

        PriorityQueue<Integer> heap =
            new PriorityQueue<>(Collections.reverseOrder());
        long sum = 0;
        double answer = Double.MAX_VALUE;
        for (int i : order) {
            heap.offer(quality[i]);
            sum += quality[i];
            if (heap.size() > k) sum -= heap.poll();
            if (heap.size() == k) {
                double ratio = (double) wage[i] / quality[i];
                answer = Math.min(answer, sum * ratio);
            }
        }
        return answer;
    }
}

var mincostToHireWorkers = function(quality, wage, k) {
    const workers = quality.map((q, i) => [wage[i] / q, q]);
    workers.sort((a, b) => a[0] - b[0]);

    const heap = [];
    const push = x => {
        heap.push(x);
        let i = heap.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (heap[p] >= heap[i]) break;
            [heap[p], heap[i]] = [heap[i], heap[p]];
            i = p;
        }
    };
    const pop = () => {
        const top = heap[0], last = heap.pop();
        if (heap.length) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let m = i, l = i * 2 + 1, r = l + 1;
                if (l < heap.length && heap[l] > heap[m]) m = l;
                if (r < heap.length && heap[r] > heap[m]) m = r;
                if (m === i) break;
                [heap[i], heap[m]] = [heap[m], heap[i]];
                i = m;
            }
        }
        return top;
    };

    let sum = 0, answer = Infinity;
    for (const [ratio, q] of workers) {
        push(q);
        sum += q;
        if (heap.length > k) sum -= pop();
        if (heap.length === k) answer = Math.min(answer, sum * ratio);
    }
    return answer;
};
from typing import List
import heapq

class Solution:
    def mincostToHireWorkers(
        self, quality: List[int], wage: List[int], k: int
    ) -> float:
        workers = sorted((w / q, q) for q, w in zip(quality, wage))
        heap = []
        quality_sum = 0
        answer = float("inf")

        for ratio, q in workers:
            heapq.heappush(heap, -q)
            quality_sum += q
            if len(heap) > k:
                quality_sum += heapq.heappop(heap)
            if len(heap) == k:
                answer = min(answer, quality_sum * ratio)

        return answer
class Solution {
public:
    double mincostToHireWorkers(vector<int>& quality,
                                vector<int>& wage, int k) {
        vector<pair<double, int>> workers;
        for (int i = 0; i < quality.size(); ++i) {
            workers.push_back({
                static_cast<double>(wage[i]) / quality[i], quality[i]
            });
        }
        sort(workers.begin(), workers.end());

        priority_queue<int> heap;
        long long sum = 0;
        double answer = numeric_limits<double>::max();
        for (auto [ratio, q] : workers) {
            heap.push(q);
            sum += q;
            if (heap.size() > k) {
                sum -= heap.top();
                heap.pop();
            }
            if (heap.size() == k) answer = min(answer, sum * ratio);
        }
        return answer;
    }
};

面试追问

  • 为什么按比例排序，而不是按工资或质量？
  • 为何堆中弹出最大质量？
  • 如何用交换论证证明留下的是最优 K 人？
  • 若还要输出工人编号，结构如何调整？
  • 怎样减少比较比例时的浮点误差？

常见错误

  • 把最低工资和直接当作成本。
  • 使用最小堆，误删最小质量。
  • 在堆裁剪前计算候选成本。
  • 只在堆首次达到 K 时更新。
  • 整数除法截断比例。
