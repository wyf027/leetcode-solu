CORE INSIGHT

把题目写成单向状态机

指针只向右走：先消费空格，再消费至多一个符号，最后消费一段连续数字。数字阶段一旦遇到非数字，答案立即确定。真正容易错的不是乘加，而是规则顺序与溢出时机。

SPACE SIGN DIGIT STOP

OVERFLOW GATE

乘 10 之前先问：还放得下吗？

value > (INT_MAX - digit) / 10

条件成立时，不执行 value × 10 + digit，直接按符号返回 INT_MAX 或 INT_MIN。这样四种语言都不依赖溢出后的值。

FULL WALKTHROUGH

完整解题过程

  1. 1. 跳过前导空格

    只认普通空格，并且只在字符串开头跳过。

  2. 2. 读取一次符号

    看到 − 记为 −1，看到 + 或没有符号则为 +1。

  3. 3. 连续读取数字

    每轮先计算 digit，再通过边界式检查，最后乘 10 加 digit。

  4. 4. 非数字立即停止

    不跳过、不恢复扫描；返回 sign × value。未读到数字时 value 自然为 0。

边界情况

  • • 空串或全是空格 → 0
  • • 只有 + / − → 0
  • • “+−12” → 0
  • • “4193 with words” → 4193
  • • “words 987” → 0
  • • “00000−42” → 0
  • • 正溢出 → INT_MAX
  • • 负溢出 → INT_MIN

class Solution {
    public int myAtoi(String s) {
        int index = 0;
        int length = s.length();

        while (index < length && s.charAt(index) == ' ') {
            index++;
        }

        int sign = 1;
        if (index < length && (s.charAt(index) == '+' || s.charAt(index) == '-')) {
            sign = s.charAt(index) == '-' ? -1 : 1;
            index++;
        }

        int value = 0;
        while (index < length && s.charAt(index) >= '0' && s.charAt(index) <= '9') {
            int digit = s.charAt(index) - '0';
            if (value > (Integer.MAX_VALUE - digit) / 10) {
                return sign == 1 ? Integer.MAX_VALUE : Integer.MIN_VALUE;
            }
            value = value * 10 + digit;
            index++;
        }
        return sign * value;
    }
}
var myAtoi = function (s) {
  const INT_MAX = 2147483647;
  const INT_MIN = -2147483648;
  let index = 0;

  while (index < s.length && s[index] === " ") index++;

  let sign = 1;
  if (index < s.length && (s[index] === "+" || s[index] === "-")) {
    sign = s[index] === "-" ? -1 : 1;
    index++;
  }

  let value = 0;
  while (index < s.length && s[index] >= "0" && s[index] <= "9") {
    const digit = s.charCodeAt(index) - 48;
    if (value > Math.floor((INT_MAX - digit) / 10)) {
      return sign === 1 ? INT_MAX : INT_MIN;
    }
    value = value * 10 + digit;
    index++;
  }
  return sign * value;
};

面试高频追问

为什么遇到字母后不能继续找数字？
题目只转换合法的连续数字前缀，非法字符就是终止边界。
为什么在乘 10 前判断？
在固定宽度整数语言中，溢出后的值已经不可信，无法靠事后比较补救。
如何扩展到浮点数？
增加小数点、指数和结束状态，显式状态机会比多个 if 更稳。

常见错误

  • • 使用 trim，误以为中间或末尾空格也可随意忽略。
  • • 遇到非法字符后 continue，错误地拼接后面的数字。
  • • 允许连续两个符号，或在数字后重新读取符号。
  • • 先乘加再判断溢出，Java / C++ 中结果已经越界。
  • • 忘记空串、全空格和只有符号的输入。
