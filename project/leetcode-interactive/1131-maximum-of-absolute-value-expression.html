Maximum of Absolute Value Expression

绝对值表达式的最大值

两组同长度整数数组，任取两个下标。你的任务，是找出三个“距离”之和能达到的最大值。

|arr1[i] − arr1[j]| + |arr2[i] − arr2[j]| + |i − j|

先理解问题，再动手观察数据。题解被收在页面底部，不会在首屏剧透。

Problem

题目描述

给定两个长度相等的整数数组 arr1 和 arr2，在所有满足 0 ≤ i, j < arr1.length 的下标对中，返回上述表达式的最大值。

示例 1

输入：arr1 = [1,2,3,4], arr2 = [-1,4,5,6] 输出：13

完整参数：maxAbsValExpr([1,2,3,4], [-1,4,5,6])

示例 2

输入：arr1 = [1,-2,-5,0,10], arr2 = [0,-2,-1,-7,-4] 输出：20

完整参数：maxAbsValExpr([1,-2,-5,0,10], [0,-2,-1,-7,-4])

约束

  • 2 ≤ arr1.length == arr2.length ≤ 40000
  • -10⁶ ≤ arr1[i], arr2[i] ≤ 10⁶

Key Insight

核心洞察：把绝对值变成有限个方向

利用 |x| = max(x, -x)，三个绝对值可以展开成符号组合。对任意 s1, s2, s3 ∈ {−1, +1}，考虑：

s1·(arr1[i]−arr1[j]) + s2·(arr2[i]−arr2[j]) + s3·(i−j)

它等于某个投影值 F(i) 减去 F(j)。固定符号后，最大差就是 max(F) − min(F)。八种符号组合中，一组与“全部符号取反”的另一组得到相同跨度，因此固定下标项系数为 +1，只需枚举 arr1 与 arr2 的四种正负组合：

F(i) = s1·arr1[i] + s2·arr2[i] + i，s1,s2 ∈ {−1,+1}

完整过程

  1. 初始化答案为 0。
  2. 枚举四组 (s1, s2)：(+,+)、(+,-)、(-,+)、(-,-)。
  3. 对每组符号，从左到右计算 F(i)，同步维护最小值与最大值。
  4. 用该方向的 max(F) − min(F) 更新全局答案。
  5. 四个方向扫描完成后返回答案。

复杂度

时间：O(4n) = O(n)，四个方向各扫描一次。

空间：O(1)，只维护每个方向的极值和答案。

边界情况

  • 长度最小为 2，仍能正常形成下标对。
  • 两数组元素完全相同，下标距离仍会贡献答案。
  • 全负数、重复值、极端正负值不影响投影推导。
  • 题目范围下 32 位有符号整数足够；迁移到更大范围时应改用 64 位。

正确性证明

引理 1：对固定下标对 (i,j)，原式等于八种符号组合线性式的最大值。这直接来自对三个绝对值分别选择正号或负号。

引理 2：固定符号组合时，线性式可写为 F(i) − F(j)，其在所有下标对上的最大值必为 max(F) − min(F)。

引理 3：符号组合 (s1,s2,s3) 与 (−s1,−s2,−s3) 产生相同的取值跨度，因为后者只是将所有 F 取反。因此固定 s3=+1 后的四组组合已经覆盖全部可能最大值。

结论：算法计算每个必要方向的精确最大跨度，并取其中最大者；依据三个引理，该值恰好等于原表达式的全局最大值，算法正确。

四语言完整代码

class Solution {
    public int maxAbsValExpr(int[] arr1, int[] arr2) {
        int answer = 0;
        int[][] signs = {{1, 1}, {1, -1}, {-1, 1}, {-1, -1}};

        for (int[] sign : signs) {
            int minValue = Integer.MAX_VALUE;
            int maxValue = Integer.MIN_VALUE;

            for (int i = 0; i < arr1.length; i++) {
                int value = sign[0] * arr1[i] + sign[1] * arr2[i] + i;
                minValue = Math.min(minValue, value);
                maxValue = Math.max(maxValue, value);
            }
            answer = Math.max(answer, maxValue - minValue);
        }
        return answer;
    }
}

替代方案

枚举下标对：直接计算每个 (i,j)，逻辑直观，但时间复杂度为 O(n²)，在 n=40000 时不可行。

枚举八个符号：同样正确，时间仍为 O(n)，但做了成对重复工作。固定下标项为正后压缩到四种更简洁。

常见错误

  • 漏掉 +i，只处理两个数组差值。
  • 只枚举两种正负组合，无法覆盖所有方向。
  • 误以为必须满足 i < j；题目允许任意 i,j。
  • 每个方向没有重新初始化最小值和最大值。
  • 把投影最大值当答案，忘记答案是最大值减最小值。

面试追问

  1. 为什么八种符号可以减为四种？请从“投影整体取反不改变极差”解释。
  2. 如果再增加一组数组 arr3 呢？固定下标符号后，需要枚举 2³=8 个方向。
  3. 如何返回达到最大值的下标对？维护每个方向最小、最大投影对应的下标，并在更新全局答案时记录它们。
  4. 能否在线处理追加元素？可以；对每个方向持续更新极值和全局答案，每次追加只需常数个方向的工作。
