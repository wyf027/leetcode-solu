统计目标成绩的出现次数

给定非递减成绩数组与目标成绩，返回目标值的出现次数。先操作双边界雷达观察定位过程，再到页面底部决定是否展开完整题解。

Easy数组 · 非递减scores.length ≤ 10⁵
题意（准确转述）

成绩 scores 按非递减顺序给出。返回目标成绩 target 在数组中出现的次数。

示例 1

scores = [2, 2, 3, 4, 4, 4, 5, 6, 6, 8]

target = 4

输出 = 3

约束：0 ≤ scores.length ≤ 10⁵；scores 非递减；分数与 target 在 [-10⁹, 10⁹]。

题解区域

默认收起：先亲手观察两个边界，再查看完整解释与可提交代码。

核心洞察

有序性让每个谓词形成单调分界线：scores[i] ≥ target 的第一处是左边界；scores[i] > target 的第一处是右边界。两者之间恰好全等于 target，所以答案为 right - left。

完整过程

  1. 在区间 [0, n) 二分，遇到 scores[mid] < target 时让 left = mid + 1，否则收缩右边界，得到 lower bound。
  2. 再次二分，判断改为 scores[mid] ≤ target；满足时推进左边界，得到 upper bound。
  3. 相减。目标不存在时两个边界会重合，自然返回 0。

边界与复杂度

  • 空数组：两个边界均为 0。
  • 目标小于最小值或大于最大值：边界仍在合法的 [0, n] 内。
  • 全数组都等于目标：左边界为 0，右边界为 n。
  • 时间 O(log n)，额外空间 O(1)。

替代方案、面试追问与常见错误

替代：线性扫描可读但为 O(n)；库函数 lower/upper bound 也合适，面试中要能说明其单调谓词。
追问：若数组未排序，先排序会改变索引并花 O(n log n)；若有大量查询，可预处理每个分数的频次。
常见错误：用“找到任意一个 target”无法得到次数；upper bound 条件应为 ≤ target；用 [left, right] 时容易写出越界，推荐半开区间 [left, right)。

class Solution {
    public int countTarget(int[] scores, int target) {
        return upperBound(scores, target) - lowerBound(scores, target);
    }

    private int lowerBound(int[] a, int target) {
        int left = 0, right = a.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (a[mid] < target) left = mid + 1;
            else right = mid;
        }
        return left;
    }

    private int upperBound(int[] a, int target) {
        int left = 0, right = a.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (a[mid] <= target) left = mid + 1;
            else right = mid;
        }
        return left;
    }
}
var countTarget = function (scores, target) {
  const bound = (strict) => {
    let left = 0;
    let right = scores.length;
    while (left < right) {
      const mid = left + Math.floor((right - left) / 2);
      if (scores[mid] < target || (strict && scores[mid] === target)) left = mid + 1;
      else right = mid;
    }
    return left;
  };
  return bound(true) - bound(false);
};
