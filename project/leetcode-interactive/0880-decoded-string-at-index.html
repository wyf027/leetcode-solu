Decoded String at Index · 不必真的铺满一条近乎无限长的磁带，也能定位第 k 个字符。

MEDIUM双向推演O(n) 时间O(1) 额外空间
Problem

先读懂编码规则

函数签名：decodeAtIndex(s, k) → string

题意

给定编码字符串 s。从左到右读取：遇到小写字母，就把它写到磁带末尾；遇到数字 d，就把当前整条磁带再复制 d - 1 次，使其总共出现 d 份。

给定从 1 开始计数的索引 k，返回完整解码结果中的第 k 个字母。

注意：完整磁带可能极长。题目只要求一个字符，并未要求构造解码字符串。

约束

  • 2 ≤ s.length ≤ 100
  • s 只含小写英文字母和数字 2..9
  • s 以字母开头
  • 1 ≤ k ≤ 10⁹
  • k 不超过解码字符串长度
  • 解码字符串长度小于 2⁶³

示例 1

输入：s = "leet2code3", k = 10
输出："o"
解释：解码为
"leetleetcodeleetleetcodeleetleetcode"，
第 10 个字母是 "o"。

示例 2

输入：s = "ha22", k = 5
输出："h"
解释：解码为 "hahahaha"，
第 5 个字母是 "h"。

示例 3

输入：
s = "a2345678999999999999999", k = 1
输出："a"
解释："a" 被重复
8301530446056247680 次。

准备好再揭开题解

核心推导、证明、复杂度与四种语言代码均在下方折叠区。

Full Solution

反向折叠索引，而不是展开字符串

核心洞察

数字会让已有前缀整体重复，因此只需知道前缀长度。若当前长度为 size，目标位置可用 k %= size 映射回这一层复制之前；余数为 0 表示该层最后一个字符。

完整过程

  1. 正向扫描：字母令 size + 1，数字 d 令 size × d。
  2. 反向扫描：先令 k %= size。
  3. 若当前是字母且 k == 0，它就是答案。
  4. 撤销当前字符：数字令 size /= d，字母令 size--。

正确性

不变式：反向处理每一层时，k 指向当前解码前缀中与原目标等价的位置。数字产生的每份内容完全相同，模当前长度能保留等价位置；撤销字母时长度减一。当模后位置为 0 且当前字符是字母，它恰是当前前缀末位，因此返回值正确。

边界与复杂度

用 64 位整数保存长度；k 从 1 开始，所以余数 0 代表末位。时间复杂度 O(n)，额外空间 O(1)（不计语言字符迭代细节）。

替代方案

直接构造字符串最直观，但解码长度可接近 2⁶³，内存与时间均不可接受。也可保存每个位置的前缀长度栈，反向时更易理解，但会使用 O(n) 空间。

面试追问

  • 为什么余数 0 不能改成 k = (k - 1) % size + 1 后直接照搬判断？
  • 若数字允许多位数，解析方式如何改变？
  • 若长度可能超过 64 位，如何使用大整数或提前截断？

常见错误

  • 真的构造完整解码字符串，导致爆内存。
  • 把 1-based 的 k 当作 0-based，遗漏余数为 0 的含义。
  • 反向遇到数字时先除长度、后取模，映射到了错误层级。
  • JavaScript 使用普通 Number 保存接近 2⁶³ 的长度而丢失精度，应使用 BigInt。

class Solution {
    public String decodeAtIndex(String s, int k) {
        long size = 0;
        for (char ch : s.toCharArray()) {
            if (Character.isDigit(ch)) {
                size *= ch - '0';
            } else {
                size++;
            }
        }

        long target = k;
        for (int i = s.length() - 1; i >= 0; i--) {
            char ch = s.charAt(i);
            target %= size;
            if (!Character.isDigit(ch) && target == 0) {
                return String.valueOf(ch);
            }
            if (Character.isDigit(ch)) {
                size /= ch - '0';
            } else {
                size--;
            }
        }
        return "";
    }
}

var decodeAtIndex = function(s, k) {
    let size = 0n;
    for (const ch of s) {
        if (ch >= '2' && ch <= '9') {
            size *= BigInt(ch);
        } else {
            size += 1n;
        }
    }

    let target = BigInt(k);
    for (let i = s.length - 1; i >= 0; i--) {
        const ch = s[i];
        target %= size;
        if (!(ch >= '2' && ch <= '9') && target === 0n) {
            return ch;
        }
        if (ch >= '2' && ch <= '9') {
            size /= BigInt(ch);
        } else {
            size -= 1n;
        }
    }
    return '';
};
class Solution:
    def decodeAtIndex(self, s: str, k: int) -> str:
        size = 0
        for ch in s:
            if ch.isdigit():
                size *= int(ch)
            else:
                size += 1

        for ch in reversed(s):
            k %= size
            if ch.isalpha() and k == 0:
                return ch
            if ch.isdigit():
                size //= int(ch)
            else:
                size -= 1

        return ""
