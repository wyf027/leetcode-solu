检查数组是否经
排序和轮转得到

一个数组看似打乱，却可能只是把有序序列从某个位置“剪开”，再把前半段接到尾部。先观察环上的相邻关系，再决定它是否仍保留了有序结构。

英文：Check if Array Is Sorted and Rotated 允许重复元素 可轮转 0 次
Problem

题意

给定整数数组 nums。判断它能否由某个按非递减顺序排列、元素完全相同的源数组，轮转若干位置（包括 0 个位置）得到；可以则返回 true，否则返回 false。

若长度为 n 的数组 A 轮转 x 个位置得到 B，则每个有效下标 i 都满足：

B[i] = A[(i + x) mod n]

Contract

参数与约束

check(nums: integer[]): boolean

  • 1 ≤ nums.length ≤ 100
  • 1 ≤ nums[i] ≤ 100
  • 源数组按非递减顺序排列，因此相等元素合法。

官方示例

示例 1

输入：nums = [3,4,5,1,2]
输出：true
解释：[1,2,3,4,5] 轮转 x = 2
后可得到 [3,4,5,1,2]。

示例 2

输入：nums = [2,1,3,4]
输出：false
解释：不存在一个有序源数组，
经轮转后可得到 nums。

示例 3

输入：nums = [1,2,3]
输出：true
解释：源数组就是 [1,2,3]，
轮转 x = 0 即可。

Key Insight

只允许一个“下降断点”

把数组首尾相连，逐一检查 nums[i] > nums[(i+1) % n]。如果这样的逆序相邻对不超过 1 个，数组就能由非递减数组轮转得到。

dropCount ≤ 1 ⇔ 可以由有序数组轮转得到

完整过程

  1. 令逆序边计数 drops = 0。
  2. 遍历每个下标 i，将当前元素与环上的下一个元素比较；最后一个元素的下一项是第一个元素。
  3. 若当前值大于下一值，说明这里发生一次下降，计数加一。
  4. 一旦计数超过 1，可立即返回 false；遍历完成仍不超过 1，则返回 true。

正确性证明

必要性

非递减数组内部不存在下降。轮转相当于在源数组上剪一刀并交换两段，只有新数组末段最大值接向首段最小值的位置可能下降。因此，合法数组的环上下降边至多一条。

充分性

若没有下降边，数组本身已非递减，选择轮转 0 次即可。若恰有一条下降边，在该边之后切开环：从较小元素起依次读取，所有其余相邻关系均非递减，因此得到一个非递减源数组；再轮转回原起点即可得到 nums。故条件充分。

边界情况

  • 长度为 1：唯一的环边连接元素自身，答案为真。
  • 全部相等：不存在严格下降，答案为真。
  • 已经有序：末项到首项可能形成唯一下降，仍合法。
  • 重复元素：使用严格大于号判断下降，不能把相等误判为下降。

复杂度

只扫描一圈，时间复杂度 O(n)；只使用常数个变量，空间复杂度 O(1)。

替代方案

可以复制数组得到 nums + nums，再检查排序后的数组是否作为长度为 n 的连续片段出现；也可以枚举每个切点验证。它们更直观，但通常需要额外空间或达到 O(n²) 时间，不如直接数环形下降边。

常见错误

  • 只比较线性相邻项，漏掉末项到首项这条边。
  • 把 >= 当作下降条件，错误拒绝重复值。
  • 认为必须恰好有一个下降；实际零次轮转也合法。
  • 找到第二个下降后仍继续做无意义扫描。

面试追问

  • 如何返回一个可行的源数组和轮转量？记录唯一下降边后的下标作为有序起点即可。
  • 如果要求严格递增怎么办？除检查下降边外，还要拒绝任何相邻相等元素。
  • 若数据以流式方式到达？保存首项、前一项和下降次数，流结束后再补比较末项与首项。

JavaLeetCode 提交
class Solution {
    public boolean check(int[] nums) {
        int drops = 0;
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            if (nums[i] > nums[(i + 1) % n]) {
                drops++;
                if (drops > 1) return false;
            }
        }
        return true;
    }
}

from typing import List


class Solution:
    def check(self, nums: List[int]) -> bool:
        drops = 0
        n = len(nums)

        for i in range(n):
            if nums[i] > nums[(i + 1) % n]:
                drops += 1
                if drops > 1:
                    return False
        return True

class Solution {
public:
    bool check(vector<int>& nums) {
        int drops = 0;
        int n = nums.size();

        for (int i = 0; i < n; ++i) {
            if (nums[i] > nums[(i + 1) % n]) {
                if (++drops > 1) return false;
            }
        }
        return true;
    }
};
