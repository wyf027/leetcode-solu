截断句子

Truncate Sentence

保留句子的前 k 个单词。先想清楚：截断点应该落在哪里？

打开官方题目 ↗

01 / 题目与输入约定

给定字符串 s 和整数 k，返回只包含原句前 k 个单词的句子。保留单词原有大小写和顺序，单词之间仍用一个空格连接。

句子仅含大小写英文字母与空格；相邻单词之间恰好一个空格，没有前导或尾随空格，也没有标点。

  • 1 ≤ s.length ≤ 500
  • 1 ≤ k ≤ s 中单词的数量
  • 参数形式：truncateSentence(s: string, k: integer) → string

官方示例

示例 1
输入：s = "Hello how are you Contestant", k = 4
输出："Hello how are you"

前四个单词依次为 Hello、how、are、you。

示例 2
输入：s = "What is the solution to this problem", k = 4
输出："What is the solution"

仅保留 What、is、the、solution。

示例 3
输入：s = "chopper is not a tanuki", k = 5
输出："chopper is not a tanuki"

请求的单词数等于原句单词数，因此原样返回。

04 / 独立题解

完成思考后再展开，包含推导与四种语言实现。

核心洞察：空格就是单词边界

第一个空格结束第一个单词，第 k 个空格结束第 k 个单词。找到它时，取它前面的子串即可；这个空格本身不属于答案。若 k 等于单词总数，就不存在第 k 个空格，返回原句。

完整过程

  1. 设置空格计数 spaces = 0，从左向右扫描字符索引 i。
  2. 普通字母无需操作；遇到空格则计数加一。
  3. 当计数恰好等于 k，返回半开区间 s[0, i)。
  4. 直到字符串末尾都没有触发返回，则直接返回 s。

示例 1 的空格索引依次为 5、9、13、17；k = 4 时在索引 17 截断，答案为索引 0 到 16 的字符，即 “Hello how are you”。

正确性说明

循环不变式：处理索引 i 之前，spaces 恰好等于前缀 s[0, i) 中的空格数量。初始前缀为空，计数为零，成立；字母不改变计数，空格使计数增加一，因此不变式始终成立。由于单词之间恰好一个空格，第 k 次遇到空格时，其前缀必定包含恰好前 k 个完整单词，且末尾没有空格。若扫描完成仍未遇到第 k 个空格，设总词数为 m，则 m − 1 < k，而合法输入要求 k ≤ m，所以 k = m，返回整个 s 正确。

边界与复杂度

单个单词、k = 1、k 等于总词数均由同一逻辑处理。无需处理空串或非法 k，因为官方约束排除了这些输入；本页编辑器会拦截非法输入。

设 n 为句长、L 为返回字符串长度。扫描最坏 O(n)，生成结果需 O(L)，总时间 O(n)。扫描辅助空间 O(1)；计入返回字符串的存储通常为 O(L)。C++ 官方签名按值传入 s，还可能产生 O(n) 的参数副本；不应将包含输入副本与输出的总存储说成 O(1)。

四语言完整代码

Java

class Solution {
    public String truncateSentence(String s, int k) {
        int spaces = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == ' ') {
                spaces++;
                if (spaces == k) return s.substring(0, i);
            }
        }
        return s;
    }
}

JavaScript

/**
 * @param {string} s
 * @param {number} k
 * @return {string}
 */
var truncateSentence = function(s, k) {
    let spaces = 0;
    for (let i = 0; i < s.length; i++) {
        if (s[i] === ' ') {
            spaces++;
            if (spaces === k) return s.slice(0, i);
        }
    }
    return s;
};

Python 3

class Solution:
    def truncateSentence(self, s: str, k: int) -> str:
        spaces = 0
        for i, char in enumerate(s):
            if char == ' ':
                spaces += 1
                if spaces == k:
                    return s[:i]
        return s

C++

#include <string>
using namespace std;

class Solution {
public:
    string truncateSentence(string s, int k) {
        int spaces = 0;
        for (int i = 0; i < static_cast<int>(s.size()); i++) {
            if (s[i] == ' ') {
                spaces++;
                if (spaces == k) return s.substr(0, i);
            }
        }
        return s;
    }
};

替代方案

按空格 split，取前 k 项，再用单个空格 join。例如 JavaScript 的 s.split(' ').slice(0, k).join(' ')。表达直观，时间 O(n)，通常额外空间 O(n)，且会拆分未使用的后半句。扫描法可以在确定边界时提前停止。

常见错误

  • 遇到第 k − 1 个空格就返回：这会少保留一个词。
  • 取到 i + 1：把截断处的空格也放进结果，产生尾随空格。
  • 仅在空格处 return：忘记 k 等于总词数时返回原句。
  • 把 k 当作字符数量，或为了截断而改变大小写。

面试追问

  • 允许连续空白怎么办？必须按“进入单词/离开单词”的状态转换计数，并明确输出是否规范化空白。
  • 输入来自流怎么办？逐字符读取并记录单词边界，确定第 k 个单词结束后即可停止。
  • 能做到总空间 O(1) 吗？不可变字符串通常需要存放结果；C++ 可在明确生命周期的条件下返回 string_view，但这会改变官方返回接口。
