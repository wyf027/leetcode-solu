Strobogrammatic Number

把数字整体旋转 180 度后仍保持不变，称为中心对称数。两端数字必须形成允许的翻转对：0↔0、1↔1、8↔8、6↔9。用双指针从外向内核对即可。

题意与约束

题解 · 一张小映射表

核心洞察

旋转会同时改变顺序与字符。于是原串左端 num[left] 旋转后应当等于原串右端 num[right]。只要任意一对不在映射表中，立即失败；所有对通过则成功。

完整过程

  1. 建立映射：{0:0, 1:1, 8:8, 6:9, 9:6}。
  2. 令两个指针位于字符串两端。
  3. 检查 map[num[left]] == num[right]。
  4. 成功则双指针向内移动；失败直接返回 false。
  5. 两指针相遇或交错时，返回 true。

复杂度与边界

每个字符至多被读一次：时间 O(n)，映射表大小恒定，额外空间 O(1)。

  • 长度为 1：只有 0、1、8 为真。
  • 中间字符必须能自映射，6 或 9 不能单独处在中间。
  • 2、3、4、5、7 没有允许的旋转对应，出现即为假。

替代方案取舍

可构造反转并旋转后的完整字符串再比较，写法直观但需要 O(n) 额外空间。双指针更节省内存，也更直接地表达镜像配对。

常见错误：只检查左右字符相同（会错过 6↔9）；把 6 误映射到 6；忘了单字符中心只能为 0、1 或 8；或对数值而非字符串处理，导致失去位数信息。

面试追问

如何生成长度 n 的所有中心对称数？从中心向两侧递归添加允许对。如何处理前导零？外层不能使用 0↔0（除非 n=1）。若字母也可旋转？只需扩展映射表。

import java.util.Map;

class Solution {
    public boolean isStrobogrammatic(String num) {
        Map<Character, Character> map = Map.of('0','0','1','1','8','8','6','9','9','6');
        int left = 0, right = num.length() - 1;
        while (left <= right) {
            if (!map.containsKey(num.charAt(left)) || map.get(num.charAt(left)) != num.charAt(right)) return false;
            left++; right--;
        }
        return true;
    }
}

#include <string>
#include <unordered_map>
using namespace std;

class Solution {
public:
    bool isStrobogrammatic(string num) {
        unordered_map<char, char> pairs{{'0','0'}, {'1','1'}, {'8','8'}, {'6','9'}, {'9','6'}};
        int left = 0, right = (int)num.size() - 1;
        while (left <= right) {
            if (!pairs.count(num[left]) || pairs[num[left]] != num[right]) return false;
            ++left; --right;
        }
        return true;
    }
};
