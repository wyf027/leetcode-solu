网格中保持一致的最大列数

允许删除任意列、保持其余列相对顺序。留下的每对相邻列必须在每一行的绝对差都恰好为 limit；求最多能留下多少列。

观察对象

把“列”当作节点。列 a 能接到 b，当且仅当所有行都满足 |grid[r][b] - grid[r][a]| = limit。

推荐主线

列下标天然从左到右，合法连接构成 DAG；求最长路径就是最长可保留列序列。

题意、示例与约束

示例

grid = [[-2, 0, 3]]

limit = 2

输出：2。保留列 0, 1，唯一一行的差为 |0 - (-2)| = 2。

grid = [[1,-1,1],[2,2,2]], limit = 1，输出 2。

约束

1 ≤ m = grid.length ≤ 250

1 ≤ n = grid[i].length ≤ 250

0 ≤ limit ≤ 10⁹；元素为整数。至少保留一列，因此答案最小为 1。

题解（默认收起）

先动手观察边，再展开完整推导和四份代码。

核心洞察：如果保留列序列为 c₁ < c₂ < …，只需检查相邻对。于是每个合法列对是一条有向边，列编号从小到大保证无环，答案正是这张图的最长路径节点数。

完整过程

  1. 令 dp[j] 为以第 j 列结尾的最大保留数量，初始均为 1。
  2. 枚举所有 i < j，扫描每一行验证 abs(grid[r][j]-grid[r][i]) == limit。
  3. 若合法，更新 dp[j] = max(dp[j], dp[i] + 1)。
  4. 答案是全部 dp[j] 的最大值。

边界

仅一列、没有任何合法边、limit = 0、负数元素都无需特殊分支；差值比较始终取绝对值。

复杂度

共有 O(n²) 对列，每次检验 m 行：时间 O(m·n²)，DP 额外空间 O(n)。

替代方案、追问与常见错误

替代：可显式建图再做 DAG 最长路，但会多占 O(n²) 边空间。追问：若允许重排列，则不再是按下标的 DAG，需要按列向量关系建模。常见错误：只检查某一行；比较相邻原列而不是相邻保留列；误把条件写成 <= limit。
