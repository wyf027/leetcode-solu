合并两个二维数组
— 求和法

两份按编号排好的价值清单，要汇成一份没有重复编号的总表。先读题，再到调度台亲手推进每一步。

数组哈希表双指针

Problem Brief

任务说明

给定两个二维整数数组 nums1 和 nums2。每个元素均为 [id, value]，表示某个编号及其对应的值。每个输入数组内部的 id 互不相同，并且已经按 id 严格递增排列。

请将它们合并为一个数组：只保留至少在一个输入中出现过的编号；每个编号只出现一次，其值为两个数组中该编号对应值之和。若编号仅出现在一侧，另一侧的值按 0 计算。返回结果仍须按 id 递增排列。

函数mergeArrays(nums1, nums2)
参数两个 integer[][]
返回按 id 递增的 integer[][]

示例 1

输入 
nums1 = [[1,2],[2,3],[4,5]]
nums2 = [[1,4],[3,2],[4,1]]
输出 
[[1,6],[2,3],[3,2],[4,6]]

编号 1 和 4 在两侧都出现，分别相加为 6；编号 2、3 沿用各自已有的值。

示例 2

输入 
nums1 = [[2,4],[3,6],[5,5]]
nums2 = [[1,3],[4,3]]
输出 
[[1,3],[2,4],[3,6],[4,3],[5,5]]

两侧没有相同编号，因此每个编号和值都直接进入结果。

约束

  • 1 <= nums1.length, nums2.length <= 200
  • nums1[i].length == nums2[j].length == 2
  • 1 <= idᵢ, valᵢ <= 1000
  • 每个数组内的 id 互不相同。
  • 两个数组都按 id 严格递增排列。

Solution Notes

题解：让两个游标只向前走

核心洞察

两个数组已经按 id 排序。比较当前位置的编号，较小者不可能在另一数组的后续位置再次出现，可立即写入；编号相同则合并值。这样天然维持结果有序，无需额外排序。

完整过程

  1. 令 i = 0、j = 0，创建结果数组。
  2. 若两个当前 id 相等，写入 id 与两值之和，两个游标都前进。
  3. 否则写入 id 较小的一项，只推进对应游标。
  4. 某侧耗尽后，把另一侧剩余项依次写入。

正确性

循环不变式：每轮开始前，结果恰好包含两个游标之前出现过的全部 id，值均为两侧对应值之和，并且严格按 id 递增。

当前 id 相等时，合并后不会遗漏或重复；不等时，较小 id 小于另一侧当前及后续所有 id，可以安全写入。两种操作都保持不变式。循环结束时，未耗尽一侧的剩余 id 都大于已处理部分，依次追加仍然有序。故返回结果满足题意。

复杂度

时间O(n + m)每项访问一次
额外空间O(1)不计返回数组

其中 n、m 分别为两个输入数组长度；返回结果本身需要 O(n + m) 空间。

边界情况

  • 两侧 id 完全不相交。
  • 一侧所有 id 都小于另一侧。
  • 所有 id 一一对应，需要每次求和。
  • 某侧先耗尽，必须追加另一侧余项。
  • 输入长度为最小值 1。

替代方案

也可用哈希表按 id 累加，再对键排序，时间复杂度为 O(n + m + k log k)，额外空间为 O(k)。写法直观，但没有利用输入已排序这一条件；本题用双指针更省空间。

若输入不保证有序，哈希表方案更通用。

面试追问

  • 如果有很多个有序数组，如何用最小堆做多路归并？
  • 如果数据以流的形式到达，怎样边读边输出？
  • 如果单个数组内允许重复 id，应在哪里先聚合？
  • 输入无序时，哈希与排序该如何取舍？

常见错误

  • id 相等时只推进一个游标，导致重复处理。
  • 主循环结束后忘记追加未耗尽一侧。
  • 比较了 value 而不是 id。
  • 额外排序结果，掩盖了输入有序带来的优势。
  • 把额外空间误写为包含返回数组的 O(1)。

JavaLeetCode 可提交
class Solution {
    public int[][] mergeArrays(int[][] nums1, int[][] nums2) {
        int[][] merged = new int[nums1.length + nums2.length][2];
        int i = 0, j = 0, k = 0;

        while (i < nums1.length && j < nums2.length) {
            if (nums1[i][0] == nums2[j][0]) {
                merged[k++] = new int[]{nums1[i][0], nums1[i][1] + nums2[j][1]};
                i++;
                j++;
            } else if (nums1[i][0] < nums2[j][0]) {
                merged[k++] = nums1[i++];
            } else {
                merged[k++] = nums2[j++];
            }
        }
        while (i < nums1.length) merged[k++] = nums1[i++];
        while (j < nums2.length) merged[k++] = nums2[j++];

        return java.util.Arrays.copyOf(merged, k);
    }
}

/**
 * @param {number[][]} nums1
 * @param {number[][]} nums2
 * @return {number[][]}
 */
var mergeArrays = function(nums1, nums2) {
    const result = [];
    let i = 0, j = 0;

    while (i < nums1.length && j < nums2.length) {
        if (nums1[i][0] === nums2[j][0]) {
            result.push([nums1[i][0], nums1[i][1] + nums2[j][1]]);
            i++;
            j++;
        } else if (nums1[i][0] < nums2[j][0]) {
            result.push(nums1[i++]);
        } else {
            result.push(nums2[j++]);
        }
    }
    return result.concat(nums1.slice(i), nums2.slice(j));
};

class Solution:
    def mergeArrays(
        self, nums1: List[List[int]], nums2: List[List[int]]
    ) -> List[List[int]]:
        result = []
        i = j = 0

        while i < len(nums1) and j < len(nums2):
            if nums1[i][0] == nums2[j][0]:
                result.append([nums1[i][0], nums1[i][1] + nums2[j][1]])
                i += 1
                j += 1
            elif nums1[i][0] < nums2[j][0]:
                result.append(nums1[i])
                i += 1
            else:
                result.append(nums2[j])
                j += 1

        return result + nums1[i:] + nums2[j:]

class Solution {
public:
    vector<vector<int>> mergeArrays(
        vector<vector<int>>& nums1,
        vector<vector<int>>& nums2
    ) {
        vector<vector<int>> result;
        int i = 0, j = 0;

        while (i < nums1.size() && j < nums2.size()) {
            if (nums1[i][0] == nums2[j][0]) {
                result.push_back({nums1[i][0], nums1[i][1] + nums2[j][1]});
                i++;
                j++;
            } else if (nums1[i][0] < nums2[j][0]) {
                result.push_back(nums1[i++]);
            } else {
                result.push_back(nums2[j++]);
            }
        }
        while (i < nums1.size()) result.push_back(nums1[i++]);
        while (j < nums2.size()) result.push_back(nums2[j++]);
        return result;
    }
};
