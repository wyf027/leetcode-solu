统计网格路径中好整数的数目

把区间里的数补成 16 位，按行放进 4×4 网格；指定路径经过的 7 个数字非递减时，这个数就是“好整数”。重点不是枚举区间，而是只给路径位置加上相邻数字的约束。

题意

给定 l、r 与恰含 3 个 D、3 个 R 的 directions。从 (0, 0) 出发走 6 步（包含起点共 7 格）。统计 x ∈ [l, r] 中，路径数字序列非递减的个数。

示例：l = 123456789，r = 123456790，directions = "DDRRDR" 的答案是 1。

约束1 ≤ l ≤ r ≤ 9 × 1015
路径恰好经过 7 格
输出区间中好整数个数

路径播放器

第 0 步：起点 (0, 0)

路径数字：0, 0, 2, 3, 4, 8, 9

键盘：←/→ 逐步，空格切换自动播放。

测试与验证

快速生成模式：UI、算法对拍、四语言编译和交互验收待补

题解：路径位置上的数字 DP

核心洞察

16 个格子中只有 7 个会被路径读取。预先把这 7 个行主序下标标记为 pathPos；在扫描 16 位十进制表示时，普通位置可选 0 到 9，路径位置只能选不小于上一条路径数字的值。

完整过程

  1. 由 directions 算出 7 个路径下标：起点为 0，向下加 4，向右加 1。
  2. 定义 F(N) 为区间 [0, N] 的好整数数。
  3. 对 N 的 16 位补零字符串做 digit DP：状态为位置、是否贴着 N 的前缀、上一个路径数字（初始为 0）。
  4. 当当前位置属于路径时，枚举下界为上一个路径数字；其他位置下界为 0。
  5. 答案为 F(r) − F(l − 1)。

边界与复杂度

l = 1 时 F(0) 仍可计算；补零是数字的一部分，不能忽略。状态最多 16 × 2 × 10，每个枚举 10 位，时间 O(16 × 2 × 10 × 10)，空间 O(16 × 2 × 10)。

替代方案与常见错误

直接枚举最多可跨越 9×1015 个数，不可行。常见错误是忘记把路径外的 9 格仍计入 digit DP，或把前导零当作“不存在”而破坏路径比较。

面试追问

若网格或路径长度变大，状态仍只需记录最近一个受比较约束的数字；若关系换为严格递增，把下界改成 prev + 1。
