03 / 题解与实现

准备好后，再展开推导与四种语言代码。

核心洞察：从左往右，符号每次翻转

将 n 转成字符串即可保留从最高位到最低位的顺序。维护累计和 answer = 0 和符号 sign = 1；每读一位 d，加入 sign × d，再令 sign = −sign。不需要保存每位的贡献。

完整过程

  1. 得到十进制字符串，初始化累计和为 0、符号为 +1。
  2. 按字符从左到右遍历，将当前字符转换成整数。
  3. 把带符号的数字加到累计和，翻转符号，为下一位做准备。
  4. 所有字符处理完后返回累计和。

以 n = 521 为例：初始 0；读 5 得到 0 + 5 = 5；读 2 得到 5 − 2 = 3；读 1 得到 3 + 1 = 4。符号序列为 +、−、+。

正确性证明

循环不变量：处理前 k 位后，answer 等于这 k 位按题意赋予符号后的和，sign 等于第 k + 1 位应使用的符号 (−1)k。初始 k = 0，空前缀的和为 0，下一位符号为 +1，不变量成立。加入 sign × d 正好补上下一位的贡献，再翻转 sign，保持相邻符号相反，因此不变量成立。遍历结束时 k 等于总位数，answer 即所求。

边界与复杂度

单个数字直接得到自身；数字 0 的贡献虽为 0，仍占据一位且必须翻转符号。结果可能为负，例如 19 得到 −8。最大值 109 有 10 位。设位数为 D，时间 O(D)，字符串占 O(D) 额外空间，累计变量为 O(1)。等价地，时间和空间可写为 O(log n)，单个数字按常数处理。

替代方案：纯整数取位

从右侧用 n % 10 取位，先令最右位为正并交替累加，同时记录位数 D，最后若 D 为偶数就将结果取反。原因是从左向右的符号与从右向左的符号相差统一系数 (−1)D−1。这种方法时间 O(D)、额外空间 O(1)，但要小心偶数位时的整体符号修正。

常见错误

  • 从个位开始按正号累加，却忘记偶数位需要整体取反。
  • 跳过 0 时也跳过了符号翻转，后续所有位的符号都会错位。
  • 把结果取绝对值；题目允许负结果。
  • 将字符串版本空间复杂度写为 O(1)，忽略字符串的存储。

面试追问

  • 如何省去字符串？使用上述取余、整除与位数修正。
  • 输入是百万位十进制字符串怎么办？顺序读取，持续维护和与符号即可；数字流本身不必整体存储。
  • 与 11 的整除规则有什么联系？因为 10 ≡ −1 (mod 11)，交替数字和为 11 的倍数，当且仅当原数可被 11 整除。

四语言实现

以下均使用官方方法名及可提交类／函数形式；均待补验证。

Java

class Solution {
    public int alternateDigitSum(int n) {
        String digits = Integer.toString(n);
        int answer = 0, sign = 1;
        for (int i = 0; i < digits.length(); i++) {
            answer += sign * (digits.charAt(i) - '0');
            sign = -sign;
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number} n
 * @return {number}
 */
var alternateDigitSum = function(n) {
    let answer = 0, sign = 1;
    for (const digit of String(n)) {
        answer += sign * Number(digit);
        sign = -sign;
    }
    return answer;
};

Python 3

class Solution:
    def alternateDigitSum(self, n: int) -> int:
        answer, sign = 0, 1
        for digit in str(n):
            answer += sign * int(digit)
            sign = -sign
        return answer

C++

#include <string>

class Solution {
public:
    int alternateDigitSum(int n) {
        int answer = 0, sign = 1;
        for (char digit : std::to_string(n)) {
            answer += sign * (digit - '0');
            sign = -sign;
        }
        return answer;
    }
};
