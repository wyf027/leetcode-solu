LeetCode 1203 · Graph / Topological Sort

项目管理：让依赖顺序与小组连续同时成立

一条顺序要满足两种尺度的约束。先把“无组项目”变成独立小组，再分别对小组和项目拓扑排序，最后像装配车厢一样拼接答案。

HARD双层拓扑排序有向图Kahn 算法O(n + E)

题意

有 n 个项目与 m 个小组。group[i] 是项目 i 的小组编号；值为 -1 表示暂时不属于任何小组。beforeItems[i] 列出所有必须排在项目 i 之前的项目。

请返回任意一个项目排列，使每条先后依赖都满足，并且同一小组的所有项目在结果中形成连续区间。如果不可能，返回空数组。

真正的难点：普通项目拓扑序不保证同组相邻；只排小组又无法处理组内依赖。因此需要同时维护“项目图”和“小组图”。
函数签名sortItems(n, m, group, beforeItems) → integer[]
返回规则多解时任意合法排列；无解时 []

示例 1

输入
n = 8, m = 2, group = [-1,-1,1,0,0,1,0,-1], beforeItems = [[],[6],[5],[6],[3,6],[],[],[]]
输出
[6,3,4,1,5,2,0,7]
说明
这是一个合法答案：每个依赖项都在被依赖项左侧，组 0 的 [6,3,4] 与组 1 的 [5,2] 各自连续。

示例 2

输入
n = 8, m = 2, group = [-1,-1,1,0,0,1,0,-1], beforeItems = [[],[6],[5],[6],[3],[],[4],[]]
输出
[]
说明
与示例 1 基本相同，但现在项目 4 还必须位于项目 6 之前，约束无法同时满足。

约束

  • 1 ≤ m ≤ n ≤ 3 × 10⁴
  • group.length = beforeItems.length = n
  • -1 ≤ group[i] ≤ m - 1
  • 0 ≤ beforeItems[i].length ≤ n - 1
  • 0 ≤ beforeItems[i][j] ≤ n - 1，且 i ≠ beforeItems[i][j]
  • beforeItems[i] 内没有重复项目

题解：两张图、两次拓扑、一次装配

核心洞察：把每个无组项目视作只有一节车厢的独立列车。小组拓扑序决定“列车顺序”，项目拓扑序决定“每列车内部的车厢顺序”。

完整过程

  1. 标准化小组
    扫描 group。每遇到一个 -1，就分配一个从 m 开始递增的全新组号。最终组数最多为 m + n。
  2. 建立项目图
    对每条依赖 before → item，都添加项目边并更新项目入度；组内、跨组依赖全部保留。
  3. 建立小组图
    若依赖两端属于不同小组，添加 group(before) → group(item)；重复边可以保留，只要入度同步累计。
  4. 分别拓扑排序
    对组图与项目图运行 Kahn 算法。任一结果数量不足，说明存在环，立即返回空数组。
  5. 按组收集项目
    依次扫描项目拓扑序，把项目放进其所属小组的桶中。每个桶内部仍遵守项目依赖。
  6. 按组序拼接
    扫描小组拓扑序，依次追加对应桶。组块天然连续，跨组依赖也由小组拓扑序保证。

正确性证明

引理 1：每个小组在结果中连续。 最终答案按小组拓扑序逐桶追加，一个桶完成后才处理下一桶，因此同组项目恰好占据一个连续区间。
引理 2：所有组内依赖都满足。 项目桶保留项目拓扑序中的相对顺序；同组依赖边属于项目图，所以前驱一定先于后继进入同一桶。
引理 3：所有跨组依赖都满足。 每条跨组项目边都对应一条小组边。小组拓扑序令前驱所在组整体先于后继所在组，因此前驱项目必然更早。
定理。 若两次拓扑排序均成功，由引理 1–3，构造出的排列同时满足小组连续性与全部依赖；若任一图有环，对应约束不可能满足，返回空数组正确。

复杂度

时间 O(n + E)E 是 beforeItems 中依赖总数。建图、两次拓扑与装配均为线性。
空间 O(n + m + E)用于两张邻接表、入度、队列、分组桶与结果。

边界情况

  • 全部为 -1：每个项目都是独立小组，只需满足项目依赖。
  • 存在空小组：它可出现在组拓扑序中，但桶为空，拼接时没有影响。
  • 组内成环：项目拓扑排序失败；组图可能看不见这个环。
  • 组间成环：组拓扑排序失败；这表示连续组块无法安排。
  • 重复小组边：无需去重；添加边和入度严格配对即可。

替代方案

可以用 DFS 三色标记分别生成两张图的拓扑序，复杂度相同，但递归深度在 3 × 10⁴ 时要留意栈限制。也可以用集合对组边去重以减少重复边，但这不是正确性的必要条件。只对项目做一次拓扑排序后再强行把同组项目挪到一起，通常会破坏依赖。

面试追问

为什么跨组依赖仍要保留在项目图？
保留后，项目拓扑序本身是全局合法的；按该顺序放入各组桶时，每个桶的内部顺序自然正确。小组图负责组块先后，两张图承担不同层级的约束。
如果要求字典序最小怎么办？
把两次 Kahn 队列改为最小堆只能控制各自拓扑序的局部选择；还需要明确“组块字典序”的定义。不能只机械替换一个队列。
如何返回导致失败的环？
Kahn 结束后，入度仍大于 0 的节点落在环或受环影响的区域。可在该诱导子图上再做 DFS，记录递归栈与父指针，恢复一条具体环路径。

常见错误

  • 把所有 -1 项目分到同一个虚拟组，凭空要求它们连续。
  • 只建项目图，得到合法依赖序却不保证同组相邻。
  • 只建小组图，遗漏同组内部的依赖环。
  • 重复组边只增加一次入度，却在遍历时减少多次。
  • 项目桶按项目编号而不是项目拓扑序填充。

class Solution {
    public int[] sortItems(int n, int m, int[] group,
                           List<List<Integer>> beforeItems) {
        int groupCount = m;
        for (int i = 0; i < n; i++) {
            if (group[i] == -1) group[i] = groupCount++;
        }

        List<List<Integer>> itemGraph = new ArrayList<>();
        List<List<Integer>> groupGraph = new ArrayList<>();
        for (int i = 0; i < n; i++) itemGraph.add(new ArrayList<>());
        for (int i = 0; i < groupCount; i++) groupGraph.add(new ArrayList<>());
        int[] itemDegree = new int[n];
        int[] groupDegree = new int[groupCount];

        for (int item = 0; item < n; item++) {
            for (int before : beforeItems.get(item)) {
                itemGraph.get(before).add(item);
                itemDegree[item]++;
                int fromGroup = group[before], toGroup = group[item];
                if (fromGroup != toGroup) {
                    groupGraph.get(fromGroup).add(toGroup);
                    groupDegree[toGroup]++;
                }
            }
        }

        List<Integer> itemOrder = topo(itemGraph, itemDegree);
        List<Integer> groupOrder = topo(groupGraph, groupDegree);
        if (itemOrder.size() != n || groupOrder.size() != groupCount) {
            return new int[0];
        }

        List<List<Integer>> buckets = new ArrayList<>();
        for (int i = 0; i < groupCount; i++) buckets.add(new ArrayList<>());
        for (int item : itemOrder) buckets.get(group[item]).add(item);

        int[] answer = new int[n];
        int index = 0;
        for (int g : groupOrder) {
            for (int item : buckets.get(g)) answer[index++] = item;
        }
        return answer;
    }

    private List<Integer> topo(List<List<Integer>> graph, int[] degree) {
        ArrayDeque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < degree.length; i++) {
            if (degree[i] == 0) queue.offer(i);
        }
        List<Integer> order = new ArrayList<>();
        while (!queue.isEmpty()) {
            int node = queue.poll();
            order.add(node);
            for (int next : graph.get(node)) {
                if (--degree[next] == 0) queue.offer(next);
            }
        }
        return order;
    }
}

var sortItems = function(n, m, group, beforeItems) {
    let groupCount = m;
    for (let i = 0; i < n; i++) {
        if (group[i] === -1) group[i] = groupCount++;
    }

    const itemGraph = Array.from({ length: n }, () => []);
    const groupGraph = Array.from({ length: groupCount }, () => []);
    const itemDegree = new Array(n).fill(0);
    const groupDegree = new Array(groupCount).fill(0);

    for (let item = 0; item < n; item++) {
        for (const before of beforeItems[item]) {
            itemGraph[before].push(item);
            itemDegree[item]++;
            const fromGroup = group[before];
            const toGroup = group[item];
            if (fromGroup !== toGroup) {
                groupGraph[fromGroup].push(toGroup);
                groupDegree[toGroup]++;
            }
        }
    }

    const topo = (graph, degree) => {
        const queue = [];
        for (let i = 0; i < degree.length; i++) {
            if (degree[i] === 0) queue.push(i);
        }
        const order = [];
        let head = 0;
        while (head < queue.length) {
            const node = queue[head++];
            order.push(node);
            for (const next of graph[node]) {
                if (--degree[next] === 0) queue.push(next);
            }
        }
        return order;
    };

    const itemOrder = topo(itemGraph, itemDegree);
    const groupOrder = topo(groupGraph, groupDegree);
    if (itemOrder.length !== n || groupOrder.length !== groupCount) return [];

    const buckets = Array.from({ length: groupCount }, () => []);
    for (const item of itemOrder) buckets[group[item]].push(item);

    const answer = [];
    for (const g of groupOrder) answer.push(...buckets[g]);
    return answer;
};

from collections import deque
from typing import List


class Solution:
    def sortItems(
        self,
        n: int,
        m: int,
        group: List[int],
        beforeItems: List[List[int]],
    ) -> List[int]:
        group_count = m
        for item in range(n):
            if group[item] == -1:
                group[item] = group_count
                group_count += 1

        item_graph = [[] for _ in range(n)]
        group_graph = [[] for _ in range(group_count)]
        item_degree = [0] * n
        group_degree = [0] * group_count

        for item in range(n):
            for before in beforeItems[item]:
                item_graph[before].append(item)
                item_degree[item] += 1
                from_group = group[before]
                to_group = group[item]
                if from_group != to_group:
                    group_graph[from_group].append(to_group)
                    group_degree[to_group] += 1

        def topo(graph: List[List[int]], degree: List[int]) -> List[int]:
            queue = deque(i for i, value in enumerate(degree) if value == 0)
            order = []
            while queue:
                node = queue.popleft()
                order.append(node)
                for nxt in graph[node]:
                    degree[nxt] -= 1
                    if degree[nxt] == 0:
                        queue.append(nxt)
            return order

        item_order = topo(item_graph, item_degree)
        group_order = topo(group_graph, group_degree)
        if len(item_order) != n or len(group_order) != group_count:
            return []

        buckets = [[] for _ in range(group_count)]
        for item in item_order:
            buckets[group[item]].append(item)

        answer = []
        for current_group in group_order:
            answer.extend(buckets[current_group])
        return answer

class Solution {
public:
    vector<int> sortItems(int n, int m, vector<int>& group,
                          vector<vector<int>>& beforeItems) {
        int groupCount = m;
        for (int i = 0; i < n; ++i) {
            if (group[i] == -1) group[i] = groupCount++;
        }

        vector<vector<int>> itemGraph(n), groupGraph(groupCount);
        vector<int> itemDegree(n), groupDegree(groupCount);

        for (int item = 0; item < n; ++item) {
            for (int before : beforeItems[item]) {
                itemGraph[before].push_back(item);
                ++itemDegree[item];
                int fromGroup = group[before];
                int toGroup = group[item];
                if (fromGroup != toGroup) {
                    groupGraph[fromGroup].push_back(toGroup);
                    ++groupDegree[toGroup];
                }
            }
        }

        vector<int> itemOrder = topo(itemGraph, itemDegree);
        vector<int> groupOrder = topo(groupGraph, groupDegree);
        if ((int)itemOrder.size() != n ||
            (int)groupOrder.size() != groupCount) return {};

        vector<vector<int>> buckets(groupCount);
        for (int item : itemOrder) buckets[group[item]].push_back(item);

        vector<int> answer;
        answer.reserve(n);
        for (int currentGroup : groupOrder) {
            for (int item : buckets[currentGroup]) answer.push_back(item);
        }
        return answer;
    }

private:
    vector<int> topo(const vector<vector<int>>& graph,
                     vector<int> degree) {
        queue<int> q;
        for (int i = 0; i < (int)degree.size(); ++i) {
            if (degree[i] == 0) q.push(i);
        }
        vector<int> order;
        while (!q.empty()) {
            int node = q.front();
            q.pop();
            order.push_back(node);
            for (int next : graph[node]) {
                if (--degree[next] == 0) q.push(next);
            }
        }
        return order;
    }
};
