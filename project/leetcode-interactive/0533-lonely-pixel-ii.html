孤独像素 II

真正满足条件的黑像素，必须同时通过“行数量、列数量、同行一致性”三重审查。

ArrayHash TableMatrixfindBlackPixel(picture, target)

题目

给定只含 'W'（白）和 'B'（黑）的二维矩阵 picture，以及正整数 target = N。统计满足以下全部条件的黑像素 picture[r][c]：

  1. 第 r 行恰好有 N 个黑像素；
  2. 第 c 列恰好有 N 个黑像素；
  3. 第 c 列中每个黑像素所在的行，都与第 r 行完全相同。
返回：满足条件的黑像素总数，而不是合格行或合格列的数量。

约束与签名

  • picture 非空且各行等长；
  • 元素只会是 'W' 或 'B'；
  • 1 ≤ picture.length, picture[0].length ≤ 200；
  • 1 ≤ target ≤ 200。

官方元数据函数：findBlackPixel(character[][] picture, integer target) → integer。

官方参数形式示例

示例 1

输入：picture = [["W","B","W","B","B","W"],
                  ["W","B","W","B","B","W"],
                  ["W","B","W","B","B","W"],
                  ["W","W","B","W","B","W"]],
      target = 3
输出：6
解释：前三行相同且各有 3 个 B；下标 1、3 两列各贡献 3 个合格像素。

示例 2

输入：picture = [["W","W","B"],
                  ["W","W","B"],
                  ["W","W","B"]],
      target = 1
输出：3

完整题解

先自己推导，再展开核对。

核心洞察

把每一行序列化为模式。若某模式自身恰含 N 个 B，且在矩阵中恰好出现 N 次，再检查该模式为 B 的各列是否也恰含 N 个 B。每个通过的列贡献 N 个像素。

完整过程

  1. 一次扫描统计每列黑像素数。
  2. 编码每行并统计模式频次。
  3. 只处理“含 N 个 B 且出现 N 次”的模式。
  4. 对模式中每个 B 位置检查列计数；等于 N 就把答案加 N。

正确性

充分性：算法计入的列恰有 N 个 B，它们来自恰好 N 条相同行，且这些行各含 N 个 B，三个条件均满足。

必要性：任一合格像素所在列的 N 个 B 必须位于 N 条完全相同的行；该行模式含 N 个 B、出现 N 次，且该列计数为 N，算法必然计入。

边界

  • 无黑像素，或 target 超过行/列容量，结果为 0；
  • 模式出现次数多于 N 也不合格；
  • 列多一个额外 B，该列全部不合格；
  • 必须比较整行，不能只比较黑像素数量。

复杂度

R 行 C 列：时间 O(RC)，存储行模式的空间最坏 O(RC)，列计数另需 O(C)。

替代方案

可对每个候选像素逐行比较，但会重复工作。行哈希可减少字符串成本，却要处理碰撞；面试中以不可变字符串作键更直接。

面试追问

  • 若矩阵流式输入且无法回看，如何组织计数？
  • 怎样用无碰撞的行标识替代字符串？
  • 为何合格模式出现次数必定恰好为 N？

常见错误

  • 漏掉同行一致性；
  • 每个合格列只加 1 而不是 N；
  • 允许模式出现次数大于 N；
  • 把字符串内容相等误写成引用相等。

class Solution {
    public int findBlackPixel(char[][] picture, int target) {
        int cols = picture[0].length, answer = 0;
        int[] colBlack = new int[cols];
        java.util.Map<String, Integer> freq = new java.util.HashMap<>();
        for (char[] row : picture) {
            String pattern = new String(row);
            freq.put(pattern, freq.getOrDefault(pattern, 0) + 1);
            for (int c = 0; c < cols; c++) if (row[c] == 'B') colBlack[c]++;
        }
        for (var entry : freq.entrySet()) {
            String pattern = entry.getKey();
            if (entry.getValue() != target) continue;
            int black = 0;
            for (char ch : pattern.toCharArray()) if (ch == 'B') black++;
            if (black != target) continue;
            for (int c = 0; c < cols; c++)
                if (pattern.charAt(c) == 'B' && colBlack[c] == target) answer += target;
        }
        return answer;
    }
}
var findBlackPixel = function(picture, target) {
    const cols = picture[0].length, colBlack = Array(cols).fill(0);
    const freq = new Map();
    for (const row of picture) {
        const pattern = row.join('');
        freq.set(pattern, (freq.get(pattern) || 0) + 1);
        for (let c = 0; c < cols; c++) if (row[c] === 'B') colBlack[c]++;
    }
    let answer = 0;
    for (const [pattern, count] of freq) {
        if (count !== target || [...pattern].filter(ch => ch === 'B').length !== target) continue;
        for (let c = 0; c < cols; c++)
            if (pattern[c] === 'B' && colBlack[c] === target) answer += target;
    }
    return answer;
};
from collections import Counter
from typing import List

class Solution:
    def findBlackPixel(self, picture: List[List[str]], target: int) -> int:
        cols = len(picture[0])
        col_black = [0] * cols
        patterns = Counter()
        for row in picture:
            pattern = ''.join(row)
            patterns[pattern] += 1
            for c, pixel in enumerate(row):
                if pixel == 'B':
                    col_black[c] += 1
        answer = 0
        for pattern, count in patterns.items():
            if count != target or pattern.count('B') != target:
                continue
            for c, pixel in enumerate(pattern):
                if pixel == 'B' and col_black[c] == target:
                    answer += target
        return answer
