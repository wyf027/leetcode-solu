Navigation brief

题意与样例

给定按起点升序排列、互不重叠的区间列表 intervals，以及新区间 newInterval = [start, end]。插入新区间，必要时合并重叠部分，使结果仍然有序且互不重叠；无需原地修改输入。

Official sample 01

输入
intervals = [[1,3],[6,9]], newInterval = [2,5]
输出
[[1,5],[6,9]]

Official sample 02

输入
intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
输出
[[1,2],[3,10],[12,16]]

约束：0 ≤ intervals.length ≤ 10⁴；端点范围为 0…10⁵；原区间按起点升序且互不重叠；newInterval 恰有两个合法端点。

Core insight

有序且不重叠，天然把输入切成三段

先复制所有完全位于新区间左侧的区间；接着只要当前起点不大于新区间终点，就扩大新区间的左右端点；把扩大后的新区间加入结果，再复制剩余右侧区间。每个原区间只访问一次。

Full process

完整过程

  1. 1. 当 interval.end < newStart，原区间完全在左侧，直接加入结果。
  2. 2. 当 interval.start ≤ newEnd，两者重叠或相接，更新新区间两端。
  3. 3. 合并阶段结束后，只把最终新区间加入一次。
  4. 4. 将所有剩余右侧区间原样接回。

Boundaries

边界与不变量

  • 空列表会跳过两次扫描，只返回 [newInterval]。
  • 新区间在最前或最后时，不会发生合并。
  • 端点相接视为重叠，所以合并条件使用 ≤。
  • 新区间完全包含原区间，或被原区间包含，都由 min/max 统一处理。

Complexity

复杂度

时间 O(n)；除返回数组外额外空间 O(1)。返回结果本身需要 O(n) 空间。

Trade-offs

替代方案

把新区间加入数组后复用第 56 题排序合并，正确但需要 O(n log n)。二分只能快速找到插入点，最终移动与合并仍可能 O(n)，主线三段扫描更简洁。

Common mistakes

常见错误

左侧条件写成 ≤；合并后重复加入新区间；只扩终点不扩起点；直接修改调用方传入的 newInterval；空列表越界。

Interview follow-up

面试追问

为什么不需要排序？

原列表已经按起点有序且互不重叠，新区间只可能与一段连续区间重叠。

二分查找能把整体降到 O(log n) 吗？

不能；构造结果与移动元素最坏仍需 O(n)。

如何避免修改 newInterval？

复制起点和终点到局部变量，最终创建新数组放入结果。

若输入区间可能互相重叠？

先归并原列表，或将新区间一起排序后统一执行区间合并。

class Solution {
    public int[][] insert(int[][] intervals, int[] newInterval) {
        List<int[]> result = new ArrayList<>();
        int index = 0;
        int start = newInterval[0];
        int end = newInterval[1];

        while (index < intervals.length && intervals[index][1] < start) {
            result.add(intervals[index++]);
        }
        while (index < intervals.length && intervals[index][0] <= end) {
            start = Math.min(start, intervals[index][0]);
            end = Math.max(end, intervals[index][1]);
            index++;
        }
        result.add(new int[] {start, end});
        while (index < intervals.length) {
            result.add(intervals[index++]);
        }

        return result.toArray(new int[result.size()][]);
    }
}
