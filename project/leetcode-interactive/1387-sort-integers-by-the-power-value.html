Sort Integers by The Power Value

将整数按
权重排序

一串整数走上 Collatz 轨道：偶数折半，奇数变成三倍加一。谁先抵达 1，谁的权重更轻。

偶 x → x ÷ 2 奇 x → 3x + 1 序 (权重, 数值) 升序

Problem

题意

非付费题

整数 x 的权重，是按下面规则把它变成 1 所需的操作次数：

  • x 为偶数时，令 x = x / 2；
  • x 为奇数时，令 x = 3 * x + 1。

给定 lo、hi 和 k，将闭区间 [lo, hi] 内所有整数按权重升序排列；若权重相同，则按整数本身升序排列。返回排序后的第 k 个整数（k 从 1 开始）。题目保证区间内每个数都会到达 1，且权重可由 32 位有符号整数表示。

约束

  • 1 <= lo <= hi <= 1000
  • 1 <= k <= hi - lo + 1

权重示意

3 → 10 → 5 → 16 → 8 → 4 → 2 → 1
共走 7 步，所以 power(3) = 7。

示例 1

输入
lo = 12, hi = 15, k = 2
输出
13
解释
权重依次为 9, 9, 17, 17，按“权重优先、数值次之”排序得到 [12, 13, 14, 15]，第 2 个数是 13。

示例 2

输入
lo = 7, hi = 11, k = 4
输出
7
解释
权重为 [16, 3, 19, 6, 14]，排序得到 [8, 10, 11, 7, 9]，第 4 个数是 7。

Solution

准备好看完整题解了吗？

先用上面的轨道形成直觉。下方内容默认收起，包含算法、证明、复杂度与四种语言实现。

Memoization + Sorting

记忆化权重，再按二元键排序

核心洞察

每个整数的 Collatz 轨迹最终都会进入已经算过的后缀。设下一状态为 next(x)，则 power(x) = 1 + power(next(x))。缓存权重，就能复用公共后缀。

随后把每个整数映射成排序键 (power(x), x)。二元键的第二项自然完成“权重相同则数值小者优先”的规则。

完整过程

  1. 初始化缓存 power(1) = 0。
  2. 遍历 lo…hi，递归或迭代计算每个数的权重；遇到缓存值即停止向后展开。
  3. 把区间整数按 (权重, 整数值) 升序排序。
  4. 返回下标 k - 1 处的整数。

正确性证明

1
权重计算正确。
基例 power(1)=0 正确。对任意 x>1，算法执行题目规定的一次变换，再加上后继状态到 1 的步数，因此得到的正是 x 到 1 的总步数。缓存只保存已正确得到的值，不改变结果。
2
排序次序正确。
比较键先比较权重，因此权重小的整数一定靠前；权重相同时再比较整数值，因此数值小的整数靠前，恰好符合题意。
3
返回值正确。
排序后数组完全遵守目标顺序。题目中的第 k 个元素对应零基下标 k-1，故返回值正确。

复杂度与边界

令 n = hi - lo + 1，令 S 为本次计算中首次遇到的不同 Collatz 状态总数。记忆化求权重耗时 O(S)、缓存空间 O(S)；排序耗时 O(n log n)，数组空间 O(n)（不计具体排序实现的额外空间）。

  • lo = hi 时只能有 k = 1。
  • x = 1 的权重是 0，不能算成 1。
  • k 从 1 开始，数组下标从 0 开始。
  • 权重相同必须用整数值打破平局。

替代方案

直接模拟：对每个整数独立跑到 1，不缓存。写法简单但会重复计算大量公共后缀。

堆或快速选择：只需要第 k 个元素时，可围绕二元键做选择，理论上减少完整排序成本；但本题区间最多 1000 个数，完整排序更直观可靠。

预处理：若需要回答很多查询，可预先缓存更多整数的权重；不过 Collatz 轨迹可能跑出 [1,1000]，缓存键不能只按输入区间设计。

面试追问

  • 如果查询次数很多，怎样复用全局缓存？需要考虑什么并发问题？
  • 能否不用完整排序找到第 k 个元素？比较堆、快速选择的利弊。
  • 如果输入上界大幅提升，3x+1 是否可能溢出？该如何选择数值类型？
  • 递归深度受限的语言里，如何改写成迭代并回填路径？

常见错误

  • 只按权重排序，遗漏相同权重时按整数值升序。
  • 把变换后序列的节点数当成权重，导致结果多 1。
  • 返回 values[k]，造成一位偏移。
  • 只缓存区间内的数；事实上中间状态常常超出 [lo, hi]。
  • 比较器写成布尔值而非负数、零、正数，造成排序行为不稳定。

import java.util.*;

class Solution {
    private final Map<Integer, Integer> memo = new HashMap<>();

    public int getKth(int lo, int hi, int k) {
        memo.put(1, 0);
        List<Integer> values = new ArrayList<>();
        for (int value = lo; value <= hi; value++) {
            values.add(value);
        }

        values.sort((a, b) -> {
            int byPower = Integer.compare(power(a), power(b));
            return byPower != 0 ? byPower : Integer.compare(a, b);
        });
        return values.get(k - 1);
    }

    private int power(int x) {
        Integer cached = memo.get(x);
        if (cached != null) return cached;
        int next = (x % 2 == 0) ? x / 2 : 3 * x + 1;
        int result = 1 + power(next);
        memo.put(x, result);
        return result;
    }
}

 * @param {number} lo

var getKth = function(lo, hi, k) {
    const memo = new Map([[1, 0]]);

    function power(x) {
        if (memo.has(x)) return memo.get(x);
        const next = x % 2 === 0 ? x / 2 : 3 * x + 1;
        const result = 1 + power(next);
        memo.set(x, result);
        return result;
    }

    const values = [];
    for (let value = lo; value <= hi; value++) {
        values.push(value);
    }
    values.sort((a, b) => power(a) - power(b) || a - b);
    return values[k - 1];
};
class Solution:
    def getKth(self, lo: int, hi: int, k: int) -> int:
        memo = {1: 0}

        def power(x: int) -> int:
            if x not in memo:
                nxt = x // 2 if x % 2 == 0 else 3 * x + 1
                memo[x] = 1 + power(nxt)
            return memo[x]

        values = list(range(lo, hi + 1))
        values.sort(key=lambda value: (power(value), value))
        return values[k - 1]
class Solution {
private:
    unordered_map<int, int> memo{{1, 0}};

    int power(int x) {
        auto it = memo.find(x);
        if (it != memo.end()) return it->second;
        int next = (x % 2 == 0) ? x / 2 : 3 * x + 1;
        return memo[x] = 1 + power(next);
    }

public:
    int getKth(int lo, int hi, int k) {
        vector<int> values;
        for (int value = lo; value <= hi; ++value) {
            values.push_back(value);
        }
        sort(values.begin(), values.end(), [this](int a, int b) {
            int pa = power(a), pb = power(b);
            return pa == pb ? a < b : pa < pb;
        });
        return values[k - 1];
    }
};
