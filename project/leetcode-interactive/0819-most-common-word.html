最常见的

给定一段英文文本和一组禁用词，找出出现频率最高的非禁用词。比较时忽略大小写与标点，返回结果必须为小写。

01 / Prompt

题目说明

单词本身不包含标点符号；段落中的大小写不影响统计。题目保证最终答案存在且唯一。

官方示例

示例 1
输入：paragraph = "Bob hit a ball, the hit BALL flew far after it was hit.", banned = ["hit"] 输出："ball"

“hit” 虽出现 3 次，但属于禁用词；“ball” 忽略大小写后出现 2 次，是频率最高的合法词。

示例 2
输入：paragraph = "a.", banned = [] 输出："a"

句点不是单词的一部分；规范化后得到小写单词 “a”。

约束

  • 1 ≤ paragraph.length ≤ 1000
  • paragraph 仅含英文字母、空格及 !?',;.
  • 0 ≤ banned.length ≤ 100
  • 1 ≤ banned[i].length ≤ 10
  • banned[i] 仅含小写英文字母

04 / Solution

准备好看完整题解了吗？

先用观察器走几步，再展开核心洞察、正确性说明、复杂度与四种语言实现。

Solution unlocked

一次扫描 + 哈希计数

把禁用词放进集合；扫描段落得到小写单词，只对非禁用词计数，并在计数增长时维护当前最高频单词。

核心洞察

难点不是排序，而是可靠地划分单词、统一大小写并排除禁用词。答案唯一，因此只要维护严格更大的频次即可。

完整过程

  1. 将 banned 放入哈希集合。
  2. 逐字符提取连续英文字母，转为小写单词。
  3. 跳过禁用词，否则递增其哈希计数。
  4. 若新计数超过历史最大值，更新答案。

边界处理

  • 段落以字母结尾时，扫描末尾补一次“分隔符”逻辑。
  • 连续标点和空格都只负责结束当前单词。
  • banned 为空时，所有单词均可计数。
  • 同词不同大小写必须合并。

复杂度

时间 O(n + b)：扫描段落长度 n，并建立含 b 个禁用词的集合。
空间 O(u + b)：保存至多 u 个不同合法词及禁用集合。

正确性说明

  1. 提取正确：连续英文字母恰好构成一个单词，其他允许字符均为分隔符；转小写后，大小写不同的相同单词得到同一个键。
  2. 过滤正确：每个提取出的单词都先查询禁用集合，禁用词从不进入计数表，所有非禁用词恰好计数一次。
  3. 计数不变式：处理前 k 个单词后，计数表中每个键的值等于它在这 k 个词里出现的合法次数。处理下一个词只会正确跳过或让对应计数加一，因此不变式保持。
  4. 答案正确：每次计数增加后都与当前最大值比较，所以扫描结束时保存的是全体非禁用词中的最高频者；题目保证该词唯一，返回值即为答案。

替代方案

  • 正则提取 + Counter：代码短、表达清晰；仍是线性期望时间。
  • 全部计数后排序：可行但多出 O(u log u)，本题没有必要。
  • 替换标点再 split：直观，但要小心连续分隔符产生空串。

面试追问

  • 若输入是无法一次装入内存的字符流，如何跨块保留未结束单词？
  • 若最高频答案不唯一，应返回字典序最小者还是全部结果？
  • 若支持 Unicode 单词，字符分类与大小写折叠应如何调整？

常见错误

  • 只按空格切分，导致 ball, 与 ball 被视为不同词。
  • 忘记统一转小写，无法合并 Bob 与 bob。
  • 先找最高频再排除禁用词，得到错误候选。
  • 字符扫描结束后忘记提交最后一个单词。

实现提示

在 Java / C++ 中逐字符扫描可避免复杂的分隔正则；JavaScript / Python 用英文字母正则提取更简洁。四份代码遵循各自官方函数签名。

四种语言完整代码

import java.util.Arrays;
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution {
    public String mostCommonWord(String paragraph, String[] banned) {
        Set<String> bannedSet = new HashSet<>(Arrays.asList(banned));
        Map<String, Integer> counts = new HashMap<>();
        StringBuilder word = new StringBuilder();
        String answer = "";
        int best = 0;

        for (int i = 0; i <= paragraph.length(); i++) {
            if (i < paragraph.length()
                    && Character.isLetter(paragraph.charAt(i))) {
                word.append(Character.toLowerCase(paragraph.charAt(i)));
            } else if (word.length() > 0) {
                String current = word.toString();
                word.setLength(0);
                if (bannedSet.contains(current)) {
                    continue;
                }
                int frequency = counts.getOrDefault(current, 0) + 1;
                counts.put(current, frequency);
                if (frequency > best) {
                    best = frequency;
                    answer = current;
                }
            }
        }
        return answer;
    }
}
/**
 * @param {string} paragraph
 * @param {string[]} banned
 * @return {string}
 */
var mostCommonWord = function(paragraph, banned) {
    const bannedSet = new Set(banned);
    const words = paragraph.toLowerCase().match(/[a-z]+/g) || [];
    const counts = new Map();
    let answer = "";
    let best = 0;

    for (const word of words) {
        if (bannedSet.has(word)) continue;
        const frequency = (counts.get(word) || 0) + 1;
        counts.set(word, frequency);
        if (frequency > best) {
            best = frequency;
            answer = word;
        }
    }
    return answer;
};
import re
from collections import Counter
from typing import List


class Solution:
    def mostCommonWord(self, paragraph: str, banned: List[str]) -> str:
        banned_set = set(banned)
        words = re.findall(r"[a-z]+", paragraph.lower())
        counts = Counter(word for word in words if word not in banned_set)
        return counts.most_common(1)[0][0]
class Solution {
public:
    string mostCommonWord(string paragraph, vector<string>& banned) {
        unordered_set<string> bannedSet(banned.begin(), banned.end());
        unordered_map<string, int> counts;
        string word;
        string answer;
        int best = 0;

        for (size_t i = 0; i <= paragraph.size(); ++i) {
            if (i < paragraph.size()
                    && isalpha(static_cast<unsigned char>(paragraph[i]))) {
                word.push_back(static_cast<char>(
                    tolower(static_cast<unsigned char>(paragraph[i]))
                ));
            } else if (!word.empty()) {
                if (!bannedSet.count(word)) {
                    int frequency = ++counts[word];
                    if (frequency > best) {
                        best = frequency;
                        answer = word;
                    }
                }
                word.clear();
            }
        }
        return answer;
    }
};
