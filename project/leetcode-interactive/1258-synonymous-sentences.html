近义词句子Synonymous Sentences

一组词语彼此呼应，一句话便拥有许多种说法。你的任务，是找全这些表达，并让它们井然有序。

阅读题目 先做交互演练

一个小线索

近义关系可能跨越不止一对词。

happyjoy
joycheerful

先想一想：句子中的 happy 一共有多少种选择？

Problem

题目

给定近义词对数组 synonyms 和句子 text。每一对词可以相互替换，且这种关系具有传递性。请替换句子中可替换的每个单词，生成所有可能句子，并按字典序返回；没有近义词的词保持不变。

函数参数

generateSentences(synonyms, text) synonyms: List<List<String>> text: String 返回: List<String>

关键规则

  • 同一连通关系中的词都可相互替换。
  • 一个词也可以保留为它自己。
  • 最终结果必须按字典序排列。

官方示例 1

输入： synonyms = [["happy","joy"],["sad","sorrow"],["joy","cheerful"]] text = "I am happy today but was sad yesterday" 输出： ["I am cheerful today but was sad yesterday", "I am cheerful today but was sorrow yesterday", "I am happy today but was sad yesterday", "I am happy today but was sorrow yesterday", "I am joy today but was sad yesterday", "I am joy today but was sorrow yesterday"]

官方示例 2

输入： synonyms = [["happy","joy"],["cheerful","glad"]] text = "I am happy today but was sad yesterday" 输出： ["I am happy today but was sad yesterday", "I am joy today but was sad yesterday"]

约束

  • 0 <= synonyms.length <= 10
  • synonyms[i].length == 2
  • 1 <= synonyms[i][0].length, synonyms[i][1].length <= 10
  • synonyms[i][0] != synonyms[i][1]
  • 所有近义词对互不重复，单词仅由英文字母组成。
  • text 最多包含 10 个单词，单词之间恰由一个空格分隔。

Solution

并查集合并关系，回溯枚举句子

近义词对不是彼此孤立的：先把它们合并成连通分量，再把句子每个位置的候选词做一次有序笛卡尔积。

完整过程

建立并查集

把每个出现在近义词对中的单词加入集合。对每一对词执行合并，使直接或间接相连的词拥有同一个根。

收集并排序分组

遍历全部近义词，以根为键收集各连通分量；每组按字典序排序。再让组内每个词都指向同一候选数组。

切分原句

按单个空格得到单词序列。若某个词属于近义词组，该位置可选择整组单词；否则只有原词一个选择。

深度优先枚举

从左到右为每个位置选择一个候选词，走到末尾时拼接为句子。因为每组候选已排序，DFS 自然产生字典序结果。

正确性证明

01 · 分组正确

同组当且仅当可替换

并查集对每个给定词对执行合并。由连通性的传递闭包，同一连通分量恰好包含所有直接或间接近义词。

02 · 枚举完备且唯一

每个组合恰好一次

DFS 在每个句子位置遍历所有合法候选。每条根到叶路径对应唯一选择序列，所有选择序列也都对应一条路径。

03 · 顺序正确

输出保持字典序

各位置候选按字典序访问；DFS 总会先穷尽较小前缀，再进入较大前缀，因此叶子句子整体按字典序生成。

复杂度

记号：P 为近义词对数，U 为不同近义词数，W 为句子单词数，K 为最终句子数。

时间：O(P α(U) + U log U + K·W)。前两项来自合并与组内排序，最后一项是输出本身不可避免的成本。

空间：O(U + W) 辅助空间（不计必须返回的 O(K·W) 输出）；递归深度为 W。

边界情况

  • 近义词表为空：只返回原句。
  • 句子中没有词出现在近义词表：只返回原句。
  • 多个近义词对形成长链或环：并查集会归入同一组。
  • 同一个可替换词在句中多次出现：每个位置独立选择。

替代方案

也可以把近义词建成无向图，用 DFS/BFS 求连通分量，再做同样的句子回溯。数据很小时同样清晰；并查集更贴合“持续合并等价关系”，也便于处理流式加入的词对。

class Solution {
    private final Map<String, String> parent = new HashMap<>();
    private final Map<String, Integer> rank = new HashMap<>();

    public List<String> generateSentences(List<List<String>> synonyms, String text) {
        for (List<String> pair : synonyms) {
            add(pair.get(0));
            add(pair.get(1));
            union(pair.get(0), pair.get(1));
        }

        Map<String, List<String>> groups = new HashMap<>();
        for (String word : parent.keySet()) {
            groups.computeIfAbsent(find(word), key -> new ArrayList<>()).add(word);
        }

        Map<String, List<String>> choices = new HashMap<>();
        for (List<String> group : groups.values()) {
            Collections.sort(group);
            for (String word : group) choices.put(word, group);
        }

        String[] words = text.split(" ");
        List<String> answer = new ArrayList<>();
        dfs(words, 0, choices, new ArrayList<>(), answer);
        return answer;
    }

    private void add(String word) {
        parent.putIfAbsent(word, word);
        rank.putIfAbsent(word, 0);
    }

    private String find(String word) {
        if (!parent.get(word).equals(word)) {
            parent.put(word, find(parent.get(word)));
        }
        return parent.get(word);
    }

    private void union(String a, String b) {
        String rootA = find(a), rootB = find(b);
        if (rootA.equals(rootB)) return;
        int rankA = rank.get(rootA), rankB = rank.get(rootB);
        if (rankA < rankB) parent.put(rootA, rootB);
        else if (rankA > rankB) parent.put(rootB, rootA);
        else {
            parent.put(rootB, rootA);
            rank.put(rootA, rankA + 1);
        }
    }

    private void dfs(String[] words, int index,
                     Map<String, List<String>> choices,
                     List<String> path, List<String> answer) {
        if (index == words.length) {
            answer.add(String.join(" ", path));
            return;
        }
        List<String> options = choices.getOrDefault(
            words[index], Collections.singletonList(words[index])
        );
        for (String option : options) {
            path.add(option);
            dfs(words, index + 1, choices, path, answer);
            path.remove(path.size() - 1);
        }
    }
}

/**
 * @param {string[][]} synonyms
 * @param {string} text
 * @return {string[]}
 */
var generateSentences = function(synonyms, text) {
    const parent = new Map();
    const rank = new Map();

    const add = (word) => {
        if (!parent.has(word)) {
            parent.set(word, word);
            rank.set(word, 0);
        }
    };

    const find = (word) => {
        if (parent.get(word) !== word) {
            parent.set(word, find(parent.get(word)));
        }
        return parent.get(word);
    };

    const union = (a, b) => {
        let rootA = find(a);
        let rootB = find(b);
        if (rootA === rootB) return;
        if (rank.get(rootA) < rank.get(rootB)) [rootA, rootB] = [rootB, rootA];
        parent.set(rootB, rootA);
        if (rank.get(rootA) === rank.get(rootB)) {
            rank.set(rootA, rank.get(rootA) + 1);
        }
    };

    for (const [a, b] of synonyms) {
        add(a);
        add(b);
        union(a, b);
    }

    const groups = new Map();
    for (const word of parent.keys()) {
        const root = find(word);
        if (!groups.has(root)) groups.set(root, []);
        groups.get(root).push(word);
    }

    const choices = new Map();
    for (const group of groups.values()) {
        group.sort();
        for (const word of group) choices.set(word, group);
    }

    const words = text.split(" ");
    const answer = [];
    const path = [];

    const dfs = (index) => {
        if (index === words.length) {
            answer.push(path.join(" "));
            return;
        }
        const options = choices.get(words[index]) || [words[index]];
        for (const option of options) {
            path.push(option);
            dfs(index + 1);
            path.pop();
        }
    };

    dfs(0);
    return answer;
};
Python 
from collections import defaultdict
from typing import List


class Solution:
    def generateSentences(
        self, synonyms: List[List[str]], text: str
    ) -> List[str]:
        parent = {}
        rank = {}

        def add(word: str) -> None:
            if word not in parent:
                parent[word] = word
                rank[word] = 0

        def find(word: str) -> str:
            if parent[word] != word:
                parent[word] = find(parent[word])
            return parent[word]

        def union(a: str, b: str) -> None:
            root_a, root_b = find(a), find(b)
            if root_a == root_b:
                return
            if rank[root_a] < rank[root_b]:
                root_a, root_b = root_b, root_a
            parent[root_b] = root_a
            if rank[root_a] == rank[root_b]:
                rank[root_a] += 1

        for a, b in synonyms:
            add(a)
            add(b)
            union(a, b)

        groups = defaultdict(list)
        for word in parent:
            groups[find(word)].append(word)

        choices = {}
        for group in groups.values():
            group.sort()
            for word in group:
                choices[word] = group

        words = text.split(" ")
        answer, path = [], []

        def dfs(index: int) -> None:
            if index == len(words):
                answer.append(" ".join(path))
                return
            for option in choices.get(words[index], [words[index]]):
                path.append(option)
                dfs(index + 1)
                path.pop()

        dfs(0)
        return answer
C++ 
class Solution {
    unordered_map<string, string> parent;
    unordered_map<string, int> rankValue;

    void add(const string& word) {
        if (!parent.count(word)) {
            parent[word] = word;
            rankValue[word] = 0;
        }
    }

    string find(const string& word) {
        if (parent[word] != word) parent[word] = find(parent[word]);
        return parent[word];
    }

    void unite(const string& a, const string& b) {
        string rootA = find(a), rootB = find(b);
        if (rootA == rootB) return;
        if (rankValue[rootA] < rankValue[rootB]) swap(rootA, rootB);
        parent[rootB] = rootA;
        if (rankValue[rootA] == rankValue[rootB]) ++rankValue[rootA];
    }

    void dfs(const vector<string>& words, int index,
             const unordered_map<string, vector<string>>& choices,
             vector<string>& path, vector<string>& answer) {
        if (index == static_cast<int>(words.size())) {
            string sentence;
            for (int i = 0; i < static_cast<int>(path.size()); ++i) {
                if (i) sentence += ' ';
                sentence += path[i];
            }
            answer.push_back(sentence);
            return;
        }

        auto it = choices.find(words[index]);
        if (it == choices.end()) {
            path.push_back(words[index]);
            dfs(words, index + 1, choices, path, answer);
            path.pop_back();
            return;
        }
        for (const string& option : it->second) {
            path.push_back(option);
            dfs(words, index + 1, choices, path, answer);
            path.pop_back();
        }
    }

public:
    vector<string> generateSentences(vector<vector<string>>& synonyms,
                                     string text) {
        for (const auto& pair : synonyms) {
            add(pair[0]);
            add(pair[1]);
            unite(pair[0], pair[1]);
        }

        unordered_map<string, vector<string>> groups;
        for (const auto& [word, ignored] : parent) {
            groups[find(word)].push_back(word);
        }

        unordered_map<string, vector<string>> choices;
        for (auto& [root, group] : groups) {
            sort(group.begin(), group.end());
            for (const string& word : group) choices[word] = group;
        }

        vector<string> words;
        string word;
        stringstream stream(text);
        while (stream >> word) words.push_back(word);

        vector<string> answer, path;
        dfs(words, 0, choices, path, answer);
        return answer;
    }
};

常见错误

只看直接词对

漏掉 happy → joy → cheerful 这类传递关系。必须先求完整连通分量。

候选组未排序

组合虽然齐全，返回顺序却不符合要求。应在回溯前排序，或最后整体排序。

回溯忘记撤销

递归返回后不弹出刚加入的词，会让后续分支混入旧路径。

面试追问

如果近义词对持续在线加入？

并查集很适合增量合并；若需要立即查询组内所有词，还要维护根到成员集合的映射。

如果结果数量巨大？

改为迭代器或生成器逐条产出，并允许分页/上限；任何算法都无法绕过完整输出本身的规模。

为什么有序 DFS 能保证整体字典序？

比较两个不同结果时，顺序由第一个不同位置决定；DFS 正是按该位置候选从小到大穷尽前缀。

图搜索与并查集怎样选择？

只需一次静态分组时二者皆可；频繁增加等价边并查询连通性时，并查集通常更直接。
