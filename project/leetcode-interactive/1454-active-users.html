题意转述

先定义“连续”，再处理重复登录

给定账号表 Accounts 与登录记录表 Logins。若某个账号在至少 5 个连续的自然日里每天都登录过，则称它为活跃用户。请返回这些用户的 id 和 name，结果按 id 升序排列。

同一用户同一天可以出现多条登录记录，但判断连续天数时这一天只能算一次。

04 / SOLUTION

题解：日期减序号分组

核心洞察

对每个用户的不同登录日期排序并编号。若一段日期严格连续，那么“日期减去它的行号”会得到同一个锚点日期，于是同一连续段自然落入同一组。

group_key = login_date − ROW_NUMBER() 天

例如 05-30、05-31、06-01 分别减去 1、2、3 天，都会得到 05-29。只要按用户和这个锚点分组并计数，就能找出长度至少为 5 的连续段。

完整过程

  1. 对 Logins(id, login_date) 做 DISTINCT，消除同日重复登录。
  2. 按用户分区、日期升序，用 ROW_NUMBER() 编号。
  3. 计算日期减序号得到连续段锚点。
  4. 按 id + anchor_date 分组，保留计数不少于 5 的组。
  5. 取唯一用户 id，与 Accounts 连接得到姓名，最后按 id 排序。

正确性说明

引理 1：同一用户任意一段连续登录日期在减去递增行号后具有相同锚点。相邻日期与相邻行号都增加 1 天，差值保持不变。

引理 2：同一用户中，具有相同锚点的不同日期必定连续。设排序后两个相邻记录的日期间隔大于 1 天，则日期增量大于行号增量，二者差值必然改变。

结论：按用户和锚点形成的每个组恰好对应一段最大连续登录日期。筛选组大小 ≥ 5，得到且仅得到至少连续登录 5 天的用户；连接账号表后输出的正是题目所求。

边界情况

  • 同一用户同一天登录多次：必须先去重。
  • 恰好连续 5 天：应被选中。
  • 连续超过 5 天：整段仍只让用户出现一次。
  • 多段连续区间都达标：最终仍只返回一个用户。
  • 跨月、跨年：使用日期运算，不依赖日号差值。
  • 空登录表或没有达标用户：返回空结果集。

复杂度

设去重后的登录记录数为 N。窗口函数排序通常需要 O(N log N) 时间；后续分组和连接通常为 O(N)。中间结果占 O(N) 空间。实际执行代价还受数据库索引与优化器影响，推荐为 Logins(id, login_date) 建联合索引。

替代方案

可以用自连接把某日与之后 1～4 天连接，但连接层数固定、可读性差且容易被重复行放大。MySQL 8+ 下，窗口函数的“gaps and islands”写法更清晰、可扩展。

WITH distinct_logins AS (
  SELECT DISTINCT id, login_date
  FROM Logins
),
numbered AS (
  SELECT
    id,
    login_date,
    ROW_NUMBER() OVER (
      PARTITION BY id
      ORDER BY login_date
    ) AS rn
  FROM distinct_logins
),
streaks AS (
  SELECT
    id,
    DATE_SUB(login_date, INTERVAL rn DAY) AS anchor_date
  FROM numbered
),
active_ids AS (
  SELECT id
  FROM streaks
  GROUP BY id, anchor_date
  HAVING COUNT(*) >= 5
)
SELECT DISTINCT a.id, a.name
FROM Accounts AS a
JOIN active_ids AS x ON x.id = a.id
ORDER BY a.id;

本地语义参考：输入内存对象，返回按 id 升序的活跃用户。

import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.*;

public class ActiveUsers {
  record Account(int id, String name) {}
  record Login(int id, LocalDate date) {}

  public static List<Account> activeUsers(
      List<Account> accounts, List<Login> logins) {
    Map<Integer, TreeSet<LocalDate>> dates = new HashMap<>();
    for (Login login : logins) {
      dates.computeIfAbsent(login.id(), k -> new TreeSet<>())
          .add(login.date());
    }

    Set<Integer> active = new HashSet<>();
    for (var entry : dates.entrySet()) {
      LocalDate previous = null;
      int streak = 0;
      for (LocalDate current : entry.getValue()) {
        streak = previous != null
            && ChronoUnit.DAYS.between(previous, current) == 1
            ? streak + 1 : 1;
        if (streak >= 5) active.add(entry.getKey());
        previous = current;
      }
    }

    return accounts.stream()
        .filter(account -> active.contains(account.id()))
        .sorted(Comparator.comparingInt(Account::id))
        .toList();
  }
}

本地语义参考：日期按 UTC 天序号比较，避免夏令时造成误差。

function activeUsers(accounts, logins) {
  const datesById = new Map();
  for (const { id, login_date } of logins) {
    if (!datesById.has(id)) datesById.set(id, new Set());
    datesById.get(id).add(login_date);
  }

  const toDay = (date) => {
    const [year, month, day] = date.split("-").map(Number);
    return Math.floor(Date.UTC(year, month - 1, day) / 86400000);
  };

  const activeIds = new Set();
  for (const [id, uniqueDates] of datesById) {
    const days = [...uniqueDates].map(toDay).sort((a, b) => a - b);
    let streak = 0;
    for (let i = 0; i < days.length; i += 1) {
      streak = i > 0 && days[i] === days[i - 1] + 1 ? streak + 1 : 1;
      if (streak >= 5) activeIds.add(id);
    }
  }

  return accounts
    .filter(({ id }) => activeIds.has(id))
    .sort((a, b) => a.id - b.id);
}

from collections import defaultdict
from datetime import date

def active_users(accounts: list[dict], logins: list[dict]) -> list[dict]:
    dates_by_id: dict[int, set[date]] = defaultdict(set)
    for login in logins:
        dates_by_id[login["id"]].add(date.fromisoformat(login["login_date"]))

    active_ids: set[int] = set()
    for user_id, unique_dates in dates_by_id.items():
        previous = None
        streak = 0
        for current in sorted(unique_dates):
            streak = streak + 1 if previous and (current - previous).days == 1 else 1
            if streak >= 5:
                active_ids.add(user_id)
            previous = current

    return sorted(
        ({"id": row["id"], "name": row["name"]} for row in accounts
         if row["id"] in active_ids),
        key=lambda row: row["id"],
    )

本地语义参考：使用 C++20 chrono 将 ISO 日期转换为天序号。

#include <algorithm>
#include <chrono>
#include <map>
#include <set>
#include <string>
#include <vector>

struct Account { int id; std::string name; };
struct Login { int id; std::string loginDate; };

static long long toDay(const std::string& value) {
  int y = std::stoi(value.substr(0, 4));
  unsigned m = std::stoi(value.substr(5, 2));
  unsigned d = std::stoi(value.substr(8, 2));
  return std::chrono::sys_days{
      std::chrono::year{y} / std::chrono::month{m} / std::chrono::day{d}
  }.time_since_epoch().count();
}

std::vector<Account> activeUsers(
    const std::vector<Account>& accounts,
    const std::vector<Login>& logins) {
  std::map<int, std::set<long long>> datesById;
  for (const auto& login : logins) {
    datesById[login.id].insert(toDay(login.loginDate));
  }

  std::set<int> activeIds;
  for (const auto& [id, days] : datesById) {
    long long previous = 0;
    int streak = 0;
    bool first = true;
    for (long long current : days) {
      streak = !first && current == previous + 1 ? streak + 1 : 1;
      if (streak >= 5) activeIds.insert(id);
      previous = current;
      first = false;
    }
  }

  std::vector<Account> answer;
  for (const auto& account : accounts) {
    if (activeIds.contains(account.id)) answer.push_back(account);
  }
  std::sort(answer.begin(), answer.end(),
            [](const Account& a, const Account& b) {
              return a.id < b.id;
            });
  return answer;
}

常见错误

  • 忘记去重，重复登录把连续段长度虚增。
  • 直接用 MAX(date)-MIN(date)，忽略中间缺失日期。
  • 只比较日号，跨月时得到错误结果。
  • 用 RANK() 处理未去重数据，形成不可控间隙。
  • 一个用户有多段达标区间时，没有在最终输出去重。
