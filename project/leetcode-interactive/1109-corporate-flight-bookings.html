1109. 航班预订统计

Corporate Flight Bookings
中等 · MEDIUM

题目

共有 n 个航班，编号为 1 到 n。每条预订 bookings[i] = [firstᵢ, lastᵢ, seatsᵢ] 表示：从 firstᵢ 到 lastᵢ（两端都包含）的每个航班都增加 seatsᵢ 个预订座位。

返回长度为 n 的数组 answer，其中 answer[i] 是编号 i + 1 的航班预订座位总数。

示例 1

输入：bookings = [[1,2,10],[2,3,20],[2,5,25]], n = 5
输出：[10,55,45,25,25]
解释：
航班编号        1   2   3   4   5
预订记录 1      10  10
预订记录 2          20  20
预订记录 3          25  25  25  25
总座位数        10  55  45  25  25

示例 2

输入：bookings = [[1,2,10],[2,2,15]], n = 2
输出：[10,25]
解释：第 1 次为航班 1、2 各加 10；第 2 次只为航班 2 加 15。

约束

  • 1 ≤ n ≤ 2 × 10⁴
  • 1 ≤ bookings.length ≤ 2 × 10⁴
  • bookings[i].length == 3
  • 1 ≤ firstᵢ ≤ lastᵢ ≤ n
  • 1 ≤ seatsᵢ ≤ 10⁴

阅读建议

先操作实验台，尝试解释为什么区间末尾的下一格要做相反变化。题解默认收起，避免首屏直接泄露答案。

题解：差分数组 + 前缀和

核心洞察：区间 [first, last] 每项加 seats，不必逐项修改；只记录“从 first 开始加 seats”和“从 last + 1 开始撤销 seats”。最后一次前缀累加即可恢复每个航班的总数。

完整过程

  1. 建立长度为 n 的差分数组 diff，初始全为 0。
  2. 对每条 [first, last, seats]：令 diff[first - 1] += seats；若 last < n，令 diff[last] -= seats。
  3. 从左到右计算前缀和：diff[i] += diff[i - 1]。此时 diff 就是答案。

正确性说明

对任意一条预订，正增量从索引 first - 1 进入前缀和，因此影响编号不小于 first 的航班。

负增量从索引 last 进入，恰好在编号 last + 1 起抵消前述增量，所以影响不会越过 last。

前缀和具有线性可加性，多条预订的贡献可独立叠加。因此最终每个位置恰为覆盖该航班的所有预订座位数之和。

边界情况

  • first = 1：直接在差分数组首位增加。
  • last = n：数组内没有撤销位置，跳过减法。
  • 只有一个航班或区间长度为 1：两个边界操作仍成立。
  • 区间高度重叠：增量会自然叠加；约束范围内 int 足够。

复杂度

设预订数为 m。时间复杂度 O(m + n)，返回数组之外可原地使用差分数组，空间复杂度 O(n)（它同时也是输出）。

四语言完整代码

Java

class Solution {
    public int[] corpFlightBookings(int[][] bookings, int n) {
        int[] diff = new int[n];
        for (int[] b : bookings) {
            int first = b[0], last = b[1], seats = b[2];
            diff[first - 1] += seats;
            if (last < n) diff[last] -= seats;
        }
        for (int i = 1; i < n; i++) diff[i] += diff[i - 1];
        return diff;
    }
}

替代方案

最直接的方法是遍历每条预订中的每个航班并累加，时间复杂度最坏为 O(mn)，在 2 × 10⁴ 规模下可能超时。若要在线交替进行区间更新与区间/单点查询，可进一步考虑树状数组或线段树；本题所有更新先完成再统一输出，差分数组最简洁。

面试追问

  • 如果预订和查询交错出现，如何改用树状数组？
  • 如果要支持二维矩形区域加值，二维差分的四个角如何更新？
  • 为什么 last = n 时不需要额外开一格？开 n + 1 又有什么好处？

常见错误

  • 忘记航班编号从 1 开始，数组索引从 0 开始。
  • 在 diff[last - 1] 做减法，导致最后一个航班没有被覆盖。
  • last = n 时仍访问 diff[last]，造成越界。
  • 构建差分后忘记做前缀累加。
