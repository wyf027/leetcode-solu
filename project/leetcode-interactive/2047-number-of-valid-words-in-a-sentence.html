句子中的有效单词数

Number of Valid Words in a Sentence

一个连字符、一处标点，可能决定一个 token 是否有效。先读规则，再亲手推演。

打开官方题目 ↗

01 / 题目

给定字符串 sentence，按一个或多个空格划分成非空 token。返回其中满足以下全部条件的 token 数量。

  1. 不包含数字；字符只能是小写字母、连字符或允许的标点。
  2. 至多包含一个 -，且它的左右相邻字符都必须是小写字母。
  3. 至多包含一个标点 !、. 或 ,，且只能出现在 token 的最后一位。

单独的 ! 或 . 也有效，不要求 token 一定包含字母。a-b. 有效，-ab、ab-、a!b、c., 无效。

参数与返回值

countValidWords(sentence: string) → integer

约束

  • 1 ≤ sentence.length ≤ 1000。
  • 只含小写英文字母、数字 0–9、空格和 - ! . ,。
  • 至少有一个非空 token；可以有连续空格、首尾空格。

02 / 官方示例

示例 1

输入：sentence = "cat and  dog"
输出：3

三个 token：cat、and、dog 都有效。连续空格不会产生单词。

示例 2

输入：sentence = "!this  1-s b8d!"
输出：0

!this 的标点不在末尾；1-s 和 b8d! 包含数字，均无效。

示例 3

输入：sentence = "alice and  bob are playing stone-game10"
输出：5

前五个 token 有效；stone-game10 含有数字。

05 / 独立题解

准备好之后，再展开推导与四语言实现。

核心洞察：每个 token 独立检查

逐个字符检查规则即可。连字符需要记数量并检查左右邻居；标点只需检查是否在末尾。因为末尾只有一个位置，只允许末尾标点就已经保证“至多一个标点”。

完整过程

  1. 按空格分割句子，忽略空串。
  2. 开始一个 token 时，把连字符数设为 0。
  3. 小写字母直接继续；数字直接判无效。
  4. 遇到连字符，数量加一；超过一个、位于首尾或任一邻居不是小写字母，都判无效。
  5. 遇到标点，如果不是最后一位则无效。所有字符通过后，答案加一。

例如 a-b.：a 正常；- 的两侧为 a、b，数量为 1；b 正常；. 在最后，整个 token 有效。a-b-c 会在第二个 - 处被拒绝。

正确性

必要性：算法拒绝的情况恰好是数字、过多或邻居不合法的连字符、非末尾标点，均违反题目条件，所以有效 token 不会被误拒。

充分性：若算法接受，所有字符都属于允许类型且无数字；连字符至多一个且左右均为小写字母；标点只能占据唯一的末尾位置。因此三条规则全部满足。分割后的每个非空 token 恰好处理一次，累加结果就是有效单词总数。

边界与复杂度

单独标点有效；单独连字符无效；首尾和连续空格应忽略；数字出现在任何位置都无效。以下四份代码采用分割后扫描：设句长为 n，时间 O(n)，额外空间 O(n)（分割产生的字符串等）；每个 token 的判定状态为 O(1)。

替代方案

直接在原句上用双指针定位 token 区间，可在不复制字符串的情况下把辅助空间降到 O(1)。也可以使用正则完整匹配 ([a-z]+(-[a-z]+)?)?[!.,]?，但必须先排除空 token；不能只做子串搜索。显式扫描更便于解释失败原因。

Java

class Solution {
    public int countValidWords(String sentence) {
        int answer = 0;
        for (String word : sentence.split(" +")) {
            if (!word.isEmpty() && valid(word)) answer++;
        }
        return answer;
    }

    private boolean letter(char c) {
        return c >= 'a' && c <= 'z';
    }

    private boolean valid(String word) {
        int hyphens = 0;
        for (int i = 0; i < word.length(); i++) {
            char c = word.charAt(i);
            if (letter(c)) continue;
            if (c == '-') {
                if (++hyphens > 1 || i == 0 || i == word.length() - 1
                    || !letter(word.charAt(i - 1))
                    || !letter(word.charAt(i + 1))) return false;
            } else if (c == '!' || c == '.' || c == ',') {
                if (i != word.length() - 1) return false;
            } else {
                return false;
            }
        }
        return true;
    }
}

var countValidWords = function(sentence) {
    const letter = c => c >= 'a' && c <= 'z';
    function valid(word) {
        let hyphens = 0;
        for (let i = 0; i < word.length; i++) {
            const c = word[i];
            if (letter(c)) continue;
            if (c === '-') {
                if (++hyphens > 1 || i === 0 || i === word.length - 1
                    || !letter(word[i - 1]) || !letter(word[i + 1])) {
                    return false;
                }
            } else if ('!.,'.includes(c)) {
                if (i !== word.length - 1) return false;
            } else {
                return false;
            }
        }
        return true;
    }
    let answer = 0;
    for (const word of sentence.split(' ')) {
        if (word.length > 0 && valid(word)) answer++;
    }
    return answer;
};

class Solution:
    def countValidWords(self, sentence: str) -> int:
        def letter(c):
            return 'a' <= c <= 'z'

        def valid(word):
            hyphens = 0
            for i, c in enumerate(word):
                if letter(c):
                    continue
                if c == '-':
                    hyphens += 1
                    if (hyphens > 1 or i == 0 or i == len(word) - 1
                            or not letter(word[i - 1])
                            or not letter(word[i + 1])):
                        return False
                elif c in '!.,':
                    if i != len(word) - 1:
                        return False
                else:
                    return False
            return True

        return sum(valid(word) for word in sentence.split())

C++

#include <string>
#include <sstream>
using namespace std;

class Solution {
    bool letter(char c) {
        return c >= 'a' && c <= 'z';
    }
    bool valid(const string& word) {
        int hyphens = 0, n = static_cast<int>(word.size());
        for (int i = 0; i < n; ++i) {
            char c = word[i];
            if (letter(c)) continue;
            if (c == '-') {
                if (++hyphens > 1 || i == 0 || i == n - 1
                    || !letter(word[i - 1]) || !letter(word[i + 1]))
                    return false;
            } else if (c == '!' || c == '.' || c == ',') {
                if (i != n - 1) return false;
            } else {
                return false;
            }
        }
        return true;
    }
public:
    int countValidWords(string sentence) {
        istringstream input(sentence);
        string word;
        int answer = 0;
        while (input >> word) {
            if (valid(word)) ++answer;
        }
        return answer;
    }
};

常见错误

  • 只检查连字符不在首尾，忘记它必须紧邻两个字母，例如 a-!。
  • 检查标点数量，却漏掉位置限制，例如 a!b。
  • 要求至少一个字母，错误排除 !。
  • 把分割产生的空串计入答案，或把 token 的连字符数沿用到下一词。

面试追问

能否只遍历一次且不分割？ 可以，维护当前 token 的合法性、连字符数量和边界，在空格或句尾结算。

为何不用标点计数器？ 任何不在末尾的标点都立即失败；剩下唯一可能的位置只能容纳一个标点。

流式输入如何处理右邻居？ 遇到连字符设置“下一位必须为字母”的状态，遇到空格或结束时也要处理这个待满足条件。
