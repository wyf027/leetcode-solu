LCP 37. 最小矩形面积

不必枚举 O(n²) 个交点。极左/极右交点只可能是“无穷远处相邻”的两条线；把直线反写为 x 关于 y 的函数，同一技巧还能找最低/最高交点。

扫描线顺序对偶变换O(n log n)

题意

给定 lines[i] = [k, b]，表示直线 y = kx + b，其中 k > 0、无重合直线。用一条边平行坐标轴的最小矩形覆盖全部两两交点，返回面积；无交点、仅一个交点或交点共线时返回 0。

示例 1

lines = [[2,3],[3,0],[4,1]]

输出：48

示例 2

lines = [[1,1],[2,3]]

输出：0

约束：1 ≤ lines.length ≤ 10⁵，1 ≤ k ≤ 10⁴，-10⁴ ≤ b ≤ 10⁴。

交互：边界计算器

每条线写作 k,b，用分号分隔。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

题解：只看相邻线的交叉

核心洞察

在 x→−∞ 时，按 k 升序、同斜率按 b 降序排列，就是直线的垂直顺序；最早发生的交叉必在相邻两线间，故可得到最小 x。x→+∞ 时同斜率按 b 升序，得到最大 x。将 y=kx+b 改写成 x=(1/k)y-b/k，再跑一次即可得到 y 的范围。

完整过程

  1. 定义 range：按斜率排序后，仅检查相邻非平行线交点。
  2. 两种同斜率 tie-break 分别求左、右端点。
  3. 把每条线转换为 x 关于 y 的直线，求下、上端点。
  4. 面积为 (maxX-minX)(maxY-minY)。

边界与复杂度

若某个范围不存在交点，或宽/高为 0，答案为 0。相同 k 的线平行，应跳过除零。两次排序各为 O(n log n)，相邻扫描为 O(n)，总空间 O(n)。

替代方案

小数据可枚举所有点验证，但 O(n²) 在 10⁵ 条线时不可用。凸包表述也可解释边界，却不必显式构造全部交点。

常见错误

  • 只计算 x 范围，忘记 y 范围不由同一批点决定。
  • 同斜率时没有按截距打破平局。
  • 使用整数除法导致交点精度丢失。

面试追问

若允许负斜率，需分别处理无穷远处的排序方向；若要求旋转矩形，则不再能直接用 x/y 极值，应转向凸包与旋转卡壳。

class Solution:
 def minRecSize(self,lines):
  def rg(a):
   lo,hi=float('inf'),-float('inf')
   for rev in (True,False):
    a.sort(key=lambda z:(z[0], -z[1] if rev else z[1]))
    for u,v in zip(a,a[1:]):
     if u[0]!=v[0]:
      q=(v[1]-u[1])/(u[0]-v[0]); lo=min(lo,q) if rev else lo; hi=max(hi,q) if not rev else hi
   return lo,hi
  x=rg([[float(k),float(b)] for k,b in lines]); y=rg([[1/k,-b/k] for k,b in lines])
  return 0 if x[0]>x[1] or y[0]>y[1] else (x[1]-x[0])*(y[1]-y[0])
