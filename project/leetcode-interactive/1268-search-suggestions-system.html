Problem brief

题目要求

先读规则、示例与边界；完整解法被收在页面底部，默认不会展开。

准确转述

给定字符串数组 products 和字符串 searchWord。用户从左到右输入 searchWord，每输入一个字符，就要推荐所有以当前已输入内容为前缀的产品。

每轮最多返回三个产品；若匹配产品超过三个，只保留字典序最小的三个。最终按输入字符的轮次，返回一个二维字符串列表。

官方函数形式

suggestedProducts(products: string[], searchWord: string): list<list<string>>
Constraints

约束

  • 1 ≤ products.length ≤ 1000
  • 1 ≤ products[i].length ≤ 3000
  • 1 ≤ Σ products[i].length ≤ 2 × 10⁴
  • 所有产品名互不相同，且只含小写英文字母。
  • 1 ≤ searchWord.length ≤ 1000
  • searchWord 只含小写英文字母。

Full solution

排序 + 前缀边界

将相同前缀的产品变成排序数组中的连续区间，再只读取区间开头三个。

01 / 连续性

相同前缀聚在一起

字典序排序后，拥有同一前缀的字符串必定形成一个连续区间。

02 / 边界

两次二分定位

前缀 p 的区间可写为 [lower_bound(p), lower_bound(p + "{"))。题目限定小写字母，{ 恰好大于 z。

03 / 推荐

只取开头三个

区间已经按字典序排列，所以前三项就是题目要求的最小三个产品。

Process

完整过程

  1. 先将 products 原地按字典序排序。
  2. 依次把 searchWord 的字符追加到当前前缀 prefix。
  3. 用二分查找得到第一个不小于 prefix 的位置 left。
  4. 用 prefix + "{" 查得匹配区间的右开端 right。
  5. 加入 products[left .. min(left + 3, right))，重复直至搜索词结束。
正确性证明

引理 1：排序后，以同一前缀 p 开头的产品连续出现。否则若两个匹配项之间存在一个不匹配项，该项在首次不同字符处不可能同时夹在二者之间，矛盾。

引理 2：lower_bound(p) 是匹配区间左端；由于字符只可能是 a..z，所有以 p 开头的字符串都严格小于 p + "{"，故 lower_bound(p + "{") 是右端。

定理：算法截取该连续区间开头最多三个元素。区间内部沿用全局字典序，因此返回结果恰好是全部匹配产品中字典序最小的三个；对每个输入前缀均成立。

复杂度

  • 时间：排序约为 O(n log n · L)；每个搜索字符进行两次字符串二分比较，约为 O(m log n · L)。L 表示比较字符串的相关长度。
  • 空间：除排序实现与答案外，额外空间约 O(log n + m)；不同语言的排序实现可能有所差异。

边界处理

  • 没有任何匹配：仍需为该轮加入空列表。
  • 匹配少于三个：只返回实际存在的产品。
  • 产品名恰好等于前缀：它应位于匹配区间内。
  • 某轮已无匹配：后续更长前缀也必然无匹配，但仍要输出对应空列表。

import java.util.*;

class Solution {
    public List<List<String>> suggestedProducts(
            String[] products, String searchWord) {
        Arrays.sort(products);
        List<List<String>> answer = new ArrayList<>();
        StringBuilder prefix = new StringBuilder();

        for (char ch : searchWord.toCharArray()) {
            prefix.append(ch);
            String lowKey = prefix.toString();
            String highKey = lowKey + "{";
            int left = lowerBound(products, lowKey);
            int right = lowerBound(products, highKey);

            List<String> suggestions = new ArrayList<>();
            for (int i = left; i < Math.min(left + 3, right); i++) {
                suggestions.add(products[i]);
            }
            answer.add(suggestions);
        }
        return answer;
    }

    private int lowerBound(String[] items, String target) {
        int left = 0, right = items.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (items[mid].compareTo(target) < 0) left = mid + 1;
            else right = mid;
        }
        return left;
    }
}

var suggestedProducts = function(products, searchWord) {
    products.sort();

    const lowerBound = (target) => {
        let left = 0, right = products.length;
        while (left < right) {
            const mid = left + Math.floor((right - left) / 2);
            if (products[mid] < target) left = mid + 1;
            else right = mid;
        }
        return left;
    };

    const answer = [];
    let prefix = "";
    for (const ch of searchWord) {
        prefix += ch;
        const left = lowerBound(prefix);
        const right = lowerBound(prefix + "{");
        answer.push(products.slice(left, Math.min(left + 3, right)));
    }
    return answer;
};
from bisect import bisect_left
from typing import List


class Solution:
    def suggestedProducts(
        self, products: List[str], searchWord: str
    ) -> List[List[str]]:
        products.sort()
        answer: List[List[str]] = []
        prefix = ""

        for char in searchWord:
            prefix += char
            left = bisect_left(products, prefix)
            right = bisect_left(products, prefix + "{")
            answer.append(products[left:min(left + 3, right)])

        return answer

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<string>> suggestedProducts(
        vector<string>& products, string searchWord
    ) {
        sort(products.begin(), products.end());
        vector<vector<string>> answer;
        string prefix;

        for (char ch : searchWord) {
            prefix += ch;
            auto left = lower_bound(products.begin(), products.end(), prefix);
            auto right = lower_bound(
                products.begin(), products.end(), prefix + '{'
            );

            vector<string> suggestions;
            for (auto it = left; it != right && suggestions.size() < 3; ++it) {
                suggestions.push_back(*it);
            }
            answer.push_back(move(suggestions));
        }
        return answer;
    }
};

替代方案

  • 字典树：在每个节点保存最多三个字典序最小产品。查询近似线性于搜索词长度，但实现和空间开销更高，适合大量重复查询。
  • 排序 + 双指针：前缀增长时只向内推进左右边界，避免每轮重新二分；逻辑也很紧凑。
  • 逐轮扫描：每轮过滤全部产品，约 O(mnL)，在给定规模可能通过，但没有利用排序结构。

面试追问

  • 如果产品库持续增删，该选 Trie、平衡树还是离线排序？
  • 如果推荐要按热度优先、字典序次之，节点中该维护什么？
  • 如何支持 Unicode、大小写折叠和本地化排序？
  • 前缀查询量极大时，怎样缓存热门前缀并控制失效？

常见错误

  • 每轮返回全部匹配项，忘记“最多三个”。
  • 先截取三个再排序，导致不是全体匹配项中字典序最小的三个。
  • 找不到匹配时提前结束，漏掉后续每轮所需的空列表。
  • 二分区间使用闭区间/开区间混杂，造成越界或漏掉边界产品。
  • 使用 prefix + "{" 却忽略本题“小写英文字母”的前提；若字符集扩大，应改用更通用的上界策略。
