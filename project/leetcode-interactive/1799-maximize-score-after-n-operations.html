N 次操作后的
最大分数和

Maximize Score After N Operations

同样的数字，不同的配对与出场顺序，会得到怎样的总分？

题目 · 配对、计分、移除

给定一个含 2 × n 个正整数的数组 nums，必须进行恰好 n 次操作。第 i 次操作（从 1 开始）从尚未使用的元素中选出两个数 x、y，获得 i × gcd(x, y) 分，然后移除这两个元素。返回所有操作可以获得的最大总分。

gcd 表示最大公约数；重复值也属于不同的数组元素，每个位置只能用一次。

约束
  • 1 ≤ n ≤ 7
  • nums.length = 2 × n
  • 1 ≤ nums[i] ≤ 10⁶

官方题目 · 以下内容依据本地官方元数据转述。

官方示例

示例 1

输入：nums = [1,2]
输出：1

第 1 次选 (1, 2)：1 × gcd(1, 2) = 1。

示例 2

输入：nums = [3,4,6,8]
输出：11

先选 (3, 6)，再选 (4, 8)：1 × 3 + 2 × 4 = 11。

示例 3

输入：nums = [1,2,3,4,5,6]
输出：14

依次选 (1, 5)、(2, 4)、(3, 6)：1 × 1 + 2 × 2 + 3 × 3 = 14。

题解 · 用集合压缩历史

核心洞察

最多只有 14 个元素。用一个二进制掩码记录已用位置，置 1 表示已经移除。操作轮次由已用位数唯一决定：i = popcount(mask) / 2 + 1。因此不必把轮次额外存入状态。

定义 dp[mask] 为恰好使用 mask 中元素时的最大已得分。枚举每一对未用下标 a < b，令 next = mask | (1<<a) | (1<<b)，更新：

dp[next] = max(dp[next], dp[mask] + i × gcd(nums[a], nums[b]))

完整过程

  1. 预计算所有下标对的 gcd，避免在每个状态重复计算。
  2. 设 dp[0] = 0。所有偶数位数的子集都可通过配对到达，且分数非负，所以数组可以整体初始化为 0。
  3. 按 mask 从小到大处理，仅处理偶数个已用位的状态，枚举所有未用元素对。
  4. 每次置入两位，next 总大于 mask，因此上述顺序是合法的拓扑顺序。
  5. 返回所有位均为 1 的 dp 值。

正确性证明

状态充分性：给定已用位置集合，剩余元素和下一轮权重均确定。不同历史若到达相同 mask，后续可行操作集合完全一致，因此只需保留最高前缀分数。

归纳：空集最优值为 0。假设此前状态最优值正确，任意到达 next 的方案都有最后一对 (a, b)，去掉这对得到其前驱 mask。转移枚举了这对，并用最优前缀加上本轮合法收益，故不会漏掉最优方案；每个转移又都对应合法方案，故不会高估。沿拓扑顺序归纳，满集状态就是答案。

边界与复杂度

只有两个数时返回其 gcd。所有数相同为 v 时，答案为 v × n(n+1)/2；两两互质时为 n(n+1)/2。即使有重复值也必须按下标标记。答案最多为 10⁶ × 28 = 28,000,000，32 位有符号整数足够。

令 m = 2n、A = max(nums)。预计算耗时 O(m² log A)，状态转移耗时 O(m² 2ᵐ)，总空间 O(2ᵐ + m²)。奇数位状态不参与转移。

替代方案

记忆化 DFS 的后缀递推为 F(mask) = max(i × g[a][b] + F(next))，边界 F(满集)=0，复杂度相同，便于还原路径。也可枚举所有无序完美匹配，再把该匹配的 gcd 从小到大排列以匹配递增权重；此时可以固定首个未用元素来枚举匹配，但必须在完整匹配后排序计分。其匹配数为 (m−1)!!，扩展性不如状态压缩。

常见错误

  • 每轮直接取最大 gcd：例如 [3,4,6,8] 先拿 4 得 4 + 2×3 = 10，低于 11。
  • 在按轮次计分的 dp 中固定首个未用位置：会遗漏不同出场顺序。例如 [4,8,3,6] 必须允许先使用后两个元素。
  • 按数值去重：两个相等的数仍是两个独立位置。
  • 把 popcount(mask) 当轮次，或从第 0 轮开始计分。
  • 每次转移覆盖而非取 max，丢失同一集合的更优历史。

面试追问

怎样返回配对方案？每次改进 dp[next] 时保存前驱 mask 和选中的下标对，从满集反向回溯再翻转。

为什么固定匹配后可以按 gcd 排序？若两个权重 i < j 配到公约数 a > b，交换后增加 (j−i)(a−b) ≥ 0。但这不能用于贪心选择匹配本身。

扩到 30 个元素怎么办？2³⁰ 状态已不实用，需要利用额外输入结构、剪枝或近似策略；当前方法的可行性依赖 m ≤ 14。

Java

class Solution {
    private int gcd(int a, int b) {
        while (b != 0) { int t = a % b; a = b; b = t; }
        return a;
    }
    public int maxScore(int[] nums) {
        int m = nums.length, size = 1 << m;
        int[][] g = new int[m][m];
        for (int a = 0; a < m; a++)
            for (int b = a + 1; b < m; b++)
                g[a][b] = gcd(nums[a], nums[b]);
        int[] dp = new int[size];
        for (int mask = 0; mask < size; mask++) {
            int count = Integer.bitCount(mask);
            if ((count & 1) != 0) continue;
            int op = count / 2 + 1;
            for (int a = 0; a < m; a++) {
                if ((mask & (1 << a)) != 0) continue;
                for (int b = a + 1; b < m; b++) {
                    if ((mask & (1 << b)) != 0) continue;
                    int next = mask | (1 << a) | (1 << b);
                    dp[next] = Math.max(dp[next], dp[mask] + op * g[a][b]);
                }
            }
        }
        return dp[size - 1];
    }
}

/** @param {number[]} nums @return {number} */
var maxScore = function(nums) {
    const m = nums.length, size = 1 << m;
    const gcd = (a, b) => {
        while (b !== 0) [a, b] = [b, a % b];
        return a;
    };
    const g = Array.from({length: m}, () => Array(m).fill(0));
    for (let a = 0; a < m; a++)
        for (let b = a + 1; b < m; b++) g[a][b] = gcd(nums[a], nums[b]);
    const dp = new Int32Array(size), bits = new Uint8Array(size);
    for (let mask = 1; mask < size; mask++)
        bits[mask] = bits[mask >> 1] + (mask & 1);
    for (let mask = 0; mask < size; mask++) {
        if (bits[mask] & 1) continue;
        const op = bits[mask] / 2 + 1;
        for (let a = 0; a < m; a++) {
            if (mask & (1 << a)) continue;
            for (let b = a + 1; b < m; b++) {
                if (mask & (1 << b)) continue;
                const next = mask | (1 << a) | (1 << b);
                dp[next] = Math.max(dp[next], dp[mask] + op * g[a][b]);
            }
        }
    }
    return dp[size - 1];
};

Python

from typing import List
from math import gcd

class Solution:
    def maxScore(self, nums: List[int]) -> int:
        m = len(nums)
        size = 1 << m
        g = [[0] * m for _ in range(m)]
        for a in range(m):
            for b in range(a + 1, m):
                g[a][b] = gcd(nums[a], nums[b])
        dp = [0] * size
        for mask in range(size):
            count = mask.bit_count()
            if count % 2:
                continue
            op = count // 2 + 1
            for a in range(m):
                if mask & (1 << a):
                    continue
                for b in range(a + 1, m):
                    if mask & (1 << b):
                        continue
                    nxt = mask | (1 << a) | (1 << b)
                    dp[nxt] = max(dp[nxt], dp[mask] + op * g[a][b])
        return dp[-1]

C++

#include <vector>
#include <algorithm>
#include <numeric>
using namespace std;

class Solution {
public:
    int maxScore(vector<int>& nums) {
        int m = nums.size(), size = 1 << m;
        vector<vector<int>> g(m, vector<int>(m));
        for (int a = 0; a < m; ++a)
            for (int b = a + 1; b < m; ++b)
                g[a][b] = gcd(nums[a], nums[b]);
        vector<int> dp(size, 0);
        for (int mask = 0; mask < size; ++mask) {
            int count = __builtin_popcount((unsigned)mask);
            if (count & 1) continue;
            int op = count / 2 + 1;
            for (int a = 0; a < m; ++a) {
                if (mask & (1 << a)) continue;
                for (int b = a + 1; b < m; ++b) {
                    if (mask & (1 << b)) continue;
                    int next = mask | (1 << a) | (1 << b);
                    dp[next] = max(dp[next], dp[mask] + op * g[a][b]);
                }
            }
        }
        return dp.back();
    }
};
