灯泡开关 Ⅱ二

四个开关、恰好若干次按压。真正要数的不是操作序列，而是最后留下了多少种不同的明暗图案。

MEDIUM Bulb Switcher II 非会员题
全部偶数奇数3k + 1

Problem

题意

房间里有 n 只灯泡，编号为 1 到 n，初始时全部点亮。墙上有 4 个开关，每次可任选一个按下：

  1. 1反转全部灯泡。
  2. 2反转编号为偶数的灯泡：2、4、6、……
  3. 3反转编号为奇数的灯泡：1、3、5、……
  4. 4反转编号满足 j = 3k + 1 的灯泡：1、4、7、10、……

必须恰好按下 presses 次。求操作完成后可能出现的不同灯泡状态数量。

Signature

flipLights(n, presses) → integer

约束

  • 1 ≤ n ≤ 1000
  • 0 ≤ presses ≤ 1000

示例 1

输入：n = 1, presses = 1
输出：2
解释：[关]（开关 1）或 [开]（开关 2）。

示例 2

输入：n = 2, presses = 1
输出：3
解释：[关, 关]、[开, 关]、[关, 开]。

示例 3

输入：n = 3, presses = 1
输出：4
解释：[关, 关, 关]、[开, 关, 开]、[关, 开, 关]、[关, 开, 开]。

    Solution

    核心洞察：状态空间只有 8

    不要模拟最多 1000 次按键。同一开关按两次会互相抵消，所以每个开关只剩“奇数次 / 偶数次”两种有效选择；4 个开关最多只有 2⁴ = 16 个奇偶掩码。进一步利用开关关系，n ≥ 3 时最终也只有 8 种不同状态。

    完整推导

    1. 只看奇偶性。记 4 个开关是否被按奇数次为 x₁…x₄。偶数次等价于没按，奇数次等价于按一次。
    2. 满足“恰好”。掩码中有 k 个 1，代表最少按 k 次。它能由恰好 presses 次实现，当且仅当 k ≤ presses 且两者奇偶性相同；多出的偶数次可用任一开关连按两次补齐。
    3. 前三只灯足够。4 个开关作用在灯 1、2、3 上的翻转向量分别是 111、010、101、100。它们最多生成 2³ = 8 种状态。
    4. 不会漏掉后面的差异。前三个向量满足“全部 = 偶数 XOR 奇数”，这是四个操作唯一的全局冗余关系；若两个掩码在前三只灯上相同，它们对所有灯的效果也相同。
    5. 按小规模分类。灯越少，能区分的状态越少；按压次数达到 3 后，n ≥ 3 的 8 种状态全部可达。于是答案只由 min(n, 3) 和小范围的 presses 决定。

    正确性证明

    引理 1：任何操作序列都等价于一个 4 位奇偶掩码。因为每个开关的翻转操作可交换，且同一开关执行两次为恒等操作。

    引理 2：一个包含 k 个奇数开关的掩码恰好可在 presses 次后到达，当且仅当 k ≤ presses 且 k ≡ presses (mod 2)。必要性来自每次操作只改变总次数 1；充分性来自先各按一次这 k 个开关，再用同一开关的成对按压补齐。

    引理 3：当 n ≥ 3 时，前三只灯可唯一确定完整状态。四个操作在前三位上的向量秩为 3，唯一核关系是开关 1、2、3 同时取反；该关系对所有灯恒等，因此前三位相同的两个掩码在全部灯上也相同。

    定理：分类表返回正确答案。由引理 1、2，所有且仅有合法奇偶掩码被计入；由引理 3，状态去重只需至多前三只灯。对 n = 1、n = 2 和 n ≥ 3 的合法掩码计数分别得到表中各值，所以算法既不遗漏也不重复。

    边界与复杂度

    • presses = 0：只能保持初始全亮，答案为 1。
    • n = 1：只区分亮和灭；只要按压次数大于 0，两者都能实现。
    • 很大的 n 或 presses 不需要额外空间，也不会增加运行时间。
    • 时间复杂度：O(1)；空间复杂度：O(1)。

    替代方案

    枚举奇偶掩码：遍历 0 到 15，筛选满足按压次数与奇偶条件的掩码，在前 min(n, 3) 只灯上计算状态并放入集合。仍是常数时间，推导更少，也很适合面试时先写出稳妥版本。

    BFS：把灯泡状态视为节点，每轮扩展四种操作。将 n 压到 3 后状态最多 8 个，但仍需正确处理“恰好按压”的层数；可行却不如奇偶枚举直接。

    面试追问

    • 如果要求“至多”按 presses 次，可达性条件会怎样变化？
    • 如果新增一个按质数编号灯泡的开关，是否仍能压缩到前三只灯？应如何找最小代表长度？
    • 如何用 GF(2) 线性代数描述这些翻转向量、秩与等价掩码？
    • 如何恢复一条具体的、恰好包含 presses 次操作的序列？

    常见错误

    • 把题目看成“最多按 presses 次”，漏掉掩码与总次数必须同奇偶。
    • 直接模拟 n 只灯和 1000 层操作，忽略状态空间极小。
    • 认为 4 个开关必有 16 种不同结果，未注意“全部 = 偶数 XOR 奇数”。
    • 忘记单独处理 presses = 0、n = 1、n = 2。

    class Solution {
    public int flipLights(int n, int presses) {
        if (presses == 0) {
            return 1;
        }
        if (n == 1) {
            return 2;
        }
        if (n == 2) {
            return presses == 1 ? 3 : 4;
        }
        if (presses == 1) {
            return 4;
        }
        if (presses == 2) {
            return 7;
        }
        return 8;
    }
}
