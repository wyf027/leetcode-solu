966. 元音拼写检查器
Vowel Spellchecker

MEDIUM哈希表字符串归一化非付费题

题目描述

给定单词列表 wordlist 和若干查询 queries，请为每个查询返回按规则纠正后的单词。

匹配必须严格遵循优先级；若同一级别有多个候选，返回它们在 wordlist 中最先出现的一个。

  1. 完全匹配
    区分大小写；直接返回查询词本身。
  2. 大小写匹配
    忽略大小写，返回词表中的第一个匹配项。
  3. 元音容错匹配
    忽略大小写，并允许每个元音在 a/e/i/o/u 之间替换；返回第一个匹配项。
  4. 无匹配
    返回空字符串 ""。元音替换不会增删字符。
函数签名
spellchecker(wordlist, queries) → string[]

约束

  • 1 ≤ wordlist.length, queries.length ≤ 5000
  • 1 ≤ wordlist[i].length, queries[i].length ≤ 7
  • 所有单词仅含英文字母。
关键语义
辅音必须相同；元音位置必须对应元音。hare 与 Hear 不匹配，因为字符位置不同。

官方示例

示例 1
输入：wordlist = ["KiTe","kite","hare","Hare"] queries = ["kite","Kite","KiTe","Hare","HARE","Hear","hear","keti","keet","keto"] 输出：["kite","KiTe","KiTe","Hare","hare","","","KiTe","","KiTe"]
示例 2
输入：wordlist = ["yellow"], queries = ["YellOw"] 输出：["yellow"]

准备好看实现了吗？

题解默认收起，避免在你推导之前泄露核心结构。

题解：三个索引，一次预处理

核心洞察：匹配优先级天然对应三个查询键：原词、全小写、把小写元音统一替换为 * 的掩码。后两类映射只保留第一次出现的词，就能忠实保留词表顺序。

完整过程

  1. 把所有原词放入精确匹配集合。
  2. 以小写词为键，记录第一次出现的原词。
  3. 以元音掩码为键，记录第一次出现的原词。
  4. 每个查询依次检查三个索引，首次命中即停止。

边界与不变量

  • 掩码前必须先统一小写。
  • 只替换元音，不删除或交换字符。
  • putIfAbsent / 首次赋值保障最早候选。
  • 完全匹配返回查询本身，等价于词表中同字面值。

正确性说明

引理 1：精确集合恰好识别所有区分大小写的完全匹配。

引理 2：两个词的小写形式相同，当且仅当它们仅存在大小写差异；映射保存的值是词表中第一个此类词。

引理 3：两个等长单词的元音掩码相同，当且仅当其对应辅音相同、对应元音位置均为元音；这正是题目允许的元音替换。

结论：算法按完全匹配、大小写匹配、元音匹配的顺序返回第一个命中，否则返回空串，因此结果满足全部优先级规则。

复杂度

设词表与查询的总字符数为 S。预处理和查询总时间均为 O(S)，额外空间为 O(S)。题设单词长度至多 7，但分析不依赖此常数。

四语言完整代码

import java.util.*;

class Solution {
    public String[] spellchecker(String[] wordlist, String[] queries) {
        Set<String> exact = new HashSet<>();
        Map<String, String> lower = new HashMap<>();
        Map<String, String> masked = new HashMap<>();
        for (String word : wordlist) {
            exact.add(word);
            String low = word.toLowerCase(Locale.ROOT);
            lower.putIfAbsent(low, word);
            masked.putIfAbsent(mask(low), word);
        }
        String[] answer = new String[queries.length];
        for (int i = 0; i < queries.length; i++) {
            String query = queries[i];
            String low = query.toLowerCase(Locale.ROOT);
            if (exact.contains(query)) answer[i] = query;
            else if (lower.containsKey(low)) answer[i] = lower.get(low);
            else answer[i] = masked.getOrDefault(mask(low), "");
        }
        return answer;
    }

    private String mask(String word) {
        StringBuilder result = new StringBuilder();
        for (char c : word.toCharArray())
            result.append("aeiou".indexOf(c) >= 0 ? '*' : c);
        return result.toString();
    }
}
/**
 * @param {string[]} wordlist
 * @param {string[]} queries
 * @return {string[]}
 */
var spellchecker = function(wordlist, queries) {
    const exact = new Set(wordlist);
    const lower = new Map();
    const masked = new Map();
    const mask = word => word.toLowerCase().replace(/[aeiou]/g, '*');

    for (const word of wordlist) {
        const low = word.toLowerCase();
        if (!lower.has(low)) lower.set(low, word);
        const key = mask(word);
        if (!masked.has(key)) masked.set(key, word);
    }
    return queries.map(query => {
        if (exact.has(query)) return query;
        const low = query.toLowerCase();
        if (lower.has(low)) return lower.get(low);
        return masked.get(mask(query)) || '';
    });
};
from typing import List

class Solution:
    def spellchecker(self, wordlist: List[str], queries: List[str]) -> List[str]:
        exact = set(wordlist)
        lower = {}
        masked = {}

        def mask(word: str) -> str:
            return ''.join('*' if c in 'aeiou' else c for c in word.lower())

        for word in wordlist:
            low = word.lower()
            lower.setdefault(low, word)
            masked.setdefault(mask(word), word)

        answer = []
        for query in queries:
            low = query.lower()
            if query in exact:
                answer.append(query)
            elif low in lower:
                answer.append(lower[low])
            else:
                answer.append(masked.get(mask(query), ''))
        return answer
class Solution {
    string mask(string word) {
        for (char& c : word) {
            c = tolower(static_cast<unsigned char>(c));
            if (string("aeiou").find(c) != string::npos) c = '*';
        }
        return word;
    }
public:
    vector<string> spellchecker(vector<string>& wordlist,
                                vector<string>& queries) {
        unordered_set<string> exact(wordlist.begin(), wordlist.end());
        unordered_map<string, string> lower, masked;
        for (const string& word : wordlist) {
            string low = word;
            transform(low.begin(), low.end(), low.begin(),
                      [](unsigned char c) { return tolower(c); });
            if (!lower.count(low)) lower[low] = word;
            string key = mask(word);
            if (!masked.count(key)) masked[key] = word;
        }
        vector<string> answer;
        for (const string& query : queries) {
            string low = query;
            transform(low.begin(), low.end(), low.begin(),
                      [](unsigned char c) { return tolower(c); });
            if (exact.count(query)) answer.push_back(query);
            else if (lower.count(low)) answer.push_back(lower[low]);
            else {
                string key = mask(query);
                answer.push_back(masked.count(key) ? masked[key] : "");
            }
        }
        return answer;
    }
};

替代方案与面试追问

替代方案

可以为每个查询线性扫描词表并逐字符比较，空间近乎为零，但最坏时间为 O(Q · W · L)，无法利用重复规则键，通常不如预处理哈希表。

也可以把三种匹配写成一个复合键结构，但会模糊优先级；三索引更易验证和维护。

常见追问

  • 若加入编辑距离 1，应放在哪一级？如何避免候选爆炸？
  • 若支持 Unicode，大小写折叠与“元音”的定义如何本地化？
  • 若词表在线更新，三个索引如何保持首个候选语义？

常见错误

  • 用普通赋值覆盖映射，错误地返回最后一个候选。
  • 先查元音键再查小写键，破坏优先级。
  • 只将查询转小写，却未将词表键统一。
  • 把 y 当元音，或使用正则删除元音而非替换占位符。
