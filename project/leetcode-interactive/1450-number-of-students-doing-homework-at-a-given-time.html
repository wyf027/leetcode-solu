在既定时间做作业的学生人数

把每名学生的学习时间看成一个闭区间，观察指定时刻究竟落入多少个区间。先读题、动手探索，再决定是否展开题解。

简单非付费题数组Number of Students Doing Homework at a Given Time
Problem

题目描述

区间的两端都包含在内；完成时刻仍视为正在做作业。

给定两个整数数组 startTime 和 endTime，以及整数 queryTime。第 i 名学生从 startTime[i] 开始做作业，在 endTime[i] 完成。

任务：返回在 queryTime 时仍在做作业的学生人数。也就是统计满足 startTime[i] ≤ queryTime ≤ endTime[i] 的下标数量。

官方示例

示例 1
输入：startTime = [1,2,3], endTime = [3,2,7], queryTime = 4
输出：1
解释：只有第三名学生的区间 [3,7] 包含时间 4。
示例 2
输入：startTime = [4], endTime = [4], queryTime = 4
输出：1
解释：唯一一名学生在查询时刻仍在做作业。
示例 3
输入：startTime = [4], endTime = [4], queryTime = 5
输出：0
示例 4
输入：startTime = [1,1,1,1], endTime = [1,3,2,4], queryTime = 7
输出：0
示例 5
输入：startTime = [9,8,7,6,5,4,3,2,1], endTime = [10,10,10,10,10,10,10,10,10], queryTime = 5
输出：5

约束

  • startTime.length == endTime.length
  • 1 <= startTime.length <= 100
  • 1 <= startTime[i] <= endTime[i] <= 1000
  • 1 <= queryTime <= 1000

函数形式

busyStudent(startTime, endTime, queryTime) → integer

Solution

一次遍历，直接判断闭区间

数据量不大，最清晰的线性扫描就是合适答案。

核心洞察

第 i 名学生在查询时刻做作业，当且仅当查询时刻没有早于开始、也没有晚于结束：

startTime[i] ≤ queryTime ≤ endTime[i]

对每个区间独立判断，满足就将计数器加一。

完整过程

  1. 初始化答案 count = 0。
  2. 从下标 0 到 n - 1 遍历两数组。
  3. 若 startTime[i] <= queryTime 且 queryTime <= endTime[i]，答案加一。
  4. 遍历完成后返回 count。

正确性证明

充分性：若算法把学生 i 计入，则两个不等式均成立，因此 queryTime 位于其闭区间内，该学生确实正在做作业。

必要性：若学生 i 在查询时刻做作业，按题意查询时刻必在 [startTime[i], endTime[i]] 内，两个不等式必然成立，算法一定将其计入。

每名且仅有正在做作业的学生会被计数一次，所以最终计数正确。

复杂度

  • 时间复杂度：O(n)
  • 额外空间复杂度：O(1)

边界情况

  • 查询时刻等于开始或结束时刻：闭区间，两端都计入。
  • 所有区间都不包含查询时刻：返回 0。
  • 所有区间都包含查询时刻：返回数组长度。
  • 单点区间 [t,t]：仅在 queryTime == t 时计入。

替代方案

函数式计数：可用 filter、生成式或流式 API 直接统计，表达简洁，时间仍为 O(n)，但可能创建中间集合或带来额外抽象。

差分数组：若要回答很多不同查询时刻，可在时间范围上记录开始与结束后的变化，再做前缀和，让每次查询接近 O(1)。本题只有一次查询，使用它反而更复杂。

面试追问

  • 如果查询次数达到十万次，如何预处理？
  • 如果时间值非常大，差分数组还能直接使用吗？可否离散化或排序？
  • 区间改成左闭右开 [start,end) 时，条件如何变化？

常见错误

  • 使用严格不等号，漏掉两个端点。
  • 只比较开始时间，忘记检查结束时间。
  • 把 endTime[i] 与错误下标配对。
  • 排序两个数组后破坏每名学生的区间对应关系。

class Solution {
    public int busyStudent(int[] startTime, int[] endTime, int queryTime) {
        int count = 0;
        for (int i = 0; i < startTime.length; i++) {
            if (startTime[i] <= queryTime && queryTime <= endTime[i]) {
                count++;
            }
        }
        return count;
    }
}

from typing import List


class Solution:
    def busyStudent(
        self,
        startTime: List[int],
        endTime: List[int],
        queryTime: int
    ) -> int:
        count = 0
        for start, end in zip(startTime, endTime):
            if start <= queryTime <= end:
                count += 1
        return count
