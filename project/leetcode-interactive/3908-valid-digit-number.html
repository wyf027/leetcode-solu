有效数字整数

给定整数 n 与一位数字 x。只有当 n 至少出现一次 x，且最高位不是 x 时，才返回 true。

约束：0 ≤ n ≤ 10⁵，0 ≤ x ≤ 9。这里的“开头”是整数正常十进制表示的最高位。

逐位检查器

n = 101，x = 0。先否决“首位等于 x”，再从右向左找是否有命中。

题意示例

n = 101, x = 0
期望输出：true；0 出现且首位为 1。
n = 232, x = 2
期望输出：false；虽然出现 2，但首位也是 2。
n = 5, x = 1
期望输出：false；没有出现 1。

“␠”表示可见空格；本题整数输入没有前导空格或前导零。

题解：先看最高位，再确认出现

最高位一旦等于 x 就直接不合法。否则只需要扫描剩余数字；右到左取模扫描可以避免字符串额外空间。

完整过程

  1. 保存 hasX = false。
  2. 当 n > 9 时，比较末位 n % 10 与 x，再令 n /= 10。
  3. 循环结束后的 n 是原数最高位：返回 hasX && n != x。

边界、复杂度与替代方案

单数字、n = 0、x = 0 都由同一逻辑覆盖。时间 O(log₁₀ n)，额外空间 O(1)。替代方案：转成字符串后检查首字符与后缀，代码直观但用 O(log n) 空间。

常见错误 / 面试追问

不要只检查“包含 x”；首位规则优先级更高。若 n 可达大整数，字符串方案能避开数值溢出；若输入改为带符号文本，要先定义负号是否属于开头。
