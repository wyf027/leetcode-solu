FULL SOLUTION

题解：按位数分组定位

核心洞察

不要生成无限字符串。所有一位数贡献 9 × 1 位，所有二位数贡献 90 × 2 位，所有三位数贡献 900 × 3 位。逐段减去整组长度，最多经过十来个分组，就能确定目标属于几位数。

digitsInBlock = digitLength × 9 × start

完整过程

  1. 令 digitLength = 1、start = 1、count = 9。
  2. 若 n > digitLength × count，减去整个分组，并把三项分别扩展到下一位数。
  3. 进入目标分组后，用 start + (n - 1) / digitLength 的整数部分得到目标整数。
  4. 用 (n - 1) % digitLength 得到目标数字在该整数中的下标。
  5. 把目标整数转成字符串，读取该下标即可。

为什么统一使用 n − 1

题目位置从 1 开始，而整数偏移和字符串下标从 0 开始。先减一，可同时把“第几个整数”和“整数内第几位”转换成零基偏移，避免整除边界落到下一个整数。

正确性证明

引理 1：跳过循环结束时，目标必定位于当前 digitLength 位数分组。循环只在目标位置严格超过整组长度时跳过，因此不会越过包含目标的分组；每次又完整扣除一个更短位数分组，所以剩余位置相对当前分组仍然准确。

引理 2：start + floor((n - 1) / digitLength) 是包含目标位的整数。当前分组每个整数恰贡献 digitLength 位，把零基数字偏移按该长度分组，商就是相对 start 的整数偏移。

引理 3：(n - 1) % digitLength 是目标在该整数内的零基下标。按除法定理，余数正是未组成完整整数块的位数。

结论：算法先由引理 1 找到正确位数段，再由引理 2 找到正确整数，最后由引理 3 读取正确位置，因此返回第 n 位数字。

边界处理

  • n = 1 直接定位整数 1 的首位。
  • n = 9 仍在一位数段；判断必须使用严格大于，而不是大于等于。
  • n = 10 是二位数段的第一位，n - 1 可正确定位整数 10 的下标 0。
  • 虽然参数是 32 位整数，分组乘积可能更大；Java/C++ 中间量使用 64 位整数。

复杂度

分组数与 n 的十进制位数成正比，时间复杂度为 O(log₁₀ n)，额外空间为 O(log₁₀ n)（目标整数转字符串）；若用数学取位，可做到 O(1) 额外空间。

替代方案

  • 二分查找：定义前 x 个整数一共产生多少位，然后二分第一个覆盖位置 n 的整数。可行，但计数函数和边界更繁琐。
  • 数学取位：无需转字符串，通过除以适当的 10 的幂取出目标位。空间更少，但可读性略差。
  • 直接拼接：只适合非常小的演示输入；对最大约束会消耗不可接受的时间与内存。

面试追问

  • 如果序列从 0 开始，第一组的起点和数量如何变化？
  • 如果把所有整数写成二进制，分组公式如何改写？
  • 如何不转字符串而直接取得目标位？
  • 若 n 扩展到 1018，哪些乘法需要防溢出？

常见错误

  • 忘记把一基位置转换为零基偏移，导致整除边界错一位。
  • 使用 n >= blockSize 跳组，使分组最后一位被错误跳过。
  • Java/C++ 全程使用 32 位 int，计算 digitLength × count 时溢出。
  • 误以为目标整数的最后一位总是答案，忽略整数内部下标。

class Solution {
    public int findNthDigit(int n) {
        long remaining = n;
        long digitLength = 1;
        long start = 1;
        long count = 9;

        while (remaining > digitLength * count) {
            remaining -= digitLength * count;
            digitLength++;
            start *= 10;
            count *= 10;
        }

        long number = start + (remaining - 1) / digitLength;
        int index = (int) ((remaining - 1) % digitLength);
        return Long.toString(number).charAt(index) - '0';
    }
}
