Problem

题意

给定整数 tomatoSlices 与 cheeseSlices，分别表示现有番茄片与奶酪片数量。你只能制作下列两种汉堡，并且必须把两种原料都恰好用完。

巨无霸汉堡

Jumbo
T4 片番茄 C1 片奶酪

小皇堡

Small
T2 片番茄 C1 片奶酪

返回 [total_jumbo, total_small]，即「巨无霸数量、小皇堡数量」。若不存在非负整数方案，返回空数组 []。

函数签名

numOfBurgers(tomatoSlices: integer, cheeseSlices: integer) → integer[]

Solution

准备好揭晓了吗？

题解默认收起。建议先在原料台走完一遍，再查看公式与代码。

Full Explanation

题解：解一个二元一次方程组

核心洞察

设巨无霸数量为 x，小皇堡数量为 y。每个汉堡都消耗 1 片奶酪，因此总汉堡数一定是 cheeseSlices。

4x + 2y = tomatoSlices
x + y = cheeseSlices

把第二式乘 2 后从第一式相减，得到 2x = tomatoSlices - 2 × cheeseSlices。

完整过程

  1. 番茄片总数必须是偶数，因为两种汉堡消耗的番茄片都是偶数。
  2. 由方程组算出 x = tomatoSlices / 2 - cheeseSlices。
  3. 再算 y = cheeseSlices - x，等价于 2 × cheeseSlices - tomatoSlices / 2。
  4. 只有当 x ≥ 0 且 y ≥ 0 时才是合法方案，否则返回 []。

也可以把合法范围写成 2 × cheeseSlices ≤ tomatoSlices ≤ 4 × cheeseSlices，再加上番茄片为偶数。方程组若有解，解是唯一的。

正确性证明

必要性

假设存在合法方案 (x, y)。按配方统计原料，必有 4x + 2y = tomatoSlices 与 x + y = cheeseSlices。两式消元得到算法计算的 x，随后 y = cheeseSlices - x。因为汉堡数量不能为负，所以算法的非负检查是必要的；左式为偶数，因此番茄奇偶检查也是必要的。

充分性

若番茄数为偶数，且算法算出的 x、y 都是非负整数，则 x + y = cheeseSlices。同时由 x = tomatoSlices / 2 - cheeseSlices 可得 4x + 2y = tomatoSlices。所以制作这两类汉堡会恰好用完全部原料，算法返回的方案合法。

唯一性

两个独立线性方程决定唯一的 x 和 y。因此题目不存在多个不同的合法答案。

边界情况

  • tomatoSlices = 0 且 cheeseSlices = 0：返回 [0,0]。
  • 番茄片为奇数：不可能完全消耗，返回 []。
  • 番茄少于 2 × cheeseSlices：即使全做小皇堡也不够。
  • 番茄多于 4 × cheeseSlices：即使全做巨无霸也用不完。
  • 只有一种原料为 0：除非两者都为 0，否则无解。

复杂度

只做常数次算术与判断：时间复杂度 O(1)，额外空间复杂度 O(1)（不计返回数组）。

四语言完整代码

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<Integer> numOfBurgers(int tomatoSlices, int cheeseSlices) {
        if ((tomatoSlices & 1) != 0) {
            return new ArrayList<>();
        }

        int jumbo = tomatoSlices / 2 - cheeseSlices;
        int small = cheeseSlices - jumbo;

        if (jumbo < 0 || small < 0) {
            return new ArrayList<>();
        }
        return Arrays.asList(jumbo, small);
    }
}

替代方案

枚举巨无霸数量：从 0 枚举到 cheeseSlices，检查剩余汉堡是否满足番茄约束。它更直观，但最坏时间复杂度为 O(cheeseSlices)，在上限 107 下没有必要。

范围判断后直接计算：先验证番茄为偶数且位于 [2C, 4C]，再计算答案。与当前方案同为 O(1)，只是判断条件的表达不同。

面试追问

  • 为什么合法答案最多只有一个？请用方程组或“把小皇堡升级为巨无霸”的视角解释。
  • 如果新增第三种汉堡，方程数少于未知数时会发生什么？如何描述全部解？

  • 能否只用范围条件判断有解，而不先计算 x、y？

常见错误

  • 只判断番茄为偶数，却忘记答案数量必须非负。
  • 把返回顺序写反；题目要求先巨无霸、后小皇堡。
  • 使用浮点数求解后直接取整，掩盖本来无解的输入。
  • 错误地拒绝 (0, 0)；它对应合法答案 [0,0]。
  • 通过循环逐个制作汉堡，使常数问题退化为线性问题。
