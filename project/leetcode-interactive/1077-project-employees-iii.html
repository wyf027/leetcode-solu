项目员工 III

在每个项目的成员中，找出经验年限最高的员工；若最高值并列，保留所有并列员工。

MEDIUM付费题窗口函数 / 分组最大值

题目

给定项目成员关系表 Project 和员工信息表 Employee。请为每个项目返回经验年限最多的员工，结果包含 project_id 与 employee_id。同一项目出现最高经验并列时，所有并列员工都应返回；结果顺序不限。

Project

列类型说明

employee_idint员工编号

Employee

列类型说明

namevarchar(10)姓名
experience_yearsint经验年限

约束

  • Project 的 (project_id, employee_id) 组合唯一，一个员工可参与多个项目。
  • Employee.employee_id 唯一；项目中的员工编号可在员工表中找到。
  • 每个项目至少有一名员工，经验年限为非负整数；并列最大值必须全部保留。

完整题解

核心洞察：问题不是“每组取第一条”，而是“每组保留所有最大值”。窗口函数 DENSE_RANK() 正好给并列最大者相同的第 1 名。

完整过程

  1. 按 employee_id 连接两张表，为每条项目成员关系补上经验年限。
  2. 按 project_id 分区，在每个分区内按 experience_years DESC 排名。
  3. 筛选排名为 1 的记录，只投影题目要求的两列。

正确性证明

对任意项目 p，窗口分区恰好包含该项目的全部员工。降序稠密排名会将经验最大值对应的每一行赋值为 1，其他行的排名大于 1。因此筛选 ranking = 1 不遗漏任何最高经验员工，也不会包含经验更少的员工。此结论对每个分区独立成立，故结果对全部项目正确。

边界情况

  • 项目只有一名员工：该员工自然为第 1 名。
  • 全部员工经验相同：全部返回。
  • 一名员工参与多个项目：在各项目分区中独立参与排名。
  • 结果无排序要求；如展示需要，可额外按项目和员工编号排序，但不影响语义。

复杂度

设连接后共有 N 条项目成员记录。窗口排序通常需要 O(N log N) 时间（数据库可按分区优化），窗口结果占 O(N) 级别空间。实际执行计划受索引与数据库实现影响。

替代方案

也可先按项目聚合出 MAX(experience_years)，再连接回明细表。这种写法兼容不支持窗口函数的数据库，但需要多一次聚合结果连接。相关子查询也能表达，但大型数据上往往更难优化。

可提交 SQL（MySQL 8+）

WITH ranked AS (
  SELECT
    p.project_id,
    p.employee_id,
    DENSE_RANK() OVER (
      PARTITION BY p.project_id
      ORDER BY e.experience_years DESC
    ) AS experience_rank
  FROM Project AS p
  JOIN Employee AS e
    ON e.employee_id = p.employee_id
)
SELECT project_id, employee_id
FROM ranked
WHERE experience_rank = 1;

import java.util.*;

class Solution {
    // projectRows: [projectId, employeeId]
    // employees: [employeeId, experienceYears]
    public List<int[]> mostExperienced(int[][] projectRows, int[][] employees) {
        Map<Integer, Integer> exp = new HashMap<>();
        for (int[] e : employees) exp.put(e[0], e[1]);
        Map<Integer, Integer> max = new HashMap<>();
        for (int[] row : projectRows) {
            int years = exp.get(row[1]);
            max.merge(row[0], years, Math::max);
        }
        List<int[]> answer = new ArrayList<>();
        for (int[] row : projectRows)
            if (exp.get(row[1]).equals(max.get(row[0])))
                answer.add(new int[]{row[0], row[1]});
        return answer;
    }
}
function mostExperienced(projectRows, employees) {
  const experience = new Map(employees.map(([id, years]) => [id, years]));
  const maximum = new Map();
  for (const [projectId, employeeId] of projectRows) {
    const years = experience.get(employeeId);
    maximum.set(projectId, Math.max(maximum.get(projectId) ?? -Infinity, years));
  }
  return projectRows.filter(([projectId, employeeId]) =>
    experience.get(employeeId) === maximum.get(projectId)
  );
}
from typing import List

class Solution:
    def most_experienced(
        self, project_rows: List[List[int]], employees: List[List[int]]
    ) -> List[List[int]]:
        experience = {employee_id: years for employee_id, years in employees}
        maximum = {}
        for project_id, employee_id in project_rows:
            years = experience[employee_id]
            maximum[project_id] = max(maximum.get(project_id, -1), years)
        return [
            [project_id, employee_id]
            for project_id, employee_id in project_rows
            if experience[employee_id] == maximum[project_id]
        ]
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> mostExperienced(
        const vector<vector<int>>& projectRows,
        const vector<vector<int>>& employees) {
        unordered_map<int, int> experience, maximum;
        for (const auto& e : employees) experience[e[0]] = e[1];
        for (const auto& row : projectRows)
            maximum[row[0]] = max(maximum[row[0]], experience[row[1]]);
        vector<vector<int>> answer;
        for (const auto& row : projectRows)
            if (experience[row[1]] == maximum[row[0]]) answer.push_back(row);
        return answer;
    }
};

面试追问

  • 为什么不用 ROW_NUMBER？ 它会在并列者中强行只选一行，除非另做处理。
  • 不用窗口函数怎么写？ 先连接并按项目求最大经验，再把最大值连接回项目员工明细。
  • 如何优化？ 关注 Project(employee_id)、Employee(employee_id) 以及项目分区相关索引，并以执行计划为准。

常见错误

  • 按全表求一个最大值，忘记按项目分组。
  • 使用 LIMIT 1 或 ROW_NUMBER，丢失并列员工。
  • 只返回经验年限，没有返回题目要求的员工编号。
  • 连接条件写错，造成笛卡尔积或成员重复。
