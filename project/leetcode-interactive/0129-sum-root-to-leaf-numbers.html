求根节点到叶节点数字之和 Sum Root to Leaf Numbers

从根节点携带一个前缀数字向下。每经过一个节点，旧数字左移一位，再把当前数字装进个位； 只有抵达叶子时，这个路径数字才进入最终总和。

Problem brief

先看任务，不展开题解

树中每个节点只包含 0 到 9。每条从根到叶子的路径按顺序拼成一个十进制数，返回所有路径数字之和。

输入与约束

参数 root 是二叉树根节点；叶子节点指没有左右孩子的节点。

  • 节点数量在 [1, 1000] 范围内。
  • 0 ≤ Node.val ≤ 9。
  • 树深不超过 10。
  • 最终答案保证可放入 32 位整数。

本题输入不含字符串空格；若页面需要展示空格，将使用可见符号 ␠。

官方样例 1 OUTPUT 25
root = [1,2,3]

路径数字：12 与 13，总和为 25。

官方样例 2 OUTPUT 1026
root = [4,9,0,5,1]

路径数字：495、491、40，总和为 1026。

题解

主线采用携带前缀的递归 DFS；展开后查看完整推导、边界、复杂度、替代方案、追问、错误清单和四语言代码。

核心洞察

前缀 prefix 已经表示从根到父节点的数字。进入当前节点后，十进制左移一位并写入当前数字： current = prefix × 10 + node.val。

若当前节点是叶子，直接返回 current；否则把它继续传给左右子树，并把两边返回值相加。

完整过程

  1. 空节点贡献 0。
  2. 计算当前路径数字。
  3. 叶子直接结算当前数字。
  4. 非叶子递归左右子树并求和。
时间 O(n) 递归栈 O(h)

边界与替代方案

  • 节点值 0 仍然参与十进制拼接，例如 4 → 0 表示 40。
  • 单节点树本身就是一条根到叶路径。
  • 防御性处理空树时返回 0。
  • 迭代 DFS 可用栈保存 [node, prefix]，避免语言递归限制，但面试表达略重。
  • BFS 同样可行，却需要队列保存一整层状态；本题没有层序收益。

面试追问与常见错误

  • 追问：若数字串很长怎么办？改用大整数或边走边取模。
  • 追问：如何返回每条路径？在叶子处记录路径或数字，而不是只累加。
  • 错误：在每个节点都加入总和，导致非叶节点也被结算。
  • 错误：用字符串反复拼接，增加额外分配。
  • 错误：把路径值做成全局变量，回溯时忘记恢复。 
class Solution {
    public int sumNumbers(TreeNode root) {
        return dfs(root, 0);
    }

    private int dfs(TreeNode node, int prefix) {
        if (node == null) return 0;

        int current = prefix * 10 + node.val;
        if (node.left == null && node.right == null) {
            return current;
        }

        return dfs(node.left, current) + dfs(node.right, current);
    }
}
