3842. 切换打开灯泡

每次出现都是一次翻转：出现奇数次的灯泡最终亮，偶数次的最终灭。

输入：bulbs = [10, 30, 20, 10] · 输出：[20, 30]

题意

有编号 1 到 100 的灯泡，初始全部关闭。依次处理 bulbs[i]：关闭就打开，打开就关闭。返回最终仍打开的编号，按升序排列。

约束：1 ≤ bulbs.length ≤ 100，1 ≤ bulbs[i] ≤ 100。

示例读法

bulbs = [10, 30, 20, 10]：10 被翻转两次而关闭，20 与 30 各翻转一次而打开。

交互：逐次点亮 / 熄灭

用英文逗号分隔 1 到 100 的整数；这里仅展示发生过的灯泡。

准备就绪：按“下一步”处理第一盏灯。

最终打开：待处理

题解

核心洞察

同一编号每出现一次就异或一次：state[x] ^= 1。因为编号范围固定为 1 到 100，长度为 101 的状态数组既直接又稳定；从 1 扫到 100 即自然得到升序输出。

完整过程

  1. 建立 state[101]，均为 0。
  2. 遍历 bulbs，对 state[x] 异或 1。
  3. 扫描 1 到 100，将状态为 1 的下标加入答案。

边界

  • 重复偶数次：最终关闭。
  • 只触发 100：上界编号可被正确收集。
  • 全部偶数次：答案为空数组。

复杂度

时间 O(n + 100)，空间 O(100)；这里 100 是固定灯泡范围。

替代方案

也可用集合保存当前打开的编号，最后排序；更通用，但固定范围下数组更直观。

面试追问与常见错误

若编号范围扩大到未知整数，改用哈希集合；若需要持续查询，可维护有序集合。常见错误是忘记输出必须升序，或把偶数次翻转误判为打开。 

import java.util.*;

class Solution {
    public List<Integer> toggleLightBulbs(List<Integer> bulbs) {
        int[] state = new int[101];
        for (int bulb : bulbs) state[bulb] ^= 1;
        List<Integer> ans = new ArrayList<>();
        for (int bulb = 1; bulb <= 100; bulb++) if (state[bulb] == 1) ans.add(bulb);
        return ans;
    }
}
function toggleLightBulbs(bulbs) {
  const state = new Array(101).fill(0);
  for (const bulb of bulbs) state[bulb] ^= 1;
  const ans = [];
  for (let bulb = 1; bulb <= 100; bulb++) if (state[bulb] === 1) ans.push(bulb);
  return ans;
}
class Solution:
    def toggleLightBulbs(self, bulbs: List[int]) -> List[int]:
        state = [0] * 101
        for bulb in bulbs:
            state[bulb] ^= 1
        return [bulb for bulb in range(1, 101) if state[bulb]]
