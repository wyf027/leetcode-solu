最大价值和与
最小价值和的差值

Difference Between Maximum and Minimum Price Sum

一棵树，多种起点。选择一个根，让两条路径的价值差尽可能大。

官方题目 ↗

01 / 题意

给定有 n 个节点的无向树，编号为 0…n−1。数组 edges 中的每项 [aᵢ,bᵢ] 表示一条无向边；price[i] 是节点 i 的价值。

一条路径的价值和等于沿途所有节点的价值之和。任选节点 root 作为起点，考察从它出发的所有简单路径（包含仅有 root 自身的路径），其最大价值和减去最小价值和就是这个根的开销。返回所有根的开销最大值。

maxOutput(n, edges, price) → 最大开销（整数）
n: int
edges: int[n - 1][2]
price: int[n]

约束

  • 1 ≤ n ≤ 10⁵，edges.length = n − 1。
  • 0 ≤ aᵢ, bᵢ ≤ n − 1，edges 保证表示一棵合法的树。
  • price.length = n，1 ≤ price[i] ≤ 10⁵。

02 / 官方示例

示例 1

n = 6
edges = [[0,1],[1,2],[1,3],[3,4],[3,5]]
price = [9,8,7,6,10,5]
输出：24

选节点 2 为根。最大路径 [2,1,3,4] 的价值和为 7+8+6+10=31；最小路径 [2] 的价值和为 7。差值为 24，也是所有根中的最大开销。

选节点 0 为根。最大路径 [0,1,2] 的价值和为 3；最小路径 [0] 的价值和为 1。差值 2 是最大开销。

05 / 独立题解

洞察、逐步演示与四语言实现

核心洞察 / 路径扣掉一个端点

所有价值均为正，所以从 root 出发的最小价值和必然是 price[root]。目标因此变成：在任意简单路径中，选择一个端点作为 root，最大化“路径总和 − 该端点价值”。

仅为计算把树固定根在 0；这不限制题目中可选的 root。用两种向下路径状态，把所有方向的答案合并起来：

  • A[u]：从 u 向下到某节点的路径，所有节点都计价的最大和。
  • B[u]：同样从 u 向下，但扣除末端节点价值的最大和。允许末端就是 u，此时为 0。

初始 a=price[u], b=0。逐个合并孩子 v，先使用已处理孩子的旧状态更新全局答案：

answer = max(answer, a + B[v], b + A[v])
// 然后扩展以 u 为起点的单支路径：
a = max(a, price[u] + A[v])
b = max(b, price[u] + B[v])

两个答案候选分别扣除 v 一侧或已处理一侧的端点。a、b 已含 u（b=0 的退化情况表示扣除 u），而孩子状态不含 u，所以连接时无需额外加减 u。

完整过程
  1. 构造邻接表，从 0 出发生成 parent 与遍历顺序 order。
  2. 反转 order 处理；树中每个孩子都在父节点之前完成，无需递归。
  3. 每个 u 从单节点状态开始，先计算跨分支答案，再把孩子合并进 a、b。
  4. 把 a、b 写入 A[u]、B[u]，最终返回全局最大值。
示例中，节点 3 合并孩子后得到 A[3]=16、B[3]=6。节点 1 合并节点 2 后，a=15、b=8；再合并节点 3 时，候选为 15+6=21 和 8+16=24。后者对应扣除端点 2 的路径 2→1→3→4。


正确性
状态归纳：叶节点只有自身，A=price、B=0 正确。任意向下路径要么停在 u，要么进入唯一孩子 v；取初始化与所有 price[u]+孩子状态的最大值，就穷尽了 A、B 的全部选择。
答案覆盖：固定计算根为 0 后，每条路径都有唯一的最高节点 u。它要么以 u 为端点，要么分布在 u 的两个不同孩子子树中。初始化让 u 自身成为已处理侧；顺序合并时，两条分支一定在后处理的那一侧加入时相遇。a+B[v] 与 b+A[v] 覆盖扣除两个端点的两种方向。
合法性：先计算答案再更新状态，使已处理侧与当前孩子侧互不重叠；连接后是一条简单路径，且恰好扣除一个端点。每个候选合法，每个最优候选被覆盖，因此全局最大值就是题目答案。


复杂度与边界
  • 时间 O(n)：建图、遍历和合并均线性。
  • 空间 O(n)：邻接表、parent、order、两个状态数组。
  • n=1：没有边，答案保持 0。
  • 长链：使用迭代顺序，避免递归栈溢出。
  • 答案最多 (n−1)×10⁵，小于 10¹⁰；Java 用 long、C++ 用 long long。JavaScript Number 的精确整数范围足够。
常见错误
  • 先扩展 a、b，再计算答案：会重复使用同一个孩子分支。
  • 把 B 的初值写成 price[u]：忘记扣除末端。
  • 只算“向下最优路径”：遗漏跨兄弟子树的路径。
  • 只保留普通最大路径和：扣哪个端点也会影响答案。
  • Java/C++ 用 32 位整数累计；在 10⁵ 节点长链中溢出。


替代方案
枚举每个根：遍历所有起点并计算最远路径和，O(n²) 时间、O(n) 空间，易理解但不适用于最大规模。
换根 DP：先计算各节点向子树方向的最大贡献，再把父方向的贡献传给孩子；借助孩子贡献的最大值和次大值，排除当前孩子。对每个根求最大路径和再减自身，时间和空间均 O(n)，但需要两轮传递与排除逻辑。
面试追问
  • 若允许负价值？最小路径未必是单节点，这里的化简不成立；可以改为换根求每个根的最大与最小路径和。
  • 如何返回路径？为状态记录末端及选择的孩子，在刷新答案时记下两个端点，再用父指针还原唯一路径。
  • 为什么可以固定根 0？它只定义处理顺序与最高节点，答案通过两侧状态覆盖所有可能的实际根。
  • 能直接用递归吗？递推相同，但最坏 10⁵ 层深度不稳妥，迭代后序更适合本题约束。

import java.util.*;

class Solution {
    public long maxOutput(int n, int[][] edges, int[] price) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
        }
        int[] parent = new int[n], order = new int[n];
        Arrays.fill(parent, -1);
        order[0] = 0;
        int size = 1;
        for (int i = 0; i < size; i++) {
            int u = order[i];
            for (int v : g.get(u)) {
                if (v == parent[u]) continue;
                parent[v] = u;
                order[size++] = v;
            }
        }
        long[] full = new long[n], cut = new long[n];
        long ans = 0;
        for (int i = n - 1; i >= 0; i--) {
            int u = order[i];
            long a = price[u], b = 0;
            for (int v : g.get(u)) {
                if (v == parent[u]) continue;
                ans = Math.max(ans, Math.max(a + cut[v], b + full[v]));
                a = Math.max(a, price[u] + full[v]);
                b = Math.max(b, price[u] + cut[v]);
            }
            full[u] = a;
            cut[u] = b;
        }
        return ans;
    }
}

from typing import List

class Solution:
    def maxOutput(self, n: int, edges: List[List[int]],
                  price: List[int]) -> int:
        g = [[] for _ in range(n)]
        for u, v in edges:
            g[u].append(v)
            g[v].append(u)
        parent = [-1] * n
        order = [0]
        i = 0
        while i < len(order):
            u = order[i]
            i += 1
            for v in g[u]:
                if v == parent[u]:
                    continue
                parent[v] = u
                order.append(v)
        full, cut = [0] * n, [0] * n
        ans = 0
        for u in reversed(order):
            a, b = price[u], 0
            for v in g[u]:
                if v == parent[u]:
                    continue
                ans = max(ans, a + cut[v], b + full[v])
                a = max(a, price[u] + full[v])
                b = max(b, price[u] + cut[v])
            full[u], cut[u] = a, b
        return ans
