唯一中间元素

数组长度为奇数。只需锁定中间下标，再问它的值在整个数组里是否恰好出现一次。

可视化把“中间位置”和“同值计数”分开呈现，避免把中位数误当成题意。

主线解法

令 mid = nums[n / 2]，单次扫描统计等于 mid 的元素；计数为 1 即返回 true。

时间
O(n)
额外空间
O(1)

题意与示例

给定奇数长度整数数组 nums。若其下标中间元素在数组中恰好出现一次，返回 true；否则返回 false。

  • 示例：nums = [1, 2, 3]，中间值为 2，仅出现一次，输出 true。
  • 示例：nums = [1, 2, 2]，中间值为 2，出现两次，输出 false。
  • 约束：1 <= nums.length <= 100；长度为奇数；1 <= nums[i] <= 100。

题解：先定位，再计数

核心洞察

“中间元素”指数组原始顺序的中间下标 n / 2，不是排序后的中位数。取出该值后扫描整个数组，仅在匹配时累加。

完整过程

  1. 计算 midIndex = nums.length / 2。
  2. 记录 target = nums[midIndex]。
  3. 遍历 nums 并统计 target 出现次数；最终判断 count 是否为 1。

边界与替代方案

长度为 1 时唯一元素必然通过。也可用哈希表预统计全部频次，时间仍为 O(n) 但空间为 O(n)，本题没有必要。

面试追问与常见错误

若数组不是奇数长度，应先明确中间位置定义。常见错误是排序数组（改变了“中间下标”的语义）或误用 nums[nums.length / 2] 的值作下标。
