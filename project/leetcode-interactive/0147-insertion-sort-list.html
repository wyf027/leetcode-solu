对链表进行插入排序 插入编排台

让节点依次驶入有序区：每轮摘下一个待处理节点，从哨兵后向右寻找插入点，再用常数次指针重连把它放回正确位置。

任务边界

输入单链表 head，返回按节点值升序排列的新链表头。复用原节点，只改变 next；节点数 1～5000，节点值范围 -5000～5000。

Problem / 题意

逐个插入有序前缀

给定单链表 head，使用插入排序把所有节点按值升序排列，并返回排序后链表的头。每轮从未处理区摘下一个节点，在已排序前缀中找到第一个更大的节点之前插入。

官方示例 1
head = [4,2,1,3]

输出：[1,2,3,4]

官方示例 2
head = [-1,5,3,4,0]

输出：[-1,0,3,4,5]

关键边界
head = [1]

输出：[1]

核心洞察

哨兵固定入口，每轮把一个节点插入有序区

用值小于所有合法节点的哨兵统一处理“插到最前面”。从原链表依次摘下 current，令 prev 从哨兵出发，停在最后一个值不大于 current 的节点处，再把 current 插入 prev 与 prev.next 之间。链表节点本身就是排序元素，无需数组。

完整过程

  1. 建立哨兵 dummy，初始有序区为空。
  2. 保存 current.next，避免摘链后丢失未处理区。
  3. 从 dummy 向右寻找插入位置 prev。
  4. 重连两条 next，把 current 插入后继续处理。

边界与复杂度

  • 单节点直接成为完整有序区。
  • 负数、重复值与已有序输入都适用。
  • 时间 O(n²)，额外空间 O(1)，复用全部节点。

替代方案取舍

把值复制到数组后排序可做到 O(n log n)，但会额外占用 O(n) 空间且没有练到链表重连。归并排序同样能做到 O(n log n) 且 O(log n) 递归栈，是第 148 题的更优主线；本题明确要求演示插入排序。

常见错误

  • 插入前没有保存 current.next，未处理链丢失。
  • 寻找位置时使用错误比较符，重复值顺序不稳定。
  • 忘记让 current.next 指向 prev.next，造成断链。
  • 返回 head 而不是 dummy.next，漏掉新头节点。

面试追问

为什么需要哨兵？它消除“插到头部”的单独分支。
如何保持稳定性？查找时越过所有 ≤ current.val 的节点。
能否加速？链表归并排序可把时间降为 O(n log n)。 
class Solution {
    public ListNode insertionSortList(ListNode head) {
        ListNode dummy = new ListNode(Integer.MIN_VALUE);
        ListNode current = head;
        while (current != null) {
            ListNode next = current.next;
            ListNode prev = dummy;
            while (prev.next != null && prev.next.val <= current.val) {
                prev = prev.next;
            }
            current.next = prev.next;
            prev.next = current;
            current = next;
        }
        return dummy.next;
    }
}
