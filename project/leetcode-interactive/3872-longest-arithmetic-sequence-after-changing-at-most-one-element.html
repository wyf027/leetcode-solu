替换最多一个元素后的最长等差子数组

把相邻差值看成一条“差分轨道”：一次替换只会重写目标元素左右两格差分。交互台展示如何把两段同公差轨道桥接起来。

子数组必须连续；允许不替换，或把一个元素替换为任意整数。

题意与示例

给定整数数组 nums。若一个连续片段的相邻差值全部相同，它就是等差子数组。至多替换一个元素后，返回可选的最大长度。

示例 1

nums = [9, 7, 5, 10, 1]

把 nums[3] = 10 改成 3，得到公差 -2 的整段，长度为 5。

示例 2

nums = [1, 2, 6, 7]

可把首元素改为 -2，选取 [-2, 2, 6]，答案为 3。

约束与观察

  • 4 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁵
  • 替换内部元素时，左右两个新差值必须相同；因此两侧邻居之和必须为偶数。
不直接枚举公差。先压缩原数组为差分数组，再记录每个差值连续段在左右方向的长度。

题解：差分连续段 + 一次桥接

核心洞察

令 d[i] = nums[i + 1] - nums[i]。一段等差子数组等价于 d 中一段全相等区间。替换 nums[i] 只影响 d[i - 1] 与 d[i]：若两侧邻居差 nums[i+1]-nums[i-1] 为偶数，可把它改成中点，使这两个差值都变为其一半。

完整过程

  1. 预处理每个差分位置左侧、右侧连续相同差分的长度。
  2. 每个原始连续段都能在一端多接一个元素，给出“端点替换”候选。
  3. 枚举内部下标 i；若两邻居之差为偶数，以中点差值为目标，合并左段、两条被修补差分和右段。

边界、复杂度与替代方案

原数组本身完全等差时答案就是 n。中点不是整数时不能让内部两条差同时相等。时间 O(n)，空间 O(n)；可用分段数组压缩空间，但实现更易出错。

面试追问

若允许替换 k 个元素，可把“修改次数”加入区间 DP；若要求子序列而非子数组，则连续差分段模型不再适用。

常见错误

  • 把子数组误写成子序列。
  • 内部修补时忘记检查邻居和的奇偶性。
  • 只合并两边段，漏掉中间被改写的两条差分。
class Solution {
    public int longestArithmetic(int[] nums) {
        int n = nums.length, m = n - 1, ans = 3;
        int[] d = new int[m], left = new int[m], right = new int[m];
        for (int i = 0; i < m; i++) d[i] = nums[i + 1] - nums[i];
        for (int i = 0; i < m; i++) left[i] = i > 0 && d[i] == d[i - 1] ? left[i - 1] + 1 : 1;
        for (int i = m - 1; i >= 0; i--) right[i] = i + 1 < m && d[i] == d[i + 1] ? right[i + 1] + 1 : 1;
        for (int i = 0; i < m; i++) ans = Math.max(ans, left[i] == m ? n : left[i] + 2);
        for (int i = 1; i + 1 < n; i++) {
            int sum = nums[i + 1] - nums[i - 1];
            if ((sum & 1) != 0) continue;
            int x = sum / 2, a = i >= 2 && d[i - 2] == x ? left[i - 2] : 0;
            int b = i + 1 < m && d[i + 1] == x ? right[i + 1] : 0;
            ans = Math.max(ans, a + 2 + b + 1);
        }
        return Math.min(n, ans);
    }
}

class Solution:
    def longestArithmetic(self, nums: List[int]) -> int:
        n = len(nums); m = n - 1; d = [nums[i + 1] - nums[i] for i in range(m)]
        left = [1] * m; right = [1] * m; ans = 3
        for i in range(1, m): left[i] = left[i - 1] + 1 if d[i] == d[i - 1] else 1
        for i in range(m - 2, -1, -1): right[i] = right[i + 1] + 1 if d[i] == d[i + 1] else 1
        for k in left: ans = max(ans, n if k == m else k + 2)
        for i in range(1, n - 1):
            total = nums[i + 1] - nums[i - 1]
            if total % 2: continue
            x = total // 2
            a = left[i - 2] if i >= 2 and d[i - 2] == x else 0
            b = right[i + 1] if i + 1 < m and d[i + 1] == x else 0
            ans = max(ans, a + 2 + b + 1)
        return min(n, ans)
class Solution {
public:
    int longestArithmetic(vector<int>& nums) {
        int n = nums.size(), m = n - 1, ans = 3;
        vector<int> d(m), l(m, 1), r(m, 1);
        for (int i = 0; i < m; ++i) d[i] = nums[i + 1] - nums[i];
        for (int i = 1; i < m; ++i) if (d[i] == d[i - 1]) l[i] = l[i - 1] + 1;
        for (int i = m - 2; i >= 0; --i) if (d[i] == d[i + 1]) r[i] = r[i + 1] + 1;
        for (int x : l) ans = max(ans, x == m ? n : x + 2);
        for (int i = 1; i + 1 < n; ++i) {
            int s = nums[i + 1] - nums[i - 1]; if (s & 1) continue;
            int x = s / 2, a = i >= 2 && d[i - 2] == x ? l[i - 2] : 0;
            int b = i + 1 < m && d[i + 1] == x ? r[i + 1] : 0;
            ans = max(ans, a + 2 + b + 1);
        }
        return min(n, ans);
    }
