01 / Problem

题意

给定一个 n × n 的网格 grid。其中 0 表示海洋，1 表示陆地。请在所有海洋单元格中，找到“到最近陆地的距离”最大的一个，并返回这个最大距离。

如果地图上没有陆地，或没有海洋，则不存在符合要求的单元格，返回 -1。

distance = |x₀ − x₁| + |y₀ − y₁|

函数签名

maxDistance(grid: integer[][]) → integer

约束

  • n == grid.length
  • n == grid[i].length
  • 1 ≤ n ≤ 100
  • grid[i][j] 只会是 0 或 1
坐标从 (0, 0) 开始。上下左右移动一步，曼哈顿距离增加 1；不允许对角线一步到达。
Example 01
输入：grid = [[1,0,1],[0,0,0],[1,0,1]] 输出：2 解释：海洋单元格 (1,1) 到最近陆地的距离为 2，且这是所有海洋单元格中的最大值。
Example 02
输入：grid = [[1,0,0],[0,0,0],[0,0,0]] 输出：4 解释：海洋单元格 (2,2) 到唯一陆地 (0,0) 的曼哈顿距离为 4。

Solution / Revealed

从所有陆地同时出发

关键不是为每一格海洋分别寻找陆地，而是把问题反过来：让所有陆地作为同一批起点，同时向海洋扩散。

核心洞察

将所有陆地同时放入队列，等价于建立一个“超级源点”。广度优先搜索按距离从小到大访问格子，因此海洋第一次被访问时，得到的就是它到最近陆地的距离。最后一层被访问的海洋，距离最大。

完整过程

  1. 扫描网格，把所有陆地坐标加入队列，并统计陆地数量。
  2. 若陆地为 0，或陆地占满网格，直接返回 -1。
  3. 按层取出队列中的格子，访问其上下左右邻格。
  4. 每个尚未访问的海洋第一次入队时标记为已访问。
  5. 每扩展完一层，距离加 1；队列清空时，当前层数就是答案。

正确性

1

最短性：BFS 按路径长度递增扩展。任一海洋第一次被访问时，不可能存在更短的陆地到它的路径尚未处理。

2

最近性：所有陆地在第 0 层同时入队，所以最先到达某海洋的波前，必然来自距离它最近的某块陆地。

3

最大性：各海洋的首次到达层数已是其最短距离；最后一个非空海洋层的层数，自然是这些最短距离中的最大值。

边界与复杂度

  • 全是陆地：没有候选海洋，返回 -1。
  • 全是海洋：没有距离参照，返回 -1。
  • 仅一块陆地：最远点通常在某个最远角落。
  • 时间复杂度：O(n²)，每个格子至多入队一次。
  • 空间复杂度：O(n²)，队列最坏容纳平方级格子；原地标记可省去额外访问矩阵。

替代方案

两遍动态规划：先从左上到右下，用上方和左方更新距离；再从右下到左上，用下方和右方更新。最终取海洋格距离最大值，同样是 O(n²)。

逐海洋搜索：对每个海洋单独寻找最近陆地，最坏可达 O(n⁴)，会重复计算，不适合作为主解。

常见错误

  • 从单块陆地开始 BFS，只得到相对某一块陆地的距离。
  • 海洋出队后才标记访问，导致同一格被重复入队。
  • 把对角线当作一步，误用了八方向距离。
  • 层数从 0 或 1 开始处理不一致，答案多 1 或少 1。
  • 忘记全陆地、全海洋都应返回 -1。

JavaMulti-source BFS
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int maxDistance(int[][] grid) {
        int n = grid.length;
        Queue<int[]> queue = new ArrayDeque<>();

        for (int row = 0; row < n; row++) {
            for (int col = 0; col < n; col++) {
                if (grid[row][col] == 1) {
                    queue.offer(new int[] {row, col});
                }
            }
        }

        if (queue.isEmpty() || queue.size() == n * n) {
            return -1;
        }

        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        int distance = -1;

        while (!queue.isEmpty()) {
            int size = queue.size();
            distance++;

            for (int i = 0; i < size; i++) {
                int[] cell = queue.poll();

                for (int[] direction : directions) {
                    int nextRow = cell[0] + direction[0];
                    int nextCol = cell[1] + direction[1];

                    if (nextRow < 0 || nextRow >= n
                            || nextCol < 0 || nextCol >= n
                            || grid[nextRow][nextCol] != 0) {
                        continue;
                    }

                    grid[nextRow][nextCol] = 1;
                    queue.offer(new int[] {nextRow, nextCol});
                }
            }
        }

        return distance;
    }
}
JavaScriptMulti-source BFS
/**
 * @param {number[][]} grid
 * @return {number}
 */
var maxDistance = function(grid) {
    const n = grid.length;
    const queue = [];

    for (let row = 0; row < n; row++) {
        for (let col = 0; col < n; col++) {
            if (grid[row][col] === 1) {
                queue.push([row, col]);
            }
        }
    }

    if (queue.length === 0 || queue.length === n * n) {
        return -1;
    }

    const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    let head = 0;
    let distance = -1;

    while (head < queue.length) {
        const levelEnd = queue.length;
        distance++;

        while (head < levelEnd) {
            const [row, col] = queue[head++];

            for (const [dr, dc] of directions) {
                const nextRow = row + dr;
                const nextCol = col + dc;

                if (nextRow < 0 || nextRow >= n
                    || nextCol < 0 || nextCol >= n
                    || grid[nextRow][nextCol] !== 0) {
                    continue;
                }

                grid[nextRow][nextCol] = 1;
                queue.push([nextRow, nextCol]);
            }
        }
    }

    return distance;
};
Python 3Multi-source BFS
from collections import deque
from typing import List


class Solution:
    def maxDistance(self, grid: List[List[int]]) -> int:
        n = len(grid)
        queue = deque()

        for row in range(n):
            for col in range(n):
                if grid[row][col] == 1:
                    queue.append((row, col))

        if not queue or len(queue) == n * n:
            return -1

        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
        distance = -1

        while queue:
            distance += 1

            for _ in range(len(queue)):
                row, col = queue.popleft()

                for dr, dc in directions:
                    next_row = row + dr
                    next_col = col + dc

                    if not (0 <= next_row < n and 0 <= next_col < n):
                        continue
                    if grid[next_row][next_col] != 0:
                        continue

                    grid[next_row][next_col] = 1
                    queue.append((next_row, next_col))

        return distance
C++Multi-source BFS
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int maxDistance(vector<vector<int>>& grid) {
        int n = static_cast<int>(grid.size());
        queue<pair<int, int>> cells;

        for (int row = 0; row < n; ++row) {
            for (int col = 0; col < n; ++col) {
                if (grid[row][col] == 1) {
                    cells.push({row, col});
                }
            }
        }

        if (cells.empty() || static_cast<int>(cells.size()) == n * n) {
            return -1;
        }

        const int directions[4][2] = {
            {1, 0}, {-1, 0}, {0, 1}, {0, -1}
        };
        int distance = -1;

        while (!cells.empty()) {
            int levelSize = static_cast<int>(cells.size());
            ++distance;

            while (levelSize-- > 0) {
                auto [row, col] = cells.front();
                cells.pop();

                for (const auto& direction : directions) {
                    int nextRow = row + direction[0];
                    int nextCol = col + direction[1];

                    if (nextRow < 0 || nextRow >= n
                        || nextCol < 0 || nextCol >= n
                        || grid[nextRow][nextCol] != 0) {
                        continue;
                    }

                    grid[nextRow][nextCol] = 1;
                    cells.push({nextRow, nextCol});
                }
            }
        }

        return distance;
    }
};
