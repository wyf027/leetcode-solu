圆和矩形
是否有重叠

在二维坐标系里，一个圆靠近一个轴对齐矩形。你的任务只有一个：判断它们是否至少共享一个点，边界接触也算重叠。

01 / Problem

题意与输入形式

准确转述

圆由 (radius, xCenter, yCenter) 表示；轴对齐矩形由 (x1, y1, x2, y2) 表示，其中前一坐标是左下角，后一坐标是右上角。如果存在一个点同时属于圆与矩形，就返回 true，否则返回 false。圆周和矩形边界上的点都属于图形。

函数签名

checkOverlap(
  radius, xCenter, yCenter,
  x1, y1, x2, y2
) -> boolean

官方示例

Example 01 
输入：radius = 1, xCenter = 0, yCenter = 0,
      x1 = 1, y1 = -1, x2 = 3, y2 = 1
输出：true
解释：圆和矩形共享点 (1, 0)。
Example 02 
输入：radius = 1, xCenter = 1, yCenter = 1,
      x1 = 1, y1 = -3, x2 = 2, y2 = -1
输出：false
Example 03 
输入：radius = 1, xCenter = 0, yCenter = 0,
      x1 = -1, y1 = 0, x2 = 0, y2 = 1
输出：true

约束

  • 1 <= radius <= 2000
  • -10^4 <= xCenter, yCenter <= 10^4
  • -10^4 <= x1 < x2 <= 10^4
  • -10^4 <= y1 < y2 <= 10^4

Solution / Nearest Point

把二维相交，变成一次距离比较

核心洞察

矩形中离圆心最近的点，决定了圆能否碰到矩形。对圆心的横、纵坐标分别做区间截断（clamp），即可得到这个最近点。若最近点到圆心的距离不超过半径，两个闭图形就有公共点。

关键公式

nearestX = clamp(xCenter, x1, x2)
nearestY = clamp(yCenter, y1, y2)
dx² + dy² ≤ radius²

完整过程

  1. 定位横坐标。 若圆心在矩形横向范围左侧，最近点横坐标是 x1；在右侧则是 x2；范围内就是 xCenter。
  2. 定位纵坐标。 对 [y1, y2] 做相同处理，得到 nearestY。
  3. 计算平方距离。 令 dx = xCenter - nearestX、dy = yCenter - nearestY，比较 dx*dx + dy*dy 与 radius*radius。
  4. 包含相切。 使用 <=，因为只要边界共享一个点也属于重叠。

正确性证明

引理：分别把圆心坐标截断到矩形的横、纵闭区间，所得点 P 是矩形内距离圆心最近的点。因为二维欧氏距离平方是两个非负坐标差平方之和，而每个坐标上的截断都独立取得该维度的最小差。

充分性：若 dist(P, center) ≤ radius，则 P 同时位于矩形和圆内，所以二者重叠。

必要性：若二者重叠，存在矩形内点 Q 也在圆内。由最近点定义，dist(P, center) ≤ dist(Q, center) ≤ radius。故算法返回 true。充分性与必要性同时成立，算法正确。

边界与复杂度

  • 圆心在矩形内部：最近点就是圆心，平方距离为 0。
  • 圆与边或顶点相切：等号成立，应返回 true。
  • 圆心与矩形横向或纵向范围重合：相应维度距离为 0。
  • 负坐标不改变算法。
  • 时间复杂度：O(1)。
  • 空间复杂度：O(1)。

class Solution {
    public boolean checkOverlap(int radius, int xCenter, int yCenter,
                                int x1, int y1, int x2, int y2) {
        int nearestX = Math.max(x1, Math.min(xCenter, x2));
        int nearestY = Math.max(y1, Math.min(yCenter, y2));

        int dx = xCenter - nearestX;
        int dy = yCenter - nearestY;
        return dx * dx + dy * dy <= radius * radius;
    }
}

替代方案

分类讨论九个区域：按圆心在矩形左/中/右与下/中/上的组合，分别计算到边或顶点的距离。可行，但分支多、容易遗漏相切。

矩形膨胀直觉：把矩形向四周扩张半径并补上四个圆角，再判断圆心是否落入。它适合解释 Minkowski 和，但直接编码仍会回到最近点距离。

常见错误

只检查四个顶点

圆可能穿过矩形的一条边，却不包含任何矩形顶点。

只检查圆心

圆心在矩形外时，圆仍可能与矩形相交。

使用严格小于

题目把边界算在图形内，因此相切必须返回 true。

先开平方

直接比较平方距离更简洁，也避免不必要的浮点运算。
