文件组合

接收方给出一个目标编号和。找出所有由至少两个连续正整数构成、且总和刚好等于该目标的文件编号组合。

官方题意

每部分文件编号为正整数，且一个传输组合至少含两个文件。返回连续编号总和为 target 的全部组合；每个组合升序，不同组合按第一个编号升序。

示例 1target = 12
输出：[[3, 4, 5]]
示例 2target = 18
输出：[[3,4,5,6],[5,6,7]]
约束1 ≤ target ≤ 10⁵
仅允许连续正整数。

题解：正整数滑动窗口

核心洞察

窗口内始终是连续正整数。右端加一会让和增大；当和超过目标时，从左端依次减去，直到不超过目标。和相等且窗口长度至少为二时，记录当前窗口。

完整过程

  1. 初始化 left = 1、right = 2 与窗口和。
  2. 若和小于目标，右端扩张；若大于目标，左端收缩。
  3. 若相等，复制区间 [left, right]，再扩张继续寻找。

边界与复杂度

target ≤ 2 没有合法组合。每个端点只向右移动，时间 O(target)，除返回结果外空间 O(1)。

替代方案、追问与常见错误

替代：枚举长度并用等差数列求和，判断整除性。追问：若允许负数，窗口单调性消失，应改用前缀和加哈希。常见错误：允许长度为一、遗漏命中后继续搜索，或把组合排序成降序。 
/** @param {number} target @return {number[][]} */
var fileCombination = function(target) {
  const ans = [];
  let left = 1, right = 2, sum = 3;
  while (left < right) {
    if (sum === target) {
      ans.push(Array.from({ length: right - left + 1 }, (_, i) => left + i));
    }
    if (sum >= target) sum -= left++;
    else sum += ++right;
  }
  return ans;
};

class Solution {
    public int[][] fileCombination(int target) {
        List<int[]> ans = new ArrayList<>();
        int left = 1, right = 2, sum = 3;
        while (left < right) {
            if (sum == target) {
                int[] sequence = new int[right - left + 1];
                for (int i = 0; i < sequence.length; i++) {
                    sequence[i] = left + i;
                }
                ans.add(sequence);
            }
            if (sum >= target) sum -= left++;
            else sum += ++right;
        }
        return ans.toArray(new int[ans.size()][]);
    }
}
