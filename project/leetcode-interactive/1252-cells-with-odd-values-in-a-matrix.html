奇数值单元格
的数目

给每个指定位置对应的整行与整列各加一次。操作结束后，数一数矩阵里有多少个单元格是奇数。

题号 1252简单Cells with Odd Values in a Matrix非付费题
Problem

先把操作做准确

所有下标均从 0 开始

给定一个初始值全为 0 的 m × n 矩阵，以及二维数组 indices。其中每一项 indices[i] = [rᵢ, cᵢ] 指定一行和一列。

依次处理每个位置时，需要同时执行：

  1. 把第 rᵢ 行的所有单元格加 1；
  2. 把第 cᵢ 列的所有单元格加 1。

返回全部操作完成后，矩阵中值为奇数的单元格数量。

Examples

官方示例

示例 1

输入
m = 2, n = 3, indices = [[0,1],[1,1]]
输出
6
解释

初始矩阵为 [[0,0,0],[0,0,0]]。第一次操作后为 [[1,2,1],[0,1,0]]，最终为 [[1,3,1],[1,3,1]]，共 6 个奇数。

示例 2

输入
m = 2, n = 2, indices = [[1,1],[0,0]]
输出
0
解释

最终矩阵为 [[2,2],[2,2]]，所有单元格都是偶数，因此答案为 0。

先形成自己的判断

题解被单独收起。建议先观察：一个单元格最终是奇数，究竟取决于哪些操作次数？

Solution

只记录奇偶，不必保存数值

核心洞察

单元格 (i, j) 被增加的总次数，等于“第 i 行被选中的次数 + 第 j 列被选中的次数”。我们只关心最终值的奇偶性，因此每次遇到某行或某列时，只需把它的奇偶状态翻转。

计数公式

设奇数状态的行数为 oddRows，奇数状态的列数为 oddCols：

答案 = oddRows × (n − oddCols)
＋ (m − oddRows) × oddCols

完整过程

  1. 建立长度为 m 的行奇偶数组和长度为 n 的列奇偶数组，初始均为偶数状态。
  2. 遍历 indices。对每个 [r, c]，分别翻转 rows[r] 与 cols[c]。
  3. 统计奇数状态的行数 oddRows 和奇数状态的列数 oddCols。
  4. “奇行 + 偶列”与“偶行 + 奇列”会产生奇数值，两类单元格互不重叠，按公式相加即可。

正确性证明

任一单元格 (i,j) 的值是行 i 与列 j 的操作次数之和。和为奇数，当且仅当两者奇偶性不同。因此，所有奇数单元格恰好分成两类：奇行中的偶列，共 oddRows × (n − oddCols) 个；偶行中的奇列，共 (m − oddRows) × oddCols 个。公式完整覆盖且没有重复，所以算法正确。

复杂度与边界

时间 O(m + n + k)空间 O(m + n)

其中 k = indices.length。重复操作同一行或列会互相抵消奇偶状态；只有一行/一列、所有操作集中于同一位置、答案为 0 或 m × n 都无需特殊分支。

四种语言实现

class Solution {
    public int oddCells(int m, int n, int[][] indices) {
        boolean[] rows = new boolean[m];
        boolean[] cols = new boolean[n];

        for (int[] index : indices) {
            rows[index[0]] = !rows[index[0]];
            cols[index[1]] = !cols[index[1]];
        }

        int oddRows = 0;
        int oddCols = 0;
        for (boolean row : rows) {
            if (row) oddRows++;
        }
        for (boolean col : cols) {
            if (col) oddCols++;
        }

        return oddRows * (n - oddCols)
             + (m - oddRows) * oddCols;
    }
}

 * @param {number} m
 * @param {number} n

var oddCells = function(m, n, indices) {
    const rows = Array(m).fill(false);
    const cols = Array(n).fill(false);

    for (const [r, c] of indices) {
        rows[r] = !rows[r];
        cols[c] = !cols[c];
    }

    const oddRows = rows.filter(Boolean).length;
    const oddCols = cols.filter(Boolean).length;

    return oddRows * (n - oddCols)
         + (m - oddRows) * oddCols;
};

class Solution:
    def oddCells(
        self,
        m: int,
        n: int,

        rows = [False] * m
        cols = [False] * n

            rows[r] = not rows[r]

class Solution {
public:
    int oddCells(int m, int n,
                 vector<vector<int>>& indices) {
        vector<bool> rows(m, false);
        vector<bool> cols(n, false);

        for (const auto& index : indices) {
            rows[index[0]] = !rows[index[0]];
            cols[index[1]] = !cols[index[1]];
        }

        int oddRows = count(rows.begin(), rows.end(), true);
        int oddCols = count(cols.begin(), cols.end(), true);

        return oddRows * (n - oddCols)
             + (m - oddRows) * oddCols;
    }

替代方案

直接模拟矩阵：每次真实增加一整行和一整列，最后遍历矩阵计数。直观但时间为 O(k(m+n)+mn)，空间为 O(mn)。

逐格检查：先统计每行每列的操作次数，再遍历全部 mn 个格子判断奇偶，时间为 O(k+mn)。比直接模拟好，但不如公式计数。

常见错误

  • 只给交点单元格加 1，而不是给整行和整列分别加 1。
  • 把奇行 × 奇列计入答案；奇数加奇数其实得到偶数。
  • 遇到重复行列时一直累加整数，却忽略只需维护奇偶状态。
  • 公式漏掉“偶行 + 奇列”这一类，或两项中的行列维度写反。
Interview

面试追问

为什么布尔数组就足够？

最终只判断奇偶。一次加 1 会翻转奇偶性，两次又回到原状态，所以无需保存具体次数。

能否做到 O(1) 额外空间？

若允许修改输入或有额外位编码约束，可以尝试原地标记；在一般输入模型下，需要区分 m 行和 n 列的独立奇偶状态，O(m+n) 是清晰且稳妥的方案。

如果每次不是加 1，而是加任意整数 x 呢？

偶数 x 不改变奇偶，奇数 x 仍等价于一次翻转。只要按 x 的奇偶决定是否翻转对应行列即可。

如果要返回所有奇数坐标呢？

公式只能给数量。此时遍历每个坐标，找出行列奇偶状态不同的位置，时间会增加到 O(mn)。
