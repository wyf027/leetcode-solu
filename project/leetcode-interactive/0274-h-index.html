01 / BRIEF

题目说明

paidOnly: false

给定整数数组 citations，其中 citations[i] 表示研究者第 i 篇论文的引用次数。返回这名研究者的 h 指数。

定义：h 指数是满足下述条件的最大整数 h：研究者至少有 h 篇论文，并且其中每篇都至少被引用 h 次。
官方示例 1
输入：citations = [3,0,6,1,5] 输出：3 解释：共有 5 篇论文，引用次数分别为 3、0、6、1、5。 至少有 3 篇论文的引用次数不低于 3，因此 h = 3。
官方示例 2
输入：citations = [1,3,1] 输出：1

约束

  • n == citations.length
  • 1 <= n <= 5000
  • 0 <= citations[i] <= 1000

03 / SOLUTION

完整题解

默认收起
?

先尝试从定义判断答案。准备好后，再展开推导、证明与代码。

核心洞察

答案一定在 [0,n]。因此无需保存超过 n 的具体引用次数：它们对所有候选 h 的意义相同，都可以放入桶 n。随后从高到低累计论文数，第一次满足“累计数 ≥ 当前刻度”的刻度就是最大答案。

复杂度

建桶与逆向扫描都至多访问 n 个元素，时间复杂度 O(n)；计数桶长度为 n+1，空间复杂度 O(n)。

完整过程

  1. 令 n = citations.length，创建长度为 n+1 的数组 bucket。
  2. 对每个引用次数 c，执行 bucket[min(c,n)]++。最后一桶表示“引用次数至少为 n”。
  3. 令 papers = 0，从 h = n 递减到 0，把 bucket[h] 加入 papers。
  4. 此时 papers 恰好是引用次数不低于 h 的论文数。若 papers >= h，立即返回 h。

正确性证明

引理：扫描到刻度 h 时，累计变量 papers 等于引用次数至少为 h 的论文数量。原因是逆向扫描已经合并了桶 h,h+1,...,n；所有引用次数超过 n 的论文也被安全地包含在桶 n 中。

充分性：当 papers >= h，至少有 h 篇论文各自被引用至少 h 次，所以 h 是合法的 h 指数候选。

最大性：算法从 n 向 0 递减检查。返回 h 之前的所有更大刻度都不满足条件，因此不存在更大的合法值。故返回值正是最大 h 指数。

边界情况

  • 只有一篇且引用为 0：答案为 0。
  • 所有引用为 0：扫描最终在 h=0 成立。
  • 所有引用都很高：桶 n 的数量为 n，答案为 n。
  • 重复引用次数：直接在同一桶累加。

替代方案

先将数组降序排序，找到最大的下标区间，使第 h 篇论文的引用次数至少为 h。实现更直观，时间复杂度为 O(n log n)，若允许原地排序，额外空间可视语言实现而定。

面试追问

  • 若输入已按升序排列，能否二分？
  • 若论文流式到达，如何动态维护 h 指数？
  • 为何超过 n 的引用次数可以截断为 n？
  • 能否在约束 citations[i] ≤ 1000 时改用固定桶？

常见错误

  • 把条件写成 papers > h，漏掉刚好相等。
  • 误以为 h 是引用次数之和或平均值。
  • 建长度 n 的桶后直接访问 bucket[n]。
  • 正向累计桶，导致统计的是“至多 h”而非“至少 h”。

四语言实现

class Solution {
    public int hIndex(int[] citations) {
        int n = citations.length;
        int[] bucket = new int[n + 1];

        for (int citation : citations) {
            bucket[Math.min(citation, n)]++;
        }

        int papers = 0;
        for (int h = n; h >= 0; h--) {
            papers += bucket[h];
            if (papers >= h) {
                return h;
            }
        }
        return 0;
    }
}

class Solution:
    def hIndex(self, citations: List[int]) -> int:
        n = len(citations)
        bucket = [0] * (n + 1)

        for citation in citations:
            bucket[min(citation, n)] += 1

        papers = 0
        for h in range(n, -1, -1):
            papers += bucket[h]
            if papers >= h:
                return h

        return 0
