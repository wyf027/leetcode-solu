美丽子集的数目

The Number of Beautiful Subsets

在所有由下标决定的非空子集中，数出那些不会让任意两个元素相差恰好 k 的选择。

中等 数组哈希表回溯组合数学 非付费题
Problem

题意

给定正整数数组 nums 和正整数 k。如果一个子集中不存在两个整数，使它们的绝对差恰好等于 k，这个子集就是美丽子集。

返回 nums 中非空美丽子集的数量。子集按被选择的下标区分，因此相同数值位于不同下标时，可能形成不同子集。

示例 1
输入：nums = [2, 4, 6], k = 2
输出：4
解释：[2]、[4]、[6]、[2, 6] 是全部美丽子集。
示例 2
输入：nums = [1], k = 1
输出：1
解释：唯一的非空子集 [1] 满足条件。

约束

  • 1 <= nums.length <= 18
  • 1 <= nums[i], k <= 1000

Walkthrough

题解：用频次表守住选择边界

核心洞察

对每个下标只有“跳过”和“选择”两条路。若当前值为 x，只要已选集合里没有 x-k 与 x+k，就能安全选择它。

状态设计

freq[v] 记录值 v 在当前路径里出现了几次。频次而非布尔值能正确处理重复元素，回溯时也能精确撤销。

完整过程

  1. 从下标 0 开始深度优先搜索。
  2. 无条件进入“不选当前元素”的分支。
  3. 检查当前值 x 的两个冲突值；若它们在路径中都没有出现，则把 x 加入频次表，进入“选择”分支。
  4. 选择分支返回后，将 x 的频次减一，恢复现场。
  5. 走到数组末尾时得到一个合法子集；最终减去空集。
answer = DFS(0) − 1

正确性说明

  1. 覆盖性：每个下标都恰好枚举“不选/选择”，因此所有按下标区分的子集都被考虑。
  2. 合法性：只有在路径中不存在与当前值相差 k 的元素时才允许选择，所以任何到达叶子的路径都美丽。
  3. 无重复：一条根到叶的决策序列唯一对应一组下标，因此每个子集只计数一次。
  4. 结论：叶子数包含且仅包含所有美丽子集；减去空集后即为题目答案。

边界与复杂度

  • 单元素数组：两个分支中去掉空集，答案为 1。
  • 重复值：差为 0，而 k > 0，重复值之间不冲突。
  • 时间复杂度：O(2^n)。
  • 空间复杂度：O(n)，来自递归栈与当前路径频次。

替代方案

可以按模 k 分组，再将同组数值排序，把每个不同数值及其出现次数压成带权“打家劫舍”动态规划。它可做到约 O(n log n)，但在 n <= 18 时，回溯更直接且足够。

Java 
import java.util.HashMap;
import java.util.Map;

class Solution {
    private int[] nums;
    private int k;
    private final Map<Integer, Integer> freq = new HashMap<>();

    public int beautifulSubsets(int[] nums, int k) {
        this.nums = nums;
        this.k = k;
        return dfs(0) - 1;
    }

    private int dfs(int index) {
        if (index == nums.length) return 1;

        int total = dfs(index + 1);
        int value = nums[index];
        if (freq.getOrDefault(value - k, 0) == 0
                && freq.getOrDefault(value + k, 0) == 0) {
            freq.put(value, freq.getOrDefault(value, 0) + 1);
            total += dfs(index + 1);
            freq.put(value, freq.get(value) - 1);
        }
        return total;
    }
}
JavaScript 
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var beautifulSubsets = function(nums, k) {
    const freq = new Map();

    function dfs(index) {
        if (index === nums.length) return 1;

        let total = dfs(index + 1);
        const value = nums[index];
        if (!freq.get(value - k) && !freq.get(value + k)) {
            freq.set(value, (freq.get(value) || 0) + 1);
            total += dfs(index + 1);
            freq.set(value, freq.get(value) - 1);
        }
        return total;
    }

    return dfs(0) - 1;
};
Python 3 
from collections import Counter
from typing import List


class Solution:
    def beautifulSubsets(self, nums: List[int], k: int) -> int:
        freq = Counter()

        def dfs(index: int) -> int:
            if index == len(nums):
                return 1

            total = dfs(index + 1)
            value = nums[index]
            if freq[value - k] == 0 and freq[value + k] == 0:
                freq[value] += 1
                total += dfs(index + 1)
                freq[value] -= 1
            return total

        return dfs(0) - 1
C++ 
class Solution {
    vector<int> nums;
    unordered_map<int, int> freq;
    int k;

    int dfs(int index) {
        if (index == nums.size()) return 1;

        int total = dfs(index + 1);
        int value = nums[index];
        if (freq[value - k] == 0 && freq[value + k] == 0) {
            ++freq[value];
            total += dfs(index + 1);
            --freq[value];
        }
        return total;
    }

public:
    int beautifulSubsets(vector<int>& input, int difference) {
        nums = input;
        k = difference;
        return dfs(0) - 1;
    }
};

面试追问

  • 为什么必须用频次而不是 Set？
  • 若 n 扩大到 10^5，如何按余数分组并做动态规划？
  • 值 x 出现 c 次时，“至少选一个”的方案数为什么是 2^c - 1？

常见错误

  • 忘记减掉空集。
  • 把值相同的元素合并，漏掉按下标区分的方案。
  • 回溯返回后没有恢复频次，污染兄弟分支。
  • 只检查某一个方向，却又没有先排序数组。
