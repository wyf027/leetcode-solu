给定一个不含重复元素的整数集合 nums，返回它的所有子集。结果中不能出现重复子集，子集顺序不限。

空集也是子集；若集合有 n 个元素，结果共有 2ⁿ 个子集。

Core insight

核心洞察

对 nums[index] 只有“不放入当前子集”和“放入当前子集”两种互斥选择。递归处理下一个下标；当 index === nums.length 时，一条完整决策链结束，复制当前路径作为一个答案。

Full trace

完整过程

对 nums = [1,2,3]，搜索树依次枚举 000、001、010、011、100、101、110、111。每一位表示对应元素不选或选，因此 8 个叶子与 8 个子集一一对应，既不会遗漏也不会重复。

Limits

边界与复杂度

  • 空集合：只有一个子集 []。
  • 无重复元素：题目保证输入是集合，不需要排序去重。
  • 时间：O(n · 2ⁿ)，复制每个子集需要最多 O(n)。
  • 辅助空间：O(n) 递归栈与路径；答案本身占 O(n · 2ⁿ)。

Alternatives

替代方案

  • 迭代扩展：从空集开始，每读入一个数，把它追加到现有每个子集的副本中；写法短，空间规律直观。
  • 位掩码：枚举 0 到 2ⁿ−1，用每一位决定元素是否出现；适合强调位运算。
  • 循环式回溯：每到一个节点就收集路径，再从 start 向后选择；同样经典，但“选/不选”证明更直接。

Interview follow-up

面试追问

为什么不会有重复？
每个元素只在固定层做一次二选一；一条位序列唯一对应一个子集。
输入有重复元素怎么办？
先排序，同层枚举时跳过相同值；那将变成“子集 II”的去重回溯。
能把辅助栈去掉吗？
可以用位掩码迭代枚举，但输出规模仍然不可避免。

Pitfalls

常见错误

  • 收集答案时直接保存可变路径引用，导致所有答案最后相同。
  • “选”分支返回后忘记删除末尾元素，污染后续分支。
  • 遗漏空集，或只收集非空路径。
  • 把输出顺序当成唯一正确顺序。

class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> answer = new ArrayList<>();
        backtrack(nums, 0, new ArrayList<>(), answer);
        return answer;
    }

    private void backtrack(
        int[] nums,
        int index,
        List<Integer> path,
        List<List<Integer>> answer
    ) {
        if (index == nums.length) {
            answer.add(new ArrayList<>(path));
            return;
        }

        backtrack(nums, index + 1, path, answer);

        path.add(nums[index]);
        backtrack(nums, index + 1, path, answer);
        path.remove(path.size() - 1);
    }
}

 * @param {number[]} nums
 * @return {number[][]}

var subsets = function (nums) {
    const answer = [];
    const path = [];

    function backtrack(index) {
        if (index === nums.length) {
            answer.push([...path]);
            return;
        }

        backtrack(index + 1);

        path.push(nums[index]);
        backtrack(index + 1);
        path.pop();
    }

    backtrack(0);
    return answer;
};
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        answer = []
        path = []

        def backtrack(index: int) -> None:
            if index == len(nums):
                answer.append(path.copy())
                return

            backtrack(index + 1)

            path.append(nums[index])
            backtrack(index + 1)
            path.pop()

        backtrack(0)
        return answer
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> answer;
        vector<int> path;
        backtrack(nums, 0, path, answer);
        return answer;
    }

private:
    void backtrack(
        const vector<int>& nums,
        int index,
        vector<int>& path,
        vector<vector<int>>& answer
    ) {
        if (index == static_cast<int>(nums.size())) {
            answer.push_back(path);
            return;
        }

        backtrack(nums, index + 1, path, answer);

        path.push_back(nums[index]);
        backtrack(nums, index + 1, path, answer);
        path.pop_back();
    }
};
