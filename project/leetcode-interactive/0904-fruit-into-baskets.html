水果成篮

Fruit Into Baskets · 中等

数组哈希表滑动窗口

题目

一排果树由整数数组 fruits 表示，fruits[i] 是第 i 棵树的水果类型。你可从任意位置开始并持续向右，每棵树恰好摘一个水果。你只有两个容量不限的篮子，每个篮子只能装一种水果；遇到第三种类型时必须停止。返回最多能连续采摘的水果数。

等价目标：寻找只包含至多两种不同整数的最长连续子数组。

约束与签名

int totalFruit(int[] fruits)

  • 1 ≤ fruits.length ≤ 10⁵
  • 0 ≤ fruits[i] < fruits.length
  • 答案是连续区间长度，不允许跳过中间树。

官方示例

输入：fruits = [1,2,1]
输出：3
解释：可以采摘全部 3 棵树。
输入：fruits = [0,1,2,2]
输出：3
解释：选择连续区间 [1,2,2]。
输入：fruits = [1,2,3,2,2]
输出：4
解释：选择连续区间 [2,3,2,2]。
输入：fruits = [3,3,3,1,2,1,1,2,3,3,4]
输出：5
解释：选择连续区间 [1,2,1,1,2]。

题解：至多两种的滑动窗口

核心洞察

任意合法采摘过程必然对应一个连续子数组，并且其中最多有两种水果。维护窗口 [left, right]：右端不断扩张；当计数表出现第三种类型时，从左端逐个移除，直到重新只剩两种。

完整过程

  1. 令 left = 0，用哈希表记录窗口内各类型数量。
  2. 右指针依次扫描数组，把当前水果加入计数表。
  3. 若不同类型超过 2，持续减少 fruits[left] 的计数；计数归零便删除该键，然后右移 left。
  4. 窗口恢复合法后，用其长度更新答案。

正确性

不变式：每轮更新答案时，窗口内至多包含两种水果。扩张造成第三种类型后，收缩循环恰好删除最短必要前缀，因此所得窗口是以当前 right 结尾的最长合法窗口。算法检查了每个右端点的最优合法窗口，所以其中最大长度就是全局最优答案。

边界与复杂度

  • 单个元素、全相同或恰好两种：窗口无需收缩。
  • 类型频繁交替：计数归零时必须删除键。
  • 左右指针各自至多走 n 步；时间 O(n)，计数表最多短暂含 3 个键，额外空间 O(1)（按本题容量约束）。

四语言完整代码

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int totalFruit(int[] fruits) {
        Map<Integer, Integer> count = new HashMap<>();
        int left = 0, answer = 0;
        for (int right = 0; right < fruits.length; right++) {
            count.merge(fruits[right], 1, Integer::sum);
            while (count.size() > 2) {
                int fruit = fruits[left++];
                int remain = count.get(fruit) - 1;
                if (remain == 0) count.remove(fruit);
                else count.put(fruit, remain);
            }
            answer = Math.max(answer, right - left + 1);
        }
        return answer;
    }
}

var totalFruit = function(fruits) {
    const count = new Map();
    let left = 0, answer = 0;
    for (let right = 0; right < fruits.length; right++) {
        count.set(fruits[right], (count.get(fruits[right]) || 0) + 1);
        while (count.size > 2) {
            const fruit = fruits[left++];
            count.set(fruit, count.get(fruit) - 1);
            if (count.get(fruit) === 0) count.delete(fruit);
        }
        answer = Math.max(answer, right - left + 1);
    }
    return answer;
};
from typing import List

class Solution:
    def totalFruit(self, fruits: List[int]) -> int:
        count = {}
        left = answer = 0
        for right, fruit in enumerate(fruits):
            count[fruit] = count.get(fruit, 0) + 1
            while len(count) > 2:
                removed = fruits[left]
                count[removed] -= 1
                if count[removed] == 0:
                    del count[removed]
                left += 1
            answer = max(answer, right - left + 1)
        return answer
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int totalFruit(vector<int>& fruits) {
        unordered_map<int, int> count;
        int left = 0, answer = 0;
        for (int right = 0; right < (int)fruits.size(); ++right) {
            ++count[fruits[right]];
            while (count.size() > 2) {
                int fruit = fruits[left++];
                if (--count[fruit] == 0) count.erase(fruit);
            }
            answer = max(answer, right - left + 1);
        }
        return answer;
    }
};

替代方案

可只记录“最近一段连续相同水果”的长度，用常数变量推导新窗口，空间更少但更难证明和维护；通用的计数滑窗更适合面试表达。暴力枚举起点需要 O(n²)，无法承受 10⁵ 数据。

面试追问

  • 若有 k 个篮子？把条件改为计数表大小不超过 k，复杂度仍为 O(n)。
  • 若要求返回区间？更新答案时同步保存最佳左右边界。
  • 为何 while 不能写成 if？一次加入新类型后，可能要移除多个左端元素才会消失一种类型。

常见错误

  • 只减少计数却不删除零计数键，导致类型数永远超限。
  • 在窗口恢复合法之前更新答案。
  • 把题目误解为任选元素，忽略采摘必须连续。
