3917. 统计下标的相反奇偶性得分

对每个下标 i，只数右侧 j > i 中与 nums[i] 奇偶性不同的元素。把“右侧还剩什么”浓缩成奇数、偶数两个计数器，就能在线性时间内得到每一格分数。

题意

只看右边的相反奇偶数

给定正整数数组 nums。answer[i] 是满足 i < j < n 且 nums[i] 与 nums[j] 奇偶性不同的下标 j 数量。返回整张答案表。

示例

nums = [1, 2, 3, 4]

answer = [2, 1, 1, 0]

约束

1 ≤ nums.length ≤ 100

1 ≤ nums[i] ≤ 100

右侧奇数数量：0
右侧偶数数量：0

准备从最右端开始：右侧暂时没有元素。

先自己推一步

当前数是奇数时，应取哪个后缀计数？先思考，再打开题解核对不变量。

题解

后缀奇偶计数

处理 i 前，odd、even 恰好记录区间 (i, n) 的奇、偶数数量。若 nums[i] 是奇数，答案就是 even；反之就是 odd。写完答案后再更新当前数所属的计数器。

复杂度

O(n) 时间，除答案外 O(1) 空间。

替代方案

双重循环直观但为 O(n²)；本题约束虽小，面试更推荐后缀计数。

常见错误：先把当前数加入计数会把自己算进右侧；或把 j > i 错写成含当前下标。

追问：若要统计“右侧值小于当前值且奇偶不同”，可按值域配合两棵 Fenwick 树维护后缀。

class Solution {
    public int[] countOppositeParity(int[] nums) {
        int n = nums.length, odd = 0, even = 0;
        int[] answer = new int[n];
        for (int i = n - 1; i >= 0; --i) {
            if ((nums[i] & 1) == 1) { answer[i] = even; odd++; }
            else { answer[i] = odd; even++; }
        }
        return answer;
    }
}

from typing import List

class Solution:
    def countOppositeParity(self, nums: List[int]) -> List[int]:
        odd = even = 0
        answer = [0] * len(nums)
        for i in range(len(nums) - 1, -1, -1):
            if nums[i] & 1:
                answer[i] = even
                odd += 1
            else:
                answer[i] = odd
                even += 1
        return answer
