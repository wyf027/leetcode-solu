223. 矩形面积

两个轴对齐矩形的并集面积，等于各自面积之和减去重复计算的相交面积。关键在于用投影端点求出相交宽和高。

Medium几何容斥原理
官方标题

输入
两组左下 / 右上坐标
主线

题意

给定两个轴对齐矩形：第一个由左下角 (ax1, ay1) 与右上角 (ax2, ay2) 定义，第二个由 (bx1, by1) 与 (bx2, by2) 定义。返回两个矩形覆盖区域的总面积。
示例 1
ax1 = -3, ay1 = 0, ax2 = 3, ay2 = 4, bx1 = 0, by1 = -1, bx2 = 9, by2 = 2
输出：45
示例 2
ax1 = -2, ay1 = -2, ax2 = 2, ay2 = 2, bx1 = -2, by1 = -2, bx2 = 2, by2 = 2
输出：16

约束：所有坐标均在 [-10⁴, 10⁴] 内，且每个矩形满足左下坐标严格小于右上坐标。

题解：总和减去被数了两次的那一块

核心洞察

两个独立面积相加会把重叠区域算两遍。只要从 A 与 B 的投影中得到真正相交的区间，就能按 areaA + areaB - overlapWidth × overlapHeight 修正。

完整过程

  1. 计算 areaA = (ax2 - ax1) × (ay2 - ay1) 和 B 的面积。
  2. x 轴相交宽：max(0, min(ax2,bx2) - max(ax1,bx1))。
  3. y 轴相交高同理。
  4. 两者乘积就是重叠面积；从面积和中减去它。
时间复杂度
O(1)：常数个算术与比较。
空间复杂度
O(1)：不依赖输入规模。

替代方案与取舍

扫描格点或做坐标压缩都比问题需要的复杂得多。轴对齐是本题的关键信号：二维相交可拆成两条一维投影的相交。

边界

  • 没有重叠时，宽或高为负，必须用 max(0, ...) 截断。
  • 边界恰好接触时，重叠面积为 0。
  • 一个矩形完全包含另一个时，总面积就是大矩形面积。
  • 坐标可负，不影响宽高差。

常见错误

忘记把负相交长度截为 0，会在两个分离矩形时错误“减去负面积”；把左端取 min、右端取 max 会得到并集区间而不是交集区间。

面试追问

若有多个矩形，简单容斥会出现高阶交集；可用扫描线配合线段树维护活动 y 区间长度。

class Solution {
    public int computeArea(int ax1, int ay1, int ax2, int ay2,
                           int bx1, int by1, int bx2, int by2) {
        int areaA = (ax2 - ax1) * (ay2 - ay1);
        int areaB = (bx2 - bx1) * (by2 - by1);
        int width = Math.max(0, Math.min(ax2, bx2) - Math.max(ax1, bx1));
        int height = Math.max(0, Math.min(ay2, by2) - Math.max(ay1, by1));
        return areaA + areaB - width * height;
    }
}
