最长字符串链

把“添加一个字符”反过来看成“删除一个字符”：每个单词只需向更短的已知状态寻找前身。

题目

给定仅含小写英文字母的数组 words。若在 wordA 的任意位置插入恰好一个字符，且不改变其余字符的相对顺序，就能得到 wordB，则 A 是 B 的前身。

词链中，每个单词都是下一个单词的前身。请从数组中选词，返回最长可构成词链的长度；单个单词也构成长度为 1 的词链。

函数： longestStrChain(words: string[]) → integer

约束

  • 1 ≤ words.length ≤ 1000
  • 1 ≤ words[i].length ≤ 16
  • words[i] 只含小写英文字母

关键定义：相邻单词长度必须恰好相差 1；原字符顺序不能改变。

官方示例

示例 1 输入：words = ["a","b","ba","bca","bda","bdca"] 输出：4 解释：最长词链之一是 ["a","ba","bda","bdca"]。
示例 2 输入：words = ["xbc","pcxbcf","xb","cxbc","pcxbc"] 输出：5 解释：可形成 ["xb","xbc","cxbc","pcxbc","pcxbcf"]。
示例 3 输入：words = ["abcd","dbqca"] 输出：1 解释：["abcd"] 本身是一条最长链；二者不能成链，因为字符次序不符。

核心洞察

将单词按长度升序处理。对当前单词逐一删除字符，得到所有可能的前身；若前身已在哈希表中，则用 dp[word] = max(dp[word], dp[prev] + 1) 转移。

完整过程

  1. 按字符串长度升序排序，确保前身总在当前单词之前处理。
  2. 每个单词的链长初始化为 1。
  3. 枚举当前单词的每个位置，删除该字符形成候选前身。
  4. 从哈希表查询候选前身的最优链长并更新当前值。
  5. 保存当前值，同时维护全局最大值。

正确性

归纳基础：最短单词没有列表中的更短前身，dp 为 1 正确。

归纳步骤：处理单词 w 时，它的所有合法前身一定能通过删除 w 的某一位得到，且已被处理。算法枚举全部删除位置并取最大前身链长加 1，因此既不会漏掉最优链，也不会引入非法链。

结论：每个 dp 值正确，全局最大值即最长字符串链长度。

复杂度与边界

设单词数为 n，最长长度为 L。排序耗时 O(n log n)；构造候选串在多数语言中需 O(L)，总时间 O(n·L²)，空间 O(n)。本题 L ≤ 16。

边界：单词互不相连时答案为 1；重复删除位置可能生成同一字符串，但不影响最大值；前身必须存在于输入数组。

四种语言实现

import java.util.*;

class Solution {
    public int longestStrChain(String[] words) {
        Arrays.sort(words, Comparator.comparingInt(String::length));
        Map<String, Integer> dp = new HashMap<>();
        int answer = 1;
        for (String word : words) {
            int best = 1;
            for (int i = 0; i < word.length(); i++) {
                String prev = word.substring(0, i) + word.substring(i + 1);
                best = Math.max(best, dp.getOrDefault(prev, 0) + 1);
            }
            dp.put(word, best);
            answer = Math.max(answer, best);
        }
        return answer;
    }
}

var longestStrChain = function(words) {
    words.sort((a, b) => a.length - b.length);
    const dp = new Map();
    let answer = 1;
    for (const word of words) {
        let best = 1;
        for (let i = 0; i < word.length; i++) {
            const prev = word.slice(0, i) + word.slice(i + 1);
            best = Math.max(best, (dp.get(prev) || 0) + 1);
        }
        dp.set(word, best);
        answer = Math.max(answer, best);
    }
    return answer;
};

class Solution:

        for word in words:

class Solution {
public:
    int longestStrChain(vector<string>& words) {
        sort(words.begin(), words.end(), [](const string& a, const string& b) {
            return a.size() < b.size();
        });
        unordered_map<string, int> dp;
        int answer = 1;
        for (const string& word : words) {
            int best = 1;
            for (int i = 0; i < (int)word.size(); ++i) {
                string prev = word.substr(0, i) + word.substr(i + 1);
                best = max(best, dp.count(prev) ? dp[prev] + 1 : 1);
            }
            dp[word] = best;
            answer = max(answer, best);
        }
        return answer;
    }
};

替代方案

也可把每个单词视为图节点，再做记忆化 DFS：尝试删除一位后递归查前身。时间量级相近，但迭代 DP 的依赖顺序更直观，也避免递归开销。

逐对比较单词是否为前身需要 O(n²·L)，在 n=1000 时通常不如哈希枚举删除串。

面试追问

  • 如何恢复具体词链？为每个单词额外记录取得最优值的前身，最后从最大值反向追踪。
  • 若允许一次添加多个字符？需要重新定义边，或检查子序列关系，转移规模会扩大。
  • 为什么必须按长度排序？它建立了无环、已计算的依赖顺序。

常见错误

  • 把“前身”误解为连续子串；实际上只要求其余字符相对顺序不变。
  • 只尝试从末尾删字符，遗漏中间或开头插入的情况。
  • 没有按长度排序就读取 dp，导致依赖尚未计算。
  • 把不存在的候选前身也按长度 1 计入，错误得到 2。
  • 返回最长单词长度，而非词链包含的单词数量。
