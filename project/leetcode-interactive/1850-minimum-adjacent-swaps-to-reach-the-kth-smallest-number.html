邻位交换的最小次数

Minimum Adjacent Swaps to Reach the Kth Smallest Number

从同一组数字出发，抵达指定排名的更大数字。先思考，再展开推演。

题目

给定数字字符串 num 和整数 k。将这些数字重新排列，得到所有严格大于原数的不同数字串，按数值递增排列。你要把原串变成其中第 k 个，每次只能交换相邻两个位置，返回所需交换次数的最小值。

数字串长度保持不变，可以含前导零；重复数字不会让同一个结果被重复计数。题目保证第 k 个结果存在。

getMinSwaps(num: string, k: integer) → integer

  • 2 ≤ num.length ≤ 1000
  • 1 ≤ k ≤ 1000
  • num 仅包含字符 0–9。

独立题解

准备好后，展开算法、数字轨道和四语言代码。

核心洞察：先确定目标，再计算移动距离

长度相同的数字串，字典序与数值顺序一致。连续执行 k 次“下一个排列”，就得到目标。之后从左到右固定目标前缀：在尚未固定的后缀中，找到第一个与目标当前位置相等的数字，把它逐格向左交换。

完整过程

  1. 复制原串为目标数组，避免丢失原始起点。
  2. 从右向左找到 target[i] < target[i+1] 的最右位置 i。后缀此时非递增。
  3. 在右侧从后向前找到第一个大于 target[i] 的数，与其交换，再反转 i 后面的后缀。这得到严格下一个排列，重复 k 次。
  4. 遍历位置 i，在工作数组 i 及其右侧找到第一个 target[i]，记下标 j。
  5. 连续交换 j 与 j−1，直到该数字抵达 i，每次答案加一。固定位置 i，继续后面的部分。

为什么正确

下一个排列保留尽可能长的前缀，让最右可提升位置增加最小幅度，并把剩余后缀排成最小顺序，因此没有跳过任何更大的排列。重复 k 次恰好到达所需排名。

对重复数字按从左到右的出现顺序进行匹配。若两个相同数字的匹配交叉，交换它们的身份不会改变最终数字串，却能消除不必要的交叉，所以总存在稳定匹配的最优解。稳定匹配后的任务等价于排序带唯一目标位置的元素：每个逆序对都必须被某次相邻交换消除，一次交换最多消除一个逆序对。逐个取出所需数字并左移，恰好消除它与前方元素的逆序对，从不破坏已固定的前缀。因此交换次数达到逆序对下界，得到最小值。

复杂度与边界

令 n 为字符串长度。k 次排列计算 O(kn)，匹配与邻位搬运最坏 O(n²)，总时间 O(kn+n²)，额外空间 O(n)。答案不超过 n(n−1)/2，n=1000 时为 499500，32 位整数足够。

保留前导零，始终使用字符数组，不将 num 转为整数。重复数字需找后缀第一个匹配位置；某位已匹配时移动距离为零。官方保证目标存在，所以提交代码中的每一次排列都有合法支点；自定义动画对不存在的目标明确报错。全相同字符串无更大排列，不属于官方有效输入。

替代方案

为每个数字建立原位置队列，按目标顺序取出位置，形成稳定映射序列，再用树状数组统计逆序对。交换计数可降为 O(n log n)，总时间 O(kn+n log n)，空间 O(n)，但本题规模直接模拟更简洁。枚举所有排列会产生阶乘开销；BFS 邻位交换也不适合长串。

常见错误

  • 把原数当成第一个妙数，少做一次排列。
  • 直接交换 i 与 j 却只计一次：非相邻交换并非题目操作。
  • 交换支点后未反转后缀，导致跳过排列。
  • 按整数解析而丢失前导零或超过安全整数范围。
  • 选择更靠右的重复数字，引入额外移动。

面试追问

如何加速交换计数？稳定位置映射加树状数组。若 k 极大呢？可以研究按多重集合的排列数量跳过整个前缀块，但必须处理重复数字及大整数。若允许任意两位交换呢？距离不再等价于逆序对，当前计数不适用。

Java

class Solution {
    public int getMinSwaps(String num, int k) {
        char[] target = num.toCharArray(), a = num.toCharArray();
        int n = a.length, ans = 0;
        for (int t = 0; t < k; t++) {
            int i = n - 2;
            while (i >= 0 && target[i] >= target[i + 1]) i--;
            int j = n - 1;
            while (target[j] <= target[i]) j--;
            swap(target, i, j);
            for (int l = i + 1, r = n - 1; l < r; l++, r--)
                swap(target, l, r);
        }
        for (int i = 0; i < n; i++) {
            int j = i;
            while (a[j] != target[i]) j++;
            while (j > i) {
                swap(a, j, j - 1);
                j--; ans++;
            }
        }
        return ans;
    }
    private void swap(char[] a, int i, int j) {
        char tmp = a[i]; a[i] = a[j]; a[j] = tmp;
    }
}

var getMinSwaps = function(num, k) {
    const target = [...num], a = [...num], n = a.length;
    for (let t = 0; t < k; t++) {
        let i = n - 2;
        while (i >= 0 && target[i] >= target[i + 1]) i--;
        let j = n - 1;
        while (target[j] <= target[i]) j--;
        [target[i], target[j]] = [target[j], target[i]];
        for (let l = i + 1, r = n - 1; l < r; l++, r--)
            [target[l], target[r]] = [target[r], target[l]];
    }
    let ans = 0;
    for (let i = 0; i < n; i++) {
        let j = i;
        while (a[j] !== target[i]) j++;
        while (j > i) {
            [a[j], a[j - 1]] = [a[j - 1], a[j]];
            j--; ans++;
        }
    }
    return ans;
};

class Solution:
    def getMinSwaps(self, num: str, k: int) -> int:
        target, a = list(num), list(num)
        n = len(a)
        for _ in range(k):
            i = n - 2
            while i >= 0 and target[i] >= target[i + 1]:
                i -= 1
            j = n - 1
            while target[j] <= target[i]:
                j -= 1
            target[i], target[j] = target[j], target[i]
            target[i + 1:] = target[i + 1:][::-1]
        ans = 0
        for i in range(n):
            j = i
            while a[j] != target[i]:
                j += 1
            while j > i:
                a[j], a[j - 1] = a[j - 1], a[j]
                j -= 1
                ans += 1
        return ans
