生成每种字符都是奇数个的字符串

给定整数 n，构造一个恰好包含 n 个字符的字符串。字符串只能使用小写英文字母，并且所有实际出现的字符，其出现次数都必须是奇数。满足条件的答案不唯一，返回任意一个即可。

Full Solution

利用总长度的奇偶性构造

核心洞察

如果 n 是奇数，重复同一个字符 n 次就满足要求。如果 n 是偶数，不能让同一个字符出现 n 次；把其中 1 个位置换成另一字符后，两个字符的频次分别是 n − 1 和 1，恰好都为奇数。

完整过程

  1. 判断 n 的奇偶性。
  2. n 为奇数：返回由 n 个 a 组成的字符串。
  3. n 为偶数：返回 n − 1 个 a，再追加一个 b。
  4. 结果长度恒为 n，且只使用小写字母。

边界与复杂度

  • n = 1：返回 "a"。
  • n = 2：返回 "ab"。
  • n = 500：构造 499 个 a 和 1 个 b。
  • 时间复杂度：O(n)，写出 n 个字符。
  • 额外空间：O(n) 为返回字符串；若不计返回值则 O(1)。

正确性证明

n 为奇数。算法只使用字符 a，a 出现 n 次。因为 n 为奇数，所以所有出现过的字符频次均为奇数；字符串长度也是 n。

n 为偶数。算法让 a 出现 n − 1 次，让 b 出现 1 次。偶数减 1 是奇数，1 也是奇数，因此 a、b 的频次均为奇数；总长度为 (n − 1) + 1 = n。

结论。两种奇偶情况覆盖全部合法 n，且每种情况的返回值都满足长度、字符范围与奇数频次要求，所以算法正确。

替代方案

可以在 n 为偶数时返回任意两个各出现奇数次、次数之和为 n 的字符组合，例如 1 个 a 与 n − 1 个 z。也可以让多个字符都出现奇数次，只要频次之和为 n；但这会增加实现和核对成本，不如两字符构造直接。

四语言完整代码

JavaLeetCode 可提交
class Solution {
    public String generateTheString(int n) {
        if (n % 2 == 1) {
            return "a".repeat(n);
        }
        return "a".repeat(n - 1) + "b";
    }
}

class Solution {
public:
    string generateTheString(int n) {
        if (n % 2 == 1) {
            return string(n, 'a');
        }
        return string(n - 1, 'a') + 'b';
    }
};

面试追问与常见错误

为什么偶数 n 不能只用一个字符？
因为唯一字符会出现 n 次，而偶数 n 不满足“出现奇数次”。至少需要调整为两个或更多字符的奇数频次之和。
奇数个奇数相加与偶数个奇数相加有什么规律？
奇数个奇数之和为奇数，偶数个奇数之和为偶数。因此 n 为偶数时，可以让两个字符分别出现奇数次；n 为奇数时，一个字符就够了。
常见错误有哪些？
误把“每个小写字母”理解为 26 个字母都必须出现；偶数 n 仍返回 n 个相同字符；构造 n − 1 个 a 后忘记追加 b；返回长度与 n 不一致；使用了大写字母或非英文字母。
能否构造字典序最小的答案？
按本题约束，奇数 n 的 a × n 已经最小；偶数 n 时，a × (n − 1) + b 是满足本构造并保持前缀尽量小的自然选择。
