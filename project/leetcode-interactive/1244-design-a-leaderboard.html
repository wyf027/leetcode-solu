01 / PROBLEM

你要设计什么？

初始排行榜为空；玩家被 reset 后视为移出。

实现 Leaderboard 类，让它支持累计分数、查询前 K 名总分、以及移除已存在玩家。玩家编号只用于识别玩家；名次完全由当前累计分数决定。

addScore(playerId, score)
给玩家增加 score 分；若玩家尚不存在，则以该分数加入排行榜。
top(K)
返回当前分数最高的 K 位玩家的分数总和。题目保证 K 不超过当前玩家数。
reset(playerId)
把指定玩家从排行榜移除（等价于分数归零）；调用前保证该玩家已经加入。

BOUNDARIES

约束

  • 1 ≤ playerId, K ≤ 10⁴
  • 1 ≤ score ≤ 100
  • K ≤ 当前玩家数量
  • 函数调用总数不超过 1000

输出中的 null 对应构造器和无返回值方法。

官方示例（完整参数形式）

输入：
["Leaderboard","addScore","addScore","addScore","addScore","addScore","top","reset","reset","addScore","top"]
[[],[1,73],[2,56],[3,39],[4,51],[5,4],[1],[1],[2],[2,51],[3]]

输出：
[null,null,null,null,null,null,73,null,null,null,141]

说明：先加入 5 位玩家；top(1) = 73。移除玩家 1、2 后，玩家 2 以 51 分重新加入；
此时 top(3) = 51 + 51 + 39 = 141。

THE KEY

核心洞察：身份与名次分开处理

按玩家编号更新分数最方便的结构是哈希表。查询 top(K) 时不关心编号，只关心所有当前分数：复制分数、降序排序、取前 K 个求和即可。由于调用总数最多 1000，这个直接方案清楚、稳健，也足以通过约束。

完整过程

  1. 构造时创建空哈希表 scores，键是玩家 ID，值是累计分数。
  2. addScore：读取旧分数（不存在则按 0），加上本次分数再写回。
  3. top：取出全部值并降序排序，累加下标 0..K-1。
  4. reset：从哈希表删除玩家，使其不再参与后续排名。

正确性说明

不变式：任意操作完成后，scores[playerId] 恰好等于该玩家自最近一次加入（或 reset）以来收到的所有加分之和，并且哈希表中只包含当前排行榜玩家。

addScore 对新玩家从 0 累加，对旧玩家在准确旧值上累加，因此保持分数不变式；reset 删除指定键，因此准确移除玩家。top(K) 对不变式保存的全部当前分数降序排列，前 K 项按定义就是最高的 K 个分数，求和即为所需答案。故三个方法均正确。

边界与复杂度

  • 玩家 reset 后可再次通过 addScore 加入，此时从新分数开始。
  • 多个玩家同分无需特殊处理：top 只计算分数和。
  • 题目保证 reset 的玩家存在、K 合法，因此提交代码无需额外异常分支。
addScore / reset平均 O(1)哈希表更新或删除
top(K)O(n log n)复制并排序 n 个分数
空间O(n)分数表与排序数组

import java.util.ArrayList;
import java.util.Collections;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Leaderboard {
    private final Map<Integer, Integer> scores;

    public Leaderboard() {
        scores = new HashMap<>();
    }

    public void addScore(int playerId, int score) {
        scores.put(playerId, scores.getOrDefault(playerId, 0) + score);
    }

    public int top(int K) {
        List<Integer> values = new ArrayList<>(scores.values());
        values.sort(Collections.reverseOrder());
        int sum = 0;
        for (int i = 0; i < K; i++) {
            sum += values.get(i);
        }
        return sum;
    }

    public void reset(int playerId) {
        scores.remove(playerId);
    }
}

class Leaderboard:
    def __init__(self):
        self.scores = {}

    def addScore(self, playerId: int, score: int) -> None:
        self.scores[playerId] = self.scores.get(playerId, 0) + score

    def top(self, K: int) -> int:
        values = sorted(self.scores.values(), reverse=True)
        return sum(values[:K])

    def reset(self, playerId: int) -> None:
        del self.scores[playerId]

#include <functional>
#include <numeric>
#include <unordered_map>

using namespace std;

class Leaderboard {
private:
    unordered_map<int, int> scores;

public:
    Leaderboard() = default;

    void addScore(int playerId, int score) {
        scores[playerId] += score;
    }

    int top(int K) {
        vector<int> values;
        values.reserve(scores.size());
        for (const auto& entry : scores) {
            values.push_back(entry.second);
        }
        sort(values.begin(), values.end(), greater<int>());
        return accumulate(values.begin(), values.begin() + K, 0);
    }

    void reset(int playerId) {
        scores.erase(playerId);
    }
};

替代方案

最小堆：每次 top 查询扫描全部分数，仅保留最大的 K 个，时间 O(n log K)、额外空间 O(K)。当 K 远小于 n 时更合适。

有序多重集合 + 哈希表：更新时同时删除旧分数并插入新分数，Java 可用 TreeMap<score, count>。add/reset 为 O(log n)，top 只需从高分向下遍历到 K 人；实现更复杂，但适合频繁查询。

面试追问与常见错误

  • 追问：若玩家与查询各有百万量级，可讨论平衡树、分数桶、Fenwick 树或分布式有序集合。
  • 追问：若要返回玩家 ID 且同分按时间排序，需要为排序键补充稳定的次级规则。
  • 错误：把 addScore 当成覆盖分数；它要求累加。
  • 错误：reset 后仍保留值为 0 的玩家，导致其被计入“当前玩家数”。
  • 错误：降序比较器写成布尔值，或只累加前 K-1 项。
