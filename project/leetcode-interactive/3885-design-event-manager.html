设计事件管理器

Design Event Manager

维护一组活跃事件，每个事件都有唯一 eventId 与优先级。更新优先级后，pollHighest() 必须移除并返回最高优先级事件；并列时返回更小的 eventId。

接口：EventManager(events) 初始化，updatePriority(eventId, newPriority) 更新活跃事件，pollHighest() 出队最高优先级事件。

题意与规则

给定初始二维数组 events，其中 events[i] = [eventIdᵢ, priorityᵢ]。每个 eventId 唯一；只要尚未被 pollHighest() 移除，它就是活跃事件。

  • EventManager(int[][] events)：用初始事件建立管理器。
  • void updatePriority(int eventId, int newPriority)：将指定活跃事件的优先级改为新值。
  • int pollHighest()：移除并返回优先级最大的活跃事件 ID；并列时选更小 ID；没有活跃事件时返回 -1。

官方示例（完整参数）

输入 
["EventManager", "pollHighest", "updatePriority", "pollHighest", "pollHighest"]
[[[5, 7], [2, 7], [9, 4]], [], [9, 7], [], []]
输出 
[null, 2, null, 5, 9]

第一次出队时，ID 2 与 ID 5 的优先级同为 7，因此取更小的 2；把 9 的优先级升到 7 后，剩余的 5 与 9 再按 ID 升序出队。

约束

  • 1 ≤ events.length ≤ 10⁵，所有初始 eventId 互不相同。
  • 1 ≤ eventId, priority, newPriority ≤ 10⁹。
  • updatePriority 与 pollHighest 的调用总数至多为 10⁵。
  • 每次 updatePriority 指向的都是仍活跃的事件。

完整题解

核心洞察：Map 是真相，堆只是候选列表

普通堆无法在 O(log n) 内定位并删除“旧优先级”的任意元素。于是把 eventId → 最新 priority 存在 Map 中：更新时不删除旧堆项，而是写入新值并推入新候选。出队时持续弹堆，只有候选的优先级仍等于 Map 里的当前值，才是真正可返回的事件；否则它是旧版本，丢弃即可。

堆排序键：优先级降序、ID 升序。使用最大堆时，比较器先令更大的 priority 靠前；优先级相等时令更小的 eventId 靠前。

过程

  1. 初始化：将每个事件写入 Map，并将 (priority, eventId) 推入堆。
  2. 更新：Map 覆盖为新优先级；把新二元组压入堆，历史节点暂不处理。
  3. 出队：重复弹出顶部；若 Map 中不存在该 ID，说明已被移除；若优先级不同，说明是过期节点；两者都跳过。
  4. 遇到匹配节点后，从 Map 删除该 ID 并返回它；堆空则返回 -1。

正确性概要

Map 始终精确记录所有活跃事件及其最新优先级。对于任意活跃事件，其最新二元组在最后一次更新时被压入堆；因此堆中至少有一个可验证候选。顶部所有比它优先的候选若不匹配 Map 都会被跳过，匹配的第一个候选必拥有最大优先级、且在该优先级内 ID 最小，所以返回值满足题意。

复杂度、边界与替代方案

  • 每次更新压入一个节点，时间 O(log(n+q))；每个旧节点最多被弹出一次，因此出队的总弹出次数摊还为 O(q)。
  • 空间 O(n+q)，因为惰性删除保留历史候选。
  • 并列必须按较小 ID 处理；事件已出队时要从 Map 删除；堆空时返回 -1。
  • Java 可用 TreeSet 支持直接删除旧键，空间更紧；但通用的“堆 + Map”在 JavaScript、Python 和 C++ 中更一致。

面试追问与常见错误

  • 若要允许新增事件，可向 Map 写入并压堆；若允许取消事件，只删除 Map 键。
  • 若担心堆无限累积，可在旧节点明显过多时基于 Map 重建堆。
  • 不要仅按优先级比较而遗漏 ID 的并列规则；不要把“堆顶”直接当成当前状态。

四语言实现

Java · TreeSet 直接维护有序活跃集 
import java.util.*;

class EventManager {
    private final Map<Integer, Integer> priority = new HashMap<>();
    private final TreeSet<int[]> ordered = new TreeSet<>((a, b) -> {
        if (a[0] != b[0]) return Integer.compare(b[0], a[0]);
        return Integer.compare(a[1], b[1]);
    });

    public EventManager(int[][] events) {
        for (int[] e : events) {
            priority.put(e[0], e[1]);
            ordered.add(new int[] {e[1], e[0]});
        }
    }

    public void updatePriority(int eventId, int newPriority) {
        ordered.remove(new int[] {priority.get(eventId), eventId});
        priority.put(eventId, newPriority);
        ordered.add(new int[] {newPriority, eventId});
    }

    public int pollHighest() {
        if (ordered.isEmpty()) return -1;
        int[] top = ordered.pollFirst();
        priority.remove(top[1]);
        return top[1];
    }
}
JavaScript · 二叉堆与惰性删除 
class EventManager {
  constructor(events) {
    this.current = new Map();
    this.heap = [];
    for (const [id, priority] of events) {
      this.current.set(id, priority);
      this.push([priority, id]);
    }
  }
  better(a, b) { return a[0] !== b[0] ? a[0] > b[0] : a[1] < b[1]; }
  push(x) {
    const h = this.heap; h.push(x);
    for (let i = h.length - 1; i > 0;) {
      const p = (i - 1) >> 1; if (this.better(h[p], h[i])) break;
      [h[p], h[i]] = [h[i], h[p]]; i = p;
    }
  }
  pop() {
    const h = this.heap, ans = h[0], last = h.pop();
    if (h.length) {
      h[0] = last;
      for (let i = 0;;) {
        let best = i, l = i * 2 + 1, r = l + 1;
        if (l < h.length && this.better(h[l], h[best])) best = l;
        if (r < h.length && this.better(h[r], h[best])) best = r;
        if (best === i) break; [h[i], h[best]] = [h[best], h[i]]; i = best;
      }
    }
    return ans;
  }
  updatePriority(eventId, newPriority) { this.current.set(eventId, newPriority); this.push([newPriority, eventId]); }
  pollHighest() {
    while (this.heap.length) {
      const [p, id] = this.pop();
      if (this.current.get(id) === p) { this.current.delete(id); return id; }
    }
    return -1;
  }
}
Python · heapq 的负优先级键 
import heapq
from typing import List

class EventManager:
    def __init__(self, events: List[List[int]]):
        self.current = {event_id: priority for event_id, priority in events}
        self.heap = [(-priority, event_id) for event_id, priority in events]
        heapq.heapify(self.heap)

    def updatePriority(self, eventId: int, newPriority: int) -> None:
        self.current[eventId] = newPriority
        heapq.heappush(self.heap, (-newPriority, eventId))

    def pollHighest(self) -> int:
        while self.heap:
            negative_priority, event_id = heapq.heappop(self.heap)
            if self.current.get(event_id) == -negative_priority:
                del self.current[event_id]
                return event_id
        return -1
C++ · priority_queue 与哈希表 
#include <bits/stdc++.h>
using namespace std;

class EventManager {
    unordered_map<int, int> current;
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> pq;
public:
    EventManager(vector<vector<int>>& events) {
        for (auto& e : events) {
            current[e[0]] = e[1];
            pq.push({-e[1], e[0]});
        }
    }
    void updatePriority(int eventId, int newPriority) {
        current[eventId] = newPriority;
        pq.push({-newPriority, eventId});
    }
    int pollHighest() {
        while (!pq.empty()) {
            auto [negativePriority, eventId] = pq.top(); pq.pop();
            auto it = current.find(eventId);
            if (it != current.end() && it->second == -negativePriority) {
                current.erase(it);
                return eventId;
            }
        }
        return -1;
    }
};
