任务速览
m 个区间

对每个闭区间 [l[i], r[i]] 独立判断：其中的数字能否换个顺序，排成一个相邻差值恒定的序列。

Problem

先读懂题目

数组下标从 0 开始，每个查询互不影响；只需要返回对应的布尔结果。

给定一个含 n 个整数的数组 nums，以及长度都为 m 的两个数组 l 与 r。第 i 个查询表示闭区间 [l[i], r[i]]，取出子数组 nums[l[i]], nums[l[i]+1], …, nums[r[i]]。

等差数列：至少包含两个元素，且任意相邻两项的差都相同。例如 [1,3,5,7]、[7,7,7] 和 [3,-1,-5] 都是等差数列。

对子数组中的元素可以任意重新排列。如果能排成等差数列，则答案中的第 i 项为 true，否则为 false。返回全部查询的答案列表 answer。

示例 01
输入nums = [4,6,5,9,3,7]\nl = [0,0,2]\nr = [2,3,5]
输出[true,false,true]

三个子数组分别为 [4,6,5]、[4,6,5,9]、[5,9,3,7]；第一和第三个可以重排为等差数列，第二个不可以。

示例 02
输入nums = [-12,-9,-3,-12,-6,15,20,-25,-20,-15,-10]\nl = [0,1,6,4,8,7]\nr = [4,4,9,7,9,10]
输出[false,true,false,false,true,true]

约束

  • n == nums.length
  • m == l.length == r.length
  • 2 <= n <= 500
  • 1 <= m <= 500
  • 0 <= l[i] < r[i] < n
  • -105 <= nums[i] <= 105

Complete solution

排序，让唯一的候选顺序浮现

一个集合若能重排为等差数列，那么升序排列一定就是那条等差数列（逆序只是方向相反）。因此逐个提取查询区间、排序并检查相邻差值即可。

01 · EXTRACT

提取区间

对查询 [l[i], r[i]] 创建独立副本，不修改原数组。

02 · SORT

升序排列

排序把所有可能重排压缩成一个只需检查的规范顺序。

03 · COMPARE

检查差值

以第一对元素的差为基准，逐对比较；一旦不同就返回 false。

完整过程

  1. 建立答案列表，按顺序遍历全部 m 个查询。
  2. 复制 nums[l[i]...r[i]]，并按数值升序排序。
  3. 记录 difference = sub[1] - sub[0]。
  4. 从下标 2 开始，检查 sub[j] - sub[j-1] 是否等于基准差。
  5. 所有差都相同则加入 true；遇到不同则加入 false。

正确性证明

1

若算法返回 true：排序后每对相邻元素之差都等于同一基准，因此排序后的子数组按定义就是等差数列。它是原子数组的一种重排，所以该查询确实可行。

2

若子数组可重排为等差数列：把这个等差数列按升序观察；公差若为负，只需逆序，若为零则次序不影响。于是原元素的升序排列也具有恒定相邻差。算法检查的正是该升序排列，因此一定返回 true。

✓

两个方向都成立，所以算法对每个查询的判断正确；逐项收集后，整个答案列表正确。

边界情况

  • 区间只有两个元素：任意两个数总能构成等差数列。
  • 所有元素相同：公差为 0，应返回 true。
  • 包含负数或公差为负：升序后统一转化为非负公差。
  • 含重复值但不全相同：排序后的差值会不一致。

复杂度

设第 i 个查询长度为 kᵢ。

时间O(Σ kᵢ log kᵢ)
额外空间O(max kᵢ)

若用统一上界 K 表示最长区间，则时间为 O(m · K log K)。

替代方案

可在每个区间中求最小值、最大值，根据长度计算候选公差，再用哈希集合验证每个目标位置是否存在。平均时间可到 O(k)，但必须小心处理整除、重复元素和公差为 0。

在本题 n,m ≤ 500 的范围内，排序法更直接、清晰且足够快。

面试追问与常见错误

可能的追问

  • 如何用哈希集合把单次查询优化到平均 O(k)？
  • 若查询数量极大，能否预处理全部区间答案？
  • 为什么只检查排序后的顺序就足够？
  • 若输入是浮点数，怎样处理比较精度？

常见错误

  • 直接在原数组区间上排序，破坏后续查询的数据。
  • 只比较最大值与最小值，遗漏中间元素。
  • JavaScript 使用默认 sort()，变成字典序。
  • 循环边界少查或多查一对相邻元素。
  • 误以为公差必须大于 0。

Solution.java
import java.util.*;

class Solution {
    public List<Boolean> checkArithmeticSubarrays(int[] nums, int[] l, int[] r) {
        List<Boolean> answer = new ArrayList<>();
        for (int q = 0; q < l.length; q++) {
            int[] sub = Arrays.copyOfRange(nums, l[q], r[q] + 1);
            Arrays.sort(sub);
            int difference = sub[1] - sub[0];
            boolean isArithmetic = true;
            for (int i = 2; i < sub.length; i++) {
                if (sub[i] - sub[i - 1] != difference) {
                    isArithmetic = false;
                    break;
                }
            }
            answer.add(isArithmetic);
        }
        return answer;
    }
}
solution.js
/**
 * @param {number[]} nums
 * @param {number[]} l
 * @param {number[]} r
 * @return {boolean[]}
 */
var checkArithmeticSubarrays = function(nums, l, r) {
    return l.map((left, queryIndex) => {
        const sub = nums.slice(left, r[queryIndex] + 1);
        sub.sort((a, b) => a - b);
        const difference = sub[1] - sub[0];
        for (let i = 2; i < sub.length; i++) {
            if (sub[i] - sub[i - 1] !== difference) return false;
        }
        return true;
    });
};
solution.py
from typing import List

class Solution:
    def checkArithmeticSubarrays(
        self, nums: List[int], l: List[int], r: List[int]
    ) -> List[bool]:
        answer = []
        for left, right in zip(l, r):
            sub = sorted(nums[left:right + 1])
            difference = sub[1] - sub[0]
            is_arithmetic = all(
                sub[i] - sub[i - 1] == difference
                for i in range(2, len(sub))
            )
            answer.append(is_arithmetic)
        return answer
solution.cpp
class Solution {
public:
    vector<bool> checkArithmeticSubarrays(
        vector<int>& nums, vector<int>& l, vector<int>& r
    ) {
        vector<bool> answer;
        for (int q = 0; q < static_cast<int>(l.size()); ++q) {
            vector<int> sub(nums.begin() + l[q], nums.begin() + r[q] + 1);
            sort(sub.begin(), sub.end());
            int difference = sub[1] - sub[0];
            bool isArithmetic = true;
            for (int i = 2; i < static_cast<int>(sub.size()); ++i) {
                if (sub[i] - sub[i - 1] != difference) {
                    isArithmetic = false;
                    break;
                }
            }
            answer.push_back(isArithmetic);
        }
        return answer;
    }
};
