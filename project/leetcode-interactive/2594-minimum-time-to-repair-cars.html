2594 · Minimum Time to Repair Cars

修车的最少时间

几位能力不同的机械工同时开工。每个人修得越多，单人所需时间按平方增长——你需要找出所有车全部修完的最早时刻。

time = r × n²

Problem

题目描述

给定整数数组 ranks，其中 ranks[i] 表示第 i 位机械工的能力值。能力值为 r 的机械工修好 n 辆车需要 r × n² 分钟。

再给定整数 cars，表示等待修理的汽车总数。所有机械工可以同时工作，请返回修完全部汽车所需的最少时间。

示例 1

输入：ranks = [4,2,3,1], cars = 10
输出：16
解释：四位机械工分别修 2、2、2、4 辆车，
各自耗时 16、8、12、16 分钟。
所有工作并行进行，因此总耗时为 16 分钟。

示例 2

输入：ranks = [5,1,8], cars = 6
输出：16
解释：三位机械工分别修 1、4、1 辆车，
各自耗时 5、16、8 分钟。
所有工作并行进行，因此总耗时为 16 分钟。

约束

11 ≤ ranks.length ≤ 10⁵
21 ≤ ranks[i] ≤ 100
31 ≤ cars ≤ 10⁶

Editorial

二分答案：判断某个时刻是否够用

核心洞察

给定时间 t，能力值为 r 的机械工最多能修 ⌊√(t / r)⌋ 辆车。把所有人的数量相加，就能判断 t 是否足够。时间越多，能修的车只会更多，因此答案具有单调性，可以二分。

完整过程

  1. 令左边界 left = 0。
  2. 最快机械工独自修完所有车一定可行，故右边界为 min(ranks) × cars²。
  3. 取中点 mid，累加每位机械工在 mid 分钟内最多能修的车数。
  4. 若总数不少于 cars，说明 mid 可行，继续寻找更小时间；否则增大下界。
  5. 当左右边界重合时，该值就是最小可行时间。

为什么正确

引理：时间为 t 时，机械工 i 可修车辆数恰为 ⌊√(t / ranks[i])⌋。这是由 r × n² ≤ t 直接移项得到的最大整数 n。

单调性：若 t 可行，则任意 t′ ≥ t 都可行；每位机械工原来的分配仍能按时完成。

结论：二分始终保留最小可行值，并排除不可能包含答案的一半区间。循环结束时唯一剩余值就是最小修车时间。

边界处理

  • 只有一辆车时，答案是最小能力值。
  • 右边界最大可到 100 × 10¹² = 10¹⁴，Java/C++ 必须使用 64 位整数。
  • 累计车辆数达到 cars 后可提前停止，避免无用计算。
  • 整数平方根必须向下取整，表示完整修好的车辆数。

复杂度

设机械工数量为 m，搜索上界为 U = min(ranks) × cars²。

  • 时间复杂度：O(m log U)
  • 额外空间：O(1)

替代方案

可以用最小堆模拟每位机械工下一辆车的完成时刻，每次取最早完成者并安排下一辆车，复杂度约为 O(cars log m)。当 cars 达到 10⁶ 时，二分答案通常更快，也不需要维护堆。

四语言完整代码

JavaLeetCode 提交
class Solution {
    public long repairCars(int[] ranks, int cars) {
        int fastest = ranks[0];
        for (int rank : ranks) fastest = Math.min(fastest, rank);

        long left = 0;
        long right = (long) fastest * cars * cars;

        while (left < right) {
            long mid = left + (right - left) / 2;
            long repaired = 0;

            for (int rank : ranks) {
                repaired += (long) Math.sqrt(mid / rank);
                if (repaired >= cars) break;
            }

            if (repaired >= cars) right = mid;
            else left = mid + 1;
        }
        return left;
    }
}

var repairCars = function(ranks, cars) {
    let left = 0;
    let right = Math.min(...ranks) * cars * cars;

    while (left < right) {
        const mid = Math.floor((left + right) / 2);
        let repaired = 0;

        for (const rank of ranks) {
            repaired += Math.floor(Math.sqrt(mid / rank));
            if (repaired >= cars) break;
        }

        if (repaired >= cars) right = mid;
        else left = mid + 1;
    }
    return left;

from math import isqrt
from typing import List


class Solution:
    def repairCars(self, ranks: List[int], cars: int) -> int:
        left = 0
        right = min(ranks) * cars * cars

        while left < right:
            mid = (left + right) // 2
            repaired = 0

            for rank in ranks:
                repaired += isqrt(mid // rank)
                if repaired >= cars:
                    break

            if repaired >= cars:
                right = mid
            else:
                left = mid + 1

        return left

面试追问

  • 为什么上界一定可行？能否换成固定的更大上界？
  • 若机械工不能并行工作，模型会发生什么变化？
  • 如何避免浮点平方根潜在的边界误差？
  • 若需要返回具体分配方案，应如何恢复每人的修车数？

常见错误

  • 把所有机械工的耗时相加；实际上他们同时工作。
  • 用 t / r 当作可修车辆数，忽略耗时与车辆数的平方关系。
  • 右边界使用 32 位整数，计算 cars² 时溢出。
  • 可行时写成 right = mid - 1，破坏“寻找第一个可行值”的闭区间语义。
