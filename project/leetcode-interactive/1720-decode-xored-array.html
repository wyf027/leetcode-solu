Decode XORed Array

解码异或后的数组

一串相邻数字被异或后，只留下编码结果。你拿到原数组的第一个数字，能否逐格复原全部内容？先读题，再到实验台亲手推演。

Problem

题意与约束

题目描述

有一个由 n 个非负整数组成的未知数组 arr。它被编码成长度为 n - 1 的数组 encoded，且对每个合法下标都有：

encoded[i] = arr[i] XOR arr[i + 1]

现在给出 encoded 和原数组首元素 first = arr[0]，返回唯一的原数组 arr。

函数签名

decode(encoded: integer[], first: integer): integer[]

约束

  • 2 <= n <= 10⁴
  • encoded.length == n - 1
  • 0 <= encoded[i] <= 10⁵
  • 0 <= first <= 10⁵
目标：恢复完整数组，而不只是判断它是否存在。题目保证答案存在且唯一。

示例 1

输入：encoded = [1,2,3], first = 1
输出：[1,0,2,1]
解释：encoded = [1 XOR 0, 0 XOR 2, 2 XOR 1]
                  = [1,2,3]

示例 2

输入：encoded = [6,2,7,3], first = 4
输出：[4,2,0,7,4]

Solution

完整题解

洞察、证明、实现与面试延伸均收纳在这里，默认不会提前展开。

核心洞察

异或满足自反性：x XOR x = 0，且 x XOR 0 = x。所以等式两边再异或 arr[i]，即可消去已知项：

arr[i + 1] = encoded[i] XOR arr[i]

正确性证明

初始时 arr[0] = first 正确。假设 arr[i] 已正确恢复，由编码定义可知 encoded[i] = arr[i] XOR arr[i+1]；两边异或 arr[i] 后，左侧变为 encoded[i] XOR arr[i]，右侧相同项抵消，只剩 arr[i+1]。因此下一项也正确。由数学归纳法，全部元素均被正确恢复。

完整过程

  1. 创建答案数组。

    长度应为 encoded.length + 1，将第一项设为 first。

  2. 从左向右扫描编码数组。

    在位置 i，答案中的 arr[i] 已经确定。

  3. 恢复下一项。

    计算 arr[i + 1] = arr[i] XOR encoded[i] 并写入答案。

  4. 返回答案。

    扫描结束时，长度为 n 的所有元素都已恢复。

时间复杂度O(n)

每个编码元素只处理一次。

额外空间O(1)

不计必须返回的答案数组，只使用常数个变量。

边界情况

  • 最短数组：n = 2 时只需执行一次异或。
  • 零值：0 XOR x = x，首元素或编码项为零都无需特殊处理。
  • 重复值：相邻两项相同时编码结果为零，公式仍然成立。
  • 数值范围：约束中的整数适用于四种语言的普通整数类型。

Java
class Solution {
    public int[] decode(int[] encoded, int first) {
        int[] arr = new int[encoded.length + 1];
        arr[0] = first;

        for (int i = 0; i < encoded.length; i++) {
            arr[i + 1] = arr[i] ^ encoded[i];
        }
        return arr;
    }
}

class Solution {
public:
    vector<int> decode(vector<int>& encoded, int first) {
        vector<int> arr(encoded.size() + 1);
        arr[0] = first;

        for (int i = 0; i < encoded.size(); ++i) {

替代方案

可以原地复用一个新答案数组，并让当前位置直接依赖前一项；本质仍是同一递推。递归也能表达该过程，但会增加调用栈且没有收益。由于输出长度固定为 n，无法省掉返回数组本身。

常见错误

  • 答案长度误写成 encoded.length。
  • 循环边界多执行一次，访问越界。
  • 把 XOR 写成逻辑异或、乘方或普通加法。
  • 忘记先把 first 放进答案。

面试追问

为什么答案唯一？

首项固定后，每一项都由前一项与对应编码项唯一确定，不存在分支。

能否流式处理？

可以。若输出允许逐项发送，只需保留上一项即可持续解码，工作内存为常数。

若 first 未知呢？

仅凭相邻异或通常无法确定绝对值，需要额外信息或约束。

如何反向验证？

对恢复后的每对相邻元素重新异或，应逐项等于 encoded。
