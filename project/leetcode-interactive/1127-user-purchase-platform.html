用户购买平台

把同一用户、同一天的消费先归为“仅桌面端”“仅移动端”或“两端都有”，再为每个日期完整报告三类平台的消费额与用户数。

Reading brief
  • 01按用户与日期收拢当天的消费记录。
  • 02结果必须覆盖每个日期的三种平台标签。
  • 03没有用户的组合也要输出 0 与 0。

Problem statement

题意与数据契约

官方元数据仅提供表结构和样例数据。下面以不复刻付费题面正文的方式，准确转述查询目标。

输入表 Spending

每条记录表示某位用户在某天、某个平台产生的一笔消费。需要按“用户 + 日期”判断用户当天使用了一个平台还是两个平台，并汇总消费金额。

  • user_idINT，用户标识
  • spend_dateDATE，消费日期
  • platformENUM('desktop','mobile')
  • amountINT，本条消费金额
输出列

对输入中出现的每个日期，都输出 desktop、mobile、both 三行：

  • total_amount：归入该类别的用户当天消费总额；
  • total_users：归入该类别的不同用户数；
  • 若某类别无人，仍需输出该行，两个统计值均为 0。
分类互斥：同一用户同一天如果同时使用 desktop 与 mobile，则他当天的全部金额只计入 both，不再进入另外两类。

Solution

先压缩用户日，再补齐日期平台网格

核心洞察

原始行不能直接按平台汇总，因为一个“两端都有”的用户会同时落进 desktop 和 mobile。正确的统计粒度是用户 + 日期：先把这一粒度压成一行，再把它映射到互斥的三类平台。

完整过程

  1. 按 user_id, spend_date 分组，求金额之和与不同平台数。
  2. 平台数为 2 时标记为 both，否则取唯一平台名。
  3. 用不同日期与固定三平台做笛卡尔积，得到完整骨架。
  4. 左连接用户日数据，按日期和平台聚合；空值金额转为 0。

SQL · 官方可提交语言

MySQL 8+ 完整查询 
WITH user_day AS (
    SELECT
        user_id,
        spend_date,
        CASE
            WHEN COUNT(DISTINCT platform) = 2 THEN 'both'
            ELSE MAX(platform)
        END AS platform,
        SUM(amount) AS amount
    FROM Spending
    GROUP BY user_id, spend_date
),
platforms AS (
    SELECT 'desktop' AS platform
    UNION ALL SELECT 'mobile'
    UNION ALL SELECT 'both'
),
dates AS (
    SELECT DISTINCT spend_date
    FROM Spending
)
SELECT
    d.spend_date,
    p.platform,
    COALESCE(SUM(u.amount), 0) AS total_amount,
    COUNT(u.user_id) AS total_users
FROM dates AS d
CROSS JOIN platforms AS p
LEFT JOIN user_day AS u
    ON u.spend_date = d.spend_date
   AND u.platform = p.platform
GROUP BY d.spend_date, p.platform
ORDER BY
    d.spend_date,
    CASE p.platform
        WHEN 'desktop' THEN 1
        WHEN 'mobile' THEN 2
        ELSE 3
    END;

正确性证明

  1. 用户日分类唯一。同一用户同一天的不同平台数只能为 1 或 2；CASE 分别映射到唯一平台或 both，因此每个用户日恰好属于一类。
  2. 金额与人数正确。user_day 已含该用户当天全部金额。按类别求和得到正确总额，而每个用户日仅一行，所以 COUNT 得到正确用户数。
  3. 输出完整。日期与三平台的笛卡尔积包含每个必需组合。左连接保留无人组合，COALESCE 与 COUNT 分别产生 0 和 0。

边界与复杂度

  • 单日只有一个平台：另两类仍输出零值行。
  • 同一用户同平台多笔：金额先相加，不会重复计用户。
  • 输入为空时没有日期，因此自然返回空结果。
  • 设原始记录数为 N、不同日期数为 D。逻辑时间约为 O(N + D)，中间用户日数据最多 O(N)；数据库实际代价受分组、排序和索引影响。

替代方案

可以用两个按平台条件聚合的 CTE 判断每个用户日是否两端都有，也可以分别查询 desktop、mobile、both 后 UNION ALL。后者往往重复扫描和重复表达分类规则；“用户日压缩 + 网格补齐”更集中，也更容易证明。

面试追问

  • 如果未来平台从 2 个扩展到 10 个，类别应如何建模？
  • 若 amount 可为负数（退款），总额与人数定义是否要调整？
  • 如何用组合索引优化用户日聚合？
  • 若要求输出没有消费的日历日期，日期集合应从哪里来？

常见错误

  • 直接按原始 platform 分组，导致 both 用户被拆开。
  • 用内连接聚合，遗漏统计值为零的组合。
  • 对原始行 COUNT，导致同一用户多笔消费被重复计数。
  • 只对 SUM 做 COALESCE，却误以为 COUNT(*) 在空组合上也是 0。

import java.util.*;

public class Main {
    record Spending(int userId, String date, String platform, long amount) {}
    record Result(String date, String platform, long totalAmount, int totalUsers) {}

    static List<Result> solve(List<Spending> rows) {
        class Day {
            long amount;
            Set<String> platforms = new HashSet<>();
        }

        Map<String, Day> byUserDay = new HashMap<>();
        SortedSet<String> dates = new TreeSet<>();
        for (Spending row : rows) {
            dates.add(row.date());
            String key = row.date() + "\u0000" + row.userId();
            Day day = byUserDay.computeIfAbsent(key, ignored -> new Day());
            day.amount += row.amount();
            day.platforms.add(row.platform());
        }

        Map<String, long[]> totals = new HashMap<>();
        for (Map.Entry<String, Day> entry : byUserDay.entrySet()) {
            String date = entry.getKey().split("\u0000", 2)[0];
            Day day = entry.getValue();
            String platform = day.platforms.size() == 2
                    ? "both" : day.platforms.iterator().next();
            long[] stats = totals.computeIfAbsent(date + "\u0000" + platform,
                    ignored -> new long[2]);
            stats[0] += day.amount;
            stats[1]++;
        }

        List<Result> answer = new ArrayList<>();
        List<String> platforms = List.of("desktop", "mobile", "both");
        for (String date : dates) {
            for (String platform : platforms) {
                long[] stats = totals.getOrDefault(date + "\u0000" + platform, new long[2]);
                answer.add(new Result(date, platform, stats[0], (int) stats[1]));
            }
        }
        return answer;
    }

    public static void main(String[] args) {
        List<Spending> sample = List.of(
            new Spending(1, "2019-07-01", "mobile", 100),
            new Spending(1, "2019-07-01", "desktop", 100),
            new Spending(2, "2019-07-01", "mobile", 100),
            new Spending(2, "2019-07-02", "mobile", 100),
            new Spending(3, "2019-07-01", "desktop", 100),
            new Spending(3, "2019-07-02", "desktop", 100)
        );
        solve(sample).forEach(System.out::println);
    }
}

function solve(spending) {
  const byUserDay = new Map();
  const dates = new Set();

  for (const row of spending) {
    dates.add(row.spend_date);
    const key = `${row.spend_date}\u0000${row.user_id}`;
    if (!byUserDay.has(key)) {
      byUserDay.set(key, { date: row.spend_date, amount: 0, platforms: new Set() });
    }
    const day = byUserDay.get(key);
    day.amount += row.amount;
    day.platforms.add(row.platform);
  }

  const totals = new Map();
  for (const day of byUserDay.values()) {
    const platform = day.platforms.size === 2 ? "both" : [...day.platforms][0];
    const key = `${day.date}\u0000${platform}`;
    const stats = totals.get(key) || { total_amount: 0, total_users: 0 };
    stats.total_amount += day.amount;
    stats.total_users += 1;
    totals.set(key, stats);
  }

  const answer = [];
  for (const date of [...dates].sort()) {
    for (const platform of ["desktop", "mobile", "both"]) {
      const stats = totals.get(`${date}\u0000${platform}`) || {
        total_amount: 0,
        total_users: 0
      };
      answer.push({ spend_date: date, platform, ...stats });
    }
  }
  return answer;
}

from collections import defaultdict


def solve(spending):
    by_user_day = {}
    dates = set()

    for row in spending:
        date = row["spend_date"]
        dates.add(date)
        key = (date, row["user_id"])
        day = by_user_day.setdefault(key, {"amount": 0, "platforms": set()})
        day["amount"] += row["amount"]
        day["platforms"].add(row["platform"])

    totals = defaultdict(lambda: [0, 0])
    for (date, _user_id), day in by_user_day.items():
        platform = "both" if len(day["platforms"]) == 2 else next(iter(day["platforms"]))
        totals[(date, platform)][0] += day["amount"]
        totals[(date, platform)][1] += 1

    answer = []
    for date in sorted(dates):
        for platform in ("desktop", "mobile", "both"):
            total_amount, total_users = totals[(date, platform)]
            answer.append({
                "spend_date": date,
                "platform": platform,
                "total_amount": total_amount,
                "total_users": total_users,
            })
    return answer

#include <iostream>
#include <map>
#include <set>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

struct Spending {
    int userId;
    string date;
    string platform;
    long long amount;
};

struct Result {
    string date;
    string platform;
    long long totalAmount;
    int totalUsers;
};

vector<Result> solve(const vector<Spending>& rows) {
    struct Day {
        long long amount = 0;
        set<string> platforms;
    };

    map<pair<string, int>, Day> byUserDay;
    set<string> dates;
    for (const auto& row : rows) {
        dates.insert(row.date);
        auto& day = byUserDay[{row.date, row.userId}];
        day.amount += row.amount;
        day.platforms.insert(row.platform);
    }

    map<pair<string, string>, pair<long long, int>> totals;
    for (const auto& [key, day] : byUserDay) {
        const string& date = key.first;
        string platform = day.platforms.size() == 2 ? "both" : *day.platforms.begin();
        auto& stats = totals[{date, platform}];
        stats.first += day.amount;
        stats.second += 1;
    }

    vector<Result> answer;
    const vector<string> platforms = {"desktop", "mobile", "both"};
    for (const auto& date : dates) {
        for (const auto& platform : platforms) {
            auto stats = totals[{date, platform}];
            answer.push_back({date, platform, stats.first, stats.second});
        }
    }
    return answer;
}

int main() {
    vector<Spending> sample = {
        {1, "2019-07-01", "mobile", 100},
        {1, "2019-07-01", "desktop", 100},
        {2, "2019-07-01", "mobile", 100},
        {2, "2019-07-02", "mobile", 100},
        {3, "2019-07-01", "desktop", 100},
        {3, "2019-07-02", "desktop", 100}
    };
    for (const auto& row : solve(sample)) {
        cout << row.date << ' ' << row.platform << ' '
             << row.totalAmount << ' ' << row.totalUsers << '\n';
    }
    return 0;
}
