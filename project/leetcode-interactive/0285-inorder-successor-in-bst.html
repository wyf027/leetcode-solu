二叉搜索树中的
中序后继

给定一棵二叉搜索树和其中一个结点 p，返回严格排在 p 后面的中序遍历结点；如果不存在，返回 null。

题目#285
主题BST · DFS
目标找严格后继
模式快速生成
Problem

题意与输入形式

二叉搜索树中任意结点左子树的值更小、右子树的值更大。这里的“后继”是按左—根—右的中序顺序，紧挨着 p 的下一个结点。

函数签名

inorderSuccessor(root: TreeNode, p: TreeNode) -> TreeNode | null

序列化用例用整数表示 p 的值；调用函数时传入的是树中对应的结点引用。

约束

  • 树中结点数在 [1, 104] 范围内。
  • -105 ≤ Node.val ≤ 105。
  • 所有结点值互不相同，且满足二叉搜索树性质。
  • p 保证是树中的一个结点。

官方参数形式示例

输入root = [2,1,3], p = 1
输出2
说明中序序列为 [1,2,3]，1 后面紧邻 2。
输入root = [5,3,6,2,4,null,null,1], p = 6
输出null
说明6 已是整棵树中最大的结点，没有中序后继。

Full Solution

利用 BST 有序性逐层收紧候选

无需生成完整中序序列。搜索 p.val 的同时，维护目前遇到的最小“大于 p”的结点。

核心洞察

当 p.val < current.val 时，当前结点可能是答案，但左子树中还可能有更小的可行值；记录它并向左。否则，当前结点不可能是严格后继，向右。

完整过程

  1. 令 successor = null，current = root。
  2. 若 p.val < current.val，把 current 记为新候选，再进入左子树。
  3. 否则进入右子树；相等时也向右，确保寻找的是严格后继。
  4. 走到空指针后返回 successor。

正确性

循环不变式：successor 始终是已访问结点中值大于 p.val 的最小者。向左时，当前值可行且后续只可能找到更小的可行值；向右时，当前值不大于目标，不可能成为后继。搜索结束时，所有可能改进候选的分支都已按 BST 次序排除，因此候选正是严格中序后继；没有候选则答案为 null。

复杂度

时间：O(h)，其中 h 是树高；平衡树为 O(log n)，最坏退化为 O(n)。

空间：O(1)，只维护两个结点引用。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) { val = x; }
 * }
 */
class Solution {
    public TreeNode inorderSuccessor(TreeNode root, TreeNode p) {
        TreeNode successor = null;
        TreeNode current = root;

        while (current != null) {
            if (p.val < current.val) {
                successor = current;
                current = current.left;
            } else {
                current = current.right;
            }
        }
        return successor;
    }
}
/**
 * function TreeNode(val, left, right) {
 *   this.val = (val === undefined ? 0 : val);
 *   this.left = (left === undefined ? null : left);
 *   this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @param {TreeNode} p
 * @return {TreeNode}
 */
var inorderSuccessor = function(root, p) {
  let successor = null;
  let current = root;

  while (current !== null) {
    if (p.val < current.val) {
      successor = current;
      current = current.left;
    } else {
      current = current.right;
    }
  }
  return successor;
};

        TreeNode* current = root;

边界情况

  • p 是最大结点：候选始终为空。
  • 单结点树：没有严格后继。
  • 后继可能是祖先，也可能位于 p 的右子树。
  • 树退化为链：时间复杂度达到 O(n)。

替代方案

  • 完整中序遍历：找到 p 后取下一项，时间与额外空间均可达 O(n)。
  • 结构化做法：若 p.right 存在，取右子树最左结点；否则从根搜索最近的更大祖先。
  • 若结点自带父指针，可向上寻找第一个把当前结点置于其左子树的祖先。

面试追问

  • 若 BST 允许重复值，如何定义并定位“严格后继”？
  • 如果只给 p 而不给根，必须增加什么信息？
  • 怎样在同一思路下求中序前驱？
  • 如何支持大量连续的后继查询？

常见错误

  • 相等时停止，误把当前结点当作后继。
  • 只检查 p.right，遗漏后继是祖先的情况。
  • 向左时未先保存当前候选。
  • 默认树一定平衡，错误地宣称最坏时间为 O(log n)。
