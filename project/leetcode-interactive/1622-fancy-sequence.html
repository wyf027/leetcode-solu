Problem brief

让每次整体变化都可追踪

实现 Fancy 类。对象从空序列开始，支持以下四个操作；查询结果需要对 1,000,000,007 取模。

API 定义
  • ＋
    Fancy()

    初始化一个空序列。

  • ↳
    append(val)

    把整数 val 添加到序列末尾。

  • Σ
    addAll(inc)

    让序列中所有已经存在的数都增加 inc。

  • ×
    multAll(m)

    让序列中所有已经存在的数都乘以 m。

  • ?
    getIndex(idx)

    返回下标 idx 当前的值；越界时返回 -1。

约束
  • 1 ≤ val, inc, m ≤ 100
  • 0 ≤ idx ≤ 10⁵
  • 四类操作合计最多调用 10⁵ 次。
  • getIndex 的有效结果均对 10⁹ + 7 取模。
注意时间边界：整体加法和乘法只作用于操作发生时已经在序列里的元素；后来 append 的值不追溯参与旧操作。

Spoiler boundary

准备好再打开题解

建议先在脑中尝试：怎样避免每次 addAll / multAll 都遍历整个序列？

Solution

把所有变化压缩成一个仿射函数

维护全局变换 f(x) = mul × x + add。整体操作只更新两个系数，追加时则把新值逆向还原到统一坐标系。

核心洞察

连续的加法与乘法复合后仍然是仿射变换。令每个元素保存为基础值 base，当前真实值统一解释为：

value ≡ base × mul + add (mod MOD)

于是 addAll 和 multAll 都不必触碰数组里的每个元素。

append 如何不继承过去

新元素在加入时必须立刻等于 val，所以反解它的基础值：

base ≡ (val − add) × mul⁻¹ (mod MOD)

MOD = 10⁹ + 7 是质数，而题目中的乘数为 1…100，因此 mul 始终非零，可以用费马小定理求逆元。

完整过程

  1. 初始化 mul = 1, add = 0，数组为空。
  2. append(val)：计算并保存逆变换后的基础值。
  3. addAll(inc)：令 add = add + inc。
  4. multAll(m)：令 mul = mul × m 且 add = add × m。
  5. getIndex(idx)：越界返回 -1，否则计算 base[idx] × mul + add。

边界与取模

  • 空序列或 idx ≥ size 时返回 -1。
  • 反解中的减法要规范化为非负模数。
  • Java / C++ 的乘法中间结果必须使用 64 位整数。
  • JavaScript 使用 BigInt，避免 Number 超过安全整数范围。
  • 若题目允许 m = 0，逆元方案需要分段或特殊处理；本题约束排除了它。

正确性证明

不变式：任意时刻，对数组中每个基础值 base[i]，序列当前值均满足 value[i] ≡ base[i] × mul + add (mod MOD)。

  1. 初始化：数组为空，不变式显然成立，且恒等变换为 mul=1, add=0。
  2. append：保存 (val-add)×mul⁻¹ 后，代回不变式得到 val，旧元素与系数不变。
  3. addAll：把 add 增加 inc，每个解释值同步增加 inc。
  4. multAll：同时把 mul 与 add 乘 m，新的解释值恰为旧值乘 m。
  5. getIndex：直接使用不变式计算有效下标的当前值；无效下标按定义返回 -1。

四类操作均保持定义，因此算法正确。

复杂度

addAll、multAll、getIndex 都是 O(1)。append 通过快速幂求逆元为 O(log MOD)；若同步维护逆元，可进一步做到摊还 O(1)。空间为保存 n 个基础值的 O(n)。

替代方案

线段树可对区间 [0, n−1] 做懒标记仿射更新，并支持单点查询，每次 O(log n)，也能通过，但代码更长。离线倒序处理适合一次性事件列表，却不符合在线类 API 的调用方式。

四语言完整实现

import java.util.*;

class Fancy {
    private static final long MOD = 1_000_000_007L;
    private final List<Long> base = new ArrayList<>();
    private long mul = 1;
    private long add = 0;

    public Fancy() {}

    public void append(int val) {
        long normalized = (val - add + MOD) % MOD;
        base.add(normalized * modPow(mul, MOD - 2) % MOD);
    }

    public void addAll(int inc) {
        add = (add + inc) % MOD;
    }

    public void multAll(int m) {
        mul = mul * m % MOD;
        add = add * m % MOD;
    }

    public int getIndex(int idx) {
        if (idx < 0 || idx >= base.size()) return -1;
        return (int) ((base.get(idx) * mul + add) % MOD);
    }

    private long modPow(long a, long e) {
        long result = 1;
        while (e > 0) {
            if ((e & 1) == 1) result = result * a % MOD;
            a = a * a % MOD;
            e >>= 1;
        }
        return result;
    }
}
var Fancy = function() {
    this.MOD = 1000000007n;
    this.base = [];
    this.mul = 1n;
    this.add = 0n;
};

Fancy.prototype.pow = function(a, e) {
    let result = 1n;
    while (e > 0n) {
        if (e & 1n) result = result * a % this.MOD;
        a = a * a % this.MOD;
        e >>= 1n;
    }
    return result;
};

Fancy.prototype.append = function(val) {
    const normalized = (BigInt(val) - this.add + this.MOD) % this.MOD;
    const inverse = this.pow(this.mul, this.MOD - 2n);
    this.base.push(normalized * inverse % this.MOD);
};

Fancy.prototype.addAll = function(inc) {
    this.add = (this.add + BigInt(inc)) % this.MOD;
};

Fancy.prototype.multAll = function(m) {
    const factor = BigInt(m);
    this.mul = this.mul * factor % this.MOD;
    this.add = this.add * factor % this.MOD;
};

Fancy.prototype.getIndex = function(idx) {
    if (idx < 0 || idx >= this.base.length) return -1;
    return Number((this.base[idx] * this.mul + this.add) % this.MOD);
};
class Fancy:
    MOD = 10**9 + 7

    def __init__(self):
        self.base = []
        self.mul = 1
        self.add = 0

    def append(self, val: int) -> None:
        normalized = (val - self.add) % self.MOD
        inverse = pow(self.mul, self.MOD - 2, self.MOD)
        self.base.append(normalized * inverse % self.MOD)

    def addAll(self, inc: int) -> None:
        self.add = (self.add + inc) % self.MOD

    def multAll(self, m: int) -> None:
        self.mul = self.mul * m % self.MOD
        self.add = self.add * m % self.MOD

    def getIndex(self, idx: int) -> int:
        if idx < 0 or idx >= len(self.base):
            return -1
        return (self.base[idx] * self.mul + self.add) % self.MOD
class Fancy {
    static constexpr long long MOD = 1000000007LL;
    vector<long long> base;
    long long mul = 1;
    long long add = 0;

    long long modPow(long long a, long long e) {
        long long result = 1;
        while (e > 0) {
            if (e & 1) result = result * a % MOD;
            a = a * a % MOD;
            e >>= 1;
        }
        return result;
    }

public:
    Fancy() = default;

    void append(int val) {
        long long normalized = (val - add + MOD) % MOD;
        base.push_back(normalized * modPow(mul, MOD - 2) % MOD);
    }

    void addAll(int inc) {
        add = (add + inc) % MOD;
    }

    void multAll(int m) {
        mul = mul * m % MOD;
        add = add * m % MOD;
    }

    int getIndex(int idx) {
        if (idx < 0 || idx >= static_cast<int>(base.size())) return -1;
        return static_cast<int>((base[idx] * mul + add) % MOD);
    }
};

面试追问与常见错误

追问：append 能否 O(1)？

可以额外维护 mul 的逆元：乘法时让逆元乘以 m⁻¹，append 直接使用它。单次 multAll 仍需一次快速幂，或预处理 1…100 的逆元。

追问：若允许乘零？

全局 mul 会变为 0，无法求逆。可在乘零时固化一个统一基准并开启新纪元，或使用能表达仿射懒标记的线段树。

错误：只更新 mul

执行 multAll 时，历史累计的 add 也必须乘 m；因为 (mul×x+add)×m 的常数项是 add×m。

错误：append 直接存 val

这样新元素会被过去累积的变换重复作用。必须通过当前仿射函数的逆变换，把 val 放回基础坐标。

错误：负模数

某些语言中负数取模仍为负。计算 val-add 后要先加 MOD 再取模。

错误：数值溢出

两个模数内的数相乘接近 10¹⁸。Java 与 C++ 使用 64 位；JavaScript 使用 BigInt 且不要混用 Number。
