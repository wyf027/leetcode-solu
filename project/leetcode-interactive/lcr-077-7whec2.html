LCR 077 · MEDIUM

排序链表

给定链表头节点，将链表按升序排列并返回。要求时间复杂度为 O(n log n)，尽量减少额外空间。

题意

链表不支持随机访问，不能直接套用数组排序。需要重新连接节点，让节点值从小到大。

示例

[4,2,1,3] → [1,2,3,4]

[-1,5,3,4,0] → [-1,0,3,4,5]

约束

链表节点数在 [0, 5×10⁴]；节点值范围为 [-10⁵, 10⁵]。

分步交互：归并排序

每轮把相邻的有序子链表合并，子链长度逐倍增长。

准备就绪。

核心洞察

归并排序天然适合链表：用快慢指针将链表二分，分别排序后线性合并。每层合并处理所有节点一次，共 log n 层，达到 O(n log n)。

完整过程

  1. 快慢指针寻找中点，并从中点断开链表。
  2. 递归排序左右两半；单节点或空链表直接返回。
  3. 用哨兵节点合并两个有序链表，返回合并后的头节点。

边界

  • 空链表和单节点无需排序。
  • 找到中点后必须断链，否则递归不会缩小。
  • 合并时相等元素任选一侧，仍保持正确排序。

复杂度

时间 O(n log n)。自顶向下递归的栈空间为 O(log n)；自底向上写法可使辅助空间为 O(1)。

替代方案与追问

可将节点值复制进数组再排序，但额外空间为 O(n)，不符合进阶要求。追问：若要求稳定排序，合并相等值时优先取左链节点；若是双向链表，中点与合并的指针维护要同步更新 prev。

常见错误

  • 中点节点未断开，导致无限递归。
  • 合并后漏接剩余链表。
  • 用快指针从 head 开始造成偶数长度分割不对称，但仍须确保子问题缩小。

# Python
class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next: return head
        slow, fast = head, head.next
        while fast and fast.next: slow, fast = slow.next, fast.next.next
        right, slow.next = slow.next, None
        return self.merge(self.sortList(head), self.sortList(right))
    def merge(self, a, b):
        dummy = ListNode(); p = dummy
        while a and b:
            if a.val <= b.val: p.next, a = a, a.next
            else: p.next, b = b, b.next
            p = p.next
        p.next = a or b; return dummy.next
