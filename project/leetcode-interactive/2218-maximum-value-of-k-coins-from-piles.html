2218. 从栈中取出 K 个硬币的最大面值和

Maximum Value of K Coins From Piles

每次只能拿走栈顶的一枚硬币。如何在恰好取出 K 枚后，让钱包里的面值总和最大？先想一想：眼前最大的硬币，一定值得先拿吗？

恰好 K 枚只能从顶向下返回最大面值和

题意与输入

给定 piles，其中有 n 个非空硬币栈。piles[i] 按从栈顶到栈底的顺序记录第 i 个栈的硬币面值。每次选择任意非空栈，取走其顶部一枚硬币。执行恰好 k 次操作，返回所有可行取法中最大的面值总和。

参数：piles: 整数二维数组，k: 正整数；返回值：整数。取到某枚硬币前，必须先取走同栈位于它上方的所有硬币。

官方示例 1

输入：piles = [[1,100,3],[7,8,9]], k = 2
输出：101

从第一个栈取顶部两枚，面值为 1 + 100 = 101。

官方示例 2

输入：piles = [[100],[100],[100],[100],[100],[100],[1,1,1,1,1,1,700]], k = 7
输出：706

全部七枚都从最后一个栈取出，面值为 6 + 700 = 706。

完整约束

  • n == piles.length，且 1 ≤ n ≤ 1000。
  • 每个栈至少有一枚硬币。
  • 1 ≤ piles[i][j] ≤ 10⁵。
  • 1 ≤ k ≤ sum(piles[i].length) ≤ 2000。

题解实验室

准备好后，再展开思路、动态过程和四语言代码。

前缀和 + 分组背包

核心洞察

每个栈只能选择它的一段前缀：取 0 枚、1 枚、2 枚……。一旦确定从各栈取的枚数，总价值便确定；栈与栈之间的实际取币顺序不影响结果。这就把操作序列转成了“每组选择一种前缀”的容量分配。

令 dp[j] 为已处理栈中恰好取 j 枚的最大价值。当前栈前 t 枚的价值记为 prefix[t]，则：

next[j] = max(dp[j - t] + prefix[t])
           0 ≤ t ≤ min(j, 当前栈长度)
           只枚举 dp[j - t] 可达的情况

初始化只有 dp[0] = 0 可达，其余是 -1。所有价值为正数，所以 -1 可安全表示不可达。每处理一个栈，用独立 next 数组保存新一层，避免同栈被重复选取。

交互 · 前缀选择如何填入背包

每一步尝试一个 (总枚数 j, 当前栈取 t 枚) 的候选，绿色硬币是本次选取的前缀。上排固定为上一层，下排累积本栈的最优结果。“—”表示不可达。

完整过程

  1. 创建长度 k + 1 的 dp，仅 0 枚可达。
  2. 对每个栈计算前 min(k, 栈长) 枚的前缀和，包含 prefix[0] = 0。
  3. 枚举目标枚数 j，再枚举本栈贡献 t；用上一层恰好 j − t 枚的最优解扩展。
  4. 跳过不可达来源，对 next[j] 取最大值，整栈完成后令 dp = next。
  5. 处理完全部栈，返回 dp[k]。题目保证硬币总数不少于 k。

示例 1 中，第一栈处理后 dp = [0, 1, 101]。第二栈的 j = 2 分别比较：取 0 枚得 101，取 1 枚得 1 + 7 = 8，取 2 枚得 0 + 15 = 15，最终仍为 101。

正确性证明

归纳假设：处理前 i − 1 个栈后，dp[j] 正确表示恰好 j 枚的最大价值，不可行则为 -1。任何使用前 i 个栈且恰好取 j 枚的方案，必从第 i 栈取某个前缀 t，余下 j − t 枚来自前 i − 1 个栈。该部分价值不超过 dp[j − t]，因此整体不超过转移枚举的最大值。反过来，每个可达的 dp[j − t] 与本栈前 t 枚都能组成合法方案，转移值可被实现。故 next[j] 正确。初始空集合只有取 0 枚可行，归纳成立，最终 dp[k] 为答案。

边界与复杂度

  • k = 1：只比较各栈顶部；单栈时只能取其前 k 枚。
  • k 等于硬币总数：必须全部取走；t = 0 的选项允许跳过任意栈。
  • 不可达状态必须跳过。最大答案不超过 2000 × 10⁵ = 2 × 10⁸，Java / C++ 的 32 位有符号整数足够。
  • 记 S 为总硬币数，mᵢ 为第 i 栈长度。时间为 O(k · Σ min(k, mᵢ) + nk)，由于每栈非空、n ≤ S，可写为 O(kS)；也可给较宽上界 O(nk²)。
  • 额外空间 O(k)：两层数组和当前栈截断后的前缀和；不计输入。交互演示为支持回退保存快照，空间不代表提交算法。

替代方案

记忆化搜索 f(i, j) 枚举第 i 栈取多少枚，状态和转移相同，需 O(nk) 缓存且递归深度可达 n；Python 要留意递归深度。二维 DP 更容易恢复具体取法，但多占 O(nk) 空间。一维原地更新也可行，j 必须从大到小枚举，且每个候选都只读上一层含义的状态；双数组更直观。

栈顶最大堆的贪心不可靠：示例 1 中先拿 7，再拿 8，只能得到 15，而先拿 1 能解锁 100。

常见错误

  • 对每个栈排序：会破坏从顶到底的取币限制。
  • 把整栈当作只能全取的一个物品：漏掉中间长度的前缀。
  • 遗漏 t = 0：强制每栈至少拿一枚。
  • 同一数组正向更新 j：可能重复消费当前栈。
  • 在“恰好 j 枚”的定义下把所有初值设为 0：把不可行状态误标为可行；应显式定义状态或使用不可达哨兵。

面试追问

  • 如何返回每栈取了几枚？在二维状态中记录最优 t，从 (n, k) 反向回溯。
  • 若允许负面值？仍可用相同递推，但不可达应改用负无穷，并继续要求恰好 k 枚。
  • 若改为最多 k 枚？可以取最终 dp[0…k] 的最大值；本题价值均为正且有足够硬币，最优会取满。
  • 还能缩小循环范围吗？用已处理硬币数限制 j，只枚举可达容量。

Java

import java.util.*;

class Solution {
    public int maxValueOfCoins(List<List<Integer>> piles, int k) {
        int[] dp = new int[k + 1];
        Arrays.fill(dp, -1);
        dp[0] = 0;
        for (List<Integer> pile : piles) {
            int m = Math.min(k, pile.size());
            int[] prefix = new int[m + 1];
            for (int t = 1; t <= m; t++)
                prefix[t] = prefix[t - 1] + pile.get(t - 1);
            int[] next = new int[k + 1];
            Arrays.fill(next, -1);
            for (int j = 0; j <= k; j++) {
                for (int t = 0; t <= Math.min(j, m); t++) {
                    if (dp[j - t] != -1)
                        next[j] = Math.max(next[j], dp[j - t] + prefix[t]);
                }
            }
            dp = next;
        }
        return dp[k];
    }
}

Python

from typing import List

class Solution:
    def maxValueOfCoins(self, piles: List[List[int]], k: int) -> int:
        dp = [-1] * (k + 1)
        dp[0] = 0
        for pile in piles:
            m = min(k, len(pile))
            prefix = [0] * (m + 1)
            for t in range(1, m + 1):
                prefix[t] = prefix[t - 1] + pile[t - 1]
            nxt = [-1] * (k + 1)
            for j in range(k + 1):
                for t in range(min(j, m) + 1):
                    if dp[j - t] != -1:
                        nxt[j] = max(nxt[j], dp[j - t] + prefix[t])
            dp = nxt
        return dp[k]

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maxValueOfCoins(vector<vector<int>>& piles, int k) {
        vector<int> dp(k + 1, -1);
        dp[0] = 0;
        for (const auto& pile : piles) {
            int m = min(k, static_cast<int>(pile.size()));
            vector<int> prefix(m + 1, 0);
            for (int t = 1; t <= m; ++t)
                prefix[t] = prefix[t - 1] + pile[t - 1];
            vector<int> next(k + 1, -1);
            for (int j = 0; j <= k; ++j) {
                for (int t = 0; t <= min(j, m); ++t) {
                    if (dp[j - t] != -1)
                        next[j] = max(next[j], dp[j - t] + prefix[t]);
                }
            }
            dp.swap(next);
        }
        return dp[k];
    }
};
