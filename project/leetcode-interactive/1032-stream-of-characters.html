LeetCode 1032 · Data Stream × Reversed Trie

字符流Stream of Characters

每次只来一个字符，却要立刻回答：到此为止的字符流，是否有一个后缀属于词典？先亲手推进字符流，再决定是否展开完整题解。

HARD设计字典树字符串数据流

题目

设计 StreamChecker：构造时接收字符串数组 words；之后每次调用 query(letter)，把一个小写字母追加到字符流。若当前完整字符流的任一非空后缀恰好是 words 中的词，返回 true，否则返回 false。

接口

  • StreamChecker(String[] words) 初始化词典。
  • boolean query(char letter) 接收新字符并判断后缀。

约束

  • 1 ≤ words.length ≤ 2000
  • 1 ≤ words[i].length ≤ 200
  • words[i] 与 letter 仅含小写英文字母
  • query 最多调用 4 × 10⁴ 次
关键语义：匹配的是当前字符流的后缀，不是任意子串。

官方示例

Input
["StreamChecker", "query", "query", "query", "query", "query", "query", "query", "query", "query", "query", "query", "query"] [[["cd", "f", "kl"]], ["a"], ["b"], ["c"], ["d"], ["e"], ["f"], ["g"], ["h"], ["i"], ["j"], ["k"], ["l"]]
Output
[null, false, false, false, true, false, true, false, false, false, false, false, true]

依次读入 a…l。读到 d 时后缀 cd 命中；读到 f 时后缀 f 命中；读到 l 时后缀 kl 命中。

Solution

把词倒过来，查询从流尾开始

核心洞察

后缀天然共享“末尾”。将每个单词倒序插入字典树后，一次查询只需从字符流末尾向前走：走到终止节点就命中，缺少下一条边就立即失败。只保留最长单词长度以内的字符，因为更早的字符不可能参与任何匹配。

完整过程

  1. 构造反向 Trie，把每个词从最后一个字符到第一个字符插入，并标记词尾。
  2. 记录最大词长 L。
  3. 每次追加字母；若缓冲区超过 L，移除最旧字符。
  4. 从缓冲区末尾向前沿 Trie 走：遇到词尾返回真，断边返回假；遍历结束仍未遇到词尾则返回假。

正确性

引理：从流尾逆序读取的前 k 个字符沿 Trie 形成路径，当且仅当长度为 k 的流后缀等于某个词的前述倒序路径。原因是 Trie 正是按词尾到词首逐字符插入。
充分性：查询到达终止节点时，该路径对应某个完整倒序词，所以原顺序下它就是当前流的后缀。
必要性：若某个词是当前流后缀，逆序扫描必依次经过该词在 Trie 中的全部节点并到达其终止节点。因此算法返回真当且仅当存在匹配后缀。

边界

  • 长度为 1 的词可在读入该字符时立即命中。
  • 一个词可能是另一个词的后缀，经过较短词的终止节点即可提前返回。
  • 重复词不影响结果；最大词长为 200，因此缓冲区始终有界。

复杂度

设词典总字符数为 S，最大词长为 L ≤ 200。构造时间与空间均为 O(S)；每次查询时间 O(L)，字符缓冲额外空间 O(L)。

替代方案

可用 Aho–Corasick 自动机将多模式流式匹配做到摊还每字符 O(1)，但失败指针与实现复杂度更高。也可维护所有 Trie 活跃状态，但状态管理更繁琐。本题最大词长仅 200，反向 Trie 更直接。

面试追问

  • 若允许动态增加/删除单词，如何维护计数与最大词长？
  • 字符集从 26 个字母扩展到 Unicode 时，节点存储如何选择？
  • 若要求极高吞吐，何时应改用 AC 自动机？

常见错误

  • 正向存 Trie，却仍从字符流尾部查，方向不一致。
  • 保存无限长的历史流，造成无意义的空间增长。
  • 只在扫描完缓冲区后检查词尾，漏掉较短后缀。
  • 把“后缀命中”误写成“历史任意位置出现”。

四语言完整实现

class StreamChecker {
    private static class Node {
        Node[] next = new Node[26];
        boolean end;
    }
    private final Node root = new Node();
    private final StringBuilder stream = new StringBuilder();
    private int maxLen = 0;

    public StreamChecker(String[] words) {
        for (String word : words) {
            maxLen = Math.max(maxLen, word.length());
            Node cur = root;
            for (int i = word.length() - 1; i >= 0; i--) {
                int x = word.charAt(i) - 'a';
                if (cur.next[x] == null) cur.next[x] = new Node();
                cur = cur.next[x];
            }
            cur.end = true;
        }
    }

    public boolean query(char letter) {
        stream.append(letter);
        if (stream.length() > maxLen) stream.deleteCharAt(0);
        Node cur = root;
        for (int i = stream.length() - 1; i >= 0; i--) {
            cur = cur.next[stream.charAt(i) - 'a'];
            if (cur == null) return false;
            if (cur.end) return true;
        }
        return false;
    }
}
var StreamChecker = function(words) {
  this.root = {};
  this.stream = [];
  this.maxLen = 0;
  for (const word of words) {
    this.maxLen = Math.max(this.maxLen, word.length);
    let node = this.root;
    for (let i = word.length - 1; i >= 0; i--) {
      const ch = word[i];
      if (!node[ch]) node[ch] = {};
      node = node[ch];
    }
    node.end = true;
  }
};

StreamChecker.prototype.query = function(letter) {
  this.stream.push(letter);
  if (this.stream.length > this.maxLen) this.stream.shift();
  let node = this.root;
  for (let i = this.stream.length - 1; i >= 0; i--) {
    node = node[this.stream[i]];
    if (!node) return false;
    if (node.end) return true;
  }
  return false;
};
class StreamChecker:
    def __init__(self, words: List[str]):
        self.root = {}
        self.stream = []
        self.max_len = 0
        for word in words:
            self.max_len = max(self.max_len, len(word))
            node = self.root
            for ch in reversed(word):
                node = node.setdefault(ch, {})
            node["#"] = True

    def query(self, letter: str) -> bool:
        self.stream.append(letter)
        if len(self.stream) > self.max_len:
            self.stream.pop(0)
        node = self.root
        for ch in reversed(self.stream):
            if ch not in node:
                return False
            node = node[ch]
            if "#" in node:
                return True
        return False
class StreamChecker {
    struct Node {
        array<Node*, 26> next{};
        bool end = false;
    };
    Node* root = new Node();
    deque<char> stream;
    int maxLen = 0;
public:
    StreamChecker(vector<string>& words) {
        for (const string& word : words) {
            maxLen = max(maxLen, (int)word.size());
            Node* cur = root;
            for (auto it = word.rbegin(); it != word.rend(); ++it) {
                int x = *it - 'a';
                if (!cur->next[x]) cur->next[x] = new Node();
                cur = cur->next[x];
            }
            cur->end = true;
        }
    }

    bool query(char letter) {
        stream.push_back(letter);
        if ((int)stream.size() > maxLen) stream.pop_front();
        Node* cur = root;
        for (auto it = stream.rbegin(); it != stream.rend(); ++it) {
            cur = cur->next[*it - 'a'];
            if (!cur) return false;
            if (cur->end) return true;
        }
        return false;
    }
};
