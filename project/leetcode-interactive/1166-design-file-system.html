LeetCode 1166 · Design File System

设计文件系统

维护一组带整数值的绝对路径：创建时父路径必须已经存在，查询时返回路径保存的值。先用下面的文件树亲手走一遍，再决定是否展开完整题解。

设计字典树哈希表字符串

题目要求

实现 FileSystem。系统最初只有隐含的根目录 /，但根目录不保存题目中的值。每个新路径都关联一个正整数。

  • 创建路径boolean createPath(String path, int value)仅当路径尚不存在，且它的直接父路径已经存在时，保存 path → value 并返回 true；否则不改变系统并返回 false。一级路径（如 /a）的父级视为根目录，可以直接创建。
  • 读取路径int get(String path)路径存在时返回关联值，否则返回 -1。

约束

  • 2 ≤ path.length ≤ 100
  • 1 ≤ value ≤ 10⁹
  • 路径以 / 开头、不以 / 结尾。
  • 路径由一段或多段小写英文字母组成，各段以 / 分隔。
  • createPath 与 get 合计调用不超过 10⁴ 次。

完整题解

把“已存在路径”当作键集合

核心洞察：要创建 path，只需确认它自己不存在，并确认去掉最后一段后的直接父路径存在。任何已存在路径在创建时已经通过相同规则，所以它更高层的祖先天然合法，无需重复遍历。
  1. 保存路径。用哈希表记录完整绝对路径到整数值的映射，根目录不必作为可查询条目保存。
  2. 定位父级。找到最后一个 /，它之前的前缀就是直接父路径；若斜杠位于下标 0，父级就是隐含根目录。
  3. 判定并写入。目标已存在则失败；非一级路径的父级不存在也失败；其余情况写入并成功。
  4. 直接查询。get 查哈希表，不存在就返回 -1。

正确性说明

不变量：哈希表中每条非一级路径的直接父路径也在哈希表中。

初始化：表为空，不变量成立；隐含根目录允许创建一级路径。

保持：createPath 仅在目标不存在且父级存在（或父级为根）时写入，所以新增项满足不变量；失败操作不写入。

结论：成功返回恰好对应题目允许的创建情形；get 从同一映射取值，故结果正确。

复杂度与边界

设路径长度为 L。提取父路径及字符串哈希都按 O(L) 计，所以两种操作的期望时间均为 O(L)。保存路径的总字符数为 S 时，空间为 O(S)。

  • /a 的父级是隐含根目录，可直接创建。
  • 重复创建必须失败，不能覆盖旧值。
  • 父路径必须是完整键，普通字符串前缀不算。
  • 查询不会自动创建路径。

替代方案：字典树

可以按路径段建立 Trie，每个节点代表一个目录名并保存值。它更适合扩展“列出子目录、删除子树、按前缀搜索”等能力；本题只有完整路径创建和查询，哈希表更简洁。Trie 的时间仍为 O(L)，但节点和实现开销更大。

四语言完整实现

import java.util.HashMap;
import java.util.Map;

class FileSystem {
    private final Map<String, Integer> values;

    public FileSystem() {
        values = new HashMap<>();
    }

    public boolean createPath(String path, int value) {
        if (values.containsKey(path)) return false;

        int lastSlash = path.lastIndexOf('/');
        String parent = path.substring(0, lastSlash);
        if (!parent.isEmpty() && !values.containsKey(parent)) {
            return false;
        }

        values.put(path, value);
        return true;
    }

    public int get(String path) {
        return values.getOrDefault(path, -1);
    }
}

    constructor() {
        this.values = new Map();
    }

     * @param {string} path
     * @param {number} value

        const lastSlash = path.lastIndexOf('/');
        const parent = path.slice(0, lastSlash);
        if (parent !== '' && !this.values.has(parent)) {
            return false;
        }

        this.values.set(path, value);
        return true;
    }

    /**
     * @param {string} path
     * @return {number}
     */

        return this.values.has(path) ? this.values.get(path) : -1;
    }
}
class FileSystem:
    def __init__(self):
        self.values = {}

    def createPath(self, path: str, value: int) -> bool:
        if path in self.values:
            return False

        last_slash = path.rfind('/')
        parent = path[:last_slash]
        if parent and parent not in self.values:
            return False

        self.values[path] = value
        return True

    def get(self, path: str) -> int:
        return self.values.get(path, -1)
#include <string>
#include <unordered_map>
using namespace std;

class FileSystem {
private:
    unordered_map<string, int> values;

public:
    FileSystem() = default;

    bool createPath(string path, int value) {
        if (values.count(path)) return false;

        size_t lastSlash = path.rfind('/');
        string parent = path.substr(0, lastSlash);
        if (!parent.empty() && !values.count(parent)) {
            return false;
        }

        values[path] = value;
        return true;
    }

    int get(string path) {
        auto it = values.find(path);
        return it == values.end() ? -1 : it->second;
    }
};

面试追问

  • 如何支持删除？需先定义非空目录能否删除；哈希表要额外维护孩子关系，Trie 更自然。
  • 如何支持并发创建？“检查重复和父级 → 写入”必须是原子操作，可用锁或事务。
  • 如何列出直接孩子？纯哈希表会全表扫描，应加邻接表或改用 Trie。
  • 如何持久化？可把路径设为唯一键，用父路径外键或事务维持不变量。

常见错误

  • 把任意字符串前缀误当父路径。
  • 要求一级路径的空字符串父级也出现在哈希表。
  • 重复创建时覆盖旧值，而不是返回 false。
  • 查询缺失路径时修改了文件系统状态。
