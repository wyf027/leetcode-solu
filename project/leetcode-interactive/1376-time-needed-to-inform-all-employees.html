通知所有员工
所需的时间

Time Needed to Inform All Employees

树深度优先搜索广度优先搜索非付费题

Problem

题目说明

公司共有 n 名员工，编号为 0 到 n - 1，总负责人编号为 headID。数组 manager 给出每名员工的直属负责人，其中 manager[headID] = -1，整个上下级关系构成一棵树。

紧急消息从总负责人开始向下传播。员工 i 需要 informTime[i] 分钟同时通知其所有直属下属；这些下属收到消息后才能继续通知自己的下属。请返回让所有员工都获知消息所需的分钟数。

函数签名： numOfMinutes(n, headID, manager, informTime) → integer

官方示例 1

输入：n = 1, headID = 0,
manager = [-1],
informTime = [0]
输出：0

总负责人就是公司唯一的员工。

官方示例 2

输入：n = 6, headID = 2,
manager = [2,2,-1,2,2,2],
informTime = [0,0,1,0,0,0]
输出：1

员工 2 直接管理其余所有员工，用 1 分钟完成通知。

约束

  • 1 ≤ n ≤ 105
  • 0 ≤ headID < n
  • manager.length == n
  • 除总负责人外，0 ≤ manager[i] < n；且 manager[headID] == -1
  • informTime.length == n
  • 0 ≤ informTime[i] ≤ 1000
  • 员工 i 没有下属时，informTime[i] == 0
  • 题目保证所有员工最终都能收到通知

想好如何计算总耗时了吗？

Solution

把管理关系反向建成树

核心洞察

每名员工收到消息的时刻，等于从总负责人到该员工路径上所有上级的 informTime 之和。不同分支并行传播，因此答案不是所有耗时之和，而是所有根到节点路径累计时间的最大值。

完整过程

  1. 遍历 manager，为每个负责人收集直属下属，得到从上到下的邻接表。
  2. 把 (headID, 0) 放入栈；第二个值表示该员工收到消息的时刻。
  3. 弹出员工 u，其下属 v 的收到时刻为 time[u] + informTime[u]。
  4. 更新最大收到时刻，并继续遍历，直到所有员工处理完毕。

正确性说明

  1. 路径时间正确：根的收到时刻为 0；若员工 u 的时刻正确，则直属下属恰好在再过 informTime[u] 后收到，归纳可知所有节点时刻都正确。
  2. 覆盖完整：上下级关系是一棵以 headID 为根的树，遍历每条父子边一次，所以每名员工都会且只会被访问一次。
  3. 答案正确：全员获知的最早时刻由最后收到消息的员工决定，即所有正确收到时刻的最大值。

边界情况

  • 只有总负责人：答案为 0。
  • 星形组织：答案就是总负责人的通知耗时。
  • 退化成长度 n 的链：使用显式栈，避免递归深度风险。
  • 叶子耗时为 0，不会给路径额外增加时间。

复杂度

建图和遍历都只处理每名员工、每条管理边一次。

时间：O(n)
空间：O(n)（邻接表与遍历栈）

四种语言完整代码

以下均采用迭代 DFS，适配 n = 105 的深链情况。

Java 
import java.util.*;

class Solution {
    public int numOfMinutes(int n, int headID, int[] manager, int[] informTime) {
        List<List<Integer>> children = new ArrayList<>(n);
        for (int i = 0; i < n; i++) {
            children.add(new ArrayList<>());
        }
        for (int employee = 0; employee < n; employee++) {
            if (manager[employee] != -1) {
                children.get(manager[employee]).add(employee);
            }
        }

        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[] {headID, 0});
        int answer = 0;

        while (!stack.isEmpty()) {
            int[] current = stack.pop();
            int employee = current[0];
            int receiveTime = current[1];
            answer = Math.max(answer, receiveTime);

            for (int subordinate : children.get(employee)) {
                stack.push(new int[] {
                    subordinate,
                    receiveTime + informTime[employee]
                });
            }
        }
        return answer;
    }
}

var numOfMinutes = function(n, headID, manager, informTime) {
    const children = Array.from({ length: n }, () => []);

    for (let employee = 0; employee < n; employee++) {
        if (manager[employee] !== -1) {
            children[manager[employee]].push(employee);
        }
    }

    const stack = [[headID, 0]];
    let answer = 0;

    while (stack.length > 0) {
        const [employee, receiveTime] = stack.pop();
        answer = Math.max(answer, receiveTime);

        for (const subordinate of children[employee]) {
            stack.push([
                subordinate,
                receiveTime + informTime[employee]
            ]);
        }
    }
    return answer;
};

C++ 
#include <algorithm>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int numOfMinutes(
        int n,
        int headID,
        vector<int>& manager,
        vector<int>& informTime
    ) {
        vector<vector<int>> children(n);
        for (int employee = 0; employee < n; ++employee) {
            if (manager[employee] != -1) {
                children[manager[employee]].push_back(employee);
            }
        }

        vector<pair<int, int>> stack;
        stack.push_back({headID, 0});
        int answer = 0;

        while (!stack.empty()) {
            auto [employee, receiveTime] = stack.back();
            stack.pop_back();
            answer = max(answer, receiveTime);

            for (int subordinate : children[employee]) {
                stack.push_back({
                    subordinate,
                    receiveTime + informTime[employee]
                });
            }
        }
        return answer;
    }
};

替代方案

  • BFS：队列存储员工与收到时刻，复杂度同样为 O(n)；更贴近逐层传播的直觉。
  • 沿 manager 向上记忆化：直接求每名员工到根的累计耗时，避免显式建子节点表；需要缓存以防重复计算。
  • 递归 DFS：代码简洁，但长度接近 105 的链可能触发语言栈溢出。

面试追问

  • 如果每个下属的通知耗时不同，边权和状态应如何调整？
  • 如果管理关系会动态变化，怎样支持多次查询？
  • 若要返回最后收到消息的员工编号，如何处理并列？
  • 为什么这里取最大值，而不是把每个负责人的耗时相加？

常见错误

  • 把 informTime[child] 加到下属的收到时刻；正确增加的是当前负责人 informTime[parent]。
  • 把并行分支的时间相加；不同负责人可以同时传播，应比较各分支完成时间。
  • 把叶子自己的 informTime 计入答案；员工收到消息即算完成，无需等待它通知不存在的下属。
  • 直接对 manager 做向下遍历，却没有先建立“负责人 → 下属”的索引。
