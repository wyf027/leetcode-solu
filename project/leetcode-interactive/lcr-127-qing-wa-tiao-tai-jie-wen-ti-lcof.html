跳跃训练

一只青蛙每次可跳上 1 级或 2 级台阶。给定总台阶数 n，求跳到第 n 级的不同方法数，结果取模 1_000_000_007。

题意

从第 0 级开始，青蛙需要恰好到达第 n 级。一次只能前进 1 级或 2 级；不同的跳跃顺序算作不同方法。

示例

n = 2 → 2（1+1，2）

n = 7 → 21

约束

0 ≤ n ≤ 100。到达第 0 级有 1 种方式：不跳。

分步交互：滚动状态

每一步展示 f(i) = f(i - 1) + f(i - 2) 的计算。

准备就绪。

    核心洞察

    最后一跳只有两种可能：从第 n-1 级跳 1 级，或从第 n-2 级跳 2 级。因此 f(n)=f(n-1)+f(n-2)。这是斐波那契递推，但本题的初值是 f(0)=1,f(1)=1。

    完整过程

    1. 处理 n=0 和 n=1，直接返回 1。
    2. 用两个变量保存前两项：a=f(i-2)、b=f(i-1)。
    3. 从 2 迭代到 n，计算 next=(a+b)%MOD，再向前滚动变量。

    边界

    • n=0 不是 0 种，而是空跳法 1 种。
    • n=1 只有一次跳 1 级。
    • 每轮相加后立即取模，避免不同语言的整数溢出。

    复杂度

    时间 O(n)，空间 O(1)。只需要两个历史状态，无需保存整张 DP 表。

    替代方案与追问

    数组 DP 写法更直观但空间为 O(n)；递归若不记忆化会指数爆炸。追问：若一次能跳 1、2、3 级，则改为三项递推；若 n 极大，可用矩阵快速幂把时间降为 O(log n)。

    常见错误

    • 误设 f(0)=0，使所有结果偏小。
    • 直接递归而没有缓存，重复计算大量子问题。
    • 忘记取模，较大的 n 会溢出。

    官方签名代码

    // Java
class Solution { public int numWays(int n) { final int mod=1000000007; int a=1,b=1; for(int i=2;i<=n;i++){int c=(a+b)%mod;a=b;b=c;} return b; } }
    // JavaScript
var numWays = function(n) { const mod=1000000007; let a=1,b=1; for(let i=2;i<=n;i++){[a,b]=[b,(a+b)%mod];} return b; };
    # Python
class Solution:
    def numWays(self, n: int) -> int:
        a = b = 1
        for _ in range(2, n + 1):
            a, b = b, (a + b) % 1000000007
        return b
    // C++
class Solution { public: int numWays(int n) { const int mod=1000000007; long long a=1,b=1; for(int i=2;i<=n;++i){long long c=(a+b)%mod;a=b;b=c;} return b; } };
