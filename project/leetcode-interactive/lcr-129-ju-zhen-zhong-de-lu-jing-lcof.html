LCR 129·深度优先搜索MEDIUM

字母迷宫

从方格的任意位置出发，沿上下左右相邻格拼出目标字符串。回溯让每条路径都干净地“试过即还原”。

开始分步演示

题意

在字符矩阵 grid 中判断是否存在一条路径，恰好依次拼出 target。路径每一步只能向上、下、左、右移动，同一个格子在同一路径中不能重复使用。

示例

grid = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]

target = "ABCCED"

输出：true

约束

  • 1 <= grid.length, grid[i].length <= 200
  • 1 <= target.length <= 15
  • 矩阵和目标串均由英文字母组成。

核心洞察

把“当前位置能否完成剩余后缀”定义为一个递归问题。进入格子时临时标记为已访问；四个方向都失败后，恢复原字符，交给其他起点继续尝试。

状态：(row, col, index)。其中 index 表示已匹配到目标串的第几个字符。

分步交互

用目标串 ABCCED 观察一条成功的 DFS 路径。

快捷键：Enter

完整过程

  1. 枚举每个格子，作为目标串第一个字符的潜在起点。
  2. 若越界、字符不匹配或格子已访问，当前分支立即失败。
  3. 匹配完成最后一个字符时返回成功；否则标记当前格，向四邻递归。
  4. 任一方向成功即返回；全部失败则撤销标记，这就是回溯。

边界

  • 目标长度为 1 时，只需查找一个相同字符。
  • 矩阵中不存在首字符可快速跳过该起点。
  • 不能只用全局访问标记而不恢复，否则会错误剪掉其他路径。

复杂度

时间最坏为 O(m · n · 3k)，其中 k 是目标串长度；首步后通常不回头。

递归栈空间为 O(k)。

替代方案

可使用独立的 visited 矩阵，代码更直观，但空间为 O(mn)。原地把字符临时改为特殊标记，恢复后即可省去该矩阵。

官方签名代码

class Solution {
    public boolean wordPuzzle(char[][] grid, String target) {
        for (int r = 0; r < grid.length; r++)
            for (int c = 0; c < grid[0].length; c++)
                if (dfs(grid, target, r, c, 0)) return true;
        return false;
    }
    private boolean dfs(char[][] g, String s, int r, int c, int i) {
        if (r < 0 || r == g.length || c < 0 || c == g[0].length || g[r][c] != s.charAt(i)) return false;
        if (i == s.length() - 1) return true;
        char keep = g[r][c]; g[r][c] = '#';
        boolean ok = dfs(g, s, r + 1, c, i + 1) || dfs(g, s, r - 1, c, i + 1) || dfs(g, s, r, c + 1, i + 1) || dfs(g, s, r, c - 1, i + 1);
        g[r][c] = keep;
        return ok;
    }
}
var wordPuzzle = function(grid, target) {
  const dfs = (r, c, i) => {
    if (r < 0 || r === grid.length || c < 0 || c === grid[0].length || grid[r][c] !== target[i]) return false;
    if (i === target.length - 1) return true;
    const keep = grid[r][c]; grid[r][c] = '#';
    const ok = dfs(r + 1, c, i + 1) || dfs(r - 1, c, i + 1) || dfs(r, c + 1, i + 1) || dfs(r, c - 1, i + 1);
    grid[r][c] = keep;
    return ok;
  };
  return grid.some((row, r) => row.some((_, c) => dfs(r, c, 0)));
};
class Solution:
    def wordPuzzle(self, grid: List[List[str]], target: str) -> bool:
        def dfs(r: int, c: int, i: int) -> bool:
            if not (0 <= r < len(grid) and 0 <= c < len(grid[0])) or grid[r][c] != target[i]:
                return False
            if i == len(target) - 1:
                return True
            keep, grid[r][c] = grid[r][c], '#'
            ok = any(dfs(r + dr, c + dc, i + 1) for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)))
            grid[r][c] = keep
            return ok
        return any(dfs(r, c, 0) for r in range(len(grid)) for c in range(len(grid[0])))

追问与常见错误

追问

如何进一步剪枝？可先统计每个字符在矩阵和目标串中的次数；若目标串中某字符更多，直接返回 false。还可从更稀少的一端字符开始匹配。

常见错误

  • 忘记在递归返回前恢复格子，污染后续搜索。
  • 只检查字符而遗漏越界检查。
  • 允许斜向移动或复用同一格，改变了题目规则。

测试与验证区

建议覆盖单格、路径转弯、相同字母密集、需要回溯以及不存在目标串的情况。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。
