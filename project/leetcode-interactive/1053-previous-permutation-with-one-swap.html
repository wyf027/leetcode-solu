交换一次的
先前排列

Previous Permutation With One Swap

题目

给定可能含重复元素的正整数数组 arr。交换恰好两个位置后，在所有字典序严格小于原数组的结果中，返回字典序最大的一个；若不存在这样的交换，返回原数组。

函数形式：prevPermOpt1(arr: integer[]): integer[]

约束

1 ≤ arr.length ≤ 10⁴1 ≤ arr[i] ≤ 10⁴

字典序比较从左到右，在首个不同位置由数值较小的一方更小。

官方示例

输入：arr = [3,2,1]
输出：[3,1,2]
解释：交换 2 和 1。
输入：arr = [1,1,5]
输出：[1,1,5]
解释：它已经是最小排列。
输入：arr = [1,9,4,6,7]
输出：[1,7,4,6,9]
解释：交换 9 和 7。

一次交换，怎样“只退一小步”？

用示例 [1,9,4,6,7] 观察寻找下降点、候选值与交换的过程。

题解：最靠右的下降点 + 最合适的替换值

核心洞察：为了让结果尽可能大，首个发生变化的位置必须尽量靠右；在该位置变小后，又应选择右侧严格小于它的最大值。若这个最大值重复，选最左边那个，避免把较大值过早放进后缀。

完整过程

  1. 从右向左找第一个 arr[i] > arr[i+1]。若找不到，数组非递减，无法得到更小排列。
  2. 在 i 右侧从右向左找第一个严格小于 arr[i] 的元素。因为下降点右侧非递减，从右侧遇到的即为最大候选值。
  3. 若候选值有重复，继续向左移动到这组相同值的最左位置。
  4. 交换 arr[i] 与 arr[j] 并返回。

正确性

下降点右侧之前都无法作为更靠右的首差位置，因此选择最右下降点使前缀保持最长。固定该位置后，放入所有可行小值中的最大值，会最大化首个差异位。候选值相同时选择最左者，使被换出的较大值落得更靠左之后的位置更晚，从而令后缀最大。因此所得数组正是一次交换可达的最大前驱。

边界

  • 长度 1 或整体非递减：原样返回。
  • 候选值必须严格小于轴点。
  • 右侧存在重复候选：交换最左副本。

复杂度

时间 O(n)；除返回数组本身外，额外空间 O(1)。

替代方案

枚举所有交换并比较需要 O(n³)（含数组比较），排序候选也至少 O(n log n)，都没有利用后缀单调性。

面试追问

  • 为什么重复候选要选最左边？可用 [3,1,1,3] 演示。
  • 若允许任意次交换，如何构造标准的前一排列？
  • 若输入不可修改，空间复杂度会怎样变化？

常见错误

  • 寻找最左下降点，导致结果退得太多。
  • 选择小于轴点的最小值，而不是最大值。
  • 对相同候选取最右副本，得到的后缀不是最大。
  • 用 <= 接受相等值，交换后可能没有变化。
