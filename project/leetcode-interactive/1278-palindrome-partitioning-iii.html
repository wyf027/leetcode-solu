分割回文串 III

把一个字符串切成恰好 k 个非空片段，并允许修改字符，使每个片段都成为回文串。你的任务是找出最少修改次数。

01 / Problem

先把目标说清楚

题意

给定仅含小写英文字母的字符串 s 与整数 k。你可以把若干字符改成其他小写字母，然后将 s 分成恰好 k 个连续、非空、互不重叠且覆盖整个字符串的子串。

要求每个子串最终都是回文串，返回需要修改的最少字符数。

注意：一次修改按一个字符计数；切割本身不产生成本。每个字符恰好属于一个片段。

约束

  • 1 ≤ k ≤ s.length ≤ 100
  • s 只包含小写英文字母
  • 函数签名：palindromePartition(s, k)
  • 返回值：最少修改次数（整数）
EXAMPLE 01
输入：s = "abc", k = 2
输出：1

可切成 "ab" 与 "c"；前者修改一个字符即可成为回文串。

EXAMPLE 02
输入：s = "aabbc", k = 3
输出：0

可切成 "aa"、"bb"、"c"，无需修改。

EXAMPLE 03
输入：s = "leetcode", k = 8
输出：0

每个字符各自成为一个片段；长度为 1 的字符串天然回文。

区间成本预处理 + 分段 DP

核心洞察完整过程正确性边界情况复杂度替代方案四语言代码面试追问常见错误测试与验证

核心洞察

问题可以拆成两层：先回答“任意子串变成回文串要改多少字符”，再回答“把前缀切成若干段的总成本最小是多少”。一个片段变成回文串时，只需比较首尾向内的字符对；不相同的一对恰好贡献一次修改。

cost[i][j] = cost[i + 1][j − 1] + (s[i] ≠ s[j] ? 1 : 0)

定义 dp[p][end]：将前 end 个字符恰好切成 p 个非空回文片段所需的最少修改数。

dp[p][end] = min(dp[p − 1][start] + cost[start][end − 1])

完整过程

  1. 用区间长度从小到大填充 cost。长度 1 的成本为 0；较长区间由内层区间加上首尾是否失配得到。
  2. 令所有 DP 状态为无穷大，只设 dp[0][0] = 0。
  3. 枚举片段数 p = 1..k，再枚举前缀终点 end = p..n。
  4. 枚举最后一段起点 start。前 start 个字符由 p − 1 段覆盖，最后一段是 s[start..end−1]。
  5. 所有合法起点中取最小值，最终返回 dp[k][n]。

正确性证明

引理 1：cost[i][j] 等于子串 s[i..j] 变为回文串所需的最少修改数。因为回文要求对称位置相等：相等字符对无需修改，不等字符对至少改一个且改一个就足够；不同对互不重叠，逐对相加即为最优。

引理 2：dp[p][end] 枚举了前 end 个字符切成 p 段的所有方案。任何合法方案都有唯一的最后一段起点 start，其前缀最优成本是 dp[p−1][start]，最后一段成本是 cost[start][end−1]。

结论：转移对全部合法最后切点取最小值；依据片段数归纳，每个 DP 状态均最优，因此 dp[k][n] 正是题目所求。

边界情况

  • k = 1：答案就是整个字符串的回文修改成本。
  • k = n：每段长度为 1，答案必为 0。
  • 字符串本身已有适合的切分：答案可能为 0。
  • DP 中必须保证每段非空，因此 end ≥ p 且 start ≥ p − 1。

复杂度

预处理区间成本为 O(n²)。DP 有片段数、前缀终点、最后切点三重枚举，为 O(k·n²)；总时间复杂度 O(k·n²)。空间保存 cost 和 dp，为 O(n² + k·n)。

替代方案

  • 记忆化搜索：用 dfs(pos, parts) 枚举下一段终点，配合同一张 cost 表。复杂度相同，表达更贴近“从当前位置继续切”。
  • 滚动数组：DP 只依赖上一层片段数，可把 k·n 降为 n；但区间成本仍需 O(n²)。
  • 暴力枚举切点：需要考察组合数量级的分割方案，会随字符串长度快速失控，不适合 n = 100。

class Solution {
    public int palindromePartition(String s, int k) {
        int n = s.length();
        int[][] cost = new int[n][n];
        for (int len = 2; len <= n; len++) {
            for (int left = 0; left + len <= n; left++) {
                int right = left + len - 1;
                cost[left][right] = (len > 2 ? cost[left + 1][right - 1] : 0)
                        + (s.charAt(left) == s.charAt(right) ? 0 : 1);
            }
        }

        int inf = 1_000_000;
        int[][] dp = new int[k + 1][n + 1];
        for (int[] row : dp) java.util.Arrays.fill(row, inf);
        dp[0][0] = 0;

        for (int parts = 1; parts <= k; parts++) {
            for (int end = parts; end <= n; end++) {
                for (int start = parts - 1; start < end; start++) {
                    dp[parts][end] = Math.min(dp[parts][end],
                            dp[parts - 1][start] + cost[start][end - 1]);
                }
            }
        }
        return dp[k][n];
    }
}

var palindromePartition = function(s, k) {
    const n = s.length;
    const cost = Array.from({ length: n }, () => Array(n).fill(0));

    for (let len = 2; len <= n; len++) {
        for (let left = 0; left + len <= n; left++) {
            const right = left + len - 1;
            const inner = len > 2 ? cost[left + 1][right - 1] : 0;
            cost[left][right] = inner + (s[left] === s[right] ? 0 : 1);
        }
    }

    const INF = Number.MAX_SAFE_INTEGER;
    const dp = Array.from({ length: k + 1 }, () => Array(n + 1).fill(INF));
    dp[0][0] = 0;

    for (let parts = 1; parts <= k; parts++) {

            for (let start = parts - 1; start < end; start++) {
                dp[parts][end] = Math.min(
                    dp[parts][end],
                    dp[parts - 1][start] + cost[start][end - 1]
                );
            }
        }
    }
    return dp[k][n];

class Solution:
    def palindromePartition(self, s: str, k: int) -> int:
        n = len(s)
        cost = [[0] * n for _ in range(n)]

        for length in range(2, n + 1):
            for left in range(n - length + 1):
                right = left + length - 1
                inner = cost[left + 1][right - 1] if length > 2 else 0
                cost[left][right] = inner + (s[left] != s[right])

        inf = 10 ** 9
        dp = [[inf] * (n + 1) for _ in range(k + 1)]
        dp[0][0] = 0

        for parts in range(1, k + 1):
            for end in range(parts, n + 1):
                for start in range(parts - 1, end):
                    dp[parts][end] = min(
                        dp[parts][end],
                        dp[parts - 1][start] + cost[start][end - 1]
                    )
        return dp[k][n]

class Solution {
public:
    int palindromePartition(string s, int k) {
        int n = static_cast<int>(s.size());
        vector<vector<int>> cost(n, vector<int>(n, 0));

        for (int len = 2; len <= n; ++len) {
            for (int left = 0; left + len <= n; ++left) {
                int right = left + len - 1;
                int inner = len > 2 ? cost[left + 1][right - 1] : 0;
                cost[left][right] = inner + (s[left] == s[right] ? 0 : 1);
            }
        }

        const int INF = 1e9;
        vector<vector<int>> dp(k + 1, vector<int>(n + 1, INF));
        dp[0][0] = 0;

        for (int parts = 1; parts <= k; ++parts) {
            for (int end = parts; end <= n; ++end) {
                for (int start = parts - 1; start < end; ++start) {
                    dp[parts][end] = min(
                        dp[parts][end],
                        dp[parts - 1][start] + cost[start][end - 1]
                    );
                }
            }
        }
        return dp[k][n];
    }
};

面试追问

  • 如何恢复具体切割方案？ 记录每个 dp[p][end] 取得最小值时的 start，再从 (k,n) 反向追踪。
  • 如何输出修改后的回文串？ 对恢复出的每一段双指针扫描，每遇到失配，把任一侧改成另一侧即可。
  • 空间能否优化？ 分段 DP 可滚动到两行，但若需恢复路径，要额外保存决策或重新计算。
  • 为什么不是回文判断表？ 这里需要的是最少修改数，不只是“是否为回文”；成本表保留了更完整的信息。

常见错误

  • 把一次失配当成修改两个字符；实际上改一侧即可。
  • 允许空片段，导致起点枚举从 0 开始而没有满足 start ≥ parts−1。
  • 混淆闭区间 cost[start][end−1] 与半开前缀 [0,end)。
  • 忘记初始化 dp[0][0] = 0，或让不可达状态参与加法。
  • 只判断子串是否回文，没有累加把它改成回文所需的最少次数。
