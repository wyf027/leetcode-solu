Next Palindrome Using Same Digits

相同的数字，严格更大的回文。
先理解目标，再打开下方的推演与题解。

01 / 题目任务

给定数字字符串 num，它已经是一个回文数。重新排列其全部数字，寻找数值严格大于原数、且在这些候选中最小的回文字符串；无法构造时返回空字符串 ""。每个数字的使用次数必须保持不变。

参数与返回：nextPalindrome(num: string) → string
约束：1 ≤ num.length ≤ 10⁵；num 为回文数字字符串。回文指正读与倒读相同；不要转换为机器整数处理。

示例 1

输入：num = "1221"
输出："2112"

2112 是符合要求的最小更大回文。

示例 2

输入：num = "32123"
输出：""

无论如何重排，都没有更大的回文。

示例 3

输入：num = "45544554"
输出："54455445"

数字数量不变，结果仍左右对称。

题名、签名和示例输入来自本地官方元数据。付费题面为空；示例输出与约束依据公开题面存档转述。LeetCode 原题。

02 / 先想一想

如果最左侧的某一位变大，右边的数字还能改变两个等长数字的大小关系吗？奇数长度时，中间的一位有多少选择？

下方独立题解包含交互推演和四语言代码。展开后才显示算法过程。

03 / 半边重排，整串镜像

核心洞察：回文的右半段由左半段唯一确定。数字总频次固定，左半段每种数字的数量也固定；奇数长度时，唯一的奇数频次数字只能留在中心。因此只需找到左半段的下一个字典序排列。

完整过程
  1. 令 m = floor(n / 2)，只处理区间 [0, m)，中间位不参与。
  2. 从右向左找到首个 a[i] < a[i+1]。若没有，左半段已最大，返回空串。
  3. 从左半段末尾向左，找到首个 a[j] > a[i]，交换两位。
  4. 反转左半段后缀 [i+1, m)，让增大后的尾部尽可能小。
  5. 将新左半段反向复制到右半段，中心位保持原值。

05 / 为什么得到的恰好是下一个？

正确性

固定数字频次后，每种数字在左右两边必须平分（中心占用一枚时先扣除）。因此所有合法回文与左半段的不同排列一一对应。等长字符串的比较由第一个不同的位置决定；左半段的字典序也就是整个回文的大小顺序。

扫描得到的后缀为非递增序列，已经是这些数字的最大排列，不能仅在后缀内增大。选择最右支点，保留尽可能长的前缀；再从非递增后缀中选择最小的严格更大值，得到该位置的最小增量。交换后后缀仍非递增，将其反转为升序便是最小后缀。于是得到严格大于原左半段的最小排列。

镜像恢复后仍保持数字频次与回文性质。若支点不存在，左半段已是最大排列，一一对应关系说明全串也无更大答案。

边界与复杂度

  • 长度 1–3：左半段至多一位，不能得到更大排列。
  • 全相同或左半段非递增：返回 ""，不能返回原串。
  • 重复数字：支点比较使用 >=，后继搜索跳过 <=，保证严格增大。
  • 奇数长度：不移动、不复制中心位。
  • 包含 0：字符比较与数字次序一致。原串无前导零时，下一个更大排列也不会引入前导零。

时间 O(n)：扫描、反转、镜像均为线性。空间 O(n)：Java / JS / Python 创建可变数组和结果；C++ 在按值字符串内修改，除该字符串与返回结果外的算法辅助空间为 O(1)。

替代方案

枚举左半段全部排列后选取最小更大者，候选数最坏达 m!，无法应对 10⁵ 位。交换支点后对后缀排序也正确，但需要 O(n log n) 时间；这里已知后缀单调，直接反转即可。C++ 的 std::next_permutation 可以直接完成左半段更新。

常见错误

对整个字符串求下一个排列会破坏回文；只交换支点不反转后缀可能跳过更小答案；把中心位纳入排列会改变镜像结构；转为 Number / long 会丢精度或溢出；C++ 用无符号长度减 2 可能下溢。

面试追问

  • 若输入不是回文？先按频次判断能否组成回文，再求大于给定阈值的最小合法回文，不能直接沿用原左半段。
  • 求上一个回文？反转比较方向，选最大的严格更小后继，后缀改为降序。
  • 求第 k 个更大回文？小 k 可重复更新，大 k 需考虑重复数字的多重集排列计数与排名。

06 / 四语言提交代码

接口依据官方元数据 nextPalindrome(num: string) → string；以下实现尚未执行验证。

Java

class Solution {
    public String nextPalindrome(String num) {
        char[] a = num.toCharArray();
        int n = a.length, m = n / 2, i = m - 2;
        while (i >= 0 && a[i] >= a[i + 1]) i--;
        if (i < 0) return "";
        int j = m - 1;
        while (a[j] <= a[i]) j--;
        char t = a[i]; a[i] = a[j]; a[j] = t;
        for (int l = i + 1, r = m - 1; l < r; l++, r--) {
            t = a[l]; a[l] = a[r]; a[r] = t;
        }
        for (int k = 0; k < m; k++) a[n - 1 - k] = a[k];
        return new String(a);
    }
}

JavaScript

/** @param {string} num @return {string} */
var nextPalindrome = function(num) {
    const a = num.split(''), n = a.length, m = Math.floor(n / 2);
    let i = m - 2;
    while (i >= 0 && a[i] >= a[i + 1]) i--;
    if (i < 0) return "";
    let j = m - 1;
    while (a[j] <= a[i]) j--;
    [a[i], a[j]] = [a[j], a[i]];
    for (let l = i + 1, r = m - 1; l < r; l++, r--)
        [a[l], a[r]] = [a[r], a[l]];
    for (let k = 0; k < m; k++) a[n - 1 - k] = a[k];
    return a.join('');
};

Python

class Solution:
    def nextPalindrome(self, num: str) -> str:
        a = list(num)
        n = len(a)
        m = n // 2
        i = m - 2
        while i >= 0 and a[i] >= a[i + 1]:
            i -= 1
        if i < 0:
            return ""
        j = m - 1
        while a[j] <= a[i]:
            j -= 1
        a[i], a[j] = a[j], a[i]
        l, r = i + 1, m - 1
        while l < r:
            a[l], a[r] = a[r], a[l]
            l += 1
            r -= 1
        for k in range(m):
            a[n - 1 - k] = a[k]
        return "".join(a)

#include <algorithm>
#include <string>
using namespace std;

class Solution {
public:
    string nextPalindrome(string num) {
        int n = static_cast<int>(num.size());
        int m = n / 2;
        if (!next_permutation(num.begin(), num.begin() + m)) return "";
        for (int k = 0; k < m; ++k) num[n - 1 - k] = num[k];
        return num;
    }
};
