Number of Distinct Roll Sequences

先观察限制，再展开你的解法。

官方题目 ↗

01 / 题目

为每一次掷骰子安排点数

给定整数 n，每次可以掷出 1 到 6 中的一个点数，一共掷 n 次。统计满足以下两个条件的不同序列：

  1. 任意相邻两项的最大公约数必须为 1。
  2. 任意两次相同点数之间必须至少隔着两次其他投掷，即不同位置 i、j 若点数相同，则 |i − j| > 2。

只要有一个位置的点数不同，就算不同序列。返回数量对 1,000,000,007 取模的结果；这里求数量，不求概率。

参数与返回：distinctSequences(n: integer) → integer
约束：1 ≤ n ≤ 10⁴，骰子始终为六面骰子。

官方示例 1

输入：n = 4
输出：184

合法序列包括 (1, 2, 3, 4)、(6, 1, 2, 3)、(1, 2, 3, 1)。序列 (1, 2, 1, 3) 的相同点数只相隔 2 个位置；(1, 2, 3, 6) 的相邻点数 3 和 6 不互质。满足条件的序列共有 184 个。

官方示例 2

输入：n = 2
输出：22

合法序列包括 (1, 2)、(2, 1)、(3, 2)；(3, 6)、(2, 4) 因为最大公约数不为 1 而无效。一共有 22 个合法的有序序列。

04 / 独立题解

只记住末尾两次投掷

核心洞察

追加点数 c 时，只需知道倒数第二项 a 和最后一项 b：必须满足 c ≠ a、c ≠ b、gcd(b,c) = 1。更早的点数离 c 至少有三个位置，不会违反相等点数的间隔要求。因此，同一末尾二元组的前缀可以合并计数。

dp[a][b]：当前长度的合法序列中，以 a,b 结尾的序列数。
next[b][c] += dp[a][b]，仅在上述三个条件均满足时转移，每次相加后取模。

完整过程

  1. n = 1 时直接返回 6。
  2. 枚举长度 2 的末尾对 (a,b)。若 a ≠ b 且 gcd(a,b) = 1，则 dp[a][b] = 1，否则为 0。共有 22 个合法有序对。
  3. 从长度 3 到 n，每轮创建全零的 next。枚举 a、b、c，将每个 dp 状态累加到可行的 next[b][c]。
  4. 整轮结束后再以 next 替换 dp。最后累加所有末尾对的数量，并对 10⁹+7 取模。

把演示连接到递推

对前缀 (1,2)，追加 1 因距离为 2 被拒绝，追加 2 因相邻重复被拒绝，4、6 与末尾 2 不互质；3、5 可以接受。于是 dp[1][2] 分别贡献给 next[2][3] 与 next[2][5]。不同前缀可能落入同一个新末尾对，因此必须累加，不能覆盖。

正确性证明

  1. 基础：长度 2 的全部合法序列恰为初始化时标记的互质且不同的有序对；长度 1 已单独处理。
  2. 合法性：假设 dp 只计入合法前缀。转移检查排除了新增点数与前两项的重复以及新增相邻边的不互质；其余约束已由前缀保证，因此生成的序列合法。
  3. 完备性与不重不漏：任何长度增加一的合法序列，删除末项后得到唯一合法前缀。它的最后三项必满足转移条件，因而一定被计入。前缀和末项唯一，不会因合并状态而重复计数。
  4. 结论：归纳得到最终 dp 按末尾对完整划分所有合法序列，求和即所求数量。模加法保持总数的余数正确。

边界与数值

  • gcd(1,1) = 1，所以互质不能代替“不相等”条件。
  • 距离恰为 2 的相等点数仍不合法；距离为 3 则允许，例如 (1,2,3,1)。
  • n = 2 不执行转移，直接汇总初始化结果；不需要给不存在的前项设置哨兵。
  • 每次相加后取模；Java 使用 long，C++ 使用 long long。JavaScript 的每次加法小于 2×MOD，远低于安全整数上限。

复杂度

时间 O(n × 6³) = O(n)；空间 O(6²) = O(1)，因为只保留两层 7×7 数组（索引 0 未使用）。骰子点数固定时最大公约数运算为常数工作。若推广到 m 面骰子，直接版本为 O(nm³ log m) 时间、O(m²) 空间。

替代方案

  • 记忆化搜索：用 (剩余长度,a,b) 记忆结果，思路相同但需要 O(n×6²) 存储和 O(n) 调用栈；n = 10⁴ 时递归深度不理想。
  • 预处理合法转移：先建立每个末尾对可接的点数列表，可去掉重复 gcd 判断，改善常数。
  • 矩阵快速幂：把合法末尾对作为状态构造转移矩阵，适合 n 极大时；本题长度上限下线性滚动 DP 更直接。

常见错误

  • 只记最后一个点数，漏掉与倒数第二项相等的情况。
  • 额外要求 gcd(a,c) = 1；题目只要求相邻互质，这会少算。
  • 原地更新 dp 导致同一轮读到新长度的数据。
  • 用赋值替代累加，丢失汇入同一状态的其他前缀。
  • 把计数误写成概率，或者把 (1,2) 与 (2,1) 合并。

面试追问

为什么不能仅存最后一项？前缀 (1,2) 与 (3,2) 的末项相同，却对追加 1 有不同结论。
若相同点数需间隔 k 次其他投掷？需要记住最近 k 次点数；状态空间随 k 增长，可以再讨论合法状态压缩。
若只需返回一个合法序列？无需累计所有方案，构造或搜索即可；计数状态是为合并大量等价前缀服务的。

Java

class Solution {
    private static final long MOD = 1_000_000_007L;

    private int gcd(int a, int b) {
        while (b != 0) {
            int t = a % b;
            a = b;
            b = t;
        }
        return a;
    }

    public int distinctSequences(int n) {
        if (n == 1) return 6;
        long[][] dp = new long[7][7];
        for (int a = 1; a <= 6; a++)
            for (int b = 1; b <= 6; b++)
                if (a != b && gcd(a, b) == 1) dp[a][b] = 1;

        for (int len = 3; len <= n; len++) {
            long[][] next = new long[7][7];
            for (int a = 1; a <= 6; a++)
                for (int b = 1; b <= 6; b++)
                    for (int c = 1; c <= 6; c++)
                        if (c != a && c != b && gcd(b, c) == 1)
                            next[b][c] = (next[b][c] + dp[a][b]) % MOD;
            dp = next;
        }
        long ans = 0;
        for (int a = 1; a <= 6; a++)
            for (int b = 1; b <= 6; b++)
                ans = (ans + dp[a][b]) % MOD;
        return (int) ans;
    }
}

var distinctSequences = function(n) {
    const MOD = 1_000_000_007;
    if (n === 1) return 6;
    const gcd = (a, b) => {
        while (b !== 0) [a, b] = [b, a % b];
        return a;
    };
    const grid = () => Array.from({ length: 7 }, () => Array(7).fill(0));
    let dp = grid();
    for (let a = 1; a <= 6; a++)
        for (let b = 1; b <= 6; b++)
            if (a !== b && gcd(a, b) === 1) dp[a][b] = 1;

    for (let len = 3; len <= n; len++) {
        const next = grid();
        for (let a = 1; a <= 6; a++)
            for (let b = 1; b <= 6; b++)
                for (let c = 1; c <= 6; c++)
                    if (c !== a && c !== b && gcd(b, c) === 1)

    for (let a = 1; a <= 6; a++)

Python 3

from math import gcd

class Solution:
    def distinctSequences(self, n: int) -> int:
        MOD = 10**9 + 7
        if n == 1:
            return 6
        dp = [[0] * 7 for _ in range(7)]
        for a in range(1, 7):
            for b in range(1, 7):
                if a != b and gcd(a, b) == 1:
                    dp[a][b] = 1

        for _ in range(3, n + 1):
            nxt = [[0] * 7 for _ in range(7)]
            for a in range(1, 7):
                for b in range(1, 7):
                    for c in range(1, 7):
                        if c != a and c != b and gcd(b, c) == 1:
                            nxt[b][c] = (nxt[b][c] + dp[a][b]) % MOD
            dp = nxt
        return sum(map(sum, dp)) % MOD
