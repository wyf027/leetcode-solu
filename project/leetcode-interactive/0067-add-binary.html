01 · Problem

题意

给定两个只包含字符 0 和 1 的非空字符串 a、b，返回它们相加后的二进制字符串。 除了字符串本身就是 "0"，输入没有前导零。

官方样例 1

输入
a = "11", b = "1"
输出
"100"

官方样例 2

输入
a = "1010", b = "1011"
输出
"10101"

约束

  • 1 ≤ a.length, b.length ≤ 10⁴
  • a、b 仅由 0 和 1 组成
  • 除零本身外，字符串不含前导零

可见字符说明：␠ 表示一个空格；本题合法输入不含空格。轨道中的 ∅ 表示该字符串在此列没有数位，不代表输入字符。

04 · Solution Vault

题解

核心思路与提交代码默认隐藏。

Core Insight

核心洞察：把字符串当作人工竖式

最低位在字符串末尾，因此用两个指针从右向左读取。每轮只需要三个量：当前的 bitA、bitB 和上一轮的 carry。令 sum = bitA + bitB + carry，则当前答案位是 sum % 2，新的进位是 ⌊sum / 2⌋。

完整过程

  1. 1.两个指针分别指向 a、b 的末尾，进位初始为 0。
  2. 2.指针越界时，该字符串在当前列贡献 0。
  3. 3.计算三者之和，把最低二进制位追加到临时答案尾部。
  4. 4.更新进位并让两个指针左移。
  5. 5.只要仍有数位或进位就继续，最后反转临时答案。

边界与不变量

  • 长度不同：短字符串耗尽后按 0 处理。
  • 最终进位：循环条件必须包含 carry != 0。
  • 零：a = "0", b = "0" 应返回 "0"。
  • 长输入：不能先转为机器整数，否则会溢出。
  • 不变量：临时数组始终保存已经处理列的正确低位，顺序为低位到高位。

时间复杂度

O(max(m, n))

每个输入数位最多读取一次。

空间复杂度

O(max(m, n))

返回字符串所需；额外状态为 O(1)。

主线选择

双指针模拟

清晰、无溢出，也是面试最推荐写法。

替代方案取舍

大整数转换：代码看似短，但 JavaScript 的普通 Number、Java 的基础整数以及 C++ 固定宽度整数都无法承受 10⁴ 位输入；依赖 BigInt 也削弱跨语言通用性。

补齐后逐列扫描：可以先把短字符串左侧补零，但会额外创建字符串；双指针在越界时直接取 0 更简洁。

常见错误

  • 循环只检查两个指针，遗漏最高位的最终进位。
  • 把字符 '0'/'1' 当成数值直接相加。
  • 低位先生成却忘记反转答案。
  • 短字符串指针越界后仍读取字符。
  • 直接解析成整数，隐藏溢出问题。

面试追问

为什么循环条件包含 carry？

最高列可能产生新的一位，例如 "1" + "1" = "10"。

能否不反转结果？

可以使用双端队列从头插入，但数组尾插再反转通常更直接、常数也更稳定。

如果扩展到任意进制？

把 2 替换为基数 base：答案位为 sum % base，进位为 ⌊sum / base⌋。

如何处理流式超长输入？

需要能从低位方向读取的存储或分块反向访问；进位依赖决定了从高位直接流入并不方便。

class Solution {
    public String addBinary(String a, String b) {
        StringBuilder answer = new StringBuilder();
        int i = a.length() - 1;
        int j = b.length() - 1;
        int carry = 0;

        while (i >= 0 || j >= 0 || carry != 0) {
            int bitA = i >= 0 ? a.charAt(i--) - '0' : 0;
            int bitB = j >= 0 ? b.charAt(j--) - '0' : 0;
            int sum = bitA + bitB + carry;

            answer.append(sum & 1);
            carry = sum >> 1;
        }

        return answer.reverse().toString();
    }
}

var addBinary = function (a, b) {
    const answer = [];
    let i = a.length - 1;
    let j = b.length - 1;
    let carry = 0;

    while (i >= 0 || j >= 0 || carry !== 0) {
        const bitA = i >= 0 ? Number(a[i--]) : 0;
        const bitB = j >= 0 ? Number(b[j--]) : 0;
        const sum = bitA + bitB + carry;

        answer.push(String(sum & 1));
        carry = sum >> 1;
    }

    return answer.reverse().join("");
};
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        answer = []
        i, j = len(a) - 1, len(b) - 1
        carry = 0

        while i >= 0 or j >= 0 or carry:
            bit_a = int(a[i]) if i >= 0 else 0
            bit_b = int(b[j]) if j >= 0 else 0
            total = bit_a + bit_b + carry

            answer.append(str(total & 1))
            carry = total >> 1
            i -= 1
            j -= 1

        return "".join(reversed(answer))
class Solution {
public:
    string addBinary(string a, string b) {
        string answer;
        int i = static_cast<int>(a.size()) - 1;
        int j = static_cast<int>(b.size()) - 1;
        int carry = 0;

        while (i >= 0 || j >= 0 || carry != 0) {
            int bitA = i >= 0 ? a[i--] - '0' : 0;
            int bitB = j >= 0 ? b[j--] - '0' : 0;
            int sum = bitA + bitB + carry;

            answer.push_back(static_cast<char>('0' + (sum & 1)));
            carry = sum >> 1;
        }

        reverse(answer.begin(), answer.end());
        return answer;
    }
};
