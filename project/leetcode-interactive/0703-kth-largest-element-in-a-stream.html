703. 数据流中的
第 K 大元素

为持续到来的整数设计一个类：每次加入新值后，立即给出截至当前的第 k 大元素。这里按排序位置计算，重复值也各自占一个位置。

Kth Largest Element in a Stream 非付费题 Heap / Priority Queue Binary Search Tree

Problem

题目要求

实现 KthLargest 类，持续维护整数流中的第 k 大元素。每次调用 add(val) 时，把 val 加入数据流，并返回此时全部元素按从大到小排序后的第 k 个值。

关键语义：求的是“第 k 大”，不是“第 k 个不同的值”。例如 [8, 8, 7] 的第 2 大仍是 8。
KthLargest(int k, int[] nums)
用目标名次 k 与初始整数流 nums 初始化对象。
int add(int val)
加入整数 val，返回当前数据流中的第 k 大元素。

703 · 完整题解

The Idea

只维护最大的 k 个元素

核心洞察：无需保存完整排序。用容量最多为 k 的小顶堆保存当前最大的 k 个值；堆顶是这组候选中最小的，因此恰好是全局第 k 大。

完整过程

  1. 记录 k，创建空的小顶堆。
  2. 构造时把 nums 中每个元素按同一套规则加入。
  3. 堆未满时直接插入新值。
  4. 堆已满时，只有新值大于堆顶才替换堆顶；否则它不可能进入最大的 k 个值。
  5. 每次 add 完成后返回堆顶。

边界情况

  • 空初始流：约束保证此时 k = 1，第一次 add 后即可返回。
  • 重复值：每次出现都占一个排名位置，不需要去重。
  • 负数：比较规则不变，小顶堆照常工作。
  • 新值等于堆顶：保留或替换结果相同，可直接忽略。

正确性证明

不变式

处理任意数量的元素后，堆中保存截至当前最大的 min(k, n) 个元素，其中 n 是已经出现的元素数。

初始化成立

堆未满时每个元素都被纳入；堆满后，只用更大的新元素替换当前候选中最小的元素。因此处理完 nums 后，不变式成立。

加入新值后仍成立

若堆未满，加入新值即可得到全部已见元素。若堆已满且 val <= heap.top()，新值不可能进入最大的 k 个；若 val > heap.top()，用它替换候选中最小者，新的堆正好仍是最大的 k 个。

返回值正确

当 add 被调用后，数据量至少为 k。由不变式，堆中是全局最大的 k 个元素；其中最小的堆顶正是全局第 k 大。

复杂度

设初始数组长度为 n。逐个加入构造时耗时 O(n log k)；每次 add 为 O(log k)，在直接丢弃时是 O(1)。堆最多保存 k 个元素，空间为 O(k)。

替代方案

始终维护完整有序数组：查询很快，但插入需要移动元素，单次可达 O(n)。

带子树大小的平衡搜索树：可在 O(log n) 插入和查询排名，也能支持删除及任意排名，但实现更复杂且空间为 O(n)。

Implementations

四种语言完整实现

Java · PriorityQueue可提交
import java.util.PriorityQueue;

class KthLargest {
    private final int k;
    private final PriorityQueue<Integer> minHeap;

    public KthLargest(int k, int[] nums) {
        this.k = k;
        this.minHeap = new PriorityQueue<>();
        for (int num : nums) {
            offer(num);
        }
    }

    public int add(int val) {
        offer(val);
        return minHeap.peek();
    }

    private void offer(int val) {
        if (minHeap.size() < k) {
            minHeap.offer(val);
        } else if (val > minHeap.peek()) {
            minHeap.poll();
            minHeap.offer(val);
        }
    }
}
JavaScript · 手写小顶堆可提交
/**
 * @param {number} k
 * @param {number[]} nums
 */
var KthLargest = function(k, nums) {
    this.k = k;
    this.heap = [];
    for (const num of nums) {
        this._offer(num);
    }
};

/**
 * @param {number} val
 * @return {number}
 */
KthLargest.prototype.add = function(val) {
    this._offer(val);
    return this.heap[0];
};

KthLargest.prototype._offer = function(val) {
    if (this.heap.length < this.k) {
        this.heap.push(val);
        this._siftUp(this.heap.length - 1);
    } else if (val > this.heap[0]) {
        this.heap[0] = val;
        this._siftDown(0);
    }
};

KthLargest.prototype._siftUp = function(index) {
    while (index > 0) {
        const parent = Math.floor((index - 1) / 2);
        if (this.heap[parent] <= this.heap[index]) break;
        [this.heap[parent], this.heap[index]] =
            [this.heap[index], this.heap[parent]];
        index = parent;
    }
};

KthLargest.prototype._siftDown = function(index) {
    const size = this.heap.length;
    while (true) {
        let smallest = index;
        const left = index * 2 + 1;
        const right = index * 2 + 2;

        if (left < size && this.heap[left] < this.heap[smallest]) {
            smallest = left;
        }
        if (right < size && this.heap[right] < this.heap[smallest]) {
            smallest = right;
        }
        if (smallest === index) break;

        [this.heap[index], this.heap[smallest]] =
            [this.heap[smallest], this.heap[index]];
        index = smallest;
    }
};
Python 3 · heapq可提交
from typing import List
import heapq


class KthLargest:
    def __init__(self, k: int, nums: List[int]):
        self.k = k
        self.heap: List[int] = []
        for num in nums:
            self._offer(num)

    def add(self, val: int) -> int:
        self._offer(val)
        return self.heap[0]

    def _offer(self, val: int) -> None:
        if len(self.heap) < self.k:
            heapq.heappush(self.heap, val)
        elif val > self.heap[0]:
            heapq.heapreplace(self.heap, val)
C++ · priority_queue可提交
#include <functional>
#include <queue>
#include <vector>
using namespace std;

class KthLargest {
private:
    int k;
    priority_queue<int, vector<int>, greater<int>> minHeap;

    void offer(int val) {
        if (static_cast<int>(minHeap.size()) < k) {
            minHeap.push(val);
        } else if (val > minHeap.top()) {
            minHeap.pop();
            minHeap.push(val);
        }
    }

public:
    KthLargest(int k, vector<int>& nums) : k(k) {
        for (int num : nums) {
            offer(num);
        }
    }

    int add(int val) {
        offer(val);
        return minHeap.top();
    }
};

面试追问

  • 若还要支持删除任意元素？ 普通堆不擅长随机删除，可用平衡树计数，或“堆 + 延迟删除”。
  • 若 k 会动态变化？ 可维护两个堆并在 k 改变时重平衡；若变化频繁，考虑顺序统计树。
  • 为何不用大顶堆？ 大顶堆直接给最大值；要得到第 k 大需要移除前 k−1 个，无法以 O(log k) 持续更新。
  • 能否把构造优化？ 可先对至多 k 个候选建堆，再扫描余下元素；渐进上限仍常写作 O(n log k)。

常见错误

!

错误去重

把第 k 大误解成第 k 个不同元素，导致重复值的排名错误。

!

保留最小的 k 个

小顶堆只是数据结构；候选池必须保留最大的 k 个，不能见值就无条件替换。

!

返回新加入的值

add 返回的是更新后堆顶，而不一定是 val。
