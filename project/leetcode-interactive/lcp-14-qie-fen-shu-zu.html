切分数组 质因数 DP

每段首尾的 gcd 必须大于 1。把“共享某个质因数”作为状态键，就能在线维护能以当前位置结尾的最佳切分。

题意

切成最少非空子数组，每段第一个数和最后一个数的最大公约数大于 1。

nums = [2,3,3,2,3,3]

期望输出：2；实际输出：2；通过 ✓

状态

best[p] 保存所有可作为某段起点、且数值含质因数 p 的位置之前的最小 DP。处理 nums[i] 时先用 dp[i-1] 更新它的质因数，再取同因数 best 的最小值。

核心洞察、过程、边界

            

              分解 nums[i]
              的不同质因数。单元素段始终合法，因此当前数也可成为下一段起点，先用上一前缀代价更新
              best。对当前质因数取最小 best 加一即 dp。预处理最小质因子，复杂度
              O(n log V) 级别；注意去重质因数、单元素和 INF。
            

          

          

            
替代方案与追问

            

              可用试除分解但在 10^5×10^6
              下较慢；最小质因子筛最稳。追问在线流时持续保留 best。常见错误：以
              gcd 全段做状态、更新顺序错误、重复质因数反复更新。

// Java
class Solution{public int splitArray(int[] a){int M=1000000,INF=1<<29;int[] sp=new int[M+1],b=new int[M+1];for(int i=2;i<=M;i++)if(sp[i]==0)for(int j=i;j<=M;j+=i)if(sp[j]==0)sp[j]=i;Arrays.fill(b,INF);int pre=0;for(int x:a){int y=x,cur=INF;while(y>1){int p=sp[y];b[p]=Math.min(b[p],pre);cur=Math.min(cur,b[p]+1);while(y%p==0)y/=p;}pre=cur;}return pre;}}

class Solution:
 def splitArray(self,a):
  M=10**6;sp=list(range(M+1));best=[10**9]*(M+1)
  for i in range(2,int(M**.5)+1):
   if sp[i]==i:
    for j in range(i*i,M+1,i):
     if sp[j]==j:sp[j]=i
  pre=0
  for x in a:
   y=x;cur=10**9
   while y>1:
    p=sp[y];best[p]=min(best[p],pre);cur=min(cur,best[p]+1)
    while y%p==0:y//=p
   pre=cur
  return pre
