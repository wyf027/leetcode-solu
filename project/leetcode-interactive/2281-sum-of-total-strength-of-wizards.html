HARD非付费题

巫师的总力量和

Sum of Total Strength of Wizards

一支队伍的力量，取决于最弱的成员，也取决于所有成员的合力。
把每一种连续队伍都考虑进去，会得到多少？

01 / 题目

给定从下标 0 开始的整数数组 strength，其中 strength[i] 是第 i 位巫师的力量。任选一个非空、连续子数组，它的总力量等于该子数组的最小值乘以元素之和。求所有子数组的总力量之和，返回对 1,000,000,007 取模的结果。

Σ（0 ≤ l ≤ r < n）min(strength[l..r]) × sum(strength[l..r])

参数：strength: integer[]；返回：integer；函数：totalStrength(strength)。

  • 1 ≤ strength.length ≤ 100,000
  • 1 ≤ strength[i] ≤ 1,000,000,000

04 / 想好自己的思路了吗？

展开后可查看推导、逐步演示和四种语言的完整实现。

核心洞察：让最小值认领队伍

把“枚举子数组”换成“枚举最小值的位置”。对每个 i，聚合所有由它负责的子数组。相同最小值出现多次时，把队伍交给最右边的最小值，保证归属唯一。

令 L[i] 为左侧最近的严格更小元素下标，R[i] 为右侧最近的小于或等于元素下标；不存在时分别是 −1 和 n。归属 i 的端点范围恰好为：

L[i] < l ≤ i ≤ r < R[i] 左端点数 = i − L[i]；右端点数 = R[i] − i

严格与非严格比较必须配对，才能让重复的最小值不重不漏。

完整过程：二重前缀和

  1. 从左向右维护单调栈：弹出值 ≥ 当前值的下标，剩余栈顶即 L[i]。
  2. 从右向左维护单调栈：弹出值 > 当前值的下标，剩余栈顶即 R[i]。
  3. 定义 P[k] 为前 k 个力量值之和，P[0]=0；再令 Q[k] 为前 k 个 P 值之和，Q[0]=0。
  4. 固定 i，子数组和为 P[r+1]−P[l]。每个右侧前缀值重复 i−L 次，每个左侧前缀值重复 R−i 次。
  5. 聚合区间和，乘以 strength[i]，累加贡献并取模。
A = Σ(r=i..R−1) P[r+1] = Q[R+1] − Q[i+1] B = Σ(l=L+1..i) P[l] = Q[i+1] − Q[L+1] Sᵢ = (i−L) × A − (R−i) × B Cᵢ = strength[i] × Sᵢ 答案 = Σ Cᵢ mod (10⁹+7)

P 长度为 n+1，Q 长度为 n+2，保证 R=n 时能访问 Q[n+1]。区间统一采用左闭右开的前缀定义。

示例 1 的 i=2：L=−1、R=4，P=[0,1,4,5,7]，Q=[0,0,1,5,10,17]。A=12、B=5，S₂=3×12−2×5=26，贡献为 26。其余下标贡献为 5、9、4，总和为 44。

正确性

  1. 边界正确：左扫描弹出的元素被更近且不大的当前元素支配，不再可能成为后续位置最近的严格更小元素。弹出结束后，栈顶就是所求边界。右扫描同理，但保留等值边界。
  2. 分组唯一：任一子数组都有唯一的最右最小值位置 i。它不能跨过左边更小的值，也不能包含右边小于等于的值，因此满足 L<l≤i≤r<R。反之，满足该范围的子数组，其最右最小值一定是 i。
  3. 聚合准确：在合法端点构成的矩形中展开 Σ(P[r+1]−P[l])，按前缀值出现次数分组，恰好得到 Sᵢ。再乘最小值即为该组贡献。
  4. 答案正确：各组不重不漏，贡献之和就是目标值。模运算与加减乘相容，逐步取模不会改变最终余数。

复杂度与边界

时间 O(n)，空间 O(n)。每轮扫描每个下标只入栈、出栈一次。每个位置的贡献在 O(1) 内求出。

  • n=1：答案为唯一元素的平方取模。
  • 全相等：每个队伍由最右位置负责。
  • 递增或递减：栈可能有 n 个元素，但总操作数仍为线性。
  • Java/C++ 使用 64 位整数，并先将 S 取模再乘力量值，最大乘积在有符号 64 位范围内。
  • JavaScript 用 BigInt，最终余数转 Number；Python 使用整数并持续取模。

常见错误

  • 两侧都找严格更小，会重复认领含等值最小值的队伍。
  • 两侧都找小于等于，会漏掉跨越等值元素的队伍。
  • 误写 Q[R] 或 Q[L]，导致前缀下标偏一。
  • 负数取余未归一化到 [0,M)。
  • JS 先用 Number 相乘，再转 BigInt：精度已丢失。
  • Java/C++ 先用 int 相乘，或在所有因子相乘后才取模：可能溢出。

替代方案与面试追问

暴力枚举：固定左端点，右移时维护区间和与最小值，时间 O(n²)、额外空间 O(1)，适合小规模解释题意，无法承受 n=10⁵。

单次弹栈结算：预先构建 Q，扫描到更小或等值元素时，弹出位置的右边界确定，可以立即结算。省去 L/R 数组，仍为 O(n) 时间与空间，但哨兵、弹栈后的左边界更易写错。

  • 能由最左最小值认领吗？可以，左边找小于等于，右边找严格更小，两侧规则一起切换。
  • 只求子数组最小值之和呢？贡献变为 strength[i]×(i−L)×(R−i)，不再需要二重前缀和。
  • 为什么一重前缀和不够？它能快速求单个区间和，第二重用于批量聚合这些前缀值。
  • 若力量值允许负数？归属和代数仍成立，但所有前缀余数都应统一规范化；下面代码按官方正整数约束实现。

Java

class Solution {
    public int totalStrength(int[] strength) {
        final long MOD = 1_000_000_007L;
        int n = strength.length, top = 0;
        int[] left = new int[n], right = new int[n], stack = new int[n];
        for (int i = 0; i < n; i++) {
            while (top > 0 && strength[stack[top - 1]] >= strength[i]) top--;
            left[i] = top == 0 ? -1 : stack[top - 1];
            stack[top++] = i;
        }
        top = 0;
        for (int i = n - 1; i >= 0; i--) {
            while (top > 0 && strength[stack[top - 1]] > strength[i]) top--;
            right[i] = top == 0 ? n : stack[top - 1];
            stack[top++] = i;
        }
        long[] prefix = new long[n + 1], q = new long[n + 2];
        for (int i = 0; i < n; i++)
            prefix[i + 1] = (prefix[i] + strength[i]) % MOD;
        for (int k = 0; k <= n; k++) q[k + 1] = (q[k] + prefix[k]) % MOD;
        long answer = 0;
        for (int i = 0; i < n; i++) {
            int l = left[i], r = right[i];
            long a = (q[r + 1] - q[i + 1] + MOD) % MOD;
            long b = (q[i + 1] - q[l + 1] + MOD) % MOD;
            long sums = ((i - l) * a % MOD - (r - i) * b % MOD + MOD) % MOD;
            answer = (answer + strength[i] * sums) % MOD;
        }
        return (int) answer;
    }
}

/**

var totalStrength = function(strength) {
    const MOD = 1000000007n, n = strength.length;
    const left = Array(n), right = Array(n), stack = [];
    for (let i = 0; i < n; i++) {
        while (stack.length && strength[stack[stack.length - 1]] >= strength[i]) stack.pop();
        left[i] = stack.length ? stack[stack.length - 1] : -1;
        stack.push(i);
    }
    stack.length = 0;
    for (let i = n - 1; i >= 0; i--) {
        while (stack.length && strength[stack[stack.length - 1]] > strength[i]) stack.pop();
        right[i] = stack.length ? stack[stack.length - 1] : n;
        stack.push(i);
    }
    const prefix = Array(n + 1).fill(0n), q = Array(n + 2).fill(0n);
    for (let i = 0; i < n; i++)
        prefix[i + 1] = (prefix[i] + BigInt(strength[i])) % MOD;
    for (let k = 0; k <= n; k++) q[k + 1] = (q[k] + prefix[k]) % MOD;
    let answer = 0n;
    for (let i = 0; i < n; i++) {
        const l = left[i], r = right[i];
        const a = (q[r + 1] - q[i + 1] + MOD) % MOD;
        const b = (q[i + 1] - q[l + 1] + MOD) % MOD;
        const sums = (BigInt(i - l) * a % MOD - BigInt(r - i) * b % MOD + MOD) % MOD;
        answer = (answer + BigInt(strength[i]) * sums) % MOD;
    }
    return Number(answer);
};

Python

from typing import List

class Solution:
    def totalStrength(self, strength: List[int]) -> int:
        mod = 10**9 + 7
        n = len(strength)
        left, right, stack = [-1] * n, [n] * n, []
        for i in range(n):
            while stack and strength[stack[-1]] >= strength[i]:
                stack.pop()
            left[i] = stack[-1] if stack else -1
            stack.append(i)
        stack.clear()
        for i in range(n - 1, -1, -1):
            while stack and strength[stack[-1]] > strength[i]:
                stack.pop()
            right[i] = stack[-1] if stack else n
            stack.append(i)
        prefix, q = [0] * (n + 1), [0] * (n + 2)
        for i, value in enumerate(strength):
            prefix[i + 1] = (prefix[i] + value) % mod
        for k in range(n + 1):
            q[k + 1] = (q[k] + prefix[k]) % mod
        answer = 0
        for i, value in enumerate(strength):
            l, r = left[i], right[i]
            a = (q[r + 1] - q[i + 1]) % mod
            b = (q[i + 1] - q[l + 1]) % mod
            sums = ((i - l) * a - (r - i) * b) % mod
            answer = (answer + value * sums) % mod
        return answer

C++

#include <vector>
using namespace std;

class Solution {
public:
    int totalStrength(vector<int>& strength) {
        const long long MOD = 1000000007LL;
        int n = strength.size();
        vector<int> left(n), right(n), stack;
        for (int i = 0; i < n; ++i) {
            while (!stack.empty() && strength[stack.back()] >= strength[i]) stack.pop_back();
            left[i] = stack.empty() ? -1 : stack.back();
            stack.push_back(i);
        }
        stack.clear();
        for (int i = n - 1; i >= 0; --i) {
            while (!stack.empty() && strength[stack.back()] > strength[i]) stack.pop_back();
            right[i] = stack.empty() ? n : stack.back();
            stack.push_back(i);
        }
        vector<long long> prefix(n + 1), q(n + 2);
        for (int i = 0; i < n; ++i)
            prefix[i + 1] = (prefix[i] + strength[i]) % MOD;
        for (int k = 0; k <= n; ++k) q[k + 1] = (q[k] + prefix[k]) % MOD;
        long long answer = 0;
        for (int i = 0; i < n; ++i) {
            int l = left[i], r = right[i];
            long long a = (q[r + 1] - q[i + 1] + MOD) % MOD;
            long long b = (q[i + 1] - q[l + 1] + MOD) % MOD;
            long long sums = ((i - l) * a % MOD - (r - i) * b % MOD + MOD) % MOD;
            answer = (answer + strength[i] * sums) % MOD;
        }
        return static_cast<int>(answer);
    }
};
