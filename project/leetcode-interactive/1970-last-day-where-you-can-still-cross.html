你能穿过矩阵的最后一天

Last Day Where You Can Still Cross

陆地一天少一格，通路何时消失？从顶行任意陆地出发，只走上下左右，尝试抵达底行。先观察每天的变化，再展开题解探索高效做法。

01 / 题目与规则

给定 row × col 的矩阵，第 0 天所有格子都是陆地（0）。从第 1 天起，每天将 cells 指定的一格变为水域（1）。坐标从 1 开始；用程序的零基下标表示，第 d 天淹没 cells[d - 1]。

在当天淹水完成后的矩阵上，只能沿四个基本方向走陆地；起点可以是顶行任意格子，终点可以是底行任意格子。返回仍然存在这样的通路的最大天数。

latestDayToCross(row, col, cells) → integer

  • 2 ≤ row, col ≤ 2 × 10⁴
  • 4 ≤ row × col ≤ 2 × 10⁴
  • cells.length = row × col
  • 1 ≤ rᵢ ≤ row，1 ≤ cᵢ ≤ col
  • 所有坐标互不相同，因此每格最终都会淹没。

05 / 独立题解

准备好后再展开思路、算法演示与代码。

倒放时间，用并查集接通两岸

核心洞察

正向淹水会删除节点，使连通块分裂，普通并查集不擅长拆分。将过程倒放：从全水开始逐格恢复陆地，每步只增加节点和连接，恰好适合并查集。

完整过程

  1. 令 N = row × col，实格编号 r × col + c（r、c 已减 1）。额外创建顶边节点 TOP=N 与底边节点 BOTTOM=N+1。
  2. 初始化 N 个格子为水域，并查集有 N+2 个独立节点。逆序枚举 i = N-1 … 0。
  3. 恢复 cells[i]，若位于顶行或底行，就连到对应虚拟节点；再与上下左右已经恢复的陆地合并。
  4. 若 TOP 和 BOTTOM 的根相同，立即返回 i。恢复后仍被淹没的正是 cells[0 … i-1]，所以对应正向第 i 天，而不是第 i+1 天。

逆序实验 · 官方示例 3

一帧恢复一格并完成它的合并。格内 G 编号为当前并查集根（包含虚拟边界连接），不是父指针树。可继续到第 0 天以观察，正式算法会在首次接通时返回。

正确性证明

状态不变式：处理完下标 i 后，恰好恢复了下标 i 到 N-1 的格子，等价于正向第 i 天的陆地集合。每次将新陆地的所有四向陆地邻边加入，并连接对应边界，故并查集恰好表示这个增广图的连通性。

判定等价：真实顶到底陆地路径可以延伸为 TOP 到 BOTTOM 的路径；反过来，若虚拟节点连通，取其简单路径，去掉两端虚拟节点后，就是顶行到达底行的真实陆地路径。

最优性：正向只能减少通路。逆序从第 N 天向第 0 天检查，首次接通的第 i 天可行，而所有大于 i 的天数都已检查为不可行，所以 i 是最后一天。

边界与复杂度

第 0 天必可通过，第 N 天必不可通过。题目至少有两行两列；最小 2×2 也需检查四向邻接，不能走对角线。顶行、底行任意陆地都要接入虚拟节点，不能指定唯一入口。使用路径压缩与按大小合并，每格最多四次邻接合并：时间 O(N α(N))，空间 O(N)。α 为反阿克曼函数。

替代方案

二分天数 + BFS：第 d 天是否可走具有单调性。建立前 d 格被淹的矩阵，从所有顶行陆地多源 BFS，判定能否到达底行。维护 lo=0 可行、hi=N 不可行，直到 hi-lo=1，返回 lo。时间 O(N log N)，空间 O(N)，实现直观。逐日 BFS 则需要 O(N²)，不适合最大规模。

常见错误

  • 恢复下标 i 后返回 i+1：混淆了原始淹水日与撤销后的天数。
  • 与水域节点合并：虚构出穿水的路线。
  • 编号写成 r×row+c，或只检查线性编号差 1：非方阵会出错，行末还可能接到下一行行首。
  • 只连接一个顶行起点，或将对角邻居也视为相连。
  • 正向删除并查集节点：根信息无法表达连通块拆分。

面试追问

  • 需要实际路线？先求最后一天，再在当天矩阵 BFS 保存前驱并回溯。
  • 格子会反复淹没与恢复？单次逆序不再仅有添加，可考虑离线时间线段树与可回滚并查集。
  • 只允许向下或向右移动？无向连通性不足以表达方向限制，应使用有向可达性或动态规划判定。
  • 为什么虚拟顶边可以连接多个不相邻入口？这里只查询是否存在任意顶到底路径，虚拟边界连接保持这一存在性判定。

/**
 * @param {number} row
 * @param {number} col
 * @param {number[][]} cells
 * @return {number}
 */
var latestDayToCross = function(row, col, cells) {
    const n = row * col, top = n, bottom = n + 1;
    const parent = Array.from({length: n + 2}, (_, i) => i);
    const size = Array(n + 2).fill(1), land = Array(n).fill(false);
    function find(x) {
        while (parent[x] !== x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    function union(a, b) {
        a = find(a); b = find(b);
        if (a === b) return;
        if (size[a] < size[b]) [a, b] = [b, a];
        parent[b] = a; size[a] += size[b];
    }
    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    for (let i = cells.length - 1; i >= 0; i--) {
        const r = cells[i][0] - 1, c = cells[i][1] - 1;
        const id = r * col + c;
        land[id] = true;
        if (r === 0) union(id, top);
        if (r === row - 1) union(id, bottom);
        for (const [dr, dc] of dirs) {
            const nr = r + dr, nc = c + dc;
            if (nr >= 0 && nr < row && nc >= 0 && nc < col) {
                const next = nr * col + nc;
                if (land[next]) union(id, next);
            }
        }
        if (find(top) === find(bottom)) return i;
    }
    return 0;
};

Python

from typing import List

class Solution:
    def latestDayToCross(self, row: int, col: int,
                         cells: List[List[int]]) -> int:
        n = row * col
        top, bottom = n, n + 1
        parent = list(range(n + 2))
        size = [1] * (n + 2)
        land = [False] * n

        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a, b):
            a, b = find(a), find(b)
            if a == b:
                return
            if size[a] < size[b]:
                a, b = b, a
            parent[b] = a
            size[a] += size[b]

        for i in range(len(cells) - 1, -1, -1):
            r, c = cells[i][0] - 1, cells[i][1] - 1
            idx = r * col + c
            land[idx] = True
            if r == 0:
                union(idx, top)
            if r == row - 1:
                union(idx, bottom)
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < row and 0 <= nc < col:
                    nxt = nr * col + nc
                    if land[nxt]:
                        union(idx, nxt)
            if find(top) == find(bottom):
                return i
        return 0

#include <vector>
#include <numeric>
#include <algorithm>
using namespace std;

class Solution {
    vector<int> parent, sz;
    int find(int x) {
        while (parent[x] != x) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    void unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return;
        if (sz[a] < sz[b]) swap(a, b);
        parent[b] = a; sz[a] += sz[b];
    }
public:
    int latestDayToCross(int row, int col, vector<vector<int>>& cells) {
        int n = row * col, top = n, bottom = n + 1;
        parent.resize(n + 2); iota(parent.begin(), parent.end(), 0);
        sz.assign(n + 2, 1);
        vector<bool> land(n, false);
        const int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        for (int i = static_cast<int>(cells.size()) - 1; i >= 0; --i) {
            int r = cells[i][0] - 1, c = cells[i][1] - 1;
            int id = r * col + c;
            land[id] = true;
            if (r == 0) unite(id, top);
            if (r == row - 1) unite(id, bottom);
            for (const auto& d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < row && nc >= 0 && nc < col) {
                    int next = nr * col + nc;
                    if (land[next]) unite(id, next);
                }
            }
            if (find(top) == find(bottom)) return i;
        }
        return 0;
    }
};
