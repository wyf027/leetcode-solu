前序序列，如何“长”成一棵搜索树？

先观察节点落位的过程，再决定是否展开完整题解。交互区用一条单调递减的祖先栈，呈现每个值如何找到父节点。

MEDIUM栈二叉搜索树O(n)

题目

给定整数数组 preorder，它是某棵二叉搜索树的前序遍历。请构造并返回这棵树的根节点。题目保证输入能够对应一棵满足要求的 BST。

BST 规则

任一节点左子树中的所有值都严格小于节点值，右子树中的所有值都严格大于节点值。

前序顺序

先访问根节点，再遍历左子树，最后遍历右子树，即「根 → 左 → 右」。

示例 1

输入preorder = [8,5,1,7,10,12]输出[8,5,10,1,7,null,12]

示例 2

输入preorder = [1,3]输出[1,null,3]

约束

1 ≤ preorder.length ≤ 100
每个节点值为正整数；官方英文元数据给出 1 ≤ preorder[i] ≤ 1000，且所有值互不相同。

核心洞察

前序遍历保证父节点先出现。维护一条从祖先到当前节点、值严格递减的栈：新值更小时，它是栈顶的左孩子；新值更大时，弹出所有更小的节点，最后一个被弹出的节点就是它的父节点，它应成为该父节点的右孩子。

完整过程

  1. 以首元素建立根节点并入栈。
  2. 依次读取后续值。若小于栈顶，挂到栈顶左侧。
  3. 否则不断弹出所有小于当前值的节点，记录最后弹出的节点。
  4. 把当前节点挂到最后弹出节点的右侧，再将当前节点入栈。

为什么正确

循环不变量：处理每个值之前，栈保存从某个祖先到最近插入节点的候选路径，且值严格递减。

若新值更小，根据前序顺序和 BST 性质，它只能进入当前栈顶尚未填充的左侧。若新值更大，被弹出的节点都已结束左子树；最后一个小于新值的节点是最近且合法的右侧父节点。每个节点仅被压栈、弹栈各一次，因此最终恰好恢复唯一 BST。

复杂度与边界

时间：O(n)；额外空间：O(n)。

单节点直接返回；严格递增输入形成全右链，严格递减输入形成全左链。值互不相同，因此无需定义重复值落在哪边。

替代方案

递归 + 上界：按前序索引建树，每层只接收小于当前上界的值，同样可达 O(n)，但极端链状树递归深度为 O(n)。

逐个普通插入：直观，但链状输入会退化到 O(n²)。

四种语言实现

class Solution {
    public TreeNode bstFromPreorder(int[] preorder) {
        TreeNode root = new TreeNode(preorder[0]);
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        for (int i = 1; i < preorder.length; i++) {
            TreeNode node = new TreeNode(preorder[i]);
            if (preorder[i] < stack.peek().val) {
                stack.peek().left = node;
            } else {
                TreeNode parent = null;
                while (!stack.isEmpty() && stack.peek().val < preorder[i])
                    parent = stack.pop();
                parent.right = node;
            }
            stack.push(node);
        }
        return root;
    }
}
var bstFromPreorder = function(preorder) {
    const root = new TreeNode(preorder[0]);
    const stack = [root];
    for (let i = 1; i < preorder.length; i++) {
        const node = new TreeNode(preorder[i]);
        if (preorder[i] < stack[stack.length - 1].val) {
            stack[stack.length - 1].left = node;
        } else {
            let parent = null;
            while (stack.length && stack[stack.length - 1].val < preorder[i]) {
                parent = stack.pop();
            }
            parent.right = node;
        }
        stack.push(node);
    }
    return root;
};
class Solution:
    def bstFromPreorder(self, preorder: List[int]) -> Optional[TreeNode]:
        root = TreeNode(preorder[0])
        stack = [root]
        for value in preorder[1:]:
            node = TreeNode(value)
            if value < stack[-1].val:
                stack[-1].left = node
            else:
                parent = None
                while stack and stack[-1].val < value:
                    parent = stack.pop()
                parent.right = node
            stack.append(node)
        return root
class Solution {
public:
    TreeNode* bstFromPreorder(vector<int>& preorder) {
        TreeNode* root = new TreeNode(preorder[0]);
        vector<TreeNode*> stack{root};
        for (int i = 1; i < preorder.size(); ++i) {
            TreeNode* node = new TreeNode(preorder[i]);
            if (preorder[i] < stack.back()->val) {
                stack.back()->left = node;
            } else {
                TreeNode* parent = nullptr;
                while (!stack.empty() && stack.back()->val < preorder[i]) {
                    parent = stack.back(); stack.pop_back();
                }
                parent->right = node;
            }
            stack.push_back(node);
        }
        return root;
    }
};

面试追问

  • 能否用递归上界法完成，并解释为什么不需要显式下界？
  • 若允许重复值，规则和实现应怎样调整？
  • 如果给的是后序遍历，处理方向与边界如何变化？

常见错误

  • 只弹出一个节点，导致较大的值挂在错误父节点下。
  • 把“当前栈顶”而非“最后弹出的节点”作为右孩子父节点。
  • 在循环内忘记将新节点入栈，后续失去祖先路径。
  • 误报空间为 O(1)；倾斜树时栈可容纳全部节点。
