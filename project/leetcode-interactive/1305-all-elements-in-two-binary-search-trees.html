Problem

题目与边界

函数签名：getAllElements(root1, root2) → 整数列表

给定两棵二叉搜索树 root1 和 root2，返回一个列表，包含两棵树中的全部整数，并按升序排列。两个树中的相同数值都要保留。

示例 1
输入：root1 = [2,1,4], root2 = [1,0,3]
输出：[0,1,1,2,3,4]
示例 2
输入：root1 = [1,null,8], root2 = [8,1]
输出：[1,1,8,8]
Constraints
  • 每棵树的节点数在 [0, 5000] 范围内。
  • -10⁵ ≤ Node.val ≤ 10⁵。
  • 输入保证分别构成合法的二叉搜索树。
  • 空树合法；两棵树都空时结果为空列表。

核心洞察

BST 的中序遍历天然升序。分别中序遍历两棵树，可得到两个非递减数组；随后像归并排序的最后一步一样，用两个指针线性合并。

这里不必把所有元素混在一起再调用通用排序。二叉搜索树已经提供了局部有序性，我们只需要把这份结构信息转换成两条有序序列。

完整过程

  1. 对 root1 做中序遍历，把节点值依次写入 list1。
  2. 对 root2 做中序遍历，把节点值依次写入 list2。
  3. 令指针 i = 0、j = 0。比较两个指针所指元素，把较小者加入答案并移动对应指针。
  4. 若其中一个数组耗尽，把另一个数组剩余元素依次加入答案。

正确性证明

引理 1BST 的中序遍历先访问左子树，再访问根，最后访问右子树，所以得到非递减序列。
引理 2每次取两个未处理首元素的较小者，它就是所有未处理元素中的最小值。
结论归并过程不遗漏、不重复新增任何节点值，且每次追加当前最小值，因此最终答案恰含全部元素并升序排列。

边界与复杂度

边界情况

  • 两棵树都为空：返回空列表。
  • 仅一棵树为空：返回另一棵树的中序序列。
  • 存在重复值：全部保留。
  • 树严重倾斜：递归栈深度可能达到节点数。
  • 含负数或极值：比较逻辑不变。

复杂度

时间O(m + n)每个节点访问一次，归并再线性扫描。
额外空间O(m + n)两个序列与返回结果；递归栈另为 O(h₁+h₂)。

四语言完整代码

以下实现都遵循“分别中序遍历 + 双指针归并”，可按 LeetCode 对应语言签名提交。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    public List<Integer> getAllElements(TreeNode root1, TreeNode root2) {
        List<Integer> first = new ArrayList<>();
        List<Integer> second = new ArrayList<>();
        inorder(root1, first);
        inorder(root2, second);

        List<Integer> answer = new ArrayList<>(first.size() + second.size());
        int i = 0, j = 0;
        while (i < first.size() && j < second.size()) {
            if (first.get(i) <= second.get(j)) {
                answer.add(first.get(i++));
            } else {
                answer.add(second.get(j++));
            }
        }
        while (i < first.size()) answer.add(first.get(i++));
        while (j < second.size()) answer.add(second.get(j++));
        return answer;
    }

    private void inorder(TreeNode node, List<Integer> values) {
        if (node == null) return;
        inorder(node.left, values);
        values.add(node.val);
        inorder(node.right, values);
    }
}

        while (j < second.size()) answer.push_back(second[j++]);
        return answer;
    }

替代方案

全部收集后排序

用任意遍历收集两棵树的节点，再整体排序。实现直观，但时间为 O((m+n) log(m+n))，没有利用 BST 的有序性质。

双迭代器在线归并

给每棵树维护一个显式栈，按需取出下一个最小节点，可把中间存储降至 O(h₁+h₂)（不计返回值）。代码更复杂，但适合讨论空间优化。

面试追问

  • 能否不用两个完整数组？可以，用两个 BST 迭代器边取边合并。
  • 如果需要降序呢？改为“右—根—左”的逆中序遍历，再从大到小归并。
  • 如果输入不是 BST 呢？遍历序列不再有序，需要整体排序或使用其他有序容器。
  • 如何避免深树递归溢出？把中序遍历改成显式栈迭代。

常见错误

  • 误用前序或后序遍历，以为得到的数组仍有序。
  • 比较相等时同时移动两个指针，导致重复值只保留一次。
  • 主归并循环结束后忘记追加未耗尽数组的尾部。
  • 假定两棵树一定非空，直接访问根节点。
  • 只计算辅助数组，却忽略倾斜树可能造成的递归栈空间。
