Reverse Vowels of a String

01 / Problem

题目要求

给定字符串 s，仅反转其中所有元音字母的出现顺序，并返回变换后的字符串。元音为 a、e、i、o、u，大小写都视为元音，且可重复出现。

示例 1

大小写混合
输入：s = "IceCreAm"
输出："AceCreIm"
解释：元音序列为 ['I', 'e', 'e', 'A']；
      逆序后为 ['A', 'e', 'e', 'I']。

示例 2

重复元音
输入：s = "leetcode"
输出："leotcede"

约束与边界

LEN1 ≤ s.length ≤ 3 × 105
SETs 由可打印的 ASCII 字符组成。
CASE大写与小写元音都需要识别。
KEEP辅音、数字、空格和符号的位置均保持不变。

03 / Solution

双指针：只交换需要移动的字符

核心洞察 完整过程 正确性 边界与错误 复杂度与替代方案 四语言代码 测试与验证 面试追问

核心洞察

反转元音序列

目标不是反转整个字符串，而是让“从左到右读到的元音序列”倒序。最左侧尚未处理的元音，应与最右侧尚未处理的元音交换。

因此用两个游标从首尾向中间移动：左游标跳过非元音，右游标也跳过非元音；当两者都落在元音上时交换，然后同时向内推进。

完整过程

  1. 把字符串转换为可修改的字符数组，令 left = 0、right = n - 1。
  2. 当 left < right 且左侧不是元音时，递增 left。
  3. 当 left < right 且右侧不是元音时，递减 right。
  4. 若游标仍未相遇，交换两个元音，再令 left++、right--。
  5. 游标相遇或交错后，将字符数组拼回字符串。

正确性证明

1

定位正确。 两个跳过循环只越过非元音，因此停下时，left 和 right 分别指向尚未处理区域最左、最右的元音；越过的非元音从未被修改。

2

交换正确。 在目标结果中，最左侧未处理元音必须接收当前最右侧未处理元音，反之亦然；一次交换恰好确定这两个最终位置。

3

不变式保持。 交换并向内推进后，区间外的所有元音均已处于最终位置，非元音始终未移动。新的未处理区间仍满足同一性质。

4

终止即完整。 游标相遇或交错时，至多剩一个元音，无需移动。由不变式，所有元音均已逆序，其他字符位置不变，算法正确。

边界情况

  • 没有元音或只有一个元音：返回原字符串。
  • 全部是元音：效果等同于反转整个字符串。
  • 大小写混合：字符本身连同大小写一起交换，不做大小写转换。
  • 包含空格、数字或标点：它们都不是元音，位置保持不变。
  • 长度达到 3 × 105：应避免反复创建子串导致的二次复杂度。

常见错误

  • 元音集合只写小写，漏掉 AEIOU。
  • 找到一侧元音后立即交换，另一侧可能仍指向辅音。
  • 交换后忘记同时移动两个指针，造成死循环。
  • 用 left <= right 交换中点；虽然常常不改变结果，却增加无意义操作并易引入越界。
  • JavaScript 直接修改字符串下标；字符串不可变，应先转字符数组。

复杂度

TIMEO(n)每个游标单向移动，每个字符最多被检查常数次。
SPACEO(n)*不可变字符串语言需字符数组；若输入字符数组可原地修改，则额外空间 O(1)。

替代方案：收集元音栈

先遍历并收集所有元音，再次遍历时从栈顶依次填回。逻辑直观，同样为 O(n) 时间，但额外保存 k 个元音，空间为 O(k)。双指针省去这份独立元音存储，并更直接地表达成对交换。

四语言完整代码

JAVA · LEETCODE SUBMISSION
class Solution {
    public String reverseVowels(String s) {
        char[] chars = s.toCharArray();
        int left = 0;
        int right = chars.length - 1;

        while (left < right) {
            while (left < right && !isVowel(chars[left])) {
                left++;
            }
            while (left < right && !isVowel(chars[right])) {
                right--;
            }

            if (left < right) {
                char temp = chars[left];
                chars[left] = chars[right];
                chars[right] = temp;
                left++;
                right--;
            }
        }
        return new String(chars);
    }

    private boolean isVowel(char c) {
        return "aeiouAEIOU".indexOf(c) >= 0;
    }
}
JAVASCRIPT · LEETCODE SUBMISSION
/**
 * @param {string} s
 * @return {string}
 */
var reverseVowels = function(s) {
    const chars = [...s];
    const vowels = new Set("aeiouAEIOU");
    let left = 0;
    let right = chars.length - 1;

    while (left < right) {
        while (left < right && !vowels.has(chars[left])) {
            left++;
        }
        while (left < right && !vowels.has(chars[right])) {
            right--;
        }

        if (left < right) {
            [chars[left], chars[right]] = [chars[right], chars[left]];
            left++;
            right--;
        }
    }
    return chars.join("");
};
PYTHON 3 · LEETCODE SUBMISSION
class Solution:
    def reverseVowels(self, s: str) -> str:
        chars = list(s)
        vowels = set("aeiouAEIOU")
        left, right = 0, len(chars) - 1

        while left < right:
            while left < right and chars[left] not in vowels:
                left += 1
            while left < right and chars[right] not in vowels:
                right -= 1

            if left < right:
                chars[left], chars[right] = chars[right], chars[left]
                left += 1
                right -= 1

        return "".join(chars)
C++ · LEETCODE SUBMISSION
class Solution {
public:
    string reverseVowels(string s) {
        int left = 0;
        int right = static_cast<int>(s.size()) - 1;

        while (left < right) {
            while (left < right && !isVowel(s[left])) {
                ++left;
            }
            while (left < right && !isVowel(s[right])) {
                --right;
            }

            if (left < right) {
                swap(s[left], s[right]);
                ++left;
                --right;
            }
        }
        return s;
    }

private:
    bool isVowel(char c) {
        return c == 'a' || c == 'e' || c == 'i' || c == 'o' ||
               c == 'u' || c == 'A' || c == 'E' || c == 'I' ||
               c == 'O' || c == 'U';
    }
};

面试追问

  • 能否真正做到 O(1) 额外空间？ 若调用方提供可变字符数组，可以原地交换；若语言中的字符串不可变，返回新字符串通常至少需要 O(n) 输出空间。
  • 若元音规则可配置呢？ 把元音集合改为参数，并用哈希集合提供平均 O(1) 判断。
  • 若要支持完整 Unicode 呢？ 需要先明确“元音”的语言学定义，并按 Unicode 码点或字素簇迭代，不能简单按 UTF-16 代码单元切分。
  • 能否用于流式输入？ 完整反转依赖尾部元音，单向流无法在有限内存中直接确定前部输出；需要双向存储、外部缓存或两遍处理。
