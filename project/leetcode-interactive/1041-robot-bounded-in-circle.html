困于环中的
机器人

一串会无限重复的指令，看似需要模拟到天荒地老。真正需要观察的，却只有执行一轮之后的两个状态：机器人在哪里，以及它朝向哪里。

函数1 → ∞

isRobotBounded(instructions)
输入长度 1–100，返回布尔值。

01 / 题目

无限重复，是否有界？

机器人从原点出发并面朝北。它按顺序执行一串指令，然后从头继续，无限重复。

规则

  • G：沿当前方向前进 1 个单位。
  • L：原地向左转 90°。
  • R：原地向右转 90°。

北、东、南、西分别对应 y 正、x 正、y 负、x 负方向。判断是否存在一个圆，使机器人永远不会走出这个圆。

函数与约束

boolean isRobotBounded(string instructions)

  • 1 ≤ instructions.length ≤ 100
  • 每个字符只能是 G、L 或 R。

示例 1

输入：instructions = "GGLLGG"
输出：true
解释：一轮后回到 (0, 0)，面朝南；
重复时轨迹始终位于有限范围内。

示例 2

输入：instructions = "GG"
输出：false
解释：每轮继续面朝北并向北移动，
因此距离原点越来越远。

示例 3

输入：instructions = "GL"
输出：true
解释：四轮后回到初始位置和朝向，
轨迹形成有限循环。

03 / 解锁思路

准备好看穿无限了吗？

题解默认收起，先用实验台形成自己的猜想。

完整题解

一轮状态决定所有未来

执行一轮后，只要回到原点，或不再面朝北，机器人就一定有界。

核心洞察
若一轮后仍面朝北且不在原点，同一个位移向量会被不断累加，轨迹必然逃向无穷。除此之外，朝向发生改变时，至多重复 4 轮，旋转后的位移向量会互相抵消。

完整过程

  1. 用方向编号 0、1、2、3 表示北、东、南、西，并准备对应位移数组。
  2. 仅扫描一次 instructions：遇到 G 更新坐标，遇到 L/R 更新方向。
  3. 扫描结束后判断：坐标是否仍为 (0,0)，或者方向是否不为北。

正确性证明

情形一：一轮后回到原点。每轮都会从原点以某个朝向再次出发，状态数量有限，轨迹有界。

情形二：一轮后未回原点但朝向改变。这个净位移会在后续轮次中随朝向旋转；2 或 4 轮后朝向复原，旋转位移之和为零，轨迹回到原点，因此有界。

情形三：一轮后未回原点且仍朝北。每轮增加相同非零位移，距离无限增长，因此无界。三种情形完备，判定正确。

边界与复杂度

  • 只有转向：位置始终在原点，返回 true。
  • 单个 G：持续直行，返回 false。
  • 净位移为零但朝向任意：直接返回 true。
  • 时间复杂度：O(n)。
  • 空间复杂度：O(1)。

替代方案

可以直接模拟 4 轮，再检查是否回到初始状态。因为朝向只有 4 种，这同样正确，时间仍是 O(n)，但做了更多工作，也不如“一轮状态”揭示本质。

也可以把每轮运动视作“旋转 + 平移”的刚体变换；这是更一般的数学表述，但面试中方向数组通常更清晰。

实现

四种语言

方向数组按顺时针排列，转向只需修改下标。

class Solution {
    public boolean isRobotBounded(String instructions) {
        int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        int x = 0, y = 0, dir = 0;
        for (char command : instructions.toCharArray()) {
            if (command == 'G') {
                x += dirs[dir][0];
                y += dirs[dir][1];
            } else if (command == 'L') {
                dir = (dir + 3) % 4;
            } else {
                dir = (dir + 1) % 4;
            }
        }
        return (x == 0 && y == 0) || dir != 0;
    }
}

面试追问

  • 为什么只需要观察一轮，而不是四轮？
  • 如果允许任意角度旋转，结论还成立吗？
  • 如何返回一个能够覆盖完整轨迹的最小包围圆？
  • 若 G 的步长不固定，需要记录哪些额外状态？

常见错误

  • 认为必须一轮回到原点才有界，遗漏朝向改变的情况。
  • 左转时直接对负数取模，在某些语言中得到负下标。
  • 把转向也当成移动，错误更新坐标。
  • 无终止条件地模拟无限轮次。
