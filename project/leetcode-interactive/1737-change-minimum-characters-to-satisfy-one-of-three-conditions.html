01 / Problem

题目在问什么？

给定两个仅含小写英文字母的字符串 a 与 b。一次操作可以把任一字符串中的任一字符改成任一小写字母。求至少操作多少次，才能满足以下条件之一：

01

a 中每个字母都严格小于 b 中每个字母。

02

b 中每个字母都严格小于 a 中每个字母。

03

a 和 b 全部由同一个字母组成。

“严格小于”比较的是字母表顺序；例如 b < d，相等不算。

官方示例

示例 1 
输入：a = "aba", b = "caa"
输出：2
解释：可把 b 改成 "ccc"；也可把两者都改成全 'a'。
示例 2 
输入：a = "dabadd", b = "cda"
输出：3
解释：把 b 改成 "eee"，即可让 a 的每个字母都小于 b。

约束

  • 1 ≤ a.length, b.length ≤ 10⁵
  • a 与 b 仅由小写英文字母组成。

Solution

26 个计数，覆盖三种条件

核心洞察

字母表只有 26 个字符。先统计 a、b 中每个字母的频次，再枚举目标字母或相邻字母之间的分界线。这样无需关心字符原来的位置。

同字母条件：|a| + |b| − max(countA[c] + countB[c])

对于前两种严格大小关系，分界线只能放在 a|b 到 y|z 之间。设分界字母为 c，左侧包含 a…c，右侧包含比 c 大的字母。

完整过程

  1. 建立长度为 26 的 countA、countB。
  2. 枚举每个字母作为“统一后的字符”，计算把两个字符串全改成它的代价。
  3. 维护两个前缀和。对每个 c ∈ ['a','y']：
    • a ≤ c < b 的代价 = a 中 > c 的数量 + b 中 ≤ c 的数量；
    • b ≤ c < a 的代价 = b 中 > c 的数量 + a 中 ≤ c 的数量。
  4. 返回全部候选代价中的最小值。

正确性

引理 1：统一字母代价正确选定目标字母 c 后，原本不是 c 的每个字符都必须且只需修改一次；因此代价恰为总长度减去 c 的总频次。枚举所有 c 即覆盖条件 3 的最优解。
引理 2：固定分界线的代价正确若目标是 a 中所有字符 ≤ c，b 中所有字符 > c，则 a 中 > c 与 b 中 ≤ c 的字符都必须修改；其他字符已合法。每个违规字符改到对应区间即可，所以该计数既是下界也是可达上界。
引理 3：枚举覆盖全部严格关系任何满足 max(a) < min(b) 的结果，都存在一条位于两者之间的分界线 c；反向关系同理。枚举 a|b 到 y|z 覆盖所有可能分界。
定理算法分别取得三种条件的最小代价，并返回三者最小值，因此返回满足任一条件所需的全局最少操作数。

边界情况

  • 两个字符串都只有一个字符时，仍可能需要 0 或 1 次操作。
  • 已经满足某个条件时答案为 0。
  • 分界线不能放在 z 之后：小写字母中没有比 z 更大的字母。
  • 条件 3 要求两个字符串共享同一个字母，不是各自只含一种不同字母。
  • 字符串长度之和可达 2×10⁵，不能枚举每个位置的改法。

复杂度

统计耗时 O(|a| + |b|)，扫描字母表耗时 O(26)；总时间复杂度为 O(|a| + |b|)，额外空间为 O(26)，即常数空间。

替代方案

可以先分别构造 26 长度的完整前缀和数组，再用公式查询；可读性更直观，但这里的滚动前缀只需两个变量。排序后寻找分界也能做，但排序会把时间复杂度提高到 O(n log n + m log m)，没有利用字母表固定的优势。

面试追问

  • 若字符集不是固定 26 个？ 对离散字符排序或坐标压缩，再扫描相邻分界。
  • 若修改不同字符代价不同？ 频次改成“修改代价总和”，前缀和逻辑仍可复用。
  • 如何构造实际修改方案？ 记录产生最优值的条件与分界/目标字母，再二次扫描字符串修改违规位置。
  • 能否在线处理字符更新？ 用两个 26 长度计数维护更新，每次查询仍只扫描 26 个字母。

常见错误

  • 把严格小于写成小于等于，允许两边出现同一字母。
  • 在前缀和包含当前字母之前计算，导致边界偏移一位。
  • 枚举 26 条严格分界，把 z 当成左侧上界，实际右侧将无合法字母。
  • 条件 3 只取各字符串最大频次之和，而没有对同一个目标字母求和。
  • 使用嵌套位置枚举，无法通过 10⁵ 的长度约束。

JavaLeetCode 可提交
class Solution {
    public int minCharacters(String a, String b) {
        int[] countA = new int[26];
        int[] countB = new int[26];
        for (char ch : a.toCharArray()) countA[ch - 'a']++;
        for (char ch : b.toCharArray()) countB[ch - 'a']++;

        int n = a.length(), m = b.length();
        int answer = n + m;
        int prefixA = 0, prefixB = 0;

        for (int i = 0; i < 26; i++) {
            // Condition 3: both strings become the same letter.
            answer = Math.min(answer, n + m - countA[i] - countB[i]);

            if (i < 25) {
                prefixA += countA[i];
                prefixB += countB[i];
                // a < b, separated after letter i.
                answer = Math.min(answer, (n - prefixA) + prefixB);
                // b < a, separated after letter i.
                answer = Math.min(answer, (m - prefixB) + prefixA);
            }
        }
        return answer;
    }
}

class Solution:
    def minCharacters(self, a: str, b: str) -> int:
        count_a = [0] * 26
        count_b = [0] * 26
        for ch in a:
            count_a[ord(ch) - ord('a')] += 1
        for ch in b:
            count_b[ord(ch) - ord('a')] += 1

        n, m = len(a), len(b)
        answer = n + m
        prefix_a = prefix_b = 0

        for i in range(26):
            answer = min(answer, n + m - count_a[i] - count_b[i])
            if i < 25:
                prefix_a += count_a[i]
                prefix_b += count_b[i]
                answer = min(answer, n - prefix_a + prefix_b)
                answer = min(answer, m - prefix_b + prefix_a)

        return answer

class Solution {
public:
    int minCharacters(string a, string b) {
        array<int, 26> countA{};
        array<int, 26> countB{};
        for (char ch : a) ++countA[ch - 'a'];
        for (char ch : b) ++countB[ch - 'a'];

        int n = static_cast<int>(a.size());
        int m = static_cast<int>(b.size());
        int answer = n + m;
        int prefixA = 0, prefixB = 0;

        for (int i = 0; i < 26; ++i) {
            answer = min(answer, n + m - countA[i] - countB[i]);
            if (i < 25) {
                prefixA += countA[i];
                prefixB += countB[i];
                answer = min(answer, n - prefixA + prefixB);
                answer = min(answer, m - prefixB + prefixA);
            }
        }
        return answer;
    }
};
