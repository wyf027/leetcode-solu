进击的骑士

Minimum Knight Moves — 在一张无限棋盘上，找到骑士从原点抵达目标的最少步数。

广度优先搜索双向搜索启发式搜索

题目描述

一名骑士位于无限国际象棋棋盘的 (0, 0)。它每次必须按“一个方向移动两格、垂直方向移动一格”的方式跳跃，因此共有 8 种合法走法。

给定整数坐标 (x, y)，返回骑士到达该位置所需的最少移动次数。棋盘无限延伸，并允许目标坐标为负数。

函数签名： minKnightMoves(x, y) → integer

示例 1

输入：x = 2, y = 1
输出：1
解释：(0, 0) → (2, 1)，一次跳跃即可到达。

示例 2

输入：x = 5, y = 5
输出：4
解释：存在一条 4 步路径，且不存在更短路径。

约束

  • -300 ≤ x ≤ 300
  • -300 ≤ y ≤ 300
  • 起点固定为 (0, 0)。

完整题解

核心洞察

把棋盘坐标视为图的节点、骑士跳跃视为权重均为 1 的边。BFS 按距离逐层访问节点，所以第一次到达目标时的层数就是最少步数。

棋盘关于 x 轴、y 轴和直线 y = x 对称。先取绝对值并令 x ≤ y，只需搜索一个对称区域。

为什么允许坐标到 -2？

最短路径偶尔需要暂时绕到坐标轴外侧。例如到 (1, 1) 的最优路线会经过负坐标。保留 x, y ≥ -2 足够容纳这种绕行；目标正方向则限制到目标坐标再外扩 2 格。

完整过程

  1. 令 x = |x|、y = |y|，若 x > y 则交换二者。
  2. 从 (0, 0) 入队，同时记录已访问集合。
  3. 逐层取出队列节点，枚举 8 种骑士位移。
  4. 仅保留 -2 ≤ nx ≤ x + 2 且 -2 ≤ ny ≤ y + 2 的新节点。
  5. 某一层首次遇到目标，返回该层编号。

正确性说明

引理 1：对称变换不改变答案。骑士的 8 种移动在轴反射和坐标交换后仍是合法骑士移动，因此原目标与规范化目标的最短距离相同。

引理 2：BFS 第 d 层恰好包含所有最短距离为 d 的、此前未访问的坐标。这由 BFS 的先进先出和所有边权均为 1 直接成立。

引理 3：搜索边界不会排除规范化目标的一条最短路径。朝负方向最多保留到 -2，覆盖靠近原点时必要的绕行；超过目标 2 格的继续外扩可被对称地折回而不增加抵达目标的最短距离。

结论：算法第一次访问目标时，依据引理 2 得到的是最少步数；依据引理 1 与 3，该结果也等于原输入的答案。

边界情况

  • (0, 0)：无需移动，答案为 0。
  • (1, 0)：不能一步到达，最少 3 步。
  • (1, 1)：需要绕行，最少 2 步；这也是不能把搜索粗暴限制在第一象限的原因。
  • 负坐标与交换后的坐标由棋盘对称性统一处理。

复杂度

时间O((|x|+1)(|y|+1))每个边界内坐标至多访问一次。
空间O((|x|+1)(|y|+1))队列与访问集合的最坏规模。

替代方案

  • 双向 BFS：同时从起点和终点扩展，总是扩展较小的一侧；通常显著减少状态数，但代码更复杂。
  • A*：用不高估剩余步数的启发函数引导搜索，适合更远坐标；正确设计启发函数与去重策略是关键。
  • 数学 / 动态规划：可利用坐标差建立递推，但要单独处理 (1,0)、(2,2) 等例外，面试中更易出错。

面试追问

  • 如果坐标扩大到十亿，如何用数学规律或 A* 避免遍历大矩形？
  • 双向 BFS 的停止条件是什么？为什么不能在“两个边界相邻”时随意停止？
  • 若不同跳跃具有不同代价，应改用 Dijkstra 还是 0-1 BFS？

常见错误

  • 只搜索第一象限，导致 (1,1) 等靠近原点的答案错误。
  • 出队后才标记访问，使同一坐标被重复入队并放大内存。
  • 用字符串键时坐标没有分隔符，让 (1, 23) 与 (12, 3) 冲突。
  • 把 DFS 的第一次到达误认为最短路径。

import java.util.*;

class Solution {
    public int minKnightMoves(int x, int y) {
        x = Math.abs(x);
        y = Math.abs(y);
        if (x > y) { int temp = x; x = y; y = temp; }

        int[][] directions = {
            {1, 2}, {2, 1}, {-1, 2}, {-2, 1},
            {1, -2}, {2, -1}, {-1, -2}, {-2, -1}
        };
        Queue<int[]> queue = new ArrayDeque<>();
        Set<String> visited = new HashSet<>();
        queue.offer(new int[]{0, 0});
        visited.add("0,0");
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                int[] current = queue.poll();
                if (current[0] == x && current[1] == y) return steps;

                for (int[] d : directions) {
                    int nx = current[0] + d[0];
                    int ny = current[1] + d[1];
                    if (nx < -2 || ny < -2 || nx > x + 2 || ny > y + 2) continue;
                    String key = nx + "," + ny;
                    if (visited.add(key)) queue.offer(new int[]{nx, ny});
                }
            }
            steps++;
        }
        return -1;
    }
}

var minKnightMoves = function(x, y) {
    x = Math.abs(x);
    y = Math.abs(y);
    if (x > y) [x, y] = [y, x];

    const directions = [
        [1, 2], [2, 1], [-1, 2], [-2, 1],
        [1, -2], [2, -1], [-1, -2], [-2, -1]
    ];
    const queue = [[0, 0]];
    const visited = new Set(["0,0"]);
    let head = 0;
    let steps = 0;

    while (head < queue.length) {
        const levelEnd = queue.length;
        while (head < levelEnd) {
            const [cx, cy] = queue[head++];
            if (cx === x && cy === y) return steps;

            for (const [dx, dy] of directions) {
                const nx = cx + dx;
                const ny = cy + dy;
                if (nx < -2 || ny < -2 || nx > x + 2 || ny > y + 2) continue;
                const key = nx + "," + ny;
                if (!visited.has(key)) {
                    visited.add(key);
                    queue.push([nx, ny]);
                }
            }
        }
        steps++;
    }
    return -1;
};
from collections import deque

class Solution:
    def minKnightMoves(self, x: int, y: int) -> int:
        x, y = abs(x), abs(y)
        if x > y:
            x, y = y, x

        directions = (
            (1, 2), (2, 1), (-1, 2), (-2, 1),
            (1, -2), (2, -1), (-1, -2), (-2, -1),
        )
        queue = deque([(0, 0)])
        visited = {(0, 0)}
        steps = 0

        while queue:
            for _ in range(len(queue)):
                cx, cy = queue.popleft()
                if (cx, cy) == (x, y):
                    return steps

                for dx, dy in directions:
                    nx, ny = cx + dx, cy + dy
                    if nx < -2 or ny < -2 or nx > x + 2 or ny > y + 2:
                        continue
                    if (nx, ny) not in visited:
                        visited.add((nx, ny))
                        queue.append((nx, ny))
            steps += 1

        return -1
class Solution {
public:
    int minKnightMoves(int x, int y) {
        x = abs(x);
        y = abs(y);
        if (x > y) swap(x, y);

        const int directions[8][2] = {
            {1, 2}, {2, 1}, {-1, 2}, {-2, 1},
            {1, -2}, {2, -1}, {-1, -2}, {-2, -1}
        };
        queue<pair<int, int>> q;
        set<pair<int, int>> visited;
        q.push({0, 0});
        visited.insert({0, 0});
        int steps = 0;

        while (!q.empty()) {
            int size = q.size();
            while (size--) {
                auto [cx, cy] = q.front();
                q.pop();
                if (cx == x && cy == y) return steps;

                for (const auto& d : directions) {
                    int nx = cx + d[0];
                    int ny = cy + d[1];
                    if (nx < -2 || ny < -2 || nx > x + 2 || ny > y + 2) continue;
                    if (visited.insert({nx, ny}).second) q.push({nx, ny});
                }
            }
            steps++;
        }
        return -1;
    }
};
