Problem brief

从词库中找出所有连接词

给定一个没有重复项的字符串数组 words，返回其中所有连接词。连接词必须能完整拆成数组里至少两个更短的单词；组成它的短词允许重复使用。

示例 1 
输入：words = ["cat","cats","catsdogcats","dog",
  "dogcatsdog","hippopotamuses","rat","ratcatdogcat"]
输出：["catsdogcats","dogcatsdog","ratcatdogcat"]
解释：
  "catsdogcats" = "cats" + "dog" + "cats"
  "dogcatsdog"  = "dog" + "cats" + "dog"
  "ratcatdogcat" = "rat" + "cat" + "dog" + "cat"
示例 2 
输入：words = ["cat","dog","catdog"]
输出：["catdog"]
解释："catdog" = "cat" + "dog"
函数签名

findAllConcatenatedWordsInADict(words)

参数：string[] · 返回：list<string>

约束

1 <= words.length <= 104
1 <= words[i].length <= 30
words[i] 仅含小写英文字母
words 中所有字符串互不相同
1 <= Σ words[i].length <= 105

Full solution

从短到长，维护可用积木

核心组合是“按长度排序 + 已处理词集合 + 单词拆分动态规划”。当前词只尝试用更短、已经处理过的词拼接，因此不会把自己当成答案。

1

先处理短词

按长度升序排列。检查一个词时，集合中只有不比它长的已处理词；同长度的不同词也不可能完整匹配当前词。

2

用 DP 判定可拆分

dp[i] 表示前 i 个字符能否由集合中的词组成。若 dp[j] 为真且 word[j:i] 在集合中，则令 dp[i] 为真。

3

判定后再入库

无论当前词是否为连接词，检查完成后都把它加入集合，供更长的词使用。当前词不在检查集合里，天然排除“只由自己组成”。

完整过程

  1. 将 words 按字符串长度从小到大排序。
  2. 准备哈希集合 built，保存已经处理过的词。
  3. 对当前词 word 建立长度为 n + 1 的布尔数组，令 dp[0] = true。
  4. 枚举结尾 i，再枚举切分点 j。只要前缀可达且片段 word[j:i] 在 built 中，就标记 dp[i]。
  5. 若 dp[n] 为真，把当前词加入答案；随后将当前词加入 built。

为什么至少有两个短词？

检查当前词时，它自己尚未加入集合，所以 DP 不可能通过一次“整词匹配”到达末尾。任何成功路径都必须至少经过一个内部切分点，即使用至少两个片段。

数组没有重复词。长度相同但内容不同的已处理词，也不可能等于当前整词，因此不会破坏这个结论。

正确性证明

A
DP 不变式

对任意位置 i，dp[i] = true 当且仅当 word[0:i] 可以由 built 中的单词完整拼成。基础情形 dp[0] = true 对应空前缀。

B
转移完备且可靠

若某个可达前缀在 j 结束，且后续片段 word[j:i] 属于集合，则拼接后前 i 个字符可达；反过来，任意合法拼接的最后一段都会对应某个这样的 j，因此不会漏解。

C
整体结论

排序确保集合中的可用词已先于当前词处理。若 dp[n] 为真，当前词由至少两个更短词组成；若当前词是连接词，其合法分段都已在集合中，DP 必然找到路径。因此算法返回且仅返回全部连接词。

Time

O(Σ L²) 次查询

每个长度为 L 的词枚举至多 O(L²) 个片段。若语言的切片会复制字符，最坏字符处理量可达 O(Σ L³)；本题 L ≤ 30。

Space

O(S + Lmax)

S 是全部单词字符数，用于集合；单词级 DP 使用 O(Lmax) 额外空间。排序实现还可能占用栈或临时空间。

边界情况

  • 最短词：集合为空时一定不能被判为连接词，但之后仍需入库。
  • 重复使用：同一短词可重复参与拼接，例如 "aa" = "a" + "a"。
  • 多种拆法：只要存在一种合法拆分即可，无需恢复所有路径。
  • 长前缀陷阱：某段前缀在词库中不代表余下部分可拆，必须保留多个可达切分点。
  • 相同长度：唯一性保证另一个同长度字符串不可能等于当前词，整词误匹配不会发生。

Solution.java官方可提交签名
import java.util.*;

class Solution {
    public List<String> findAllConcatenatedWordsInADict(String[] words) {
        Arrays.sort(words, Comparator.comparingInt(String::length));
        Set<String> built = new HashSet<>();
        List<String> answer = new ArrayList<>();

        for (String word : words) {
            if (canForm(word, built)) {
                answer.add(word);
            }
            built.add(word);
        }
        return answer;
    }

    private boolean canForm(String word, Set<String> built) {
        if (built.isEmpty()) return false;
        int n = word.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;

        for (int end = 1; end <= n; end++) {
            for (int start = 0; start < end; start++) {
                if (dp[start] && built.contains(word.substring(start, end))) {
                    dp[end] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
}

/**
 * @param {string[]} words

var findAllConcatenatedWordsInADict = function(words) {
    words.sort((a, b) => a.length - b.length);
    const built = new Set();
    const answer = [];

    const canForm = (word) => {
        if (built.size === 0) return false;
        const dp = new Array(word.length + 1).fill(false);
        dp[0] = true;

        for (let end = 1; end <= word.length; end++) {
            for (let start = 0; start < end; start++) {
                if (dp[start] && built.has(word.slice(start, end))) {
                    dp[end] = true;
                    break;
                }
            }
        }
        return dp[word.length];
    };

    for (const word of words) {
        if (canForm(word)) answer.push(word);
        built.add(word);
    }
    return answer;
};

from typing import List, Set


class Solution:
    def findAllConcatenatedWordsInADict(self, words: List[str]) -> List[str]:
        words.sort(key=len)
        built: Set[str] = set()
        answer: List[str] = []

        def can_form(word: str) -> bool:
            if not built:
                return False
            dp = [False] * (len(word) + 1)
            dp[0] = True

            for end in range(1, len(word) + 1):
                for start in range(end):
                    if dp[start] and word[start:end] in built:
                        dp[end] = True
                        break
            return dp[len(word)]

        for word in words:
            if can_form(word):
                answer.append(word)
            built.add(word)

        return answer
solution.cpp官方可提交签名
#include <algorithm>
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> findAllConcatenatedWordsInADict(vector<string>& words) {
        sort(words.begin(), words.end(),
             [](const string& a, const string& b) {
                 return a.size() < b.size();
             });

        unordered_set<string> built;
        vector<string> answer;

        for (const string& word : words) {
            if (canForm(word, built)) {
                answer.push_back(word);
            }
            built.insert(word);
        }
        return answer;
    }

private:
    bool canForm(const string& word,
                 const unordered_set<string>& built) {
        if (built.empty()) return false;
        const int n = static_cast<int>(word.size());
        vector<char> dp(n + 1, false);
        dp[0] = true;

        for (int end = 1; end <= n; ++end) {
            for (int start = 0; start < end; ++start) {
                if (dp[start] &&
                    built.count(word.substr(start, end - start))) {
                    dp[end] = true;
                    break;
                }
            }
        }
        return dp[n];
    }
};

替代方案

  • Trie + DFS / DP：逐字符沿字典树走，避免创建大量子串；实现更复杂，在最大词长较大时更有优势。
  • 记忆化 DFS：从某个下标开始尝试所有词，缓存“后缀是否可拆”。思路直观，但仍需特别防止当前词匹配自身。
  • 逐词移除自身：先将所有词放进集合，检查前暂时删除当前词，之后加回。无需排序，但反复操作集合，且不如长度顺序清晰。

常见错误

  • 把当前词预先放进集合，导致每个词都能通过一次整词匹配。
  • 只贪心选择最长前缀；某条路径失败并不代表其他切分点也失败。
  • 判定失败后不把普通词加入集合，导致更长连接词缺少基础词。
  • 误以为组成词必须不同；题目允许同一个短词重复出现。
  • 只统计片段数量却没有确保覆盖整个字符串。

Interview follow-ups

面试追问

如果单词最大长度很大，怎样优化？

使用 Trie 沿字符扫描，避免为每个区间创建子串；也可以记录词库的最短、最长长度，缩小切分点范围。

如何恢复一种具体拆分方案？

把布尔 DP 改为记录前驱切分点。到达末尾后从 n 反向回溯，再翻转片段序列。

为什么排序是安全的？

连接词的每个组成词都严格更短，因此它们必然先被处理。相同长度的词无法成为当前词的真子片段并单独覆盖全文。

可以并行处理同一长度的词吗？

可以。先用仅含更短词的只读集合并行判定这一长度组，整组完成后再统一入库，语义保持不变。
