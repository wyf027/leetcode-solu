Problem / 题意

一个数组，同时容纳三个固定容量栈

push · pop · peek · isEmpty

实现 TripleInOne。构造函数给出每个栈的容量 stackSize；支持 push(stackNum, value)、 pop(stackNum)、peek(stackNum) 与 isEmpty(stackNum)。栈满时 push 不写入；空栈的 pop、peek 返回 -1。

核心洞察

先切三段，再让 size 同时充当栈顶指针

长度为 3 × stackSize 的数组被均分成三个互不重叠的区间。 第 stackNum 个栈的下一写入地址是 stackNum × stackSize + sizes[stackNum]；一个长度为 3 的计数数组即可定位每个栈顶。

复杂度

所有操作 O(1)

push、pop、peek、isEmpty 都只做常数次寻址。数组占 O(3 × stackSize) 空间，三个 size 计数器占 O(1) 额外空间。

完整过程

  1. 构造时申请 3 × stackSize 个槽位，并把三个 size 置零。
  2. push 先判断 size 是否等于容量；未满才按公式写入并自增。
  3. pop 先判空，再把 size 自减，读取缩减后所指向的槽位。
  4. peek 读取 size - 1 的槽位；isEmpty 只检查 size 是否为 0。

边界

  • stackSize = 0 时数组为空，所有 push 都被忽略。
  • 栈满后的 push 不覆盖已有栈顶，也不影响另外两个栈。
  • 空栈 pop、peek 返回 -1；isEmpty 返回 true。
  • stackNum 的有效范围由题目保证为 0、1、2。

替代方案

若三个栈容量极不均衡，可在单数组内使用循环区间和搬移策略动态借槽，空间利用率更高；但扩容时可能移动 O(n) 个元素，不符合本题最清晰的固定容量契约。

面试追问

如果必须让三个栈共享未使用空间，可维护每段的 start、size、capacity；某段满时沿环形数组寻找可移动的邻段。需要说明均摊复杂度与搬移成本。

常见错误

忘记乘 stackSize 导致三栈地址重叠；满栈仍递增 size；pop 先读取再自减造成越界；peek 使用 size 而不是 size - 1。 

class TripleInOne {
    private final int[] values;
    private final int[] sizes = new int[3];
    private final int stackSize;

    public TripleInOne(int stackSize) {
        this.stackSize = stackSize;
        values = new int[3 * stackSize];
    }

    public void push(int stackNum, int value) {
        if (sizes[stackNum] == stackSize) {
            return;
        }
        int index = stackNum * stackSize + sizes[stackNum];
        values[index] = value;
        sizes[stackNum]++;
    }

    public int pop(int stackNum) {
        if (isEmpty(stackNum)) {
            return -1;
        }
        sizes[stackNum]--;
        return values[stackNum * stackSize + sizes[stackNum]];
    }

    public int peek(int stackNum) {
        if (isEmpty(stackNum)) {
            return -1;
        }
        return values[stackNum * stackSize + sizes[stackNum] - 1];
    }

    public boolean isEmpty(int stackNum) {
        return sizes[stackNum] == 0;
    }
}

    def __init__(self, stackSize: int):
        self.stack_size = stackSize
        self.values = [0] * (3 * stackSize)
        self.sizes = [0, 0, 0]

    def push(self, stackNum: int, value: int) -> None:
        if self.sizes[stackNum] == self.stack_size:
            return
        index = stackNum * self.stack_size + self.sizes[stackNum]
        self.values[index] = value
        self.sizes[stackNum] += 1

    def pop(self, stackNum: int) -> int:
        if self.isEmpty(stackNum):
            return -1
        self.sizes[stackNum] -= 1
        index = stackNum * self.stack_size + self.sizes[stackNum]
        return self.values[index]

    def peek(self, stackNum: int) -> int:
        if self.isEmpty(stackNum):
            return -1
        index = stackNum * self.stack_size + self.sizes[stackNum] - 1
        return self.values[index]
