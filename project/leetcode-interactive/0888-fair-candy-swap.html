01 / 题目

交换一盒，让总量公平

返回 [x, y]：Alice 交出大小为 x 的盒子，Bob 交出大小为 y 的盒子。

给定整数数组 aliceSizes 与 bobSizes，每个元素表示一盒糖果的数量。两人必须各选一盒互换，使交换后两人的糖果总数相同。若答案不止一个，返回任意一个；输入保证至少存在有效答案。

函数形式
fairCandySwap(aliceSizes: integer[], bobSizes: integer[]) → integer[]

约束

  • 1 ≤ aliceSizes.length, bobSizes.length ≤ 10⁴
  • 1 ≤ aliceSizes[i], bobSizes[j] ≤ 10⁵
  • 两人的初始糖果总数不同。
  • 至少存在一个有效交换方案。
示例 1输入：aliceSizes = [1,1], bobSizes = [2,2]\n输出：[1,2]
示例 2输入：aliceSizes = [1,2], bobSizes = [2,3]\n输出：[1,2]
示例 3输入：aliceSizes = [2], bobSizes = [1,3]\n输出：[2,3]
示例 4输入：aliceSizes = [1,2,5], bobSizes = [2,4]\n输出：[5,4]

03 / 题解

用集合寻找唯一需要补偿的差值

设 Alice 交出 x、Bob 交出 y，直接从交换后的等式推导。

核心洞察：两人总量之差的一半，就是 Alice 交出的盒子相对 Bob 交出的盒子应多出的糖果数。

sumA - x + y = sumB - y + x ⟹ x - y = (sumA - sumB) / 2

令 delta = (sumA - sumB) / 2。枚举 Alice 的每个 x，只需判断 Bob 是否拥有 y = x - delta。把 Bob 的盒子大小放入哈希集合即可 O(1) 平均查询。

完整过程

  1. 分别求出 sumA 与 sumB。
  2. 计算 delta = (sumA - sumB) / 2。
  3. 把 bobSizes 的元素加入集合。
  4. 遍历 Alice 的盒子 x，计算 y = x - delta。
  5. 若集合包含 y，返回 [x, y]。

边界

  • 盒子数量可为 1，逻辑不变。
  • 数组可有重复值，集合只用于存在性判断。
  • 总量差可能为负；公式仍然成立。
  • 题目保证有解，因此差值会对应合法整数盒子。

正确性证明

必要性：若交换 x 与 y 后总量相等，则整理等式必有 x - y = delta，也就是 y = x - delta。

充分性：算法返回的 x 来自 Alice，y 来自 Bob，且满足 x - y = delta。代回可得 sumA - x + y = sumB - y + x，交换后总量相等。

因此算法返回的方案必定正确；又因题目保证存在方案，枚举时必能找到。

复杂度

时间 O(n + m)；空间 O(m)，m 为 Bob 的盒子数。

替代方案

排序 + 二分：排序 Bob 的数组后，为每个 x 二分查找 x - delta，时间 O(m log m + n log m)，额外空间取决于排序实现。

排序 + 双指针：两数组排序后根据当前差值移动指针，时间 O(n log n + m log m)。

哈希集合通常最直接，也避免了排序改变输入顺序。

面试追问与常见错误

  • 为什么除以 2？ 一次交换同时让 Alice 减少差额、Bob 增加差额，双方距离缩短两倍。
  • 能否返回任意解？ 可以，首次命中即可返回。
  • 错误地寻找 x + y，而真正固定的是 x - y。
  • 把 delta 写成 (sumB-sumA)/2 后仍使用 y=x-delta，导致符号反转。
  • 双重循环会退化到 O(nm)，在 10⁴ × 10⁴ 时过慢。
  • 用位运算除以 2 可能引入语言相关的溢出或符号问题。

四语言完整代码

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int[] fairCandySwap(int[] aliceSizes, int[] bobSizes) {
        int sumA = 0, sumB = 0;
        for (int x : aliceSizes) sumA += x;
        for (int y : bobSizes) sumB += y;

        int delta = (sumA - sumB) / 2;
        Set<Integer> bobBoxes = new HashSet<>();
        for (int y : bobSizes) bobBoxes.add(y);

        for (int x : aliceSizes) {
            int y = x - delta;
            if (bobBoxes.contains(y)) return new int[] {x, y};
        }
        return new int[0];
    }
}

var fairCandySwap = function(aliceSizes, bobSizes) {
    const sumA = aliceSizes.reduce((sum, x) => sum + x, 0);
    const sumB = bobSizes.reduce((sum, y) => sum + y, 0);
    const delta = (sumA - sumB) / 2;
    const bobBoxes = new Set(bobSizes);

    for (const x of aliceSizes) {
        const y = x - delta;
        if (bobBoxes.has(y)) return [x, y];
    }
    return [];
};
