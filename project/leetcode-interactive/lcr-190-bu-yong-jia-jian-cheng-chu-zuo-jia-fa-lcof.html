加密运算
把进位送上线路。

不用 +、-、*、/。XOR 先拼出不进位和，AND 找出进位，再将进位左移；直到进位归零。

启动可视化

THE CIRCUIT

  1. 01 / SUM
    a ^ b：相异的位留下来。
  2. 02 / CARRY
    (a & b) << 1：同为 1 的位向左传递。
  3. 03 / REPEAT
    下一轮把“和”和“进位”再合成。

01 · PROBLEM

题意与边界

安全通信专家需要统计两次通信的数据量：正数表示发送量、负数表示接收量、0表示数据遗失。给定 dataA 与 dataB，不使用四则运算符，计算两次通信数据量之和。

  • • 官方保证：结果不会溢出 32 位整数
  • • 时间：循环次数至多 32 次，O(1)
  • • 空间：只保留两个寄存器，O(1)
  • • 负数：二进制补码自然参与运算
官方示例

输入：dataA = 5, dataB = -1；输出：4。

03 · SOLUTION

完整题解、可提交代码与易错点

为什么会收敛？

每轮都把进位往高位推进。有限的 32 位中，进位不可能无限向左移动；最多 32 轮后，b === 0，此时 a 就是结果。

易错点

  • 不要写 a + b 作为循环条件或返回值。
  • JavaScript 的位运算结果自动回到有符号 32 位；不要用普通算术修正负数。
  • Python 需要掩码限制为 32 位，否则负数会无限符号扩展。

复杂度

最多 32 次固定宽度循环，时间和额外空间均为 O(1)。

交互阅读

本页在每轮同时显示未进位和与下一轮进位。黄色是 XOR 结果，粉色是向左传播的 carry。 

var encryptionCalculate = function(dataA, dataB) {
  while (dataB !== 0) {
    const sum = dataA ^ dataB;
    dataB = (dataA & dataB) << 1;
    dataA = sum;
  }
  return dataA;
};
class Solution {
    public int encryptionCalculate(int dataA, int dataB) {
        while (dataB != 0) {
            int sum = dataA ^ dataB;
            dataB = (dataA & dataB) << 1;
            dataA = sum;
        }
        return dataA;
    }
}
class Solution:
    def encryptionCalculate(self, dataA: int, dataB: int) -> int:
        mask = 0xffffffff
        while dataB:
            dataA, dataB = (dataA ^ dataB) & mask, ((dataA & dataB) << 1) & mask
        return dataA if dataA < 0x80000000 else ~(dataA ^ mask)
class Solution {
public:
    int encryptionCalculate(int dataA, int dataB) {
        unsigned a = static_cast<unsigned>(dataA);
        unsigned b = static_cast<unsigned>(dataB);
        while (b) { unsigned sum = a ^ b; b = (a & b) << 1; a = sum; }
        return static_cast<int>(a);
    }
};
