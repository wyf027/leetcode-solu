1365. 有多少小于
当前数字的数字

How Many Numbers Are Smaller Than the Current Number

数组哈希表计数排序排序

题目

给定整数数组 nums，对每个位置 i，统计数组中严格小于 nums[i] 的元素个数。也就是计算满足 j ≠ i 且 nums[j] < nums[i] 的下标 j 数量，并按原下标顺序返回这些计数。

函数形式： smallerNumbersThanCurrent(nums: integer[]) → integer[]

官方示例

示例 1
输入：nums = [8,1,2,2,3]
输出：[4,0,1,1,3]
解释：8 的左侧答案是 4，因为 1、2、2、3 都更小；
1 前没有任何更小值；两个 2 的答案均为 1；3 的答案为 3。
示例 2
输入：nums = [6,5,4,8]
输出：[2,1,0,3]
示例 3
输入：nums = [7,7,7,7]
输出：[0,0,0,0]

约束

  • 2 ≤ nums.length ≤ 500
  • 0 ≤ nums[i] ≤ 100

Full solution

计数桶 + 前缀和

核心洞察：值域只有 0..100。先统计每个值出现几次，再令 count[x] 表示严格小于 x 的元素数量，原数组中的每个 x 便可直接查表。

完整过程

  1. 建立长度 101 的数组 count，遍历 nums，令 count[x]++。此时它是频次数组。
  2. 从右向左更新：对 x = 100..1，执行 count[x] = count[x - 1] 对应的累计思想需要额外数组；更直接的实现是先做频次前缀和，再对值 x 查询 x == 0 ? 0 : prefix[x - 1]。
  3. 保持原数组顺序，把每个 nums[i] 映射为严格更小元素的累计数量，写入答案。

正确性

引理：完成前缀累计后，prefix[v] 等于数组中值不大于 v 的元素数量，因为它累加了从 0 到 v 的全部频次。

结论：当当前值为 x > 0 时，所有严格小于它的整数值恰好位于 0..x-1，所以答案为 prefix[x-1]；当 x = 0 时不存在更小的合法值，答案为 0。逐个映射且不改变下标顺序，返回数组因此对每个位置都正确。

边界情况

  • 全部相同：每个位置都得到 0。
  • 包含 0：0 的答案始终是 0，查询时避免访问下标 -1。
  • 重复值：相同值查询同一个前缀位置，答案自然相同；不会把相等元素误算为更小。
  • 已升序或降序：算法只依赖频次，与输入次序无关，输出仍按原下标排列。

复杂度

设数组长度为 n，值域大小为 U = 101。时间复杂度 O(n + U)，额外空间复杂度 O(U)；在本题固定值域下可视为 O(n) 时间、O(1) 额外空间。

替代方案

  • 暴力比较：每个元素与全部元素比较，O(n²) 时间、O(1) 额外空间，直观但未利用值域。
  • 排序 + 首次下标：复制并排序，某个值第一次出现的位置就是比它小的数量；配合哈希表可达 O(n log n)。

面试追问

  • 如果数值范围非常大或含负数？可排序并记录首次下标，或先做坐标压缩。
  • 如果数据流持续到来并要求在线查询？可用支持秩查询的平衡树、树状数组或线段树。
  • 如果问题改为“小于等于”？查询 prefix[x]，但要根据是否排除自身调整语义。

常见错误

  • 查询 prefix[x]，把与当前值相等的元素也算进去。
  • 直接排序原数组，导致无法按原下标返回答案。
  • 对 0 查询 prefix[-1]，没有单独处理最小值。
  • 忽略重复数字应拥有相同答案。

class Solution {
    public int[] smallerNumbersThanCurrent(int[] nums) {
        int[] prefix = new int[101];
        for (int value : nums) {
            prefix[value]++;
        }
        for (int value = 1; value <= 100; value++) {
            prefix[value] += prefix[value - 1];
        }

        int[] answer = new int[nums.length];
        for (int i = 0; i < nums.length; i++) {
            answer[i] = nums[i] == 0 ? 0 : prefix[nums[i] - 1];
        }
        return answer;
    }
}

var smallerNumbersThanCurrent = function(nums) {
    const prefix = new Array(101).fill(0);
    for (const value of nums) {
        prefix[value]++;
    }
    for (let value = 1; value <= 100; value++) {
        prefix[value] += prefix[value - 1];
    }
    return nums.map(value => value === 0 ? 0 : prefix[value - 1]);
};
from typing import List


class Solution:
    def smallerNumbersThanCurrent(self, nums: List[int]) -> List[int]:
        prefix = [0] * 101
        for value in nums:
            prefix[value] += 1

        for value in range(1, 101):
            prefix[value] += prefix[value - 1]

        return [0 if value == 0 else prefix[value - 1] for value in nums]
class Solution {
public:
    vector<int> smallerNumbersThanCurrent(vector<int>& nums) {
        vector<int> prefix(101, 0);
        for (int value : nums) {
            ++prefix[value];
        }
        for (int value = 1; value <= 100; ++value) {
            prefix[value] += prefix[value - 1];
        }

        vector<int> answer;
        answer.reserve(nums.size());
        for (int value : nums) {
            answer.push_back(value == 0 ? 0 : prefix[value - 1]);
        }
        return answer;
    }
};
