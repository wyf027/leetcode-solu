Easy数组 · 升序记录records.length ≤ 10000

题意

某班有 n 位同学，学号本应覆盖 0 到 n - 1。升序数组 records 是实际到场记录，恰有一人缺席，返回缺席学号。

官方示例 1：records = [0, 1, 2, 3, 5]，输出 4。

官方示例 2：records = [0, 1, 2, 3, 4, 5, 6, 8]，输出 7。

提示：1 <= records.length <= 10000。数组升序且只缺一位。

题解：寻找第一个 records[i] ≠ i 的位置

缺席前，记录满足 records[i] = i；从缺席者开始，后面的每个学号都会比下标大 1。因此布尔条件 records[mid] === mid 是一段连续的“真”，随后都是“假”，可以二分找第一个假值。

完整过程

  1. 令 left = 0，right = records.length - 1。
  2. 取中点 mid。若 records[mid] = mid，缺席者在右半段，令 left = mid + 1。
  3. 否则缺席者在 mid 或左侧，令 right = mid - 1。
  4. 循环结束时 left 正是第一个不相等的位置，也就是答案。

边界与复杂度

缺 0 时首次就不相等；缺最后一个学号时，所有已有位置都相等，最终 left = records.length。时间 O(log n)，额外空间 O(1)。

替代方案与面试追问

线性扫描首个 records[i] !== i 更直观，时间 O(n)；也可用理论总和减实际总和，但在某些语言要注意整数范围。追问“可能缺多个”时，单一分界不再成立，需要按区间或哈希记录缺失集合。

常见错误

  • 把 right 设为 mid 却使用不匹配的循环条件，造成死循环。
  • 找到了 records[mid] > mid 后返回数组值，而非缺席学号 mid。
  • 忽略答案可能是 records.length（最后一个学号缺席）。 
class Solution {
  public int takeAttendance(int[] records) {
    int left = 0, right = records.length - 1;
    while (left <= right) {
      int mid = left + (right - left) / 2;
      if (records[mid] == mid) left = mid + 1;
      else right = mid - 1;
    }
    return left;
  }
}
