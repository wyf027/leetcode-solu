距离顺序排列矩阵单元格

Matrix Cells in Distance Order

EASY · 免费题

题目

给定四个整数 rows、cols、rCenter 和 cCenter。一个 rows × cols 矩阵的坐标从 (0,0) 开始。返回全部单元格坐标，使其到中心 (rCenter,cCenter) 的距离非递减；相同距离内顺序任意。

距离为曼哈顿距离：|r₁-r₂| + |c₁-c₂|。函数形式：allCellsDistOrder(rows, cols, rCenter, cCenter) → integer[][]

示例 1
输入：rows=1, cols=2, rCenter=0, cCenter=0
输出：[[0,0],[0,1]]
距离：[0,1]
示例 2
输入：rows=2, cols=2, rCenter=0, cCenter=1
输出：[[0,1],[0,0],[1,1],[1,0]]
距离：[0,1,1,2]
同距离坐标可交换。
示例 3
输入：rows=2, cols=3, rCenter=1, cCenter=2
输出：[[1,2],[0,2],[1,1],[0,1],[1,0],[0,0]]
距离：[0,1,1,2,2,3]
约束
  • 1 ≤ rows, cols ≤ 100
  • 0 ≤ rCenter < rows
  • 0 ≤ cCenter < cols

题解：距离桶

核心洞察

最大曼哈顿距离不超过 rows + cols - 2，所以距离可直接作为桶下标。枚举所有坐标并入桶，最后从小到大展开桶，无需比较排序。

完整过程

  1. 创建 rows + cols - 1 个桶。
  2. 枚举坐标并计算 d=|r-rCenter|+|c-cCenter|。
  3. 将坐标放入第 d 桶。
  4. 按 d 递增连接各桶。

正确性

双重循环恰好访问每个坐标一次，因此输出不重不漏。第 d 桶内所有坐标的距离都是 d；按桶号递增连接后，前项距离必不大于后项距离。同桶内部顺序任意，符合题意。

边界与复杂度

单格矩阵只产生中心；中心在角落或边缘时算法不变。时间 O(rows·cols)，空间（含结果）O(rows·cols)。

替代方案

收集后比较排序为 O(RC log RC)，代码直观但较慢。BFS 可按距离逐层输出，时间线性但需要队列和 visited；只取前 k 个结果时更合适。

面试追问

  • 只取最近 k 个：BFS 到 k 个即停。
  • 切比雪夫距离：桶键改为行列差绝对值的最大值。
  • 减少辅助空间：逐距离枚举菱形边界并裁剪。

常见错误

  • 使用欧氏距离；桶数少一；遗漏边界坐标。
  • 误以为同距离坐标必须与示例完全同序。
  • JavaScript 比较器错误地返回布尔值。

四语言完整代码

import java.util.*;
class Solution {
  public int[][] allCellsDistOrder(int rows,int cols,int rCenter,int cCenter) {
    List<int[]>[] b=new List[rows+cols-1];
    for(int i=0;i<b.length;i++) b[i]=new ArrayList<>();
    for(int r=0;r<rows;r++) for(int c=0;c<cols;c++)
      b[Math.abs(r-rCenter)+Math.abs(c-cCenter)].add(new int[]{r,c});
    int[][] ans=new int[rows*cols][2]; int k=0;
    for(List<int[]> x:b) for(int[] cell:x) ans[k++]=cell;
    return ans;
  }
}
var allCellsDistOrder=function(rows,cols,rCenter,cCenter){

    b[Math.abs(r-rCenter)+Math.abs(c-cCenter)].push([r,c]);
  return b.flat();
};
