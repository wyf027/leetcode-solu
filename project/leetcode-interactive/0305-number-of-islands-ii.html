岛屿数量 II

Number of Islands II

一片最初全是水的网格，会依次长出陆地。每次变化后，都要立即回答当前有多少个互不相连的岛屿。先读清楚输入输出，再用下方实验场逐步观察变化。

01题目描述

给定两个正整数 m 和 n，表示一个 m × n 的二维网格。网格初始全部是水。岛屿由若干通过上、下、左、右相邻的陆地格组成，斜向接触不算连通。

positions[i] = [rᵢ, cᵢ] 表示第 i 次操作把坐标 (rᵢ, cᵢ) 变成陆地。请在每次操作后记录岛屿数量，并按顺序返回这些数量。若同一坐标重复出现，它仍然是原来的陆地，本次答案不变。

函数签名：numIslands2(m, n, positions) → List<Integer>

示例 1

输入：m = 3, n = 3
positions = [[0,0],[0,1],[1,2],[2,1]]
输出：[1,1,2,3]

操作后的陆地集合：
[(0,0)] → 1
[(0,0),(0,1)] → 1
再加入 (1,2) → 2
再加入 (2,1) → 3

示例 2

输入：m = 1, n = 1
positions = [[0,0]]
输出：[1]

参数约束

  • 1 ≤ m, n, positions.length ≤ 10⁴
  • 1 ≤ m × n ≤ 10⁴
  • positions[i].length = 2
  • 0 ≤ rᵢ < m，0 ≤ cᵢ < n

并查集：让新增陆地与邻居合并

跳到代码

A核心洞察

每次新增一个此前不存在的陆地格时，先把它当作一个独立岛屿，所以岛屿数加一。然后检查四个方向：若相邻格已经是陆地，且两格属于不同连通分量，就合并这两个分量，岛屿数减一。

这正是并查集擅长维护的动态连通性：find(x) 找到格子所在集合的根，union(a,b) 只在两个根不同时合并。路径压缩与按大小合并让一连串操作几乎保持常数时间。

B完整过程

  1. 建立长度为 m × n 的 parent，用 -1 表示水；size 记录根集合大小。
  2. 依次处理 (r,c)，映射到一维编号 id = r × n + c。
  3. 若 parent[id] != -1，说明是重复操作，直接记录当前计数。
  4. 否则设置 parent[id] = id、size[id] = 1，并令计数加一。
  5. 检查四邻居。对每个合法陆地邻居执行合并；每次真正合并都令计数减一。
  6. 将本轮计数加入答案。

C复杂度与边界

设操作次数为 k。初始化数组需要 O(mn) 空间与时间；每次最多做四次并查集操作，总时间为 O(mn + k·α(mn))，其中 α 是反阿克曼函数，实际近似常数。额外空间为 O(mn)。

  • 重复坐标：不可再次增加岛屿数。
  • 边角格：先做越界判断再访问邻居。
  • 一次加入可能同时连接多个岛屿；每次真正合并都要减一。
  • 邻居虽多，但可能已属于同一集合；根相同不能重复减一。

D正确性证明

1
不变量。处理完任意前缀后，并查集中的每个集合恰好对应网格中的一个岛屿，变量 count 等于集合数量。
2
初始成立。开始时没有陆地、没有集合，count = 0，不变量成立。
3
保持。重复坐标不改变网格和并查集。新增坐标先形成唯一的新集合，计数加一；它只能通过四邻接与既有岛屿连通。每合并两个不同集合，真实岛屿数与 count 都恰好减一；相同集合不变。因此本轮结束后不变量继续成立。
4
结论。由数学归纳法，每次写入答案的 count 都等于该次操作后的岛屿数量，算法正确。

E替代方案与取舍

每轮 DFS / BFS 重数

容易想到，但每次都扫描整个网格，最坏约 O(kmn)；适合极小输入或作为基准实现。

哈希版并查集

只为出现过的陆地建节点，空间降为 O(k)；当 m × n 很大而操作稀疏时更合适，但常数和实现复杂度略高。

F常见错误

  • 把“遇到一个陆地邻居就减一”当成规则，导致同一岛屿从两侧接触时重复减少。
  • 忽略重复的 positions，错误地再次初始化节点或增加计数。
  • 混淆行列，使用 id = r × m + c；正确乘数是列数 n。
  • 递归实现 find 却不做路径压缩，或合并时未按秩/大小，可能退化。
  • 把对角线当作邻接，改变了题目定义的连通关系。

import java.util.*;

class Solution {
    private int[] parent;
    private int[] size;

    public List<Integer> numIslands2(int m, int n, int[][] positions) {
        parent = new int[m * n];
        size = new int[m * n];
        Arrays.fill(parent, -1);

        List<Integer> answer = new ArrayList<>();
        int islands = 0;
        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        for (int[] position : positions) {
            int row = position[0];
            int col = position[1];
            int id = row * n + col;

            if (parent[id] != -1) {
                answer.add(islands);
                continue;
            }

            parent[id] = id;
            size[id] = 1;
            islands++;

            for (int[] direction : directions) {
                int nextRow = row + direction[0];
                int nextCol = col + direction[1];
                if (nextRow < 0 || nextRow >= m ||
                    nextCol < 0 || nextCol >= n) {
                    continue;
                }

                int neighborId = nextRow * n + nextCol;
                if (parent[neighborId] != -1 && union(id, neighborId)) {
                    islands--;
                }
            }
            answer.add(islands);
        }
        return answer;
    }

    private int find(int node) {
        if (parent[node] != node) {
            parent[node] = find(parent[node]);
        }
        return parent[node];
    }

    private boolean union(int first, int second) {
        int rootA = find(first);
        int rootB = find(second);
        if (rootA == rootB) return false;

        if (size[rootA] < size[rootB]) {
            int temp = rootA;
            rootA = rootB;
            rootB = temp;
        }
        parent[rootB] = rootA;
        size[rootA] += size[rootB];
        return true;
    }
}

var numIslands2 = function (m, n, positions) {
    const parent = new Int32Array(m * n);
    const size = new Int32Array(m * n);
    parent.fill(-1);

    const find = (node) => {
        let root = node;
        while (parent[root] !== root) root = parent[root];
        while (parent[node] !== node) {
            const next = parent[node];
            parent[node] = root;
            node = next;
        }
        return root;
    };

    const union = (first, second) => {
        let rootA = find(first);
        let rootB = find(second);
        if (rootA === rootB) return false;
        if (size[rootA] < size[rootB]) [rootA, rootB] = [rootB, rootA];
        parent[rootB] = rootA;
        size[rootA] += size[rootB];
        return true;
    };

    const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    const answer = [];
    let islands = 0;

    for (const [row, col] of positions) {
        const id = row * n + col;
        if (parent[id] !== -1) {
            answer.push(islands);
            continue;
        }

        parent[id] = id;
        size[id] = 1;
        islands++;

        for (const [dr, dc] of directions) {
            const nextRow = row + dr;
            const nextCol = col + dc;
            if (nextRow < 0 || nextRow >= m ||
                nextCol < 0 || nextCol >= n) continue;
            const neighborId = nextRow * n + nextCol;
            if (parent[neighborId] !== -1 && union(id, neighborId)) islands--;
        }
        answer.push(islands);
    }
    return answer;
};
from typing import List


class Solution:
    def numIslands2(
        self, m: int, n: int, positions: List[List[int]]
    ) -> List[int]:
        parent = [-1] * (m * n)
        size = [0] * (m * n)

        def find(node: int) -> int:
            while parent[node] != node:
                parent[node] = parent[parent[node]]
                node = parent[node]
            return node

        def union(first: int, second: int) -> bool:
            root_a = find(first)
            root_b = find(second)
            if root_a == root_b:
                return False
            if size[root_a] < size[root_b]:
                root_a, root_b = root_b, root_a
            parent[root_b] = root_a
            size[root_a] += size[root_b]
            return True

        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
        answer: List[int] = []
        islands = 0

        for row, col in positions:
            node = row * n + col
            if parent[node] != -1:
                answer.append(islands)
                continue

            parent[node] = node
            size[node] = 1
            islands += 1

            for dr, dc in directions:
                next_row, next_col = row + dr, col + dc
                if not (0 <= next_row < m and 0 <= next_col < n):
                    continue
                neighbor = next_row * n + next_col
                if parent[neighbor] != -1 and union(node, neighbor):
                    islands -= 1

            answer.append(islands)

        return answer
#include <array>
#include <numeric>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> numIslands2(
        int m, int n, vector<vector<int>>& positions
    ) {
        vector<int> parent(m * n, -1);
        vector<int> size(m * n, 0);

        auto find = [&](int node) {
            int root = node;
            while (parent[root] != root) root = parent[root];
            while (parent[node] != node) {
                int next = parent[node];
                parent[node] = root;
                node = next;
            }
            return root;
        };

        auto unite = [&](int first, int second) {
            int rootA = find(first);
            int rootB = find(second);
            if (rootA == rootB) return false;
            if (size[rootA] < size[rootB]) swap(rootA, rootB);
            parent[rootB] = rootA;
            size[rootA] += size[rootB];
            return true;
        };

        constexpr array<array<int, 2>, 4> directions{{
            {{1, 0}}, {{-1, 0}}, {{0, 1}}, {{0, -1}}
        }};
        vector<int> answer;
        int islands = 0;

        for (const auto& position : positions) {
            int row = position[0];
            int col = position[1];
            int id = row * n + col;
            if (parent[id] != -1) {
                answer.push_back(islands);
                continue;
            }

            parent[id] = id;
            size[id] = 1;
            ++islands;

            for (const auto& direction : directions) {
                int nextRow = row + direction[0];
                int nextCol = col + direction[1];
                if (nextRow < 0 || nextRow >= m ||
                    nextCol < 0 || nextCol >= n) continue;
                int neighborId = nextRow * n + nextCol;
                if (parent[neighborId] != -1 && unite(id, neighborId)) {
                    --islands;
                }
            }
            answer.push_back(islands);
        }
        return answer;
    }
};

H面试追问

如果允许删除陆地呢？

普通并查集不擅长拆分集合。可离线逆序处理只删除的情况，或使用回滚并查集配合线段树维护时间区间；完全在线动态连通则需要更复杂的数据结构。

网格巨大但操作很少呢？

把坐标编码为整数键，仅在哈希表中保存出现过的节点，使空间从 O(mn) 变为 O(k)。

为什么一定要检查根？

新增格可能从多个方向接触同一个旧岛屿。只有根不同才表示岛屿数量真的减少。

如何支持八方向连通？

并查集逻辑不变，只需把方向数组扩展为八个方向；正确性证明中的邻接定义同步替换。
