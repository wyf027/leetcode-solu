任务

给定一个字符串 s，统计其中所有只包含一种不同字母的非空连续子串数量，并返回总数。

子串由原字符串中一段连续位置组成；相同文本如果出现在不同位置，需要按出现次数分别计数。

官方函数签名：countLetters(s: string): integer

约束

  • 1 ≤ s.length ≤ 1000
  • s[i] 仅为小写英文字母。
  • 返回值类型为整数。

Solution

一次扫描，累加“以当前位置结尾”的答案

核心洞察

扫描到字符 s[i] 时，只需知道它与左侧相同字符连续了多长。设这个长度为 run，那么恰好以 i 结尾的合法子串有 run 个。

字符相同就令 run += 1，字符变化就把 run 重置为 1；每一步把它加入答案。

等价的连续段公式

若一个极大连续相同段长度为 L，它贡献：

1 + 2 + ··· + L = L × (L + 1) / 2

对所有极大连续段求和，与逐字符累加 run 完全等价。

完整过程

  1. 初始化 run = 0、answer = 0。
  2. 从左到右读取每个字符。如果它与前一个字符相同，连续长度加一；否则开始新段，连续长度变为 1。
  3. 把当前连续长度加入 answer。这一步只加入以当前位置结尾的新合法子串，因此不会重不漏。
  4. 扫描结束后返回 answer。

正确性证明

引理：当当前位置所在连续相同段的当前长度为 run 时，以当前位置结尾且只含一种字母的子串恰有 run 个。

因为合法起点只能是该连续段内的任一位置，共 run 种；段外紧邻字符若存在则不同，不能再向左延伸。

结论：每个非空子串都有唯一终点。算法在处理其终点时恰好计数一次，且所计数的都合法，因此最终总数正确。

复杂度

  • 时间：O(n)，每个字符仅访问一次。
  • 额外空间：O(1)，只维护连续长度和总数。
  • 数值范围：当 n = 1000 且所有字符相同时，答案为 500500，32 位整数足够。

边界情况

  • 单字符：连续长度为 1，答案为 1。
  • 所有字符都不同：每步连续长度都是 1，答案为字符串长度。
  • 所有字符都相同：答案达到最大值 n(n+1)/2。
  • 字符在多段中重复（如 "aabaa"）：不同连续段必须分开计数。

常见错误

  • 把“子串”误当成可以跳过字符的“子序列”。
  • 只统计不同文本，忘了相同文本在不同位置要分别计数。
  • 字符变化时把 run 清零；当前位置本身已构成长度 1 的合法子串，应重置为 1。
  • 按字符总频次套公式；公式只能用于连续相同段。

替代方案

可以先用双指针找出每个极大连续相同段，再累加 L(L+1)/2，同样是 O(n) 时间与 O(1) 空间。暴力枚举所有起点并向右扩展也能工作，但最坏时间为 O(n²)；它只适合作为小规模思路或人工校验模型，不是首选提交方案。

class Solution {
    public int countLetters(String s) {
        int answer = 0;
        int run = 0;

        for (int i = 0; i < s.length(); i++) {
            if (i > 0 && s.charAt(i) == s.charAt(i - 1)) {
                run++;
            } else {
                run = 1;
            }
            answer += run;
        }

        return answer;
    }
}
