04 / 独立题解

准备好后再展开：包含实现思路、证明与四语言代码。

核心洞察：原地模拟有效前缀

新的一行始终短一格，所以不必真的创建新数组。用 len 表示当前有效长度，按索引从左到右更新 nums[i]，再让 len 减一。尾部旧值不再读取。

从左到右是关键：更新位置 i 时，位置 i 和 i+1 都还保留本轮开始时的值；已覆盖的位置都在 i 左侧，不会再次使用。

完整过程

  1. 令有效长度为数组长度 n。
  2. 当有效长度大于 1 时，遍历 i = 0 到 len − 2，写入 (nums[i] + nums[i+1]) % 10。
  3. 有效长度减少一；只把前缀看作当前行。
  4. 只剩一个有效元素时返回 nums[0]。
nums = [1,2,3,4,5]
有效行  [1,2,3,4,5]
        [3,5,7,9]
        [8,2,6]
        [0,8]
        [8]
返回 8

正确性证明

外层不变式：每轮开始时，数组前 len 个元素等于题目过程中的当前数组。初始时显然成立。

内层保持：更新 i 前，只修改了索引小于 i 的位置，因此 nums[i] 与 nums[i+1] 都仍是上一行对应值。将两者之和模 10 写入 i，恰好得到新一行的第 i 项。完成循环后，前 len − 1 项组成完整下一行，缩短有效长度后不变式继续成立。

终止：len 每轮减一且下界为 1，经过 n − 1 轮终止。此时 nums[0] 正是定义要求的唯一剩余值。

边界与复杂度

  • n = 1 时循环不执行，直接返回原值；0 也同样适用。
  • 每次相加至多为 18，取余后保持 0～9，不会整数溢出。
  • 更新次数为 (n − 1) + … + 1 = n(n − 1)/2，时间 O(n²)，额外空间 O(1)。
  • 代码会修改输入数组。若调用方需要保留原数组，先复制一份，此时额外空间为 O(n)。
  • n = 1000 时共 499500 次更新；复杂度结论不代表已测运行结果。

替代方案

逐轮创建新数组最贴近题意，时间仍为 O(n²)，峰值额外空间 O(n)。保留所有行便于展示，但会占用 O(n²) 空间，本页短数组演示采用这种方式。

也可以展开贡献系数：答案等于 Σ C(n−1,i) × nums[i] mod 10。相邻合并使系数满足帕斯卡恒等式。直接计算组合数会非常大，而且模 10 下不能随意除以 i：2、5 没有乘法逆元。进阶可分别用 Lucas 定理计算模 2 和模 5 的系数，再用中国剩余定理合成模 10 的结果；逐项计算约 O(n log n) 时间。此题规模下原地模拟更直接。

面试追问

  • 为什么反向更新不行？右侧元素先被覆盖，左侧再读取时就混入下一行数据。例如 [1,2,3] 反向得到 [6,5]，正确下一行应为 [3,5]。
  • 能最后才取模吗？数学上可利用模运算分配性，但中间整数会膨胀；逐次取余避免溢出，也符合定义。
  • 输入规模进一步变大呢？考虑组合系数与模 2 / 模 5 分解，先解决复合模数下的除法问题。

常见错误

  • 内层写成 i < len，会读取 nums[len]。
  • 每一轮仍遍历完整原数组，错误地使用已失效的尾部。
  • 把相加后的个位写成除以 10；应使用取余 % 10。
  • 从右向左原地覆盖，破坏本轮依赖。
  • 声称原地方案保留输入，或把展示所有行的空间算成 O(1)。

Java

class Solution {
    public int triangularSum(int[] nums) {
        // ponytail: O(n²) simulation; use modular combinations for much larger n.
        for (int len = nums.length; len > 1; len--) {
            for (int i = 0; i < len - 1; i++) {
                nums[i] = (nums[i] + nums[i + 1]) % 10;
            }
        }
        return nums[0];
    }
}

from typing import List

class Solution:
    def triangularSum(self, nums: List[int]) -> int:
        # ponytail: O(n²); modular combinations for substantially larger n.
        for length in range(len(nums), 1, -1):
            for i in range(length - 1):
                nums[i] = (nums[i] + nums[i + 1]) % 10
        return nums[0]

#include <vector>
using std::vector;

class Solution {
public:
    int triangularSum(vector<int>& nums) {
        // ponytail: O(n²); modular combinations for much larger n.
        for (int len = static_cast<int>(nums.size()); len > 1; --len) {
            for (int i = 0; i < len - 1; ++i) {
                nums[i] = (nums[i] + nums[i + 1]) % 10;
            }
        }
        return nums[0];
    }
};
