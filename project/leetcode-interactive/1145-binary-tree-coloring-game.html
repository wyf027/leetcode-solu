Binary Tree Coloring Game

二叉树
着色游戏

一棵树、两个起点、三片疆域。你是后手：能否选择一个蓝色起点，确保最终占据严格多数节点？

boolean btreeGameWinningMove(TreeNode root, int n, int x) ↓先读题，不提前揭晓答案
01 · Problem

题目说明

树有 n 个节点，节点值恰为 1..n 且互不相同，n 为奇数。一号玩家先选红色起点 x，你再选不同的蓝色起点 y。

规则 01
红方从 x 开始，蓝方从 y 开始；随后红方先行动，双方轮流操作。
规则 02
每回合只能从己方已染色节点扩张到一个尚未染色的相邻节点；相邻包括父节点、左孩子或右孩子。
规则 03
只有确实无法扩张时才跳过回合。双方都跳过后游戏结束，占据节点更多的一方获胜。
你的任务
判断是否存在合法的 y，使二号玩家无论如何都能获胜；存在返回 true，否则返回 false。

参数与返回值

rootTreeNode：二叉树根节点
nint：树的节点总数
xint：一号玩家选择的节点值
返回boolean：二号玩家是否存在必胜选择

Solution

关键不是模拟，而是断路

把红方起点 x 从树中拿掉，整棵树最多被分成三个互不连通的区域：x 的左子树、右子树，以及经过父节点通往树其余部分的区域。

蓝方只要把起点放在某个区域与 x 相邻的入口上，就能封住唯一通道。若该区域节点数严格大于 n / 2，蓝方独占这片区域便已取得严格多数；反之三个区域都不超过半数，蓝方无法锁下一片多数区域。

left = size(x.left)　 right = size(x.right)　 parent = n − left − right − 1
答案 = max(left, right, parent) > n / 2

完整过程

  1. 用一次后序 DFS 计算每棵子树的节点数。
  2. 访问值为 x 的节点时，记录其左、右子树规模。
  3. 由总数减去两棵子树和 x 自身，得到父节点方向的规模。
  4. 判断三个规模的最大值是否严格超过半数。

为什么入口必须相邻

树中两点之间路径唯一。区域与 x 之间只有一条边；蓝方抢占这条边另一端的入口后，红方无法绕行进入。选在区域更深处并不能提供更强的理论保证，因为可能把入口留给红方。

注意比较必须是“严格大于”半数。虽然题目保证 n 为奇数，写作 maxRegion > n / 2 依然最直观。

正确性证明

分区成立。 删除节点 x 后，树只能沿 x 原有的至多三条边分裂，所以所得连通分量正是左子树、右子树和父节点方向；三者互斥且总数为 n - 1。
充分性。 若某个分量大小大于 n / 2，蓝方选择该分量中与 x 相邻的节点。红方无法越过已染蓝的入口，蓝方最终可占据该分量，节点数严格过半，因此必胜。
必要性。 若三个分量均不大于 n / 2，蓝方无论从哪个分量开始，都不能用单个起点隔离出超过半数的节点。红方占据 x 并封锁分量间唯一的连接点，蓝方不存在可保证严格多数的选择。
结论。 二号玩家存在必胜选择，当且仅当三个分量之一严格大于 n / 2；算法的判断与此完全一致。

边界与复杂度

  • x 是叶子：左右规模为 0，父方向为 n - 1。
  • x 是根：父方向为 0，只比较左右子树。
  • n = 1：三个区域均为空，返回 false。
  • 时间复杂度 O(n)；递归栈空间 O(h)，h 为树高，最坏 O(n)。

替代方案

可以先用 BFS 建立父指针，再从 x 的三个邻居分别计数；复杂度仍为 O(n)，但需要额外映射。逐回合模拟则要处理双方策略与传球，状态远多于必要信息，不适合本题。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    private int x;
    private int leftSize;
    private int rightSize;

    public boolean btreeGameWinningMove(TreeNode root, int n, int x) {
        this.x = x;
        dfs(root);
        int parentSize = n - leftSize - rightSize - 1;
        int largest = Math.max(parentSize, Math.max(leftSize, rightSize));
        return largest > n / 2;
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;
        int left = dfs(node.left);
        int right = dfs(node.right);
        if (node.val == x) {
            leftSize = left;
            rightSize = right;
        }
        return left + right + 1;
    }
}

常见错误

  • 忘记父节点方向大小是 n - left - right - 1。
  • 只比较左右子树，漏掉 x 上方的巨大区域。
  • 使用 >= n / 2；获胜要求严格更多。
  • 真的模拟轮流染色，反而把简单的树分区问题复杂化。
  • 按节点值推断树结构；节点值只用于定位 x。

面试追问

  • 若 n 可以是偶数，平局规则会怎样影响判断？
  • 如何改成非递归遍历，避免退化树造成深递归？
  • 若输入是一棵普通无根树，应如何选根并计算各相邻分量？
  • 若允许多个初始蓝点，问题会转化为什么样的分割或覆盖问题？
