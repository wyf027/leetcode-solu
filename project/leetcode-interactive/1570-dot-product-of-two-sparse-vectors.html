两个稀疏向量的点积

01 / Problem

题意与契约

给定两个长度相同的稀疏向量 nums1 和 nums2。实现 SparseVector：构造时接收一个向量，dotProduct(vec) 返回当前向量与 vec 的点积。

nums1 · nums2 =  Σ nums1[i] × nums2[i]

稀疏向量的大部分元素为 0。设计时应避免为大量无效的 0 做不必要的工作。

约束

  • n == nums1.length == nums2.length
  • 1 ≤ n ≤ 10⁵
  • 0 ≤ nums1[i], nums2[i] ≤ 100
  • 两个向量的长度始终相同。

03 / Solution

先思考，再揭晓

已经想清楚如何保存非零元素，以及怎样只访问两个向量共同拥有的索引了吗？

核心洞察完整过程正确性边界与复杂度替代方案四语言代码面试追问常见错误

题解：压缩坐标 + 双指针

核心洞察

构造对象时，仅保存每个非零元素的 (index, value)。这些坐标天然按索引递增。计算点积时，用两个指针寻找相同索引：相同则把两值乘积加入答案；较小索引对应的指针前进。

完整过程

  1. 扫描原数组，把所有非零项压缩为有序坐标对。
  2. 令 i = 0、j = 0，分别指向两个压缩数组。
  3. 若索引相等，累加乘积，两个指针都前进。
  4. 若索引不同，只推进索引较小的一方，因为该索引不可能再与另一方匹配。
  5. 任一方遍历结束，返回累加值。

正确性

  1. 压缩保持信息：被丢弃的位置值为 0，对点积贡献恒为 0；保留的坐标对完整记录所有潜在非零贡献。
  2. 指针推进安全：当 A[i].index < B[j].index，B 后续索引只会更大，A 当前项不可能与 B 的任何项同索引，因此跳过 A[i] 不会遗漏贡献；另一方向对称。
  3. 匹配恰好一次：索引相等时累加对应乘积并同时前进，所以每个共同非零索引被计入一次且仅一次。
  4. 结论：算法累加了所有且仅有的非零乘积，因此结果等于定义中的完整点积。

边界与复杂度

  • 全零向量：压缩数组为空，答案为 0。
  • 只有一个公共非零索引：只累加该位置一次。
  • 无公共索引：指针最终越界，答案保持 0。
  • 构造时间 O(n)；若两个向量分别有 k₁、k₂ 个非零项，点积时间 O(k₁+k₂)，每个对象空间 O(k)。

替代方案

  • 哈希表：保存索引到值的映射，遍历更稀疏的一方并查询另一方。平均点积时间 O(min(k₁,k₂))，但有哈希开销。
  • 二分查找：遍历较短压缩表，在较长表按索引二分，时间 O(kmin · log kmax)。当稀疏度差异极大时可能更好。
  • 直接扫描：O(n) 时间、可不压缩；实现简单，但没有利用稀疏性。

JavaLeetCode class
class SparseVector {
    private final int[][] entries;

    SparseVector(int[] nums) {
        int count = 0;
        for (int value : nums) if (value != 0) count++;
        entries = new int[count][2];
        int p = 0;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] != 0) {
                entries[p][0] = i;
                entries[p][1] = nums[i];
                p++;
            }
        }
    }

    public int dotProduct(SparseVector vec) {
        int i = 0, j = 0, sum = 0;
        while (i < entries.length && j < vec.entries.length) {
            if (entries[i][0] == vec.entries[j][0]) {
                sum += entries[i][1] * vec.entries[j][1];
                i++;
                j++;
            } else if (entries[i][0] < vec.entries[j][0]) {
                i++;
            } else {
                j++;
            }
        }
        return sum;
    }
}
JavaScriptLeetCode class
class SparseVector {
  constructor(nums) {
    this.entries = [];
    for (let i = 0; i < nums.length; i++) {
      if (nums[i] !== 0) this.entries.push([i, nums[i]]);
    }
  }

  dotProduct(vec) {
    let i = 0;
    let j = 0;
    let sum = 0;
    while (i < this.entries.length && j < vec.entries.length) {
      const [indexA, valueA] = this.entries[i];
      const [indexB, valueB] = vec.entries[j];
      if (indexA === indexB) {
        sum += valueA * valueB;
        i++;
        j++;
      } else if (indexA < indexB) {
        i++;
      } else {
        j++;
      }
    }
    return sum;
  }
}

class SparseVector:
    def __init__(self, nums: List[int]):
        self.entries = [
            (index, value)
            for index, value in enumerate(nums)
            if value != 0
        ]

    def dotProduct(self, vec: 'SparseVector') -> int:
        i = j = total = 0
        while i < len(self.entries) and j < len(vec.entries):
            index_a, value_a = self.entries[i]
            index_b, value_b = vec.entries[j]
            if index_a == index_b:
                total += value_a * value_b
                i += 1
                j += 1
            elif index_a < index_b:
                i += 1
            else:
                j += 1
        return total
C++LeetCode class
class SparseVector {
private:
    vector<pair<int, int>> entries;

public:
    SparseVector(vector<int> &nums) {
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            if (nums[i] != 0) entries.push_back({i, nums[i]});
        }
    }

    int dotProduct(SparseVector& vec) {
        int i = 0, j = 0, sum = 0;
        while (i < static_cast<int>(entries.size()) &&
               j < static_cast<int>(vec.entries.size())) {
            if (entries[i].first == vec.entries[j].first) {
                sum += entries[i].second * vec.entries[j].second;
                ++i;
                ++j;
            } else if (entries[i].first < vec.entries[j].first) {
                ++i;
            } else {
                ++j;
            }
        }
        return sum;
    }
};

面试追问

  • 若只有一个向量稀疏？保存稀疏向量的坐标，点积时直接读取稠密向量对应位置，时间 O(k)。
  • 两个向量稀疏度相差悬殊？可遍历更短者，并在另一方哈希查询或二分查找。
  • 需要频繁更新元素？静态数组对更新不友好，可改用有序映射或哈希表，并根据查询/更新比例取舍。
  • 整数会溢出吗？本题约束下通常安全；若数值或长度放大，应使用 64 位累加器。

常见错误

  • 索引相等后只移动一个指针，导致重复或死循环。
  • 索引不等时移动了较大索引的一方，从而遗漏未来匹配。
  • 只保存非零值却没有保存原索引，无法判断两个值是否位于同一位置。
  • 误把点积写成两个向量元素之和，或忽略向量长度契约。
