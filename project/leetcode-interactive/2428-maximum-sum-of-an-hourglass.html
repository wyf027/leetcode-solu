沙漏的最大总和

Maximum Sum of an Hourglass

在数字矩阵中放入一个不能旋转的沙漏，找到七个格子的最大总和。先观察形状，再尝试自己的思路。

阅读题目 ↓

01 / 题目与形状

给定整数矩阵 grid，大小为 m × n。一个沙漏由连续三行中的七个位置组成：第一行连续三格，第二行仅中间一格，第三行连续三格。

返回所有合法沙漏的元素和中的最大值。沙漏不能旋转，也不能有任何部分超出矩阵。

参数：grid: integer[][]；返回值：integer。

●●●×●×●●●

× 位置不属于沙漏；外接范围为 3 × 3。

约束

  • m == grid.length
  • n == grid[i].length，矩阵每行长度相同。
  • 3 ≤ m, n ≤ 150
  • 0 ≤ grid[i][j] ≤ 106

官方示例 1

输入：grid = [[6,2,1,3],[4,2,1,5],[9,2,8,7],[4,1,2,9]]
输出：30

左上方沙漏的七格总和为 6 + 2 + 1 + 2 + 9 + 2 + 8 = 30，这是该矩阵中的最大值。

官方示例 2

输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：35

只有一个沙漏：1 + 2 + 3 + 5 + 7 + 8 + 9 = 35。

04 / 独立题解

准备好后，再展开完整思路与四语言代码。

核心洞察：固定七格，只需确定位置

每个合法沙漏恰好对应一个 3 × 3 子矩阵。用外接子矩阵的左上角 (r, c) 唯一表示它；只要这个角落合法，七个取值位置就全部确定。

(r, c)       (r, c+1)       (r, c+2)
             (r+1, c+1)
(r+2, c)     (r+2, c+1)     (r+2, c+2)

完整过程

  1. 令最大和 best = 0。题目中所有元素非负，因此这是合法下界。
  2. 枚举行号 r = 0 … m-3，列号 c = 0 … n-3。
  3. 把上方三格、中间一格、下方三格相加得到 sum。
  4. 更新 best = max(best, sum)。全部位置结束后返回 best。

示例 1 依次得到：左上角 (0,0) → 30，(0,1) → 24，(1,0) → 16，(1,1) → 28；最大和保持为 30。可视化中的“上一步”会回到当时的最大和，不会保留未来结果。

正确性

覆盖：任意合法沙漏的外接左上角都满足 0 ≤ r ≤ m−3、0 ≤ c ≤ n−3，所以双重循环会访问它；不同左上角对应不同位置，没有遗漏或重复。

求和：每次只累加定义中的七个坐标，中间行的左右两格不参与，计算的正是该沙漏的总和。

维护最大值：处理第一个位置后，best 是该位置的和。假设此前 best 是已处理位置的最大和，与新位置的和取最大值后，仍是全部已处理位置的最大和。循环结束时所有沙漏都已处理，因此返回全局最大和。

边界与复杂度

  • 3 × 3 时仅计算一次；非方阵也使用各自的行列边界。
  • 全零返回 0；并列最大无需特殊处理，只要求和。
  • 最大和为 7 × 106，Java/C++ 的 32 位 int 足够，JavaScript Number 也能精确表示。
  • 时间：O((m−2)(n−2)) = O(mn)；每个位置只有固定七次取值。额外空间：O(1)，不修改输入。可视化为回放保存记录，其空间不属于提交算法。

替代方案

可以先建二维前缀和，用完整 3 × 3 矩形和减去中间行两侧的值。总时间仍为 O(mn)，常规前缀表需要 O(mn) 空间。对本题固定七格，直接求和更短；若要反复查询任意大小矩形，前缀和才更有复用价值。也可逐行维护宽度为 3 的滑动和，但不会改善渐进复杂度。

Java

class Solution {
    public int maxSum(int[][] grid) {
        int best = 0;
        for (int r = 0; r < grid.length - 2; r++) {
            for (int c = 0; c < grid[0].length - 2; c++) {
                int sum = grid[r][c] + grid[r][c + 1] + grid[r][c + 2]
                        + grid[r + 1][c + 1]
                        + grid[r + 2][c] + grid[r + 2][c + 1] + grid[r + 2][c + 2];
                best = Math.max(best, sum);
            }
        }
        return best;
    }
}

C++

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maxSum(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size(), best = 0;
        for (int r = 0; r < m - 2; ++r) {
            for (int c = 0; c < n - 2; ++c) {
                int sum = grid[r][c] + grid[r][c + 1] + grid[r][c + 2]
                        + grid[r + 1][c + 1]
                        + grid[r + 2][c] + grid[r + 2][c + 1] + grid[r + 2][c + 2];
                best = max(best, sum);
            }
        }
        return best;
    }
};

常见错误

  • 把整个 3 × 3 的九格相加，误计入中间行两侧。
  • 循环写成 r < m−3，遗漏最后一个可用起点；应为 r < m−2。
  • 列循环使用行数，非方阵会漏算或越界。
  • 以为允许旋转，从而把另一种形状也算入答案。
  • 将每个窗口求和时的变量不清零，导致跨窗口累加。

面试追问

  • 若允许负数？best 初始化为首个合法沙漏的和或负无穷；不能继续从 0 开始。
  • 若要返回位置？每次严格变大时同时记录 (r,c)；使用严格大于可保留扫描顺序中的第一个并列最大位置。
  • 若数据动态变化？单个格子只影响包含它的少量固定形状沙漏，可局部重算；维护全局最大值还需支持更新的数据结构。
  • 能低于 O(mn) 吗？一般情况下，未读取的相关格子可能改变最大和；直接扫描已达到线性量级。
