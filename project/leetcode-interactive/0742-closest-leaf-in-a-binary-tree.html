二叉树最近的叶节点

Closest Leaf in a Binary Tree

给定一棵节点值互不相同的二叉树，以及树中一定存在的目标值 k。请返回距离目标节点最近的叶节点的值。

两个节点之间的距离按连接它们的路径所经过的边数计算。没有左、右孩子的节点才是叶节点；当目标节点本身是叶节点时，答案就是 k。

若最近距离上出现多个叶节点，可返回其中任意一个。本页示例 1 沿用常见官方展示结果 2。

先自己想一遍，再展开完整题解

关键问题：二叉树的子指针只能向下，怎样让搜索跨过父节点去往另一棵子树？

Complete solution

父指针 + BFS：把树看成无向图

先遍历整棵树，记录每个节点的父节点并定位目标；随后从目标节点出发，把左孩子、右孩子和父节点都当作相邻点进行 BFS。BFS 首次遇到的原树叶节点，就是边数意义下的最近叶节点。

1

补齐“向上”边

对每条父子关系记录 parent[child] = node。无需真的改动树结构。

2

目标作为 BFS 源点

队列天然按距离递增访问节点，左右孩子和父节点都是一步可达的邻居。

3

按原树定义叶子

只用 left == null && right == null 判断叶节点；无向图中的度数不能替代它。

完整过程

  1. DFS 或 BFS 遍历树，建立每个非根节点到父节点的映射，同时找到值为 k 的目标节点。
  2. 将目标节点入队并加入访问集合，防止在父子双向边之间来回走。
  3. 反复取出队首。若它在原树中没有左右孩子，立即返回其值。
  4. 依次检查左孩子、右孩子、父节点；尚未访问的邻居入队。

复杂度与边界

  • 时间：O(n)。建父指针至多访问每个节点一次，BFS 也至多访问一次。
  • 空间：O(n)。父指针表、队列和访问集合都可能保存线性数量节点。
  • 单节点树：目标就是叶节点，BFS 第一次出队便返回。
  • 目标是内部节点：答案可能在其子树内，也可能需要先向上再进入旁支。
  • 多个最近叶子：BFS 会返回同一最短层中的某一个，具体由邻居入队顺序决定。

正确性证明

  1. 图保持树上距离。为每条父子关系补上反向访问能力后，图中的无向边与原树的边一一对应。因此任意两节点之间的边数距离保持不变。
  2. BFS 按非递减距离访问。从目标节点开始，BFS 在处理距离为 d + 1 的节点之前，会先处理完所有距离为 d 的节点。
  3. 首次叶节点最优。假设首次出队的叶节点为 x，距离为 d。若存在更近的叶节点 y，其距离小于 d，则按 BFS 顺序 y 必须先于 x 出队，矛盾。因此 x 是最近叶节点。
  4. 算法必然终止。树有限且目标存在；访问集合确保每个节点最多入队一次，而有限树至少有一个叶节点，所以 BFS 最终会返回。

import java.util.*;

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) { val = x; }
 * }
 */
class Solution {
    public int findClosestLeaf(TreeNode root, int k) {
        Map<TreeNode, TreeNode> parent = new HashMap<>();
        TreeNode target = buildParentAndFind(root, null, k, parent);

        Queue<TreeNode> queue = new ArrayDeque<>();
        Set<TreeNode> visited = new HashSet<>();
        queue.offer(target);
        visited.add(target);

        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            if (node.left == null && node.right == null) {
                return node.val;
            }

            addIfUnvisited(node.left, queue, visited);
            addIfUnvisited(node.right, queue, visited);
            addIfUnvisited(parent.get(node), queue, visited);
        }

        throw new IllegalStateException("A finite tree must contain a leaf");
    }

    private TreeNode buildParentAndFind(
            TreeNode node,
            TreeNode parentNode,
            int k,
            Map<TreeNode, TreeNode> parent) {
        if (node == null) {
            return null;
        }

        if (parentNode != null) {
            parent.put(node, parentNode);
        }

        TreeNode found = node.val == k ? node : null;
        TreeNode leftFound = buildParentAndFind(node.left, node, k, parent);
        TreeNode rightFound = buildParentAndFind(node.right, node, k, parent);

        if (found != null) return found;
        if (leftFound != null) return leftFound;
        return rightFound;
    }

    private void addIfUnvisited(
            TreeNode node,
            Queue<TreeNode> queue,
            Set<TreeNode> visited) {
        if (node != null && visited.add(node)) {
            queue.offer(node);
        }
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @param {number} k
 * @return {number}
 */
var findClosestLeaf = function(root, k) {
    const parent = new Map();
    let target = null;

    const buildParent = (node, parentNode) => {
        if (node === null) return;
        if (parentNode !== null) parent.set(node, parentNode);
        if (node.val === k) target = node;
        buildParent(node.left, node);
        buildParent(node.right, node);
    };

    buildParent(root, null);

    const queue = [target];
    const visited = new Set([target]);
    let head = 0;

    while (head < queue.length) {
        const node = queue[head++];
        if (node.left === null && node.right === null) {
            return node.val;
        }

        const neighbors = [node.left, node.right, parent.get(node) ?? null];
        for (const next of neighbors) {
            if (next !== null && !visited.has(next)) {
                visited.add(next);
                queue.push(next);
            }
        }
    }

    throw new Error("A finite tree must contain a leaf");
};
from collections import deque
from typing import Optional


# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def findClosestLeaf(self, root: Optional[TreeNode], k: int) -> int:
        parent = {}
        target = None

        def build_parent(node: Optional[TreeNode], parent_node: Optional[TreeNode]) -> None:
            nonlocal target
            if node is None:
                return
            if parent_node is not None:
                parent[node] = parent_node
            if node.val == k:
                target = node
            build_parent(node.left, node)
            build_parent(node.right, node)

        build_parent(root, None)

        queue = deque([target])
        visited = {target}

        while queue:
            node = queue.popleft()
            if node.left is None and node.right is None:
                return node.val

            for neighbor in (node.left, node.right, parent.get(node)):
                if neighbor is not None and neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)

        raise RuntimeError("A finite tree must contain a leaf")
#include <queue>
#include <stdexcept>
#include <unordered_map>
#include <unordered_set>

using namespace std;

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int findClosestLeaf(TreeNode* root, int k) {
        unordered_map<TreeNode*, TreeNode*> parent;
        TreeNode* target = nullptr;
        buildParent(root, nullptr, k, parent, target);

        queue<TreeNode*> nodes;
        unordered_set<TreeNode*> visited;
        nodes.push(target);
        visited.insert(target);

        while (!nodes.empty()) {
            TreeNode* node = nodes.front();
            nodes.pop();

            if (node->left == nullptr && node->right == nullptr) {
                return node->val;
            }

            addIfUnvisited(node->left, nodes, visited);
            addIfUnvisited(node->right, nodes, visited);
            auto it = parent.find(node);
            addIfUnvisited(it == parent.end() ? nullptr : it->second,
                           nodes, visited);
        }

        throw logic_error("A finite tree must contain a leaf");
    }

private:
    void buildParent(
        TreeNode* node,
        TreeNode* parentNode,
        int k,
        unordered_map<TreeNode*, TreeNode*>& parent,
        TreeNode*& target
    ) {
        if (node == nullptr) return;
        if (parentNode != nullptr) parent[node] = parentNode;
        if (node->val == k) target = node;
        buildParent(node->left, node, k, parent, target);
        buildParent(node->right, node, k, parent, target);
    }

    void addIfUnvisited(
        TreeNode* node,
        queue<TreeNode*>& nodes,
        unordered_set<TreeNode*>& visited
    ) {
        if (node != nullptr && visited.insert(node).second) {
            nodes.push(node);
        }
    }
};

替代方案

  • 根到目标路径 + 子树最近叶：找出路径，对路径上每个祖先计算不经过目标方向的最近叶，综合距离取最小。可以做到 O(n)，但状态和证明更繁琐。
  • 完整邻接表：将每个节点值映射为无向图后 BFS。节点值唯一时很好写，但会额外保存双向邻接边；父指针表更贴近原树结构。
  • 多源 BFS：从全部叶节点同时向内扩散，可一次预处理出每个节点的最近叶。适合对同一棵树回答很多个 k 查询。

面试追问

  • 如果同一棵树有大量查询，如何预处理以降低单次查询成本？
  • 如果节点值不唯一，目标改为节点引用或路径，接口应怎样设计？
  • 如果并列时要求返回值最小的叶节点，怎样保证同一层全部比较后再返回？
  • 如何改为返回目标到最近叶节点的完整路径，而不只返回叶节点值？

常见错误

  • 只向下搜索：会漏掉“先到父节点，再进入兄弟子树”的更短路径，示例 3 就会出错。
  • 忘记 visited：补上父边后图是双向的，搜索会在父子之间反复入队。
  • 用无向图度数判断叶子：根节点或单孩子节点可能被误判。叶子必须按原树的左右孩子判断。
  • 看到叶子就在入队时返回：若需要处理并列规则或扩展为带权边，这种写法容易埋雷；标准 BFS 在出队时判断最清晰。
  • 递归深度假设：节点数最多 1000，极端链状树可能接近语言递归栈边界；生产环境可将建表 DFS 改为显式栈。
