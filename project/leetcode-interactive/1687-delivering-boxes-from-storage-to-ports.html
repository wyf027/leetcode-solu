从仓库到码头
运输箱子

Delivering Boxes from Storage to Ports

数组动态规划前缀和单调队列
Problem brief

题目说明

boxDelivering

一辆货运卡车需要按给定顺序，把仓库队列中的箱子送往各码头。boxes[i] = [portᵢ, weightᵢ] 表示第 i 个箱子的目的码头与重量。

每轮从队首连续装入若干箱子，数量不超过 maxBoxes、总重量不超过 maxWeight。卡车按装载顺序访问目的码头；相邻箱子目的地相同时不新增码头间行程。卸完后还要返回仓库，最终也必须停在仓库。

目标：求运完全部箱子的最少行程数。“仓库 → 码头”、“不同码头之间”或“码头 → 仓库”各计一趟。

参数形式

boxDelivering(boxes, portsCount, maxBoxes, maxWeight) → integer
  • portsCount 是码头总数，码头编号为 1..portsCount。
  • 箱子必须按数组顺序处理，不能跳过或重排。
  • 每个箱子的重量均不超过单趟重量上限。

示例 1

输入：boxes = [[1,1],[2,1],[1,1]],
      portsCount = 2, maxBoxes = 3, maxWeight = 3
输出：4
说明：仓库 → 1 → 2 → 1 → 仓库。

示例 2

输入：boxes = [[1,2],[3,3],[3,1],[3,1],[2,4]],
      portsCount = 3, maxBoxes = 3, maxWeight = 6
输出：6
说明：可分为 [1]、[3,3,3]、[2] 三轮。

示例 3

输入：boxes = [[1,4],[1,2],[2,1],[2,1],[3,2],[3,4]],
      portsCount = 3, maxBoxes = 6, maxWeight = 7
输出：6
说明：三个同码头批次分别往返。

示例 4

输入：boxes = [[2,4],[2,5],[3,1],[3,2],[3,7],
               [3,1],[4,4],[1,3],[5,2]],
      portsCount = 5, maxBoxes = 5, maxWeight = 7
输出：14

约束

  • 1 ≤ boxes.length ≤ 10⁵
  • 1 ≤ portsCount, maxBoxes, maxWeight ≤ 10⁵
  • 1 ≤ portᵢ ≤ portsCount
  • 1 ≤ weightᵢ ≤ maxWeight

完整题解

先独立思考，再按需展开。

动态规划 + 前缀和 + 单调队列

核心洞察

把箱子改为 1 下标。令 change[i] 为前 i 个箱子中相邻目的码头发生变化的次数，change[1]=0。若最后一车运送 j+1..i：

本车行程 = 2 + change[i] - change[j+1]

2 代表离开仓库与返回仓库；中间每次换码头再加 1。因此：

dp[i] = change[i] + 2 + min(dp[j] - change[j+1])

只在 i-j ≤ maxBoxes 且该段重量不超限的 j 中取最小值。右端点单调右移时，合法起点只会从左侧失效，可以用单调队列维护括号内的最小值。

完整过程

  1. 预处理重量前缀和 weight 与码头变化前缀 change。
  2. 令 dp[0]=0，把划分点 j=0 放入双端队列。
  3. 枚举 i=1..n，从队首删除数量或重量不合法的候选。
  4. 队首就是使 dp[j]-change[j+1] 最小的合法起点，用它计算 dp[i]。
  5. 若 i<n，让新划分点 i 入队；先从队尾删掉值不小于它的候选。
portsCount 为什么没进入计算？ 它只限定码头编号范围；答案取决于序列中实际发生的码头变化。

正确性证明

引理 1：单车代价公式正确。

仓库到首码头、末码头回仓库固定贡献 2；装载段内仅在相邻箱子的码头不同时增加行程，数量恰为 change[i]-change[j+1]。

引理 2：转移覆盖全部方案。

任一运完前 i 箱的方案都有唯一末车起点 j+1；其前缀最优代价是 dp[j]。反之，每个满足两种容量限制的 j 都构成可行末车。

引理 3：队首给出合法最小值。

失效条件随 i 单调，只需从队首删除；入队时删除更大或相等的旧值也安全，因为新下标更晚失效。

结论：每个 dp[i] 均为精确最优值，故 dp[n] 是答案。

复杂度与边界

每个下标至多入队、出队一次：时间 O(n)，空间 O(n)。

  • 单箱答案为 2。
  • 所有箱子同码头时，每个合法批次只需往返 2 趟。
  • maxBoxes=1 时每箱单独往返。
  • 重量等于上限仍合法，判断应使用“>”。
  • Java/C++ 的重量前缀和必须用 64 位整数。

替代方案

朴素 DP 枚举所有 j，最坏 O(n²)；线段树或最小堆也能维护区间最小值，但复杂度为 O(n log n)，实现和失效清理更繁琐。

面试追问

  1. 同码头连续箱子为何只算一次？ 车辆已在该码头，继续卸货不新增行程。
  2. 队尾相等值为何可删？ 新候选值相同且下标更靠右，未来至少同样晚失效。
  3. 能否降低空间？ 队列可限制在窗口大小；再滚动保存所需前缀状态可进一步压缩。
  4. 若允许重排箱子？ 连续前缀 DP 结构会消失，转为不同的装箱与路径优化问题。

常见错误

  • 把单车代价写成码头种类数，而不是按顺序形成的码头段数。
  • 误用 change[j]，产生边界偏差。
  • 漏检重量，或只弹出一个失效队首。
  • 用 32 位整数存最高可达约 10¹⁰ 的重量前缀和。

Java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int boxDelivering(int[][] boxes, int portsCount,
                             int maxBoxes, int maxWeight) {
        int n = boxes.length;
        long[] weight = new long[n + 1];
        int[] change = new int[n + 1];
        int[] dp = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            weight[i] = weight[i - 1] + boxes[i - 1][1];
            if (i > 1) {
                change[i] = change[i - 1]
                    + (boxes[i - 1][0] != boxes[i - 2][0] ? 1 : 0);
            }
        }
        Deque<Integer> deque = new ArrayDeque<>();
        deque.addLast(0);
        for (int i = 1; i <= n; i++) {
            while (i - deque.peekFirst() > maxBoxes
                    || weight[i] - weight[deque.peekFirst()] > maxWeight) {
                deque.removeFirst();
            }
            int j = deque.peekFirst();
            dp[i] = dp[j] + change[i] - change[j + 1] + 2;
            if (i < n) {
                int value = dp[i] - change[i + 1];
                while (!deque.isEmpty()
                        && dp[deque.peekLast()]
                           - change[deque.peekLast() + 1] >= value) {
                    deque.removeLast();
                }
                deque.addLast(i);
            }
        }
        return dp[n];
    }
}

/**
 * @param {number[][]} boxes
 * @param {number} portsCount
 * @param {number} maxBoxes
 * @param {number} maxWeight
 * @return {number}
 */
var boxDelivering = function (boxes, portsCount, maxBoxes, maxWeight) {
  const n = boxes.length;
  const weight = new Array(n + 1).fill(0);
  const change = new Array(n + 1).fill(0);
  const dp = new Array(n + 1).fill(0);
  for (let i = 1; i <= n; i++) {
    weight[i] = weight[i - 1] + boxes[i - 1][1];
    if (i > 1) {
      change[i] = change[i - 1]
        + (boxes[i - 1][0] !== boxes[i - 2][0] ? 1 : 0);
    }
  }
  const deque = new Array(n + 1);
  let head = 0, tail = 0;
  deque[tail++] = 0;
  for (let i = 1; i <= n; i++) {
    while (i - deque[head] > maxBoxes
        || weight[i] - weight[deque[head]] > maxWeight) {
      head++;
    }
    const j = deque[head];
    dp[i] = dp[j] + change[i] - change[j + 1] + 2;
    if (i < n) {
      const value = dp[i] - change[i + 1];
      while (head < tail
          && dp[deque[tail - 1]]
             - change[deque[tail - 1] + 1] >= value) {
        tail--;
      }
      deque[tail++] = i;
    }
  }
  return dp[n];
};

from collections import deque
from typing import List


class Solution:
    def boxDelivering(
        self,
        boxes: List[List[int]],
        portsCount: int,
        maxBoxes: int,
        maxWeight: int,
    ) -> int:
        n = len(boxes)
        weight = [0] * (n + 1)
        change = [0] * (n + 1)
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            weight[i] = weight[i - 1] + boxes[i - 1][1]
            if i > 1:
                change[i] = change[i - 1] + (
                    boxes[i - 1][0] != boxes[i - 2][0]
                )
        candidates = deque([0])
        for i in range(1, n + 1):
            while (
                i - candidates[0] > maxBoxes
                or weight[i] - weight[candidates[0]] > maxWeight
            ):
                candidates.popleft()
            j = candidates[0]
            dp[i] = dp[j] + change[i] - change[j + 1] + 2
            if i < n:
                value = dp[i] - change[i + 1]
                while candidates and (
                    dp[candidates[-1]] - change[candidates[-1] + 1]
                    >= value
                ):
                    candidates.pop()
                candidates.append(i)
        return dp[n]
C++
#include <deque>
#include <vector>
using namespace std;

class Solution {
public:
    int boxDelivering(vector<vector<int>>& boxes, int portsCount,
                      int maxBoxes, int maxWeight) {
        int n = static_cast<int>(boxes.size());
        vector<long long> weight(n + 1, 0);
        vector<int> change(n + 1, 0), dp(n + 1, 0);
        for (int i = 1; i <= n; ++i) {
            weight[i] = weight[i - 1] + boxes[i - 1][1];
            if (i > 1) {
                change[i] = change[i - 1]
                    + (boxes[i - 1][0] != boxes[i - 2][0]);
            }
        }
        deque<int> candidates{0};
        for (int i = 1; i <= n; ++i) {
            while (i - candidates.front() > maxBoxes
                   || weight[i] - weight[candidates.front()] > maxWeight) {
                candidates.pop_front();
            }
            int j = candidates.front();
            dp[i] = dp[j] + change[i] - change[j + 1] + 2;
            if (i < n) {
                int value = dp[i] - change[i + 1];
                while (!candidates.empty()
                       && dp[candidates.back()]
                          - change[candidates.back() + 1] >= value) {
                    candidates.pop_back();
                }
                candidates.push_back(i);
            }
        }
        return dp[n];
    }
};
