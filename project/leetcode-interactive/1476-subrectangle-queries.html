Problem

题目要求

实现 SubrectangleQueries 类。构造函数接收一个 rows × cols 的整数矩阵，并在同一个对象上持续处理更新和查询。

  • 更新：把左上角 (row1, col1) 到右下角 (row2, col2) 的闭区间内所有元素改成 newValue。
  • 查询：返回坐标 (row, col) 当前保存的值。

接口签名

SubrectangleQueries(rectangle)
updateSubrectangle(row1, col1, row2, col2, newValue)
getValue(row, col) → int

Spoiler boundary

准备好再看题解

先自己判断：更新时直接改矩阵，还是先记录操作、查询时再倒推？

Solution

直接更新矩阵

核心洞察：题目最多只有 500 次操作，矩阵最多 100×100。直接遍历更新区域简单、可靠，而且让每次查询保持 O(1)。

完整过程

  1. 构造时保存一份矩阵副本。
  2. 更新时，用两层循环遍历行 row1…row2 和列 col1…col2。
  3. 把每个覆盖到的单元格赋为 newValue。
  4. 查询时直接返回 matrix[row][col]。

边界处理

  • 端点是闭区间，两层循环都必须包含 row2 与 col2。
  • 单行、单列、单点更新可由同一逻辑自然处理。
  • 后一次更新覆盖前一次更新的交叠区域。
  • 值可到 10⁹，四种语言的普通整数类型均可承载。

复杂度

  • 构造：O(rows × cols) 时间与空间（按本文实现复制）。
  • 更新：O((row2-row1+1) × (col2-col1+1)) 时间。
  • 查询：O(1) 时间。
  • 对象额外存储：O(rows × cols)。

替代方案

也可以把每次更新记录下来，更新 O(1)，查询时从后向前寻找最后一个覆盖该坐标的更新，查询 O(U)。这适合“更新远多于查询”的场景；本题规模下，直接更新更直观。

正确性说明

  1. 初始化成立：构造后内部矩阵的每个位置都与输入对应位置相同。
  2. 更新保持正确：双层循环恰好枚举闭区间内全部坐标，并将它们设为新值；区间外坐标不被访问，因此不变。
  3. 顺序一致：每次更新都写入当前矩阵，交叠位置自然保留最后一次更新的值。
  4. 查询正确：内部矩阵始终表示所有已执行操作后的当前状态，所以直接读取目标坐标就是所求值。

常见错误

循环条件写成 r < row2 或 c < col2，漏掉下边界或右边界。
只保存构造参数的浅层引用，在不希望共享外部修改时造成状态串扰。
为二维区域套用一维差分，但忘记查询之间还要得到完整当前值，反而增加实现复杂度。
误把坐标顺序当作 (列, 行)；本题始终先行后列。

面试追问

  • 如果矩阵和操作数都达到 10⁵，怎样在更新与单点查询间权衡？可讨论二维树状数组、二维差分或离线处理。
  • 如果查询变为“子矩形求和”，应该选择二维前缀和、二维树状数组还是线段树？
  • 若要求持久化每个历史版本，如何用结构共享避免复制整个矩阵？
Java可提交实现
class SubrectangleQueries {
    private final int[][] matrix;

    public SubrectangleQueries(int[][] rectangle) {
        int rows = rectangle.length;
        int cols = rectangle[0].length;
        matrix = new int[rows][cols];
        for (int r = 0; r < rows; r++) {
            System.arraycopy(rectangle[r], 0, matrix[r], 0, cols);
        }
    }

    public void updateSubrectangle(int row1, int col1,
                                   int row2, int col2,
                                   int newValue) {
        for (int r = row1; r <= row2; r++) {
            for (int c = col1; c <= col2; c++) {
                matrix[r][c] = newValue;
            }
        }
    }

    public int getValue(int row, int col) {
        return matrix[row][col];
    }
}

var SubrectangleQueries = function(rectangle) {

 * @param {number} row1
 * @param {number} col1

 * @return {void}

SubrectangleQueries.prototype.updateSubrectangle = function(
    row1, col1, row2, col2, newValue

    for (let r = row1; r <= row2; r++) {
        for (let c = col1; c <= col2; c++) {
            this.matrix[r][c] = newValue;
        }
    }
};

 * @param {number} row
 * @param {number} col
 * @return {number}

Python 3可提交实现
from typing import List


class SubrectangleQueries:
    def __init__(self, rectangle: List[List[int]]):
        self.matrix = [row[:] for row in rectangle]

    def updateSubrectangle(
        self,
        row1: int,
        col1: int,
        row2: int,
        col2: int,
        newValue: int,
    ) -> None:
        for row in range(row1, row2 + 1):
            for col in range(col1, col2 + 1):
                self.matrix[row][col] = newValue

    def getValue(self, row: int, col: int) -> int:
        return self.matrix[row][col]
