MONOTONIC DEQUE · O(n)

239. 滑动窗口最大值 Hard

队列只保留仍有资格成为最大值的下标，并让对应数值从队首到队尾严格递减：队首永远就是当前窗口答案。

?题意

给定整数数组 nums 和窗口大小 k。窗口从最左侧开始，每次向右移动一格，返回每个窗口中的最大值。

官方样例 1

nums = [1,3,-1,-3,5,3,6,7]
k = 3
输出：[3,3,5,5,6,7]

官方样例 2

nums = [1]
k = 1
输出：[1]

约束：1 ≤ nums.length ≤ 10⁵，−10⁴ ≤ nums[i] ≤ 10⁴，1 ≤ k ≤ nums.length。

核心洞察

当新元素 nums[i] 到来时，任何比它小或相等的队尾元素，在 i 仍在窗口期间都不可能再当最大值，直接淘汰。于是队列递减，队首最大。

完整过程

  1. 弹出队首所有 index ≤ i−k 的过期下标。
  2. 从队尾弹出 nums[index] ≤ nums[i] 的下标。
  3. 把 i 入队；当 i ≥ k−1 时，记录 nums[deque.front]。

边界与复杂度

  • k=1：每个元素都是答案。
  • 递减数组：队列长度可能到 k。
  • 相等元素：用 ≤ 淘汰旧下标，队列更短且正确。

时间：O(n)，每下标最多进出一次；空间：O(k)。

替代方案、追问与常见错误

替代：最大堆 O(n log k)，删除过期项；分块前后缀最大值 O(n) 也可行。
追问：若要滑动中位数？改用双堆。
错误：队列里存值而无法判过期；忘了先弹过期；从队尾只弹一个而不是循环。

import java.util.*;
class Solution { public int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> dq = new ArrayDeque<>(); int[] ans = new int[nums.length-k+1];
    for (int i=0;i<nums.length;i++) { while (!dq.isEmpty() && dq.peekFirst() <= i-k) dq.pollFirst();
        while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) dq.pollLast(); dq.offerLast(i);
        if (i >= k-1) ans[i-k+1] = nums[dq.peekFirst()]; }
    return ans;
} }

from collections import deque
class Solution:
    def maxSlidingWindow(self, nums: list[int], k: int) -> list[int]:
        q, ans = deque(), []
        for i, x in enumerate(nums):
            while q and q[0] <= i - k: q.popleft()
            while q and nums[q[-1]] <= x: q.pop()
            q.append(i)
            if i >= k - 1: ans.append(nums[q[0]])
        return ans
