判断是否为平衡二叉树

判断一棵二叉树中，是否每个节点的左右子树深度差都不超过 1。先观察树的回传轨迹，再到页面底部展开完整题解。

Easy树 · 深度优先搜索节点数 ≤ 10000

题意

输入二叉树根节点 root。若任意节点左右子树深度之差都不超过 1，返回 true；否则返回 false。

示例 1：root = [3, 9, 20, null, null, 15, 7]，输出 true

示例 2：root = [1, 2, 2, 3, 3, null, null, 4, 4]，输出 false

数组按层序表示；null 表示没有该位置的节点。

题解：后序遍历 + 失衡哨兵

先拿到左右高度，再决定当前节点：任一子树为 -1 或高度差大于 1，就立刻返回 -1；否则返回 max(left, right) + 1。

完整过程

  1. 空节点高度为 0。
  2. 先递归左右子树（后序）。
  3. 发现红牌立即向上传播，避免重复计算高度。

边界与复杂度

空树平衡；单链长度很大时递归栈深为树高。每个节点仅访问一次：时间 O(n)，额外空间 O(h)。

替代方案与面试追问

朴素做法对每个节点重复求高度，最坏会到 O(n²)。追问：若递归深度受限，可用显式栈模拟后序并保存子树高度。

常见错误

  • 只比较根节点，漏掉深层失衡。
  • 失衡后仍递归计算，失去剪枝。
  • 把节点数当树高。
class Solution {
  public boolean isBalanced(TreeNode root) { return height(root) >= 0; }
  private int height(TreeNode node) {
    if (node == null) return 0;
    int left = height(node.left);
    if (left < 0) return -1;
    int right = height(node.right);
    if (right < 0 || Math.abs(left - right) > 1) return -1;
    return Math.max(left, right) + 1;
  }
}
