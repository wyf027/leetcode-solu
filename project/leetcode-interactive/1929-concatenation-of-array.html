Concatenation of Array

一段数组，连续出现两次。先理解目标，再亲手推进每一步。

01 / 题目

给定整数数组 nums，长度为 n。返回一个长度为 2n 的新数组 ans：先放一份完整的 nums，再接一份相同的数组，保留各元素的原始顺序。

下标从 0 开始；对每个 0 ≤ i < n，要求 ans[i] = nums[i] 且 ans[i + n] = nums[i]。

官方示例 1

输入：nums = [1,2,1]
输出：[1,2,1,1,2,1]

完整的 [1,2,1] 重复两遍，连接处是两个 1。

官方示例 2

输入：nums = [1,3,2,1]
输出：[1,3,2,1,1,3,2,1]

先保留 [1,3,2,1]，再接上相同的四个元素。

约束

  • n == nums.length
  • 1 ≤ n ≤ 1000
  • 1 ≤ nums[i] ≤ 1000

参数：nums: integer[]；返回：integer[]；函数名：getConcatenation。

04 / 独立题解

准备好后，再打开思路与四语言代码。

核心洞察：一份源数据，两个固定落点

对每个源下标 i，对应的两个目标下标恰好是 i 和 i+n。只遍历一次源数组，每次写入两个位置，无须排序、比较或额外映射表。

完整过程

  1. 保存原长度 n，分配长度为 2n 的答案数组。
  2. 依次处理 i = 0, 1, …, n−1。
  3. 把 nums[i] 同时写到 ans[i] 与 ans[i+n]。
  4. 循环结束后返回 ans，原数组不变。

以 nums = [1,2,1] 为例：i=0 写入下标 0 和 3；i=1 写入 1 和 4；i=2 写入 2 和 5。最后得到 [1,2,1,1,2,1]。工作台的一步对应这两次赋值，空格以“·”表示。

正确性

循环不变式：处理完前 k 个源元素后，对所有 0 ≤ j < k，都有 ans[j] = ans[j+n] = nums[j]。初始 k=0 时结论自然成立。第 k 次处理写入 k 和 k+n，不覆盖之前的落点，因此结论扩展到 k+1。结束时 k=n，前后两段恰好覆盖所有 2n 个位置，满足题目要求。

边界与复杂度

n=1 时得到两个相同元素；重复值无需特殊处理。最大目标下标是 2n−1，在分配范围内。官方输入非空，代码无需为约束外的空值添加分支。

时间 O(n)：共读取 n 个元素并写入 2n 次。含返回数组的空间为 O(n)；排除输出后辅助空间为 O(1)。由于必须生成 2n 个结果元素，线性时间已是最优量级。

四语言完整提交代码

四份代码均使用官方函数签名，统一展示相同的双位置写入过程。

Java

class Solution {
    public int[] getConcatenation(int[] nums) {
        int n = nums.length;
        int[] ans = new int[2 * n];
        for (int i = 0; i < n; i++) {
            ans[i] = nums[i];
            ans[i + n] = nums[i];
        }
        return ans;
    }
}

Python 3

from typing import List

class Solution:
    def getConcatenation(self, nums: List[int]) -> List[int]:
        n = len(nums)
        ans = [0] * (2 * n)
        for i in range(n):
            ans[i] = nums[i]
            ans[i + n] = nums[i]
        return ans

C++

#include <vector>
using std::vector;

class Solution {
public:
    vector<int> getConcatenation(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        vector<int> ans(2 * n);
        for (int i = 0; i < n; ++i) {
            ans[i] = nums[i];
            ans[i + n] = nums[i];
        }
        return ans;
    }
};

替代方案

  • 直接串联：JavaScript 可写 return nums.concat(nums)，Python 可写 return nums + nums，都是 O(n) 时间和 O(n) 输出空间，表达最简。
  • 按目标下标遍历：ans[j] = nums[j % n]，其中 0 ≤ j < 2n。便于推广到重复 k 次，但本题无须取模。
  • Java 可用两次 System.arraycopy。C++ 可预留容量后插入两份原数组；复杂度不变。

常见错误

  • 把每个元素连续复制两次：例如得到 [1,1,2,2,1,1]，这不是整段串联。
  • 第二个位置写成 i+n−1，导致边界重叠且末尾遗漏。
  • 循环写成 i ≤ n，会越界；正确边界是 i < n。
  • 向 nums 自身追加时仍用不断增长的长度作为循环上界，可能无法结束。保存原长度并构造新数组更直接。
  • 误称空间为 O(1)：只有排除返回数组后的辅助空间才是 O(1)。

面试追问

重复 k 次怎么做？ 分配 kn 个元素，按 ans[j] = nums[j % n] 填充，时间与输出空间均为 O(kn)。

能不分配新数组吗？ 如果调用方允许惰性视图，可以只保存原数组与逻辑长度，通过取模访问；但本题要求返回实际数组，仍需存储全部结果。

若元素是对象会怎样？ 常规拼接通常复制引用而非深拷贝；本题只有整数，不涉及对象别名问题。
