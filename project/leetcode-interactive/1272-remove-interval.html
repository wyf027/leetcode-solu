删除区间

Remove Interval

MEDIUM Array 付费题 半开区间

把一段指定范围从若干个互不相交的区间中“剪掉”，返回仍被覆盖的部分。先读清半开区间，再动手操作下方切割台。

Problem

题目转述

removeInterval(intervals, toBeRemoved)

一个实数集合可以表示为若干互不相交的半开区间之并。区间 [a, b) 包含所有满足 a ≤ x < b 的实数。

给定按起点升序排列且互不相交的 intervals，以及另一个半开区间 toBeRemoved，请从集合中移除落在 toBeRemoved 内的所有实数，并以同样的升序、互不相交半开区间形式返回余下集合。

端点提醒：右端点不属于区间。因此 [0, 2) 与 [2, 3) 不重叠，也不会产生需要额外保留的零长度区间。

函数签名

removeInterval(int[][] intervals, int[] toBeRemoved)
  • intervals：每项为 [aᵢ, bᵢ]，语义是 [aᵢ, bᵢ)。
  • toBeRemoved：长度为 2 的待删除半开区间。
  • 返回：List<List<Integer>>。
Examples

      toBeRemoved = [1,6]
输出：[[0,1],[6,7]]

Constraints

约束与输入保证

  • 1 ≤ intervals.length ≤ 10⁴
  • −10⁹ ≤ aᵢ < bᵢ ≤ 10⁹

  • toBeRemoved 也表示一个合法的半开区间 [x, y)，其中 x < y。

Solution

一次扫描，保留两侧

核心洞察

无需真的“删除”或合并。对每个原区间 [a,b)，只问两个独立问题：左侧是否有落在删除范围之外的长度？右侧是否有？最多产生两段答案。

左残段：[a, x) 当 a < x 右残段：[y, b) 当 b > y

完整过程

  1. 记待删除区间为 [x,y)。
  2. 依次读取每个 [a,b)。
  3. 若 a < x，加入 [a, min(b,x))。
  4. 若 b > y，加入 [max(a,y), b)。
  5. 严格不等号保证不会加入零长度区间。

为什么正确

固定考察一段 I=[a,b)。删除 R=[x,y) 后，I \ R 中小于 x 的部分恰为 [a,min(b,x))（若非空）；大于等于 y 的部分恰为 [max(a,y),b)（若非空）。除此之外的点都在 I∩R 中，必须删除。因此算法对每个输入区间保留且仅保留应留下的点。输入原本有序且互不相交，每段残片仍位于原段内部，按扫描顺序加入后仍然有序且互不相交，故总答案正确。

复杂度与边界

  • 时间：O(n)，每个区间只处理一次。
  • 额外空间：O(1)（不计返回结果）；结果本身为 O(n)。
  • 完全无交集：原区间会由其中一个残段公式原样加入。
  • 完全覆盖：两个条件都不成立，该段消失。
  • 端点相触：严格比较自然处理半开边界。

替代方案

可以先写出“不相交 / 左重叠 / 右重叠 / 被覆盖 / 从中间切开”五种分类，再分别处理，语义直观但分支较多。也可以把所有端点做扫描线事件，不过这会把一个线性、局部的集合差问题复杂化；在输入已经有序且互不相交时没有收益。

Java 
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> removeInterval(
            int[][] intervals, int[] toBeRemoved) {
        int x = toBeRemoved[0];
        int y = toBeRemoved[1];
        List<List<Integer>> answer = new ArrayList<>();

        for (int[] interval : intervals) {
            int a = interval[0];
            int b = interval[1];

            if (a < x) {
                int leftEnd = Math.min(b, x);
                if (a < leftEnd) {
                    answer.add(Arrays.asList(a, leftEnd));
                }
            }
            if (b > y) {
                int rightStart = Math.max(a, y);
                if (rightStart < b) {
                    answer.add(Arrays.asList(rightStart, b));
                }
            }
        }
        return answer;
    }
}

var removeInterval = function (intervals, toBeRemoved) {
    const [x, y] = toBeRemoved;
    const answer = [];

    for (const [a, b] of intervals) {
        const leftEnd = Math.min(b, x);
        if (a < leftEnd) {
            answer.push([a, leftEnd]);
        }

        const rightStart = Math.max(a, y);
        if (rightStart < b) {
            answer.push([rightStart, b]);
        }
    }

    return answer;
};

C++ 
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> removeInterval(
        vector<vector<int>>& intervals,
        vector<int>& toBeRemoved
    ) {
        const int x = toBeRemoved[0];
        const int y = toBeRemoved[1];
        vector<vector<int>> answer;

        for (const auto& interval : intervals) {
            const int a = interval[0];
            const int b = interval[1];

            const int leftEnd = min(b, x);
            if (a < leftEnd) {
                answer.push_back({a, leftEnd});
            }

            const int rightStart = max(a, y);
            if (rightStart < b) {
                answer.push_back({rightStart, b});
            }
        }
        return answer;
    }
};

常见错误

  • 把半开区间当成闭区间，错误处理相触端点。
  • 无条件加入 [a,x) 或 [y,b)，产生反向或零长度区间。
  • 只处理一个残段，漏掉删除区间位于原区间内部时的另一侧。
  • 修改原数组后继续遍历，造成跳项或顺序问题。
