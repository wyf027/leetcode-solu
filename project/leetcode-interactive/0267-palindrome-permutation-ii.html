01 · Problem

题目说明

题意

给定一个字符串 s，返回使用其中全部字符能够组成的所有不同回文排列。结果可按任意顺序返回；如果不存在满足条件的排列，则返回空列表。

“排列”意味着每个字符都必须按原有出现次数使用；“回文”意味着从左向右和从右向左读取完全相同。

官方付费题面字段为空；本页依据官方题名、函数签名、示例测试值与提示作简洁转述，不复刻长篇题面。

函数签名

generatePalindromes(s: string) -> list<string>

约束

  • 1 ≤ s.length ≤ 16
  • s 仅由小写英文字母组成
  • 结果中不得出现重复字符串

示例 1

存在解
输入
s = "aabb"
输出
["abba", "baab"]
解释
两种结果都使用全部字符，且左右镜像。

示例 2

无解
输入
s = "abc"
输出
[]
解释
三个字符的出现次数均为奇数，无法组成回文。

Complete Editorial

完整题解

核心洞察

回文两侧成对出现。因此，对每个字符，只需要把其出现次数的一半放进“左半串”；完整答案由 左半串 + 中心字符 + reverse(左半串) 唯一确定。

偶数长度回文不允许任何奇数频次；奇数长度回文恰好允许一个奇数频次字符，它必须位于中心。只要奇数频次字符超过一个，就可以立刻返回空列表。

完整过程

  1. 统计 s 中每个字符的出现次数。
  2. 记录奇数频次字符。若超过一个，返回空列表；否则它就是可选的中心字符。
  3. 把每个字符的 count / 2 份数作为左半边的可用计数。
  4. 用回溯构造长度为 n / 2 的左半串：每层尝试一个仍有剩余计数的字符，选择后减一，返回时恢复。
  5. 左半串填满时，拼接它、中心字符和它的逆序，加入结果。
使用“字符 → 剩余次数”的计数回溯，而不是对含重复字符的数组做全排列，可以从生成机制上消除重复结果。

正确性证明

必要性。

任意回文中，除中心位置外的字符都成对出现，所以最多只有一个字符的总频次为奇数。若存在中心字符，它只能是这个奇数频次字符。

完备性。

当奇数频次不超过一个时，把每个字符的一半放入左半边，再镜像到右半边，并把唯一的剩余字符放在中心，就一定使用了原字符串的全部字符并得到回文。

无重复。

每个不同左半串对应唯一完整回文。计数回溯在每层按字符种类选择，不区分相同字符的不同副本，因此每个左半串恰好生成一次。

边界情况

  • 单字符字符串：左半边为空，字符自身是唯一答案。
  • 所有字符都相同：只有一个回文排列。
  • 超过一个奇数频次：无解，直接返回空列表。
  • 存在大量重复字符：计数回溯天然去重，无需结果集合二次去重。

复杂度

令 m = n / 2，不同左半串数量为 P。

时间
O(n + P · n)
辅助空间
O(n)
结果空间
O(P · n)

最坏情况下 P = m!；输出本身就有这一数量级，无法整体避免。

替代方案

  • 排序数组 + used[]：先构造并排序半串字符，用相邻重复跳过规则生成不重复排列。通用，但状态更长。
  • next_permutation：从排序后的半串开始不断求下一个字典序排列。实现紧凑，尤其适合 C++。
  • 全串排列后筛选：会探索最多 n! 个候选，且重复严重，不推荐。

import java.util.*;

class Solution {
    public List<String> generatePalindromes(String s) {
        int[] count = new int[26];
        for (char ch : s.toCharArray()) {
            count[ch - 'a']++;
        }

        int odd = 0;
        char middle = '\0';
        int halfLength = 0;
        for (int i = 0; i < 26; i++) {
            if ((count[i] & 1) == 1) {
                odd++;
                middle = (char) ('a' + i);
            }
            count[i] /= 2;
            halfLength += count[i];
        }
        if (odd > 1) {
            return new ArrayList<>();
        }

        List<String> answer = new ArrayList<>();
        String center = odd == 1 ? String.valueOf(middle) : "";
        build(count, halfLength, new StringBuilder(), center, answer);
        return answer;
    }

    private void build(int[] count, int targetLength,
                       StringBuilder left, String center,
                       List<String> answer) {
        if (left.length() == targetLength) {
            String leftPart = left.toString();
            String rightPart = new StringBuilder(leftPart).reverse().toString();
            answer.add(leftPart + center + rightPart);
            return;
        }

        for (int i = 0; i < 26; i++) {
            if (count[i] == 0) continue;
            count[i]--;
            left.append((char) ('a' + i));
            build(count, targetLength, left, center, answer);
            left.deleteCharAt(left.length() - 1);
            count[i]++;
        }
    }
}

var generatePalindromes = function(s) {
    const count = new Array(26).fill(0);
    for (const ch of s) {
        count[ch.charCodeAt(0) - 97]++;
    }

    let odd = 0;
    let center = "";
    let halfLength = 0;
    for (let i = 0; i < 26; i++) {
        if (count[i] % 2 === 1) {
            odd++;
            center = String.fromCharCode(97 + i);
        }
        count[i] = Math.floor(count[i] / 2);
        halfLength += count[i];
    }
    if (odd > 1) return [];

    const answer = [];
    const left = [];

    function backtrack() {
        if (left.length === halfLength) {
            const leftPart = left.join("");
            answer.push(leftPart + center + [...left].reverse().join(""));
            return;
        }

        for (let i = 0; i < 26; i++) {
            if (count[i] === 0) continue;
            count[i]--;
            left.push(String.fromCharCode(97 + i));
            backtrack();
            left.pop();
            count[i]++;
        }
    }

    backtrack();
    return answer;
};
from collections import Counter
from typing import List


class Solution:
    def generatePalindromes(self, s: str) -> List[str]:
        counts = Counter(s)
        odd_chars = [ch for ch, amount in counts.items() if amount % 2 == 1]
        if len(odd_chars) > 1:
            return []

        center = odd_chars[0] if odd_chars else ""
        half_counts = {ch: amount // 2 for ch, amount in counts.items()}
        half_length = len(s) // 2
        chars = sorted(half_counts)
        left: List[str] = []
        answer: List[str] = []

        def backtrack() -> None:
            if len(left) == half_length:
                left_part = "".join(left)
                answer.append(left_part + center + left_part[::-1])
                return

            for ch in chars:
                if half_counts[ch] == 0:
                    continue
                half_counts[ch] -= 1
                left.append(ch)
                backtrack()
                left.pop()
                half_counts[ch] += 1

        backtrack()
        return answer
class Solution {
public:
    vector<string> generatePalindromes(string s) {
        array<int, 26> count{};
        for (char ch : s) {
            ++count[ch - 'a'];
        }

        int odd = 0;
        int halfLength = 0;
        string center;
        for (int i = 0; i < 26; ++i) {
            if (count[i] % 2 == 1) {
                ++odd;
                center = string(1, static_cast<char>('a' + i));
            }
            count[i] /= 2;
            halfLength += count[i];
        }
        if (odd > 1) return {};

        vector<string> answer;
        string left;
        backtrack(count, halfLength, center, left, answer);
        return answer;
    }

private:
    void backtrack(array<int, 26>& count, int targetLength,
                   const string& center, string& left,
                   vector<string>& answer) {
        if (static_cast<int>(left.size()) == targetLength) {
            string right = left;
            reverse(right.begin(), right.end());
            answer.push_back(left + center + right);
            return;
        }

        for (int i = 0; i < 26; ++i) {
            if (count[i] == 0) continue;
            --count[i];
            left.push_back(static_cast<char>('a' + i));
            backtrack(count, targetLength, center, left, answer);
            left.pop_back();
            ++count[i];
        }
    }
};

面试追问

  1. 为什么只生成半串就不会漏解？请用双射说明。
  2. 如果字符集是完整 Unicode，如何替换固定长度的 26 位数组？
  3. 结果很多时，怎样改成惰性迭代器或流式输出？
  4. 如果只要求回文排列的数量，如何用多重集合排列公式计算而不枚举？
  5. 怎样让结果严格按字典序输出？当前四份实现具有什么顺序性质？

常见错误

  • 把“至多一个奇数频次”误写成“必须恰好一个”，从而拒绝偶数长度回文。
  • 只生成左半边却忘记恢复计数，导致后续分支缺字符。
  • 对重复字符副本逐个选取，生成大量重复答案。
  • 拼接右半边时直接反转正在回溯的可变缓冲区，破坏搜索状态。
  • 复杂度只写 O(n!)，忽略实际输出数量和每个答案的构造成本。
