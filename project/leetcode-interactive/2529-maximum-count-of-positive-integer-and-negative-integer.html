正整数和负整数的最大计数

Maximum Count of Positive Integer and Negative Integer

先读题，自己判断，再展开交互推演与四语言题解。

01 / 题目

给定按非递减顺序排列的整数数组 nums，分别计算其中严格大于 0 和严格小于 0 的元素个数，返回这两个计数中的较大者。重复出现的元素也分别计数。

注意：0 既不属于正整数，也不属于负整数。

参数与返回值

maximumCount(nums: integer[]) → integer

约束

  • 1 ≤ nums.length ≤ 2000
  • -2000 ≤ nums[i] ≤ 2000
  • nums 按非递减顺序排列，允许重复值。

进阶：能否将时间复杂度降到 O(log n)？

02 / 官方示例

示例 1

输入：nums = [-2,-1,-1,1,2,3]
输出：3

负整数 3 个，正整数 3 个，较大计数为 3。

示例 2

输入：nums = [-3,-2,-1,0,0,1,2]
输出：3

负整数 3 个，正整数 2 个，两个 0 不计入，答案为 3。

示例 3

输入：nums = [5,20,66,1314]
输出：4

正整数 4 个，负整数 0 个，答案为 4。

03 / 先想一想

数组已经有序，这个条件能帮你省去哪些工作？全是 0、全是负数时，你的思路仍然适用吗？

展开后可使用逐步推演

SOLUTION / TWO BOUNDARIES

两次二分，切出三个区间

核心洞察

有序数组可分成「负数 | 零 | 正数」。令 a 为第一个 ≥ 0 的位置，b 为第一个 ≥ 1 的位置。因为元素都是整数，第一个 ≥ 1 就是第一个正数。目标值不存在时，边界为 n。

负数有 a 个，正数有 n − b 个，答案是 max(a, n − b)。零区间 [a, b) 被自然排除。

交互实验 · 边界探针

依次寻找第一个 ≥ 0、第一个 ≥ 1 的位置。绿色格子表示当前待查区间 [L, R)，金色边框标出 mid。最右侧 n 是哨兵位置，不读取元素。

遵循题目约束；长数组可在格子区域横向滚动。修改后点击应用或按 Enter。

完整过程

  1. 对目标值 t = 0，初始化半开搜索区间 [L, R) = [0, n)。
  2. 当 L < R，计算 mid = L + floor((R − L) / 2)。
  3. 若 nums[mid] < t，则 mid 及左侧都不满足，令 L = mid + 1；否则保留 mid，令 R = mid。
  4. L = R 时得到第一个 ≥ t 的位置。第一次记为 a；将 t 改为 1，重新从 [0, n) 搜索得到 b。
  5. 返回 max(a, n − b)。

以 nums = [-3,-2,-1,0,0,1,2] 为例：第一次区间依次为 [0,7) → [0,3) → [2,3) → [3,3)，得到 a = 3；第二次为 [0,7) → [4,7) → [4,5) → [5,5)，得到 b = 5。答案为 max(3, 7 − 5) = 3。

正确性证明

每次搜索维护：所有下标 < L 的元素均 < t，所有下标 ≥ R 的元素均 ≥ t。初始时两个已知区间为空，不变式成立。若 nums[mid] < t，由有序性，mid 及左边都 < t，可将 L 移到 mid + 1；否则 mid 及右边都 ≥ t，可将 R 移到 mid。不变式保持，且区间严格缩小。

终止时 L = R，该位置左边全部 < t，右边全部 ≥ t，因此它恰是所求边界，也允许为 n。t = 0 时左侧正好是负数，共 a 个；t = 1 时右侧正好是正整数，共 n − b 个。取两者最大值满足题意。

边界与复杂度

  • 全零：a = 0、b = n，答案为 0；全负：a = b = n；全正：a = b = 0。
  • 没有零：a = b；重复元素必须找第一个满足条件的位置，不能遇到相等就返回。
  • 单元素 [-1]、[0]、[1] 分别返回 1、0、1。空数组不在官方输入范围。
  • 两次二分总时间 O(log n)，额外空间 O(1)。可视化保存步骤并绘制数组的开销不属于提交算法。

替代方案

一次遍历分别累加正数与负数计数，时间 O(n)、空间 O(1)，实现直观且足够处理 n ≤ 2000，但不满足进阶的 O(log n)。Python 的 bisect_left / bisect_right、C++ 的 lower_bound / upper_bound 也可直接得到两个边界。

常见错误

  • 用 n − a 计算正数：这会把零算进去，应使用 n − b。
  • 遇到 0 就停止搜索：重复零需要找到整个零区间的两端。
  • 把 R 初始化为 n 却读取 nums[R]：n 是合法边界，但不是合法元素下标。
  • 写成 L = mid：区间只剩一个位置时可能无法收缩。

面试追问

  • 数组未排序呢？直接 O(n) 计数；为计数而排序会增加到 O(n log n)。
  • 元素改成小数呢？第二次应直接查第一个 > 0；≥ 1 的等价关系只适用于整数。
  • 多次查询不同阈值呢？每次用上下界二分得到严格小于、等于、严格大于阈值的区间长度。

Java

class Solution {
    public int maximumCount(int[] nums) {
        int neg = lowerBound(nums, 0);
        int pos = nums.length - lowerBound(nums, 1);
        return Math.max(neg, pos);
    }

    private int lowerBound(int[] nums, int target) {
        int left = 0, right = nums.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) left = mid + 1;
            else right = mid;
        }
        return left;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number}
 */
var maximumCount = function(nums) {
    function lowerBound(target) {
        let left = 0, right = nums.length;
        while (left < right) {
            const mid = left + Math.floor((right - left) / 2);
            if (nums[mid] < target) left = mid + 1;
            else right = mid;
        }
        return left;
    }
    return Math.max(lowerBound(0), nums.length - lowerBound(1));
};

Python 3

from typing import List

class Solution:
    def maximumCount(self, nums: List[int]) -> int:
        def lower_bound(target: int) -> int:
            left, right = 0, len(nums)
            while left < right:
                mid = left + (right - left) // 2
                if nums[mid] < target:
                    left = mid + 1
                else:
                    right = mid
            return left

        return max(lower_bound(0), len(nums) - lower_bound(1))

C++

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
    int lowerBound(const vector<int>& nums, int target) {
        int left = 0, right = static_cast<int>(nums.size());
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < target) left = mid + 1;
            else right = mid;
        }
        return left;
    }
public:
    int maximumCount(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        return max(lowerBound(nums, 0), n - lowerBound(nums, 1));
    }
};
