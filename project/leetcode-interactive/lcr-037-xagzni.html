LCR 037 · MEDIUM

行星碰撞

每个整数是一颗行星：绝对值表示大小，正负号表示飞行方向。只有相向而行的行星才可能相撞；相等大小会同时消失。

题意

行星沿同一直线移动，速度相同。正数向右，负数向左；任意两颗相向的行星相遇时，较小的爆炸，大小相同则两者爆炸。求所有碰撞后剩余行星的状态。

示例

asteroids = [5, 10, -5]
输出 = [5, 10]
asteroids = [8, -8]
输出 = []
asteroids = [10, 2, -5]
输出 = [10]

约束

1 ≤ asteroids.length ≤ 10⁴；−1000 ≤ asteroids[i] ≤ 1000；asteroids[i] ≠ 0。

交互实验室

输入逗号分隔的非零整数。用栈保存尚未被摧毁的行星，逐步观察每一次可能的相撞。

载入示例后开始观察。

当前栈（从左到右）

    核心洞察：栈只保留未决的右行行星

    从左向右处理。新来的右行行星不会与栈顶碰撞，直接入栈。新来的左行行星只可能与栈顶的右行行星相遇，因此不断比较栈顶和当前行星：较小者消失；若当前行星消失便停止；若大小相等，两者消失并停止。这个循环精确覆盖一颗左行行星连续撞碎多颗较小右行行星的情况。

    完整过程

    1. 创建空栈 stack，依次读取 asteroid。
    2. 只要栈顶为正数且当前值为负数，二者就相向：比较 stack.top() 与 -asteroid。
    3. 栈顶较小就弹出，当前行星继续尝试；栈顶较大则当前行星消失；相等则弹栈且当前行星消失。
    4. 若当前行星最终幸存，压入栈。扫描结束的栈即答案。

    复杂度：时间 O(n)，每颗行星至多入栈、出栈一次；额外空间 O(n)。

    可提交代码

    var asteroidCollision = function(asteroids) {
  const stack = [];
  for (const asteroid of asteroids) {
    let alive = true;
    while (alive && asteroid < 0 && stack.length && stack.at(-1) > 0) {
      const top = stack.at(-1);
      if (top < -asteroid) stack.pop();
      else {
        if (top === -asteroid) stack.pop();
        alive = false;
      }
    }
    if (alive) stack.push(asteroid);
  }
  return stack;
};

    class Solution {
    public int[] asteroidCollision(int[] asteroids) {
        Deque<Integer> stack = new ArrayDeque<>();
        for (int asteroid : asteroids) {
            boolean alive = true;
            while (alive && asteroid < 0 && !stack.isEmpty() && stack.peek() > 0) {
                if (stack.peek() < -asteroid) stack.pop();
                else { if (stack.peek() == -asteroid) stack.pop(); alive = false; }
            }
            if (alive) stack.push(asteroid);
        }
        int[] answer = new int[stack.size()];
        for (int i = answer.length - 1; i >= 0; i--) answer[i] = stack.pop();
        return answer;
    }
}

    vector<int> asteroidCollision(vector<int>& asteroids) {

            while (alive && asteroid < 0 && !stack.empty() && stack.back() > 0) {

        }

    }
