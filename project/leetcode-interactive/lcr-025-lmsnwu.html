两数相加 II

两个链表从高位到低位存放数字。不能反转链表时，用两个栈把计算顺序带回个位，再把每一位头插回答案。

题意

给定两个非空链表 l1 与 l2，每个节点保存一位数字，数字按从高位到低位排列。返回它们之和对应的链表，且不能修改输入链表。

示例

l1 = [7,2,4,3], l2 = [5,6,4]

output = [7,8,0,7]

链表头是最高位，而加法应从最低位开始。分别入栈后，从栈顶弹出即可模拟个位到高位的计算。

约束

1 ≤ l1.length, l2.length ≤ 100；每个节点值在 [0, 9]；除数字 0 本身外，链表不会以 0 开头。

交互实验室

输入以英文逗号分隔的数字（从高位到低位）。先压入两个栈，再逐步弹出、相加，并将新节点头插到答案链表。

    核心洞察

    栈的后进先出恰好把“最高位在前”的链表变成“个位先算”。每轮弹出两个栈顶（不存在则为 0），计算 sum = a + b + carry；新节点保存 sum % 10，再头插到已构建的答案前面，因此最终顺序自然恢复为高位到低位。

    完整过程

    1. 遍历两个输入链表，将每一位依次压入对应栈。
    2. 只要任一栈非空或还有进位，就弹出栈顶；空栈按 0 处理。
    3. 计算当前位与新进位，并把当前位节点头插入答案链表。
    4. 循环结束，当前头节点即为所求结果。

    边界与常见错误

    • 循环条件必须包含 carry != 0，例如 999 + 1 需要额外的最高位。
    • 新节点应头插，尾插会得到倒序结果。
    • 栈元素是原节点值，不修改输入链表，满足题目约束。

    复杂度：设两个链表长度为 m、n。时间 O(m + n)，两个栈和结果链表额外占用 O(m + n) 空间。

    可提交代码

    Java

    class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        Deque<Integer> a = new ArrayDeque<>(), b = new ArrayDeque<>();
        for (; l1 != null; l1 = l1.next) a.push(l1.val);
        for (; l2 != null; l2 = l2.next) b.push(l2.val);
        ListNode head = null; int carry = 0;
        while (!a.isEmpty() || !b.isEmpty() || carry != 0) {
            int sum = carry + (a.isEmpty() ? 0 : a.pop()) + (b.isEmpty() ? 0 : b.pop());
            head = new ListNode(sum % 10, head); carry = sum / 10;
        }
        return head;
    }
}

    class Solution:
    def addTwoNumbers(self, l1: ListNode, l2: ListNode) -> ListNode:
        a, b = [], []
        while l1:
            a.append(l1.val); l1 = l1.next
        while l2:
            b.append(l2.val); l2 = l2.next
        head = None; carry = 0
        while a or b or carry:
            total = carry + (a.pop() if a else 0) + (b.pop() if b else 0)
            head = ListNode(total % 10, head); carry = total // 10
        return head

    C++

    class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        stack<int> a, b;
        for (; l1; l1 = l1->next) a.push(l1->val);
        for (; l2; l2 = l2->next) b.push(l2->val);
        ListNode* head = nullptr; int carry = 0;
        while (!a.empty() || !b.empty() || carry) {
            int sum = carry;
            if (!a.empty()) sum += a.top(), a.pop();
            if (!b.empty()) sum += b.top(), b.pop();
            head = new ListNode(sum % 10, head); carry = sum / 10;
        }
        return head;
    }
};
