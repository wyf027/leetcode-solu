1619. 删除某些元素后的数组均值

Mean of Array After Removing Some Elements

简单 数组排序
题目任务

给定整数数组 arr，删除其中最小的 5% 与最大的 5% 元素，返回余下元素的平均值。

  • 函数签名：trimMean(arr)
  • 返回类型：double / number / float

n ÷ 20

数组长度保证是 20 的倍数，因此删除数量始终为整数。

Complete solution

排序后，保留中间 90%

核心洞察

“最小 5%”和“最大 5%”描述的是按数值排序后的两端。令 k = n / 20，排序后只需求下标区间 [k, n-k) 的平均值。

完整过程

  1. 将数组升序排序。
  2. 计算每侧删除量 k = n / 20。
  3. 累加下标 k 到 n-k-1。
  4. 用总和除以剩余数量 n - 2k。

正确性证明

引理 1：升序排序后，前 k 个元素恰好构成数组最小的 5%，后 k 个元素恰好构成最大的 5%。相同值跨越边界时，删除其中任意等值元素不会改变剩余元素的总和。

引理 2：删除这两段后，所有且仅有下标位于 [k, n-k) 的元素被保留。

结论：算法累加的正是题目要求保留的全部元素，再除以其准确数量 n-2k，所得即为修剪后的算术平均值。

边界情况

  • n = 20：每侧删 1 个。
  • 全部元素相同：结果仍是该值。
  • 边界处存在重复值：无需特别去重。
  • 最大总和可达约 10⁸，各语言实现使用安全的求和类型。

复杂度

时间 O(n log n)额外空间 O(log n)～O(n)

空间复杂度取决于语言的排序实现；若不计排序内部空间，累加本身是 O(1)。

四语言完整代码

import java.util.Arrays;

class Solution {
    public double trimMean(int[] arr) {
        Arrays.sort(arr);
        int n = arr.length;
        int k = n / 20;
        long sum = 0;

        for (int i = k; i < n - k; i++) {
            sum += arr[i];
        }

        return (double) sum / (n - 2 * k);
    }
}

class Solution:

        n = len(arr)

替代方案

计数法：由于 arr[i] ≤ 10⁵，可以构建频次数组，从小到大跳过前 k 个、从大到小跳过后 k 个，再累加中间部分。时间为 O(n + V)、空间为 O(V)，其中 V = 10⁵。在本题 n ≤ 1000 时，排序更直接。

选择算法：两次快速选择可定位两侧边界，期望 O(n)，但重复值和边界计数会使实现明显复杂。

常见错误

  • 按原数组的首尾删除，而不是按数值大小删除。
  • 使用 Math.floor(n * 0.05) 后忽略了本题可直接精确计算 n / 20；浮点比例在一般场景还可能带来精度隐患。
  • 循环右边界写成 i ≤ n-k，多计一个元素。
  • 分母仍使用 n，正确分母是 n-2k。
  • Java / C++ 先做整数除法再转浮点，导致小数部分被截断。
