01 · Briefing

题意

给定单链表 head 和整数 x，重新排列节点，使所有值小于 x 的节点位于值大于或等于 x 的节点之前。两个分区内部都必须保持节点原来的相对顺序。

  • 节点数范围：[0, 200]
  • -100 <= Node.val <= 100
  • -200 <= x <= 200

官方样例 1

MAIN
输入
head = [1,4,3,2,5,2], x = 3
输出
[1,2,2,4,3,5]

官方样例 2

SHORT
输入
head = [2,1], x = 2
输出
[1,2]

04 · Sealed answer

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码均封存在这里。

Core insight

核心洞察

建立两条链：small 收集小于 x 的节点，large 收集其余节点。每次都把当前节点追加到对应尾部，因此两条链内部天然保持原相对顺序。扫描后将两条链连接即可。

Invariant

循环不变量

处理前 i 个节点后，左链恰好按原顺序包含其中所有 value < x 的节点；右链同理包含所有 value >= x 的节点；尚未处理部分仍由遍历指针访问。

完整过程

  1. 01

    创建 smallDummy 与 largeDummy，尾指针分别指向它们。

  2. 02

    从头扫描；小于 x 就追加到左链，否则追加到右链。

  3. 03

    令 largeTail.next = null，切断原链残留连接，防止成环。

  4. 04

    令 smallTail.next = largeDummy.next，返回 smallDummy.next。

边界

  • 空链表：两个分区均为空，直接返回 null。
  • 全在同侧：另一条链为空，拼接仍成立。
  • 值等于 x：必须进入右链。
  • 重复值：节点身份和相对顺序都不能丢。

复杂度

时间
O(n)

O(1)

1

替代方案取舍

把值写入数组再重建链表更直观，但需要 O(n) 空间且可能破坏节点身份。原链内频繁插入容易写错指针和稳定性。双虚拟头结点最适合面试：结构清晰、常数空间、证明简洁。

面试追问

为什么是稳定分区？

因为节点只被按扫描顺序追加到各自链尾，从不插到已有节点前面。

为何最后要断开右链尾？

节点仍保留原来的 next；若不置空，右链尾可能回指已被接入左链的旧节点并成环。

虚拟头结点的价值？

统一空链与非空链追加逻辑，避免为第一个节点写分支。

常见错误

  • 把 value == x 错分到左链。
  • 头插节点，导致分区内部顺序反转。
  • 忘记 largeTail.next = null，留下旧边甚至形成环。
  • 先拼接再继续扫描，覆盖遍历路径。

四语言可提交代码

class Solution {
    public ListNode partition(ListNode head, int x) {
        ListNode smallDummy = new ListNode(0);
        ListNode largeDummy = new ListNode(0);
        ListNode smallTail = smallDummy;
        ListNode largeTail = largeDummy;

        while (head != null) {
            if (head.val < x) {
                smallTail.next = head;
                smallTail = smallTail.next;
            } else {
                largeTail.next = head;
                largeTail = largeTail.next;
            }
            head = head.next;
        }

        largeTail.next = null;
        smallTail.next = largeDummy.next;
        return smallDummy.next;
    }
}
