困难数组栈单调栈会员题

题目

给定一个整数数组 nums。如果一个非空连续子数组的最左侧元素不大于该子数组中的其他所有元素，那么它是“有效”的。返回所有有效子数组的数量。

对区间 [i, j]：nums[i] ≤ nums[k]，其中 i ≤ k ≤ j

函数签名

int validSubarrays(int[] nums)

约束

  • 1 ≤ nums.length ≤ 50,000
  • 0 ≤ nums[i] ≤ 100,000

官方示例

示例 1
输入：nums = [1,4,2,5,3]
输出：11

示例 2
输入：nums = [3,2,1]
输出：3

示例 3
输入：nums = [2,2,2]
输出：6

示例 1 中，以 1 开头的 5 个前缀都有效；相等元素不会破坏有效性。

Solution

单调递增栈：每轮直接计数

核心洞察

扫描到 x 时，栈中保存的每个元素都能作为一个有效子数组的左端点，并延伸到当前位置。若栈顶大于 x，它遇到了第一个更小值，必须永久弹出。弹出后将 x 入栈；此时栈的长度就是“以当前位置结尾”的有效子数组数量。

answer += stack.size()

完整过程

  1. 准备一个从栈底到栈顶单调不降的栈。
  2. 遍历每个 x，反复弹出所有严格大于 x 的栈顶。
  3. 将 x 入栈；相等值保留，因为“不大于”允许相等。
  4. 把当前栈大小累加到答案。

正确性证明

不变式：处理位置 j 后，栈中的元素与所有满足 nums[i] ≤ nums[k]（i ≤ k ≤ j）的起点 i 一一对应。

当 nums[i] > nums[j] 时，区间 [i,j] 无效，且任何继续向右扩展的区间仍包含这个更小的 nums[j]，所以该起点可永久弹出。未弹出的起点均不大于扫描至今的每个元素，故与 j 构成有效子数组；新元素自身也形成长度为 1 的有效子数组。于是栈大小恰为以 j 结尾的有效子数组数。对所有 j 累加即得到全部答案，且每个子数组只按其右端点计算一次。

边界与复杂度

  • 单元素：答案为 1。
  • 严格递增：答案为 n(n+1)/2。
  • 严格递减：每轮栈大小为 1，答案为 n。
  • 重复值：不能用 >= 弹栈。

时间：O(n)，每个元素至多入栈、出栈一次。
空间：O(n)。

替代方案与面试追问

可为每个起点寻找右侧第一个严格更小元素，其距离就是该起点的贡献；同样可用单调栈完成。官方提示还给出 RMQ + 二分，复杂度通常为 O(n log n)。

追问

  • 若定义改为左端点严格小于其余元素，如何处理相等值？
  • 怎样改成从右向左计算每个起点的贡献？
  • 答案类型为何用 64 位更稳妥？

常见错误

  • 把弹栈条件写成 top >= x，错误删除相等起点。
  • 累加 1 而非栈大小，漏掉多个左端点。
  • 只保存不同的值，丢失重复元素各自代表的起点。
  • 把“有效”误读成左端点是最大值。

四语言完整代码

class Solution {
    public int validSubarrays(int[] nums) {
        int[] stack = new int[nums.length];
        int top = 0;
        long answer = 0;
        for (int x : nums) {
            while (top > 0 && stack[top - 1] > x) top--;
            stack[top++] = x;
            answer += top;
        }
        return (int) answer;
    }
}

var validSubarrays = function(nums) {
    const stack = [];
    let answer = 0;
    for (const x of nums) {
        while (stack.length && stack[stack.length - 1] > x) {
            stack.pop();
        }
        stack.push(x);
        answer += stack.length;
    }
    return answer;
};
from typing import List

class Solution:
    def validSubarrays(self, nums: List[int]) -> int:
        stack = []
        answer = 0
        for x in nums:
            while stack and stack[-1] > x:
                stack.pop()
            stack.append(x)
            answer += len(stack)
        return answer
class Solution {
public:
    int validSubarrays(vector<int>& nums) {
        vector<int> stack;
        long long answer = 0;
        for (int x : nums) {
            while (!stack.empty() && stack.back() > x) {
                stack.pop_back();
            }
            stack.push_back(x);
            answer += stack.size();
        }
        return static_cast<int>(answer);
    }
};
