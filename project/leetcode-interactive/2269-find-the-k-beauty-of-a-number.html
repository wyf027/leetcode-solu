2269. 找到一个数字的 K 美丽值

Find the K-Beauty of a Number

从一串数字里，发现满足条件的连续片段。

官方题目 ↗先读题，再展开演示与题解

01 / PROBLEM

题意

给定正整数 num 和整数 k，把 num 看成十进制字符串。统计其中长度恰好为 k、且转成整数后能够整除 num 的连续子字符串数量，返回这个数量。

  • 子字符串必须连续，不能跳过中间的数字。
  • 允许前导零，例如 "04" 对应整数 4。
  • 数值为 0 的片段不满足条件，不能把零当作除数。
  • 按出现位置计数：两个位置上的相同片段分别计算。

参数与约束

divisorSubstrings(num, k) → integer

  • 1 ≤ num ≤ 10⁹
  • 1 ≤ k ≤ n，其中 n 是 num 的十进制位数。

官方示例

示例 1

输入：num = 240, k = 2
输出：2

长度为 2 的片段是 "24" 和 "40"；24 和 40 都能整除 240，所以计数为 2。

示例 2

输入：num = 430043, k = 2
输出：2

依次得到 "43"、"30"、"00"、"04"、"43"。两个 43 均符合条件；30 和 4 不能整除原数，0 被排除。答案为 2。

题解 · 固定长度的数字窗口

核心洞察

每个候选片段都由起点唯一确定。把长度为 k 的窗口从左向右移动一位，就能遍历所有候选。窗口原文保留前导零，转换后的整数用来判断整除；只累加位置，不去重。

起点（从 0 开始）片段数值判断累计

完整过程

  1. 令 s = String(num)，n = s.length，答案从 0 开始。
  2. 枚举起点 i = 0 … n − k，提取左闭右开的 s[i : i + k]。
  3. 把片段按十进制解析为整数 x。若 x = 0，直接跳过。
  4. 否则检查 num % x === 0，成立则答案增加 1。
  5. 窗口处理完毕后返回答案。

正确性说明

不变式：处理起点 i 之前，计数恰好等于起点小于 i 的所有合格窗口数量。开始时没有处理窗口，计数为 0，成立。每轮只检查起点 i 的唯一长度 k 片段；当且仅当它非零且整除 num 时加 1，因此处理后不变式仍成立。起点从 0 到 n − k，覆盖每个合法片段且没有重复处理同一位置，所以循环结束时计数就是 k 美丽值。

边界与复杂度

  • k = n：唯一片段就是正整数 num 自身，答案为 1。
  • k = 1：逐位判断，数字 0 仍要跳过。
  • 前导零不影响数值；数值相同而位置不同的片段仍分别计数。
  • 令 n 为位数。下列代码每个窗口截取与解析花费 O(k)，总时间 O(n + (n − k + 1)k)，可简写为 O(nk)。
  • 存储完整数字字符串 O(n)，临时片段 O(k)，额外空间合计 O(n)。本题 n ≤ 10。
  • 所有窗口值 ≤ 10⁹，Java/C++ 的 32 位有符号整数足够；JavaScript Number 在此范围内可精确表示整数。

替代方案

可以维护数值窗口：令 base = 10^(k − 1)，窗口右移时使用 x = (x % base) * 10 + nextDigit。处理首个窗口后，每次更新 O(1)，总时间 O(n)；若仍存字符串，空间 O(n)。需要额外小心窗口长度和零。也可以从右向左用取模、整除枚举窗口，实现 O(1) 额外空间，但必须严格枚举 n − k + 1 次以保留左侧含零的位置。若使用 10^k，k = 10 时应使用 64 位整数。

常见错误

  • 直接计算 num % 0；应先判断窗口值非零。
  • 把片段放进 Set，丢失不同位置的重复贡献。
  • 循环使用 i < n − k，漏掉最后一个窗口。
  • 把 x % num 当成判断式，颠倒被除数与除数。
  • 使用自动推断进制的解析方式，误读前导零。这里统一按十进制转换。

面试追问

  • 为什么称为固定窗口？窗口长度始终为 k，每轮左右端点同时右移一位。
  • 能省去重复解析吗？可以，使用上面的数值窗口递推。
  • num 超过机器整数范围呢？应以字符串接收，配合大整数或逐位取模；此时需重新分析大整数运算的成本。
  • 要求返回片段位置呢？判断成功时记录起点 i，额外结果空间与命中数成正比。

Java

class Solution {
    public int divisorSubstrings(int num, int k) {
        String s = Integer.toString(num);
        int answer = 0;
        for (int i = 0; i + k <= s.length(); i++) {
            int x = Integer.parseInt(s.substring(i, i + k));
            if (x != 0 && num % x == 0) {
                answer++;
            }
        }
        return answer;
    }
}

    let answer = 0;

        const x = Number(s.slice(i, i + k));

C++

#include <string>
using namespace std;

class Solution {
public:
    int divisorSubstrings(int num, int k) {
        string s = to_string(num);
        int answer = 0;
        int n = static_cast<int>(s.size());
        for (int i = 0; i + k <= n; ++i) {
            int x = stoi(s.substr(i, k));
            if (x != 0 && num % x == 0) {
                ++answer;
            }
        }
        return answer;
    }
};
