Distance Between Bus Stops

难度：简单 非付费题 核心结构：环形数组

Problem

题目描述

一条环形公交线路有 n 个站点，编号为 0 到 n - 1。数组 distance 描述相邻站点间的距离：distance[i] 是站点 i 到站点 (i + 1) % n 的距离。

公交车可以沿顺时针或逆时针方向行驶。给定 start 与 destination，返回两站之间可达路线的最短距离。

函数签名

distanceBetweenBusStops(distance: integer[], start: integer, destination: integer) -> integer

Limits

约束

  • 1 <= n <= 10^4
  • distance.length == n
  • 0 <= start, destination < n
  • 0 <= distance[i] <= 10^4

Core insight

核心洞察

环上任意两站之间恰好有两条互补路径。先令 start <= destination，则从 start 沿编号递增方向走到 destination 的距离是区间和 forward；另一条路一定覆盖剩余路段，所以距离是 total - forward。答案就是二者较小值。

完整过程

  1. 统一端点顺序
    若 start > destination，交换二者，便于表达连续区间。
  2. 扫描整个数组
    累计所有路段得到 total；同时累计下标位于 [start, destination) 的路段得到 forward。
  3. 得到互补路径
    反向路径距离为 total - forward。
  4. 取最短者
    返回 min(forward, total - forward)。

正确性证明

环上的所有路段被两条起终点路径恰好划分为互不重叠的两部分。算法计算其中编号递增的一部分为 forward，剩余部分自然是 total - forward。任何从起点到终点且不重复绕圈的路线只能是这两条之一；额外绕圈只会增加非负距离。因此二者最小值即全局最短距离。

复杂度

时间复杂度 O(n)：扫描一次数组。空间复杂度 O(1)：只维护常数个累计变量。

边界情况

  • start == destination 时区间和为 0，答案为 0。
  • 某些路段可以为 0，互补关系仍成立。
  • 起点编号大于终点编号时先交换，不改变两条路径的长度集合。
  • 使用足够大的整数类型保存总和。

替代方案

也可以分别模拟顺时针和逆时针：从起点沿两个方向移动直到终点，各自累计。它同样是 O(n)，但下标取模与停止条件更容易写错。若要回答大量查询，可预处理前缀和，把每次区间查询降到 O(1)。

常见错误

  • 把区间写成闭区间，误加了从终点离开的路段。
  • 只计算一个方向，忘记与补集比较。
  • start > destination 时仍直接循环连续区间。
  • 使用 distance[destination] 作为到达终点前的最后一段。

面试追问

大量查询怎么办？

构造前缀和；任意两点的顺向区间和可在常数时间得到。

距离会动态修改呢？

用树状数组或线段树维护区间和与总和，使修改和查询都为对数复杂度。

为什么不必 BFS？

图固定是一条环，每个点度数为 2，两条简单路径可直接由区间和描述。

class Solution {
    public int distanceBetweenBusStops(int[] distance, int start, int destination) {
        if (start > destination) {
            int temp = start;
            start = destination;
            destination = temp;
        }

        int total = 0;
        int forward = 0;
        for (int i = 0; i < distance.length; i++) {
            total += distance[i];
            if (i >= start && i < destination) {
                forward += distance[i];
            }
        }
        return Math.min(forward, total - forward);
    }
}

class Solution:
    def distanceBetweenBusStops(
        self, distance: List[int], start: int, destination: int
    ) -> int:
        if start > destination:
            start, destination = destination, start

        total = sum(distance)
        forward = sum(distance[start:destination])
        return min(forward, total - forward)
