题目重述

给定字符串 expression，以及由 evalvars[i] → evalints[i] 组成的变量求值映射。先把映射中出现的变量替换成整数，再按括号、乘法、加减法的通常优先级化简，返回表示结果多项式的字符串列表。

  • 表达式的块可以是括号表达式、变量或非负整数；变量仅由小写字母组成，可以有多个字母。
  • 同一单项式中的自由变量按字典序排列，重复变量保留，因此 a*a*b 的次数为 3。
  • 输出先按次数从高到低；次数相同时，忽略系数后按单项式字典序排列。
  • 非零系数必须输出，即使系数为 1；常数项只输出系数。系数为 0 的项全部省略，零多项式输出空列表。
函数形式： basicCalculatorIV(expression, evalvars, evalints) → List<String>。题目保证表达式有效，所有中间结果都在 32 位有符号整数范围内。

约束

  • 1 ≤ expression.length ≤ 250
  • expression 仅含小写字母、数字、+、-、*、括号和空格。
  • 表达式无首尾空格，所有记号之间由一个空格分隔。
  • 0 ≤ evalvars.length ≤ 100
  • 1 ≤ evalvars[i].length ≤ 20，且仅含小写字母。
  • evalints.length == evalvars.length，-100 ≤ evalints[i] ≤ 100。

HARD

核心洞察

表示单项式 → 系数

把已排序变量元组作为键：(a,a,b) 表示 a*a*b，空元组表示常数。

运算多项式封装

加减法按键合并系数；乘法枚举两侧项，拼接并重新排序变量键。

解析优先级分层

expression → term → factor 天然实现加减、乘法、括号的优先级。

完整过程

01
建立求值表。 将 evalvars[i] 映射到 evalints[i]。解析变量原子时，若命中就立即变成常数多项式，否则保留为自由变量。
02
词法切分。 跳过空格，把连续字母或数字读成一个记号，把 + - * ( ) 读成单字符记号，兼容括号紧贴变量的写法。
03
递归下降。 parseExpression 循环处理加减，内部调用 parseTerm 处理连续乘法，最底层 parseFactor 处理数字、变量和括号。
04
同步计算。 解析器不构造 AST；每识别一个运算符，就直接调用多项式的加、减或乘，将局部表达式归约为新映射。
05
过滤与排序。 删除零系数项，按变量个数降序、变量序列字典序升序排列，再把系数与变量用星号连接。

正确性说明

表示不变式：每个多项式映射中，键是按字典序排列的自由变量序列，值是该单项式的总系数。常数使用空键。

运算保持不变式：加减法只合并相同键，正好对应同类项合并；乘法枚举全部项对、系数相乘、变量序列合并排序，正好展开分配律，并把相同乘积归到同一键。因此三种操作都得到与原运算等价的规范多项式。

解析正确：factor 正确处理原子和括号；term 只在其上组合乘法；expression 最后组合加减。由递归结构和运算优先级归纳，返回多项式与整个输入表达式等价。最终排序恰好遵循题目的次数与字典序规则，所以输出格式正确。

边界处理

  • 同类项抵消到 0：从映射中移除，最终可能返回 []。
  • 所有变量均被赋值：所有键都为空，结果至多只有一个常数项。
  • 变量重复相乘：键保留重复元素，确保次数计算准确。
  • 负数只由减法或求值映射产生；原始数字块仍按非负整数解析。
  • 括号可多层嵌套，parseFactor 在右括号前递归完成内部表达式。

复杂度

时间与中间多项式规模相关

设运算过程中左右多项式最多含 P 项，乘法一次最坏枚举 O(P²) 项对；变量键合并还需排序。整体不能只用表达式长度给出紧致多项式界，因为展开项数可能组合爆炸。

空间O(P · D + N)

D 为最大单项式次数，映射存储至多 P 个变量键；N 为记号数和递归解析开销。

替代方案

运算符栈 + 操作数栈：可以用类似 Shunting-yard 的方式按优先级归约多项式，避免递归；好处是显式控制栈深，代价是括号和归约条件更容易写错。也可以先构造 AST 再求值，结构更适合做常量折叠、打印或其他优化，但本题只需一次求值，递归下降时直接计算更简洁。

面试追问

  1. 如何支持除法？ 普通多项式对除法不封闭，需要限制为整除、引入有理式，或保留 AST。
  2. 如何减少乘法中间项？ 乘法生成每个项对时立即累加到哈希表，并及时删除零系数项。
  3. 为何不用字符串直接表示单项式？ 可以，但结构化变量序列更容易计算次数、排序和无歧义合并。
  4. 怎样支持幂运算？ 在语法中增加高于乘法的幂层，并用快速幂反复执行多项式乘法。

常见错误

  • 把输出整体按字符串排序，遗漏“次数优先、字典序次之”。
  • 乘法拼接变量后未排序，导致 a*b 和 b*a 无法合并。
  • 漏打印非零项的系数 1，或错误保留系数为 0 的项。
  • 用空格简单切分表达式，无法正确处理 (e、8) 这类括号相邻情况。
  • 让加减和乘法处于同一解析层，破坏运算优先级。

import java.util.*;

class Solution {
    static class Poly {
        Map<String, Long> terms = new HashMap<>();

        static Poly constant(long value) {
            Poly p = new Poly();
            if (value != 0) p.terms.put("", value);
            return p;
        }

        static Poly variable(String name) {
            Poly p = new Poly();
            p.terms.put(name, 1L);
            return p;
        }

        void addTo(String key, long value) {
            long next = terms.getOrDefault(key, 0L) + value;
            if (next == 0) terms.remove(key);
            else terms.put(key, next);
        }

        Poly add(Poly other, long sign) {
            Poly result = new Poly();
            result.terms.putAll(terms);
            for (Map.Entry<String, Long> e : other.terms.entrySet()) {
                result.addTo(e.getKey(), sign * e.getValue());
            }
            return result;
        }

        Poly multiply(Poly other) {
            Poly result = new Poly();
            for (Map.Entry<String, Long> a : terms.entrySet()) {
                for (Map.Entry<String, Long> b : other.terms.entrySet()) {
                    List<String> vars = new ArrayList<>();
                    if (!a.getKey().isEmpty()) vars.addAll(Arrays.asList(a.getKey().split("\\*")));
                    if (!b.getKey().isEmpty()) vars.addAll(Arrays.asList(b.getKey().split("\\*")));
                    Collections.sort(vars);
                    result.addTo(String.join("*", vars), a.getValue() * b.getValue());
                }
            }
            return result;
        }

        List<String> format() {
            List<String> keys = new ArrayList<>(terms.keySet());
            keys.sort((a, b) -> {
                int da = a.isEmpty() ? 0 : a.split("\\*").length;
                int db = b.isEmpty() ? 0 : b.split("\\*").length;
                if (da != db) return Integer.compare(db, da);
                return a.compareTo(b);
            });
            List<String> answer = new ArrayList<>();
            for (String key : keys) {
                long coefficient = terms.get(key);
                answer.add(key.isEmpty() ? Long.toString(coefficient)
                                         : coefficient + "*" + key);
            }
            return answer;
        }
    }

    private List<String> tokens;
    private int index;
    private Map<String, Integer> values;

    public List<String> basicCalculatorIV(String expression,
                                           String[] evalvars,
                                           int[] evalints) {
        values = new HashMap<>();
        for (int i = 0; i < evalvars.length; i++) values.put(evalvars[i], evalints[i]);
        tokens = tokenize(expression);
        index = 0;
        return parseExpression().format();
    }

    private List<String> tokenize(String s) {
        List<String> out = new ArrayList<>();
        for (int i = 0; i < s.length();) {
            char c = s.charAt(i);
            if (c == ' ') { i++; continue; }
            if (Character.isLetterOrDigit(c)) {
                int j = i;
                while (j < s.length() && Character.isLetterOrDigit(s.charAt(j))) j++;
                out.add(s.substring(i, j));
                i = j;
            } else {
                out.add(String.valueOf(c));
                i++;
            }
        }
        return out;
    }

    private Poly parseExpression() {
        Poly left = parseTerm();
        while (index < tokens.size() &&
               (tokens.get(index).equals("+") || tokens.get(index).equals("-"))) {
            String op = tokens.get(index++);
            Poly right = parseTerm();
            left = left.add(right, op.equals("+") ? 1 : -1);
        }
        return left;
    }

    private Poly parseTerm() {
        Poly left = parseFactor();
        while (index < tokens.size() && tokens.get(index).equals("*")) {
            index++;
            left = left.multiply(parseFactor());
        }
        return left;
    }

    private Poly parseFactor() {
        String token = tokens.get(index++);
        if (token.equals("(")) {
            Poly inside = parseExpression();
            index++; // ')'
            return inside;
        }
        if (Character.isDigit(token.charAt(0))) return Poly.constant(Long.parseLong(token));
        if (values.containsKey(token)) return Poly.constant(values.get(token));
        return Poly.variable(token);
    }
}

JavaScript

/**
 * @param {string} expression
 * @param {string[]} evalvars
 * @param {number[]} evalints
 * @return {string[]}
 */
var basicCalculatorIV = function (expression, evalvars, evalints) {
    const values = new Map(evalvars.map((name, i) => [name, evalints[i]]));
    const tokens = expression.match(/[a-z]+|\d+|[+\-*()]/g) || [];
    let index = 0;

    const addTo = (poly, key, value) => {
        const next = (poly.get(key) || 0) + value;
        if (next === 0) poly.delete(key);
        else poly.set(key, next);
    };

    const add = (left, right, sign) => {
        const result = new Map(left);
        for (const [key, value] of right) addTo(result, key, sign * value);
        return result;
    };

    const multiply = (left, right) => {
        const result = new Map();
        for (const [keyA, valueA] of left) {
            for (const [keyB, valueB] of right) {
                const vars = [];
                if (keyA) vars.push(...keyA.split("*"));
                if (keyB) vars.push(...keyB.split("*"));
                vars.sort();
                addTo(result, vars.join("*"), valueA * valueB);
            }
        }
        return result;
    };

    const atom = (token) => {
        if (/^\d+$/.test(token)) return new Map([["", Number(token)]]);
        if (values.has(token)) {
            const value = values.get(token);
            return value === 0 ? new Map() : new Map([["", value]]);
        }
        return new Map([[token, 1]]);
    };

    const parseFactor = () => {
        const token = tokens[index++];
        if (token === "(") {
            const inside = parseExpression();
            index++; // ')'
            return inside;
        }
        return atom(token);
    };

    const parseTerm = () => {
        let left = parseFactor();
        while (tokens[index] === "*") {
            index++;
            left = multiply(left, parseFactor());
        }
        return left;
    };

    const parseExpression = () => {
        let left = parseTerm();
        while (tokens[index] === "+" || tokens[index] === "-") {
            const op = tokens[index++];
            left = add(left, parseTerm(), op === "+" ? 1 : -1);
        }
        return left;
    };

    const poly = parseExpression();
    const keys = [...poly.keys()].sort((a, b) => {
        const degreeA = a ? a.split("*").length : 0;
        const degreeB = b ? b.split("*").length : 0;
        return degreeB - degreeA || a.localeCompare(b);
    });
    return keys.map((key) => key ? `${poly.get(key)}*${key}` : String(poly.get(key)));
};

Python 3

from collections import defaultdict
from typing import Dict, List, Tuple
import re


class Solution:
    def basicCalculatorIV(
        self, expression: str, evalvars: List[str], evalints: List[int]
    ) -> List[str]:
        values = dict(zip(evalvars, evalints))
        tokens = re.findall(r"[a-z]+|\d+|[+\-*()]", expression)
        index = 0

        # A polynomial maps a sorted tuple of variables to its coefficient.
        Poly = Dict[Tuple[str, ...], int]

        def clean(poly: Poly) -> Poly:
            return {key: value for key, value in poly.items() if value != 0}

        def add(left: Poly, right: Poly, sign: int) -> Poly:
            result = defaultdict(int, left)
            for key, value in right.items():
                result[key] += sign * value
            return clean(result)

        def multiply(left: Poly, right: Poly) -> Poly:
            result = defaultdict(int)
            for key_a, value_a in left.items():
                for key_b, value_b in right.items():
                    key = tuple(sorted(key_a + key_b))
                    result[key] += value_a * value_b
            return clean(result)

        def parse_factor() -> Poly:
            nonlocal index
            token = tokens[index]
            index += 1
            if token == "(":
                inside = parse_expression()
                index += 1  # ')'
                return inside
            if token.isdigit():
                value = int(token)
                return {(): value} if value else {}
            if token in values:
                value = values[token]
                return {(): value} if value else {}
            return {(token,): 1}

        def parse_term() -> Poly:
            nonlocal index
            left = parse_factor()
            while index < len(tokens) and tokens[index] == "*":
                index += 1
                left = multiply(left, parse_factor())
            return left

        def parse_expression() -> Poly:
            nonlocal index
            left = parse_term()
            while index < len(tokens) and tokens[index] in ("+", "-"):
                operator = tokens[index]
                index += 1
                left = add(left, parse_term(), 1 if operator == "+" else -1)
            return left

        polynomial = parse_expression()
        ordered = sorted(polynomial, key=lambda key: (-len(key), key))
        answer = []
        for key in ordered:
            coefficient = polynomial[key]
            answer.append("*".join((str(coefficient), *key)) if key else str(coefficient))
        return answer

C++17

class Solution {
    using Key = vector<string>;
    using Poly = map<Key, long long>;

    vector<string> tokens;
    int index = 0;
    unordered_map<string, int> values;

    void addTo(Poly& poly, const Key& key, long long value) {
        poly[key] += value;
        if (poly[key] == 0) poly.erase(key);
    }

    Poly add(const Poly& left, const Poly& right, int sign) {
        Poly result = left;
        for (const auto& [key, value] : right) addTo(result, key, sign * value);
        return result;
    }

    Poly multiply(const Poly& left, const Poly& right) {
        Poly result;
        for (const auto& [keyA, valueA] : left) {
            for (const auto& [keyB, valueB] : right) {
                Key key = keyA;
                key.insert(key.end(), keyB.begin(), keyB.end());
                sort(key.begin(), key.end());
                addTo(result, key, valueA * valueB);
            }
        }
        return result;
    }

    Poly atom(const string& token) {
        if (isdigit(token[0])) {
            long long value = stoll(token);
            return value == 0 ? Poly{} : Poly{{Key{}, value}};
        }
        if (values.count(token)) {
            long long value = values[token];
            return value == 0 ? Poly{} : Poly{{Key{}, value}};
        }
        return Poly{{Key{token}, 1}};
    }

    Poly parseFactor() {
        string token = tokens[index++];
        if (token == "(") {
            Poly inside = parseExpression();
            index++;  // ')'
            return inside;
        }
        return atom(token);
    }

    Poly parseTerm() {
        Poly left = parseFactor();
        while (index < (int)tokens.size() && tokens[index] == "*") {
            index++;
            left = multiply(left, parseFactor());
        }
        return left;
    }

    Poly parseExpression() {
        Poly left = parseTerm();
        while (index < (int)tokens.size() &&
               (tokens[index] == "+" || tokens[index] == "-")) {
            string op = tokens[index++];
            left = add(left, parseTerm(), op == "+" ? 1 : -1);
        }
        return left;
    }

    vector<string> tokenize(const string& expression) {
        vector<string> out;
        for (int i = 0; i < (int)expression.size();) {
            if (expression[i] == ' ') { i++; continue; }
            if (isalnum(expression[i])) {
                int j = i;
                while (j < (int)expression.size() && isalnum(expression[j])) j++;
                out.push_back(expression.substr(i, j - i));
                i = j;
            } else {
                out.push_back(string(1, expression[i++]));
            }
        }
        return out;
    }

public:
    vector<string> basicCalculatorIV(string expression,
                                      vector<string>& evalvars,
                                      vector<int>& evalints) {
        for (int i = 0; i < (int)evalvars.size(); i++) values[evalvars[i]] = evalints[i];
        tokens = tokenize(expression);
        index = 0;
        Poly polynomial = parseExpression();

        vector<pair<Key, long long>> items(polynomial.begin(), polynomial.end());
        sort(items.begin(), items.end(), [](const auto& a, const auto& b) {
            if (a.first.size() != b.first.size()) return a.first.size() > b.first.size();
            return a.first < b.first;
        });

        vector<string> answer;
        for (const auto& [key, coefficient] : items) {
            string term = to_string(coefficient);
            for (const string& variable : key) term += "*" + variable;
            answer.push_back(term);
        }
        return answer;
    }
};
