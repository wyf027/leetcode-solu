逆波兰表达式求值 栈式计算台

数字入栈，运算符弹出右、左操作数并计算，再把结果压回栈顶；后缀表达式因此无需括号。

任务边界

输入字符串数组 tokens，长度 1～10⁴；数字范围 [-200,200]，运算符为 + - * /，除法向零截断。

Problem / 题意

后缀表达式天然匹配栈

给定合法逆波兰表达式 tokens。数字直接入栈；遇到运算符时先弹出的数是右操作数 b，后弹出的是左操作数 a，计算 a op b 后压回。最后栈中唯一元素就是答案。

官方示例 1
tokens = ["2","1","+","3","*"]

输出：9

官方示例 2
tokens = ["4","13","5","/","+"]

输出：6

官方示例 3
tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]

输出：22

核心洞察

运算符消费最近两个结果

后缀表达式已经编码运算优先级。栈保存尚未被运算符消费的子表达式结果；运算符到来时按 b、a 顺序弹栈，计算 a op b，避免减法与除法次序颠倒。

完整过程

  1. 创建空栈，从左到右遍历 tokens。
  2. 整数 token 解析后压栈。
  3. 运算符依次弹出 b、a，计算 a op b。
  4. 结果压回栈；扫描结束返回栈顶。

边界与复杂度

  • 单个数字直接成为最终答案。
  • 整数除法必须向零截断，负数尤其容易写错。
  • 时间 O(n)，空间 O(n)。

替代方案取舍

可以递归构造表达式树，但需要额外解析状态；也可原地复用 tokens 前缀模拟栈。显式整数栈最清晰、最适合面试。

常见错误

  • 把先弹出的 b 当作左操作数。
  • 用 floor 处理负数除法，而不是向零截断。
  • 把 "-11" 误判成减号而不是整数。
  • 运算后忘记把结果重新压栈。

面试追问

为什么不需要括号？运算符位置已经唯一确定消费顺序。
为什么先弹 b？栈顶是更晚出现的右操作数。
JavaScript 如何截断？使用 Math.trunc(a / b)。 
class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();
        for (String token : tokens) {
            if (!"+-*/".contains(token) || token.length() > 1) {
                stack.push(Integer.parseInt(token));
                continue;
            }
            int b = stack.pop(), a = stack.pop();
            switch (token) {
                case "+" -> stack.push(a + b);
                case "-" -> stack.push(a - b);
                case "*" -> stack.push(a * b);
                default -> stack.push(a / b);
            }
        }
        return stack.pop();
    }
}
var evalRPN = function (tokens) {
  const stack = [];
  for (const token of tokens) {
    if (!["+", "-", "*", "/"].includes(token)) {
      stack.push(Number(token));
      continue;
    }
    const b = stack.pop();
    const a = stack.pop();
    if (token === "+") stack.push(a + b);
    else if (token === "-") stack.push(a - b);
    else if (token === "*") stack.push(a * b);
    else stack.push(Math.trunc(a / b));
  }
  return stack.pop();
};

class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        vector<int> stack;
        for (const string& token : tokens) {
            if (token.size() > 1 || isdigit(token[0])) {
                stack.push_back(stoi(token));
                continue;
            }
            int b = stack.back(); stack.pop_back();
            int a = stack.back(); stack.pop_back();
            if (token == "+") stack.push_back(a + b);
            else if (token == "-") stack.push_back(a - b);
            else if (token == "*") stack.push_back(a * b);
            else stack.push_back(a / b);
        }
        return stack.back();
    }
};
