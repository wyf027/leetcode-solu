题解：前缀和 + 频次哈希表

核心洞察

扫描到当前位置时前缀和为 sum。若此前出现过 sum-k，两段前缀之差就是一个和为 k 的子数组。同一前缀和可能出现多次，因此表中保存频次。

完整过程

  1. 令 freq[0]=1，表示未取元素的空前缀。
  2. 依次把元素加入 sum。
  3. 将 freq[sum-k] 加入答案。
  4. 最后把当前 sum 的频次加一。

正确性

固定右端点时，合法左边界与此前值为 当前前缀和-k 的前缀一一对应。哈希表保存了所有且仅有已扫描前缀及频次，因此该步不漏不重地统计以当前元素结尾的合法区间。每个子数组具有唯一右端点，所以遍历结束后答案恰为全部合法子数组数。

边界与常见错误

  • 数组允许负数，普通滑动窗口不适用。
  • 漏掉初始 0 → 1 会漏算从下标 0 开始的区间。
  • 先查询再更新，否则 k=0 时会计入空区间。
  • 必须保存频次，不能只保存是否出现。

复杂度

时间 O(n)，额外空间 O(n)。

替代方案

枚举左右端点并用前缀和查询为 O(n²)；三层暴力为 O(n³)。全非负数组可讨论滑动窗口，但不适用于本题通用输入。

面试追问

  • 输出全部区间：把各前缀和对应的下标列表保存下来。
  • 只判断是否存在：频次表可简化为集合。
  • 持续数据流：累计和、频次表和答案都可在线更新。

四语言完整实现

class Solution {
    public int subarraySum(int[] nums, int k) {
        java.util.Map<Integer, Integer> freq = new java.util.HashMap<>();
        freq.put(0, 1);
        int sum = 0, answer = 0;
        for (int value : nums) {
            sum += value;
            answer += freq.getOrDefault(sum - k, 0);
            freq.put(sum, freq.getOrDefault(sum, 0) + 1);
        }
        return answer;
    }
}
