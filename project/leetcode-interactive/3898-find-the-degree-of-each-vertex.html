3898. 统计每个顶点的度

邻接矩阵的第 i 行，恰好记录了顶点 i 是否连向每一个顶点。把这一行的 0/1 相加，就是它的度。

题意

给定 matrix：一个 n × n 的无向图邻接矩阵。matrix[i][j] = 1 表示 i 与 j 有边；返回每个顶点连接边数的数组。

保证对角线为 0、元素只为 0/1、矩阵对称，且 1 ≤ n ≤ 100。

示例

matrix = [[0,1,1],[1,0,1],[1,1,0]]，输出 [2,2,2]。

一眼看懂

读第 0 行：0 + 1 + 1 = 2；顶点 0 有两条相邻边。每一行独立做同一件事。

无需 DFS、无需建邻接表：输入的表示已经足够。

交互：逐行计数

用示例矩阵观察当前行的和。也可用键盘 ← / → 切换步骤，空格自动播放。

已得到的度

当前行中每一个 1 都是一条与该顶点相连的边；自环位置已保证为 0。

测试与验证

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

用例 1
输入：matrix = [[0,1,1],[1,0,1],[1,1,0]]
期望输出：[2,2,2]
实际输出：—　状态：待补
用例 2
输入：matrix = [[0,1,0],[1,0,0],[0,0,0]]
期望输出：[1,1,0]
实际输出：—　状态：待补

题解：逐行求和

核心洞察

无向性和对称性说明一条边会同时出现在两个对应位置，但我们要的是每个点自己的度。因此直接将每一行相加即可；不要把所有 1 除以 2。

完整过程

  1. 创建长度为 n 的答案数组。
  2. 对每个 i 扫描 matrix[i]。
  3. 累加这一行每个 x，写入 ans[i]。

边界

  • n = 1 时唯一元素是 0，答案为 [0]。
  • 孤立点对应全 0 行，度自然为 0。
  • 矩阵为对称矩阵，但无需额外校验。

复杂度

时间 O(n²)；除返回数组外空间 O(1)。

替代方案

若输入是边列表，可以对边的两个端点各加一；若已是邻接矩阵，逐行计数更直接。

面试追问

若存在自环，通常自环对无向图度贡献 2；本题明确对角线为 0，因此直接行和安全。

常见错误

  • 把总边数当作单点度，或错误地把每行和除以 2。
  • 只扫描上三角而忘记为两端同步加度。
  • 误用列和：本题矩阵对称时列和也对，但行和表达更贴合定义。
