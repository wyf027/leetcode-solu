Problem

题意与边界

给定字符串 s 与整数 k，返回一个连续子串能够拥有的最大长度，其中不同字符的数量不超过 k。

你需要返回什么？

目标是长度，不是子串本身。子串必须连续；“至多”表示不同字符数可以少于 k，也可以恰好等于 k。

函数参数形式：lengthOfLongestSubstringKDistinct(s, k)，其中 s 为字符串、k 为整数，返回整数。

约束

  • 1 <= s.length <= 5 × 104
  • 0 <= k <= 50
  • s 由英文字母组成。

输出
3
说明

Example 02

输入

输出
2
说明
整个字符串 "aa" 只有一种字符。

Solution

滑动窗口 + 频次哈希表

让右边界负责探索，让左边界只在约束被破坏时追赶；哈希表负责回答“窗口里有多少种字符”。

核心洞察

01

窗口代表候选子串

区间 [left, right] 始终连续，天然满足“子串”要求。

02

哈希表代表约束

保存窗口内每个字符的出现次数；键的数量就是不同字符数。

03

合法时才更新答案

若种类数超过 k，不断右移 left；重新合法后记录长度。

完整过程

  1. 初始化 left = 0、best = 0 和空频次表。
  2. 枚举右边界 right，将 s[right] 的计数加一。
  3. 当频次表的键数大于 k 时，减少 s[left] 的计数；若降到零就删除该键，然后右移 left。
  4. 窗口恢复合法后，用 right - left + 1 更新最大长度。
  5. 右边界扫描结束，返回 best。

以 s = "eceba", k = 2 为例

窗口先扩展为 "ece"，字符集合是 {e, c}，最佳长度更新为 3。加入 b 后出现三种字符，于是左边界向右移动，直到旧字符被完全移出；之后继续处理 a。最终答案保持为 3。

正确性证明

不变式：每次更新答案时，窗口 s[left..right] 至多含 k 种字符，并且对于当前 right，left 是通过移除必要前缀得到的最靠左合法边界。

保持：加入 s[right] 后若窗口仍合法，不变式自然成立；若不合法，循环逐个移除左端字符，直到种类数重新不超过 k。循环不会多移：它在第一次恢复合法时立即停止。

完备性：对任意固定右端点，最靠左的合法边界给出以该点结尾的最长合法子串。算法检查每个右端点并记录最大值，因此不会遗漏全局最优解。

终止：right 单调向右扫描，left 也只向右移动，二者均至多移动 n 次，算法最终结束并返回正确最大长度。

边界情况

  • k = 0：任何非空窗口都不合法，答案为 0。
  • 字符串只有一种字符且 k >= 1：整个字符串都是答案。
  • k 大于等于字符串中的不同字符总数：无需收缩，答案为 s.length。
  • 字符交替出现：同一字符的计数可能反复增减，只有计数归零时才能从哈希表删除。
  • 最优子串出现在开头、结尾或中间：统一由每次合法窗口的长度更新覆盖。

复杂度

O(n)时间复杂度。每个字符至多被右边界加入一次、被左边界移出一次。
O(min(n, Σ))空间复杂度。哈希表最多保存窗口中的不同字符；Σ 为字符集大小。

四语言完整实现

Java · LeetCode 可提交形式 
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int lengthOfLongestSubstringKDistinct(String s, int k) {
        if (k == 0 || s.isEmpty()) {
            return 0;
        }

        Map<Character, Integer> frequency = new HashMap<>();
        int left = 0;
        int best = 0;

        for (int right = 0; right < s.length(); right++) {
            char incoming = s.charAt(right);
            frequency.put(incoming, frequency.getOrDefault(incoming, 0) + 1);

            while (frequency.size() > k) {
                char outgoing = s.charAt(left);
                int nextCount = frequency.get(outgoing) - 1;
                if (nextCount == 0) {
                    frequency.remove(outgoing);
                } else {
                    frequency.put(outgoing, nextCount);
                }
                left++;
            }

            best = Math.max(best, right - left + 1);
        }

        return best;
    }
}

Python · LeetCode 可提交形式 
class Solution:
    def lengthOfLongestSubstringKDistinct(self, s: str, k: int) -> int:
        if k == 0 or not s:
            return 0

        frequency: dict[str, int] = {}
        left = 0
        best = 0

        for right, incoming in enumerate(s):
            frequency[incoming] = frequency.get(incoming, 0) + 1

            while len(frequency) > k:
                outgoing = s[left]
                frequency[outgoing] -= 1
                if frequency[outgoing] == 0:
                    del frequency[outgoing]
                left += 1

            best = max(best, right - left + 1)

        return best
C++ · LeetCode 可提交形式 
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int lengthOfLongestSubstringKDistinct(string s, int k) {
        if (k == 0 || s.empty()) {
            return 0;
        }

        unordered_map<char, int> frequency;
        int left = 0;
        int best = 0;

        for (int right = 0; right < static_cast<int>(s.size()); right++) {
            frequency[s[right]]++;

            while (static_cast<int>(frequency.size()) > k) {
                char outgoing = s[left];
                frequency[outgoing]--;
                if (frequency[outgoing] == 0) {
                    frequency.erase(outgoing);
                }
                left++;
            }

            best = max(best, right - left + 1);
        }

        return best;
    }
};

替代方案

有序索引 / 最晚位置

只保存每种字符的最新下标。当种类数超过 k 时，找到最小的最新下标并跳过它。逻辑可行，但寻找最小值若用普通映射会增加开销；使用有序结构通常是 O(n log k)。

暴力枚举

从每个起点向右扩展并统计种类数，超限后停止。易于想到，但最坏需要 O(n²) 时间，只适合作为小规模对照思路。

面试追问

  • 如果要求恰好包含 k 种字符？ 可以用“至多 k 的子串计数减去至多 k - 1 的子串计数”解决计数问题；若仍只求最长长度，则更新答案时额外要求种类数恰为 k。
  • 如果输入是数据流？ 需要保存当前窗口字符以便从左端淘汰；窗口可能很长，空间下界与当前有效窗口相关。
  • 若字符集固定且很小？ 可用定长数组替代哈希表，并单独维护非零计数的槽位数量，常数更小。
  • 如何返回具体子串？ 在更新最佳长度时同步记录最佳左边界，最后截取 s[bestLeft..bestLeft + bestLen)。

常见错误

  • 把“至多 k 种”误写为“恰好 k 种”，导致 k 很大时漏掉答案。
  • 字符计数变为零后没有删除哈希键，使不同字符数永远无法下降。
  • 收缩窗口只使用一次 if，而不是持续执行的 while；一次移除未必能恢复合法。
  • 在窗口尚未恢复合法时更新答案，记录了不满足约束的长度。
  • 窗口长度写成 right - left，遗漏闭区间的 + 1。
