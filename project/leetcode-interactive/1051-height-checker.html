1051. 高度检查器

Height Checker · 找出当前队列与理想身高顺序不一致的位置数

题目

学校拍年度照时，学生应按身高非递减排列。给定当前顺序 heights，将同一组身高排序得到 expected。返回满足 heights[i] != expected[i] 的下标数量。

约束

  • 1 <= heights.length <= 100
  • 1 <= heights[i] <= 100

官方示例

示例 1 输入：heights = [1,1,4,2,1,3] 输出：3 解释：排序后为 [1,1,1,2,3,4]，下标 2、4、5 不匹配。
示例 2 输入：heights = [5,1,2,3,4] 输出：5 解释：排序后为 [1,2,3,4,5]，所有下标都不匹配。
示例 3 输入：heights = [1,2,3,4,5] 输出：0 解释：当前顺序已经符合要求。

题解：排序副本后逐位比较

核心洞察

题目并不要求把学生真的移动到位，只要求统计当前位置与目标位置的差异。保留原数组，复制并排序得到唯一的非递减目标顺序，再逐位比较即可。

完整过程

  1. 复制 heights，避免改变输入。
  2. 将副本升序排序为 expected。
  3. 扫描所有下标；两数组对应值不同时将答案加一。
  4. 返回累计值。

正确性证明

排序后的 expected 含有与输入完全相同的元素，并且非递减，因此它正是题目规定的理想队列。算法检查每一个合法下标且仅在 heights[i] != expected[i] 时计数，所以每个不匹配位置恰好贡献一次，匹配位置不贡献。最终计数正好等于题目所求。

边界情况

  • 只有一个学生：答案为 0。
  • 已经有序：答案为 0。
  • 所有位置均错位：答案可等于数组长度。
  • 重复身高：排序仍产生正确的目标序列。

复杂度

通用排序：时间 O(n log n)，空间 O(n)（保存副本；排序实现自身空间另计）。

替代方案

由于身高范围仅为 1～100，可用计数排序边生成目标值边比较，达到 O(n + 100) 时间与 O(100) 空间。

面试追问

  • 能否不显式构造完整的 expected？可以，用频次数组按身高从小到大与原数组比较。
  • 为什么不能只统计逆序对？逆序对数量衡量交换关系，不等于最终位置不匹配数。
  • 是否能原地排序？若允许修改输入可以，但会丢失比较基准，因此仍需保留原顺序或采用计数法。

常见错误

  • JavaScript 使用默认 sort()，导致按字符串字典序排序；必须传入 (a, b) => a - b。
  • 直接排序原数组后再与自身比较，结果总是 0。
  • 把“错位人数”误解为最少交换次数。

四语言完整实现

Java

import java.util.Arrays;

class Solution {
    public int heightChecker(int[] heights) {
        int[] expected = heights.clone();
        Arrays.sort(expected);
        int answer = 0;
        for (int i = 0; i < heights.length; i++) {
            if (heights[i] != expected[i]) answer++;
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number[]} heights
 * @return {number}
 */
var heightChecker = function(heights) {
    const expected = [...heights].sort((a, b) => a - b);
    let answer = 0;
    for (let i = 0; i < heights.length; i++) {
        if (heights[i] !== expected[i]) answer++;
    }
    return answer;
};

Python 3

from typing import List

class Solution:
    def heightChecker(self, heights: List[int]) -> int:
        expected = sorted(heights)
        return sum(a != b for a, b in zip(heights, expected))

C++

class Solution {
public:
    int heightChecker(vector<int>& heights) {
        vector<int> expected = heights;
        sort(expected.begin(), expected.end());
        int answer = 0;
        for (int i = 0; i < heights.size(); ++i) {
            if (heights[i] != expected[i]) ++answer;
        }
        return answer;
    }
};
