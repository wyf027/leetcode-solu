Minimum Lines to Represent a Line Chart

沿着日期阅读价格轨迹。画出同一幅折线图，最少需要几段直线？

打开官方题目 ↗

01 / 题目

给定二维整数数组 stockPrices，每项 [dayᵢ, priceᵢ] 表示第 dayᵢ 天的股票价格。以日期为横坐标、价格为纵坐标，按照日期先后把相邻数据点连接起来，得到折线图。

返回完整表示这条折线所需的最少线段数。一条直线段可以经过多个数据点；必须保留原折线的形状。输入不保证按日期有序。

参数：stockPrices: integer[][] → 返回：integer。只有一个数据点时，没有需要连接的线段。

约束

  • 1 ≤ stockPrices.length ≤ 10⁵
  • stockPrices[i].length == 2
  • 1 ≤ dayᵢ, priceᵢ ≤ 10⁹
  • 所有日期 dayᵢ 互不相同。

02 / 官方示例

示例 1 · 三段轨迹

输入：stockPrices = [[1,7],[2,6],[3,5],[4,4],[5,4],[6,3],[7,2],[8,1]]
输出：3

第一段从 (1,7) 到 (4,4)，经过 (2,6)、(3,5)；第二段从 (4,4) 到 (5,4)；第三段从 (5,4) 到 (8,1)，经过 (6,3)、(7,2)。三段可以完整表示这幅图，无法再减少。

示例 2 · 无序输入

输入：stockPrices = [[3,4],[1,2],[7,8],[2,3]]
输出：1

按日期连线后，(1,2)、(2,3)、(3,4)、(7,8) 全部落在同一条直线段上。

题解 / 在方向改变的地方分段

核心洞察

先按日期升序排列。每两个相邻点构成一条小边；方向相同的连续小边可以合成一段。答案等于第一条边的 1 段，加上后续方向改变的次数。

对连续三个点 A、B、C，令前一条边为 (dx₁, dy₁)，当前边为 (dx₂, dy₂)。由于日期严格递增，两个 dx 都大于 0，方向相同当且仅当：

dy₁ × dx₂ == dy₂ × dx₁

用整数交叉乘积精确判断，不计算浮点斜率。JavaScript 的乘积可能超过安全整数范围，要先转成 BigInt 再相乘。

方向接力台

连续三点 · 精确乘积

灰线是完整轨迹，彩色边是已经处理的部分；橙色圆环标出本步比较的点。颜色变化代表开启新线段。按步骤观察合并边界。

完整过程
  1. 原地按日期升序排序。
  2. 只有一个点，直接返回 0；否则令答案为 1，表示第一条边。
  3. 从第三个点开始，取相邻三点，计算前后两条边的 dx、dy。
  4. 若交叉乘积不等，方向改变，答案加 1；相等则继续当前段。
  5. 扫描到最后一个点，返回答案。
正确性
必须分段：相邻两条边方向不同，一条直线段不可能同时覆盖这两条边，因此该交点必须是分段边界。第一条边也至少需要一段，这给出了“1 + 方向改变次数”的下界。
足够分段：方向相同的连续边共享端点，且日期始终递增，所以它们依次落在同一直线上，可合并为一条直线段。按每次方向改变划分，恰好使用上述下界数量的线段。因此算法最优。单点无边，答案 0，单独处理即可。
边界与数值
  • 两个点必为 1 段；全部共线为 1 段；水平边的 dy 为 0，公式仍成立。
  • 所有内点均转折时为 n − 1 段；下跌价格产生负 dy，不需要特殊分支。
  • 重复日期在题目范围之外；合法输入没有竖直边。
  • 乘积绝对值不超过 (10⁹ − 1)²，小于 10¹⁸。Java 用 long、C++ 用 long long；Python 整数自动扩展；JavaScript 用 BigInt。
  • 必须在乘法前提升类型，先发生溢出再转换无法补救。
复杂度
排序 O(n log n)，扫描 O(n)，总时间 O(n log n)。扫描本身额外空间 O(1)。下面实现均修改输入顺序；排序额外空间依语言而定：Java 对象数组排序与 Python 排序最坏 O(n)，C++ std::sort 通常 O(log n) 栈空间，JavaScript 取决于引擎。固定题目整数范围下，整数运算按常数时间计。
替代方案
也可将每条边的 (dy, dx) 用最大公约数约分，比较相邻方向对，但会多出 GCD 计算，本题无需保存整组方向。浮点除法或人为 epsilon 不适合作为精确共线判定；直接使用交叉乘积更简单。
常见错误
  • 没排序就按输入顺序连接，画出了另一幅图。
  • 计算不同斜率的集合大小。相同方向如果被另一段隔开，也不能跨过去合并。
  • 把 n − 1 条相邻小边直接当答案，忽略共线合并。
  • 把单点初始化成 1；或者把方向比较循环从第二个点开始，访问越界。
  • JavaScript 用 Number 计算乘积，或 Java / C++ 用 32 位整数相乘。
面试追问
数据已按日期排序？省略排序，O(n) 时间、O(1) 额外空间。
需要返回具体线段？记录当前段起点；方向改变时输出到前一个点的线段，最后补上末段。
实时按日期追加点？保留最后两个点和当前段数即可更新；乱序插入则需要维护日期顺序并重算受影响的局部转折。

Java
import java.util.Arrays;

class Solution {
    public int minimumLines(int[][] stockPrices) {
        Arrays.sort(stockPrices, (a, b) -> Integer.compare(a[0], b[0]));
        int n = stockPrices.length;
        if (n == 1) return 0;
        int answer = 1;
        for (int i = 2; i < n; i++) {
            long dx1 = (long) stockPrices[i - 1][0] - stockPrices[i - 2][0];
            long dy1 = (long) stockPrices[i - 1][1] - stockPrices[i - 2][1];
            long dx2 = (long) stockPrices[i][0] - stockPrices[i - 1][0];
            long dy2 = (long) stockPrices[i][1] - stockPrices[i - 1][1];
            if (dy1 * dx2 != dy2 * dx1) answer++;
        }
        return answer;
    }
}

var minimumLines = function(stockPrices) {
    stockPrices.sort((a, b) => a[0] - b[0]);
    if (stockPrices.length === 1) return 0;
    let answer = 1;
    for (let i = 2; i < stockPrices.length; i++) {
        const [a, b, c] = [stockPrices[i - 2], stockPrices[i - 1], stockPrices[i]];
        const dx1 = BigInt(b[0] - a[0]);
        const dy1 = BigInt(b[1] - a[1]);
        const dx2 = BigInt(c[0] - b[0]);
        const dy2 = BigInt(c[1] - b[1]);
        if (dy1 * dx2 !== dy2 * dx1) answer++;
    }
    return answer;
};


Python 3
from typing import List

class Solution:
    def minimumLines(self, stockPrices: List[List[int]]) -> int:
        stockPrices.sort(key=lambda p: p[0])
        if len(stockPrices) == 1:
            return 0
        answer = 1
        for i in range(2, len(stockPrices)):
            a, b, c = stockPrices[i - 2], stockPrices[i - 1], stockPrices[i]
            dx1, dy1 = b[0] - a[0], b[1] - a[1]
            dx2, dy2 = c[0] - b[0], c[1] - b[1]
            if dy1 * dx2 != dy2 * dx1:
                answer += 1
        return answer


C++
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int minimumLines(vector<vector<int>>& stockPrices) {
        sort(stockPrices.begin(), stockPrices.end());
        int n = static_cast<int>(stockPrices.size());
        if (n == 1) return 0;
        int answer = 1;
        for (int i = 2; i < n; ++i) {
            long long dx1 = 1LL * stockPrices[i - 1][0] - stockPrices[i - 2][0];
            long long dy1 = 1LL * stockPrices[i - 1][1] - stockPrices[i - 2][1];
            long long dx2 = 1LL * stockPrices[i][0] - stockPrices[i - 1][0];
            long long dy2 = 1LL * stockPrices[i][1] - stockPrices[i - 1][1];
            if (dy1 * dx2 != dy2 * dx1) ++answer;
        }
        return answer;
    }
};
