2289. 使数组按非递减顺序排列

Steps to Make Array Non-decreasing

观察相邻元素，理解“同时删除”。先自己尝试，再展开页面底部的题解。

01 / 题目

给定从下标 0 开始的整数数组 nums。每轮以该轮开始时的数组为准，同时移除所有满足 nums[i - 1] > nums[i] 的元素 nums[i]（0 < i < nums.length）。重复操作，直到数组非递减，返回执行的轮数。

同一轮先确定全部删除对象，再统一删除。删除形成的新邻接关系只能影响下一轮。非递减允许相邻值相等，首元素没有左邻居。

参数与返回值

totalSteps(nums: integer[]) → integer

输入为一个整数数组；输出为非负整数轮数。

约束

  • 1 ≤ nums.length ≤ 105
  • 1 ≤ nums[i] ≤ 109

02 / 官方示例

示例 1

输入：nums = [5,3,4,4,7,3,6,11,8,5,11]
输出：3
第 1 轮后：[5,4,4,7,6,11,11]
第 2 轮后：[5,4,7,11,11]
第 3 轮后：[5,7,11,11]

完成第 3 轮后，每一对相邻值都满足左边 ≤ 右边。

示例 2

输入：nums = [4,5,7,7,13]
输出：0

原数组已经非递减，无需进行任何删除。

05 / 独立题解

准备好后再展开：核心推导、单调栈回放、正确性与四语言实现。

核心洞察：给元素计算“删除轮次”

逐轮扫描在 [10,1,2,3,4] 这类等待链上会反复访问元素。改为从左向右一次遍历，计算每个元素的删除轮次 dp；不会删除记为 0，答案是所有轮次的最大值。

维护一个值从栈底到栈顶严格递减的栈，每项为 (值, 删除轮次)。处理当前值 x 时，所有栈顶 值 ≤ x 的项都不能成为最终删除它的更大左邻居，因此弹出，并记录其中最大的删除轮次 wait。

  • 弹出后栈为空：左侧没有更大的元素，dp(x) = 0。
  • 栈仍非空：有更大的左侧元素，等待中间障碍消失后再过一轮，dp(x) = wait + 1。
  • 把 (x, dp(x)) 压栈，并更新全局最大轮次。
栈的“弹出”只压缩计算状态，不表示元素此刻从原数组删除。相等值也要弹栈以传递等待时间，但相等的两个相邻元素不会直接互相删除。

完整过程：nums = [5,3,4,4]

x弹出项waitdp(x)栈底 → 栈顶
5无00(5,0)
3无01(5,0), (3,1)
4(3,1)12(5,0), (4,2)
4(4,2)23(5,0), (4,3)

对应删除过程为 [5,3,4,4] → [5,4,4] → [5,4] → [5]，答案为 3。各障碍的轮次是从全局第 1 轮开始计数，等待时间取最大值，不求和。

单调栈回放 · 使用实验台已载入的 nums

每一步处理一个原始元素。栈项显示“值 / 删除轮次”，底在左、顶在右。

正确性说明

  1. 归纳不变式：处理完一个前缀后，栈内值严格递减，栈项的 dp 是该元素真实删除轮次；被弹出的片段，其等待信息已汇总到右侧代表项。
  2. 定位更大元素：对 x 弹出所有 ≤ x 的栈顶后，若还有栈顶 g，它是最近的未被压缩掉的更大左侧代表。g 与 x 之间的片段均不大于 x，不会直接删除 x，却会暂时隔开 g 与 x。
  3. 等待递推：这些片段的消失时间由弹出项记录的轮次覆盖。它们同时演化，最后一个片段消失于最大轮次 wait。存在 g 时，x 在此前不能被更大元素触及，在下一轮会被删除；即使 g 已被更大的左元素删除，该更大元素也能继承删除作用。因此 dp(x) = wait + 1。若没有 g，左侧没有任何值大于 x，它永久保留，dp(x) = 0。
  4. 答案：遍历计算了所有元素的删除轮次。最后一次删除对应最大 dp；其后不存在逆序相邻对，否则还会有元素待删。最大 dp 就是所求操作数。

复杂度与边界

每个元素入栈一次、至多出栈一次，总时间 O(n)，栈额外空间 O(n)。轮数最多 n − 1；值只比较、不相加，给定约束下四种实现使用的数值类型足够。

单元素、全相等或非递减数组返回 0；严格递减且长度大于 1 时，其余元素同时删除，返回 1。相等值的弹栈条件必须包含等号。题目不包含空数组。

替代方案

  • 同步数组模拟：每轮先标记再生成新数组，直观但最坏 O(n²) 时间、O(n) 空间。上方实验台为这种方案，限制 60 个元素用于教学。
  • 链表邻接 + 分轮队列：记录前后存活下标，只检查删除处形成的新边界，可做到 O(n) 总时间和 O(n) 空间；必须对每轮候选做去重并维持同步删除语义，实现更复杂。
  • 从右往左的单调栈：也能线性求解，但状态含义和轮次递推不同，不能照搬本页的左向右公式。

常见错误

  • 在一轮内边遍历边删除，并立即比较新邻居，混淆同步与串行。
  • 弹栈只用 <，导致相等值的等待信息无法合并。
  • 栈空时仍写 wait + 1，错误删除前缀最大值。
  • 把多个等待轮次相加；它们在同一时间轴演化，应取最大。
  • 返回最后一个元素的 dp；应返回所有元素的最大 dp。

面试追问

为什么嵌套 while 仍为线性？以元素的入栈与出栈次数做摊还分析，每项最多各一次。

哪些元素最终保留？原数组中的前缀最大值（含与此前最大值相等者），因为左侧没有严格更大的元素。

如何输出每轮删除的下标？额外保存每项 dp，再按正轮次分桶；原始下标天然可保留，空间 O(n)。

如果改为逐个立即删除？操作顺序会影响过程，当前同步轮次模型和递推不能直接套用。

Java

class Solution {
    public int totalSteps(int[] nums) {
        int n = nums.length, top = -1, answer = 0;
        int[] values = new int[n];
        int[] rounds = new int[n];
        for (int x : nums) {
            int wait = 0;
            while (top >= 0 && values[top] <= x) {
                wait = Math.max(wait, rounds[top--]);
            }
            int current = top < 0 ? 0 : wait + 1;
            values[++top] = x;
            rounds[top] = current;
            answer = Math.max(answer, current);
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number}
 */
var totalSteps = function(nums) {
    const stack = [];
    let answer = 0;
    for (const x of nums) {
        let wait = 0;
        while (stack.length && stack[stack.length - 1][0] <= x) {
            wait = Math.max(wait, stack.pop()[1]);
        }
        const current = stack.length ? wait + 1 : 0;
        stack.push([x, current]);
        answer = Math.max(answer, current);
    }
    return answer;
};

from typing import List

class Solution:
    def totalSteps(self, nums: List[int]) -> int:
        stack = []
        answer = 0
        for x in nums:
            wait = 0
            while stack and stack[-1][0] <= x:
                wait = max(wait, stack.pop()[1])
            current = wait + 1 if stack else 0
            stack.append((x, current))
            answer = max(answer, current)
        return answer

C++

#include <algorithm>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int totalSteps(vector<int>& nums) {
        vector<pair<int, int>> stack;
        int answer = 0;
        for (int x : nums) {
            int wait = 0;
            while (!stack.empty() && stack.back().first <= x) {
                wait = max(wait, stack.back().second);
                stack.pop_back();
            }
            int current = stack.empty() ? 0 : wait + 1;
            stack.emplace_back(x, current);
            answer = max(answer, current);
        }
        return answer;
    }
};
