01 / 题目与规则

输入整数二维数组 matches，每项 matches[i] = [winnerᵢ, loserᵢ] 表示前者击败后者。返回长度为 2 的列表 answer：第一项列出从未输过的玩家，第二项列出恰好输过一次的玩家。两项都必须按玩家编号递增排列。

只纳入至少参加过一场比赛的玩家；相同的有序赛果不会重复出现。胜者也可能在其他比赛里输过。

约束

  • 1 ≤ matches.length ≤ 10⁵
  • matches[i].length == 2
  • 1 ≤ winnerᵢ, loserᵢ ≤ 10⁵
  • winnerᵢ != loserᵢ
  • 所有 matches[i] 互不相同。

官方示例 1

输入：matches = [[1,3],[2,3],[3,6],[5,6],[5,7],[4,5],[4,8],[4,9],[10,4],[10,9]]
输出：[[1,2,10],[4,5,7,8]]

1、2、10 零败；4、5、7、8 一败；3、6、9 均为两败，不能进入结果。

官方示例 2

输入：matches = [[2,3],[1,3],[5,4],[6,4]]
输出：[[1,2,5,6],[]]

1、2、5、6 零败；3、4 均为两败，所以第二个列表为空。

04 / 独立题解
准备好后再展开：思路、证明、四语言实现与面试延伸。






核心洞察：只记负场，不必记胜场


答案仅依赖每位参赛者输了多少次。用映射 losses 同时记录“是否登场”和“负场数”：首次遇到胜者时建一个 0 记录；遇到败者时累计一次。已经有记录的胜者绝不能清零。


完整过程
  1. 创建空映射。
  2. 扫描每个 [winner, loser]：若 winner 不存在，登记为 0；将 loser 的值从默认 0 加到 1，或在原值上加 1。
  3. 遍历映射，只把值为 0 和 1 的键分别放入两个结果列表。
  4. 分别按编号数值升序排序，返回两个列表。


示例 1 中：处理 [1,3] 后，1 零败、3 一败；处理 [2,3] 后，3 变为两败；处理 [3,6] 时，3 虽然获胜，但仍是两败。最后再将名单排序，编号 10 应排在 2 后面。


正确性证明
不变式：处理前 k 场后，映射的键恰为这 k 场的参赛者，每个键的值恰为其在前 k 场中的负场数。k = 0 时空映射成立。处理下一场时，首次登场的胜者此前没有负场，登记 0 正确；已登场的胜者本场未输，保持原值正确；败者本场多输一次，增加 1 正确，其他记录不变。因此不变式由归纳法对所有比赛成立。最后按值为 0、1 筛选，恰好得到两个所求集合；数值排序满足递增要求。


边界与复杂度
只赢不输的玩家也必须建档；只输不赢的玩家由计数操作自动建档。编号不连续，未参赛编号不能视为零败。两人互相击败是两个不同的合法赛果。零败或一败列表都可能为空，两列表也可能同时为空。
设 m 为比赛数、p 为不同参赛者数。哈希表操作按均摊 O(1) 计，扫描 O(m)，分类 O(p)，排序最坏 O(p log p)，总时间 O(m + p log p)，辅助空间 O(p)，结果也最多 O(p)。


替代方案
  • 定长计数数组：编号上界 U = 100000。用 -1 表示未登场、0 表示已登场零败；最后从 1 扫到 U，天然有序。时间 O(m + U)、空间 O(U)，适合稠密小编号。
  • 三个集合：维护零败、一败、多败状态，输一次就迁移到下一区；最终仍需排序。能描述流式状态，但比单个计数映射更易写错。
  • 有序映射：插入和更新 O(log p)，最后依键顺序输出，时间 O(m log p + p)，不用另排序。

Java
import java.util.*;

class Solution {
    public List<List<Integer>> findWinners(int[][] matches) {
        Map<Integer, Integer> losses = new HashMap<>();
        for (int[] match : matches) {
            losses.putIfAbsent(match[0], 0);
            losses.put(match[1], losses.getOrDefault(match[1], 0) + 1);
        }
        List<List<Integer>> answer = new ArrayList<>();
        answer.add(new ArrayList<>());
        answer.add(new ArrayList<>());
        for (Map.Entry<Integer, Integer> entry : losses.entrySet()) {
            int count = entry.getValue();
            if (count < 2) answer.get(count).add(entry.getKey());
        }
        Collections.sort(answer.get(0));
        Collections.sort(answer.get(1));
        return answer;
    }
}


JavaScript
/**
 * @param {number[][]} matches
 * @return {number[][]}
 */
var findWinners = function(matches) {
    const losses = new Map();
    for (const [winner, loser] of matches) {
        if (!losses.has(winner)) losses.set(winner, 0);
        losses.set(loser, (losses.get(loser) ?? 0) + 1);
    }
    const answer = [[], []];
    for (const [player, count] of losses) {
        if (count < 2) answer[count].push(player);
    }
    answer[0].sort((a, b) => a - b);
    answer[1].sort((a, b) => a - b);
    return answer;
};

from typing import List

class Solution:
    def findWinners(self, matches: List[List[int]]) -> List[List[int]]:
        losses = {}
        for winner, loser in matches:
            losses.setdefault(winner, 0)
            losses[loser] = losses.get(loser, 0) + 1
        answer = [[], []]
        for player, count in losses.items():
            if count < 2:
                answer[count].append(player)
        answer[0].sort()
        answer[1].sort()
        return answer


C++
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> findWinners(vector<vector<int>>& matches) {
        unordered_map<int, int> losses;
        for (const auto& match : matches) {
            losses.emplace(match[0], 0);
            ++losses[match[1]];
        }
        vector<vector<int>> answer(2);
        for (const auto& entry : losses) {
            if (entry.second < 2)
                answer[entry.second].push_back(entry.first);
        }
        sort(answer[0].begin(), answer[0].end());
        sort(answer[1].begin(), answer[1].end());
        return answer;
    }
};


常见错误
  • 只统计败者，导致零败的胜者从未进入映射。
  • 每次遇到胜者都赋值 0，擦掉它此前的负场记录。
  • 把“恰好一败”写成“不超过一败”，使两组混淆。
  • JavaScript 使用默认 sort()，把编号按字符串排成 1、10、2。
  • 数组初值全为 0 且不标记参赛，错误纳入未出场玩家。


面试追问
  • 每场结束后查询名单？ 维护计数及两个候选集合；更新只触及两人，输出时再排序。若查询频繁，可考虑有序集合。
  • 只关心零败和一败，能否压缩计数？ 可以将计数饱和到 2，2 代表至少两败；但如果未来要支持撤销比赛，需保留真实计数。
  • 编号巨大且稀疏？ 使用哈希表，避免按编号最大值分配数组。
  • 允许重复赛果？ 若每项是一场独立比赛，就每项都计数；若它们是重复上报的同一场比赛，需先按比赛唯一标识去重，不能仅凭双方编号判断。
