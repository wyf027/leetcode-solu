Count Distinct Numbers on Board

统计桌面上的不同数字

从一个数字开始，让“余数为 1”的关系每天把新数字带到桌面。先观察规则如何扩散，再决定是否查看题解。

Problem

题目描述

给定正整数 n，开始时桌面上只有 n。接下来的 109 天里，每天对桌面上的每个数字 x，找出所有满足 1 ≤ i ≤ n 且 x % i == 1 的整数 i，并把它们放到桌面上。

数字放上桌面后不会被移除。请返回十亿天后桌面上不同整数的数量。符号 % 表示取余，例如 14 % 3 == 2。

示例 1

输入：n = 5
输出：4

初始有 5；随后加入 2 和 4，再由 4 带来 3。最终桌面上是 2、3、4、5。

示例 2

输入：n = 3
输出：2

因为 3 % 2 == 1，2 会被加入；最终只有 2 和 3。

约束：1 ≤ n ≤ 100

    Solution

    题解

    核心洞察

    当 n > 1 时，最终桌面恰好包含 2, 3, …, n，答案是 n - 1；当 n == 1 时，桌面始终只有 1，答案是 1。因此可直接返回 max(1, n - 1)。

    完整过程

    1. 若桌面上有 x ≥ 3，取 i = x - 1。
    2. 此时 x % (x - 1) == 1，所以下一天一定会加入 x - 1。
    3. 从初始的 n 反复应用，最终可得到从 n 到 2 的每个整数。
    4. 数字 1 永远不会由规则加入，因为任意 x % 1 == 0。
    5. 因此无需模拟十亿天，只需按边界返回结果。

    正确性证明

    对于 n > 1，先证明所有 2..n 都会出现。初始时 n 已在桌面；若 k 在桌面且 k ≥ 3，则 k % (k - 1) == 1，故 k - 1 会被加入。由递降归纳可知 n - 1, n - 2, …, 2 全部出现。

    再证明没有其他数字：规则只允许 1..n，而 1 不可能被加入；初始 n 也位于 2..n。所以最终集合恰为 {2, …, n}，大小为 n - 1。当 n == 1 时，初始集合 {1} 不再变化，答案为 1。

    边界与复杂度

    • n = 1：不能返回 0，应返回 1。
    • n = 2：只有初始数字 2，结果也是 1。
    • 时间复杂度：O(1)。
    • 空间复杂度：O(1)。

    替代方案：集合模拟

    可以用集合保存桌面数字，每轮枚举当前 x 与所有 i ∈ [1,n]，直到没有新增数字。 这个方案直观，适合验证小数据，但写法更长，最坏需要多轮枚举，且直接执行十亿轮不可行。

    本题的递降关系已经给出完整闭包，因此常数时间公式更直接。

    面试追问

    • 如果条件改为 x % i == r，哪些数仍可保证出现？
    • 如果新数字第二天会消失，状态还会单调增长吗？
    • 若 i 不限制在 1..n，结果是否仍有限？
    • 如何写一个集合闭包模拟器来验证公式？

    常见错误

    • 把答案无条件写成 n - 1，遗漏 n = 1。
    • 误以为 1 会出现，忽略 x % 1 恒等于 0。
    • 真的循环 109 天，导致超时。
    • 只分析 n % i，忘记新加入的数字也会继续产生后继。
