01 / PROBLEM

任务与规则

给定整数数组 tasks，第 i 个任务耗时 tasks[i] 小时。每个工作时间段最多持续 sessionTime 小时，之后休息。返回完成全部任务所需的最少工作时间段数。

  • 一个任务不能拆开，必须在开始它的同一个时间段内完成。
  • 完成一个任务后，可以立即开始下一个；任务顺序可任意调整。
  • 每段总时长可以小于上限，不要求恰好用满。
参数与返回值

minSessions(tasks: integer[], sessionTime: integer) → integer

完整约束
  • n == tasks.length
  • 1 ≤ n ≤ 14
  • 1 ≤ tasks[i] ≤ 10
  • max(tasks[i]) ≤ sessionTime ≤ 15

04 / SOLUTION LAB

准备好后，再打开题解

把一组任务，看作一个状态

核心洞察：n ≤ 14，可以用二进制位表示任务集合。对一组待完成任务，选出能够在一段内完成的非空子集，剩余任务使用已经求出的最优结果。

记 sum[mask] 为集合总耗时，dp[mask] 为完成该集合的最少段数。dp[0] = 0；其余状态初始设为 n，因为每个任务单独一段总是可行。

dp[mask] = min(dp[mask ^ sub] + 1)
其中：sub 是 mask 的非空子集，且 sum[sub] ≤ sessionTime

完整过程

  1. 位 i 为 1 表示包含任务 tasks[i]；相同时长的任务仍有不同下标。
  2. 从 mask = 1 递增处理。取最低位 bit = mask & -mask，使用 sum[mask] = sum[mask ^ bit] + tasks[i] 计算耗时。
  3. 令 sub = mask，通过 sub = (sub - 1) & mask 枚举全部非空子集。
  4. 若当前子集超时，跳过；否则尝试 dp[mask ^ sub] + 1，取最小值。
  5. 非空子集被移除后，剩余掩码严格小于当前掩码，因此依赖均已计算。最后返回 dp[(1 << n) - 1]。

状态账本

绿色边框为当前更新状态，蓝色边框为本次引用的剩余状态；“—”表示未开始，“初始上界”或“暂存”表示仍在枚举。

具体走一遍

对于 tasks = [1,2,3], sessionTime = 3，掩码 011 表示任务 0 和 1，总耗时为 3，因此 dp[011] = 1。计算完整状态 111 时，选择 sub = 100，它表示耗时 3 的任务，可以单独占一段；剩余为 011，候选值为 1 + dp[011] = 2。全部任务耗时 6，不可能只用一段，故最优值是 2。

为什么一定正确？

基础情况：空集合不需要工作时间段，dp[0] = 0。

可行性：每次转移都选取不超过容量的子集作为一个完整工作时间段，再与剩余集合的最优安排合并。两部分互不重叠，覆盖当前集合，因此产生的方案均合法。

最优性：考虑当前集合的任意最优安排，取其中一个工作时间段的任务集合为 sub。它必是枚举到的合法子集。移除后，剩余任务的最优段数不大于原安排的剩余段数，所以这次转移不会比原最优方案更差。结合可行性，转移取到的最小值恰好是最优解。由于剩余掩码更小，按掩码递增计算满足归纳条件。

边界与复杂度

  • 只有一个任务时，答案是 1；总耗时不超过上限时，答案也是 1。
  • 每个任务都等于上限时，答案为任务数。时长相同不能合并为一个“任务种类”。
  • 容量判断使用 ≤，刚好装满是合法的；题目保证没有单个任务超时。
  • 预计算总耗时为 O(2ⁿ)；枚举所有状态及其子集为 O(3ⁿ)：每个任务有“不在 mask”“在 sub”“在剩余集合”三种归属。
  • 总时间 O(3ⁿ)，辅助空间 O(2ⁿ)。可视化为了回放保存快照，额外占用空间，仅展示至多 5 个任务；提交代码没有回放数据。

替代方案

二元状态 DP：每个集合保存“已开段数、最后一段已用时”，按字典序保留最优状态，每次加入一个任务；放不下就开新段。可将时间降到 O(n·2ⁿ)，空间仍为 O(2ⁿ)，但需要解释为什么同段数下更小的尾段用时支配更大的用时。

回溯与剪枝：按任务耗时降序尝试放入已有段或新段；相同已用时的段只试一次，用当前最优答案剪枝。实现直观，但最坏情况仍为指数级搜索。

贪心局限：降序后放入第一个能容纳的段并不保证最优。例如 [3,3,2,2,2,2], sessionTime = 7 会得到 3 段，而 [3,2,2] + [3,2,2] 只需 2 段。

常见错误

  • 只用 ceil(sum / sessionTime) 当答案：它只是下界。三个 4 小时任务、容量 6 时，下界为 2，实际需要 3 段。
  • 枚举空子集会造成无意义自依赖；子集循环必须在 sub == 0 时停止。
  • 把 mask ^ sub 随意用于非子集：异或只有在 sub ⊆ mask 时才表示移除。
  • 将 dp[0] 初始化为 1，会让所有结果多一段。
  • 只按原数组顺序切分，会漏掉重新安排后的更优方案。

面试追问

  • 如何还原具体安排？在最优值更新时记录 choice[mask] = sub，从全集反复移除该子集，直到空集。
  • n 大很多怎么办？一般形式属于装箱问题，精确求解困难；可以讨论分支限界、整数规划或近似算法，而不是直接扩大位掩码。
  • 如何减少重复分组？枚举时强制当前子集包含 mask 的最低有效位；任意分组中必有一段包含该任务，因此不漏最优方案，但不改变指数级复杂度。

Java完整提交实现 · 待补验证

class Solution {
    public int minSessions(int[] tasks, int sessionTime) {
        int n = tasks.length, size = 1 << n;
        int[] sum = new int[size];
        int[] dp = new int[size];
        for (int mask = 1; mask < size; mask++) {
            int bit = mask & -mask;
            int i = Integer.numberOfTrailingZeros(bit);
            sum[mask] = sum[mask ^ bit] + tasks[i];
            dp[mask] = n;
            for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
                if (sum[sub] <= sessionTime) {
                    dp[mask] = Math.min(dp[mask], dp[mask ^ sub] + 1);
                }
            }
        }
        return dp[size - 1];
    }
}

/**

var minSessions = function(tasks, sessionTime) {
    const n = tasks.length, size = 1 << n;
    const sum = Array(size).fill(0);
    const dp = Array(size).fill(n);
    dp[0] = 0;
    for (let mask = 1; mask < size; mask++) {
        const bit = mask & -mask;
        const i = 31 - Math.clz32(bit);
        sum[mask] = sum[mask ^ bit] + tasks[i];
        for (let sub = mask; sub > 0; sub = (sub - 1) & mask) {
            if (sum[sub] <= sessionTime) {
                dp[mask] = Math.min(dp[mask], dp[mask ^ sub] + 1);
            }
        }
    }
    return dp[size - 1];
};

from typing import List

class Solution:
    def minSessions(self, tasks: List[int], sessionTime: int) -> int:
        n = len(tasks)
        size = 1 << n
        total = [0] * size
        dp = [n] * size
        dp[0] = 0
        for mask in range(1, size):
            bit = mask & -mask
            i = bit.bit_length() - 1
            total[mask] = total[mask ^ bit] + tasks[i]
            sub = mask
            while sub:
                if total[sub] <= sessionTime:
                    dp[mask] = min(dp[mask], dp[mask ^ sub] + 1)
                sub = (sub - 1) & mask
        return dp[-1]

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int minSessions(vector<int>& tasks, int sessionTime) {
        int n = tasks.size(), size = 1 << n;
        vector<int> sum(size, 0), dp(size, n);
        dp[0] = 0;
        for (int mask = 1; mask < size; ++mask) {
            int bit = mask & -mask;
            int i = __builtin_ctz(static_cast<unsigned>(bit));
            sum[mask] = sum[mask ^ bit] + tasks[i];
            for (int sub = mask; sub; sub = (sub - 1) & mask) {
                if (sum[sub] <= sessionTime) {
                    dp[mask] = min(dp[mask], dp[mask ^ sub] + 1);
                }
            }
        }
        return dp[size - 1];
    }
};
