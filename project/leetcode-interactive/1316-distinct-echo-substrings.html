HARD字符串滚动哈希Suffix Array非付费题

题目转述

给定字符串 text，统计它有多少个内容不同的非空子串，能够写成某个字符串连续出现两次，即 a + a。

“不同”按子串内容判断，而不是按它在原串中的起止位置判断。相同内容出现多次，只计一次。

函数签名

distinctEchoSubstrings(text: string) → integer

示例 1

输入：text = "abcabcabc"
输出：3
解释：三个不同子串为 "abcabc"、"bcabca" 和 "cabcab"。

示例 2

输入：text = "leetcodeleetcode"
输出：2
解释：两个不同子串为 "ee" 和 "leetcodeleetcode"。

约束与抓手

  • 1 ≤ text.length ≤ 2000
  • text 只含小写英文字母
  • 候选子串长度必为偶数
  • 只需比较候选的左右两半
  • 相等判断和内容去重都可由哈希加速

Solution

双滚动哈希：枚举窗口，常数时间验半

期望 O(n²)

核心洞察

任意回声子串长度都是 2 × half。枚举半长 half 和起点 start 后，只需判断区间 [start, start+half) 与 [start+half, start+2×half) 是否相同。前缀滚动哈希能在 O(1) 时间给出两个区间的指纹；匹配后，再把整个窗口的“长度 + 双哈希”放进集合去重。

H(l, r) = prefix[r] − prefix[l] × base^(r−l) (mod M)

完整过程

  1. 为两个不同的大质数模数分别预处理幂数组与前缀哈希。
  2. 令 half 从 1 枚举到 ⌊n/2⌋，令 start 覆盖所有能容纳 2×half 字符的位置。
  3. 用两套区间哈希同时比较左右两半；任一模数不相等即可淘汰。
  4. 若两半的双哈希都相等，将完整窗口的长度与双哈希组成键，加入集合。
  5. 扫描完成后，集合大小就是不同回声子串的数量。

正确性

不漏解每个回声子串都有某个起点和半长；双重枚举必然访问对应窗口。
只收合法窗口只有左右两半的两套区间哈希均相等时才收录，因此在无哈希碰撞的条件下，它恰为 a+a。
准确去重集合键包含总长度和完整内容的双哈希；相同内容归为同一键，不同长度不会混淆。
这是 Monte Carlo 算法：双模哈希的碰撞概率极低，但理论上不为零。若要求数学意义上的零碰撞，可改用后缀数组/LCP 对子串做确定性等价类编号。

复杂度

  • 时间：O(n²)，共有 O(n²) 个候选窗口，每次哈希比较与插入均为期望 O(1)。
  • 空间：O(n + k)，前缀数组为 O(n)，集合至多保存 k 个不同回声子串指纹，k ≤ O(n²)。

边界情况

  • 长度为 1：没有偶数长度候选，答案为 0。
  • 全相同字符：会有大量位置重复，必须按内容去重。
  • 回声互相重叠：重叠不影响枚举，例如 abcabcabc。
  • 不同长度的回声：键中必须包含长度，避免跨长度误判。

替代方案与面试追问

  • 直接切片 + 集合：直观，但切片和比较可能让最坏时间退化到 O(n³)。
  • LCP 动态规划：可在 O(n²) 预处理任意两后缀的最长公共前缀，但精确去重仍要谨慎设计。
  • 后缀数组 / 后缀树：可以确定性地比较、归并相等子串，代码更复杂。
  • 追问：如何把碰撞概率降到更低？为什么只枚举半长？若要输出所有结果，应如何恢复子串？

常见错误

  • 按出现位置计数，没有给相同内容去重。
  • 枚举任意长度，忘记回声子串长度必为偶数。
  • 只比较或只存单哈希，碰撞风险更高。
  • 哈希减法后没有归一化为非负数。
  • 集合键不含长度，导致不同长度的前导零式哈希表示发生歧义。

import java.util.HashSet;
import java.util.Set;

class Solution {
    private static final long BASE = 911382323L;
    private static final long MOD1 = 1_000_000_007L;
    private static final long MOD2 = 1_000_000_009L;

    public int distinctEchoSubstrings(String text) {
        int n = text.length();
        long[] p1 = new long[n + 1], p2 = new long[n + 1];
        long[] h1 = new long[n + 1], h2 = new long[n + 1];
        p1[0] = p2[0] = 1;
        for (int i = 0; i < n; i++) {
            int value = text.charAt(i) - 'a' + 1;
            p1[i + 1] = p1[i] * BASE % MOD1;
            p2[i + 1] = p2[i] * BASE % MOD2;
            h1[i + 1] = (h1[i] * BASE + value) % MOD1;
            h2[i + 1] = (h2[i] * BASE + value) % MOD2;
        }

        Set<String> seen = new HashSet<>();
        for (int half = 1; half * 2 <= n; half++) {
            for (int start = 0; start + 2 * half <= n; start++) {
                int mid = start + half, end = mid + half;
                long left1 = hash(h1, p1, start, mid, MOD1);
                long right1 = hash(h1, p1, mid, end, MOD1);
                if (left1 != right1) continue;
                long left2 = hash(h2, p2, start, mid, MOD2);
                long right2 = hash(h2, p2, mid, end, MOD2);
                if (left2 != right2) continue;

                long whole1 = hash(h1, p1, start, end, MOD1);
                long whole2 = hash(h2, p2, start, end, MOD2);
                seen.add((2 * half) + ":" + whole1 + ":" + whole2);
            }
        }
        return seen.size();
    }

    private long hash(long[] prefix, long[] power, int l, int r, long mod) {
        return (prefix[r] - prefix[l] * power[r - l] % mod + mod) % mod;
    }
}

class Solution:
    def distinctEchoSubstrings(self, text: str) -> int:
        n = len(text)
        base = 911_382_323
        mod1, mod2 = 1_000_000_007, 1_000_000_009
        p1, p2 = [1] * (n + 1), [1] * (n + 1)
        h1, h2 = [0] * (n + 1), [0] * (n + 1)

        for i, ch in enumerate(text):
            value = ord(ch) - ord('a') + 1
            p1[i + 1] = p1[i] * base % mod1
            p2[i + 1] = p2[i] * base % mod2
            h1[i + 1] = (h1[i] * base + value) % mod1
            h2[i + 1] = (h2[i] * base + value) % mod2

        def get_hash(prefix, power, left, right, mod):
            return (prefix[right] - prefix[left] * power[right - left]) % mod

        seen = set()
        for half in range(1, n // 2 + 1):
            for start in range(n - 2 * half + 1):
                mid, end = start + half, start + 2 * half
                left1 = get_hash(h1, p1, start, mid, mod1)
                right1 = get_hash(h1, p1, mid, end, mod1)
                if left1 != right1:
                    continue
                left2 = get_hash(h2, p2, start, mid, mod2)
                right2 = get_hash(h2, p2, mid, end, mod2)
                if left2 != right2:
                    continue

                whole1 = get_hash(h1, p1, start, end, mod1)
                whole2 = get_hash(h2, p2, start, end, mod2)
                seen.add((2 * half, whole1, whole2))

        return len(seen)
