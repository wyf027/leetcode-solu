132 模式

在索引顺序不变的前提下，寻找一个“先低、再高、最后居中”的三元子序列。这里先把问题看清楚，再决定是否展开完整题解。

132 Pattern 非付费题 数组 严格不等式
01 / Problem

题目描述

函数：find132pattern(nums)

给定一个包含 n 个整数的数组 nums。如果能从中选出三个元素 nums[i]、nums[j]、nums[k]，它们既保持原数组中的先后顺序，又满足下列大小关系，就称它们构成一个 132 模式。

只需判断数组中是否存在至少一个这样的子序列：存在返回 true，否则返回 false。元素不必连续。

i < j < k   且   nums[i] < nums[k] < nums[j]

约束

  • n == nums.length
  • 1 <= n <= 2 × 105
  • -109 <= nums[i] <= 109

返回类型：boolean

Example 01
输入：nums = [1,2,3,4]
输出：false
解释：序列中不存在 132 模式。
Example 02
输入：nums = [3,1,4,2]
输出：true
解释：[1,4,2] 构成 132 模式。
Example 03
输入：nums = [-1,3,2,0]
输出：true
解释：[-1,3,2]、[-1,3,0] 和
[-1,2,0] 均满足条件。

04 / Deep Dive

单调栈：先锁定“2”，再寻找“1”

O(n) time · O(n) space
命名提醒：“132”描述的是数值相对大小，不是三个元素的实际值。nums[i] 最小，nums[j] 最大，nums[k] 居中。

核心洞察

如果从右向左扫描，那么当前位置天然可以尝试扮演最左侧的“1”。右侧已经扫描过的元素负责组成“3”和“2”。

维护一个单调递减栈保存可能的“3”。当当前值比栈顶大时，被弹出的较小值便找到了左侧更大的搭档，所以它可以成为“2”。用 third 记录这些合法“2”中的最大值。以后只要出现 nums[i] < third，三者立即齐全。

完整过程

  1. 初始化空栈，并令 third = -∞。
  2. 从右到左遍历数组；先判断当前值是否严格小于 third。
  3. 若是，当前值就是“1”，而 third 已有对应的“3”，返回 true。
  4. 否则，持续弹出所有小于当前值的栈顶；弹出值已有当前值作为更大的左侧“3”，用它更新 third。
  5. 把当前值压栈。遍历结束仍未命中则返回 false。

正确性说明

不变式：处理下标 i 之前，栈中只含 i 右侧尚可充当“3”的值，且从栈底到栈顶严格非增；third 若非负无穷，则一定存在右侧下标 j < k 使 third = nums[k] < nums[j]。

弹栈时，当前元素位于被弹元素左侧且更大，因此为新的“2”候选建立了真实的“3”。若之后遇到 nums[i] < third，结合已存在的 j,k 就得到 i < j < k 与严格大小关系，返回结果必然正确。

反过来，若存在 132 模式，当扫描到对应的“3”时，“2”会被保留或弹出为不小于该值的合法候选；继续扫描至对应的“1”时必满足 nums[i] < third，因此算法不会漏解。

边界与复杂度

  • 少于 3 个元素不可能构成模式，流程会自然返回 false。
  • 相等值不能组成严格不等式；比较必须使用 <，弹栈也只弹严格更小值。
  • 负数无需特殊处理；初始“2”候选用负无穷或小于值域下界的哨兵。
  • 每个元素最多入栈、出栈各一次，时间复杂度 O(n)；最坏栈占 O(n) 空间。

class Solution {
    public boolean find132pattern(int[] nums) {
        int third = Integer.MIN_VALUE;
        int[] stack = new int[nums.length];
        int size = 0;

        for (int i = nums.length - 1; i >= 0; i--) {
            if (nums[i] < third) {
                return true;
            }
            while (size > 0 && stack[size - 1] < nums[i]) {
                third = Math.max(third, stack[--size]);
            }
            stack[size++] = nums[i];
        }
        return false;
    }
}

var find132pattern = function(nums) {
    const stack = [];
    let third = -Infinity;

    for (let i = nums.length - 1; i >= 0; i--) {
        if (nums[i] < third) {
            return true;
        }
        while (stack.length > 0 && stack[stack.length - 1] < nums[i]) {
            third = Math.max(third, stack.pop());
        }
        stack.push(nums[i]);
    }
    return false;
};
class Solution:
    def find132pattern(self, nums: List[int]) -> bool:
        stack = []
        third = float("-inf")

        for value in reversed(nums):
            if value < third:
                return True
            while stack and stack[-1] < value:
                third = max(third, stack.pop())
            stack.append(value)

        return False
class Solution {
public:
    bool find132pattern(vector<int>& nums) {
        vector<int> stack;
        int third = INT_MIN;

        for (int i = static_cast<int>(nums.size()) - 1; i >= 0; --i) {
            if (nums[i] < third) {
                return true;
            }
            while (!stack.empty() && stack.back() < nums[i]) {
                third = max(third, stack.back());
                stack.pop_back();
            }
            stack.push_back(nums[i]);
        }
        return false;
    }
};
06 / Trade-offs

替代方案与面试追问

替代方案

  • 前缀最小值 + 有序集合：枚举中间的“3”，左侧最小值充当“1”，在右侧有序集合中查询严格位于二者之间的值。时间 O(n log n)，思路直观但结构更重。
  • 枚举与预处理：只记录前缀最小仍不足以快速确认右侧区间，若线性扫描右侧会退化到 O(n²)。
  • 暴力三枚举：O(n³) 仅适合解释定义，无法承受 2 × 10⁵ 的数据规模。

面试追问

  • 如何返回一组下标？栈中保存值和下标；更新 third 时同步记录对应的 j,k，命中时补上当前 i。
  • 为什么要从右向左？这样一旦得到“2”，其对应的“3”与索引顺序已经成立，只缺更左边的“1”。
  • 若数据持续流式到达？右向左扫描不适用于未知未来的流；可考虑维护前缀信息与支持区间查询的有序结构，代价通常升为对数级。
  • 值域更大怎么办？算法仅比较、不做加减；为哨兵选择语言的负无穷或更宽整数类型即可。

常见错误

  • 把模式理解成连续子数组；题目要求的是子序列。
  • 将严格比较误写成 <=，导致相等值被错误接受。
  • 只保存最近一次弹出值，却没有维持合法候选的最大值，破坏 third 的语义。
  • 从左向右照搬同一栈逻辑，索引方向不再自动满足。
  • 先弹栈再检查 nums[i] < third，混淆当前元素扮演的角色。

快速自检

  • 递增数组：右扫时不断弹栈，但左侧不存在更小“1”，结果为 false。
  • 递减数组：不会产生任何合法“2”候选，结果为 false。
  • [3,1,4,2]：扫描 4 时确定“2”为 2，扫描 1 时命中。
  • [1,0,1,-4,-3]：相对顺序无法同时满足，结果为 false。
