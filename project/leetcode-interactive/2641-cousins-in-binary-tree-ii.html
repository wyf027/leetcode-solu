2641二叉树的
堂兄弟节点 II

把树中每个节点的值，替换为同一深度、但父节点不同的所有节点之和；返回修改后的原树根节点。

Relation Card

堂兄弟节点：深度相同，父节点不同。节点深度等于从根到该节点路径上的边数。

输入 / 输出参数

replaceValueInTree(root: TreeNode): TreeNode

Problem Brief

题意与样例

给定一棵非空二叉树。对每个节点，找到所有与它深度相同但父节点不同的节点，将这些节点的原始值相加，并用结果替换当前节点的值。若没有堂兄弟，替换为 0。

Example 01
输入root = [5,4,9,1,10,null,7]
输出[0,0,0,7,7,null,11]

节点 1 和 10 的堂兄弟是 7；节点 7 的堂兄弟是 1 与 10。根节点以及第二层节点都没有堂兄弟。

Example 02
输入root = [3,1,2]
输出[0,0,0]

根没有同层节点；1 与 2 共享父节点，因此互为兄弟而不是堂兄弟，三者结果都为 0。

Constraints
  • 树中节点数为 [1, 10⁵]。
  • 1 ≤ Node.val ≤ 10⁴。

One-pass BFS

完整题解

逐层读取下一层原值，再原地写回堂兄弟和。

时间O(n)
空间O(w)

核心洞察

对下一层的任意节点，它的堂兄弟恰好是“下一层全部节点”减去“与它共享父节点的所有孩子”。二叉树中，同父组最多包含左右两个孩子。

新值 = 下一层原值总和 − 当前父节点的孩子原值和

因此不需要为每个节点寻找堂兄弟。处理当前层父节点时，先把其所有孩子的原值求和，再按父节点分组统一改写孩子。

完整过程

  1. 根节点没有堂兄弟，先将根值设为 0。
  2. 令当前层为根所在层。遍历当前层的所有父节点，收集下一层节点，并计算下一层节点的原值总和 nextSum。
  3. 再次遍历当前层。对每个父节点，先计算其左右孩子的原值和 siblingSum。
  4. 把该父节点每个非空孩子的值写为 nextSum - siblingSum。
  5. 下一层成为当前层，重复直到没有节点。

关键顺序是“先统计整层，再改写”。这样统计阶段读到的一定是原始值。

正确性

引理：对同一父节点的任意孩子，集合“同层全部节点”去掉“该父节点的全部孩子”后，剩余节点恰好都是它的堂兄弟。因为剩余节点与它深度相同，且父节点均不同；反之，任何堂兄弟都必在这个剩余集合中。

归纳：根节点没有堂兄弟，置 0 正确。假设开始处理某一层时，其孩子仍保留原值。算法先用这些原值算出下一层总和；随后对每个父节点，依据引理用总和减去同父组原值和，得到每个孩子全部堂兄弟的值之和。因此下一层所有节点都被正确替换。逐层推进后，整棵树均正确。

边界与复杂度

  • 单节点：根直接变为 0。
  • 只有一个孩子：同父组只包含该孩子本身，仍按同一公式处理。
  • 退化链：每层只有一个节点，没有堂兄弟，结果全为 0。
  • 数值范围：最大层和不超过 10⁵ × 10⁴ = 10⁹。

每个节点被常数次访问，时间复杂度 O(n)；层序数组最多保存树的最大宽度 w 个节点，额外空间 O(w)。

Java 
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode replaceValueInTree(TreeNode root) {
        java.util.List<TreeNode> level = java.util.List.of(root);
        root.val = 0;

        while (!level.isEmpty()) {
            java.util.List<TreeNode> next = new java.util.ArrayList<>();
            int nextSum = 0;

            for (TreeNode node : level) {
                if (node.left != null) {
                    nextSum += node.left.val;
                    next.add(node.left);
                }
                if (node.right != null) {
                    nextSum += node.right.val;
                    next.add(node.right);
                }
            }

            for (TreeNode node : level) {
                int siblingSum = (node.left == null ? 0 : node.left.val)
                    + (node.right == null ? 0 : node.right.val);
                if (node.left != null) node.left.val = nextSum - siblingSum;
                if (node.right != null) node.right.val = nextSum - siblingSum;
            }
            level = next;
        }
        return root;
    }
}

C++ 
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* replaceValueInTree(TreeNode* root) {
        std::vector<TreeNode*> level{root};
        root->val = 0;

        while (!level.empty()) {
            std::vector<TreeNode*> next;
            int nextSum = 0;

            for (TreeNode* node : level) {
                if (node->left) {
                    nextSum += node->left->val;
                    next.push_back(node->left);
                }
                if (node->right) {
                    nextSum += node->right->val;
                    next.push_back(node->right);
                }
            }

            for (TreeNode* node : level) {
                int siblingSum = (node->left ? node->left->val : 0)
                    + (node->right ? node->right->val : 0);
                if (node->left) node->left->val = nextSum - siblingSum;
                if (node->right) node->right->val = nextSum - siblingSum;
            }
            level = std::move(next);
        }
        return root;
    }
};

替代方案

也可以两次 DFS：第一次记录每层原值总和，第二次携带同父组原值和并更新节点。时间仍为 O(n)，但深度可能达到 10⁵，递归实现存在调用栈溢出风险；迭代 BFS 更直接。

面试追问

  • 为什么不能边求层和边改值？ 因为后续父节点还需要读取孩子的原值；提前覆盖会污染层和或同父组和。
  • 能否做到 O(1) 额外空间？ 一般二叉树的层序处理中，需要保存下一层节点；若允许利用或改造节点指针结构，才可能讨论更激进的空间优化。
  • 推广到多叉树呢？ 公式不变：下一层总和减去当前父节点全部孩子的原值和。

常见错误

  • 只减去当前节点和它的一个兄弟，遗漏同父节点的其他孩子；推广到多叉树时尤其明显。
  • 第一遍扫描下一层时就写新值，导致后续计算读取到被修改的数据。
  • 误把兄弟节点计入堂兄弟和；同父节点必须整体排除。
  • 使用递归 DFS 却忽略最深 10⁵ 层带来的栈风险。
