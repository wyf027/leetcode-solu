独立题解

核心洞察：连续段与累计数量分开计算

先把三种奖牌列展开成 (contest_id, user_id) 集合。对每位用户按比赛编号编号：若比赛 ID 连续，ID 与 ROW_NUMBER 的差值保持不变，因此相同差值构成一个连续获奖段。另从原表统计金牌，两类合格用户取并集。

完整过程

  1. 用 UNION 合并三列，保证每人每场至多一行。
  2. 窗口按 user_id 分区，按 contest_id 排序，计算 grp = contest_id − ROW_NUMBER()。
  3. 按 user_id、grp 分组，保留长度至少 3 的段。
  4. 按 gold_medal 分组，保留金牌数至少 3 的用户。
  5. UNION 去重后关联 Users，输出 name 与 mail。

以 Bob 为例：比赛 ID 为 [190,191,192,194,195,196]，行号为 [1,2,3,4,5,6]，差值为 [189,189,189,190,190,190]，恰好形成两个长度为 3 的连续段。

正确性

同一用户相邻两条去重记录的行号差恒为 1；差值相等当且仅当比赛 ID 差也为 1。比赛 ID 的跳跃会让差值严格增加，故一个差值分组恰好对应一个最大连续获奖段。段长至少 3 当且仅当连续条件成立。金牌列每场只贡献一条记录，计数至少 3 等价于三场不同比赛夺金。最后取并集恰好实现逻辑“或”，去重防止重复候选人。

边界与常见错误

  • 三枚不同颜色奖牌不等于连续三场；需判断比赛 ID。
  • 金牌条件不要求连续；不能把两条件用 AND 连接。
  • 先按用户分区，分组时也要带 user_id；不同用户可能有相同 grp。
  • 多个连续段、两条件同时成立，均只输出该用户一次。
  • 空表或少于三场返回空结果；重复姓名不能作为用户标识。
  • 源表展示顺序无保证，窗口必须显式排序；最终输出顺序不限。

复杂度

设比赛数为 C，用户数为 U，奖牌展开量 M ≤ 3C。SQL 的典型排序执行计划约为 O(C log C + U)，中间结果空间 O(C + U)；实际耗时由数据库的去重、连接算法、索引与执行计划决定。下方四语言采用哈希集合寻找 x、x+1、x+2，期望时间 O(C + U)、空间 O(C + U)，依赖常见哈希平均性能。

官方可提交语言主解 · MySQL 8+

WITH medals AS (
    SELECT contest_id, gold_medal AS user_id FROM Contests
    UNION
    SELECT contest_id, silver_medal FROM Contests
    UNION
    SELECT contest_id, bronze_medal FROM Contests
), ranked AS (
    SELECT user_id, contest_id,
           contest_id - ROW_NUMBER() OVER (
               PARTITION BY user_id ORDER BY contest_id
           ) AS grp
    FROM medals
), candidates AS (
    SELECT user_id FROM ranked
    GROUP BY user_id, grp
    HAVING COUNT(*) >= 3
    UNION
    SELECT gold_medal AS user_id FROM Contests
    GROUP BY gold_medal
    HAVING COUNT(*) >= 3
)
SELECT u.name, u.mail
FROM Users u JOIN candidates c ON u.user_id = c.user_id;

替代方案

固定三场可对展开后的奖牌表自连接三次，匹配同一用户和 ID+1、ID+2；也可使用 LEAD(contest_id,2)，比较第三条与当前条是否相差 2。两者都需要每人每场先去重。差值分组更方便扩展为任意长度。

面试追问

若阈值改为 n：连续段 HAVING COUNT(*) ≥ n，金牌条件保持原来的 3，除非业务也要求修改。若“连续”指用户实际参加的比赛：必须取得完整参赛表（包括未获奖记录），按用户参赛顺序编号，再对获奖行的参赛序号做连续段识别，不能继续直接比较比赛 ID。

import java.util.*;

// Local reference; Java 17 records describe the table rows.
class Solution {
    record Contest(int id, int gold, int silver, int bronze) {}
    record User(int id, String mail, String name) {}
    record Candidate(String name, String mail) {}

    public List<Candidate> findInterviewCandidates(
            List<Contest> contests, List<User> users) {
        Map<Integer, Set<Long>> medals = new HashMap<>();
        Map<Integer, Integer> gold = new HashMap<>();
        for (Contest c : contests) {
            gold.merge(c.gold(), 1, Integer::sum);
            for (int u : new int[]{c.gold(), c.silver(), c.bronze()})
                medals.computeIfAbsent(u, k -> new HashSet<>()).add((long)c.id());
        }
        List<Candidate> result = new ArrayList<>();
        for (User u : users) {
            Set<Long> ids = medals.getOrDefault(u.id(), Collections.emptySet());
            boolean ok = gold.getOrDefault(u.id(), 0) >= 3;
            for (long x : ids)
                if (ids.contains(x + 1) && ids.contains(x + 2)) {
                    ok = true;
                    break;
                }
            if (ok) result.add(new Candidate(u.name(), u.mail()));
        }
        return result;
    }
}

JavaScript

// Local reference. Contests: [id,gold,silver,bronze]
// Users: [id,mail,name]. Returns [{name,mail}].
function findInterviewCandidates(contests, users) {
  const medals = new Map(), gold = new Map();
  for (const [id, g, s, b] of contests) {
    gold.set(g, (gold.get(g) || 0) + 1);
    for (const u of new Set([g, s, b])) {
      if (!medals.has(u)) medals.set(u, new Set());
      medals.get(u).add(id);
    }
  }
  return users.filter(([u]) => {
    if ((gold.get(u) || 0) >= 3) return true;
    const ids = medals.get(u) || new Set();
    return [...ids].some(x => ids.has(x + 1) && ids.has(x + 2));
  }).map(([, mail, name]) => ({name, mail}));
}

Python

# Local reference: rows use the same order as the example.
def find_interview_candidates(contests, users):
    medals, gold = {}, {}
    for cid, g, s, b in contests:
        gold[g] = gold.get(g, 0) + 1
        for uid in {g, s, b}:
            medals.setdefault(uid, set()).add(cid)
    result = []
    for uid, mail, name in users:
        ids = medals.get(uid, set())
        consecutive = any(x + 1 in ids and x + 2 in ids for x in ids)
        if gold.get(uid, 0) >= 3 or consecutive:
            result.append({"name": name, "mail": mail})
    return result

C++

#include <vector>
#include <string>
#include <unordered_map>
#include <unordered_set>
using namespace std;

struct Contest { int id, gold, silver, bronze; };
struct User { int id; string mail, name; };
struct Candidate { string name, mail; };

vector<Candidate> findInterviewCandidates(
    const vector<Contest>& contests, const vector<User>& users) {
    unordered_map<int, unordered_set<long long>> medals;
    unordered_map<int, int> gold;
    for (const auto& c : contests) {
        ++gold[c.gold];
        for (int u : {c.gold, c.silver, c.bronze})
            medals[u].insert(c.id);
    }
    vector<Candidate> result;
    for (const auto& u : users) {
        bool ok = gold[u.id] >= 3;
        const auto& ids = medals[u.id];
        for (long long x : ids)
            if (ids.count(x + 1) && ids.count(x + 2)) {
                ok = true;
                break;
            }
        if (ok) result.push_back({u.name, u.mail});
    }
    return result;
}
