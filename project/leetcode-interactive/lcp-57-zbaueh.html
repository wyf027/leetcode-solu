LCP 57. 打地鼠

3×3 棋盘看似很小，时间却可达十亿。关键不是逐秒模拟，而是把“超过 4 秒必然可达”的历史压缩成一个最大值，只精查最近 3 秒的候选。

时间 DP棋盘直径 = 4O(n log n)

题意

棋盘坐标为 (x, y)，moles[i] = [t, x, y] 表示地鼠在第 t 秒出现，到第 t + 1 秒消失。锤子第 0 秒在 (1, 1)，每秒可上下左右移动一格或不动，敲击不耗时。求最多敲到的地鼠数。

示例 1

moles = [[1,1,0],[2,0,1],[4,2,2]]

输出：2

示例 2

moles = [[2,0,2],[5,2,0],[4,1,0],[1,2,1],[3,0,2]]

输出：3

约束：1 ≤ moles.length ≤ 10⁵，0 ≤ t ≤ 10⁹。同一时刻同一坐标至多一只；展示内参数始终写成 moles = […]。

交互：时间 DP

每项格式为 t,x,y，用分号分隔。

题解：远历史压缩，近历史枚举

核心洞察

棋盘两点最大曼哈顿距离为 4。对当前时刻 t，任何时刻 ≤ t - 4 的已击中地鼠都一定能到达当前位置，因此只保留它们的最大 DP 值。时差 1、2、3 的事件才需逐个按距离判断；每秒最多 9 个，候选为常数。

完整过程

  1. 按时间分组排序，避免同一秒互相转移。
  2. 把时间差 ≥ 4 的 DP 值吸收到 farBest。
  3. 枚举最近 3 秒事件，按曼哈顿距离转移。
  4. 从初始中心 (1,1) 也可直接走到当前地鼠。

边界与复杂度

第 0 秒只有中心地鼠可被敲到；同一时刻不能连续敲两个不同格。排序 O(n log n)，每个事件只检查最近常数个候选，DP 为 O(n)，总时间 O(n log n)、空间 O(n)。

替代方案

也可向前暴力检查最近 45 个事件：4 秒内最多 4×9 个，加同秒上界，常数足够；但远历史压缩的表达更直接。

常见错误

  • 让同一秒的地鼠相互转移。
  • 漏掉第 0 秒中心位置可立即敲击。
  • 仅用相邻事件 DP，遗漏时间间隔较大时“必达”的历史最优。

面试追问

若棋盘为 R×C，直径变为 R + C - 2；把 4 和最近 3 秒替换为该直径及其前一段即可。若移动每秒可走 k 格，则有效直径是 ceil((R+C-2)/k)。

// Java
class Solution {
  public int getMaximumNumber(int[][] m) {
    java.util.Arrays.sort(m, (a,b) -> Integer.compare(a[0], b[0]));
    int n=m.length, ans=0, far=0, p=0; boolean hasFar=false; int[] dp=new int[n];
    for(int l=0;l<n;){ int r=l; while(r<n&&m[r][0]==m[l][0]) r++;
      while(p<l && m[p][0]<=m[l][0]-4) { if(dp[p]>0){far=Math.max(far,dp[p]);hasFar=true;} p++; }
      for(int i=l;i<r;i++){ int best=Math.abs(m[i][1]-1)+Math.abs(m[i][2]-1)<=m[i][0]?1:0;
        if(hasFar) best=Math.max(best, far+1);
        for(int j=p;j<l;j++) if(dp[j]>0 && Math.abs(m[i][1]-m[j][1])+Math.abs(m[i][2]-m[j][2])<=m[i][0]-m[j][0]) best=Math.max(best,dp[j]+1);
        dp[i]=best; ans=Math.max(ans,best); } l=r; }
    return ans;
  }
}

class Solution:
    def getMaximumNumber(self, moles: List[List[int]]) -> int:
        moles.sort(); n=len(moles); dp=[0]*n; ans=far=p=0; has_far=False; l=0
        while l<n:
            r=l
            while r<n and moles[r][0]==moles[l][0]: r+=1
            while p<l and moles[p][0]<=moles[l][0]-4:
                if dp[p]: far=max(far,dp[p]); has_far=True
                p+=1
            for i in range(l,r):
                t,x,y=moles[i]; best=1 if abs(x-1)+abs(y-1)<=t else 0
                if has_far: best=max(best,far+1)
                for j in range(p,l):
                    if dp[j] and abs(x-moles[j][1])+abs(y-moles[j][2])<=t-moles[j][0]: best=max(best,dp[j]+1)
                dp[i]=best; ans=max(ans,best)
            l=r
        return ans
