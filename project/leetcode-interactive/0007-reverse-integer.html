MANUAL 02 · PROCEDURE

完整解题过程

  1. 1

    用 digit=x%10 取得末位，再用向 0 截断的整数除法移除末位。

  2. 2

    正溢出：rev>214748364，或相等且 digit>7，立即返回 0。

  3. 3

    负溢出：rev<−214748364，或相等且 digit<−8，立即返回 0。

  4. 4

    只有闸门通过后才执行 rev=rev×10+digit；x 归零时返回 rev。

WHY 7 / −8?

边界最后一位不对称

INT_MAX = 2147483647

INT_MIN = −2147483648

当 rev 已经等于 ±214748364 时，只剩最后一位决定是否越界。负数范围比正数多容纳 1。

SAFETY CASES

边界情况

ZERO

x = 0

循环不执行，直接返回初始 rev=0。

TRAILING ZERO

120 → 21

首次弹出 0，推入空累计器仍为 0，前导零自然消失。

NEGATIVE

−123 → −321

Java/C++ 的 % 保留被除数符号；Python 需特别处理负余数语义。

INT MIN

−2147483648

不能先取绝对值，32 位中 abs(INT_MIN) 本身就溢出。

TIME

O(log |x|)

十进制位数决定循环次数，32 位最多 10 次。

SPACE

O(1)

只维护 x、digit、rev。

class Solution {
    public int reverse(int x) {
        int reversed = 0;

        while (x != 0) {
            int digit = x % 10;
            x /= 10;

            if (reversed > Integer.MAX_VALUE / 10
                    || (reversed == Integer.MAX_VALUE / 10 && digit > 7)) {
                return 0;
            }
            if (reversed < Integer.MIN_VALUE / 10
                    || (reversed == Integer.MIN_VALUE / 10 && digit < -8)) {
                return 0;
            }
            reversed = reversed * 10 + digit;
        }
        return reversed;
    }
}
var reverse = function (x) {
  const MAX_DIV_10 = 214748364;
  const MIN_DIV_10 = -214748364;
  let reversed = 0;

  while (x !== 0) {
    const digit = x % 10;
    x = Math.trunc(x / 10);

    if (reversed > MAX_DIV_10 ||
        (reversed === MAX_DIV_10 && digit > 7)) return 0;
    if (reversed < MIN_DIV_10 ||
        (reversed === MIN_DIV_10 && digit < -8)) return 0;

    reversed = reversed * 10 + digit;
  }
  return reversed;
};

面试高频追问

为什么不能算完后再比较？

在 32 位环境中，溢出发生的那次乘加已经产生未定义或错误结果，之后比较为时已晚。

负数取余为什么能工作？

Java/C++ 的整数除法向 0 截断，余数与被除数同号；Python 的 // 向下取整，所以代码显式模拟向 0 截断。

为什么不用 abs(x)？

INT_MIN 的绝对值是 2147483648，超出 INT_MAX；直接保留符号逐位处理最安全。

常见错误告警

  • ❌ 使用 long/long long：直接违反题目环境限制，绕开了核心考点。
  • ❌ 乘完再判断：溢出已经发生，结果不可信。
  • ❌ 正负都用末位 7：INT_MIN 的最后一位阈值是 −8。
  • ❌ Python 直接用负数 % 10：−123 % 10 得 7，不是 −3。
  • ❌ 先 abs(INT_MIN)：固定 32 位语言中会立即溢出。

60-SECOND RECAP

“我每轮用 x%10 弹出末位，并用向 0 截断的除法缩短 x。在执行 reversed×10+digit 前，先与 INT_MAX/10、INT_MIN/10 比较；等于阈值时再检查最后一位 7 或 −8。通过才推入，否则返回 0。时间与位数成正比，空间 O(1)，不使用 64 位整数。”
