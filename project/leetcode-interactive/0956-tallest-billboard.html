Tallest Billboard

最高的广告牌

把钢筋分给左右支架或舍弃，使两边总长度相等；求这个公共高度的最大值。

题目

给定整数数组 rods，每根钢筋最多使用一次。你可以把选中的钢筋焊接成广告牌左右两个支架，也可以不使用某些钢筋。两个支架必须等高。返回能够得到的最大相等高度；若无法形成正高度的等高支架，返回 0。

函数参数：tallestBillboard(rods: integer[]): integer

示例 1
输入：rods = [1,2,3,6]
输出：6
左侧 1+2+3，右侧 6。
示例 2
输入：rods = [1,2,3,4,5,6]
输出：10
可取 2+3+5 与 4+6。
示例 3
输入：rods = [1,2]
输出：0
无法组成两个等高支架。

约束

  • 1 <= rods.length <= 20
  • 1 <= rods[i] <= 1000
  • sum(rods[i]) <= 5000

准备好看完整题解了吗？

建议先操作可视化，并尝试解释为什么只记录“较矮侧最大高度”就足够。

题解：用差值压缩两个支架

核心洞察

若直接记录左右高度，需要二维状态。令 dp[d] 表示两侧高度差为 d 时，较矮侧能达到的最大高度。答案就是 dp[0]。对每根长度 x，从旧状态复制转移，确保一根钢筋不会重复使用。

完整过程

  1. 初始化 dp = {0: 0}。
  2. 不使用 x：状态保持。
  3. 把 x 放到较高侧：新差值 d+x，较矮侧高度不变。
  4. 把 x 放到较低侧：新差值 |d-x|，较矮侧增加 min(d,x)。
  5. 相同差值只保留较矮侧高度最大的状态。

正确性

不变式：处理前 i 根钢筋后，dp[d] 恰为所有可行分配中差值为 d 的最大较矮侧高度。初始空分配成立。第 i+1 根钢筋只有舍弃、加入高侧、加入低侧三种互斥选择，转移完整枚举它们；对同一差值取最大值不会丢失更优后续解，因为未来转移只依赖差值和较矮侧高度。因此不变式归纳成立。最终 d=0 表示两侧等高，dp[0] 即最大公共高度。

边界与复杂度

  • 单根或无法平分时，初始的 dp[0]=0 保证返回 0。
  • 重复长度按不同钢筋处理，每根仍只用一次。
  • 设所有钢筋之和为 S：时间 O(nS)，空间 O(S)。

替代方案

也可用“中途相遇”：把数组分半，枚举每根钢筋的三种归属，并按差值合并两半，适合 n 小而总和很大；本题 S ≤ 5000，差值 DP 更直接。二维背包记录两侧高度则需要约 O(S²) 空间，不划算。

面试追问

  • 为什么转移必须基于快照？原地遍历哈希表可能在同一轮重复使用钢筋。
  • 为什么加到低侧时增加 min(d,x)？它正是两边共同增加的可匹配部分。
  • 如果要恢复具体选择？为每层状态保存前驱差值与本次决策。

常见错误

  • 只做普通子集和，忽略钢筋还可以被舍弃。
  • 把 dp[d] 误定义为总使用长度，导致转移混乱。
  • 更新低侧时直接加 x，而不是 min(d,x)。

import java.util.*;

class Solution {
    public int tallestBillboard(int[] rods) {
        Map<Integer, Integer> dp = new HashMap<>();
        dp.put(0, 0);
        for (int x : rods) {
            Map<Integer, Integer> next = new HashMap<>(dp);
            for (Map.Entry<Integer, Integer> e : dp.entrySet()) {
                int d = e.getKey(), low = e.getValue();
                next.merge(d + x, low, Math::max);
                next.merge(Math.abs(d - x), low + Math.min(d, x), Math::max);
            }
            dp = next;
        }
        return dp.get(0);
    }
}

var tallestBillboard = function(rods) {
  let dp = new Map([[0, 0]]);
  for (const x of rods) {
    const next = new Map(dp);
    for (const [d, low] of dp) {
      next.set(d + x, Math.max(next.get(d + x) ?? -1, low));
      const nd = Math.abs(d - x);
      next.set(nd, Math.max(next.get(nd) ?? -1, low + Math.min(d, x)));
    }
    dp = next;
  }
  return dp.get(0);
};
from typing import List

class Solution:
    def tallestBillboard(self, rods: List[int]) -> int:
        dp = {0: 0}
        for x in rods:
            nxt = dp.copy()
            for d, low in dp.items():
                nxt[d + x] = max(nxt.get(d + x, -1), low)
                nd = abs(d - x)
                nxt[nd] = max(nxt.get(nd, -1), low + min(d, x))
            dp = nxt
        return dp[0]
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int tallestBillboard(vector<int>& rods) {
        int sum = 0;
        for (int x : rods) sum += x;
        vector<int> dp(sum + 1, -1);
        dp[0] = 0;
        for (int x : rods) {
            vector<int> next(dp);
            for (int d = 0; d <= sum - x; ++d) {
                if (dp[d] < 0) continue;
                next[d + x] = max(next[d + x], dp[d]);
                next[abs(d - x)] = max(next[abs(d - x)], dp[d] + min(d, x));
            }
            dp.swap(next);
        }
        return dp[0];
    }
};
