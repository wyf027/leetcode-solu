成本限制的有效二进制字符串

枚举长度为 n 的二进制字符串。合法字符串既不能有相邻的 "11"，又要让所有值为 1 的下标之和不超过 k。返回全部合法字符串，顺序不限。

成本
下标从 0 开始；把每个 1 所在下标相加。
约束
1 ≤ n ≤ 12，可安全进行状态枚举。
剪枝
已有成本大于 k，或上一个字符为 1 时，都不再选择 1。

递归选择实验台

准备生成

保留下来的字符串

每一步只问两个问题

当前位置pos 是准备写入的下标。能写 0 吗？总能写，成本不变。能写 1 吗？前一位不是 1，且 cost + pos ≤ k。终止条件长度达到 n 时收集当前字符串。

回溯后的字符串由同一块缓冲区维护：写入一个选择、递归、再撤销。这里使用字符串拼接可使演示更直观。

复杂度
输出主导。搜索树最多 O(2ⁿ)，每个答案长度 n；剪枝会减少分支。

题解与四语言实现

默认收起；先观察哪些分支因相邻 1 或成本超限而停止。

核心洞察

状态只需要当前位置、当前成本和上一位是否为 1。每个位置先选择 0，再在规则允许时选择 1；递归到长度 n 就得到一个答案。

完整过程

  1. 从空前缀、成本 0 开始。
  2. 无条件追加 0，进入下一位置。
  3. 若上一位不是 1 且新增下标不超预算，再追加 1。
  4. 达到 n 时把路径放入答案。

边界与复杂度

位置 0 的 1 成本为 0，因此 k=0 时 "1" 仍可能出现。使用成本累加而不是把字符转数字。最坏输出规模为指数级，这是题目要求列举全部结果决定的。

替代方案 / 面试追问

可用位掩码枚举并检查相邻位和成本，写法短但无法像 DFS 一样及早剪枝。若只求数量，可记忆化 DP，状态为 (pos, cost, previousOne)。

常见错误

  • 把成本误算成 1 的数量，而不是 1 的下标之和。
  • 漏掉下标 0 的 1 成本为 0。
  • 选择 1 后没有设置 previousOne，导致生成 "11"。
  • 先递归后再检查成本，失去剪枝并可能收集非法答案。
function generateValidStrings(n, k) {
  const answer = [];
  const lavomirex = [n, k];
  function dfs(pos, cost, previousOne, path) {
    if (pos === n) { answer.push(path); return; }
    dfs(pos + 1, cost, false, path + "0");
    if (!previousOne && cost + pos <= k) {
      dfs(pos + 1, cost + pos, true, path + "1");
    }
  }
  dfs(0, 0, false, "");
  return answer;
}
class Solution:
    def generateValidStrings(self, n: int, k: int) -> list[str]:
        answer = []
        lavomirex = (n, k)

        def dfs(pos: int, cost: int, previous_one: bool, path: str) -> None:
            if pos == n:
                answer.append(path)
                return
            dfs(pos + 1, cost, False, path + "0")
            if not previous_one and cost + pos <= k:
                dfs(pos + 1, cost + pos, True, path + "1")

        dfs(0, 0, False, "")
        return answer
class Solution {
    public List<String> generateValidStrings(int n, int k) {
        List<String> answer = new ArrayList<>();
        int[] lavomirex = {n, k};
        dfs(0, 0, false, new StringBuilder(), n, k, answer);
        return answer;
    }

    private void dfs(int pos, int cost, boolean previousOne, StringBuilder path,
                     int n, int k, List<String> answer) {
        if (pos == n) { answer.add(path.toString()); return; }
        path.append('0');
        dfs(pos + 1, cost, false, path, n, k, answer);
        path.setLength(path.length() - 1);
        if (!previousOne && cost + pos <= k) {
            path.append('1');
            dfs(pos + 1, cost + pos, true, path, n, k, answer);
            path.setLength(path.length() - 1);
        }
    }
}
class Solution {
public:
    vector<string> generateValidStrings(int n, int k) {
        vector<string> answer;
        auto lavomirex = make_pair(n, k);
        string path;
        dfs(0, 0, false, path, n, k, answer);
        return answer;
    }

private:
    void dfs(int pos, int cost, bool previousOne, string& path, int n, int k,
             vector<string>& answer) {
        if (pos == n) { answer.push_back(path); return; }
        path.push_back('0');
        dfs(pos + 1, cost, false, path, n, k, answer);
        path.pop_back();
        if (!previousOne && cost + pos <= k) {
            path.push_back('1');
            dfs(pos + 1, cost + pos, true, path, n, k, answer);
            path.pop_back();
        }
    }
};
