Problem 414

第三大的数

Third Maximum Number

给定一个整数数组 nums，请返回数组中所有不同数值里的第三大值；如果不同数值不足三个，则返回数组中的最大值。

“第三大”按不同数值排名。重复出现的相同数字只占一个名次，例如两个 2 不会占据第二名和第三名。

官方示例

示例 1

输入：nums = [3, 2, 1] 输出：1 解释：三个不同数值依次为 3、2、1，第三大值是 1。

示例 2

输入：nums = [1, 2] 输出：2 解释：不存在第三个不同值，因此返回最大值 2。

示例 3

输入：nums = [2, 2, 3, 1] 输出：1 解释：重复的 2 只计一个名次；不同值 3、2、1 中第三大是 1。

函数签名

thirdMax(nums: integer[]) -> integer

约束

  • 1 <= nums.length <= 104
  • -231 <= nums[i] <= 231 - 1

Solution

一次扫描，维护三个不同最大值

O(n) 时间 · O(1) 空间

核心洞察

答案只依赖最大的三个不同值，所以无需保存全部元素或完整排序。扫描时维护 first > second > third 三个可空席位即可。

更新顺序

  1. 若当前值已在任一席位，直接跳过。
  2. 若它超过第一名，旧第一、第二名依次后移。
  3. 否则依次尝试插入第二名或第三名。

完整过程

  1. 初始化三个空席位 first、second、third。
  2. 顺序读取 nums。先判重，保证三个席位代表不同数值。
  3. 从最高席位向最低席位判断插入位置；插入较高位置时，把原有值向后移动，保持严格降序。
  4. 扫描结束后，若 third 已存在就返回它；否则不同值不足三个，返回 first。

正确性证明

循环不变式：处理完任意前缀后，三个非空席位恰好保存该前缀最大的至多三个不同值，并严格递减。

保持：重复值不改变不同值集合；新值若进入前三，其插入与后移会保留正确次序；若不进入前三，原席位仍正确。

终止：扫描完整个数组，不变式覆盖全部元素。第三席位存在时它就是第三大不同值；否则第一席位是全局最大值，正好符合返回规则。

边界处理

  • 数组只有一个或两个不同值：返回第一名。
  • 大量重复值：先判重，避免重复占位。
  • 包含负数：所有比较仍然有效。
  • 包含 -231：不可把它当作“空”的哨兵；使用空引用、None 或 optional。

时间复杂度

O(n)，每个元素只进行常数次比较。

空间复杂度

O(1)，只维护三个席位。

替代方案

去重后排序最直观，但通常需要 O(n log n) 时间及额外空间；有序集合可行，但对固定的三个席位而言偏重。

Java
class Solution {
    public int thirdMax(int[] nums) {
        Long first = null;
        Long second = null;
        Long third = null;

        for (int num : nums) {
            long value = num;
            if ((first != null && value == first)
                    || (second != null && value == second)
                    || (third != null && value == third)) {
                continue;
            }

            if (first == null || value > first) {
                third = second;
                second = first;
                first = value;
            } else if (second == null || value > second) {
                third = second;
                second = value;
            } else if (third == null || value > third) {
                third = value;
            }
        }

        return third == null ? first.intValue() : third.intValue();
    }
}

var thirdMax = function(nums) {
    let first = null;
    let second = null;
    let third = null;

    for (const value of nums) {
        if (value === first || value === second || value === third) {
            continue;
        }

        if (first === null || value > first) {
            third = second;
            second = first;
            first = value;
        } else if (second === null || value > second) {
            third = second;
            second = value;
        } else if (third === null || value > third) {
            third = value;
        }
    }

    return third === null ? first : third;
};
Python 3
from typing import List, Optional


class Solution:
    def thirdMax(self, nums: List[int]) -> int:
        first: Optional[int] = None
        second: Optional[int] = None
        third: Optional[int] = None

        for value in nums:
            if value == first or value == second or value == third:
                continue

            if first is None or value > first:
                third, second, first = second, first, value
            elif second is None or value > second:
                third, second = second, value
            elif third is None or value > third:
                third = value

        return first if third is None else third
C++17
#include <optional>
#include <vector>
using namespace std;

class Solution {
public:
    int thirdMax(vector<int>& nums) {
        optional<long long> first;
        optional<long long> second;
        optional<long long> third;

        for (long long value : nums) {
            if ((first && value == *first)
                    || (second && value == *second)
                    || (third && value == *third)) {
                continue;
            }

            if (!first || value > *first) {
                third = second;
                second = first;
                first = value;
            } else if (!second || value > *second) {
                third = second;
                second = value;
            } else if (!third || value > *third) {
                third = value;
            }
        }

        return static_cast<int>(third ? *third : *first);
    }
};

常见错误

  • 把第三个元素误当作第三大不同值。
  • 没有先判重，导致相同数字占多个席位。
  • 更新第一名时忘记同步后移旧第一、第二名。
  • 用 Integer.MIN_VALUE 作为空哨兵，却忽略它本身是合法输入。
  • 不同值不足三个时误返回第二名或空值。
