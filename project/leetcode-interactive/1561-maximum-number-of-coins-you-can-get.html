你可以获得的最大硬币数目

桌上共有 3n 堆硬币。每轮你任选三堆，Alice 拿最大的一堆，你拿第二大的一堆，Bob 拿剩下的一堆。不断重复，求你最终能拿到的硬币总数最大值。

中等 贪心 数组 排序 非付费题

Game rules

一轮里，三堆如何分配？

三堆不要求在原数组中连续。

01

任选三堆

从仍未取走的硬币堆中选择任意三堆。

02

Alice 先拿

Alice 固定拿走三堆中硬币数最多的一堆。

03

轮到你

你拿走剩余两堆中较大的一堆，也就是原三堆的第二大。

04

Bob 收尾

Bob 拿走最后一堆；重复 n 轮直到分完。

Solution

题解：排序后从第二大开始隔一个取一个

核心洞察

设共有 3n 堆。每轮给 Bob 一堆尽可能小的；在剩余较大的堆里，让 Alice 拿当前最大，你拿当前第二大。这样 Bob 消耗排序数组左侧的 n 个较小元素，而你和 Alice 平分右侧的 2n 个较大元素。

升序后，你取：piles[3n-2], piles[3n-4], …，共 n 个

完整过程

  1. 将 piles 升序排序。
  2. 令右指针从倒数第二个元素开始，它代表第一轮你能拿到的堆。
  3. 每次把该值加入答案，然后右指针左移 2：被跳过的更大元素交给 Alice。
  4. 重复 n 次；数组左侧剩余的 n 个小元素可逐轮交给 Bob。

为什么正确

交换论证：任取一轮，Alice 一定会压过你拿走三堆中的最大值。因此，为让你的收益尽量大，应把与它配对的第二大值给你；第三堆不影响这一轮你的所得，可以换成当前全局最小的剩余堆交给 Bob，而不会降低收益。

不断进行上述交换，就能把任一最优分组变成“最小给 Bob、最大给 Alice、次大给你”的形式而不变差。排序后逐轮执行，得到的正是从倒数第二位开始隔一个取一个的总和，因此该贪心策略最优。

边界与复杂度

  • 只有 3 堆时，答案就是排序后的中间值。
  • 重复值不影响贪心关系，也不要求稳定排序。
  • 值全相等时，任意分组收益一致。
  • 时间复杂度 O(m log m)，其中 m = piles.length。
  • 额外空间依语言排序实现而定；遍历本身为 O(1)。

替代方案

也可以排序后维护左右指针：每轮左指针右移 1（Bob），右侧最大值给 Alice，再把次大值计入答案。它与“从倒数第二位隔一个累加”完全等价，但显式指针更贴近分组过程。

使用优先队列反复取值通常需要更多常数开销，复杂度仍不会优于排序。

面试追问与常见错误

  • 追问：为什么不是直接取最大的 n 堆？因为每轮 Alice 必须拿走一个比你所取不小的堆。
  • 追问：若 Bob 改为拿三堆中的最小值，结论是否变化？需重新分析选择顺序与约束，不可直接套用。
  • 错误：从最大值开始隔一个累加，会把 Alice 的份额算给自己。
  • 错误：遍历次数用 piles.length / 2，正确轮数是 piles.length / 3。
  • 错误：只考虑连续三元组；题目允许任意选三堆。
一句话记忆：排序，舍掉给 Bob 的较小三分之一；在较大三分之二里，Alice 与你交替拿，你从第二大开始拿。

import java.util.Arrays;

class Solution {
    public int maxCoins(int[] piles) {
        Arrays.sort(piles);
        int rounds = piles.length / 3;
        int index = piles.length - 2;
        int answer = 0;

        for (int i = 0; i < rounds; i++) {
            answer += piles[index];
            index -= 2;
        }
        return answer;
    }
}
