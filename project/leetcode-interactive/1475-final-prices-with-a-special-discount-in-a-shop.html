商品折扣后的
最终价格

找到每件商品右侧第一个不高于它的价格，将其作为折扣；如果不存在，原价结算。先理解规则，再亲手观察价格如何变化。

01 / Problem

规则只有一句，关键在“第一个”

给定整数数组 prices，其中 prices[i] 表示第 i 件商品的原价。购买商品 i 时，从它右侧寻找满足价格不高于当前商品的第一件商品 j，并用 prices[j] 作为折扣。

若存在最小下标 j > i 且 prices[j] <= prices[i]，则 answer[i] = prices[i] - prices[j]；否则 answer[i] = prices[i]。

返回每件商品实际支付价格组成的整数数组 answer。

函数签名
finalPrices(prices: integer[]) → integer[]
约束
  • 1 <= prices.length <= 500
  • 1 <= prices[i] <= 10³
主题
数组栈单调栈
02 / Examples

官方示例

示例 01
输入：prices = [8,4,6,2,3]
输出：[4,2,4,2,3]

8 使用右侧第一个 4 抵扣；4 与 6 都使用后续第一个 2 抵扣；最后两件没有可用折扣。

示例 02
输入：prices = [1,2,3,4,5]
输出：[1,2,3,4,5]

价格严格递增，每件商品右侧都不存在不高于自己的价格，所以全部按原价支付。

示例 03
输入：prices = [10,1,1,6]
输出：[9,0,1,6]

相等也满足折扣条件：下标 1 的价格 1 使用下标 2 的价格 1 抵扣，最终为 0。

05 / Solution

单调栈：让折扣主动找到商品

核心洞察

从左向右扫描。栈中保存尚未找到折扣的商品下标，并让对应价格保持严格递增。当前价格 prices[i] 不高于栈顶商品时，它就是栈顶商品右侧出现的第一个合法折扣。

连续弹栈是必要的：同一个低价可能同时成为多件此前商品的第一个合法折扣。

完整过程

  1. 复制 prices 得到答案数组，未匹配的商品自然保留原价。
  2. 从左到右扫描下标 i。
  3. 当栈非空且 prices[stack.top] >= prices[i]，弹出下标 j。
  4. 令 answer[j] -= prices[i]；继续检查新的栈顶。
  5. 把当前下标 i 入栈。扫描结束后返回答案。

正确性

  • 合法：下标 i 位于被弹出下标 j 的右侧，且弹出条件保证 prices[i] <= prices[j]。
  • 最近：j 在遇到 i 之前一直留在栈中，说明中间没有任何价格满足折扣条件；因此 i 是最小合法下标。
  • 完整：能找到折扣的商品一定会在第一次遇到合法价格时弹出；最终仍在栈中的商品右侧不存在合法折扣，保留原价正确。

边界与复杂度

  • 单个元素：没有右侧商品，返回原价。
  • 相等价格：条件是 <=，相等必须触发折扣。
  • 严格递增：所有下标留在栈中，答案等于输入。
  • 每个下标最多入栈、出栈一次，时间 O(n)，辅助空间 O(n)；答案数组不计输出空间时仍需栈空间。

替代方案：逐项向右查找

对每个 i 从 i + 1 开始扫描，一旦发现第一个不高于 prices[i] 的价格便扣除并停止。它直观、额外空间为 O(1)（不计答案），但最坏时间为 O(n²)。在本题 n <= 500 时也能工作，面试中可先讲清楚再优化。

四种语言完整实现

JavaLeetCode 可提交
class Solution {
    public int[] finalPrices(int[] prices) {
        int n = prices.length;
        int[] answer = prices.clone();
        int[] stack = new int[n];
        int top = -1;

        for (int i = 0; i < n; i++) {
            while (top >= 0 && prices[stack[top]] >= prices[i]) {
                int j = stack[top--];
                answer[j] -= prices[i];
            }
            stack[++top] = i;
        }
        return answer;
    }
}

var finalPrices = function(prices) {
    const answer = [...prices];
    const stack = [];

    for (let i = 0; i < prices.length; i++) {
        while (
            stack.length > 0 &&
            prices[stack[stack.length - 1]] >= prices[i]
        ) {
            const j = stack.pop();
            answer[j] -= prices[i];
        }
        stack.push(i);
    }
    return answer;
};

from typing import List


class Solution:
    def finalPrices(self, prices: List[int]) -> List[int]:
        answer = prices.copy()
        stack: List[int] = []

        for i, price in enumerate(prices):
            while stack and prices[stack[-1]] >= price:
                j = stack.pop()
                answer[j] -= price
            stack.append(i)

        return answer
C++LeetCode 可提交
class Solution {
public:
    vector<int> finalPrices(vector<int>& prices) {
        vector<int> answer = prices;
        vector<int> stack;

        for (int i = 0; i < prices.size(); ++i) {
            while (!stack.empty() &&
                   prices[stack.back()] >= prices[i]) {
                int j = stack.back();
                stack.pop_back();
                answer[j] -= prices[i];
            }
            stack.push_back(i);
        }
        return answer;
    }
};

面试追问

  • 如果要找右侧第一个严格更低的价格，弹栈条件应如何变化？
  • 为什么栈里存下标而不是价格？如果还要返回折扣商品下标呢？
  • 能否直接修改输入数组以减少一份答案拷贝？这样做有什么接口副作用？
  • 如何把思路迁移到“下一个更大元素”或“每日温度”？

常见错误

  • 只弹出一次，漏掉同一低价可以结算的多件商品。
  • 使用 > 而不是 >=，错误忽略相等价格。
  • 从右侧找到了最低价，却没有遵守“最小下标”。
  • 把答案数组当作比较依据；答案已被修改，比较必须使用原始 prices。
