每日温度
Daily Temperatures

给定整数数组 temperatures 表示每天的温度。请返回数组 answer：answer[i] 表示从第 i 天起，还要等待多少天才会遇到更高温度；如果之后没有更暖的一天，该位置填写 0。

函数参数： dailyTemperatures(temperatures: integer[]) → integer[]

非付费题 1 ≤ n ≤ 10⁵ 30°C ≤ temperatures[i] ≤ 100°C

Inputs & outputs

先读懂等待天数

输出不是未来的温度值，而是当前位置到第一个更高温度之间的下标距离。

示例 1

起伏序列
输入：temperatures = [73,74,75,71,69,72,76,73]
输出：[1,1,4,2,1,1,0,0]

示例 2

输出：[1,1,1,0]

示例 3

快速升温
输入：temperatures = [30,60,90]
输出：[1,1,0]

Monotonic stack

题解：维护尚未等到答案的日子

核心洞察

从左到右扫描时，只有“还没遇到更高温度”的日子需要继续保留。若这些下标按入栈顺序保存，则其对应温度从栈底到栈顶保持单调不升。当前温度一旦高于栈顶温度，就能立刻确定栈顶那天的第一个更暖日期。

为什么答案是距离？ 当前下标 i 是被弹出下标 j 右侧第一个更高温度，所以填写 answer[j] = i - j。

完整过程

  1. 建立长度为 n 的答案数组并全部初始化为 0；栈中只存数组下标。
  2. 依次访问每个下标 i。只要栈非空，并且 temperatures[i] 大于栈顶下标对应的温度，就弹出栈顶 j。
  3. 当前日是 j 右侧第一个更暖的日子，记录 answer[j] = i - j；继续比较新的栈顶，当前温度可能一次解决多个等待中的日子。
  4. 将当前下标 i 入栈。扫描结束后仍在栈中的下标右侧没有更高温度，其答案保持初始值 0。

正确性

不变式：处理下标 i 之前，栈内下标严格递增；其温度从栈底到栈顶单调不升，并且这些下标在已扫描区间内都还没有遇到更高温度。

当当前温度高于栈顶下标 j 的温度时，j 与当前下标之间不存在更高温度，否则 j 早已被弹出。因此当前下标正是 j 的第一个更暖日，i-j 正确。

弹出所有更低温度后把 i 入栈，仍满足不变式。结束时留在栈中的日子没有更暖的后继，保留 0 也正确。

复杂度

时间：O(n)。每个下标最多入栈一次、出栈一次。

空间：O(n)。最坏情况下所有下标都留在栈中。

边界情况

  • 只有一天：答案为 [0]。
  • 严格递减或全部相等：所有答案为 0。
  • 严格递增：除最后一天外，答案均为 1。
  • 相等不算更暖，比较条件必须是严格大于。

四种语言完整实现

四份代码均遵循官方函数签名，栈中保存下标而非温度。

Java

int[]
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty()
                    && temperatures[i] > temperatures[stack.peek()]) {
                int previous = stack.pop();
                answer[previous] = i - previous;
            }
            stack.push(i);
        }

        return answer;
    }
}

/**

var dailyTemperatures = function (temperatures) {
    const answer = new Array(temperatures.length).fill(0);
    const stack = [];

    for (let i = 0; i < temperatures.length; i += 1) {
        while (
            stack.length > 0 &&
            temperatures[i] > temperatures[stack[stack.length - 1]]
        ) {
            const previous = stack.pop();
            answer[previous] = i - previous;
        }
        stack.push(i);
    }

    return answer;
};

Python

List[int]
from typing import List


class Solution:
    def dailyTemperatures(
        self, temperatures: List[int]
    ) -> List[int]:
        answer = [0] * len(temperatures)
        stack: List[int] = []

        for i, temperature in enumerate(temperatures):
            while stack and temperature > temperatures[stack[-1]]:
                previous = stack.pop()
                answer[previous] = i - previous
            stack.append(i)

        return answer

C++

vector<int>
#include <vector>
#include <stack>
using namespace std;

class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        const int n = static_cast<int>(temperatures.size());
        vector<int> answer(n, 0);
        stack<int> waiting;

        for (int i = 0; i < n; ++i) {
            while (!waiting.empty()
                   && temperatures[i] > temperatures[waiting.top()]) {
                int previous = waiting.top();
                waiting.pop();
                answer[previous] = i - previous;
            }
            waiting.push(i);
        }

        return answer;
    }
};

替代方案

  • 暴力向右扫描：对每一天寻找右侧第一个更高温度，最坏 O(n²)，在 10⁵ 数据量下不可取。
  • 从右向左跳跃：利用已求出的答案跨过不可能成为结果的区间，可达 O(n)，但边界推导更绕。
  • 温度桶：由于温度只有 30 到 100，可记录每个温度最近出现的下标，时间 O(71n)，空间 O(71)。

面试追问

  • 如果“更暖”改为“大于等于”，弹栈条件如何变化？
  • 为什么栈里保存下标比保存温度更合适？
  • 如何改成求左侧最近的更高温度？
  • 如果温度以数据流形式到达，哪些答案可以立即输出？

常见错误

  • 使用 >=，把相同温度误当作更暖。
  • 答案填写温度差，而不是下标差 i - j。
  • 只弹出一个栈顶，漏掉当前高温能够同时解决的其他日子。
  • 栈里只存温度，导致无法计算等待天数。
