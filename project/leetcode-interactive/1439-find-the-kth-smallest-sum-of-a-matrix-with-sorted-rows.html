01 / Problem

题目说了什么？

给定一个 m × n 矩阵 mat 和整数 k。矩阵每一行均按非递减顺序排列。你必须从每一行恰好选择一个元素，这些元素组成一个数组；求所有可能数组和中第 k 小的值。相同的和来自不同选择时仍按各自组合计数。

函数签名：kthSmallest(mat, k) → integer

核心洞察完整过程正确性边界复杂度四语言代码替代方案面试追问常见错误

核心洞察：把多行问题拆成两两合并

若 A 已保存前几行最小的至多 k 个和，而 B 是下一行，那么只需找出 A[i] + B[j] 中最小的 k 个。合并完成后继续处理下一行。

因为 A、B 都有序，对固定的 i，序列 A[i]+B[0], A[i]+B[1], ... 也有序。于是问题变成：从若干条有序链中取全局最小的 k 项。最小堆恰好维护每条链当前的队首。

完整过程

  1. 令 sums = [0]，表示还未处理任何行时唯一的和。
  2. 逐行处理矩阵。对当前有序数组 sums 和该行 row 做一次合并。
  3. 对每个有效的 sums[i]，先把链首 (sums[i] + row[0], i, 0) 压入最小堆。
  4. 最多弹出 k 次。弹出 (sum, i, j) 后记录 sum；若 j + 1 存在，就压入同一条链的下一项。
  5. 用本轮得到的有序结果替换 sums。全部行处理完后，返回 sums[k - 1]。

正确性证明

引理 1：两数组合并会按非递减顺序输出。

对每个固定的 i，链 A[i]+B[j] 随 j 非递减。堆始终包含每条尚未耗尽链的最小未输出元素，因此堆顶就是所有未输出组合中的全局最小值。弹出后只补入该链下一项，归纳可知输出顺序正确。

引理 2：中间结果截断到前 k 个不会丢失最终答案。

若某个前缀和在当前阶段已排在第 k 名之后，那么至少已有 k 个不大的前缀和。给这些前缀和都加上后续各行的最小元素，仍得到至少 k 个不大于它的完整和，因此它不可能成为最终前 k 名所必需的候选。

定理。

由引理 1，每次合并正确产生当前所有组合和的前 k 个；由引理 2，截断不影响后续第 k 小结果。对矩阵行数归纳，最终 sums[k-1] 即全部组合中的第 k 小数组和。

边界情况

  • k = 1：答案就是每行第一个元素之和。
  • 只有一行：合并后直接得到该行前 k 个元素。
  • 大量重复值：不能去重；不同下标组合需要分别计数。
  • k 大于某个中间阶段的组合数：本轮只弹到堆空，后续仍能正常合并。
  • 整数范围：最大和不超过 40 × 5000 = 200000，32 位有符号整数足够。

复杂度

时间O(m · k log k)每行最多弹出 k 次，堆规模至多 k。
空间O(k)中间结果与最小堆均只保留至多 k 项。

class Solution {
    public int kthSmallest(int[][] mat, int k) {
        int[] sums = new int[]{0};
        for (int[] row : mat) sums = merge(sums, row, k);
        return sums[k - 1];
    }

    private int[] merge(int[] a, int[] b, int k) {
        // node = {sum, indexInA, indexInB}
        java.util.PriorityQueue<int[]> pq =
            new java.util.PriorityQueue<>((x, y) -> x[0] - y[0]);
        for (int i = 0; i < Math.min(a.length, k); i++) {
            pq.offer(new int[]{a[i] + b[0], i, 0});
        }

        int size = Math.min(k, a.length * b.length);
        int[] result = new int[size];
        for (int p = 0; p < size; p++) {
            int[] cur = pq.poll();
            result[p] = cur[0];
            int i = cur[1], j = cur[2];
            if (j + 1 < b.length) {
                pq.offer(new int[]{a[i] + b[j + 1], i, j + 1});
            }
        }
        return result;
    }
}

var kthSmallest = function(mat, k) {
    let sums = [0];

    const merge = (a, b) => {
        const heap = [];
        const swap = (i, j) => [heap[i], heap[j]] = [heap[j], heap[i]];
        const push = node => {
            heap.push(node);
            let i = heap.length - 1;
            while (i > 0) {
                const p = (i - 1) >> 1;
                if (heap[p][0] <= heap[i][0]) break;
                swap(i, p); i = p;
            }
        };
        const pop = () => {
            const top = heap[0], last = heap.pop();
            if (heap.length) {
                heap[0] = last;
                let i = 0;
                while (true) {
                    let smallest = i, l = i * 2 + 1, r = l + 1;
                    if (l < heap.length && heap[l][0] < heap[smallest][0]) smallest = l;
                    if (r < heap.length && heap[r][0] < heap[smallest][0]) smallest = r;
                    if (smallest === i) break;
                    swap(i, smallest); i = smallest;
                }
            }
            return top;
        };

        for (let i = 0; i < Math.min(a.length, k); i++) {
            push([a[i] + b[0], i, 0]);
        }
        const result = [];
        const limit = Math.min(k, a.length * b.length);
        while (result.length < limit) {
            const [sum, i, j] = pop();
            result.push(sum);
            if (j + 1 < b.length) push([a[i] + b[j + 1], i, j + 1]);
        }
        return result;
    };

    for (const row of mat) sums = merge(sums, row);
    return sums[k - 1];
};
from typing import List
import heapq

class Solution:
    def kthSmallest(self, mat: List[List[int]], k: int) -> int:
        def merge(a: List[int], b: List[int]) -> List[int]:
            # heap item: (sum, index_in_a, index_in_b)
            heap = [(a[i] + b[0], i, 0)
                    for i in range(min(len(a), k))]
            heapq.heapify(heap)
            result = []
            limit = min(k, len(a) * len(b))

            while heap and len(result) < limit:
                total, i, j = heapq.heappop(heap)
                result.append(total)
                if j + 1 < len(b):
                    heapq.heappush(heap, (a[i] + b[j + 1], i, j + 1))
            return result

        sums = [0]
        for row in mat:
            sums = merge(sums, row)
        return sums[k - 1]
class Solution {
    using Node = array<int, 3>; // {sum, index in a, index in b}

    vector<int> merge(const vector<int>& a,
                      const vector<int>& b, int k) {
        priority_queue<Node, vector<Node>, greater<Node>> pq;
        for (int i = 0; i < min((int)a.size(), k); ++i) {
            pq.push({a[i] + b[0], i, 0});
        }

        vector<int> result;
        int limit = min(k, (int)(a.size() * b.size()));
        while (!pq.empty() && (int)result.size() < limit) {
            auto [sum, i, j] = pq.top();
            pq.pop();
            result.push_back(sum);
            if (j + 1 < (int)b.size()) {
                pq.push({a[i] + b[j + 1], i, j + 1});
            }
        }
        return result;
    }

public:
    int kthSmallest(vector<vector<int>>& mat, int k) {
        vector<int> sums{0};
        for (const auto& row : mat) sums = merge(sums, row, k);
        return sums[k - 1];
    }
};

替代方案

答案二分 + 计数组合：对答案区间做二分，用 DFS 计算和不超过阈值的组合数，并在计数达到 k 时提前停止。理论上可行，额外空间小，但剪枝、溢出和计数边界更容易写错；本题 k ≤ 200 时，逐行保留前 k 个和更直观。

全量枚举：共有 n^m 种选择，最坏为 40^40，无法接受。即便每轮生成全部笛卡尔积再排序，也会迅速膨胀。

面试追问

  • 为什么每轮只保留前 k 个和仍然安全？请给出单调性论证。
  • 如果每行没有排序，应该怎样预处理？排序成本如何计入？
  • 若 k 非常大而数值范围较窄，答案二分何时更有优势？
  • 如何返回第 k 小和对应的具体下标组合，而不只是和？
  • 如果各行长度不同，当前实现要改哪里？答案是：算法不变，代码已自然支持。

常见错误

  • 把重复的和去重，导致“第 k 个组合”计数不足。
  • 堆中只放一个全局候选，没有为每个 A[i] 建立一条有序链。
  • 弹出 (i,j) 后错误地同时推进 i 和 j，造成遗漏或重复。
  • 默认每轮一定能弹出 k 项；早期组合总数可能少于 k。
  • 直接枚举所有 n^m 个数组和，忽略指数爆炸。
