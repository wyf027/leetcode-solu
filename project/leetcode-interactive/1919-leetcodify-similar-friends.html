01 / 题意与输入契约

找出已有好友中，至少在某一天共同听过三首不同歌曲的用户对。输出列为 user1_id、user2_id，每对只出现一次，较小编号在前，行顺序不限。

Listens

(user_id INT, song_id INT, day DATE)

每行表示某用户在某日听过某首歌。没有主键，可有完全重复的行。

Friendship

(user1_id INT, user2_id INT)

两列联合主键；每行是一对好友，保证 user1_id < user2_id。

约束：歌曲必须不同、日期必须相同、关系必须存在。可用资料未给出行数或编号的额外数值上限，不额外假定范围。

05 / 独立题解

核心洞察：好友对 × 日期

共同歌曲数属于一对好友的某一天，不能把不同日期混在一起。原始播放行可能重复，所以先在语义上把歌曲看作集合，再比较集合交集是否至少有三个元素。

完整过程

  1. 从 Friendship 出发，分别连接两人的 Listens 记录，天然限制为已有好友。
  2. 连接条件同时要求 song_id 与 day 相等，留下同日共同歌曲。
  3. 按 user1_id、user2_id、day 分组，用 COUNT(DISTINCT song_id) 计算不同歌曲数。
  4. HAVING 保留至少三首的日分组；SELECT DISTINCT 去掉同一好友对在多天达标造成的重复。

正确性

可靠性：每个保留下来的分组都来自好友表，且至少包含三首同日共同歌曲，因此输出的每对用户都满足定义。完备性：任意满足定义的好友对必有一天的三首共同歌曲；这些记录必被连接保留，去重后计数仍至少为三，因此不会遗漏。最终按用户对去重只消除重复证明，不会删除唯一答案。

边界与常见错误

  • 空表、没有共同歌曲或不足三首：输出空结果。
  • 同一首歌反复播放：COUNT(*) 会被重复行甚至连接乘积放大，必须统计 DISTINCT。
  • 不同天各有两首：不可累计；GROUP BY 不能漏 day。
  • 同日听歌相似但并非好友：不能返回；本题不是好友推荐。
  • 多日满足：仍仅输出一次；日期不应出现在最终结果。

复杂度

SQL 复杂度取决于执行计划。令 N 为收听行数，F 为好友数，J 为连接产生的匹配行数；采用索引或哈希连接时，通常需处理 O(N + F + J) 规模的数据，排序聚合可增加 O(J log J) 时间，物化中间结果可能使用 O(N + F + J) 空间。重复播放导致 J 最坏达到 O(N²)，不能把查询简单称作线性。

四语言参考先建 user → day → set(song) 索引。令 S 为遍历每个好友对第一位用户所有日歌曲集合的总次数，哈希实现平均 O(N + F + S) 时间，索引与输出 O(N + F) 空间；Python 交集还会临时分配集合。它们返回与 SQL 相同的用户对，但不冒充该数据库题的提交接口。

替代方案与面试追问

可先将 Listens 按三列去重再连接，减少重复播放引起的中间行膨胀；也可使用 EXISTS 包裹按日聚合子查询。是否更快应由真实执行计划决定。

  • 数据量很大如何优化？考虑 (user_id, day, song_id) 复合索引，并先消除重复记录。
  • 阈值改成 k？把 HAVING 中的 3 换成参数，日粒度不变。
  • 需要返回达标日期？输出 day 并保留每日一行，不再只按用户对去重。
  • 好友关系可变怎么办？若要求收听当日已为好友，就需要关系生效时间；当前输入没有这种语义。

MySQL · 官方可提交语言

SELECT DISTINCT f.user1_id, f.user2_id
FROM Friendship AS f
JOIN Listens AS a ON a.user_id = f.user1_id
JOIN Listens AS b ON b.user_id = f.user2_id
 AND b.day = a.day AND b.song_id = a.song_id
GROUP BY f.user1_id, f.user2_id, a.day
HAVING COUNT(DISTINCT a.song_id) >= 3;

JavaScript · 本地语义参考

// Listens: [user_id, song_id, day][]; Friendship: [user1_id, user2_id][]
function similarFriends(Listens, Friendship) {
  const users = new Map();
  for (const [u, s, d] of Listens) {
    if (!users.has(u)) users.set(u, new Map());
    const days = users.get(u);
    if (!days.has(d)) days.set(d, new Set());
    days.get(d).add(s);
  }
  return Friendship.filter(([u, v]) => {
    for (const [d, songs] of users.get(u) || []) {
      const other = users.get(v)?.get(d);
      if (!other) continue;
      let count = 0;
      for (const song of songs)
        if (other.has(song) && ++count >= 3) return true;
    }
    return false;
  });
}

Python · 本地语义参考

from collections import defaultdict

def similar_friends(Listens, Friendship):
    # 每行分别为 (user_id, song_id, day) 和 (user1_id, user2_id)
    users = defaultdict(lambda: defaultdict(set))
    for user, song, day in Listens:
        users[user][day].add(song)
    result = []
    for u, v in Friendship:
        for day, songs in users.get(u, {}).items():
            other = users.get(v, {}).get(day, set())
            if len(songs & other) >= 3:
                result.append([u, v])
                break
    return result

Java · 本地语义参考（Java 17）

import java.util.*;

class Solution {
    record Listen(int user, int song, String day) {}
    // Friendship 每行为 {user1_id, user2_id}
    static List<int[]> similarFriends(List<Listen> listens, int[][] friendship) {
        Map<Integer, Map<String, Set<Integer>>> users = new HashMap<>();
        for (Listen r : listens)
            users.computeIfAbsent(r.user(), k -> new HashMap<>())
                 .computeIfAbsent(r.day(), k -> new HashSet<>()).add(r.song());
        List<int[]> result = new ArrayList<>();
        for (int[] pair : friendship) {
            var a = users.getOrDefault(pair[0], Collections.emptyMap());
            var b = users.getOrDefault(pair[1], Collections.emptyMap());
            for (var entry : a.entrySet()) {
                Set<Integer> other = b.getOrDefault(entry.getKey(), Collections.emptySet());
                int count = 0;
                for (int song : entry.getValue()) {
                    if (other.contains(song)) count++;
                    if (count >= 3) break;
                }
                if (count >= 3) {
                    result.add(new int[]{pair[0], pair[1]});
                    break;
                }
            }
        }
        return result;
    }
}

C++ · 本地语义参考（C++17）

#include <array>
#include <string>
#include <vector>
#include <unordered_map>
#include <unordered_set>
using namespace std;

struct Listen { int user, song; string day; };
vector<array<int, 2>> similarFriends(
    const vector<Listen>& listens, const vector<array<int, 2>>& friendship) {
    unordered_map<int, unordered_map<string, unordered_set<int>>> users;
    for (const auto& r : listens) users[r.user][r.day].insert(r.song);
    vector<array<int, 2>> result;
    for (auto pair : friendship) {
        auto a = users.find(pair[0]), b = users.find(pair[1]);
        if (a == users.end() || b == users.end()) continue;
        for (const auto& [day, songs] : a->second) {
            auto other = b->second.find(day);
            if (other == b->second.end()) continue;
            int count = 0;
            for (int song : songs) {
                if (other->second.count(song)) ++count;
                if (count >= 3) break;
            }
            if (count >= 3) { result.push_back(pair); break; }
        }
    }
    return result;
}
