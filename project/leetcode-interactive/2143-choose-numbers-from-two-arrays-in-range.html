在两个数组的区间中

Choose Numbers From Two Arrays in Range

同一个下标，二选一。让两边的和恰好相等。

先理解计数对象，再展开底部题解探索状态变化。

01 / PROBLEM

题意重述

给定长度同为 n 的整数数组 nums1 与 nums2。选定非空连续下标区间 [l,r]，对其中每个下标恰好选一个数，来自 nums1 或 nums2。若所选 nums1 元素的和等于所选 nums2 元素的和，这就是一种平衡方案。某侧没有选数时，其和记为 0。

只要区间端点不同，或者某个位置所选的数组不同，就视为不同方案。因此，同一个区间可能贡献多种方案；两侧数值相等也不能合并选择来源。返回所有平衡方案数，对 1_000_000_007 取模。

每列只能选一侧，区间内不能跳过位置。统计的是“区间 + 每列选择来源”，不只是合法区间的个数。

官方接口：countSubranges(nums1: integer[], nums2: integer[]) → integer

约束

  • n == nums1.length == nums2.length
  • 1 ≤ n ≤ 100
  • 0 ≤ nums1[i], nums2[i] ≤ 100
  • 0 ≤ l ≤ r < n，区间两端都包含。

题号、签名与示例输入来自本地官方元数据。付费题面字段为空，规则、输出和约束据公开题面转述：LeetCode 原题 · LeetCode Wiki · 公开示例与约束。本页推导与代码为独立编写，未执行验证。

04 / SOLUTION

从选择分支到差值计数

交互演示、证明与四语言实现，默认折叠。

核心洞察：用一个差值替代两个和

令 d = 已选 nums1 的和 − 已选 nums2 的和。当前选择 nums1 的值 a，差值增加 a；选择 nums2 的值 b，差值减少 b。平衡恰好对应 d = 0。

dp[d] 统计恰好在上一列结束且差值为 d 的非空区间选择方案数。不同左端点、不同选法可以汇入同一个桶，桶中累加的次数保留全部方案。

递推规则

当前列 i：a = nums1[i]，b = nums2[i]
next[a]  += 1                 // 新区间 [i,i]，选择 nums1
next[-b] += 1                 // 新区间 [i,i]，选择 nums2
对于每个旧差值 d，令 c = dp[d]：
    next[d+a] += c            // 延长，选 nums1[i]
    next[d-b] += c            // 延长，选 nums2[i]
answer += next[0]
dp = next                    // 使用全新的一层
全部计数对 1_000_000_007 取模。

完整过程

  1. 求 S1 = sum(nums1)、S2 = sum(nums2)。差值一定落在 [−S2,S1]。令下标 j = d + S2，数组宽度 W = S1 + S2 + 1。
  2. 初始 dp 全零，不放入空区间。遍历每列，创建新的 next，分别加入选 a、选 −b 的单列方案。
  3. 把上一层的方案沿两条边传播。代码采用等价的反向读取：next[j] 加上 dp[j−a] 与 dp[j+b]，下标合法时才读取。
  4. next[S2] 对应差值零，将其加到答案，再令 dp = next。处理完所有右端点后返回答案。

示例 1：第 0 列结束后差值桶是 {−2:1,1:1}，贡献 0；第 1 列零桶为 1，累计 1；第 2 列零桶为 2，累计 3。

正确性证明

不变量：处理完第 i 列，dp[d] 正好是以 i 结尾、差值为 d 的全部非空方案数，计数以模数表示。

基础：第 0 列只有两种选择来源，分别进入 a、−b。若两者都为零，也保留两次计数。

归纳：以 i 结尾的方案要么只有当前位置，要么由一个以 i−1 结尾的方案追加当前选择组成。前者被两次初始化覆盖；后者根据当前来源，唯一对应 +a 或 −b 的转移。删除最后一次选择可还原唯一前驱，因此没有遗漏或重复生成同一方案。

答案：d = 0 当且仅当两侧和相等。每个方案有唯一右端点，逐列累加零桶即为总答案。取模与加法相容，不改变计数递推。

边界与常见错误

  • 两侧都是 0：两次初始化、两次转移都必须累加，不能覆盖或去重。
  • 不能只计“存在解的区间”；同一区间的不同选法也要计数。
  • 不能跳过位置，也不能原地更新 dp，否则当前列会被重复使用。
  • 一次选择不是 a−b：每个下标只能选一个数组。
  • 显式初始化单列时，不要再预置空区间 dp[0] = 1。
  • 全零时 W = 1 仍可正确表示状态；偏移下标必须统一。

复杂度与取模

W = S1 + S2 + 1 ≤ 20001。滚动偏移数组的时间为 O(nW)，空间为 O(W)。

若 M 是单个元素的最大值，可写作时间 O(n(nM+1))、空间 O(nM+1)。两层数组复用只保留相邻右端点的信息。

每次相加后立即取模，两个已取模数之和最多为 2×(MOD−1)，在 Java/C++ 的有符号 32 位范围内，也远小于 JavaScript 的安全整数上限。单列初始化至多累加到 2。

替代方案与面试追问

  • 稀疏哈希表：只记录可达差值，稀疏时节约遍历；本题数值范围小，偏移数组更直接。哈希更新也应及时取模。
  • 枚举区间与二进制选法：长度 k 的区间有 2^k 种选法，总量呈指数增长，仅适合极小输入作为参照。
  • 为什么普通前缀和不足？每列二选一，存在多条差值轨迹，而不是唯一固定序列。
  • 目标改为差值 K？每列统计 K 的桶；若 K 超出合法差值范围，贡献为零。
  • 允许负元素？需重新求差值上下界，或换成哈希表，不能沿用 [−S2,S1]。
  • 双方必须至少选一个？增加两位掩码记录是否使用过各数组，仅统计掩码为 3 的零桶状态。

Java

class Solution {
    public int countSubranges(int[] nums1, int[] nums2) {
        final int MOD = 1_000_000_007;
        int s1 = 0, s2 = 0;
        for (int x : nums1) s1 += x;
        for (int x : nums2) s2 += x;
        int width = s1 + s2 + 1;
        int[] dp = new int[width];
        int answer = 0;
        for (int i = 0; i < nums1.length; i++) {
            int a = nums1[i], b = nums2[i];
            int[] next = new int[width];
            next[s2 + a]++;
            next[s2 - b]++;
            for (int j = 0; j < width; j++) {
                if (j >= a)
                    next[j] = (next[j] + dp[j - a]) % MOD;
                if (j + b < width)
                    next[j] = (next[j] + dp[j + b]) % MOD;
            }
            answer = (answer + next[s2]) % MOD;
            dp = next;
        }
        return answer;
    }
}

from typing import List

class Solution:
    def countSubranges(self, nums1: List[int], nums2: List[int]) -> int:
        mod = 10**9 + 7
        s1, s2 = sum(nums1), sum(nums2)
        width = s1 + s2 + 1
        dp = [0] * width
        answer = 0
        for a, b in zip(nums1, nums2):
            nxt = [0] * width
            nxt[s2 + a] += 1
            nxt[s2 - b] += 1
            for j in range(width):
                if j >= a:
                    nxt[j] = (nxt[j] + dp[j - a]) % mod
                if j + b < width:
                    nxt[j] = (nxt[j] + dp[j + b]) % mod
            answer = (answer + nxt[s2]) % mod
            dp = nxt
        return answer

C++

#include <vector>
#include <numeric>
using namespace std;

class Solution {
public:
    int countSubranges(vector<int>& nums1, vector<int>& nums2) {
        constexpr int MOD = 1'000'000'007;
        int s1 = accumulate(nums1.begin(), nums1.end(), 0);
        int s2 = accumulate(nums2.begin(), nums2.end(), 0);
        int width = s1 + s2 + 1;
        vector<int> dp(width);
        int answer = 0;
        for (int i = 0; i < static_cast<int>(nums1.size()); ++i) {
            int a = nums1[i], b = nums2[i];
            vector<int> next(width);
            ++next[s2 + a];
            ++next[s2 - b];
            for (int j = 0; j < width; ++j) {
                if (j >= a)
                    next[j] = (next[j] + dp[j - a]) % MOD;
                if (j + b < width)
                    next[j] = (next[j] + dp[j + b]) % MOD;
            }
            answer = (answer + next[s2]) % MOD;
            dp.swap(next);
        }
        return answer;
    }
};
