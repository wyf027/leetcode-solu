Count Integers With Even Digit Sum

一个整数是否入选，取决于它的每一位。先读题，再亲手观察。

01题目

给定正整数 num，考虑从 1 到 num 的所有整数（包含两端）。把每个整数的十进制各位数字相加，返回其中数字和为偶数的整数数量。

参数：num（整数） · 返回值：整数 · 约束：1 ≤ num ≤ 1000

示例 1

输入：num = 4
输出：2

符合条件的是 2 和 4。

示例 2

输入：num = 30
输出：14

符合条件的是 2、4、6、8、11、13、15、17、19、20、22、24、26、28。

04独立题解

准备好之后，再展开思路与四语言代码。

核心洞察：逐个枚举，逐位求和

num 最多为 1000，直接检查每一个候选整数就足够。整数的奇偶性不能代替数字和的奇偶性：10 是偶数，数字和却是 1；11 是奇数，数字和却是 2。

完整过程

  1. 令答案 ans = 0，从 i = 1 枚举到 num，包含 num。
  2. 复制 x = i，并令 sum = 0。每次用 x % 10 取得个位，加到 sum；再用整数除法去掉个位。
  3. x 变为 0 时，所有数字都已处理。如果 sum % 2 = 0，将答案增加 1。
  4. 完成所有候选整数后返回 ans。例：i = 28 时依次提取 8、2，sum 从 0 变为 8、10，因此入选。

为什么正确

内层循环的不变式是：sum 等于已经移除的低位数字之和，x 保存尚未处理的高位数字。取余得到下一位，整数除法移除该位，保持不变式；终止时 x = 0，因此 sum 是 i 的完整数字和。

外层每次开始处理 i 之前，ans 恰好统计了区间 [1, i − 1] 中数字和为偶数的整数。根据精确的数字和判定 i 是否入选，就得到区间 [1, i] 的正确计数。初始区间为空，最终覆盖 [1, num]，且无重复，所以答案正确。

边界与复杂度

num = 1 时答案为 0；不统计整数 0；num 自身必须参与判定。末尾的 0 对数字和贡献为 0，1000 的数字和为 1。设 n = num、d 为 n 的十进制位数，时间 O(n·d)，即 O(n log(n + 1))；仅用固定数量的整数变量，额外空间 O(1)。页面为了回退保存演示帧，这部分内存不属于提交算法。

四语言完整提交代码

Java

class Solution {
    public int countEven(int num) {
        int ans = 0;
        for (int i = 1; i <= num; i++) {
            int x = i, sum = 0;
            while (x > 0) {
                sum += x % 10;
                x /= 10;
            }
            if (sum % 2 == 0) ans++;
        }
        return ans;
    }
}

替代方案：按十个数分块

写成 num = 10q + r。先统计 [0, num]：每个完整十数块的高位相同，个位从 0 到 9，数字和的奇偶各出现 5 次。前 q 块贡献 5q。最后一块高位为 q，令 p = digitSum(q) % 2，需要个位与 p 同奇偶。

在个位区间 [0, r] 中，合格数量为 ⌊(r + 2 − p) / 2⌋。由于前面包含了 0，最终答案为 5q + ⌊(r + 2 − p) / 2⌋ − 1。约定 digitSum(0) = 0，这个公式也适用于 num < 10。计算 q 的数字和需要 O(log(n + 1)) 时间、O(1) 空间；当前约束下枚举更直观。

常见错误

  • 使用 i % 2 判断是否入选：要检查的是各位数字之和。
  • 枚举从 0 开始，导致多计数；或使用 i < num，漏掉上界。
  • 直接修改 i 来拆位，破坏外层枚举。必须先复制成 x。
  • 每次候选整数没有清空 sum，导致数字和跨整数累积。
  • JavaScript 使用 x / 10 而没有取整，无法正确删除个位。
  • 认为相邻两数的数字和总是一奇一偶：9 和 10 的数字和都是奇数，进位需要特别处理。

面试追问

  • 范围变成 [L, R] 呢？定义 F(n) 为 [1, n] 的答案，并约定 F(0) = 0，结果是 F(R) − F(L − 1)。
  • num 极大且用字符串给出？可以做数位 DP，记录当前位置、当前数字和奇偶与是否受上界限制，最后排除全零数。
  • 数字和要能被 k 整除呢？把奇偶状态扩展为 sum % k 的 k 种余数状态。
  • 为什么不直接返回 num / 2？例如 num = 30 时正确计数为 14；末尾的不完整分块受高位数字和奇偶影响。
