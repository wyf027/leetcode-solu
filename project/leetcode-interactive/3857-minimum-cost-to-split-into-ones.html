拆分到 1 的最小总代价

把一个整数 x 拆成 a + b，本次花费 a × b。目标是最终得到 n 个 1，并让总花费最小。

关键并不在于如何挑分割点：每一对最终的 1 恰好会在某次分裂时被分到两边，因此总账单固定。

主线结论

总成本 = 所有叶子对的数量：

n × (n − 1) / 2

n ≤ 500，结果不超过 124750，int / number 足够。

题意与样例

样例 1

n = 3，输出 3。

可拆 3 → 1 + 2（花 2），再拆 2 → 1 + 1（花 1）。

样例 2

n = 4，输出 6。

可拆 4 → 2 + 2（花 4），两个 2 各拆一次（花 1 + 1）。

约束：1 ≤ n ≤ 500。输入展示中 n = 4 的等号表示参数赋值，没有省略空格。

交互：一张不会变的分裂账本

输入 n，选择一种分裂策略；两种策略的累计账单应相同。

    题解

    默认收起，先自己观察账本再展开。

    核心洞察：每对 1 只被计一次

    把最终 n 个 1 想成叶子。一次把 x 拆成 a 和 b 时，左子树有 a 个叶子、右子树有 b 个叶子；这次费用 a×b 正好对应所有跨左右子树的叶子对。任意一对叶子在它们的最低公共分裂点第一次分居两边，以后不会再跨组，因此全程恰好贡献一次。总数就是 C(n,2)。

    完整过程与边界

    1. 读入 n。
    2. 计算 n * (n - 1) / 2。
    3. n = 1 时公式自然为 0；不需要模拟递归或区间 DP。

    时间 O(1)，空间 O(1)。替代方案是区间/整数 DP：dp[x] = min(dp[a] + dp[x-a] + a(x-a))，但它把固定账单重复算了一遍，O(n²) 且不适合本题主线。

    面试追问与常见错误

    • 若单次费用改成与 a、b 无关，叶子对论证不再适用，需要重建状态。
    • 不要只认为“均分最优”；本题任意完整拆分的总成本都相同。
    • 不要递归枚举拆法，n=500 时会产生大量重复子问题。
