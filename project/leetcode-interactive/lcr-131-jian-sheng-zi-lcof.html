砍竹子 I

一根长度为 bamboo_len 的竹子至少砍一刀，切成若干段正整数长度。求所有段长乘积的最大值。

查看分步演示

题意、示例与约束

输入：bamboo_len = 12

输出：81

解释：12 = 3 + 3 + 3 + 3，3 × 3 × 3 × 3 = 81。

输入：bamboo_len = 2

输出：1

  • 2 ≤ bamboo_len ≤ 58。
  • 必须至少切一刀，因此长度 2、3 不能直接保留为 2、3。
  • 返回最大乘积，题目范围内可用 32 位整数表示。

分步交互：长度 10 如何切？

尽量不断取 3；余数为 1 时，把最后的 3 和 1 改成 2 和 2。

核心洞察

当一段长度 x ≥ 5 时，拆出 3 不会变差，因为 3(x - 3) ≥ x。而任意整数 x ≥ 5 也可以继续拆成 3 与剩余部分。相比拆 2，拆 3 的乘积增长更快；但余数为 1 时，3 × 1 不如 2 × 2，所以要回退一个 3。

完整过程

  1. 1. 特判
    n=2 返回 1；n=3 返回 2。
  2. 2. 取 3
    当 n > 4，乘上 3。
  3. 3. 缩短
    n 减去 3，继续判断。
  4. 4. 收尾
    剩余 2、3、4 直接乘入。

边界与复杂度

  • n=2：只能切为 1+1，结果 1。
  • n=3：切为 1+2，结果 2。
  • 时间：O(n)，循环约 n/3 次；空间：O(1)。

替代方案、追问与常见错误

动态规划：令 dp[i] 为长度 i 的最大乘积，枚举第一段，时间 O(n²)、空间 O(n)，更直观但不如贪心精简。
追问：若结果很大需要取模，应如何快速幂计算 3 的指数？若允许不切，n=2、3 的结果如何变化？
常见错误：没有“至少切一刀”的特判；看到余数 1 仍乘 1；循环条件写为 n > 3，会让 n=4 错误拆成 3+1。

官方签名代码

// Java
class Solution {
  public int cuttingBamboo(int bamboo_len) {
    if (bamboo_len == 2) return 1;
    if (bamboo_len == 3) return 2;
    int ans = 1;
    while (bamboo_len > 4) {
      ans *= 3; bamboo_len -= 3;
    }
    return ans * bamboo_len;
  }
}
