01 · Problem

题目要求

给定一棵二叉搜索树的根节点 root 与整数 val，把新值插入树中，并返回插入后的根节点。

输入保证 val 不在原树中。插入后必须继续满足二叉搜索树性质：每个节点左子树中的值都更小，右子树中的值都更大。可能有多种合法插法，返回任意一种合法结果即可。

示例 1

输入：root = [4,2,7,1,3], val = 5
输出：[4,2,7,1,3,5]
说明：其他保持 BST 性质的插入结果也可接受。

示例 2

输入：root = [40,20,60,10,30,50,70], val = 25
输出：[40,20,60,10,30,50,70,null,null,25]

示例 3

输入：root = [4,2,7,1,3,null,null,null,null,null,null], val = 5
输出：[4,2,7,1,3,5]
  • 树中节点数范围为 [0, 104]
  • -108 ≤ Node.val ≤ 108
  • 所有 Node.val 互不相同
  • -108 ≤ val ≤ 108
  • 保证 val 不存在于原始 BST 中

    03 · Solution

    迭代定位第一个空孩子

    利用 BST 的有序性，只需沿一条从根到叶的路径下降，无须遍历整棵树。

    i

    核心洞察

    在任意节点 cur，若 val < cur.val，新节点只能进入左子树；否则只能进入右子树。目标方向为空时，就在这里连接新节点并结束。

    完整过程

    1. 若 root 为空，直接返回值为 val 的新节点。
    2. 令游标 cur = root，反复比较 val 与 cur.val。
    3. 该走左边且左孩子为空，就把新节点接为左孩子；否则令 cur = cur.left。
    4. 该走右边时完全对称。连接完成后返回原根节点。

    正确性证明

    循环不变式：每次循环开始时，若存在合法插入位置，它必定位于以 cur 为根的子树中。比较后，BST 性质排除了另一侧子树，因此沿选定方向仍保持不变式。当目标孩子为空时，新值与所有祖先的大小关系已由路径上的比较保证；把它接入该空位不会改变任何已有节点关系，所以整棵树仍是 BST。算法由此正确。

    边界情况

    • 空树：新节点直接成为根。
    • 新值小于或大于路径上的所有值：最终接到最左或最右空位。
    • 极度倾斜的树：迭代写法不会增加递归调用栈。
    • 题目保证值唯一，因此无须定义“相等”分支；生产代码若无此保证，应明确重复值策略。

    复杂度

    令 h 为树高。算法只访问从根到插入位置的一条路径。

    时间O(h)
    额外空间O(1)
    最坏树高O(n)

    替代方案

    递归：代码更贴近树的定义：递归插入左或右子树，再把返回的子树根接回当前节点。时间仍为 O(h)，但调用栈为 O(h)。还可以先沿路径找到任意合法空位；题目允许多种结果，不过标准叶子插入最直接。

    常见错误

    • 找到空孩子后只移动游标，没有真正修改父节点指针。
    • 插入非空树后返回了游标或新节点，而不是原始 root。
    • 忘记单独处理空树，导致访问空指针。
    • 方向写反：较小值必须向左，较大值必须向右。

    面试追问

    • 如果允许重复值，你会把相等值放在哪一侧，或如何计数？
    • 连续插入有序数据为何会退化到 O(n)？怎样用 AVL 树或红黑树避免？
    • 如何实现不可变 BST，使插入只复制搜索路径上的节点？
    • 递归与迭代在高度接近 104 时有什么风险差异？

    一句话记忆

    “比当前小就去左边，否则去右边；第一次遇到空孩子，就把新节点挂上去。”

    四语言完整代码

    /**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode insertIntoBST(TreeNode root, int val) {
        if (root == null) {
            return new TreeNode(val);
        }

        TreeNode cur = root;
        while (true) {
            if (val < cur.val) {
                if (cur.left == null) {
                    cur.left = new TreeNode(val);
                    break;
                }
                cur = cur.left;
            } else {
                if (cur.right == null) {
                    cur.right = new TreeNode(val);
                    break;
                }
                cur = cur.right;
            }
        }
        return root;
    }
}

 * }
 */
