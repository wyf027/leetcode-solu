最大差值

Maximum Difference Between Increasing Elements

先读懂问题

给定长度为 n 的整数数组 nums，从中选择两个位置 i、j：前一个位置必须在左边，后一个值必须更大。求所有合法选择中最大的 nums[j] − nums[i]；没有合法选择则返回 −1。

0 ≤ i < j < n
nums[i] < nums[j]

输入与约束

  • n == nums.length
  • 2 ≤ n ≤ 1000
  • 1 ≤ nums[i] ≤ 10⁹

参数：nums，整数数组
返回：整数
官方方法名：maximumDifference

先想一想：数组中的最大值减最小值，一定合法吗？

向下阅读示例，或进入交互实验。完整题解需主动展开。

01 / UNDERSTAND

示例 1

输入：nums = [7,1,5,4]
输出：4

示例 2

输入：nums = [9,4,3,2]
输出：-1

示例 3

输入：nums = [1,5,2,10]
输出：9

i = 0, j = 3，得到 10 − 1 = 9。两个位置不必相邻。

04 / EXPLAIN

独立题解

准备好后，再查看算法与完整代码。

核心洞察：固定右端点，只需最小的左值

当右端点 j 固定，nums[j] 就是常量。要让差值最大，只需从 [0, j−1] 中选最小值 minValue。若 nums[j] ≤ minValue，本轮不存在合法组合；否则差值为 nums[j] − minValue。

完整过程

  1. 用 nums[0] 初始化左侧最小值，答案初始化为 −1。
  2. 从 j = 1 扫描到 n−1。先判断当前值是否严格大于左侧最小值；若成立，用差值更新答案。
  3. 比较完成后，将当前值纳入最小值：minValue = min(minValue, nums[j])，为下一个右端点做准备。
  4. 返回答案；如果从未出现正差值，答案仍为 −1。

以 [7,1,5,4] 为例：初始最小值是 7；遇到 1 时无合法差值，将最小值降为 1；遇到 5 得到 4；遇到 4 得到 3，保留答案 4。扫描台在每一步显示的是“比较之前”的左侧最小值。

为什么正确

循环不变式：处理位置 j 之前，minValue 是 nums[0..j−1] 的最小值，best 是所有右端点小于 j 的合法配对的最大差值；若没有合法配对则为 −1。

初始化：j = 1 时，左侧仅 nums[0]，还没有处理任何右端点，不变式成立。保持：若 nums[j] 大于 minValue，该差值是以 j 为右端点的最大合法差值；否则所有左侧元素都不小于 nums[j]，本轮没有合法配对。合并本轮结果后，再更新 minValue，不变式推进至 j+1。终止：全部右端点都被处理，best 覆盖所有合法配对，因此返回值正确。

边界与复杂度

  • 相等不满足严格递增，不能把差值 0 当作答案；递减和全相等数组返回 −1。
  • 长度为 2 时只需处理一次。最优位置允许不相邻。
  • 最大差值为 10⁹−1，Java / C++ 的 32 位有符号整数和 JavaScript 的 Number 都足够。
  • 时间 O(n)，额外空间 O(1)，输入不被修改。扫描台为回放保存步骤并渲染数组，会使用 O(n) 空间，这不属于提交算法的空间复杂度。

替代方案

暴力枚举所有 i < j，并过滤 nums[i] < nums[j]，时间 O(n²)、空间 O(1)，适合解释定义。也可建立前缀最小值数组，时间 O(n)、空间 O(n)；当只需一个最终答案时，单个变量已经足够。反向扫描维护右侧最大值是对称的 O(n) 时间、O(1) 空间做法。

常见错误

  • 直接全局最大值减全局最小值：忽略位置先后。
  • 先排序：破坏原始下标关系。
  • 答案从 0 开始，或允许相等：无合法配对时应返回 −1。
  • 只比较相邻元素：遗漏跨多个位置的更大差值。
  • 用当前元素更新最小值后才解释候选下标：可能把 i = j 当作候选。先比较再更新，严格保持左侧范围。

面试追问

  • 如何返回下标？额外维护最小值的下标，在答案增大时记录这对 i、j；同差值的取舍需约定规则。
  • 能处理数据流吗？可以，每次到达新值先计算差值再更新最小值，只保留常数状态。
  • 与单次股票交易有何区别？核心扫描机制一致，但本题没有正差值时返回 −1，常见股票题返回 0。
  • 若 j−i 有上界？候选范围成为滑动窗口，旧最小值会过期，可使用单调队列维护窗口最小值。

Java

class Solution {
    public int maximumDifference(int[] nums) {
        int minValue = nums[0];
        int best = -1;
        for (int j = 1; j < nums.length; j++) {
            if (nums[j] > minValue) {
                best = Math.max(best, nums[j] - minValue);
            }
            minValue = Math.min(minValue, nums[j]);
        }
        return best;
    }
}
