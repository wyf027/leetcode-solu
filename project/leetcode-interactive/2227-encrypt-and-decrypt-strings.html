2227. 加密解密字符串

Encrypt and Decrypt Strings

同一个密文，可能对应多个原文。你需要返回其中被字典允许的原文数量。

官方题目 ↗

01 / 题目与接口

给定互不相同的字符数组 keys、等长数组 values（每项恰好两个字符），以及由不同单词组成的 dictionary。构造一个支持下列操作的对象：

  • Encrypter(char[] keys, String[] values, String[] dictionary)：初始化映射和允许的原文集合。
  • String encrypt(String word1)：依次将字符 keys[i] 替换成 values[i]，拼接得到密文。若有字符没有映射，返回空字符串。
  • int decrypt(String word2)：从下标 0 开始，每两个字符分成一组。每组可替换成任意一个映射到该组的字符。返回所有可能原文中，出现在字典里的字符串数目。
先思考

题目要求返回的是数量，不要求列出所有原文。映射值能重复，但字符键和字典单词不重复。

02 / 官方示例

操作：
["Encrypter", "encrypt", "decrypt"]
参数：
[
  [
    ["a", "b", "c", "d"],
    ["ei", "zf", "ei", "am"],
    ["abcd", "acbd", "adbc", "badc", "dacb", "cadb", "cbda", "abad"]
  ],
  ["abcd"],
  ["eizfeiam"]
]
输出：
[null, "eizfeiam", 2]

abcd 依次产生 ei | zf | ei | am。解密时，两处 ei 都能选 a 或 c，得到 abad、cbad、abcd、cbcd。只有 abad 与 abcd 属于字典，因此数量为 2。

03 / 完整约束

  • 1 ≤ keys.length = values.length ≤ 26；values[i].length = 2。
  • 1 ≤ dictionary.length ≤ 100；1 ≤ dictionary[i].length ≤ 100。
  • keys 内字符互不相同；dictionary 内单词互不相同。
  • 1 ≤ word1.length ≤ 2000，且 word1 的每个字符都出现在 keys 中。
  • 2 ≤ word2.length ≤ 200，长度为偶数。
  • keys、values[i]、dictionary[i]、word1、word2 仅含小写英文字母。
  • encrypt 和 decrypt 合计最多调用 200 次。

元数据的中文字段将 word2 下界写为 1，英文为 2；结合偶数长度要求，有效最小长度均为 2。字典单词不保证所有字符都有映射。

05 / 题解：把字典送进加密器

核心洞察

加密是确定的函数 E。一个字典词 w 能由密文 s 解密得到，当且仅当 E(w) = s。既然合法原文最多只有 100 个，可以在初始化时把所有可加密的字典词加密，统计每个密文出现的次数。

完整过程

  1. 建立字符到二字符字符串的映射 encode。
  2. 遍历每个字典词，逐字符查映射并拼接。有任意缺失字符就放弃整词。
  3. 对有效密文执行 count[cipher] += 1，让碰撞的不同原文落入同一计数桶。
  4. encrypt 直接执行映射拼接；decrypt 返回 count[word2]，键不存在返回 0。

为什么正确

等价关系：若 w 可由 s 解密，每个 w[i] 都映射到 s 的第 i 个二字符块，所以 E(w) = s。反过来，若 E(w) = s，逐块选择 w[i] 就是一条合法解密路径。

计数不变量：处理前 k 个字典词后，count[s] 恰等于其中可加密且密文为 s 的词数。初始为空成立；新词无映射时不能产生合法路径，应跳过；否则只使自己的密文桶加一，保持不变量。

结论：处理完整字典后，查询桶计数就是满足等价关系的合法原文数。字典词唯一，因此不需要额外去重；同一原文的确定加密也不会被重复计算。

边界与常见错误

  • 多个键映射到相同值是合法碰撞，计数要累加，不能覆盖成 1。
  • 解密只数字典内词；直接把每个块的候选数相乘，会把字典外组合也算进去。
  • 字典可能含缺失映射的字符。不能删除该字符继续拼接，也不能将失败的空串加入计数。
  • 不同长度的原文产生不同长度密文；同一桶内所有原文长度必然一致。
  • 不存在的密文返回 0；encrypt 不受 dictionary 限制。
  • 不要误以为 encrypt(decrypt(s)) 是接口目标：decrypt 返回整数，并非原文。

复杂度

设 K 为键数，S 为字典总字符数，L 为待加密词长度，M 为待解密密文长度，U 为全部不同有效密文的总长度。

  • 初始化：期望时间 O(K + S)，额外持久空间 O(K + U)，其中 U ≤ 2S；单词转换临时空间 O(字典最大词长)。
  • encrypt：时间 O(L)，结果及拼接缓存空间 O(L)。
  • decrypt：哈希表期望常数次桶访问；计入字符串哈希或比较成本，通常记为期望 O(M) 时间，额外空间 O(1)。不能无条件将任意长字符串查表算作总时间 O(1)。
  • 以上为通常的哈希表平均表现，不承诺对抗性哈希碰撞下的最坏常数查询。

替代方案

每次 decrypt 逐个加密字典词并比较，单次 O(S + M)，实现直观，但重复查询重复做工。逆映射 DFS 的候选树最坏可达 O(26M/2)；字典 Trie 能剪掉不属于任何字典前缀的路径，但本题字典静态且只需数量，预计算计数表更直接。

面试追问

  • 字典支持增删？计算单词密文，对桶增减；另存原词集合以避免重复插入或删除不存在的词。
  • 要返回具体原文？把桶值从计数改成词列表，查询另需 O(输出大小)。
  • 映射可修改？现有密文索引失效；小字典直接重建最简单。
  • value 不再固定两字符？正向加密统计仍可服务“有至少一种切分的原文数”，但原题的逐二字符块解密定义需要同步修改，不能原样套用。

JavaScript
var Encrypter = function(keys, values, dictionary) {
    this.encode = new Map(keys.map((key, i) => [key, values[i]]));
    this.count = new Map();
    for (const word of dictionary) {
        const cipher = this.encrypt(word);
        if (cipher !== "") {
            this.count.set(cipher, (this.count.get(cipher) || 0) + 1);
        }
    }
};

Encrypter.prototype.encrypt = function(word1) {
    const parts = [];
    for (const ch of word1) {
        if (!this.encode.has(ch)) return "";
        parts.push(this.encode.get(ch));
    }
    return parts.join("");
};

Encrypter.prototype.decrypt = function(word2) {
    return this.count.get(word2) || 0;
};
Java
import java.util.HashMap;
import java.util.Map;

class Encrypter {
    private final String[] encode = new String[26];
    private final Map<String, Integer> count = new HashMap<>();

    public Encrypter(char[] keys, String[] values, String[] dictionary) {
        for (int i = 0; i < keys.length; i++) {
            encode[keys[i] - 'a'] = values[i];
        }
        for (String word : dictionary) {
            String cipher = encrypt(word);
            if (!cipher.isEmpty()) {
                count.merge(cipher, 1, Integer::sum);
            }
        }
    }

    public String encrypt(String word1) {
        StringBuilder result = new StringBuilder(word1.length() * 2);
        for (int i = 0; i < word1.length(); i++) {
            String value = encode[word1.charAt(i) - 'a'];
            if (value == null) return "";
            result.append(value);
        }
        return result.toString();
    }

    public int decrypt(String word2) {
        return count.getOrDefault(word2, 0);
    }
}
Python 3
from collections import Counter
from typing import List

class Encrypter:
    def __init__(self, keys: List[str], values: List[str],
                 dictionary: List[str]):
        self.encode = dict(zip(keys, values))
        self.count = Counter()
        for word in dictionary:
            cipher = self.encrypt(word)
            if cipher:
                self.count[cipher] += 1

    def encrypt(self, word1: str) -> str:
        parts = []
        for ch in word1:
            if ch not in self.encode:
                return ""
            parts.append(self.encode[ch])
        return "".join(parts)

    def decrypt(self, word2: str) -> int:
        return self.count[word2]
C++
#include <array>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Encrypter {
    array<string, 26> encode{};
    unordered_map<string, int> count;

public:
    Encrypter(vector<char>& keys, vector<string>& values,
              vector<string>& dictionary) {
        for (size_t i = 0; i < keys.size(); ++i) {
            encode[keys[i] - 'a'] = values[i];
        }
        for (const string& word : dictionary) {
            string cipher = encrypt(word);
            if (!cipher.empty()) ++count[cipher];
        }
    }

    string encrypt(string word1) {
        string result;
        result.reserve(word1.size() * 2);
        for (char ch : word1) {
            const string& value = encode[ch - 'a'];
            if (value.empty()) return "";
            result += value;
        }
        return result;
    }

    int decrypt(string word2) {
        auto it = count.find(word2);
        return it == count.end() ? 0 : it->second;
    }
};
