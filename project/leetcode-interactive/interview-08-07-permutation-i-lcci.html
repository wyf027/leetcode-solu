Problem brief

题意

输入字符串中的字符两两不同。返回它的全部排列，结果顺序不限。 字符串长度最多为 9，输出规模本身可达 n!。

任务与约束

给定字符串 S，重新安排其中全部字符，收集每一种不同顺序。 因为字符不重复，每条完整选择路径天然对应一个唯一答案。

  • S 仅由英文字母组成。
  • 1 <= S.length <= 9。
  • 所有字符互不相同，无需同层去重。
示例 1

S = "qwe"

输出 = ["qwe", "qew", "wqe", "weq", "ewq", "eqw"]

示例 2

S = "ab"

输出 = ["ab", "ba"]

Answer gate

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码均在此处，默认收起。

核心洞察

递归参数 depth 表示“接下来要确定哪个位置”。 对每个 i ∈ [depth, n)，把候选字符交换到 depth，于是前缀长度增加 1。递归返回后交换回来， 保证下一个候选看到同一份现场。

状态：chars + depth
选择：swap(depth, i)
递归：dfs(depth + 1)
撤销：swap(depth, i)

完整过程

  1. 把字符串转为可修改字符数组。
  2. 从 depth = 0 开始。
  3. 枚举剩余区间的每个候选，换到当前轨位。
  4. 递归确定下一位置。
  5. 当 depth == n 时复制字符数组并加入答案。
  6. 每次递归返回后交换复原，继续枚举。

边界与正确性

  • 长度为 1：第一次到达叶子就得到原字符串。
  • 字符互异：每层候选代表不同字符，不会产生重复排列。
  • 必须在叶子复制字符串；不能保存同一个可变数组引用。
  • 撤销交换维持回溯不变式：处理候选 i 前，后缀仍是本层原现场。

复杂度

一共有 n! 个答案，每个答案转成字符串需 O(n)，总时间为 O(n · n!)。 除输出外，字符数组与递归栈占 O(n)。 输出本身需要 O(n · n!) 空间。

替代方案

  • used 数组 + 路径：语义直观，但额外维护选择状态和路径。
  • 插入递归：把新字符插入旧排列的每个缝隙，思路漂亮， 但中间字符串复制更多。
  • next_permutation：先排序后迭代，适合按字典序输出， 面试中实现细节更重。

面试追问

  • 若字符可能重复怎么办？每层使用集合去重，或排序后跳过同层重复候选。
  • 能否惰性生成？把叶子结果改为迭代器 / generator 逐个产出。
  • 为什么无法做到多项式时间？仅输出 n! 个答案就需要指数级工作量。
  • 如何求第 k 个排列？使用阶乘数制，避免枚举全部排列。

常见错误

  • 递归后漏掉 swap back，导致兄弟分支从错误现场出发。
  • 循环从 0 开始，破坏已经锁定的前缀。
  • 过早加入答案，得到长度不足的路径。
  • 把复杂度误写成 O(n!)，忽略构造每个字符串的 O(n)。
  • 本题字符互异，却加入不必要的全局去重集合。

一句话证明

第 depth 层恰好把剩余每个字符各放到位置 depth 一次； 归纳地，每个前缀下生成全部且仅有一次的后缀排列， 因而所有完整排列不重不漏。

四语言可提交代码

class Solution {
    public String[] permutation(String S) {
        char[] chars = S.toCharArray();
        List<String> answer = new ArrayList<>();
        dfs(chars, 0, answer);
        return answer.toArray(new String[0]);
    }

    private void dfs(char[] chars, int depth, List<String> answer) {
        if (depth == chars.length) {
            answer.add(new String(chars));
            return;
        }

        for (int i = depth; i < chars.length; i++) {
            swap(chars, depth, i);
            dfs(chars, depth + 1, answer);
            swap(chars, depth, i);
        }
    }

    private void swap(char[] chars, int i, int j) {
        char temp = chars[i];
        chars[i] = chars[j];
        chars[j] = temp;
    }
}

var permutation = function (S) {
    const chars = [...S];
    const answer = [];

    const dfs = (depth) => {
        if (depth === chars.length) {
            answer.push(chars.join(""));
            return;
        }

        for (let i = depth; i < chars.length; i++) {
            [chars[depth], chars[i]] = [chars[i], chars[depth]];
            dfs(depth + 1);
            [chars[depth], chars[i]] = [chars[i], chars[depth]];
        }
    };

    dfs(0);
    return answer;
};
class Solution:
    def permutation(self, S: str) -> List[str]:
        chars = list(S)
        answer = []

        def dfs(depth: int) -> None:
            if depth == len(chars):
                answer.append("".join(chars))
                return

            for i in range(depth, len(chars)):
                chars[depth], chars[i] = chars[i], chars[depth]
                dfs(depth + 1)
                chars[depth], chars[i] = chars[i], chars[depth]

        dfs(0)
        return answer
class Solution {
public:
    vector<string> permutation(string S) {
        vector<string> answer;
        dfs(S, 0, answer);
        return answer;
    }

private:
    void dfs(string& chars, int depth, vector<string>& answer) {
        if (depth == static_cast<int>(chars.size())) {
            answer.push_back(chars);
            return;
        }

        for (int i = depth; i < static_cast<int>(chars.size()); ++i) {
            swap(chars[depth], chars[i]);
            dfs(chars, depth + 1, answer);
            swap(chars[depth], chars[i]);
        }
    }
};
