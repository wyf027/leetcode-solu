LeetCode 2398 / Maximum Number of Robots Within Budget

预算内的最多
机器人数目

连续选一段机器人，让总开销留在预算线内。先独立思考，再展开推演。

官方题目 ↗

01 / 任务说明

给定两个长度为 n、下标从 0 开始的整数数组 chargeTimes 和 runningCosts。第 i 个机器人的充电开销为 chargeTimes[i]，运行开销为 runningCosts[i]。另给定整数 budget。

选择一段连续的 k 个机器人，总开销按下式计算；其中最大值和求和都只在所选区间内计算。

总开销 = max(chargeTimes[l..r])
       + (r - l + 1) × sum(runningCosts[l..r])

返回总开销不超过预算时，可选择的最多连续机器人数目。若连一个机器人也无法负担，返回 0。

约束

  • chargeTimes.length == runningCosts.length == n
  • 1 ≤ n ≤ 5 × 10⁴
  • 1 ≤ chargeTimes[i], runningCosts[i] ≤ 10⁵
  • 1 ≤ budget ≤ 10¹⁵

02 / 官方示例

示例 1

chargeTimes = [3,6,1,3,4]
runningCosts = [2,1,3,4,5]
budget = 25
输出 = 3

选择下标 0 到 2：开销为 6 + 3 × (2+1+3) = 24。所有单个机器人及连续两个机器人的组合都在预算内，但没有长度超过 3 的可行连续区间。

示例 2

chargeTimes = [11,12,19]
runningCosts = [10,8,7]
budget = 19
输出 = 0

单个机器人的开销分别为 21、20、26，均大于 19，因此无法选择任何机器人。

03 / 思考入口

区间变长时，费用可能变小吗？最大充电开销与运行开销之和，分别需要保存什么信息？

展开后可查看过程演示、证明与四语言代码。

04 / 题解 · 滑动窗口与单调队列

核心洞察

开销都是正数，扩展区间时，最大充电开销不会下降，长度和运行开销之和都会增长。因此，固定右端点后，只需不断右移左端点，直到费用不再超预算。用运行和 sum 维护累加项，用一个按充电开销递减的双端队列维护最大值。

队列存下标：新元素进来时，删除队尾所有充电开销小于或等于它的下标。新元素更靠右、开销不小，会在未来窗口中更晚过期，旧元素永远不再需要。队首就是当前最大充电开销。

完整过程

  1. 初始化左端点 left=0、运行和与答案为 0、队列为空。
  2. 右端点逐个前进，将新运行开销加入 sum；删除较弱队尾后，将新下标入队。
  3. 若 chargeTimes[队首] + (right-left+1) × sum > budget，不断移除左端机器人。若其下标是队首，则同步弹出队首，再扣除运行开销并右移左端点。
  4. 窗口重新合法后，用当前长度更新答案；继续处理下一个右端点。

示例 1 中，右端点到 2 时费用为 24，答案更新为 3；到 3 时费用为 46，移除下标 0 后仍为 30，再移除下标 1 后降至 17。到 4 时费用为 40，收缩后为 22。最终答案仍为 3。

正确性

队列不变式：下标递增且充电开销严格递减。队尾删除只移除被更晚且更强元素支配的候选；左端离开时删除过期队首。因此队首总能给出窗口最大值，运行和也由一次加入、一次移除准确维护。

窗口不变式：每次更新答案前，窗口费用不超过预算。某个左端点一旦因超预算被舍弃，未来右端点更靠右时，费用只会不降，因此该左端点不可能重新成为可行选择。收缩停止时保留的是当前右端点对应的最长可行窗口。

全局最优：每个右端点都被处理，且其最长可行窗口都用于更新答案；任意最优区间都有一个右端点，所以最终记录一定等于全局最优长度。

边界与数值范围

  • 单个机器人也超预算：收缩到空窗口，长度为 0；空窗口不读取队首。
  • 费用恰等于预算时合法，收缩条件必须是 >。
  • 最大值重复时可以弹出旧的相等值，但必须保存新下标并按下标过期。
  • 运行和最大为 5 × 10⁹，总开销至多 250000000100000。Java 使用 long，C++ 使用 long long，乘法前提升类型。
  • 以上整数及预算不超过 JavaScript 安全整数上限 2⁵³−1，本题可用 Number；Python 整数无需额外处理。

复杂度

时间 O(n)：每个下标入队一次，最多出队一次，两个端点各前进至多 n 次。空间 O(n)：最坏情况下队列保存整个窗口。JavaScript 使用头尾指针，避免 shift() 反复搬移数组。

替代方案

二分答案长度：对固定长度，用滚动运行和与单调队列在 O(n) 时间内判断是否存在合法区间，总计 O(n log n)、空间 O(n)。正费用保证可行长度向下封闭。也可用平衡树维护窗口最大值，实现 O(n log n)；暴力枚举所有区间并增量维护费用需 O(n²)，仅适合小规模理解。

常见错误

  • 忘记“连续”而排序数组或任意挑选机器人。
  • 把费用写成 max + sum，漏乘当前窗口长度。
  • 仅收缩一次就更新答案，窗口可能仍然超预算；本实现需要 while。
  • 队列只存值导致重复值过期混乱；移除队首时未同步更新窗口。
  • 用 32 位整数计算乘积，或在窗口为空时访问队首。

面试追问

怎样返回区间？答案增长时记录 left 和 right。允许负运行开销还成立吗？不成立，扩张费用单调性与舍弃左端点的证明失效。为什么可以删除相等队尾？新下标相同强度且更晚过期。支持在线处理吗？可以，逐个接收机器人，保留当前窗口运行开销及最大值候选；不再需要完整历史数组。

Java

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int maximumRobots(int[] chargeTimes, int[] runningCosts, long budget) {
        Deque<Integer> q = new ArrayDeque<>();
        int left = 0, best = 0;
        long sum = 0;
        for (int right = 0; right < chargeTimes.length; right++) {
            sum += runningCosts[right];
            while (!q.isEmpty() && chargeTimes[q.peekLast()] <= chargeTimes[right]) {
                q.pollLast();
            }
            q.addLast(right);
            while (left <= right &&
                   chargeTimes[q.peekFirst()] + (long)(right - left + 1) * sum > budget) {
                if (q.peekFirst() == left) q.pollFirst();
                sum -= runningCosts[left++];
            }
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}

JavaScript

/**
 * @param {number[]} chargeTimes
 * @param {number[]} runningCosts
 * @param {number} budget
 * @return {number}
 */
var maximumRobots = function(chargeTimes, runningCosts, budget) {
    const q = new Array(chargeTimes.length);
    let head = 0, tail = 0, left = 0, sum = 0, best = 0;
    for (let right = 0; right < chargeTimes.length; right++) {
        sum += runningCosts[right];
        while (head < tail && chargeTimes[q[tail - 1]] <= chargeTimes[right]) {
            tail--;
        }
        q[tail++] = right;
        while (left <= right &&
               chargeTimes[q[head]] + (right - left + 1) * sum > budget) {
            if (q[head] === left) head++;
            sum -= runningCosts[left++];
        }
        best = Math.max(best, right - left + 1);
    }
    return best;
};

Python

from collections import deque
from typing import List

class Solution:
    def maximumRobots(self, chargeTimes: List[int], runningCosts: List[int], budget: int) -> int:
        q = deque()
        left = best = total = 0
        for right, charge in enumerate(chargeTimes):
            total += runningCosts[right]
            while q and chargeTimes[q[-1]] <= charge:
                q.pop()
            q.append(right)
            while left <= right and chargeTimes[q[0]] + (right - left + 1) * total > budget:
                if q[0] == left:
                    q.popleft()
                total -= runningCosts[left]
                left += 1
            best = max(best, right - left + 1)
        return best

C++

#include <algorithm>
#include <deque>
#include <vector>
using namespace std;

class Solution {
public:
    int maximumRobots(vector<int>& chargeTimes, vector<int>& runningCosts, long long budget) {
        deque<int> q;
        long long sum = 0;
        int left = 0, best = 0;
        for (int right = 0; right < (int)chargeTimes.size(); ++right) {
            sum += runningCosts[right];
            while (!q.empty() && chargeTimes[q.back()] <= chargeTimes[right]) {
                q.pop_back();
            }
            q.push_back(right);
            while (left <= right &&
                   chargeTimes[q.front()] + 1LL * (right - left + 1) * sum > budget) {
                if (q.front() == left) q.pop_front();
                sum -= runningCosts[left++];
            }
            best = max(best, right - left + 1);
        }
        return best;
    }
};
