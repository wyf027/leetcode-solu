CASE 16.03 CROSS EXAM

Problem

题意

给定两条线段，每条线段由起点和终点表示。若它们相交，返回交点；否则返回空数组。允许的浮点误差不超过 10^-6。若线段重叠产生多个交点，返回 X 最小的点；X 相同则返回 Y 最小的点。坐标绝对值不超过 2^7。

示例 1 · 输入 start1 = [0, 0], end1 = [1, 0], start2 = [1, 1], end2 = [0, -1] 输出 [0.5, 0]
示例 2 · 输入 start1 = [0, 0], end1 = [3, 3], start2 = [1, 1], end2 = [2, 2] 输出 [1, 1]
示例 3 · 输入 start1 = [0, 0], end1 = [1, 1], start2 = [1, 0], end2 = [2, 1] 输出 []

Solution Vault

题解

核心洞察、完整过程、边界、复杂度、替代方案与四语言代码默认收起。

核心洞察

参数方程负责“在哪相交”

写成 p + t·r = q + u·s，叉积消元后直接求出 t 与 u。

区间负责“线段是否相交”

直线交点只有在 t,u ∈ [0,1] 时才同时落在两条有限线段上。

共线负责“选哪个交点”

共同端点最多四个候选，筛选后按 X、Y 排序，首个就是题目要求的点。

完整过程

  1. 令 p = start1、r = end1 - start1，另有 q 与 s。
  2. 计算 den = cross(r, s)。非零表示两条所在直线不平行。
  3. 非平行时求 t = cross(q-p, s)/den 与 u = cross(q-p, r)/den。
  4. 只有 t、u 都在闭区间 [0,1] 内，才返回 p + t·r。
  5. 若 den 为 0，再检查 cross(q-p, r)：非零是平行不共线，直接无交点。
  6. 共线时检查四个端点是否同时位于两段上，按 X、Y 取字典序最小者。

边界与数值

  • 竖直线无需斜率，因此不会出现除以零的特殊分支。
  • 端点相接属于相交，参数等于 0 或 1 都应接受。
  • 零长度线段仍可作为点处理，共线候选法自然覆盖。
  • 坐标是整数，叉积先用整数精确判断；只在最终求 t、u 时转浮点。
  • 输出中的 -0 统一整理为 0，不影响误差要求。

复杂度

  • 时间复杂度：O(1)，只进行固定次数向量与端点运算。
  • 空间复杂度：O(1)，候选集合最多包含四个端点。
  • Java/C++ 使用 64 位整数保存叉积，虽然本题范围内 32 位也足够。

替代方案

斜率 + 截距

直观，但竖直线、重合线和浮点误差会制造大量分支，不推荐面试主线。

方向判定四次叉积

适合只判断是否相交；本题还要返回坐标，最终仍需求参数或直线方程。

包围盒 + 直线方程

可先快速排除，但这里只有两条线段，增加预判不会改善渐进复杂度。

面试追问

  • 如果坐标范围扩大到 10^9，叉积可能溢出 64 位，应如何选择大整数或精确谓词？
  • 如果有 N 条线段，需要报告所有交点，何时使用 Bentley–Ottmann 扫描线？
  • 若只需判断严格相交、不允许端点接触，区间条件应该如何改变？
  • 如何为浮点输出设计相对误差与绝对误差兼顾的测试断言？

常见错误

  • 只判断两条无限直线是否相交，忘记检查 t、u 是否属于 [0,1]。
  • 用斜率判断平行，导致竖直线需要额外分支或产生 Infinity。
  • 共线重叠时随便返回一个端点，没有按 X、Y 的字典序取最小。
  • 只检查两个起点作为重叠候选，遗漏“某个终点落在另一段内”。
  • 用浮点数判断叉积是否为零；本题输入是整数，应保留精确整数判定。

class Solution {
    public double[] intersection(int[] start1, int[] end1,
                                 int[] start2, int[] end2) {
        long[] p = {start1[0], start1[1]};
        long[] q = {start2[0], start2[1]};
        long[] r = {end1[0] - start1[0], end1[1] - start1[1]};
        long[] s = {end2[0] - start2[0], end2[1] - start2[1]};
        long den = cross(r, s);
        long[] qp = {q[0] - p[0], q[1] - p[1]};

        if (den != 0) {
            double t = (double) cross(qp, s) / den;
            double u = (double) cross(qp, r) / den;
            if (t >= 0 && t <= 1 && u >= 0 && u <= 1) {
                return new double[]{clean(p[0] + t * r[0]),
                                    clean(p[1] + t * r[1])};
            }
            return new double[0];
        }

        if (cross(qp, r) != 0) return new double[0];
        int[][] points = {start1, end1, start2, end2};
        int[] best = null;
        for (int[] point : points) {
            if (onSegment(point, start1, end1)
                    && onSegment(point, start2, end2)
                    && (best == null || point[0] < best[0]
                    || (point[0] == best[0] && point[1] < best[1]))) {
                best = point;
            }
        }
        return best == null ? new double[0]
                : new double[]{best[0], best[1]};
    }

    private long cross(long[] a, long[] b) {
        return a[0] * b[1] - a[1] * b[0];
    }

    private boolean onSegment(int[] p, int[] a, int[] b) {
        long[] ap = {p[0] - a[0], p[1] - a[1]};
        long[] ab = {b[0] - a[0], b[1] - a[1]};
        return cross(ap, ab) == 0
                && p[0] >= Math.min(a[0], b[0])
                && p[0] <= Math.max(a[0], b[0])
                && p[1] >= Math.min(a[1], b[1])
                && p[1] <= Math.max(a[1], b[1]);
    }

    private double clean(double value) {
        return Math.abs(value) < 1e-10 ? 0.0 : value;
    }
}
/**
 * @param {number[]} start1
 * @param {number[]} end1
 * @param {number[]} start2
 * @param {number[]} end2
 * @return {number[]}
 */
var intersection = function (start1, end1, start2, end2) {
  const sub = (a, b) => [a[0] - b[0], a[1] - b[1]];
  const cross = (a, b) => a[0] * b[1] - a[1] * b[0];
  const onSegment = (p, a, b) =>
    cross(sub(p, a), sub(b, a)) === 0 &&
    p[0] >= Math.min(a[0], b[0]) &&
    p[0] <= Math.max(a[0], b[0]) &&
    p[1] >= Math.min(a[1], b[1]) &&
    p[1] <= Math.max(a[1], b[1]);

  const p = start1;
  const q = start2;
  const r = sub(end1, start1);
  const s = sub(end2, start2);
  const qp = sub(q, p);
  const den = cross(r, s);

  if (den !== 0) {
    const t = cross(qp, s) / den;
    const u = cross(qp, r) / den;
    if (t >= 0 && t <= 1 && u >= 0 && u <= 1) {
      const clean = (value) => (Math.abs(value) < 1e-10 ? 0 : value);
      return [clean(p[0] + t * r[0]), clean(p[1] + t * r[1])];
    }
    return [];
  }

  if (cross(qp, r) !== 0) return [];
  return [start1, end1, start2, end2]
    .filter(
      (point) =>
        onSegment(point, start1, end1) &&
        onSegment(point, start2, end2),
    )
    .sort((a, b) => a[0] - b[0] || a[1] - b[1])
    .slice(0, 1)
    .flat();
};

class Solution {
public:
    vector<double> intersection(vector<int>& start1, vector<int>& end1,
                                vector<int>& start2, vector<int>& end2) {
        auto sub = [](const vector<int>& a, const vector<int>& b) {
            return array<long long, 2>{a[0] - b[0], a[1] - b[1]};
        };
        auto cross = [](const auto& a, const auto& b) {
            return a[0] * b[1] - a[1] * b[0];
        };
        auto r = sub(end1, start1);
        auto s = sub(end2, start2);
        auto qp = sub(start2, start1);
        long long den = cross(r, s);

        if (den != 0) {
            double t = static_cast<double>(cross(qp, s)) / den;
            double u = static_cast<double>(cross(qp, r)) / den;
            if (0 <= t && t <= 1 && 0 <= u && u <= 1) {
                double x = start1[0] + t * r[0];
                double y = start1[1] + t * r[1];
                return {abs(x) < 1e-10 ? 0.0 : x,
                        abs(y) < 1e-10 ? 0.0 : y};
            }
            return {};
        }

        if (cross(qp, r) != 0) return {};
        auto onSegment = [&](const vector<int>& point,
                             const vector<int>& a,
                             const vector<int>& b) {
            auto ap = sub(point, a);
            auto ab = sub(b, a);
            return cross(ap, ab) == 0
                && min(a[0], b[0]) <= point[0] && point[0] <= max(a[0], b[0])
                && min(a[1], b[1]) <= point[1] && point[1] <= max(a[1], b[1]);
        };

        vector<vector<int>> candidates;
        for (const auto& point : {start1, end1, start2, end2}) {
            if (onSegment(point, start1, end1)
                    && onSegment(point, start2, end2)) {
                candidates.push_back(point);
            }
        }
        if (candidates.empty()) return {};
        sort(candidates.begin(), candidates.end());
        return {static_cast<double>(candidates[0][0]),
                static_cast<double>(candidates[0][1])};
    }
};
