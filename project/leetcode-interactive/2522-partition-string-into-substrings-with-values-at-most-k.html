将字符串分割成值不超过 K 的子字符串

Partition String Into Substrings With Values at Most K

在数字之间放置分隔线。每一段都要合规，分段数量要尽可能少。

01 / 题目

给定仅由数字 1 到 9 组成的字符串 s，以及整数 k。把 s 切成若干个非空、连续的子字符串，保持原有顺序，且每个字符恰好属于一段。

把每段看作十进制整数，其值都必须 ≤ k。返回满足条件的最少段数；如果无法完成分割，返回 -1。

例如字符串 “123” 的值是 123。不能重排字符，也不能跳过某一位。

输入边界

  • 1 ≤ s.length ≤ 10⁵
  • s[i] ∈ {'1', …, '9'}
  • 1 ≤ k ≤ 10⁹

函数：minimumPartition(s, k) → integer

05 / 题解笔记

准备好后，展开推导与四语言实现。

让每段尽可能向右延伸

核心洞察

数位都是正数字，向右追加一位会使数值严格增大。当前段还能放下下一位时，继续追加；第一次超过 k 时，在这位之前切开。如果某一位本身大于 k，它所在的任何段都不合法，立即返回 -1。

完整过程

  1. 令 count = 1、value = 0；字符串按约束非空。
  2. 逐位取得数字 d，先判断 d > k，成立则无解。
  3. 计算 next = value × 10 + d。若 next ≤ k，把这一位加入当前段。
  4. 否则在 d 前切分，令 count++，新段从 value = d 开始。不能丢掉触发切分的这一位。
  5. 全部处理后返回 count。

示例 1：读入 1、6 得到 16；拼 5 得 165 > 60，切为 16 | 5；拼 4 得 54；拼 6 得 546 > 60，切为 16 | 54 | 6；拼 2 得 62 > 60，最终 16 | 54 | 6 | 2。

正确性：同样段数，贪心覆盖得最远

设贪心前 j 段覆盖到位置 Gj，任意合法分法前 j 段覆盖到 Oj。证明 Gⱼ ≥ Oⱼ，即贪心始终不会落后。

  1. j = 1 时，贪心选择最长合法前缀，显然不短于其他分法的第一段。
  2. 假设 Gⱼ₋₁ ≥ Oⱼ₋₁。若 Gⱼ₋₁ ≥ Oⱼ，结论已成立。
  3. 否则，从 Gⱼ₋₁ + 1 到 Oⱼ 是其他分法第 j 段的一个后缀。去掉正数的前缀不会增大其十进制值，因此该后缀仍 ≤ k。贪心选最长合法段，至少可延伸到 Oⱼ。

若某个最优分法用 m 段覆盖全串，贪心用至多 m 段也覆盖全串。贪心产生的每段都合法，所以它恰好最优。若有 d > k，包含 d 的整数值至少为 d，因此返回 -1 正确；若每位都 ≤ k，逐位切分至少是一种合法方案。

边界与数值安全

  • 相等可以追加：只有 next > k 才切分。
  • 没有空串与数字 0；无需为官方输入添加前导零逻辑。
  • Java 用 long、C++ 用 long long 计算候选值；value × 10 + d 可能超过 32 位整数。
  • 候选值不超过 10k + 9 ≤ 10¹⁰ + 9，小于 JavaScript 的安全整数上限。Python 整数无需担心溢出。
  • 最后一段已在 count 中，不需要遍历结束后再加一。

复杂度

时间 O(n)，每位只处理一次；辅助空间 O(1)，只保存当前值和计数。可视化为支持回退保存快照，空间开销与提交算法不同。

替代方案

动态规划：dp[i] 表示前 i 位的最少段数，枚举以 i 结尾、值 ≤ k 的最后一段，更新 dp[i] = min(dp[j] + 1)，初始 dp[0] = 0。合法段长度最多为 k 的十进制位数 D，因此时间 O(nD)、空间 O(n)。它便于扩展段费用规则，但本题只求段数，用贪心即可。

常见错误

  • 把整个 s 转成一个数：长度可达 10⁵，既没必要也会溢出。
  • 超限后把 value 置为 0，丢失当前数字；应置为 d。
  • 没有检查单个数字是否大于 k，给无解输入算出段数。
  • 误写 next >= k，把可以合并的相等情况切开。
  • 只说“尽量放满”而没有最优性论证；应给出覆盖位置归纳或交换论证。

面试追问

如何返回实际分段？ 在每次切分时记录边界，末尾补上 n；额外空间 O(段数)。
输入是流怎么办？ 保留当前值和段数即可逐位处理；遇到非法数位可提前结束。
如果每段有不同费用？ 当前贪心证明不再保证费用最小，考虑动态规划。
k 超出整数安全范围怎么办？ 使用大整数，或按位数与字典序比较数字字符串。

Java

class Solution {
    public int minimumPartition(String s, int k) {
        int count = 1;
        long value = 0;
        for (int i = 0; i < s.length(); i++) {
            int d = s.charAt(i) - '0';
            if (d > k) return -1;
            long next = value * 10 + d;
            if (next > k) {
                count++;
                value = d;
            } else {
                value = next;
            }
        }
        return count;
    }
}
