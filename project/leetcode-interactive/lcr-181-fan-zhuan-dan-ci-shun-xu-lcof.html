字符串中的单词反转

朋友习惯从右往左阅读：单词内容仍正确，只是整句话的词序相反。把输入消息整理为正常语序，同时让多余空格消失。

官方题意

将 message 转换为正常语序。输入可能含前导、尾随或连续空格；结果中的单词仅以一个空格分隔，且没有额外空格。

示例 1message = "the sky is blue"
输出："blue is sky the"
示例 2message = "␠␠hello␠world!␠␠"
输出："world! hello"
示例 3message = "a␠good␠␠␠example"
输出："example good a"

约束：0 ≤ message.length ≤ 10⁴；message 仅含英文大小写字母、空格和数字。下方将空格渲染为 ␠，仅用于可视化，不改变真实字符串。

题解：从右向左收集单词

核心洞察

词本身无需翻转；只需按从右到左的顺序读取完整单词。跳过空格后，找到一个单词的左右边界，再追加到答案。用一次连接自然保证单词间恰为一个空格。

完整过程

  1. 令指针从末尾开始，跳过尾部或单词之间的空格。
  2. 记录单词右端；向左移动到空格或开头，得到一个完整单词。
  3. 将它追加至结果；重复直到指针越过开头。

边界与复杂度

空串或纯空格返回 ""；单词之间的任意多个空格都会被压缩。时间复杂度 O(n)，辅助空间 O(n)（输出与单词数组）。

替代方案、追问与常见错误

替代：message.trim().split(/\s+/).reverse().join(" ") 简洁但依赖正则。追问：若要求原地字符数组，可先整体反转再逐词反转。常见错误：反转每个单词字符、没有过滤空白、或在结果末尾多拼一个空格。 
/** @param {string} message @return {string} */
var reverseMessage = function(message) {
  const words = [];
  let i = message.length - 1;
  while (i >= 0) {
    while (i >= 0 && message[i] === " ") i--;
    if (i < 0) break;
    const end = i;
    while (i >= 0 && message[i] !== " ") i--;
    words.push(message.slice(i + 1, end + 1));
  }
  return words.join(" ");
};
class Solution:
    def reverseMessage(self, message: str) -> str:

class Solution {
    public String reverseMessage(String message) {
        StringBuilder ans = new StringBuilder();
        int i = message.length() - 1;
        while (i >= 0) {
            while (i >= 0 && message.charAt(i) == ' ') i--;
            if (i < 0) break;
            int end = i;
            while (i >= 0 && message.charAt(i) != ' ') i--;
            if (ans.length() > 0) ans.append(' ');
            ans.append(message, i + 1, end + 1);
        }
        return ans.toString();
    }
}
