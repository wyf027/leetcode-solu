Valid Palindrome IV · 一到两次改动，能否让文字映成镜像？

先理解操作规则，再亲手推进演示。解题推导与四语言代码折叠在页面底部。

01题目与约定

给定从下标 0 开始的字符串 s，其中只有小写英文字母。每次操作选择一个位置，将该字符替换成另一个字符。判断能否在恰好执行 1 次或 2 次操作后，得到正读与反读一致的字符串；可以则返回 true，否则返回 false。

这是字符替换操作，字符串长度保持不变。即使原串已经是回文，也需要满足操作次数要求。
  • 参数：s: string；返回：boolean。
  • 官方函数名：makePalindrome(s)。
  • 约束：1 ≤ s.length ≤ 100000，且 s 仅包含 a–z。

来源：本地官方元数据提供题名、签名及示例输入；付费题面字段为空，规则、输出和约束参照公开题目资料简要转述。官方题目。

02官方示例

示例 1

输入：s = "abcdba"
输出：true

示例 2

输出：true

依次替换两个 a：aa → ba → bb。两次操作后仍是回文。

输出：false

无论选择怎样的字符替换，1 次或 2 次操作都不够。

05独立题解

想好了吗？展开阅读推导与实现。

把修改次数，换成镜像差异数

核心洞察

只看 i < n - 1 - i 的镜像位置对。设其中字符不同的对数为 d，使字符串成为回文的最少替换次数就是 d。本题答案为 d ≤ 2，但需要额外解释 d = 0 时怎样执行合法操作。

完整过程

  1. 让左指针从 0 出发，右指针从 n − 1 出发，差异计数初始化为 0。
  2. 当左指针小于右指针时比较字符；不同就将计数加 1。
  3. 一旦差异数达到 3，立即返回 false；已经确定至少需要三次替换。
  4. 两端同时向内移动。处理完所有位置对仍未超过两组差异，返回 true。

例如 abcdba：依次比较 (0,5) 的 a/a、(1,4) 的 b/b、(2,3) 的 c/d，差异计数为 0、0、1；一次替换可得到 abddba。对 abcdef，三组均不同，计数达到 3 后返回 false。

正确性：下界与构造一致

必要性：每组不同的镜像字符至少要改动其中一个位置；不同镜像对没有公共位置，一次操作无法修复两组。因此至少需要 d 次操作，d > 2 时不可能成功。

充分性：d 为 1 或 2 时，把每组差异对的一端改成另一端，正好使用 d 次操作，所有镜像对相等。d 为 0 时，若长度为奇数，替换中心字符一次仍是回文；若长度为偶数，长度至少为 2，将任意一对对称字符都改成同一个不同字符，恰好两次，仍是回文。因此 d ≤ 2 都可以成功。

循环不变式：每次比较开始前，计数恰好等于两指针外侧已处理区域中的差异对数。比较并移动维持该事实；相遇时所有镜像对均已覆盖，所以返回值正确。

边界与常见错误

  • 长度 1：循环不执行，答案 true；更换唯一字符一次即可。
  • 已有回文：不能因为差异为 0 就返回 false；存在保持回文的合法改动。
  • 奇数长度：中心字符不参与成对比较。例如 abcde 只有两组差异，结果是 true。
  • 计数单位是“不同的镜像对”，不是把两个位置分别计数；每对只需一次替换。
  • 操作是替换，不能套用删除字符的回文串 II 解法，也不能排序破坏位置关系。
  • 阈值是大于 2 才失败；不要求差异数恰好为 2。

复杂度

最坏时间 O(n)，只扫描半个字符串；额外空间 O(1)。第三组差异可触发早停。页面可视化存储快照是教学需要，不计入提交算法。

替代方案

使用单个下标遍历前半段，并直接访问 n − 1 − i，复杂度相同。也可以反转字符串再计算差异，但会产生 O(n) 的额外空间，而且全串的差异位置数是镜像差异对数的两倍。枚举一或两次替换再检查回文需要约 O(26²n³) 时间，不适合上限。

面试追问

  • 改成至多 k 次呢？返回 d ≤ k；若 k 为 0，则只接受原本回文。
  • 需要返回修改方案呢？记录差异对，对每一对把左侧替换成右侧；d = 0 时按奇偶长度补出上述 1 次或 2 次合法操作。
  • 每个位置替换代价不同呢？若仅与位置相关，每个差异对选成本更小的一端；已相同的对不需要修复。若仍要求正次数，则需单独处理原本回文的最小代价方案。

四语言提交代码

均使用官方方法名 makePalindrome；以下代码未编译、未运行。

Java

class Solution {
    public boolean makePalindrome(String s) {
        int diff = 0;
        for (int l = 0, r = s.length() - 1; l < r; l++, r--) {
            if (s.charAt(l) != s.charAt(r)) {
                if (++diff > 2) return false;
            }
        }
        return true;
    }
}

Python

class Solution:
    def makePalindrome(self, s: str) -> bool:
        left, right = 0, len(s) - 1
        diff = 0
        while left < right:
            if s[left] != s[right]:
                diff += 1
                if diff > 2:
                    return False
            left += 1
            right -= 1
        return True

C++

#include <string>
using std::string;

class Solution {
public:
    bool makePalindrome(string s) {
        int diff = 0;
        for (int l = 0, r = static_cast<int>(s.size()) - 1;
             l < r; ++l, --r) {
            if (s[l] != s[r]) {
                if (++diff > 2) return false;
            }
        }
        return true;
    }
};
