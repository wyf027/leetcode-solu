Problem

题意

给定两个长度相同的整数数组 nums1 与 nums2，其中 nums2 是 nums1 的变位（元素及出现次数完全相同，只是顺序可能不同）。请返回索引数组 mapping，使每个位置都满足：

nums1[i] == nums2[mapping[i]]

数组可能包含重复值；若存在多种合法映射，返回任意一种即可。下面的演示会为重复值保存一组可用下标，并逐个取出，因此还能形成不重复使用下标的一一映射。

官方样例 1

完整参数索引从 0 开始
输入：nums1 = [12, 28, 46, 32, 50]
      nums2 = [50, 12, 32, 46, 28]
输出：[1, 4, 3, 2, 0]

解释：
nums1[0] = 12 = nums2[1]
nums1[1] = 28 = nums2[4]
nums1[2] = 46 = nums2[3]
nums1[3] = 32 = nums2[2]
nums1[4] = 50 = nums2[0]

官方样例 2

完整参数顺序可保持不变
输入：nums1 = [84, 46]
      nums2 = [84, 46]
输出：[0, 1]

约束

  • 1 <= nums1.length == nums2.length <= 100
  • 0 <= nums1[i], nums2[i] < 10^5
  • nums2 与 nums1 包含相同的元素及相同的出现次数。

Solution

哈希表：让值直接指向下标

核心洞察

我们真正需要的是反向索引：看到一个值，就能立刻知道它在 nums2 的位置。先把 nums2 建成“值 → 下标栈”，之后遍历 nums1，每项只做一次哈希查询和一次弹栈。

为什么保存下标栈？

同一个值可能出现多次。保存它的全部下标，并在使用时弹出一个，既保证等值匹配，也不会重复占用同一个 nums2 下标。

完整过程

  1. 创建哈希表 positions，键是数组值，值是该值在 nums2 中出现的所有下标。
  2. 遍历 nums2。遇到 nums2[j]，就把 j 压入对应下标栈。
  3. 遍历 nums1。对于每个 nums1[i]，从对应栈中弹出一个下标，写入 mapping[i]。
  4. 返回 mapping。题目保证两个数组互为变位，所以所需下标栈一定存在且不会提前耗尽。

正确性说明

不变式：哈希表中值 x 的下标栈，始终只包含尚未使用且满足 nums2[j] = x 的下标 j。

建表后不变式显然成立。处理 nums1[i] = x 时，算法从 x 的栈弹出一个 j，因此必有 nums2[j] = x = nums1[i]；弹出后该下标不再可用，不变式继续成立。由于两个数组中每个值的出现次数相同，每一次弹栈都有元素可取。最终所有 i 都满足题目条件，所以返回的映射正确。

复杂度

时间：O(n) 期望时间，建表与查询各遍历一次。

空间：O(n)，保存全部下标与答案。

边界

  • 只有一个元素时，映射必为 [0]。
  • 顺序完全相同时，可以得到单位映射。
  • 重复值由下标栈逐个消费。
  • 值可以为 0，不可用真假判断代替键存在性判断。

四种语言完整代码

JavaHashMap + ArrayDeque
import java.util.*;

class Solution {
    public int[] anagramMappings(int[] nums1, int[] nums2) {
        Map<Integer, Deque<Integer>> positions = new HashMap<>();

        for (int j = 0; j < nums2.length; j++) {
            positions
                .computeIfAbsent(nums2[j], key -> new ArrayDeque<>())
                .addLast(j);
        }

        int[] mapping = new int[nums1.length];
        for (int i = 0; i < nums1.length; i++) {
            mapping[i] = positions.get(nums1[i]).removeLast();
        }
        return mapping;
    }
}
JavaScriptMap + Array
/**
 * @param {number[]} nums1
 * @param {number[]} nums2
 * @return {number[]}
 */
var anagramMappings = function(nums1, nums2) {
    const positions = new Map();

    for (let j = 0; j < nums2.length; j++) {
        const value = nums2[j];
        if (!positions.has(value)) {
            positions.set(value, []);
        }
        positions.get(value).push(j);
    }

    const mapping = new Array(nums1.length);
    for (let i = 0; i < nums1.length; i++) {
        mapping[i] = positions.get(nums1[i]).pop();
    }
    return mapping;
};
Pythondefaultdict + list
from collections import defaultdict
from typing import List


class Solution:
    def anagramMappings(
        self, nums1: List[int], nums2: List[int]
    ) -> List[int]:
        positions = defaultdict(list)

        for j, value in enumerate(nums2):
            positions[value].append(j)

        mapping = []
        for value in nums1:
            mapping.append(positions[value].pop())

        return mapping
C++unordered_map + vector
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> anagramMappings(
        vector<int>& nums1,
        vector<int>& nums2
    ) {
        unordered_map<int, vector<int>> positions;

        for (int j = 0; j < static_cast<int>(nums2.size()); j++) {
            positions[nums2[j]].push_back(j);
        }

        vector<int> mapping;
        mapping.reserve(nums1.size());
        for (int value : nums1) {
            auto& indices = positions[value];
            mapping.push_back(indices.back());
            indices.pop_back();
        }
        return mapping;
    }
};

替代方案

逐项线性查找

对 nums1 的每个值扫描 nums2，找到尚未使用的相等位置。空间可低至 O(n) 的使用标记，但时间是 O(n²)，没有利用重复查询的结构。

值 → 单一下标

若只需满足每项等值条件，或数据保证值唯一，可以只保存一个下标，代码更短。下标栈版本对重复值的语义更完整，能保持一一对应。

面试追问

  • 如果输入不保证互为变位？查询时检查键是否存在、下标栈是否为空；失败时返回错误或空结果，取决于接口约定。
  • 如何减少额外空间？若允许修改并只关心值配对，可讨论排序；但排序会丢失原始下标，必须把值与下标一起排序，总体仍需保存索引信息。
  • 哈希表最坏时间是多少？理论上碰撞可能使操作退化；通常按期望 O(1) 分析，总时间期望 O(n)。
  • 如何稳定选择重复值的映射？使用队列从头取会得到按 nums2 下标递增的确定性结果；栈则从后向前取。

常见错误

  • 误把答案当作重排后的值数组；题目要返回的是 nums2 的下标。
  • 写反键和值，把“下标 → 数值”存进哈希表，查询仍然需要扫描。
  • 遇到重复值却只消费一个固定下标，导致想构造一一映射时重复使用位置。
  • 用排序后的下标回答，却没有保留它们对应到原始 nums2 的位置。
  • JavaScript 中用 if (map.get(value)) 判断存在性；当下标为 0 时会误判，应使用 map.has(value)。
