01 / 比赛规则

输入两张表 NewYork 和 California，分别记录纽约大学与加州大学参赛学生的成绩。两校参赛人数相同，成绩达到 90 分（含） 的学生为优秀学生。优秀学生更多的学校获胜；人数相同则为平局。

返回只有一行、一列 winner 的结果表。纽约大学获胜时填写 New York University，加州大学获胜时填写 California University，平局填写 No Winner。

  • 每张表的 student_id 唯一；两表之间可重复。
  • 两校参加比赛的学生人数相同。
  • 优秀门槛是 score ≥ 90，不是严格大于。
  • 所获题面资料未提供行数、ID 或分数的数值上下界，也未明确 NULL、空表保证；不补造数值约束。

05 / 独立题解

先尝试写出自己的查询，再展开推导与完整代码。

核心洞察：先各自聚合，再比较两个数

学生 ID 只区分本校记录，不用于跨校配对。比赛关心的是达到门槛的人数，与总分、最高分和平均分无关。分别筛出 score >= 90 的记录并 COUNT(*)，每张表压缩成一个数；最后用 CASE 输出学校名称。

完整过程

  1. 在 NewYork 中筛选优秀学生，聚合为单行 ny.total。
  2. 在 California 中做同样操作，得到单行 ca.total。
  3. 对两个单行结果做 CROSS JOIN，仅得到一行；这里并不是对原始学生表做笛卡尔积。
  4. 纽约人数更多就返回纽约；加州人数更多就返回加州；否则返回 No Winner，并将列别名设为 winner。

MySQL · 官方可提交 SQL

SELECT CASE
         WHEN ny.total > ca.total THEN 'New York University'
         WHEN ny.total < ca.total THEN 'California University'
         ELSE 'No Winner'
       END AS winner
FROM (SELECT COUNT(*) AS total
      FROM NewYork WHERE score >= 90) AS ny
CROSS JOIN (SELECT COUNT(*) AS total
            FROM California WHERE score >= 90) AS ca;

正确性

对任一学校，WHERE 恰好保留所有且仅有优秀学生记录。每位学生在本表中只有一行，因此 COUNT(*) 恰等于该校优秀人数。两个无 GROUP BY 的聚合各返回一行，故连接也恰好产生一行。对任意两个人数，只有大于、小于、等于三种互斥且完备的关系；CASE 的三个结果分别与题目的胜负规则一致，所以返回的 winner 正确。

边界与常见错误

  • 90 分必须计入；写成 > 90 会漏计。
  • 没有优秀学生时，COUNT(*) 返回 0；两校都为 0 时平局。空表是扩展语义，查询同样返回一个数。
  • 若扩展输入含 NULL，WHERE 不保留该行。题面未明确允许 NULL，交互及四语言示例仅接收整数。
  • 不能按 student_id JOIN 原表：两校 ID 无配对含义，匹配或重复扩张都会改坏计数。
  • COUNT(score >= 90) 会把非 NULL 的真假值都计入，不能代替 WHERE。
  • 直接 SUM 布尔表达式在空输入时可能为 NULL；使用时需要 COALESCE。
  • 输出名称、空格和列别名必须准确；不要输出学校表名或人数。

复杂度与替代方案

设两校分别有 n、m 行，无索引全表扫描的时间为 O(n + m)，计数器额外空间为 O(1)；这是逻辑计算成本，数据库的缓存与执行计划另计。score 索引可能支持范围扫描，是否更快取决于优秀记录比例与优化器。替代写法可用两个标量子查询或 CTE 保存计数，也可 UNION ALL 带学校标签后条件聚合；本题只有两张表，独立聚合更直接。

面试追问

  • 学校数量扩展到多所？统一为带 school 字段的学生表，分组计数，再处理最高人数及并列规则。
  • 比较优秀率而非人数？同时统计总人数，明确零人数处理；本题人数相同，所以无需除法。
  • 一名学生多次考试？先明确最佳、最近或平均成绩规则，再按学生归约，不能直接数考试记录。

函数接收两张表的行数组，每行为 [student_id, score]，返回 winner 字符串；数据库结果相当于将该字符串放入单行 winner 列。输入遵守表结构和唯一性约束，不含 NULL。这些代码未执行。

Java

public class Solution {
    public static String findWinner(int[][] newYork, int[][] california) {
        long ny = 0, ca = 0;
        for (int[] row : newYork) {
            if (row[1] >= 90) ny++;
        }
        for (int[] row : california) {
            if (row[1] >= 90) ca++;
        }
        if (ny > ca) return "New York University";
        if (ny < ca) return "California University";
        return "No Winner";
    }
}

def find_winner(new_york: list[list[int]],
                california: list[list[int]]) -> str:
    ny = sum(score >= 90 for _, score in new_york)
    ca = sum(score >= 90 for _, score in california)
    if ny > ca:
        return "New York University"
    if ny < ca:
        return "California University"
    return "No Winner"
