左链栈不变量、next 均摊分析、右子树补栈、预先中序数组方案、追问、错误清单与四语言代码都在下方。

核心洞察：栈顶始终是尚未访问的最小节点

构造时把根节点到最左节点的整条左链压栈。next() 弹出栈顶，它就是当前最小值；若该节点有右子树，再把右子树根节点及其全部左链压栈。这样栈顶重新变为剩余节点中的最小值。hasNext() 只需判断栈是否为空。

next()

弹出一个节点，再补入其右子树左链。

hasNext()

栈非空即说明还有下一个中序节点。

完整过程

  1. 1

    压入初始左链

    从根开始持续向左，沿途节点全部入栈。

  2. 2

    弹出当前最小值

    next 弹出栈顶并准备返回其值。

  3. 3

    补入右子树左链

    从弹出节点的右孩子开始重复向左压栈。

  4. 4

    栈空即结束

    hasNext 返回栈是否非空，不移动迭代器。

边界与不变量

单节点：构造后栈中只有根；一次 next 后栈空。
左斜树：构造一次压入 h 个节点，之后连续弹出。
右斜树：每次 next 只补入一个右孩子。
不变量：栈从底到顶保存待访问节点路径，栈顶最小。
右子树：不能只压右孩子，必须继续压入其完整左链。

替代方案：预先中序数组

构造时完整中序遍历并保存所有值，之后 next 与 hasNext 都是 O(1)。实现更直观，但初始化为 O(n)，额外空间固定为 O(n)，没有利用迭代器按需消费的优势，也不满足进阶要求的 O(h) 内存目标。

面试追问

为什么 next 只是均摊 O(1)？

单次可能压入一条高度为 h 的左链，但 n 次迭代中每个节点只入栈一次，总工作为 O(n)。

hasNext 会改变状态吗？

不会。它只检查栈是否为空，重复调用必须得到相同结果。

若树在迭代期间被修改怎么办？

本题假设树不变。支持修改需要定义迭代一致性，并可能引入版本控制或重新定位。

常见错误

只压根节点

首次 next 会错误返回根，而不是全树最小值。

右子树只压一层

会跳过右子树内部更小的左后代。

hasNext 弹栈

查询方法不应移动迭代器状态。

误称最坏 O(1)

单次 next 可能压入 O(h) 个节点，只能说均摊 O(1)。

import java.util.ArrayDeque;
import java.util.Deque;

class BSTIterator {
    private final Deque<TreeNode> stack = new ArrayDeque<>();

    public BSTIterator(TreeNode root) {
        pushLeft(root);
    }

    public int next() {
        TreeNode node = stack.pop();
        pushLeft(node.right);
        return node.val;
    }

    public boolean hasNext() {
        return !stack.isEmpty();
    }

    private void pushLeft(TreeNode node) {
        while (node != null) {
            stack.push(node);
            node = node.left;
        }
    }
}
var BSTIterator = function (root) {
  this.stack = [];
  this.pushLeft(root);
};

BSTIterator.prototype.pushLeft = function (node) {
  while (node !== null) {
    this.stack.push(node);
    node = node.left;
  }
};

BSTIterator.prototype.next = function () {
  const node = this.stack.pop();
  this.pushLeft(node.right);

BSTIterator.prototype.hasNext = function () {

class BSTIterator:
    def __init__(self, root):
        self.stack = []
        self._push_left(root)

    def _push_left(self, node):
        while node is not None:
            self.stack.append(node)
            node = node.left

    def next(self) -> int:
        node = self.stack.pop()
        self._push_left(node.right)
        return node.val

    def hasNext(self) -> bool:
        return bool(self.stack)

using namespace std;

class BSTIterator {
private:
    stack<TreeNode*> nodes;

    void pushLeft(TreeNode* node) {
        while (node != nullptr) {
            nodes.push(node);
            node = node->left;
        }
    }

public:
    BSTIterator(TreeNode* root) {
        pushLeft(root);
    }

    int next() {
        TreeNode* node = nodes.top();
        nodes.pop();
        pushLeft(node->right);
        return node->val;
    }

    bool hasNext() {
        return !nodes.empty();
    }
};
