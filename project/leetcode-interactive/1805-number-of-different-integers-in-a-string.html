1805 · 字符串中不同整数的数目

Number of Different Integers in a String

数字可以重复，写法也可以变化。你能数清字符串中有多少种整数吗？

题目

给定字符串 word，它只包含数字和小写英文字母。将所有字母替换为空格后，每一段连续数字表示一个整数。返回这些整数中不同数值的数量。

比较整数时忽略前导零：例如 1、01 和 001 表示相同整数。字母之间没有数字时，不会产生整数。

参数：word: string　返回：integer

约束

  • 1 ≤ word.length ≤ 1000
  • word 仅由 0–9 和 a–z 组成。

输入：word = "a123bc34d8ef34"

核心洞察：用规范字符串代表数值

提取每个最大连续数字段，去除前导零，但全零段保留一个“0”。把规范字符串放入集合即可去重，无需转换为机器整数。

完整过程

  1. 从左向右扫描，跳过所有字母。
  2. 遇到数字后，找到当前连续数字段的右边界 j。
  3. 从左侧跳过零，但至少保留一位。
  4. 把规范子串加入哈希集合，指针移动到 j。
  5. 处理完所有数字段后，返回集合大小。

例如 a1b01c001 的三个数字段依次变为 1、1、1，集合始终只有一个元素。可视化按字符展示缓冲区，代码则直接寻找段边界；两者在每个完整数字段结束时执行相同的归一化与入集合操作。

正确性

完整性：每次扫描得到一个最大连续数字段，字母分隔不同段，指针只向右移动，因此所有数字段恰好处理一次。

唯一性：非零数值去掉前导零后有唯一十进制表示，全零段统一表示为 0。所以数字段数值相同，当且仅当规范字符串相同。

不变式：处理任意数量的完整数字段后，集合恰好包含它们的所有不同规范表示。插入下一段只增加新的数值；扫描完成时，集合大小就是所有不同整数的数量。

边界与常见错误

  • 全字母没有整数，返回 0；不能插入空字符串。
  • 0、00、000 都要规范为 0，而不是丢弃。
  • 数字出现在末尾也必须收录，不能只在读到字母时提交。
  • 直接把 01 和 1 放入集合会重复计数。
  • 删除字母会合并相邻数字段；例如 a12b34 不能变成 1234。
  • 数字段最长可达 1000 位。Java int/long、C++ stoi、JavaScript Number 都不能可靠保存所有输入，使用字符串避免溢出和精度损失。

复杂度

令 n 为 word 长度。扫描、去零、子串构建和哈希的总字符工作量为 O(n)。采用哈希集合时，期望时间 O(n)，额外空间 O(n)。极端哈希碰撞可能使时间退化，这不是最坏情况线性保证。

替代方案

可用正则 [0-9]+ 提取数字段，再规范化并去重，写法更短，但匹配结果可能额外占用内存。也可把规范字符串排序后统计相邻不同项，代价是排序和字符串比较。任意精度整数可以避免溢出，但此题不需要数值运算。

面试追问

  • 流式输入？保留当前段，在分隔符或流结束时规范化并提交。
  • 允许负数？先定义负号语法，再统一 -0 与 0。
  • 数据太多无法放入集合？可采用外部排序去重；只存摘要有哈希碰撞风险。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int numDifferentIntegers(String word) {
        Set<String> seen = new HashSet<>();
        int i = 0, n = word.length();
        while (i < n) {
            if (word.charAt(i) < '0' || word.charAt(i) > '9') {
                i++;
                continue;
            }
            int j = i;
            while (j < n && word.charAt(j) >= '0'
                    && word.charAt(j) <= '9') j++;
            while (i < j - 1 && word.charAt(i) == '0') i++;
            seen.add(word.substring(i, j));
            i = j;
        }
        return seen.size();
    }
}

/**

var numDifferentIntegers = function(word) {
    const seen = new Set();
    let i = 0;
    while (i < word.length) {
        if (word[i] < '0' || word[i] > '9') {
            i++;
            continue;
        }
        let j = i;
        while (j < word.length && word[j] >= '0'
               && word[j] <= '9') j++;
        while (i < j - 1 && word[i] === '0') i++;
        seen.add(word.slice(i, j));
        i = j;
    }
    return seen.size;
};

Python 3

class Solution:
    def numDifferentIntegers(self, word: str) -> int:
        seen = set()
        i, n = 0, len(word)
        while i < n:
            if not ('0' <= word[i] <= '9'):
                i += 1
                continue
            j = i
            while j < n and '0' <= word[j] <= '9':
                j += 1
            while i < j - 1 and word[i] == '0':
                i += 1
            seen.add(word[i:j])
            i = j
        return len(seen)

C++

#include <string>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int numDifferentIntegers(string word) {
        unordered_set<string> seen;
        int i = 0, n = static_cast<int>(word.size());
        while (i < n) {
            if (word[i] < '0' || word[i] > '9') {
                ++i;
                continue;
            }
            int j = i;
            while (j < n && word[j] >= '0'
                   && word[j] <= '9') ++j;
            while (i < j - 1 && word[i] == '0') ++i;
            seen.insert(word.substr(i, j - i));
            i = j;
        }
        return static_cast<int>(seen.size());
    }
};
