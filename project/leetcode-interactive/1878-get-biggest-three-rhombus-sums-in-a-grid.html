Get Biggest Three Rhombus Sums in a Grid

01 / Problem

题目与规则

给定整数矩阵 grid，形状为 m × n。选取一个由正方形旋转 45° 得到的菱形，四个顶点都落在矩阵的格子中心，且整个菱形位于矩阵内。把它的边界格子相加，内部格子不计入。

单个格子也算面积为 0 的菱形。返回所有合法菱形和中最大的三个不同数值，按降序排列；不足三个不同值时返回全部。

只算边界

内部格子不参与；每个边界格子只加一次。

允许一个点

零面积菱形的和就是该格子的值。

按和去重

位置和大小可以不同，但相同的和只能返回一次。

参数与约束

  • getBiggestThree(grid: integer[][]) → integer[]
  • m == grid.length，n == grid[i].length。
  • 官方英文元数据：1 ≤ m, n ≤ 50。
  • 1 ≤ grid[i][j] ≤ 100000。

所给官方元数据的中文题面写作 1 ≤ m, n ≤ 100，与英文的 50 不一致。这里保留差异；下方算法也适用于 100 × 100 的范围，尚未执行验证。

02 / Examples

官方示例

示例 1 · 三个不同的边界和

输入：grid = [[3,4,5,1,3],[3,3,4,2,3],[20,30,200,40,10],[1,5,5,4,1],[4,3,2,2,5]]
输出：[228,216,211]

对应边界分别为 20 + 3 + 200 + 5 = 228、200 + 2 + 10 + 4 = 216、5 + 200 + 4 + 2 = 211。

示例 2 · 单点也参与比较

输入：grid = [[1,2,3],[4,5,6],[7,8,9]]
输出：[20,9,8]

20 来自 2 + 6 + 8 + 4；9 和 8 分别来自两个单点。

示例 3 · 不足三个不同值

输入：grid = [[7,7,7]]
输出：[7]

只能选取单点，三个单点的和都为 7，去重后只剩一个值。

04 / Solution studio

想好你的思路了吗？

展开后可逐格走过菱形边界，查看推导与四种语言实现。

枚举中心与半径，沿边走一圈

一个合法菱形由整数中心 (r,c) 和半径 k 唯一确定。四个顶点为上 (r-k,c)、右 (r,c+k)、下 (r+k,c)、左 (r,c-k)。最大半径是到矩阵四条边的最小距离。

边界巡游台

坐标从 0 开始。每条边包含起点、不包含终点，所以四个角不会被重复累加。选择一个菱形，再逐步观察当前和；完成后才加入前三大候选。

绿边＝边界未访问 · 深绿＝已累计 · 金色＝当前格 · 斜纹＝内部不计

当前边界和
0

尚未累加

已完成候选的前三大不同值

包括当前选项之前的所有菱形；跳选时会按枚举顺序重新累计历史。

核心洞察

无需把菱形内部求和。对于 k > 0，四条边各取 k 个格子，一共恰好 4k 个。每次得到一个完整的和，只保留最大的三个不同数值。

完整过程

  1. 遍历所有中心 (r,c)，先将 grid[r][c] 作为半径 0 的候选。
  2. 设 limit = min(r,m-1-r,c,n-1-c)，枚举 k = 1…limit。
  3. 让 i = 0…k-1，累加下面四组坐标，分别对应上→右、右→下、下→左、左→上四条半开边。
  4. 把和加入至多三个数的集合；去重后如有四个值，删除最小值。最终降序返回。
(r-k+i, c+i)       // 上 → 右，不含右顶点
(r+i,   c+k-i)     // 右 → 下，不含下顶点
(r+k-i, c-i)       // 下 → 左，不含左顶点
(r-i,   c-k+i)     // 左 → 上，不含上顶点

正确性说明

  1. 枚举完整且合法：每个符合定义的菱形都有整数中心与非负整数半径。距离边界的最小值恰是半径上限，因此所有合法菱形都被枚举，且不会越界。
  2. 求和准确：半径 0 单独处理。正半径时四条半开边互不重叠，连接后覆盖全部边界，每个角作为一条边的起点恰出现一次，内部坐标从未加入。
  3. 前三大不变式：处理任意数量的候选后，集合保留其中最多三个最大不同值。新值加入并删除最小值维持此性质；曾被删除的值已有三个更大的不同值，不可能重新进入最终答案。
  4. 所有候选处理结束后，不变式直接给出题目要求的降序结果。

边界与数值范围

单行、单列或仅有两行/两列时，只存在半径 0 的菱形。所有和相同只返回一个值。半径最大的菱形允许顶点贴边。即使采用中文元数据的 100 上限，半径至多 49，边界和至多 4 × 49 × 100000 = 19600000，32 位有符号整数足够。

复杂度

令 K = floor((min(m,n)-1)/2)。每个中心的边界访问量上界为 4(1+2+…+K)，总时间 O(mn(K+1)²)，通常写作 O(mn·min(m,n)²)。只维护至多四个临时候选值，辅助空间 O(1)；不包含输入与返回结果。交互演示为便于回放缓存了坐标，空间与下面提交代码不同。

替代方案

数据更大时，可构建两种对角线前缀和，用四次区间查询获得四条边。若每条边含两个端点，要减去四个重复顶点；半径 0 仍单独处理。这样时间降为 O(mn·min(m,n))，辅助空间为 O(mn)。直接枚举边界的实现更短，适合本题的小矩阵。

常见错误

  • 把内部格子也加入，得到的是区域和而非边界和。
  • 循环写成 i ≤ k，四个角被算两次。
  • 忘记半径 0，遗漏可能进入前三名的大单点。
  • 求三个最大菱形却没有按和去重，或最终结果不是降序。
  • 只用上下距离限制半径，忽略左右边界。

面试追问

  • 若要求最大的不同 K 个和？使用大小不超过 K 的有序集合，或最小堆配合去重集合。
  • 允许负数后是否仍正确？枚举和去重逻辑不变，但不能用 0 初始化固定大小的答案数组。
  • 怎样优化重复访问的对角线？写出两种方向的前缀和，并明确每次区间查询的端点是否包含。

Java

import java.util.TreeSet;

class Solution {
    private void keep(TreeSet<Integer> best, int sum) {
        best.add(sum);
        if (best.size() > 3) best.pollFirst();
    }

    public int[] getBiggestThree(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        TreeSet<Integer> best = new TreeSet<>();
        // ponytail: small-grid border enumeration; use diagonal prefixes for larger grids.
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                keep(best, grid[r][c]);
                int limit = Math.min(Math.min(r, m - 1 - r),
                                     Math.min(c, n - 1 - c));
                for (int k = 1; k <= limit; k++) {
                    int sum = 0;
                    for (int i = 0; i < k; i++) {
                        sum += grid[r-k+i][c+i];
                        sum += grid[r+i][c+k-i];
                        sum += grid[r+k-i][c-i];
                        sum += grid[r-i][c-k+i];
                    }
                    keep(best, sum);
                }
            }
        }
        int[] answer = new int[best.size()];
        int pos = 0;
        for (int value : best.descendingSet()) answer[pos++] = value;
        return answer;
    }
}

/**
 * @param {number[][]} grid
 * @return {number[]}

var getBiggestThree = function(grid) {
    const m = grid.length, n = grid[0].length;
    const best = [];
    function keep(sum) {
        if (best.includes(sum)) return;
        best.push(sum);
        best.sort((a, b) => b - a);
        if (best.length > 3) best.pop();
    }
    // ponytail: small-grid border enumeration; use diagonal prefixes for larger grids.
    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            keep(grid[r][c]);
            const limit = Math.min(r, m-1-r, c, n-1-c);
            for (let k = 1; k <= limit; k++) {
                let sum = 0;
                for (let i = 0; i < k; i++) {
                    sum += grid[r-k+i][c+i];
                    sum += grid[r+i][c+k-i];
                    sum += grid[r+k-i][c-i];
                    sum += grid[r-i][c-k+i];
                }
                keep(sum);
            }
        }
    }
    return best;
};

from typing import List

class Solution:
    def getBiggestThree(self, grid: List[List[int]]) -> List[int]:
        m, n = len(grid), len(grid[0])
        best = set()

        def keep(total):
            best.add(total)
            if len(best) > 3:
                best.remove(min(best))

        # ponytail: small-grid border enumeration; use diagonal prefixes for larger grids.
        for r in range(m):
            for c in range(n):
                keep(grid[r][c])
                limit = min(r, m - 1 - r, c, n - 1 - c)
                for k in range(1, limit + 1):
                    total = 0
                    for i in range(k):
                        total += grid[r-k+i][c+i]
                        total += grid[r+i][c+k-i]
                        total += grid[r+k-i][c-i]
                        total += grid[r-i][c-k+i]
                    keep(total)
        return sorted(best, reverse=True)

C++

#include <vector>
#include <set>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> getBiggestThree(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        set<int> best;
        auto keep = [&](int sum) {
            best.insert(sum);
            if (best.size() > 3) best.erase(best.begin());
        };
        // ponytail: small-grid border enumeration; use diagonal prefixes for larger grids.
        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                keep(grid[r][c]);
                int limit = min({r, m - 1 - r, c, n - 1 - c});
                for (int k = 1; k <= limit; ++k) {
                    int sum = 0;
                    for (int i = 0; i < k; ++i) {
                        sum += grid[r-k+i][c+i];
                        sum += grid[r+i][c+k-i];
                        sum += grid[r+k-i][c-i];
                        sum += grid[r-i][c-k+i];
                    }
                    keep(sum);
                }
            }
        }
        return vector<int>(best.rbegin(), best.rend());
    }
};
