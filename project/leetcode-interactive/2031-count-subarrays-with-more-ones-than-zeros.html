在一段连续区间里，1 能否占据严格多数？

01 / 题目

给定仅含 0 和 1 的数组 nums，统计其中 1 的数量严格大于 0 的数量的非空连续子数组。返回计数对 1,000,000,007 取模后的结果。不同起止下标代表不同子数组，即使内容相同也分别计数。

约束：1 ≤ nums.length ≤ 10⁵；每个 nums[i] 为 0 或 1。

参数：整数数组 nums；返回：整数。官方方法名：subarraysWithMoreOnesThanZeroes。

示例 1

nums = [0,1,1,0,1]
输出：9

按长度 1 至 5 分类，分别有 3、1、3、1、1 个合格区间，总计 9。

示例 2

nums = [0]
输出：0

唯一的非空区间没有 1。

示例 3

nums = [1]
输出：1

单独的 1 即为合格区间。

03 / 题解 · 把区间变成高度差

核心洞察

把 1 看成 +1，0 看成 −1。令 P[0] = 0，P[j] 为前 j 个数的转换后总和。区间 [i,j) 合格等价于 P[j] − P[i] > 0，也就是 P[i] < P[j]。从左到右扫描每个右端点，只需知道历史前缀中有多少个严格更低的高度。

前缀高度实验室

每一步处理一个右端点。绿色标出可配对的历史前缀；蓝色为当前前缀。树状数组查询路径显示哪些频次块被相加。

历史前缀 → 当前前缀



完整过程
  1. 所有前缀落在 [−n,n]。统一映射为下标 k = P + n + 1，避免树状数组下标 0。
  2. 先插入 P[0] = 0 的一次出现，覆盖从数组开头出发的区间。
  3. 读取 nums[j−1] 更新 P[j]；查询树状数组 query(k−1)，得到历史中严格小于当前前缀的数量。
  4. 把查询结果加到答案并取模；再执行 add(k,1)，保存当前前缀。重复到数组末尾。
树状数组中每个节点保存一个频次区间。查询时反复减去 lowbit 汇总不相交区间；更新时反复加上 lowbit 更新包含该位置的节点。相同高度必须保留出现次数，而不是只保存一个集合元素。


正确性
循环开始时，树状数组恰好存有当前右端点之前所有前缀的频次。初始化插入空前缀使性质成立。查询 k−1 精确统计 P[i] < P[j] 的历史下标 i，而每个这样的 i 与一个合格的非空区间 [i,j) 一一对应；相等或更高的前缀不会计入。查询后插入 P[j]，性质保持。所有非空子数组有唯一右端点，因此累加既不重复也不遗漏。取模只改变答案的表示，不影响比较与计数逻辑。


边界与常见错误
  • 全 0 返回 0；全 1 为 n(n+1)/2 再取模。
  • 相同前缀对应 0 与 1 一样多，必须排除：查询 k−1 而非 k。
  • 漏掉空前缀会漏算从下标 0 开始的区间。
  • 负前缀需要偏移，树状数组不能从 0 更新。
  • 通用滑动窗口不成立：添加一个 0 会降低区间和，合法性不单调。
  • 答案可能超过 32 位；Java/C++ 用 long/long long 累加。
复杂度与替代方案
时间 O(n log n)，空间 O(n)，无需排序或坐标压缩。
暴力枚举区间为 O(n²)，仅适合小规模理解。归并排序统计有序前缀对同为 O(n log n)，但实现更长。一般权值可用离散化加树状数组。
本题还可利用前缀每次仅变化 ±1，用频次数组维护“比当前高度低”的数量，做到 O(n)。它依赖二进制转换的特殊性质。


面试追问
怎样推导 O(n)？设旧高度为 s，less 为历史中小于 s 的数量。走到 s+1 时，less 增加 freq[s]；走到 s−1 时，less 减去 freq[s−1]。将 less 加入答案，再插入新高度。插入相等高度不改变 less。初始化 freq[0]=1、less=0。
若要求 1 至少比 0 多 K 个？查询历史前缀 P[i] ≤ P[j]−K 的频次。若数字是任意权值，保留前缀比较框架并离散化；±1 的线性递推不再直接适用。

Java
class Solution {
    public int subarraysWithMoreOnesThanZeroes(int[] nums) {
        int n = nums.length, size = 2 * n + 2;
        int[] bit = new int[size + 1];
        for (int k = n + 1; k <= size; k += k & -k) bit[k]++;
        int prefix = 0;
        long ans = 0;
        for (int x : nums) {
            prefix += x == 1 ? 1 : -1;
            int index = prefix + n + 1;
            int count = 0;
            for (int k = index - 1; k > 0; k -= k & -k) count += bit[k];
            ans = (ans + count) % 1_000_000_007;
            for (int k = index; k <= size; k += k & -k) bit[k]++;
        }
        return (int) ans;
    }
}

Python
from typing import List

class Solution:
    def subarraysWithMoreOnesThanZeroes(self, nums: List[int]) -> int:
        n = len(nums)
        size = 2 * n + 2
        bit = [0] * (size + 1)

        def add(index):
            while index <= size:
                bit[index] += 1
                index += index & -index

        add(n + 1)
        prefix = ans = 0
        for x in nums:
            prefix += 1 if x == 1 else -1
            index = prefix + n + 1
            k, count = index - 1, 0
            while k > 0:
                count += bit[k]
                k -= k & -k
            ans = (ans + count) % 1_000_000_007
            add(index)
        return ans


C++
#include <vector>
using namespace std;

class Solution {
public:
    int subarraysWithMoreOnesThanZeroes(vector<int>& nums) {
        int n = nums.size(), size = 2 * n + 2;
        vector<int> bit(size + 1);
        auto add = [&](int k) {
            for (; k <= size; k += k & -k) ++bit[k];
        };
        add(n + 1);
        int prefix = 0;
        long long ans = 0;
        for (int x : nums) {
            prefix += x == 1 ? 1 : -1;
            int index = prefix + n + 1, count = 0;
            for (int k = index - 1; k > 0; k -= k & -k) count += bit[k];
            ans = (ans + count) % 1000000007;
            add(index);
        }
        return static_cast<int>(ans);
    }
};
