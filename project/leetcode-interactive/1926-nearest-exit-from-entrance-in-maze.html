迷宫中离入口最近的出口

Nearest Exit from Entrance in Maze

MEDIUM

从入口出发，走到哪个出口需要的步数最少？

题意

给定下标从 0 开始的 m × n 字符矩阵 maze，'.' 表示空格，'+' 表示墙。入口 entrance = [entrance_row, entrance_col]。每次只能上下左右移动一个格子，不能穿墙或越出矩阵。

出口是位于矩阵边界的空格，但入口本身不算出口。返回到达最近出口的最少步数；没有可达出口则返回 -1。到达边界格即可，不需要再走出矩阵。

约束

  • maze.length == m，maze[i].length == n。
  • 1 ≤ m, n ≤ 100。
  • maze[i][j] 只能为 '.' 或 '+'。
  • entrance.length == 2。
  • 0 ≤ entrance_row < m，0 ≤ entrance_col < n。
  • 入口保证是空格。
官方题目

官方示例

示例 1

maze = [["+","+",".","+"],[".",".",".","+"],["+","+","+","."]]
entrance = [1,2]
输出：1

上移一步到达 (0,2)；到 (1,0) 需要两步；(2,3) 虽是出口但不可达。

示例 2

maze = [["+","+","+"],[".",".","."],["+","+","+"]]
entrance = [1,0]
输出：2

入口 (1,0) 不算出口。右移两步，到达 (1,2)。

示例 3

maze = [[".","+"]]
entrance = [0,0]
输出：-1

除入口外没有出口。

思考区

入口在边界时，答案能是 0 吗？最先沿一条路找到的出口，必然最近吗？题解与演示位于底部，默认收起。

测试与验证

快速生成模式：待补验证

题解：按距离向外扩散

核心洞察

每一步代价相同，把空格看作图的顶点，使用广度优先搜索 BFS。先进先出队列按距离非递减处理格子，第一个出队的非入口边界格就是最近出口。

距离波纹实验室

入 = 入口；+ = 墙；数字 = 距离；浅绿 = 已发现；黄色 = 当前处理；绿框 = 出口。一步处理一个队首格。



完整过程
  1. 入口携带距离 0 入队，立即标记访问。
  2. 出队 (r,c,d)，若 d > 0 且位于边界，返回 d。
  3. 检查上下左右，跳过越界、墙、已访问格。其余格标记后以 d+1 入队。
  4. 队列耗尽仍未找到出口，返回 -1。
示例 2 依次处理 (1,0,0)、(1,1,1)、(1,2,2)。入口距离 0 被排除，最后返回 2。


正确性
不变式：队列中的距离非递减，每个已发现格的距离均为最短距离。入口距离 0 正确；处理距离 d 的顶点时，新邻居获得 d+1。若它有更短路径，那么更早出队的前驱应已经发现它，矛盾。入队时标记保证每格只入队一次。因此第一个有效出口出队时，所有可能更近的格子已处理，返回值最小。队列耗尽意味着入口可达的所有空格均已处理，若无出口则返回 -1 正确。


边界与常见错误
  • 单格迷宫只有入口，返回 -1。单行、单列中的其他空格都是边界格。
  • 入口即使在边界也不能返回 0；到边界无需额外加一步。
  • 不能仅用曼哈顿距离，墙可能挡路。
  • 必须在入队时标记，以免环路导致重复入队。
  • 以下代码将访问格改为 '+'，会修改输入；要保留原矩阵可复制或另建 visited。
  • JavaScript 使用 head 游标，避免反复 shift 搬移数组。


复杂度
时间 O(mn)，每格至多处理一次，每次检查四个方向。额外空间 O(mn)，用于队列；原地标记不会让队列空间消失。
替代方案
DFS 找到的第一个出口未必最近；枚举简单路径可能指数增长。Dijkstra 支持不同移动代价，但本题等权，BFS 更简单。重复查询可考虑多源 BFS，但必须特别处理入口自身是边界出口的排除条件。
面试追问
如何输出路径？首次发现时记录前驱，从出口回溯再反转。如何处理 0/1 边权？使用双端队列做 0-1 BFS。能在入队时返回吗？可以，在首次发现邻居时判断边界，返回 d+1；入口必须事先标记。


JavaScript
/** @param {character[][]} maze @param {number[]} entrance @return {number} */
var nearestExit = function(maze, entrance) {
    const m = maze.length, n = maze[0].length;
    const q = [[entrance[0], entrance[1], 0]];
    maze[entrance[0]][entrance[1]] = '+';
    for (let head = 0; head < q.length; head++) {
        const [r,c,d] = q[head];
        if (d > 0 && (r === 0 || r === m-1 || c === 0 || c === n-1)) return d;
        for (const [dr,dc] of [[-1,0],[1,0],[0,-1],[0,1]]) {
            const nr = r+dr, nc = c+dc;
            if (nr < 0 || nr >= m || nc < 0 || nc >= n || maze[nr][nc] !== '.') continue;
            maze[nr][nc] = '+';
            q.push([nr,nc,d+1]);
        }
    }
    return -1;
};


Python
from typing import List
from collections import deque

class Solution:
    def nearestExit(self, maze: List[List[str]], entrance: List[int]) -> int:
        m, n = len(maze), len(maze[0])
        q = deque([(entrance[0], entrance[1], 0)])
        maze[entrance[0]][entrance[1]] = '+'
        while q:
            r, c, d = q.popleft()
            if d > 0 and (r == 0 or r == m-1 or c == 0 or c == n-1):
                return d
            for dr, dc in ((-1,0),(1,0),(0,-1),(0,1)):
                nr, nc = r+dr, c+dc
                if 0 <= nr < m and 0 <= nc < n and maze[nr][nc] == '.':
                    maze[nr][nc] = '+'
                    q.append((nr,nc,d+1))
        return -1


Java
import java.util.ArrayDeque;
class Solution {
    public int nearestExit(char[][] maze, int[] entrance) {
        int m = maze.length, n = maze[0].length;
        ArrayDeque<int[]> q = new ArrayDeque<>();
        q.offer(new int[]{entrance[0], entrance[1], 0});
        maze[entrance[0]][entrance[1]] = '+';
        int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            int r = cur[0], c = cur[1], d = cur[2];
            if (d > 0 && (r == 0 || r == m-1 || c == 0 || c == n-1)) return d;
            for (int[] dir : dirs) {
                int nr = r+dir[0], nc = c+dir[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n || maze[nr][nc] != '.') continue;
                maze[nr][nc] = '+';
                q.offer(new int[]{nr,nc,d+1});
            }
        }
        return -1;
    }
}
