1022. 从根到叶的二进制数之和

Sum of Root To Leaf Binary Numbers

EASY

题目

给定一棵二叉树，节点值只能是 0 或 1。每条从根到叶子的路径按“最高位到最低位”的顺序组成一个二进制数，请返回所有这类数字的十进制之和。答案保证可由 32 位整数表示。

例如路径 0 → 1 → 1 → 0 → 1 表示二进制 01101，即十进制 13。

函数形式

sumRootToLeaf(root: TreeNode) -> integer

约束

  • 树中节点数为 [1, 1000]
  • Node.val 仅为 0 或 1

官方示例

示例 1

输入：root = [1,0,1,0,1,0,1] 输出：22 解释：(100)₂ + (101)₂ + (110)₂ + (111)₂ = 4 + 5 + 6 + 7 = 22

示例 2

输入：root = [0] 输出：0

路径位移实验室

沿深度优先搜索的事件逐步观察：进入节点时，已有二进制值左移一位，再加当前位；只有抵达叶子时才计入总和。

题解：把路径当作滚动的二进制数

核心洞察

从父节点的值 x 走到值为 b 的子节点，相当于在二进制末尾追加一位：next = (x << 1) | b，也就是 2x + b。因此无需保存路径字符串。

完整过程

  1. 从根开始 DFS，并携带当前路径值。
  2. 进入节点后执行左移与追加。
  3. 若是叶子，返回当前值；否则递归计算左右子树并相加。

正确性

路径值不变式：每次进入节点后，携带值恰好等于从根到该节点的位序列所表示的二进制数。根节点时显然成立；若父路径值为 x，追加当前位 b 后正是 2x+b，故不变式保持。每片叶子返回且仅返回其完整路径值，左右子树之和覆盖所有叶子且不重不漏，因此最终答案正确。

边界与复杂度

  • 单节点树：根同时是叶，直接贡献 0 或 1。
  • 前导零不影响数值，滚动计算天然处理。
  • 时间复杂度 O(n)；递归栈空间 O(h)，其中 h 是树高。

四种语言实现

Java

class Solution {
    public int sumRootToLeaf(TreeNode root) {
        return dfs(root, 0);
    }
    private int dfs(TreeNode node, int value) {
        if (node == null) return 0;
        int next = (value << 1) | node.val;
        if (node.left == null && node.right == null) return next;
        return dfs(node.left, next) + dfs(node.right, next);
    }
}

JavaScript

var sumRootToLeaf = function(root) {
  function dfs(node, value) {
    if (node === null) return 0;
    const next = value * 2 + node.val;
    if (node.left === null && node.right === null) return next;
    return dfs(node.left, next) + dfs(node.right, next);
  }
  return dfs(root, 0);
};

Python

class Solution:
    def sumRootToLeaf(self, root: Optional[TreeNode]) -> int:
        def dfs(node, value):
            if node is None:
                return 0
            value = (value << 1) | node.val
            if node.left is None and node.right is None:
                return value
            return dfs(node.left, value) + dfs(node.right, value)
        return dfs(root, 0)

C++

class Solution {
    int dfs(TreeNode* node, int value) {
        if (!node) return 0;
        int next = (value << 1) | node->val;
        if (!node->left && !node->right) return next;
        return dfs(node->left, next) + dfs(node->right, next);
    }
public:
    int sumRootToLeaf(TreeNode* root) {
        return dfs(root, 0);
    }
};

替代方案

可用显式栈保存 [节点, 当前值]，从而避免递归栈溢出；也可以先收集每条路径再转换，但会引入不必要的字符串或数组空间。

面试追问

若节点是十进制数字怎么办？

把转移改为 next = value * 10 + digit。

若需要返回每条路径的值？

在叶子处把当前值连同路径写入结果数组，而非直接求和。

递归很深时如何处理？

改用显式栈的迭代 DFS，时间复杂度不变。

常见错误

  • 在每个节点都把当前值加进答案，而不是只在叶子处累加。
  • 把“追加一位”误写为仅加节点值，漏掉左移。
  • 仅用“没有左孩子”判断叶子，忽略右孩子可能存在。
  • 共享可变路径而未在回溯时恢复。
