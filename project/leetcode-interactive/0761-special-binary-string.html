特殊的
二进制字符串

在一串满足严格平衡规则的 0 与 1 之间，通过交换相邻的特殊子串，寻找能达到的字典序最大结果。

HARD 字符串 分治 排序 非付费题

Problem

什么是“特殊”？

先只看规则与操作，不提前展开解法。

特殊的二进制字符串同时满足两条性质：

  • 1整个字符串中 0 和 1 的数量相等。
  • 2任意前缀中，1 的数量都不少于 0 的数量。

给定一个特殊字符串 s，允许执行任意次合法操作，返回可能得到的字典序最大字符串。

一次合法移动

选择两个连续、非空、且各自都是特殊字符串的子串，然后交换它们的位置。

101100⇄110010

官方示例 1

输入s = "11011000"
输出"11100100"
说明交换相邻的特殊子串 "10" 与 "1100"，可得到可达结果中的字典序最大值。

官方示例 2

输入s = "10"
输出"10"
说明字符串已经只有一个最小的特殊结构，没有可改善字典序的交换。

约束

  • 1 <= s.length <= 50
  • s[i] 为 '0' 或 '1'
  • s 保证是特殊的二进制字符串

Solution

准备好看完整题解了吗？

核心洞察、证明、复杂度、四语言代码与面试追问都收在这里。

Core Insight

同层降序，逐层最优

特殊字符串与合法括号串同构：1 类似左括号，0 类似右括号。

1. 顶层分块

扫描字符串并维护平衡值 balance。从一个块开始后，第一次回到 0 的位置就是该顶层特殊块的结尾。

2. 去壳递归

每个顶层块一定形如 1 + interior + 0。外壳固定，把内部 interior 用同样的方法做到最大。

3. 同层重排

题目允许交换相邻特殊块，所以同一层的完整块可以通过若干相邻交换形成任意排列。

4. 字典序降序

每个块内部已经最优后，把同层块按字符串字典序从大到小排列，拼接就是该层最大结果。

answer = sortDescending("1" + F(interior) + "0").join("")

Walkthrough

完整过程

扫描当前串

令 1 使平衡值加一、0 使其减一。每次平衡值回到 0，就截出一个互不交叠的顶层特殊块。

递归处理内部

对每块去掉首尾的 1 与 0，递归求内部的最大表示，再重新包上外壳。

降序排列块

所有规范化后的同层块按字典序降序排列。较大的块越早出现，整体字符串就越大。

拼接并返回

把排序后的块依次连接，作为当前递归层的答案。空串递归直接返回空串。

Correctness

为什么一定正确？

归纳证明

  1. 基础情形：空串没有可交换内容，算法返回空串，显然最优。
  2. 分解完备：平衡值每次回到 0 时切分，恰好得到当前层全部最大顶层特殊块；每个块的外壳固定为首位 1、末位 0。
  3. 内部最优：假设所有更短字符串都能被递归正确最大化，则每个块的内部都已达到可达的最大形式；保留外壳后，该块也达到最大形式。
  4. 排列最优：相邻合法块可交换，所以同层块的任意排列都可达。对于一组固定字符串，字典序降序拼接最大；若相邻两块逆序，交换它们不会减小且会在首次差异处增大结果。
  5. 结论：内部最优与同层排列最优结合，当前层最优。由字符串长度归纳，算法对输入 s 正确。

Complexity

复杂度与边界

时间：保守上界 O(n³ log n)

包含递归扫描、字符串构造以及排序中的字符串比较；n ≤ 50，这一实现足够稳定。常见简化分析会写成 O(n² log n)。

空间：O(n²)

计入各递归层创建的子串与规范化结果；只看递归栈则为 O(n)。

递归深度：O(n)

最深情形是层层嵌套，实际最多约为 n / 2 层。

边界情况

  • "10"：内部为空，原样返回。
  • 完全嵌套：每层只有一个块，仍需递归优化内部。
  • 多个相同块：排序后次序不影响结果。
  • 多个顶层块：必须在全部块递归最优后再统一排序。

替代方案

  • 可显式构造“括号树”，自底向上对子节点编码排序；本质与递归分块相同。
  • 枚举所有合法交换再搜索状态空间虽然直观，但状态数量增长快，不适合一般输入。
  • 无需动态规划：子结构之间只通过同层排列交互，没有额外状态。

四语言完整实现

Java · LeetCode 可提交
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public String makeLargestSpecial(String s) {
        List<String> blocks = new ArrayList<>();
        int balance = 0;
        int start = 0;

        for (int i = 0; i < s.length(); i++) {
            balance += s.charAt(i) == '1' ? 1 : -1;

            if (balance == 0) {
                String interior = s.substring(start + 1, i);
                String normalized = "1" + makeLargestSpecial(interior) + "0";
                blocks.add(normalized);
                start = i + 1;
            }
        }

        blocks.sort(Collections.reverseOrder());
        return String.join("", blocks);
    }
}

var makeLargestSpecial = function(s) {
    const blocks = [];
    let balance = 0;
    let start = 0;

    for (let i = 0; i < s.length; i++) {
        balance += s[i] === '1' ? 1 : -1;

        if (balance === 0) {
            const interior = s.slice(start + 1, i);
            const normalized = '1' + makeLargestSpecial(interior) + '0';
            blocks.push(normalized);
            start = i + 1;
        }
    }

    blocks.sort((a, b) => b.localeCompare(a));
    return blocks.join('');
};

class Solution:
    def makeLargestSpecial(self, s: str) -> str:
        blocks = []
        balance = 0
        start = 0

        for i, bit in enumerate(s):
            balance += 1 if bit == "1" else -1

            if balance == 0:
                interior = s[start + 1:i]
                normalized = "1" + self.makeLargestSpecial(interior) + "0"
                blocks.append(normalized)
                start = i + 1

        blocks.sort(reverse=True)
        return "".join(blocks)

#include <algorithm>
#include <functional>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string makeLargestSpecial(string s) {
        vector<string> blocks;
        int balance = 0;
        int start = 0;

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            balance += s[i] == '1' ? 1 : -1;

            if (balance == 0) {
                string interior = s.substr(start + 1, i - start - 1);
                string normalized = "1" + makeLargestSpecial(interior) + "0";
                blocks.push_back(normalized);
                start = i + 1;
            }
        }

        sort(blocks.begin(), blocks.end(), greater<string>());

        string answer;
        for (const string& block : blocks) {
            answer += block;
        }
        return answer;
    }
};

Interview Notes

追问与常见错误

面试追问

  • 为什么同层块的任意排列都可达？——相邻交换可以实现任意置换。
  • 为什么要先递归、后排序？——排序比较的应该是每个块可达到的最大表示。
  • 它和括号字符串有什么关系？——把 1/0 映射成左/右括号，前缀条件就是括号合法性。
  • 能否避免频繁切片？——可以传递左右边界或构建树，减少中间子串。

常见错误

  • 只对原始顶层块排序，没有递归优化块内部。
  • 平衡值归零后忘记更新下一块的起点。
  • 升序排序，得到字典序更小的结果。
  • 误以为只能交换一次；题目允许任意次操作。
  • 用数值大小比较长字符串，而不是按字符串字典序比较。
