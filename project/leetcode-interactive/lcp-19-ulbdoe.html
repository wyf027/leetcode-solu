题解：滚动三状态 DP

状态与转移

当前字符若要放进红段，代价是它为 y；放进黄段，代价是它为 r。第一状态只能延续；第二状态取“第一状态转入”或“第二状态延续”；第三状态同理从第二状态转入或延续。

初始化

首字符只能属于第一红段，所以 red = costRed(leaves[0])，另外两态为无穷。同步更新时必须先保存旧值，避免同一字符跨越多个阶段。

边界与复杂度

长度至少为 3，因此最终三段均可非空。无穷值取大于最大可能答案的数即可。时间 O(n)，额外空间 O(1)。

替代方案与常见错误

也可枚举两个分界点配合前缀和，但三状态 DP 更直接。常见错误是允许空段、原地更新污染旧状态，或把红叶放进红段的代价写反。
