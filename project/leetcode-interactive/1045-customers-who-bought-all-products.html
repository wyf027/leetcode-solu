买下所有产品的客户

Customers Who Bought All Products

MEDIUM数据库集合覆盖GROUP BY / HAVING

题目

Customer(customer_id, product_key) 记录客户购买的产品，且可能有重复行；customer_id 非空，product_key 引用产品表。Product(product_key) 保存全部产品，主键唯一。

找出买过 Product 表中每一种产品 的客户编号，结果顺序任意。

关键不是“购买次数够多”，而是去重后的购买集合覆盖产品全集。

表结构与约束

表列说明

Customerproduct_key INT外键；行可重复
Productproduct_key INT主键，唯一

输出只有 customer_id；无顺序要求。官方元数据未给额外数值范围。

题解

核心洞察

按客户分组，对 product_key 去重计数；若等于 Product 总行数，就覆盖全部产品。外键确保购买集合是产品全集的子集，DISTINCT 抵御重复记录。

完整过程

  1. 按 customer_id 分组。
  2. 计算每组不同产品数。
  3. 用标量子查询计算全部产品数。
  4. 在 HAVING 中保留两者相等者。

正确性

任意客户的去重购买集合是产品全集的子集。两集合大小相等时，子集必等于全集，因此查询保留的客户一定买过全部产品；反之，买过全部产品的客户，其集合大小必等于全集大小，一定被保留。

边界

  • 重复购买：必须 DISTINCT。
  • 少一种产品：计数更小，被排除。
  • Product 为空：本分组写法不产生客户；若业务将空全集视为所有候选客户均满足，应另行定义候选集合。

复杂度

N 条购买记录、P 个产品：典型执行约需 O(N) 扫描与分组/去重空间 O(N)，产品计数 O(P)，实际取决于索引和执行计划。

替代方案

双重 NOT EXISTS 可表达“不存在客户没买过的产品”，更贴近关系除法且自然处理空 Product。连接后分组也可行，但仍须去重。

面试追问

  • 普通 COUNT 为什么错？重复行会虚增。
  • 没有外键怎么办？先连接 Product 或用双重 NOT EXISTS。
  • 如何优化？考虑 Customer(customer_id, product_key) 复合索引。

常见错误

  • 比较购买行数而非不同产品数。
  • 把聚合条件写进 WHERE。
  • 硬编码产品总数。
  • 连接后忘记 DISTINCT。

可提交 SQL（MySQL）

SELECT customer_id
FROM Customer
GROUP BY customer_id
HAVING COUNT(DISTINCT product_key) = (
    SELECT COUNT(*)
    FROM Product
);

该标准写法也适用于常见 PostgreSQL / SQL Server 环境。

import java.util.*;
class Solution {
  static List<Integer> findCustomers(int[][] rows, int[] products) {
    Set<Integer> all=new HashSet<>();
    for(int p:products) all.add(p);
    Map<Integer,Set<Integer>> bought=new HashMap<>();
    for(int[] r:rows) bought.computeIfAbsent(r[0],k->new HashSet<>()).add(r[1]);
    List<Integer> ans=new ArrayList<>();
    for(var e:bought.entrySet()) if(e.getValue().containsAll(all)) ans.add(e.getKey());
    return ans;
  }
}
function findCustomers(rows, products) {
  const all=new Set(products), bought=new Map();
  for (const [id,key] of rows) {
    if (!bought.has(id)) bought.set(id,new Set());
    bought.get(id).add(key);
  }
  return [...bought].filter(([,s])=>[...all].every(k=>s.has(k))).map(([id])=>id);
}
def find_customers(rows: list[list[int]], products: list[int]) -> list[int]:
    all_products = set(products)
    bought = {}
    for customer_id, product_key in rows:
        bought.setdefault(customer_id, set()).add(product_key)
    return [customer_id for customer_id, keys in bought.items()
            if all_products.issubset(keys)]
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;
vector<int> findCustomers(const vector<vector<int>>& rows,
                          const vector<int>& products) {
  unordered_set<int> all(products.begin(),products.end());
  unordered_map<int,unordered_set<int>> bought;
  for(const auto& r:rows) bought[r[0]].insert(r[1]);
  vector<int> ans;
  for(const auto& [id,keys]:bought) {
    bool ok=true;
    for(int p:all) if(!keys.count(p)){ok=false;break;}
    if(ok) ans.push_back(id);
  }
  return ans;
}
