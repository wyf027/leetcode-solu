最少数目

从数组中恰好拿走 k 个元素，让留下来的整数种类尽可能少。先读题、再动手观察；完整思路被单独收在页面底部。

Problem

题意与边界

给定整数数组 arr 和整数 k，从数组中恰好移除 k 个元素。返回操作结束后，数组中不同整数数量的最小可能值。

函数形式：findLeastNumOfUniqueInts(arr, k) → integer
移除的是元素，不是数值标签；同一个整数可能出现多次。

官方示例

示例 1
输入：arr = [5,5,4], k = 1
输出：1
解释：移除唯一的 4，最终只剩整数 5。
示例 2
输入：arr = [4,3,1,1,3,3,2], k = 3
输出：2
解释：移除 4、2，再移除一个 1（或一个 3）；最终仍有 1 和 3 两种整数。

约束

  • 1 ≤ arr.length ≤ 10⁵
  • 1 ≤ arr[i] ≤ 10⁹
  • 0 ≤ k ≤ arr.length

贪心：按频次从小到大清空

核心洞察

要让某个整数从“不同整数集合”中消失，必须删除它的全部出现次数。若它出现 f 次，消灭这一种整数的成本就是 f。每完整消灭一种整数，收益都同样是“种类数减少 1”，因此优先选择成本最低的种类。

完整过程

  1. 使用哈希表统计每个整数的出现频次。
  2. 把所有频次放入数组，按升序排列。
  3. 从最小频次开始：若剩余 k 足以覆盖当前频次，就将该种整数全部移除并令种类数减一；否则停止完整消除。
  4. 未花完但不足以清空下一种整数的预算，可以删除任意现存元素；因为题目要求恰好删除 k 个，这些局部删除不会再减少种类数。

以示例 2 走一遍

1
计数：4→1, 2→1, 1→2, 3→3，共有 4 种整数。
2
花 1：清空 4，k 从 3 变 2，剩 3 种。
3
再花 1：清空 2，k 从 2 变 1，剩 2 种。
4
花最后 1：不足以清空频次为 2 的整数，只能局部删除，最终仍剩 2 种。

正确性证明

引理：存在一个最优方案，完整删除的种类按频次非递减选择。

设某方案完整删除了频次较大的种类 B，却保留了频次更小的种类 A。用完整删除 A 替换完整删除 B，消耗不会增加，减少的种类数仍是 1。因此替换后的方案同样可行且不更差。重复交换后，可得到按频次从小到大完整删除的最优方案。

定理：算法返回最少的不同整数数目。

依据引理，某个最优方案可先完整删除最小频次。算法持续执行这一选择，直到预算不足以完整删除下一个种类。此时所有尚存种类的删除成本都不小于下一个频次，剩余预算无法再完整删除任何一种；局部删除也不会减少种类数。因此算法已取得最大可消除种类数，返回的剩余种类数最小。

边界情况

  • k = 0：不删除任何元素，答案就是初始不同整数数。
  • k = arr.length：数组被清空，答案为 0。
  • 所有元素相同：若未全部删除，答案为 1；全部删除则为 0。
  • 所有元素互异：每花一次移除就能减少一种，答案为 n - k。
  • 多个频次相同：它们的处理顺序不影响答案。

复杂度

设数组长度为 n，不同整数个数为 m。计数耗时 O(n)，频次数组排序耗时 O(m log m)，总时间为 O(n + m log m)，额外空间为 O(m)。

替代方案

  • 频次桶：频次最大不超过 n，可用长度 n + 1 的桶记录“出现 f 次的整数有多少种”，做到 O(n) 时间、O(n) 空间。
  • 最小堆：将频次入堆，每次弹出最小值，复杂度约为 O(n + m log m)；适合只需要消费少量最小频次的情形，但实现比排序更繁琐。

面试追问

  • 若每种整数的删除收益不同，如何从“相同收益的贪心”转向背包模型？
  • 如何用频次桶把排序优化掉？
  • 若数据流持续到达、需要频繁查询不同 k 的答案，如何预处理频次前缀和？
  • 如果允许删除至多 k 个而非恰好 k 个，答案是否改变？为什么？

常见错误

  • 按数值大小删除，而不是按出现频次删除。
  • 删除某个整数的一部分后，误把不同整数数减一。
  • 只处理 k > frequency，漏掉恰好 k = frequency 时可以清空该种类。
  • 没有覆盖 k = arr.length，错误地把答案下限固定为 1。

Java

Java官方签名
import java.util.*;

class Solution {
    public int findLeastNumOfUniqueInts(int[] arr, int k) {
        Map<Integer, Integer> frequency = new HashMap<>();
        for (int value : arr) {
            frequency.put(value, frequency.getOrDefault(value, 0) + 1);
        }

        List<Integer> counts = new ArrayList<>(frequency.values());
        Collections.sort(counts);
        int remainingKinds = counts.size();

        for (int count : counts) {
            if (k < count) {
                break;
            }
            k -= count;
            remainingKinds--;
        }
        return remainingKinds;
    }
}

var findLeastNumOfUniqueInts = function(arr, k) {
    const frequency = new Map();
    for (const value of arr) {
        frequency.set(value, (frequency.get(value) || 0) + 1);
    }

    const counts = [...frequency.values()].sort((a, b) => a - b);
    let remainingKinds = counts.length;

    for (const count of counts) {
        if (k < count) break;
        k -= count;
        remainingKinds--;
    }
    return remainingKinds;
};

from collections import Counter
from typing import List

class Solution:
    def findLeastNumOfUniqueInts(self, arr: List[int], k: int) -> int:
        counts = sorted(Counter(arr).values())
        remaining_kinds = len(counts)

        for count in counts:
            if k < count:
                break
            k -= count
            remaining_kinds -= 1

        return remaining_kinds

C++

C++官方签名
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int findLeastNumOfUniqueInts(vector<int>& arr, int k) {
        unordered_map<int, int> frequency;
        for (int value : arr) {
            frequency[value]++;
        }

        vector<int> counts;
        counts.reserve(frequency.size());
        for (const auto& entry : frequency) {
            counts.push_back(entry.second);
        }
        sort(counts.begin(), counts.end());

        int remainingKinds = static_cast<int>(counts.size());
        for (int count : counts) {
            if (k < count) break;
            k -= count;
            remainingKinds--;
        }
        return remainingKinds;
    }
};
