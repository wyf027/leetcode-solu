骑士拨号器
Knight Dialer

让国际象棋骑士落在电话键盘上。每一次 L 形跳跃都追加一个数字：长度为 n 的号码，一共有多少种？

难度 · MEDIUM时间 O(n)空间 O(1)模 10⁹ + 7
官方函数签名
knightDialer(n: integer) → integer
核心视角
10 个状态
每一轮只依赖上一轮

题目

骑士按国际象棋规则移动：沿一个方向走两格，再沿垂直方向走一格，形成 L 形。它只能停在电话键盘的数字键上。起点可以是任意数字；随后执行 n - 1 次合法跳跃，依次得到一个长度为 n 的电话号码。

给定整数 n，返回不同电话号码的数量。答案可能很大，需对 1,000,000,007 取模。

示例 1
输入：n = 1
输出：10
解释：任意一个数字都可作为起点。
示例 2

输出：20
解释：[04, 06, 16, 18, 27, 29, 34, 38,
      40, 43, 49, 60, 61, 67, 72, 76,
      81, 83, 92, 94]
示例 3
输入：n = 3131
输出：136006598
解释：计算过程中持续取模。
约束
1 ≤ n ≤ 5000

核心洞察

号码的具体前缀不重要；继续跳跃时，我们只需知道它当前以哪个数字结尾。令 dp[d] 表示当前长度下、以数字 d 结尾的方案数。初始长度为 1 时，十个位置都可作为起点，因此全部为 1。

完整过程

  1. 写出每个数字经过一次骑士跳跃可以到达的邻居。
  2. 重复 n - 1 轮：新数组清零；对每个起点 from，把 dp[from] 加到所有邻居 to。
  3. 每次加法取模，轮末用新数组替换旧数组。
  4. 最后把十个终点状态相加并取模。

正确性证明

归纳基础：长度为 1 时，每个数字恰好对应一个号码，故 dp[d] = 1 正确。归纳步骤：假设 dp[from] 精确计数了长度为 k 且以 from 结尾的号码。每条这样的号码，追加任意合法邻居 to，会唯一得到长度为 k+1、以 to 结尾的号码；反之，每个长度为 k+1 的合法号码删去末位，都唯一落回某个 from 状态。因此转移不漏不重。归纳得最终各状态正确，求和即为全部号码数。

边界与复杂度

  • n = 1：不发生跳跃，答案为 10。
  • 数字 5 没有邻居；长度超过 1 时其状态为 0。
  • 每轮仅处理 10 个点和 20 条有向边，时间 O(n)；滚动数组空间 O(1)。

替代方案

可把转移写成 10×10 邻接矩阵并做快速幂，把时间降为 O(log n)、空间增至 O(10²)。本题 n ≤ 5000，线性 DP 更简单、常数也更小。也可以按对称性合并等价按键，但容易写错权重，面试中通常不如 10 状态版本清晰。

面试追问

  • 若 n 扩展到 10¹⁸，如何用矩阵快速幂？
  • 若某些数字临时禁用，状态图和初始化如何调整？
  • 能否解释为何滚动数组不会覆盖仍需使用的旧状态？

常见错误

  • 只给转移结果取模，却让中间累加溢出。
  • 误把跳跃次数写成 n，实际应为 n - 1。
  • 原地更新同一数组，混用了本轮与下一轮状态。
  • 忘记 5 无法到达任何数字，也无法从其他数字到达。

class Solution {
    public int knightDialer(int n) {
        final long MOD = 1_000_000_007L;
        int[][] next = {{4,6},{6,8},{7,9},{4,8},{0,3,9},{},{0,1,7},{2,6},{1,3},{2,4}};
        long[] dp = new long[10];
        java.util.Arrays.fill(dp, 1L);
        for (int len = 2; len <= n; len++) {
            long[] ndp = new long[10];
            for (int from = 0; from < 10; from++)
                for (int to : next[from]) ndp[to] = (ndp[to] + dp[from]) % MOD;
            dp = ndp;
        }
        long answer = 0;
        for (long ways : dp) answer = (answer + ways) % MOD;
        return (int) answer;
    }
}
/** @param {number} n @return {number} */
var knightDialer = function(n) {
  const MOD = 1_000_000_007;
  const next = [[4,6],[6,8],[7,9],[4,8],[0,3,9],[],[0,1,7],[2,6],[1,3],[2,4]];
  let dp = Array(10).fill(1);
  for (let len = 2; len <= n; len++) {
    const ndp = Array(10).fill(0);
    for (let from = 0; from < 10; from++) {
      for (const to of next[from]) ndp[to] = (ndp[to] + dp[from]) % MOD;
    }
    dp = ndp;
  }
  return dp.reduce((sum, ways) => (sum + ways) % MOD, 0);
};
class Solution:
    def knightDialer(self, n: int) -> int:
        mod = 1_000_000_007
        nxt = ((4, 6), (6, 8), (7, 9), (4, 8), (0, 3, 9), (),
               (0, 1, 7), (2, 6), (1, 3), (2, 4))
        dp = [1] * 10
        for _ in range(2, n + 1):
            ndp = [0] * 10
            for start, ways in enumerate(dp):
                for end in nxt[start]:
                    ndp[end] = (ndp[end] + ways) % mod
            dp = ndp
        return sum(dp) % mod
class Solution {
public:
    int knightDialer(int n) {
        const long long MOD = 1000000007;
        vector<vector<int>> next = {{4,6},{6,8},{7,9},{4,8},{0,3,9},{},
                                    {0,1,7},{2,6},{1,3},{2,4}};
        vector<long long> dp(10, 1);
        for (int len = 2; len <= n; ++len) {
            vector<long long> ndp(10);
            for (int from = 0; from < 10; ++from)
                for (int to : next[from]) ndp[to] = (ndp[to] + dp[from]) % MOD;
            dp.swap(ndp);
        }
        long long answer = 0;
        for (long long ways : dp) answer = (answer + ways) % MOD;
        return static_cast<int>(answer);
    }
};
