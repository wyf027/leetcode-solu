Maximum Students Taking Exam

参加考试的最大学生数

在破损座位和“斜着偷看”的限制之间，安排尽可能多的学生。先观察规则与状态变化，再决定是否展开完整题解。

位运算 · 数组 · 动态规划 · 位掩码 · 矩阵
Problem

题目

给定一个 m × n 的字符矩阵 seats。其中 '.' 表示完好座位，'#' 表示不可用的破损座位。每名学生只能坐在完好座位上。

一名学生能看到紧邻自己的左侧、右侧、左上和右上座位上的答卷，但看不到正前方或正后方。请返回能够同时参加考试、且任意学生都无法通过这些方向作弊的最多学生人数。

函数形式： maxStudents(seats)，参数为 character[][]，返回一个整数。
  • 完好座位
    可以安排学生。
  • 破损座位
    必须保持为空。
  • 冲突方向
    同排相邻、跨排斜对角均不可同时有人。

状态压缩动态规划

核心洞察

一名学生只可能与同一行的左右邻座、以及上一行的两个斜对角座位发生冲突。于是处理第 i 行时，历史信息无需全部保留，只要知道第 i-1 行的安排即可。

用一个 n 位整数表示一行：第 j 位为 1 表示第 j 列坐了学生。合法行状态必须满足：

(mask & availableRow) == mask
(mask & (mask << 1)) == 0

完整过程

  1. 将每行的完好座位转换成位掩码 available[i]。
  2. 枚举 0 .. (1<<n)-1，筛出不包含相邻 1 的所有行状态。
  3. 令 dp[prev] 表示处理完上一行、上一行状态为 prev 时的最多人数。
  4. 枚举当前合法状态 cur。除适配当前完好座位外，还要求 cur 与 prev 没有左右斜对角冲突。
  5. 用 bitCount(cur) 更新新一行的状态值，逐行滚动；最后取最大值。

转移关系

若 ((cur << 1) & prev) == 0
且 ((cur >> 1) & prev) == 0：

next[cur] = max(
  next[cur],
  dp[prev] + popcount(cur)
)

横向相邻只需要在筛选单行状态时检查；跨行只检查斜对角，不检查同列，因为学生看不到正前方或正后方。

正确性证明

  1. 单行合法性：状态只使用完好座位，且没有相邻的两个 1，所以同一行没有左右作弊冲突。
  2. 跨行合法性：转移明确排除了 cur 与 prev 的两种斜对角重叠，因此相邻两行间没有作弊冲突。
  3. 状态完备性：任何全局合法安排拆到每一行后，都一定是某个被枚举的单行合法状态，并能通过相邻行兼容检查。
  4. 最优性：动态规划对每个当前状态保留所有兼容前驱中的最大人数。由行数归纳，处理到任意一行时均为该状态下的最优解；最终取最大值即全局最优。

边界情况

  • 只有一个座位：完好时答案为 1，破损时为 0。
  • 某一整行均破损：该行只能选择状态 0，但前后行仍可正常转移。
  • 所有座位完好：每行仍不能相邻坐，且相邻行还要避开斜线。
  • 同列上下都有学生是允许的，不能误判为冲突。
  • n = 8 时只有 256 个原始位掩码，适合直接枚举。

复杂度

设行数为 m、列数为 n。每行至多考察 2^n 个当前状态与 2^n 个前驱状态，时间复杂度上界为 O(m · 4^n)；滚动数组空间复杂度为 O(2^n)。过滤合法状态后，实际转移数会更少。

替代方案

还可把每个完好座位视为图节点、作弊关系视为边，将问题转化为二分图最大独立集，并用“节点数 − 最大匹配”求解。但在 m,n ≤ 8 下，行状态压缩更直接，也更容易实现。

class Solution {
    public int maxStudents(char[][] seats) {
        int m = seats.length, n = seats[0].length;
        int limit = 1 << n;
        int[] valid = new int[limit];
        int validCount = 0;

        for (int mask = 0; mask < limit; mask++) {
            if ((mask & (mask << 1)) == 0) {
                valid[validCount++] = mask;
            }
        }

        int[] dp = new int[limit];
        java.util.Arrays.fill(dp, -1);
        dp[0] = 0;

        for (char[] row : seats) {
            int available = 0;
            for (int col = 0; col < n; col++) {
                if (row[col] == '.') available |= 1 << col;
            }

            int[] next = new int[limit];
            java.util.Arrays.fill(next, -1);
            for (int a = 0; a < validCount; a++) {
                int cur = valid[a];
                if ((cur & available) != cur) continue;
                for (int b = 0; b < validCount; b++) {
                    int prev = valid[b];
                    if (dp[prev] < 0) continue;
                    if ((cur & (prev << 1)) != 0) continue;
                    if ((cur & (prev >> 1)) != 0) continue;
                    next[cur] = Math.max(next[cur],
                        dp[prev] + Integer.bitCount(cur));
                }
            }
            dp = next;
        }

        int answer = 0;
        for (int value : dp) answer = Math.max(answer, value);
        return answer;
    }
}

var maxStudents = function (seats) {
    const m = seats.length;
    const n = seats[0].length;
    const limit = 1 << n;
    const valid = [];

    for (let mask = 0; mask < limit; mask++) {
        if ((mask & (mask << 1)) === 0) valid.push(mask);
    }

    let dp = new Int16Array(limit);
    dp.fill(-1);
    dp[0] = 0;

    for (let row = 0; row < m; row++) {
        let available = 0;
        for (let col = 0; col < n; col++) {
            if (seats[row][col] === '.') available |= 1 << col;
        }

        const next = new Int16Array(limit);
        next.fill(-1);
        for (const cur of valid) {
            if ((cur & available) !== cur) continue;
            for (const prev of valid) {
                if (dp[prev] < 0) continue;
                if ((cur & (prev << 1)) !== 0) continue;
                if ((cur & (prev >> 1)) !== 0) continue;
                next[cur] = Math.max(
                    next[cur], dp[prev] + popcount(cur)
                );
            }
        }
        dp = next;
    }

    return Math.max(...dp);
};

function popcount(value) {
    let count = 0;
    while (value !== 0) {
        value &= value - 1;
        count++;
    }
    return count;
}

class Solution:
    def maxStudents(self, seats: List[List[str]]) -> int:
        m, n = len(seats), len(seats[0])
        limit = 1 << n
        valid = [mask for mask in range(limit)
                 if mask & (mask << 1) == 0]

        dp = [-1] * limit
        dp[0] = 0

        for row in range(m):
            available = 0
            for col in range(n):
                if seats[row][col] == ".":
                    available |= 1 << col

            next_dp = [-1] * limit
            for cur in valid:
                if cur & available != cur:
                    continue
                for prev in valid:
                    if dp[prev] < 0:
                        continue
                    if cur & (prev << 1):
                        continue
                    if cur & (prev >> 1):
                        continue
                    next_dp[cur] = max(
                        next_dp[cur],
                        dp[prev] + cur.bit_count()
                    )
            dp = next_dp

        return max(dp)
class Solution {
public:
    int maxStudents(vector<vector<char>>& seats) {
        int m = seats.size();
        int n = seats[0].size();
        int limit = 1 << n;
        vector<int> valid;

        for (int mask = 0; mask < limit; ++mask) {
            if ((mask & (mask << 1)) == 0) {
                valid.push_back(mask);
            }
        }

        vector<int> dp(limit, -1);
        dp[0] = 0;

        for (const auto& row : seats) {
            int available = 0;
            for (int col = 0; col < n; ++col) {
                if (row[col] == '.') available |= 1 << col;
            }

            vector<int> next(limit, -1);
            for (int cur : valid) {
                if ((cur & available) != cur) continue;
                for (int prev : valid) {
                    if (dp[prev] < 0) continue;
                    if ((cur & (prev << 1)) != 0) continue;
                    if ((cur & (prev >> 1)) != 0) continue;
                    next[cur] = max(next[cur],
                        dp[prev] + __builtin_popcount(cur));
                }
            }
            dp.swap(next);
        }

        return *max_element(dp.begin(), dp.end());
    }
};

常见错误

  • 只检查同一行相邻，却漏掉上下行斜对角冲突。
  • 把上下同列当成冲突，错误减少可安排人数。
  • 位掩码方向前后不一致，导致左移、右移检查错位。
  • 忘记检查 cur 是否是当前行完好座位集合的子集。
  • 原地更新同一个 dp 数组，混入当前行尚未完成的状态。
