数组中的第 K 个最大元素

找的是排序后第 k 个位置的元素，而不是第 k 个不同的元素。重复值仍要计入名次。

题意

给定整数数组 nums 和整数 k，返回数组中第 k 个最大的元素。

示例

输入：nums = [3,2,1,5,6,4], k = 2

输出：5

约束

  • 1 <= k <= nums.length <= 10000
  • -10000 <= nums[i] <= 10000

想想“第 k 个”意味着我们不必完全排序。题解默认收起，先自行选择堆或快速选择的方向。

核心洞察

维护大小为 k 的最小堆。堆顶是候选中的最小值；扫描完成后，它恰好是全局第 k 大元素。

过程

  1. 依次将元素放入最小堆。
  2. 若堆大小超过 k，弹出堆顶。
  3. 遍历完毕，返回堆顶。

边界

k=1 时返回最大值；k 等于数组长度时返回最小值；相同元素必须分别保留，不能用集合去重。

复杂度

堆最多 k 个元素：时间 O(n log k)，额外空间 O(k)。快速选择平均 O(n)，但最坏可能 O(n²)。

替代方案

直接排序最简单，时间 O(n log n)。快速选择分区后只进入目标一侧，适合一次性查询且希望平均线性时间的场景。

常见错误

  • 误解为第 k 个不同元素。
  • 使用最大堆却弹出错误次数。
  • 堆大小超过 k 后没有及时移除堆顶。

参考实现

Java

class Solution {
    public int findKthLargest(int[] nums, int k) {
        PriorityQueue<Integer> heap = new PriorityQueue<>();
        for (int num : nums) {
            heap.offer(num);
            if (heap.size() > k) heap.poll();
        }
        return heap.peek();
    }
}

JavaScript

var findKthLargest = function(nums, k) {
  nums.sort((a, b) => b - a);
  return nums[k - 1];
};

Python

class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        import heapq
        heap = []
        for num in nums:
            heapq.heappush(heap, num)
            if len(heap) > k:
                heapq.heappop(heap)
        return heap[0]

C++

class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        priority_queue<int, vector<int>, greater<int>> heap;
        for (int num : nums) {
            heap.push(num);
            if (heap.size() > k) heap.pop();
        }
        return heap.top();
    }
};
