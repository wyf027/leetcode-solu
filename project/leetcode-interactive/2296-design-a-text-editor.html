01 / SPECIFICATION

先明确编辑器的行为

实现 TextEditor 类，初始文本为空，光标在位置 0。在光标处插入字符串、删除左侧字符，以及左右移动光标。删除等同于退格，不会删除光标右侧内容。光标始终满足 0 ≤ position ≤ 当前文本长度。

完整接口行为与返回值
TextEditor()构造空编辑器。
void addText(string text)在光标处插入 text，光标移到新插入文本右侧。
int deleteText(int k)最多删除左边 k 个字符，返回实际删除数量。
string cursorLeft(int k)左移最多 k 格，返回新光标左侧最后 min(10, len) 个字符。
string cursorRight(int k)右移最多 k 格，返回新光标左侧最后 min(10, len) 个字符。

len 指本次移动完成后，光标左边的字符总数；返回的字符串按文本原顺序排列。

约束

  • 1 ≤ text.length ≤ 40，1 ≤ k ≤ 40。
  • text 仅包含小写英文字母。
  • 四种操作的调用总数不超过 2 × 10⁴。

进阶：能否让每次调用只花费 O(k) 时间？插入时，用插入字符串长度衡量操作规模。

04 / SOLUTION

准备好再看实现

先思考：哪些修改总是紧挨着光标发生？

让光标成为两个栈的分界

核心洞察

维护左栈 L 与右栈 R，两个栈的栈顶都在光标旁。L 从栈底到栈顶按文本顺序保存左侧；R 从栈底到栈顶逆序保存右侧。因此完整文本恒为 L + reverse(R)，光标位置恒为 L.length。只在数组末尾增删，就不必每次搬动整个文本后缀。

例：leet|practice 对应 L = [l,e,e,t]，R = [e,c,i,t,c,a,r,p]。R 的末尾 p 才是光标右边紧邻的字符。

双栈状态 · 与上方回放同步

每行从左到右是「栈底 → 栈顶」，右端贴近光标。请用下方控制观察字符转移。

L · 正序左侧 → TOP

R · 逆序右侧 → TOP

两个栈均为空。

完整过程

  1. 初始化：建立两个空栈。
  2. 插入：按顺序把 text 的字符压入 L，R 保持不变，光标自然到达新文本末尾。
  3. 删除：令 d = min(k, |L|)，从 L 弹出 d 次，返回 d。
  4. 左移：最多执行 k 次 R.push(L.pop())，L 为空时停止。
  5. 右移：最多执行 k 次 L.push(R.pop())，R 为空时停止。
  6. 返回窗口：移动结束后只截取 L 的最后 10 个字符，按原顺序拼接。

正确性论证

以操作次数归纳，维持不变式：L 为光标左侧的正序字符，reverse(R) 为右侧正序字符，光标位置等于 |L|。初始两个空栈显然成立。

  • 插入将新字符追加到 L，正好位于旧左侧与旧右侧之间，光标随 L 的增长向右移动。
  • 删除仅弹出 L 的末尾，正好删除紧邻光标的左侧字符，数量被 |L| 限制，不影响 R。
  • 左移一次把 L 的最后一个字符放到 reverse(R) 的最前端，完整文本不变，光标左移一格；右移是其逆操作。重复最多 k 次即可得到正确位置。
  • 栈空即停止，所以光标不能越界。L 的末尾 min(10, |L|) 个字符恰好等于要求的返回窗口。

每种操作都保持不变式并产生正确返回值，因此任意合法调用序列都正确。

边界与常见错误

  • 空文本时删除返回 0，左右移动返回空字符串；空字符串不是 null。
  • 到达边界后多余步数忽略，删除返回实际数量而非请求的 k。
  • R 必须逆序存储；直接拼接 L 与 R 会把右侧文本倒置。
  • 窗口在移动之后提取；即使无法继续移动，仍要返回当前窗口。
  • 不要先连接整个 L 再取后 10 位，那会把一次返回变成 O(n)。
  • 中间插入不应清空 R；本题的删除是 Backspace，不是向右删除。

复杂度

设 m 为插入长度，d 为实际删除数量，t 为实际移动次数，n 为当前字符数。插入摊还 O(m)，删除摊还 O(d)，移动摊还 O(t + 10)，提取返回值 O(min(10, |L|))。因此以每次操作的请求规模衡量，满足摊还 O(k)；动态数组偶发扩容会复制已有元素，单次最坏界并非严格 O(k)。

两个栈合计存 n 个有效字符，逻辑空间 O(n)。下方动态容器可能保留历史容量；按实际分配内存计算，上界是 O(N)，N 为历史最大文本长度。返回字符串最多占 10 个字符的额外空间。

替代方案与面试追问

  • 双向链表 + 光标节点：每个字符单独一个节点，邻近位置的插删与移动为 O(k)，不依赖数组扩容的摊还分析；节点额外内存与缓存局部性通常更差。
  • 字符串 + 光标下标：容易写，但中间插删需要复制后缀，最坏每次 O(n)。适合小规模原型。
  • Gap Buffer：用连续数组中间的空隙表示光标，编辑与光标移动靠调整空隙；双栈可视为相似思路。
  • 随机跳转到第 i 个字符？双栈要逐字符搬运；大文档可考虑带子树长度的平衡树或 Rope，实现 O(log n) 定位。
  • 撤销 / 重做？记录逆操作和被删除文本；单独移动光标是否进入撤销历史需要明确产品语义。
  • 支持 emoji？本题只含 ASCII 小写字母；真实编辑器需明确码点与字素簇边界，不能直接沿用按字符单元计数的假设。

Java
class TextEditor {
    private final StringBuilder left = new StringBuilder();
    private final StringBuilder right = new StringBuilder();

    public TextEditor() {}

    public void addText(String text) {
        left.append(text);
    }

    public int deleteText(int k) {
        int count = Math.min(k, left.length());
        left.setLength(left.length() - count);
        return count;
    }

    public String cursorLeft(int k) {
        while (k-- > 0 && left.length() > 0) {
            right.append(left.charAt(left.length() - 1));
            left.setLength(left.length() - 1);
        }
        return context();
    }

    public String cursorRight(int k) {
        while (k-- > 0 && right.length() > 0) {
            left.append(right.charAt(right.length() - 1));
            right.setLength(right.length() - 1);
        }
        return context();
    }

    private String context() {
        return left.substring(Math.max(0, left.length() - 10));
    }
}
JavaScript
class TextEditor {
    constructor() {
        this.left = [];
        this.right = [];
    }

    addText(text) {
        for (const char of text) this.left.push(char);
    }

    deleteText(k) {
        const count = Math.min(k, this.left.length);
        for (let i = 0; i < count; i++) this.left.pop();
        return count;
    }

    cursorLeft(k) {
        while (k-- > 0 && this.left.length) {
            this.right.push(this.left.pop());
        }
        return this.context();
    }

    cursorRight(k) {
        while (k-- > 0 && this.right.length) {
            this.left.push(this.right.pop());
        }
        return this.context();
    }

    context() {
        return this.left.slice(-10).join('');
    }
}

class TextEditor:
    def __init__(self):
        self.left = []
        self.right = []

    def addText(self, text: str) -> None:
        self.left.extend(text)

    def deleteText(self, k: int) -> int:
        count = min(k, len(self.left))
        for _ in range(count):
            self.left.pop()
        return count

    def cursorLeft(self, k: int) -> str:
        for _ in range(min(k, len(self.left))):
            self.right.append(self.left.pop())
        return self._context()

    def cursorRight(self, k: int) -> str:
        for _ in range(min(k, len(self.right))):
            self.left.append(self.right.pop())
        return self._context()

    def _context(self) -> str:
        return ''.join(self.left[-10:])
C++
#include <algorithm>
#include <string>
using namespace std;

class TextEditor {
    string left, right;

    string context() const {
        size_t start = left.size() > 10 ? left.size() - 10 : 0;
        return left.substr(start);
    }

public:
    TextEditor() = default;

    void addText(string text) {
        left += text;
    }

    int deleteText(int k) {
        int count = min(k, static_cast<int>(left.size()));
        for (int i = 0; i < count; ++i) left.pop_back();
        return count;
    }

    string cursorLeft(int k) {
        while (k-- > 0 && !left.empty()) {
            right.push_back(left.back());
            left.pop_back();
        }
        return context();
    }

    string cursorRight(int k) {
        while (k-- > 0 && !right.empty()) {
            left.push_back(right.back());
            right.pop_back();
        }
        return context();
    }
};
