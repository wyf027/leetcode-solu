01 · Problem

题意

一只圆环上按顺序刻着字符串 ring。初始时，ring[0] 对准十二点方向。给定需要拼写的字符串 key，要从左到右依次完成每个字符。

拼写一个字符时，可以把圆环顺时针或逆时针旋转；每转动一个位置计 1 步。当某个等于当前目标字符的刻度对准十二点后，按下中心按钮完成输入，再计 1 步。返回拼完整个 key 所需的最少总步数。

函数形式

findRotateSteps(ring: string, key: string) -> integer

约束

06 · Solution

准备好查看题解了吗？

建议先想清楚：为什么每次只选最近的同字符位置不一定安全？

Core insight

题解：按字符分层的环形动态规划

核心洞察

同一个字符可能出现在圆环的多个位置。当前看起来最近的落点，未必有利于拼写下一个字符，因此不能只做局部贪心。

把“已经拼到 key[i]，且十二点对准圆环位置 j”视为状态。只保留到达每个可行位置的最小旋转代价，再向下一层转移。

环形距离

设圆环长度为 n，两个索引差的绝对值为 d = |a - b|，则最少旋转步数为：

dist(a, b) = min(d, n - d)

最终再统一加上 key.length，对应每个字符都要按一次中心按钮。

完整过程

  1. 预处理圆环：为每个字母记录它出现的全部索引。
  2. 初始状态只有位置 0，旋转代价为 0。
  3. 依次处理 key 的每个字符。枚举上一层可达位置 p，再枚举当前字符的每个位置 q。
  4. 用 dp[p] + dist(p, q) 更新当前层 next[q] 的最小值。
  5. 所有字符处理完成后，取最后一层的最小旋转代价，并加上按键次数 key.length。

正确性证明

状态不变式：处理完 key[0..i] 后，dp[j] 等于拼完这一前缀并让位置 j 对准十二点所需的最小旋转次数。

基础情形：尚未拼写字符时，圆环位置 0 对准十二点，旋转代价为 0，初始状态成立。

归纳转移：若上一层不变式成立，要在位置 q 拼写下一个字符，之前必然停在某个上一层位置 p，新增的最小旋转代价正是 dist(p,q)。枚举全部 p 并取最小值，就覆盖且只覆盖所有到达 q 的合法路径，因此当前层仍满足不变式。

结论：最后一层所有状态覆盖拼完整个 key 的全部结尾位置，取最小旋转代价后加上每个字符一次的按键代价，即为最少总步数。

复杂度

设圆环长度为 n，关键词长度为 m。最坏时间复杂度为 O(m · n²)，滚动状态空间为 O(n)；位置表额外占用 O(n)。

边界情况

  • 圆环或关键词长度为 1。
  • 目标字符已经在十二点方向，旋转代价为 0。
  • 同一字符重复出现，或 key 含连续重复字符。
  • 顺时针与逆时针距离相同。

替代方案

记忆化 DFS：状态同样是 (keyIndex, ringIndex)，递归尝试目标字符的所有位置并缓存结果。表达直观，但要注意递归深度与函数调用开销。

Dijkstra / 最短路：可以把状态图显式理解为分层最短路；所有层只向下一层连边，因而直接动态规划更轻量。

局部贪心：每次选择最近的目标字符位置并不可靠，因为相同的当前代价可能带来完全不同的后续位置，无法保证全局最优。

四语言完整实现

Java

官方签名
import java.util.*;

class Solution {
    public int findRotateSteps(String ring, String key) {
        int n = ring.length();
        List<Integer>[] positions = new ArrayList[26];
        for (int i = 0; i < 26; i++) {
            positions[i] = new ArrayList<>();
        }
        for (int i = 0; i < n; i++) {
            positions[ring.charAt(i) - 'a'].add(i);
        }

        Map<Integer, Integer> dp = new HashMap<>();
        dp.put(0, 0);

        for (char target : key.toCharArray()) {
            Map<Integer, Integer> next = new HashMap<>();
            for (int q : positions[target - 'a']) {
                int best = Integer.MAX_VALUE;
                for (Map.Entry<Integer, Integer> entry : dp.entrySet()) {
                    int p = entry.getKey();
                    int diff = Math.abs(p - q);
                    int distance = Math.min(diff, n - diff);
                    best = Math.min(best, entry.getValue() + distance);
                }
                next.put(q, best);
            }
            dp = next;
        }

        int minRotation = Collections.min(dp.values());
        return minRotation + key.length();
    }
}

JavaScript

官方签名
/**
 * @param {string} ring
 * @param {string} key
 * @return {number}
 */
var findRotateSteps = function(ring, key) {
    const n = ring.length;
    const positions = Array.from({ length: 26 }, () => []);

    for (let i = 0; i < n; i++) {
        positions[ring.charCodeAt(i) - 97].push(i);
    }

    let dp = new Map([[0, 0]]);

    for (const target of key) {
        const next = new Map();
        for (const q of positions[target.charCodeAt(0) - 97]) {
            let best = Number.POSITIVE_INFINITY;
            for (const [p, cost] of dp) {
                const diff = Math.abs(p - q);
                const distance = Math.min(diff, n - diff);
                best = Math.min(best, cost + distance);
            }
            next.set(q, best);
        }
        dp = next;
    }

    return Math.min(...dp.values()) + key.length;
};

Python 3
from collections import defaultdict
from typing import Dict, List


class Solution:
    def findRotateSteps(self, ring: str, key: str) -> int:
        n = len(ring)
        positions: Dict[str, List[int]] = defaultdict(list)

        for index, char in enumerate(ring):
            positions[char].append(index)

        dp = {0: 0}

        for target in key:
            next_dp = {}
            for q in positions[target]:
                best = float("inf")
                for p, cost in dp.items():
                    diff = abs(p - q)
                    distance = min(diff, n - diff)
                    best = min(best, cost + distance)
                next_dp[q] = best
            dp = next_dp

        return min(dp.values()) + len(key)

C++

C++17
#include <algorithm>
#include <climits>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int findRotateSteps(string ring, string key) {
        int n = static_cast<int>(ring.size());
        vector<vector<int>> positions(26);
        for (int i = 0; i < n; ++i) {
            positions[ring[i] - 'a'].push_back(i);
        }

        unordered_map<int, int> dp;
        dp[0] = 0;

        for (char target : key) {
            unordered_map<int, int> next;
            for (int q : positions[target - 'a']) {
                int best = INT_MAX;
                for (const auto& [p, cost] : dp) {
                    int diff = abs(p - q);
                    int distance = min(diff, n - diff);
                    best = min(best, cost + distance);
                }
                next[q] = best;
            }
            dp = move(next);
        }

        int minRotation = INT_MAX;
        for (const auto& [position, cost] : dp) {
            minRotation = min(minRotation, cost);
        }
        return minRotation + static_cast<int>(key.size());
    }
};

常见错误

  • 忘记环形距离中的 n - diff。
  • 只选择离当前位置最近的一个同字符位置。
  • 把按下中心按钮的次数漏掉或重复计算。
  • 更新当前层时原地覆盖上一层状态。
  • 只记录一个字符的首次出现位置。
