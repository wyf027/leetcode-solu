n 的第 k 个因子

The kth Factor of n

在升序排列的因子中定位第 k 个。先读清返回条件，再通过交互实验观察每个候选数；完整解法不会在首屏提前揭晓。

n % i 余数为 0，
i 才是因子
01 / PROBLEM

题目要求

非付费题

给定两个正整数 n 和 k。若正整数 i 满足 n % i == 0，则 i 是 n 的因子。把所有因子按升序排列，返回其中第 k 个；如果因子不足 k 个，则返回 -1。

示例 01

输入：n = 12, k = 3 输出：3 解释：[1, 2, 3, 4, 6, 12] 中第 3 个是 3。

示例 02

输入：n = 7, k = 2 输出：7 解释：[1, 7] 中第 2 个是 7。

示例 03

输入：n = 4, k = 4 输出：-1 解释：[1, 2, 4] 只有 3 个因子。

约束与进阶

1 <= k <= n <= 1000

进阶：能否把时间复杂度降到低于 O(n)？

04 / SOLUTION

平方根扫描 + 因子配对

若 i 整除 n，那么 n / i 也一定是因子。两者成对出现，且至少一个不大于 √n。因此只需扫描到平方根。

1

收集小因子

从 1 向 √n 扫描。命中整除时，把 i 追加到 small；它天然升序。

2

收集大因子

同时保存 n / i。随着 i 变大，配对的大因子变小，所以 large 天然降序。

3

处理完全平方数

若 i × i = n，配对的两个值相同，只记录一次，避免重复平方根。

完整过程

  1. 1
    初始化

    创建 small 与 large 两个数组。

  2. 2
    扫描

    对 i = 1…⌊√n⌋，仅在 n % i = 0 时记录。

  3. 3
    拼接

    完整升序为 small + reverse(large)。

  4. 4
    取值

    若 k 超出总长度返回 -1，否则返回下标 k - 1。

正确性说明

完备性：任意因子 d 都与 n / d 配对。两者不可能都大于 √n，否则乘积会大于 n；所以扫描一定遇到这对中的较小者，并记录两者。

无重复：非平方根配对得到两个不同因子；完全平方数的平方根只加入 small，不再加入 large。因此每个因子恰好记录一次。

有序性：small 随 i 递增；large 中 n / i 随 i 递减，反转后递增。且 small 的末尾不大于 large 反转后的开头，拼接得到完整升序序列。

结论：第 k-1 个数组元素正是第 k 个因子；数组不足 k 个时返回 -1，符合题意。

时间复杂度

O(√n)

最多检查 ⌊√n⌋ 个候选数。

空间复杂度

O(√n)

保存因子数组；若只计额外变量，可用按排名定位的变体进一步优化。

Solution.java
class Solution {
    public int kthFactor(int n, int k) {
        java.util.List<Integer> small = new java.util.ArrayList<>();
        java.util.List<Integer> large = new java.util.ArrayList<>();

        for (int i = 1; i <= n / i; i++) {
            if (n % i == 0) {
                small.add(i);
                if (i != n / i) {
                    large.add(n / i);
                }
            }
        }

        if (k <= small.size()) {
            return small.get(k - 1);
        }
        int largeIndex = large.size() - (k - small.size());
        return largeIndex >= 0 ? large.get(largeIndex) : -1;
    }
}

var kthFactor = function(n, k) {
    const small = [];
    const large = [];

    for (let i = 1; i <= Math.floor(n / i); i++) {
        if (n % i === 0) {
            small.push(i);
            if (i !== n / i) {
                large.push(n / i);
            }
        }
    }

    if (k <= small.length) {
        return small[k - 1];
    }
    const largeIndex = large.length - (k - small.length);
    return largeIndex >= 0 ? large[largeIndex] : -1;
};

class Solution:
    def kthFactor(self, n: int, k: int) -> int:
        small = []
        large = []
        i = 1

        while i <= n // i:
            if n % i == 0:
                small.append(i)
                if i != n // i:
                    large.append(n // i)
            i += 1

        if k <= len(small):
            return small[k - 1]

        large_index = len(large) - (k - len(small))
        return large[large_index] if large_index >= 0 else -1

class Solution {
public:
    int kthFactor(int n, int k) {
        vector<int> small;
        vector<int> large;

        for (int i = 1; i <= n / i; ++i) {
            if (n % i == 0) {
                small.push_back(i);
                if (i != n / i) {
                    large.push_back(n / i);
                }
            }
        }

        if (k <= static_cast<int>(small.size())) {
            return small[k - 1];
        }
        int largeIndex = static_cast<int>(large.size())
                       - (k - static_cast<int>(small.size()));
        return largeIndex >= 0 ? large[largeIndex] : -1;
    }
};

边界与常见错误

  • • n = 1：唯一因子是 1；扫描仍能正确记录。
  • • 完全平方数：不要把 √n 放入两个数组，否则排名整体错位。
  • • k 超界：因子不足时必须返回 -1，不能访问越界下标。
  • • 顺序误判：large 保存时是降序；直接拼接会得到错误次序。
  • • 浮点边界：用 i <= n / i 可避免乘法溢出，也无需依赖浮点平方根。

替代方案

线性扫描 O(n)：从 1 到 n 逐个检查，每命中一个因子就让 k 减 1。写法最短，在 n ≤ 1000 时足够，但没有回答进阶问题。

不保存完整数组：先扫描小因子并直接消耗 k；若答案落在大因子一侧，可根据已发现的配对数量反向定位。空间可降到 O(1)，但索引推导更容易出错。

质因数分解：先分解 n，再枚举所有因子并排序。对单次、n 较小的查询通常更复杂；多查询或需要因子结构时才更有价值。

面试追问

为什么扫描到 √n 就够？

因为因子成对相乘为 n，每对中至少一个不超过 √n。

能否边扫描边提前返回？

若 k 落在小因子段可以；大因子段仍需知道共有多少对才能定位。

怎样做到 O(1) 额外空间？

第一次统计小因子数量，第二次按目标配对位置扫描；以额外一次 √n 遍历换空间。

n 很大时要注意什么？

避免 i * i 的整数溢出，使用 i ≤ n / i；语言整数范围也要匹配输入。
