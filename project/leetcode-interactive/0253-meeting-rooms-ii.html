Meeting Rooms II
会议高度图

每场会议开始时占用一个房间，结束时归还一个房间。把所有端点排序后扫一遍，同时进行的会议数就是曲线高度；最高点便是最少会议室数。

题意

给定会议时间区间数组 intervals，返回容纳所有会议所需的最少会议室数量。每个区间为 [start, end]。

经典样例
intervals = [[0, 30], [5, 10], [15, 20]]
输出：2

付费题；按常见题面，会议结束时刻可立刻复用同一间会议室。

交互：扫描事件点

同一时刻先处理结束（−1）再处理开始（+1），可复用刚释放的会议室。

题解：扫描线统计并发

O(n log n)

核心洞察

把每个开始记为 +1、结束记为 −1。按时间排序并累加，任何时刻的和等于正在开会的数量，最大和就是不能共用的最大数量。结束事件在同一时刻排在开始事件前面。

完整过程

  1. 为每个区间生成两个事件。
  2. 按时间升序，时间相同则 −1 在前。
  3. 累加 delta，维护 maximum。
  4. 返回 maximum。

边界与复杂度

空数组答案是 0；相接区间 [1,5] 与 [5,8] 只需一间。排序是主要成本。

时间：O(n log n)
空间：O(n)

替代方案取舍

最小堆维护最早结束时间同样是 O(n log n)，还能自然解释“分配哪一间房”。扫描线更直观地直接得到并发峰值。

常见错误

  • 同一时间把开始排在结束前，导致相接会议被误判为重叠。
  • 只统计开始事件却未正确释放房间。
  • 排序后忘记维护历史最大值。
  • 把区间当作闭区间；本题会议可在结束时刻复用。

面试追问

如何给每场会议分配具体房间号？ 用按结束时间排序的最小堆，并维护可复用房间编号。
若端点很大但稀疏？ 扫描线仍适用，不需离散整个时间轴。

class Solution {
    public int minMeetingRooms(int[][] intervals) {
        int[][] events = new int[intervals.length * 2][2];
        for (int i = 0; i < intervals.length; i++) { events[2*i] = new int[]{intervals[i][0], 1}; events[2*i+1] = new int[]{intervals[i][1], -1}; }
        java.util.Arrays.sort(events, (a, b) -> a[0] != b[0] ? Integer.compare(a[0], b[0]) : Integer.compare(a[1], b[1]));
        int current = 0, answer = 0;
        for (int[] event : events) { current += event[1]; answer = Math.max(answer, current); }
        return answer;
    }
}

var minMeetingRooms = function (intervals) {
  const events = intervals.flatMap(([start, end]) => [[start, 1], [end, -1]]);
  events.sort((a, b) => a[0] - b[0] || a[1] - b[1]);
  let current = 0, answer = 0;
  for (const [, delta] of events) { current += delta; answer = Math.max(answer, current); }
  return answer;
};
