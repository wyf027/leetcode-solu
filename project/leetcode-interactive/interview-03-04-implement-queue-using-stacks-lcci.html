Restricted operations manual

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误和四语言代码默认隐藏。

Core insight

把顺序翻转推迟到 OUT 真正空的时候

IN 只接收新元素；OUT 只提供队首。peek 或 pop 前，若 OUT 为空，才将 IN 从栈顶逐个弹出并压入 OUT。两次后进先出叠加成先进先出，而且 OUT 未空时绝不重复搬运。

完整过程

  1. push(x)：直接把 x 压入 IN。
  2. 读取或删除队首前调用 shift()。
  3. 若 OUT 非空，shift() 立即返回。
  4. 若 OUT 为空，把 IN 全部逐个压入 OUT。
  5. peek/pop 直接操作 OUT 栈顶；empty 同时检查两个栈。

边界

  • 题目保证空队列不会调用 pop 或 peek。
  • OUT 未空时，新 push 的元素仍留在 IN，不影响已有队首。
  • 一次批量翻转之后可以连续 pop，直到 OUT 清空。
  • 重复值不影响顺序；两个栈保存的是到达先后关系。

复杂度

pushO(1)
peek / pop摊还 O(1)
单次最坏O(n)
额外空间O(n)

替代方案

每次 pop 时把 IN 倒到临时栈、取出队首、再全部倒回，单次稳定 O(n)，但会重复搬运；也可让 push O(n) 始终维护队首在栈顶。面试中优先给出延迟翻转的摊还方案。

面试追问

  • 如何用势能或记账法证明摊还 O(1)？
  • 为什么 OUT 非空时不能把 IN 的新元素搬过去？
  • 如果需要线程安全，两个栈之间的转移如何加锁？
  • 怎样扩展出 O(1) 的 size 接口？

常见错误

  • 每次 peek/pop 都搬运 IN，丢掉摊还优化。
  • OUT 非空时仍继续转移，导致新元素越过旧元素。
  • empty() 只检查一个栈。
  • 把数组头部 shift 当作栈操作，既违反题意又可能引入 O(n)。

class MyQueue {
    private final java.util.Deque<Integer> in = new java.util.ArrayDeque<>();
    private final java.util.Deque<Integer> out = new java.util.ArrayDeque<>();

    public MyQueue() {}

    public void push(int x) {
        in.push(x);
    }

    public int pop() {
        moveIfNeeded();
        return out.pop();
    }

    public int peek() {
        moveIfNeeded();
        return out.peek();
    }

    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }

    private void moveIfNeeded() {
        if (!out.isEmpty()) return;
        while (!in.isEmpty()) {
            out.push(in.pop());
        }
    }
}
var MyQueue = function () {
  this.inStack = [];
  this.outStack = [];
};

MyQueue.prototype.push = function (x) {
  this.inStack.push(x);
};

MyQueue.prototype.moveIfNeeded = function () {
  if (this.outStack.length) return;
  while (this.inStack.length) {
    this.outStack.push(this.inStack.pop());
  }
};

MyQueue.prototype.pop = function () {
  this.moveIfNeeded();
  return this.outStack.pop();
};

MyQueue.prototype.peek = function () {
  this.moveIfNeeded();
  return this.outStack[this.outStack.length - 1];
};

MyQueue.prototype.empty = function () {
  return this.inStack.length === 0 && this.outStack.length === 0;
};
class MyQueue:
    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x: int) -> None:
        self.in_stack.append(x)

    def _move_if_needed(self) -> None:
        if self.out_stack:
            return
        while self.in_stack:
            self.out_stack.append(self.in_stack.pop())

    def pop(self) -> int:
        self._move_if_needed()
        return self.out_stack.pop()

    def peek(self) -> int:
        self._move_if_needed()
        return self.out_stack[-1]

    def empty(self) -> bool:
        return not self.in_stack and not self.out_stack
class MyQueue {
private:
    std::stack<int> in;
    std::stack<int> out;

    void moveIfNeeded() {
        if (!out.empty()) return;
        while (!in.empty()) {
            out.push(in.top());
            in.pop();
        }
    }

public:
    MyQueue() = default;

    void push(int x) {
        in.push(x);
    }

    int pop() {
        moveIfNeeded();
        int value = out.top();
        out.pop();
        return value;
    }

    int peek() {
        moveIfNeeded();
        return out.top();
    }

    bool empty() {
        return in.empty() && out.empty();
    }
};
