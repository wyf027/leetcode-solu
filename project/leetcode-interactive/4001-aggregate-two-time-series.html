聚合两个时间序列

按时间升序合并两条序列。关键规则不是“缺失记 0”：某时间戳缺失时，应使用该序列下一条更晚记录的值；没有更晚记录才是 0。

题意

给定严格按 timestamp 递增的 series1 与 series2，每个点为 [timestamp, value]。只在任一序列出现过的时间戳输出 [timestamp, summedValue]，并保持严格递增。

约束：1 ≤ length ≤ 10⁵，时间戳和值均为正整数且不超过 10⁹。输入框中 ␠ 表示一个可见空格，换行与空格均可分隔点。

官方示例（转述）

series1 = [[1,3],[4,1]]
series2 = [[2,2],[5,2]]
输出：[[1,5],[2,3],[4,3],[5,2]]

在 t = 1，第二条的下一条是 [2,2]，因此为 3 + 2 = 5；在 t = 4，第二条仍使用 [5,2]。

可见交互：双指针时序台

每行输入 timestamp,value，例如 1,3␠4,1；输入不合法时不会执行。

准备好：运行后会显示每个输出时间戳使用的两条值。

题解

首屏默认收起；展开后提供正确性、边界、替代方案和四语言提交签名。

核心洞察

若 t1 < t2，series2 在 t1 缺失，但当前指针正好是下一条更晚记录；输出 [t1, v1 + v2]，只移动 i。相等时两指针同时移动。

完整过程与正确性

循环不变式：i、j 分别指向每条序列尚未处理的最早点。较小时间戳不会再有更近的未来值，故可安全写入。耗尽一侧后，另一侧没有对方的更晚点，直接保留。

复杂度、边界与替代

O(m+n) 时间、O(m+n) 输出空间。尾部另一条值必须为 0；相等时须同时前进。哈希表后排序多了存储和排序，且不如双指针直接表达“下一更晚值”。面试追问：K 条序列用最小堆。
