聚合两个时间序列

把两个按时间升序排列的序列合成一条：相同时间戳的数值相加，不同时间戳原样保留，结果仍按时间升序。

题目描述

给定 series1 和 series2，其中每个元素为 [timestamp, value]。两条序列内部的时间戳均严格递增。返回聚合后的时间序列。

约束
1 ≤ series1.length, series2.length ≤ 105
时间戳严格递增；value 为整数。
输出中每个时间戳只出现一次。

示例

输入
series1 = [[1,2],[3,4],[6,1]]
series2 = [[2,5],[3,7],[5,2]]

输出
[[1,2],[2,5],[3,11],[5,2],[6,1]]

时间戳 3 同时出现，因此值为 4 + 7 = 11。

可见交互：逐步聚合

每行写成 时间戳,数值；可用空格或换行分隔多个点。

洞察

两条序列已经有序。每一步只需比较两个“尚未处理的最早时间戳”，就能确定下一个输出。

过程

A 小则取 A；B 小则取 B；相等则输出一次，并让两个指针同时前进。某一边耗尽后追加另一边。

复杂度

每个元素至多被查看一次：时间 O(m+n)，输出空间 O(m+n)（不计返回结果之外为 O(1)）。

边界与常见错误

边界
• 相同时间戳必须只写入一个点。
• 一条序列可能先耗尽。
• 输入已保证各自严格有序，不需要排序。
• 负值照常累加，不要过滤为零。
错误与替代方案
• 错误：相等时只移动一个指针，会重复或死循环。
• 错误：双层循环比对，退化为 O(mn)。
• 可替代：哈希表累加再排序，逻辑直观但多了 O((m+n) log(m+n)) 排序成本；这里双指针更合适。
