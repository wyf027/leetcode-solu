四个线程共享同一个计数器：只有匹配当前数字规则的线程可以打印，其余线程必须等待。目标不仅是输出正确，还要严格保持 1 到 n 的顺序。

实现 FizzBuzz 类。相同实例会交给四个不同线程；四个方法可能并发开始，但整体必须依次产生前 n 个 Fizz Buzz 项。

  • fizz()当前数能被 3 整除、但不能被 5 整除时，调用 printFizz()。
  • buzz()当前数能被 5 整除、但不能被 3 整除时，调用 printBuzz()。
  • fizzbuzz()当前数同时能被 3 和 5 整除时，调用 printFizzBuzz()。
  • number()当前数既不能被 3 整除也不能被 5 整除时，调用 printNumber(x)。

Solution

题解：一个计数器，四个条件谓词

核心洞察

共享状态只需要当前数字 i。四个线程分别等待自己的谓词成立；拿到执行权的线程完成一次打印，把 i 加一，再唤醒其他等待者重新竞争。判断必须放在循环中，以抵御虚假唤醒。

完整过程

  1. 初始化 i = 1 与同步原语。
  2. 每个 worker 在锁保护下等待：要么 i > n，要么自己的谓词成立。
  3. 匹配线程调用对应打印回调。
  4. 递增 i，广播唤醒；到达终点也必须广播，让所有线程退出。

正确性

互斥：同一时刻仅一个线程能检查并推进共享计数器，因此不会重复打印同一个位置。

唯一性：对任意整数 i，四个谓词两两互斥且穷尽全部情况，所以恰有一个 worker 可打印。

顺序性：打印与 i++ 在同一临界区发生；下一次打印只能观察到更大的 i，因此输出严格按 1…n 排列。

终止性：每次有效执行都令 i 增加，最多 n 次后所有线程被唤醒并退出。

边界与复杂度

  • n = 1 时只有 number 线程打印一次，其余线程被终止广播唤醒。
  • n = 3/5/15 分别触达 fizz、buzz、fizzbuzz 边界。
  • 时间复杂度：O(n) 次有效打印；等待/唤醒的调度开销依赖运行时。
  • 额外空间：O(1)（不计判题器收集的输出）。

替代方案

可以用四个信号量组成“令牌环”：number/对应 worker 打印后直接释放下一数字所需线程的信号量。它减少无效唤醒，但路由逻辑重复，终止时还要额外释放所有信号量。条件变量版本更统一，也更适合面试中证明。

面试追问

  • 为什么条件变量必须配合 while，不能只用 if？
  • 打印回调放在锁内有什么取舍？怎样兼顾顺序和慢 I/O？
  • 若扩展为任意规则表，如何避免为每条规则新建专用代码？
  • 如何处理某个 worker 异常退出，避免其他线程永久等待？

常见错误

  • 先判断 3 或 5，再判断 15，导致 15 被 fizz/buzz 抢走。
  • 每个线程自己遍历 1…n，却没有共享进度，输出重复或乱序。
  • 使用 if 等待，忽略虚假唤醒。
  • 递增计数器后忘记唤醒，造成死锁。
  • 只在正常打印后通知，终点处没通知仍在等待的线程。
  • 在临界区之外检查或修改 i，引入数据竞争。

Java · LeetCode 可提交ReentrantLock + Condition
import java.util.concurrent.locks.Condition;
import java.util.concurrent.locks.ReentrantLock;
import java.util.function.IntConsumer;

class FizzBuzz {
    private final int n;
    private int current = 1;
    private final ReentrantLock lock = new ReentrantLock();
    private final Condition changed = lock.newCondition();

    public FizzBuzz(int n) { this.n = n; }

    private void run(Runnable action, java.util.function.IntPredicate match)
            throws InterruptedException {
        while (true) {
            lock.lock();
            try {
                while (current <= n && !match.test(current)) changed.await();
                if (current > n) { changed.signalAll(); return; }
                action.run();
                current++;
                changed.signalAll();
            } finally { lock.unlock(); }
        }
    }

    public void fizz(Runnable printFizz) throws InterruptedException {
        run(printFizz, x -> x % 3 == 0 && x % 5 != 0);
    }
    public void buzz(Runnable printBuzz) throws InterruptedException {
        run(printBuzz, x -> x % 5 == 0 && x % 3 != 0);
    }
    public void fizzbuzz(Runnable printFizzBuzz) throws InterruptedException {
        run(printFizzBuzz, x -> x % 15 == 0);
    }
    public void number(IntConsumer printNumber) throws InterruptedException {
        run(() -> printNumber.accept(current),
            x -> x % 3 != 0 && x % 5 != 0);
    }
}

JavaScript · 本地语义参考异步条件队列
class FizzBuzz {
  constructor(n) {
    this.n = n;
    this.current = 1;
    this.waiters = [];
    this.locked = false;
    this.lockQueue = [];
  }

  async lock() {
    if (!this.locked) { this.locked = true; return; }
    await new Promise(resolve => this.lockQueue.push(resolve));
  }
  unlock() {
    const next = this.lockQueue.shift();
    if (next) next(); else this.locked = false;
  }
  notifyAll() {
    const list = this.waiters.splice(0);
    list.forEach(resolve => resolve());
  }
  wait() {
    return new Promise(resolve => this.waiters.push(resolve));
  }

  async worker(match, print) {
    while (true) {
      await this.lock();
      while (this.current <= this.n && !match(this.current)) {
        this.unlock();
        await this.wait();
        await this.lock();
      }
      if (this.current > this.n) {
        this.notifyAll(); this.unlock(); return;
      }
      print(this.current);
      this.current++;
      this.notifyAll();
      this.unlock();
    }
  }
  fizz(printFizz) {
    return this.worker(x => x % 3 === 0 && x % 5 !== 0, () => printFizz());
  }
  buzz(printBuzz) {
    return this.worker(x => x % 5 === 0 && x % 3 !== 0, () => printBuzz());
  }
  fizzbuzz(printFizzBuzz) {
    return this.worker(x => x % 15 === 0, () => printFizzBuzz());
  }
  number(printNumber) {
    return this.worker(x => x % 3 !== 0 && x % 5 !== 0, printNumber);
  }
}
Python 3 · LeetCode 可提交threading.Condition
from threading import Condition
from typing import Callable

class FizzBuzz:
    def __init__(self, n: int):
        self.n = n
        self.current = 1
        self.condition = Condition()

    def _run(self, match: Callable[[int], bool], emit: Callable[[int], None]):
        while True:
            with self.condition:
                self.condition.wait_for(
                    lambda: self.current > self.n or match(self.current)
                )
                if self.current > self.n:
                    self.condition.notify_all()
                    return
                emit(self.current)
                self.current += 1
                self.condition.notify_all()

    def fizz(self, printFizz: 'Callable[[], None]') -> None:
        self._run(lambda x: x % 3 == 0 and x % 5 != 0,
                  lambda _: printFizz())

    def buzz(self, printBuzz: 'Callable[[], None]') -> None:
        self._run(lambda x: x % 5 == 0 and x % 3 != 0,
                  lambda _: printBuzz())

    def fizzbuzz(self, printFizzBuzz: 'Callable[[], None]') -> None:
        self._run(lambda x: x % 15 == 0,
                  lambda _: printFizzBuzz())

    def number(self, printNumber: 'Callable[[int], None]') -> None:
        self._run(lambda x: x % 3 != 0 and x % 5 != 0, printNumber)
C++ · LeetCode 可提交mutex + condition_variable
#include <condition_variable>
#include <functional>
#include <mutex>

using namespace std;

class FizzBuzz {
private:
    int n, current = 1;
    mutex m;
    condition_variable cv;

    void run(const function<bool(int)>& match,
             const function<void(int)>& emit) {
        while (true) {
            unique_lock<mutex> lock(m);
            cv.wait(lock, [&] { return current > n || match(current); });
            if (current > n) { cv.notify_all(); return; }
            emit(current);
            ++current;
            cv.notify_all();
        }
    }

public:
    FizzBuzz(int n) : n(n) {}

    void fizz(function<void()> printFizz) {
        run([](int x) { return x % 3 == 0 && x % 5 != 0; },
            [&](int) { printFizz(); });
    }
    void buzz(function<void()> printBuzz) {
        run([](int x) { return x % 5 == 0 && x % 3 != 0; },
            [&](int) { printBuzz(); });
    }
    void fizzbuzz(function<void()> printFizzBuzz) {
        run([](int x) { return x % 15 == 0; },
            [&](int) { printFizzBuzz(); });
    }
    void number(function<void(int)> printNumber) {
        run([](int x) { return x % 3 != 0 && x % 5 != 0; },
            [&](int x) { printNumber(x); });
    }
};
