Minimum Operations to Halve Array Sum

每一次对折，都改变下一次选择。先理解目标，再探索如何用更少的操作达到它。

01 / 题目

给定正整数数组 nums。每次可以选择数组中的一个当前数值，将其变为原来的一半；允许得到小数，也允许再次选择之前已经减半的元素。返回让数组总和相对初始总和减少至少一半所需的最少操作次数。

设初始总和为 S，目标是最终总和 ≤ S / 2。返回操作次数，不是最终数组或减少量。

官方示例 1

输入：nums = [5,19,8,1]
输出：3

初始和为 33。依次将 19 → 9.5、9.5 → 4.75、8 → 4，得到 [5,4.75,4,1]，总和为 14.75；减少 18.25 ≥ 16.5。最少需要 3 次。

官方示例 2

输入：nums = [3,8,20]
输出：3

初始和为 31。一种操作方式是 20 → 10、10 → 5、3 → 1.5，得到 [1.5,8,5]，总和为 14.5；减少 16.5 ≥ 15.5。最少需要 3 次。

约束与接口

  • 1 ≤ nums.length ≤ 100000
  • 1 ≤ nums[i] ≤ 10000000
  • 参数：nums: integer[]；返回：integer；方法：halveArray(nums)。

03 / 独立题解

准备好后展开，查看交互过程、推导与四语言实现。

每次拿走当前最大的半份

选择当前值 x，会减少 x / 2。因此当前值越大，这一步的收益就越大。使用最大堆保存所有当前值：取最大值、减半、把新值放回，累计减少量达到初始和的一半时停止。

完整过程

  1. 计算初始总和 S，并固定目标 T = S / 2；将数组值加入最大堆。
  2. 维护累计减少量 R = 0、操作次数 k = 0。
  3. 当 R < T，取堆顶 x，令 h = x / 2；更新 R += h，将 h 放回堆，k 加一。
  4. 当 R ≥ T，返回 k。

示例 1 的收益依次为 9.5、4.75、4，累计 9.5 → 14.25 → 18.25，第三次达到 16.5。示例 2 的贪心过程选择 20、10、8，收益 10、5、4，同样为 3 次；最优序列不必与官方展示的序列相同。

为什么正确

对原始元素 a，连续操作产生的收益链为 a/2、a/4、a/8……，严格递减；要取链中后面的收益，必须先取它前面的收益。

任意时刻，每条链尚未取走的第一项就是当前元素的一半；这条链更深的收益都不会更大。所以所有尚未取走的收益中，最大者一定在某条链的首部。最大堆每次恰好选择这个全局最大收益。

因此，贪心取出的前 k 个收益之和不小于任何合法 k 次操作的收益和。若贪心在第 k 次首次达标，那么前 k−1 次收益仍不足，其他 k−1 次方案也不可能达标；而贪心 k 次可达标，故 k 最小。相同最大值任取其一不会改变结论。

边界与数值

  • 一个元素只需 1 次；全体相等时需对每项减半一次，总计 n 次。
  • 单个元素很大时可能连续被选中；不要把被减半的数永久丢弃。
  • 允许恰好达标，循环条件是 R < T。原数组为空不在本题输入范围内。
  • 总和最大为 10¹²，Java/C++ 的 32 位整数无法容纳。使用 double 累加，且必须保留小数。
  • 这里除以 2 产生二进制有限小数，适合双精度。正整数初值下，未达标时平均当前值大于 0.5，因此被选择的最大值也大于 0.5；结合单项上界，减半深度很小。不要改用整除或人为添加会提前停下的 epsilon。

复杂度

设操作次数为 k。每次最大堆更新 O(log n)，额外空间 O(n)。对所有元素各减半一次一定能达标，因此最优 k ≤ n。Java 逐个入堆的初始化为 O(n log n)，总时间 O((n+k) log n)；JavaScript、Python 和 C++ 的批量建堆为 O(n)，总时间 O(n+k log n)。最坏时间统一为 O(n log n)；n = 1 时为常数时间。

替代方案与取舍

每次线性扫描最大值可省去堆实现，耗时 O(nk)，最坏 O(n²)，适合小规模演示。每次完整排序为 O(kn log n)，浪费了其余元素次序不变这一点。只在开始排序一次后依次处理不正确，因为减半后的元素可能仍然最大。最大堆只维护下一步需要的最大值，适合本题规模。

常见错误

  • 将“减少一半”误解为每次删除元素，或只把原数组每项处理一次。
  • 对整数使用整除，让 1 变为 0；这不符合恰好减半。
  • 不断以当前总和的一半作为新目标，导致目标漂移。
  • Python 小根堆忘记取负数，或更新时符号不一致。
  • JavaScript 没有标准内置最大堆；下方代码自带下沉操作，不依赖平台队列库。

面试追问

若要求减少 80% 呢？同一收益链论证仍适用，把目标改为 0.8S，但 k ≤ n 不再成立。

是否存在唯一最优序列？不存在；并列最大值可任取，而且有些非贪心序列也能用最少次数达标，如官方示例 2。

为什么可以原地替换堆顶后仅下沉？堆顶数值只会减小，潜在违规只发生在它与子节点之间，无需向上调整。

Java

import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public int halveArray(int[] nums) {
        PriorityQueue<Double> heap =
            new PriorityQueue<>(Collections.reverseOrder());
        double sum = 0;
        for (int x : nums) {
            sum += x;
            heap.offer((double) x);
        }
        double reduced = 0;
        int operations = 0;
        while (reduced < sum / 2) {
            double half = heap.poll() / 2;
            reduced += half;
            heap.offer(half);
            operations++;
        }
        return operations;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number}
 */
var halveArray = function(nums) {
    const heap = nums.slice();
    const n = heap.length;
    const target = nums.reduce((s, x) => s + x, 0) / 2;

    function down(i) {
        while (2 * i + 1 < n) {
            let child = 2 * i + 1;
            if (child + 1 < n && heap[child + 1] > heap[child]) {
                child++;
            }
            if (heap[i] >= heap[child]) break;
            [heap[i], heap[child]] = [heap[child], heap[i]];
            i = child;
        }
    }
    for (let i = Math.floor(n / 2) - 1; i >= 0; i--) down(i);

    let reduced = 0, operations = 0;
    while (reduced < target) {
        const half = heap[0] / 2;
        reduced += half;
        heap[0] = half;
        down(0);
        operations++;
    }
    return operations;
};

Python 3

from typing import List
import heapq

class Solution:
    def halveArray(self, nums: List[int]) -> int:
        heap = [-float(x) for x in nums]
        heapq.heapify(heap)
        target = sum(nums) / 2
        reduced = 0.0
        operations = 0
        while reduced < target:
            half = -heap[0] / 2
            reduced += half
            heapq.heapreplace(heap, -half)
            operations += 1
        return operations

C++

#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    int halveArray(vector<int>& nums) {
        priority_queue<double> heap(nums.begin(), nums.end());
        double sum = 0;
        for (int x : nums) sum += x;
        double reduced = 0;
        int operations = 0;
        while (reduced < sum / 2) {
            double half = heap.top() / 2;
            heap.pop();
            heap.push(half);
            reduced += half;
            ++operations;
        }
        return operations;
    }
};
