Easy哈希计数贪心

题目与约束

每个数字代表一道题涉及的知识点类型。

目标：覆盖 N 题

任务

给定长度为 2 * N 的整数数组 questions。选择 N 道互不相同的题目时，返回被选题目至少需要多少种知识点类型。

约束

  • questions.length == 2 * N
  • 2 ≤ questions.length ≤ 10⁵
  • 1 ≤ questions[i] ≤ 1000

示例 1

questions = [2, 1, 6, 2]

输出：1。选两道类型为 2 的题即可。

示例 2

questions = [1,5,1,3,4,5,2,5,3,3,8,6]

输出：2。类型 3 与 5 合计正好覆盖 6 题。

频次降序贪心

核心洞察

固定要选 N 题，先选频次最大者永远不会比选择频次更小者差。

交换论证

若方案选了频次较小类型 A 却没选较大类型 B，用 B 替换 A 不会降低覆盖题数。因此存在一个最优方案按频次降序取前若干类。

复杂度

哈希计数为 O(n)，对 k 个不同类型排序为 O(k log k)，空间 O(k)。题目类型值有界时也可用长度 1001 的计数数组。

完整过程

把“选题”转成“挑类型”。

  1. 用哈希表记录每种知识点的出现次数。
  2. 提取所有频次并按从大到小排序。
  3. 依次累加频次，累计值达到 N 时停止，已取频次数量即为答案。

边界与替代方案

边界

所有题类型相同，答案为 1。每道题类型都不同，覆盖 N 题恰需 N 种类型。频次总和一定为 2N。

替代方案

可维护大小为 1001 的桶，逆序扫描非零频次，避免比较器开销。对本题约束，两种做法都安全。

常见错误

按类型编号排序而非按频次排序；累计后未检查是否已达到 N；把“至少覆盖 N”误写成“必须恰好覆盖 N”。

面试追问

如果题目类型没有上界怎么办？使用哈希表后排序。若改为每类选择有成本，则不能只按频次贪心，需要重新建模为带成本的覆盖问题。

四语言实现

class Solution {
  public int halfQuestions(int[] questions) {
    int[] count = new int[1001];
    for (int x : questions) count[x]++;
    Arrays.sort(count);
    int need = questions.length / 2, answer = 0;
    for (int i = 1000; need > 0; i--) { need -= count[i]; answer++; }
    return answer;
  }
}
function halfQuestions(questions) {
  const count = new Map();
  for (const x of questions) count.set(x, (count.get(x) || 0) + 1);
  const freq = [...count.values()].sort((a, b) => b - a);
  let need = questions.length / 2, answer = 0;
  for (const n of freq) { need -= n; answer++; if (need <= 0) break; }
  return answer;
}
from collections import Counter

class Solution:
    def halfQuestions(self, questions: List[int]) -> int:
        need = len(questions) // 2
        answer = 0
        for amount in sorted(Counter(questions).values(), reverse=True):
            need -= amount
            answer += 1
            if need <= 0:
                return answer
class Solution {
public:
  int halfQuestions(vector<int>& questions) {
    unordered_map<int, int> count;
    for (int x : questions) ++count[x];
    vector<int> freq;
    for (auto& [_, n] : count) freq.push_back(n);
    sort(freq.rbegin(), freq.rend());
    int need = questions.size() / 2, answer = 0;
    for (int n : freq) { need -= n; if (++answer && need <= 0) break; }
    return answer;
  }
};
