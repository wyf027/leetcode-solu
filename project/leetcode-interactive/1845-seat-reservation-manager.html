座位预约管理系统

1845 · Seat Reservation Manager / MEDIUM

每次预约，都把当前最小的空座位交给下一位观众。

官方题目 ↗

01 / 任务说明

管理编号从 1 到 n 的座位，初始全部空闲。实现下列类接口，持续维护预约状态：

  • SeatManager(int n)：创建含 n 个座位的管理器。
  • int reserve()：预约当前空闲座位中编号最小的一个，并返回编号。
  • void unreserve(int seatNumber)：取消该编号座位的预约，无返回值。

约束：1 ≤ n ≤ 10⁵；1 ≤ seatNumber ≤ n；reserve 与 unreserve 的调用总数不超过 10⁵。每次 reserve 都保证有空座位；每次 unreserve 的座位都保证已预约。

输入操作：
["SeatManager","reserve","reserve","unreserve","reserve","reserve","reserve","reserve","unreserve"]

输出：

先预约 1、2；释放 2 后再次预约得到 2；随后依次得到 3、4、5；最后释放 5。构造函数和取消预约在示例输出中记为 null。

05 / 题解：回收最小堆 + 新座位指针

核心洞察

从未分配的座位始终是连续区间 [next, n]。已分配后又释放的座位都小于 next。只需用最小堆保存被释放的编号，用 next 表示下一个从未分配的编号。

内部状态 · 与剧场回放同步

堆的根是回收编号的最小值。各层按数组顺序展示；同一层不保证有序。官方例子中最多只有一个回收座位。

完整过程

  1. 初始化 next = 1，回收堆为空；不预先存入 n 个编号。
  2. reserve：堆非空就弹出堆顶；否则返回 next，再将 next 加一。
  3. unreserve(x)：将 x 插入最小堆，通过上浮恢复父节点不大于子节点的性质。
  4. 弹出根时，用末尾元素填补根位置，反复与较小的孩子交换、下沉。

例如前两次预约后 next = 3。释放 2 得到堆 [2]；再次预约从堆取 2，next 仍为 3。之后才继续分配新编号。

正确性

维护不变量：所有空闲座位恰好是不相交的两部分——回收堆中的编号与 [next, n]。初始化显然成立。释放一个已预约编号时，它必然小于 next，插入堆后恰好恢复该空座位。预约时，若堆非空，其最小元素比所有未分配编号都小；弹出它就是全局最小空位。若堆为空，next 即为最小空位；递增 next 恰好移除该座位。各操作保持不变量，因此每次返回值正确。

边界与复杂度

n = 1 同样适用。next 可到达 n + 1，此时未分配区间为空；合法的后续 reserve 必然从回收堆取座位。题目保证取消的是已预约座位，故不会重复插入同一空闲编号。

设堆中回收座位数为 k：构造 O(1)；使用新编号的 reserve 为 O(1)；堆弹出和 unreserve 为 O(log(k + 1))，最坏 O(log n)。额外空间 O(k)，最坏 O(n)。JavaScript 动态数组扩容按摊还计算。

替代方案

  • 全部空座位放入最小堆：思路直接，构造可用 O(n) heapify；逐个插入的一般上界为 O(n log n)，空间从一开始就是 O(n)。
  • 有序集合：查最小值、删除、插入均可高效完成，空间 O(n)。
  • 布尔数组每次扫描：容易实现，但单次预约最坏 O(n)，大量操作不合适。

常见错误

  • 用队列保存释放编号：释放顺序不等于编号顺序。
  • 堆非空仍递增 next：会跳过从未分配的座位。
  • 在 C++ 使用默认最大堆，或认为 JavaScript 数组默认排序是数值顺序。
  • 把堆数组当成完全排序的数组；只保证父子关系。

面试追问

若允许非法调用？增加容量与预约状态检查，防止重复释放和超卖。若要求连续 m 个空位？需要维护空闲区间或线段树。若多线程同时预约？最小值查询与删除必须组成原子操作，可用互斥锁保护管理器。

Java

import java.util.PriorityQueue;

class SeatManager {
    private int next = 1;
    private final PriorityQueue<Integer> recycled = new PriorityQueue<>();

    public SeatManager(int n) {}

    public int reserve() {
        if (!recycled.isEmpty()) return recycled.poll();
        return next++;
    }

    public void unreserve(int seatNumber) {
        recycled.offer(seatNumber);
    }
}

JavaScript

自带二叉最小堆，不依赖平台的优先队列库。

var SeatManager = function(n) {
    this.next = 1;
    this.heap = [];
};

SeatManager.prototype.reserve = function() {
    const h = this.heap;
    if (h.length === 0) return this.next++;
    const answer = h[0];
    const last = h.pop();
    if (h.length) {
        h[0] = last;
        let i = 0;
        while (2 * i + 1 < h.length) {
            let child = 2 * i + 1;
            if (child + 1 < h.length && h[child + 1] < h[child]) child++;
            if (h[i] <= h[child]) break;
            [h[i], h[child]] = [h[child], h[i]];
            i = child;
        }
    }
    return answer;
};

SeatManager.prototype.unreserve = function(seatNumber) {
    const h = this.heap;
    h.push(seatNumber);
    let i = h.length - 1;
    while (i > 0) {
        const p = Math.floor((i - 1) / 2);
        if (h[p] <= h[i]) break;
        [h[p], h[i]] = [h[i], h[p]];
        i = p;
    }
};

Python 3

import heapq

class SeatManager:
    def __init__(self, n: int):
        self.next = 1
        self.recycled = []

    def reserve(self) -> int:
        if self.recycled:
            return heapq.heappop(self.recycled)
        seat = self.next
        self.next += 1
        return seat

    def unreserve(self, seatNumber: int) -> None:
        heapq.heappush(self.recycled, seatNumber)

C++

#include <queue>
#include <vector>
#include <functional>

class SeatManager {
    int next = 1;
    std::priority_queue<int, std::vector<int>, std::greater<int>> recycled;
public:
    SeatManager(int n) {}

    int reserve() {
        if (recycled.empty()) return next++;
        int seat = recycled.top();
        recycled.pop();
        return seat;
    }

    void unreserve(int seatNumber) {
        recycled.push(seatNumber);
    }
};
