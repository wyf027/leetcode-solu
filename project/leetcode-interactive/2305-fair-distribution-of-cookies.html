公平分发饼干

Fair Distribution of Cookies

每一袋都必须完整交出去。怎样让拿得最多的孩子，尽可能少拿？

前往 LeetCode 官方题目 ↗

01 / 题意与输入

给定整数数组 cookies，第 i 项代表第 i 袋的饼干数；另有 k 个孩子。把全部袋子分给这些孩子，每袋只能交给一个孩子，不能拆分。

一种分法的不公平程度，是所有孩子的饼干总数中的最大值。返回所有分法中，这个最大值的最小可能值。目标不是“最多与最少的差”，也不是平均数。

返回形式：distributeCookies(cookies, k) → integer
只返回最优数值，无须返回每袋归属。题目未要求每个孩子必须拿到袋子。

约束

  • 2 ≤ cookies.length ≤ 8
  • 1 ≤ cookies[i] ≤ 100000
  • 2 ≤ k ≤ cookies.length

02 / 官方示例

示例 1

cookies = [8,15,10,20,8], k = 2
输出：31

分成 [8,15,8] 和 [10,20]，两个孩子分别拿到 31、30 块。最大值为 31，无法再降低。

示例 2

cookies = [6,1,3,2,2,4,1,2], k = 3
输出：7

分成 [6,1]、[3,2,2]、[4,1,2]。每个孩子都是 7 块，不公平程度为 7。

04 / 独立题解

先想一想：袋子不可拆分，会怎样影响分配？

把一袋的选择，变成一层搜索

核心洞察：最多只有 8 袋，每袋可选择 k 个孩子。维护每个孩子当前总量 load[j]，依次尝试“放入 → 递归 → 撤销”。找到完整分法时，用其中最大的总量更新答案。

完整过程

  1. 令 best = sum(cookies)：把所有袋子给同一个孩子，是合法的初始上界。
  2. dfs(i, peak) 表示前 i 袋已分完，peak 是当前最大的孩子总量。
  3. 尝试把第 i 袋放到孩子 j。若新总量 ≥ best，后续只能增加，跳过该分支。
  4. 否则加上这袋，递归处理下一袋，返回后减去同一袋，恢复现场。
  5. 若恢复后该孩子的总量是 0，停止本层循环；其余空孩子与他等价。
  6. 当 i 到达 n，令 best 与 peak 取较小值。所有分支处理完后返回 best。

为什么正确

状态不变式：进入 dfs(i, peak) 时，前 i 袋各被分配一次，load 正确记录各孩子总数，peak 为它们的最大值。放入和撤销保证这个不变式在每次递归和返回时成立。

覆盖性：不剪枝时，每层枚举孩子，覆盖全部 kⁿ 种分法。空孩子之间交换名字不会改变后续能达到的最大总量，因此仅探索第一个空孩子仍保留每种本质不同分法。

上界剪枝：饼干数均为正，如果某次放入后的总量已经达到 best，则此分支最终最大值不可能小于 best；已有合法答案可替代它。best 只来自合法分法，故始终为可行上界。终止时，所有可能更优的分法均已考虑，返回值即最小不公平程度。

边界与复杂度

  • k = n：每人一袋可达到 max(cookies)，这也是任何分法的下界。
  • 总量能整除 k，不代表可以均分；例如 [2,2,2]、k = 2，答案是 4。
  • 重复袋子仍是独立袋子；撤销必须按当前袋子准确减回。
  • 总量最多 800000，四份代码的整数范围足够；JavaScript Number 在此范围内精确。
  • 时间最坏 O(kⁿ)，每个搜索边只需常数工作，peak 避免叶子扫描。剪枝改善实际搜索量，但不承诺更低的最坏上界。
  • 额外空间 O(n + k)：递归深度 n 与负载数组 k。演示额外缓存已观看帧，提交代码不保存轨迹。

替代方案

可将袋子降序排列，让大袋更早触发剪枝，但需说明是否修改输入。也可采用子集动态规划：预计算每个袋子集合的总和，令 dp[t][mask] 表示用 t 个孩子分配 mask 的最小最大负载，枚举 sub ⊆ mask，取 min(max(dp[t−1][mask−sub], sum[sub]))。设 dp[0][0] = 0，其余为无穷；允许空子集，整体 O(k·3ⁿ) 时间、滚动数组 O(2ⁿ) 空间。

常见错误

  • 把目标写成最大值减最小值，或直接返回向上取整的平均值。
  • 每次都给当前最少的孩子：这是启发式，不能保证最优。例如 [8,7,6,5,4]、k = 2，按此规则可能得到 17，最优是 15。
  • 忘记撤销 load，导致兄弟分支继承错误状态。
  • 在非空孩子处直接 break，会漏掉不同总量对应的有效分支。
  • 把初始上界设成 0，再用 ≥ best 剪枝，会截掉所有分支。

面试追问

  • 能否提前结束？当 best 达到 max(最大单袋, ⌈总量/k⌉) 这个下界时，已证明最优。
  • 需要分配方案怎么办？记录每袋归属，在 best 严格改善时复制当前归属；初始也保存全部给第一个孩子的可行方案。
  • 如何去掉更多对称分支？本层用集合跳过相同 load 值的孩子，而不仅跳过空孩子；相同负载的未来子问题等价。

四语言完整提交代码

四份实现均保留输入顺序，采用相同的上界剪枝和空孩子对称剪枝。代码尚未执行验证。

Java

class Solution {
    private int best;
    private int[] load;

    public int distributeCookies(int[] cookies, int k) {
        best = 0;
        for (int x : cookies) best += x;
        load = new int[k];
        dfs(cookies, 0, 0);
        return best;
    }

    private void dfs(int[] a, int i, int peak) {
        if (i == a.length) {
            best = Math.min(best, peak);
            return;
        }
        for (int j = 0; j < load.length; j++) {
            if (load[j] + a[i] < best) {
                load[j] += a[i];
                dfs(a, i + 1, Math.max(peak, load[j]));
                load[j] -= a[i];
            }
            // Empty children are interchangeable.
            if (load[j] == 0) break;
        }
    }
}

/**
 * @param {number[]} cookies
 * @param {number} k
 * @return {number}

var distributeCookies = function(cookies, k) {
    let best = cookies.reduce((s, x) => s + x, 0);
    const load = Array(k).fill(0);
    function dfs(i, peak) {
        if (i === cookies.length) {
            best = Math.min(best, peak);
            return;
        }
        for (let j = 0; j < k; j++) {
            if (load[j] + cookies[i] < best) {
                load[j] += cookies[i];
                dfs(i + 1, Math.max(peak, load[j]));
                load[j] -= cookies[i];
            }
            if (load[j] === 0) break;
        }
    }
    dfs(0, 0);
    return best;
};

from typing import List

class Solution:
    def distributeCookies(self, cookies: List[int], k: int) -> int:
        best = sum(cookies)
        load = [0] * k

        def dfs(i: int, peak: int) -> None:
            nonlocal best
            if i == len(cookies):
                best = min(best, peak)
                return
            for j in range(k):
                if load[j] + cookies[i] < best:
                    load[j] += cookies[i]
                    dfs(i + 1, max(peak, load[j]))
                    load[j] -= cookies[i]
                if load[j] == 0:
                    break

        dfs(0, 0)
        return best

class Solution {
public:
    int distributeCookies(vector<int>& cookies, int k) {
        int best = accumulate(cookies.begin(), cookies.end(), 0);
        vector<int> load(k, 0);
        function<void(int, int)> dfs = [&](int i, int peak) {
            if (i == static_cast<int>(cookies.size())) {
                best = min(best, peak);
                return;
            }
            for (int j = 0; j < k; ++j) {
                if (load[j] + cookies[i] < best) {
                    load[j] += cookies[i];
                    dfs(i + 1, max(peak, load[j]));
                    load[j] -= cookies[i];
                }
                if (load[j] == 0) break;
            }
        };
        dfs(0, 0);
        return best;
    }
};
