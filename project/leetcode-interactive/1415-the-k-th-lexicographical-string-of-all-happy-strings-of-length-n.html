01

题目

开心字符串只使用字符 a、b、c，并且任意两个相邻字符都不相同。

给定整数 n 和 k，把所有长度恰好为 n 的开心字符串按字典序排列，返回其中第 k 个；若总数不足 k 个，返回空字符串。

函数形式： getHappyString(n: int, k: int) -> string
注意：题目中的 k 从 1 开始计数。
字符范围
每一位只能从 {a, b, c} 中选择。
相邻约束
对所有有效下标 i，满足 s[i] != s[i + 1]。
约束
1 <= n <= 10
1 <= k <= 100

官方示例

示例 1
输入：n = 1, k = 3
输出："c"
解释：["a", "b", "c"] 的第 3 个是 "c"。
示例 2
输入：n = 1, k = 4
输出：""
解释：长度为 1 的开心字符串只有 3 个。
示例 3
输入：n = 3, k = 9
输出："cab"
解释：["aba", "abc", "aca", "acb",
      "bab", "bac", "bca", "bcb",
      "cab", "cac", "cba", "cbc"]
      中第 9 个是 "cab"。
示例 4
输入：n = 2, k = 7
输出：""
示例 5
输入：n = 10, k = 100
输出："abacbabacb"

题解：按分支计数，直接定位

核心洞察

3 × 2^(n-1)
第一位有 3 种选择；之后每一位都不能等于前一位，所以各有 2 种。
2^remaining
固定当前某个合法字符后，剩余位置形成大小相同且连续的字典序区间。
跳块，不枚举
若 k 大于当前分支大小，减去整块；否则答案就在该分支中，立即选定字符。

完整过程

  1. 先算总数 3 * 2^(n - 1)。若 k 更大，直接返回空字符串。
  2. 从左到右构造答案。当前位置剩余 r 位未填时，每个合法候选字符下面恰有 2^r 个完整字符串。
  3. 按 a, b, c 的字典序检查候选，并跳过与前一字符相同的候选。
  4. 若 k > 2^r，说明目标不在该块，令 k -= 2^r；否则选中该字符，继续下一位。
  5. 填满 n 位后，当前前缀就是原列表中的第 k 个目标字符串。

以 n = 3, k = 9 为例

首字符每个分支覆盖 2^2 = 4 个字符串。先跳过 a 块（k 变 5），再跳过 b 块（k 变 1），因此首字符为 c。第二位不能选 c；a 分支覆盖 2 个，k = 1 落入其中，所以选 a。最后一位不能选 a，b 分支覆盖 1 个，选 b，得到 cab。

正确性证明

引理 1：固定任意合法前缀后，若还剩 r 位，每一位都有恰好 2 个不等于前一字符的选择，因此补全数是 2^r。

引理 2：在同一前缀下，按 a、b、c 顺序选择的各候选分支，在完整字典序列表中分别占据连续且依次排列的区间。这来自字典序先比较第一个不同位置。

归纳：在每一位开始时，k 表示目标在当前前缀对应区间中的相对名次。由引理 1 与引理 2，减去某个完整分支大小只会跳过不包含目标的前置区间；第一个满足 k <= block 的分支必然包含目标。选中它后，不变量对下一位仍成立。n 位全部选完时，区间只含一个字符串，它就是目标。因此算法正确；总数不足 k 时返回空串也符合题意。

边界情况

  • n = 1：总数为 3，答案依次是 a、b、c。
  • k = 1：始终进入第一个合法分支。
  • k = total：始终定位到最后一个可行区间。
  • k > total：在构造前返回空字符串。

复杂度

时间：O(n)。每一位最多检查 3 个字符。

额外空间：O(n)，用于保存返回字符串；若不计输出空间，辅助空间为 O(1)。

替代方案

回溯枚举：按字典序生成所有开心字符串，生成到第 k 个即可停止。它直观且在本题 n <= 10 时完全可行，最坏生成 3 * 2^(n-1) 个字符串；但没有利用各分支大小相等的结构。

全量生成后排序：也能通过，但如果生成顺序本身就是 a、b、c，则排序是多余的，还会增加存储和排序成本。

class Solution {
    public String getHappyString(int n, int k) {
        int total = 3 * (1 << (n - 1));
        if (k > total) {
            return "";
        }

        StringBuilder answer = new StringBuilder();
        char previous = '\0';

        for (int position = 0; position < n; position++) {
            int remaining = n - position - 1;
            int blockSize = 1 << remaining;

            for (char candidate = 'a'; candidate <= 'c'; candidate++) {
                if (candidate == previous) {
                    continue;
                }
                if (k > blockSize) {
                    k -= blockSize;
                } else {
                    answer.append(candidate);
                    previous = candidate;
                    break;
                }
            }
        }
        return answer.toString();
    }
}

var getHappyString = function(n, k) {
    const total = 3 * (1 << (n - 1));
    if (k > total) return "";

    let answer = "";
    let previous = "";

    for (let position = 0; position < n; position++) {
        const remaining = n - position - 1;
        const blockSize = 1 << remaining;

        for (const candidate of ["a", "b", "c"]) {
            if (candidate === previous) continue;
            if (k > blockSize) {
                k -= blockSize;
            } else {
                answer += candidate;
                previous = candidate;
                break;
            }
        }
    }
    return answer;
};

public:

            return "";
        }

面试追问

  • 若字符集大小从 3 变成 m，分支大小与总数如何变化？
  • 若不同位置允许的字符集不同，还能否用同样的等块跳过？
  • 如果 n 很大、结果数量超过整数范围，怎样进行饱和计数防止溢出？
  • 如何把算法改造成返回字典序第 k 个、且禁止更多相邻模式的字符串？

常见错误

  • 把 1-based 的 k 当成 0-based，导致边界整体偏一。
  • 分支大小写成 2^(n-position)，多算了一层。
  • 跳过分支时忘记从 k 中减去完整块大小。
  • 没有跳过与前一字符相同的候选。
  • 先构造再判断越界，可能返回长度不足 n 的前缀。
