岛屿的最大面积

在二维网格中找出由上下左右相连的陆地所组成的最大岛屿。

中等

题意

给定仅包含 0（海洋）和 1（陆地）的网格，返回最大岛屿面积；没有岛屿时返回 0。岛屿只按上下左右方向相连。

示例

grid = [[0,0,1,0],[1,1,1,0],[0,1,0,0]]

输出：5

约束

  • m、n 的范围为 1 到 50。
  • 每个格子为 0 或 1。
  • 面积按陆地格子数计算。

分步交互

对每块未访问陆地应做什么？

发现陆地 (1, 2)，当前面积 = 1

题解：洪泛搜索

洞察

一座岛就是图中的一个连通分量。枚举格子，遇到陆地便从它出发，搜索并统计整个分量。

过程

  1. 扫描全部格子。
  2. 遇到 1 时将其置为 0。
  3. 向四个方向递归或入队。
  4. 记录每次搜索面积的最大值。

边界

越界、海洋、已经访问的陆地都立即停止；全海洋网格答案为 0。

复杂度

每个格子至多访问一次，时间 O(mn)，递归栈或队列最坏 O(mn)。

替代方案

可用 BFS 避免深递归，或用并查集合并相邻陆地。

常见错误

漏掉四个方向、没有标记访问，或将对角线误当作相连。

追问

若不能修改原网格，如何维护访问状态？如何求岛屿数量？

# Python
class Solution:
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        def dfs(r, c):
            if not (0 <= r < len(grid) and 0 <= c < len(grid[0])) or not grid[r][c]: return 0
            grid[r][c] = 0
            return 1 + dfs(r+1,c) + dfs(r-1,c) + dfs(r,c+1) + dfs(r,c-1)
        return max((dfs(r,c) for r in range(len(grid)) for c in range(len(grid[0]))), default=0)
