01 / CHALLENGE

把一串数字，恰好分成 k 段

给定只包含数字 1–9 的字符串 s，以及整数 k、minLength。请统计将整个字符串切成恰好 k 段的方案数，要求各段连续、互不重叠，且没有遗漏字符。

  1. 每段长度至少为 minLength。
  2. 每段首位是质数数字：2、3、5、7。
  3. 每段末位是非质数数字：1、4、6、8、9。

返回方案数对 1,000,000,007 取余的结果。这里判断的是首尾数字的属性，不是整段表示的数是否为质数。

输入与返回

beautifulPartitions(s, k, minLength) → integer

  • s：待分割字符串。
  • k：要求的段数。
  • minLength：每段的长度下界。

完整约束

1 ≤ k, minLength ≤ s.length ≤ 1000

s 中每个字符均为 '1' 到 '9'。

包含逐步演示、证明与四语言代码。

核心洞察：把切点当作状态

用前缀长度表示位置：切点 t 位于 s[t-1] 与 s[t] 之间。内部切点必须满足“左边非质数、右边质数”。首尾位置 0、n 作为边界；先确保整串首位为质数、末位为非质数。

单字符不可能同时以质数开头、以非质数结尾，所以有效最短长度为 L = max(2, minLength)。若 k × L > n，直接返回 0。

cut[0] = cut[n] = true cut[t] = !prime(s[t-1]) && prime(s[t]) （0 < t < n） dp[p][j]：把前 j 个字符分成 p 段，且 j 是合法切点的方案数。 dp[0][0] = 1，其余初始为 0。 dp[p][j] = Σ dp[p-1][t]，其中 cut[t] 且 0 ≤ t ≤ j-L （仅当 cut[j] 为真，否则为 0）

固定段数 p，让右端点 j 从左到右移动。每次只新纳入 t = j-L 这一个起点，累加它在上一层的计数。这个累加器就是前缀和，省去了逐一枚举所有左端点。

完整过程

  1. 检查整串首尾及总长度；计算 L 和全部 cut。
  2. 准备上一层数组 prev，只令 prev[0] = 1。
  3. 对段数 p = 1…k，新建全零 curr，累加器 sum = 0。
  4. 对 j = 1…n，若 t = j-L ≥ 0 且 cut[t] 合法，将 prev[t] 加入 sum 并取模。
  5. 若 cut[j] 合法，将 sum 写入 curr[j]；不合法则保留 0。注意无论 j 能否作为切点，都要先更新累加器。
  6. 完成一层后令 prev = curr。最终返回 prev[n]。

示例 1 的合法切点是 0、4、7、9、11。第一层可到达 4、7、9、11，计数各为 1；第二层在 7、9、11 的计数为 1、2、3；第三层在 11 汇总来自切点 7 和 9 的计数，即 1 + 2 = 3。

正确性说明

  1. 切点条件必要且充分。内部切口左侧是上一段末位、右侧是下一段首位，因而必须且只需满足非质数到质数的变化。预检查保证全串两端同样满足要求。
  2. 状态转移不重不漏。一个 p 段分割有唯一的最后一段起点 t。删去最后一段，得到前 t 个字符的一个 p−1 段方案，且 j−t ≥ L。反之，任何这样的前缀方案都能接上合法末段 s[t:j]，形成唯一的 p 段方案。
  3. 累加器保持精确范围。处理 j 之前保留此前所有合法起点的上一层计数；加入新起点 j−L 后，恰好包含所有 t ≤ j−L，没有遗漏，也没有重复加入。
  4. 归纳得出结论。空前缀分成 0 段的方案数为 1。由上述双向对应，每一层状态均正确。因此第 k 层前缀 n 的计数就是答案，逐次取模保持计数的模值。

边界与常见错误

  • minLength = 1：有效段仍至少 2 位；不要把质数单字符作为完整一段。
  • k = 1：长度足够且首尾满足要求时，整串就是唯一方案；中间数字无限制。
  • 首位非质数或末位质数：答案为 0；数字 1 是非质数。
  • 只用“右边是质数”判切点会遗漏左边条件。
  • 累计范围包含 t = j-L；漏掉等号会排除恰好满足长度的段。
  • 不能在同一数组里从左往右覆盖上一层，否则可能重复使用本层状态。
  • 每层必须清空累加器。所有加法及时取模；不要相乘大量计数再取模。

复杂度与替代方案

时间 O(k·n)，额外空间 O(n)。预处理为 O(n)，每层扫描 n 个位置；两个滚动数组及切点数组均为线性空间。

  • 朴素动态规划：对每个状态枚举末段起点，O(k·n²) 时间、O(n) 滚动空间，容易推导但不适合最大输入。
  • 记忆化搜索：缓存“起点、剩余段数”，逐一试下个切点；直接实现最坏仍为 O(k·n²)，且有递归栈成本。
  • 压缩合法切点：若只有 m 个合法切点，可用双指针累加满足长度条件的前态，达到 O(n+k·m) 时间、O(m) 空间；本页保留按原位置扫描的简单写法。
  • 贪心选最长或最短一段只能找到某个方案，不能统计全部方案。

面试追问

  • 如果还要求每段长度不超过 R？把前态求和范围改为 j−R ≤ t ≤ j−L；用滑动窗口加入右侧新项、移除左侧过期项，并处理取模后的负数。
  • 如果要输出一个实际分割？另存可达性和前驱，沿前驱回溯；不要用取模计数是否为零判断可达性，因为正计数也可能模后为零。
  • 为什么中间出现质数或非质数都可以？条件仅约束每段端点，内部字符无需逐个过滤。
  • 能否进一步剪枝？每层只考虑 pL ≤ j ≤ n−(k−p)L；本页全范围扫描更直观，阶数相同。

Java

class Solution {
    private static final int MOD = 1_000_000_007;

    private boolean prime(char c) {
        return c == '2' || c == '3' || c == '5' || c == '7';
    }

    public int beautifulPartitions(String s, int k, int minLength) {
        int n = s.length(), len = Math.max(2, minLength);
        if (!prime(s.charAt(0)) || prime(s.charAt(n - 1)) || k * len > n) {
            return 0;
        }
        boolean[] cut = new boolean[n + 1];
        cut[0] = cut[n] = true;
        for (int t = 1; t < n; t++) {
            cut[t] = !prime(s.charAt(t - 1)) && prime(s.charAt(t));
        }
        int[] prev = new int[n + 1];
        prev[0] = 1;
        for (int p = 1; p <= k; p++) {
            int[] curr = new int[n + 1];
            long sum = 0;
            for (int j = 1; j <= n; j++) {
                int t = j - len;
                if (t >= 0 && cut[t]) sum = (sum + prev[t]) % MOD;
                if (cut[j]) curr[j] = (int) sum;
            }
            prev = curr;
        }
        return prev[n];
    }
}

class Solution:
    def beautifulPartitions(self, s: str, k: int, minLength: int) -> int:
        mod = 10**9 + 7
        n, length = len(s), max(2, minLength)
        prime = set("2357")
        if s[0] not in prime or s[-1] in prime or k * length > n:
            return 0
        cut = [False] * (n + 1)
        cut[0] = cut[n] = True
        for t in range(1, n):
            cut[t] = s[t - 1] not in prime and s[t] in prime
        prev = [0] * (n + 1)
        prev[0] = 1
        for _ in range(k):
            curr = [0] * (n + 1)
            total = 0
            for j in range(1, n + 1):
                t = j - length
                if t >= 0 and cut[t]:
                    total = (total + prev[t]) % mod
                if cut[j]:
                    curr[j] = total
            prev = curr
        return prev[n]

C++

#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
    bool prime(char c) {
        return c == '2' || c == '3' || c == '5' || c == '7';
    }
public:
    int beautifulPartitions(string s, int k, int minLength) {
        const int MOD = 1000000007;
        int n = static_cast<int>(s.size());
        int len = max(2, minLength);
        if (!prime(s[0]) || prime(s[n - 1]) || k * len > n) return 0;
        vector<bool> cut(n + 1, false);
        cut[0] = cut[n] = true;
        for (int t = 1; t < n; ++t) {
            cut[t] = !prime(s[t - 1]) && prime(s[t]);
        }
        vector<int> prev(n + 1, 0);
        prev[0] = 1;
        for (int p = 1; p <= k; ++p) {
            vector<int> curr(n + 1, 0);
            long long sum = 0;
            for (int j = 1; j <= n; ++j) {
                int t = j - len;
                if (t >= 0 && cut[t]) sum = (sum + prev[t]) % MOD;
                if (cut[j]) curr[j] = static_cast<int>(sum);
            }
            prev.swap(curr);
        }
        return prev[n];
    }
};
