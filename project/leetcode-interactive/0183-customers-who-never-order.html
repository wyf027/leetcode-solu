    Solution unlocked

    相关 NOT EXISTS

    对每位客户，只要找不到 Orders.customerId = Customers.id 的行，就保留。

    MySQL 主提交

    SELECT c.name AS Customers
FROM Customers AS c
WHERE NOT EXISTS (
    SELECT 1
    FROM Orders AS o
    WHERE o.customerId = c.id
);

    EXISTS 只关心是否有匹配行，子查询写 SELECT 1 即可。重复订单不会改变真假；Orders 为空时所有客户都保留。

    NOT EXISTS、LEFT JOIN 与 NOT IN

    • LEFT JOIN ... WHERE o.id IS NULL 同样表达反连接，检查非空主键 o.id 最清晰。
    • NOT IN 若子查询出现 NULL，会因三值逻辑让比较变成 UNKNOWN，可能错误地返回空集。
    • NOT EXISTS 对 NULL 更稳健，也是主线选择。

    四种官方 SQL 方言

    LEFT JOIN 与 Pandas

    SELECT c.name AS Customers
FROM Customers c
LEFT JOIN Orders o ON o.customerId = c.id
WHERE o.id IS NULL;

    官方 Pandas 可对两个 DataFrame 做 left merge 并使用 indicator=True，保留 left_only 行。

    Java / JavaScript / Python / C++ 语义参考

    本题在 LeetCode 上的正式提交语言是 SQL 或 Pandas；以下四份代码仅用于在内存数组上复现“客户全集减去已下单客户集合”的同一语义，不伪称可提交。

    Java · 本地语义参考
    import java.util.*;

class NeverOrderReference {
    static List<String> solve(List<String> customers,
                              List<Integer> orderCustomerIds) {
        Set<Integer> ordered = new HashSet<>();
        for (Integer id : orderCustomerIds) {
            if (id != null) ordered.add(id);
        }
        List<String> answer = new ArrayList<>();
        for (int i = 0; i < customers.size(); i++) {
            if (!ordered.contains(i + 1)) answer.add(customers.get(i));
        }
        return answer;
    }
}
    JavaScript · 本地语义参考
    function customersWhoNeverOrder(customers, orderCustomerIds) {
  const ordered = new Set(orderCustomerIds.filter((id) => id !== null));
  return customers.filter((_, index) => !ordered.has(index + 1));
}
    Python · 本地语义参考
    from typing import List, Optional

def customers_who_never_order(
    customers: List[str], order_customer_ids: List[Optional[int]]
) -> List[str]:
    ordered = {customer_id for customer_id in order_customer_ids if customer_id is not None}
    return [name for index, name in enumerate(customers, 1) if index not in ordered]
    C++ · 本地语义参考
    #include <optional>
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

vector<string> customersWhoNeverOrder(
    const vector<string>& customers,
    const vector<optional<int>>& orderCustomerIds) {
    unordered_set<int> ordered;
    for (const auto& id : orderCustomerIds) {
        if (id.has_value()) ordered.insert(*id);
    }
    vector<string> answer;
    for (int i = 0; i < static_cast<int>(customers.size()); ++i) {
        if (!ordered.count(i + 1)) answer.push_back(customers[i]);
    }
    return answer;
}
