判断根结点是否等于子结点之和

Root Equals Sum of Children

三个结点，一次判断。先理解输入，再亲手观察数据如何流动。

LeetCode 官方题目 ↗

01 / 题目

给定二叉树的根结点 root，树恰好包含三个结点：根结点、左子结点和右子结点。当根结点的值与左右两个子结点值的和相等时，返回布尔值 true；否则返回 false。

参数：root: TreeNode；返回：boolean。示例中的数组是树的层序表示，提交函数接收的是结点对象。

  • 树只包含根结点及其左、右两个子结点，三者都存在。
  • 每个结点的值均为整数，-100 ≤ Node.val ≤ 100。

官方示例 1

输入：root = [10,4,6]
输出：true

根值为 10，左右子结点值为 4、6。10 等于 4 + 6，故返回 true。

官方示例 2

输入：root = [5,3,1]
输出：false

根值为 5，左右子结点值为 3、1。5 不等于 3 + 1，故返回 false。

04 / 独立题解

完成思考后，展开推导与四种语言实现。

核心洞察

树的结构已经固定，左右子结点必定存在。直接读取三个值，计算两个子值的和，再与根值比较即可；无需遍历或递归。

完整过程

  1. 读取 root.val、root.left.val、root.right.val。
  2. 计算 sum = root.left.val + root.right.val。
  3. 返回 root.val == sum 的布尔结果；JavaScript 使用严格相等 ===。

以 root = [10,4,6] 为例：读出根值 10，子值相加得到 10，比较相等，返回 true。以 root = [5,3,1] 为例：子值相加为 4，与根值 5 不同，返回 false。

正确性

设根值为 r，两个子值为 l、q。算法计算 s = l + q，并且仅在 r = s 时返回 true。这与题目要求的 r = l + q 完全一致。因此满足条件时一定返回 true，不满足时一定返回 false，覆盖所有合法输入。

边界与复杂度

零、负数、正负混合都按普通整数加法处理。子值之和范围为 [-200,200]，在四种语言的这里所用数值类型中都可准确表示。合法输入不会出现空根或缺失子结点。时间复杂度 O(1)，额外空间复杂度 O(1)。

替代方案

可以先保存两个子值之和再比较，可读性略有不同，但复杂度相同。也可用 if/else 返回 true 或 false，不过直接返回比较表达式更简洁。递归和队列没有必要；若将来要求检查任意树的所有非叶结点，才需要遍历，并先定义缺失子结点的处理规则。

常见错误

  • 把 root 当作数组读取；官方函数实际接收 TreeNode。
  • 比较结点对象而非 .val，或把根值也加到“子值和”中。
  • 返回数值和或字符串，而不是布尔值。
  • 将这里的三结点保证套用到任意二叉树，导致访问不存在的子结点。

面试追问

如果树有任意多个结点？只判断根与直接孩子仍是常数时间；若判断所有非叶结点，则用 DFS/BFS，时间 O(n)，空间取决于递归高度或队列宽度。如果值扩大到接近整型上限？Java/C++ 应在加法前提升到更宽的类型，JavaScript 超出安全整数范围时使用 BigInt；Python 整数可自动扩展。

四语言提交代码

下列实现使用官方 checkTree 签名。TreeNode 由 LeetCode 提供，注释展示其定义供阅读；本地运行时需自行构造树。所有代码均待补验证。

Java

/**
 * TreeNode 由平台提供：
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean checkTree(TreeNode root) {
        return root.val == root.left.val + root.right.val;
    }
}

JavaScript

/**
 * TreeNode 由平台提供：
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {boolean}
 */
var checkTree = function(root) {
    return root.val === root.left.val + root.right.val;
};

Python 3

from typing import Optional

# TreeNode 由平台提供：
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def checkTree(self, root: Optional['TreeNode']) -> bool:
        return root.val == root.left.val + root.right.val

C++

/**
 * TreeNode 由平台提供：
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool checkTree(TreeNode* root) {
        return root->val == root->left->val + root->right->val;
    }
};
