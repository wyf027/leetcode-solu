题意

难度：简单

目标

给定一棵二叉搜索树 root，直接修改原树：每个节点的 left 必须为空，right 指向升序链表中的下一个节点。返回链表头节点。

转换必须原址完成；不能用复制节点构造一条新链表。

节点值按 0 到 6 升序排列，每个 null 都表示对应节点的 left 已清空。

题解

核心洞察、完整过程、边界、复杂度、取舍、追问、错误与四语言代码默认全部隐藏。

核心洞察

BST 的中序就是最终链表顺序

中序遍历二叉搜索树会按非递减顺序访问节点。维护哨兵节点 dummy 与尾指针 tail：每弹出一个节点，就清空它的 left，让 tail.right = node，再移动 tail。这里只新建辅助哨兵，不新建任何输出节点。

为什么用显式栈

官方提示鼓励递归，但节点上限是 100,000。完全退化的 BST 会让递归深度达到 O(n)，可能溢出语言调用栈。显式栈仍是同一中序思想，却能稳定覆盖深树。

完整过程

  1. 1. 当前节点非空时持续压栈并走向 left。
  2. 2. 走到空指针后弹出栈顶，它就是下一小节点。
  3. 3. 保存其原 right，清空 left，再接到 tail.right。
  4. 4. tail 前移，继续处理保存下来的右子树。

边界

  • 空树返回 null。
  • 单节点只需清空 left。
  • 全左树会把顺序完全反转。
  • 全右树保持节点次序。

复杂度

每个节点入栈、出栈各一次，时间 O(n)。显式栈最多保存树高个节点，辅助空间 O(h)；退化树最坏 O(n)。

替代方案

递归写法更短，但深树有栈风险；Morris 中序能把额外空间降到 O(1)，却需要临时穿线并更容易写错，面试时应在追问空间优化后再使用。

面试追问

  • 如何做到 O(1) 额外空间？
  • 如何验证节点身份没有被复制？
  • 允许重复值时顺序是否稳定？

常见错误

  • • 创建新 TreeNode 复制值，违反原址转换。
  • • 忘记把 node.left 设为空，结果仍是一棵树。
  • • 先覆盖 node.right 再保存右子树，导致后续节点丢失。
  • • 返回 tail 而不是 dummy.right，只得到链表末尾。

class Solution {
    public TreeNode convertBiNode(TreeNode root) {
        TreeNode dummy = new TreeNode(0);
        TreeNode tail = dummy;
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode current = root;

        while (current != null || !stack.isEmpty()) {
            while (current != null) {
                stack.push(current);
                current = current.left;
            }

            current = stack.pop();
            TreeNode right = current.right;
            current.left = null;
            tail.right = current;
            tail = current;
            current = right;
        }
        return dummy.right;
    }
}
