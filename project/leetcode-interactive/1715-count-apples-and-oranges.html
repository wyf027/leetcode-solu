苹果和橘子的个数

盒子里装着水果，有些盒子还嵌着一只小箱子。汇总所有盒子实际包含的苹果与橘子，并分别给出总数。

Problem

先把关系读清楚

Count Apples and Oranges

题意转述

Boxes 记录每只盒子自身的苹果、橘子数量；盒子的 chest_id 可以为空，也可以指向 Chests 中的一只小箱子。小箱子中的水果也属于该盒子的实际内容。

编写查询，返回一行：apple_count 和 orange_count，分别表示全部盒子及其关联小箱子的水果总数。

关键语义：无小箱子的盒子仍须计入；未被任何盒子关联的 Chests 记录不单独计入。

约束与字段定义

  • Boxes.box_id 是 Boxes 主键。
  • Chests.chest_id 是 Chests 主键。
  • Boxes.chest_id 是指向 Chests 的外键，可为 NULL。
  • 两表的水果数量字段均为 INT。
  • 每只盒子可以包含一只小箱子；结果列名必须为 apple_count、orange_count。

Solution

保留盒子，再补上小箱子

核心洞察

统计主体始终是 Boxes：每个盒子必须出现，即使没有小箱子。因此从 Boxes 出发左连接；连接不到的计数补 0，再对“盒子值 + 小箱子值”聚合。

一句话模型

总水果 = Σ（每只盒子自身水果 + 它所关联小箱子的水果或 0）

完整过程

  1. 从 Boxes 出发，以 chest_id 左连接 Chests。
  2. 左连接保留 chest_id IS NULL 的盒子。
  3. 用 IFNULL(value, 0) 将缺失的小箱子计数当作零。
  4. 分别汇总苹果、橘子表达式，并设置题目指定列名。

正确性

对任意盒子 b，左连接保留一条以 b 为主体的记录。若 b 关联小箱子 c，表达式计入 b 与 c；若未关联，补零后只计入 b。故每个盒子的实际水果恰被计入一次，所有行求和即为目标总数。

复杂度与边界

设盒子数 n、箱子数 m。常见哈希连接时间 O(n + m)、空间 O(m)；有主键索引时执行器也可按 n 次索引查找。

边界：空 chest_id、未引用箱子、零计数、同一 chest_id 被多行 Boxes 引用。

官方可提交方案 · MySQL

SELECT
    SUM(b.apple_count + IFNULL(c.apple_count, 0)) AS apple_count,
    SUM(b.orange_count + IFNULL(c.orange_count, 0)) AS orange_count
FROM Boxes AS b
LEFT JOIN Chests AS c
    ON b.chest_id = c.chest_id;

import java.util.*;
public class Main {
  record Box(int id, Integer chestId, long apples, long oranges) {}

  static long[] count(List<Box> boxes, List<Chest> chests) {
    Map<Integer, Chest> map = new HashMap<>();
    for (Chest c : chests) map.put(c.id(), c);
    long a = 0, o = 0;
    for (Box b : boxes) {
      Chest c = b.chestId() == null ? null : map.get(b.chestId());
      a += b.apples() + (c == null ? 0 : c.apples());

function countFruits(boxes, chests) {
  const map = new Map(chests.map(c => [c.chestId, c]));
  let apples = 0, oranges = 0;
  for (const b of boxes) {

    apples += b.apples + (c?.apples ?? 0);
    oranges += b.oranges + (c?.oranges ?? 0);
  }
  return { apple_count: apples, orange_count: oranges };
}

#include <iostream>
#include <optional>
#include <unordered_map>
#include <vector>
using namespace std;
struct Box { int id; optional<int> chestId; long long apples, oranges; };
struct Chest { int id; long long apples, oranges; };
pair<long long,long long> countFruits(
  const vector<Box>& boxes, const vector<Chest>& chests) {
  unordered_map<int,Chest> map;
  for (const auto& c : chests) map.emplace(c.id, c);
  long long a = 0, o = 0;
  for (const auto& b : boxes) {
    a += b.apples; o += b.oranges;
    if (b.chestId && map.count(*b.chestId)) {
      const auto& c = map.at(*b.chestId);
      a += c.apples; o += c.oranges;
    }
  }
  return {a, o};
}

替代方案

可分别聚合 Boxes 与被引用的 Chests 再相加，但通常需要子查询或多次聚合。内连接不适合，因为它会丢失没有小箱子的盒子。

面试追问

  • 如果一只小箱子全局只能计一次，怎样去重？
  • 空表时希望返回 0，最外层如何处理？
  • 若一只盒子可含多只小箱子，如何设计关系表？

常见错误

  • 误用 INNER JOIN，漏掉无小箱子的盒子。
  • 右表字段不补零，让 NULL 污染加法。
  • 从 Chests 出发，把未使用的小箱子也统计进去。
  • 擅自对 chest_id 去重，改变按 Boxes 行贡献的语义。
