题号 419MEDIUM数组矩阵深度优先搜索非付费题

任务简报

给定一个由战舰格与空格组成的矩阵，统计棋盘上的战舰数量。

题意

给你一个 m × n 的字符矩阵 board。每个单元格要么是战舰的一部分 'X'，要么是空位 '.'。请返回棋盘上的战舰数量。

每艘战舰只能水平或垂直放置，形状为 1 × k 或 k × 1，其中 k ≥ 1。不同战舰不会在水平或垂直方向直接相邻。

函数参数：countBattleships(board: character[][]) → integer

进阶：尝试只扫描一次、使用 O(1) 额外空间，并且不修改原棋盘。
约束
  • m == board.length
  • n == board[i].length
  • 1 ≤ m, n ≤ 200
  • board[i][j] 为 '.' 或 'X'
官方示例 1

输入

board = [["X",".",".","X"],
         [".",".",".","X"],
         [".",".",".","X"]]

输出

2
官方示例 2

输入

board = [["."]]

输出

0

一次扫描：只数战舰起点

把一艘连续战舰唯一映射到它在行优先顺序下最靠前的格子。

核心洞察

扫描到 'X' 时，如果它的上方也是 'X'，它属于一艘竖直战舰的后续部分；如果它的左侧也是 'X'，它属于一艘水平战舰的后续部分。只有上方和左侧都不是 'X' 的战舰格，才是一艘战舰唯一的起点，计数加一。

判定式：board[r][c] == 'X'，且 r == 0 || board[r-1][c] == '.'，且 c == 0 || board[r][c-1] == '.'。

完整过程

  1. 初始化答案 count = 0。
  2. 按行从左到右遍历每个单元格。
  3. 跳过空格 '.'。
  4. 对 'X' 检查上方与左侧；越界视为空。
  5. 两处都没有战舰格时，将 count 加一。
  6. 扫描结束后返回 count。

边界处理

  • 左上角：上方和左侧都越界，若为 X 就是起点。
  • 首行：只需要检查左侧。
  • 首列：只需要检查上方。
  • 单格战舰：天然满足起点条件，只计一次。
  • 全空棋盘：没有任何格触发计数，答案为 0。
  • 输入前提：依赖题目保证战舰合法且不同战舰不直接相邻。

正确性证明

引理 1：每艘战舰恰有一个格满足判定。水平战舰最左格的左侧不是 X，且因战舰不相邻、不能弯折，其上方不是 X；其余格左侧均为 X。竖直战舰同理：最上格满足判定，其余格上方均为 X。单格战舰也只有自身满足。
引理 2：每个被计数的格都对应一艘不同战舰。被计数格本身是 X，因此属于某艘战舰；引理 1 表明同一艘战舰不会产生第二个被计数格。
结论。算法在战舰集合与被计数格集合之间建立一一对应，因此最终计数等于棋盘上的战舰数量。

时间复杂度

O(mn)。每个格子只被访问一次，邻格检查为常数时间。

空间复杂度

O(1)。只维护循环变量与计数器，不修改棋盘。

算法特征

一次扫描；无递归；无需访问标记；满足官方进阶要求。

替代方案

DFS / BFS 连通分量：遇到未访问的 X 就搜索整艘战舰，答案加一。思路通用，甚至能处理不规则连通块，但需要 O(mn) 访问标记，或必须修改棋盘；递归 DFS 还可能产生较深调用栈。

原地淹没：搜索后把 X 改为点，可省访问数组，但违反“不修改 board”的进阶要求。

为什么起点计数更合适：题目保证战舰笔直且互不相邻，局部检查已经足够识别每艘战舰的唯一代表。

class Solution {
    public int countBattleships(char[][] board) {
        int count = 0;

        for (int row = 0; row < board.length; row++) {
            for (int col = 0; col < board[0].length; col++) {
                if (board[row][col] != 'X') {
                    continue;
                }

                boolean hasTop = row > 0 && board[row - 1][col] == 'X';
                boolean hasLeft = col > 0 && board[row][col - 1] == 'X';

                if (!hasTop && !hasLeft) {
                    count++;
                }
            }
        }
        return count;
    }
}

面试追问

  • 如果战舰允许弯折，局部起点判定为什么失效？该如何改用连通分量？
  • 如果输入按行流式到达，能否只保留上一行完成计数？
  • 如果不同战舰允许对角接触，算法是否受影响？为什么？
  • 如果允许水平相邻但属于不同战舰，还需要哪些额外信息才能区分？
  • 并行扫描矩阵时，怎样合并分块边界上的结果？

常见错误

  • 每遇到一个 X 就计数，导致长战舰被重复计算。
  • 只检查上方或只检查左侧，遗漏另一种方向的延续格。
  • 首行、首列直接访问负下标，造成越界。
  • 使用 DFS 却忘记访问标记，出现重复遍历甚至无限递归。
  • 把对角线邻格也纳入判定；题目只按水平和垂直定义战舰。
  • 为了省空间修改 board，却忽略了进阶要求中的“不修改”。
