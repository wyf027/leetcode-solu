LCR 034 EASY 自定义排序

验证外星语词典

给定一个由小写字母组成的单词列表，以及外星语言的字母顺序，判断这些单词是否已经按该顺序字典序排列。

题目与规则

相邻两个单词才需要比较：从左到右找到第一对不同字符，再由外星字母表决定大小；若前缀完全相同，则较短单词在前。

例 1

["hello","leetcode"]

顺序正确

前缀陷阱

["apple","app"]

顺序错误

核心洞察

先把 order 映射成排名表。之后字符比较就变成常数时间；整个列表只需检查 n - 1 对相邻词。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

交互验证台

每行一个单词；只使用 a–z。

准备就绪：输入数据后点击“开始验证”。

解题过程

  1. 1记录每个字符在 order 中的下标。
  2. 2逐对比较 words[i] 与 words[i + 1]。
  3. 3首个不同字符决定顺序；找不到则检查长度。

边界、复杂度与替代方案

  • 前缀："apple" 不能排在 "app" 前。
  • 复杂度：设所有单词字符数总和为 S，时间 O(S + 26)，额外空间 O(26)。
  • 替代：可为比较器直接查 order.indexOf，但每次查找多为线性，排名表更清晰稳定。

四语言参考实现

统一采用“排名数组 + 相邻比较”。

面试追问与常见错误

可以追问

  • 若字母表不完整，如何定义未知字符？
  • 如何设计多个自定义字母表的批量校验？
  • 能否返回第一个违反顺序的相邻位置？

易错点

  • 只比较首字母，忽略后续字符。
  • 漏掉“长单词在其前缀之前”的反例。
  • 比较完成后仍继续扫描，而非在首个差异处返回。

伪代码：建立 rank；对每个相邻对，逐字符比较。若发现 rank(a) > rank(b) 则失败；若公共前缀结束且左词更长则失败；否则继续。全部通过即为真。
