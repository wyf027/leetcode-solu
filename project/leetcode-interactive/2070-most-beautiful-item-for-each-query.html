LeetCode 2070

每一个查询的
最大美丽值

Most Beautiful Item for Each Query

给定预算，挑出买得起的物品中最美的那一个。

01 / Problem

预算是上限，美丽值是目标

items[i] = [priceᵢ, beautyᵢ] 表示第 i 个物品的价格与美丽值。对每个 queries[j]，从所有价格小于等于该预算的物品中，返回最大的美丽值。没有物品符合条件时，返回 0。

返回与 queries 等长、顺序相同的答案数组。查询彼此独立，物品不会被消耗；不需要购买组合，也不计算美丽值之和。

官方题目 ↗

参数与约束

  • items：二维整数数组。
  • queries：下标从 0 开始的整数数组。
  • 1 ≤ items.length, queries.length ≤ 10⁵
  • items[i].length == 2
  • 1 ≤ priceᵢ, beautyᵢ, queries[j] ≤ 10⁹

价格、美丽值均可重复。等于预算的物品也可以买。

排序，把预算变成一条边界

核心洞察：按价格从低到高排序后，预算 q 能买的物品恰好构成一个前缀。提前保存每个前缀的最大美丽值，每次查询只需找到这个前缀的右边界。

Interactive / Budget frontier

预算边界实验台

先观察前缀最大值逐格形成，再观察半开区间 [L, R) 收缩。绿色表示已处理的前缀或可负担物品，金色边框标出 mid；灰色表示当前二分候选区间外的物品。R 可以等于 n，位于末尾之外。

输入仅用于演示。修改后点击“应用输入”；重置返回当前输入的第一步。

按原查询顺序填回答案

演示是算法状态推演，不计入测试实际输出。支持 Tab 聚焦、Enter / 空格激活按钮。系统启用减少动态效果时，自动播放使用较慢节奏。

完整过程

  1. 按价格升序排列 items，价格相同的物品无需去重。
  2. 建立数组 best，令 best[i] 为下标 0…i 的最大美丽值。
  3. 对每个 q，在 [0,n) 中二分第一个价格 > q 的位置 L。
  4. 若 L=0，答案为 0；否则答案为 best[L−1]。按 queries 原顺序输出。

示例 1 的排序价格是 [1,2,3,3,5]，前缀最大值是 [2,4,4,5,6]。预算 3 的上界下标为 4，答案是 best[3]=5。

为什么一定正确？

前缀不变式：处理 i 前，best[i−1] 已是前 i 件的最大美丽值；将它与当前美丽值取最大，就得到前 i+1 件的最大值。初始最大值 0 合法，因为美丽值均为正。

二分不变式：下标小于 L 的价格都 ≤ q，下标大于等于 R 的价格都 > q。若 price[mid] ≤ q，令 L=mid+1；否则令 R=mid。循环结束 L=R，正是第一个价格 > q 的位置。

因此所有可选物品恰为 [0,L)，读取该前缀的最大美丽值即可；空前缀返回 0。

复杂度与边界

令 n 为物品数，m 为查询数。排序 O(n log n)，前缀预处理 O(n)，每个查询 O(log n)，总时间 O(n log n + m log n)。

best 占 O(n)，返回数组占 O(m)；包含输出的总额外空间为 O(n+m)，各语言排序额外空间不超过该量级。以下实现均会重排传入的 items。

预算小于最小价格 → 0；预算覆盖全部 → best[n−1]；重复价格全部纳入 ≤ 边界；查询无需排序；只有一个物品也使用同一流程。

替代方案

离线排序 + 双指针：把查询携带原下标按预算排序，让物品指针只向右走并更新最大美丽值，最后按原下标写答案。时间 O(n log n + m log m)，需要保存查询下标。

暴力扫描：每个查询扫描 n 件物品，时间 O(nm)，大规模输入不适用。

压缩记录：只保留美丽值前缀纪录上升的价格拐点，可缩短二分数组；同价更新必须完整处理。

常见错误

  • 只返回预算内最贵物品的美丽值；价格与美丽值没有单调关系。
  • 寻找第一个 ≥ q 的位置，漏掉恰好等于预算的物品。
  • 相同价格只保留任意一件，遗漏更大的美丽值。
  • L=0 时读取 best[L−1]。
  • JavaScript 使用默认字典序排序；应提供数值比较器。
  • 对查询排序后忘记还原输出顺序。

面试追问

查询持续到来？预处理一次，随后在线二分即可。

需要返回物品编号？前缀同时记录最大值对应的原始下标，并明确并列规则。

物品允许更新？静态前缀失效。可离散化价格，用支持前缀最大值查询的线段树；同价多物品还要维护该价格的最大值。

不允许修改输入？排序前复制 items。当前代码重排外层数组，不改写物品内的价格或美丽值。

Java

import java.util.Arrays;

class Solution {
    public int[] maximumBeauty(int[][] items, int[] queries) {
        Arrays.sort(items, (a, b) -> Integer.compare(a[0], b[0]));
        int n = items.length;
        int[] best = new int[n];
        int maxBeauty = 0;
        for (int i = 0; i < n; i++) {
            maxBeauty = Math.max(maxBeauty, items[i][1]);
            best[i] = maxBeauty;
        }
        int[] answer = new int[queries.length];
        for (int j = 0; j < queries.length; j++) {
            int left = 0, right = n;
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (items[mid][0] <= queries[j]) left = mid + 1;
                else right = mid;
            }
            answer[j] = left == 0 ? 0 : best[left - 1];
        }
        return answer;
    }
}

Python

from typing import List

class Solution:
    def maximumBeauty(self, items: List[List[int]], queries: List[int]) -> List[int]:
        items.sort(key=lambda item: item[0])
        n = len(items)
        best = [0] * n
        max_beauty = 0
        for i, (_, beauty) in enumerate(items):
            max_beauty = max(max_beauty, beauty)
            best[i] = max_beauty
        answer = []
        for q in queries:
            left, right = 0, n
            while left < right:
                mid = left + (right - left) // 2
                if items[mid][0] <= q:
                    left = mid + 1
                else:
                    right = mid
            answer.append(0 if left == 0 else best[left - 1])
        return answer

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> maximumBeauty(vector<vector<int>>& items,
                              vector<int>& queries) {
        sort(items.begin(), items.end(), [](const auto& a, const auto& b) {
            return a[0] < b[0];
        });
        int n = static_cast<int>(items.size());
        vector<int> best(n);
        int maxBeauty = 0;
        for (int i = 0; i < n; ++i) {
            maxBeauty = max(maxBeauty, items[i][1]);
            best[i] = maxBeauty;
        }
        vector<int> answer;
        answer.reserve(queries.size());
        for (int q : queries) {
            int left = 0, right = n;
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (items[mid][0] <= q) left = mid + 1;
                else right = mid;
            }
            answer.push_back(left == 0 ? 0 : best[left - 1]);
        }
        return answer;
    }
};
