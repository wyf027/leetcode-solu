Minimum Split Into Subarrays With GCD Greater Than One

把一串数字分成连续的几段，让每一段都保留大于 1 的共同因子。

01 / 题目

给定正整数数组 nums，将它划分为一个或多个非空、连续且互不重叠的子数组。每个元素必须恰好属于一段，每段所有元素的最大公约数（GCD）都必须严格大于 1。返回满足条件的最少子数组数量。

返回的是段数：分成 2 段时返回 2，虽然只切了 1 刀。不能重排、跳过或重复使用元素。

函数约定

minimumSplits(nums: integer[]) → integer

约束

  • 1 ≤ nums.length ≤ 2000
  • 2 ≤ nums[i] ≤ 10⁹

元数据提供题名、参数与样例输入；因付费题面字段为空，下述题意与约束据公开资料转述。来源：力扣原题、LeetCode Wiki 题面资料。

02 / 官方示例

示例 1

输入：nums = [12,6,3,14,8]
输出：2

可分为 [12,6,3] 与 [14,8]，两段 GCD 分别为 3 和 2；整个数组的 GCD 为 1，因此不能只分一段。

示例 2

输入：nums = [4,12,6,14]
输出：1

所有元素共有因子 2，整个数组就是一段合法子数组。

04 / 题解 · 让每段尽可能延伸

核心洞察

向一段追加元素后，新的 GCD 一定整除旧的 GCD，因此只会不变或减小。一旦降为 1，继续追加也不会恢复。维护整段的 GCD：能加入就加入；试算变成 1 时，在当前元素前结束上一段，以当前元素重新开段。

变量 g 记录当前段 GCD，count 记录段数。初始化 g = nums[0], count = 1，从下标 1 开始扫描。

完整过程

  1. 第一个元素 12 开段：段数 1，GCD 为 12。
  2. 加入 6：gcd(12, 6) = 6；加入 3：gcd(6, 3) = 3。
  3. 尝试加入 14：gcd(3, 14) = 1，必须结束当前段。以 14 开新段，段数 2，GCD 重置为 14。
  4. 加入 8：gcd(14, 8) = 2。扫描结束，返回 2。

正确性：贪心边界不会落后

首先，每次追加只在新 GCD 大于 1 时发生，新段的单元素又至少为 2，所以输出的每段都合法且恰好覆盖数组。

再比较任意合法划分与贪心划分。贪心第一段取从数组起点出发的最长合法前缀，因此结束位置不早于任意合法划分的第一段。假设贪心前 k−1 段已经覆盖得至少一样远：若它还没覆盖到另一划分第 k 段的结尾，则从贪心下一段起点到该结尾，是那一合法段的后缀，仍有大于 1 的公因子。贪心第 k 段至少能延伸到那里。

由归纳，任意划分用 k 段覆盖全数组时，贪心至多用 k 段也能覆盖。结合合法性，贪心段数最少。

复杂度

令 n 为数组长度、M 为最大元素。每个元素最多调用一次欧几里得算法，时间上界 O(n log M)，迭代 GCD 的额外空间为 O(1)。页面为展示分组创建 DOM 节点，不计入提交算法空间。

边界与常见错误

  • 数组非空且每个数至少为 2，单元素必然合法；不存在无解情况。
  • 整体 GCD 大于 1 时返回 1；若相邻都互质，则返回 n。
  • 不能只看相邻两个数。[6,10,15] 的相邻 GCD 都大于 1，但整体 GCD 为 1。
  • 开新段后要把 g 重置为当前元素，不能留为 1 或漏掉该元素。
  • GCD 可以不变；“每次都严格下降”是错误说法。
  • 不要排序，不要把段数减 1；本题求的不是切刀次数。

替代方案

动态规划：令 dp[i] 为前 i 个元素最少段数，dp[0] = 0。枚举最后一段起点 j，若 gcd(nums[j…i−1]) > 1，则更新 dp[i] = min(dp[i], dp[j] + 1)。向左扩展最后一段时滚动维护 GCD，降为 1 即可停止。时间 O(n² log M)，空间 O(n)。适合扩展为每段带权代价的版本，本题使用贪心更直接。

面试追问

  • 如何返回分段位置？每次新开段时记录下标，结束后追加数组末端；存储 O(段数)。
  • 允许 nums[i] = 1 会怎样？含 1 的任何段 GCD 都是 1，整个划分无解，需要约定失败返回值。
  • 条件换为 GCD ≥ K 呢？若每个元素 ≥ K，同样具有向后扩展不可恢复和合法段后缀仍合法的性质，可沿用最长前缀证明。
  • 能流式处理吗？可以，只需当前段 GCD 与累计段数，不必保存原数组。

Java

class Solution {
    public int minimumSplits(int[] nums) {
        int count = 1, g = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int next = gcd(g, nums[i]);
            if (next == 1) {
                count++;
                g = nums[i];
            } else {
                g = next;
            }
        }
        return count;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }
}
