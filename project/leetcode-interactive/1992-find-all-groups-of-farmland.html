找到所有的农场组

Find All Groups of Farmland

从一张土地网格中，为每一组农场标出两个角。

先理解输入与坐标，再到页面底部展开题解和交互推演。

01 / 题目

给定从 0 开始索引的 m × n 二进制矩阵 land。0 是森林，1 是农场。每个农场组是一个全部由 1 构成的矩形；不同组之间不会上下左右相邻，但可以对角接触。

返回每组的 [r1, c1, r2, c2]：前两个数为左上角的行、列，后两个数为右下角的行、列，两个端点都包含在组内。左上格是 (0,0)，右下格是 (m-1,n-1)。组的返回顺序不限，没有农场则返回 []。

坐标始终按「行、列」排列；一格农场也构成一个矩形。

参数与约束

  • m == land.length
  • n == land[i].length
  • 1 ≤ m, n ≤ 300
  • land[i][j] 只能为 0 或 1。
  • 题目保证各农场组为矩形，不同组不四向相邻。

04 / 独立题解

含交互推演、证明及四语言完整代码。

核心洞察：只从左上角量边

某个 1 是组的左上角，当且仅当它的上方没有 1、左方也没有 1（越界视为没有）。只在这种格子启动边界搜索，其余格子跳过，因此不需要修改矩阵或维护 visited。

矩形保证让我们只量两条边：沿顶边向右找到末列，沿左边向下找到末行。组内其他格子由矩形性质保证填满；四向不相邻保证量边时不会跨入别的组。

完整过程与正确性
  1. 按行、列遍历所有格子，遇到 0 立即继续。
  2. 当前格上方或左方是 1 时，它不是左上角，继续扫描。
  3. 对左上角 (r,c)，令 bottom=r、right=c。只要右侧下一格是 1 就扩展 right，只要下方下一格是 1 就扩展 bottom。
  4. 加入 [r,c,bottom,right]，继续扫描；最终返回全部记录。


为什么不会漏组、重组或量错？
存在性：每个矩形都有唯一左上角。它的上方、左方既不属于本组，也不能属于别组，否则违反组间不四向相邻，因此会被识别。
唯一性：矩形内其他格子，只要不在最上行，其上方就是 1；在最上行却不在最左列，其左方就是 1。所以它们不能再次启动搜索。
边界准确：矩形的顶边连续到最右列、左边连续到最下行。再走一步必为 0 或越界，否则仍与该组连通，说明原边界尚未到达。两条边的终点恰好确定右下角。
因此每个真实农场组被准确记录一次，答案恰为所有组。


复杂度
外层扫描 O(mn)。设各组宽高为 w、h，额外搜索总成本为 Σ(w+h)，而对正整数宽高有 w+h ≤ 2wh；不同组互不重叠，Σwh ≤ mn。因此整体时间为 O(mn)。除返回值外，额外空间 O(1)；若计入 k 个输出矩形，空间为 O(k)。可视化保存步骤用于回退，不属于提交算法的空间开销。


边界与常见错误
  • 全为 0 返回 []；单个 1 的两端坐标相同。
  • 单行、单列和触边矩形都适用；先检查范围，再访问相邻格。
  • 上方、左方都必须没有 1。写成“任意一个没有”会重复记录边缘格子。
  • 右下角是最后一个 1 的下标，不是下一个 0 的下标；输出不是宽高。
  • 对角相邻不合并。题目只考虑四方向。
  • 不要一边清零一边用上方、左方判定左上角，清零会破坏判据。
  • 如果输入含 L 形连通块，两条边无法代表整块；本算法依赖题目矩形保证。


替代方案
BFS 或迭代 DFS 遍历每个四向连通块，更新最小、最大行列，再输出包围框。时间 O(mn)，visited 与队列/栈最坏 O(mn)。允许修改输入时可原地标记访问状态，但工作队列仍可能占用空间；递归 DFS 在大组上可能栈溢出。非矩形输入也可求包围框，但包围框并不等于真实土地形状。


面试追问
不能修改 land？当前角点法天然只读。如何解释嵌套 while 仍是线性？按每组面积摊还边长。没有矩形保证呢？转为连通块搜索，并先明确要返回包围框还是全部成员。改为八方向连通呢？对角组可能合并成非矩形，需更换遍历与输出语义。

Java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[][] findFarmland(int[][] land) {
        int m = land.length, n = land[0].length;
        List<int[]> answer = new ArrayList<>();
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (land[r][c] == 0) continue;
                if (r > 0 && land[r - 1][c] == 1) continue;
                if (c > 0 && land[r][c - 1] == 1) continue;
                int bottom = r, right = c;
                while (right + 1 < n && land[r][right + 1] == 1) right++;
                while (bottom + 1 < m && land[bottom + 1][c] == 1) bottom++;
                answer.add(new int[]{r, c, bottom, right});
            }
        }
        return answer.toArray(new int[answer.size()][]);
    }
}
