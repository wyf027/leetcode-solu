数据流中的中位数

设计 MedianFinder：数字会陆续到达，你需要随时给出当前有序列表的中间值。

设计数据结构 动态数据流 难度：困难

题意、示例与约束

中位数是有序整数列表的中间值。列表长度为偶数时，中位数是两个中间值的平均值。 数据结构需要支持 addNum(int num) 添加整数，以及 findMedian() 返回当前中位数。

题解：用两个堆守住中间边界

核心洞察

不需要让所有元素始终有序，只需持续维护中间边界。用最大堆 lower 保存较小的一半，用最小堆 upper 保存较大的一半；堆顶正好是中位数所需的一个或两个边界值。

完整过程与不变量

  1. 若 lower 为空，或新数不大于 lower 的堆顶，就先放入 lower；否则放入 upper。
  2. 若 lower 比 upper 多两个元素，把 lower 堆顶移到 upper。
  3. 若 upper 的元素更多，把 upper 堆顶移到 lower。
  4. 始终保持所有 lower 元素不大于所有 upper 元素；两边数量相等，或 lower 恰好多一个。

边界情况

覆盖首个数、重复值、全负数、严格升序或降序、奇偶长度交替，以及两个 32 位极值同时出现。题目保证调用 findMedian 前已有数据。

复杂度

每次插入只进行常数次堆操作，时间复杂度 O(log n)；查询只读堆顶，为 O(1)；两个堆共保存 n 个元素，空间 O(n)。

真正的替代方案

维护始终有序的数组：二分找到位置，再移动元素完成插入。查询仍为 O(1)，但插入为 O(n)。它适合插入很少、查询很多，且希望直接保留完整有序序列的场景。

面试追问

  • 滑动窗口需要删除过期元素：两个堆配合延迟删除表，并维护逻辑大小。
  • 需要任意分位数：可使用带子树计数的平衡树，或坐标压缩后的树状数组。
  • 值域很窄且固定：用计数桶维护频次，再累计到中间位置。

常见错误

  • 把最大堆与最小堆方向写反，或再平衡后让右侧元素更多。
  • 只调整数量，却破坏跨堆的大小关系。
  • Java/C++ 先计算 lower.top() + upper.top() 再除以 2，两个 int 可能在转换为浮点数前溢出。
  • 实验室输入错误后仍显示上一轮的中位数或继续自动播放。

import java.util.Collections;
import java.util.PriorityQueue;

class MedianFinder {
    private final PriorityQueue<Integer> lower =
            new PriorityQueue<>(Collections.reverseOrder());
    private final PriorityQueue<Integer> upper = new PriorityQueue<>();

    public MedianFinder() {}

    public void addNum(int num) {
        if (lower.isEmpty() || num <= lower.peek()) {
            lower.offer(num);
        } else {
            upper.offer(num);
        }

        if (lower.size() > upper.size() + 1) {
            upper.offer(lower.poll());
        } else if (lower.size() < upper.size()) {
            lower.offer(upper.poll());
        }
    }

    public double findMedian() {
        if (lower.size() > upper.size()) return lower.peek();
        return lower.peek() / 2.0 + upper.peek() / 2.0;
    }
}
class BinaryHeap {
  constructor(before) {
    this.data = [];
    this.before = before;
  }

  size() { return this.data.length; }
  peek() { return this.data[0]; }

  push(value) {
    this.data.push(value);
    let index = this.data.length - 1;
    while (index > 0) {
      const parent = Math.floor((index - 1) / 2);
      if (!this.before(this.data[index], this.data[parent])) break;
      [this.data[index], this.data[parent]] =
        [this.data[parent], this.data[index]];
      index = parent;
    }
  }

  pop() {
    const top = this.data[0];
    const last = this.data.pop();
    if (this.data.length) {
      this.data[0] = last;
      let index = 0;
      while (true) {
        const left = index * 2 + 1;
        const right = left + 1;
        let best = index;
        if (left < this.data.length &&
            this.before(this.data[left], this.data[best])) best = left;
        if (right < this.data.length &&
            this.before(this.data[right], this.data[best])) best = right;
        if (best === index) break;
        [this.data[index], this.data[best]] =
          [this.data[best], this.data[index]];
        index = best;
      }
    }
    return top;
  }
}

var MedianFinder = function () {
  this.lower = new BinaryHeap((a, b) => a > b);
  this.upper = new BinaryHeap((a, b) => a < b);
};

MedianFinder.prototype.addNum = function (num) {
  if (this.lower.size() === 0 || num <= this.lower.peek()) {
    this.lower.push(num);

    this.upper.push(num);

  if (this.lower.size() > this.upper.size() + 1) {
    this.upper.push(this.lower.pop());
  } else if (this.lower.size() < this.upper.size()) {
    this.lower.push(this.upper.pop());
  }
};

MedianFinder.prototype.findMedian = function () {
  if (this.lower.size() > this.upper.size()) return this.lower.peek();

import heapq

class MedianFinder:
    def __init__(self):
        self.lower = []
        self.upper = []

    def addNum(self, num: int) -> None:
        if not self.lower or num <= -self.lower[0]:
            heapq.heappush(self.lower, -num)
        else:
            heapq.heappush(self.upper, num)

        if len(self.lower) > len(self.upper) + 1:
            heapq.heappush(self.upper, -heapq.heappop(self.lower))
        elif len(self.lower) < len(self.upper):
            heapq.heappush(self.lower, -heapq.heappop(self.upper))

    def findMedian(self) -> float:
        if len(self.lower) > len(self.upper):
            return float(-self.lower[0])
        return (-self.lower[0]) / 2.0 + self.upper[0] / 2.0
#include <functional>
#include <queue>
#include <vector>
using namespace std;

class MedianFinder {
    priority_queue<int> lower;
    priority_queue<int, vector<int>, greater<int>> upper;

public:
    MedianFinder() {}

    void addNum(int num) {
        if (lower.empty() || num <= lower.top()) {
            lower.push(num);
        } else {
            upper.push(num);
        }

        if (lower.size() > upper.size() + 1) {
            upper.push(lower.top());
            lower.pop();
        } else if (lower.size() < upper.size()) {
            lower.push(upper.top());
            upper.pop();
        }
    }

    double findMedian() {
        if (lower.size() > upper.size()) {
            return static_cast<double>(lower.top());
        }
        return static_cast<double>(lower.top()) / 2.0 +
               static_cast<double>(upper.top()) / 2.0;
    }
};
