Problem

题目

findKthNumber(m, n, k) → integer

题意

给定正整数 m、n 与 k。构造一个按 1 开始编号的 m × n 乘法表，其中第 i 行第 j 列的值为 i × j。

把表中全部 m × n 个元素按非递减顺序排列（重复值也分别计数），返回第 k 小的元素。

约束

  • 1 ≤ m, n ≤ 3 × 10⁴
  • 1 ≤ k ≤ m × n

注意：最大表格包含 9 × 10⁸ 个元素，直接生成整张表并不现实。

示例 1

输入
m = 3, n = 3, k = 5
输出
3
解释
排序后为 1, 2, 2, 3, 3, 4, 6, 6, 9，第 5 个数是 3。

示例 2

输入
m = 2, n = 3, k = 6
输出
6
解释
排序后为 1, 2, 2, 3, 4, 6，第 6 个数是 6。

Solution

值域二分 + 单调计数

O(min(m,n) · log(mn))

核心洞察

不去生成并排序乘法表，而是在答案可能出现的值域 [1, m × n] 上搜索。对于任意阈值 x，计算表中 ≤ x 的元素数量 count(x)。

第 i 行依次是 i, 2i, …, ni，所以该行不大于 x 的元素数为 min(n, floor(x / i))。逐行求和即可。

完整过程

  1. 令 left = 1，right = m × n。
  2. 取 mid = left + floor((right-left)/2)。
  3. 累计每行 min(n, floor(mid/i))，得到 count(mid)。
  4. 若数量至少为 k，说明第 k 小值不超过 mid，令 right = mid；否则令 left = mid + 1。
  5. 当左右边界相等，该值就是答案。

正确性证明

引理 1：上述逐行公式精确给出 count(x)。因为第 i 行的第 j 个数为 i×j，满足 i×j≤x 等价于 j≤floor(x/i)，再受列数 n 限制。

引理 2：谓词 count(x) ≥ k 单调。阈值增大时，任何已计入的元素都不会消失。

定理：答案是使该谓词第一次成立的最小整数。二分始终保留这个最小可行值：成立时保留左半区并含 mid，不成立时排除 mid 及其左侧。最终区间收缩到唯一值，因此返回值正是第 k 小元素。

边界处理

  • m=1 或 n=1 时退化为单行有序数组，公式仍成立。
  • k=1 的答案为 1；k=m×n 的答案为 m×n。
  • 相同乘积来自不同格子时必须重复计数，逐行求和天然保留重复项。
  • 可先交换 m、n，让逐行计数遍历较小维度。

复杂度

值域大小为 m×n，二分执行 O(log(mn)) 轮；每轮遍历较小维度，时间复杂度为 O(min(m,n) × log(mn))。只使用常数个变量，空间复杂度为 O(1)。

替代方案

  • 展开后排序：O(mn log(mn)) 时间和 O(mn) 空间，最大输入不可行。
  • 最小堆合并有序行：约 O(k log min(m,n)) 时间、O(min(m,n)) 空间；k 较小时可用，但本题 k 可达 9×10⁸。

面试追问

  • 为什么二分的是“值”而不是表格索引？
  • 如何把计数从 O(min(m,n)) 进一步分段优化？
  • 若行内函数从乘法改为其他单调函数，哪些条件仍能套用本方法？
  • 若只需要处理很小的 k，堆方案何时会更快？

常见错误

  • 把重复乘积只计一次，错误地当作集合。
  • 用 right = mid - 1，从而跳过可能就是答案的 mid。
  • 逐行计数忘记用 min(n, floor(mid/i)) 限制列数。
  • 循环条件和边界更新不匹配，造成死循环或 off-by-one。
  • 在更宽约束的变体中用易溢出的 (left+right)/2。

四种完整实现

均使用相同的值域二分策略

Java

LeetCode 可提交
class Solution {
    public int findKthNumber(int m, int n, int k) {
        if (m > n) {
            int temp = m;
            m = n;
            n = temp;
        }

        int left = 1;
        int right = m * n;
        while (left < right) {
            int mid = left + (right - left) / 2;
            int count = 0;
            for (int row = 1; row <= m; row++) {
                count += Math.min(n, mid / row);
            }

            if (count >= k) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }
}

var findKthNumber = function(m, n, k) {
    if (m > n) [m, n] = [n, m];

    let left = 1;
    let right = m * n;
    while (left < right) {
        const mid = left + Math.floor((right - left) / 2);
        let count = 0;
        for (let row = 1; row <= m; row++) {
            count += Math.min(n, Math.floor(mid / row));
        }

        if (count >= k) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left;
};

class Solution:
    def findKthNumber(self, m: int, n: int, k: int) -> int:
        if m > n:
            m, n = n, m

        left, right = 1, m * n
        while left < right:
            mid = left + (right - left) // 2
            count = 0
            for row in range(1, m + 1):
                count += min(n, mid // row)

            if count >= k:
                right = mid
            else:
                left = mid + 1
        return left

                left = mid + 1;
            }
        }
        return left;
    }
