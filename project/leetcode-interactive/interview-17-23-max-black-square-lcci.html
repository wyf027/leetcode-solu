Detection brief

题意

给定一个只含 0 与 1 的正方形矩阵。找出边长最大的子方阵，使它的上、下、左、右四条边全部由 0 构成；内部像素可以是任意值。

返回规则

返回 [r, c, size]。先最大化边长，再选择最小 r，最后选择最小 c；完全没有黑色方框时返回空数组。

官方样例 1

输入
matrix = [[1, 0, 1], [0, 0, 1], [0, 0, 1]]
输出
[1, 0, 2]

从第 1 行、第 0 列开始的 2 × 2 方框，其四条边均为黑色。

像素约定

0 表示黑色，1 表示白色；这与部分图像题的约定相反。

约束与显示

矩阵为方阵且边长不超过 200。若出现字符串空格，会用 ␠ 显示；本题无字符串输入。

题解

核心洞察、完整过程、边界、复杂度、取舍、追问、常见错误与四语言代码均在此区域，默认不展示。

核心洞察

把一条边压缩成一个计数

对每个黑色像素预处理两个值：从它开始向右连续有多少个 0，以及向下连续有多少个 0。一个边长为 size 的方框只需检查四个计数，不必逐像素重扫四条边。

四个 O(1) 周界条件

左上点的向右、向下计数，左下点的向右计数，右上点的向下计数，都必须至少为 size。

完整过程

  1. 1. 从右下向左上遍历矩阵，生成 right 与 down。
  2. 2. 候选边长从 n 递减到 1，保证首次命中的尺寸最大。
  3. 3. 同一尺寸内按行、再按列递增枚举左上角。
  4. 4. 用四个连续长度判断四条边；全部满足就立即返回。
  5. 5. 扫描结束仍未命中则返回空数组。

边界与正确性

  • • 内部可白：只验证四条边，绝不能要求整个方块全黑。
  • • 边长 1：单个黑色像素的四条边重合，是合法方框。
  • • 全白矩阵：所有连续长度均为 0，最终返回 []。
  • • 并列规则：尺寸降序、行列升序，第一次命中正是题目指定答案。

正确性来自等价关系：四个计数条件分别完整覆盖上、左、下、右边；枚举又覆盖全部尺寸与左上角，因此不会漏掉任何合法方框。

复杂度与替代方案

时间

O(n³)

空间

O(n²)

面试最推荐连续长度预处理：周界判断清晰且为 O(1)。二维行列前缀和也能做到 O(n³)，但四条边的区间公式更容易写错；逐条扫描边界则退化到 O(n⁴)。

可以把两个计数合在每个格子的二元组中，渐进空间不变；分开数组通常更易读。

面试追问

为什么必须从右下向左上预处理？

当前位置依赖右侧和下方格子的结果，逆序遍历能保证依赖已计算。

如何找最大“全黑实心方块”？

那是另一类问题，可用最大正方形 DP；本题只要求周界为黑，不能直接套用。

如何返回全部并列答案？

找到首个最大尺寸后继续扫描同尺寸剩余位置，把所有合法坐标追加到结果。

常见错误

  • • 把 1 当黑色、0 当白色。
  • • 错把内部像素也纳入检查，漏掉合法空心方框。
  • • 只检查左上与右下两个角，无法证明整条边连续。
  • • 下边索引或右边索引忘记减 1。
  • • 尺寸或坐标枚举顺序错误，破坏并列时的最小行列规则。

class Solution {
    public int[] findSquare(int[][] matrix) {
        int n = matrix.length;
        if (n == 0) return new int[0];
        int[][] right = new int[n][n];
        int[][] down = new int[n][n];

        for (int row = n - 1; row >= 0; row--) {
            for (int col = n - 1; col >= 0; col--) {
                if (matrix[row][col] == 0) {
                    right[row][col] = 1 +
                        (col + 1 < n ? right[row][col + 1] : 0);
                    down[row][col] = 1 +
                        (row + 1 < n ? down[row + 1][col] : 0);
                }
            }
        }

        for (int size = n; size >= 1; size--) {
            for (int row = 0; row + size <= n; row++) {
                for (int col = 0; col + size <= n; col++) {
                    int bottom = row + size - 1;
                    int edge = col + size - 1;
                    if (right[row][col] >= size &&
                        down[row][col] >= size &&
                        right[bottom][col] >= size &&
                        down[row][edge] >= size) {
                        return new int[] {row, col, size};
                    }
                }
            }
        }
        return new int[0];
    }
}

from typing import List


class Solution:
    def findSquare(self, matrix: List[List[int]]) -> List[int]:
        n = len(matrix)
        if n == 0:
            return []
        right = [[0] * n for _ in range(n)]
        down = [[0] * n for _ in range(n)]

        for row in range(n - 1, -1, -1):
            for col in range(n - 1, -1, -1):
                if matrix[row][col] == 0:
                    right[row][col] = 1 + (
                        right[row][col + 1] if col + 1 < n else 0
                    )
                    down[row][col] = 1 + (
                        down[row + 1][col] if row + 1 < n else 0
                    )

        for size in range(n, 0, -1):
            for row in range(n - size + 1):
                for col in range(n - size + 1):
                    bottom = row + size - 1
                    edge = col + size - 1
                    if (
                        right[row][col] >= size
                        and down[row][col] >= size
                        and right[bottom][col] >= size
                        and down[row][edge] >= size
                    ):
                        return [row, col, size]
        return []
