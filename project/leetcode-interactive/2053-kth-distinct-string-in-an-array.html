数组中第 K 个
独一无二的字符串

Kth Distinct String in an Array

有些字符串只来过一次。保持原来的顺序，找到其中第 k 个。

官方题目 ↗
01 / 读题

任务与约束

给定字符串数组 arr 与整数 k。一个字符串只有在整个数组里恰好出现一次，才算“独一无二”。按它们在原数组中的先后顺序，从 1 开始编号，返回第 k 个；若数量不足，返回空字符串 ""。

参数：arr: string[]、k: integer；返回值：string。字符串的长度、字典序都不会改变编号顺序。

  • 1 ≤ k ≤ arr.length ≤ 1000
  • 1 ≤ arr[i].length ≤ 5
  • arr[i] 仅包含小写英文字母。
先自行思考：同一个值出现两次时，是保留一次，还是两次都不能入选？题解与交互演示在页面底部，默认收起。
02 / 官方示例

观察输入与输出

示例 1

输入：arr = ["d","b","c","b","c","a"], k = 2
输出："a"

只有 "d" 与 "a" 各出现一次，按原顺序分别排第 1、第 2，因此返回 "a"。

示例 2

输入：arr = ["aaa","aa","a"], k = 1
输出："aaa"

三个字符串都只出现一次，第一个是 "aaa"。

示例 3

输入：arr = ["a","b","a"], k = 3
输出：""

只有 "b" 符合条件，总共 1 个，取不到第 3 个。

04 / 深入理解

准备好再打开题解

两次扫描：先确认频次，再按序取第 k 个

核心洞察：某个值第一次出现时，不能断定它是唯一值；数组后面可能再次出现。先统计整个数组的频次，再沿原数组筛选频次等于 1 的值，就能同时满足“全局唯一”和“原始顺序”。

完整过程

  1. 创建频次表 count，遍历 arr，将每个值的次数加 1。
  2. 重新从左到右遍历 arr。频次不是 1 的项直接跳过。
  3. 每遇到一个频次为 1 的字符串，就让 k 减 1；减到 0 时返回当前字符串。
  4. 遍历结束仍未找到，返回 ""。
交互 / 频次闸门

先盖次数章，再发顺序票

第一轮显示已见次数（还不能判定最终唯一）；第二轮打开“次数 = 1”的闸门，只有通过的字符串得到序号。

正确性说明

第一轮的循环不变式：处理完前 i 个元素后，表里每个值的次数恰好等于它在此前缀中的出现次数。初始前缀为空，每处理一项只增加该项次数，因此整轮结束后得到全局准确频次。

第二轮只接受全局频次为 1 的元素，故不会接受重复值，也不会漏掉唯一值。扫描严格遵循原数组顺序；遇到 t 个唯一值后，剩余 k 等于原始 k − t。因此第一次减到 0 的元素恰为目标。若没有减到 0，唯一值总数不足，返回空字符串正确。

边界与复杂度

单元素数组、全部重复、全部唯一、k 等于唯一值数量或大于该数量，均由同一流程覆盖。官方输入不含空字符串，因此 "" 可以明确表示不存在。

令 n 为数组长度，u 为不同字符串数量，L 为最大字符串长度。平均哈希条件下时间为 O(nL)，字符串长度上限为 5，本题通常写作 O(n)；辅助空间为 O(u) 个频次表条目（若计入键内容为 O(uL)）。哈希冲突严重时不保证最坏线性时间。可视化中的状态重算不属于提交算法。

替代方案

  • 暴力：对每项扫描整个数组计数，再按序选取。时间 O(n²L)，额外空间 O(1)，易写但会重复比较。
  • 先生成唯一值列表，再读取下标 k − 1：同样需要频次表，额外存储 O(n) 个候选引用；代码直观，但两遍直接返回可省去列表。
  • 只用 Set 去重会保留重复值的一份，不能判定“恰好出现一次”；直接按字典序排序会破坏要求的顺序。

四种可提交语言

使用官方方法名 kthDistinct；Python 使用 Python3 签名。代码尚未运行验证。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public String kthDistinct(String[] arr, int k) {
        Map<String, Integer> count = new HashMap<>();
        for (String s : arr) {
            count.put(s, count.getOrDefault(s, 0) + 1);
        }
        for (String s : arr) {
            if (count.get(s) == 1 && --k == 0) {
                return s;
            }
        }
        return "";
    }
}

JavaScript

/**
 * @param {string[]} arr
 * @param {number} k
 * @return {string}
 */
var kthDistinct = function(arr, k) {
    const count = new Map();
    for (const s of arr) {
        count.set(s, (count.get(s) || 0) + 1);
    }
    for (const s of arr) {
        if (count.get(s) === 1 && --k === 0) return s;
    }
    return "";
};

Python 3

from collections import Counter
from typing import List

class Solution:
    def kthDistinct(self, arr: List[str], k: int) -> str:
        count = Counter(arr)
        for s in arr:
            if count[s] == 1:
                k -= 1
                if k == 0:
                    return s
        return ""

C++

#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    string kthDistinct(vector<string>& arr, int k) {
        unordered_map<string, int> count;
        for (const string& s : arr) ++count[s];
        for (const string& s : arr) {
            if (count[s] == 1 && --k == 0) return s;
        }
        return "";
    }
};

常见错误

  • 把“只出现一次”误读成“去重后保留一份”。
  • 第一轮遇到新字符串就扣减 k，忽略后面可能重复。
  • 无条件执行 --k；只有唯一字符串才应消耗名额。
  • 依赖无序哈希表的遍历顺序，导致返回值不符合原数组顺序。
  • 混淆第 k 个与下标 k；候选列表的正确下标是 k − 1。

面试追问

  • 同一数组有许多不同 k 查询？预先生成唯一值列表，预处理后每次 O(1) 查询。
  • 数据流尚未结束时能否给出确定答案？一般不能，因为后续元素可使当前唯一值失去资格；需等流结束或额外约束。
  • 若要求最坏复杂度保证？可以用平衡树计数，约 O(nL log u)，以额外对数成本避免平均哈希假设。
  • 能提前结束第一遍吗？一般不能；但第二遍找到目标后可以立即返回。
