二叉树中所有距离为 K 的结点

All Nodes Distance K in Binary Tree

给定二叉树根结点 root、树中的目标结点 target 和整数 k，返回与目标结点的最短路径恰好包含 k 条边的所有结点值。答案顺序不限。

示例与约束

示例 1

输入：root = [3,5,1,6,2,0,8,null,null,7,4], target = 5, k = 2
输出：[7,4,1]
解释：从值为 5 的目标结点出发，距离 2 的结点值为 7、4、1。

示例 2

输入：root = [1], target = 1, k = 3
输出：[]
  • 树中结点数为 [1, 500]。
  • 0 <= Node.val <= 500，且所有结点值互不相同。
  • target 是树中的某个结点。
  • 0 <= k <= 1000。

建议先思考：树上的结点怎样才能“向上走”？

题解：补齐父边，再做 BFS

核心洞察

二叉树的指针只能从父亲走向孩子，但“距离”是无向概念。先遍历整棵树，为每个非根结点记录父结点，就能把每个结点的邻居统一为 left、right、parent。随后从 target 做分层 BFS，第 k 层队列中的结点就是答案。

完整过程

  1. DFS/BFS 遍历二叉树，建立 parent.get(child) = node。
  2. 将目标结点入队，并加入访问集合，防止父子边来回重复。
  3. 每轮完整处理当前队列，轮数即从目标出发的距离。
  4. 当距离等于 k 时停止扩展，返回队列内所有结点值。

正确性

引理：父映射建立后，邻接关系恰好包含原树中每条边的两个方向，没有新增路径。层次不变式：BFS 开始处理第 d 层时，队列恰好包含所有距目标为 d 且仅包含这些结点。初始 d=0 成立；处理本层时，把每个未访问邻居加入下一层，树中唯一简单路径使其距离恰为 d+1，访问集合排除回退和重复。因此归纳成立。当 d=k 时，队列正是全部所求结点。

边界

  • k = 0：直接返回目标结点。
  • k 大于目标到所有结点的最大距离：队列提前为空，返回空数组。
  • 单结点树同样适用；目标可能是根、内部结点或叶结点。

复杂度

设结点数为 n。建立父映射和 BFS 最多各访问所有结点一次，时间复杂度 O(n)；父映射、访问集合与队列占用 O(n) 空间。

替代方案

可以只用 DFS：递归寻找目标结点，回溯时计算目标到祖先的距离，再向祖先的另一棵子树向下收集剩余距离的结点。这能省去显式父映射，但状态更复杂，容易出现距离差一错误。

面试追问

  • 如果同一棵树有大量不同目标与 k 查询，可预处理父指针；进一步可讨论重心分解或距离索引。
  • 若结点值不唯一，不能用值作为访问标识，必须使用结点对象身份。
  • 若树动态更新，父映射需要同步维护。

常见错误

  • 只向左右孩子扩散，遗漏目标祖先方向上的答案。
  • 没有访问集合，父子之间无限往返。
  • 逐结点增加距离而非逐层增加，导致层数错误。
  • 在处理完第 k 层后才收集，产生 off-by-one。

Java官方签名
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *   int val; TreeNode left, right;
 *   TreeNode(int x) { val = x; }
 * }
 */
class Solution {
    public List<Integer> distanceK(TreeNode root, TreeNode target, int k) {
        Map<TreeNode, TreeNode> parent = new HashMap<>();
        buildParent(root, null, parent);
        Queue<TreeNode> queue = new ArrayDeque<>();
        Set<TreeNode> seen = new HashSet<>();
        queue.offer(target);
        seen.add(target);
        int distance = 0;

        while (!queue.isEmpty() && distance < k) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                add(node.left, queue, seen);
                add(node.right, queue, seen);
                add(parent.get(node), queue, seen);
            }
            distance++;
        }
        List<Integer> answer = new ArrayList<>();
        while (!queue.isEmpty()) answer.add(queue.poll().val);
        return answer;
    }

    private void buildParent(TreeNode node, TreeNode p,
                             Map<TreeNode, TreeNode> parent) {
        if (node == null) return;
        if (p != null) parent.put(node, p);
        buildParent(node.left, node, parent);
        buildParent(node.right, node, parent);
    }

    private void add(TreeNode node, Queue<TreeNode> queue,
                     Set<TreeNode> seen) {
        if (node != null && seen.add(node)) queue.offer(node);
    }
}
JavaScript官方签名
/**
 * @param {TreeNode} root
 * @param {TreeNode} target
 * @param {number} k
 * @return {number[]}
 */
var distanceK = function(root, target, k) {
    const parent = new Map();
    const buildParent = (node, p) => {
        if (node === null) return;
        if (p !== null) parent.set(node, p);
        buildParent(node.left, node);
        buildParent(node.right, node);
    };
    buildParent(root, null);

    let queue = [target];
    const seen = new Set([target]);
    let distance = 0;
    while (queue.length > 0 && distance < k) {
        const next = [];
        for (const node of queue) {
            for (const neighbor of [node.left, node.right, parent.get(node)]) {
                if (neighbor != null && !seen.has(neighbor)) {
                    seen.add(neighbor);
                    next.push(neighbor);
                }
            }
        }
        queue = next;
        distance++;
    }
    return queue.map(node => node.val);
};

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def distanceK(self, root: TreeNode, target: TreeNode, k: int) -> List[int]:
        parent = {}

        def build_parent(node, p):
            if node is None:
                return
            if p is not None:
                parent[node] = p
            build_parent(node.left, node)
            build_parent(node.right, node)

        build_parent(root, None)
        queue = [target]
        seen = {target}
        distance = 0
        while queue and distance < k:
            next_level = []
            for node in queue:
                for neighbor in (node.left, node.right, parent.get(node)):
                    if neighbor is not None and neighbor not in seen:
                        seen.add(neighbor)
                        next_level.append(neighbor)
            queue = next_level
            distance += 1
        return [node.val for node in queue]
C++官方签名
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *   int val; TreeNode *left; TreeNode *right;
 *   TreeNode(int x) : val(x), left(NULL), right(NULL) {}
 * };
 */
class Solution {
    unordered_map<TreeNode*, TreeNode*> parent;

    void buildParent(TreeNode* node, TreeNode* p) {
        if (!node) return;
        if (p) parent[node] = p;
        buildParent(node->left, node);
        buildParent(node->right, node);
    }

public:
    vector<int> distanceK(TreeNode* root, TreeNode* target, int k) {
        buildParent(root, nullptr);
        queue<TreeNode*> q;
        unordered_set<TreeNode*> seen;
        q.push(target);
        seen.insert(target);
        int distance = 0;

        while (!q.empty() && distance < k) {
            int size = q.size();
            while (size--) {
                TreeNode* node = q.front(); q.pop();
                TreeNode* neighbors[3] = {node->left, node->right,
                                          parent.count(node) ? parent[node] : nullptr};
                for (TreeNode* next : neighbors) {
                    if (next && !seen.count(next)) {
                        seen.insert(next);
                        q.push(next);
                    }
                }
            }
            distance++;
        }
        vector<int> answer;
        while (!q.empty()) {
            answer.push_back(q.front()->val);
            q.pop();
        }
        return answer;
    }
};
