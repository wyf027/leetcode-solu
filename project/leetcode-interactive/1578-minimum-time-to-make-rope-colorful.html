Problem

题目说明

贪心数组字符串动态规划

Alice 把 n 个气球依次系在一根绳子上。字符串 colors 的第 i 个字符表示第 i 个气球的颜色；整数数组 neededTime 的第 i 项表示移除它需要的秒数。

如果绳子上不存在两个相邻且同色的气球，绳子就是“彩色”的。Bob 可以移除任意气球，请返回把绳子变成彩色所需的最少总时间。

函数形式
minCost(colors: string, neededTime: integer[]) → integer

约束

  • n == colors.length == neededTime.length
  • 1 ≤ n ≤ 105
  • 1 ≤ neededTime[i] ≤ 104
  • colors 仅包含小写英文字母

Examples

输出：3

输出：0
解释：绳子原本就满足相邻颜色不同，无需移除任何气球。

输出：2
解释：移除下标 0 和 4 的气球，各耗时 1 秒，总耗时为 2 秒。

Solution

准备好核对思路了吗？

题解默认收起，展开后包含证明、边界、复杂度、替代方案与四种语言的完整代码。

Core idea

把连续同色段拆开看

任何冲突都只会发生在一个连续同色段内部。若某段的移除耗时为 t₁, t₂, …, tₖ，最终至多保留一个气球。为了让移除总耗时最小，应保留其中耗时最大的那个，其余全部移除。因此该段的代价是：

段内代价 = 段内耗时总和 − 段内最大耗时
局部目标每个同色段独立消除相邻冲突。
最佳保留留下移除代价最大的气球最省时间。
一次扫描滚动维护当前段中被保留者的最大耗时。

完整过程

  1. 令 answer = 0，并把第 0 个气球视为当前同色段暂时保留的气球。
  2. 从下标 1 开始扫描。如果颜色与前一个位置不同，说明进入新段，更新当前保留耗时。
  3. 如果颜色相同，二者不能同时留下：把较小耗时加入 answer，并用较大耗时继续代表该段中暂时保留的气球。
  4. 扫描结束后，answer 就是所有同色段最小移除代价之和。

这里比较的是当前段已保留的最大耗时与新气球耗时，而不是机械地只比较两个相邻原始元素。

正确性证明

同色段中必须删到只剩一个

连续同色段若保留两个或更多气球，它们在删去中间同色气球后仍会相邻且同色；因此一个合法结果至多保留一个。

保留最大耗时者最优

某段所有气球耗时之和固定。移除代价等于段内总和减去被保留气球的耗时，所以保留最大耗时会使差值最小。

各段代价可以独立相加

不同同色段之间原本颜色就不同，在各段各留一个后仍不冲突。算法在每段取得最优，所有段的最优之和即全局最优。

复杂度

时间 O(n)额外空间 O(1)

只扫描一次数组，维护答案与当前同色段的最大耗时。

边界情况

  • 只有一个气球：答案为 0。
  • 所有颜色都不同：没有冲突，答案为 0。
  • 所有颜色都相同：删除总和减去最大值。
  • 最大长度：总答案可能超过单个耗时，但在题目约束下 32 位有符号整数足够。

class Solution {
    public int minCost(String colors, int[] neededTime) {
        int answer = 0;
        int keptTime = neededTime[0];

        for (int i = 1; i < colors.length(); i++) {
            if (colors.charAt(i) == colors.charAt(i - 1)) {
                answer += Math.min(keptTime, neededTime[i]);
                keptTime = Math.max(keptTime, neededTime[i]);
            } else {
                keptTime = neededTime[i];
            }
        }
        return answer;
    }
}

替代方案

按段求和：双指针显式找到每个连续同色段，累加“段和 − 段最大值”。思路直观，同样是 O(n) 时间与 O(1) 额外空间。

动态规划：可以维护处理到当前位置时、最后保留某颜色的最小代价，但状态远比需要的复杂；本题的冲突只在连续同色段内，贪心已经足够。

常见错误

  • 同色时总是删除右边气球，没有比较耗时。
  • 长度大于 2 的同色段中，只比较原数组相邻两个耗时，忘了维护段内最大值。
  • 颜色切换时没有重置 keptTime。
  • 真的删除数组元素，导致额外复杂度和下标错位。

面试追问

如果要求返回被删除的下标呢？

在同色段内维护当前保留者的下标。遇到更大耗时就记录旧保留者为删除项并替换；否则记录当前下标为删除项。空间复杂度会因输出本身变为 O(k)。

为什么比较前一个颜色就够了？

颜色是否仍处于同一连续段，只取决于当前字符与前一个原始字符是否相同。段内保留者的“颜色”不变，只需额外维护它的最大耗时。

如果删除气球后，相隔的两个同色气球重新相邻怎么办？

两个不同连续同色段之间至少有一个不同颜色的气球；算法在每个段都会保留一个气球，所以这个分隔不会消失，不会产生跨段的新冲突。
