H 指数 II

研究者的 H 指数

至少 h 篇论文
各被引用至少 h 次

01 · Problem

题目档案

准确转述

给定整数数组 citations，其中 citations[i] 表示第 i 篇论文的引用次数。数组已按非降序排列，请返回这名研究者的 H 指数。

H 指数是满足“至少有 h 篇论文分别获得至少 h 次引用”的最大整数 h。

题目额外要求：算法的运行时间应为 O(log n)。

约束

  • n == citations.length
  • 1 <= n <= 10^5
  • 0 <= citations[i] <= 1000
  • citations 按升序排列

输出：3
解释：共有 5 篇论文；其中 3 篇的引用次数至少为 3，其余 2 篇的引用次数不超过 3。
官方示例 02 
输入：citations = [1,2,100]
输出：2

04 · Solution

把定义变成单调条件

数组的排序性质把“有多少篇论文达到门槛”变成了一个可以二分定位的边界问题。

核心洞察

若选择下标 i 作为第一篇“高引用论文”，那么从 i 到末尾共有 n - i 篇。只要 citations[i] >= n - i，这些论文每篇都至少有 n - i 次引用。

随着 i 右移，引用次数不减，而论文数 n-i 递减，因此条件从不成立变为成立，具有单调性。

完整过程

  1. 在半开区间 [0, n) 内二分。
  2. 令 mid = l + (r-l)/2。
  3. 若 citations[mid] >= n-mid，边界可能在更左侧，令 r = mid。
  4. 否则当前及其左侧都不可能成为答案，令 l = mid+1。
  5. 循环结束时 l 是第一个满足条件的位置，答案为 n-l。

正确性证明

单调性：设谓词 P(i): citations[i] >= n-i。若 P(i) 成立，则任意 j>i 都有 citations[j] >= citations[i] 且 n-j < n-i，所以 P(j) 也成立。

边界定位：二分始终保留第一个使 P 成立的位置；当 l==r 时，该位置即为 l。若所有位置都不满足，边界为虚拟位置 n。

答案最大：从边界 l 起共有 n-l 篇论文，且每篇引用次数至少为 n-l，所以该值可行；若尝试更大的值，就必须跨过边界包含下标 l-1，而该位置不满足条件，因此不可行。故 n-l 正是最大 H 指数。

边界情况

  • 全部为 0：没有位置满足，l=n，返回 0。
  • 单篇论文：[0] 返回 0，[1] 返回 1。
  • 全部引用都很高：边界为 0，返回 n。
  • 重复值不会破坏单调性。

复杂度

时间：O(log n)，每轮将搜索区间缩小一半。

空间：O(1)，只使用常数个变量。

替代方案

从左向右扫描第一个满足条件的位置，时间为 O(n)、空间为 O(1)；逻辑直观，但没有利用题目要求的对数复杂度。

面试追问

  • 如果数组未排序怎么办？可先排序后复用，或使用计数桶。
  • 为什么搜索区间右端可以取 n？它代表“所有真实位置都不满足”。
  • 能否二分 H 值而不是下标？可以，但验证条件时仍需定位满足引用门槛的论文数。

常见错误

  • 把比较写成严格大于 >，漏掉刚好等于门槛的情况。
  • 混用闭区间与半开区间，造成死循环或越界。
  • 返回边界下标 l，而不是论文数 n-l。
  • 忘记处理“没有位置满足条件”，错误访问 citations[n]。

四语言完整代码

Java 
class Solution {
    public int hIndex(int[] citations) {
        int n = citations.length;
        int left = 0;
        int right = n;

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (citations[mid] >= n - mid) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }

        return n - left;
    }
}
