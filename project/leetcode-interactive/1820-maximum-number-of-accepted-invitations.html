1820. 最多邀请的个数

Maximum Number of Accepted Invitations

MEDIUM 付费题

01 / 题目：让更多邀请被接受

有 m 个男生和 n 个女生参加聚会。给定 m × n 的二进制矩阵 grid：grid[i][j] 为 1 时，男生 i 可以邀请女生 j；为 0 则不能。每个男生最多邀请一位女生，每个女生最多接受一位男生的邀请。返回能够同时被接受的邀请数量的最大值。

参数：grid: integer[][]。函数：maximumInvitations(grid)，返回整数。讲解中的人物编号从 1 开始，代码下标从 0 开始。

官方示例 1

输入：grid = [[1,1,1],[1,0,1],[0,0,1]]
输出：3

男生 1 → 女生 2，男生 2 → 女生 1，男生 3 → 女生 3。

官方示例 2

输入：grid = [[1,0,1,0],[1,0,0,0],[0,0,1,0],[1,1,1,0]]
输出：3

男生 1 → 女生 3，男生 2 → 女生 1，男生 4 → 女生 2，男生 3 不邀请。

约束

  • grid.length == m
  • grid[i].length == n
  • 1 ≤ m, n ≤ 200
  • grid[i][j] 为 0 或 1。

思考：一个已经确定的邀请安排，是否应该永远不变？

03 / 题解：寻找可以改派的路线

核心洞察

男生和女生是二分图的两侧，允许邀请是一条边；不共享端点的边集叫匹配。我们要求最大匹配。若目标女生已有搭档，尝试递归为原搭档安排其他女生，直到找到空闲位置。这条交替经过未选边和已选边的路线就是增广路。

在 [[1,1],[1,0]] 中，先选男生 1 → 女生 1 后，男生 2 似乎无处可去。将男生 1 改派到女生 2，男生 2 就能邀请女生 1，总数增加到 2。因此不能把早先选择永久锁定。

交互实验 / 邀请改派过程

灰线：可邀请；绿线：已确认匹配；黄虚线：当前探索。一次搜索成功后统一呈现改派结果。演示输入限 6 × 6；提交算法支持完整题目规模。

完整过程

  1. 令 match[j] 记录女生 j 当前对应的男生，初始为 -1。
  2. 依次为每个男生启动 DFS，每轮创建新的 seen 数组。
  3. 遍历可邀请且本轮未访问的女生 j，递归前先标记 seen[j]。
  4. 若女生空闲，或她当前搭档能通过 DFS 找到新位置，就令 match[j] 等于当前男生，返回 true。
  5. 所有选择失败则返回 false。仅外层 DFS 成功时，答案加 1。

正确性证明

每轮开始和结束时，match 都表示合法匹配。找到空闲女生后，沿增广路从尾到头改派，使原来匹配的人继续拥有位置，同时为新男生增加一个位置，匹配数恰好加 1。失败的搜索不修改 match。

归纳假设前 k−1 个男生已有最大匹配。加入男生 k 后，最优值至多增加 1。若存在更大的匹配，它与当前匹配的对称差必包含从新男生到空闲女生的增广路；否则前 k−1 个男生的匹配也能扩大，矛盾。DFS 遍历可达女生及其当前搭档，seen 仅防止重复访问，因此存在增广路就一定能找到。成功时达到新最优，失败时原解仍最优。处理完全部男生，答案即最大值。

复杂度

矩阵版本每轮最多访问 O(m) 个男生状态，每个扫描 n 列，耗时 O(mn)；m 轮总时间 O(m²n)。match、seen、递归栈共 O(m+n) 额外空间，不计输入。递归链不会重复访问女生，深度 O(min(m,n))。交互演示另存快照用于回放，不属于提交算法的空间分析。

边界

  • 全零矩阵：0；单格 [[1]]：1。
  • 全一矩阵：min(m,n)，两侧人数不必相同。
  • 多人只能邀请同一位女生：至多 1。
  • 官方保证非空矩形，最大行列数均为 200。

替代方案

邻接表 DFS 搜索可按 O(mE) 分析，建表仍需扫描 O(mn) 个元素。规模更大时可用 Hopcroft–Karp，时间 O(E√(m+n))。也可构造源点 → 男生 → 女生 → 汇点的单位容量网络求最大流，但实现更长。单纯挑第一个空闲女生的贪心会遗漏改派机会。

常见错误

  • seen 跨外层轮次共用，导致后来不能访问必要位置。
  • 递归前未标记女生，可能沿旧匹配循环。
  • 递归失败仍改写 match，破坏已有安排。
  • 对每个递归成功都加答案；应仅统计外层成功次数。
  • 将本题与圆桌邀请题混淆；这里输入是二分关系矩阵。

面试追问

如何输出名单？遍历最终 match。每个女生可以接收多份邀请？改用容量网络。邀请带不同收益？使用带权匹配或最小费用流。为什么只标记女生？交替搜索通过女生进入她唯一的搭档，女生去重已经足够阻断循环。

Java

import java.util.Arrays;
class Solution {
    private int[][] grid;
    private int[] match;
    public int maximumInvitations(int[][] grid) {
        this.grid = grid;
        match = new int[grid[0].length];
        Arrays.fill(match, -1);
        int ans = 0;
        for (int u = 0; u < grid.length; u++) {
            if (dfs(u, new boolean[match.length])) ans++;
        }
        return ans;
    }
    private boolean dfs(int u, boolean[] seen) {
        for (int v = 0; v < match.length; v++) {
            if (grid[u][v] == 0 || seen[v]) continue;
            seen[v] = true;
            if (match[v] == -1 || dfs(match[v], seen)) {
                match[v] = u;
                return true;
            }
        }
        return false;
    }
}

var maximumInvitations = function(grid) {
    const n = grid[0].length;
    const match = Array(n).fill(-1);
    function dfs(u, seen) {
        for (let v = 0; v < n; v++) {
            if (grid[u][v] === 0 || seen[v]) continue;
            seen[v] = true;
            if (match[v] === -1 || dfs(match[v], seen)) {
                match[v] = u;
                return true;
            }
        }
        return false;
    }
    let ans = 0;
    for (let u = 0; u < grid.length; u++) {
        if (dfs(u, Array(n).fill(false))) ans++;
    }
    return ans;
};

Python

from typing import List

class Solution:
    def maximumInvitations(self, grid: List[List[int]]) -> int:
        n = len(grid[0])
        match = [-1] * n

        def dfs(u: int, seen: List[bool]) -> bool:
            for v in range(n):
                if grid[u][v] == 0 or seen[v]:
                    continue
                seen[v] = True
                if match[v] == -1 or dfs(match[v], seen):
                    match[v] = u
                    return True
            return False

        ans = 0
        for u in range(len(grid)):
            if dfs(u, [False] * n):
                ans += 1
        return ans

C++

#include <vector>
using namespace std;
class Solution {
    bool dfs(int u, const vector<vector<int>>& grid,
             vector<int>& match, vector<bool>& seen) {
        for (int v = 0; v < (int)match.size(); ++v) {
            if (grid[u][v] == 0 || seen[v]) continue;
            seen[v] = true;
            if (match[v] == -1 ||
                dfs(match[v], grid, match, seen)) {
                match[v] = u;
                return true;
            }
        }
        return false;
    }
public:
    int maximumInvitations(vector<vector<int>>& grid) {
        int n = grid[0].size(), ans = 0;
        vector<int> match(n, -1);
        for (int u = 0; u < (int)grid.size(); ++u) {
            vector<bool> seen(n, false);
            if (dfs(u, grid, match, seen)) ++ans;
        }
        return ans;
    }
};
