的数量

给定两种合法块长，统计指定长度区间内能由这些块拼出的不同二进制字符串。先读题与动手观察，题解默认收在页面底部。

MEDIUM 会员题 Number of Good Binary Strings

Problem

题意

goodBinaryStrings(…)

给你四个整数 minLength、maxLength、oneGroup 和 zeroGroup。一个二进制字符串被称为好字符串，当且仅当：

  • 长度位于 [minLength, maxLength]，包含两个端点；
  • 每一段连续的 1，长度都是 oneGroup 的倍数；
  • 每一段连续的 0，长度都是 zeroGroup 的倍数。

返回不同好字符串的数量。答案可能很大，需对 10⁹ + 7 取模。

约束

  • 1 ≤ minLength ≤ maxLength ≤ 10⁵
  • 1 ≤ oneGroup, zeroGroup ≤ maxLength
“某段长度是块长的倍数”也可以理解为：从空串开始，每次追加整块 1…1 或 0…0。

Examples

官方示例

EXAMPLE 01

输入：minLength = 2, maxLength = 3,
      oneGroup = 1, zeroGroup = 2
输出：5

五个好字符串是 "00"、"11"、"001"、"100" 和 "111"。

EXAMPLE 02

输入：minLength = 4, maxLength = 4,
      oneGroup = 4, zeroGroup = 3
输出：1

唯一的好字符串是 "1111"；四个零既不是三的倍数，也无法与四个一组合成长度四。

Solution

动态规划：按最后追加的块计数

O(maxLength)

核心洞察

任意非空好字符串的末尾，要么是恰好 oneGroup 个一组成的新块，要么是恰好 zeroGroup 个零组成的新块。删去最后一块后，前缀仍由合法块构成。

dp[i] = dp[i - oneGroup] + dp[i - zeroGroup]

越界的项视为 0，并设置 dp[0] = 1 表示唯一的空前缀。最终累加目标长度区间内的 dp[i]。

完整过程

  1. 创建长度为 maxLength + 1 的数组，并令 dp[0] = 1。
  2. 从长度 1 递增到 maxLength。
  3. 若能放下一块一，就加上较短长度 i - oneGroup 的方案数。
  4. 若能放下一块零，就加上 i - zeroGroup 的方案数。
  5. 当当前长度进入目标区间时，把该状态加入答案；每一步都取模。

正确性

完备性：每个好字符串都能删除其最后一个固定大小的块，得到一个被 dp 统计的更短前缀，因此一定出现在某次转移中。

不重复性：一个字符串的最后若干位确定了最后追加的是一块还是零块；去掉该块后的前缀也唯一。因此两个转移集合互不相交，且同一字符串不会被重复计数。

由长度递增归纳，dp[i] 恰好等于长度为 i 的好字符串数量，区间求和即为所求。

边界与复杂度

  • dp[0] = 1 只作为转移起点；因 minLength ≥ 1，空串不会进入答案。
  • 块长大于当前长度时跳过对应转移。
  • 两种块长相等时仍要分别相加，因为全一块和全零块产生不同字符串。
  • 时间复杂度：O(maxLength)；空间复杂度：O(maxLength)。

替代方案

可以把状态拆成“最后一段是 0 / 1”，再用前缀和优化跨越若干倍块长的转移，同样做到线性时间。但本题的固定块拼装视角已经把同一连续段唯一分块，单数组写法更短，也更直接。

面试追问

  • 如果要求多个区间查询，可先构造 dp 的前缀和，单次查询降为 O(1)。
  • 如果 maxLength 极大而块长较小，可讨论线性递推的矩阵快速幂。
  • 如果要恢复一个具体好字符串，需要为可达状态保存前驱选择。

常见错误

  • 把 dp[0] 设为 0，导致任何第一块都无法产生。
  • 只计算 dp[maxLength]，漏掉区间内其他合法长度。
  • 当两个块长相等时只加一次，误把末尾全零块与全一块合并。
  • 最后才取模，造成固定宽度整数溢出。
  • 误以为连续相同块会造成重复；固定块长使同一连续段的分块位置唯一。

四份代码均使用官方参数顺序：minLength, maxLength, oneGroup, zeroGroup。

class Solution {
    public int goodBinaryStrings(int minLength, int maxLength,
                                 int oneGroup, int zeroGroup) {
        final int mod = 1_000_000_007;
        int[] dp = new int[maxLength + 1];
        dp[0] = 1;
        int answer = 0;

        for (int length = 1; length <= maxLength; length++) {
            if (length >= oneGroup) {
                dp[length] = (dp[length] + dp[length - oneGroup]) % mod;
            }
            if (length >= zeroGroup) {
                dp[length] = (dp[length] + dp[length - zeroGroup]) % mod;
            }
            if (length >= minLength) {
                answer = (answer + dp[length]) % mod;
            }
        }
        return answer;
    }
}
