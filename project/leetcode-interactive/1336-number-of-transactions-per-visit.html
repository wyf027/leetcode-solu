1336. 每次访问的交易次数

Number of Transactions per Visit

HARD数据库付费题

先把每次访问映射为“当天发生了几笔交易”，再补齐从 0 到最大值之间没有出现的次数。难点不是计数本身，而是让结果中的空桶也存在。

题目转述

Visits 记录用户的访问日期；Transactions 记录用户在某日完成的交易与金额。一次访问由同一个 (user_id, visit_date) 标识，只有用户与日期同时相同的交易才属于该次访问。

请统计：恰好发生 transactions_count 笔交易的访问有多少次，记作 visits_count。结果必须覆盖从 0 到“任意一次访问中的最大交易笔数”的每个整数；即使某个次数没有对应访问，也要输出 visits_count = 0，并按 transactions_count 升序排列。

表结构与约束

  • Visits(user_id INT, visit_date DATE)
  • Transactions(user_id INT, transaction_date DATE, amount INT)
  • 交易只有在用户和日期均匹配时，才计入某次访问。
  • 必须保留零交易访问，并补出 0 到最大交易数的连续统计区间。
  • 输出列为 transactions_count、visits_count。

题解

核心洞察

先对交易按“用户 + 日期”聚合，再从访问表左连接得到每次访问的交易数。接着生成连续整数序列 0…max，最后把访问计数与序列左连接。连续序列正是保留空桶（例如示例中的 2）的关键。

  1. 聚合交易。按 (user_id, transaction_date) 分组，得到当天交易数。
  2. 映射到访问。以 Visits 为左表连接聚合结果；没有交易的访问用 COALESCE(..., 0)。
  3. 生成整数序列。递归 CTE 从 0 增至单次访问最大交易数。
  4. 统计并补齐。按交易数统计访问数，再与序列左连接并升序输出。
正确性说明

交易预聚合使每个“用户 + 日期”最多对应一行计数；左连接确保每个访问恰好贡献一次，缺失计数被映射为 0。因此分组结果准确统计每个已有桶。递归序列包含 0 到最大值的每个整数；对分组结果再次左连接，使缺失桶映射为 0。故最终每行且仅一行对应目标区间内的一个交易次数，访问数正确。

边界情况

  • 某次访问没有任何交易。
  • 中间某个交易次数无人命中，仍输出 0。
  • 同一用户在不同日期访问，必须分别统计。
  • 同一天多笔交易，金额不参与计数。
  • 若数据平台允许空输入，应单独确认其输出契约。

复杂度

设访问数为 V、交易数为 T、最大单次交易数为 M。散列聚合/连接的逻辑成本约为 O(V + T + M)，空间约为 O(V + T + M)；实际 SQL 成本由索引、执行计划和数据库实现决定。

SQL · 官方题型主解
WITH RECURSIVE
transaction_totals AS (
  SELECT user_id, transaction_date, COUNT(*) AS transaction_count
  FROM Transactions
  GROUP BY user_id, transaction_date
),
visit_totals AS (
  SELECT v.user_id,
         v.visit_date,
         COALESCE(t.transaction_count, 0) AS transaction_count
  FROM Visits AS v
  LEFT JOIN transaction_totals AS t
    ON t.user_id = v.user_id
   AND t.transaction_date = v.visit_date
),
visit_histogram AS (
  SELECT transaction_count, COUNT(*) AS visits_count
  FROM visit_totals
  GROUP BY transaction_count
),
counts AS (
  SELECT 0 AS transaction_count
  UNION ALL
  SELECT transaction_count + 1
  FROM counts
  WHERE transaction_count < (SELECT MAX(transaction_count) FROM visit_totals)
)
SELECT c.transaction_count AS transactions_count,
       COALESCE(h.visits_count, 0) AS visits_count
FROM counts AS c
LEFT JOIN visit_histogram AS h
  ON h.transaction_count = c.transaction_count
ORDER BY c.transaction_count;

Java · 本地语义参考
import java.util.*;

class Solution {
  static int[][] countVisits(String[][] visits, String[][] transactions) {
    Map<String, Integer> tx = new HashMap<>();
    for (String[] row : transactions) {
      String key = row[0] + "#" + row[1];
      tx.merge(key, 1, Integer::sum);
    }
    Map<Integer, Integer> histogram = new HashMap<>();
    int max = 0;
    for (String[] row : visits) {
      int count = tx.getOrDefault(row[0] + "#" + row[1], 0);
      histogram.merge(count, 1, Integer::sum);
      max = Math.max(max, count);
    }
    int[][] answer = new int[max + 1][2];
    for (int i = 0; i <= max; i++) {
      answer[i][0] = i;
      answer[i][1] = histogram.getOrDefault(i, 0);
    }
    return answer;
  }
}
JavaScript · 本地语义参考
function countVisits(visits, transactions) {
  const tx = new Map();
  for (const [user, date] of transactions) {
    const key = `${user}#${date}`;
    tx.set(key, (tx.get(key) ?? 0) + 1);
  }
  const histogram = new Map();
  let max = 0;
  for (const [user, date] of visits) {
    const count = tx.get(`${user}#${date}`) ?? 0;
    histogram.set(count, (histogram.get(count) ?? 0) + 1);
    max = Math.max(max, count);
  }
  return Array.from({ length: max + 1 }, (_, count) => [
    count,
    histogram.get(count) ?? 0,
  ]);
}
Python · 本地语义参考
from collections import Counter

def count_visits(visits, transactions):
    tx = Counter((user, date) for user, date, _ in transactions)
    per_visit = [tx[(user, date)] for user, date in visits]
    histogram = Counter(per_visit)
    maximum = max(per_visit, default=0)
    return [[count, histogram[count]] for count in range(maximum + 1)]
C++ · 本地语义参考
#include <algorithm>
#include <map>
#include <string>
#include <utility>
#include <vector>
using namespace std;

vector<pair<int, int>> countVisits(
    const vector<pair<int, string>>& visits,
    const vector<tuple<int, string, int>>& transactions) {
  map<pair<int, string>, int> tx;
  for (const auto& [user, date, amount] : transactions) {
    (void)amount;
    ++tx[{user, date}];
  }
  map<int, int> histogram;
  int maximum = 0;
  for (const auto& [user, date] : visits) {
    int count = tx[{user, date}];
    ++histogram[count];
    maximum = max(maximum, count);
  }
  vector<pair<int, int>> answer;
  for (int count = 0; count <= maximum; ++count)
    answer.push_back({count, histogram[count]});
  return answer;
}

替代方案

  • MySQL 8.0 可用递归 CTE；支持 generate_series 的数据库可直接生成序列。
  • 若题目给出安全且很小的固定上限，可借助数字表，但可维护性较差。
  • 先逐访问关联再分组也能做，但预聚合交易通常更清晰，可避免连接后行数膨胀。

面试追问

  • 若一次访问由 session_id 而非日期定义，连接键如何改？
  • 如何利用 (user_id, transaction_date) 复合索引？
  • 数据库不支持递归 CTE 时怎样补齐序列？
  • 超大交易表上如何分区与预聚合？
常见错误
  • 直接内连接，导致零交易访问消失。
  • 只按用户连接，误把其他日期的交易算入当前访问。
  • 只对已有交易数分组，漏掉中间的空桶。
  • 用 SUM(amount) 代替 COUNT(*)。
  • 递归终止条件写成 <= max，多生成一个桶。
