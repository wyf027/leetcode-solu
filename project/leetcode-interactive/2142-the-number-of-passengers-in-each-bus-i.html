01 / THE TASK

题目与数据约定

输入为 Buses(bus_id INT, arrival_time INT) 和 Passengers(passenger_id INT, arrival_time INT) 两张表。车辆到站时，会接走所有已到站且尚未乘车的乘客；乘客与车辆同时到站，也可以乘坐该车。本题没有容量限制。

编写 SQL，输出每辆车的 bus_id 与人数 passengers_cnt，即使人数为 0 也保留该车。结果按 bus_id 升序排列。

字段类型 / 含义

Passengers · 乘客到站表
字段类型 / 含义
passenger_idINT，唯一标识 / 主键
arrival_timeINT，乘客到站时刻

约束与语义

  • 两辆车不会同时到达；乘客到站时刻不要求互不相同。
  • 可乘车条件是乘客时间 ≤ 车辆时间，且乘客之前未登上任何车。
  • 车辆编号与到站先后没有必然关系。输入表无默认行顺序。
  • 晚于末班车到站的乘客不计入任何车辆。
  • 公开题面未列出行数或时间数值范围；不虚构范围，也不假设时间一定大于 0。

05 / SOLUTION

先想一想，再揭开答案

怎样保证同一个乘客不会在之后的车辆中再次被计数？

题解 · 把时间轴切成左开右闭区间

核心洞察

设车辆按时间排序为 t₁ < t₂ < … < tᵦ。第 i 辆车只接收 (tᵢ₋₁, tᵢ] 的乘客；第一辆车接收所有时间 ≤ t₁ 的乘客。前一辆车已经带走更早到站的人。

完整过程

  1. 对车辆时间使用 LAG，取得前一辆车的到站时间。
  2. LEFT JOIN 乘客表，上界为当前时间，下界严格大于前车时间。首车没有下界。
  3. 按车辆分组，以 COUNT(passenger_id) 计数。
  4. 最后按 bus_id 排序，保留空载车辆。

官方提交主解 · MySQL 8 SQL

数据库题以 SQL 为主要提交形式。使用非递归 CTE 和窗口函数；首车保留 NULL 前驱，避免臆造时间下界。

WITH bus_windows AS (
    SELECT bus_id,
           arrival_time,
           LAG(arrival_time) OVER (
               ORDER BY arrival_time
           ) AS prev_time
    FROM Buses
)
SELECT b.bus_id,
       COUNT(p.passenger_id) AS passengers_cnt
FROM bus_windows AS b
LEFT JOIN Passengers AS p
    ON p.arrival_time <= b.arrival_time
   AND (b.prev_time IS NULL OR p.arrival_time > b.prev_time)
GROUP BY b.bus_id
ORDER BY b.bus_id;

正确性证明

考虑第 i 辆车。若乘客到站时间 ≤ tᵢ₋₁，他必已搭乘某辆更早的车，因此不应计入本车。若到站时间位于 (tᵢ₋₁, tᵢ]，前面的车均早于他到站，且本车已能接到他，因此他恰好属于本车。首车之前没有任何车辆，只有上界约束。各区间两两不交，覆盖所有不晚于末班车的乘客，所以每名可乘车的乘客恰好计数一次。LEFT JOIN 保留无匹配乘客的车，COUNT 非空主键使其人数为 0。

边界与常见错误

  • 上界必须用 ≤，同刻到站可以乘车；下界必须用 >，避免重复。
  • 不要把 LAG 的缺省值写成 0：题面未给出正时间约束。
  • 不要使用 INNER JOIN，否则空载车丢失。
  • 不要 COUNT(*)，空载车的占位行会被计成 1。
  • 不要将乘客筛选移入 WHERE，容易破坏左连接。
  • 窗口按时间排序，最终输出按车号排序。

复杂度

记 B 为车辆数，P 为乘客数。SQL 的实际代价依赖优化器与索引：排序通常为 O(B log B)；若以朴素嵌套循环判断区间，连接最坏 O(BP)。匹配结果至多 O(B + P) 行，不代表引擎只比较这些行。临时空间与执行计划有关，不能无条件声称常数空间。

下方四语言采用排序 + 双指针：时间 O(B log B + P log P + B + P)，复制输入、排序工作区及返回值合计 O(B + P) 空间。

替代方案

① 累计人数差：求每辆车到站时已到达的总人数 Cᵢ，再计算 Cᵢ − Cᵢ₋₁；但累计连接可能产生 O(BP) 行。② 对每名乘客找最小的合格车辆时间，再按车辆汇总，并从 Buses 左连接补零。③ 内存语义参考使用排序与双指针，每个乘客只推进一次。

面试追问

  • 加上容量限制？ 超出容量的乘客会延后上车，固定时间区间不再成立，需要维护等待队列或累计分配状态。
  • 多条线路？ 需有线路字段，LAG 按线路分区，并在 JOIN 条件中匹配线路。
  • 两车同时到站？ 需先明确业务分配或车号优先规则；原题已排除此情况。
  • 数据量很大？ 检视执行计划、到站时间索引和区间连接的实际扫描量，不能仅凭 SQL 文本判断性能。

Java

import java.util.Arrays;
import java.util.Comparator;

public class Solution {
    public int[][] countPassengers(int[][] buses, int[][] passengers) {
        int[][] bs = Arrays.stream(buses)
                .map(int[]::clone).toArray(int[][]::new);
        int[] times = Arrays.stream(passengers)
                .mapToInt(row -> row[1]).sorted().toArray();
        Arrays.sort(bs, Comparator.comparingInt(row -> row[1]));
        int[][] result = new int[bs.length][2];
        int p = 0;
        for (int i = 0; i < bs.length; i++) {
            int start = p;
            while (p < times.length && times[p] <= bs[i][1]) p++;
            result[i] = new int[]{bs[i][0], p - start};
        }
        Arrays.sort(result, Comparator.comparingInt(row -> row[0]));
        return result;
    }
}

JavaScript

function countPassengers(buses, passengers) {
  const bs = buses.map(row => [...row]).sort((a, b) => a[1] - b[1]);
  const times = passengers.map(row => row[1]).sort((a, b) => a - b);
  const result = [];
  let p = 0;
  for (const [id, time] of bs) {
    const start = p;
    while (p < times.length && times[p] <= time) p++;
    result.push([id, p - start]);
  }
  return result.sort((a, b) => a[0] - b[0]);
}

Python · 普通数组函数

def count_passengers(buses: list[list[int]],
                     passengers: list[list[int]]) -> list[list[int]]:
    bs = sorted(buses, key=lambda row: row[1])
    times = sorted(row[1] for row in passengers)
    result = []
    p = 0
    for bus_id, time in bs:
        start = p
        while p < len(times) and times[p] <= time:
            p += 1
        result.append([bus_id, p - start])
    return sorted(result, key=lambda row: row[0])

C++

#include <algorithm>
#include <array>
#include <vector>
using namespace std;

class Solution {
public:
    vector<array<int, 2>> countPassengers(
        vector<array<int, 2>> buses,
        const vector<array<int, 2>>& passengers) {
        sort(buses.begin(), buses.end(),
             [](const auto& a, const auto& b) { return a[1] < b[1]; });
        vector<int> times;
        for (const auto& row : passengers) times.push_back(row[1]);
        sort(times.begin(), times.end());
        vector<array<int, 2>> result;
        size_t p = 0;
        for (const auto& bus : buses) {
            size_t start = p;
            while (p < times.size() && times[p] <= bus[1]) ++p;
            result.push_back({bus[0], static_cast<int>(p - start)});
        }
        sort(result.begin(), result.end(),
             [](const auto& a, const auto& b) { return a[0] < b[0]; });
        return result;
    }
};
