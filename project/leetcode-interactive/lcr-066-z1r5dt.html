LCR 066 · MEDIUM

键值映射

实现可更新键值的 MapSum：插入键与整数值，并返回所有以给定前缀开头的键的值之和。

题意

设计 MapSum，支持 insert(key, val) 与 sum(prefix)。同一个键再次插入时，旧值必须被新值覆盖；查询只累计键以 prefix 开头的项目。

示例

insert("apple", 3)
sum("ap") → 3
insert("app", 2)
sum("ap") → 5
insert("apple", 4)
sum("ap") → 6

约束

键和前缀只含小写英文字母，长度在 1 到 50 之间；操作次数不超过 50。val 为非负整数。

交互实验台：Trie 增量

输入小写字母键；重复插入将展示 delta 如何沿前缀路径传播。

已预置 apple → 3，可先查询 ap。

核心洞察

Trie 的每个节点保存子节点与经过该前缀的累计和。插入时先在哈希表取出该键旧值，计算 delta = val - oldValue，再把 delta 加到根至末字符的每个节点。首次写入与覆盖写入因此统一。

完整过程

  1. 维护 values[key]，取旧值（不存在时为 0）。
  2. 计算 delta，沿 key 的字符路径创建或进入 Trie 节点。
  3. 每到一个节点都加上 delta；根节点代表空前缀总和。
  4. 查询时走到 prefix 节点；路径缺失返回 0，否则返回累计和。

边界

  • 重复插入 apple 时必须扣掉旧值，不能二次累加。
  • 不存在的前缀应立即返回 0，无需扫描所有键。
  • 前缀可以恰好等于完整键，也可以只是一段共享路径。

复杂度

键长为 L、前缀长为 P 时：插入 O(L)，查询 O(P)；空间为所有不同键字符数之和。

替代方案与追问

操作很少时，HashMap 保存全部键、查询时逐个 startsWith，实现短但单次查询是 O(键数 × 前缀比较)。若频繁查询或共享前缀多，Trie 更合适。若还需要删除，使用负 delta 更新路径，并可按需剪枝。

常见错误

  • 用新值直接更新节点和，遗漏覆盖语义。
  • 只在叶子存值，导致 sum(prefix) 必须遍历整棵子树。
  • 查询中途找不到字符仍访问空节点。

# Python
class MapSum:
    def __init__(self): self.root = {'sum': 0, 'next': {}}; self.values = {}
    def insert(self, key: str, val: int) -> None:
        delta = val - self.values.get(key, 0); self.values[key] = val; node = self.root; node['sum'] += delta
        for ch in key:
            node = node['next'].setdefault(ch, {'sum': 0, 'next': {}})
            node['sum'] += delta
    def sum(self, prefix: str) -> int:
        node = self.root
        for ch in prefix:
            if ch not in node['next']: return 0
            node = node['next'][ch]
        return node['sum']
