金字塔
转换矩阵Pyramid Transition Matrix

从一行颜色积木出发，用合法的三角规则逐层缩短。真正的问题不是“能不能搭下一层”，而是“是否存在一条选择链，能一直抵达唯一的塔尖”。

MEDIUM 回溯 哈希表 字符串 位运算 非会员题

01 · Brief

题意转述

每个积木的颜色用 A 到 F 中的一个字母表示。给定字符串 bottom 作为金字塔底层；每向上一层，积木数必须恰好减少一个，并且上层居中放置。

allowed 中每个长度为 3 的字符串描述一个合法小三角形：前两个字符依次是左下、右下积木，第三个字符是它们上方的积木。例如 ABC 表示 A、B 上方允许放置 C；左右顺序不能交换。

若存在一种搭法，使金字塔能从给定底层一直构造到单个塔尖，且每个小三角形都在 allowed 中，返回 true；否则返回 false。

函数参数： pyramidTransition(bottom: string, allowed: list<string>) → boolean
规则

"ABC"

→
含义

A（左）+ B（右）可以托起 C

06 · Solution

回溯生成上一层 + 失败状态记忆

把每条三字符规则按前两个字符分组。对当前行从左到右选择每一对的顶部字符，拼出完整上一层，再递归处理更短的一行。

核心洞察

  • 每个位置的候选只取决于当前行的一对相邻字符，可预处理为 pair → tops。
  • 某个位置可能有多个顶部字符，必须保留分支；贪心选择任意一个不能保证成功。
  • 若一整行已经被证明无法到达塔尖，再次遇到它时结论不变，因此可记忆失败行。

完整过程

  1. 扫描 allowed，将第三个字符放入以前两个字符为键的候选表。
  2. 若当前行长度为 1，说明已经形成塔尖，返回 true。
  3. 从索引 0 开始，为每对相邻字符枚举顶部字符，逐个追加到 next。
  4. next 长度达到当前行长度减一时，递归检查它；任何分支成功即可立即返回。
  5. 所有组合都失败后，将当前行记入失败集合并返回 false。

正确性证明

引理 1：生成函数枚举了当前行所有合法的直接上一层。对上一层的每个位置，它恰好查询对应相邻对的全部合法顶部字符；不同位置候选做笛卡尔积，因此没有遗漏，也不会生成含非法小三角形的上一层。

引理 2：递归函数在且仅在当前行能构造到塔尖时返回 true。长度为 1 时显然成立。长度大于 1 时，由引理 1，函数检查所有合法直接上一层；根据归纳假设，其中任一层能到塔尖时返回真，全部不能时返回假。

结论：将给定 bottom 交给递归函数，返回值恰好表示是否存在满足全部规则的完整金字塔。缓存仅复用已经证明为假的结论，不改变搜索集合。

边界情况

  • allowed 为空：任意长度至少为 2 的底层都无法继续。
  • 某一相邻对没有候选：当前上一层组合立即失败。
  • 同一对有多个顶部字符：候选必须全部枚举。
  • 不同路径得到相同的中间行：失败记忆避免重复展开。
  • 左右有方向性：键必须是有序的两字符字符串。

复杂度

设字母表大小为 A（本题最多 6），底层长度为 n（最多 6）。不考虑记忆时，最坏会为金字塔中每个非底层位置尝试最多 A 种颜色，时间上界为 O(A^(n(n−1)/2))。

失败行记忆后，可出现的长度不超过 n 的行总数为 O(A^n)；每行仍可能生成许多父行，因此可给出较宽松的时间上界 O(A^(2n))，空间为 O(A^n + n²)（缓存加递归构造路径）。在本题极小约束下足够。

替代方案

  • 位掩码候选：用 6 位整数保存每个相邻对可生成的字符，减少集合遍历和对象分配。
  • 逐层状态集合：维护当前所有可能行，批量生成所有上一层并去重；思路直观，但可能同时保存大量字符串。
  • 纯暴力回溯：代码最短，却会反复搜索相同中间行；在更大约束下表现明显更差。

面试追问

  • 为什么不能只缓存当前索引？还必须知道当前行与已经拼出的上一层前缀。
  • 为什么这里只缓存“失败的完整行”就够？完整行的后续可行性与到达路径无关。
  • 如果字母表扩大到 26，怎样改变候选存储与复杂度分析？
  • 如何返回一座实际可行的金字塔，而不只是布尔值？在成功路径上保留每层字符串即可。

常见错误

错误直觉：每对相邻字符独立选一个候选 → 正确做法：上一层的完整组合决定后续是否可行
  • 把 AB 与 BA 当成同一个键，破坏了规则方向。
  • 只生成第一种上一层，遗漏其他能到塔尖的分支。
  • 在上一层尚未拼完整时就递归换层，导致相邻关系错位。
  • 把“访问过”直接当作失败；只有完整搜索后确认无解，才能写入失败集合。

class Solution {
    private Map<String, List<Character>> transitions;
    private Set<String> failed;

    public boolean pyramidTransition(String bottom, List<String> allowed) {
        transitions = new HashMap<>();
        failed = new HashSet<>();

        for (String rule : allowed) {
            String pair = rule.substring(0, 2);
            transitions.computeIfAbsent(pair, key -> new ArrayList<>())
                       .add(rule.charAt(2));
        }
        return canBuild(bottom);
    }

    private boolean canBuild(String row) {
        if (row.length() == 1) return true;
        if (failed.contains(row)) return false;

        if (buildNext(row, 0, new StringBuilder())) return true;
        failed.add(row);
        return false;
    }

    private boolean buildNext(String row, int index, StringBuilder next) {
        if (index == row.length() - 1) {
            return canBuild(next.toString());
        }

        String pair = row.substring(index, index + 2);
        List<Character> tops = transitions.get(pair);
        if (tops == null) return false;

        for (char top : tops) {
            next.append(top);
            if (buildNext(row, index + 1, next)) return true;
            next.deleteCharAt(next.length() - 1);
        }
        return false;
    }
}
/**
 * @param {string} bottom
 * @param {string[]} allowed
 * @return {boolean}
 */
var pyramidTransition = function(bottom, allowed) {
    const transitions = new Map();
    const failed = new Set();

    for (const rule of allowed) {
        const pair = rule.slice(0, 2);
        if (!transitions.has(pair)) transitions.set(pair, []);
        transitions.get(pair).push(rule[2]);
    }

    function canBuild(row) {
        if (row.length === 1) return true;
        if (failed.has(row)) return false;

        if (buildNext(row, 0, "")) return true;
        failed.add(row);
        return false;
    }

    function buildNext(row, index, next) {
        if (index === row.length - 1) return canBuild(next);

        const pair = row.slice(index, index + 2);
        const tops = transitions.get(pair) || [];
        for (const top of tops) {
            if (buildNext(row, index + 1, next + top)) return true;
        }
        return false;
    }

    return canBuild(bottom);
};
from collections import defaultdict
from typing import List


class Solution:
    def pyramidTransition(self, bottom: str, allowed: List[str]) -> bool:
        transitions = defaultdict(list)
        for rule in allowed:
            transitions[rule[:2]].append(rule[2])

        failed = set()

        def can_build(row: str) -> bool:
            if len(row) == 1:
                return True
            if row in failed:
                return False

            def build_next(index: int, next_chars: List[str]) -> bool:
                if index == len(row) - 1:
                    return can_build("".join(next_chars))

                pair = row[index:index + 2]
                for top in transitions.get(pair, []):
                    next_chars.append(top)
                    if build_next(index + 1, next_chars):
                        return True
                    next_chars.pop()
                return False

            if build_next(0, []):
                return True
            failed.add(row)
            return False

        return can_build(bottom)
class Solution {
private:
    unordered_map<string, vector<char>> transitions;
    unordered_set<string> failed;

    bool canBuild(const string& row) {
        if (row.size() == 1) return true;
        if (failed.count(row)) return false;

        string next;
        if (buildNext(row, 0, next)) return true;
        failed.insert(row);
        return false;
    }

    bool buildNext(const string& row, int index, string& next) {
        if (index == static_cast<int>(row.size()) - 1) {
            return canBuild(next);
        }

        string pair = row.substr(index, 2);
        auto it = transitions.find(pair);
        if (it == transitions.end()) return false;

        for (char top : it->second) {
            next.push_back(top);
            if (buildNext(row, index + 1, next)) return true;
            next.pop_back();
        }
        return false;
    }

public:
    bool pyramidTransition(string bottom, vector<string>& allowed) {
        for (const string& rule : allowed) {
            transitions[rule.substr(0, 2)].push_back(rule[2]);
        }
        return canBuild(bottom);
    }
};
