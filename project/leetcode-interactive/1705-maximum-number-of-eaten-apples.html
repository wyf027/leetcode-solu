吃苹果的
最大数目

每天只能吃一个苹果，而每一批苹果都有自己的腐烂日。怎样安排每天的选择，才能让尽可能少的苹果被时间夺走？

贪心数组堆（优先队列）Maximum Number of Eaten Apples
≤ 1
每天最多吃一个苹果；第 n 天以后仍可继续。
Problem

先读懂保质期

下标从 0 开始。第 i 天长出的苹果，在第 i + days[i] 天已经腐烂，不能再吃。

一棵苹果树连续 n 天结果。第 i 天会长出 apples[i] 个苹果，这批苹果可保存 days[i] 天；到了第 i + days[i] 天，它们就会腐烂。没有新苹果的日子用 apples[i] = 0 且 days[i] = 0 表示。

你每天最多吃一个苹果，并且在前 n 天结束后仍可继续食用尚未腐烂的库存。给定两个长度均为 n 的整数数组 apples 和 days，返回最多能吃掉多少个苹果。

示例 1

输入：apples = [1,2,3,5,2],
      days = [3,2,1,4,2]
输出：7

第 1、2、3 天分别吃当天/第二天批次的苹果；第 4 至第 7 天吃第 4 天长出的苹果，共 7 个。

示例 2

输入：apples = [3,0,0,0,0,2],
      days = [3,0,0,0,0,2]
输出：5

前三天吃第一批，第四、五天没有可吃的苹果，第六、七天吃最后一批，共 5 个。

约束

n == apples.length == days.length
1 <= n <= 2 × 104
0 <= apples[i], days[i] <= 2 × 104
days[i] = 0 当且仅当 apples[i] = 0

核心洞察

只要今天有苹果可吃，就优先吃最早腐烂的那一批；更晚腐烂的苹果留给未来，选择空间不会变小。

完整过程

维护小根堆。每个堆元素记录 [腐烂日, 剩余数量]，堆顶始终是腐烂日最早的批次。
接收当天产出。若第 day 天长出苹果，就把 [day + days[day], apples[day]] 入堆。
清理过期库存。不断弹出腐烂日 <= day 的批次；它们在今天已经不能吃。
食用一枚。若堆非空，从堆顶批次吃一个；数量减为 0 时移除该批次，答案加一。
继续到库存耗尽。即使 day >= n，只要堆里还有未腐烂的苹果就继续模拟。

为什么正确

交换论证

考虑任意一天，存在最早腐烂批次 A 和更晚腐烂批次 B。若某个最优方案今天吃 B，而之后某天才吃 A，那么交换这两次食用：今天吃 A，原来吃 A 的那天改吃 B。因为 B 的腐烂日不早于 A，B 在那天仍然可用，食用总数不变。

归纳到每一天

因此，总能把某个最优方案当天的选择替换成最早腐烂批次，而不降低答案。逐天做同样交换，就得到与算法完全相同的选择序列，所以该贪心算法达到最大食用数量。

复杂度

设总共模拟 D 天，最多有 n 个批次入堆。每批只入堆、出堆一次，时间复杂度为 O((n + D) log n)；空间复杂度为 O(n)。在本题约束下，逐日模拟足够。

边界情况

  • 当天无产出：不入堆。
  • 多批同日腐烂：吃任意一批都等价。
  • 腐烂日等于今天：必须先清理，不能吃。
  • 前 n 天结束：仍要处理堆中库存。
  • 全部为 0：答案为 0。

替代方案

可以用有序映射按腐烂日维护数量，也能快速找到最早日期，但实现和常数通常比小根堆更重。每天扫描所有批次寻找最早腐烂项会退化为 O(nD)，无法适应上限。

import java.util.PriorityQueue;

class Solution {
    public int eatenApples(int[] apples, int[] days) {
        // [腐烂日, 剩余数量]
        PriorityQueue<int[]> heap =
            new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));
        int day = 0;
        int eaten = 0;

        while (day < apples.length || !heap.isEmpty()) {
            if (day < apples.length && apples[day] > 0) {
                heap.offer(new int[] {day + days[day], apples[day]});
            }

            while (!heap.isEmpty() && heap.peek()[0] <= day) {
                heap.poll();
            }

            if (!heap.isEmpty()) {
                int[] batch = heap.peek();
                batch[1]--;
                eaten++;
                if (batch[1] == 0) heap.poll();
            }
            day++;
        }
        return eaten;
    }
}

var eatenApples = function(apples, days) {
    const heap = [];

    const swap = (i, j) => {
        [heap[i], heap[j]] = [heap[j], heap[i]];
    };
    const push = (item) => {
        heap.push(item);
        let i = heap.length - 1;
        while (i > 0) {
            const parent = (i - 1) >> 1;
            if (heap[parent][0] <= heap[i][0]) break;
            swap(parent, i);
            i = parent;
        }
    };
    const pop = () => {
        const top = heap[0];
        const last = heap.pop();
        if (heap.length > 0) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let smallest = i;
                const left = i * 2 + 1;
                const right = left + 1;
                if (left < heap.length && heap[left][0] < heap[smallest][0]) smallest = left;
                if (right < heap.length && heap[right][0] < heap[smallest][0]) smallest = right;
                if (smallest === i) break;
                swap(i, smallest);
                i = smallest;
            }
        }
        return top;
    };

    let day = 0;
    let eaten = 0;
    while (day < apples.length || heap.length > 0) {
        if (day < apples.length && apples[day] > 0) {
            push([day + days[day], apples[day]]);
        }
        while (heap.length > 0 && heap[0][0] <= day) pop();

        if (heap.length > 0) {
            heap[0][1]--;
            eaten++;
            if (heap[0][1] === 0) pop();
        }
        day++;
    }
    return eaten;
};
from typing import List
import heapq


class Solution:
    def eatenApples(self, apples: List[int], days: List[int]) -> int:
        # (腐烂日, 剩余数量)
        heap = []
        day = 0
        eaten = 0

        while day < len(apples) or heap:
            if day < len(apples) and apples[day] > 0:
                heapq.heappush(heap, (day + days[day], apples[day]))

            while heap and heap[0][0] <= day:
                heapq.heappop(heap)

            if heap:
                expire, count = heapq.heappop(heap)
                eaten += 1
                if count > 1:
                    heapq.heappush(heap, (expire, count - 1))

            day += 1

        return eaten
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int eatenApples(vector<int>& apples, vector<int>& days) {
        // {腐烂日, 剩余数量}
        priority_queue<pair<int, int>,
                       vector<pair<int, int>>,
                       greater<pair<int, int>>> heap;
        int day = 0;
        int eaten = 0;

        while (day < static_cast<int>(apples.size()) || !heap.empty()) {
            if (day < static_cast<int>(apples.size()) && apples[day] > 0) {
                heap.push({day + days[day], apples[day]});
            }

            while (!heap.empty() && heap.top().first <= day) {
                heap.pop();
            }

            if (!heap.empty()) {
                auto [expire, count] = heap.top();
                heap.pop();
                eaten++;
                if (count > 1) heap.push({expire, count - 1});
            }
            day++;
        }
        return eaten;
    }
};

常见错误

  • 把腐烂日误写成 day + days[day] - 1，又用错误的比较条件。
  • 先吃再删除过期批次，导致吃到今天已腐烂的苹果。
  • 循环只执行前 n 天，漏掉后续库存。
  • 堆中数量归零后没有删除。
  • 按数量最多而不是腐烂日最早来选。
