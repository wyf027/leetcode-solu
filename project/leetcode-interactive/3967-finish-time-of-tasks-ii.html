任务完成时间 II

换一个根，父子关系就会改变。关键是把每条边两侧的“完成时间”都作为一条可复用的有向消息。

题意

给定一棵含 n 个任务的无向树 edges 与每个任务自己的时长 baseTime。任选一个节点作根。叶子的完成时间为自己的 baseTime；非叶子若孩子完成时间的最小、最大值为 mn、mx，则它的完成时间为 mx + (mx - mn) + baseTime[u]。返回所有根中最小的根完成时间。

示例 1
n = 3, edges = [[0,1],[1,2]], baseTime = [9,1,5]
输出：14。根取 1 时，孩子值为 9、5。
约束
1 ≤ n ≤ 10^5
1 ≤ baseTime[i] ≤ 10^5；edges 是一棵树。

交互分步可视化

样例链 0 — 1 — 2。先自底向上得到孩子消息，再把“排除当前孩子后的父侧消息”传回去。

核心洞察：有向边消息

定义 msg(x → y) 为删掉边 (x,y) 后，包含 x 的那一侧以 x 为根时的完成时间。节点 u 只要收齐每个邻居 v 的 msg(v → u)，就能计算把 u 作为根的答案。

combine(u, values) = baseTime[u]，若 values 非空则 baseTime[u] + 2 × max(values) − min(values)

完整过程

  1. 1. 任选 0 为暂定根，后序 DFS 得到每个子树的 down[child] = msg(child → parent)。
  2. 2. 前序 DFS 时，节点收集父侧 up[u] 和全部子侧 down。
  3. 3. 一次扫描记录最小值、次小值及最大值、次大值和出现次数；排除某个孩子后即可 O(1) 算出 msg(u → child)。

边界、替代与错误

没有可用邻居消息时必须返回 baseTime[u]；相同最值不能误用次值。逐个换根重算是 O(n²)，而重根 DP 是 O(n)。常见错误是忘记“排除正在下传的孩子”或用 int 溢出。
