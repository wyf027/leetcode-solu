题意

给定字符串 s，它表示一个语法有效的整数算术表达式。计算并返回表达式的值。表达式可以包含非负整数、空格、圆括号，以及加、减、乘、除四种运算符。

乘除优先于加减，括号优先级最高；除法只保留整数部分，并向零截断。提交时不能直接调用语言内置的表达式求值函数，例如 eval。

约束

  • 1 ≤ s.length ≤ 10⁴
  • s 由数字、空格、+ - * / ( ) 组成。
  • 输入表达式语法有效，括号成对且顺序正确。
  • 所有中间结果与最终结果均在 32 位有符号整数范围内。
  • 函数形式：calculate(s: string): integer。

    04 / SOLUTION

    让语法层级承担优先级

    不必手写一堆“遇到哪个符号怎么办”的分支；把表达式拆成三个层级，每层只处理自己负责的运算符。

    核心洞察

    递归下降解析器直接对应运算优先级：表达式层处理加减，项层处理乘除，因子层处理数字、括号和一元正负号。高优先级函数先返回完整结果，低优先级函数再归并。

    一个共享指针 i 从左到右只走一遍。读到左括号时递归计算括号内部，读到右括号时把控制权交还上一层。

    对应文法

    expression := term (('+' | '-') term)* term := factor (('*' | '/') factor)* factor := number | '(' expression ')' | ('+' | '-') factor

    完整过程

    1. 跳过空格。每个解析函数在观察下一个有效字符前移动共享指针。
    2. 解析因子。数字就连续读取全部位；左括号就递归解析一段完整表达式，再消费右括号；一元正负号则递归作用于下一个因子。
    3. 解析项。先拿到一个因子，再持续吸收后续的乘法或除法。除法使用向零截断。
    4. 解析表达式。先拿到一个项，再持续吸收后续的加法或减法。遇到右括号或字符串末尾时返回。
    5. 返回顶层结果。顶层表达式结束后，共享指针应抵达输入末尾，累积值就是答案。

    正确性证明

    引理 1：factor 返回一个完整因子的值

    数字分支读取整个十进制数；括号分支由 expression 正确求出括号内结果并消费配对右括号；一元运算分支把符号正确作用于紧随其后的完整因子。因此三种合法形态都被正确处理。

    引理 2：term 返回一个完整项的值

    由引理 1，第一个及后续 factor 均正确。term 按从左到右顺序只归并乘除，直到下一个字符不再是乘除号，所以恰好得到该项的值，并满足乘除同级左结合。

    引理 3：expression 返回一个完整表达式的值

    由引理 2，每个 term 已包含所有高优先级乘除。expression 再从左到右归并加减，直到右括号或输入末尾，因此加减不会越过括号，也不会抢在乘除之前执行。

    定理：算法返回题目表达式的正确结果

    顶层调用解析完整 expression。由引理 3，其返回值遵守括号、乘除、加减的全部优先级与结合规则；合法输入被完整消费，所以返回值就是目标结果。

    时间复杂度 O(n)

    共享指针单向移动，每个字符只被常数次查看或消费。

    空间复杂度 O(d)

    d 是括号与一元运算造成的最大递归深度；不计返回结果。

    边界情况

    • 表达式只有一个多位整数，或在数字、运算符、括号周围包含空格。
    • 连续嵌套括号，例如 ((2+3))。
    • 除法结果为负数时仍须向零截断，不能用数学意义上的向下取整替代。
    • 一元符号出现在开头或左括号之后，例如 -(2+3)；实现显式覆盖这一语义。
    • 左结合不能被破坏：8/4/2 应解释为 (8/4)/2。

    class Solution {
    private String s;
    private int index;

    public int calculate(String s) {
        this.s = s;
        this.index = 0;
        return parseExpression();
    }

    private int parseExpression() {
        int value = parseTerm();

        while (true) {
            skipSpaces();
            if (index >= s.length() || s.charAt(index) == ')') {
                return value;
            }

            char operator = s.charAt(index);
            if (operator != '+' && operator != '-') {
                return value;
            }

            index++;
            int right = parseTerm();
            value = operator == '+' ? value + right : value - right;
        }
    }

    private int parseTerm() {
        int value = parseFactor();

        while (true) {
            skipSpaces();
            if (index >= s.length()) {
                return value;
            }

            char operator = s.charAt(index);
            if (operator != '*' && operator != '/') {
                return value;
            }

            index++;
            int right = parseFactor();
            value = operator == '*' ? value * right : value / right;
        }
    }

    private int parseFactor() {
        skipSpaces();

        if (s.charAt(index) == '+' || s.charAt(index) == '-') {
            char sign = s.charAt(index++);
            int value = parseFactor();
            return sign == '-' ? -value : value;
        }

        if (s.charAt(index) == '(') {
            index++;
            int value = parseExpression();
            skipSpaces();
            index++;
            return value;
        }

        int value = 0;
        while (index < s.length() && Character.isDigit(s.charAt(index))) {
            value = value * 10 + (s.charAt(index) - '0');
            index++;
        }
        return value;
    }

    private void skipSpaces() {
        while (index < s.length() && s.charAt(index) == ' ') {
            index++;
        }
    }
}
    var calculate = function (s) {
  let index = 0;

  const skipSpaces = () => {
    while (index < s.length && s[index] === " ") index++;
  };

  const parseFactor = () => {
    skipSpaces();

    if (s[index] === "+" || s[index] === "-") {
      const sign = s[index++];
      const value = parseFactor();
      return sign === "-" ? -value : value;
    }

    if (s[index] === "(") {
      index++;
      const value = parseExpression();
      skipSpaces();
      index++;
      return value;
    }

    let value = 0;
    while (index < s.length && /[0-9]/.test(s[index])) {
      value = value * 10 + Number(s[index]);
      index++;
    }
    return value;
  };

  const parseTerm = () => {
    let value = parseFactor();

    while (true) {
      skipSpaces();
      const operator = s[index];
      if (operator !== "*" && operator !== "/") return value;

      index++;
      const right = parseFactor();
      value = operator === "*" ? value * right : Math.trunc(value / right);
    }
  };

  const parseExpression = () => {
    let value = parseTerm();

      skipSpaces();
      const operator = s[index];
      if (operator !== "+" && operator !== "-") return value;

      index++;
      const right = parseTerm();
      value = operator === "+" ? value + right : value - right;

    class Solution:
    def calculate(self, s: str) -> int:
        self.s = s
        self.index = 0
        return self.parse_expression()

    def parse_expression(self) -> int:
        value = self.parse_term()

        while True:
            self.skip_spaces()
            if self.index == len(self.s) or self.s[self.index] == ")":
                return value

            operator = self.s[self.index]
            if operator not in "+-":
                return value

            self.index += 1
            right = self.parse_term()
            value = value + right if operator == "+" else value - right

    def parse_term(self) -> int:
        value = self.parse_factor()

        while True:
            self.skip_spaces()
            if self.index == len(self.s):
                return value

            operator = self.s[self.index]
            if operator not in "*/":
                return value

            self.index += 1
            right = self.parse_factor()
            if operator == "*":
                value *= right
            else:
                quotient = abs(value) // abs(right)
                value = -quotient if (value < 0) != (right < 0) else quotient

    def parse_factor(self) -> int:
        self.skip_spaces()

        if self.s[self.index] in "+-":
            sign = self.s[self.index]
            self.index += 1
            value = self.parse_factor()
            return -value if sign == "-" else value

        if self.s[self.index] == "(":
            self.index += 1
            value = self.parse_expression()
            self.skip_spaces()
            self.index += 1
            return value

        value = 0
        while self.index < len(self.s) and self.s[self.index].isdigit():
            value = value * 10 + int(self.s[self.index])
            self.index += 1
        return value

    def skip_spaces(self) -> None:
        while self.index < len(self.s) and self.s[self.index] == " ":
            self.index += 1

private:
    string expression;
    int index = 0;

    void skipSpaces() {
        while (index < expression.size() && expression[index] == ' ') {
            index++;
        }
    }

    int parseFactor() {
        skipSpaces();

        if (expression[index] == '+' || expression[index] == '-') {
            char sign = expression[index++];
            int value = parseFactor();
            return sign == '-' ? -value : value;
        }

        if (expression[index] == '(') {
            index++;
            int value = parseExpression();
            skipSpaces();
            index++;
            return value;
        }

        int value = 0;
        while (index < expression.size() && isdigit(expression[index])) {
            value = value * 10 + expression[index] - '0';
            index++;
        }
        return value;
    }

    int parseTerm() {
        int value = parseFactor();

        while (true) {
            skipSpaces();
            if (index == expression.size()) return value;

            char operatorSymbol = expression[index];
            if (operatorSymbol != '*' && operatorSymbol != '/') return value;

            index++;
            int right = parseFactor();
            value = operatorSymbol == '*' ? value * right : value / right;
        }
    }

    int parseExpression() {
        int value = parseTerm();

        while (true) {
            skipSpaces();
            if (index == expression.size() || expression[index] == ')') {
                return value;
            }

            char operatorSymbol = expression[index];
            if (operatorSymbol != '+' && operatorSymbol != '-') return value;

            index++;
            int right = parseTerm();
            value = operatorSymbol == '+' ? value + right : value - right;
        }
    }

    替代方案

    • 双栈 / 调度场算法：用数字栈和运算符栈显式比较优先级，适合后续扩展更多运算符，但括号与一元符号的状态处理更繁琐。
    • 单栈按括号递归：在每一层延迟处理加减、立即折叠乘除，也能达到 O(n)；代码较短，但语法层级没有递归下降直观。
    • 转后缀表达式再求值：结构清晰且适合重复执行，但需要额外的 token 序列与第二遍扫描。

    常见错误

    • 把整个字符串按运算符切分，导致括号深度和优先级信息丢失。
    • Python 直接使用 //，负数会向下取整而不是向零截断。
    • 读到右括号后没有停止当前 expression，意外把括号外内容也算进去。
    • 只读取一位数字，或跳过空格后忘记再次检查字符串边界。
    • 用浮点数承载中间值，带来不必要的精度风险。

    面试追问

    如果加入幂运算 ^ 呢？

    增加比 factor 更高的 power 层，并注意幂通常是右结合，递归方向与四则运算不同。

    如何避免极深括号造成递归栈溢出？

    改用显式的数字栈与运算符栈，或手动维护解析帧，把调用栈转为堆上结构。

    怎样报告非法表达式的位置？

    让每个解析函数在预期 token 缺失时抛出包含 index、期望集合和上下文的结构化错误。

    怎样扩展变量和函数调用？

    先加入词法分析，把字符流转成 token 流；factor 再识别标识符、参数列表，并通过环境表解析值。
