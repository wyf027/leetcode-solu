05 / 独立题解

准备好后，再查看推导与实现。

核心洞察

每行独立决定是否入选，无须 JOIN 或 GROUP BY。对于总票数大于零的非负票数，L / (L + D) < 3 / 5 等价于 5L < 3L + 3D，即 2L < 3D。用整数比较避开整除截断和浮点边界。

完整过程

  1. 扫描 Problems，每行取 likes 与 dislikes。
  2. 用放宽后的数值类型判断 2 × likes 是否严格小于 3 × dislikes。
  3. 保留符合条件的 problem_id；其余行不输出。
  4. 按 problem_id 升序排序，仅返回该列。

示例按输入顺序收集为 [11, 7, 13, 10]，排序后得到 [7, 10, 11, 13]。

正确性

总票数为正时，不等式两侧乘正数不会改变方向，因此乘法判定与原喜欢率定义充要等价。WHERE 恰好保留所有且仅有符合定义的行。主键确保结果不重复；ORDER BY 保证题号升序，SELECT 保证列结构符合要求。零票不在比例推导范围内，代码中的 0 < 0 为假，对应本地跳过约定。

边界与复杂度

60% 必须排除；仅点踩则入选，仅点赞则排除。空表自然返回空结果。MySQL 查询先转 DECIMAL 再乘法，避免 int 中间值溢出。设输入 n 行、入选 k 行：常规扫描 O(n)，排序 O(k log k)，总计 O(n + k log k)。本地实现使用 O(k) 结果空间；数据库排序空间与索引、执行计划有关，不能保证固定 O(1)。

替代方案

也可以用比例表达式 WHERE 1.0 * likes / NULLIF(likes + dislikes, 0) < 0.6；跨数据库时要检查整数除法、加法溢出和数值类型。若采用此方案，大整数应先转宽类型再相加。乘法方案更容易精确处理 60% 边界。无需聚合或窗口函数。

常见错误

  • 把 < 写成 <=，误收恰好 60% 的题。
  • 用 likes / dislikes，把分母写错。
  • 先四舍五入喜欢率再判断，使接近阈值的记录被错误分类。
  • 忘记 ORDER BY，依赖表的读取顺序。
  • 在窄整数里先乘法，再转换类型；转换时溢出已经发生。

面试追问

阈值变成 a/b？ 用 (b − a)L < aD，要求 b > 0、总票数正，并检查乘法范围。数据变为逐条投票日志？ 先按题号聚合票数，再筛选。能否只建题号索引？ 可能减少排序成本，但比例过滤通常仍要读取票数，须结合执行计划讨论。

完整代码

本题是数据库题，优先提交 MySQL SQL。以下 Java、JavaScript、Python、C++ 仅是本地语义参考，输入为三列行数组，输出为升序 ID 列表；不是本题官方函数签名，也不声称能直接提交。

MySQL · 官方可提交语言

SELECT problem_id
FROM Problems
WHERE CAST(likes AS DECIMAL(20, 0)) * 2
    < CAST(dislikes AS DECIMAL(20, 0)) * 3
ORDER BY problem_id ASC;

Java · 本地语义参考

import java.util.*;
class Solution {
    // rows: [problem_id, likes, dislikes]，非负 int 票数
    public List<Integer> lowQualityProblems(int[][] rows) {
        List<Integer> result = new ArrayList<>();
        for (int[] row : rows) {
            if (2L * row[1] < 3L * row[2]) result.add(row[0]);
        }
        Collections.sort(result);
        return result;
    }
}

// rows: [problem_id, likes, dislikes]，票数为非负 int
function lowQualityProblems(rows) {
  return rows
    .filter(([, likes, dislikes]) => 2n * BigInt(likes) < 3n * BigInt(dislikes))
    .map(([id]) => id)
    .sort((a, b) => a - b);
}

Python · 本地语义参考

def low_quality_problems(rows):
    """rows: iterable of (problem_id, likes, dislikes)."""
    return sorted(problem_id for problem_id, likes, dislikes in rows
                  if 2 * likes < 3 * dislikes)

C++ · 本地语义参考

#include <algorithm>
#include <array>
#include <vector>
using namespace std;
class Solution {
public:
    vector<int> lowQualityProblems(const vector<array<int, 3>>& rows) {
        vector<int> result;
        for (const auto& row : rows) {
            if (2LL * row[1] < 3LL * row[2]) result.push_back(row[0]);
        }
        sort(result.begin(), result.end());
        return result;
    }
};
