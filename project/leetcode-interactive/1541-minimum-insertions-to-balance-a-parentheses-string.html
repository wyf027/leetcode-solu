Minimum Insertions to Balance a Parentheses String

Problem

题目说明

给定只含 ( 与 ) 的字符串 s。若每个左括号都位于与它匹配的两个连续右括号 )) 之前，则字符串平衡；也就是把 ( 看作开启符，把 )) 看作关闭符。你可以在任意位置插入左右括号，请返回使 s 平衡所需的最少插入次数。

1

成对关闭

一个 ( 恰好需要后续连续的 ))。

2

顺序固定

开启的 ( 必须出现在对应的 )) 之前。

官方示例

示例 1
输入：s = "(()))"
输出：1
解释：末尾补一个 ')'，得到 "(())))"。
示例 2
输入：s = "())"
输出：0
解释：原字符串已经平衡。
示例 3
输入：s = "))())("
输出：3
解释：为开头的 '))' 补 '('，并为末尾的 '(' 补 '))'。
示例 4
输入：s = "(((((("
输出：12
解释：需要插入 12 个 ')'。
示例 5
输入：s = ")))))))"
输出：5
解释：补 4 个 '('，并补 1 个 ')'。

约束

  • 1 <= s.length <= 10^5
  • s 只包含 ( 和 )。

Solution

贪心：维护尚欠的右括号数

核心洞察

扫描到任意前缀时，用 need 表示已有左括号仍需要多少个 )。每个 ( 新增 2 笔债务，每个 ) 偿还 1 笔。因为关闭符必须是连续的 ))，在开始新的 ( 前，旧债务不能是奇数。

完整过程

  1. 初始化 insertions = 0、need = 0。
  2. 遇到 (：若 need 为奇数，说明前一个关闭组只收到了一个 )，必须先插入一个 )；随后为新左括号令 need += 2。
  3. 遇到 )：令 need--。若变成负数，当前右括号没有可匹配的左括号，立即在它前面插入一个 (，此时当前 ) 是所需两个右括号中的第一个，所以令 need = 1。
  4. 扫描结束后，剩余的 need 就是必须追加的右括号数，答案为 insertions + need。

正确性

不变量：处理完每个前缀后，need >= 0，且在下一次开启新组前，未完成关闭组的结构保持可行。

无可匹配左括号时插入 ( 是唯一能让当前 ) 合法的操作；奇数债务前遇到 ( 时插入 ) 是保持 )) 连续的唯一操作。这两类插入都不可避免。结尾的每笔债务也各需一个 ) 偿还，因此贪心结果达到下界，即为最少插入次数。

复杂度

时间复杂度 O(n)：只扫描一次字符串。

空间复杂度 O(1)：只维护两个整数，不需要真实栈。

边界

单个 ( 需补 2；单个 ) 需补一个 ( 和一个 )；全左括号答案为长度的两倍；连续奇数个右括号会留下半个关闭组。

替代方案

可以使用栈记录未匹配的左括号，并把连续右括号分组处理，逻辑更贴近题意，但需要 O(n) 空间。由于栈中元素只用于计数，最终可压缩为这里的常量空间贪心。

四语言完整代码

Java
class Solution {
    public int minInsertions(String s) {
        int insertions = 0;
        int need = 0;

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == '(') {
                if ((need & 1) == 1) {
                    insertions++;
                    need--;
                }
                need += 2;
            } else {
                need--;
                if (need < 0) {
                    insertions++;
                    need = 1;
                }
            }
        }
        return insertions + need;
    }
}

常见错误

  • 把普通括号平衡问题的 balance 直接套用，忘记一次关闭需要两个连续右括号。
  • 在 need 为奇数时直接读取新的 (，破坏 )) 的连续性。
  • need < 0 时修复后写成 2；当前 ) 已经偿还一笔，因此应设为 1。
  • 返回插入计数时漏加扫描结束后的 need。
