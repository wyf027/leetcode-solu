让两棵树从根开始对齐：同一位置的节点相遇时合并数值，只有一侧存在时保留该节点。先理解任务，再用下面的逐步视图观察每个位置发生了什么。

题目要求

函数：mergeTrees(root1, root2)

给定两棵二叉树 root1 和 root2。将它们从根节点开始覆盖：若同一位置上两个节点都存在，新节点值为两者之和；若只有一个节点存在，则该非空节点成为合并树在该位置的节点。

返回合并后的二叉树。两棵树必须从各自的根开始对齐，不能平移或重新排列节点。

返回形式
输入参数：root1: TreeNode、root2: TreeNode
返回值：TreeNode

约束

  • 两棵树中的节点总量各自在 [0, 2000] 范围内。
  • -10⁴ ≤ Node.val ≤ 10⁴。
  • 空树用 null 表示。

Complete solution

递归：让函数定义直接对应合并规则

核心洞察

一棵树的合并结果，等于“合并当前根”加上“分别合并左右子树”。题目规则本身已经给出了递归定义。

递归出口

任一节点为空时，当前位置没有相加动作，直接返回另一侧节点即可。两侧都为空也自然返回 null。

完整过程

  1. 若 root1 == null，返回 root2；若 root2 == null，返回 root1。
  2. 两者都存在时，把 root2.val 加到 root1.val，让 root1 充当合并结果的当前节点。
  3. 递归合并两棵树的左子树，把返回值接到 root1.left。
  4. 递归合并两棵树的右子树，把返回值接到 root1.right，最后返回 root1。

这份实现会原地更新第一棵树；当一侧为空时，直接复用另一侧整棵非空子树。因此空间开销不包含重新复制所有节点的成本。若业务要求输入不可变，见后面的替代方案。

正确性证明

命题：mergeTrees(a, b) 返回的树，在每个位置都满足题目定义的合并规则。

基础情形：若 a 为空，函数返回 b；若 b 为空，函数返回 a。这正是“只有一个节点存在时保留非空节点”的规则。两者都为空时返回空，同样正确。

归纳步骤：设两节点都非空。函数先将当前节点值设为 a.val + b.val，满足当前位置的重叠规则。根据归纳假设，两次递归分别正确生成左、右子树的合并结果。把它们连接到当前节点后，以当前节点为根的整棵树在所有位置均满足规则。

结论：由结构归纳，函数对任意两棵二叉树都返回正确的合并树。

复杂度

  • 时间：O(min(n₁, n₂))，递归只继续深入两边都存在的重叠区域；在一侧为空的边界会直接返回。宽松上界为 O(n₁ + n₂)。
  • 辅助空间：O(min(h₁, h₂))，来自递归调用栈；最坏退化链上可达较小树的高度。

必须覆盖的边界

  • 两棵树都为空。
  • 只有一棵树为空。
  • 树高差异很大，非重叠子树要完整保留。
  • 节点值为负数、零或合并后为零。
  • 树退化成链，递归栈深度增加。

四种语言的完整实现

以下代码遵循官方函数签名，均采用“更新 root1 并复用单侧非空子树”的递归策略。

Java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode mergeTrees(TreeNode root1, TreeNode root2) {
        if (root1 == null) return root2;
        if (root2 == null) return root1;

        root1.val += root2.val;
        root1.left = mergeTrees(root1.left, root2.left);
        root1.right = mergeTrees(root1.right, root2.right);
        return root1;
    }
}

替代方案

迭代 BFS

用队列保存成对节点。每次相加后，分别处理左右孩子：两边都存在就入队；第一棵缺少而第二棵存在，就把第二棵对应子树接过来。它避免递归栈溢出，时间量级相同，但分支和状态管理更多。

不可变合并

每个位置都创建新节点，并递归克隆单侧非空子树。这样完全不修改输入，但时间和新节点空间均为 O(n₁ + n₂)。

常见错误

  • 任一节点为空就返回 null，导致单侧子树丢失。
  • 只相加根节点，忘记把递归返回值接回左右孩子。
  • 误以为要按层序数组下标直接相加；数组中的 null 会改变真实结构。
  • 复用节点却宣称输入树保持不变。
  • 把节点值限制成正数，忽略合法负值。

面试追问

如果不能修改输入树？

改为始终创建新节点；一侧为空时也要深拷贝另一侧子树，避免结果与输入共享引用。

极深的退化树怎么办？

改用显式队列或栈的迭代写法，规避语言递归深度限制。

如何扩展到多棵树？

可以依次两两合并；若必须保持输入不可变，则为每个位置汇总存在节点的值并构造新树。

DFS 与 BFS 如何选择？

两者渐进复杂度相近。递归 DFS 更贴合结构定义；BFS 的控制流更显式，适合担心栈深或需要逐层处理的场景。
