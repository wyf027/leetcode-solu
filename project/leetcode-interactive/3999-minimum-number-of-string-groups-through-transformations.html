字符串变换后的
最少分组数

把每个字符串的偶数下标与奇数下标拆开；两条“环”可独立右移。每条环取字典序最小循环表示，二元规范形相同即属于同一组。

O(Σ|s|)Booth 线性规范化
2 条环奇偶位置彼此独立
HashSet规范形的不同个数

题意

给定字符串数组 words。一次变换中，先取字符串偶数下标字符组成序列 E，取奇数下标字符组成序列 O；分别将 E、O 循环右移任意次数（可为 0），再放回原来的奇偶位置。

若两个字符串能经过一次这样的变换互相得到，则它们等价。将所有字符串划分为若干组，使每组内任意两串等价；返回最少组数。

示例

words = ["ntgwz", "zwntg"]
对 "ntgwz"：E = "ngz"、O = "tw"。两者各右移 1 位得到 "zng" 与 "wt"，交织回 "zwntg"，答案为 1。
words = ["abc", "cab", "bac", "acb", "bca", "cba"]，答案 3。

约束

  • 1 ≤ words.length ≤ 10⁵
  • 1 ≤ words[i].length ≤ 5 × 10⁵
  • Σ words[i].length ≤ 5 × 10⁵，仅含小写字母。

题解

默认收起，避免首屏直接泄露解法。

核心洞察：等价类的唯一标签

一次变换不会让偶数位置与奇数位置交换，因此可分别处理。循环移位的所有结果中，取字典序最小者作为该序列的 canonical rotation。两个串等价，当且仅当它们的 canonical(E) + "#" + canonical(O) 完全相同。分隔符确保 ("ab","c") 不会和 ("a","bc") 混淆。

完整过程

  1. 遍历每个单词，按下标奇偶拆成 E、O。
  2. 用 Booth 算法在 E+E 中找到最小循环起点；O 同理。空串规范形为 ""。
  3. 将两段规范形以不可出现在输入中的分隔符连接，放进哈希集合。
  4. 集合大小就是最少组数。

边界与复杂度

  • 长度为 1 时，奇数序列为空；仍应保留分隔符。
  • 重复字符时存在多个最小旋转，任取相同字符串即可。
  • Booth 对每段线性运行：总时间 O(Σ|words[i]|)，额外空间 O(Σ|words[i]|)（集合键）。

替代方案、面试追问与常见错误

短字符串可枚举每个旋转取最小值，但最坏 O(L²) 会超时。面试可追问：若只允许同时移动两条序列，规范形应改成配对旋转而非独立规范化。常见错误是把整串旋转、忘了空的奇数序列，或用无分隔符拼键。
