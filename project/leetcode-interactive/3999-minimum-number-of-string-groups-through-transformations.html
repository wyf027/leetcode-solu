Problem statement

题意

给定字符串数组 words。对一个字符串进行一次变换时，先取出偶数下标字符形成子序列 E，再取出奇数下标字符形成子序列 O；两者可以独立循环右移任意位（含 0 位），最后放回各自的奇偶下标。

若一个字符串能通过一次这样的变换得到另一个字符串，则二者等价。请把所有字符串分入最少数量的组，使同组内任意两个字符串都等价。

  • words[i] 仅包含小写英文字母

Core insight

核心洞察

一次变换不会混合奇偶位置：偶数位子序列只能做循环移位，奇数位子序列也只能做循环移位。因此两个字符串等价，当且仅当它们的偶数位子序列互为循环移位，并且奇数位子序列也互为循环移位。

为每条子序列选定唯一代表——字典序最小循环表示。用 Booth 算法在线性时间求出它。一个单词的签名就是 (minRotation(E), minRotation(O))；相同签名恰好对应同一个等价类，所以最少分组数就是不同签名数量。

Complete process

完整过程

  1. SPLIT

    拆成双轨

    遍历单词，下标为偶数的字符进入 E，下标为奇数的字符进入 O。

  2. ROTATE

    求最小循环表示

    对 E、O 分别运行 Booth；用两个候选起点 i、j 一次淘汰一段不可能成为最优的起点。

  3. SIGN

    组合唯一签名

    将两条规范串用不属于小写字母的分隔符组合，保留两部分边界。

  4. COUNT

    统计不同签名

    把签名放入哈希集合，集合大小即最少分组数。

Correctness

为什么签名充要

同一循环轨道上的所有字符串拥有相同最小表示；反之最小表示相同，二者都能旋转到该表示，因而互为循环移位。奇偶两轨同时成立，恰好对应一次合法变换。

Complexity

复杂度

设所有字符串总长度为 L。拆分、两次 Booth 与哈希均为 O(L) 期望时间；签名集合及临时字符串占 O(L) 空间。

Boundary

边界

长度 1 时 O 为空；重复单词签名相同；不同长度不可能签名相同；全相同字符的任意旋转仍为自身；总长度上限要求线性算法。

替代方案取舍

枚举所有旋转

对长度 m 的子序列生成 m 个长度 m 的旋转需要 O(m²)，在总长度 5 × 10⁵ 时不可行，只适合小规模对拍。

Duval 最小表示

同样可在线性时间求最小循环表示，常数优秀；但 Booth 的双候选淘汰更便于面试解释与交互演示。

后缀数组 / 后缀自动机

可以在双倍字符串上寻找合法起点，但实现复杂、常数和出错面更大，超出本题所需。

面试追问

  • 为何是“最少组数 = 等价类数”？
    合法组不能混入不同签名，而相同签名的全部字符串可以放进一个组。
  • 一次变换足够连接任意同签名字符串吗？
    足够。两条子序列都可独立选择任意右移量，直接从源旋到目标。
  • 哈希碰撞怎么办？
    集合实际存完整规范串，语言运行库会在哈希相等后继续比较字符串内容。

常见错误

  • • 把奇偶子序列合在一起求旋转，破坏独立移动规则。
  • • 只比较字符计数；循环顺序不同仍可能不等价。
  • • 用排序作为规范化，错误忽略相对顺序。
  • • Booth 更新 i 或 j 后忘记令 k 归零。
  • • 拼接签名时没有安全分隔符，产生边界歧义。
  • • 枚举所有旋转，时间退化到 O(L²)。

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minimumGroups(String[] words) {
        Set<String> signatures = new HashSet<>();

        for (String word : words) {
            StringBuilder even = new StringBuilder();
            StringBuilder odd = new StringBuilder();
            for (int index = 0; index < word.length(); index++) {
                (index % 2 == 0 ? even : odd).append(word.charAt(index));
            }
            signatures.add(minRotation(even.toString()) + "#" + minRotation(odd.toString()));
        }
        return signatures.size();
    }

    private String minRotation(String s) {
        int n = s.length();
        if (n <= 1) return s;

        String doubled = s + s;
        int i = 0, j = 1, k = 0;
        while (i < n && j < n && k < n) {
            char left = doubled.charAt(i + k);
            char right = doubled.charAt(j + k);
            if (left == right) {
                k++;
            } else if (left > right) {
                i = i + k + 1;
                if (i == j) i++;
                k = 0;
            } else {
                j = j + k + 1;
                if (i == j) j++;
                k = 0;
            }
        }
        int start = Math.min(i, j);
        return doubled.substring(start, start + n);
    }
}

from typing import List


class Solution:
    def minimumGroups(self, words: List[str]) -> int:
        signatures = set()

        for word in words:
            even = word[::2]
            odd = word[1::2]
            signatures.add((self.min_rotation(even), self.min_rotation(odd)))

        return len(signatures)

    def min_rotation(self, s: str) -> str:
        n = len(s)
        if n <= 1:
            return s

        doubled = s + s
        i, j, k = 0, 1, 0
        while i < n and j < n and k < n:
            left, right = doubled[i + k], doubled[j + k]
            if left == right:
                k += 1
            elif left > right:
                i = i + k + 1
                if i == j:
                    i += 1
                k = 0
            else:
                j = j + k + 1
                if i == j:
                    j += 1
                k = 0

        start = min(i, j)
        return doubled[start : start + n]
