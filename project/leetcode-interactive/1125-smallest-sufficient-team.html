最小的必要团队

Smallest Sufficient Team

从候选人中挑出尽可能少的成员，让项目要求的每项技能都至少由一人覆盖。答案返回成员下标，顺序不限。

困难 HARD免费题位掩码动态规划
先想一想：技能种类最多只有 16 个，如何把“已经覆盖哪些技能”压缩成一个整数？

题目说明

给定技能要求与候选人的技能清单，寻找人数最少且覆盖全部要求的团队。

准确转述

输入字符串数组 req_skills，以及二维字符串列表 people。people[i] 表示第 i 位候选人掌握的技能。

一个团队是“必要团队”，当且仅当 req_skills 中的每项技能都能在至少一位团队成员身上找到。返回任意一个人数最少的必要团队，用成员下标组成数组表示；下标顺序不限。题目保证答案存在。

函数形式

smallestSufficientTeam(req_skills: string[], people: string[][]): number[]

约束

  • 1 ≤ req_skills.length ≤ 16
  • 1 ≤ req_skills[i].length ≤ 16，且仅含小写英文字母
  • req_skills 内的字符串互不相同
  • 1 ≤ people.length ≤ 60
  • 0 ≤ people[i].length ≤ 16
  • 1 ≤ people[i][j].length ≤ 16，且仅含小写英文字母
  • 同一人的技能互不相同，并且都属于 req_skills
  • 保证至少存在一个必要团队
官方示例 1
输入：req_skills = ["java","nodejs","reactjs"], people = [["java"],["nodejs"],["nodejs","reactjs"]]
输出：[0,2]
官方示例 2
输入：req_skills = ["algorithms","math","java","reactjs","csharp","aws"], people = [["algorithms","math","java"],["algorithms","math","reactjs"],["java","csharp","aws"],["reactjs","csharp"],["csharp","math"],["aws","java"]]
输出：[1,2]

核心洞察：状态是技能集合，值是最小团队

最多 16 项技能，正好可以用一个整数的二进制位表示集合。令 dp[mask] 保存覆盖 mask 所需的当前最小成员下标数组。逐个处理候选人，从旧状态 mask 转移到 mask | personMask。

01 编号每项技能映射到一个 bit
02 压缩计算每位候选人的技能掩码
03 转移逐人更新可达覆盖状态
04 读取返回全技能掩码对应团队

完整过程

  1. 建立 skill → bit 映射，第 j 项要求对应 1 << j。
  2. 把每个人掌握的要求技能按位或起来，得到 personMask。
  3. 初始化 dp[0] = []，其余状态不可达。
  4. 处理某个人时，基于处理前的快照枚举所有可达状态。令 nextMask = mask | personMask；若原团队加上此人后，比 dp[nextMask] 更短，就替换。
  5. 所有人处理完后，dp[(1 << m) - 1] 就是任一最小必要团队。

每轮使用快照很重要：它清楚表达“每个人最多选择一次”，也避免在同一轮里反复把当前人加入团队。

正确性证明

不变式。处理完前 i 个人后，对于每个可达 mask，dp[mask] 是只从这 i 人中选择、覆盖恰好为该掩码（或其技能并集等于该掩码）的最小规模团队。
保持。处理第 i 人时，任一最优团队要么不选此人，原状态继续保留；要么选择此人，它必可写成旧状态团队加此人，并转移到 mask | personMask。两类候选取人数更小者，所以新表对所有状态仍最优。
终止。所有人均处理后，任何合法团队都由这些人组成，因而已被上述两类选择覆盖。全量掩码代表所有要求技能，故其记录团队覆盖全部技能且人数最少。

边界情况

  • 只有一项技能：返回任意一位掌握它的人。
  • 有人技能列表为空：其掩码为 0，不会产生更优状态。
  • 多人技能完全相同：DP 会自然保留人数更少的方案。
  • 一人掌握全部技能：全量状态会得到长度为 1 的答案。
  • 最小团队不唯一：题目允许返回其中任意一个。

复杂度

设技能数为 m、人数为 n。共有 2^m 个技能状态。转移次数为 O(n·2^m)；复制团队数组的长度最多为 m，因此按代码实现计为 O(n·2^m·m) 时间。

DP 表保存至多 2^m 个、长度至多 m 的团队，空间为 O(2^m·m)。

四语言完整代码

class Solution {
    public int[] smallestSufficientTeam(String[] req_skills,
                                        List<List<String>> people) {
        int m = req_skills.length;
        Map<String, Integer> bitOf = new HashMap<>();
        for (int i = 0; i < m; i++) {
            bitOf.put(req_skills[i], i);
        }

        @SuppressWarnings("unchecked")
        List<Integer>[] dp = new List[1 << m];
        dp[0] = new ArrayList<>();

        for (int i = 0; i < people.size(); i++) {
            int personMask = 0;
            for (String skill : people.get(i)) {
                personMask |= 1 << bitOf.get(skill);
            }
            if (personMask == 0) continue;

            List<Integer>[] before = dp.clone();
            for (int mask = 0; mask < before.length; mask++) {
                if (before[mask] == null) continue;
                int nextMask = mask | personMask;
                if (nextMask == mask) continue;
                if (dp[nextMask] == null ||
                    before[mask].size() + 1 < dp[nextMask].size()) {
                    List<Integer> team = new ArrayList<>(before[mask]);
                    team.add(i);
                    dp[nextMask] = team;
                }
            }
        }

        List<Integer> answer = dp[(1 << m) - 1];
        int[] result = new int[answer.size()];
        for (int i = 0; i < answer.size(); i++) result[i] = answer.get(i);
        return result;
    }
}

var smallestSufficientTeam = function(req_skills, people) {
    const m = req_skills.length;
    const bitOf = new Map();
    req_skills.forEach((skill, i) => bitOf.set(skill, i));

    let dp = Array(1 << m).fill(null);
    dp[0] = [];

    people.forEach((skills, person) => {
        let personMask = 0;
        for (const skill of skills) {
            personMask |= 1 << bitOf.get(skill);
        }
        if (personMask === 0) return;

        const before = dp.slice();
        const next = dp.slice();
        for (let mask = 0; mask < before.length; mask++) {
            if (before[mask] === null) continue;
            const nextMask = mask | personMask;
            if (nextMask === mask) continue;
            const candidate = [...before[mask], person];
            if (next[nextMask] === null ||
                candidate.length < next[nextMask].length) {
                next[nextMask] = candidate;
            }
        }
        dp = next;
    });

    return dp[(1 << m) - 1];
};
from typing import List


class Solution:
    def smallestSufficientTeam(
        self, req_skills: List[str], people: List[List[str]]
    ) -> List[int]:
        bit_of = {skill: i for i, skill in enumerate(req_skills)}
        full = (1 << len(req_skills)) - 1
        dp = [None] * (full + 1)
        dp[0] = []

        for person, skills in enumerate(people):
            person_mask = 0
            for skill in skills:
                person_mask |= 1 << bit_of[skill]
            if person_mask == 0:
                continue

            next_dp = dp.copy()
            for mask, team in enumerate(dp):
                if team is None:
                    continue
                next_mask = mask | person_mask
                if next_mask == mask:
                    continue
                candidate = team + [person]
                if next_dp[next_mask] is None or len(candidate) < len(next_dp[next_mask]):
                    next_dp[next_mask] = candidate
            dp = next_dp

        return dp[full]
class Solution {
public:
    vector<int> smallestSufficientTeam(
        vector<string>& req_skills,
        vector<vector<string>>& people
    ) {
        int m = req_skills.size();
        unordered_map<string, int> bitOf;
        for (int i = 0; i < m; ++i) bitOf[req_skills[i]] = i;

        vector<vector<int>> dp(1 << m);
        vector<char> reachable(1 << m, false);
        reachable[0] = true;

        for (int person = 0; person < (int)people.size(); ++person) {
            int personMask = 0;
            for (const string& skill : people[person]) {
                personMask |= 1 << bitOf[skill];
            }
            if (personMask == 0) continue;

            auto nextDp = dp;
            auto nextReachable = reachable;
            for (int mask = 0; mask < (1 << m); ++mask) {
                if (!reachable[mask]) continue;
                int nextMask = mask | personMask;
                if (nextMask == mask) continue;
                vector<int> candidate = dp[mask];
                candidate.push_back(person);
                if (!nextReachable[nextMask] ||
                    candidate.size() < nextDp[nextMask].size()) {
                    nextReachable[nextMask] = true;
                    nextDp[nextMask] = move(candidate);
                }
            }
            dp = move(nextDp);
            reachable = move(nextReachable);
        }
        return dp[(1 << m) - 1];
    }
};

替代方案

回溯 + 剪枝

可先移除无贡献者与被完全支配的人，再按未覆盖技能较多者优先搜索。但最坏情况下仍可能枚举大量人员子集，不如状态压缩 DP 稳定。

BFS 技能状态

把技能掩码看作图节点，每选择一人走一条边。首次到达全量状态即为最少人数。它与 DP 本质接近，但需要额外保存前驱，写法通常更繁琐。

面试追问

  • 为什么状态数取决于技能数，而不是候选人数？
  • 怎样预处理掉技能集合被另一人包含的候选人？
  • 若每个人有不同成本，目标改为最小总成本，该怎么改？
  • 若还要求最小人数下字典序最小，转移时如何处理平局？
  • 技能数超过 64 时，位掩码如何替换？

常见错误

  • 把 dp[mask] 只存人数却不存前驱或团队，最终无法还原成员下标。
  • 同一轮直接读写同一张表，可能把当前候选人重复加入路径；使用快照最清晰。
  • 仅按某人的技能数量贪心。局部覆盖最多不保证全局人数最少。
  • 忘记 people[i] 可以为空，或对技能位映射使用错误下标。
  • JavaScript 用 Array.fill([]) 初始化团队，导致所有状态共享同一个数组。
