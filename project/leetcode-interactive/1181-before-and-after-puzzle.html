LeetCode 1181 · String Puzzle

前后拼接Before and After Puzzle

短语的结尾，有时恰好是另一个短语的开头。找出所有可以首尾相接的表达，并把重复结果收束为一份有序答案。

MEDIUMPremium数组哈希表字符串排序
01 / Problem

题意

给定字符串数组 phrases。每个元素都是由小写英文字母和单个空格组成的短语。

任选两个下标不同的短语 phrases[i] 与 phrases[j]。如果前者的最后一个单词等于后者的第一个单词，就可以将两者拼成一个新短语；相同的衔接单词只保留一次。

返回所有不同的拼接结果，并按字典序升序排列。一个短语即使内容与另一个短语相同，只要下标不同，仍可作为不同的输入位置参与配对；最终结果仍需去重。

函数形式： beforeAndAfterPuzzles(phrases: string[]): string[]

官方示例

示例 1
输入：phrases = ["writing code", "code rocks"]
输出：["writing code rocks"]
示例 2
输入：phrases = ["mission statement", "a quick bite to eat", "a chip off the old block", "chocolate bar", "mission impossible", "a man on a mission", "block party", "eat my words", "bar of soap"]
输出：["a chip off the old block party", "a man on a mission impossible", "a man on a mission statement", "a quick bite to eat my words", "chocolate bar of soap"]
示例 3
输入：phrases = ["a", "b", "a"]
输出：["a"]
示例 4
输入：phrases = ["ab ba", "ba ab", "ab ba"]
输出：["ab ba ab", "ba ab ba"]

约束

  • 1 ≤ phrases.length ≤ 100
  • 1 ≤ phrases[i].length ≤ 100
  • 每个短语只含小写英文字母与空格。
  • 短语没有首尾空格，单词之间恰有一个空格。
拼接规则示意
“writing code” + “code rocks” → “writing code rocks”。两处 code 在结果里只出现一次。

04 / Solution

枚举每一道接缝

核心洞察

合法性只由两个边界单词决定：左短语的最后一个单词，以及右短语的第一个单词。输入最多 100 个短语，因此直接枚举所有有序下标对既清晰又足够快。

使用集合保存新短语，可以同时处理多条路径产生同一文本、以及输入中存在重复短语的情况。最后排序即可满足输出顺序。

完整过程

  1. 提取每个短语的首词和末词。
  2. 枚举所有 (i, j)，跳过 i == j。
  3. 若 last[i] == first[j]，把左短语与右短语去掉首词后的后缀相连。
  4. 将结果放入去重集合，最终按字典序返回。

正确性证明

1

每个加入集合的结果都合法。 算法只在 i ≠ j 且左末词等于右首词时拼接，并只删除右侧重复的首词，所以加入的每个字符串都符合题目定义。

2

每个合法结果都会被找到。 任意合法结果都来自某个有序下标对 (i, j)。双层枚举一定会访问这个对，并因边界单词相等而生成该结果。

3

返回集合恰好是答案。 前两点分别证明没有非法结果、没有遗漏合法结果；集合消除重复，排序保证字典序，因此最终数组完全满足要求。

复杂度

时间 O(n² · L + k log k)

L 为短语最大长度，k 为不同结果数；字符串构造也计入 L。

空间 O(k · L + n · L)

边界情况

  • 只有一个短语：不能与自身配对。
  • 单词短语：衔接后右侧没有剩余后缀。
  • 内容相同但下标不同：允许配对。
  • 多对产生同一文本：集合去重。
  • 没有匹配：返回空数组。

替代方案

可以用“首词 → 右短语列表”的哈希表建立索引，再按左短语末词查找候选，减少无效比较。最坏情况下仍可能生成 O(n²) 个配对；在本题规模内，双层枚举更直接且不易出错。

import java.util.*;

class Solution {
    public List<String> beforeAndAfterPuzzles(String[] phrases) {
        int n = phrases.length;
        String[] first = new String[n];
        String[] last = new String[n];

        for (int i = 0; i < n; i++) {
            int firstSpace = phrases[i].indexOf(' ');
            int lastSpace = phrases[i].lastIndexOf(' ');
            first[i] = firstSpace == -1
                    ? phrases[i]
                    : phrases[i].substring(0, firstSpace);
            last[i] = lastSpace == -1
                    ? phrases[i]
                    : phrases[i].substring(lastSpace + 1);
        }

        Set<String> puzzles = new TreeSet<>();
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i == j || !last[i].equals(first[j])) continue;
                puzzles.add(phrases[i] + phrases[j].substring(first[j].length()));
            }
        }
        return new ArrayList<>(puzzles);
    }
}

var beforeAndAfterPuzzles = function(phrases) {
    const n = phrases.length;
    const first = new Array(n);
    const last = new Array(n);

    for (let i = 0; i < n; i++) {
        const words = phrases[i].split(' ');
        first[i] = words[0];
        last[i] = words[words.length - 1];
    }

    const puzzles = new Set();
    for (let i = 0; i < n; i++) {
        for (let j = 0; j < n; j++) {
            if (i === j || last[i] !== first[j]) continue;
            puzzles.add(phrases[i] + phrases[j].slice(first[j].length));
        }
    }
    return Array.from(puzzles).sort();
};
from typing import List


class Solution:
    def beforeAndAfterPuzzles(self, phrases: List[str]) -> List[str]:
        first = []
        last = []
        for phrase in phrases:
            words = phrase.split()
            first.append(words[0])
            last.append(words[-1])

        puzzles = set()
        for i, left in enumerate(phrases):
            for j, right in enumerate(phrases):
                if i == j or last[i] != first[j]:
                    continue
                puzzles.add(left + right[len(first[j]):])

        return sorted(puzzles)

            size_t firstSpace = phrases[i].find(' ');

        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                if (i == j || last[i] != first[j]) continue;
                puzzles.insert(phrases[i] + phrases[j].substr(first[j].size()));
            }
        }
        return vector<string>(puzzles.begin(), puzzles.end());

常见错误

  • 只枚举 i < j：拼接有方向，必须枚举有序对。
  • 允许 i == j：题目要求两个不同下标。
  • 直接拼接完整右短语：会让接缝单词重复两次。
  • 用输入文本判定“同一个短语”：应比较下标，而非内容。
  • 忘记去重或最终排序。
