连续数组

Contiguous Array

Medium

给定二进制数组 nums，返回其中 0 和 1 数量相等的最长连续子数组长度。

题目

函数：findMaxLength(nums: integer[]) -> integer

示例 1
输入：nums = [0,1]
输出：2
[0,1] 中 0 和 1 各一个。
示例 2
输入：nums = [0,1,0]
输出：2
[0,1] 或 [1,0] 均满足。
示例 3
输入：nums = [0,1,1,1,1,1,0,0,0]
输出：6
最长可取 [1,1,1,0,0,0]。

约束

1 <= nums.length <= 10^5

nums[i] 只能是 0 或 1

Prefix-balance radar

平衡值复现雷达

逐格扫描示例三。雷达把 0 记为向下一步、1 记为向上一步；同一高度再次出现时，两次位置之间恰好平衡。

想好了吗？

先从可视化中找出“重复高度”与区间长度的关系，再展开完整题解。

题解：前缀平衡值 + 最早位置

核心洞察：把 0 当作 -1、1 当作 +1。若两个前缀的累加和相同，它们之间的元素和为 0，因此 0 与 1 数量相等。

完整过程

  1. 令平衡值 balance = 0，并记录 first[0] = -1。
  2. 从左到右扫描：遇 1 加一，遇 0 减一。
  3. 若当前平衡值首次出现，保存当前位置；否则用“当前位置 − 最早位置”更新答案。
  4. 始终保留最早位置，才能让同一平衡值产生最长区间。

正确性

设位置 j 与更早位置 i 的前缀平衡值相等，则区间 (i,j] 的平衡变化为 0，所以其中 +1 与 -1 的数量相同，也就是 1 与 0 数量相同。算法检查每个位置，并对每个平衡值使用最早出现位置，得到以该位置结尾的最长合法区间；取全局最大值即为答案。

复杂度

时间 O(n)；哈希表空间 O(n)。

边界

长度为 1 时答案为 0；全 0 或全 1 时为 0；first[0] = -1 用于覆盖从下标 0 开始的合法区间。

替代方案

暴力枚举所有区间并计数需要 O(n²)；也可用长度 2n+1 的数组以偏移量存平衡值的最早位置，替代哈希表并获得更稳定常数。

面试追问

  • 为什么只存最早位置？因为固定右端点时，它给出最大长度。
  • 如何推广到 0、1 数量满足固定差值？查询前缀平衡值之间的目标差。
  • 三种字符数量相等怎么办？同时记录两组前缀计数差作为状态键。

常见错误

  • 遗漏虚拟前缀 (0,-1)。
  • 每次重复时覆盖最早位置，导致答案变短。
  • 把问题误写成非连续子序列。

四种语言实现

import java.util.*;

class Solution {
    public int findMaxLength(int[] nums) {
        Map<Integer, Integer> first = new HashMap<>();
        first.put(0, -1);
        int balance = 0, answer = 0;
        for (int i = 0; i < nums.length; i++) {
            balance += nums[i] == 1 ? 1 : -1;
            if (first.containsKey(balance)) {
                answer = Math.max(answer, i - first.get(balance));
            } else {
                first.put(balance, i);
            }
        }
        return answer;
    }
}

var findMaxLength = function(nums) {
    const first = new Map([[0, -1]]);
    let balance = 0, answer = 0;
    for (let i = 0; i < nums.length; i++) {
        balance += nums[i] === 1 ? 1 : -1;
        if (first.has(balance)) {
            answer = Math.max(answer, i - first.get(balance));
        } else {
            first.set(balance, i);
        }
    }
    return answer;
};
from typing import List

class Solution:
    def findMaxLength(self, nums: List[int]) -> int:
        first = {0: -1}
        balance = answer = 0
        for i, value in enumerate(nums):
            balance += 1 if value == 1 else -1
            if balance in first:
                answer = max(answer, i - first[balance])
            else:
                first[balance] = i
        return answer
