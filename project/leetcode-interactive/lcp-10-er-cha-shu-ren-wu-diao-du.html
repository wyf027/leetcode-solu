二叉树任务调度

二叉树的左右孩子是父任务的前导任务，必须先完成。系统有两个 CPU 核；任务可以暂停并稍后继续，但同一个任务不能同时占用两个核。求完成整棵任务树的最短时间。

节点数 ≤ 1000，单节点耗时 ≤ 1000；允许非整数时刻切换任务。

题意与示例

左右子树互不依赖，可以穿插到两个 CPU 上执行；但父节点必须等待两棵子树全部完成，然后独占一个 CPU 执行自身任务。

示例 1

root = [47, 74, 31]

输出：121

两个孩子并行 31，剩余 43 与根任务 47 串行。

示例 2

root = [15,21,null,24,null,27,26]

输出：87

链式依赖造成关键路径，无法仅按总工作量除以 2。

示例 3

root = [1,3,2,null,null,4,4]

输出：7.5

允许在 0.5 时刻抢占与切换任务。

题解：每棵子树维护工作量与最短时间

DP 状态

后序遍历。对子树返回 (sum,time)：sum 是全部任务总耗时，time 是两个 CPU 完成该子树的最短时间。空树返回 (0,0)。

合并左右子树

两个独立子树共同执行至少受三条下界约束：不能短于左子树最优时间 lt，不能短于右子树最优时间 rt，也不能短于总工作量除以两个 CPU：(ls+rs)/2。允许任意时刻抢占，所以这三条下界的最大值可以达到。

转移、边界与复杂度

sum=ls+rs+val，time=max(lt,rt,(ls+rs)/2)+val。父任务必须等孩子全完成，所以 val 最后串行加入。每个节点访问一次，时间 O(n)；递归栈 O(h)。单节点返回 val，链形树自然退化为全部串行。

替代方案、追问与常见错误

离散时间背包无法处理 0.5 时刻，显式模拟调度也没有必要。若 CPU 数增加到 k，只有总工作量下界还不够，需要更丰富的子树调度轮廓。常见错误：只取总和/2、只算最长根到叶路径、把根节点与孩子并行、使用整数除法。
