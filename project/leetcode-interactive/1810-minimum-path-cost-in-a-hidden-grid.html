1810. 隐藏网格下的
最小消耗路径

Minimum Path Cost in a Hidden Grid

看不见地图，只有一个能移动的机器人。你能确定到达目标的最低代价吗？

题意与接口

机器人位于未知矩形网格。部分格子不可进入，其余格子每次进入都要付费。初始站立不计费；起点与目标不同，且均可通行。你不知道地图大小和两个位置，只能调用 GridMaster，返回起点到目标的最小总消耗；无法到达返回 −1。

  • canMove(direction): boolean：判断该方向是否可走。
  • move(direction): integer：移动并返回目的格费用；撞墙或出界则不动，返回 −1。
  • isTarget(): boolean：当前位置是否为目标。

方向为 U / D / L / R。提交入口为 findShortestPath(master)，GridMaster 由平台提供。

下列 grid, r1, c1, r2, c2 仅是判题器构建环境的完整参数，不会传给你的解法。grid 的 0 表示障碍，正数表示进入费用；(r1,c1) 是起点，(r2,c2) 是终点。

约束

m = grid.length；n = grid[i].length
1 ≤ m,n ≤ 100；0 ≤ grid[i][j] ≤ 100
0 ≤ r1,r2 < m；0 ≤ c1,c2 < n
起终点不同，且 grid[r1][c1]、grid[r2][c2] 均为正数。

官方示例 · 完整参数

示例 1

grid = [[2,3],[1,1]], r1 = 0, c1 = 1, r2 = 1, c2 = 0
输出：2

从起点向下再向左，费用 1 + 1 = 2；起点的 3 不计入。

示例 2

grid = [[0,3,1],[3,4,2],[1,2,0]], r1 = 2, c1 = 0, r2 = 0, c2 = 2
输出：9

一条最优路径为 (2,0) → (2,1) → (1,1) → (1,2) → (0,2)，费用 2 + 4 + 2 + 1 = 9。

示例 3

grid = [[1,0],[0,1]], r1 = 0, c1 = 0, r2 = 1, c2 = 1
输出：-1

起点无法离开，终点不可达。

题解：先还原地图，再计算费用

核心洞察

GridMaster 是有物理位置的接口。用深度优先探索建立可达地图，每深入一步，都必须在完成后反向移动回父格。探索费用不是答案。地图建立后，把进入格子的费用作为边权，在内存中运行 Dijkstra。

双阶段交互 · 示例 2

先观察机器人实际往返和地图揭示，再观察最小距离如何扩散。黄色边框表示当前位置；绿色表示距离已确定。数字“费”是格子费用，“距”是从起点出发的累计费用。

此演示是教学模拟，并非提交代码运行结果。探索按 U、R、D、L 顺序进行。


完整过程
  1. 把起点放在虚拟坐标 (100,100)，使用 201×201 数组，−1 表示未知。真实网格每个维度至多 100，所有可达位置落在 [1,199]，相邻探测落在 [0,200]，因此代码的平铺坐标安全。
  2. 栈帧保存位置、下一个方向、进入方向。对未访问且可移动的邻格调用 move，记录费用，检查目标，然后压栈。
  3. 四个方向完成后弹栈，按进入方向的反方向移动到父格。返回值也是父格的进入费用，顺手记录，包括起点的真实费用。
  4. 完整探索后若未发现目标，返回 −1。否则设置 dist[start]=0，最小堆放入起点。
  5. 弹出最小距离，跳过过期条目；用 d+cost[v] 松弛邻格。目标以有效最小距离出堆时返回答案。


正确性
位置不变式：每轮栈顶就是机器人的真实位置；进入新格后压栈，退出时反向移动，因此逻辑与物理位置始终一致。每个格子首次进入即标记，深度优先遍历覆盖起点连通块。
建图正确：每条可行移动 u→v 的权重仅由 v 决定，首次进入 v 时取得它的费用。网格中相邻的两个通行格自然相连；探索完成可据坐标恢复全部边，不只恢复探索树。
最优性：所有费用为正，Dijkstra 每次确定未确定节点中的最小距离。若存在更短路径，其首个未确定节点会在前驱确定时被松弛，不可能让更大的距离先确定。于是目标有效出堆时的距离就是最小消耗。


边界与常见错误
  • 目标不可达：必须探索完连通块后返回 −1；不能用坐标猜目标。
  • 忘记起点标记会重复进入；忘记反向 move 会让整张地图错位。
  • 不能把 move 的返回值当累计费用，不能把探索往返费用加进答案。
  • 不能第一次 DFS 发现目标就结束。普通 BFS 最小化步数，费用不等时不适用。
  • 不要把 u→v 与 v→u 设成相同费用：两者分别取 cost[v] 和 cost[u]。
  • 最多一万个格子的长通道可能导致递归爆栈；四份实现均采用显式栈。
  • 起点初始距离为 0，即使回退取得了起点费用也不改变这一点。


复杂度
设 V 是可达格子数，E ≤ 4V。探索 O(V+E)，每条探索树边恰好往返各一次，成功 move 共 2(V−1) 次。最小堆阶段 O((V+E) log V)。若用大小 A 的坐标数组，总时间 O(A+V log V)，空间 O(A+V)，这里 A=201²。用哈希坐标图可将辅助空间写成 O(V)。


替代方案与面试追问
全部通行费用相等时，可在建图后 BFS。费用仅为 0/1 的变体可用 0-1 BFS；本题 0 是障碍，不能直接套用。费用上界 100 时可考虑桶式最短路，但二叉堆实现更通用。
为什么不直接让机器人按 Dijkstra 出堆顺序走？连续出堆的格子未必相邻，机器人不能瞬移，需要额外导航。若要求返回路径，可在松弛时记录前驱。若允许负费用，Dijkstra 的确定性证明失效，需要重新讨论负环及其他最短路算法。

from heapq import heappush, heappop

class Solution:
    def findShortestPath(self, master: 'GridMaster') -> int:
        # GridMaster 由判题器提供；显式栈避免深递归。
        size, start = 201 * 201, 100 * 201 + 100
        step, direction = [-201, 1, 201, -1], 'URDL'
        cost = [-1] * size
        cost[start] = 0
        target = start if master.isTarget() else -1
        stack = [[start, 0, -1]]  # 位置、下个方向、进入方向
        while stack:
            u, k, back = stack[-1]
            if k == 4:
                stack.pop()
                if stack:
                    cost[stack[-1][0]] = master.move(direction[(back + 2) % 4])
                continue
            stack[-1][1] += 1
            v = u + step[k]
            if cost[v] != -1 or not master.canMove(direction[k]):
                continue
            cost[v] = master.move(direction[k])
            if master.isTarget():
                target = v
            stack.append([v, 0, k])
        if target == -1:
            return -1
        dist = [float('inf')] * size
        dist[start] = 0
        heap = [(0, start)]
        while heap:
            d, u = heappop(heap)
            if d != dist[u]:
                continue
            if u == target:
                return d
            for delta in step:
                v = u + delta
                if cost[v] >= 0 and d + cost[v] < dist[v]:
                    dist[v] = d + cost[v]
                    heappush(heap, (dist[v], v))
        return -1



Java
import java.util.*;

class Solution {
    public int findShortestPath(GridMaster master) {
        int size = 201 * 201, start = 100 * 201 + 100;
        int[] step = {-201, 1, 201, -1};
        char[] direction = {'U', 'R', 'D', 'L'};
        int[] cost = new int[size];
        Arrays.fill(cost, -1);
        cost[start] = 0;
        int target = master.isTarget() ? start : -1;
        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[]{start, 0, -1});
        while (!stack.isEmpty()) {
            int[] f = stack.peek();
            int u = f[0], k = f[1], back = f[2];
            if (k == 4) {
                stack.pop();
                if (!stack.isEmpty())
                    cost[stack.peek()[0]] = master.move(direction[(back + 2) % 4]);
                continue;
            }
            f[1]++;
            int v = u + step[k];
            if (cost[v] != -1 || !master.canMove(direction[k])) continue;
            cost[v] = master.move(direction[k]);
            if (master.isTarget()) target = v;
            stack.push(new int[]{v, 0, k});
        }
        if (target == -1) return -1;
        int[] dist = new int[size];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[start] = 0;
        PriorityQueue<int[]> heap = new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        heap.offer(new int[]{0, start});
        while (!heap.isEmpty()) {
            int[] node = heap.poll();
            int d = node[0], u = node[1];
            if (d != dist[u]) continue;
            if (u == target) return d;
            for (int delta : step) {
                int v = u + delta;
                if (cost[v] >= 0 && d + cost[v] < dist[v]) {
                    dist[v] = d + cost[v];
                    heap.offer(new int[]{dist[v], v});
                }
            }
        }
        return -1;
    }
}

class Solution {
public:
    int findShortestPath(GridMaster &master) {
        const int size = 201 * 201, start = 100 * 201 + 100;
        const int step[4] = {-201, 1, 201, -1};
        const char direction[4] = {'U', 'R', 'D', 'L'};
        vector<int> cost(size, -1);
        cost[start] = 0;
        int target = master.isTarget() ? start : -1;
        vector<array<int, 3>> stack{{start, 0, -1}};
        while (!stack.empty()) {
            auto f = stack.back();
            int u = f[0], k = f[1], back = f[2];
            if (k == 4) {
                stack.pop_back();
                if (!stack.empty())
                    cost[stack.back()[0]] = master.move(direction[(back + 2) % 4]);
                continue;
            }
            ++stack.back()[1];
            int v = u + step[k];
            if (cost[v] != -1 || !master.canMove(direction[k])) continue;
            cost[v] = master.move(direction[k]);
            if (master.isTarget()) target = v;
            stack.push_back({v, 0, k});
        }
        if (target == -1) return -1;
        vector<int> dist(size, INT_MAX);
        dist[start] = 0;
        using Node = pair<int, int>;
        priority_queue<Node, vector<Node>, greater<Node>> heap;
        heap.push({0, start});
        while (!heap.empty()) {
            auto [d, u] = heap.top(); heap.pop();
            if (d != dist[u]) continue;
            if (u == target) return d;
            for (int delta : step) {
                int v = u + delta;
                if (cost[v] >= 0 && d + cost[v] < dist[v]) {
                    dist[v] = d + cost[v];
                    heap.push({dist[v], v});
                }
            }
        }
        return -1;
    }
};



JavaScript
/** @param {GridMaster} master @return {number} */
var findShortestPath = function(master) {
    const size = 201 * 201, start = 100 * 201 + 100;
    const step = [-201, 1, 201, -1], direction = 'URDL';
    const cost = Array(size).fill(-1);
    cost[start] = 0;
    let target = master.isTarget() ? start : -1;
    const stack = [[start, 0, -1]];
    while (stack.length) {
        const f = stack[stack.length - 1];
        const [u, k, back] = f;
        if (k === 4) {
            stack.pop();
            if (stack.length)
                cost[stack[stack.length - 1][0]] = master.move(direction[(back + 2) % 4]);
            continue;
        }
        f[1]++;
        const v = u + step[k];
        if (cost[v] !== -1 || !master.canMove(direction[k])) continue;
        cost[v] = master.move(direction[k]);
        if (master.isTarget()) target = v;
        stack.push([v, 0, k]);
    }
    if (target === -1) return -1;
    // 原生二叉最小堆，无外部依赖。
    const heap = [];
    function push(node) {
        let i = heap.length;
        heap.push(node);
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (heap[p][0] <= node[0]) break;
            heap[i] = heap[p]; i = p;
        }
        heap[i] = node;
    }
    function pop() {
        const root = heap[0], last = heap.pop();
        if (heap.length) {
            let i = 0;
            while (i * 2 + 1 < heap.length) {
                let c = i * 2 + 1;
                if (c + 1 < heap.length && heap[c + 1][0] < heap[c][0]) c++;
                if (last[0] <= heap[c][0]) break;
                heap[i] = heap[c]; i = c;
            }
            heap[i] = last;
        }
        return root;
    }
    const dist = Array(size).fill(Infinity);
    dist[start] = 0; push([0, start]);
    while (heap.length) {
        const [d, u] = pop();
        if (d !== dist[u]) continue;
        if (u === target) return d;
        for (const delta of step) {
            const v = u + delta;
            if (cost[v] >= 0 && d + cost[v] < dist[v]) {
                dist[v] = d + cost[v]; push([dist[v], v]);
            }
        }
    }
    return -1;
};
