解码字母到整数映射

Decrypt String from Alphabet to Integer Mapping

把数字和 # 组成的密文恢复成小写英文字母。先通过交互沙盘观察字符如何逐步出现，再决定是否展开完整题解。

01题目说明

给定字符串 s，它只由数字字符和 # 组成。请按下面的对应关系，把它映射成由小写英文字母构成的新字符串并返回。题目保证输入有效，且映射结果唯一。

单数字映射
1 到 9 分别对应 a 到 i。
带 # 的映射
10# 到 26# 分别对应 j 到 z。

示例 1

输入：s = "10#11#12"
输出："jkab"
解释："10#" → "j"，"11#" → "k"，
      "1" → "a"，"2" → "b"。

示例 2

输入：s = "1326#"
输出："acz"

约束

  • 1 <= s.length <= 1000
  • s[i] 只包含数字 0–9 和字符 #。
  • s 是可以完成映射的有效字符串，结果唯一。

04完整题解

准备好后再展开。题解包含推导、证明、复杂度与四种语言实现。

✓题解：检查后缀标记

核心洞察

# 是没有歧义的结束标记：当当前位置后面隔一个字符出现 # 时，当前位置起的三个字符必然是 10# 到 26#；否则当前位置的单个数字对应 a 到 i。

完整过程

  1. 令游标 i = 0，准备输出容器。
  2. 若 i + 2 < n 且 s[i + 2] == '#'，读取两位数，转换成字母后令 i += 3。
  3. 否则读取一个数字，转换成字母后令 i += 1。
  4. 直到游标到达字符串末尾，拼接并返回所有字母。

正确性证明

对每次循环开始时已经处理的前缀做归纳。初始前缀为空，显然被正确解码。假设游标前的前缀已经正确：

  • 若 s[i + 2] 是 #，有效输入规则保证这三个字符构成唯一的两位映射，算法恰好输出其对应字母。
  • 否则当前位置不可能属于带 # 的三字符映射，因此唯一选择是把当前数字作为 1..9 解码，算法同样正确。

两种情况都正确扩展了已解码前缀，并让游标前进。循环最终覆盖全部输入，因此返回的是唯一正确映射。

边界情况

  • 最短输入，如 "1"。
  • 只有一个三字符编码，如 "10#" 或 "26#"。
  • 单字符与三字符编码连续交替。
  • 长度接近 1000；应使用可增长的字符串容器，避免不必要的反复复制。

复杂度

每个输入字符最多访问常数次，时间复杂度为 O(n)。除返回结果外，额外空间为 O(1)；若把输出容器计入，则为 O(n)。

替代方案

也可从右向左扫描：遇到 # 就向前取两位，否则取一位，最后反转结果。这同样是 O(n)，但需要反转；正向扫描通常更直观。正则替换也能实现，却更难清楚表达边界和复杂度。

面试追问

  • 若输入可能无效，如何报告非法 0、悬空 # 或超出 26？
  • 若编码扩展到任意长度，应如何设计前缀无歧义的协议？
  • 如何在流式输入中处理尚未到齐的三字符编码？

常见错误

  • 只看到数字 1 或 2 就盲目读取三位，没有检查两位之后的 #。
  • 字符转整数时忘记减去字符 '0'。
  • 读取 s[i + 2] 前未检查边界。
  • 处理三字符编码后只移动一格，导致重复读取。

class Solution {
    public String freqAlphabets(String s) {
        StringBuilder answer = new StringBuilder();

        for (int i = 0; i < s.length();) {
            int value;
            if (i + 2 < s.length() && s.charAt(i + 2) == '#') {
                value = (s.charAt(i) - '0') * 10
                      + (s.charAt(i + 1) - '0');
                i += 3;
            } else {
                value = s.charAt(i) - '0';
                i++;
            }
            answer.append((char) ('a' + value - 1));
        }

        return answer.toString();
    }
}

var freqAlphabets = function(s) {
    const answer = [];

    for (let i = 0; i < s.length;) {
        let value;
        if (i + 2 < s.length && s[i + 2] === '#') {
            value = Number(s.slice(i, i + 2));
            i += 3;
        } else {
            value = Number(s[i]);
            i += 1;
        }
        answer.push(String.fromCharCode(96 + value));
    }

    return answer.join('');
};
