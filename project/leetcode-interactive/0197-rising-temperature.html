题意：比较真正的“昨天”

表 Weather 含唯一的 id、日期 recordDate 和温度 temperature；不同记录不会拥有同一日期。

找出所有温度严格高于昨天的记录 id。结果顺序不限。

题解区域

默认收起，先动手观察日历，再展开理解 SQL 的精确连接条件。

核心洞察：用日期条件连接同一张表

令 w1 是今天、w2 是昨天。连接条件必须是 DATEDIFF(w1.recordDate, w2.recordDate) = 1，然后仅保留 w1.temperature > w2.temperature。

  1. 为每一条 w1 寻找日期恰好早一天的 w2。
  2. 比较同一配对的温度。
  3. 输出满足严格升温的今天 w1.id。

边界与复杂度

  • 最早日期没有昨天，自连接自然不会产生配对。
  • 日期断档不应跨越比较；DATEDIFF = 1 会阻止它。
  • 温度相等不算上升，因此使用 >。
  • 在 recordDate 建索引可改善连接查找；逻辑上扫描/连接取决于数据库执行计划。

替代方案取舍

窗口函数 LAG 很直观，但如果只按日期排序后比较前一行，遇到日期断档会误判；仍需同时检查日期相隔一天。对本题，显式自连接最直接地表达“昨天”。

面试追问与常见错误

追问：若每个城市独立比较？在连接条件加入城市相等。若“前一条记录”而非昨天？使用 LAG。

错误：按 id 相邻比较；只写温度条件；把 DATEDIFF 的方向颠倒；使用 >=。

SELECT w1.id
FROM Weather AS w1
JOIN Weather AS w2
  ON DATEDIFF(w1.recordDate, w2.recordDate) = 1
WHERE w1.temperature > w2.temperature;
// 兼容参考：rows 每项含 id, LocalDate date, temperature
List<Integer> rising(List<Row> rows) {
  Map<LocalDate, Row> byDate = rows.stream().collect(Collectors.toMap(r -> r.date, r -> r));
  return rows.stream().filter(r -> { Row y = byDate.get(r.date.minusDays(1)); return y != null && r.temperature > y.temperature; }).map(r -> r.id).toList();
}
const rising = (rows) => {
  const byDate = new Map(rows.map((r) => [r.date, r]));
  return rows.filter((r) => {
    const yesterday = byDate.get(previousDate(r.date));
    return yesterday && r.temperature > yesterday.temperature;
  }).map((r) => r.id);
};
