01 · Read the contract

题意、示例与约束

题意

给定二叉搜索树 root，原地转换成一个已排序的循环双向链表。 复用每个节点，不允许创建新的链表节点。返回值是链表中的最小节点；空树返回 null。

输入：root = [4,2,5,1,3]
顺序：1 ⇄ 2 ⇄ 3 ⇄ 4 ⇄ 5
闭环：1.left = 5，5.right = 1
返回：节点 1

约束与边界

  • 节点数 0 ≤ n ≤ 2000
  • -1000 ≤ Node.val ≤ 1000
  • 节点值互不重复，满足严格 BST 性质
  • 单节点转换后，左右指针都指向自身
  • 返回最小节点，而不是原来的根节点

核心洞察

中序顺序就是链表顺序

二叉搜索树的中序遍历严格递增。维护 head 记录首个访问到的最小节点， prev 记录已处理序列的最后一个节点；当前节点只需与 prev 双向相连。

关键不变式

已访问部分始终有序

每次处理完当前节点后，从 head 到 prev 已构成递增的非循环双向链表； 遍历结束时再连接最小值与最大值完成闭环。

完整过程

六步完成原地转换

  1. 空树直接返回 null。
  2. 递归处理当前节点的左子树。
  3. 若 prev == null，当前节点是最小节点，令 head = cur。
  4. 否则连接 prev.right = cur 与 cur.left = prev。
  5. 更新 prev = cur，再递归处理右子树。
  6. 遍历完成后执行 head.left = prev、prev.right = head，返回 head。

边界

最容易漏的四种情况

  • 空树：不能访问 head.left。
  • 单节点：左右指针最终都指向自己。
  • 退化链：递归深度可达到 n。
  • 首尾节点：最后必须补上两个方向的闭环。

复杂度

每个节点只处理一次

时间O(n)访问并改链一次
空间O(h)递归调用栈

替代方案

迭代栈与 Morris

  • 显式栈中序：同为 O(h)，避免递归调用。
  • 数组收集：写法直观，但额外占用 O(n)。
  • Morris 中序：可达额外 O(1)，但临时线索和指针复用更易出错。

面试追问

继续向下推一层

  • 为什么必须返回最小节点，而不是原根？
  • 若要求非循环链表，需要删掉哪两条语句？
  • 如何改成严格 O(1) 辅助空间？
  • 如果 BST 允许重复值，不变式如何表述？

常见错误

这些指针细节会直接破坏答案

  • 使用前序或后序遍历，链表无法自然递增。
  • 只设置一个方向，结果不是双向链表。
  • 首个节点仍访问空的 prev，触发异常。
  • 最后忘记首尾闭环，只得到普通双向链表。
  • 返回原 root，而不是最小节点 head。
  • 新建节点或先存进数组，偏离原地复用目标。

class Solution {
    private Node head;
    private Node prev;

    public Node treeToDoublyList(Node root) {
        if (root == null) {
            return null;
        }

        head = null;
        prev = null;
        inorder(root);
        head.left = prev;
        prev.right = head;
        return head;
    }

    private void inorder(Node node) {
        if (node == null) {
            return;
        }

        inorder(node.left);
        if (prev == null) {
            head = node;
        } else {
            prev.right = node;
            node.left = prev;
        }
        prev = node;
        inorder(node.right);
    }
}

        if (root == nullptr) {
            return nullptr;

        head_ = nullptr;
        prev_ = nullptr;
        inorder(root);
        head_->left = prev_;
        prev_->right = head_;
        return head_;

    Node* head_;
    Node* prev_;

        if (node == nullptr) {
            return;

            head_ = node;
