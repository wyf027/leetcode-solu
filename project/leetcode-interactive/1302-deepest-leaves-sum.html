层数最深叶子节点的和

像声呐一层层下潜：每到新深度，清空旧读数；最后一次回波里的所有节点之和，就是答案。

Mission

O(n) 一次逐层遍历，只保留最后一层的求和结果。

Problem

题目要求

函数：deepestLeavesSum(root) → integer

准确转述

给定一棵二叉树的根节点 root，找出整棵树中深度最大的所有叶子节点，并返回这些叶子节点值的总和。根节点位于深度 0；叶子节点没有左右子节点。

约束

  • 树中节点数在 [1, 10⁴] 范围内。
  • 1 ≤ Node.val ≤ 100。

Complete Solution

逐层覆盖：让最后一层留下答案

主解采用 BFS。每轮固定处理当前队列中的全部节点，并把 levelSum 重置为 0。

核心洞察

层序遍历天然把同一深度的节点放在同一轮中。每一轮都重新计算层和，并用它覆盖答案。只要遍历尚未结束，旧答案就可以被丢弃；遍历结束后保留下来的正是最深层之和。

answer ← Σ（当前层所有节点值）

完整过程

  1. 把根节点放入队列。
  2. 当队列非空，记录当前长度 levelSize，并将层和清零。
  3. 恰好弹出 levelSize 个节点，累加值并把孩子入队。
  4. 本轮结束后，以当前层和覆盖答案。
  5. 队列为空时返回最后一次覆盖后的答案。

正确性说明

循环不变式：每轮开始时，队列恰好包含某个深度的全部节点，且不包含其他深度节点。

初始时队列只有深度 0 的根节点，不变式成立。处理一轮时，只把这些节点的孩子加入队列，所以新队列恰好包含下一深度的全部节点，不变式继续成立。每轮答案被设置为当前层所有节点值之和。最后一轮处理的层没有下一层，因此它就是最大深度；该层节点也必然都是叶子。故最终答案等于所有最深叶子节点之和。

边界与复杂度

  • 单节点树：根节点既是最深节点也是叶子，直接得到根值。
  • 退化链：每层只有一个节点，返回链尾节点值。
  • 不平衡树：BFS 仍按全局深度分层，不会混淆不同分支。

时间复杂度：O(n)，每个节点入队、出队各一次。

空间复杂度：O(w)，其中 w 是树的最大宽度；最坏为 O(n)。

替代方案：一次 DFS

递归时同时维护当前已知的最大深度与对应总和。若访问到更深的叶子，就更新最大深度并重置总和；若访问到同样深的叶子，就累加。时间仍为 O(n)，空间取决于树高 O(h)。

面试追问

  • 如果节点值允许为负数，算法是否变化？不变，不能用和的大小判断深度。
  • 如何返回最深叶子的列表？在新最大深度时清空列表，同深度时追加。
  • BFS 与 DFS 如何选择？宽树可能让 BFS 队列很大；高树可能让递归 DFS 溢栈。

常见错误

  • 把“最深叶子”误解为某一条最长根到叶路径上的节点。
  • 没有在每层开始时把 levelSum 清零，导致累加整棵树。
  • 用动态变化的队列长度控制当前层，结果把下一层也在同一轮处理。
  • DFS 遇到更深叶子时只更新深度，却忘记用新叶子值重置总和。

Java LeetCode 可提交
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int deepestLeavesSum(TreeNode root) {
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int answer = 0;

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            int levelSum = 0;

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                levelSum += node.val;

                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
            answer = levelSum;
        }
        return answer;
    }
}

/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *   this.val = (val === undefined ? 0 : val);
 *   this.left = (left === undefined ? null : left);
 *   this.right = (right === undefined ? null : right);
 * }

/**
 * @param {TreeNode} root
 * @return {number}
 */
var deepestLeavesSum = function(root) {
    const queue = [root];
    let head = 0;
    let answer = 0;

    while (head < queue.length) {
        const levelEnd = queue.length;
        let levelSum = 0;

        while (head < levelEnd) {
            const node = queue[head++];
            levelSum += node.val;

            if (node.left !== null) {
                queue.push(node.left);
            }
            if (node.right !== null) {
                queue.push(node.right);
            }
        }
        answer = levelSum;
    }
    return answer;
};

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional


class Solution:
    def deepestLeavesSum(
        self, root: Optional[TreeNode]
    ) -> int:
        queue = deque([root])
        answer = 0

        while queue:
            level_sum = 0

            for _ in range(len(queue)):
                node = queue.popleft()
                level_sum += node.val

                if node.left is not None:
                    queue.append(node.left)
                if node.right is not None:
                    queue.append(node.right)

            answer = level_sum

        return answer

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int deepestLeavesSum(TreeNode* root) {
        queue<TreeNode*> nodes;
        nodes.push(root);
        int answer = 0;

        while (!nodes.empty()) {
            int levelSize = static_cast<int>(nodes.size());
            int levelSum = 0;

            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = nodes.front();
                nodes.pop();
                levelSum += node->val;

                if (node->left != nullptr) {
                    nodes.push(node->left);
                }
                if (node->right != nullptr) {
                    nodes.push(node->right);
                }
            }
            answer = levelSum;
        }
        return answer;
    }
};
