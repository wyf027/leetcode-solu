LEETCODE 2130

链表最大孪生和

Maximum Twin Sum of a Linked List

从链表两端配成一对，寻找其中最大的和。先理解配对规则，再展开下方题解探索实现。

官方题目 ↗

题意与约束

给定单链表的头节点 head，链表有偶数个节点，记为 n，下标从 0 开始。对于 0 ≤ i < n/2，节点 i 与节点 n − 1 − i 互为孪生节点；它们的值相加得到孪生和。返回所有这些配对中的最大孪生和。

例如四个节点只形成两对：下标 (0,3) 与 (1,2)。输入中的数组表示链表的节点顺序，函数实际接收的是 ListNode head，返回一个整数。

  • 节点数为 [2, 100000] 范围内的偶数。
  • 每个节点满足 1 ≤ Node.val ≤ 100000。

官方示例

01 / 两对相等

输入：head = [5,4,2,1]
输出：6

下标 (0,3) 的和为 5+1=6，(1,2) 的和为 4+2=6，最大值为 6。

02 / 外侧更大

输入：head = [4,2,2,3]
输出：7

下标 (0,3) 的和为 4+3=7，(1,2) 的和为 2+2=4，最大值为 7。

03 / 只有一对

输入：head = [1,100000]
输出：100001

唯一配对的和为 1+100000=100001。

交互推演、证明与四语言实现

题解 · 将链表投影成可索引序列

核心洞察：孪生关系由原始位置决定，而不是由值决定。顺序收集节点值到数组 a 后，a[i] 和 a[n−1−i] 就能直接配对。这里选用不改动链表、容易解释的 O(n) 额外空间方案。

镜面对读台

先逐节点复制，再让两个读取位置向中心靠拢。上轨保留原链表，下轨显示已收集的数组；绿色边框标记当前操作。演示最多 12 个节点，提交算法支持官方上限。

每个数须为 1–100000 的整数。

原链表 · 下标从 0 开始

数组 · 按原顺序收集

键盘：Tab 选择控件，Enter / 空格触发按钮。启用减少动态效果时不自动推进，可逐步操作。

完整过程

  1. 从 head 出发，依次把每个节点的值追加到数组，直到遇到空指针。
  2. 初始化 best = 0。令 i 从 0 走到 n/2 − 1。
  3. 计算 a[i] + a[n−1−i]，将 best 更新为它与当前和的较大者。
  4. 所有 n/2 对处理完后返回 best。

示例 [2,7,3,9,4,6] 的三对和依次为 8、11、12，记录值依次为 8、11、12。

正确性证明

收集过程保持顺序，因此数组下标与原链表下标一一对应。循环第 i 次处理的两个元素恰好对应题目定义的节点 i 与 n−1−i。

循环不变式：处理前 k 对后，best 是这 k 对的最大和；k=0 时 best=0，由于节点值均为正，初始化有效。每次通过 max 纳入下一对，保持不变式。结束时 k=n/2，所有合法配对恰好出现一次，因此 best 即题目要求的最大孪生和。

边界与复杂度

  • 只有两个节点：循环一次，直接返回它们的和。
  • 重复值、多个最大配对：不影响位置配对与 max 更新。
  • 最大和为 200000，四种语言的常用整数表示均足够。
  • 官方保证非空、偶数长度；不需要为奇数链表定义额外行为。
  • 时间 O(n)：收集 n 次、配对 n/2 次。额外空间 O(n)：保存全部节点值。原链表不变。

替代方案：反转后半段

快指针每次走两步、慢指针每次走一步。偶数长度时，快指针到空，慢指针位于后半段首节点。反转从慢指针开始的后半段，再用 p 从 head、q 从反转后的头同时向后走，直到 q 为空。它们依次对应原下标 i 与 n−1−i；逐对更新最大值，时间 O(n)、额外空间 O(1)。

代价是修改 next 指针。若需要保持输入结构，保留反转段的头，计算后再次反转后半段并确保前半段尾节点连接恢复。数组方案更直接；栈也能逆序读取，但通常仍需 O(n) 空间。

常见错误

  • 把相邻节点当孪生节点：孪生关系是首尾对称。
  • 使用 n−i 作为右下标：正确位置是 n−1−i。
  • 对值排序：排序破坏原始位置，改变了配对。
  • 对每个 i 都从头遍历到其孪生节点：最坏退化到 O(n²)。
  • 使用反转方案却忘记输入结构已改变；递归反转还可能导致深链表栈溢出。

面试追问

  • 如何将空间降到常数？用快慢指针找到中点，原地反转后半段，然后同步遍历。
  • 输入必须保持不变怎么办？选择数组；或者计算后恢复被反转的后半段。
  • 允许负数后还能 best=0 吗？不能，应用第一对和或负无穷初始化。
  • 为什么只遍历一半？后半段只是前半段配对的镜像，不产生新配对。

四语言完整提交代码

均采用数组方案。ListNode 由 LeetCode 运行环境提供，不重复定义；Python 为 Python 3。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public int pairSum(ListNode head) {
        List<Integer> values = new ArrayList<>();
        for (ListNode p = head; p != null; p = p.next) {
            values.add(p.val);
        }
        int n = values.size(), best = 0;
        for (int i = 0; i < n / 2; i++) {
            best = Math.max(best, values.get(i) + values.get(n - 1 - i));
        }
        return best;
    }
}

Python

from typing import Optional

class Solution:
    def pairSum(self, head: Optional[ListNode]) -> int:
        values = []
        p = head
        while p is not None:
            values.append(p.val)
            p = p.next
        n = len(values)
        best = 0
        for i in range(n // 2):
            best = max(best, values[i] + values[n - 1 - i])
        return best

        std::vector<int> values;
        for (ListNode* p = head; p != nullptr; p = p->next) {
            values.push_back(p->val);
        }
        int n = static_cast<int>(values.size());
        int best = 0;
        for (int i = 0; i < n / 2; ++i) {
            best = std::max(best, values[i] + values[n - 1 - i]);
        }
        return best;
    }
};
