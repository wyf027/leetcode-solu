图中最大星和

Maximum Star Sum of a Graph

一个中心，几条相连的边。哪些节点能组成最大的星和？

先理解题意，再按步骤探索。完整推导与代码在页面底部，默认收起。

01 / 题目

给定有 n 个节点的无向图，编号为 0 … n − 1。数组 vals[i] 是节点 i 的权值；每个 edges[j] = [a, b] 表示 a 与 b 相连。再给定整数 k。

选择一个中心节点，再选择它的若干条相邻边，组成一个星图。所有选中的边必须共享这个中心；星和是其中所有节点的权值之和，每个节点只算一次。求使用至多 k 条边时的最大星和。

可以只选中心而不选边；中心必须存在。这里选择的是边的子集，邻居之间即使还有其他边，也不影响所选星图。

官方示例 1

vals = [1,2,3,4,10,-10,-20]
edges = [[0,1],[1,2],[1,3],[3,4],[3,5],[3,6]]
k = 2
输出：16

以节点 3 为中心，选择邻居 1 和 4，星和为 4 + 2 + 10 = 16。

官方示例 2

vals = [-5]
edges = []
k = 0
输出：-5

只有节点 0，自身即为唯一星图，星和为 −5。

完整约束与函数签名
  • n == vals.length，1 ≤ n ≤ 10⁵
  • −10⁴ ≤ vals[i] ≤ 10⁴
  • 0 ≤ edges.length ≤ min(n(n−1)/2, 10⁵)
  • edges[i].length == 2
  • 0 ≤ aᵢ, bᵢ ≤ n−1，且 aᵢ ≠ bᵢ
  • 0 ≤ k ≤ n−1

maxStarSum(vals: integer[], edges: integer[][], k: integer) → integer

04 / 题解与实现

固定中心，把问题变成“选哪些邻居”

核心洞察

中心确定后，每条相邻边的增益就是另一端节点的权值。因为是“至多 k 条”，负数不选，零也可以跳过；只取正权邻居中最大的 k 个。然后枚举所有中心，取最大结果。

完整过程

  1. 建立邻接表。对无向边 [a,b]，若 vals[b] > 0，把它加入 a 的候选表；若 vals[a] > 0，把它加入 b 的候选表。
  2. 对每个中心 i，把其候选权值降序排序。
  3. 令 sum = vals[i]，累加前 min(k, 候选数) 个值。
  4. 更新全局最大值。初始答案必须是某个真实节点值，不能是 0。

示例 1 各中心的最优星和依次为 [3,9,5,16,14,-6,-16]。中心 3 的正权邻居是 4（10）和 1（2），得到 4 + 10 + 2 = 16。负权中心仍必须参与枚举。

正确性证明

去除非正增益：任何解移除一个负权叶子都会增大星和，移除零权叶子不会变差，且边数仍满足限制。因此总存在只含正权叶子的最优解。

交换论证：固定中心，如果已选叶子 x 的权值小于未选正权邻居 y，替换 x 为 y 不改变边数，星和却变大。不断替换后，选中的一定可以是最大的 min(k, 正权邻居数) 个。若还有空位和正权邻居，加入它会严格增大星和。

覆盖所有中心：每个合法星图都有中心。算法计算每个中心的最优值并取最大，因此覆盖全局最优星图；所有构造也都满足边数限制，所以结果正确。

复杂度

设 n 为节点数、m 为边数、pᵢ 为中心 i 的正权邻居数。建表 O(n + m)，排序与求和总计 O(n + m + Σ pᵢ log(pᵢ + 1))，可记为 O(n + m log(n + 1))；邻接表和排序辅助空间整体 O(n + m)。k = 0 时可直接返回最大节点值，把时间降为 O(n)。下面代码保留统一流程。

边界与常见错误

  • 没有边、k = 0 或全负数时，答案都是最大节点值，而非 0。
  • “至多”不是“恰好”：不要为了选满 k 而加入负数。
  • 不能只考虑权值最大的节点作为中心；连接结构同样关键。
  • 无向边要处理两个方向；相同权值的不同节点不能按权值去重。
  • JavaScript 默认排序是字符串顺序，必须写 (a, b) => b - a。
  • 星图不是多层路径，不要把邻居的邻居递归加入。
  • 最多 n 个节点各贡献 10⁴，星和上界为 10⁹，32 位有符号整数足够，JavaScript Number 也能精确表示。

替代方案

为每个中心维护大小不超过 k 的小根堆，仅保留最大的正权邻居。时间 O(n + m log(k + 1))（k = 0 单独处理），空间 O(n + min(m, nk))，适合 k 远小于度数时。排序方案代码更直接；无需维护堆。也可用快速选择找前 k 大，平均线性，但普通实现存在最坏二次时间且边界更复杂。

面试追问

  • 改成恰好 k 条边？中心度数必须至少为 k，前 k 大邻居要允许包含负数；没有可行中心时需另行定义返回值。
  • 边流式到达？对每个端点维护容量 k 的小根堆与堆内总和。
  • 输出星图本身？候选中存节点编号，保存最优中心及其选中邻居。
  • 权值会更新？一个节点变更会影响自身与所有邻居作为中心的结果，需要按更新/查询频率选择重新排序或有序结构。

Java

import java.util.*;

class Solution {
    public int maxStarSum(int[] vals, int[][] edges, int k) {
        int n = vals.length;
        List<List<Integer>> neighbors = new ArrayList<>();
        for (int i = 0; i < n; i++) neighbors.add(new ArrayList<>());
        for (int[] e : edges) {
            int a = e[0], b = e[1];
            if (vals[b] > 0) neighbors.get(a).add(vals[b]);
            if (vals[a] > 0) neighbors.get(b).add(vals[a]);
        }
        int answer = vals[0];
        for (int i = 0; i < n; i++) {
            List<Integer> list = neighbors.get(i);
            list.sort(Collections.reverseOrder());
            int sum = vals[i];
            for (int j = 0; j < Math.min(k, list.size()); j++) {
                sum += list.get(j);
            }
            answer = Math.max(answer, sum);
        }
        return answer;
    }
}

var maxStarSum = function(vals, edges, k) {
    const neighbors = Array.from({length: vals.length}, () => []);
    for (const [a, b] of edges) {
        if (vals[b] > 0) neighbors[a].push(vals[b]);
        if (vals[a] > 0) neighbors[b].push(vals[a]);
    }
    let answer = vals[0];
    for (let i = 0; i < vals.length; i++) {
        neighbors[i].sort((a, b) => b - a);
        let sum = vals[i];
        for (let j = 0; j < Math.min(k, neighbors[i].length); j++) {
            sum += neighbors[i][j];
        }
        answer = Math.max(answer, sum);
    }
    return answer;
};

from typing import List

class Solution:
    def maxStarSum(self, vals: List[int], edges: List[List[int]], k: int) -> int:
        neighbors = [[] for _ in vals]
        for a, b in edges:
            if vals[b] > 0:
                neighbors[a].append(vals[b])
            if vals[a] > 0:
                neighbors[b].append(vals[a])
        answer = vals[0]
        for i, values in enumerate(neighbors):
            values.sort(reverse=True)
            total = vals[i]
            for j in range(min(k, len(values))):
                total += values[j]
            answer = max(answer, total)
        return answer

#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

class Solution {
public:
    int maxStarSum(vector<int>& vals, vector<vector<int>>& edges, int k) {
        int n = vals.size();
        vector<vector<int>> neighbors(n);
        for (const auto& e : edges) {
            int a = e[0], b = e[1];
            if (vals[b] > 0) neighbors[a].push_back(vals[b]);
            if (vals[a] > 0) neighbors[b].push_back(vals[a]);
        }
        int answer = vals[0];
        for (int i = 0; i < n; ++i) {
            auto& v = neighbors[i];
            sort(v.begin(), v.end(), greater<int>());
            int sum = vals[i];
            for (int j = 0; j < min(k, static_cast<int>(v.size())); ++j) {
                sum += v[j];
            }
            answer = max(answer, sum);
        }
        return answer;
    }
};
