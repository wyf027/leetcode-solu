最大的幻方

Largest Magic Square · 寻找每个方向都平衡的正方形。

先读题、观察，再展开底部题解。官方题目 ↗

01 / 题目

给定一个 m × n 整数矩阵 grid，从中选取连续的 k × k 正方形区域。如果每一行、每一列以及两条完整对角线的和全部相等，这个区域就是幻方。返回能找到的最大幻方的边长 k。

元素允许重复，每个 1 × 1 的区域都满足要求。

largestMagicSquare(grid: integer[][]) → integer

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 50
  • 1 ≤ grid[i][j] ≤ 10⁶

示例 1

输入：grid = [[7,1,4,5,6],
               [2,5,1,6,4],
               [1,5,4,3,2],
               [1,2,7,3,4]]
输出：3

第 2～4 行、第 2～4 列形成边长 3 的幻方。

  • 行：5+1+6 = 5+4+3 = 2+7+3 = 12
  • 列：5+5+2 = 1+4+7 = 6+3+3 = 12
  • 对角线：5+4+3 = 6+4+2 = 12

示例 2

输入：grid = [[5,1,3,1],
               [9,3,3,1],
               [1,3,3,8]]
输出：2

第 2～3 行、第 2～3 列的四个元素均为 3，每条需要比较的线之和都是 6，最大边长为 2。

04 / 独立题解
思路、正确性与四语言实现。
核心洞察
令 L = min(m,n)。从大到小枚举边长，再枚举左上角；固定候选后核对 k 行、k 列和两条对角线。行列前缀和使每条行、列区间的求和只需 O(1)。首次找到的幻方就是最大值。
完整过程
  1. 构建行前缀和 row[i][j+1] = row[i][j] + grid[i][j] 与列前缀和 col[i+1][j] = col[i][j] + grid[i][j]，初始第 0 项为 0。
  2. 边长 k 从 L 递减到 2。枚举左上角 (r,c)，满足 r+k ≤ m 且 c+k ≤ n。
  3. 以候选第一行的和 row[r][c+k] − row[r][c] 为 target。
  4. t 从 0 到 k−1：检查行和 row[r+t][c+k] − row[r+t][c]、列和 col[r+k][c+t] − col[r][c+t]。任何一个不等于 target 就拒绝。
  5. 同一个循环累加两条对角线 grid[r+t][c+t] 和 grid[r+t][c+k−1−t]；最后比较它们是否均等于 target。
  6. 找到即返回 k；没有边长至少为 2 的幻方就返回 1。
正确性证明
区间和准确：前缀差消去区间之前的元素，保留恰好 k 个连续元素。两条对角线的索引分别逐一覆盖其 k 个元素。
候选判定充要：被接受的区域所有行、列和两条对角线都等于 target，符合定义。反过来，幻方的这些线之和必然等于其第一行的和，因此一定被接受。
最大性：对每个边长枚举了所有合法位置，且按边长降序检查。首次返回 k 时所有更大的候选都已被排除，所以答案最大。若全部失败，1 × 1 总存在且必为幻方，返回 1 正确。
复杂度
前缀预处理 O(mn)。单候选检查 O(k)，总检查成本为 O(Σ[k=2…L] k(m−k+1)(n−k+1))，上界 O(mnL²)；额外空间 O(mn)。对角线在已有循环中累加，无需额外数组。
边界与数值
  • 单行、单列答案为 1；全相同矩阵答案为 min(m,n)。
  • 元素允许重复，不能加去重条件。
  • 前缀与线和最大为 50 × 10⁶ = 5 × 10⁷，Java/C++ 的 int 足够，JavaScript Number 可精确表示。
  • 右边界与下边界允许刚好等于 n、m；副对角线列索引从 c+k−1 降到 c。
替代方案
直接逐个元素计算每条行列和，单候选 O(k²)，总上界 O(mnL³)，直观但重复求和多。也可增加两方向对角线前缀和，使对角线求和为 O(1)；然而仍要逐一检查 k 行与 k 列，总复杂度上界不变。
常见错误
  • 漏查某条对角线，或只比较行列总和；行总和与列总和天然相等。
  • 返回面积 k²，题目要边长。
  • 把合法边界写成 r+k<m，漏掉贴住底边的候选。
  • 对边长二分。存在大幻方不保证存在小幻方，例如经典 3 × 3 洛书幻方没有 2 × 2 幻方，不能假设判定单调。
面试追问
返回位置？成功时返回 (r,c,k)。返回所有最大幻方？在首次成功的边长上继续扫描全部位置，再停止缩小。允许负数？前缀差和等和判定仍然适用，但需依据数值范围选类型。
Java
class Solution {
    public int largestMagicSquare(int[][] grid) {
        int m=grid.length, n=grid[0].length;
        int[][] row=new int[m][n+1], col=new int[m+1][n];
        for (int i=0;i<m;i++) for (int j=0;j<n;j++) {
            row[i][j+1]=row[i][j]+grid[i][j];
            col[i+1][j]=col[i][j]+grid[i][j];
        }
        for (int k=Math.min(m,n);k>=2;k--)
            for (int r=0;r+k<=m;r++)
                for (int c=0;c+k<=n;c++)
                    if (valid(grid,row,col,r,c,k)) return k;
        return 1;
    }
    private boolean valid(int[][] g,int[][] row,int[][] col,
                          int r,int c,int k) {
        int target=row[r][c+k]-row[r][c], d1=0,d2=0;
        for (int t=0;t<k;t++) {
            if (row[r+t][c+k]-row[r+t][c]!=target ||
                col[r+k][c+t]-col[r][c+t]!=target) return false;
            d1+=g[r+t][c+t];
            d2+=g[r+t][c+k-1-t];
        }
        return d1==target && d2==target;
    }
}

Python
from typing import List

class Solution:
    def largestMagicSquare(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        row = [[0] * (n + 1) for _ in range(m)]
        col = [[0] * n for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                row[i][j+1] = row[i][j] + grid[i][j]
                col[i+1][j] = col[i][j] + grid[i][j]

        def valid(r, c, k):
            target = row[r][c+k] - row[r][c]
            d1 = d2 = 0
            for t in range(k):
                if (row[r+t][c+k] - row[r+t][c] != target or
                        col[r+k][c+t] - col[r][c+t] != target):
                    return False
                d1 += grid[r+t][c+t]
                d2 += grid[r+t][c+k-1-t]
            return d1 == target and d2 == target

        for k in range(min(m, n), 1, -1):
            for r in range(m - k + 1):
                for c in range(n - k + 1):
                    if valid(r, c, k):
                        return k
        return 1
