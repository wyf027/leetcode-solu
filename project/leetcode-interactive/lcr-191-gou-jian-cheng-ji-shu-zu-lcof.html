LCR 191 · Medium · Array / Prefix product

按规则计算统计结果前后缀积工坊

让每个位置暂时离开传送带：左边累积的前缀积与右边送来的后缀积相乘，恰好得到“除自己外全部元素的积”。前后缀积是本页推荐的稳健主解，也自然覆盖 0。

O(n) 时间 O(1) 额外空间 推荐：前后缀积

题目规则

给定整数数组 arrayA，返回 arrayB；其中 arrayB[i] 是 arrayA 中除 i 外全部元素的乘积。

官方约束：arrayA.length ≤ 100000，测试数据保证结果不溢出 32 位整数。

Official example

官方示例

输入：arrayA = [2,4,6,8,10]

输出：[1920,960,640,480,384]

Interactive lab

两条传送带，一次合流

准备就绪

键盘：Enter 计算，←/→ 切换步骤。

输入 arrayA当前排除位置 —
左传送带：prefix（当前位置左侧的乘积）
右传送带：suffix（当前位置右侧的乘积）
合流 output = prefix × suffix

How it works

先左后右，原地合流

  1. 1从左到右写入 answer[i] = prefix，随后令 prefix *= arrayA[i]。
  2. 2从右到左维护 suffix，将 answer[i] *= suffix，再令 suffix *= arrayA[i]。
  3. 3每格只接收“自己左边”与“自己右边”的积；0 无需特判，因为它会沿对应传送带自然传播。
为什么不用除法？ 总积除以当前元素在遇到 0 时失效；前后缀积没有这个前提，也不需要额外分支。

Complexity

两次线性扫描

时间
O(n)
额外空间
O(1)

输出数组不计入额外空间。两个扫描方向各访问一次数组，适合长度达到 100000 的输入。

Implementation

四语言实现 

var statisticalResult = function(arrayA) {
  const answer = Array(arrayA.length).fill(1);
  let prefix = 1;
  for (let i = 0; i < arrayA.length; i++) {
    answer[i] = prefix;
    prefix *= arrayA[i];
  }
  let suffix = 1;
  for (let i = arrayA.length - 1; i >= 0; i--) {
    answer[i] *= suffix;
    suffix *= arrayA[i];
  }
  return answer;
};
from typing import List

class Solution:
    def statisticalResult(self, arrayA: List[int]) -> List[int]:
        answer = [1] * len(arrayA)
        prefix = 1
        for i, value in enumerate(arrayA):
            answer[i] = prefix
            prefix *= value
        suffix = 1
        for i in range(len(arrayA) - 1, -1, -1):
            answer[i] *= suffix
            suffix *= arrayA[i]
        return answer

Explanation

题解

令 answer[i] 先保存 arrayA[0] × … × arrayA[i - 1]。反向扫描时，变量 suffix 保存 arrayA[i + 1] × … × arrayA[n - 1]，二者相乘正好遗漏 arrayA[i]。

前向扫描结束后，answer 已经复用了输出空间；反向扫描只需一个 suffix 变量。因此在不计返回数组的复杂度模型中，额外空间是 O(1)。

边界：数组只有两个元素时每格得到另一项；出现一个 0 时只有对应位置可能为非零；出现两个及以上 0 时所有结果为 0。前后缀扫描无需为这些情况写任何分支。

正确性：正向循环第 i 次写入前，prefix 恰为所有下标小于 i 的元素乘积；反向循环第 i 次处理时，suffix 恰为所有下标大于 i 的元素乘积。因此合流值只乘了除 i 外的全部元素，且每个位置都被处理一次。
