Basic Calculator II

扫描表达式，不调用 eval：把加减项入栈，遇到乘除就立刻折叠，最后求和。

题意

给定有效表达式字符串 s，计算并返回结果。只包含非负整数、+ - * / 和空格；整数除法必须向 0 截断，不能调用任何内建表达式求值函数。

约束
1 ≤ s.length ≤ 3 × 10⁵；中间结果位于 32 位有符号整数范围；答案保证可用 32 位整数表示。

官方样例（转述）

输入s = "3+2*2"输出7
输入s = "␠3/2␠"输出1
输入s = "␠3+5␠/␠2␠"输出5

␠ 表示一个可见的普通空格。

题解：用栈延迟加减，立即处理乘除

扫描字符累积 num。当遇到运算符或字符串末尾时，依据上一个运算符处理刚读完的数字：+ 压入 num，- 压入 −num，*// 则弹出栈顶并与 num 计算后压回。

  1. 空格直接略过，数字连续累积为多位整数。
  2. 初始前一个运算符设为 '+'，让第一个数字自然入栈。
  3. 末尾也必须触发一次处理，因此判断 i == length - 1。
  4. 最后求栈中所有带符号项的和。
优先级为何正确？乘除在入栈前就与前一项合并；剩下的栈只包含同优先级的加减项，线性求和即可。

完整过程

3 由初始 + 入栈；读到 2 时前一个 +，压入 2；读到最后一个 2 时前一个 *，将栈顶 2 替换成 4。栈为 [3,4]，和为 7。

边界与复杂度

多位数和首尾空格都由扫描器覆盖。Java/C++ 的整数除法向 0 截断；JavaScript/Python 必须显式使用 trunc。时间 O(n)，最坏额外空间 O(n)。

替代方案

也可只用 sum 与 lastTerm 把空间降为 O(1)：乘除时调整 lastTerm 并同步 sum。但栈版本更直观，也更适合首次面试讲解。

面试追问

若加入括号（Basic Calculator III），遇到左括号递归求子表达式或用双栈；若要支持一元负号，需要在词法阶段识别其位置。

常见错误

  • 遇到当前运算符就用它处理 num，应该用“前一个运算符”。
  • 漏掉末尾数字的结算。
  • 对负数除法使用向下取整而不是向 0 截断。
  • 使用 eval，违反题意且无法展示解析过程。
