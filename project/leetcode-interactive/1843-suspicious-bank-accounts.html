Suspicious Bank Accounts

MEDIUM数据库付费题

观察月度入账，判断异常是否持续发生。先阅读业务规则，再按需展开底部题解。

阅读题意 ↓

题意与约束

给定账户表和交易表，返回至少连续两个自然月的入账总额都严格超过该账户 max_income 的账户编号。月收入仅累加 Creditor（存入）交易，Debtor（取出）不抵扣收入。结果只保留不同的 account_id，顺序不限。

独立题解

准备好后展开推导与代码。

核心洞察

原始交易行不是判定单位，账户的自然月才是。先聚合出唯一的账户月份行，再检查两条超额行的月份是否连续。令 month_id = YEAR(day) × 12 + MONTH(day)，跨年相邻月也恰好相差 1。

完整过程

  1. 只保留 Creditor，按 account_id 和 month_id 分组，累加入账。
  2. 连接 Accounts，保留 income > max_income 的月份。
  3. 超额月份表自连接，要求账户一致且后一月编号等于前一月加一。
  4. DISTINCT account_id，避免连续三个月或多个区间造成重复。

正确性

聚合恰好包含每个账户当月的全部存入，所以月收入与定义相同。过滤后恰好保留所有超额月。连接命中的两行来自同账户、相邻自然月且都超额，因此返回账户必符合条件。反过来，任意至少两个月的连续超额区间都包含相邻的一对超额月，这两行必然保留并匹配，因此不会遗漏。去重只消除重复行，不改变账户集合。

边界与常见错误

  • 不要用 >=，恰好等于上限不符合。
  • 不要用存入减取出的净额，Debtor 应直接忽略。
  • 同月多笔入账应先合计；不能把两条超额交易当作两个月。
  • 只用 MONTH 会混合年份；YYYYMM 加一不能处理跨年。
  • 两个超额月之间缺月，不构成连续。没有交易时输出空表。
  • 连续三月可能匹配两对，必须去重。累计金额要使用足够宽的数值类型。

复杂度

设 A 为账户数，T 为交易数，M 为聚合后的账户月份数。本地哈希参考实现平均耗时 O(A + T + M)，空间 O(A + M)。SQL 取决于执行计划：排序聚合可耗时 O(T log T)，相邻月连接若无有效索引或哈希连接最坏可达 O(M²)，不能无条件声称 SQL 线性时间。

替代方案与面试追问

可以对超额月份按账户分区、月份排序，使用 LAG 比较前一超额月编号，差 1 即命中，排序通常为 O(M log M)。若改成连续 K 个月，可按 month_id − ROW_NUMBER() 构造连续段，再筛选段长。若需返回异常区间，保留每段起止月份。真实业务还需约定时区和币种，本题按 day 给定的自然月计算。

MySQL 8 · 官方可提交语言

WITH monthly AS (
    SELECT account_id,
           YEAR(day) * 12 + MONTH(day) AS month_id,
           SUM(amount) AS income
    FROM Transactions
    WHERE type = 'Creditor'
    GROUP BY account_id, YEAR(day) * 12 + MONTH(day)
), excessive AS (
    SELECT m.account_id, m.month_id
    FROM monthly m
    JOIN Accounts a ON a.account_id = m.account_id
    WHERE m.income > a.max_income
)
SELECT DISTINCT x.account_id
FROM excessive x
JOIN excessive y
  ON x.account_id = y.account_id
 AND y.month_id = x.month_id + 1;

JavaScript · 本地语义参考

// accounts: {account_id, max_income}[]
// transactions: {transaction_id, account_id, type, amount, day}[]
// 金额与累计结果需在 Number 安全整数范围内。
function suspiciousAccounts(accounts, transactions) {
  const limits = new Map(accounts.map(a => [a.account_id, a.max_income]));
  const sums = new Map();
  for (const t of transactions) {
    if (t.type !== 'Creditor') continue;
    const m = Number(t.day.slice(0, 4)) * 12 + Number(t.day.slice(5, 7));
    if (!sums.has(t.account_id)) sums.set(t.account_id, new Map());
    const row = sums.get(t.account_id);
    row.set(m, (row.get(m) || 0) + t.amount);
  }
  const result = [];
  for (const [id, row] of sums) {
    if (!limits.has(id)) continue;
    const cap = limits.get(id);
    for (const [m, value] of row) {
      if (value > cap && row.has(m + 1) && row.get(m + 1) > cap) {
        result.push({account_id: id});
        break;
      }
    }
  }
  return result;
}

from collections import defaultdict

# 输入为两张表的字典列表。
def suspicious_accounts(accounts, transactions):
    limits = {a['account_id']: a['max_income'] for a in accounts}
    sums = defaultdict(lambda: defaultdict(int))
    for t in transactions:
        if t['type'] != 'Creditor':
            continue
        m = int(t['day'][:4]) * 12 + int(t['day'][5:7])
        sums[t['account_id']][m] += t['amount']
    result = []
    for account, row in sums.items():
        if account not in limits:
            continue
        cap = limits[account]
        if any(value > cap and m + 1 in row and row[m + 1] > cap
               for m, value in row.items()):
            result.append({'account_id': account})
    return result

Java 17 · 本地语义参考

import java.util.*;

public class Solution {
    public record Account(int account_id, long max_income) {}
    public record Transaction(int transaction_id, int account_id,
                              String type, long amount, String day) {}
    public List<Integer> suspiciousAccounts(List<Account> accounts,
                                           List<Transaction> transactions) {
        Map<Integer, Long> limits = new HashMap<>();
        for (Account a : accounts) limits.put(a.account_id(), a.max_income());
        Map<Integer, Map<Integer, Long>> sums = new HashMap<>();
        for (Transaction t : transactions) {
            if (!t.type().equals("Creditor")) continue;
            int m = Integer.parseInt(t.day().substring(0, 4)) * 12
                  + Integer.parseInt(t.day().substring(5, 7));
            sums.computeIfAbsent(t.account_id(), k -> new HashMap<>())
                .merge(m, t.amount(), Long::sum);
        }
        List<Integer> result = new ArrayList<>();
        for (var account : sums.entrySet()) {
            Long cap = limits.get(account.getKey());
            if (cap == null) continue;
            var row = account.getValue();
            for (var entry : row.entrySet()) {
                Long next = row.get(entry.getKey() + 1);
                if (entry.getValue() > cap && next != null && next > cap) {
                    result.add(account.getKey());
                    break;
                }
            }
        }
        return result;
    }
}

C++17 · 本地语义参考

#include <string>
#include <vector>
#include <unordered_map>
using namespace std;
struct Account { int account_id; long long max_income; };
struct Transaction {
    int transaction_id, account_id;
    string type;
    long long amount;
    string day;
};
vector<int> suspiciousAccounts(const vector<Account>& accounts,
                               const vector<Transaction>& transactions) {
    unordered_map<int, long long> limits;
    for (const auto& a : accounts) limits[a.account_id] = a.max_income;
    unordered_map<int, unordered_map<int, long long>> sums;
    for (const auto& t : transactions) {
        if (t.type != "Creditor") continue;
        int m = stoi(t.day.substr(0, 4)) * 12 + stoi(t.day.substr(5, 2));
        sums[t.account_id][m] += t.amount;
    }
    vector<int> result;
    for (const auto& account : sums) {
        auto cap = limits.find(account.first);
        if (cap == limits.end()) continue;
        const auto& row = account.second;
        for (const auto& entry : row) {
            auto next = row.find(entry.first + 1);
            if (entry.second > cap->second && next != row.end()
                && next->second > cap->second) {
                result.push_back(account.first);
                break;
            }
        }
    }
    return result;
}
