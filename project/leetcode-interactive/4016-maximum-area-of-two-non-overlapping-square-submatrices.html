两个不重叠子正方形的最大面积

从全 1 正方形出发，利用“两个不相交轴对齐矩形总能被一条横线或竖线隔开”，把二维配对变成两次线性扫描。

二维动态规划前后缀最大值矩阵转置复用
返回的是每个正方形的面积k²，而不是 2k²

先取同一条分割线两侧可得边长的较小者，再平方。

题意 · 完整说明

给定 m × n 二进制矩阵 mat：1 表示可用，0 表示不可用。选择两个边长相同的子矩阵；它们都必须是只含 1 的正方形，且不能共享任何单元格。返回每个正方形可取得的最大面积；无法选出一对时返回 0。

约束：1 ≤ m,n ≤ 500。不能枚举两块正方形的位置和边长；目标是 O(mn)。

样例

[[1,1,1,0],[1,1,1,1],[0,0,1,1]] 中，左上与右下各有边长 2 的全 1 正方形，答案为 4。

隐藏题解前先看障碍

  1. “两个”会诱导枚举成对位置，造成组合爆炸。
  2. 最大单方块不一定能与另一个最大单方块配对，不能贪心。
  3. 两块必须同边长；两侧能做到 5 和 3 时，只能配边长 3。
关键几何事实：两个轴对齐且不相交的矩形，行区间或列区间至少一组不相交。因此总存在水平或竖直分割线把它们分开。
显示解题核心

分别计算每条切线两侧能容纳的最大全 1 正方形边长。对每条线取两侧最小值，并在横切与竖切中取最大。

洞察：把“两个方块”压缩成“一条线”

  1. 求每个位置可扩出的最大全 1 正方形边长。
  2. 枚举水平线，记录线上方与线下方各自能提供的最大边长。
  3. 该线可配的边长是两者最小值，面积为其平方。
  4. 转置矩阵后复用逻辑，覆盖竖直分割线。

为什么不二分？

二维前缀和 + 二分可做，但每次判定仍需扫描矩阵；DP 直接给出每点最大边长，少一层 log min(m,n)。

DP 状态与过程

down[r][c] 表示以 (r,c) 为左上角的最大全 1 正方形边长： 

down[r][c] = mat[r][c] ? 1 + min(down[r+1][c], down[r][c+1], down[r+1][c+1]) : 0

倒序 DP 给出线下候选，正序 DP 给出线上候选。每行取最大，再做前缀 / 后缀最大值，就确保方块完全落在切线一侧。

过程演示

1. 自底向上

行 r 的最大 down 值是“从该行开始”的最大方块。后缀最大值 below[r] 表示完全在第 r 行及之后的最佳边长。

2. 自顶向下

正序 DP 取得“以该行收尾”的最大方块；前缀最大值 above[r] 表示完全在第 r 行及之前的最佳边长。

3. 枚举切线

对 r | r+1，公共边长为 min(above[r], below[r+1])。保留最大的平方。

4. 转置复用

矩阵转置后，“左右切”变为“上下切”。两个答案取最大，所有合法不重叠对都被覆盖。

边界、复杂度与替代

情况 处理
不足两个 1 任何分割都给边长 0，答案为 0。
斜对角方块 它们仍会在行或列上分离，横 / 竖扫描必覆盖。
一侧大、一侧小 取 min 保证两块同边长。

时间：O(mn)；空间：O(mn)，DP 可滚动优化到 O(n)。

替代方案：前缀和 + 二分

二维前缀和可 O(1) 判 k×k 是否全 1，再二分 k 并检查可分割的一对。更通用，但复杂度约为 O(mn log min(m,n))。

常见错误与追问

  1. 返回总面积：答案是 k²，不是 2k²。
  2. 只找两个最大方块：最大单方块可能堵住另一个候选；必须按切线配对。
  3. 遗漏竖切：只扫行会漏掉左右排列；转置复用最稳。
  4. 边界越界：DP 外扩一圈 0，三个邻居可直接访问。

追问

如何恢复坐标？前后缀同时保存边长与起点 / 终点即可。
如果选三个？一条切线不足，需要二维分区 DP 或更复杂状态。
