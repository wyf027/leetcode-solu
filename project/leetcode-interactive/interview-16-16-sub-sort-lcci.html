01 / Brief

题意与样例

任务

给定整数数组 array，寻找最短闭区间 [m,n]。将区间内元素升序排列后，整个数组必须有序；若数组原本有序，返回 [-1,-1]。

空数组也视为已经有序。

官方样例

输入 array = [1,2,4,7,10,11,7,12,6,7,16,18,19]
期望输出 [3,9]
解释 仅排序 array[3..9]，整个数组恢复升序

约束

0 <= array.length <= 1,000,000

百万级长度意味着复制并排序整个数组并非面试中的最优主线。

返回值边界

区间使用闭区间语义。全部逆序时可能返回整个数组；有序、单元素或空数组都返回 [-1,-1]。

04 / Solution vault

完成巡检后再打开题解

核心洞察、完整推导、复杂度、替代方案与四语言代码都收在这里。

核心洞察

从左向右维护前缀最大值 maxSeen。若 array[i] < maxSeen，说明当前元素前面存在比它大的值，因此 i 必须落在待排序区间内，持续更新右边界 n。

对称地，从右向左维护后缀最小值 minSeen。若 array[i] > minSeen，当前位置右边存在更小值，持续更新左边界 m。

完整过程

  1. 令 m = n = -1。
  2. 前向扫描，维护最大值并锁定最后一个逆序位置 n。
  3. 若 n == -1，数组已有序，直接返回。
  4. 后向扫描，维护最小值并锁定最前一个逆序位置 m。
  5. 返回闭区间 [m,n]。

边界条件

  • 空数组、单元素、有序数组：返回 [-1,-1]。
  • 全逆序：返回 [0,n-1]。
  • 重复值必须使用严格比较：前向是 <，后向是 >。
  • 扫描只读取数组，不需要真的排序。

复杂度

维度 结果 原因
时间 O(n) 前后各扫描一次
空间 O(1) 只维护四个标量

替代方案

复制数组并排序，再比较首尾差异，直观但需要 O(n) 额外空间与 O(n log n) 时间。单调栈也能找边界，但需要 O(n) 空间。面试中优先选择双向扫描。

面试追问

  • 为什么右边界由前缀最大值决定？
  • 重复值时把严格比较改成非严格比较会怎样？
  • 能否把两次扫描写进同一个循环？可以，但可读性通常更差。
  • 如果数组来自数据流，何时才能确定最终左边界？

常见错误

  • 只找相邻逆序对，遗漏需要向外扩展的边界。
  • 先找一个局部降序片段就停止，无法覆盖后续更小或更大的元素。
  • 有序数组返回 [0,0]，而不是题目要求的 [-1,-1]。
  • 对空数组直接读取 array[0]。
