Problem

题目转述

有 n 个人，编号从 0 到 n - 1。watchedVideos[i] 是第 i 个人看过的视频，friends[i] 是其好友编号。

从你的 id 出发，好友关系图中最短路径长度恰好等于 level 的所有人构成目标层。收集这些人的视频并统计出现次数，先按频次升序，再对同频视频按字母升序返回名称列表。

关键语义：不是“距离不超过 level”，也不是沿任意长度为 level 的路径；只取最短距离恰好为 level 的人。

函数签名

watchedVideosByFriends(
  watchedVideos: List<List<String>>,
  friends: int[][],
  id: int,
  level: int
) -> List<String>

约束

  • n == watchedVideos.length == friends.length
  • 2 ≤ n ≤ 100
  • 1 ≤ watchedVideos[i].length ≤ 100
  • 1 ≤ watchedVideos[i][j].length ≤ 8
  • 0 ≤ friends[i].length < n，且好友编号合法
  • 0 ≤ id < n，1 ≤ level < n
  • 好友关系双向：i 的列表含 j，则 j 的列表含 i

Solution

分层 BFS + 频次排序

核心洞察

无权图中的 BFS 天生按最短距离逐层扩张。队列推进完恰好 level 层后，队列里的节点正是最短距离等于该层数的人；只对他们的视频计数，再用二级比较器排序。

复杂度

设好友图有 V 个点、E 条边，目标层共记录 M 次视频、不同视频有 U 个。时间为 O(V + E + M + U log U)，空间为 O(V + U)。

完整过程

  1. 建立访问数组，把 id 入队并标记已访问。
  2. 重复 level 次：记住本层队列长度，只弹出这些节点，将所有尚未访问的好友标记并入队。
  3. 循环结束时，队列只保留目标层的人；遍历他们的 watchedVideos，用哈希表累计频次。
  4. 取出不同视频名，比较时先看频次；频次相同再按字典序比较。

正确性证明

分层不变量：第 d 轮开始时，队列恰好包含从 id 出发最短距离为 d 的全部节点。d = 0 时队列只有 id，成立。
归纳推进：处理距离 d 的所有节点时，未访问邻居首次被发现，其最短距离必为 d + 1；已有更短路径的节点已访问，不会重复加入。因此下一轮队列恰为第 d + 1 层。
计数与排序：推进 level 轮后，队列恰为目标层。哈希表逐条计入这些人的每次观看记录，得到准确频次；指定比较器正好实现频次升序、同频字母升序，故结果正确。

边界情况

  • 不同目标好友看过同名视频：次数必须累加。
  • 同一人的列表若出现重复名，也按出现次数计入。
  • 图中存在环：访问标记阻止回到起点或重复入队。
  • 目标层只有一人或同频视频很多，排序规则仍然一致。

替代方案与面试追问

DFS：可记录每个节点的最小深度，但需要剪枝并防止先由更长路径到达，复杂度和证明都更绕；本题优先 BFS。

追问：若有大量不同 id、level 查询，可预处理全源最短路或按起点缓存分层结果；若好友边带权，则需改用 Dijkstra。

常见错误

  • 出队时才标记访问，导致同层多个节点把同一好友重复入队。
  • 层循环未固定当前队列长度，把下一层也在同一轮处理掉。
  • 统计了 0 到 level 的所有层，而不是只统计第 level 层。
  • 比较器只按频次排序，遗漏同频时的字母序。
  • 直接把“频次 + 名称”拼成字符串排序，产生数值和字符排序陷阱。

class Solution {
    public List<String> watchedVideosByFriends(
            List<List<String>> watchedVideos,
            int[][] friends, int id, int level) {
        boolean[] visited = new boolean[friends.length];
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(id);
        visited[id] = true;

        for (int depth = 0; depth < level; depth++) {
            int size = queue.size();
            while (size-- > 0) {
                int person = queue.poll();
                for (int friend : friends[person]) {
                    if (!visited[friend]) {
                        visited[friend] = true;
                        queue.offer(friend);
                    }
                }
            }
        }

        Map<String, Integer> count = new HashMap<>();
        for (int person : queue) {
            for (String video : watchedVideos.get(person)) {
                count.merge(video, 1, Integer::sum);
            }
        }

        List<String> answer = new ArrayList<>(count.keySet());
        answer.sort((a, b) -> {
            int byFrequency = Integer.compare(count.get(a), count.get(b));
            return byFrequency != 0 ? byFrequency : a.compareTo(b);
        });
        return answer;
    }
}

/**
 * @param {string[][]} watchedVideos
 * @param {number[][]} friends
 * @param {number} id
 * @param {number} level
 * @return {string[]}
 */
var watchedVideosByFriends = function(watchedVideos, friends, id, level) {
    const visited = Array(friends.length).fill(false);
    let queue = [id];
    visited[id] = true;

    for (let depth = 0; depth < level; depth++) {
        const next = [];
        for (const person of queue) {
            for (const friend of friends[person]) {
                if (!visited[friend]) {
                    visited[friend] = true;
                    next.push(friend);
                }
            }
        }
        queue = next;
    }

    const count = new Map();
    for (const person of queue) {
        for (const video of watchedVideos[person]) {
            count.set(video, (count.get(video) || 0) + 1);
        }
    }

    return [...count.keys()].sort((a, b) =>
        count.get(a) - count.get(b) || a.localeCompare(b)
    );
};
Python 3 · LeetCode 可提交
from collections import Counter, deque
from typing import List


class Solution:
    def watchedVideosByFriends(
        self,
        watchedVideos: List[List[str]],
        friends: List[List[int]],
        id: int,
        level: int,
    ) -> List[str]:
        visited = [False] * len(friends)
        queue = deque([id])
        visited[id] = True

        for _ in range(level):
            for _ in range(len(queue)):
                person = queue.popleft()
                for friend in friends[person]:
                    if not visited[friend]:
                        visited[friend] = True
                        queue.append(friend)

        count = Counter()
        for person in queue:
            count.update(watchedVideos[person])

        return sorted(count, key=lambda video: (count[video], video))
C++ · LeetCode 可提交
class Solution {
public:
    vector<string> watchedVideosByFriends(
        vector<vector<string>>& watchedVideos,
        vector<vector<int>>& friends,
        int id,
        int level
    ) {
        vector<bool> visited(friends.size(), false);
        queue<int> people;
        people.push(id);
        visited[id] = true;

        for (int depth = 0; depth < level; ++depth) {
            int size = people.size();
            while (size-- > 0) {
                int person = people.front();
                people.pop();
                for (int friendId : friends[person]) {
                    if (!visited[friendId]) {
                        visited[friendId] = true;
                        people.push(friendId);
                    }
                }
            }
        }

        unordered_map<string, int> count;
        while (!people.empty()) {
            int person = people.front();
            people.pop();
            for (const string& video : watchedVideos[person]) {
                ++count[video];
            }
        }

        vector<string> answer;
        for (const auto& [video, frequency] : count) {
            answer.push_back(video);
        }
        sort(answer.begin(), answer.end(), [&](const string& a, const string& b) {
            if (count[a] != count[b]) return count[a] < count[b];
            return a < b;
        });
        return answer;
    }
};
