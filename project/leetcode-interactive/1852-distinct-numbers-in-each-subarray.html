每个子数组的数字种类数

Distinct Numbers in Each Subarray

MEDIUM · 付费题

同样长度的片段，可能藏着不同数量的数字。先理解要统计什么，再展开解法。

题目 · 固定长度的连续片段

给定整数数组 nums 和整数 k。对每个长度恰好为 k 的连续子数组，统计其中不同整数的个数。按子数组起点从左到右返回这些计数。

令 n = nums.length，返回长度为 n − k + 1 的数组 ans，其中 ans[i] 对应下标 i 到 i + k − 1（两端均包含）的片段。重复出现的同一个值只算一种。

约束：1 ≤ k ≤ nums.length ≤ 10⁵；1 ≤ nums[i] ≤ 10⁵。
提交函数：distinctNumbers(nums, k) → integer[]。

官方示例 1

输入：nums = [1,2,3,2,2,1,3], k = 3
输出：[3,2,2,2,3]

五个片段依次为 [1,2,3]、[2,3,2]、[3,2,2]、[2,2,1]、[2,1,3]，种类数分别为 3、2、2、2、3。

官方示例 2

输入：nums = [1,1,1,1,2,3,4], k = 4
输出：[1,2,3,4]

片段依次为 [1,1,1,1]、[1,1,1,2]、[1,1,2,3]、[1,2,3,4]，种类数逐个增加。

题面为概括转述。题号、函数与示例输入来自本地官方元数据；空缺题面、输出与约束参考 公开题目资料。官方题目。

先想一想

如果片段里有三个 2，移走其中一个 2，会不会减少数字种类？你会如何避免每次从头统计？

下面的题解包含交互演示和四语言代码。准备好后再展开。

题解 · 为每种数字保留一张计数卡

核心洞察：相邻窗口有 k − 1 个位置重叠。维护值到出现次数的映射，只在频次从 0 变为 1 或从 1 变为 0 时改变种类数。移走一个副本并不等于移走整个种类。

交互实验 · 移出 / 移入 / 记录

固定使用官方示例 1（k = 3）。紫色为当前成员，橙色为刚移出的下标，绿色为刚移入的下标。中间状态可能只有 k − 1 项，此时不记录答案。

Tab 切换按钮，Enter / 空格操作。减少动态效果偏好下仍可手动单步；自动播放需主动点击。

完整过程

  1. 从左到右枚举右端点 r，频次表初始为空。
  2. 当 r ≥ k，先移除 nums[r − k] 的一个副本；若频次变为 0，删除键。
  3. 加入 nums[r] 的一个副本。
  4. 当 r ≥ k − 1，窗口已完整，把频次表的键数写入 ans[r − k + 1]。

正确性

不变式：每轮移出与移入完成后，表中仅有当前片段 nums[max(0,r−k+1)..r] 内出现的值，其频次精确等于出现次数。起初空表成立；移出旧左端点恰好删除离开片段的一次出现，加入右端点恰好增加新出现，故不变式保持。所有零频次键都被删除，因此键数等于不同值数量。从 r = k − 1 开始，每轮恰好产生一个合法窗口，覆盖所有 n − k + 1 个起点且无重复，答案正确。

边界与复杂度

  • k = 1：每个窗口都只有一种；k = n：只输出一次。
  • 全部相同：移出后仍有副本时不能删键；全部不同：每个完整窗口答案均为 k。
  • 移出值与移入值相同：最终频次不变，中间变化不能提前写入答案。
  • 哈希表操作按均摊 O(1) 计算，总时间 O(n)，辅助空间 O(min(k,U))，U 为数组不同值总数；返回数组另占 O(n − k + 1)。哈希退化时不保证最坏 O(n)。

替代方案

每个窗口重建集合容易理解，但需要 O((n−k+1)k) 时间和 O(k) 空间。值域只有 1..10⁵ 时也可使用频次数组加独立 distinct 变量，时间 O(n + Uₘₐₓ)，空间 O(Uₘₐₓ)，其中 Uₘₐₓ = 10⁵；数组初始化成本也要算入。

常见错误

  • 仅使用 Set：删除重复值时会丢失仍在窗口内的副本。
  • 保留频次 0 的键，再直接取表大小，会多算。
  • r 尚未达到 k − 1 就输出，或用 r − k 作为答案下标，产生错位。
  • 把“种类数”当作“恰好出现一次的值数量”：二者不同。

面试追问

数据流怎么办？ 用长度 k 的队列保存待移出的元素，配合频次表即可在线输出。窗口大小会变化呢？ 每次移动边界都更新频次；查询时必须确保表对应新的区间。需要每窗恰好出现一次的值数？ 另维护计数，只在频次跨越 0↔1 或 1↔2 时调整。

Java

import java.util.*;

class Solution {
    public int[] distinctNumbers(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        int[] ans = new int[nums.length - k + 1];
        for (int r = 0; r < nums.length; r++) {
            if (r >= k) {
                int old = nums[r - k];
                int remaining = freq.get(old) - 1;
                if (remaining == 0) freq.remove(old);
                else freq.put(old, remaining);
            }
            freq.put(nums[r], freq.getOrDefault(nums[r], 0) + 1);
            if (r >= k - 1) ans[r - k + 1] = freq.size();
        }
        return ans;
    }
}

    const ans = [];

            if (remaining === 0) freq.delete(old);

    }
    return ans;

Python

from typing import List

class Solution:
    def distinctNumbers(self, nums: List[int], k: int) -> List[int]:
        freq = {}
        ans = []
        for r, value in enumerate(nums):
            if r >= k:
                old = nums[r - k]
                freq[old] -= 1
                if freq[old] == 0:
                    del freq[old]
            freq[value] = freq.get(value, 0) + 1
            if r >= k - 1:
                ans.append(len(freq))
        return ans

C++

#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    vector<int> distinctNumbers(vector<int>& nums, int k) {
        unordered_map<int, int> freq;
        vector<int> ans;
        for (int r = 0; r < static_cast<int>(nums.size()); ++r) {
            if (r >= k) {
                int old = nums[r - k];
                if (--freq[old] == 0) freq.erase(old);
            }
            ++freq[nums[r]];
            if (r >= k - 1) ans.push_back(static_cast<int>(freq.size()));
        }
        return ans;
    }
};
