单词拆分 II Word Break II / enumerate every valid sentence

不只判断“能不能拆”，而要把每一种合法句子都找出来。沿分句树向下探索；当多个分支抵达同一后缀时，从记忆仓库直接取回已经完成的句子集合。

Mission brief

把全部句子带回来

给定字符串和互不相同的字典单词，在原字符串中加入空格，使每段都来自字典；返回所有可能句子，顺序不限。字典单词可以重复使用。

题意转述

每次从当前位置选择一个能够匹配前缀的字典单词，再对剩余后缀继续选择。只有恰好走到字符串末尾的路径，才形成一条答案。

  • s.length 为 1～20。
  • wordDict.length 为 1～1000。
  • 每个单词长度为 1～10，仅包含小写英文字母。
  • 答案总长度不超过 10^5。
关键差异：第 139 题只返回布尔值；本题必须保留每条成功路径，因此复杂度天然与输出规模相关。

官方样例 1

输入 s = "catsanddog" wordDict = ["cat","cats","and","sand","dog"]
输出 ["cat sand dog","cats and dog"]

句子里的空格是分隔符；若输入中出现空格，本页会用 ␠ 显示，但本题输入本身不含空格。

            Memoized DFS playbook
          
        
          
        
            从后缀答案反推整句
          
        

          
        
            
        
              
        核心洞察
        
              
        
                定义 dfs(start) 为“从下标
                start 到末尾能组成的全部句子”。若前缀单词
                word 合法，就把它与
                dfs(end) 的每条后缀句子拼接。
              
        
              
        
                不同前缀可能抵达同一
                start。缓存该下标的句子集合，可避免重复展开同一棵后缀子树。
              
        
            
        

            
        
              
        完整过程
        
              
          
                
        1. 把字典放入哈希集合，并记录最长单词长度。
          2. 
                
        2. 
                  从 start 起枚举至多 maxLen 个字符。
                
          3. 
                
        3. 前缀在字典中时，递归取得后缀全部句子。
          4. 
                
        4. 
                  将前缀与每条后缀组合；到达末尾时返回一个空串作为拼接哨兵。
                
          5. 
                
        5. 把当前下标结果写入 memo，再返回给上层。
          6. 
              
        
            
        

            
        
              
        边界与正确性
        
              
          
                
        • 
                  到达 s.length 时返回
                  [""]，让最后一个单词无需额外空格。
                
          • 
                
        • 无合法前缀时返回空列表，并同样缓存。
          • 
                
        • 
                  字典词可重复使用，因为每次只推进字符串下标，不会删除单词。
                
          • 
                
        • 
                  每条答案对应一条从 0 到 n
                  的唯一路径，算法既不会漏，也不会重复生成同一路径。
                
          • 
              
        
            
        

            
        
              
        复杂度
        
              
        
                设 n 为字符串长度，L
                为最长单词长度，A
                为最终输出的总字符数。考虑子串构造，搜索检查约为
                O(n·L²)，生成答案还需 O(A)，总计
                O(n·L² + A)。
              
        
              
        
                空间为递归栈、memo 与保存句子的总规模，可写作
                O(n + S)；其中
                S
                是缓存中所有后缀句子的总字符数，至少受输出规模影响。
              
        
            
        

            
        
              
        替代方案取舍
        
              
          
                
        • 
                  纯回溯：写法直观，但同一后缀会被指数级重复搜索。
                
          • 
                
        • 
                  自底向上 DP：同样可行，但每个位置存整组句子，面试中更难自然解释路径拼接。
                
          • 
                
        • 
                  Trie：可减少前缀匹配开销；在本题
                  n ≤ 20 下，哈希集合更简洁。
                
          • 
              
        
            
        

            
        
              
        面试追问
        
              
          
                
        • 若只要答案数量，memo 中应存什么？
          • 
                
        • 若只返回前 K 条句子，如何提前停止搜索？
          • 
                
        • 怎样先用第 139 题的可达性 DP 剪掉必死后缀？
          • 
                
        • 为什么本题无法承诺与输出无关的多项式时间？
          • 
              
        
            
        

            
        
              
        常见错误
        
              
          
                
        • 基线返回空列表，导致最后一个单词无法与任何后缀组合。
          • 
                
        • 只缓存“能否拆分”，却仍然反复生成相同后缀句子。
          • 
                
        • 拼接时无条件添加空格，产生尾部空格或多余空格。
          • 
                
        • 
                  认为
                  Set
                  会导致答案重复；真正的重复来自重复字典词，而题目已保证字典元素互不相同。

        class Solution {
    public List<String> wordBreak(String s, List<String> wordDict) {
        Set<String> words = new HashSet<>(wordDict);
        int maxLen = 0;
        for (String word : wordDict) {
            maxLen = Math.max(maxLen, word.length());
        }
        return dfs(s, 0, words, maxLen, new HashMap<>());
    }

    private List<String> dfs(
        String s,
        int start,
        Set<String> words,
        int maxLen,
        Map<Integer, List<String>> memo
    ) {
        if (memo.containsKey(start)) {
            return memo.get(start);
        }
        if (start == s.length()) {
            return List.of("");
        }

        List<String> result = new ArrayList<>();
        int limit = Math.min(s.length(), start + maxLen);
        for (int end = start + 1; end <= limit; end++) {
            String word = s.substring(start, end);
            if (!words.contains(word)) {
                continue;
            }
            for (String tail : dfs(s, end, words, maxLen, memo)) {
                result.add(word + (tail.isEmpty() ? "" : " " + tail));
            }
        }
        memo.put(start, result);
        return result;
    }
}
        

              
        var wordBreak = function (s, wordDict) {
  const words = new Set(wordDict);
  const maxLen = Math.max(...wordDict.map((word) => word.length));
  const memo = new Map();

  const dfs = (start) => {
    if (memo.has(start)) return memo.get(start);
    if (start === s.length) return [""];

    const result = [];
    const limit = Math.min(s.length, start + maxLen);
    for (let end = start + 1; end <= limit; end += 1) {
      const word = s.slice(start, end);
      if (!words.has(word)) continue;
      for (const tail of dfs(end)) {
        result.push(word + (tail ? ` ${tail}` : ""));
      }
    }
    memo.set(start, result);
    return result;
  };

  return dfs(0);
};
        

              
        from functools import cache
from typing import List


class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> List[str]:
        words = set(wordDict)
        max_len = max(map(len, wordDict))

        @cache
        def dfs(start: int) -> tuple[str, ...]:
            if start == len(s):
                return ("",)

            result = []
            limit = min(len(s), start + max_len)
            for end in range(start + 1, limit + 1):
                word = s[start:end]
                if word not in words:
                    continue
                for tail in dfs(end):
                    result.append(word + (" " + tail if tail else ""))
            return tuple(result)

        return list(dfs(0))
        

              
        class Solution {
public:
    vector<string> wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> words(wordDict.begin(), wordDict.end());
        int maxLen = 0;
        for (const string& word : wordDict) {
            maxLen = max(maxLen, static_cast<int>(word.size()));
        }
        unordered_map<int, vector<string>> memo;
        return dfs(s, 0, words, maxLen, memo);
    }

private:
    vector<string> dfs(
        const string& s,
        int start,
        const unordered_set<string>& words,
        int maxLen,
        unordered_map<int, vector<string>>& memo
    ) {
        if (memo.count(start)) return memo[start];
        if (start == static_cast<int>(s.size())) return {""};

        vector<string> result;
        int limit = min(static_cast<int>(s.size()), start + maxLen);
        for (int end = start + 1; end <= limit; end++) {
            string word = s.substr(start, end - start);
            if (!words.count(word)) continue;
            for (const string& tail : dfs(s, end, words, maxLen, memo)) {
                result.push_back(word + (tail.empty() ? "" : " " + tail));
            }
        }
        memo[start] = result;
        return result;
    }
};
