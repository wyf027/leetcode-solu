题目说明

函数：scoreOfParentheses(s) → integer

给定一个仅由 ( 和 ) 组成的平衡括号字符串 s，请按照下面三条规则返回它的分数。

() = 1
最小的平衡单元得 1 分。
AB = A + B
相邻的平衡片段分数相加。
(A) = 2 × A
外层括号让内部片段翻倍。

Solution

一次扫描：只为最小单元计分

核心洞察

每一分最终都来自某个最小单元 ()。若这个单元外面包了 d 层括号，它就贡献 2d。所以扫描时只需记录深度，并在遇到相邻的 () 时加上对应权重。

完整过程

  1. 令 depth = 0、score = 0，从左向右扫描。
  2. 读到 (，进入一层：depth++。
  3. 读到 )，先退出一层：depth--。
  4. 若当前 ) 的前一个字符是 (，说明刚闭合一个最小单元；把 2^depth 加入答案。
  5. 扫描结束后返回累计分数。

以 (()(())) 为例

第一个最小单元位于 1 层外壳中，贡献 2；第二个最小单元位于 2 层外壳中，贡献 4。总分为 2 + 4 = 6。

正确性说明

任意平衡括号串都可由“并列”和“包裹”组合而成。把结构继续拆分，最终只剩若干个 ()。并列规则意味着各最小单元贡献相加；每多一层包裹，其贡献按规则翻倍。因此，一个位于 d 层外壳中的 () 恰好贡献 2^d。算法识别全部且仅有这些相邻括号，并累加正确权重，所以结果正确。

边界情况

  • 最短输入 ()：退出后深度为 0，贡献 1。
  • 完全并列 ()()…：每个单元都贡献 1。
  • 完全嵌套：只有最内层 () 产生一次较大贡献。
  • 题目保证输入平衡，提交代码无需额外处理非法字符串。

复杂度

时间复杂度 O(n)；只使用常数个变量，额外空间复杂度 O(1)。

四种语言实现

class Solution {
    public int scoreOfParentheses(String s) {
        int score = 0;
        int depth = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                depth++;
            } else {
                depth--;
                if (s.charAt(i - 1) == '(') {
                    score += 1 << depth;
                }
            }
        }
        return score;
    }
}

public:
    int scoreOfParentheses(string s) {
        int score = 0;
        int depth = 0;

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            if (s[i] == '(') {
                ++depth;
            } else {
                --depth;
                if (s[i - 1] == '(') {
                    score += 1 << depth;
                }
            }
        }
        return score;
    }

替代方案：栈归约

栈顶保存当前层已经累计的分数。遇到 ( 压入 0；遇到 ) 弹出内部值 v，向外层加上 max(2 × v, 1)。思路更贴近递归定义，但使用 O(n) 空间。

常见错误

  • 在处理右括号时忘记先减少深度。
  • 每遇到 ) 都加分，重复计算复合结构。
  • 用 2 × depth 代替指数权重 2^depth。
  • 把并列结构误认为还会整体翻倍。

面试追问

  • 如何用栈直接模拟三条定义？
  • 如果输入不保证平衡，怎样报告首个错误位置？
  • 若长度很大导致结果溢出，如何改用大整数或取模？
