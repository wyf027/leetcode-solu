LCR 013 · MEDIUM · 二维前缀和

二维区域和检索
- 矩阵不可变

矩阵不会修改，却会反复查询子矩形的和。一次预处理，把每次查询从逐格累加变成四个角的加减法。

核心公式

sum(r1,c1,r2,c2)
= P[r2+1][c2+1] - P[r1][c2+1]
- P[r2+1][c1] + P[r1][c1]

题意与观察

实现 NumMatrix：构造函数接收二维矩阵，随后多次调用 sumRegion(row1,col1,row2,col2)，返回闭区间矩形内的元素和。

每次现算需要扫描区域面积；当查询次数很多且矩阵不变时，预先记录从左上角到每个位置的累计和更划算。

四角容斥

大矩形减去上方、左方多余区域；左上角被减了两次，最后加回一次。给前缀表额外留一行一列 0，可消除边界判断。

交互演示

点选四角，查看区域和

高亮单元格构成当前查询矩形。点击“切换查询”观察不同区域。

查询拆解

P[i][j] 表示原矩阵前 i 行、前 j 列的和，坐标从 1 开始，因而查询右下角需要使用 r2+1、c2+1。

01 / 预处理

构造 (m+1)×(n+1) 表

首行和首列都是 0，避免 r=0 或 c=0 时单独处理。

02 / 状态转移

累积当前格

P[i][j] = matrix[i-1][j-1] + 上 + 左 - 左上。

03 / 常数查询

四个前缀值容斥

查询不再遍历区域，直接读四个表项，时间 O(1)。

复杂度

构造：O(mn)

遍历矩阵填完二维前缀表，额外空间也是 O(mn)。

查询：O(1)

无论矩形大小如何，都只做四次数组读取和三次加减。

四语言提交版

以 1-based 前缀表统一边界。

  1. 新建多一圈的前缀表，初始化为 0。
  2. 对每个原矩阵元素应用“上 + 左 - 左上 + 当前”的转移。
  3. 查询时用右下大前缀减上、减左、加左上。
