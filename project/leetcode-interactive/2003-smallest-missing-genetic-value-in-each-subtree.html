01 / UNDERSTAND

题目说明

给定一棵以节点 0 为根、共 n 个节点的合法树。节点编号是 0 … n−1。数组 parents[i] 给出节点 i 的父节点，根节点满足 parents[0] = -1。数组 nums[i] 给出节点 i 的基因值，所有基因值互不相同。

返回长度为 n 的数组 ans：ans[i] 是节点 i 及其所有后代的基因值中，没有出现的最小正整数。子树必须包含节点自身。

参数：parents: integer[]，nums: integer[] → integer[]。这里求的是最小缺失正整数（MEX 从 1 开始），并非最小缺失节点编号。

官方示例 1

parents = [-1,0,0,2]
nums = [1,2,3,4]
输出 = [5,1,1,1]

节点 0 拥有值 {1,2,3,4}，答案为 5。节点 1、2、3 的子树分别有 {2}、{3,4}、{4}，答案均为 1。

官方示例 2

parents = [-1,0,1,0,3,3]
nums = [5,4,6,2,1,3]
输出 = [7,1,1,4,2,1]

节点 0 的子树含 1…6，答案为 7；节点 3 含 {2,1,3}，答案为 4；节点 4 含 {1}，答案为 2。其余子树缺少 1。

官方示例 3

parents = [-1,2,3,0,2,4,1]
nums = [2,3,4,5,6,7,8]
输出 = [1,1,1,1,1,1,1]

整棵树都没有基因值 1，因此每个子树缺失的最小正整数都是 1。

完整约束

  • n == parents.length == nums.length，2 ≤ n ≤ 10⁵。
  • parents[0] == -1；当 i ≠ 0 时，0 ≤ parents[i] ≤ n−1。
  • parents 表示一棵合法的树；父节点编号不一定小于孩子编号。
  • 1 ≤ nums[i] ≤ 10⁵，且所有 nums[i] 互不相同。

04 / EDITORIAL

准备好看完整题解了吗？

包含推导、证明和四种语言的完整实现。

从基因值 1 向根扩张

核心洞察

一个集合不包含 1，最小缺失正整数就必定是 1。由于基因值互不相同，值为 1 的节点最多只有一个，记作 start。只有 start 本身及其祖先的子树包含 1；其他节点的答案直接设为 1。

从 start 向根走，子树逐层包含前一层子树。用 visited 跳过已经完整收集过的子树，用 seen 保留已出现的基因值，用单调递增的 mex 指向最小未出现的正整数。

完整过程

  1. 初始化所有答案为 1。查找 nums[i] == 1 的节点；若没有，直接返回。
  2. 由 parents 建立孩子邻接表。建立 visited、seen，令 mex = 1。
  3. 当前节点 u 从 start 开始。用显式栈 DFS 扫描 u 的子树；遇到已访问节点就跳过它及其全部孩子。
  4. 首次访问节点 v 时标记 visited[v]，记录 nums[v]。只需记录 ≤ n 的基因值，因为 n 个节点的最小缺失正整数最多是 n+1。
  5. 当 seen[mex] 为真时向右移动 mex。令 ans[u] = mex。
  6. 令 u = parents[u]，重复直到 u = -1。seen 和 mex 在层与层之间保留。

示例 2 的关键快照

当前根  新增节点       累积基因值        mex / 写入
4       [4]            {1}              2 → ans[4]
3       [3,5]          {1,2,3}          4 → ans[3]
0       [0,1,2]        {1,2,3,4,5,6}    7 → ans[0]
其他节点默认 1 → [7,1,1,4,2,1]

外层从 4 上升到 3 时，子树 4 已扫描完成，可以整棵跳过；从 3 上升到 0 同理。DFS 内部顺序不影响结果。

正确性证明

非祖先节点：如果节点 u 不是 start 的祖先（且不是 start），u 的子树不包含唯一的基因值 1，所以 ans[u] = 1 正确。不存在 start 时，这个结论适用于整棵树。

集合不变式：每次为当前祖先 u 计算答案前，seen 恰好记录 u 子树内所有不超过 n 的基因值。起点的 DFS 收集完整子树；上升一层时，旧子树包含于新子树中，跳过的节点对应已经完整遍历的子树，其值仍在 seen 中；DFS 会补齐其余所有节点，因此不变式保持。

游标不变式：每次循环开始时所有小于 mex 的正整数都已出现。集合只增不减，因此旧 mex 左侧不会产生新缺口；不断跳过已出现的值后，mex 本身未出现且前面的值全部出现，恰是当前子树的最小缺失正整数。

算法覆盖所有可能答案大于 1 的节点，其他节点保留正确的 1，故返回数组正确。

复杂度

时间 O(n)，额外空间 O(n)。建图 O(n)。每个节点首次访问时才会展开孩子，孩子边总共 O(n)，每个祖先最多再触发一次外层入口。mex 一共最多前进 n 次。邻接表、visited、seen 和显式栈均为 O(n)。

seen 长度为 n+2，保留 n+1 作为未出现的哨兵。即使输入覆盖 1…100000，答案也可以是 100001。

边界与常见错误

  • 没有 1：直接返回全 1，不做多余扫描。
  • 1 在根：只需一次完整 DFS；在叶子：逐层扩张。
  • 不能假定 parents[i] < i。
  • 不要每层清空 seen，或从 1 重新扫描 mex。
  • 只跳过 visited 节点的记录却继续遍历孩子，会重复扫子树并退化。
  • 深度可达 10⁵，递归 DFS 可能栈溢出；四份代码均用显式栈。
  • 不要用 nums[v] 作为节点编号。

替代方案

逐节点 DFS：每个节点重新收集子树并计算 MEX，思路直观，但链形树会达到 O(n²)，不适合本题上限。

小并大 / DSU on tree：合并孩子集合并维护 MEX，可处理更一般的子树集合问题，但需要额外的合并与查询维护。只写“用集合合并”并不能自动得到高效 MEX；若每次从 1 重扫仍可能退化。本题利用唯一的 1，把需要特殊处理的节点缩成一条祖先链，更简单。

面试追问

  • 如果 nums 可以重复？多个值 1 的节点可能分布在不同分支，单条祖先链不再覆盖所有候选节点，需要通用的子树集合维护方案。
  • 如果出现在线修改？seen 只增不减的性质失效，本解法不能直接支持删除和改值，需要重新设计动态维护结构。
  • 为什么可忽略大于 n 的值？n 个节点无法同时覆盖 1…n+1，答案一定 ≤ n+1，大值无法影响之前的缺口。
  • 为什么嵌套循环不是 O(n²)？visited 限制全部 DFS 展开次数，mex 单调限制全部游标推进次数，应按全局累计工作量计数。

Java

import java.util.*;

class Solution {
    public int[] smallestMissingValueSubtree(int[] parents, int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        Arrays.fill(ans, 1);
        int start = -1;
        for (int i = 0; i < n; i++) {
            if (nums[i] == 1) start = i;
        }
        if (start == -1) return ans;

        List<List<Integer>> children = new ArrayList<>();
        for (int i = 0; i < n; i++) children.add(new ArrayList<>());
        for (int i = 1; i < n; i++) children.get(parents[i]).add(i);
        boolean[] visited = new boolean[n];
        boolean[] seen = new boolean[n + 2];
        Deque<Integer> stack = new ArrayDeque<>();
        int mex = 1;
        for (int u = start; u != -1; u = parents[u]) {
            stack.push(u);
            while (!stack.isEmpty()) {
                int v = stack.pop();
                if (visited[v]) continue;
                visited[v] = true;
                if (nums[v] <= n) seen[nums[v]] = true;
                for (int child : children.get(v)) stack.push(child);
            }
            while (seen[mex]) mex++;
            ans[u] = mex;
        }
        return ans;
    }
}

/**
 * @param {number[]} parents
 * @param {number[]} nums
 * @return {number[]}

var smallestMissingValueSubtree = function(parents, nums) {
    const n = nums.length;
    const ans = Array(n).fill(1);
    const start = nums.indexOf(1);
    if (start === -1) return ans;

    const children = Array.from({ length: n }, () => []);
    for (let i = 1; i < n; i++) children[parents[i]].push(i);
    const visited = new Uint8Array(n);
    const seen = new Uint8Array(n + 2);
    let mex = 1;
    for (let u = start; u !== -1; u = parents[u]) {
        const stack = [u];
        while (stack.length) {
            const v = stack.pop();
            if (visited[v]) continue;
            visited[v] = 1;
            if (nums[v] <= n) seen[nums[v]] = 1;
            for (const child of children[v]) stack.push(child);
        }
        while (seen[mex]) mex++;
        ans[u] = mex;
    }
    return ans;
};

Python 3

from typing import List

class Solution:
    def smallestMissingValueSubtree(
        self, parents: List[int], nums: List[int]
    ) -> List[int]:
        n = len(nums)
        ans = [1] * n
        start = next((i for i, value in enumerate(nums) if value == 1), -1)
        if start == -1:
            return ans

        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[parents[i]].append(i)
        visited = [False] * n
        seen = [False] * (n + 2)
        mex = 1
        u = start
        while u != -1:
            stack = [u]
            while stack:
                v = stack.pop()
                if visited[v]:
                    continue
                visited[v] = True
                if nums[v] <= n:
                    seen[nums[v]] = True
                stack.extend(children[v])
            while seen[mex]:
                mex += 1
            ans[u] = mex
            u = parents[u]
        return ans

C++

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> smallestMissingValueSubtree(vector<int>& parents,
                                             vector<int>& nums) {
        int n = nums.size();
        vector<int> ans(n, 1);
        int start = -1;
        for (int i = 0; i < n; ++i) {
            if (nums[i] == 1) start = i;
        }
        if (start == -1) return ans;

        vector<vector<int>> children(n);
        for (int i = 1; i < n; ++i) children[parents[i]].push_back(i);
        vector<bool> visited(n, false), seen(n + 2, false);
        int mex = 1;
        for (int u = start; u != -1; u = parents[u]) {
            vector<int> stack{u};
            while (!stack.empty()) {
                int v = stack.back();
                stack.pop_back();
                if (visited[v]) continue;
                visited[v] = true;
                if (nums[v] <= n) seen[nums[v]] = true;
                for (int child : children[v]) stack.push_back(child);
            }
            while (seen[mex]) ++mex;
            ans[u] = mex;
        }
        return ans;
    }
};
