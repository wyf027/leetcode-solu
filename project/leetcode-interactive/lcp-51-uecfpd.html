烹饪料理

八道菜以内，枚举菜单的每一种组合：食材够、饱腹达标，就用美味度更新答案。

题意

背包有编号 0..4 的五种食材。每道料理最多制作一次，食谱给出五种食材消耗，属性 [x,y] 分别表示美味度与饱腹感。在总饱腹感不少于 limit 的所有可行菜单中，返回最大美味度；不存在则返回 -1。

示例 1

materials = [3,2,4,1,2]

cookbooks = [[1,1,0,1,2],[2,1,4,0,0],[3,2,4,1,0]]

attribute = [[3,2],[2,4],[7,6]], limit = 5

仅制作料理 2，饱腹感为 6、美味度为 7，因此输出 7。

数据规模

1 ≤ n ≤ 8，五种食材；数值均不超过 20，1 ≤ limit ≤ 100。

关键限制

每种料理只能做一次，所以每道菜只有“选 / 不选”两个状态。

核心洞察

料理数最多 8，所有菜单只有 2⁸ = 256 个。枚举每个二进制掩码，累加被选料理的五维食材消耗、美味度和饱腹感。资源不超背包且饱腹达标时更新最大美味度。

完整过程

  1. 答案初始化为 -1。
  2. 枚举 mask ∈ [0, 2ⁿ)。
  3. 把每个选中料理的消耗、属性累加。
  4. 任一食材超量就舍弃；否则饱腹达标时更新答案。

复杂度与边界

时间 O(2ⁿ · n · 5)，额外空间 O(5)。若没有可行菜单，保留 -1。美味度可以为 0，因此不能用 0 表示“无解”。空菜单饱腹为 0，不会满足题目中至少为 1 的 limit。

替代方案 / 面试追问 / 常见错误

可用 DFS 做同样的选或不选搜索并按食材提前剪枝，但位掩码更短且不易出错。追问可讨论如何在料理数增大时改用背包 DP。常见错误是把同一道菜重复制作、只检查食材总量而漏掉五个维度，或把美味与饱腹属性下标写反。 

class Solution {
  public int perfectMenu(int[] materials, int[][] cookbooks, int[][] attribute, int limit) {
    int n = cookbooks.length, answer = -1;
    for (int mask = 0; mask < (1 << n); mask++) {
      int[] used = new int[5]; int taste = 0, full = 0; boolean ok = true;
      for (int i = 0; i < n && ok; i++) if ((mask & (1 << i)) != 0) {
        taste += attribute[i][0]; full += attribute[i][1];
        for (int j = 0; j < 5; j++) { used[j] += cookbooks[i][j]; if (used[j] > materials[j]) ok = false; }
      }
      if (ok && full >= limit) answer = Math.max(answer, taste);
    }
    return answer;
  }
}

class Solution:
    def perfectMenu(self, materials: List[int], cookbooks: List[List[int]], attribute: List[List[int]], limit: int) -> int:
        n, answer = len(cookbooks), -1
        for mask in range(1 << n):
            used, taste, full = [0] * 5, 0, 0
            for i in range(n):
                if mask >> i & 1:
                    taste += attribute[i][0]; full += attribute[i][1]
                    for j in range(5): used[j] += cookbooks[i][j]
            if all(used[j] <= materials[j] for j in range(5)) and full >= limit:
                answer = max(answer, taste)
        return answer
