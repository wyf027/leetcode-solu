1121. 将数组分成几个递增序列

Divide Array Into Increasing Sequences

题目

给定一个按非递减顺序排列的整数数组 nums 和正整数 k。判断能否把每个元素恰好使用一次，划分成一个或多个子序列，使每个子序列严格递增且长度不少于 k。子序列不要求连续。

示例 1

输入：nums = [1,2,2,3,3,4,4], k = 3
输出：true
解释：可分为 [1,2,3,4] 与 [2,3,4]。

示例 2

输入：nums = [5,6,6,7,8], k = 3
输出：false
解释：两个 6 要进入不同序列，但 5 个元素
不足以组成两条长度至少为 3 的序列。

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁵
  • 1 ≤ k ≤ nums.length
  • nums 按非递减顺序排列。

题解：最大频次决定最低序列数

核心洞察

同一条严格递增序列不能包含两个相等元素。若某个值最多出现 m 次，就至少需要 m 条序列；每条至少长 k，故必须有 m × k ≤ n。按升序把元素轮转放进这 m 条序列，可使它们严格递增且长度均衡，所以条件也充分。

完整过程

  1. 扫描有序数组，统计每段相等元素的长度。
  2. 维护最大段长 maxFreq。
  3. 返回 maxFreq ≤ n / k，用除法避免乘法溢出。

正确性

必要性：频次最高的值必须分散到至少 maxFreq 条序列，共需要至少 maxFreq × k 个元素。

充分性：建立这么多条序列，按值递增并轮转均衡分配；相同值进入不同序列，后加入的不同值更大。最短序列长 ⌊n/maxFreq⌋，给定条件保证其至少为 k。

边界

  • k=1 总可行。
  • 全相等时仅 k=1 可行。
  • 全互异时一条序列即可。
  • n 无需被序列数整除。

复杂度

时间 O(n)，额外空间 O(1)。

替代方案

未排序数组可用哈希表求最大频次，时间 O(n)、空间 O(u)；用最小堆实际构造序列需 O(n log m)，仅判断时没有必要。

面试追问

  • 未排序怎么办？哈希计数，结论不变。
  • 如何输出划分？建 maxFreq 个桶，按升序轮转分配。
  • 为什么只看最大频次？它就是严格递增约束下的最少序列数。

常见错误

  • 把子序列误当连续子数组。
  • 错误要求 n % k == 0。
  • 只看相邻是否不同而未统计最大频次。
  • 构造时不均衡，产生过短序列。

Java

class Solution {
    public boolean canDivideIntoSubsequences(int[] nums, int k) {
        int maxFreq = 1, run = 1;
        for (int i = 1; i < nums.length; i++) {
            run = nums[i] == nums[i - 1] ? run + 1 : 1;
            maxFreq = Math.max(maxFreq, run);
        }
        return maxFreq <= nums.length / k;
    }
}

JavaScript

var canDivideIntoSubsequences = function(nums, k) {
  let maxFreq = 1, run = 1;
  for (let i = 1; i < nums.length; i++) {
    run = nums[i] === nums[i - 1] ? run + 1 : 1;
    maxFreq = Math.max(maxFreq, run);
  }
  return maxFreq <= Math.floor(nums.length / k);
};

Python

class Solution:
    def canDivideIntoSubsequences(self, nums: List[int], k: int) -> bool:
        max_freq = run = 1
        for i in range(1, len(nums)):
            run = run + 1 if nums[i] == nums[i - 1] else 1
            max_freq = max(max_freq, run)
        return max_freq <= len(nums) // k

C++

class Solution {
public:
    bool canDivideIntoSubsequences(vector<int>& nums, int k) {
        int maxFreq = 1, run = 1;
        for (int i = 1; i < (int)nums.size(); ++i) {
            run = nums[i] == nums[i - 1] ? run + 1 : 1;
            maxFreq = max(maxFreq, run);
        }
        return maxFreq <= (int)nums.size() / k;
    }
};
