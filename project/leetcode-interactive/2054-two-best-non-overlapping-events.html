01 / 题目

最多参加两个活动

给定下标从 0 开始的二维整数数组 events，每个元素为 [startTimeᵢ, endTimeᵢ, valueᵢ]，分别表示第 i 个活动的开始时间、结束时间和价值。请选择至多两个时间不重叠的活动，返回能够获得的最大价值总和。

开始与结束时刻都包含在活动内。
若一个活动在 t 结束，下一个活动必须在 t + 1 或之后开始。[1,3] 与 [3,4] 重叠；[1,3] 与 [4,5] 不重叠。允许只选一个活动。

参数与返回值

maxTwoEvents(events: integer[][]) → integer

  • 2 ≤ events.length ≤ 10⁵
  • events[i].length = 3
  • 1 ≤ startTimeᵢ ≤ endTimeᵢ ≤ 10⁹
  • 1 ≤ valueᵢ ≤ 10⁶

04 / 独立题解

准备好再向下探索

展开后可查看分步交互、推导和四种语言的完整实现。

排序 → 后缀最优 → 严格右边界

核心洞察：固定第一个活动后，只需在所有开始时间严格大于它结束时间的活动中，找到价值最大的一个。按开始时间排序后，这些合法搭档恰好构成一个后缀。

完整过程

  1. 把活动按开始时间升序排列，记为 a。
  2. 从右向左预处理 suf[i] = max(a[i].value, suf[i+1])，设 suf[n] = 0。它表示后缀里单个活动的最大价值。
  3. 枚举活动 i，以 a[i].end 为阈值，二分找到第一个满足 a[j].start > a[i].end 的位置 j。不存在则 j = n。
  4. 当前候选为 a[i].value + suf[j]，更新全局最大值。这里 suf[n] = 0 自动覆盖只选一个活动的情形。

交互实验室 · 看见合法后缀的起点

金色：当前活动；绿色：当前最优搭档；紫色边框：二分探针。时间条展示闭区间，单时刻活动用短条表示。表格中的 j 与 suf[j] 是最终组合的依据。

排序位置原编号闭区间价值suf[i]状态

二分区间采用 [lo, hi)。当 start ≤ end 时排除左侧，令 lo = mid + 1；否则 hi = mid。lo = hi 时得到 j。

正确性证明

后缀不变量：空后缀的最大价值为 0。假设 suf[i+1] 已正确，则后缀 i 中的最大单项价值只可能来自活动 i 或后面的后缀，故取二者最大值得到正确的 suf[i]。由倒序归纳，所有后缀值正确。

合法性：排序使开始时间单调。二分返回第一个 start > end 的位置，因此 j 及之后的活动都与当前活动不重叠，j 之前的活动都不能作为它的后续活动。suf[j] 只选一个活动，组合总数最多为两个。

最优性：任意合法二活动方案都能按时间先后排序。枚举到其中较早的活动时，较晚活动必定位于其合法后缀，suf[j] 不小于这个较晚活动的价值；因此枚举候选覆盖或改进任意二活动方案。每个单活动方案也被“自身价值 + 非负后缀值”的候选覆盖。所有候选均合法，所以最大候选等于全局最优。

边界与复杂度

  • 端点相同必须拒绝：查找条件是 start > end，不能使用 ≥。
  • 完全重叠时 j 可等于 n，此时只取当前活动。开始时间重复不影响单调性。
  • 当 start = end 时，活动仍占据这个时刻；排序后二分不会选回自身，因为 start ≤ end。
  • 时间可到 10⁹，不能开按时间索引的巨大数组。最大答案为 2 × 10⁶，四份实现的数值类型都能容纳。
  • 排序 O(n log n)，后缀构造 O(n)，n 次二分 O(n log n)，总时间 O(n log n)，额外空间 O(n)。下面代码均先复制外层数据，保留输入顺序。

替代方案

按结束时间排序 + 前缀最大值：为每个活动查找 end < start 的最后一个位置，与前面单活动最优组合，复杂度同样为 O(n log n)。

开始时间扫描 + 最小堆：堆按结束时间排序，扫描时先弹出所有 end < start 的活动，维护已结束活动的最大价值，再与当前活动组合，时间 O(n log n)、空间 O(n)。

枚举所有活动对：思路直接，但时间 O(n²)，只能作为小规模参考，无法满足 10⁵ 的规模。

常见错误

  • 把“最多两个”写成“必须两个”，导致忽略高价值单活动。
  • 找到第一个合法搭档就直接取它的价值；更远的活动可能更有价值，必须查询整个后缀。
  • 用后缀价值之和代替最大单项价值，会偷偷选择超过两个活动。
  • 二分使用错误的相等分支，错误地组合接触端点的活动。
  • 忘记 suf[n] 哨兵，查无搭档时访问越界。
  • JavaScript 直接对数组调用无比较器的 sort，会得到字符串排序。

面试追问

最多 k 个活动？使用按时间排序的加权区间调度 DP，状态额外记录已选数量；预处理每个活动的下一合法位置后，DP 可做到 O(nk)，加排序与二分预处理 O(n log n)。

怎样返回原活动编号？排序前保留编号；后缀除价值外也保留取得最大价值的位置，更新答案时保存当前编号与搭档编号。若要求稳定平局规则，可统一按编号比较。

如果边界为半开区间？兼容条件将改为 start ≥ end，二分也要改成对应的 lower bound；须同时明确零长度活动和自选问题。

Java
import java.util.Arrays;

class Solution {
    public int maxTwoEvents(int[][] events) {
        int[][] a = events.clone();
        Arrays.sort(a, (x, y) -> Integer.compare(x[0], y[0]));
        int n = a.length;
        int[] suf = new int[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            suf[i] = Math.max(a[i][2], suf[i + 1]);
        }
        int answer = 0;
        for (int[] event : a) {
            int lo = 0, hi = n;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (a[mid][0] <= event[1]) lo = mid + 1;
                else hi = mid;
            }
            answer = Math.max(answer, event[2] + suf[lo]);
        }
        return answer;
    }
}

Python 3
from typing import List
from bisect import bisect_right

class Solution:
    def maxTwoEvents(self, events: List[List[int]]) -> int:
        a = sorted(events, key=lambda event: event[0])
        n = len(a)
        starts = [event[0] for event in a]
        suf = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suf[i] = max(a[i][2], suf[i + 1])
        answer = 0
        for start, end, value in a:
            j = bisect_right(starts, end)
            answer = max(answer, value + suf[j])
        return answer

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maxTwoEvents(vector<vector<int>>& events) {
        auto a = events;
        sort(a.begin(), a.end(), [](const auto& x, const auto& y) {
            return x[0] < y[0];
        });
        int n = static_cast<int>(a.size());
        vector<int> suf(n + 1, 0);
        for (int i = n - 1; i >= 0; --i) {
            suf[i] = max(a[i][2], suf[i + 1]);
        }
        int answer = 0;
        for (const auto& event : a) {
            int lo = 0, hi = n;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (a[mid][0] <= event[1]) lo = mid + 1;
                else hi = mid;
            }
            answer = max(answer, event[2] + suf[lo]);
        }
        return answer;
    }
};
