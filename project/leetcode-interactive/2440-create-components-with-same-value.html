创建价值相同的连通块

Create Components With Same Value

一棵树，多种切法。让每个留下来的连通块，拥有相同的价值。

树数组数学官方题目 ↗

01 / 题目

给定一棵有 n 个节点的无向树，节点编号为 0…n−1。数组 nums 长度为 n，nums[i] 是节点 i 的价值；数组 edges 包含 n−1 条边，每条 [a, b] 表示节点 a 与 b 相连。

你可以删除若干条边。删除后，每个连通块的价值是其中所有节点价值之和。要求所有连通块价值相同，返回最多能删除的边数。允许不删边。

参数：componentValue(nums, edges) → integer。节点不能拆分，也不能改变价值。

官方示例 1

nums = [6,2,2,2,6]
edges = [[0,1],[1,2],[1,3],[3,4]]
输出 = 2

删除 [0,1] 和 [3,4]，得到 {0}、{1,2,3}、{4}，价值都为 6。最多删除 2 条边。

官方示例 2

nums = [2]
edges = []
输出 = 0

只有一个节点，没有边可以删除。

约束

  • 1 ≤ n ≤ 2 × 10⁴；nums.length = n。
  • 1 ≤ nums[i] ≤ 50。
  • edges.length = n − 1；edges[i].length = 2。
  • 0 ≤ edges[i][0], edges[i][1] ≤ n − 1。
  • edges 保证表示一棵合法的树。

04 / 题解 · 把完成的子树归零

核心洞察

树删掉 k−1 条边后恰好得到 k 个连通块。设总价值为 S，每块目标价值 T 必须满足 S = kT，且 T ≥ max(nums)。因此从大到小枚举 k，只检查能整除 S 的候选，找到第一个可行解就返回 k−1。

固定 T 后，按子节点先于父节点的顺序汇总。已凑齐 T 的部分独立成块，只向父节点传 0；不足 T 的部分必须继续向父节点合并；超过 T 则本候选不可行。所有节点价值都为正，是这个贪心成立的关键。

交互实验 · 沿树向上交接剩余价值

完整过程

  1. 建立无向邻接表，以 0 为根，记录 parent 和父节点在前的 order。
  2. 求 S 和最大节点值 M；枚举 k = ⌊S/M⌋, …, 1。由于 S ≤ nM，该上界不会超过 n。
  3. 若 S 不能被 k 整除，跳过；否则令 T = S/k，重新复制 nums 为 rem。
  4. 逆序处理 order：若 rem[u] > T 则失败；若等于 T 则置 0；把 rem[u] 加到父节点。
  5. 遍历结束后，只有 rem[0] = 0 才算成功。返回 k−1；k=1 总能成功。

示例中 T=6：节点 4 凑齐，切断 3—4；节点 3 留下 2，节点 2 留下 2；节点 1 合计 2+2+2=6，切断 0—1；根节点 0 自成价值 6 的块。根的归零不会增加切边数。

为什么正确

后序不变量：处理节点 u 时，其每个孩子子树已经移除了若干个价值 T 的完整块；剩余部分若非空，仍与孩子根连通，并通过唯一的父边连接 u。rem[u] 正是 u 与这些未完成部分的价值和。

如果 rem[u] < T，切断父边会留下不足 T 的块，所以必须上交。如果等于 T，正数价值保证它不能再与任何非空上方部分合并成 T，故可立即封块。如果超过 T，孩子不足 T 的部分都无法单独切出，且继续向上只会增加价值，因此无解。由叶到根归纳，这一判定既不会遗漏合法切法，也只会产生合法块。

根的剩余值为 0 表示全树都被划入价值 T 的块。总和守恒使块数必为 S/T=k。按 k 递减检查，第一个可行 k 最大，因而 k−1 条切边也是最优。

边界与复杂度

  • n=1 返回 0；所有值相等时可删掉全部 n−1 条边；单块方案永远存在。
  • 每次候选必须重置 rem；根没有父边，不能把根封块当成切边。
  • 用迭代遍历避免长链上递归深度溢出。S ≤ 10⁶，四语言这里使用的数值类型均足够。
  • 令 d(S) 为 S 的正约数个数。扫描候选上界至多 n，每个整除候选耗时 O(n)，总时间 O(n + n·d(S))，额外空间 O(n)。不可简单写成总时间 O(n)。

替代方案

也可以从小到大枚举目标价值 T 的约数，然后做同样的后序判定；约数可在 O(√S) 时间内收集。递归 DFS 更短，但深链需要处理栈限制。叶子队列剥离也能汇总剩余价值，却需要每个候选重置度数。直接枚举删边集合需要 O(2ⁿ⁻¹) 个方案，不适用于本题规模。

常见错误

  • 只看总和能否整除，忽略树的连接限制。例如星形树 nums=[1,1,1,1] 虽能算出 T=2，却无法分成两个价值 2 的连通块。
  • 拿原始子树总和作判断，忘了减去已经完成并切出的块。
  • 返回 k 而不是 k−1，或把根封块也计作一条切边。
  • 对 k 二分：可行性没有需要的单调性，不能用普通二分代替约数枚举。

面试追问

  • 如何返回具体删边？成功候选中，每个非根节点 rem[u] 恰好等于 T 时记录 [u,parent[u]]，最终仅保留该候选的结果。
  • 允许负数会怎样？超过 T 后仍可能被负数抵消，当前剪枝和强制封块论证失效，需要重新设计状态。
  • 节点价值很大呢？使用足够宽的整数类型；仍可枚举至多 n 个块数，不必扫描到 S。

JavaScript

/**
 * @param {number[]} nums
 * @param {number[][]} edges
 * @return {number}
 */
var componentValue = function(nums, edges) {
    const n = nums.length;
    const graph = Array.from({length: n}, () => []);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
    }
    const parent = Array(n).fill(-1), order = [0];
    for (let i = 0; i < order.length; i++) {
        const u = order[i];
        for (const v of graph[u]) {
            if (v === parent[u]) continue;
            parent[v] = u;
            order.push(v);
        }
    }
    const total = nums.reduce((a, b) => a + b, 0);
    const largest = Math.max(...nums);
    for (let k = Math.floor(total / largest); k >= 1; k--) {
        if (total % k !== 0) continue;
        const target = total / k, rem = nums.slice();
        let ok = true;
        for (let i = n - 1; i >= 0; i--) {
            const u = order[i];
            if (rem[u] > target) { ok = false; break; }
            if (rem[u] === target) rem[u] = 0;
            if (parent[u] !== -1) rem[parent[u]] += rem[u];
        }
        if (ok && rem[0] === 0) return k - 1;
    }
    return 0;
};

Java

import java.util.*;

class Solution {
    public int componentValue(int[] nums, int[][] edges) {
        int n = nums.length;
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        int[] parent = new int[n], order = new int[n];
        Arrays.fill(parent, -1);
        int size = 1;
        for (int i = 0; i < size; i++) {
            int u = order[i];
            for (int v : graph.get(u)) {
                if (v == parent[u]) continue;
                parent[v] = u;
                order[size++] = v;
            }
        }
        int total = 0, largest = 0;
        for (int x : nums) {
            total += x;
            largest = Math.max(largest, x);
        }
        for (int k = total / largest; k >= 1; k--) {
            if (total % k != 0) continue;
            int target = total / k;
            int[] rem = nums.clone();
            boolean ok = true;
            for (int i = n - 1; i >= 0; i--) {
                int u = order[i];
                if (rem[u] > target) { ok = false; break; }
                if (rem[u] == target) rem[u] = 0;
                if (parent[u] != -1) rem[parent[u]] += rem[u];
            }
            if (ok && rem[0] == 0) return k - 1;
        }
        return 0;
    }
}

Python

from typing import List

class Solution:
    def componentValue(self, nums: List[int], edges: List[List[int]]) -> int:
        n = len(nums)
        graph = [[] for _ in range(n)]
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)
        parent = [-1] * n
        order = [0]
        # Python 的列表迭代会访问后续追加的节点。
        for u in order:
            for v in graph[u]:
                if v == parent[u]:
                    continue
                parent[v] = u
                order.append(v)
        total = sum(nums)
        for k in range(total // max(nums), 0, -1):
            if total % k:
                continue
            target = total // k
            rem = nums.copy()
            ok = True
            for u in reversed(order):
                if rem[u] > target:
                    ok = False
                    break
                if rem[u] == target:
                    rem[u] = 0
                if parent[u] != -1:
                    rem[parent[u]] += rem[u]
            if ok and rem[0] == 0:
                return k - 1
        return 0

#include <algorithm>

class Solution {
public:
    int componentValue(vector<int>& nums, vector<vector<int>>& edges) {
        int n = nums.size();
        vector<vector<int>> graph(n);
        for (const auto& e : edges) {
            graph[e[0]].push_back(e[1]);
            graph[e[1]].push_back(e[0]);
        }
        vector<int> parent(n, -1), order{0};
        for (int i = 0; i < (int)order.size(); ++i) {
            int u = order[i];
            for (int v : graph[u]) {
                if (v == parent[u]) continue;
                parent[v] = u;
                order.push_back(v);
            }
        }
        int total = accumulate(nums.begin(), nums.end(), 0);
        int largest = *max_element(nums.begin(), nums.end());
        for (int k = total / largest; k >= 1; --k) {
            if (total % k != 0) continue;

            vector<int> rem = nums;

            for (int i = n - 1; i >= 0; --i) {

                if (parent[u] != -1) rem[parent[u]] += rem[u];
