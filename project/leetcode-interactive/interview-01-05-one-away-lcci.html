一次偏移，还来得及对齐

两个指针从左向右同步走。首个不同字符可以消耗唯一一次编辑：等长时替换，较长串向前跳一格时删除或插入；第二次不同立刻出局。

面试题 01.05 中等 字符串 · 双指针 · O(1)

题意：至多一次字符串编辑

可做三种操作：插入一个英文字符、删除一个英文字符、替换一个英文字符。判断 first 与 second 是否只需一次或零次编辑即可互相转换。

输入first = "pale"
second = "ple"
输出True
解释删除 "pale" 中的 a 即得到 "ple"。

官方示例 2

输入first = "pales"
second = "pal"
输出False
解释长度差为 2，至少需要两次删除，不能在一次编辑内完成。

约束与输入表示

  • 题面限定编辑单位为一个英文字符，比较时字符大小写不同即视为不同。
  • 官方题面未额外列出数值长度上限；算法只线性扫描较短字符串及最多一个尾字符。
  • 本页输入保留双引号：空格显示为 ␠，它仍是一个真实字符，并不会被 trim。

题解（默认隐藏）

先自己用对齐台推演；展开后查看统一双指针解法和四种可提交语言实现。

核心洞察

长度差决定指针的走法：相等时遇到差异只能替换，较长串遇到差异只能让较长串指针单独前进，相当于删除该字符（或向短串插入）。只允许一次不同步。

完整过程

  1. 长度差超过 1，返回 false。
  2. i、j 指向两个串当前字符，used 表示是否已编辑。
  3. 相同则二者一起前进；首次不同按长度关系前进一个或两个指针。
  4. 再遇不同立刻返回 false；扫描结束则返回 true。

边界

  • 相同字符串是零次编辑，返回 true。
  • "" 与 "a" 相差一次，返回 true。
  • 首个差异发生在末尾，例如 "abc" / "ab"，循环结束后仍应返回 true。
  • 空格不是空串的一部分："a␠b" 和 "ab" 相差一次删除。

复杂度

时间 O(min(m, n))，加上常数次长度检查仍是 O(m + n) 上界；额外空间 O(1)。不需要动态规划编辑距离表。

替代方案

通用编辑距离 DP 能求最少编辑次数，但会使用 O(mn) 时间和空间；本题阈值固定为 1，双指针在第一次不匹配后只需观察一次偏移，信息已经足够。

面试追问

  • 若允许至多 k 次编辑？可用带阈值剪枝的 DP 或 banded edit distance。
  • 若需输出具体编辑？第一次不匹配的长度关系与下标就是操作位置。
  • 若按 Unicode 用户可见字符编辑？先按 grapheme cluster 分割，不能直接按 UTF-16 code unit。

常见错误

  • 只统计相同下标的不同字符：这会错过插入/删除造成的整体偏移。
  • 长度不同却让两个指针都前进：等价于错误地做了替换。
  • 第一次不匹配后没有标记已编辑，导致接受两次替换。
  • 对输入调用 trim()：会把有意义的开头、结尾空格误删。

可提交代码

class Solution {
    public boolean oneEditAway(String first, String second) {
        if (Math.abs(first.length() - second.length()) > 1) return false;
        int i = 0, j = 0;
        boolean used = false;
        while (i < first.length() && j < second.length()) {
            if (first.charAt(i) == second.charAt(j)) { i++; j++; continue; }
            if (used) return false;
            used = true;
            if (first.length() == second.length()) { i++; j++; }
            else if (first.length() > second.length()) i++;
            else j++;
        }
        return true;
    }
}
