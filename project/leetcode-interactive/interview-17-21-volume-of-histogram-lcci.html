Problem brief

题意

给定一个柱宽均为 1 的直方图，高度由非负整数数组 height 表示。持续从上方倒水，求柱子之间最终能够留住的水量。

官方示例

height = [0,1,0,2,1,0,1,3,2,1,2,1]

输出 6，即蓝色凹槽合计容纳 6 个单位的水。

说明：官方题页没有另外列出数组长度与单柱高度的数值范围；本页实现也安全处理空数组。

Solution revealed

题解

Core insight

核心洞察：短板一侧可以立刻结算

位置 i 的水深是 min(左侧最高, 右侧最高) - height[i]。双指针从两端向内时，较矮端一定能在另一端找到不低于它的边界，因此这一端的水量已经确定，无须知道更远处的精确最高值。

Invariant

循环不变量

leftMax 与 rightMax 分别是已经扫过区域的最高柱。每次只移动当前柱高较小的一侧；被移走的位置水量从此不会再改变，累计答案始终等于所有已结算位置的水量之和。

Full process

完整过程

  1. 令 left = 0、right = n - 1，两侧最高值和答案都从 0 开始。
  2. 若 height[left] < height[right]，右侧当前柱足以充当左侧边界；更新 leftMax，累加 leftMax - height[left]，然后左指针右移。
  3. 否则对称地更新 rightMax，累加 rightMax - height[right]，然后右指针左移。相等时处理右侧不影响正确性。
  4. 当两指针相遇时，所有可能蓄水的位置均已结算。样例各步新增水量为 0,0,0,1,0,1,0,0,1,2,1，总和为 6。

Edges

边界

  • 空数组、单柱或双柱：无法形成凹槽，返回 0。
  • 单调递增、单调递减：一侧没有封闭边界，返回 0。
  • 相同高度与平台：差值为 0，正常移动指针即可。
  • 高度为 0：可作为槽底，不需要特殊分支。
  • 官方题页未给数值上限；极大数据场景可将累计量改为 64 位整数。

Complexity

复杂度

TIME

O(n)

每个位置至多被处理一次。

EXTRA SPACE

O(1)

只保存指针、两侧最高值与答案。

Trade-offs

替代方案取舍

  • 前缀/后缀最大值：最直观、易证明，同为 O(n) 时间，但需要 O(n) 空间。
  • 单调栈：按横向面积结算凹槽，适合追问“下一个更高元素”，实现更易写错宽度。
  • 逐列暴力：每列扫描左右最高值，O(n²)，只适合作为对拍基准。

Interview follow-ups

面试追问

为什么比较当前柱高就能决定处理哪边？
较矮端已经看到另一端这个确定边界；更内侧即使更高，只会抬高另一侧，不会降低当前侧可用的边界。
能否改为比较 leftMax 与 rightMax？
可以。先更新两侧最大值，再结算较小最大值的一侧，是同一不变量的另一种写法。
如果要求每个位置的水深呢？
增加长度为 n 的结果数组，在结算某侧时记录差值；总时间仍为 O(n)，空间变为 O(n)。

Failure modes

常见错误

  • 用较高一侧的最大值结算，破坏“短板已确定”的前提。
  • 先移动指针再计算，导致跳过当前位置或重复结算。
  • 把盛最多水的容器公式 宽 × 短板 直接套用；本题要累计每个槽位。
  • 单调栈方案忘记宽度是 right - left - 1。
  • 语言环境中累计值可能溢出时仍使用过小整数类型。

class Solution {
    public int trap(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int leftMax = 0;
        int rightMax = 0;
        int water = 0;

        while (left < right) {
            if (height[left] < height[right]) {
                leftMax = Math.max(leftMax, height[left]);
                water += leftMax - height[left];
                left++;
            } else {
                rightMax = Math.max(rightMax, height[right]);
                water += rightMax - height[right];
                right--;
            }
        }

        return water;
    }
}
