子串的最大出现次数

Maximum Number of Occurrences of a Substring

LeetCode 1297字符串滑动窗口
Problem

题目描述

给定字符串 s，请返回满足下列规则的任意子串中，最高的出现次数。出现位置可以重叠。

  • 01子串包含的不同字母数不超过 maxLetters。
  • 02子串长度在 minSize 与 maxSize 之间（含两端）。

示例 1

输入：s = "aababcaab", maxLetters = 2, minSize = 3, maxSize = 4
输出：2

子串 "aab" 出现 2 次，包含 2 种字母且长度为 3。

示例 2

输入：s = "aaaa", maxLetters = 1, minSize = 3, maxSize = 3
输出：2

"aaa" 出现 2 次；两次出现允许重叠。

示例 3

输入：s = "aabcabcab", maxLetters = 2, minSize = 2, maxSize = 3
输出：3

示例 4

输入：s = "abcde", maxLetters = 2, minSize = 3, maxSize = 3
输出：0

约束

  • 1 ≤ s.length ≤ 10⁵
  • 1 ≤ maxLetters ≤ 26
  • 1 ≤ minSize ≤ maxSize ≤ min(26, s.length)
  • s 仅由小写英文字母组成。

Core Insight

核心洞察：只统计最短允许长度

关键结论：答案一定可以由长度恰好为 minSize 的子串取得，因此 maxSize 无需参与枚举。

若某个长度大于 minSize 的合法子串出现了 k 次，那么取它每次出现的同一段长度为 minSize 的前缀，该前缀也至少出现 k 次；而且前缀的不同字母数不会增加，所以仍合法。

固定窗口

窗口长度固定为 minSize，从左到右扫描所有起点。

维护种类数

用 26 位频次数组维护窗口字符计数，并同步更新不同字母数。

哈希计数

仅当不同字母数不超过 maxLetters 时，累计窗口字符串的出现次数。

完整过程

  1. 初始化：建立字符频次数组、不同字母计数 distinct、子串频次哈希表和答案 answer。
  2. 窗口右移：加入右端字符；若该字符频次由 0 变为 1，则 distinct + 1。
  3. 固定长度：当窗口超过 minSize，移除左端字符；若其频次降为 0，则 distinct - 1。
  4. 筛选与计数：窗口长度等于 minSize 且 distinct ≤ maxLetters 时，将窗口文本在哈希表中的次数加一，并更新答案。
  5. 扫描结束：返回最高计数；如果没有合法窗口则保持为 0。

正确性证明

引理 1：任意合法的较长子串，其长度为 minSize 的前缀也合法，并且出现次数不少于该较长子串。

引理 2：算法恰好访问 s 中每个长度为 minSize 的子串一次。窗口频次数组准确描述当前窗口，所以合法性判断无误；哈希表因而准确记录所有合法最短子串的出现次数。

结论：由引理 1，全局最优值必能在最短长度中达到；由引理 2，算法会准确统计并取出这个值，故返回结果正确。

复杂度

设 n = s.length、m = minSize。

  • 窗口维护是 O(n)；常规语言中生成长度为 m 的子串需 O(m)，总时间为 O(nm)。因为题目保证 m ≤ 26，实际等价于线性扫描。
  • 哈希表最多保存 O(n) 个不同窗口；计入字符串副本时空间为 O(nm)，频次数组为 O(26)。

边界情况

  • minSize = 1：统计满足条件的单字符频次。
  • 所有窗口的不同字母数均超限：答案为 0。
  • 窗口可重叠，例如 "aaaa" 中 "aaa" 出现两次。
  • minSize = maxSize：结论和扫描方式不变。
  • 同一最高频次可能由多个不同子串取得，只需返回次数。

替代方案

枚举全部长度：遍历 [minSize, maxSize] 的每种长度也能做，因为 maxSize ≤ 26，但重复工作更多，且没有利用最短前缀结论。

滚动哈希：可避免复制窗口字符串，把键换成哈希值，使扫描更接近严格 O(n)；但要处理碰撞，面试中通常不如直接字符串键清晰。

四语言完整代码

Java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maxFreq(String s, int maxLetters, int minSize, int maxSize) {
        int[] frequency = new int[26];
        int distinct = 0;
        int answer = 0;
        Map<String, Integer> occurrences = new HashMap<>();

        for (int right = 0; right < s.length(); right++) {
            int added = s.charAt(right) - 'a';
            if (frequency[added]++ == 0) distinct++;

            if (right >= minSize) {
                int removed = s.charAt(right - minSize) - 'a';
                if (--frequency[removed] == 0) distinct--;
            }

            if (right >= minSize - 1 && distinct <= maxLetters) {
                String window = s.substring(right - minSize + 1, right + 1);
                int count = occurrences.merge(window, 1, Integer::sum);
                answer = Math.max(answer, count);
            }
        }
        return answer;
    }
}

/**
 * @param {string} s
 * @param {number} maxLetters

var maxFreq = function(s, maxLetters, minSize, maxSize) {
    const frequency = new Array(26).fill(0);
    const occurrences = new Map();
    let distinct = 0;
    let answer = 0;

    for (let right = 0; right < s.length; right++) {
        const added = s.charCodeAt(right) - 97;
        if (frequency[added]++ === 0) distinct++;

        if (right >= minSize) {
            const removed = s.charCodeAt(right - minSize) - 97;
            if (--frequency[removed] === 0) distinct--;
        }

        if (right >= minSize - 1 && distinct <= maxLetters) {
            const window = s.slice(right - minSize + 1, right + 1);
            const count = (occurrences.get(window) || 0) + 1;
            occurrences.set(window, count);
            answer = Math.max(answer, count);
        }
    }
    return answer;
};

from collections import defaultdict


class Solution:
    def maxFreq(
        self,
        s: str,
        maxLetters: int,
        minSize: int,
        maxSize: int,
    ) -> int:
        frequency = [0] * 26
        occurrences = defaultdict(int)
        distinct = 0
        answer = 0

        for right, char in enumerate(s):
            added = ord(char) - ord("a")
            if frequency[added] == 0:
                distinct += 1
            frequency[added] += 1

            if right >= minSize:
                removed = ord(s[right - minSize]) - ord("a")
                frequency[removed] -= 1
                if frequency[removed] == 0:
                    distinct -= 1

            if right >= minSize - 1 and distinct <= maxLetters:
                window = s[right - minSize + 1:right + 1]
                occurrences[window] += 1
                answer = max(answer, occurrences[window])

        return answer
C++
#include <algorithm>
#include <array>
#include <string>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int maxFreq(string s, int maxLetters, int minSize, int maxSize) {
        array<int, 26> frequency{};
        unordered_map<string, int> occurrences;
        int distinct = 0;
        int answer = 0;

        for (int right = 0; right < static_cast<int>(s.size()); ++right) {
            int added = s[right] - 'a';
            if (frequency[added]++ == 0) ++distinct;

            if (right >= minSize) {
                int removed = s[right - minSize] - 'a';
                if (--frequency[removed] == 0) --distinct;
            }

            if (right >= minSize - 1 && distinct <= maxLetters) {
                string window = s.substr(right - minSize + 1, minSize);
                answer = max(answer, ++occurrences[window]);
            }
        }
        return answer;
    }
};

面试追问

为什么参数 maxSize 没有在代码中使用？

最短前缀保留合法性且出现次数不会更少，所以最优值必能由长度 minSize 的窗口取得。保留参数是为了符合官方函数签名。

如何做到严格的 O(n) 扫描？

可用滚动哈希生成固定窗口键，或在支持零拷贝字符串视图的语言中使用视图；需要妥善处理哈希碰撞和生命周期。

如果字符集不再只有 26 个小写字母？

将定长数组换成哈希频次表，字符计数从 0/1 转换时维护 distinct 即可。

常见错误

  • 枚举所有长度，却遗漏“只看 minSize”的单调性证明。
  • 把重叠出现误判为一次，跳跃移动窗口。
  • 移除字符后忘记在频次变为 0 时减少不同字母数。
  • 先截取大量无效子串再判断合法性，增加不必要的分配。
  • 误把“最多 maxLetters 种”写成“恰好”。
