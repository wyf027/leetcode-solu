01 / 题目与规则

从剩余队伍的两端选人

输入从 0 开始的整数数组 costs，其中 costs[i] 是第 i 位工人的雇佣代价；另有整数 k 和 candidates。恰好进行 k 轮，每轮雇佣一人，返回总代价。

  1. 候选集合为当前剩余队伍的前 candidates 人与后 candidates 人的并集。
  2. 选其中代价最小者；代价相同，选当前下标更小者。
  3. 选中后从队伍移除，同一人只能雇佣一次；候选区重叠时同一人只算一次。
  4. 剩余人数小于 candidates 时，所有剩余工人都可选。

可视化固定显示原始编号 #i，便于追踪。删除不会改变剩余工人的相对顺序，因此用原始编号处理平局与当前下标等价。

官方约束

  • 1 ≤ costs.length ≤ 10⁵
  • 1 ≤ costs[i] ≤ 10⁵
  • 1 ≤ k, candidates ≤ costs.length

官方示例 1

输入：costs = [17,12,10,2,7,2,11,20,8],
      k = 3, candidates = 4
输出：11

依次选择原始编号 #3、#5、#4，代价为 2、2、7；总代价 11。第三轮两端候选区域重叠。

官方示例 2

输入：costs = [1,2,4,1],
      k = 3, candidates = 3
输出：4

依次选择原始编号 #0、#3、#1，代价为 1、1、2；总代价 4。候选区最初就重叠，最后一轮所有剩余人都可选。

04 / 独立题解

准备好再揭开实现

先思考：删除一个候选人后，哪些工人的资格发生了变化？

核心洞察：维护候选池，不搬动整个队伍

未进入候选集合的工人始终是一个连续区间 [l, r]。只要这个区间非空，左池移除一人就从 l 补一人，右池移除一人就从 r 补一人。两端候选的并集可以用一个最小堆维护；堆元素记录 (代价, 原始编号, 来源侧)。

堆按代价优先、编号次优排序。来源侧只决定从哪边补位。用两个最小堆也可以，但一个带来源标记的堆让四份代码共享同一过程。

完整过程

  1. 设置 l = 0、r = n − 1。最多取 candidates 人放入堆，标记左侧，每次 l 加一。
  2. 再从右侧最多取 candidates 人，标记右侧，每次 r 减一。每一次入堆都要求 l ≤ r，避免重叠重复。
  3. 重复 k 次：弹出堆顶，将其代价累加到答案。
  4. 若 l ≤ r，按弹出元素的来源侧补入 costs[l] 或 costs[r]，并移动对应指针；否则不再补位。
  5. 返回累计代价。堆中元素始终是尚未雇佣且当前有资格被选择的工人。

示例 1 的完整轨迹

初始左池 #0–#3，右池 #5–#8，未进入区只有 #4。第一轮两个代价 2 中 #3 更靠前，因此选 #3，左侧补入 #4（代价 7），未进入区变空。第二轮选 #5（代价 2），不补位。第三轮选 #4（代价 7），不补位，累计 11。

正确性证明

  1. 初始化不变量：两次入堆分别覆盖剩余队伍的前 c 人与后 c 人。l ≤ r 保证每人最多入堆一次；若两端重叠，则所有工人已在堆中。
  2. 选择正确：假设堆恰好包含本轮候选并集。按 (代价, 编号) 排序的堆顶就是规则要求的唯一选择；原始编号顺序与删除后的下标顺序一致。
  3. 维持不变量：未进入区非空时，两侧候选区互不重叠。某侧删除一人，只会使该侧紧邻未进入区的一个工人获得资格，将其补入即可。未进入区为空时，所有剩余工人已在堆中，无须补位。
  4. 终止：每轮恰好删除一名不同工人，k ≤ n 保证可进行 k 轮。每次选取符合题目规则，累加结果因此是所求总代价。

复杂度

记 c = candidates，m = min(n, 2c)。下方代码逐个入堆，初始化 O(m log(m + 1))；k 轮操作 O(k log(m + 1))；总时间 O((m + k) log(m + 1))，额外空间 O(m)。若一次性 heapify，初始化可降为 O(m)。可视化为易读而对最多 24 人的候选池排序，不作为正式解法复杂度依据。

边界与数值类型

  • n = 1、k = n、c = n 均由同一流程处理。
  • 2c ≥ n 时初始候选覆盖所有人，后续只出堆，不重复补位。
  • 所有代价相同也必须按编号选，否则补位方向可能改变后续选择。
  • 总和最大 10¹⁰：Java 使用 long，C++ 使用 long long；Python int 自动扩展，JavaScript Number 在该范围内能精确表示整数。

替代方案

  • 两个最小堆：分别维护左池和右池。比较两堆顶，代价相同时选左池，再在该池内部按编号排序；复杂度同阶。
  • 直接扫描剩余队伍：每轮取两端并集、选最小并删除，简单但最坏 O(kn)，可用于小规模规则推演。
  • 全局排序：仅当 2c ≥ n、所有工人一开始就可见时可直接取前 k 小。一般情况中间便宜工人尚无资格，不能全局排序替代过程。

常见错误

  • 仅按代价排序，丢掉编号的平局规则。
  • 左右初始化都取满 c 个，却不判断 l ≤ r，导致同一工人重复雇佣。
  • 从固定方向补位，而不是从被选中工人的来源侧补位。
  • 把原数组的固定前后 c 个位置当成每轮候选，忽略删除后的资格变化。
  • Java / C++ 用 32 位整数保存总代价，发生溢出。

面试追问

  • 为何不重编号？只删除、不换序，原始编号足以表达所有存活工人的先后关系。
  • 候选区相遇后来源侧还有意义吗？来源仍可保留，但不再触发补位，因此不影响选择。
  • 能否只存代价？在双堆方案中可利用左侧优先和同侧补位的性质简化；若需返回精确工人序列，仍应保留编号。
  • 如果每轮 c 会变化？现有池可能需要扩展或移除资格，不再只有单侧补一个，须重新设计候选维护机制。

Java

import java.util.PriorityQueue;

class Solution {
    public long totalCost(int[] costs, int k, int candidates) {
        // 元素：(代价, 原始编号, 来源侧 0/1)
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) ->
            a[0] != b[0] ? Integer.compare(a[0], b[0])
                         : Integer.compare(a[1], b[1]));
        int l = 0, r = costs.length - 1;
        for (int t = 0; t < candidates && l <= r; t++) {
            heap.offer(new int[]{costs[l], l, 0});
            l++;
        }
        for (int t = 0; t < candidates && l <= r; t++) {
            heap.offer(new int[]{costs[r], r, 1});
            r--;
        }
        long answer = 0;
        for (int t = 0; t < k; t++) {
            int[] worker = heap.poll();
            answer += worker[0];
            if (l <= r) {
                int i = worker[2] == 0 ? l++ : r--;
                heap.offer(new int[]{costs[i], i, worker[2]});
            }
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number[]} costs
 * @param {number} k
 * @param {number} candidates
 * @return {number}
 */
var totalCost = function(costs, k, candidates) {
    const heap = [];
    const less = (a, b) =>
        a[0] < b[0] || (a[0] === b[0] && a[1] < b[1]);
    function push(item) {
        let i = heap.length;
        heap.push(item);
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (!less(item, heap[p])) break;
            heap[i] = heap[p];
            i = p;
        }
        heap[i] = item;
    }
    function pop() {
        const first = heap[0], last = heap.pop();
        if (heap.length) {
            let i = 0;
            while (2 * i + 1 < heap.length) {
                let child = 2 * i + 1;
                if (child + 1 < heap.length &&
                    less(heap[child + 1], heap[child])) child++;
                if (!less(heap[child], last)) break;
                heap[i] = heap[child];
                i = child;
            }
            heap[i] = last;
        }
        return first;
    }
    let l = 0, r = costs.length - 1;
    for (let t = 0; t < candidates && l <= r; t++) {
        push([costs[l], l, 0]);
        l++;
    }
    for (let t = 0; t < candidates && l <= r; t++) {
        push([costs[r], r, 1]);
        r--;
    }
    let answer = 0;
    for (let t = 0; t < k; t++) {
        const [cost, index, side] = pop();
        answer += cost;
        if (l <= r) {
            const i = side === 0 ? l++ : r--;
            push([costs[i], i, side]);
        }
    }
    return answer;
};

Python 3

from typing import List
from heapq import heappush, heappop

class Solution:
    def totalCost(self, costs: List[int], k: int, candidates: int) -> int:
        heap = []
        l, r = 0, len(costs) - 1
        for _ in range(candidates):
            if l > r:
                break
            heappush(heap, (costs[l], l, 0))
            l += 1
        for _ in range(candidates):
            if l > r:
                break
            heappush(heap, (costs[r], r, 1))
            r -= 1
        answer = 0
        for _ in range(k):
            cost, index, side = heappop(heap)
            answer += cost
            if l <= r:
                if side == 0:
                    heappush(heap, (costs[l], l, side))
                    l += 1
                else:
                    heappush(heap, (costs[r], r, side))
                    r -= 1
        return answer

C++

#include <vector>
#include <queue>
#include <tuple>
#include <functional>
using namespace std;

class Solution {
public:
    long long totalCost(vector<int>& costs, int k, int candidates) {
        using Worker = tuple<int, int, int>;
        priority_queue<Worker, vector<Worker>, greater<Worker>> heap;
        int l = 0, r = static_cast<int>(costs.size()) - 1;
        for (int t = 0; t < candidates && l <= r; ++t) {
            heap.emplace(costs[l], l, 0);
            ++l;
        }
        for (int t = 0; t < candidates && l <= r; ++t) {
            heap.emplace(costs[r], r, 1);
            --r;
        }
        long long answer = 0;
        for (int t = 0; t < k; ++t) {
            auto [cost, index, side] = heap.top();
            heap.pop();
            answer += cost;
            if (l <= r) {
                int i = side == 0 ? l++ : r--;
                heap.emplace(costs[i], i, side);
            }
        }
        return answer;
    }
};
