每一列的宽度

给定一个从 0 开始编号的 m × n 整数矩阵 grid。一列的宽度，是该列所有整数写成字符串后长度的最大值；负号也占一个字符。

题号 2639非付费题返回 integer[]

Problem

题意与输入输出

函数接收参数 grid: integer[][]，返回长度为 n 的整数数组 ans，其中 ans[i] 表示第 i 列的宽度。若整数有 len 个数位，非负数的字符串长度为 len，负数还需为负号增加 1。

例：一列为 [-10, 3, 12] 时，宽度为 3，因为字符串 "-10" 最长。

示例 1

输入：grid = [[1],[22],[333]]
输出：[3]
解释：第 0 列中，333 的字符串长度为 3。

示例 2

输入：grid = [[-15,1,3],[15,7,12],[5,6,-2]]
输出：[3,1,2]
解释：第 0 列的最大长度为 3；
      第 1 列的最大长度为 1；
      第 2 列的最大长度为 2。

约束

  • m == grid.length
  • n == grid[i].length
  • 1 <= m, n <= 100
  • -109 <= grid[r][c] <= 109

Walkthrough

题解：逐列维护最大长度

核心洞察

每一列的答案彼此独立。把每个整数转成字符串，字符串长度天然同时计入数位与负号；扫描一列时维护最大值即可。

完整过程

  1. 创建长度为列数 n 的答案数组。
  2. 依次枚举每一列，再枚举该列的所有行。
  3. 计算 grid[r][c] 的字符串长度，并更新本列最大值。
  4. 将最大值写入 ans[c]，处理下一列。

正确性证明

循环不变量：处理完第 r 行后，当前最大值等于该列前 r + 1 个整数的最大字符串长度。

初始化：读入首个元素后，最大值就是只含该元素的集合中的最大长度。

保持：加入下一元素时取旧最大值与新长度的较大者，因此不变量继续成立。

终止：一列所有行均处理后，最大值就是该列宽度。每一列都如此处理，所以返回数组完全正确。

边界情况

  • 0 的字符串长度是 1。
  • 负号计入长度，例如 -2 长度为 2。
  • 只有一行或一列时，流程无需特殊分支。
  • ±109 均可由标准整数与字符串转换安全处理。
时间复杂度O(m × n)每个单元格恰好访问一次。
额外空间O(1)不计必须返回的答案数组。

四种语言实现

Java

Java
class Solution {
    public int[] findColumnWidth(int[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;
        int[] ans = new int[cols];

        for (int c = 0; c < cols; c++) {
            for (int r = 0; r < rows; r++) {
                int width = String.valueOf(grid[r][c]).length();
                ans[c] = Math.max(ans[c], width);
            }
        }
        return ans;
    }
}

var findColumnWidth = function(grid) {
    const cols = grid[0].length;
    const ans = Array(cols).fill(0);

    for (let c = 0; c < cols; c++) {
        for (let r = 0; r < grid.length; r++) {
            ans[c] = Math.max(ans[c], String(grid[r][c]).length);
        }
    }
    return ans;
};

from typing import List


class Solution:
    def findColumnWidth(self, grid: List[List[int]]) -> List[int]:
        rows, cols = len(grid), len(grid[0])
        ans = [0] * cols

        for c in range(cols):
            for r in range(rows):
                ans[c] = max(ans[c], len(str(grid[r][c])))
        return ans

替代方案：数学计数

也可反复除以 10 计算数位，并为负数额外加 1；但必须单独处理 0，分支更多。字符串转换更短、更直观，且约束范围内性能足够。

面试追问

  • 如果矩阵按行流式到达，如何在线更新列宽？
  • 如果禁止字符串转换，如何正确处理 0 和负数？
  • 若输出需要对齐打印，列宽结果如何参与排版？

常见错误

  • 忘记负号也占一个字符。
  • 按行求最大值，导致答案长度变成 m。
  • 数学计数时把 0 的长度算成 0。
  • 把答案初始化为固定上限，而非逐列更新。

一句话记忆

列优先扫描，把每个数转成字符串，逐列取最大长度。
