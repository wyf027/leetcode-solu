LEETCODE / 1814 / MEDIUM

统计一个数组中
好对子的数目

Count Nice Pairs in an Array

把数字翻转，寻找满足等式的下标对。先思考，再展开推导。

题目

给定非负整数数组 nums。rev(x) 表示将十进制数字反转后得到的整数；前导零不保留，例如 rev(123) = 321、rev(120) = 21，rev(0) = 0。

统计满足以下条件的下标对 (i, j)：

  • 0 ≤ i < j < nums.length
  • nums[i] + rev(nums[j]) = nums[j] + rev(nums[i])

返回好对子数对 1,000,000,007 取余的结果。

约束

1 ≤ nums.length ≤ 10⁵；0 ≤ nums[i] ≤ 10⁹。

官方示例 1

输入：nums = [42,11,1,97]
输出：2

(0,3)：42 + 79 = 97 + 24 = 121。
(1,2)：11 + 1 = 1 + 11 = 12。

官方示例 2

输入：nums = [13,10,35,24,76]
输出：4
官方题目

思考入口

如果枚举每个下标对，需要比较多少次？有没有一种只与单个数字有关的属性，可以判断两个数字是否能够配对？

下面的独立题解包含交互演示与四语言实现，默认收起。

题解 · 同差值进入同一个桶

核心洞察

将原等式两侧各自的反转项移项，可得：

nums[i] − rev(nums[i]) = nums[j] − rev(nums[j])

定义键 d(x) = x − rev(x)。同一个键的数字都能互相配对。维护已经出现的键频次：当前数字进入桶前，桶里有 k 个旧下标，就新增 k 个好对子。

交互实验 · 差值分桶流水线

演示逐个处理元素，突出“读取旧频次 → 累加 → 入桶”。交互规模限制为 1–30 个整数；正式解法支持完整约束。动画只在点击后播放。

已处理元素的桶

本轮新增配对

完整过程

  1. 初始化空哈希表与答案 0。
  2. 从左到右遍历 x，通过取个位、拼到末尾计算 rev(x)。
  3. 计算键 x − rev(x)，读取之前出现的频次 k，答案加 k 并取模。
  4. 将该键频次加 1，继续处理下一个数字。

示例 1 的键依次是 18、0、0、18；新增对子数依次是 0、0、1、1，最终为 2。

正确性

循环不变式：处理下标 j 之前，哈希表准确记录所有 i < j 的键频次，答案记录右端点小于 j 的全部好对子数（取模）。移项是等价变换，因此当前键在表中的 k 次出现，恰好对应以 j 为右端点的全部好对子。先加 k 再入桶不会计入 (j,j)，也不会遗漏旧下标。每对下标仅在其右端点被处理时计数一次。初始空前缀成立，循环保持不变式，遍历结束即得到全部答案。

边界与复杂度

0 的反转仍为 0；尾零自然被丢弃；键可以为负数。长度为 1 时返回 0；相同键出现 m 次贡献 m(m−1)/2。设最大十进制位数为 D（本题至多 10），哈希操作期望 O(1)，总时间期望 O(nD)，空间 O(n)。在给定值域下通常简写为期望 O(n)。

结果可能超过 32 位整数；Java/C++ 使用 long/long long 累加。JavaScript 的 Number 足以精确表示本题整数中间值：即便不取模，最多也只有 4,999,950,000 对；代码仍每步取模。

替代方案

  • 暴力枚举：预计算反转后 O(n²) 时间，适合手工核对小输入，不适合 10⁵ 长度。
  • 排序分组：对所有键排序，每段长度 m 加 m(m−1)/2；时间 O(nD + n log n)，需要存储键。
  • 先统计所有频次再求组合数：时间与哈希增量法相同，乘法前必须提升到宽整数。

常见错误

  • 先增加频次再加答案，会误计自身。
  • 只统计不同数值，会漏掉值相同但下标不同的对子。
  • 把键取绝对值，导致正负键错误合并。
  • 用字符串反转后忘记转回整数，或者未处理零。
  • 在 32 位整数中先计算 m(m−1) 再转为长整数，溢出已经发生。

面试追问

数据流如何处理？ 保留哈希表和取模答案，每来一个数执行相同步骤。如何列出全部对子？ 每个键存旧下标列表，输出所有匹配下标；时间还要加上输出规模，最坏为 O(n²)。删除一个元素呢？ 若桶当前有 c 个元素，删除后减少 c−1 个对子，模减法需归一化。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int countNicePairs(int[] nums) {
        final long MOD = 1_000_000_007L;
        Map<Integer, Integer> freq = new HashMap<>();
        long answer = 0;
        for (int x : nums) {
            int t = x, reversed = 0;
            while (t > 0) {
                reversed = reversed * 10 + t % 10;
                t /= 10;
            }
            int key = x - reversed;
            int count = freq.getOrDefault(key, 0);
            answer = (answer + count) % MOD;
            freq.put(key, count + 1);
        }
        return (int) answer;
    }
}

    let answer = 0;
    for (const x of nums) {
        let t = x, reversed = 0;

            t = Math.floor(t / 10);

        answer = (answer + count) % MOD;
        freq.set(key, count + 1);

    return answer;
};

from typing import List

class Solution:
    def countNicePairs(self, nums: List[int]) -> int:
        mod = 1_000_000_007
        freq = {}
        answer = 0
        for x in nums:
            t, reversed_num = x, 0
            while t > 0:
                reversed_num = reversed_num * 10 + t % 10
                t //= 10
            key = x - reversed_num
            count = freq.get(key, 0)
            answer = (answer + count) % mod
            freq[key] = count + 1
        return answer

C++

#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int countNicePairs(vector<int>& nums) {
        const long long MOD = 1000000007LL;
        unordered_map<int, int> freq;
        long long answer = 0;
        for (int x : nums) {
            int t = x, reversed = 0;
            while (t > 0) {
                reversed = reversed * 10 + t % 10;
                t /= 10;
            }
            int key = x - reversed;
            int count = freq[key];
            answer = (answer + count) % MOD;
            freq[key] = count + 1;
        }
        return static_cast<int>(answer);
    }
};
