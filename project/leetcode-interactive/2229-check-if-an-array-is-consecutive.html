01 / 理解问题

这些数字能否组成一段完整的整数？

给定整数数组 nums，设最小值为 x、长度为 n。如果从 x 到 x + n − 1 的每一个整数都出现在数组中，返回 true；否则返回 false。原数组不必有序；这段范围中的每个数都应恰好出现一次。

接口：isConsecutive(nums: integer[]) → boolean。唯一参数是整个数组，返回布尔值。

先自己判断：nums = [2, 2, 4] 是否连贯？重复数字会对结果有什么影响？

03 / 独立题解

给每个整数安排一个唯一槽位

核心洞察

找到最小值 m 后，目标集合固定为 [m, m+n−1]。建立长度为 n 的布尔数组，数字 v 对应槽位 v−m。槽位越界意味着数字不属于目标范围；槽位已经占用意味着重复。

完整过程

  1. 扫描一遍，求最小值 m。
  2. 建立全为 false 的 seen[n]。
  3. 依次读取 v，计算 k = v − m。若 k ≥ n 或 seen[k] 已为 true，立即返回 false；否则标记该槽位。
  4. 全部数字入槽后返回 true。由于 m 是最小值，k 不会小于零。

数字入槽实验台

先扫描最小值，再按原顺序入槽。演示限 1–16 个整数，值域仍为 0–100000；提交代码支持完整题目约束。

正确性证明

循环不变式：处理完前 i 个元素且尚未返回 false 时，这 i 个元素都在目标范围内，互不相同，并且恰好占据 i 个对应槽位。初始 i=0 时成立；下一元素只有在合法且未占用时才被加入，因此不变式保持。

充分性：处理完 n 个元素时，n 个合法槽位被 n 个不同元素占据，因而没有缺口，数组连贯。必要性：连贯数组中的值均在目标范围内且各出现一次，不可能越界或重复，算法必然返回 true。发生越界或重复时则违反题意，可以立即返回 false。

边界与复杂度

单元素总为 true，含零正常处理；原顺序和是否逆序都不影响结论。空数组不在输入约束内。两次线性扫描，时间 O(n)，布尔标记占额外空间 O(n)，不修改输入。当前值域下整数相减安全；若推广到大整数，需相应扩大整数类型。

Java

class Solution {
    public boolean isConsecutive(int[] nums) {
        int m = nums[0], n = nums.length;
        for (int v : nums) m = Math.min(m, v);
        boolean[] seen = new boolean[n];
        for (int v : nums) {
            int k = v - m;
            if (k >= n || seen[k]) return false;
            seen[k] = true;
        }
        return true;
    }
}

Python

from typing import List

class Solution:
    def isConsecutive(self, nums: List[int]) -> bool:
        m = min(nums)
        n = len(nums)
        seen = [False] * n
        for v in nums:
            k = v - m
            if k >= n or seen[k]:
                return False
            seen[k] = True
        return True

替代方案

  • 排序：排序后逐对判断差值是否为 1。时间 O(n log n)，额外空间取决于排序实现及是否复制数组；原地排序会改变输入。
  • 集合 + 两端：要求不同元素个数等于 n，且最大值减最小值加 1 等于 n。哈希集合平均 O(n) 时间、O(n) 空间；范围长度条件不能代替去重。

常见错误

  • 只看最大值与最小值：[2,2,4] 范围长度虽为 3，却缺少 3。
  • 直接比较原数组相邻元素：会误判合法的乱序输入。
  • 先访问槽位再检查越界：Java、Python 等可能抛异常，C++ 可能产生未定义行为。
  • JavaScript 用默认 sort() 做数值排序：应提供 (a,b) => a-b。求最小值也不宜对大数组直接使用参数展开。
  • 仅比较总和：重复与缺失可以互相抵消，不能证明元素恰好各出现一次。

面试追问

能在线读取一次吗？集合方案可同时记录最小值、最大值和不同值数量，读完再判断。可否 O(1) 额外空间？若允许改动输入，可先取最小值再按偏移进行循环置换；必须额外处理重复与非法位置。若采用堆排序，也可用 O(1) 辅助空间，以 O(n log n) 时间交换空间。
