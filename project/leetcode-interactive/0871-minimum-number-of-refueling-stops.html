01 / 题目

一段只向东的旅程

汽车从起点出发，目的地位于东面 target 英里。初始油量为 startFuel，油箱容量无限；每行驶 1 英里消耗 1 升油。

stations[i] = [positionᵢ, fuelᵢ] 表示一个沿途加油站。到站时可以选择停车，并一次性加入该站的全部燃料。

任务：返回抵达目的地所需的最少加油次数；若无法抵达，返回 -1。以 0 油量恰好到站或到达终点均有效。

约束

  • 1 ≤ target, startFuel ≤ 10⁹
  • 0 ≤ stations.length ≤ 500
  • 1 ≤ positionᵢ < positionᵢ₊₁ < target
  • 1 ≤ fuelᵢ < 10⁹

站点按位置严格递增排列；返回值类型为整数。

04 / 完整题解

延迟决定 + 最大堆

核心洞察

把 startFuel 看作当前“最远可达位置”。凡是位置不超过该值的加油站，都已经具备选择资格。只有当目标仍不可达时，才从所有有资格的站点里取燃料最多的一个，将可达范围扩得最远。

这等价于把“是否在路过时加油”的决定延迟到缺油时。最大堆保存所有已经路过但尚未使用的站点燃料。

完整过程

  1. 令 reach = startFuel，站点下标与答案均为 0。
  2. 把所有 position ≤ reach 的站点燃料加入最大堆。
  3. 若 reach ≥ target，返回已加油次数。
  4. 若堆为空，说明再无可用燃料，返回 -1。
  5. 弹出堆顶燃料，加到 reach，次数加一，继续循环。

正确性证明

  1. 候选集合完整：每轮进入堆的恰好是当前可达且尚未使用的站点，因此任何合法的下一次加油都来自堆中。
  2. 贪心选择不劣：当必须加油时，若某最优方案选择燃料量较小的站点，可将它替换为堆中燃料最多的站点。加油次数不变，可达范围只会更远，不会破坏后续可行性。
  3. 最少次数：算法仅在现有油量无法继续抵达目标时加油；每次又采用不劣于任何其他候选的选择。故若它用 k 次抵达，不存在少于 k 次的可行方案。
  4. 失败可靠：目标未到且堆为空时，没有任何已可达的未用站点，车辆无法扩展可达范围，因此任何方案都失败。

复杂度

时间：O(n log n)。每座站最多入堆、出堆各一次。
空间：O(n)，用于最大堆。

边界清单

  • 初始油量已经覆盖终点：返回 0。
  • 没有站点且燃料不足：返回 -1。
  • 恰好 0 油到站：该站仍可入堆。
  • 恰好到终点：视为成功。
  • 数值可达 10⁹：Java/C++ 的累计里程使用 64 位整数。

替代方案：动态规划

定义 dp[k] 为恰好加油 k 次所能到达的最远位置。依次处理站点，并倒序更新 dp[k + 1]。时间 O(n²)、空间 O(n)。它更直接地枚举次数，但不如最大堆高效。

面试追问

  • 若每站可以只加一部分，结论会变吗？在本题无限油箱、只最小化次数的目标下，选择后加满不吃亏。
  • 若油箱容量有限？候选燃料不能简单累加，需要重新建模，常见做法是图最短路或更细的 DP。
  • 为什么不能到站就加油？这可能在同样能到达时产生额外停车，失去最少次数保证。

常见错误

  • 按站点顺序遇站必加，得到可行但非最少的次数。
  • 缺油时只看最近站点，而不是所有已路过站点。
  • 使用最小堆，优先取了最少燃料。
  • 把 position === reach 错判为不可达。
  • 忘记在无候选燃料时返回 -1。
  • 累计可达里程使用 32 位整数导致溢出。

四语言完整实现

class Solution {
    public int minRefuelStops(int target, int startFuel, int[][] stations) {
        java.util.PriorityQueue<Integer> maxHeap =
            new java.util.PriorityQueue<>((a, b) -> Integer.compare(b, a));
        long reach = startFuel;
        int index = 0;
        int stops = 0;

        while (reach < target) {
            while (index < stations.length && stations[index][0] <= reach) {
                maxHeap.offer(stations[index][1]);
                index++;
            }
            if (maxHeap.isEmpty()) return -1;
            reach += maxHeap.poll();
            stops++;
        }
        return stops;
    }
}
/**
 * @param {number} target
 * @param {number} startFuel
 * @param {number[][]} stations
 * @return {number}
 */
var minRefuelStops = function(target, startFuel, stations) {
    const heap = [];
    const push = (value) => {
        heap.push(value);
        let i = heap.length - 1;
        while (i > 0) {
            const p = Math.floor((i - 1) / 2);
            if (heap[p] >= heap[i]) break;
            [heap[p], heap[i]] = [heap[i], heap[p]];
            i = p;
        }
    };
    const pop = () => {
        const top = heap[0];
        const last = heap.pop();
        if (heap.length) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let largest = i;
                const left = i * 2 + 1;
                const right = left + 1;
                if (left < heap.length && heap[left] > heap[largest]) largest = left;
                if (right < heap.length && heap[right] > heap[largest]) largest = right;
                if (largest === i) break;
                [heap[i], heap[largest]] = [heap[largest], heap[i]];
                i = largest;
            }
        }
        return top;
    };

    let reach = startFuel;
    let index = 0;
    let stops = 0;
    while (reach < target) {
        while (index < stations.length && stations[index][0] <= reach) {
            push(stations[index][1]);
            index++;
        }
        if (heap.length === 0) return -1;
        reach += pop();
        stops++;
    }
    return stops;
};
from typing import List
import heapq

class Solution:
    def minRefuelStops(
        self, target: int, startFuel: int, stations: List[List[int]]
    ) -> int:
        max_heap = []
        reach = startFuel
        index = 0
        stops = 0

        while reach < target:
            while index < len(stations) and stations[index][0] <= reach:
                heapq.heappush(max_heap, -stations[index][1])
                index += 1
            if not max_heap:
                return -1
            reach += -heapq.heappop(max_heap)
            stops += 1

        return stops

public:

                ++index;
