连续的一段，能有多少种选法？先理解规则，再动手观察。

01 / 题目

只统计连续、严格上升的片段

给你正整数数组 nums，返回其中满足严格递增条件的非空连续子数组数量。对选中的片段，每个后继元素都必须大于前一个元素。长度为 1 的片段也符合条件。

按下标区间计数：位于不同位置的两个 [4] 是两份子数组。不能跳过元素，也不能把相等当作递增。

参数与返回值

countSubarrays(nums: integer[]) → long

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁶

题名、签名与示例输入来自本次官方元数据；空缺题面依据公开资料转述，示例输出及约束参考 LeetCode Wiki。官方题目入口。

官方示例 1

输入：nums = [1,3,5,4,4,6]
输出：10

单元素片段有 6 个；双元素片段为 [1,3]、[3,5]、[4,6]；三元素片段仅 [1,3,5]。合计 10 个。

官方示例 2

输入：nums = [1,2,3,4,5]
输出：15

所有非空连续片段都满足条件。长度从 1 到 5 分别有 5、4、3、2、1 种，共 15 种。

04 / 独立题解

准备好揭开计数规律了吗？

展开后包含推导、证明、边界与四种语言实现。

每个右端点，贡献一段长度

核心洞察

设 run 是以当前下标 i 结尾的最长严格递增连续段长度。它的所有后缀都是合法片段，起点恰有 run 种，因此本步贡献就是 run。

run = (i > 0 且 nums[i] > nums[i-1]) ? run + 1 : 1
answer += run

完整过程

  1. 将 run 和 answer 初始化为 0，从 i = 0 开始扫描。
  2. 当前元素比前一个更大时，原有片段都能延长，再新增当前单元素片段，令 run 加 1。
  3. 首元素、相等或下降时，只能从当前元素重新开始，令 run = 1。
  4. 把 run 加入 answer。遍历结束返回 answer。

正确性证明

循环不变量：处理完 i 后，run 等于以 i 结尾的合法子数组数，answer 等于右端点不超过 i 的合法子数组总数。

起始 i = 0 时，唯一的片段是 [nums[0]]，所以 run = answer = 1。假设上一轮成立：若 nums[i] 大于 nums[i−1]，所有以上一位置结尾的合法片段都能延长，另加 [nums[i]]，得到 run + 1 个；任何更长的合法片段去掉末尾也必须属于上一轮，因此没有遗漏。若相邻元素不严格上升，任何长度至少为 2 的片段都包含这个违规相邻对，仅单元素片段合法，所以 run = 1。

将本轮数量加到 answer 后，不同轮次的右端点不同，不会重复。所有非空子数组都有唯一右端点，遍历完即覆盖全部合法子数组，答案正确。

边界与数值范围

  • 单元素返回 1；全相等或全下降返回 n。
  • 全递增时计数为 n(n+1)/2；n = 100000 时为 5,000,050,000，超过 32 位有符号整数。
  • Java 使用 long，C++ 使用 long long；Python 整数无需额外处理。JavaScript Number 能精确表示本题上界，因为它小于 2⁵³−1，不要使用位运算截断。
  • 官方输入保证非空；无需排序或修改 nums。

复杂度

时间 O(n)，每个元素只处理一次；额外空间 O(1)，只维护 run 和 answer。演示为展示各片段而创建的节点不计入提交算法空间。

替代方案

按最大严格递增段分组，一段长度为 L 时贡献 L(L+1)/2，逐段累加，也为 O(n) 时间、O(1) 空间；注意结算最后一段，并在乘法前转为 64 位。枚举每个起点再向右扩展，最坏 O(n²)，适合小输入讲解，不适合 10⁵ 的规模。

常见错误

  • 用 ≥ 比较导致把 [4,4] 算入。
  • 在断点将 run 设为 0，漏算单元素片段。
  • 只返回最长段长度，或只累加增长次数，混淆长度与数量。
  • 把子数组当成子序列，允许跳跃；或用集合去重，错误合并不同位置。
  • 使用 32 位答案，或先做 32 位乘法再转 long。

面试追问

  • 只统计长度至少 k？每个右端点贡献 max(0, run − k + 1)，k ≥ 1。
  • 改成非递减？延长条件改为 nums[i] ≥ nums[i−1]，其余推导相同。
  • 流式输入？保存前一个值、run 和累计答案即可，每次接收新值做一次更新。
  • 要求输出所有片段？用区间表示也可能有 Θ(n²) 个结果，不能保证线性输出时间。

Java

class Solution {
    public long countSubarrays(int[] nums) {
        long answer = 0;
        long run = 0;
        for (int i = 0; i < nums.length; i++) {
            run = i > 0 && nums[i] > nums[i - 1] ? run + 1 : 1;
            answer += run;
        }
        return answer;
    }
}

Python

from typing import List

class Solution:
    def countSubarrays(self, nums: List[int]) -> int:
        answer = 0
        run = 0
        for i, value in enumerate(nums):
            run = run + 1 if i > 0 and value > nums[i - 1] else 1
            answer += run
        return answer

class Solution {

    long long countSubarrays(vector<int>& nums) {
        long long answer = 0;
        long long run = 0;
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {

            answer += run;
        }
        return answer;
    }
};
