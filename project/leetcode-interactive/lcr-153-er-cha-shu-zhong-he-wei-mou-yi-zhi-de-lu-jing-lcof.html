二叉树中和为目标值的路径

给定二叉树根节点 root 与整数 target，找出所有从根节点到叶子节点、节点值之和恰好等于 target 的路径。

路径边界

根节点 → 叶子节点

输出

全部匹配路径

节点值

可能包含负数

题意

只接受完整的根到叶路径

  • 叶子节点没有左、右子节点。
  • 到达中间节点时，即使路径和等于目标也不能立即收集。
  • 答案中的每条路径按从根到叶的访问顺序保存。

示例

target = 22

root = [5,4,8,11,null,13,4,7,2,null,null,5,1]
target = 22

输出：
[
  [5,4,11,2],
  [5,8,4,5]
]

完整题解

核心洞察

DFS 穷举，回溯复用路径

每个节点只属于当前正在探索的根到节点路径。进入节点时把值加入 path 并从剩余目标中扣除；离开节点时删除最后一个值，让同一个数组安全服务兄弟子树。

判定条件

叶子 + 剩余目标为 0

只有节点同时没有左右孩子，且扣除当前值后的 remaining === 0，才能把当前路径的副本加入答案。

完整过程

递归模板

  1. 1. 空节点返回：没有路径状态需要修改。
  2. 2. 进入节点：push 当前值，并更新剩余目标。
  3. 3. 叶子验收：剩余目标为 0 时复制并收集路径。
  4. 4. 继续搜索：依次递归左子树与右子树。
  5. 5. 回溯恢复：pop 当前值，交还父层原有状态。 
target = 22
5  → remaining = 17, path = [5]
4  → remaining = 13, path = [5,4]
11 → remaining = 2,  path = [5,4,11]
2  → remaining = 0,  且为叶子，收集路径副本
回退 2、11、4，再探索其他分支

边界

五个必须守住的细节

  • 空树返回空数组。
  • 单节点树必须同时匹配目标。
  • 中间节点凑到目标仍不能收集。
  • 负数场景不能按大小剪枝。
  • 记录答案时必须复制当前路径。

复杂度

一次树遍历

设节点数为 n、树高为 h。遍历时间 O(n)；复制答案的额外时间与所有答案路径长度之和成正比。递归栈与当前路径占用 O(h)，不含返回结果。

替代方案

迭代 DFS 或 BFS

显式栈可以避免递归深度风险，但每个状态需保存节点、剩余目标和路径。BFS 也能完成，不过队列状态携带完整路径，空间通常更高。

常见错误

路径状态污染

  • 忘记叶子判断，把根到中间节点计入答案。
  • 保存原 path 引用，后续回溯改坏答案。
  • 忘记 pop，兄弟分支携带错误节点。
  • 因节点值可能为负数却错误剪枝。

class Solution {
    public List<List<Integer>> pathTarget(TreeNode root, int target) {
        List<List<Integer>> answer = new ArrayList<>();
        dfs(root, target, new ArrayList<>(), answer);
        return answer;
    }

    private void dfs(TreeNode node, int remaining, List<Integer> path,
                     List<List<Integer>> answer) {
        if (node == null) {
            return;
        }

        path.add(node.val);
        remaining -= node.val;

        if (node.left == null && node.right == null && remaining == 0) {
            answer.add(new ArrayList<>(path));
        } else {
            dfs(node.left, remaining, path, answer);
            dfs(node.right, remaining, path, answer);
        }

        path.remove(path.size() - 1);
    }
}

 * @param {TreeNode} root
 * @param {number} target

var pathTarget = function (root, target) {
  const answer = [];
  const path = [];

  const dfs = (node, remaining) => {
    if (node === null) return;

    path.push(node.val);
    remaining -= node.val;

    if (node.left === null && node.right === null && remaining === 0) {
      answer.push([...path]);
    } else {
      dfs(node.left, remaining);
      dfs(node.right, remaining);
    }

    path.pop();
  };

  dfs(root, target);
  return answer;
};

class Solution {
public:
    vector<vector<int>> pathTarget(TreeNode* root, int target) {
        vector<vector<int>> answer;
        vector<int> path;
        dfs(root, target, path, answer);
        return answer;
    }

private:
    void dfs(TreeNode* node, int remaining, vector<int>& path,
             vector<vector<int>>& answer) {
        if (node == nullptr) {
            return;
        }

        path.push_back(node->val);
        remaining -= node->val;

        if (node->left == nullptr && node->right == nullptr &&
            remaining == 0) {
            answer.push_back(path);
        } else {
            dfs(node->left, remaining, path, answer);
            dfs(node->right, remaining, path, answer);
        }

        path.pop_back();
    }
};
