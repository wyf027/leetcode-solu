    04 / SQL notes

    准备好再展开题解

    数据库题提供官方 SQL 方言与 Pandas，不伪称算法语言可提交。

    Solution unlocked

    GROUP BY + HAVING

    WHERE 在分组前筛行；按聚合结果筛组选用 HAVING。

    MySQL 主提交

    SELECT email AS Email
FROM Person
GROUP BY email
HAVING COUNT(*) > 1;

    每个 email 分组天然输出一行；COUNT 大于 1 就是重复。邮箱保证非 NULL，因此 COUNT(*) 与 COUNT(email) 在本题一致，但前者更直接。

    正确性与复杂度

    GROUP BY 将且仅将相同邮箱放入同一组，组大小就是出现次数；HAVING 保留次数至少 2 的组，恰好等于重复邮箱集合。数据库通常用哈希或排序聚合，概念时间约 O(n) 或 O(n log n)，执行计划依引擎与索引而定。

    四种官方 SQL 方言

    MySQL
    SELECT email AS Email
FROM Person
GROUP BY email
HAVING COUNT(*) > 1;
    PostgreSQL
    SELECT email AS "Email"
FROM Person
GROUP BY email
HAVING COUNT(*) > 1;
    SQL Server
    SELECT email AS Email
FROM Person
GROUP BY email
HAVING COUNT(*) > 1;
    Oracle
    SELECT email AS "Email"
FROM Person
GROUP BY email
HAVING COUNT(*) > 1

    替代方案与 Pandas

    • 自连接 p1.email=p2.email AND p1.id<>p2.id 再 DISTINCT 可行，但会生成更多中间配对。
    • 窗口 COUNT(*) OVER(PARTITION BY email) 再筛选也可行，但需要额外子查询和 DISTINCT。
    • 官方 Pandas 可用 value_counts() 或 duplicated(keep=False) 后去重。

    Java / JavaScript / Python / C++ 语义参考

    本题在 LeetCode 上的正式提交语言是 SQL 或 Pandas；以下四份代码仅用于在内存数组上复现“分组计数后筛出重复邮箱”的同一语义，不伪称可提交。

    Java · 本地语义参考
    import java.util.*;

class DuplicateEmailsReference {
    static List<String> duplicateEmails(List<String> emails) {
        Map<String, Integer> counts = new HashMap<>();
        for (String email : emails) {
            counts.merge(email, 1, Integer::sum);
        }
        List<String> answer = new ArrayList<>();
        for (Map.Entry<String, Integer> entry : counts.entrySet()) {
            if (entry.getValue() > 1) answer.add(entry.getKey());
        }
        Collections.sort(answer);
        return answer;
    }
}
    JavaScript · 本地语义参考
    function duplicateEmails(emails) {
  const counts = new Map();
  for (const email of emails) {
    counts.set(email, (counts.get(email) ?? 0) + 1);
  }
  return [...counts]
    .filter(([, count]) => count > 1)
    .map(([email]) => email)
    .sort();
}
    Python · 本地语义参考
    from collections import Counter

def duplicate_emails(emails: list[str]) -> list[str]:
    counts = Counter(emails)
    return sorted(email for email, count in counts.items() if count > 1)
    C++ · 本地语义参考
    #include <algorithm>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

vector<string> duplicateEmails(const vector<string>& emails) {
    unordered_map<string, int> counts;
    for (const string& email : emails) ++counts[email];
    vector<string> answer;
    for (const auto& [email, count] : counts) {
        if (count > 1) answer.push_back(email);
    }
    sort(answer.begin(), answer.end());
    return answer;
}
