独特的电子邮件地址

先别急着看答案。把每个地址送进“邮件净化器”，观察点号和加号如何改变本地名，而域名始终原样保留。

数组哈希表字符串Unique Email Addresses

题意

有效邮箱由 本地名 与 域名 组成，中间用 @ 分隔。只对本地名应用两条转发规则：

点号规则：本地名中的所有 . 都会被忽略；域名里的点不能删除。
加号规则：本地名里第一个 + 及其后的内容全部忽略；域名不受影响。

给定字符串数组 emails，向每个地址各发送一封邮件，返回实际收到邮件的不同地址数量。

函数与约束

numUniqueEmails(emails: string[]) → integer

  • 1 ≤ emails.length ≤ 100
  • 1 ≤ emails[i].length ≤ 100
  • 字符仅含小写字母、+、.、@
  • 每项恰有一个 @，本地名和域名均非空
  • 本地名不以 + 开头
  • 域名以 .com 结尾，且此前至少有一个字符

官方示例

示例 1 输入：emails = ["test.email+alex@leetcode.com","test.e.mail+bob.cathy@leetcode.com","testemail+david@lee.tcode.com"] 输出：2 解释：实际收件地址为 "testemail@leetcode.com" 和 "testemail@lee.tcode.com"。 示例 2 输入：emails = ["a@leetcode.com","b@leetcode.com","c@leetcode.com"] 输出：3

题解：规范化后去重

核心洞察：规则只改变 @ 左侧。把每个邮箱转换成唯一的规范形式，再交给集合去重，集合大小就是答案。

完整过程

  1. 在唯一的 @ 处分割本地名与域名。
  2. 只保留本地名中第一个 + 之前的前缀。
  3. 删除该前缀里的所有 .。
  4. 拼回未改动的域名，将结果加入哈希集合。
  5. 处理完所有输入后返回集合大小。

正确性证明

对任意地址，算法恰好执行题目规定的两种本地名转换，并完整保留域名，因此所得规范地址就是其实际收件地址。若两个输入实际送达同一地址，它们规范化后字符串相同，集合只保留一次；若实际送达地址不同，则规范字符串至少在净化后的本地名或域名上不同，集合会分别保留。故集合大小恰为不同实际收件地址数。

边界情况

  • 没有点号或加号：本地名保持不变。
  • 多个加号：只认第一个。
  • 点号出现在加号后：整段先被忽略，无需处理。
  • 域名包含点号：必须原样保留。
  • 不同域名：即使本地名相同也不是同一地址。

复杂度

设所有字符串总长度为 L，扫描和构造规范地址耗时 O(L)，集合存储最坏需要 O(L) 额外空间。

替代方案

可以用正则完成截断与删点，但字符扫描更直观、跨语言一致，也更易避免误改域名。还可逐字符扫描本地名，在遇到 + 或 @ 时改变状态。

面试追问

  • 若规则按域名不同而变化，如何设计可扩展的规范化策略？
  • 输入是海量数据流时，怎样控制内存或做分布式去重？
  • 为什么不能直接对原字符串排序后数相邻差异？

常见错误

  • 删除整个邮箱中的点，误伤域名。
  • 先按加号分割整个邮箱，忽略了规则仅针对本地名。
  • 把 + 后内容删掉却保留 + 本身。
  • 用数组做线性查重，使最坏时间复杂度退化。

四语言完整实现

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int numUniqueEmails(String[] emails) {
        Set<String> received = new HashSet<>();
        for (String email : emails) {
            int at = email.indexOf('@');
            String local = email.substring(0, at);
            String domain = email.substring(at);
            int plus = local.indexOf('+');
            if (plus != -1) local = local.substring(0, plus);
            local = local.replace(".", "");
            received.add(local + domain);
        }
        return received.size();
    }
}

var numUniqueEmails = function(emails) {
    const received = new Set();
    for (const email of emails) {
        const at = email.indexOf('@');
        const domain = email.slice(at);
        let local = email.slice(0, at);
        const plus = local.indexOf('+');
        if (plus !== -1) local = local.slice(0, plus);
        local = local.replaceAll('.', '');
        received.add(local + domain);
    }
    return received.size;
};

            size_t at = email.find('@');
            string local;
            for (size_t i = 0; i < at && email[i] != '+'; ++i) {
