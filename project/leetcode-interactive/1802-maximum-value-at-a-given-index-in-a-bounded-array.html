有界数组中指定下标处的最大值

Maximum Value at a Given Index in a Bounded Array

在有限的总和预算里，让指定位置尽可能高。

题目 · 相邻差不能超过 1

给定整数 n、index、maxSum，构造一个长度为 n、下标从 0 开始的数组 nums，满足：

  • 每个元素都是正整数，至少为 1。
  • 任意相邻两个元素的绝对差不超过 1。
  • 所有元素的总和不超过 maxSum。

返回所有合法构造中 nums[index] 的最大可能值。只返回该数值，不需要返回数组。

约束

1 ≤ n ≤ maxSum ≤ 10⁹
0 ≤ index < n

index 可以是 0。数组总和可以小于预算，不要求恰好用完。

官方示例

示例 1

输入：n = 4, index = 2, maxSum = 6
输出：2

例如 [1,1,2,1] 与 [1,2,2,1] 都合法；指定位置无法达到 3。

示例 2

输入：n = 6, index = 1, maxSum = 10
输出：3

目标位置是下标 1，即数组的第二个元素。

先想一想

如果指定位置已经确定，其他位置最少需要多少？当目标值增大时，所需预算会如何变化？

题解 · 山形下界 + 二分答案

核心洞察

假设目标位置的值为 x。距离目标 d 的元素至少为 max(1, x − d)：每移动一步最多下降 1，又不能低于 1。把所有位置恰好取到这个下界，就得到总和最小的合法山形数组。

因此，存在目标值为 x 的合法数组，当且仅当这个最小总和 S(x) ≤ maxSum。S(x) 随 x 严格递增，可行性呈现“可行 → 不可行”的单调边界。

常数时间求和

一侧有 k 个位置，不含峰顶。令 t = min(k, x − 1)，前 t 项为 x−1 到 x−t，剩余 k−t 项全为 1：

side(x, k) = t × (2x − t − 1) / 2 + (k − t)
S(x) = x + side(x, index) + side(x, n − index − 1)

峰顶只加一次。即使 x−t 等于 1，也可以把这一项算进等差段，结果不变。

完整过程

  1. 设 lo = 1，hi = maxSum − n + 1。除峰顶外至少需要 n−1 的预算。
  2. 取上中位数 mid = lo + floor((hi−lo+1)/2)。
  3. 若 S(mid) 不超过预算，令 lo = mid；否则令 hi = mid−1。
  4. 当 lo = hi，返回 lo。

示例 2 的搜索轨迹

初始范围 [1,5]。候选 3 的最小数组是 [2,3,2,1,1,1]，总和 10，可行，范围变为 [3,5]。候选 4 的最小数组是 [3,4,3,2,1,1]，总和 14，超预算，范围变为 [3,3]，答案为 3。

正确性证明

  1. 下界必要：由相邻差至多 1，距离 d 的位置至少为 x−d；结合正整数限制，至少为 max(1,x−d)。任何合法数组总和都不小于 S(x)。
  2. 下界可达：逐项取 max(1,x−d) 得到正整数数组，相邻差为 0 或 1，且峰顶为 x。因此 S(x) ≤ maxSum 正好刻画可行性。
  3. 单调性：x 增大时，每项下界均不减，峰顶严格增加，故 S 严格增加。
  4. 搜索不变量：lo 始终可行，最大可行值始终位于 [lo,hi]。可行时舍去 mid 以下，不可行时舍去 mid 及以上。上中位数保证区间严格缩小，最终唯一值即最大可行值。

边界与数值安全

  • n = 1 时没有两侧，答案就是 maxSum。
  • maxSum = n 时所有元素只能为 1。
  • index 位于端点时，一侧 k = 0，公式自然返回 0。
  • 峰形降到 1 后只能保持 1，不能继续降到 0 或负数。
  • 乘积可达到 10¹⁸ 量级。Java 用 long，C++ 用 long long；Python 整数自动扩展；JavaScript 用 BigInt 精确求和，最后答案转 Number。

复杂度

每轮用两个等差求和公式，O(1) 时间；总计 O(log(maxSum − n + 1)) 时间（至少做常数初始化），额外空间 O(1)，按固定范围整数运算计。交互柱状图单独使用 O(n) 展示空间，不属于提交算法。

替代方案

逐个尝试峰值并公式求和需要 O(maxSum − n + 1) 次尝试；每次真实构造数组更会增加 O(n) 成本。也可按两侧是否触底分段，解线性或二次不等式，但需处理端点与取整误差；二分更易实现。

常见错误

  • 左右都包含峰顶却忘记减去一个 x。
  • 把右侧长度写为 n−index，而非 n−index−1。
  • 只算等差部分，漏掉剩余位置的 1。
  • 使用下中位数并令 lo = mid，导致相邻边界时无法推进。
  • Java / C++ 先以 32 位计算乘积，再转换为 64 位，溢出已经发生。

面试追问

相邻差上限改为 d？每个位置的下界变为 max(1,x−d·距离)，求对应等差段；d=0 时所有值相同。

要求返回数组？求出最大峰值后逐项生成最小山形即可，总和允许小于预算，输出成本 O(n)。

为什么不贪心把剩余预算全放峰顶？峰顶增高可能迫使周围一起增高，单点成本不是固定的 1。

Java

class Solution {
    private long side(long x, long k) {
        long t = Math.min(k, x - 1);
        return t * (2 * x - t - 1) / 2 + k - t;
    }

    public int maxValue(int n, int index, int maxSum) {
        long lo = 1, hi = (long) maxSum - n + 1;
        while (lo < hi) {
            long mid = lo + (hi - lo + 1) / 2;
            long sum = mid + side(mid, index)
                          + side(mid, n - index - 1);
            if (sum <= maxSum) lo = mid;
            else hi = mid - 1;
        }
        return (int) lo;
    }
}

JavaScript

/**
 * @param {number} n
 * @param {number} index
 * @param {number} maxSum
 * @return {number}
 */
var maxValue = function(n, index, maxSum) {
    const side = (x, k) => {
        const t = k < x - 1n ? k : x - 1n;
        return t * (2n * x - t - 1n) / 2n + k - t;
    };
    const budget = BigInt(maxSum);
    const left = BigInt(index), right = BigInt(n - index - 1);
    let lo = 1n, hi = budget - BigInt(n) + 1n;
    while (lo < hi) {
        const mid = lo + (hi - lo + 1n) / 2n;
        const sum = mid + side(mid, left) + side(mid, right);
        if (sum <= budget) lo = mid;
        else hi = mid - 1n;
    }
    return Number(lo);
};

            return t * (2 * x - t - 1) // 2 + k - t
