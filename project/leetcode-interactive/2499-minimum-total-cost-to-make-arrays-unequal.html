让数组不相等的
最小总代价

Minimum Total Cost to Make Arrays Unequal

交换上面一行，让每一列的两个数都不同。你能付出最少的下标代价吗？

01 / 题目

给定两个长度同为 n 的整数数组 nums1、nums2，下标从 0 开始。一次操作可以交换 nums1 中任意两个位置 i 与 j 的值，费用是 i + j。

允许执行任意次操作，包括零次。要求最后对每个位置都有 nums1[i] != nums2[i]。返回最小总费用；无解则返回 -1。nums2 始终不变。

“不相等”指每一列都不相等，而不是两个数组只要有一处不同。费用使用下标，不是数值。

约束

  • n == nums1.length == nums2.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ nums1[i], nums2[i] ≤ n

04 / 题解 · 必选位置与补位

核心洞察

把 nums1[i] == nums2[i] 的位置称为“冲突位”。它们一定要参与操作，基础费用至少为这些下标之和。令冲突位数量为 m，其中出现次数最多的值为 v，频次为 f。

不同值的冲突位可以两两交换，同时修复。若 2f > m，值 v 占据超过一半的冲突位，其他冲突位不够与它配对，还需要 d = 2f − m 个外部帮手。

帮手必须同时满足：nums1[i] != nums2[i]、nums1[i] != v、nums2[i] != v。这样与一个值为 v 的冲突位交换，双方才都能变为合法。

完整过程

  1. 第一遍统计所有冲突位的下标和 cost、数量 m、最大频次 f 和对应值 v。
  2. 计算 need = max(0, 2f − m)。如果为 0，基础费用就是答案。
  3. 第二遍从小到大扫描下标。遇到合格帮手就加入费用，并令 need 减一；补满后停止。
  4. 若扫描完仍缺帮手，返回 -1；否则返回费用。

正确性证明

  1. 必选费用下界。每个冲突位上的原值必须移走，故至少参与一次交换。每次费用是参与下标之和，因此所有冲突位的下标和是必要费用。
  2. 帮手数量下界。若 v 有 f 个冲突位，其余 m−f 个冲突位最多提供 m−f 个非 v 值，仍缺 2f−m 个。对于额外选中的原本合法位置，只有上下值均非 v 的位置能增加一个非 v 值且不额外增加一个“禁止 v”的目标位置。任一侧为 v 的合法位置对这个缺口净贡献为零。因此任意可行方案都至少要触及 d 个合格帮手；不足 d 个则无解。
  3. 费用下界可达到。有严格多数时，用 d 个帮手分别与 d 个 v 冲突位交换。剩余 v 冲突位数量恰好等于其他冲突位数量，按不同值配对即可；每个选中下标恰好计费一次。没有严格多数且 m 为偶数时，可将不同值的冲突位两两配对。
  4. 奇数情形。若 m 为奇数且没有严格多数，可以保留三个互异值的冲突位，其余位置按不同值配对。若下标 0 本身是冲突位，可把它保留在这三个位置中，两次以 0 为端点的交换解决三者，重复使用 0 不增费用。若 0 原本合法，则把它作为中转，依次与这三个位置交换一次；选第一个值不同于原 nums1[0]、最后一个值不同于 nums2[0]，三种互异值保证能安排这样的顺序。三处冲突与位置 0 都合法，总费用仍只增加三个下标的和。
  5. 贪心最优。每个合格帮手都只补一个缺口，所需数量固定为 d。选下标最小的 d 个使额外费用最小；从左向右扫描恰好得到这一选择。结合可达到的下界，返回费用为全局最优。

边界与复杂度

  • 没有冲突：返回 0；n = 1 时按约束只能为两个 [1]，返回 −1。
  • 最大频次恰好一半：无需帮手；最大频次并列时任选一个，只有严格多数才需要补位。
  • 冲突数为奇数不等于无解，下标 0 可以免费重复参与。
  • 时间 O(n)，计数数组空间 O(n)；不修改输入。
  • 答案上界不超过 n(n−1)/2 = 4,999,950,000（n = 10⁵），Java 使用 long，C++ 使用 long long。JavaScript Number 在此范围能精确表示整数，Python int 无需额外处理。

替代方案

计数可换成哈希表，空间 O(k)，其中 k 为冲突位的不同数值个数。也可先用多数投票寻找候选值，再一遍确认频次，得到 O(n) 时间、O(1) 额外空间，但遍历次数与证明略多。一般排列搜索或 Dijkstra 只适合极小规模的参考推导，状态数量随排列数增长，不适用于 n = 10⁵。

常见错误

  • 把费用算成交换数值之和，或使用从 1 开始的下标。
  • 只检查帮手原本合法，却忘了上下值都不能等于主导值。
  • 统计整个数组的最大频次；这里统计的是冲突位。
  • 使用 32 位整数存总费用；或认为每个位置只能交换一次。
  • 为求费用而模拟全部交换，平添状态维护和奇数配对难题。

面试追问

为什么不用排序？扫描下标的自然顺序就是费用升序。如果交换费用变为 w[i]+w[j]？下界仍有参考意义，但失去下标 0 的零费用中转后，奇数构造可能需要重复支付最小权重，不能直接套用本公式。如何输出交换操作？额外保存各值的冲突位置与帮手位置，按上述配对及三点中转构造；本题只要求最小费用。

Java

class Solution {
    public long minimumTotalCost(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int[] freq = new int[n + 1];
        int count = 0, maxFreq = 0, dominant = 0;
        long cost = 0;
        for (int i = 0; i < n; i++) {
            if (nums1[i] == nums2[i]) {
                cost += i;
                count++;
                int f = ++freq[nums1[i]];
                if (f > maxFreq) {
                    maxFreq = f;
                    dominant = nums1[i];
                }
            }
        }
        int need = Math.max(0, 2 * maxFreq - count);
        for (int i = 0; i < n && need > 0; i++) {
            if (nums1[i] != nums2[i] &&
                nums1[i] != dominant && nums2[i] != dominant) {
                cost += i;
                need--;
            }
        }
        return need == 0 ? cost : -1;
    }
}

    const n = nums1.length;
    const freq = new Array(n + 1).fill(0);
    let cost = 0, count = 0, maxFreq = 0, dominant = 0;

            count++;
            const f = ++freq[nums1[i]];
            if (f > maxFreq) {
                maxFreq = f;
                dominant = nums1[i];
            }
        }
    }
    let need = Math.max(0, 2 * maxFreq - count);
    for (let i = 0; i < n && need > 0; i++) {
        if (nums1[i] !== nums2[i] &&
            nums1[i] !== dominant && nums2[i] !== dominant) {
            cost += i;
            need--;
        }
    }
    return need === 0 ? cost : -1;
};

Python 3

from typing import List

class Solution:
    def minimumTotalCost(self, nums1: List[int], nums2: List[int]) -> int:
        n = len(nums1)
        freq = [0] * (n + 1)
        cost = count = max_freq = dominant = 0
        for i in range(n):
            if nums1[i] == nums2[i]:
                cost += i
                count += 1
                freq[nums1[i]] += 1
                if freq[nums1[i]] > max_freq:
                    max_freq = freq[nums1[i]]
                    dominant = nums1[i]
        need = max(0, 2 * max_freq - count)
        for i in range(n):
            if need == 0:
                break
            if (nums1[i] != nums2[i] and
                    nums1[i] != dominant and nums2[i] != dominant):
                cost += i
                need -= 1
        return cost if need == 0 else -1

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    long long minimumTotalCost(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size();
        vector<int> freq(n + 1);
        int count = 0, maxFreq = 0, dominant = 0;
        long long cost = 0;
        for (int i = 0; i < n; ++i) {
            if (nums1[i] == nums2[i]) {
                cost += i;
                ++count;
                int f = ++freq[nums1[i]];
                if (f > maxFreq) {
                    maxFreq = f;
                    dominant = nums1[i];
                }
            }
        }
        int need = max(0, 2 * maxFreq - count);
        for (int i = 0; i < n && need > 0; ++i) {
            if (nums1[i] != nums2[i] &&
                nums1[i] != dominant && nums2[i] != dominant) {
                cost += i;
                --need;
            }
        }
        return need == 0 ? cost : -1;
    }
};
