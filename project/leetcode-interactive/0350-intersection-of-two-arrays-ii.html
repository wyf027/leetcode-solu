核心洞察

重复交集不是判断“是否出现”，而是管理“还能匹配几次”。先为较短数组建立频次表，再扫描另一个数组：遇到库存大于 0 的值就加入结果，并把库存减 1。减库存这一步保证同一份元素不会被重复使用。

完整过程

  1. 若 nums1 更长，交换两数组，让频次表来自较短数组，降低额外空间。
  2. 遍历较短数组，用哈希表记录每个值的出现次数。
  3. 遍历较长数组。若当前值的剩余次数大于 0，将它放入答案。
  4. 每次成功匹配后，将对应计数减 1；扫描结束后返回答案，顺序无需固定。

正确性证明

不会放多：每输出一次值 x，频次表中 x 的库存就减 1，而库存初值等于 x 在较短数组中的出现次数。因此输出的 x 不可能超过任一数组中的次数。

不会漏掉：扫描另一个数组时，只要 x 仍有库存就立即输出。于是成功匹配次数恰好达到 min(count1(x), count2(x))。对每个值都成立，所以最终数组正是带重复次数的交集。

边界情况

  • 两数组完全没有共同元素：结果为空数组。
  • 同一个值大量重复：库存减到 0 后不再加入结果。
  • 数组长度为 1：逻辑不需要特殊分支。
  • 两数组相同：结果包含全部元素，顺序可能与扫描数组一致。

复杂度

设两数组长度分别为 m 与 n。时间复杂度为 O(m + n)；额外空间复杂度为 O(min(m, n))，答案数组不计入额外空间。

替代方案

排序后使用双指针：先分别排序，两指针指向当前元素；相等时收集并同时前进，小的一侧前进。若排序成本计入，总时间复杂度为 O(m log m + n log n)，额外空间取决于语言的排序实现。当输入已排序时，它会自然退化为 O(m+n) 扫描，且可不使用哈希表。

面试追问：当一个数组远小于另一个数组时，为小数组建表；若大数组在磁盘上，可按块流式读取并匹配。若两者都已排序，可用双指针顺序读取；若只有较短数组可常驻内存，也可对较长的已排序数组做分段或二分查找，但要谨慎处理重复区间。

常见错误

  • 使用集合而不是频次表，导致重复元素被错误去重。
  • 匹配成功后忘记把计数减 1，导致答案次数超出较短数组。
  • 直接比较结果数组顺序；题目允许任意顺序，测试时应比较多重集合。
  • 为更长数组建表，答案虽正确，却浪费可避免的空间。

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public int[] intersect(int[] nums1, int[] nums2) {
        if (nums1.length > nums2.length) {
            return intersect(nums2, nums1);
        }

        Map<Integer, Integer> counts = new HashMap<>();
        for (int value : nums1) {
            counts.put(value, counts.getOrDefault(value, 0) + 1);
        }

        List<Integer> result = new ArrayList<>();
        for (int value : nums2) {
            int remaining = counts.getOrDefault(value, 0);
            if (remaining > 0) {
                result.add(value);
                counts.put(value, remaining - 1);
            }
        }

        int[] answer = new int[result.size()];
        for (int i = 0; i < result.size(); i++) {
            answer[i] = result.get(i);
        }
        return answer;
    }
}

var intersect = function(nums1, nums2) {
    if (nums1.length > nums2.length) {
        return intersect(nums2, nums1);
    }

    const counts = new Map();
    for (const value of nums1) {
        counts.set(value, (counts.get(value) || 0) + 1);
    }

    const result = [];
    for (const value of nums2) {
        const remaining = counts.get(value) || 0;
        if (remaining > 0) {
            result.push(value);
            counts.set(value, remaining - 1);
        }
    }
    return result;
};
from collections import Counter
from typing import List


class Solution:
    def intersect(self, nums1: List[int], nums2: List[int]) -> List[int]:
        if len(nums1) > len(nums2):
            return self.intersect(nums2, nums1)

        counts = Counter(nums1)
        result: List[int] = []

        for value in nums2:
            if counts[value] > 0:
                result.append(value)
                counts[value] -= 1

        return result
class Solution {
public:
    vector<int> intersect(vector<int>& nums1, vector<int>& nums2) {
        if (nums1.size() > nums2.size()) {
            return intersect(nums2, nums1);
        }

        unordered_map<int, int> counts;
        for (int value : nums1) {
            ++counts[value];
        }

        vector<int> result;
        for (int value : nums2) {
            auto it = counts.find(value);
            if (it != counts.end() && it->second > 0) {
                result.push_back(value);
                --it->second;
            }
        }
        return result;
    }
};
