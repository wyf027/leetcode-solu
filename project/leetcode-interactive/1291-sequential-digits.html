顺次数 Sequential Digits

让数字像沿着刻度尺滑动一样自然生长：后一位永远比前一位大 1。本页先理解规则，再用交互轨道观察候选数如何被生成与筛选。

题目

如果一个整数中，每一位数字都恰好比它前一位的数字大 1，就称它为顺次数。给定两个整数 low 和 high，返回闭区间 [low, high] 内全部顺次数组成的升序列表。

函数形式：sequentialDigits(low, high)，其中 low、high 均为整数，返回整数列表。

约束：10 ≤ low ≤ high ≤ 10⁹

示例 1

输入：low = 100, high = 300
输出：[123,234]

示例 2

输入：low = 1000, high = 13000
输出：[1234,2345,3456,4567,5678,6789,12345]

完整题解

核心洞察

十进制顺次数只能由连续递增的数字构成，而数字不能超过 9。因此所有答案恰好是母串 123456789 的长度至少为 2 的连续子串所表示的整数。候选总数只有 8 + 7 + … + 1 = 36 个。

完整过程

  1. 准备字符串 digits = "123456789"。
  2. 按长度从 2 到 9 枚举窗口；同一长度内按起点从左到右移动。
  3. 把窗口片段转为整数。若它位于 [low, high]，加入结果。
  4. 因为先枚举位数、再枚举起点，候选天然递增，结果无需额外排序。

正确性证明

完备性：任意顺次数的第一位只能是 1 到 8；其余每一位被上一位唯一确定，且不能越过 9，所以它必然对应 123456789 的一个连续子串。算法枚举所有长度至少为 2 的连续子串，因此不会漏掉区间内的顺次数。

可靠性：算法生成的每个候选都来自母串的连续子串，相邻两位必然相差 1；只有满足闭区间条件的候选才会进入结果，因此不会加入非法数字。

有序性：位数更少的正整数一定更小；同一位数下，窗口起点越靠右，首位越大，整个数越大。枚举顺序就是严格升序。

边界情况

  • 区间不含任何顺次数时返回空列表。
  • low 或 high 本身为顺次数时，因为区间闭合，应当包含。
  • 最大候选是 123456789；约束允许 high = 10⁹，但不会产生含 0 或超过 9 的延伸候选。
  • 最短合法数是两位数，例如 12；约束中的 low ≥ 10 与此一致。

复杂度

最多生成 36 个候选，每个候选至多 9 位；在本题十进制约束下，时间和额外空间都可视为 O(1)。若把最大位数记为 D，生成成本为 O(D²)，结果列表占 O(K)。

替代方案

也可以从每个起始数字 1 到 8 出发，不断执行 num = num × 10 + nextDigit，直到下一位超过 9。它避免字符串转换，同样只生成合法候选，但生成顺序不是全局升序，通常需要最后排序。还可以预先写死全部 36 个候选后二分筛选，适合大量查询，但可读性和泛化性较弱。

面试追问

  • 如果有很多组区间查询，如何预计算并用两次二分将每次查询降到 O(log 36 + K)？
  • 如果规则改成相邻数字递增 d，母串方法还能否直接使用？
  • 为什么按“长度、起点”的顺序无需排序，而按“起点、持续追加”的顺序需要排序？

常见错误

  • 把区间写成开区间，漏掉恰好等于 low 或 high 的答案。
  • 从长度 1 开始，错误地把单个数字视为本题需要的候选。
  • 尝试从 9 继续追加 10，忽略每一位必须是单个十进制数字。
  • 改变枚举顺序后仍假设结果天然有序。

四种语言完整代码

class Solution {
    public List<Integer> sequentialDigits(int low, int high) {
        List<Integer> answer = new ArrayList<>();
        String digits = "123456789";

        for (int length = 2; length <= 9; length++) {
            for (int start = 0; start + length <= 9; start++) {
                int value = Integer.parseInt(
                    digits.substring(start, start + length)
                );
                if (value >= low && value <= high) {
                    answer.add(value);
                }
            }
        }
        return answer;
    }
}

class Solution:
    def sequentialDigits(self, low: int, high: int) -> List[int]:
        answer = []
        digits = "123456789"

        for length in range(2, 10):
            for start in range(10 - length):

class Solution {
public:
    vector<int> sequentialDigits(int low, int high) {
        vector<int> answer;
        const string digits = "123456789";

        for (int length = 2; length <= 9; ++length) {
            for (int start = 0; start + length <= 9; ++start) {
                int value = stoi(digits.substr(start, length));
                if (value >= low && value <= high) {
