摧毁一系列目标

Destroy Sequential Targets

一个起点，一种固定步长。怎样让机器命中尽可能多的目标？

先理解规则并试射，再按需展开底部题解。

01 / 任务说明

给定从下标 0 开始的正整数数组 nums，每个元素代表数轴上的一个目标；另有正整数 space。选择数组中的一个值 nums[i] 作为机器的起点，它可以摧毁所有位于 nums[i] + c × space 的目标，其中 c 为非负整数。

返回能够摧毁最多目标的起点值；若多个起点达到相同的最大数量，返回其中最小的值。重复数值表示多个目标，需要分别计数。

机器只向起点及其右侧发射，包含 c = 0 的起点位置。答案必须来自 nums，返回的是值，不是下标或摧毁数量。

官方示例 1

nums = [3,7,8,1,1,5]
space = 2
输出：1

从 1 开始可命中 1、3、5、7……，数组中两个 1 都算目标，共摧毁 5 个，只有 8 留下。

官方示例 2

nums = [1,3,5,2,4,6]
space = 2
输出：1

从 1 或 2 开始都能摧毁 3 个目标，无法更多，因此取较小起点 1。

官方示例 3

nums = [6,2,5]
space = 100
输出：2

任意起点都只能命中 1 个目标，选择最小的 2。

约束：1 ≤ nums.length ≤ 10⁵；1 ≤ nums[i] ≤ 10⁹；1 ≤ space ≤ 10⁹。

04 / 独立题解

准备好后，展开思路、证明与四语言实现。

核心洞察：按余数分组

起点为 s 时，位置 x 可被摧毁的充要条件是 x ≥ s 且 x % space = s % space。因此一台机器只能命中同一个余数组。选择这个组的最小值作起点，就能覆盖整组，重复元素也全部计入。

目标转换为：寻找元素数量最多的余数组，在所有这样的组中，选择最小的元素。

完整过程

  1. 第一遍遍历 nums，用哈希表记录每个余数出现的次数。
  2. 第二遍遍历 nums，对于 x，读取它所在组的总数 count[x % space]。
  3. 如果该数量比当前最佳数量大，更新最佳数量和答案；若数量相同，取更小的 x。
  4. 结束后返回答案。无需排序，也不需要逐次生成 s + c × space。

示例 1 的分组：余数 1 → [3,7,1,1,5]，共 5 个；余数 0 → [8]，共 1 个。最大组的最小值是 1。第二遍扫描时答案可能先暂存 3，它只是该组的候选代表；扫描到 1 后才得到能覆盖整组的真正起点。

正确性证明

上界：任意起点 s 只能命中余数与它一致的目标，所以它能摧毁的数量不超过所在组的大小，也不超过所有组的最大大小 M。

可达：任意大小为 M 的组，其最小值 m 对组内每个 x 都满足 x ≥ m 且 (x − m) 被 space 整除。因此存在非负整数 c 使 x = m + c × space，m 能摧毁整组 M 个目标，达到上界。

最小性：第二遍维护“已扫描元素中组大小最高、并列时数值最小”的元素。遍历结束，它就是所有大小为 M 的组内的最小元素，也必然是其所在组的最小值。故返回值既实现最大摧毁数量，又是满足条件的最小起点。

边界与复杂度

  • 重复元素必须逐个计数；只有一个元素时返回自身。
  • space = 1 时所有元素同组，答案为全数组最小值。
  • space 大于数组最大值时，不同数值各自成组；重复值仍可形成多目标组，不能直接返回全局最小值。
  • 平均时间 O(n)，额外空间 O(k)，k 是实际出现的余数数量，k ≤ min(n, space)。哈希表复杂度为平均意义；不按 space 分配大数组。
  • 代码只做取余与计数，数值上界 10⁹、计数上界 10⁵；JavaScript Number 可精确表达这些整数。

替代方案

可以在哈希表里同时保存每组的次数和最小值，然后遍历所有组挑选答案，平均仍是 O(n) 时间、O(k) 空间。也可按“余数、数值”排序后扫描连续组，时间 O(n log n)，能避开哈希表的平均复杂度假设；排序空间取决于语言实现。枚举每个起点并检查所有目标需要 O(n²)，不适合 n = 10⁵。

常见错误

  • 把 nums 去重，漏掉同一位置的多个目标。
  • 只比较余数，不解释起点方向；同组较大的值可能无法覆盖较小的目标。
  • 找到最大组后直接返回首次遇到的元素，忘记组内最小值及组间并列规则。
  • 直接返回全局最小值，忽略“数量最多”优先级。
  • 按 10⁹ 的 space 建数组，或逐个生成发射位置，浪费时间与空间。

面试追问

若需要返回摧毁数量？返回第一遍统计得到的最大频数。若目标带权重？当权重非负时，将计数改为组内权重和，仍从该组最小值开始。若 c 可以为负？任意组内起点都能覆盖整组，题目的最小起点规则仍使答案落在最大组的最小值。若 space 可变并有多次查询？分组依赖 space；可缓存重复步长结果，不同步长通常需重新扫描。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int destroyTargets(int[] nums, int space) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int x : nums) {
            int r = x % space;
            count.put(r, count.getOrDefault(r, 0) + 1);
        }
        int best = 0;
        int answer = Integer.MAX_VALUE;
        for (int x : nums) {
            int size = count.get(x % space);
            if (size > best || (size == best && x < answer)) {
                best = size;
                answer = x;
            }
        }
        return answer;
    }
}

Python3

from collections import Counter
from typing import List

class Solution:
    def destroyTargets(self, nums: List[int], space: int) -> int:
        count = Counter(x % space for x in nums)
        best, answer = 0, float("inf")
        for x in nums:
            size = count[x % space]
            if size > best or (size == best and x < answer):
                best, answer = size, x
        return answer

class Solution {

    int destroyTargets(vector<int>& nums, int space) {
        unordered_map<int, int> count;
        for (int x : nums) ++count[x % space];
        int best = 0, answer = INT_MAX;
        for (int x : nums) {
            int size = count[x % space];
            if (size > best || (size == best && x < answer)) {
                best = size;
                answer = x;
            }
        }
        return answer;
    }
};
