Problem statement

题意与参数

返回值：表示方法的数量

输入一个正整数 n。每一种合法方案都由一个或多个连续、严格为正的整数构成，并且这些整数的总和等于 n。返回不同方案的总数。

consecutiveNumbersSum(n: integer) -> integer

约束

  • 1 <= n <= 109
  • 序列中的每个数都必须大于 0
  • 不同长度或不同起点视为不同方案

Ready for the reasoning?

把观察变成可证明的算法

题解默认收起。建议先用实验室观察几个不同的 n，再展开核对你的规律。

Solution

枚举长度，把连续性变成整除条件

核心洞察

若一段序列的起点是 a、长度是 k，它就是 a, a+1, …, a+k−1。把公共的 a 与固定增量分开：

n = k × a + k(k − 1) / 2

因此固定 k 后，只需令 rest = n − k(k−1)/2，检查 rest 是否能被 k 整除。若能整除，唯一的起点就是 a = rest/k。

完整过程

  1. 从长度 k = 1 开始。
  2. 只有当最小序列 1 + 2 + … + k ≤ n 时，这个长度才可能合法。
  3. 计算 rest = n − k(k−1)/2。
  4. 若 rest % k == 0，答案加一。
  5. 令 k 加一，继续直到最小序列之和超过 n。

正确性证明

  1. 固定长度的充分必要条件。 对任意固定 k，长度为 k 的连续正整数和必为 ka + k(k−1)/2。所以它等于 n，当且仅当 rest 是 k 的正整数倍。
  2. 不会重复。 固定 k 时，方程给出的 a = rest/k 唯一；不同 k 对应不同长度，因此方案互不相同。
  3. 不会遗漏。 任意合法序列的最小起点至少为 1，所以其长度一定满足 k(k+1)/2 ≤ n，必在循环范围内，并会通过整除条件被计数。
  4. 结论。 算法计入且仅计入所有合法方案，因此返回值正确。

边界与复杂度

  • n = 1：只有 [1]，循环仍会执行一次。
  • k = 1：保证单元素序列 [n] 总被计入。
  • 循环上界来自 k(k+1)/2 ≤ n，所以时间复杂度为 O(√n)。
  • 只使用若干变量，额外空间复杂度为 O(1)。
  • 乘法使用 64 位整数，避免扩展约束时发生中间值溢出。

替代方案

奇因子计数：答案也等于 n 的奇因子个数。可以先移除所有因子 2，再对剩余奇数做质因数分解；若奇数部分为 p₁^e₁ · p₂^e₂…，答案就是 (e₁+1)(e₂+1)…。

滑动窗口：维护连续区间也能求解，但最坏接近 O(n)，在 10⁹ 约束下不合适。

面试追问

  • 如果要求输出所有序列，如何在不改变枚举主干的情况下构造结果？
  • 为什么答案恰好等于奇因子的数量？能否建立一一对应？
  • 若 n 扩大到 64 位正整数，循环条件怎样避免乘法溢出？
  • 如果允许起点为 0 或负数，停止条件和答案会发生什么变化？

常见错误

  • 把偏移和误写成 k(k+1)/2；真正从 a 拆出的增量是 0 + 1 + … + (k−1)。
  • 只检查整除，却没有用最小和限制 k，从而把起点为 0 或负数的序列算进去。
  • 从 k = 2 开始，漏掉始终合法的单元素序列 [n]。
  • 使用浮点数判定“是不是整数”，引入不必要的精度风险。
  • 在更大约束下仍用 32 位乘法计算 k(k+1)，导致溢出。
Implementations

四语言完整代码

均遵循同一长度枚举机制
JavaLeetCode 可提交
class Solution {
    public int consecutiveNumbersSum(int n) {
        int answer = 0;

        for (long k = 1; k * (k + 1) / 2 <= n; k++) {
            long rest = n - k * (k - 1) / 2;
            if (rest % k == 0) {
                answer++;
            }
        }

        return answer;
    }
}

class Solution:
    def consecutiveNumbersSum(self, n: int) -> int:
        answer = 0
        k = 1

        while k * (k + 1) // 2 <= n:
            rest = n - k * (k - 1) // 2
            if rest % k == 0:
                answer += 1
            k += 1

        return answer

class Solution {
public:
    int consecutiveNumbersSum(int n) {
        int answer = 0;

        for (long long k = 1;
             k * (k + 1) / 2 <= n;
             ++k) {
            long long rest = n - k * (k - 1) / 2;
            if (rest % k == 0) {
                ++answer;
            }
        }

        return answer;
    }
};
