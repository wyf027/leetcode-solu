网格照明

Grid Illumination — 在最大 10⁹ × 10⁹ 的棋盘上，用稀疏计数追踪行、列与两类对角线的光。

HARD数组哈希表非付费题

题目

在 n × n 网格中，lamps[i] = [row,col] 表示一盏开启的灯；重复位置仍只算一盏。亮灯照亮自身、整行、整列及两条对角线。

依次处理 queries[j]：先判断查询格是否被照亮，记录 1 或 0；然后关闭该格和相邻八格（即以它为中心的 3 × 3 邻域）中的灯。返回全部查询结果。

约束

  • 1 ≤ n ≤ 10⁹
  • 0 ≤ lamps.length, queries.length ≤ 20000
  • 每个位置含两个整数，且 0 ≤ row, col < n

Solution

四本计数账 + 一份亮灯集合

核心洞察

格子 (r,c) 有光，当且仅当行 r、列 c、正斜线 r-c、反斜线 r+c 中至少一条仍有亮灯。四张哈希表记录各条线上的灯数，一份集合记录真实亮灯坐标并消除重复输入。

完整过程

  1. 初始化时，只有新坐标加入集合，才给对应四条线的计数各加一。
  2. 每次查询先检查四个计数是否任一大于零。
  3. 再枚举查询中心和八邻域；若坐标合法且有灯，则从集合删除，并将四个计数各减一。
  4. 按顺序返回答案数组。

正确性证明

不变式：每次查询前，集合恰好包含所有开启的灯，四张表的每个计数恰好等于集合中位于该线上的灯数。

初始化只为去重后的灯增加贡献，故不变式成立。根据照明定义，查询格有光恰好等价于四条所属线路中至少一条计数非零，所以回答正确。随后算法完整枚举 3 × 3 邻域，并对每盏实际存在的灯同时删除集合元素和四项贡献，其他灯不变，故不变式保持。归纳可知全部回答正确。

边界与复杂度

  • 重复灯必须去重；否则熄灭一次后计数会虚高。
  • 邻域坐标须在 [0,n) 内；查询格自身也要检查。
  • 空灯、重复查询、查询格本身有灯均由同一流程处理。
  • 设灯数 L、查询数 Q：时间 O(L + Q)，空间 O(L)。每次查询只额外检查固定 9 格。

替代方案

直接网格需要 O(n²) 空间；逐查询扫描所有灯需 O(LQ)。分别维护行列坐标集合仍要额外支持两类对角线，删除也更复杂。四种线计数是更直接的稀疏表示。

面试追问

  • 为何不能只存布尔值？一条线上可能有多盏灯，关闭一盏后仍可能有光。
  • 如何编码坐标？可用字符串 "r,c"，或用 64 位整数 r*n+c。
  • 关闭半径变为 k 呢？判断仍为 O(1)，删除变为 O(k²)。

常见错误

  • 先熄灯再回答，颠倒处理顺序。
  • 只处理四邻域，漏掉角上的灯，或漏掉查询格自身。
  • 两类对角线键混淆。
  • 对重复灯重复计数。

import java.util.*;
class Solution {
  public int[] gridIllumination(int n, int[][] lamps, int[][] queries) {
    Map<Integer,Integer> row=new HashMap<>(),col=new HashMap<>(),d=new HashMap<>(),a=new HashMap<>();
    Set<Long> on=new HashSet<>();
    for(int[] p:lamps){ long k=(long)p[0]*n+p[1]; if(on.add(k)){
      add(row,p[0],1);add(col,p[1],1);add(d,p[0]-p[1],1);add(a,p[0]+p[1],1);
    }}
    int[] ans=new int[queries.length];
    for(int i=0;i<queries.length;i++){ int r=queries[i][0],c=queries[i][1];
      ans[i]=(row.getOrDefault(r,0)>0||col.getOrDefault(c,0)>0||
        d.getOrDefault(r-c,0)>0||a.getOrDefault(r+c,0)>0)?1:0;
      for(int dr=-1;dr<=1;dr++)for(int dc=-1;dc<=1;dc++){int x=r+dr,y=c+dc;
        if(x<0||x>=n||y<0||y>=n)continue;
        if(on.remove((long)x*n+y)){add(row,x,-1);add(col,y,-1);add(d,x-y,-1);add(a,x+y,-1);}
      }
    } return ans;
  }
  private void add(Map<Integer,Integer> m,int k,int v){m.put(k,m.getOrDefault(k,0)+v);}
}
var gridIllumination = function(n, lamps, queries) {
  const row=new Map(),col=new Map(),d=new Map(),a=new Map(),on=new Set();
  const add=(m,k,v)=>m.set(k,(m.get(k)||0)+v);
  for(const [r,c] of lamps){const k=r+","+c;if(on.has(k))continue;
    on.add(k);add(row,r,1);add(col,c,1);add(d,r-c,1);add(a,r+c,1);
  }
  const ans=[];
  for(const [r,c] of queries){
    ans.push((row.get(r)||col.get(c)||d.get(r-c)||a.get(r+c))?1:0);
    for(let dr=-1;dr<=1;dr++)for(let dc=-1;dc<=1;dc++){
      const x=r+dr,y=c+dc,k=x+","+y;
      if(x<0||x>=n||y<0||y>=n||!on.has(k))continue;
      on.delete(k);add(row,x,-1);add(col,y,-1);add(d,x-y,-1);add(a,x+y,-1);
    }
  } return ans;
};
from typing import List
from collections import Counter
class Solution:
  def gridIllumination(self, n: int, lamps: List[List[int]], queries: List[List[int]]) -> List[int]:
    row, col, d, a, on = Counter(), Counter(), Counter(), Counter(), set()
    for r,c in lamps:
      if (r,c) in on: continue
      on.add((r,c)); row[r]+=1; col[c]+=1; d[r-c]+=1; a[r+c]+=1
    ans=[]
    for r,c in queries:
      ans.append(int(bool(row[r] or col[c] or d[r-c] or a[r+c])))
      for dr in (-1,0,1):
        for dc in (-1,0,1):
          x,y=r+dr,c+dc
          if (x,y) not in on: continue
          on.remove((x,y)); row[x]-=1; col[y]-=1; d[x-y]-=1; a[x+y]-=1
    return ans
