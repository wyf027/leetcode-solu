2129 · 将标题首字母大写

Capitalize the Title

让每个单词，拥有恰当的大小写。

题目说明

给定字符串 title，其中一个或多个非空英文单词由单个空格连接。根据每个单词的长度调整大小写，返回处理后的完整标题：

  • 长度为 1 或 2：所有字母改为小写。
  • 长度至少为 3：首字母改为大写，其余字母改为小写。

参数：title: string　返回值：string。这里的“标题大小写”完全遵循长度规则，无须判断冠词或介词。

约束

  • 1 ≤ title.length ≤ 100。
  • 单词之间恰好一个空格，没有前导或末尾空格。
  • 单词非空，且仅含大写或小写英文字母。

独立题解

先尝试自己的思路，再展开推导与四语言实现。

先统一小写，再修正长词首字母

核心洞察

所有单词的非首字母最终都必须小写。先将整个标题转成小写，再按空格分词；只需对长度大于 2 的词修改第一个字母。各词相互独立，无须字典或语义判断。

完整过程

  1. 将 title 全部转换为小写。
  2. 按单个空格拆成单词序列。
  3. 依次检查词长：不超过 2 时直接保留；否则将首字母转大写，并保留小写后缀。
  4. 按原顺序用一个空格连接，返回新标题。

例如 "AB cDE" → ["ab", "cde"] → ["ab", "Cde"] → "ab Cde"。工作台将小写操作拆到每个词内展示；它与一次性将整串转小写等价，因为空格不受大小写转换影响。

正确性说明

初始小写转换保证每个词的所有字母都是小写。对任意单词：若长度为 1 或 2，保持原状恰好满足短词规则；若长度至少为 3，仅将首字母转为大写，后缀仍为小写，恰好满足长词规则。处理不会改变字母内容、词长和词序。最后按原来的单空格连接，因此每个词与分隔符都满足要求，返回值正确。

边界与复杂度

单个字母必须小写，两个字母同样不能大写首字母；长度为 3 时开始应用长词规则。单词可以全部大写、全部小写或混合大小写。输入保证没有空词、连续空格或非英文字母，提交代码不需要额外修复这些输入。

令 n = title.length。四份分词实现的总时间为 O(n)，分词、转换及结果存储需要 O(n) 空间；这些实现没有宣称原地修改。

替代方案

可以在可变字符数组上扫描单词边界，先将当前词全部小写，发现词尾时再按长度修正首字母。时间仍为 O(n)；若已有可变缓冲区，额外工作空间可为 O(1)。JavaScript、Python 的字符串不可变，创建字符数组本身仍需 O(n) 空间。当前题目长度至多 100，分词写法更直接。

常见错误

  • 直接对每个词首字母大写，遗漏长度 1、2 的例外。
  • 只修改首字母，没有将原来的大写后缀变成小写。
  • 写成长度大于等于 2；正确条件是大于 2。
  • 依赖通用 title-case 函数：它通常会把短词首字母也大写。
  • 逐次拼接不断增长的完整结果，在某些语言中造成平方级复制；优先 join 或字符串流。

面试追问

  • 为什么可先整串小写？大小写转换对空格无影响，且每个词的规则只依赖长度。
  • 再执行一次会改变结果吗？不会；结果已经满足每个词的规则，转换具有幂等性。
  • 若必须保留连续空格？按字符扫描并保留分隔符，避免分词后规范化空白。
  • 若支持 Unicode？必须另行定义“长度”、字素边界和语言相关大小写规则，ASCII 题目的假设不能直接沿用。

Java

import java.util.Locale;

class Solution {
    public String capitalizeTitle(String title) {
        String[] words = title.toLowerCase(Locale.ROOT).split(" ");
        for (int i = 0; i < words.length; i++) {
            String word = words[i];
            if (word.length() > 2) {
                words[i] = Character.toUpperCase(word.charAt(0))
                        + word.substring(1);
            }
        }
        return String.join(" ", words);
    }
}

JavaScript

/**
 * @param {string} title
 * @return {string}
 */
var capitalizeTitle = function(title) {
    return title.toLowerCase().split(' ').map(word =>
        word.length > 2
            ? word[0].toUpperCase() + word.slice(1)
            : word
    ).join(' ');
};

Python 3

class Solution:
    def capitalizeTitle(self, title: str) -> str:
        return " ".join(
            word[0].upper() + word[1:] if len(word) > 2 else word
            for word in title.lower().split(" ")
        )

C++

#include <cctype>
#include <sstream>
#include <string>
using namespace std;

class Solution {
public:
    string capitalizeTitle(string title) {
        for (char& c : title) {
            c = static_cast<char>(tolower(static_cast<unsigned char>(c)));
        }
        istringstream input(title);
        ostringstream output;
        string word;
        bool first = true;
        while (input >> word) {
            if (word.size() > 2) {
                word[0] = static_cast<char>(
                    toupper(static_cast<unsigned char>(word[0])));
            }
            if (!first) output << ' ';
            output << word;
            first = false;
        }
        return output.str();
    }
};
