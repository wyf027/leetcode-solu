842. 将数组拆分成
斐波那契序列

Split Array into Fibonacci Sequence — 在数字字符串中选择起点，然后让“和”决定后续。

MEDIUM字符串回溯非付费题

题目

给定一个仅含数字的字符串 num。请把它切分为一个由非负整数构成的序列，使序列至少包含 3 个数，且从第三项开始，每一项都等于前两项之和。

  • 1每个数必须满足 0 ≤ f[i] < 2³¹，即能放入 32 位有符号整数。
  • 2切出的数字块不能有多余前导零；只有数字 0 本身可以以零开头。
  • 3若存在多种答案，返回任意一种；无解时返回空数组 []。

函数形式

splitIntoFibonacci(num: string): number[]

官方示例

示例 1存在多解
输入：num = "1101111"
输出：[11,0,11,11]
解释：[110,1,111] 也会被接受。
示例 2无解
输入：num = "112358130"
输出：[]
解释：无法完成满足条件的拆分。
示例 3前导零
输入：num = "0123"
输出：[]
解释："01" 不是合法数字块。

约束

1 ≤ num.length ≤ 200
num 只包含数字字符

核心洞察

只猜前两项一旦路径里已有两个数，下一个数就被它们的和唯一确定，不再需要盲目枚举。
字符串比较当前数字小于目标和时只能继续延长；大于目标和时越延长越大，可立即停止本层。
尽早剪枝前导零、超过 2³¹−1、和不匹配，都应在候选生成时排除。

完整过程

  1. 从索引 0 开始，逐位扩展当前数字 value。
  2. 若当前块长度大于 1 且首字符是 '0'，停止扩展；若 value > 2³¹−1，也停止。
  3. 路径不足两项时，候选均可暂时加入；路径已有两项时，令 sum = a + b：候选小于它就继续扩展，大于它就停止，等于才加入。
  4. 递归处理剩余后缀。若恰好用完字符串且路径长度至少为 3，立即返回该答案。
  5. 若递归失败，弹出候选，恢复现场并尝试更长或其他切分。

正确性说明

合法性：算法只加入不带多余前导零、位于 32 位整数范围内的数字；从第三项起只在候选等于前两项之和时加入。因此返回路径满足全部条件。

完备性：对前两项的每一种合法切分，回溯都会枚举到。一旦前两项固定，之后每一项唯一等于前两项之和；算法会精确匹配这个十进制表示。任何存在的合法答案都不会被合法剪枝跳过。

终止性：每次递归都至少消费一个字符，字符串有限；每层循环也向右推进，因此搜索必然结束。

边界与复杂度

  • "0000" 可以拆成 [0,0,0,0]，但 "01" 不能把 01 当作整数。
  • 路径必须至少有 3 项；只切成两个数不算答案。
  • 输入可很长，但任何候选超过 2147483647 就无需继续扩展。
  • 计算前两项之和时使用更宽的数值类型，避免相加溢出。
时间：O(n²)
空间：O(n)

解释：前两个数字的结束位置构成 O(n²) 种选择；后续项由和唯一决定。回溯路径与递归深度最多 O(n)。

替代方案

也可以用两层循环显式枚举前两个数，然后用字符串前缀匹配不断验证后续的和。这与回溯本质相同，状态更少，但四种语言中统一写成回溯更容易表达“选择—递归—撤销”。不建议使用动态规划：后续值依赖前两个具体整数，状态空间并不会因此变小。

四语言完整代码

Java
class Solution {
    public List<Integer> splitIntoFibonacci(String num) {
        List<Integer> path = new ArrayList<>();
        backtrack(num, 0, path);
        return path;
    }

    private boolean backtrack(String s, int start, List<Integer> path) {
        if (start == s.length()) return path.size() >= 3;

        long value = 0;
        for (int end = start; end < s.length(); end++) {
            if (end > start && s.charAt(start) == '0') break;
            value = value * 10 + (s.charAt(end) - '0');
            if (value > Integer.MAX_VALUE) break;

            int size = path.size();
            if (size >= 2) {
                long expected = (long) path.get(size - 2) + path.get(size - 1);
                if (value < expected) continue;
                if (value > expected) break;
            }

            path.add((int) value);
            if (backtrack(s, end + 1, path)) return true;
            path.remove(path.size() - 1);
        }
        return false;
    }
}
JavaScript
/**
 * @param {string} num
 * @return {number[]}
 */
var splitIntoFibonacci = function(num) {
    const path = [];

    function backtrack(start) {
        if (start === num.length) return path.length >= 3;

        let value = 0;
        for (let end = start; end < num.length; end++) {
            if (end > start && num[start] === "0") break;
            value = value * 10 + Number(num[end]);
            if (value > 2147483647) break;

            const size = path.length;
            if (size >= 2) {
                const expected = path[size - 2] + path[size - 1];
                if (value < expected) continue;
                if (value > expected) break;
            }

            path.push(value);
            if (backtrack(end + 1)) return true;
            path.pop();
        }
        return false;
    }

    backtrack(0);
    return path;
};

    vector<int> splitIntoFibonacci(string num) {

private:
    bool backtrack(const string& s, int start, vector<int>& path) {
        if (start == (int)s.size()) return path.size() >= 3;

        long long value = 0;
        for (int end = start; end < (int)s.size(); ++end) {
            if (end > start && s[start] == '0') break;
            value = value * 10 + (s[end] - '0');
            if (value > INT_MAX) break;

            int size = path.size();

                long long expected = (long long)path[size - 2] + path[size - 1];
                if (value < expected) continue;
                if (value > expected) break;
            }

            path.push_back((int)value);
            if (backtrack(s, end + 1, path)) return true;
            path.pop_back();
        }
        return false;
    }
};

面试追问与常见错误

为什么候选大于目标和时能 break？

继续向右扩展只会在十进制末尾追加数字，数值不会变小，所以不可能重新等于目标和。

为什么不是指数复杂度？

只有前两项有自由切分；第三项开始由前两项之和唯一确定，匹配失败即剪枝。

常见错误：整数溢出

构造候选以及计算两数之和时先用 long/long long；通过范围检查后再转为 32 位整数。

常见错误：成功条件过宽

消费完字符串还不够，必须同时检查路径长度至少为 3，否则两个数字也会被误判为答案。
