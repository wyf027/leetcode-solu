上升下降字符串

把 26 个字母想成一排高低不同的积木：从左到右各拿一块，再从右到左各拿一块，往复直到清空。

简单 EASY字符串哈希表计数非付费题

Problem

题目描述

给定只含小写英文字母的字符串 s，按下面的顺序重新排列其中的全部字符，并返回结果字符串：

  1. 从剩余字符中拿走最小字符，放到结果末尾。
  2. 继续拿走“比刚才字符大”的最小字符；不断重复，直到无法继续变大。
  3. 再从剩余字符中拿走最大字符。
  4. 继续拿走“比刚才字符小”的最大字符；不断重复，直到无法继续变小。
  5. 重复以上上升、下降两趟，直到所有字符都被取完。

重复字符：当最小或最大字符有多个相同副本时，任选一个即可；每趟扫描对某个字母至多取一个。

官方示例

示例 1
输入s = "aaaabbbbcccc"输出"abccbaabccba"

第一趟上升得到 abc，下降得到 cba；剩余 aabbcc 后再重复一次。

示例 2
输入s = "rat"输出"art"

上升扫描依次取走 a → r → t，字符已清空，无需下降。

函数形式

sortString(s: string) → string

字符串长度1 ≤ s.length ≤ 500
字符范围'a' 到 'z'仅含小写英文字母

Spoiler Gate

先形成自己的思路，再查看题解

提示：字符种类只有 26 个。想一想，是否真的需要不断在字符串里搜索最小值与最大值？

Solution

计数数组 + 双向扫描

核心洞察

1

顺序固定。每一趟上升都按 a…z，下降都按 z…a。

2

只需库存。count[i] 记录第 i 个字母还剩多少个。

3

一次取一个。扫描到库存大于 0 的字母就追加一次，并将频次减 1。

完整过程

  1. 统计 s 中 26 个小写字母的出现次数。
  2. 当结果长度仍小于 s.length 时，从下标 0 扫到 25；遇到正频次就追加对应字符并减 1。
  3. 紧接着从下标 25 扫回 0，执行相同的“存在则取一个”操作。
  4. 所有频次归零时，结果恰好包含原字符串的全部字符。

正确性证明

  1. 上升趟合法：下标按 0 到 25 访问，因此每个被追加的字符都严格大于本趟前一个字符；跳过零频次后，它也是当前可选的最小合法字符。
  2. 下降趟合法：下标按 25 到 0 访问，同理，每个被追加的字符都是当前可选的最大合法字符，且严格小于本趟前一个字符。
  3. 字符守恒：仅当频次为正时才追加，并同时将其减 1，所以不会多取；每个输入字符最终都对应一次减 1，所以不会漏取。
  4. 终止：每一轮至少会取走一个剩余字符，剩余总数严格下降且有限，最终结果长度等于输入长度。由前三点可知，返回结果正是题目规定的重排。

复杂度

时间复杂度O(n + 26n)简化为 O(n)。计数 O(n)，每轮固定扫描 52 个位置。
空间复杂度O(26)除返回字符串外为 O(1) 常量额外空间。

边界情况

  • 单字符：第一次上升扫描就取完。
  • 全相同：每个上升趟和下降趟各最多取一个，仍会持续减少库存。
  • 已经升序或降序：输入的原顺序无关紧要，只看频次。
  • 字母有空档：频次为 0 的位置直接跳过，不影响“最小合法字符”的定义。

四语言完整代码

class Solution {
    public String sortString(String s) {
        int[] count = new int[26];
        for (char ch : s.toCharArray()) {
            count[ch - 'a']++;
        }

        StringBuilder answer = new StringBuilder(s.length());
        while (answer.length() < s.length()) {
            for (int i = 0; i < 26; i++) {
                if (count[i] > 0) {
                    answer.append((char) ('a' + i));
                    count[i]--;
                }
            }
            for (int i = 25; i >= 0; i--) {
                if (count[i] > 0) {
                    answer.append((char) ('a' + i));
                    count[i]--;
                }
            }
        }
        return answer.toString();
    }
}

class Solution:
    def sortString(self, s: str) -> str:
        count = [0] * 26
        for ch in s:
            count[ord(ch) - ord('a')] += 1

        answer = []
        while len(answer) < len(s):
            for i in range(26):
                if count[i] > 0:
                    answer.append(chr(ord('a') + i))
                    count[i] -= 1

            for i in range(25, -1, -1):
                if count[i] > 0:
                    answer.append(chr(ord('a') + i))
                    count[i] -= 1

        return ''.join(answer)

替代方案

方案做法复杂度与取舍
计数数组（推荐）26 个槽位双向扫描O(n)，结构最贴合题意，常量极小
有序映射 / TreeMap维护字符到频次，正序与逆序遍历键O(n log 26)，更通用但代码更重
排序后模拟先排序，再维护未使用位置至少 O(n log n)，删除或标记的实现也更复杂

面试追问

如果字符集不是 26 个小写字母怎么办？

用有序映射统计频次，升序遍历键后再逆序遍历；若字符集有限但较大，也可使用按码点排序后的键数组。

为什么总扫描次数不会导致 O(n²)？

每轮扫描固定 52 个槽位，轮数最多为最大字符频次且不超过 n，所以是 O(52n)，渐进意义上仍为 O(n)。

能否一次排序后直接拼出答案？

可以借助排序后的分组频次来模拟，但本质仍需按轮从每组各取一个；计数数组省去了 O(n log n) 的排序。

常见错误

  • 一趟内把某个字母的全部副本都追加了；正确行为是每个方向、每个字母至多取一个。
  • 上升扫描结束后忘记立刻下降，或者下一轮没有重新从 a 开始。
  • 用“频次是否全零”反复求和作为循环条件；直接比较结果长度更简单。
  • 下降循环写成无符号下标，减到 0 后发生下溢。
