Problem

题目说明

非付费题

给定一个含 n 个节点（编号为 0 ... n-1）的无向加权图。edges[i] = [a, b] 表示节点 a 与 b 相连，通过这条边的成功概率是 succProb[i]。请返回从 start_node 到 end_node 的一条路径所能取得的最大成功概率；路径概率等于沿途各边概率的乘积。若不可达，返回 0。

函数形式

maxProbability(
  n,
  edges,
  succProb,
  start_node,
  end_node
) -> double

约束

  • 2 ≤ n ≤ 10⁴
  • 0 ≤ start_node, end_node < n，且二者不同
  • 0 ≤ edges.length = succProb.length ≤ 2×10⁴
  • 每条边端点合法且不同；任意两点间最多一条边
  • 0 ≤ succProb[i] ≤ 1

官方示例

输入：
n = 3
edges = [[0,1],[1,2],[0,2]]
succProb = [0.5,0.5,0.2]

输出：0.25000

路线 0→1→2 的概率为 0.5×0.5=0.25，高于直达的 0.2。

Max-product Dijkstra

最大乘积版 Dijkstra

推荐方案

核心洞察

普通 Dijkstra 每次固定“距离最小”的节点；这里将评价指标换成路径概率乘积，每次固定“概率最大”的节点。由于每条边概率都在 [0,1]，路径继续延伸只会让乘积不增，所以当一个节点以当前全局最大概率出队时，它的最优值已经无法被后来更长的路径超过。

状态定义

best[v] 表示从起点到 v 已知的最大成功概率。初始 best[start_node]=1，其余为 0。最大堆保存 (概率, 节点)。

完整过程

  1. 按 edges 与 succProb 建立双向邻接表。
  2. 把起点以概率 1 放入最大堆。
  3. 取出堆顶 (prob, u)。若它比 best[u] 小，说明是过期条目，跳过。
  4. 若 u == end_node，直接返回 prob；这是全局可取得的最大值。
  5. 遍历邻边 u→v，候选概率为 prob × edgeProb。若更大，则更新 best[v] 并入堆。
  6. 堆耗尽仍没到终点，则终点不可达，返回 0。

正确性说明

引理：当节点 u 以堆中最大概率 p 被有效取出时，p 就是从起点到 u 的最大可能概率。

理由：假设存在更优路径。沿那条路径找到第一个尚未固定的节点，它前面的节点已经处理过，并会把对应候选概率加入堆。由于后续边概率不超过 1，这个候选值不会小于完整路径到 u 的概率，应优先于 p 出堆，产生矛盾。

结论：终点首次有效出堆时，其概率最优；若永不出堆，则不存在正概率可达路径，返回 0 正确。

复杂度

时间
O((n + m) log n)

每次有效改善产生一次堆操作，m = edges.length。

空间
O(n + m)

邻接表、最优概率数组与优先队列。

边界情况

  • 图不连通：堆耗尽后返回 0。
  • 概率为 0 的边：不会改善初值 0，可自然忽略。
  • 存在多条到同一节点的候选：允许堆中有旧条目，出堆时用 prob < best[u] 丢弃。
  • 概率为 1 的环：严格大于才更新，不会无限入堆。
  • 浮点比较：题目容许 1e-5 误差；本算法不需要自行四舍五入。

替代方案

  • Bellman-Ford 式松弛：可做，但最坏约 O(nm)，规模下不理想。
  • 对数变换：把边权转为 -log(p)，乘积最大变为和最小；但要单独处理 p=0，也引入额外浮点运算。
  • SPFA：缺少可靠最坏复杂度保证，不推荐用于面试主解。

常见错误

① 使用最小堆却没有对概率取负或反转比较。

② 把路径概率写成边概率之和。

③ 看到终点被“加入堆”就提前返回；应在终点有效出堆时返回。

④ 忘记图是无向图，只添加了一个方向。

import java.util.*;

class Solution {
    public double maxProbability(int n, int[][] edges, double[] succProb,
                                 int start_node, int end_node) {
        List<double[]>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();

        for (int i = 0; i < edges.length; i++) {
            int a = edges[i][0], b = edges[i][1];
            graph[a].add(new double[]{b, succProb[i]});
            graph[b].add(new double[]{a, succProb[i]});
        }

        double[] best = new double[n];
        best[start_node] = 1.0;
        PriorityQueue<double[]> heap = new PriorityQueue<>(
            (x, y) -> Double.compare(y[0], x[0])
        );
        heap.offer(new double[]{1.0, start_node});

        while (!heap.isEmpty()) {
            double[] top = heap.poll();
            double probability = top[0];
            int node = (int) top[1];
            if (probability < best[node]) continue;
            if (node == end_node) return probability;

            for (double[] next : graph[node]) {
                int neighbor = (int) next[0];
                double candidate = probability * next[1];
                if (candidate > best[neighbor]) {
                    best[neighbor] = candidate;
                    heap.offer(new double[]{candidate, neighbor});
                }
            }
        }
        return 0.0;
    }
}
/**
 * @param {number} n
 * @param {number[][]} edges
 * @param {number[]} succProb
 * @param {number} start_node
 * @param {number} end_node
 * @return {number}
 */
var maxProbability = function(n, edges, succProb, start_node, end_node) {
    const graph = Array.from({ length: n }, () => []);
    for (let i = 0; i < edges.length; i++) {
        const [a, b] = edges[i];
        graph[a].push([b, succProb[i]]);
        graph[b].push([a, succProb[i]]);
    }

    const best = new Array(n).fill(0);
    best[start_node] = 1;

    // Binary max-heap storing [probability, node].
    const heap = [];
    const push = (item) => {
        heap.push(item);
        let i = heap.length - 1;
        while (i > 0) {
            const parent = (i - 1) >> 1;
            if (heap[parent][0] >= heap[i][0]) break;
            [heap[parent], heap[i]] = [heap[i], heap[parent]];
            i = parent;
        }
    };
    const pop = () => {
        const top = heap[0];
        const last = heap.pop();
        if (heap.length) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let largest = i;
                const left = i * 2 + 1, right = left + 1;
                if (left < heap.length && heap[left][0] > heap[largest][0]) largest = left;
                if (right < heap.length && heap[right][0] > heap[largest][0]) largest = right;
                if (largest === i) break;
                [heap[i], heap[largest]] = [heap[largest], heap[i]];
                i = largest;
            }
        }
        return top;
    };

    push([1, start_node]);
    while (heap.length) {
        const [probability, node] = pop();
        if (probability < best[node]) continue;
        if (node === end_node) return probability;

        for (const [neighbor, edgeProbability] of graph[node]) {
            const candidate = probability * edgeProbability;
            if (candidate > best[neighbor]) {
                best[neighbor] = candidate;
                push([candidate, neighbor]);
            }
        }
    }
    return 0;
};
from typing import List
import heapq

class Solution:
    def maxProbability(
        self,
        n: int,
        edges: List[List[int]],
        succProb: List[float],
        start_node: int,
        end_node: int
    ) -> float:
        graph = [[] for _ in range(n)]
        for (a, b), probability in zip(edges, succProb):
            graph[a].append((b, probability))
            graph[b].append((a, probability))

        best = [0.0] * n
        best[start_node] = 1.0
        heap = [(-1.0, start_node)]

        while heap:
            negative_probability, node = heapq.heappop(heap)
            probability = -negative_probability
            if probability < best[node]:
                continue
            if node == end_node:
                return probability

            for neighbor, edge_probability in graph[node]:
                candidate = probability * edge_probability
                if candidate > best[neighbor]:
                    best[neighbor] = candidate
                    heapq.heappush(heap, (-candidate, neighbor))

        return 0.0

public:
    double maxProbability(int n, vector<vector<int>>& edges,

        for (int i = 0; i < static_cast<int>(edges.size()); ++i) {
            int a = edges[i][0], b = edges[i][1];
            graph[a].push_back({b, succProb[i]});
            graph[b].push_back({a, succProb[i]});
        }

        vector<double> best(n, 0.0);
        best[start_node] = 1.0;
        priority_queue<pair<double, int>> heap;
        heap.push({1.0, start_node});

        while (!heap.empty()) {
            auto [probability, node] = heap.top();
            heap.pop();
            if (probability < best[node]) continue;

                if (candidate > best[neighbor]) {

                    heap.push({candidate, neighbor});
                }
            }
        }
        return 0.0;

面试追问

为什么可以在终点出堆时提前结束？
因为它是候选中概率最大的节点，而所有后续边概率不超过 1。任何尚未展开的路径继续延伸后都不可能超过当前概率。
若边概率可能大于 1，还成立吗？
不一定。乘积可能沿路径增长，贪心固定节点的依据会失效；若还存在增益环，最优值甚至可能无界，需要重新定义问题与算法。
为什么不用 visited 数组？
可以使用，但“过期条目判断”已足够：若出堆值小于当前 best，就跳过。一个节点首次以有效最大值出堆时已被隐式固定。
如何同时返回最优路径？
每次改善 best[v] 时记录 parent[v]=u；终点出堆后从终点沿 parent 回溯，再反转即可。
