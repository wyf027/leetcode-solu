Maximum Number of Ones

矩阵中 1 的最大数量

把局部窗口的限制，变成一张可以反复平铺的“小模板”。先亲手观察规律，再决定是否展开完整题解。

Problem

题意

函数：maximumNumberOfOnes

给定一个由 0 和 1 组成、宽为 width、高为 height 的矩阵。每个连续的 sideLength × sideLength 正方形子矩阵内，最多只能出现 maxOnes 个 1。求整个矩阵最多能放多少个 1。

示例 1

width = 3, height = 3, sideLength = 2, maxOnes = 1

输出：4

101 000 101

任意 2 × 2 子矩阵都至多含 1 个 1。

示例 2

width = 3, height = 3, sideLength = 2, maxOnes = 2

输出：6

101 101 101

任意 2 × 2 子矩阵都至多含 2 个 1。

约束

  • 1 ≤ width, height ≤ 100
  • 1 ≤ sideLength ≤ width, height
  • 0 ≤ maxOnes ≤ sideLength²

Full Solution

完整题解

核心洞察：把无限重叠的窗口折叠成模板

用一个 sideLength × sideLength 模板表示坐标的余数类。矩阵位置 (r, c) 对应模板位置 (r % sideLength, c % sideLength)。任何连续的同尺寸正方形窗口，恰好包含每种余数位置各一次，因此模板最多选 maxOnes 个位置。

同一个模板位置会在完整矩阵中重复出现多次。应当贪心选择重复次数最大的 maxOnes 个位置。

freq(r,c) = ⌈(height-r) / sideLength⌉ × ⌈(width-c) / sideLength⌉

完整过程

  1. 枚举模板里的每个位置 (r, c)，其中 0 ≤ r,c < sideLength。
  2. 计算该行余数在高度方向出现的次数，以及该列余数在宽度方向出现的次数；两者相乘得到总频次。
  3. 将全部 sideLength² 个频次降序排序。
  4. 累加最大的 maxOnes 项，得到最大 1 的数量。

正确性说明

可行性

选定模板中的至多 maxOnes 个余数位置，并把矩阵里属于这些余数类的格子都设为 1。每个连续 sideLength × sideLength 窗口对每个余数类恰好取到一个格子，所以窗口内恰有不超过 maxOnes 个 1，构造合法。

最优性

局部限制允许模板贡献至多 maxOnes 个位置。模板位置 (r,c) 被选择后，对全局答案的贡献就是它的出现频次 freq(r,c)。在固定选择数量下，若方案选择了较小频次却漏掉较大频次，交换二者不会破坏窗口限制，并会让答案不减。因此最优方案必可取频次最大的 maxOnes 个位置；算法返回的和达到上界。

边界情况

  • maxOnes = 0：不选任何模板位置，答案为 0。
  • sideLength = 1：唯一模板位置若可选，就会覆盖整个矩阵。
  • maxOnes = sideLength²：模板位置全选，整个矩阵都能填 1。
  • 宽或高不能整除 sideLength：靠近模板左上角的余数位置通常重复更多，正是频次公式要处理的部分。

复杂度

令 k = sideLength²。构造频次数组需要 O(k)，排序需要 O(k log k)，额外空间为 O(k)。

替代方案

可以维护大小为 maxOnes 的最小堆，在枚举频次时保留最大的若干项，时间为 O(k log maxOnes)，空间为 O(maxOnes)。约束只有 100，直接排序更短、更不易错。也可按完整块、右边条、下边条和右下角分类推导闭式贪心，但分支多、可读性较弱。

面试追问

  • 如果不能使用排序，如何用最小堆或频次分组得到前 maxOnes 大？
  • 为什么任意滑动窗口而不只是对齐模板的窗口，都恰好覆盖每种余数类一次？
  • 若限制改成长方形 a × b 窗口，余数模板和频次公式如何变化？
  • 如果每个模板位置有不同放置收益，选择策略是否仍然成立？

常见错误

  • 只检查不重叠的分块，忽略题目限制的是所有连续滑动窗口。
  • 把 width 与行数、height 与列数混淆，导致边缘频次计算颠倒。
  • 统一使用 ceil(width / sideLength) × ceil(height / sideLength)，忽略尾部不足一个周期。
  • 排序后误取最小的 maxOnes 项，或遗漏 maxOnes = 0。

import java.util.Arrays;

class Solution {
    public int maximumNumberOfOnes(
            int width, int height, int sideLength, int maxOnes) {
        int[] frequency = new int[sideLength * sideLength];
        int index = 0;

        for (int row = 0; row < sideLength; row++) {
            int rowCount = (height + sideLength - 1 - row) / sideLength;
            for (int col = 0; col < sideLength; col++) {
                int colCount = (width + sideLength - 1 - col) / sideLength;
                frequency[index++] = rowCount * colCount;
            }
        }

        Arrays.sort(frequency);
        int answer = 0;
        for (int i = frequency.length - 1;
                i >= frequency.length - maxOnes; i--) {
            answer += frequency[i];
        }
        return answer;
    }
}
/**
 * @param {number} width
 * @param {number} height
 * @param {number} sideLength
 * @param {number} maxOnes
 * @return {number}
 */
var maximumNumberOfOnes = function(width, height, sideLength, maxOnes) {
    const frequency = [];

    for (let row = 0; row < sideLength; row++) {
        const rowCount = Math.floor(
            (height + sideLength - 1 - row) / sideLength
        );
        for (let col = 0; col < sideLength; col++) {
            const colCount = Math.floor(
                (width + sideLength - 1 - col) / sideLength
            );
            frequency.push(rowCount * colCount);
        }
    }

    frequency.sort((a, b) => b - a);
    let answer = 0;
    for (let i = 0; i < maxOnes; i++) answer += frequency[i];
    return answer;
};

            row_count = (height + sideLength - 1 - row) // sideLength
            for col in range(sideLength):

        frequency.sort(reverse=True)

#include <algorithm>
#include <functional>
#include <numeric>
#include <vector>
using namespace std;

class Solution {
public:
    int maximumNumberOfOnes(
        int width, int height, int sideLength, int maxOnes) {
        vector<int> frequency;
        frequency.reserve(sideLength * sideLength);

        for (int row = 0; row < sideLength; ++row) {
            int rowCount = (height + sideLength - 1 - row) / sideLength;
            for (int col = 0; col < sideLength; ++col) {
                int colCount = (width + sideLength - 1 - col) / sideLength;
                frequency.push_back(rowCount * colCount);
            }
        }

        sort(frequency.begin(), frequency.end(), greater<int>());
        return accumulate(frequency.begin(),
                          frequency.begin() + maxOnes, 0);
    }
};
