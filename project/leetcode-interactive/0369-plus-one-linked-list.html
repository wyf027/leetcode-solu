Plus One Linked List

Problem

题目描述

给定一个非空单链表 head。链表按从最高位到最低位的顺序保存一个非负整数，每个节点恰好存放一位十进制数字。请把这个整数加一，并以同样的链表形式返回结果。

函数签名语义

plusOne(head: ListNode) -> ListNode

示例 1

输入

head = [1,2,3]

输出

[1,2,4]

链表表示 123，加一后得到 124。

示例 2

输入

head = [0]

输出

[1]

链表表示 0，加一后得到 1。

约束

  • 链表节点数在 [1, 100] 范围内。
  • 0 <= Node.val <= 9。
  • 除数字 0 本身外，链表表示的整数不含前导零。

Solution

完整题解

核心洞察

真正会被加一的，是从右向左遇到的第一个非 9 数字；它右侧一定全是 9，加一后这些 9 都变成 0。单链表不能反向走，但可以从左向右扫描并持续记录目前最右侧的非 9 节点。

在头部放一个值为 0 的哨兵节点。这样即使原链表全是 9，哨兵也会成为要加一的节点，统一得到类似 0 → 9 → 9 变为 1 → 0 → 0 的流程。

完整过程

  1. 创建 dummy(0)，令 dummy.next = head。
  2. 令 notNine = dummy；从原头节点开始向右扫描。
  3. 每遇到值不等于 9 的节点，就把 notNine 更新为该节点。
  4. 扫描结束后，把 notNine.val 加一。
  5. 把 notNine 后面的所有节点值改为 0。
  6. 若哨兵值变成 1，返回 dummy；否则返回 dummy.next。

正确性证明

引理 1：扫描结束后，notNine 指向哨兵或原链表中最右侧的非 9 节点。

初始时它指向值为 0 的哨兵。扫描每个原节点时，仅在节点值不为 9 时更新，因此最后一次更新必然对应最右侧非 9 节点；若不存在这样的原节点，它仍指向哨兵。

引理 2：notNine 后的所有原链表节点值都是 9。

若其后存在非 9 节点，扫描时 notNine 会被更新到那个更靠右的节点，与“最右侧”矛盾。

定理：算法返回的链表恰好表示原整数加一。

根据引理 2，notNine 右侧是十进制数的末尾连续 9。给整数加一时，这些位全部因进位变成 0，紧邻其左侧的 notNine 增加 1；算法执行的修改完全一致。若原数全为 9，notNine 是哨兵，哨兵从 0 变 1 并作为新最高位返回。因此所有情况均正确。

边界情况

  • 单节点 0：[0] 直接变为 [1]。
  • 末位不是 9：只增加末位，不需要归零其他节点。
  • 末尾连续多个 9：增加它们左侧最近的非 9 位，并把这些 9 全部归零。
  • 所有节点都是 9：哨兵成为新的最高位，链表长度增加 1。

复杂度

设链表长度为 n。一次扫描定位节点，再最多扫描一段后缀进行归零，时间复杂度为 O(n)；除新增的哨兵节点外只使用常数个指针，额外空间复杂度为 O(1)。

四语言完整代码

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode plusOne(ListNode head) {
        ListNode dummy = new ListNode(0, head);
        ListNode notNine = dummy;

        for (ListNode node = head; node != null; node = node.next) {
            if (node.val != 9) {
                notNine = node;
            }
        }

        notNine.val++;
        for (ListNode node = notNine.next; node != null; node = node.next) {
            node.val = 0;
        }

        return dummy.val == 0 ? dummy.next : dummy;
    }
}
/**
 * Definition for singly-linked list.
 * function ListNode(val, next) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.next = (next === undefined ? null : next);
 * }
 *
 * @param {ListNode} head
 * @return {ListNode}
 */
var plusOne = function(head) {
    const dummy = new ListNode(0, head);
    let notNine = dummy;

    for (let node = head; node !== null; node = node.next) {
        if (node.val !== 9) {
            notNine = node;
        }
    }

    notNine.val += 1;
    for (let node = notNine.next; node !== null; node = node.next) {
        node.val = 0;
    }

    return dummy.val === 0 ? dummy.next : dummy;
};

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* plusOne(ListNode* head) {
        ListNode dummy(0, head);
        ListNode* notNine = &dummy;

        for (ListNode* node = head; node != nullptr; node = node->next) {
            if (node->val != 9) {
                notNine = node;
            }
        }

        ++notNine->val;
        for (ListNode* node = notNine->next; node != nullptr; node = node->next) {
            node->val = 0;
        }

        return dummy.val == 0 ? dummy.next : new ListNode(dummy.val, dummy.next);
    }
};

替代方案

  • 反转链表：先反转，像数组一样从最低位处理进位，再反转回来。仍是 O(n) 时间、O(1) 空间，但修改指针较多，出错面更大。
  • 递归：递归到尾节点，回溯时返回进位。代码直观，但需要 O(n) 调用栈，长链表会带来栈空间成本。
  • 栈：把所有节点压栈后从右向左处理。实现简单，但额外空间为 O(n)。

常见错误

  • 只修改最后一个节点，遗漏末尾为 9 时的连续进位。
  • 没有哨兵，导致全 9 情况需要额外且容易遗漏的分支。
  • 把最右非 9 节点之后的节点“减 9”而不是明确置 0。
  • 哨兵没有变为 1 时仍返回哨兵，错误引入前导零。
  • 把链表转成机器整数，可能溢出，也偏离链表处理的考察目标。
