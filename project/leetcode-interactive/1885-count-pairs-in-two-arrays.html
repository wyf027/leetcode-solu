Count Pairs in Two Arrays

MEDIUM付费题双数组 · 下标计数
01 / PROBLEM

两组数组，同一对下标

给定两个长度相同的整数数组 nums1 和 nums2。选出两个不同下标，以 i < j 表示一对；当第一组在这两个位置的元素之和严格大于第二组对应位置之和时，这一对计入答案。返回满足条件的下标对总数。

nums1[i] + nums1[j] > nums2[i] + nums2[j]

同一个下标可出现在不同数对中；相等不计数，不计算 (i, i)，也不重复计算 (j, i)。

参数与返回值

countPairs(nums1: integer[], nums2: integer[]) → long

约束

  • n == nums1.length == nums2.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ nums1[i], nums2[i] ≤ 10⁵

题名、参数、示例输入来自本地官方元数据；因付费题题面为空，题意、示例输出及约束依据公开题目资料简要转述。官方题目。

官方示例

示例 1

nums1 = [2,1,2,1]
nums2 = [1,2,1,2]
输出：1

只有下标对 (0, 2) 满足：4 > 2。

示例 2

nums1 = [1,10,6,2]

有效下标对为 (0,1)、(0,2)、(1,2)、(1,3)、(2,3)；剩余的 (0,3) 不满足。

03 / SOLUTION LAB

把两边的和，压成一个差值

核心洞察

对每个原始下标建立 d[i] = nums1[i] − nums2[i]，原条件等价于 d[i] + d[j] > 0。问题变成：从差值数组中选两个不同元素，有多少组的和为正？

先计算差值，再将差值升序排序。排序只改变元素位置，保留每个原始下标对应的元素实例；每一组无序实例对仍唯一对应一个原始 i < j，因此计数不变。

完整过程

  1. 构建并排序差值数组，令 l = 0、r = n − 1、ans = 0。
  2. 若 d[l] + d[r] > 0，则 d[l..r−1] 中每个元素都能与 d[r] 组成有效数对。一次加入 r − l，随后 r--。
  3. 否则，即使最大的 d[r] 也救不了 d[l]，这个左端点的所有剩余搭配都无效，直接 l++。
  4. 持续到 l ≥ r，返回累计答案。

正确性证明
不变式：每轮开始时，区间 [l,r] 外涉及的数对都已被正确计入或排除，未处理数对恰为区间内部所有不同位置的组合。
若两端之和为正，由单调性，对于任意 l ≤ k < r，有 d[k] ≥ d[l]，所以 d[k] + d[r] > 0。所有包含当前右端点的剩余数对恰好有 r−l 个；一次计入并移除右端点，不遗漏也不重复。
若两端之和不为正，则对任意 l < k ≤ r，有 d[k] ≤ d[r]，所以 d[l] + d[k] ≤ 0。左端点不可能产生有效数对，移除它不会丢失答案。每次区间缩小一格，不变式继续成立；结束时区间不足两个元素，没有未处理数对，累计值即答案。


边界与数值范围
  • n = 1 时循环不进入，答案为 0；差值全为 0 或全非正时也为 0。
  • 重复差值不能去重，因为不同下标代表不同数对。和为 0 时必须走排除分支。
  • 差值范围为 [−99999,99999]，和范围为 [−199998,199998]；计数最大 n(n−1)/2 = 4,999,950,000，超过 32 位有符号整数。
  • Java 用 long，C++ 用 long long；Python 整数自动扩展；JavaScript Number 在本题范围内精确，不要使用位运算截断答案。


复杂度
构造差值 O(n)，排序 O(n log n)，双指针总共移动至多 n−1 次，扫描 O(n)。总时间 O(n log n)，额外空间 O(n)（包含差值副本；排序工作空间依语言实现而定）。四份实现均保留两个输入数组。


替代方案
  • 排序 + 二分：固定每个 i，在右侧寻找第一个严格大于 −d[i] 的位置，累加后缀长度；O(n log n)。注意用 upper bound。
  • 树状数组：按原下标扫描，维护已见差值频次，查询大于 −d[j] 的数量；离散化后 O(n log n)，适合需要保留扫描顺序的扩展。
  • 枚举：逐一判断所有 i < j，O(n²)、额外 O(1)，适合小输入推演，大规模会超时。


常见错误
  • 分别排序 nums1 和 nums2 会打乱对应位置关系；必须先相减。
  • 有效时只加 1、或加 r−l+1，都会错；批量大小是 r−l，不能包含右端点自身。
  • 把严格大于写成大于等于，误收和为零的数对。
  • 用集合消除重复差值、用 32 位变量存答案、JavaScript 忘记数值排序比较器。


面试追问
阈值改为 K？将比较改成 d[l]+d[r] > K，批量计数证明不变。要求输出原始数对？排序时携带原下标，枚举每个有效批次并将原下标按大小排列；输出 k 对本身就需要 Ω(k) 时间，不能只依靠常数时间批量加法。允许修改输入？可将差值写入其中一个数组，省去差值副本，但排序自身仍可能需要工作空间。

Java
import java.util.Arrays;

class Solution {
    public long countPairs(int[] nums1, int[] nums2) {
        int n = nums1.length;
        int[] d = new int[n];
        for (int i = 0; i < n; i++) {
            d[i] = nums1[i] - nums2[i];
        }
        Arrays.sort(d);
        int l = 0, r = n - 1;
        long ans = 0L;
        while (l < r) {
            if (d[l] + d[r] > 0) {
                ans += r - l;
                r--;
            } else {
                l++;
            }
        }
        return ans;
    }
}

from typing import List

class Solution:
    def countPairs(self, nums1: List[int], nums2: List[int]) -> int:
        d = sorted(a - b for a, b in zip(nums1, nums2))
        l, r = 0, len(d) - 1
        ans = 0
        while l < r:
            if d[l] + d[r] > 0:
                ans += r - l
                r -= 1
            else:
                l += 1
        return ans

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    long long countPairs(vector<int>& nums1, vector<int>& nums2) {
        int n = static_cast<int>(nums1.size());
        vector<int> d(n);
        for (int i = 0; i < n; ++i) {
            d[i] = nums1[i] - nums2[i];
        }
        sort(d.begin(), d.end());
        int l = 0, r = n - 1;
        long long ans = 0;
        while (l < r) {
            if (d[l] + d[r] > 0) {
                ans += r - l;
                --r;
            } else {
                ++l;
            }
        }
        return ans;
    }
};
