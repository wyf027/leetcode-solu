01 / 题目规则

大面额优先，是机器的固定规则

机器只保存 20、50、100、200、500 美元的钞票。取款时，从大面额开始，在库存和剩余待取金额允许的范围内优先使用大钞。不能为了凑出金额而撤回已经优先选择的大面额。

例如取 300 美元，库存有 2 张 50、1 张 100、1 张 200，应使用 200 + 100。若取 600 美元，库存只有 3 张 200 和 1 张 500，则必须先选 500，剩余 100 无法满足，所以拒绝；不能改用 3 张 200。

  • ATM()：初始化对象。
  • void deposit(int[] banknotesCount)：将五种面额的张数累加进库存，无返回值。
  • int[] withdraw(int amount)：成功返回按面额升序排列的长度 5 数组；失败返回 [-1]，不能扣除任何钞票。

  4. 再取 600：按规则无法凑齐，返回 [-1]，库存不变。
  5. 取 550：返回 [0,1,0,0,1]，库存成为 [0,0,0,3,0]。

约束

  • banknotesCount.length == 5。
  • 0 ≤ banknotesCount[i] ≤ 10⁹。
  • 1 ≤ amount ≤ 10⁹。
  • deposit 和 withdraw 合计最多调用 5000 次，且两个方法至少各调用一次。
  • 英文官方元数据另列：所有存款中的 banknotesCount[i] 总和不超过 10⁹；中文元数据未列此补充项。

04 / 独立题解

准备好对照自己的思路了吗？

先做选择，成功后统一扣款

核心洞察

这里的贪心是题目要求的执行顺序，不是在所有组合中寻找最优解。记录五种面额库存，从 500 向 20 计算暂取张数；在确认金额恰好凑齐之前，不修改真实库存。

完整过程

  1. 保存 value = [20,50,100,200,500] 和五个库存计数。存款逐项累加。
  2. 取款创建全零 take 数组，令 remaining = amount。
  3. 对 i = 4 ... 0：take[i] = min(stock[i], floor(remaining / value[i]))，再减少 take[i] * value[i] 的剩余金额。
  4. 若最终剩余金额不为 0，立即返回 [-1]；否则遍历扣除 take，返回该数组。

失败场景 [0,1,0,3,1] 取 600：暂取 500 后剩 100；200 面额取 0；100 库存为 0；50 只能取 1 张，剩 50；20 库存为 0。因此拒绝，并保留全部原库存。

正确性说明

循环处理面额之前，已处理的较大面额都按规则取了最大允许张数，且“已暂取金额 + 剩余金额 = 请求金额”。取库存与整除商的较小值，既不超过库存，也不超出剩余金额，并满足当前面额必须尽量多取的规则；更新后不变量继续成立。五种面额全部处理后，余数为零意味着得到合法分配。余数非零意味着固定优先规则无法完成请求，返回失败是正确的，即使存在其他组合也不能改选。真实库存仅在成功分支扣除，故失败不改变状态，成功精确扣除返回的钞票。

边界与数值

  • 空库存、请求小于 20 或无法由现有面额凑齐，都返回 [-1]。
  • 零张存款不改变状态；连续存款是累加，不是替换。
  • 库存总金额足够也可能失败，例如 500 + 3 × 200 无法按规则取 600。
  • Java 使用 long、C++ 使用 long long 保存内部计数；Python 整数无固定宽度。JavaScript 的 Number 在题目整数范围内可精确表示。无需计算可能更大的库存总金额。
  • 输出顺序永远是小面额到大面额，尽管取款遍历顺序相反。

复杂度

设面额数为 k，每次存款 O(k)，取款 O(k)，库存 O(k)，取款暂存 O(k)。本题 k = 5，所以单次时间与额外空间都是 O(1)。

替代方案

可以先复制库存，在副本上扣除，再成功提交副本；同样是 O(k)，但单独的 take 数组即可同时作为候选与返回值。边取边改原库存需要失败回滚，容易遗漏。动态规划或回溯寻找其他组合违反本题固定优先规则；只有题意改为“任意可行组合”时才适用。

面试追问

  • 若改为最少钞票数且允许回退？这是有限库存的组合优化问题，不能沿用这里的规则模拟结论。
  • 真实 ATM 如何处理并发？读取、确认和扣减必须放在受保护的事务或临界区中。
  • 扣款成功但硬件出钞失败怎么办？需要明确设备状态、补偿与幂等事务；本题不涉及硬件异常。

常见错误

  • 认为有 3 张 200 就一定能取 600，忽略 500 优先。
  • 失败之前直接扣库存，导致下一次操作读取错误状态。
  • 忘记库存上限，或用普通除法代替整数除法。
  • 返回面额倒序的数组；把存款张数当作存款金额。

四语言完整实现

均采用官方 ATM 接口，可用于对应语言提交；以下代码未运行验证。

Java

class ATM {
    private final int[] value = {20, 50, 100, 200, 500};
    private final long[] stock = new long[5];

    public ATM() {}

    public void deposit(int[] banknotesCount) {
        for (int i = 0; i < 5; i++) stock[i] += banknotesCount[i];
    }

    public int[] withdraw(int amount) {
        int[] take = new int[5];
        for (int i = 4; i >= 0; i--) {
            take[i] = (int) Math.min(stock[i], amount / value[i]);
            amount -= take[i] * value[i];
        }
        if (amount != 0) return new int[]{-1};
        for (int i = 0; i < 5; i++) stock[i] -= take[i];
        return take;
    }
}

JavaScript

var ATM = function() {
    this.value = [20, 50, 100, 200, 500];
    this.stock = Array(5).fill(0);

ATM.prototype.deposit = function(banknotesCount) {
    for (let i = 0; i < 5; i++) this.stock[i] += banknotesCount[i];
};

ATM.prototype.withdraw = function(amount) {
    const take = Array(5).fill(0);
    for (let i = 4; i >= 0; i--) {
        take[i] = Math.min(this.stock[i], Math.floor(amount / this.value[i]));
        amount -= take[i] * this.value[i];
    }
    if (amount !== 0) return [-1];
    for (let i = 0; i < 5; i++) this.stock[i] -= take[i];
    return take;
};

Python

from typing import List

class ATM:
    def __init__(self):
        self.value = [20, 50, 100, 200, 500]
        self.stock = [0] * 5

    def deposit(self, banknotesCount: List[int]) -> None:
        for i in range(5):
            self.stock[i] += banknotesCount[i]

    def withdraw(self, amount: int) -> List[int]:
        take = [0] * 5
        for i in range(4, -1, -1):
            take[i] = min(self.stock[i], amount // self.value[i])
            amount -= take[i] * self.value[i]
        if amount != 0:
            return [-1]
        for i in range(5):
            self.stock[i] -= take[i]
        return take

C++

#include <algorithm>
#include <array>
#include <vector>
using namespace std;

class ATM {
    const array<int, 5> value{20, 50, 100, 200, 500};
    array<long long, 5> stock{};
public:
    ATM() = default;

    void deposit(vector<int> banknotesCount) {
        for (int i = 0; i < 5; ++i) stock[i] += banknotesCount[i];
    }

    vector<int> withdraw(int amount) {
        vector<int> take(5);
        for (int i = 4; i >= 0; --i) {
            take[i] = static_cast<int>(min(stock[i], 1LL * amount / value[i]));
            amount -= take[i] * value[i];
        }
        if (amount != 0) return {-1};
        for (int i = 0; i < 5; ++i) stock[i] -= take[i];
        return take;
    }
};
