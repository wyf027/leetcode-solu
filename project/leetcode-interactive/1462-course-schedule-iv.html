Problem brief

先理解问题，再寻找路径

课程编号为 0 到 numCourses - 1。每个先修关系 [a, b] 表示修读课程 b 前必须先修 a。

题意转述

先修关系允许传递：若 a 是 b 的先修课、b 是 c 的先修课，那么 a 也算 c 的先修课。对每个查询 [u, v]，判断从课程 u 沿先修方向能否到达课程 v。

按查询原顺序返回布尔数组；第 j 项就是对 queries[j] 的回答。

方向很重要：关系 [a, b] 是从 a 指向 b，不是“b 指向它的前置课”。

函数形式

checkIfPrerequisite(
  numCourses,
  prerequisites,
  queries
) → boolean[]

参数：课程数、先修关系二维数组、查询二维数组；返回与查询等长的布尔列表。

Official examples

示例

示例 1

输入
numCourses = 2
prerequisites = [[1,0]]
queries = [[0,1],[1,0]]
输出[false,true]

1 必须先于 0；因此 0 不是 1 的先修课，反向则成立。

示例 2

输入
numCourses = 2
prerequisites = []
queries = [[1,0],[0,1]]
输出[false,false]

没有任何先修关系，两门课程彼此独立。

示例 3

输入
numCourses = 3
prerequisites = [[1,2],[1,0],[2,0]]
queries = [[1,0],[1,2]]
输出[true,true]

1 可直接到达 2，也可直接或经 2 到达 0。

Constraints

约束

  • 2 <= numCourses <= 100
  • 0 <= prerequisites.length <= numCourses * (numCourses - 1) / 2
  • prerequisites[i].length == 2，且 0 <= aᵢ, bᵢ <= numCourses - 1、aᵢ != bᵢ
  • 每个先修关系对都不同，且先修课程图没有环。
  • 1 <= queries.length <= 10⁴
  • 0 <= uᵢ, vᵢ <= numCourses - 1，且 uᵢ != vᵢ

Complete solution

传递闭包：一次预处理，常数时间查询

核心洞察

把课程看作点，把 [a,b] 看作有向边 a → b。问题等价于批量查询两点之间是否存在路径。课程最多 100 门，适合用布尔矩阵保存任意两点的可达性，再用 Floyd–Warshall 的传递闭包形式补全间接关系。

完整过程

  1. 建立 reachable[n][n]，将每条直接边 a → b 标为真。
  2. 依次枚举中转点 k、起点 i、终点 j。
  3. 若 i 能到 k 且 k 能到 j，则 i 能到 j。
  4. 每个查询 [u,v] 直接读取矩阵。

正确性证明

  1. 初始：矩阵恰好包含所有长度为 1 的直接先修路径。
  2. 归纳：处理 k 后，若路径 i → j 经过 k，则其可拆为 i → k 与 k → j；两段已被先前状态识别，更新会将 i → j 标真。未经过 k 的既有路径仍保留。
  3. 结束：所有课程都作为中转点处理后，矩阵包含且只包含图中存在路径的有序点对，因此每个查询答案正确。

复杂度与边界

时间：O(n³ + q)；空间：O(n²)。

  • 没有先修边时矩阵全为假。
  • 直接边和多级间接路径统一处理。
  • 题目保证 u ≠ v 且图无环，不需要把对角线预设为真。
  • 重复可达路径只会重复写入 true，不影响答案。

替代方案

  • 从每个点 BFS/DFS：O(n(n+m)+q)，稀疏图上直观。
  • 逐查询搜索：O(q(n+m))，查询多时不划算。
  • 拓扑序 + 位集合：沿拓扑序传播祖先集合，常数更小，但实现和语言位集差异更复杂。

面试追问与常见错误

  • 追问：若 n 很大且图稀疏，优先考虑从每个源点搜索或按查询源点分组。
  • 追问：若图可能有环，Floyd 仍能求可达性；但“先修”业务语义需额外处理环。
  • 错误：把 [a,b] 的边方向反过来。
  • 错误：只记录直接边，遗漏传递关系。
  • 错误：循环顺序写成 i、j、k，破坏按中转点归纳的状态语义。

四语言完整代码

Java · LeetCode 可提交Floyd–Warshall
class Solution {
    public List<Boolean> checkIfPrerequisite(
            int numCourses,
            int[][] prerequisites,
            int[][] queries) {
        boolean[][] reachable = new boolean[numCourses][numCourses];

        for (int[] edge : prerequisites) {
            reachable[edge[0]][edge[1]] = true;
        }

        for (int k = 0; k < numCourses; k++) {
            for (int i = 0; i < numCourses; i++) {
                if (!reachable[i][k]) continue;
                for (int j = 0; j < numCourses; j++) {
                    reachable[i][j] = reachable[i][j]
                            || reachable[k][j];
                }
            }
        }

        List<Boolean> answer = new ArrayList<>(queries.length);
        for (int[] query : queries) {
            answer.add(reachable[query[0]][query[1]]);
        }
        return answer;
    }
}

/**
 * @param {number} numCourses
 * @param {number[][]} prerequisites
 * @param {number[][]} queries
 * @return {boolean[]}
 */
var checkIfPrerequisite = function(numCourses, prerequisites, queries) {
    const reachable = Array.from(
        { length: numCourses },
        () => Array(numCourses).fill(false)
    );

    for (const [from, to] of prerequisites) {
        reachable[from][to] = true;
    }

    for (let k = 0; k < numCourses; k++) {
        for (let i = 0; i < numCourses; i++) {
            if (!reachable[i][k]) continue;
            for (let j = 0; j < numCourses; j++) {
                reachable[i][j] = reachable[i][j] || reachable[k][j];
            }
        }
    }

    return queries.map(([from, to]) => reachable[from][to]);
};
Python 3 · LeetCode 可提交Floyd–Warshall
class Solution:
    def checkIfPrerequisite(
        self,
        numCourses: int,
        prerequisites: List[List[int]],
        queries: List[List[int]]
    ) -> List[bool]:
        reachable = [
            [False] * numCourses for _ in range(numCourses)
        ]

        for start, end in prerequisites:
            reachable[start][end] = True

        for middle in range(numCourses):
            for start in range(numCourses):
                if not reachable[start][middle]:
                    continue
                for end in range(numCourses):
                    reachable[start][end] = (
                        reachable[start][end]
                        or reachable[middle][end]
                    )

        return [reachable[start][end] for start, end in queries]
C++ · LeetCode 可提交Floyd–Warshall
class Solution {
public:
    vector<bool> checkIfPrerequisite(
        int numCourses,
        vector<vector<int>>& prerequisites,
        vector<vector<int>>& queries
    ) {
        vector<vector<bool>> reachable(
            numCourses, vector<bool>(numCourses, false)
        );

        for (const auto& edge : prerequisites) {
            reachable[edge[0]][edge[1]] = true;
        }

        for (int k = 0; k < numCourses; ++k) {
            for (int i = 0; i < numCourses; ++i) {
                if (!reachable[i][k]) continue;
                for (int j = 0; j < numCourses; ++j) {
                    reachable[i][j] = reachable[i][j]
                        || reachable[k][j];
                }
            }
        }

        vector<bool> answer;
        answer.reserve(queries.size());
        for (const auto& query : queries) {
            answer.push_back(reachable[query[0]][query[1]]);
        }
        return answer;
    }
};
