1766. 互质树

Tree of Coprimes

困难 非会员题 值域 1…50

在一棵以 0 为根的树中，为每个节点寻找距离最近、且节点值与它互质的祖先。先理解“最近祖先”的判定，再进入遍历实验室观察每一步。

01题目描述

给定一棵由 n 个节点组成的无环连通无向图，节点编号为 0 到 n - 1，根节点是 0。数组 nums 给出每个节点的值，edges[j] = [uj, vj] 表示一条无向边。

如果 gcd(x, y) = 1，则称 x 与 y 互质。节点 i 的祖先是从它到根节点的最短路径上除它自身外的节点。

返回长度为 n 的数组 ans：ans[i] 是与 nums[i] 互质的最近祖先编号；不存在时为 -1。

02官方示例

示例 1

输入
nums = [2,3,3,2]
edges = [[0,1],[1,2],[1,3]]
输出
[-1,0,0,1]

节点 2 跳过值同为 3 的节点 1，选择节点 0；节点 3 与节点 1 互质，因此最近答案是 1。

示例 2

输入
nums = [5,6,10,2,3,6,15]
edges = [[0,1],[0,2],[1,3],[1,4],[2,5],[2,6]]
输出
[-1,0,-1,0,0,0,-1]

nums.length == n
1 ≤ nums[i] ≤ 50
1 ≤ n ≤ 105
edges.length == n - 1
edges[j].length == 2
0 ≤ uj, vj < n
uj != vj
输入保证 edges 构成一棵树

05题解：值域栈 + 深度优先遍历

核心洞察：nums[i] 只在 1 到 50 之间。对每个值维护“当前根到节点路径”上具有该值的节点栈；查询时只需枚举 50 个值，并从互质值的栈顶中选择深度最大的节点。

完整过程

  1. 由无向边构造邻接表，以节点 0 为根。
  2. 进入节点 u 时，枚举值 v = 1..50。若 gcd(nums[u], v) = 1 且值 v 的路径栈非空，就查看栈顶。
  3. 在所有候选栈顶中，选择深度最大者作为 ans[u]；没有候选则保留 -1。
  4. 把 (u, depth) 压入 nums[u] 对应的栈，继续访问子节点。
  5. 离开节点 u 时弹栈，保证状态始终只代表当前祖先链。

为什么只看同值栈顶？

对固定值 v，路径上更浅的同值节点与当前值的互质性完全相同；如果 v 互质，离当前节点最近的一定是该栈的栈顶。因此每个值只保留一次候选比较即可。

实现选择

下面四份代码都使用显式“进入 / 离开”事件栈，避免链状树在 n = 105 时触发语言递归栈溢出。

正确性证明

不变式。处理节点 u 的进入事件之前，stacks[v] 按深度保存且仅保存从根到 u 的路径上、值为 v 的所有严格祖先。
候选完备。任意与 u 互质的祖先值都在 1 到 50 中，因此枚举会覆盖它的值；该值栈顶是具有此值的最近祖先。
最优选择。从所有互质值的栈顶中取深度最大者，等价于在所有互质祖先中取距离 u 最近者。
状态维护。进入时压入 u，离开时恰好弹出 u，对子树成立且不会污染兄弟子树。不变式归纳成立，所以所有 ans[u] 都正确。

复杂度

  • 时间：O(50n) = O(n)
  • 空间：O(n)，包含邻接表、事件栈和值栈

关键边界

  • 根节点没有祖先，答案一定为 -1。
  • 值 1 与所有 1..50 的值互质，包括另一个 1。
  • 兄弟节点不能互为祖先，退出事件必须恢复现场。
  • 链状树深度可达 105。

四语言完整代码

import java.util.*;

class Solution {
    public int[] getCoprimes(int[] nums, int[][] edges) {
        int n = nums.length;
        List<Integer>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : edges) {
            graph[edge[0]].add(edge[1]);
            graph[edge[1]].add(edge[0]);
        }

        int[] ans = new int[n];
        Arrays.fill(ans, -1);
        Deque<int[]>[] active = new ArrayDeque[51];
        for (int value = 1; value <= 50; value++) {
            active[value] = new ArrayDeque<>();
        }

        // event = {node, parent, depth, type}; type 0: enter, 1: exit
        Deque<int[]> events = new ArrayDeque<>();
        events.push(new int[]{0, -1, 0, 0});

        while (!events.isEmpty()) {
            int[] event = events.pop();
            int node = event[0], parent = event[1];
            int depth = event[2], type = event[3];

            if (type == 1) {
                active[nums[node]].pop();
                continue;
            }

            int bestDepth = -1;
            for (int value = 1; value <= 50; value++) {
                if (!active[value].isEmpty() && gcd(nums[node], value) == 1) {
                    int[] candidate = active[value].peek();
                    if (candidate[1] > bestDepth) {
                        bestDepth = candidate[1];
                        ans[node] = candidate[0];
                    }
                }
            }

            active[nums[node]].push(new int[]{node, depth});
            events.push(new int[]{node, parent, depth, 1});
            List<Integer> children = graph[node];
            for (int i = children.size() - 1; i >= 0; i--) {
                int next = children.get(i);
                if (next != parent) {
                    events.push(new int[]{next, node, depth + 1, 0});
                }
            }
        }
        return ans;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }
}

var getCoprimes = function(nums, edges) {
    const n = nums.length;
    const graph = Array.from({ length: n }, () => []);
    for (const [u, v] of edges) {
        graph[u].push(v);
        graph[v].push(u);
    }

    const gcd = (a, b) => {
        while (b !== 0) {
            [a, b] = [b, a % b];
        }
        return a;
    };

    const answer = new Array(n).fill(-1);
    const active = Array.from({ length: 51 }, () => []);
    // event = [node, parent, depth, type]; type 0: enter, 1: exit
    const events = [[0, -1, 0, 0]];

    while (events.length > 0) {
        const [node, parent, depth, type] = events.pop();
        if (type === 1) {
            active[nums[node]].pop();
            continue;
        }

        let bestDepth = -1;
        for (let value = 1; value <= 50; value++) {
            const stack = active[value];
            if (stack.length === 0 || gcd(nums[node], value) !== 1) continue;
            const [candidate, candidateDepth] = stack[stack.length - 1];
            if (candidateDepth > bestDepth) {
                bestDepth = candidateDepth;
                answer[node] = candidate;
            }
        }

        active[nums[node]].push([node, depth]);
        events.push([node, parent, depth, 1]);
        for (let i = graph[node].length - 1; i >= 0; i--) {
            const next = graph[node][i];
            if (next !== parent) events.push([next, node, depth + 1, 0]);
        }
    }
    return answer;
};
from typing import List


class Solution:
    def getCoprimes(self, nums: List[int], edges: List[List[int]]) -> List[int]:
        n = len(nums)
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        answer = [-1] * n
        active = [[] for _ in range(51)]

        def gcd(a: int, b: int) -> int:
            while b:
                a, b = b, a % b
            return a

        # event = (node, parent, depth, type); type 0: enter, 1: exit
        events = [(0, -1, 0, 0)]
        while events:
            node, parent, depth, event_type = events.pop()
            if event_type == 1:
                active[nums[node]].pop()
                continue

            best_depth = -1
            for value in range(1, 51):
                if active[value] and gcd(nums[node], value) == 1:
                    candidate, candidate_depth = active[value][-1]
                    if candidate_depth > best_depth:
                        best_depth = candidate_depth
                        answer[node] = candidate

            active[nums[node]].append((node, depth))
            events.append((node, parent, depth, 1))
            for next_node in reversed(graph[node]):
                if next_node != parent:
                    events.append((next_node, node, depth + 1, 0))

        return answer
class Solution {
public:
    vector<int> getCoprimes(vector<int>& nums, vector<vector<int>>& edges) {
        int n = nums.size();
        vector<vector<int>> graph(n);
        for (const auto& edge : edges) {
            graph[edge[0]].push_back(edge[1]);
            graph[edge[1]].push_back(edge[0]);
        }

        vector<int> answer(n, -1);
        vector<vector<pair<int, int>>> active(51);

        struct Event {
            int node;
            int parent;
            int depth;
            bool exit;
        };
        vector<Event> events = {{0, -1, 0, false}};

        while (!events.empty()) {
            Event event = events.back();
            events.pop_back();
            int node = event.node;

            if (event.exit) {
                active[nums[node]].pop_back();
                continue;
            }

            int bestDepth = -1;
            for (int value = 1; value <= 50; ++value) {
                if (!active[value].empty() && std::gcd(nums[node], value) == 1) {
                    auto [candidate, candidateDepth] = active[value].back();
                    if (candidateDepth > bestDepth) {
                        bestDepth = candidateDepth;
                        answer[node] = candidate;
                    }
                }
            }

            active[nums[node]].push_back({node, event.depth});
            events.push_back({node, event.parent, event.depth, true});
            for (auto it = graph[node].rbegin(); it != graph[node].rend(); ++it) {
                if (*it != event.parent) {
                    events.push_back({*it, node, event.depth + 1, false});
                }
            }
        }
        return answer;
    }
};

面试追问

  • 如果值域变成 109？ 不能再枚举 1..50，可考虑质因数表示、分块或路径查询结构。
  • 如果允许在线修改节点值？ 当前离线 DFS 状态不够，需要树链剖分配合可维护的区间结构等方案。
  • 为什么不能只记录每个值最后出现的一个节点？ 递归回退到兄弟子树时还要恢复此前状态，所以需要栈或显式保存旧值。

常见错误

  • 把当前节点先压栈再查询，错误地把自己当作祖先。
  • 只按节点编号而不是深度选择候选。
  • 遍历完子树后忘记弹栈，导致兄弟节点状态串线。
  • 使用深递归，却没有处理 n = 105 的栈深限制。
