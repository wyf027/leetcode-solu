双端字符匹配

从最左边的下标开始，把 s[i] 与它的镜像位置 s[n - i - 1] 配对。第一个相等的位置就是答案；奇数长度字符串的正中间会与自己重合。

题意

给定只含小写字母的字符串 s。返回最小下标 i，使 s[i] == s[n - i - 1]；所有镜像对都不同则返回 -1。

示例 1
s = "abcacbd"
输出 1：位置 1 和 5 都是 "b"。
示例 2
s = "abc"
输出 1：中间位置映射回自己。
示例 3
s = "abcdab"
输出 -1：没有任何镜像位置字符相等。

约束与取舍

1 ≤ s.length ≤ 100；s 仅包含小写英文字符。

每个下标只需要常数时间比较，不必建立反转字符串。按下标从小到大扫描，第一次相等天然就是最小答案。

输入中的空格以 ␠ 展示；本题正式输入仅含小写字母。

题解：从外向内的镜像扫描

核心洞察

下标 i 的镜像下标唯一确定为 n - 1 - i。按 i 从 0 往右扫描，首次命中已经保证最小；无须真的反转字符串。

完整过程

  1. 令 n = s.length。
  2. 依次枚举 i = 0 ... n - 1。
  3. 若 s[i] == s[n - 1 - i]，立即返回 i。
  4. 循环结束仍无命中，返回 -1。

边界、复杂度与替代方案

长度为 1 时 i = 0 必定命中；奇数长度的中心 i 也必定命中，因此只有偶数长度才可能得到 -1。时间复杂度 O(n)，额外空间 O(1)。构造反转字符串再逐位比较也可行，但需要额外空间。

面试追问与常见错误

若题目改成“所有匹配下标”，就不要提前返回；若只需判断是否存在，可在首个命中后返回 true。常见错误是写成 n - i，这会越界并错过正确镜像位置。
