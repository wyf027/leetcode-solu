Solution

ASCII 区间判断 + 单次扫描

手动实现一次小写转换，关键在于只修改大写英文字母。

核心洞察与完整过程

1

识别目标字符

逐个读取字符。仅当字符位于 'A' 到 'Z' 的闭区间内时，才需要转换。

2

利用固定偏移

ASCII 中，同一个英文字母的大写与小写编码相差 'a' - 'A' = 32，因此可加上这一偏移。

3

收集新字符串

转换大写字符，原样保留小写字母、数字、空格与标点，最后按原顺序拼接并返回。

正确性证明

对字符串中的任意位置 i：如果 s[i] 是大写字母，算法利用固定 ASCII 偏移得到对应的小写字母；如果它不是大写字母，算法原样保留它。因此，输出的每个位置都恰好满足题意。字符按原顺序逐一写入，所以最终字符串的长度与顺序均不变，算法正确。

时间复杂度：O(n) 额外空间：O(n) n = s.length

四种语言完整代码

class Solution {
    public String toLowerCase(String s) {
        StringBuilder answer = new StringBuilder(s.length());

        for (int i = 0; i < s.length(); i++) {
            char current = s.charAt(i);
            if (current >= 'A' && current <= 'Z') {
                current = (char) (current + ('a' - 'A'));
            }
            answer.append(current);
        }

        return answer.toString();
    }
}
/**
 * @param {string} s
 * @return {string}
 */
var toLowerCase = function(s) {
    const answer = [];

    for (const character of s) {
        const code = character.charCodeAt(0);
        if (code >= 65 && code <= 90) {
            answer.push(String.fromCharCode(code + 32));
        } else {
            answer.push(character);
        }
    }

    return answer.join('');
};
class Solution:
    def toLowerCase(self, s: str) -> str:
        answer = []

        for character in s:
            if 'A' <= character <= 'Z':
                answer.append(chr(ord(character) + ord('a') - ord('A')))
            else:
                answer.append(character)

        return ''.join(answer)
class Solution {
public:
    string toLowerCase(string s) {
        for (char& current : s) {
            if (current >= 'A' && current <= 'Z') {
                current = static_cast<char>(current + ('a' - 'A'));
            }
        }

        return s;
    }
};

边界情况与常见错误

  • 字符串已全部小写：应保持不变。
  • 含数字、空格或标点：这些字符不能被修改。
  • 区间边界 'A' 与 'Z' 必须包含在判断内。
  • 不要对所有字符盲目加 32，否则小写字母和符号都会损坏。
  • 拼接或修改时要保留原字符顺序与字符串长度。

替代方案

实际工程中可直接调用语言标准库，例如 Java 的 s.toLowerCase()、JavaScript/Python 的 s.toLowerCase()/s.lower()。它更短，也往往提供更完整的语言规则；但本题的练习重点是理解逐字符处理与 ASCII 大小写关系。位运算写法虽然存在，却不如区间判断清晰，且同样必须先确认字符范围。
