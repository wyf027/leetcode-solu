二叉树最长连续序列 II

Binary Tree Longest Consecutive Sequence II

MEDIUM树深度优先搜索树形 DP

题目

给定一棵二叉树，求其中最长的连续路径长度。相邻节点的值必须恰好相差 1；路径既可以递增，也可以递减，并允许沿“子节点 → 父节点 → 另一个子节点”转向，但不能重复经过节点。

路径不要求从根开始，也不要求到叶子结束。与第一版不同，本题允许路径在某个节点处把递减链与递增链拼接起来。

示例 1输入：root = [1,2,3]输出：2可取 1 → 2 或 2 → 3；2 与 3 不通过值为 1 的父节点形成连续三节点路径。
示例 2输入：root = [2,1,3]输出：3路径 1 → 2 → 3 的每一步都增加 1。

约束

  • 树中节点数在 [1, 3 × 10⁴] 范围内。
  • -3 × 10⁴ ≤ Node.val ≤ 3 × 10⁴。

先尝试回答：为什么每个节点只需要向父节点返回两种状态？

Solution

后序 DFS：向上返回两条单向链

核心洞察

一条合法路径若在节点 x 转向，只可能由一条以 x 为端点的递减链和一条以 x 为端点的递增链组成。DFS 对每个节点返回二元组：inc 表示从当前节点向下、每步加 1 的最长长度；dec 表示每步减 1 的最长长度。

完整过程

  1. 空节点返回 (0, 0)。
  2. 后序计算左右子树，当前 inc = dec = 1。
  3. 若子节点值等于当前值加 1，用该子节点的 inc 延长当前 inc；若等于当前值减 1，用其 dec 延长当前 dec。左右孩子都要取最大值。
  4. 以当前节点为转折点的最长路径是 inc + dec - 1，减一是因为当前节点被两条链重复计算。

正确性证明

引理：DFS 返回的 inc 与 dec 分别是以当前节点为起点、向其子树延伸的最长递增与递减连续链。叶子显然成立；对当前节点，任何此类链只能选择一个满足值差条件的孩子，归纳假设保证取孩子状态的最大值即最优。

定理：算法得到全树最长连续路径。任意简单路径都有唯一最高节点；若路径跨越该节点的两个方向，它必由一条递增链和一条递减链构成，算法在处理该节点时计算了最优拼接；若只有一侧，另一状态长度为 1，同样包含在公式中。因此所有合法路径均被覆盖，且拼接出的路径都合法。

边界与复杂度

  • 单节点答案为 1；空孩子不贡献链长。
  • 值差必须恰好为 1，相等或跨越多个整数都不能连接。
  • 时间 O(n)；递归栈空间平均 O(h)，最坏退化树为 O(n)。

代码

class Solution {
    private int answer = 0;
    public int longestConsecutive(TreeNode root) {
        dfs(root);
        return answer;
    }
    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0};
        int inc = 1, dec = 1;
        for (TreeNode child : new TreeNode[]{node.left, node.right}) {
            if (child == null) continue;
            int[] state = dfs(child);
            if (child.val == node.val + 1) inc = Math.max(inc, state[0] + 1);
            if (child.val == node.val - 1) dec = Math.max(dec, state[1] + 1);
        }
        answer = Math.max(answer, inc + dec - 1);
        return new int[]{inc, dec};
    }
}
var longestConsecutive = function(root) {
  let answer = 0;
  function dfs(node) {
    if (!node) return [0, 0];
    let inc = 1, dec = 1;
    for (const child of [node.left, node.right]) {
      if (!child) continue;
      const [childInc, childDec] = dfs(child);
      if (child.val === node.val + 1) inc = Math.max(inc, childInc + 1);
      if (child.val === node.val - 1) dec = Math.max(dec, childDec + 1);
    }
    answer = Math.max(answer, inc + dec - 1);
    return [inc, dec];
  }
  dfs(root);
  return answer;
};

替代方案

也可让 DFS 携带父节点和值差方向，自顶向下维护链长，但遇到“子 → 父 → 子”的拼接时仍需在每个节点同时保存两个方向，因此二元状态的后序 DP 更直接。极深树可改用显式栈模拟后序，避免递归栈溢出。

面试追问

  • 如果允许相邻值差不超过 k，状态还能保持常数个吗？
  • 如何用显式栈实现相同的后序计算？
  • 若需要返回具体路径而不只是长度，应记录哪些端点或父指针？

常见错误

  • 只算从父到子的单方向链，漏掉在父节点转向的路径。
  • 把左右孩子的两条递增链相加；合法拼接必须一增一减。
  • 写成 inc + dec，没有减去重复的中心节点。
  • 返回全局最佳值给父节点；父节点需要的是可继续延长的单向链。
