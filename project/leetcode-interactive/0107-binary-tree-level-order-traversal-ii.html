01 / Mission brief

题意与边界

给定二叉树根节点，从最深层开始逐层向上返回节点值；每一层内部仍保持从左到右。页面转述自 LeetCode 官方题面，示例与约束已逐项核对。

任务目标

输入二叉树的 root，输出它的 自底向上层序遍历。也就是先给出叶子附近的最深层，再逐层回到根；同一层节点顺序不变。

面试主线选用 BFS 队列收集层 + 最后整体反转。这与“层序”语义完全一致，状态清晰，也便于证明每个节点只处理一次。

官方约束
  • 树中节点数范围为 [0, 2000]。
  • -1000 <= Node.val <= 1000。
  • 空树必须返回空列表，而不是包含空层的列表。

官方示例 1

输入 root = [3,9,20,null,null,15,7]
输出 [[15,7],[9,20],[3]]

官方示例 2

输入 root = [1]
输出 [[1]]

官方示例 3

输入 root = []
输出 []

可见符号说明：null 表示对应孩子为空；若示例含字符串，空格会写成 ␠ 并保留成对直引号。本题输入没有字符串，仍保留该统一阅读约定。

核心洞察

BFS 负责分层，反转负责方向

层序遍历最自然的数据结构是队列。每轮先固定 levelSize = queue.size()，只弹出这一层的节点，把它们的孩子加入队尾。这样得到的 levels 天然是根到叶；最后一次整体反转即可得到叶到根。

bottomUp = reverse(topDownLevels)
完整过程
  1. 若 root == null，直接返回空列表。
  2. 根节点入队；当队列不空时记录当前长度。
  3. 弹出恰好这一层的节点，并把左右非空孩子入队。
  4. 把本层值追加到结果，继续处理下一层。
  5. 所有楼层收集完成后整体反转结果。
边界与不变量
  • 空树：结果为 []。
  • 单节点：反转前后都为 [[root.val]]。
  • 链状树：每层只有一个节点，方向仍需反转。
  • 节点值可重复，算法不能把值当作节点身份。
  • 每轮开始时，队列前 levelSize 个节点恰好属于同一层。
复杂度
O(n) 每个节点入队、出队各一次；反转至多再访问每层一次。
O(n) 返回结果本身占 O(n)，队列最坏可容纳一层的 O(n) 节点。
替代方案取舍

头插层结果或 DFS 都能做，但不是首选

  • 双端队列头插：每层完成后 addFirst，省去最终反转；语言有原生双端队列时可用，但面试表达比“收集后反转”略绕。
  • 普通数组头插：JavaScript unshift / Python 列表 insert(0, ...) 会搬移已有元素，可能退化为层数平方级开销。
  • DFS 按深度收集：也能得到各层，再反转；但递归深度与“层序”语义都不如 BFS 直接。
面试追问
  • 如果不能调用库函数反转，如何原地交换首尾层？
  • 如果只允许流式输出，何时才能安全输出最深层？
  • 树非常宽时，队列的空间下界是什么？
  • 如何改成锯齿形层序遍历？
  • DFS 方案在极深链状树上有什么栈风险？
常见错误
  • 循环中不先固定层大小，导致把下一层也混入本层。
  • 反转了每一层内部的节点顺序，而不是反转层的顺序。
  • 空树仍把空层加入结果，得到 [[]]。
  • 在普通数组头部反复插入，忽略搬移成本。
  • 把 null 孩子加入队列后未做保护。

class Solution {
    public List<List<Integer>> levelOrderBottom(TreeNode root) {
        List<List<Integer>> levels = new ArrayList<>();
        if (root == null) {
            return levels;
        }

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            List<Integer> level = new ArrayList<>(levelSize);

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);

                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }

            levels.add(level);
        }

        Collections.reverse(levels);
        return levels;
    }
}
var levelOrderBottom = function (root) {
  if (root === null) {
    return [];
  }

  const levels = [];
  const queue = [root];
  let head = 0;

  while (head < queue.length) {
    const levelSize = queue.length - head;
    const level = [];

    for (let i = 0; i < levelSize; i += 1) {
      const node = queue[head];
      head += 1;
      level.push(node.val);

      if (node.left !== null) {
        queue.push(node.left);
      }
      if (node.right !== null) {
        queue.push(node.right);
      }
    }

    levels.push(level);
  }

  levels.reverse();
  return levels;
};

class Solution {
public:
    vector<vector<int>> levelOrderBottom(TreeNode* root) {
        if (root == nullptr) {
            return {};
        }

        vector<vector<int>> levels;
        queue<TreeNode*> nodes;
        nodes.push(root);

        while (!nodes.empty()) {
            int levelSize = static_cast<int>(nodes.size());
            vector<int> level;
            level.reserve(levelSize);

            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = nodes.front();
                nodes.pop();
                level.push_back(node->val);

                if (node->left != nullptr) {
                    nodes.push(node->left);
                }
                if (node->right != nullptr) {
                    nodes.push(node->right);
                }
            }

            levels.push_back(std::move(level));
        }

        reverse(levels.begin(), levels.end());
        return levels;
    }
};
