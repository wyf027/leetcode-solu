每天的最大交易

1831 / Maximum Transaction Each Day

同一天，可能有不止一笔最大的交易。你的查询能全部找出来吗？

题目任务

给定 Transactions 表，找出每个自然日金额最高的交易，返回它们的 transaction_id。同日最高金额并列时全部保留，结果按 transaction_id 升序排列。

字段类型含义
transaction_idint唯一交易 ID，主键
daydatetime交易发生时间
amountint交易金额

约束

每行代表一笔交易；ID 唯一，同日可有多笔交易。“一天”按完整年月日判断，忽略时分秒。公开题面没有额外列出行数与金额上下界，本页不补造范围。

元数据部分建表模板将 day 写作 DATE，但示例含时分秒；这里采用题面的 datetime 表达。

官方示例 · 完整参数

Transactions = {
  "headers": ["transaction_id", "day", "amount"],
  "rows": [
    [8, "2021-4-3 15:57:28", 57],
    [9, "2021-4-28 08:47:25", 21],
    [1, "2021-4-29 13:28:30", 58],
    [5, "2021-4-28 16:39:59", 40],
    [6, "2021-4-29 23:39:28", 58]

输出 = {"headers":["transaction_id"],"rows":[[1],[5],[6],[8]]}

独立题解

先思考：如何定义日期分区？如何保留并列第一？

核心洞察

按 DATE(day) 分区，再按 amount 降序使用 RANK 排名。全部并列最高交易的名次都为 1。

完整过程

  1. 取完整年月日，去除时分秒。
  2. 在每个日期分区内按金额降序排名。
  3. 外层过滤 rnk = 1，不能在同层 WHERE 使用窗口别名。
  4. 只输出交易 ID，按数值升序排列。

正确性

每行恰好属于一个日期分区。某行排名为 1，当且仅当同日没有更大金额，因此它恰好是该日最大交易。所有并列最大行都取得排名 1，其他行均被过滤。最后排序仅改变输出顺序，满足 ID 升序要求。

边界与常见错误

  • 同日全相等要全部返回；单笔日期返回该笔；空表返回空结果。
  • ROW_NUMBER = 1 会丢失并列。RANK 与 DENSE_RANK 的首名在这里相同。
  • DAY(day) 只有日号，会混淆跨月、跨年记录；完整时间戳分区又会错误拆分同一天。
  • 只求 MAX(amount) 不足以返回交易 ID；不要遗漏最终 ORDER BY。
  • 本地代码以有效、非 NULL、无时区记录为输入契约。业务若含 NULL 或时区，需先约定归日与空值口径。

复杂度

设 n 为记录数、d 为日期数、k 为结果数。窗口查询典型排序成本 O(n log n)，中间空间通常 O(n)，实际依赖数据库执行计划。下面哈希映射参考实现期望时间 O(n + k log k)，空间 O(d + k)；C++ 使用有序 map，时间 O(n log(d+1) + k log k)。

替代方案

先按日期 GROUP BY 求最大金额，再以日期和金额两列回连原表，同样保留并列。也可用 NOT EXISTS 判断同日不存在更大金额，但缺乏有效索引时可能反复扫描。

面试追问

每天前三个不同金额档位用 DENSE_RANK ≤ 3；只要三条记录用 ROW_NUMBER，并补充 ID 作为确定性排序条件。大表考虑日期生成列及组合索引，效果要由执行计划判断。跨时区业务先确定业务日期。

MySQL 8+ · 可提交主解

WITH ranked AS (
    SELECT transaction_id,
           RANK() OVER (
               PARTITION BY DATE(day)
               ORDER BY amount DESC
           ) AS rnk
    FROM Transactions
)
SELECT transaction_id
FROM ranked
WHERE rnk = 1
ORDER BY transaction_id;

Java 17 · 本地语义参考

import java.time.LocalDate;
import java.time.LocalDateTime;
import java.util.*;

class Solution {
    record Transaction(int transaction_id, LocalDateTime day, int amount) {}
    public List<Integer> findMaximumTransaction(List<Transaction> rows) {
        Map<LocalDate, Integer> maximum = new HashMap<>();
        for (Transaction t : rows)
            maximum.merge(t.day().toLocalDate(), t.amount(), Math::max);
        List<Integer> result = new ArrayList<>();
        for (Transaction t : rows)
            if (t.amount() == maximum.get(t.day().toLocalDate()))
                result.add(t.transaction_id());
        result.sort(Integer::compare);
        return result;
    }
}

JavaScript · 本地语义参考

// rows: {transaction_id: number, day: string, amount: number}[]
// 日期允许 YYYY-M-D HH:mm:ss 或补零格式，不做时区转换。
function findMaximumTransaction(rows) {
    const key = day => day.split(/[ T]/)[0].split('-').map(Number).join('-');
    const maximum = new Map();
    for (const row of rows) {
        const d = key(row.day);
        maximum.set(d, Math.max(maximum.get(d) ?? -Infinity, row.amount));
    }
    return rows.filter(r => r.amount === maximum.get(key(r.day)))
        .map(r => r.transaction_id).sort((a, b) => a - b);
}

Python · 本地语义参考（非 Pandas 签名）

from datetime import datetime
from typing import NamedTuple

class Transaction(NamedTuple):
    transaction_id: int
    day: datetime
    amount: int

def find_maximum_transaction(rows: list[Transaction]) -> list[int]:
    maximum = {}
    for row in rows:
        day = row.day.date()
        maximum[day] = max(maximum.get(day, row.amount), row.amount)
    return sorted(row.transaction_id for row in rows
                  if row.amount == maximum[row.day.date()])

C++17 · 本地语义参考

#include <algorithm>
#include <map>
#include <sstream>
#include <string>
#include <tuple>
#include <vector>
using namespace std;
struct Transaction { int transaction_id; string day; int amount; };
class Solution {
    using Date = tuple<int, int, int>;
    static Date dateKey(const string& day) {
        istringstream in(day);
        int y, m, d; char dash;
        in >> y >> dash >> m >> dash >> d;
        return {y, m, d};
    }
public:
    vector<int> findMaximumTransaction(const vector<Transaction>& rows) {
        map<Date, int> maximum;
        for (const auto& t : rows) {
            auto [it, inserted] = maximum.emplace(dateKey(t.day), t.amount);
            if (!inserted) it->second = max(it->second, t.amount);
        }
        vector<int> result;
        for (const auto& t : rows)
            if (t.amount == maximum.at(dateKey(t.day)))
                result.push_back(t.transaction_id);
        sort(result.begin(), result.end());
        return result;
    }
};
