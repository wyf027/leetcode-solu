链表求和

个位就在表头。让两个指针同步前进，用一枚 carry 把上一列的十位送进下一列。

难度中等
推荐策略逐位模拟
额外空间O(1)

题意

两个非负整数以逆序单链表保存，每个节点只放一位数字。返回它们之和的同类链表。

给定链表 l1 与 l2。表头是个位，后续节点依次是十位、百位。不得依赖把整个链表转换成机器整数，因为位数可能超出整数范围。

  • 每个节点值处于 0 到 9。
  • 两个链表可能长度不同。
  • 最高位相加后可能产生一个新节点。
  • 进阶问题把数位改成正序存放，需要调整处理顺序。
输入l1 = [7,1,6], l2 = [5,9,2]
期望输出[2,1,9]
解释617 + 295 = 912
输入l1 = [9,9], l2 = [1]
期望输出[0,0,1]
解释最后的进位必须单独成为最高位。

题解开关

题解：把链表当成手算草稿纸

核心洞察

逆序存放省去了反转。每轮只读取两个当前节点与一个 carry，写入 sum % 10，再把 Math.floor(sum / 10) 交给下一轮。

复杂度

时间 O(max(m, n)) 额外空间 O(1)

答案链表占用 O(max(m, n))，通常不计入额外空间。

完整过程

  1. 建立哑节点用 dummy 统一首节点与后续节点的追加逻辑。
  2. 读取当前数位节点存在则取值，否则把该链表本列看作 0。
  3. 拆分和与进位digit = sum % 10，carry = sum / 10 的整数部分。
  4. 继续到全部清空循环条件同时检查 l1、l2 和 carry。

边界

  • 长度不同：短链表耗尽后，该侧数位按 0 处理。
  • 最终进位：[9,9] + [1] 必须多写一个节点 1。
  • 零：[0] + [0] 返回 [0]，不能返回空链表。
  • 超长输入：始终逐位计算，不转换为 JavaScript Number 或其他定长整数。

替代方案

递归逐位相加

状态是两个节点与进位，写法贴近定义，但递归栈会增加 O(max(m, n)) 空间，并有栈深限制。

正序链表进阶

可用两个栈从尾部弹出数位，或先补齐长度再递归。若允许修改输入，也可反转后复用本算法。

面试追问

  • 如果不能新建答案节点，如何在原链表上复用较长链表？需要怎样处理尾部进位？
  • 数位改成正序时，怎样在不修改输入链表的前提下保持 O(n) 时间？
  • 若节点保存的是十进制块而非单个数位，进制基数应该如何抽象？

常见错误

  • 循环条件只写 while (l1 && l2)，导致较长链表余下部分丢失。
  • 循环条件没有包含 carry，最终进位没有写入。
  • 先移动指针再读值，跳过当前节点。
  • 把链表整体转换成整数，遇到超长输入时溢出或丢失精度。
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        int carry = 0;

        while (l1 != null || l2 != null || carry != 0) {
            int a = l1 == null ? 0 : l1.val;
            int b = l2 == null ? 0 : l2.val;
            int sum = a + b + carry;

            tail.next = new ListNode(sum % 10);
            tail = tail.next;
            carry = sum / 10;

            if (l1 != null) l1 = l1.next;
            if (l2 != null) l2 = l2.next;
        }

        return dummy.next;
    }
}

var addTwoNumbers = function (l1, l2) {
  const dummy = new ListNode(0);
  let tail = dummy;
  let carry = 0;

  while (l1 !== null || l2 !== null || carry !== 0) {
    const a = l1 === null ? 0 : l1.val;
    const b = l2 === null ? 0 : l2.val;
    const sum = a + b + carry;

    tail.next = new ListNode(sum % 10);
    tail = tail.next;
    carry = Math.floor(sum / 10);

    if (l1 !== null) l1 = l1.next;
    if (l2 !== null) l2 = l2.next;
  }

  return dummy.next;
};
