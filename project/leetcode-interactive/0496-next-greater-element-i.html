01 / PROBLEM

问题到底在问什么？

两个数组中的数都互不相同，且 nums1 是 nums2 的子集。每次查询都以 nums2 中的位置为准。

给定两个从 0 开始编号的整数数组 nums1 和 nums2。对于 nums1[i]，先在 nums2 中定位与它相等的 nums2[j]，再从 j + 1 开始向右寻找第一个严格大于 nums2[j] 的元素。

找到时，它就是本次查询的答案；如果直到数组末尾都没有更大的元素，则答案为 -1。返回与 nums1 等长的数组 ans，其中 ans[i] 对应 nums1[i] 的查询结果。

关键词：不是右侧最大的元素，而是从当前位置向右遇到的第一个严格更大的元素。

示例 1

输入：nums1 = [4,1,2], nums2 = [1,3,4,2]
输出：[-1,3,-1]

4 和 2 的右侧都没有更大的数，因此对应 -1；1 右侧第一个更大的数是 3。

示例 2

输入：nums1 = [2,4], nums2 = [1,2,3,4]
输出：[3,-1]

2 向右首先遇到 3；4 已在末尾，因而没有下一个更大元素。

  • 1 <= nums1.length <= nums2.length <= 1000
  • 0 <= nums1[i], nums2[i] <= 104
  • nums1 与 nums2 中的所有整数都互不相同。
  • nums1 中的每个整数也都出现在 nums2 中。
  • 进阶目标：设计 O(nums1.length + nums2.length) 的解法。

04 / SOLUTION

准备好看完整题解了吗？

核心洞察、证明、复杂度与四种语言代码都在折叠区内。

核心洞察：一次预处理，回答所有查询

如果为 nums1 的每个元素都单独向右扫描，最坏会重复遍历 nums2。更好的做法是先为 nums2 中的每个值求出答案，并存入哈希表，最后按 nums1 的顺序查询。

从右向左遍历 nums2，维护一个单调递减栈（从栈底到栈顶严格递减）。处理当前值 x 时，栈中所有小于或等于 x 的值都不可能成为 x 的下一个更大元素，应先弹出。弹出后若栈非空，栈顶就是 x 右侧第一个更大的值；否则答案为 -1。记录后再把 x 入栈。

完整过程

  1. 创建哈希表 nextGreater 和空栈 stack。
  2. 从 nums2.length - 1 到 0 逆序遍历，当前值记作 x。
  3. 当栈非空且栈顶小于或等于 x 时持续弹栈，移除被 x 遮挡的候选值。
  4. 若栈为空，记录 nextGreater[x] = -1；否则记录 nextGreater[x] = stack.top()。
  5. 把 x 压入栈，继续处理左侧元素。
  6. 遍历 nums1，将每个值在哈希表中的映射依次写入答案数组。

正确性说明

为何可以弹出？

设当前值为 x，栈顶候选为 y <= x。对 x 而言，y 不够大；对更左侧的元素而言，x 比 y 更靠近且不小于 y，所以 y 永远不会比 x 更优，可以永久移除。

为何栈顶是“第一个”？

逆序扫描保证栈中只含当前元素右侧的值。所有不大于当前值的候选已被移除；剩余候选中，后来压栈的值对应更靠近当前位置的元素，因此栈顶恰是右侧最近的严格更大值。

由上述两个结论，每一步记录的映射都等于定义中的下一个更大元素。遍历完成后，哈希表对 nums2 中所有值都正确，按 nums1 查询得到的答案数组也正确。

边界情况

  • 单元素：右侧没有元素，映射为 -1。
  • 严格递增：除最后一个值外，每个值的答案都是紧邻右侧元素。
  • 严格递减：每个值都没有右侧更大元素，答案全为 -1。
  • 包含 0：0 是合法值，不能把它误当作“未找到”的哨兵；未找到必须明确记录为 -1。
  • 唯一性：本题保证元素互不相同，因此可以直接以值作为哈希表键。

复杂度

时间 O(n + m)n = nums2.length，每个元素至多入栈、出栈各一次；再用 O(m) 查询 nums1。
空间 O(n)哈希表和单调栈最多都保存与 nums2 同阶数量的元素。

四语言完整代码

Java · 官方提交签名O(n + m)
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        Map<Integer, Integer> nextGreater = new HashMap<>();
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = nums2.length - 1; i >= 0; i--) {
            int current = nums2[i];
            while (!stack.isEmpty() && stack.peek() <= current) {
                stack.pop();
            }
            nextGreater.put(current, stack.isEmpty() ? -1 : stack.peek());
            stack.push(current);
        }

        int[] answer = new int[nums1.length];
        for (int i = 0; i < nums1.length; i++) {
            answer[i] = nextGreater.get(nums1[i]);
        }
        return answer;
    }
}
JavaScript · 官方提交签名O(n + m)
/**
 * @param {number[]} nums1
 * @param {number[]} nums2
 * @return {number[]}
 */
var nextGreaterElement = function(nums1, nums2) {
    const nextGreater = new Map();
    const stack = [];

    for (let i = nums2.length - 1; i >= 0; i--) {
        const current = nums2[i];
        while (stack.length > 0 && stack[stack.length - 1] <= current) {
            stack.pop();
        }
        nextGreater.set(
            current,
            stack.length === 0 ? -1 : stack[stack.length - 1]
        );
        stack.push(current);
    }

    return nums1.map((value) => nextGreater.get(value));
};
Python 3 · 官方提交签名O(n + m)
from typing import List


class Solution:
    def nextGreaterElement(
        self,
        nums1: List[int],
        nums2: List[int]
    ) -> List[int]:
        next_greater = {}
        stack = []

        for current in reversed(nums2):
            while stack and stack[-1] <= current:
                stack.pop()
            next_greater[current] = stack[-1] if stack else -1
            stack.append(current)

        return [next_greater[value] for value in nums1]
C++ · 官方提交签名O(n + m)
#include <stack>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> nextGreaterElement(
        vector<int>& nums1,
        vector<int>& nums2
    ) {
        unordered_map<int, int> nextGreater;
        stack<int> candidates;

        for (int i = static_cast<int>(nums2.size()) - 1; i >= 0; --i) {
            int current = nums2[i];
            while (!candidates.empty() && candidates.top() <= current) {
                candidates.pop();
            }
            nextGreater[current] = candidates.empty() ? -1 : candidates.top();
            candidates.push(current);
        }

        vector<int> answer;
        answer.reserve(nums1.size());
        for (int value : nums1) {
            answer.push_back(nextGreater[value]);
        }
        return answer;
    }
};

替代方案

逐次暴力扫描：先在 nums2 中找到每个查询值，再向右扫描直到遇到更大值。它直观且额外空间可做到 O(1)（不计结果），但最坏时间为 O(mn)。在本题上限 1000 时可能仍能运行，却没有达到进阶要求，也无法体现重复工作的消除。

从左向右的单调栈：也可以把尚未找到答案的值放入递减栈；遇到更大值时持续弹栈并写入映射。它同样是 O(n + m)，只是状态含义从“右侧候选”变成“等待匹配的历史元素”。

常见错误

  • 把“右侧第一个更大值”误写成“右侧最大值”。
  • 从右向左时忘记先弹出不大于当前值的栈顶，导致取到无效候选。
  • 只对 nums1 建栈，忽略了答案的相对位置由完整的 nums2 决定。
  • 在 JavaScript 中用 nextGreater.get(value) || -1 取值；如果合法答案是 0，这种写法会误判。应直接使用 Map.get。
  • 返回顺序跟随 nums2，而不是题目要求的 nums1 顺序。

面试追问

  1. 如果数组允许重复值，当前“以值为键”的哈希表为什么失效？你会改为记录索引还是记录一组位置？
  2. 如果要求的是循环数组中的下一个更大元素，如何通过遍历两轮并对索引取模来复用单调栈？
  3. 如何改造成“下一个更小元素”？单调性和弹栈条件分别怎样变化？
  4. 为什么总弹栈次数不是平方级？请用摊还分析解释每个元素至多进栈和出栈一次。
