Problem brief

题意转述

一排孩子的评分由整数数组 ratings 给出。给每个孩子正整数颗糖果，使任意相邻孩子中评分较高者拿到更多糖果，并让总数最小。

  • 每个孩子至少 1 颗。
  • 只比较相邻孩子；评分相等时没有大小要求。
  • 返回满足规则的最少糖果总数。

Official example 1

输入
ratings = [1,0,2]
期望输出
5

最小分配为 [2,1,2]。

Official example 2

输入
ratings = [1,2,2]
期望输出
4

相等评分之间无需递增，分配为 [1,2,1]。

Core insight

把双边约束拆成两个单边约束

从左到右只保证“若评分高于左邻居，糖果多 1”；从右到左只保证右邻居。第二遍不能覆盖第一遍，而是取 max(当前值, 右邻居 + 1)，同时满足两侧并保持最小。

Complete process

  1. 1. 初始化每个孩子 1 颗。
  2. 2. 左到右：上升时令当前值等于左侧 + 1。
  3. 3. 右到左：下降反向看是上升，取当前值与右侧 + 1 的最大值。
  4. 4. 求糖果数组总和。

边界与复杂度

  • 单个孩子：答案固定为 1。
  • 评分相等：无严格大小要求，双方都可保持 1。
  • 严格递增或递减：形成 1…n 的糖果阶梯。
  • 时间复杂度 O(n)；额外空间 O(n)。

替代方案与取舍

可以只记录连续上坡、下坡和山峰长度，将空间降为 O(1)。但峰值修正容易出错、可解释性弱。面试主线优先双遍历数组版；追问极致空间时再给斜坡计数。

面试追问

  • 为什么第二遍必须取最大值，不能直接赋值？
  • 评分相等时为什么可以重新从 1 开始？
  • 如何证明两遍得到的是满足约束的逐点最小值？
  • 怎样用山峰/山谷把空间压到常数？

常见错误

  • 只做一遍，遗漏另一方向的下降约束。
  • 把评分相等误判为也必须多发糖果。
  • 右扫直接覆盖左扫结果，破坏已满足的左约束。
  • 右扫边界写到 i = n - 1，访问越界。

class Solution {
    public int candy(int[] ratings) {
        int n = ratings.length;
        int[] candies = new int[n];
        java.util.Arrays.fill(candies, 1);

        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) {
                candies[i] = candies[i - 1] + 1;
            }
        }
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) {
                candies[i] = Math.max(candies[i], candies[i + 1] + 1);
            }
        }

        int answer = 0;
        for (int count : candies) answer += count;
        return answer;
    }
}
var candy = function (ratings) {
  const candies = new Array(ratings.length).fill(1);

  for (let i = 1; i < ratings.length; i += 1) {
    if (ratings[i] > ratings[i - 1]) {
      candies[i] = candies[i - 1] + 1;
    }
  }
  for (let i = ratings.length - 2; i >= 0; i -= 1) {
    if (ratings[i] > ratings[i + 1]) {
      candies[i] = Math.max(candies[i], candies[i + 1] + 1);
    }
  }

  return candies.reduce((sum, count) => sum + count, 0);
};
