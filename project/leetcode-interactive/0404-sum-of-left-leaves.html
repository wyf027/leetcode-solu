题目说明

给定一棵二叉树的根节点 root，返回树中所有左叶子节点的节点值之和。

叶子节点没有左孩子和右孩子；左叶子还必须是其父节点的左孩子。仅仅“位于画面左侧”并不构成左叶子。

官方示例

示例 1两枚左叶子
输入：root = [3,9,20,null,null,15,7] 输出：24 解释：9 和 15 都是左叶子，因此 9 + 15 = 24。
示例 2只有根节点
输入：root = [1] 输出：0 解释：根节点没有父节点，所以它不是左叶子。

参数与约束

函数接收 root: TreeNode，返回一个整数。

  • 树中节点数量在 [1, 1000] 范围内。
  • -1000 <= Node.val <= 1000。

Complete solution

递归携带“来自左侧”身份

01

身份

节点是不是左孩子，只能由父节点向下传递；根节点没有这个身份。

02

叶子

当前节点左右孩子都为空时，才进入是否累加的判断。

03

汇总

非叶子节点把左、右子树的结果相加，完整覆盖整棵树且不重复。

核心洞察与完整过程

定义辅助函数 dfs(node, isLeft)。布尔值 isLeft 表示当前节点是否由父节点的左指针到达。

  1. 若节点为空，贡献为 0。
  2. 若节点没有任何孩子，它是叶子；仅当 isLeft 为真时返回节点值，否则返回 0。
  3. 若节点不是叶子，递归处理左孩子并传入 true，处理右孩子并传入 false，再把两边相加。
  4. 根节点没有父节点，因此入口调用使用 dfs(root, false)。

正确性证明

命题：dfs(node, isLeft) 返回以 node 为根的子树中所有左叶子节点值的总和，并且当 node 自身是左叶子时正确计入它。

基础情况：空节点没有贡献；叶子节点没有更小子树，函数依据从父节点传来的 isLeft 精确决定返回节点值还是 0。

递推步骤：对于非叶子节点，所有左叶子必然且仅可能位于左子树或右子树。递归调用分别传递正确的孩子方向。根据递归假设，两次调用都返回各自子树的正确总和，相加便得到当前子树的正确总和。

结论：入口把根节点标记为非左孩子，因此不会误计单独的根节点；递归最终返回整棵树的所有左叶子之和。

边界与复杂度

时间复杂度O(n)

每个节点访问一次。

递归空间O(h)

h 为树高；最坏 O(n)，平衡树为 O(log n)。

  • 单节点树：根没有父节点，即使是叶子也不能计入。
  • 只有右孩子的链：不存在左叶子，答案为 0。
  • 只有左孩子的链：仅最深处叶子被计入，中间节点不是叶子。
  • 节点值可为负数：直接做整数加法，不应取绝对值或强行截断为非负数。

四语言完整代码

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int sumOfLeftLeaves(TreeNode root) {
        return dfs(root, false);
    }

    private int dfs(TreeNode node, boolean isLeft) {
        if (node == null) {
            return 0;
        }
        if (node.left == null && node.right == null) {
            return isLeft ? node.val : 0;
        }
        return dfs(node.left, true) + dfs(node.right, false);
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var sumOfLeftLeaves = function(root) {
    const dfs = (node, isLeft) => {
        if (node === null) {
            return 0;
        }
        if (node.left === null && node.right === null) {
            return isLeft ? node.val : 0;
        }
        return dfs(node.left, true) + dfs(node.right, false);
    };

    return dfs(root, false);
};

# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sumOfLeftLeaves(self, root: Optional[TreeNode]) -> int:
        def dfs(node: Optional[TreeNode], is_left: bool) -> int:
            if node is None:
                return 0
            if node.left is None and node.right is None:
                return node.val if is_left else 0
            return dfs(node.left, True) + dfs(node.right, False)

        return dfs(root, False)
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int sumOfLeftLeaves(TreeNode* root) {
        return dfs(root, false);
    }

private:
    int dfs(TreeNode* node, bool isLeft) {
        if (node == nullptr) {
            return 0;
        }
        if (node->left == nullptr && node->right == nullptr) {
            return isLeft ? node->val : 0;
        }
        return dfs(node->left, true) + dfs(node->right, false);
    }
};

替代方案

显式栈 DFS

把“节点 + 是否左孩子”成对压栈，可以避免系统递归栈；时间仍为 O(n)，额外空间最坏 O(n)。

队列 BFS

逐层取出节点，检查其左孩子是否为叶子，再继续入队非空孩子；更适合顺带处理层级信息。

面试追问

  • 能否不传 isLeft？ 可以在每个父节点处直接检查它的左孩子是否为叶子，再递归处理两个非空子树。
  • 如何改成“右叶子之和”？ 把方向标记的含义反转，或在父节点处检查右孩子。
  • 树极度倾斜时怎样规避栈溢出？ 使用显式栈或队列完成迭代遍历。
  • 若树可能动态更新怎么办？ 频繁查询时可在节点维护子树统计量，并在更新路径上重新计算。

常见错误

  • 把所有没有孩子的节点都计入，遗漏“必须是父节点的左孩子”这一条件。
  • 把只有左孩子或只有右孩子的节点误判为叶子；叶子必须两个孩子都为空。
  • 入口把根节点标成左孩子，导致单节点树错误返回根节点值。
  • 只检查根的左孩子，没有继续遍历更深层的左右子树。
  • 看到负数约束后把答案限制为非负数；左叶子之和可以是负数。
