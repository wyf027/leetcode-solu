1294. 不同国家的天气类型

Weather Type in Each Country

EASY数据库付费题MySQL

题目

给定国家表 Countries 和逐日天气表 Weather，统计每个国家在 2019 年 11 月的平均温度，并按平均值输出天气类型：

Cold平均温度 ≤ 15
Warm15 < 平均温度 < 25
Hot平均温度 ≥ 25

返回至少包含 country_name 与 weather_type 的结果；结果顺序不限。没有 2019 年 11 月天气记录的国家不会出现在聚合结果中。

表结构（完整参数形式）

Countries 字段类型含义
country_idINT国家标识
country_nameVARCHAR(20)国家名称
Weather 字段类型含义
country_idINT关联国家
weather_stateINT当日温度
dayDATE记录日期

约束：Countries.country_id 可唯一定位国家；Weather.country_id 对应已存在的国家；本题仅使用日期落在 [2019-11-01, 2019-12-01) 的记录。

题解

核心洞察

这是一条标准的“连接 → 过滤 → 分组 → 条件映射”查询。真正容易出错的是日期边界：使用半开区间可以覆盖整月，同时避开时间字段或月末天数带来的边界问题。

day >= '2019-11-01' AND day < '2019-12-01'

完整过程

  1. 通过 country_id 将天气记录连接到国家名称。
  2. 在 WHERE 中只保留 2019 年 11 月的天气记录。
  3. 按国家 ID 和名称分组，对 weather_state 求平均。
  4. 用 CASE：平均值 ≤ 15 为 Cold，平均值 ≥ 25 为 Hot，其余为 Warm。

正确性说明

过滤条件保证参与计算的恰好是目标月份的记录。内连接为每条保留记录补上唯一国家名称；按国家分组后，AVG 得到该国目标月份所有且仅有的温度记录的算术平均值。三个 CASE 分支覆盖实数轴且互不重叠，所以每个有记录的国家被唯一、正确地映射为 Cold、Warm 或 Hot。

边界情况

  • 平均值恰好为 15：Cold。
  • 平均值恰好为 25：Hot。
  • 只有一条月内记录：平均值就是该记录。
  • 只有月外记录：过滤后不出现在结果中。
  • 负温度与小数平均值：AVG 和比较逻辑均可自然处理。

复杂度

设 Weather 有 W 行、Countries 有 C 行。逻辑扫描成本通常为 O(W + C)，分组需要 O(C) 级别的聚合状态；真实执行成本取决于索引与优化器。为 Weather(day, country_id) 建索引可帮助时间范围过滤。

官方可提交语言：MySQL

SELECT
    c.country_name,
    CASE
        WHEN AVG(w.weather_state) <= 15 THEN 'Cold'
        WHEN AVG(w.weather_state) >= 25 THEN 'Hot'
        ELSE 'Warm'
    END AS weather_type
FROM Countries AS c
JOIN Weather AS w
  ON w.country_id = c.country_id
WHERE w.day >= '2019-11-01'
  AND w.day < '2019-12-01'
GROUP BY c.country_id, c.country_name;

import java.time.LocalDate;
import java.util.*;

public class Main {
    record Country(int id, String name) {}
    record Weather(int countryId, int state, LocalDate day) {}

    static Map<String, String> classify(List<Country> countries,
                                         List<Weather> weather) {
        LocalDate start = LocalDate.of(2019, 11, 1);
        LocalDate end = LocalDate.of(2019, 12, 1);
        Map<Integer, int[]> stats = new HashMap<>();
        for (Weather w : weather) {
            if (!w.day().isBefore(start) && w.day().isBefore(end)) {
                int[] s = stats.computeIfAbsent(w.countryId(), k -> new int[2]);
                s[0] += w.state(); s[1]++;
            }
        }
        Map<String, String> answer = new LinkedHashMap<>();
        for (Country c : countries) {
            int[] s = stats.get(c.id());
            if (s == null) continue;
            double avg = (double) s[0] / s[1];
            answer.put(c.name(), avg <= 15 ? "Cold" : avg >= 25 ? "Hot" : "Warm");
        }
        return answer;
    }

    public static void main(String[] args) {
        List<Country> countries = List.of(new Country(2, "USA"), new Country(3, "Australia"));
        List<Weather> weather = List.of(
            new Weather(2, 15, LocalDate.parse("2019-11-01")),
            new Weather(3, -2, LocalDate.parse("2019-11-10")),
            new Weather(3, 3, LocalDate.parse("2019-11-12"))
        );
        System.out.println(classify(countries, weather));
    }
}
function classify(countries, weather) {
  const stats = new Map();
  for (const row of weather) {
    if (row.day >= "2019-11-01" && row.day < "2019-12-01") {
      const value = stats.get(row.countryId) || { sum: 0, count: 0 };
      value.sum += row.state;
      value.count += 1;
      stats.set(row.countryId, value);
    }
  }
  return countries.flatMap((country) => {
    const value = stats.get(country.id);
    if (!value) return [];
    const average = value.sum / value.count;
    return [{
      country_name: country.name,
      weather_type: average <= 15 ? "Cold" : average >= 25 ? "Hot" : "Warm"
    }];
  });
}

from collections import defaultdict
from datetime import date

def classify(countries, weather):
    start, end = date(2019, 11, 1), date(2019, 12, 1)
    stats = defaultdict(lambda: [0, 0])
    for country_id, state, day in weather:
        parsed = date.fromisoformat(day)
        if start <= parsed < end:
            stats[country_id][0] += state
            stats[country_id][1] += 1

    answer = []
    for country_id, name in countries:
        if country_id not in stats:
            continue
        total, count = stats[country_id]
        average = total / count
        kind = "Cold" if average <= 15 else "Hot" if average >= 25 else "Warm"
        answer.append({"country_name": name, "weather_type": kind})
    return answer

#include <iostream>
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

struct Country { int id; string name; };
struct Weather { int countryId; int state; string day; };

vector<pair<string, string>> classify(const vector<Country>& countries,
                                            const vector<Weather>& weather) {
    unordered_map<int, pair<long long, int>> stats;
    for (const auto& row : weather) {
        if (row.day >= "2019-11-01" && row.day < "2019-12-01") {
            stats[row.countryId].first += row.state;
            stats[row.countryId].second++;
        }
    }
    vector<pair<string, string>> answer;
    for (const auto& country : countries) {
        if (!stats.count(country.id)) continue;
        auto [sum, count] = stats[country.id];
        double average = static_cast<double>(sum) / count;
        string kind = average <= 15 ? "Cold" : average >= 25 ? "Hot" : "Warm";
        answer.push_back({country.name, kind});
    }
    return answer;
}

替代方案

可先在子查询或 CTE 中按 country_id 聚合，再连接 Countries。它能避免在 GROUP BY 中携带名称，层次也更清晰；本题直接连接后聚合已经足够简洁。

常见错误

  • 用 MONTH(day)=11 却忘记限制年份，并可能让普通索引失效。
  • 把边界写成 < 15 或 > 25，误判恰好 15/25。
  • 先对所有月份求平均，再试图过滤日期。
  • 用整数除法手算平均值，丢失小数部分。
  • 无意使用左连接，输出了目标月份无记录的国家。
