数组归约运算

让一个累加值从左到右穿过数组：每遇到一个元素，就由 reducer 函数生成新的累加值。

2626 EASY Array Reduce Transformation 免费题

Problem

题目描述

给定整数数组 nums、reducer 函数 fn 和初始值 init。依次处理数组中的每个元素，每一步都把上一步结果和当前元素交给 fn，最终返回最后一次计算所得的值。

形式化地说：先计算 val = fn(init, nums[0])，随后计算 val = fn(val, nums[1])、val = fn(val, nums[2])……直到所有元素处理完毕。 若数组为空，直接返回 init。不得使用内置的 Array.reduce。

函数签名： reduce(nums: number[], fn: (accum, curr) => number, init: number): number

  • 0 <= nums[i] <= 1000
  • 0 <= init <= 1000

先自己想一遍：哪个变量应该跨迭代保存状态？

Solution

题解

核心洞察

只需一个变量保存“截至当前位置的结果”。它从 init 开始；每访问一个元素，就以 fn(result, nums[i]) 覆盖自己。循环结束时，它恰好是完整数组的归约结果。

完整过程

  1. 令 result = init。
  2. 从左到右遍历 nums。
  3. 执行 result = fn(result, nums[i])。
  4. 遍历结束后返回 result。

正确性

循环开始前，result 是零个元素的归约值 init。假设处理前 i 个元素后它是正确归约值；处理 nums[i] 时，赋值严格执行题目规定的下一步 fn(result, nums[i])，所以不变式继续成立。处理全部元素后，返回值就是题目定义的最终值。

边界与复杂度

  • 空数组：循环不执行，返回 init。
  • 单元素：只调用一次 fn(init, nums[0])。
  • 时间复杂度：O(n)（视单次 fn 为 O(1)）。
  • 额外空间：O(1)。

四种语言实现

本题官方提交语言为 JavaScript / TypeScript；下方 Java、Python、C++ 版本用于表达相同的本地语义，不能直接套用到该题的在线提交入口。

JavaScript 官方可提交 
/**
 * @param {number[]} nums
 * @param {Function} fn
 * @param {number} init
 * @return {number}
 */
var reduce = function (nums, fn, init) {
  let result = init;

  for (const value of nums) {
    result = fn(result, value);
  }

  return result;
};
Java 本地语义参考 
import java.util.function.IntBinaryOperator;

class Solution {
    public int reduce(
        int[] nums,
        IntBinaryOperator fn,
        int init
    ) {
        int result = init;

        for (int value : nums) {
            result = fn.applyAsInt(result, value);
        }

        return result;
    }
}

C++ 本地语义参考 
#include <functional>
#include <vector>

class Solution {
public:
    int reduce(
        const std::vector<int>& nums,
        const std::function<int(int, int)>& fn,
        int init
    ) {
        int result = init;

        for (int value : nums) {
            result = fn(result, value);
        }

        return result;
    }
};

替代方案

  • 内置 Array.reduce：一行即可完成，但题目明确禁止。
  • 递归：能表达相同定义，却需要 O(n) 调用栈，长数组还有栈溢出风险。
  • 生成中间数组：没有必要；最终只需要一个累加值。

面试追问

  • 若不给 init，空数组该如何处理？
  • 归约能否并行？需要 fn 满足哪些结合性条件？
  • 如何实现带索引或可提前终止的 reducer？
  • 若 fn 抛出异常，应该传播、包装还是跳过？

常见错误

  • 把累加值初始化为 0，忽略传入的 init。
  • 调用 fn(nums[i], result)，颠倒参数顺序。
  • 忘记将 fn 的返回值写回累加变量。
  • 空数组时调用 fn 或访问 nums[0]。
  • 直接使用被题目禁止的 Array.reduce。

一句话记忆

result 代表“已经处理完的前缀”，把当前元素交给 fn 后，前缀就向右扩展一格。
