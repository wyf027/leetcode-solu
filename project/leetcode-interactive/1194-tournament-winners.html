Problem brief

题意与数据契约

给出球员所属小组与已完成比赛的双方得分。计算每位球员的累计得分；每组累计分最高者获胜，同分时选择编号最小者。结果可按任意顺序返回。

Solution — spoiler area

把“比赛的两侧”折叠成同一种事实

核心洞察：先用 UNION ALL 把 first_player / first_score 与 second_player / second_score 统一为 (player_id, score)，再累计、排序、取每组第一名。必须保留重复得分事件，因此不能使用去重的 UNION。

完整过程

  1. 将每场比赛拆成两条球员得分事件。
  2. 以 Players 为全集左连接事件，保证从未出赛的球员也以 0 分参与。
  3. 按 group_id、player_id 聚合累计分。
  4. 每组按 total_score 降序、player_id 升序编号。
  5. 仅保留行号 1。

正确性

引理 1：展开后，每场比赛恰为双方各贡献一条、且数值等于其该场得分的事件。

引理 2：按球员求和得到其所有比赛得分之和；左连接使无事件者的和归零。

结论：组内排序首先最大化累计分，只有同分时才最小化 player_id，因此行号 1 恰是题目规定的唯一优胜者。

边界与复杂度

  • 无比赛的小组：全员 0 分，最小 player_id 胜。
  • 单人小组：该球员自然获胜。
  • 重复比分：UNION ALL 不会误删事件。
  • 若 P 为球员数、M 为比赛数，展开与聚合处理 O(P + M) 条量级记录；窗口排序最坏 O(P log P)，数据库可借助索引与分区执行优化。

替代方案与面试追问

可用相关子查询或反连接排除“分更高/同分编号更小”的对手，但通常比窗口函数更难读。若数据库不支持窗口函数，可在 totals 上做 NOT EXISTS。

追问：如何支持多轮实时更新？如何返回并列冠军？如何用索引优化？若一场允许跨组，应该按球员归属还是比赛分组校验？

常见错误

  • 使用 UNION，导致完全相同的得分事件被错误去重。
  • 只从 Matches 出发内连接，遗漏从未参赛但仍可能以 0 分获胜的球员。
  • 只按总分降序，不补 player_id ASC，使同分结果不确定。
  • 直接按 first_player 聚合，漏掉球员作为 second_player 出场时的得分。
  • 依赖非标准 GROUP BY 恰好挑中某一行，结果受执行计划影响。
MySQL 8+ · 官方可提交语言窗口函数
WITH score_events AS (
    SELECT first_player AS player_id, first_score AS score
    FROM Matches
    UNION ALL
    SELECT second_player AS player_id, second_score AS score
    FROM Matches
), totals AS (
    SELECT
        p.group_id,
        p.player_id,
        COALESCE(SUM(e.score), 0) AS total_score
    FROM Players AS p
    LEFT JOIN score_events AS e
        ON e.player_id = p.player_id
    GROUP BY p.group_id, p.player_id
), ranked AS (
    SELECT
        group_id,
        player_id,
        ROW_NUMBER() OVER (
            PARTITION BY group_id
            ORDER BY total_score DESC, player_id ASC
        ) AS place_no
    FROM totals
)
SELECT group_id, player_id
FROM ranked
WHERE place_no = 1;

import java.util.*;

public class TournamentWinners {
    record Player(int playerId, int groupId) {}
    record Match(int matchId, int firstPlayer, int secondPlayer,
                 int firstScore, int secondScore) {}

    public static Map<Integer, Integer> winners(
            List<Player> players, List<Match> matches) {
        Map<Integer, Long> score = new HashMap<>();
        for (Player p : players) score.put(p.playerId(), 0L);
        for (Match m : matches) {
            score.merge(m.firstPlayer(), (long) m.firstScore(), Long::sum);
            score.merge(m.secondPlayer(), (long) m.secondScore(), Long::sum);
        }

        Map<Integer, Integer> answer = new TreeMap<>();
        for (Player p : players) {
            Integer current = answer.get(p.groupId());
            if (current == null
                    || score.get(p.playerId()) > score.get(current)
                    || (score.get(p.playerId()).equals(score.get(current))
                        && p.playerId() < current)) {
                answer.put(p.groupId(), p.playerId());
            }
        }
        return answer;
    }
}
JavaScript · 本地语义参考Array → Array
function tournamentWinners(players, matches) {
  const score = new Map(players.map(({ player_id }) => [player_id, 0]));

  for (const match of matches) {
    score.set(match.first_player,
      (score.get(match.first_player) ?? 0) + match.first_score);
    score.set(match.second_player,
      (score.get(match.second_player) ?? 0) + match.second_score);
  }

  const best = new Map();
  for (const { player_id, group_id } of players) {
    const current = best.get(group_id);
    if (current === undefined ||
        score.get(player_id) > score.get(current) ||
        (score.get(player_id) === score.get(current) &&
         player_id < current)) {
      best.set(group_id, player_id);
    }
  }

  return [...best.entries()]
    .sort(([groupA], [groupB]) => groupA - groupB)
    .map(([group_id, player_id]) => ({ group_id, player_id }));
}

import pandas as pd

def tournament_winners(players: pd.DataFrame,
                       matches: pd.DataFrame) -> pd.DataFrame:
    first = matches[["first_player", "first_score"]].rename(
        columns={"first_player": "player_id", "first_score": "score"}
    )
    second = matches[["second_player", "second_score"]].rename(
        columns={"second_player": "player_id", "second_score": "score"}
    )
    events = pd.concat([first, second], ignore_index=True)
    totals = events.groupby("player_id", as_index=False)["score"].sum()

    board = players.merge(totals, on="player_id", how="left")
    board["score"] = board["score"].fillna(0)
    board = board.sort_values(
        ["group_id", "score", "player_id"],
        ascending=[True, False, True]
    )
    return board.drop_duplicates("group_id")[["group_id", "player_id"]]
C++ · 本地语义参考vector → map
#include <map>
#include <tuple>
#include <vector>
using namespace std;

struct Player { int playerId; int groupId; };
struct Match {
    int matchId, firstPlayer, secondPlayer, firstScore, secondScore;
};

map<int, int> tournamentWinners(
        const vector<Player>& players,
        const vector<Match>& matches) {
    map<int, long long> score;
    for (const auto& p : players) score[p.playerId] = 0;
    for (const auto& m : matches) {
        score[m.firstPlayer] += m.firstScore;
        score[m.secondPlayer] += m.secondScore;
    }

    map<int, int> best;
    for (const auto& p : players) {
        auto it = best.find(p.groupId);
        if (it == best.end() ||
            score[p.playerId] > score[it->second] ||
            (score[p.playerId] == score[it->second] &&
             p.playerId < it->second)) {
            best[p.groupId] = p.playerId;
        }
    }
    return best;
}
