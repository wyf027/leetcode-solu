最多可以参加的会议数目

每天只能赴一场会。面对不断开始、陆续截止的会议，你能把日程塞得多满？先读题，再亲手推进时间。

挑战：同一天有多个可选会议时，你会先参加哪一个？先形成直觉，题解会留到页面底部。
Problem

题目说明

给定二维数组 events，其中 events[i] = [startDayᵢ, endDayᵢ] 表示第 i 场会议可参加的日期区间。你可以在闭区间内任选一天参加该会议，但同一天最多参加一场。返回最多能参加的会议数量。

示例 1

输入：events = [[1,2],[2,3],[3,4]]
输出：3
解释：第 1、2、3 天分别参加三场会议，三场都能参加。

示例 2

输入：events = [[1,2],[2,3],[3,4],[1,2]]
输出：4

约束

  • 1 <= events.length <= 10⁵
  • events[i].length == 2
  • 1 <= startDayᵢ <= endDayᵢ <= 10⁵
函数形式
maxEvents(events: integer[][]): integer

Solution

截止日最早者优先

核心洞察：来到某一天时，在所有已经开始且尚未结束的会议中，优先参加结束日最早的一场。它最紧迫，同时为其余会议留下不小于其他选择的未来空间。

完整过程

  1. 按开始日升序排序全部会议，指针 i 指向下一个尚未加入的会议。
  2. 用最小堆保存当前可参加会议的结束日；堆顶就是最早截止者。
  3. 若堆为空，把当前日期直接跳到下一场会议的开始日，避免逐日空转。
  4. 加入所有 startDay <= day 的会议，移除所有 endDay < day 的过期会议。
  5. 弹出堆顶并参加，答案加一，日期推进一天；循环直至排序数组和堆都为空。

正确性说明

交换论证：设某天可参加的会议中 A 的结束日最早，而某个最优方案这天选择了 B。若 A 在该方案中从未参加，直接用 A 替换 B，数量不变。若 A 在更晚一天参加，则交换 A 与 B：A 能在今天参加；又因为 end(A) ≤ end(B)，B 也能占用原来 A 的更晚日期。交换后仍合法且总数不变。因此总存在一个最优方案在今天选择最早截止的会议。逐日应用即可得到全局最优。

边界与复杂度

  • 只有一场会议：会在其开始日被安排。
  • 大量会议同日起止：堆会选出其中一场，其余随后过期。
  • 日期跨度很大：堆为空时跳日，避免扫描所有空白日期。
  • 时间复杂度：O(n log n)，排序与每场会议一次入堆、出堆。
  • 空间复杂度：O(n)，最坏情况下堆保存全部会议。

替代方案与取舍

若日期上界很小，可以按天建立“当天开始的会议”桶，再配合最小堆，省去对开始日的排序；在本题上界 10⁵ 时可行，但依赖日期范围。也可使用并查集为按结束日排序的会议寻找下一个空闲日，复杂度近似 O(n log n)，但实现更绕。排序 + 最小堆最通用、最适合面试表达。

面试追问

  • 如果每天能参加 k 场，如何修改？每天最多从堆中弹出 k 个。
  • 如果会议有权重，当前贪心还成立吗？通常不成立，会转向动态规划或其他调度模型。
  • 为什么按开始日最早选不对？因为它没有保护即将截止的会议。
  • 如何输出具体安排？堆中保存 [endDay, eventId]，弹出时记录日期与编号。

常见错误

  • 把结束日等于今天的会议误删；过期条件应为 endDay < day。
  • 先选会议再把当天新开始的会议入堆，导致漏掉更紧迫者。
  • 堆为空时仍逐天递增，在日期范围扩展时产生无谓扫描。
  • 只按区间长度排序；短区间不等于更早截止。
Implementations

四种语言完整实现

四份代码都遵循同一条数据流：排序 → 入堆 → 清除过期 → 选择最早截止。

Java
import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int maxEvents(int[][] events) {
        Arrays.sort(events, (a, b) -> Integer.compare(a[0], b[0]));
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        int i = 0, day = 0, attended = 0;

        while (i < events.length || !minHeap.isEmpty()) {
            if (minHeap.isEmpty()) {
                day = Math.max(day, events[i][0]);
            }
            while (i < events.length && events[i][0] <= day) {
                minHeap.offer(events[i][1]);
                i++;
            }
            while (!minHeap.isEmpty() && minHeap.peek() < day) {
                minHeap.poll();
            }
            if (!minHeap.isEmpty()) {
                minHeap.poll();
                attended++;
                day++;
            }
        }
        return attended;
    }
}
JavaScript
class MinHeap {
    constructor() { this.data = []; }
    get size() { return this.data.length; }
    peek() { return this.data[0]; }
    push(value) {
        const a = this.data;
        a.push(value);
        let i = a.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (a[p] <= a[i]) break;
            [a[p], a[i]] = [a[i], a[p]];
            i = p;
        }
    }
    pop() {
        const a = this.data;
        const top = a[0];
        const last = a.pop();
        if (a.length) {
            a[0] = last;
            let i = 0;
            while (true) {
                let smallest = i;
                const left = i * 2 + 1;
                const right = left + 1;
                if (left < a.length && a[left] < a[smallest]) smallest = left;
                if (right < a.length && a[right] < a[smallest]) smallest = right;
                if (smallest === i) break;
                [a[i], a[smallest]] = [a[smallest], a[i]];
                i = smallest;
            }
        }
        return top;
    }
}

/**
 * @param {number[][]} events
 * @return {number}
 */
var maxEvents = function(events) {
    events.sort((a, b) => a[0] - b[0]);
    const heap = new MinHeap();
    let i = 0, day = 0, attended = 0;

    while (i < events.length || heap.size) {
        if (!heap.size) day = Math.max(day, events[i][0]);
        while (i < events.length && events[i][0] <= day) {
            heap.push(events[i][1]);
            i++;
        }
        while (heap.size && heap.peek() < day) heap.pop();
        if (heap.size) {
            heap.pop();
            attended++;
            day++;
        }
    }
    return attended;
};

from typing import List
import heapq

class Solution:
    def maxEvents(self, events: List[List[int]]) -> int:
        events.sort()
        min_heap = []
        i = 0
        day = 0
        attended = 0

        while i < len(events) or min_heap:
            if not min_heap:
                day = max(day, events[i][0])

            while i < len(events) and events[i][0] <= day:
                heapq.heappush(min_heap, events[i][1])
                i += 1

            while min_heap and min_heap[0] < day:
                heapq.heappop(min_heap)

            if min_heap:
                heapq.heappop(min_heap)
                attended += 1
                day += 1

        return attended

#include <algorithm>
#include <functional>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    int maxEvents(vector<vector<int>>& events) {
        sort(events.begin(), events.end());
        priority_queue<int, vector<int>, greater<int>> minHeap;
        int i = 0, day = 0, attended = 0;

        while (i < static_cast<int>(events.size()) || !minHeap.empty()) {
            if (minHeap.empty()) {
                day = max(day, events[i][0]);
            }
            while (i < static_cast<int>(events.size()) &&
                   events[i][0] <= day) {
                minHeap.push(events[i][1]);
                ++i;
            }
            while (!minHeap.empty() && minHeap.top() < day) {
                minHeap.pop();
            }
            if (!minHeap.empty()) {
                minHeap.pop();
                ++attended;
                ++day;
            }
        }
        return attended;
    }
};
