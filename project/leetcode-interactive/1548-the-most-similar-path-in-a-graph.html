图中最相似的路径

The Most Similar Path in a Graph

图数组字符串动态规划

在一张带城市名的无向连通图中，寻找一段与目标名称序列长度相同的合法行程。目标不是走得最短，而是让每个位置上的城市名尽可能贴近目标序列。

Problem

题意

有 n 座城市，编号为 0..n-1。每条 roads[i] = [aᵢ, bᵢ] 表示两座城市之间存在一条双向道路；整张图保证连通。names[i] 是城市 i 的三字母大写名称，不同城市允许同名。

请返回一个长度等于 targetPath.length 的城市编号序列 ans。相邻的 ans[i] 与 ans[i+1] 必须有直接道路，城市可以重复经过。把路径对应的城市名逐项与 targetPath 比较，不相等的位置数就是编辑距离；要求该距离最小。若最优解不唯一，返回任意一个即可。

函数签名： mostSimilar(n, roads, names, targetPath) → List<Integer>

完整示例

示例 1
输入：
n = 5
roads = [[0,2],[0,3],[1,2],
         [1,3],[1,4],[2,4]]
names = ["ATL","PEK","LAX","DXB","HND"]
targetPath = ["ATL","DXB","HND","LAX"]

输出：[0,2,4,2]

名称路径为 [ATL,LAX,HND,LAX]，仅第 2 个位置不同，距离为 1。[0,3,0,2] 等也同样最优。

示例 2
输入：
n = 4
roads = [[1,0],[2,0],[3,0],
         [2,1],[3,1],[3,2]]
names = ["ATL","PEK","LAX","DXB"]
targetPath = ["ABC","DEF","GHI","JKL",
              "MNO","PQR","STU","VWX"]

输出：[0,1,0,1,0,1,0,1]

目标中的每个名称都不在图中，任何合法长度为 8 的路径距离均为 8。

示例 3
输入：
n = 6
roads = [[0,1],[1,2],[2,3],[3,4],[4,5]]
names = ["ATL","PEK","LAX",
         "ATL","DXB","HND"]
targetPath = ["ATL","DXB","HND","DXB",
              "ATL","LAX","PEK"]

输出：[3,4,5,4,3,2,1]

对应名称与目标完全一致，编辑距离为 0。

约束

  • 2 ≤ n ≤ 100
  • m == roads.length
  • n - 1 ≤ m ≤ n(n - 1) / 2
  • 0 ≤ aᵢ, bᵢ ≤ n - 1 且 aᵢ ≠ bᵢ
  • 图连通，任意点对之间至多一条直接道路
  • names.length == n
  • names[i].length == 3，仅含大写英文字母
  • 不同城市可以拥有相同名称
  • 1 ≤ targetPath.length ≤ 100
  • targetPath[i].length == 3，仅含大写英文字母

Editorial

分层图上的动态规划

核心洞察

路径长度已经由 targetPath 固定。走到目标序列第 i 个位置时，未来只关心“当前停在哪个城市”，不必记住此前具体走法。因此令 dp[i][v] 表示：匹配目标下标 0..i，且第 i 步停在城市 v 时的最少错位数。

dp[i][v] = mismatch(names[v], targetPath[i]) + min(dp[i-1][u])，其中 u 与 v 有道路相连

同时记录取得最小值的前驱 parent[i][v]。最后在 dp[last] 中选最小终点，沿前驱逆推并反转，即得到一条最优合法路径。

完整过程

  1. 用 roads 构建无向邻接表。
  2. 初始化第一层：dp[0][v] 只由城市名是否等于 targetPath[0] 决定，代价为 0 或 1。
  3. 从目标位置 1 向后扫描。对每个当前城市 v，枚举它的所有相邻城市 u，取上一层代价最小者，并记录 u。
  4. 在最后一层找到代价最小的城市作为终点。
  5. 按 parent 从后往前还原恰好 targetPath.length 个节点。

正确性证明

引理：对每个位置 i 和城市 v，dp[i][v] 等于所有长度为 i+1、终点为 v 的合法路径中的最小错位数。

证明：当 i=0 时，路径只含 v，初始化显然正确。假设结论对 i-1 成立。任何在第 i 步到达 v 的合法路径，其上一步必在某个邻居 u；根据归纳假设，该前缀最小代价为 dp[i-1][u]，再加当前位置是否错位的 0/1 代价。枚举全部邻居并取最小值，既不会遗漏合法前驱，也不会引入非法路径，故转移正确。

定理：最后一层枚举全部终点得到全局最小错位数；parent 保存的每一跳都对应真实道路，所以回溯所得路径合法且达到该最小值。

边界情况

  • 目标长度为 1：答案可从任意城市开始，选名称最匹配者。
  • 目标名均不存在：仍能返回合法路径，只是每一位都计错。
  • 城市同名：按节点编号分别参与状态，不可合并。
  • 最优解并列：任意前驱选择都合法。
  • 路径允许反复走同一条边或重复访问节点。

复杂度

设目标长度为 L，城市数为 n，道路数为 E。

  • 时间：O(L·(n+E))。每一层扫描所有节点及其邻接边。
  • 空间：O(L·n + E)，包括完整 DP、前驱和邻接表。
  • 若只求最小距离，可将 DP 降为 O(n)；但还原路径仍需保存前驱。

替代方案

可把每个状态看成分层图中的节点 (i,v)，跨层道路权重为当前名称的 0/1 错位代价，再求最短路。由于层只从前往后，按拓扑序做 DP 更直接，不需要 Dijkstra。

面试追问

  • 如果每个节点最多访问一次？ 原状态不足以判断“是否已访问”。通用做法需把已用节点集合加入状态（位掩码），复杂度变为指数级；在 n=100 时通常不可行，应继续询问图结构或规模是否有额外限制。
  • 能否输出字典序最小的最优编号序列？ 需要制定稳定的并列规则。可结合后缀最优代价，从前往后贪心选择仍可达全局最优的最小编号。
  • 错位代价不是 0/1 呢？ 将 mismatch 换成任意非负位置代价，转移结构不变。

常见错误

  • 把题目误解成传统字符串编辑距离；这里长度固定，只统计逐位置替换差异。
  • 只保留每一层的全局最小城市，丢掉其他终点状态，导致未来无法合法连接。
  • 忘记道路是双向的，或允许了没有直接道路的相邻答案节点。
  • 只计算最小代价却没有记录前驱，最后无法还原节点序列。
  • 假设城市名唯一；题目明确允许同名城市。

import java.util.*;

class Solution {
    public List<Integer> mostSimilar(int n, int[][] roads,
                                     String[] names, String[] targetPath) {
        List<Integer>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] road : roads) {
            graph[road[0]].add(road[1]);
            graph[road[1]].add(road[0]);
        }

        int length = targetPath.length;
        int[][] dp = new int[length][n];
        int[][] parent = new int[length][n];
        int inf = 1_000_000_000;
        for (int i = 0; i < length; i++) {
            Arrays.fill(dp[i], inf);
            Arrays.fill(parent[i], -1);
        }

        for (int city = 0; city < n; city++) {
            dp[0][city] = names[city].equals(targetPath[0]) ? 0 : 1;
        }

        for (int i = 1; i < length; i++) {
            for (int city = 0; city < n; city++) {
                int mismatch = names[city].equals(targetPath[i]) ? 0 : 1;
                for (int previous : graph[city]) {
                    int candidate = dp[i - 1][previous] + mismatch;
                    if (candidate < dp[i][city]) {
                        dp[i][city] = candidate;
                        parent[i][city] = previous;
                    }
                }
            }
        }

        int end = 0;
        for (int city = 1; city < n; city++) {
            if (dp[length - 1][city] < dp[length - 1][end]) end = city;
        }

        Integer[] path = new Integer[length];
        for (int i = length - 1; i >= 0; i--) {
            path[i] = end;
            end = parent[i][end];
        }
        return Arrays.asList(path);
    }
}

from typing import List


class Solution:
    def mostSimilar(
        self,
        n: int,
        roads: List[List[int]],
        names: List[str],
        targetPath: List[str],
    ) -> List[int]:
        graph = [[] for _ in range(n)]
        for a, b in roads:
            graph[a].append(b)
            graph[b].append(a)

        length = len(targetPath)
        infinity = 10**9
        dp = [[infinity] * n for _ in range(length)]
        parent = [[-1] * n for _ in range(length)]

        for city in range(n):
            dp[0][city] = 0 if names[city] == targetPath[0] else 1

        for i in range(1, length):
            for city in range(n):
                mismatch = 0 if names[city] == targetPath[i] else 1
                for previous in graph[city]:
                    candidate = dp[i - 1][previous] + mismatch
                    if candidate < dp[i][city]:
                        dp[i][city] = candidate
                        parent[i][city] = previous

        end = min(range(n), key=lambda city: dp[-1][city])
        path = [0] * length
        for i in range(length - 1, -1, -1):
            path[i] = end
            end = parent[i][end]
        return path
#include <algorithm>
#include <limits>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> mostSimilar(int n, vector<vector<int>>& roads,
                            vector<string>& names,
                            vector<string>& targetPath) {
        vector<vector<int>> graph(n);
        for (const auto& road : roads) {
            graph[road[0]].push_back(road[1]);
            graph[road[1]].push_back(road[0]);
        }

        const int length = static_cast<int>(targetPath.size());
        const int inf = numeric_limits<int>::max() / 4;
        vector<vector<int>> dp(length, vector<int>(n, inf));
        vector<vector<int>> parent(length, vector<int>(n, -1));

        for (int city = 0; city < n; ++city) {
            dp[0][city] = names[city] == targetPath[0] ? 0 : 1;
        }

        for (int i = 1; i < length; ++i) {
            for (int city = 0; city < n; ++city) {
                int mismatch = names[city] == targetPath[i] ? 0 : 1;
                for (int previous : graph[city]) {
                    int candidate = dp[i - 1][previous] + mismatch;
                    if (candidate < dp[i][city]) {
                        dp[i][city] = candidate;
                        parent[i][city] = previous;
                    }
                }
            }
        }

        int end = static_cast<int>(
            min_element(dp.back().begin(), dp.back().end()) - dp.back().begin()
        );
        vector<int> path(length);
        for (int i = length - 1; i >= 0; --i) {
            path[i] = end;
            end = parent[i][end];
        }
        return path;
    }
};
