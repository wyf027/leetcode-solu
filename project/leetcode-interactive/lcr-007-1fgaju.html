三数之和

先排序，再固定第一个数，用一对收缩的指针寻找剩余两数。命中后跳过相同值，答案自然不重复。

LCR 007排序 + 双指针O(n²)

题意

所有和为零且不重复的三元组

给定整数数组 nums，找出所有 [nums[i], nums[j], nums[k]] 使三数之和为 0。答案中不能有重复三元组。

输入

[-1,0,1,2,-1,-4]

输出

[[-1,-1,2],[-1,0,1]]

三条规则

  1. 1. 排序后相同数字相邻，才能跳重。
  2. 2. 固定 i，只在右侧搜索。
  3. 3. 和小就左移，和大就右移；命中后两端都跳过重复值。

为何排序

单调性让双指针不遗漏

固定 nums[i] 后，数组有序。若三数和偏小，右移 left 必然增大和；若偏大，左移 right 必然减小和。每一次移动都排除一批不可能组合，因此一轮扫描是线性的。

去重位置

外层遇到与前一个相同的固定值直接跳过。找到答案后，left 和 right 各自跨过连续重复值。三处去重共同保证每组值只输出一次。

时间
O(n²)
额外空间（不含输出）
O(log n) ~ O(n)

排序后枚举 i。每个 i 通过 left/right 一次线性扫描寻找 -nums[i] 的两数和；命中时写入答案并跨过相同值。

class Solution { public List<List<Integer>> threeSum(int[] a) { Arrays.sort(a); List<List<Integer>> ans=new ArrayList<>(); for(int i=0;i<a.length-2;i++){ if(i>0 && a[i]==a[i-1]) continue; int l=i+1,r=a.length-1; while(l<r){ long sum=(long)a[i]+a[l]+a[r]; if(sum<0)l++; else if(sum>0)r--; else { ans.add(Arrays.asList(a[i],a[l],a[r])); while(l<r && a[l]==a[l+1])l++; while(l<r && a[r]==a[r-1])r--; l++;r--; } } } return ans; } }

Python

class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort(); ans = []
        for i, x in enumerate(nums[:-2]):
            if i and x == nums[i-1]: continue
            l, r = i + 1, len(nums) - 1
            while l < r:
                total = x + nums[l] + nums[r]
                if total < 0: l += 1
                elif total > 0: r -= 1
                else:
                    ans.append([x, nums[l], nums[r]])
                    while l < r and nums[l] == nums[l+1]: l += 1
                    while l < r and nums[r] == nums[r-1]: r -= 1
                    l, r = l + 1, r - 1
        return ans
