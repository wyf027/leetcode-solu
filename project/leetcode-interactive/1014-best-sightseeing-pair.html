最佳观光组合

Best Sightseeing Pair · 在距离惩罚下，为两个景点评分找到最划算的搭配。

问题

选两个不同的景点

给定正整数数组 values，values[i] 是第 i 个景点的评分。选择下标满足 i < j 的两个景点，它们的距离是 j - i。

组合得分等于两个景点评分之和减去距离，请返回所有合法组合中的最高分。

score(i, j) = values[i] + values[j] + i - j，且 i < j

示例 1

输入：values = [8,1,5,2,6]
输出：11
解释：i = 0, j = 2
      8 + 5 + 0 - 2 = 11

示例 2

输入：values = [1,2]
输出：2

约束

  • 2 <= values.length <= 5 × 10⁴
  • 1 <= values[i] <= 1000

独立题解

准备好后再展开

核心洞察

把公式拆成 (values[i] + i) + (values[j] - j)。当扫描到固定的右端 j 时，第二项已经确定；只需知道此前所有合法 i < j 中最大的 values[i] + i。因此一个变量就能概括整个左侧历史。

完整过程

  1. 用下标 0 初始化 bestLeft = values[0] + 0，答案初始化为 0。
  2. 令 j 从 1 扫描到数组末尾。
  3. 先用旧的 bestLeft 计算候选分数，保证左端下标严格小于右端。
  4. 更新全局答案。
  5. 最后再用当前位置更新 bestLeft，让它服务于后续右端。

正确性：左端不变量

处理右端 j 前，bestLeft 等于所有 0 ≤ i < j 中 values[i] + i 的最大值。初始化时集合只有下标 0；每轮结束把下标 j 纳入最大值，故不变量持续成立。

正确性：全局最优

对每个右端 j，算法用不变量选出该 j 对应的最佳左端，所以得到所有以 j 结尾组合的最高分。遍历所有 j 并取最大值，覆盖每个合法二元组，最终答案即全局最优。

边界

长度最小为 2，初始化后至少执行一轮。所有值为正，因此用 0 初始化答案是安全的；若题目允许负数，应初始化为负无穷或首个合法组合。

复杂度

时间 O(n)：每个景点访问一次。额外空间 O(1)：只维护两个标量。

替代方案

枚举所有 i,j 是 O(n²)，在 5×10⁴ 规模会超时。也可写前缀最大值数组，但会多用 O(n) 空间。

面试追问

  • 为什么必须先计算候选答案，再更新 bestLeft？否则可能让 i = j，违反题意。
  • 若距离惩罚改成 k × (j-i)？拆成 values[i]+k·i 与 values[j]-k·j，结构不变。
  • 如何返回下标？维护最佳左端贡献对应的索引，并在答案改善时记录左右下标。

常见错误

把公式符号写反；允许当前位置同时充当左右端；只比较相邻景点；每轮重新扫描左侧；答案更新后忘记更新左端贡献。

class Solution {
    public int maxScoreSightseeingPair(int[] values) {
        int bestLeft = values[0];
        int answer = 0;
        for (int j = 1; j < values.length; j++) {
            answer = Math.max(answer, bestLeft + values[j] - j);
            bestLeft = Math.max(bestLeft, values[j] + j);
        }
        return answer;
    }
}
