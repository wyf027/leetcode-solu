区间加法 IIRange Addition II

在一个初始全为零的矩阵上，连续执行若干次“左上角矩形加一”操作。你的任务不是还原整张矩阵，而是计算最终最大整数一共出现了多少次。

m × n 矩阵 前缀矩形 返回整数

Problem

题目说明

准确转述

给定一个 m × n 的矩阵 M，所有单元格初始均为 0。操作数组中的每个元素 ops[i] = [aᵢ, bᵢ] 表示：对所有满足 0 ≤ x < aᵢ 且 0 ≤ y < bᵢ 的单元格 M[x][y] 加一。

依次完成全部操作后，返回矩阵中等于最终最大整数的单元格数量。

函数形式：maxCount(m, n, ops) → integer

约束

  • 1 ≤ m, n ≤ 4 × 10⁴
  • 0 ≤ ops.length ≤ 10⁴
  • ops[i].length = 2
  • 1 ≤ aᵢ ≤ m
  • 1 ≤ bᵢ ≤ n

输入
m = 3, n = 3,
ops = [[2,2],[3,3]]
输出
4

Complete Solution

完整题解

核心洞察：最大值只会出现在所有矩形的交集

每次操作都从左上角 (0, 0) 开始。一个格子要取得全局最大值，就必须被每一次操作覆盖。所有前缀矩形的公共部分仍是一个左上角矩形，其高是全部 aᵢ 的最小值，宽是全部 bᵢ 的最小值。

rows = min(m, a₁, a₂, ...)
cols = min(n, b₁, b₂, ...)
answer = rows × cols

完整过程

  1. 用 minRow = m、minCol = n 表示当前公共覆盖区域。
  2. 遍历每个操作 [a, b]，分别收缩行上界与列上界。
  3. 遍历结束后，公共区域包含 minRow × minCol 个格子，直接返回该乘积。
  4. 若 ops 为空，两个初值保持为 m 和 n，自然得到整张矩阵的格子数。

边界情况

  • 没有操作：所有格子都是最大值 0，答案为 m × n。
  • 操作覆盖整张矩阵：它不会缩小公共区域。
  • 某个维度为 1：公共区域可能退化为单行、单列或单格，公式仍成立。
  • 大量重复操作：最小边界不变，无需去重。

正确性证明

最大值的含义。若共有 k 次操作，一个格子最多被加一 k 次；被每次操作都覆盖的格子恰好得到值 k，因此它们一定取到最大值。
交集的形状。第 i 个操作覆盖 [0, aᵢ) × [0, bᵢ)。这些区域的交集为 [0, min aᵢ) × [0, min bᵢ)。
交集外不可能取最大值。任意交集外的格子至少漏掉一次操作，所以其值至多为 k - 1，严格小于交集内格子的值 k。
计数。交集矩形共有 minRow 行、minCol 列，所以最大整数的个数正是二者乘积。无操作时整张矩阵都为 0，初始化边界同样返回 m × n。故算法正确。

复杂度

  • 时间：O(k)，其中 k = ops.length。
  • 额外空间：O(1)。
  • 不创建矩阵，因此不会受到 m × n 最多 16 亿个格子的影响。

替代方案与取舍

  • 直接模拟：对每次操作逐格加一，最坏接近 O(kmn)，时间和空间都不可接受。
  • 二维差分：能高效执行矩形加法，但仍需保存或扫描 m × n 规模的数据；本题只问最大值个数，属于过度设计。
  • 排序边界：可以排序后取最小值，但会增加到 O(k log k)，没有必要。

Javaint maxCount(int m, int n, int[][] ops)
class Solution {
    public int maxCount(int m, int n, int[][] ops) {
        int minRow = m;
        int minCol = n;

        for (int[] op : ops) {
            minRow = Math.min(minRow, op[0]);
            minCol = Math.min(minCol, op[1]);
        }

        return minRow * minCol;
    }
}

面试追问

  • 如果要返回最大值区域坐标？返回左上角 (0,0) 与右下角的开区间边界 (minRow,minCol)。
  • 如果操作是任意矩形？公共交集不一定从原点开始；若仍只问被所有操作覆盖的区域，可维护四条交集边界。
  • 如果要查询每个值的出现次数？仅维护最小边界不够，需考虑二维差分、坐标压缩或扫描线。
  • 如果操作在线到达？持续更新两个最小值，每次都可在 O(1) 时间返回当前答案。

常见错误

  • 误把答案写成所有 aᵢ × bᵢ 的最小值；行最小值与列最小值可能来自不同操作，必须分别求最小值后相乘。
  • 在 ops 为空时返回 0；此时最大值为 0，且出现 m × n 次。
  • 真的创建完整矩阵，忽略 m,n ≤ 40000 带来的空间上限。
  • 把操作范围误写成含右边界；题目使用的是 x < aᵢ、y < bᵢ。
