Problem

题目说明

给定变量对数组 equations 与实数数组 values。其中 equations[i] = [Ai, Bi]、values[i] 表示已知关系 Ai / Bi = values[i]；变量由字符串表示。

另给查询数组 queries，每个 queries[j] = [Cj, Dj] 要求计算 Cj / Dj。返回全部查询的结果；若结果无法由已知条件确定，则返回 -1.0。

输入保证有效：不会发生除数为零，也不存在相互矛盾的已知关系。没有在任何等式中出现过的变量视为未定义——即使查询形式是它除以自身，也应返回 -1.0。

calcEquation(equations, values, queries) → double[] / number[] / List[float]

示例 1

输入：equations = [["a","b"],["b","c"]], values = [2.0,3.0], queries = [["a","c"],["b","a"],["a","e"],["a","a"],["x","x"]]
输出：[6.00000,0.50000,-1.00000,1.00000,-1.00000]

已知 a / b = 2、b / c = 3。x 未定义，因此 x / x 也无法确定。

示例 2

输入：equations = [["a","b"],["b","c"],["bc","cd"]], values = [1.5,2.5,5.0], queries = [["a","c"],["c","b"],["bc","cd"],["cd","bc"]]
输出：[3.75000,0.40000,5.00000,0.20000]

示例 3

输入：equations = [["a","b"]], values = [0.5], queries = [["a","b"],["b","a"],["a","c"],["x","y"]]
输出：[0.50000,2.00000,-1.00000,-1.00000]

约束

  • 1 <= equations.length <= 20
  • equations[i].length == 2
  • 1 <= Ai.length, Bi.length <= 5
  • values.length == equations.length
  • 0.0 < values[i] <= 20.0
  • 1 <= queries.length <= 20
  • queries[i].length == 2
  • 1 <= Cj.length, Dj.length <= 5
  • 变量名只含小写英文字母与数字

Solution

加权图 + 深度优先搜索

核心洞察

等式 a / b = k 同时给出两条有向边：a → b 的权重是 k，b → a 的权重是 1 / k。一条从分子到分母的路径，其边权乘积就是所求比值。

完整过程

  1. 遍历全部等式，构造双向加权邻接表。
  2. 对每个查询，先判断两个变量是否都存在。
  3. 从分子开始 DFS；沿边递乘权重，并用集合防止重复访问。
  4. 到达分母时返回累计乘积；搜索结束仍未到达则返回 -1.0。

正确性证明

引理 1：图中每条有向边 u → v 的权重都等于 u / v。正向边由输入直接保证，反向边则为其倒数。

引理 2：对任意路径 x = p0 → p1 → … → pk = y，沿路边权之积等于 x / y。相邻项会依次约去：(p0/p1) × (p1/p2) × … × (p{k-1}/pk) = p0/pk。

结论：若 DFS 到达目标，它返回的累计乘积由引理 2 可知就是正确比值；若 DFS 遍历起点所在连通分量仍未到达目标，则图中不存在对应路径，已知关系不能确定该比值，返回 -1.0 正确。

边界情况

  • 任一变量未定义：返回 -1.0。
  • 两个已定义变量相同：立即得到 1.0。
  • 变量存在但位于不同连通分量：返回 -1.0。
  • 用访问集合处理环，避免无限递归。

复杂度

设变量数为 V、等式数为 E、查询数为 Q。建图时间与空间均为 O(E)；单次 DFS 最坏 O(V + E)，全部查询为 O(Q(V + E))；单次搜索额外空间 O(V)。

替代方案

BFS：与 DFS 同复杂度，更易改造成迭代式。带权并查集：适合大量在线查询，可把查询降到近似常数时间，但维护父节点比例更易出错。Floyd：变量很少时可预计算所有可达比值，时间 O(V³)。

面试追问

  • 若等式持续在线加入，怎样用带权并查集维护比例？
  • 若输入可能矛盾，怎样检测闭环乘积不为 1？
  • 若路径很长，如何讨论浮点误差或用对数域计算？

常见错误

  • 只添加正向边，导致逆向查询失败。
  • 把未知变量的 x / x 错判为 1；必须先确认 x 出现过。
  • 复用同一个访问集合而不为每次查询重置，错误屏蔽后续搜索。
  • 找到目标后忘记返回当前累计乘积，或在回溯时重复相乘。
JavaDFS · 邻接表
class Solution {
    private static class Edge {
        String to;
        double weight;

        Edge(String to, double weight) {
            this.to = to;
            this.weight = weight;
        }
    }

    public double[] calcEquation(List<List<String>> equations,
                                 double[] values,
                                 List<List<String>> queries) {
        Map<String, List<Edge>> graph = new HashMap<>();

        for (int i = 0; i < equations.size(); i++) {
            String a = equations.get(i).get(0);
            String b = equations.get(i).get(1);
            graph.computeIfAbsent(a, key -> new ArrayList<>())
                 .add(new Edge(b, values[i]));
            graph.computeIfAbsent(b, key -> new ArrayList<>())
                 .add(new Edge(a, 1.0 / values[i]));
        }

        double[] answer = new double[queries.size()];
        for (int i = 0; i < queries.size(); i++) {
            String source = queries.get(i).get(0);
            String target = queries.get(i).get(1);
            if (!graph.containsKey(source) || !graph.containsKey(target)) {
                answer[i] = -1.0;
            } else {
                answer[i] = dfs(source, target, 1.0, graph, new HashSet<>());
            }
        }
        return answer;
    }

    private double dfs(String current, String target, double product,
                       Map<String, List<Edge>> graph, Set<String> visited) {
        if (current.equals(target)) return product;
        visited.add(current);

        for (Edge edge : graph.get(current)) {
            if (visited.contains(edge.to)) continue;
            double result = dfs(edge.to, target, product * edge.weight,
                                graph, visited);
            if (result != -1.0) return result;
        }
        return -1.0;
    }
}

/**
 * @param {string[][]} equations
 * @param {number[]} values
 * @param {string[][]} queries
 * @return {number[]}
 */
var calcEquation = function(equations, values, queries) {
    const graph = new Map();

    const addEdge = (from, to, weight) => {
        if (!graph.has(from)) graph.set(from, []);
        graph.get(from).push([to, weight]);
    };

    for (let i = 0; i < equations.length; i++) {
        const [a, b] = equations[i];
        addEdge(a, b, values[i]);
        addEdge(b, a, 1 / values[i]);
    }

    const dfs = (current, target, product, visited) => {
        if (current === target) return product;
        visited.add(current);

        for (const [next, weight] of graph.get(current)) {
            if (visited.has(next)) continue;
            const result = dfs(next, target, product * weight, visited);
            if (result !== -1.0) return result;
        }
        return -1.0;
    };

    return queries.map(([source, target]) => {
        if (!graph.has(source) || !graph.has(target)) return -1.0;
        return dfs(source, target, 1.0, new Set());
    });
};
Python 3DFS · 邻接表
from collections import defaultdict
from typing import List


class Solution:
    def calcEquation(
        self,
        equations: List[List[str]],
        values: List[float],
        queries: List[List[str]],
    ) -> List[float]:
        graph = defaultdict(list)

        for (a, b), value in zip(equations, values):
            graph[a].append((b, value))
            graph[b].append((a, 1.0 / value))

        def dfs(current: str, target: str, product: float, visited: set) -> float:
            if current == target:
                return product

            visited.add(current)
            for neighbor, weight in graph[current]:
                if neighbor in visited:
                    continue
                result = dfs(neighbor, target, product * weight, visited)
                if result != -1.0:
                    return result
            return -1.0

        answer = []
        for source, target in queries:
            if source not in graph or target not in graph:
                answer.append(-1.0)
            else:
                answer.append(dfs(source, target, 1.0, set()))
        return answer
C++DFS · 邻接表
class Solution {
    using Edge = pair<string, double>;
    unordered_map<string, vector<Edge>> graph;

    double dfs(const string& current, const string& target,
               double product, unordered_set<string>& visited) {
        if (current == target) return product;
        visited.insert(current);

        for (const auto& [next, weight] : graph[current]) {
            if (visited.count(next)) continue;
            double result = dfs(next, target, product * weight, visited);
            if (result != -1.0) return result;
        }
        return -1.0;
    }

public:
    vector<double> calcEquation(vector<vector<string>>& equations,
                                vector<double>& values,
                                vector<vector<string>>& queries) {
        for (int i = 0; i < static_cast<int>(equations.size()); i++) {
            const string& a = equations[i][0];
            const string& b = equations[i][1];
            graph[a].push_back({b, values[i]});
            graph[b].push_back({a, 1.0 / values[i]});
        }

        vector<double> answer;
        answer.reserve(queries.size());
        for (const auto& query : queries) {
            const string& source = query[0];
            const string& target = query[1];
            if (!graph.count(source) || !graph.count(target)) {
                answer.push_back(-1.0);
                continue;
            }
            unordered_set<string> visited;
            answer.push_back(dfs(source, target, 1.0, visited));
        }
        return answer;
    }
};
