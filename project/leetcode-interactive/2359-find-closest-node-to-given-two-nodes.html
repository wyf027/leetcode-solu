找到离给定两个节点
最近的节点

Find Closest Node to Given Two Nodes

两个起点，同一个目的地。你要照顾的，是走得更远的那个人。

在双方都可到达的节点中，让两段距离的较大值尽可能小；并列时，选编号更小的节点。

先理解目标，再自行推演。完整解法与四语言代码收在页面底部。

01 / PROBLEM

题意与输入约定

给定 n 个节点，编号为 0 到 n − 1。数组 edges 描述有向边：edges[i] 是节点 i 指向的下一个节点；值为 −1 表示无出边。每个节点最多有一条出边，图中可能存在环。

另给两个起点 node1、node2。返回双方都能沿有向边到达的某个节点编号，使 max(从 node1 到它的最短距离, 从 node2 到它的最短距离) 最小。若最优节点不唯一，返回编号最小者；无共同可达节点时返回 −1。距离按经过的边数计，起点到自身为 0。

官方示例 1

edges = [2,2,3,-1], node1 = 0, node2 = 1
输出：2
结构：0 → 2 → 3
      1 ↗

到节点 2 的距离分别为 1、1，较大值为 1；节点 3 的较大值为 2，因此返回 2。

官方示例 2

edges = [1,2,-1], node1 = 0, node2 = 2
输出：2
结构：0 → 1 → 2

到节点 2 的距离分别为 2、0，较大值为 2。它是唯一共同可达节点。

完整约束

  • n == edges.length
  • 2 ≤ n ≤ 10⁵
  • −1 ≤ edges[i] < n
  • edges[i] != i（无自环，但可有多节点环）
  • 0 ≤ node1, node2 < n

04 / SOLUTION

推导与实现

核心洞察：每个起点只有一条前进路线

因为每个节点至多一条出边，从一个起点出发没有分支可选。顺着 edges 行走，第一次到达节点时走过的边数就是最短距离。遇到 −1 或已经访问过的节点就停止；再次绕环不会获得更短距离。

完整过程

  1. 建立两个长度为 n 的距离数组 d1、d2，初始都为 −1。
  2. 从 node1 出发，起点距离为 0；每前进一步距离加 1。仅在当前节点有效且未访问时记录。得到 d1。
  3. 用完全独立的距离数组从 node2 再走一次，得到 d2。
  4. 按编号 0 到 n − 1 扫描，只考虑两侧距离都非 −1 的节点。计算 score = max(d1[i], d2[i])。
  5. 只有 score 严格小于当前最佳值才更新答案；同分不更新，因此保留更小编号。若从未更新，返回 −1。

正确性论证

距离正确：起点首次记录为 0。若当前节点首次到达的距离为 k，沿唯一出边到达的新节点距离为 k + 1；不存在另一条更短的分支路线。重复节点后的路线已走过，停止不会遗漏新节点。因此数组记录所有可达节点的最短距离，不可达节点保持 −1。

候选完整：同时具有两侧距离的节点恰是共同可达节点。遍历全部编号不会遗漏可行答案。

选择最优：扫描任意前缀后，当前答案是此前可行节点中得分最小且编号最小者。新得分更小时替换，否则保持；升序扫描使同分时已有答案编号更小。不变式在扫描结束时给出全局答案；没有候选则保持 −1。

边界与复杂度

  • 起点相同：该起点得分为 0，直接满足全局最优。
  • 图含环：每次行走必须独立判重；不能无限追踪 edges。
  • 无出边 / 图不连通：保留不可达标记并排除不完整候选。
  • 时间 O(n)：两次行走和一次扫描各最多 n 步。额外空间 O(n)：两个距离数组。迭代写法避免 10⁵ 层递归导致栈溢出。

替代方案

两次 BFS 也可求无权最短距离，时间和空间仍为 O(n)，但本题每个节点仅一个后继，队列可省。递归 DFS 可沿路线记录距离，但长链存在栈深风险。逐个候选重新走路径会退化为 O(n²)，无需采用。Dijkstra 适合非负加权图，本题单位边权不需要堆。

常见错误

  • 最小化距离之和，而非较大值。
  • 把第一次发现的共同节点立即返回：环上还可能有更优或同分小编号节点。
  • 忘记起点到自身的距离为 0，或把 −1 当成合法数组下标。
  • 两次遍历共用 visited，导致第二个起点的距离缺失。
  • 升序扫描时用 ≤ 更新答案，错误地保留同分大编号节点。

面试追问

允许多条出边？无权图使用两次 BFS，复杂度 O(V + E)。改成有非负边权？一般图使用两次 Dijkstra，再扫描共同可达节点。变成 k 个起点？分别求距离，只在所有起点可达时比较 k 个距离的最大值；本类单后继图直接方法为 O(kn) 时间，可逐轮累计最大距离与可达计数来控制空间。

Java

import java.util.Arrays;

class Solution {
    private int[] distances(int[] edges, int start) {
        int[] dist = new int[edges.length];
        Arrays.fill(dist, -1);
        int steps = 0;
        while (start != -1 && dist[start] == -1) {
            dist[start] = steps++;
            start = edges[start];
        }
        return dist;
    }

    public int closestMeetingNode(int[] edges, int node1, int node2) {
        int[] d1 = distances(edges, node1);
        int[] d2 = distances(edges, node2);
        int answer = -1, best = Integer.MAX_VALUE;
        for (int i = 0; i < edges.length; i++) {
            if (d1[i] == -1 || d2[i] == -1) continue;
            int score = Math.max(d1[i], d2[i]);
            if (score < best) {
                best = score;
                answer = i;
            }
        }
        return answer;
    }
}

class Solution:
    def closestMeetingNode(self, edges: List[int], node1: int, node2: int) -> int:
        def distances(start):
            dist = [-1] * len(edges)
            steps = 0
            while start != -1 and dist[start] == -1:
                dist[start] = steps
                steps += 1
                start = edges[start]
            return dist

        d1, d2 = distances(node1), distances(node2)
        answer, best = -1, float("inf")
        for i in range(len(edges)):
            if d1[i] == -1 or d2[i] == -1:
                continue
            score = max(d1[i], d2[i])
            if score < best:
                best, answer = score, i
        return answer

C++

#include <vector>
#include <algorithm>
#include <limits>
using namespace std;

class Solution {
public:
    int closestMeetingNode(vector<int>& edges, int node1, int node2) {
        auto distances = [&](int start) {
            vector<int> dist(edges.size(), -1);
            int steps = 0;
            while (start != -1 && dist[start] == -1) {
                dist[start] = steps++;
                start = edges[start];
            }
            return dist;
        };
        auto d1 = distances(node1), d2 = distances(node2);
        int answer = -1, best = numeric_limits<int>::max();
        for (int i = 0; i < static_cast<int>(edges.size()); ++i) {
            if (d1[i] == -1 || d2[i] == -1) continue;
            int score = max(d1[i], d2[i]);
            if (score < best) {
                best = score;
                answer = i;
            }
        }
        return answer;
    }
};
