单词规律
Word Pattern

一串字母与一组单词，能否形成严格的一一对应？先理解规则，再用交互演示逐步观察匹配过程。

简单 非付费题 pattern → word word → pattern
01 · Problem

题目描述

给定字符串 pattern 和字符串 s，判断 s 是否遵循 pattern 所表达的规律。

“遵循”要求完全匹配：pattern 中的每个字母必须对应 s 中一个非空单词，并且这种对应是双射。同一字母不能对应不同单词，不同字母也不能对应同一单词。

示例 1
输入
pattern = "abba"
s = "dog cat cat dog"
输出
true
说明
a ↔ dog，b ↔ cat，对应关系完整且唯一。
示例 2
输入
pattern = "abba"
s = "dog cat cat fish"
输出
false
示例 3
输入
pattern = "aaaa"
s = "dog cat cat dog"
输出
false

约束

  • 1 <= pattern.length <= 300
  • pattern 仅包含小写英文字母。
  • 1 <= s.length <= 3000
  • s 仅包含小写英文字母和空格。
  • s 没有前导或尾随空格；相邻单词恰好由一个空格分隔。

Core Insight

核心洞察：双射需要双向约束

只记录“字母对应哪个单词”还不够，因为两个不同字母可能偷偷指向同一个单词。使用两张哈希表，同时维护 字母 → 单词 与 单词 → 字母，即可在常数平均时间内检查两侧是否一致。

完整过程

  1. 按单个空格拆分 s，得到单词数组。
  2. 若字母数量与单词数量不同，无法逐位置完全匹配，立即返回 false。
  3. 从左到右取当前字母 c 和单词 w。
  4. 若任一方向已有映射且与当前配对不一致，返回 false；否则写入两张表。
  5. 扫描结束仍无冲突，返回 true。

正确性说明

不变式：处理完前 i 个位置后，两张表恰好记录这些位置形成的互逆、一致映射。

处理第 i + 1 对时，已有键必须复用原值；新键则同时写入两个方向。因此接受该配对后，不变式继续成立。若发现冲突，当前输入必然违反函数性或单射性，拒绝是正确的。所有位置处理完毕后，两侧元素一一对应，所以返回 true 正确。

边界与复杂度

  • 数量不等：先判断，避免越界和非完全匹配。
  • 重复字母：必须始终命中同一单词。
  • 重复单词：必须始终来自同一字母。
  • 最短输入：单个字母与单个单词自然成立。

时间复杂度：O(n + |s|)，拆词与扫描各一次；空间复杂度：O(n)，用于单词数组和映射。

替代方案

可给每个字母和每个单词记录“最近出现位置”，每一步比较两者的上次位置是否相同。若不同则模式不一致。该方案同样为线性时间，但双哈希表的语义更直观，面试中更容易解释双射约束。

常见错误

  • 只建单向映射，漏掉 a → dog, b → dog。
  • 忘记先比较长度。
  • 用映射值是否为假来判断键存在，混淆“未出现”和合法值。
  • 把整段字符串按字符而不是按单词处理。

面试追问

  • 能否只用一张表？ 若额外用集合约束已占用单词，本质上仍维护了反向信息；可以，但双向表更直接。
  • 若输入来自数据流？ 只要能同步读到字母与下一个单词，就可边读边检查；结束时还需确认两侧同时耗尽。
  • 若模式符号不止小写字母？ 算法不变，只需让映射键支持相应字符或记号类型。
  • 为什么不能排序后比较？ 排序会丢失位置关系，无法验证相同模式位置是否对应相同单词。
Implementations

四种语言完整代码

Java · 官方可提交签名双向 HashMap
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean wordPattern(String pattern, String s) {
        String[] words = s.split(" ");
        if (pattern.length() != words.length) {
            return false;
        }

        Map<Character, String> charToWord = new HashMap<>();
        Map<String, Character> wordToChar = new HashMap<>();

        for (int i = 0; i < pattern.length(); i++) {
            char letter = pattern.charAt(i);
            String word = words[i];

            if (charToWord.containsKey(letter)
                    && !charToWord.get(letter).equals(word)) {
                return false;
            }
            if (wordToChar.containsKey(word)
                    && wordToChar.get(word) != letter) {
                return false;
            }

            charToWord.put(letter, word);
            wordToChar.put(word, letter);
        }
        return true;
    }
}

/**
 * @param {string} pattern
 * @param {string} s
 * @return {boolean}

var wordPattern = function(pattern, s) {
    const words = s.split(" ");
    if (pattern.length !== words.length) {
        return false;
    }

    const charToWord = new Map();
    const wordToChar = new Map();

    for (let i = 0; i < pattern.length; i++) {
        const letter = pattern[i];
        const word = words[i];

        if (charToWord.has(letter) && charToWord.get(letter) !== word) {
            return false;
        }
        if (wordToChar.has(word) && wordToChar.get(word) !== letter) {
            return false;
        }

        charToWord.set(letter, word);
        wordToChar.set(word, letter);
    }
    return true;
};
Python 3 · 官方可提交签名双向 dict
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        words = s.split()
        if len(pattern) != len(words):
            return False

        char_to_word = {}
        word_to_char = {}

        for letter, word in zip(pattern, words):
            if letter in char_to_word and char_to_word[letter] != word:
                return False
            if word in word_to_char and word_to_char[word] != letter:
                return False

            char_to_word[letter] = word
            word_to_char[word] = letter

        return True
C++ · 官方可提交签名双向 unordered_map
class Solution {
public:
    bool wordPattern(string pattern, string s) {
        vector<string> words;
        string word;
        istringstream input(s);
        while (input >> word) {
            words.push_back(word);
        }

        if (pattern.size() != words.size()) {
            return false;
        }

        unordered_map<char, string> charToWord;
        unordered_map<string, char> wordToChar;

        for (int i = 0; i < pattern.size(); ++i) {
            char letter = pattern[i];
            const string& currentWord = words[i];

            if (charToWord.count(letter)
                    && charToWord[letter] != currentWord) {
                return false;
            }
            if (wordToChar.count(currentWord)
                    && wordToChar[currentWord] != letter) {
                return false;
            }

            charToWord[letter] = currentWord;
            wordToChar[currentWord] = letter;
        }
        return true;
    }
};
