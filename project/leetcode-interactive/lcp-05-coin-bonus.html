发 LeetCoin

把组织树压成一段连续区间：单人发币是一个点，整支团队发币和查账都是一段区间。

题意与约束

公司有 n 位编号为 1 到 n 的成员，leadership 的每条 [a,b] 表示 a 是 b 的直接上级。处理 operations：

  1. [1, x, y]：只给成员 x 发 y 枚币。
  2. [2, x, y]：给 x 与其全部下属各发 y 枚币。
  3. [3, x]：查询 x 与其全部下属当前币数之和。

所有查询结果按 1,000,000,007 取模。成员和操作数可达 50,000，逐个给下属发币会超时。

Euler Tour 把一棵树变成一段数组

  1. 1. 入、出时间

    DFS 先访问 x 时记录 tin[x]；处理完子树记录 tout[x]。x 的整棵子树恰好就是 [tin[x], tout[x]]。

  2. 2. 两棵 Fenwick 树

    区间加、区间求和可用差分前缀的双树状数组：在 L 加 v、R+1 加 -v。

  3. 3. 三种操作统一

    操作 1 是 [tin[x], tin[x]]；操作 2 和 3 都是 [tin[x], tout[x]]。

题解：DFS 序 + 双树状数组

树状数组不能直接做“区间加、区间和”。维护差分数组 d 后，原数组前缀为 sum(d)，区间和还需要位置加权。令 B1 存 d，B2 存 i·d，则前缀和 prefix(p) = (p + 1) · sum(B1,p) - sum(B2,p)。

给 [L,R] 加 v 时，在 d[L] 加 v、d[R+1] 减 v；两棵树都同步更新即可。查询 [L,R] 等于 prefix(R) - prefix(L-1)。每一步仅做常数次 Fenwick update/query。

正确性：DFS 序保证每个子树是连续区间；差分更新正好令该区间每个位置增加 y；双树状数组公式准确恢复任意前缀和。因此操作 1、2、3 分别得到题意规定的点更新、子树更新、子树求和。

复杂度：建树和 DFS 为 O(n)，每个操作 O(log n)，空间 O(n)。递归深度在 JavaScript / Python 可能溢出，下面的提交版使用迭代 DFS。

常见错误：把领导关系方向反了；把 x 自己漏出子树；R+1 未分配 n+2；使用 int 导致乘法溢出；没有对负的差分更新做模归一化。

from typing import List
class Solution:
 def bonus(self,n:int,leadership:List[List[int]],operations:List[List[int]])->List[int]:
  MOD=10**9+7; g=[[] for _ in range(n+1)]; child=[False]*(n+1)
  for a,b in leadership:g[a].append(b);child[b]=True
  tin=[0]*(n+1);tout=[0]*(n+1);it=[0]*(n+1);t=0
  for root in range(1,n+1):
   if child[root]:continue
   st=[root]
   while st:
    x=st[-1]
    if not tin[x]:t+=1;tin[x]=t
    if it[x]<len(g[x]):st.append(g[x][it[x]]);it[x]+=1
    else:tout[x]=t;st.pop()
  b1=[0]*(n+2);b2=[0]*(n+2)
  def add(b,i,v):
   while i<=n+1:b[i]=(b[i]+v)%MOD;i+=i&-i
  def sm(b,i):
   s=0
   while i:s=(s+b[i])%MOD;i-=i&-i
   return s
  def inc(l,r,v):add(b1,l,v);add(b1,r+1,-v);add(b2,l,v*(l-1));add(b2,r+1,-v*r)
  def pre(x):return (x*sm(b1,x)-sm(b2,x))%MOD
  ans=[]
  for op in operations:
   l=tin[op[1]];r=l if op[0]==1 else tout[op[1]]
   if op[0]<3:inc(l,r,op[2])
   else:ans.append((pre(r)-pre(l-1))%MOD)
  return ans
