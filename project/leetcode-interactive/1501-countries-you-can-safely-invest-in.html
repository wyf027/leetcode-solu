可以放心投资的国家

01 / PROBLEM

题意与数据契约

官方付费题面为空；以下为基于官方元数据的准确转述

电信公司希望选择新的投资国家。给定人员、国家电话区号和通话记录，请返回所有“居民参与通话的平均时长”严格高于全部通话平均时长的国家名称，结果顺序不限。

关键语义：只要某位居民是主叫方或被叫方，这通电话就计入其所属国家；同一国家的两位居民互相通话时，两个端点都会归入该国家。

约束与保证

  • Calls.caller_id、Calls.callee_id 均引用 Person 中存在的人员，且一通电话的两端是不同人员。
  • 官方元数据只公开了字段类型，没有公开数值型行数范围；本页不虚构缺失的上下界。

05 / SOLUTION

准备好再揭晓

先操作上面的实验室，确认为什么一通电话需要形成两个国家端点。

SOLUTION REVEALED

一次展开，两层聚合

核心洞察

国家平均值不是按 Calls 的某一个固定列分组，因为居民可能出现在主叫或被叫列。先把每通电话投影为两个同构记录 (country, duration)，之后普通的 GROUP BY 就足够了。

safe(country) ⇔ AVG(endpoint.duration) > AVG(Calls.duration)

完整过程

  1. 主叫方连接 Person，再按电话号码前三位连接 Country。
  2. 被叫方重复同样连接，用 UNION ALL 保留每个端点。
  3. 按国家分组计算端点通话时长平均值。
  4. 用标量子查询计算 Calls 的全局平均值，仅保留严格大于者。

正确性说明

引理 1：展开结果与所有“居民参与通话”端点一一对应。每通 Calls 记录的主叫和被叫分别生成一行，因此既不漏掉任何参与者，也不把非参与者加入。

引理 2：对某国家展开行的 duration 求平均，正是该国居民参与的通话端点平均时长。若通话两端都属于该国，两位居民各贡献一个端点，符合端点语义。

定理：HAVING 比较上述国家平均值与 Calls 全局平均值，并只保留严格大于者，所以查询返回且仅返回可以放心投资的国家。

复杂度

设通话数为 C、人员数为 P。具备主键与区号索引时，连接和聚合的期望时间为 O(C + P)，展开中间结果为 2C 行，额外空间 O(C)；数据库可能根据执行计划采用不同物理策略。

边界与常见错误

  • 必须使用 UNION ALL；UNION 会错误去重完全相同的端点记录。
  • 比较符必须是 >，等于全局均值的国家不返回。
  • 不能只按 caller_id 统计，否则漏掉仅作为被叫方出现的居民。
  • 无通话国家不会出现在展开结果，也不应凭空产生平均值。
  • 电话号码区号保留前导零，应该作为字符串处理。

替代方案与面试追问

替代：可把主叫和被叫人员先用条件连接到同一查询，再借助横向展开生成两行；但兼容性和可读性通常不如两个分支的 UNION ALL。

  • 如果业务定义改成“每通电话对国家只计一次”，同国通话如何去重？
  • 怎样设计 Person(phone_number) 的前缀匹配或单独 country_code 列以提高连接效率？
  • 如果 duration 可能为 NULL，应如何明确排除或补零语义？
  • 如何输出国家均值、全局均值及差值用于审计？

WITH call_endpoints AS (
    SELECT c.name AS country, calls.duration
    FROM Calls AS calls
    JOIN Person AS p ON p.id = calls.caller_id
    JOIN Country AS c
      ON c.country_code = LEFT(p.phone_number, 3)

    UNION ALL

    SELECT c.name AS country, calls.duration
    FROM Calls AS calls
    JOIN Person AS p ON p.id = calls.callee_id
    JOIN Country AS c
      ON c.country_code = LEFT(p.phone_number, 3)
)
SELECT country
FROM call_endpoints
GROUP BY country
HAVING AVG(duration) > (SELECT AVG(duration) FROM Calls);

import java.util.*;

public class SafeCountries {
    public record Person(int id, String name, String phoneNumber) {}
    public record Country(String name, String countryCode) {}
    public record Call(int callerId, int calleeId, int duration) {}

    public static List<String> findSafeCountries(
            List<Person> people, List<Country> countries, List<Call> calls) {
        Map<Integer, String> personCountry = new HashMap<>();
        Map<String, String> codeToCountry = new HashMap<>();
        for (Country c : countries) codeToCountry.put(c.countryCode(), c.name());
        for (Person p : people) {
            personCountry.put(p.id(), codeToCountry.get(p.phoneNumber().substring(0, 3)));
        }

        Map<String, long[]> stats = new HashMap<>();
        long globalSum = 0;
        for (Call call : calls) {
            globalSum += call.duration();
            add(stats, personCountry.get(call.callerId()), call.duration());
            add(stats, personCountry.get(call.calleeId()), call.duration());
        }

        List<String> answer = new ArrayList<>();
        long callCount = calls.size();
        for (var entry : stats.entrySet()) {
            long[] value = entry.getValue();
            if (value[0] * callCount > globalSum * value[1]) answer.add(entry.getKey());
        }
        return answer;
    }

    private static void add(Map<String, long[]> stats, String country, int duration) {
        long[] value = stats.computeIfAbsent(country, key -> new long[2]);
        value[0] += duration;
        value[1]++;
    }
}

function findSafeCountries(people, countries, calls) {
  const codeToCountry = new Map(countries.map(c => [c.countryCode, c.name]));
  const personCountry = new Map(
    people.map(p => [p.id, codeToCountry.get(p.phoneNumber.slice(0, 3))])
  );
  const stats = new Map();
  let globalSum = 0;

  const add = (country, duration) => {
    const value = stats.get(country) ?? { sum: 0, count: 0 };
    value.sum += duration;
    value.count += 1;
    stats.set(country, value);
  };

  for (const call of calls) {
    globalSum += call.duration;
    add(personCountry.get(call.callerId), call.duration);
    add(personCountry.get(call.calleeId), call.duration);
  }

  return [...stats]
    .filter(([, value]) => value.sum * calls.length > globalSum * value.count)
    .map(([country]) => country);
}

import pandas as pd

def find_safe_countries(
    person: pd.DataFrame,
    country: pd.DataFrame,
    calls: pd.DataFrame,
) -> pd.DataFrame:
    people = person.assign(
        country_code=person["phone_number"].str.slice(0, 3)
    ).merge(country, on="country_code", how="inner")

    caller = calls.merge(
        people[["id", "name"]], left_on="caller_id", right_on="id"
    )[["name", "duration"]]
    callee = calls.merge(
        people[["id", "name"]], left_on="callee_id", right_on="id"
    )[["name", "duration"]]

    endpoints = pd.concat([caller, callee], ignore_index=True)
    averages = endpoints.groupby("name", as_index=False)["duration"].mean()
    return (
        averages.loc[averages["duration"] > calls["duration"].mean(), ["name"]]
        .rename(columns={"name": "country"})
    )

#include <string>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

struct Person { int id; string name; string phoneNumber; };
struct Country { string name; string countryCode; };
struct Call { int callerId; int calleeId; int duration; };

vector<string> findSafeCountries(
    const vector<Person>& people,
    const vector<Country>& countries,
    const vector<Call>& calls) {
    unordered_map<string, string> codeToCountry;
    unordered_map<int, string> personCountry;
    for (const auto& c : countries) codeToCountry[c.countryCode] = c.name;
    for (const auto& p : people) personCountry[p.id] = codeToCountry[p.phoneNumber.substr(0, 3)];

    unordered_map<string, pair<long long, long long>> stats;
    long long globalSum = 0;
    for (const auto& call : calls) {
        globalSum += call.duration;
        for (int id : {call.callerId, call.calleeId}) {
            auto& [sum, count] = stats[personCountry[id]];
            sum += call.duration;
            ++count;
        }
    }

    vector<string> answer;
    for (const auto& [name, value] : stats) {
        if (value.first * calls.size() > globalSum * value.second) answer.push_back(name);
    }
    return answer;
}
