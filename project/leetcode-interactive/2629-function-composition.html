Problem

题意

compose(functions) → fn

给定一个一元函数数组 [f₁, f₂, …, fₙ]，返回它们的复合函数 fn。调用 fn(x) 时，函数按数组的从右到左顺序执行：对于 [f, g, h]，结果为 f(g(h(x)))。

若数组为空，返回的函数应当是恒等函数，即任意输入 x 都原样返回 x。可以假设每个函数都接收一个整数并返回一个整数。

示例 1
输入：functions = [
  x => x + 1,
  x => x * x,
  x => 2 * x
], x = 4
输出：65
解释：2 × 4 = 8，
8 × 8 = 64，64 + 1 = 65。
示例 2
输入：functions = [
  x => 10 * x,
  x => 10 * x,
  x => 10 * x
], x = 1
输出：1000
解释：10 × 1 = 10，
10 × 10 = 100，10 × 100 = 1000。
示例 3
输入：functions = [], x = 42
输出：42
解释：空函数列表的复合函数
是恒等函数，所以返回原输入。

约束

  • -1000 <= x <= 1000
  • 0 <= functions.length <= 1000
  • 所有函数都接收并返回一个整数

Complete solution

题解：逆序传递一个值

数组越靠右的函数越靠近输入，因此最先执行。

核心洞察

执行方向

把 x 作为当前值，从数组末尾遍历到开头；每次用当前函数处理它。

空数组自然成立

循环零次时当前值仍是 x，无需单独分支便得到恒等函数。

完整过程

  1. 返回一个接收整数 x 的新函数，组合工作在它被调用时发生。
  2. 令 value = x，它保存上一层函数的输出。
  3. 从 functions.length - 1 递减到 0，更新 value = functions[i](value)。
  4. 循环结束后返回 value；若没有函数，初值会直接返回。

正确性

循环不变式：处理完索引 i+1 ... n-1 后，value 等于这些函数从右到左作用于原始输入的结果。初始时尚未处理函数，value = x，命题成立。处理 functions[i] 时，把它作用于已有结果，不变式继续成立。终止时所有函数均已处理，所以得到 f₁(f₂(...fₙ(x)))。当数组为空时循环不执行，返回 x，正是恒等函数。

边界情况

  • 空数组：返回输入本身。
  • 单个函数：只调用一次该函数。
  • 输入可为负数、零或正数。
  • 最多 1000 个函数，迭代写法不会堆叠递归调用。

复杂度

  • 创建复合函数：O(1)。
  • 每次调用：时间 O(n)。
  • 执行时额外空间：O(1)。
  • 返回的闭包会保留函数数组的引用。

JavaScript官方可提交
/**
 * @param {Function[]} functions
 * @return {Function}
 */
var compose = function(functions) {
  return function(x) {
    for (let i = functions.length - 1; i >= 0; i--) {
      x = functions[i](x);
    }
    return x;
  };
};

// const fn = compose([x => x + 1, x => 2 * x]);
// fn(4); // 9
Python本地语义参考 · 非官方提交语言
from collections.abc import Callable

Unary = Callable[[int], int]

def compose(functions: list[Unary]) -> Unary:
    def composed(x: int) -> int:
        for function in reversed(functions):
            x = function(x)
        return x

    return composed

# fn = compose([lambda x: x + 1, lambda x: 2 * x])
# print(fn(4))  # 9
Java本地语义参考 · 非官方提交语言
import java.util.List;
import java.util.function.IntUnaryOperator;

class FunctionComposition {
    static IntUnaryOperator compose(
            List<IntUnaryOperator> functions) {
        return x -> {
            int value = x;
            for (int i = functions.size() - 1; i >= 0; i--) {
                value = functions.get(i).applyAsInt(value);
            }
            return value;
        };
    }

    public static void main(String[] args) {
        IntUnaryOperator fn = compose(List.of(
                x -> x + 1,
                x -> 2 * x
        ));
        System.out.println(fn.applyAsInt(4)); // 9
    }
}
C++本地语义参考 · 非官方提交语言
#include <functional>
#include <iostream>
#include <vector>

using Unary = std::function<int(int)>;

Unary compose(std::vector<Unary> functions) {
    return [functions = std::move(functions)](int x) {
        for (auto it = functions.rbegin();
             it != functions.rend(); ++it) {
            x = (*it)(x);
        }
        return x;
    };
}

int main() {
    auto fn = compose({
        [](int x) { return x + 1; },
        [](int x) { return 2 * x; }
    });
    std::cout << fn(4) << '\n'; // 9
}

替代方案

  • reduceRight 可直接表达从右到左，但循环更易调试，也无回调开销。
  • 递归定义贴近数学形式，却可能在函数很多时触及调用栈限制。
  • 可预先两两组合函数，但仍需遍历，且会增加嵌套闭包。

常见错误

  • 从左向右执行，得到相反的组合顺序。
  • 在创建复合函数时就执行，忘记返回新函数。
  • 使用没有初始值的归约，导致空数组报错。
  • 通过 reverse() 改动原数组，造成意外副作用。
