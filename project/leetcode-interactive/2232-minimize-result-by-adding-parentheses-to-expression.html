Minimize Result by Adding Parentheses to Expression

只移动一对括号，结果会发生什么变化？先理解规则，再动手探索。

LeetCode 官方题目 ↗

01 / 题目与规则

给定从下标 0 开始的字符串 expression = "<num1>+<num2>"，其中两部分都是正整数。保持原有字符顺序，插入且仅插入一对括号：左括号位于加号左侧，右括号位于加号右侧，括号内加号两边都必须有数字。

括号与外部数字相邻表示乘法。返回使整个表达式数值最小的带括号字符串，不是最小数值本身；多个最优结果可返回任意一个。

  • 3 ≤ expression.length ≤ 10。
  • 只包含数字 '1' 至 '9' 和恰好一个 '+'，首尾都是数字，不含 0。
  • 原表达式以及每一种合法加括号结果都在 32 位有符号整数范围内。

例如 2(4)7+38 不合法：右括号没有位于加号右边。

05 / 独立题解

准备好后，展开推导与四语言实现。

核心洞察：用两个切分点表示一对括号

将表达式分为字符串 L 与 R。左括号放在 L 的下标 i 前，右括号放在 R 的前 j 个数字后：L[:i](L[i:]+R[:j])R[j:]。任何合法结果都可写成 a × (b + c) × d。外部段为空时，对应乘数取 1；内部段不能为空。

完整过程

  1. 按加号切分；设左右长度为 m、k。
  2. 枚举 0 ≤ i < m 和 1 ≤ j ≤ k，一共 m × k 个组合。
  3. 把四段转为整数，空外部段使用 1，计算候选值。
  4. 候选严格小于当前最小值时保存值与带括号字符串；相等时保留已有答案。
  5. 遍历结束返回保存的字符串。无需使用 eval，也无需通用表达式解析器。

以 247+38 为例，按 i 外层、j 内层依次得到 (247+3)8 → 2000、(247+38) → 285、2(47+3)8 → 800、2(47+38) → 170、24(7+3)8 → 1920、24(7+38) → 1080。最小值对应 2(47+38)。

正确性

完整性：每个合法左括号唯一对应一个 i，每个合法右括号唯一对应一个 j；循环范围覆盖全部且没有非法空内部段。求值正确：四段恰好对应相邻数字与括号间的隐式乘法，空外部段的单位元为 1。最优性：处理每个候选后，保存的值始终是已处理候选的最小值；初始为无穷大，每次只接受更小值，遍历完整候选集后即为全局最优。

边界与复杂度

单数字一侧只有一个边界可选；整式括起时 a=d=1；同值时任取一个；输入不含 0，故没有前导零或零乘数问题。题目保证合法候选落在 32 位整数范围，Java 与 C++ 用 64 位中间结果更稳妥，JavaScript Number 在该范围精确。

以下实现每个候选都进行长度至多 n 的切片与转换，因此时间 O(mkn)，最坏 O(n³)；候选数本身是 O(mk)。辅助空间 O(n)（临时子串与答案），没有保存所有候选。实验台为回放额外保存候选，与提交代码的空间不同。

替代方案

可预计算两侧的前缀数值和后缀数值，使每个候选求值 O(1)，只保存最优下标并在最后构造答案，整体 O(n + mk) 时间、O(n) 空间。n ≤ 10 时，直接切片更清晰。动态规划或搜索树没有必要；只挑某一边的局部最小值无法保证乘积最小。

常见错误

  • 把空外部段当 0，导致乘积错误归零。
  • 让 i=m 或 j=0，使加号一侧在括号内没有数字。
  • 把字符串连接当作相加，或忘记括号外相邻部分表示乘法。
  • 只返回数值，或在答案中额外插入 *。
  • 忽略 substring 的右端点不包含在内，或把每次字符串解析成本遗漏。

面试追问

为何不采用贪心？移动边界会同时改变外部乘数与内部加数，影响相互耦合。多个最优解怎样固定输出？相等时比较字符串字典序或下标，原题不要求。如果数字可包含 0？需先明确前导零语法，仍可枚举，但零乘数使许多答案并列。如果有多个加号或多对括号？当前两个边界模型不够，需重新定义合法结构，考虑区间动态规划等方法。

Java

class Solution {
    public String minimizeResult(String expression) {
        String[] parts = expression.split("\\+");
        String l = parts[0], r = parts[1], answer = "";
        long best = Long.MAX_VALUE;
        for (int i = 0; i < l.length(); i++) {
            for (int j = 1; j <= r.length(); j++) {
                long a = i == 0 ? 1 : Long.parseLong(l.substring(0, i));
                long b = Long.parseLong(l.substring(i));
                long c = Long.parseLong(r.substring(0, j));
                long d = j == r.length() ? 1 : Long.parseLong(r.substring(j));
                long value = a * (b + c) * d;
                if (value < best) {
                    best = value;
                    answer = l.substring(0, i) + "(" + l.substring(i)
                           + "+" + r.substring(0, j) + ")" + r.substring(j);
                }
            }
        }
        return answer;
    }
}

class Solution:
    def minimizeResult(self, expression: str) -> str:
        left, right = expression.split('+')
        best, answer = float('inf'), ''
        for i in range(len(left)):
            for j in range(1, len(right) + 1):
                a = int(left[:i]) if i else 1
                b = int(left[i:])
                c = int(right[:j])
                d = int(right[j:]) if j < len(right) else 1
                value = a * (b + c) * d
                if value < best:
                    best = value
                    answer = (left[:i] + '(' + left[i:] + '+'
                              + right[:j] + ')' + right[j:])
        return answer
