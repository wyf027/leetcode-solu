查找和最小的 K 对数字

两列已经排好序的数字，会织成一张“数对地图”。你的任务，是从所有坐标中取出总和最小的前 k 个。

中等 数组 堆（优先队列） 非付费题
Problem brief

先把任务说清楚

给定两个按非递减顺序排列的整数数组 nums1、nums2 和整数 k。每个数对的第一个值取自 nums1，第二个值取自 nums2；返回和最小的 k 个数对。

参数与返回值

nums1 与 nums2 都已排序，数对可按下标区分，因此相同数值可以重复出现在答案中。

kSmallestPairs(nums1: integer[], nums2: integer[], k: integer) → integer[][]

数对从哪里来？

每个合法坐标 (i, j) 对应一个数对 [nums1[i], nums2[j]]。

nums1 → 行 nums2 → 列 权重 → 两数之和

示例 1

输入：nums1 = [1,7,11], nums2 = [2,4,6], k = 3
输出：[[1,2],[1,4],[1,6]]

按和从小到大观察所有数对，最先出现的三个是 [1,2]、[1,4]、[1,6]。

示例 2

输入：nums1 = [1,1,2], nums2 = [1,2,3], k = 2
输出：[[1,1],[1,1]]

两个值相同的 1 位于不同下标，分别与 nums2[0] 组成合法数对，所以答案可以重复。

约束

  • 011 <= nums1.length, nums2.length <= 105
  • 02-109 <= nums1[i], nums2[i] <= 109
  • 03nums1 和 nums2 均按非递减顺序排列
  • 041 <= k <= 104
  • 05k <= nums1.length * nums2.length

Solution

最小堆维护每一行的前沿

把所有数对按下标放进矩阵：固定 i 后，这一行的和会随 j 非递减。于是无需一次性生成全部 m × n 个数对，只要维护各行尚未取出的最小者。

核心洞察

1

每一行都有序

固定 nums1[i] 后，随着 j 增大，nums1[i] + nums2[j] 不会变小。

2

只留行首候选

某行只有当前最靠左、尚未取出的格子可能成为全局最小值。

3

取出后向右推进

弹出坐标 (i,j) 后，只需把同一行的 (i,j+1) 加入候选。

完整过程

  1. 令 rows = min(nums1.length, k)。把每个 i ∈ [0, rows) 的坐标 (i,0) 放入按数对和排序的最小堆。
  2. 重复至多 k 次：从堆顶弹出和最小的坐标 (i,j)，把对应数对加入答案。
  3. 若 j + 1 < nums2.length，把同一行的下一个坐标 (i,j+1) 压入堆。
  4. 达到 k 个答案或堆为空时结束。

为什么只初始化前 min(m,k) 行？

若 m > k，任意第 k 行及更后面的行，其第一个数对都不小于前 k 行各自的第一个数对；前面已存在至少 k 个不更大的候选。因此更后面的行不必参与前 k 个答案的竞争。和相同时，题目允许返回任意满足条件的 k 个下标数对。

正确性证明

不变式

在每轮弹出前，对于每个已经初始化且仍有未输出元素的行，堆中恰好保存该行最靠左的未输出坐标。

初始化

每行尚未输出任何元素，最靠左坐标是 (i,0)；算法把它们放进堆，所以不变式成立。

保持

弹出 (i,j) 后，该行新的最靠左未输出坐标只能是 (i,j+1)。若它存在，算法立即将其入堆；其他行的候选不变，因此不变式继续成立。

贪心选择正确

每一行都非递减，所以该行任何更靠右的未输出元素都不小于堆中保存的行前沿。由不变式，所有尚未输出数对中的全局最小值必然位于堆中；弹出堆顶就得到下一小的数对。归纳可知，前 k 次弹出正好组成和最小的 k 个数对。

终止

每轮都会新增一个答案，最多执行 k 轮。结合只初始化前 min(m,k) 行的论证，算法返回所需结果。

复杂度与边界

时间复杂度O(k log min(m, k))
初始化至多 k 行，每次弹出和压入都操作同一个小堆。
空间复杂度O(min(m, k))
不计返回结果；堆内每一行最多一个候选。

边界处理

  • 数组值可为负数，但排序矩阵仍按行非递减。
  • 重复值对应不同下标，不能去重。
  • k 可以等于全部数对数量；堆会在最后一次弹出后自然耗尽。
  • Java 与 C++ 比较和时使用更宽整数类型，避免两个 int 相加溢出。

import java.util.*;

class Solution {
    public List<List<Integer>> kSmallestPairs(int[] nums1, int[] nums2, int k) {
        List<List<Integer>> answer = new ArrayList<>();
        PriorityQueue<int[]> minHeap = new PriorityQueue<>((a, b) ->
            Long.compare(
                (long) nums1[a[0]] + nums2[a[1]],
                (long) nums1[b[0]] + nums2[b[1]]
            )
        );

        int rows = Math.min(nums1.length, k);
        for (int i = 0; i < rows; i++) {
            minHeap.offer(new int[]{i, 0});
        }

        while (k > 0 && !minHeap.isEmpty()) {
            int[] cell = minHeap.poll();
            int i = cell[0];
            int j = cell[1];
            answer.add(Arrays.asList(nums1[i], nums2[j]));
            k--;

            if (j + 1 < nums2.length) {
                minHeap.offer(new int[]{i, j + 1});
            }
        }
        return answer;
    }
}
/**
 * @param {number[]} nums1
 * @param {number[]} nums2
 * @param {number} k
 * @return {number[][]}
 */
var kSmallestPairs = function(nums1, nums2, k) {
    const heap = [];
    const answer = [];

    const less = (a, b) =>
        nums1[a[0]] + nums2[a[1]] < nums1[b[0]] + nums2[b[1]];

    const push = (cell) => {
        heap.push(cell);
        let child = heap.length - 1;
        while (child > 0) {
            const parent = Math.floor((child - 1) / 2);
            if (!less(heap[child], heap[parent])) break;
            [heap[child], heap[parent]] = [heap[parent], heap[child]];
            child = parent;
        }
    };

    const pop = () => {
        const top = heap[0];
        const last = heap.pop();
        if (heap.length > 0) {
            heap[0] = last;
            let parent = 0;
            while (true) {
                let smallest = parent;
                const left = parent * 2 + 1;
                const right = left + 1;
                if (left < heap.length && less(heap[left], heap[smallest])) {
                    smallest = left;
                }
                if (right < heap.length && less(heap[right], heap[smallest])) {
                    smallest = right;
                }
                if (smallest === parent) break;
                [heap[parent], heap[smallest]] = [heap[smallest], heap[parent]];
                parent = smallest;
            }
        }
        return top;
    };

    const rows = Math.min(nums1.length, k);
    for (let i = 0; i < rows; i++) push([i, 0]);

    while (k > 0 && heap.length > 0) {
        const [i, j] = pop();
        answer.push([nums1[i], nums2[j]]);
        k--;
        if (j + 1 < nums2.length) push([i, j + 1]);
    }
    return answer;
};
from typing import List
import heapq


class Solution:
    def kSmallestPairs(
        self, nums1: List[int], nums2: List[int], k: int
    ) -> List[List[int]]:
        min_heap = []
        answer = []

        rows = min(len(nums1), k)
        for i in range(rows):
            heapq.heappush(min_heap, (nums1[i] + nums2[0], i, 0))

        while k > 0 and min_heap:
            _, i, j = heapq.heappop(min_heap)
            answer.append([nums1[i], nums2[j]])
            k -= 1

            if j + 1 < len(nums2):
                heapq.heappush(
                    min_heap,
                    (nums1[i] + nums2[j + 1], i, j + 1),
                )

        return answer
#include <queue>
#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<vector<int>> kSmallestPairs(
        vector<int>& nums1, vector<int>& nums2, int k
    ) {
        using Cell = pair<int, int>;
        auto greaterSum = [&](const Cell& a, const Cell& b) {
            long long sumA = (long long)nums1[a.first] + nums2[a.second];
            long long sumB = (long long)nums1[b.first] + nums2[b.second];
            return sumA > sumB;
        };

        priority_queue<Cell, vector<Cell>, decltype(greaterSum)>
            minHeap(greaterSum);
        vector<vector<int>> answer;

        int rows = min((int)nums1.size(), k);
        for (int i = 0; i < rows; ++i) {
            minHeap.push({i, 0});
        }

        while (k > 0 && !minHeap.empty()) {
            auto [i, j] = minHeap.top();
            minHeap.pop();
            answer.push_back({nums1[i], nums2[j]});
            --k;

            if (j + 1 < (int)nums2.size()) {
                minHeap.push({i, j + 1});
            }
        }
        return answer;
    }

替代方案

枚举全部数对 + 大根堆保留前 k 个

依次扫描全部 m × n 个数对，用大小为 k 的大根堆保留最小候选。实现直接，但最坏时间为 O(mn log k)，在两个数组长度都达到 105 时不可行。

二分答案和

可以二分第 k 小的“和”，并用双指针统计不超过某个和的数对数量。它适合只询问第 k 小的和值；本题还要恢复具体的 k 个数对，处理重复值与边界会更复杂，因此最小堆方案更自然。

面试追问

如果两个数组没有排序？

先分别排序，额外时间为 O(m log m + n log n)；若不能改变原数组，可排序副本或下标。

为什么不把所有行都放进堆？

可以，但堆会膨胀到 m。前 k 个答案至多需要前 k 行，截断可把空间和堆操作控制在 min(m,k)。

相同和值的顺序重要吗？

不重要。题目只要求返回任意一组和最小的 k 个数对；比较器无需额外保证稳定性。

能交换两个数组吗？

可以选择较短数组作为“行”来进一步缩小堆，但输出时必须恢复原本的数对顺序。

常见错误

  • 只用两个指针在矩阵里单一路径移动，会漏掉来自其他行的更小候选。
  • 把数对按数值放入集合去重，导致重复下标对应的合法答案丢失。
  • 一次性生成全部数对再排序，内存和时间都可能达到 O(mn) 级别。
  • 弹出 (i,j) 后忘记压入 (i,j+1)，该行剩余元素就永远不会再参与竞争。
  • 在 Java/C++ 中直接用两个和值相减作为比较器，可能发生整数溢出或违反比较器契约。
