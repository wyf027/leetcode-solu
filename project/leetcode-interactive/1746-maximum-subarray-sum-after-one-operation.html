经过一次操作后的
最大子数组和

平方一次，是把一次性的“特殊能力”放进 Kadane 状态机。难点不在平方，而在精确记录：能力还没用，还是已经用过。

Maximum Subarray Sum After One Operation 时间 O(n)空间 O(1)
Problem

题目转述

给定一个整数数组 nums。你必须选择其中恰好一个元素，把它替换成自身的平方；然后从操作后的数组中选择一个非空连续子数组。求这个子数组可能取得的最大元素和。

操作形式：选择下标 i，令 nums[i] = nums[i] × nums[i]。平方发生一次且仅一次，但最终子数组不必覆盖数组的全部元素。

函数签名

maxSumAfterOperation(nums: integer[]) → integer

约束

  • 1 ≤ nums.length ≤ 10⁵
  • −10⁴ ≤ nums[i] ≤ 10⁴
  • 答案可能超过单个元素的范围，计算时应使用语言中足够安全的整数类型。

输入：nums = [2, -1, -4, -3]
输出：17
解释：将 -4 平方为 16，选择
[2, -1, 16]，和为 17。

选择前四项 [1, 1, 1, 1]。

Solution

一次性能力，两个 Kadane 状态

关键不是枚举“平方谁”，而是扫描到每个位置时，同时维护“还没平方”和“已经平方”的最佳连续段。

核心洞察

令 plain 表示以当前元素结尾、尚未做平方操作的最大子数组和；令 used 表示以当前元素结尾、已经恰好平方过一个元素的最大子数组和。答案只能从 used 中取，因为操作是必做的。

完整过程

  1. 读取当前值 x。保存上一位置的 plain 与 used，避免更新顺序污染转移。
  2. 更新未平方状态。newPlain = max(x, oldPlain + x)，即从当前位置重开，或接到旧连续段后面。
  3. 更新已平方状态。newUsed = max(x², oldPlain + x², oldUsed + x)。分别对应平方当前值并重开、平方当前值并接到未平方段、此前已平方而当前正常加入。
  4. 汇总答案。每一步用 newUsed 更新全局最大值。扫描结束后返回它。

正确性说明

状态不变式：处理完下标 i 后，plain 等于所有以 i 结尾且未平方的非空子数组中的最大和；used 等于所有以 i 结尾且恰好平方一次的非空子数组中的最大和。

对 plain，合法子数组只可能从当前项开始，或把当前项接到上一位置的最优未平方段。对 used，平方要么发生在当前项（重开或连接旧 plain），要么早已发生（连接旧 used）；三类互斥且覆盖所有可能。初始位置显然成立，因此由归纳法不变式始终成立。任何非空连续子数组都有唯一末尾，取所有位置的 used 最大值，即得到全局最优答案。

边界情况

  • 单元素数组：答案就是该元素的平方。
  • 全为负数：平方某个绝对值较大的负数通常能形成正答案。
  • 含 0：平方 0 仍为 0，但可能承担“恰好一次”的操作。
  • 平方值可到 10⁸，Java / C++ 的累计和用 long / long long 更稳妥。

复杂度

时间：O(n)，每个元素只处理一次。

额外空间：O(1)，二维 DP 可压缩为两个滚动变量。

替代方案

也可预计算每个位置左右两侧的最大延伸和，再枚举被平方的位置，组合“左贡献 + x² + 右贡献”。同样是 O(n)，但需要 O(n) 空间；双状态写法更直接。

四语言完整代码

class Solution {
    public int maxSumAfterOperation(int[] nums) {
        long plain = nums[0];
        long used = 1L * nums[0] * nums[0];
        long answer = used;

        for (int i = 1; i < nums.length; i++) {
            long x = nums[i];
            long squared = x * x;
            long nextUsed = Math.max(
                Math.max(squared, plain + squared),
                used + x
            );
            long nextPlain = Math.max(x, plain + x);
            plain = nextPlain;
            used = nextUsed;
            answer = Math.max(answer, used);
        }
        return (int) answer;
    }
}

public:
    int maxSumAfterOperation(vector<int>& nums) {

        long long used = 1LL * nums[0] * nums[0];
        long long answer = used;

                squared,

            plain = nextPlain;
            used = nextUsed;
            answer = max(answer, used);
        }

面试追问

Q：如果允许“至多一次”平方呢？
最终答案取所有位置的 plain 与 used 的最大值；当前题要求恰好一次，所以只取 used。
Q：如果允许平方两次？
把状态扩展为使用 0、1、2 次操作的三层 DP，每层从自身延续或由上一层在当前元素执行平方后转入。
Q：能否返回具体子数组和被平方下标？
可以。为每个候选转移同步记录起点、平方位置与父状态，并在全局答案更新时保存终点。

常见错误

  • 把答案也从 plain 更新，违反“必须进行一次操作”。
  • 先覆盖 plain，再用新值计算 used，导致同一元素参与两次逻辑位置。
  • 遗漏 x² 单独开新段，导致前缀很差时不能重新开始。
  • 只返回最后一个位置的 used，忘记最优子数组可以提前结束。
