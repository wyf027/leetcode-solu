01 / PROBLEM

规则很短，方向未必直观

设 target 长度为 n。初始数组 A 的 n 个元素均为 1；可以执行任意多次下面的操作。

  1. 计算当前数组全部元素之和 x。
  2. 任选一个下标 i（0 ≤ i < n），把 A[i] 更新为 x，其他位置不变。
  3. 重复操作；若最终能得到给定的 target，返回 true，否则返回 false。
Example 01
输入：target = [9,3,5]
输出：true
解释：[1,1,1] → [1,3,1]
      → [1,3,5] → [9,3,5]
Example 02
输入：target = [1,1,1,2]
输出：false
解释：无法从 [1,1,1,1]
      构造该目标。
Example 03
输入：target = [8,5]
输出：true

04 / SOLUTION

最后一步是唯一的线索

正向分支太多，逆向却近乎确定：目标中的最大值只能是上一步被替换的位置。

核心洞察

设当前最大值为 largest，其他元素之和为 rest。最后一次操作前，该位置的值是 previous，因此：

largest = previous + k × rest
previous = largest mod rest

取模一次跳过连续更新同一位置的多轮操作。最大堆让我们始终能取出当前最大值。

完整过程

  1. 把所有目标值放入最大堆，并计算总和 total。
  2. 弹出最大值 largest，令 rest = total - largest。
  3. 若 largest == 1 或 rest == 1，一定能还原到全 1，返回 true。
  4. 若 rest == 0、largest ≤ rest，或 largest mod rest == 0，不存在合法的正整数前驱，返回 false。
  5. 将 previous = largest mod rest 放回堆，更新总和并继续。

正确性说明

引理 1：在任一非初始可达状态中，最后被修改的元素等于修改前全数组之和，因而不小于其他任一未修改元素；所以逆向时选择最大值不会错过最后一步。

引理 2：固定其他元素和为 rest 时，连续修改最大值会让它每次增加 rest。因此所有可能的前驱与 largest 同余，唯一落在 [1, rest] 内的候选是余数；余数为 0 表示候选不是正整数。

终止：每次合法还原都把最大值严格减小；当最大值为 1 时全部元素均为 1，或当其余和为 1 时可反复减去 1 回到 1。由两个引理，算法接受且仅接受可由全 1 数组构造出的目标。

边界与复杂度

  • n = 1 时，只有 [1] 可达。
  • rest = 1 时可立即成功，避免余数得到 0 的误判。
  • 总和最大约 5 × 10¹³；Java/C++ 使用 64 位整数。
  • 设逆向迭代次数为 k：时间 O(n + k log n)，空间 O(n)。取模令 k 远小于逐次相减。

替代方案

反向逐次相减：每次用 largest - rest 得到前驱，逻辑正确但当 rest = 1 且最大值很大时会退化，超时。

正向搜索：每步有 n 种选择，数值又快速增长，状态空间爆炸，不适合本题约束。

四语言完整代码

JavaPriorityQueue · long
import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public boolean isPossible(int[] target) {
        PriorityQueue<Long> maxHeap =
            new PriorityQueue<>(Collections.reverseOrder());
        long total = 0;

        for (int value : target) {
            maxHeap.offer((long) value);
            total += value;
        }

        while (true) {
            long largest = maxHeap.poll();
            long rest = total - largest;

            if (largest == 1 || rest == 1) return true;
            if (rest == 0 || largest <= rest) return false;

            long previous = largest % rest;
            if (previous == 0) return false;

            total = rest + previous;
            maxHeap.offer(previous);
        }
    }
}
JavaScriptCustom MaxHeap · Number-safe sum
class MaxHeap {
    constructor(values) {
        this.data = [];
        for (const value of values) this.push(value);
    }

    push(value) {
        const heap = this.data;
        heap.push(value);
        let i = heap.length - 1;
        while (i > 0) {
            const parent = Math.floor((i - 1) / 2);
            if (heap[parent] >= heap[i]) break;
            [heap[parent], heap[i]] = [heap[i], heap[parent]];
            i = parent;
        }
    }

    pop() {
        const heap = this.data;
        const top = heap[0];
        const last = heap.pop();
        if (heap.length > 0) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let largest = i;
                const left = i * 2 + 1;
                const right = left + 1;
                if (left < heap.length && heap[left] > heap[largest]) largest = left;
                if (right < heap.length && heap[right] > heap[largest]) largest = right;
                if (largest === i) break;
                [heap[i], heap[largest]] = [heap[largest], heap[i]];
                i = largest;
            }
        }
        return top;
    }
}

/**
 * @param {number[]} target
 * @return {boolean}
 */
var isPossible = function(target) {
    const maxHeap = new MaxHeap(target);
    let total = target.reduce((sum, value) => sum + value, 0);

    while (true) {
        const largest = maxHeap.pop();
        const rest = total - largest;

        if (largest === 1 || rest === 1) return true;
        if (rest === 0 || largest <= rest) return false;

        const previous = largest % rest;
        if (previous === 0) return false;

        total = rest + previous;
        maxHeap.push(previous);
    }
};

from typing import List
import heapq


class Solution:
    def isPossible(self, target: List[int]) -> bool:
        total = sum(target)
        max_heap = [-value for value in target]
        heapq.heapify(max_heap)

        while True:
            largest = -heapq.heappop(max_heap)
            rest = total - largest

            if largest == 1 or rest == 1:
                return True
            if rest == 0 or largest <= rest:
                return False

            previous = largest % rest
            if previous == 0:
                return False

            total = rest + previous
            heapq.heappush(max_heap, -previous)

常见错误

  • 把最大值只减一次 rest，导致极端数据超时。
  • 漏掉 rest == 1 的成功出口。
  • 把余数 0 放回堆；原数组必须始终为正整数。
  • Java/C++ 用 32 位整数保存总和而溢出。
  • 尝试每轮排序，平白增加开销；最大堆更贴合操作。

面试追问

为什么最大值一定对应最后一次操作？

它等于上一步整个数组的和，至少不小于上一步任何单个元素；其他位置在最后一步没有改变。

为什么取模不会跳过关键状态？

在其他元素不变时，同一位置每次增加的量恒为 rest；中间状态只相差 rest，取模直达最小正前驱。

什么时候不能直接做 largest % rest？

rest 为 0 时除法无定义；rest 为 1 时应直接成功，否则余数 0 会造成错误拒绝。
