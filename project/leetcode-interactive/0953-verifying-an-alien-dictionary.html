验证外星语词典

一份从“未知字母表”出发的互动题卡。先观察相邻单词如何逐字符裁决顺序，再按需展开完整题解。

数组哈希表字符串Verifying an Alien Dictionary

题目

某种外星语言仍使用 26 个英文小写字母，只是字母的先后顺序由 order 给出。给定单词序列 words，判断它是否已经按照这套外星字母表的字典序排列。

函数形式： boolean isAlienSorted(string[] words, string order)
只有所有相邻单词都满足外星字典序，才返回 true。

官方示例

示例 1
输入：words = ["hello","leetcode"]
order = "hlabcdefgijkmnopqrstuvwxyz"
输出：true
解释：h 在 l 之前。
示例 2
输入：words = ["word","world","row"]
order = "worldabcefghijkmnpqstuvxyz"
输出：false
解释：首个差异处 d 排在 l 之后。
示例 3
输入：words = ["apple","app"]
order = "abcdefghijklmnopqrstuvwxyz"
输出：false
解释：前缀相同，但较长单词在前。

约束

  • 1 <= words.length <= 100
  • 1 <= words[i].length <= 20
  • order.length == 26
  • words[i] 与 order 中均为英文小写字母；order 是 26 个字母的排列。

外星排序扫描仪

输入单词（用英文逗号分隔）和字母顺序。每一步只做一件事：定位相邻单词的首个差异字符，或识别前缀关系。

完整题解

核心洞察

先把 order 映射成“字符 → 排名”。字典序是否成立，只需检查每一对相邻单词：找到首个不同字符，用排名判断；如果一直相同，则较短者必须在前。相邻关系全部成立，就能由传递性推出整个序列有序。

完整过程

  1. 建立长度为 26 的排名数组 rank。
  2. 从左到右遍历每对 words[i-1] 与 words[i]。
  3. 扫描两词公共长度内的字符。
  4. 遇到首个不同字符：若左侧排名更大，立即返回 false；否则这对合法，停止比较该对。
  5. 若公共部分完全相同且左词更长，出现非法前缀，返回 false。
  6. 所有相邻对合法，返回 true。

正确性说明

  1. 首差字符充分：字典序由第一处不同字符决定，之后字符不会改变结果。
  2. 前缀规则完整：没有首差字符时，只有“长前缀在短词前”是逆序。
  3. 局部推出整体：算法验证每个相邻对非递减；字典序具有传递性，因此整个数组非递减。
  4. 提前返回可靠：发现任意逆序相邻对时，整个序列必然无序。

边界情况

  • 只有一个单词：没有相邻对，返回 true。
  • 两个单词完全相同：合法。
  • 短词是长词前缀且短词在前：合法；反过来非法。
  • 差异可能直到最后一个公共字符才出现。

复杂度

设所有单词字符总数为 S。构建排名为 O(26)，比较总计 O(S)；额外空间 O(26)，视为常数空间。

四语言完整代码

Java

class Solution {
    public boolean isAlienSorted(String[] words, String order) {
        int[] rank = new int[26];
        for (int i = 0; i < 26; i++) {
            rank[order.charAt(i) - 'a'] = i;
        }
        for (int i = 1; i < words.length; i++) {
            String a = words[i - 1], b = words[i];
            int limit = Math.min(a.length(), b.length());
            int j = 0;
            while (j < limit && a.charAt(j) == b.charAt(j)) j++;
            if (j == limit) {
                if (a.length() > b.length()) return false;
            } else if (rank[a.charAt(j) - 'a'] > rank[b.charAt(j) - 'a']) {
                return false;
            }
        }
        return true;
    }
}

Python 3

from typing import List

class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        rank = {ch: i for i, ch in enumerate(order)}
        for a, b in zip(words, words[1:]):
            limit = min(len(a), len(b))
            j = 0
            while j < limit and a[j] == b[j]:
                j += 1
            if j == limit:
                if len(a) > len(b):
                    return False
            elif rank[a[j]] > rank[b[j]]:
                return False
        return True

替代方案

可以把每个单词转换为排名数组，再让语言自带的数组比较完成排序判断；但会分配更多中间数据，也容易在前缀规则上写错。逐相邻对扫描更直接，且能在发现逆序时提前结束。

面试追问

  • 为什么只比较相邻单词？ 有序关系具备传递性，相邻非递减足以保证全局非递减。
  • 如果字母表包含 Unicode 字符？ 用映射表替代固定长度数组，并按 Unicode 码点而非 UTF-16 代码单元迭代。
  • 若 order 不保证合法？ 先校验长度、唯一性，以及单词字符是否均被覆盖。

常见错误

  • 比较到首个不同字符后仍继续扫描。
  • 忘记处理 ["apple", "app"] 这种逆序前缀。
  • 误用英语字母自然顺序，而不是 order 中的排名。
  • 只比较第一对单词，遗漏后续相邻对。
