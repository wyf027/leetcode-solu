01 / 问题

让组合保留一个非零结果

给定正整数数组 candidates，从中选择一个非空组合，计算其中所有整数的按位与，返回结果大于 0 的组合所能达到的最大元素个数。组合不要求连续；每个数组位置最多选择一次，相同数值出现在不同位置时可以分别选择。返回的是长度，不是按位与的值。

按位与：同一二进制位在所有参与运算的数中均为 1，该位的结果才为 1。例如 1 & 5 & 3 = 1；单个数 [7] 的结果是 7。

官方示例 1

输入：candidates = [16,17,71,62,12,24,14]
输出：4

可选 [16,17,62,24]，按位与为 16，长度为 4；不存在长度更大的合法组合。最优组合可以不唯一：[62,12,24,14] 的按位与为 8，长度也为 4。

官方示例 2

输入：candidates = [8,8]
输出：2

两个位置都可以选择，8 & 8 = 8 > 0，因此最大长度为 2。

参数与约束

  • candidates：整数数组，1 ≤ candidates.length ≤ 10⁵。
  • 1 ≤ candidates[i] ≤ 10⁷。
  • 返回整数：满足条件的最大组合长度。

04 / 独立题解

准备好后，再看推导

核心洞察：寻找所有数共同为 1 的某一位

一组数的按位与大于 0，当且仅当至少有一个二进制位，在这组数中全部为 1。固定第 b 位，把数组中这一位为 1 的所有元素都选上，便得到这一位所能支持的最大组合。答案就是所有位上的计数最大值。

answer = max(count[b])，b = 0, 1, …, 23

因为 10⁷ < 2²⁴，只需考虑 24 个二进制位。

完整过程

  1. 令答案 ans = 0。
  2. 枚举位 b 从 0 到 23，令本位计数 count = 0。
  3. 遍历每个 x。若 (x & (1 << b)) != 0，本位计数加一。
  4. 更新 ans = max(ans, count)，最后返回 ans。

示例 1 中，b0–b6 的计数依次为 [2,3,4,4,4,1,1]。最大计数是 4；例如 b4 对应 [16,17,62,24]。b2 和 b3 也能支持长度为 4 的组合。

正确性证明

上界：设任意合法组合为 S。由于其按位与非零，存在一位 b 在 S 的全部元素中为 1。因此 |S| ≤ count[b] ≤ max(count)，任何合法组合都不会超过算法的答案。

可达：选取计数最大的某位 b，并选择这一位为 1 的全部元素。它们的按位与在 b 位保留 1，故组合合法，且长度恰好等于 max(count)。输入全为正数且非空，至少一位有正计数。上下界一致，算法正确。

复杂度

时间 O(24n)，固定值域下可记为 O(n)。额外空间 O(1)，逐位计数无需保存完整计数数组。一般化为 W 位整数时，时间为 O(nW)。

边界处理

  • 单个正数可独立成组，答案至少为 1。
  • 重复值要按位置计数，不能去重。
  • 必须包含 b23，2²³ = 8388608 仍在值域内。
  • 全数组按位与为 0，不代表答案为 0。

替代方案与取舍

  • 枚举子集：枚举每个非空子集并计算按位与，朴素复杂度 O(n·2ⁿ)，只适合很小的输入。
  • 先遍历数，再累加每一位：维护 24 个计数，时间仍为 O(24n)；也可通过 x & (x - 1) 只遍历置位，但需要识别位位置，当前约束下未必值得增加实现细节。

常见错误

  • 将“组合”误当连续子数组，使用滑动窗口。
  • 累加所有数的 1 的总数；应比较同一位上的元素数量。
  • 只检查最低位或最高位；最优位置可能在中间。
  • 用两两按位与非零推断整个组合合法：3 & 5 & 6 = 0，即使任意两个的按位与都大于 0。
  • 写成 (x & mask) == 1；高位为 1 时，结果是 mask，应判断非零。
  • JavaScript 位运算按 32 位整数执行；本题 24 位安全，更大整数需调整方案。

面试追问

  • 如何返回一个最优组合？记住最大计数对应的位，再遍历并收集该位为 1 的元素；新增输出空间 O(k)。
  • 能否流式处理？可以保留 24 个计数，每读取一个数更新所有位，最后取最大值。
  • 改成按位与大于等于 K 呢？单列计数不再直接成立；数值阈值可能依赖多个位，需重新分析约束。
  • 允许更大整数呢？按实际位宽扩展，Java/C++ 使用足够宽的类型；JavaScript 可用 BigInt，避免 32 位截断。

Java

class Solution {
    public int largestCombination(int[] candidates) {
        int ans = 0;
        for (int b = 0; b < 24; b++) {
            int count = 0;
            for (int x : candidates) {
                if ((x & (1 << b)) != 0) count++;
            }
            ans = Math.max(ans, count);
        }
        return ans;
    }
}
