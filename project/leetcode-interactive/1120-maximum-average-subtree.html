最大平均值

MEDIUM · PREMIUMMaximum Average Subtree

一次后序遍历，让每棵子树用两个数字完成自我介绍：节点总和与节点数量。

题目

给定一棵非空二叉树的根节点 root。一棵子树由某个节点及其全部后代组成。请返回所有子树中最大的节点值平均数；结果允许存在浮点误差。

函数形式： double maximumAverageSubtree(TreeNode root)

示例 1

输入：root = [5,6,1]
输出：6.00000
解释：以节点 6 为根的单节点子树平均值最大。

示例 2

输入：root = [0,null,1]
输出：1.00000
解释：以节点 1 为根的单节点子树平均值最大。

约束

  • 树中节点数在 [1, 10⁴] 范围内。
  • 0 ≤ Node.val ≤ 10⁵。
  • 输入为二叉树，每个节点最多有两个孩子。

SOLUTION

后序 DFS：先收集，再比较

核心洞察

平均值不能只由孩子的平均值推出，但可以由总和与数量推出。令 DFS 返回当前子树的 (sum, count)；拿到左右结果后计算当前子树平均值，并更新全局最大值。

完整过程

  1. 空节点返回 (0, 0)。
  2. 后序递归左右孩子，取得两棵子树的总和与数量。
  3. 当前总和为左右总和加节点值；当前数量为左右数量加一。
  4. 用 sum / count 更新答案，再把当前二元组返回父节点。

正确性

归纳基础：叶节点得到其自身值与数量 1，因此统计正确。归纳步骤：若左右子树统计正确，将二者与根节点合并，就恰好覆盖当前子树的所有节点且没有重复。算法会在每个节点处计算对应子树平均值，所以所有候选都被检查；维护的最大值最终即为答案。

边界情况

  • 单节点树：答案就是节点值。
  • 链状树：递归深度可达节点数。
  • 全零：最大平均值仍为 0。
  • 总和应使用足够宽的整数类型。

复杂度

每个节点访问一次，时间 O(n)；递归栈为 O(h)，其中 h 是树高，最坏为 O(n)。

替代方案

可以用显式栈模拟后序遍历，以避免深树造成调用栈溢出；仍需保存每个节点的统计结果，代码更长但复杂度不变。

四种语言完整实现

Java

class Solution {
    private double best = 0.0;
    public double maximumAverageSubtree(TreeNode root) {
        dfs(root);
        return best;
    }
    private long[] dfs(TreeNode node) {
        if (node == null) return new long[]{0, 0};
        long[] l = dfs(node.left), r = dfs(node.right);
        long sum = l[0] + r[0] + node.val;
        long count = l[1] + r[1] + 1;
        best = Math.max(best, (double) sum / count);
        return new long[]{sum, count};
    }
}

JavaScript

var maximumAverageSubtree = function(root) {
  let best = 0;
  function dfs(node) {
    if (node === null) return [0, 0];
    const [ls, lc] = dfs(node.left);
    const [rs, rc] = dfs(node.right);
    const sum = ls + rs + node.val;
    const count = lc + rc + 1;
    best = Math.max(best, sum / count);
    return [sum, count];
  }
  dfs(root);
  return best;
};

Python

class Solution:
    def maximumAverageSubtree(self, root: Optional[TreeNode]) -> float:
        best = 0.0
        def dfs(node):
            nonlocal best
            if node is None:
                return 0, 0
            ls, lc = dfs(node.left)
            rs, rc = dfs(node.right)
            total = ls + rs + node.val
            count = lc + rc + 1
            best = max(best, total / count)
            return total, count
        dfs(root)
        return best

C++

class Solution {
    double best = 0.0;
    pair<long long, int> dfs(TreeNode* node) {
        if (!node) return {0, 0};
        auto [ls, lc] = dfs(node->left);
        auto [rs, rc] = dfs(node->right);
        long long sum = ls + rs + node->val;
        int count = lc + rc + 1;
        best = max(best, (double)sum / count);
        return {sum, count};
    }
public:
    double maximumAverageSubtree(TreeNode* root) {
        dfs(root);
        return best;
    }
};

面试追问

  • 若节点值允许为负数，答案应如何初始化？用负无穷。
  • 如何返回最大平均值子树的根？更新最大值时同步保存节点。
  • 如何消除递归？用带访问标志的显式后序栈。

常见错误

  • 取所有节点平均值，而不是枚举每棵子树。
  • 错误地平均左右孩子的平均值，忽略子树大小。
  • 整数除法截断小数。
  • 只比较叶节点或忘记把当前节点计入统计。
