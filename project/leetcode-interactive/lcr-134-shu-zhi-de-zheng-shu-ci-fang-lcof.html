Pow(x, n)

数值的整数次方：用二进制快速幂将线性的乘法次数压缩为对数级。

题意

实现 myPow(x, n)，计算并返回 x 的 n 次幂。n 可以为负数。

示例 1

x = 2.00000, n = 10
输出：1024.00000

示例 2

x = 2.10000, n = 3
输出：9.26100

示例 3

x = 2.00000, n = -2
输出：0.25000

约束：-100.0 < x < 100.0，-2³¹ ≤ n ≤ 2³¹ − 1；x 不是 0 或 n > 0。

核心洞察

把指数写成二进制。每轮检查最低位：若为 1，就将当前底数乘进答案；不论最低位为何，都把底数平方，并把指数右移一位。

边界处理与复杂度

负指数先求正幂再取倒数；最小 32 位整数需先提升为更宽整型；n = 0 返回 1。时间 O(log |n|)，迭代额外空间 O(1)。

替代方案、追问与常见错误

递归快速幂同为 O(log |n|)，但有调用栈。可追问模幂和字符串指数。常见错误包括忘记负指数倒数、MIN_VALUE 取负溢出、忘记平方或右移。

class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n < 0: x, n = 1 / x, -n
        ans = 1.0
        while n:
            if n & 1: ans *= x
            x *= x; n >>= 1
        return ans
