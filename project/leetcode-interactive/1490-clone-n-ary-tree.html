01 / Problem

任务与边界

题意

给定一棵 N 叉树的根节点 root，返回整棵树的深拷贝。副本中每个节点的值、孩子数量和孩子顺序均与原树一致，但不能复用原树中的任何节点对象。

函数：Node cloneTree(Node root)。输入为空时返回空；评测还会检查新旧树是否共享节点。

节点定义

Node { val: int, children: List<Node> }

约束

  • 节点总数在 [0, 10⁴] 内。
  • N 叉树深度不超过 1000。
  • children 保留给定的孩子顺序。
  • 展示输入使用 null 分隔各层父节点的孩子组；它不是函数参数。

示例 1

输入 root
[1,null,3,2,4,null,5,6]
输出
[1,null,3,2,4,null,5,6]
说明
形状和值相同，所有节点均为新对象。

示例 2

[1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出
[1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]

03 / Solution

递归复制：先造自己，再造孩子

01

核心洞察

树的递归定义天然对应深拷贝：克隆一个节点，就是创建值相同的新节点，并把每个原孩子的克隆依次放入新节点的 children。原树无环，无需哈希表去重。

02

完整过程

  1. 若 root == null，返回空。
  2. 创建只复制当前值的新节点 copy。
  3. 按原顺序递归克隆每个孩子并追加到 copy.children。
  4. 返回 copy。

正确性证明

命题：算法对任意以 u 为根的子树，返回结构和值相同且不共享节点的副本。

基础情形：u 为空时返回空；u 为叶子时创建值相同、孩子为空的新节点，结论成立。

归纳步骤：假设每个孩子子树均能被正确深拷贝。算法新建当前节点，再按顺序接入各孩子的独立副本，所以值、分支数量、顺序和结构均一致。当前节点及所有后代都是新对象，故不共享节点，命题成立。

时间复杂度
O(n)
每个节点访问并创建一次。
额外空间
O(h)
递归栈取决于树高；返回副本 O(n) 不计入额外空间。

四种语言完整代码

/*
// Definition for a Node.
class Node {
    public int val;
    public List<Node> children;
    public Node() {}
    public Node(int val) { this.val = val; }
    public Node(int val, List<Node> children) {
        this.val = val; this.children = children;
    }
}
*/
class Solution {
    public Node cloneTree(Node root) {
        if (root == null) return null;
        List<Node> children = new ArrayList<>();
        for (Node child : root.children) {
            children.add(cloneTree(child));
        }
        return new Node(root.val, children);
    }
}

 * function Node(val, children) {

 *   this.children = children;
 * }
 */
var cloneTree = function(root) {
    if (root === null) return null;
    const copy = new Node(root.val, []);
    for (const child of root.children) {
        copy.children.push(cloneTree(child));
    }
    return copy;
};

// Definition for a Node.
class Node {
public:
    int val;
    vector<Node*> children;
    Node() {}
    Node(int val) : val(val) {}
    Node(int val, vector<Node*> children)

class Solution {
public:
    Node* cloneTree(Node* root) {
        if (root == nullptr) return nullptr;
        Node* copy = new Node(root->val);
        for (Node* child : root->children) {
            copy->children.push_back(cloneTree(child));
        }
        return copy;
    }
};

边界情况

  • 空树：直接返回 null。
  • 单节点：创建没有孩子的新节点。
  • 退化成长链：递归深度等于树深，注意语言栈限制。
  • 同值节点：不能按值复用，每个位置都要新建对象。
  • 超宽节点：孩子顺序必须保持。

替代方案

BFS：队列成对保存“原节点 / 副本节点”，逐层创建孩子，显式空间 O(w)。

哈希表：严格的树不需要；若推广为共享节点或含环的图，应记录原节点到副本的映射，防止重复克隆和无限递归。

面试追问

担心深度 1000 栈溢出？

改用 BFS 或显式栈模拟 DFS。

如果输入是图？

用 Map<原节点, 副本> 处理共享子节点与环。

怎样证明是真深拷贝？

比较结构和值，并验证所有对应节点引用不同；修改副本不影响原树。

常见错误

直接复用 children
副本仍指向原树孩子，属于浅拷贝。
打乱孩子顺序
无序重建会改变树的结构表示。
遗漏空树
访问 root.val 前必须先判空。
按值去重
值相等不代表同一节点，不能用值当缓存键。
