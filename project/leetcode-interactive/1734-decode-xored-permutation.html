解码异或后的排列

一串相邻元素的异或结果，能否唯一还原原排列？先理解题目，再用交互实验观察线索；完整思路默认收起。

1734MEDIUMDecode XORed Permutation非付费题

Problem

题意

有一个整数数组 perm，它是前 n 个正整数，即 1..n 的一个排列，并且 n 一定是奇数。

它被编码为长度为 n - 1 的数组 encoded，其中 encoded[i] = perm[i] XOR perm[i + 1]。给定 encoded，返回原始排列 perm。题目保证答案存在且唯一。

函数形式：decode(encoded: integer[]) → integer[]

示例 1
输入：encoded = [3,1]
输出：[1,2,3]
解释：[1 XOR 2, 2 XOR 3] = [3,1]
示例 2
输入：encoded = [6,5,4,6]
输出：[2,4,1,5,3]

约束

  • 3 ≤ n < 10⁵
  • n 是奇数
  • encoded.length == n - 1

Core insight

先找 perm[0]，再沿链还原

关键式：
perm[0] = (1 XOR 2 XOR … XOR n) XOR encoded[1] XOR encoded[3] XOR …

设 total = 1 XOR 2 XOR ... XOR n。因为 n 为奇数，encoded 的奇数下标项恰好覆盖 perm[1] XOR perm[2] XOR ... XOR perm[n-1]：

encoded[1] XOR encoded[3] XOR ... = (perm[1] XOR perm[2]) XOR (perm[3] XOR perm[4]) XOR ...

因此，再与包含全体排列元素的 total 异或，成对元素全部抵消，只剩 perm[0]。

Walkthrough

完整过程

  1. 令 n = encoded.length + 1。
  2. 计算 1..n 的异或和 total。
  3. 计算 encoded[1], encoded[3], ... 的异或和 withoutFirst。
  4. 得到 perm[0] = total XOR withoutFirst。
  5. 从左向右递推：perm[i+1] = perm[i] XOR encoded[i]。

样例 2：total = 1，withoutFirst = 5 XOR 6 = 3，所以 perm[0] = 1 XOR 3 = 2，继而得到 [2,4,1,5,3]。

正确性证明

引理 1：因为 perm 是 1..n 的排列，所以所有 perm 元素的异或值等于 total = 1 XOR ... XOR n。

引理 2：当 n 为奇数时，n-1 为偶数。所有奇数下标编码项两两不重叠，异或后正好包含 perm[1]..perm[n-1] 各一次。

首项：由异或自反律 x XOR x = 0，total XOR withoutFirst 抵消后只剩 perm[0]。

递推：若 perm[i] 已正确，因 encoded[i] = perm[i] XOR perm[i+1]，两边再异或 perm[i] 即得唯一正确的 perm[i+1]。由归纳法，算法返回完整原排列。

复杂度与边界

时间复杂度：O(n)，三次线性扫描的常数开销很小。

空间复杂度：O(n) 用于返回数组；若不计返回值，额外空间为 O(1)。

  • 最小合法规模 n = 3 同样适用。
  • n 必须为奇数，这是奇数下标编码项恰好覆盖除首项外所有元素的前提。
  • 数值不超过 n < 10⁵，四种语言的普通整数位运算均足够。

class Solution {
    public int[] decode(int[] encoded) {
        int n = encoded.length + 1;
        int total = 0;
        for (int value = 1; value <= n; value++) {
            total ^= value;
        }

        int withoutFirst = 0;
        for (int i = 1; i < encoded.length; i += 2) {
            withoutFirst ^= encoded[i];
        }

        int[] perm = new int[n];
        perm[0] = total ^ withoutFirst;
        for (int i = 0; i < encoded.length; i++) {
            perm[i + 1] = perm[i] ^ encoded[i];
        }
        return perm;
    }
}

Trade-offs

替代方案与追问

尝试每个首项

枚举 1..n 作为首项，再检查所得数组是否为排列。容易想到，但最坏 O(n²)；在 10⁵ 规模下不可取。

用集合验证

若题目不保证答案存在，可在还原后使用布尔数组验证范围与唯一性，需要额外 O(n) 空间。本题保证合法，无须增加开销。

周期公式优化

1..n 的异或和可用模 4 规律在 O(1) 计算，但整体仍要扫描并输出 n 个元素，总复杂度仍是 O(n)。

面试追问：为什么 n 为偶数时当前方法失效？

此时除首项外还有奇数个元素，无法由互不重叠的相邻二元组全部覆盖；仅凭这些异或关系一般不能唯一确定首项。

面试追问：能否原地复用 encoded？

encoded 只有 n-1 个位置，而输出有 n 个元素，普通数组无法完全原地返回；仍需一个长度为 n 的结果容器。

常见错误有哪些？

把“奇数位置”误写成下标 0,2,4...；忘记 n = encoded.length + 1；递推时使用了 encoded[i+1]；或误把逻辑异或与按位异或混用。
