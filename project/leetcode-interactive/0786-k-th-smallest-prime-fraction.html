第 K 个最小的质数分数

从一组严格递增的数字中构造所有合法分数，找到排序后的第 k 个。先理解问题，再通过交互实验观察分数前沿如何移动。

英文题名K-th Smallest Prime Fraction
输入arr, k
输出[分子, 分母]
付费限制无

Problem brief

题目要求

这里仅准确转述题意与输入输出，不提前展开求解方法。

题意

给定严格递增数组 arr，其中第一个元素是 1，其余元素都是互不相同的质数；另给整数 k。

对每一对下标 0 ≤ i < j < arr.length，构造分数：

arr[i] / arr[j]

将所有这些分数按数值从小到大排列，返回第 k 个分数对应的两个整数 [arr[i], arr[j]]。

示例 1
输入：arr = [1,2,3,5], k = 3
输出：[2,5]
解释：全部分数升序为 1/5, 1/3, 2/5, 1/2, 3/5, 2/3，第三个是 2/5。
示例 2
输入：arr = [1,7], k = 1
输出：[1,7]

约束

  • 2 ≤ arr.length ≤ 1000
  • 1 ≤ arr[i] ≤ 3 × 10⁴
  • arr[0] = 1
  • 当 i > 0 时，arr[i] 是质数
  • 所有元素互不相同，且严格递增
  • 1 ≤ k ≤ n(n − 1) / 2

准备好看完整题解了吗？

核心洞察、证明、复杂度、四语言实现与面试追问都收在下方，默认保持收起。

核心洞察：把二维分数拆成多条有序轨道

固定分母下标 j，合法分数依次是 arr[0]/arr[j]、arr[1]/arr[j]……arr[j-1]/arr[j]。分母不变而分子递增，所以这一列天然有序。

问题因此等价于合并 n − 1 条有序序列。优先队列只保存每条序列中“尚未取出的第一个分数”，也就是可视化里的候选前沿。

完整过程

  1. 对每个分母下标 j = 1..n−1，把状态 (0, j) 放入最小堆。
  2. 重复 k 次：从堆中取出数值最小的 (i, j)。
  3. 若 i + 1 < j，将同一分母轨道的下一个状态 (i+1, j) 放入堆。
  4. 第 k 次取出的状态就是答案，返回 [arr[i], arr[j]]。

比较两个分数 a/b 与 c/d 时使用交叉乘法 a×d < c×b，避免浮点误差。

正确性证明

引理 1：固定分母 arr[j] 后，随着 i 增大，arr[i]/arr[j] 严格增大，因此每条轨道有序。

引理 2：任意时刻，堆中都包含每条尚未耗尽轨道的最小未取出元素。初始化时成立；从某条轨道取出元素后，仅用该轨道的下一个元素补位，所以性质保持。

定理：由引理 2，全局最小的未取出分数一定是各轨道首元素中的最小值，也就是堆顶。因此每次取出都得到全局下一小分数，第 k 次取出的分数就是第 k 小。

边界处理

  • n = 2 时只有一个分数，初始化后第一次取出即可返回。
  • k = 1 时返回所有轨道首元素中的最小者。
  • k = n(n−1)/2 时会走到全部分数中的最大者。
  • 推进轨道前必须检查 i + 1 < j，否则会产生分子下标不小于分母下标的非法状态。
  • Java/C++ 中交叉乘积使用 64 位整数；JavaScript 的最大乘积不超过 9×10⁸，在安全整数范围内。

复杂度

O((n+k) log n)时间
O(n)额外空间

堆中最多保留 n−1 个候选；逐个入堆初始化计入 O(n log n)。

替代方案

  • 枚举 + 排序：生成全部 O(n²) 个分数再排序，简单但不满足进阶目标。
  • 值域二分 + 双指针：统计不大于中点的分数数量，并记录其中最大者；空间 O(1)，但实现要谨慎处理浮点收敛。

常见错误

  • 直接用浮点数作为长期比较依据。
  • 把同一对下标重复放入堆。
  • 轨道推进到了 i = j。
  • 忘记题目中的 k 从 1 开始。
  • 比较器交叉乘法左右下标写反。

面试追问

  • 为什么堆里只放每条轨道的一个元素就够？
  • 如何证明交叉乘法不会溢出？
  • 当 k 接近总分数数目时，能否改从大到小找？
  • 值域二分怎样在线性时间内完成计数？
import java.util.PriorityQueue;

class Solution {
    public int[] kthSmallestPrimeFraction(int[] arr, int k) {
        PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) ->
            Long.compare(
                (long) arr[a[0]] * arr[b[1]],
                (long) arr[b[0]] * arr[a[1]]
            )
        );

        for (int j = 1; j < arr.length; j++) {
            heap.offer(new int[] {0, j});
        }

        int[] current = null;
        for (int rank = 0; rank < k; rank++) {
            current = heap.poll();
            int i = current[0];
            int j = current[1];
            if (i + 1 < j) {
                heap.offer(new int[] {i + 1, j});
            }
        }

        return new int[] {arr[current[0]], arr[current[1]]};
    }
}

var kthSmallestPrimeFraction = function(arr, k) {
    const less = (a, b) =>
        arr[a[0]] * arr[b[1]] < arr[b[0]] * arr[a[1]];

    const heap = [];
    const push = (value) => {
        heap.push(value);
        let child = heap.length - 1;
        while (child > 0) {
            const parent = Math.floor((child - 1) / 2);
            if (!less(heap[child], heap[parent])) break;
            [heap[child], heap[parent]] = [heap[parent], heap[child]];
            child = parent;
        }
    };

    const pop = () => {
        const top = heap[0];
        const last = heap.pop();
        if (heap.length > 0) {
            heap[0] = last;
            let parent = 0;
            while (true) {
                let child = parent * 2 + 1;
                if (child >= heap.length) break;
                if (child + 1 < heap.length &&
                    less(heap[child + 1], heap[child])) {
                    child++;
                }
                if (!less(heap[child], heap[parent])) break;
                [heap[child], heap[parent]] = [heap[parent], heap[child]];
                parent = child;
            }
        }
        return top;
    };

    for (let j = 1; j < arr.length; j++) push([0, j]);

    let current;
    for (let rank = 0; rank < k; rank++) {
        current = pop();
        const [i, j] = current;
        if (i + 1 < j) push([i + 1, j]);
    }
    return [arr[current[0]], arr[current[1]]];
};
from typing import List
import heapq

class Solution:
    def kthSmallestPrimeFraction(
        self, arr: List[int], k: int
    ) -> List[int]:
        class Node:
            def __init__(self, i: int, j: int) -> None:
                self.i = i
                self.j = j

            def __lt__(self, other: "Node") -> bool:
                return (arr[self.i] * arr[other.j]
                        < arr[other.i] * arr[self.j])

        heap = [Node(0, j) for j in range(1, len(arr))]
        heapq.heapify(heap)

        current = None
        for _ in range(k):
            current = heapq.heappop(heap)
            if current.i + 1 < current.j:
                heapq.heappush(
                    heap,
                    Node(current.i + 1, current.j)
                )

        return [arr[current.i], arr[current.j]]
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> kthSmallestPrimeFraction(
        vector<int>& arr, int k
    ) {
        using State = pair<int, int>;
        auto greaterFraction = [&arr](const State& a,
                                      const State& b) {
            return (long long) arr[a.first] * arr[b.second]
                 > (long long) arr[b.first] * arr[a.second];
        };

        priority_queue<State, vector<State>,
                       decltype(greaterFraction)> heap(greaterFraction);

        for (int j = 1; j < (int) arr.size(); ++j) {
            heap.push({0, j});
        }

        State current;
        while (k-- > 0) {
            current = heap.top();
            heap.pop();
            auto [i, j] = current;
            if (i + 1 < j) {
                heap.push({i + 1, j});
            }
        }

        return {arr[current.first], arr[current.second]};
    }
};
