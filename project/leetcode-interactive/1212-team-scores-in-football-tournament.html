1212. 查询球队积分

把每场比赛拆成主队与客队各自的一条积分记录，再汇总成包含所有球队的排行榜。

数据库条件表达式UNION ALLLEFT JOIN

积分规则

3获胜
1平局
0失利

排序：总积分降序；积分相同则按 team_id 升序。

01题目描述

给定球队表 Teams 与已结束比赛表 Matches。一场比赛中，进球更多的一方获 3 分；双方进球相同，各获 1 分；失利方获 0 分。

请查询每支球队的 team_id、team_name 和总积分 num_points。没有参加任何比赛的球队也必须出现，其积分为 0。结果先按 num_points 降序，再按 team_id 升序排列。

Teams

Matches

ColumnType说明

host_teamINT主队编号
guest_teamINT客队编号
host_goalsINT主队进球数
guest_goalsINT客队进球数
约束与数据语义
  • team_id 与 match_id 分别唯一。
  • host_team、guest_team 均引用 Teams.team_id，且同场比赛的两支球队不同。
  • 进球数为非负整数；Matches 中记录的比赛均已结束。

05完整题解

核心洞察完整过程正确性边界复杂度替代方案面试追问常见错误代码

核心洞察：一场比赛拆成两条球队积分

比赛表一行同时描述两支球队，但排行榜需要“每支球队一行”。因此先把每场比赛投影为两条记录：一条属于主队，一条属于客队，并分别用 CASE 算出 3、1、0 分。使用 UNION ALL 保留每一条贡献，再按球队汇总。

汇总结果必须从 Teams 出发做 LEFT JOIN，这样从未参赛的球队不会消失；其空积分再用 COALESCE 变为 0。

完整过程

  1. 扫描 Matches，为主队生成 (host_team, points)。
  2. 再次投影同一批比赛，为客队生成 (guest_team, points)。
  3. 用 UNION ALL 合并两侧记录。不能使用 UNION，否则内容相同的积分行可能被去重。
  4. 从所有球队出发左连接积分明细，按球队编号与名称分组求和。
  5. 把未参赛球队的 NULL 改为 0，最后按积分降序、球队编号升序排序。

正确性说明

引理 1：积分明细恰好包含每场比赛中两支球队各自应得的一条积分。主队分支按比分三种关系返回 3、1、0；客队分支使用对称条件，也返回其唯一正确积分。两分支通过 UNION ALL 合并，不丢失重复贡献。

引理 2：对某球队的明细积分求和，等于该球队在所有已结束比赛中获得的总积分，因为每场相关比赛贡献一次且仅一次。

定理：查询从 Teams 保留每支球队；有比赛者由引理 2 得到正确总分，无比赛者通过 COALESCE 得 0。最终排序严格符合题意，因此输出正确。

边界情况

  • 球队从未参赛：必须输出 0 分。
  • 全部比赛都是平局：每次双方各加 1。
  • 多支球队同分：按 team_id 升序稳定决定顺序。
  • 同一对球队多次比赛或多场产生相同积分：每场都要保留，不能去重。

复杂度

设球队数为 T、比赛数为 M。逻辑上生成 2M 条积分明细并聚合，时间复杂度约为 O(T + M)；排序至多为 O(T log T)。中间积分明细占 O(M) 空间，具体执行计划与数据库优化器有关。

替代方案

也可以分别在主队侧、客队侧先聚合，再将两个聚合结果合并后二次求和；这可能减少中间行数，但 SQL 更长。还可以通过带 OR 的连接一次匹配主客队，再用复杂的 CASE 判断角色；这种写法通常可读性较差，也更容易让连接条件影响索引策略。

面试追问

  • 为什么必须是 UNION ALL，而不是 UNION？
  • 如果积分规则存放在配置表中，如何避免把 3、1、0 写死？
  • 若比赛存在取消、延期或赛季字段，查询应在什么位置过滤？
  • 数据量很大时，会为 host_team、guest_team、赛季与状态建立怎样的索引？

常见错误

  • 从 Matches 开始聚合，导致未参赛球队缺失。
  • 使用 UNION 去重，使多场相同结果的积分贡献被误删。
  • 客队分支仍按主队条件计分，胜负恰好颠倒。
  • 忘记 COALESCE，未参赛球队显示 NULL。
  • 只按积分排序，忽略同分时的 team_id ASC。

MySQL可提交
WITH points AS (
    SELECT
        host_team AS team_id,
        CASE
            WHEN host_goals > guest_goals THEN 3
            WHEN host_goals = guest_goals THEN 1
            ELSE 0
        END AS points
    FROM Matches

    UNION ALL

    SELECT
        guest_team AS team_id,
        CASE
            WHEN guest_goals > host_goals THEN 3
            WHEN guest_goals = host_goals THEN 1
            ELSE 0
        END AS points
    FROM Matches
)
SELECT
    t.team_id,
    t.team_name,
    COALESCE(SUM(p.points), 0) AS num_points
FROM Teams AS t
LEFT JOIN points AS p
    ON p.team_id = t.team_id
GROUP BY t.team_id, t.team_name
ORDER BY num_points DESC, t.team_id ASC;

import java.util.*;

public class Main {
    record Team(int id, String name) {}
    record Match(int id, int host, int guest, int hostGoals, int guestGoals) {}
    record Row(int id, String name, int points) {}

    static List<Row> teamScores(List<Team> teams, List<Match> matches) {
        Map<Integer, Integer> points = new HashMap<>();
        for (Team team : teams) points.put(team.id(), 0);

        for (Match match : matches) {
            int hostPoints = match.hostGoals() > match.guestGoals() ? 3
                : match.hostGoals() == match.guestGoals() ? 1 : 0;
            int guestPoints = match.guestGoals() > match.hostGoals() ? 3
                : match.guestGoals() == match.hostGoals() ? 1 : 0;
            points.merge(match.host(), hostPoints, Integer::sum);
            points.merge(match.guest(), guestPoints, Integer::sum);
        }

        List<Row> result = new ArrayList<>();
        for (Team team : teams) {
            result.add(new Row(team.id(), team.name(), points.get(team.id())));
        }
        result.sort(Comparator.comparingInt(Row::points).reversed()
            .thenComparingInt(Row::id));
        return result;
    }

    public static void main(String[] args) {
        List<Team> teams = List.of(new Team(10, "Leetcode FC"),
            new Team(20, "NewYork FC"), new Team(30, "Atlanta FC"),
            new Team(40, "Chicago FC"), new Team(50, "Toronto FC"));
        List<Match> matches = List.of(new Match(1,10,20,3,0),
            new Match(2,30,10,2,2), new Match(3,10,50,5,1),
            new Match(4,20,30,1,0), new Match(5,50,30,1,0));
        teamScores(teams, matches).forEach(System.out::println);
    }
}

function teamScores(teams, matches) {
  const points = new Map(teams.map(team => [team.team_id, 0]));

  for (const match of matches) {
    const hostPoints = match.host_goals > match.guest_goals ? 3
      : match.host_goals === match.guest_goals ? 1 : 0;
    const guestPoints = match.guest_goals > match.host_goals ? 3
      : match.guest_goals === match.host_goals ? 1 : 0;
    points.set(match.host_team, points.get(match.host_team) + hostPoints);
    points.set(match.guest_team, points.get(match.guest_team) + guestPoints);
  }

  return teams
    .map(team => ({ ...team, num_points: points.get(team.team_id) }))
    .sort((a, b) => b.num_points - a.num_points || a.team_id - b.team_id);
}

from typing import TypedDict

class Team(TypedDict):
    team_id: int
    team_name: str

class Match(TypedDict):
    match_id: int
    host_team: int
    guest_team: int
    host_goals: int
    guest_goals: int

def team_scores(teams: list[Team], matches: list[Match]) -> list[dict]:
    points = {team["team_id"]: 0 for team in teams}

    for match in matches:
        host_goals = match["host_goals"]
        guest_goals = match["guest_goals"]
        host_points = 3 if host_goals > guest_goals else 1 if host_goals == guest_goals else 0
        guest_points = 3 if guest_goals > host_goals else 1 if guest_goals == host_goals else 0
        points[match["host_team"]] += host_points
        points[match["guest_team"]] += guest_points

    result = [
        {**team, "num_points": points[team["team_id"]]}
        for team in teams
    ]
    return sorted(result, key=lambda row: (-row["num_points"], row["team_id"]))

#include <algorithm>
#include <iostream>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Team { int id; string name; };
struct Match { int id, host, guest, hostGoals, guestGoals; };
struct Row { int id; string name; int points; };

vector<Row> teamScores(const vector<Team>& teams,
                       const vector<Match>& matches) {
    unordered_map<int, int> points;
    for (const Team& team : teams) points[team.id] = 0;

    for (const Match& match : matches) {
        int hostPoints = match.hostGoals > match.guestGoals ? 3
            : match.hostGoals == match.guestGoals ? 1 : 0;
        int guestPoints = match.guestGoals > match.hostGoals ? 3
            : match.guestGoals == match.hostGoals ? 1 : 0;
        points[match.host] += hostPoints;
        points[match.guest] += guestPoints;
    }

    vector<Row> result;
    for (const Team& team : teams) {
        result.push_back({team.id, team.name, points[team.id]});
    }
    sort(result.begin(), result.end(), [](const Row& a, const Row& b) {
        return a.points != b.points ? a.points > b.points : a.id < b.id;
    });
    return result;
}

int main() {
    vector<Team> teams = {{10,"Leetcode FC"},{20,"NewYork FC"},
        {30,"Atlanta FC"},{40,"Chicago FC"},{50,"Toronto FC"}};
    vector<Match> matches = {{1,10,20,3,0},{2,30,10,2,2},
        {3,10,50,5,1},{4,20,30,1,0},{5,50,30,1,0}};
    for (const Row& row : teamScores(teams, matches)) {
        cout << row.id << " | " << row.name << " | " << row.points << '\n';
    }
}
