Maximum Score After Splitting a String

在每一条合法缝隙处切开二进制字符串：左侧的 0 与右侧的 1 都会得分。先亲手移动切线，观察得分如何变化。

Problem

题目要求

函数：maxScore(s)

给定一个只包含 0 和 1 的字符串 s，在某个字符间隙把它分成两个非空子字符串。

一次分割的得分等于 左侧 0 的数量 + 右侧 1 的数量。返回所有合法分割中的最大得分。

题解区域

Solution

一次扫描：让切线向右走

O(n) 时间 · O(1) 空间

先数出整个字符串里有多少个 1。切线每跨过一个字符，只需更新左侧 0 数或右侧 1 数，就能立刻得到新分割的得分。

核心洞察

把变量维护成当前切线两边真正需要的量：zerosLeft 和 onesRight。字符从右侧移到左侧时，若是 0，前者加一；若是 1，后者减一。

完整过程

  1. 统计 s 中所有 1，作为初始 onesRight。
  2. 让下标 i 从 0 走到 n - 2。
  3. 把 s[i] 纳入左侧并更新计数。
  4. 用两项之和更新最大值。

边界处理

  • 循环止于 n - 2，保证右侧至少留一个字符。
  • 全 0、全 1 仍适用，无需特判。
  • 长度为 2 时只有一个合法分割点。

复杂度

第一次计数和第二次扫描都为线性，合并为 O(n) 时间；只使用固定数量的整数变量，额外空间为 O(1)。

时间 O(n)空间 O(1)

正确性说明

循环不变量：处理完位置 i 后，zerosLeft 恰好等于 s[0..i] 中 0 的数量，onesRight 恰好等于 s[i+1..n-1] 中 1 的数量。因此两者之和就是在 i 后切开的准确得分。循环依次覆盖全部 n-1 个合法分割点，取到的最大值必然是全局最大得分。

四语言完整代码

Java官方签名
class Solution {
    public int maxScore(String s) {
        int onesRight = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '1') onesRight++;
        }

        int zerosLeft = 0;
        int answer = 0;
        for (int i = 0; i < s.length() - 1; i++) {
            if (s.charAt(i) == '0') {
                zerosLeft++;
            } else {
                onesRight--;
            }
            answer = Math.max(answer, zerosLeft + onesRight);
        }
        return answer;
    }
}

C++官方签名
class Solution {
public:
    int maxScore(string s) {
        int onesRight = 0;
        for (char ch : s) {
            if (ch == '1') ++onesRight;
        }

        int zerosLeft = 0;
        int answer = 0;
        for (int i = 0; i < static_cast<int>(s.size()) - 1; ++i) {
            if (s[i] == '0') {
                ++zerosLeft;
            } else {
                --onesRight;
            }
            answer = max(answer, zerosLeft + onesRight);
        }
        return answer;
    }
};

替代方案

可以为 0 和 1 分别建立前缀和，然后 O(1) 查询每个分割点；总时间仍为 O(n)，但需要 O(n) 空间。也可以对每个分割重新计数，写法直观却会退化为 O(n²)。

常见错误

  • 遍历到最后一个字符，使右子串为空。
  • 移动 1 时忘记从 onesRight 中减去。
  • 把右侧 0 或左侧 1 误算入得分。
  • 最大值只在循环结束后更新，遗漏中间分割点。

面试追问

  • 能否把两次扫描合并为一次？提示：把得分写成“固定总量 + 动态差值”。
  • 若 0 和 1 各自有不同权重，状态如何更新？
  • 若必须分成 k 个非空段并定义分段得分，该如何建模？

一步扫描变体

除最后一位外，维护 zeros - ones 的最大值；答案等于“字符串中 1 的总数 + 最大差值”。它仍需知道总 1 数，表达更数学化，但双计数版本通常更易讲清。
