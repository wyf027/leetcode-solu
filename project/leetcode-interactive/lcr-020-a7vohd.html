回文子串

回文像一面以中心为轴的镜子。枚举每个单字符中心和相邻双字符中心，向两侧扩展并在每次匹配时累计答案。

Reasoning / 题意拆解

每个回文都恰好拥有一个中心

为什么是 2n−1 个中心？

n 个字符中心对应奇数长度，n−1 个间隙中心对应偶数长度。两类中心合起来不遗漏任何回文。

一次扩展为何计数？

当 s[left] === s[right] 时，区间 [left, right] 就是一个新回文；继续向外尝试即可。

停止条件

越界或两端字符不同立刻停止。无需维护 DP 表，也不需要额外字符串空间。

执行步骤

  1. 遍历 i = 0 到 n−1。
  2. 从 (i, i) 扩展，统计奇数长度回文。
  3. 从 (i, i+1) 扩展，统计偶数长度回文。
  4. 两次扩展的成功次数都累加到答案。

复杂度与常见错误

  • 最坏时间 O(n²)，额外空间 O(1)。
  • 只检查 (i, i) 会漏掉 "aa"、"abba" 等偶数回文。
  • 每次成功比较后必须先计数，再继续 left--、right++。
  • 单字符天然是回文，因此每个字符中心至少贡献一个。

class Solution {
    public int countSubstrings(String s) {
        int answer = 0;
        for (int center = 0; center < s.length(); center++) {
            answer += expand(s, center, center);
            answer += expand(s, center, center + 1);
        }
        return answer;
    }

    private int expand(String s, int left, int right) {
        int count = 0;
        while (left >= 0 && right < s.length() &&
               s.charAt(left) == s.charAt(right)) {
            count++;
            left--;
            right++;
        }
        return count;
    }
}

class Solution {
    int expand(const string& s, int left, int right) {
        int count = 0;
        while (left >= 0 && right < s.size() && s[left] == s[right]) {
            ++count;
            --left;
            ++right;
        }
        return count;
    }
public:

        int answer = 0;
        for (int i = 0; i < s.size(); ++i)
            answer += expand(s, i, i) + expand(s, i, i + 1);
        return answer;
    }
};
