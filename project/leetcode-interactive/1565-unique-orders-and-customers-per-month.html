按月统计订单数与顾客数

Unique Orders and Customers Per Month

#1565EasyDatabasePaid only
01 · Brief

题目说明

先读题，再决定查询结构

给定订单表 Orders。请对发票金额严格大于 20 的订单，按订单日期所属的自然月统计：该月的订单数，以及下单顾客的去重数量。

输出列为 month、order_count、customer_count；month 使用 YYYY-MM。没有任何合格订单的月份不应出现。结果允许按任意顺序返回。

注意边界：条件是 invoice > 20，金额恰好为 20 的订单不计入。

04 · Solution

筛选 → 分月 → 聚合

1

先筛选

只保留 invoice > 20，使后续每个分组天然只含合格订单。

2

统一月份键

将完整日期格式化为 YYYY-MM，年份与月份一起参与分组。

3

分别计数

订单 ID 唯一，直接计数；顾客可能重复，必须使用去重计数。

完整过程

  1. 扫描 Orders，用 WHERE invoice > 20 丢弃不合格订单。
  2. 为每个保留行计算月份键 DATE_FORMAT(order_date, '%Y-%m')。
  3. 按月份键分组。组内 COUNT(order_id) 得到订单数，COUNT(DISTINCT customer_id) 得到不同顾客数。
  4. 返回三个指定列。题目允许任意顺序；显式排序只用于让展示更稳定，不是正确性的必要条件。

正确性

筛选后留下的集合恰好是金额严格大于 20 的全部订单。月份格式化把且只把同一自然月的行放进同一组。由于 order_id 唯一，组内行数等于合格订单数；对 customer_id 去重后计数，恰好得到该月合格订单涉及的不同顾客数。因此每个输出行的两个计数都符合要求。

边界

  • invoice = 20：被排除。
  • 整月无合格订单：不会生成分组。
  • 同一顾客同月多单：订单全部计入，顾客只计一次。
  • 跨年同月：2020-01 与 2021-01 不会混组。

复杂度

设表中有 n 行。逻辑扫描成本为 O(n)；分组与去重通常使用哈希或排序，实际成本由数据库执行计划和索引决定。聚合工作内存与分组数量及各组的不同顾客数量有关。

替代方案

可以用条件聚合一次保留所有月份，但还需额外排除计数为 0 的月份，表达更绕。PostgreSQL 可用 TO_CHAR 或 DATE_TRUNC；SQL Server 可用 FORMAT 或年份、月份组合键。生产环境通常优先按原生日期范围分区，并在最后格式化展示。

MySQL · 官方可提交语言Primary
SELECT
    DATE_FORMAT(order_date, '%Y-%m') AS month,
    COUNT(order_id) AS order_count,
    COUNT(DISTINCT customer_id) AS customer_count
FROM Orders
WHERE invoice > 20
GROUP BY DATE_FORMAT(order_date, '%Y-%m');

Java · 本地语义参考
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.util.*;

public class Solution {
    public record Order(int orderId, LocalDate orderDate, int customerId, int invoice) {}
    public record Result(String month, int orderCount, int customerCount) {}

    private static final class Bucket {
        int orders;
        Set<Integer> customers = new HashSet<>();
    }

    public List<Result> uniqueOrdersAndCustomers(List<Order> orders) {
        DateTimeFormatter monthFormat = DateTimeFormatter.ofPattern("yyyy-MM");
        Map<String, Bucket> groups = new TreeMap<>();

        for (Order order : orders) {
            if (order.invoice() <= 20) continue;
            String month = order.orderDate().format(monthFormat);
            Bucket bucket = groups.computeIfAbsent(month, key -> new Bucket());
            bucket.orders++;
            bucket.customers.add(order.customerId());
        }

        List<Result> answer = new ArrayList<>();
        for (Map.Entry<String, Bucket> entry : groups.entrySet()) {
            Bucket b = entry.getValue();
            answer.add(new Result(entry.getKey(), b.orders, b.customers.size()));
        }
        return answer;
    }
}
JavaScript · 本地语义参考
/**
 * @param {{order_id:number, order_date:string, customer_id:number, invoice:number}[]} orders
 * @return {{month:string, order_count:number, customer_count:number}[]}
 */
function uniqueOrdersAndCustomers(orders) {
  const groups = new Map();

  for (const order of orders) {
    if (order.invoice <= 20) continue;
    const month = order.order_date.slice(0, 7);
    if (!groups.has(month)) groups.set(month, { orders: 0, customers: new Set() });
    const bucket = groups.get(month);
    bucket.orders += 1;
    bucket.customers.add(order.customer_id);
  }

  return [...groups.entries()]
    .sort(([a], [b]) => a.localeCompare(b))
    .map(([month, bucket]) => ({
      month,
      order_count: bucket.orders,
      customer_count: bucket.customers.size,
    }));
}
Python · 本地语义参考
from collections import defaultdict
from datetime import date
from typing import TypedDict


class Order(TypedDict):
    order_id: int
    order_date: date
    customer_id: int
    invoice: int


def unique_orders_and_customers(orders: list[Order]) -> list[dict[str, int | str]]:
    groups: dict[str, dict[str, object]] = defaultdict(
        lambda: {"order_count": 0, "customers": set()}
    )

    for order in orders:
        if order["invoice"] <= 20:
            continue
        month = order["order_date"].strftime("%Y-%m")
        groups[month]["order_count"] += 1
        groups[month]["customers"].add(order["customer_id"])

    return [
        {
            "month": month,
            "order_count": data["order_count"],
            "customer_count": len(data["customers"]),
        }
        for month, data in sorted(groups.items())
    ]
C++ · 本地语义参考
#include <map>
#include <set>
#include <string>
#include <vector>

struct Order {
    int orderId;
    std::string orderDate;  // YYYY-MM-DD
    int customerId;
    int invoice;
};

struct Result {
    std::string month;
    int orderCount;
    int customerCount;
};

std::vector<Result> uniqueOrdersAndCustomers(const std::vector<Order>& orders) {
    struct Bucket {
        int orderCount = 0;
        std::set<int> customers;
    };
    std::map<std::string, Bucket> groups;

    for (const Order& order : orders) {
        if (order.invoice <= 20) continue;
        std::string month = order.orderDate.substr(0, 7);
        Bucket& bucket = groups[month];
        ++bucket.orderCount;
        bucket.customers.insert(order.customerId);
    }

    std::vector<Result> answer;
    for (const auto& [month, bucket] : groups) {
        answer.push_back({month, bucket.orderCount,
                          static_cast<int>(bucket.customers.size())});
    }
    return answer;
}

面试追问

  • 为什么顾客要 DISTINCT，订单不用？ 因为表定义保证 order_id 唯一，而同一顾客可以在同月多次下单。为了应对脏数据，也可把订单写成 COUNT(DISTINCT order_id)。
  • 数据量很大怎么办？ 观察过滤选择性、日期分区和执行计划；仅对展示字段做日期格式化，避免让日期范围索引失效。
  • 要补齐没有订单的月份呢？ 需要日历表或递归 CTE 生成月份序列，再左连接聚合结果并用 0 补空值。
  • 如果阈值可配置？ 使用参数绑定，不拼接 SQL 字符串；相同过滤条件仍应尽量前置。

常见错误

  • 写成 invoice >= 20，错误包含边界值 20。
  • 只按月份数字分组，导致不同年份的同月混在一起。
  • 对顾客使用普通 COUNT，重复计算同月多次下单的顾客。
  • 用条件聚合保留了整月均不合格的月份，却忘记排除计数为 0 的行。
  • 把结果顺序当作数据库的隐含保证；若业务需要稳定顺序，应明确写 ORDER BY。
