打印零与奇偶数

三个线程并不是在比赛谁先打印，而是在共同执行一份严格的交接协议：零线程开场，奇数或偶数线程接棒，然后把控制权交还。

MEDIUM多线程信号量Print Zero Even Odd

题目

给定一个由三个线程共享的 ZeroEvenOdd 实例。线程 A 调用 zero()，只能输出 0；线程 B 调用 even()，只能输出偶数；线程 C 调用 odd()，只能输出奇数。

请同步这三个方法，使最终输出依次为 010203…0n，也就是对每个 i = 1..n，先输出一个零，再输出 i。三条线程可能以任意顺序被调度。

接口形式
ZeroEvenOdd(int n)
void zero(printNumber)
void even(printNumber)
void odd(printNumber)

约束与目标

  • 1 <= n <= 1000
  • printNumber(x) 将整数 x 输出到控制台。
  • 三个方法由三条不同线程并发调用。
  • 共调用打印函数 2n 次。

关键要求：输出顺序必须确定，与操作系统怎样穿插调度线程无关。

官方示例

示例 1

输入：n = 2
输出："0102"

解释：三条线程异步执行，分别调用 zero()、even()、odd()；正确的有序输出是 0102。

示例 2

输入：n = 5
输出："0102030405"

线程接力台

观察许可证如何在三条线程之间传递。演示固定使用 n = 5；它表现的是同步规则，而不是某一次真实调度耗时。

步骤 0/10：只有零线程持有初始许可证。

先尝试设计三张“许可证”的初始数量与交接方向。

题解：三只信号量构成确定性接力

让 zero 信号量初始为 1，odd 与 even 初始为 0。任何时刻只放行应该打印的那条线程，打印完成后再精准唤醒下一棒。

完整过程

zero 获取 Z打印 0
看 i 奇偶释放 O 或 E
数字线程打印 i只运行对应奇偶线程
释放 Z开始下一轮
  1. 零线程循环 i = 1..n，获取 zero 后打印 0。
  2. 若 i 为奇数就释放 odd，否则释放 even。
  3. 奇数线程只遍历 1,3,5…；偶数线程只遍历 2,4,6…。各自获取许可证、打印数字、释放 zero。

正确性

不变式：每轮开始时仅 zero 拥有一个可用许可证。于是该轮首先且只能打印 0。随后 zero 根据轮次 i 只释放 odd 或 even 中正确的一只信号量，因此接着只能打印 i。数字线程打印后只释放 zero，使下一轮才能开始。由数学归纳法，前 k 轮输出必为 0102…0k；完成第 n 轮即得到目标序列。

边界与复杂度

  • n = 1：输出 01，偶数线程不进入循环。
  • n = 1000：循环次数线性增长，不保存输出数组。
  • 时间复杂度 O(n)，额外空间 O(1)（固定数量同步原语）。

替代方案

也可以用一把互斥锁、一个条件变量和状态值 turn 实现；等待必须写成 while 防御虚假唤醒。信号量方案更直接地表达“许可证交接”，但部分语言或运行环境需选择等价同步原语。

面试追问

  • 为何不能用休眠控制顺序？调度和机器负载不可预测。
  • 若打印函数抛异常如何处理？应通过 finally 或明确的取消协议避免其他线程永久等待。
  • 如何推广到多个余数线程？为每种状态准备条件/信号量，由当前线程释放确定的下一状态。

常见错误

  • zero 初始许可证设为 0，导致三条线程全部阻塞。
  • 数字线程打印后唤醒另一个数字线程，破坏“每个数字前一个 0”。
  • JavaScript 直接把普通同步循环当作多线程；应使用异步闸门模拟可等待的许可证。
  • 条件变量用 if 而非 while 检查条件。

四种语言完整实现

import java.util.concurrent.Semaphore;
import java.util.function.IntConsumer;

class ZeroEvenOdd {
    private final int n;
    private final Semaphore zero = new Semaphore(1);
    private final Semaphore odd = new Semaphore(0);
    private final Semaphore even = new Semaphore(0);

    public ZeroEvenOdd(int n) { this.n = n; }

    public void zero(IntConsumer printNumber) throws InterruptedException {
        for (int i = 1; i <= n; i++) {
            zero.acquire();
            printNumber.accept(0);
            if ((i & 1) == 1) odd.release();
            else even.release();
        }
    }
    public void even(IntConsumer printNumber) throws InterruptedException {
        for (int i = 2; i <= n; i += 2) {
            even.acquire();
            printNumber.accept(i);
            zero.release();
        }
    }
    public void odd(IntConsumer printNumber) throws InterruptedException {
        for (int i = 1; i <= n; i += 2) {
            odd.acquire();
            printNumber.accept(i);
            zero.release();
        }
    }
}

JavaScript 为本地语义参考：用 Promise 闸门表达异步任务的许可证交接，并非 LeetCode 本题官方可提交语言。

class Gate {
  constructor(permits = 0) { this.permits = permits; this.waiters = []; }
  acquire() {
    if (this.permits > 0) { this.permits--; return Promise.resolve(); }
    return new Promise(resolve => this.waiters.push(resolve));
  }
  release() {
    const resolve = this.waiters.shift();
    if (resolve) resolve(); else this.permits++;
  }
}

class ZeroEvenOdd {
  constructor(n) {
    this.n = n;
    this.z = new Gate(1); this.o = new Gate(0); this.e = new Gate(0);
  }
  async zero(printNumber) {
    for (let i = 1; i <= this.n; i++) {
      await this.z.acquire(); printNumber(0);
      (i % 2 ? this.o : this.e).release();
    }
  }
  async odd(printNumber) {
    for (let i = 1; i <= this.n; i += 2) {
      await this.o.acquire(); printNumber(i); this.z.release();
    }
  }
  async even(printNumber) {
    for (let i = 2; i <= this.n; i += 2) {
      await this.e.acquire(); printNumber(i); this.z.release();
    }
  }
}
from threading import Semaphore
from typing import Callable

class ZeroEvenOdd:
    def __init__(self, n: int):
        self.n = n
        self.z = Semaphore(1)
        self.o = Semaphore(0)
        self.e = Semaphore(0)

    def zero(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(1, self.n + 1):
            self.z.acquire()
            printNumber(0)
            (self.o if i % 2 else self.e).release()

    def odd(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(1, self.n + 1, 2):
            self.o.acquire()
            printNumber(i)
            self.z.release()

    def even(self, printNumber: 'Callable[[int], None]') -> None:
        for i in range(2, self.n + 1, 2):
            self.e.acquire()
            printNumber(i)
            self.z.release()
#include <condition_variable>
#include <functional>
#include <mutex>
using namespace std;

class ZeroEvenOdd {
    int n, turn = 0; // 0=zero, 1=odd, 2=even
    mutex m;
    condition_variable cv;
public:
    ZeroEvenOdd(int n) : n(n) {}
    void zero(function<void(int)> printNumber) {
        for (int i = 1; i <= n; ++i) {
            unique_lock<mutex> lock(m);
            cv.wait(lock, [&]{ return turn == 0; });
            printNumber(0);
            turn = (i & 1) ? 1 : 2;
            cv.notify_all();
        }
    }
    void odd(function<void(int)> printNumber) {
        for (int i = 1; i <= n; i += 2) {
            unique_lock<mutex> lock(m);
            cv.wait(lock, [&]{ return turn == 1; });
            printNumber(i); turn = 0; cv.notify_all();
        }
    }
    void even(function<void(int)> printNumber) {
        for (int i = 2; i <= n; i += 2) {
            unique_lock<mutex> lock(m);
            cv.wait(lock, [&]{ return turn == 2; });
            printNumber(i); turn = 0; cv.notify_all();
        }
    }
};
