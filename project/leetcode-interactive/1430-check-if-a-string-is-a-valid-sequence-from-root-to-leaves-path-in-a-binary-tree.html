这串数字，真的走到了叶子吗？

给你一棵二叉树和整数数组 arr。判断是否存在一条从根节点开始、在叶节点结束的向下路径，使沿途节点值依次与数组完全相同。

TreeDFSBFSBinary Tree
判定重点：数值顺序相同还不够；数组必须恰好覆盖一条完整的“根 → 叶”路径，不能提前结束，也不能在到达叶子后仍有剩余元素。
01

题目说明

函数签名

isValidSequence(root, arr) → boolean

root 是二叉树根节点；arr 是待匹配的整数序列。若存在完全匹配的根到叶路径，返回 true，否则返回 false。

约束
  • 树中节点数在 [1, 5000] 内。
  • 0 ≤ Node.val ≤ 9。
  • 1 ≤ arr.length ≤ 5000。
  • 0 ≤ arr[i] ≤ 9。
示例 1
输入：
root = [0,1,0,0,1,0,null,null,1,0,0]
arr  = [0,1,0,1]

输出：true

序列对应根节点向左、再向左、最后向右到达叶节点的路径。

示例 2
输入：
root = [0,1,0,0,1,0,null,null,1,0,0]
arr  = [0,0,1]

输出：false

树中没有值依次为 0 → 0 → 1 的根到叶路径。

示例 3
输入：
root = [0,1,0,0,1,0,null,null,1,0,0]
arr  = [0,1,1]

输出：false

虽然能走到值为 1 的节点，但该节点不是叶子，序列结束得太早。

深度优先搜索：位置与节点同步推进

核心洞察

搜索状态只需要两个量：当前树节点 node 和它应该匹配的数组下标 i。任何时候，只要节点为空、下标越界或 node.val !== arr[i]，该分支立即失败。只有当 i 位于数组最后一项，并且当前节点同时是叶子时，才算完整匹配。

完整过程

  1. 从 dfs(root, 0) 开始。
  2. 先检查节点存在、下标有效且值相等；否则返回 false。
  3. 若已经匹配数组最后一个元素，返回“当前节点是否为叶子”。
  4. 否则让下标加一，递归搜索左子树或右子树；任意一边成功即可。

正确性说明

必要性：算法返回 true 时，每一层都验证了节点值等于对应的 arr[i]，递归从父节点走向子节点，且最后一个元素只在叶节点处被接受，因此得到的必然是一条值序列完全相同的根到叶路径。
充分性：如果存在满足条件的根到叶路径，算法从根开始会枚举每个值匹配的左右分支。沿目标路径的每次检查都能通过，最终在数组最后一项和目标叶节点同时到达时返回 true，并通过逻辑或传回根节点。

必要性与充分性同时成立，因此算法正确。

复杂度

时间：O(n)，最坏访问整棵树的每个节点。
空间：O(h)，递归栈深度等于树高；退化树最坏为 O(n)。

关键边界

  • 只有一个节点：数组必须恰好含相同的一个值。
  • 数组在非叶节点结束：必须判假。
  • 已到叶子但数组还有元素：必须判假。
  • 根节点就不匹配：立即剪枝。

四语言完整代码

class Solution {
    public boolean isValidSequence(TreeNode root, int[] arr) {
        return dfs(root, arr, 0);
    }

    private boolean dfs(TreeNode node, int[] arr, int index) {
        if (node == null || index == arr.length || node.val != arr[index]) {
            return false;
        }
        if (index == arr.length - 1) {
            return node.left == null && node.right == null;
        }
        return dfs(node.left, arr, index + 1)
            || dfs(node.right, arr, index + 1);
    }
}

替代方案

可以使用队列执行 BFS，并把 (node, index) 成对入队；判断条件完全相同。BFS 的最坏时间仍为 O(n)，但队列可能容纳一整层，空间为 O(w)。递归 DFS 更贴合“沿路径推进”的结构，代码也更紧凑。

面试追问

  • 若树高可能达到百万，如何改为显式栈避免递归溢出？
  • 若要返回所有匹配路径而不是布尔值，状态和返回类型怎样调整？
  • 若节点值是字符串片段，如何匹配一整个字符序列？

常见错误

  • 数组匹配完就直接返回真，漏掉“当前节点必须是叶子”。
  • 走到叶子就返回真，漏掉“数组也必须恰好用完”。
  • 把问题理解成任意向下路径，未强制从根开始。
  • 值不匹配后仍继续搜索子树，既浪费时间又可能产生错误结果。
