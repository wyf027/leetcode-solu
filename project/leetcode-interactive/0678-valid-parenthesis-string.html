括号字符串

一个星号有三种身份。你的任务不是立刻替它做决定，而是判断：是否存在一种解释，让整段括号保持有效。

01 · Problem

先读懂星号的自由度

给定字符串 s，其中只含 (、) 与 *。若能把每个 * 独立解释为左括号、右括号或空字符串，使最终括号串有效，则返回 true；否则返回 false。

  • 1每个左括号都必须与之后出现的一个右括号配对。
  • 2每个右括号都必须有一个更早出现、尚未配对的左括号。
  • 3每个星号可以分别选择 (、) 或空字符串，不要求所有星号选择相同身份。

Greedy interval solution

不猜星号，只维护所有可能

用两个边界压缩指数级分支：low 是当前可能的最少未闭合左括号数，high 是最多数量。

核心洞察

处理完任意前缀后，所有可达到的“未闭合左括号数”可以用一个连续区间 [low, high] 表示。我们不需要保存每一种星号选择，只要更新区间两端。若 high < 0，说明即使把此前星号都尽量当作左括号，当前右括号仍无处配对；扫描结束后，只有 low == 0 才表示存在一种选择能完全闭合。

完整过程

1

初始化：low = high = 0，空前缀的未闭合数只能是 0。

2

遇到 (：每种解释都新增一个未闭合左括号，因此 low++、high++。

3

遇到 )：它尝试闭合一个左括号，因此 low--、high--；最低值不能为负，更新为 low = max(low, 0)。

4

遇到 *：把它当右括号可让下界减 1，把它当左括号可让上界加 1；空串的结果自然位于两者之间，所以 low = max(low - 1, 0)、high++。

5

任一步若 high < 0 立即返回 false。扫描结束返回 low == 0。

正确性说明

区间不变式：处理每个前缀后，low 与 high 分别覆盖可实现的非负余额最小值与最大值。三种字符的更新恰好对应所有合法选择；负余额不可能属于有效前缀，所以把下界截到 0 不会丢失合法解。

若中途 high < 0，所有解释都已产生多余右括号，必定无解。若扫描结束 low == 0，区间包含 0，存在一种解释完全配平；若 low > 0，即使尽量闭合仍有左括号剩余。故算法当且仅当字符串有效时返回 true。

边界处理

  • ")"：第一步 high 变为 -1，立即失败。
  • "*"：星号可为空，最终 low == 0。
  • 全是 (：最终下界大于 0，无法闭合。
  • 多个星号：每个独立解释，区间会整体扩张或收缩。
  • 下界每步截到 0，因为有效前缀的括号余额不能为负。

复杂度

时间O(n)

每个字符处理一次。

空间O(1)

只维护两个整数。

替代方案

  • 双栈：分别保存左括号与星号下标，先配右括号，再检查剩余左括号能否由更靠后的星号补齐。时间 O(n)、空间 O(n)。
  • 动态规划：记录各前缀可达到的余额，容易证明但空间更高。
  • 回溯：枚举星号三种身份，直观却可能达到 O(3k)，不适合作为最终方案。

面试追问

  • 为什么可达余额一定能用连续区间压缩，而不是若干离散点？
  • 能否构造一个例子说明只记录单一余额会误判？
  • 如果星号只能表示左括号或空串，更新规则如何变化？
  • 如果需要输出一组实际替换方案，O(1) 空间方法还够吗？

常见错误

  • 把所有星号统一当作同一种字符，忽略它们可以独立选择。
  • 只在末尾检查余额，漏掉中途出现“右括号过多”的非法前缀。
  • 更新右括号或星号后忘记将 low 截到 0。
  • 最终检查 high == 0；正确条件是可行区间包含 0，即 low == 0。
Complete implementations

四语言完整代码

Java 
class Solution {
    public boolean checkValidString(String s) {
        int low = 0;
        int high = 0;

        for (char c : s.toCharArray()) {
            if (c == '(') {
                low++;
                high++;
            } else if (c == ')') {
                low = Math.max(0, low - 1);
                high--;
            } else {
                low = Math.max(0, low - 1);
                high++;
            }

            if (high < 0) {
                return false;
            }
        }

        return low == 0;
    }
}

    bool checkValidString(string s) {

        int high = 0;

        for (char c : s) {
            if (c == '(') {
                ++low;
                ++high;
            } else if (c == ')') {
                low = max(0, low - 1);
                --high;
            } else {
                low = max(0, low - 1);
                ++high;

            if (high < 0) {
                return false;
            }
        }

        return low == 0;
    }
};
