破解闯关密码

重新排列一组非负整数，使它们拼接出的密码在所有排列中最小。

非负整数数组返回字符串保留前导 0

题意与示例

给定非负整数数组 password，把所有元素拼接成最小数字并返回字符串。最终答案可能很长，并且前导 0 不能删除。 

password = [15, 8, 7]
输出 = "1578"
password = [0, 3, 30, 34, 5, 9]
输出 = "03033459"

约束：0 < password.length <= 100。

准备好再看题解

先自行判断两个字符串该怎样排；完整证明与代码默认隐藏。

题解：比较 a+b 和 b+a

核心洞察

不能按整数大小排。例如 3 应排在 30 前，因为 "330" < "303" 为假，实际应让 30 在 3 前。对两个字符串 a、b，若 a+b < b+a，a 就应在 b 前；按此规则排序后直接连接。交换论证说明其正确性：若相邻两项不满足该顺序，交换它们会让整体拼接串更小；消除全部逆序后即得到全局最小串。

完整过程

  1. 将每个非负整数转换成字符串。
  2. 用比较器 (a+b).compareTo(b+a) 排序。
  3. 按排序结果连接，保留任何前导 0。

边界与复杂度

全 0 时应得到与元素数量相同的零串，例如 [0,0] → "00"。设每个字符串平均长度为 k，排序为 O(n log n · k)，结果空间 O(nk)。

替代方案、面试追问与常见错误

  • 替代方案：仅在 n 很小时枚举全部排列，复杂度 O(n! · nk)，可作为对拍基准，不适合正式提交。
  • 面试追问：若要得到最大密码，把比较方向反转即可；仍应返回字符串。
  • 常见错误：用数值升序、只比较首位字符，或把结果转回数值导致溢出和前导 0 丢失。

class Solution {
    public String crackPassword(int[] password) {
        String[] values = new String[password.length];
        for (int i = 0; i < password.length; i++) values[i] = String.valueOf(password[i]);
        Arrays.sort(values, (a, b) -> (a + b).compareTo(b + a));
        return String.join("", values);
    }
}
var crackPassword = function (password) {
  return password.map(String).sort((a, b) => (a + b < b + a ? -1 : a + b > b + a ? 1 : 0)).join("");
};
from functools import cmp_to_key

class Solution:
    def crackPassword(self, password: List[int]) -> str:
        values = list(map(str, password))
        values.sort(key=cmp_to_key(lambda a, b: (a + b > b + a) - (a + b < b + a)))
        return ''.join(values)
class Solution {
public:
    string crackPassword(vector<int>& password) {
        vector<string> values;
        for (int x : password) values.push_back(to_string(x));
        sort(values.begin(), values.end(), [](const string& a, const string& b) { return a + b < b + a; });
        string answer; for (const string& s : values) answer += s;
        return answer;
    }
