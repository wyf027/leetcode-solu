一最多的行

Row With Maximum Ones

给定一个 m × n 二进制矩阵，找出含 1 最多的行。若多行并列，选择下标最小者，并返回它的行下标与 1 的数量。

数组 矩阵 非付费题

目标输出

[rowIndex, ones]

下标从 0 开始；并列时保留更小的行下标。

Problem

题意与示例

输入参数为 mat: integer[][]，返回值为 integer[]。

Example 01

输入：mat = [[0,1],[1,0]]
输出：[0,1]

两行都含 1 个 1，选择下标更小的第 0 行。

Example 02

输入：mat = [[0,0,0],[0,1,1]]
输出：[1,2]

第 1 行含 2 个 1，是唯一最大值。

Example 03

输入：mat = [[0,0],[1,1],[0,0]]
输出：[1,2]

第 1 行含 2 个 1，因此返回 [1,2]。

约束

  • m == mat.length
  • n == mat[i].length
  • 1 ≤ m, n ≤ 100
  • mat[i][j] 只能是 0 或 1

Solution

准备好后，再揭晓题解

先独立思考如何处理并列情况，再展开完整过程、证明与四种语言实现。

Full Explanation

一次扫描，严格更新

核心洞察

逐行统计 1 的数量，用两个变量保存目前最优的行下标和数量。只有当前数量严格大于最佳数量时才更新；相等时不更新，自然保留更早、也就是下标更小的行。

完整过程

  1. 初始化 bestRow = 0、bestCount = 0。
  2. 从第 0 行到第 m - 1 行，累计该行所有元素。
  3. 若当前计数大于 bestCount，同步更新下标和计数。
  4. 扫描结束后返回 [bestRow, bestCount]。

正确性

循环不变量：处理完第 i 行后，bestCount 等于前 i + 1 行中的最大 1 数量，bestRow 是达到该数量的最小下标。

初始处理第 0 行时成立。处理新行时，若计数更大就替换；若更小或相等就保留原答案，因此最大值和最小下标性质都保持。扫描全部行后，该不变量覆盖整个矩阵，返回值即为题目所求。

边界情况

  • 只有一行或一列。
  • 所有元素均为 0，答案为 [0,0]。
  • 多行拥有相同最大计数，保留最小下标。
  • 所有元素均为 1，答案仍选择第 0 行。

复杂度

时间O(m × n)每个元素恰好访问一次
额外空间O(1)只维护常数个变量

四语言完整代码

Java 
class Solution {
    public int[] rowAndMaximumOnes(int[][] mat) {
        int bestRow = 0;
        int bestCount = 0;

        for (int i = 0; i < mat.length; i++) {
            int count = 0;
            for (int value : mat[i]) {
                count += value;
            }
            if (count > bestCount) {
                bestRow = i;
                bestCount = count;
            }
        }

        return new int[] {bestRow, bestCount};
    }
}

Python 
from typing import List


class Solution:
    def rowAndMaximumOnes(self, mat: List[List[int]]) -> List[int]:
        best_row = 0
        best_count = 0

        for i, row in enumerate(mat):
            count = sum(row)
            if count > best_count:
                best_row = i
                best_count = count

        return [best_row, best_count]

替代方案

也可以先求出每行计数，再排序或寻找最大值，但排序会引入不必要的 O(m log m) 时间与额外存储。若每一行已按 0、1 排序，可用二分查找首个 1；本题没有这个前提。

面试追问

  • 若矩阵按行流式到达，如何保持 O(n) 单行内存？
  • 若每行已排序，如何把每行计数降到 O(log n)？
  • 若要返回所有并列行，应如何调整状态？

常见错误

  • 使用 >= 更新，导致并列时错误选择最后一行。
  • 把返回顺序写成 [ones, rowIndex]。
  • 误用从 1 开始的行号。
  • 假设每行已排序，从而套用不适用的二分查找。

一句话记忆

逐行求和，只有“严格更大”才更新——这个严格号同时解决了最小下标的并列规则。
