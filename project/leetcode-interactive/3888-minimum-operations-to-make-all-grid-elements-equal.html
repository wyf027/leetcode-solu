3888. 使所有网格元素相等的最小操作次数

把二维网格摊平成一条数轴：每次只能让一个数增加或减少 x。能否相等先看余数；能相等时，选中位数作为汇合点。

一次操作
选择任意格子，使它加上或减去 x。
目标
让所有网格元素相同；不可达时返回 -1。

题意与示例

给定整数网格 grid 与正整数 x。每步只改变一个格子 ±x；求使全部元素相等的最少步数。每个值沿操作轨迹的 mod x 余数不变，因此余数不同的两个格子永远无法相遇。

示例 A
grid = [[2,4],[6,8]]，x = 2。排序为 [2,4,6,8]，取中位数 6，代价是 (4+2+0+2)/2 = 4。
示例 B
grid = [[1,5],[2,3]]，x = 2。1 mod 2 与 2 mod 2 不同，答案为 -1。

约束要点：网格元素总数可达较大规模；答案累计时需要使用足够宽的整数类型。

中位数汇合实验室

每行用分号分隔、行内用逗号分隔。例如 grid = [[2,4],[6,8]] 输入为 2,4;6,8。

等待分析：先检查所有元素对 x 的余数。

题解

默认折叠，先自行操作实验室再展开。

1. 同余是可达性的门

每次变动是 x 的倍数，所以任一数字的余数保持不变。任选首元素 base，若存在 (v - base) % x != 0，立刻返回 -1。

2. 中位数最小化绝对距离

余数一致后，将每个元素缩放到以 x 为单位的数轴。总代价等于 Σ |v - target| / x；绝对距离和在任意中位数处最小。

完整过程

  1. 摊平网格，并同时检查每个数是否与首元素同余。
  2. 将摊平数组排序，取下标 n / 2 的元素为中位数。
  3. 对每个值累加 abs(value - median) / x。

边界：仅一个元素时代价为 0；偶数个元素的两个中位数之间都最优，任选排序后的上中位数即可；差值要先转为宽整数再取绝对值。

阶段 复杂度
摊平与同余检查 O(mn)
排序 O(mn log(mn))
累计代价 O(mn)
额外空间 O(mn)

四语言可提交代码

import java.util.*;

class Solution {
    public int minOperations(int[][] grid, int x) {
        List<Integer> values = new ArrayList<>();
        int base = grid[0][0];
        for (int[] row : grid) for (int value : row) {
            if ((value - base) % x != 0) return -1;
            values.add(value);
        }
        Collections.sort(values);
        int median = values.get(values.size() / 2);
        long moves = 0;
        for (int value : values) moves += Math.abs((long) value - median) / x;
        return (int) moves;
    }
}
/** @param {number[][]} grid @param {number} x @return {number} */
var minOperations = function (grid, x) {
  const values = grid.flat();
  const base = values[0];
  if (values.some((value) => (value - base) % x !== 0)) return -1;
  values.sort((a, b) => a - b);
  const median = values[Math.floor(values.length / 2)];
  return values.reduce((moves, value) => moves + Math.abs(value - median) / x, 0);
};

替代方案

可用快速选择在线性期望时间找到中位数，节省排序的对数因子；但实现复杂度和常数更高。面试中排序更稳健、易验证。

常见错误与追问

  • 只检查相邻元素差，漏掉与基准值的同余比较。
  • 取均值而不是中位数，绝对距离和不一定最小。
  • 忘记除以 x，得到的是数值距离而非操作数。
  • 追问：若每次可选不同步长，什么不变量还保留？若只允许增加，目标应如何选择？
