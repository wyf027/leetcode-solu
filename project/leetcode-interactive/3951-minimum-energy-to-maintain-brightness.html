3951. 维持亮度的最小总能量

每盏开启的灯覆盖自己和相邻位置；把空间最少开灯数与时间并集长度相乘。

打开题目

题意与示例

有 n 个排成一行的灯泡。开启一盏可照亮自身及相邻位置。所有被 intervals 覆盖的整数时刻，照亮位置数至少为 brightness；求最小总能量。

输入 输出 解释
n=5, brightness=5, [[6,12]] 14 开 2 盏灯 × 7 个时刻
n=4, brightness=2, [[1,3],[2,4]] 4 1 盏灯 × 并集长度 4

约束：n 至 10⁶、区间端点至 10⁹、区间数至 10⁵。

交互：合并时间区间

题解与四语言实现

默认隐藏，展开后查看贪心公式。

空间：每灯最多覆盖 3 格

最少灯数为 ceil(brightness / 3)；端点不会破坏此上界，因 brightness ≤ n。

时间：只算并集

要求相同，重叠区间不应重复付能量。按起点排序后扫描合并。

相乘

空间布置可在每个活跃时刻复用，答案为灯数 × 时间并集长度。

完整过程：排序区间，累加合并后的闭区间长度；乘 (brightness + 2) / 3。使用 64 位整数。边界：相邻区间如 [1,3]、[4,4] 在整数时间轴连续；单个灯泡只能照亮一个位置。替代方案：端点排序可做扫描线，但只求并集长度时排序合并更直接。面试追问：若每灯覆盖半径改变，灯数变为 ceil(brightness/(2r+1))。 

class Solution { public long minimumEnergy(int n, int brightness, int[][] intervals) { Arrays.sort(intervals, (a,b) -> Integer.compare(a[0], b[0])); long length=0; int left=intervals[0][0], right=intervals[0][1]; for (int[] x:intervals) { if (x[0] > right+1) { length += (long)right-left+1; left=x[0]; right=x[1]; } else right=Math.max(right,x[1]); } length += (long)right-left+1; return length*((brightness+2L)/3); } }
function minimumEnergy(n, brightness, intervals) { intervals.sort((a,b)=>a[0]-b[0]); let [l,r]=intervals[0], len=0; for (const [a,b] of intervals) { if(a>r+1){len+=r-l+1;[l,r]=[a,b];} else r=Math.max(r,b); } return (len+r-l+1)*Math.ceil(brightness/3); }
class Solution:
    def minimumEnergy(self, n: int, brightness: int, intervals: list[list[int]]) -> int:
        intervals.sort(); left, right = intervals[0]; length = 0
        for start, end in intervals:
            if start > right + 1: length += right-left+1; left, right = start, end
            else: right = max(right, end)
        return (length + right-left+1) * ((brightness+2)//3)
