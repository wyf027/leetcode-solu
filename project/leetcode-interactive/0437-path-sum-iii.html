路径总和 III

一条路径只允许从父节点走向子节点，但它可以在树中的任意节点开始、任意节点结束。你需要数清所有和恰好等于目标值的路径。

树 深度优先搜索 二叉树

题目说明

给定二叉树根节点 root 和整数 targetSum，返回树中节点值之和等于目标值的向下路径数量。路径不必经过根节点，也不必在叶子节点结束。

示例 1

输入：root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
输出：3
解释：共有 3 条向下路径的节点和等于 8。

示例 2

输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：3

约束

  • 树中节点数为 [0, 1000]。
  • -109 ≤ Node.val ≤ 109。
  • -1000 ≤ targetSum ≤ 1000。
  • 路径必须连续，并且只能由父节点走向子节点。
函数形式：pathSum(root, targetSum) → integer

准备好看完整题解了吗？

下面包含核心算法、证明、复杂度与四种语言实现。

Core insight

前缀和 + 回溯计数

沿当前根到节点的分支维护前缀和。若当前前缀为 S，那么以当前节点结尾、和为 targetSum 的路径数量，等于此前出现过的前缀 S - targetSum 的次数。

完整过程

  1. 前缀计数表初始化为 {0: 1}，让从根开始的合法路径也能被统计。
  2. DFS 进入节点时，令 prefix += node.val。
  3. 把 count[prefix - targetSum] 加入答案。
  4. 将当前 prefix 的计数加一，再递归左右子树。
  5. 离开节点时将当前 prefix 的计数减一，避免其他分支误用它。

为什么需要回溯

计数表只能描述“当前祖先链”。左子树的前缀不能成为右子树节点的祖先前缀；因此离开节点时必须撤销本节点的记录。

只删除计数、不改变累计答案：已经发现的路径仍然合法。

正确性证明

  1. 不遗漏：对任意以当前节点结尾的合法向下路径，路径起点之前的祖先前缀必为 S - targetSum，计数表会在访问终点时统计它。
  2. 不重复：每条路径只在其唯一终点被统计一次；同一前缀的多次出现对应不同起点，应分别计数。
  3. 不串支：回溯保证表中只保留当前根到节点链上的前缀，所以不存在跨左右子树拼接出的非法路径。
  4. 结论：DFS 结束后，累计值恰好等于全部合法路径数量。

边界处理

  • 空树直接返回 0。
  • 节点可为负数，不能使用滑动窗口或“和过大就停止”的剪枝。
  • 大量零值会产生重叠路径，前缀计数必须保存出现次数，而不是布尔值。
  • 路径前缀绝对值可达约 1012；Java/C++ 应使用 64 位整数保存前缀和。
时间复杂度O(n)

每个节点进入、离开各一次；哈希表操作期望为 O(1)。

空间复杂度O(h)

递归栈和当前分支的前缀记录最多与树高 h 同阶；最坏为 O(n)。

四语言完整实现

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int pathSum(TreeNode root, int targetSum) {
        Map<Long, Integer> prefixCount = new HashMap<>();
        prefixCount.put(0L, 1);
        return dfs(root, 0L, targetSum, prefixCount);
    }

    private int dfs(TreeNode node, long prefix, int target,
                    Map<Long, Integer> prefixCount) {
        if (node == null) {
            return 0;
        }

        prefix += node.val;
        int answer = prefixCount.getOrDefault(prefix - target, 0);

        prefixCount.put(prefix, prefixCount.getOrDefault(prefix, 0) + 1);
        answer += dfs(node.left, prefix, target, prefixCount);
        answer += dfs(node.right, prefix, target, prefixCount);
        prefixCount.put(prefix, prefixCount.get(prefix) - 1);

        return answer;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @param {number} targetSum
 * @return {number}
 */
var pathSum = function(root, targetSum) {
    const prefixCount = new Map([[0, 1]]);

    function dfs(node, prefix) {
        if (node === null) {
            return 0;
        }

        prefix += node.val;
        let answer = prefixCount.get(prefix - targetSum) || 0;

        prefixCount.set(prefix, (prefixCount.get(prefix) || 0) + 1);
        answer += dfs(node.left, prefix);
        answer += dfs(node.right, prefix);

        const remaining = prefixCount.get(prefix) - 1;
        if (remaining === 0) {
            prefixCount.delete(prefix);
        } else {
            prefixCount.set(prefix, remaining);
        }
        return answer;
    }

    return dfs(root, 0);
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def pathSum(self, root: Optional[TreeNode], targetSum: int) -> int:
        prefix_count = {0: 1}

        def dfs(node: Optional[TreeNode], prefix: int) -> int:
            if node is None:
                return 0

            prefix += node.val
            answer = prefix_count.get(prefix - targetSum, 0)

            prefix_count[prefix] = prefix_count.get(prefix, 0) + 1
            answer += dfs(node.left, prefix)
            answer += dfs(node.right, prefix)

            prefix_count[prefix] -= 1
            if prefix_count[prefix] == 0:
                del prefix_count[prefix]
            return answer

        return dfs(root, 0)
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int pathSum(TreeNode* root, int targetSum) {
        unordered_map<long long, int> prefixCount;
        prefixCount[0] = 1;
        return dfs(root, 0LL, targetSum, prefixCount);
    }

private:
    int dfs(TreeNode* node, long long prefix, int target,
            unordered_map<long long, int>& prefixCount) {
        if (node == nullptr) {
            return 0;
        }

        prefix += node->val;
        int answer = prefixCount[prefix - target];

        ++prefixCount[prefix];
        answer += dfs(node->left, prefix, target, prefixCount);
        answer += dfs(node->right, prefix, target, prefixCount);
        --prefixCount[prefix];

        return answer;
    }
};

替代方案

枚举每个节点作为起点，再向下 DFS 统计路径，逻辑直观但最坏需要 O(n²) 时间。它适合先讲清定义，随后再优化到一次 DFS。

滑动窗口不适用，因为节点值可能为负，路径和不具有单调性。

常见错误

  • 忘记初始化 count[0] = 1，漏掉从根开始的路径。
  • 递归返回前不撤销前缀，错误统计跨分支路径。
  • 前缀只用集合，漏掉相同前缀对应的多个起点。
  • Java/C++ 用 32 位整数存前缀和，存在溢出风险。

面试追问

  • 为什么前缀计数表必须是“当前路径局部状态”？
  • 如果只要求判断是否存在一条路径，可以如何提前返回？
  • 如果路径允许向上再向下，当前方法为什么失效？可以怎样重新建模？
  • 递归深度可能达到 1000，如何改写成显式栈？

一句话记忆

来到节点先查差值，深入子树前登记，离开节点必撤销。

“查差值”负责计数，“登记 / 撤销”负责限定在同一条祖先链。
