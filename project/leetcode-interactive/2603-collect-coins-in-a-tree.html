收集树中金币

Collect Coins in a Tree

在无根树上任选起点；你可以收集当前位置两步以内的金币，也可以沿边移动。收集全部金币并回到起点，求最少经过的边数。

困难树图拓扑排序数组

Problem

题目描述

任务

给定 coins 与 edges。节点编号为 0...n-1，coins[i] = 1 表示节点 i 有金币，edges[i] = [aᵢ,bᵢ] 表示一条无向边。

  • 1收集与当前节点距离不超过 2 的全部金币。
  • 2沿一条边移动到相邻节点。

起点可任选，但结束时必须回到同一节点。同一条边经过多次，需要分别计数。

约束

  • n == coins.length
  • 1 ≤ n ≤ 3 × 10⁴
  • coins[i] ∈ {0, 1}
  • edges.length == n - 1
  • edges[i].length == 2
  • 0 ≤ aᵢ, bᵢ < n 且 aᵢ ≠ bᵢ
  • edges 构成一棵合法的树
EXAMPLE 01

链形树

输入：coins = [1,0,0,0,0,1]
edges = [[0,1],[1,2],[2,3],[3,4],[4,5]]
输出：2

从节点 2 出发即可收集节点 0 的金币；移动到节点 3 收集节点 5 的金币，再返回节点 2。

EXAMPLE 02

分叉树

输入：coins = [0,0,0,1,1,0,0,1]
edges = [[0,1],[0,2],[1,3],[1,4],[2,5],[5,6],[5,7]]
输出：2

从节点 0 收集节点 3、4 的金币；往返节点 2 时可收集节点 7 的金币。

Solution

拓扑剪枝：只为真正要走的边买单

💡
核心洞察

先递归删除没有金币的叶子，再同步删除两层叶子。剩下的每条边都必须往返一次，答案就是剩余边数乘 2。

完整过程

  1. 建邻接表并统计每个节点的度，令剩余边数为 n - 1。
  2. 把所有“度为 1 且没有金币”的节点入队，持续删除；新出现的空叶子也继续入队。
  3. 将此时所有叶子入队，按层同步删除两轮。只能删除两轮，第二轮中新产生的叶子不能在同一轮继续处理。
  4. 返回 max(0, remainingEdges × 2)。

为什么恰好两层？

站在某个节点就能收集距离至多 2 的金币。因此，金币最小连通子树最外侧的两层只需被“覆盖”，无需真的走到。再往内的边承担连接不同覆盖区域的任务，无法省略。

正确性证明

  1. 空叶剪枝安全。 空叶子所在的末端分支没有金币；进入该分支不会收集新金币，只会增加往返路程。递归删除所有空叶不会改变最优答案。
  2. 两层边界无需经过。 第一步后，每个叶子都有金币。对于叶子及其向内一层，旅行者只要到达再向内一层的节点，就能在距离 2 内收集边界金币，所以这些边不必经过。
  3. 核心边不能省。 删除两层后留下的任一边都连接着必须共同覆盖的两侧区域；树上没有替代路径，任何覆盖全部金币的连通行走区域都必须包含它。
  4. 计数最优。 要回到起点，树中被使用的每条边至少经过两次；深度优先式往返可以恰好经过两次。因此最少次数等于核心边数的两倍。

边界情况

  • 没有金币：整棵树被第一阶段删空，答案为 0。
  • 只剩一个节点或核心为空：没有需要经过的边，答案为 0。
  • 短链或小直径树：一个位置可能覆盖全部金币，答案仍为 0。
  • 两节点同时为叶子时，每条边只会在一端处理时扣除一次。

复杂度

每个节点至多入队常数次，每条边至多从两端访问一次。

时间 O(n)空间 O(n)

替代方案

可以把树定根，做树形 DP，记录子树最近金币距离以及必须进入的分支，再合并答案。它能推广到更复杂的距离或代价模型，但本题状态更繁琐；拓扑剪枝更直接。

常见错误

  • 第二阶段一直删到队列为空，而不是严格删两层。
  • 一轮内把新叶子立刻继续删除，破坏“同步分层”。
  • 使用剩余节点数乘 2；应使用剩余边数。
  • 只删初始空叶，没有递归处理新出现的空叶。

import java.util.*;

class Solution {
    public int collectTheCoins(int[] coins, int[][] edges) {
        int n = coins.length, remainingEdges = n - 1;
        List<Integer>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        int[] degree = new int[n];
        for (int[] edge : edges) {
            int a = edge[0], b = edge[1];
            graph[a].add(b);
            graph[b].add(a);
            degree[a]++;
            degree[b]++;
        }

        Deque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (degree[i] == 1 && coins[i] == 0) queue.offer(i);
        }
        while (!queue.isEmpty()) {
            int node = queue.poll();
            degree[node] = 0;
            for (int next : graph[node]) {
                if (degree[next] == 0) continue;
                degree[next]--;
                remainingEdges--;
                if (degree[next] == 1 && coins[next] == 0) queue.offer(next);
            }
        }

        for (int i = 0; i < n; i++) {
            if (degree[i] == 1) queue.offer(i);
        }
        for (int round = 0; round < 2; round++) {
            for (int size = queue.size(); size > 0; size--) {
                int node = queue.poll();
                degree[node] = 0;
                for (int next : graph[node]) {
                    if (degree[next] == 0) continue;
                    degree[next]--;
                    remainingEdges--;
                    if (degree[next] == 1) queue.offer(next);
                }
            }
        }
        return Math.max(0, remainingEdges * 2);
    }
}

var collectTheCoins = function(coins, edges) {
    const n = coins.length;
    const graph = Array.from({ length: n }, () => []);
    const degree = Array(n).fill(0);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
        degree[a]++;
        degree[b]++;
    }

    let remainingEdges = n - 1;
    const queue = [];
    let head = 0;
    for (let i = 0; i < n; i++) {
        if (degree[i] === 1 && coins[i] === 0) queue.push(i);
    }
    while (head < queue.length) {
        const node = queue[head++];
        degree[node] = 0;
        for (const next of graph[node]) {
            if (degree[next] === 0) continue;
            degree[next]--;
            remainingEdges--;
            if (degree[next] === 1 && coins[next] === 0) queue.push(next);
        }
    }

    queue.length = 0;
    head = 0;
    for (let i = 0; i < n; i++) {
        if (degree[i] === 1) queue.push(i);
    }
    for (let round = 0; round < 2; round++) {
        const end = queue.length;
        while (head < end) {
            const node = queue[head++];
            degree[node] = 0;
            for (const next of graph[node]) {
                if (degree[next] === 0) continue;
                degree[next]--;
                remainingEdges--;
                if (degree[next] === 1) queue.push(next);
            }
        }
    }
    return Math.max(0, remainingEdges * 2);
};
from collections import deque
from typing import List


class Solution:
    def collectTheCoins(self, coins: List[int], edges: List[List[int]]) -> int:
        n = len(coins)
        graph = [[] for _ in range(n)]
        degree = [0] * n
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)
            degree[a] += 1
            degree[b] += 1

        remaining_edges = n - 1
        queue = deque(i for i in range(n) if degree[i] == 1 and coins[i] == 0)
        while queue:
            node = queue.popleft()
            degree[node] = 0
            for nxt in graph[node]:
                if degree[nxt] == 0:
                    continue
                degree[nxt] -= 1
                remaining_edges -= 1
                if degree[nxt] == 1 and coins[nxt] == 0:
                    queue.append(nxt)

        queue = deque(i for i in range(n) if degree[i] == 1)
        for _ in range(2):
            for _ in range(len(queue)):
                node = queue.popleft()
                degree[node] = 0
                for nxt in graph[node]:
                    if degree[nxt] == 0:
                        continue
                    degree[nxt] -= 1
                    remaining_edges -= 1
                    if degree[nxt] == 1:
                        queue.append(nxt)

        return max(0, remaining_edges * 2)

public:
    int collectTheCoins(vector<int>& coins, vector<vector<int>>& edges) {

        vector<vector<int>> graph(n);
        vector<int> degree(n);
        for (const auto& edge : edges) {
            int a = edge[0], b = edge[1];
            graph[a].push_back(b);
            graph[b].push_back(a);
            degree[a]++;
            degree[b]++;
        }

        queue<int> q;
        for (int i = 0; i < n; i++) {
            if (degree[i] == 1 && coins[i] == 0) q.push(i);
        }
        while (!q.empty()) {
            int node = q.front();
            q.pop();
            degree[node] = 0;
            for (int next : graph[node]) {
                if (degree[next] == 0) continue;
                degree[next]--;
                remainingEdges--;
                if (degree[next] == 1 && coins[next] == 0) q.push(next);
            }
        }

        for (int i = 0; i < n; i++) {
            if (degree[i] == 1) q.push(i);
        }
        for (int round = 0; round < 2; round++) {
            int size = q.size();
            while (size--) {
                int node = q.front();
                q.pop();
                degree[node] = 0;
                for (int next : graph[node]) {
                    if (degree[next] == 0) continue;
                    degree[next]--;
                    remainingEdges--;
                    if (degree[next] == 1) q.push(next);

面试追问

收集半径改为 k？

完成空叶剪枝后，把同步删除两层改为同步删除 k 层。

为什么不能普通 DFS 贪心？

局部最近金币不代表全局最短；回到起点迫使选中的树边成对经过。

如果不要求回到起点？

在同一核心树上可省掉一条最长路径的重复路程，通常继续转化为树的直径问题。

怎样避免同一轮删多层？

进入每轮前固定当前队列长度，只处理这批节点，新叶留到下一轮。
