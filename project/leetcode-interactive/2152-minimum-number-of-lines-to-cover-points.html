Minimum Number of Lines to Cover Points

在平面上放置无限延伸的直线，让每个给定点都被穿过。
先观察位置关系，再决定何时展开解法。

01 / THE CHALLENGE

题意与输入约定

输入二维整数数组 points，每个 points[i] = [xᵢ, yᵢ] 代表平面上的一个点。选择任意方向的直线，使每个点至少在一条直线上。返回所需直线条数的最小值，不需要返回具体直线。

直线向两端无限延伸；同一点允许被多条线穿过；输入顺序不限制连线，也不要求线段首尾相连。

官方示例 1

输入：points = [[0,1],[2,3],[4,5],[4,3]]
输出：2

y = x + 1 经过前三个点，再用 y = 3 经过第四个点。四点不共线，一条线不够。

官方示例 2

输入：points = [[0,2],[-2,-2],[1,4]]
输出：1

三个点都在 y = 2x + 2 上，一条线即可覆盖。

完整约束

  • 1 ≤ points.length ≤ 10
  • points[i].length == 2
  • −100 ≤ xᵢ, yᵢ ≤ 100
  • 所有点互不相同。

官方接口：minimumLines(points: integer[][]) → integer。官方元数据的题面和代码片段为空；示例输入及接口来自元数据，示例输出和约束据公开题目资料补足，题意为原创转述。

04 / SOLUTION

固定一个点，枚举经过它的直线

核心洞察

最多 10 个点，可以用整数的二进制位表示剩余点集合。如果一条线覆盖至少两个剩余点，它就由其中两个点确定；只覆盖一个剩余点的情形，单独列为候选即可。

固定剩余集合里编号最小的点 i。最终必有一条线覆盖它，因此只需枚举它与其他剩余点 j 确定的直线，加上单点候选。直线的放置顺序不影响结果，不必把所有与 i 无关的线也作为第一步枚举。

整数判共线

(xⱼ − xᵢ) × (yₖ − yᵢ) = (yⱼ − yᵢ) × (xₖ − xᵢ)

叉积为零表示三点共线。没有浮点误差，也不需要对竖直线额外分类。预计算 lines[i][j]，将直线 ij 上所有点的位设为 1，包括 i 和 j。

完整过程

  1. 枚举 i < j，扫描每个 k，预处理直线覆盖掩码，耗时 O(n³)。
  2. 定义 f(mask) 为覆盖 mask 中剩余点的最少新增直线数，边界 f(0) = 0。
  3. 找到 mask 的最低置位 i。先尝试只覆盖 i，得到 1 + f(mask & ~(1 << i))。
  4. 枚举仍在 mask 内的 j > i，尝试 1 + f(mask & ~lines[i][j])，保留最小值。
  5. 缓存每个 mask 的答案，最终返回 f((1 << n) - 1)。
f(mask) = 1 + min(f(mask \ {i}), minⱼ f(mask \ lines[i][j]))

单点候选总能用实际直线实现：经过 i 的方向无限多，只需避开通往其他有限个点的方向。取反后必须与 mask 相与，防止高位混入状态。

示例 1 的转移

剩余集合 {P0,P1,P2,P3} 中固定 P0。直线 P0–P1 同时穿过 P2，一次去掉三个点，余下 P3 再用一条线。总代价 1 + 1 = 2。按通常高位在左的掩码写法是 1111 → 1000 → 0000。也存在其他同样使用两条线的最优方案。

正确性证明

  1. 候选完备：任意最优覆盖必有一条线 L 经过固定点 i。若 L 包含另一个剩余点 j，则 L 就是枚举的 ij；否则它就是单点候选。可将 L 调整为先放置而不改变结果。
  2. 子问题保持：选线后移除它覆盖的全部剩余点，剩下的仍是同一种覆盖问题。一次多覆盖点不会增加后续难度。
  3. 归纳最优：空集答案为 0。每步至少移除 i，所以递归严格缩小。假设更小集合答案正确，枚举中包含最优方案的第一条线，接上最优子解并取最小值，便得到当前集合的最优答案。

边界与复杂度

  • 一个点需要一条线；两个点或全部共线时也只需要一条。
  • 横线、竖线和负坐标由同一叉积公式处理；题目保证没有重复点。
  • 答案范围为 1 至 ⌈n/2⌉：两两配对即可，奇数时补一条。
  • 时间为 O(n³ + n·2ⁿ)：预处理 O(n³)，每个状态固定 i 后最多枚举 n−1 个 j。
  • 空间为 O(n² + 2ⁿ)：直线掩码与记忆化数组。递归栈 O(n)，包含在上述上界内。
  • 坐标差绝对值不超过 200，单个乘积不超过 40000。Java/C++ 仍用宽整数乘法；若坐标范围扩大，JavaScript 也可能需要 BigInt。

替代方案

将所有两点直线掩码加上单点掩码作为集合覆盖候选，可以做自底向上的 DP，朴素转移为 O(n²·2ⁿ)。无记忆化回溯则会重复求解相同剩余集合。固定最低位并缓存结果更简洁。每次贪心选覆盖点最多的直线，无法保证后续组合最优。

常见错误

  • 使用浮点斜率判等，或遗漏竖直线除零情况。
  • 只删除选中的两个点，没有删除该直线上其余共线点。
  • 遗漏单点候选，最后一个点无法处理。
  • 混淆“已覆盖”与“未覆盖”的位含义，本实现 1 始终表示剩余点。
  • 误把本题当作按横坐标排序后的折线段计数题。

面试追问

如何返回具体直线？为每个 mask 记录达到最小值的候选，再从全 1 状态回放。单点候选可以输出该点与一个避开其他点的方向。本页交互使用这一方式展示决策路径。

为什么固定最低位不会漏解？覆盖 i 的线总会出现，把它放在第一步不影响后续覆盖；无关直线无需重复作为第一步枚举。

n 大幅增加怎么办？2ⁿ 状态空间将成为瓶颈，需要利用输入结构、分支限界或近似方法；仅更换位掩码类型无法解决复杂度问题。

JavaScript

/**
 * @param {number[][]} points
 * @return {number}
 */
var minimumLines = function(points) {
    const n = points.length;
    const lines = Array.from({length: n}, () => Array(n).fill(0));
    for (let i = 0; i < n; i++) {
        const [x, y] = points[i];
        for (let j = i + 1; j < n; j++) {
            const dx = points[j][0] - x, dy = points[j][1] - y;
            for (let k = 0; k < n; k++) {
                if (dx * (points[k][1] - y) === dy * (points[k][0] - x))
                    lines[i][j] |= 1 << k;
            }
        }
    }
    const memo = Array(1 << n).fill(-1);
    memo[0] = 0;
    function solve(mask) {
        if (memo[mask] !== -1) return memo[mask];
        let i = 0;
        while (!(mask & (1 << i))) i++;
        let best = 1 + solve(mask & ~(1 << i));
        for (let j = i + 1; j < n; j++) {
            if (mask & (1 << j))
                best = Math.min(best, 1 + solve(mask & ~lines[i][j]));
        }
        return memo[mask] = best;
    }
    return solve((1 << n) - 1);
};

Python

from functools import lru_cache
from typing import List

class Solution:
    def minimumLines(self, points: List[List[int]]) -> int:
        n = len(points)
        lines = [[0] * n for _ in range(n)]
        for i, (x, y) in enumerate(points):
            for j in range(i + 1, n):
                dx, dy = points[j][0] - x, points[j][1] - y
                for k, (px, py) in enumerate(points):
                    if dx * (py - y) == dy * (px - x):
                        lines[i][j] |= 1 << k

        @lru_cache(None)
        def solve(mask: int) -> int:
            if mask == 0:
                return 0
            i = (mask & -mask).bit_length() - 1
            best = 1 + solve(mask & ~(1 << i))
            for j in range(i + 1, n):
                if mask & (1 << j):
                    best = min(best, 1 + solve(mask & ~lines[i][j]))
            return best

        return solve((1 << n) - 1)

Java

import java.util.Arrays;

class Solution {
    private int n;
    private int[][] lines;
    private int[] memo;

    public int minimumLines(int[][] points) {
        n = points.length;
        lines = new int[n][n];
        for (int i = 0; i < n; i++) {
            int x = points[i][0], y = points[i][1];
            for (int j = i + 1; j < n; j++) {
                long dx = points[j][0] - x, dy = points[j][1] - y;
                for (int k = 0; k < n; k++) {
                    if (dx * (points[k][1] - y) == dy * (points[k][0] - x))
                        lines[i][j] |= 1 << k;
                }
            }
        }
        memo = new int[1 << n];
        Arrays.fill(memo, -1);
        memo[0] = 0;
        return solve((1 << n) - 1);
    }

    private int solve(int mask) {
        if (memo[mask] != -1) return memo[mask];
        int i = Integer.numberOfTrailingZeros(mask);
        int best = 1 + solve(mask & ~(1 << i));
        for (int j = i + 1; j < n; j++) {
            if ((mask & (1 << j)) != 0)
                best = Math.min(best, 1 + solve(mask & ~lines[i][j]));
        }
        return memo[mask] = best;
    }
}

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
    int n;
    vector<vector<int>> lines;
    vector<int> memo;

    int solve(int mask) {
        if (memo[mask] != -1) return memo[mask];
        int i = 0;
        while ((mask & (1 << i)) == 0) ++i;
        int best = 1 + solve(mask & ~(1 << i));
        for (int j = i + 1; j < n; ++j) {
            if (mask & (1 << j))
                best = min(best, 1 + solve(mask & ~lines[i][j]));
        }
        return memo[mask] = best;
    }

public:
    int minimumLines(vector<vector<int>>& points) {
        n = points.size();
        lines.assign(n, vector<int>(n, 0));
        for (int i = 0; i < n; ++i) {
            int x = points[i][0], y = points[i][1];
            for (int j = i + 1; j < n; ++j) {
                long long dx = points[j][0] - x, dy = points[j][1] - y;
                for (int k = 0; k < n; ++k) {
                    if (dx * (points[k][1] - y) == dy * (points[k][0] - x))
                        lines[i][j] |= 1 << k;
                }
            }
        }
        memo.assign(1 << n, -1);
        memo[0] = 0;
