最大层内元素和 Maximum Level Sum of a Binary Tree

一棵树，每一层都有自己的“总分”。你的任务是找出总分最高的层；若最高分并列，选择层号更小的那一层。

Problem

题目说明

根节点所在层为第 1 层，根的孩子所在层为第 2 层，以此类推。

任务

给定二叉树的根节点 root，计算每一层全部节点值之和。返回层内元素和最大的层号 x；如果多层并列最大，返回其中最小的层号。

函数签名：maxLevelSum(root: TreeNode) -> int

约束

  • 树中节点数在 [1, 104] 范围内。
  • -105 <= Node.val <= 105。
  • 输入保证至少有一个节点。

Solution

准备好核对思路了吗？

题解默认收起，展开后可查看完整推导、正确性证明、四语言代码与面试追问。

Breadth-first Search

层序遍历，一层结算一次

队列天然把同一层节点聚在一起。先记下本层队列长度，只处理这些节点并累加；处理完再和历史最佳比较。

核心洞察只在 currentSum > bestSum 时更新答案。严格大于让首次出现的最大层和被保留，因此自动满足“并列取较小层号”。

完整过程

  1. 将根节点放入队列，层号从 1 开始；最佳层和初始化为负无穷。
  2. 读取队列当前长度 size，它恰好是当前层的节点数。
  3. 连续弹出 size 个节点，累加节点值，并把非空孩子加入队尾。
  4. 若本层和严格大于最佳层和，更新最佳层和与答案层号。
  5. 层号加一，队列非空时继续；最后返回答案层号。

正确性

分层不变式每轮开始时，队列中恰好包含当前层的所有节点，且不含其他层节点。处理固定的 size 个节点后，队列恰好变为下一层节点。
层和正确本轮把当前层每个节点值恰好累加一次，因此得到该层准确总和。
答案最优按层号递增检查所有层，仅遇到严格更大的层和才更新。结束时保存的是全局最大层和对应的最早层号，也就是要求的最小最优层号。

复杂度

时间O(n)每个节点入队、出队一次。
空间O(w)w 为二叉树最大宽度。

边界与细节

  • 节点值可能全为负数，不能把最佳层和初始化为 0。
  • 输入非空，但代码仍可保持类型签名与平台定义一致。
  • 理论层和范围约为 [-10^9, 10^9]；Java/C++ 示例用更宽整数累计更稳妥。
  • 并列时不要更新答案；比较必须是 >，不是 >=。

替代方案：DFS 累加数组

深度优先遍历时把节点值累加到 sums[depth]，遍历结束后从浅到深寻找最大值。它同样是 O(n) 时间，额外空间为层数数组加递归栈，最坏可达 O(n)。本题按层汇总，BFS 的数据流更直接；若现有框架已经使用 DFS，数组方案也完全可行。

面试追问

  • 若要返回所有并列层？遇到更大值清空列表，遇到相等值追加当前层。
  • 若树以流式形式到达？只要输入仍按层提供，可维护当前层和与最佳记录，无需保存整棵树。
  • DFS 如何保证取最小层号？汇总后从索引 0 向后扫描，并仅在严格更大时更新。

常见错误

  • 在遍历本层时使用不断变化的 queue.length 作为循环上限，把下一层混入当前层。
  • 用 >= 更新答案，错误地返回并列最大值中的更深层。
  • 把最佳和设为 0，导致全负数树从未更新答案。
  • 返回最大层和本身，而不是题目要求的层号。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int maxLevelSum(TreeNode root) {
        java.util.Queue<TreeNode> queue = new java.util.ArrayDeque<>();
        queue.offer(root);

        int level = 1;
        int bestLevel = 1;
        long bestSum = Long.MIN_VALUE;

        while (!queue.isEmpty()) {
            int size = queue.size();
            long currentSum = 0;

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                currentSum += node.val;
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }

            if (currentSum > bestSum) {
                bestSum = currentSum;
                bestLevel = level;
            }
            level++;
        }

        return bestLevel;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var maxLevelSum = function(root) {
    const queue = [root];
    let head = 0;
    let level = 1;
    let bestLevel = 1;
    let bestSum = -Infinity;

    while (head < queue.length) {
        const size = queue.length - head;
        let currentSum = 0;

        for (let i = 0; i < size; i++) {
            const node = queue[head++];
            currentSum += node.val;
            if (node.left !== null) queue.push(node.left);
            if (node.right !== null) queue.push(node.right);
        }

        if (currentSum > bestSum) {
            bestSum = currentSum;
            bestLevel = level;
        }
        level++;
    }

    return bestLevel;
};

#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque
from typing import Optional


class Solution:
    def maxLevelSum(self, root: Optional[TreeNode]) -> int:
        queue = deque([root])
        level = 1
        best_level = 1
        best_sum = float("-inf")

        while queue:
            current_sum = 0

            for _ in range(len(queue)):
                node = queue.popleft()
                current_sum += node.val
                if node.left is not None:
                    queue.append(node.left)
                if node.right is not None:
                    queue.append(node.right)

            if current_sum > best_sum:
                best_sum = current_sum
                best_level = level
            level += 1

        return best_level

 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}

public:
