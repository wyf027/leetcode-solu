LCR 003 · EASY · 动态规划 / 位运算

比特位计数

给定整数 n，返回从 0 到 n 每个数的二进制中 1 的个数。关键在于：不要为每个数从头数位，而是复用更小数的答案。

状态转移

bits[i] = bits[i >> 1]
+ (i & 1)

题意与直觉

返回长度为 n + 1 的数组，其中第 i 项是 i 的二进制表示中 1 的数量。示例：n = 5，输出 [0,1,1,2,1,2]。

右移一位相当于除以 2 并丢掉最低位；丢掉的这一位若为 1，就在较小问题的答案上加 1。

从 5 看转移

5 = 101₂
5 >> 1 = 2 = 10₂
bits[5] = bits[2] + 1 = 2

当前计算

每次只读取已经算好的 bits[i >> 1]。这就是从小到大填表的原因。

01 / 定义

bits[i]

表示整数 i 的二进制中 1 的个数，bits[0] = 0。

02 / 拆解

右移去最低位

i >> 1 一定比 i 小，最低位由 i & 1 告诉我们。

03 / 填表

线性遍历

从 1 到 n 依次写入状态，避免对每一个数重复逐位扫描。

复杂度

时间：O(n)

每个 i 只做常数次位运算与一次数组读取。

空间：O(n)

返回数组也就是 DP 表；题目本身要求它。

四语言提交版

最低有效位 DP，线性完成。

  1. 创建 n+1 长度的答案数组，0 默认就是 0。
  2. 对每个 i，右移得到已求解的子问题。
  3. 将最低位 i & 1 加入子问题答案。

验证区域

  • ✓ n = 0
  • ✓ 2 的幂：只有一个 1
  • ✓ 奇偶连续转移
  • ✓ 较大 n 的线性性能
