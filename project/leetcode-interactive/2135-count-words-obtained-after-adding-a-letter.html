统计追加字母
可以获得的单词数

Count Words Obtained After Adding a Letter

一次追加，一次重排。哪些目标单词能由起始词得到？

题目

给定两个下标从 0 开始的字符串数组 startWords 与 targetWords。每个单词只含小写英文字母，且同一单词内没有重复字母。

对每一个目标词，可以任选一个起始词，先在末尾恰好追加一个原词中没有的字母，再任意重排所有字母（也允许保持顺序）。如果能得到该目标词，就将它计入答案。

返回能够得到的目标词数量。起始词不会被消耗或修改，可以反复使用；统计的是目标数组中的元素数量，而不是转换方式数量。

参数与返回值

wordCount(startWords: string[], targetWords: string[]) → integer

约束

  • 1 ≤ startWords.length, targetWords.length ≤ 5 × 10⁴
  • 1 ≤ startWords[i].length, targetWords[j].length ≤ 26
  • 两个数组中的所有单词都仅包含 a 到 z。
  • 任意一个单词内，每个字母至多出现一次；不同数组元素可以拥有相同字母集合。

官方示例

示例 1

startWords = ["ant","act","tack"]
targetWords = ["tack","act","acti"]
输出：2

act 追加 k 并重排得到 tack；追加 i 得到 acti。目标 act 无法获得：即使它存在于起始数组中，也不能省略追加操作。

示例 2

startWords = ["ab","a"]
targetWords = ["abc","abcd"]
输出：1

ab 追加 c 得到 abc；没有起始词能只追加一个字母就得到 abcd。

题解 · 从目标中拿掉一个字母

核心洞察

任意重排意味着顺序不重要；无重复字母意味着一个单词完全可以用一个 26 位的集合掩码 表示。字母 a 对应第 0 位，z 对应第 25 位。

正向枚举“起始词 + 新字母”可行，但逆向更直接：对每个目标词，依次移除它已有的一个字母，检查剩余字母集合是否属于某个起始词。

mask(word) = 对每个字符 c，执行 m |= 1 << (c - 'a')
删除目标中已有的字符 c：candidate = targetMask ^ (1 << (c - 'a'))
只要 candidate 在起始掩码集合中：答案 +1，处理下一个目标

完整过程

  1. 计算所有起始词掩码，并放入哈希集合，自动合并相同字母集合。
  2. 按数组顺序读取每个目标词，计算其掩码。
  3. 仅枚举目标词内实际出现的字符，将对应的 1 位翻转为 0。
  4. 查询这个候选掩码；首次命中后答案加一并停止当前目标的枚举。
  5. 没有候选命中则不计数，最终返回答案。

准备开始累计 0

起始词集合（相同掩码只存一份）

为什么正确？

必要性：如果起始词追加字母 c 后能重排为目标词，那么删去目标词中的 c，剩余字母集合必然与该起始词相同。算法枚举所有目标内的字母，一定会枚举到 c 并命中。

充分性：如果删去目标词中的 c 后，候选掩码属于起始集合，那么该起始词恰好包含目标中除 c 外的全部字母。由于各词字母不重复，c 必不在起始词中，追加 c 合法，重排后可以得到目标词。

计数：每个目标独立处理，首次命中就停止，所以每个可达目标恰好计一次，不可达目标计零次；重复的目标数组元素会分别处理。

边界与复杂度

  • 单字母目标删除后为空集合，起始词长度至少为 1，因此不会命中。
  • 目标与起始词完全相同也必须追加一个字母，不能直接将“存在于起始集合”判为可达。
  • 26 个字母只使用第 0–25 位，最大掩码为 2²⁶−1，JavaScript 的 32 位按位运算以及 Java / C++ 的整数均可容纳。
  • 令 S、T 分别为起始数组、目标数组的总字符数，n 为起始词数量。哈希查询平均 O(1)，总期望时间 O(S + T)，亦可写为 O((n + m)L)，其中 L ≤ 26；额外空间 O(n)。哈希表复杂度为平均意义，不保证最坏常数查询。

替代方案

用排序后的字符串作为哈希键，目标排序后删除一个字符并查询。实现直观，但排序与反复构造字符串增加开销，直接实现每个目标可达 O(L log L + L²)。也可正向枚举每个起始词缺失的字母，将所有可生成掩码存入集合，再扫描目标；代价是额外存储最多 26n 个候选。

常见错误

  • 省略“必须追加一个”或错误地允许追加已有字母。
  • 枚举所有 26 位并直接 XOR：对不存在的位会变成添加，而不是删除。这里必须只枚举目标词已有字符。
  • 找到多个起始词时重复累计同一目标；命中后应立即 break。
  • 将目标数组也去重，导致重复目标漏计。
  • 用字母和当作集合键，可能碰撞；或者把掩码当成能保存重复次数的结构。

面试追问

允许重复字母怎么办？存在性掩码不再足够，应改用 26 维计数作为规范键，逆向删除后还要检查被追加字母在起始词中不存在。

要返回具体方案呢？将 Set 改成“掩码 → 一个起始词下标”的 Map，命中时同时记录下标和删除的字母。

改成追加 k 个互不相同的新字母呢？可枚举目标中 k 个字母的删除组合，但组合数 C(L,k) 会增长，需按 k 和输入规模重新选择方案。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    private int mask(String word) {
        int value = 0;
        for (int i = 0; i < word.length(); i++) {
            value |= 1 << (word.charAt(i) - 'a');
        }
        return value;
    }

    public int wordCount(String[] startWords, String[] targetWords) {
        Set<Integer> starts = new HashSet<>();
        for (String word : startWords) starts.add(mask(word));
        int answer = 0;
        for (String word : targetWords) {
            int value = mask(word);
            for (int i = 0; i < word.length(); i++) {
                int candidate = value ^ (1 << (word.charAt(i) - 'a'));
                if (starts.contains(candidate)) {
                    answer++;
                    break;
                }
            }
        }
        return answer;
    }
}

var wordCount = function(startWords, targetWords) {
    const mask = word => {
        let value = 0;
        for (const c of word) value |= 1 << (c.charCodeAt(0) - 97);
        return value;
    };
    const starts = new Set(startWords.map(mask));
    let answer = 0;
    for (const word of targetWords) {
        const value = mask(word);
        for (const c of word) {
            if (starts.has(value ^ (1 << (c.charCodeAt(0) - 97)))) {
                answer++;
                break;
            }
        }
    }
    return answer;
};

from typing import List

class Solution:
    def wordCount(self, startWords: List[str], targetWords: List[str]) -> int:
        def mask(word: str) -> int:
            value = 0
            for c in word:
                value |= 1 << (ord(c) - ord('a'))
            return value

        starts = {mask(word) for word in startWords}
        answer = 0
        for word in targetWords:
            value = mask(word)
            for c in word:
                candidate = value ^ (1 << (ord(c) - ord('a')))
                if candidate in starts:
                    answer += 1
                    break
        return answer

C++

#include <string>
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
    int mask(const string& word) {
        int value = 0;
        for (char c : word) value |= 1 << (c - 'a');
        return value;
    }
public:
    int wordCount(vector<string>& startWords, vector<string>& targetWords) {
        unordered_set<int> starts;
        for (const string& word : startWords) starts.insert(mask(word));
        int answer = 0;
        for (const string& word : targetWords) {
            int value = mask(word);
            for (char c : word) {
                if (starts.count(value ^ (1 << (c - 'a')))) {
                    ++answer;
                    break;
                }
            }
        }
        return answer;
    }
};
