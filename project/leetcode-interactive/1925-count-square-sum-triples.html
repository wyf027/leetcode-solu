统计平方和三元组的数目

Count Square Sum Triples 简单

题目任务

给定整数 n，统计整数三元组 (a, b, c) 的数量，要求三个数均在 1 … n 内，且 a² + b² = c²。

位置有意义：(3,4,5) 与 (4,3,5) 分别计数。

参数：countTriples(n: integer) → integer
约束：1 ≤ n ≤ 250。

官方示例 1

输入：n = 5
输出：2

对应 (3,4,5)、(4,3,5)。

官方示例 2

输入：n = 10
输出：4

对应 (3,4,5)、(4,3,5)、(6,8,10)、(8,6,10)。

先想一想：如何保证三元组不遗漏，又不会重复统计同一个有序三元组？准备好后再展开下方实验与题解。

查看官方题目

题解 · 为每一对边寻找整数斜边

核心洞察

固定有序数对 (a,b) 后，正整数 c 若存在就只能等于 √(a²+b²)。因此不必再枚举 c。取 c = floor(sqrt(a*a+b*b))，再严格检查 c*c === a*a+b*b 与 c ≤ n。

完整过程

  1. 计数器从 0 开始。
  2. 外层遍历 a = 1 … n，内层遍历 b = 1 … n。
  3. 计算 s = a²+b²，以及向下取整的平方根 c。
  4. 如果 c²=s 且 c≤n，计数加 1。
  5. 遍历结束返回计数。交换后的 (b,a) 由循环自然处理。

正确性

可靠性：只在 c²=a²+b² 且 c≤n 时计数，a、b 已由循环保证范围合法，而 a、b≥1 使 c≥1，因此每次计入的三元组都满足要求。

完整性：任意合法 (a,b,c) 的 (a,b) 必然被访问，其平方和是完全平方数，计算出的正平方根恰为 c，因此一定计入。

唯一性：每个有序数对只被访问一次，正平方根唯一，故同一有序三元组只统计一次。

边界与复杂度

n<5 时结果为 0；c 恰好等于 n 时必须计入。a=b 无需特殊处理。约束内平方和最大为 125000，四种语言的对应数值类型均可表示。

时间 O(n²)，辅助空间 O(1)。此处按固定范围内的平方根运算为常数计算；演示界面保存格子和步骤所用空间不属于提交算法。

替代方案

可预先把 1² … n² 放入集合，再查询 a²+b² 是否存在，平均时间 O(n²)、空间 O(n)，无需平方根。三重枚举最直接，但时间 O(n³)。也可只枚举 a<b，命中加 2；需要额外说明正整数 a=b 不可能满足方程。

常见错误

  • 用四舍五入后的平方根直接计数，没有回乘确认完全平方。
  • 漏掉 c≤n 的限制，例如 n=4 时误算 (3,4,5)。
  • 枚举全部有序数对后又乘 2，造成重复。
  • 从 0 开始遍历，将不合法的零边计入。

面试追问

如何完全避开浮点？使用平方集合、整数平方根或二分找平方根。Python 的 isqrt 直接返回整数平方根。

若 n 很大？可以研究勾股数生成公式 (u²−v², 2uv, u²+v²)，通过互质、奇偶条件生成本原三元组，再枚举倍数并计入交换顺序，重点是避免重复。

Java

class Solution {
    public int countTriples(int n) {
        int answer = 0;
        for (int a = 1; a <= n; a++) {
            for (int b = 1; b <= n; b++) {
                int s = a * a + b * b;
                int c = (int) Math.sqrt(s);
                if (c <= n && c * c == s) answer++;
            }
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number} n
 * @return {number}
 */
var countTriples = function(n) {
    let answer = 0;
    for (let a = 1; a <= n; a++) {
        for (let b = 1; b <= n; b++) {
            const s = a * a + b * b;
            const c = Math.floor(Math.sqrt(s));
            if (c <= n && c * c === s) answer++;
        }
    }
    return answer;
};

Python 3

from math import isqrt

class Solution:
    def countTriples(self, n: int) -> int:
        answer = 0
        for a in range(1, n + 1):
            for b in range(1, n + 1):
                s = a * a + b * b
                c = isqrt(s)
                if c <= n and c * c == s:
                    answer += 1
        return answer

C++

#include <cmath>

class Solution {
public:
    int countTriples(int n) {
        int answer = 0;
        for (int a = 1; a <= n; ++a) {
            for (int b = 1; b <= n; ++b) {
                int s = a * a + b * b;
                int c = static_cast<int>(std::sqrt(s));
                if (c <= n && c * c == s) ++answer;
            }
        }
        return answer;
    }
};
