工作计划的最低难度

Minimum Difficulty of a Job Schedule

题目

按原顺序把 jobDifficulty 的工作安排到恰好 d 天，每天至少一项。一天的难度是当天工作难度的最大值，总难度是各天难度之和。返回最小总难度；无法安排则返回 -1。

函数：minDifficulty(jobDifficulty: integer[], d: integer): integer

输入：jobDifficulty = [6,5,4,3,2,1], d = 2
输出：7
解释：前五项在第一天（6），最后一项在第二天（1）。
输入：jobDifficulty = [9,9,9], d = 4
输出：-1
解释：无法让每天至少完成一项。
输入：jobDifficulty = [1,1,1], d = 3
输出：3
解释：每天一项。
输入：[7,1,7,1,7,1], d=3
输出：15
输入：[11,111,22,222,33,333,44,444], d=6
输出：843

约束

  • 1 ≤ jobDifficulty.length ≤ 300
  • 0 ≤ jobDifficulty[i] ≤ 1000
  • 1 ≤ d ≤ 10

切分决策可视化

观察两天计划的每个合法分界线；黄色边框表示第二天开始。

题解：动态规划

核心洞察

依赖顺序意味着每天只能取得原数组中的连续段，故需把数组切成 d 个非空连续段，并最小化各段最大值之和。

完整过程

  1. 若 n<d 返回 -1。
  2. dp[i] 表示上一层天数覆盖前 i 项的最小代价。
  3. 增加一天，枚举末段起点 j，并倒序维护 max(job[j..i-1])，以 dp[j]+max 更新新状态。
  4. 滚动数组，最终返回覆盖全部工作的状态。

正确性

一天时前缀只有一种分组，其代价为前缀最大值。假设上一天状态最优，任意当前最优方案都有唯一末段起点 j；其前缀由归纳假设取得最优，末段代价是区间最大值。转移枚举所有合法 j，因此包含且只包含全部合法方案，取最小值即全局最优。

边界、复杂度与替代方案

n<d 不可行；d=1 取全局最大值；d=n 取总和；难度可为 0。时间 O(dn²)，空间 O(n)。二维 DP 更直观但占 O(dn)；单调栈可优化到 O(dn)，实现更复杂。

面试追问

  • 恢复分组：保存切点并回溯。
  • 为何不能排序：排序破坏依赖顺序。
  • 如何优化：单调栈维护受区间最大值变化影响的状态。

常见错误

  • 允许空天或漏判 n<d。
  • 切点范围未给前面天数预留任务。
  • 把每日最大值误写为和。
  • 原地更新而混用两层状态。

Java

class Solution {
 public int minDifficulty(int[] a,int d){
  int n=a.length,I=1000000000;if(n<d)return -1;
  int[] dp=new int[n+1];java.util.Arrays.fill(dp,I);dp[0]=0;
  for(int day=1;day<=d;day++){int[] nd=new int[n+1];java.util.Arrays.fill(nd,I);
   for(int i=day;i<=n;i++){int mx=0;for(int j=i-1;j>=day-1;j--){mx=Math.max(mx,a[j]);nd[i]=Math.min(nd[i],dp[j]+mx);}}dp=nd;
  }return dp[n];
 }
}

Python

class Solution:
 def minDifficulty(self, a: List[int], d: int) -> int:
  n=len(a)
  if n<d:return -1
  dp=[0]+[float('inf')]*n
  for day in range(1,d+1):
   nd=[float('inf')]*(n+1)
   for i in range(day,n+1):
    mx=0
    for j in range(i-1,day-2,-1):
     mx=max(mx,a[j]);nd[i]=min(nd[i],dp[j]+mx)
   dp=nd
  return dp[n]
