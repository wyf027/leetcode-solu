题解：不断除以 7

核心洞察

任意非负整数都可写成各位数字与 7 的幂之和。n % 7 恰好得到最低位，n / 7（向下取整）则移除最低位。

完整过程

  1. 单独处理 num == 0。
  2. 记录符号，并对绝对值重复取余与整除。
  3. 取得的余数顺序是从低位到高位，因此反转。
  4. 若原数为负，在开头添加 -。

正确性证明

设某一步当前值为 n。整数除法定理保证唯一存在 q 与 r，使 n = 7q + r 且 0 ≤ r < 7；所以 r 正是最低七进制位，q 包含其余高位。循环令 n = q，逐次取得所有位，并在有限步后到达 0。反转余数序列并恢复符号，所得字符串因此恰为原数的七进制表示。

边界与复杂度

  • 0 必须直接返回 "0"，否则循环不会写入数字。
  • 负数只处理符号，数位来自绝对值。
  • 时间复杂度 O(log₇ |num|)，结果存储空间 O(log₇ |num|)。

替代方案

部分语言内置任意进制转换，例如 Java 的 Integer.toString(num, 7)。面试中手写除基取余更能展示机制，也更容易扩展到自定义字符表。

四种语言实现

class Solution {
    public String convertToBase7(int num) {
        if (num == 0) return "0";
        boolean negative = num < 0;
        int n = Math.abs(num);
        StringBuilder digits = new StringBuilder();
        while (n > 0) {
            digits.append(n % 7);
            n /= 7;
        }
        if (negative) digits.append('-');
        return digits.reverse().toString();
    }
}

var convertToBase7 = function(num) {
    if (num === 0) return "0";
    const negative = num < 0;
    let n = Math.abs(num), digits = [];
    while (n > 0) {
        digits.push(String(n % 7));
        n = Math.floor(n / 7);
    }
    if (negative) digits.push("-");
    return digits.reverse().join("");
};

class Solution {
public:
    string convertToBase7(int num) {
        if (num == 0) return "0";
        bool negative = num < 0;
        int n = abs(num);
        string digits;
        while (n > 0) {
            digits.push_back(char('0' + n % 7));

        if (negative) digits.push_back('-');
        reverse(digits.begin(), digits.end());
        return digits;
    }

常见错误

  • 忘记反转余数，导致数位次序颠倒。
  • 未单独处理 0，返回空字符串。
  • 直接对负数取余，遇到不同语言的负余数语义。
  • 把每一步的商而不是余数加入答案。

面试追问

  • 如何抽象成 2 到 36 进制？传入基数和字符表。
  • 如果输入超出机器整数范围？可对十进制字符串做长除法。
  • 能否递归实现？可以，先递归处理商，再拼接余数，但要考虑调用栈。
