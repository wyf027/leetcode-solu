把“相邻 1”变成一段位运算

只看 n & (n >> 1)

题解与可提交代码

核心洞察

把 n 右移一位后与原数按位与：只有原二进制中相邻的 11 会在同一位同时为 1。于是 mask = n & (n >> 1) 的每个置位，恰好对应一对相邻置位。mask 非零且是 2 的幂，就说明恰好只有一对。

完整过程

  1. 计算 mask = n & (n >> 1)。
  2. 排除 mask = 0：没有相邻对。
  3. 用 (mask & (mask - 1)) == 0 判断 mask 是否只有一个置位。

边界与复杂度

n = 0、单独的 1、或 101 都返回 false；111 有两对重叠相邻位，也返回 false。时间 O(1)，空间 O(1)。

替代方案

从低位到高位扫描，遇到 11 时计数。它更直观，但位掩码更短、更直接地表达“每一对重合一次”。

面试追问与常见错误

若改为“至少一对”，只需 mask != 0。常见错误是把 111 当成一对；实际上它贡献两个相邻对，mask 为 11。 

class Solution {
    public boolean consecutiveSetBits(int n) {
        int mask = n & (n >> 1);
        return mask != 0 && (mask & (mask - 1)) == 0;
    }
}
