排序链表 归并调度台

用快慢指针把链表一分为二，再把两条有序链稳定合并；交互区用段长翻倍展示每一层归并的结果。

任务边界

输入单链表 head，返回升序链表。节点数 0～5×10⁴，节点值范围 -10⁵～10⁵；进阶要求 O(n log n) 时间；迭代归并还能达到常数额外空间。

Problem / 题意

分治链表，再稳定合并

给定单链表 head，按节点值升序排序并返回新头。主线解法用快慢指针找中点、断链递归排序两半，再在线性时间内稳定合并。

核心洞察

快慢指针二分，再稳定合并

归并排序天然适合链表：快慢指针定位中点，断开 next 后递归排序两半，再通过指针稳定合并。面试中最容易解释和正确实现，时间 O(n log n)。

完整过程

  1. 空链表或单节点直接返回。
  2. slow 每次走一步，fast 每次走两步，找到中点前驱。
  3. 保存右半头节点，并令 slow.next = null 断开链表。
  4. 递归排序左右两半，再稳定 merge。

边界与复杂度

  • 空链表与单节点直接返回。
  • 重复值合并时优先取左段，保持稳定。
  • 时间 O(n log n)，递归栈额外空间 O(log n)。

替代方案取舍

数组排序实现简单，但额外空间 O(n)；插入排序原地却需要 O(n²)。递归归并是面试主线；若严格追求 O(1) 额外空间，可改为按段长 1、2、4… 翻倍的自底向上归并。

常见错误

  • 找到中点后没有断链，递归无法缩小规模。
  • fast 从 head 开始导致偶数长度切分不符合预期。
  • 合并时忘记接上尚未耗尽的剩余链表。
  • 相等时先取右段，破坏稳定性。

面试追问

为什么 fast 从 head.next 开始？让 slow 停在左半末尾，便于断链。
如何达到 O(1) 空间？改用自底向上迭代归并，消除递归栈。
为什么适合链表？合并只改 next，不需要数组搬移元素。 
class Solution {
    public ListNode sortList(ListNode head) {
        if (head == null || head.next == null) return head;
        ListNode slow = head, fast = head.next;
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        ListNode right = slow.next;
        slow.next = null;
        return merge(sortList(head), sortList(right));
    }

    private ListNode merge(ListNode a, ListNode b) {
        ListNode dummy = new ListNode(), tail = dummy;
        while (a != null && b != null) {
            if (a.val <= b.val) { tail.next = a; a = a.next; }
            else { tail.next = b; b = b.next; }
            tail = tail.next;
        }
        tail.next = a != null ? a : b;
        return dummy.next;
    }
}

class Solution:
    def sortList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if not head or not head.next:
            return head
        slow, fast = head, head.next
        while fast and fast.next:
            slow, fast = slow.next, fast.next.next
        right, slow.next = slow.next, None
        return self.merge(self.sortList(head), self.sortList(right))

        dummy = tail = ListNode()
        while a and b:
            if a.val <= b.val:
                tail.next, a = a, a.next
            else:
                tail.next, b = b, b.next
            tail = tail.next
        tail.next = a or b
        return dummy.next
class Solution {
    ListNode* merge(ListNode* a, ListNode* b) {
        ListNode dummy, *tail = &dummy;
        while (a && b) {
            if (a->val <= b->val) {
                tail->next = a;
                a = a->next;
            } else {
                tail->next = b;
                b = b->next;
            }
            tail = tail->next;
        }
        tail->next = a ? a : b;
        return dummy.next;
    }

public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;
        ListNode *slow = head, *fast = head->next;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        ListNode* right = slow->next;
        slow->next = nullptr;
        return merge(sortList(head), sortList(right));
    }
};
