统计子树中城市之间最大距离

Count Subtrees With Max Distance Between Cities

困难
01 · Problem brief

先把“子树”数清楚

给定一棵由 n 个城市组成的无向树。对每个距离 d = 1…n-1，统计有多少个连通城市子集，其内部任意两座城市的最大距离恰好为 d。

题意转述

城市编号为 1 到 n，edges[i] = [uᵢ, vᵢ] 表示一条双向道路。整张图是一棵树，因此任意两城之间只有一条简单路径。

这里的“子树”不是随意选点：选出的城市必须在原树的诱导结构中保持连通。只含一个城市的子集直径为 0，不计入长度为 n-1 的答案。

函数： countSubgraphsForEachDiameter(n, edges) → int[n-1]
下标： 返回数组的 d-1 位记录直径为 d 的子树数。
距离怎么量？

距离等于唯一道路上经过的边数。一个连通城市子集的最大两点距离，就是它的直径。

  • 2 ≤ n ≤ 15
  • edges.length = n - 1
  • 每条边恰有两个端点
  • 1 ≤ uᵢ, vᵢ ≤ n
  • 所有边互不相同，输入构成树

Full walkthrough

位掩码枚举 + 两次 BFS

因为 n ≤ 15，可以直接枚举所有非空城市子集。对每个候选子集，先确认它连通，再在其诱导树上求直径。

核心洞察 ①：规模允许枚举

一个 n 位掩码表示选中的城市，共有 2ⁿ 种。去掉空集与单点集后，逐一判断即可。

核心洞察 ②：连通子集仍是树

原图没有环，因此任意连通的诱导子图也没有环。它仍是一棵树，可以用“两次 BFS/DFS”找直径。

  1. 枚举掩码。
    从 1 到 (1<<n)-1，跳过只有一个置位的掩码。
  2. 第一次受限 BFS。
    从任意选中城市出发，只沿两端都在掩码中的边移动；同时统计实际访问城市数。
  3. 拒绝不连通子集。
    若访问数小于掩码中的城市数，说明候选不是子树，直接继续下一个掩码。
  4. 定位直径端点。
    第一次 BFS 中最远的城市一定可以作为该树某条直径的端点。
  5. 第二次受限 BFS。
    从这个端点再走一次，所得最大层数就是当前子树的直径 d，累加 answer[d-1]。

正确性说明

完备性：每个城市子集都有唯一掩码，枚举遍历全部掩码，所以不会漏掉任何可能的子树。

合法性：第一次 BFS 只能访问掩码内城市。访问数等于置位数，当且仅当这些城市彼此连通，因此只有合法子树会进入计数。

直径正确性：合法候选是树。树上从任意点出发能到达的最远点可作为直径端点；再从该点搜索得到的最大距离等于树直径。因此每次都累加到正确的 d-1 位置。

唯一计数：一个子树只对应一个掩码，而每个掩码只处理一次，所以每个合法子树恰好被统计一次。

时间 O(2ⁿ · n)空间 O(n)答案空间 O(n)

Java · LeetCode 可提交O(2ⁿ · n)
import java.util.*;

class Solution {
    private List<Integer>[] graph;

    public int[] countSubgraphsForEachDiameter(int n, int[][] edges) {
        graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : edges) {
            int u = edge[0] - 1, v = edge[1] - 1;
            graph[u].add(v);
            graph[v].add(u);
        }

        int[] answer = new int[n - 1];
        for (int mask = 1; mask < (1 << n); mask++) {
            int size = Integer.bitCount(mask);
            if (size < 2) continue;

            int start = Integer.numberOfTrailingZeros(mask);
            int[] first = bfs(start, mask, n);
            if (first[2] != size) continue;

            int[] second = bfs(first[0], mask, n);
            int diameter = second[1];
            answer[diameter - 1]++;
        }
        return answer;
    }

    // [最远点, 最远距离, 访问点数]
    private int[] bfs(int start, int mask, int n) {
        int[] distance = new int[n];
        Arrays.fill(distance, -1);
        ArrayDeque<Integer> queue = new ArrayDeque<>();
        queue.offer(start);
        distance[start] = 0;
        int farthest = start, visited = 0;

        while (!queue.isEmpty()) {
            int u = queue.poll();
            visited++;
            if (distance[u] > distance[farthest]) farthest = u;
            for (int v : graph[u]) {
                if ((mask & (1 << v)) != 0 && distance[v] == -1) {
                    distance[v] = distance[u] + 1;
                    queue.offer(v);
                }
            }
        }
        return new int[]{farthest, distance[farthest], visited};
    }
}

/**
 * @param {number} n
 * @param {number[][]} edges
 * @return {number[]}
 */
var countSubgraphsForEachDiameter = function(n, edges) {
    const graph = Array.from({ length: n }, () => []);
    for (const [from, to] of edges) {
        const u = from - 1;
        const v = to - 1;
        graph[u].push(v);
        graph[v].push(u);
    }

    function bfs(start, mask) {
        const distance = new Array(n).fill(-1);
        const queue = [start];
        distance[start] = 0;
        let head = 0;
        let farthest = start;

        while (head < queue.length) {
            const u = queue[head++];
            if (distance[u] > distance[farthest]) farthest = u;
            for (const v of graph[u]) {
                const selected = (mask & (1 << v)) !== 0;
                if (selected && distance[v] === -1) {
                    distance[v] = distance[u] + 1;
                    queue.push(v);
                }
            }
        }
        return { farthest, diameter: distance[farthest], visited: queue.length };
    }

    const answer = new Array(n - 1).fill(0);
    for (let mask = 1; mask < (1 << n); mask++) {
        let size = 0;
        let start = -1;
        for (let i = 0; i < n; i++) {
            if ((mask & (1 << i)) !== 0) {
                size++;
                if (start === -1) start = i;
            }
        }
        if (size < 2) continue;

        const first = bfs(start, mask);
        if (first.visited !== size) continue;
        const second = bfs(first.farthest, mask);
        answer[second.diameter - 1]++;
    }
    return answer;
};
Python 3 · LeetCode 可提交O(2ⁿ · n)
from collections import deque
from typing import List, Tuple


class Solution:
    def countSubgraphsForEachDiameter(
        self, n: int, edges: List[List[int]]
    ) -> List[int]:
        graph = [[] for _ in range(n)]
        for a, b in edges:
            u, v = a - 1, b - 1
            graph[u].append(v)
            graph[v].append(u)

        def bfs(start: int, mask: int) -> Tuple[int, int, int]:
            distance = [-1] * n
            distance[start] = 0
            queue = deque([start])
            farthest = start
            visited = 0

            while queue:
                u = queue.popleft()
                visited += 1
                if distance[u] > distance[farthest]:
                    farthest = u
                for v in graph[u]:
                    if mask & (1 << v) and distance[v] == -1:
                        distance[v] = distance[u] + 1
                        queue.append(v)

            return farthest, distance[farthest], visited

        answer = [0] * (n - 1)
        for mask in range(1, 1 << n):
            size = mask.bit_count()
            if size < 2:
                continue

            lowest_bit = mask & -mask
            start = lowest_bit.bit_length() - 1
            endpoint, _, visited = bfs(start, mask)
            if visited != size:
                continue

            _, diameter, _ = bfs(endpoint, mask)
            answer[diameter - 1] += 1

        return answer
C++ · LeetCode 可提交O(2ⁿ · n)
class Solution {
public:
    vector<vector<int>> graph;

    vector<int> countSubgraphsForEachDiameter(
        int n, vector<vector<int>>& edges
    ) {
        graph.assign(n, {});
        for (const auto& edge : edges) {
            int u = edge[0] - 1;
            int v = edge[1] - 1;
            graph[u].push_back(v);
            graph[v].push_back(u);
        }

        vector<int> answer(n - 1, 0);
        for (int mask = 1; mask < (1 << n); ++mask) {
            int size = __builtin_popcount(mask);
            if (size < 2) continue;

            int start = __builtin_ctz(mask);
            auto [endpoint, ignored, visited] = bfs(start, mask, n);
            if (visited != size) continue;

            auto [otherEndpoint, diameter, allVisited] = bfs(endpoint, mask, n);
            answer[diameter - 1]++;
        }
        return answer;
    }

private:
    tuple<int, int, int> bfs(int start, int mask, int n) {
        vector<int> distance(n, -1);
        queue<int> pending;
        pending.push(start);
        distance[start] = 0;
        int farthest = start;
        int visited = 0;

        while (!pending.empty()) {
            int u = pending.front();
            pending.pop();
            ++visited;
            if (distance[u] > distance[farthest]) farthest = u;

            for (int v : graph[u]) {
                if ((mask & (1 << v)) != 0 && distance[v] == -1) {
                    distance[v] = distance[u] + 1;
                    pending.push(v);
                }
            }
        }
        return {farthest, distance[farthest], visited};
    }
};
Review notes

边界、替代方案与面试追问

边界情况

  • n = 2 时只有整棵树贡献直径 1。
  • 单点掩码不计入答案，避免访问 answer[-1]。
  • 不连通的选点集合必须排除，即使其中某一连通块有有效直径。

替代方案

可以预先求全树两点距离，然后对每个掩码检查连通性并枚举选中点对取最大距离，时间约为 O(2ⁿ·n²)；思路直观但多一层点对枚举。

面试追问

  • 为什么两次 BFS 只适用于连通树？
  • 若 n 增到 30，如何避免枚举全部子集？
  • 能否按直径端点设计树形 DP？

常见错误

  • 把任意点集都当成子树，没有验证掩码诱导出的城市是否连通。
  • 在 BFS 中走到掩码外城市，导致本不相连的点集借道外部节点“连通”。
  • 把节点数当距离；题目距离是路径的边数，含 k 个节点的链长度是 k-1。
  • 把直径 d 写进 answer[d]，忽略返回数组从下标 0 对应距离 1。
  • 用一次 BFS 的最大距离当直径；任意起点的最远距离不一定就是整棵树的直径。
