二叉树的最近公共祖先 IV

不再只找两个节点：给定一组目标节点，寻找能同时覆盖它们、且位置最深的那个祖先。先观察递归如何把“找到了目标”逐层向上汇合，再按需展开完整题解。

中等 MEDIUM会员题二叉树深度优先搜索哈希集合
Problem

题目描述

给你一棵二叉树的根节点 root，以及一个由树中若干互不相同节点组成的数组 nodes。请返回这些目标节点的最近公共祖先（LCA）：它是同时作为所有目标节点祖先的节点中，深度最大的一个。按照通常定义，节点可以是它自己的祖先。

函数形式： lowestCommonAncestor(root: TreeNode, nodes: TreeNode[]) → TreeNode
平台元数据将第二个参数记为 integer[]，实际提交模板与题意均表示树节点数组；下方四种语言按 TreeNode 数组书写。

示例 1

输入：root = [3,5,1,6,2,0,8,null,null,7,4], nodes = [4,7] 输出：2 解释：节点 2 是 4 与 7 的最近公共祖先。

示例 2

输入：root = [3,5,1,6,2,0,8,null,null,7,4], nodes = [1] 输出：1 解释：节点可以是自己的祖先。

示例 3

输入：root = [3,5,1,6,2,0,8,null,null,7,4], nodes = [7,6,2,4] 输出：5 解释：5 是能覆盖全部四个目标的最深节点。

约束

  • 树中节点数在 [1, 10⁴] 范围内。
  • 每个节点值唯一，且可在 32 位有符号整数范围内。
  • 1 ≤ nodes.length ≤ 10⁴。
  • nodes 中的节点互不相同，并且都存在于树中。

先尝试用一句话描述递归函数的返回含义。想好后，展开下面的独立题解。

Full Explanation

把多个目标压缩成一个集合问题

1 · 集合判定把所有目标节点放进哈希集合，使“当前节点是不是目标”能在均摊 O(1) 时间判断。
2 · 返回值语义dfs(x) 返回 x 子树中应该向上报告的节点：没有目标则 null；命中目标或发现汇合点则返回相应节点。
3 · 首个汇合点后序处理左右子树。若左右都非空，说明目标分居两侧，当前节点是最低的汇合点。
最关键的提前返回：如果当前节点本身就在目标集合中，直接返回当前节点，无须继续向下找。因为所有目标都保证存在，任何更深目标也只能让当前节点继续成为整组目标的祖先。

完整过程

  1. 将 nodes 中的节点引用加入哈希集合。
  2. 从根开始后序 DFS。空节点返回 null；命中目标节点时返回自己。
  3. 分别获得左右子树的返回值 left 与 right。
  4. 二者都非空，返回当前节点；只有一个非空，原样向上传递；都为空则返回空。
  5. 根调用的返回值就是全部目标节点的最近公共祖先。

正确性证明

  1. 归纳语义。对任意节点 x，若 x 的子树不含目标，DFS 返回空；若所有已发现目标集中于一条分支，返回该分支报告的最深候选；若分居两边，返回 x。叶子情形显然成立，后序组合保持该语义。
  2. 命中目标。若 x 本身是目标，任何包含 x 和其他目标的公共祖先都不可能严格位于 x 下方，因此将 x 向上报告不会错过更低的合法答案。
  3. 最低性。第一次出现左右均非空的节点，其任一真后代都不能同时覆盖两侧目标，所以该节点正是这些目标的最低公共祖先；继续上报不会改变这个候选。
  4. 覆盖全部目标。题目保证每个目标都存在于树中。根调用覆盖整棵树，因此最终返回值同时覆盖目标集合中的每个节点，且由最低性知它就是所求 LCA。
复杂度设树有 n 个节点、目标数为 k。构建集合 O(k)，DFS 最坏访问每个节点一次 O(n)，总时间 O(n+k)；集合 O(k)，递归栈最坏 O(h)，其中 h 是树高。
边界情况目标只有一个时答案是它自己；根在目标集合中时答案必为根；退化链会产生 O(n) 递归深度；不要按节点值推断祖先关系。
替代方案可先用 DFS 记录父指针，再从第一个目标向上建立祖先集合，并逐个求交；仍为 O(n+k·h) 的直观做法。大量重复 LCA 查询时可预处理深度与倍增祖先表。
面试追问若目标不保证全部存在，应让 DFS 同时返回候选与命中数量，只有命中数等于 k 才接受答案。若树极深，可改用显式栈，避免递归栈溢出。

常见错误

  • 用节点值而非节点引用建集合；值唯一时看似可行，却偏离函数参数的真实语义。
  • 命中目标后仍只搜索子节点，导致当前目标本身没有被计入。
  • 把“任意一个目标的祖先”误当成“全部目标的公共祖先”。
  • 为每个目标单独从根搜索，造成不必要的 O(nk) 扫描。
  • 目标可能含祖先与后代时，错误要求左右子树都必须返回非空。

Java

Java可提交
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *   int val;
 *   TreeNode left;
 *   TreeNode right;
 *   TreeNode(int x) { val = x; }
 * }
 */
class Solution {
    private Set<TreeNode> targets;

    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode[] nodes) {
        targets = new HashSet<>();
        for (TreeNode node : nodes) {
            targets.add(node);
        }
        return dfs(root);
    }

    private TreeNode dfs(TreeNode node) {
        if (node == null || targets.contains(node)) {
            return node;
        }

        TreeNode left = dfs(node.left);
        TreeNode right = dfs(node.right);

        if (left != null && right != null) {
            return node;
        }
        return left != null ? left : right;
    }
}

/**
 * @param {TreeNode} root
 * @param {TreeNode[]} nodes
 * @return {TreeNode}
 */
var lowestCommonAncestor = function(root, nodes) {
    const targets = new Set(nodes);

    function dfs(node) {
        if (node === null || targets.has(node)) {
            return node;
        }

        const left = dfs(node.left);
        const right = dfs(node.right);

        if (left !== null && right !== null) {
            return node;
        }
        return left !== null ? left : right;
    }

    return dfs(root);
};

class Solution:
    def lowestCommonAncestor(
        self, root: 'TreeNode', nodes: 'List[TreeNode]'
    ) -> 'TreeNode':
        targets = set(nodes)

        def dfs(node: 'TreeNode') -> 'TreeNode':
            if node is None or node in targets:
                return node

            left = dfs(node.left)
            right = dfs(node.right)

            if left is not None and right is not None:
                return node
            return left if left is not None else right

        return dfs(root)

C++可提交
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode(int x) : val(x), left(NULL), right(NULL) {}
 * };
 */
class Solution {
private:
    unordered_set<TreeNode*> targets;

    TreeNode* dfs(TreeNode* node) {
        if (node == nullptr || targets.count(node)) {
            return node;
        }

        TreeNode* left = dfs(node->left);
        TreeNode* right = dfs(node->right);

        if (left != nullptr && right != nullptr) {
            return node;
        }
        return left != nullptr ? left : right;
    }

public:
    TreeNode* lowestCommonAncestor(
        TreeNode* root, vector<TreeNode*>& nodes
    ) {
        targets = unordered_set<TreeNode*>(nodes.begin(), nodes.end());
        return dfs(root);
    }
};
