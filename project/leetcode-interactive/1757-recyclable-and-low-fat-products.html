1757. 可回收且低脂的产品

Recyclable and Low Fat Products

难度：简单数据库非付费题

1题目

给定产品表 Products，找出同时满足“低脂”与“可回收”的产品编号。结果只需返回 product_id 一列，行顺序不限。

目标：两个条件必须同时成立；枚举值 Y 表示“是”，N 表示“否”。

表结构

product_idINT · 主键，值唯一
low_fatsENUM('Y','N') · 是否低脂
recyclableENUM('Y','N') · 是否可回收

约束

  • product_id 是主键，因此每个产品编号唯一。
  • low_fats 与 recyclable 只取 'Y' 或 'N'。
  • 官方元数据未给出表的行数范围；结果允许任意顺序。

完整题解

核心洞察

这是一个“取行”问题：保留所有同时满足两个布尔式枚举条件的记录，再只投影产品编号。关键词是“且”，因此逻辑连接必须是 AND。

保留行 ⇔ low_fats = 'Y' AND recyclable = 'Y'

完整过程

  1. 从 Products 表读取记录。
  2. 用两个等值条件筛选：低脂标记为 Y，且回收标记也为 Y。
  3. 仅选择 product_id 作为输出列。题目不要求排序，无需添加 ORDER BY。

官方可提交解法 · SQL

SELECT product_id
FROM Products
WHERE low_fats = 'Y'
  AND recyclable = 'Y';

正确性证明

充分性：查询输出的任意一行都通过了两个由 AND 连接的谓词，所以对应产品既低脂又可回收，必然符合题意。

必要性：任意符合题意的产品，其两个字段都为 Y，因此一定通过筛选并输出其编号。综上，查询输出恰好是全部目标产品。

边界情况

  • 没有记录同时满足条件时，返回带有 product_id 列的空结果集。
  • 所有记录都满足时，返回全部产品编号。
  • 只有一个条件为 Y 的行必须排除。
  • 主键保证产品编号不会因原表重复行而重复。

复杂度

设表中有 n 行。没有合适索引时，查询通常扫描整表，时间复杂度为 O(n)；除结果集外额外空间可视为 O(1)。实际执行计划由数据库与索引决定。

替代方案

可以使用布尔表达式、子查询或集合运算，但会让这个简单筛选更冗长。若数据量很大且该组合筛选十分频繁，可评估复合索引 (low_fats, recyclable, product_id)；是否值得取决于字段选择性、写入成本和执行计划。

import java.util.ArrayList;
import java.util.List;

public class Solution {
    record Product(int productId, char lowFats, char recyclable) {}

    public static List<Integer> findProducts(List<Product> products) {
        List<Integer> answer = new ArrayList<>();
        for (Product product : products) {
            if (product.lowFats() == 'Y' && product.recyclable() == 'Y') {
                answer.add(product.productId());
            }
        }
        return answer;
    }
}
/**
 * @param {{product_id:number, low_fats:string, recyclable:string}[]} products
 * @return {number[]}
 */
function findProducts(products) {
  return products
    .filter((product) =>
      product.low_fats === "Y" && product.recyclable === "Y"
    )
    .map((product) => product.product_id);
}
from dataclasses import dataclass
from typing import List

@dataclass(frozen=True)
class Product:
    product_id: int
    low_fats: str
    recyclable: str

def find_products(products: List[Product]) -> List[int]:
    return [
        product.product_id
        for product in products
        if product.low_fats == "Y" and product.recyclable == "Y"
    ]

面试追问

为什么不能使用 OR？
OR 会保留“仅低脂”或“仅可回收”的产品，扩大结果集；题意要求两个性质同时成立。
需要 DISTINCT 吗？
不需要。product_id 是主键，每行编号唯一。无根据地添加 DISTINCT 可能引入额外去重开销。
索引一定能提速吗？
不一定。两个枚举字段的基数很低；若大量行都匹配，优化器可能仍选择全表扫描。应结合数据分布与执行计划判断。

常见错误

  • 把 AND 写成 OR。
  • 把字符值写成未加引号的标识符 Y。
  • 返回整个记录，而不是题目要求的单列 product_id。
  • 误以为输出必须排序，添加无必要的排序步骤。
  • 把“可回收”字段名误写为相近单词；应严格使用 recyclable。
