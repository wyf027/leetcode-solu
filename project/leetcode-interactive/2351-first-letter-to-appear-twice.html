第一个出现两次的字母

First Letter to Appear Twice

同一个字母的第二次相遇，哪一次最早发生？

官方题目 ↗

01 / 题目

给定只包含小写英文字母的字符串 s，返回最早完成第二次出现的字母。比较的是各字母第二次出现的下标，不是第一次的位置，也不是字母表顺序。题目保证至少存在一个重复字母。

官方示例 1

输入：s = "abccbaacz"
输出："c"

a 出现在下标 0、5、6；b 在 1、4；c 在 2、3、7；z 在 8。c 的第二次出现位于下标 3，早于 b 的 4 和 a 的 5。

官方示例 2

输入：s = "abcdd"
输出："d"

只有 d 重复，它的第二次出现位于下标 4，因此返回 d。

约束与接口

  • 2 <= s.length <= 100。
  • s 仅含小写英文字母 a 至 z。
  • s 至少包含一个重复字母。
  • 参数：s: string；返回值：一个字符。官方方法名：repeatedCharacter。

04 / 题解实验室

准备好后，展开观察每一次相遇。

核心洞察：只记住“见过没有”

从左向右读取字符。读到某个已经见过的字母时，立即返回它。此刻是第一次遇到重复，也就是所有字母的第二次出现位置中最靠前的一个。无需统计最终频率。

交互 / 字母签到台

每一步读取一个字符，下方 26 格签到台记录已出现字母。再次签到时，当前格与首次出现位置一起标记，然后停止。

2–100 个小写英文字母，至少一个重复。按 Enter 应用；修改后需应用才能更新演示。

绿色 / 已读　橙色实线 / 当前　橙色虚线 / 首次出现位置；每格下方为从 0 开始的下标。

所有按钮支持 Tab 聚焦、Enter / 空格操作；减少动态效果偏好下自动播放间隔延长，无平滑滚动。

完整过程

  1. 初始化空集合 seen。
  2. 依次读取 s 中的字符 c，先判断 c 是否已在集合里。
  3. 如果已存在，返回 c；否则把它加入集合并继续。

以 s = "abccbaacz" 为例：读 a、b、c 后集合为 {a, b, c}；下标 3 再读 c，已存在，返回 c。后面的字符无需读取。

正确性

循环不变式：处理下标 i 前，seen 恰好包含前缀 s[0..i−1] 出现过的字符。空前缀对应空集合；遇到新字符并插入，保持该性质。

若当前字符已在 seen 中，它已经出现过。由于此前遇到任何重复都会返回，因此这是扫描中的第一次重复，也必然是该字符的第二次出现。所有更小下标都未完成第二次出现，所以当前字符满足题目要求。题目保证有重复，算法必定返回。

边界与复杂度

  • 长度 2 时，合法输入只能是两个相同字母；第二个字符即触发返回。
  • 连续重复、非连续重复、出现三次及以上，都由第一次命中 seen 决定结果。
  • 标准分析：时间 O(n)，额外空间 O(26) = O(1)；集合操作按常数时间分析。
  • 更紧的界：固定 26 字母表下，最多读到第 27 个字符就必然重复，实际扫描量为 O(min(n, 27))。泛化到任意字符集时，空间可达 O(n)。
  • 空串、无重复或含非小写字母不在官方输入范围内；演示输入会拒绝这些情况。

四语言实现

以下均使用官方方法签名，可作为 LeetCode 提交代码；尚未编译或运行。Java / C++ 用 26 位布尔表，JavaScript / Python 用集合，机制相同。末尾返回值仅用于补全函数，合法输入不会走到该处。

Java

class Solution {
    public char repeatedCharacter(String s) {
        boolean[] seen = new boolean[26];
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            int index = c - 'a';
            if (seen[index]) return c;
            seen[index] = true;
        }
        return '\0';
    }
}

JavaScript

/**
 * @param {string} s
 * @return {character}
 */
var repeatedCharacter = function(s) {
    const seen = new Set();
    for (const c of s) {
        if (seen.has(c)) return c;
        seen.add(c);
    }
    return "";
};

Python 3

class Solution:
    def repeatedCharacter(self, s: str) -> str:
        seen = set()
        for c in s:
            if c in seen:
                return c
            seen.add(c)
        return ""

C++

#include <string>
using namespace std;

class Solution {
public:
    char repeatedCharacter(string s) {
        bool seen[26] = {};
        for (char c : s) {
            int index = c - 'a';
            if (seen[index]) return c;
            seen[index] = true;
        }
        return '\0';
    }
};

替代方案

  • 位掩码：用一个整数的低 26 位记录是否见过。先检查 mask & (1 << index)，再按位或置位；复杂度相同，代码更紧凑但可读性稍差。
  • 逐个回看前缀：对每个位置检查此前是否有相同字符。泛化分析时间 O(n²)，空间 O(1)，但重复比较较多。
  • 记录每个字母第二次位置：扫描后选择最小值，同样可行，但保存的信息更多且失去提前退出的优势。

面试追问

  • 字符以流的形式到达？维护同一个 seen，出现首次命中即可输出，不必保留完整字符串。
  • 改成最早出现 k 次？集合改为计数表，每次加一后检查是否等于 k。
  • 支持 Unicode？使用集合并约定“字符”是码点还是用户看到的字素；还需按需求处理规范化。
  • 若不保证重复？扫描完显式返回空值或约定的哨兵，并相应调整接口。

常见错误

  • 先加入 seen 再检查，导致第一个字符就被误判；应先查后加。
  • 先统计频率，再返回字符串里最早出现的重复字母；abbbac 的答案是 b，而不是 a。
  • 排序会破坏原始位置，无法确定谁先完成第二次出现。
  • 继续扫描并覆盖答案，会得到后来的重复字母；找到第一个就返回。
