Briefing

任务说明

每个数字只出现一次。相邻对的排列顺序与对内方向都不代表原数组方向。

有一个由 n 个互不相同的整数组成的数组 nums，现在数组本身遗失了，但它的每一对相邻元素仍被记录下来。

给定大小为 n - 1 的二维整数数组 adjacentPairs。每个完整参数项 adjacentPairs[i] = [uᵢ, vᵢ] 仅表示 uᵢ 与 vᵢ 在 nums 中相邻；它可能按任意方向记录，所有项也可能被任意打乱。

返回任意一个符合这些相邻关系的原数组 nums。题目保证答案存在。

约束

  • nums.length == n
  • adjacentPairs.length == n - 1
  • adjacentPairs[i].length == 2
  • 2 <= n <= 10⁵
  • -10⁵ <= nums[i], uᵢ, vᵢ <= 10⁵
  • 存在至少一个满足全部相邻对的数组。

Complete solution

把数组看成一条无向路径

核心洞察：相邻对就是无向图的边。因为原数组元素互不相同且所有相邻关系都被完整记录，这张图必然是一条简单路径：两个端点度数为 1，其余节点度数为 2。任选一个端点出发，只走向不是上一个节点的邻居，就能依次还原整个数组。

完整过程

  1. 用哈希表为每个数字建立邻接表，同时加入 u → v 和 v → u。
  2. 扫描邻接表，找到任意一个邻居数量为 1 的节点，作为答案首元素。
  3. 令 prev 表示刚走过的节点。查看当前节点的邻居，选择不等于 prev 的那一个加入答案。
  4. 持续更新 prev 与当前节点，直到答案长度达到 n。

正确性证明

  1. 图结构成立：每个相邻对对应原数组中一条边，全部 n-1 条边恰好把 n 个互异节点连成原数组路径。
  2. 起点正确：原数组两端只与一个元素相邻，所以度数为 1；任选其一会得到正向或反向数组，二者都合法。
  3. 每一步正确：路径内部节点只有前驱和后继两个邻居。排除 prev 后，剩下的唯一邻居必是下一个数组元素。
  4. 终止完整：从端点沿唯一后继不断前进，不会分叉或成环，恰好访问全部 n 个节点。因此输出包含且仅包含原数组元素，并满足所有相邻对。

边界情况

  • n = 2：两个节点都是端点，返回任一方向均可。
  • 负数与大值：数字仅作为哈希键，无需按值域开数组。
  • 答案反转：从另一个端点开始会得到反向结果，同样正确。
  • 唯一元素：题目保证互异，因此无需处理同值节点合并。

复杂度与替代方案

时间O(n)建图、找端点、遍历各一次
空间O(n)邻接表与答案数组

替代方案：可以从端点做递归 DFS，但最坏递归深度为 10⁵，某些语言可能栈溢出；迭代走链更直接。也可维护每个点的异或邻居值以压缩常数，但可读性更差，且仍需哈希表保存节点信息。

JavaLeetCode 可提交
import java.util.*;

class Solution {
    public int[] restoreArray(int[][] adjacentPairs) {
        Map<Integer, List<Integer>> graph = new HashMap<>();
        for (int[] pair : adjacentPairs) {
            graph.computeIfAbsent(pair[0], k -> new ArrayList<>())
                 .add(pair[1]);
            graph.computeIfAbsent(pair[1], k -> new ArrayList<>())
                 .add(pair[0]);
        }

        int start = 0;
        for (Map.Entry<Integer, List<Integer>> entry : graph.entrySet()) {
            if (entry.getValue().size() == 1) {
                start = entry.getKey();
                break;
            }
        }

        int n = adjacentPairs.length + 1;
        int[] answer = new int[n];
        answer[0] = start;
        if (n == 1) return answer;
        answer[1] = graph.get(start).get(0);

        for (int i = 2; i < n; i++) {
            List<Integer> neighbors = graph.get(answer[i - 1]);
            answer[i] = neighbors.get(0) != answer[i - 2]
                    ? neighbors.get(0)
                    : neighbors.get(1);
        }
        return answer;
    }
}
JavaScriptLeetCode 可提交
/**
 * @param {number[][]} adjacentPairs
 * @return {number[]}
 */
var restoreArray = function(adjacentPairs) {
    const graph = new Map();

    for (const [u, v] of adjacentPairs) {
        if (!graph.has(u)) graph.set(u, []);
        if (!graph.has(v)) graph.set(v, []);
        graph.get(u).push(v);
        graph.get(v).push(u);
    }

    let start;
    for (const [value, neighbors] of graph) {
        if (neighbors.length === 1) {
            start = value;
            break;
        }
    }

    const n = adjacentPairs.length + 1;
    const answer = [start];
    while (answer.length < n) {
        const current = answer[answer.length - 1];
        const previous = answer.length > 1
            ? answer[answer.length - 2]
            : undefined;
        const next = graph.get(current).find(value => value !== previous);
        answer.push(next);
    }
    return answer;
};
Python 3LeetCode 可提交
from collections import defaultdict
from typing import List


class Solution:
    def restoreArray(
        self, adjacentPairs: List[List[int]]
    ) -> List[int]:
        graph = defaultdict(list)
        for u, v in adjacentPairs:
            graph[u].append(v)
            graph[v].append(u)

        start = next(
            value
            for value, neighbors in graph.items()
            if len(neighbors) == 1
        )

        n = len(adjacentPairs) + 1
        answer = [start]
        while len(answer) < n:
            current = answer[-1]
            previous = answer[-2] if len(answer) > 1 else None
            for neighbor in graph[current]:
                if neighbor != previous:
                    answer.append(neighbor)
                    break

        return answer
C++LeetCode 可提交
class Solution {
public:
    vector<int> restoreArray(
        vector<vector<int>>& adjacentPairs
    ) {
        unordered_map<int, vector<int>> graph;
        for (const auto& pair : adjacentPairs) {
            graph[pair[0]].push_back(pair[1]);
            graph[pair[1]].push_back(pair[0]);
        }

        int start = 0;
        for (const auto& [value, neighbors] : graph) {
            if (neighbors.size() == 1) {
                start = value;
                break;
            }
        }

        const int n = adjacentPairs.size() + 1;
        vector<int> answer;
        answer.reserve(n);
        answer.push_back(start);

        while (answer.size() < n) {
            int current = answer.back();
            int previous = answer.size() > 1
                ? answer[answer.size() - 2]
                : INT_MAX;
            for (int neighbor : graph[current]) {
                if (neighbor != previous) {
                    answer.push_back(neighbor);
                    break;
                }
            }
        }
        return answer;
    }
};

常见错误

  • 把 [u,v] 当作有向关系，只记录 u → v。
  • 直接从任意节点出发；内部节点会产生两个方向，难以确定首项。
  • 只用全局 visited 集合却忘记路径结构只需记录 prev，增加不必要复杂度。
  • 默认输出必须与示例方向一致；反向数组也合法。
  • 递归 DFS 未考虑 n = 10⁵ 时的调用栈风险。

面试追问

如果元素不再互异呢？数值不能再唯一标识节点，仅凭数值相邻对通常不足以唯一恢复，需要额外位置标识或更强约束。
如何验证输入一定是一条路径？检查节点数为边数加一、连通、恰有两个度数为 1 的节点、其余度数为 2；n=2 时两点度数均为 1。
能否边读数据边输出？一般不能。端点可能最后才出现，且在找出起点前无法确定遍历方向，至少要保存足够的相邻关系。
