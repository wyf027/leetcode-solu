LEETCODE 2376 / COUNT SPECIAL INTEGERS

统计特殊整数

十个数字，不许重复。数一数上界之内有多少种可能。

01 / 题目

一个正整数的十进制表示中，如果任何数字都没有出现两次，就称它为特殊整数。给定正整数 n，计算闭区间 [1, n] 内特殊整数的数量。

例如 102 符合条件；100 中数字 0 重复，不符合条件。数字的顺序不同，表示的整数也不同。

参数：n: integer　返回：integer
官方方法：countSpecialNumbers(n)

约束与思考

1 ≤ n ≤ 2 × 10⁹

只计正整数，区间包含 n。整数通常表示中没有前导零。

先想一想：从 99 到 100，答案会增加吗？当 n 很大时，逐个检查整数是否仍然合适？

02 / 官方示例

示例 1

输入：n = 20
输出：19

1 到 20 中只有 11 出现重复数字，因此有 19 个特殊整数。

示例 2

输入：n = 5
输出：5

1 到 5 的每个整数都符合条件。

示例 3

输入：n = 135
输出：110

共有 110 个。22、114、131 等整数因含有重复数字而被排除。

03 / 题解 · 前缀计数与排列

核心洞察

把所有合法整数分成“位数更短”和“与 n 等长”两类。对于等长整数，从高位向低位走：第一次选出比 n 对应数位更小的数字后，后面就不再受上界约束，只需从未使用的数字中按顺序取出若干个。

定义 A(m, r) = m × (m−1) × … × (m−r+1)，其中 A(m, 0) = 1。它表示从 m 个数字里不重复地安排 r 个位置。r 超过 m 时为 0。

完整过程

  1. 令 L 为 n 的位数。每个长度 k < L 的合法整数有 9 × A(9, k−1) 个：首位不为 0，后面可用包括 0 在内的剩余数字。
  2. 等长时，从位置 i = 0 开始，维护与 n 相同的前缀和已用数字的位掩码 mask。
  3. 枚举尚未使用、且小于 n[i] 的 d；首位只能从 1 开始。每个选择增加 A(9−i, L−i−1)。
  4. 尝试沿 n[i] 继续。如果该数字已经使用，立刻返回累计值；否则将它标为已用。
  5. 若走完所有位，说明 n 自身也合法，最后加 1。

n = 135：较短位数贡献 9 + 81；前缀 10、12 各贡献 8；前缀 130、132、134 各贡献 1；135 自身再贡献 1，合计 110。

正确性证明

划分完整：不超过 n 的整数要么位数更短，要么等长。等长且小于 n 的整数有唯一的“首次小于 n 的位置”，因此恰好归入一个枚举分支。

分支计数准确：前缀始终无重复；当前位置选取可用的 d 后，已用 i+1 个数字，后缀从剩余 9−i 个数字中选取排列。前缀已经更小，任意这样的后缀都不会超过 n。

停止与等号：若沿上界的下一位重复，任何延续该前缀的整数都不合法；此前较小的分支已计完。若完整走到底，仅 n 自身尚未计入，故加 1。各部分不重不漏。

边界与复杂度

  • n < 10：返回 n；n = 1 返回 1。
  • n = 100：重复的 0 阻止上界分支继续，100 本身不计入。
  • 首位排除 0，其他位可以使用一次 0。
  • 空后缀只有一种填法，所以 A(m, 0) = 1。
  • L ≤ 10。此实现逐次计算排列，时间 O(10L²)，固定十进制下为 O(L²)；存储数位需 O(L) 空间，掩码为常数空间。
  • 全部十位以内的不重复正整数最多 8,877,690 个；在本题范围内，32 位有符号整数足够承载计数和中间排列值。

替代方案、追问与常见错误

替代：数位 DP 使用 (pos, mask, tight, started)。用 started 区分前导零和真正的数字 0，结束时只接受已开始的正整数。记忆化后时间 O(L × 2¹⁰ × 10)，空间 O(L × 2¹⁰)。适合继续增加数位条件。

面试追问：区间 [a,b] 怎么数？定义 F(0)=0，返回 F(b)−F(a−1)。若还要求数位和为某数，数位 DP 增加“数位和”状态。若要线性于 L 的计数，可预先存储小型排列值表。

常见错误：使用组合数而忽略顺序；把前导零算入已用集合；重复后仍继续沿上界；忘记计入合法的 n；错误地把后缀可用数写成 10−i；枚举到 n 导致 O(nL) 超时。

Java
class Solution {
    private int perm(int m, int r) {
        if (r > m) return 0;
        int ans = 1;
        for (int j = 0; j < r; j++) ans *= m - j;
        return ans;
    }

    public int countSpecialNumbers(int n) {
        char[] s = Integer.toString(n).toCharArray();
        int len = s.length, ans = 0, mask = 0;
        for (int k = 1; k < len; k++) {
            ans += 9 * perm(9, k - 1);
        }
        for (int i = 0; i < len; i++) {
            int cur = s[i] - '0';
            for (int d = (i == 0 ? 1 : 0); d < cur; d++) {
                if ((mask & (1 << d)) == 0) {
                    ans += perm(9 - i, len - i - 1);
                }
            }
            if ((mask & (1 << cur)) != 0) return ans;
            mask |= 1 << cur;
        }
        return ans + 1;
    }
}

        def perm(m: int, r: int) -> int:
            if r > m:
                return 0

            return ans

        s = str(n)

        ans = 0

            ans += 9 * perm(9, k - 1)

                return ans
            mask |= 1 << cur
        return ans + 1
