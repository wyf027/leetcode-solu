动态口令

某公司将密码开头的 target 个字符按顺序移到末尾。这里先观察字符怎样移动，再自己完成这次更新。

题目（LeetCode CN 官方题面复核）

初始密码为字符串 password。设定正整数 target 后，将 password 前 target 个字符按原顺序移动至字符串末尾，返回更新后的密码字符串。

示例 1password = "s3cur1tyC0d3", target = 4
输出："r1tyC0d3s3cu"
示例 2password = "lrloseumgh", target = 6
输出："umghlrlose"

约束：1 ≤ target < password.length ≤ 10000。官方函数：dynamicPassword(password, target)（JavaScript / Python / Java / C++）。

题解：一次左旋，就是两段拼接

核心洞察

前 target 个字符的相对次序不变，余下字符的相对次序也不变。因此把两段分别取出，再按“右段 + 左段”连接即可。

完整过程

  1. 令 left = password.slice(0, target)。
  2. 令 right = password.slice(target)。
  3. 返回 right + left。

边界与复杂度

题目保证 target 合法。长度为 n 时需要构造返回字符串，时间 O(n)，额外空间 O(n)。

替代方案、追问与常见错误

  • 三次反转：先反转左段、再反转右段、最后反转整体；适合考察原地数组操作，但字符串通常不可变。
  • 追问：若 target 可能大于长度，可先取 target % n；本题不需要。
  • 错误：把左段倒序、丢失空格，或拼成 left + right；均会改变题意。 
var dynamicPassword = function(password, target) {
  return password.slice(target) + password.slice(0, target);
};
class Solution:
    def dynamicPassword(self, password: str, target: int) -> str:
        return password[target:] + password[:target]
class Solution {
    public String dynamicPassword(String password, int target) {
        return password.substring(target) + password.substring(0, target);
    }
}
class Solution {
public:
    string dynamicPassword(string password, int target) {
        return password.substr(target) + password.substr(0, target);
    }
