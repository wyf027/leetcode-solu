题意与数据契约

准确转述

表 Calls 记录一次通话的发起人、接听人和持续时间。请对每一对发生过通话的不同用户进行汇总：输出较小的用户编号 person1、较大的用户编号 person2、两人之间的通话次数 call_count，以及总通话时长 total_duration。通话方向不影响“两人组合”，结果顺序不限。

Calls 表

列名类型含义
from_idint发起人编号
to_idint接听人编号
durationint本次通话时长

约束与输出

  • 输入列均为整数；每行表示一条通话记录。
  • 一对用户可能双向、多次通话，重复记录也应分别计数。
  • 输出必须满足 person1 < person2。
  • 官方元数据未提供数值范围，因此这里不虚构上下界。
  • 输出列：person1, person2, call_count, total_duration。
关键语义：(1, 2) 与 (2, 1) 属于同一对人；每条记录只进入一个分组。

Solution

规范化键 + 分组聚合

MySQL

核心洞察

问题不是按有向边 from_id → to_id 分组，而是按无向边分组。用较小编号作 person1、较大编号作 person2，就能为同一对人构造唯一键。

完整过程

  1. 对每行计算 LEAST(from_id, to_id)。
  2. 计算 GREATEST(from_id, to_id)。
  3. 按这两个表达式分组。
  4. 用 COUNT(*) 计数，用 SUM(duration) 求总时长。

边界情况

  • 只有一次通话：计数为 1。
  • 两个方向都有记录：归入同一组。
  • 完全重复的行：每行仍代表一次通话，应全部计数。
  • 多组用户：每个规范化键独立聚合。

复杂度

设记录数为 n、不同用户对数为 k。数据库通常通过哈希聚合达到期望时间 O(n)、额外空间 O(k)；若采用排序聚合，时间可能为 O(n log n)。

正确性证明

1

唯一归一化。 对任意不同用户 a,b，无论记录为 a→b 还是 b→a，(min(a,b), max(a,b)) 都相同。

2

组间不混淆。 两个不同的无序用户对不可能拥有相同的“较小值、较大值”二元组，因此不会进入同一分组。

3

聚合完整。 COUNT(*) 恰好计入组内每条通话记录一次，SUM(duration) 恰好累加这些记录的时长。

由唯一归一化、组间不混淆和组内完整聚合可知，输出恰好是每对用户的通话次数与总时长。

MySQL · 官方提交方案

可提交
SELECT
    LEAST(from_id, to_id) AS person1,
    GREATEST(from_id, to_id) AS person2,
    COUNT(*) AS call_count,
    SUM(duration) AS total_duration
FROM Calls
GROUP BY
    LEAST(from_id, to_id),
    GREATEST(from_id, to_id);

替代方案与权衡

也可以先用 CTE 或子查询生成 person1/person2，再在外层分组；可读性更强，也避免重复书写表达式。用 UNION ALL 把两个方向强制翻转也能完成，但分支更多且更易漏掉一个方向。不要使用 UNION，它会去重并错误减少通话次数。

Java

本地语义参考
import java.util.*;

public class Main {
    static long[][] numberOfCalls(int[][] calls) {
        Map<String, long[]> groups = new HashMap<>();
        for (int[] call : calls) {
            int a = Math.min(call[0], call[1]);
            int b = Math.max(call[0], call[1]);
            String key = a + ":" + b;
            long[] value = groups.computeIfAbsent(key, k -> new long[]{a, b, 0, 0});
            value[2]++;
            value[3] += call[2];
        }
        List<long[]> answer = new ArrayList<>(groups.values());
        answer.sort(Comparator.comparingLong((long[] x) -> x[0])
                .thenComparingLong(x -> x[1]));
        return answer.toArray(new long[0][]);
    }

    public static void main(String[] args) {
        int[][] calls = {{1,2,59},{2,1,11},{1,3,20},{3,4,100},
                         {3,4,200},{3,4,200},{4,3,499}};
        System.out.println(Arrays.deepToString(numberOfCalls(calls)));
    }
}

function numberOfCalls(calls) {
  const groups = new Map();
  for (const [from, to, duration] of calls) {
    const person1 = Math.min(from, to);
    const person2 = Math.max(from, to);
    const key = `${person1}:${person2}`;
    const value = groups.get(key) ?? [person1, person2, 0, 0];
    value[2] += 1;
    value[3] += duration;
    groups.set(key, value);
  }
  return [...groups.values()].sort((a, b) => a[0] - b[0] || a[1] - b[1]);
}

const calls = [[1,2,59],[2,1,11],[1,3,20],[3,4,100],
               [3,4,200],[3,4,200],[4,3,499]];
console.log(numberOfCalls(calls));

from collections import defaultdict

def number_of_calls(calls: list[list[int]]) -> list[list[int]]:
    groups = defaultdict(lambda: [0, 0])
    for from_id, to_id, duration in calls:
        pair = (min(from_id, to_id), max(from_id, to_id))
        groups[pair][0] += 1
        groups[pair][1] += duration
    return [
        [person1, person2, count, total]
        for (person1, person2), (count, total) in sorted(groups.items())
    ]

calls = [[1,2,59],[2,1,11],[1,3,20],[3,4,100],
         [3,4,200],[3,4,200],[4,3,499]]
print(number_of_calls(calls))

#include <iostream>
#include <map>
#include <utility>
#include <vector>
using namespace std;

vector<vector<long long>> numberOfCalls(const vector<vector<int>>& calls) {
    map<pair<int, int>, pair<long long, long long>> groups;
    for (const auto& call : calls) {
        int person1 = min(call[0], call[1]);
        int person2 = max(call[0], call[1]);
        auto& value = groups[{person1, person2}];
        ++value.first;
        value.second += call[2];
    }
    vector<vector<long long>> answer;
    for (const auto& [pair, value] : groups) {
        answer.push_back({pair.first, pair.second, value.first, value.second});
    }
    return answer;
}

int main() {
    vector<vector<int>> calls = {{1,2,59},{2,1,11},{1,3,20},
        {3,4,100},{3,4,200},{3,4,200},{4,3,499}};
    for (const auto& row : numberOfCalls(calls)) {
        for (long long value : row) cout << value << ' ';
        cout << '\n';
    }
}

常见错误

  • 直接按 from_id, to_id 分组，导致两个方向分裂。
  • 只在输出中交换编号，却仍按原始列分组。
  • 使用 COUNT(duration)；若扩展数据允许空时长，会与行数语义不同，COUNT(*) 更准确。
  • 使用 UNION 去重，吞掉真实的重复通话。
