等计数子串的数量

Number of Equal Count Substrings

中等 · MEDIUM付费题字符串计数

连续的一段字符，能否让每一种出现的字母都达到指定次数？

01 / 题目

只检查子串中出现过的字母

输入小写英文字母组成的字符串 s 和正整数 count。请统计所有满足以下条件的非空连续子串：其中每种实际出现的字母，都恰好出现 count 次。返回这样的子串数量。

下标从 0 开始；不同位置的子串分别计数，即使内容相同。子串必须连续，不允许跳过字符；未出现的字母无需达到指定次数。

函数契约
equalCountSubstrings(s: string, count: integer) → integer

约束

  • 1 ≤ s.length ≤ 3 × 10⁴
  • 1 ≤ count ≤ 3 × 10⁴
  • s 仅包含小写英文字母 a 至 z。

03 / 独立题解

准备好再揭开思路

包含窗口实验台、推导、证明与四语言实现。

枚举字母种类，固定窗口长度

核心洞察

设合法子串有 k 种字母，每种都出现 count 次，那么长度一定是 L = k × count。小写字母至多 26 种，所以只需扫描至多 26 种窗口长度。

维护频率数组 freq[26] 和 exact：恰好出现 count 次的字母种类数。当窗口长度恰为 L 且 exact == k 时，这 k 种字母已占满 L 个位置，窗口不可能再有其他字母，因此合法。

完整过程

  1. 枚举 k 从 1 到 26，若 k × count > n 就结束枚举。
  2. 每轮清空频率数组，令 exact = 0。右端指针 r 从 0 向右移动。
  3. 修改某个字母频率前，如果旧频率等于 count，先让 exact 减一；修改后，若新频率等于 count，让 exact 加一。
  4. 加入 s[r]；当 r ≥ L 时移除 s[r-L]，恢复最多 L 长的窗口。
  5. 只有窗口已经填满，即 r ≥ L-1，且 exact == k 时才累加答案。
  6. 所有长度扫描完毕，返回答案；不复制子串，也不保存所有答案区间。

以示例一为例：k = 1 时长度为 3，找到 [0,2]；k = 2 时长度为 6，找到 [3,8]；k = 3 时长度为 9，找到 [0,8]，总计 3。

正确性论证

频率不变式：每次右端推进后，加入新字符并在必要时移除最左字符，freq 因而准确表示当前窗口。每次更改频率前撤销旧贡献、之后加入新贡献，exact 始终是频率恰好为 count 的字母数。

可靠性：在长为 k × count 的窗口中，如果 exact = k，则这 k 种字母各占 count 个位置，合计正好覆盖整个窗口。不存在额外字母，因此所有出现的字母都恰好出现 count 次。

完备性：任意合法子串有唯一的字母种类数 k，长度必定是 k × count。扫描该长度时，每个起点的完整窗口都会出现，所以一定被计数。

无重复：同一长度下每个右端只处理一次；不同 k 的长度不同。因此每个下标区间恰好计数一次。

复杂度

令 K = min(26, floor(n / count))。时间为 O(nK)，最坏 O(26n)；频率更新只涉及进入和离开的字母。

额外空间 O(26)，固定字母表下视为 O(1)。若 count > n，循环不进入，直接返回 0。演示为支持回退存储了快照，不计入提交算法复杂度。

边界处理

  • count = 1：统计没有重复字母的非空子串。
  • 全是同一字母：n ≥ count 时有 n − count + 1 个。
  • 相同内容、不同起点必须分别计数。
  • 窗口尚未填满时禁止计数。
  • 答案不超过 n(n+1)/2；n = 30000 时上界 450015000，32 位有符号整数足够。

Java

class Solution {
    public int equalCountSubstrings(String s, int count) {
        int n = s.length(), answer = 0;
        for (int k = 1; k <= 26 && k * count <= n; k++) {
            int length = k * count, exact = 0;
            int[] freq = new int[26];
            for (int r = 0; r < n; r++) {
                int x = s.charAt(r) - 'a';
                if (freq[x] == count) exact--;
                freq[x]++;
                if (freq[x] == count) exact++;
                if (r >= length) {
                    int y = s.charAt(r - length) - 'a';
                    if (freq[y] == count) exact--;
                    freq[y]--;
                    if (freq[y] == count) exact++;
                }
                if (r >= length - 1 && exact == k) answer++;
            }
        }
        return answer;
    }
}

var equalCountSubstrings = function(s, count) {
    const n = s.length;
    let answer = 0;
    for (let k = 1; k <= 26 && k * count <= n; k++) {
        const length = k * count;
        const freq = Array(26).fill(0);
        let exact = 0;
        const update = (index, delta) => {
            if (freq[index] === count) exact--;
            freq[index] += delta;
            if (freq[index] === count) exact++;
        };
        for (let r = 0; r < n; r++) {
            update(s.charCodeAt(r) - 97, 1);
            if (r >= length) {
                update(s.charCodeAt(r - length) - 97, -1);
            }
            if (r >= length - 1 && exact === k) answer++;
        }
    }
    return answer;
};

Python

class Solution:
    def equalCountSubstrings(self, s: str, count: int) -> int:
        n = len(s)
        answer = 0
        for k in range(1, 27):
            length = k * count
            if length > n:
                break
            freq = [0] * 26
            exact = 0

            def update(index: int, delta: int) -> None:
                nonlocal exact
                if freq[index] == count:
                    exact -= 1
                freq[index] += delta
                if freq[index] == count:
                    exact += 1

            for r, char in enumerate(s):
                update(ord(char) - ord('a'), 1)
                if r >= length:
                    update(ord(s[r - length]) - ord('a'), -1)
                if r >= length - 1 and exact == k:
                    answer += 1
        return answer

C++

#include <array>
#include <string>
using namespace std;

class Solution {
public:
    int equalCountSubstrings(string s, int count) {
        int n = static_cast<int>(s.size());
        int answer = 0;
        for (int k = 1; k <= 26 && k * count <= n; ++k) {
            int length = k * count;
            array<int, 26> freq{};
            int exact = 0;
            auto update = [&](int index, int delta) {
                if (freq[index] == count) --exact;
                freq[index] += delta;
                if (freq[index] == count) ++exact;
            };
            for (int r = 0; r < n; ++r) {
                update(s[r] - 'a', 1);
                if (r >= length) {
                    update(s[r - length] - 'a', -1);
                }
                if (r >= length - 1 && exact == k) ++answer;
            }
        }
        return answer;
    }
};

替代方案与取舍

  • 枚举起点并扩展终点：每次更新频率并维护合法性，可做到 O(n²)；在 n = 30000 时不适合作为首选。
  • 固定长度后每次扫描 26 个频率：实现更直观，但总时间 O(26²n)。维护 exact 可免去每个窗口的一次全量扫描。
  • 前缀频率：可快速获得指定区间每个字母的次数；仍需枚举候选长度和起点，并额外使用 O(26n) 空间，不如滑动窗口直接。

常见错误

  • 只在频率达到 count 时增加 exact，却忘记超过 count 后应减一。
  • 移除字符后，从 count + 1 回落到 count 时，漏掉 exact 加一。
  • 将“所有频率相等”误解为合法；必须等于给定的 count。
  • 将“至少 count 次”当成条件，或把不同位置的相同内容去重。
  • 只判断长度为 count 的倍数。长度条件是必要条件，频率条件仍需检查。
  • 直接套普通双指针的“合法则扩展、非法则收缩”；精确次数条件不是这样的单调条件。

面试追问

为什么不必再维护 distinct？固定长度 k × count 配合 exact = k，已通过位置总量证明不存在其他字母。

字符集扩大怎么办？用映射存储频率，枚举种类数到实际种类 D；时间可能变成 O(Dn)，26 的常数优势不再成立。Unicode 还需明确按码点还是字素计数。

如何返回合法区间？命中时记录 [r − L + 1, r]；时间增加输出成本，空间增加 O(答案数量)。

同一个字符串查询多个 count？少量查询可重复扫描；大量查询需结合 n、查询数、不同 count 的数量再考虑缓存或预处理，不能默认一次扫描能复用全部窗口。
