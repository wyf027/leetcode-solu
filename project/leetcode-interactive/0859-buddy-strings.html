亲密字符串

两个字符串之间，是否只差一次“交换两个不同下标的字符”？先别急着看答案——用差异扫描器亲手找到决定结果的线索。

EASYBuddy Strings一次交换

01 · Problem

题目说明

函数：buddyStrings(s, goal)

准确转述

给定两个字符串 s 与 goal。你必须在 s 中选择两个不同下标 i ≠ j，交换这两个位置的字符。若能使交换后的 s 恰好等于 goal，返回 true，否则返回 false。

注意：必须实施一次交换；交换的两个字符可以相同。

约束

  • 1 <= s.length, goal.length <= 2 × 104
  • s 与 goal 只含小写英文字母。
  • 下标从 0 开始，交换位置必须不同。

示例 1

输入
s = "ab", goal = "ba"
输出
true
解释
交换下标 0 和 1，得到 "ba"。

示例 2

输入
s = "ab", goal = "ab"
输出
false
解释
唯一可交换的两个字符不同，交换后变成 "ba"。

示例 3

输入
s = "aa", goal = "aa"
输出
true
解释
交换两个 'a'，字符串仍为 "aa"。

03 · Solution

一次扫描，分清两条路径

核心洞察：若字符串不同，必须恰好只有两个差异位置，并且交叉字符相等；若字符串完全相同，必须存在某个重复字符，才能交换两个不同下标而保持不变。

完整过程

长度不同，直接返回 false。
从左到右记录 s[i] !== goal[i] 的下标；超过两个立即返回 false。
若恰有两个差异 i, j，检查 s[i] === goal[j] 且 s[j] === goal[i]。
若没有差异，检查 s 是否含重复字符；有则能交换两个相同字符。

正确性说明

必要性：一次交换最多改变两个位置。若结果与目标不同的位置多于两个，无法一次修复；若正好两个，交换必须让两处交叉对应。零个差异时，交换后还要保持不变，只能交换值相同的两个字符。

充分性：两个差异交叉相等时，交换它们即可得到目标；字符串相同且存在重复字符时，交换那两个相同字符后仍等于目标。因此算法返回 true 的两种情况都可构造合法交换。

复杂度

时间 O(n)；小写字母频次数组为固定大小，额外空间 O(1)。

边界情况

  • 长度不同。
  • 长度为 1 且相同。
  • 完全相同但没有重复字符。
  • 完全相同且存在重复字符。
  • 恰好两个差异，但字符不能交叉匹配。
  • 差异超过两个。

替代方案

可先收集全部差异下标，再统一判断，表达直观但可能多占 O(n) 空间。也可对两个字符串排序比较字符集合，但仍不能替代“差异恰好为两处”的位置条件，且复杂度升为 O(n log n)。

常见错误

  • 认为 s === goal 时总为真。
  • 只比较两字符串的字符频次。
  • 允许交换同一个下标。
  • 看到两个差异就返回真，漏掉交叉验证。
  • 忘记先检查长度。

四语言完整实现

class Solution {
    public boolean buddyStrings(String s, String goal) {
        if (s.length() != goal.length()) return false;

        int first = -1, second = -1;
        int[] count = new int[26];
        boolean hasDuplicate = false;

        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i) - 'a';
            if (++count[c] >= 2) hasDuplicate = true;

            if (s.charAt(i) != goal.charAt(i)) {
                if (first == -1) first = i;
                else if (second == -1) second = i;
                else return false;
            }
        }

        if (first == -1) return hasDuplicate;
        if (second == -1) return false;
        return s.charAt(first) == goal.charAt(second)
            && s.charAt(second) == goal.charAt(first);
    }
}

 * @param {string} s
 * @param {string} goal

var buddyStrings = function(s, goal) {
    if (s.length !== goal.length) return false;

    const diff = [];
    const seen = new Set();
    let hasDuplicate = false;

    for (let i = 0; i < s.length; i++) {
        if (seen.has(s[i])) hasDuplicate = true;
        seen.add(s[i]);

        if (s[i] !== goal[i]) {
            diff.push(i);
            if (diff.length > 2) return false;
        }
    }

    if (diff.length === 0) return hasDuplicate;
    if (diff.length !== 2) return false;
    const [i, j] = diff;
    return s[i] === goal[j] && s[j] === goal[i];
};
class Solution:
    def buddyStrings(self, s: str, goal: str) -> bool:
        if len(s) != len(goal):
            return False

        diff = []
        seen = set()
        has_duplicate = False

        for i, char in enumerate(s):
            if char in seen:
                has_duplicate = True
            seen.add(char)

            if char != goal[i]:
                diff.append(i)
                if len(diff) > 2:
                    return False

        if not diff:
            return has_duplicate
        if len(diff) != 2:
            return False
        i, j = diff
        return s[i] == goal[j] and s[j] == goal[i]
class Solution {
public:
    bool buddyStrings(string s, string goal) {
        if (s.size() != goal.size()) return false;

        vector<int> diff;
        array<int, 26> count{};
        bool hasDuplicate = false;

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            if (++count[s[i] - 'a'] >= 2) hasDuplicate = true;
            if (s[i] != goal[i]) {
                diff.push_back(i);
                if (diff.size() > 2) return false;
            }
        }

        if (diff.empty()) return hasDuplicate;
        if (diff.size() != 2) return false;
        int i = diff[0], j = diff[1];
        return s[i] == goal[j] && s[j] == goal[i];
    }
};

06 · Interview

面试追问

如果允许“至多交换一次”，判断会怎样变化？

当 s === goal 时无需再要求重复字符，可以直接返回真；两个差异分支保持不变。

如果字符集不是 26 个小写字母呢？

将定长频次数组换成哈希集合或哈希表；对于 Unicode，还需按语言的码点或字素簇语义明确“字符”的定义。

为什么不能只比较两个字符串排序后的结果？

排序相同只能说明字符多重集合相同，却不能保证只需一次交换。例如多个位置错位时，频次相同仍可能需要多次交换。

能否单次遍历且不保存差异数组？

可以，仅保存前两个差异下标，并在第三个差异出现时提前返回，额外空间为常数。
