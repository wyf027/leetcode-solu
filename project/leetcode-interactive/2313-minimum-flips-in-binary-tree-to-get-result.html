Minimum Flips in Binary Tree to Get Result

一棵布尔表达式树，一次只能翻转一个叶子。怎样用最少的改动，让整棵树得到指定结果？先读题并尝试思考，再展开底部题解。

01 / 题目与规则

给定二叉树根节点 root 和目标布尔值 result。叶子保存 0（false）或 1（true）；内部节点保存一种逻辑运算，对孩子的计算结果求值。每次只能将一个叶子的 0、1 互换。返回使根节点结果等于 result 的最少操作次数，题目保证目标可以实现。

2 · OR 或

至少一个孩子为 1 时输出 1。

3 · AND 与

两个孩子全部为 1 时输出 1。

4 · XOR 异或

两个孩子的值不同才输出 1。

5 · NOT 非

唯一孩子的结果取反。

参数与约束

  • minimumFlips(root: TreeNode, result: boolean) → integer。
  • 节点数为 1 到 10⁵，节点值在 0 到 5 之间。
  • 叶子的值只能为 0、1；非叶子的值只能为 2、3、4、5。
  • OR、AND、XOR 恰好有两个孩子；NOT 恰好有一个孩子，可在左侧或右侧。
  • 只能翻转叶子，不能改变运算符或树的结构。

题意为独立转述。题名、签名、示例输入来自本地官方元数据；缺失题面参考 LeetCode Wiki 题面资料。官方题目入口。

04 / 独立题解

包含交互推演、证明与四种语言代码，默认折叠。

核心洞察：每个节点保留两种未来

只记当前值不够：父节点可能需要子树变成 0，也可能需要它变成 1。定义 dp[u] = [让 u 为 0 的最少代价, 让 u 为 1 的最少代价]。从叶子向根合并两个代价。

叶子值为 v 时，代价为 [v, 1-v]。NOT 交换唯一孩子的两个代价。二元运算仅有 4 种孩子取值组合，按运算结果归类，取左右代价之和的最小值。

交互 / 双代价电路

按代码的逆序层序顺序，先处理孩子，再处理父节点。方框下方是 [变成 0 的代价, 变成 1 的代价]。亮边框为当前节点，绿色为已完成节点。示例取自官方示例 1。

Tab 切换控件，Enter / 空格激活按钮。系统启用“减少动态效果”时停用自动播放，手动步进仍可用。

完整过程与转移

  1. 用数组收集层序节点。每个父节点都排在孩子之前，逆序计算就满足“先孩子后父亲”的依赖。
  2. 叶子以 0 次保留值、1 次翻转值建立状态。
  3. NOT 选择真实存在的孩子，交换两个代价。NOT 节点自身不付翻转代价。
  4. 二元节点枚举 a、b ∈ {0,1}，计算 t = op(a,b)，用 L[a] + R[b] 更新 dp[u][t]。
  5. 最后返回 dp[root][result ? 1 : 0]。
令 L0、L1、R0、R1 为左右子树两种状态的最优代价

示例 1：OR 状态为 [1,0]，上层 NOT 为 [0,1]；XOR 两个叶子都是 1，状态为 [0,1]；根 AND 为 [0,2]。目标 true 的答案为 2。可翻转 OR 下原值为 1 的叶子，使 NOT 输出 1；再翻转 XOR 的任意一个叶子，使 XOR 输出 1。

正确性

对树高归纳。叶子的两个状态显然最优。假设孩子状态最优：NOT 的目标唯一决定孩子目标，交换代价即最优；二元节点的任何合法方案都对应一组 (a,b)。左右子树不共享叶子，所以代价相加。归纳假设保证每个组合都得到最小代价，枚举全部 4 种组合再取最小值，既没有遗漏方案，也能实际实现。因此根的目标状态给出全局最优值。

复杂度与边界

每节点处理常数次，每次最多 4 种组合，时间 O(n)，顺序表与状态表共 O(n) 额外空间；哈希表按常规均摊分析。

  • 单叶：取决于原值是否等于目标。
  • NOT 可能只有右孩子，不可写死 left。
  • 最多 10⁵ 节点，链状树可能让递归栈溢出，使用迭代。
  • 答案不超过叶子数，32 位整数足够。
  • 约束保证 root 非空且输入是合法树。

替代方案、常见错误与面试追问

替代方案

递归返回双代价更短，但需要高度有保障。记忆化搜索 (node,target) 等价，若漏记忆化则可能重复计算。枚举全部叶子翻转集合需要 O(n·2ᴸ) 时间，L 为叶子数，仅适合极小输入。手写逻辑运算公式可以替代四组合枚举，复杂度不变。

常见错误

  • 把内部运算符也当作可翻转节点。
  • 把 OR 的“至少一个为 1”误写为“恰好一个为 1”，漏掉 (1,1)。
  • 仅保存当前值或变成 true 的代价，无法支持 NOT、XOR 的父层需求。
  • 把空孩子当作零代价 false，破坏 NOT 语义。
  • 以节点值为哈希键；同值不同节点必须分别存储。

面试追问

如何输出实际翻转的叶子？每个状态记录最优孩子组合，从根的目标反向恢复。翻转有不同权重？叶子的初值变成 [0,w] 或 [w,0]，转移不变。表达式为共享子树的 DAG？分支可能共享叶子，简单相加会重复计费，当前依赖子树独立性的证明不再成立。

Java

import java.util.ArrayList;
import java.util.IdentityHashMap;
import java.util.List;
import java.util.Map;

// TreeNode 由 LeetCode 提供：int val; TreeNode left, right。
class Solution {
    public int minimumFlips(TreeNode root, boolean result) {
        List<TreeNode> order = new ArrayList<>();
        Map<TreeNode, int[]> dp = new IdentityHashMap<>();
        order.add(root);
        for (int i = 0; i < order.size(); i++) {
            TreeNode u = order.get(i);
            if (u.left != null) order.add(u.left);
            if (u.right != null) order.add(u.right);
        }
        for (int i = order.size() - 1; i >= 0; i--) {
            TreeNode u = order.get(i);
            int v = u.val;
            if (v < 2) {
                dp.put(u, new int[]{v, 1 - v});
            } else if (v == 5) {
                int[] c = dp.get(u.left != null ? u.left : u.right);
                dp.put(u, new int[]{c[1], c[0]});
            } else {
                int[] l = dp.get(u.left), r = dp.get(u.right);
                int[] d = {1_000_000_000, 1_000_000_000};
                for (int a = 0; a < 2; a++)
                    for (int b = 0; b < 2; b++) {
                        int t = v == 2 ? (a | b) : v == 3 ? (a & b) : (a ^ b);
                        d[t] = Math.min(d[t], l[a] + r[b]);
                    }
                dp.put(u, d);
            }
        }
        return dp.get(root)[result ? 1 : 0];
    }
}

from typing import Optional

# TreeNode 由 LeetCode 提供，具有 val、left、right 属性。
class Solution:
    def minimumFlips(self, root: Optional[TreeNode], result: bool) -> int:
        order, dp = [root], {}
        i = 0
        while i < len(order):
            u = order[i]
            if u.left:
                order.append(u.left)
            if u.right:
                order.append(u.right)
            i += 1
        for u in reversed(order):
            v = u.val
            if v < 2:
                dp[u] = (v, 1 - v)
            elif v == 5:
                c = dp[u.left or u.right]
                dp[u] = (c[1], c[0])
            else:
                l, r = dp[u.left], dp[u.right]
                d = [float('inf'), float('inf')]
                for a in range(2):
                    for b in range(2):
                        t = (a | b) if v == 2 else (a & b) if v == 3 else (a ^ b)
                        d[t] = min(d[t], l[a] + r[b])
                dp[u] = d
        return dp[root][int(result)]

C++

#include <algorithm>
#include <array>
#include <unordered_map>
#include <vector>
using namespace std;

// TreeNode 由 LeetCode 提供：val、left、right。
class Solution {
public:
    int minimumFlips(TreeNode* root, bool result) {
        vector<TreeNode*> order{root};
        unordered_map<TreeNode*, array<int, 2>> dp;
        for (size_t i = 0; i < order.size(); ++i) {
            TreeNode* u = order[i];
            if (u->left) order.push_back(u->left);
            if (u->right) order.push_back(u->right);
        }
        for (auto it = order.rbegin(); it != order.rend(); ++it) {
            TreeNode* u = *it;
            int v = u->val;
            if (v < 2) {
                dp[u] = {v, 1 - v};
            } else if (v == 5) {
                auto c = dp.at(u->left ? u->left : u->right);
                dp[u] = {c[1], c[0]};
            } else {
                auto l = dp.at(u->left), r = dp.at(u->right);
                array<int, 2> d{1000000000, 1000000000};
                for (int a = 0; a < 2; ++a)
                    for (int b = 0; b < 2; ++b) {
                        int t = v == 2 ? (a | b) : v == 3 ? (a & b) : (a ^ b);
                        d[t] = min(d[t], l[a] + r[b]);
                    }
                dp[u] = d;
            }
        }
        return dp.at(root)[result ? 1 : 0];
    }
};
