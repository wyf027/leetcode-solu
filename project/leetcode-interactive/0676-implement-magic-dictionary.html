LeetCode 676 · Design

实现一个魔法字典

构建一个由互不相同的单词组成的字典。查询时，判断能否把查询词中的恰好一个字母换成另一个字母，使结果成为字典里的单词。

中等 字典树 哈希表 字符串 设计

题目说明

实现 MagicDictionary 类：

  • MagicDictionary()：初始化对象。
  • void buildDict(String[] dictionary)：使用互不相同的字符串数组 dictionary 构建数据结构。
  • bool search(String searchWord)：如果能只替换 searchWord 中恰好一个字符，使其与字典中的某个字符串完全相同，则返回 true；否则返回 false。
关键语义：必须替换一个字符；零次替换、插入、删除或替换两个及以上字符都不符合要求。

官方示例

输入
["MagicDictionary", "buildDict", "search", "search", "search", "search"]
[[], [["hello", "leetcode"]], ["hello"], ["hhllo"], ["hell"], ["leetcoded"]]
输出
[null, null, false, true, false, false]

hhllo 可把第二个 h 换成 e 得到 hello；其余查询不满足“恰好替换一个字符”。

约束

  • 1 <= dictionary.length <= 100
  • 1 <= dictionary[i].length <= 100
  • dictionary[i] 仅含小写英文字母，且所有单词互不相同。
  • 1 <= searchWord.length <= 100，且仅含小写英文字母。
  • buildDict 仅调用一次，并且发生在所有 search 之前。
  • 最多调用 search 100 次。

题解：按长度分组后逐词比较

直接比较
核心洞察 完整过程 正确性 复杂度 四语言代码 替代方案

核心洞察

✦
“只改一个字符”就是：长度相等，并且对应位置恰好有一个不同。
所以只需保存字典，并在查询时扫描等长单词；逐字符计数，差异超过 1 就提前停止。

完整过程

  1. buildDict 时按单词长度分组保存，避免查询时比较不可能匹配的异长单词。
  2. search(searchWord) 只遍历与查询词等长的组。
  3. 对每个候选词逐位比较，用 diff 记录不同字符数。
  4. 如果 diff > 1，当前候选已不可能满足条件，立即转向下一个候选。
  5. 某个候选比较结束且 diff == 1 时返回 true；全部失败后返回 false。

边界情况

  • 查询词本身在字典中：与自身的差异数是 0，不能据此返回 true；但字典里若还有另一个等长词与它只差一位，仍应返回 true。
  • 长度不同：替换不会改变长度，因此一定不能匹配。
  • 多个差异：一旦差异超过 1，可以提前结束当前比较。
  • 单字符单词：只要字典中有另一个不同的单字符单词，就能恰好替换一次并匹配。

正确性证明

1
充分性：算法返回 true 时，必然找到了一个与查询词长度相同且恰好一个位置不同的字典词。替换这个位置后，两者完全相同，因此题目条件成立。
2
必要性：若题目条件成立，则存在一个字典词可由查询词恰好替换一个字符得到。替换不改变长度，且除被替换位置外其余位置都相同，所以两词对应位置恰好有一个不同。算法会扫描到该等长词，并返回 true。
3
结论：算法返回 true 当且仅当存在满足条件的字典词，因此算法正确。

复杂度

构建时间O(S)S 为字典总字符数
单次查询O(K · L)K 为等长候选数，L 为查询词长度
额外空间O(S)保存所有字典单词

最坏情况下 K = N，单次查询为 O(N · L)。给定题目的上限（字典和查询各最多 100），该方案简单且足够高效。

完整代码

import java.util.*;

class MagicDictionary {
    private final Map<Integer, List<String>> wordsByLength;

    public MagicDictionary() {
        wordsByLength = new HashMap<>();
    }

    public void buildDict(String[] dictionary) {
        for (String word : dictionary) {
            wordsByLength
                .computeIfAbsent(word.length(), key -> new ArrayList<>())
                .add(word);
        }
    }

    public boolean search(String searchWord) {
        List<String> candidates = wordsByLength.get(searchWord.length());
        if (candidates == null) return false;

        for (String word : candidates) {
            int diff = 0;
            for (int i = 0; i < searchWord.length(); i++) {
                if (searchWord.charAt(i) != word.charAt(i)) {
                    diff++;
                    if (diff > 1) break;
                }
            }
            if (diff == 1) return true;
        }
        return false;
    }
}
var MagicDictionary = function() {
    this.wordsByLength = new Map();
};

/**
 * @param {string[]} dictionary
 * @return {void}
 */
MagicDictionary.prototype.buildDict = function(dictionary) {
    for (const word of dictionary) {
        const length = word.length;
        if (!this.wordsByLength.has(length)) {
            this.wordsByLength.set(length, []);
        }
        this.wordsByLength.get(length).push(word);
    }
};

/**
 * @param {string} searchWord
 * @return {boolean}
 */
MagicDictionary.prototype.search = function(searchWord) {
    const candidates = this.wordsByLength.get(searchWord.length) || [];

    for (const word of candidates) {
        let diff = 0;
        for (let i = 0; i < searchWord.length; i++) {
            if (searchWord[i] !== word[i]) {
                diff++;
                if (diff > 1) break;
            }
        }
        if (diff === 1) return true;
    }
    return false;
};
from collections import defaultdict
from typing import List


class MagicDictionary:
    def __init__(self):
        self.words_by_length = defaultdict(list)

    def buildDict(self, dictionary: List[str]) -> None:
        for word in dictionary:
            self.words_by_length[len(word)].append(word)

    def search(self, searchWord: str) -> bool:
        for word in self.words_by_length[len(searchWord)]:
            diff = 0
            for left, right in zip(searchWord, word):
                if left != right:
                    diff += 1
                    if diff > 1:
                        break
            if diff == 1:
                return True
        return False
class MagicDictionary {
private:
    unordered_map<int, vector<string>> wordsByLength;

public:
    MagicDictionary() = default;

    void buildDict(vector<string> dictionary) {
        for (const string& word : dictionary) {
            wordsByLength[word.size()].push_back(word);
        }
    }

    bool search(string searchWord) {
        auto it = wordsByLength.find(searchWord.size());
        if (it == wordsByLength.end()) return false;

        for (const string& word : it->second) {
            int diff = 0;
            for (int i = 0; i < static_cast<int>(searchWord.size()); i++) {
                if (searchWord[i] != word[i]) {
                    diff++;
                    if (diff > 1) break;
                }
            }
            if (diff == 1) return true;
        }
        return false;
    }
};

替代方案

通配模式哈希表

把每个单词的每个位置依次替换为 *，例如 hello → *ello, h*llo, ...。查询时生成相同模式，若模式来自某个真正不同的字典词即可命中。该方案能加快多次查询，但必须额外判断“只有查询词自身产生该模式”的情况，不能把零次实际变化误判为成功。

字典树 + DFS

在 Trie 上搜索，并用状态记录是否已经替换过字符。每层可以沿相同字符前进，也可在尚未替换时尝试一个不同分支。它贴合官方标签，但实现和常数开销都更大。

面试追问

  • 如果允许“至多替换一个字符”，判定条件要如何改变？
  • 如果字典规模和查询次数都达到百万级，三种方案如何选型？
  • 若允许插入、删除或替换恰好一次，怎样扩展到编辑距离为 1？
  • 通配模式方案如何处理字典词互不相同这一条件被取消的情况？

常见错误

  • 使用 diff <= 1，错误地把完全相同（差异为 0）的词判为成功。
  • 比较不同长度的词，或把插入、删除当作字符替换。
  • 发现一个不同字符就立刻返回 true，没有确认后面是否还存在第二个差异。
  • 通配模式只用集合记录，无法区分模式由查询词自身产生还是由另一个词产生。
