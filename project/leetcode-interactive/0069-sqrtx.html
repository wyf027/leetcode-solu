Core insight

寻找最后一个可行整数

整数 m 满足 m² ≤ x 时，所有更小整数也满足；一旦 m² ＞ x，更大整数都不可能。这个真假分界点具有单调性，因此寻找“最后一个 true”即可。

代码用 mid ≤ x / mid 代替 mid × mid ≤ x，避免 32 位乘法溢出。

Full process

完整过程

  1. x 小于 2 时直接返回 x。
  2. 在 [1, floor(x / 2)] 中二分，answer 记录当前最大可行整数。
  3. 若 mid ≤ floor(x / mid)，保存 mid，并令 left = mid + 1。
  4. 否则令 right = mid − 1；区间为空后返回 answer。

边界

  • 0 与 1 直接返回。
  • 非完全平方数向下取整。
  • 最大输入用除法比较。

复杂度

时间 O(log x)，每轮减半候选区间；额外空间 O(1)。

替代方案

牛顿迭代同样高效，但整数舍入、收敛条件和跨语言精度解释更复杂；面试主线优先二分。

常见错误

  • mid × mid 发生溢出。
  • 命中可行值后忘记继续向右。
  • 循环边界写成 left ＜ right 导致漏判。

面试追问

为什么返回 answer？

循环维护 answer 为已知最大可行整数；结束时它就是分界点左侧最后一个值。

能把右边界设为 x 吗？

可以，但 x ≥ 2 时平方根一定不超过 x / 2，收紧边界更清晰。

如何返回小数精度？

可在整数结果后对小数区间继续二分，并根据误差阈值停止。

class Solution {
    public int mySqrt(int x) {
        if (x < 2) return x;

        int left = 1;
        int right = x / 2;
        int answer = 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (mid <= x / mid) {
                answer = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return answer;
    }
}

  let left = 1;
  let right = Math.floor(x / 2);
  let answer = 1;

  while (left <= right) {
    const mid = left + Math.floor((right - left) / 2);
    if (mid <= Math.floor(x / mid)) {
      answer = mid;
      left = mid + 1;
    } else {
      right = mid - 1;
    }
  }
  return answer;
};
