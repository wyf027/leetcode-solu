贴纸拼词

把贴纸上的字母剪开、重新排列，用尽可能少的贴纸拼出目标词。贴纸种类有限，但每种贴纸都可以使用无限次。

困难 记忆化搜索 动态规划 字符串计数 位掩码

PROBLEM BRIEF

无限贴纸，有限目标，求最小使用数。

给定字符串数组 stickers 和字符串 target。每次选择一张贴纸后，可使用它包含的每个字母至多一次；字母可以任意重排。

返回拼出 target 所需的最少贴纸数；若无论如何都不能完成，返回 -1。

函数签名

minStickers(stickers: string[], target: string): integer

Examples & limits

官方示例与约束

示例 1

输入：stickers = ["with","example","science"], target = "thehat"
输出：3
解释：使用 2 张 "with" 和 1 张 "example"，剪下并重排字母后可组成 "thehat"；这是最少数量。

示例 2

输入：stickers = ["notice","possible"], target = "basicbasic"
输出：-1
解释：给定贴纸中缺少完成目标所需的字母组合，因此无法组成 "basicbasic"。

约束

  • n == stickers.length
  • 1 ≤ n ≤ 50
  • 1 ≤ stickers[i].length ≤ 10
  • 1 ≤ target.length ≤ 15
  • stickers[i] 与 target 只含小写英文字母。

容易忽略的规则

  • 每种贴纸数量无限，但一次使用仍计作一张。
  • 贴纸内与目标无关的字母可以直接忽略。
  • 字母可任意重排，所以状态只关心剩余字符的数量，不关心位置顺序。
  • 如果某个目标字母从未出现在任何贴纸中，答案必为 -1。

Memoized depth-first search

记忆化搜索：只追踪还缺什么

目标长度最多 15，适合枚举“剩余需求”的状态；贴纸最多 50 张，不适合枚举无限使用次数。把搜索方向从“选了哪些贴纸”改为“还差哪些字母”，状态空间便有限了。

核心洞察

状态不是贴纸集合，而是剩余目标。 将剩余字符排序后作为键；不论此前按什么顺序选贴纸，只要剩余字符相同，后续最优答案就完全相同。
  • 先把每张贴纸压缩成 26 位字母频次，所有与目标无关的排列信息都被丢弃。
  • 设 dfs(rest) 为拼完剩余字符串 rest 所需的最少贴纸数。
  • 尝试一张贴纸后，从需求计数中扣除它能提供的字母；未被满足的字母按字母序重建为 next。
  • 转移为 dfs(rest) = 1 + min(dfs(next))；空字符串的答案为 0。

完整过程

  1. 预处理贴纸。 把每个单词转换为长度 26 的频次数组，避免在搜索中反复扫描贴纸字符。
  2. 规范化初始状态。 将 target 排序。排序不会改变需求，只会让等价状态拥有相同的备忘录键。
  3. 建立当前需求。 对 rest 计数，并令其第一个字符作为本层的锚点。
  4. 剪去无效选择。 只尝试包含锚点字符的贴纸。任意可行解都必须有某张贴纸覆盖该字符，而贴纸使用顺序可交换，因此可把那张贴纸提前到当前层。
  5. 生成下一状态。 对每个字母保留 max(需求数 - 贴纸提供数, 0) 个，并按字母序拼接。
  6. 递归并缓存。 若子状态可达，就用 1 + 子答案 更新最小值；所有选择都不可达时记录 -1。

正确性证明

引理 1 · 状态充分贴纸内字母可任意重排，所以从某一时刻开始，未来可行性只由各字母尚缺数量决定，与此前贴纸顺序无关。排序后的剩余串准确表示这些数量。
引理 2 · 锚点剪枝安全若 rest 非空，任何完成它的贴纸序列都至少有一张包含首字符。把这张贴纸交换到序列开头，不改变贴纸总数或最终能提供的字母。
引理 3 · 转移完备算法遍历所有包含锚点的贴纸。根据引理 2，至少存在一个最优解的第一张贴纸属于这个集合；扣除该贴纸后，递归求得其余需求的最优值。
定理 · 返回值最优空状态返回 0。对任意非空状态，算法在所有可能的最优首步中取 1 + dfs(next) 的最小值，因此由状态规模归纳可知结果是最少贴纸数；若不存在可达转移则正确返回 -1。

边界与复杂度

  • 空子状态：递归过程中一旦剩余串为空，立即返回 0。
  • 完全不可达：某个所需字母不在任何贴纸中时，不会出现可达子状态，最终返回 -1。
  • 重复字母：频次相减自然处理同一字母的多份需求，不可用集合代替计数。
  • 无贡献贴纸：锚点剪枝会跳过不含当前首字符的贴纸，也避免生成完全不变的状态。

设贴纸数为 N，贴纸最大长度为 L，目标长度为 T，不同剩余状态数为 S，其中 S ≤ 2^T。预处理为 O(NL)；搜索时间为 O(S · N · (T + 26))，空间为 O(26N + S·T)（字符串键会保存剩余字符）。

import java.util.*;

class Solution {
    private int[][] counts;
    private Map<String, Integer> memo;

    public int minStickers(String[] stickers, String target) {
        counts = new int[stickers.length][26];
        for (int i = 0; i < stickers.length; i++) {
            for (char ch : stickers[i].toCharArray()) {
                counts[i][ch - 'a']++;
            }
        }

        char[] chars = target.toCharArray();
        Arrays.sort(chars);
        memo = new HashMap<>();
        memo.put("", 0);
        return dfs(new String(chars));
    }

    private int dfs(String rest) {
        if (memo.containsKey(rest)) {
            return memo.get(rest);
        }

        int[] need = new int[26];
        for (char ch : rest.toCharArray()) {
            need[ch - 'a']++;
        }

        int best = Integer.MAX_VALUE;
        int anchor = rest.charAt(0) - 'a';

        for (int[] sticker : counts) {
            if (sticker[anchor] == 0) continue;

            StringBuilder next = new StringBuilder();
            for (int c = 0; c < 26; c++) {
                int missing = Math.max(0, need[c] - sticker[c]);
                for (int k = 0; k < missing; k++) {
                    next.append((char) ('a' + c));
                }
            }

            int sub = dfs(next.toString());
            if (sub != -1) {
                best = Math.min(best, sub + 1);
            }
        }

        int answer = best == Integer.MAX_VALUE ? -1 : best;
        memo.put(rest, answer);
        return answer;
    }
}

/**
 * @param {string[]} stickers
 * @param {string} target
 * @return {number}
 */
var minStickers = function(stickers, target) {
    const counts = stickers.map((word) => {
        const freq = Array(26).fill(0);
        for (const ch of word) freq[ch.charCodeAt(0) - 97]++;
        return freq;
    });

    const start = [...target].sort().join("");
    const memo = new Map([["", 0]]);

    const dfs = (rest) => {
        if (memo.has(rest)) return memo.get(rest);

        const need = Array(26).fill(0);
        for (const ch of rest) need[ch.charCodeAt(0) - 97]++;

        let best = Infinity;
        const anchor = rest.charCodeAt(0) - 97;

        for (const sticker of counts) {
            if (sticker[anchor] === 0) continue;

            const parts = [];
            for (let c = 0; c < 26; c++) {
                const missing = Math.max(0, need[c] - sticker[c]);
                if (missing > 0) parts.push(String.fromCharCode(97 + c).repeat(missing));
            }

            const sub = dfs(parts.join(""));
            if (sub !== -1) best = Math.min(best, sub + 1);
        }

        const answer = best === Infinity ? -1 : best;
        memo.set(rest, answer);
        return answer;
    };

    return dfs(start);
};

Python

from collections import Counter
from functools import cache
from typing import List


class Solution:
    def minStickers(self, stickers: List[str], target: str) -> int:
        sticker_counts = [Counter(word) for word in stickers]

        @cache
        def dfs(rest: str) -> int:
            if not rest:
                return 0

            need = Counter(rest)
            anchor = rest[0]
            best = float("inf")

            for sticker in sticker_counts:
                if sticker[anchor] == 0:
                    continue

                next_rest = "".join(
                    ch * max(0, need[ch] - sticker[ch])
                    for ch in sorted(need)
                )
                sub = dfs(next_rest)
                if sub != -1:
                    best = min(best, sub + 1)

            return -1 if best == float("inf") else best

        return dfs("".join(sorted(target)))

#include <algorithm>
#include <array>
#include <climits>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
private:
    vector<array<int, 26>> counts;
    unordered_map<string, int> memo;

    int dfs(const string& rest) {
        auto found = memo.find(rest);
        if (found != memo.end()) return found->second;

        array<int, 26> need{};
        for (char ch : rest) need[ch - 'a']++;

        int best = INT_MAX;
        int anchor = rest[0] - 'a';

        for (const auto& sticker : counts) {
            if (sticker[anchor] == 0) continue;

            string next;
            for (int c = 0; c < 26; c++) {
                int missing = max(0, need[c] - sticker[c]);
                next.append(missing, static_cast<char>('a' + c));
            }

            int sub = dfs(next);
            if (sub != -1) best = min(best, sub + 1);
        }

        int answer = best == INT_MAX ? -1 : best;
        memo[rest] = answer;
        return answer;
    }

public:
    int minStickers(vector<string>& stickers, string target) {
        counts.resize(stickers.size());
        for (int i = 0; i < static_cast<int>(stickers.size()); i++) {
            counts[i].fill(0);
            for (char ch : stickers[i]) counts[i][ch - 'a']++;
        }

        sort(target.begin(), target.end());
        memo[""] = 0;
        return dfs(target);
    }
};

替代方案

位掩码动态规划：用目标串的每个位置作为一位，mask 表示哪些位置已被覆盖。对每个状态尝试每张贴纸，并贪心匹配尚未覆盖的相同字母，更新新掩码。状态数固定为 2^T，时间约为 O(2^T · N · (L + T))。它避免字符串键，适合目标长度很小；但重复字母的匹配过程更绕，代码直观性不如剩余计数 DFS。

纯回溯：可以通过去除被其他贴纸完全支配的贴纸、全局上界剪枝来提速，但缺少记忆化时仍会反复求解相同的剩余需求，不建议作为主方案。

面试追问

为什么能固定首字符剪枝？因为贴纸的使用顺序不影响最终字符总量；任意完整方案里负责覆盖首字符的贴纸都可以交换到第一步。
如何预先发现必定无解？合并所有贴纸出现过的字符集合，若目标含集合外字符即可直接返回 -1；这只是提前失败，不改变主算法。
贴纸有使用上限怎么办？状态必须额外记录各类贴纸的剩余数量，状态空间会显著扩大；若数量小，可用多维 DP 或带库存向量的搜索。
目标长度扩大到 100 呢？2^T 状态不再可行，需要利用字符种类少、整数规划、启发式搜索或问题数据的额外结构，通常不存在同样简单的精确解法。

常见错误

  • 把贴纸当作只能使用一次，错误地做 0/1 背包。
  • 用字符集合代替频次，无法处理 target 中的重复字母。
  • 备忘录键未规范化，使 aeh 与 hea 被当成两个状态。
  • 生成下一状态时保留负数，或没有用 max(0, need - supply) 截断。
  • 不可达子状态返回 -1 后仍执行 sub + 1 并参与最小值比较。
  • 不做锚点剪枝，尝试完全无贡献的贴纸，可能递归回同一个状态。
