04 / 独立题解

准备好后再展开 SQL 和各语言参考。

核心洞察 · 每行独立格式化

这是一元投影：日期语义不变，只改变展示形式。MySQL 的 DATE_FORMAT 已提供星期、月份、无前导零的日和四位年的格式指令，无需连接、聚合、排序或自己推算星期。

完整过程

  1. 从 Days 读取一行 day。
  2. 用 %W 取英文星期全称，%M 取月份全称，%e 取无前导零的日，%Y 取四位年。
  3. 按 %W, %M %e, %Y 插入字面逗号和空格。
  4. 结果别名设为 day，对全部输入行重复。

例如 2021-08-09 的四部分是 Monday、August、9、2021，组合成 Monday, August 9, 2021。

正确性

对任意一行，四个格式指令分别给出同一日期所要求的四个字段；格式串的字面字符保证字段顺序和标点准确。查询没有过滤或聚合，因此每个输入行恰好产生一行输出；别名保证输出列契约一致。逐行成立即整个结果表成立，且任意顺序符合要求。

边界与环境

单数字日期应输出 9 而非 09；闰日由日期类型与内置日历逻辑处理；空表自然得到空结果。MySQL 月份和星期的语言受 lc_time_names 控制，题解按英文环境 en_US 说明；实际环境若更改了语言，应在会话层明确设置。NULL 与非法日期不作为题面新增假设，生产数据需另定契约。

复杂度

n 行输入，每个固定长度日期的格式化为 O(1)，总时间 O(n)。逐行计算额外空间 O(1)，若物化整个输出则占 O(n)；此处不计数据库内部执行实现差异。

替代方案

可用 CONCAT、DAYNAME、MONTHNAME、DAYOFMONTH、YEAR 拼接，语义相同但标点更容易出错。其他数据库应使用各自格式函数，不能直接复用 MySQL 的百分号格式串。为显示格式而在应用层重新实现日历计算没有必要。

常见错误

  • 使用 %d 得到补零日期；%m 得到数字月份；%w 得到星期数字。
  • 漏逗号后空格，或漏 AS day。
  • 用 DISTINCT、GROUP BY、ORDER BY 增加不需要的处理。
  • 参考代码依赖系统默认语言或本地时区，导致英文名或日期偏移。

面试追问

如果要按日期排序？按原始 DATE 排序后再展示，不按英文字符串排序。如果多语言展示？明确 locale 契约。如果输入改成带时区的时间戳？先确定目标时区和当地日期，再格式化。格式化后的列能用于日期范围索引吗？应在原始日期列做过滤，展示转换留在投影阶段。

完整代码

MySQL 是本题正式数据库解法。以下 Java、JavaScript、Python、C++ 仅为本地语义参考：命令行参数逐个传入 ISO 日期，逐行输出字符串，不冒充平台提交签名。参考代码面向合法的公历 ISO 日期。

MySQL · 正式提交

SELECT DATE_FORMAT(day, '%W, %M %e, %Y') AS day
FROM Days;

Java · 本地语义参考

import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.util.Locale;

public class Main {
    static String convert(String day) {
        return LocalDate.parse(day).format(
            DateTimeFormatter.ofPattern("EEEE, MMMM d, uuuu", Locale.ENGLISH));
    }
    public static void main(String[] args) {
        for (String day : args) System.out.println(convert(day));
    }
}

JavaScript · 本地语义参考

// Node.js: node main.js 2022-04-12 2021-08-09
function convert(day) {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(day)) throw Error('Invalid date');
  const date = new Date(day + 'T00:00:00Z');
  if (Number.isNaN(date.getTime()) || date.toISOString().slice(0, 10) !== day)
    throw Error('Invalid date');
  const parts = new Intl.DateTimeFormat('en-US', {
    weekday: 'long', month: 'long', day: 'numeric', year: 'numeric',
    timeZone: 'UTC'
  }).formatToParts(date);
  const get = type => parts.find(p => p.type === type).value;
  return `${get('weekday')}, ${get('month')} ${get('day')}, ${get('year').padStart(4, '0')}`;
}
for (const day of process.argv.slice(2)) console.log(convert(day));

Python · 本地语义参考

from datetime import date
import sys

WEEK = ("Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday")
MONTH = ("January", "February", "March", "April", "May", "June",
         "July", "August", "September", "October", "November", "December")

def convert(day: str) -> str:
    d = date.fromisoformat(day)
    return f"{WEEK[d.weekday()]}, {MONTH[d.month - 1]} {d.day}, {d.year:04d}"

if __name__ == "__main__":
    for day in sys.argv[1:]:
        print(convert(day))

C++ · 本地语义参考（C++20）

#include <chrono>
#include <iomanip>
#include <iostream>
#include <sstream>
#include <stdexcept>
#include <string>
using namespace std;

string convert(const string& s) {
    if (s.size() != 10 || s[4] != '-' || s[7] != '-')
        throw invalid_argument("Invalid date");
    for (int i = 0; i < 10; ++i)
        if (i != 4 && i != 7 && (s[i] < '0' || s[i] > '9'))
            throw invalid_argument("Invalid date");
    int y = stoi(s.substr(0, 4));
    unsigned m = stoi(s.substr(5, 2)), d = stoi(s.substr(8, 2));
    chrono::year_month_day value{chrono::year{y}, chrono::month{m}, chrono::day{d}};
    if (y < 1 || !value.ok()) throw invalid_argument("Invalid date");
    const char* weeks[] = {"Sunday", "Monday", "Tuesday", "Wednesday",
                          "Thursday", "Friday", "Saturday"};
    const char* months[] = {"January", "February", "March", "April", "May", "June",
                           "July", "August", "September", "October", "November", "December"};
    unsigned w = chrono::weekday{chrono::sys_days{value}}.c_encoding();
    ostringstream out;
    out << weeks[w] << ", " << months[m - 1] << ' ' << d << ", "
        << setfill('0') << setw(4) << y;
    return out.str();
}
int main(int argc, char** argv) {
    try {
        for (int i = 1; i < argc; ++i) cout << convert(argv[i]) << '\n';
    } catch (const exception& e) {
        cerr << e.what() << '\n';
        return 1;
    }
}
