2249. 统计圆内格点数目

Count Lattice Points Inside a Circle

网格上的圆可以重叠。你的任务是数出被它们覆盖的整数坐标点。

先读题，再动手观察；完整算法与四语言代码位于底部折叠题解。

01 / 题目

输入二维整数数组 circles。每项 circles[i] = [x_i, y_i, r_i] 表示圆心为 (x_i, y_i)、半径为 r_i 的圆。返回至少落在一个圆内的不同格点数量。

格点的两个坐标都必须是整数；圆周上的点也计入；同一个点被多个圆覆盖时只算一次。

官方示例 1

输入：circles = [[2,2,1]]
输出：5

五个点是 (1,2)、(2,1)、(2,2)、(2,3)、(3,2)。对角处的 (1,1)、(1,3) 不在圆内。

官方示例 2

输入：circles = [[2,2,2],[3,4,1]]
输出：16

两个圆合计覆盖 16 个不同格点，其中包括 (0,2)、(2,0)、(2,4)、(3,2)、(4,4)。

完整约束

  • 1 ≤ circles.length ≤ 200
  • circles[i].length == 3
  • 1 ≤ x_i, y_i ≤ 100
  • 1 ≤ r_i ≤ min(x_i, y_i)

04 / 独立题解
准备好后再展开：推导、证明与四语言实现。




核心洞察：覆盖是一个集合


一个圆内的所有格点都在它的外接正方形中。枚举正方形内的整数点，用 (x-cx)² + (y-cy)² ≤ r² 判断是否落在圆内，再用布尔表标记；只有首次标记才增加答案。这样既包括圆周，也自然处理重叠。


完整过程
  1. 建立 201 × 201 的布尔表 seen，答案从 0 开始。
  2. 对每个圆 [cx, cy, r]，令 x 遍历 [cx-r, cx+r]，y 遍历 [cy-r, cy+r]，两端都取到。
  3. 计算到圆心的距离平方。大于 r*r 时跳过。
  4. 若在圆内且 seen[x][y] 为假，则标记为真并加一；否则不增加。
  5. 处理完所有圆，返回答案。
示例 2：第一个圆有 13 个格点；第二个圆有 5 个，其中 (2,4)、(3,3) 已被覆盖，因此只新增 3 个，答案为 16。


为什么布尔表只要 201 × 201？
由 r ≤ min(cx,cy) 得到最小坐标不小于 0；又因为圆心和半径都不超过 100，最大坐标不超过 200。下标包含 0 和 200，所以需要 201 个位置。两个偏移量的平方和不超过 20000，四份代码在题目范围内可安全使用各自的整数或 Number 运算。


正确性证明
不多算：只有满足圆内判定的点会被标记，因此每个计入点都属于至少一个圆。
不漏算：任何属于某圆的格点，其横纵坐标必在该圆的外接正方形范围内；遍历该圆时一定会遇到它并通过判定。
不重复：处理任意数量的候选点后，seen 恰好标记此前遇到的圆内格点，答案等于真值数量。新点将真值数量和答案同时加一，已标记点不改变二者，此不变量始终成立。结合前两点，最终答案恰为圆覆盖的不同格点数量。


复杂度
设圆数为 n，最大半径为 R，坐标表边长为 M=201。时间为 O(M² + Σ(2r_i+1)²)，可写为 O(M²+nR²)；辅助空间为 O(M²)。在本题固定坐标范围下，空间有常数上界。每个圆最多检查 40401 个点，200 个圆最多约 808 万次判定。


边界与常见错误
  • 圆周用 ≤，不能写成 <。
  • 循环上界要包含 cx+r、cy+r。
  • 不能直接相加每个圆的点数。
  • 坐标可能是 0 或 200，表长不是 200。
  • 半径平方不要误写为半径。
  • 避免开平方带来的浮点边界误差。
  • Python 不要用重复同一个行对象的二维列表初始化方式。
替代方案
全局枚举：遍历 0…200 的所有点，对每个点检查圆列表，首次命中就停止。时间 O(M²n)，空间 O(1)，实现同样直接。
哈希集合：按圆枚举并插入坐标二元组或无冲突编码，适合坐标稀疏或范围较大时；期望时间 O(nR²)，空间 O(U)，U 为覆盖点数。可视化用集合保存已覆盖点，等价于代码中的布尔表。


面试追问
  • 允许负坐标怎么办？使用坐标偏移表或二元组集合，不直接用负数作数组下标。
  • 半径达到 10⁹ 呢？逐点枚举不再合适；可按整数横坐标求每个圆的纵向整数区间并合并。仍需关注扫描行总数，巨大跨度要进一步分析结构，不能声称简单区间合并就足够。
  • 求“恰好被一个圆覆盖”呢？把布尔表替换为覆盖次数表，所有圆处理完后统计次数为 1 的位置。

Java
class Solution {
    public int countLatticePoints(int[][] circles) {
        boolean[][] seen = new boolean[201][201];
        int answer = 0;
        for (int[] c : circles) {
            int cx = c[0], cy = c[1], r = c[2];
            for (int x = cx - r; x <= cx + r; x++) {
                for (int y = cy - r; y <= cy + r; y++) {
                    int dx = x - cx, dy = y - cy;
                    if (dx * dx + dy * dy <= r * r && !seen[x][y]) {
                        seen[x][y] = true;
                        answer++;
                    }
                }
            }
        }
        return answer;
    }
}

from typing import List

class Solution:
    def countLatticePoints(self, circles: List[List[int]]) -> int:
        seen = [[False] * 201 for _ in range(201)]
        answer = 0
        for cx, cy, r in circles:
            for x in range(cx - r, cx + r + 1):
                for y in range(cy - r, cy + r + 1):
                    dx, dy = x - cx, y - cy
                    if dx * dx + dy * dy <= r * r and not seen[x][y]:
                        seen[x][y] = True
                        answer += 1
        return answer
