关键连接

一张连通的服务器网络里，有些连接承担着不可替代的连通职责。你的任务是找出：删除后会让部分服务器彼此不可达的所有连接。

01 · Problem

题意与输入输出

先把问题本身钉牢，再进入算法机制。

有 n 台服务器，编号为 0 到 n - 1。无向边数组 connections 中，connections[i] = [aᵢ, bᵢ] 表示服务器 aᵢ 与 bᵢ 直接相连。初始网络保证连通。

若删除某条连接后，网络中出现两台服务器无法再互相到达，则这条连接是关键连接。请按任意顺序返回全部关键连接；同一条边的两个端点顺序也可以互换。

函数形式：criticalConnections(n, connections) → number[][]

示例 1

输入：n = 4,
connections = [[0,1],[1,2],[2,0],[1,3]]
输出：[[1,3]]
解释：[[3,1]] 同样被接受。

示例 2

输入：n = 2,
connections = [[0,1]]
输出：[[0,1]]

约束

  • 2 ≤ n ≤ 10⁵
  • n - 1 ≤ connections.length ≤ 10⁵
  • 0 ≤ aᵢ, bᵢ ≤ n - 1，且 aᵢ ≠ bᵢ
  • 不存在重复连接，且任意服务器可直接或间接到达其他服务器。

03 · Solution

准备好看完整题解了吗？

展开后包含推导、证明、复杂度、四语言代码与面试追问。

Tarjan 桥算法：用 low 值识别断点边

核心洞察

对无向图做一次 DFS。令 disc[u] 为首次访问 u 的时间，low[u] 为从 u 的 DFS 子树出发，允许经过若干树边并至多一条返祖边所能到达的最小 disc。

树边 (u,v) 是桥 ⇔ low[v] > disc[u]

如果 low[v] ≤ disc[u]，说明 v 的子树存在另一条路回到 u 或更早祖先，删掉 (u,v) 仍可绕行；严格大于时没有这种替代路线。

完整过程

  1. 建立无向邻接表，并给每条边一个唯一编号。
  2. DFS 首次到达 u 时令 disc[u] = low[u] = timer++。
  3. 遇到父边编号就跳过；未访问邻点 v 则递归遍历。
  4. 回溯后以 low[v] 更新 low[u]，再检查桥条件。
  5. 遇到已访问邻点时，以 disc[v] 更新 low[u]。

正确性证明

引理：DFS 树边 (u,v) 删除后仍有替代路径，当且仅当 v 的子树中存在一条返祖边连接到 u 或 u 的祖先。

充分性：若存在该返祖边，从 v 的子树沿它回到 u 或祖先，再沿 DFS 树路径可绕过 (u,v)，所以该边不是桥。

必要性：无向图 DFS 中，跨出 v 子树且不经过父边的任何路径，必通过连接到某个祖先的返祖边；若没有，子树与外部只剩 (u,v) 一条通路。

对应数值：存在上述返祖边等价于 low[v] ≤ disc[u]。因此 low[v] > disc[u] 恰好表示没有替代路径，算法返回且仅返回所有桥。

复杂度

  • 时间：O(n + m)，每个节点和每条无向边只处理常数次。
  • 空间：O(n + m)，邻接表、状态数组及最坏 O(n) 的 DFS 栈。

边界情况

  • 只有两个节点：唯一边必为桥。
  • 所有节点构成一个环：没有桥。
  • 图是一棵树：每条边都是桥。
  • 长链会带来深递归；语言栈较小时应使用显式栈。

替代方案

逐边删除后再做连通性搜索需要 O(m(n+m))，在 10⁵ 规模下不可行。并查集适合增量合并，却不擅长直接回答“删除某条边后的连通性”。求边双连通分量也能导出桥，本质仍依赖相同的 DFS low-link 信息。

常见错误

  • 把更新写成 low[u] = min(low[u], low[v]) 处理返祖边；返祖边应使用 disc[v]。
  • 用“父节点”而非“父边编号”跳过边，在允许平行边的扩展问题中会错。
  • 桥条件写成 ≥；必须严格 >。
  • 计时器未全局递增，导致时间戳失真。

面试追问

  • 如何求割点？ 对非根节点检查是否存在子节点 v 满足 low[v] ≥ disc[u]；DFS 根需至少两个子树。
  • 图不保证连通怎么办？ 从每个尚未访问的节点启动 DFS，形成 DFS 森林。
  • 如何避免递归爆栈？ 显式保存节点、父边、邻接迭代位置，并在退出帧时完成 low 回传。
  • 动态图持续删边呢？ 单次 Tarjan 不够，需要离线倒序、分治回滚并查集或更复杂的动态连通结构，取决于操作模型。

class Solution {
    private List<int[]>[] graph;
    private int[] disc, low;
    private int timer;
    private List<List<Integer>> bridges;

    public List<List<Integer>> criticalConnections(
            int n, List<List<Integer>> connections) {
        graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int id = 0; id < connections.size(); id++) {
            int u = connections.get(id).get(0);
            int v = connections.get(id).get(1);
            graph[u].add(new int[]{v, id});
            graph[v].add(new int[]{u, id});
        }
        disc = new int[n];
        low = new int[n];
        Arrays.fill(disc, -1);
        bridges = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if (disc[i] == -1) dfs(i, -1);
        }
        return bridges;
    }

    private void dfs(int u, int parentEdge) {
        disc[u] = low[u] = timer++;
        for (int[] edge : graph[u]) {
            int v = edge[0], id = edge[1];
            if (id == parentEdge) continue;
            if (disc[v] == -1) {
                dfs(v, id);
                low[u] = Math.min(low[u], low[v]);
                if (low[v] > disc[u]) {
                    bridges.add(Arrays.asList(u, v));
                }
            } else {
                low[u] = Math.min(low[u], disc[v]);
            }
        }
    }
}

var criticalConnections = function(n, connections) {
    const graph = Array.from({ length: n }, () => []);
    connections.forEach(([u, v], id) => {
        graph[u].push([v, id]);
        graph[v].push([u, id]);
    });

    const disc = new Int32Array(n);
    disc.fill(-1);
    const low = new Int32Array(n);
    const answer = [];
    let timer = 0;

    for (let root = 0; root < n; root++) {
        if (disc[root] !== -1) continue;
        disc[root] = low[root] = timer++;
        const stack = [{ u: root, parent: -1, parentEdge: -1, next: 0 }];

        while (stack.length) {
            const frame = stack[stack.length - 1];
            if (frame.next < graph[frame.u].length) {
                const [v, edgeId] = graph[frame.u][frame.next++];
                if (edgeId === frame.parentEdge) continue;
                if (disc[v] === -1) {
                    disc[v] = low[v] = timer++;
                    stack.push({ u: v, parent: frame.u,
                                 parentEdge: edgeId, next: 0 });
                } else {
                    low[frame.u] = Math.min(low[frame.u], disc[v]);
                }
            } else {
                stack.pop();
                if (frame.parent !== -1) {
                    const p = frame.parent;
                    low[p] = Math.min(low[p], low[frame.u]);
                    if (low[frame.u] > disc[p]) answer.push([p, frame.u]);
                }
            }
        }
    }
    return answer;
};
from typing import List
import sys

class Solution:
    def criticalConnections(
        self, n: int, connections: List[List[int]]
    ) -> List[List[int]]:
        sys.setrecursionlimit(max(1_000_000, n * 2 + 10))
        graph = [[] for _ in range(n)]
        for edge_id, (u, v) in enumerate(connections):
            graph[u].append((v, edge_id))
            graph[v].append((u, edge_id))

        disc = [-1] * n
        low = [0] * n
        bridges = []
        timer = 0

        def dfs(u: int, parent_edge: int) -> None:
            nonlocal timer
            disc[u] = low[u] = timer
            timer += 1
            for v, edge_id in graph[u]:
                if edge_id == parent_edge:
                    continue
                if disc[v] == -1:
                    dfs(v, edge_id)
                    low[u] = min(low[u], low[v])
                    if low[v] > disc[u]:
                        bridges.append([u, v])
                else:
                    low[u] = min(low[u], disc[v])

        for node in range(n):
            if disc[node] == -1:
                dfs(node, -1)
        return bridges
class Solution {
    vector<vector<pair<int, int>>> graph;
    vector<int> disc, low;
    vector<vector<int>> bridges;
    int timer = 0;

    void dfs(int u, int parentEdge) {
        disc[u] = low[u] = timer++;
        for (auto [v, edgeId] : graph[u]) {
            if (edgeId == parentEdge) continue;
            if (disc[v] == -1) {
                dfs(v, edgeId);
                low[u] = min(low[u], low[v]);
                if (low[v] > disc[u]) bridges.push_back({u, v});
            } else {
                low[u] = min(low[u], disc[v]);
            }
        }
    }

public:
    vector<vector<int>> criticalConnections(
        int n, vector<vector<int>>& connections) {
        graph.assign(n, {});
        for (int id = 0; id < (int)connections.size(); id++) {
            int u = connections[id][0], v = connections[id][1];
            graph[u].push_back({v, id});
            graph[v].push_back({u, id});
        }
        disc.assign(n, -1);
        low.resize(n);
        for (int i = 0; i < n; i++) {
            if (disc[i] == -1) dfs(i, -1);
        }
        return bridges;
    }
};
