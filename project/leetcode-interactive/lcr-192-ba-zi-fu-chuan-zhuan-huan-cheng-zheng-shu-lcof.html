LCR 192MEDIUMSTRING · STATE MACHINE

PARSER CONTROL ROOM / 10 MIN REVIEW

把字符串转换成整数
atoi 状态机控制台

字符只能排队经过四个状态：跳过前导空格、读取一次符号、累积连续数字、终止。任何不符合当前状态规则的字符都会让解析立即停下。

记忆口令

空格 → 符号 → 数字 → 停止

没有数字返回 0；数值越界收紧到 32 位有符号整数边界。

OFFICIAL RULE, PARAPHRASED

题意

实现 myAtoi(str)。先忽略前导空格，再读取一个可选的 + 或 -，接着读取连续十进制数字；遇到首个非数字就停止。若没读到数字，返回 0。结果限制在 [−2147483648, 2147483647]。

输入由空格、英文字母、数字、正负号和小数点组成。本页使用 ␠ 显示普通空格，避免把空白字符看漏。题目保证 0 <= s.length <= 200，且只需忽略普通空格 ' '。

SOLUTION VAULT

完整题解

核心洞察

解析的合法前缀只有“空格* 符号? 数字+”。有限状态机使每一位字符只被访问一次，且不必切片或回退。

完整过程

  1. LEADING 中持续跳过 ␠；遇到符号进入 SIGN，遇到数字进入 NUMBER，其余结束。
  2. SIGN 只接受第一位数字，否则结束。
  3. NUMBER 用 value = value × 10 + digit 累积；一旦非数字，结束。
  4. 每次累积后按符号截断到边界。

边界

空串、全空格、只有符号、双符号、符号后空格都返回 0。前导零无碍；数字后字母或小数点不是错误，只是停止点。

复杂度

时间 O(n)，额外空间 O(1)。遇到非法字符即可提前结束。

替代方案

正则可抽取候选前缀，但边界截断与“只允许一个符号”的规则仍需单独处理；手写状态机的控制流更透明。

面试追问

若要求不使用 64 位整数，可在乘十前比较 value > (limit - digit) / 10，提前判断溢出。

常见错误

不要用 parseInt 代替实现；它的规则不是本题契约。也不要跳过中间空格或在数字后继续寻找下一段数字。 

/** @param {string} str @return {number} */
var myAtoi = function (str) {
  let i = 0, sign = 1, value = 0;
  while (str[i] === " ") i++;
  if (str[i] === "+" || str[i] === "-") sign = str[i++] === "-" ? -1 : 1;
  while (i < str.length && /\d/.test(str[i])) {
    value = value * 10 + (str.charCodeAt(i++) - 48);
    if (sign * value > 2147483647) return 2147483647;
    if (sign * value < -2147483648) return -2147483648;
  }
  return sign * value;
};
class Solution:
    def myAtoi(self, str: str) -> int:

        if i < len(str) and str[i] in '+-':

        while i < len(str) and str[i].isdigit():
            value = value * 10 + int(str[i]); i += 1
            if sign * value > 2147483647: return 2147483647
            if sign * value < -2147483648: return -2147483648

class Solution {
  public int myAtoi(String str) {
    int i = 0, sign = 1; long value = 0;
    while (i < str.length() && str.charAt(i) == ' ') i++;
    if (i < str.length() && "+-".indexOf(str.charAt(i)) >= 0)
      sign = str.charAt(i++) == '-' ? -1 : 1;
    while (i < str.length() && Character.isDigit(str.charAt(i))) {
      value = value * 10 + str.charAt(i++) - '0';
      if (sign * value > Integer.MAX_VALUE) return Integer.MAX_VALUE;
      if (sign * value < Integer.MIN_VALUE) return Integer.MIN_VALUE;
    }
    return (int) (sign * value);
  }
}
