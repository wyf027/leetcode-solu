和为 K 的子数组

不必枚举每个子数组。把当前位置的前缀和记为 sum，那么任何此前等于 sum − k 的前缀都能和当前组成一个答案。

前缀和

sum 表示从 0 到当前元素的累计和。

补数查询

查询 sum − k 出现了几次。

频次而非下标

相同前缀可对应多个不同子数组。

Mechanism / sum − k

一步一笔的前缀账本

每一步只做一次哈希查询与写入

初始状态

先登记前缀和 0

空前缀的出现次数为 1，这样从下标 0 开始的合法子数组也能被统计。

当前 sum0
答案 count0

数组与当前扫描位置

0 / 0
本轮查询：map[sum − k] = map[0 − k]

频次哈希表

prefix sum → count
关键顺序：先查询 sum − k，后将当前 sum 写入表。否则会把空长度区间误算为答案。

Reasoning / 等式变形

子数组和可以变成两个前缀和的差

等式

若区间 (j, i] 的和为 k，则 prefix[i] − prefix[j] = k，即 prefix[j] = prefix[i] − k。

为什么存频次

同一前缀和可在不同 j 出现。每一个 j 都对应一个不同起点，因此要将出现次数全部加到答案。

初始化 map[0] = 1

当当前 sum 恰好为 k，所需前缀为 0；它代表数组开头之前的空前缀。

算法步骤

  1. 设 map[0] = 1，sum = answer = 0。
  2. 读入 num，更新 sum += num。
  3. 将 map[sum − k] 的频次加入 answer。
  4. 执行 map[sum]++，进入下一轮。

边界与复杂度

  • 负数使双指针不再可靠，前缀和方案仍适用。
  • k = 0 时，相同前缀和之间的区间就是答案。
  • 时间 O(n)，哈希表空间 O(n)。
  • 不要只记最后一个下标，会漏掉重复前缀。

import java.util.*;
class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> frequency = new HashMap<>();
        frequency.put(0, 1);
        int sum = 0, answer = 0;
        for (int num : nums) {
            sum += num;
            answer += frequency.getOrDefault(sum - k, 0);
            frequency.put(sum, frequency.getOrDefault(sum, 0) + 1);
        }
        return answer;
    }
}
var subarraySum = function (nums, k) {
  const frequency = new Map([[0, 1]]);
  let sum = 0, answer = 0;
  for (const num of nums) {
    sum += num;
    answer += frequency.get(sum - k) || 0;
    frequency.set(sum, (frequency.get(sum) || 0) + 1);
  }
  return answer;
};
from collections import defaultdict

class Solution:
    def subarraySum(self, nums: list[int], k: int) -> int:
        frequency = defaultdict(int, {0: 1})
        total = answer = 0
        for num in nums:
            total += num
            answer += frequency[total - k]
            frequency[total] += 1
        return answer
#include <vector>
#include <unordered_map>
using namespace std;
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> frequency{{0, 1}};
        int sum = 0, answer = 0;
        for (int num : nums) {
            sum += num;
            answer += frequency[sum - k];
            ++frequency[sum];
        }
        return answer;
    }
};

复杂度：遍历一次数组，时间 O(n)，频次表最多保存 n+1 个不同前缀和，空间 O(n)。
