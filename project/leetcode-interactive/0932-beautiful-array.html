LeetCode 932 · Divide & Conquer

漂亮数组

Beautiful Array

MEDIUM数组数学分治

题目

给定整数 n，构造并返回任意一个由 1..n 组成的排列 nums。它必须满足：任取 0 ≤ i < j < n，在两者之间不存在下标 k 使 2 × nums[k] = nums[i] + nums[j]。

换句话说，数组中任何一个位于另外两个元素之间的数，都不能成为它们的算术平均数。题目保证答案存在。

示例 1
输入：n = 4 输出：[2,1,4,3]
示例 2
输入：n = 5 输出：[3,1,2,5,4]

函数参数：beautifulArray(n: integer) → integer[]

约束：1 ≤ n ≤ 1000

分治实验室

观察一个漂亮数组如何通过“奇数映射”和“偶数映射”逐轮扩张。先探索规律，再决定是否查看完整题解。

准备好揭开构造规律了吗？

下面包含完整证明、复杂度与四种语言实现。

题解：奇偶分治构造

核心洞察

若数组 A 已经漂亮，那么对每个元素做相同的正仿射变换，元素间“不构成中点”的性质仍然成立。用 2x-1 把 A 映射成奇数，用 2x 映射成偶数，再把两段拼接。跨段元素奇偶性不同，它们的和是奇数，不可能等于偶数 2×nums[k]。

完整过程

  1. 从唯一排列 [1] 开始。
  2. 对当前数组依次生成不超过 n 的 2x-1，形成奇数段。
  3. 再生成不超过 n 的 2x，形成偶数段。
  4. 拼接两段并重复，直到得到 n 个数。

正确性证明

归纳基础：[1] 显然漂亮。

同段：若映射后出现 2f(A[k])=f(A[i])+f(A[j])，消去仿射变换即得到原数组中的同一等式，与归纳假设矛盾。

跨段：一个端点来自奇数段，另一个来自偶数段，二者之和为奇数；而任意 2×nums[k] 为偶数，因此等式不成立。两段拼接后仍漂亮，并且恰好覆盖 1..n，故算法正确。

边界与复杂度

  • n=1 时直接返回 [1]。
  • 每轮规模至少接近翻倍，最终保存 n 个元素。
  • 时间复杂度 O(n log n)（逐轮构造）；空间复杂度 O(n)。

替代方案

可使用记忆化递归：长度为 n 的答案由长度 (n+1)/2 的奇数子问题与长度 n/2 的偶数子问题映射而来，同样是分治思想。迭代版更短，也避免递归与缓存管理。

面试追问

  • 为什么必须把奇数段与偶数段完整分开？因为这样跨段端点之和恒为奇数。
  • 是否只有一个答案？不是；题目允许返回任意合法排列。
  • 能否做到线性时间？可以从二进制位反转等视角生成相关顺序，但迭代扩张更容易证明与实现；本实现总工作量按轮累计为 O(n log n)。

常见错误

  • 只生成一次奇偶映射，未循环到长度 n。
  • 忘记过滤大于 n 的值。
  • 把偶数段放入奇数段内部，破坏跨段的奇偶隔离。
  • 误把条件理解成数组中完全不能出现三项等差数列；限制还要求中间值的下标位于两个端点之间。

Java

class Solution {
    public int[] beautifulArray(int n) {
        int[] a = {1};
        while (a.length < n) {
            int[] next = new int[n];
            int size = 0;
            for (int x : a) if (2 * x - 1 <= n) next[size++] = 2 * x - 1;
            for (int x : a) if (2 * x <= n) next[size++] = 2 * x;
            a = java.util.Arrays.copyOf(next, size);
        }
        return a;
    }
}

JavaScript

/** @param {number} n @return {number[]} */
var beautifulArray = function(n) {
  let a = [1];
  while (a.length < n) {
    const next = [];
    for (const x of a) if (2 * x - 1 <= n) next.push(2 * x - 1);
    for (const x of a) if (2 * x <= n) next.push(2 * x);
    a = next;
  }
  return a;
};

Python

from typing import List

class Solution:
    def beautifulArray(self, n: int) -> List[int]:
        a = [1]
        while len(a) < n:
            a = ([2 * x - 1 for x in a if 2 * x - 1 <= n] +
                 [2 * x for x in a if 2 * x <= n])
        return a

C++

class Solution {
public:
    vector<int> beautifulArray(int n) {
        vector<int> a{1};
        while ((int)a.size() < n) {
            vector<int> next;
            for (int x : a) if (2 * x - 1 <= n) next.push_back(2 * x - 1);
            for (int x : a) if (2 * x <= n) next.push_back(2 * x);
            a = move(next);
        }
        return a;
    }
};
