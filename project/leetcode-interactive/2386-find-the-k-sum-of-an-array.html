HARD2386 · 子序列的排名

找出数组的第 K 大和

Find the K-Sum of an Array

给定整数数组 nums 和正整数 k。考虑每一种子序列的元素和，把这些和从大到小排列，返回第 k 项。

按位置选择

可以删除任意元素，剩余元素保持原顺序；无需连续。

相同和也占名次

不同子序列得到的和即使相同，也分别计数。

空子序列有效

什么都不选也是一种选择，其和为 0。

先独立思考：元素很多，但最多只问到第 2000 项，怎样避免列出所有选择？交互推演与题解位于底部，默认折叠。

01 / 官方示例与约束

示例 1

输入：nums = [2,4,-2], k = 5
输出：2

所有和降序为 6、4、4、2、2、0、0、−2。第 5 项为 2。重复出现的值保留各自名次。

示例 2

输入：nums = [1,-2,3,4,-10,12], k = 16
输出：10

这 6 个位置共有 64 种选择，子序列和降序排列后，第 16 项为 10。

约束与签名

  • n == nums.length，1 ≤ n ≤ 10⁵。
  • −10⁹ ≤ nums[i] ≤ 10⁹。
  • 1 ≤ k ≤ min(2000, 2ⁿ)。
  • 函数形式：kSum(nums, k)。返回整数，可能超过 32 位有符号整数范围。

03 / 打开解题工作台

机制推演、正确性证明与四语言实现。

从第 K 大和，转为第 K 小损失

把所有正数选入，得到最大和 S。移除正数会损失它的值，加入负数会损失它的绝对值。相对于这个基准选择，翻转位置 i 的选择状态，就损失 |nums[i]|。

将绝对值排序为数组 a。原数组的每一种位置选择都对应一种损失子集，原和等于 S − loss。因此，第 k 大和对应第 k 小损失。空损失为 0，先占据第 1 名。

候选损失队列 · 双分支推演

每一步取出最小候选，再生成“追加下一个”和“替换末尾”两个孩子。队列按值排序展示，不是堆的物理存储顺序。

完整过程

  1. 累加正数得到 S，把所有元素取绝对值、升序排序为 a。
  2. 第 1 小损失为 0。最小堆初始化为 (a[0], 0)。状态 (s, i) 表示损失 s 和该子集最大下标 i。
  3. 连续弹出 k−1 次；弹出的 s 依次是第 2、3、…、k 小损失。
  4. 若 i+1 < n，加入 (s+a[i+1], i+1)：保留当前末尾，追加下一个位置。
  5. 同时加入 (s−a[i]+a[i+1], i+1)：用下一个位置替换当前末尾。
  6. 返回 S−s。k=1 时使用损失 0，无需弹出。

例如 a=[2,2,4]，损失子集 {0} 生成 {0,1}（损失 4）和 {1}（损失 2）。两条分支表示不同位置选择。

正确性证明

  1. 映射保持所有选择。正数默认选，非正数默认不选。按位置翻转是双射；零也有选与不选两种身份。原和为 S−loss，因此排名反转且重复次数不变。
  2. 每个非空子集有唯一父节点。设最大下标为 j。j=0 时是根 {0}。j>0 时，若含 j−1，父节点是删除 j 后的子集，经追加得到；若不含 j−1，父节点是把 j 换成 j−1 后的子集，经替换得到。父节点的最大下标严格变小，最终到根，因此完整且无重复生成。
  3. 每条边损失不减。追加增量为非负数，替换增量为 a[i+1]−a[i] ≥ 0。任何尚未生成的节点，其路径上第一个未弹出的祖先都在堆中，且不大于该节点。堆顶因而是所有未取子集中的最小损失。
  4. 得到目标名次。空子集先算第 1 名，再弹出 k−1 个非空子集，得到第 k 小损失；S 减去它即为第 k 大和。

实现只存 (s,i) 即可计算孩子。两个状态即使 (s,i) 完全相同，也可能代表不同位置子集，必须作为两个堆元素保留。

边界与常见错误

  • k=1 直接取正数总和；不要多弹一次。
  • 全负数时最大和是空子序列的 0。
  • 零与重复值不能使用 Set 去重。
  • i 到达末端就不扩展，避免访问 a[n]。
  • JS 必须数值排序，不能使用默认字典序。
  • 总和绝对值最多 10¹⁴。Java 用 long，C++ 用 long long；Python 整数可直接保存，JS Number 在此范围内可精确表示整数。

复杂度与替代方案

时间：O(n log n + k log(k+1))。排序 n 项，每次弹出后至多添加两个节点，堆规模为 O(k)。

额外空间：O(n+k)，包含绝对值副本和堆。以下实现都不改动输入数组。

替代方案：小 n 可以枚举全部 2ⁿ 个和后排序，但不能覆盖 n=10⁵。也可二分损失阈值，用非负有序数组的 DFS 统计不超过阈值的子集数，达到 k 即截断；计数、剪枝及递归深度更容易出错。

面试追问

  • 若求第 k 个不同的和？题目语义改变，不能直接按弹出次数排名；需处理重复和，并重新分析生成的节点数量。
  • 如何恢复原子序列？排序时保留原下标，为堆状态记录父节点及追加/替换动作，再把损失子集映射为基准选择的翻转位置。
  • 零让边增量为 0，会破坏证明吗？不会，只需损失不减，不要求严格增加；重复损失仍逐个计数。
  • 为什么只保存和与末尾？两个孩子的增量只由 a[i] 和 a[i+1] 决定。恢复具体子集才需要额外路径信息。

Java

import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public long kSum(int[] nums, int k) {
        long base = 0;
        long[] a = new long[nums.length];
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] > 0) base += nums[i];
            a[i] = Math.abs((long) nums[i]);
        }
        Arrays.sort(a);
        PriorityQueue<long[]> pq = new PriorityQueue<>(
            (x, y) -> Long.compare(x[0], y[0]));
        pq.offer(new long[]{a[0], 0});
        long loss = 0;
        for (int rank = 2; rank <= k; rank++) {
            long[] cur = pq.poll();
            loss = cur[0];
            int i = (int) cur[1];
            if (i + 1 < a.length) {
                pq.offer(new long[]{loss + a[i + 1], i + 1});
                pq.offer(new long[]{loss - a[i] + a[i + 1], i + 1});
            }
        }
        return base - loss;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var kSum = function(nums, k) {
    const base = nums.reduce((s, x) => s + Math.max(0, x), 0);
    const a = nums.map(Math.abs).sort((x, y) => x - y);
    const heap = [];
    function push(item) {
        let i = heap.length;
        heap.push(item);
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (heap[p][0] <= item[0]) break;
            heap[i] = heap[p];
            i = p;
        }
        heap[i] = item;
    }
    function pop() {
        const top = heap[0], last = heap.pop();
        if (heap.length) {
            let i = 0;
            while (2 * i + 1 < heap.length) {
                let c = 2 * i + 1;
                if (c + 1 < heap.length && heap[c + 1][0] < heap[c][0]) c++;
                if (heap[c][0] >= last[0]) break;
                heap[i] = heap[c];
                i = c;
            }
            heap[i] = last;
        }
        return top;
    }
    push([a[0], 0]);
    let loss = 0;
    for (let rank = 2; rank <= k; rank++) {
        const [s, i] = pop();
        loss = s;
        if (i + 1 < a.length) {
            push([s + a[i + 1], i + 1]);
            push([s - a[i] + a[i + 1], i + 1]);
        }
    }
    return base - loss;
};

Python

from typing import List
from heapq import heappop, heappush

class Solution:
    def kSum(self, nums: List[int], k: int) -> int:
        base = sum(x for x in nums if x > 0)
        a = sorted(abs(x) for x in nums)
        heap = [(a[0], 0)]
        loss = 0
        for _ in range(k - 1):
            loss, i = heappop(heap)
            if i + 1 < len(a):
                heappush(heap, (loss + a[i + 1], i + 1))
                heappush(heap, (loss - a[i] + a[i + 1], i + 1))
        return base - loss

C++

#include <algorithm>
#include <functional>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    long long kSum(vector<int>& nums, int k) {
        long long base = 0;
        vector<long long> a;
        for (int x : nums) {
            if (x > 0) base += x;
            a.push_back(x < 0 ? -(long long)x : (long long)x);
        }
        sort(a.begin(), a.end());
        using State = pair<long long, int>;
        priority_queue<State, vector<State>, greater<State>> pq;
        pq.push({a[0], 0});
        long long loss = 0;
        for (int rank = 2; rank <= k; ++rank) {
            auto [s, i] = pq.top();
            pq.pop();
            loss = s;
            if (i + 1 < (int)a.size()) {
                pq.push({s + a[i + 1], i + 1});
                pq.push({s - a[i] + a[i + 1], i + 1});
            }
        }
        return base - loss;
    }
};
