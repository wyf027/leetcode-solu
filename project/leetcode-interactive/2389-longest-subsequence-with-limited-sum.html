2389. 和有限的最长子序列

Longest Subsequence With Limited Sum

给定一个总和上限，你最多能留下多少个元素？

先独立思考，再到页面底部展开题解与交互演示。

题目

给定长度为 n 的整数数组 nums 和长度为 m 的查询数组 queries。对于每个 queries[i]，从 nums 中选出元素和不超过该值的子序列，返回它可能达到的最大长度，组成长度为 m 的数组 answer。

子序列允许删除任意位置的元素，但保留的元素必须维持原数组中的相对顺序；不要求连续。每个查询独立作答，不会消耗数组中的元素。

官方示例 1

输入：nums = [4,5,2,1], queries = [3,10,21]
输出：[2,3,4]
  • 上限 3：可以保留 [2,1]，长度为 2。
  • 上限 10：可以保留 [4,5,1]，长度为 3。
  • 上限 21：可以保留整个 [4,5,2,1]，长度为 4。

官方示例 2

输入：nums = [2,3,4,5], queries = [1]
输出：[0]

任何单个元素都超过 1，因此只能选空子序列。

约束

  • n == nums.length
  • m == queries.length
  • 1 ≤ n, m ≤ 1000
  • 1 ≤ nums[i], queries[i] ≤ 10⁶

01 / 从最省预算的元素开始

只问长度，不问具体子序列时，选定 k 个元素的最小可能总和，就是数组中最小的 k 个数之和。将数组升序排列为 a，构造 P[0] = 0、P[k] = a[0] + … + a[k-1]。

所有数都是正数，所以 P 严格递增。对每个上限 q，找最大的 k 使 P[k] ≤ q：二分查找第一个 P[k] > q 的位置，再减一。

排序只改变分析的顺序。选出的那些元素可以按原下标重新排列，仍是合法子序列，元素和与长度都不变。

03 / 完整过程与正确性

  1. 复制并升序排序 nums，保留输入数组。
  2. 构造长度 n + 1 的前缀和，含空前缀 P[0] = 0。
  3. 对每个查询，令 lo = 0、hi = n + 1，使用半开区间 [lo, hi)。
  4. 若 P[mid] ≤ q，则令 lo = mid + 1；否则令 hi = mid。
  5. 结束时 lo 是第一个超出预算的位置（可能是数组末尾的虚拟位置），答案为 lo - 1，按原查询顺序写入结果。

为什么一定最优？

将任意选出的 k 个元素排序，其第 j 小的元素不小于全数组的第 j 小元素。因此任何长度为 k 的子序列，其和都至少为 P[k]。反过来，全数组最小的 k 个元素按原下标排列，就得到和恰为 P[k] 的合法子序列。所以“存在长度 k 的可行子序列”等价于“P[k] ≤ q”。

二分维持：索引小于 lo 的前缀都 ≤ q，索引大于等于 hi 的真实前缀都 > q。每一步根据中点比较缩小区间且保持不变量。lo 与 hi 相等时找到第一个不可行前缀，其前一个长度就是最大可行长度。

边界与复杂度

  • 上限小于最小元素：只有 P[0] 可行，返回 0。
  • 上限恰好等于某个前缀和：等号必须被计入。
  • 上限不小于全数组之和：二分返回 n + 1，答案是 n。
  • 重复元素正常累加；查询乱序、重复也独立处理。
  • 最大总和是 10⁹，Java/C++ 的 32 位有符号整数足够，JavaScript Number 也能精确表示。
  • 时间 O(n log n + m log n)；本页复制排序和前缀数组，额外空间 O(n)，结果数组 O(m)。

替代方案

排序后对每个查询从小到大累加，到超出上限就停止，时间 O(n log n + mn)，更直观但重复扫描。也可将查询连同原下标排序，用单指针向右推进前缀位置，时间 O(n log n + m log m + n + m)，最后还原查询顺序。

常见错误

  • 沿原数组顺序取数，遇到第一个超预算就停止：后面可能有更小元素。
  • 误用连续子数组滑动窗口：题目允许跳过元素。
  • 用 lower_bound / bisect_left 找 ≥ q：会漏掉刚好等于 q 的合法前缀。
  • JavaScript 直接调用 sort()：默认按字符串排序，必须传数值比较函数。
  • 混用有无 P[0] 的写法：本页含空前缀，所以要减一。

面试追问

  • 如何返回具体子序列？保留元素原下标，选择最小的 k 个，再按原下标排列。
  • 若允许负数？正数保证的前缀单调性不再成立，不能直接对整个前缀数组套此二分；应重新分析可行区间。
  • 如果 nums 频繁修改？静态排序与前缀和需要重建；可在值域可控时维护计数和总和的树状数组。

Java

import java.util.Arrays;

class Solution {
    public int[] answerQueries(int[] nums, int[] queries) {
        int[] a = nums.clone();
        Arrays.sort(a);
        int[] prefix = new int[a.length + 1];
        for (int i = 0; i < a.length; i++) {
            prefix[i + 1] = prefix[i] + a[i];
        }
        int[] answer = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int lo = 0, hi = prefix.length;
            while (lo < hi) {
                int mid = lo + (hi - lo) / 2;
                if (prefix[mid] <= queries[i]) lo = mid + 1;
                else hi = mid;
            }
            answer[i] = lo - 1;
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @param {number[]} queries
 * @return {number[]}
 */
var answerQueries = function(nums, queries) {
    const a = [...nums].sort((x, y) => x - y);
    const prefix = [0];
    for (const x of a) prefix.push(prefix[prefix.length - 1] + x);
    return queries.map(q => {
        let lo = 0, hi = prefix.length;
        while (lo < hi) {
            const mid = Math.floor((lo + hi) / 2);
            if (prefix[mid] <= q) lo = mid + 1;
            else hi = mid;
        }
        return lo - 1;
    });
};

Python

from typing import List
from bisect import bisect_right

class Solution:
    def answerQueries(self, nums: List[int], queries: List[int]) -> List[int]:
        prefix = [0]
        for x in sorted(nums):
            prefix.append(prefix[-1] + x)
        return [bisect_right(prefix, q) - 1 for q in queries]

class Solution {

    vector<int> answerQueries(vector<int>& nums, vector<int>& queries) {
        vector<int> a = nums;
        sort(a.begin(), a.end());
        vector<int> prefix(a.size() + 1, 0);
        for (int i = 0; i < (int)a.size(); ++i) {
            prefix[i + 1] = prefix[i] + a[i];
        }
        vector<int> answer;
        answer.reserve(queries.size());
        for (int q : queries) {
            int pos = upper_bound(prefix.begin(), prefix.end(), q) - prefix.begin();
            answer.push_back(pos - 1);
        }
        return answer;
    }
