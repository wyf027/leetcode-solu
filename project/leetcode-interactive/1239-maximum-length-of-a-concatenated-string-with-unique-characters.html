Problem

从若干字符串中，拼出不重复字母的最长结果

给定字符串数组 arr。从中选择一个子序列，并按原相对顺序连接成字符串 s；要求 s 内每个字母最多出现一次。返回所有合法选择中 s 的最大可能长度。

这里的“子序列”允许删除任意个元素（也可以一个都不删），但不能改变被保留元素的先后顺序；空选择同样是合法候选。

示例 1

输入：arr = ["un","iq","ue"]
输出：4

合法串联包括 ""、"un"、"iq"、"ue"、"uniq" 与 "ique"，最长为 4。

示例 2

输入：arr = ["cha","r","act","ers"]
输出：6

最长合法结果可以是 "chaers" 或 "acters"。

示例 3

输入：arr = ["abcdefghijklmnopqrstuvwxyz"]
输出：26

唯一字符串已经包含 26 个互不相同的英文字母。

1 <= arr.length <= 16
1 <= arr[i].length <= 26
arr[i] 只含小写英文字母

准备好核对思路了吗？

展开后将看到位掩码回溯、正确性证明、复杂度与四种语言实现。

Deep Dive

位掩码 + 回溯：搜索所有可行子序列

核心洞察

合法性只取决于“哪些字母已经出现”，而不取决于它们的具体排列。用一个 26 位整数表示字母集合：第 k 位为 1 表示字母 a + k 已占用。两个字符串能否连接，只需检查两个掩码按位与是否为 0。

还要先过滤自身含重复字母的字符串。例如 "aa" 永远不可能出现在合法答案里。

完整过程

01 · 编码

逐字符构建每个字符串的掩码；如果某一位已经出现，则丢弃整个字符串。

02 · 决策

对每个有效字符串做“不选”和“选”两种决策；仅在掩码不冲突时进入“选”的分支。

03 · 更新

每到一个搜索状态，用当前掩码中 1 的数量更新全局最大值。

状态定义

dfs(index, usedMask) 表示考虑到第 index 个有效字符串、当前已用字母集合为 usedMask 时继续搜索。输入最多 16 个字符串，因此枚举子集是可接受的。

正确性证明

  1. 预处理不会删除任何可行答案。自身含重复字母的字符串一旦被选择，连接结果必然含重复字母，所以它不可能属于合法解。
  2. 每次选择都保持合法。只有当 usedMask & wordMask == 0 时才合并掩码；因此新字符串内部无重复，且与已选字符也无交集。
  3. 搜索覆盖所有合法子序列。对每个有效字符串，递归都枚举“不选”；若可行也枚举“选”。任意合法子序列都对应唯一的一串选/不选决策，所以不会遗漏。
  4. 返回值最优。算法在所有可行状态上更新最大长度。由覆盖性，最优合法子序列必被访问；由合法性，记录值不会来自非法结果，故最终最大值恰为答案。

边界与复杂度

时间 O(2ⁿ · n · L)预处理为 O(nL)；回溯至多枚举 2ⁿ 个子集。实现中每次计数 26 位，可视为常数。
空间 O(n)保存至多 n 个有效掩码，递归栈深度至多 n；不计输出。
  • 所有字符串自身都重复：有效集合为空，答案为 0。
  • 字符串之间完全不冲突：答案等于所有字符串长度之和，最大不超过 26。
  • 单个字符串覆盖全部字母：可直接形成长度 26 的答案。
  • 多个字符串掩码相同或互有重叠：回溯会分别探索但不会非法合并。

替代方案

迭代式状态集合：维护所有已出现的合法掩码。读到新掩码时，遍历旧状态；若不冲突则加入合并状态。它本质上也是子集 DP，避免递归，代码很紧凑。

纯字符串回溯：把当前连接串转为集合来检测重复，更直观但反复创建集合与扫描字符，常数更大。由于字符域固定为 26，位掩码表达更自然。

class Solution {
    private int answer = 0;

    public int maxLength(List<String> arr) {
        List<Integer> masks = new ArrayList<>();
        for (String word : arr) {
            int mask = encode(word);
            if (mask != -1) masks.add(mask);
        }
        dfs(masks, 0, 0);
        return answer;
    }

    private int encode(String word) {
        int mask = 0;
        for (char ch : word.toCharArray()) {
            int bit = 1 << (ch - 'a');
            if ((mask & bit) != 0) return -1;
            mask |= bit;
        }
        return mask;
    }

    private void dfs(List<Integer> masks, int index, int used) {
        answer = Math.max(answer, Integer.bitCount(used));
        for (int i = index; i < masks.size(); i++) {
            int next = masks.get(i);
            if ((used & next) == 0) {
                dfs(masks, i + 1, used | next);
            }
        }
    }
}

var maxLength = function(arr) {
    const masks = [];

    for (const word of arr) {
        let mask = 0;
        let valid = true;
        for (const ch of word) {
            const bit = 1 << (ch.charCodeAt(0) - 97);
            if ((mask & bit) !== 0) {
                valid = false;
                break;
            }
            mask |= bit;
        }
        if (valid) masks.push(mask);
    }

    let answer = 0;
    const dfs = (index, used) => {
        answer = Math.max(answer, countBits(used));
        for (let i = index; i < masks.length; i++) {
            if ((used & masks[i]) === 0) {
                dfs(i + 1, used | masks[i]);
            }
        }
    };

    const countBits = (value) => {
        let count = 0;
        while (value !== 0) {
            value &= value - 1;
            count++;
        }
        return count;
    };

    dfs(0, 0);
    return answer;
};

面试追问

为什么 32 位整数足够？

字符域只有 26 个小写字母，只需低 26 位。

能否加入剪枝？

可以预估当前长度加“剩余可能新增字母数”的上界；若不超过答案则停止。但 n ≤ 16，基础版本已经足够。

如果字符不限于 a-z？

改用集合，或先对出现过的字符离散化；字符种类超过整数位宽时可用 BigInt、BitSet 或多段位图。

常见错误

  • 只检查字符串之间的冲突，却忘了过滤 "aa" 这类自身重复字符串。
  • 用加法合并掩码；正确做法是按位或 used | next。
  • 在 JavaScript 中直接用字符串长度当作已用字符数；应计算掩码中 1 的数量。
  • 递归后手动撤销共享掩码时出错。整数按值传递，直接传入新掩码更安全。
  • 误以为必须选择连续区间；题目要求的是子序列，可以跳过任意元素。
