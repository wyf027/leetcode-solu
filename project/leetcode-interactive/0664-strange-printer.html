01 · Problem

题目说明

输入一个仅由小写英文字母组成的字符串 s，返回打印机把空白纸带变成 s 所需的最少轮数。

机器的两个特性

  • A 一轮打印必须使用同一个字符，但打印区间的起点和终点可以任意选择。
  • B 一轮可以覆盖此前已经打印的内容，因此中间状态不必是目标字符串的前缀。
函数形式： strangePrinter(s: string) -> integer

约束

  • 1 <= s.length <= 100
  • s 只包含小写英文字母。
示例 1 OUTPUT · 2
输入：s = "aaabbb" 输出：2

先在前三个位置打印 aaa，再在后三个位置打印 bbb。

示例 2 OUTPUT · 2
输入：s = "aba" 输出：2

先在全部位置打印 aaa，再用 b 覆盖中间位置。

04 · Solution

准备好看题解了吗？

下面会展开完整思路、证明、复杂度与四种语言代码。默认收起，避免提前泄露关键洞察。

Interval Dynamic Programming

区间动态规划：让相同字符共用一轮

真正的突破口不是模拟所有打印顺序，而是把“最后形成一个区间”的最优代价记录下来，并在相同字符之间合并打印轮次。

核心洞察

连续相同字符可以在同一轮覆盖，因此先把相邻重复字符压缩。例如 aaabbb 可压缩为 ab，答案不变。

设压缩后的字符串为 t。打印 t[i..j] 时，可以先把 t[i] 单独算作一轮；如果右侧某个位置 k 与它字符相同，那么打印 t[k] 的那一轮也可以顺带覆盖位置 i，从而省掉单独的一轮。

状态与转移

dp[i][j] 表示打印子串 t[i..j] 的最少轮数。

dp[i][i] = 1 dp[i][j] = 1 + dp[i + 1][j] 若 t[i] == t[k]： dp[i][j] = min( dp[i][j], dp[i + 1][k - 1] + dp[k][j] ) 空区间的代价视为 0。

完整过程

  1. 扫描原字符串，只保留每段连续相同字符中的一个，得到 t。
  2. 创建二维数组 dp，把所有单字符区间 dp[i][i] 设为 1。
  3. 按区间长度从 2 到 m 枚举，确保转移所依赖的更短区间已经求出。
  4. 先令 t[i] 独立打印，得到上界 1 + dp[i + 1][j]。
  5. 枚举 k ∈ [i + 1, j]。若 t[i] == t[k]，尝试让两者共用打印 t[k] 的那一轮。
  6. 最终答案是 dp[0][m - 1]。

正确性证明

归纳对象：区间长度。

单字符区间显然只需一轮。假设所有更短区间的 dp 都是最优值。对区间 [i, j]，任一最优方案中，位置 i 的最终字符要么没有与右侧同字符位置共用最后一次有效打印，此时可分解为打印 i 的一轮加上 [i+1, j] 的最优方案；要么与某个 k 共用一轮，此时中间区间 [i+1, k-1] 独立完成，而位置 i 可并入 [k, j] 的方案。转移枚举了这两类全部可能，并对子区间取最优值，所以得到 [i, j] 的最少轮数。归纳成立。

边界与复杂度

  • 长度为 1：答案为 1。
  • 全部字符相同：压缩后长度为 1，答案仍为 1。
  • 没有重复字符：每个字符都必须单独贡献一轮。
  • 相同字符分散出现：覆盖机制最有价值，也是转移枚举 k 的原因。
时间复杂度O(m³)
空间复杂度O(m²)

m 是压缩后长度，且 m <= n <= 100。

替代方案

也可定义 dp[i][j] 后枚举分割点，把左右区间答案相加，并在端点字符相同的情况下减少一次。 这种写法直观，但不同递推式的下标细节容易混淆。记忆化搜索同样可行，递归状态仍是区间，复杂度与二维表方案同阶。

常见错误

  • 只按连续字符段计数，忽略“先大范围打印、再覆盖中间”的机会。
  • 把相同端点直接减一，却没有正确处理端点之间的独立区间。
  • 区间长度遍历顺序错误，读取了尚未计算的状态。
  • k = i + 1 时忘记中间区间为空，其贡献应为 0。
  • 把时间复杂度误写成 O(n²)；转移内部仍枚举了 k。

四语言完整代码

均使用“压缩相邻重复字符 + 区间动态规划”的同一递推。

class Solution {
    public int strangePrinter(String s) {
        StringBuilder compressed = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            if (i == 0 || s.charAt(i) != s.charAt(i - 1)) {
                compressed.append(s.charAt(i));
            }
        }

        String t = compressed.toString();
        int n = t.length();
        int[][] dp = new int[n][n];

        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                dp[i][j] = 1 + dp[i + 1][j];
                for (int k = i + 1; k <= j; k++) {
                    if (t.charAt(i) == t.charAt(k)) {
                        int middle = (k == i + 1) ? 0 : dp[i + 1][k - 1];
                        dp[i][j] = Math.min(dp[i][j], middle + dp[k][j]);
                    }
                }
            }
        }
        return dp[0][n - 1];
    }
}

    for (let i = 0; i < s.length; i++) {

            t += s[i];
        }

class Solution:
    def strangePrinter(self, s: str) -> int:
        chars = []
        for char in s:
            if not chars or chars[-1] != char:
                chars.append(char)

        n = len(chars)
        dp = [[0] * n for _ in range(n)]

        for i in range(n - 1, -1, -1):
            dp[i][i] = 1
            for j in range(i + 1, n):
                dp[i][j] = 1 + dp[i + 1][j]
                for k in range(i + 1, j + 1):
                    if chars[i] == chars[k]:
                        middle = 0 if k == i + 1 else dp[i + 1][k - 1]
                        dp[i][j] = min(dp[i][j], middle + dp[k][j])

        return dp[0][n - 1]
class Solution {
public:
    int strangePrinter(string s) {
        string t;
        for (char ch : s) {
            if (t.empty() || t.back() != ch) {
                t.push_back(ch);
            }
        }

        int n = static_cast<int>(t.size());
        vector<vector<int>> dp(n, vector<int>(n, 0));

        for (int i = n - 1; i >= 0; --i) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; ++j) {
                dp[i][j] = 1 + dp[i + 1][j];
                for (int k = i + 1; k <= j; ++k) {
                    if (t[i] == t[k]) {
                        int middle = (k == i + 1) ? 0 : dp[i + 1][k - 1];
                        dp[i][j] = min(dp[i][j], middle + dp[k][j]);
                    }
                }
            }
        }
        return dp[0][n - 1];
    }

面试追问

为什么压缩连续重复字符不会改变答案？

同一连续段最终都是同一个字符。任何覆盖其中一个位置的打印区间，都可扩展或收缩到覆盖整段而不增加轮数；反过来，把压缩后的一个位置还原为整段也无需额外打印。

为什么不能使用普通贪心？

局部看似合理的短区间打印，可能破坏让两个远处相同字符共用一轮的机会。覆盖顺序带来跨区间依赖，无法仅凭当前位置做出安全决策。

如何输出一组实际打印操作？

在更新 dp[i][j] 时额外记录选择：是单独打印左端点，还是与某个 k 合并。随后递归回溯这些选择，并谨慎调整合并操作的覆盖区间。

约束扩大到几千时怎么办？

标准三次方区间 DP 会过慢。需要进一步利用字符位置表减少无效的 k 枚举，或研究问题结构是否允许更强优化；但一般情形下不能直接声称可降为二次方。
