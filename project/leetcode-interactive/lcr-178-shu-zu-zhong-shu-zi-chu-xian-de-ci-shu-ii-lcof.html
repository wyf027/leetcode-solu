LCR 178 · Medium数组 · 位运算

训练计划 VI

混乱的训练录像中：每名学员出现 3 次，只有教练出现 1 次。请从记录中找出只示范一次的教练编号，并观察状态如何随录像逐条变化。

题意与示例

数组 actions 记录每次动作的人员编号；每个学员恰好记录三次，教练只记录一次。返回教练编号。

示例 1

actions = [5, 7, 5, 5]

期望输出：7

示例 2

actions = [12, 1, 6, 12, 6, 12, 6]

期望输出：1

限制：1 ≤ actions.length ≤ 10000；1 ≤ actions[i] < 2³¹。

本页数字均为十进制；二进制位从低位开始演示。空格以 ␠ 表示（本题输入不含字符串）。

三拍状态机实验室

准备开始

用逗号分隔正整数。每个非教练编号必须刚好出现 3 次。

点击“下一步”，将一条录像送入两个位状态寄存器。

ones = (ones XOR x) AND NOT twos

twos = (twos XOR x) AND NOT ones

逐位有限状态机：只保存“出现次数 mod 3”

核心洞察

对任意二进制位，三次相同输入会让计数回到 0；只出现一次的教练位最终停在 1。ones 保存余数为 1 的位，twos 保存余数为 2 的位。每读一个编号，先更新 ones，再用新 ones 更新 twos。

完整过程

  1. 1. 初始化 ones = 0、twos = 0。
  2. 2. 逐个读入 x：用异或切换候选位，并清掉另一寄存器已经占用的位。
  3. 3. 三次相同 x 后相关位回零；循环结束 ones 即教练编号。

边界与复杂度

单元素数组直接返回自身；编号可达 2³¹ − 1，四种语言的 32 位整数均可表达。时间 O(n)，额外空间 O(1)。

替代方案、追问与常见错误

替代：哈希计数 O(n) 空间，或逐位统计 O(32n)；状态机同时满足一次遍历与 O(1) 空间。追问：若其他人出现 k 次，可为每位计数后取模 k；若有两个只出现一次的数，则是另一类 XOR 分组题。易错：更新 twos 时误用旧 ones；JavaScript 位运算固定为有符号 32 位；输入校验不能把“出现两次”的非法数据当作答案。

class Solution {
    public int trainingPlan(int[] actions) {
        int ones = 0, twos = 0;
        for (int x : actions) {
            ones = (ones ^ x) & ~twos;
            twos = (twos ^ x) & ~ones;
        }
        return ones;
    }
}
