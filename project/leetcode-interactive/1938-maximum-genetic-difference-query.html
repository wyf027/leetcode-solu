Maximum Genetic Difference Query

每个节点都有自己的编号。沿着祖先链，寻找与给定数异或后最大的那个值。

01 / PROBLEM

先理解问题

给定一棵有根树，节点编号为 0 … n−1，编号本身就是节点的基因值。数组 parents 描述每个节点的父节点，根的父节点是 −1。两个值的基因差定义为按位异或。

每项查询 queries[i] = [nodeᵢ, valᵢ] 要求在 nodeᵢ 到根的路径上选择节点 p，使 valᵢ XOR p 最大。两个端点都包含在候选中。返回数组 ans，顺序与原查询一致。

返回最大异或值，而非所选节点编号。其他分支的节点不能作为候选。

约束

  • 2 ≤ parents.length ≤ 10⁵
  • 每个非根节点 i 满足 0 ≤ parents[i] ≤ parents.length−1。
  • parents[root] = −1；输入描述一棵有根树。
  • 1 ≤ queries.length ≤ 3 × 10⁴
  • 0 ≤ nodeᵢ ≤ parents.length−1
  • 0 ≤ valᵢ ≤ 2 × 10⁵

示例 1

parents = [-1,0,1,1]
queries = [[0,2],[3,2],[2,5]]
输出 = [2,3,7]

[0,2] 只能选 0，得到 2；[3,2] 选节点 1，得到 2 XOR 1 = 3；[2,5] 选节点 2，得到 5 XOR 2 = 7。

示例 2

parents = [3,7,-1,2,0,7,0,2]
queries = [[4,6],[1,15],[0,5]]
输出 = [6,14,7]

根节点是 2。三项查询分别选择节点 0、1、2，得到 6 XOR 0 = 6、15 XOR 1 = 14、5 XOR 2 = 7。

准备好再揭开思路

展开后包含交互推演、正确性说明和四语言实现。

离线查询 + 可删除的二进制 Trie

核心洞察：DFS 到达节点 u 时，当前路径正好是根到 u。进入时插入编号，退出时删除编号，一个 Trie 就能始终维护当前合法候选集合。

查询时，从最高位向最低位，优先选择与 val 当前位相反、且计数大于 0 的分支。一次高位收益大于所有低位收益之和。

  1. 建立 children 邻接表，找到真正的根。将查询按节点归组，并保存原始下标。
  2. 显式栈保存进入和退出事件。进入 u 后，沿编号的 18 位 Trie 路径将计数加 1，再回答该节点的所有查询。
  3. 先压入退出标记 ~u，再压入孩子；后进先出保证孩子处理完后才退出父节点。
  4. 退出 u 时将其 Trie 路径计数减 1。保留节点结构，按有效计数选择查询分支。
  5. 每项答案写回原始下标，最终返回 ans。

B = 18，遍历 bit 17 … 0，因为 200000 < 2¹⁸。使用迭代 DFS，避免长度 10⁵ 的链造成调用栈溢出。

当前有效路径

累计答案（原查询顺序）

为什么正确

  1. 路径不变量。根进入前集合为空。进入 u 插入 u 后，集合是父路径加上 u；孩子退出恢复父集合，u 退出再移除 u。因此回答 u 的查询时，集合恰好包含 u 到根的所有节点，没有旁支节点。
  2. 位贪心。在已选高位前缀下，若存在让异或第 b 位为 1 的有效分支，就选它。收益 2ᵇ 大于所有低位之和 2ᵇ−1。不存在时只能选同位分支，且始终至少有一个候选保留。
  3. 输出顺序。每个查询在所属节点进入后回答一次，写到保存的原下标。因此输出是每条合法路径的最大异或值，并保持原顺序。

边界与常见错误

  • 根不一定是 0；根查询只能选择根自己。
  • val = 0 时最大编号最优；一般 val 下不能只挑最大编号。
  • 退出时不减计数会引入兄弟分支。分支结构存在不代表有效，必须检查 count > 0。
  • 多个编号共享前缀，不能直接删除共享 Trie 节点。
  • 位宽必须覆盖 val 的高位，不能只看节点编号；异或不是加法或乘方。
  • 同节点允许多次或重复查询。退出标记用 ~u，不能用 −u，否则节点 0 无法区分。
  • JavaScript 位运算是 32 位有符号操作，本题 18 位安全；扩展到更大整数时需调整表示。

复杂度

令 n 为节点数、q 为查询数、B = 18。每个编号插入、删除各一次，每次查询走 B 位，总时间 O((n+q)B)。Trie 最多分配 1+nB 个节点，加上邻接表、查询归组、答案及栈，总空间 O(nB+q)。退出后不释放结构，空间不能只按树高计算。

替代方案

逐查询枚举父链：时间 O(qh)、辅助空间 O(1)（不计答案），方便理解但链状树最坏 O(nq)。可持久化 Trie 为每个节点保存根路径版本，时间同样 O((n+q)B)、空间 O(nB+q)，适合建树后按任意顺序到来的查询，但需要复制版本节点。

面试追问

  • 还要返回被选中编号？沿查询分支累计所选 bit，或在叶子保留编号。
  • 基因值可以重复？插入实际值，计数仍有效；需要节点身份时再管理叶子上的有效节点集合。
  • 改成任意两点路径？可持久化 Trie 结合 LCA：两端版本计数之和，减去 LCA 与 LCA 父节点的版本计数。
  • 为什么不能全树共用一个静态 Trie？全树集合包含不合法的旁支，而当前查询只允许祖先路径。

import java.util.*;

class Solution {
    private int[] zero, one, count;
    private int size;
    private static final int B = 18;

    private void change(int x, int delta) {
        int t = 0;
        for (int b = B - 1; b >= 0; b--) {
            int[] next = ((x >>> b) & 1) == 0 ? zero : one;
            if (next[t] == 0) next[t] = ++size;
            t = next[t];
            count[t] += delta;
        }
    }
    private int best(int x) {
        int t = 0, result = 0;
        for (int b = B - 1; b >= 0; b--) {
            int bit = (x >>> b) & 1;
            int other = bit == 0 ? one[t] : zero[t];
            if (other != 0 && count[other] > 0) {
                result |= 1 << b;
                t = other;
            } else t = bit == 0 ? zero[t] : one[t];
        }
        return result;
    }
    public int[] maxGeneticDifference(int[] parents, int[][] queries) {
        int n = parents.length, root = -1;
        List<List<Integer>> children = new ArrayList<>();
        List<List<int[]>> at = new ArrayList<>();
        for (int u = 0; u < n; u++) {
            children.add(new ArrayList<>());
            at.add(new ArrayList<>());
        }
        for (int u = 0; u < n; u++) {
            if (parents[u] == -1) root = u;
            else children.get(parents[u]).add(u);
        }
        for (int i = 0; i < queries.length; i++)
            at.get(queries[i][0]).add(new int[]{queries[i][1], i});
        zero = new int[n * B + 1];
        one = new int[n * B + 1];
        count = new int[n * B + 1];
        size = 0;
        int[] ans = new int[queries.length];
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            int event = stack.pop();
            if (event < 0) { change(~event, -1); continue; }
            int u = event;
            change(u, 1);
            for (int[] q : at.get(u)) ans[q[1]] = best(q[0]);
            stack.push(~u);
            for (int child : children.get(u)) stack.push(child);
        }
        return ans;
    }
}

var maxGeneticDifference = function(parents, queries) {
    const n = parents.length, B = 18;
    const children = Array.from({length:n}, () => []);
    const at = Array.from({length:n}, () => []);
    let root = -1;
    parents.forEach((p,u) => {
        if (p === -1) root = u;
        else children[p].push(u);
    });
    queries.forEach(([u,v],i) => at[u].push([v,i]));
    const zero = new Int32Array(n*B+1);
    const one = new Int32Array(n*B+1);
    const count = new Int32Array(n*B+1);
    let size = 0;
    function change(x, delta) {
        let t = 0;
        for (let b=B-1; b>=0; b--) {
            const next = ((x>>>b)&1) ? one : zero;
            if (next[t] === 0) next[t] = ++size;
            t = next[t];
            count[t] += delta;
        }
    }
    function best(x) {
        let t=0, result=0;
        for (let b=B-1; b>=0; b--) {
            const bit=(x>>>b)&1;
            const other=bit ? zero[t] : one[t];
            if (other && count[other]>0) {
                result |= 1<<b;
                t=other;
            } else t=bit ? one[t] : zero[t];
        }
        return result;
    }
    const ans = new Array(queries.length);
    // ~u is a negative exit marker, including for node 0.
    const stack = [root];
    while (stack.length) {
        const event=stack.pop();
        if (event<0) { change(~event,-1); continue; }
        const u=event;
        change(u,1);
        for (const [v,i] of at[u]) ans[i]=best(v);
        stack.push(~u);
        for (const child of children[u]) stack.push(child);
    }
    return ans;
};

Python

from typing import List

class Solution:
    def maxGeneticDifference(self, parents: List[int],
                             queries: List[List[int]]) -> List[int]:
        n, B = len(parents), 18
        children = [[] for _ in range(n)]
        at = [[] for _ in range(n)]
        root = -1
        for u, p in enumerate(parents):
            if p == -1:
                root = u
            else:
                children[p].append(u)
        for i, (u, v) in enumerate(queries):
            at[u].append((v, i))
        # Trie node: [zero child, one child, active count]
        trie = [[0, 0, 0]]
        def change(x, delta):
            t = 0
            for b in range(B - 1, -1, -1):
                bit = (x >> b) & 1
                if trie[t][bit] == 0:
                    trie[t][bit] = len(trie)
                    trie.append([0, 0, 0])
                t = trie[t][bit]
                trie[t][2] += delta
        def best(x):
            t = result = 0
            for b in range(B - 1, -1, -1):
                bit = (x >> b) & 1
                other = trie[t][bit ^ 1]
                if other and trie[other][2] > 0:
                    result |= 1 << b
                    t = other
                else:
                    t = trie[t][bit]
            return result
        ans = [0] * len(queries)
        stack = [root]
        while stack:
            event = stack.pop()
            if event < 0:
                change(~event, -1)
                continue
            u = event
            change(u, 1)
            for v, i in at[u]:
                ans[i] = best(v)
            stack.append(~u)
            stack.extend(children[u])
        return ans

C++

#include <vector>
#include <array>
#include <utility>
using namespace std;

class Solution {
public:
    vector<int> maxGeneticDifference(vector<int>& parents,
                                     vector<vector<int>>& queries) {
        const int B = 18;
        int n = parents.size(), root = -1;
        vector<vector<int>> children(n);
        vector<vector<pair<int,int>>> at(n);
        for (int u = 0; u < n; ++u) {
            if (parents[u] == -1) root = u;
            else children[parents[u]].push_back(u);
        }
        for (int i = 0; i < (int)queries.size(); ++i)
            at[queries[i][0]].push_back({queries[i][1], i});
        // [zero child, one child, active count]
        vector<array<int,3>> trie(1, {0,0,0});
        auto change = [&](int x, int delta) {
            int t = 0;
            for (int b = B - 1; b >= 0; --b) {
                int bit = (x >> b) & 1;
                if (trie[t][bit] == 0) {
                    int id = trie.size();
                    trie[t][bit] = id;
                    trie.push_back({0,0,0});
                }
                t = trie[t][bit];
                trie[t][2] += delta;
            }
        };
        auto best = [&](int x) {
            int t = 0, result = 0;
            for (int b = B - 1; b >= 0; --b) {
                int bit = (x >> b) & 1;
                int other = trie[t][bit ^ 1];
                if (other && trie[other][2] > 0) {
                    result |= 1 << b;
                    t = other;
                } else t = trie[t][bit];
            }
            return result;
        };
        vector<int> ans(queries.size()), stack{root};
        while (!stack.empty()) {
            int event = stack.back(); stack.pop_back();
            if (event < 0) { change(~event, -1); continue; }
            int u = event;
            change(u, 1);
            for (auto [v, i] : at[u]) ans[i] = best(v);
            stack.push_back(~u);
            for (int child : children[u]) stack.push_back(child);
        }
        return ans;
    }
};
