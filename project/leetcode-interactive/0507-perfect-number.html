完美数

一个数，能否被它自身之外的所有正因子恰好“拼回”原值？先读题，再亲手推动因子配对镜；题解默认收在页面底部。

输入

num: integer

输出

boolean

范围

1 ≤ num ≤ 10⁸

Problem

题目描述

对于一个正整数，如果它等于除它自身以外全部正因子之和，就称它为完美数。正因子是能够整除该数、余数为零的正整数。

给定整数 num，若它是完美数则返回 true，否则返回 false。

示例 1

输入：num = 28
输出：true
解释：28 = 1 + 2 + 4 + 7 + 14
1、2、4、7、14 是 28 的全部正因子（不含 28）。

示例 2

输入：num = 7
输出：false

约束

1 <= num <= 108

Solution

平方根枚举：一次找到一对因子

下面是完整题解。关键在于把因子按乘积配对，只扫描到平方根。

核心洞察

若 i 整除 num，那么 num / i 也必然是因子。每对因子至少有一个不大于 √num，所以枚举到平方根就不会漏掉任何因子。

完整过程

  1. num <= 1 时直接返回 false。
  2. 把必然存在的真因子 1 计入总和。
  3. 从 2 枚举到 i * i <= num；整除时同时累加 i 与 num / i。
  4. 平方数的两个因子相同，只累加一次；最终比较总和与 num。

正确性证明

完备性：除 1 外，每个真因子 d 都有配对因子 num / d。二者中至少一个不超过平方根，因此循环一定会访问这对因子。

不重复性：每个较小因子只被枚举一次；对应较大因子同时加入。若二者相等，分支只加一次。

结论：循环结束后，累计值恰为全部真因子之和，所以与 num 相等当且仅当它是完美数。

边界与复杂度

  • 1 没有正真因子，必须返回 false。
  • 质数只会保留因子 1，因此返回 false。
  • 完全平方数要避免重复累加平方根。
  • 时间复杂度 O(√num)，额外空间复杂度 O(1)。

替代方案

  • 逐个枚举：检查 1..num-1，直观但需要 O(num) 时间。
  • 固定完美数表：在当前上限内可列出有限候选并查询，但依赖范围与数学先验，泛化性较差。
  • 欧几里得–欧拉形式：能从梅森素数构造偶完美数，但判断梅森素数并不适合这道基础实现题。

面试追问

  • 为什么扫描到平方根足够？请用反证法说明。
  • 若输入上限扩大到 64 位，如何避免 i * i 溢出？可改写为 i <= num / i。
  • 能否提前结束？当累计和已经大于 num 时，可安全返回 false。
  • 如何批量查询很多个数？可用类似筛法累计真因子和。

常见错误

  • 把 num 本身也加入因子和。
  • 默认 sum = 1 却忘记单独处理 num = 1。
  • 遇到平方数时，把平方根累加两遍。
  • 循环边界写成 i * i < num，漏掉平方根。
  • 在更大整数范围中直接计算 i * i，引发溢出。

class Solution {
    public boolean checkPerfectNumber(int num) {
        if (num <= 1) {
            return false;
        }

        long sum = 1;
        for (int i = 2; i <= num / i; i++) {
            if (num % i == 0) {
                sum += i;
                int paired = num / i;
                if (paired != i) {
                    sum += paired;
                }
            }
        }
        return sum == num;
    }
}

var checkPerfectNumber = function(num) {
    if (num <= 1) {
        return false;
    }

    let sum = 1;
    for (let i = 2; i <= Math.floor(num / i); i++) {
        if (num % i === 0) {
            sum += i;
            const paired = num / i;
            if (paired !== i) {
                sum += paired;
            }
        }
    }
    return sum === num;
};
