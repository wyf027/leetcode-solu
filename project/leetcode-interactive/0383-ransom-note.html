赎金信 Ransom Note

两段小写字母，一条不可重复使用的规则。判断杂志里的字母，是否足够拼出指定的赎金信。

01 / Problem

题目说了什么？

给定字符串 ransomNote 和 magazine。如果能只使用 magazine 中的字符拼出 ransomNote，返回 true；否则返回 false。

规则与约束

  • magazine 中的每个字符最多使用一次。
  • 1 <= ransomNote.length, magazine.length <= 10^5
  • 两个字符串均只由小写英文字母组成。
  • 函数形式：canConstruct(ransomNote: string, magazine: string): boolean
示例 1 
输入：ransomNote = "a", magazine = "b"
输出：false
示例 2 
输入：ransomNote = "aa", magazine = "ab"
输出：false
示例 3 
输入：ransomNote = "aa", magazine = "aab"
输出：true

04 / Solution

准备好再揭开题解

先自己想一想：如何在不反复扫描杂志字符串的情况下，判断每种字母是否足够？

Answer Unsealed

计数数组：先存后取

O(m + n) / O(1)

核心洞察

字符范围固定为 26 个小写英文字母，因此不必保存字符出现的位置，只需保存每种字母的可用数量。 长度为 26 的数组就是一张固定大小的“库存表”。

完整过程

  1. 创建长度为 26、初值全为 0 的计数数组。
  2. 遍历 magazine，把对应字母的计数加 1。
  3. 遍历 ransomNote，每需要一个字母就将对应计数减 1。
  4. 若任一计数减到负数，说明库存不足，立即返回 false。
  5. 全部取用成功后返回 true。

正确性证明

建立库存后，数组中每一项准确等于 magazine 中对应字母的出现次数。处理赎金信前 k 个字符后，每一项等于“杂志提供数量减去这 k 个字符已使用数量”。若某项为负，该字母需求必然超过供给，所以无法构成；若遍历结束仍无负数，则每种字母的需求都不超过供给，所有字符都能各自取用一次，因此一定可以构成。

边界情况

  • 同一字母重复出现时，必须逐次扣减，不能只判断“是否存在”。
  • 两串长度相等时，只有每种字母的数量都足够才返回真。
  • 长度达到 10^5 时仍只需线性扫描。
  • 若先发现某个字母不足，可以立即结束，无需扫描剩余字符。
O(m + n) 时间：分别扫描杂志与赎金信，其中 m、n 为两串长度。
O(1) 额外空间：计数数组固定为 26 个位置，与输入规模无关。

替代方案

  • 哈希表：适合字符集未知或包含 Unicode 的情况，但常数更大。
  • 排序后双指针：可以判断包含关系，但需要 O(m log m + n log n) 时间。
  • 每次查找并删除：实现直观，但反复查找和修改字符串可能退化到平方级。

常见错误

  • 只用集合记录出现过的字母，丢失重复次数。
  • 字母扣减后没有检查负数，导致库存不足仍返回真。
  • 用 indexOf 逐字搜索却忽略“每个字符只能使用一次”。
  • 把 26 大小的固定数组误记成 O(n) 空间。

面试追问

  • 如果输入包含任意 Unicode 字符，数据结构应如何调整？
  • 如果 magazine 是持续到达的数据流，何时可以提前给出结论？
  • 如果要同时判断很多封赎金信，怎样复用杂志的统计结果？
  • 若内存极其受限，还能否利用原字符串原地处理？

一句话记忆

先把 magazine 变成 26 格字母库存，再让 ransomNote 逐字领用；任何一格欠账，就无法构成。

四语言完整代码

Java · LeetCode 可提交
class Solution {
    public boolean canConstruct(String ransomNote, String magazine) {
        int[] count = new int[26];

        for (char c : magazine.toCharArray()) {
            count[c - 'a']++;
        }

        for (char c : ransomNote.toCharArray()) {
            if (--count[c - 'a'] < 0) {
                return false;
            }
        }

        return true;
    }
}

    for (const ch of magazine) {
        count[ch.charCodeAt(0) - 97]++;
    }

    for (const ch of ransomNote) {
        if (--count[ch.charCodeAt(0) - 97] < 0) {
            return false;
        }
    }

    return true;
};
Python · LeetCode 可提交
class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        count = [0] * 26

        for ch in magazine:
            count[ord(ch) - ord('a')] += 1

        for ch in ransomNote:
            index = ord(ch) - ord('a')
            count[index] -= 1
            if count[index] < 0:
                return False

        return True
