最小时间差

一只跨过午夜的 24 小时时钟。先观察时间点如何落在圆盘上，再决定怎样找出距离最近的一对。

数组 数学 字符串 排序

题目

给定一组采用 24 小时制 "HH:MM" 格式表示的时间点，请返回其中任意两个时间点之间的最小分钟差。时间按一天循环，因此午夜两侧也可能形成最短距离。

函数参数：findMinDifference(timePoints: List<String>) -> int

示例 1

输入：timePoints = ["23:59","00:00"]
输出：1

示例 2

输入：timePoints = ["00:00","23:59","00:00"]
输出：0

约束

  • 2 <= timePoints.length <= 2 × 10⁴
  • timePoints[i] 的格式为 "HH:MM"。

完整题解

核心洞察

把每个时间转换成从午夜起经过的分钟数并升序排列。线性数轴上的最短距离必然出现在相邻元素之间；而一天是环，仍需比较最后一个与第一个跨越午夜的距离 1440 - last + first。

完整过程

  1. 解析 HH:MM，计算 60 × HH + MM。
  2. 排序所有分钟数。
  3. 扫描每对相邻元素，维护最小差。
  4. 比较首尾的环形差并返回更小值。

正确性说明

排序后，若某个非相邻点对形成最小线性距离，它们之间至少还有一个时间点，因此其中一段相邻距离不会更大，产生矛盾。所以线性最优解包含在相邻对中。圆环上唯一未成为线性相邻对的是末尾与开头，补充跨午夜比较后覆盖了全部候选，算法返回全局最小值。

边界情况

  • 重复时间点会立即产生差值 0。
  • 23:59 与 00:00 的环形差为 1。
  • 若时间点多于 1440 个，根据鸽巢原理必有重复，答案一定为 0。

复杂度

排序方案时间复杂度 O(n log n)，额外空间 O(n)。使用 1440 个槽位的计数方案可达到 O(n + 1440) 时间与 O(1440) 空间。

替代方案

建立长度为 1440 的布尔数组。遇到重复槽位直接返回 0；随后扫描出现过的分钟，并比较连续槽位及首尾环形距离。常数空间非常适合固定的一天范围。

面试追问

  • 为什么只比较排序后的相邻元素？
  • 怎样利用输入上限提前返回 0？
  • 若时间精度变为秒，槽位法如何变化？
  • 若存在时区和夏令时，单纯分钟映射为何不再可靠？

常见错误

  • 漏掉首尾跨午夜的比较。
  • 把字符串按错误格式解析，或忘记小时乘 60。
  • 只计算绝对差，没有考虑环形距离。
  • 去重后再计算，导致漏掉正确答案 0。

import java.util.*;

class Solution {
    public int findMinDifference(List<String> timePoints) {
        int n = timePoints.size();
        if (n > 1440) return 0;
        int[] mins = new int[n];
        for (int i = 0; i < n; i++) {
            String s = timePoints.get(i);
            mins[i] = Integer.parseInt(s.substring(0, 2)) * 60
                    + Integer.parseInt(s.substring(3, 5));
        }
        Arrays.sort(mins);
        int ans = 1440 - mins[n - 1] + mins[0];
        for (int i = 1; i < n; i++) ans = Math.min(ans, mins[i] - mins[i - 1]);
        return ans;
    }
}

from typing import List

class Solution:
    def findMinDifference(self, timePoints: List[str]) -> int:
        if len(timePoints) > 1440:
            return 0
        mins = sorted(int(s[:2]) * 60 + int(s[3:]) for s in timePoints)
        ans = 1440 - mins[-1] + mins[0]
        for a, b in zip(mins, mins[1:]):
            ans = min(ans, b - a)
        return ans

public:
    int findMinDifference(vector<string>& timePoints) {

        vector<int> mins;
        for (const string& s : timePoints)
            mins.push_back(stoi(s.substr(0, 2)) * 60 + stoi(s.substr(3, 2)));
        sort(mins.begin(), mins.end());
        int ans = 1440 - mins.back() + mins.front();
        for (int i = 1; i < (int)mins.size(); ++i)
            ans = min(ans, mins[i] - mins[i - 1]);
        return ans;
    }
