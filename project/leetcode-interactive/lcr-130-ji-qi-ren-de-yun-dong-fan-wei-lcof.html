衣橱整理

给定 m × n 网格，机器人从 [0, 0] 出发，只能向右或向下移动。它不能进入行、列坐标各位数字之和大于 cnt 的格子。求机器人能到达的格子数量。

DFS / BFS网格遍历剪枝

示例

输入：m = 2, n = 3, cnt = 1
输出：3

可达格子：(0,0)、(0,1)、(1,0)

约束

  • 1 ≤ m, n ≤ 100
  • 0 ≤ cnt ≤ 20
  • 坐标从 [0, 0] 开始；数字和按十进制每一位相加。

分步交互：探索可达区域

演示网格为 4 × 5，阈值 cnt = 3。按“下一步”模拟队列取出一个可达格子并扩展右、下邻居。

当前处理已到达不可达

核心洞察

从起点做图遍历即可。某个格子若越界、已经访问，或坐标数字和超过阈值，就停止向它扩展。因为只允许向右、向下，搜索不会漏掉任何能从起点抵达的位置。

复杂度

最多访问 m × n 个格子。时间复杂度为 O(mn)，访问数组的空间复杂度为 O(mn)；递归 DFS 还会使用至多 O(mn) 的调用栈。

完整过程

  1. 准备 visited 标记已经到达的格子。
  2. 从 (0, 0) 开始检查边界、重复访问和数字和。
  3. 条件合格则计数加一，并递归或入队访问右、下邻居。
  4. 搜索结束时，计数就是可整理的衣橱格子数。

边界情况

  • cnt = 0 时通常只有原点可达。
  • 起点一定满足数字和限制，故答案至少为 1。
  • 行或列为 1 时，问题退化为一条路径。

替代方案

DFS 实现紧凑；BFS 使用显式队列，可避免深递归。还可通过递推维护数字和，减少重复计算，但在本约束下直接计算更清晰。

  • 如何避免二维数组？可用集合保存访问坐标，但空间量级不变。

  • 只比较 row + col，而不是各位数字之和。
    •

    • 
            
  • 越界检查晚于数组访问，导致异常。
