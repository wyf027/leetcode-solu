题目

给定长度均为 n 的字符串 s1、s2，以及字符串 evil，统计满足以下条件的字符串数量：

  • 长度恰好为 n；
  • 字典序位于闭区间 [s1, s2]；
  • 不包含 evil 作为连续子串。

答案可能很大，返回对 1,000,000,007 取模后的结果。

示例 1

输入：n = 2, s1 = "aa", s2 = "da", evil = "b"
输出：51

以 a 开头有 25 个，以 c 开头有 25 个，再加上 da。

示例 2

输入：n = 8, s1 = "leetcode", s2 = "leetgoes", evil = "leet"
输出：0

区间内每个字符串都以禁用串 leet 开头。

示例 3

输入：n = 2, s1 = "gx", s2 = "gz", evil = "x"
输出：2

有效字符串为 gy、gz。

约束

  • s1.length == n
  • s2.length == n
  • s1 <= s2
  • 1 <= n <= 500
  • 1 <= evil.length <= 50
  • 所有字符串仅含小写英文字母

核心洞察

把区间计数拆成 count(≤ s2) − count(≤ predecessor(s1))。在逐位构造字符串时，状态只需记录位置、当前与 evil 前缀匹配的长度，以及是否仍贴着上界。

KMP 自动机

匹配长度 matched 表示已构造字符串的最长后缀，恰好等于 evil 的长度为 matched 的前缀。预处理每个状态遇到 a～z 的转移；一旦转移到 m，说明 evil 已出现，舍弃该分支。

完整过程

  1. 用 KMP 前缀函数构建 evil 的失配信息，再得到 next[matched][letter]。
  2. 定义 dfs(pos, matched, tight)：填到 pos，当前 KMP 匹配长度为 matched；tight 表示此前前缀是否等于上界前缀。
  3. 本位枚举范围为 a 到 bound[pos]（tight 为真）或 z（tight 为假）。使用自动机得到新匹配长度。
  4. 若新长度等于 evil.length，跳过；否则递归到下一位。pos 到 n 时得到一个合法字符串。
  5. 分别计算上界 s2 和 s1 的固定长度字典序前驱，作差并规范化取模。
answer = (countLE(s2) − countLE(prev(s1)) + MOD) mod MOD

正确性说明

引理 1：上界状态完整

tight 为真时，本位不超过 bound[pos]；选得更小后 tight 永久为假。因此 DFS 恰好生成所有且仅生成不超过 bound 的长度 n 字符串，每个字符串对应唯一选择序列。

引理 2：禁串判断正确

KMP 状态始终等于当前字符串后缀与 evil 前缀的最大匹配长度。达到 m 当且仅当刚刚形成了 evil，因此被剪枝的分支恰为包含禁串的分支。

定理

countLE 由两引理计数所有不超过上界且不含 evil 的字符串。两个前缀集合之差恰好是闭区间 [s1,s2]，所以最终答案正确。

边界与复杂度

  • s1 全为 a 时没有同长度前驱，左侧计数视为 0。
  • evil 长度为 1 时，遇到该字符立即剪枝。
  • evil 可能长于尚未构造的前缀，matched 仍正常推进。
  • 所有加减都按 MOD 规范化，避免负数。

时间：O((n·m·26) + m·26)；空间：O(n·m + m·26)，递归栈 O(n)。

四语言完整代码

import java.util.Arrays;

class Solution {
    private static final int MOD = 1_000_000_007;
    private int n, m;
    private String evil, bound;
    private int[][] next;
    private long[][][] memo;

    public int findGoodStrings(int n, String s1, String s2, String evil) {
        this.n = n;
        this.evil = evil;
        this.m = evil.length();
        buildAutomaton();
        long right = countLE(s2);
        String beforeS1 = predecessor(s1);
        long left = beforeS1 == null ? 0 : countLE(beforeS1);
        return (int) ((right - left + MOD) % MOD);
    }

    private long countLE(String limit) {
        bound = limit;
        memo = new long[n][m][2];
        for (long[][] layer : memo)
            for (long[] row : layer) Arrays.fill(row, -1);
        return dfs(0, 0, 1);
    }

    private long dfs(int pos, int matched, int tight) {
        if (pos == n) return 1;
        if (memo[pos][matched][tight] != -1) return memo[pos][matched][tight];
        int upper = tight == 1 ? bound.charAt(pos) - 'a' : 25;
        long ways = 0;
        for (int c = 0; c <= upper; c++) {
            int nextMatched = next[matched][c];
            if (nextMatched == m) continue;
            int nextTight = tight == 1 && c == upper ? 1 : 0;
            ways = (ways + dfs(pos + 1, nextMatched, nextTight)) % MOD;
        }
        return memo[pos][matched][tight] = ways;
    }

    private void buildAutomaton() {
        int[] lps = new int[m];
        for (int i = 1, j = 0; i < m; i++) {
            while (j > 0 && evil.charAt(i) != evil.charAt(j)) j = lps[j - 1];
            if (evil.charAt(i) == evil.charAt(j)) j++;
            lps[i] = j;
        }
        next = new int[m][26];
        for (int state = 0; state < m; state++) {
            for (int c = 0; c < 26; c++) {
                char ch = (char) ('a' + c);
                int j = state;
                while (j > 0 && evil.charAt(j) != ch) j = lps[j - 1];
                if (evil.charAt(j) == ch) j++;
                next[state][c] = j;
            }
        }
    }

    private String predecessor(String s) {
        char[] a = s.toCharArray();
        int i = a.length - 1;
        while (i >= 0 && a[i] == 'a') a[i--] = 'z';
        if (i < 0) return null;
        a[i]--;
        return new String(a);
    }
}

var findGoodStrings = function(n, s1, s2, evil) {
    const MOD = 1000000007;
    const m = evil.length;
    const lps = new Array(m).fill(0);
    for (let i = 1, j = 0; i < m; i++) {
        while (j > 0 && evil[i] !== evil[j]) j = lps[j - 1];
        if (evil[i] === evil[j]) j++;
        lps[i] = j;
    }

    const next = Array.from({ length: m }, () => new Array(26).fill(0));
    for (let state = 0; state < m; state++) {
        for (let c = 0; c < 26; c++) {
            const ch = String.fromCharCode(97 + c);
            let j = state;
            while (j > 0 && evil[j] !== ch) j = lps[j - 1];
            if (evil[j] === ch) j++;
            next[state][c] = j;
        }
    }

    const countLE = (bound) => {
        const memo = Array.from({ length: n }, () =>
            Array.from({ length: m }, () => [-1, -1]));
        const dfs = (pos, matched, tight) => {
            if (pos === n) return 1;
            if (memo[pos][matched][tight] !== -1) return memo[pos][matched][tight];
            const upper = tight ? bound.charCodeAt(pos) - 97 : 25;
            let ways = 0;
            for (let c = 0; c <= upper; c++) {
                const nm = next[matched][c];
                if (nm === m) continue;
                ways = (ways + dfs(pos + 1, nm, tight && c === upper ? 1 : 0)) % MOD;
            }
            memo[pos][matched][tight] = ways;
            return ways;
        };
        return dfs(0, 0, 1);
    };

    const predecessor = (s) => {
        const a = [...s];
        let i = a.length - 1;
        while (i >= 0 && a[i] === 'a') { a[i] = 'z'; i--; }
        if (i < 0) return null;
        a[i] = String.fromCharCode(a[i].charCodeAt(0) - 1);
        return a.join('');
    };

    const leftBound = predecessor(s1);
    const right = countLE(s2);
    const left = leftBound === null ? 0 : countLE(leftBound);
    return (right - left + MOD) % MOD;
};
from functools import lru_cache

class Solution:
    def findGoodStrings(self, n: int, s1: str, s2: str, evil: str) -> int:
        MOD = 1_000_000_007
        m = len(evil)
        lps = [0] * m
        j = 0
        for i in range(1, m):
            while j and evil[i] != evil[j]:
                j = lps[j - 1]
            if evil[i] == evil[j]:
                j += 1
            lps[i] = j

        nxt = [[0] * 26 for _ in range(m)]
        for state in range(m):
            for c in range(26):
                ch = chr(97 + c)
                j = state
                while j and evil[j] != ch:
                    j = lps[j - 1]
                if evil[j] == ch:
                    j += 1
                nxt[state][c] = j

        def count_le(bound: str) -> int:
            @lru_cache(None)
            def dfs(pos: int, matched: int, tight: bool) -> int:
                if pos == n:
                    return 1
                upper = ord(bound[pos]) - 97 if tight else 25
                ways = 0
                for c in range(upper + 1):
                    nm = nxt[matched][c]
                    if nm == m:
                        continue
                    ways += dfs(pos + 1, nm, tight and c == upper)
                return ways % MOD
            return dfs(0, 0, True)

        def predecessor(s: str):
            chars = list(s)
            i = len(chars) - 1
            while i >= 0 and chars[i] == 'a':
                chars[i] = 'z'
                i -= 1
            if i < 0:
                return None
            chars[i] = chr(ord(chars[i]) - 1)
            return ''.join(chars)

        before_s1 = predecessor(s1)
        left = 0 if before_s1 is None else count_le(before_s1)
        return (count_le(s2) - left) % MOD
class Solution {
    static constexpr int MOD = 1'000'000'007;
    int n, m;
    string evil, bound;
    vector<array<int, 26>> go;
    vector<vector<array<int, 2>>> memo;

    int dfs(int pos, int matched, int tight) {
        if (pos == n) return 1;
        int &cached = memo[pos][matched][tight];
        if (cached != -1) return cached;
        int upper = tight ? bound[pos] - 'a' : 25;
        long long ways = 0;
        for (int c = 0; c <= upper; ++c) {
            int nm = go[matched][c];
            if (nm == m) continue;
            ways += dfs(pos + 1, nm, tight && c == upper);
            ways %= MOD;
        }
        return cached = static_cast<int>(ways);
    }

    int countLE(const string &limit) {
        bound = limit;
        memo.assign(n, vector<array<int, 2>>(m, array<int, 2>{-1, -1}));
        return dfs(0, 0, 1);
    }

    optional<string> predecessor(string s) {
        int i = static_cast<int>(s.size()) - 1;
        while (i >= 0 && s[i] == 'a') s[i--] = 'z';
        if (i < 0) return nullopt;
        --s[i];
        return s;
    }

public:
    int findGoodStrings(int length, string s1, string s2, string forbidden) {
        n = length;
        evil = std::move(forbidden);
        m = evil.size();

        vector<int> lps(m);
        for (int i = 1, j = 0; i < m; ++i) {
            while (j > 0 && evil[i] != evil[j]) j = lps[j - 1];
            if (evil[i] == evil[j]) ++j;
            lps[i] = j;
        }

        go.assign(m, {});
        for (int state = 0; state < m; ++state) {
            for (int c = 0; c < 26; ++c) {
                char ch = static_cast<char>('a' + c);
                int j = state;
                while (j > 0 && evil[j] != ch) j = lps[j - 1];
                if (evil[j] == ch) ++j;
                go[state][c] = j;
            }
        }

        int right = countLE(s2);
        auto before = predecessor(s1);
        int left = before ? countLE(*before) : 0;
        return (right - left + MOD) % MOD;
    }
};

替代方案

也可一次做四维 DP：(pos, matched, lowerTight, upperTight)，直接在 [s1,s2] 内枚举。它省去求前驱，但状态和转移更复杂。两种方法的渐进复杂度相同；“两次上界计数”通常更易复用与证明。

面试追问

  • 为什么只保留最长匹配后缀就够？
  • 如何把字符集从 26 个字母扩展为任意有序字符集？
  • 如果有多个 evil，如何改用 Aho–Corasick 自动机？
  • 怎样改写为自底向上的滚动数组，将 DP 空间降到 O(m)？

常见错误

  • 用普通子串搜索检查每个候选前缀，导致状态无法复用、复杂度失控。
  • KMP 转移失败时只退一次，而不是循环退到可匹配前缀。
  • 把到达 matched == m 的状态继续递归，错误计入已经出现 evil 的字符串。
  • 区间做差时使用 count(≤s2) − count(≤s1)，漏掉 s1 本身。
  • 紧贴上界的下一状态写成 c == bound[pos]，却忘了还要满足当前 tight。
