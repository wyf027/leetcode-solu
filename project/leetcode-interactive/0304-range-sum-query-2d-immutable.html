Range Sum Query 2D — Immutable

二维区域和检索
矩阵不可变

矩阵一经初始化便不再改变。你需要回答大量矩形区域求和查询，并让每次查询达到 O(1)。先理解任务，再用交互区观察一个矩形如何被四块前缀区域拼出来。

题目

给定整数矩阵 matrix，需要处理多次查询。每次查询由左上角 (row1, col1) 和右下角 (row2, col2) 定义一个闭合矩形，返回其中所有元素之和。

接口：NumMatrix(int[][] matrix) 初始化对象；int sumRegion(int row1, int col1, int row2, int col2) 返回指定矩形区域和。要求每次 sumRegion 的时间复杂度为 O(1)。

约束

  • m == matrix.length，n == matrix[i].length
  • 1 ≤ m, n ≤ 200
  • -10⁴ ≤ matrix[i][j] ≤ 10⁴
  • 0 ≤ row1 ≤ row2 < m
  • 0 ≤ col1 ≤ col2 < n
  • 最多调用 sumRegion 10⁴ 次

Solution

二维前缀和题解

核心洞察

查询很多、矩阵不变，适合把重复工作提前到构造阶段。令 pre[r][c] 表示原矩阵从 (0,0) 到 (r-1,c-1) 的矩形和，并额外保留第 0 行、第 0 列作为零边界。

完整过程

  1. 创建大小为 (m+1) × (n+1) 的前缀表。
  2. 逐格计算 pre[i+1][j+1] = matrix[i][j] + pre[i][j+1] + pre[i+1][j] - pre[i][j]。
  3. 查询时取右下大矩形，扣掉上方和左方，再加回被重复扣除的左上角。
查询公式
pre[row2+1][col2+1] − pre[row1][col2+1] − pre[row2+1][col1] + pre[row1][col1]

正确性证明

根据定义，pre[row2+1][col2+1] 覆盖查询矩形以及它上方、左方的所有元素。减去 pre[row1][col2+1] 后移除查询上方；减去 pre[row2+1][col1] 后移除查询左方。左上重叠区域在这两次减法中被减了两次，而在原大矩形里只出现一次，因此加回 pre[row1][col1]。剩余元素恰好且仅为查询矩形内元素，公式正确。

边界

  • 单行、单列和单元素无需分支。
  • row1=0 或 col1=0 时，零边界自然生效。
  • 负数不影响容斥关系。
  • 整张矩阵查询直接得到末格前缀和。

复杂度

  • 构造：时间 O(mn)，空间 O(mn)。
  • 每次查询：时间 O(1)，额外空间 O(1)。

替代方案

逐行前缀和可用 O(mn) 空间、O(row2-row1+1) 查询；暴力逐格查询为 O(mn)。它们实现简单，但不满足本题要求的 O(1) 查询。

常见错误

  • 忘记加回左上重叠区域。
  • 混淆原矩阵 0 下标与前缀表 1 下标，尤其漏写 row2+1、col2+1。
  • 前缀构造时没有减去被重复加入的左上角。
  • 误以为矩阵会更新；若支持更新，应改用二维树状数组等结构。

面试追问

  • 若允许单点更新？ 使用二维树状数组：更新、查询均 O(log m · log n)。
  • 能否省空间？ 仅做少量查询可逐行累加，但会牺牲 O(1) 查询；严格要求下通常保留二维前缀表。
  • 为什么多一行一列？ 用哨兵零边界消除四种边缘条件，使构造和查询使用同一公式。

Java
class NumMatrix {
    private final int[][] pre;

    public NumMatrix(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        pre = new int[m + 1][n + 1];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                pre[i + 1][j + 1] = matrix[i][j]
                    + pre[i][j + 1] + pre[i + 1][j] - pre[i][j];
            }
        }
    }

    public int sumRegion(int row1, int col1, int row2, int col2) {
        return pre[row2 + 1][col2 + 1] - pre[row1][col2 + 1]
             - pre[row2 + 1][col1] + pre[row1][col1];
    }
}

var NumMatrix = function(matrix) {

    this.pre = Array.from({ length: m + 1 }, () => Array(n + 1).fill(0));

            this.pre[i + 1][j + 1] = matrix[i][j]
                + this.pre[i][j + 1] + this.pre[i + 1][j] - this.pre[i][j];
        }
    }
};

from typing import List

class NumMatrix:
    def __init__(self, matrix: List[List[int]]):
        m, n = len(matrix), len(matrix[0])
        self.pre = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                self.pre[i + 1][j + 1] = (
                    matrix[i][j] + self.pre[i][j + 1]
                    + self.pre[i + 1][j] - self.pre[i][j]
                )

    def sumRegion(self, row1: int, col1: int, row2: int, col2: int) -> int:
        return (self.pre[row2 + 1][col2 + 1]
                - self.pre[row1][col2 + 1]
                - self.pre[row2 + 1][col1]
                + self.pre[row1][col1])

class NumMatrix {
    vector<vector<int>> pre;
public:
    NumMatrix(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        pre.assign(m + 1, vector<int>(n + 1, 0));
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                pre[i + 1][j + 1] = matrix[i][j]
                    + pre[i][j + 1] + pre[i + 1][j] - pre[i][j];
            }
        }
    }

    int sumRegion(int row1, int col1, int row2, int col2) {
        return pre[row2 + 1][col2 + 1] - pre[row1][col2 + 1]
             - pre[row2 + 1][col1] + pre[row1][col1];
    }
};
