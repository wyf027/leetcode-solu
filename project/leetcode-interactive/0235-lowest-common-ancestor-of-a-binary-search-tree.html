Lowest Common Ancestor of a Binary Search Tree

BST 的每个节点都把值域分成两半。若两个目标都小于当前节点，公共祖先只能在左子树；都大于则只能在右子树；第一次不再同侧的节点，就是最低公共祖先。

题意与约束

🌲 BST · 区间收缩

给定二叉搜索树根节点 root 以及其中两个不同节点 p、q，返回它们的最低公共祖先（LCA）。最低指该祖先在树中深度尽可能大，且自身也可以是 p 或 q。

题解 · 两个目标的分叉点

核心洞察

设 low = min(p.val, q.val)、high = max(...)。当前节点值小于 low，两个目标都在右边；大于 high，都在左边；否则当前值落在目标区间内，两个路径在此分叉（或当前节点正是目标），它就是 LCA。

完整过程

  1. 规范化两个目标为 low 与 high。
  2. 从根迭代：若 root.val < low，移动到右孩子。
  3. 若 root.val > high，移动到左孩子。
  4. 否则返回当前节点。

复杂度与边界

只走一条根到节点的路径：时间 O(h)，迭代额外空间 O(1)，其中 h 是树高。平衡 BST 为 O(log n)，最坏退化链为 O(n)。

  • 一个目标就是另一个的祖先：该目标节点返回。
  • 目标分居当前节点两边：当前节点返回。
  • 不能只比较其中一个目标：必须判断两者是否同侧。

替代方案取舍

普通二叉树没有大小关系，需要后序递归同时从左右子树返回命中情况，时间 O(n)。BST 的排序不变量让我们无需搜索整棵树。

常见错误：遗漏“当前节点等于 p 或 q”的情况；未先取 min/max 导致 p、q 顺序影响逻辑；或误把普通二叉树 LCA 的递归模板直接套用，浪费 BST 性质。

面试追问

若节点不存在？题目保证存在；扩展题可先验证路径。若树允许重复值？应以节点引用而非值区分，并重新定义 BST 规则。若要递归版？逻辑相同，但深树可能造成栈溢出。

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        int low = Math.min(p.val, q.val), high = Math.max(p.val, q.val);
        while (root != null) {
            if (root.val < low) root = root.right;
            else if (root.val > high) root = root.left;
            else return root;
        }
        return null;
    }
}
