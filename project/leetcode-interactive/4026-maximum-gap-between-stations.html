LEETCODE 4026 · MEDIUM

工位的最大间隔

用两次贪心匹配，把每个相邻工人的“最左”和“最右”边界同时看清：最大间隔就藏在两条轨迹之间。

字符串贪心双指针O(n + m)

题意

给定 skill（工人技能序列）和 station（工位支持的技能序列）。为每位工人分配一个不同工位，且分配下标必须严格递增；技能必须相同。

一个方案的间隔是相邻两位工人的工位下标差的最大值。请返回所有有效方案中，可能达到的最大间隔。

约束：1 ≤ skill.length ≤ station.length ≤ 10⁵，且保证存在有效方案。仅一位工人时答案为 0。

核心洞察

固定分界 i | i+1。要把这对相邻工人拉得最开，左边工人应在“前缀仍可完成”的最早位置，右边工人应在“后缀仍可完成”的最晚位置。
  1. 从左扫，记录每个 skill[i] 的最早可选工位 earliest[i]。
  2. 从右扫，记录每个 skill[i] 的最晚可选工位 latest[i]。
  3. 答案为所有 latest[i] - earliest[i - 1] 的最大值。

交互实验室

输入小写字母字符串。按 Enter 可运行；左右方向键切换代码语言。

完整过程：cbc → cbcdbc

  1. 左扫匹配到 c@0, b@1, c@2，所以 earliest = [0,1,2]。
  2. 右扫匹配到 c@5, b@4, c@3（反向记录后），所以 latest = [3,4,5]。
  3. 分界 0|1：4 - 0 = 4；分界 1|2：5 - 1 = 4，答案为 4。

注意：两条轨迹不是同一个完整方案；它们是针对每个分界的左右极限，用于证明可达到的最大差。

边界与易错点

  • n = 1：没有相邻对，直接返回 0。
  • 重复字符：不能只记录字符第一次/最后一次出现；必须保留顺序可完成性。
  • 下标差：题目要 j[i] - j[i-1]，不是中间空位数，因此不减 1。
  • 非贪心枚举：指数级方案无需枚举；每侧的极端贪心已给出每个分界的最优界。

隐藏题解与四语言实现

正确性要点：对任意分界 i-1 | i，左侧若不取尽可能靠左的可完成位置，向左替换不会破坏此前顺序；右侧同理可向右替换。因此该分界可达到的最大间隔就是 latest[i] - earliest[i-1]。枚举全部分界即得到全局答案。 

class Solution {
  public int maximumGap(String skill, String station) {
    int n = skill.length(), m = station.length();
    if (n == 1) return 0;
    int[] early = new int[n], late = new int[n];
    for (int i = 0, p = 0; i < n; i++) {
      while (station.charAt(p) != skill.charAt(i)) p++;
      early[i] = p++;
    }
    for (int i = n - 1, p = m - 1; i >= 0; i--) {
      while (station.charAt(p) != skill.charAt(i)) p--;
      late[i] = p--;
    }
    int ans = 0;
    for (int i = 1; i < n; i++) ans = Math.max(ans, late[i] - early[i - 1]);
    return ans;
  }
}
function maximumGap(skill, station) {
  const n = skill.length, early = Array(n), late = Array(n);
  if (n === 1) return 0;
  for (let i = 0, p = 0; i < n; i++) {
    while (station[p] !== skill[i]) p++;
    early[i] = p++;
  }
  for (let i = n - 1, p = station.length - 1; i >= 0; i--) {
    while (station[p] !== skill[i]) p--;
    late[i] = p--;
  }
  return Math.max(...late.slice(1).map((x, i) => x - early[i]));
}
class Solution:
    def maximumGap(self, skill: str, station: str) -> int:
        n = len(skill)
        if n == 1: return 0
        early, late = [0] * n, [0] * n
        p = 0
        for i, ch in enumerate(skill):
            while station[p] != ch: p += 1
            early[i] = p; p += 1
        p = len(station) - 1
        for i in range(n - 1, -1, -1):
            while station[p] != skill[i]: p -= 1
            late[i] = p; p -= 1
        return max(late[i] - early[i - 1] for i in range(1, n))

public:

      late[i] = p--;

    int ans = 0;
    for (int i = 1; i < n; ++i) ans = max(ans, late[i] - early[i - 1]);
    return ans;
  }
};

复杂度

O(n + m)

两根指针各自单调移动，额外保存两条长度 n 的边界数组，空间 O(n)。

替代思路

可先构造左匹配，再从右扫描更新答案；本质仍是双向边界。二分答案不自然：判定“是否存在某个足够大的间隔”还要选分界，反而更复杂。

追问

若要返回造成最大间隔的分界，只在更新答案时保存 i - 1；若要求最小化最大间隔，则问题会转向另一类可行性/动态规划设计。
