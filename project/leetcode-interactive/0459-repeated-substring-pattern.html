Solution

用最长相等前后缀锁定最短周期

KMP 的前缀函数不仅能匹配文本，也能刻画字符串自身的周期。

核心洞察

令 L = π[n - 1]，它表示整个字符串的最长相等真前缀与真后缀长度。若字符串存在重复单元，最短候选周期就是 p = n - L。

最终条件是：L > 0 且 n % p == 0。第二个条件确保候选片段恰好铺满字符串，不能只凭“有相等前后缀”下结论。

完整过程

  1. 线性计算字符串的前缀函数数组 π。
  2. 取末项 L = π[n - 1]，得到候选周期 p = n - L。
  3. 检查 L > 0 且字符串长度能被 p 整除。

为什么正确

充分性：若 L > 0 且 p = n - L 整除 n，相等前后缀给出 s[i] = s[i - p]（对所有 i ≥ p）。因此每个字符都等于其在首个长度为 p 片段中的对应字符，整个字符串由该片段重复 n / p 次构成。

必要性：若 s 由长度为 p < n 的片段重复构成，则长度为 n - p 的前缀与后缀相等，所以最长边界 L ≥ n - p > 0。最短周期与最长边界满足 p = n - L，且重复必然要求 p 整除 n。

边界与陷阱

  • n = 1 时不存在更短非空子串，返回 false。
  • 全相同字符的最短周期为 1。
  • "ababa" 有长度为 3 的相等前后缀，但候选周期 2 不能整除 5，仍应返回 false。
  • 构造前缀函数时，失配要反复回退到 π[j - 1]，而不是简单把 j 清零。

复杂度

时间复杂度：O(n)。虽然存在内层回退循环，但指针总移动次数是线性的。

空间复杂度：O(n)，用于保存前缀函数数组。

四语言完整实现

均采用相同的 KMP 前缀函数思路；代码容器可独立横向滚动。

class Solution {
    public boolean repeatedSubstringPattern(String s) {
        int n = s.length();
        int[] pi = new int[n];

        for (int i = 1; i < n; i++) {
            int j = pi[i - 1];
            while (j > 0 && s.charAt(i) != s.charAt(j)) {
                j = pi[j - 1];
            }
            if (s.charAt(i) == s.charAt(j)) {
                j++;
            }
            pi[i] = j;
        }

        int longestBorder = pi[n - 1];
        int period = n - longestBorder;
        return longestBorder > 0 && n % period == 0;
    }
}

替代方案

双倍字符串：若 s 可重复构成，那么它会出现在 (s + s) 去掉首尾字符后的字符串中。写法短，但底层查找复杂度依赖语言实现，且会创建额外字符串。

枚举因子：枚举所有能整除 n 的候选周期并逐字符检查。思路直观，最坏可能达到 O(n²)。

面试追问

  • 为什么最长相等前后缀本身不够，必须再检查整除？
  • 能否只用常数额外空间？双倍字符串方案的实际空间成本是什么？
  • 如果输入以字符流到达，如何在线维护前缀函数？
  • 如何返回最短重复单元，而不仅是布尔值？

常见错误

  • 把整个字符串也当作可重复的“子串”，导致长度 1 时误判。
  • 只判断 π[n - 1] > 0，忽略铺满条件。
  • 失配时使用 j--，破坏 KMP 的线性复杂度。
  • 在不同语言中混淆字符索引与字节索引；本题限定小写英文字母，因此官方约束下没有多字节字符问题。

举一反三

前缀函数还可以用于查找字符串的所有边界、统计前缀出现次数、寻找最短循环节，以及完成经典模式匹配。掌握“失配后跳到次长可用边界”，比记住一个公式更重要。
