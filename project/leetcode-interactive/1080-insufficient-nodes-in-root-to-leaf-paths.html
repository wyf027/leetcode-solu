根到叶路径上的
不足节点

Insufficient Nodes in Root to Leaf Paths

一次自底向上的判断：只有无法通向任何“达标根到叶路径”的节点，才会消失。

题目

给定二叉树根节点 root 和整数 limit。如果经过某节点的每一条完整根到叶路径，其节点值总和都严格小于 limit，该节点就是不足节点。请同时删除全部不足节点，并返回剩余树的根节点。

函数形式： sufficientSubset(root: TreeNode, limit: integer): TreeNode
注意：叶子是没有任何子节点的节点；删除后，原本的内部节点可能成为叶子。

官方示例

示例 1
输入：root = [1,2,3,4,-99,-99,7,8,9,-99,-99,12,13,-99,14], limit = 1
输出：[1,2,3,4,null,null,7,8,9,null,14]
示例 2
输入：root = [5,4,8,11,null,17,4,7,1,null,null,5,3], limit = 22
输出：[5,4,8,11,null,17,4,7,null,null,null,5]
示例 3
输入：root = [1,2,-3,-5,null,4,null], limit = -1
输出：[1,null,-3,4]

约束

  • 节点数在 [1, 5000] 内。
  • -10^5 ≤ Node.val ≤ 10^5。
  • -10^9 ≤ limit ≤ 10^9。

题解

核心洞察

走到节点时把累计和带下来。对原树中的叶子，若累计和小于 limit 就返回空；对内部节点，先递归改写左右孩子，若两边最终都为空，说明它不能通向任何达标的原始叶路径，也返回空。

完整过程

  1. 从根开始 DFS，参数记录根到当前节点之前的路径和。
  2. 加入当前值；若当前节点原本就是叶子，直接按总和判定。
  3. 递归处理左右子树，并把返回值写回左右指针。
  4. 若两个孩子都被删除，则当前节点也删除；否则保留。

正确性

归纳命题：DFS 返回非空，当且仅当当前节点的子树中存在一条原树叶路径，使“根到该叶”的和至少为 limit。叶节点处由和的比较直接成立。内部节点处，只要任一子调用非空，就存在一条达标路径并应保留当前节点；两者皆空则所有相关路径均不足。由结构归纳，根节点的返回值正是题目要求的树。

复杂度

时间 O(n)；递归栈 O(h)，最坏 O(n)。

边界

单节点、负值与负 limit、根也被删除、极端链形树。

替代方案

也可让 DFS 返回当前节点到叶子的最大后缀和，再与剩余预算比较；语义等价。

常见错误

  • 在孩子删除后才把当前节点当作“原始叶子”比较累计和，混淆了路径终点。
  • 只判断某一条路径不足，而不是所有经过该节点的根到叶路径都不足。
  • 先序直接删除，尚未获得子树是否存在达标路径的信息。

面试追问

  • 若不能修改原树，如何复制并剪枝？
  • 递归深度可能溢出时，如何用显式栈模拟后序遍历？
  • 若阈值频繁变化，能否预处理每个节点通向叶子的最大路径和？

四种语言实现

class Solution {
    public TreeNode sufficientSubset(TreeNode root, int limit) {
        return dfs(root, 0L, limit);
    }
    private TreeNode dfs(TreeNode node, long sum, int limit) {
        if (node == null) return null;
        sum += node.val;
        if (node.left == null && node.right == null)
            return sum >= limit ? node : null;
        node.left = dfs(node.left, sum, limit);
        node.right = dfs(node.right, sum, limit);
        return node.left == null && node.right == null ? null : node;
    }
}

    node.right = dfs(node.right, sum);

  }
  return dfs(root, 0);

class Solution:
    def sufficientSubset(self, root: Optional[TreeNode], limit: int) -> Optional[TreeNode]:
        def dfs(node, total):
            if not node:
                return None
            total += node.val
            if not node.left and not node.right:
                return node if total >= limit else None
            node.left = dfs(node.left, total)
            node.right = dfs(node.right, total)
            return node if node.left or node.right else None
        return dfs(root, 0)
