3894. 交通信号灯的颜色

把剩余秒数映射成信号灯状态：三个精确条件之外，一律是 "Invalid"。用可点击时间点观察分类边界。

主线：直接条件分支

题意

给定 timer（交通信号灯的剩余秒数）：timer == 0 返回 "Green"；timer == 30 返回 "Orange"；30 < timer <= 90 返回 "Red"；其他情况返回 "Invalid"。

判定规则

timer == 0 → Green
timer == 30 → Orange
30 < timer <= 90 → Red
其余 → Invalid

官方示例

timer = 60 → "Red"；timer = 5 → "Invalid"。约束：0 <= timer <= 1000。

交互：点亮当前状态

当前输入
timer = 60 → Red

60 落在区间 30 < timer <= 90。

题解

默认折叠，避免首屏直接展示解法。

核心洞察

规则只有四类，且前两类是单点；按“0、30、红灯区间、默认”依次判断即可。不要把 timer = 30 误归入红灯。

完整过程

  1. 若 timer == 0，立即返回 Green。
  2. 否则若 timer == 30，返回 Orange。
  3. 否则若 timer > 30 && timer <= 90，返回 Red。
  4. 否则返回 Invalid。
时间复杂度
O(1)
空间复杂度
O(1)

边界与替代方案

重点检查 0、30、31、90、91。也可以写成查表或多个三元表达式，但直接分支最清晰、最易维护。

面试追问与常见错误

若规则持续增加，可将条件抽成有序规则表；当前规模下无需过度抽象。常见错误是把红灯写成 timer >= 30，导致 30 被错误分类。
