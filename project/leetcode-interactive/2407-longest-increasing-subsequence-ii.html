最长递增子序列 II

Longest Increasing Subsequence II

保持顺序，严格上升，每一步的跨度都不能超过 k。
你能留下多少个数字？

子序列 ≠ 连续子数组相邻差值 ≤ k免费题

01 / PROBLEM

题目与输入

给定整数数组 nums 和整数 k。从数组中按原顺序选取若干元素，使选出的元素严格递增，且所选序列中每一对相邻元素的差不超过 k。返回能够选出的最大长度。

可以删除任意位置的元素，也可以不删除；剩余元素不能重排。差值约束针对选出序列的相邻元素，不是原数组相邻位置。

函数形式

lengthOfLIS(nums, k) → integer

官方约束

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i], k ≤ 10⁵

05 / SOLUTION LAB

准备好查看题解了吗？

值域动态规划 + 线段树

核心洞察

按原数组从左到右处理。设 best[v] 为已经处理的元素中，以值 v 结尾的合法子序列最大长度。当前值是 x 时，前驱值必须满足 x − k ≤ v < x。因此，问题变成了“值域区间最大值查询 + 单点取最大值更新”。

cur = 1 + max(best[v]), v ∈ [max(1, x−k), x−1]
best[x] = max(best[x], cur)

空区间最大值视为 0，代表从当前元素重新开始。线段树叶子记录每个值的 best，内部节点记录所覆盖值域的最大值。

访问的线段树节点

完整过程

  1. 令 M 为 nums 的最大值，选取不小于 M 的最小二次幂 S。用长度 2S 的数组表示线段树；值 v 对应叶子 S + v − 1，所有节点初始为 0。
  2. 顺序读取 x。把闭区间 [max(1,x−k),x−1] 转成叶子下标，向上查询其最大值 q。左右边界每层至多选两个节点，选出的区间互不相交。
  3. 令 cur = q + 1；先完成查询，再更新 x 的叶子为原值和 cur 的最大值，并向上重新计算父节点最大值。
  4. 处理完全部元素后，根节点保存所有结尾值中的最大长度，即答案。

以示例 1 为例，每次计算的 cur 依次为 [1,1,1,2,2,3,4,5,1]。处理 8 时查询 [5,7] 得到 4，从而产生长度 5；处理 15 时查询 [12,14] 得到 0，只能形成长度 1，根节点仍为 5。

正确性证明

不变量：处理前 i 个元素后，叶子 v 恰好保存这些元素中以 v 结尾的最优长度，内部节点是对应叶子的最大值。

  1. 初始：没有元素时，不存在非空子序列，各叶子为 0，不变量成立。
  2. 转移的上界：任何以当前 x 结尾、长度大于 1 的合法序列，倒数第二个元素一定已出现，且值在 [x−k,x−1]。删去 x 后，长度不超过该区间已有最优值 q，因此总长度不超过 q+1。
  3. 上界可达：若 q>0，在达到 q 的合法序列后追加 x，顺序、严格递增、差值上限都成立；若 q=0，单元素序列 [x] 达到长度 1。
  4. 保持与结束：当前元素只会新增以 x 结尾的序列，对叶子 x 取最大值并更新祖先即可保持不变量。最终根节点取遍所有结尾值，故为全局最优。

边界与常见错误

  • x=1 时前驱区间为空，查询返回 0。
  • 不能包含 x 本身；右端必须是 x−1，否则重复值会错误延长。
  • 左端 x−k 是允许的，不能排除差值恰为 k 的前驱。
  • 必须按原下标处理，不能排序 nums 后计算。
  • k 大于 x 时将左边界截到 1。
  • 更新要保留已有最优值，不能把叶子当作出现次数累加。
  • 叶子映射减 1；填充到二次幂的虚拟叶子保持 0。

复杂度

设 n 为元素个数，M = max(nums)，S 是不小于 M 的最小二次幂，满足 M ≤ S < 2M。

  • 时间：O(M + n log(M+1))，包含数组初始化；常见简写为 O(n log M + M)。
  • 额外空间：O(M)，长度 2S 的线段树。
  • 可视化会保存逐帧状态，因此只接收小输入；四份提交代码均不保存历史帧。

替代方案及局限

  • 按下标的 O(n²) DP：枚举 j<i 且 0<nums[i]−nums[j]≤k，求 dp[i]。最直观，可用于小规模理解，n=10⁵ 时过慢。
  • 坐标压缩 + 线段树：若值域很大，排序去重并用二分定位 x−k 与 x−1 对应的原值区间，空间变为 O(n)。不能直接拿压缩后的排名减 k，因为排名差不是数值差。
  • 普通 LIS 的 tails 贪心：单纯保留相同长度的最小结尾会丢失有用状态。例如 nums=[4,1,5], k=2：把长度 1 的结尾 4 替换成 1 后，会漏掉 [4,5]。
  • 普通最大值树状数组：擅长前缀最大值，两个前缀最大值无法相减得到任意区间最大值，不能照搬前缀和写法。

面试追问

  • 如何还原序列？节点保存“长度、末尾下标”，查询时拿到最优前驱下标；为每个位置记录父指针，最后从最优末尾回溯。
  • 改成非递减呢？查询右端改为 x，但必须在本轮更新前查询，避免重复使用当前元素。
  • 每个位置有不同 k 呢？用当前 k[i] 计算查询左边界，处理顺序和树结构不变。
  • 允许删除历史元素呢？当前单调取最大值的叶子不足以撤销贡献，需要额外维护同值候选与可删除状态，不能直接复用更新逻辑。

Java

class Solution {
    public int lengthOfLIS(int[] nums, int k) {
        int m = 0;
        for (int x : nums) m = Math.max(m, x);
        int size = 1;
        while (size < m) size <<= 1;
        int[] tree = new int[size * 2];
        for (int x : nums) {
            int l = size + Math.max(1, x - k) - 1;
            int r = size + x - 2;
            int best = 0;
            while (l <= r) {
                if ((l & 1) == 1) best = Math.max(best, tree[l++]);
                if ((r & 1) == 0) best = Math.max(best, tree[r--]);
                l >>= 1;
                r >>= 1;
            }
            int p = size + x - 1;
            tree[p] = Math.max(tree[p], best + 1);
            for (p >>= 1; p > 0; p >>= 1) {
                tree[p] = Math.max(tree[p * 2], tree[p * 2 + 1]);
            }
        }
        return tree[1];
    }
}

Python 3

from typing import List

class Solution:
    def lengthOfLIS(self, nums: List[int], k: int) -> int:
        size = 1
        while size < max(nums):
            size *= 2
        tree = [0] * (size * 2)
        for x in nums:
            left = size + max(1, x - k) - 1
            right = size + x - 2
            best = 0
            while left <= right:
                if left & 1:
                    best = max(best, tree[left])
                    left += 1
                if not (right & 1):
                    best = max(best, tree[right])
                    right -= 1
                left //= 2
                right //= 2
            p = size + x - 1
            tree[p] = max(tree[p], best + 1)
            p //= 2
            while p:
                tree[p] = max(tree[p * 2], tree[p * 2 + 1])
                p //= 2
        return tree[1]
