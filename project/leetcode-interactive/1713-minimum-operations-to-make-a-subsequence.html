HARD贪心哈希表二分查找最长上升子序列

题目

给定由互不相同整数组成的数组 target，以及可能含重复元素的整数数组 arr。每次操作可以在 arr 的任意位置插入任意整数。请返回让 target 成为 arr 的子序列所需的最少操作次数。

子序列可由原数组删除任意数量元素得到，但保留下来的元素相对顺序不能改变。

示例 1

输入：target = [5,1,3], arr = [9,4,2,3,4]
输出：2
解释：可以插入 5 和 1，使 target 成为 arr 的子序列。

示例 2

输入：target = [6,4,8,1,3,2], arr = [4,7,6,2,3,8,6,1]
输出：3

约束

  • 1 <= target.length, arr.length <= 10^5
  • 1 <= target[i], arr[i] <= 10^9
  • target 中的元素互不相同。

已经形成自己的猜想了吗？

题解：索引映射 + 最长上升子序列

核心洞察：最少插入次数 = target.length - LCS(target, arr)。由于 target 元素互不相同，可以把 arr 中命中的值换成它在 target 的索引，LCS 就变成索引序列的严格 LIS。

完整过程

建立坐标。 用哈希表记录每个 target[i] 对应的索引 i。
过滤并映射。 依次扫描 arr，跳过不在 target 中的值；其余值替换成 target 索引。
在线维护 LIS。 tails[k] 表示长度为 k+1 的严格上升子序列可取得的最小末尾索引。对每个索引用二分查找第一个 >= x 的位置并替换；若不存在则追加。
计算答案。 LIS 中的元素已经以 target 的顺序出现在 arr 中，无须插入；其余每个 target 元素各插入一次。

为什么正确

引理 1：任意公共子序列之外的每个 target 元素都至少需要一次插入，而把这些缺失元素插入即可构成 target，因此答案是 |target| - LCS。

引理 2：target 元素唯一，所以值到索引是一一映射。arr 中命中元素按 target 顺序构成公共子序列，当且仅当其索引严格递增。因此最长公共子序列长度等于映射索引序列的 LIS 长度。

结论：算法求得的 LIS 长度正是可复用元素的最大数量，返回 target.length - LIS 即为最少操作数。

边界情况

  • arr 没有任何 target 元素：LIS 为 0，答案为 target 长度。
  • target 已是 arr 子序列：答案为 0。
  • arr 中重复命中：严格 LIS 与 lower_bound 会正确处理重复索引。
  • 极大数值不影响算法，只作为哈希键。

复杂度

令 m = target.length，n = arr.length。

时间：O(m + n log m)
空间：O(m)

替代方案

直接做 LCS 动态规划需要 O(mn) 时间，在长度达到 10^5 时不可行。若 target 允许重复，简单索引映射不再成立，需要更一般的 LCS 技巧或为每个值维护多个位置。

面试追问

  • 为什么二分查找第一个大于等于 x 的位置，而不是大于 x？
  • 如何还原一条实际的最长上升子序列？
  • 若 target 含重复元素，如何调整？
  • 能否流式处理 arr？可以，tails 只依赖已扫描前缀。

常见错误

  • 没有过滤 arr 中不属于 target 的元素。
  • 把最长上升子序列写成非递减子序列，重复值会被错误累计。
  • 直接对数值求 LIS；必须先映射成 target 中的位置。
  • 返回 LIS 长度，而不是 target.length - LIS。

四语言完整代码

Java O(n log m)

import java.util.*;

class Solution {
    public int minOperations(int[] target, int[] arr) {
        Map<Integer, Integer> index = new HashMap<>();
        for (int i = 0; i < target.length; i++) {
            index.put(target[i], i);
        }

        int[] tails = new int[target.length];
        int size = 0;
        for (int value : arr) {
            Integer x = index.get(value);
            if (x == null) continue;

            int left = 0, right = size;
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (tails[mid] < x) left = mid + 1;
                else right = mid;
            }
            tails[left] = x;
            if (left == size) size++;
        }
        return target.length - size;
    }
}

JavaScript O(n log m)

/**
 * @param {number[]} target
 * @param {number[]} arr
 * @return {number}
 */
var minOperations = function(target, arr) {
    const index = new Map();
    target.forEach((value, i) => index.set(value, i));

    const tails = [];
    for (const value of arr) {
        if (!index.has(value)) continue;
        const x = index.get(value);
        let left = 0;
        let right = tails.length;
        while (left < right) {
            const mid = left + Math.floor((right - left) / 2);
            if (tails[mid] < x) left = mid + 1;
            else right = mid;
        }
        tails[left] = x;
    }
    return target.length - tails.length;
};

Python O(n log m)

from bisect import bisect_left
from typing import List

class Solution:
    def minOperations(self, target: List[int], arr: List[int]) -> int:
        index = {value: i for i, value in enumerate(target)}
        tails = []

        for value in arr:
            if value not in index:
                continue
            x = index[value]
            position = bisect_left(tails, x)
            if position == len(tails):
                tails.append(x)
            else:
                tails[position] = x

        return len(target) - len(tails)

C++ O(n log m)

#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int minOperations(vector<int>& target, vector<int>& arr) {
        unordered_map<int, int> index;
        for (int i = 0; i < static_cast<int>(target.size()); ++i) {
            index[target[i]] = i;
        }

        vector<int> tails;
        for (int value : arr) {
            auto it = index.find(value);
            if (it == index.end()) continue;
            int x = it->second;
            auto position = lower_bound(tails.begin(), tails.end(), x);
            if (position == tails.end()) tails.push_back(x);
            else *position = x;
        }
        return static_cast<int>(target.size() - tails.size());
    }
};
