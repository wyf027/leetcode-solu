二叉树的最近公共祖先 III

Lowest Common Ancestor of a Binary Tree III

先把它当作一道寻路题。

每个节点都知道自己的父节点。你能只沿着向上的路，让两个起点找到最近的共同落脚点吗？先读题并操作实验，再决定是否展开题解。

从题目开始 ↓

Problem

题目转述

给定一棵二叉树中的两个不同节点 p 和 q。与普通二叉树不同，每个节点除 left、right 外，还保存了指向父节点的 parent 指针。

请返回 p 与 q 的最近公共祖先节点。可以直接使用父指针向根方向移动；函数不会额外接收根节点。

最近公共祖先（LCA）：同时是两个节点祖先、并且离这两个节点尽可能近的那个节点。按照定义，一个节点也可以是它自己的祖先。

提交函数 lowestCommonAncestor(p, q)
  • 输入：两个 Node 引用
  • 返回：一个 Node 引用
  • 可用字段：val / left / right / parent
EXAMPLE 01
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1 输出：3

节点 5 与节点 1 分居根节点 3 的两侧，它们最近的共同祖先是 3。

EXAMPLE 02
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4 输出：5

节点 5 本身就是节点 4 的祖先，所以答案可以等于输入节点之一。

EXAMPLE 03
输入：root = [1,2], p = 1, q = 2 输出：1

根节点 1 是节点 2 的直接父节点，也是两者的最近公共祖先。

约束

  • 树中节点数在 2 到 105 之间。
  • -109 ≤ Node.val ≤ 109，且所有节点值互不相同。
  • p != q，并且 p、q 都存在于树中。
  • 每个节点的 parent 要么指向其父节点，要么在根节点处为 null。

Solution

把两条祖先链对齐

↻

核心洞察：从任一节点到根都是一条单向链。问题因此等价于“两个带公共尾部的链表在哪里第一次相交”。两个指针走到链尾后，改从另一条链的起点继续；这样它们各自都走过相同的总路程，深度差会被自然抵消。

完整过程

  1. 令 a = p、b = q。
  2. 当 a != b 时同时移动。
  3. a 非空就走向父节点；为空则跳到 q。
  4. b 非空就走向父节点；为空则跳到 p。
  5. 两者第一次相等的位置就是最近公共祖先。

边界情况

  • 若 p 是 q 的祖先，最终会在 p 会合。
  • 若两者深度相同，不一定需要发生换路。
  • 若最近公共祖先是根，两个指针会在根会合。
  • 无需递归，深度达到 10⁵ 也不会产生调用栈溢出。

正确性证明

记从 p 到最近公共祖先的独占长度为 x，从 q 到最近公共祖先的独占长度为 y，从最近公共祖先到根的公共长度为 z。

指针 A 按“p 链后接 q 链”行走，指针 B 按“q 链后接 p 链”行走。当 A 走过 x + z + y 条边、B 走过 y + z + x 条边时，二者已走过相同距离，并同时到达公共尾部的起点，也就是最近公共祖先。公共尾部中再没有比它更靠近 p、q 的共同节点，因此返回值正确。

复杂度

时间 O(h) 空间 O(1)

h 表示树高；两个指针至多各走完两条祖先链。

替代方案

祖先集合：先把 p 到根的所有节点存入哈希集合，再沿 q 向上找第一个已出现的节点。时间 O(h)，空间 O(h)，直观但多用内存。

深度对齐：先分别求深度，让较深指针上移深度差，再同步上移。时间 O(h)，空间 O(1)，但步骤和代码稍多。

四种语言完整实现

/*
// Definition for a Node.
class Node {
    public int val;
    public Node left;
    public Node right;
    public Node parent;
}
*/

class Solution {
    public Node lowestCommonAncestor(Node p, Node q) {
        Node a = p;
        Node b = q;

        while (a != b) {
            a = (a == null) ? q : a.parent;
            b = (b == null) ? p : b.parent;
        }

        return a;
    }
}

 * // Definition for a Node.
 * function Node(val) {
 *   this.val = val;
 *   this.left = null;
 *   this.right = null;
 *   this.parent = null;

 */

/**
 * @param {Node} p
 * @param {Node} q
 * @return {Node}
 */
var lowestCommonAncestor = function (p, q) {
  let a = p;
  let b = q;

  while (a !== b) {
    a = a === null ? q : a.parent;
    b = b === null ? p : b.parent;
  }

  return a;
};

面试追问

为什么换路后一定能消除深度差？

因为两个指针都完整走过“p 的祖先链长度 + q 的祖先链长度”，只是顺序相反。到达公共段时累计路程相等。

如果节点可能来自不同的树呢？

原题保证它们属于同一棵树。若取消保证，这套写法最终会同时变为 null，可返回 null；也可以先比较各自根节点。

大量 LCA 查询应怎样优化？

单次查询用双指针足够；若树固定且查询很多，可预处理倍增祖先表，以 O(n log n) 预处理换取每次 O(log n) 查询。

常见错误

  • 把题目写成普通 LCA 的递归 DFS，忘记本题没有传入 root，却提供了 parent。
  • 比较 node.val 而不是节点引用；LCA 是节点身份问题。
  • 走到 null 后回到自己的起点，无法抵消两条链的长度差；必须换到另一条链的起点。
  • 忽略“一个节点可以是自己的祖先”，导致 p 是 q 的祖先时多走一步。
  • 使用递归沿父指针上溯，最坏深度为 10⁵ 时可能造成栈溢出。
