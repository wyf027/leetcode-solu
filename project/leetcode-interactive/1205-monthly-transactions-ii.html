每月交易 II

同一笔交易有两个可能的时间坐标：交易发生月与退单发生月。你的任务是把它们归入正确的月度账本。

Problem

题目转述

先读题，不泄露解法

给定交易表 Transactions 与退单表 Chargebacks。请按“月份 + 国家”汇总四项指标：批准交易笔数、批准交易金额、退单笔数、退单金额。

时间口径：批准数据使用原交易的 trans_date；退单数据使用退单记录的 trans_date，但国家与金额仍来自其关联的原交易。

若某个“月份 + 国家”的四项指标全为 0，则不返回该行。结果顺序不限。

约束与数据关系

  • Transactions.id 是唯一值。
  • state 仅为 approved 或 declined。
  • Chargebacks.trans_id 引用已存在的交易。
  • 退单对应的原交易可能并未批准。
  • 提供的官方元数据未给出额外数值范围，不在此虚构规模约束。

Solution

事件归一化 + 一次聚合

官方提交语言：MySQL

核心洞察

把“批准交易”和“退单”都改写成相同结构的事件：(month, country, type, amount)。两类事件用 UNION ALL 纵向拼接，最后只需按月份与国家分组。

  1. 批准支流

    仅保留 approved，月份取交易日期。

  2. 退单支流

    连接原交易补出 country 与 amount，月份取退单日期。

  3. 统一汇总

    按 type 做条件计数与条件求和。

正确性证明

引理 1：批准支流包含且只包含每笔批准交易一次，并以其交易月、国家与金额记账，因此批准指标准确。

引理 2：每条退单通过 trans_id 找到唯一原交易，并以退单月、原国家与原金额记账，因此退单指标准确。

定理：两支流互不丢失地并入统一事件集。对每个 (month,country) 条件聚合，由引理 1、2 分别得到四个正确指标；事件集不会产生全零组，所以输出恰好符合要求。

边界与细节

  • 被拒交易本身不贡献批准指标，但若发生退单，仍贡献退单指标。
  • 交易月和退单月可能不同，禁止使用原交易日期统计退单。
  • 某月只有退单时，批准两列应为 0。
  • 国家来自原交易；退单表没有 country。
  • UNION ALL 不去重，符合事件计数语义。

复杂度

设交易数为 T、退单数为 C。逻辑上需扫描两张表并分组，时间复杂度约为 O(T + C)；数据库实际代价受连接索引、哈希/排序聚合与执行计划影响。中间分组空间约为不同“月份 + 国家”组合数。

替代方案

可先分别聚合批准与退单，再用全外连接合并；但 MySQL 缺少原生 FULL OUTER JOIN，通常要再用左右连接或键集合模拟，结构更繁琐。

面试追问

  • 若同一交易允许多次退单，当前模型会把每条退单都作为独立事件；业务是否需要去重必须另定。
  • 如何优化？为 Transactions.id 与 Chargebacks.trans_id 建立可用索引，并评估按日期分区。
  • 如果金额有小数，应使用定点 DECIMAL，避免浮点累计误差。
  • 若要求补全无事件月份，需引入日历表再左连接，不能依赖现有事件集。

常见错误

  • 把所有交易都纳入 approved_count。
  • 用交易日期代替退单日期。
  • 对两类事件使用 UNION，误删看似重复的真实事件。
  • 直接连接两表后聚合，造成批准交易因多条退单而被重复计算。
  • 忽略“被拒交易也可能退单”。

MySQL · LeetCode 可提交主答案
WITH events AS (
    SELECT
        DATE_FORMAT(trans_date, '%Y-%m') AS month,
        country,
        'approved' AS event_type,
        amount
    FROM Transactions
    WHERE state = 'approved'

    UNION ALL

    SELECT
        DATE_FORMAT(c.trans_date, '%Y-%m') AS month,
        t.country,
        'chargeback' AS event_type,
        t.amount
    FROM Chargebacks AS c
    INNER JOIN Transactions AS t
        ON t.id = c.trans_id
)
SELECT
    month,
    country,
    SUM(event_type = 'approved') AS approved_count,
    SUM(IF(event_type = 'approved', amount, 0)) AS approved_amount,
    SUM(event_type = 'chargeback') AS chargeback_count,
    SUM(IF(event_type = 'chargeback', amount, 0)) AS chargeback_amount
FROM events
GROUP BY month, country;

import java.time.LocalDate;
import java.time.YearMonth;
import java.util.*;

public class MonthlyTransactionsII {
    record Transaction(int id, String country, String state,
                       long amount, LocalDate date) {}
    record Chargeback(int transactionId, LocalDate date) {}
    record Result(String month, String country, long approvedCount,
                  long approvedAmount, long chargebackCount,
                  long chargebackAmount) {}
    record Key(YearMonth month, String country)
            implements Comparable<Key> {
        public int compareTo(Key other) {
            int byMonth = month.compareTo(other.month);
            return byMonth != 0 ? byMonth : country.compareTo(other.country);
        }
    }
    static class Agg {
        long approvedCount, approvedAmount, chargebackCount, chargebackAmount;
    }

    public static List<Result> solve(List<Transaction> transactions,
                                     List<Chargeback> chargebacks) {
        Map<Integer, Transaction> byId = new HashMap<>();
        Map<Key, Agg> groups = new TreeMap<>();
        for (Transaction t : transactions) {
            byId.put(t.id(), t);
            if ("approved".equals(t.state())) {
                Key key = new Key(YearMonth.from(t.date()), t.country());
                Agg agg = groups.computeIfAbsent(key, unused -> new Agg());
                agg.approvedCount++;
                agg.approvedAmount += t.amount();
            }
        }
        for (Chargeback c : chargebacks) {
            Transaction t = byId.get(c.transactionId());
            if (t == null) continue;
            Key key = new Key(YearMonth.from(c.date()), t.country());
            Agg agg = groups.computeIfAbsent(key, unused -> new Agg());
            agg.chargebackCount++;
            agg.chargebackAmount += t.amount();
        }
        List<Result> answer = new ArrayList<>();
        groups.forEach((key, agg) -> answer.add(new Result(
            key.month().toString(), key.country(), agg.approvedCount,
            agg.approvedAmount, agg.chargebackCount, agg.chargebackAmount)));
        return answer;
    }
}
JavaScript · 本地语义参考非 LeetCode 数据库题提交语言
function monthlyTransactions(transactions, chargebacks) {
  const byId = new Map(transactions.map((transaction) => [transaction.id, transaction]));
  const groups = new Map();

  function getGroup(month, country) {
    const key = `${month}\u0000${country}`;
    if (!groups.has(key)) {
      groups.set(key, {
        month, country,
        approved_count: 0, approved_amount: 0,
        chargeback_count: 0, chargeback_amount: 0
      });
    }
    return groups.get(key);
  }

  for (const transaction of transactions) {
    if (transaction.state !== "approved") continue;
    const group = getGroup(transaction.trans_date.slice(0, 7), transaction.country);
    group.approved_count += 1;
    group.approved_amount += transaction.amount;
  }

  for (const chargeback of chargebacks) {
    const transaction = byId.get(chargeback.trans_id);
    if (!transaction) continue;
    const group = getGroup(chargeback.trans_date.slice(0, 7), transaction.country);
    group.chargeback_count += 1;
    group.chargeback_amount += transaction.amount;
  }

  return [...groups.values()].sort((a, b) =>
    a.month.localeCompare(b.month) || a.country.localeCompare(b.country)
  );
}

from collections import defaultdict
from dataclasses import dataclass
from datetime import date

@dataclass(frozen=True)
class Transaction:
    id: int
    country: str
    state: str
    amount: int
    trans_date: date

@dataclass(frozen=True)
class Chargeback:
    trans_id: int
    trans_date: date

def monthly_transactions(transactions: list[Transaction],
                         chargebacks: list[Chargeback]) -> list[dict]:
    by_id = {transaction.id: transaction for transaction in transactions}
    groups = defaultdict(lambda: [0, 0, 0, 0])

    for transaction in transactions:
        if transaction.state == "approved":
            key = (transaction.trans_date.strftime("%Y-%m"), transaction.country)
            groups[key][0] += 1
            groups[key][1] += transaction.amount

    for chargeback in chargebacks:
        transaction = by_id.get(chargeback.trans_id)
        if transaction is None:
            continue
        key = (chargeback.trans_date.strftime("%Y-%m"), transaction.country)
        groups[key][2] += 1
        groups[key][3] += transaction.amount

    return [
        {
            "month": month, "country": country,
            "approved_count": values[0], "approved_amount": values[1],
            "chargeback_count": values[2], "chargeback_amount": values[3],
        }
        for (month, country), values in sorted(groups.items())
    ]
C++ · 本地语义参考非 LeetCode 数据库题提交语言
#include <array>
#include <map>
#include <string>
#include <unordered_map>
#include <vector>

using namespace std;

struct Transaction {
    int id;
    string country;
    string state;
    long long amount;
    string transDate;
};

struct Chargeback {
    int transId;
    string transDate;
};

struct Result {
    string month, country;
    long long approvedCount, approvedAmount;
    long long chargebackCount, chargebackAmount;
};

vector<Result> monthlyTransactions(const vector<Transaction>& transactions,
                                   const vector<Chargeback>& chargebacks) {
    unordered_map<int, const Transaction*> byId;
    map<pair<string, string>, array<long long, 4>> groups;

    for (const auto& transaction : transactions) {
        byId[transaction.id] = &transaction;
        if (transaction.state == "approved") {
            auto& values = groups[{transaction.transDate.substr(0, 7),
                                   transaction.country}];
            ++values[0];
            values[1] += transaction.amount;
        }
    }
    for (const auto& chargeback : chargebacks) {
        auto found = byId.find(chargeback.transId);
        if (found == byId.end()) continue;
        const Transaction& transaction = *found->second;
        auto& values = groups[{chargeback.transDate.substr(0, 7),
                               transaction.country}];
        ++values[2];
        values[3] += transaction.amount;
    }

    vector<Result> answer;
    for (const auto& [key, values] : groups) {
        answer.push_back({key.first, key.second, values[0], values[1],
                          values[2], values[3]});
    }
    return answer;
}
