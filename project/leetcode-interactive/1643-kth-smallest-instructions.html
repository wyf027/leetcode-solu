第 K 条
最小指令

在只允许向右与向下的网格中，找到按字典序排列后的第 k 条路线。先理解问题并亲手探索；完整题解收在页面底部，默认不会提前展开。

Kth Smallest Instructions 非付费题 H < V

01 / Problem

题意

Bob 从网格坐标 (0, 0) 出发，要到达 destination = [row, column]。每一步只能向右或向下：

  • H：水平方向向右移动一格；
  • V：竖直方向向下移动一格。

每条合法指令恰好含有 column 个 H 与 row 个 V。将全部合法指令按字典序升序排列，返回其中第 k 条；k 从 1 开始计数。

函数形式： kthSmallestPath(destination, k) → string。因为字符 H 的字典序小于 V，所以以 H 开头的合法指令总排在以 V 开头的合法指令之前。
示例 1
输入：
destination = [2,3], k = 1

输出：
"HHHVV"

解释：
所有可达指令按字典序排列，
第一条是 "HHHVV"。
示例 2
输入：
destination = [2,3], k = 2

输出：
"HHVHV"
示例 3
输入：
destination = [2,3], k = 3

输出：
"HHVVH"

约束

  • destination.length == 2
  • 1 <= row, column <= 15
  • 1 <= k <= C(row + column, row)

Core insight

用组合数跳过整段字典序区间

假设还剩 h 个 H 和 v 个 V。若下一位先放 H，那么余下 h - 1 + v 个位置中只需决定哪 v 个位置放 V，因此以 H 开头的路线数量是：

countH = C(h + v - 1, v)

由于 H 的字典序小于 V，这 countH 条路线构成当前候选集合最前面的一整块。如果 k ≤ countH，答案下一位一定是 H；否则跳过这一整块，选择 V，并把 k 更新为 k - countH。

完整过程

  1. 令 v = destination[0]、h = destination[1]。
  2. 只要 H 与 V 仍有剩余，就计算以 H 作为下一字符的路线数。
  3. 若 k 落在 H 分区，追加 H 并令 h 减一；否则追加 V、令 k 减去 H 分区大小，再令 v 减一。
  4. 某种字符耗尽后，剩余位置只能全部填入另一种字符。

以 destination = [2,3], k = 3 为例

h=3, v=2：以 H 开头有 C(4,2)=6 条，3 ≤ 6，取 H。

h=2, v=2：以 HH 开头有 C(3,2)=3 条，3 ≤ 3，再取 H。

h=1, v=2：以 HHH 开头有 C(2,2)=1 条，3 > 1，跳过它，取 V，k 变成 2。

h=1, v=1：以 HHVH 开头有 1 条，2 > 1，取 V，k 变成 1。最后只剩 H。

得到 HHVVH。

正确性证明

循环不变量：每轮开始时，当前前缀与剩余的 h、v 描述了所有仍可能成为答案的合法路线；当前 k 是目标路线在这些候选路线中的 1-based 名次。

保持：这些候选路线按首字符被分为连续两块：先是全部以 H 开头的 C(h+v-1,v) 条，再是全部以 V 开头的路线。若 k 不超过第一块大小，保留 H 块且 k 不变；否则丢弃 H 块、进入 V 块并减去被跳过的数量。两种情况都选择了目标路线必然拥有的下一字符，且更新后的 k 仍是它在新候选集合中的名次，所以不变量成立。

终止：每轮消耗一个字符，最多经过 row + column 轮便无字符剩余。此时候选集合只含构造出的唯一字符串；根据不变量，它正是原集合中字典序第 k 条路线。

边界与复杂度

  • k = 1：每次都尽可能选 H，得到字典序最小路线。
  • k = 总路线数：会持续跳过 H 分区，得到字典序最大路线。
  • h = 0 或 v = 0：后缀被唯一确定，无需继续比较。
  • 组合数最大为 C(30,15) = 155117520；Java/C++ 仍用 long/long long 计算中间乘积更稳妥。
时间：O(row + column) 额外空间：O(1)（不计返回字符串）

替代方案

枚举 + 排序：生成所有路线后排序，路线数是组合数，指数级膨胀，不可取。

动态规划计数：可预先用二维 DP 计算每个状态的路线数，再按同样规则选字符。复杂度 O(row·column)，容易理解，但本题 15 的约束下直接算组合数更简洁。

逐个 next permutation：从最小字符串开始迭代到第 k 个，时间依赖 k，最坏明显慢于按区间跳跃。

Java官方签名
class Solution {
    public String kthSmallestPath(int[] destination, int k) {
        int v = destination[0];
        int h = destination[1];
        StringBuilder answer = new StringBuilder(h + v);

        while (h > 0 || v > 0) {
            if (h == 0) {
                answer.append('V');
                v--;
                continue;
            }
            if (v == 0) {
                answer.append('H');
                h--;
                continue;
            }

            long countH = combination(h + v - 1, v);
            if (k <= countH) {
                answer.append('H');
                h--;
            } else {
                answer.append('V');
                k -= (int) countH;
                v--;
            }
        }
        return answer.toString();
    }

    private long combination(int n, int r) {
        r = Math.min(r, n - r);
        long value = 1;
        for (int i = 1; i <= r; i++) {
            value = value * (n - r + i) / i;
        }
        return value;
    }
}

/**
 * @param {number[]} destination
 * @param {number} k
 * @return {string}
 */
var kthSmallestPath = function(destination, k) {
    let v = destination[0];
    let h = destination[1];
    const answer = [];

    const combination = (n, r) => {
        r = Math.min(r, n - r);
        let value = 1;
        for (let i = 1; i <= r; i++) {
            value = value * (n - r + i) / i;
        }
        return Math.round(value);
    };

    while (h > 0 || v > 0) {
        if (h === 0) {
            answer.push("V");
            v--;
            continue;
        }
        if (v === 0) {
            answer.push("H");
            h--;
            continue;
        }

        const countH = combination(h + v - 1, v);
        if (k <= countH) {
            answer.push("H");
            h--;
        } else {
            answer.push("V");
            k -= countH;
            v--;
        }
    }
    return answer.join("");
};

from math import comb
from typing import List


class Solution:
    def kthSmallestPath(
        self, destination: List[int], k: int
    ) -> str:
        v, h = destination
        answer = []

        while h > 0 or v > 0:
            if h == 0:
                answer.append("V")
                v -= 1
                continue
            if v == 0:
                answer.append("H")
                h -= 1
                continue

            count_h = comb(h + v - 1, v)
            if k <= count_h:
                answer.append("H")
                h -= 1
            else:
                answer.append("V")
                k -= count_h
                v -= 1

        return "".join(answer)

class Solution {
public:
    string kthSmallestPath(vector<int>& destination, int k) {
        int v = destination[0];
        int h = destination[1];
        string answer;
        answer.reserve(h + v);

        while (h > 0 || v > 0) {
            if (h == 0) {
                answer.push_back('V');
                --v;
                continue;
            }
            if (v == 0) {
                answer.push_back('H');
                --h;
                continue;
            }

            long long countH = combination(h + v - 1, v);
            if (k <= countH) {
                answer.push_back('H');
                --h;
            } else {
                answer.push_back('V');
                k -= static_cast<int>(countH);
                --v;
            }
        }
        return answer;
    }

private:
    long long combination(int n, int r) {
        r = min(r, n - r);
        long long value = 1;
        for (int i = 1; i <= r; ++i) {
            value = value * (n - r + i) / i;
        }
        return value;
    }
};

面试追问

为什么能贪心地决定每一位？
这里不是凭局部最优猜答案，而是用组合数精确计算每个前缀覆盖的连续排名区间。k 属于哪个区间，下一字符就被唯一确定。
如果 row、column 增大到 10⁵ 怎么办？
不能直接计算巨大组合数的完整值。只需判断 countH 是否至少为 k，可在乘法过程中把结果截断到 k，或用质因数/对数避免溢出；答案本身仍需 O(row + column) 时间。
如何求一条给定路线的字典序排名？
从左到右扫描；每遇到 V，就把当前状态下所有以 H 开头的路线数加到排名中，初始排名为 1。

常见错误

  • 把 k 当成 0-based，造成边界判断写成 k < countH。
  • 误以为 destination 的顺序是 [column, row]；实际是 [row, column]。
  • 选择 V 后忘记执行 k -= countH。
  • 组合数参数写错：固定下一位 H 后，应计算 C(h+v-1, v)。
  • 使用阶乘直接相乘，在更宽约束下很容易溢出。
