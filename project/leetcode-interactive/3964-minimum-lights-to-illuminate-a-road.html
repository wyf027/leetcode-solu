照亮道路的最少灯泡数

Minimum Lights to Illuminate a Road · 差分数组 / 贪心

Medium

题意

道路位置为 0..n-1。lights[i] = v > 0 表示位置 i 的既有灯泡照亮闭区间 [max(0,i-v), min(n-1,i+v)]；值为 0 表示没有既有灯泡。

可以在任意位置安装新灯泡，每盏新灯照亮自身及相邻位置，即 [j-1,j+1] 截断到道路边界。返回让所有位置可见所需的新灯最少数。

示例

lights = [0,0,0,2,0]，既有灯照亮 [1,4]，只需在位置 1 新装一盏灯覆盖位置 0，答案为 1。

约束：1 ≤ lights.length ≤ 10⁵；0 ≤ lights[i] ≤ n。

交互演示

金色位置已被既有或新增灯照亮；蓝框为新灯。

题解

核心洞察

先用差分数组把所有既有灯泡的照明区间合并。未被照亮的位置形成互不相交的暗段；一盏新增灯最多覆盖暗段中的连续 3 个位置，且把灯放在当前暗段最左未覆盖位置的右侧，能取得这 3 个位置。因此长度为 len 的暗段需要 ceil(len / 3) 盏。

完整过程

  1. 对每个 v > 0 的既有灯泡在差分数组上给 [i-v,i+v] 加 1。
  2. 前缀和为 0 的位置是暗的，连续暗位组成一段。
  3. 每结束一段，累加 (len + 2) / 3；演示器也记录每盏新增灯的位置。

边界、复杂度与替代方案

全亮时答案为 0；道路端点的新灯只覆盖 2 个位置，公式仍成立。时间 O(n)，空间 O(n)。也可显式标记每个区间，但会在大范围灯泡下退化到 O(n²)。

面试追问与常见错误

若新增灯的半径改为 r，暗段公式变为 ceil(len / (2r+1))。常见错误是没有截断既有灯的左右端点，或把被已有区间部分覆盖的区域仍算入暗段。
