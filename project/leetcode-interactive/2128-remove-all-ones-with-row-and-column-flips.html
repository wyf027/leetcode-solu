Remove All Ones With Row and Column Flips

一次操作影响整条行或列。你能判断一个二进制矩阵是否可以最终变成全 0 吗？

先尝试独立思考；完整题解、逐步演示与四语言实现收在页面底部。

01 · 题目

给定一个 m × n 矩阵 grid，其中每个元素都是 0 或 1。你可以选择任意一行或任意一列，将这条行或列上的所有元素同时取反：0 变成 1，1 变成 0。操作次数不限，也可以一次都不操作。

如果存在某个操作序列，使最终矩阵中的元素全部为 0，返回 true；否则返回 false。这里只需判断可行性。

函数契约
removeOnes(grid: integer[][]) → boolean

参数只有 grid；m 和 n 由矩阵尺寸确定。

约束

  • m == grid.length
  • n == grid[i].length，所有行等长。
  • 1 ≤ m, n ≤ 300
  • grid[i][j] 只能是 0 或 1。

04 · 题解与翻转实验

准备好后，展开推导与代码。

核心洞察 · 每一行只能相同或互补

同一条行或列翻转两次会抵消，行翻转与列翻转的顺序也不影响最终结果。把每行、每列是否翻转记为 r[i]、c[j]，要变为 0 就必须满足：

grid[i][j] XOR r[i] XOR c[j] = 0
即 grid[i][j] = r[i] XOR c[j]

两行在同一列做异或时，列翻转量会抵消。因此某行与第 0 行的逐列异或，必须始终等于同一个值：全为 0 表示两行相同；全为 1 表示两行互补。

完整过程

  1. 固定第 0 行为参照，不修改输入矩阵。
  2. 对每行 i ≥ 1，计算首列差异 d = grid[i][0] XOR grid[0][0]。
  3. 从第 1 列开始逐列比较；若 grid[i][j] XOR grid[0][j] != d，立即返回 false。
  4. 所有行都没有冲突，返回 true。无需真正执行翻转。

正确性证明

必要性：如果可以归零，则 grid[i][j] = r[i] XOR c[j]。与第 0 行异或后，得到 grid[i][j] XOR grid[0][j] = r[i] XOR r[0]，右侧不随列号变化。所以每一行都必须与第 0 行相同或互补，任何一个不匹配的列都足以否定可行性。

充分性：如果每行与第 0 行相同或互补，令 c[j] = grid[0][j]，翻转对应的列。第 0 行变成全 0，其他行变成全 0 或全 1。再把所有全 1 行翻转，就得到全 0。故算法接受的矩阵一定可归零。

冲突证据：若某格不满足条件，则 grid[0][0] XOR grid[0][j] XOR grid[i][0] XOR grid[i][j] = 1。任何行列翻转都会影响这四个角中的 0 个或 2 个，异或不变；全 0 的四角异或却为 0，因此不可能到达。

边界与复杂度

  • 单行可逐列消除 1；单列可逐行消除 1，所以两种情况都返回 true。相应内层或外层循环自然为空。
  • 全 0、全 1、重复行、互补行均符合判定条件。
  • 输入保证非空、矩形且为二进制；代码按这些官方约束实现。
  • 最坏时间 O(mn)；发现冲突可提前返回。额外空间 O(1)，不复制或修改矩阵。演示为支持回退而保存快照，其内存开销不属于提交算法。

替代方案

可以把首元素为 1 的行实际翻转，让首列全为 0，然后判断所有行是否相同；同样是 O(mn) 时间，但会修改输入。也可把归一化后的行转成字符串放入集合，检查是否只有一种模式，不过会额外分配 O(mn) 空间。直接逐格异或无需这些存储。

常见错误

  • 仅统计不同的行不超过两种：两种行还必须逐位互补。
  • 把“行取反”理解为逆序；正确操作是每个元素都做 0 ↔ 1。
  • 只比较每行的 1 的数量，忽略 1 的位置。
  • 根据当前 1 的多少贪心翻转，可能不断抵消之前的操作。
  • 用单个 JavaScript 32 位整数压缩最多 300 列，导致信息截断。

面试追问

  • 如何输出操作序列？可行时取 c[j] = grid[0][j]、r[i] = grid[i][0] XOR grid[0][0]，输出值为 1 的行列编号。
  • 如何最小化操作次数？可行矩阵的翻转奇偶方案恰有互补的两组。第一组共 k 次，另一组为 m + n - k 次，取较小者；重复翻转不能更优。
  • 目标是任意二进制矩阵怎么办？将原矩阵与目标矩阵逐格异或，对差异矩阵应用同一判定。
  • 为什么用 XOR 而不是加法？每格只关心翻转次数的奇偶性，XOR 正好描述模 2 加法。

四语言完整实现

均采用相同的 O(mn) 时间 / O(1) 额外空间判定，包含平台所需类或函数。以下代码仅生成，未编译、未运行。

Java

class Solution {
    public boolean removeOnes(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        for (int i = 1; i < m; i++) {
            int diff = grid[i][0] ^ grid[0][0];
            for (int j = 1; j < n; j++) {
                if ((grid[i][j] ^ grid[0][j]) != diff) {
                    return false;
                }
            }
        }
        return true;
    }
}
