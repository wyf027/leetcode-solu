Ternary Expression Parser

三元表达式解析器

给定一个合法的嵌套三元表达式，沿着条件分支求出最终的单字符结果。先读题并亲手观察求值过程，再决定是否展开完整题解。

MEDIUM 付费题 字符串 栈 递归
Expression signal right associative
F ? 1 : T ? 4 : 5

条件只会选择两个分支之一；嵌套结构按题目规定合法。

官方签名：parseTernary(expression) → string

Problem brief

题意与输入约定

给你一个字符串 expression，它表示一个合法的嵌套三元表达式。每个条件都是 T（真）或 F（假），格式为 condition ? trueExpression : falseExpression。

计算表达式并返回最终结果。返回值一定是单个数字字符、T 或 F。三元表达式按从右向左结合理解，且数字均为单个字符。

官方示例

输入：expression = "T?2:3" 输出："2" 解释：条件 T 为真，因此选择 2。
输入：expression = "F?1:T?4:5" 输出："4" 解释：外层条件 F 为假，继续计算 T?4:5，得到 4。
输入：expression = "T?T?F:5:3" 输出："F" 解释：外层条件 T 为真，真分支 T?F:5 的结果为 F。

参数形式

String parseTernary(String expression)

约束

  • 5 <= expression.length <= 104
  • expression 仅包含数字字符、T、F、? 和 :
  • 每个数字均为 0 到 9 的单个字符
  • 输入保证是合法的三元表达式
  • 最终结果是一个数字字符、T 或 F

Solution

右向左扫描 + 工作栈

右结合结构意味着最右侧的完整子表达式最先具备求值条件。反向扫描可以让每次局部归约都只处理四个栈元素。

01

核心洞察

从右往左读取字符。普通字符直接入栈；当当前字符是条件，且栈顶是 ? 时，栈顶必然依次构成 ? 真值 : 假值，可以立刻选出一个结果。

02

完整过程

  1. 初始化空栈，从字符串末尾开始扫描。
  2. 若栈顶不是 ?，把当前字符压栈。
  3. 若栈顶是 ?，依次弹出问号、真分支、冒号、假分支。
  4. 根据当前条件 T/F 选择分支，把结果压回栈。
  5. 扫描结束后，栈顶就是最终的单字符答案。
03

正确性

不变式：扫描位置右侧已经完成的每个三元子表达式，在栈中都被它的正确结果替代；尚未闭合的符号顺序保持不变。

普通字符入栈不会破坏不变式。遇到可归约条件时，输入合法性保证栈顶四项正是该条件的两个已正确求值分支及分隔符；按条件选取后压回的字符就是整个子表达式的正确值。因此不变式继续成立。扫描完全部字符后，整个表达式已归约为唯一结果。

04

边界与复杂度

  • 最外层条件为 T 或 F 都按同一规则处理。
  • 分支结果可以是数字、T 或 F。
  • 深度嵌套无需递归调用栈，适合长度上限 104。
  • 时间复杂度 O(n)；辅助空间复杂度 O(n)。

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String parseTernary(String expression) {
        Deque<Character> stack = new ArrayDeque<>();

        for (int i = expression.length() - 1; i >= 0; i--) {
            char current = expression.charAt(i);

            if (!stack.isEmpty() && stack.peek() == '?') {
                stack.pop();                 // ?
                char trueValue = stack.pop();
                stack.pop();                 // :
                char falseValue = stack.pop();
                stack.push(current == 'T' ? trueValue : falseValue);
            } else {
                stack.push(current);
            }
        }

        return String.valueOf(stack.peek());
    }
}

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string parseTernary(string expression) {
        vector<char> stack;

        for (int i = static_cast<int>(expression.size()) - 1; i >= 0; --i) {
            char current = expression[i];

            if (!stack.empty() && stack.back() == '?') {
                stack.pop_back();           // ?
                char trueValue = stack.back();
                stack.pop_back();
                stack.pop_back();           // :
                char falseValue = stack.back();
                stack.pop_back();
                stack.push_back(current == 'T' ? trueValue : falseValue);
            } else {
                stack.push_back(current);
            }
        }

        return string(1, stack.back());
    }
};

替代方案

递归下降：维护全局下标，解析条件后递归计算两个分支，逻辑贴近文法，但极深嵌套可能占用较多调用栈。

显式保存分隔位置：可从左向右寻找与当前问号匹配的冒号，再递归选分支；若反复线性搜索，最坏可能退化为 O(n²)。

常见错误

  • 按从左向右结合拆分，导致嵌套分支边界错误。
  • 归约时弹栈顺序颠倒，把假分支当成真分支。
  • 把单个数字误当成多位整数解析。
  • 使用递归却忽略最大长度下的调用栈风险。

面试追问

  • 为什么反向扫描能自然处理右结合？
  • 能否做到 O(1) 额外空间？需要怎样复用字符数组？
  • 如果操作数扩展为多位整数或标识符，词法层需要怎样变化？
  • 如果输入不保证合法，怎样返回准确的错误位置？

答题表达

先说明右结合带来的局部可归约性，再给出栈顶布局 ? / true / : / false，最后用扫描不变式证明每次压回的都是正确子表达式结果。
