用栈操作构建数组

让整数流依次经过一座“闸门”：需要的数留在栈里，不需要的数立刻撤回。先亲手推进操作，再决定是否展开完整题解。

MEDIUM栈数组模拟非会员题

01题目

给定严格递增的整数数组 target 和整数 n。从空栈出发，你会按顺序读取整数流 1, 2, …, n。每次读取一个数时必须先执行 "Push"；当栈非空时，可以用 "Pop" 删除栈顶。

请给出一组操作，使栈内元素从栈底到栈顶恰好等于 target。一旦相等，就必须停止读取和操作；存在多个答案时可返回任意合法答案。

函数形式： buildArray(target, n) → List<String>

约束

  • 1 <= target.length <= 100
  • 1 <= n <= 100
  • 1 <= target[i] <= n
  • target 严格递增

02官方示例

示例 1
输入：target = [1,3], n = 3
输出：["Push","Push","Pop","Push"]
解释：保留 1；读取 2 后弹出；再保留 3。
示例 2
输入：target = [1,2,3], n = 3
输出：["Push","Push","Push"]
解释：读取的三个数全部保留。
示例 3
输入：target = [1,2], n = 4
输出：["Push","Push"]
解释：到达 [1,2] 后立刻停止，不能继续读取 3。

05完整题解

核心洞察

整数流只能向前，且 target 严格递增。读到的数如果等于当前目标，就只 Push 并保留；否则它永远不会成为后续目标，只能先 Push 再立刻 Pop。读到 target 的最后一个数便停止。

完整过程

  1. 令流指针 current = 1，遍历 target 中每个目标值 want。
  2. 当 current < want，加入 Push 和 Pop，丢弃该流值，然后递增 current。
  3. 当 current == want，加入一次 Push 并递增 current；该数留在栈内。
  4. 遍历完 target 后立即返回，不读取剩余流。

边界与不变量

  • 最小输入：target=[1] 时只需一次 Push。
  • 目标无缺口：每个读取值都保留，不产生 Pop。
  • 首个目标大于 1：前面的流值都成对执行 Push, Pop。
  • 停止条件：只处理到 target[target.length-1]；n 更大也不继续。
  • 不变量：处理目标下标 i 前，栈恰为 target[0..i-1]。

正确性证明

1

丢弃动作合法：若当前流值小于当前目标值，由于目标严格递增，它不在尚未构建的目标后缀中。执行 Push 后紧接 Pop，栈恢复原状。

2

保留动作正确：流值等于当前目标时，执行 Push 会把它接到已正确构建的目标前缀末尾，因此不变量继续成立。

3

终止结果：每次保留都会完成一个目标位置。处理完最后一个目标后，栈正好等于整个 target，算法立即停止，所以输出操作合法且能构建目标数组。

复杂度

设 m = target[target.length - 1]。流中的 1..m 各读取一次，时间复杂度为 O(m)；输出数组本身最多有 2m 个字符串，因此计入返回结果的空间复杂度为 O(m)，额外工作空间为 O(1)。

Java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> buildArray(int[] target, int n) {
        List<String> operations = new ArrayList<>();
        int current = 1;

        for (int want : target) {
            while (current < want) {
                operations.add("Push");
                operations.add("Pop");
                current++;
            }
            operations.add("Push");
            current++;
        }
        return operations;
    }
}

替代方案

集合判断模拟：把所有目标值放进集合，再从 1 枚举到最后一个目标；在集合中则只 Push，否则 Push 后 Pop。它同样是 O(m)，但需要 O(k) 额外空间。

双指针：同时维护流值和目标下标，根据二者是否相等决定是否 Pop。与正文方案本质相同；按目标值逐段推进通常更简洁。

常见错误

  • 对不需要的值只写 Pop，忘了流值必须先被 Push。
  • 循环到 n 才停止，违反“栈等于 target 后立即停止”。
  • 把 target.length 当成最后一个目标值。
  • 输出小写 push/pop，没有匹配规定字符串。

面试追问

  • 为什么参数 n 没直接参与循环？约束保证最后一个目标值不超过 n，而合法过程必须在构建完目标时立刻停止，所以最后一个目标值已经给出精确上界。
  • 如果 target 不再严格递增呢？当前单向递增流无法构建含重复值或下降位置的目标，需要改变数据源规则或允许额外操作。
  • 操作数是多少？读取次数为 m；其中 k 个值被保留，其余 m-k 个被弹出，所以总操作数为 m + (m-k) = 2m-k。
  • 能否在线输出操作而不保存数组？可以把每个操作逐个交给消费者，使算法额外空间降为 O(1)，但题目接口要求返回列表。
