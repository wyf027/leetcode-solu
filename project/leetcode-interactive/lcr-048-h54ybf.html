二叉树的序列化与反序列化

把任意二叉树转换为字符串，再从同一份字符串无歧义地还原出原树。关键不是遍历顺序本身，而是绝不能丢掉空孩子的位置。

题意

设计一个算法完成两个操作：serialize 将树编码为字符串；deserialize 将该字符串还原为同构、同值的树。题目不限定编码格式。

推荐编码：前序遍历 + 空标记

树：     1

/ \

2  3

/ \

4  5

编码：1,2,#,#,3,4,#,#,5,#,#

其中 # 表示空节点。每个真实节点都紧跟两个子树描述，因此递归读取一个 token 后，消费范围是唯一的。

约束与复杂度

  • 节点值可为负数，不能把 -1 等值当作空节点。
  • 序列化与反序列化均访问每个 token 一次：时间 O(n)。
  • 字符串、递归调用栈和重建树总计使用 O(n) 空间。

    为什么必须记录空节点？

    若只写真实值，前序序列 1,2,3 可能来自多种不同形状的树，无法还原。加入 # 后，一棵空树就是一个 token；一棵非空树就是“根、左子树、右子树”三个连续且完整的片段，结构信息没有丢失。

    1. 序列化：遇到空指针写 #；否则写当前值，再递归写左、右孩子。
    2. 反序列化：从左向右取一个 token。它为 # 时返回空；否则创建节点，并递归读取其左、右子树。
    3. 不变量：每一次 build() 恰好消费当前子树的整个编码，调用结束后读取位置正好指向下一棵兄弟子树。

    常见错误：反序列化时把 token 数组从头重复读取；漏掉空节点；或不验证 token 是否全部被消费，都会让非法输入或树形错位悄悄通过。

    正确性证明

    归纳证明。对任意子树 T，设 S(T) 是上述前序编码。若 T 为空，S(T)=#，反序列化立即返回空，结论成立。若 T 非空，首 token 是其根值，反序列化创建同值根；随后按编码定义，接下来的连续片段分别是 S(T.left) 与 S(T.right)。由归纳假设，两次递归分别还原原左右子树。因此得到的根、左、右都与 T 相同，故整棵树被精确还原。

    var serialize = function(root) {
  const out = [];
  const dfs = (node) => {
    if (!node) { out.push('#'); return; }
    out.push(String(node.val));
    dfs(node.left); dfs(node.right);
  };
  dfs(root); return out.join(',');
};

var deserialize = function(data) {
  const tokens = data.split(','); let i = 0;
  const build = () => {
    const token = tokens[i++];
    if (token === '#') return null;
    const node = new TreeNode(Number(token));
    node.left = build(); node.right = build();
    return node;
  };
  return build();
};
    class Codec:
    def serialize(self, root):
        out = []
        def dfs(node):
            if not node:
                out.append('#'); return
            out.append(str(node.val))
            dfs(node.left); dfs(node.right)
        dfs(root)
        return ','.join(out)

    def deserialize(self, data):
        tokens = iter(data.split(','))
        def build():
            token = next(tokens)
            if token == '#': return None
            node = TreeNode(int(token))
            node.left, node.right = build(), build()
            return node
        return build()
    class Codec {
    public String serialize(TreeNode root) {
        StringBuilder out = new StringBuilder();
        write(root, out); return out.toString();
    }
    private void write(TreeNode node, StringBuilder out) {
        if (node == null) { out.append("#,"); return; }
        out.append(node.val).append(',');
        write(node.left, out); write(node.right, out);
    }
    public TreeNode deserialize(String data) {
        Deque<String> q = new ArrayDeque<>(Arrays.asList(data.split(",")));
        return build(q);
    }
    private TreeNode build(Deque<String> q) {
        String token = q.removeFirst();
        if (token.equals("#")) return null;
        TreeNode node = new TreeNode(Integer.parseInt(token));
        node.left = build(q); node.right = build(q); return node;
    }
}
    class Codec {
    void write(TreeNode* node, string& out) {
        if (!node) { out += "#,"; return; }
        out += to_string(node->val) + ",";
        write(node->left, out); write(node->right, out);
    }
    TreeNode* build(istringstream& in) {
        string token; getline(in, token, ',');
        if (token == "#") return nullptr;
        TreeNode* node = new TreeNode(stoi(token));
        node->left = build(in); node->right = build(in); return node;
    }
public:
    string serialize(TreeNode* root) { string out; write(root, out); return out; }
    TreeNode* deserialize(string data) { istringstream in(data); return build(in); }
};
