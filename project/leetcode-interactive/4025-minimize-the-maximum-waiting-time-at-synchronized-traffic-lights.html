交通灯的最大等待时间

每辆车可独立选择任意灯，灯与灯之间没有容量限制。把“分配”问题压缩成一盏最优灯，答案便清晰了。

打开原题进入实验室

题意重述

所有灯每 period 秒同时重启绿灯。第 i 盏灯前 lights[i] 秒为绿。车在时刻 t 到达，余数 r=t mod period；若 r < lights[i]，等待 0，否则等待 period-r。为每辆车选一盏灯，使所有等待中的最大值最小。

一眼洞察

更长的绿灯对任意到达余数都不差：若 a ≥ b，选择绿灯 a 的等待 ≤ 选择 b。因此所有车都可选 max(lights)；只需扫描到达时间，取其等待的最大值。

不是二分答案，也不需要匹配或排序。

交互推演

逗号分隔整数；按 Enter 或点击运行。

完整过程

  1. 1. 找到最长绿灯 g = max(lights)。
  2. 2. 对每个到达时刻求 r = t % period。
  3. 3. r < g 时等待 0，否则等待 period-r。
  4. 4. 维护这些等待的最大值。

边界

  • 余数恰好等于绿灯时长时已转红，必须等待。
  • r = 0 一定可立即通过。
  • 只有一盏灯时，上述支配关系依然成立。

复杂度与替代思路

时间：O(lights.length + arrivalTime.length)；额外空间：O(1)（不计输入）。

看似可行但多余：对每辆车枚举每盏灯是 O(nm)；二分惩罚并验证也不能比一次扫描更直接。它们忽略了“同一时刻所有灯同步、车可无限并行”的支配性质。

追问

若灯不同步、每盏灯有容量、或分配会互相阻塞，最长绿灯不再必然支配，才可能需要扫描线、流或二分可行性。

隐藏题解与代码

先自己推导，再揭晓实现。

将所有车辆分配给最长绿灯。对每辆车，该选择的等待不大于任意较短绿灯，故逐车最优同时也是全局最小最大值。

Java

int minimizeMaximumWaitingTime(int p, int[] lights, int[] arrivals) {\n  int g = 0, ans = 0;\n  for (int x : lights) g = Math.max(g, x);\n  for (int t : arrivals) { int r = t % p;\n    ans = Math.max(ans, r < g ? 0 : p - r); }\n  return ans;\n}

JavaScript

function solve(p, lights, arrivals) {\n  const g = Math.max(...lights); let ans = 0;\n  for (const t of arrivals) { const r = t % p;\n    ans = Math.max(ans, r < g ? 0 : p - r); }\n  return ans;\n}

Python

def solve(p, lights, arrivals):\n    g, ans = max(lights), 0\n    for t in arrivals:\n        r = t % p\n        ans = max(ans, 0 if r < g else p - r)\n    return ans

C++

int solve(int p, vector<int>& a, vector<int>& b) {\n  int g = *max_element(a.begin(), a.end()), ans = 0;\n  for (int t : b) { int r = t % p;\n    ans = max(ans, r < g ? 0 : p - r); }\n  return ans;\n}

常见错误

把 r ≤ g 当成绿灯（题目是严格小于）；忘记先取最长绿灯；误以为多辆车不能同时通行；为每辆车保留不同分配而引入不必要状态。
