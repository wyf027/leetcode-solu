最小差值平方和

Minimum Sum of Squared Difference

有限次调整，怎样让两组数字更接近？
先读题并尝试推演，准备好后再展开底部题解。

01 / 题目

给定两个长度相同、下标从 0 开始的整数数组 nums1、nums2。它们的差值平方和为 Σ (nums1[i] − nums2[i])²。

你可以在 nums1 中执行至多 k1 次操作，在 nums2 中执行至多 k2 次操作。每次选择该数组的一个元素，加 1 或减 1。返回所有合法调整方案中最小的差值平方和。调整后的元素可以为负数，操作次数不必用完。

参数与约束

  • minSumSquareDiff(nums1, nums2, k1, k2)，返回整数。
  • n == nums1.length == nums2.length
  • 1 ≤ n ≤ 10⁵
  • 0 ≤ nums1[i], nums2[i] ≤ 10⁵
  • 0 ≤ k1, k2 ≤ 10⁹

官方示例 1

nums1 = [1,2,3,4]
nums2 = [2,10,20,19]
k1 = 0, k2 = 0
输出：579

没有可用操作，结果为 1² + 8² + 17² + 15² = 579。

官方示例 2

nums1 = [1,4,10,12]
nums2 = [5,8,6,9]
k1 = 1, k2 = 1
输出：43

一种最优调整是将 nums1[0] 加 1、nums2[2] 加 1。最终为 [2,4,10,12] 与 [5,8,7,9]，平方和为 3² + 4² + 3² + 3² = 43。

03 / 题解与交互推演

包含思路、证明与四语言实现。

核心洞察：把最高的差值削低

只需关注绝对差 d[i] = |nums1[i] − nums2[i]|。只要差值大于 0，在任意一侧朝另一侧调整，都能把差值减 1，因此可合并预算为 K = k1 + k2。任意总次数不超过 K 的降差计划，都可把前至多 k1 次分给 nums1，其余分给 nums2。

将差值 x 减为 x−1，平方和减少 x² − (x−1)² = 2x−1。x 越大收益越高，所以优先降低当前最大差值。逐次操作太慢，用一个“高度上限”批量表达这些操作。

交互实验 / 找到可负担的高度上限

每一步是一轮二分判定，柱形表示将差值压到候选高度后的形状。失败候选只是试算；最后才扣除剩余预算。演示为便于阅读限制为 1–12 个元素，每项 0–30；提交代码使用完整官方约束。

完整过程

  1. 计算 d、总差值 S 和最大差值 M。若 K ≥ S，返回 0，剩余预算不必使用。
  2. 定义 C(t) = Σ max(d[i]−t, 0)，表示把所有差值降至不超过 t 所需的操作数。t 越大，成本越低。
  3. 在 [0, M] 中寻找满足 C(t) ≤ K 的最小整数 t。若 C(mid) ≤ K，令 hi=mid；否则令 lo=mid+1。
  4. 先令每项为 min(d[i], t)，再计算剩余次数 r = K−C(t)。
  5. 再将 r 个等于 t 的差值各减 1。每次收益为 2t−1，最终答案是 Σ min(d[i],t)² − r(2t−1)。

示例 2：d=[4,4,4,3]、K=2。C(3)=3 超出预算，所以 t=4。此时 C(4)=0、r=2，任选两个 4 降成 3，得到 [3,3,4,3]，答案 43；与官方方案的降差位置可以不同。

正确性说明

贪心交换。 每个差值提供按 2d−1、2d−3、…、1 递减的收益。如果某方案选了较小的可用收益而漏掉较大的可用收益，交换这两次操作会让答案更小；同一差值的收益按顺序递减，优先选较大收益不会违反操作先后关系。因此重复降低最大差值是最优的。

二分等价于批量贪心。 把所有高于 t 的值降到 t，取走的收益都大于 2t−1。由于 t 是最小可行高度，K<S 时有 t≥1，且 C(t−1)=C(t)+count(d[i]≥t)>K，所以 0≤r<count(d[i]≥t)。剩下 r 次恰好能分给不同的高度 t，每次取得剩余的最大收益 2t−1，故公式得到全局最优值。

边界与数值范围

  • K=0 时保持原差值；数组相等或预算充足时直接返回 0。
  • 所有差值可降到 0；不要因剩余预算的奇偶性把答案改成 1，因为是“至多”。
  • 总差值最多 10¹⁰，平方和最多 10¹⁵。Java / C++ 用 64 位整数，且平方前先提升类型。
  • JavaScript Number 可精确表示本题整数上界，10¹⁵ 小于 2⁵³−1；不要用位运算累计平方和。Python 整数自动扩展。

复杂度与替代方案

本实现时间 O(n log(M+1))，空间 O(n) 用于保存差值，M≤10⁵。直接从原数组反复计算差值可以将额外空间降到 O(1)，代价是代码中重复读取与计算。

桶计数可按差值从高到低批量搬移，时间 O(n+M)、空间 O(M)。排序后逐层抹平最高一组，时间 O(n log n)。最大堆逐次降差时间 O(n+min(K,S) log n)，适用于预算很小的情形；本题 K 可达 2×10⁹，不能默认逐次操作。

常见错误

  • 优先降低最小差值：忽略平方的边际收益。
  • 仅截断到 t 就求和：遗漏剩余 r 次，示例 2 会得到 57 而不是 43。
  • 对同一个 t 连续减 r 次：应优先分散给仍等于 t 的项。
  • 把 C(mid) 的可行方向写反：允许的上限越高，所需操作越少。
  • 平方先在 32 位类型中计算再转 long：溢出已经发生。

面试追问

若目标换为绝对差之和？ 每次收益恒为 1，直接返回 max(S−K,0)。
若每项带不同权重？ 比较权重乘以边际收益，统一的差值高度不再成立，可以考虑二分收益阈值。
若要求恰好使用所有操作？ 降到零后的剩余次数奇偶性会影响结果，必须重新处理可行性，不能沿用提前返回的结论。

Java

class Solution {
    public long minSumSquareDiff(int[] nums1, int[] nums2, int k1, int k2) {
        int n = nums1.length, max = 0;
        int[] d = new int[n];
        long total = 0, k = (long) k1 + k2;
        for (int i = 0; i < n; i++) {
            d[i] = Math.abs(nums1[i] - nums2[i]);
            total += d[i];
            max = Math.max(max, d[i]);
        }
        if (k >= total) return 0;
        int lo = 0, hi = max;
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            long cost = 0;
            for (int x : d) cost += Math.max(0, x - mid);
            if (cost <= k) hi = mid;
            else lo = mid + 1;
        }
        long used = 0, ans = 0;
        for (int x : d) {
            int y = Math.min(x, lo);
            used += x - y;
            ans += (long) y * y;
        }
        return ans - (k - used) * (2L * lo - 1);
    }
}

var minSumSquareDiff = function(nums1, nums2, k1, k2) {
    const d = nums1.map((x, i) => Math.abs(x - nums2[i]));
    const k = k1 + k2;
    let total = 0, hi = 0;
    for (const x of d) {
        total += x;
        hi = Math.max(hi, x);
    }
    if (k >= total) return 0;
    let lo = 0;
    while (lo < hi) {
        const mid = Math.floor((lo + hi) / 2);
        let cost = 0;
        for (const x of d) cost += Math.max(0, x - mid);
        if (cost <= k) hi = mid;
        else lo = mid + 1;
    }
    let used = 0, ans = 0;
    for (const x of d) {
        const y = Math.min(x, lo);
        used += x - y;
        ans += y * y;
    }
    return ans - (k - used) * (2 * lo - 1);
};

Python

from typing import List

class Solution:
    def minSumSquareDiff(self, nums1: List[int], nums2: List[int],
                         k1: int, k2: int) -> int:
        d = [abs(a - b) for a, b in zip(nums1, nums2)]
        k = k1 + k2
        if k >= sum(d):
            return 0
        lo, hi = 0, max(d)
        while lo < hi:
            mid = (lo + hi) // 2
            cost = sum(max(0, x - mid) for x in d)
            if cost <= k:
                hi = mid
            else:
                lo = mid + 1
        used = sum(max(0, x - lo) for x in d)
        ans = sum(min(x, lo) ** 2 for x in d)
        return ans - (k - used) * (2 * lo - 1)
