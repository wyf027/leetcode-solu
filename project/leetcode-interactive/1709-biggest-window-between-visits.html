LeetCode 1709 · Temporal analytics

访问日期之间
最大的空档期Biggest Window Between Visits

一份零售访问日志里，真正重要的不只是“来过几次”，而是两次到访之间沉默了多久。先读题，再沿时间轴逐步观察每位用户的访问间隔。

截止日固定：2021-01-01按 user_id 升序返回输出最大天数差
Problem brief

题目转述

表 UserVisits 记录用户访问某零售商的日期。把“今天”固定视为 2021-01-01。

对每位用户，将每次访问与其按日期排列后的下一次访问配对；如果当前记录已经是该用户最后一次访问，就与固定的“今天”配对。计算每个配对相隔的天数，并取其中最大值作为 biggest_window。

结果每位用户一行，并按 user_id 升序排列。

参数形式：本题为数据库题，输入参数是整张 UserVisits(user_id INT, visit_date DATE) 表，输出列为 user_id, biggest_window。
列名类型含义
user_idINT用户编号
visit_dateDATE访问日期

约束与约定

  • 表没有主键，并且可能包含重复行。
  • 每位出现在表中的用户都需要返回一行。
  • 日期差按自然日天数计算，不包含时分秒。
  • 公开题面未给出额外的数值范围。

Solution

把“下一次访问”变成当前行的一列

按用户分区、按日期排序后，每一行只缺一个信息：下一次访问日期。补出它，再求日期差与分组最大值，问题就从“比较行”变成了普通聚合。

完整过程

  1. 用 PARTITION BY user_id 隔离不同用户。
  2. 在每个分区内按 visit_date 排序。
  3. 用 LEAD 取下一日期；末行默认补 2021-01-01。
  4. 用 DATEDIFF(next_date, visit_date) 得到每段空档。
  5. 按用户分组取 MAX，最后按用户编号排序。

边界情况

  • 只有一次访问：答案就是该日期到截止日的天数。
  • 重复访问日期：会产生 0 天空档，不会错误放大最大值。
  • 输入无序：窗口函数内部的排序负责恢复时间顺序。
  • 跨月、跨年：交给数据库日期运算，避免手算月份天数。
Correctness

正确性说明

1

邻接完整性：对某个用户按访问日期排序后，LEAD 为每条非末记录返回紧随其后的访问日期，所以所有相邻访问对都被且仅被表示一次。

2

末段完整性：该用户的最后一条记录没有后继，默认值将其与固定日期 2021-01-01 配对，因此题目要求的最后一个空档也被包含。

3

最大值正确：中间结果已包含该用户要求考察的全部空档，按用户取 MAX 必然得到且仅得到最大的天数差。

复杂度：设记录数为 n。窗口排序通常为 O(n log n) 时间；窗口结果和排序工作区通常需要 O(n) 额外空间，具体由数据库执行器决定。

WITH visit_gaps AS (
    SELECT
        user_id,
        DATEDIFF(
            LEAD(visit_date, 1, '2021-01-01') OVER (
                PARTITION BY user_id
                ORDER BY visit_date
            ),
            visit_date
        ) AS gap_days
    FROM UserVisits
)
SELECT user_id, MAX(gap_days) AS biggest_window
FROM visit_gaps
GROUP BY user_id
ORDER BY user_id;
import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.*;

public class Solution {
    // record: [userId, yyyy-MM-dd]
    public static Map<Integer, Long> biggestWindow(List<String[]> records) {
        Map<Integer, List<LocalDate>> visits = new TreeMap<>();
        for (String[] row : records) {
            int userId = Integer.parseInt(row[0]);
            visits.computeIfAbsent(userId, k -> new ArrayList<>())
                  .add(LocalDate.parse(row[1]));
        }

        LocalDate today = LocalDate.of(2021, 1, 1);
        Map<Integer, Long> answer = new LinkedHashMap<>();
        for (Map.Entry<Integer, List<LocalDate>> entry : visits.entrySet()) {
            List<LocalDate> dates = entry.getValue();
            Collections.sort(dates);
            long best = 0;
            for (int i = 0; i < dates.size(); i++) {
                LocalDate next = i + 1 < dates.size() ? dates.get(i + 1) : today;
                best = Math.max(best, ChronoUnit.DAYS.between(dates.get(i), next));
            }
            answer.put(entry.getKey(), best);
        }
        return answer;
    }
}
// record: [userId, 'yyyy-MM-dd']
function biggestWindow(records) {
  const visits = new Map();
  for (const [userId, date] of records) {
    if (!visits.has(userId)) visits.set(userId, []);
    visits.get(userId).push(date);
  }

  const toUtc = (date) => Date.parse(`${date}T00:00:00Z`);
  const day = 86_400_000;
  const today = toUtc('2021-01-01');

  return [...visits.entries()]
    .sort(([a], [b]) => a - b)
    .map(([userId, dates]) => {
      dates.sort();
      let best = 0;
      for (let i = 0; i < dates.length; i++) {
        const next = i + 1 < dates.length ? toUtc(dates[i + 1]) : today;
        best = Math.max(best, (next - toUtc(dates[i])) / day);
      }
      return { user_id: userId, biggest_window: best };
    });
}
from collections import defaultdict
from datetime import date
from typing import Iterable

def biggest_window(records: Iterable[tuple[int, str]]) -> list[dict[str, int]]:
    visits: dict[int, list[date]] = defaultdict(list)
    for user_id, value in records:
        visits[user_id].append(date.fromisoformat(value))

    today = date(2021, 1, 1)
    answer: list[dict[str, int]] = []
    for user_id in sorted(visits):
        dates = sorted(visits[user_id])
        ends = dates[1:] + [today]
        best = max((end - start).days for start, end in zip(dates, ends))
        answer.append({"user_id": user_id, "biggest_window": best})
    return answer
#include <algorithm>
#include <map>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

class Solution {
    static int serial(const string& s) {
        int y = stoi(s.substr(0, 4));
        unsigned m = stoi(s.substr(5, 2));
        unsigned d = stoi(s.substr(8, 2));
        y -= m <= 2;
        const int era = (y >= 0 ? y : y - 399) / 400;
        const unsigned yoe = static_cast<unsigned>(y - era * 400);
        const unsigned doy = (153 * (m + (m > 2 ? -3 : 9)) + 2) / 5 + d - 1;
        const unsigned doe = yoe * 365 + yoe / 4 - yoe / 100 + doy;
        return era * 146097 + static_cast<int>(doe);
    }
public:
    // record: (userId, yyyy-MM-dd)
    vector<pair<int, int>> biggestWindow(
        const vector<pair<int, string>>& records) {
        map<int, vector<int>> visits;
        for (const auto& [userId, value] : records)
            visits[userId].push_back(serial(value));

        const int today = serial("2021-01-01");
        vector<pair<int, int>> answer;
        for (auto& [userId, dates] : visits) {
            sort(dates.begin(), dates.end());
            int best = 0;
            for (size_t i = 0; i < dates.size(); ++i) {
                int next = i + 1 < dates.size() ? dates[i + 1] : today;
                best = max(best, next - dates[i]);
            }
            answer.push_back({userId, best});
        }
        return answer;
    }
};
Alternatives & interview

替代方案与追问

替代方案

可以自连接同一用户的更晚日期，并对每次访问取最小的后继日期，再补截止日并取最大差值。它无需窗口函数，但连接会产生更多候选行，SQL 更长，通常也更难优化。

也可以把固定截止日作为每个用户的一条哨兵记录 UNION ALL 进去，再对完整序列使用 LAG。思路同样正确，但多了一层用户集合与哨兵构造。

面试追问

  • 如果“今天”是动态日期，应使用 CURRENT_DATE 还是传入业务结算日？
  • 若同一天的重复记录应先去重，应该在哪一层执行 DISTINCT？
  • 若要求每位用户的最大空档起止日期，如何用 ROW_NUMBER 保留获胜行？
  • 数据量很大时，(user_id, visit_date) 复合索引能帮助哪些阶段？

常见错误

  • 把跨用户的下一行当作下一次访问，遗漏 PARTITION BY user_id。
  • 只比较真实访问之间的间隔，忘记最后一次访问到 2021-01-01 的空档。
  • DATEDIFF 参数顺序颠倒，得到负数。
  • 先全表取最大值再分组，导致每个用户拿到同一个结果。
  • 误把本题的“window”理解成固定长度滑动窗口；这里指两个日期之间的时间空档。
