袋子里最少数目的球

不要真的模拟每一次拆袋。先猜一个“最大袋容量”，再计算实现它究竟需要多少次拆分。

中等ArrayBinary Search非付费题

Problem

题目

给定整数数组 nums，其中 nums[i] 表示第 i 个袋子里的球数；另给定整数 maxOperations。

一次操作可以选一个袋子，将其中的球拆到两个新袋子中，且两个新袋子的球数都必须是正整数。最多操作 maxOperations 次。操作结束后，所有袋子中球数的最大值称为“开销”，请返回能够得到的最小开销。

函数形式
minimumSize(nums, maxOperations) → integer

完整示例

示例 1
输入：nums = [9], maxOperations = 2
输出：3
解释：[9] → [6,3] → [3,3,3]，最大袋为 3。
示例 2
输入：nums = [2,4,8,2], maxOperations = 4
输出：2
解释：[2,4,8,2] → [2,4,4,4,2]
     → [2,2,2,4,4,2] → [2,2,2,2,2,4,2]
     → [2,2,2,2,2,2,2,2]，最大袋为 2。
示例 3
输入：nums = [7,17], maxOperations = 2
输出：7

Solution

二分答案：寻找最小可行容量

核心洞察

若限定每袋最多 x 个球，一个有 n 个球的袋子最终至少分成 ceil(n / x) 袋，因此需要：

ceil(n / x) - 1 = floor((n - 1) / x)

把所有袋子的次数相加；总数不超过操作上限，说明 x 可行。

为什么可以二分？

容量越大，需要的拆分次数只会减少。因此候选值呈现单调序列：

不可行 … 不可行 | 可行 … 可行

目标是第一个“可行”的容量。

完整过程

确定区间。答案至少是 1，至多为数组最大值；令 left = 1、right = max(nums)。
尝试中点。计算 mid，并累加每个袋子的 floor((num-1)/mid)。
收缩区间。若总操作数不超过上限，令 right = mid；否则令 left = mid + 1。
返回收敛点。当 left == right，它就是最小可行容量。

正确性证明

引理 1：大小为 n 的袋子在容量上限 x 下最少需要 floor((n-1)/x) 次拆分。最终至少需要 ceil(n/x) 个袋子，而一次拆分恰好使袋子数增加 1。

引理 2：若容量 x 可行，则任意 y ≥ x 也可行，因为放宽容量不会增加所需拆分次数。

定理：中点可行时最小解仍在 [left, mid]；不可行时最小解在 [mid+1, right]。二分始终保留最小可行值，最终收敛点即答案。

复杂度

时间：O(n log M)空间：O(1)

M = max(nums)；每次判定扫描数组，值域最多约二分 30 轮。

边界

  • num == mid 时公式给出 0。
  • 整除时用 (num-1)/mid 避免多算。
  • Java/C++ 用 64 位数累计操作次数。
  • 累计超过预算即可提前停止判定。

替代方案

优先队列逐次拆袋很难稳定定义每一步的最优收益，而且 maxOperations 可达 10⁹，逐次模拟不可行。二分答案直接利用单调性，更简洁可靠。

常见错误

  • 把次数写成 num / limit，整除时多算。
  • 混用不同二分模板，漏掉最小可行值。
  • 真正创建所有拆出的袋子。
  • 累加操作数时发生 32 位溢出。

class Solution {
    public int minimumSize(int[] nums, int maxOperations) {
        int left = 1, right = 0;
        for (int num : nums) right = Math.max(right, num);
        while (left < right) {
            int mid = left + (right - left) / 2;
            long operations = 0;
            for (int num : nums) {
                operations += (num - 1L) / mid;
                if (operations > maxOperations) break;
            }
            if (operations <= maxOperations) right = mid;
            else left = mid + 1;
        }
        return left;
    }
}
