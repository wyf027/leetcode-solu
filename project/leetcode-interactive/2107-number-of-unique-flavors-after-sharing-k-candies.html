01 / 问题

连续送出，保留多样性

整数数组 candies 按原顺序排列，candies[i] 是第 i 颗糖果的口味。选择恰好 k 颗连续糖果送给妹妹，其余糖果归你。返回你最多能保留多少种不同口味。同一种口味保留多颗，只算一种。

不能重新排序，也不能从不相邻的位置凑够 k 颗。k = 0 时无需送出糖果。

参数与返回值

shareCandies(candies: integer[], k: integer)
→ integer

约束

  • 0 ≤ candies.length ≤ 10⁵
  • 1 ≤ candies[i] ≤ 10⁵
  • 0 ≤ k ≤ candies.length

04 / 独立题解

准备好对照思路了吗？

展开后可查看推导、正确性与四语言完整实现。

固定长度窗口，维护窗外库存

核心洞察

目标取决于窗外还剩哪些口味。同一种口味被送走一颗，只有它在保留区的最后一颗也消失时，种数才减少。用哈希表 kept 保存每种口味在窗外的正频次，表的大小就是当前保留种数。

完整过程

  1. 初始分享区间是 [0,k−1]。统计下标 k 到 n−1 的频次，作为保留库存，用键数初始化 best。
  2. k = 0 时，库存包含所有糖果，直接返回键数。
  3. 让 right 从 k 枚举到 n−1。旧窗口左端 right−k 回到保留区，对应频次加一；新右端 right 进入分享区，对应频次减一，为零则删除键。
  4. 完成这一对操作后，窗口长度仍为 k。更新 best，继续右移，最后返回 best。

示例 1 的初始窗口 [0,2] 外是 {3:2, 4:1}，种数为 2。移到 [1,3] 时归还口味 1，送出口味 3，库存变为 {1:1, 3:1, 4:1}，种数为 3。之后窗口 [2,4]、[3,5] 的种数分别为 3、2，因此最大值是 3。

正确性证明

不变式：每次比较 best 前，kept 恰好记录当前分享区间外每种口味的正频次。初始化直接统计后缀，满足不变式。右移后两个分享区间的差异仅为旧左端和新右端；归还前者、扣除后者，正好更新窗外集合。其他位置不变，零频次键被删除，所以键数准确表示剩余种数。

最优性：对于 k > 0，所有合法起点 0 到 n−k 都被枚举一次。best 取这些准确种数的最大值，因而是全局最优值。k = 0 时所有空区间效果相同，统计全部口味即为答案。

边界与复杂度

  • 空数组：约束允许 n = 0，此时 k 只能为 0，答案是 0。
  • k = n：库存为空，无需右移，答案为 0。
  • 所有口味相同：只要剩下一颗，答案就是 1。
  • 所有口味不同：答案固定为 n−k。
  • 两端口味相同：先加再减，最终频次不变；应在两步完成后比较 best。

设 n 为糖果数，U 为不同口味总数。哈希操作平均 O(1)，总时间期望 O(n)，额外空间 O(U)，最坏为 O(n)。严重哈希碰撞下不保证最坏线性时间。交互演示为回退保存小数组快照，其开销不代表提交代码。

替代方案

  • 每个窗口重建集合：逐个枚举分享区间，再扫描所有保留位置，最坏 O(n²) 时间、O(U) 空间；适合作为后续小数据对照算法。
  • 总频次与窗内频次：当一种口味的窗内数量达到总数量时，该口味完全丢失。用总种数减去完全丢失种数也能得到答案，但需要维护等号跨越的状态。
  • 定长频次数组：口味值最多 10⁵，可用 100001 大小的数组并单独维护 distinct，确定性 O(n + V) 时间、O(V) 空间，V = 100001。

常见错误

  • 统计送出区间的种类，而不是留下来的种类。
  • 先排序，破坏原始的连续性。
  • 频次归零后不删除键，却仍用 Map.size 或 len 计算种数。
  • 漏掉初始窗口或最后一个合法起点。
  • 认为送出的种类越少越好，忽略窗外是否还存在同口味副本。

面试追问

如何返回具体区间？best 严格增大时记录起点，平局不覆盖就能保留最早最优区间；k = 0 可约定返回空区间 [0,0)。

若改成“最多送 k 颗”？在允许送 0 颗、没有其他要求时，直接保留所有口味即可。

若数组是环形？对于 0 < k < n，枚举 n 个起点，用下标取模移动窗口；k = 0 与 k = n 单独处理。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int shareCandies(int[] candies, int k) {
        Map<Integer, Integer> kept = new HashMap<>();
        for (int i = k; i < candies.length; i++) {
            int x = candies[i];
            kept.put(x, kept.getOrDefault(x, 0) + 1);
        }
        int best = kept.size();
        if (k == 0) return best;
        for (int right = k; right < candies.length; right++) {
            int back = candies[right - k];
            kept.put(back, kept.getOrDefault(back, 0) + 1);
            int give = candies[right];
            int remaining = kept.get(give) - 1;
            if (remaining == 0) kept.remove(give);
            else kept.put(give, remaining);
            best = Math.max(best, kept.size());
        }
        return best;
    }
}

    const kept = new Map();
    for (let i = k; i < candies.length; i++) {

        if (remaining === 0) kept.delete(give);
        else kept.set(give, remaining);
        best = Math.max(best, kept.size);

};

from typing import List

class Solution:
    def shareCandies(self, candies: List[int], k: int) -> int:
        kept = {}
        for i in range(k, len(candies)):
            x = candies[i]
            kept[x] = kept.get(x, 0) + 1
        best = len(kept)
        if k == 0:
            return best
        for right in range(k, len(candies)):
            back = candies[right - k]
            kept[back] = kept.get(back, 0) + 1
            give = candies[right]
            kept[give] -= 1
            if kept[give] == 0:
                del kept[give]
            best = max(best, len(kept))
        return best

C++

#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int shareCandies(vector<int>& candies, int k) {
        unordered_map<int, int> kept;
        int n = static_cast<int>(candies.size());
        for (int i = k; i < n; ++i) ++kept[candies[i]];
        int best = static_cast<int>(kept.size());
        if (k == 0) return best;
        for (int right = k; right < n; ++right) {
            ++kept[candies[right - k]];
            int give = candies[right];
            if (--kept[give] == 0) kept.erase(give);
            best = max(best, static_cast<int>(kept.size()));
        }
        return best;
    }
};
