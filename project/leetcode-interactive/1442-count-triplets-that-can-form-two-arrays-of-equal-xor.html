形成两个异或相等数组的三元组数目

Count Triplets That Can Form Two Arrays of Equal XOR

MEDIUM位运算前缀和哈希表
Problem

题目描述

给定整数数组 arr，选择下标 i、j、k，满足 0 ≤ i < j ≤ k < arr.length。令：

a = arr[i] ^ ... ^ arr[j - 1]
b = arr[j] ^ ... ^ arr[k]

其中 ^ 表示按位异或。返回使 a == b 的三元组 (i, j, k) 数量。

约束：1 ≤ arr.length ≤ 300；1 ≤ arr[i] ≤ 108。

Solution

题解：前缀异或 + 聚合计数

核心洞察

设 P[t] 是前 t 个元素的异或，P[0] = 0。左右两段异或相等时，把等式两边再次异或，得到整个区间 arr[i..k] 的异或为 0，也就是 P[i] = P[k+1]。

一旦某对前缀位置 i < r = k+1 的值相同，切分点 j 可以取 i+1..k，共有 k-i = r-i-1 种。因此无需逐个枚举 j。

当前前缀位置 r 的贡献 = Σ(r - i - 1) = count[x] × (r - 1) - indexSum[x] 其中 x = P[r]

完整过程

  1. 用哈希表记录每个前缀异或值出现的次数 count，以及出现位置之和 indexSum。
  2. 先登记空前缀：异或值 0 在位置 0 出现一次。
  3. 从左到右计算位置 r = 1..n 的前缀异或 x。
  4. 此前每个相同前缀位置 i 贡献 r-i-1；合并求和后加入答案。
  5. 把当前位置登记到两个哈希表中，供后续位置使用。

正确性证明

引理 1：三元组满足两段异或相等，当且仅当 P[i] = P[k+1]。这是因为 a ^ b 恰为区间 arr[i..k] 的异或，而 a=b 当且仅当 a^b=0。

引理 2：固定相同前缀位置 i 与 r=k+1 后，恰有 r-i-1 个合法 j。合法整数正是 i+1,...,r-1。

结论：算法在处理每个 r 时，对所有更早且前缀值相同的 i 汇总上述贡献。每个合法三元组由唯一的 (i,r,j) 对应，既不遗漏也不重复，因此答案正确。

边界情况

  • 长度为 1 时不存在 i < j，答案为 0。
  • 两个相同前缀若相邻，贡献 r-i-1=0，不会产生空区间。
  • 前缀异或为 0 时必须能匹配空前缀位置 0，所以要预先登记它。
  • 题目范围内答案可放入 32 位有符号整数；聚合公式仍建议按语言习惯使用安全数值类型。

复杂度

时间复杂度 O(n)，空间复杂度 O(n)；哈希操作按均摊 O(1) 计算。

替代方案

可以枚举 i、k 并滚动计算区间异或。当区间异或为 0 时直接累加 k-i，时间 O(n²)、额外空间 O(1)。在 n≤300 时也足够，且更容易现场写对；哈希聚合则展示了进一步优化能力。

面试追问

  • 为什么不是贡献 r-i？ 因为 j 不能等于 i，也不能等于 r。
  • 能否只保存次数？ 不能，贡献还依赖历史位置 i 的总和。
  • 若要求输出全部三元组？ 需保留每个前缀值的完整位置列表，再枚举匹配对与切分点，输出规模本身可能达到 O(n³)。

常见错误

  • 忘记初始化 P[0]=0，从而漏掉从数组开头开始的零异或区间。
  • 把当前前缀先写入哈希表再计算贡献，容易引入自己与自己匹配的错误。
  • 混淆数组下标 k 与前缀位置 r=k+1，导致公式差 1。
  • 三重循环逐个重算异或，退化到 O(n⁴)。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int countTriplets(int[] arr) {
        Map<Integer, Integer> count = new HashMap<>();
        Map<Integer, Integer> indexSum = new HashMap<>();
        count.put(0, 1);
        indexSum.put(0, 0);

        int prefix = 0;
        int answer = 0;
        for (int r = 1; r <= arr.length; r++) {
            prefix ^= arr[r - 1];
            int c = count.getOrDefault(prefix, 0);
            int sum = indexSum.getOrDefault(prefix, 0);
            answer += c * (r - 1) - sum;
            count.put(prefix, c + 1);
            indexSum.put(prefix, sum + r);
        }
        return answer;
    }
}

from collections import defaultdict
from typing import List

class Solution:
    def countTriplets(self, arr: List[int]) -> int:
        count = defaultdict(int)
        index_sum = defaultdict(int)
        count[0] = 1

        prefix = 0
        answer = 0
        for r, value in enumerate(arr, start=1):
            prefix ^= value
            answer += count[prefix] * (r - 1) - index_sum[prefix]
            count[prefix] += 1
            index_sum[prefix] += r
        return answer

            prefix ^= arr[r - 1];
            int c = count[prefix];
            int sum = indexSum[prefix];
            answer += c * (r - 1) - sum;
            count[prefix] = c + 1;
            indexSum[prefix] = sum + r;
        }
        return answer;
    }
