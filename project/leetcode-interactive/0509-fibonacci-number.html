Problem statement

题意

斐波那契数通常记作 F(n)。数列从 0 和 1 开始，此后的每一项都等于前两项之和。给定整数 n，返回 F(n)。

F(0) = 0，F(1) = 1
F(n) = F(n - 1) + F(n - 2)，n > 1

Input contract

约束与标签

  • 0 <= n <= 30
  • 参数：n: integer
  • 返回：integer

Complete solution

滚动变量：只保留真正需要的状态

核心洞察

计算 F(i) 时只依赖 F(i - 1) 和 F(i - 2)。因此无需保存完整数组；用两个变量维护这两项，每轮向前滚动即可。

完整过程

  1. 若 n < 2，直接返回 n。
  2. 令 prev = 0、curr = 1。
  3. 从下标 2 到 n，计算两者之和，再同步前移。
  4. 循环结束后，curr 就是 F(n)。

边界处理

  • n = 0 时答案为 0。
  • n = 1 时答案为 1。
  • 约束上界为 30，结果可安全放入 32 位有符号整数。

循环不变量

处理下标 i 之前，prev = F(i - 2) 且 curr = F(i - 1)；更新后，两者分别变为 F(i - 1) 与 F(i)。

正确性说明

初始化：循环首次处理 i = 2 前，prev = F(0)、curr = F(1)，不变量成立。保持：由递推定义，prev + curr = F(i)；滚动赋值后，两个变量恰好对应下一轮所需的连续两项。终止：最后一轮处理完 i = n，故 curr = F(n)。对 n < 2 的情况已由提前返回覆盖，因此算法对所有允许输入都返回定义中的值。

时间复杂度O(n)
额外空间复杂度O(1)

四语言完整代码

Java · LeetCode 可提交
class Solution {
    public int fib(int n) {
        if (n < 2) {
            return n;
        }

        int prev = 0;
        int curr = 1;
        for (int i = 2; i <= n; i++) {
            int next = prev + curr;
            prev = curr;
            curr = next;
        }
        return curr;
    }
}

class Solution:
    def fib(self, n: int) -> int:
        if n < 2:
            return n

        prev, curr = 0, 1
        for _ in range(2, n + 1):
            prev, curr = curr, prev + curr
        return curr

替代方案

  • 朴素递归：最贴近定义，但会反复计算相同子问题，时间复杂度约为 O(2^n)。
  • 记忆化递归：缓存每个结果，时间 O(n)、空间 O(n)。
  • DP 数组：直观保存从 0 到 n 的所有结果，时间与空间均为 O(n)。
  • 矩阵快速幂：可将时间降为 O(log n)，适合 n 很大时。

常见错误

  • 循环从错误下标开始，导致 n = 2 时多算或少算一轮。
  • 先覆盖 curr 再计算下一项，丢失上一轮旧值。
  • 遗漏 n = 0 的提前返回。
  • 把朴素递归误认为线性复杂度；它的调用树含有大量重复分支。
