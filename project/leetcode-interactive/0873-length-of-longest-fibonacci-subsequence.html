最长的斐波那契子序列的长度

Length of Longest Fibonacci Subsequence

873

01题目

如果一个长度至少为 3 的序列满足：从第三项起，每一项都等于前两项之和，那么它就是斐波那契式序列。

x[i] + x[i + 1] = x[i + 2]

给你一个由正整数组成、且严格递增的数组 arr。请从中选出一个保持原相对顺序的子序列，使它满足上述关系，并返回这样的子序列能达到的最大长度；若不存在长度至少为 3 的结果，返回 0。

子序列允许删除任意数量的元素，但不能改变剩余元素的先后顺序。

02官方示例

示例 1
输入：arr = [1,2,3,4,5,6,7,8]
输出：5
解释：最长斐波那契式子序列为 [1,2,3,5,8]。
示例 2
输入：arr = [1,3,7,11,12,14,18]
输出：3
解释：[1,11,12]、[3,11,14]、[7,11,18] 都是最长结果。

03约束与签名

  • 3 <= arr.length <= 1000
  • 1 <= arr[i] < arr[i+1] <= 10⁹
函数lenLongestFibSubseq(arr)
参数arr: integer[]
返回integer

05完整题解

核心洞察

下一项是否能接上，不只取决于当前末尾，还取决于倒数第二项。因此令 dp[j][i] 表示以 arr[j], arr[i] 结尾的最长斐波那契式子序列长度。要延长它，只需寻找 arr[k] = arr[i] - arr[j]。

为何哈希表有效

数组严格递增，所以每个值只有一个下标。用“值 → 下标”的映射即可在常数期望时间找到 k；同时要求 k < j，保证子序列顺序正确。

完整过程

  1. 建立每个数组值到其下标的映射。
  2. 枚举末尾下标 i，再枚举倒数第二个下标 j < i。
  3. 计算所需前驱 prev = arr[i] - arr[j]。
  4. 若 prev 存在且其下标 k < j，则令 dp[j][i] = dp[k][j] + 1。未显式出现的两元素状态长度视为 2。
  5. 维护所有有效状态的最大值；没有任何长度至少为 3 的状态时返回 0。

正确性说明

状态覆盖：任意长度至少为 3 的斐波那契式子序列都有唯一的最后两个下标 j,i，并且倒数第三项必为 arr[i]-arr[j]。算法枚举所有 j<i，不会漏掉它。
转移正确：若映射找到 k<j，则三项满足 arr[k]+arr[j]=arr[i]，把 arr[i] 接到以 k,j 结尾的最优序列后仍合法，长度恰加一。反之，没有这样的 k 就不存在能形成三项的合法前缀。故所有状态及最终最大值均正确。

边界与复杂度

时间 O(n²)空间 O(n²)

长度恰为 3 时返回 3；没有合法三元组返回 0。数值差在题目范围内安全，但通用实现仍应留意整数类型。

替代方案

可以从每一对起点开始，用集合不断查找两数之和，写法直观，最坏时间可达 O(n² log M) 或受数值增长影响；二维 DP 更稳定，也直接复用了重叠子问题。

面试追问

若数组不严格递增怎么办？此时“值 → 单一下标”不再成立，需要保存每个值的下标列表并保证索引顺序。若只求一个具体序列，可额外记录每个状态的前驱下标并回溯。

常见错误

把状态只设为一维；忘记检查 k<j；把两元素初始状态误设为 0；存在结果时忘记从 3 起计；无结果时错误返回 2。

四语言完整实现

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int lenLongestFibSubseq(int[] arr) {
        int n = arr.length;
        Map<Integer, Integer> index = new HashMap<>();
        for (int i = 0; i < n; i++) index.put(arr[i], i);

        int[][] dp = new int[n][n];
        int answer = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                int previous = arr[i] - arr[j];
                Integer k = index.get(previous);
                if (k != null && k < j) {
                    dp[j][i] = (dp[k][j] == 0 ? 2 : dp[k][j]) + 1;
                    answer = Math.max(answer, dp[j][i]);
                }
            }
        }
        return answer;
    }
}

                }
            }
