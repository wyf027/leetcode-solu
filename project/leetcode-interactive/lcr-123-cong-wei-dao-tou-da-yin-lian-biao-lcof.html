图书整理 I

给定一个单链表的头节点 head，将其中的图书编号按从尾到头的顺序返回为数组。

开始推演

首屏只说明任务与输入；题解默认隐藏。

题意

链表只能从头节点向后访问，但答案需要从最后一个节点开始排列。返回的数组中，第一个元素应是原链表的尾节点值。

示例

输入：head = [3,6,4,1]
输出：[1,4,6,3]

约束

  • 0 <= 链表节点数 <= 10000
  • 节点值范围为 0 到 10000

  3. 3空链表应该返回什么？

第 1 步：顺序遍历并收集

沿 next 指针从头走到尾，依次把编号放进数组。此时数组是 [3, 6, 4, 1]。

第 2 步：反转收集结果

数组已经保留全部节点值，原地反转或从后向前读取都能得到目标顺序。

第 3 步：返回答案

反转后的数组为 [1, 4, 6, 3]，正好是从尾到头的编号顺序。

SOLUTION

遍历 + 反转

核心洞察

单链表本身不支持倒序访问，但数组支持。将链表值按正序存储，再反转数组，就把访问限制与输出要求分离开了。

过程

  1. 创建空数组。
  2. 遍历链表，将每个 val 追加到数组。
  3. 反转数组并返回。

边界

  • head == null 时返回空数组。
  • 只有一个节点时，反转后保持不变。
  • 不要修改节点的 next 指针：题目要求的是数组。

复杂度

遍历和反转各一次，时间复杂度为 O(n)。保存 n 个值的数组，额外空间为 O(n)。

Java

class Solution {
    public int[] reverseBookList(ListNode head) {
        List<Integer> values = new ArrayList<>();
        for (ListNode node = head; node != null; node = node.next) values.add(node.val);
        Collections.reverse(values);
        return values.stream().mapToInt(Integer::intValue).toArray();
    }
}

        values = []
        while head:
            values.append(head.val)
            head = head.next
        return values[::-1]
class Solution {
public:
    vector<int> reverseBookList(ListNode* head) {
        vector<int> values;
        while (head) { values.push_back(head->val); head = head->next; }
        reverse(values.begin(), values.end());
        return values;
    }
};

替代方案与追问

递归在回溯阶段收集节点，也能天然得到倒序；但最深 10000 层可能造成栈风险。追问：若允许修改链表且要返回新头节点，则可以原地反转指针。

常见错误

  • 误把题目理解成返回反转后的链表。
  • 忘记处理空链表。
  • 在遍历时直接覆盖 next，导致后续节点丢失。
