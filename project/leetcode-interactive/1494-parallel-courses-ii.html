Parallel Courses II

每个学期最多修 k 门课。课程之间存在先修依赖，你需要安排一个用时最短、且严格遵守依赖的修课计划。

01题目说明

任务

共有 n 门课程，编号为 1 到 n。每个 relations[i] = [xᵢ, yᵢ] 表示课程 xᵢ 必须早于课程 yᵢ 完成。

一个学期最多选择 k 门课；本学期所选课程的全部先修课，必须已经在此前学期完成。返回修完所有课程需要的最少学期数。输入保证课程可以全部完成。

注意：同一学期内完成的课程，不能作为该学期另一门课的先修课。

函数与约束

minNumberOfSemesters(n, relations, k) → integer
  • 1 ≤ n ≤ 15
  • 1 ≤ k ≤ n
  • 0 ≤ relations.length ≤ n × (n − 1) / 2
  • relations[i].length == 2
  • 1 ≤ xᵢ, yᵢ ≤ n，且 xᵢ != yᵢ
  • 所有先修关系互不相同
  • 依赖图是有向无环图（DAG）
示例 1
输入：n = 4
relations = [[2,1],[3,1],[1,4]]
k = 2
输出：3
解释：依次选择 [2,3]、[1]、[4]。
示例 2
输入：n = 5
relations = [[2,1],[3,1],[4,1],[1,5]]
k = 2
输出：4
解释：可选择 [2,3]、[4]、[1]、[5]。
示例 3
输入：n = 11
relations = []
k = 2
输出：6

04完整题解

核心洞察

n ≤ 15 暗示可以用一个整数的二进制位记录已完成课程集合。令 mask 的第 i 位为 1，表示课程 i + 1 已完成；dp[mask] 表示抵达该集合所需的最少学期数。

对每个状态，找出所有“尚未完成且先修集合完全包含于 mask”的课程，组成 available。若它不超过 k 门，就全部选；否则枚举其中恰好含 k 门课的子集。

完整过程

dp[mask | take] = min(dp[mask | take], dp[mask] + 1)
  1. 预处理每门课的先修掩码 pre[i]。
  2. 从 mask = 0 开始枚举已完成集合。
  3. 用 (pre[i] & mask) == pre[i] 判断课程是否已解锁。
  4. 枚举合法的本学期集合 take，更新新状态。
  5. 答案为 dp[(1 << n) - 1]。

为什么只枚举 k 门？

可选课程超过 k 时，少选不会带来优势：当前所有可选课已经满足先修条件，多完成一门只会扩大之后的选择，不会使任何课程重新被锁定。因此存在一个最优方案在此时恰好选满 k 门。

复杂度

预处理与可选集计算需要 O(n·2ⁿ)。所有状态上的子集枚举最坏为 O(3ⁿ)；空间为 O(2ⁿ + n)。这里 n ≤ 15，可以承受。

边界

无依赖时答案为 ⌈n/k⌉；k = 1 时答案为 n；k = n 仍可能因依赖链需要多个学期；单条长链始终逐门推进。

正确性证明

引理 1：由状态 mask 计算出的 available 恰好是下一学期允许选择的全部课程。因为其中课程尚未完成，且其每一门先修课都已经包含在 mask 中；反之，任何合法课程也必然满足这两个条件。

引理 2：当可选课程数大于 k 时，至少存在一个最优方案选择恰好 k 门。若某最优方案只选了更少课程，可从当期未选的可选课中补入课程；它的先修条件已经满足，提前完成它不会破坏后续安排，因此学期数不会增加。

定理：算法得到最少学期数。依据引理 1 与引理 2，算法从每个可达状态枚举了某个最优计划可能采用的全部必要转移。每次转移恰好增加一个学期，动态规划取所有前驱中的最小值。因此全集状态的值不大于任何合法计划的学期数，同时每条转移都对应合法修课安排，故该值正是最优答案。

四语言完整代码

import java.util.Arrays;

class Solution {
    public int minNumberOfSemesters(int n, int[][] relations, int k) {
        int[] pre = new int[n];
        for (int[] edge : relations) {
            pre[edge[1] - 1] |= 1 << (edge[0] - 1);
        }
        int total = 1 << n;
        int[] dp = new int[total];
        Arrays.fill(dp, n + 1);
        dp[0] = 0;
        for (int mask = 0; mask < total; mask++) {
            if (dp[mask] > n) continue;
            int available = 0;
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) == 0 &&
                    (pre[i] & mask) == pre[i]) {
                    available |= 1 << i;
                }
            }
            if (Integer.bitCount(available) <= k) {
                int next = mask | available;
                dp[next] = Math.min(dp[next], dp[mask] + 1);
            } else {
                for (int take = available; take > 0;
                     take = (take - 1) & available) {
                    if (Integer.bitCount(take) == k) {
                        int next = mask | take;
                        dp[next] = Math.min(dp[next], dp[mask] + 1);
                    }
                }
            }
        }
        return dp[total - 1];
    }
}

var minNumberOfSemesters = function(n, relations, k) {
    const pre = new Array(n).fill(0);
    for (const [from, to] of relations) {
        pre[to - 1] |= 1 << (from - 1);
    }
    const total = 1 << n;
    const dp = new Array(total).fill(Infinity);
    dp[0] = 0;
    const bitCount = (value) => {
        let count = 0;
        while (value) {
            value &= value - 1;
            count++;
        }
        return count;
    };
    for (let mask = 0; mask < total; mask++) {
        if (!Number.isFinite(dp[mask])) continue;
        let available = 0;
        for (let i = 0; i < n; i++) {
            if ((mask & (1 << i)) === 0 &&
                (pre[i] & mask) === pre[i]) {
                available |= 1 << i;
            }
        }
        if (bitCount(available) <= k) {
            const next = mask | available;
            dp[next] = Math.min(dp[next], dp[mask] + 1);
        } else {
            for (let take = available; take > 0;
                 take = (take - 1) & available) {
                if (bitCount(take) === k) {
                    const next = mask | take;
                    dp[next] = Math.min(dp[next], dp[mask] + 1);
                }
            }
        }
    }
    return dp[total - 1];
};
from typing import List

class Solution:
    def minNumberOfSemesters(
        self, n: int, relations: List[List[int]], k: int
    ) -> int:
        pre = [0] * n
        for source, target in relations:
            pre[target - 1] |= 1 << (source - 1)
        total = 1 << n
        dp = [n + 1] * total
        dp[0] = 0
        for mask in range(total):
            if dp[mask] > n:
                continue
            available = 0
            for course in range(n):
                if not (mask & (1 << course)) and (
                    pre[course] & mask
                ) == pre[course]:
                    available |= 1 << course
            if available.bit_count() <= k:
                nxt = mask | available
                dp[nxt] = min(dp[nxt], dp[mask] + 1)
            else:
                take = available
                while take:
                    if take.bit_count() == k:
                        nxt = mask | take
                        dp[nxt] = min(dp[nxt], dp[mask] + 1)
                    take = (take - 1) & available
        return dp[total - 1]

替代方案

可以用 BFS 在位掩码状态图上逐层搜索，第一次到达全集即是答案；本质上与此处 DP 相同。也可做带记忆化的 DFS。只按入度贪心挑课并不可靠，因为当前选择会影响后续解锁速度。

面试追问

  • 为什么 available ≤ k 时可以全部选？
  • 怎样从一个掩码枚举所有子集？
  • 能否只枚举大小为 k 的组合来减少常数？
  • 若课程带权、每学期容量也变化，状态如何扩展？

常见错误

  • 把“同一学期所选课程”误当成彼此可提供先修条件。
  • 构造先修掩码时将边的方向写反。
  • 直接枚举 available 的所有子集，却忘记限制数量不超过 k。
  • 可选课程多于 k 时使用固定贪心规则，遗漏最优组合。
  • 更新成 dp[available]，而不是包含历史课程的 dp[mask | take]。
