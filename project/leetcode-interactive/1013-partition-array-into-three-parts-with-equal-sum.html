将数组分成和相等的三个部分

Partition Array Into Three Parts With Equal Sum。先理解“三个非空连续部分”的目标，再用扫描动画观察两个分割点如何自然出现。

难度：简单方法：一次扫描空间：O(1)

题目

给定整数数组 arr，判断能否把它切成三个非空、连续的部分，并让三部分的元素和完全相等。

需要找到下标 i、j，满足 i + 1 < j，并且 sum(arr[0..i]) = sum(arr[i+1..j-1]) = sum(arr[j..n-1])。

官方示例

输入：arr = [0,2,1,-6,6,-7,9,1,2,0,1]
输出：true
解释：0+2+1 = -6+6-7+9+1 = 2+0+1
输入：arr = [0,2,1,-6,6,7,9,-1,2,0,1]
输出：false
输入：arr = [3,3,6,5,-2,2,5,1,-9,4]
输出：true
解释：3+3 = 6 = 5-2+2+5+1-9+4

约束

  • 3 <= arr.length <= 5 × 10⁴
  • -10⁴ <= arr[i] <= 10⁴

题解：按目标和计数

核心洞察：设数组总和为 S。三段等和意味着每段都等于 S / 3，所以先排除 S % 3 != 0；随后逐项累加，每次累加值达到目标就完成一段并清零。

完整过程

  1. 计算总和 S。若不能被 3 整除，直接返回 false。
  2. 令目标和 target = S / 3，维护当前段和 sum 与完成段数 count。
  3. 从左到右把元素加入 sum；当 sum == target 时，令 count++ 并把 sum 清零。
  4. 最终判断 count >= 3。当目标为 0 时可能切出超过三段，把相邻的多余零和段合并即可得到恰好三段。

正确性证明

引理：每次扫描累加值达到 target 时，从上一切点之后到当前位置构成一个非空、和为目标值的连续部分。

充分性：若计数至少为 3，取前两次命中作为切点；剩余元素的总和等于 3×target - 2×target = target。若还有更多命中，可合并到第三部分，因此存在三个非空等和部分。

必要性：若合法三分存在，则总和必为三倍段和，能被 3 整除；按顺序扫描必然会在前两部分末尾命中目标，并最终完成至少三段。因此算法不会漏掉合法划分。

边界情况

  • 长度最小为 3，每段只能含一个元素。
  • 总和为负数不影响等式判断。
  • 总和为 0 时，至少需要出现三次零和段。
  • 不能把“子序列”误当成连续部分。

复杂度

时间复杂度 O(n)：求和与扫描均为线性过程。

额外空间复杂度 O(1)：只使用常数个变量。

四种语言完整代码

Java

class Solution {
    public boolean canThreePartsEqualSum(int[] arr) {
        int total = 0;
        for (int x : arr) total += x;
        if (total % 3 != 0) return false;

        int target = total / 3;
        int sum = 0, count = 0;
        for (int x : arr) {
            sum += x;
            if (sum == target) {
                count++;
                sum = 0;
            }
        }
        return count >= 3;
    }
}

var canThreePartsEqualSum = function(arr) {
    const total = arr.reduce((sum, x) => sum + x, 0);
    if (total % 3 !== 0) return false;

    const target = total / 3;
    let sum = 0;
    let count = 0;
    for (const x of arr) {
        sum += x;
        if (sum === target) {
            count++;
            sum = 0;
        }
    }
    return count >= 3;
};

from typing import List

class Solution:
    def canThreePartsEqualSum(self, arr: List[int]) -> bool:
        total = sum(arr)
        if total % 3 != 0:
            return False

        target = total // 3
        current = 0
        count = 0
        for value in arr:
            current += value
            if current == target:
                count += 1
                current = 0
        return count >= 3

替代方案

可以维护前缀和，寻找值分别为 S/3 和 2S/3 的两个位置，并保证第二个位置不在数组末尾。这同样是 O(n)，但切点边界更容易写错；段计数法更紧凑。

面试追问

  • 如果要返回所有合法切点组合，如何扩展？
  • 如果要求分成 k 个等和部分，判断条件如何变化？
  • 为什么存在负数时不能用“超过目标就停止”的贪心？

常见错误

  • 只判断找到了两次目标和，却没有确保第三部分非空。
  • 要求恰好命中三次；当目标为 0 时，命中次数可能超过 3，仍然可以合并。
  • 看到当前和超过目标就判失败；数组含负数，后续仍可能回落。
  • 使用浮点数目标进行比较；这里整数整除即可。
