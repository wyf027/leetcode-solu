The Latest Time to Catch a Bus

车会准点开走，座位有限。你能把到站时间推迟到哪一刻？

数组时间与排队离线单文件

01 / 读懂规则

给定公交发车时间数组 buses、乘客到站时间数组 passengers，以及每辆车的载客上限 capacity。两数组都可能无序，各自内部的时间互不相同。

  • 乘客按到站时间从早到晚排队，每次优先搭乘下一辆仍有座位的公交。
  • 到站时间小于或等于发车时间，就有资格上该车；满员后的乘客继续等待。
  • 你也遵循同一排队规则，且你的到站时间不能等于任何已有乘客的到站时间。

返回你能赶上任意一辆车的最晚整数到站时间。无需保证所有已有乘客都能上车。

约束

  • n == buses.length，m == passengers.length
  • 1 ≤ n, m, capacity ≤ 10⁵
  • 2 ≤ buses[i], passengers[i] ≤ 10⁹
  • buses 内元素互不相同；passengers 内元素互不相同。两个数组之间可以出现相同时间。

passengers = [2,17,18,19]

04 / 排队模拟，再向前找空时刻

核心洞察

先让原有乘客按规则上车。如果末班车还有座位，候选上界就是末班发车时间；如果已满，候选上界就是最后一名成功上车乘客的到站时间。然后向前退，跳过所有与乘客重合的时间。

满员时，这个上界本身不合法，但它准确定位了“最后一个可争取的座位”。退到未被占用的时间，你就能排在该乘客之前。

乘客到站时间（已排序）

完整过程

  1. 升序排序 buses 和 passengers；建立所有乘客时间的集合 occupied。
  2. 用指针 j 指向下一位未上车乘客。对每辆车把剩余座位 free 重置为 capacity。
  3. 当还有座位且 passengers[j] ≤ bus，让乘客上车，j++、free--。
  4. 所有车处理完成后，若 free > 0，令 answer = buses[n-1]；否则令 answer = passengers[j-1]。
  5. 只要 occupied 包含 answer，就令 answer--。返回最终值。

示例 1 原队列上车情况：10 → [2]，20 → [17,18]；候选 18 被占，退到 17 仍被占，退到 16 可用。

为什么正确

  1. 队列模拟准确：每辆车从最早未上车乘客开始，只接收已到站的人并遵守容量；归纳地，已处理车的分配与真实规则一致。
  2. 候选上界有效：末班车未满时，任何晚于末班发车时间的到站都不可行。末班车已满时，设最后上车者为 p；晚于 p 到站的人既无法越过先到者取得末班座位，也无法抢到此前已按队列分配的座位。此前若出现空位，则当时没有等待乘客，p 必在该班发车后才到达，晚于 p 的你同样赶不上它。
  3. 向前退不会破坏可行性：未满情形下，在末班发车前加入队列，总能取得末班空位，或更早上车；满员情形下，在 p 之前加入队列会排在 p 前面，可能使后续乘客逐车顺延，但你一定能在 p 原本占用的末班座位之前上车。
  4. 最晚性：从上界开始逐个整数回退，只跳过与已有乘客时间冲突的点。第一个未占用点可行，所有更晚点要么超过可行上界，要么违反不同时到达的规则，因此它就是最优答案。

边界与复杂度

  • 没人赶上末班车：返回其发车时刻，再处理重合。
  • 满车且容量为 1：依然取最后上车者的时间作上界。
  • 回退可能撞到已搭上更早班车的人，因此检查全体乘客时间。
  • 答案可为 1；原题只限制已有时间至少为 2，不限制答案必须至少为 2。
  • 排序 O(n log n + m log m)；模拟 O(n+m)；回退至多 m 次，不取决于时间跨度。
  • 集合采用通常的均摊常数查找假设。集合空间 O(m)，另加语言排序实现所需辅助空间；保守总空间界 O(n+m)。四份代码均原地排序输入。

替代方案与面试追问

  • 能去掉集合吗？可以。候选确定后，从 j-1 向左扫描已排序乘客；遇到与候选相同的值就同时递减。模拟后未上车者都晚于候选，因此不必扫描它们。额外状态为常数，另计排序空间。
  • 二分可以吗？“时间未被占用且能上车”有空洞，不能直接二分。可先二分忽略重合限制的排队可行边界，再跳过占用时刻；模拟成本更高，且同刻的排序规则必须先定义。
  • 各车容量不同？把每班重置的容量换为该车容量；原队列模拟与最后座位推理仍可沿用。

常见错误

  • 只看末班车前的乘客，漏掉早班车带走的人与留下的队列。
  • 把 arrival ≤ departure 写成严格小于，误判准点到站。
  • 满员时直接返回末班发车时间，或只把最后上车时间减 1 就返回。
  • 认为容量没用完就能直接返回发车时刻，忘了它可能与乘客重合。
  • JavaScript 排序忘记 (a, b) => a - b，导致按字符串顺序排序。
  • 空车时读取 passengers[j-1]：只有末班满员时才读取它，且此时一定有已上车乘客。

四语言完整实现

Java

import java.util.Arrays;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int latestTimeCatchTheBus(int[] buses, int[] passengers, int capacity) {
        Arrays.sort(buses);
        Arrays.sort(passengers);
        Set<Integer> occupied = new HashSet<>();
        for (int time : passengers) occupied.add(time);
        int j = 0, free = 0;
        for (int bus : buses) {
            free = capacity;
            while (free > 0 && j < passengers.length && passengers[j] <= bus) {
                j++;
                free--;
            }
        }
        int answer = free > 0 ? buses[buses.length - 1] : passengers[j - 1];
        while (occupied.contains(answer)) answer--;
        return answer;
    }
}

from typing import List

class Solution:
    def latestTimeCatchTheBus(self, buses: List[int], passengers: List[int], capacity: int) -> int:
        buses.sort()
        passengers.sort()
        occupied = set(passengers)
        j = 0
        free = 0
        for bus in buses:
            free = capacity
            while free > 0 and j < len(passengers) and passengers[j] <= bus:
                j += 1
                free -= 1
        answer = buses[-1] if free > 0 else passengers[j - 1]
        while answer in occupied:
            answer -= 1
        return answer

C++

#include <algorithm>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    int latestTimeCatchTheBus(vector<int>& buses, vector<int>& passengers, int capacity) {
        sort(buses.begin(), buses.end());
        sort(passengers.begin(), passengers.end());
        unordered_set<int> occupied(passengers.begin(), passengers.end());
        int j = 0, free = 0;
        for (int bus : buses) {
            free = capacity;
            while (free > 0 && j < static_cast<int>(passengers.size()) && passengers[j] <= bus) {
                ++j;
                --free;
            }
        }
        int answer = free > 0 ? buses.back() : passengers[j - 1];
        while (occupied.count(answer)) --answer;
        return answer;
    }
};
