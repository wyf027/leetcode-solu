好子数组的最大分数

Maximum Score of a Good Subarray

一段连续区间，一个必须覆盖的位置。怎样让「最低值 × 长度」尽可能大？

01 / 题目

给定从 0 开始编号的整数数组 nums 与下标 k。你需要选择连续区间 [i, j]，且满足 i ≤ k ≤ j。区间分数等于其中的最小元素乘以区间长度：

score(i, j) = min(nums[i…j]) × (j − i + 1)

返回所有满足条件的区间中的最大分数。

参数与约束

  • maximumScore(nums, k) → integer
  • 1 ≤ nums.length ≤ 100000
  • 1 ≤ nums[i] ≤ 20000
  • 0 ≤ k < nums.length

官方示例 1

nums = [1,4,3,7,4,5], k = 3
输出：15

选择 [1,5]，最小值 3，长度 5，分数 15。

官方示例 2

nums = [5,5,4,5,4,1,1,1], k = 0
输出：20

选择 [0,4]，最小值 4，长度 5，分数 20。

04 / 从 k 向两侧扩张

核心洞察

从 [k,k] 开始，每次把左右相邻元素中较大的那个纳入区间，尽量推迟最小值下降。相等时任选一侧；这里固定选右侧。每扩张一次，都更新最小值和历史最高分，不能只算最后一个区间。

交互 / 扩张轨迹

绿色为当前区间，紫色描边固定标记 k。柱高代表数值；下面同时展示最小值、宽度与面积。可编辑小数组观察两侧候选如何影响下一步。

完整过程

  1. 初始化 l = r = k，mn = ans = nums[k]。
  2. 只要还有可扩张的边界，就先处理数组边界：右端已到头必须向左；左端已到头必须向右。
  3. 两侧都存在时，比较 nums[l−1] 与 nums[r+1]，向较大的一侧扩张。
  4. 更新 mn，再用 mn × (r−l+1) 更新 ans。覆盖整个数组后返回 ans。

示例 1 的区间轨迹：[3,3] → [3,4] → [3,5] → [2,5] → [1,5] → [0,5]；对应分数 7、8、12、12、15、6。

为什么正确：按最小值阈值看扩张

任取一个最优区间 I，其最小值为 m。令 C 是包含 k、且所有元素都 ≥ m 的最大连续区间。I 包含于 C，所以 C 的分数至少为 m × |I|。

当算法的当前区间尚未覆盖 C 时，至少一侧存在属于 C 的相邻元素，数值 ≥ m；C 外紧邻元素若存在则小于 m。选择较大的相邻元素保证算法不会先跨出 C。因此算法必然到达恰好覆盖 C 的状态，并记录至少 m × |C| 的分数，从而不会错过最优值。

所有被记录的区间始终包含 k，都是合法解，所以答案也不会超过真正最优值。两边合起来即得正确性。相邻值相等时，两侧同属或同不属于阈值区间，任选一侧不影响论证。

边界与复杂度

  • n = 1 时直接返回 nums[k]；k 在端点时自然退化为单方向扩张。
  • 维护历史答案：更长的区间不一定分数更高。所有值为正是阈值扩张证明的重要条件。
  • 最多扩张 n−1 次：时间 O(n)，额外空间 O(1)。交互为回放保存 O(n) 个状态，不属于提交算法。
  • 最大分数 20000 × 100000 = 2,000,000,000，Java/C++ 的 32 位有符号整数可容纳；约束扩大时应使用 long / long long。

四语言完整实现

Java

class Solution {
    public int maximumScore(int[] nums, int k) {
        int n = nums.length, l = k, r = k;
        int mn = nums[k], ans = mn;
        while (l > 0 || r < n - 1) {
            if (r == n - 1 || (l > 0 && nums[l - 1] > nums[r + 1])) {
                mn = Math.min(mn, nums[--l]);
            } else {
                mn = Math.min(mn, nums[++r]);
            }
            ans = Math.max(ans, mn * (r - l + 1));
        }
        return ans;
    }
}

替代方案

单调栈：为每个元素求左右最近的严格更小元素，用弹出 ≥ 当前值的规则分别扫描两侧。若可延伸区间包含 k，计算该高度 × 区间宽度。时间 O(n)，空间 O(n)，适合复用柱状图最大矩形的思路。暴力枚举所有包含 k 的区间并维护最小值可做到 O(n²)，只适合小规模理解。

常见错误

  • 向较小邻居扩张：过早降低最小值，丢掉更高阈值的候选。
  • 把局部最小值直接设成新元素：应取历史 mn 与新元素的较小值。
  • 比较邻居前不检查边界，或把长度写成 r−l。
  • 只用最终整段分数、漏算初始单元素区间，或忘记区间必须包含 k。

面试追问

如何返回区间？ 每当 ans 严格变大时保存 l、r；并列时按要求加入长度或左端点规则。

允许负数还成立吗？ 不直接成立：负最小值乘更长区间反而更小，上述最大阈值区间论证失效。

与最大矩形有什么联系？ 都是最低高度乘宽度，本题额外要求矩形横跨 k，因此可以从固定锚点线性扩张。
