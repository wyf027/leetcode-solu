字母移位
Shifting Letters

一串针对“前缀”的移位操作，看似需要反复修改字符串；真正需要追踪的，是每个位置最终承受的累计移位量。

题目

给定一个仅含小写英文字母的字符串 s，以及与它等长的整数数组 shifts。一次移位会把字母变成字母表中的下一个字母，且 z 会环绕到 a。

对每个下标 i，把 s 的前 i + 1 个字符各向后移位 shifts[i] 次。返回完成全部操作后的字符串。

函数形式： shiftingLetters(s, shifts) → string
示例 1
输入：s = "abc", shifts = [3,5,9]
输出："rpl"
解释："abc" → "dbc" → "igc" → "rpl"
示例 2
输入：s = "aaa", shifts = [1,2,3]
输出："gfd"
约束
  • 1 ≤ s.length ≤ 10⁵
  • s 仅由小写英文字母组成
  • shifts.length == s.length
  • 0 ≤ shifts[i] ≤ 10⁹

题解：反向后缀累计

核心洞察

位置 j 会受到所有满足 i ≥ j 的操作影响，所以它的总移位量是 shifts[j] + shifts[j+1] + … + shifts[n-1]。这正是 shifts 的后缀和。只需从右向左维护一个累计值。

suffix = (suffix + shifts[i]) mod 26

完整过程

  1. 令 suffix = 0，并把字符串转成可修改的字符结构。
  2. 从下标 n - 1 递减到 0。
  3. 将 shifts[i] 加入 suffix，每次对 26 取模。
  4. 把字符映射到 0..25，加上 suffix 后再对 26 取模，最后映射回字母。

正确性说明

处理位置 i 时，累计量 suffix 恰好包含区间 [i, n-1] 的全部 shifts。这些操作且只有这些操作会覆盖字符串位置 i。因此对该字符应用 suffix 次移位后得到的就是最终字符。循环覆盖所有位置，故最终字符串正确。

边界与复杂度

  • 空移位值不会改变字符。
  • 用模 26 处理 z → a 与超大移位。
  • 时间复杂度：O(n)。
  • 额外空间：除结果字符结构外为 O(1)；语言字符串不可变时结果占 O(n)。

替代方案

可以先构造完整后缀和数组，再逐位变换，逻辑直观但额外占用 O(n) 空间。逐次模拟每个前缀则最坏达到 O(n²)，无法满足 10⁵ 的规模。

面试追问

  • 如果操作改为区间 [l, r] 加减移位，可使用差分数组。
  • 为何每步取模？它限制数值增长，且不改变最终字母。
  • 能否原地修改？取决于语言的字符串是否可变；算法本身只需常数状态。

常见错误

  • 从左向右累加，得到前缀和而不是所需的后缀和。
  • 忘记对 26 取模，或遗漏 z 的环绕。
  • Java 中用 int 累加所有原值而不及时取模，可能溢出。

class Solution {
    public String shiftingLetters(String s, int[] shifts) {
        char[] chars = s.toCharArray();
        int suffix = 0;
        for (int i = chars.length - 1; i >= 0; i--) {
            suffix = (suffix + shifts[i]) % 26;
            chars[i] = (char) ('a' + (chars[i] - 'a' + suffix) % 26);
        }
        return new String(chars);
    }
}

 * @param {string} s

var shiftingLetters = function(s, shifts) {
    const chars = s.split('');
    let suffix = 0;
    for (let i = chars.length - 1; i >= 0; i--) {
        suffix = (suffix + shifts[i]) % 26;
        const code = chars[i].charCodeAt(0) - 97;
        chars[i] = String.fromCharCode(97 + (code + suffix) % 26);
    }
    return chars.join('');
};

class Solution:
    def shiftingLetters(self, s: str, shifts: List[int]) -> str:
        chars = list(s)
        suffix = 0
        for i in range(len(chars) - 1, -1, -1):
            suffix = (suffix + shifts[i]) % 26
            code = ord(chars[i]) - ord('a')
            chars[i] = chr(ord('a') + (code + suffix) % 26)
        return ''.join(chars)
