解出数学表达式的学生分数

The Score of Students Solving Math Expression

结果相同，计算顺序未必相同。你会如何给这些答案评分？

官方题目 ↗

题意

给定合法表达式 s，仅包含个位数字、+ 和 *。标准顺序是从左到右先计算乘法，再从左到右计算加法。answers 记录每位学生提交的答案，请返回所有学生得分之和。

  • 答案等于标准结果：5 分。
  • 否则，如果只改变运算顺序且每步算术正确可以得到该答案：2 分。
  • 其他答案：0 分。

改变顺序可以用括号表示，但不能交换数字或运算符。即使顺序有误，只要结果正确仍给 5 分。

scoreOfStudents(s: string, answers: integer[]) → integer

约束

  • 3 ≤ s.length ≤ 31；s 是只含数字 0–9、+、* 的合法表达式。
  • 所有操作数都在 [0,9]；运算符数量为 1 到 15。
  • 标准结果在 [0,1000]，乘法中间步骤不超过 10⁹。
  • n = answers.length，1 ≤ n ≤ 10⁴。
  • 0 ≤ answers[i] ≤ 1000。

官方示例

示例 1

输入：s = "7+3*1*2", answers = [20,13,42]
输出：7

13 正确得 5 分；((7+3)*1)*2=20 得 2 分；42 得 0 分。

示例 2

输入：s = "3+5*2", answers = [13,0,10,13,13,16,16]
输出：19

三个 13 各得 5 分；两个 16 可以由 (3+5)*2 得到，各得 2 分；其余为 0 分。

示例 3

输入：s = "6+0*1", answers = [12,9,6,4,8,6]
输出：10

两个 6 各得 5 分。即便按 (6+0)*1 计算也得到 6，仍优先给 5 分。

想一想

怎样穷尽所有合法的计算顺序？重复出现的结果与重复提交的答案，需要相同的处理方式吗？

题解：区间结果集合

核心洞察与过程

任意括号结构都有最后计算的运算符。它把数字区间 [l,r] 切成 [l,k] 和 [k+1,r]。保存每个区间的所有可能结果，枚举切分点，组合左右集合。

  1. 维护当前乘积项，遇加号将乘积项累加，独立求标准答案。
  2. dp[i][i] 只含第 i 个数字。
  3. 按长度递增遍历区间。每个 k 都将左右集合的笛卡尔积用原运算符组合并去重。
  4. 先判断学生答案是否正确，再判断是否在完整区间集合中。

为严格保留零乘法的语义，把大于 1000 的结果统一压缩为哨兵 1001，而非丢弃。令 cap(x)=min(x,1001)，对非负整数的加法、乘法都有 cap(x ◦ y)=cap(cap(x) ◦ cap(y))。大数乘零仍能恢复零，范围内结果精确保留。

区间拼接台

固定表达式 7+3*1*2。每一步展示更长区间的结果集合；这是教学轨迹，不是测试执行结果。



正确性证明
对区间长度归纳。单数字区间显然正确。任意更长括号结构的最后一步必在某个 k 处切分；归纳假设保证左右结果均在集合中，枚举组合因此不会遗漏。反过来，每次组合来自合法子表达式并保留原顺序，所以不会加入无来源的结果。cap 的运算相容性保证所有 0…1000 的可达值仍精确。最后按 5、2、0 的优先规则逐项累加，得出总分。
复杂度
设数字数量为 m≤16，学生数为 n，每个集合最多 V=1002 个状态（包括哨兵）。期望时间 O(m³V²+n)，空间 O(m²V)，哈希操作按期望常数计；实际集合通常更小。
边界与常见错误
  • 正确结果可能也由错误顺序得到，必须优先给 5 分。
  • 集合去重的是表达式结果，学生答案重复仍重复计分。
  • 只尝试“先加后乘”不完整；必须枚举局部括号。
  • 数字下标 k 对应的后继运算符是 s[2k+1]。
  • 零会让大数变小，不能用“运算只会增大”论证剪枝。
  • 标准答案使用真实乘积计算，不使用哨兵。
替代方案
可用自顶向下区间记忆化替代按长度填表；两者状态与转移相同。纯枚举括号会产生 Catalan 数量的结构且重复计算。布尔数组可代替集合，但需要考虑稀疏遍历成本。
面试追问
多位数：先解析数字与运算符数组。加入减法或负数：大数可能抵消，当前 cap 不再有效，需重新定义范围。恢复一个括号式：为结果保存首次生成的切分点及左右值，再回溯。


JavaScript
var scoreOfStudents = function(s, answers) {
    const a = [...s].filter((_, i) => i % 2 === 0).map(Number);
    const m = a.length;
    let correct = 0, term = a[0];
    for (let i = 1; i < m; i++) {
        if (s[2*i-1] === '*') term *= a[i];
        else { correct += term; term = a[i]; }
    }
    correct += term;
    const dp = Array.from({length:m}, () => Array(m));
    for (let i = 0; i < m; i++) dp[i][i] = new Set([a[i]]);
    for (let len = 2; len <= m; len++) {
        for (let l = 0; l + len <= m; l++) {
            const r = l + len - 1, values = new Set();
            for (let k = l; k < r; k++)
                for (const x of dp[l][k]) for (const y of dp[k+1][r]) {
                    const v = s[2*k+1] === '+' ? x+y : x*y;
                    values.add(Math.min(1001, v));
                }
            dp[l][r] = values;
        }
    }
    return answers.reduce((sum, v) => sum +
        (v === correct ? 5 : dp[0][m-1].has(v) ? 2 : 0), 0);
};

from typing import List

class Solution:
    def scoreOfStudents(self, s: str, answers: List[int]) -> int:
        a = list(map(int, s[::2]))
        m = len(a)
        correct, term = 0, a[0]
        for i in range(1, m):
            if s[2*i-1] == '*':
                term *= a[i]
            else:
                correct += term
                term = a[i]
        correct += term
        dp = [[set() for _ in range(m)] for _ in range(m)]
        for i, v in enumerate(a):
            dp[i][i].add(v)
        for length in range(2, m + 1):
            for l in range(m - length + 1):
                r = l + length - 1
                for k in range(l, r):
                    for x in dp[l][k]:
                        for y in dp[k+1][r]:
                            v = x+y if s[2*k+1] == '+' else x*y
                            dp[l][r].add(min(1001, v))
        return sum(5 if v == correct else 2 if v in dp[0][m-1]
                   else 0 for v in answers)


Java
import java.util.*;
class Solution {
    public int scoreOfStudents(String s, int[] answers) {
        int m = (s.length()+1)/2;
        int[] a = new int[m];
        for (int i=0; i<m; i++) a[i] = s.charAt(2*i)-'0';
        int correct=0, term=a[0];
        for (int i=1; i<m; i++) {
            if (s.charAt(2*i-1)=='*') term *= a[i];
            else { correct += term; term = a[i]; }
        }
        correct += term;
        List<List<Set<Integer>>> dp = new ArrayList<>();
        for (int i=0; i<m; i++) {
            List<Set<Integer>> row = new ArrayList<>();
            for (int j=0; j<m; j++) row.add(new HashSet<>());
            row.get(i).add(a[i]);
            dp.add(row);
        }
        for (int len=2; len<=m; len++) {
            for (int l=0; l+len<=m; l++) {
                int r=l+len-1;
                for (int k=l; k<r; k++)
                    for (int x:dp.get(l).get(k))
                        for (int y:dp.get(k+1).get(r)) {
                            int v=s.charAt(2*k+1)=='+' ? x+y : x*y;
                            dp.get(l).get(r).add(Math.min(1001,v));
                        }
            }
        }
        int total=0;
        for (int v:answers)
            total += v==correct ? 5 : dp.get(0).get(m-1).contains(v) ? 2 : 0;
        return total;
    }
}
