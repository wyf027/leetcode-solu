大餐计数

Count Good Meals

从一桌餐品中任选两道：当美味程度之和恰好是 2 的幂，它们就组成一顿“大餐”。你需要数清所有按下标区分的搭配。

输入：integer[]输出：integer结果 mod 10⁹ + 7

01 题目说明

给定整数数组 deliciousness，第 i 个值代表第 i 道餐品的美味程度。任选两个下标不同的餐品；如果二者之和等于 2 的某个非负整数次幂，这一对就是一顿大餐。

返回不同大餐的数量，并对 10⁹ + 7 取余。即使两道餐品的数值相同，只要下标不同，也视作不同餐品。

函数形式： countPairs(deliciousness)，其中 deliciousness 为整数数组，返回整数。

示例 1

输入： deliciousness = [1,3,5,7,9]
输出： 4
解释： (1,3)、(1,7)、(3,5)、(7,9)
的和依次为 4、8、8、16。

示例 2

输入： deliciousness = [1,1,1,3,3,3,7]
输出： 15
解释： (1,1) 有 3 种，(1,3) 有 9 种，
(1,7) 有 3 种，共 15 种。

约束

  • 1 ≤ deliciousness.length ≤ 10⁵
  • 0 ≤ deliciousness[i] ≤ 2²⁰

03 哈希表枚举幂

核心洞察

每个美味程度最多是 2²⁰，所以两个值的和最多是 2²¹。可行目标只有 1, 2, 4, …, 2²¹ 这 22 个值。扫描当前值 x 时，对每个目标和 s 查询先前出现过多少个 s - x 即可。

新增配对数 = Σ freq[2ᵏ − x]，其中 0 ≤ k ≤ 21

完整过程

  1. 建立频次表 freq，只记录已经扫描过的餐品。
  2. 依次读取当前值 x，枚举从 1 到 2²¹ 的所有 2 的幂。
  3. 将 freq[target - x] 加入答案；不存在的补数贡献 0。
  4. 所有查询完成后，再把 x 写入频次表。这样不会让餐品与自己配对，每一对也只会在后一个下标到来时统计一次。
  5. 累计过程中持续对 10⁹ + 7 取余。

正确性证明

引理 1：算法不会漏掉任何大餐

任取一对下标 i < j 的大餐，其和为某个不超过 2²¹ 的 2 的幂 s。扫描到 deliciousness[j] 时，位置 i 已记录在频次表中；枚举到 s 时，查询的补数正是 deliciousness[i]，因此该对必被统计。

引理 2：算法不会重复或错误统计

频次表只含当前下标之前的元素，所以每次贡献都对应唯一的有序扫描关系 i < j，不会选中同一下标，也不会在之后反向重复统计。只有当枚举目标是 2 的幂且补数真实存在时才累加，因此不会统计非大餐。

结论

由两个引理，算法统计且仅统计所有合法下标对，返回值正确。

边界情况

  • 数组仅有一个元素：没有可选的两个不同下标，答案为 0。
  • 包含 0：例如 0 + 1 = 1 合法；目标幂必须从 1 开始枚举。
  • 重复数值：频次直接贡献组合数量，例如第 3 个 1 到来时可与前两个 1 分别配对。
  • 最大值 2²⁰ 可与另一个最大值组成 2²¹，所以上界必须包含 2²¹。
  • 答案可能很大：使用足够宽的整数，并按题意取模。

复杂度

每个元素固定枚举 22 个目标和，时间复杂度为 O(22n) = O(n)；频次表最多保存 n 个不同值，空间复杂度为 O(n)。

替代方案

可以先统计全局频次，再枚举“数值对”，但要谨慎处理相同数值的组合数与去重；也可以对每个目标和排序后使用双指针，但 22 次扫描会达到 O(n log n + 22n)，实现更绕。单遍哈希表最直接。

面试追问

  • 为什么只枚举到 2²¹？ 两个输入值均不超过 2²⁰，最大和正好是 2²¹。
  • 为何先查询再入表？ 保证只连接当前元素与更早元素，从结构上杜绝自配对和重复计数。
  • 若目标集合不是 2 的幂怎么办？ 只要目标集合规模较小，仍可枚举目标并查补数；复杂度变为 O(nm)。

常见错误

  • 遗漏目标和 1，导致包含 0 的有效配对丢失。
  • 只枚举到 2²⁰，漏掉两个大值组成的 2²¹。
  • 当前值先入表再查询，使其可能与自己配对。
  • 把相同美味程度当成同一道餐品，忽略下标不同即是不同选择。
  • 使用 32 位累计答案而在取模前溢出。

Java

import java.util.HashMap; import java.util.Map; class Solution { public int countPairs(int[] deliciousness) { final int MOD = 1_000_000_007; Map<Integer, Integer> freq = new HashMap<>(); long answer = 0; for (int value : deliciousness) { for (int target = 1; target <= (1 << 21); target <<= 1) { answer += freq.getOrDefault(target - value, 0); } answer %= MOD; freq.put(value, freq.getOrDefault(value, 0) + 1); } return (int) answer; } }

JavaScript

/** * @param {number[]} deliciousness * @return {number} */ var countPairs = function(deliciousness) { const MOD = 1_000_000_007; const freq = new Map(); let answer = 0; for (const value of deliciousness) { for (let target = 1; target <= 2 ** 21; target *= 2) { answer = (answer + (freq.get(target - value) || 0)) % MOD; } freq.set(value, (freq.get(value) || 0) + 1); } return answer; };

Python

from collections import defaultdict from typing import List class Solution: def countPairs(self, deliciousness: List[int]) -> int: mod = 1_000_000_007 freq = defaultdict(int) answer = 0 for value in deliciousness: target = 1 while target <= 1 << 21: answer += freq[target - value] target <<= 1 answer %= mod freq[value] += 1 return answer

C++

#include <unordered_map> #include <vector> using namespace std; class Solution { public: int countPairs(vector<int>& deliciousness) { static constexpr int MOD = 1'000'000'007; unordered_map<int, int> freq; long long answer = 0; for (int value : deliciousness) { for (int target = 1; target <= (1 << 21); target <<= 1) { auto it = freq.find(target - value); if (it != freq.end()) answer += it->second; } answer %= MOD; ++freq[value]; } return static_cast<int>(answer); } };
