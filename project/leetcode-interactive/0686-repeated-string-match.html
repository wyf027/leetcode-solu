重复叠加字符串匹配

Repeated String Match

给定两个非空字符串 a 与 b，求最少重复多少次 a，才能让 b 成为重复后字符串的子串；若无论如何都不能出现，返回 -1。

中等 字符串 字符串匹配 非付费题

题目说明

字符串 "abc" 重复 0 次是空字符串，重复 1 次是 "abc"，重复 2 次是 "abcabc"。返回满足条件的最小重复次数。

函数签名

repeatedStringMatch(a: string, b: string): integer

约束

  • 1 ≤ a.length, b.length ≤ 10⁴
  • a 和 b 仅由小写英文字母组成。

官方示例

输入
a = "abcd", b = "cdabcdab"
输出
3
解释
"abcd" 重复三次得到 "abcdabcdabcd"，其中包含 "cdabcdab"。
输入
a = "a", b = "aa"
输出
2
输入
a = "a", b = "a"
输出
1
输入
a = "abc", b = "wxyz"
输出
-1

Solution

长度下界 + 一次跨接缝检查

核心洞察

01 / 下界

先覆盖长度

设 n = |a|、m = |b|。任何能容纳 b 的重复串，重复次数都至少为 q = ⌈m / n⌉。

02 / 接缝

起点可能偏移

b 不一定从某一份 a 的开头出现，它可能从中间开始并跨越最后一个接缝，所以还要观察 q + 1 次。

03 / 截止

不必无限拼接

若 b 存在于无限周期串中，把起点平移到第一份 a 内后，它一定会在 q + 1 份 a 内结束。

完整过程

  1. 计算 q = ⌈b.length / a.length⌉，这是答案可能取到的最小次数。
  2. 构造 a 重复 q 次的字符串，用 KMP 判断其中是否包含 b；若包含，直接返回 q。
  3. 再追加一份 a，检查重复 q + 1 次的字符串；若包含，返回 q + 1。
  4. 两次都不包含，说明继续重复只会复现相同的周期位置，返回 -1。

正确性证明

引理 1：答案不小于 q。重复 r 次得到的字符串长度是 r·n。若其中能放下长度为 m 的 b，必有 r·n ≥ m，因此 r ≥ ⌈m/n⌉ = q。
引理 2：若 b 能出现，q + 1 次内必能出现。无限重复串以 n 为周期，可把任意一次匹配的起点平移到下标 [0, n-1]。其结束位置（开区间）小于 n + m；又因为 q·n ≥ m，所以 n + m ≤ (q+1)·n。因此完整匹配位于前 q+1 份 a 中。
定理：算法返回正确的最小答案。根据引理 1，先检查的 q 是唯一可能的更小候选；若失败，再检查 q+1。引理 2 保证若第二次仍失败，匹配不可能存在。故算法返回最小重复次数，或正确返回 -1。

复杂度

时间复杂度O(n + m)构造长度不超过 m + 2n 的文本，并用 KMP 线性匹配两次；常数级两次扫描不改变阶数。
空间复杂度O(n + m)重复串占线性空间，KMP 的 LPS 数组占 O(m)。

边界情况

  • a == b：第一次检查立即返回 1。
  • b 比 a 短但跨接缝，如 a="abc", b="cab"：需要 2 次。
  • b 含有 a 从未出现的字符：两次匹配均失败，返回 -1。
  • 高度重复字符，如 a="aaab", b="abaa"：朴素回退容易重复比较，KMP 保持线性扫描。
  • 题目保证输入非空，因此无需定义空串除法或空模式匹配语义。

四语言完整代码

四份实现均显式使用 KMP，避免把标准库子串搜索的最坏复杂度当作既定保证。

Java 
class Solution {
    public int repeatedStringMatch(String a, String b) {
        int q = (b.length() + a.length() - 1) / a.length();
        StringBuilder text = new StringBuilder((q + 1) * a.length());

        for (int i = 0; i < q; i++) {
            text.append(a);
        }
        if (containsKmp(text, b)) {
            return q;
        }

        text.append(a);
        return containsKmp(text, b) ? q + 1 : -1;
    }

    private boolean containsKmp(CharSequence text, String pattern) {
        int[] lps = buildLps(pattern);
        int j = 0;

        for (int i = 0; i < text.length(); i++) {
            while (j > 0 && text.charAt(i) != pattern.charAt(j)) {
                j = lps[j - 1];
            }
            if (text.charAt(i) == pattern.charAt(j)) {
                j++;
            }
            if (j == pattern.length()) {
                return true;
            }
        }
        return false;
    }

    private int[] buildLps(String pattern) {
        int[] lps = new int[pattern.length()];
        for (int i = 1, len = 0; i < pattern.length();) {
            if (pattern.charAt(i) == pattern.charAt(len)) {
                lps[i++] = ++len;
            } else if (len > 0) {
                len = lps[len - 1];
            } else {
                lps[i++] = 0;
            }
        }
        return lps;
    }
}

/**
 * @param {string} a
 * @param {string} b

var repeatedStringMatch = function(a, b) {
    const q = Math.ceil(b.length / a.length);
    let text = a.repeat(q);

    if (containsKmp(text, b)) {
        return q;
    }

    text += a;
    return containsKmp(text, b) ? q + 1 : -1;
};

function containsKmp(text, pattern) {
    const lps = buildLps(pattern);
    let j = 0;

    for (let i = 0; i < text.length; i++) {
        while (j > 0 && text[i] !== pattern[j]) {
            j = lps[j - 1];
        }
        if (text[i] === pattern[j]) {
            j++;
        }
        if (j === pattern.length) {
            return true;
        }
    }
    return false;
}

Python 
class Solution:
    def repeatedStringMatch(self, a: str, b: str) -> int:
        q = (len(b) + len(a) - 1) // len(a)
        text = a * q

        if self._contains_kmp(text, b):
            return q

        text += a
        return q + 1 if self._contains_kmp(text, b) else -1

    def _contains_kmp(self, text: str, pattern: str) -> bool:
        lps = self._build_lps(pattern)
        j = 0

        for char in text:
            while j > 0 and char != pattern[j]:
                j = lps[j - 1]
            if char == pattern[j]:
                j += 1
            if j == len(pattern):
                return True
        return False

    def _build_lps(self, pattern: str) -> list[int]:
        lps = [0] * len(pattern)
        i, length = 1, 0

        while i < len(pattern):
            if pattern[i] == pattern[length]:
                length += 1
                lps[i] = length
                i += 1
            elif length > 0:
                length = lps[length - 1]
            else:
                i += 1
        return lps
C++ 
class Solution {
public:
    int repeatedStringMatch(string a, string b) {
        int q = (static_cast<int>(b.size()) + a.size() - 1) / a.size();
        string text;
        text.reserve((q + 1) * a.size());

        for (int i = 0; i < q; ++i) {
            text += a;
        }
        if (containsKmp(text, b)) {
            return q;
        }

        text += a;
        return containsKmp(text, b) ? q + 1 : -1;
    }

private:
    bool containsKmp(const string& text, const string& pattern) {
        vector<int> lps = buildLps(pattern);
        int j = 0;

        for (char ch : text) {
            while (j > 0 && ch != pattern[j]) {
                j = lps[j - 1];
            }
            if (ch == pattern[j]) {
                ++j;
            }
            if (j == static_cast<int>(pattern.size())) {
                return true;
            }
        }
        return false;
    }

    vector<int> buildLps(const string& pattern) {
        vector<int> lps(pattern.size(), 0);
        for (int i = 1, len = 0; i < static_cast<int>(pattern.size());) {
            if (pattern[i] == pattern[len]) {
                lps[i++] = ++len;
            } else if (len > 0) {
                len = lps[len - 1];
            } else {
                lps[i++] = 0;
            }
        }
        return lps;
    }
};

替代方案

虚拟重复串 + KMP

扫描时用 a[i % n] 取字符，不实际构造重复串，可把额外文本空间降下来；但下标与最终重复次数的推导更容易写错。

Rabin–Karp

可在周期字符流上滚动哈希，平均效率好；若只用单哈希，必须处理碰撞，面试中通常不如 KMP 的确定性证明直接。

标准库 contains / find

代码最短，工程中通常足够；不过不同语言实现的最坏复杂度保证不同，不宜在严格复杂度证明中想当然地写成线性。

字符集合预检

若 b 含有 a 没有的字符，可立即返回 -1；它只是剪枝，不能判断字符顺序和周期位置。

面试追问

  • 为什么不是检查到 q + 2？要求候选人用“匹配起点平移到第一周期”与长度上界给出严格证明。
  • 如何不构造重复串？在至多 m + n 个字符的虚拟文本上做 KMP，用模运算访问 a。
  • 若输入通过流到达怎么办？保留 KMP 状态与当前位置模 n，逐字符推进；达到上界仍未匹配即可停止。
  • Unicode 会改变什么？需要明确按字节、码点还是用户可见字素匹配；不同语言默认字符串索引语义不同。

常见错误

只检查覆盖长度的 q 次

会漏掉跨最后一个接缝的匹配，例如 a="abc", b="cab"。

循环拼接直到“看起来够长”

缺少明确停止条件，可能多拼很多次，甚至写出无法终止的循环。

先枚举很多重复次数

重复串是周期性的；超过 q+1 不会产生新的起点相位，只会复现已有情况。

复杂度忽略字符串拼接

某些语言中的不可变字符串反复 += 可能产生额外复制，应使用批量重复或可变缓冲区。
