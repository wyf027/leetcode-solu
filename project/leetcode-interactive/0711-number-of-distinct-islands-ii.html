Problem statement

题意与判定规则

给定一个只包含 0 和 1 的二维网格，1 表示陆地。上下左右相邻的陆地组成一个岛屿。

你需要返回多少种岛屿形状

两个岛屿若能通过任意次数的平移、以 90° 为单位的旋转或镜像翻转彼此重合，就视为相同；否则视为不同。水域不会把对角接触的陆地连接起来。

输入 / 输出
numDistinctIslands2(grid: integer[][]) → integer
输入为完整网格，输出为等价类数量。
相同形状允许
  • 平移：整体移动，不拉伸。
  • 旋转：0° / 90° / 180° / 270°。
  • 翻转：镜像后也可继续旋转。
约束
  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 50
  • grid[i][j] 为 0 或 1

Canonical form

题解：为每个岛屿建立唯一规范形

关键不是比较岛屿两两是否等价，而是让同一等价类中的所有形状都映射到同一个字符串。

收集坐标

DFS / BFS 收集一个岛屿的所有绝对坐标，访问过的陆地就地标记或另设 visited。

枚举八种姿态

正方形的旋转与镜像一共给出 8 种坐标变换，覆盖题目允许的全部刚性对称。

选择最小表示

每种姿态排序、消除平移，再取字典序最小的序列作为规范签名。

Complete process

完整过程

遍历整个网格

遇到未访问的 1，就启动一次 DFS，得到当前岛屿的坐标集合 S。

生成 8 个变换集合

对每个点 (x,y)，分别生成 (x,y)、(x,-y)、(-x,y)、(-x,-y)、(y,x)、(y,-x)、(-y,x)、(-y,-x)。

排序并平移到共同原点

每个变换集合按坐标字典序排序，再让所有点减去排序后的第一个点。绝对位置随之消失。

选规范签名并计数

把 8 个归一化序列序列化，取字典序最小者放入哈希集合；最终集合大小就是答案。

Why it works

正确性证明

引理 1：枚举完整

平面正方格上的 90° 旋转与镜像组成 8 个对称变换。所列公式恰好覆盖这 8 个结果，因此题目允许的任意姿态都不会遗漏。

引理 2：归一化消除平移

同一坐标集合整体加上任意偏移后，排序首点也增加同一偏移；所有点减去首点得到的相对坐标保持不变。

引理 3：等价岛屿签名相同

若两个岛屿可经允许变换与平移重合，则它们的 8 个归一化候选集合相同，只是枚举次序可能不同，所以最小候选必然相同。

定理：算法返回正确答案

由引理 3，相同形状只进入哈希集合一次；若签名相同，则对应候选坐标完全一致，两个岛屿必可通过允许变换和平移重合。因此集合元素与不同形状一一对应。

Complexity

复杂度

设网格共有 N = m·n 个格子，单个岛屿有 k 个陆地格。

时间O(N log N)最坏一个岛屿覆盖全图；常数含 8 次变换。
空间O(N)DFS、候选坐标和签名集合。

Boundaries

边界处理

  • 全是水：从不启动 DFS，返回 0。
  • 单格岛屿：8 个候选都归一化为同一坐标。
  • 高度对称的形状：可能产生重复候选，不影响取最小值。
  • 细长岛屿：旋转后宽高互换，仍由交换 x/y 的变换覆盖。
  • DFS 可能较深；JavaScript / Python 可改用显式栈规避递归限制。

Implementations

四种语言完整代码

LeetCode Java 提交格式。

class Solution {
    private int rows, cols;
    private final int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

    public int numDistinctIslands2(int[][] grid) {
        rows = grid.length;
        cols = grid[0].length;
        Set<String> shapes = new HashSet<>();

        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (grid[r][c] == 1) {
                    List<int[]> island = new ArrayList<>();
                    dfs(grid, r, c, island);
                    shapes.add(canonical(island));
                }
            }
        }
        return shapes.size();
    }

    private void dfs(int[][] grid, int r, int c, List<int[]> island) {
        if (r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] == 0) return;
        grid[r][c] = 0;
        island.add(new int[]{r, c});
        for (int[] d : dirs) dfs(grid, r + d[0], c + d[1], island);
    }

    private String canonical(List<int[]> island) {
        List<List<int[]>> forms = new ArrayList<>();
        for (int i = 0; i < 8; i++) forms.add(new ArrayList<>());

        for (int[] p : island) {
            int x = p[0], y = p[1];
            int[][] t = {{x,y},{x,-y},{-x,y},{-x,-y},
                         {y,x},{y,-x},{-y,x},{-y,-x}};
            for (int i = 0; i < 8; i++) forms.get(i).add(t[i]);
        }

        List<String> keys = new ArrayList<>();
        for (List<int[]> form : forms) {
            form.sort((a, b) -> a[0] != b[0]
                ? Integer.compare(a[0], b[0]) : Integer.compare(a[1], b[1]));
            int ox = form.get(0)[0], oy = form.get(0)[1];
            StringBuilder key = new StringBuilder();
            for (int[] p : form) key.append(p[0] - ox).append(':').append(p[1] - oy).append(';');
            keys.add(key.toString());
        }
        Collections.sort(keys);
        return keys.get(0);
    }
}

/**
 * @param {number[][]} grid
 * @return {number}
 */
var numDistinctIslands2 = function(grid) {
    const m = grid.length, n = grid[0].length;
    const shapes = new Set();
    const dirs = [[1,0],[-1,0],[0,1],[0,-1]];

    function collect(sr, sc) {
        const points = [];
        const stack = [[sr, sc]];
        grid[sr][sc] = 0;
        while (stack.length) {
            const [r, c] = stack.pop();
            points.push([r, c]);
            for (const [dr, dc] of dirs) {
                const nr = r + dr, nc = c + dc;
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] === 1) {
                    grid[nr][nc] = 0;
                    stack.push([nr, nc]);
                }
            }
        }
        return points;
    }

    function canonical(points) {
        const forms = Array.from({ length: 8 }, () => []);
        for (const [x, y] of points) {
            const t = [[x,y],[x,-y],[-x,y],[-x,-y],
                       [y,x],[y,-x],[-y,x],[-y,-x]];
            t.forEach((p, i) => forms[i].push(p));
        }
        const keys = forms.map(form => {
            form.sort((a, b) => a[0] - b[0] || a[1] - b[1]);
            const [ox, oy] = form[0];
            return form.map(([x, y]) => `${x - ox}:${y - oy}`).join(';');
        });
        keys.sort();
        return keys[0];
    }

    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            if (grid[r][c] === 1) shapes.add(canonical(collect(r, c)));
        }
    }
    return shapes.size;
};

LeetCode Python 提交格式；使用显式栈收集岛屿。

from typing import List

class Solution:
    def numDistinctIslands2(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        shapes = set()
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

        def collect(sr: int, sc: int):
            points = []
            stack = [(sr, sc)]
            grid[sr][sc] = 0
            while stack:
                r, c = stack.pop()
                points.append((r, c))
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == 1:
                        grid[nr][nc] = 0
                        stack.append((nr, nc))
            return points

        def canonical(points):
            forms = [[] for _ in range(8)]
            for x, y in points:
                transformed = (
                    (x, y), (x, -y), (-x, y), (-x, -y),
                    (y, x), (y, -x), (-y, x), (-y, -x)
                )
                for i, point in enumerate(transformed):
                    forms[i].append(point)

            candidates = []
            for form in forms:
                form.sort()
                ox, oy = form[0]
                candidates.append(tuple((x - ox, y - oy) for x, y in form))
            return min(candidates)

        for r in range(m):
            for c in range(n):
                if grid[r][c] == 1:
                    shapes.add(canonical(collect(r, c)))
        return len(shapes)

LeetCode C++ 提交格式。

class Solution {
    int rows, cols;
    const int dirs[4][2] = {{1,0},{-1,0},{0,1},{0,-1}};

    void dfs(vector<vector<int>>& grid, int r, int c,
             vector<pair<int,int>>& island) {
        if (r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] == 0) return;
        grid[r][c] = 0;
        island.push_back({r, c});
        for (auto& d : dirs) dfs(grid, r + d[0], c + d[1], island);
    }

    string canonical(const vector<pair<int,int>>& island) {
        vector<vector<pair<int,int>>> forms(8);
        for (auto [x, y] : island) {
            pair<int,int> t[8] = {
                {x,y},{x,-y},{-x,y},{-x,-y},
                {y,x},{y,-x},{-y,x},{-y,-x}
            };
            for (int i = 0; i < 8; ++i) forms[i].push_back(t[i]);
        }

        vector<string> keys;
        for (auto& form : forms) {
            sort(form.begin(), form.end());
            int ox = form[0].first, oy = form[0].second;
            string key;
            for (auto [x, y] : form) {
                key += to_string(x - ox) + ":" + to_string(y - oy) + ";";
            }
            keys.push_back(key);
        }
        return *min_element(keys.begin(), keys.end());
    }

public:
    int numDistinctIslands2(vector<vector<int>>& grid) {
        rows = grid.size();
        cols = grid[0].size();
        unordered_set<string> shapes;
        for (int r = 0; r < rows; ++r) {
            for (int c = 0; c < cols; ++c) {
                if (grid[r][c] == 1) {
                    vector<pair<int,int>> island;
                    dfs(grid, r, c, island);
                    shapes.insert(canonical(island));
                }
            }
        }
        return shapes.size();
    }
};

Alternatives

替代方案

两两匹配：为每对岛屿尝试 8 种姿态，直观但重复工作多，岛屿数量大时效率较差。

边界路径编码：只处理平移等价很方便，但加入旋转与翻转后需要对路径方向做 8 套变换，细节更容易出错。

几何不变量：距离多重集可快速排除不同形状，却不能保证唯一识别，可能出现碰撞。

Interview follow-ups

面试追问

如果只允许平移怎么办？

DFS 坐标减去固定起点并排序即可，不需要 8 种变换。

如果只允许旋转、不允许镜像？

只保留 4 个保持朝向类别的旋转变换。

怎样避免修改输入 grid？

使用同尺寸 visited 布尔矩阵，空间增加 O(mn)。

能否做到线性时间？

可为小坐标范围设计更复杂的线性编码，但排序方案更稳定、易证且在 50×50 约束内足够。

Pitfalls

常见错误

只减 DFS 起点旋转后“起点”未必仍是字典序首点；应对每个变换集合重新排序并归一化。
漏掉镜像或坐标交换只改变正负号无法覆盖 90° 旋转，必须包含 x/y 交换。
直接拼接数字例如 1,11 与 11,1 可能产生歧义；坐标和点之间需要明确分隔符。
用浮点旋转公式本题角度固定为 90°，整数交换与取反更精确，也无需处理舍入。
