Iterative parent map

把树临时变成可向上的路线图

树节点原本只有向下指针。用 DFS 建立 child→parent 后，问题变成两条到根路径的第一个交点。

完整过程与正确性

  1. 显式栈 DFS，记录 parent[child] = node，直到 p、q 都被发现。
  2. 从 p 不断沿 parent 到根，把整条祖先链放入集合。
  3. 从 q 向根移动，第一个属于集合的节点就是答案。

p 的祖先集合包含且仅包含根到 p 路径。q 向上按“从低到高”经过其所有祖先，所以首次进入集合的节点是两条路径中最靠近 q 的交点，也就是最深、即最低的公共祖先。

复杂度、边界与替代方案

主线

  • 最多访问全部节点一次，时间 O(n)。
  • parent、栈和祖先集合共 O(n) 空间。
  • 迭代实现不受 10⁵ 层偏斜树的语言递归深度限制。
  • 若 p 是 q 的祖先，q 上行会直接命中 p；根也可直接成为答案。

替代

  • 经典递归后序：左右都返回非空时当前节点为 LCA，代码更短，空间 O(h)。
  • 但最坏树高 10⁵，JavaScript/Python/Java/C++ 都可能栈溢出。
  • 若有大量 LCA 查询，可预处理倍增表，单次查询 O(log n)。
  • Euler Tour + RMQ 适合静态树高频查询。

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        Map<TreeNode, TreeNode> parent = new HashMap<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        parent.put(root, null);
        stack.push(root);

        while (!parent.containsKey(p) || !parent.containsKey(q)) {
            TreeNode node = stack.pop();
            if (node.left != null) {
                parent.put(node.left, node);
                stack.push(node.left);
            }
            if (node.right != null) {
                parent.put(node.right, node);
                stack.push(node.right);
            }
        }

        Set<TreeNode> ancestors = new HashSet<>();
        while (p != null) {
            ancestors.add(p);
            p = parent.get(p);
        }
        while (!ancestors.contains(q)) q = parent.get(q);
        return q;
    }
}

#include <stack>
#include <unordered_map>
#include <unordered_set>

class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        std::unordered_map<TreeNode*, TreeNode*> parent;
        std::stack<TreeNode*> nodes;
        parent[root] = nullptr;
        nodes.push(root);

        while (!parent.count(p) || !parent.count(q)) {
            TreeNode* node = nodes.top();
            nodes.pop();
            if (node->left) {
                parent[node->left] = node;
                nodes.push(node->left);
            }
            if (node->right) {
                parent[node->right] = node;
                nodes.push(node->right);
            }
        }

        std::unordered_set<TreeNode*> ancestors;
        while (p) {
            ancestors.insert(p);
            p = parent[p];
        }
        while (!ancestors.count(q)) q = parent[q];
        return q;
    }
};

面试追问

  • 递归版左右返回值如何汇合？
  • 多次查询如何做 binary lifting？
  • 若 p 或 q 可能不存在，怎样修改？
  • parent 映射能否只建到发现目标为止？

常见错误

  • 忽略“节点是自己的后代”。
  • 比较节点值而非节点引用（本题值虽唯一，但接口语义是节点）。
  • 只记录 p、q 的父节点，缺少完整上行链。
  • 从根找第一个公共点，得到的是最高而非最低。
  • 在 10⁵ 深树上无条件依赖递归栈。
