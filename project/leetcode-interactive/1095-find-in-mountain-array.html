山脉数组中查找目标值

HARD数组二分查找交互题

题意

给定只能通过 get(index) 与 length() 访问的严格山脉数组：它先严格递增至唯一峰顶，再严格递减。返回值等于 target 的最小下标；不存在则返回 -1。

评测限制：调用 MountainArray.get 超过 100 次会判错，不能直接读取底层数组。

约束

  • 3 ≤ mountainArr.length() ≤ 10⁴
  • 0 ≤ target ≤ 10⁹
  • 0 ≤ mountainArr.get(index) ≤ 10⁹

官方示例

输入：mountainArr = [1,2,3,4,5,3,1], target = 3
输出：2
解释：值 3 位于下标 2 和 5，返回较小的 2。
输入：mountainArr = [0,1,2,4,2,1], target = 3
输出：-1
解释：数组中不存在 3。

核心洞察

山脉的单调性把问题拆成三个二分：比较相邻值定位峰顶；在左侧做升序二分；仅当左侧未命中时，在右侧做降序二分。优先搜索左侧天然保证最小下标。

完整过程

  1. 在 [0,n-1] 内令 mid=(l+r)/2。若 get(mid)<get(mid+1)，峰顶在右侧（不含 mid）；否则峰顶在左侧（含 mid）。收敛点即峰顶。
  2. 对 [0,peak] 升序二分 target，命中立即返回。
  3. 对 [peak+1,n-1] 降序二分；降序中若当前值小于 target，应向左移动，反之向右移动。

正确性

峰顶：上升坡上的 mid 不可能是峰或在峰右侧，故舍弃左半；下降坡（含峰）则保留左半。循环始终包含峰且最终唯一。查找：两段分别严格单调，标准方向化二分不会排除可能答案。若左段存在答案，它的下标一定小于右段；因此先返回左段命中值即全局最小下标。两段皆无则目标不存在。

边界与复杂度

  • 峰值等于 target：左侧二分包含峰并返回它。
  • target 可能两坡各出现一次：必须先查左坡。
  • 峰顶不能位于首尾；长度最小为 3。
  • 时间 O(log n)，额外空间 O(1)，get 调用次数为 O(log n)。

替代方案

三分可用于单峰函数，但常数调用更多且仍需两侧查找；线性扫描会超过 100 次接口调用，不能通过最大数据。

面试追问

如何进一步减少 get 调用？

缓存已访问下标的值；也可在循环内保存 mid 值，避免同一轮重复访问。

为什么峰顶搜索用 mid+1 不越界？

循环条件是 l<r，且 mid 向下取整，所以 mid<r≤n-1。

常见错误

  • 先查右坡，错误返回较大下标。
  • 对降序区间仍使用升序的移动方向。
  • 峰顶二分写成 r=mid-1，可能丢失峰顶。
  • 重复调用 get，不必要地逼近 100 次限制。

class Solution {
    public int findInMountainArray(int target, MountainArray a) {
        int n=a.length(), l=0, r=n-1;
        while(l<r){int m=l+(r-l)/2;if(a.get(m)<a.get(m+1))l=m+1;else r=m;}
        int peak=l, ans=search(a,target,0,peak,true);
        return ans!=-1?ans:search(a,target,peak+1,n-1,false);
    }
    private int search(MountainArray a,int t,int l,int r,boolean up){
        while(l<=r){int m=l+(r-l)/2,v=a.get(m);if(v==t)return m;
            if((v<t)==up)l=m+1;else r=m-1;}
        return -1;
    }
}
