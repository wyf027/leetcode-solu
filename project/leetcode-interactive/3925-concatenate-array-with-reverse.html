连接逆序数组

把原数组放在前半段，再把它从右向左镜像复制到后半段。这里的实验室只展示构造过程，题解与代码保持折叠。

数组模拟O(n)额外输出数组

题意

给定 nums，长度为 n。构造长度 2 × n 的 ans：前 n 项等于 nums，后 n 项等于 nums 的逆序。

形式化地：ans[i] = nums[i]，且 ans[i + n] = nums[n - 1 - i]（0 ≤ i < n）。

官方示例

nums = [1, 2, 3]

ans = [1, 2, 3, 3, 2, 1]

约束：1 ≤ nums.length ≤ 100，1 ≤ nums[i] ≤ 100。

题解：双指针填入即可

创建长度为 2n 的答案数组。令 i 从 0 到 n - 1：把 nums[i] 写入 ans[i]，同时把 nums[n - 1 - i] 写入 ans[n + i]。两个位置互不冲突，且每个输入元素恰好被读取两次。

边界与复杂度

  • n = 1 时同一个元素复制两次。
  • 不应原地 reverse nums，否则会破坏前半段来源。
  • 时间 O(n)；除返回数组外额外空间 O(1)。

替代方案与追问

可先复制再追加逆序遍历，表达更直接；双指针写入更便于证明索引公式。追问：若要求不分配新数组则题意无法直接满足，因为返回长度翻倍。

常见错误

  • 第二段误写成 nums[i]。
  • 把下标写成 n - i，在 i = 0 时越界。
  • 漏掉 + n，覆盖前半段。

class Solution {
    public int[] concatWithReverse(int[] nums) {
        int n = nums.length;
        int[] ans = new int[2 * n];
        for (int i = 0; i < n; i++) {
            ans[i] = nums[i];
            ans[n + i] = nums[n - 1 - i];
        }
        return ans;
    }
}
