01 / Problem

题目说明

非付费题 · EASY

Activity 表

每一行表示一位玩家在某一天、使用某台设备登录后，在退出前完成的游戏局数。

列名类型含义
player_idint玩家编号
device_idint登录设备编号
event_datedate活动日期
games_playedint当天玩的局数，可能为 0

查询任务

为 每一位玩家找出其第一次登录平台的日期，结果列必须是：

player_id, first_login
返回顺序：任意顺序均可。
主键：(player_id, event_date)，因此同一玩家同一天至多一条记录。

约束与保证

  • player_id、device_id 与 games_played 均为整数，event_date 为日期。
  • (player_id, event_date) 的组合值唯一。
  • games_played 可以是 0；它与“是否发生登录”无关。
  • 题目要求按玩家输出首次登录日期，不要求保留设备或游戏局数。
  • 官方元数据未给出额外数值范围，因此此处不补造行数或字段上下界。

完整题解

官方提交主语言：SQL

核心洞察

对同一玩家而言，第一次登录就是该玩家所有 event_date 中的最小值。因此按 player_id 分组，再聚合求 MIN(event_date)。

完整过程

数据库先把相同 player_id 的行归入一组；每组独立求日期最小值；最后把聚合列命名为题目要求的 first_login。

MySQL 提交代码

推荐
MySQLLeetCode 可提交
SELECT
    player_id,
    MIN(event_date) AS first_login
FROM Activity
GROUP BY player_id;

正确性证明

分组完备性：对于任意玩家 p，GROUP BY player_id 恰好收集 Activity 中属于 p 的全部记录，不混入其他玩家。

聚合正确性：MIN(event_date) 返回该组全部活动日期中不晚于任何其他日期的那个日期，按定义正是玩家 p 的首次登录日期。

结论：每位出现过的玩家恰好输出一行，且 first_login 正确，因此查询满足题意。

复杂度

设 Activity 有 n 行、不同玩家有 p 个。

  • 概念上的单次扫描时间为 O(n)。
  • 哈希聚合通常使用 O(p) 额外空间。
  • 若执行器采用排序聚合，时间可能为 O(n log n)；实际计划由数据库优化器与索引决定。

边界情况

  • 某玩家只有一行：这一行的日期自然就是首次登录。
  • games_played = 0：仍然发生过登录，不能排除该行。
  • 同一玩家换设备：设备不影响首次登录日期的判断。
  • 输入物理顺序混乱：聚合最小值不依赖行顺序。
  • 不同玩家在同一天首次登录：分别输出，互不影响。

替代方案：窗口函数

可以为每位玩家按日期编号，再选择第一行。它能方便地连带取出首次登录那一行的其他列，但对本题只求日期而言更长。

MySQL 8+可提交替代方案
SELECT player_id, event_date AS first_login
FROM (
    SELECT
        player_id,
        event_date,
        ROW_NUMBER() OVER (
            PARTITION BY player_id
            ORDER BY event_date
        ) AS row_num
    FROM Activity
) AS ranked
WHERE row_num = 1;

Java · 本地语义参考

Java 17本地参考
import java.time.LocalDate;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class GamePlayAnalysis {
    public record Activity(
        int playerId,
        int deviceId,
        LocalDate eventDate,
        int gamesPlayed
    ) {}

    public static Map<Integer, LocalDate> firstLogin(
        List<Activity> activity
    ) {
        Map<Integer, LocalDate> answer = new HashMap<>();

        for (Activity row : activity) {
            answer.merge(
                row.playerId(),
                row.eventDate(),
                (known, current) ->
                    known.isBefore(current) ? known : current
            );
        }
        return answer;
    }
}

JavaScript · 本地语义参考

ECMAScript 2022本地参考
/**
 * @param {Array<{
 *   player_id: number,
 *   device_id: number,
 *   event_date: string,
 *   games_played: number
 * }>} activity
 * @return {Array<{player_id: number, first_login: string}>}
 */
function firstLogin(activity) {
  const earliest = new Map();

  for (const row of activity) {
    const known = earliest.get(row.player_id);
    if (known === undefined || row.event_date < known) {
      earliest.set(row.player_id, row.event_date);
    }
  }

  return Array.from(earliest, ([player_id, first_login]) => ({
    player_id,
    first_login,
  }));
}

Python · 本地语义参考

Python 3本地参考
from typing import TypedDict


class Activity(TypedDict):
    player_id: int
    device_id: int
    event_date: str
    games_played: int


def first_login(activity: list[Activity]) -> list[dict]:
    earliest: dict[int, str] = {}

    for row in activity:
        player = row["player_id"]
        date = row["event_date"]
        if player not in earliest or date < earliest[player]:
            earliest[player] = date

    return [
        {"player_id": player, "first_login": date}
        for player, date in earliest.items()
    ]

C++ · 本地语义参考

C++17本地参考
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>

struct Activity {
    int playerId;
    int deviceId;
    std::string eventDate; // YYYY-MM-DD
    int gamesPlayed;
};

std::vector<std::pair<int, std::string>> firstLogin(
    const std::vector<Activity>& activity
) {
    std::unordered_map<int, std::string> earliest;

    for (const Activity& row : activity) {
        auto it = earliest.find(row.playerId);
        if (it == earliest.end() || row.eventDate < it->second) {
            earliest[row.playerId] = row.eventDate;
        }
    }

    std::vector<std::pair<int, std::string>> answer;
    answer.reserve(earliest.size());
    for (const auto& [player, date] : earliest) {
        answer.emplace_back(player, date);
    }
    return answer;
}

import pandas as pd


def game_analysis(activity: pd.DataFrame) -> pd.DataFrame:
    return (
        activity.groupby("player_id", as_index=False)["event_date"]
        .min()
        .rename(columns={"event_date": "first_login"})
    )

常见错误

  • 误用 MAX(event_date)，得到最后一次登录。
  • 按 device_id 继续分组，导致同一玩家输出多行。
  • 过滤 games_played = 0，错误丢掉真实登录记录。
  • SELECT * 与聚合混用，产生非法或含义不确定的结果。
  • 忘记把聚合列别名写成 first_login。
