01 / QUESTION

题目要你判断什么？

目标不是寻找相同的某个节点，而是寻找一个节点，使从它出发的全部后代在结构与数值上都与 subRoot 一致。

题意

给定两棵二叉树的根节点 root 和 subRoot。如果 root 中存在一棵子树，与 subRoot 拥有完全相同的结构和节点值，返回 true；否则返回 false。

子树定义：从原树中的某个节点开始，连同该节点的所有后代一起构成一棵子树；整棵原树也可以视为自身的子树。

参数形式

  • root: TreeNode — 主树根节点。
  • subRoot: TreeNode — 待匹配树的根节点。
  • 返回值：boolean。

约束

  • root 的节点数在 [1, 2000] 内。
  • subRoot 的节点数在 [1, 1000] 内。
  • -10⁴ <= root.val <= 10⁴。
  • -10⁴ <= subRoot.val <= 10⁴。
示例 1可以找到完整匹配
输入root = [3,4,5,1,2], subRoot = [4,1,2]
输出true
示例 2多一个后代也不行
输入root = [3,4,5,1,2,null,null,null,null,0], subRoot = [4,1,2]
输出false

04 / SOLUTION

递归枚举起点 + 递归判同

核心洞察

把一个问题拆成两个职责清晰的小问题

外层搜索遍历 root 的所有节点，把每个节点当作候选子树根；内层判同检查该候选子树与 subRoot 是否在节点值和左右结构上完全一致。

两棵树完全相同，当且仅当

值相同 ∧ 左子树相同 ∧ 右子树相同

完整过程

  1. 在当前 root 节点调用判同函数，与 subRoot 逐节点比较。
  2. 判同函数中：两个节点都为空时相同；仅一个为空时不同；值不相同时也不同。
  3. 当前节点值相同后，继续递归比较左子树和右子树，二者都相同才算成功。
  4. 若当前候选未匹配，分别到 root.left 与 root.right 继续寻找。
  5. 任一候选完全匹配即可返回 true；遍历结束仍未匹配则返回 false。

边界情况

  • 两棵树从根开始就完全相同，主树自身就是答案。
  • 节点值相同但左右孩子位置不同，仍然不匹配。
  • 候选树比目标树多任意一个后代节点，不匹配。
  • 主树中存在多个与 subRoot.val 相同的节点，需要逐一检查。
  • 实现判同函数时要先判断空节点，再访问 val。

正确性证明

引理 1：判同函数返回 true 当且仅当输入的两棵树完全相同。证明可对树高做归纳：空树情形由边界判断直接成立；非空时，函数要求根值相同，并递归要求左右子树分别相同。由归纳假设，这恰好等价于两棵树的全部结构和节点值相同。

引理 2：外层搜索会访问 root 的每个节点。因为它先检查当前节点，再递归进入左右子树，所以按树的结构归纳，所有节点都会被访问且没有遗漏。

结论：若算法返回 true，根据引理 1，某个候选节点对应的整棵子树与 subRoot 完全相同；反之，若这样的子树存在，引理 2 保证其根节点会成为候选，引理 1 保证届时判同成功。因此算法返回值正确。

时间复杂度 · O(n × m)最坏情况下，主树的每个候选节点都要与目标树的至多 m 个节点比较。n 是主树节点数。
空间复杂度 · O(h₁ + h₂)递归栈由外层主树高度 h₁ 与一次判同过程的高度 h₂ 共同决定；退化树最坏为 O(n + m)。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isSubtree(TreeNode root, TreeNode subRoot) {
        if (subRoot == null) {
            return true;
        }
        if (root == null) {
            return false;
        }

        return isSameTree(root, subRoot)
                || isSubtree(root.left, subRoot)
                || isSubtree(root.right, subRoot);
    }

    private boolean isSameTree(TreeNode first, TreeNode second) {
        if (first == null && second == null) {
            return true;
        }
        if (first == null || second == null) {
            return false;
        }
        if (first.val != second.val) {
            return false;
        }

        return isSameTree(first.left, second.left)
                && isSameTree(first.right, second.right);
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @param {TreeNode} subRoot
 * @return {boolean}
 */
var isSubtree = function(root, subRoot) {
    if (subRoot === null) return true;
    if (root === null) return false;

    return isSameTree(root, subRoot)
        || isSubtree(root.left, subRoot)
        || isSubtree(root.right, subRoot);
};

/**
 * @param {TreeNode} first
 * @param {TreeNode} second
 * @return {boolean}
 */
function isSameTree(first, second) {
    if (first === null && second === null) return true;
    if (first === null || second === null) return false;
    if (first.val !== second.val) return false;

    return isSameTree(first.left, second.left)
        && isSameTree(first.right, second.right);
}

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    bool isSubtree(TreeNode* root, TreeNode* subRoot) {
        if (subRoot == nullptr) {
            return true;
        }
        if (root == nullptr) {
            return false;
        }

        return isSameTree(root, subRoot)
            || isSubtree(root->left, subRoot)
            || isSubtree(root->right, subRoot);
    }

private:
    bool isSameTree(TreeNode* first, TreeNode* second) {
        if (first == nullptr && second == nullptr) {
            return true;
        }
        if (first == nullptr || second == nullptr) {
            return false;
        }
        if (first->val != second->val) {
            return false;
        }

        return isSameTree(first->left, second->left)
            && isSameTree(first->right, second->right);
    }
};

替代方案

  • 序列化 + KMP：先序遍历时写入空节点标记和边界标记，再在线性序列中匹配，可做到 O(n + m)；标记不完整会产生歧义。
  • 树哈希：为每棵子树计算包含左右结构的哈希值，先筛选哈希相同的候选，再做一次精确判同；平均更快，但要谨慎处理哈希碰撞。
  • 迭代遍历：可用栈枚举候选节点，但候选树判同仍需栈或队列，代码通常比递归版本更长。

面试追问

  • 如果树非常深，如何避免递归栈溢出？
  • 怎样设计无歧义的树序列化，为什么必须保留空节点？
  • 能否把最坏时间降到 O(n + m)？
  • 树哈希发生碰撞时，怎样保持结果绝对正确？
  • 若要找出所有匹配子树的根节点，接口和算法怎样调整？

常见错误

  • 只要遇到与 subRoot.val 相同的节点就返回 true，没有继续比较完整结构。
  • 候选节点首次判同失败后直接返回 false，漏掉主树中后续同值候选。
  • 判同只比较非空节点值，忽略“一边为空、另一边非空”的结构差异。
  • 序列化时不写空节点标记，使不同结构生成相同序列。
  • 把平均复杂度更优的哈希方案描述成绝对无碰撞，却没有最终精确比较。
