01 / Problem contract

题目契约

设计一个保存字符串计数的数据结构，它既能更新某个字符串的计数，也能返回当前计数最大或最小的任意字符串。

接口定义

AllOne()初始化空数据结构。constructor
inc(String key)将 key 的计数加 1；不存在时以 1 插入。void
dec(String key)将 key 的计数减 1；变为 0 时删除。void
getMaxKey()返回计数最大的任意 key；空时返回 ""。String
getMinKey()返回计数最小的任意 key；空时返回 ""。String

约束

  • 1 ≤ key.length ≤ 10
  • key 只包含小写英文字母。
  • 每次调用 dec 前，保证 key 已存在。
  • inc、dec、getMaxKey、getMinKey 总调用次数不超过 5 × 10⁴。
  • 每个函数都必须达到平均 O(1) 时间复杂度。
返回值规则：若多个 key 同为最大或最小计数，返回其中任意一个都有效。

双向计数桶链表 + 哈希定位

核心洞察

不要按 key 排序，而要按“出现次数”组织。 让一个桶保存一个计数值和所有具有该计数的 key；只保留非空计数桶，并按计数严格递增连接。这样，最左有效桶与最右有效桶就是答案所在位置。

单独的哈希表可以在平均 O(1) 时间找到某个 key，却不能在 O(1) 时间知道全局最小和最大计数。单独的有序结构可以找极值，但一次更新通常需要 O(log n)。把二者组合：

  • keyToBucket：key → 当前桶节点，平均 O(1) 定位。
  • 双向链表：所有非空桶按 count 递增排列。
  • 每个桶内部用哈希集合保存 key，平均 O(1) 插入、删除与取任意元素。
  • 头尾哨兵消除空链表与边界插入的分支。

完整过程

inc(key)

  1. 若 key 不存在，它的目标计数是 1：复用第一个计数为 1 的桶，否则在头哨兵后新建计数 1 桶。
  2. 若 key 已存在于计数 c 的桶，目标是 c + 1：复用右邻的 c + 1 桶，否则紧邻当前桶右侧新建。
  3. 把 key 加入目标桶、更新哈希映射，再从旧桶删除。
  4. 旧桶若变空，立即从链表移除。

dec(key)

  1. 由哈希表找到计数 c 的当前桶。
  2. 若 c = 1，减一后 key 消失：删除其哈希映射。
  3. 若 c > 1，目标是 c - 1：复用左邻的 c - 1 桶，否则在当前桶左侧新建。
  4. 从旧桶删除 key；旧桶为空时将其摘除。

getMinKey() / getMaxKey()

若链表没有有效桶，返回空字符串；否则分别从头哨兵的右邻或尾哨兵的左邻集合中取任意 key。

为什么只检查相邻桶？

一次更新只让计数变化 1。当前桶计数为 c 时，目标只可能是 c + 1 或 c - 1。链表严格递增且不存在空桶，所以若目标计数桶存在，它必然紧挨当前桶；若相邻桶计数不是目标值，就可以在两者之间直接插入新桶。

正确性证明

1
不变式一：每个 key 恰好属于一个桶，桶计数等于该 key 的真实计数。

初始化显然成立。inc/dec 都先将 key 放入唯一的目标计数桶并更新映射，再从旧桶移除；计数减至 0 时同时从结构和映射删除，因此不变式保持。

2
不变式二：有效桶按计数严格递增，且没有空桶。

目标计数只比当前值相差 1。算法只复用计数吻合的相邻桶，否则在正确相邻位置插入新桶；每次迁移后都删除空桶，因此顺序与非空性保持。

3
极值查询正确。

由不变式二，头哨兵后的第一个有效桶计数全局最小，尾哨兵前的最后一个有效桶计数全局最大。由不变式一，桶中任意 key 都具有该计数，所以返回值有效。

4
结论。

所有更新保持两个不变式，所有查询依据不变式返回正确答案，因此整个数据结构正确。

边界情况

  • 空结构查询：返回 ""，不能访问哨兵的空集合。
  • 新 key：只能进入计数 1 桶。
  • 计数 1 执行 dec：key 必须彻底删除，而不是进入计数 0 桶。
  • 旧桶只剩最后一个 key：迁移后必须摘除空桶。
  • 多个 key 并列极值：返回集合中的任意一个即可，输出不要求稳定。
  • 所有 key 同处一个桶：该桶同时提供最小值与最大值。

复杂度

更新

inc / dec 平均 O(1)：哈希操作、相邻节点检查和常数次链表修改。

查询

getMinKey / getMaxKey 平均 O(1)：直接访问首尾有效桶并取任意 key。

空间

O(n)：每个 key 存储一次；桶数不超过不同计数的数量，也不超过 key 数。

import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class AllOne {
    private static class Bucket {
        int count;
        Set<String> keys = new HashSet<>();
        Bucket prev;
        Bucket next;

        Bucket(int count) {
            this.count = count;
        }
    }

    private final Bucket head;
    private final Bucket tail;
    private final Map<String, Bucket> keyToBucket;

    public AllOne() {
        head = new Bucket(0);
        tail = new Bucket(0);
        head.next = tail;
        tail.prev = head;
        keyToBucket = new HashMap<>();
    }

    public void inc(String key) {
        if (!keyToBucket.containsKey(key)) {
            Bucket target;
            if (head.next != tail && head.next.count == 1) {
                target = head.next;
            } else {
                target = new Bucket(1);
                insertAfter(head, target);
            }
            target.keys.add(key);
            keyToBucket.put(key, target);
            return;
        }

        Bucket current = keyToBucket.get(key);
        Bucket target;
        if (current.next != tail && current.next.count == current.count + 1) {
            target = current.next;
        } else {
            target = new Bucket(current.count + 1);
            insertAfter(current, target);
        }
        moveKey(key, current, target);
    }

    public void dec(String key) {
        Bucket current = keyToBucket.get(key);
        if (current.count == 1) {
            keyToBucket.remove(key);
            current.keys.remove(key);
            if (current.keys.isEmpty()) remove(current);
            return;
        }

        Bucket target;
        if (current.prev != head && current.prev.count == current.count - 1) {
            target = current.prev;
        } else {
            target = new Bucket(current.count - 1);
            insertAfter(current.prev, target);
        }
        moveKey(key, current, target);
    }

    public String getMaxKey() {
        return tail.prev == head ? "" : tail.prev.keys.iterator().next();
    }

    public String getMinKey() {
        return head.next == tail ? "" : head.next.keys.iterator().next();
    }

    private void moveKey(String key, Bucket from, Bucket to) {
        from.keys.remove(key);
        to.keys.add(key);
        keyToBucket.put(key, to);
        if (from.keys.isEmpty()) remove(from);
    }

    private void insertAfter(Bucket node, Bucket added) {
        added.prev = node;
        added.next = node.next;
        node.next.prev = added;
        node.next = added;
    }

    private void remove(Bucket node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
}

    added.next = node.next;
    node.next.prev = added;
    node.next = added;
};

AllOne.prototype.removeBucket = function(node) {
    node.prev.next = node.next;
    node.next.prev = node.prev;
};

AllOne.prototype.moveKey = function(key, from, to) {
    from.keys.delete(key);
    to.keys.add(key);
    this.keyToBucket.set(key, to);
    if (from.keys.size === 0) this.removeBucket(from);
};

AllOne.prototype.inc = function(key) {
    if (!this.keyToBucket.has(key)) {
        let target = this.head.next;
        if (target === this.tail || target.count !== 1) {
            target = new Bucket(1);
            this.insertAfter(this.head, target);
        }
        target.keys.add(key);
        this.keyToBucket.set(key, target);
        return;
    }

    const current = this.keyToBucket.get(key);
    let target = current.next;
    if (target === this.tail || target.count !== current.count + 1) {
        target = new Bucket(current.count + 1);
        this.insertAfter(current, target);
    }
    this.moveKey(key, current, target);
};

AllOne.prototype.dec = function(key) {
    const current = this.keyToBucket.get(key);
    if (current.count === 1) {
        this.keyToBucket.delete(key);
        current.keys.delete(key);
        if (current.keys.size === 0) this.removeBucket(current);
        return;
    }

    let target = current.prev;
    if (target === this.head || target.count !== current.count - 1) {
        target = new Bucket(current.count - 1);
        this.insertAfter(current.prev, target);
    }
    this.moveKey(key, current, target);
};

AllOne.prototype.getMaxKey = function() {
    if (this.tail.prev === this.head) return "";
    return this.tail.prev.keys.values().next().value;
};

AllOne.prototype.getMinKey = function() {
    if (this.head.next === this.tail) return "";
    return this.head.next.keys.values().next().value;

class Bucket:
    def __init__(self, count: int):
        self.count = count
        self.keys = set()
        self.prev = None
        self.next = None


class AllOne:
    def __init__(self):
        self.head = Bucket(0)
        self.tail = Bucket(0)
        self.head.next = self.tail
        self.tail.prev = self.head
        self.key_to_bucket = {}

    def _insert_after(self, node: Bucket, added: Bucket) -> None:
        added.prev = node
        added.next = node.next
        node.next.prev = added
        node.next = added

    def _remove_bucket(self, node: Bucket) -> None:
        node.prev.next = node.next
        node.next.prev = node.prev

    def _move_key(self, key: str, source: Bucket, target: Bucket) -> None:
        source.keys.remove(key)
        target.keys.add(key)
        self.key_to_bucket[key] = target
        if not source.keys:
            self._remove_bucket(source)

    def inc(self, key: str) -> None:
        if key not in self.key_to_bucket:
            target = self.head.next
            if target is self.tail or target.count != 1:
                target = Bucket(1)
                self._insert_after(self.head, target)
            target.keys.add(key)
            self.key_to_bucket[key] = target
            return

        current = self.key_to_bucket[key]
        target = current.next
        if target is self.tail or target.count != current.count + 1:
            target = Bucket(current.count + 1)
            self._insert_after(current, target)
        self._move_key(key, current, target)

    def dec(self, key: str) -> None:
        current = self.key_to_bucket[key]
        if current.count == 1:
            del self.key_to_bucket[key]
            current.keys.remove(key)
            if not current.keys:
                self._remove_bucket(current)
            return

        target = current.prev
        if target is self.head or target.count != current.count - 1:
            target = Bucket(current.count - 1)
            self._insert_after(current.prev, target)
        self._move_key(key, current, target)

    def getMaxKey(self) -> str:
        if self.tail.prev is self.head:
            return ""
        return next(iter(self.tail.prev.keys))

    def getMinKey(self) -> str:
        if self.head.next is self.tail:
            return ""
        return next(iter(self.head.next.keys))
#include <list>
#include <string>
#include <unordered_map>
#include <unordered_set>
using namespace std;

class AllOne {
    struct Bucket {
        int count;
        unordered_set<string> keys;
        Bucket* prev;
        Bucket* next;

        explicit Bucket(int count) : count(count), prev(nullptr), next(nullptr) {}
    };

    Bucket* head;
    Bucket* tail;
    unordered_map<string, Bucket*> keyToBucket;

    void insertAfter(Bucket* node, Bucket* added) {
        added->prev = node;
        added->next = node->next;
        node->next->prev = added;
        node->next = added;
    }

    void removeBucket(Bucket* node) {
        node->prev->next = node->next;
        node->next->prev = node->prev;
        delete node;
    }

    void moveKey(const string& key, Bucket* from, Bucket* to) {
        from->keys.erase(key);
        to->keys.insert(key);
        keyToBucket[key] = to;
        if (from->keys.empty()) removeBucket(from);
    }

public:
    AllOne() {
        head = new Bucket(0);
        tail = new Bucket(0);
        head->next = tail;
        tail->prev = head;
    }

    ~AllOne() {
        Bucket* current = head;
        while (current != nullptr) {
            Bucket* next = current->next;
            delete current;
            current = next;
        }
    }

    void inc(string key) {
        if (!keyToBucket.count(key)) {
            Bucket* target = head->next;
            if (target == tail || target->count != 1) {
                target = new Bucket(1);
                insertAfter(head, target);
            }
            target->keys.insert(key);
            keyToBucket[key] = target;
            return;
        }

        Bucket* current = keyToBucket[key];
        Bucket* target = current->next;
        if (target == tail || target->count != current->count + 1) {
            target = new Bucket(current->count + 1);
            insertAfter(current, target);
        }
        moveKey(key, current, target);
    }

    void dec(string key) {
        Bucket* current = keyToBucket[key];
        if (current->count == 1) {
            keyToBucket.erase(key);
            current->keys.erase(key);
            if (current->keys.empty()) removeBucket(current);
            return;
        }

        Bucket* target = current->prev;
        if (target == head || target->count != current->count - 1) {
            target = new Bucket(current->count - 1);
            insertAfter(current->prev, target);
        }
        moveKey(key, current, target);
    }

    string getMaxKey() {
        return tail->prev == head ? "" : *tail->prev->keys.begin();
    }

    string getMinKey() {
        return head->next == tail ? "" : *head->next->keys.begin();
    }
};

替代方案

  • 哈希表 + 平衡树：更新和极值查询清晰，但更新需 O(log n)，不满足本题平均 O(1)。
  • 哈希表 + 最小/最大堆：可以惰性删除，但一次查询可能连续弹出多个失效项，无法保证题目要求的每个操作平均 O(1)，空间也会积累历史条目。
  • 直接扫描所有 key：更新 O(1)，极值查询 O(n)，仅适合数据极小且查询很少的场景。
  • 固定计数数组：计数上界虽受操作数限制，但寻找下一个非空计数仍可能线性扫描，并且浪费空间。

面试追问

为什么说“平均” O(1)？

哈希表与哈希集合的查找、插入、删除通常按期望或平均 O(1) 计；极端碰撞下不保证严格最坏 O(1)。

如何返回所有最大 key？

遍历最后一个有效桶的集合即可；查询本身变为 O(k)，其中 k 是并列最大 key 的数量，输出这些元素本来也需要 O(k)。

如何支持 add(key, delta)？

若 delta 不再是 ±1，目标桶不一定相邻；需要额外的 count → bucket 映射协助定位，但维持有序位置仍可能需要更强的有序结构。

并发环境怎么办？

一次迁移同时修改映射、两个集合和链表，必须作为原子操作保护。可从全局锁开始，再讨论分片和锁顺序。

常见错误

  • key 迁移后忘记更新 keyToBucket。
  • 桶变空却不删除，导致极值查询落在空桶。
  • 在 dec 计数为 1 时创建计数 0 桶。
  • 新建 c - 1 桶时插错到当前桶右侧，破坏递增顺序。
  • 没有使用哨兵，导致空结构、首桶和尾桶产生大量易错分支。
  • 误以为必须返回固定的并列 key；题目允许任意一个，因此集合无序不是问题。
  • C++ 删除桶节点后继续访问旧指针，造成悬空指针。
