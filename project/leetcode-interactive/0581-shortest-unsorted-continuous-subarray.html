Solution unlocked

一次线性扫描，锁定两个边界

核心洞察

从左向右时维护已见元素的最大值 maxSeen。若当前位置小于它，说明当前位置无法待在最终有序数组的原位，右边界至少要延伸到这里。

对称地，从右向左维护最小值 minSeen。若当前位置大于它，左边界至少要扩展到这里。

为什么不能只找相邻逆序？

相邻下降点只能告诉你“哪里坏了”，却不一定给出完整边界。例如 [1,5,3,4,2,6] 中，最小的乱序值 2 会迫使左边界越过 5、3、4，最终区间是索引 [1,4]。

完整过程

初始化。令 right = -1，表示尚未发现乱序；从数组首项开始维护 maxSeen。
确定右边界。从左向右扫描。若 nums[i] < maxSeen，当前位置被左侧更大的数压住，更新 right = i；否则更新最大值。
确定左边界。令 left = n，从右向左维护 minSeen。若 nums[i] > minSeen，当前位置被右侧更小的数越过，更新 left = i；否则更新最小值。
返回长度。若 right = -1，数组从未出现违序，返回 0；否则返回 right - left + 1。

正确性证明

  1. 右边界的必要性：从左向右扫描到 i 时，若 nums[i] < maxSeen，在 i 左侧存在更大的元素。若排序区间不包含 i，该逆序关系不可能被消除。因此每个这样的位置都必须位于区间内，最后一个位置就是必要的最右边界。
  2. 左边界的必要性：从右向左扫描到 i 时，若 nums[i] > minSeen，在 i 右侧存在更小的元素。若区间不包含 i，该逆序关系仍会保留。因此最前面的这种位置就是必要的最左边界。
  3. 充分性：区间外的左侧没有任何元素大于其右侧已见最小值，区间外的右侧也没有任何元素小于其左侧已见最大值。将 [left, right] 排序后，区间内部有序，且与两侧边界衔接有序，所以整个数组有序。
  4. 最短性：任何可行区间都必须覆盖上述全部违序位置，因此不能比 [left, right] 更短；而该区间又足以使整体有序，故它就是最短区间。
时间复杂度O(n)

两次方向相反的线性扫描。

空间复杂度O(1)

只维护边界与运行极值。

边界情况

  • 空乱序区间：数组已有序，right 保持 -1。
  • 单元素：天然有序，返回 0。
  • 存在重复值：目标是非递减，比较必须使用严格的 < / >。
  • 完全逆序：左右边界扩展到数组两端。
  • 负数不会改变比较逻辑。

替代方案

  • 排序副本：复制并排序数组，再找首尾不同位置。直观但需要 O(n log n) 时间与 O(n) 空间。
  • 单调栈：递增栈找左边界、递减栈找右边界。也是 O(n) 时间，但使用 O(n) 空间。

面试追问

  • 能否用一次外层循环同时完成左右扫描？可以，在第 i 轮同时处理 i 与 n-1-i。
  • 若要求返回区间本身？返回 [left, right]；有序时可返回 [-1, -1]。
  • 若数据流只能从左到右？可以确定右边界，但精确左边界通常需要额外存储或第二遍数据。

常见错误

  • 只记录第一个和最后一个相邻下降点，遗漏需要向外扩展的元素。
  • 把非递减误写成严格递增，对相等元素错误扩边。
  • 有序数组直接计算 right - left + 1，得到错误负值。
  • 扫描时先更新极值再比较，丢失违序判断。

class Solution {
    public int findUnsortedSubarray(int[] nums) {
        int n = nums.length;
        int right = -1;
        int maxSeen = nums[0];

        for (int i = 1; i < n; i++) {
            if (nums[i] < maxSeen) {
                right = i;
            } else {
                maxSeen = nums[i];
            }
        }

        if (right == -1) return 0;

        int left = n;
        int minSeen = nums[n - 1];
        for (int i = n - 2; i >= 0; i--) {
            if (nums[i] > minSeen) {
                left = i;
            } else {
                minSeen = nums[i];
            }
        }

        return right - left + 1;
    }
}
