Problem

题目

函数：isNStraightHand(hand, groupSize)

Alice 有若干张牌，第 i 张牌的数值为 hand[i]。她希望重新排列所有牌，把它们分成若干组：每组恰好有 groupSize 张牌，并且组内数值连续。若可以做到则返回 true，否则返回 false。每张牌必须且只能使用一次，重复数值代表不同的牌。

示例 1

输入：hand = [1,2,3,6,2,3,4,7,8], groupSize = 3
输出：true
解释：可重排为 [1,2,3]、[2,3,4]、[6,7,8]。

示例 2

输入：hand = [1,2,3,4,5], groupSize = 4
输出：false
解释：无法把全部 5 张牌分成若干个大小为 4 的组。
1 ≤ hand.length ≤ 10⁴
0 ≤ hand[i] ≤ 10⁹
1 ≤ groupSize ≤ hand.length

Solution

贪心：最小牌没有退路

当前还没被使用的最小牌，只可能成为某个连续组的第一张牌。

核心洞察

设剩余最小值为 x。它不可能接在更小的牌后面，因为更小的牌已经处理完；因此必须用 x,x+1,…,x+groupSize-1 开启新组。若其中任何数值缺失，答案立即为 false。

完整过程

先剪枝
总牌数不能被 groupSize 整除时直接失败。
统计并排序
用计数表保存频次，对不同数值升序遍历。
批量开组
若 x 还有 c 张，则必须同时开启 c 组，连续 c 次消耗后续每个值。

正确性证明

引理：剩余牌中的最小值 x 必须是某个组的起点。若不是起点，该组还应含有小于 x 的前驱牌，与 x 是剩余最小值矛盾。

贪心安全性：算法从 x 开始拿走一组所需的连续值，这是任何合法方案都必须做的选择；所以不会排除合法解。

归纳：拿走这些牌后问题缩小为同类问题。不断重复，若全部频次归零便得到合法划分；若某一步缺牌，由引理可知任何方案都无法安置当前最小牌。因此算法当且仅当存在合法划分时返回 true。

复杂度

排序数组实现：时间 O(n log n)，计数表空间 O(n)。若使用有序映射，设不同值数量为 m，典型时间为 O(n log m)。

边界

  • groupSize = 1 时总能成功。
  • 牌数不能整除组大小时必定失败。
  • 重复牌必须按频次消费。
  • 数值可到 10⁹，不能依赖按最大值开大数组。

四种语言

Java · HashMap + 排序
class Solution {
    public boolean isNStraightHand(int[] hand, int groupSize) {
        if (hand.length % groupSize != 0) return false;
        java.util.Arrays.sort(hand);
        java.util.Map<Integer, Integer> count = new java.util.HashMap<>();
        for (int card : hand) count.merge(card, 1, Integer::sum);

        for (int start : hand) {
            int copies = count.getOrDefault(start, 0);
            if (copies == 0) continue;
            for (int card = start; card < start + groupSize; card++) {
                int available = count.getOrDefault(card, 0);
                if (available < copies) return false;
                count.put(card, available - copies);
            }
        }
        return true;
    }
}
JavaScript · Map + 排序
/**
 * @param {number[]} hand
 * @param {number} groupSize
 * @return {boolean}
 */
var isNStraightHand = function(hand, groupSize) {
    if (hand.length % groupSize !== 0) return false;
    hand.sort((a, b) => a - b);
    const count = new Map();
    for (const card of hand) count.set(card, (count.get(card) || 0) + 1);

    for (const start of hand) {
        const copies = count.get(start) || 0;
        if (copies === 0) continue;
        for (let card = start; card < start + groupSize; card++) {
            const available = count.get(card) || 0;
            if (available < copies) return false;
            count.set(card, available - copies);
        }
    }
    return true;
};
Python · Counter + 排序
from collections import Counter
from typing import List

class Solution:
    def isNStraightHand(self, hand: List[int], groupSize: int) -> bool:
        if len(hand) % groupSize != 0:
            return False

        count = Counter(hand)
        for start in sorted(count):
            copies = count[start]
            if copies == 0:
                continue
            for card in range(start, start + groupSize):
                if count[card] < copies:
                    return False
                count[card] -= copies
        return True
C++ · map 有序计数
class Solution {
public:
    bool isNStraightHand(vector<int>& hand, int groupSize) {
        if (hand.size() % groupSize != 0) return false;
        map<int, int> count;
        for (int card : hand) ++count[card];

        while (!count.empty()) {
            int start = count.begin()->first;
            for (int card = start; card < start + groupSize; ++card) {
                auto it = count.find(card);
                if (it == count.end()) return false;
                if (--it->second == 0) count.erase(it);
            }
        }
        return true;
    }
};

替代方案

可用最小堆不断取当前最小值，再按顺序找后继，但需要额外维护被暂时取出的元素，逻辑更繁琐。也可记录“等待某张牌续接”的开放序列数量，适合流式思考；本题的有序计数贪心更直接。

面试追问

  • 为什么必须批量消耗 count[x] 份，而不只开一组？
  • 如果输入已排序，复杂度可以怎样变化？
  • 若允许每组长度至少为 k，而非恰好为 k，该如何调整？

常见错误

  • 只检查是否出现连续值，却没有扣除频次。
  • 从任意牌开始拼组，错过“剩余最小牌”提供的必然性。
  • 忽略总牌数不可整除的快速失败条件。
  • 遍历哈希表的任意顺序；贪心必须按数值升序处理。
