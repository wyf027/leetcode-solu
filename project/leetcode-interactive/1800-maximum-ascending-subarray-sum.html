最大升序子数组和

Maximum Ascending Subarray Sum

连续、严格递增、元素和最大。先读题，再用交互轨道观察每个元素。

官方题目 ↗

题目与约束

给定正整数数组 nums，选择一个非空且连续的片段，其中每个后继元素都严格大于前一个元素，返回满足条件的片段能取得的最大元素和。单个元素也属于升序子数组。

参数：nums: integer[]；返回：integer；函数：maxAscendingSum(nums)。

  • 1 ≤ nums.length ≤ 100
  • 1 ≤ nums[i] ≤ 100
  • 必须保持原位置连续，不能跳过元素或排序；相等不满足严格递增。

官方示例

输入：nums = [10,20,30,5,10,50]
输出：65

选择 [5,10,50]，和为 65。

示例 2

输入：nums = [10,20,30,40,50]
输出：150

整个数组严格递增，和为 150。

示例 3

输入：nums = [12,17,15,13,10,11,12]
输出：33

选择 [10,11,12]，和为 33。

独立题解

先尝试自己判断每个升序片段的边界，再展开分析。

核心洞察

所有元素为正数，所以在一个严格升序段中，向外扩展合法片段总能增大和。最优答案可取某个完整的最大升序段。只维护当前段和 current，以及历史最大和 best。

完整过程

  1. 用 nums[0] 初始化 current 和 best。
  2. 从 i=1 扫描：若 nums[i] > nums[i−1]，令 current += nums[i]；否则令 current = nums[i]。
  3. 每一步更新 best = max(best,current)，最后返回 best。

示例 1 中 current：10 → 30 → 60 → 5 → 15 → 65。best：10 → 30 → 60 → 60 → 60 → 65。30 到 5 的下降断开原段，本步从 5 重新开始。

正确性

循环不变式：处理下标 i 后，current 等于以 i 结尾的升序子数组的最大和，best 等于前缀 nums[0..i] 内的最优和。首元素初始化显然成立。

如果 nums[i] 大于前驱，则可接在前驱的最优片段后面。由于元素为正数，保留前驱段优于只取当前元素。如果不大于前驱，任何长度至少为 2 且以 i 结尾的连续片段都会包含这对不合法邻居，故只能选当前单元素。取旧 best 与 current 的最大值，就覆盖了旧候选和所有以 i 结尾的新候选。不变式保持，扫描结束得到全局最大值。

边界与复杂度

  • 单元素直接返回该值；相等或下降都要断开。
  • 全递增返回总和；全递减或全相等返回最大单值。
  • 最优不一定最长：[100,1,2,3] 的答案是 100。
  • 时间 O(n)，额外空间 O(1)。总和粗略上界 10000，普通整数足够。
  • 官方输入非空且为正数；演示为支持回放保存 O(n) 状态，不属于提交算法的空间开销。

替代方案

枚举每个左端点，向右累加直到遇到非递增边界，更新最大和。最坏时间 O(n²)、空间 O(1)。也可保存所有升序段的和再取最大值，但额外保存并非必要。

面试追问

  • 允许负数怎么办？递增时用 current = max(nums[i], current + nums[i])，避免负和前缀拖累答案；断点仍重置。
  • 要返回子数组怎么办？保存当前段起点，并在刷新 best 时记录左右端点；相同和保留先遇到者即可。
  • 改成非递减怎么办？把比较符改为 ≥。
  • 能流式处理吗？只保留前驱、current 和 best 即可。

常见错误

  • 误用 ≥ 连接相等值。
  • 先排序或跳过元素，破坏子数组的连续性。
  • 断点把 current 清零而不是设为当前元素。
  • 只在断点更新 best，遗漏最后一个段。
  • 比较长度而非元素和。

Java

class Solution {
    public int maxAscendingSum(int[] nums) {
        int current = nums[0], best = nums[0];
        for (int i = 1; i < nums.length; i++) {
            current = nums[i] > nums[i - 1]
                ? current + nums[i] : nums[i];
            best = Math.max(best, current);
        }
        return best;
    }
}

Python 3

from typing import List

class Solution:
    def maxAscendingSum(self, nums: List[int]) -> int:
        current = best = nums[0]
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                current += nums[i]
            else:
                current = nums[i]
            best = max(best, current)
        return best

        for (int i = 1; i < static_cast<int>(nums.size()); ++i) {

            best = max(best, current);
