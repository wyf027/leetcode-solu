Number of Subsequences That Satisfy the Given Sum Condition

#1498中等免费题数组双指针排序

题目描述

给定整数数组 nums 与整数 target，统计其中的非空子序列数量，使每个被统计子序列的最小元素与最大元素之和不超过 target。答案可能很大，返回其对 10⁹ + 7 取模的结果。

关键辨析：子序列不要求连续，但保留原数组中的相对位置；值相同、来源下标不同的选择仍视作不同子序列。

官方示例

示例 1
输入：nums = [3,5,6,7], target = 9
输出：4
解释：[3]、[3,5]、[3,6]、[3,5,6] 满足条件。
示例 2
输入：nums = [3,3,6,8], target = 10
输出：6
解释：[3]、[3]、[3,3]、两种 [3,6]、[3,3,6]；重复值来自不同下标。
示例 3
输入：nums = [2,3,3,4,6,7], target = 12
输出：61
解释：63 个非空子序列中，仅 [6,7] 与 [7] 不满足条件。

约束

长度
1 ≤ nums.length ≤ 10⁵
元素
1 ≤ nums[i] ≤ 10⁶
目标值
1 ≤ target ≤ 10⁶

L：候选最小值R：候选最大值

核心解法

排序，让“最小 / 最大”可定位

升序排列后，区间两端 nums[L] 与 nums[R] 分别是当前候选子序列的最小值和最大值。

和太大：只缩小最大值

若 nums[L] + nums[R] > target，以 nums[R] 为最大值且包含 nums[L] 的组合都不合格，执行 R--。

和合格：整批计数

若两端之和合格，固定选择 nums[L]，而区间 (L, R] 的 R-L 个元素均可独立选或不选，所以新增 2^(R-L) 个子序列，再执行 L++。

取模并移动指针

预计算所有二次幂并随累计过程对 1,000,000,007 取模，直到 L > R。
O(n log n)

排序主导时间；双指针扫描为 O(n)。

O(n)

二次幂表占用空间；不计排序栈。

为什么不会重计？ 每一批子序列都以当前 nums[L] 作为被固定选中的最小下标。L 每次只向右移动，因此不同批次的固定最小下标不同。

易错点拆解

单元素子序列的最小值和最大值都是它自身，因此需要检查 2 × nums[i] ≤ target。双指针在 L = R 时自然处理，合格则新增 2⁰ = 1。
长度 n 的数组有 2ⁿ − 1 个非空子序列；n 可达 10⁵，指数枚举不可行。排序将大量组合压缩成一次幂计数。
这里仅统计选择方案数量，条件只取决于所选值的最小值与最大值。对值排序不会改变“选择哪些原下标”的组合数。

JavaScript 实现

LeetCode 函数签名：numSubseq(nums, target)
/**
 * @param {number[]} nums
 * @param {number} target
 * @return {number}
 */
var numSubseq = function(nums, target) {
  const MOD = 1_000_000_007;
  nums.sort((a, b) => a - b);

  const pow2 = new Array(nums.length).fill(1);
  for (let i = 1; i < nums.length; i++) {
    pow2[i] = (pow2[i - 1] * 2) % MOD;
  }

  let left = 0;
  let right = nums.length - 1;
  let answer = 0;

  while (left <= right) {
    if (nums[left] + nums[right] <= target) {
      answer = (answer + pow2[right - left]) % MOD;
      left++;
    } else {
      right--;
    }
  }

  return answer;
};
