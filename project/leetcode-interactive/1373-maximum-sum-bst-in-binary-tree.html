01 / Problem

问题定义

给定二叉树 root，返回任意一棵同时也是二叉搜索树的子树所能取得的最大键值和。

这里的“子树”必须由某个节点及其全部后代组成。空树允许参与答案，因此当所有节点值都为负时，返回 0。

左侧严格更小左子树中的每个键值都小于当前节点。
右侧严格更大右子树中的每个键值都大于当前节点。
递归成立左右子树自身也都必须是二叉搜索树。

函数签名

maxSumBST(root: TreeNode) → integer

官方示例

EXAMPLE 01答案子树根 = 3
输入
root = [1,4,3,2,4,2,5,null,null,null,null,null,null,4,6]
输出
20
解释
以值为 3 的节点为根的子树是一棵 BST，其节点和为 3 + 2 + 5 + 4 + 6 = 20。
EXAMPLE 02
输入
root = [4,3,null,1,2]
输出
2
解释
值为 2 的单节点子树取得最大和。
EXAMPLE 03
输入
root = [-4,-2,-5]
输出
0
解释
所有值都为负，选择空 BST。
EXAMPLE 04
输入
root = [2,1,3]

EXAMPLE 05
输入

7

约束

  • 树中节点数在 [1, 4 × 10⁴] 范围内。
  • -4 × 10⁴ ≤ Node.val ≤ 4 × 10⁴。
  • BST 使用严格不等号；相等值不能分别落在父节点两侧来构成合法 BST。

Full solution

后序遍历 + 树形 DP

核心洞察

判断“以当前节点为根的整棵子树是否为 BST”，必须先知道左右子树的状态。一次后序 DFS 让每个节点向父节点返回四元组：(isBST, min, max, sum)。

左右子树都是 BST，并且满足 left.max < node.val < right.min 时，当前子树才能合并成 BST。此时更新全局最大和。

状态意义父节点用途
isBST整棵当前子树是否合法阻止非法子树继续合并
min子树最小键值作为右子树的下界
max子树最大键值作为左子树的上界
sum子树全部键值和合并并更新答案

完整过程

  1. 全局答案初始化为 0，体现空 BST 可选。
  2. 空节点返回合法 BST：最小值为 +∞、最大值为 -∞、和为 0。这个哨兵让叶子自然通过边界判断。
  3. 递归取得左右子树的四元组。
  4. 若任一侧非法，或不满足严格边界，当前子树标记为非法。
  5. 否则计算 sum = left.sum + right.sum + node.val，更新全局答案，并返回新的最小值与最大值。
  6. 遍历结束后返回全局答案。

正确性证明

  1. 基础情形：空树是 BST，和为 0；使用 (+∞, -∞) 边界后，任意叶子都满足合并条件。
  2. 归纳假设：假设 DFS 已正确返回左右子树是否为 BST，以及合法时的最小值、最大值和总和。
  3. 归纳步骤：若两侧合法且 left.max < node.val < right.min，BST 的递归定义保证当前整棵子树合法；反之至少违反一条必要条件，当前子树必不合法。合并的总和及极值也由定义直接得到。
  4. 答案完备性：每个非空子树都有唯一根节点，DFS 会恰好在该根处判断它。所有合法 BST 子树的和都会参与最大值更新，再与空树的 0 比较，所以最终答案正确。

边界与复杂度

时间复杂度

O(n)。每个节点只访问一次，每次合并是常数操作。

空间复杂度

O(h) 递归栈；h 为树高，最坏退化为 O(n)。

必须留意

  • 所有值为负时仍返回 0，而不是最大的负数。
  • 比较必须使用严格的 <；重复值不能通过。
  • 节点数可达 4 万，极度倾斜的树可能触发部分语言的递归深度限制。
  • 最大可能绝对和约为 1.6 × 10⁹；题目范围内 32 位有符号整数可容纳，但累加时用更宽类型更稳妥。

四语言完整代码

class Solution {
    private int answer = 0;

    public int maxSumBST(TreeNode root) {
        dfs(root);
        return answer;
    }

    // [isBST(1/0), min, max, sum]
    private int[] dfs(TreeNode node) {
        if (node == null) {
            return new int[]{1, Integer.MAX_VALUE, Integer.MIN_VALUE, 0};
        }

        int[] left = dfs(node.left);
        int[] right = dfs(node.right);

        if (left[0] == 1 && right[0] == 1
                && left[2] < node.val && node.val < right[1]) {
            int sum = left[3] + right[3] + node.val;
            answer = Math.max(answer, sum);
            int minValue = Math.min(left[1], node.val);
            int maxValue = Math.max(right[2], node.val);
            return new int[]{1, minValue, maxValue, sum};
        }

        return new int[]{0, 0, 0, 0};
    }
}

var maxSumBST = function(root) {
    let answer = 0;

    // 返回 [isBST, min, max, sum]
    function dfs(node) {
        if (node === null) {
            return [true, Infinity, -Infinity, 0];
        }

        const left = dfs(node.left);
        const right = dfs(node.right);

        if (left[0] && right[0]
            && left[2] < node.val && node.val < right[1]) {
            const sum = left[3] + right[3] + node.val;
            answer = Math.max(answer, sum);
            return [
                true,
                Math.min(left[1], node.val),
                Math.max(right[2], node.val),
                sum
            ];
        }

        return [false, 0, 0, 0];
    }

    dfs(root);
    return answer;
};
class Solution:
    def maxSumBST(self, root: Optional[TreeNode]) -> int:
        answer = 0

        # 返回 (is_bst, min_value, max_value, subtree_sum)
        def dfs(node: Optional[TreeNode]):
            nonlocal answer
            if node is None:
                return True, float("inf"), float("-inf"), 0

            left_bst, left_min, left_max, left_sum = dfs(node.left)
            right_bst, right_min, right_max, right_sum = dfs(node.right)

            if (left_bst and right_bst
                    and left_max < node.val < right_min):
                total = left_sum + right_sum + node.val
                answer = max(answer, total)
                return (
                    True,
                    min(left_min, node.val),
                    max(right_max, node.val),
                    total,
                )

            return False, 0, 0, 0

        dfs(root)
        return answer
class Solution {
    struct State {
        bool isBST;
        int minValue;
        int maxValue;
        int sum;
    };

    int answer = 0;

    State dfs(TreeNode* node) {
        if (node == nullptr) {
            return {true, INT_MAX, INT_MIN, 0};
        }

        State left = dfs(node->left);
        State right = dfs(node->right);

        if (left.isBST && right.isBST
                && left.maxValue < node->val
                && node->val < right.minValue) {
            int sum = left.sum + right.sum + node->val;
            answer = max(answer, sum);
            return {
                true,
                min(left.minValue, node->val),
                max(right.maxValue, node->val),
                sum
            };
        }

        return {false, 0, 0, 0};
    }

public:
    int maxSumBST(TreeNode* root) {
        dfs(root);
        return answer;
    }
};

替代方案

对每棵子树单独验证

枚举根节点，再中序遍历验证 BST 并求和。直观，但最坏会重复扫描大量节点，达到 O(n²)。

后序遍历 + 对象状态

与四元组算法相同，只是用具名对象或结构体提升可读性。复杂度不变，工程代码通常更清晰。

还可以写迭代后序遍历来规避深递归，但需要显式栈和“节点 → 状态”的映射，代码更长。

面试追问

为什么空树的 min 是 +∞，max 是 -∞？

让叶子节点的比较 -∞ < value < +∞ 自动成立，从而统一逻辑，免去左右孩子为空的分支。

为什么非法子树返回什么 min/max 都可以？

父节点先检查 isBST；一旦为假就不会读取这些边界来完成合法合并。

若要求返回最大和 BST 的根节点呢？

更新最大和时同步保存当前节点引用即可；若还要处理并列答案，需要额外定义并列规则。

如何改为允许重复值？

必须先明确重复值放左还是放右，再只放宽对应一侧的比较符号，不能两侧都随意放宽。

常见错误

  • 只比较当前节点与直接孩子，忽略左子树最大值和右子树最小值。
  • 当前子树非法后直接停止搜索，漏掉其内部已经发现的合法 BST。
  • 答案初始化为负无穷，导致全负输入没有返回题目约定的 0。
  • 用 <= 判断边界，错误接受重复键。
  • 只返回“是否 BST”和“和”，导致父节点无法判断全局边界。
