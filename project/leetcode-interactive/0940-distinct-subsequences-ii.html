不同的子序列 II

重复字符像回声：它们会制造看似全新的选择，却也让一部分结果重合。先在交互沙盘里观察“以哪个字符结尾”的数量如何变化，再决定是否展开完整题解。

HARDDistinct Subsequences II非会员题mod 10⁹ + 7

题目

给定字符串 s，返回其中不同且非空的子序列数量。结果可能很大，请对 1,000,000,007 取模。

子序列可由原串删除任意数量的字符得到，但剩余字符的相对次序不能改变。例如 ace 是 abcde 的子序列，aec 不是。

函数参数：distinctSubseqII(s: string): integer

约束

  • 1 ≤ s.length ≤ 2000
  • s 仅由小写英文字母组成

答案定义为非空子序列的去重数量，并在每一步按模数处理。

官方示例

示例 1

输入：s = "abc" 输出：7 解释："a", "b", "c", "ab", "ac", "bc", "abc"。

示例 2

输入：s = "aba" 输出：6 解释："a", "b", "ab", "ba", "aa", "aba"。

示例 3

输入：s = "aaa" 输出：3 解释："a", "aa", "aaa"。

题解：记录每种结尾

核心洞察

令 end[c] 表示当前所有不同非空子序列中，以字符 c 结尾的数量。处理新字符 c 前，所有已有子序列都可以追加它，再加上只含它自己的子序列。因此，新一批以 c 结尾的集合完全覆盖旧的该桶，直接替换即可自然去重。

newEnd[c] = 1 + Σ end[x]　（x 为 a…z）
答案 = Σ end[x] mod (10⁹ + 7)

完整过程

  1. 创建长度 26 的数组 end，初始全为 0。
  2. 依次读取 s 中每个字符 c，先求所有桶之和 total。
  3. 把 end[c] 替换为 total + 1；其他桶不变。若字符重复，原桶被覆盖，恰好消除重复结果。
  4. 遍历结束后，对全部 26 个桶求和并取模。

以 aba 为例

  • 读 a：a 桶为 1，对应 {a}。
  • 读 b：b 桶为 2，对应 {b, ab}，总数 3。
  • 再读 a：新的 a 桶为 4，对应 {a, aa, ba, aba}，覆盖旧 a 桶；加上 b 桶共 6。

正确性证明

  1. 不遗漏：处理字符 c 后，任何新出现的子序列要么仅为 c，要么由此前某个不同非空子序列追加 c 得到，所以全部进入新的 end[c]。
  2. 桶内不重复：此前不同的字符串追加同一个 c 后仍然不同；单字符 c 也不与它们相同。
  3. 跨桶不重复：不同桶的字符串末尾字符不同，不可能相等。
  4. 覆盖合法：所有旧的以 c 结尾的子序列，都会在新的构造集合中再次出现；用新桶替换旧桶既保留它们，又不重复计数。归纳可知每一步的 26 个桶恰好划分全部不同非空子序列。

边界

  • 单字符答案为 1。
  • 全部相同字符时，答案为字符串长度。
  • 每次加法都应取模，避免数值溢出。
  • JavaScript 使用普通 Number 是安全的：每次累加的中间值远低于安全整数上限。

复杂度

按当前直观实现，每个字符扫描 26 个桶：

  • 时间：O(26n) = O(n)
  • 空间：O(26) = O(1)

替代方案

也可设 dp[i] 为前 i 个字符的不同子序列总数（包含空串），新增字符时先翻倍，再减去该字符上次出现之前的总数。这需要记录每个字符最近出现位置或对应旧状态。其复杂度同为 O(n)，但下标与减法取模更容易出错；按结尾分桶通常更直观。

面试追问

  • 若字符集不固定为 26 个小写字母？可用哈希表维护结尾桶。
  • 如何做到每步严格 O(1)？额外维护总和，替换桶时用 total = total - old + fresh 更新。
  • 为什么不能用集合枚举？不同子序列可能指数级增长，长度 2000 时不可行。

常见错误

  • 把新的计数累加到旧 end[c]，导致重复字符重复计数；这里必须覆盖。
  • 忘记加上单字符子序列本身的 1。
  • 只在最终取模，造成 Java/C++ 整数溢出。
  • 使用减法优化时未处理负数取模。

四语言完整代码

class Solution {
    public int distinctSubseqII(String s) {
        final long MOD = 1_000_000_007L;
        long[] end = new long[26];
        for (char ch : s.toCharArray()) {
            long total = 0;
            for (long count : end) total = (total + count) % MOD;
            end[ch - 'a'] = (total + 1) % MOD;
        }
        long answer = 0;
        for (long count : end) answer = (answer + count) % MOD;
        return (int) answer;
    }
}
/**
 * @param {string} s
 * @return {number}
 */
var distinctSubseqII = function(s) {
    const MOD = 1_000_000_007;
    const end = Array(26).fill(0);
    for (const ch of s) {
        let total = 0;
        for (const count of end) total = (total + count) % MOD;
        end[ch.charCodeAt(0) - 97] = (total + 1) % MOD;
    }
    return end.reduce((sum, count) => (sum + count) % MOD, 0);
};

    def distinctSubseqII(self, s: str) -> int:
