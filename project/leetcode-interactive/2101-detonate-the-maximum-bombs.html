引爆最多的炸弹

Detonate the Maximum Bombs

只能点燃一枚炸弹。它引起的连锁反应，最终能触及多少枚？
先观察位置与半径，再选择你的起点。

打开官方题目 ↗

题意

给定从 0 开始编号的炸弹数组 bombs，每项 bombs[i] = [xᵢ, yᵢ, rᵢ] 描述中心坐标和爆炸半径。

选择一枚炸弹主动引爆。中心落在其圆形范围内（包括边界）的其他炸弹也会爆炸，并继续产生连锁反应。每枚炸弹最多计数一次。

返回所有初始选择中，最终引爆数量的最大值，包含最初那枚炸弹。

参数与约束

maximumDetonation(bombs: integer[][]) → integer
  • 1 ≤ bombs.length ≤ 100
  • bombs[i].length = 3
  • 1 ≤ xᵢ, yᵢ, rᵢ ≤ 100000

输入只有 bombs；起点由你选择，输出不要求返回起点编号。

官方示例

01 · 范围有方向

输入：bombs = [[2,1,3],[6,1,4]]
输出：2

从左边引爆只能影响自身；从右边引爆可触及左边，因此最大数量为 2。

02 · 相互隔离

输入：bombs = [[1,1,5],[10,10,5]]
输出：1

两枚炸弹都无法影响对方。无论选哪一枚，最终数量都是 1。

03 · 连锁延伸

输入：bombs = [[1,2,3],[2,3,1],[3,4,2],[4,5,3],[5,6,4]]
输出：5

选择 0：它触发 1、2，随后 2 触发 3，3 再触发 4，最终五枚全部引爆。

READY TO GO DEEPER?

先做一次选择，再理解全局最优

题解包含建模、正确性证明与四种语言实现，默认收起。

题解 · 有向可达性 + 枚举起点

核心洞察

把炸弹看作顶点。如果 j 的中心位于 i 的半径内，就连一条 i → j。这是有向图：半径不同，i 能触发 j，并不意味着 j 能触发 i。

dx = xᵢ − xⱼ, dy = yᵢ − yⱼ
存在边 i → j ⇔ i ≠ j 且 dx² + dy² ≤ rᵢ²

从某个起点最终引爆的炸弹，恰好是从该点能够到达的所有顶点。不能只数直接邻居，也不能只选择半径最大的炸弹。

完整过程

  1. 枚举所有有序对 (i, j)，用距离平方比较建立邻接表，避免开平方。
  2. 依次选择每枚炸弹作为 start；为每个起点新建 visited 和队列，并将起点标记、入队。
  3. 取出队首 u，检查它的每个邻居 v。若尚未访问，则立即标记并入队，防止重复入队。
  4. 队列为空时，访问数量就是该起点的连锁规模，更新答案。
  5. 全部起点处理完后返回最大规模。若已达到 n，可提前结束；下方代码保留统一循环。

示例 3 从 0 出发：队列 [0] → [1,2] → [2] → [3] → [4] → []。节点 1 没有带来新触发，但仍需要处理；最终访问集合为 {0,1,2,3,4}。

正确性证明

建图准确：判定式与“中心位于爆炸圆内”完全等价，因此每条边都代表一次可发生的直接触发，每次直接触发也都有对应边。

固定起点可靠且完整：起点真实被引爆；搜索仅沿真实触发边加入新顶点，故所有被计数顶点都能引爆。反过来，对任一可达顶点的路径长度归纳：起点已入队，路径前一顶点被处理时，后一顶点若未访问便会入队，因此所有可达顶点最终都被计数。

计数和最优性：入队时标记使每个顶点仅计数一次，即使存在环也会终止。枚举覆盖所有合法主动引爆选择，取各自准确计数的最大值，正是题目所求。

边界与数值

  • 单枚炸弹：答案为 1。
  • 全部隔离：每次搜索只有起点，答案为 1。
  • 边界接触：使用 ≤，中心恰在圆周上仍可引爆。
  • 同坐标：距离为 0，不同编号仍是不同炸弹。
  • 环与多条路径：visited 防止重复计数。
  • Java 用 long，C++ 用 long long，乘法前就提升类型。平方和可超过 32 位整数范围。
  • JavaScript 的平方和小于 2 × 10¹⁰，远小于 2⁵³，Number 可精确表示；Python 整数不受此溢出限制。

复杂度

设顶点数为 n、边数为 m。建图 O(n²)，每个起点的 BFS 为 O(n + m)，总计 O(n² + n(n + m))，最坏 O(n³)。

邻接表占 O(n + m)，visited 和队列占 O(n)，总空间最坏 O(n²)。n ≤ 100 适合这种直接实现。

替代方案

DFS 可得到相同可达集合，复杂度相同；迭代栈可以避免递归深度问题。Floyd 传递闭包也是 O(n³) 时间、O(n²) 空间，最后统计每行可达数。更大规模可考虑强连通分量压缩配合位集去重，复杂度和实现成本更高。

常见错误

  • 把图当无向图或直接使用并查集，丢失触发方向。
  • 用 rᵢ + rⱼ 判断圆相交；题目要求目标中心在当前爆炸范围内。
  • 选择半径最大或出度最大者，忽略位置和多跳连锁。
  • 多个起点共用 visited，导致后续结果被前一次搜索污染。
  • 漏算起点，或出队时才标记而重复入队。
  • 写成 (long)(dx * dx)；若 dx 是 int，转换前已可能溢出。

面试追问

  • 怎样返回最佳起点？更新最大数量时同时保存 start；若需要所有最优起点，遇到相等值时追加。
  • 为什么并查集不合适？它表达无向等价关系，不能回答单向可达性。
  • 可否引爆两枚？计算两起点可达集合的并集大小，不能直接相加，因为连锁可能重叠。
  • 压缩强连通分量后能否简单相加？不能；不同分支可能到达同一分量，需要集合或位集去重。

Java

import java.util.*;

class Solution {
    public int maximumDetonation(int[][] bombs) {
        int n = bombs.length;
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                long dx = (long) bombs[i][0] - bombs[j][0];
                long dy = (long) bombs[i][1] - bombs[j][1];
                long r = bombs[i][2];
                if (i != j && dx * dx + dy * dy <= r * r)
                    graph.get(i).add(j);
            }
        }
        int best = 0;
        for (int start = 0; start < n; start++) {
            boolean[] seen = new boolean[n];
            Queue<Integer> queue = new ArrayDeque<>();
            seen[start] = true;
            queue.add(start);
            int count = 0;
            while (!queue.isEmpty()) {
                int u = queue.remove();
                count++;
                for (int v : graph.get(u)) {
                    if (!seen[v]) {
                        seen[v] = true;
                        queue.add(v);
                    }
                }
            }
            best = Math.max(best, count);
        }
        return best;
    }
}

/**
 * @param {number[][]} bombs
 * @return {number}
 */
var maximumDetonation = function(bombs) {
    const n = bombs.length;
    const graph = Array.from({ length: n }, () => []);
    for (let i = 0; i < n; i++) {
        for (let j = 0; j < n; j++) {
            const dx = bombs[i][0] - bombs[j][0];
            const dy = bombs[i][1] - bombs[j][1];
            const r = bombs[i][2];
            if (i !== j && dx * dx + dy * dy <= r * r) {
                graph[i].push(j);
            }
        }
    }
    let best = 0;
    for (let start = 0; start < n; start++) {
        const seen = Array(n).fill(false);
        const queue = [start];
        seen[start] = true;
        for (let head = 0; head < queue.length; head++) {
            for (const v of graph[queue[head]]) {
                if (!seen[v]) {
                    seen[v] = true;
                    queue.push(v);
                }
            }
        }
        best = Math.max(best, queue.length);
    }
    return best;
};

Python

from typing import List
from collections import deque

class Solution:
    def maximumDetonation(self, bombs: List[List[int]]) -> int:
        n = len(bombs)
        graph = [[] for _ in range(n)]
        for i, (x, y, r) in enumerate(bombs):
            for j, (xx, yy, _) in enumerate(bombs):
                if i != j and (x - xx) ** 2 + (y - yy) ** 2 <= r ** 2:
                    graph[i].append(j)

        best = 0
        for start in range(n):
            seen = {start}
            queue = deque([start])
            while queue:
                u = queue.popleft()
                for v in graph[u]:
                    if v not in seen:
                        seen.add(v)
                        queue.append(v)
            best = max(best, len(seen))
        return best

C++

#include <vector>
#include <queue>
#include <algorithm>
using namespace std;

class Solution {
public:
    int maximumDetonation(vector<vector<int>>& bombs) {
        int n = bombs.size();
        vector<vector<int>> graph(n);
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                long long dx = (long long)bombs[i][0] - bombs[j][0];
                long long dy = (long long)bombs[i][1] - bombs[j][1];
                long long r = bombs[i][2];
                if (i != j && dx * dx + dy * dy <= r * r)
                    graph[i].push_back(j);
            }
        }
        int best = 0;
        for (int start = 0; start < n; ++start) {
            vector<bool> seen(n, false);
            queue<int> q;
            q.push(start);
            seen[start] = true;
            int count = 0;
            while (!q.empty()) {
                int u = q.front();
                q.pop();
                ++count;
                for (int v : graph[u]) {
                    if (!seen[v]) {
                        seen[v] = true;
                        q.push(v);
                    }
                }
            }
            best = max(best, count);
        }
        return best;
    }
};
