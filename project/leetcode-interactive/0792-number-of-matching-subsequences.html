Problem 792 · 字符串

匹配子序列的单词数Number of Matching Subsequences

给一条主字符串和一组候选单词。无需改动原有顺序，判断每个候选词能否沿着主字符串依次找到全部字符，并统计成功的个数。

难度中等
题号792
输入string, string[]
返回integer

01 · 理解任务

题意与约束

先理解“保持相对顺序”的含义，再进入下方的逐字符实验。

给定字符串 s 和字符串数组 words，返回其中有多少个 words[i] 是 s 的子序列。数组中的重复单词按出现次数分别计数。

子序列：从原字符串删除任意数量的字符（也可以一个都不删），且不改变剩余字符相对顺序后得到的新字符串。例如，"ace" 是 "abcde" 的子序列。

官方函数形式 numMatchingSubseq(s: string, words: string[]) → integer
约束
  • 1 ≤ s.length ≤ 5 × 10⁴
  • 1 ≤ words.length ≤ 5000
  • 1 ≤ words[i].length ≤ 50
  • s 与每个 words[i] 只包含小写英文字母。

示例 1

输入s = "abcde", words = ["a","bb","acd","ace"]
输出3

“a”、“acd” 与 “ace” 都能依次匹配；“bb” 需要两个 b，而主字符串只有一个。

示例 2

输入s = "dsahjpjauf", words = ["ahjpjau","ja","ahbwzgqnuk","tnmlanowax"]
输出2

完整参数与官方示例一致，成功匹配的候选词共有 2 个。

Solution · Waiting Buckets

让单词等待字符，而不是反复扫描 s

核心实现使用 26 个等待桶。每个候选词只保存“下一位要匹配哪里”，主字符串只从左到右扫描一次。

核心洞察

逐个单词拿双指针扫描 s 会反复经过同一批字符。换一个方向：先把每个单词按“当前所需字符”分组。扫描到 s[i] = c 时，只推进正在等待 c 的单词；其他单词无需检查。

等待桶不变量：每个尚未完成的单词状态，恰好位于它下一待匹配字符对应的桶中。

完整过程

  1. 建立 26 个桶，桶 c 保存下一位正在等待字符 c 的单词状态。
  2. 每个状态记录单词编号与待匹配下标，初始下标为 0，放入首字母桶。
  3. 从左到右读取 s。取出当前字符对应桶的旧内容，并立即换成一个新空桶。
  4. 把取出的每个状态向后推进一位：若到达词尾，答案加一；否则进入下一个所需字符的桶。
  5. 必须先隔离旧桶，避免像 "bb" 这样的单词用同一个 b 连续推进两次。

正确性证明

初始化：每个单词尚未匹配任何字符，被放入首个所需字符的桶，不变量成立。

保持：扫描到字符 c 时，只有等待 c 的状态能合法使用它。推进后，未完成状态进入新的下一字符桶，因此不变量继续成立；其他桶完全不受影响。

终止：状态只有在按顺序匹配完全部字符后才计数；任何确为 s 子序列的单词，又会在对应字符出现时逐步推进到词尾。因此最终计数恰好等于匹配子序列的单词数。

复杂度

时间 O(|s| + Σ|word|)每个 s 字符扫描一次；每个单词位置至多被成功推进一次。
额外空间 O(words)每个单词仅维护一个活动状态，另有固定 26 个桶；不计输入字符串存储。

边界情况

  • 同一个单词重复出现时，每个数组元素都是独立状态，应分别计数。
  • 单词比 s 长时不可能完成，会停留在某个桶中。
  • s 中大量重复字符时，务必把当前旧桶整体取出后再推进。
  • 最短长度为 1；题目约束下无需处理空单词或非小写字符。

替代方案

  • 逐词双指针：实现最直观，时间最坏为 O(words × |s|)，在上界下可能过慢。
  • 位置表 + 二分：预存 s 中每个字符的全部下标，对每个单词依次二分查找更靠后的位置，时间约为 O(|s| + Σ|word| log |s|)。
  • 去重计数：先统计相同单词频次，可减少重复状态；完成一个唯一单词时一次加上频次，适合重复很多的数据。

面试追问

  • 如果 words 持续在线到达，而 s 固定，如何用位置表快速回答？
  • 如果字符集是 Unicode，如何把固定 26 桶改为按字符建立的哈希映射？
  • 如何对重复单词压缩状态，并保证答案仍按原数组出现次数计数？
  • 当 s 也以流式字符到达时，等待桶方案为什么天然适配？

常见错误

  • 一边遍历当前桶一边把仍等待相同字符的状态放回同一个数组，导致本轮重复消费。
  • 只用字符串值作为状态，忽略数组里相同单词需要重复计数。
  • 完成判断差一位：推进下标后，应在等于单词长度时立即计数。
  • 错误地把子序列理解为子串；子序列允许跳过字符，但顺序不能改变。

Java · LeetCode 提交形式
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int numMatchingSubseq(String s, String[] words) {
        @SuppressWarnings("unchecked")
        List<int[]>[] buckets = new ArrayList[26];
        for (int i = 0; i < 26; i++) {
            buckets[i] = new ArrayList<>();
        }

        for (int i = 0; i < words.length; i++) {
            buckets[words[i].charAt(0) - 'a'].add(new int[] {i, 0});
        }

        int answer = 0;
        for (int i = 0; i < s.length(); i++) {
            int bucketIndex = s.charAt(i) - 'a';
            List<int[]> current = buckets[bucketIndex];
            buckets[bucketIndex] = new ArrayList<>();

            for (int[] state : current) {
                String word = words[state[0]];
                int nextIndex = state[1] + 1;
                if (nextIndex == word.length()) {
                    answer++;
                } else {
                    state[1] = nextIndex;
                    buckets[word.charAt(nextIndex) - 'a'].add(state);
                }
            }
        }
        return answer;
    }
}

var numMatchingSubseq = function(s, words) {
    const buckets = Array.from({ length: 26 }, () => []);

    for (let i = 0; i < words.length; i++) {
        const first = words[i].charCodeAt(0) - 97;
        buckets[first].push([i, 0]);
    }

    let answer = 0;
    for (const char of s) {
        const bucketIndex = char.charCodeAt(0) - 97;
        const current = buckets[bucketIndex];
        buckets[bucketIndex] = [];

        for (const state of current) {
            const word = words[state[0]];
            const nextIndex = state[1] + 1;
            if (nextIndex === word.length) {
                answer++;
            } else {
                state[1] = nextIndex;
                const nextBucket = word.charCodeAt(nextIndex) - 97;
                buckets[nextBucket].push(state);
            }
        }
    }
    return answer;
};
Python 3 · LeetCode 提交形式
from typing import List


class Solution:
    def numMatchingSubseq(self, s: str, words: List[str]) -> int:
        buckets = [[] for _ in range(26)]

        for word_index, word in enumerate(words):
            buckets[ord(word[0]) - ord("a")].append([word_index, 0])

        answer = 0
        for char in s:
            bucket_index = ord(char) - ord("a")
            current = buckets[bucket_index]
            buckets[bucket_index] = []

            for state in current:
                word = words[state[0]]
                next_index = state[1] + 1
                if next_index == len(word):
                    answer += 1
                else:
                    state[1] = next_index
                    next_bucket = ord(word[next_index]) - ord("a")
                    buckets[next_bucket].append(state)

        return answer
C++ · LeetCode 提交形式
class Solution {
public:
    int numMatchingSubseq(string s, vector<string>& words) {
        vector<vector<pair<int, int>>> buckets(26);

        for (int i = 0; i < static_cast<int>(words.size()); ++i) {
            buckets[words[i][0] - 'a'].push_back({i, 0});
        }

        int answer = 0;
        for (char ch : s) {
            int bucketIndex = ch - 'a';
            vector<pair<int, int>> current = move(buckets[bucketIndex]);
            buckets[bucketIndex].clear();

            for (auto [wordIndex, position] : current) {
                int nextIndex = position + 1;
                if (nextIndex == static_cast<int>(words[wordIndex].size())) {
                    ++answer;
                } else {
                    char nextChar = words[wordIndex][nextIndex];
                    buckets[nextChar - 'a'].push_back({wordIndex, nextIndex});
                }
            }
        }
        return answer;
    }
};
