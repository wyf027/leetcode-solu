祖父节点值为偶数的节点和

Sum of Nodes with Even-Valued Grandparent

先读题目 打开三代追踪器
先别急着想“哪些节点是偶数”。这道题真正追问的是：当你站在一个节点上，如何知道两层之前的值？答案隐藏在页面后半段。

01 · Problem

题目说明

给定一棵二叉树的根节点 root，计算并返回所有“祖父节点的值为偶数”的节点值之和。一个节点的祖父节点，是它的父节点的父节点；如果不存在符合条件的节点，返回 0。

参数
root: TreeNode

二叉树根节点，至少包含一个节点。

返回值
integer

满足条件的全部节点值之和。

示例 1

多层树
输入：root = [6,7,8,2,7,1,3,9,null,1,4,null,null,null,5]
输出：18
解释：符合条件的节点为 2、7、1、3、5，
它们的和是 18。

示例 2

单节点
输入：root = [1]
输出：0
解释：唯一节点没有祖父节点。

约束

  • 树中节点数在 [1, 10⁴] 范围内。
  • 每个节点满足 1 <= Node.val <= 100。

03 · Solution

准备好连接线索了吗？

题解默认收起。先用上面的追踪器形成自己的状态设计，再展开核对。

Core Insight

让递归参数携带两代历史

核心洞察

访问 node 时，同时携带它的 parent 与 grandparent。若祖父存在且值为偶数，就把当前值加入答案。递归到孩子时，当前节点变成父亲，原父亲变成祖父。

状态转移

dfs(child, node, parent)

这一个参数位移，恰好保存从当前节点向上两层所需的全部信息，不需要额外哈希表。

Walkthrough

完整过程

初始化

从根节点开始，父亲和祖父都为空，累计和为 0。

访问与判断

每到一个节点，只检查携带来的祖父节点是否为偶数，符合就累加。

向下传递

分别递归左右孩子，把三代窗口整体向下平移一层。

在示例 1 中，根节点 6 让其孙辈 2、7、1、3 被计入；节点 8 让其孙辈 5 被计入，最终为 2 + 7 + 1 + 3 + 5 = 18。

Correctness

正确性说明

参数不变式

每次调用 dfs(node, parent, grandparent) 时，后两个参数确实分别是当前节点的一层和两层祖先。根调用成立；递归到孩子时传入 (child, node, parent)，因此不变式继续成立。

局部判断准确

由不变式，算法检查的 grandparent 正是当前节点唯一的祖父节点。因此当前节点被累加，当且仅当它的祖父值为偶数。

覆盖且不重复

深度优先遍历恰好访问树中每个节点一次，每个符合条件的节点被加一次，不符合的节点不被加入，所以最终和正确。

Bounds

边界与复杂度

  • 单节点或树高不足 3：没有合法祖父，答案为 0。
  • 祖父值为 0 时也属于偶数；本题约束实际从 1 开始。
  • 节点值可重复，判断依据是祖先关系而不是值是否唯一。
  • 时间复杂度：O(n)。
  • 递归栈空间：O(h)；最坏退化为 O(n)。

Alternatives

替代方案

向下看两层：遇到偶数节点时直接加它所有孙辈的值，同样是 O(n)，但分支判断较多。

BFS 队列：队列元素保存节点、父值与祖父值，可避免递归深度风险，额外空间为 O(w)。

Implementations

四语言完整代码

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int sumEvenGrandparent(TreeNode root) {
        return dfs(root, null, null);
    }

    private int dfs(TreeNode node, TreeNode parent, TreeNode grandparent) {
        if (node == null) return 0;

        int sum = 0;
        if (grandparent != null && grandparent.val % 2 == 0) {
            sum += node.val;
        }

        sum += dfs(node.left, node, parent);
        sum += dfs(node.right, node, parent);
        return sum;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var sumEvenGrandparent = function(root) {
    function dfs(node, parent, grandparent) {
        if (node === null) return 0;

        let sum = 0;
        if (grandparent !== null && grandparent.val % 2 === 0) {
            sum += node.val;
        }

        sum += dfs(node.left, node, parent);
        sum += dfs(node.right, node, parent);
        return sum;
    }

    return dfs(root, null, null);
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def sumEvenGrandparent(self, root: Optional[TreeNode]) -> int:
        def dfs(node, parent, grandparent):
            if node is None:
                return 0

            total = 0
            if grandparent is not None and grandparent.val % 2 == 0:
                total += node.val

            total += dfs(node.left, node, parent)
            total += dfs(node.right, node, parent)
            return total

        return dfs(root, None, None)
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int sumEvenGrandparent(TreeNode* root) {
        return dfs(root, nullptr, nullptr);
    }

private:
    int dfs(TreeNode* node, TreeNode* parent, TreeNode* grandparent) {
        if (node == nullptr) return 0;

        int sum = 0;
        if (grandparent != nullptr && grandparent->val % 2 == 0) {
            sum += node->val;
        }

        sum += dfs(node->left, node, parent);
        sum += dfs(node->right, node, parent);
        return sum;
    }
};

面试追问

  • 如果改成“第 k 代祖先满足条件”，状态如何推广？
  • 如何用 BFS 完成，并分析队列的最大空间？
  • 树可能退化到 10⁵ 层时，如何避免递归栈溢出？
  • 如果需要返回节点列表而不是和值，要改哪些位置？

Pitfalls

常见错误

  • 检查父节点为偶数，而不是祖父节点。
  • 向下递归时把参数顺序写反，破坏三代关系。
  • 祖父为空时直接访问其值，引发空指针错误。
  • 只考虑左右孙子都存在的完整二叉树。
  • 误把偶数节点自身加入，而不是加入它的孙辈。
