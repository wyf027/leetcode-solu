Assignment

题意转述

给定一个元素互不相同的整数数组 nums，返回它的所有可能子集（幂集）。答案中不能出现重复子集，返回顺序不限。

约束

  • 1 ≤ nums.length ≤ 10
  • −10 ≤ nums[i] ≤ 10
  • nums 中所有元素互不相同

Official example 01

输入

nums = [1,2,3]

输出

[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

Official example 02

输入

nums = [0]

输出

[[],[0]]

注：若输入包含字符串，空格会显示为 ␠；本题输入仅含整数。子集内部顺序按原数组保持，子集列表顺序可以不同。

Core insight

每个元素只有两种命运

处理到 nums[index] 时，递归分成“不选”和“选”两支。直到 index === nums.length，当前路径就是一个完整子集。每个二进制选择串唯一，因此没有重复。

Invariant

路径只描述已处理前缀

进入 dfs(index) 时，path 精确记录前 index 个元素中被选中的那些。递归返回后执行 pop，恢复父节点状态，再探索另一条支路。

Complete process

完整过程

  1. 01

    从空路径开始

    调用 dfs(0)。

  2. 02

    先关闭

    不加入当前数字，递归到下一位。

  3. 03

    再接通

    加入当前数字，再递归到下一位。

  4. 04

    撤销现场

    返回后 pop，让兄弟支路看到原状态。

Complexity

复杂度

共有 2ⁿ 个答案，每次复制路径最多 O(n)：时间 O(n·2ⁿ)。递归栈与路径额外空间 O(n)，不计输出。

Boundaries

边界

  • 单元素必须得到空集与自身。
  • 负数和零不改变选择逻辑。
  • 空集一定要收录。
  • 题目保证元素互异，无需去重。

Trade-offs

替代方案

位掩码枚举最短，但解释回溯状态较弱；迭代倍增从 [[]] 开始，每读一个数复制已有答案并追加它，直观但仍需复制全部中间集合。面试主推二叉 DFS，状态与证明最清楚。

Common mistakes

常见错误

  • 把 path 引用直接存入答案，后续修改污染已保存结果。
  • 选中后忘记 pop，兄弟分支继承错误状态。
  • 只在路径非空时保存，漏掉空集。
  • 误以为答案顺序必须和样例一致。

Interview follow-ups

面试追问

  • 如果数组有重复元素，如何排序并在同层去重？
  • 怎样用位掩码证明共有 2ⁿ 个子集？
  • 能否改成流式生成，避免一次保留所有答案？
  • 为什么输出规模决定了不可能优于 Ω(n·2ⁿ)？

class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> answer = new ArrayList<>();
        dfs(nums, 0, new ArrayList<>(), answer);
        return answer;
    }

    private void dfs(int[] nums, int index, List<Integer> path,
                     List<List<Integer>> answer) {
        if (index == nums.length) {
            answer.add(new ArrayList<>(path));
            return;
        }

        dfs(nums, index + 1, path, answer);
        path.add(nums[index]);
        dfs(nums, index + 1, path, answer);
        path.remove(path.size() - 1);
    }
}
var subsets = function (nums) {
  const answer = [];
  const path = [];

  function dfs(index) {
    if (index === nums.length) {
      answer.push([...path]);
      return;
    }

    dfs(index + 1);
    path.push(nums[index]);
    dfs(index + 1);
    path.pop();
  }

  dfs(0);
  return answer;
};
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        answer = []
        path = []

        def dfs(index: int) -> None:
            if index == len(nums):
                answer.append(path.copy())
                return

            dfs(index + 1)
            path.append(nums[index])
            dfs(index + 1)
            path.pop()

        dfs(0)
        return answer
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> answer;
        vector<int> path;
        dfs(nums, 0, path, answer);
        return answer;
    }

private:
    void dfs(const vector<int>& nums, int index, vector<int>& path,
             vector<vector<int>>& answer) {
        if (index == nums.size()) {
            answer.push_back(path);
            return;
        }

        dfs(nums, index + 1, path, answer);
        path.push_back(nums[index]);
        dfs(nums, index + 1, path, answer);
        path.pop_back();
    }
};
