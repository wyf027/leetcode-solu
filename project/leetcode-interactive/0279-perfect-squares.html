完全平方数

把一个整数拆成若干块正方形面积，并让使用的方块数量尽可能少。

Problem

题目描述

给定一个整数 n，返回和为 n 的完全平方数的最少数量。

完全平方数是某个整数与自身相乘的结果，例如 1、4、9、16；而 3、11 不是完全平方数。

示例 1

输入：n = 12
输出：3
解释：12 = 4 + 4 + 4

示例 2

输入：n = 13
输出：2
解释：13 = 4 + 9
约束

1 <= n <= 104

Solution

独立题解

默认收起，准备好后再揭晓完整思路与代码。

动态规划：让每个状态复用更小状态的答案

核心洞察

设 dp[i] 为组成整数 i 所需的最少完全平方数数量。若最后选用了平方数 j²，前面的部分就是 i - j² 的最优解，因此可以从所有合法的 j² 中取最小值。

dp[i] = min(dp[i - j²] + 1)，其中 1 <= j² <= i

完整过程

  1. 定义状态：dp[i] 表示和为 i 的最少平方数数量。
  2. 初始化：dp[0] = 0；其他位置先设为一个大值。
  3. 枚举目标：依次计算 i = 1 ... n。
  4. 枚举最后一块：尝试每个满足 j * j <= i 的平方数。
  5. 转移并返回：用 dp[i - j*j] + 1 更新 dp[i]，最终返回 dp[n]。

以 n = 12 为例

当计算 dp[12] 时，可作为最后一块的平方数有 1、4、9：

  • 选 1：dp[11] + 1
  • 选 4：dp[8] + 1 = 3
  • 选 9：dp[3] + 1 = 4

最小值为 3，对应 12 = 4 + 4 + 4。

正确性说明

归纳基础：dp[0] = 0 显然正确，组成 0 不需要任何平方数。

归纳假设：假设所有小于 i 的状态都已经得到最少数量。

归纳步骤：任取一种组成 i 的最优方案，设它最后使用的平方数为 j²。去掉这一项后，剩余和为 i-j²。若剩余部分不是该状态的最优解，就能替换为更短方案，使原方案更短，与“最优”矛盾。算法枚举了所有可能的最后一项，并取 dp[i-j²]+1 的最小值，因此得到的 dp[i] 恰为最优值。由数学归纳法，dp[n] 正确。

复杂度

  • 时间：O(n√n)，每个 i 至多枚举 √i 个平方数。
  • 空间：O(n)，用于保存状态数组。

边界情况

  • n = 1：答案为 1。
  • n 本身是完全平方数：答案为 1。
  • 较大输入 n = 10⁴：状态数组仍在约束范围内。
  • 重复使用同一平方数是允许的，例如 12 = 4 + 4 + 4。

四语言完整实现

import java.util.Arrays;

class Solution {
    public int numSquares(int n) {
        int[] dp = new int[n + 1];
        Arrays.fill(dp, n + 1);
        dp[0] = 0;

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j * j <= i; j++) {
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }
}

class Solution:
    def numSquares(self, n: int) -> int:
        dp = [n + 1] * (n + 1)
        dp[0] = 0

        for i in range(1, n + 1):
            j = 1
            while j * j <= i:
                dp[i] = min(dp[i], dp[i - j * j] + 1)
                j += 1

        return dp[n]

替代方案

  • 广度优先搜索：把“当前和”视为节点，每加入一个平方数走一层，第一次到达 n 的层数就是答案。直观但队列和去重也需要额外空间。
  • 数论：利用四平方和定理与三平方和判定，可把时间优化到 O(√n)、空间降到 O(1)，但证明与实现更不直观。
  • 完全背包：把每个平方数视为可无限使用的物品，目标是用最少件数恰好装满容量 n，本质上与这里的状态转移一致。

常见错误

  • 把平方数当成只能使用一次，错误地写成 0/1 背包。
  • 忘记设置 dp[0] = 0，导致所有状态都无法正确转移。
  • 循环条件写成 j * j < i，漏掉 i 本身是平方数的情况。
  • 用 Infinity + 1 或超大整数时忽略溢出；这里用 n + 1 已足够安全。

面试追问

  1. 为什么可以重复选择同一个平方数？因为题目只要求各项是完全平方数，没有限制每个值出现次数，对应完全背包。
  2. 能否交换两层循环？若只求最少数量且按正确方向更新，可以采用完全背包写法；但需要清楚状态含义和遍历方向，避免误写为 0/1 背包。
  3. 如何输出具体分解？更新 dp[i] 时同步记录带来最小值的平方数，再从 n 反向回溯到 0。
  4. 能否做到常数空间？动态规划版本通常不能；若允许使用数论定理，可以做到 O(1) 额外空间。
