1666.
改变二叉树的根节点

Change the Root of a Binary Tree：沿着“叶子 → 原根”的唯一路径，把父子指针逐段翻转，同时让路径外的子树留在正确的位置。

中等会员题路径长度驱动原地修改
01 / Problem

题意转述

给定一棵带有 parent 指针的二叉树根节点 root，以及树中一个确定的叶节点 leaf。请把这棵树重新定根，使 leaf 成为新根。

从 leaf 沿 parent 一直走到原根（不含原根），对每个当前节点 cur 依次执行：若它还有左孩子，就先把该左孩子挪到右侧；再把原父节点接成它的新左孩子，并断开原父节点指向它的旧孩子边。最后还要让所有受影响节点的 parent 指针与新结构一致。

关键保证：路径上的当前节点在需要挪动时至多保留一个孩子，因此“左孩子挪到右边”不会覆盖另一棵有效子树。
输入 1root: Node
输入 2leaf: Node
返回Node（新的根）

官方示例参数

示例 1 
输入：root = [3,5,1,6,2,0,8,null,null,7,4], leaf = 7
输出：[7,2,null,5,4,3,6,null,null,null,1,null,null,0,8]
示例 2 
输入：root = [3,5,1,6,2,0,8,null,null,7,4], leaf = 0
输出：[0,1,null,3,8,5,null,null,null,6,2,null,null,7,4]

数组采用按层序列化表示；函数实际接收的是 Node 对象，leaf 也是节点引用，而不是只接收数值。

约束

  • 树中节点数在 [2, 100] 范围内。
  • -10⁹ ≤ Node.val ≤ 10⁹。
  • 所有节点值互不相同。
  • leaf 一定存在于树中，并且是叶节点。

03 / Solution

沿 parent 链原地翻转

核心洞察：先保存 cur.parent，再改任何指针。每轮只需修正一条路径边；若 cur.left 仍是一棵路径外子树，就先把它移到 cur.right，腾出左槽位接原父节点。

完整过程

  1. 令 cur = leaf，并保存它的原父节点 parent。
  2. 循环直到处理完原根：先保存下一跳 next = parent.parent。
  3. 若 cur.left 非空，把它移动到 cur.right。
  4. 令 cur.left = parent，同步 parent.parent = cur。
  5. 判断 cur 原来在 parent 的哪一侧，并把那条旧边置空，避免形成环。
  6. 让 cur、parent 沿原 parent 链各前进一步；最后令 leaf.parent = null 并返回 leaf。

边界情况

  • 只有两个节点：只反转一条边。
  • leaf 是原根的直接孩子。
  • 路径从父节点左侧或右侧进入，断边方向必须分别判断。
  • 路径节点保留左侧旁支时，必须先迁到右侧。
  • 新根的 parent 必须显式设为 null。

正确性说明

  1. 旁支保持：每轮修改前，当前节点可能保留的左侧路径外子树会被整体移到右侧；子树内部结构与 parent 指针都未改变。
  2. 路径边正确反转：把原父节点设为 cur.left，并令原父节点的 parent 指向 cur，恰好同时反转这一段向下边和向上边。
  3. 没有环：新边建立后，立即断开原父节点指向 cur 的旧左/右边，所以同一对节点之间不会保留相反方向的孩子边。
  4. 覆盖整条路径：循环沿事先保存的原 parent 链逐段前进，直到原根；因此每条路径边恰好处理一次，路径外节点不被触碰。最终 leaf.parent = null，故它是合法的新根。
复杂度

时间：O(h)，其中 h 是 leaf 到原根的路径长度。
额外空间：O(1)，只维护常数个指针。

替代方案

可用递归从 leaf 沿 parent 链回溯，逻辑相近，但会占用 O(h) 调用栈。若节点没有 parent 指针，则先用 DFS 建立父映射，时间和空间都会变为 O(n)。

四语言完整实现

以下签名按题目的 Node（包含 val / left / right / parent）模型编写，可直接放入对应语言的提交类中。

JavaO(h) / O(1)
/*
// Definition for a Node.
class Node {
    public int val;
    public Node left;
    public Node right;
    public Node parent;
}
*/

class Solution {
    public Node flipBinaryTree(Node root, Node leaf) {
        Node cur = leaf;
        Node parent = cur.parent;

        while (cur != root) {
            Node next = parent.parent;

            if (cur.left != null) {
                cur.right = cur.left;
            }
            cur.left = parent;
            parent.parent = cur;

            if (parent.left == cur) {
                parent.left = null;
            } else {
                parent.right = null;
            }

            cur = parent;
            parent = next;
        }

        leaf.parent = null;
        return leaf;
    }
}

/**

var flipBinaryTree = function(root, leaf) {
  let cur = leaf;
  let parent = cur.parent;

  while (cur !== root) {
    const next = parent.parent;

    if (cur.left !== null) {
      cur.right = cur.left;
    }
    cur.left = parent;
    parent.parent = cur;

    if (parent.left === cur) {
      parent.left = null;
    } else {
      parent.right = null;
    }

    cur = parent;
    parent = next;
  }

  leaf.parent = null;
  return leaf;
};

常见错误

  • 改完 cur.parent 才读取下一跳，导致原路径丢失。
  • 建立反向边却不断开旧边，形成二节点环。
  • 忽略 parent.left == cur 与 parent.right == cur 的区别。
  • 直接覆盖 cur.left，丢失原有旁支。
  • 只改 left/right，不同步 parent。
