240. 搜索二维矩阵 II

每行从左到右递增、每列从上到下递增的矩阵中，判断目标值是否存在。选择右上角，比较一次就能排除整行或整列。

二维矩阵阶梯搜索单调性O(m+n)

题意

给定 m × n 整数矩阵 matrix，其中每行从左到右非递减、每列从上到下非递减；判断 target 是否在矩阵中。

官方样例 1

输入matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]target = 5
输出true

官方样例 2

输入matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]target = 20
输出false

约束：m,n ∈ [1,300]；-10⁹ ≤ matrix[i][j], target ≤ 10⁹。

交互：从右上角 15 开始寻找 5

当前值大于 target，排除当前列并向左；当前值小于 target，排除当前行并向下。

键盘：← / →；Space 播放

题解：右上角阶梯搜索

核心洞察

右上角的左侧都更小、下侧都更大。若当前值大于 target，当前列及其下方都不可能命中，向左；若当前值小于 target，当前行及其左侧都不可能命中，向下。

完整过程

  1. 令 row = 0、col = n - 1。
  2. 当前值等于 target，返回 true。
  3. 当前值大于 target，col--。
  4. 当前值小于 target，row++。
  5. 越界则返回 false。

边界与复杂度

单行/单列：仍是同一循环。

目标小于最小值或大于最大值：很快沿边界越界。

重复值：非递减而非严格递增，规则仍成立。

复杂度：每步消去一行或一列，时间 O(m+n)，空间 O(1)。

替代方案

逐行二分为 O(m log n)；分治也可，但常数更高。阶梯搜索直接利用两维单调性，是最佳主线。

常见错误：从左上角出发无法同时获得可排除的一行/列；或遇到大于 target 时向下走，方向应当是向左。

面试追问

若每行严格递增、行与行之间也有整体大小关系，可将矩阵看作有序一维数组并二分。若要返回所有重复目标的位置，则命中后需扩展扫描。

class Solution {
  public boolean searchMatrix(int[][] matrix, int target) {
    int row = 0, col = matrix[0].length - 1;
    while (row < matrix.length && col >= 0) {
      int value = matrix[row][col];
      if (value == target) return true;
      if (value > target) col--;
      else row++;
    }
    return false;
  }
}
