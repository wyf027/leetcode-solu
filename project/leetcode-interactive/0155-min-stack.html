核心洞察

让每一层携带当时的最小值

数据栈保存真实元素；最小值栈在相同下标保存“截至这一层的最小值”。 两栈永远等长，因此 push 与 pop 都同步一次，getMin 只读取辅助栈顶。

复杂度

所有操作 O(1)

push、pop、top、getMin 的时间复杂度均为 O(1)；存储 n 个元素时，额外空间复杂度为 O(n)。

完整过程

  1. push(val)：数据栈压入 val。
  2. 最小值栈压入 min(val, 当前最小值)。
  3. pop()：两个栈同时弹出顶部。
  4. top() 读取数据栈顶；getMin() 读取最小值栈顶。

边界

  • 首次 push 时辅助栈为空，直接压入 val。
  • 重复最小值必须逐层保留，弹出一个后答案仍正确。
  • 使用 int 即可覆盖题目给定的 32 位范围。
  • 题目保证查询和弹出时非空，无需自行约定异常返回值。

替代方案取舍

辅助栈也可只记录新最小值，但相等时必须使用 ≤，pop 时还要比较两个栈顶。同步前缀最小值更易证明，也更适合面试主线。

面试追问

能否只用一个栈？可以存储 val 与当前最小值的二元组；也可用差值编码， 但要警惕整数溢出与可读性下降。

常见错误

只保存一个全局 min，弹出最小值后无法恢复；稀疏辅助栈使用 < 而不是 ≤，会丢失重复最小值。 

class MinStack {
    private final java.util.Deque<Integer> data = new java.util.ArrayDeque<>();
    private final java.util.Deque<Integer> mins = new java.util.ArrayDeque<>();

    public MinStack() {}

    public void push(int val) {
        data.push(val);
        mins.push(mins.isEmpty() ? val : Math.min(val, mins.peek()));
    }

    public void pop() {
        data.pop();
        mins.pop();
    }

    public int top() {
        return data.peek();
    }

    public int getMin() {
        return mins.peek();
    }
}
var MinStack = function () {
    this.data = [];
    this.mins = [];
};

MinStack.prototype.push = function (val) {
    this.data.push(val);
    const currentMin = this.mins.length
        ? Math.min(val, this.mins[this.mins.length - 1])
        : val;
    this.mins.push(currentMin);
};

MinStack.prototype.pop = function () {
    this.data.pop();
    this.mins.pop();
};

MinStack.prototype.top = function () {
    return this.data[this.data.length - 1];
};

MinStack.prototype.getMin = function () {
    return this.mins[this.mins.length - 1];
};
class MinStack:
    def __init__(self):
        self.data = []
        self.mins = []

    def push(self, val: int) -> None:
        self.data.append(val)
        current_min = min(val, self.mins[-1]) if self.mins else val
        self.mins.append(current_min)

    def pop(self) -> None:
        self.data.pop()
        self.mins.pop()

    def top(self) -> int:
        return self.data[-1]

    def getMin(self) -> int:
        return self.mins[-1]
class MinStack {
private:
    std::stack<int> data;
    std::stack<int> mins;

public:
    MinStack() = default;

    void push(int val) {
        data.push(val);
        mins.push(mins.empty() ? val : std::min(val, mins.top()));
    }

    void pop() {
        data.pop();
        mins.pop();
    }

    int top() {
        return data.top();
    }

    int getMin() {
        return mins.top();
    }
};
