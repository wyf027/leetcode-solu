扫地机器人Robot Room Cleaner

隔着一层受限接口，让看不见地图的机器人清扫所有可达空间。页面先呈现题目与可操作实验；完整策略藏在底部，按需展开。

Problem brief

题目转述

付费题官方题面字段为空；以下依据官方题名、元数据、交互签名与公开通行定义作简明转述，不复刻原题长文本。

一个房间可由 m × n 的二进制网格表示：1 是可通行空地，0 是障碍。机器人从给定空地出发，初始朝上；但提交的算法拿不到 room、row、col，只能调用机器人接口。

请实现 cleanRoom(Robot robot)，让机器人清扫从起点能够到达的每一个空地。方法本身返回 void；评测器依据清扫覆盖情况判定。元数据中的 room, row, col 是交互评测夹具的完整输入参数，不会直接暴露给解法。

move(): boolean前方为空地时前进一步并返回 true；否则原地不动并返回 false。
turnLeft()原地向左旋转 90°。
turnRight()原地向右旋转 90°。
clean()清扫机器人当前所在单元格。
关键限制：机器人不知道自己的绝对坐标，也不能直接探测整张地图；算法必须只依据接口调用结果行动。

约束

  • m == room.length
  • n == room[i].length
  • 1 ≤ m ≤ 100
  • 1 ≤ n ≤ 200
  • room[i][j] 为 0 或 1
  • 0 ≤ row < m
  • 0 ≤ col < n
  • room[row][col] == 1
  • 所有空地都可从起点到达

评测输入完整形式：cleanRoom(room, row, col)；提交代码接收平台提供的 Robot 对象。

01

核心洞察

真实坐标不可见，但我们可以把起点记作虚拟坐标 (0,0)。每次成功移动时，根据当前朝向推导相邻虚拟坐标，用集合避免重复访问。

难点不是“走过去”，而是递归返回后让机器人回到原格并恢复原朝向。这样每一层都拥有稳定的物理状态。

完整过程

建立局部坐标系

固定方向数组为北、东、南、西。起点映射为 (0,0)，实际地图边界在哪里并不重要。

进入即标记并清扫

把当前虚拟坐标加入 visited，调用 clean()。标记发生在继续探索之前，避免环路。

按四个方向尝试

当前朝向为 d 时，第 i 次尝试方向 (d+i)%4。若目标坐标未访问且 move() 成功，递归探索。

物理回退

子递归结束后连续右转两次、前进一步、再右转两次。机器人回到父格，朝向也与进入子递归前一致。

转向下一个候选

每轮末尾右转一次。四轮后恰好检查四个方向，且朝向回到本层刚进入时的方向。

正确性证明

引理 1：坐标一致

从虚拟坐标 (x,y) 沿方向 d 成功移动，实际与虚拟位置都沿同一方向变化，所以递归参数始终对应机器人的实际位置。

引理 2：状态恢复

goBack 先掉头回到父格，再次掉头恢复原朝向。因此子调用返回后，父调用的位置和方向不变。

定理：清扫完备

每个首次到达的可达格都会被标记并清扫；每格又会尝试四个邻居。由可达路径归纳，所有可达格最终都会被访问。集合保证每格至多递归一次。

复杂度、边界与取舍

  • 设可达空地数为 N。每格只递归一次并检查四个方向，时间复杂度为 O(N)，接口动作总量也是 O(N)。
  • visited 与最深递归栈均为 O(N)；狭长房间会达到最坏递归深度。
  • 单格房间：四次移动均失败，但当前格仍会被正确清扫。
  • 环形通道：访问集合阻止重复进入，不会无限绕圈。
  • 深链通道：若运行环境栈很小，可把递归 DFS 改写为显式栈状态机。
  • 替代方案：BFS 需要让机器人在队列中的任意两个位置间导航，物理状态管理更复杂；在受限移动接口下，DFS 的天然回退更直接。

JavaDFS
/**
 * // This is the robot's control interface.
 * interface Robot {
 *   boolean move();
 *   void turnLeft();
 *   void turnRight();
 *   void clean();
 * }
 */
class Solution {
    private final int[][] dirs = {
        {-1, 0}, {0, 1}, {1, 0}, {0, -1}
    };
    private final Set<String> visited = new HashSet<>();
    private Robot robot;

    public void cleanRoom(Robot robot) {
        this.robot = robot;
        dfs(0, 0, 0);
    }

    private void dfs(int row, int col, int direction) {
        visited.add(key(row, col));
        robot.clean();
        for (int i = 0; i < 4; i++) {
            int nextDirection = (direction + i) % 4;
            int nextRow = row + dirs[nextDirection][0];
            int nextCol = col + dirs[nextDirection][1];
            String nextKey = key(nextRow, nextCol);
            if (!visited.contains(nextKey) && robot.move()) {
                dfs(nextRow, nextCol, nextDirection);
                goBack();
            }
            robot.turnRight();
        }
    }

    private void goBack() {
        robot.turnRight();
        robot.turnRight();
        robot.move();
        robot.turnRight();
        robot.turnRight();
    }

    private String key(int row, int col) {
        return row + "," + col;
    }
}

var cleanRoom = function(robot) {
  const directions = [
    [-1, 0], [0, 1], [1, 0], [0, -1]
  ];
  const visited = new Set();
  const key = (row, col) => row + "," + col;

  const goBack = () => {
    robot.turnRight();
    robot.turnRight();
    robot.move();
    robot.turnRight();
    robot.turnRight();
  };

  const dfs = (row, col, direction) => {
    visited.add(key(row, col));
    robot.clean();
    for (let i = 0; i < 4; i += 1) {
      const nextDirection = (direction + i) % 4;
      const [dr, dc] = directions[nextDirection];
      const nextRow = row + dr;
      const nextCol = col + dc;
      if (!visited.has(key(nextRow, nextCol)) &&
          robot.move()) {
        dfs(nextRow, nextCol, nextDirection);
        goBack();
      }
      robot.turnRight();
    }
  };
  dfs(0, 0, 0);
};

/**
 * // This is the robot's control interface.
 * class Robot {
 * public:
 *   bool move();
 *   void turnLeft();
 *   void turnRight();
 *   void clean();
 * };
 */
class Solution {
    const int directions[4][2] = {
        {-1, 0}, {0, 1}, {1, 0}, {0, -1}
    };
    set<pair<int, int>> visited;

    void goBack(Robot& robot) {
        robot.turnRight();
        robot.turnRight();
        robot.move();
        robot.turnRight();
        robot.turnRight();
    }

    void dfs(Robot& robot, int row, int col,
             int direction) {
        visited.insert({row, col});
        robot.clean();
        for (int i = 0; i < 4; ++i) {
            int nextDirection = (direction + i) % 4;
            int nextRow = row + directions[nextDirection][0];
            int nextCol = col + directions[nextDirection][1];
            if (!visited.count({nextRow, nextCol}) &&
                robot.move()) {
                dfs(robot, nextRow, nextCol, nextDirection);
                goBack(robot);
            }
            robot.turnRight();
        }
    }

public:
    void cleanRoom(Robot& robot) {
        dfs(robot, 0, 0, 0);
    }
};

面试追问

  • 为什么虚拟坐标可信？它只要求相对位移一致，不要求知道真实原点。
  • 为什么不能只记录方向，不做物理回退？递归返回时机器人仍停在子树末端，父层后续动作会从错误位置开始。
  • 若初始朝向未知怎么办？把进入时朝向定义为虚拟北方即可；算法只依赖相对方向。
  • 能否用左转？可以，保持方向编号、循环转向和回退操作彼此一致即可。
  • 接口动作昂贵时如何优化？每个格子仍须清扫；可比较不同邻居顺序减少特定地图上的回退，但最坏渐进阶不变。

常见错误

  • 把评测夹具中的 room 当作提交代码可访问的参数。
  • 成功移动后递归，却忘记执行 goBack。
  • 回到父格了，但没有恢复递归前的朝向。
  • 方向数组与每轮旋转方向不一致，导致虚拟坐标漂移。
  • 在递归完成后才加入 visited，环形区域会反复进入。
  • 对已访问邻格仍调用 move()，随后不回退，破坏当前位置。
