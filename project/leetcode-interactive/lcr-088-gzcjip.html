使用最小花费爬楼梯

每次可爬一阶或两阶，踏上台阶需要支付对应花费；从第 0 或第 1 阶出发，求到达顶部的最低花费。

题意与约束

给定数组 cost，返回越过最后一级楼梯的最低花费。2 ≤ cost.length ≤ 1000，每项为非负整数。

示例

[10,15,20] → 15

分步交互

输入逗号分隔花费，逐项计算最低到达成本。

洞察、过程与边界

到达第 i 阶只能来自 i-1 或 i-2，因此 dp[i]=cost[i]+min(dp[i-1],dp[i-2])。首两阶可直接起步，答案为最后两阶最低值。数组长度为 2 时仍适用。

复杂度、替代与追问

时间 O(n)、滚动变量空间 O(1)。完整 DP 数组更便于恢复路线；若可一次爬 k 阶，转移为前 k 个状态最小值。常见错误：把顶部误计入 cost，或只允许从第 0 阶起步。

官方签名代码

// Java
class Solution { public int minCostClimbingStairs(int[] c){int a=0,b=0;for(int x:c){int t=x+Math.min(a,b);a=b;b=t;}return Math.min(a,b);} }
