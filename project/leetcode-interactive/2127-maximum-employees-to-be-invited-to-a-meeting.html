Maximum Employees to Be Invited to a Meeting

一张圆桌，每人一个必须相邻的人。你能让多少位员工同时满意？先理解座位限制，再展开下方题解探索结构。

数组输入圆桌相邻官方题目 ↗

01 / THE CHALLENGE

题目描述

公司有 n 位员工，编号为 0 到 n - 1。会议使用一张容量不限的圆桌。每位员工恰好喜欢另一位员工，只有当喜欢的人坐在自己左右相邻的位置之一时，他才愿意参加。

给定整数数组 favorite，其中 favorite[i] 是员工 i 喜欢的人的编号。选择部分员工并安排圆桌座位，使所有被邀请者都满足条件，返回最多能邀请的人数。喜欢关系有方向，不要求彼此喜欢；圆桌的首尾座位也相邻。

输入：favorite: integer[]　输出：integer（最大人数）。每个人只占一个座位。

约束

  • n == favorite.length
  • 2 ≤ n ≤ 10⁵
  • 0 ≤ favorite[i] ≤ n - 1
  • favorite[i] ≠ i

02 / EXAMPLES

官方示例

示例 1

favorite = [2,2,1,2]
输出：3

可以沿圆桌安排 0 → 2 → 1 → 0（此处箭头表示座位顺序）。员工 2 无法同时邻接 0、1、3，所以不能全部邀请；邀请 1、2、3 也可。

示例 2

favorite = [1,2,0]
输出：3

圆桌顺序为 0、1、2：0 的邻座为 2 和 1，1 的邻座为 0 和 2，2 的邻座为 1 和 0。三人都能参加。

示例 3

favorite = [3,0,1,4,1]
输出：4

圆桌顺序可取 0、3、4、1。员工 1 的两个邻座已被 0 和 4 占用，无法再让喜欢 1 的员工 2 入座。

题解 · 入链剥离与圆桌拼接

将喜欢关系画成 i → favorite[i]。答案是：
max（最长的长度 ≥ 3 的环，所有二元环及其两侧最长入链的总人数）。

核心洞察：每人只有一条出边

不断沿出边前进，必然进入某个环；每个弱连通分量由一个环和流入环的树组成。环上的员工必须一起被选中，因为被选中者喜欢的人也必须出现。

  • 长度 ≥ 3 的环：每个环节点都要邻接环内的前驱和后继，两个座位方向已用完。它只能独占圆桌，不能带入链，也不能与另一个环相加。
  • 长度为 2 的环：a ↔ b 共用同一条相邻关系，a、b 各有一侧空位。两端分别接一条最长入链，形成一段合法座位序列。多个这样的序列可以首尾拼接成一圈。
  • 为什么只取最长入链：一个端点只剩一个方向，分叉不能并排接入。沿某一条链，所有人都朝下一个人表达喜欢，因此只需取最长路径。

完整过程

  1. 统计每个节点的入度，初始化 depth[i] = 1，将入度为 0 的节点加入队列。
  2. 弹出 u，令 v = favorite[u]；更新 depth[v] = max(depth[v], depth[u] + 1)，再减少 v 的入度。若变为 0，将 v 入队。这里 depth 含端点自身。
  3. 剥离结束后，入度仍大于 0 的节点恰好属于环。沿出边逐一遍历环，用入度置 0 标记已经统计，避免重复计数。
  4. 若环长为 2，将 depth[a] + depth[b] 加入 pairs。两条链已经分别包含 a 与 b，不必再加 2。其他环更新 longest。
  5. 返回 max(longest, pairs)。例如 [1,0,0,2,1,6,5,6] 可把 3,2,0,1,4 与 5,6,7 拼成圆桌，邀请 8 人。

正确性证明

引理 1（剩余节点）。环内节点始终有一个来自环内前驱的入边，所以不会被剥离。非环节点处于有向入树中，叶子先入队，随后向根推进，因此全部被剥离。

引理 2（最长链）。u 出队时，它所有非环前驱都已处理；以 u 为终点的最长链，要么只有 u，要么接在某个前驱的最长链之后。用最大值更新恰好实现这一递推。环节点不出队，因此不会通过环内边污染 depth。

上界。任一合法非空邀请集合沿喜欢关系闭合，必然含环。若含长度 ≥ 3 的环，其每个节点的两侧都被占满，整个圆桌只能是这个环。否则集合由二元环及入链组成，每个环端点最多接一条链，所以人数不超过所有二元环最长链贡献之和。

可达性。任一长环可以按环顺序就座。每个二元环两边的最长链来自不相交的入树，可构成一个合法段；各段的外端员工已由段内邻座满足，跨段拼接不会破坏条件。两个上界都可实现，取较大值即最优解。

复杂度

时间 O(n)：每个节点最多入队一次，环遍历总计不超过 n 次；只有 n 条出边。空间 O(n)：入度、depth 和队列。不需要递归或显式反向邻接表。

边界与常见错误

  • n = 2 时必然互相喜欢，答案为 2。
  • 无入链时 depth = 1，二元环贡献为 2。
  • 多个长环只能取最大，不能求和。
  • 入链分叉取 max，不能把子树人数累加。
  • 环必须去重；二元环只能累计一次。
  • 长环不能附带 depth；JS 队列用头指针，避免反复 shift。

替代方案

可以用三色 DFS 寻环，再用反向图计算每个二元环端点的最长链；必须排除环边，且深链可能造成递归栈溢出。Tarjan / Kosaraju 能识别强连通分量，但本题每点一条出边，拓扑剥离更直接。枚举子集和座位排列只适用于很小的 n，不适合 10⁵ 的约束。

面试追问

  • 如何返回座位顺序？在 depth 更新时保存取得最大值的前驱；回溯恢复两侧链，一侧按朝向端点排列，另一侧反向排列，再拼接各二元环段。与最长环的序列择优返回。
  • 为什么互相喜欢是特殊情况？双方的需求由同一条无向座位边满足，释放了两个外侧连接位置。
  • 若有多张圆桌？原题只有一张桌。若桌数不限，长环可以各占一桌，二元环段也可成桌；此时各分量贡献可以累加。
  • 允许一个人喜欢多人时呢？出度为 1 的结构前提消失，不能直接沿用本题的环与入树分解。

JavaScript

/**
 * @param {number[]} favorite
 * @return {number}
 */
var maximumInvitations = function(favorite) {
    const n = favorite.length;
    const indegree = Array(n).fill(0), depth = Array(n).fill(1);
    for (const v of favorite) indegree[v]++;
    const queue = [];
    for (let i = 0; i < n; i++) if (indegree[i] === 0) queue.push(i);
    for (let head = 0; head < queue.length; head++) {
        const u = queue[head], v = favorite[u];
        depth[v] = Math.max(depth[v], depth[u] + 1);
        if (--indegree[v] === 0) queue.push(v);
    }
    let longest = 0, pairs = 0;
    for (let i = 0; i < n; i++) {
        if (indegree[i] === 0) continue;
        let u = i, size = 0;
        while (indegree[u] > 0) {
            indegree[u] = 0;
            size++;
            u = favorite[u];
        }
        if (size === 2) pairs += depth[i] + depth[favorite[i]];
        else longest = Math.max(longest, size);
    }
    return Math.max(longest, pairs);
};

import java.util.Arrays;

class Solution {
    public int maximumInvitations(int[] favorite) {
        int n = favorite.length;
        int[] indegree = new int[n], depth = new int[n];
        Arrays.fill(depth, 1);
        for (int v : favorite) indegree[v]++;
        int[] queue = new int[n];
        int head = 0, tail = 0;
        for (int i = 0; i < n; i++)
            if (indegree[i] == 0) queue[tail++] = i;
        while (head < tail) {
            int u = queue[head++], v = favorite[u];
            depth[v] = Math.max(depth[v], depth[u] + 1);
            if (--indegree[v] == 0) queue[tail++] = v;
        }
        int longest = 0, pairs = 0;
        for (int i = 0; i < n; i++) {
            if (indegree[i] == 0) continue;
            int u = i, size = 0;
            while (indegree[u] > 0) {
                indegree[u] = 0;
                size++;
                u = favorite[u];
            }
            if (size == 2) pairs += depth[i] + depth[favorite[i]];
            else longest = Math.max(longest, size);
        }
        return Math.max(longest, pairs);
    }
}

Python

from typing import List
from collections import deque

class Solution:
    def maximumInvitations(self, favorite: List[int]) -> int:
        n = len(favorite)
        indegree, depth = [0] * n, [1] * n
        for v in favorite:
            indegree[v] += 1
        queue = deque(i for i in range(n) if indegree[i] == 0)
        while queue:
            u = queue.popleft()
            v = favorite[u]
            depth[v] = max(depth[v], depth[u] + 1)
            indegree[v] -= 1
            if indegree[v] == 0:
                queue.append(v)
        longest = pairs = 0
        for i in range(n):
            if indegree[i] == 0:
                continue
            u, size = i, 0
            while indegree[u] > 0:
                indegree[u] = 0
                size += 1
                u = favorite[u]
            if size == 2:
                pairs += depth[i] + depth[favorite[i]]
            else:
                longest = max(longest, size)
        return max(longest, pairs)

C++

#include <algorithm>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    int maximumInvitations(vector<int>& favorite) {
        int n = favorite.size();
        vector<int> indegree(n, 0), depth(n, 1);
        for (int v : favorite) ++indegree[v];
        queue<int> q;
        for (int i = 0; i < n; ++i)
            if (indegree[i] == 0) q.push(i);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            int v = favorite[u];
            depth[v] = max(depth[v], depth[u] + 1);
            if (--indegree[v] == 0) q.push(v);
        }
        int longest = 0, pairs = 0;
        for (int i = 0; i < n; ++i) {
            if (indegree[i] == 0) continue;
            int u = i, size = 0;
            while (indegree[u] > 0) {
                indegree[u] = 0;
                ++size;
                u = favorite[u];
            }
            if (size == 2) pairs += depth[i] + depth[favorite[i]];
            else longest = max(longest, size);
        }
        return max(longest, pairs);
    }
};
