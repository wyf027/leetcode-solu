易混淆数 II

从“能旋转的数字”出发，不枚举 1 到 n，而是只生成可能成立的候选数。先通过交互观察旋转如何发生，再决定是否展开完整题解。

Confusing Number II付费题回溯生成数位旋转

题目

将一个十进制整数旋转 180°：每个数位按 0→0、1→1、6→9、8→8、9→6 映射，同时数位顺序反转。若某个正整数旋转后仍是合法数字，且结果与原数不同，则称它为“易混淆数”。

给定整数 n，返回闭区间 [1, n] 中易混淆数的数量。

函数签名： confusingNumberII(n: integer) → integer

约束

  • 1 ≤ n ≤ 10⁹
  • 只有包含 0、1、6、8、9 的数字，才可能在旋转后仍合法。
  • 生成多位数时不能以 0 开头。

官方示例（完整参数形式）

示例 1输入：n = 20输出：6易混淆数为 6、9、10、16、18、19。
示例 2输入：n = 100输出：19

注意：11、69、88、96 等数字旋转后与自身相同，不计入答案。

Solution

回溯生成全部合法候选

核心洞察

若一个数含有 2、3、4、5、7，它旋转后就不是合法数字。因此，答案一定来自只含五个可旋转数位的集合。长度最多 10 位时，搜索规模约为几何级数 5¹ + … + 5¹⁰，并且用 n 及时剪枝后远小于逐个检查 1…n。

DFS 同时维护原数 x、旋转数 r 与当前位权 base。向原数末尾追加 d 时：

nextX = x × 10 + d
nextR = rotate[d] × base + r
nextBase = base × 10

完整过程

从空前缀开始
首位只选 1、6、8、9，避免前导零。
扩展五种数位
后续可追加 0、1、6、8、9。
边生成边剪枝
若 x > (n-d)/10，则追加后会越过 n，停止该分支。
立即判定
每生成一个正数，若 x ≠ r 就把答案加一。

正确性证明

完备性：任一易混淆数的每一位必属于集合 {0,1,6,8,9}，且首位非零。DFS 从所有合法首位出发，并在每层追加全部五种合法数位，因此会生成每个不超过 n 的易混淆数。

唯一性：每个整数拥有唯一的十进制数位序列，对应搜索树中唯一的一条根到节点路径，因此不会重复生成。

判定正确：当追加数位 d 时，d 旋转后应出现在旋转结果左侧、权值为当前 base；旧旋转结果保持在低位，故更新式 rotate[d] × base + r 始终等于 x 的 180° 旋转。算法仅在两者不同时计数，恰好符合定义。

由完备性、唯一性和判定正确性，最终计数正好是 [1,n] 中易混淆数的数量。

边界与复杂度

  • n < 6 时答案为 0。
  • 0 可出现在内部或末尾，但不能作为首位。
  • 用除法形式判断是否还能追加，避免定长整数溢出。
  • 设 n 有 L 位。时间复杂度为 O(5^L)，空间复杂度为递归栈 O(L)；L 最多为 10。

替代方案与面试追问

  • 数位 DP：可按“是否贴上界、是否开始、旋转关系”等状态计数，理论上更一般，但状态与自旋转排除更复杂。
  • 逐数检查：单次 O(log n)，总体 O(n log n)，n=10⁹ 时不可接受。
  • 追问：若映射集合改变怎么办？把 digits 与 rotate 表参数化即可。
  • 追问：为何不必保存 visited？因为十进制表示唯一，搜索树天然无重复。

常见错误

  • 只检查数位是否合法，却忘记排除旋转后与原数相同的数。
  • 把映射后的数字按原顺序拼接，遗漏“整体旋转会反转数位顺序”。
  • 允许首位为 0，造成重复表示。
  • 先计算 x * 10 + d 再判断越界，在某些语言中可能溢出。
  • 误以为 6 与 9 自身无效；单个 6 旋转为 9，反而是易混淆数。

四语言完整实现

class Solution {
    private final int[] digits = {0, 1, 6, 8, 9};
    private final int[] rotated = {0, 1, 9, 8, 6};
    private int limit;

    public int confusingNumberII(int n) {
        limit = n;
        return dfs(0L, 0L, 1L);
    }

    private int dfs(long value, long rotation, long base) {
        int count = value != 0 && value != rotation ? 1 : 0;
        for (int i = 0; i < digits.length; i++) {
            int d = digits[i];
            if (value == 0 && d == 0) continue;
            if (value > (limit - d) / 10L) continue;
            count += dfs(value * 10 + d,
                         rotated[i] * base + rotation,
                         base * 10);
        }
        return count;
    }
}
var confusingNumberII = function(n) {
  const digits = [0, 1, 6, 8, 9];
  const rotated = [0, 1, 9, 8, 6];

  function dfs(value, rotation, base) {
    let count = value !== 0 && value !== rotation ? 1 : 0;
    for (let i = 0; i < digits.length; i++) {
      const d = digits[i];
      if (value === 0 && d === 0) continue;
      if (value > Math.floor((n - d) / 10)) continue;
      count += dfs(value * 10 + d,
                   rotated[i] * base + rotation,
                   base * 10);
    }
    return count;
  }

  return dfs(0, 0, 1);
};
