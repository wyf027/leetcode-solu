最小公共区域

Smallest Common Region：从一组“父区域直接包含若干子区域”的关系中，找出同时包含两个指定区域的最小区域。

#1257MEDIUM数组哈希表树最近公共祖先
Problem

题意

给定字符串列表 regions。每个子列表的第一个字符串是父区域，其后的字符串都是它直接包含的子区域。包含关系可以传递：若 A 包含 B、B 包含 C，则 A 也间接包含 C；每个区域也视为包含自身。

再给定不同的区域 region1 与 region2，返回同时包含二者且范围最小的区域。输入保证答案存在，且任一区域不会被两个不同区域直接包含，因此所有关系构成一棵有根树。

函数签名：findSmallestRegion(regions, region1, region2) → string
示例 1
输入：
regions = [
  ["Earth","North America","South America"],
  ["North America","United States","Canada"],
  ["United States","New York","Boston"],
  ["Canada","Ontario","Quebec"],
  ["South America","Brazil"]
]
region1 = "Quebec"
region2 = "New York"

输出："North America"

Quebec 与 New York 分属 Canada、United States 两支，首次汇合于 North America。

示例 2
输入：
regions = [
  ["Earth","North America","South America"],
  ["North America","United States","Canada"],
  ["United States","New York","Boston"],
  ["Canada","Ontario","Quebec"],
  ["South America","Brazil"]
]
region1 = "Canada"
region2 = "South America"

输出："Earth"

两条向上的祖先链直到根区域 Earth 才相交。

约束

  • 2 ≤ regions.length ≤ 10⁴
  • 2 ≤ regions[i].length ≤ 20
  • 1 ≤ regions[i][j].length, region1.length, region2.length ≤ 20
  • region1 != region2；区域名由英文字母组成。
  • 存在一个直接或间接包含所有其他区域的根区域；一个区域至多有一个直接父区域。

Solution

核心洞察：把区域关系看成树

为什么是最近公共祖先

每个非根区域至多有一个直接父区域，所以全部包含关系是一棵有根树。一个区域“包含”另一个区域，等价于前者是后者的祖先；要找的最小公共区域，正是两个节点的最近公共祖先（LCA）。

为什么只需要父指针

题目查询只有一对区域。建立 child → parent 映射后，无需构造完整邻接表或递归整棵树：记录 region1 到根的链，再从 region2 向上找到第一个已记录节点即可。

Walkthrough

完整过程

  1. 遍历每个 regions[i]，令首项为 parent，把其余每项映射到这个父区域。
  2. 从 region1 出发，依次加入自身、父区域、祖父区域……直到根，把整条链存入集合。
  3. 从 region2 出发逐级向上检查；遇到的第一个属于上述集合的区域就是答案。
  4. 示例 1 中，region1 链集合为 {Quebec, Canada, North America, Earth}；region2 依次检查 New York → United States → North America，故返回 North America。
Correctness

正确性证明

引理 1：集合 A 恰好包含 region1 及它的全部祖先。因为算法从 region1 开始反复沿唯一父指针上移，直到没有父节点，既不会漏过链上节点，也不会加入链外节点。
引理 2：从 region2 向上遇到的第一个 A 中节点，是二者的最近公共祖先。它属于 A，所以也是 region1 的祖先；它又在 region2 的祖先链上，因此是公共祖先。由于扫描按 region2 到根的顺序进行，在它之前不存在更靠近 region2 的公共祖先。
结论：最近公共祖先对应同时包含两个给定区域且范围最小的区域，因此算法返回值满足题意。题目保证公共祖先存在，所以扫描必然能够返回。
Analysis

复杂度、边界与替代方案

复杂度

  • 设输入中父子关系总数为 E，树高为 H。
  • 时间复杂度：O(E + H)。
  • 空间复杂度：O(E + H)，分别用于父映射和祖先集合。

边界情况

  • region1 是 region2 的祖先，或反之。
  • 两个区域只有根节点这个公共祖先。
  • 层级退化成很深的链；迭代写法不受递归栈限制。
  • region1 与 region2 同层但属于不同分支。

替代方案

DFS 路径：先构造父到子的邻接表，分别搜索根到两个目标的路径，再找路径最后一个相同节点。逻辑直观，但一次查询需要更多结构和遍历。

同步深度：先算两节点深度，把更深者抬到同一高度，再同步上移，空间可不建祖先集合，但仍需父映射。

倍增：当区域树固定且存在大量查询时，预处理二进制祖先表，将单次查询降至 O(log V)；对本题单次查询属于过度设计。

Interview Notes

面试追问与常见错误

可能追问

  • 如果一次构建后有十万次查询，如何改为倍增 LCA？
  • 若一个区域允许属于多个父区域，树变成 DAG 后怎么定义并查找“最小”？
  • 输入可能有环或多个根时，如何验证数据并报告错误？
  • 能否在不保存祖先集合的情况下完成？代价是什么？

常见错误

  • 祖先集合没有加入 region1 自身，导致“一个目标是另一个目标祖先”的情况出错。
  • 只检查直接父区域，忽略包含关系的传递性。
  • 构建成 parent → child 后仍试图直接向上走。
  • 在 region2 链上找到所有公共祖先后返回根，而不是返回第一个交点。
Implementations

四种语言完整代码

JavaHashMap + HashSet
class Solution {
    public String findSmallestRegion(
            List<List<String>> regions,
            String region1,
            String region2) {
        Map<String, String> parent = new HashMap<>();

        for (List<String> group : regions) {
            String root = group.get(0);
            for (int i = 1; i < group.size(); i++) {
                parent.put(group.get(i), root);
            }
        }

        Set<String> ancestors = new HashSet<>();
        String current = region1;
        while (current != null) {
            ancestors.add(current);
            current = parent.get(current);
        }

        current = region2;
        while (!ancestors.contains(current)) {
            current = parent.get(current);
        }
        return current;
    }
}

var findSmallestRegion = function(regions, region1, region2) {
    const parent = new Map();

    for (const group of regions) {
        const root = group[0];
        for (let i = 1; i < group.length; i++) {
            parent.set(group[i], root);
        }
    }

    const ancestors = new Set();
    let current = region1;
    while (current !== undefined) {
        ancestors.add(current);
        current = parent.get(current);
    }

    current = region2;
    while (!ancestors.has(current)) {
        current = parent.get(current);
    }
    return current;
};
Pythondict + set
from typing import List


class Solution:
    def findSmallestRegion(
        self,
        regions: List[List[str]],
        region1: str,
        region2: str
    ) -> str:
        parent = {}

        for group in regions:
            root = group[0]
            for child in group[1:]:
                parent[child] = root

        ancestors = set()
        current = region1
        while current is not None:
            ancestors.add(current)
            current = parent.get(current)

        current = region2
        while current not in ancestors:
            current = parent.get(current)

        return current
C++unordered_map + unordered_set
class Solution {
public:
    string findSmallestRegion(
        vector<vector<string>>& regions,
        string region1,
        string region2
    ) {
        unordered_map<string, string> parent;

        for (const auto& group : regions) {
            const string& root = group[0];
            for (int i = 1; i < group.size(); ++i) {
                parent[group[i]] = root;
            }
        }

        unordered_set<string> ancestors;
        string current = region1;
        while (true) {
            ancestors.insert(current);
            if (!parent.count(current)) break;
            current = parent[current];
        }

        current = region2;
        while (!ancestors.count(current)) {
            current = parent[current];
        }
        return current;
    }
};
