01 / 任务与数据契约

给定表 Transactions，返回每笔交易完成后所属账户的余额。结果列为 account_id, day, balance，先按账户编号升序，再按日期升序排列。

列类型含义
account_idint账户编号
daydate交易日期
typeENUMDeposit（存入）、Withdraw（取出）
amountint交易金额
  • 联合主键是 (account_id, day)，同一账户同一天最多一笔交易。
  • 各账户在交易开始前余额均为 0，题目保证每笔交易后余额非负。
  • 交易类型只有 Deposit 和 Withdraw。
  • 每笔交易对应一条结果，无交易日期不需要补行。
  • 可用题面没有给出行数、账户编号、金额的具体数值上下界，不额外编造限制。

本地官方元数据提供题名、表结构及完整示例输入，付费题面字段为空。规则根据公开题面镜像简述补足；官方入口需要订阅查看正文。

04 / 从交易到账户窗口

核心洞察：余额是本账户从第一笔到当前交易的有符号金额之和。存入为正，取出为负；累计值需要保留在每条原始记录上。

  1. 使用 CASE 将交易变成正负金额。
  2. PARTITION BY account_id 隔离各账户。
  3. 在每个账户内按 day 排序，以第一行到当前行为窗口进行 SUM。
  4. 最后显式 ORDER BY account_id, day。窗口内排序不能替代结果排序。

05 / 正确性与取舍
正确性证明
对一个账户的交易数量归纳：处理零笔时，累计值为 0，等于初始余额。假设前 k−1 笔的累计和正确，第 k 笔存入时加上金额、取出时减去金额，恰好得到交易后的余额。窗口包含且仅包含该账户前 k 笔交易，因此每行的累计和都正确。账户分区防止相互污染，最终排序满足输出要求。
完整过程：官方示例
账户 1：0 + 2000 = 2000；2000 − 1000 = 1000；1000 + 3000 = 4000。进入账户 2 时重新从 0 起算：0 + 7000 = 7000；7000 − 7000 = 0。每个等式对应一行结果。
边界
空表返回空表；单笔存入即可产生余额；取出恰好清空账户时必须保留 0。物理输入顺序不影响查询语义。不同账户可以在同一天交易；同一账户同日多笔交易违反本题联合主键。
复杂度
设 n 为交易数。常见计划先排序 O(n log n)，再做线性窗口累计 O(n)；排序及结果物化通常占 O(n) 空间，具体取决于执行计划与索引。四种本地实现复制并排序输入，时间 O(n log n)，包含副本与输出的空间 O(n)。已排序的流只需 O(1) 累计状态，不包含输出存储。
替代方案
相关子查询可以对每行统计同账户且日期不晚于该行的交易金额，最坏需 O(n²) 比较；自连接再分组也可以，但可能产生大量中间结果。普通 GROUP BY account_id 只留下账户最终余额，无法保留每笔交易对应的记录。
常见错误
  • 取款漏加负号，或遗漏 PARTITION BY 导致跨账户累加。
  • 把整个分区作为窗口，每一行都显示最终余额。
  • 仅依赖窗口排序，未显式排列最终结果。
  • 误认为必须给无交易日期补行。
  • 误解 ROWS 与 RANGE：本题同账户日期唯一，相同排序下默认 RANGE 与这里的 ROWS 结果一致；显式指定前缀窗口更清晰。
面试追问
  • 一天多笔交易怎么办？增加稳定交易序号，与日期一起用于窗口及最终排序。
  • 如何显示无交易日期的余额？引入日历序列，计算或延续截至每一天的余额。
  • 索引如何帮助？(account_id, day) 与窗口顺序匹配，但是否免排序仍需执行计划确认。
  • 存在开户余额怎么办？将每个账户的开户余额加到累计净额上。

SQL · MySQL 8+ 可提交查询
SELECT account_id, day,
       SUM(CASE WHEN type = 'Deposit' THEN amount ELSE -amount END)
       OVER (PARTITION BY account_id ORDER BY day
             ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS balance
FROM Transactions
ORDER BY account_id, day;


Java · 本地语义参考（Java 17+）
import java.util.*;

public class Main {
    record Transaction(int accountId, String day, String type, long amount) {}
    record Balance(int accountId, String day, long balance) {}

    static List<Balance> accountBalance(List<Transaction> transactions) {
        var rows = new ArrayList<>(transactions);
        rows.sort(Comparator.comparingInt(Transaction::accountId)
                            .thenComparing(Transaction::day));
        var result = new ArrayList<Balance>();
        Integer previous = null;
        long balance = 0;
        for (var row : rows) {
            if (previous == null || previous.intValue() != row.accountId()) {
                previous = row.accountId();
                balance = 0;
            }
            balance += row.type().equals("Deposit") ? row.amount() : -row.amount();
            result.add(new Balance(row.accountId(), row.day(), balance));
        }
        return result;
    }

    public static void main(String[] args) {
        var transactions = List.of(
            new Transaction(1, "2021-11-07", "Deposit", 2000),
            new Transaction(1, "2021-11-09", "Withdraw", 1000),
            new Transaction(1, "2021-11-11", "Deposit", 3000),
            new Transaction(2, "2021-12-07", "Deposit", 7000),
            new Transaction(2, "2021-12-12", "Withdraw", 7000));
        accountBalance(transactions).forEach(System.out::println);
    }
}

// 每行：[account_id, day, type, amount]。
function accountBalance(transactions) {
  const rows = [...transactions].sort((a, b) =>
    a[0] - b[0] || a[1].localeCompare(b[1]));
  let previous = null, balance = 0n;
  return rows.map(([accountId, day, type, amount]) => {
    if (accountId !== previous) {
      previous = accountId;
      balance = 0n;
    }
    balance += type === 'Deposit' ? BigInt(amount) : -BigInt(amount);
    return [accountId, day, balance];
  });
}

def account_balance(transactions):
    rows = sorted(transactions, key=lambda row: (row[0], row[1]))
    result = []
    previous = None
    balance = 0
    for account_id, day, kind, amount in rows:
        if account_id != previous:
            previous = account_id
            balance = 0
        balance += amount if kind == "Deposit" else -amount
        result.append((account_id, day, balance))
    return result

#include <algorithm>
#include <iostream>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

struct Transaction { int accountId; string day, type; long long amount; };
struct Balance { int accountId; string day; long long balance; };

vector<Balance> accountBalance(vector<Transaction> rows) {
    sort(rows.begin(), rows.end(), [](const auto& a, const auto& b) {
        return tie(a.accountId, a.day) < tie(b.accountId, b.day);
    });
    vector<Balance> result;
    int previous = 0;
    bool first = true;
    long long balance = 0;
    for (const auto& row : rows) {
        if (first || previous != row.accountId) {
            first = false;
            previous = row.accountId;
            balance = 0;
        }
        balance += row.type == "Deposit" ? row.amount : -row.amount;
        result.push_back({row.accountId, row.day, balance});
    }
    return result;
}

int main() {
    vector<Transaction> transactions = {
        {1, "2021-11-07", "Deposit", 2000},
        {1, "2021-11-09", "Withdraw", 1000},
        {1, "2021-11-11", "Deposit", 3000},
        {2, "2021-12-07", "Deposit", 7000},
        {2, "2021-12-12", "Withdraw", 7000}
    };
    for (const auto& row : accountBalance(transactions))
        cout << row.accountId << ' ' << row.day << ' ' << row.balance << '\n';
}
