两个盒子中球的颜色数相同的概率

把一组多彩小球随机打乱，平均放进两个不同的盒子。我们关心的不是每种颜色各有多少，而是两个盒子最终拥有的颜色种类数是否相同。

01 · Problem

准确理解随机过程

盒子有先后之分；同色球彼此不可区分，但随机排列中的位置是等概率的。

共有 2n 个球，分属 k 种颜色。整数数组 balls 长度为 k，其中 balls[i] 表示颜色 i 的球数。将全部球均匀随机打乱，把前 n 个放入第一个盒子，其余 n 个放入第二个盒子。

返回两个盒子中不同颜色的数量相同的概率。两个盒子不同，因此把颜色 a 放入盒 1、颜色 b 放入盒 2，与反过来放是两种不同结果。答案与真实值误差不超过 10−5 即可。

别混淆：要求相同的是“颜色种类数”，不是每一种颜色的球数，也不是两个盒子的颜色集合完全相同。
1
输入：balls = [1,1]
输出：1.00000

两种等分方式都会让每个盒子恰有一种颜色，因此概率为 2 / 2。

2
输入：balls = [2,1,1]
输出：0.66667

球序列为 [1,1,2,3]。12 种等概率排列中有 8 种满足条件，概率为 8 / 12。

3
输入：balls = [1,2,1,2]
输出：0.60000

180 种等概率排列中有 108 种满足条件，概率为 108 / 180。

颜色数1 ≤ balls.length ≤ 8
单色球数1 ≤ balls[i] ≤ 6
总球数sum(balls) 为偶数

04 · Full solution

组合计数 + 回溯枚举

把“随机排列”压缩成“每种颜色进入盒 A 的数量”，并保留每种分配的组合权重。

核心洞察

设颜色 i 一共有 balls[i] 个球，选择其中 xᵢ 个进入盒 A，则其余进入盒 B。只枚举满足 Σxᵢ = n 的向量。

weight(x) = ∏ C(balls[i], xᵢ)

这个权重表示该数量分配对应多少种“盒 A 的位置选择”。所有合法权重之和等于 C(2n,n)。

颜色数怎么更新

  • 若 xᵢ > 0，颜色 i 出现在盒 A。
  • 若 xᵢ < balls[i]，颜色 i 出现在盒 B。
  • 枚举结束时，两边颜色计数相同，便把当前权重计入 favorable。
answer = favorable / total

完整过程

  1. 预计算阶乘或组合数。
  2. 深搜每种颜色，尝试把 0..balls[i] 个放入盒 A。
  3. 若盒 A 已超过 n 个球，立即剪枝。
  4. 处理完全部颜色且盒 A 恰有 n 个球时，累计 total；颜色数相等时再累计 favorable。
  5. 返回二者比值。

边界处理

  • 某颜色全部进 A：只增加 A 的颜色数。
  • 某颜色全部进 B：只增加 B 的颜色数。
  • 两边都有该颜色：两边颜色数都增加。
  • 两盒不同，无需除以 2。
  • 最大总球数 48，使用浮点数保存计数足以稳定求比值。

正确性证明

枚举完备且不重复

任意等分结果都唯一决定向量 (x₀,…,xₖ₋₁)，其中 xᵢ 是颜色 i 在盒 A 中的数量，且总和为 n。回溯对每个分量枚举完整取值区间，因此每个向量恰被访问一次。

权重准确

对于固定向量，颜色 i 有 C(balls[i],xᵢ) 种方式选出进入盒 A 的球。不同颜色的选择互相独立，乘法原理给出总权重 ∏C(balls[i],xᵢ)。

成功条件准确

当且仅当 xᵢ>0 时盒 A 含颜色 i；当且仅当 xᵢ<balls[i] 时盒 B 含颜色 i。因此深搜维护的两个颜色计数正是最终种类数。

概率准确

total 汇总全部等分选择，favorable 只汇总颜色数相同的选择。所有具体选择等概率，所以 favorable / total 就是所求概率。

复杂度

设颜色数为 k。每种颜色有 balls[i]+1 个选择，时间复杂度为 O(∏(balls[i]+1))，题目范围内最多 7⁸ 个搜索节点，并会被容量剪枝减少。递归栈空间为 O(k)；阶乘表为 O(Σballs)。

替代方案

可做动态规划：状态包含已处理颜色、盒 A 球数、两盒颜色数之差，值为累计权重。它避免重复子状态，思路更体系化，但状态和转移较繁琐；在 k ≤ 8 时，回溯更直接。

常见错误

  • 把每个数量向量当成等概率，遗漏组合权重。
  • 误判为两盒颜色集合必须相同。
  • 把两个盒子当成无序后额外除以 2。
  • 只计算 favorable，却用错误的分母。
  • 用整数除法返回 0 或 1。

面试追问

  • 如何把回溯改成记忆化或 DP？
  • 为什么组合选择与原题随机排列的概率等价？
  • 若两个盒子容量不等，状态如何调整？
  • 若要求颜色数相差不超过 d，成功条件如何变化？

四语言完整代码

JavaLeetCode 提交格式
class Solution {
    private int[] balls;
    private double[] factorial;
    private double favorable;
    private double total;
    private int half;

    public double getProbability(int[] balls) {
        this.balls = balls;
        int sum = 0;
        for (int count : balls) sum += count;
        half = sum / 2;

        factorial = new double[sum + 1];
        factorial[0] = 1.0;
        for (int i = 1; i <= sum; i++) {
            factorial[i] = factorial[i - 1] * i;
        }

        dfs(0, 0, 0, 0, 1.0);
        return favorable / total;
    }

    private void dfs(int color, int usedA, int colorsA,
                     int colorsB, double ways) {
        if (usedA > half) return;
        if (color == balls.length) {
            if (usedA == half) {
                total += ways;
                if (colorsA == colorsB) favorable += ways;
            }
            return;
        }

        int count = balls[color];
        for (int take = 0; take <= count; take++) {
            dfs(color + 1,
                usedA + take,
                colorsA + (take > 0 ? 1 : 0),
                colorsB + (take < count ? 1 : 0),
                ways * combination(count, take));
        }
    }

    private double combination(int n, int r) {
        return factorial[n] / (factorial[r] * factorial[n - r]);
    }
}

/**
 * @param {number[]} balls
 * @return {number}
 */
var getProbability = function(balls) {
    const sum = balls.reduce((acc, value) => acc + value, 0);
    const half = sum / 2;
    const factorial = new Array(sum + 1).fill(1);
    for (let i = 1; i <= sum; i++) {
        factorial[i] = factorial[i - 1] * i;
    }

    const combination = (n, r) =>
        factorial[n] / (factorial[r] * factorial[n - r]);

    let favorable = 0;
    let total = 0;

    const dfs = (color, usedA, colorsA, colorsB, ways) => {
        if (usedA > half) return;
        if (color === balls.length) {
            if (usedA === half) {
                total += ways;
                if (colorsA === colorsB) favorable += ways;
            }
            return;
        }

        const count = balls[color];
        for (let take = 0; take <= count; take++) {
            dfs(
                color + 1,
                usedA + take,
                colorsA + (take > 0 ? 1 : 0),
                colorsB + (take < count ? 1 : 0),
                ways * combination(count, take)
            );
        }
    };

    dfs(0, 0, 0, 0, 1);
    return favorable / total;
};

from math import comb

class Solution:
    def getProbability(self, balls: List[int]) -> float:
        half = sum(balls) // 2
        favorable = 0
        total = 0

        def dfs(color: int, used_a: int, colors_a: int,

            nonlocal favorable, total
            if used_a > half:
                return
            if color == len(balls):
                if used_a == half:
                    total += ways
                    if colors_a == colors_b:
                        favorable += ways
                return

            for take in range(count + 1):
                dfs(
                    color + 1,
                    used_a + take,
                    colors_a + (take > 0),
                    colors_b + (take < count),
                    ways * comb(count, take),
                )

        dfs(0, 0, 0, 0, 1)
        return favorable / total
C++LeetCode 提交格式
class Solution {
    vector<int> balls;
    vector<long double> factorial;
    long double favorable = 0;
    long double total = 0;
    int half = 0;

    long double combination(int n, int r) {
        return factorial[n] / (factorial[r] * factorial[n - r]);
    }

    void dfs(int color, int usedA, int colorsA,
             int colorsB, long double ways) {
        if (usedA > half) return;
        if (color == static_cast<int>(balls.size())) {
            if (usedA == half) {
                total += ways;
                if (colorsA == colorsB) favorable += ways;
            }
            return;
        }

        int count = balls[color];
        for (int take = 0; take <= count; take++) {
            dfs(color + 1,
                usedA + take,
                colorsA + (take > 0),
                colorsB + (take < count),
                ways * combination(count, take));
        }
    }

public:
    double getProbability(vector<int>& input) {
        balls = input;
        int sum = accumulate(balls.begin(), balls.end(), 0);
        half = sum / 2;
        factorial.assign(sum + 1, 1);
        for (int i = 1; i <= sum; i++) {
            factorial[i] = factorial[i - 1] * i;
        }

        dfs(0, 0, 0, 0, 1);
        return static_cast<double>(favorable / total);
    }
};

快速自检问答

为什么不直接统计所有随机排列？

同色球使排列数量巨大且存在重复结构。数量向量把同类结果合并，再用组合数恢复它们的概率权重。

为什么 total 不直接写成 C(2n,n)？

当然可以。代码同时累加 total，是为了让分子和分母沿同一枚举口径产生，更容易检查；将分母替换为 C(2n,n) 也等价。

浮点组合数会不会溢出？

本题最多 48 个球，阶乘与组合计数远小于双精度浮点数的上限；最终又只取比值，精度满足题目要求。
