删除链表的倒数第 N 个结点

只扫描一次链表：让快指针先走 N 步，再让快慢指针同步前进。快指针到尾部时，慢指针正好停在待删节点的前驱。

快指针
先领先 N 个节点
慢指针
最后停在前驱
哑节点
统一删除头结点

    ■ 快指针■ 慢指针■ 删除目标

    KEY INVARIANT

    距离差恒为 N

    1. 1. 建立 dummy → head，使头结点也有前驱。
    2. 2. fast 从 dummy 前进 N+1 步。
    3. 3. fast 与 slow 同步走到 fast 为 null。
    4. 4. 删除 slow.next。

    题目保证 n 合法；dummy 消除了“删除第一个节点”的特判。

    DERIVATION

    为什么慢指针停在前驱？

    快指针比慢指针始终多走 N+1 步（包含 dummy）。当快指针越过最后一个节点到达 null，慢指针与末尾相差 N 个真实节点，因此 slow.next 正是倒数第 N 个节点。

    class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0, head), fast = dummy, slow = dummy;
        for (int i = 0; i <= n; i++) fast = fast.next;
        while (fast != null) { fast = fast.next; slow = slow.next; }
        slow.next = slow.next.next;
        return dummy.next;
    }
}
