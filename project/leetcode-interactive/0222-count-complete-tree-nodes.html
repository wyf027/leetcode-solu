Count Complete Tree Nodes

比较当前根的左右子树最左链高度：高度相同，左子树必满；否则右子树必满。满的那半边可用 2ʰ − 1 一次计数，只递归进入另一半。

🌲 完全二叉树 · 子树高度判满

题意

给定一棵完全二叉树的根节点 root，返回树中节点数量。除最后一层可能未满外，每层均满；最后一层节点从左向右连续排列。要求设计优于 O(n) 的算法。

官方样例 1root = [1, 2, 3, 4, 5, 6]

期望输出：6。

官方样例 2root = []

期望输出：0。

官方样例 3root = [1]

期望输出：1。

约束：节点数范围 [0, 5 × 10⁴]，0 ≤ Node.val ≤ 5 × 10⁴，树保证完全。

满子树跳跃计数器

准备：从根 1 比较最左与最右链高度。

测试与验证

树以层序数组完整显示：root = [...]；字符串输入的空格会以 ␠ 展示，本题仅使用整数和 null。

页面验证

Prettier、HTML Validate、内联 JavaScript 语法：通过。主流程负责真实 Chrome、390px、键盘、控制台与横向溢出复核。

算法对拍

50,000 棵随机合法完全树：高度判满计数与独立 BFS 节点数逐棵一致；四语言代码都使用同一 O(log²n) 思路。

题解默认折叠。

题解：比较左右子树的左侧高度

核心洞察

对当前根，比较 root.left 与 root.right 的最左链高度。相等时，左子树一定满；不等时，右子树一定满。这是完全性带来的结构保证，因而可以跳过满的半边。

完整过程

  1. 空节点返回 0。
  2. 计算左右子树的最左高度 lh、rh。
  3. lh == rh：左子树满，有 2ˡʰ − 1 个节点，递归右边。
  4. 否则右子树满，有 2ʳʰ − 1 个节点，递归左边。

边界

空树为 0；单节点左右子树高度均 0，左边“满树”有 0 个节点；最后一层只可能缺右侧节点，这是判定得以成立的前提。

复杂度与替代方案

每层重新走高度 O(log n)，递归深度 O(log n)，总时间 O(log²n)，递归栈 O(log n)。BFS/DFS 是 O(n)，能计数但不满足“少于 O(n)”的追问。

面试追问

也可二分最后一层的最后存在节点：先算树高，再用二进制路径测试节点存在性，仍为 O(log²n)。若树不保证完全，左右子树的这项结构推论不成立。

常见错误

把整棵树的最左、最右路径等高误判为满树；把“边数高度”和“节点数高度”混用；在普通二叉树上使用这个优化；Java/JS 用不安全的位移计算很高的 2ʰ。

class Solution {
    public int countNodes(TreeNode root) {
        if (root == null) return 0;
        int left = height(root.left), right = height(root.right);
        if (left == right) return (1 << left) + countNodes(root.right);
        return (1 << right) + countNodes(root.left);
    }
    private int heightLeft(TreeNode node) { int h = 0; while (node != null) { h++; node = node.left; } return h; }
}
var countNodes = function(root) {
  const leftHeight = node => { let h = 0; while (node) { h++; node = node.left; } return h; };
  if (!root) return 0;
  const left = leftHeight(root.left), right = leftHeight(root.right);
  return left === right ? 2 ** left + countNodes(root.right) : 2 ** right + countNodes(root.left);
};
