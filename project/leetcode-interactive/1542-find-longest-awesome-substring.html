题目

给定一个只含数字的字符串 s。如果它的某个非空连续子字符串经过任意次字符交换后能成为回文串，就称它为“超赞子字符串”。返回最长超赞子字符串的长度。

完整题解

包含推导、证明、复杂度、四种语言代码和面试追问。

核心洞察：只关心奇偶，不关心次数

一组字符能重排成回文，当且仅当出现奇数次的字符种类不超过一个。数字只有 10 种，因此用 10 位整数表示计数奇偶性：第 d 位为 1，表示数字 d 在当前前缀中出现了奇数次。

prefixMask[i + 1] = prefixMask[i] XOR (1 << digit)

区间 [l, r] 的奇偶掩码为 prefixMask[l] XOR prefixMask[r + 1]。它若为 0，所有计数都是偶数；若恰好只有一个二进制位为 1，则只有一种数字出现奇数次。这两种区间都“超赞”。

完整过程

  1. 定义前缀位置 0 的掩码为 0，并记录 first[0] = 0。
  2. 从左到右读字符，在当前掩码中翻转对应数字的那一位。
  3. 若当前掩码以前出现过，当前位置与其最早位置之间的区间掩码为 0。
  4. 依次翻转当前掩码的 10 个位；若这个邻居掩码以前出现过，则对应区间恰有一种数字计数为奇数。
  5. 更新答案。当前掩码若首次出现，只记录这次位置；保留最早位置才能产生最长区间。

正确性证明

引理 1：子字符串可重排为回文，当且仅当其奇数频次字符不超过一种。回文的成对位置必须相同，至多只有中心位置可容纳一个未配对字符；反过来，将所有偶数频次字符成对放置，再把唯一的奇数频次字符放在中心即可。

引理 2：区间 [l, r] 的频次奇偶掩码等于两个端点前缀掩码的异或。因为区间外、在两个前缀中都出现的每次计数会模 2 抵消。

引理 3：算法枚举了以每个位置结尾的所有可行奇偶形态。根据引理 1，可行区间掩码只能是 0 或某个 1 << d；这分别对应相同前缀掩码和与当前掩码相差一位的 10 个前缀掩码，算法全部检查。

定理：算法返回最长超赞子字符串长度。由引理 2、3，每个可行区间都会被考虑；对每个目标掩码保留最早前缀位置，使同一右端点下得到的长度最大。算法取所有候选最大值，因此答案正确。

复杂度

每个字符检查 1 个相同状态和 10 个单比特邻居，时间复杂度 O(10n) = O(n)。掩码一共只有 2^10 = 1024 种，额外空间为 O(2^10)，可视为常数。

边界情况

  • 长度为 1：任一字符自身就是回文，答案为 1。
  • 全部相同：整个字符串总能重排为回文。
  • 所有数字都不同：任何长度大于 1 的区间会有多个奇数频次，答案为 1。
  • 偶数长度回文形态对应区间掩码 0；奇数长度形态对应恰好一个置位。
  • 必须预置 first[0] = 0，否则会漏掉从字符串开头开始的答案。

Java

import java.util.Arrays;

class Solution {
    public int longestAwesome(String s) {
        final int STATES = 1 << 10;
        int[] first = new int[STATES];
        Arrays.fill(first, Integer.MAX_VALUE);
        first[0] = 0;

        int mask = 0;
        int answer = 0;
        for (int i = 0; i < s.length(); i++) {
            int digit = s.charAt(i) - '0';
            mask ^= 1 << digit;
            int prefix = i + 1;

            if (first[mask] != Integer.MAX_VALUE) {
                answer = Math.max(answer, prefix - first[mask]);
            }
            for (int bit = 0; bit < 10; bit++) {
                int neighbor = mask ^ (1 << bit);
                if (first[neighbor] != Integer.MAX_VALUE) {
                    answer = Math.max(answer, prefix - first[neighbor]);
                }
            }
            if (first[mask] == Integer.MAX_VALUE) {
                first[mask] = prefix;
            }
        }
        return answer;
    }
}

    }
    return answer;
};

替代方案

可以用哈希表保存出现过的掩码及最早位置，逻辑相同；但状态空间仅 1024，用定长数组更简单且常数更小。枚举所有子字符串并统计 10 个数字需要 O(n^2)；即使滑动窗口也不适用，因为“至多一个奇数频次”不具备窗口扩大后单调失效的性质。

常见错误

  • 只检查相同掩码，漏掉允许一个奇数频次的奇数长度答案。
  • 把字符计数直接存入状态，忽略只需要模 2。
  • 覆盖某个掩码的最早位置，导致候选区间变短。
  • 把字符 '7' 的编码值当作数字 7，没有减去 '0'。
  • 位置定义混淆：这里 first 存的是前缀长度，不是字符下标。

面试追问

  1. 如果字符集有 26 个小写字母？ 用 26 位整数和哈希表；每步检查 26 个邻居，时间 O(26n)。
  2. 为什么不能只统计全局频次？ 题目要求连续子字符串，必须通过前缀差分得到每个区间。
  3. 如何恢复具体子字符串？ 更新答案时同步保存产生最大长度的左右端点。
  4. 若要求恰好两个奇数频次？ 每步需枚举所有二位翻转，共 C(A,2) 个邻居。
