MEDIUM#2408 · Design SQL

设计 SQL

为表格实现一套小型数据接口。插入、删除、定位与导出之间，哪些状态应该改变，哪些必须保留？

官方题目 ↗ · 离线学习页 · 题解默认折叠
01 / PROBLEM

题意与接口

给定 n 个不同的表名 names，以及整数数组 columns 中对应的列数。实现 SQL 类，管理这些表中的字符串行。每张表首个成功插入的行 ID 为 1，之后每个成功插入的行 ID 是该表上一次成功插入 ID 加 1，即使上一行已被删除。删除不改变未来 ID，也不改变其他行的 ID。列编号从 1 开始。

SQL 完整接口与无效输入行为
接口行为
SQL(String[] names, int[] columns)创建所有表；各语言集合类型见题解。
bool ins(String name, String[] row)插入成功返回 true；表不存在或列数不符返回 false，不做插入。
void rmv(String name, int rowId)删除整行；表或行不存在时不做操作。
String sel(String name, int rowId, int columnId)查询单元格；表、行、列任一无效则返回字符串 <null>。
String[] exp(String name)导出存活行，每行由 ID 与所有列用逗号连接；无效表返回 []。

元数据校正：中文 rmv 签名多写了 columnId，示例 2 输入输出重复了示例 1。此页采用英文题面、官方代码签名及 exampleTestcases 中一致的内容。题面未单独限定导出顺序，此页按 ID 递增输出。

完整约束

  • n == names.length == columns.length；1 ≤ n ≤ 10⁴。
  • 1 ≤ names[i].length、row[i].length、name.length ≤ 10。
  • names[i]、row[i]、name 仅含小写英文字母；names[i] 互不相同。
  • 1 ≤ columns[i] ≤ 10；1 ≤ row.length ≤ 10。
  • ins 与 rmv 最多调用 2000 次；sel 最多调用 10⁴ 次；exp 最多调用 500 次。

进阶：大量删除使表稀疏时，你会选用什么方法？考虑空间和性能。

04 / SOLUTION
先想一想，再打开题解
删除之后，从哪里确定新行 ID？如何区分列不存在和整行已删除？
固定列数 + 独立计数 + 存活行映射
核心洞察
ID 记录的是成功插入的历史，而非当前行数。每张表保存列数、nextId 和 rowId → row 的映射。删除只移除映射项，不回退 nextId。本题是类设计题，四种语言均有官方提交签名，无需执行 SQL 语句。
完整过程
  1. 构造时为每张表记录列数，nextId 设为 1，行映射为空。
  2. 插入先校验表名与行宽，无效返回 false；有效则复制行保存到 nextId，计数加一，返回 true。复制避免调用方后续修改原数组影响已存数据。
  3. 删除只在表存在时移除指定行，不影响计数。无效表或行不报错。
  4. 查询先检查表及 1 ≤ columnId ≤ 列数，再按 ID 查行；合法则返回 row[columnId−1]，否则返回 "<null>"。
  5. 导出收集存活 ID，进行数值排序，再把每个 ID 与该行所有列用逗号连接。
示例 2 的计数变化：插入行 1 后 nextId=2；删除行 1 后仍是 2；列数不符的插入失败后仍是 2；随后成功插入行 2，nextId=3。
正确性
不变量：每张表的 nextId 等于其成功插入次数加一；行映射恰好包含尚未删除的成功插入行，每行列数正确。
初始空表满足不变量。合法插入使用尚未分配的 ID，保存合法行并自增，保持唯一且递增；失败插入不改变状态。删除仅移除指定键，剩余 ID 与历史计数保持不变。查询在合法行和列处返回存储值，无效时返回约定字符串。导出遍历全部且仅有的存活行，每行输出一次并带正确 ID。因此各方法都满足要求。
边界与常见错误
  • 不能用当前 rows.size+1 产生 ID，也不能删行后移动、重新编号。
  • 失败插入不能消耗 ID；不同表必须独立计数。
  • 列从 1 开始，0、负数或超过列数均无效；题面未给 rowId、columnId 数值范围，直接检查存在性与列边界即可。
  • 返回字符串 "<null>"，不是语言的 null / None。void 对应的 null 仅是示例格式。
  • 无效表与空表导出都返回 []；重复删除不产生影响。
  • 导出不要遗漏 ID，JavaScript 排序需传数值比较函数。
  • 题目值只有小写字母，可以直接逗号拼接；真实 CSV 若含逗号、引号、换行则要正确转义。
复杂度
n 为表数，c 为行宽，r 为目标表存活行数，L 为导出结果字符总量，S 为全部存活数据规模。题目限制字符串长度为常数。哈希映射的期望复杂度：构造 O(n)，插入 O(c)，查询 O(1)，删除映射操作 O(1)（释放一行最多 O(c)），导出 O(r log r + L)。总存储 O(n+S)，导出额外空间 O(r+L)。哈希常数时间是期望值，不是最坏保证。
替代方案与稀疏表
数组按 ID−1 保存行、删除置空，较直观；但大量删除后仍有空槽，导出需要扫描历史最大 ID。哈希表只保存存活行，适合稀疏数据，本实现统一在导出时排序。Java LinkedHashMap、JavaScript Map、Python dict 可利用插入顺序使单调 ID 的导出达到 O(r+L)；C++ 有序 map 可以 O(log r) 的增删查换取天然排序。长期删除可能留下哈希容量冗余，有需要时再重建容器。
面试追问
  • 并发插入？每张表的 ID 分配与写入需要同一临界区；本题按顺序调用。
  • 重启后 ID 不重复？持久化历史计数，不能仅用最大存活行 ID 恢复。
  • 导出非常大？真实系统可采用分页或流式输出；本题签名需要完整数组。
  • 为什么导出排序？提供稳定顺序并匹配示例；有序容器可消除排序，但会改变增删查成本。

Java
import java.util.*;

class SQL {
    private final Map<String, Integer> widths = new HashMap<>();
    private final Map<String, Integer> next = new HashMap<>();
    private final Map<String, Map<Integer, List<String>>> rows = new HashMap<>();

    public SQL(List<String> names, List<Integer> columns) {
        for (int i = 0; i < names.size(); i++) {
            String name = names.get(i);
            widths.put(name, columns.get(i));
            next.put(name, 1);
            rows.put(name, new HashMap<>());
        }
    }
    public boolean ins(String name, List<String> row) {
        if (!widths.containsKey(name) || row.size() != widths.get(name)) return false;
        int id = next.get(name);
        rows.get(name).put(id, new ArrayList<>(row));
        next.put(name, id + 1);
        return true;
    }
    public void rmv(String name, int rowId) {
        if (rows.containsKey(name)) rows.get(name).remove(rowId);
    }
    public String sel(String name, int rowId, int columnId) {
        if (!widths.containsKey(name) || columnId < 1 || columnId > widths.get(name))
            return "<null>";
        List<String> row = rows.get(name).get(rowId);
        return row == null ? "<null>" : row.get(columnId - 1);
    }
    public List<String> exp(String name) {
        List<String> result = new ArrayList<>();
        if (!rows.containsKey(name)) return result;
        Map<Integer, List<String>> table = rows.get(name);
        List<Integer> ids = new ArrayList<>(table.keySet());
        Collections.sort(ids);
        for (int id : ids) result.add(id + "," + String.join(",", table.get(id)));
        return result;
    }
}
JavaScript
class SQL {
  constructor(names, columns) {
    this.tables = new Map(names.map((name, i) =>
      [name, { width: columns[i], next: 1, rows: new Map() }]));
  }
  ins(name, row) {
    const t = this.tables.get(name);
    if (!t || row.length !== t.width) return false;
    t.rows.set(t.next++, row.slice());
    return true;
  }
  rmv(name, rowId) {
    const t = this.tables.get(name);
    if (t) t.rows.delete(rowId);
  }
  sel(name, rowId, columnId) {
    const t = this.tables.get(name);
    if (!t || columnId < 1 || columnId > t.width) return "<null>";
    const row = t.rows.get(rowId);
    return row ? row[columnId - 1] : "<null>";
  }
  exp(name) {
    const t = this.tables.get(name);
    if (!t) return [];
    return [...t.rows.keys()].sort((a, b) => a - b)
      .map(id => [id, ...t.rows.get(id)].join(","));
  }
}
Python 3
from typing import List

class SQL:
    def __init__(self, names: List[str], columns: List[int]):
        self.widths = dict(zip(names, columns))
        self.next_id = {name: 1 for name in names}
        self.rows = {name: {} for name in names}

    def ins(self, name: str, row: List[str]) -> bool:
        if name not in self.widths or len(row) != self.widths[name]:
            return False
        row_id = self.next_id[name]
        self.rows[name][row_id] = row.copy()
        self.next_id[name] += 1
        return True

    def rmv(self, name: str, rowId: int) -> None:
        if name in self.rows:
            self.rows[name].pop(rowId, None)

    def sel(self, name: str, rowId: int, columnId: int) -> str:
        if name not in self.widths or not 1 <= columnId <= self.widths[name]:
            return "<null>"
        row = self.rows[name].get(rowId)
        return "<null>" if row is None else row[columnId - 1]

    def exp(self, name: str) -> List[str]:
        if name not in self.rows:
            return []
        table = self.rows[name]
        return [",".join([str(i)] + table[i]) for i in sorted(table)]
C++
#include <algorithm>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class SQL {
    struct Table {
        int width;
        int next;
        unordered_map<int, vector<string>> rows;
    };
    unordered_map<string, Table> tables;
public:
    SQL(vector<string>& names, vector<int>& columns) {
        for (int i = 0; i < (int)names.size(); ++i)
            tables.emplace(names[i], Table{columns[i], 1, {}});
    }
    bool ins(string name, vector<string> row) {
        auto it = tables.find(name);
        if (it == tables.end() || (int)row.size() != it->second.width) return false;
        auto& t = it->second;
        t.rows.emplace(t.next++, row);
        return true;
    }
    void rmv(string name, int rowId) {
        auto it = tables.find(name);
        if (it != tables.end()) it->second.rows.erase(rowId);
    }
    string sel(string name, int rowId, int columnId) {
        auto it = tables.find(name);
        if (it == tables.end() || columnId < 1 || columnId > it->second.width)
            return "<null>";
        auto row = it->second.rows.find(rowId);
        if (row == it->second.rows.end()) return "<null>";
        return row->second[columnId - 1];
    }
    vector<string> exp(string name) {
        auto it = tables.find(name);
        if (it == tables.end()) return {};
        auto& rows = it->second.rows;
        vector<int> ids;
        for (const auto& entry : rows) ids.push_back(entry.first);
        sort(ids.begin(), ids.end());
        vector<string> result;
        for (int id : ids) {
            string line = to_string(id);
            for (const string& cell : rows.at(id)) line += "," + cell;
            result.push_back(line);
        }
        return result;
    }
};
