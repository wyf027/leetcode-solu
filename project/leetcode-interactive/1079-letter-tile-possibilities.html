题目

给定字符串 tiles，其中每个字符代表一枚刻有大写英文字母的字模。每枚字模至多使用一次，求这些字模能够组成多少个不同的、非空的字母序列。

相同字母的字模没有身份差异：交换两枚同为 A 的字模不会产生新序列。

函数签名

numTilePossibilities(tiles: string) → integer

官方示例

输入：tiles = "AAB" 输出：8 解释："A", "B", "AA", "AB", "BA", "AAB", "ABA", "BAA"
输入：tiles = "AAABBC" 输出：188
输入：tiles = "V" 输出：1

约束

  • 1 <= tiles.length <= 7
  • tiles 仅由大写英文字母组成。

题解：按字母频次回溯

核心洞察
当前库存中，每一种仍有剩余的字母都能成为序列的下一个字符。每做一次选择，就立即得到一个新的非空序列，因此答案加一；随后继续向下扩展，返回时恢复频次。

完整过程

  1. 统计 26 个大写字母各自的剩余数量。
  2. 遍历所有字母；跳过库存为 0 的字母。
  3. 取出一个字母（频次减一），此时形成的新前缀贡献 1。
  4. 递归统计该前缀之后还能接出的所有序列。
  5. 回溯时把字母放回（频次加一）。

不需要把字符串放进集合去重，因为每层只按“字母种类”选择一次。

正确性证明

  1. 不会漏：任意合法非空序列都可按字符从左到右，对应 DFS 中一条逐次消耗相应频次的路径。
  2. 不会重：在同一状态下，相同字母只有一个选择分支；序列的字符顺序唯一决定其搜索路径。
  3. 计数准确：每次选择恰好产生一个此前未计数的非空前缀，递归又完整统计它的所有延伸。故算法恰好计数全部不同合法序列。

边界与复杂度

边界：单字符答案为 1；全部相同字符时答案等于长度；全部不同字符时分支最多。空前缀只是搜索起点，不计入答案。

时间O(n · n!)宽松上界；重复字母会显著剪枝
空间O(n + Σ)递归深度 n，频次数组 Σ=26

替代方案

排序 + used 数组：先排序，枚举每个位置，并用“同层跳过相同字符”去重。直观但状态更多。

组合数学 / 记忆化：枚举每种长度下各字母使用量，按多重集合排列公式求和；或以频次向量为状态记忆化。规模只有 7 时，频次 DFS 更简洁。

面试追问

  • 如果要求列出所有序列？在选择后保存当前路径的副本。
  • 如果长度扩大到 20？考虑频次状态记忆化或组合数学，避免遍历每个具体序列。
  • 为什么不能按字模下标直接 DFS？可以，但必须额外排序并同层去重，否则相同字母会重复计数。

常见错误

  • 只在叶子节点加一，遗漏较短的合法序列。
  • 递归返回后忘记恢复频次，污染兄弟分支。
  • 把空字符串算进答案。
  • 用集合生成全部字符串后再去重，虽可能通过，但浪费时间和内存。

四语言完整代码

Java
class Solution {
    public int numTilePossibilities(String tiles) {
        int[] count = new int[26];
        for (char c : tiles.toCharArray()) count[c - 'A']++;
        return dfs(count);
    }

    private int dfs(int[] count) {
        int total = 0;
        for (int i = 0; i < 26; i++) {
            if (count[i] == 0) continue;
            count[i]--;
            total += 1 + dfs(count);
            count[i]++;
        }
        return total;
    }
}

class Solution:
    def numTilePossibilities(self, tiles: str) -> int:
        count = [0] * 26
        for ch in tiles:
            count[ord(ch) - ord("A")] += 1

        def dfs() -> int:
            total = 0
            for i in range(26):
                if count[i] == 0:
                    continue
                count[i] -= 1
                total += 1 + dfs()
                count[i] += 1
            return total

        return dfs()
C++
class Solution {
public:
    int numTilePossibilities(string tiles) {
        array<int, 26> count{};
        for (char c : tiles) ++count[c - 'A'];
        return dfs(count);
    }

private:
    int dfs(array<int, 26>& count) {
        int total = 0;
        for (int i = 0; i < 26; ++i) {
            if (count[i] == 0) continue;
            --count[i];
            total += 1 + dfs(count);
            ++count[i];
        }
        return total;
    }
};
