LCR 079·回溯MEDIUM

子集

对每个元素选择“加入”或“不加入”，枚举不含重复元素数组的全部子集。

开始演示

题意

给定一个不含重复元素的整数数组 nums，返回该数组所有可能的子集（幂集）。结果不能包含重复子集，输出顺序不限。

示例

输入：nums = [1,2,3]
输出：[[],[1],[2],[3],[1,2],[1,3],[2,3],[1,2,3]]

约束

  • 1 <= nums.length <= 10
  • -10 <= nums[i] <= 10
  • nums 中所有元素互不相同。

核心洞察

每个元素恰好有两种决定：选或不选。深度为 n 的决策树有 2n 个叶子，正好对应全部子集。

回溯模板：加入元素 → 递归 → 撤销加入，再继续下一个选择。

分步交互

以 [1,2,3] 为例，观察回溯逐步收集子集。

完整过程

  1. 建立答案列表与当前路径 path。
  2. 每次递归先保存当前路径副本，它就是一个合法子集。
  3. 从起始下标枚举候选元素，加入路径并递归到下一位置。
  4. 递归返回后移除末尾元素，恢复进入前状态。

边界

  • 空集必须包含在答案中。
  • 保存答案时要复制 path，不能保存同一引用。
  • 输入无重复，本题不需要同层去重。

复杂度

时间 O(n·2n)，因为需复制所有输出；递归栈 O(n)。

替代方案

位掩码枚举从 0 到 2n-1，每个 bit 表示是否选择元素；迭代构造也可逐个把现有子集复制并附加新数。

官方签名代码

class Solution {
    List<List<Integer>> ans = new ArrayList<>();
    public List<List<Integer>> subsets(int[] nums) { dfs(nums, 0, new ArrayList<>()); return ans; }
    void dfs(int[] a, int start, List<Integer> path) { ans.add(new ArrayList<>(path)); for (int i = start; i < a.length; i++) { path.add(a[i]); dfs(a, i + 1, path); path.remove(path.size() - 1); } }
}
var subsets = function(nums) {
  const ans = [], path = [];
  const dfs = start => { ans.push([...path]); for (let i = start; i < nums.length; i++) { path.push(nums[i]); dfs(i + 1); path.pop(); } };
  dfs(0); return ans;
};
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        ans, path = [], []
        def dfs(start):
            ans.append(path[:])
            for i in range(start, len(nums)):
                path.append(nums[i]); dfs(i + 1); path.pop()
        dfs(0); return ans

追问与常见错误

追问

若数组有重复元素？先排序，在同一递归层跳过重复数，以避免重复子集。

常见错误

  • 遗漏空集。
  • 没有复制 path 导致所有答案相同。
  • 递归返回后忘记 pop。

测试与验证区

建议覆盖单元素、多个正负数、最大长度与空路径。
