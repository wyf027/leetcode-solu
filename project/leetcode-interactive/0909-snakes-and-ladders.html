蛇梯棋
Snakes & Ladders

把曲折棋盘摊平成一张等权图：每次掷骰是一条边，BFS 的层数就是最少回合数。

数组矩阵BFS非付费题

题意

给定 n × n 矩阵 board。方格从左下角的 1 开始，按牛耕式逐行交替方向编号至 n²。

从 1 出发，每回合选择前进 1～6 格且不能越过终点。落点若是蛇或梯子的入口，必须传送到其目的地；一次掷骰最多传送一次，即使终点仍是另一个入口也不继续。返回到达 n² 的最少掷骰次数，不可达返回 −1。

函数签名

snakesAndLadders(board: integer[][]): integer

约束

  • n == board.length == board[i].length
  • 2 ≤ n ≤ 20
  • board[i][j] 为 −1 或 [1,n²] 内整数
  • 1 与 n² 不是蛇或梯子的起点

Solution

把棋盘变成等权图

核心洞察

每个编号是节点。一次合法掷骰连出一条边；若落点带传送，边直接指向传送目的地。所有边的代价都是一次掷骰，所以 BFS 首次到达 n² 即得到最少次数。

完整过程

把编号换算为矩阵坐标：自底向上的行号决定列方向。
方格 1 入队，距离设为 0，并记录已访问状态。
出队 curr，枚举 curr+1 到 min(curr+6,n²)，对落点至多应用一次传送。
最终方格未访问时，记录 dist[curr]+1 并入队；命中 n² 即返回。
队列耗尽仍未命中则返回 −1。

正确性

枚举 1～6 覆盖一次掷骰的全部合法选择，且按规则仅将落点传送一次，因此生成边与合法回合一一对应。BFS 按边数非递减顺序访问节点，而每条边恰耗一次骰子；所以首次到达终点的层数最小。队列耗尽代表图中不存在可达路径。

边界与复杂度

  • 枚举上界截断到 n²；传送不能连锁。
  • 蛇可后退甚至形成环，visited 防止重复搜索。
  • 时间 O(n²)，空间 O(n²)，每个节点最多检查 6 条边。

替代方案

显式建图再 BFS 会额外存边；Dijkstra 对等权边过重；DFS 不能自然保证最短路径。

面试追问

  • 骰面代价不同时改用 Dijkstra。
  • 允许连续传送时，需要沿传送链解析并检测环。
  • 可单独封装编号到坐标的映射以降低出错概率。

常见错误

  • 从矩阵顶行开始编号，或忘记行方向交替。
  • 在原始落点而非传送终点标记 visited。
  • 错误地连续触发多条蛇梯。

class Solution {
  public int snakesAndLadders(int[][] b) {
    int n=b.length, end=n*n; int[] d=new int[end+1];
    java.util.Arrays.fill(d,-1);
    java.util.Queue<Integer> q=new java.util.ArrayDeque<>();
    q.offer(1); d[1]=0;
    while(!q.isEmpty()){
      int cur=q.poll();
      for(int next=cur+1;next<=Math.min(cur+6,end);next++){
        int x=(next-1)/n, row=n-1-x, off=(next-1)%n;
        int col=x%2==0?off:n-1-off;
        int to=b[row][col]==-1?next:b[row][col];
        if(d[to]!=-1) continue;
        d[to]=d[cur]+1;
        if(to==end) return d[to];
        q.offer(to);
      }
    }
    return -1;
  }
}
var snakesAndLadders = function(board) {
  const n=board.length, end=n*n, dist=Array(end+1).fill(-1), q=[1];
  dist[1]=0;
  for(let head=0;head<q.length;head++){
    const cur=q[head];
    for(let next=cur+1;next<=Math.min(cur+6,end);next++){
      const x=Math.floor((next-1)/n), row=n-1-x, off=(next-1)%n;
      const col=x%2===0?off:n-1-off;
      const to=board[row][col]===-1?next:board[row][col];
      if(dist[to]!==-1) continue;
      dist[to]=dist[cur]+1;
      if(to===end) return dist[to];
      q.push(to);
    }
  }
  return -1;
};
from collections import deque
from typing import List
class Solution:
    def snakesAndLadders(self, board: List[List[int]]) -> int:
        n, end = len(board), len(board) ** 2
        dist, q = [-1] * (end + 1), deque([1])
        dist[1] = 0
        while q:
            cur = q.popleft()
            for nxt in range(cur + 1, min(cur + 6, end) + 1):
                x, off = divmod(nxt - 1, n)
                row = n - 1 - x
                col = off if x % 2 == 0 else n - 1 - off
                to = nxt if board[row][col] == -1 else board[row][col]
                if dist[to] != -1: continue
                dist[to] = dist[cur] + 1
                if to == end: return dist[to]
                q.append(to)
        return -1
