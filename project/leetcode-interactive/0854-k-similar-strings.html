K-Similar Strings广度优先搜索哈希表字符串
01 · Problem

题目说明

函数：kSimilarity(s1, s2) → integer

给定两个互为字母异位词的字符串 s1 与 s2。一次操作可以选择 s1 中两个位置并交换其字符。请返回将 s1 变成 s2 所需的最少交换次数 k。

关键定义：如果恰好交换 k 次可令两个字符串相同，则它们是 k-similar；题目要求所有可行 k 中的最小值。

约束

  • 1 <= s1.length <= 20
  • s2.length == s1.length
  • s1、s2 只含 {'a','b','c','d','e','f'} 中的小写字母
  • s2 是 s1 的字母异位词
示例 1

输入：s1 = "ab", s2 = "ba"

输出：1

交换下标 0 和 1："ab" → "ba"。

示例 2

输入：s1 = "abc", s2 = "bca"

输出：2

例如："abc" → "bac" → "bca"。

03 · Solution

用 BFS 保证最少交换

把每个字符串视为图上的一个状态，每次交换是一条边。无权图上第一次到达目标的层数，就是最少交换次数。

01

只修复首个错位

找到当前串与目标串第一个不同的位置 i。任何最优路径最终都必须让位置 i 正确，因此本层只考虑把目标字符 s2[i] 换到 i 的交换。

02

只从后方找候选

枚举 j > i，要求 cur[j] == s2[i]。再要求 cur[j] != s2[j]，避免破坏一个已经正确的位置。

03

分层探索

队列中同一层的状态具有相同交换次数。每扩展完一层，步数加一；首次生成或取出目标串时即可返回。

04

去重状态

不同交换序列可能得到同一字符串。使用哈希集合记录已访问状态，避免环与重复搜索。

完整过程

  1. 将 s1 入队并标记访问，令交换次数 steps = 0。
  2. 逐层处理队列。若当前串等于 s2，返回 steps。
  3. 定位首个错位下标 i。
  4. 枚举所有满足 j > i、cur[j] == s2[i] 且 cur[j] != s2[j] 的位置，交换 i、j 生成下一状态。
  5. 未访问的新状态入队；本层结束后令 steps++。

正确性证明

引理 1：设 i 为首个错位位置，存在一条最优变换路径，其第一次涉及位置 i 的交换会把字符 s2[i] 换到 i。因为在最终状态中位置 i 必须变为 s2[i]；若先把别的字符换入，再换入目标字符，可重排或删去前一次对 i 的无效操作，不会增加最优性。

引理 2：候选位置无需选择已经正确的 j。若从正确位置移走目标字符，会新增一个错位；由于两串是字母异位词，必有某个尚未正确的位置持有同字符，选择它不会更差。

定理：剪枝后的邻居仍包含至少一条最优路径的下一步。BFS 按交换次数从小到大访问这些状态，因此首次到达 s2 的层数必为最小交换次数。

时间复杂度O(N · N!)最坏情况下状态数可达排列数，每个状态需扫描与构造字符串。剪枝通常显著减少实际搜索。
空间复杂度O(N · N!)队列与访问集合保存字符串状态；重复字符会让实际状态数更少。

边界情况

  • s1 == s2 时答案为 0。
  • 长度为 1 时两串必相同。
  • 大量重复字符会生成相同后继，必须用集合去重。
  • 同一层可能有多个可行交换，不可贪心地只取第一个。

替代方案

  • 双向 BFS：从起点与终点同时扩展较小前沿，通常更快，但实现更复杂。
  • A*：可用“错位数的一半向上取整”作可采纳启发，但状态管理更重。
  • DFS + 剪枝：可维护全局最优值，但找到最短路的结构不如 BFS 直接。

面试追问

  • 为什么只处理首个错位不会漏掉最优解？
  • 为什么不能只交换“互相归位”的字符对？
  • 如何实现双向 BFS，何时交换两个前沿？
  • 若长度上升到 30，应如何改变策略或估价函数？

常见错误

  • 把“任意两位置交换”误当成相邻交换。
  • 生成所有 O(N²) 交换，导致状态爆炸。
  • 入队后才晚一步去重，重复状态占满队列。
  • 按节点计数而非按 BFS 层数累计答案。

Java · LeetCode 可提交
import java.util.*;

class Solution {
    public int kSimilarity(String s1, String s2) {
        if (s1.equals(s2)) return 0;

        Queue<String> queue = new ArrayDeque<>();
        Set<String> seen = new HashSet<>();
        queue.offer(s1);
        seen.add(s1);
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int count = 0; count < size; count++) {
                String current = queue.poll();
                if (current.equals(s2)) return steps;

                int i = 0;
                while (current.charAt(i) == s2.charAt(i)) i++;

                for (int j = i + 1; j < current.length(); j++) {
                    if (current.charAt(j) != s2.charAt(i) ||
                        current.charAt(j) == s2.charAt(j)) continue;

                    char[] chars = current.toCharArray();
                    char temp = chars[i];
                    chars[i] = chars[j];
                    chars[j] = temp;
                    String next = new String(chars);
                    if (seen.add(next)) queue.offer(next);
                }
            }
            steps++;
        }
        return -1;
    }
}
JavaScript · LeetCode 可提交
/**
 * @param {string} s1
 * @param {string} s2
 * @return {number}
 */
var kSimilarity = function(s1, s2) {
    if (s1 === s2) return 0;

    const queue = [s1];
    const seen = new Set([s1]);
    let head = 0;
    let steps = 0;

    while (head < queue.length) {
        const levelEnd = queue.length;
        while (head < levelEnd) {
            const current = queue[head++];
            if (current === s2) return steps;

            let i = 0;
            while (current[i] === s2[i]) i++;

            for (let j = i + 1; j < current.length; j++) {
                if (current[j] !== s2[i] || current[j] === s2[j]) continue;
                const chars = current.split('');
                [chars[i], chars[j]] = [chars[j], chars[i]];
                const next = chars.join('');
                if (!seen.has(next)) {
                    seen.add(next);
                    queue.push(next);
                }
            }
        }
        steps++;
    }
    return -1;
};
Python 3 · LeetCode 可提交
from collections import deque


class Solution:
    def kSimilarity(self, s1: str, s2: str) -> int:
        if s1 == s2:
            return 0

        queue = deque([s1])
        seen = {s1}
        steps = 0

        while queue:
            for _ in range(len(queue)):
                current = queue.popleft()
                if current == s2:
                    return steps

                i = 0
                while current[i] == s2[i]:
                    i += 1

                for j in range(i + 1, len(current)):
                    if current[j] != s2[i] or current[j] == s2[j]:
                        continue
                    chars = list(current)
                    chars[i], chars[j] = chars[j], chars[i]
                    nxt = ''.join(chars)
                    if nxt not in seen:
                        seen.add(nxt)
                        queue.append(nxt)
            steps += 1

        return -1
C++ · LeetCode 可提交
class Solution {
public:
    int kSimilarity(string s1, string s2) {
        if (s1 == s2) return 0;

        queue<string> q;
        unordered_set<string> seen;
        q.push(s1);
        seen.insert(s1);
        int steps = 0;

        while (!q.empty()) {
            int size = q.size();
            while (size--) {
                string current = q.front();
                q.pop();
                if (current == s2) return steps;

                int i = 0;
                while (current[i] == s2[i]) i++;

                for (int j = i + 1; j < current.size(); j++) {
                    if (current[j] != s2[i] || current[j] == s2[j]) continue;
                    string next = current;
                    swap(next[i], next[j]);
                    if (seen.insert(next).second) q.push(next);
                }
            }
            steps++;
        }
        return -1;
    }
};
