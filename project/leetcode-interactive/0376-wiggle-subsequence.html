01 · Problem

怎样才算一次“摆动”？

给定整数数组 nums，从中按原顺序选择若干元素，求能构成的最长摆动子序列长度。

严格交替

相邻元素的差值必须正、负、正、负……交替出现。第一个非零差值可正可负。

零差值不算

相等元素产生的差值为 0，既不是上升也不是下降，不能贡献新的摆动方向。

保持原顺序

子序列允许删除任意元素，但保留下来的元素必须维持它们在原数组中的先后次序。

任务：返回 nums 的最长摆动子序列长度。仅有一个元素的序列，以及含两个不相等元素的序列，都视为摆动序列。

对照：[1,7,4,9,2,5] 的连续差值为 6,-3,5,-7,3，符号严格交替；而连续同向变化或出现 0 差值时，整个序列便不满足定义。

官方示例

EXAMPLE 01 
输入：nums = [1,7,4,9,2,5]
输出：6
解释：整个序列均为摆动序列，
差值为 (6,-3,5,-7,3)。
EXAMPLE 02 
输入：nums = [1,17,5,10,13,15,10,5,16,8]
输出：7
解释：可选 [1,17,10,13,10,16,8]，
差值为 (16,-7,3,-3,6,-8)。
EXAMPLE 03 
输入：nums = [1,2,3,4,5,6,7,8,9]
输出：2

约束

  • 1 <= nums.length <= 1000
  • 0 <= nums[i] <= 1000

函数签名

wiggleMaxLength(nums: integer[]) -> integer

进阶目标：尝试在线性时间内完成。

04 · Solution

准备好看完整题解了吗？

建议先用上方交互区猜一猜两个状态的含义，再展开分析。

Greedy DP · O(n)

把所有中间坡面压缩成转折点

核心洞察

只关心摆动长度时，同一段连续上坡（或下坡）中间的点都可被忽略：保留更靠后的端点，不会妨碍未来形成相反方向的摆动。

定义两个滚动状态：

  • up：处理到当前位置、最后一次有效差值为正时的最长长度。
  • down：处理到当前位置、最后一次有效差值为负时的最长长度。

完整过程

  1. 单个元素本身有效，初始化 up = down = 1。
  2. 若当前值大于前一个值，新的正差值可接在任意“下降收尾”之后，令 up = down + 1。
  3. 若当前值小于前一个值，对称地令 down = up + 1。
  4. 若两值相等，零差值不构成摆动，两个状态都不变。
  5. 扫描结束返回 max(up, down)。

为什么相邻比较就够了？

若一段持续上升，用这段的最后一个点替换先前选中的上升端点，只会让它更适合接后续下降；持续下降同理。因此扫描相邻差值便能识别方向是否发生转折，无须枚举被删除的元素。

边界处理

  • 长度为 1：初始化值直接给出答案 1。
  • 全部相等：没有非零差值，两个状态始终为 1。
  • 严格单调且长度至少 2：只出现一个方向，答案为 2。
  • 重复值：跳过即可，绝不能把 0 当作方向切换。

正确性证明

  1. 状态含义成立。初始只有一个元素，既可视作未来的上升收尾起点，也可视作下降收尾起点，所以二者均为 1。
  2. 正差值转移正确。当 nums[i] > nums[i-1] 时，把当前元素接到一个下降收尾序列后会新增一次合法上升，得到长度 down + 1。任何连续上升段中的旧端点都可替换为当前更高、位置更后的端点，故不会漏掉更优解。
  3. 负差值对称正确。当 nums[i] < nums[i-1] 时，当前元素可接到上升收尾序列后，得到 up + 1；下降坡面中间点同样可安全替换。
  4. 零差值无需更新。相等元素不能产生正负方向，保留原状态已覆盖所有合法选择。
  5. 结论。归纳可知，扫描每个位置后，up 与 down 分别是对应收尾方向的最优长度；最终两类合法序列必属其一，因此最大值就是全局最优答案。
时间复杂度O(n)只扫描数组一次
空间复杂度O(1)仅维护两个滚动状态

四语言完整实现

class Solution {
    public int wiggleMaxLength(int[] nums) {
        int up = 1;
        int down = 1;

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > nums[i - 1]) {
                up = down + 1;
            } else if (nums[i] < nums[i - 1]) {
                down = up + 1;
            }
        }

        return Math.max(up, down);
    }
}

替代方案

可以建立长度为 n 的 up[i]、down[i] 动态规划数组，按同样规则转移，时间仍为 O(n)、空间为 O(n)。更朴素的两层循环 DP 会枚举前驱，时间 O(n²)，适合帮助推导状态，但不满足进阶目标。

常见错误

  • 把差值为 0 当成一次方向切换。
  • 统计局部峰谷时漏掉首尾元素。
  • 只统计符号变化次数，却忘记答案还要包含第一个元素。
  • 更新正差值时写成 up++，没有从相反方向状态转移。

面试追问

  • 能否恢复一条实际的最长摆动子序列，而不只是长度？
  • 为什么连续上坡只保留最后一个点是安全的？
  • 若要求差值绝对值至少为某个阈值，当前贪心还能直接成立吗？

一句话记忆

上升只能接在下降之后，下降只能接在上升之后；相等就跳过。
