LCR 045 · MEDIUM · TREE / BFS

找树左下角的值

每一层从左到右扫描。最后一层的第一个节点，就是整棵树最左下角的答案。

题意

给定一棵二叉树，找出它最后一行中最左边的节点值。树至少含有一个节点。

示例

root = [1,2,3,4,null,5,6,null,null,7]

输出：7

最后一层为 [7]，最左节点为 7。

约束

  • 节点数在 1 到 104 之间。
  • 节点值范围为 32 位有符号整数。
不需要比较“左不左”：层序遍历天然保证每层最先出队的节点就是该层最左节点。

层序遍历实验室

准备就绪

输入 LeetCode 层序数组（使用 null 表示空位），逐层观察“本层第一个节点”如何更新答案。

载入示例后，按层推进。

    验证状态

    页面内固定示例可交互演示；浏览器验收、随机对拍、四语言编译：deferred（未执行）。

    核心洞察：每层的第一个节点覆盖答案

    01 · 分层

    每轮先固定队列长度，这一轮只处理当前层。

    02 · 取首个

    当前层 i === 0 时，出队节点就是最左节点。

    03 · 最后一层

    遍历结束时，最后一次记录的值正是目标答案。

    过程

    1. 根节点入队，初始化 answer。
    2. 当队列非空，记录本层节点数 size。
    3. 依次出队 size 个节点；第一个出队节点赋给 answer。
    4. 把左右孩子按左、右顺序入队；所有层完成后返回 answer。

    复杂度

    时间 O(n)：每个节点入队、出队一次。空间 O(w)：队列最多保存树的最大宽度。

    常见错误

    不要记录每层最后一个节点（那是右视角）；也不要把 DFS 里“更深”误写成“更浅”。

    四语言实现

    class Solution {
    public int findBottomLeftValue(TreeNode root) {
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int answer = root.val;
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (i == 0) answer = node.val;
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        return answer;
    }
}
