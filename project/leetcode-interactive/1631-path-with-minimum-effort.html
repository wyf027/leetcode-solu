LeetCode 1631 · Path With Minimum Effort

最小体力
消耗路径

最好的路线未必总爬升最少，而是让途中最难跨过的那一步尽可能轻松。先读懂目标，再到路径实验室亲手观察。

二维矩阵四向移动最小化最大值非付费题
Problem

题意与参数

给定二维整数数组 heights，其中 heights[row][col] 是格子高度。从左上角 (0, 0) 出发，每次可向上、下、左、右移动一格，目标是到达右下角 (rows - 1, columns - 1)。

一条路径的体力是路径上每对相邻格子的高度差绝对值的最大值。返回所有可行路径中最小的体力。

minimumEffortPath(heights: integer[][]) → integer

约束

  • rows == heights.length
  • columns == heights[i].length
  • 1 ≤ rows, columns ≤ 100
  • 1 ≤ heights[i][j] ≤ 10⁶

官方示例

示例 1 输入：heights = [[1,2,2],[3,8,2],[5,3,5]] 输出：2 解释：路径 [1,3,5,3,5] 的最大相邻高度差是 2， 优于路径 [1,2,2,2,5] 的 3。
示例 2 输入：heights = [[1,2,3],[3,8,4],[5,3,5]] 输出：1 解释：路径 [1,2,3,4,5] 的最大相邻高度差是 1， 优于路径 [1,3,5,3,5]。
示例 3 输入：heights = [[1,2,1,1,1],[1,2,1,2,1],[1,2,1,2,1], [1,2,1,2,1],[1,1,1,2,1]] 输出：0 解释：存在一条相邻格子高度始终相同的路径。

Deep Dive

Dijkstra：把距离改成路径瓶颈

核心洞察

把格子视为顶点，相邻格子的边权是高度差绝对值。普通最短路累加边权；本题路径代价是边权的最大值。因此从 u 到邻居 v 的候选体力为 max(dist[u], |height[u] - height[v]|)。用小根堆优先确定体力最小的格子。

完整过程

  1. 创建同尺寸的 dist，初始化为无穷大，并令 dist[0][0] = 0。
  2. 把 (0, 0, 0)（体力、行、列）放入小根堆。
  3. 弹出体力最小的状态；若已落后于 dist 的新值则跳过。
  4. 枚举四邻格，按瓶颈公式松弛，更新成功就入堆。
  5. 终点第一次作为有效状态出堆时立即返回。

正确性证明

  1. 单调性：路径末尾增加一条边后，新代价是旧瓶颈与新边权的最大值，所以绝不会变小。
  2. 出堆最优性：若当前最小有效状态仍有更优路径，则那条路径上首个未确定顶点的前驱早已确定，并已把不大于该更优路径瓶颈的状态放入堆，与当前状态最小矛盾。
  3. 终点成立：每个有效出堆顶点的值均已最优，所以终点出堆时就是全局最小体力。

边界情况

  • 只有一个格子时答案为 0。
  • 单行或单列无需特殊分支。
  • 高度差在 32 位有符号整数范围内。
  • 同一格子可重复入堆，出堆时应过滤过期状态。

复杂度

令 V = rows × columns。四邻接边数为 O(V)，时间复杂度 O(V log V)，空间复杂度 O(V)。

替代方案

二分答案 + BFS/DFS：二分允许的最大高度差，检查只走不超过阈值的边能否到终点，时间 O(V log 10⁶)。并查集：按边权升序合并端点，起点与终点首次连通时的边权就是答案。

面试追问

  • 如果代价改为高度差之和，应恢复普通 Dijkstra 的加法松弛。
  • 如果要返回具体路径，每次成功松弛时记录父节点，最后回溯。
  • 局部选择最小高度差为何不行？眼前平缓可能通向之后必须跨越的断层。

常见错误

  • 误把高度差全部相加。
  • 松弛时只看当前边，没有与此前瓶颈取最大值。
  • 用普通队列却提前返回，破坏最优顺序。
  • 把“入堆”当成“已确定”，错过稍后出现的更优值。

import java.util.*;

class Solution {
    public int minimumEffortPath(int[][] heights) {
        int m = heights.length, n = heights[0].length;
        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        PriorityQueue<int[]> pq =
            new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        dist[0][0] = 0;
        pq.offer(new int[]{0, 0, 0});
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int effort = cur[0], r = cur[1], c = cur[2];
            if (effort != dist[r][c]) continue;
            if (r == m - 1 && c == n - 1) return effort;
            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int next = Math.max(effort,
                    Math.abs(heights[r][c] - heights[nr][nc]));
                if (next < dist[nr][nc]) {
                    dist[nr][nc] = next;
                    pq.offer(new int[]{next, nr, nc});
                }
            }
        }
        return 0;
    }
}

var minimumEffortPath = function(heights) {
  const m = heights.length, n = heights[0].length;
  const dist = Array.from({ length: m }, () => Array(n).fill(Infinity));
  const heap = [];
  const swap = (a, b) => [heap[a], heap[b]] = [heap[b], heap[a]];
  const push = item => {
    heap.push(item);
    for (let i = heap.length - 1; i > 0;) {
      const p = (i - 1) >> 1;
      if (heap[p][0] <= heap[i][0]) break;
      swap(i, p); i = p;
    }
  };
  const pop = () => {
    const top = heap[0], last = heap.pop();
    if (heap.length) {
      heap[0] = last;
      for (let i = 0;;) {
        let k = i, l = i * 2 + 1, r = l + 1;
        if (l < heap.length && heap[l][0] < heap[k][0]) k = l;
        if (r < heap.length && heap[r][0] < heap[k][0]) k = r;
        if (k === i) break;
        swap(i, k); i = k;
      }
    }
    return top;
  };
  dist[0][0] = 0;
  push([0, 0, 0]);
  const dirs = [[1,0],[-1,0],[0,1],[0,-1]];
  while (heap.length) {
    const [effort, row, col] = pop();
    if (effort !== dist[row][col]) continue;
    if (row === m - 1 && col === n - 1) return effort;
    for (const [dr, dc] of dirs) {
      const nr = row + dr, nc = col + dc;
      if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
      const next = Math.max(effort,
        Math.abs(heights[row][col] - heights[nr][nc]));
      if (next < dist[nr][nc]) {
        dist[nr][nc] = next;
        push([next, nr, nc]);
      }
    }
  }
  return 0;
};
from typing import List
import heapq

class Solution:
    def minimumEffortPath(self, heights: List[List[int]]) -> int:
        m, n = len(heights), len(heights[0])
        dist = [[float("inf")] * n for _ in range(m)]
        dist[0][0] = 0
        heap = [(0, 0, 0)]
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
        while heap:
            effort, row, col = heapq.heappop(heap)
            if effort != dist[row][col]:
                continue
            if row == m - 1 and col == n - 1:
                return effort
            for dr, dc in directions:
                nr, nc = row + dr, col + dc
                if not (0 <= nr < m and 0 <= nc < n):
                    continue
                edge = abs(heights[row][col] - heights[nr][nc])
                next_effort = max(effort, edge)
                if next_effort < dist[nr][nc]:
                    dist[nr][nc] = next_effort
                    heapq.heappush(heap, (next_effort, nr, nc))
        return 0

using namespace std;

class Solution {
public:
    int minimumEffortPath(vector<vector<int>>& heights) {
        int m = heights.size(), n = heights[0].size();
        vector<vector<int>> dist(m, vector<int>(n, INT_MAX));
        using State = tuple<int, int, int>;
        priority_queue<State, vector<State>, greater<State>> pq;
        dist[0][0] = 0;
        pq.emplace(0, 0, 0);
        const array<array<int, 2>, 4> dirs =
            {{{1,0},{-1,0},{0,1},{0,-1}}};
        while (!pq.empty()) {
            auto [effort, row, col] = pq.top();
            pq.pop();
            if (effort != dist[row][col]) continue;
            if (row == m - 1 && col == n - 1) return effort;
            for (const auto& d : dirs) {
                int nr = row + d[0], nc = col + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                int next = max(effort,
                    abs(heights[row][col] - heights[nr][nc]));
                if (next < dist[nr][nc]) {
                    dist[nr][nc] = next;
                    pq.emplace(next, nr, nc);
                }
            }
        }
        return 0;
    }
};
