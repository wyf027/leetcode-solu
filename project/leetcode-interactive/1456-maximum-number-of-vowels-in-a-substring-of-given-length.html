Problem

题目说明

给定一个由小写英文字母组成的字符串 s 和一个整数 k，请在所有长度恰好为 k 的连续子串中，找出元音字母数量的最大值并返回。

英语元音字母为 a、e、i、o、u。函数签名可写作 maxVowels(s, k) -> integer。

约束

  • 1 <= s.length <= 10^5
  • s 仅由小写英文字母组成

核心洞察：复用相邻窗口的计数

先统计前 k 个字符中的元音数。窗口每向右移动一位，只需减去离开窗口的字符贡献，再加上进入窗口的字符贡献；无须重新扫描整个窗口。

用 current 保存当前窗口的元音数，用 best 保存到目前为止见过的最大值。若 best === k，已经达到理论上限，可以直接返回。

完整过程

  1. 定义判断字符是否为元音的方法。
  2. 遍历下标 0..k-1，得到第一个窗口的元音数，并赋给 best。
  3. 从下标 k 开始枚举每个新进入窗口的字符。
  4. 令离开的字符下标为 i-k；当前计数减去它的元音贡献，再加上 s[i] 的贡献。
  5. 每一步用 current 更新 best；遍历结束后返回 best。

正确性证明

初始化正确

逐个检查前 k 个字符，因此 current 恰好等于第一个长度为 k 的窗口所含元音数。

转移保持正确

从窗口 [i-k, i-1] 移到 [i-k+1, i] 时，两者只相差离开的 s[i-k] 与进入的 s[i]。一减一加后，current 精确表示新窗口。

结论正确

算法依次访问全部 n-k+1 个合法窗口，并将各窗口计数纳入 best，所以最终 best 就是全局最大值。

复杂度与边界

时间复杂度：O(n)，每个字符至多作为进入/离开字符各处理一次。空间复杂度：O(1)，只维护常数个计数变量。

  • k = 1：窗口逐字符检查，逻辑不变。
  • k = s.length：只有一个窗口，初始化结果就是答案。
  • 全为辅音：计数始终为 0。
  • 首个窗口已经全为元音：best = k，可提前返回。

四语言完整代码

class Solution {
    public int maxVowels(String s, int k) {
        int current = 0;
        for (int i = 0; i < k; i++) {
            if (isVowel(s.charAt(i))) current++;
        }

        int best = current;
        if (best == k) return k;

        for (int i = k; i < s.length(); i++) {
            if (isVowel(s.charAt(i - k))) current--;
            if (isVowel(s.charAt(i))) current++;
            best = Math.max(best, current);
            if (best == k) return k;
        }
        return best;
    }

    private boolean isVowel(char ch) {
        return ch == 'a' || ch == 'e' || ch == 'i'
            || ch == 'o' || ch == 'u';
    }
}
/**
 * @param {string} s
 * @param {number} k
 * @return {number}
 */
var maxVowels = function(s, k) {
    const vowels = new Set(['a', 'e', 'i', 'o', 'u']);
    let current = 0;

    for (let i = 0; i < k; i++) {
        if (vowels.has(s[i])) current++;
    }

    let best = current;
    if (best === k) return k;

    for (let i = k; i < s.length; i++) {
        if (vowels.has(s[i - k])) current--;
        if (vowels.has(s[i])) current++;
        best = Math.max(best, current);
        if (best === k) return k;
    }
    return best;
};
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        vowels = set("aeiou")
        current = sum(ch in vowels for ch in s[:k])
        best = current

        if best == k:
            return k

        for i in range(k, len(s)):
            current -= s[i - k] in vowels
            current += s[i] in vowels
            best = max(best, current)
            if best == k:
                return k

        return best
class Solution {
public:
    int maxVowels(string s, int k) {
        auto isVowel = [](char ch) {
            return ch == 'a' || ch == 'e' || ch == 'i'
                || ch == 'o' || ch == 'u';
        };

        int current = 0;
        for (int i = 0; i < k; ++i) {
            current += isVowel(s[i]);
        }

        int best = current;
        if (best == k) return k;

        for (int i = k; i < static_cast<int>(s.size()); ++i) {
            current -= isVowel(s[i - k]);
            current += isVowel(s[i]);
            best = max(best, current);
            if (best == k) return k;
        }
        return best;
    }
};

替代方案

暴力枚举：对每个起点都重新扫描长度为 k 的子串，时间复杂度为 O((n-k+1)·k)，在 n = 10^5 时可能超时。

前缀和：先将每个字符映射为 0/1，建立元音计数前缀和；任意窗口可在 O(1) 求和，总时间和额外空间均为 O(n)。当只需一次顺序查询时，滑动窗口的 O(1) 额外空间更合适；若还要回答大量不同区间查询，前缀和更通用。

面试追问

  • 如果要返回具体子串？ 在更新 best 时同步记录最佳窗口起点。
  • 如果要求至少包含 m 个元音的最短子串？ 窗口长度不再固定，应改为可变长滑动窗口。
  • 如果字符流无法一次读入内存？ 保存最近 k 个字符（队列/环形缓冲区）及当前计数即可在线处理。
  • 为什么提前返回安全？ 长度为 k 的窗口不可能拥有超过 k 个元音。

常见错误

  • 先加入新字符却忘记移除下标 i-k 的旧字符，导致窗口实际长度增长。
  • 循环从 k+1 开始，漏掉第二个窗口。
  • 把题意误读为“最长元音连续段”；窗口内的辅音并不会让窗口失效。
  • 每次移动都重新扫描整个窗口，使复杂度退化为 O(nk)。
  • 使用 substring 反复创建新字符串，增加不必要的时间和空间开销。
