01 / Problem brief

题意与数据结构

给定员工表 Salary，把每一行的性别值 'm' 与 'f' 相互交换；其他列必须保持不变。

任务要求

必须只使用一条 UPDATE 语句完成全表变更，不能创建中间临时表，也不能以 SELECT 语句代替更新。

  • 1id 是主键，每个值唯一。
  • 2sex 为枚举列，官方保证值只来自 'm' 与 'f'。
  • 3更新应覆盖表中所有员工，且 id、name、salary 不变。
  • 4官方题面未给出行数范围；解法应按行数线性工作。

Solution revealed

单次赋值，双向映射

关键不是先改一种值再改另一种，而是让每一行在同一次赋值中，根据它的原值计算出新值。

01

核心洞察

SQL 的 CASE 表达式会为当前行返回一个新值：原来是 'm' 就产生 'f'，否则产生 'm'。题目保证只有这两种枚举值，所以分支完整覆盖。

实现代码

SQL 是本题官方可提交解法；其余四种语言只模拟同一行级映射，属于本地语义参考，不能提交到这道数据库题。

官方提交语言：MySQL。CASE 写法也便于迁移到 PostgreSQL、SQL Server 与 Oracle。

UPDATE Salary
SET sex = CASE
    WHEN sex = 'm' THEN 'f'
    ELSE 'm'
END;

本地语义参考：以内存对象列表模拟全表映射；不是本题的 LeetCode 可提交代码。

import java.util.ArrayList;
import java.util.List;

public class Main {
    record Employee(int id, String name, char sex, int salary) {}

    static List<Employee> swapSex(List<Employee> employees) {
        List<Employee> result = new ArrayList<>(employees.size());
        for (Employee employee : employees) {
            char nextSex = employee.sex() == 'm' ? 'f' : 'm';
            result.add(new Employee(
                employee.id(), employee.name(), nextSex, employee.salary()
            ));
        }
        return result;
    }

    public static void main(String[] args) {
        List<Employee> salary = List.of(
            new Employee(1, "A", 'm', 2500),
            new Employee(2, "B", 'f', 1500)
        );
        System.out.println(swapSex(salary));
    }
}

本地语义参考：复制每条字典记录后更新 sex；不是官方 Pandas 提交模板。

from typing import Any


def swap_sex(employees: list[dict[str, Any]]) -> list[dict[str, Any]]:
    result: list[dict[str, Any]] = []
    for employee in employees:
        updated = employee.copy()
        updated["sex"] = "f" if employee["sex"] == "m" else "m"
        result.append(updated)
    return result


if __name__ == "__main__":

    ]

本地语义参考：复制 vector 后原位改变副本中的 sex；不是本题的 LeetCode 可提交代码。

#include <iostream>
#include <string>
#include <vector>

struct Employee {
    int id;
    std::string name;
    char sex;
    int salary;
};

std::vector<Employee> swapSex(std::vector<Employee> employees) {
    for (Employee& employee : employees) {
        employee.sex = employee.sex == 'm' ? 'f' : 'm';
    }
    return employees;
}

int main() {
    std::vector<Employee> salary = {
        {1, "A", 'm', 2500},
        {2, "B", 'f', 1500}
    };
    for (const Employee& employee : swapSex(salary)) {
        std::cout << employee.id << ' ' << employee.sex << '\n';
    }
    return 0;
}

完整过程

  1. UPDATE 将目标集合确定为 Salary 的所有行；本题不写 WHERE。
  2. 对当前行读取更新前的 sex 值。
  3. CASE 把 m 映射到 f，把 f 映射到 m。
  4. 只把表达式结果写回 sex；其他列没有出现在 SET 中，因此保持原值。

复杂度

时间：O(n)，其中 n 是 Salary 行数；每行需要常数次判断和一次列更新。

额外空间：从算法表达式看为 O(1)。实际数据库仍可能产生事务日志、锁或引擎内部版本数据，这些不属于题目抽象中的临时表。

正确性证明

对任意一行 r，题目保证 r.sex 只能为 m 或 f：

情况一：若原值为 m，WHEN 条件成立，CASE 返回 f，符合交换要求。
情况二：若原值为 f，WHEN 条件不成立，ELSE 返回 m，同样符合交换要求。

两种可能均被正确映射，且 SET 只修改 sex。因此每一行的 sex 被交换、其他字段不变，整张表更新正确。

边界情况

  • 空表：没有行被更新，结果仍为空。
  • 单行表：仅执行一次映射。
  • 所有行值相同：每行独立映射，不依赖另一类值是否存在。
  • 若现实表允许 NULL 或第三种值，应增加显式分支并用 ELSE 保留原值；但本题枚举约束排除了它们。

替代方案

  • MySQL 可用 IF(sex = 'm', 'f', 'm')，更短但数据库可移植性较弱。
  • 也可写完整的两个 WHEN，并令 ELSE 返回 sex，适合防御现实中的脏数据。
  • 用 ASCII 运算、字符串 REPLACE 或异或技巧可读性差，且更依赖类型转换，不推荐。

常见错误

  • 连续写两条 UPDATE：第二条会再次命中第一条刚改出的值，并且违反“单条语句”。
  • 先 SELECT 再更新：不符合题目限制，也会制造不必要的中间流程。
  • 只写 WHERE sex = 'm'：会漏掉原来为 f 的行。
  • 误以为可只改显示结果：题目要求持久更新 Salary 表。

面试追问

  • 若 sex 可为 NULL，如何在不改变 NULL 的前提下交换？
  • 如何把两值互换扩展为三种状态的循环映射？
  • CASE 与数据库专属条件函数在可移植性上有何差异？

工程提示

生产环境的大表更新通常需要在事务、锁等待、日志容量、备份与回滚策略评估后执行。本题只考察集合更新表达式，不代表可以无评估地对线上全表运行。
