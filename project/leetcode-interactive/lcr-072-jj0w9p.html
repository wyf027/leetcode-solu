x 的平方根

给你一个非负整数 x，返回它的平方根的整数部分。结果只保留小数部分被舍去后的整数，不使用任何内置平方根函数。

难度：Easy 核心：二分答案 空间：O(1)

题意与示例

示例 1

x = 4 → 2

√4 恰好是 2。

示例 2

x = 8 → 2

√8 ≈ 2.828，舍去小数部分。

约束：0 ≤ x ≤ 2³¹ - 1。比较 mid × mid 时可能溢出，因此实现中使用 mid ≤ x / mid。

固定演示 x = 8；每次保留仍可能包含答案的一半区间。

思路速览

  1. 1答案一定落在 [1, x]；x < 2 直接返回 x。
  2. 2若 mid ≤ x / mid，mid 仍合法，记录它并向右寻找更大答案。
  3. 3否则 mid 偏大，右边界收缩到 mid - 1。
过程
每次丢弃一半候选，最终保留最大的合法 mid。
边界
0、1、完全平方数，以及 2³¹ - 1。
复杂度
时间 O(log x)，额外空间 O(1)。

主解：二分答案

维护闭区间 [left, right]。当 mid 不大于真实平方根时，mid 是当前答案并继续向右；否则向左收缩。用除法判断避免 mid * mid 溢出。

Java 

class Solution {
  public int mySqrt(int x) {
    if (x < 2) return x;
    int left = 1, right = x / 2, answer = 1;
    while (left <= right) {
      int mid = left + (right - left) / 2;
      if (mid <= x / mid) {
        answer = mid;
        left = mid + 1;
      } else {
        right = mid - 1;
      }
    }
    return answer;
  }
}

替代方案

牛顿迭代可更快收敛，但整数边界、停止条件和溢出处理更容易出错。

常见错误

直接比较 mid * mid；忘记保存最后一个合法 mid；x=0、1 时区间不正确。

追问

若要保留小数精度，可在整数结果后继续二分小数位，或改用牛顿迭代。
