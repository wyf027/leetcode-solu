EASY数组字符串
Permutation workshop · 重新排列

把每个字符，送到它命中注定的位置。

1528 · 重新排列字符串 / Shuffle String

Problem

题意

给定字符串 s 和与它等长的整数数组 indices。对每个下标 i，把 s[i] 移动到新字符串的 indices[i] 位置，返回最终字符串。

换句话说，映射方向是“原位置 → 新位置”：answer[indices[i]] = s[i]。

函数签名
restoreString(s: string, indices: integer[]) → string
Boundaries

约束

  • s.length == indices.length == n
  • 1 ≤ n ≤ 100
  • s 仅包含小写英文字母
  • 0 ≤ indices[i] < n
  • indices 中所有值互不相同
Official examples

官方示例

示例 1
输入：s = "codeleet", indices = [4,5,6,7,0,2,1,3]
输出："leetcode"
解释：按 indices 指示的位置移动后，"codeleet" 变成 "leetcode"。
示例 2
输入：s = "abc", indices = [0,1,2]
输出："abc"
解释：每个字符的目标位置都等于原位置，所以字符串不变。

Solution

一次扫描，按目标下标落位

最直接的做法就是把 indices 当作每个字符的“投递地址”。

核心洞察

遍历原字符串的每个下标 i，执行 answer[indices[i]] = s[i]。由于 indices 是 0 到 n−1 的一个排列，每个目标槽位恰好被写入一次。

完整过程

  1. 创建长度为 n 的字符数组 answer。
  2. 从 i = 0 扫描到 n−1。
  3. 把 s[i] 写到 answer[indices[i]]。
  4. 把 answer 拼接成字符串并返回。

正确性证明

任取原字符串中的字符 s[i]。算法按照题意将它写入 answer[indices[i]]，所以该字符落在正确位置。又因为 indices 中的值互不相同，不同字符不会写入同一位置；并且共有 n 个合法且不同的目标下标，它们恰好覆盖 0…n−1。故 answer 的每个位置都被正确填充，返回值即所求重新排列字符串。

复杂度与边界

时间：O(n)，每个字符处理一次。
空间：O(n)，答案字符数组占用线性空间；若不计返回结果所需空间，则额外工作空间为 O(n) 或依语言字符串模型而定。

n = 1 时仍成立；indices 为恒等排列时原样返回；重复字符不影响，因为处理的是位置而不是字符值。

替代方案

排序二元组：把每个字符与目标下标组成 (indices[i], s[i])，按目标下标排序后拼接。它同样正确，但时间为 O(n log n)，没有利用可直接寻址的目标位置。

原地循环置换：可以通过交换字符并同步修正 indices 来减少额外工作空间，但字符串在很多语言中不可变，而且实现更易出错。题目规模很小，辅助数组通常是面试中的清晰首选。

四语言实现

class Solution {
    public String restoreString(String s, int[] indices) {
        char[] answer = new char[s.length()];
        for (int i = 0; i < s.length(); i++) {
            answer[indices[i]] = s.charAt(i);
        }
        return new String(answer);
    }
}
/**
 * @param {string} s
 * @param {number[]} indices
 * @return {string}
 */
var restoreString = function(s, indices) {
    const answer = new Array(s.length);
    for (let i = 0; i < s.length; i++) {
        answer[indices[i]] = s[i];
    }
    return answer.join("");
};
class Solution:
    def restoreString(self, s: str, indices: List[int]) -> str:
        answer = [""] * len(s)
        for i, char in enumerate(s):
            answer[indices[i]] = char
        return "".join(answer)
class Solution {
public:
    string restoreString(string s, vector<int>& indices) {
        string answer(s.size(), ' ');
        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            answer[indices[i]] = s[i];
        }
        return answer;
    }
};

面试追问

  • 如果 indices 可能重复或越界，如何校验并定义错误行为？
  • 如何原地恢复，并证明交换过程一定终止？
  • 如果字符是 Unicode 字素簇，按“字符”移动与按代码单元移动有何区别？
  • 如果输入大到无法一次装入内存，能否流式处理？需要什么外部存储结构？

常见错误

  • 写成 answer[i] = s[indices[i]]，把映射方向反了。
  • 直接按 indices 排序，却忘了字符必须与下标绑定移动。
  • 使用字符串逐次拼接；在不可变字符串语言中可能退化到 O(n²)。
  • 原地交换时只换字符、不更新 indices，导致循环或错位。
