路径交叉 / Self Crossing

沿逆时针不断转向的折线，何时会第一次触碰或穿过自己？先观察路径，再展开题解。

Problem

题意

给定整数数组 distance。从平面原点 (0, 0) 出发，依次向北、西、南、东移动 distance[0]、distance[1]、distance[2]、distance[3] 米，之后仍按逆时针方向循环转向。

如果整条路径中的任意两段非相邻轨迹发生穿越、接触或重合，返回 true；否则返回 false。

函数形式：isSelfCrossing(distance: integer[]) -> boolean

示例 1

distance = [2,1,1,2]

输出：true

最后一段向东，与第一段在 (0, 1) 相交。

示例 2

distance = [1,2,3,4]

输出：false

路径持续向外展开，没有触碰此前轨迹。

示例 3

distance = [1,1,1,2,1]

输出：true

路径在后续移动中回到并触碰原点。

约束

  • 1 <= distance.length <= 105
  • 1 <= distance[i] <= 105

Solution

准备好分析规律了吗？

题解默认收起；展开后包含证明、复杂度、四种语言代码与面试追问。

O(n) / O(1)

局部几何：只需识别三种交叉

核心洞察

方向严格按北、西、南、东循环，线段始终与坐标轴平行。若第 i 段首次造成路径交叉，它只可能与附近的第 i-3、i-4 或 i-5 段相交；更早的线段被当前螺旋形态隔开。

因此不必保存坐标或建立线段集合，只需扫描距离数组并检查三个局部形态。比较使用 >= / <=，因为端点接触与共线重叠也属于交叉。

三种必要形态

  1. 第四边穿第一边：当前边跨过 i-3。
  2. 第五边贴住第一边：i-1 与 i-3 等长，当前边够长，形成接触或重叠。
  3. 第六边穿第一边：路径由外扩转为内收，当前边跨过 i-5。

完整过程

情况 1：与第 i-3 段交叉

d[i] >= d[i-2] 且 d[i-1] <= d[i-3]。

情况 2：与第 i-4 段接触或重叠

i >= 4，d[i-1] == d[i-3] 且 d[i] + d[i-4] >= d[i-2]。

情况 3：与第 i-5 段交叉

i >= 5，同时满足 d[i-2] >= d[i-4]、d[i]+d[i-4] >= d[i-2]、d[i-1] <= d[i-3]、d[i-1]+d[i-5] >= d[i-3]。

扫描决策

从 i = 3 开始。任一情况成立立即返回 true；扫描结束仍未命中则返回 false。

正确性说明

充分性：三组不等式分别描述当前轴对齐线段在两个坐标维度上覆盖目标线段，所以命中任一组时，两段必然穿越、接触或重合。

必要性：在第一次交叉前，逆时针路径只能处于持续外扩、由外扩向内收过渡、或持续内收。第一次交叉在这三种形态中分别对应 i-3、过渡时的 i-4、以及 i-5；更早线段被近邻边界隔开。因此若存在交叉，扫描必命中某一情况。

由充分性和必要性，算法返回值与路径是否自交等价。

边界与复杂度

  • 长度不足 4 时，不可能与非相邻线段相交。
  • 正方形回到原点、端点相触、同一直线部分重合，都应返回 true。
  • 每个下标只做常数次比较：时间复杂度 O(n)。
  • 只访问最近六个距离：额外空间复杂度 O(1)。

四种语言实现

class Solution {
    public boolean isSelfCrossing(int[] distance) {
        for (int i = 3; i < distance.length; i++) {
            // 情况 1：当前边与 i - 3 边交叉
            if (distance[i] >= distance[i - 2]
                    && distance[i - 1] <= distance[i - 3]) {
                return true;
            }

            // 情况 2：当前边与 i - 4 边接触或重叠
            if (i >= 4
                    && distance[i - 1] == distance[i - 3]
                    && distance[i] + distance[i - 4] >= distance[i - 2]) {
                return true;
            }

            // 情况 3：当前边与 i - 5 边交叉
            if (i >= 5
                    && distance[i - 2] >= distance[i - 4]
                    && distance[i] + distance[i - 4] >= distance[i - 2]
                    && distance[i - 1] <= distance[i - 3]
                    && distance[i - 1] + distance[i - 5] >= distance[i - 3]) {
                return true;
            }
        }
        return false;
    }
}

替代方案

可以显式维护每条线段的两个端点，并让新线段与所有旧的非相邻线段做轴对齐相交判断。实现直观，也适用于任意转向，但最坏时间复杂度为 O(n²)，保存线段还需 O(n) 空间，不适合 10⁵ 的数据规模。

常见错误

  • 只检查第 i-3 段，遗漏外扩转内收时的两种交叉。
  • 使用严格不等号，错误忽略端点接触或共线重叠。
  • 先生成全部坐标再两两比较，导致超时或额外内存开销。
  • 将相邻线段共享的转折端点误判为自交。

面试追问

  1. 为什么“第一次交叉”至多涉及前五条边？请按外扩、过渡、内收三阶段说明。
  2. 如果方向不再固定逆时针，而是由输入给出，应如何改为通用线段相交算法？
  3. 如果距离允许为 0，哪些相邻边或退化线段的判定需要调整？
  4. 如何返回第一次交叉的坐标以及参与交叉的两条线段下标？
