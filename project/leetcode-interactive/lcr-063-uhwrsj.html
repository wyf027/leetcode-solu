LCR 063 Medium Hash Table · String · Trie

SHORTEST ROOT MATCH

单词替换

词根是一把剪刀：沿着单词从左到右走，第一次碰到词根就立即停止。因为先碰到的，必然是能替换它的最短前缀。

TARGET

最短可用前缀

rat←rattled

建树：O(所有词根字符数)
查询：O(句子字符数)

01 / PROBLEM

把派生词换成最短词根

力扣题目 ↗

给定词根字典 dictionary 与由空格分隔的句子 sentence。如果一个词根是句中某个派生词的前缀，用最短的词根替换该派生词；没有匹配词根时保留原词。

样例 1

[cat, bat, rat]

the cattle was rattled by the battery

the cat was rat by the bat

何时停止？

走到 Trie 中带有“词尾”标记的节点时立即返回，不再继续匹配更长前缀。

为什么不用 startsWith 扫词根？

可以，但每个单词要遍历词根；Trie 把公共前缀共享，让查询跟单词长度同步。

03 / TRIE WALK

查询只做一件事：沿边走，首个词尾即答案

1

插入词根

每条边代表一个字符；共享的前缀只存一份。

2

扫描单词

字符对应的边不存在，说明没有词根能匹配。

3

首个词尾返回

不继续走，因此天然得到最短词根。

04 / SOLUTIONS

四种语言，同一条 Trie 思路

COMPLEXITY

时间 O(R + S)，空间 O(R)

R 是所有词根的字符数，S 是句子的字符数。每个字符至多被走过一次。

PITFALL

不要找到更长词根才返回

若 cat 和 cattle 都在字典里，派生词 cattles 必须替换为 cat。
