移除最多的同行或同列石头

Most Stones Removed with Same Row or Column — 先把石头看成关系网络，亲手移除它们，再揭开为什么答案只取决于连通分量。

中等并查集图哈希表非付费题

题目

二维整数坐标平面上放有 n 块石头，每个坐标最多一块。只要某块石头与一块仍留在平面上的石头同行或同列，就可以移除它。给定 stones[i] = [xᵢ, yᵢ]，返回最多能移除多少块。

示例 1

输入：stones = [[0,0],[0,1],[1,0],[1,2],[2,1],[2,2]]
输出：5
解释：可依次移除 [2,2]、[2,1]、[1,2]、[1,0]、[0,1]，最后保留 [0,0]。

示例 2

输入：stones = [[0,0],[0,2],[1,1],[2,0],[2,2]]
输出：3
解释：可移除 [2,2]、[2,0]、[0,2]；[0,0] 与 [1,1] 最终分别保留。

示例 3

输入：stones = [[0,0]]
输出：0
解释：只有一块石头，没有可与之同行或同列的另一块石头。

约束

  • 1 ≤ stones.length ≤ 1000
  • 0 ≤ xᵢ, yᵢ ≤ 10⁴
  • 任意两块石头的坐标不同。

Solution

题解：石头数 − 连通分量数

maximum removed = n − connected components

核心洞察

把每块石头视为图上的节点；两块石头同行或同列时存在联系。在任意一个连通分量中，总能沿关系逐步移除石头，直到只剩一块；最后一块无法再移除。因此每个分量恰好贡献一个必须保留的石头。

为什么用行列二分图

无需两两比较石头。把每个行坐标与列坐标当成不同类型的节点，每块 [x,y] 都连接“行 x”和“列 y”。用并查集合并它们；被石头使用到的行列节点中，根的数量就是石头关系网的连通分量数。

完整过程

  1. 为行节点和列节点建立互不冲突的键，例如字符串 r:x 与 c:y。
  2. 遍历每块石头，把对应的行节点与列节点合并；按秩或大小合并，并在查找时路径压缩。
  3. 把每块石头的行节点查找到最终根，放入集合。
  4. 若根集合大小为 components，返回 stones.length - components。

正确性证明

引理 1：同一连通分量最后至少留一块。若只剩一块，它不再有另一块同行或同列石头，所以不能移除。

引理 2：含 k 块石头的连通分量可以移除 k−1 块。取该分量的一棵生成树，反复选择叶子石头对应的边关系移除叶子；其父侧仍有石头提供合法的同行或同列伙伴。重复后只剩一个节点。

结论：每个分量恰好保留一块。若共有 c 个分量，则最多移除 n−c 块；算法计算的正是 c，因此返回值正确。

边界情况

  • 只有一块石头：一个分量，答案 0。
  • 所有石头互不同行且互不同列：每块独立，答案 0。
  • 所有石头同一行或同一列：一个分量，答案 n−1。
  • 坐标为 0 或 10⁴：字符串键不依赖偏移，不会冲突。

复杂度

设石头数为 n。并查集共有至多 2n 个有效行列节点。时间复杂度 O(n α(n))，其中 α 是反阿克曼函数；空间复杂度 O(n)。

替代方案

也可显式构造石头图后 DFS/BFS，但朴素两两判断需要 O(n²) 时间。按行列建立邻接索引可优化，却比二分图并查集更繁琐。

import java.util.*;

class Solution {
    private final Map<String, String> parent = new HashMap<>();
    private final Map<String, Integer> size = new HashMap<>();

    private String find(String x) {
        parent.putIfAbsent(x, x);
        size.putIfAbsent(x, 1);
        if (!parent.get(x).equals(x)) parent.put(x, find(parent.get(x)));
        return parent.get(x);
    }

    private void union(String a, String b) {
        String ra = find(a), rb = find(b);
        if (ra.equals(rb)) return;
        if (size.get(ra) < size.get(rb)) { String t = ra; ra = rb; rb = t; }
        parent.put(rb, ra);
        size.put(ra, size.get(ra) + size.get(rb));
    }

    public int removeStones(int[][] stones) {
        for (int[] s : stones) union("r:" + s[0], "c:" + s[1]);
        Set<String> roots = new HashSet<>();
        for (int[] s : stones) roots.add(find("r:" + s[0]));
        return stones.length - roots.size();
    }
}

var removeStones = function(stones) {
    const parent = new Map();
    const size = new Map();
    const find = (x) => {
        if (!parent.has(x)) { parent.set(x, x); size.set(x, 1); }
        if (parent.get(x) !== x) parent.set(x, find(parent.get(x)));
        return parent.get(x);
    };
    const union = (a, b) => {
        let ra = find(a), rb = find(b);
        if (ra === rb) return;
        if (size.get(ra) < size.get(rb)) [ra, rb] = [rb, ra];
        parent.set(rb, ra);
        size.set(ra, size.get(ra) + size.get(rb));
    };
    for (const [x, y] of stones) union(`r:${x}`, `c:${y}`);
    const roots = new Set(stones.map(([x]) => find(`r:${x}`)));
    return stones.length - roots.size;
};
from typing import List

class Solution:
    def removeStones(self, stones: List[List[int]]) -> int:
        parent = {}
        size = {}

        def find(x):
            if x not in parent:
                parent[x] = x
                size[x] = 1
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(a, b):
            ra, rb = find(a), find(b)
            if ra == rb:
                return
            if size[ra] < size[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            size[ra] += size[rb]

        for x, y in stones:
            union(("r", x), ("c", y))
        roots = {find(("r", x)) for x, _ in stones}
        return len(stones) - len(roots)
#include <vector>
#include <unordered_map>
#include <unordered_set>
using namespace std;

class Solution {
    unordered_map<int, int> parent, sz;
    int find(int x) {
        if (!parent.count(x)) { parent[x] = x; sz[x] = 1; }
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    void unite(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return;
        if (sz[ra] < sz[rb]) swap(ra, rb);
        parent[rb] = ra;
        sz[ra] += sz[rb];
    }
public:
    int removeStones(vector<vector<int>>& stones) {
        const int OFFSET = 10001;
        for (const auto& s : stones) unite(s[0], s[1] + OFFSET);
        unordered_set<int> roots;
        for (const auto& s : stones) roots.insert(find(s[0]));
        return static_cast<int>(stones.size() - roots.size());
    }
};

面试追问

  • 为什么不是“行数 + 列数”？ 因为答案由行列节点连接后的连通分量决定，而不是不同坐标的简单计数。
  • 如何在线加入石头？ 每次合并行列节点，维护当前有效连通分量数；新边连接两个新节点时增加一个分量，连接两个旧分量时减少一个。
  • 能否给出实际移除顺序？ 可以在每个石头分量构造生成树，再按叶子到根的顺序输出。

常见错误

  • 直接贪心删除当前伙伴最多的石头，缺少全局正确性依据。
  • 行坐标和列坐标使用同一整数命名空间，导致行 1 与列 1 被误认成同一节点。
  • 统计所有并查集节点的根，却忘了只应统计被石头实际使用的连通结构。
  • 误写为 n−1，忽略存在多个互不相连分量的情况。
