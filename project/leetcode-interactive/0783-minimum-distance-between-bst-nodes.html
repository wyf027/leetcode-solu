01 · Problem

题目说明

minDiffInBST(root) → integer

给你二叉搜索树的根节点 root，返回树中任意两个不同节点的值之间的最小差值。

对任意不同节点 u 与 v，比较 |u.val - v.val|，答案是这些差值中的最小者。

说明：题目将差值定义为两个节点值之差的绝对值。该题与 LeetCode 530「二叉搜索树的最小绝对差」相同。

约束

  • 树中节点数在 [2, 100] 范围内。
  • 0 <= Node.val <= 10^5。
  • root 是一棵有效二叉搜索树的根节点。

示例 1

输入
root = [4,2,6,1,3]
输出
1
解释
|2 - 1| = 1（其他相邻值对也可得到 1）

示例 2

输入
root = [1,0,48,null,null,12,49]
输出
1
解释
|1 - 0| = 1，且 |49 - 48| = 1

准备好看完整题解了吗？

题解包含核心洞察、正确性证明、复杂度、边界讨论、替代方案、面试追问、常见错误和四种语言的可提交实现。

Solution · Inorder Scan

中序遍历，一次扫描

时间 O(n) · 空间 O(h)

核心洞察

二叉搜索树的中序遍历结果是严格递增的有序序列。一个有序序列中的最小绝对差，一定出现在某一对相邻元素之间；所以无需比较所有节点对。

完整过程

  1. 按“左子树 → 当前节点 → 右子树”进行中序遍历。
  2. 用 prev 保存刚访问的前一个节点值。
  3. 若 prev 已存在，更新 ans = min(ans, current - prev)。
  4. 令 prev = current，继续遍历；最终返回 ans。

正确性证明

  1. 有序性：BST 的中序遍历按非降序访问全部节点；在标准严格 BST 中，序列严格递增。
  2. 相邻性：对有序序列中任意下标 i < j，若二者不相邻，则区间内至少有一个相邻差不大于 a[j] - a[i]。
  3. 完备性：算法恰好计算每一对中序相邻节点的差，并取其中最小值。
  4. 结论：算法返回值等于全部不同节点对绝对差的最小值。

边界与复杂度

  • 仅两个节点时，只会形成一个相邻差，直接成为答案。
  • 节点值可以为 0，不可用“prev === 0”判断前驱是否存在。
  • 时间复杂度 O(n)：每个节点访问一次。
  • 递归栈空间 O(h)：h 为树高；最坏为 O(n)，平衡树为 O(log n)。

替代方案

  • 收集后排序：任意 DFS 收集所有值，排序后扫描。时间 O(n log n)、额外空间 O(n)，直观但没有利用 BST 的有序性。
  • 暴力枚举：比较全部节点对，时间 O(n²)。约束较小时能工作，但面试中通常不是目标方案。
  • Morris 中序遍历：可将辅助空间降为 O(1)，但会临时改写树的指针，代码更复杂。

面试追问

  • 如果树不是 BST？收集值并排序，或维护有序集合。
  • 如果不能使用递归？用显式栈写迭代中序遍历。
  • 如果树极度倾斜？递归可能栈溢出，应优先迭代或 Morris 遍历。
  • 如果允许重复值？相邻重复值会让最小差直接变为 0。

常见错误

  • 只比较父子节点：最小差对应的两个值不一定存在直接父子关系。
  • 先更新 prev 再计算差值，导致当前值与自己相减。
  • 把 0 当成“尚无前驱”的哨兵；应使用 null / None 或独立布尔状态。
  • JavaScript / Java 中把答案初值设得太小；应使用安全的无穷大或最大整数。
  • 将普通二叉树的 DFS 访问顺序误认为有序；只有中序遍历利用了 BST 的排序性质。

Java

递归中序
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private Integer prev;
    private int answer = Integer.MAX_VALUE;

    public int minDiffInBST(TreeNode root) {
        inorder(root);
        return answer;
    }

    private void inorder(TreeNode node) {
        if (node == null) {
            return;
        }

        inorder(node.left);

        if (prev != null) {
            answer = Math.min(answer, node.val - prev);
        }
        prev = node.val;

        inorder(node.right);
    }
}

JavaScript

递归中序
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var minDiffInBST = function(root) {
    let previous = null;
    let answer = Number.POSITIVE_INFINITY;

    const inorder = (node) => {
        if (node === null) {
            return;
        }

        inorder(node.left);

        if (previous !== null) {
            answer = Math.min(answer, node.val - previous);
        }
        previous = node.val;

        inorder(node.right);
    };

    inorder(root);
    return answer;
};

class Solution:
    def minDiffInBST(self, root: Optional[TreeNode]) -> int:
        previous = None
        answer = float("inf")

        def inorder(node: Optional[TreeNode]) -> None:
            nonlocal previous, answer
            if node is None:
                return

            inorder(node.left)

            if previous is not None:
                answer = min(answer, node.val - previous)
            previous = node.val

            inorder(node.right)

        inorder(root)
        return int(answer)

C++

递归中序
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    TreeNode* previous = nullptr;
    int answer = INT_MAX;

    void inorder(TreeNode* node) {
        if (node == nullptr) {
            return;
        }

        inorder(node->left);

        if (previous != nullptr) {
            answer = min(answer, node->val - previous->val);
        }
        previous = node;

        inorder(node->right);
    }

public:
    int minDiffInBST(TreeNode* root) {
        inorder(root);
        return answer;
    }
};
