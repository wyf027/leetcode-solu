每种字符至少取 K 个

Take K of Each Character From Left and Right

只能从两端拿走字符。你能用最少的操作，让 a、b、c 各自达到目标吗？

查看 LeetCode 原题 ↗

01 / PROBLEM

任务说明

给定字符串 s 和非负整数 k。字符串只包含 a、b、c。每分钟可以取走当前字符串最左端或最右端的一个字符。目标是让取走的字符中，每种字符都至少有 k 个。

返回所需的最少分钟数；若无论如何都无法满足条件，返回 -1。两端选择可以交替，每次只能取一个字符。

参数与返回值

takeCharacters(s: string, k: integer) → integer
  • 1 ≤ s.length ≤ 10⁵
  • s 仅由字母 'a'、'b'、'c' 组成。
  • 0 ≤ k ≤ s.length

官方示例

示例 1

输入：s = "aabaaaacaabc", k = 2
输出：8

先取左端 3 个字符 aab，再取右端 5 个字符（对应原字符串后缀 caabc）。共取得 a × 4、b × 2、c × 2，用时 8 分钟，这是最少用时。

示例 2

输入：s = "a", k = 1
输出：-1

字符串里没有 b 和 c，无法各取到一个，因而无解。

03 / SOLUTION

把“最少取走”转成“最多留下”

取走的字符一定构成一个前缀和一个后缀，剩下的则是一个连续子串（也可以为空）。设字符 x 的总数为 total[x]，留下的个数为 window[x]，则取走的个数是 total[x] - window[x]。

取走每种字符至少 k 个 ⇔ 窗口中每种字符至多 limit[x] = total[x] - k 个。寻找满足上限的最长连续窗口，答案就是 n - best。

完整过程

  1. 统计 a、b、c 的总量。如果任一总量小于 k，直接返回 -1。
  2. 计算三种字符的保留上限，令 left = 0、best = 0，窗口计数归零。
  3. right 向右走一格，把 s[right] 放入窗口。如果该字符超过上限，就持续移走 s[left] 并右移 left，直到合法。
  4. 合法后用 right - left + 1 更新最长窗口长度。
  5. 遍历完成，返回 n - best。

只需检查新加入的字符：扩展前窗口合法，其他字符的计数没有增加，收缩只会减少计数。

沿着示例走一遍

在 s = "aabaaaacaabc", k = 2 中，总数为 a: 8、b: 2、c: 2，所以可保留上限是 a: 6、b: 0、c: 0。

窗口加入索引 2 的 b 后必须收缩，直到这个 b 被移出。随后索引 3–6 的 aaaa 可以完整留下，长度为 4；遇到索引 7 的 c 又必须收缩。最长合法窗口为 4，于是取走 12 - 4 = 8 个字符。

正确性

  1. 选择等价。 任意两端取字符的方案都对应一个留下的连续窗口；反过来，任意窗口都可以通过取走它左侧前缀和右侧后缀得到。取走条件与窗口上限完全等价。
  2. 窗口不漏解。 固定 right 时，收缩到首次合法便停止。比当前 left 更小的起点已因超限被舍弃，随着 right 增大，计数只会增加，这些起点不会重新合法。因此当前窗口是以 right 结尾的最长合法窗口。
  3. 全局最优。 遍历所有右端点并记录最大长度，就得到全局最长合法窗口。用 n 减去它，得到最少取走数量。若初始总量不足，任何方案都不可能满足，返回 -1 正确。

边界与复杂度

  • k = 0：整个字符串可留下，答案为 0。
  • 任一字符总数不足 k：返回 -1，即使另外两类很多也无法补足。
  • 总数恰好都是 k：保留上限均为 0，最长窗口为空，答案为 n。
  • 收缩后 left 可以等于 right + 1；此时窗口长度为 0，仍是合法状态。
  • 时间 O(n)：左右指针分别最多移动 n 次。额外空间 O(1)：仅维护三个计数。演示为了回退保存轨迹，其空间开销不属于提交算法。

替代方案

可以枚举取走的前缀长度，用后缀计数与二分寻找最短足量后缀，时间 O(n log n)、空间 O(n)。进一步利用后缀长度的单调变化，可以用两个指针做到 O(n)。直接枚举前后缀组合需要 O(n²)，仅适合小规模推导。

常见错误

  • 把“至少 k”理解成“恰好 k”：多取某种字符是允许的。
  • 将窗口上限写成 k：窗口是留下的字符，上限应为 total - k。
  • 用 if 代替 while：移走一个字符未必能解决超限。
  • 在窗口恢复合法前更新 best，或最后返回 best 而不是 n - best。
  • 总量不足时继续滑动：负上限代表无解，应在遍历前退出。

面试追问

  • 怎样返回具体方案？ 更新 best 时保存窗口起点 bestLeft，取左侧 bestLeft 个、右侧 n - bestLeft - best 个。
  • 每种字符的目标不同呢？ 将 k 替换成各字符独立的目标，窗口仍按对应 total - target 限制。
  • 字符集更大呢？ 固定字符集用数组，任意字符集用映射，空间变为 O(字符种类数)。
  • 左右操作成本不同呢？ 最长窗口未必最便宜；应在每个合法窗口上评估前缀长度和后缀长度对应的成本，不能直接返回 n - best。

Java

class Solution {
    public int takeCharacters(String s, int k) {
        int[] limit = new int[3];
        for (int i = 0; i < s.length(); i++) {
            limit[s.charAt(i) - 'a']++;
        }
        for (int i = 0; i < 3; i++) {
            if (limit[i] < k) return -1;
            limit[i] -= k;
        }
        int[] window = new int[3];
        int left = 0, best = 0;
        for (int right = 0; right < s.length(); right++) {
            int x = s.charAt(right) - 'a';
            window[x]++;
            while (window[x] > limit[x]) {
                window[s.charAt(left++) - 'a']--;
            }
            best = Math.max(best, right - left + 1);
        }
        return s.length() - best;
    }
}

class Solution:
    def takeCharacters(self, s: str, k: int) -> int:
        limit = [0, 0, 0]
        for ch in s:
            limit[ord(ch) - ord('a')] += 1
        for i in range(3):
            if limit[i] < k:
                return -1
            limit[i] -= k
        window = [0, 0, 0]
        left = best = 0
        for right, ch in enumerate(s):
            x = ord(ch) - ord('a')
            window[x] += 1
            while window[x] > limit[x]:
                window[ord(s[left]) - ord('a')] -= 1
                left += 1
            best = max(best, right - left + 1)
        return len(s) - best

C++

#include <algorithm>
#include <string>
using namespace std;

class Solution {
public:
    int takeCharacters(string s, int k) {
        int limit[3] = {0, 0, 0};
        for (char ch : s) ++limit[ch - 'a'];
        for (int i = 0; i < 3; ++i) {
            if (limit[i] < k) return -1;
            limit[i] -= k;
        }
        int window[3] = {0, 0, 0};
        int left = 0, best = 0;
        int n = static_cast<int>(s.size());
        for (int right = 0; right < n; ++right) {
            int x = s[right] - 'a';
            ++window[x];
            while (window[x] > limit[x]) {
                --window[s[left++] - 'a'];
            }
            best = max(best, right - left + 1);
        }
        return n - best;
    }
};
