04 / 独立题解

先想一想，再展开

如何避免重复扫描所有面试轮次？“工作经验”和“总得分”分别应该在哪个阶段判断？

先按面试聚合，再关联候选人

核心洞察

同一场面试的分数散落在多条记录中。将每个 interview_id 压缩成一个总分，就能用一次关联把录取分数条件带回候选人表。经验是单行条件，分数是聚合后的条件。

完整过程

  1. 遍历或扫描 Rounds，按 interview_id 累加 score。即使两轮得分相同，也分别计入。
  2. 在聚合结果上保留 SUM(score) > 15 的面试 ID。
  3. 将这个结果与 Candidates 按 interview_id 连接。聚合子查询每个面试只有一行，不会扩增候选人。
  4. 筛掉 years_of_exp < 2 的候选人，只投影 candidate_id。

示例四个分数桶为 101→16、104→22、109→10、107→6。分数合格的是 101 和 104；关联经验后只留下候选人 9。

正确性

聚合不变式：扫描前 k 条轮次后，每个桶等于这 k 条中同面试记录的分数和。初始桶为空；读到新轮次时只为所属面试加入其分数，因此不变式保持。扫描结束就得到完整总分。

可靠性：输出行必须关联到总分大于 15 的面试，并通过经验至少 2 年的过滤，因此所有输出都满足题意。完备性：任何符合题意的候选人，其面试必在合格聚合结果中，连接与经验过滤都不会丢弃该候选人。候选人主键唯一且聚合每个面试只有一行，因此每个 ID 只输出一次。

边界与常见错误

  • 总分等于 15 不录取；年限等于 2 可以录取。别写反严格和非严格比较。
  • 没有轮次的面试无法得到大于 15 的总分；内连接自然将其排除。
  • 用 SUM(score)，不是 COUNT(*)、AVG(score) 或 SUM(DISTINCT score)。两次 8 分合计 16。
  • 不要在 WHERE 里直接写 SUM(score)；分组条件属于 HAVING。
  • 不能只按 round_id 分组；也不能假设候选人表的 interview_id 唯一，然后任意选一个 candidate_id。
  • 输入顺序和输出顺序均不影响语义；无需 ORDER BY。
  • SQL 的 SUM 忽略 NULL，全为空则不能通过 > 15。四语言参考采用非空整数输入，不模拟数据库 NULL；JavaScript 还要求安全整数，Java/C++ 累加使用 64 位整数，仍受类型范围限制。

复杂度

设候选人数为 C、轮次数为 R、不同面试数为 I。哈希聚合后关联的预期时间为 O(R + C)，辅助空间 O(I)，另需 O(K) 保存 K 个输出。SQL 的真实成本由执行计划决定：排序聚合可能需要 O(R log R)，磁盘读取、索引和连接方式也会影响耗时；不能把逻辑扫描复杂度当作数据库执行保证。

替代方案

先 JOIN 两张表，再用 WHERE 过滤经验，按 candidate_id 分组，最后 HAVING SUM(score) > 15，同样正确。主解先聚合能避免多个候选人共享面试时重复展开轮次。相关子查询逐个候选人求和更直观，但若没有合适索引或优化，可能退化到 O(CR)。

面试追问

  • 如果改成“每轮都超过 5 分”？按面试求 MIN(score) 并明确 NULL 与无轮次的业务规则。
  • 如果分数可能重复导入？先依据 (interview_id, round_id) 主键处理数据质量，不能用 DISTINCT score 去重。
  • 如何优化大表？检查 Rounds.interview_id 的索引和实际执行计划；完整汇总仍可能需要扫描大量轮次。
  • 如果要显示不合格原因？保留候选人，用 LEFT JOIN 带回总分，明确无轮次的显示值，再用 CASE 生成原因。

MySQL · 官方可提交语言

SELECT c.candidate_id
FROM Candidates AS c
JOIN (
    SELECT interview_id
    FROM Rounds
    GROUP BY interview_id
    HAVING SUM(score) > 15
) AS qualified ON qualified.interview_id = c.interview_id
WHERE c.years_of_exp >= 2;

Java · 本地语义参考

import java.util.*;

class Solution {
    // candidates: [candidate_id, name, years_of_exp, interview_id]
    // rounds: [interview_id, round_id, score]; non-null integer fields
    public List<Integer> acceptedCandidates(Object[][] candidates, int[][] rounds) {
        Map<Integer, Long> totals = new HashMap<>();
        for (int[] r : rounds) {
            totals.merge(r[0], (long) r[2], Long::sum);
        }
        List<Integer> result = new ArrayList<>();
        for (Object[] c : candidates) {
            int id = ((Number) c[0]).intValue();
            int years = ((Number) c[2]).intValue();
            int interview = ((Number) c[3]).intValue();
            if (years >= 2 && totals.getOrDefault(interview, 0L) > 15) {
                result.add(id);
            }
        }
        return result;
    }
}

JavaScript · 本地语义参考

// candidates: [candidate_id, name, years_of_exp, interview_id][]
// rounds: [interview_id, round_id, score][]
// Numeric inputs and accumulated scores must be safe integers.
function acceptedCandidates(candidates, rounds) {
    const totals = new Map();
    for (const [interviewId, , score] of rounds) {
        totals.set(interviewId, (totals.get(interviewId) ?? 0) + score);
    }
    return candidates
        .filter(([, , years, interviewId]) =>
            years >= 2 && (totals.get(interviewId) ?? 0) > 15)
        .map(([candidateId]) => candidateId);
}

Python · 本地语义参考（非 Pandas 提交）

from collections import defaultdict

def accepted_candidates(candidates, rounds):
    """Rows: candidates=[id,name,years,interview], rounds=[interview,round,score]."""
    totals = defaultdict(int)
    for interview_id, round_id, score in rounds:
        totals[interview_id] += score
    return [candidate_id
            for candidate_id, name, years, interview_id in candidates
            if years >= 2 and totals[interview_id] > 15]

C++17 · 本地语义参考

#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

struct Candidate {
    int candidate_id;
    string name;
    int years_of_exp;
    int interview_id;
};
struct Round {
    int interview_id;
    int round_id;
    int score;
};
class Solution {
public:
    vector<int> acceptedCandidates(const vector<Candidate>& candidates,
                                   const vector<Round>& rounds) {
        unordered_map<int, long long> totals;
        for (const auto& r : rounds) totals[r.interview_id] += r.score;
        vector<int> result;
        for (const auto& c : candidates) {
            auto it = totals.find(c.interview_id);
            if (c.years_of_exp >= 2 && it != totals.end() && it->second > 15)
                result.push_back(c.candidate_id);
        }
        return result;
    }
};
