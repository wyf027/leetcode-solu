Disconnect Path in a Binary Matrix by at Most One Flip

只向右或向下穿过值为 1 的格子。你能否只改动至多一个非端点格子，让起点与终点彻底失联？

01
Problem

题目

把矩阵看作一张只能向右、向下行走的有向图。

任务描述

给定一个下标从 0 开始的 m × n 二进制矩阵 grid。从格子 (row, col) 只能移动到值为 1 的 (row + 1, col) 或 (row, col + 1)。

若不存在从 (0, 0) 到 (m - 1, n - 1) 的路径，矩阵就是不连通的。

你最多可以翻转一个格子（也可以不翻转），但不能翻转起点和终点。若能使矩阵不连通，返回 true；否则返回 false。

翻转会令 0 ↔ 1。目标是判断“是否存在可行翻转”，不是求具体翻转位置。

函数与约束

isPossibleToCutPath(grid: integer[][]): boolean
  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 1000
  • 1 ≤ m × n ≤ 10⁵
  • grid[i][j] 为 0 或 1
  • grid[0][0] == grid[m - 1][n - 1] == 1

04
Solution

题解：找一条路，抹掉，再找一次

单次翻转能否切断路径，本质上取决于是否还存在一条不使用首条路径内部格子的完整通路。

核心洞察

只把 1 → 0 纳入考虑即可：把 0 翻成 1 只会增加通路，不可能帮助断开。先用一次 DFS 找到任意一条起点到终点的路径，并把搜索访问到的 1 原地清零；随后恢复起点和终点，再搜索一次。

  • 第一次就找不到路：矩阵本来已断开，返回 true。
  • 第二次找不到路：存在一个非端点格子可作为单点割，返回 true。
  • 第二次仍能到达：有两条内部点不相交的路径，单次翻转切不断，返回 false。

完整过程

  1. 从起点迭代 DFS，只扩展下方与右方的值为 1 的格子；入栈时立即清零，既代表访问过，也剥离路径。
  2. 若搜索失败，说明原图不连通，不用翻转即可满足题意。
  3. 若成功，把起点和终点恢复为 1；它们不允许翻转，不能被当作切点。
  4. 在剩余格子上再次执行相同搜索。第二次失败则可切断，成功则不可切断。

正确性说明

若第二次搜索成功：第二条路不经过第一次搜索清零的任何内部格子，因此至少有两条内部点不相交的起终点路径。翻转任意一个非端点格子至多破坏其中一条，另一条仍连通，所以答案为 false。

若第二次搜索失败：在只能向右、向下的分层有向网格中，不存在两条内部点不相交的起终点路径。由点版本的 Menger 定理，存在一个内部格子命中所有路径；翻转该格子即可断开，所以答案为 true。

DFS 入栈即清零的额外格子都是已经无法到达终点的死路，不会误删一条可行的第二路径。

复杂度与边界

时间：O(mn)。每个格子在两次搜索中至多处理一次。

额外空间：O(m + n)，显式 DFS 栈的深度不超过一条单调路径长度；矩阵本身兼作访问标记。

  • 1 × 1：唯一格子同时是起终点且不能翻转，答案为 false。
  • 单行或单列：有内部格子时可切断；只有两个端点时不可切断。
  • 输入矩阵会被原地修改；若调用方还需要原矩阵，应先复制。

四语言完整代码

均使用显式栈，避免长路径导致递归栈限制。

import java.util.ArrayDeque;

class Solution {
    public boolean isPossibleToCutPath(int[][] grid) {
        if (!erasePath(grid)) return true;
        int m = grid.length, n = grid[0].length;
        grid[0][0] = 1;
        grid[m - 1][n - 1] = 1;
        return !erasePath(grid);
    }

    private boolean erasePath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        if (grid[0][0] == 0) return false;

        ArrayDeque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[]{0, 0, 0});
        grid[0][0] = 0;

        while (!stack.isEmpty()) {
            int[] top = stack.peek();
            int r = top[0], c = top[1];
            if (r == m - 1 && c == n - 1) return true;

            int nr, nc;
            if (top[2] == 0) {
                top[2] = 1;
                nr = r + 1; nc = c;
            } else if (top[2] == 1) {
                top[2] = 2;
                nr = r; nc = c + 1;
            } else {
                stack.pop();
                continue;
            }

            if (nr < m && nc < n && grid[nr][nc] == 1) {
                grid[nr][nc] = 0;
                stack.push(new int[]{nr, nc, 0});
            }
        }
        return false;
    }
}

var isPossibleToCutPath = function (grid) {
    const erasePath = () => {
        const m = grid.length, n = grid[0].length;
        if (grid[0][0] === 0) return false;

        const stack = [[0, 0, 0]];
        grid[0][0] = 0;

        while (stack.length) {
            const top = stack[stack.length - 1];
            const [r, c] = top;
            if (r === m - 1 && c === n - 1) return true;

            let nr, nc;
            if (top[2] === 0) {
                top[2] = 1;
                nr = r + 1; nc = c;
            } else if (top[2] === 1) {
                top[2] = 2;
                nr = r; nc = c + 1;
            } else {
                stack.pop();
                continue;
            }

            if (nr < m && nc < n && grid[nr][nc] === 1) {
                grid[nr][nc] = 0;
                stack.push([nr, nc, 0]);
            }
        }
        return false;
    };

    if (!erasePath()) return true;
    const m = grid.length, n = grid[0].length;
    grid[0][0] = grid[m - 1][n - 1] = 1;
    return !erasePath();
};
from typing import List


class Solution:
    def isPossibleToCutPath(self, grid: List[List[int]]) -> bool:
        m, n = len(grid), len(grid[0])

        def erase_path() -> bool:
            if grid[0][0] == 0:
                return False

            stack = [[0, 0, 0]]
            grid[0][0] = 0

            while stack:
                r, c, direction = stack[-1]
                if r == m - 1 and c == n - 1:
                    return True

                if direction == 0:
                    stack[-1][2] = 1
                    nr, nc = r + 1, c
                elif direction == 1:
                    stack[-1][2] = 2
                    nr, nc = r, c + 1
                else:
                    stack.pop()
                    continue

                if nr < m and nc < n and grid[nr][nc] == 1:
                    grid[nr][nc] = 0
                    stack.append([nr, nc, 0])

            return False

        if not erase_path():
            return True
        grid[0][0] = grid[m - 1][n - 1] = 1
        return not erase_path()

#include <vector>
using namespace std;

class Solution {
public:
    bool isPossibleToCutPath(vector<vector<int>>& grid) {
        if (!erasePath(grid)) return true;
        int m = grid.size(), n = grid[0].size();
        grid[0][0] = 1;
        grid[m - 1][n - 1] = 1;
        return !erasePath(grid);
    }

private:
    bool erasePath(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        if (grid[0][0] == 0) return false;

        vector<array<int, 3>> stack{{0, 0, 0}};
        grid[0][0] = 0;

        while (!stack.empty()) {
            auto& top = stack.back();
            int r = top[0], c = top[1];
            if (r == m - 1 && c == n - 1) return true;

            int nr, nc;
            if (top[2] == 0) {
                top[2] = 1;
                nr = r + 1; nc = c;
            } else if (top[2] == 1) {
                top[2] = 2;
                nr = r; nc = c + 1;
            } else {
                stack.pop_back();
                continue;
            }

            if (nr < m && nc < n && grid[nr][nc] == 1) {
                grid[nr][nc] = 0;
                stack.push_back({nr, nc, 0});
            }
        }
        return false;
    }
};

替代方案

按对角线计数：分别计算每格从起点可达、且能到终点；若某条中间对角线只有一个同时满足条件的格子，它就是必经点。思路直观，但通常需要额外的 O(mn) 状态。

最大流 / 点割：拆点后求最小点割可以解决一般图，但对这个单调网格明显过重。两次 DFS 已利用了题目的特殊结构。

常见错误

  • 翻转起点或终点；题目明确禁止。
  • 把第二次搜索前的所有格子都恢复，导致又走回同一路径。
  • 使用深递归却忽略语言栈限制。
  • 认为翻成 1 可能帮助断开；新增边只会让连通性增强。
  • 只数路径条数；路径很多也可能共享同一个必经格子。

面试追问

  • 如果允许翻转最多 k 个格子，如何转化为最小点割？
  • 若允许四方向移动，为什么“两次 DFS”不再能直接照搬？
  • 若不能修改输入，怎样在时间不变的前提下保存访问状态？
  • 如何输出一个实际可翻转的必经格子，而不只返回布尔值？

一句话记忆

剥掉一条路；若还能走通，就不是一次翻转能切断的。

关键限定：只能向右、向下，且起终点不可翻转。
