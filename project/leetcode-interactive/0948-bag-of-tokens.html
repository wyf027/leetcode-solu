Bag of Tokens

先观察能量与分数如何交换，再决定何时揭开贪心策略。

题目

给定整数数组 tokens 和初始能量 power，初始分数为 0。每枚尚未使用的令牌只能选择一种方式：能量不少于令牌值时，可正面使用，消耗对应能量并获得 1 分；分数至少为 1 时，可反面使用，失去 1 分并获得对应能量。可以使用任意数量的令牌，返回能达到的最高分数。

函数签名

bagOfTokensScore(tokens: integer[], power: integer) -> integer
示例 1
tokens = [100], power = 50
输出：0
既买不起令牌，也没有分数换能量。
示例 2
tokens = [200,100], power = 150
输出：1
将 100 正面使用，能量变 50，分数变 1。
示例 3
tokens = [100,200,300,400], power = 200
输出：2
依次：100 正面、400 反面、200 正面、300 正面。

约束

  • 0 <= tokens.length <= 1000
  • 0 <= tokens[i], power < 10⁴

题解：排序 + 双指针贪心

核心洞察

想用能量换分时，支付当前最小令牌最划算；能量不够且已有分数时，用当前最大令牌换回能量收益最大。每次决策都只需关注排序后区间的两端。

完整过程

  1. 升序排序，令 left = 0、right = n - 1。
  2. 若能量足够，正面使用最小令牌，分数加一，左指针右移，并更新最高分。
  3. 否则若至少有一分且仍有未用令牌，反面使用最大令牌，分数减一，右指针左移。
  4. 两种操作都不可行则停止。

正确性

在所有可正面使用的令牌中，选择最小值消耗最少，不会削弱后续可行性；需要卖分换能量时，选择最大值获得最多能量，不会比卖出其他令牌更差。因此可将任意最优方案的下一步交换为上述选择而不降低最终最高分。重复交换直至区间为空，算法得到最优值。

边界

  • 空数组直接返回 0。
  • 初始能量不足且分数为 0，立即停止。
  • 令牌值为 0 时可免费获得分数。
  • 记录历史最高分，因为反面使用会临时降低当前分数。

复杂度

排序耗时 O(n log n)；双指针扫描 O(n)。除排序所需空间外，额外空间 O(1)（具体排序实现可能使用额外空间）。

替代方案与面试追问

暴力搜索每枚令牌的两种方向会产生指数级状态，不适用于 1000 个令牌。追问：为什么反面操作后不立即更新答案？因为它必然让当前分数下降；答案只需在正面得分后更新。还能讨论原地排序是否允许，以及如何返回具体操作序列。

常见错误

  • 没排序就使用双指针。
  • 能量不足时无条件卖分，导致分数变负。
  • 返回最终分数而非历史最高分。
  • 左右指针相遇后仍将同一令牌使用两次。

四语言完整代码

import java.util.Arrays;

class Solution {
    public int bagOfTokensScore(int[] tokens, int power) {
        Arrays.sort(tokens);
        int left = 0, right = tokens.length - 1;
        int score = 0, best = 0;
        while (left <= right) {
            if (power >= tokens[left]) {
                power -= tokens[left++];
                best = Math.max(best, ++score);
            } else if (score > 0) {
                power += tokens[right--];
                score--;
            } else break;
        }
        return best;
    }
}

from typing import List

class Solution:
    def bagOfTokensScore(self, tokens: List[int], power: int) -> int:
        tokens.sort()
        left, right = 0, len(tokens) - 1
        score = best = 0
        while left <= right:
            if power >= tokens[left]:
                power -= tokens[left]
                left += 1
                score += 1
                best = max(best, score)
            elif score > 0:
                power += tokens[right]
                right -= 1
                score -= 1
            else:
                break
        return best
