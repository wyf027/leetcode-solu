将数组分成两个数组
并最小化数组和的差

Partition Array Into Two Arrays to Minimize Sum Difference

数量相等，和尽量接近。先观察，再展开底部题解。

官方题目 ↗

题目与约束

给定长度为 2 * n 的整数数组 nums，将每个元素恰好放入 A 或 B，使两个数组长度都为 n。不要求连续。返回两个数组元素和之差的绝对值的最小值。

  • 1 ≤ n ≤ 15
  • nums.length == 2 * n
  • −10⁷ ≤ nums[i] ≤ 10⁷

官方示例 1

输入：nums = [3,9,7,3]
输出：2
最优划分之一：[3,9] 与 [7,3]，|12−10| = 2。

官方示例 2

输入：nums = [-36,36]
输出：72
划分：[-36] 与 [36]，|−36−36| = 72。

官方示例 3

输入：nums = [2,-1,0,4,-2,-9]
输出：0
最优划分之一：[2,4,-9] 与 [-1,0,-2]，两边和均为 −3。

题解 · 按人数分桶的折半搜索

核心洞察

总和记作 T，选入 A 的和为 S，差值就是 |T−2S|。需要恰好选 n 个，使 S 尽可能接近 T/2。值域很大，但每半边至多 15 个元素，可以枚举半边子集。

完整过程

  1. 按位置将输入切成长度均为 n 的左右半区。这不是最终分组。
  2. 枚举每边的所有子集，按元素个数保存和：L[k] 与 R[k]。空集也要记录。
  3. 将每个右桶升序排序。
  4. 对左桶 L[k] 的每个和 a，仅在 R[n−k] 搜索目标 T/2−a。
  5. 二分找第一个不小于目标的值，检查该位置和前驱，取全局最小差。

示例 1 中 T=22，左边选 3 时右边目标是 8。右桶 [3,7] 中最近值为 7，得到 A 和为 10，B 和为 12，差为 2。

正确性

每个合法 A 都由左边 k 元素子集和右边 n−k 元素子集组成。按互补人数桶枚举覆盖所有合法分组，并保证人数正确。固定左和 a 后，差值等于 2|b−(T/2−a)|，有序右桶中最接近目标的元素必然是插入位置或其前驱。对每个 a 检查这两项，再取最小值，即为全局最优。

边界

负数不影响排序与二分。n=1、全零、重复值、k=0 和 k=n 均自然覆盖。目标可能是半整数，不能随意向零取整。二分位置可能为桶长度，访问前必须检查边界。Java/C++ 用 64 位中间值；JavaScript Number 在本题范围内精确，掩码最多使用 15 位。

复杂度

以原数组长度 2n 计，枚举 O(n·2ⁿ)，排序与全部二分 O(n·2ⁿ)，总时间 O(n·2ⁿ)，额外空间 O(2ⁿ)。

替代方案

左右桶都排序后，可用双指针匹配互补人数桶，匹配阶段线性，整体仍受排序限制。小值域变体可考虑按人数和数值和做动态规划，本题的负数及大值域使其不划算。直接枚举全部 n 元素组合需要 C(2n,n) 个候选。

常见错误

  • 只让和接近，忘记人数必须相等。
  • 把物理左右半区直接当作最终 A、B。
  • 漏掉空集、二分前驱或边界判断。
  • JavaScript 默认排序按字符串比较；应提供数值比较器。
  • 对负数目标做错误的整数截断。

面试追问

如何返回分组？ 桶中同时保存子集掩码，更新答案时记录两个掩码，其余下标归 B。改为选 m 个？ 配对 k 与 m−k 并过滤非法桶。能去重吗？ 只求最小差可以按和去重，返回方案时保留一个对应掩码。

四语言完整实现

Java

import java.util.*;
class Solution {
 public int minimumDifference(int[] nums) {
  int n=nums.length/2; long T=0,ans=Long.MAX_VALUE;
  for(int x:nums)T+=x;
  List<List<Long>> L=new ArrayList<>(),R=new ArrayList<>();
  for(int k=0;k<=n;k++){L.add(new ArrayList<>());R.add(new ArrayList<>());}
  for(int m=0;m<(1<<n);m++){
   int k=0;long a=0,b=0;
   for(int i=0;i<n;i++)if((m&(1<<i))!=0){k++;a+=nums[i];b+=nums[n+i];}
   L.get(k).add(a);R.get(k).add(b);
  }
  for(List<Long> v:R)Collections.sort(v);
  for(int k=0;k<=n;k++)for(long a:L.get(k)){
   List<Long> v=R.get(n-k);int lo=0,hi=v.size();
   while(lo<hi){int mid=(lo+hi)/2;if(2*(a+v.get(mid))<T)lo=mid+1;else hi=mid;}
   for(int j=lo-1;j<=lo;j++)if(j>=0&&j<v.size())ans=Math.min(ans,Math.abs(T-2*(a+v.get(j))));
  }
  return (int)ans;
 }
}

Python

from typing import List
from bisect import bisect_left
class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n, T = len(nums)//2, sum(nums)
        L, R = [[] for _ in range(n+1)], [[] for _ in range(n+1)]
        for m in range(1 << n):
            k = a = b = 0
            for i in range(n):
                if m & (1 << i):
                    k += 1
                    a += nums[i]
                    b += nums[n+i]
            L[k].append(a)
            R[k].append(b)
        for v in R:
            v.sort()
        ans = float('inf')
        for k in range(n+1):
            v = R[n-k]
            for a in L[k]:
                j = bisect_left(v, T/2-a)
                for q in (j-1,j):
                    if 0 <= q < len(v):
                        ans = min(ans, abs(T-2*(a+v[q])))
        return ans
