702. 搜索长度未知的有序数组

你看不见数组长度，只能向读取器询问某个下标。目标仍藏在一条严格递增的数轴上——先在实验台里观察它如何回应，再决定怎样搜索。

Search in a Sorted Array of Unknown Size

Problem brief

题意

给定一个按严格升序排列、但长度未知的整数数组 secret，以及整数 target。你不能直接访问数组，只能调用 ArrayReader.get(index)：下标有效时返回对应元素，越界时返回 231 - 1。

若目标存在，返回它的下标；否则返回 -1。

Contract

约束与读取器行为

  • 1 ≤ secret.length ≤ 104
  • -104 ≤ secret[i], target ≤ 104
  • secret 中的所有整数互不相同，且严格升序排列。
  • 有效下标返回 secret[index]；下标越界返回 231 - 1。

Full solution

题解：扩张边界，再做二分

核心洞察

普通二分需要右边界。长度未知时，从小下标开始，让右边界按倍数增长，直到 reader.get(right) ≥ target。此时右端要么已经到达一个不小于目标的元素，要么越界并得到更大的哨兵；两种情况都保证目标若存在，必在当前有限区间内。

完整过程

  1. 令 left = 0、right = 1。
  2. 当 get(right) < target 时，丢弃到 right 为止的区间，令 left = right + 1，并将 right 翻倍。
  3. 在最终的 [left, right] 上执行标准二分。读取到哨兵时，它自然走“值过大”的分支。
  4. 命中返回下标；区间变空则返回 -1。

正确性证明

边界扩张阶段不丢失答案：只有当 get(right) < target 时才越过右边界。由于数组严格递增，下标不大于该 right 的元素都小于目标，因此被排除部分不可能含有目标。

扩张结束后覆盖答案：循环结束意味着 get(right) ≥ target，其中越界哨兵也满足该关系；而此前排除部分均小于目标。因此目标若存在，必位于当前 [left, right]。

二分阶段返回正确结果：每轮比较中，严格递增性允许安全排除不可能的一半，并保持“目标若存在则仍在闭区间内”的不变式。命中时返回的下标正确；区间为空时，不变式说明目标不存在，返回 -1。故算法正确。

时间复杂度O(log p)

p 为目标下标；若目标不存在，可理解为与跨过数组末端所需的扩张尺度同阶。

额外空间O(1)

只维护常数个边界与中点变量。

边界与实现细节

  • 目标小于首元素时，不进行扩张，二分仍可正确返回 -1。
  • 单元素数组也能工作：对下标 1 的读取只得到哨兵。
  • 题目保证合法值和目标远小于 231-1，哨兵不会与目标混淆。
  • 给定长度上限下边界翻倍不会溢出；若移植到无上限场景，应在翻倍前做整数溢出保护。

替代方案

若直接利用题目给出的 secret.length ≤ 104，可以把 right 固定为 10000 再二分，仍是正确的。但它依赖具体约束，无法体现“长度未知”的通用处理；倍增搜索更稳健，也能把搜索区间控制在目标位置的常数倍。

常见错误

  • 把右边界每次只加 1，最坏退化为线性探测。
  • 扩张后仍从 0 开始二分，虽然可能正确，但浪费已知被排除的信息。
  • 写成 while (get(right) != sentinel)，这只是在找数组末端，没有利用目标大小。
  • 更新二分边界时没有加减 1，导致死循环。

面试追问

  • 如果读取器调用代价很高，怎样缓存已读位置以减少重复 I/O？
  • 若存在重复元素并要求第一个目标下标，第二阶段如何改成 lower bound？
  • 若读取器没有越界哨兵、而是抛异常，接口层怎样安全封装比较？
  • 若下标可能接近整数上限，边界翻倍怎样防溢出？

四语言完整代码

下列代码假定 LeetCode 已提供 ArrayReader 接口。

JavaSolution.search
// ArrayReader is provided by the judge.
class Solution {
    public int search(ArrayReader reader, int target) {
        int left = 0;
        int right = 1;

        while (reader.get(right) < target) {
            left = right + 1;
            right *= 2;
        }

        while (left <= right) {
            int mid = left + (right - left) / 2;
            int value = reader.get(mid);
            if (value == target) {
                return mid;
            }
            if (value < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return -1;
    }
}
