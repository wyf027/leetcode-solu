844. 比较含退格的字符串

Backspace String Compare

EASY双指针字符串模拟栈

01题目

给定两个字符串 s 和 t，把它们分别输入到初始为空的文本编辑器。字符 # 表示一次退格：删除当前文本末尾的一个字符；如果文本已经为空，则仍保持为空。判断两次输入结束后的文本是否相同。

函数形式：backspaceCompare(s: string, t: string): boolean
示例 1 输入：s = "ab#c", t = "ad#c" 输出：true 解释：两者最终都是 "ac"。
示例 2 输入：s = "ab##", t = "c#d#" 输出：true 解释：两者最终都是空字符串。
示例 3 输入：s = "a#c", t = "b" 输出：false 解释：最终分别为 "c" 和 "b"。

约束

  • 1 <= s.length, t.length <= 200
  • s 与 t 仅包含小写英文字母和 #。
进阶：尝试在 O(n) 时间、O(1) 额外空间内完成。

02从末尾穿过“退格风暴”

先观察，不急着看题解：两名指针从右向左移动；遇到 # 就积累一次“跳过额度”，遇到普通字符则优先消耗额度。只有未被跳过的字符才参与比较。

03完整题解

核心洞察

最终字符串中最后一个有效字符，可以从原字符串末尾直接找到。倒序扫描时，用 skip 记录尚未生效的退格数量：看到 # 就令 skip++；看到字母且 skip > 0 就跳过它并令 skip--；否则它就是下一个有效字符。

分别为 s、t 找到下一个有效字符并比较。若不同，立即返回 false；若二者都耗尽，返回 true。这样不用真的构造编辑后的字符串。

完整过程

  1. 令 i = s.length - 1、j = t.length - 1。
  2. 在 s 中倒序跳过退格符以及被退格删除的字母，直到 i 指向有效字母或越界。
  3. 用相同规则处理 t，得到 j。
  4. 若只有一个指针越界，最终文本长度不同；若二者字符不同，内容不同，均返回 false。
  5. 若二者都越界，所有有效字符均相同，返回 true；否则令 i--, j--，继续下一轮。
正确性

每次内层扫描结束时，指针要么越界，要么停在当前尚未比较的最右有效字符上，因为右侧每个 # 都恰好抵消其左侧最近的一个未抵消字母。外层循环按从右到左的顺序比较两份最终文本的全部字符：任一处不等就正确拒绝；同时耗尽则说明长度与对应字符都相等，故算法正确。

复杂度

每个指针只向左移动，每个字符至多访问一次，时间复杂度 O(|s| + |t|)；只使用常数个变量，额外空间复杂度 O(1)。

边界情况

  • 开头或连续出现退格，例如 "###a"，多余退格不会产生负面效果。
  • 所有字符都被删除，例如 "ab##"。
  • 一个字符串先耗尽、另一个仍有有效字符。
  • 原始长度不同但最终文本相同，例如 "a#c" 与 "c"。

替代方案

可用两个栈（或两个动态字符串）正序模拟输入：字母入栈，# 时弹出栈顶，最后比较结果。思路直观，时间仍为 O(|s|+|t|)，但需要 O(|s|+|t|) 额外空间，不满足进阶要求。

面试追问

  • 如果退格符变成“删除前 k 个字符”，如何扩展跳过额度？
  • 如果输入来自只能向前读取的流，常数空间方案是否仍可行？
  • 如果字符串包含 Unicode 组合字符，应按字节、码点还是用户感知字符退格？

常见错误

  • 只跳过 #，却忘记跳过被它删除的普通字符。
  • 在处理连续 # 时过早停止内层循环。
  • 比较字符前没有判断某个指针是否已经越界。
  • 倒序时混淆 skip++ 与 skip-- 的时机。

class Solution {
    public boolean backspaceCompare(String s, String t) {
        int i = s.length() - 1;
        int j = t.length() - 1;

        while (i >= 0 || j >= 0) {
            int skipS = 0;
            while (i >= 0) {
                if (s.charAt(i) == '#') {
                    skipS++;
                    i--;
                } else if (skipS > 0) {
                    skipS--;
                    i--;
                } else {
                    break;
                }
            }

            int skipT = 0;
            while (j >= 0) {
                if (t.charAt(j) == '#') {
                    skipT++;
                    j--;
                } else if (skipT > 0) {
                    skipT--;
                    j--;
                } else {
                    break;
                }
            }

            if (i >= 0 && j >= 0) {
                if (s.charAt(i) != t.charAt(j)) return false;
            } else if (i >= 0 || j >= 0) {
                return false;
            }
            i--;
            j--;
        }
        return true;
    }
}
