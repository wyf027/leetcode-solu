每个产品在不同商店的价格

EASY1795 · Rearrange Products Table

同一份商品目录，换一种表达方式。先理解输入与输出，再亲手观察价格如何迁移。

01 / 题意与数据契约

Products 每行对应一个产品，存储它在 store1、store2、store3 的价格。请输出三列 (product_id, store, price)，每行对应一个实际有售的“产品—商店”组合。价格为 NULL 表示缺货，此组合不出现在结果中。结果顺序任意。

列类型含义

store1int商店 1 的价格，可为 NULL
store2int商店 2 的价格，可为 NULL
store3int商店 3 的价格，可为 NULL

官方未给出行数、ID 或价格的数值范围。没有“价格必须大于 0”的额外约束；缺货只由 NULL 表示。

05 / 独立题解

准备好后再打开：思路、证明与可提交代码。

核心洞察 · 把列名变成数据

每个商店列各自生成一个结果集：保留 product_id，把列名写成 store 的字符串，把该列值命名为 price，并排除 NULL。最后用 UNION ALL 拼接三个结果集。这就是固定三列的列转行。

完整过程

  1. 扫描 store1：输出 (0, store1, 95)、(1, store1, 70)。
  2. 扫描 store2：输出 (0, store2, 100)，跳过产品 1 的 NULL。
  3. 扫描 store3：输出 (0, store3, 105)、(1, store3, 80)。
  4. 合并得到五行；无需排序，也无需去重。

正确性

可靠性：每条输出都来自原表中一个非 NULL 价格，产品 ID 和价格保持原值，store 字面量对应所读取的列，因此不存在无售组合。完整性：任意非 NULL 价格必属于三个商店列之一，并被对应分支选中。唯一性：product_id 为主键，一个分支至多产生一次同一产品记录；不同分支有不同 store 值，所以每个有效组合恰好出现一次。

边界与复杂度

空表或全 NULL 产生零行；0 是有效价格，必须保留；不同商店价格相同仍要分别输出。设产品数为 n，结果行数 m ≤ 3n，三次线性扫描为 O(n)，物化输出需要 O(m) 空间。流式扫描本身只需 O(1) 额外状态；数据库具体缓冲与执行计划由引擎决定。参考实现使用 O(m) 结果空间。

替代方案

Pandas 使用 melt 后按 price 去除缺失值。支持 UNPIVOT 的数据库可使用原生操作，但语法与 NULL 行为需按方言处理。UNION 在这里也能得到相同集合，因为完整三元组本就不重复，但额外去重没有必要。不要使用横向 JOIN 来替代纵向拼接。

常见错误

  • 写 price != NULL：SQL 的 NULL 比较得到 UNKNOWN，应该使用 IS NOT NULL。
  • 用 WHERE store1 或 JavaScript 真值判断过滤：可能误删价格 0。
  • 将 store1 当作列值输出到 store：需要字符串字面量 'store1'。
  • 只输出价格而遗漏 store：会丢失不同商店的身份。
  • 用 ORDER BY 增加无关排序：题目允许任意顺序。

面试追问

商店增至 100 个？ 静态 SQL 分支维护成本高，可考虑引擎原生列转行或由受控列名生成查询；长期模型可改为 product_id、store、price 的明细表。主键不唯一会怎样？ UNION ALL 将保留源表重复行，应先明确新的业务唯一性契约。是否可以只扫描一次？ 某些方言可用 LATERAL / APPLY 配合 VALUES 展开；以实际执行计划确认性能收益。

Pandas · 官方可提交 Python 接口

import pandas as pd

def rearrange_products_table(products: pd.DataFrame) -> pd.DataFrame:
    return products.melt(
        id_vars="product_id",
        value_vars=["store1", "store2", "store3"],
        var_name="store", value_name="price"
    ).dropna(subset=["price"])

Java · 本地语义参考（Java 17，不是本题提交接口）

import java.util.*;

public class Solution {
    record Product(int productId, Integer store1,
                   Integer store2, Integer store3) {}
    record Price(int productId, String store, int price) {}

    public static List<Price> rearrange(List<Product> products) {
        List<Price> result = new ArrayList<>();
        for (int s = 0; s < 3; s++) {
            for (Product p : products) {
                Integer v = switch (s) {
                    case 0 -> p.store1();
                    case 1 -> p.store2();
                    default -> p.store3();
                };
                if (v != null)
                    result.add(new Price(p.productId(), "store" + (s + 1), v));
            }
        }
        return result;
    }
}

JavaScript · 本地语义参考（对象数组输入输出）

function rearrangeProductsTable(products) {
  const result = [];
  for (const store of ["store1", "store2", "store3"]) {
    for (const p of products) {
      if (p[store] !== null) {
        result.push({ product_id: p.product_id, store, price: p[store] });
      }
    }
  }
  return result;
}
// 输入需有 product_id、store1、store2、store3；缺货明确用 null。

Python · 本地语义参考（字典列表，不是 Pandas 接口）

def rearrange_products_table(products):
    result = []
    for store in ("store1", "store2", "store3"):
        for product in products:
            if product[store] is not None:
                result.append({
                    "product_id": product["product_id"],
                    "store": store,
                    "price": product[store]
                })
    return result

C++ · 本地语义参考（C++17）

#include <array>
#include <optional>
#include <string>
#include <vector>

struct Product {
    int product_id;
    std::array<std::optional<int>, 3> prices;
};
struct Price {
    int product_id;
    std::string store;
    int price;
};
std::vector<Price> rearrangeProductsTable(
    const std::vector<Product>& products) {
    std::vector<Price> result;
    for (int s = 0; s < 3; ++s) {
        for (const auto& p : products) {
            if (p.prices[s].has_value())
                result.push_back({p.product_id,
                    "store" + std::to_string(s + 1), *p.prices[s]});
        }
    }
    return result;
}
