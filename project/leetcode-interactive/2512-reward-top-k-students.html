奖励最顶尖的

Reward Top K Students

一份评语，一份积分。依据正负词汇给每位学生评分，再按题目指定的规则选出前 K 名。先读题，尝试想清楚同分时该如何决定顺序。

题目与示例交互实验测试与验证题解入口

01 / THE PROBLEM

题目与输入约定

给定两个词汇数组 positive_feedback 与 negative_feedback，它们分别代表正面词和负面词，两个数组之间没有共同单词。每名学生从 0 分开始：评语中每出现一次正面词加 3 分，每出现一次负面词减 1 分，其余词不影响分数。

report[i] 是学生 student_id[i] 的评语，学生 ID 唯一。返回得分从高到低的前 k 名学生 ID；同分时，ID 较小者排在前面。

topStudents(positive_feedback, negative_feedback, report, student_id, k)
返回：按排名排列的 k 个学生 ID

官方示例 1 · 同分

positive_feedback = ["smart","brilliant","studious"]
negative_feedback = ["not"]
report = ["this student is studious","the student is smart"]
student_id = [1,2]
k = 2
输出 = [1,2]

两位学生各有一个正面词，均为 3 分。ID 1 比 ID 2 小，因此先返回 1。

官方示例 2 · 负面词

positive_feedback = ["smart","brilliant","studious"]
negative_feedback = ["not"]
report = ["this student is not studious","the student is smart"]
student_id = [1,2]
k = 2
输出 = [2,1]

学生 1 得到 3 − 1 = 2 分，学生 2 得到 3 分，因此排名为 [2,1]。

完整约束

  • 1 ≤ positive_feedback.length, negative_feedback.length ≤ 10⁴。
  • 1 ≤ positive_feedback[i].length, negative_feedback[j].length ≤ 100，词汇只包含小写英文字母。
  • 两个词汇数组之间没有相同单词。
  • n == report.length == student_id.length，且 1 ≤ n ≤ 10⁴。
  • report[i] 只包含小写英文字母与空格，相邻单词间由一个空格分隔。
  • 1 ≤ report[i].length ≤ 100。
  • 1 ≤ student_id[i] ≤ 10⁹，所有学生 ID 互不相同。
  • 1 ≤ k ≤ n。

04 / EXPLANATION

准备好对照你的思路了吗？

展开后阅读完整算法、证明与四种语言实现。

题解 · 哈希计分 + 双关键字排序

核心洞察

评语只需逐个单词查权重，无需理解自然语言。把正面词映射为 3、负面词映射为 −1，其余词视为 0。每个学生独立累加，随后将学生按“分数降序、ID 升序”统一排序。

完整过程

  1. 构建单词到权重的哈希表；重复字典词只覆盖同一权重。
  2. 对第 i 份评语按空格拆词，逐词查询权重并累加，记录 (score, student_id[i])。
  3. 比较两个学生时，优先让分数更高的排前面；分数相同则让 ID 更小的排前面。
  4. 排序后截取前 k 个元素，仅返回它们的 ID。

以官方示例 2 为例：学生 1 的中性词均贡献 0，not 贡献 −1，studious 贡献 +3，合计 2；学生 2 的 smart 贡献 +3，合计 3。最终记录顺序为 (3,2)、(2,1)，返回 [2,1]。

正确性

计分不变式：处理一份评语前 t 个单词后，累计分数恰好等于这 t 个单词的题定贡献之和。初始 t=0 时为 0；每次加入当前词的正确权重，不变式保持。因此扫描结束时得到该学生的正确分数。

排名正确性：比较器对任意两名学生严格遵循题目规定的分数与 ID 优先级。排序后，没有后面的学生应当排在前面的学生之前，因此前 k 个恰为题目要求的最顶尖 k 名学生。返回对应 ID 即为正确结果。

边界与常见错误

  • 重复出现的词必须重复计分，不能把一份评语转成集合。
  • 负分有效；不能将分数截断为 0。
  • “not smart”是 −1 + 3 = 2，不是语义上的否定翻转。
  • 按完整单词匹配，不能用子串匹配；例如 “smartness” 不等于 “smart”。
  • 同分时按 ID 升序，不按报告顺序；不能只比较分数。
  • k=1 取第一名，k=n 返回完整排名；全部 0 分仍应按 ID 排序。
  • Java 使用 Integer.compare 清晰表达比较；C++ 比较器必须使用严格的小于或大于，不能使用 ≤。

复杂度

令 D 为词汇表总字符数，R 为所有评语总字符数，L 为单份评语最大长度，n 为学生数。在哈希查找的期望模型下，时间为 O(D + R + n log n)，包含字符串哈希与扫描成本。额外空间可按字符串存储计为 O(D + n + L)，返回结果为 O(k)；若字典引用现有字符串，实际新增存储更少。各语言排序的辅助空间均被该上界覆盖。

替代方案

k 远小于 n 时，可维护大小为 k 的堆，堆顶必须是当前入选者中“分数最低、同分 ID 最大”的最差学生。新学生更优时替换堆顶，最后再对堆中 k 人按目标顺序排序。排名部分为 O(n log(k+1) + k log k)，堆额外占 O(k)；本题 n ≤ 10⁴，完整排序更直接。

面试追问

  • 评语流式到达怎么办？ 每份评语完成即计分并更新上述大小为 k 的堆。
  • 需要语言情感分析吗？ 不需要，权重仅由给定词汇表决定。
  • ID 不唯一还能用该规则吗？ 原题已保证唯一；变更条件时需要明确是否为同一学生及如何合并评语。
  • 为什么不能只统计不同正面词数？ 规则按出现次数累计，重复词仍有贡献。

Java

import java.util.*;

class Solution {
    public List<Integer> topStudents(String[] positive_feedback,
            String[] negative_feedback, String[] report,
            int[] student_id, int k) {
        Map<String, Integer> weight = new HashMap<>();
        for (String word : positive_feedback) weight.put(word, 3);
        for (String word : negative_feedback) weight.put(word, -1);
        int[][] rows = new int[report.length][2];
        for (int i = 0; i < report.length; i++) {
            int score = 0;
            for (String word : report[i].split(" ")) {
                score += weight.getOrDefault(word, 0);
            }
            rows[i][0] = score;
            rows[i][1] = student_id[i];
        }
        Arrays.sort(rows, (a, b) -> a[0] == b[0]
                ? Integer.compare(a[1], b[1])
                : Integer.compare(b[0], a[0]));
        List<Integer> answer = new ArrayList<>();
        for (int i = 0; i < k; i++) answer.add(rows[i][1]);
        return answer;
    }
}

JavaScript

/**
 * @param {string[]} positive_feedback
 * @param {string[]} negative_feedback
 * @param {string[]} report
 * @param {number[]} student_id
 * @param {number} k
 * @return {number[]}
 */
var topStudents = function(positive_feedback, negative_feedback,
                           report, student_id, k) {
    const weight = new Map();
    for (const word of positive_feedback) weight.set(word, 3);
    for (const word of negative_feedback) weight.set(word, -1);
    const rows = report.map((text, i) => {
        let score = 0;
        for (const word of text.split(' ')) {
            score += weight.get(word) ?? 0;
        }
        return { score, id: student_id[i] };
    });
    rows.sort((a, b) => b.score - a.score || a.id - b.id);
    return rows.slice(0, k).map(row => row.id);
};

Python 3

from typing import List

class Solution:
    def topStudents(self, positive_feedback: List[str],
                    negative_feedback: List[str], report: List[str],
                    student_id: List[int], k: int) -> List[int]:
        weight = {word: 3 for word in positive_feedback}
        weight.update({word: -1 for word in negative_feedback})
        rows = []
        for text, sid in zip(report, student_id):
            score = sum(weight.get(word, 0) for word in text.split())
            rows.append((-score, sid))
        rows.sort()
        return [sid for _, sid in rows[:k]]

C++

#include <algorithm>
#include <sstream>
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> topStudents(vector<string>& positive_feedback,
                            vector<string>& negative_feedback,
                            vector<string>& report,
                            vector<int>& student_id, int k) {
        unordered_map<string, int> weight;
        for (const auto& word : positive_feedback) weight[word] = 3;
        for (const auto& word : negative_feedback) weight[word] = -1;
        vector<pair<int, int>> rows;
        for (int i = 0; i < (int)report.size(); ++i) {
            istringstream input(report[i]);
            string word;
            int score = 0;
            while (input >> word) {
                auto it = weight.find(word);
                if (it != weight.end()) score += it->second;
            }
            rows.emplace_back(score, student_id[i]);
        }
        sort(rows.begin(), rows.end(), [](const auto& a, const auto& b) {
            return a.first != b.first ? a.first > b.first
                                      : a.second < b.second;
        });
        vector<int> answer;
        for (int i = 0; i < k; ++i) answer.push_back(rows[i].second);
        return answer;
    }
};
