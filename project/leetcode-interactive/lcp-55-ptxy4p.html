采集果实

每一批结束都会清空背包，因此批次之间不能合并。每批只需计算装满 limit 后还要跑几趟：一次向上取整，线性累加。

LCP 55 贪心模拟 O(|fruits|)

题意

按顺序完成每一批果实

time[type] 是采集 1 到 limit 颗该类型果实所需时间。 fruits[j] = [type, num] 表示第 j 批任务；完成一批后背包清空，才能开始下一批。

time

[2, 3, 2]

fruits

[[0,2],[1,4],[2,1]]

limit

3

关键公式

trips = ⌈num / limit⌉

当前批耗时为 time[type] × trips。余数不为零时，最后不足一背包的果实也必须额外采集一次。

    为什么不合并

    清空背包使每批独立

    即使相邻批次类型相同，也不能把剩余容量带入下一批。每个 fruits[j] 都独立贡献一项向上取整，顺序只约束执行流程，不改变答案。

    题解默认隐藏

    把每批的最少趟数写成整数向上取整，再按类型索引对应耗时。

    对每个 [type, num]，最少采集次数是 (num + limit - 1) / limit。背包在批次结束后清空，所以直接把 time[type] × 次数 加入答案即可。

    Java

    class Solution {
    public int getMinimumTime(int[] time, int[][] fruits, int limit) {
        int answer = 0;
        for (int[] fruit : fruits) {
            int type = fruit[0];
            int count = fruit[1];
            int trips = (count + limit - 1) / limit;
            answer += time[type] * trips;
        }
        return answer;
    }
}
