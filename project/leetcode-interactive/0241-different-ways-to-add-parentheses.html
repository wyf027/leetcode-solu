241. 为运算表达式设计优先级

每一个运算符都可以成为最外层的最后一步。枚举切分点，递归得到左、右表达式的所有可能值，再让两边结果两两组合。

Medium分治记忆化搜索
官方标题
Different Ways to Add Parentheses
输入
expression: string
主线
枚举最后运算符

题意

给定一个只含整数及 +、-、* 的字符串 expression，返回所有不同分组方式计算得到的结果，顺序不限。
示例 1
expression = "2-1-1"
输出：[0,2]，即 ((2-1)-1)=0 与 (2-(1-1))=2。
示例 2
expression = "2*3-4*5"
输出：[-34,-14,-10,-10,10]

约束：1 ≤ expression.length ≤ 20；只含数字和三种运算符；每个数在 [0,99]；结果均为 32 位整数，返回结果数不超过 10⁴。

题解：每个运算符都是一次“最后计算”

核心洞察

对一段子表达式，选择某个运算符为最后执行的一步，就把问题拆为左右两段。左右各自返回多个值；对每一对值应用当前运算符，得到这一切分下的全部结果。没有运算符的片段就是一个数字。

完整过程

  1. 扫描表达式，每遇到一个运算符就作为切分点。
  2. 递归求左子串、右子串的结果列表。
  3. 左右列表做双循环，加入加、减或乘的结果。
  4. 若扫描不到运算符，把整个子串解析为一个数字。
  5. 用哈希表按子串缓存，避免重复计算相同片段。
时间复杂度
由括号化方案数主导；结果数本身可能达到 10⁴。
空间复杂度
缓存子问题及其结果，递归深度 O(n)。

替代方案与取舍

区间 DP 也能从短区间逐步合成，适合需要明确表格状态时。记忆化分治更贴近表达式语义，只会求实际触达的子串。

边界

  • 没有运算符时只返回该数字。
  • 多位数字必须整体解析，不能逐字符当数。
  • 不同括号方式可以产生相同数值，必须保留重复结果。
  • 运算符只有三种，无除法与一元负号。

常见错误

只按正常运算优先级算一遍会遗漏括号方式；把结果放进 Set 会错误删掉示例中的两个 -10。

面试追问

若需输出具体括号表达式而不是值，让递归结果携带字符串；若输入更长，使用 token 化后按索引区间缓存，避免频繁切子串。

可提交代码

class Solution {
    private final java.util.Map<String, java.util.List<Integer>> memo = new java.util.HashMap<>();
    public java.util.List<Integer> diffWaysToCompute(String exp) {
        if (memo.containsKey(exp)) return memo.get(exp);
        java.util.List<Integer> ans = new java.util.ArrayList<>();
        for (int i = 0; i < exp.length(); i++) {
            char op = exp.charAt(i);
            if (op != '+' && op != '-' && op != '*') continue;
            for (int a : diffWaysToCompute(exp.substring(0, i)))
                for (int b : diffWaysToCompute(exp.substring(i + 1)))
                    ans.add(op == '+' ? a + b : op == '-' ? a - b : a * b);
        }
        if (ans.isEmpty()) ans.add(Integer.parseInt(exp));
        memo.put(exp, ans); return ans;
    }
}
var diffWaysToCompute = function (expression) {
  const memo = new Map();
  const solve = (exp) => {
    if (memo.has(exp)) return memo.get(exp);
    const ans = [];
    for (let i = 0; i < exp.length; i++) if ('+-*'.includes(exp[i])) {
      for (const a of solve(exp.slice(0, i))) for (const b of solve(exp.slice(i + 1)))
        ans.push(exp[i] === '+' ? a + b : exp[i] === '-' ? a - b : a * b);
    }
    if (!ans.length) ans.push(Number(exp));
    memo.set(exp, ans); return ans;
  };
  return solve(expression);
};
