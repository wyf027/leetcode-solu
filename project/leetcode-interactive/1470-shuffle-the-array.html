1470. 重新排列数组

Shuffle the Array

EASY数组非付费题交错重排

Problem

题目描述

给定一个含 2n 个元素的数组 nums，其前半段依次为 x₁…xₙ，后半段依次为 y₁…yₙ。请把相同下标的一对元素交错放置并返回新数组。

[x₁, x₂, …, xₙ, y₁, y₂, …, yₙ] → [x₁, y₁, x₂, y₂, …, xₙ, yₙ]

函数形式

shuffle(nums: integer[], n: integer): integer[]

Bounds

约束

1 <= n <= 500 nums.length == 2n 1 <= nums[i] <= 10³

输出长度始终与输入相同；重复元素不会影响重排规则。

Examples

官方示例

参数形式完整保留

示例 1

输入：nums = [2,5,1,3,4,7], n = 3 输出：[2,3,5,4,1,7] 解释：x = [2,5,1]，y = [3,4,7]，依次交错取出。

示例 2

输入：nums = [1,2,3,4,4,3,2,1], n = 4 输出：[1,4,2,3,3,2,4,1]

示例 3

输入：nums = [1,1,2,2], n = 2 输出：[1,2,1,2]

Solution

准备好再揭晓

先用上方动画找出索引之间的规律，再展开完整题解。

Core idea

核心洞察：第 i 对来自 i 与 i + n

对每个 i ∈ [0, n)，按顺序把 nums[i] 和 nums[i+n] 加入答案。输出中的位置分别是 2i 与 2i+1。

完整过程

  1. 建立容量为 2n 的答案数组。
  2. 令 i 从 0 遍历到 n-1。
  3. 先加入前半段的 nums[i]，再加入后半段对应的 nums[i+n]。
  4. 遍历结束后返回答案。

正确性证明

循环不变式：完成第 i 次迭代后，答案的前 2(i+1) 个元素恰为 [x₁,y₁,…,xᵢ₊₁,yᵢ₊₁]。初始时答案为空，命题成立；每轮追加 nums[i]=xᵢ₊₁ 与 nums[i+n]=yᵢ₊₁，因此不变式继续成立。循环完成时已处理全部 n 对，答案正是要求的交错数组。

复杂度

时间：O(n)，每个元素访问一次。

空间：O(n)，返回数组包含 2n 个元素；若不计返回值，辅助空间为 O(1)。

边界情况

  • n = 1 时只交错一对。
  • 所有值相同仍按索引配对。
  • 值达到上下界不影响算法。
  • 输入长度由题目保证为 2n。

替代方案

也可直接赋值 ans[2*i] = nums[i]、ans[2*i+1] = nums[i+n]，与顺序追加等价。某些语言可用 zip 后展平，但通常会产生额外中间对象；原地位运算编码能降低额外空间，却依赖数值范围、可读性较差，本题没有必要。

面试追问

  • 若要求原地完成，如何利用题目数值上界把两个值编码进一个整数？
  • 若两个分区长度不一致，应怎样定义剩余元素的处理规则？
  • 如何把方法推广到 k 个等长分区的轮流交错？

常见错误

  • 把后半段索引写成 i + n + 1，造成越界和错位。
  • 循环执行到 2n，导致同一元素重复读取。
  • 误以为需要排序；本题只改变位置，不能改变相对配对关系。
  • 在原数组上从左到右直接覆盖，破坏尚未读取的数据。

Implementations

四种语言完整代码

Java
class Solution {
    public int[] shuffle(int[] nums, int n) {
        int[] answer = new int[2 * n];
        for (int i = 0; i < n; i++) {
            answer[2 * i] = nums[i];
            answer[2 * i + 1] = nums[i + n];
        }
        return answer;
    }
}
JavaScript
/**
 * @param {number[]} nums
 * @param {number} n
 * @return {number[]}
 */
var shuffle = function(nums, n) {
    const answer = [];
    for (let i = 0; i < n; i++) {
        answer.push(nums[i], nums[i + n]);
    }
    return answer;
};
Python 3
from typing import List

class Solution:
    def shuffle(self, nums: List[int], n: int) -> List[int]:
        answer = []
        for i in range(n):
            answer.append(nums[i])
            answer.append(nums[i + n])
        return answer
C++
class Solution {
public:
    vector<int> shuffle(vector<int>& nums, int n) {
        vector<int> answer;
        answer.reserve(2 * n);
        for (int i = 0; i < n; ++i) {
            answer.push_back(nums[i]);
            answer.push_back(nums[i + n]);
        }
        return answer;
    }
};
