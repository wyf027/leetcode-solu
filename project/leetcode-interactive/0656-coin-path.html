成本最小路径 Coin Path

在有障碍的一维路径上，从第 1 格一路向前。每次落脚都要付费，步幅又有上限； 你要返回的不是最低费用，而是那条最低费用、且字典序最小的完整路径。

先把规则走清楚

数组在题意中按 1 开始编号；代码实现仍使用常见的 0 开始下标。

给定长度为 n 的整数数组 coins 和整数 maxJump。你最初位于位置 1；从位置 i 出发，只能向前跳到 i + k，其中 1 ≤ k ≤ maxJump，并且目标位置不能是 -1。 每访问一个位置，就把该位置的数值计入总成本。

输出要求： 返回从 1 到 n 的访问下标。先最小化总成本；若最低成本路径不止一条，再取字典序最小者。 若终点不可达，返回空数组。
1

只能向前

每步前进 1 到 maxJump 格，不允许停留或后退。

2

-1 是路障

被标成 -1 的位置不可访问，也不能作为落脚点。

3

相同成本比路径

在第一个不同的位置，包含更小下标的路径优先。

官方示例 1

输入 coins = [1,2,4,-1,2], maxJump = 2
输出 [1,3,5]
说明 成本 = 1 + 4 + 2 = 7

官方示例 2

输入 coins = [1,2,4,-1,2], maxJump = 1
输出 []
说明 步幅为 1 时无法绕过第 4 格的路障。

约束

  • 1 ≤ coins.length ≤ 1000
  • -1 ≤ coins[i] ≤ 100
  • coins[1] != -1
  • 1 ≤ maxJump ≤ 100

题解 · 逆向动态规划

状态

dp[i] 表示从位置 i 出发并到达终点时，能取得的最低总成本。

选择

枚举 i 右侧 maxJump 范围内的落点 j，忽略路障和不可达状态。

破同分

候选成本相等时选更小的 j；它就是两条后续路径最早出现差异的位置。

核心转移

dp[i] = coins[i] + min(dp[j]), 其中 i < j ≤ min(n - 1, i + maxJump)

只有 coins[i] != -1 且 dp[j] 可达时，候选 j 才有效。 同时保存 next[i]，最后从 0 开始沿指针重建，并把每个下标加 1。

完整过程

  1. 创建长度为 n 的 dp，全部初始化为无穷大；next 初始化为 -1。
  2. 若终点不是路障，令 dp[n - 1] = coins[n - 1]。
  3. 从 i = n - 2 递减到 0；遇到 coins[i] == -1 直接跳过。
  4. 枚举 j = i + 1 … min(n - 1, i + maxJump)。
  5. 用 coins[i] + dp[j] 更新更低成本；成本相同则保留更小的 j。
  6. 若 dp[0] 仍是无穷大，返回空数组。
  7. 否则从 0 沿 next 走到 n - 1，把每个位置转为 1 开始下标后返回。

正确性证明

  1. 状态正确： 终点状态显然等于终点成本。假设所有 j > i 的可达状态已经是其到终点的最低成本， 那么任何从 i 出发的合法路径，第一跳必定落在枚举范围内某个 j； 取这些 coins[i] + dp[j] 的最小值，恰好覆盖所有可能的第一跳， 因而得到 i 到终点的最低成本。
  2. 字典序正确： 当多个 j 产生同样的最低成本时，各路径的共同前缀都是 i， 它们第一个可能不同的元素就是下一位置 j。选择最小 j， 必然得到字典序最小的候选路径；后续部分又由相同规则递归保证。
  3. 重建正确： 每个 next[i] 都指向一个更大的可达下标，因此指针严格向右， 不会成环；从 0 连续跟随即可到达 n - 1，并且累积成本等于 dp[0]。

由以上三点，算法返回的路径既具有全局最低成本，又在所有最低成本路径中具有最小字典序； 若没有路径，则正确返回空数组。

边界情况

  • n = 1：起点就是终点，直接得到 [1]。
  • 终点为 -1：初始化后起点不可达，返回空数组。
  • 连续路障长度达到 maxJump：无法跨越时自然保持无穷大。
  • 成本为 0：仍必须执行字典序同分规则，不能偏好“跳得更远”。
  • maxJump 大于剩余长度：枚举上界必须截断到 n - 1。

复杂度

O(n · maxJump)

每个位置至多查看 maxJump 个后继位置。

O(n)

dp、next 与返回路径使用线性空间。

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<Integer> cheapestJump(int[] coins, int maxJump) {
        int n = coins.length;
        int inf = Integer.MAX_VALUE / 4;
        int[] dp = new int[n];
        int[] next = new int[n];
        Arrays.fill(dp, inf);
        Arrays.fill(next, -1);

        if (coins[n - 1] != -1) {
            dp[n - 1] = coins[n - 1];
        }

        for (int i = n - 2; i >= 0; i--) {
            if (coins[i] == -1) {
                continue;
            }

            int right = Math.min(n - 1, i + maxJump);
            for (int j = i + 1; j <= right; j++) {
                if (dp[j] == inf) {
                    continue;
                }

                int candidate = coins[i] + dp[j];
                if (candidate < dp[i]
                        || (candidate == dp[i]
                            && (next[i] == -1 || j < next[i]))) {
                    dp[i] = candidate;
                    next[i] = j;
                }
            }
        }

        List<Integer> path = new ArrayList<>();
        if (dp[0] == inf) {
            return path;
        }

        int current = 0;
        while (true) {
            path.add(current + 1);
            if (current == n - 1) {
                break;
            }
            current = next[current];
        }
        return path;
    }
}

替代方案

暴力 DFS

枚举每条合法路径再比较成本和字典序。直观，但分支数呈指数增长，会超时。

逆向 DP · 推荐

O(n · maxJump) 同时处理最优成本、下一跳和字典序，结构最清晰。

最短路建模

可把位置看成 DAG 顶点、跳跃看成有向边；通用但在本题中比 DP 更重。

面试追问

  • 若成本允许负数，逆向 DP 是否仍然成立？为什么这里不会形成负环？
  • 如果需要返回所有最低成本路径，状态和输出规模如何变化？
  • 如何用线段树把“区间最小 dp”查询优化到 O(n log n)？如何保留字典序？
  • 若允许向后跳，问题会从 DAG 变成什么模型？

常见错误

  • 只返回 dp[0] 的成本，而忘记题目要求返回路径。
  • 同分时选更大的下一跳，导致 [1,3] 错压过 [1,2,…]。
  • 把 -1 当成负成本累加，而不是不可访问的路障。
  • 使用无穷大参与加法，造成整数溢出。
  • 忘记输出下标要从 1 开始。
