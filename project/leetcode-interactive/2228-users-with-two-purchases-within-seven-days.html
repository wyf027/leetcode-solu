01 / 题目

找到符合条件的用户

给定零售商的购买记录表 Purchases。找出存在两笔不同购买记录、且两个购买日期相差至多 7 天的用户。结果只保留 user_id，每位用户出现一次，并按用户编号升序排列。

Purchases 表结构
列名类型含义
purchase_idINT购买记录编号，唯一 / 主键
user_idINT用户编号，可重复
purchase_dateDATE购买日期，可重复

约束与语义

  • 日期差允许为 0 或 7；同一天发生的两笔不同购买也符合条件。
  • 必须是同一用户的两笔记录；单笔记录不能和自身配对。
  • 输入行没有排序保证。输出按 user_id ASC 排序并去重。
  • 可取得的题面未提供行数、编号范围或日期范围的额外数值上界，也未给出额外 NULL 规则；不人为添加这些约束。

04 / 题解

相邻购买足够证明复购

核心洞察：同一用户按日期排序后，只要存在任意一对日期差 ≤ 7，就一定存在一对相邻记录日期差 ≤ 7。因此，只需对比当前行与同用户的上一行。

完整过程

  1. 按用户分组，在组内按 purchase_date, purchase_id 排序。编号仅用于同日记录的稳定顺序。
  2. 用 LAG(purchase_date) 取得上一笔日期，每组首行得到 NULL。
  3. 计算当前日期减去上一笔日期的天数，保留 0 到 7 的记录。
  4. 取这些记录的用户编号，去重后升序返回。首行的 NULL 不满足筛选条件。

正确性证明

固定一个用户，设排序后的日期为 d₁ ≤ d₂ ≤ … ≤ dₘ。若某对 dⱼ − dᵢ ≤ 7（i < j），则 dᵢ₊₁ − dᵢ ≤ dⱼ − dᵢ ≤ 7，算法必能发现一对相邻记录。反过来，每次保留的相邻行属于同一用户、是两条不同记录且日期差在 0 到 7 天之间，所以一定满足要求。去重与排序只改变呈现，不改变用户集合，故查询既不漏报也不误报。

边界与常见错误

  • 同日购买：不要先按日期去重；0 天也是有效间隔。
  • 恰好 7 天：使用 ≤ 7，不是 < 7。日期差是日历日差，不是统计涉及了几个日期标签。
  • 用户隔离：忘记 PARTITION BY 会将不同用户的记录串起来。
  • 日期运算：不能把 YYYYMMDD 当整数相减；跨月、跨年和闰年都必须使用日期类型。
  • 重复输出：一个用户可有多次命中，因此需要 DISTINCT；ORDER BY 仍要明确写出。
  • 空表或单条记录：没有成对购买，应输出空表。不要把首行的 NULL 强行替换为当天。
  • 只比较首末日期：会漏掉中间靠得很近的购买，例如第 1、20、21 天。

复杂度与索引

设总记录数为 n。排序加相邻扫描的本地参考算法时间为 O(n log n)，复制、日期解析与结果集合占 O(n) 额外空间。窗口 SQL 通常需要排序和中间结果，不能脱离数据库执行计划保证固定耗时；按比较排序估算为 O(n log n)，中间存储可达 O(n)。可考虑 (user_id, purchase_date, purchase_id) 索引，但是否消除排序应以实际执行计划为准。

替代方案：自连接

同用户记录两两配对，用购买编号的大小关系排除自身与反向重复，再判断绝对日期差。语义直观，但极端情况下配对数为 O(n²)。

SELECT DISTINCT a.user_id
FROM Purchases a
JOIN Purchases b
  ON a.user_id = b.user_id
 AND a.purchase_id < b.purchase_id
 AND ABS(DATEDIFF(a.purchase_date, b.purchase_date)) <= 7
ORDER BY a.user_id;

面试追问

  • 改为 7 天内至少 k 笔？对排序后每个位置比较当前日期与前第 k−1 条日期，或维护一个滑动窗口。
  • 改为返回所有有效购买对？相邻比较不足以枚举全部结果，应改为窗口枚举或范围连接；输出本身可能有平方规模。
  • 实时流且允许乱序？需要按用户维护日期状态，同时定义迟到事件和保留范围；不能直接依赖到达顺序。
  • 从 DATE 改为时间戳？先明确“7 个日历日”还是“168 小时”，再选择时区与差值规则。

MySQL 8 · 官方可提交语言

WITH ordered_purchases AS (
    SELECT user_id, purchase_date,
           LAG(purchase_date) OVER (
               PARTITION BY user_id
               ORDER BY purchase_date, purchase_id
           ) AS previous_date
    FROM Purchases
)
SELECT DISTINCT user_id
FROM ordered_purchases
WHERE DATEDIFF(purchase_date, previous_date) BETWEEN 0 AND 7
ORDER BY user_id;

Java · 本地语义参考（Java 17）

import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.*;

public class Solution {
    public record Purchase(int purchaseId, int userId, LocalDate date) {}

    public static List<Integer> findValidUsers(List<Purchase> purchases) {
        List<Purchase> rows = new ArrayList<>(purchases);
        rows.sort(Comparator.comparingInt(Purchase::userId)
                .thenComparing(Purchase::date)
                .thenComparingInt(Purchase::purchaseId));
        Set<Integer> result = new TreeSet<>();
        for (int i = 1; i < rows.size(); i++) {
            Purchase prev = rows.get(i - 1), cur = rows.get(i);
            if (prev.userId() == cur.userId()
                    && ChronoUnit.DAYS.between(prev.date(), cur.date()) <= 7) {
                result.add(cur.userId());
            }
        }
        return new ArrayList<>(result);
    }
}

JavaScript · 本地语义参考

// 输入：[{purchase_id: 4, user_id: 2, purchase_date: "2022-03-13"}, ...]
// 日期为有效的 YYYY-MM-DD；按 UTC 计算日差，避开夏令时。
function findValidUsers(purchases) {
    const rows = purchases.map(p => ({
        ...p, day: Date.parse(p.purchase_date + "T00:00:00Z") / 86400000
    })).sort((a, b) => a.user_id - b.user_id ||
        a.day - b.day || a.purchase_id - b.purchase_id);
    const result = new Set();
    for (let i = 1; i < rows.length; i++) {
        const prev = rows[i - 1], cur = rows[i];
        if (prev.user_id === cur.user_id && cur.day - prev.day <= 7) {
            result.add(cur.user_id);
        }
    }
    return [...result].sort((a, b) => a - b);
}

Python · 本地语义参考（非 Pandas 提交版本）

from datetime import date


def find_valid_users(purchases):
    # 输入：字典列表；purchase_date 为有效的 YYYY-MM-DD 字符串。
    rows = sorted(
        (p["user_id"], date.fromisoformat(p["purchase_date"]), p["purchase_id"])
        for p in purchases
    )
    result = set()
    for previous, current in zip(rows, rows[1:]):
        if previous[0] == current[0] and (current[1] - previous[1]).days <= 7:
            result.add(current[0])
    return sorted(result)

C++ · 本地语义参考（C++20）

#include <algorithm>
#include <chrono>
#include <set>
#include <sstream>
#include <string>
#include <tuple>
#include <vector>

struct Purchase {
    int purchase_id;
    int user_id;
    std::string purchase_date; // 有效的 YYYY-MM-DD
};

std::vector<int> findValidUsers(const std::vector<Purchase>& purchases) {
    using namespace std::chrono;
    std::vector<std::tuple<int, sys_days, int>> rows;
    for (const auto& p : purchases) {
        int y, m, d;
        char dash;
        std::istringstream in(p.purchase_date);
        in >> y >> dash >> m >> dash >> d;
        sys_days day{year{y} / month{static_cast<unsigned>(m)} /
                    std::chrono::day{static_cast<unsigned>(d)}};
        rows.emplace_back(p.user_id, day, p.purchase_id);
    }
    std::sort(rows.begin(), rows.end());
    std::set<int> result;
    for (std::size_t i = 1; i < rows.size(); ++i) {
        const auto& [prevUser, prevDay, prevId] = rows[i - 1];
        const auto& [user, day, id] = rows[i];
        if (prevUser == user && (day - prevDay).count() <= 7) {
            result.insert(user);
        }
    }
    return std::vector<int>(result.begin(), result.end());
}
