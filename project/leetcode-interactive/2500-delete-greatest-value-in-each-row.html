删除每行中的最大值

Delete Greatest Value in Each Row

每行各拿走一个最大值，再从这一批数字里选出最大值计分。不断重复，直到所有数字都被拿走。

官方题目 ↗

01 / 任务规则

输入一个由正整数组成的 m × n 矩阵 grid。每轮从每一行删除一个最大元素；若并列最大，任意删除其中一个即可。把本轮所有被删除元素中的最大值加入总分。每轮各行都少一个元素，共执行 n 轮，返回最终总分。

参数与返回值

deleteGreatestValue(grid)
grid：二维整数数组；返回值：整数。

官方约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 50
  • 1 ≤ grid[i][j] ≤ 100

示例 1

输入：grid = [[1,2,4],[3,3,1]]
输出：8

三轮删除值依次为 [4,3]、[2,3]、[1,1]；每轮贡献分别为 4、3、1，总分 8。第二行两个 3 中任选一个先删除。

示例 2

输入：grid = [[10]]
输出：10

唯一一轮删除 10，贡献 10，最终总分为 10。

    04 / 独立题解

    先观察规律，再打开思路与代码。

    核心洞察：对齐每行的排名

    每一行依次删除的值，恰好是该行从大到小的序列。元素原本在哪一列并不重要。把每行升序排序后，从最后一列向前看，同一列就对应同一轮删除的元素；这一列的最大值就是本轮贡献。

    答案 = 各行排序后，每一列最大值的总和。为了和删除顺序一致，下方代码从最右列向左扫描。

    完整过程

    1. 将每一行按数值升序排列。
    2. 初始化答案 answer = 0。
    3. 对列 j = n-1, …, 0，扫描所有行，取 max(grid[i][j])。
    4. 将这一列的最大值累加，处理完所有列后返回答案。
    原矩阵： [1, 2, 4]    排序后： [1, 2, 4]
         [3, 3, 1]             [1, 3, 3]

从右向左：max(4,3) + max(2,3) + max(1,1)
        = 4 + 3 + 1 = 8

    正确性说明

    设每行排序后为 a[i][0…n-1]。第一轮，该行最大值是 a[i][n-1]。假设前 k-1 轮已删除该行最大的 k-1 个元素，则第 k 轮该行的剩余最大值必为 a[i][n-k]，归纳得到每一轮与对应列完全一致。跨行取该列最大值，正是题目要求的本轮贡献。累加全部 n 轮，所以算法返回正确答案。相等元素身份不同但数值相同，不影响归纳和得分。

    边界与复杂度

    • 单行时答案为该行元素之和；单列时答案为该列最大值；重复值无需去重。
    • 最多 50 轮，每轮最多 100 分，答案最多 5000，四种语言的整数表示均足够。
    • 时间复杂度：排序 O(mn log n) 加扫描 O(mn)，通常写为 O(mn log n)；当 n=1 时扫描仍为 O(m)。
    • 扫描额外空间 O(1)，排序辅助空间取决于语言实现：Python 的行排序最坏 O(n)，C++ 通常 O(log n) 栈空间，Java / JavaScript 依运行时排序实现而定。各行顺序排序，辅助空间不乘 m。
    • 代码会原地改变每行顺序。如需保留输入，先逐行复制，增加 O(mn) 空间。

    四语言完整代码

    采用官方方法签名；代码尚未运行或编译。

    Java

    import java.util.Arrays;

class Solution {
    public int deleteGreatestValue(int[][] grid) {
        for (int[] row : grid) Arrays.sort(row);
        int answer = 0;
        for (int j = grid[0].length - 1; j >= 0; j--) {
            int best = 0;
            for (int[] row : grid) best = Math.max(best, row[j]);
            answer += best;
        }
        return answer;
    }
}

class Solution:

class Solution {

        for (auto& row : grid) sort(row.begin(), row.end());
        int answer = 0;

            int best = 0;
            for (const auto& row : grid) best = max(best, row[j]);

    替代方案

    • 直接模拟：每轮扫描各行剩余元素，移除一个最大值。总时间 O(mn²)，容易对应题意；实验台使用这一机制展示原位置的变化。
    • 每行一个最大堆：每轮弹出堆顶并取最大值，总时间 O(mn log n)，存储堆需要 O(mn) 空间。静态矩阵直接排序更简洁。
    • 利用值域 1–100 为每行建频次数组，维护向下移动的最大值指针，可达 O(m(n+100)) 时间、O(100m) 额外空间，但实现更繁琐。

    常见错误

    • 直接对原始列取最大值。反例 [[10,1],[1,10]] 会误得 20，正确值为 11。
    • 把本轮删除值全部相加。题目只加其中的最大值。
    • 一次删除所有并列最大值。每行每轮只能删一个。
    • JavaScript 忘记数值比较器；默认 sort 按字符串排序。
    • 声称总额外空间一定为 O(1)，忽略标准库排序工作空间。

    面试追问

    必须倒序扫描列吗？不必，升序扫描只是把轮次倒过来，总和不变。

    允许负数时怎样修改？排序规律不变，但每轮最大值不能初始化为 0，应从首行该列值开始。

    如何保留输入？复制每一行再排序，仅复制外层数组仍会修改原行。

    行长度不等怎么办？已超出本题约束，需要先定义空行在各轮中的行为；不能直接套用列对齐。
