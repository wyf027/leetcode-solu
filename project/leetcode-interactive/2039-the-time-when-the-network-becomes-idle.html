网络空闲的时刻

The Time When the Network Becomes Idle

最后一台服务器停止重发时，网络真的已经安静了吗？
先观察消息如何往返，再决定你需要计算什么。

在 LeetCode 阅读原题 ↗

01 / 任务说明

有 n 台服务器，编号为 0…n−1。无向边数组 edges 中的 [u, v] 表示两台服务器直接相连，每条线路传输一跳耗时 1 秒，容量不限。整个网络连通。

服务器 0 是主服务器，其余是数据服务器。每条请求走到主服务器的最短路径；主服务器立即处理收到的每条请求，并沿原路反向回复，没有处理延迟。

  1. 在第 0 秒开始时，所有数据服务器同时发送第一条请求。
  2. 从第 1 秒开始，每秒开始时先检查回复，包括这一时刻刚到的回复。
  3. 服务器 i 如果仍未收到任何回复，就按 patience[i] 秒的间隔重发；一旦收到任意回复，立即停止后续重发。
  4. 已经发出的请求仍会被处理并获得回复。某秒若还有信息传输或到达，就不算空闲。

返回从哪一秒开始，整个网络不再传输或接收任何消息。函数形式：networkBecomesIdle(edges, patience) → integer。

约束

  • n == patience.length，2 ≤ n ≤ 10⁵。
  • patience[0] == 0；对于 1 ≤ i < n，1 ≤ patience[i] ≤ 10⁵。
  • 1 ≤ edges.length ≤ min(10⁵, n × (n−1) / 2)。
  • edges[i].length == 2，0 ≤ uᵢ, vᵢ < n，uᵢ ≠ vᵢ。
  • 没有重复边；任意两台服务器可以直接或间接到达。

官方示例 1 · 链式网络

edges = [[0,1],[1,2]]
patience = [0,2,1]
输出：8

服务器 1 在第 2 秒收到首条回复，不再重发。服务器 2 在第 0、1、2、3 秒发送请求，第 4 秒收到首条回复，第 7 秒收到最后一条回复。因此第 8 秒开始空闲。

官方示例 2 · 三角网络

edges = [[0,1],[0,2],[1,2]]
patience = [0,10,10]
输出：3

两台数据服务器都直接连接主服务器，第 2 秒收到回复；没有重发。第 2 秒仍有到达事件，第 3 秒才开始空闲。

04 / 独立题解
准备好后展开推导、证明与四种语言实现。




BFS 最短路 + 最后一次重发


核心洞察
容量无限，消息之间不会互相阻塞。对于服务器 i，只需要知道它到 0 的最短距离 d，不需要记录每条消息经过哪一条具体路径。第一次回复在 r = 2d 秒到达。
发送时刻是 0, p, 2p, …，其中 p = patience[i]。检查新到回复发生在重发之前，因此发送时刻必须严格小于 r。
最后发送时刻 lastSend = floor((r - 1) / p) * p
最后回复时刻 lastReply = lastSend + r
网络最早空闲时刻 = max(lastReply) + 1
式子中的 r−1 排除了“首条回复到达的同一秒仍然重发”；末尾 +1 则排除了“最后回复正在到达的那一秒”。两者解决的是不同边界。


完整过程
  1. 建立无向邻接表，每条边在两端各存一次。
  2. 从 0 开始 BFS，距离初值为 −1，0 的距离为 0。入队时标记距离，确保每个点只入队一次。
  3. 遍历数据服务器 1…n−1，将最短距离乘 2 得到往返时间。
  4. 用上述整除公式计算最后回复，维护最大值。
  5. 返回最大回复时刻加 1。

正确性证明
引理 1：图中边权全为 1，BFS 按距离从小到大扩展；节点首次入队时的距离即最短距离。所以 2 × dist[i] 是任意一条该服务器请求的往返耗时，也是首条回复到达时刻。
引理 2：在首条回复到达前，服务器按耐心间隔发送，在首条回复到达后不再发送。因此合法发送时刻恰为满足 kp < r 的非负整数倍。最大的倍数为 floor((r−1)/p) × p。
引理 3：同一服务器的所有消息往返耗时相同，最后发出的请求也最后返回，其回复时间为 lastSend + r。各服务器彼此独立，取这些时间的最大值得到整个网络最后的消息到达时刻 T。
结论：在 T 时刻仍有消息到达，所以不空闲；从 T+1 开始所有消息均已结束，且不会再重发。因此返回 T+1 正确且最早。


边界与复杂度
  • p ≥ r 时只有第 0 秒的请求，公式自然得到 lastSend=0。
  • r % p == 0 时最后发送为 r−p，不能取 r。
  • p=1 时最后发送是 r−1，空闲时刻为 2r。
  • 忽略主服务器 0 的重发计算，避免用 patience[0]=0 做除法。
  • 有环或多条最短路不影响结果，只需要最短距离。
  • d ≤ n−1，全局答案不超过 4(n−1) ≤ 399996，本题 32 位整数足够。
令 m = edges.length。建图与 BFS 均为 O(n+m) 时间，最终扫描 O(n)；总时间 O(n+m)，邻接表、距离数组与队列总空间 O(n+m)。


替代方案与常见错误
逐秒模拟适合小图讲解，但耐心为 1 的长链会产生大量重发，时间与消息数相关。实际提交应直接计算时间。对每个点分别 BFS 会重复工作；Dijkstra 在单位边权图上增加优先队列开销。普通 DFS 的首次访问距离也不保证最短。
  • 误用 floor(r/p)*p：整除时会多发一条请求。
  • 遗漏最终 +1：有到达事件的秒仍然忙碌。
  • 把停止重发当作空闲：未处理完的旧请求仍然会返回。
  • 只看最远节点：较近节点如果耐心小，最后回复可能更晚。
  • JS 队列不断 shift()：用递增头指针避免前端删除开销。
  • BFS 出队才标记：同一个节点可能反复入队；应在入队前标记。


面试追问
边的传输时间不同怎么办？ 非负权重下用 Dijkstra 替代 BFS；若权重为整数、往返仍对称，重发公式保持不变。连续时间下需重新处理严格小于的边界。
主服务器有固定处理耗时 c 呢？ 如果每条请求独立并行处理且耗时固定，令 r=2d+c；如果有排队，独立性被破坏，需要建模服务队列。
如何求每台服务器的总请求数？ floor((r−1)/p)+1，其中 1 对应第 0 秒发送。
只改 patience，多次查询怎么办？ 先复用图的距离；单点修改只需重算该点的最后回复。若要高频全局最大值，可再考虑支持更新的最大值数据结构。


Java · 官方签名
import java.util.*;

class Solution {
    public int networkBecomesIdle(int[][] edges, int[] patience) {
        int n = patience.length;
        List<List<Integer>> graph = new ArrayList<>(n);
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        int[] dist = new int[n];
        Arrays.fill(dist, -1);
        int[] queue = new int[n];
        int head = 0, tail = 0;
        queue[tail++] = 0;
        dist[0] = 0;
        while (head < tail) {
            int u = queue[head++];
            for (int v : graph.get(u)) {
                if (dist[v] != -1) continue;
                dist[v] = dist[u] + 1;
                queue[tail++] = v;
            }
        }
        int answer = 0;
        for (int i = 1; i < n; i++) {
            int roundTrip = 2 * dist[i];
            int lastSend = (roundTrip - 1) / patience[i] * patience[i];
            answer = Math.max(answer, lastSend + roundTrip + 1);
        }
        return answer;
    }
}

var networkBecomesIdle = function(edges, patience) {
    const n = patience.length;
    const graph = Array.from({ length: n }, () => []);
    for (const [u, v] of edges) {
        graph[u].push(v);
        graph[v].push(u);
    }
    const dist = Array(n).fill(-1);
    const queue = [0];
    dist[0] = 0;
    for (let head = 0; head < queue.length; head++) {
        const u = queue[head];
        for (const v of graph[u]) {
            if (dist[v] !== -1) continue;
            dist[v] = dist[u] + 1;
            queue.push(v);
        }
    }
    let answer = 0;
    for (let i = 1; i < n; i++) {
        const roundTrip = 2 * dist[i];
        const lastSend = Math.floor((roundTrip - 1) / patience[i]) * patience[i];
        answer = Math.max(answer, lastSend + roundTrip + 1);
    }
    return answer;
};


Python 3 · 官方签名
from collections import deque
from typing import List

class Solution:
    def networkBecomesIdle(self, edges: List[List[int]], patience: List[int]) -> int:
        n = len(patience)
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        dist = [-1] * n
        dist[0] = 0
        queue = deque([0])
        while queue:
            u = queue.popleft()
            for v in graph[u]:
                if dist[v] != -1:
                    continue
                dist[v] = dist[u] + 1
                queue.append(v)
        answer = 0
        for i in range(1, n):
            round_trip = 2 * dist[i]
            last_send = (round_trip - 1) // patience[i] * patience[i]
            answer = max(answer, last_send + round_trip + 1)
        return answer


C++ · 官方签名
#include <algorithm>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    int networkBecomesIdle(vector<vector<int>>& edges, vector<int>& patience) {
        int n = patience.size();
        vector<vector<int>> graph(n);
        for (const auto& e : edges) {
            graph[e[0]].push_back(e[1]);
            graph[e[1]].push_back(e[0]);
        }
        vector<int> dist(n, -1);
        queue<int> q;
        dist[0] = 0;
        q.push(0);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int v : graph[u]) {
                if (dist[v] != -1) continue;
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
        int answer = 0;
        for (int i = 1; i < n; ++i) {
            int roundTrip = 2 * dist[i];
            int lastSend = (roundTrip - 1) / patience[i] * patience[i];
            answer = max(answer, lastSend + roundTrip + 1);
        }
        return answer;
    }
};
