包含每个查询的

Minimum Interval to Include Each Query

一个查询点，多个覆盖它的区间。你能找出其中最短的长度吗？

官方题目 ↗

01 / 题目

给定整数闭区间数组 intervals，每项为 [leftᵢ, rightᵢ]，以及查询数组 queries。对于每个查询值 q，在满足 leftᵢ ≤ q ≤ rightᵢ 的区间中，返回最小长度 rightᵢ − leftᵢ + 1。没有区间覆盖时返回 -1。答案顺序必须与原查询顺序一致。

返回的是区间包含的整数个数，而非区间本身；例如 [4,4] 长度为 1。

约束

  • 1 ≤ intervals.length ≤ 10⁵
  • 1 ≤ queries.length ≤ 10⁵
  • intervals[i].length == 2
  • 1 ≤ leftᵢ ≤ rightᵢ ≤ 10⁷
  • 1 ≤ queries[j] ≤ 10⁷

官方示例 1

intervals = [[1,4],[2,4],[3,6],[4,4]]
queries = [2,3,4,5]
输出 = [3,3,1,4]

2、3 的最短覆盖均为 [2,4]，长度 3；4 对应 [4,4]，长度 1；5 对应 [3,6]，长度 4。

官方示例 2

intervals = [[2,3],[2,5],[1,8],[20,25]]
queries = [2,19,5,22]
输出 = [2,-1,4,6]

2 对应 [2,3]；19 无覆盖；5 对应 [2,5]；22 对应 [20,25]，长度分别为 2、-1、4、6。

为什么逐个查询扫描全部区间会变慢？查询的处理顺序能否改变？


04 / 题解 · 离线排序 + 最小堆
核心洞察
查询互不影响，可以按数值从小到大离线处理，再用原下标恢复答案。查询点只向右移动：左端点已到达的区间可以加入候选，而右端点已经落在查询点左侧的区间永远不会再次有效。用长度作为堆的首要排序键，就能快速取得最短候选。
完整过程
  1. 按左端点升序排列区间，将每个查询变成 (值, 原下标) 并按值升序排列。
  2. 维护区间指针 i 和最小堆；堆元素为 (长度, 右端点)。
  3. 对当前 q，把所有 left ≤ q 且尚未处理的区间入堆。即使其中有过期项，也可以统一交给下一步处理。
  4. 只要堆顶 right < q 就弹出，直到堆空或堆顶覆盖 q。
  5. 非空时把堆顶长度写入原下标，空时写 -1。
示例 2 的处理顺序为 2 → 5 → 19 → 22，回填位置依次为 0 → 2 → 1 → 3。这样计算顺序变化，输出顺序不变。
正确性
候选完整性：处理 q 时，指针已加入所有左端点不超过 q 的区间。此前被弹出的区间右端点小于当时的查询，因查询非递减，其右端点也小于当前 q，因此不可能丢弃当前有效区间。
最优性：清理完成后，若堆非空，堆顶既满足 left ≤ q，又满足 right ≥ q，必定覆盖 q。所有覆盖 q 的区间仍在堆中；堆以长度排序，因此堆顶长度是全体有效区间中的最小值。更深层的过期元素无需立即删除，因为它们不影响当前最小值；将来来到堆顶时再删除即可。
空堆与回填：若清理后堆空，根据候选完整性不存在覆盖区间，应返回 -1。每个查询携带独立原下标，因此重复查询与乱序查询都能正确恢复。
边界与常见错误
  • 长度必须加 1；单点区间长度为 1。
  • 入堆条件为 left ≤ q，出堆条件为 right < q；right == q 时仍覆盖。
  • 不能只弹一次过期堆顶，必须用 while 连续清理。
  • 不能按右端点作为堆的首要排序键；本题最小化的是长度。
  • 排序查询后不能直接按新顺序返回；重复值也要保留每个原下标。
  • 两类数组都非空；但某次查询的候选堆可以为空。最大长度 10⁷，四语言使用的数值类型均可表示。
复杂度
设区间数为 n，查询数为 m。排序 O(n log n + m log m)，每个区间最多入堆、出堆一次，查询访问堆顶 O(1)。总时间 O(n log n + m log m)（更稳健写作 log(n+1)、log(m+1)），辅助空间 O(n + m)，含堆、带下标查询与答案。下方代码会原地排序 intervals；若必须保留其顺序，先复制。
替代方案
逐查询遍历区间实现简单，但 O(nm) 无法适应 10⁵ 规模。也可把区间按长度排序，对排序后的查询用二分定位左边界，再用并查集跳过已经得到答案的位置：首次覆盖就是最小长度，时间约为 O(n log n + m log m + n log m + m α(m))，实现比最小堆更复杂。坐标压缩配合区间取最小值的数据结构也可做，但无需为 10⁷ 坐标直接开数组。
面试追问
  • 为什么必须离线？这个方案利用查询单调性永久淘汰区间；在线乱序到来的查询不能直接共享该扫描状态。
  • 要求返回区间本身？在堆中保存左端点或原区间下标，并明确等长时的选择规则。
  • 过期项藏在堆底会出错吗？不会，读取答案前只需保证堆顶有效；每个过期项最多被弹一次。


Java
import java.util.*;

class Solution {
    public int[] minInterval(int[][] intervals, int[] queries) {
        Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
        int m = queries.length;
        int[][] qs = new int[m][2];
        for (int j = 0; j < m; j++) qs[j] = new int[]{queries[j], j};
        Arrays.sort(qs, Comparator.comparingInt(a -> a[0]));
        PriorityQueue<int[]> heap = new PriorityQueue<>(
            Comparator.<int[]>comparingInt(a -> a[0])
                .thenComparingInt(a -> a[1]));
        int[] ans = new int[m];
        Arrays.fill(ans, -1);
        int i = 0;
        for (int[] query : qs) {
            int q = query[0];
            while (i < intervals.length && intervals[i][0] <= q) {
                int l = intervals[i][0], r = intervals[i][1];
                heap.offer(new int[]{r - l + 1, r});
                i++;
            }
            while (!heap.isEmpty() && heap.peek()[1] < q) heap.poll();
            if (!heap.isEmpty()) ans[query[1]] = heap.peek()[0];
        }
        return ans;
    }
}


JavaScript
/**
 * @param {number[][]} intervals
 * @param {number[]} queries
 * @return {number[]}
 */
var minInterval = function(intervals, queries) {
    intervals.sort((a, b) => a[0] - b[0]);
    const qs = queries.map((q, j) => [q, j]).sort((a, b) => a[0] - b[0]);
    const heap = [], ans = Array(queries.length).fill(-1);
    const less = (a, b) => a[0] < b[0] || (a[0] === b[0] && a[1] < b[1]);
    function push(x) {
        heap.push(x);
        let k = heap.length - 1;
        while (k > 0) {
            const p = (k - 1) >> 1;
            if (!less(heap[k], heap[p])) break;
            [heap[k], heap[p]] = [heap[p], heap[k]];
            k = p;
        }
    }
    function pop() {
        const last = heap.pop();
        if (!heap.length) return;
        heap[0] = last;
        let k = 0;
        while (2 * k + 1 < heap.length) {
            let c = 2 * k + 1;
            if (c + 1 < heap.length && less(heap[c + 1], heap[c])) c++;
            if (!less(heap[c], heap[k])) break;
            [heap[c], heap[k]] = [heap[k], heap[c]];
            k = c;
        }
    }
    let i = 0;
    for (const [q, j] of qs) {
        while (i < intervals.length && intervals[i][0] <= q) {
            const [l, r] = intervals[i++];
            push([r - l + 1, r]);
        }
        while (heap.length && heap[0][1] < q) pop();
        if (heap.length) ans[j] = heap[0][0];
    }
    return ans;
};


Python 3
from typing import List
import heapq

class Solution:
    def minInterval(self, intervals: List[List[int]], queries: List[int]) -> List[int]:
        intervals.sort()
        qs = sorted((q, j) for j, q in enumerate(queries))
        heap = []
        ans = [-1] * len(queries)
        i = 0
        for q, j in qs:
            while i < len(intervals) and intervals[i][0] <= q:
                left, right = intervals[i]
                heapq.heappush(heap, (right - left + 1, right))
                i += 1
            while heap and heap[0][1] < q:
                heapq.heappop(heap)
            if heap:
                ans[j] = heap[0][0]
        return ans


C++
#include <vector>
#include <algorithm>
#include <queue>
#include <functional>
#include <utility>
using namespace std;

class Solution {
public:
    vector<int> minInterval(vector<vector<int>>& intervals,
                            vector<int>& queries) {
        sort(intervals.begin(), intervals.end());
        vector<pair<int, int>> qs;
        for (int j = 0; j < (int)queries.size(); ++j)
            qs.emplace_back(queries[j], j);
        sort(qs.begin(), qs.end());
        priority_queue<pair<int, int>, vector<pair<int, int>>,
                       greater<pair<int, int>>> heap;
        vector<int> ans(queries.size(), -1);
        int i = 0;
        for (const auto& query : qs) {
            int q = query.first, j = query.second;
            while (i < (int)intervals.size() && intervals[i][0] <= q) {
                int l = intervals[i][0], r = intervals[i][1];
                heap.emplace(r - l + 1, r);
                ++i;
            }
            while (!heap.empty() && heap.top().second < q) heap.pop();
            if (!heap.empty()) ans[j] = heap.top().first;
        }
        return ans;
    }
};
