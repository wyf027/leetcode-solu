Find Peak Element

找到山脊中的严格峰值

给定相邻元素不相等的数组，返回任意一个严格高于左右邻居的元素下标。

查看题目 进入勘测台

题意与参数

峰值元素必须严格大于相邻元素。数组边界外可视为 -∞，因此峰值也可能位于最左端或最右端。若存在多个峰，返回任意一个即可。

参数格式

INPUT
nums: number[]，长度为 1..1000
VALUE
每个元素在 32 位有符号整数范围内，相邻元素不相等
OUTPUT
返回任意一个峰值元素的整数下标
TARGET
算法时间复杂度必须为 O(log n)
Array Binary Search

样例一

输入
nums = [1, 2, 3, 1]
输出
2
解释
下标 2 的值为 3，严格大于左右相邻元素。

样例二

输入
nums = [1, 2, 1, 3, 5, 6, 4]
输出
5
解释
下标 1 和 5 都是峰值，返回任意一个均正确。

核心洞察：相邻坡度指向一侧峰顶

观察中点 mid 与右邻点 mid + 1。若中点更高，说明从右邻点向左存在上升方向，闭区间 [left, mid] 内一定有峰；否则保留 [mid + 1, right]。每次至少排除一半区间，最终左右边界会合在一个峰值下标。

下降坡

nums[mid] > nums[mid + 1]

保留左侧，令 right = mid

上升坡

nums[mid] < nums[mid + 1]

保留右侧，令 left = mid + 1

复杂度

TIME
O(log n)
候选区间每轮至少缩小一半。
SPACE
O(1)
只维护左右边界和中点。

完整过程

  1. 1

    建立闭区间

    初始化 left = 0、right = n - 1，答案始终位于闭区间内。

  2. 2

    读取相邻坡度

    当 left < right 时计算中点，并比较 mid 与 mid + 1。

  3. 3

    保留有峰一侧

    下降时保留含中点的左半边，上升时保留从右邻点开始的右半边。

  4. 4

    会合即返回

    循环结束时 left == right，该位置就是一个严格峰值。

边界与不变量

单元素：循环不执行，直接返回下标 0。
峰在左端：首个下降坡会持续把右边界向左收缩。
峰在右端：连续上升会持续把左边界向右推进。
多个峰：坡度只保证保留一侧的某个峰，不要求固定返回哪一个。
关键不变量：每轮结束后，闭区间内至少存在一个峰值。

替代方案：线性扫描

从左向右找到第一个满足 nums[i] > nums[i + 1] 的位置并返回；若始终上升则返回末尾。它同样正确且空间为 O(1)，但时间为 O(n)，不满足本题指定的对数级要求。

面试追问

为什么下降时不能写 right = mid - 1？

因为 mid 自身可能就是峰值。删除它会破坏答案始终位于候选闭区间内的不变量。

为什么 mid + 1 一定不会越界？

只有在 left < right 时进入循环，此时向下取整的 mid 必然小于 right。

若允许相邻元素相等会怎样？

严格坡度方向可能消失，当前证明不再直接成立，需要重新定义峰值或处理平台区间。

常见错误

错误缩边

下降时写成 right = mid - 1，误删可能的峰。

循环条件过宽

使用 left <= right 后仍读取 mid + 1，可能越界。

比较错邻居

改比 mid - 1 却未同步边界逻辑，导致首元素风险。

返回高度

题目要求返回下标，不是 nums[left]。

class Solution {
    public int findPeakElement(int[] nums) {
        int left = 0;
        int right = nums.length - 1;

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > nums[mid + 1]) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }

        return left;
    }
}
