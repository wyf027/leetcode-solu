路径总和 IV

一棵树被压缩进若干个三位数。先把每一位真正看懂，再用交互演算观察所有根到叶路径如何被逐条累计。

三位编码 dpv 的含义

1位置 p

任务

给定一个按升序排列的整数数组 nums。每个整数都是三位数 dpv，共同表示一棵最多 4 层的有效二叉树：

  • 百位 d：节点深度，根节点深度为 1；
  • 十位 p：该节点在本层满二叉树位置中的序号，从 1 开始；
  • 个位 v：节点值，范围为 0 到 9。

返回这棵树中所有从根节点到叶节点路径的节点值之和。输入保证能表示一棵连通且有效的二叉树。

函数签名与约束

pathSum(nums: integer[]): integer

  • 1 <= nums.length <= 15
  • 110 <= nums[i] <= 489
  • 1 <= d <= 4
  • 1 <= p <= 2^(d - 1)
  • 0 <= v <= 9
  • nums 严格升序，且表示有效二叉树

示例 1

输入
nums = [113, 215, 221]
输出
12

两条根到叶路径的和值分别为 3 + 5 = 8 与 3 + 1 = 4，合计 12。

示例 2

输入
nums = [113, 221]
输出
4

根节点只有一个右孩子，唯一根到叶路径为 3 → 1。

05 · Complete solution

哈希坐标 + 深度优先搜索

不必真的补齐一棵满二叉树。把每个节点登记在“深度、位置”坐标中，就能直接找到左右孩子。

核心洞察

编码 dpv 可以拆出深度 d、位置 p 与值 v。用 10 * d + p 作为哈希键保存 v；同一节点的左右孩子坐标恰好是：

  • 左孩子：(d + 1, 2 * p - 1)
  • 右孩子：(d + 1, 2 * p)

因此，从根坐标 (1, 1) 出发做 DFS，并携带根到父节点的前缀和即可。当两个孩子都不存在时，当前节点就是叶子，把当前路径和计入答案。

完整过程

  1. 拆解编码。 对每个整数 x，计算 d = x / 100、p = (x / 10) % 10、v = x % 10。
  2. 建立坐标表。 将 (10 * d + p) → v 放进哈希表；最多只有 15 个节点。
  3. 从根开始。 调用 dfs(1, 1, 0)，第三个参数表示到父节点为止的路径和。
  4. 更新路径和。 访问节点时令 sum = prefix + value。
  5. 识别叶子。 如果左右孩子坐标都不在哈希表中，返回 sum；否则递归两棵存在的子树并相加。

正确性证明

命题：dfs(d, p, prefix) 返回坐标 (d, p) 对应子树中，所有从整棵树根节点到该子树叶节点的路径和总和，其中 prefix 是根到当前节点父亲的和值。

基础情况：当前节点没有孩子时，它就是叶子。函数把当前值加入 prefix 后返回，恰好得到唯一一条以该叶子结束的完整根到叶路径和。

归纳步骤：当前节点不是叶子时，每条经过它的根到叶路径必然继续进入左子树或右子树，且两组路径互不重叠。根据归纳假设，两次递归分别返回各自子树中全部完整路径和；二者相加便覆盖当前子树的全部路径，既无遗漏也无重复。

结论：从根坐标 (1, 1) 调用 DFS，返回值就是整棵树所有根到叶路径和的总和。

复杂度

  • 时间复杂度：O(n)，每个节点至多访问一次。
  • 空间复杂度：O(n)，哈希表保存全部节点；递归深度最多为 4。

边界情况

  • 只有根节点，根本身也是叶子；
  • 节点值允许为 0，不能用值是否为 0 判断节点存在；
  • 节点可以只有一个孩子；
  • 最深到第 4 层，最多 15 个节点；
  • 缺失兄弟节点时，只递归实际存在的坐标。

import java.util.HashMap;
import java.util.Map;

class Solution {
    private Map<Integer, Integer> tree;

    public int pathSum(int[] nums) {
        tree = new HashMap<>();

        for (int encoded : nums) {
            int depth = encoded / 100;
            int position = (encoded / 10) % 10;
            int value = encoded % 10;
            tree.put(depth * 10 + position, value);
        }

        return dfs(1, 1, 0);
    }

    private int dfs(int depth, int position, int prefixSum) {
        Integer value = tree.get(depth * 10 + position);
        if (value == null) {
            return 0;
        }

        int currentSum = prefixSum + value;
        int leftKey = (depth + 1) * 10 + (position * 2 - 1);
        int rightKey = (depth + 1) * 10 + position * 2;

        if (!tree.containsKey(leftKey) && !tree.containsKey(rightKey)) {
            return currentSum;
        }

        return dfs(depth + 1, position * 2 - 1, currentSum)
             + dfs(depth + 1, position * 2, currentSum);
    }
}

class Solution {
private:
    unordered_map<int, int> tree;

    int dfs(int depth, int position, int prefixSum) {
        int key = depth * 10 + position;
        if (tree.find(key) == tree.end()) {
            return 0;
        }

        int currentSum = prefixSum + tree[key];
        int leftKey = (depth + 1) * 10 + (position * 2 - 1);
        int rightKey = (depth + 1) * 10 + position * 2;

        if (tree.find(leftKey) == tree.end()
                && tree.find(rightKey) == tree.end()) {
            return currentSum;
        }

        return dfs(depth + 1, position * 2 - 1, currentSum)
             + dfs(depth + 1, position * 2, currentSum);
    }

替代方案

显式构造节点对象：先根据坐标创建真实的 TreeNode，再运行普通的根到叶 DFS。它更贴近日常二叉树题，但需要维护节点引用，代码更长。

自底向上计算叶子数：每个节点值对答案的贡献等于“节点值 × 其子树叶子数量”。倒序统计每个坐标下方的叶子数也能得到答案，但理解与实现都不如直接 DFS 自然。

常见错误

  • 把位置 p 当作数组下标，而忽略它是满二叉树层内坐标；
  • 误写孩子位置为 2p 和 2p + 1；本题位置从 1 开始；
  • 遇到单个孩子就把当前节点误判成叶子；
  • 用节点值 0 表示“不存在”，从而漏掉合法零值节点；
  • 把所有节点值相加，而不是对每条根到叶路径分别累计。

面试追问

  • 如果树深度不再限制为 4 呢？ 三位整数编码将不够用，应改成二元坐标或字符串键；DFS 思路不变。
  • 可以不用递归吗？ 可以用栈保存 (d, p, prefixSum)，遇到叶子时结算。
  • 为什么哈希键不会冲突？ 当前约束下 p 只有一位，10d + p 唯一表示坐标；若层数扩展，应使用字符串或二元组。
  • 如果要求返回每条路径呢？ DFS 同时维护节点值列表，遇到叶子时复制到结果集。
