LCP 27. 黑盒光线反射

将“孔位 + 入射方向”视作状态。每个状态恰好属于一个反射环；环上只需维护已打开孔位的有序集合，查询下一个开启孔即可。

题意

n×m 黑盒四边共有 2(n+m) 个孔，初始全关。open(index,direction) 打开孔后射入光线，close(index) 关闭孔。光线遇关闭孔反射、遇开启孔射出；返回每次射出的孔号。

约束：1 ≤ n,m ≤ 10⁴，操作数 ≤ 10⁴。角点只允许唯一入射方向。

BlackBox(2,3); open(6,-1) → 6

只有入射孔开启时，环上找不到其他开启孔便绕回自身。

交互：环上后继

请输入当前反射环中的开启位置。

测试与验证

n = 2, m = 3

输入：open(6,-1)

期望：6；实际：待补；状态：Deferred

n = 2, m = 3

输入：open(4,-1)

期望：4；实际：待补；状态：Deferred

n = 3, m = 3

角点反射

期望：环内回绕；实际：待补；状态：Deferred

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

题解：预处理环 + 有序集合

核心洞察

状态 (index,direction) 的下一状态可由边界镜像公式 O(1) 得到。遍历所有未访问状态便得到互不相交的环。一个开启孔会同时加入它的两个方向状态所在的集合；射线从当前状态出发，在同环集合中取严格后继，缺失则取首元素。

复杂度

预处理 O(n+m)，open/close/查询 O(log(n+m))，空间 O(n+m)。

常见错误

  • 只把孔加入一个方向的环。
  • 在角点错误翻转方向。
  • 用线性扫描寻找下一个开启孔。

完整过程

  1. 用镜像公式计算下一孔位。
  2. 非角点反转方向，角点保持方向。
  3. 为每个状态赋予 (group, position)。
  4. 维护每组有序集合并在环上取后继。

面试追问

若要支持批量开启与区间查询，可在每个环上使用平衡树或 Fenwick 树；若边界反射规则改变，只需替换状态转移函数。
