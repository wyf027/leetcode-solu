      Core insight

      核心洞察：下标栈 + 最近断点

      栈初始化为 [-1]。遇到左括号压入下标；遇到右括号先弹栈。若弹空，说明当前右括号无法匹配，把它的下标压回去作为新断点；否则当前合法段长度就是 i - stack.top()。

      Invariant

      栈顶始终是当前合法段左边界

      栈顶要么是最近未匹配左括号，要么是最近无法匹配的右括号。匹配后，从它右边到当前位置必然是连续合法段。

      完整解题过程

      1. 1. 放哨兵

        栈先放 -1，统一处理从 0 开始的合法段。

      2. 2. 扫描与维护

        左括号压下标；右括号弹一次。弹空时把当前下标设为新断点。

      3. 3. 更新答案

        栈未空时计算 i - stack.top()，取历史最大值。

      边界情况

      • 空串、单字符：答案 0。
      • 全是左括号：只压栈，不产生合法段。
      • 全是右括号：断点持续右移。
      • 嵌套与并列合法段都由同一公式处理。

      复杂度

      时间 O(n)：每个下标最多入栈、出栈一次。
      空间 O(n)：最坏全是左括号。

      替代方案

      DP 同为 O(n)，但转移更难现场推导；左右各扫一次可做到 O(1) 空间，却要解释两种失衡方向。面试主线优先下标栈。

      面试高频追问

      为什么不能只存字符？
      题目要的是长度，必须知道合法段左边界下标。
      为什么初始值是 -1？
      让合法段从 0 开始时长度等于 i - (-1)。
      如何做到 O(1) 空间？
      从左到右、再从右到左各做一次计数扫描。

      常见错误

      • ❌ 栈空时忘记压入当前右括号下标，导致跨越非法断点计算。
      • ❌ 栈里只放左括号数量，无法得到连续区间长度。
      • ❌ 返回合法括号对数，而不是字符长度。
      • ❌ 用所有排列或所有子串暴力验证，复杂度过高。

      class Solution {
    public int longestValidParentheses(String s) {
        int maxLength = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i);
                } else {
                    maxLength = Math.max(maxLength, i - stack.peek());
                }
            }
        }
        return maxLength;
    }
}
