最小高度树

Minimum Height Trees

先别急着找算法。

如果树可以从任意节点生根，根放在哪里，最远叶子才会尽可能近？先用示例建立直觉，再进入下方实验。

Problem

题目说明

树是一种无向图：任意两个顶点之间恰好只有一条路径，也就是连通且没有简单环。

给定一棵含 n 个节点的树，节点编号为 0 到 n - 1。数组 edges 含有 n - 1 条边，其中 edges[i] = [aᵢ, bᵢ] 表示节点 aᵢ 与 bᵢ 之间存在无向边。

可以选择任意节点作为根。根为 x 时，树的高度是从根到叶子的最长向下路径所包含的边数。请返回能让高度达到最小值的所有根节点编号，答案顺序不限。

函数形式： findMinHeightTrees(n, edges) → List<Integer>

Examples

官方示例

示例 1

单中心 
输入：n = 4, edges = [[1,0],[1,2],[1,3]]
输出：[1]

以节点 1 为根时，所有叶子只隔一条边，高度为 1；它是唯一答案。

示例 2

双中心 
输入：n = 6, edges = [[3,0],[3,1],[3,2],[3,4],[5,4]]
输出：[3,4]

节点 3 和 4 都位于树的中央，分别作为根时会得到相同的最小高度。

Constraints

约束

  • 1 ≤ n ≤ 2 × 10⁴
  • edges.length == n - 1
  • 0 ≤ aᵢ, bᵢ < n，且 aᵢ != bᵢ
  • 所有边对互不相同；输入保证是一棵树，没有重复边。

Leaf Trimming

题解：从叶子向树心逐层收缩

核心洞察

最小高度树的根一定是树的中心。树的最长路径称为直径，中心恰好是直径中间的一个节点或相邻的两个节点。

所有叶子都处于边界。同步删除最外层叶子，相当于把所有可能根到边界的距离统一减一，因此不会改变剩余节点中谁最居中。不断剥离，最后留下的至多两个节点就是答案。

完整过程

  1. 若 n == 1，唯一节点 0 就是答案。
  2. 建立邻接表，同时统计每个节点的度数。
  3. 把所有度数为 1 的节点加入队列，它们是当前叶子。
  4. 当剩余节点数大于 2 时，同步移除队列中的整层叶子；每移除一条相邻边，就将邻居度数减一。
  5. 某个邻居的度数首次降到 1 时，它成为下一层叶子并入队。
  6. 循环停止时，队列中剩余的一个或两个节点就是所有最小高度树的根。

正确性证明

引理 1：当节点数大于 2 时，叶子不可能比其唯一邻居更适合作为根。把根从叶子移到邻居，通向其余所有节点的距离都减少 1，不会让最大距离变大。

引理 2：同时删除所有叶子后，原树的中心与剩余树的中心相同。任意最长路径的两个端点都是叶子；删除两端使相关路径长度统一减少 2，而路径的中点不变。

结论：依据引理 1 可安全排除每轮叶子，依据引理 2 每轮都保留原树中心。树持续缩小，最终只剩一个或两个节点，它们就是直径的中点，也恰好是全部最小高度树根。

边界与复杂度

  • 单节点：n = 1 时没有边，返回 [0]。
  • 双节点：两端都可作为根，初始剩余数已不大于 2。
  • 星形树：所有外围节点一轮后被剥离，只留下中心。
  • 链：奇数个节点留下一个中心，偶数个节点留下两个中心。
  • 时间：O(n)。每个节点和每条边只被处理常数次。
  • 空间：O(n)，用于邻接表、度数数组和队列。

import java.util.*;

class Solution {
    public List<Integer> findMinHeightTrees(int n, int[][] edges) {
        if (n == 1) {
            return Collections.singletonList(0);
        }

        List<List<Integer>> graph = new ArrayList<>(n);
        for (int i = 0; i < n; i++) {
            graph.add(new ArrayList<>());
        }

        int[] degree = new int[n];
        for (int[] edge : edges) {
            int a = edge[0], b = edge[1];
            graph.get(a).add(b);
            graph.get(b).add(a);
            degree[a]++;
            degree[b]++;
        }

        ArrayDeque<Integer> leaves = new ArrayDeque<>();
        for (int node = 0; node < n; node++) {
            if (degree[node] == 1) {
                leaves.offer(node);
            }
        }

        int remaining = n;
        while (remaining > 2) {
            int layerSize = leaves.size();
            remaining -= layerSize;

            for (int i = 0; i < layerSize; i++) {
                int leaf = leaves.poll();
                for (int neighbor : graph.get(leaf)) {
                    degree[neighbor]--;
                    if (degree[neighbor] == 1) {
                        leaves.offer(neighbor);
                    }
                }
            }
        }

        return new ArrayList<>(leaves);
    }
}

var findMinHeightTrees = function(n, edges) {
    if (n === 1) return [0];

    const graph = Array.from({ length: n }, () => []);
    const degree = new Int32Array(n);

    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
        degree[a]++;
        degree[b]++;
    }

    let leaves = [];
    for (let node = 0; node < n; node++) {
        if (degree[node] === 1) leaves.push(node);
    }

    let remaining = n;
    while (remaining > 2) {
        remaining -= leaves.length;
        const nextLeaves = [];

        for (const leaf of leaves) {
            for (const neighbor of graph[leaf]) {
                degree[neighbor]--;
                if (degree[neighbor] === 1) {
                    nextLeaves.push(neighbor);
                }
            }
        }
        leaves = nextLeaves;
    }

    return leaves;
};
from collections import deque
from typing import List


class Solution:
    def findMinHeightTrees(
        self, n: int, edges: List[List[int]]
    ) -> List[int]:
        if n == 1:
            return [0]

        graph = [[] for _ in range(n)]
        degree = [0] * n

        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)
            degree[a] += 1
            degree[b] += 1

        leaves = deque(
            node for node in range(n) if degree[node] == 1
        )
        remaining = n

        while remaining > 2:
            layer_size = len(leaves)
            remaining -= layer_size

            for _ in range(layer_size):
                leaf = leaves.popleft()
                for neighbor in graph[leaf]:
                    degree[neighbor] -= 1
                    if degree[neighbor] == 1:
                        leaves.append(neighbor)

        return list(leaves)
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> findMinHeightTrees(
        int n, vector<vector<int>>& edges
    ) {
        if (n == 1) return {0};

        vector<vector<int>> graph(n);
        vector<int> degree(n, 0);

        for (const auto& edge : edges) {
            int a = edge[0], b = edge[1];
            graph[a].push_back(b);
            graph[b].push_back(a);
            degree[a]++;
            degree[b]++;
        }

        queue<int> leaves;
        for (int node = 0; node < n; node++) {
            if (degree[node] == 1) leaves.push(node);
        }

        int remaining = n;
        while (remaining > 2) {
            int layerSize = static_cast<int>(leaves.size());
            remaining -= layerSize;

            while (layerSize-- > 0) {
                int leaf = leaves.front();
                leaves.pop();

                for (int neighbor : graph[leaf]) {
                    degree[neighbor]--;
                    if (degree[neighbor] == 1) {
                        leaves.push(neighbor);
                    }
                }
            }
        }

        vector<int> answer;
        while (!leaves.empty()) {
            answer.push_back(leaves.front());
            leaves.pop();
        }
        return answer;
    }
};

替代方案

两次 BFS/DFS 找直径：从任意点出发找到最远点 u，再从 u 找最远点 v 并记录父节点；u → v 路径中间的一个或两个节点就是答案。它同样是 O(n)，但需要恢复路径。

逐个根计算高度：对每个节点都做一次 BFS，时间为 O(n²)，在 n = 2 × 10⁴ 时不可接受。

面试追问

  • 为什么答案最多只有两个？因为树中心是任意直径的中点，中点只有一个节点或一条边的两个端点。
  • 为什么必须“整层”同步删除？逐个删除并立即判断可能把同层节点误当成下一层，破坏层次语义。
  • 如果输入不是树怎么办？应先校验边数、连通性与环；本题契约已保证合法。
  • 能否复用拓扑排序思想？可以，度数就是入队条件，叶层队列与无向图上的拓扑剥离非常相似。

常见错误

  • 忘记单节点特判，导致初始叶子队列为空并返回空答案。
  • 使用当前不断变化的队列长度作为本层循环边界，把下一层叶子提前处理。
  • 把循环条件写成 remaining > 1，从而错误删除偶数长度链的两个中心。
  • 删除邻接表元素造成额外线性开销；只维护度数即可，不需要真的从邻接表移除边。
  • 用递归 DFS 处理很长的链，可能触发语言调用栈限制；队列方案没有这个风险。
