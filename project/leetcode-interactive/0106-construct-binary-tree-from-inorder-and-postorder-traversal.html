01 / The Brief

题意与边界

两条遍历来自同一棵树、节点值互不重复。目标不是输出某个遍历，而是还原原始二叉树的结构。

Problem #106

给定两个整数数组 inorder 与 postorder，它们分别是同一棵二叉树的中序遍历与后序遍历。请构造并返回这棵二叉树。

中序顺序是“左—根—右”，后序顺序是“左—右—根”。节点值唯一，因此根在中序数组中的位置能唯一确定左右子树边界。

关键方向：从后序末端向前取根时，紧挨着根的是右子树的后序末端，所以递归必须先构造右子树，再构造左子树。

官方示例 1

输入 inorder = [9,3,15,20,7] postorder = [9,15,7,20,3]
输出 [3,9,20,null,null,15,7]

官方示例 2

输入 inorder = [-1] postorder = [-1]
输出 [-1]

展示约定：若用例含字符串，将保留成对直引号；符号“␠”表示一个可见空格。本题输入仅含整数数组。

Constraints verified
  • 1 ≤ inorder.length ≤ 3000
  • postorder.length == inorder.length
  • -3000 ≤ inorder[i], postorder[i] ≤ 3000
  • 两个数组中的节点值均互不重复。
  • postorder 中每个值也都出现在 inorder 中。
  • 两条序列保证分别是某棵同一二叉树的合法中序、后序遍历。

    题解默认封存

    核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码都在下方，按需展开。

    核心洞察

    • 后序遍历最后一个未消费元素，就是当前区间的根。
    • 用哈希表记录每个值在中序数组中的索引，可在 O(1) 时间得到切分点。
    • 反向读取后序时顺序为“根—右—左”，所以必须先递归右区间，再递归左区间。

    完整过程

    1. 建立 value → inorder index 映射。
    2. 令后序指针指向数组末尾，初始中序边界为 [0, n - 1]。
    3. 若左边界大于右边界，返回空节点。
    4. 取 postorder[postIndex--] 创建根节点。
    5. 找到根在中序中的索引，先构造右半段，再构造左半段。
    6. 返回当前根，最终得到整棵树。

    边界与不变量

    • 单节点时切分后的左右区间都为空。
    • 完全左斜或右斜树的递归深度会达到 O(n)。
    • 节点值唯一是哈希定位与唯一还原的前提。
    • 递归调用内始终只处理 inorder[left..right] 对应的子树。

    替代方案取舍

    • 每次线性扫描中序：直观但最坏 O(n²)，不推荐。
    • 数组切片：代码短，却产生额外复制与更多空间开销。
    • 迭代栈：能避开递归深度，但证明与实现更绕，面试主线通常不如区间递归清晰。

    复杂度

    项目 复杂度 原因
    时间 O(n) 每个节点恰好创建一次，哈希定位均摊 O(1)。
    辅助空间 O(n) 索引哈希表 O(n)，递归栈最坏 O(n)、平衡时 O(log n)。

    面试追问

    • 为什么反向读取后序必须先建右子树？
    • 如果节点值允许重复，如何额外消歧？
    • 如何改为迭代写法以规避极深递归？
    • 若给的是前序与后序，为什么通常不能唯一还原？

    常见错误

    • 仍按“先左后右”递归，导致后序指针消费错位。
    • 切分边界写成 [left, split]，重复包含根。
    • 每层都扫描或切片中序数组，使复杂度退化。
    • 把后序指针写成局部值传递，子递归之间无法共享消费进度。

    class Solution {
    private int postIndex;
    private int[] postorder;
    private Map<Integer, Integer> inorderIndex;

    public TreeNode buildTree(int[] inorder, int[] postorder) {
        this.postorder = postorder;
        this.postIndex = postorder.length - 1;
        this.inorderIndex = new HashMap<>();

        for (int i = 0; i < inorder.length; i++) {
            inorderIndex.put(inorder[i], i);
        }

        return build(0, inorder.length - 1);
    }

    private TreeNode build(int left, int right) {
        if (left > right) {
            return null;
        }

        int rootValue = postorder[postIndex--];
        TreeNode root = new TreeNode(rootValue);
        int split = inorderIndex.get(rootValue);

        root.right = build(split + 1, right);
        root.left = build(left, split - 1);
        return root;
    }
}
