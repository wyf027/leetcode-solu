删除无效的括号
Remove Invalid Parentheses

从一串可能失衡的括号中，删掉尽可能少的字符，并收集所有互不重复的有效答案。先理解目标，再用逐层搜索观察“最少删除”如何自然出现。

困难 广度优先搜索 回溯 字符串 非付费题
Problem

题目说明

输入中只有小写字母与圆括号；字母始终保留语义，只需要处理括号的合法性。

给定字符串 s，它由括号和小写英文字母组成。删除最少数量的无效括号，使剩余字符串中的括号配对有效。

返回所有可能且互不重复的结果；答案顺序不限。完整参数形式为：

removeInvalidParentheses(s: string) → list<string>
有效括号串

从左向右扫描时，任意前缀中的右括号数量都不能多于左括号；扫描结束后两者数量相同。字母不会影响平衡值。

约束

  • 1 ≤ s.length ≤ 25
  • s 只包含小写英文字母、( 和 )
  • s 中至多有 20 个括号
  • 返回值中的字符串必须唯一
  • 结果可以按任意顺序返回
Example 01
输入：s = "()())()"
输出：["(())()", "()()()"]
Example 02
输入：s = "(a)())()"
输出：["(a())()", "(a)()()"]
Example 03
输入：s = ")(" 
输出：[""]

Solution

题解：按删除数分层搜索

主解采用广度优先搜索。队列中的每一层都对应相同的删除次数，因此第一次找到有效字符串后，不再生成更深层节点。

核心洞察

把输入字符串看作搜索树的根。每条边代表“删除当前位置的一个括号”，于是深度 d 恰好对应删除了 d 个括号的所有候选。

广度优先搜索天然按深度递增访问。只要某一层出现有效串，该层的全部有效串就是最少删除答案；更深层一定删得更多。

  1. 把原串放入集合，作为当前层。
  2. 检查当前层所有字符串，将有效串加入答案集合。
  3. 如果答案非空，立即返回当前层答案。
  4. 否则，对每个候选逐个删除括号，借助去重集合生成下一层；字母不参与删除。
  5. 重复直到命中。空串一定是括号意义上的有效串，因此搜索必然结束。

合法性检查

令 balance 表示未匹配的左括号数：

  • 遇到 ( 时加一；
  • 遇到 ) 时减一；
  • 若中途小于零，立刻判无效；
  • 结束时必须恰好等于零。
停止条件 当前层至少有一个有效串

仍要检查完本层，才能收齐全部最优答案。

Correctness

正确性证明

层级含义：通过归纳可知，第 d 层中的每个字符串都由原串删除恰好 d 个括号得到；所有能以这种方式得到的字符串也都会被生成，集合只消除重复项。
最小性：设 BFS 首次在第 k 层发现有效串。此前每个深度小于 k 的候选都已被检查且无效，所以不可能通过少于 k 次删除得到有效结果。
完整性：算法不会在命中某个有效串时立刻打断本层，而是检查本层全部候选，因此会收集所有删除恰好 k 个括号的有效串。
结论：返回集合中的字符串全部有效、删除数量最少，且所有最少删除的唯一结果都在集合中。
Complexity

复杂度分析

设字符串长度为 n，括号数量为 p（题目保证 p ≤ 20）。不同删除子集最多有 2^p 个，每个候选的合法性检查需要 O(n)。

  • 时间复杂度：最坏 O(2^p · n)
  • 空间复杂度：最坏 O(2^p · n)，用于候选字符串与去重集合
Edges

边界情况

  • 输入本来有效：第 0 层直接返回原串。
  • 只有字母：不删除任何字符，返回原串。
  • 全部括号都无法配对，如 ")("：最终返回空串。
  • 连续相同括号会产生重复子节点：必须用集合去重。
  • 同层可能出现多个答案：命中后要完成整层检查。
Alternatives

替代方案比较

方案如何保证最少删除优势代价
BFS（本解）首次命中的层级就是最小删除数直观，停止条件清晰需要保存整层候选，峰值内存较高
计数 + 回溯先计算必须删除的左右括号数，只枚举恰好该数量的删除剪枝更强，通常更快状态与去重逻辑更细致
双向扫描删除发现首个失衡位置时只删除同类括号，反转后处理另一侧经典且高效，减少无效分支证明与实现更难在面试中一次写对

import java.util.*;

class Solution {
    public List<String> removeInvalidParentheses(String s) {
        Set<String> current = new HashSet<>();
        current.add(s);

        while (!current.isEmpty()) {
            List<String> answer = new ArrayList<>();
            for (String candidate : current) {
                if (isValid(candidate)) {
                    answer.add(candidate);
                }
            }
            if (!answer.isEmpty()) {
                return answer;
            }

            Set<String> next = new HashSet<>();
            for (String candidate : current) {
                for (int i = 0; i < candidate.length(); i++) {
                    char ch = candidate.charAt(i);
                    if (ch != '(' && ch != ')') {
                        continue;
                    }
                    String child = candidate.substring(0, i)
                            + candidate.substring(i + 1);
                    next.add(child);
                }
            }
            current = next;
        }

        return Collections.singletonList("");
    }

    private boolean isValid(String value) {
        int balance = 0;
        for (int i = 0; i < value.length(); i++) {
            char ch = value.charAt(i);
            if (ch == '(') {
                balance++;
            } else if (ch == ')') {
                balance--;
                if (balance < 0) {
                    return false;
                }
            }
        }
        return balance == 0;
    }
}

            if (isValid(candidate)) {

from typing import List


class Solution:
    def removeInvalidParentheses(self, s: str) -> List[str]:
        current = {s}

        while current:
            answer = [candidate for candidate in current
                      if self._is_valid(candidate)]
            if answer:
                return answer

            next_level = set()
            for candidate in current:
                for i, ch in enumerate(candidate):
                    if ch not in "()":
                        continue
                    next_level.add(candidate[:i] + candidate[i + 1:])
            current = next_level

        return [""]

    def _is_valid(self, value: str) -> bool:
        balance = 0
        for ch in value:
            if ch == "(":
                balance += 1
            elif ch == ")":
                balance -= 1
                if balance < 0:
                    return False
        return balance == 0
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> removeInvalidParentheses(string s) {
        unordered_set<string> current = {s};

        while (!current.empty()) {
            vector<string> answer;
            for (const string& candidate : current) {
                if (isValid(candidate)) {
                    answer.push_back(candidate);
                }
            }
            if (!answer.empty()) {
                return answer;
            }

            unordered_set<string> next;
            for (const string& candidate : current) {
                for (int i = 0; i < static_cast<int>(candidate.size()); i++) {
                    if (candidate[i] != '(' && candidate[i] != ')') {
                        continue;
                    }
                    next.insert(candidate.substr(0, i)
                                + candidate.substr(i + 1));
                }
            }
            current = move(next);
        }

        return {""};
    }

private:
    bool isValid(const string& value) {
        int balance = 0;
        for (char ch : value) {
            if (ch == '(') {
                balance++;
            } else if (ch == ')') {
                balance--;
                if (balance < 0) {
                    return false;
                }
            }
        }
        return balance == 0;
    }
};

Pitfalls

常见错误

  • 对每个字符都生成删除分支，误删字母。
  • 只用最终平衡值判断，忽略扫描途中余额为负。
  • 缺少集合去重，导致指数级重复节点。
  • 命中本层第一个答案就返回，漏掉同层其他最优解。
  • 命中有效层后仍继续生成下一层，混入非最小删除结果。
