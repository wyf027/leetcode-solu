公司命名。

Naming a Company / 交换一个字母，能创造多少种新名字？

01 / 任务说明

给定互不重复的名字数组 ideas，选取两个不同的名字，并交换它们的首字母。只有交换后的两个名字都不在原数组中，才能把这两个新名字按顺序用一个空格连接，形成有效的公司名字。返回不同有效公司名字的数量。

顺序有意义："doffee conuts" 与 "conuts doffee" 是两个名字。原名字集合始终不变，生成的新名字不会加入集合。

输入 / 输出

distinctNames(ideas: string[]) → long

返回数量，不需要返回公司名字列表。

约束
  • 2 ≤ ideas.length ≤ 5 × 10⁴
  • 1 ≤ ideas[i].length ≤ 10
  • 每个名字仅含小写英文字母。
  • 数组内所有字符串互不相同。

示例 1

输入：ideas = ["coffee","donuts","time","toffee"]
输出：6

有效结果恰好是以下六个：

doffee conuts
conuts doffee
tonuts dime
tonuts doffee
dime tonuts
doffee tonuts

选 coffee 与 time 会得到已有的 toffee，因此无效；time 与 toffee 首字母相同，交换后仍是已有名字；coffee 与 toffee 交换后两个名字都已存在。

示例 2

输入：ideas = ["lack","back"]
输出：0

交换首字母后得到 back 与 lack，两个都在原数组中，没有合法选择。

04 / 独立题解

准备好后，揭开计数方法与完整实现。

按首字母分组，排除共同后缀

核心洞察

将名字写成「首字母 + 后缀」。为每个字母 a 建立后缀集合 Sₐ。对于不同首字母 a、b，若从 Sₐ 取后缀 x，交换后生成 bx；它已经存在，当且仅当 x ∈ Sᵦ。因此，共同后缀在两边都不能被选。

c = |Sₐ ∩ Sᵦ|
该组对贡献 = 2 × (|Sₐ| − c) × (|Sᵦ| − c)

分别从 Sₐ \ Sᵦ 与 Sᵦ \ Sₐ 任取一个后缀，两个新名字都不存在。乘 2 表示两种连接顺序；只枚举 a < b，避免重复计算组对。

完整过程 · 示例 1

  1. 扫描输入，构建 26 个后缀集合：S_c = {offee}、S_d = {onuts}、S_t = {ime, offee}。
  2. 组 c 与 d：交集为空，贡献 2 × 1 × 1 = 2。
  3. 组 c 与 t：共同后缀为 offee，贡献 2 × 0 × 1 = 0。
  4. 组 d 与 t：交集为空，贡献 2 × 1 × 2 = 4。
  5. 含空集合的组对贡献为 0；合计 2 + 0 + 4 = 6。

正确性证明

必要性：首字母相同的两个名字交换后不变，必然无效。不同首字母 a、b 的选择若有效，其后缀 x 不能属于 Sᵦ，后缀 y 不能属于 Sₐ，否则对应的新名字已存在。

充分性：若 x ∈ Sₐ \ Sᵦ 且 y ∈ Sᵦ \ Sₐ，则 bx 和 ay 均不在原集合，所以每个这样的组合都有效。

不重不漏：每个有效选择对应唯一首字母组对及唯一后缀组合，均被乘积计数覆盖。交换首字母是可逆操作，不同有序原名字对不会映射到同一有序新名字对。两个顺序产生的名字不同，故乘 2 正确。

边界与数值范围

  • 长度为 1 的名字拥有空后缀 ""，集合可以直接处理。
  • 同首字母、后缀集合完全重合或有空组时，贡献为 0。
  • 无交集时贡献为两组大小乘积的两倍。
  • 总答案不超过 n(n−1) = 2,499,950,000，可能超过 32 位有符号整数。Java 使用 long，C++ 使用 long long，并在乘法前提升类型。
  • JavaScript Number 的安全整数范围足够；Python int 自动支持大整数。

复杂度

设 n 为名字数，L 为最大长度，Σ = 26。构建集合需要 O(nL)。对每对组遍历第一个集合并查询第二个集合，每个后缀最多被扫描 25 次。在哈希表平均查找假设下，计入字符串哈希成本，时间为 O(ΣnL + Σ²)，空间为 O(nL + Σ)。固定 Σ = 26、L ≤ 10 时通常简写为 O(n) 时间与 O(n) 空间；不包含输入本身。

替代方案与取舍

  • 暴力有序枚举：逐对交换并用哈希集合判断，O(n²L) 时间，适合小输入规则演示，无法承受 5 万个名字。
  • 定向计数表：记录首字母 a 的名字改成 b 后不存在的数量 cnt[a][b]，累加 2 × cnt[a][b] × cnt[b][a]（a < b）。同为 O(ΣnL)，但会构造更多临时字符串。
  • 按后缀建位掩码：用 26 位记录某后缀出现过的首字母，统计可兼容字母对；表示紧凑，计数解释比后缀集合更复杂。

常见错误

  • 只检查一个新名字：题目要求两个都不在原集合。
  • 忘记乘 2，或在遍历全部有序组对后又乘 2。
  • 只从一侧减交集：共同后缀对两边都不可用。
  • 把新名字加入集合，改变后续判断依据。
  • Java/C++ 使用 32 位中间乘法后才转为 64 位。

面试追问

若不区分连接顺序？去掉乘 2。若要求输出所有名字？枚举两个差集的笛卡尔积，输出规模本身可能达 O(n²)。字母表很大？仅保存实际出现的首字母组，代价取决于实际组数 k，最坏组对枚举 O(k²)。

Java

import java.util.*;

class Solution {
    public long distinctNames(String[] ideas) {
        List<Set<String>> groups = new ArrayList<>();
        for (int i = 0; i < 26; i++) groups.add(new HashSet<>());
        for (String s : ideas) {
            groups.get(s.charAt(0) - 'a').add(s.substring(1));
        }
        long answer = 0;
        for (int a = 0; a < 26; a++) {
            for (int b = a + 1; b < 26; b++) {
                int common = 0;
                for (String suffix : groups.get(a)) {
                    if (groups.get(b).contains(suffix)) common++;
                }
                answer += 2L * (groups.get(a).size() - common)
                             * (groups.get(b).size() - common);
            }
        }
        return answer;
    }
}

var distinctNames = function(ideas) {
    const groups = Array.from({ length: 26 }, () => new Set());
    for (const s of ideas) {
        groups[s.charCodeAt(0) - 97].add(s.slice(1));
    }
    let answer = 0;
    for (let a = 0; a < 26; a++) {
        for (let b = a + 1; b < 26; b++) {
            let common = 0;
            for (const suffix of groups[a]) {
                if (groups[b].has(suffix)) common++;
            }
            answer += 2 * (groups[a].size - common)
                        * (groups[b].size - common);
        }
    }
    return answer;
};

Python 3

from typing import List

class Solution:
    def distinctNames(self, ideas: List[str]) -> int:
        groups = [set() for _ in range(26)]
        for name in ideas:
            groups[ord(name[0]) - ord('a')].add(name[1:])
        answer = 0
        for a in range(26):
            for b in range(a + 1, 26):
                common = sum(suffix in groups[b] for suffix in groups[a])
                answer += 2 * (len(groups[a]) - common) * (len(groups[b]) - common)
        return answer

C++

#include <array>
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    long long distinctNames(vector<string>& ideas) {
        array<unordered_set<string>, 26> groups;
        for (const string& s : ideas) {
            groups[s[0] - 'a'].insert(s.substr(1));
        }
        long long answer = 0;
        for (int a = 0; a < 26; ++a) {
            for (int b = a + 1; b < 26; ++b) {
                long long common = 0;
                for (const string& suffix : groups[a]) {
                    if (groups[b].count(suffix)) ++common;
                }
                long long left = static_cast<long long>(groups[a].size()) - common;
                long long right = static_cast<long long>(groups[b].size()) - common;
                answer += 2LL * left * right;
            }
        }
        return answer;
    }
};
