破解保险箱Cracking the Safe

把所有可能的密码压进一条最短输入串。先理解保险箱如何读取“最近的 n 位”，再进入路径实验室观察每个密码窗口如何被恰好覆盖。

难度：困难 深度优先搜索 欧拉回路 De Bruijn 序列

Problem

题目说明

保险箱的密码由 n 个数字组成，每一位都在 [0, k - 1] 内。每输入一个数字，保险箱都会检查截至当前输入的最后 n 位；只要这段后缀等于真实密码，保险箱就会打开。

你不知道真实密码，只知道 n 与 k。请返回任意一个长度最短的字符串，使全部 kⁿ 种可能密码都曾作为某个长度为 n 的连续窗口出现。这样，无论真实密码是哪一种，输入过程中都一定会解锁。

校验方式示例：若密码是 345，依次输入 012345 时，保险箱检查的完整三位窗口依次为 012、123、234、345，最后一次匹配并解锁。

必须覆盖的不同密码数

kn

最短输入串长度

kn + n − 1

第一个窗口需要 n 位，此后每新增一位最多带来一个新窗口。

1示例一

输入n = 1, k = 2
输出"10"

密码只有一位，依次输入 1 和 0 即覆盖全部可能；"01" 也同样有效。

2示例二

输入n = 2, k = 2
输出"01100"

连续两位窗口依次为 01、11、10、00，刚好覆盖四种密码。"10011"、"11001" 等最短串也有效。

约束

  • 1 ≤ n ≤ 4
  • 1 ≤ k ≤ 10
  • 1 ≤ kn ≤ 4096

Solution

欧拉回路：让每种密码成为一条边

目标不是枚举后拼接，而是尽量复用相邻密码的公共前后缀。这个问题正是 De Bruijn 图上的欧拉回路。

核心洞察

把长度为 n 的密码看成边，而不是节点。一条密码 x₁x₂…xₙ 从节点 x₁…xₙ₋₁ 指向节点 x₂…xₙ。沿边追加的最后一个数字就是新输入的一位。

共有 kⁿ⁻¹ 个节点；每个节点恰有 k 条出边和 k 条入边。每条边唯一对应一种可能密码。因此，走过每条边恰好一次的欧拉回路，就会把所有密码窗口恰好覆盖一次。

最终序列包含 kⁿ 个边标签，并补上起始节点的 n−1 位，总长度为 kⁿ + n − 1，达到理论下界。

完整过程

  1. 取起点 start = "0" × (n−1)；当 n = 1 时起点为空串。
  2. 为每个节点记录下一个尚未尝试的数字。节点 u 追加数字 d 后，下一节点为 (u + d) 去掉首字符。
  3. 使用 Hierholzer 算法：有未使用出边就继续压栈；没有出边时回退，并把进入当前节点所用的数字加入后序答案。
  4. 栈清空后，后序收集的数字已经构成所需环的一种线性顺序。把起始节点追加在末尾，得到最终字符串。

以 n = 2，k = 2 为例

节点为 0、1；四条边分别是 00、01、10、11。一种后序边标签为 0110，末尾补起点 0 后得到 01100。

正确性证明

  1. 每个密码都有唯一对应边。任意长度为 n 的串，其前 n−1 位与后 n−1 位确定一条有向边；反过来，节点和追加数字也唯一确定该密码。
  2. 图存在欧拉回路。每个节点的入度和出度都为 k；同时可以通过不断追加目标数字在节点间到达所需后缀，所以所有含边节点处于同一连通结构。平衡且连通的有向图存在欧拉回路。
  3. 算法恰好使用每条边一次。每个节点的 next 指针只递增，因而同一出边不会重复；Hierholzer 算法持续走未使用边并在死路回退，最终纳入全部可达边，而本图全部边均可达。
  4. 输出覆盖全部密码。欧拉回路相邻边首尾相接，输出边标签并补上起始节点后，每个连续 n 位窗口对应回路中的一条边，因此全部 kⁿ 种密码各出现一次。
  5. 输出长度最短。任意字符串若覆盖 kⁿ 个不同长度 n 的窗口，长度 L 必须满足 L−n+1 ≥ kⁿ，即 L ≥ kⁿ+n−1。算法输出恰好达到此长度。

边界情况

  • n = 1：节点是空串，每个数字是一条自环；输出会包含 0 到 k−1 各一次，顺序任意。
  • k = 1：只有数字 0，也只有一条密码边；答案就是 n 个 0。
  • 存在多个正确答案：遍历数字的先后顺序、起点或环的旋转方式不同，都可能产生不同但同样最短的字符串。
  • 递归深度：边数最多 4096。下面采用显式栈，避免某些语言在深递归时触发栈限制。

复杂度

时间复杂度概念上 O(kⁿ)。若把长度不超过 n 的字符串切片成本计入，则为 O(n · kⁿ)；本题 n ≤ 4。
空间复杂度O(kⁿ)，用于边访问状态、显式栈和输出；输出自身也有 Θ(kⁿ) 长度。

替代方案

回溯搜索字符串

可以从若干个 0 开始，不断尝试追加数字，并用集合记录新产生的 n 位窗口；当集合大小达到 kⁿ 时返回。这实际上仍在构造 De Bruijn 序列，但普通回溯可能探索大量失败分支，缺少 Hierholzer 的线性保证。

经典 De Bruijn 序列递归构造

可使用 Lyndon word / FKM 算法直接生成 De Bruijn 序列，空间更紧凑、常数也很好，但推导更专门。面试中图建模加欧拉回路通常更直观，也更容易证明。

四种语言完整代码

四份实现都使用显式栈版 Hierholzer 算法，并符合官方函数签名。遍历数字从 0 到 k−1，但题目允许返回任意合法最短串。

Java · 官方签名 crackSafe(int n, int k)
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String crackSafe(int n, int k) {
        String start = "0".repeat(n - 1);
        Map<String, Integer> nextEdge = new HashMap<>();
        Deque<String> nodes = new ArrayDeque<>();
        Deque<Character> incoming = new ArrayDeque<>();
        StringBuilder circuit = new StringBuilder();

        nodes.addLast(start);
        while (!nodes.isEmpty()) {
            String node = nodes.peekLast();
            int digit = nextEdge.getOrDefault(node, 0);

            if (digit < k) {
                nextEdge.put(node, digit + 1);
                char label = (char) ('0' + digit);
                String nextNode = (node + label).substring(1);
                nodes.addLast(nextNode);
                incoming.addLast(label);
            } else {
                nodes.removeLast();
                if (!incoming.isEmpty()) {
                    circuit.append(incoming.removeLast());
                }
            }
        }

        return circuit.append(start).toString();
    }
}
JavaScript · 官方签名 crackSafe(n, k)
/**
 * @param {number} n
 * @param {number} k
 * @return {string}
 */
var crackSafe = function(n, k) {
    const start = "0".repeat(n - 1);
    const nextEdge = new Map();
    const nodes = [start];
    const incoming = [];
    const circuit = [];

    while (nodes.length > 0) {
        const node = nodes[nodes.length - 1];
        const digit = nextEdge.get(node) ?? 0;

        if (digit < k) {
            nextEdge.set(node, digit + 1);
            const label = String(digit);
            nodes.push((node + label).slice(1));
            incoming.push(label);
        } else {
            nodes.pop();
            if (incoming.length > 0) {
                circuit.push(incoming.pop());
            }
        }
    }

    return circuit.join("") + start;
};

class Solution:
    def crackSafe(self, n: int, k: int) -> str:
        start = "0" * (n - 1)
        next_edge = {}
        nodes = [start]
        incoming = []
        circuit = []

        while nodes:
            node = nodes[-1]
            digit = next_edge.get(node, 0)

            if digit < k:
                next_edge[node] = digit + 1
                label = str(digit)
                nodes.append((node + label)[1:])

        return "".join(circuit) + start

class Solution {
public:
    string crackSafe(int n, int k) {
        string start(n - 1, '0');
        unordered_map<string, int> nextEdge;
        vector<string> nodes{start};
        vector<char> incoming;

                nextEdge[node] = digit + 1;
                char label = char('0' + digit);

                nodes.push_back(nextNode);
                incoming.push_back(label);

                nodes.pop_back();
                if (!incoming.empty()) {
                    circuit.push_back(incoming.back());
                    incoming.pop_back();
                }
            }
        }

        return circuit + start;
    }

面试追问

  • 为什么密码必须建成边？
    因为相邻密码共享 n−1 位，图的转移正好表达这段重叠；“每种密码一次”自然变成“每条边一次”。
  • 如果要求字典序最小怎么办？
    需要明确比较的是哪种线性表示。可固定起点并调整边的访问顺序，再结合最终后序方向判断；由于欧拉环可旋转，还可能需要选择最小旋转。
  • 如何验证一个候选答案？
    检查长度等于 kⁿ+n−1、每个字符在合法范围内，并把所有长度 n 的窗口放入集合，确认集合大小为 kⁿ。
  • 能否不用字符串表示节点？
    可以。把节点视为 k 进制整数，转移为 (node × k + digit) mod kⁿ⁻¹，减少切片和哈希字符串开销。

常见错误

  • 把长度 n 的密码作为节点，然后寻找哈密顿路径；这会把问题变难，且没有利用 n−1 位重叠。
  • 在第一次到达节点时就标记节点，导致同一节点的其他合法出边永远无法使用。需要标记的是边。
  • 走边时立刻把数字写入最终答案，却不处理走入死路后的拼接顺序；Hierholzer 应在回退时后序收集。
  • 忘记在边标签末尾补上起始节点的 n−1 位，导致末尾窗口缺失或总长度不对。
  • 误以为输出必须与示例完全一致。题目接受任意覆盖全部密码的最短字符串。
