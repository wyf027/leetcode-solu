2167 / 移除所有载有违禁货物车厢所需的最少时间

Minimum Time to Remove All Cars Containing Illegal Goods

两端移除花费 1，任意位置移除花费 2。如何让列车清空违禁货物的总时间最少？

官方题目 ↗非付费题参数：字符串 s → 整数
01 / 题目

清理列车

给定从下标 0 开始的二进制字符串 s，每个字符对应一节车厢：'0' 表示没有违禁货物，'1' 表示载有违禁货物。

你可以按任意顺序、任意次数执行以下操作：

1移除当前最左端的一节车厢
1移除当前最右端的一节车厢
2移除当前任意位置的一节车厢

返回让所有载有违禁货物的车厢都被移除的最少总时间。允许删除无违禁货物的车厢，也允许删空整列车；空列车满足要求。

约束

  • 1 ≤ s.length ≤ 2 × 105
  • s[i] 只能是 '0' 或 '1'。

官方示例

示例 1

输入：s = "1100101"
输出：5

先从左端删除 2 节，再从右端删除 1 节，最后删除中间载有违禁货物的一节，总耗时 2 + 1 + 2 = 5。

也可以从左端删 2 节、右端删 3 节，同样耗时 5；不存在更低的总耗时。

示例 2

输入：s = "0010"
输出：2

直接移除载有违禁货物的一节耗时 2；从右端连续删 2 节也耗时 2。

从左端连续删 3 节需要 3，因而最少时间是 2。

03 / 独立题解

准备好再看解法

包含交互推演、正确性证明与四语言代码。

前缀最优代价 + 整段右删

核心洞察

固定一个分界点：左边的前缀只用“从左端删除”和“任意位置删除”清理违禁车厢；右边的后缀全部从右端删掉。枚举分界点，就覆盖了一个全局最优方案。

令 L 为当前前缀只用上述两种操作的最小代价。读到安全车厢时无须处理；读到违禁车厢时，要么额外支付 2 单独删除，要么从左端删掉整个前缀。

s[i] = '0'：L 保持不变
s[i] = '1'：L = min(L + 2, i + 1)
候选总时间 = L + (n − i − 1)
ans = min(ans, 候选总时间)

完整过程

  1. 初始化 L = 0、ans = n，表示空前缀以及从右端删除全部车厢的可行方案。
  2. 从左到右扫描每个字符。遇到 1，比较“此前最优代价 + 2”与“前缀长度 i + 1”；遇到 0，保持 L。
  3. 将剩余后缀全部从右端删除，代价为 n − i − 1，用总成本更新答案。
  4. 扫描结束时后缀为空，这种分界同样被枚举。返回 ans。

示例 s = "1100101" 的 L 依次为 1, 2, 2, 2, 4, 4, 6，候选总代价依次为 7, 7, 6, 5, 6, 5, 6，最小值为 5。注意最终的 L = 6 并非全局答案。

正确性证明

一、前缀递推正确。 空前缀的最小代价为 0。若新字符为 0，保留它即可；删除它不能帮助清理位于它左侧的违禁车厢，因此最优代价不变。若新字符为 1，不使用右删时，它只能被任意位置操作删除，或被左删删除。前者可先将它删除，随后按此前前缀的最优方案处理，代价为 L + 2；后者意味着整个前缀均被删去，每节至少付 1，总价至少 i + 1，而连续左删可以达到该值。取二者最小即得到新的前缀最优值。

二、分界枚举覆盖最优方案。 对任意合法操作序列，取被右端操作删除过的最靠左的原始位置 r；若没有右删则令 r = n。原始位置 r 及其右侧车厢必定全被删除，否则 r 无法到达右端。原方案对这段后缀每节至少支付 1，因此可将其替换为直接从右端逐节删除，代价不增。剩余前缀没有右删操作，可仅用左删与任意位置删除完成，最小代价正是对应的 L。因此存在最优解属于所枚举的分界方案。

三、取最小即为答案。 每个候选都能实际执行：先从右端删掉后缀，再按前缀方案清理。候选中又包含最优方案，故候选最小值恰为全局最小时间。

边界与复杂度

  • 全为 0：L 始终为 0，扫描至末尾得到答案 0。
  • 全为 1：每节都必须删，每节至少耗时 1，连续端删可达到 n。
  • n = 1：输入 0 返回 0，输入 1 返回 1。题目不接受空字符串，但删除后可以为空。
  • 答案范围是 [0, n]，普通 32 位整数足够。
  • 时间复杂度 O(n)，提交代码额外空间 O(1)。教学演示为了回退保留 O(n) 状态，且限制到 40 节。

Java

class Solution {
    public int minimumTime(String s) {
        int n = s.length(), left = 0, ans = n;
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '1') {
                left = Math.min(left + 2, i + 1);
            }
            ans = Math.min(ans, left + n - i - 1);
        }
        return ans;
    }
}

替代方案

左右 DP： 分别计算每个前缀只用左删和任意删的最小成本，以及每个后缀只用右删和任意删的最小成本；遍历所有分界取两者之和的最小值。时间 O(n)，额外空间 O(n)，更容易恢复具体操作。

最小子段和： 选择一段保留的中间区间，区间外端删，区间内每个 1 单删。总代价为 n − 区间长度 + 2 × 区间内 1 的数量。把 0 映射为 −1、1 映射为 +1，答案是 n + min(0, 最小非空子段和)。允许空区间对应整列删光，可用 Kadane 变体做到 O(n) 时间、O(1) 空间。

常见错误

  • 只统计 1 的数量再乘 2：忽略了端删更便宜。
  • 每个 1 都独立选择最近端点：多个删除共享端点成本，不能独立相加。
  • 遇到 0 时将 L 加 1：前缀目标是清除违禁车厢，安全车厢可以保留。
  • 将右侧长度写成 n − i：当前车厢已经计入前缀。
  • 返回最终 L：漏掉先前分界处更优的右删组合。
  • 反复切割字符串模拟：可能退化到 O(n²)，无法适应 200000 的长度。

面试追问

如何返回实际删除方案？ 记录最优分界点与每个前缀状态的选择，再回溯出左端删除范围和需单独删除的违禁车厢；保留原始下标以免删除后索引混淆。

三种费用变成 a、b、c 呢？ 当它们均为非负数时，可使用左右 DP：左侧读到 1 时取 min(L + c, (i + 1) × a)，右侧对称使用 b，再枚举分界。当前“后缀全部右删”的覆盖证明依赖右删单位费用不高于其他删除费用，不能无条件照搬。

为什么可以压缩成常数空间？ 当前 L 只依赖前一个 L，右删后缀的成本直接由下标算出，无需保存整张表；只有回溯展示方案才需要补充决策信息。
