题目

函数签名：shortestPathAllKeys(grid: string[]): number

任务描述

给定一个 m × n 字符网格，从唯一的起点 @ 出发。每次可以向上、下、左、右移动一格，但不能越界或进入墙 #。

小写字母表示钥匙，大写字母表示对应门锁。经过钥匙会永久获得它；只有持有对应钥匙时才能通过门锁。返回收集全部钥匙所需的最少移动次数；无法完成则返回 -1。

约束

  • m == grid.length，n == grid[i].length
  • 1 ≤ m, n ≤ 30
  • 网格仅含英文字母、.、# 与 @
  • 恰有一个起点 @
  • 钥匙数量在 [1, 6]，每把钥匙唯一
  • 每把钥匙都有同字母的大写门锁与之对应

注意：目标是拿到所有钥匙，而不是打开所有门锁。

核心洞察

搜索状态不是单独的坐标，而是 (行, 列, 钥匙掩码)。位置相同但持有钥匙不同，未来能通过的门也不同。

把至多 6 把钥匙压缩进一个整数：第 i 位为 1 表示已持有字母 'a' + i。目标掩码是 (1 << k) - 1。

完整过程

扫描网格。

找到起点并统计钥匙数，构造全钥匙目标掩码。

从零钥匙状态开始 BFS。

队列保存行、列、钥匙掩码和距离；访问集合同时包含三者。

检查四个邻居。

墙和越界直接跳过；遇到没有对应钥匙的锁也跳过。

更新钥匙集合。

若邻格是小写字母，用按位或把对应位设为 1。

命中目标。

首次得到目标掩码时立即返回当前距离加一；队列耗尽则返回 -1。

正确性证明

状态完备性：坐标决定当前所在格，掩码决定能通过哪些锁；二者足以决定所有合法后继。
转移正确性：算法仅加入未越界、非墙且门锁可通行的邻格，并在经过钥匙时更新对应位，因此恰好枚举所有合法移动。
最短性：BFS 按移动次数非递减处理状态。首次出现全钥匙掩码的状态，其距离不可能被任何尚未处理的状态改进。
终止性：状态总数至多 m·n·2^k，每个状态只入队一次，故搜索必然结束。

复杂度

设钥匙数为 k ≤ 6。时间复杂度 O(mn·2^k)，每个状态最多检查 4 个方向；空间复杂度 O(mn·2^k)。

边界情况

  • 钥匙被自己的门锁隔在后方，返回 -1。
  • 拿到最后一把钥匙即可返回，无需再开锁。
  • 同一坐标可能需要以更丰富的钥匙集合再次访问。
  • 一行或一列网格仍使用相同四向转移。

替代方案、面试追问与常见错误

替代方案：可压缩起点和钥匙为关键点，再做子集 DP；但门锁使两点间的可达性依赖当前钥匙集合，预处理明显更复杂。只有 6 把钥匙时，直接对网格状态做 BFS 更稳健。

面试追问：若钥匙增至 20 把，可考虑关键点压缩、预计算带门条件的路径并使用子集 DP；若每格移动代价不全为 1，应将 BFS 替换为 Dijkstra。

常见错误：只用坐标去重；把目标误写成开完所有门；检查门锁后忘记更新钥匙；按层计步时出现加一偏差；移位前忘记减去 'a' 或 'A'。

import java.util.*;

class Solution {
    public int shortestPathAllKeys(String[] grid) {
        int m = grid.length, n = grid[0].length();
        int sr = 0, sc = 0, keyCount = 0;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                char ch = grid[r].charAt(c);
                if (ch == '@') { sr = r; sc = c; }
                if (ch >= 'a' && ch <= 'f') keyCount++;
            }
        }
        int target = (1 << keyCount) - 1;
        boolean[][][] seen = new boolean[m][n][1 << keyCount];
        ArrayDeque<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{sr, sc, 0, 0});
        seen[sr][sc][0] = true;
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            for (int[] d : dirs) {
                int nr = cur[0] + d[0], nc = cur[1] + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                char ch = grid[nr].charAt(nc);
                if (ch == '#') continue;
                int mask = cur[2];
                if (ch >= 'A' && ch <= 'F' &&
                    (mask & (1 << (ch - 'A'))) == 0) continue;
                if (ch >= 'a' && ch <= 'f') mask |= 1 << (ch - 'a');
                if (mask == target) return cur[3] + 1;
                if (!seen[nr][nc][mask]) {
                    seen[nr][nc][mask] = true;
                    queue.offer(new int[]{nr, nc, mask, cur[3] + 1});
                }
            }
        }
        return -1;
    }
}

var shortestPathAllKeys = function(grid) {
    const m = grid.length, n = grid[0].length;
    let sr = 0, sc = 0, keyCount = 0;
    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            const ch = grid[r][c];
            if (ch === '@') [sr, sc] = [r, c];
            if (ch >= 'a' && ch <= 'f') keyCount++;
        }
    }
    const target = (1 << keyCount) - 1;
    const seen = Array.from({ length: m }, () =>
        Array.from({ length: n }, () => new Uint8Array(1 << keyCount))
    );
    const queue = [[sr, sc, 0, 0]];
    seen[sr][sc][0] = 1;
    const dirs = [[1,0],[-1,0],[0,1],[0,-1]];

    for (let head = 0; head < queue.length; head++) {
        const [r, c, oldMask, distance] = queue[head];
        for (const [dr, dc] of dirs) {
            const nr = r + dr, nc = c + dc;
            if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
            const ch = grid[nr][nc];
            if (ch === '#') continue;
            let mask = oldMask;
            if (ch >= 'A' && ch <= 'F' &&
                (mask & (1 << (ch.charCodeAt(0) - 65))) === 0) continue;
            if (ch >= 'a' && ch <= 'f')
                mask |= 1 << (ch.charCodeAt(0) - 97);
            if (mask === target) return distance + 1;
            if (!seen[nr][nc][mask]) {
                seen[nr][nc][mask] = 1;
                queue.push([nr, nc, mask, distance + 1]);
            }
        }
    }
    return -1;
};

PYTHON
from collections import deque
from typing import List

class Solution:
    def shortestPathAllKeys(self, grid: List[str]) -> int:
        m, n = len(grid), len(grid[0])
        start = (0, 0)
        key_count = 0
        for r in range(m):
            for c in range(n):
                if grid[r][c] == '@':
                    start = (r, c)
                elif 'a' <= grid[r][c] <= 'f':
                    key_count += 1

        target = (1 << key_count) - 1
        queue = deque([(start[0], start[1], 0, 0)])
        seen = {(start[0], start[1], 0)}

        while queue:
            r, c, old_mask, distance = queue.popleft()
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if not (0 <= nr < m and 0 <= nc < n):
                    continue
                ch = grid[nr][nc]
                if ch == '#':
                    continue
                mask = old_mask
                if 'A' <= ch <= 'F' and not (mask & (1 << (ord(ch) - ord('A')))):
                    continue
                if 'a' <= ch <= 'f':
                    mask |= 1 << (ord(ch) - ord('a'))
                if mask == target:
                    return distance + 1
                state = (nr, nc, mask)
                if state not in seen:
                    seen.add(state)
                    queue.append((nr, nc, mask, distance + 1))
        return -1

C++
#include <array>
#include <queue>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int shortestPathAllKeys(vector<string>& grid) {
        int m = grid.size(), n = grid[0].size();
        int sr = 0, sc = 0, keyCount = 0;
        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                char ch = grid[r][c];
                if (ch == '@') sr = r, sc = c;
                if (ch >= 'a' && ch <= 'f') ++keyCount;
            }
        }
        int target = (1 << keyCount) - 1;
        vector seen(m, vector(n, vector<bool>(1 << keyCount)));
        queue<array<int, 4>> q;
        q.push({sr, sc, 0, 0});
        seen[sr][sc][0] = true;
        int dirs[5] = {1, 0, -1, 0, 1};

        while (!q.empty()) {
            auto [r, c, oldMask, distance] = q.front(); q.pop();
            for (int i = 0; i < 4; ++i) {
                int nr = r + dirs[i], nc = c + dirs[i + 1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                char ch = grid[nr][nc];
                if (ch == '#') continue;
                int mask = oldMask;
                if (ch >= 'A' && ch <= 'F' &&
                    !(mask & (1 << (ch - 'A')))) continue;
                if (ch >= 'a' && ch <= 'f') mask |= 1 << (ch - 'a');
                if (mask == target) return distance + 1;
                if (!seen[nr][nc][mask]) {
                    seen[nr][nc][mask] = true;
                    q.push({nr, nc, mask, distance + 1});
                }
            }
        }
        return -1;
    }
};
