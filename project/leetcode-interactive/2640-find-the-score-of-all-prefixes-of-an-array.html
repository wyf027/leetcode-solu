Problem 2640 · Find the Score of All Prefixes of an Array

一个数组所有前缀的分数

从左到右观察每一个前缀：先按定义构造它的转换数组，再给出转换数组的元素总和。

非付费题 输入：整数数组 输出：long[]
先别急着看答案 看见变化

先用交互实验台逐步推进，观察“当前值、前缀最大值、转换值、累计分数”如何同步变化。

题目

定义与要求

对于数组 arr，定义它的转换数组 conver：

conver[i] = arr[i] + max(arr[0..i])，其中 max(arr[0..i]) 是下标 0 到 i 范围内的最大元素。

数组的分数等于其转换数组所有元素之和。给定一个下标从 0 开始、长度为 n 的整数数组 nums，返回长度为 n 的数组 ans，其中 ans[i] 是前缀 nums[0..i] 的分数。

示例 1

输入： nums = [2,3,7,5,10]

输出： [4,10,24,36,56]

各前缀的转换数组依次为 [4]、[4,6]、[4,6,14]、[4,6,14,12]、[4,6,14,12,20]，其元素和即为对应答案。

示例 2

输入： nums = [1,1,2,4,8,16]

输出： [2,4,8,16,32,64]

各前缀的转换数组依次为 [2]、[2,2]、[2,2,4]、[2,2,4,8]、[2,2,4,8,16]、[2,2,4,8,16,32]。

约束

  • 1 <= nums.length <= 105
  • 1 <= nums[i] <= 109

完整题解

一次扫描，维护两个量

核心洞察

走到下标 i 时，只需知道此前的最大值和此前的得分。更新 maxValue = max(maxValue, nums[i])，当前转换值就是 nums[i] + maxValue；把它加入累计分数后，所得结果正是 ans[i]。

完整过程

  1. 初始化 maxValue = 0、score = 0 和答案数组。
  2. 从左到右遍历 nums[i]，更新前缀最大值。
  3. 计算本项转换值 nums[i] + maxValue。
  4. 把转换值累加到 score，再把 score 写入答案。

正确性

循环不变式：处理完下标 i 后，maxValue 等于 nums[0..i] 的最大值；score 等于转换数组前 i + 1 项之和。

初始时尚无元素，结论成立。处理 nums[i] 时，取旧最大值与当前值的较大者，得到正确的前缀最大值；由定义算出当前转换值并累加，因此新的 score 正是前缀 nums[0..i] 的分数。遍历结束后，每个 ans[i] 都正确。

边界与数值范围

  • 只有一个元素时，结果为该元素的两倍。
  • 重复最大值不影响更新，仍按定义累加。
  • 严格递增数组中，每个转换值是当前元素的两倍。
  • 答案最大约为 2 × 1014；Java/C++ 必须使用 64 位整数。JavaScript 的安全整数范围足够本题使用。

复杂度

时间：O(n)，每个元素只处理一次。

额外空间：O(1)（不计必须返回的答案数组）。

四语言实现

class Solution {
    public long[] findPrefixScore(int[] nums) {
        long[] ans = new long[nums.length];
        long maxValue = 0;
        long score = 0;

        for (int i = 0; i < nums.length; i++) {
            maxValue = Math.max(maxValue, nums[i]);
            score += nums[i] + maxValue;
            ans[i] = score;
        }
        return ans;
    }
}

var findPrefixScore = function(nums) {

    return ans;
};

替代方案

先构造转换数组，再做前缀和：同样是 O(n) 时间，但需要额外 O(n) 空间保存转换数组，信息重复，没有必要。

逐个前缀重新计算：对每个 i 都扫描 0..i，时间为 O(n²)，在 105 规模下会超时。

常见错误

  • 先计算转换值、后更新最大值，导致漏掉当前元素。
  • 把答案写成单个转换值，而不是转换值的前缀和。
  • Java/C++ 使用 32 位整数保存累计分数，发生溢出。
  • 为每个前缀重新求最大值，退化为平方复杂度。

面试追问

  • 如果需要流式处理呢？保留 maxValue 和 score，每到一个新数即可立刻输出新的前缀分数。
  • 如果允许负数呢？最大值不能再初始化为 0，应初始化为第一个元素或负无穷；其余推导不变。
  • 能否原地写回 nums？理论上可以，但返回类型可能需要 64 位，而输入通常是 32 位，直接复用会溢出且破坏输入。

一句话记忆

每走一步：先刷新最高点，再把“当前值 + 最高点”加入累计分数。
