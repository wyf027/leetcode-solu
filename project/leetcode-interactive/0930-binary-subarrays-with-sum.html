Binary Subarrays With Sum

MEDIUM数组哈希表前缀和

题目

给定一个只包含 0 和 1 的数组 nums，以及整数 goal，返回元素和恰好等于 goal 的非空连续子数组数量。

示例 1

输入：nums = [1,0,1,0,1], goal = 2
输出：4
解释：满足要求的连续片段共有 4 个。

示例 2

输入：nums = [0,0,0,0,0], goal = 0
输出：15

约束

  • 1 <= nums.length <= 3 × 10⁴
  • nums[i] 为 0 或 1
  • 0 <= goal <= nums.length

完整题解：前缀和 + 频次表

核心洞察：当前位置前缀和为 sum 时，此前每个值为 sum - goal 的前缀，都能与当前位置组成一个和为 goal 的非空子数组。

完整过程

  1. 频次表记录扫描到当前位置之前，各前缀和出现的次数。
  2. 初始化 count[0] = 1，表示数组开始前的空前缀。
  3. 逐个读数并更新 sum。
  4. 将 count[sum - goal] 加入答案，再记录当前 sum。

正确性证明

令 P[i] 为前 i 个元素之和。区间 [j,i) 的和是 P[i]-P[j]，它等于 goal 当且仅当 P[j]=P[i]-goal。扫描到 i 时，频次表恰好保存所有 j<i 的前缀，因此本步加入的频次与以 i-1 结尾的合法非空子数组一一对应。每个子数组只有一个右端点，故既不遗漏也不重复。

边界

  • goal=0：相同前缀和之间的零和片段会被计数。
  • 全零数组：每步累计此前相同前缀的个数。
  • 无匹配时查询频次为 0。
  • 空前缀初始化保证不漏掉从下标 0 开始的片段。

复杂度

时间 O(n)，空间 O(n)。本题前缀和范围是 [0,n]，也可用长度 n+1 的数组代替哈希表。

替代方案

因元素非负，可计算 atMost(goal)-atMost(goal-1)，用两个滑动窗口得到恰好等于目标的数量，时间 O(n)、额外空间 O(1)。它需处理负阈值，且不能直接推广到含负数数组。

面试追问

  • 数组允许负数时，滑动窗口为何失效？
  • 为什么本题能用数组代替哈希表？
  • 若要输出所有区间而非数量，应保存哪些信息？

常见错误

  • 忘记 count[0]=1。
  • 先记录当前前缀再查询，导致 goal=0 时计入空片段。
  • 把连续子数组误当成可跳跃的子序列。
  • 滑动窗口方案没有处理 goal-1<0。

完整代码

class Solution {
    public int numSubarraysWithSum(int[] nums, int goal) {
        int[] count = new int[nums.length + 1];
        count[0] = 1;
        int sum = 0, answer = 0;
        for (int num : nums) {
            sum += num;
            if (sum >= goal) answer += count[sum - goal];
            count[sum]++;
        }
        return answer;
    }
}
/**
 * @param {number[]} nums
 * @param {number} goal
 * @return {number}
 */
var numSubarraysWithSum = function(nums, goal) {
    const count = new Map([[0, 1]]);
    let sum = 0, answer = 0;
    for (const num of nums) {
        sum += num;
        answer += count.get(sum - goal) ?? 0;
        count.set(sum, (count.get(sum) ?? 0) + 1);
    }
    return answer;
};
from typing import List

class Solution:
    def numSubarraysWithSum(self, nums: List[int], goal: int) -> int:
        count = {0: 1}
        prefix_sum = 0
        answer = 0
        for num in nums:
            prefix_sum += num
            answer += count.get(prefix_sum - goal, 0)
            count[prefix_sum] = count.get(prefix_sum, 0) + 1
        return answer
