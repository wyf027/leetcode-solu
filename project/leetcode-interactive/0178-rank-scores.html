    04 / SQL notes

    准备好再展开题解

    数据库题只提供官方 SQL 方言与已核实的 Pandas，不伪称算法语言可提交。

    Solution unlocked

    DENSE_RANK 正是题意

    DENSE_RANK() 让并列共享名次，并让下一档连续；RANK() 会留下空洞。

    主线与正确性

    窗口按分数降序观察所有行。每遇到一个新的不同分数，dense rank 增一；相同分数沿用当前名次。最后按 score 降序输出，完全对应三条排名规则。 

    SELECT
    score,
    DENSE_RANK() OVER (ORDER BY score DESC) AS `rank`
FROM Scores
ORDER BY score DESC;

    为什么不用 RANK / ROW_NUMBER

    • RANK() 对 1,1 之后给出 3，产生空洞。
    • ROW_NUMBER() 给并列行不同名次。
    • 相关子查询统计比当前分数更高的不同值数量也正确，但通常是 O(n²) 形态。

    Pandas · 官方支持
    import pandas as pd

def order_scores(scores: pd.DataFrame) -> pd.DataFrame:
    result = scores[["score"]].copy()
    result["rank"] = result["score"].rank(
        method="dense", ascending=False
    ).astype("Int64")
    return result.sort_values("score", ascending=False)

    复杂度与执行计划

    设记录数为 n。窗口排名通常需要按 score DESC 排序，时间为 O(n log n)，排序工作空间约为 O(n)；数据库可利用合适索引与执行计划降低实际排序成本。

    常见错误

    • 误用 RANK 导致空洞。
    • 误用 ROW_NUMBER 拆散并列。
    • 遗漏最终 ORDER BY。
    • 未引用不同方言中的 rank 别名。
