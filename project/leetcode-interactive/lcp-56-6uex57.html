信物传送

把每个格子看成图节点：顺着当前传送带走，边权为 0；临时改方向再走，边权为 1。边权只有 0/1，因此用双端队列实现线性复杂度的 0-1 BFS。

题意

网格中的 ^ v < > 分别表示传送方向。信物从 start 出发；每次可以临时改变当前格子的方向一次，信物经过后恢复。求到达 end 所需的最少施法次数。

matrix = [">>v","v^<","<><"]
start = [0,1], end = [2,0]
期望输出：1

INTERACTIVE / 0-1 BFS

队头放零代价，队尾放一代价

队列规则

方向相同 cost=0 → push_front；不同 cost=1 → push_back。只有得到更小距离时才入队。

核心洞察

这是只有 0、1 两种边权的最短路。双端队列始终让较小距离优先弹出，等价于针对 0/1 边优化的 Dijkstra。

复杂度与边界

每个格子的四条边最多松弛一次量级，时间 O(mn)，空间 O(mn)。start=end 时答案为 0；越界方向不产生边。

常见错误：使用普通 FIFO 队列会破坏距离顺序；入队时不检查更短距离会重复膨胀；代价取决于“当前格子的箭头”和准备离开的方向。 
import java.util.*;
class Solution {
  public int conveyorBelt(String[] matrix, int[] start, int[] end) {
    int m=matrix.length,n=matrix[0].length(),INF=1<<28;
    int[][] dist=new int[m][n]; for(int[] row:dist) Arrays.fill(row,INF);
    int[] dr={-1,1,0,0},dc={0,0,-1,1}; char[] arrow={'^','v','<','>'};
    Deque<int[]> q=new ArrayDeque<>(); dist[start[0]][start[1]]=0; q.offerFirst(start);
    while(!q.isEmpty()){
      int[] cur=q.pollFirst(); int r=cur[0],c=cur[1],d=dist[r][c];
      for(int k=0;k<4;k++){int nr=r+dr[k],nc=c+dc[k]; if(nr<0||nr>=m||nc<0||nc>=n)continue;
        int w=matrix[r].charAt(c)==arrow[k]?0:1; if(d+w<dist[nr][nc]){dist[nr][nc]=d+w; int[] next={nr,nc}; if(w==0)q.offerFirst(next);else q.offerLast(next);}}
    } return dist[end[0]][end[1]];
  }
}
class Deque { constructor(){this.a=new Map();this.l=0;this.r=0;} pushFront(x){this.a.set(--this.l,x)} pushBack(x){this.a.set(this.r++,x)} popFront(){const x=this.a.get(this.l);this.a.delete(this.l++);return x} get length(){return this.r-this.l} }

from collections import deque
class Solution:
    def conveyorBelt(self, matrix, start, end):
        m,n=len(matrix),len(matrix[0]); inf=10**9; dist=[[inf]*n for _ in range(m)]
        dirs=((-1,0,'^'),(1,0,'v'),(0,-1,'<'),(0,1,'>')); q=deque([tuple(start)]); dist[start[0]][start[1]]=0
        while q:
            r,c=q.popleft(); d=dist[r][c]
            for a,b,ch in dirs:
                x,y=r+a,c+b
                if 0<=x<m and 0<=y<n:
                    w=matrix[r][c]!=ch
                    if d+w<dist[x][y]:
                        dist[x][y]=d+w; (q.append if w else q.appendleft)((x,y))
        return dist[end[0]][end[1]]
