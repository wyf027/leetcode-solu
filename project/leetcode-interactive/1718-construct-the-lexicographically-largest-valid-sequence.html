给定整数 n，返回一个满足距离规则、且在所有可行答案中字典序最大的序列。题目保证有解。

01

数字 1 只出现一次

它是唯一没有配对距离要求的数字。

02

2 到 n 各出现两次

每个数字都必须完整地放入序列，不能遗漏。

03

相同数字相距自身值

若两个 i 位于下标 p、q，则 |p-q|=i。

字典序最大：比较两个等长序列时，在第一个不同的位置上，数字更大的序列更大。例如 [0,1,9,0] 大于 [0,1,5,6]。

核心洞察：从左向右，把“大”放在最前面

关键策略：每次定位最左侧空位，并按 n, n-1, ..., 1 的顺序尝试尚未使用的数字。第一个完整解就是字典序最大的解。

序列总长度为 2n-1。对于候选 x > 1，若当前空位是 i，它的另一份必须放在 i+x；只有两个位置都在范围内且为空时才能放置。数字 1 只占当前一个位置。

完整过程

  1. 找位置。从当前下标向右跳过所有已填位置，锁定最左侧空位 i。
  2. 降序枚举。从 n 到 1 检查每个尚未使用的数字。
  3. 尝试放置。x=1 时只填写 ans[i]；否则同时填写 ans[i] 与 ans[i+x]。
  4. 继续或撤销。递归填下一个空位；若后续无解，就清空本次位置并恢复数字的未使用状态。
  5. 首解即停。所有位置填满时立即返回，不再枚举其他答案。

正确性证明

引理 1：搜索只产生可行的部分序列

数字只在未使用时放置，因此 1 至多一次，其他数字至多一对。对 x>1 总是同时写入 i 与 i+x，二者距离恰为 x；并且写入前检查边界与空位，所以不会覆盖已有数字。

引理 2：搜索不会漏掉任何可行答案

在任意最左空位，任何完整可行答案都必须放入一个尚未使用、且满足配对位置条件的数字。算法会枚举全部这类候选，并在失败后完整恢复现场，因此所有可行分支都会被覆盖。

定理：算法返回字典序最大的可行序列

算法按位置从左到右决定序列，并在每个位置按数字降序探索。若某个更大的候选存在可行补全，它对应的分支一定先于所有较小候选得到完整解；若该分支无解，回溯后才尝试更小值。因此找到的第一个完整解，在第一个可能产生差异的位置都选择了可行的最大值，故它是全局字典序最大的可行序列。

复杂度与边界

时间复杂度O(n!) 上界

回溯树会被位置冲突大量剪枝；严格状态数取决于可行放置组合。

空间复杂度O(n)

答案和使用数组为 O(n)，递归深度最多 O(n)。

  • n=1：直接得到 [1]。
  • 配对越界：候选 x>1 必须满足 i+x<2n-1。
  • 跳过已填位置：它可能是早先放置的某个数字的第二个位置，不能重复决策。

class Solution {
    public int[] constructDistancedSequence(int n) {
        int[] answer = new int[2 * n - 1];
        boolean[] used = new boolean[n + 1];
        dfs(0, n, answer, used);
        return answer;
    }

    private boolean dfs(int index, int n, int[] answer, boolean[] used) {
        while (index < answer.length && answer[index] != 0) index++;
        if (index == answer.length) return true;

        for (int value = n; value >= 1; value--) {
            if (used[value]) continue;
            if (value == 1) {
                answer[index] = 1;
                used[1] = true;
                if (dfs(index + 1, n, answer, used)) return true;
                answer[index] = 0;
                used[1] = false;
            } else {
                int pairIndex = index + value;
                if (pairIndex >= answer.length || answer[pairIndex] != 0) continue;
                answer[index] = answer[pairIndex] = value;
                used[value] = true;
                if (dfs(index + 1, n, answer, used)) return true;
                answer[index] = answer[pairIndex] = 0;
                used[value] = false;
            }
        }
        return false;
    }
}

/**
 * @param {number} n

var constructDistancedSequence = function(n) {
    const answer = new Array(2 * n - 1).fill(0);
    const used = new Array(n + 1).fill(false);

    function dfs(index) {
        while (index < answer.length && answer[index] !== 0) index++;
        if (index === answer.length) return true;

        for (let value = n; value >= 1; value--) {
            if (used[value]) continue;
            if (value === 1) {
                answer[index] = 1;
                used[1] = true;
                if (dfs(index + 1)) return true;
                answer[index] = 0;
                used[1] = false;
            } else {
                const pairIndex = index + value;
                if (pairIndex >= answer.length || answer[pairIndex] !== 0) continue;
                answer[index] = value;
                answer[pairIndex] = value;
                used[value] = true;
                if (dfs(index + 1)) return true;
                answer[index] = 0;
                answer[pairIndex] = 0;
                used[value] = false;
            }
        }
        return false;
    }

    dfs(0);
    return answer;
};

from typing import List


class Solution:
    def constructDistancedSequence(self, n: int) -> List[int]:
        answer = [0] * (2 * n - 1)
        used = [False] * (n + 1)

        def dfs(index: int) -> bool:
            while index < len(answer) and answer[index] != 0:
                index += 1
            if index == len(answer):
                return True

            for value in range(n, 0, -1):
                if used[value]:
                    continue
                if value == 1:
                    answer[index] = 1
                    used[1] = True
                    if dfs(index + 1):
                        return True
                    answer[index] = 0
                    used[1] = False
                else:
                    pair_index = index + value
                    if pair_index >= len(answer) or answer[pair_index] != 0:
                        continue
                    answer[index] = answer[pair_index] = value
                    used[value] = True
                    if dfs(index + 1):
                        return True
                    answer[index] = answer[pair_index] = 0
                    used[value] = False
            return False

        dfs(0)
        return answer

替代方案

先枚举全部可行序列

逻辑直观，但需要保存或比较所有答案。没有利用“字典序”带来的提前终止机会，时间与空间都更浪费。

位掩码记录已使用数字

可用一个整数替代 boolean[]，状态更紧凑；核心搜索顺序和剪枝完全相同，代码可读性略低。

面试追问与常见错误

为什么不需要在得到答案后再做字典序比较？

因为决策位置从左到右、候选从大到小。搜索树的遍历顺序本身就是答案的字典序降序，第一个完整解已经最大。

能否加入更强的剪枝？

可以预检剩余数字是否还存在至少一个可放置的空位对，也可优先检查约束最紧的数字；但后者可能破坏直接保证字典序的决策顺序，需要谨慎组合。

常见错误有哪些？

把“距离”误写成中间元素个数；忘记数字 1 只出现一次；回溯时只清除一个配对位置；没有跳过已被配对占据的位置；或升序枚举导致得到字典序最小/非最大答案。
