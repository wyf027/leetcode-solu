01 / 题目

读懂两条资格规则

只有同时通过两项审查的记录，才把该行 tiv_2016 计入总和。

题意转述

给定 Insurance 表，统计满足以下两个条件的投保人，其 2016 年总投资额 tiv_2016 之和，并将结果四舍五入到两位小数：

  1. 该行的 tiv_2015 在表中出现至少两次。
  2. 该行的 (lat, lon) 坐标对在表中恰好出现一次。

“相同城市”要求纬度和经度同时相同；只相同一个坐标不算同城。

输入表：Insurance

列名类型含义
pidint主键，投保人编号
tiv_2015float2015 年总投资额
tiv_2016float2016 年总投资额
latfloat城市纬度，非 NULL
lonfloat城市经度，非 NULL

官方题面给出的约束

pid 唯一；每行表示一份保单；lat、lon 均不为空。官方元数据未列出行数或数值范围，因此这里不虚构额外上下界。

05 / 完整题解

把两个频次条件分别聚合

关键不是逐行寻找“另一个人”，而是先把两类群体资格算清：tiv_2015 组人数要大于 1，(lat, lon) 组人数要等于 1。符合两组资格的原表记录，才参与最终求和。

核心洞察

两个条件都是分组后的计数谓词，只是阈值方向相反：投资额找重复，坐标找唯一。

组合方式

分别得到合格的投资额集合与坐标集合，再回到原表取交集，避免条件互相干扰。

结果处理

只汇总交集行的 tiv_2016，最后用 ROUND(..., 2) 保留两位小数。

完整过程

  1. 按 tiv_2015 分组，以 HAVING COUNT(*) > 1 留下重复投资额。
  2. 按 lat, lon 联合分组，以 HAVING COUNT(*) = 1 留下唯一城市。
  3. 把两张资格表分别连接回 Insurance，只保留同时连接成功的记录。
  4. 对保留行的 tiv_2016 求和，再四舍五入到两位小数。

正确性说明

充分性：查询保留的每一行都属于人数大于 1 的 tiv_2015 分组，同时属于人数等于 1 的坐标分组，所以必定满足题目两个条件。

必要性：任意满足题意的记录，其投资额分组人数大于 1、坐标分组人数等于 1，所以一定能连接到两张资格表，不会被遗漏。

结论：被求和的记录集合恰好等于题目要求的记录集合，结果正确。

边界情况

  • 只有纬度或经度相同，不算同一坐标对。
  • 某坐标出现三次时，三行都不满足城市唯一。
  • 同一投资额的组内可以只有部分记录城市唯一。
  • 浮点字段按数据库存储值分组，不做近似相等。

复杂度

代码

可提交主答案：本题是数据库题，LeetCode 应提交 SQL。Java、JavaScript、Python、C++ 是完整的本地语义参考，不能直接作为本题数据库提交。

SELECT ROUND(SUM(i.tiv_2016), 2) AS tiv_2016
FROM Insurance AS i
JOIN (
    SELECT tiv_2015
    FROM Insurance
    GROUP BY tiv_2015
    HAVING COUNT(*) > 1
) AS repeated_value
    ON repeated_value.tiv_2015 = i.tiv_2015
JOIN (
    SELECT lat, lon
    FROM Insurance
    GROUP BY lat, lon
    HAVING COUNT(*) = 1
) AS unique_location
    ON unique_location.lat = i.lat
   AND unique_location.lon = i.lon;
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class InvestmentsIn2016 {
    public record Policy(int pid, double tiv2015, double tiv2016,
                         double lat, double lon) {}
    private record Location(double lat, double lon) {}

    public static double findInvestments(List<Policy> rows) {
        Map<Double, Integer> values = new HashMap<>();
        Map<Location, Integer> places = new HashMap<>();
        for (Policy row : rows) {
            values.merge(row.tiv2015(), 1, Integer::sum);
            places.merge(new Location(row.lat(), row.lon()), 1, Integer::sum);
        }
        double sum = 0.0;
        for (Policy row : rows) {
            Location place = new Location(row.lat(), row.lon());
            if (values.get(row.tiv2015()) > 1 && places.get(place) == 1) {
                sum += row.tiv2016();
            }
        }
        return BigDecimal.valueOf(sum)
                .setScale(2, RoundingMode.HALF_UP).doubleValue();
    }
}
/**
 * @param {{pid:number,tiv_2015:number,tiv_2016:number,
 *          lat:number,lon:number}[]} rows
 * @returns {number}
 */
function findInvestments(rows) {
  const values = new Map();
  const places = new Map();
  const placeKey = (row) => JSON.stringify([row.lat, row.lon]);

  for (const row of rows) {
    values.set(row.tiv_2015, (values.get(row.tiv_2015) || 0) + 1);
    const key = placeKey(row);
    places.set(key, (places.get(key) || 0) + 1);
  }
  let sum = 0;
  for (const row of rows) {
    if (values.get(row.tiv_2015) > 1 && places.get(placeKey(row)) === 1) {
      sum += row.tiv_2016;
    }
  }
  return Number((sum + Number.EPSILON).toFixed(2));
}
from collections import Counter
from decimal import Decimal, ROUND_HALF_UP
from typing import Iterable, TypedDict

class Policy(TypedDict):
    pid: int
    tiv_2015: float
    tiv_2016: float
    lat: float
    lon: float

def find_investments(insurance: Iterable[Policy]) -> Decimal:
    rows = list(insurance)
    values = Counter(row["tiv_2015"] for row in rows)
    places = Counter((row["lat"], row["lon"]) for row in rows)
    total = sum(
        (Decimal(str(row["tiv_2016"])) for row in rows
         if values[row["tiv_2015"]] > 1
         and places[(row["lat"], row["lon"])] == 1),
        start=Decimal("0"),
    )
    return total.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
#include <cmath>
#include <map>
#include <utility>
#include <vector>

struct Policy {
    int pid;
    double tiv2015, tiv2016, lat, lon;
};

double findInvestments(const std::vector<Policy>& rows) {
    std::map<double, int> values;
    std::map<std::pair<double, double>, int> places;
    for (const Policy& row : rows) {
        ++values[row.tiv2015];
        ++places[{row.lat, row.lon}];
    }
    double sum = 0.0;
    for (const Policy& row : rows) {
        if (values[row.tiv2015] > 1
            && places[{row.lat, row.lon}] == 1) {
            sum += row.tiv2016;
        }
    }
    return std::round(sum * 100.0) / 100.0;
}

替代方案

  • 窗口函数：用两次 COUNT(*) OVER (PARTITION BY ...) 标频次，再在外层筛选求和。
  • 相关子查询：逐行计数，直观但可能重复扫描。
  • IN 子查询：分别筛选重复金额与唯一坐标；MySQL 可用行值表达式处理坐标对。

面试追问

  • 为什么必须把 lat 与 lon 当作联合键？
  • 若允许坐标为 NULL，连接语义会怎样变化？
  • 怎样改写成窗口函数？
  • 数据量很大时，会考虑哪些索引与执行计划？

常见错误

  • 把“2015 投资额相同”误写成 COUNT(*) = 1。
  • 分别判断 lat 唯一、lon 唯一，而不是判断坐标对。
  • 用 OR 连接两个条件；题目要求同时满足。
  • 先错误聚合 tiv_2016，导致失去逐行筛选字段。
  • 忘记结果别名 tiv_2016 或两位小数。
