球不会在每个格子停下：选定方向后，它会持续滚动，直到撞墙或途中落入洞。你需要返回最短路线的方向字符串，并在距离相同时选择字典序最小者。

Problem

题意与输入约定

以下为基于官方元数据与公开题目信息的准确转述；不复刻付费题目的长篇原文。

给定一个 m × n 的迷宫 maze，其中 0 表示空地、1 表示墙。球从 ball = [row, col] 出发，每次可选择向下、向左、向右或向上滚动。球一旦开始滚动，就会沿该方向一直前进，直到下一步会撞墙或越界；只有停下后才能改变方向。

迷宫中还有一个洞 hole = [row, col]。如果球滚动途中经过洞，它会立刻落入洞中，不再继续滚动。路线用方向字符组成：d、l、r、u。

返回能使球落入洞中的路线中，总滚动格数最少的方向字符串；若有多条最短路线，返回字典序最小的一条。若无法到达洞，返回 "impossible"。

关键细节：洞可能位于一次滚动的中途。模拟滚动时必须逐格检查洞，不能只检查撞墙后的停靠点。
findShortestWay(maze: integer[][], ball: integer[], hole: integer[]) → string

约束

  • m == maze.length，n == maze[i].length，且 1 ≤ m, n ≤ 100。
  • maze[i][j] 仅为 0 或 1。
  • ball.length == 2，hole.length == 2；坐标均在迷宫范围内。
  • 起点和洞都位于空地，且二者位置不同；迷宫边界之外视为不可进入。

Solution

Dijkstra：把停靠点视作带权图状态

状态不仅需要最短距离，还要保留该距离下字典序最小的路线；优先队列也按这两个键排序。

核心洞察

停靠点是节点

球不能随时转弯，因此一次“边”是从当前停靠点沿某方向滚到下一停靠点或洞，边权是滚过的格数。

边权不是 1

一次滚动可能跨越多个格子，普通 BFS 的层数并不等于总距离，需要处理非负权最短路。

排序键是二元组

候选状态按 (distance, path) 排序；更新时距离更短，或同距但路线更小，才覆盖记录。

完整过程

  1. 为每个格子维护 dist[r][c] 与 best[r][c]，分别表示已知最短距离及该距离下最小路线。
  2. 把起点状态 (0, "", ballRow, ballCol) 放入最小堆。堆先比较距离，再比较路线字符串。
  3. 每次取出最优状态。若它与当前记录不一致，就是过期状态，跳过；若位置是洞，立即返回路线。
  4. 枚举 d、l、r、u。沿该方向逐格滚动并累计距离；一旦进入洞就停止，否则在墙或边界前停下。
  5. 按二元组规则松弛终点：距离更短，或距离相同且新路线字典序更小，就写入记录并入堆。
  6. 堆为空仍未弹出洞，返回 "impossible"。

正确性证明

  1. 图建模正确。任意合法路线都由若干次完整滚动组成，每次滚动恰对应图中的一条非负权边；反之，每条图边都能由球的一次合法滚动实现。因此原问题与该图上的到洞最短路等价。
  2. 松弛保留最优二元组。对任一格子，算法只在新状态的距离更短，或同距且路线字典序更小时更新。因此记录始终是目前发现的最小 (距离, 路线)。
  3. 弹出状态已最终确定。所有边权非负，优先队列按距离优先；不存在尚未处理的状态能经非负边产生更短距离。对相同距离，队列按完整路线排序且松弛保留更小路线，所以首次有效弹出的该距离状态也具有最小路线。
  4. 返回答案正确。洞首次以有效状态弹出时，它的距离不大于任何未处理候选；同距候选的路线也不会更小。故返回值同时满足最短距离与字典序最小。若队列耗尽，则所有可达停靠状态均已处理，洞不可达。

边界情况

  • 洞位于滚动途中：到洞立即停止，不能越过后再以墙前位置做终点。
  • 某方向一步也走不了：不生成原地自环，避免无意义状态。
  • 同一格子同一距离可能由多条路线到达：必须允许字典序更小者更新。
  • 洞几何连通但无法以滚动轨迹进入，仍应返回 impossible。
  • 过期堆元素需要跳过，否则虽不影响最终结果，却会造成大量重复扩展。

复杂度

时间复杂度

设格子数为 V = m·n，单次扩展最多向四个方向各滚动 O(max(m,n)) 格；保守为 O(mn·max(m,n)·log(mn))，另有路线字符串比较/复制开销。

空间复杂度

dist、best、堆均占 O(mn) 个状态量；路线字符串的总存储还取决于路径长度。

四语言完整代码

import java.util.*;

class Solution {
    static class State {
        int dist, row, col;
        String path;

        State(int dist, String path, int row, int col) {
            this.dist = dist;
            this.path = path;
            this.row = row;
            this.col = col;
        }
    }

    public String findShortestWay(int[][] maze, int[] ball, int[] hole) {
        int m = maze.length, n = maze[0].length;
        int[][] dist = new int[m][n];
        String[][] best = new String[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);

        PriorityQueue<State> pq = new PriorityQueue<>((a, b) -> {
            if (a.dist != b.dist) return Integer.compare(a.dist, b.dist);
            return a.path.compareTo(b.path);
        });

        int[] dr = {1, 0, 0, -1};
        int[] dc = {0, -1, 1, 0};
        char[] move = {'d', 'l', 'r', 'u'};

        dist[ball[0]][ball[1]] = 0;
        best[ball[0]][ball[1]] = "";
        pq.offer(new State(0, "", ball[0], ball[1]));

        while (!pq.isEmpty()) {
            State cur = pq.poll();
            if (cur.dist != dist[cur.row][cur.col]
                    || !cur.path.equals(best[cur.row][cur.col])) continue;
            if (cur.row == hole[0] && cur.col == hole[1]) return cur.path;

            for (int k = 0; k < 4; k++) {
                int nr = cur.row, nc = cur.col, steps = 0;
                while (true) {
                    int tr = nr + dr[k], tc = nc + dc[k];
                    if (tr < 0 || tr >= m || tc < 0 || tc >= n
                            || maze[tr][tc] == 1) break;
                    nr = tr;
                    nc = tc;
                    steps++;
                    if (nr == hole[0] && nc == hole[1]) break;
                }
                if (steps == 0) continue;

                int nd = cur.dist + steps;
                String np = cur.path + move[k];
                if (nd < dist[nr][nc]
                        || (nd == dist[nr][nc]
                        && (best[nr][nc] == null || np.compareTo(best[nr][nc]) < 0))) {
                    dist[nr][nc] = nd;
                    best[nr][nc] = np;
                    pq.offer(new State(nd, np, nr, nc));
                }
            }
        }
        return "impossible";
    }
}
var findShortestWay = function(maze, ball, hole) {
    const m = maze.length, n = maze[0].length;
    const dist = Array.from({ length: m }, () => Array(n).fill(Infinity));
    const best = Array.from({ length: m }, () => Array(n).fill(null));
    const dirs = [[1, 0, 'd'], [0, -1, 'l'], [0, 1, 'r'], [-1, 0, 'u']];

    const less = (a, b) => a.dist !== b.dist ? a.dist < b.dist : a.path < b.path;
    const heap = [];
    function push(value) {
        heap.push(value);
        let i = heap.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (!less(heap[i], heap[p])) break;
            [heap[i], heap[p]] = [heap[p], heap[i]];
            i = p;
        }
    }
    function pop() {
        const top = heap[0];
        const last = heap.pop();
        if (heap.length) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let smallest = i, left = i * 2 + 1, right = left + 1;
                if (left < heap.length && less(heap[left], heap[smallest])) smallest = left;
                if (right < heap.length && less(heap[right], heap[smallest])) smallest = right;
                if (smallest === i) break;
                [heap[i], heap[smallest]] = [heap[smallest], heap[i]];
                i = smallest;
            }
        }
        return top;
    }

    dist[ball[0]][ball[1]] = 0;
    best[ball[0]][ball[1]] = '';
    push({ dist: 0, path: '', row: ball[0], col: ball[1] });

    while (heap.length) {
        const cur = pop();
        if (cur.dist !== dist[cur.row][cur.col]
                || cur.path !== best[cur.row][cur.col]) continue;
        if (cur.row === hole[0] && cur.col === hole[1]) return cur.path;

        for (const [dr, dc, ch] of dirs) {
            let nr = cur.row, nc = cur.col, steps = 0;
            while (true) {
                const tr = nr + dr, tc = nc + dc;
                if (tr < 0 || tr >= m || tc < 0 || tc >= n || maze[tr][tc] === 1) break;
                nr = tr;
                nc = tc;
                steps++;
                if (nr === hole[0] && nc === hole[1]) break;
            }
            if (steps === 0) continue;

            const nd = cur.dist + steps, np = cur.path + ch;
            if (nd < dist[nr][nc]
                    || (nd === dist[nr][nc] && (best[nr][nc] === null || np < best[nr][nc]))) {
                dist[nr][nc] = nd;
                best[nr][nc] = np;
                push({ dist: nd, path: np, row: nr, col: nc });
            }
        }
    }
    return 'impossible';
};
from typing import List
import heapq


class Solution:
    def findShortestWay(
        self, maze: List[List[int]], ball: List[int], hole: List[int]
    ) -> str:
        m, n = len(maze), len(maze[0])
        dist = [[float("inf")] * n for _ in range(m)]
        best = [[None] * n for _ in range(m)]
        directions = [(1, 0, "d"), (0, -1, "l"),
                      (0, 1, "r"), (-1, 0, "u")]

        sr, sc = ball
        dist[sr][sc] = 0
        best[sr][sc] = ""
        heap = [(0, "", sr, sc)]

        while heap:
            cur_dist, path, row, col = heapq.heappop(heap)
            if cur_dist != dist[row][col] or path != best[row][col]:
                continue
            if [row, col] == hole:
                return path

            for dr, dc, char in directions:
                nr, nc, steps = row, col, 0
                while True:
                    tr, tc = nr + dr, nc + dc
                    if not (0 <= tr < m and 0 <= tc < n) or maze[tr][tc] == 1:
                        break
                    nr, nc = tr, tc
                    steps += 1
                    if [nr, nc] == hole:
                        break
                if steps == 0:
                    continue

                new_dist = cur_dist + steps
                new_path = path + char
                if (new_dist < dist[nr][nc] or
                    (new_dist == dist[nr][nc] and
                     (best[nr][nc] is None or new_path < best[nr][nc]))):
                    dist[nr][nc] = new_dist
                    best[nr][nc] = new_path
                    heapq.heappush(heap, (new_dist, new_path, nr, nc))

        return "impossible"

using namespace std;

class Solution {
    struct State {
        int dist, row, col;
        string path;
    };

    struct Compare {
        bool operator()(const State& a, const State& b) const {
            if (a.dist != b.dist) return a.dist > b.dist;
            return a.path > b.path;
        }
    };

public:
    string findShortestWay(vector<vector<int>>& maze,
                           vector<int>& ball,
                           vector<int>& hole) {
        int m = maze.size(), n = maze[0].size();
        const int INF = numeric_limits<int>::max();
        vector<vector<int>> dist(m, vector<int>(n, INF));
        vector<vector<string>> best(m, vector<string>(n));
        const int dr[4] = {1, 0, 0, -1};
        const int dc[4] = {0, -1, 1, 0};
        const char move[4] = {'d', 'l', 'r', 'u'};
        priority_queue<State, vector<State>, Compare> pq;

        dist[ball[0]][ball[1]] = 0;
        best[ball[0]][ball[1]] = "";
        pq.push({0, ball[0], ball[1], ""});

        while (!pq.empty()) {
            State cur = pq.top();
            pq.pop();
            if (cur.dist != dist[cur.row][cur.col]
                    || cur.path != best[cur.row][cur.col]) continue;
            if (cur.row == hole[0] && cur.col == hole[1]) return cur.path;

            for (int k = 0; k < 4; ++k) {
                int nr = cur.row, nc = cur.col, steps = 0;
                while (true) {
                    int tr = nr + dr[k], tc = nc + dc[k];
                    if (tr < 0 || tr >= m || tc < 0 || tc >= n
                            || maze[tr][tc] == 1) break;
                    nr = tr;
                    nc = tc;
                    ++steps;
                    if (nr == hole[0] && nc == hole[1]) break;
                }
                if (steps == 0) continue;

                int nd = cur.dist + steps;
                string np = cur.path + move[k];
                if (nd < dist[nr][nc]
                        || (nd == dist[nr][nc]
                        && (best[nr][nc].empty() || np < best[nr][nc]))) {
                    dist[nr][nc] = nd;
                    best[nr][nc] = np;
                    pq.push({nd, nr, nc, np});
                }
            }
        }
        return "impossible";
    }
};

替代方案

  • A*：可用到洞的曼哈顿距离作为不高估的启发式函数，但仍要谨慎处理完整路线的字典序；实现复杂度更高，百级网格通常没有必要。
  • 预计算滚动终点：若同一迷宫需要回答大量起点/洞查询，可预处理每格四向的停靠点与距离；单题只查询一次时收益有限，且洞在途中会改变终点。
  • 队列式松弛：类似 SPFA 的做法能实现，但最坏复杂度缺乏保证。普通 BFS 只适合等权边，本题不适用。

面试追问

  • 如果只要求最短距离，不要求路线，状态与更新条件可以怎样简化？
  • 为什么只把方向按 d,l,r,u 枚举，仍不足以替代队列中的路线二级排序？
  • 如何把每次逐格滚动优化成接近 O(1) 的转移？洞在途中时怎么修正？
  • 如果允许多个洞，要求最短且洞编号最小，应如何扩展排序键？

常见错误

  • 撞墙后才检查洞，导致球错误地穿过洞。
  • 只维护距离，不维护同距下的最佳路线。
  • 把一次滚动视为一步并使用普通 BFS，得到转向次数最少而非滚动距离最少。
  • 发现洞时立即返回；正确时机是洞状态以全局最优顺序从堆中弹出。
  • 构造方向字符与位移数组时顺序错位，路线与实际移动不一致。
