01 / PROBLEM

题目与约束

给你十进制数字字符串 num。在字符之间添加分隔符，把整个字符串划分为若干连续、非空的片段。每段必须表示没有前导零的正整数，且组成的数组从左到右非递减。

返回不同合法划分的数量，对 1,000,000,007 取模。允许不添加分隔符，将整个字符串作为一个数。

  • 1 ≤ num.length ≤ 3500
  • num 仅包含字符 '0' 到 '9'。
  • 相邻数字可以相等；单独的 0 不合法。

参数：num: string · 返回：integer

INSIGHT / LENGTH BEFORE VALUE

末段长度 DP + 前缀和 + LCP

对于没有前导零的正整数，位数更短一定更小。当前末段长 len 时，合法前段只有两类：长度小于 len 的所有合法前段，以及长度等于 len 且数值不大于当前段的前段。更长的前段一定过大。

状态定义

  • D[i][len]：前 i 个字符的合法划分中，最后一段恰好长 len 的方案数。
  • P[i][k]：固定 i，把末段长度从 1 到 k 的 D 累加。代码只保存 P，不再单独分配 D。
  • LCP[a][b]：起点 a、b 的两个后缀的最长公共前缀长度；字符相同则为 1 + LCP[a+1][b+1]，否则为 0。由右下向左上预处理。

完整转移过程

使用半开区间：当前末段是 num[start:i]，其中 start = i − len。

  1. 若 num[start] == '0'，这一末段无效，D 为 0。
  2. 否则若 start 为 0，整个前缀单独成数，D 为 1。
  3. 否则，所有更短前段贡献为 P[start][min(len−1,start)]。
  4. 若 start ≥ len，存在紧邻的等长候选 num[start−len:start]。令 p = start−len、c = LCP[p][start]。当 c ≥ len 时，两段相等；否则比较第一个不同字符。前段 ≤ 当前段时，额外加上 P[start][len] − P[start][len−1]。
  5. 更新本行前缀和。i 从 1 到 n，len 从 1 到 i，答案为 P[n][n]。
D[i][len] = 更短前段贡献 + 合法等长前段贡献
P[i][len] = (P[i][len−1] + D[i][len]) mod M
M = 1,000,000,007；P[i][0] = 0

实现中合并第 3、4 步：等长前段可接，直接取 P[start][len]；否则只取更短前段的前缀和。已存在状态为前导零片段记录的贡献是 0，因此不必重复过滤前段。

正确性：不漏、不重、只计合法方案

基础：起点为零下标且首字符非零的片段，独立构成唯一的一段划分；任何以字符零开头的末段都不计入。

归纳：假设所有更短前缀的状态已正确。固定当前末段后，前面的字符范围唯一确定。所有合法前段按长度分为“更短”和“等长且不大于当前段”两类，它们互斥且覆盖全部可能。前缀和精确计数第一类，LCP 精确判定第二类。每个前缀划分接上当前段得到唯一合法划分；反过来，删除任意合法划分的末段，也唯一落入其中一类。因此转移不漏不重。

终点：整个字符串的每种合法划分有唯一的末段长度，对所有末段长度求和即 P[n][n]。加法过程取模保留最终模意义下的结果。

串 327 的一条完整计数轨迹

D[1][1]=1 对应 [3]。D[2][1]=0，因为 3 > 2；D[2][2]=1 对应 [32]。最后一行：末段 7 贡献 0；末段 27 可接 [3]，贡献 1；末段 327 单独成数，贡献 1。总数为 2。

边界、复杂度与常见错误

  • 首位为零可直接返回 0；内部零不等于无解，例如 10。
  • 相等允许相接。LCP ≥ len 时应立即判定相等，不要继续读取比较字符。
  • 前缀不足 len 时没有等长前段，使用 min(len−1,start) 限制前缀和列。
  • 长数字不能转成 Number、int 或 long；只比较字符和长度。
  • 逐次切片比较会使总时间退化为 O(n³)。
  • P 是长度不超过某值的累计数，不能当作恰长 len 的 D 再次累加。
  • 直接相减求 D 时要处理负模；下面代码改为选择累计长度上限，避免该减法。

时间 O(n²)，空间 O(n²)。LCP 和计数状态都为 O(n²) 项，每项 O(1) 更新。只计算 LCP 上三角，但分配完整方阵，便于寻址。

LCP 最大为 3500，16 位足够；P 每项小于 M，两项相加最多为 2M−2，不超过 32 位有符号整数上限，也处于 JavaScript 的精确整数范围。n=3500 时，16 位 LCP 与 32 位 P 的原始数据约 73.5 MB（70.1 MiB），另有行对象等开销。

Python 使用标准库 array 避免数百万普通整数对象。实际语言性能、内存和提交结果均待补验证。P 会访问多行历史状态，不能直接压成普通两行滚动数组。

替代方案与面试追问

  • 枚举所有切点：2^(n−1) 种切法，只适合极短串的手工分析。
  • 朴素 DP：枚举每个前段长度并比较，重复工作多；前缀和解决求和，LCP 解决等长比较。
  • 字符串哈希：可二分公共前缀，但通常增加 O(log n) 比较成本和碰撞风险。此规模下确定性 LCP 更直接。

改成严格递增？

短前段仍可接；等长前段必须在第一个不同字符处更小，完全相等不可接。

只需要输出一种方案？

首位非零时，整个字符串本身就是合法的一段方案；首位为零则无解，不需要计数 DP。

要求恰好 k 段？

需要增加段数维度，再重新评估时间和空间；仅凭总计数无法恢复各段数的计数。

Java

class Solution {
    public int numberOfCombinations(String num) {
        final int MOD = 1_000_000_007;
        int n = num.length();
        if (num.charAt(0) == '0') return 0;
        char[] a = num.toCharArray();
        short[][] lcp = new short[n + 1][n + 1];
        for (int i = n - 1; i >= 0; --i)
            for (int j = n - 1; j > i; --j)
                if (a[i] == a[j])
                    lcp[i][j] = (short)(1 + lcp[i + 1][j + 1]);
        int[][] pref = new int[n + 1][n + 1];
        for (int i = 1; i <= n; ++i) {
            for (int len = 1; len <= i; ++len) {
                int start = i - len, ways = 0;
                if (a[start] != '0') {
                    if (start == 0) ways = 1;
                    else {
                        int k = Math.min(len - 1, start);
                        if (start >= len) {
                            int p = start - len, c = lcp[p][start];
                            if (c >= len || a[p + c] <= a[start + c])
                                k = len;
                        }
                        ways = pref[start][k];
                    }
                }
                pref[i][len] = (pref[i][len - 1] + ways) % MOD;
            }
        }
        return pref[n][n];
    }
}

Python 3

from array import array

class Solution:
    def numberOfCombinations(self, num: str) -> int:
        MOD = 1_000_000_007
        n = len(num)
        if num[0] == '0':
            return 0
        lcp = [array('H', [0]) * (n + 1) for _ in range(n + 1)]
        for i in range(n - 1, -1, -1):
            row, below = lcp[i], lcp[i + 1]
            for j in range(n - 1, i, -1):
                if num[i] == num[j]:
                    row[j] = 1 + below[j + 1]
        pref = [array('I', [0]) * (n + 1) for _ in range(n + 1)]
        for i in range(1, n + 1):
            row = pref[i]
            for length in range(1, i + 1):
                start = i - length
                ways = 0
                if num[start] != '0':
                    if start == 0:
                        ways = 1
                    else:
                        k = min(length - 1, start)
                        if start >= length:
                            p = start - length
                            c = lcp[p][start]
                            if c >= length or num[p + c] <= num[start + c]:
                                k = length
                        ways = pref[start][k]
                row[length] = (row[length - 1] + ways) % MOD
        return pref[n][n]
