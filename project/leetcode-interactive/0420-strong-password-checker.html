01 / Problem

任务说明

目标：最少修改步数

给定字符串 password。若它同时满足下列条件，就称为强密码；请返回把它变成强密码所需的最少操作数。已经满足时返回 0。

  1. 长度在 6 到 20 之间（含边界）。
  2. 至少包含一个小写字母、一个大写字母和一个数字。
  3. 不存在三个相同字符连续出现；例如 Baaabb0 不合格，而 Baaba0 不触发此规则。
每一步可选择一种
  • 插入一个字符
  • 删除一个字符
  • 把某个字符替换成另一个字符

一次操作可能同时修复多个条件，因此不能把三个缺陷的代价简单相加。

官方示例

示例 1
输入：password = "a"
输出：5
示例 2
输入：password = "aA1"
输出：3
示例 3
输入：password = "1337C0d3"
输出：0

约束

  • 1 <= password.length <= 50
  • password 只由英文字母、数字、点号 '.' 或感叹号 '!' 组成。

04 / Solution

按长度分区，再让删除优先“购买”替换次数

困难点不在识别违规，而在于同一次插入、删除或替换能否同时修复长度、类别和重复。关键是先计算缺失类别数与重复段替换数，再按长度分三种互不混淆的情形。

短于 6

必须插入至少 6-n 个字符；这些插入也能补类别或打断重复，所以答案取最大值。

6 到 20

长度已合法，只需在“缺失类别”和“打断重复”的需求中取较大者。

长于 20

删除不可避免。选择正确的重复段删除，能以最低代价同步降低后续替换数。

核心量

  • missing：小写、大写、数字三类中缺少的数量，范围为 0..3。
  • 对每个长度为 L >= 3 的相同字符连续段，单靠替换打断它需要 floor(L / 3) 次。所有段求和记为 replace。
  • 若 n > 20，必须删除 delete = n - 20 个字符。

完整过程

情形一：n < 6

至少要做 6-n 次插入；至少也要修复 missing 个类别。插入字符的位置可以穿插在重复段中，因此长度不足时重复不会产生额外、独立的下界。答案为 max(6-n, missing)。

情形二：6 <= n <= 20

长度无需改变。一次替换既能补一个缺失类别，也能打断一个重复三元组，所以答案是 max(missing, replace)。

情形三：n > 20

先付出固定的 n-20 次删除。删除顺序决定剩余重复段需要多少次替换。对长度为 L 的重复段：

  1. 若 L % 3 == 0，删除 1 个字符就能让 floor(L/3) 减一；最划算，先处理。
  2. 若 L % 3 == 1，删除 2 个字符能让替换数减一；其次处理。
  3. 剩余情况每删除 3 个字符，替换数减一。

用完删除预算后，仍需在缺失类别和剩余重复替换之间取较大值。最终答案是 (n-20) + max(missing, replaceAfterDelete)。

为什么正确

引理 1：长度为 L 的连续相同字符段至少需要 floor(L/3) 次替换才能消除所有连续三字符；每隔三个字符替换一个即可达到这个下界。

引理 2：当必须删除时，按余数 0 → 1 → 2 的顺序分配删除最优。三类让替换数减少一次所需的首次删除成本分别是 1、2、3，交换任何逆序分配都不会得到更多的替换下降。

分情况结论：短密码的插入可同时承担补长度、补类别、断重复；合法长度密码的替换可同时补类别与断重复；超长密码先完成不可避免且最优分配的删除，再用替换同时覆盖剩余类别与重复需求。因此三个公式都达到各自下界，算法返回全局最小操作数。

边界检查

  • 长度恰为 6 或 20：进入中间区间，不产生强制插入或删除。
  • 单个超长重复段：删除预算可能跨越多个“每三次降一次替换”的周期，第三阶段要保留整数除法。
  • 所有字符互不连续重复但缺类别：replace = 0，答案完全由长度与 missing 决定。
  • 点号和感叹号不属于三种必需类别，但仍参与连续重复段统计。

复杂度

一次线性扫描识别字符类别与连续段，时间复杂度为 O(n)。实现只保存常数个计数器，额外空间复杂度为 O(1)。

替代方案

方案思路代价与取舍
优先队列模拟删除把重复段放入堆，每次选择最能降低替换需求的段。直观但通常为 O(n log n)，还需谨慎更新段长。
状态搜索 / 动态规划把长度、类别与尾部重复状态作为维度。状态空间大，难以表达任意位置编辑，不适合本题上限与面试实现。
余数分组贪心仅统计重复段长度模 3 的类别，批量分配删除。O(n)、常数空间，是最简洁的可提交方案。

面试追问

  • 为什么中间区间取最大值而不是相加？ 因为一次恰当替换可以同时补齐一个字符类别并打断一组连续重复。
  • 为什么先删 L % 3 == 0？ 它只需一次删除就能省下一次替换，单位收益最高。
  • 若必需类别扩展到符号怎么办？ 扩展 missing 的类别检测；重复段与删除贪心不变。
  • 若操作成本不同怎么办？ 当前按单位成本设计；不同权重会破坏简单余数贪心，需建立带权状态转移或最短路模型。

常见错误

  • 把缺失类别数、长度差和重复替换数直接相加，忽略一次操作可同时修复多个条件。
  • 超长时随意删除，错过用删除降低重复替换数的机会。
  • 只对每个重复段做一次余数优化，忘记剩余删除每三次仍可继续降低一次替换。
  • 误把非字母数字字符当作某个必需类别，或不把它们计入重复段。

四语言完整实现

Java · LeetCode 可提交O(n) / O(1)
class Solution {
    public int strongPasswordChecker(String password) {
        int n = password.length();
        int missing = 3;
        if (password.chars().anyMatch(Character::isLowerCase)) missing--;
        if (password.chars().anyMatch(Character::isUpperCase)) missing--;
        if (password.chars().anyMatch(Character::isDigit)) missing--;

        int replace = 0;
        int mod0 = 0;
        int mod1 = 0;

        for (int i = 0; i < n; ) {
            int j = i;
            while (j < n && password.charAt(j) == password.charAt(i)) j++;
            int length = j - i;
            if (length >= 3) {
                replace += length / 3;
                if (length % 3 == 0) mod0++;
                else if (length % 3 == 1) mod1++;
            }
            i = j;
        }

        if (n < 6) return Math.max(missing, 6 - n);
        if (n <= 20) return Math.max(missing, replace);

        int deletions = n - 20;
        int remaining = deletions;

        int use = Math.min(remaining, mod0);
        replace -= use;
        remaining -= use;

        use = Math.min(remaining, mod1 * 2);
        replace -= use / 2;
        remaining -= use;

        replace = Math.max(0, replace - remaining / 3);
        return deletions + Math.max(missing, replace);
    }
}

/**
 * @param {string} password
 * @return {number}
 */
var strongPasswordChecker = function(password) {
    const n = password.length;
    let missing = 3;
    if (/[a-z]/.test(password)) missing--;
    if (/[A-Z]/.test(password)) missing--;
    if (/\d/.test(password)) missing--;

    let replace = 0;
    let mod0 = 0;
    let mod1 = 0;

    for (let i = 0; i < n; ) {
        let j = i;
        while (j < n && password[j] === password[i]) j++;
        const length = j - i;
        if (length >= 3) {
            replace += Math.floor(length / 3);
            if (length % 3 === 0) mod0++;
            else if (length % 3 === 1) mod1++;
        }
        i = j;
    }

    if (n < 6) return Math.max(missing, 6 - n);
    if (n <= 20) return Math.max(missing, replace);

    const deletions = n - 20;
    let remaining = deletions;

    let use = Math.min(remaining, mod0);
    replace -= use;
    remaining -= use;

    use = Math.min(remaining, mod1 * 2);
    replace -= Math.floor(use / 2);
    remaining -= use;

    replace = Math.max(0, replace - Math.floor(remaining / 3));
    return deletions + Math.max(missing, replace);
};

C++ · LeetCode 可提交O(n) / O(1)
class Solution {
public:
    int strongPasswordChecker(string password) {
        int n = password.size();
        bool hasLower = false, hasUpper = false, hasDigit = false;
        for (char c : password) {
            hasLower = hasLower || islower(static_cast<unsigned char>(c));
            hasUpper = hasUpper || isupper(static_cast<unsigned char>(c));
            hasDigit = hasDigit || isdigit(static_cast<unsigned char>(c));
        }
        int missing = !hasLower + !hasUpper + !hasDigit;
        int replace = 0, mod0 = 0, mod1 = 0;

        for (int i = 0; i < n; ) {
            int j = i;
            while (j < n && password[j] == password[i]) ++j;
            int length = j - i;
            if (length >= 3) {
                replace += length / 3;
                if (length % 3 == 0) ++mod0;
                else if (length % 3 == 1) ++mod1;
            }
            i = j;
        }

        if (n < 6) return max(missing, 6 - n);
        if (n <= 20) return max(missing, replace);

        int deletions = n - 20;
        int remaining = deletions;

        int use = min(remaining, mod0);
        replace -= use;
        remaining -= use;

        use = min(remaining, mod1 * 2);
        replace -= use / 2;
        remaining -= use;

        replace = max(0, replace - remaining / 3);
        return deletions + max(missing, replace);
    }
};
