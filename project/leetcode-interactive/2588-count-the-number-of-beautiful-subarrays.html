统计美丽子数组数目

Count the Number of Beautiful Subarrays

一次操作可以从两个数的同一有效二进制位各减去对应的二次幂。你能判断哪些连续片段最终可以全部归零吗？

Problem

题目描述

以下为官方题意的准确转述。

给定下标从 0 开始的整数数组 nums。每次操作：

  1. 选择两个不同下标 i 和 j。
  2. 选择非负整数 k，使两个数二进制表示的第 k 位都为 1。
  3. 分别从这两个数中减去 2ᵏ。

若某个连续非空子数组经过任意次操作（可以是 0 次）后能全部变为 0，则称其为美丽子数组。返回 nums 中美丽子数组的数目。

注意：初始时已经全为 0 的子数组也是美丽子数组。

函数签名

beautifulSubarrays(nums: integer[]) → long

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁶
位运算数组哈希表前缀和

Examples

输入：nums = [4,3,1,2,4]
输出：2

Solution

题解：相同前缀异或计数

把“每一位能否成对消去”转化为可以在线维护的前缀状态。

核心洞察

每次操作恰好消去同一二进制位上的两个 1。因此，一个子数组能全部归零，当且仅当它在每个二进制位上的 1 的数量都是偶数；这恰好等价于该子数组所有元素的异或值为 0。

设前缀异或 px[i] = nums[0] ⊕ … ⊕ nums[i]。区间 [l,r] 的异或为 0，当且仅当 px[r] = px[l-1]。扫描时只需统计当前前缀值此前出现过多少次。

完整过程

  1. 初始化频次表 count[0] = 1，代表数组开始前的空前缀。
  2. 从左到右令 prefix ^= nums[i]。
  3. 将 count[prefix] 加入答案：每个相同旧前缀都确定一个异或为 0 的区间。
  4. 把当前前缀的频次加一，继续扫描。

正确性证明

引理 1：子数组美丽，当且仅当其元素异或为 0。对任一二进制位，操作每次删除两个 1，所以该位可清零当且仅当 1 的个数为偶数；所有位均为偶数正是整体异或为 0。若为偶数，可在该位上任意两两配对执行操作，因此条件也充分。

引理 2：nums[l..r] 的异或为 0，当且仅当区间两端对应的前缀异或相等，因为 px[r] ⊕ px[l-1] = 0 ⇔ px[r] = px[l-1]。

结论：扫描到右端点 r 时，频次表包含所有旧前缀；加入同值前缀数，恰好且不重复地统计所有以 r 结尾的美丽子数组。遍历完成后答案正确。

复杂度与边界

  • 时间：O(n)，每个元素只处理一次。
  • 空间：O(n)，最坏有 n+1 个不同前缀值。
  • 空前缀：必须预置 0 的频次为 1，才能统计从下标 0 开始的区间。
  • 全零：每个前缀均为 0，答案为 n(n+1)/2。
  • 答案类型：n=10⁵ 时答案可达 5,000,050,000，Java/C++ 必须使用 64 位整数。

替代方案

枚举左端点并增量异或：对每个 l 扩展 r，异或为 0 时计数。空间 O(1)，但时间 O(n²)，无法通过 10⁵ 的数据规模。

按位统计奇偶：维护每一位的奇偶向量也正确，但这个向量就是前缀异或的二进制表示；直接用整数作哈希键更短、更快。

Implementations

四种语言完整代码

Java

long
import java.util.HashMap;
import java.util.Map;

class Solution {
    public long beautifulSubarrays(int[] nums) {
        Map<Integer, Long> count = new HashMap<>();
        count.put(0, 1L);
        int prefix = 0;
        long answer = 0;
        for (int num : nums) {
            prefix ^= num;
            long seen = count.getOrDefault(prefix, 0L);
            answer += seen;
            count.put(prefix, seen + 1);
        }
        return answer;
    }
}

from collections import Counter
from typing import List


class Solution:
    def beautifulSubarrays(self, nums: List[int]) -> int:
        count = Counter({0: 1})
        prefix = 0
        answer = 0
        for num in nums:
            prefix ^= num
            answer += count[prefix]
            count[prefix] += 1
        return answer

C++

long long
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    long long beautifulSubarrays(vector<int>& nums) {
        unordered_map<int, long long> count{{0, 1}};
        int prefix = 0;
        long long answer = 0;
        for (int num : nums) {
            prefix ^= num;
            answer += count[prefix];
            ++count[prefix];
        }
        return answer;
    }
};

面试追问

  • 为什么异或表达每一位的奇偶？ 异或在每一位上等价于模 2 加法。
  • 若要输出所有区间？ 把频次改为前缀值到下标列表的映射；输出量最坏为 O(n²)。
  • 很多固定区间查询？ 预处理前缀异或，每次 O(1) 判断。
  • 不用哈希表？ 前缀异或小于 2²⁰，可用长度 2²⁰ 的数组换取稳定常数。

常见错误

  • 误把总和为偶数当成条件；需要每个二进制位都为偶数。
  • 忘记初始化 count[0] = 1。
  • 先增加频次再计数，错误计入空区间。
  • Java/C++ 使用 32 位答案导致溢出。
  • 把子序列当成连续子数组。
