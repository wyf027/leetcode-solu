题目

准确转述官方定义

有 n 个互不重复的 (idKey, value) 对，以任意顺序到达；idKey 是 1 到 n 的整数，value 是字符串。设计一个流，使多次插入返回的所有片段依次拼接后，恰好按 ID 递增排列。

OrderedStream(int n)
创建可接收 n 个值的流，当前指针 ptr 从 1 开始。
String[] insert(int idKey, String value)
保存新值；若 ptr 已到达，返回从它开始的最长连续值片段并推进指针，否则返回空列表。

官方示例

保留完整参数形式

输入 / 输出
输入
["OrderedStream", "insert", "insert", "insert", "insert", "insert"]
[[5], [3, "ccccc"], [1, "aaaaa"], [2, "bbbbb"], [5, "eeeee"], [4, "ddddd"]]

输出
[null, [], ["aaaaa"], ["bbbbb", "ccccc"], [], ["ddddd", "eeeee"]]
发生了什么

先到达的 ID 3 暂时不能输出。ID 1 到达时输出 ["aaaaa"]；随后 ID 2 到达，连同已缓存的 ID 3 一起输出。ID 5 同样等待 ID 4，最后两项一起交付。

所有返回片段拼接为：aaaaa → bbbbb → ccccc → ddddd → eeeee。

约束

决定可选数据结构的边界

  • 1 ≤ n ≤ 1000
  • 1 ≤ idKey ≤ n
  • value.length == 5，且仅含小写英文字母
  • 每次 insert 的 ID 唯一
  • 恰好调用 n 次 insert

题解：数组缓存 + 单向指针

每个元素最多被扫描一次

核心洞察只有 ptr 决定下一段能否开始；比它大的 ID 到达后只需缓存。
状态长度 n + 1 的数组按 ID 存值，ptr 指向尚未交付的最小 ID。
动作写入后从 ptr 连续向右收集非空槽位，遇到第一个空位即停。

完整过程

  1. 初始化空数组，令 ptr = 1。
  2. 收到 (idKey, value)，写入 values[idKey]。
  3. 当 values[ptr] 已存在时，将其加入答案并令 ptr++。
  4. 返回这一轮收集的片段；若循环未进入，就返回空列表。

正确性

不变式：每次操作开始前，所有 ID 小于 ptr 的值均已按序且仅一次输出，而 ptr 是尚未输出的最小 ID。

写入不改变已输出前缀。循环只从 ptr 开始，逐个输出连续存在的槽位，因此不会跳过缺口，也不会打乱顺序；停止时，要么全部处理完，要么新的 ptr 尚未到达。故不变式继续成立。恰好插入全部 n 个值后，所有值都按 ID 递增输出。

复杂度
单次插入最坏 O(n)；但指针全程只前进 n 次，所以全部调用总时间 O(n)、均摊每次 O(1)。空间 O(n)。
边界
n = 1 时首次插入立即输出；若插入 ID 大于 ptr，返回空；若一次补上缺口，可连续释放多个缓存值。

四语言完整代码

JavaList<String>
class OrderedStream {
    private final String[] values;
    private int ptr;

    public OrderedStream(int n) {
        values = new String[n + 1];
        ptr = 1;
    }

    public List<String> insert(int idKey, String value) {
        values[idKey] = value;
        List<String> chunk = new ArrayList<>();

        while (ptr < values.length && values[ptr] != null) {
            chunk.add(values[ptr]);
            ptr++;
        }
        return chunk;
    }
}

var OrderedStream = function(n) {
    this.values = new Array(n + 1);
    this.ptr = 1;
};

/**
 * @param {number} idKey
 * @param {string} value
 * @return {string[]}
 */
OrderedStream.prototype.insert = function(idKey, value) {
    this.values[idKey] = value;
    const chunk = [];

    while (this.ptr < this.values.length &&
           this.values[this.ptr] !== undefined) {
        chunk.push(this.values[this.ptr]);
        this.ptr++;
    }
    return chunk;
};

from typing import List


class OrderedStream:
    def __init__(self, n: int):
        self.values = [None] * (n + 1)
        self.ptr = 1

    def insert(self, idKey: int, value: str) -> List[str]:
        self.values[idKey] = value
        chunk = []

        while (self.ptr < len(self.values)
               and self.values[self.ptr] is not None):
            chunk.append(self.values[self.ptr])
            self.ptr += 1

        return chunk
C++vector<string>
class OrderedStream {
private:
    vector<string> values;
    int ptr;

public:
    OrderedStream(int n) : values(n + 1), ptr(1) {}

    vector<string> insert(int idKey, string value) {
        values[idKey] = std::move(value);
        vector<string> chunk;

        while (ptr < values.size() && !values[ptr].empty()) {
            chunk.push_back(values[ptr]);
            ++ptr;
        }
        return chunk;
    }
};

替代方案

哈希表也能缓存值并检查当前指针，时间与空间量级相同；但本题 ID 紧密落在 1…n，数组索引更直接、常数更小。平衡树能够排序，却做了本题不需要的 O(log n) 维护。

常见错误

  • 每次只输出 ptr 一个值，忘记连带释放后续连续缓存。
  • 按“到达顺序”返回，而不是从 ptr 开始。
  • 数组只开 n 个槽位，却直接使用 1-based ID。
  • 把单次最坏复杂度误写成全部调用的总复杂度。

面试追问

如果 ID 范围极大且稀疏？改用哈希表保存已到达值，仍以单向指针控制交付。
如果允许重复 ID？先定义覆盖、拒绝或幂等语义，再在写入前检测。
如果并发插入？数组写入与指针扫描必须放入同一临界区，或采用能证明顺序一致性的并发协议。
