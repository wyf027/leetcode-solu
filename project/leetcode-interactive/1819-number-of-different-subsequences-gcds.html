序列中不同最大公约数的数目

Number of Different Subsequences GCDs

HARD 55 / 300 · 非付费题 · 单文件离线阅读

题目

给定正整数数组 nums。从中删除任意数量的元素，并保持剩余元素的相对顺序，可得到一个子序列。请统计所有非空子序列的最大公约数一共存在多少种不同的值，返回这个数量。

最大公约数（GCD）是能整除序列中每个数的最大正整数。例如 [4,6,16] 的 GCD 为 2。只含一个数的序列，其 GCD 就是这个数。

函数：countDifferentSubsequenceGCDs(nums) → integer

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 2 × 10⁵

题意、示例和签名来自本轮提供的官方元数据。官方题目

示例 1

输入：nums = [6,10,3]
输出：5

不同 GCD 为 {1,2,3,6,10}。例如 [6,10] 的 GCD 是 2，[10,3] 的 GCD 是 1。

示例 2

输入：nums = [5,15,40,5,6]
输出：7

重复元素可以出现在子序列中，但相同的 GCD 只计数一次。

题解 · 反过来枚举答案

核心洞察

令 M = max(nums)。答案中的 GCD 一定在 [1,M]。对于候选 d，只考虑数组中能被 d 整除的数，记这些数的集合为 S_d。d 能出现，当且仅当 S_d 非空且 gcd(S_d) = d。

因此不需要枚举子序列。建立值是否存在的布尔表，然后对每个 d 扫描 d,2d,3d,…，把存在的倍数累计求 GCD。一旦累计值等于 d，即可计数并提前结束。

演示限制用于控制步数；四语言提交代码遵循完整官方约束。

完整过程

  1. 求最大值 M，以布尔表记录每个数是否出现，重复值不重复处理。
  2. 枚举候选 d 从 1 到 M，将累计值 g 置为 0。
  3. 按步长 d 扫描倍数 v；只有存在的 v 才执行 g = gcd(g,v)。约定 gcd(0,v)=v。
  4. 若 g 等于 d，答案加一并退出本轮；若扫描完仍不等于 d，则不计数。没有倍数时 g 为 0，也不计数。

例如 [6,10,3]：d=1 时先得到 g=3，再访问 6 仍为 3，访问 10 后变为 1；d=2 时由 6 与 10 得到 2；d=3、6、10 分别由单个出现值直接成立。其余候选不成立。

正确性证明

充分性：若 S_d 的 GCD 为 d，选择数组中所有 d 的倍数并按原顺序排列，就得到一个非空子序列，其 GCD 正好为 d。

必要性：若某子序列 T 的 GCD 为 d，则 T 的每个数都是 d 的倍数，所以 T 包含于 S_d（按出现位置理解）。S_d 的 GCD 整除 T 的 GCD，即整除 d；同时 S_d 的每个数都被 d 整除，所以它的 GCD 是 d 的倍数。两者合起来只能等于 d。

提前退出：累计值达到 d 后，后续数都是 d 的倍数，GCD 始终保持 d。每个候选恰好判断一次，因此统计不重不漏。值去重不影响 GCD，按值排序扫描也不影响计算结果；需要见证子序列时恢复原顺序即可。

边界与复杂度

单元素只贡献自身；全相同数组同理。包含 1 时可立即证明 1 可达，但不能直接确定其他候选。无倍数的候选必须被排除，不能将 g=0 当作答案。

设 n 为数组长度，M 为最大值。倍数访问次数为 Σ⌊M/d⌋ = O(M log M)。将欧几里得算法每次的 O(log M) 成本计入，保守时间上界为 O(n + M log² M)；若将一次 GCD 视为常数，则通常描述为 O(n + M log M)。额外空间为 O(M)。提前退出减少实际工作，但不依赖它保证正确性。

Java

class Solution {
    private int gcd(int a, int b) {
        while (b != 0) {
            int t = a % b;
            a = b;
            b = t;
        }
        return a;
    }
    public int countDifferentSubsequenceGCDs(int[] nums) {
        int max = 0;
        for (int x : nums) max = Math.max(max, x);
        boolean[] present = new boolean[max + 1];
        for (int x : nums) present[x] = true;
        int answer = 0;
        for (int d = 1; d <= max; d++) {
            int g = 0;
            for (int v = d; v <= max; v += d) {
                if (!present[v]) continue;
                g = gcd(g, v);
                if (g == d) {
                    answer++;
                    break;
                }
            }
        }
        return answer;
    }
}

from typing import List
from math import gcd

class Solution:
    def countDifferentSubsequenceGCDs(self, nums: List[int]) -> int:
        maximum = max(nums)
        present = bytearray(maximum + 1)
        for x in nums:
            present[x] = 1
        answer = 0
        for d in range(1, maximum + 1):
            g = 0
            for v in range(d, maximum + 1, d):
                if not present[v]:
                    continue
                g = gcd(g, v)
                if g == d:
                    answer += 1
                    break
        return answer

替代方案

可以维护已出现的 GCD 集合：每读一个 x，把 x 和所有旧 GCD 与 x 求得的 GCD 加入集合。该状态确实覆盖全部子序列，但集合规模最坏可达到 M，时间保守上界为 O(nM log M)，通常不如按值域筛选稳定。枚举所有非空子序列则需要指数级工作，只适合极小输入。

常见错误

  • 把“子序列”当成连续子数组，遗漏不相邻的选择。
  • 只枚举原数组中的数作为答案，遗漏 1、2 等新 GCD。
  • 认为 d 能整除一个元素就足够：[6,12] 中 3 是约数，却不是任何子序列的 GCD。
  • 上界写成 n 或 10⁵；必须用最大元素 M，官方值域可到 2×10⁵。
  • JavaScript 使用 Math.max(...nums) 可能触发大量参数限制，应循环求最大值。

面试追问

如何给出 GCD=d 的见证？保留使累计 GCD 到达 d 的那些元素，再按原数组索引输出。

值域变到 10⁹ 怎么办？布尔表和全值域扫描不再适合。可对不同输入值枚举约数，为每个约数累计其倍数的 GCD，最后统计累计值等于键的项；代价转移到约数枚举和映射存储。

需要数有多少个子序列的 GCD 恰为 d？当前存在性算法不能直接回答，需要统计倍数元素数量，再通过容斥或约数上的反向扣除计算，并处理模数。
