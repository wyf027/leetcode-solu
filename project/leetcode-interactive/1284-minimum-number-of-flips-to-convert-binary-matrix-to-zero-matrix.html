LeetCode · Problem 1284

转化为全零矩阵的
最少反转次数

一次落子，会同时改变自己与上下左右的邻格。目标很简单：用最少的落子次数熄灭整张矩阵。

HARD位运算广度优先搜索矩阵非付费题
Problem

题目描述

函数：minFlips(mat)

给定一个 m × n 的二进制矩阵 mat。每一步可以选择一个单元格，反转它本身；若它的上、下、左、右邻格存在，也一并反转。反转即让 0 变成 1，让 1 变成 0。

返回把 mat 变成全零矩阵所需的最少步数；若无法做到，返回 -1。二进制矩阵只包含 0 和 1，全零矩阵的每个格子均为 0。

参数形式：输入参数为 int[][] mat（或对应语言的二维整数数组），返回一个整数。
示例 1
输入：mat = [[0,0],[0,1]] 输出：3 解释：可依次反转 (1,0)、(0,1)、(1,1)。
示例 2
输入：mat = [[0]] 输出：0 解释：矩阵已经是全零矩阵。
示例 3
输入：mat = [[1,0,0],[1,0,0]] 输出：-1 解释：无法将该矩阵转为全零矩阵。

约束

  • m == mat.length
  • n == mat[0].length
  • 1 <= m <= 3
  • 1 <= n <= 3
  • mat[i][j] 只能是 0 或 1

Solution

把矩阵看成一张很小的状态图

BFS + 位掩码

核心洞察

矩阵最多只有 3 × 3 = 9 个格子，因此所有可能矩阵状态至多 2^9 = 512 个。把每个格子压缩成一个二进制位，就能用一个整数唯一表示整张矩阵。

在某个格子执行一次反转，相当于让状态与一个固定的“十字形掩码”做异或。于是题目转化为：在至多 512 个节点的无权图中，从初始状态走到状态 0 的最短距离。

nextState = currentState XOR flipMask[row][col]

为什么每格只需考虑一次？

同一位置反转两次会让涉及的每一位变化两次，最终等于没有操作。反转顺序也不影响最终异或结果。

但要找最少次数，直接在状态图上做 BFS 更自然：第一次到达全零状态时，走过的边数就是最少操作数。

完整过程

  1. 编码起点。将 mat[i][j] 放到编号 i * n + j 的二进制位，得到整数 start。全零矩阵对应整数 0。
  2. 预计算操作。对每个格子，把它自己和合法的四邻格对应位设为 1，得到该位置的 flipMask。
  3. 分层搜索。从 start 入队。每次取出一个状态，尝试全部 m × n 个掩码，使用异或生成相邻状态。
  4. 只访问一次。未见过的新状态记录距离并入队；遇到状态 0 立即返回其距离。队列耗尽仍未到达 0，则返回 -1。

正确性证明

引理 1：位掩码转移与题目中的一次反转完全等价。掩码恰好在所选格子及其合法四邻格上为 1；异或使这些位翻转，其余位保持不变。

引理 2：BFS 记录的距离等于从初始矩阵到相应状态的最少反转次数。每条图边代表且只代表一次合法反转，所有边权均为 1；BFS 按距离从小到大首次访问每个状态。

定理：若算法返回 d，由引理 2，d 是到状态 0 的最短距离，也就是最少反转次数。若队列耗尽仍未访问状态 0，则所有从起点可达的状态均已搜索，因而不存在合法方案，返回 -1 正确。

复杂度

令 k = m × n，状态总数为 2^k。每个状态尝试 k 次反转：

  • 时间复杂度：O(2^k × k)
  • 空间复杂度：O(2^k + k)

由于 k ≤ 9，最多处理 512 个状态。

边界情况

  • 初始矩阵已经全为 0：直接返回 0。
  • 单格矩阵 [[1]]：一次反转即可归零。
  • 某些状态与全零状态不连通：BFS 最终穷尽可达状态，返回 -1。
  • 边角格的邻居少于四个：构建掩码时必须先检查行列边界。
  • 行列均达到 3：仍只有 9 位，不会造成常见整数类型溢出。

import java.util.*;

class Solution {
    public int minFlips(int[][] mat) {
        int m = mat.length;
        int n = mat[0].length;
        int cells = m * n;
        int start = 0;

        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (mat[r][c] == 1) {
                    start |= 1 << (r * n + c);
                }
            }
        }
        if (start == 0) return 0;

        int[] masks = new int[cells];
        int[][] directions = {{0, 0}, {1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                int mask = 0;
                for (int[] d : directions) {
                    int nr = r + d[0];
                    int nc = c + d[1];
                    if (nr >= 0 && nr < m && nc >= 0 && nc < n) {
                        mask |= 1 << (nr * n + nc);
                    }
                }
                masks[r * n + c] = mask;
            }
        }

        int[] distance = new int[1 << cells];
        Arrays.fill(distance, -1);
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(start);
        distance[start] = 0;

        while (!queue.isEmpty()) {
            int state = queue.poll();
            for (int mask : masks) {
                int next = state ^ mask;
                if (distance[next] != -1) continue;
                distance[next] = distance[state] + 1;
                if (next == 0) return distance[next];
                queue.offer(next);
            }
        }
        return -1;
    }
}

var minFlips = function(mat) {
    const m = mat.length;
    const n = mat[0].length;
    const cells = m * n;
    let start = 0;

    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            if (mat[r][c] === 1) {
                start |= 1 << (r * n + c);
            }
        }
    }
    if (start === 0) return 0;

    const directions = [[0, 0], [1, 0], [-1, 0], [0, 1], [0, -1]];
    const masks = new Array(cells).fill(0);
    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            let mask = 0;
            for (const [dr, dc] of directions) {
                const nr = r + dr;
                const nc = c + dc;
                if (nr >= 0 && nr < m && nc >= 0 && nc < n) {
                    mask |= 1 << (nr * n + nc);
                }
            }
            masks[r * n + c] = mask;
        }
    }

    const distance = new Int16Array(1 << cells);
    distance.fill(-1);
    const queue = [start];
    let head = 0;
    distance[start] = 0;

    while (head < queue.length) {
        const state = queue[head++];
        for (const mask of masks) {
            const next = state ^ mask;
            if (distance[next] !== -1) continue;
            distance[next] = distance[state] + 1;
            if (next === 0) return distance[next];
            queue.push(next);
        }
    }
    return -1;
};
from collections import deque
from typing import List


class Solution:
    def minFlips(self, mat: List[List[int]]) -> int:
        m, n = len(mat), len(mat[0])
        cells = m * n
        start = 0

        for r in range(m):
            for c in range(n):
                if mat[r][c] == 1:
                    start |= 1 << (r * n + c)
        if start == 0:
            return 0

        directions = ((0, 0), (1, 0), (-1, 0), (0, 1), (0, -1))
        masks = [0] * cells
        for r in range(m):
            for c in range(n):
                mask = 0
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < m and 0 <= nc < n:
                        mask |= 1 << (nr * n + nc)
                masks[r * n + c] = mask

        distance = [-1] * (1 << cells)
        distance[start] = 0
        queue = deque([start])

        while queue:
            state = queue.popleft()
            for mask in masks:
                next_state = state ^ mask
                if distance[next_state] != -1:
                    continue
                distance[next_state] = distance[state] + 1
                if next_state == 0:
                    return distance[next_state]
                queue.append(next_state)

        return -1

class Solution {
public:
    int minFlips(vector<vector<int>>& mat) {
        int m = static_cast<int>(mat.size());
        int n = static_cast<int>(mat[0].size());
        int cells = m * n;
        int start = 0;

        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                if (mat[r][c] == 1) {
                    start |= 1 << (r * n + c);
                }
            }
        }
        if (start == 0) return 0;

        const array<array<int, 2>, 5> directions = {{{0, 0}, {1, 0},
            {-1, 0}, {0, 1}, {0, -1}}};
        vector<int> masks(cells, 0);
        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                int mask = 0;
                for (const auto& d : directions) {
                    int nr = r + d[0];
                    int nc = c + d[1];
                    if (nr >= 0 && nr < m && nc >= 0 && nc < n) {
                        mask |= 1 << (nr * n + nc);
                    }
                }
                masks[r * n + c] = mask;
            }
        }

        vector<int> distance(1 << cells, -1);
        queue<int> states;
        states.push(start);
        distance[start] = 0;

        while (!states.empty()) {
            int state = states.front();
            states.pop();
            for (int mask : masks) {
                int next = state ^ mask;
                if (distance[next] != -1) continue;
                distance[next] = distance[state] + 1;
                if (next == 0) return distance[next];
                states.push(next);
            }
        }
        return -1;
    }

替代方案

枚举所有操作子集：每个位置至多反转一次，枚举 2^k 种选择，并计算最终矩阵。逻辑可行，但若每个子集都重新模拟，时间复杂度通常为 O(2^k × k^2)；也可以预计算掩码将其优化。

从全零状态反向 BFS：由于反转操作可逆，从 0 搜到起点与从起点搜到 0 完全等价。若需要回答许多相同尺寸的矩阵，可对每种尺寸从 0 预计算所有距离。

线性代数（GF(2)）：可以用高斯消元判断可达性，但要额外寻找最小汉明重量解；对本题最多 9 个变量，BFS 更直接稳妥。

常见错误

  • 只反转邻格，忘记所选格子本身也必须反转。
  • 把对角线格子算作邻居；题目只认共享一条边的上下左右邻格。
  • 用字符串或二维数组作为访问标记却没有稳定序列化，导致重复状态。
  • 访问标记在出队时才设置，让同一状态被多次入队；应在入队时立刻标记。
  • 遇到全零状态后返回当前层距离而不是新状态距离，造成少算 1 步。
  • 把“快速生成模式”的静态用例展示误写成已运行、已通过的测试。
