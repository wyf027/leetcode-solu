最接近的二叉搜索树值 II

Closest Binary Search Tree Value II

一棵有序的树、一个小数目标和有限的名额。难点不在“找到一个”，而在只沿必要路径持续取出下一位邻居。

输入
BST · target · k
输出
k 个最接近值
核心挑战
按需寻找相邻节点
Problem

题目转述

给定一棵二叉搜索树的根节点 root、一个浮点数 target 和整数 k，返回树中与 target 的绝对差最小的 k 个节点值。答案中元素的顺序不作要求。

二叉搜索树满足：任一节点左子树中的值都更小，右子树中的值都更大。若多个候选与目标距离相同，选取任意满足“最接近的 k 个值”的结果均可。

示例 1

输入
root = [4,2,5,1,3], target = 3.714286, k = 2
输出
[4,3]
说明
4 和 3 与目标的距离分别约为 0.286 和 0.714。

示例 2

输入
root = [1], target = 0.000000, k = 1
输出
[1]
说明
树中只有一个节点，因此它就是唯一答案。

函数签名

closestKValues(root: TreeNode, target: double, k: int) → list<int>

约束

  • 1 ≤ k ≤ n ≤ 10⁴，其中 n 是节点数。
  • 0 ≤ Node.val ≤ 10⁹。
  • -10⁹ ≤ target ≤ 10⁹。
  • 输入保证 root 是合法二叉搜索树。

Solution

双栈模拟前驱与后继迭代器

核心洞察

如果把 BST 中序遍历，节点值会形成递增序列。距离 target 最近的值，必然来自分界线两侧：左侧当前最大值（前驱）或右侧当前最小值（后继）。不必真的生成整个序列；分别用两个栈保存从根到这两个游标的搜索路径，即可按需取得下一前驱和下一后继。

初始化时，前驱栈只保留值 ≤ target 的路径，后继栈只保留值 > target 的路径。这样当目标恰好等于某节点值时，该节点只会出现一次。

完整过程

  1. 从根向下建立前驱栈：若当前值不大于目标，把节点压栈并转向右子树；否则转向左子树。
  2. 再次从根向下建立后继栈：若当前值大于目标，把节点压栈并转向左子树；否则转向右子树。
  3. 重复 k 次。若一侧为空，只能从另一侧取值；否则比较两侧栈顶到目标的距离，取距离更小的一侧。
  4. 取出前驱后，进入它的左子树并一路向右压栈；取出后继后，进入它的右子树并一路向左压栈。新栈顶就是该方向的下一候选。

正确性证明

引理 1：前驱栈顶始终是尚未选取且不大于目标的最大值。初始化沿搜索路径保留所有可能前驱；弹出节点后转入其左子树并取最右路径，恰好得到中序序列中的前一项。

引理 2：后继栈顶始终是尚未选取且大于目标的最小值。论证与引理 1 对称。

贪心选择：所有未选值都位于当前前驱的左侧或当前后继的右侧，因此每侧栈顶分别是该侧距离目标最近者。两者中距离更小者就是全局最近的未选值。

结论：每轮选出全局最近的一个未选值，重复 k 轮后，结果正是距离目标最近的 k 个节点值。

复杂度

  • 令树高为 h。初始化时间为 O(h)。
  • 连续推进迭代器的摊还时间为 O(k)，总时间 O(h + k)。
  • 两个路径栈的额外空间为 O(h)；输出数组占 O(k)。
  • 平衡树中 h = O(log n)；极端退化树中 h = O(n)。

边界情况

  • k = 1 或树中只有一个节点。
  • target 小于最小节点：前驱栈为空，全从后继侧取。
  • target 大于最大节点：后继栈为空，全从前驱侧取。
  • target 恰好等于节点值：该值进入前驱侧，后继侧严格取更大值，避免重复。
  • k = n：两侧迭代器最终覆盖全树。

class Solution {
    public List<Integer> closestKValues(TreeNode root, double target, int k) {
        Deque<TreeNode> predecessors = new ArrayDeque<>();
        Deque<TreeNode> successors = new ArrayDeque<>();
        initPredecessors(root, target, predecessors);
        initSuccessors(root, target, successors);

        List<Integer> answer = new ArrayList<>(k);
        while (answer.size() < k) {
            if (predecessors.isEmpty()) {
                answer.add(nextSuccessor(successors));
            } else if (successors.isEmpty()) {
                answer.add(nextPredecessor(predecessors));
            } else {
                double leftGap = target - predecessors.peek().val;
                double rightGap = successors.peek().val - target;
                if (leftGap <= rightGap) {
                    answer.add(nextPredecessor(predecessors));
                } else {
                    answer.add(nextSuccessor(successors));
                }
            }
        }
        return answer;
    }

    private void initPredecessors(TreeNode node, double target,
                                  Deque<TreeNode> stack) {
        while (node != null) {
            if (node.val <= target) {
                stack.push(node);
                node = node.right;
            } else {
                node = node.left;
            }
        }
    }

    private void initSuccessors(TreeNode node, double target,
                                Deque<TreeNode> stack) {
        while (node != null) {
            if (node.val > target) {
                stack.push(node);
                node = node.left;
            } else {
                node = node.right;
            }
        }
    }

    private int nextPredecessor(Deque<TreeNode> stack) {
        TreeNode node = stack.pop();
        int value = node.val;
        node = node.left;
        while (node != null) {
            stack.push(node);
            node = node.right;
        }
        return value;
    }

    private int nextSuccessor(Deque<TreeNode> stack) {
        TreeNode node = stack.pop();
        int value = node.val;
        node = node.right;
        while (node != null) {
            stack.push(node);
            node = node.left;
        }
        return value;
    }
}

var closestKValues = function(root, target, k) {
    const predecessors = [];
    const successors = [];

    let node = root;
    while (node !== null) {
        if (node.val <= target) {
            predecessors.push(node);
            node = node.right;
        } else {
            node = node.left;
        }
    }

    node = root;
    while (node !== null) {
        if (node.val > target) {
            successors.push(node);
            node = node.left;
        } else {
            node = node.right;
        }
    }

    const nextPredecessor = () => {
        let current = predecessors.pop();
        const value = current.val;
        current = current.left;
        while (current !== null) {
            predecessors.push(current);
            current = current.right;
        }
        return value;
    };

    const nextSuccessor = () => {
        let current = successors.pop();
        const value = current.val;
        current = current.right;
        while (current !== null) {
            successors.push(current);
            current = current.left;
        }
        return value;
    };

    const answer = [];
    while (answer.length < k) {
        if (predecessors.length === 0) {
            answer.push(nextSuccessor());
        } else if (successors.length === 0) {
            answer.push(nextPredecessor());
        } else if (target - predecessors.at(-1).val <=
                   successors.at(-1).val - target) {
            answer.push(nextPredecessor());
        } else {
            answer.push(nextSuccessor());
        }
    }
    return answer;
};

class Solution {
public:
    vector<int> closestKValues(TreeNode* root, double target, int k) {
        stack<TreeNode*> predecessors;
        stack<TreeNode*> successors;
        initPredecessors(root, target, predecessors);
        initSuccessors(root, target, successors);

        vector<int> answer;
        answer.reserve(k);
        while (static_cast<int>(answer.size()) < k) {
            if (predecessors.empty()) {
                answer.push_back(nextSuccessor(successors));
            } else if (successors.empty()) {
                answer.push_back(nextPredecessor(predecessors));
            } else {
                double leftGap = target - predecessors.top()->val;
                double rightGap = successors.top()->val - target;
                if (leftGap <= rightGap) {
                    answer.push_back(nextPredecessor(predecessors));
                } else {
                    answer.push_back(nextSuccessor(successors));
                }
            }
        }
        return answer;
    }

private:
    void initPredecessors(TreeNode* node, double target,
                          stack<TreeNode*>& path) {
        while (node != nullptr) {
            if (node->val <= target) {
                path.push(node);
                node = node->right;
            } else {
                node = node->left;
            }
        }
    }

    void initSuccessors(TreeNode* node, double target,
                        stack<TreeNode*>& path) {
        while (node != nullptr) {
            if (node->val > target) {
                path.push(node);
                node = node->left;
            } else {
                node = node->right;
            }
        }
    }

    int nextPredecessor(stack<TreeNode*>& path) {
        TreeNode* node = path.top();
        path.pop();
        int value = node->val;
        node = node->left;
        while (node != nullptr) {
            path.push(node);
            node = node->right;
        }
        return value;
    }

    int nextSuccessor(stack<TreeNode*>& path) {
        TreeNode* node = path.top();
        path.pop();
        int value = node->val;
        node = node->right;
        while (node != nullptr) {
            path.push(node);
            node = node->left;
        }
        return value;
    }
};

替代方案

  • 完整中序数组 + 滑动窗口：实现直观，时间 O(n)、空间 O(n)；当 k 很小且树很大时浪费明显。
  • 大小为 k 的最大堆：遍历全树并维护距离最远的堆顶，时间 O(n log k)、空间 O(k + h)；不利用 BST 的有序性。
  • 中序迭代器 + 双向链式能力：思想相同；若节点自带父指针，可用两个节点游标把额外路径状态进一步简化。

面试追问

  • 若同一棵树要处理大量不同目标查询，如何预处理并权衡更新成本？
  • 如果节点带父指针，前驱与后继函数怎样改写？
  • 如果结果要求按值递增、按距离递增，分别需要怎样的后处理？
  • 当 BST 极度倾斜时，如何避免 O(n) 栈空间？平衡化是否值得？

常见错误

  • 前驱和后继初始化都包含等于 target 的节点，导致重复选取。
  • 只弹出栈顶却忘记补入其子树的边界路径，迭代器会跳过节点。
  • 比较差值时没有先处理空栈，访问不存在的栈顶。
  • 声称每次推进都是严格 O(1)；准确说法应是摊还 O(1)。
  • 误以为答案顺序固定，测试时直接比较未规范化的数组顺序。
