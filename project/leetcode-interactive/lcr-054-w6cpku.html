LCR 054 · MEDIUM

把二叉搜索树转换为累加树

将每个节点替换为它原来的值加上所有大于该节点值的节点值之和；原树仍是一棵树，只是节点数值被更新。

题意

给定二叉搜索树 root，把它转换成累加树：每个节点的新值等于原值加上树中所有大于该值的节点值。要求返回转换后的根节点。

示例

root = [4,1,6,0,2,5,7,null,null,null,3,null,null,null,8]

output = [30,36,21,36,35,26,15,null,null,null,33,null,null,null,8]

中序遍历原 BST 得到递增序列；反过来遍历便从最大值开始，维护一个累计和即可。

约束

节点数范围为 0 到 104；节点值范围为 0 到 104；输入保证是二叉搜索树。

交互实验室

用层序数组输入树，null 表示空节点。逐步执行右 → 根 → 左的反向中序遍历。

载入示例后开始观察。

反向中序顺序

    当前层序结果

      验证延后：本页仅提供算法推演，跨语言编译、随机对拍和浏览器交互验收未在本轮执行。

      核心洞察

      BST 的中序遍历是递增序列，因此反向中序遍历（右、根、左）正好按递减顺序访问节点。设 sum 为已经访问过的节点原值之和；访问当前节点时先把原值加到 sum，再将节点值改为 sum。

      完整过程

      1. 递归进入右子树，优先处理所有更大的值。
      2. 访问当前节点：sum += node.val，随后令 node.val = sum。
      3. 递归进入左子树，继续处理较小的值。
      4. 遍历结束后原根即为答案根。

      边界与常见错误

      • 空树直接返回 null。
      • 更新前必须先保留或累加原值，不能把已修改的值再次当作原值使用。
      • 访问方向必须是右、根、左；普通中序会得到“小于等于”的累计值。

      复杂度：每个节点恰好访问一次，时间 O(n)；递归栈空间为 O(h)，h 为树高。迭代写法：可用显式栈模拟反向中序，避免极深树时的递归调用栈风险。

      可提交代码

      Java

      class Solution {
    private int sum = 0;
    public TreeNode convertBST(TreeNode root) {
        if (root == null) return null;
        convertBST(root.right);
        sum += root.val;
        root.val = sum;
        convertBST(root.left);
        return root;
    }
}

      var convertBST = function (root) {
  let sum = 0;
  const dfs = (node) => {
    if (!node) return;
    dfs(node.right);
    sum += node.val;
    node.val = sum;
    dfs(node.left);
  };
  dfs(root);
  return root;
};

      class Solution:
    def convertBST(self, root: TreeNode) -> TreeNode:
        total = 0

        def dfs(node):
            nonlocal total
            if not node:
                return
            dfs(node.right)
            total += node.val
            node.val = total
            dfs(node.left)

        dfs(root)
        return root

      C++

      class Solution {
    int sum = 0;
    void dfs(TreeNode* node) {
        if (!node) return;
        dfs(node->right);
        sum += node->val;
        node->val = sum;
        dfs(node->left);
    }
public:
    TreeNode* convertBST(TreeNode* root) {
        dfs(root);
        return root;
    }
};
