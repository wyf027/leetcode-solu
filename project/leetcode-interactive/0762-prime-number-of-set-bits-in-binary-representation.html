762. 二进制表示中质数个计算置位

在一个闭区间里逐个观察整数：它们的二进制表示中有多少个 1？如果这个数量恰好是质数，就把它计入答案。

简单 位运算 数学 素性测试 非付费题
Problem brief

题目说明

先理解输入与目标。算法细节被收在页面底部，不会在首屏直接揭晓。

给定两个整数 left 和 right，请统计闭区间 [left, right] 中有多少个整数，其二进制表示里 1 的数量为质数，并返回这个数量。

二进制表示中的每个 1 称为一个“计算置位”（set bit）。例如，十进制 21 的二进制是 10101，其中有 3 个 1。

countPrimeSetBits(left: integer, right: integer) → integer
示例 01
输入：left = 6, right = 10
输出：4
6  → 0110 · 2 个置位 · 2 是质数
7  → 0111 · 3 个置位 · 3 是质数
8  → 1000 · 1 个置位 · 1 不是质数
9  → 1001 · 2 个置位 · 2 是质数
10 → 1010 · 2 个置位 · 2 是质数
因此共有 4 个符合条件的整数。
示例 02
输入：left = 10, right = 15
输出：5
10 → 1010 · 2 个置位 · 2 是质数
11 → 1011 · 3 个置位 · 3 是质数
12 → 1100 · 2 个置位 · 2 是质数
13 → 1101 · 3 个置位 · 3 是质数
14 → 1110 · 3 个置位 · 3 是质数
15 → 1111 · 4 个置位 · 4 不是质数
因此共有 5 个符合条件的整数。

Complete solution

题解：枚举 + 逐个清除最低位的 1

这一段只会在点击“查看题解”后出现。按 Esc 也可收起并返回按钮。

核心洞察

区间长度最多为 104，逐个检查完全足够。对每个整数反复执行 x &= x - 1，每次会消掉最低位的一个 1；循环次数恰好就是置位数。

为什么这条位运算有效？

x - 1 会把 x 最低位的 1 变成 0，并把它右边的位翻成 1。再与原数按位与，右侧新出现的 1 被清掉，最低位原有的 1 也被清除。

完整过程

  1. 从 left 到 right 枚举当前整数 value。
  2. 复制为临时变量 x，当 x != 0 时执行 x &= x - 1，并把置位计数加一。
  3. 判断置位数是否属于 {2, 3, 5, 7, 11, 13, 17, 19}。若属于，答案加一。
  4. 区间遍历结束后返回累计答案。

正确性证明

引理：对任意正整数 x，表达式 x & (x - 1) 恰好清除 x 最低位的一个 1，且不改变更高位的其他 1。因此循环每执行一次，剩余置位数严格减少 1；循环结束时 x = 0，执行次数正好等于原数的置位总数。

定理：算法返回闭区间中置位数为质数的整数个数。

对每个 value ∈ [left, right]，由引理，算法得到的计数等于其真实置位数。算法只在该计数属于不超过 20 的完整质数集合时把答案加一，因此每个符合条件的数被计一次，每个不符合条件的数不被计入。枚举覆盖闭区间且没有重复，最终累计值就是所求答案。

O(n · log R)时间复杂度
O(1)额外空间
n = right-left+1区间长度

边界情况

  • left = right：只判断一个整数，返回值只能是 0 或 1。
  • 置位数为 1：1 不是质数，例如二的幂不会被计入。
  • 区间达到最大长度：枚举最多 10001 个数，仍在约束允许的规模内。
  • right = 106：最多 20 位，质数表覆盖到 19 即完整。
Submittable code

四种语言完整代码

均保持官方函数签名，并使用同一套 Kernighan 置位计数机制。

Java 
class Solution {
    public int countPrimeSetBits(int left, int right) {
        int answer = 0;
        for (int value = left; value <= right; value++) {
            int setBits = countSetBits(value);
            if (isPrime(setBits)) {
                answer++;
            }
        }
        return answer;
    }

    private int countSetBits(int value) {
        int count = 0;
        while (value != 0) {
            value &= value - 1;
            count++;
        }
        return count;
    }

    private boolean isPrime(int value) {
        return value == 2 || value == 3 || value == 5 || value == 7
            || value == 11 || value == 13 || value == 17 || value == 19;
    }
}

Python 3 
class Solution:
    def countPrimeSetBits(self, left: int, right: int) -> int:
        answer = 0

        for value in range(left, right + 1):
            set_bits = self.count_set_bits(value)
            if self.is_prime(set_bits):
                answer += 1

        return answer

    def count_set_bits(self, value: int) -> int:
        count = 0
        while value:
            value &= value - 1
            count += 1
        return count

    def is_prime(self, value: int) -> bool:
        return value in {2, 3, 5, 7, 11, 13, 17, 19}

替代方案

  • 语言内置置位计数：Java 的 Integer.bitCount、C++20 的 std::popcount、Python 的 int.bit_count() 都能让代码更短。
  • 质数位掩码：把质数位置设为 1，用一次移位与按位与完成查询；常数更小，但“魔法常量”可读性较差。
  • 逐位右移：检查最低位后右移，容易理解，但会遍历所有二进制位，而不是只遍历 1。

常见错误

  • 把 1 当作质数；质数必须大于 1。
  • 枚举写成 value < right，漏掉闭区间右端点。
  • 只判断整数本身是否为质数，而不是判断“置位数”。
  • 使用位掩码时漏掉 17 或 19。
  • 在 JavaScript 的更大整数场景照搬 32 位位运算；本题上限内安全，但通用场景需考虑 BigInt。
Follow-up

面试追问

如果区间扩大到非常大，不能逐个枚举怎么办？

可考虑数位 DP：按二进制位统计不超过某个上界、且置位数属于质数集合的数字数量，再用前缀计数相减。

为什么不需要对每个置位数做通用素性测试？

约束把置位数限制在 0 到 20，预先列出有限质数集合更直接，也避免重复计算。

x & (x - 1) 还能解决什么问题？

可用于判断二的幂、计算汉明重量，以及枚举一个集合位掩码的子集。
