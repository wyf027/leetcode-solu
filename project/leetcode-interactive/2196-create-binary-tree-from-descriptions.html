01 / 题目

把描述还原成节点

输入二维整数数组 descriptions。每个三元组 [parent, child, isLeft] 表示一个父子关系：isLeft = 1 时连接到左孩子，isLeft = 0 时连接到右孩子。所有节点值互不相同，输入保证描述的是一棵有效二叉树。构造这棵树并返回它的根节点对象。

函数：createBinaryTree(descriptions) → TreeNode。下方输出数组是二叉树的层序序列化，null 表示空位置，末尾空位省略；提交时返回节点，不是数组。

官方示例 1

输入：descriptions = [[20,15,1],[20,17,0],[50,20,1],[50,80,0],[80,19,1]]
输出：[50,20,80,15,17,19]

50 的左、右孩子分别是 20、80；20 的孩子是 15、17；80 的左孩子是 19。50 没有父节点。

官方示例 2

输入：descriptions = [[1,2,1],[2,3,0],[3,4,1]]
输出：[1,2,null,null,3,4]

从 1 开始依次向左到 2、向右到 3、向左到 4，根节点为 1。

约束

  • 1 ≤ descriptions.length ≤ 10⁴
  • descriptions[i].length = 3
  • 1 ≤ parentᵢ, childᵢ ≤ 10⁵
  • 0 ≤ isLeftᵢ ≤ 1，且为整数。
  • 各节点的值唯一，描述构成一棵有效二叉树。

04 / 独立题解

想好自己的方法了吗？

展开后查看推导、正确性论证与四种语言实现。

哈希表复用节点，孩子集合定位根

核心洞察

同一个值可能多次作为父节点或孩子出现，但它必须对应同一个节点对象。用 nodes[value] 保存唯一对象。所有孩子的值放进集合 children；最终唯一不在孩子集合中的节点就是根。输入顺序不保证从根开始，也不具备二叉搜索树的大小关系。

完整过程

  1. 建立空哈希表 nodes 和空集合 children。
  2. 依次读取 [p,c,isLeft]，分别在值尚未出现时创建 p、c 对应的节点。
  3. 若 isLeft === 1，令 p 的左指针指向 c；否则设置右指针。
  4. 把 c 加入孩子集合。即使 c 先前曾作为父节点，它也不会丢失已经建立的子树。
  5. 全部关系处理完后遍历节点表，返回值不在孩子集合中的那个节点。

示例 1 的孩子集合最终是 {15,17,20,80,19}，节点表还含有 50，故返回 nodes[50]。第三条描述把已经拥有两个孩子的节点 20 接到 50 下方，复用对象使整棵子树自然保留。

正确性

不变式：处理前 k 条描述后，每个已出现的值恰有一个节点对象；前 k 条描述要求的指针均已建立；孩子集合恰含这 k 条描述中出现过的孩子值。

初始 k = 0 时三个条件成立。每次只为尚不存在的值创建对象，故唯一性保持；根据标志写入指定指针，且有效树保证不会产生矛盾连接；加入当前孩子值后，集合条件仍成立。因此处理结束后，所有节点和连接都与输入一致。

有效树的每个非根节点恰有一个父节点，都会作为孩子出现；根没有父节点，不会出现在孩子集合中。因此扫描找到的唯一节点就是根，返回它即可访问完整二叉树。

复杂度与边界

令 m 为描述数量、n 为不同节点数量。有效树中 n = m + 1。哈希操作平均 O(1)，总时间期望 O(m + n) = O(m)；节点表与孩子集合的额外空间 O(n)，返回树本身也占 O(n)。哈希表理论最坏情况不承诺单次常数时间。

只有一条描述时仍有两个节点；根可能很晚才出现；左右单链都适用。构造过程不使用递归，因此深度接近 10⁴ 时也不增加调用栈。空输入、环、多父节点不属于官方有效输入契约。

替代方案

  • 父指针表：建立 child → parent，从任意节点沿父指针向上直到没有父节点；有效树中最多 O(n) 步。仍须另外构造左右指针。
  • 先存邻接关系，再 DFS 建树：仍是 O(n)，但深链可能导致递归栈溢出；直接连接对象省掉第二轮建树。
  • 数组替代哈希：利用值上界 10⁵ 建索引数组和布尔孩子标记。时间 O(m + U)、空间 O(U)，U = 10⁵，数据稀疏时会浪费空间。

常见错误

  • 每条描述都 new 一个父节点，导致同值节点分裂、先前连接丢失。
  • 认为第一条的 parent 或最小值就是根；顺序与值大小不决定根。
  • 把 parent 加进孩子集合，或将 isLeft 的 0 / 1 含义弄反。
  • 尚未读完全部描述就返回“未见父节点”的候选节点。
  • 按值大小连接成搜索树，或返回层序数组而非根对象。

面试追问

若输入不保证有效怎么办？检查左右槽冲突、孩子多父、自环；再检查唯一根以及从根可访问全部节点，可用迭代遍历检测环和连通性。
可以流式处理吗？每条到来时复用节点并连接即可，但在流结束之前不能确定最终根。
节点值不唯一呢？需要独立、唯一的节点 ID；仅凭重复值无法唯一重建。

Java

import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

/* LeetCode 提供：
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}
*/
class Solution {
    public TreeNode createBinaryTree(int[][] descriptions) {
        Map<Integer, TreeNode> nodes = new HashMap<>();
        Set<Integer> children = new HashSet<>();
        for (int[] d : descriptions) {
            int p = d[0], c = d[1];
            nodes.computeIfAbsent(p, TreeNode::new);
            nodes.computeIfAbsent(c, TreeNode::new);
            if (d[2] == 1) nodes.get(p).left = nodes.get(c);
            else nodes.get(p).right = nodes.get(c);
            children.add(c);
        }
        for (Map.Entry<Integer, TreeNode> entry : nodes.entrySet()) {
            if (!children.contains(entry.getKey())) return entry.getValue();
        }
        return null; // 有效输入不会走到这里
    }
}

function TreeNode(val, left = null, right = null) {

/**
 * @param {number[][]} descriptions
 * @return {TreeNode}
 */
var createBinaryTree = function(descriptions) {
    const nodes = new Map();
    const children = new Set();
    for (const [p, c, isLeft] of descriptions) {
        if (!nodes.has(p)) nodes.set(p, new TreeNode(p));
        if (!nodes.has(c)) nodes.set(c, new TreeNode(c));
        if (isLeft === 1) nodes.get(p).left = nodes.get(c);
        else nodes.get(p).right = nodes.get(c);
        children.add(c);
    }
    for (const [value, node] of nodes) {
        if (!children.has(value)) return node;
    }
    return null;
};

Python 3

from typing import List, Optional

# LeetCode 提供：
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def createBinaryTree(
        self, descriptions: List[List[int]]
    ) -> Optional[TreeNode]:
        nodes = {}
        children = set()
        for p, c, is_left in descriptions:
            if p not in nodes:
                nodes[p] = TreeNode(p)
            if c not in nodes:
                nodes[c] = TreeNode(c)
            if is_left == 1:
                nodes[p].left = nodes[c]
            else:
                nodes[p].right = nodes[c]
            children.add(c)
        for value, node in nodes.items():
            if value not in children:
                return node
        return None

C++

#include <vector>
#include <unordered_map>
#include <unordered_set>
using namespace std;

/* LeetCode 提供：
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
*/
class Solution {
public:
    TreeNode* createBinaryTree(vector<vector<int>>& descriptions) {
        unordered_map<int, TreeNode*> nodes;
        unordered_set<int> children;
        for (const auto& d : descriptions) {
            int p = d[0], c = d[1];
            if (!nodes.count(p)) nodes[p] = new TreeNode(p);
            if (!nodes.count(c)) nodes[c] = new TreeNode(c);
            if (d[2] == 1) nodes[p]->left = nodes[c];
            else nodes[p]->right = nodes[c];
            children.insert(c);
        }
        for (const auto& entry : nodes) {
            if (!children.count(entry.first)) return entry.second;
        }
        return nullptr;
    }
};
