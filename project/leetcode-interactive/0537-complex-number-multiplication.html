复数乘法

把字符串拆成数学对象，再把四次整数乘法组合成标准复数。先动手观察展开过程，题解藏在页面后半段。

MEDIUM非付费题O(n + m)

题目

复数以字符串 "real+imaginaryi" 表示。给定两个有效的复数字符串 num1 与 num2，返回它们乘积的同形式字符串。

实部和虚部都是整数；虚部为负时，表示中会自然出现 +-，例如 "1+-1i"。

官方示例

输入：num1 = "1+1i", num2 = "1+1i"
输出："0+2i"
解释：(1 + i)(1 + i) = 1 + 2i + i² = 2i
输入：num1 = "1+-1i", num2 = "1+-1i"
输出："0+-2i"
解释：(1 - i)(1 - i) = 1 - 2i + i² = -2i

约束

  • num1、num2 均为有效复数表示。
  • 实部、虚部均在 [-100, 100]。
  • i² = -1。

乘法展开实验室

编辑两个输入，逐步追踪解析、交叉相乘与合并。

ac
ad·i
bc·i
bd·i²

核心洞察

只需记住：若两个数是 a+bi 与 c+di，乘积为 (ac-bd)+(ad+bc)i。字符串工作只有解析与格式化。

完整过程

  1. 以加号为分界，解析出 a, b, c, d；末尾的 i 不参与数值转换。
  2. 按分配律得到 ac + adi + bci + bdi²。
  3. 利用 i²=-1，实部为 ac-bd，虚部为 ad+bc。
  4. 拼成 实部+虚部i；即使虚部为负，也保留中间的字面加号。

正确性证明

  1. 解析步骤从有效表示中分别取得两个复数的实部和虚部，因此得到的 a,b,c,d 与输入等价。
  2. 分配律保证四项 ac, adi, bci, bdi² 完整且无重复地覆盖乘积。
  3. 由 i²=-1，常数项恰为 ac-bd；含 i 的项合并后系数恰为 ad+bc。
  4. 最终字符串使用题目规定格式表达上述实部和虚部，故算法返回正确乘积。

边界

  • 零实部或零虚部。
  • 负虚部产生 +-。
  • -100 与 100 的端点。
  • 乘积实部或虚部为零。

复杂度

时间 O(n + m)，空间 O(n + m)

字符串切分与解析线性；若把整数宽度视为常数，也常表述为 O(1)。

替代方案

可用正则表达式同时捕获两部分，表达更声明式；但本题格式固定，按加号切分更直观、依赖更少。C++ 也可借助字符串流逐段读取。

面试追问

  • 若格式允许省略实部、出现空格或写成 a-bi，解析器如何设计？
  • 若系数超出机器整数范围，如何改用大整数？
  • 如何扩展为复数加减、除法与幂运算？

常见错误

  • 把结果实部误写成 ac+bd，忘记 i²=-1。
  • 按负号切分，破坏 1+-1i 的固定格式。
  • 虚部为负时输出 1-2i；题目要求字面格式是 1+-2i。
