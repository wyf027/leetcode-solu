查找给定哈希值的子串

Find Substring With Given Hash Value

一个字符串，多个长度相同的窗口。给定一套哈希规则，你要找到满足目标值、且位置最靠左的那个子串。

字符串哈希函数免费题

01 / 题目与规则

输入字符串 s 和四个整数 power、modulo、k、hashValue。字母数值从 a = 1 到 z = 26。对于长度为 k 的子串 sub，按字符在子串中的位置计算：

hash(sub) = Σ (val(sub[j]) × powerj) mod modulo，0 ≤ j < k

返回哈希值等于 hashValue 的、起始下标最小的长度 k 子串。子串必须连续；指数从子串左端的 0 重新计数。官方保证至少有一个答案。

约束

  • 1 ≤ k ≤ s.length ≤ 2 × 10⁴
  • 1 ≤ power, modulo ≤ 10⁹
  • 0 ≤ hashValue < modulo
  • s 只含小写英文字母。
  • 输入保证存在满足条件的子串。

02 / 官方示例

示例 1

s = "leetcode"
power = 7, modulo = 20
k = 2, hashValue = 0
输出："ee"

(5 × 1 + 5 × 7) mod 20 = 0，因此最早满足条件的子串是 “ee”。

示例 2

s = "fbxzaad"
power = 31, modulo = 100
k = 3, hashValue = 32
输出："fbx"

“fbx”：(6 + 2 × 31 + 24 × 31²) mod 100 = 23132 mod 100 = 32。

“bxz”：(2 + 24 × 31 + 26 × 31²) mod 100 = 25732 mod 100 = 32。两者都符合，返回更靠左的 “fbx”。

04 / 深入理解

准备好后展开，观察指数如何随窗口移动，再阅读证明与实现。

题解 · 从右向左，让指数自然递增

左端字符的权重是 p⁰。向左移动窗口时，旧字符的指数都增加 1，恰好只需将旧哈希乘 p，再加入新的左端字符；超出长度的右端字符此时权重为 pᵏ，将它减掉即可。

Hᵢ = (p × Hᵢ₊₁ + val(s[i]) − val(s[i+k]) × pᵏ) mod m

最后一项仅在 i + k < n 时存在。所有余数统一归一到 [0, m)。

完整过程

  1. 通过 k 次模乘预先计算 pk = pᵏ mod m，避免计算巨大幂。
  2. 令 h = 0，从 n − 1 扫描到 0；先执行 h = (h × p + val(s[i])) mod m。
  3. 若 i + k < n，减去离开窗口的字符贡献 val(s[i+k]) × pk mod m，再归一化。
  4. 当 i ≤ n − k 时窗口才完整；若 h 等于目标，记录当前起点 i。
  5. 命中后继续扫描。每次覆盖记录的起点都更小，结束时截取长度 k 的答案。

正确性说明

窗口不变量：处理 i 后，h 等于 s[i : min(n, i+k)] 的定义哈希。初始为空，加入最右端字符后显然成立。假定处理 i + 1 后成立，将旧值乘 p 令旧字符的指数全部加 1，加入 s[i] 的 p⁰ 项；若多出一个字符，减掉恰好处于 pᵏ 的 s[i+k]。因此不变量保持。

答案选择：所有长度 k 的窗口起点都会被访问，且只在窗口完整时比较。由于起点从大到小遍历，每次匹配都覆盖答案，最终保存的是所有匹配中的最小起点。官方保证至少一个匹配，所以返回的切片存在且正确。

边界与数值安全

  • k = 1 时是逐字符比较；k = n 时只有一个完整窗口。
  • modulo = 1 时所有哈希均为 0，最终返回最左窗口；power = 1 不影响递推。
  • p 与 m 不必互质；本方法不需要模逆元。
  • 先把移出项取模，再执行 (h − removed + m) % m，一次加 m 即可避免负数。
  • Java 用 long，C++ 用 long long。最大模乘小于 10¹⁸，处于有符号 64 位整数范围内。JavaScript 的 Number 不足以精确表示这些乘积，哈希运算使用 BigInt；下标仍用 Number。
  • 哈希碰撞是允许的：任务本来就是找目标哈希，无须把不同字符串“去重”或额外做文本相等比较。

复杂度

n = s.length。预计算 O(k)，扫描 O(n)，合计 O(n)（k ≤ n）。额外工作空间 O(1)，不计返回字符串；输出切片通常需要 O(k) 时间和空间。此处把约束内固定宽度整数运算视为 O(1)。教学演示为回放保存全部步骤，不属于提交算法的空间开销。

替代方案

  • 逐窗口重新算：O(nk) 时间、O(1) 工作空间，适合手工理解，最大输入开销过大。
  • 反向多项式前缀：定义 R[i] = (val(s[i]) + p × R[i+1]) mod m，则窗口哈希为 (R[i] − pᵏ × R[i+k]) mod m。O(n) 时间、O(n) 空间，方便查询多个起点。
  • 正向滚动：删除左端后需要除以 p；模除法要求逆元存在。由于本题没有互质保证，不能普遍采用这种做法。

常见错误

  • 误把左端的权重设为 pᵏ⁻¹，算成另一种哈希定义。
  • 移出时减 pᵏ⁻¹ 项；旧哈希已乘 p，应减 pᵏ 项。
  • 逆向遍历首次命中就返回，得到右侧答案而非最左答案。
  • 在不足 k 个字符的预热阶段比较目标。
  • 用 Number 或 32 位 int 执行大模乘，或对负余数不做归一化。

面试追问

如果没有保证存在答案？保留 answer = −1 的哨兵，结束后明确返回空串或约定结果，避免负索引切片。下面代码遵循官方保证。

如果有很多窗口查询？使用反向前缀哈希，预处理后对固定或已预计算幂的长度做 O(1) 查询。

如何查找全部匹配？收集所有匹配起点，再反转列表得到升序；输出空间为 O(匹配数量)。

Java

class Solution {
    public String subStrHash(String s, int power, int modulo,
                             int k, int hashValue) {
        int n = s.length(), answer = -1;
        long h = 0, pk = 1;
        for (int j = 0; j < k; j++) pk = pk * power % modulo;
        for (int i = n - 1; i >= 0; i--) {
            h = (h * power + s.charAt(i) - 'a' + 1) % modulo;
            if (i + k < n) {
                long removed = (s.charAt(i + k) - 'a' + 1) * pk % modulo;
                h = (h - removed + modulo) % modulo;
            }
            if (i <= n - k && h == hashValue) answer = i;
        }
        return s.substring(answer, answer + k);
    }
}

JavaScript

/**
 * @param {string} s
 * @param {number} power
 * @param {number} modulo
 * @param {number} k
 * @param {number} hashValue
 * @return {string}
 */
var subStrHash = function(s, power, modulo, k, hashValue) {
    const p = BigInt(power), m = BigInt(modulo);
    const target = BigInt(hashValue), n = s.length;
    const val = i => BigInt(s.charCodeAt(i) - 96);
    let h = 0n, pk = 1n, answer = -1;
    for (let j = 0; j < k; j++) pk = pk * p % m;
    for (let i = n - 1; i >= 0; i--) {
        h = (h * p + val(i)) % m;
        if (i + k < n) {
            const removed = val(i + k) * pk % m;
            h = (h - removed + m) % m;
        }
        if (i <= n - k && h === target) answer = i;
    }
    return s.slice(answer, answer + k);
};

#include <string>
using namespace std;

class Solution {
public:
    string subStrHash(string s, int power, int modulo,
                      int k, int hashValue) {
        int n = static_cast<int>(s.size()), answer = -1;
        long long h = 0, pk = 1;
        for (int j = 0; j < k; ++j) pk = pk * power % modulo;
        for (int i = n - 1; i >= 0; --i) {
            h = (h * power + s[i] - 'a' + 1) % modulo;
            if (i + k < n) {
                long long removed = (s[i + k] - 'a' + 1) * pk % modulo;
                h = (h - removed + modulo) % modulo;
            }
            if (i <= n - k && h == hashValue) answer = i;
        }
        return s.substr(answer, k);
    }
};
