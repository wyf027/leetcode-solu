给定二叉搜索树的
插入顺序求深度

Depth of BST Given Insertion Order

同一组数字，不同插入顺序，树会长成什么样？先观察，再推导。

题目

给定长度为 n 的数组 order，它是 1 到 n 的一个排列。从空二叉搜索树开始依次插入数组元素：第一个值成为根；之后每个值从根开始比较，小于当前节点就向左，大于就向右，直到空位置。求最终树的最大深度，也就是根到最远叶子路径上的节点数。

maxDepthBST(order: integer[]) → integer

约束：n == order.length；1 ≤ n ≤ 10⁵；order 是 1…n 的排列，每个值恰好出现一次。

官方示例 1

输入：order = [2,1,4,3]
输出：3

最长路径为 2 → 4 → 3。

官方示例 2

输入：order = [2,1,3,4]
输出：3

最长路径为 2 → 3 → 4。

官方示例 3

输入：order = [1,2,3,4]
输出：4

形成向右的链 1 → 2 → 3 → 4。

题解 · 倒序记录邻居，正序计算深度

核心洞察

插入 x 之前，在已经插入的值中找严格前驱 a 和严格后继 b。父节点是两者中较深的一个，因此 depth[x] = 1 + max(depth[a], depth[b])。缺失边界用深度为 0 的哨兵替代。

为什么两个邻居足够？

搜索树中相邻的两个键，如果都存在，其中一个必为另一个的祖先：它们的最近公共祖先若是第三个键，就会落在它们之间，与相邻矛盾。两者之间的空隙由更深者的空子链接表示；否则还会存在介于两者之间的第三个键。因此新值接到更深者下面。只有一个边界时，该边界是父节点；两个都不存在时，新值成为根。

完整过程 · O(n) 离线算法

  1. 值域是连续排列，可用 left[x]、right[x] 构成按值排序的双向链表。0 与 n+1 是哨兵。
  2. 倒序处理 order。删除 order[i] 之前，链表包含且仅包含 order[0…i]。保存该值的左右邻居，作为正向插入时的前驱与后继。
  3. 若邻居为 a、b，则更新 right[a] = b、left[b] = a，完成 O(1) 删除。每个元素只删除一次。
  4. 正向处理 order，邻居深度均已确定，按公式计算新深度，并更新最大值。
order = [2,1,4,3]，哨兵为 0 和 5
倒序删除记录：
3 → 邻居 (2,4)
4 → 邻居 (2,5)
1 → 邻居 (0,2)
2 → 邻居 (0,5)
正序计算：
depth[2] = 1 + max(0,0) = 1
depth[1] = 1 + max(0,1) = 2
depth[4] = 1 + max(1,0) = 2
depth[3] = 1 + max(1,2) = 3
答案为 3。

正确性证明

逆序阶段初始包含所有值。每次双向链接只绕过当前删除值，保留剩余元素的数值顺序，归纳可得处理 i 时链表恰为前 i+1 个元素。当前元素两侧的邻居就是正向插入前的邻居。正序阶段以哨兵深度 0 为基础，真实邻居均更早插入，深度已正确求出；由父节点性质，递推得到每个节点的真实深度。所有节点深度的最大值即所求最大树深度。

复杂度、边界

初始化、逆序删除、正向计算均为 O(n)，总时间 O(n)，额外空间 O(n)。无需建树或递归。单节点返回 1；单调序列形成链，深度为 n；n=100000 时也不会出现树高导致的递归栈溢出。数组长度必须为 n+2，两个哨兵深度始终为 0。

替代方案

在线数据可用 Java TreeMap 或 C++ map 查询邻居，总时间 O(n log n)、空间 O(n)。Python bisect 的查找虽快，但列表插入会移动元素，最坏总时间 O(n²)。直接按题意构建普通 BST 也可能退化到 O(n²)。任意互异整数可以先排序压缩坐标，再复用离线链表，总时间为 O(n log n)。

常见错误

  • 取邻居深度的最小值，或者把根深度设成 0。
  • 使用最终全集的邻居，而非本次插入之前的邻居。
  • 删除后才记录邻居，或只更新一个方向的链接。
  • 把原数组排序后再处理，丢失插入顺序。
  • 忘记本算法依赖 1…n 的排列，直接用任意值作为下标。

面试追问

不能预读所有输入？改用有序映射，逐个在线处理。允许重复键？先约定相等时走哪侧，再考虑用插入序号构造全序，不能直接套用当前排列算法。如何恢复树？取较深的真实邻居作为父节点，按新值大小连接左右孩子。

Java

class Solution {
    public int maxDepthBST(int[] order) {
        int n = order.length;
        int[] left = new int[n + 2], right = new int[n + 2];
        int[] pred = new int[n], succ = new int[n];
        int[] depth = new int[n + 2];
        for (int x = 1; x <= n; x++) {
            left[x] = x - 1; right[x] = x + 1;
        }
        for (int i = n - 1; i >= 0; i--) {
            int x = order[i], a = left[x], b = right[x];
            pred[i] = a; succ[i] = b;
            right[a] = b; left[b] = a;
        }
        int ans = 0;
        for (int i = 0; i < n; i++) {
            depth[order[i]] = 1 + Math.max(depth[pred[i]], depth[succ[i]]);
            ans = Math.max(ans, depth[order[i]]);
        }
        return ans;
    }
}

Python

from typing import List

class Solution:
    def maxDepthBST(self, order: List[int]) -> int:
        n = len(order)
        left = [x - 1 for x in range(n + 2)]
        right = [x + 1 for x in range(n + 2)]
        pred, succ = [0] * n, [0] * n
        depth = [0] * (n + 2)
        for i in range(n - 1, -1, -1):
            x = order[i]
            a, b = left[x], right[x]
            pred[i], succ[i] = a, b
            right[a], left[b] = b, a
        ans = 0
        for i, x in enumerate(order):
            depth[x] = 1 + max(depth[pred[i]], depth[succ[i]])
            ans = max(ans, depth[x])
        return ans
