211. 添加与搜索单词

Trie 让相同前缀共用节点；遇到通配符 . 时，不猜一个字母，而是把搜索分叉到当前节点的每个孩子。

Medium前缀树DFS 回溯
官方标题
Design Add and Search Words Data Structure
设计对象
WordDictionary
通配符
. 匹配任意字母

题意

设计 WordDictionary：addWord(word) 把单词加入结构；search(word) 判断此前是否有单词匹配。查询串可含 .，每一个点可以匹配任意一个小写英文字母。
官方示例
ops = ["WordDictionary","addWord","addWord","addWord","search","search","search","search"]
args = [[],["bad"],["dad"],["mad"],["pad"],["bad"],[".ad"],["b.."]]
输出：[null,null,null,null,false,true,true,true]

约束：1 ≤ word.length ≤ 25；添加单词只含小写字母；查询含小写字母或 .，且最多 2 个点；调用次数最多 10⁴。

题解：点号不是节点，是分支

核心洞察

每个 Trie 节点表示一个前缀，孩子按下一个字符连接。普通字母只沿一条边走；. 需要依次尝试当前所有孩子，并递归匹配剩余后缀。任一分支抵达单词结尾即可返回真。

完整过程

  1. addWord 沿字符创建缺失孩子，最后节点设为单词结束。
  2. search 从根和索引 0 调用 DFS。
  3. 若当前字符是字母，走对应孩子；不存在则失败。
  4. 若是 .，对所有孩子 DFS；发现一个成功分支就短路返回。
  5. 字符串用尽时，只有当前节点是单词结束才成功。
addWord
O(L) 时间、最多 O(L) 新节点。
search
无点时 O(L)；点号会分叉，最坏 O(26^d × L)，d 为点数。

替代方案与取舍

把单词放入哈希集合，查询含点时需要枚举模式匹配，无法共享前缀。Trie 在大量共同前缀的词典中更省重复比较；本题点数最多两个，使 DFS 分叉可控。

边界

  • 查询 bad 与插入 bad 匹配。
  • pad 不存在，返回 false。
  • .ad 只要 bad、dad 或 mad 任一存在就返回 true。
  • 前缀本身不是单词时，不能仅因节点存在就返回 true。

常见错误

把 . 当成 Trie 中的字面节点，或只检查第一个孩子，都会漏掉正确分支；到达查询尾部时忘记检查单词结束标记，会把任意前缀误判为单词。

面试追问

如果支持删除单词，可在结束节点清除标记，并在回溯时删除没有孩子且不再是词尾的节点。若点号很多，可考虑记忆化 (node, index) 状态。

可提交代码

class WordDictionary {
    static class Node { Node[] next = new Node[26]; boolean end; }
    private final Node root = new Node();
    public WordDictionary() {}
    public void addWord(String word) {
        Node cur = root;
        for (char ch : word.toCharArray()) {
            int i = ch - 'a';
            if (cur.next[i] == null) cur.next[i] = new Node();
            cur = cur.next[i];
        }
        cur.end = true;
    }
    public boolean search(String word) { return dfs(word, 0, root); }
    private boolean dfs(String word, int i, Node node) {
        if (i == word.length()) return node.end;
        char ch = word.charAt(i);
        if (ch != '.') return node.next[ch - 'a'] != null && dfs(word, i + 1, node.next[ch - 'a']);
        for (Node child : node.next) if (child != null && dfs(word, i + 1, child)) return true;
        return false;
    }
}

WordDictionary.prototype.search = function (word) {
  const dfs = (node, i) => {
    if (i === word.length) return node.end;
    const ch = word[i];
    if (ch !== '.') return node.next[ch] ? dfs(node.next[ch], i + 1) : false;
    return Object.values(node.next).some((child) => dfs(child, i + 1));
  };
  return dfs(this, 0);
};
class Node:
    def __init__(self):
        self.next = {}
        self.end = False

class WordDictionary:
    def __init__(self):
        self.root = Node()

    def addWord(self, word: str) -> None:
        node = self.root
        for ch in word:
            node = node.next.setdefault(ch, Node())
        node.end = True

    def search(self, word: str) -> bool:
        def dfs(node, i):
            if i == len(word): return node.end
            if word[i] != '.':
                return word[i] in node.next and dfs(node.next[word[i]], i + 1)
            return any(dfs(child, i + 1) for child in node.next.values())
        return dfs(self.root, 0)
class WordDictionary {
    struct Node { array<Node*, 26> next{}; bool end = false; };
    Node* root = new Node();
    bool dfs(const string& word, int i, Node* node) {
        if (i == (int)word.size()) return node->end;
        if (word[i] != '.') { Node* child = node->next[word[i] - 'a']; return child && dfs(word, i + 1, child); }
        for (Node* child : node->next) if (child && dfs(word, i + 1, child)) return true;
        return false;
    }
public:
    WordDictionary() = default;
    void addWord(string word) {
        Node* node = root;
        for (char ch : word) { int i = ch - 'a'; if (!node->next[i]) node->next[i] = new Node(); node = node->next[i]; }
        node->end = true;
    }
    bool search(string word) { return dfs(word, 0, root); }
