组合

从 1 到 n 中选出 k 个数，返回所有不重复组合。

题意与示例

n = 4, k = 2
输出：[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]

约束

  • 1 ≤ n ≤ 20
  • 1 ≤ k ≤ n
  • 组合内元素递增，结果无重复。

分步交互：回溯搜索树

洞察与完整过程

  1. 维护递增的当前 path。
  2. 长度等于 k 时复制收集。
  3. 从 start 开始选下一个数。
  4. 递归返回后 pop 完成回溯。

边界、复杂度、替代

k=n 时只有一个组合。输出量级为 C(n,k)，时间受答案规模主导，递归辅助空间 O(k)。可用位掩码枚举，但回溯剪枝更自然。
