杀死所有怪物的最短时间

Minimum Time to Kill All Monsters

每次胜利都会让你变强，也会清空你的魔法值。
怎样安排出手顺序，才能最早结束战斗？

01理解规则

给定整数数组 power，其中 power[i] 是第 i 只怪物的力量。你从魔法值 0 开始，每天增加 gain 点魔法值，初始 gain = 1。

① 每天积累
先获得当天的 gain 点魔法值。
② 选择击杀
魔法值达到某只存活怪物的力量，就可将其击杀。
③ 清零与成长
击杀后魔法值归零，gain 加 1。

求击杀所有怪物需要的最少天数。怪物顺序可自由选择；没有击杀时，魔法值保留到下一天。击杀不另占一天，也不保留多余魔法值。

约束：1 ≤ power.length ≤ 17；1 ≤ power[i] ≤ 10⁹。

接口：minimumTime(power: integer[]) → long

题意为简要转述。官方元数据提供题名、接口及示例输入，题面字段为空；规则、示例输出与约束补自公开题目资料。官方题目入口需订阅查看。

输出：4

依次击杀力量 1、4、3 的怪物，分别用 1、2、1 天；第 1、3、4 天完成击杀。

03题解 · 把不同顺序合并为同一个集合

核心洞察

只在刚击杀一只怪物后记录状态，此时魔法值一定是 0。若已击杀 k 只，下一阶段每天获得 k + 1 点魔法。未来只取决于“哪些怪物已经死了”，无需记录它们的击杀顺序。

用 mask 的第 i 位表示第 i 只怪物是否已击杀（1 表示已击杀）。定义 dp[mask] 为到达该集合的最少天数。这里采用“枚举最后击杀谁”的写法。

dp[0] = 0
对于每个非空 mask：
    k = popcount(mask)
    枚举 mask 中的每一只怪物 i：
        prev = mask 去掉第 i 位
        // 击杀 i 之前已有 k - 1 只死亡，因此 gain = k
        days = ceil(power[i] / k)
        dp[mask] = min(dp[mask], dp[prev] + days)
答案 = dp[(1 << n) - 1]

完整过程

  1. 给怪物按原数组位置编号，即便力量相同也保留不同的位。
  2. 建立 2ⁿ 个状态，空集合为 0 天，其余初始化为无穷大。
  3. 从小到大枚举非空 mask。清除其中一个置位必然得到更小的数，所以依赖已算好。
  4. 尝试每一只已置位怪物作为最后一只，累加前驱最优值与本阶段等待时间，取最小值。
  5. 所有位均为 1 时，已经击杀全部怪物，返回该状态的值。

正确性证明

阶段最优性：给定下一只要击杀的怪物及当前 gain，从 0 开始积累至少需要 ⌈power[i]/gain⌉ 天；恰好等待这些天即可击杀。再多等只会拖延，且多余魔法在击杀时会清零，不会帮助后续阶段。

归纳：空集合的最优值为 0。假设所有更小集合均已得到最优值。任何恰好击杀 mask 中怪物的方案都有最后一只 i，其前缀集合是 mask 去掉 i。前缀耗时不小于 dp[prev]，最后阶段耗时不小于向上取整的等待天数。因此任何方案都不小于候选值中的最小值。反过来，执行所选前驱的最优方案，再等待并击杀 i，就能达到该候选值。故转移精确得到最优值，归纳至全集即得答案。

边界与复杂度

  • 单只怪物：gain 始终为 1，答案为它的力量值。
  • 所有力量为 1：每天击杀一只，答案为 n；每次击杀后清零，不能在同一天连杀。
  • 力量重复：仍按下标建位，不能将相同力量的怪物误合并成一只。
  • 时间 O(n · 2ⁿ)，空间 O(2ⁿ)；n = 17 时共有 131072 个状态。
  • 使用 64 位累计天数。宽松上界 n · 10⁹ ≤ 17 · 10⁹，JavaScript Number 能精确表示，但不要对天数做 32 位位运算。

替代方案与常见错误

记忆化搜索可以枚举“下一只杀谁”，令 gain 等于已击杀数加 1，复杂度相同。全排列搜索为 O(n · n!)，可用于很小规模的思路推演。还可把怪物与击杀位置配对，费用为 ceil(power[i]/位置)，求最小费用完美匹配；匈牙利算法可达 O(n³)，但在本题规模下实现更复杂。

按力量升序并不总最优：[1,2,4,9] 升序耗时 1+1+2+3=7，顺序 [1,2,9,4] 只需 1+1+3+1=6。向上取整使简单排序交换论证失效。

  • 误用向下取整：力量 4、gain 3 时需要 2 天。
  • 前向转移要用 popcount(mask)+1；这里的逆向转移要用 popcount(mask)，不要混用。
  • 击杀后是彻底清零，不是减去力量；击杀也不额外加一天。
  • 不能仅按已击杀数量建状态，剩余怪物的力量决定后续成本。

面试追问

如何恢复顺序？每次更新最优值时记录最后击杀的下标，从全集沿前驱回溯并反转。
若 gain 增量取决于怪物种类？如果 gain 可由集合唯一确定，还可使用集合 DP，但须重新计算 gain。
若击杀后保留多余魔法？同一集合可能具有不同剩余魔法，当前状态不再充分，需要重新设计状态与支配关系。

四语言完整代码

统一采用前驱集合递推；对应 minimumTime 接口。以下代码未编译、未运行。

Java

import java.util.Arrays;

class Solution {
    public long minimumTime(int[] power) {
        int size = 1 << power.length;
        long[] dp = new long[size];
        Arrays.fill(dp, Long.MAX_VALUE / 2);
        dp[0] = 0;
        for (int mask = 1; mask < size; mask++) {
            int gain = Integer.bitCount(mask);
            for (int i = 0; i < power.length; i++) {
                if ((mask & (1 << i)) == 0) continue;
                int prev = mask ^ (1 << i);
                long days = (power[i] + (long) gain - 1) / gain;
                dp[mask] = Math.min(dp[mask], dp[prev] + days);
            }
        }
        return dp[size - 1];
    }
}

/**
 * @param {number[]} power
 * @return {number}

var minimumTime = function(power) {
    const size = 1 << power.length;
    const dp = Array(size).fill(Infinity);
    dp[0] = 0;
    for (let mask = 1; mask < size; mask++) {
        let gain = 0;
        for (let bits = mask; bits; bits &= bits - 1) gain++;
        for (let i = 0; i < power.length; i++) {
            if ((mask & (1 << i)) === 0) continue;
            const prev = mask ^ (1 << i);
            const days = Math.floor((power[i] + gain - 1) / gain);
            dp[mask] = Math.min(dp[mask], dp[prev] + days);
        }
    }
    return dp[size - 1];
};

C++

#include <algorithm>
#include <climits>
#include <vector>
using namespace std;

class Solution {
public:
    long long minimumTime(vector<int>& power) {
        int n = power.size(), size = 1 << n;
        vector<long long> dp(size, LLONG_MAX / 2);
        dp[0] = 0;
        for (int mask = 1; mask < size; ++mask) {
            int gain = __builtin_popcount((unsigned) mask);
            for (int i = 0; i < n; ++i) {
                if (!(mask & (1 << i))) continue;
                int prev = mask ^ (1 << i);
                long long days = (power[i] + 1LL * gain - 1) / gain;
                dp[mask] = min(dp[mask], dp[prev] + days);
            }
        }
        return dp.back();
    }
};
