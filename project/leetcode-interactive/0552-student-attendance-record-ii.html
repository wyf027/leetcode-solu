学生出勤记录 II
Student Attendance Record II

六个小状态，统计海量合法字符串。先亲手推进状态机，再决定是否揭开完整题解。

题目

长度为 n 的出勤记录仅由 A（缺勤）、L（迟到）、P（到场）组成。统计同时满足以下条件的记录数量：

  • 整个记录中的 A 少于 2 个；
  • 任何位置都不出现连续 3 个或更多 L。

答案对 10⁹ + 7 取模。函数形式：checkRecord(n: integer) → integer。

长度1 ≤ n ≤ 10⁵
字符集A · L · P
取模1,000,000,007

官方示例

输入： n = 2
输出： 8
解释： PP、AP、PA、LP、PL、AL、LA、LL 合法；AA 因有两次缺勤而不合法。
输入： n = 1
输出： 3
输入： n = 10101
输出： 183236316

题解：压缩状态动态规划

核心洞察

决定下一个字符是否合法，只需要知道两件事：已经使用了几个 A（0 或 1），以及当前末尾连续有几个 L（0、1 或 2）。因此全部历史可压缩为 2 × 3 个状态。

状态定义
dp[a][l]：当前长度下，使用了 a 个 A、并以连续 l 个 L 结尾的合法记录数。

完整过程

  1. 初始化：长度为 0 的空串计为一种，故 dp[0][0] = 1。
  2. 追加 P：不会改变 A 的数量，并把末尾 L 清零：next[a][0] += dp[a][l]。
  3. 追加 A：仅允许原状态没有 A；追加后进入 next[1][0]。
  4. 追加 L：仅当 l < 2；进入 next[a][l+1]。
  5. 重复 n 轮，每次取模；最后求六个状态之和。

正确性证明

不变式：完成第 i 轮后，每个 dp[a][l] 恰好计数长度 i、含 a 个 A、末尾连续 l 个 L 的所有合法记录。

初始空串满足不变式。任一合法记录的末字符必为 P、A 或 L：删除它会唯一落入对应前驱状态；三条转移分别覆盖这些情况且均保持限制。反之，每条转移都只从合法前缀追加允许字符，不会产生第二个 A 或第三个连续 L。各记录按末字符与新状态唯一归类，既无遗漏也无重复。归纳可得 n 轮后六格之和就是答案。

边界与复杂度

  • n = 1 时得到 P、A、L 共 3 种。
  • 每步写入新数组，避免同轮更新污染；所有加法及时取模。
  • 时间复杂度 O(n)，额外空间 O(1)。

替代方案

也可只计算“不含 A 且不出现 LLL”的三状态序列，再枚举 A 的插入位置；或者构造 6×6 转移矩阵，用快速幂做到 O(log n)。本题 n ≤ 10⁵，六状态线性 DP 更短、更清晰。

面试追问

  • 若 n 扩展到 10¹⁸，如何写矩阵快速幂？
  • 若最多允许 k 次 A、最多连续 m 次 L，状态与复杂度如何变化？
  • 如何用滚动数组证明空间是常数？

常见错误

  • 把“少于两次 A”误写成允许两个 A。
  • 只统计 L 的总数，而不是末尾连续 L 数。
  • 原地更新六状态，导致本轮新值再次参与转移。
  • 只在最终取模，中间整数溢出。

四语言完整实现

Java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int checkRecord(int n) {
        long[][] dp = new long[2][3];
        dp[0][0] = 1;
        for (int day = 0; day < n; day++) {
            long[][] next = new long[2][3];
            for (int a = 0; a < 2; a++) {
                for (int l = 0; l < 3; l++) {
                    long ways = dp[a][l];
                    next[a][0] = (next[a][0] + ways) % MOD; // P
                    if (a == 0) next[1][0] = (next[1][0] + ways) % MOD; // A
                    if (l < 2) next[a][l + 1] = (next[a][l + 1] + ways) % MOD; // L
                }
            }
            dp = next;
        }
        long answer = 0;
        for (long[] row : dp) for (long ways : row) answer = (answer + ways) % MOD;
        return (int) answer;
    }
}

var checkRecord = function(n) {
    const MOD = 1_000_000_007;
    let dp = [[1, 0, 0], [0, 0, 0]];
    for (let day = 0; day < n; day++) {
        const next = [[0, 0, 0], [0, 0, 0]];
        for (let a = 0; a < 2; a++) {
            for (let l = 0; l < 3; l++) {
                const ways = dp[a][l];
                next[a][0] = (next[a][0] + ways) % MOD;
                if (a === 0) next[1][0] = (next[1][0] + ways) % MOD;
                if (l < 2) next[a][l + 1] = (next[a][l + 1] + ways) % MOD;
            }
        }
        dp = next;
    }
    return dp.flat().reduce((sum, ways) => (sum + ways) % MOD, 0);

class Solution:
    def checkRecord(self, n: int) -> int:
        mod = 1_000_000_007
        dp = [[1, 0, 0], [0, 0, 0]]
        for _ in range(n):
            nxt = [[0, 0, 0], [0, 0, 0]]
            for a in range(2):
                for l in range(3):
                    ways = dp[a][l]
                    nxt[a][0] = (nxt[a][0] + ways) % mod
                    if a == 0:
                        nxt[1][0] = (nxt[1][0] + ways) % mod
                    if l < 2:
                        nxt[a][l + 1] = (nxt[a][l + 1] + ways) % mod
            dp = nxt
        return sum(map(sum, dp)) % mod
C++
class Solution {
public:
    int checkRecord(int n) {
        const long long MOD = 1'000'000'007;
        long long dp[2][3] = {{1, 0, 0}, {0, 0, 0}};
        for (int day = 0; day < n; ++day) {
            long long next[2][3] = {};
            for (int a = 0; a < 2; ++a) {
                for (int l = 0; l < 3; ++l) {
                    long long ways = dp[a][l];
                    next[a][0] = (next[a][0] + ways) % MOD;
                    if (a == 0) next[1][0] = (next[1][0] + ways) % MOD;
                    if (l < 2) next[a][l + 1] = (next[a][l + 1] + ways) % MOD;
                }
            }
            for (int a = 0; a < 2; ++a)
                for (int l = 0; l < 3; ++l) dp[a][l] = next[a][l];
        }
        long long answer = 0;
        for (auto &row : dp) for (long long ways : row) answer = (answer + ways) % MOD;
        return static_cast<int>(answer);
    }
};
