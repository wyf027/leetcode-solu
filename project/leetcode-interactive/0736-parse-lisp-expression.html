Lisp 语法解析

读懂一段只有 let、add、mult 的迷你 Lisp，在嵌套括号与同名变量之间，算出唯一的整数结果。

01 / Problem

题意与语法

给定字符串 expression，它表示一个合法的类 Lisp 表达式。表达式最终只会得到一个整数；你需要返回这个值。

五种表达式

  • integer正整数、负整数或 0，直接取其数值。
  • variable从当前最内层作用域开始向外查找最近的同名绑定。
  • add(add e1 e2)，计算两个子表达式并相加。
  • mult(mult e1 e2)，计算两个子表达式并相乘。
  • let(let v1 e1 ... vn en expr)，从左到右依次绑定变量，最后一个表达式就是返回值。

函数参数

输入：一个合法表达式字符串。

evaluate(expression: string) → integer

作用域规则：括号更深的绑定优先；离开对应的 let 后，该层绑定失效。

变量规则：变量名以小写字母开头，后接零个或多个小写字母或数字；add、let、mult 是保留字。

官方示例

Example 01 · Shadowing 
输入：expression = "(let x 2 (mult x (let x 3 y 4 (add x y))))"
输出：14
解释：内层 add 读取到内层 x = 3 与 y = 4，得到 7；外层 x 仍为 2，所以 2 × 7 = 14。
Example 02 · Sequential 
输入：expression = "(let x 3 x 2 x)"
输出：2
解释：let 中的赋值按顺序执行，后一次 x = 2 覆盖当前作用域内先前可见的值。
Example 03 · Rebind 
输入：expression = "(let x 1 y 2 x (add x y) (add x y))"
输出：5
解释：先把 x + y = 3 重新绑定给 x，最终再计算 3 + 2 = 5。

约束

  • 1 <= expression.length <= 2000
  • expression 没有前导或尾随空格。
  • 各 token 之间由一个空格分隔。
  • 答案及全部中间结果均在 32 位整数范围内。
  • 表达式保证合法，并且最终能计算为整数。

读题检查点

同一层 let 的绑定不是同时发生，而是从左到右；后面的表达式可以引用刚刚完成的绑定。最终项既可能是变量，也可能是数字或另一个括号表达式。

04 / Full solution

递归下降 + 变量值栈

用一个全局游标从左到右只扫描一次。每遇到子表达式就递归求值；哈希表为每个变量维护一摞可见值，进入绑定时压栈，离开当前 let 时弹栈。

核心洞察

难点不是四则运算，而是确定 token 边界和恢复词法作用域。共享游标让每个字符只被消费一次；变量值栈让“最内层绑定优先”自然等价于读取栈顶。

状态设计

i 指向下一个待解析字符；env[name] 保存该变量从外到内的所有当前有效值。每个 let 还记录自己添加过哪些变量，以便退出时准确回滚。

完整过程

  1. 若当前位置不是左括号，就读到空格或右括号：以数字开头（含负号）则转成整数，否则读取变量栈顶。
  2. 若当前位置是左括号，跳过它并读取操作符 add、mult 或 let。
  3. 对 add/mult 递归求两个参数，完成运算，再消费右括号。
  4. 对 let，依次读取变量名。若变量名后面紧接右括号，说明它本身是最终表达式；否则递归计算右侧表达式并把值压入该变量的栈。
  5. let 的最终项如果以左括号、数字或负号开头，可直接递归求值。得到答案后，逆序弹出本层增加的全部绑定，再返回。

正确性说明

归纳基础：整数 token 被直接转换为其值；变量 token 读取当前值栈顶，恰好是最内层仍有效的绑定。

归纳步骤：假设所有更短的子表达式都能正确求值，则 add 和 mult 对两个正确子结果执行定义中的运算，结果正确。对于 let，绑定严格按从左到右的顺序压栈，因此每个后续表达式看到的环境与语义一致；最终项求值后弹出本层绑定，外层环境被完整恢复。

结论：按表达式结构归纳，算法对任意合法输入都返回定义要求的整数。

复杂度

时间：O(n)（哈希表操作按均摊 O(1) 计）。共享游标使每个字符只被读取常数次。

空间：O(n)。递归深度、有效绑定和值栈在最坏情况下都与表达式长度同阶。

边界情况

  • 负数与 0。
  • 最终项只是一个变量。
  • 同一 let 多次绑定同名变量。
  • 内层遮蔽后必须恢复外层值。
  • 接近 2000 字符的深层嵌套。

替代方案

可以先按括号平衡切分当前层 token，再递归传递复制后的环境，写法直观但复制哈希表可能达到 O(n²)。也可以先构建 AST，再单独求值，结构更适合扩展语法，但本题会增加额外节点与第二次遍历。

常见错误

  • 把 let 绑定当成同时赋值。
  • 误把最终变量名当成下一组绑定。
  • 退出内层作用域时没有恢复同名外层变量。
  • 用空格直接切整个字符串，破坏嵌套表达式。
  • 子调用返回后漏消费右括号或多消费空格。

import java.util.*;

class Solution {
    private String s;
    private int i;
    private Map<String, Deque<Integer>> env;

    public int evaluate(String expression) {
        s = expression;
        i = 0;
        env = new HashMap<>();
        return eval();
    }

    private int eval() {
        if (s.charAt(i) != '(') {
            String token = readToken();
            if (token.charAt(0) == '-' || Character.isDigit(token.charAt(0))) {
                return Integer.parseInt(token);
            }
            return env.get(token).peek();
        }

        i++; // '('
        String op = readToken();
        if (op.equals("add") || op.equals("mult")) {
            skipSpace();
            int left = eval();
            skipSpace();
            int right = eval();
            i++; // ')'
            return op.equals("add") ? left + right : left * right;
        }

        List<String> added = new ArrayList<>();
        int result;
        while (true) {
            skipSpace();
            char c = s.charAt(i);
            if (c == '(' || c == '-' || Character.isDigit(c)) {
                result = eval();
                break;
            }

            String name = readToken();
            skipSpace();
            if (s.charAt(i) == ')') {
                result = env.get(name).peek();
                break;
            }

            int value = eval();
            env.computeIfAbsent(name, key -> new ArrayDeque<>()).push(value);
            added.add(name);
        }

        for (int k = added.size() - 1; k >= 0; k--) {
            env.get(added.get(k)).pop();
        }
        i++; // ')'
        return result;
    }

    private String readToken() {
        int start = i;
        while (i < s.length() && s.charAt(i) != ' ' && s.charAt(i) != ')') {
            i++;
        }
        return s.substring(start, i);
    }

    private void skipSpace() {
        if (i < s.length() && s.charAt(i) == ' ') i++;
    }
}

/**
 * @param {string} expression
 * @return {number}
 */
var evaluate = function(expression) {
    let i = 0;
    const env = new Map();

    const skipSpace = () => {
        if (i < expression.length && expression[i] === ' ') i++;
    };

    const readToken = () => {
        const start = i;
        while (
            i < expression.length &&
            expression[i] !== ' ' &&
            expression[i] !== ')'
        ) {
            i++;
        }
        return expression.slice(start, i);
    };

    const evalExpr = () => {
        if (expression[i] !== '(') {
            const token = readToken();
            if (token[0] === '-' || /\d/.test(token[0])) return Number(token);
            const values = env.get(token);
            return values[values.length - 1];
        }

        i++; // '('
        const op = readToken();
        if (op === 'add' || op === 'mult') {
            skipSpace();
            const left = evalExpr();
            skipSpace();
            const right = evalExpr();
            i++; // ')'
            return op === 'add' ? left + right : left * right;
        }

        const added = [];
        let result = 0;
        while (true) {
            skipSpace();
            const c = expression[i];
            if (c === '(' || c === '-' || /\d/.test(c)) {
                result = evalExpr();
                break;
            }

            const name = readToken();
            skipSpace();
            if (expression[i] === ')') {
                const values = env.get(name);
                result = values[values.length - 1];
                break;
            }

            const value = evalExpr();
            if (!env.has(name)) env.set(name, []);
            env.get(name).push(value);
            added.push(name);
        }

        for (let k = added.length - 1; k >= 0; k--) {
            env.get(added[k]).pop();
        }
        i++; // ')'
        return result;
    };

    return evalExpr();
};

from collections import defaultdict


class Solution:
    def evaluate(self, expression: str) -> int:
        self.s = expression
        self.i = 0
        self.env = defaultdict(list)
        return self._eval()

    def _eval(self) -> int:
        if self.s[self.i] != '(':
            token = self._read_token()
            if token[0] == '-' or token[0].isdigit():
                return int(token)
            return self.env[token][-1]

        self.i += 1  # '('
        op = self._read_token()
        if op == 'add' or op == 'mult':
            self._skip_space()
            left = self._eval()
            self._skip_space()
            right = self._eval()
            self.i += 1  # ')'
            return left + right if op == 'add' else left * right

        added = []
        while True:
            self._skip_space()
            c = self.s[self.i]
            if c == '(' or c == '-' or c.isdigit():
                result = self._eval()
                break

            name = self._read_token()
            self._skip_space()
            if self.s[self.i] == ')':
                result = self.env[name][-1]
                break

            value = self._eval()
            self.env[name].append(value)
            added.append(name)

        for name in reversed(added):
            self.env[name].pop()
        self.i += 1  # ')'
        return result

    def _read_token(self) -> str:
        start = self.i
        while self.i < len(self.s) and self.s[self.i] not in ' )':
            self.i += 1
        return self.s[start:self.i]

    def _skip_space(self) -> None:
        if self.i < len(self.s) and self.s[self.i] == ' ':
            self.i += 1

class Solution {
    string s;
    int i = 0;
    unordered_map<string, vector<int>> env;

    void skipSpace() {
        if (i < (int)s.size() && s[i] == ' ') ++i;
    }

    string readToken() {
        int start = i;
        while (i < (int)s.size() && s[i] != ' ' && s[i] != ')') ++i;
        return s.substr(start, i - start);
    }

    int eval() {
        if (s[i] != '(') {
            string token = readToken();
            if (token[0] == '-' || isdigit(token[0])) return stoi(token);
            return env[token].back();
        }

        ++i; // '('
        string op = readToken();
        if (op == "add" || op == "mult") {
            skipSpace();
            int left = eval();
            skipSpace();
            int right = eval();
            ++i; // ')'
            return op == "add" ? left + right : left * right;
        }

        vector<string> added;
        int result = 0;
        while (true) {
            skipSpace();
            char c = s[i];
            if (c == '(' || c == '-' || isdigit(c)) {
                result = eval();
                break;
            }

            string name = readToken();
            skipSpace();
            if (s[i] == ')') {
                result = env[name].back();
                break;
            }

            int value = eval();
            env[name].push_back(value);
            added.push_back(name);
        }

        for (auto it = added.rbegin(); it != added.rend(); ++it) {
            env[*it].pop_back();
        }
        ++i; // ')'
        return result;
    }

public:
    int evaluate(string expression) {
        s = move(expression);
        i = 0;
        env.clear();
        return eval();
    }
};

面试追问

如果新增减法、除法或可变参数函数，怎么扩展？

把操作符分派抽成独立层；解析器继续负责读取表达式边界，运算层根据操作符决定参数个数与聚合规则。可变参数需要读到当前表达式的配对右括号为止。

为什么不为每次递归复制整个环境？

复制更直观，但深层嵌套时会重复搬运大量无变化的绑定。按变量维护值栈只记录增量，进入和退出作用域都接近常数操作。

如何避免极深输入导致调用栈溢出？

可将递归下降改写为显式栈：栈帧记录操作符、已解析参数、当前 let 的新增绑定与解析阶段。空间阶不变，但不再依赖语言运行时调用栈。

如果输入不保证合法，需要补什么？

增加 token 类型、括号匹配、操作符参数数量、未绑定变量、非法变量名、整数溢出和多余尾部字符检查，并返回包含位置的结构化错误。
