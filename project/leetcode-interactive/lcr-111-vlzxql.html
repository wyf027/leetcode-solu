LCR 111中等 MEDIUM图 · DFS / BFS

除法求值

已知若干除法等式，回答查询的商。把变量看作图中的节点，把比值看作带权有向边。

交互演示

题意、示例与约束

equations：[["a","b"],["b","c"]]

values：[2.0, 3.0]

queries：[["a","c"],["b","a"],["a","e"]]

输出：[6.0, 0.5, -1.0]

  • 每个方程 A / B = k 同时提供 A→B 权重 k 与 B→A 权重 1/k。
  • 查询变量不存在或两点不连通时返回 -1.0。
  • 保证输入方程无矛盾，变量名由小写字母组成。

分步交互：查询 a / c

沿路径累乘边权：a → b 的权重为 2，b → c 的权重为 3。

核心洞察

每个等式都是双向带权边。要求 x / y，就是在图里找从 x 到 y 的任一路径，并把路径权重相乘。DFS 或 BFS 都可；搜索时的 visited 集合避免在双向边之间循环。

完整过程

  1. 1. 建图
    为每个等式加入两条倒数边。
  2. 2. 预检
    变量不存在，直接 -1。
  3. 3. 搜索
    队列保存节点和累计乘积。
  4. 4. 返回
    抵达终点即得到答案。

边界与复杂度

  • 同一变量查询 x/x：变量存在时为 1.0，否则 -1.0。
  • 图不连通：遍历完仍未抵达，返回 -1.0。
  • 单次查询时间 O(V+E)，建图空间 O(V+E)。

替代方案、追问与常见错误

替代：查询很多时，可用 Floyd-Warshall 预处理任意两点比值；动态加入等式可考虑带权并查集。
追问：如何检测矛盾方程？如何支持在线更新？
常见错误：漏加反向边；累计值用加法而非乘法；不记录 visited 导致图中循环；变量不存在时误返回 1。

// Java
class Solution {
  public double[] calcEquation(List<List<String>> eq, double[] v, List<List<String>> q) {
    Map<String, List<Pair<String, Double>>> g = new HashMap<>();
    for (int i=0;i<eq.size();i++) { String a=eq.get(i).get(0),b=eq.get(i).get(1); g.computeIfAbsent(a,k->new ArrayList<>()).add(new Pair<>(b,v[i])); g.computeIfAbsent(b,k->new ArrayList<>()).add(new Pair<>(a,1/v[i])); }
    double[] ans=new double[q.size()];
    for(int i=0;i<q.size();i++) ans[i]=search(g,q.get(i).get(0),q.get(i).get(1));
    return ans;
  }
  double search(Map<String,List<Pair<String,Double>>> g,String s,String t){ if(!g.containsKey(s)||!g.containsKey(t))return -1; Queue<Pair<String,Double>> qu=new LinkedList<>(); Set<String> seen=new HashSet<>(); qu.offer(new Pair<>(s,1.0)); seen.add(s); while(!qu.isEmpty()){Pair<String,Double> p=qu.poll(); if(p.getKey().equals(t))return p.getValue(); for(Pair<String,Double> e:g.get(p.getKey()))if(seen.add(e.getKey()))qu.offer(new Pair<>(e.getKey(),p.getValue()*e.getValue()));} return -1; }
}
// JavaScript
var calcEquation = function(equations, values, queries) {
  const g = new Map();
  const add = (a,b,w) => { if(!g.has(a)) g.set(a,[]); g.get(a).push([b,w]); };
  equations.forEach(([a,b],i) => { add(a,b,values[i]); add(b,a,1/values[i]); });
  const solve = (s,t) => { if(!g.has(s)||!g.has(t)) return -1; const q=[[s,1]],seen=new Set([s]); for(let h=0;h<q.length;h++){const [x,w]=q[h];if(x===t)return w;for(const [y,k] of g.get(x))if(!seen.has(y)){seen.add(y);q.push([y,w*k]);}}return -1; };
  return queries.map(([s,t]) => solve(s,t));
};
# Python
class Solution:
    def calcEquation(self, equations, values, queries):
        graph = {}
        for (a, b), value in zip(equations, values):
            graph.setdefault(a, []).append((b, value))
            graph.setdefault(b, []).append((a, 1 / value))
        def solve(s, t):
            if s not in graph or t not in graph: return -1.0
            queue, seen = [(s, 1.0)], {s}
            for node, product in queue:
                if node == t: return product
                for nxt, weight in graph[node]:
                    if nxt not in seen:
                        seen.add(nxt); queue.append((nxt, product * weight))
            return -1.0
        return [solve(s, t) for s, t in queries]
