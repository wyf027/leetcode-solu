Core insight

两次反转，抵消词内翻转

翻面与校正

先反转整个字符数组，单词顺序已经逆序，但每个单词也倒了；再逐段反转每个单词，恢复词内顺序。

完整过程

  1. 用左右指针原地反转区间 [0, n - 1]。
  2. 令 start = 0，向右扫描空格或数组末尾。
  3. 每遇到边界，原地反转 [start, end - 1]。
  4. 将 start 移到下一个单词开头，继续扫描。

例如 the␠sky 整体反转为 yks␠eht，逐词修正后成为 sky␠the。

边界与正确性

  • 单个字符或单个单词：两次反转恢复原状。
  • 最后一个单词没有尾随空格，循环必须允许 end == n。
  • 题目保证单空格分隔，因此不会出现空单词。
  • 每次交换都发生在原数组，额外空间只使用常数个下标。

复杂度与替代方案

O(n) 时间，O(1) 额外空间。

也可先逐词反转再整体反转，证明完全对称。使用 split / reverse / join 更直观，但需要 O(n) 额外空间，不满足本题原地约束。

Java · LeetCode 可提交

Java 17
class Solution {
    public void reverseWords(char[] s) {
        reverse(s, 0, s.length - 1);

        int start = 0;
        for (int end = 0; end <= s.length; end++) {
            if (end == s.length || s[end] == ' ') {
                reverse(s, start, end - 1);
                start = end + 1;
            }
        }
    }

    private void reverse(char[] s, int left, int right) {
        while (left < right) {
            char temporary = s[left];
            s[left++] = s[right];
            s[right--] = temporary;
        }
    }
}

JavaScript · LeetCode 可提交

JavaScript
var reverseWords = function (s) {
    const reverse = (left, right) => {
        while (left < right) {
            [s[left], s[right]] = [s[right], s[left]];
            left++;
            right--;
        }
    };

    reverse(0, s.length - 1);
    let start = 0;

    for (let end = 0; end <= s.length; end++) {
        if (end === s.length || s[end] === " ") {
            reverse(start, end - 1);
            start = end + 1;
        }
    }
};

class Solution:
    def reverseWords(self, s: List[str]) -> None:
        def reverse(left: int, right: int) -> None:
            while left < right:
                s[left], s[right] = s[right], s[left]
                left += 1
                right -= 1

        reverse(0, len(s) - 1)
        start = 0

        for end in range(len(s) + 1):
            if end == len(s) or s[end] == " ":
                reverse(start, end - 1)
                start = end + 1

C++ · LeetCode 可提交

C++17
class Solution {
public:
    void reverseWords(vector<char>& s) {
        reverseRange(s, 0, static_cast<int>(s.size()) - 1);

        int start = 0;
        for (int end = 0; end <= static_cast<int>(s.size()); ++end) {
            if (end == static_cast<int>(s.size()) || s[end] == ' ') {
                reverseRange(s, start, end - 1);
                start = end + 1;
            }
        }
    }

private:
    void reverseRange(vector<char>& s, int left, int right) {
        while (left < right) {
            swap(s[left++], s[right--]);
        }
    }
};

面试追问

  • 为什么两次反转不会破坏空格位置数量？
  • 如果允许连续空格，扫描边界应如何调整？
  • 如果输入是不可变字符串，空间复杂度还能否为 O(1)？

常见错误

  • 只反转整个数组，导致每个单词也倒序。
  • 循环只检查空格，漏掉最后一个单词。
  • 用 split/join 却声称额外空间 O(1)。
  • 把字符数组替换成新数组，没有原地修改参数。
