求和路径沿着树向下数

路径可以从任意节点开始，也可以在任意节点结束；唯一不变的是方向——从父节点一路向下。让每一次深入与返回都看得见。

二叉树 向下路径 正负节点值
PATH OBSERVATORY · TARGET 22

Problem

题意

给定一棵节点值可能为正、负或零的二叉树，以及目标和 sum。统计树中节点值之和恰好等于 sum 的路径数量。

  • 路径可以在任意节点开始，也可以在任意节点结束。
  • 路径必须连续，并且只能从父节点走向子节点。
  • 不同起点或终点形成的路径分别计数。
  • 节点总数不超过 10000。

Official example

root = [5,4,8,11,null,13,4,7,2,null,null,5,1]
sum = 22

输出 = 3

三条路径：
[5,4,11,2]
[5,8,4,5]
[4,11,7]

数组采用层序表示；null 表示该位置没有子节点。

    Core insight

    当前前缀 − 目标 = 合法起点之前的前缀

    沿当前根到节点的路线累加得到 running。如果某个更早的前缀和等于 running - sum，从那个前缀之后到当前节点的连续向下路径之和就恰好为目标。 哈希表记录当前递归路线中每种前缀出现的次数，因此一次查询就能加入所有有效起点。

    为什么先放入 0 → 1？

    它代表根节点之前的虚拟前缀。当前前缀本身等于目标时，路径可以直接从根开始并被计数。

    为什么离开节点必须撤销？

    哈希表只应描述当前祖先链。回到父节点时减掉当前前缀，避免把左子树的前缀错误地带进右子树。

    Full process

    完整过程

    1. 初始化账本 prefix[0] = 1。
    2. 深度优先进入节点，把节点值加入 running。
    3. 查询 prefix[running - sum]，把出现次数加入答案。
    4. 把当前 running 写入账本，再遍历左右子树。
    5. 离开节点时将当前前缀计数减一，完成回溯。

    5 → 4 → 11 → 2 22 0 1
    5 → 4 → 11 → 7 27 5 1
    5 → 8 → 4 → 5 22 0 1

    Edges & trade-offs

    边界、复杂度与替代方案

    边界情况

    • 空树直接返回 0。
    • 节点值可为负数，不能用滑动窗口。
    • 目标为 0 时，零值与正负抵消路径都要计数。
    • 使用更宽的前缀和类型，避免累加溢出。

    复杂度

    每个节点进入和离开各一次，时间 O(n)。账本与递归栈都只保存当前路径，空间 O(h)；最坏退化树为 O(n)。

    替代方案

    以每个节点为起点再向下搜索，逻辑直观，但平衡树约 O(n log n)，链状树最坏 O(n²)。面试时可先写作基线，再优化到前缀和。

    常见错误

    • 只统计从根开始的路径。
    • 先把当前前缀入表，再查询，导致目标为 0 时自我匹配。
    • 回溯时没有减计数，跨分支产生伪路径。
    • 把“向下连续路径”误解为必须到叶子。

    Interview follow-ups

    面试追问

    • 如果要返回路径内容？ 维护当前节点数组，并让账本保存前缀对应的深度列表；命中时切片得到路径。
    • 如果树可能极深？ 用显式栈模拟进入与退出事件，避免语言递归深度限制。
    • 如果允许路径向上再向下？ 当前前缀法不再直接适用，需要围绕公共祖先、树上路径或点分治重新建模。
    • 为什么不能双指针？ 节点值含负数，窗口和不具有单调性。

    class Solution {
    public int pathSum(TreeNode root, int sum) {
        Map<Long, Integer> prefix = new HashMap<>();
        prefix.put(0L, 1);
        return dfs(root, 0L, sum, prefix);
    }

    private int dfs(
        TreeNode node,
        long running,
        int target,
        Map<Long, Integer> prefix
    ) {
        if (node == null) {
            return 0;
        }

        running += node.val;
        int count = prefix.getOrDefault(running - target, 0);
        prefix.put(running, prefix.getOrDefault(running, 0) + 1);

        count += dfs(node.left, running, target, prefix);
        count += dfs(node.right, running, target, prefix);

        prefix.put(running, prefix.get(running) - 1);
        return count;
    }
}

public:
    int pathSum(TreeNode* root, int sum) {
        unordered_map<long long, int> prefix;
        prefix[0] = 1;

private:
    int dfs(
        TreeNode* node,
        long long running,
        int target,
        unordered_map<long long, int>& prefix
    ) {
        if (node == nullptr) return 0;

        running += node->val;
        int count = prefix[running - target];
        ++prefix[running];

        count += dfs(node->left, running, target, prefix);
        count += dfs(node->right, running, target, prefix);

        --prefix[running];
        return count;
    }
};
