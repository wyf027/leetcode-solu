强密码检验器 II

Strong Password Checker II

六项条件，缺一不可。先读规则，做出你的判断，再逐步观察每一个字符。

01 / 题目与规则

给定字符串 password，当它同时满足下面全部条件时返回 true，否则返回 false。

① 长度至少为 8。

② 至少有一个小写英文字母 a–z。

③ 至少有一个大写英文字母 A–Z。

④ 至少有一个数字 0–9。

⑤ 至少有一个特殊字符 !@#$%^&*()-+。

⑥ 不能有两个相邻且相同的字符。

aab 违反相邻规则，aba 不违反这一条。

约束：1 ≤ password.length ≤ 100，仅包含英文字母、数字和 !@#$%^&*()-+ 中的字符。

接口：strongPasswordCheckerII(password: string) → boolean

05 / 独立题解

准备好后，展开思路与四语言代码。

核心洞察：记录“出现过”，无需统计次数

四类字符分别用一个布尔标记；相邻重复只需比较当前字符与前一个字符。长度单独判断，最终四个标记必须全为真。

完整过程

  1. 长度小于 8 时立即返回 false。
  2. 初始化 lower、upper、digit、special 四个标记为 false。
  3. 从左至右扫描；当 i > 0 且 password[i] 等于 password[i−1] 时返回 false。
  4. 根据字符类别将对应标记置为 true，保留已经出现的类别。
  5. 扫描结束后返回四个标记的逻辑与。

示例 1 中，下标 0 的 I 点亮大写，下标 1 的 l 点亮小写，下标 7 的 3 点亮数字，下标 12 的 ! 点亮特殊字符；长度为 13，且没有相邻重复，因此返回 true。

正确性

循环不变量：处理完前 i 个字符后，每个标记恰好表示该前缀是否包含对应类别；若尚未返回，则前缀中没有相邻重复。空前缀时所有标记为 false，不变量成立。加入一个字符时，更新其类别，并比较唯一新增的相邻字符对，因此不变量保持。遍历结束后，标记与相邻检查覆盖整个字符串，再结合预先完成的长度检查，返回 true 当且仅当六项要求全部成立。所有提前返回都对应一项必要条件被违反。

边界与复杂度

  • 长度 7 一定失败；恰好 8 仍要检查其他条件。
  • 首字符没有前驱，必须先判断 i > 0。
  • 同一字符可以非相邻重复，不能用全局去重代替相邻比较。
  • 四类字符齐全后仍需扫描末尾，后面可能发生相邻重复。
  • 输入保证为限定 ASCII 字符，范围比较符合题意。

时间 O(n)，额外空间 O(1)。每个字符只处理一次，特殊字符集合固定为 12 个，查找成本为常数。C++ 的官方按值参数属于输入接口；算法工作变量为常数空间。可视化为了回退而重新计算前缀，不代表提交代码的执行开销。

Java

class Solution {
    public boolean strongPasswordCheckerII(String password) {
        if (password.length() < 8) return false;
        boolean lower = false, upper = false, digit = false, special = false;
        for (int i = 0; i < password.length(); i++) {
            char c = password.charAt(i);
            if (i > 0 && c == password.charAt(i - 1)) return false;
            if (c >= 'a' && c <= 'z') lower = true;
            else if (c >= 'A' && c <= 'Z') upper = true;
            else if (c >= '0' && c <= '9') digit = true;
            else if ("!@#$%^&*()-+".indexOf(c) >= 0) special = true;
        }
        return lower && upper && digit && special;
    }
}

C++

#include <string>
using namespace std;

class Solution {
public:
    bool strongPasswordCheckerII(string password) {
        if (password.size() < 8) return false;
        bool lower = false, upper = false, digit = false, special = false;
        const string symbols = "!@#$%^&*()-+";
        for (int i = 0; i < static_cast<int>(password.size()); ++i) {
            char c = password[i];
            if (i > 0 && c == password[i - 1]) return false;
            if (c >= 'a' && c <= 'z') lower = true;
            else if (c >= 'A' && c <= 'Z') upper = true;
            else if (c >= '0' && c <= '9') digit = true;
            else if (symbols.find(c) != string::npos) special = true;
        }
        return lower && upper && digit && special;
    }
};

替代方案

使用四位 bitmask 表示类别出现情况，最后判断是否等于 15，时间与空间复杂度相同。也可以分别搜索四类字符，再检查相邻对：固定次数遍历仍为 O(n)。组合正则较紧凑，但特殊字符集合中的减号等更容易转义错误。

面试追问

  • 流式输入？保留长度、前一个字符、四个标记及重复标记，结束时汇总。
  • 每类至少 k 个？把布尔标记换成计数器。
  • 支持 Unicode？先明确“字符”是码点还是字素簇，以及类别定义；当前 ASCII 范围判断不能直接推广。
  • 返回全部失败原因？发现重复时记录而不提前返回，扫描完汇总所有未满足条件，正如演示。

常见错误

  • 四个类别用逻辑或连接，误把“全部满足”写成“任意满足”。
  • 用当前字符的类别覆盖所有标记，丢失已扫描的信息。
  • 使用集合拒绝任意重复字符，误伤非相邻重复。
  • 四类字符齐全就返回 true，漏掉后面的重复。
  • 忘记长度或漏掉最后一对相邻字符。
  • 把任意非字母数字都当作特殊字符，而没有明确题目的允许集合。
