01 / Problem

先读懂编码语言

这里只陈述问题与输入规则。算法思路被收在页面底部，不会在首屏直接泄露。

给定一个经过编码的字符串 s，返回解码后的字符串。

k[encoded_string] 表示把方括号内的 encoded_string 恰好重复 k 次，其中 k 是正整数。

输入始终有效：没有多余空格，方括号正确配对；原始文本本身不含数字，数字只用于表示重复次数。因此不会出现 3a 或 2[4] 这样的形式。测试数据保证最终输出长度不超过 105。

约束

  • 1 <= s.length <= 30
  • s 仅由小写英文字母、数字与 [ ] 组成。
  • s 保证是有效输入。
  • 所有重复次数均在 [1, 300] 内。
  • 输出长度不超过 105。
示例 1
输入：s = "3[a]2[bc]"
输出："aaabcbc"
示例 2
输入：s = "3[a2[c]]"
输出："accaccacc"
示例 3
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
示例 4
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"

04 / Solution

用栈保存“上一层现场”

每遇到一个左括号，就把当前层尚未完成的信息寄存起来；右括号出现时，再取回并合并。

核心洞察

栈帧 =（进入括号前的字符串，当前重复次数）

扫描时只维护 currentNumber 与 currentString。左括号把这两个上下文压栈并开启新层；右括号把当前层重复后，拼回上一层的前缀。

复杂度

时间：O(n + L)，其中 n 是编码串长度，L 是解码结果长度；必须至少读完输入并写出结果。

空间：O(d + L)，d 是嵌套深度，输出与构造中的片段占 O(L)。

完整过程

  1. 数字字符：累积多位数，number = number × 10 + digit。
  2. 普通字母：直接追加到当前片段。
  3. 左括号：保存“当前前缀 + 重复次数”，然后清空当前片段和数字。
  4. 右括号：弹出栈帧，用“前缀 + 当前片段重复 k 次”替换当前片段。
  5. 扫描结束后，当前片段就是完整答案。

正确性

  1. 不变式：扫描任意前缀后，currentString 是最内层未闭合括号中已经解码的内容；栈按顺序保存所有外层现场。
  2. 保持：数字和字母只更新当前层；左括号保存现场并进入新层；右括号按规则完成当前层，再准确恢复外层，所以不变式始终成立。
  3. 终止：输入合法，扫描结束时所有括号都已闭合、栈为空；按不变式，currentString 正好是整个输入的解码结果。

边界与常见错误

  • 重复次数可能有多位，不能把 12 当成两个独立数字。
  • 压栈后必须同时清空当前数字与当前片段。
  • 弹栈合并顺序是“旧前缀在前、重复片段在后”。
  • 结尾可能有不在括号内的字母，如 ...ef 或 ...xyz。
  • 不要预先展开所有组合；始终按闭括号从内到外完成。

替代方案

递归下降：把每个 [...] 看作一个子问题，递归函数读取到 ] 时返回当前层结果。代码贴近文法，但需要共享扫描下标，调用栈深度也是 O(d)。

双栈：分别维护数字栈与字符串栈。逻辑等价，但一个“成对栈帧”更能避免两个栈错位。

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String decodeString(String s) {
        Deque<Integer> counts = new ArrayDeque<>();
        Deque<StringBuilder> prefixes = new ArrayDeque<>();
        StringBuilder current = new StringBuilder();
        int number = 0;

        for (char ch : s.toCharArray()) {
            if (Character.isDigit(ch)) {
                number = number * 10 + (ch - '0');
            } else if (ch == '[') {
                counts.push(number);
                prefixes.push(current);
                number = 0;
                current = new StringBuilder();
            } else if (ch == ']') {
                int repeat = counts.pop();
                StringBuilder parent = prefixes.pop();
                for (int i = 0; i < repeat; i++) {
                    parent.append(current);
                }
                current = parent;
            } else {
                current.append(ch);
            }
        }
        return current.toString();
    }
}

var decodeString = function(s) {
    const stack = [];
    let current = "";
    let number = 0;

    for (const ch of s) {
        if (ch >= "0" && ch <= "9") {
            number = number * 10 + Number(ch);
        } else if (ch === "[") {
            stack.push([current, number]);
            current = "";
            number = 0;
        } else if (ch === "]") {
            const [prefix, repeat] = stack.pop();
            current = prefix + current.repeat(repeat);
        } else {
            current += ch;
        }
    }
    return current;
};

#include <string>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    string decodeString(string s) {
        vector<pair<string, int>> stack;
        string current;
        int number = 0;

        for (char ch : s) {
            if (ch >= '0' && ch <= '9') {
                number = number * 10 + (ch - '0');
            } else if (ch == '[') {
                stack.push_back({current, number});
                current.clear();
                number = 0;
            } else if (ch == ']') {
                auto [prefix, repeat] = stack.back();
                stack.pop_back();
                string expanded;
                expanded.reserve(current.size() * repeat);
                for (int i = 0; i < repeat; ++i) {
                    expanded += current;
                }
                current = prefix + expanded;
            } else {
                current += ch;
            }
        }
        return current;
    }
};
