创建一个恰好有 K 条路径的网格图 II

把 K 的每一位二进制权重，嵌进一个只允许向右、向下的迷你网格。

题意

给定整数 k，构造仅含 '.'（可走）和 '#'（障碍）的网格。路径从 (0, 0) 走到右下角，只能向右或向下；返回任意一个恰好有 k 条有效路径的网格。网格行、列均不超过 25；若不能构造则返回空数组。

示例 1

k = 2
输出可为 ["..#", "#..", "#.."]

在中心格分岔后，恰好有 2 条路抵达终点。

示例 2

k = 3
输出可为 ["...", "#..", "#.."]

多打开一个上侧通道，就额外加入一条路。

约束：1 ≤ k ≤ 1000。本页中 '.' 表示空闲格，'#' 表示障碍格。

输入 K，观察每个置位如何从一条竖向汇合通道贡献对应的路径数。

允许 1 到 1000。

题解（默认收起）

先尝试从 K 的二进制表示推导构造，再展开对照。

核心洞察：第 i 个 2×2 小方块把已有的前缀路径数翻倍；若 k 的第 i 位为 1，就从该层额外开一条横向走廊，让它把 2^i 条路径送进最右侧的公共竖井。各层的贡献相加，正好恢复 K。

完整过程

  1. 令 L = bitLength(k)，建立 2L × (L+3) 的全障碍网格。
  2. 在第 i 层放置对角线上的 2×2 空闲块；沿这些块到达该层出口的办法恰为 2^i。
  3. 若第 i 位是 1，从该层上格一路向右打开到竖井；所有层共用最后一列并汇入右下角。
  4. 最后一列全部打开。每个被选中的位独立贡献 2^i，所以路径总数是二进制各置位之和。

边界与复杂度

  • k=1 时只有一个模块，仍可形成唯一通路。
  • k≤1000 时 L≤10，网格最多 20×13，远小于 25×25 限制。
  • 构造时间、额外空间均为 O((log k)^2)（输出网格本身也占此量级）。

替代方案与面试追问

也可以把帕斯卡三角形的组合数当“路径面额”做贪心拼和，但要额外设计避免模块互相串路。面试中可追问：若 K 增至 10^12、或限制固定 m×n，如何选择更紧凑的基底与通道。

常见错误

  • 漏开最后一列，导致各位贡献无法汇到终点。
  • 把走廊起点开在 2×2 块的错误格，路径数量会偏一倍。
  • 将二进制位从高到低连到错误列，模块之间会产生非预期交叉路径。

import java.util.*;

class Solution {
    public List<String> createGrid(int k) {
        int l = 32 - Integer.numberOfLeadingZeros(k);
        int m = 2 * l, n = l + 3;
        char[][] g = new char[m][n];
        for (char[] row : g) Arrays.fill(row, '#');
        for (int i = 0; i < l; i++) {
            int r = 2 * i;
            g[r][i] = g[r][i + 1] = g[r + 1][i] = g[r + 1][i + 1] = '.';
            if ((k & (1 << i)) != 0)
                for (int c = i + 2; c < n; c++) g[r][c] = '.';
        }
        List<String> ans = new ArrayList<>();
        for (int r = 0; r < m; r++) { g[r][n - 1] = '.'; ans.add(new String(g[r])); }
        return ans;
    }
}
var createGrid = function(k) {
  const l = Math.floor(Math.log2(k)) + 1, m = 2 * l, n = l + 3;
  const g = Array.from({ length: m }, () => Array(n).fill('#'));
  for (let i = 0; i < l; i++) {
    const r = 2 * i;
    g[r][i] = g[r][i + 1] = g[r + 1][i] = g[r + 1][i + 1] = '.';
    if ((k & (1 << i)) !== 0) for (let c = i + 2; c < n; c++) g[r][c] = '.';
  }
  for (let r = 0; r < m; r++) g[r][n - 1] = '.';
  return g.map(row => row.join(''));
};

    def createGrid(self, k: int) -> list[str]:
        L = k.bit_length(); m, n = 2 * L, L + 3

            r = 2 * i

                g[x][y] = '.'
            if k & (1 << i):
                for c in range(i + 2, n): g[r][c] = '.'
        for r in range(m): g[r][-1] = '.'

            g[r][i] = g[r][i + 1] = g[r + 1][i] = g[r + 1][i + 1] = '.';

        }
        for (int r = 0; r < m; ++r) g[r][n - 1] = '.';
        return g;
    }
