2401. 最长优雅子数组

Longest Nice Subarray

在一段连续数字里，每两个数字都能做到「互不占用」吗？先理解条件，再展开下方实验室寻找规律。

LeetCode 官方题目 ↗

题目与输入

给定正整数数组 nums，寻找一个最长的连续子数组，使其中任意两个不同位置的元素，按位与的结果都等于 0。返回该子数组的长度。单个元素总是满足条件。

参数：nums: integer[]；返回：integer。不同位置也可能具有相同数值，仍须满足条件。

官方示例 1

输入：nums = [1,3,8,48,10]
输出：3

可选择 [3,8,48]，其中 3 & 8 = 0、3 & 48 = 0、8 & 48 = 0，没有更长的符合条件的连续片段。

官方示例 2

输入：nums = [3,1,5,11,13]
输出：1

任意长度为 1 的子数组均可选取，更长的连续片段不能满足条件。

约束

  • 1 ≤ nums.length ≤ 105
  • 1 ≤ nums[i] ≤ 109
先想一想：要求的是「每一对」都满足条件，还是把整个片段一起按位与之后为 0？它们等价吗？

题解 · 用位占用表维护窗口

核心洞察

两个数按位与为 0，等价于它们没有共同为 1 的二进制位。因此，优雅窗口中每一位最多属于一个元素。用 mask 保存窗口内所有元素的按位或，就能一次检测新数是否和窗口里的任何元素冲突。

(mask & x) !== 0 时，从左边移除元素直到冲突消失。窗口本来是优雅的，移出的元素独占它的所有 1 位，所以 mask ^= nums[left] 恰好清除这些位。随后 mask |= x 加入新元素并更新答案。

完整过程

  1. 初始化 left = 0, mask = 0, best = 0。
  2. 右端点 right 从左到右依次扫描，新元素为 x。
  3. 只要 mask & x 非零，就异或移除 nums[left] 并把左端点右移一格。
  4. 冲突消除后把 x 按位或入 mask；用 right - left + 1 更新最长长度。
  5. 遍历结束，返回 best。

示例 1 中先加入 1；3 与 1 冲突，移除 1 后加入 3。接着加入 8、48，得到长度 3 的窗口。处理 10 时先移除 3，仍与 8 冲突，再移除 8，最后得到 [48,10]，全局答案保持 3。

正确性

不变量：每次加入新元素前，当前窗口两两按位与为 0，且 mask 是其中所有元素的按位或。空窗口显然成立。删除元素只会减少占用；由于每个位至多出现一次，异或删除后 mask 仍精确表示窗口。冲突为 0 时加入 x 不会引入任何重复位，因此不变量持续成立。

最优性：当候选 x 和当前窗口冲突，任何保留该冲突元素的更长后缀也不合法，必须移除到冲突消失。以前被舍弃的左端点，其对应冲突对仍包含在更长区间里，不可能因追加元素而恢复合法。因此每个 right 得到的都是以它结尾的最长合法窗口；对所有右端点取最大值即为全局答案。

边界与复杂度

  • 单个元素返回 1；重复正整数不能同时存在于合法窗口；全部位互斥时返回数组长度。
  • 两个指针各最多移动 n 次，时间 O(n)，算法额外空间 O(1)。可视化保存历史快照，与提交算法的空间无关。
  • 数值小于 2³⁰，JavaScript 的有符号 32 位运算在本题范围内安全；超出范围需改用 BigInt 或逐位计数。
  • 正整数至少占用一个位，且仅有低 30 位可能被占用，因此合法窗口长度最多为 30。若允许任意多个 0，这个长度上界不再成立。

四语言完整实现

Java

class Solution {
    public int longestNiceSubarray(int[] nums) {
        int left = 0, mask = 0, best = 0;
        for (int right = 0; right < nums.length; right++) {
            while ((mask & nums[right]) != 0) {
                mask ^= nums[left++];
            }
            mask |= nums[right];
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}

Python 3

from typing import List

class Solution:
    def longestNiceSubarray(self, nums: List[int]) -> int:
        left = mask = best = 0
        for right, x in enumerate(nums):
            while mask & x:
                mask ^= nums[left]
                left += 1
            mask |= x
            best = max(best, right - left + 1)
        return best

};

替代方案

可以为每个二进制位维护出现次数，扩展右边界后遇到计数大于 1 就收缩窗口；时间 O(30n)，空间 O(30)，更适合扩展“每位最多出现 k 次”的条件。也可以枚举起点并逐个 OR，出现冲突立即停止；在本题正整数、30 位的约束下每个起点至多扫描约 31 个元素，时间 O(30n)、空间 O(1)。通用的两两比较枚举则远慢于此。

常见错误

  • 用整个区间的 AND 判断合法：1 & 2 & 3 = 0，但 1 和 3 冲突。
  • 只比较相邻元素：[1,2,1] 的相邻对都通过，首尾仍冲突。
  • 把收缩写成 if：一个候选可能和多个旧元素冲突，必须使用 while。
  • 在不合法窗口上用 XOR 删除：若一个位被多个元素占用，异或会错误清除共享位；先维持合法窗口，再加入候选。
  • 排序后求答案会破坏原数组的连续性；长度应为 right - left + 1。

面试追问

怎样返回子数组本身？更新 best 时同步记录起点和长度，最后切片。
允许 0 有何变化？滑动窗口逻辑仍然正确，但合法长度可以超过 30。
为什么不能直接清空整个窗口？冲突可能只在左侧少数元素，清空会丢失仍可保留的最长合法后缀。
