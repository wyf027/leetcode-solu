Maximize the Confusion of an Exam

考试的最大困扰度

最多修改 k 个答案，一段连续相同的答案能有多长？

LeetCode 官方题目 ↗

题目说明

给定判断题答案字符串 answerKey，其中每个字符为 T 或 F。一次操作可以把任意位置改为 T 或 F。最多进行 k 次操作，返回能得到的最长连续相同字符段的长度。相同字符必须相邻，且不要求用完修改次数。

参数：maxConsecutiveAnswers(answerKey, k) → integer

约束

  • n == answerKey.length
  • 1 ≤ n ≤ 5 × 10⁴
  • answerKey[i] ∈ {'T', 'F'}
  • 1 ≤ k ≤ n

官方示例

示例 1

输入：answerKey = "TTFF", k = 2
输出：4

将两个 F 改成 T，得到 TTTT，连续长度为 4。

示例 2

输入：answerKey = "TFFT", k = 1
输出：3

将第一个 T 改成 F，得到 FFFT；也可将末尾的 T 改成 F，得到 TFFF。最长连续长度均为 3。

示例 3

输入：answerKey = "TTFTTFTT", k = 1
输出：5

将第一个 F 改成 T 得到 TTTTTFTT，或将第二个 F 改成 T 得到 TTFTTTTT；都能得到长度 5。

题解 · 两次滑动窗口

核心洞察

先固定目标为 T：窗口内每个 F 都必须修改，故窗口合法当且仅当 F 的数量不超过 k。目标为 F 时完全对称。分别求出两个最大值，再取较大者。

交互 · 修改预算窗口

蓝框是当前窗口，橙框是需要修改的字符。逐步观察扩张、超预算收缩和记录答案；先扫描目标 T，再扫描目标 F。轨迹为教学演示，不代表验证结果。

下标从 0 开始。重置返回已应用输入的起点；编辑后点击“应用输入”。减少动态效果偏好下，自动播放使用更慢节奏。

完整过程

  1. 固定目标字符，初始化 left、异字符数量 bad、最优长度 best。
  2. right 向右扩张，遇到非目标字符则 bad 加一。
  3. 只要 bad > k，就移除左端字符并移动 left；被移除字符不是目标时 bad 减一。
  4. 窗口合法后，用 right − left + 1 更新 best。
  5. 对 T、F 各扫描一次，取全局最大值。

例如 TTFTTFTT、k=1，以 T 为目标：扫描至下标 4 时长度为 5；加入下标 5 的 F 后超预算，左端依次移走下标 0、1、2，直到只剩一个 F。后续仍可达到长度 5。

正确性

固定目标字符后，窗口变成该字符所需修改次数恰好等于异字符数，因此判定充要。每次收缩停止时，窗口是以当前 right 结尾的最长合法窗口：此前丢弃的起点曾导致异字符数超过 k，继续添加字符不可能使其重新合法；本轮被移除的起点也都不合法。算法枚举每个右端点并记录最长合法窗口，因而得到固定目标的最优值。任何最终连续段要么全为 T，要么全为 F，两次扫描覆盖全部可能，取最大值即为答案。

边界与复杂度

单字符返回 1；全相同返回 n；k=n 时整串可统一。虽然官方不含 k=0，代码也支持不修改的扩展情形。每次扫描中左右指针各移动至多 n 次，两次扫描仍为 O(n) 时间、O(1) 额外空间。教学轨迹会保存快照，仅用于最多 40 个字符，与提交代码的空间复杂度不同。

替代方案

也可单次维护 T、F 数量，以 min(countT, countF) ≤ k 作为合法条件，同样 O(n) 时间、O(1) 空间。另一方案是二分长度，用前缀计数判断是否存在合法定长窗口，时间 O(n log n)、空间 O(n)，但实现更长。

面试追问

  • 如何返回具体修改位置？记录最优窗口和目标，最后遍历该段收集异字符位置。
  • 扩展到多种字符？合法条件变为窗口长度减窗口内最大字符频数不超过 k。
  • 为何不用枚举修改组合？组合数量很大，而固定目标后只需统计窗口内异字符数。

常见错误

  • 只扫描目标 T，遗漏以 F 为答案的情形。
  • 超预算只用 if 收缩一次，却将仍不合法的窗口当作合法窗口记录。
  • 在恢复合法之前更新答案，或移走字符时忘记递减 bad。
  • 把连续子串误当作可跳过位置的子序列。

Java

class Solution {
    public int maxConsecutiveAnswers(String answerKey, int k) {
        int best = 0;
        for (char target : new char[]{'T', 'F'}) {
            int left = 0, bad = 0;
            for (int right = 0; right < answerKey.length(); right++) {
                if (answerKey.charAt(right) != target) bad++;
                while (bad > k) {
                    if (answerKey.charAt(left) != target) bad--;
                    left++;
                }
                best = Math.max(best, right - left + 1);
            }
        }
        return best;
    }
}

Python

class Solution:
    def maxConsecutiveAnswers(self, answerKey: str, k: int) -> int:
        best = 0
        for target in ('T', 'F'):
            left = bad = 0
            for right, char in enumerate(answerKey):
                if char != target:
                    bad += 1
                while bad > k:
                    if answerKey[left] != target:
                        bad -= 1
                    left += 1
                best = max(best, right - left + 1)
        return best

C++

#include <algorithm>
#include <string>
using namespace std;

class Solution {
public:
    int maxConsecutiveAnswers(string answerKey, int k) {
        int best = 0;
        for (char target : string("TF")) {
            int left = 0, bad = 0;
            for (int right = 0; right < (int)answerKey.size(); ++right) {
                if (answerKey[right] != target) ++bad;
                while (bad > k) {
                    if (answerKey[left] != target) --bad;
                    ++left;
                }
                best = max(best, right - left + 1);
            }
        }
        return best;
    }
};
