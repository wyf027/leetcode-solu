自定义字符串排序

Custom Sort String

Problem

题目说明

customSortString(order, s)

给定字符串 order 和 s。order 中的字符互不相同，它们定义了一种自定义先后顺序。

重新排列 s 中的字符：若字符 x 在 order 中位于字符 y 之前，那么在返回结果中，所有受该规则约束的 x 也应位于 y 之前。返回任意一个满足要求的 s 的排列。

注意：没有出现在 order 中的字符不受自定义顺序约束，可以出现在结果的任意位置；因此同一输入可能有多个正确答案。

示例 1

输入：order = "cba", s = "abcd" 输出："cbad"

c、b、a 必须按 order 的次序出现；d 不受约束，所以 dcba、cdba、cbda 等也都合法。

示例 2

输入：order = "bcafg", s = "abcd" 输出："bcad"

s 中受约束的字符按 b → c → a 排列；d 可自由放置。dbca、bcda 也满足要求。

约束

  • 1 <= order.length <= 26
  • 1 <= s.length <= 200
  • order 和 s 仅由小写英文字母组成。
  • order 中的所有字符互不相同。

Solution

计数后按轨道出库

O(|s| + |order| + 26)

核心洞察

order 只规定“不同字符种类”的先后，不规定同一字符出现几次。因此先统计 s 的每个字符频次，再依次读取 order，把对应字符一次性写出；最后补上未出现在 order 中的剩余字符即可。

完整过程

  1. 建立长度为 26 的计数数组，扫描 s 并记录每个字母的出现次数。
  2. 从左到右遍历 order。对于当前字符，将它按计数重复追加到答案，并把该计数清零。
  3. 遍历 26 个字母，把计数仍大于 0 的字符追加到答案。这些都是不受 order 约束的字符。
  4. 返回答案。剩余字符采用字母序只是为了输出稳定，并非题目要求。

正确性说明

  1. 字符守恒：每个字符的写出次数恰好等于其在 s 中的计数，所以答案是 s 的排列。
  2. 自定义顺序成立：若 x 在 order 中早于 y，算法会先一次性写出全部 x 再写出全部 y，因此结果中受约束字符的相对顺序满足要求。
  3. 剩余字符合法：最后写出的字符均不在 order 中，题目不限制它们的位置，所以追加在尾部仍然合法。

边界情况

  • order 中的字符可能完全不在 s 中，跳过即可。
  • s 中可能有大量重复字符，必须按频次完整输出。
  • s 中的字符可能全部不在 order 中，此时任意排列都合法。
  • order 最长 26，且字符唯一，无需处理相互冲突的规则。

复杂度

时间：O(|s| + |order| + 26)。输出本身需要写入 |s| 个字符。

空间：除返回结果外为 O(26)；若把结果计入空间，则为 O(|s|)。

四语言完整代码

Java
class Solution {
    public String customSortString(String order, String s) {
        int[] count = new int[26];
        for (int i = 0; i < s.length(); i++) {
            count[s.charAt(i) - 'a']++;
        }

        StringBuilder answer = new StringBuilder(s.length());
        for (int i = 0; i < order.length(); i++) {
            char ch = order.charAt(i);
            int index = ch - 'a';
            while (count[index] > 0) {
                answer.append(ch);
                count[index]--;
            }
        }

        for (int index = 0; index < 26; index++) {
            while (count[index] > 0) {
                answer.append((char) ('a' + index));
                count[index]--;
            }
        }
        return answer.toString();
    }
}

var customSortString = function(order, s) {
    const count = new Array(26).fill(0);
    for (const ch of s) {
        count[ch.charCodeAt(0) - 97]++;
    }

    const answer = [];
    for (const ch of order) {
        const index = ch.charCodeAt(0) - 97;
        while (count[index] > 0) {
            answer.push(ch);
            count[index]--;
        }
    }

    for (let index = 0; index < 26; index++) {
        while (count[index] > 0) {
            answer.push(String.fromCharCode(97 + index));
            count[index]--;
        }
    }
    return answer.join("");
};
Python
class Solution:
    def customSortString(self, order: str, s: str) -> str:
        count = [0] * 26
        for ch in s:
            count[ord(ch) - ord("a")] += 1

        answer = []
        for ch in order:
            index = ord(ch) - ord("a")
            if count[index] > 0:
                answer.append(ch * count[index])
                count[index] = 0

        for index in range(26):
            if count[index] > 0:
                answer.append(chr(ord("a") + index) * count[index])

        return "".join(answer)
C++
class Solution {
public:
    string customSortString(string order, string s) {
        array<int, 26> count{};
        for (char ch : s) {
            ++count[ch - 'a'];
        }

        string answer;
        answer.reserve(s.size());
        for (char ch : order) {
            int index = ch - 'a';
            answer.append(count[index], ch);
            count[index] = 0;
        }

        for (int index = 0; index < 26; ++index) {
            answer.append(count[index], static_cast<char>('a' + index));
        }
        return answer;
    }
};

替代方案

自定义比较器排序：先建立字符到排名的映射，再按排名排序 s。写法直观，但一般需要 O(|s| log |s|) 时间，并要为不在 order 中的字符定义统一排名。

桶分组：用映射保存每个字符对应的字符串片段，本质与计数法一致；当字符集不再固定为 26 个小写字母时更灵活。

面试追问

  • 如果字符集是完整 Unicode，如何改用哈希表并保持剩余字符的原始顺序？
  • 如果要求排序稳定，即未受约束字符保持它们在 s 中的相对顺序，如何收集剩余字符？
  • 如果 order 不是一个序列，而是一组偏序关系，何时需要拓扑排序？

常见错误

  • 只把每种字符输出一次，丢失 s 中的重复字符。
  • 只遍历 order 并忘记追加不受约束的剩余字符。
  • 误以为结果必须与示例完全相同；本题接受任意满足规则的排列。
  • 使用比较器时给未出现在 order 中的字符返回不一致的比较结果，破坏排序契约。
