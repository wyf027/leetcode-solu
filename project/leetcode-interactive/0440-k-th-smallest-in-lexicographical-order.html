字典序的第 K 小数字

数字不只按大小排队。当它们被当作字符串比较时，会形成一片隐形的十叉森林。你的目标是在不展开全部节点的前提下，准确抵达第 k 个位置。

难度 HARD 主题 字典树 函数 findKthNumber(n, k) 非付费题

Challenge brief

题目说明

给定两个整数 n 和 k，把区间 [1, n] 中的整数按十进制字符串的字典序排列，返回其中第 k 小的数字。

如何理解“字典序”

比较数字时，将它们视作不含前导零的字符串：先比较第一个字符；相同时继续比较下一位；如果一方是另一方的前缀，较短者在前。例如 1 会排在 10 之前，而 13 会排在 2 之前。

约束
  • 1 ≤ k ≤ n ≤ 109
  • 返回值为区间 [1, n] 内的整数。
官方示例 1 
输入：n = 13, k = 2
输出：10
解释：[1, 10, 11, 12, 13, 2, 3, 4, 5, 6, 7, 8, 9] 中，第 2 个数是 10。
官方示例 2 
输入：n = 1, k = 1
输出：1

Full solution

前缀计数 + 贪心定位

把所有数字看作一棵不实际创建的十叉字典树：先计算某个前缀子树中有多少合法数字，再决定整棵跳过还是进入下一层。

核心洞察

一次决策跳过一整棵前缀子树。 对相邻前缀 curr 与 curr + 1，逐层放大十倍，就能累计区间 [curr, curr + 1) 在 [1, n] 内覆盖的节点数。若目标名次不在其中，直接移动到右侧兄弟；否则进入 curr × 10。

完整过程

  1. 字典序第一个数字必为 1。令 curr = 1，并将 k 减一，改为“从当前节点还需前进多少步”。
  2. 计算前缀 curr 的子树大小 steps。第 d 层覆盖 [curr × 10^d, (curr + 1) × 10^d)，再用 n + 1 截断右端点。
  3. 若 steps ≤ k，目标不在该子树：执行 curr++ 与 k -= steps。
  4. 否则目标在该子树：当前节点本身占一个名次，执行 curr *= 10 与 k--。
  5. 当偏移 k 变为 0，curr 就是答案。

为什么正确

引理 1：计数准确

所有以 curr 开头的数字，在每个十进制层级恰好落入半开区间 [first, next)。用 n + 1 截断后，各层互不重叠且覆盖全部合法后代，逐层求和即为子树大小。

引理 2：两种转移不漏答案

字典序的前缀子树是连续区间。若其大小不超过剩余偏移，目标必在区间右侧，可整体跳过；否则目标位于区间内，而当前节点已计入顺序，进入最左孩子并消耗一步恰好保持目标不变量。

结论

每轮都保持“答案是从 curr 开始向后第 k 步的数字”这一不变量，同时严格减少剩余搜索范围。循环在 k = 0 时终止，因此返回值正是原序列第 K 小的数字。

边界处理

  • k = 1：初始化减一后立即返回 1。
  • 不完整的最深层：计数时用 min(n + 1, next) 截断，不能假设每层都有完整的 10 个分支。
  • 数值溢出：Java 与 C++ 的层级边界必须使用 64 位整数；JavaScript 的本题范围仍处于安全整数区间。
  • 没有前导零：根层只有 1 到 9，后续层才允许数字 0。

复杂度

O((log n)²)每次前缀计数需要 O(log n)，决策次数至多为每层常数个兄弟加下潜层数。
O(1)只维护当前前缀、下一前缀、剩余偏移与计数器。

四语言完整代码

Java
class Solution {
    public int findKthNumber(int n, int k) {
        long curr = 1;
        k--;

        while (k > 0) {
            long steps = countSteps(n, curr, curr + 1);
            if (steps <= k) {
                curr++;
                k -= (int) steps;
            } else {
                curr *= 10;
                k--;
            }
        }
        return (int) curr;
    }

    private long countSteps(int n, long first, long next) {
        long steps = 0;
        while (first <= n) {
            steps += Math.min((long) n + 1, next) - first;
            first *= 10;
            next *= 10;
        }
        return steps;
    }
}

C++
class Solution {
public:
    int findKthNumber(int n, int k) {
        long long curr = 1;
        --k;

        while (k > 0) {
            long long steps = countSteps(n, curr, curr + 1);
            if (steps <= k) {
                ++curr;
                k -= static_cast<int>(steps);
            } else {
                curr *= 10;
                --k;
            }
        }
        return static_cast<int>(curr);
    }

private:
    long long countSteps(int n, long long first, long long next) {
        long long steps = 0;
        while (first <= n) {
            steps += min(static_cast<long long>(n) + 1, next) - first;
            first *= 10;
            next *= 10;
        }
        return steps;
    }
};

替代方案

全部转字符串后排序

实现直观，但需要保存 n 个整数并进行排序；在 n = 109 时完全不可行。通常为 O(n log n) 时间与 O(n) 空间。

逐节点字典序 DFS

无需排序，但仍可能访问到第 k 个节点才停止，最坏 O(k) 次访问。前缀计数把整棵子树压缩成一次跳跃，更适合本题上界。

面试追问

  • 若允许任意进制，如何把十叉树推广到 b 叉树？根层与后续层分别有哪些数字限制？
  • 为什么判断条件是 steps ≤ k 而不是 steps < k？
  • 如果区间变为 [L, R]，能否构造“前缀计数 ≤ X”的函数并做差？
  • 如何返回第 k 个字符串，而输入允许固定宽度和前导零？

常见错误

忘记先执行 k--

当前前缀 1 已经占据第一个位置。若仍把 k 当作一基名次，所有结果都会错位。

右边界写成 n

区间长度应使用半开边界，所以截断点是 n + 1；否则会漏掉数字 n。

下潜时不消耗一步

从父前缀移动到最左孩子前，父节点自身已经经过，必须执行 k--。

计数变量使用 32 位

即使 n 只有 109，层级边界继续乘 10 也可能超出 32 位整数。
