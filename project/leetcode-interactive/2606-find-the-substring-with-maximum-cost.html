找到最大开销的子字符串Find the Substring With Maximum Cost

字母不再总按字母表计价：部分字符会被重新标价。你的目标，是从连续片段中找到能累积出的最高开销；空字符串也参与竞争。

读完规则后，先判断负价值字符会怎样改变最优片段的边界。

一段连续字符的开销

a+d+a

每个字符都有价值；自定义价值优先于字母表位置。

Problem

题目描述

给定三个参数，计算 s 的所有连续子字符串中可能得到的最大开销。

输入与目标

给你字符串 s、由互不相同的小写字母组成的字符串 chars，以及与 chars 等长的整数数组 vals。

一个子字符串的开销，是其中每个字符价值的总和。返回所有子字符串可取得的最大开销。空字符串的开销定义为 0。

maximumCostSubstring(s, chars, vals) → integer

字符如何计价

  • 若字符 c 不在 chars 中，它的价值等于字母表中的 1-based 位置：a = 1，…，z = 26。
  • 若 c == chars[i]，它的价值改为 vals[i]；这个自定义价格覆盖默认价格。
  • 只允许选择连续字符，也可以选择空字符串。

示例 1

输入：s = "adaa", chars = "d", vals = [-1000]
输出：2

a 的价值是 1，d 被改为 -1000。最大开销子字符串是末尾的 "aa"，开销为 1 + 1 = 2。

示例 2

输入：s = "abc", chars = "abc", vals = [-1,-1,-1]
输出：0

三个字符的价值都为 -1。任何非空子字符串都会产生负开销，因此选择空字符串，开销为 0。

约束

  • 1 ≤ s.length ≤ 10⁵
  • s 只包含小写英文字母
  • 1 ≤ chars.length ≤ 26
  • chars 只包含互不相同的小写英文字母
  • vals.length == chars.length
  • -1000 ≤ vals[i] ≤ 1000

Solution

准备好对答案了吗？

题解默认收起。建议先说出你的状态定义、状态转移，以及为什么答案不能小于零。

Editorial

一次映射，一次线性扫描

把字符转换为整数后，问题就是允许空数组的最大连续子数组和。

核心洞察

先建立 26 个字母的价值表：默认价值是 a → 1 到 z → 26，再用 chars 和 vals 覆盖。随后对价值序列运行 Kadane 算法。

ending = max(0, ending + value(c))
answer = max(answer, ending)

把 ending 截断为 0 同时表示：负收益前缀不再携带，并且空字符串始终可选。

初始化价值表

令 value[i] = i + 1，得到每个小写字母的默认价值。

覆盖特殊字符

对每个 i，令 value[chars[i] - 'a'] = vals[i]。由于字符互不相同，无需处理冲突。

维护以当前位置结尾的最优值

读到字符 c 时，更新 ending = max(0, ending + value[c])。若总和变负，就从空片段重新开始。

维护全局答案

每一步用 ending 更新 answer。两者从 0 开始，因此全为负值时自然返回空字符串的开销 0。

正确性证明

引理：处理完位置 i 后，ending 等于所有以 i 结尾的子字符串与空字符串中的最大开销。

证明：任何以 i 结尾的非空子字符串，要么只含当前字符，要么是在以 i-1 结尾的某段后追加当前字符。若此前最佳开销为负，丢弃它并从空串开始不会更差；因此转移 max(0, ending + value) 恰好保留最优选择。

结论：answer 取遍每个位置的 ending 最大值，覆盖所有非空子字符串；初值 0 又覆盖空字符串，所以最终答案正确。

边界与复杂度

  • 所有价值为负：状态始终回到 0，返回空字符串。
  • 没有自定义字符出现在 s 中：直接使用字母表默认价值。
  • 自定义价值可以大于、等于或小于默认价值，覆盖规则不变。
  • s.length = 10⁵：一次线性扫描足够，无需保存完整价值数组。
时间 O(|s| + |chars|)额外空间 O(1)

四种语言实现

class Solution {
    public int maximumCostSubstring(String s, String chars, int[] vals) {
        int[] value = new int[26];
        for (int i = 0; i < 26; i++) value[i] = i + 1;
        for (int i = 0; i < chars.length(); i++) {
            value[chars.charAt(i) - 'a'] = vals[i];
        }

        int ending = 0, answer = 0;
        for (char c : s.toCharArray()) {
            ending = Math.max(0, ending + value[c - 'a']);
            answer = Math.max(answer, ending);
        }
        return answer;
    }
}

    const value = Array.from({ length: 26 }, (_, i) => i + 1);

    let answer = 0;
    for (const c of s) {
        ending = Math.max(0, ending + value[c.charCodeAt(0) - 97]);
        answer = Math.max(answer, ending);
    }
    return answer;

class Solution:
    def maximumCostSubstring(
        self, s: str, chars: str, vals: List[int]
    ) -> int:
        value = list(range(1, 27))
        for char, cost in zip(chars, vals):
            value[ord(char) - ord("a")] = cost

        ending = answer = 0
        for char in s:
            ending = max(0, ending + value[ord(char) - ord("a")])
            answer = max(answer, ending)
        return answer

替代方案

前缀和 + 最小前缀

维护当前前缀和以及此前最小前缀和，用两者差值更新答案。同样是 O(n) 时间、O(1) 空间，本质与 Kadane 等价，但状态解释略绕。

枚举所有子字符串

固定左端点并扩展右端点，复杂度为 O(n²)。可用于手算或极小输入，但无法承受 10⁵ 的字符串长度。

面试追问

如果必须返回最大开销子字符串本身呢？

在状态从 0 重新开始时记录候选左端点；当 answer 被更新时保存当前左右端点。若最终答案为 0，还要按题目约定处理空串与零和非空串的优先级。

为什么不需要先构造价值数组？

扫描 s 时可直接查 26 长度的价值表并更新状态，完整数值序列不会被再次使用，因此存下来只是额外空间。

若允许删除字符而不要求连续，会发生什么？

问题将不再是最大连续子数组：只需累加所有正价值字符；如果还要求非空，则在没有正值时选价值最大的单个字符。

若字符集不只含 26 个小写字母呢？

把定长数组换成语言自带的映射结构，并为未覆盖字符提供明确的默认价值函数；核心的线性扫描不变。

常见错误有哪些？

忘记空字符串导致全负输入返回负数；未用自定义价值覆盖默认价值；把子字符串误当成子序列；每次用 chars.indexOf 查价，虽因长度至多 26 尚可，但没有直接价值表清晰。
