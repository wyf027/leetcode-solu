最近的请求次数

Number of Recent Calls · 用一个不断向前滑动的 3000ms 时间窗口理解数据流。

题目

实现 RecentCounter 类，统计指定时间范围内的最近请求：

  • RecentCounter()：初始化，请求数为 0。
  • int ping(int t)：在毫秒时间 t 加入一个请求，返回闭区间 [t - 3000, t] 中的请求数量。

每次调用 ping 时，t 都严格大于前一次调用的值。

官方示例

输入：
["RecentCounter", "ping", "ping", "ping", "ping"]
[[], [1], [100], [3001], [3002]]

输出：
[null, 1, 2, 3, 3]

逐次调用

RecentCounter recentCounter = new RecentCounter();
recentCounter.ping(1);    // [-2999, 1] → 1
recentCounter.ping(100);  // [-2900, 100] → 2
recentCounter.ping(3001); // [1, 3001] → 3
recentCounter.ping(3002); // [2, 3002] → 3

约束

  • 1 ≤ t ≤ 10⁹
  • t 严格递增
  • 至多调用 ping 10⁴ 次

请求雷达

逐帧观察窗口左边界如何淘汰过期请求。

题解：让队首代表最早的有效请求

核心洞察

因为 t 严格递增，请求天然按时间有序。每次把新时间放到队尾，再从队首删除所有小于 t - 3000 的时间；留下的正好全部位于闭区间内。

完整过程

  1. 将 t 入队。
  2. 当队首 < t - 3000 时出队。注意等于左边界仍有效。
  3. 返回队列长度。

正确性

删除循环结束后，队首及其后的元素都不小于左边界；又因所有已加入请求不大于当前 t，所以队列中的每个时间都在窗口内。所有被删除元素都小于左边界，不可能属于窗口。因此队列长度恰为所求。

边界与复杂度

  • 窗口是闭区间，淘汰条件必须是 <，不是 ≤。
  • 每个请求最多入队、出队各一次，单次均摊 O(1)。
  • 空间为 O(W)，W 是窗口中请求数；最坏 O(n)。

替代方案

可保存所有时间并用二分查找左边界，单次 O(log n) 且不会释放旧数据；队列更贴合流式场景。数组加头指针也能避免 JavaScript shift() 的搬移开销。

面试追问

  • 若时间不单调：可用平衡树或有序多重集合。
  • 若窗口长度可变：固定队列淘汰后无法恢复旧数据，需要保留更长历史或使用索引。
  • 若并发调用：需保证入队、淘汰、计数的原子性。

常见错误

  • 把 t-3000 本身删除。
  • 先淘汰再忘记加入当前请求。
  • JavaScript 反复 shift() 导致潜在的数组移动。

四语言完整实现

Java

import java.util.ArrayDeque;
import java.util.Deque;

class RecentCounter {
    private final Deque<Integer> queue = new ArrayDeque<>();

    public RecentCounter() {}

    public int ping(int t) {
        queue.offerLast(t);
        while (queue.peekFirst() < t - 3000) {
            queue.pollFirst();
        }
        return queue.size();
    }
}

JavaScript

var RecentCounter = function () {
  this.queue = [];
  this.head = 0;
};

RecentCounter.prototype.ping = function (t) {
  this.queue.push(t);
  while (this.queue[this.head] < t - 3000) {
    this.head++;
  }
  return this.queue.length - this.head;
};

Python

from collections import deque

class RecentCounter:
    def __init__(self):
        self.queue = deque()

    def ping(self, t: int) -> int:
        self.queue.append(t)
        while self.queue[0] < t - 3000:
            self.queue.popleft()
        return len(self.queue)

C++

#include <queue>
using namespace std;

class RecentCounter {
    queue<int> requests;
public:
    RecentCounter() {}

    int ping(int t) {
        requests.push(t);
        while (requests.front() < t - 3000) {
            requests.pop();
        }
        return static_cast<int>(requests.size());
    }
};
