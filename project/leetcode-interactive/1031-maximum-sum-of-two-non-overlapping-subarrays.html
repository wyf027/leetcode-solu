两个无重叠子数组的最大和

Maximum Sum of Two Non-Overlapping Subarrays。先从题意和可操作的窗口实验开始；完整解法刻意收在页面底部。

MEDIUM非付费题前缀和双顺序扫描

题目

给定整数数组 nums，以及两个长度 firstLen、secondLen。请选择两个互不重叠的连续子数组，它们的长度分别等于这两个值，并返回两段元素和的最大值。

两段的先后顺序不限：firstLen 对应的窗口既可以在前，也可以在后。子数组必须连续。

函数形式
maxSumTwoNoOverlap(nums, firstLen, secondLen) → integer

约束

  • 1 ≤ firstLen, secondLen ≤ 1000
  • 2 ≤ firstLen + secondLen ≤ 1000
  • firstLen + secondLen ≤ nums.length ≤ 1000
  • 0 ≤ nums[i] ≤ 1000

官方示例

输入：nums = [0,6,5,2,2,5,1,9,4], firstLen = 1, secondLen = 2

输出：20

例如选择长度 1 的 [9] 和长度 2 的 [6,5]。

输入：nums = [3,8,1,3,2,1,8,9,0], firstLen = 3, secondLen = 2

输出：29

例如选择 [3,8,1] 与 [8,9]。

输入：nums = [2,1,5,6,0,9,5,0,3,8], firstLen = 4, secondLen = 3

输出：31

例如选择 [5,6,0,9] 与 [0,3,8]。

Solution

前缀和 + 两次线性扫描

核心洞察

固定右侧长度为 R 的窗口，并从左向右移动它。右窗口起点为 i - R 时，合法的左侧长度 L 窗口必须结束在该起点或更早。历史上所有合法左窗无需全部保存，只保留其中最大的窗口和 bestLeft。

一种扫描只能覆盖“L 在左、R 在右”。调用 scan(firstLen, secondLen) 和 scan(secondLen, firstLen) 并取最大值，就覆盖了两段的全部相对顺序。

完整过程

  1. 建立前缀和 prefix，区间 [l, r) 的和为 prefix[r] - prefix[l]。
  2. 对顺序 (L, R)，令分界终点 i 从 L + R 走到 n。
  3. 用刚刚变为合法的 L 窗口 [i-R-L, i-R) 更新 bestLeft。
  4. 计算当前 R 窗口 [i-R, i)，用 bestLeft + rightSum 更新答案。
  5. 交换 L 与 R 再扫描一次，返回两个顺序中的最大值。

正确性证明

引理 1

扫描到 i 时，bestLeft 等于所有结束位置不超过 i-R 的长度 L 子数组的最大和。因为每前进一步恰好纳入一个新合法窗口，并与历史最大值取较大者。

引理 2

固定当前右窗口 [i-R,i) 后，与它不重叠且位于左侧的最优长度 L 窗口必然由 bestLeft 表示。因此该步得到此右窗口下的最优组合。

结论

第一次扫描枚举所有 L 在 R 左边的组合，交换长度后枚举另一顺序。任意合法解必属其中之一，所以两次扫描的最大值就是全局最优。

边界处理

  • 两段长度之和可以刚好等于数组长度。
  • 窗口首尾相接是合法的，因为没有共享元素。
  • 所有元素非负，但算法不依赖这一点；若允许负数，也应将答案按实际窗口和初始化。
  • 前缀和使用半开区间，能减少下标偏移错误。

复杂度

  • 时间：O(n)，两次扫描仍是线性。
  • 空间：下方代码使用前缀数组，为 O(n)。
  • 也可用滑动窗口把额外空间优化到 O(1)。

替代方案

可以预计算每个位置左侧/右侧固定长度窗口的最大值，再枚举分割点，仍是 O(n) 时间和 O(n) 空间。暴力枚举两段起点是 O(n²)；它直观但没有利用“右窗口移动后，左侧只需历史最大值”这一单调扩展结构。

面试追问

  • 能否做到 O(1) 额外空间？ 同时维护左右两个滑动窗口和，以及历史最佳左窗即可。
  • 扩展到 k 个定长不重叠子数组？ 使用按段数和前缀位置定义的动态规划。
  • 如果两个长度相同？ 两次扫描结果相同，但保留统一写法更简洁。
  • 为什么不能只扫描 firstLen 在左？ 最优解可能要求 firstLen 窗口出现在 secondLen 窗口右侧。

常见错误

  • 只考虑一种先后顺序。
  • 把相邻窗口误判为重叠，或在闭区间/半开区间之间混用。
  • 更新 bestLeft 时取错新加入窗口的起止下标。
  • 枚举所有窗口对导致二次复杂度。

class Solution {
    public int maxSumTwoNoOverlap(int[] nums, int firstLen, int secondLen) {
        int[] prefix = new int[nums.length + 1];
        for (int i = 0; i < nums.length; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        return Math.max(scan(prefix, firstLen, secondLen),
                        scan(prefix, secondLen, firstLen));
    }

    private int scan(int[] prefix, int leftLen, int rightLen) {
        int answer = 0;
        int bestLeft = 0;
        for (int i = leftLen + rightLen; i < prefix.length; i++) {
            int leftEnd = i - rightLen;
            int leftSum = prefix[leftEnd] - prefix[leftEnd - leftLen];
            bestLeft = Math.max(bestLeft, leftSum);
            int rightSum = prefix[i] - prefix[i - rightLen];
            answer = Math.max(answer, bestLeft + rightSum);
        }
        return answer;
    }
}
