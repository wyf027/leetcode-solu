Daily Leads and Partners

每天的领导和合伙人

把重复销售记录压缩成「日期 × 产品」的唯一关系快照。

Problem

题目描述

DailySales 记录销售日期、产品名称，以及对应的领导和合伙人编号。表没有主键，因此完全相同或部分相同的记录可能重复出现。

列名类型含义
date_iddate销售日期
make_namevarchar产品名称
lead_idint领导编号
partner_idint合伙人编号
目标：对每个 (date_id, make_name) 组合，分别统计不同 lead_id 的数量 unique_leads 与不同 partner_id 的数量 unique_partners，结果可按任意顺序返回。

约束与数据特征

  • 表没有主键，可能含重复记录。
  • make_name 只包含小写英文字母。
  • 官方题面未给出额外的行数或数值范围。

Full Solution

题解

核心洞察

输出的一行由 date_id 和 make_name 唯一确定，所以先按这两列 GROUP BY。组内可能重复，必须分别对两个编号做 COUNT(DISTINCT ...)。

完整过程

  1. 扫描 DailySales，以 (date_id, make_name) 划分分组。
  2. 在每组内建立领导编号的去重集合，并统计集合大小。
  3. 独立建立合伙人编号的去重集合，并统计集合大小。
  4. 输出分组键和两个计数。题目允许任意顺序，因此无需 ORDER BY。

正确性证明

任取一个输出分组 G=(d,m)。GROUP BY date_id, make_name 恰好将且仅将日期为 d、产品为 m 的记录放入 G。COUNT(DISTINCT lead_id) 对 G 中每个不同领导编号恰计一次，所以得到该组准确的领导数；同理，COUNT(DISTINCT partner_id) 得到准确的合伙人数。因此每个输出分组及其两个计数均正确。

边界情况

  • 完全重复的行不会放大任一计数。
  • 同一领导对应多个合伙人时，领导仍只计一次。
  • 同一编号出现在不同日期或不同产品中，应在各自分组重新计数。
  • 标准 SQL 的 COUNT(DISTINCT x) 忽略 NULL；官方结构未额外声明 NULL 规则。

复杂度

设表有 n 行、结果有 g 组。概念上的哈希分组与集合去重平均时间 O(n)，额外空间 O(n)；数据库实际执行计划可能选择哈希或排序聚合。

替代方案

可以先分别去重 (date_id, make_name, lead_id) 与 (date_id, make_name, partner_id) 后聚合再连接，但需要多次扫描/连接，远不如双重 COUNT(DISTINCT) 简洁。

面试追问

  • 如果需要同时统计多列组合的不同数量，数据库方言是否支持多列 COUNT(DISTINCT ...)？
  • 数据量很大时，(date_id, make_name) 索引、分区和预聚合各有什么收益？
  • 为什么不能用 COUNT(*) 或普通 COUNT(lead_id)？

常见错误

  • 只按日期分组，混合了不同产品。
  • 忘记 DISTINCT，重复记录导致过计数。
  • 将领导和合伙人的去重逻辑互相绑定，错误统计“成对组合”而非两列各自的不同值。
  • 加入题目未要求的固定排序，并误以为输出顺序影响正确性。

官方可提交答案：MySQL / 通用 SQL

SELECT
    date_id,
    make_name,
    COUNT(DISTINCT lead_id) AS unique_leads,
    COUNT(DISTINCT partner_id) AS unique_partners
FROM DailySales
GROUP BY date_id, make_name;

本题是数据库题；LeetCode 官方提交语言为 SQL（另支持 Pandas）。以下 Java、JavaScript、Python、C++ 仅演示相同的“复合键分组 + 两个集合去重”语义，不能替代平台 SQL 提交。

import java.util.*;

class Solution {
    static class Sale {
        String date, make;
        int lead, partner;
        Sale(String d, String m, int l, int p) {
            date = d; make = m; lead = l; partner = p;
        }
    }

    public List<List<Object>> summarize(List<Sale> sales) {
        Map<String, Set<Integer>> leads = new LinkedHashMap<>();
        Map<String, Set<Integer>> partners = new LinkedHashMap<>();
        for (Sale s : sales) {
            String key = s.date + "\u0000" + s.make;
            leads.computeIfAbsent(key, k -> new HashSet<>()).add(s.lead);
            partners.computeIfAbsent(key, k -> new HashSet<>()).add(s.partner);
        }
        List<List<Object>> ans = new ArrayList<>();
        for (String key : leads.keySet()) {
            String[] parts = key.split("\u0000", -1);
            ans.add(Arrays.asList(parts[0], parts[1],
                    leads.get(key).size(), partners.get(key).size()));
        }
        return ans;
    }
}
function summarize(sales) {
  const groups = new Map();
  for (const [date, make, lead, partner] of sales) {
    const key = JSON.stringify([date, make]);
    if (!groups.has(key)) groups.set(key, { leads: new Set(), partners: new Set() });
    groups.get(key).leads.add(lead);
    groups.get(key).partners.add(partner);
  }
  return [...groups].map(([key, group]) => {
    const [date, make] = JSON.parse(key);
    return [date, make, group.leads.size, group.partners.size];
  });
}
from collections import defaultdict

def summarize(sales):
    groups = defaultdict(lambda: [set(), set()])
    for date, make, lead, partner in sales:
        groups[(date, make)][0].add(lead)
        groups[(date, make)][1].add(partner)
    return [
        [date, make, len(values[0]), len(values[1])]
        for (date, make), values in groups.items()
    ]
#include <map>
#include <set>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

struct Sale { string date, make; int lead, partner; };

vector<tuple<string, string, int, int>> summarize(const vector<Sale>& sales) {
    using Key = pair<string, string>;
    map<Key, pair<set<int>, set<int>>> groups;
    for (const auto& sale : sales) {
        auto& group = groups[{sale.date, sale.make}];
        group.first.insert(sale.lead);
        group.second.insert(sale.partner);
    }
    vector<tuple<string, string, int, int>> answer;
    for (const auto& [key, values] : groups) {
        answer.emplace_back(key.first, key.second,
                            values.first.size(), values.second.size());
    }
    return answer;
}
