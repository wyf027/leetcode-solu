230. 二叉搜索树中第 K 小的元素

BST 的中序遍历天然从小到大。用显式栈模拟递归，每访问一个节点就让计数推进一格，第 k 次访问即是答案。

Medium二叉搜索树中序遍历
官方标题
Kth Smallest Element in a BST
输入
root, k
推荐解法
迭代中序

题意

给定二叉搜索树根节点 root 和整数 k，返回树中所有节点值里第 k 小（从 1 开始计数）的值。
示例 1
root = [3,1,4,null,2], k = 1
输出：1
示例 2
root = [5,3,6,2,4,null,null,1], k = 3
输出：3

约束：1 ≤ k ≤ n ≤ 10⁴，0 ≤ Node.val ≤ 10⁴。追问：若树经常插入、删除且频繁查询第 k 小，如何优化？

题解：访问顺序就是排序顺序

核心洞察

BST 保证左子树所有值小于根、右子树所有值大于根。因此中序遍历（左、根、右）正好按升序访问节点。无需真正收集全部数组：第 k 次弹栈访问时即可返回。

完整过程

  1. 不断把当前节点及其左孩子压入栈，直到空。
  2. 弹出栈顶：这是当前未访问节点中的最小值，计数加一。
  3. 若计数到 k，直接返回；否则转向它的右孩子。
  4. 重复，右子树仍会先压它的最左链。
时间复杂度
O(H + k)，最坏 O(n)。
空间复杂度
O(H)，显式栈最多保存树高。

替代方案与取舍

完整中序数组后取第 k 个写法直观但多用了 O(n) 空间。递归写法简短，不过极端偏斜树可能有调用栈风险；迭代栈可早停，也更稳妥。

边界

  • k = 1：一直向左，得到最小节点。
  • k = n：访问到最大节点。
  • 单节点树直接返回根值。
  • 树很偏斜时，显式栈仍正确。

常见错误

先访问根再访问左孩子会变成先序，顺序错误；每次转向右子树后忘记继续压它的左链，会跳过更小的候选。

面试追问

频繁修改并查询时，在每个节点维护左子树节点数；插入/删除时更新计数，查询可沿树走 O(H)。

可提交代码

class Solution {
    public int kthSmallest(TreeNode root, int k) {
        java.util.ArrayDeque<TreeNode> stack = new java.util.ArrayDeque<>();
        TreeNode cur = root;
        while (true) {
            while (cur != null) { stack.push(cur); cur = cur.left; }
            cur = stack.pop();
            if (--k == 0) return cur.val;
            cur = cur.right;
        }
    }
}
