股票价格跨度

Online Stock Span · 用一座会“合并历史”的单调栈，实时回答今天能向前覆盖多少天。

题目

设计 StockSpanner：它逐日接收价格。调用 next(price) 时，返回从今天向前数、价格连续小于或等于今天价格的最大天数（包含今天）；遇到更高价格即停止。

接口：StockSpanner() 初始化；int next(int price) 接收当天价格并返回跨度。

官方示例（完整参数形式）

输入：
["StockSpanner","next","next","next","next","next","next","next"]
[[],[100],[80],[60],[70],[60],[75],[85]]

输出：
[null,1,1,1,2,1,4,6]

解释：依次输入 100、80、60、70、60、75、85；
对应跨度为 1、1、1、2、1、4、6。

约束

  • 1 ≤ price ≤ 10⁵
  • 最多调用 next 10⁴ 次。

题解：压缩式单调递减栈

核心洞察

栈内从底到顶价格严格递减。每个元素保存 (price, span)：不仅代表一天，还把它右侧已经确认“不高于它”的连续日期压缩进 span。新价格到来时，只要栈顶价格 ≤ price，整块都属于今天的跨度，可一次性合并。

完整过程

  1. 令今天跨度 span = 1。
  2. 当栈非空且栈顶价格不高于今天价格：弹出栈顶，把它保存的跨度累加。
  3. 将 (price, span) 入栈并返回 span。

为什么正确

不遗漏：被弹出的块都紧邻今天，且块中每个价格不高于该块代表价，而代表价又不高于今天，因此整块都可计入。不越界：循环结束时若栈非空，栈顶价格严格高于今天，是跨度向左扩展的第一个阻挡。故累加结果恰好是最大连续天数。入栈后仍保持严格递减不变量。

边界与复杂度

  • 首次调用返回 1；相同价格必须用 ≤ 合并。
  • 单调下降时每次为 1；单调上升时新值会合并全部历史。
  • 每个价格最多入栈、出栈各一次：单次均摊 O(1)，共 O(n)；最坏空间 O(n)。

Java

import java.util.ArrayDeque;
import java.util.Deque;

class StockSpanner {
    private final Deque<int[]> stack = new ArrayDeque<>();

    public StockSpanner() {}

    public int next(int price) {
        int span = 1;
        while (!stack.isEmpty() && stack.peek()[0] <= price) {
            span += stack.pop()[1];
        }
        stack.push(new int[]{price, span});
        return span;
    }
}

};

Python

class StockSpanner:
    def __init__(self):
        self.stack = []

    def next(self, price: int) -> int:
        span = 1
        while self.stack and self.stack[-1][0] <= price:
            span += self.stack.pop()[1]
        self.stack.append((price, span))
        return span

C++

#include <vector>
using namespace std;

class StockSpanner {
    vector<pair<int, int>> stack;
public:
    StockSpanner() = default;

    int next(int price) {
        int span = 1;
        while (!stack.empty() && stack.back().first <= price) {
            span += stack.back().second;
            stack.pop_back();
        }
        stack.push_back({price, span});
        return span;
    }
};

替代方案

保存全部价格并从今天向前线性扫描，单次最坏 O(n)、总计 O(n²)。也可保存“前一个更大元素”的索引并跳跃；本质上仍利用相同的历史压缩思想，但对象题用二元组栈更直接。

面试追问

为什么是均摊 O(1)，不是每次 O(1)？

一次调用可能弹出很多元素，但每个元素在整个数据流中只会被弹出一次。

如果跨度定义改为“严格小于”呢？

弹栈条件从 top.price ≤ price 改为 top.price < price，相同价格成为阻挡。

能否支持撤销最后一次 next？

需额外记录每次被弹出的元素与新入栈元素，形成可逆操作日志；普通单调栈本身无法恢复已弹元素。

常见错误

  • 只把弹出元素个数加一，忘了每个元素已经压缩了多个日期。
  • 用 < 而不是 ≤，导致相等价格未计入。
  • 把栈写成递增方向，或只存价格导致重复扫描。
  • 误称单次严格 O(1)；准确说法是均摊 O(1)。
