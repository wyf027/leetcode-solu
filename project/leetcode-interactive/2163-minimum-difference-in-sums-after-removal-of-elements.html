最小差值

Minimum Difference in Sums After Removal of Elements

从长度为 3n 的数组中删除恰好 n 个元素。保留元素的相对顺序，把它们的前 n 个与后 n 个分别求和。你能让「前半和 − 后半和」有多小？

这是带符号的差值，可以为负数；不取绝对值，也不能重排剩余元素。

01 / 题目约定

输入参数为零下标整数数组 nums，返回删除后能得到的最小差值。删除的位置可以不连续。

  • nums.length == 3 * n
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁵
  • 保留的两部分各有恰好 n 个元素。

官方接口：minimumDifference(nums)
返回值：整数，Java / C++ 使用 64 位。

02 / 官方示例

示例 1

输入：nums = [3,1,2]
输出：-1

n = 1。删除 3、1、2 时，保留数组分别是 [1,2]、[3,2]、[3,1]，差值依次为 −1、1、2，所以最小值是 −1。

示例 2

输入：nums = [7,9,5,8,1,3]
输出：1

n = 2。删除下标 1 和 4 的元素，保留 [7,5,8,3]，差值为 (7+5) − (8+3) = 1。若删除 5 和 8，保留 [7,9,1,3]，差值为 12，未达到最小值。

04 / 把删除问题变成分界问题

固定分界 k，左边尽量小，右边尽量大。令 k 表示原数组右侧区间的第一个下标。左侧区间为 [0,k)，右侧为 [k,3n)；左右都要容纳 n 个元素，所以 n ≤ k ≤ 2n。

左侧 L[k]

前 k 个元素中最小 n 个元素的和。用大根堆保留 n 个候选，超额时弹出最大值。

右侧 R[k]

从下标 k 开始的后缀中最大 n 个元素的和。用小根堆保留 n 个候选，超额时弹出最小值。

answer = min(L[k] − R[k]), k ∈ [n,2n]

  1. 从左到右处理下标 0 至 2n−1，累计堆内和；元素数达到 n 后记录 L[i+1]。
  2. 从右到左处理下标 3n−1 至 n，同样维护堆内和；当 i ≤ 2n 时，当前和即 R[i]。
  3. 用 L[i] − R[i]更新答案。提交代码边扫描右侧边取最小值；演示分三阶段展示以便观察。

06 / 为什么正确

堆的不变式

左扫描中，候选不足 n 个时全部保留。加入新值后若超额，移除最大值，留下的恰好是已扫描区间最小的 n 个值。交换论证：任何包含较大值却遗漏较小值的选择，都可交换而不增大总和。右侧对称，删除最小值即可保留最大的 n 个。

每个合法答案都有一个分界

取最终第一部分的最后一个原始下标 a，令 k = a + 1。第一部分全部在 [0,k)，第二部分全部在 [k,3n)。因为两侧各有 n 个元素，k 必在 [n,2n]。这组选择的第一部分和至少为 L[k]，第二部分和至多为 R[k]，故它的差值至少为 L[k]−R[k]。

每个分界的最优值都能实现

左右区间不相交，分别取最小 n 个与最大 n 个，然后按原下标保留；总计保留 2n 个、删除 n 个，且左组总在右组前面。因此 L[k]−R[k] 对应合法方案。枚举所有分界就同时满足下界与可达性，得到全局最优值。

示例 2 的分界账本

k = 2：L = 16，R = 11，差值 = 5
k = 3：L = 12，R = 11，差值 = 1  ← 最优
k = 4：L = 12，R =  4，差值 = 8
保留原下标 [0,2] 与 [3,5]，删除 [1,4]。

边界与复杂度

  • n = 1 时仍有 k = 1、2 两个分界，不能漏掉端点。
  • 重复值可任取等值下标；堆处理的是出现次数，不可使用去重集合。
  • 单侧和最大可达 10¹⁰。Java 用 long，C++ 用 long long；Python 整数无需额外处理，JavaScript Number 的安全整数范围足够。
  • 时间 O(n log n)（统一表达可写 O(n log(n+1))）；额外空间 O(n)，包括前缀和数组与堆。

import java.util.*;

class Solution {
    public long minimumDifference(int[] nums) {
        int n = nums.length / 3;
        long[] left = new long[2 * n + 1];
        PriorityQueue<Integer> maxHeap =
            new PriorityQueue<>(Comparator.reverseOrder());
        long sum = 0;
        for (int i = 0; i < 2 * n; i++) {
            maxHeap.offer(nums[i]);
            sum += nums[i];
            if (maxHeap.size() > n) sum -= maxHeap.poll();
            if (i + 1 >= n) left[i + 1] = sum;
        }
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        sum = 0;
        long answer = Long.MAX_VALUE;
        for (int i = nums.length - 1; i >= n; i--) {
            minHeap.offer(nums[i]);
            sum += nums[i];
            if (minHeap.size() > n) sum -= minHeap.poll();
            if (i <= 2 * n) answer = Math.min(answer, left[i] - sum);
        }
        return answer;
    }
}

JavaScript

class Heap {
    constructor(before) { this.a = []; this.before = before; }
    push(value) {
        const a = this.a;
        a.push(value);
        let i = a.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (!this.before(a[i], a[p])) break;
            [a[i], a[p]] = [a[p], a[i]];
            i = p;
        }
    }
    pop() {
        const a = this.a, root = a[0], last = a.pop();
        if (a.length) {
            a[0] = last;
            let i = 0;
            while (2 * i + 1 < a.length) {
                let c = 2 * i + 1;
                if (c + 1 < a.length && this.before(a[c + 1], a[c])) c++;
                if (!this.before(a[c], a[i])) break;
                [a[i], a[c]] = [a[c], a[i]];
                i = c;
            }
        }
        return root;
    }
}

from typing import List
import heapq

class Solution:
    def minimumDifference(self, nums: List[int]) -> int:
        n = len(nums) // 3
        left = [0] * (2 * n + 1)
        heap = []
        total = 0
        for i in range(2 * n):
            heapq.heappush(heap, -nums[i])
            total += nums[i]
            if len(heap) > n:
                total += heapq.heappop(heap)
            if i + 1 >= n:
                left[i + 1] = total
        heap = []
        total = 0
        answer = float('inf')
        for i in range(len(nums) - 1, n - 1, -1):
            heapq.heappush(heap, nums[i])
            total += nums[i]
            if len(heap) > n:
                total -= heapq.heappop(heap)
            if i <= 2 * n:
                answer = min(answer, left[i] - total)
        return answer

    long long minimumDifference(vector<int>& nums) {

        vector<long long> left(2 * n + 1);
        priority_queue<int> maxHeap;

08 / 替代方案与面试延伸

替代方案

  • 枚举删除位置：枚举 C(3n,n) 个子集并计算差值，适合小规模思考，无法应对 10⁵ 的 n。
  • 每个分界重新排序：分别排序左右候选并取 n 个，总体 O(n² log n)，重复处理相邻分界的大量相同元素。
  • 有序多重集 / 值域树：维护数量与总和，支持第 n 小或第 n 大的前缀统计。值域树可得到 O(n log U)，但实现更复杂。本题使用两个堆即可。

常见错误

  • 把差值取绝对值，或者把答案初始值设为 0：答案也可能为正。
  • 全数组排序后取两组，破坏原数组先后关系。
  • 左侧用小根堆、右侧用大根堆，弹出了应该留下的值。
  • 将 L[k] 与从 k+1 开始的后缀配对，或令左右同时包含 k，造成漏项或重叠。
  • 堆还不足 n 个就参与答案比较；弹出元素后忘记调整总和。
  • 堆内重排仅用于选取，不能将堆的遍历顺序作为保留数组顺序。

面试追问

如何返回删除位置？先记住最佳 k，再对该分界重跑左右选择，将原下标一起放入堆，未入选下标就是删除位置；额外时间仍是 O(n log n)。

允许负数时成立吗？成立，交换论证只依赖值的大小关系；需重新评估数值范围。

如果目标改成绝对差值最小？固定分界后单独最小化左和、最大化右和不再正确，需要考虑两侧可达和之间的匹配，不能直接复用此贪心。

左右保留数量不同呢？分别将堆容量设为 p 和 q，合法分界为 p ≤ k ≤ m−q；相同的分界与交换论证仍成立。
