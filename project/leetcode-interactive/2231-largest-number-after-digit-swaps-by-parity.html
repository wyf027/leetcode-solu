按奇偶性交换后的最大数字

Largest Number After Digit Swaps by Parity

只能交换同为奇数或同为偶数的数字。这样的限制下，你能把数字变得多大？

查看官方题目 ↗

01 / 题目与规则

输入一个正整数 num。每次可以选中任意两个数位，只要这两个位置上的数字奇偶性相同，就可以交换它们。可以不交换，也可以交换任意多次。返回所有可达到的整数中的最大值。

奇偶性指的是数字本身，不是数位下标；所选位置不必相邻。数字 0 是偶数。

参数与返回
largestInteger(num: integer) → integer
约束：1 ≤ num ≤ 10⁹。

02 / 官方示例

示例 1

输入：num = 1234
输出：3412

交换 1 和 3：1234 → 3214；再交换 2 和 4：3214 → 3412。1 与 4 奇偶性不同，不能直接交换。3412 是可达到的最大值。

示例 2

输入：num = 65875
输出：87655

交换 6 和 8：65875 → 85675；再交换左边的 5 与 7：85675 → 87655。允许有其他交换路径，最大值相同。

04 / 独立题解

准备好后展开，查看数字库存推演、正确性证明与四语言代码。

核心洞察：位置的奇偶类型不会改变

交换两个同奇偶数字，两个位置仍然保留原来的奇偶类型。同类位置之间又能任意交换，因此每一类数字都可自由排列。为了让整数最大，越靠左的位置，越应该放入当前剩余的同奇偶数字中最大的一个。

数字库存台 · 从高位逐格填入

每个槽位保留原数位的奇偶性。每前进一步，就从库存中取出一个最大的同类数字。金色库存格表示本步选中的数字，边框文字标明奇偶，不仅依赖颜色。

请输入 1 到 1000000000 的整数，不含前导零。载入会回到初始状态。

完整过程

  1. 把 num 转成十进制字符序列，统计 0–9 每个数字出现的次数。
  2. 维护偶数候选指针 top[0] = 8 与奇数候选指针 top[1] = 9。
  3. 从左到右读取原数位 d，用 d % 2 选择指针。若候选库存为 0，就把该指针减 2，直到找到库存。
  4. 将选中数字接到结果末尾，并减少一次库存。指针无需回退，因为库存只会减少。

例如 65875 的固定类型是「偶、奇、偶、奇、奇」。依次取 8、7、6、5、5，得到 87655。这里展示的是构造最终排列，而非逐次模拟物理交换。

正确性证明

可行性：每个位置都使用同奇偶的数字，且每次消耗一个原始库存，因此不改变数字多重集合与位置类型。同类位置内任意排列都能通过两两交换实现，构造结果可达。

最优性：假设存在比构造结果更大的可达数。取两者从左往右第一个不同的位置，此前使用的数字相同，所以当前可用库存相同。算法已经选择此位置允许的最大数字，另一个数无法在该位置放入更大的数字，矛盾。相同长度十进制数的大小由首个不同数位决定，因此算法结果最大。

边界与数值范围

  • 单个数字、重复数字、已最优排列都自然处理，允许零次交换。
  • 0 属于偶数，只能填入原本为偶数的位置。正整数首位为偶数时，原首位至少为 2，因此最大可选偶数不会是 0；首位为奇数时也不会填入 0。
  • 每个原始位置都有一个对应类型的库存需求，已填位置按同类消耗，当前类型必有剩余；指针不会在选取过程中越界。
  • 最多 10 位；唯一 10 位合法输入是 10⁹，交换后仍为 10⁹。其他输入至多 9 位，结果不超过 999999999。Java/C++ 的 32 位有符号整数与 JavaScript 的 Number 均能精确容纳。

复杂度

设 d 是数位数。统计与构造各扫描一次，两个指针总共只下降常数次，时间为 O(d + 10) = O(d)。计数数组和两个指针占 O(10)，保存原数位字符串占 O(d)，总额外空间为 O(d + 10) = O(d)。本题中 d ≤ 10。

替代方案

分别提取奇数与偶数并降序排序，再按照原位置类型依次回填，时间 O(d log d)、空间 O(d)，更直观。也可对每个位置扫描后缀并与最大同奇偶数字交换，时间 O(d²)。数字取值仅 0–9，计数库存最直接。

Java

class Solution {
    public int largestInteger(int num) {
        char[] digits = String.valueOf(num).toCharArray();
        int[] count = new int[10];
        for (char c : digits) count[c - '0']++;
        int[] top = {8, 9};
        int answer = 0;
        for (char c : digits) {
            int p = (c - '0') % 2;
            while (count[top[p]] == 0) top[p] -= 2;
            int digit = top[p];
            answer = answer * 10 + digit;
            count[digit]--;
        }
        return answer;
    }
}

var largestInteger = function(num) {
    const digits = String(num);
    const count = Array(10).fill(0);
    for (const c of digits) count[Number(c)]++;
    const top = [8, 9];
    let answer = 0;
    for (const c of digits) {
        const p = Number(c) % 2;
        while (count[top[p]] === 0) top[p] -= 2;
        const digit = top[p];
        answer = answer * 10 + digit;
        count[digit]--;
    }
    return answer;
};

class Solution:

C++

#include <string>
using namespace std;

class Solution {
public:
    int largestInteger(int num) {
        string digits = to_string(num);
        int count[10] = {};
        for (char c : digits) ++count[c - '0'];
        int top[2] = {8, 9};
        int answer = 0;
        for (char c : digits) {
            int p = (c - '0') % 2;
            while (count[top[p]] == 0) top[p] -= 2;
            int digit = top[p];
            answer = answer * 10 + digit;
            --count[digit];
        }
        return answer;
    }
};

面试追问

  • 若只能交换一次？不能直接回填全部位置。应寻找最左侧可提升位置，并与其右侧最大的同类数字交换；最大数字重复时选最靠右者。
  • 若只能交换相邻同奇偶数字？可交换范围缩小到连续同奇偶段，不能跨越另一类型，需对每段单独处理。
  • 若按模 k 分组？位置余数类型同样不变，分别维护各组库存，优先填入组内最大值。

常见错误

  • 按位置下标奇偶分组，而不是按该位置原数字的奇偶性。
  • 直接把全部数字降序排列，例如把 12 变成 21，这是非法交换。
  • 遗漏数字 0 或重复数字；应按出现次数消费库存。
  • 用 JavaScript 默认字符串排序处理一般数值集合；使用数值比较器可避免迁移到多位数场景出错。
