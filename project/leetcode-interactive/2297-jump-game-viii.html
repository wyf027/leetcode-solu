Jump Game VIII

跳跃游戏 VIII

落点有价格，跨越有条件。找到通往最后一格的最低花费。

先读规则并自行思考；算法推演与代码收在页面底部的“查看题解”中。

01 / 题目与跳跃规则

输入等长整数数组 nums 与 costs，起点为下标 0。只能向右跳，即 i < j；一次跳跃只要满足下面任意一类规则就合法：

规则 A · 落点不低于起点

nums[j] ≥ nums[i]，且所有中间位置 i < k < j 都满足 nums[k] < nums[i]。

规则 B · 落点低于起点

nums[j] < nums[i]，且所有中间位置都满足 nums[k] ≥ nums[i]。

每次落到 j 支付 costs[j]。求从 0 到 n − 1 的最小总费用；起点不收取费用。相邻位置之间没有中间元素，因此一定可以跳。

参数、返回值与约束

minCost(nums: integer[], costs: integer[]) → long

  • n == nums.length == costs.length
  • 1 ≤ n ≤ 100000
  • 0 ≤ nums[i], costs[i] ≤ 100000

官方元数据提供题名、签名与示例输入；付费题正文为空。规则及约束参考公开题面整理转述，官方题目入口需订阅查看。

02 / 官方示例

示例 1

nums = [3,2,4,4,1]
costs = [3,7,6,4,2]
输出 = 8

路线 0 → 2 → 4，依次支付 6 和 2。跨过下标 3 时，中间值 4 与出发值相等，符合规则 B。

示例 2

nums = [0,1,2]
costs = [1,1,1]
输出 = 2

路线 0 → 1 → 2，支付 1 + 1。0 → 2 被中间的 1 阻挡：它不小于起点值 0。

04 / 独立题解

核心洞察：两个“第一次”

固定起点 i：规则 A 的落点只能是右侧第一个值 ≥ nums[i] 的位置；更早出现的同类值会阻挡后面的落点。规则 B 同理，只能落到右侧第一个值 < nums[i] 的位置。因此每个点至多有两条出边。

从左到右扫描，把等待 A 类落点的下标放入栈 A（值严格递减），把等待 B 类落点的下标放入栈 B（值非递减）。遇到新位置 j 时，弹出的下标恰好第一次遇见合法落点 j。

dp[0] = 0；每弹出一个起点 i，执行 dp[j] = min(dp[j], dp[i] + costs[j])。所有边向右，扫描顺序正好也是动态规划顺序。

双栈扫描思路可参见作者的公开解法；以下解释、演示与实现为本页整理，尚未验证。

双等待栈 · 逐事件推演

青色：当前落点 · 紫色：弹出的起点

观察一个落点如何同时接收多个起点的报价。栈从左至右是栈底到栈顶；每一步只做一次扫描、弹栈或入栈。

A · 等待第一个 ≥

B · 等待第一个 <

控制区可用 ← / → 切换步骤；按钮支持 Enter / 空格。减少动态效果模式下，自动播放使用较慢间隔且无过渡动画。

完整过程

  1. 将 dp 初始化为无穷大，只有 dp[0] = 0；两个栈为空。
  2. 扫描 j。只要 A 栈顶的值 ≤ nums[j]，弹出起点 i，以 dp[i] + costs[j] 更新 dp[j]。
  3. 只要 B 栈顶的值 > nums[j]，弹出起点 i，并用相同公式更新 dp[j]。
  4. 处理完所有弹栈后，将 j 同时压入两个栈，继续向右。
  5. 返回 dp[n − 1]。不需要显式保存跳跃图。

示例 1 的逐点最优费用为 [0,7,6,10,8]。处理下标 4 时，B 栈中的 3、2、1 都能以 4 为首次严格更小的落点，候选费用分别为 12、8、9，最终取 8。

正确性说明

1. 跳跃边完整且合法

A 栈保留尚未遇到 ≥ 自身值的起点。值严格递减，因此当新值能满足某个起点时，位于其上方的更小值也会先弹出；不会漏掉可连边的起点。起点首次被弹出时，中间所有值都更小，满足 A。B 栈对称：保留尚未遇到严格更小值的起点，栈值非递减；首次弹出即满足 B。

2. 状态按依赖顺序定值

归纳假设所有 i < j 的 dp[i] 已经最优。任何到 j 的路径都以某条合法 i → j 结束，而本轮弹栈恰好枚举所有这类边。取 dp[i] + costs[j] 的最小值就得到 dp[j] 的最优值。初始 dp[0] = 0，归纳成立。

3. 最终目标

相邻边始终存在，终点必定可达。扫描完最后一个位置后，dp[n − 1] 即所求最小费用。

复杂度与边界

  • 时间 O(n)：每个下标在每个栈各进出一次。
  • 空间 O(n)：dp 数组与两个栈。
  • n = 1 返回 0；costs[0] 不计入费用。
  • 相等值在 A 中弹出，在 B 中保留；全相等只能逐格跳。
  • 费用允许为 0，不能把 0 当“未访问”。
  • 最大费用可达 9,999,900,000，Java 用 long、C++ 用 long long；JS Number 在此范围内精确，Python 整数安全。

替代方案

  • 先用单调栈生成两类 next 数组，再按下标顺序 DP：同为 O(n)，更容易把找边与求最短路分开解释，但多存两份数组。
  • 从每个点向右找两类首次落点，再 DP：最坏 O(n²)，只适合小规模教学。
  • 显式图上用 Dijkstra：费用非负可用，但增加优先队列和 O(n log n) 开销，向右有向无环图直接 DP 更简单。

常见错误

  • 把高度当作可跳距离；本题高度只参与大小关系。
  • 把 A 写成严格大于或把 B 写成小于等于，改变相等值的阻挡规则。
  • 弹栈时支付 costs[i] 而非 costs[j]，或一开始就支付 costs[0]。
  • 贪心选择当前最便宜的落点，忽略后续路径。
  • 只保存栈中的值，丢失对应下标和 dp。
  • 用 32 位整数保存总费用；或每个点只弹一次，没有使用 while。

面试追问

如何返回最优路线？ 每次严格改善 dp[j] 时保存 parent[j] = i，终点向前追溯后反转。

如果费用允许为负？ 所有边仍然向右，没有环；按下标的 DP 仍可用，但 Dijkstra 不再适用。

允许向左跳呢？ 下标顺序不再保证依赖已完成，需要重新建模边与环，不能直接套用这段 DP。

四语言完整实现

面向题目 minCost 接口，省略平台提供的输入读取入口。四份代码均为待补验证的生成稿。

Java long 返回值

import java.util.Arrays;

class Solution {
    public long minCost(int[] nums, int[] costs) {
        int n = nums.length;
        long[] dp = new long[n];
        Arrays.fill(dp, Long.MAX_VALUE / 4);
        dp[0] = 0;
        int[] a = new int[n], b = new int[n];
        int sa = 0, sb = 0;
        for (int j = 0; j < n; j++) {
            while (sa > 0 && nums[a[sa - 1]] <= nums[j]) {
                int i = a[--sa];
                dp[j] = Math.min(dp[j], dp[i] + costs[j]);
            }
            while (sb > 0 && nums[b[sb - 1]] > nums[j]) {
                int i = b[--sb];
                dp[j] = Math.min(dp[j], dp[i] + costs[j]);
            }
            a[sa++] = j;
            b[sb++] = j;
        }
        return dp[n - 1];
    }
}

JavaScript Number 精度满足约束

/**
 * @param {number[]} nums
 * @param {number[]} costs
 * @return {number}
 */
var minCost = function(nums, costs) {
    const n = nums.length;
    const dp = Array(n).fill(Infinity);
    const a = [], b = [];
    dp[0] = 0;
    for (let j = 0; j < n; j++) {
        while (a.length && nums[a[a.length - 1]] <= nums[j]) {
            const i = a.pop();
            dp[j] = Math.min(dp[j], dp[i] + costs[j]);
        }
        while (b.length && nums[b[b.length - 1]] > nums[j]) {
            const i = b.pop();
            dp[j] = Math.min(dp[j], dp[i] + costs[j]);
        }
        a.push(j);
        b.push(j);
    }
    return dp[n - 1];
};

Python 整数哨兵与任意精度整数

from typing import List

class Solution:
    def minCost(self, nums: List[int], costs: List[int]) -> int:
        n = len(nums)
        dp = [10**30] * n
        dp[0] = 0
        a, b = [], []
        for j, value in enumerate(nums):
            while a and nums[a[-1]] <= value:
                i = a.pop()
                dp[j] = min(dp[j], dp[i] + costs[j])
            while b and nums[b[-1]] > value:
                i = b.pop()
                dp[j] = min(dp[j], dp[i] + costs[j])
            a.append(j)
            b.append(j)
        return dp[-1]

C++ long long 返回值

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    long long minCost(vector<int>& nums, vector<int>& costs) {
        int n = nums.size();
        vector<long long> dp(n, 1LL << 60);
        vector<int> a, b;
        dp[0] = 0;
        for (int j = 0; j < n; ++j) {
            while (!a.empty() && nums[a.back()] <= nums[j]) {
                int i = a.back();
                a.pop_back();
                dp[j] = min(dp[j], dp[i] + costs[j]);
            }
            while (!b.empty() && nums[b.back()] > nums[j]) {
                int i = b.back();
                b.pop_back();
                dp[j] = min(dp[j], dp[i] + costs[j]);
            }
            a.push_back(j);
            b.push_back(j);
        }
        return dp[n - 1];
    }
};
