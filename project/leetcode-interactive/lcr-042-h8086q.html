最近的请求次数

实现 RecentCounter：每次请求 ping(t) 返回时间区间 [t - 3000, t] 内（含边界）的请求数。

核心思路：只保留仍在窗口里的请求

  1. 1用队列按时间顺序保存已经到来的请求。题目保证每个 t 比上一次更大。
  2. 2新请求进队后，持续移除所有小于 t - 3000 的队首元素。
  3. 3剩余队列恰好是区间 [t - 3000, t] 内的全部请求，长度就是答案。

时间复杂度

均摊 O(1) / 次

每个请求最多入队、出队一次。

空间复杂度

O(W)

W 为当前 3000ms 窗口内请求数。

边界别漏掉

包含左端点：时间为 t - 3000 的请求仍在窗口中，淘汰条件是严格小于。

单调时间：队首永远是最早请求，所以过期元素只会从队首连续移除。

不用遍历历史：离开窗口的请求不会再次回来，删掉后无需保留。

队列只向两端移动，避免重复扫描。

在当前 t 到来时，队列先追加它。因为每个时间戳单调递增，过期请求一定连续出现在队首；移除所有 < t - 3000 的值后，每个保留元素都满足 t - 3000 ≤ x ≤ t，且没有任何符合条件的请求留在队外。因此队列长度正是题目所求。
