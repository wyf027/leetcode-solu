分配重复整数

一批相同数字只能按“整组容量”分给若干顾客。真正的挑战，是在至多 10 份订单之间找到可行的子集组合。

m ≤ 10 订单数量很少，正是用一个二进制位代表一位顾客的信号。

题目到底要求什么？

可以不使用部分整数，但每位顾客拿到的数字必须完全相同，且数量恰好匹配订单。

任务

给定整数数组 nums 和订单数组 quantity。数组中至多出现 50 种不同的值。判断能否从 nums 中取数满足全部顾客。

  • 第 i 位顾客必须恰好获得 quantity[i] 个整数。
  • 同一位顾客拿到的所有整数必须相等。
  • 不同顾客可以拿到同一个值，只要该值的总出现次数足够。

函数签名

canDistribute(nums: integer[], quantity: integer[]) → boolean

关键不是数值本身，而是每种数值在 nums 中出现了多少次。

1 ≤ n ≤ 10⁵n = nums.length
1 ≤ nums[i] ≤ 1000nums 中至多 50 种不同值
1 ≤ m ≤ 10m = quantity.length
1 ≤ quantity[i] ≤ 10⁵每位顾客的精确需求
允许剩余nums 不要求全部分完
返回 boolean只判断是否存在一种方案

官方示例

示例 1

输入：nums = [1,2,3,4], quantity = [2] 输出：false

每个值都只出现一次，无法交付两个相同整数。

示例 2

输入：nums = [1,2,3,3], quantity = [2] 输出：true

把 [3,3] 给顾客即可，1 和 2 可以不用。

示例 3

输入：nums = [1,1,2,2], quantity = [2,2] 输出：true

两位顾客分别获得两个 1 和两个 2。

分配控制台

用一组小数据观察：每种数字的出现次数如何承载一个顾客子集。

步骤 1 / 6

数字库存（按出现次数压缩）

顾客订单

可达掩码 dp[mask]

演示数据：nums = [1,1,1,2,2,3,3]，quantity = [2,2,1]。掩码从右到左对应顾客 C0、C1、C2。

先自己想一想

提示：先统计频次，再问“这一份频次能覆盖哪组顾客？”

题解：频次背包 × 子集状态

把每一种数值看成一只容量有限、不可拆成不同值的“箱子”；一只箱子可以一次满足若干顾客。

核心洞察：数值是什么并不重要，只需要它的出现次数。订单数 m ≤ 10，所以可用长度为 2^m 的位掩码表示哪些顾客已经满足。

完整过程

  1. 统计 nums 中每个不同数值的出现次数，得到容量数组 counts。
  2. 预处理每个顾客子集的总需求：need[mask]。
  3. 令 dp[mask] 表示已经处理过的容量能否恰好满足 mask 中的顾客，初始只有 dp[0] = true。
  4. 处理一个容量 cap 时，从每个可达状态枚举尚未满足顾客的所有子集 sub。若 need[sub] ≤ cap，则新状态 mask | sub 可达。
  5. 所有顾客对应的全掩码可达时返回 true。

为什么它正确？

不漏解：任意合法分配中，每种数值会服务某个顾客子集，且该子集总需求不超过此数值的出现次数。转移会枚举这个子集，因此能沿着各数值对应的选择重建整套合法分配。

不造假：一次转移只把尚未满足的顾客加入状态，并检查其需求之和不超过当前同值库存；因此每位新顾客都能拿到足量且相同的整数。不同容量只代表不同数值，不会重复使用库存。

归纳：处理前 dp 准确描述旧容量能满足的集合；完成所有合法子集转移后，新 dp 也准确描述加入当前容量后的集合。由归纳法，全掩码可达当且仅当存在合法分配。

时间复杂度O(n + m·2^m + k·3^m)k 为不同数值个数，k ≤ 50
空间复杂度O(2^m + k)频次数组、子集和与两层状态

边界情况

  • 单个订单大于所有频次：必定失败。
  • 订单总量大于 nums.length：可提前失败。
  • 只有一位顾客：检查是否有任一频次足够。
  • 同一容量可以同时满足多位顾客；不能只做“一容量配一顾客”的贪心。
  • 剩余库存无需用完，因此判断是 need[sub] ≤ cap。

替代方案

排序 + 回溯：把订单从大到小尝试放入各频次桶，并跳过相同剩余容量。实现直观，剪枝好时很快，但最坏界限较弱。

记忆化搜索：用“第几个容量 + 已满足掩码”记忆结果，本质上与当前 DP 相同，适合提前找到答案。

为什么不用普通贪心：大订单占用哪个频次会影响多个小订单能否合并；局部最优没有交换性质。

四语言完整实现

import java.util.*;

class Solution {
    public boolean canDistribute(int[] nums, int[] quantity) {
        Map<Integer, Integer> frequency = new HashMap<>();
        for (int value : nums) {
            frequency.merge(value, 1, Integer::sum);
        }

        int m = quantity.length;
        int size = 1 << m;
        int[] need = new int[size];
        for (int mask = 1; mask < size; mask++) {
            int bit = Integer.numberOfTrailingZeros(mask);
            need[mask] = need[mask ^ (1 << bit)] + quantity[bit];
        }

        boolean[] dp = new boolean[size];
        dp[0] = true;
        int full = size - 1;
        for (int capacity : frequency.values()) {
            boolean[] next = dp.clone();
            for (int mask = 0; mask < size; mask++) {
                if (!dp[mask]) continue;
                int remaining = full ^ mask;
                for (int sub = remaining; sub > 0; sub = (sub - 1) & remaining) {
                    if (need[sub] <= capacity) next[mask | sub] = true;
                }
            }
            dp = next;
            if (dp[full]) return true;
        }
        return false;
    }
}

 * @param {number[]} nums
 * @param {number[]} quantity
 * @return {boolean}
 */
var canDistribute = function(nums, quantity) {
    const frequency = new Map();
    for (const value of nums) {
        frequency.set(value, (frequency.get(value) || 0) + 1);
    }

    const m = quantity.length;
    const size = 1 << m;
    const need = new Int32Array(size);
    for (let mask = 1; mask < size; mask++) {
        const lowbit = mask & -mask;
        const bit = 31 - Math.clz32(lowbit);
        need[mask] = need[mask ^ lowbit] + quantity[bit];
    }

    let dp = new Uint8Array(size);
    dp[0] = 1;
    const full = size - 1;
    for (const capacity of frequency.values()) {
        const next = dp.slice();
        for (let mask = 0; mask < size; mask++) {
            if (!dp[mask]) continue;
            const remaining = full ^ mask;
            for (let sub = remaining; sub; sub = (sub - 1) & remaining) {
                if (need[sub] <= capacity) next[mask | sub] = 1;
            }
        }
        dp = next;
        if (dp[full]) return true;
    }
    return false;
};
from collections import Counter
from typing import List


class Solution:
    def canDistribute(self, nums: List[int], quantity: List[int]) -> bool:
        capacities = Counter(nums).values()
        m = len(quantity)
        size = 1 << m
        full = size - 1

        need = [0] * size
        for mask in range(1, size):
            lowbit = mask & -mask
            bit = lowbit.bit_length() - 1
            need[mask] = need[mask ^ lowbit] + quantity[bit]

        dp = [False] * size
        dp[0] = True
        for capacity in capacities:
            nxt = dp[:]
            for mask in range(size):
                if not dp[mask]:
                    continue
                remaining = full ^ mask
                sub = remaining
                while sub:
                    if need[sub] <= capacity:
                        nxt[mask | sub] = True
                    sub = (sub - 1) & remaining
            dp = nxt
            if dp[full]:
                return True
        return False
class Solution {
public:
    bool canDistribute(vector<int>& nums, vector<int>& quantity) {
        unordered_map<int, int> frequency;
        for (int value : nums) ++frequency[value];

        int m = quantity.size();
        int size = 1 << m;
        int full = size - 1;
        vector<int> need(size, 0);
        for (int mask = 1; mask < size; ++mask) {
            int bit = __builtin_ctz(mask);
            need[mask] = need[mask ^ (1 << bit)] + quantity[bit];
        }

        vector<char> dp(size, false);
        dp[0] = true;
        for (auto const& entry : frequency) {
            int capacity = entry.second;
            vector<char> next = dp;
            for (int mask = 0; mask < size; ++mask) {
                if (!dp[mask]) continue;
                int remaining = full ^ mask;
                for (int sub = remaining; sub; sub = (sub - 1) & remaining) {
                    if (need[sub] <= capacity) next[mask | sub] = true;
                }
            }
            dp.swap(next);
            if (dp[full]) return true;
        }
        return false;
    }
};

面试追问

  • 为什么是 3^m？对每个顾客，枚举一对“已满足集合 / 当前选择子集”时有三种归属：已满足、这次选择、两者都不在。
  • 能否提前退出？可以；全掩码一旦可达立即返回。
  • 如果 m 很大怎么办？位掩码失去优势，需要研究频次与订单值域、网络流或近似/参数化方案。
  • 如何输出具体分配？为首次到达的状态记录前驱容量索引、旧掩码和所选子集，再从全掩码回溯。

常见错误

  • 把一个顾客的订单拆到两个不同数值中，违反“全部相同”。
  • 原地更新 dp 后继续使用新状态，导致同一份容量被重复消费；必须从上一层 dp 转移到 next。
  • 只枚举单个顾客，没有考虑一份大频次同时服务多人。
  • 写成 need[sub] == capacity，错误地要求库存用完。
  • 枚举所有 2^m 子集却忘了限制为未满足集合的子集。
