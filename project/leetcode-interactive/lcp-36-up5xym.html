最多牌组数

先把相同牌计数。处理数字 v 时，只需记住前两种数字各开启了多少条尚未完成的顺子；每个数量只需保留 0、1、2，形成常数大小的 3×3 动态规划。

题意

每组三张牌，可以是连续数字 [x,x+1,x+2]，也可以是三张相同数字。每张牌至多使用一次，求最多组成多少组。

tiles=[2,2,2,3,4]
输出：1（刻子 [2,2,2] 或顺子 [2,3,4]）

INTERACTIVE / 3×3 DP

顺子欠账沿数字轴移动

状态 dp[a][b]

a：从 v-2 开始、现在必须用一张 v 才能完成的顺子数；b：从 v-1 开始、使用 v 后还需要 v+1 的顺子数。

SOLUTION / 默认隐藏

压缩计数动态规划

转移

当前有 cnt 张 v，先支付 a+b 张给已有顺子；再枚举新开 c 条顺子。剩余牌组成刻子。贡献为 a + floor((cnt-a-b-c)/3)，新状态是 (b,c)。

为什么 c≤2

若同时新开 3 条同起点顺子，把这三张 v 改成一个刻子，并对后两种数字做相同替换，组数不减。因此仅需 0..2。数字断档时只允许无欠账状态继续。

排序计数 O(n log n)，每种数字仅做 27 次常数转移；空间 O(k) 保存计数，DP 本身 O(1)。末尾补两个 cnt=0，强制结清未完成顺子。 

import java.util.*;
class Solution {
 public int maxGroupNumber(int[] tiles) {
  Arrays.sort(tiles); List<Integer> values=new ArrayList<>(),counts=new ArrayList<>();
  for(int x:tiles){int z=values.size();if(z==0||values.get(z-1)!=x){values.add(x);counts.add(1);}else counts.set(z-1,counts.get(z-1)+1);}
  int NEG=-1<<28;int[][] dp=new int[3][3];for(int[] r:dp)Arrays.fill(r,NEG);dp[0][0]=0;int last=values.get(0)-1;
  for(int i=0;i<values.size();i++){int v=values.get(i);if(v>last+1){int done=dp[0][0];for(int[] r:dp)Arrays.fill(r,NEG);dp[0][0]=done;}dp=step(dp,counts.get(i),NEG);last=v;}
  dp=step(dp,0,NEG);dp=step(dp,0,NEG);return dp[0][0];
 }
 int[][] step(int[][] dp,int cnt,int neg){int[][] nd=new int[3][3];for(int[]r:nd)Arrays.fill(r,neg);for(int a=0;a<3;a++)for(int b=0;b<3;b++)if(dp[a][b]>neg)for(int c=0;c<3;c++)if(a+b+c<=cnt)nd[b][c]=Math.max(nd[b][c],dp[a][b]+a+(cnt-a-b-c)/3);return nd;}
}

from collections import Counter
class Solution:
 def maxGroupNumber(self, tiles):
  neg=-10**9;dp=[[neg]*3 for _ in range(3)];dp[0][0]=0;last=None
  for v,cnt in sorted(Counter(tiles).items()):
   if last is not None and v>last+1:
    done=dp[0][0];dp=[[neg]*3 for _ in range(3)];dp[0][0]=done
   nd=[[neg]*3 for _ in range(3)]
   for a in range(3):
    for b in range(3):
     for c in range(3):
      if dp[a][b]>neg and a+b+c<=cnt:nd[b][c]=max(nd[b][c],dp[a][b]+a+(cnt-a-b-c)//3)
   dp=nd;last=v
  for _ in range(2):
   nd=[[neg]*3 for _ in range(3)]
   for a in range(3):
    for b in range(3):
     if a+b==0:nd[b][0]=max(nd[b][0],dp[a][b]+a)
   dp=nd
  return dp[0][0]
