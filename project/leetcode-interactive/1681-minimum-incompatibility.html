把相同大小的若干组拼出来，同时让每组的“跨度”尽可能小。先理解规则并亲手走完一次分组，再决定是否展开完整题解。

Minimum Incompatibility非会员题n ≤ 16
01 · Problem

题目要你做什么？

给定整数数组 nums 和整数 k，把数组中的所有元素分配到 k 个大小相等的子集。同一个子集内不能出现相同的数。

一个子集的不兼容性
最大值 − 最小值

目标是最小化全部子集的不兼容性之和；如果无论如何都不能满足条件，返回 -1。数组中的每个位置只能使用一次，子集内部的顺序不重要。

分组检查单
  • 每组恰有 nums.length / k 个元素
  • 同一组内数值互不相同
  • 所有数组位置恰好被使用一次
  • 最小化各组极差之和

04 · Solution

位掩码动态规划

核心洞察

把“元素”看成数组位置。 两个值即使相同，也对应不同的位。先枚举所有大小为 m = n / k、内部值互异的合法位置集合，并记录其代价；再用位掩码 DP 把这些合法组无重叠地拼满整个数组。

令 dp[mask] 表示恰好使用 mask 中这些位置时的最小代价。初始 dp[0] = 0。从一个完整分组边界出发，挑选与 mask 不相交的合法组 g，更新 dp[mask | g]。

完整过程

  1. 先做不可能性筛选。 如果某个数出现超过 k 次，它至少有两个副本必须落在同一组，直接返回 -1。
  2. 枚举合法组。 遍历所有恰有 m 个 1 的掩码；检查对应数值是否互异。合法时计算 max − min。
  3. 建立按位置索引的候选表。 把每个合法组放入它所包含位置的候选列表，便于后续只看含某个固定位置的组。
  4. 推进 DP。 只处理已选数量是 m 的倍数的状态。找到第一个未使用位置 p，仅尝试包含 p 的合法组，避免同一组序列的排列被重复搜索。
  5. 读取答案。 全 1 掩码的值若仍为无穷大，则返回 -1；否则返回该最小值。

正确性证明

引理 1：预处理恰好包含全部可用的小组。

枚举了所有大小为 m 的位置子集，并且仅在对应数值互异时保留，所以合法组不漏、非法组不进；记录的最大值减最小值正是该组的不兼容性。

引理 2：DP 能表示每一种合法划分。

对任意合法划分，在任一中间状态，第一个未使用位置必属于余下某个合法组。算法会尝试所有包含该位置且与当前状态不相交的合法组，因此可以沿着该划分逐组到达全 1 状态。固定第一个未使用位置只去除了组顺序的重复，没有去除任何划分。

引理 3：每个可达状态保存最小代价。

归纳来看，空状态代价为 0；每次转移把一个合法且不重叠组的真实代价加入已有最优值，并对所有前驱取最小。因此新状态也保存其全部合法构造中的最小代价。

结论

由引理 1–3，全 1 状态覆盖所有且仅覆盖合法划分，并取其中代价最小者；不可达时返回 −1，故算法正确。

边界情况

  • k = n：每组一个数，不兼容性全部为 0。
  • 某值出现次数大于 k：必定无解。
  • 存在重复值但频次不超过 k：不同副本可以进入不同组，不能直接判无解。
  • 最终状态不可达：即使频次筛选通过，也以 -1 返回。

复杂度

时间O(3ⁿ)枚举组与状态组合的宽松上界；n ≤ 16
空间O(2ⁿ + G·n)DP 与合法组索引；G 为合法组数量

预处理检查所有掩码可写作 O(2ⁿ·n)。实际转移因“必须包含第一个未使用位置”和固定组大小而明显少于朴素枚举。

替代方案

方案做法取舍
记忆化回溯按组搜索，状态同样是已使用位置 mask写法直观，但剪枝与去重更容易遗漏
逐元素装箱维护 k 个组的内容与代价状态维度大，组之间的对称性造成大量重复
合法组 + DP先过滤组，再拼接掩码结构清晰，最适合 n ≤ 16

import java.util.*;

class Solution {
    public int minimumIncompatibility(int[] nums, int k) {
        int n = nums.length, size = n / k;
        Map<Integer, Integer> freq = new HashMap<>();
        for (int x : nums) {
            int count = freq.getOrDefault(x, 0) + 1;
            if (count > k) return -1;
            freq.put(x, count);
        }

        int full = (1 << n) - 1;
        int[] cost = new int[1 << n];
        Arrays.fill(cost, -1);
        List<Integer>[] groupsAt = new ArrayList[n];
        for (int i = 0; i < n; i++) groupsAt[i] = new ArrayList<>();

        for (int mask = 0; mask <= full; mask++) {
            if (Integer.bitCount(mask) != size) continue;
            Set<Integer> seen = new HashSet<>();
            int min = Integer.MAX_VALUE, max = Integer.MIN_VALUE;
            boolean valid = true;
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) == 0) continue;
                if (!seen.add(nums[i])) { valid = false; break; }
                min = Math.min(min, nums[i]);
                max = Math.max(max, nums[i]);
            }
            if (!valid) continue;
            cost[mask] = max - min;
            for (int i = 0; i < n; i++)
                if ((mask & (1 << i)) != 0) groupsAt[i].add(mask);
        }

        int inf = 1_000_000_000;
        int[] dp = new int[1 << n];
        Arrays.fill(dp, inf);
        dp[0] = 0;
        for (int mask = 0; mask <= full; mask++) {
            if (dp[mask] == inf || Integer.bitCount(mask) % size != 0 || mask == full) continue;
            int first = Integer.numberOfTrailingZeros(full ^ mask);
            for (int group : groupsAt[first]) {
                if ((mask & group) == 0) {
                    int next = mask | group;
                    dp[next] = Math.min(dp[next], dp[mask] + cost[group]);
                }
            }
        }
        return dp[full] == inf ? -1 : dp[full];
    }
}

var minimumIncompatibility = function(nums, k) {
    const n = nums.length;
    const size = n / k;
    const freq = new Map();
    for (const x of nums) {
        const count = (freq.get(x) || 0) + 1;
        if (count > k) return -1;
        freq.set(x, count);
    }

    const limit = 1 << n;
    const full = limit - 1;
    const cost = new Int32Array(limit);
    cost.fill(-1);
    const groupsAt = Array.from({ length: n }, () => []);

    for (let mask = 0; mask < limit; mask++) {
        let bits = 0;
        for (let x = mask; x; x &= x - 1) bits++;
        if (bits !== size) continue;
        const seen = new Set();
        let min = Infinity, max = -Infinity, valid = true;
        for (let i = 0; i < n; i++) {
            if ((mask & (1 << i)) === 0) continue;
            if (seen.has(nums[i])) { valid = false; break; }
            seen.add(nums[i]);
            min = Math.min(min, nums[i]);
            max = Math.max(max, nums[i]);
        }
        if (!valid) continue;
        cost[mask] = max - min;
        for (let i = 0; i < n; i++)
            if (mask & (1 << i)) groupsAt[i].push(mask);
    }

    const dp = new Array(limit).fill(Infinity);
    dp[0] = 0;
    for (let mask = 0; mask < limit; mask++) {
        if (!Number.isFinite(dp[mask]) || mask === full) continue;
        let used = 0;
        for (let x = mask; x; x &= x - 1) used++;
        if (used % size !== 0) continue;
        const remaining = full ^ mask;
        let first = 0;
        while ((remaining & (1 << first)) === 0) first++;
        for (const group of groupsAt[first]) {
            if ((mask & group) !== 0) continue;
            const next = mask | group;
            dp[next] = Math.min(dp[next], dp[mask] + cost[group]);
        }
    }
    return Number.isFinite(dp[full]) ? dp[full] : -1;
};
from collections import Counter
from typing import List


class Solution:
    def minimumIncompatibility(self, nums: List[int], k: int) -> int:
        n = len(nums)
        size = n // k
        if max(Counter(nums).values()) > k:
            return -1

        limit = 1 << n
        full = limit - 1
        cost = [-1] * limit
        groups_at = [[] for _ in range(n)]

        for mask in range(limit):
            if mask.bit_count() != size:
                continue
            values = [nums[i] for i in range(n) if mask & (1 << i)]
            if len(set(values)) != size:
                continue
            cost[mask] = max(values) - min(values)
            for i in range(n):
                if mask & (1 << i):
                    groups_at[i].append(mask)

        inf = float("inf")
        dp = [inf] * limit
        dp[0] = 0
        for mask in range(limit):
            if dp[mask] == inf or mask == full or mask.bit_count() % size:
                continue
            remaining = full ^ mask
            first = (remaining & -remaining).bit_length() - 1
            for group in groups_at[first]:
                if mask & group:
                    continue
                nxt = mask | group
                dp[nxt] = min(dp[nxt], dp[mask] + cost[group])

        return -1 if dp[full] == inf else dp[full]
#include <algorithm>
#include <climits>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    int minimumIncompatibility(vector<int>& nums, int k) {
        int n = nums.size(), size = n / k;
        unordered_map<int, int> freq;
        for (int x : nums) if (++freq[x] > k) return -1;

        int limit = 1 << n, full = limit - 1;
        vector<int> cost(limit, -1);
        vector<vector<int>> groupsAt(n);
        for (int mask = 0; mask < limit; ++mask) {
            if (__builtin_popcount((unsigned)mask) != size) continue;
            unordered_set<int> seen;
            int lo = INT_MAX, hi = INT_MIN;
            bool valid = true;
            for (int i = 0; i < n; ++i) if (mask & (1 << i)) {
                if (!seen.insert(nums[i]).second) { valid = false; break; }
                lo = min(lo, nums[i]);
                hi = max(hi, nums[i]);
            }
            if (!valid) continue;
            cost[mask] = hi - lo;
            for (int i = 0; i < n; ++i)
                if (mask & (1 << i)) groupsAt[i].push_back(mask);
        }

        const int INF = 1e9;
        vector<int> dp(limit, INF);
        dp[0] = 0;
        for (int mask = 0; mask < limit; ++mask) {
            if (dp[mask] == INF || mask == full ||
                __builtin_popcount((unsigned)mask) % size != 0) continue;
            int remaining = full ^ mask;
            int first = __builtin_ctz((unsigned)remaining);
            for (int group : groupsAt[first]) {
                if (mask & group) continue;
                int next = mask | group;
                dp[next] = min(dp[next], dp[mask] + cost[group]);
            }
        }
        return dp[full] == INF ? -1 : dp[full];
    }
};

面试追问

  • 为什么固定第一个未使用位置？ 每个完整划分都必须覆盖它，这样不会漏解，却能消除按不同顺序挑选同一批组的重复。
  • 频次不超过 k 为什么只是必要条件？ 它排除了显然冲突，但剩余元素的组合结构仍可能使全 1 状态不可达。
  • 如果 n 增长到 30？ 2ⁿ 状态已经不可接受，需要利用值域、组大小或图结构寻找新的性质，不能直接放大本方案。

常见错误

  • 对数值去重后再做 mask，丢失相同值在不同位置上的多个副本。
  • 只检查组大小，不检查组内值是否重复。
  • 从任意未用组转移，导致组顺序产生大量等价搜索。
  • 使用新组覆盖旧状态而不是取 min。
  • 把未到达的全 1 状态直接当成 0，而不是返回 -1。
