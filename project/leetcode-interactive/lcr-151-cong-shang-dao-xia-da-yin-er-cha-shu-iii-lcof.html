彩灯装饰记录 III

用一棵树的层次，记录彩灯的左右交替排列。先读题、亲手推演；题解默认收起，随时可以展开。

二叉树广度优先搜索双端队列

题意

给定一棵二叉树的根节点 root，请按从上到下的层序遍历记录每一层的节点值。第 1 层从左到右记录，第 2 层从右到左记录，之后每层交替方向，最终返回二维数组。

示例 1

root = [3,9,20,null,null,15,7]

输出：[[3],[20,9],[15,7]]

第二层需要反向记录。

示例 2

root = [1]

输出：[[1]]

只有一层时，方向交替不会改变结果。

约束

  • 节点总数在 0 到 1000 的范围内。
  • 节点值在 -1000 到 1000 的范围内。
  • 空树应返回空二维数组。

先自己推一遍

示例 1 的每层节点依次为：[3] → [9,20] → [15,7]。哪一层需要从右向左放入结果？

核心洞察

层序遍历天然把同一层聚在一起。每处理完一层，根据层号决定正向追加或反向插入；最简洁的实现是：始终按队列出队顺序收集一层，遇到反向层再反转该层数组。

过程

  1. 若 root 为空，返回空数组。
  2. 队列初始化为根节点，设置 leftToRight = true。
  3. 每轮固定当前队列长度，只弹出这一层的节点，并把孩子入队。
  4. 若方向为反向，翻转当前层；加入答案后切换方向。

边界

空树、单节点树、只有左/右孩子的链式树，以及节点值为负数时逻辑均相同。务必在每层开始时保存队列长度，避免把下一层混入本层。

复杂度

时间 O(n)；队列与结果所需额外空间在最宽层可达 O(n)。

替代方案

可用双端队列按方向从两端插入，省去每层翻转；但在 JavaScript 中频繁 shift() 可能退化，建议用头指针模拟队列。

易错点

  • 把“反向输出”误写成“从右孩子先入队”，会破坏下一层的结构。
  • 每次出队都判断方向，容易使同层节点顺序混乱。
  • 忘记空根节点的返回值。

追问

如果要求流式输出每层结果，应如何在不保存全部答案的前提下交给回调？如果树极宽，如何评估队列峰值内存？

// Java
class Solution {
    public List<List<Integer>> decorateRecord(TreeNode root) {
        List<List<Integer>> ans = new ArrayList<>();
        if (root == null) return ans;
        Queue<TreeNode> q = new LinkedList<>(); q.offer(root);
        boolean leftToRight = true;
        while (!q.isEmpty()) {
            int size = q.size(); List<Integer> level = new ArrayList<>();
            for (int i = 0; i < size; i++) { TreeNode node = q.poll(); level.add(node.val); if (node.left != null) q.offer(node.left); if (node.right != null) q.offer(node.right); }
            if (!leftToRight) Collections.reverse(level);
            ans.add(level); leftToRight = !leftToRight;
        } return ans;
    }
}

var decorateRecord = function(root) {
  if (!root) return [];
  const ans = [], queue = [root]; let head = 0, leftToRight = true;
  while (head < queue.length) {
    const end = queue.length, level = [];
    while (head < end) { const node = queue[head++]; level.push(node.val); if (node.left) queue.push(node.left); if (node.right) queue.push(node.right); }
    if (!leftToRight) level.reverse();
    ans.push(level); leftToRight = !leftToRight;
  } return ans;
};

class Solution:
    def decorateRecord(self, root: TreeNode) -> List[List[int]]:
        if not root: return []
        ans, queue, left_to_right = [], deque([root]), True
        while queue:
            level = []
            for _ in range(len(queue)):
                node = queue.popleft(); level.append(node.val)
                if node.left: queue.append(node.left)
                if node.right: queue.append(node.right)
            ans.append(level if left_to_right else level[::-1])
            left_to_right = not left_to_right
        return ans

class Solution {
public:
    vector<vector<int>> decorateRecord(TreeNode* root) {
        if (!root) return {};
        vector<vector<int>> ans; queue<TreeNode*> q; q.push(root);
        bool leftToRight = true;
        while (!q.empty()) {
            int size = q.size(); vector<int> level;
            while (size--) { auto node = q.front(); q.pop(); level.push_back(node->val); if (node->left) q.push(node->left); if (node->right) q.push(node->right); }
            if (!leftToRight) reverse(level.begin(), level.end());
            ans.push_back(level); leftToRight = !leftToRight;
        } return ans;
    }
};
