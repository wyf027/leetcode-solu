LEETCODE 2582

递枕头
Pass the Pillow

一只枕头在队伍中逐秒移动，抵达端点后立即折返。给定人数与经过的秒数，找出此刻拿着枕头的人。

难度：简单 参数：n, time 返回：整数编号
1234

方向会变，队伍不会动。先用动画建立直觉，再决定是否展开题解。

Problem

题目说明

编号为 1 到 n 的人站成一排。第 1 个人起初持有枕头，每过一秒向当前方向相邻的人传递一次；到达任一端点后，方向反转。

任务

给定两个正整数 n 和 time，返回经过 time 秒后持有枕头的人的编号。

约束

  • 2 ≤ n ≤ 1000
  • 1 ≤ time ≤ 1000

示例 1

输入：n = 4, time = 5
输出：2
解释：1 → 2 → 3 → 4 → 3 → 2；5 秒后由第 2 个人持有。

示例 2

输入：n = 3, time = 2
输出：3
解释：1 → 2 → 3；2 秒后由第 3 个人持有。

Solution

Walkthrough

折返运动，可以按“趟”计算

核心洞察

枕头从一个端点走到另一个端点，恰好需要 n - 1 秒。把总时间拆成若干完整的“单程”和剩余步数：偶数趟后从左端出发，奇数趟后从右端出发。

span = n - 1, trips = time / span, offset = time % span

边界与复杂度

  • time 正好是 n - 1 的倍数时，offset = 0，端点由趟数奇偶决定。
  • n = 2 时每秒都换人，公式仍成立。
  • 时间复杂度 O(1)，空间复杂度 O(1)。

完整过程

  1. 令单程长度 span = n - 1。
  2. 计算完整单程数 trips = time / span 与当前单程内步数 offset = time % span。
  3. 若 trips 为偶数，当前从左向右，答案是 offset + 1。
  4. 若 trips 为奇数，当前从右向左，答案是 n - offset。

正确性证明

  1. 相邻两人之间传递一次耗时 1 秒，因此从编号 1 到编号 n（或反向）恰好经过 n - 1 次传递。
  2. 每完成一趟，枕头位于另一个端点且方向反转，所以偶数趟后位于左端并向右，奇数趟后位于右端并向左。
  3. 剩余 offset 秒内不会再次越过端点；向右时位置为 1 + offset，向左时为 n - offset。
  4. 两种趟数奇偶覆盖全部情况，故算法总能返回 time 秒后的正确持有者。

Code

四种语言

class Solution {
    public int passThePillow(int n, int time) {
        int span = n - 1;
        int trips = time / span;
        int offset = time % span;
        return trips % 2 == 0 ? offset + 1 : n - offset;
    }
}

替代方案

逐秒模拟：维护当前位置和方向，每秒移动一步，到端点时反向。它直观且复杂度为 O(time)。

完整周期折叠：周期为 2(n - 1)。令 r = time % period，答案可写成 min(r, period - r) + 1，同样是 O(1)。

常见错误

  • 把单程长度误写成 n；实际只有 n - 1 条相邻间隔。
  • 到端点后多停一秒；题意要求下一秒立即向反方向传递。
  • 只对余数取模，却没有根据完整单程数判断方向。

面试追问

  • 如果编号从 0 开始？ 向右时直接返回 offset，向左时返回 n - 1 - offset。
  • 如果 time 很大？ 公式只做常数次运算；在定长整数语言中，根据输入范围选择足够大的整数类型。
  • 如何输出完整路径？ 必须逐秒生成持有者，输出本身需要 O(time) 时间；可复用模拟法。
