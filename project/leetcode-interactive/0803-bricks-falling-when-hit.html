Problem

题意

给定一个 m × n 的二元网格 grid：1 表示砖块，0 表示空白。一块砖是稳定的，当且仅当它直接位于顶部一行，或它通过上下左右相邻的砖块连接到某块稳定砖。

数组 hits 给出依次敲除的位置。执行第 i 次敲击时，hits[i] = [rowᵢ, colᵢ] 处的砖块若存在就被移除；由此失去稳定性的其他砖块会立即掉落并从网格中消失，不会落到别的砖块上。

返回值：返回整数数组 result，其中 result[i] 是第 i 次敲击后掉落的砖块数量。被直接敲掉的那一块不计入“掉落”；若敲中空白，则本次没有砖块掉落。

函数参数

hitBricks(grid: integer[][], hits: integer[][]) → integer[] grid: m × n 的 0/1 矩阵 hits: 每项为 [row, col] 的敲击序列 返回: 每次敲击造成的掉落数量
Official examples

官方示例

示例 1

输入：
grid = [[1,0,0,0],
        [1,1,1,0]]
hits = [[1,0]]

输出：
[2]

敲掉 [1,0] 后，第二行右侧两块砖失去与顶部的连接，因此掉落。

示例 2

输入：
grid = [[1,0,0,0],
        [1,1,0,0]]
hits = [[1,1],[1,0]]

输出：
[0,0]

第一次只敲掉支线末端，主干仍稳定；第二次直接敲掉剩余下方砖块，两次都没有额外砖块掉落。

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 200
  • grid[i][j] 为 0 或 1
  • 1 ≤ hits.length ≤ 4 × 10⁴
  • hits[i].length == 2
  • 0 ≤ xᵢ ≤ m - 1
  • 0 ≤ yᵢ ≤ n - 1
  • 所有 (xᵢ, yᵢ) 互不相同

Solution

题解：逆序恢复 + 并查集

核心洞察

正向敲掉一块砖后，要找出所有因此与顶部断开的砖，删除操作会让连通性变得难维护。把时间倒过来则相反：先把所有将被敲击的砖移除，再从最后一次敲击开始逐块装回。每次装回只会合并连通块，正好适合并查集。

新建一个“虚拟屋顶”节点，把顶部一行所有现存砖块与它相连。某块砖稳定，当且仅当它和虚拟屋顶属于同一个集合。装回一块砖前后，屋顶集合增加的节点数减去装回砖本身，就是对应正向敲击时掉落的砖数。

完整过程

  1. 复制网格，并在副本中移除所有命中位置上原本存在的砖。
  2. 为副本中剩余砖块建立并查集，顶部砖连接虚拟屋顶。
  3. 倒序遍历 hits；若原位置是空白，答案记为 0。
  4. 记录屋顶集合大小，装回砖并与四邻及屋顶合并，再用规模差计算答案。
before = size(roof)
restore current brick and union its neighbors
after  = size(roof)
answer[i] = max(0, after - before - 1)

减去的 1 是刚装回的砖；它在正向过程中是被直接敲掉的，不属于随后“掉落”的砖。

正确性证明

  1. 稳定性等价：把顶部一行连接到虚拟屋顶后，一块现存砖与虚拟屋顶连通，当且仅当它能通过四向砖路径到达顶部，也就是它稳定。
  2. 逆向状态对应：处理倒序位置 i 前，并查集描述的是所有敲击都已发生、随后已倒序恢复 i+1…h-1 后的网格。这与正向第 i 次敲击刚完成后的保留砖集合相对应。
  3. 规模差计数：装回 hits[i] 后，新进入屋顶集合的旧砖，恰好是正向敲掉该砖后失去稳定性的砖。规模增量还包含装回砖自身，因此减一；若没有新增旧砖，结果取 0。
  4. 归纳结论：初始并查集正确表示全部敲击后的副本网格；每次恢复只执行完备的邻接合并，因此不变式始终成立。由规模差计数可知每个 result[i] 都正确，故整个返回数组正确。

复杂度

Time
O((m·n + h) α(m·n))

建图与倒序恢复各做常数次并查集操作；h = hits.length，α 为反阿克曼函数。

Space
O(m·n)

网格副本、父节点数组与集合大小数组均与格子数同阶。

边界情况

命中空白

原网格该处为 0 时不恢复，答案直接为 0。

命中顶部砖

恢复时先连接虚拟屋顶，再合并四邻。

没有新稳定砖

屋顶规模可能只增加恢复砖自身，减一后答案为 0。

孤立连通块

它可以在并查集中存在，但未连屋顶前不计入稳定规模。

替代方案

最直接的方法是在每次敲击后，从顶部对当前网格做 BFS/DFS，标记稳定砖并删除其余砖。它容易理解，但最坏时间为 O(h·m·n)；在 h ≤ 4×10⁴、网格最多 4 万格时不可接受。逆序并查集把动态删除转成动态添加，才把总成本压到近似线性。

class Solution {
    public int[] hitBricks(int[][] grid, int[][] hits) {
        int m = grid.length;
        int n = grid[0].length;
        int roof = m * n;
        int[][] work = new int[m][n];

        for (int r = 0; r < m; r++) {
            work[r] = grid[r].clone();
        }
        for (int[] hit : hits) {
            int r = hit[0], c = hit[1];
            if (work[r][c] == 1) {
                work[r][c] = 0;
            }
        }

        UnionFind uf = new UnionFind(m * n + 1);
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (work[r][c] == 0) continue;
                int id = r * n + c;
                if (r == 0) uf.union(id, roof);
                if (r > 0 && work[r - 1][c] == 1) {
                    uf.union(id, (r - 1) * n + c);
                }
                if (c > 0 && work[r][c - 1] == 1) {
                    uf.union(id, r * n + c - 1);
                }
            }
        }

        int[] answer = new int[hits.length];
        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        for (int i = hits.length - 1; i >= 0; i--) {
            int r = hits[i][0], c = hits[i][1];
            if (grid[r][c] == 0) {
                answer[i] = 0;
                continue;
            }

            int before = uf.size(roof);
            work[r][c] = 1;
            int id = r * n + c;

            if (r == 0) uf.union(id, roof);
            for (int[] d : directions) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n
                        && work[nr][nc] == 1) {
                    uf.union(id, nr * n + nc);
                }
            }

            int after = uf.size(roof);
            answer[i] = Math.max(0, after - before - 1);
        }
        return answer;
    }

    private static class UnionFind {
        private final int[] parent;
        private final int[] size;

        UnionFind(int n) {
            parent = new int[n];
            size = new int[n];
            for (int i = 0; i < n; i++) {
                parent[i] = i;
                size[i] = 1;
            }
        }

        int find(int x) {
            if (parent[x] != x) {
                parent[x] = find(parent[x]);
            }
            return parent[x];
        }

        void union(int a, int b) {
            int rootA = find(a), rootB = find(b);
            if (rootA == rootB) return;
            if (size[rootA] < size[rootB]) {
                int temp = rootA;
                rootA = rootB;
                rootB = temp;
            }
            parent[rootB] = rootA;
            size[rootA] += size[rootB];
        }

        int size(int x) {
            return size[find(x)];
        }
    }
}

var hitBricks = function(grid, hits) {
    const m = grid.length;
    const n = grid[0].length;
    const roof = m * n;
    const work = grid.map((row) => row.slice());

    for (const [r, c] of hits) {
        if (work[r][c] === 1) work[r][c] = 0;
    }

    class UnionFind {
        constructor(length) {
            this.parent = new Int32Array(length);
            this.sizes = new Int32Array(length);
            for (let i = 0; i < length; i++) {
                this.parent[i] = i;
                this.sizes[i] = 1;
            }
        }

        find(x) {
            let root = x;
            while (this.parent[root] !== root) {
                root = this.parent[root];
            }
            while (this.parent[x] !== x) {
                const next = this.parent[x];
                this.parent[x] = root;
                x = next;
            }
            return root;
        }

        union(a, b) {
            let rootA = this.find(a);
            let rootB = this.find(b);
            if (rootA === rootB) return;
            if (this.sizes[rootA] < this.sizes[rootB]) {
                [rootA, rootB] = [rootB, rootA];
            }
            this.parent[rootB] = rootA;
            this.sizes[rootA] += this.sizes[rootB];
        }

        size(x) {
            return this.sizes[this.find(x)];
        }
    }

    const uf = new UnionFind(m * n + 1);
    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            if (work[r][c] === 0) continue;
            const id = r * n + c;
            if (r === 0) uf.union(id, roof);
            if (r > 0 && work[r - 1][c] === 1) {
                uf.union(id, (r - 1) * n + c);
            }
            if (c > 0 && work[r][c - 1] === 1) {
                uf.union(id, r * n + c - 1);
            }
        }
    }

    const answer = new Array(hits.length).fill(0);
    const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];

    for (let i = hits.length - 1; i >= 0; i--) {
        const [r, c] = hits[i];
        if (grid[r][c] === 0) continue;

        const before = uf.size(roof);
        work[r][c] = 1;
        const id = r * n + c;

        if (r === 0) uf.union(id, roof);
        for (const [dr, dc] of directions) {
            const nr = r + dr;
            const nc = c + dc;
            if (nr >= 0 && nr < m && nc >= 0 && nc < n
                    && work[nr][nc] === 1) {
                uf.union(id, nr * n + nc);
            }
        }

        const after = uf.size(roof);
        answer[i] = Math.max(0, after - before - 1);
    }
    return answer;
};
from typing import List


class UnionFind:
    def __init__(self, n: int) -> None:
        self.parent = list(range(n))
        self.size = [1] * n

    def find(self, x: int) -> int:
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, a: int, b: int) -> None:
        root_a = self.find(a)
        root_b = self.find(b)
        if root_a == root_b:
            return
        if self.size[root_a] < self.size[root_b]:
            root_a, root_b = root_b, root_a
        self.parent[root_b] = root_a
        self.size[root_a] += self.size[root_b]

    def component_size(self, x: int) -> int:
        return self.size[self.find(x)]


class Solution:
    def hitBricks(
        self, grid: List[List[int]], hits: List[List[int]]
    ) -> List[int]:
        m, n = len(grid), len(grid[0])
        roof = m * n
        work = [row[:] for row in grid]

        for r, c in hits:
            if work[r][c] == 1:
                work[r][c] = 0

        uf = UnionFind(m * n + 1)
        for r in range(m):
            for c in range(n):
                if work[r][c] == 0:
                    continue
                cell = r * n + c
                if r == 0:
                    uf.union(cell, roof)
                if r > 0 and work[r - 1][c] == 1:
                    uf.union(cell, (r - 1) * n + c)
                if c > 0 and work[r][c - 1] == 1:
                    uf.union(cell, r * n + c - 1)

        answer = [0] * len(hits)
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

        for i in range(len(hits) - 1, -1, -1):
            r, c = hits[i]
            if grid[r][c] == 0:
                continue

            before = uf.component_size(roof)
            work[r][c] = 1
            cell = r * n + c

            if r == 0:
                uf.union(cell, roof)
            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if (
                    0 <= nr < m
                    and 0 <= nc < n
                    and work[nr][nc] == 1
                ):
                    uf.union(cell, nr * n + nc)

            after = uf.component_size(roof)
            answer[i] = max(0, after - before - 1)

        return answer
#include <algorithm>
#include <numeric>
#include <vector>
using namespace std;

class UnionFind {
private:
    vector<int> parent;
    vector<int> sizes;

public:
    explicit UnionFind(int n) : parent(n), sizes(n, 1) {
        iota(parent.begin(), parent.end(), 0);
    }

    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    void unite(int a, int b) {
        int rootA = find(a);
        int rootB = find(b);
        if (rootA == rootB) return;
        if (sizes[rootA] < sizes[rootB]) swap(rootA, rootB);
        parent[rootB] = rootA;
        sizes[rootA] += sizes[rootB];
    }

    int componentSize(int x) {
        return sizes[find(x)];
    }
};

class Solution {
public:
    vector<int> hitBricks(
        vector<vector<int>>& grid,
        vector<vector<int>>& hits
    ) {
        int m = static_cast<int>(grid.size());
        int n = static_cast<int>(grid[0].size());
        int roof = m * n;
        vector<vector<int>> work = grid;

        for (const auto& hit : hits) {
            int r = hit[0], c = hit[1];
            if (work[r][c] == 1) work[r][c] = 0;
        }

        UnionFind uf(m * n + 1);
        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                if (work[r][c] == 0) continue;
                int id = r * n + c;
                if (r == 0) uf.unite(id, roof);
                if (r > 0 && work[r - 1][c] == 1) {
                    uf.unite(id, (r - 1) * n + c);
                }
                if (c > 0 && work[r][c - 1] == 1) {
                    uf.unite(id, r * n + c - 1);
                }
            }
        }

        vector<int> answer(hits.size(), 0);
        const int directions[4][2] = {
            {1, 0}, {-1, 0}, {0, 1}, {0, -1}
        };

        for (int i = static_cast<int>(hits.size()) - 1; i >= 0; --i) {
            int r = hits[i][0], c = hits[i][1];
            if (grid[r][c] == 0) continue;

            int before = uf.componentSize(roof);
            work[r][c] = 1;
            int id = r * n + c;

            if (r == 0) uf.unite(id, roof);
            for (const auto& d : directions) {
                int nr = r + d[0], nc = c + d[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n
                        && work[nr][nc] == 1) {
                    uf.unite(id, nr * n + nc);
                }
            }

            int after = uf.componentSize(roof);
            answer[i] = max(0, after - before - 1);
        }
        return answer;
    }

常见错误

  • 直接对每次敲击做全图 DFS，复杂度超限。
  • 用 after - before 当答案，忘了排除恢复砖自身。
  • 在副本移除命中位置后，用副本判断该位置原来是否有砖；应查看原始 grid。
  • 只把顶部砖标记为稳定，却没有通过虚拟屋顶把所有顶部连通分量统一计数。
  • 恢复砖时漏掉四个方向之一，或先算规模差再完成所有合并。

面试追问

为什么不能在线删除并查集节点？

普通并查集擅长合并但不支持拆分。删除一个关节点可能把集合拆成多个部分，无法靠局部父指针高效恢复。

为何要保存集合大小？

每次答案来自虚拟屋顶连通分量的规模变化；若只保存父节点，还得额外遍历才能计数。

若 hits 允许重复怎么办？

可在预处理移除时记录每次是否真正删到砖，或维护命中计数；倒序时仅在对应计数归零后恢复。

可以不用虚拟屋顶吗？

可以为每个根维护“是否触顶”与规模，但合并和计数逻辑更复杂；虚拟节点把条件统一为普通连通性。
