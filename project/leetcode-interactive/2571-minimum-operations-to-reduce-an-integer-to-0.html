01 / 题目

允许“加”，往往会更快归零

给定正整数 n。一次操作可以让 n 加上或减去任意一个 2 的幂，求把它变成 0 的最少操作次数。若 x = 2i 且 i ≥ 0，则 x 是 2 的幂。

函数形式

minOperations(n: integer) → integer

示例 1

输入：n = 39
输出：3
解释：39 + 2⁰ = 40
      40 - 2³ = 32
      32 - 2⁵ = 0
最少需要 3 次操作。

示例 2

输入：n = 54
输出：3
解释：54 + 2¹ = 56
      56 + 2³ = 64
      64 - 2⁶ = 0
最少需要 3 次操作。
约束：1 ≤ n ≤ 105

03 / 题解

把二进制写成“带符号”的幂之和

每次加减一个 2 的幂，等价于在一个带符号二进制表示里使用一个系数为 +1 或 −1 的位。目标就是让非零系数尽可能少。

核心洞察

连续的一串 1 不必逐位处理。例如 00111100₂ 可以写成 01000000₂ − 00000100₂：一整段 1 被压缩为两次操作。每轮找到最低的 1（lowbit）：若它上方紧邻的位也是 1，就加上这个 lowbit 触发进位；否则减去它，直接清除孤立位。若当前数已是 2 的幂，只需最后一次减法。

连续位簇：2ˡ + 2ˡ⁺¹ + … + 2ʳ = 2ʳ⁺¹ − 2ˡ

完整过程

  1. 当 n > 0 时，先判断它是否只有一个 1。
  2. 取最低的 1：lowbit = n & -n。
  3. 若 lowbit 的高一位也是 1，执行 n += lowbit；否则执行 n -= lowbit。
  4. 每次加减后计数加一，直到 n = 0。

正确性

从最低位向高位看，当剩余数为奇数时，任何表示都必须在当前位使用一次 +2ᵏ 或 −2ᵏ，否则奇偶性无法被修正。对末两位为 01 的数，减去最低位会让下一位为 0；对末两位为 11 的数，加上最低位会进位，同样让下一位为 0。另一种选择会留下相邻的非零位，至少还要再付一次操作。因此每轮都在必须付出的一次操作中选取不会制造相邻非零位的方向，得到非相邻形式；逐位归纳可知其非零位数最少，算法最优。

边界与复杂度

  • n = 1 或任意 2 的幂：答案是 1。
  • 形如 2ᵏ − 1：加 1 再减去 2ᵏ，答案是 2。
  • 中间加法可能让位数增加 1，但在题目范围内四种实现都安全。
  • 时间复杂度 O(log n)，额外空间复杂度 O(1)。

替代方案

可用数位 DP 维护“当前位是否有进位”两个状态，同样是 O(log n)；它更容易扩展到输出方案，但本题只求最少次数，低位贪心更短。BFS 虽能在小范围验证直觉，却需要额外边界与访问集合，不适合作为提交方案。

JavaLeetCode signature
class Solution {
    public int minOperations(int n) {
        int operations = 0;
        while (n != 0) {
            if ((n & (n - 1)) == 0) return operations + 1;

            int lowbit = n & -n;
            if ((n & (lowbit << 1)) != 0) n += lowbit;
            else n -= lowbit;
            operations++;
        }
        return operations;
    }
}

var minOperations = function(n) {
    let operations = 0;
    while (n !== 0) {
        if ((n & (n - 1)) === 0) return operations + 1;

        const lowbit = n & -n;
        n = (n & (lowbit << 1)) !== 0
            ? n + lowbit
            : n - lowbit;
        operations++;
    }
    return operations;
};

04 / 延伸

面试追问与常见错误

面试追问

  • 如何恢复具体操作？ 每轮记录 +lowbit 或 −lowbit 即可。
  • 若 n ≤ 10¹⁸？ Java/C++ 使用 64 位整数；JavaScript 使用 BigInt；Python 无需改动。
  • 为什么叫非相邻形式？ 最终带符号表示中不会出现相邻的非零系数。

常见错误

  • 总是减去最近的 2 的幂，会错过通过加法合并连续 1 的机会。
  • 把“右移”误算成一次题目操作；右移只是分析位结构，不是对原数执行的操作。
  • 忘记单独处理 2 的幂，导致多计一次。
  • 扩展到大整数时仍使用 JavaScript 的 32 位位运算。
为什么对末两位 11 选择加，而不是减？

减去最低位会把 …11 变为 …10，高一位仍需处理；加上最低位会触发连锁进位，把整段连续 1 一次推到更高位。

结果是否等于普通二进制中 1 的个数？

不一定。普通表示中 15 = 1111₂ 有四个 1，但带符号表示 16 − 1 只需两次操作。
