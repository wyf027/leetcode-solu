Problem

题目说明

官方元数据转述

学校有学生表 Students、科目表 Subjects 和考试记录表 Examinations。考试表中的每一行表示一名学生参加了对应科目的一次测试，同一组合可以重复出现。

请查询每名学生参加每门科目测试的次数。即使某名学生从未参加某门科目的测试，也必须返回这一组合，次数记为 0。结果先按 student_id，再按 subject_name 升序排列。

Spoiler boundary

准备好再看完整题解

先问自己：怎样保证“0 次”组合也存在？单独从考试记录出发，能不能生成根本没有出现的行？

Insight

核心洞察

答案的骨架不是 Examinations，而是 Students × Subjects 的所有组合。先生成完整骨架，再把考试记录接上来计数；这样没有记录的组合仍保留，并自然得到 0。

一句话：先用笛卡尔积枚举“应该出现什么”，再用左连接统计“实际发生多少”。

完整过程

生成完整组合

用 Students CROSS JOIN Subjects 得到每名学生与每门科目的组合。

保留零次数组合

从完整组合出发，对 Examinations 做 LEFT JOIN。不存在匹配记录时，右表列为 NULL，左侧组合仍在。

按组合分组计数

按学生编号、姓名和科目分组，使用 COUNT(e.subject_name)。它只统计非空值，因此没有匹配的组合得到 0。

按要求排序

最后按 student_id 和 subject_name 升序输出。

官方可提交语言：MySQL

本题是数据库题，SQL 是主要可提交答案。

MySQL可提交
SELECT
    s.student_id,
    s.student_name,
    sub.subject_name,
    COUNT(e.subject_name) AS attended_exams
FROM Students AS s
CROSS JOIN Subjects AS sub
LEFT JOIN Examinations AS e
    ON e.student_id = s.student_id
   AND e.subject_name = sub.subject_name
GROUP BY
    s.student_id,
    s.student_name,
    sub.subject_name
ORDER BY
    s.student_id,
    sub.subject_name;

正确性说明

  1. 完整性：笛卡尔积恰好包含每名学生与每门科目的一个组合，所以所有要求的输出行都存在。
  2. 保留性：左连接不会删除这些组合；没有考试记录时，右表字段为 NULL。
  3. 计数正确：每条匹配的考试记录对应一次参加行为；COUNT(e.subject_name) 统计其非空匹配数，没有匹配时为 0。
  4. 顺序正确：ORDER BY 与题目规定的两个排序键完全一致。

因此查询返回且只返回每名学生、每门科目的正确参加次数。

边界情况

  • 某名学生从未参加任何测试：其所有科目计数均为 0。
  • 某个科目没有任何人参加：每名学生对应计数均为 0。
  • 同一学生同一科目有重复记录：每一行都代表一次考试，应全部计数。
  • 只有一名学生或一门科目：算法仍按相同逻辑工作。

复杂度

设学生数为 S，科目数为 C，考试记录数为 E。

  • 结果骨架有 S × C 行。
  • 概念上的处理量至少为 O(SC + E)；实际连接代价取决于数据库执行计划和索引。
  • 输出本身需要 O(SC) 空间；聚合与排序会使用额外工作空间。

替代方案

先聚合考试表再连接：先把 Examinations 按学生和科目聚合，再左连接到完整组合，并用 COALESCE(count, 0) 补零。这在考试记录很大时可能减少连接数据量，语义也很清楚。

条件聚合：当科目集合固定且很小，可以把科目透视成列；但本题需要每个学生—科目组合占一行，且科目是数据驱动的，所以不如完整组合方案通用。

import java.util.*;

class Solution {
    record Student(int id, String name) {}
    record Exam(int studentId, String subject) {}
    record Result(int id, String name, String subject, int count) {}

    public List<Result> studentsAndExaminations(
            List<Student> students,
            List<String> subjects,
            List<Exam> examinations) {
        Map<String, Integer> counts = new HashMap<>();
        for (Exam exam : examinations) {
            String key = exam.studentId() + "\u0000" + exam.subject();
            counts.merge(key, 1, Integer::sum);
        }

        List<Student> sortedStudents = new ArrayList<>(students);
        sortedStudents.sort(Comparator.comparingInt(Student::id));
        List<String> sortedSubjects = new ArrayList<>(subjects);
        Collections.sort(sortedSubjects);

        List<Result> answer = new ArrayList<>();
        for (Student student : sortedStudents) {
            for (String subject : sortedSubjects) {
                String key = student.id() + "\u0000" + subject;
                answer.add(new Result(
                    student.id(), student.name(), subject,
                    counts.getOrDefault(key, 0)
                ));
            }
        }
        return answer;
    }
}
JavaScript本地语义参考
function studentsAndExaminations(students, subjects, examinations) {
  const counts = new Map();
  for (const [studentId, subject] of examinations) {
    const key = `${studentId}\u0000${subject}`;
    counts.set(key, (counts.get(key) ?? 0) + 1);
  }

  const sortedStudents = [...students].sort((a, b) => a[0] - b[0]);
  const sortedSubjects = [...subjects].sort((a, b) => a.localeCompare(b));
  const answer = [];

  for (const [studentId, studentName] of sortedStudents) {
    for (const subject of sortedSubjects) {
      const key = `${studentId}\u0000${subject}`;
      answer.push([
        studentId,
        studentName,
        subject,
        counts.get(key) ?? 0,
      ]);
    }
  }
  return answer;
}
Python本地语义参考
from collections import Counter
from typing import List, Tuple

Student = Tuple[int, str]
Exam = Tuple[int, str]
Result = Tuple[int, str, str, int]


def students_and_examinations(
    students: List[Student],
    subjects: List[str],
    examinations: List[Exam],
) -> List[Result]:
    counts = Counter(examinations)
    answer: List[Result] = []

    for student_id, student_name in sorted(students):
        for subject in sorted(subjects):
            answer.append((
                student_id,
                student_name,
                subject,
                counts[(student_id, subject)],
            ))
    return answer
C++本地语义参考
#include <algorithm>
#include <map>
#include <string>
#include <tuple>
#include <utility>
#include <vector>
using namespace std;

struct Student { int id; string name; };
struct Exam { int studentId; string subject; };
using Result = tuple<int, string, string, int>;

vector<Result> studentsAndExaminations(
    vector<Student> students,
    vector<string> subjects,
    const vector<Exam>& examinations
) {
    map<pair<int, string>, int> counts;
    for (const Exam& exam : examinations) {
        ++counts[{exam.studentId, exam.subject}];
    }

    sort(students.begin(), students.end(),
         [](const Student& a, const Student& b) { return a.id < b.id; });
    sort(subjects.begin(), subjects.end());

    vector<Result> answer;
    for (const Student& student : students) {
        for (const string& subject : subjects) {
            answer.emplace_back(
                student.id, student.name, subject,
                counts[{student.id, subject}]
            );
        }
    }
    return answer;
}

常见错误

  • 从 Examinations 出发，导致 0 次组合完全消失。
  • 使用内连接，仍会过滤无匹配组合。
  • 左连接后写 COUNT(*)，把占位行误计为 1。
  • 连接条件只写学生编号，没有同时匹配科目。
  • 遗漏规定的排序字段或排序顺序。
