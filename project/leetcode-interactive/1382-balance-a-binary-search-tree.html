将二叉搜索树
变平衡

给定一棵二叉搜索树 root，请返回一棵包含相同节点值的平衡二叉搜索树。若答案不唯一，返回其中任意一种即可。

MEDIUM二叉搜索树深度优先搜索分治非会员题
平衡的定义：对树中每个节点，其左、右子树的高度差都不超过 1。
示例 01

输入：root = [1,null,2,null,3,null,4,null,null]

输出：[2,1,3,null,null,null,4]

输出不唯一；[3,1,4,null,2,null,null] 也符合要求。

示例 02

输入：root = [2,1,3]

输出：[2,1,3]

输入本身已经平衡，可以保持原结构。

约束
  • 树中节点数在 [1, 10⁴] 范围内。
  • 1 ≤ Node.val ≤ 10⁵。

函数签名：balanceBST(root: TreeNode): TreeNode

核心洞察

BST 的中序遍历天然有序

先中序遍历原树，得到升序节点数组。随后每次选择当前区间的中点作为根：中点左侧递归构造左子树，右侧递归构造右子树。

中点让两侧节点数之差至多为 1；递归应用同一规则，就能同时保住 BST 的顺序和平衡性。

一句话模型

排序顺序不变，父子关系重排

节点值集合没有变化。我们只把原树的“形状信息”丢掉，用有序序列重新决定父子关系。

节点值互不重复（BST 常规定义）；代码直接复用原节点对象，也可以新建节点。
完整过程
  1. 对 root 做中序 DFS：左子树 → 当前节点 → 右子树，把节点引用依次放入数组 nodes。
  2. 定义 build(left, right) 构造数组闭区间对应的平衡子树；空区间直接返回 null。
  3. 取 mid = left + floor((right - left) / 2)，令 nodes[mid] 成为当前根。
  4. 递归构造 [left, mid - 1] 和 [mid + 1, right]，覆盖该节点原来的左右指针。
  5. 返回 build(0, nodes.length - 1)。
正确性证明
1

节点完整且唯一

中序遍历恰好访问原树每个节点一次；重建时每个数组下标也恰好被选作一次根。因此新树包含且仅包含原树的全部节点。

2

仍是二叉搜索树

数组按节点值递增。对任意中点，左区间所有值更小，右区间所有值更大；递归构造也满足该性质，所以整棵树满足 BST 条件。

3

必然平衡

每次中点把区间分成大小相差至多 1 的两部分。对区间长度做归纳：两部分递归得到平衡子树，且它们的高度差至多 1，因此当前树也平衡。归纳可知最终整棵树平衡。

复杂度
时间复杂度O(n)遍历与重建各访问每个节点一次。
空间复杂度O(n)节点数组占 O(n)，重建递归栈为 O(log n)。
边界情况
  • 只有一个节点：数组中点就是它本身。
  • 原树已经平衡：允许返回结构不同但节点值相同的平衡树。
  • 完全左斜或右斜：递归收集深度可能达到 n。
  • 节点数为偶数：选择左中点或右中点都正确。
常见错误
  • 只旋转一次根节点，无法保证所有子树都平衡。
  • 重用节点时忘记覆盖旧的左右指针，残留原树连接。
  • 区间边界混用闭区间与半开区间，导致漏节点或无限递归。
  • 误把“平衡”理解为完全二叉树。
替代方案

DSW 算法可通过旋转先把树压成“藤蔓”，再按层旋转成平衡树，额外空间 O(1)。不过实现更复杂，面试中数组 + 分治通常更清晰。

若要求在线持续插入后仍平衡，应使用 AVL 树或红黑树，而不是每次整体重建。

面试追问
  • 能否不用 O(n) 数组？如何用 DSW 做到？
  • 为何左右节点数接近能推出高度差不超过 1？
  • 若不允许修改原树，如何改成创建新节点？
  • 递归中序在 n = 10⁴ 的斜树上有什么栈风险？

四语言完整代码

Java · 复用原节点O(n) / O(n)
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private final List<TreeNode> nodes = new ArrayList<>();

    public TreeNode balanceBST(TreeNode root) {
        inorder(root);
        return build(0, nodes.size() - 1);
    }

    private void inorder(TreeNode node) {
        if (node == null) return;
        inorder(node.left);
        nodes.add(node);
        inorder(node.right);
    }

    private TreeNode build(int left, int right) {
        if (left > right) return null;
        int mid = left + (right - left) / 2;
        TreeNode root = nodes.get(mid);
        root.left = build(left, mid - 1);
        root.right = build(mid + 1, right);
        return root;
    }
}
JavaScript · 复用原节点O(n) / O(n)
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {TreeNode}
 */
var balanceBST = function(root) {
    const nodes = [];

    function inorder(node) {
        if (node === null) return;
        inorder(node.left);
        nodes.push(node);
        inorder(node.right);
    }

    function build(left, right) {
        if (left > right) return null;
        const mid = left + Math.floor((right - left) / 2);
        const node = nodes[mid];
        node.left = build(left, mid - 1);
        node.right = build(mid + 1, right);
        return node;
    }

    inorder(root);
    return build(0, nodes.length - 1);
};

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def balanceBST(
        self, root: Optional[TreeNode]
    ) -> Optional[TreeNode]:
        nodes = []

        def inorder(node: Optional[TreeNode]) -> None:
            if node is None:
                return
            inorder(node.left)
            nodes.append(node)
            inorder(node.right)

        def build(left: int, right: int) -> Optional[TreeNode]:
            if left > right:
                return None
            mid = left + (right - left) // 2
            node = nodes[mid]
            node.left = build(left, mid - 1)
            node.right = build(mid + 1, right)
            return node

        inorder(root)
        return build(0, len(nodes) - 1)
C++ · 复用原节点O(n) / O(n)
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    vector<TreeNode*> nodes;

    void inorder(TreeNode* node) {
        if (node == nullptr) return;
        inorder(node->left);
        nodes.push_back(node);
        inorder(node->right);
    }

    TreeNode* build(int left, int right) {
        if (left > right) return nullptr;
        int mid = left + (right - left) / 2;
        TreeNode* root = nodes[mid];
        root->left = build(left, mid - 1);
        root->right = build(mid + 1, right);
        return root;
    }

public:
    TreeNode* balanceBST(TreeNode* root) {
        inorder(root);
        return build(0, static_cast<int>(nodes.size()) - 1);
    }
};
