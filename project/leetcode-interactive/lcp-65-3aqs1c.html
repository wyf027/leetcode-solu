让每一段连续操作都尽量温和。

舒适的湿度

每条指令可保留为增加湿度，也可改为同等幅度的降低湿度。任一连续操作的绝对影响是其不适宜度；我们要安排所有正负号，使其中最大者尽可能小。

KEY EQUIVALENCE

max |subarray sum|

= max(prefix) − min(prefix)

把当前前缀相对最低点的位置记作状态。

PROBLEM BRIEF

题意与约束

给定正整数数组 operate，将任意数量元素变为负数。控制器会任选一个连续子数组；返回所有符号方案中，连续子数组和的绝对值最大值的最小可能值。

示例 1

[5, 3, 7] → 8

选择 [5, 3, -7]，前缀和为 0, 5, 8, 1，极差为 8。

示例 2

[20, 10] → 20

单个 20 已经给出不可避免的下界。

1 ≤ operate.length ≤ 1000；1 ≤ operate[i] ≤ 1000。

STATE INVARIANT

极差就是答案

  1. 1连续子数组和等于两个前缀和之差，因此最大绝对值恰为全部前缀和的最大值减最小值。
  2. 2将历史最小前缀归零，只记录当前前缀距最低点的高度 h 和已见极差 w。
  3. 3加号会抬高 h；减号若跌破零，则整体平移、极差增加跌落量。
O(n · M)时间
O(M)空间

M = 2 × max(operate)，最大为 2000。

DP 定义

dp[h] 表示处理到当前位置、当前前缀相对历史最低前缀的高度为 h 时，能达到的最小前缀极差。初始 dp[0] = 0。高度不必超过 2 × max(operate)：总可通过交替选择符号将范围控制在该上界内。

  • 选 +x：next[h + x] = min(next[h + x], max(dp[h], h + x))。
  • 选 -x 且 h ≥ x：next[h - x] = min(next[h - x], dp[h])。
  • 选 -x 且 h < x：前缀创新低，平移后高度为 0，next[0] = min(next[0], dp[h] + x - h)。
