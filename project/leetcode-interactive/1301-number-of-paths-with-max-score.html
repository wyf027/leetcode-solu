Problem brief

任务：分数与路径数，一次返回

给定一个 n × n 的字符棋盘 board。从右下角的 'S' 出发，目标是抵达左上角的 'E'。其余格子是数字字符 '1'…'9' 或不可通过的障碍 'X'。

  • 每一步只能向上、向左或向左上移动，且目标格不能是障碍。
  • 路径得分是沿途所有数字之和；S 与 E 不计分。
  • 返回 [最大得分, 达到最大得分的路径数]，路径数对 10⁹ + 7 取余。
  • 如果无法从 S 到达 E，返回 [0, 0]。

⌁ 约束

  • 2 ≤ board.length ≤ 100
  • board.length == board[i].length

ƒ 官方函数形式

pathsWithMaxScore(board: List<String>)
→ int[2]

Dynamic programming

同一张表，同时维护“最优”与“计数”

对每个格子保存两个状态：从 S 走到这里能够取得的最大分数，以及恰好取得该分数的路径条数。只让最优前驱贡献计数，就能避免把较低分路线混入答案。

核心洞察 分数决定哪些前驱有资格参与；计数只在分数相等时相加。二者必须成对转移，但职责不同。

状态与转移

best[i][j] 表示从 S 到格子 (i,j) 的最高得分；ways[i][j] 表示取得该分数的路径数。倒序扫描时，候选前驱是下、右、右下三个格子。

先取三个可达前驱中的最大 best，再把所有等于最大值的 ways 相加，最后加入当前数字。

完整过程

  1. 将所有 best 初始化为 -1，表示不可达。
  2. 设置 best[S]=0、ways[S]=1。
  3. 从右下到左上扫描，跳过 X 与 S。
  4. 选出最优前驱并合并其计数，再加当前格数字。
  5. 若 E 仍不可达返回 [0,0]，否则返回其两项状态。

正确性证明

1

基础：S 到自身只有一条空路径，得分为 0，初始化正确。

2

归纳：处理某格时，它的三个候选前驱均已处理。任何合法路径的最后一步必来自其中之一。

3

结论：取最高前驱分保证最优；仅累加并列最优前驱的计数，恰好枚举全部最优路径且无重复。

边界情况

  • 障碍格永远不可达，不参与转移。
  • 没有可达前驱的普通格保持 -1 / 0。
  • E 与 S 都按数值 0 处理。
  • 路径数每次相加都取模；最大得分本身无需取模。
  • 若终点不可达，必须返回 [0,0]，不能返回负分。

复杂度与替代方案

扫描每个格子一次，每格只看三个方向：时间复杂度 O(n²)，二维实现空间复杂度 O(n²)。

也可从 E 正向扫描至 S，转移方向改为上、左、左上；还可用滚动数组把额外空间降到 O(n)，但实现更容易混淆右下角依赖。

class Solution {
    private static final int MOD = 1_000_000_007;

    public int[] pathsWithMaxScore(java.util.List<String> board) {
        int n = board.size();
        int[][] best = new int[n][n];
        int[][] ways = new int[n][n];
        for (int[] row : best) java.util.Arrays.fill(row, -1);

        best[n - 1][n - 1] = 0;
        ways[n - 1][n - 1] = 1;
        int[][] next = {{1, 0}, {0, 1}, {1, 1}};

        for (int i = n - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                char cell = board.get(i).charAt(j);
                if (cell == 'X' || cell == 'S') continue;

                int maxPrev = -1;
                long count = 0;
                for (int[] d : next) {
                    int ni = i + d[0], nj = j + d[1];
                    if (ni >= n || nj >= n || best[ni][nj] < 0) continue;
                    if (best[ni][nj] > maxPrev) {
                        maxPrev = best[ni][nj];
                        count = ways[ni][nj];
                    } else if (best[ni][nj] == maxPrev) {
                        count = (count + ways[ni][nj]) % MOD;
                    }
                }
                if (maxPrev < 0) continue;
                int value = cell == 'E' ? 0 : cell - '0';
                best[i][j] = maxPrev + value;
                ways[i][j] = (int) (count % MOD);
            }
        }
        return best[0][0] < 0
                ? new int[]{0, 0}
                : new int[]{best[0][0], ways[0][0]};
    }
}

var pathsWithMaxScore = function(board) {
    const MOD = 1_000_000_007;
    const n = board.length;
    const best = Array.from({ length: n }, () => Array(n).fill(-1));
    const ways = Array.from({ length: n }, () => Array(n).fill(0));
    const next = [[1, 0], [0, 1], [1, 1]];

    best[n - 1][n - 1] = 0;
    ways[n - 1][n - 1] = 1;

    for (let i = n - 1; i >= 0; i--) {
        for (let j = n - 1; j >= 0; j--) {
            const cell = board[i][j];
            if (cell === 'X' || cell === 'S') continue;

            let maxPrev = -1;
            let count = 0;
            for (const [di, dj] of next) {
                const ni = i + di;
                const nj = j + dj;
                if (ni >= n || nj >= n || best[ni][nj] < 0) continue;
                if (best[ni][nj] > maxPrev) {
                    maxPrev = best[ni][nj];
                    count = ways[ni][nj];
                } else if (best[ni][nj] === maxPrev) {
                    count = (count + ways[ni][nj]) % MOD;
                }
            }
            if (maxPrev < 0) continue;
            const value = cell === 'E' ? 0 : Number(cell);
            best[i][j] = maxPrev + value;
            ways[i][j] = count;
        }
    }
    return best[0][0] < 0 ? [0, 0] : [best[0][0], ways[0][0]];
};

from typing import List


class Solution:
    def pathsWithMaxScore(self, board: List[str]) -> List[int]:
        MOD = 10**9 + 7
        n = len(board)
        best = [[-1] * n for _ in range(n)]
        ways = [[0] * n for _ in range(n)]
        directions = ((1, 0), (0, 1), (1, 1))

        best[n - 1][n - 1] = 0
        ways[n - 1][n - 1] = 1

        for i in range(n - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                cell = board[i][j]
                if cell in "XS":
                    continue

                max_prev = -1
                count = 0
                for di, dj in directions:
                    ni, nj = i + di, j + dj
                    if ni >= n or nj >= n or best[ni][nj] < 0:
                        continue
                    if best[ni][nj] > max_prev:
                        max_prev = best[ni][nj]
                        count = ways[ni][nj]
                    elif best[ni][nj] == max_prev:
                        count = (count + ways[ni][nj]) % MOD

                if max_prev < 0:
                    continue
                value = 0 if cell == "E" else int(cell)
                best[i][j] = max_prev + value
                ways[i][j] = count

        return [0, 0] if best[0][0] < 0 else [best[0][0], ways[0][0]]

class Solution {
public:
    vector<int> pathsWithMaxScore(vector<string>& board) {
        static constexpr int MOD = 1'000'000'007;
        int n = static_cast<int>(board.size());
        vector<vector<int>> best(n, vector<int>(n, -1));
        vector<vector<int>> ways(n, vector<int>(n, 0));
        const int directions[3][2] = {{1, 0}, {0, 1}, {1, 1}};

        best[n - 1][n - 1] = 0;
        ways[n - 1][n - 1] = 1;

        for (int i = n - 1; i >= 0; --i) {
            for (int j = n - 1; j >= 0; --j) {
                char cell = board[i][j];
                if (cell == 'X' || cell == 'S') continue;

                int maxPrev = -1;
                long long count = 0;
                for (const auto& d : directions) {
                    int ni = i + d[0], nj = j + d[1];
                    if (ni >= n || nj >= n || best[ni][nj] < 0) continue;
                    if (best[ni][nj] > maxPrev) {
                        maxPrev = best[ni][nj];
                        count = ways[ni][nj];
                    } else if (best[ni][nj] == maxPrev) {
                        count = (count + ways[ni][nj]) % MOD;
                    }
                }
                if (maxPrev < 0) continue;
                int value = cell == 'E' ? 0 : cell - '0';
                best[i][j] = maxPrev + value;
                ways[i][j] = static_cast<int>(count % MOD);
            }
        }
        return best[0][0] < 0
                ? vector<int>{0, 0}
                : vector<int>{best[0][0], ways[0][0]};
    }
};

Pitfalls

常见错误

把所有可达路径数都相加

只有分数等于当前最优前驱分数的路线才有资格计数；较低分路径必须被丢弃。

给 E 或 S 加上字符数值

二者只是端点标记，贡献值均为 0。直接做 cell - '0' 会得到错误结果。

用 0 同时表示不可达与零分

合法路径可能恰好得 0 分。应以 -1 作为不可达哨兵，并让计数保持 0。

Follow-up

面试追问

如何把空间降到 O(n)？

按行倒序扫描，保留当前行和下一行的分数/计数。更新顺序必须保证右、下、右下仍是旧的已结算状态。

如果允许四个方向移动呢？

状态依赖可能形成环，简单网格 DP 不再成立。若边权非负，可考虑在扩展状态上使用最短/最长路思想，但正权环还会使最大分无界，需要先澄清路径是否允许重复格子。

为什么计数要随时取模？

最优路径数可能指数增长。及时取模既符合题意，也避免固定宽度整数溢出；分数不取模，因为它用于大小比较。
