股票价格波动

Stock Price Fluctuation · 乱序到达，同一时刻允许更正。

先观察，再揭晓思路

01 / 任务与接口

维护一支股票的时间戳与价格记录。记录可能乱序到达；同一时间戳再次出现时，以新价格替换旧价格。最新价格取最大时间戳对应的值，而最高、最低价格只考虑每个时间戳更正后的有效值。

  • StockPrice()：创建空对象。
  • void update(int timestamp, int price)：写入或更正记录。
  • int current()：返回最大时间戳的价格。
  • int maximum()：返回有效记录的最大价格。
  • int minimum()：返回有效记录的最小价格。

约束：1 ≤ timestamp, price ≤ 109；四种方法总调用次数不超过 105；任何查询前至少调用一次 update。

05 / 独立题解

核心洞察：真值表 + 双堆惰性删除

哈希表保存每个时间戳当前有效的价格。最大时间戳单独维护。最大堆、最小堆保留所有写入的 (价格, 时间戳)，旧记录不急着删除；只有旧记录来到堆顶，且其价格与真值表不一致时，才弹出。

完整过程

  1. 初始化空哈希表和两个堆，latest = 0。
  2. update(t,p)：覆盖表中 t 的值，令 latest = max(latest,t)，向两堆插入 (p,t)。
  3. current()：读取表中 latest 的值，不受最近到达记录的时间先后影响。
  4. maximum()/minimum()：反复检查对应堆顶；与表不符则弹出，直到有效，再返回其价格。

示例更正 (1,10) 为 (1,3) 时，10 仍在最大堆中。下一次 maximum 弹出失效的 (10,1)，随后有效堆顶为 (5,2)，返回 5。

正确性

每次覆盖后，哈希表恰好保存每个时间戳最后写入的值；latest 通过取最大值始终等于已出现时间戳的最大值，所以 current 正确。每次更新都向两堆加入新记录，因此每个有效价格都有一个候选副本。清理只移除与当前值不符的候选，不会移除该时间戳当前值的所有副本。清理结束时最大堆顶有效，且不小于堆内任何有效候选，所以等于全局最大值；最小堆同理。

边界与复杂度

同价重复写入可留下多个有效副本，不影响答案。价格从 8 改为 3 再恢复为 8 时，旧的 8 也可视为有效，因为查询只关心价格。同一时间戳被反复更正时，必须用 while 连续清理。题目保证查询时非空，无需定义空查询返回值。

设 U 为累计更新次数，N 为不同时间戳数：update 为 O(log U)，current 为期望 O(1)。一次极值查询清理 k 个旧条目需要 O(k log U + 1)，最坏 O(U log U)，不可宣称每次都 O(log U)。每个条目在每个堆只进出一次，整个调用序列的总成本为 O(U log U + Q)，其中 Q 为查询次数；空间 O(U + N)，即 O(U)。哈希表操作采用期望 O(1) 假设。

替代方案

哈希表 + 有序多重集合：更新时删除旧价格的一个副本，再插入新价格。Java 可用 TreeMap 记录价格频次，C++ 可用 multiset；能将空间控制在 O(N)，更新 O(log N)。Python 与 JavaScript 标准库没有对应平衡树。直接扫描哈希表查询极值为 O(N)，大量查询时不适合本题规模。

常见错误

  • 把最近一次调用 update 的价格当作 current。
  • 只保存历史最大值，无法撤销被更正的极值。
  • 堆只存价格、不存时间戳，无法判断有效性。
  • 仅弹出一次失效记录，或在多重集合中删除所有同价副本。
  • 把惰性堆空间写成 O(N)，忽略累计历史更新。

面试追问

如果需要严格控制单次查询延迟？使用有序多重集合。若长期运行且历史更新无限增长？可周期性从真值表重建堆以回收旧条目，并分析重建开销。若还要查询时间范围内的极值？需增加按时间组织的区间数据结构，当前双堆只能回答全局极值。

Java

import java.util.*;

class StockPrice {
    private final Map<Integer, Integer> prices = new HashMap<>();
    private final PriorityQueue<int[]> low = new PriorityQueue<>(
        (a, b) -> Integer.compare(a[0], b[0]));
    private final PriorityQueue<int[]> high = new PriorityQueue<>(
        (a, b) -> Integer.compare(b[0], a[0]));
    private int latest = 0;

    public StockPrice() {}
    public void update(int timestamp, int price) {
        prices.put(timestamp, price);
        latest = Math.max(latest, timestamp);
        low.offer(new int[]{price, timestamp});
        high.offer(new int[]{price, timestamp});
    }
    public int current() { return prices.get(latest); }
    private int read(PriorityQueue<int[]> heap) {
        while (prices.get(heap.peek()[1]).intValue() != heap.peek()[0])
            heap.poll();
        return heap.peek()[0];
    }
    public int maximum() { return read(high); }
    public int minimum() { return read(low); }
}

// 自带二叉堆，不依赖平台的优先队列版本。
class Heap {
    constructor(before) { this.a = []; this.before = before; }
    peek() { return this.a[0]; }
    push(x) {
        const a = this.a;
        let i = a.length;
        a.push(x);
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (!this.before(x, a[p])) break;
            a[i] = a[p]; i = p;
        }
        a[i] = x;
    }
    pop() {
        const a = this.a, root = a[0], x = a.pop();
        if (!a.length) return root;
        let i = 0;
        while (i * 2 + 1 < a.length) {
            let c = i * 2 + 1;
            if (c + 1 < a.length && this.before(a[c + 1], a[c])) c++;
            if (!this.before(a[c], x)) break;
            a[i] = a[c]; i = c;
        }
        a[i] = x;
        return root;
    }
}
class StockPrice {
    constructor() {
        this.prices = new Map(); this.latest = 0;
        this.low = new Heap((a, b) => a[0] < b[0]);
        this.high = new Heap((a, b) => a[0] > b[0]);
    }
    update(timestamp, price) {
        this.prices.set(timestamp, price);
        this.latest = Math.max(this.latest, timestamp);
        this.low.push([price, timestamp]);
        this.high.push([price, timestamp]);
    }
    current() { return this.prices.get(this.latest); }
    read(heap) {
        while (this.prices.get(heap.peek()[1]) !== heap.peek()[0]) heap.pop();
        return heap.peek()[0];
    }
    maximum() { return this.read(this.high); }
    minimum() { return this.read(this.low); }
}

Python

import heapq

class StockPrice:
    def __init__(self):
        self.prices = {}
        self.latest = 0
        self.low = []
        self.high = []

    def update(self, timestamp: int, price: int) -> None:
        self.prices[timestamp] = price
        self.latest = max(self.latest, timestamp)
        heapq.heappush(self.low, (price, timestamp))
        heapq.heappush(self.high, (-price, timestamp))

    def current(self) -> int:
        return self.prices[self.latest]

    def maximum(self) -> int:
        while -self.high[0][0] != self.prices[self.high[0][1]]:
            heapq.heappop(self.high)
        return -self.high[0][0]

    def minimum(self) -> int:
        while self.low[0][0] != self.prices[self.low[0][1]]:
            heapq.heappop(self.low)
        return self.low[0][0]

C++

#include <unordered_map>
#include <queue>
#include <vector>
#include <functional>
#include <algorithm>
using namespace std;

class StockPrice {
    using Entry = pair<int, int>; // price, timestamp
    unordered_map<int, int> prices;
    priority_queue<Entry> high;
    priority_queue<Entry, vector<Entry>, greater<Entry>> low;
    int latest = 0;
public:
    StockPrice() {}
    void update(int timestamp, int price) {
        prices[timestamp] = price;
        latest = max(latest, timestamp);
        high.emplace(price, timestamp);
        low.emplace(price, timestamp);
    }
    int current() { return prices.at(latest); }
    int maximum() {
        while (prices.at(high.top().second) != high.top().first) high.pop();
        return high.top().first;
    }
    int minimum() {
        while (prices.at(low.top().second) != low.top().first) low.pop();
        return low.top().first;
    }
};
