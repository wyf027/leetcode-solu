WORDS WITHIN TWO EDITS OF DICTIONARY

距离字典两次编辑
以内的单词

一个单词，两次修改机会。哪些查询词能够抵达字典？

01题目与规则

给定字符串数组 queries 和 dictionary。所有单词长度相同，且只含小写英文字母。每次编辑允许把查询词的一个字母替换成另一个字母。找出那些最多经过两次编辑，就能与字典中至少一个单词完全一致的查询词。

返回原查询词，顺序与 queries 一致。允许零次编辑；不允许插入或删除字母。若查询中有重复项，逐项判断并保留符合条件的重复项。

官方示例 1

输入：
queries = ["word","note","ants","wood"]
dictionary = ["wood","joke","moat"]
输出：["word","note","wood"]

word 可把 r 改成 o；note 可把 n 改成 j、t 改成 k；wood 无需修改。ants 无法在两次修改内匹配任何字典词。

官方示例 2

输入：
queries = ["yes"]
dictionary = ["not"]
输出：[]

yes 无法在至多两次替换后成为 not，因此不返回任何词。

约束

  • 1 ≤ queries.length, dictionary.length ≤ 100
  • n == queries[i].length == dictionary[j].length
  • 1 ≤ n ≤ 100
  • 所有 queries[i] 与 dictionary[j] 仅由小写英文字母组成。

04独立题解

准备好后展开：推导、正确性证明、边界讨论与四语言可提交代码。

从替换次数到位置差异

核心洞察

只允许替换，单词又等长，所以两个词之间所需的最少编辑次数，正好是同一位置字符不同的个数（汉明距离）。逐个查询词尝试字典词，存在一对差异数不超过 2，就把当前原查询词加入答案。

完整过程

  1. 按原顺序遍历 queries，为当前查询逐个尝试 dictionary 中的词。
  2. 每开始比较一对词，把差异计数 diff 清零；从左向右比较同位置字符。
  3. 遇到不同字符就加一；当计数达到 3，提前结束当前词对，因为后续字符无法减少已有差异。
  4. 若当前词对结束后 diff ≤ 2，加入原查询词，并停止遍历它的其余字典词，防止重复加入。
  5. 若所有字典词均失败，跳过该查询词。继续处理下一个查询词。

例：note 对 wood 有 3 处差异，失败；对 joke 有 2 处差异，因此加入 note。找到一个匹配就够了，不必计算所有字典词的最小距离。

正确性证明

引理：若两个等长单词有 d 个不同位置，每个位置都必须至少被修改一次，所以至少需要 d 次编辑；直接替换这 d 个位置即可完成匹配，所以最少编辑数恰好为 d。

循环不变式：每对词的字符循环在处理完一个前缀后，diff 恰等于该前缀的不同位置数。遇到第 3 处不同后，整词差异至少为 3，提前退出不会遗漏合法匹配。

可靠性：被加入的查询词一定存在差异不超过 2 的字典词，由引理可在两次以内编辑得到它。完备性：若查询词存在这样的字典词，遍历字典时会找到它，或更早已找到另一个合法匹配，因此不会漏掉。外层顺序遍历且每个查询项最多加入一次，保证原顺序和重复项语义。

边界与复杂度

  • 完全相同：差异为 0，必须接收；恰好两处不同同样接收。
  • 第三处不同即可拒绝当前词对，但不能拒绝整个查询词。
  • 长度为 1 或 2 时，任意等长词之间至多两处不同；由于字典非空，所有查询均符合条件。
  • 重复查询逐项保留；多个字典词匹配同一个查询项时，答案只加入该项一次。
  • 设查询数 Q、字典数 D、词长 n：最坏时间 O(QDn)，辅助空间 O(1)，返回列表空间 O(Q) 个词条。C++ 返回列表复制字符串，字符存储最坏 O(Qn)；其余代码存储已有字符串引用。
  • 给定上界下，最多约 100 × 100 × 100 = 1,000,000 次字符比较；提前结束只改善实际工作量，不改变最坏上界。交互演示另存步骤，不计入提交算法空间。

替代方案

完整统计差异：不提前停止，写法简单但会做无用比较，复杂度同为 O(QDn)。字典树：沿字符路径搜索并携带剩余编辑额度，可在共享前缀多时复用路径，超过预算就剪枝，但实现和内存成本更高，最坏仍可能访问大量节点。枚举修改词 + 哈希集合：每个词会产生约 O(n²·26²) 个候选，还要承担字符串构造与哈希成本，本题规模下直接比较更合适。

常见错误

  • 使用通用编辑距离动态规划：误把插入、删除也当作允许操作。
  • 把“至多两次”写成“恰好两次”，漏掉零次和一次匹配。
  • 每对词没有清零 diff，或者找到匹配后没有退出字典循环。
  • 返回字典词、排序查询、用集合去重，都会改变所需输出。
  • 一对词差异超过 2 就退出全部字典遍历，会漏掉后续匹配。

面试追问

预算改成 k？将阈值 2 改成 k，证明不变；若 k ≥ n，全部查询合格。允许增删字符？等位置比较不再成立，需要考虑编辑距离算法。字典巨大且查询频繁？先评估共享前缀与查询分布，再考虑字典树或近邻检索索引。如何输出修改操作？找到匹配词后再次扫描，记录不同位置及目标字符即可。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> twoEditWords(String[] queries, String[] dictionary) {
        List<String> answer = new ArrayList<>();
        for (String q : queries) {
            for (String d : dictionary) {
                int diff = 0;
                for (int i = 0; i < q.length(); i++) {
                    if (q.charAt(i) != d.charAt(i)) diff++;
                    if (diff > 2) break;
                }
                if (diff <= 2) {
                    answer.add(q);
                    break;
                }
            }
        }
        return answer;
    }
}

/**

var twoEditWords = function(queries, dictionary) {
    const answer = [];
    for (const q of queries) {
        for (const d of dictionary) {
            let diff = 0;
            for (let i = 0; i < q.length; i++) {
                if (q[i] !== d[i]) diff++;
                if (diff > 2) break;
            }
            if (diff <= 2) {
                answer.push(q);
                break;
            }
        }
    }
    return answer;
};

Python 3

from typing import List

class Solution:
    def twoEditWords(self, queries: List[str], dictionary: List[str]) -> List[str]:
        answer = []
        for q in queries:
            for d in dictionary:
                diff = 0
                for a, b in zip(q, d):
                    if a != b:
                        diff += 1
                    if diff > 2:
                        break
                if diff <= 2:
                    answer.append(q)
                    break
        return answer

C++

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> twoEditWords(vector<string>& queries,
                                vector<string>& dictionary) {
        vector<string> answer;
        for (const string& q : queries) {
            for (const string& d : dictionary) {
                int diff = 0;
                for (int i = 0; i < static_cast<int>(q.size()); ++i) {
                    if (q[i] != d[i]) ++diff;
                    if (diff > 2) break;
                }
                if (diff <= 2) {
                    answer.push_back(q);
                    break;
                }
            }
        }
        return answer;
    }
};
