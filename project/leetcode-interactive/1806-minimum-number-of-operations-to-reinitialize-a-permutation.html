还原排列的最少操作步数

Minimum Number of Operations to Reinitialize a Permutation

把一副有序数字分成两半，再交错放回。它会在第几轮重新有序？

01 / 题目与规则

给定偶数整数 n，从排列 perm = [0, 1, …, n−1] 开始（下标从 0 开始）。每轮创建一个全新的数组 arr，按下列规则取值，然后令 perm = arr：

i 为偶数：arr[i] = perm[i / 2]
i 为奇数：arr[i] = perm[n / 2 + (i - 1) / 2]

返回排列首次回到初始状态所需的最小非零操作次数。初始状态的 0 次不计入答案。

参数：n: integer；返回：integer。约束：2 ≤ n ≤ 1000 且 n 为偶数。

官方示例 1

输入：n = 2
输出：1

[0,1] → [0,1]，执行 1 次即还原。

官方示例 2

输入：n = 4
输出：2

[0,1,2,3] → [0,2,1,3] → [0,1,2,3]。

官方示例 3

输入：n = 6
输出：4

首次还原需要 4 轮。

04 / 独立题解

先观察实验，再按需展开推导与四语言代码。

核心洞察：只追踪数字 1 的位置

题面写的是“新位置从哪里取值”。反过来看旧位置 p 去哪里：若 p < n/2，新位置是 2p；否则为 2p−n+1。数字 0 和 n−1 始终不动。对其余位置，这等价于 p' = 2p mod (n−1)。

当 n > 2，数字 1 经过 k 轮的位置是 2^k mod (n−1)。它回到 1，意味着 2^k ≡ 1 (mod n−1)，进而每个内部位置 p 都满足 2^k p ≡ p。所以数字 1 首次回到原位的时间，就是整个排列的还原时间。

完整过程

  1. 初始化 p = 1、steps = 0。
  2. 按上述分段位置映射更新 p，再将 steps 加一。
  3. 只在完成操作后判断 p 是否为 1；否则继续。
  4. 返回 steps。分段写法自然覆盖 n = 2，无需取模特判。
n = 6，跟踪数字 1 的位置：
第 0 轮：1
第 1 轮：2
第 2 轮：4
第 3 轮：3
第 4 轮：1 → 答案为 4

正确性证明

映射正确：前半段旧下标 p 被新数组偶数下标 2p 读取，后半段旧下标 p 被奇数下标 2(p−n/2)+1 读取，因此位置更新准确。

充要性：整个排列还原必然要求数字 1 还原；当 n > 2，数字 1 还原又使 2 的 k 次幂模 n−1 等于 1，从而所有内部位置还原，两个端点本就固定。

终止与最小性：n−1 为奇数，2 与它互质，反复倍增最终回到 1。循环逐次检查所有正整数步数，故首次停止就是最小正解。n = 2 时 p = 1 映射到 1，执行一次即返回，结论同样成立。

复杂度与边界

令答案为 T，时间 O(T)、额外空间 O(1)。n > 2 时 T 是 2 模 n−1 的乘法阶，至多 φ(n−1) ≤ n−2，因此也可写时间 O(n)。n = 2 返回 1；不要把未操作的初始状态判作答案 0。

替代方案

直接创建 arr 模拟整个排列，每轮检查所有位置是否还原，时间 O(nT)、空间 O(n)，最贴近题面，也是上方实验采用的机制。还可求所有置换环长度的最小公倍数。若 n 大幅增加，可从 φ(n−1) 的因子中用快速幂寻找乘法阶，但需要因数分解，当前约束下没有必要。

常见错误

  • 把 arr[i] 的取值公式直接当作旧位置的移动公式，混淆映射方向。
  • 原地覆盖 perm，导致后续取到本轮刚写入的数据；完整模拟必须用新数组。
  • 先判断 p != 1 再进入循环，导致一次也不执行。
  • 直接套取模公式到 n = 2；模 1 无法得到余数 1，应特判或使用分段映射。
  • 认为任意置换都能只追踪一个元素；这里依赖特殊的模倍增结构。

Java

class Solution {
    public int reinitializePermutation(int n) {
        int p = 1, steps = 0;
        do {
            p = p < n / 2 ? 2 * p : 2 * p - n + 1;
            steps++;
        } while (p != 1);
        return steps;
    }
}

class Solution:
    def reinitializePermutation(self, n: int) -> int:
        p, steps = 1, 0
        while True:
            p = 2 * p if p < n // 2 else 2 * p - n + 1
            steps += 1
            if p == 1:
                return steps

    int reinitializePermutation(int n) {

面试追问

追踪数字 2 也一定够吗？对于本题 n−1 为奇数，2 可逆，因此也够；一般位置 p 若与 n−1 不互质，可能提前返回，不能代表全局。

n = 8 为什么答案是 3？因为 2³ ≡ 1 (mod 7)，且更小的正指数不满足。

一般置换如何做？分解为互不相交的环，返回各环长度的最小公倍数，并留意整数溢出。
