05 / 从独立排序到结果表

准备好后再查看核心洞察、正确性证明与完整实现。

核心洞察：新的位置是连接键

原表的行关系没有保留要求。分别对两列排序，再给每个元素分配唯一的位置编号，就能把同位置元素拼成新行。SQL 的 ROW_NUMBER() 让相等的值也各占一个位置。

完整过程

  1. CTE A 按 first_col ASC 生成 1 到 n 的编号。
  2. CTE B 按 second_col DESC 独立生成 1 到 n 的编号。
  3. 用 A.rn = B.rn 连接；连接键是新位置，不是原值。
  4. 最外层 ORDER BY A.rn 明确结果展示次序，仅返回题目要求的两列。

MySQL 8+ · 主要可提交代码

WITH A AS (
    SELECT first_col,
           ROW_NUMBER() OVER (ORDER BY first_col ASC) AS rn
    FROM Data
), B AS (
    SELECT second_col,
           ROW_NUMBER() OVER (ORDER BY second_col DESC) AS rn
    FROM Data
)
SELECT A.first_col, B.second_col
FROM A
JOIN B ON A.rn = B.rn
ORDER BY A.rn;

正确性

设第一列排序后的序列为 a₁ ≤ … ≤ aₙ，第二列为 b₁ ≥ … ≥ bₙ。ROW_NUMBER 为每个序列恰好分配一次编号 1…n，所以每个 i 在连接中只匹配一对 (aᵢ,bᵢ)。因此输出恰有 n 行，保留每列全部值及其重数。按 i 输出后，两列分别非递减、非递增，满足要求。相等值内部如何编号不影响最终的数值序列。

边界与复杂度

空表得到空结果；单行不变；重复值仍保留；负数按数值次序排列。按通常比较排序模型，两次排序耗时 O(n log n)，序列及中间结果占 O(n) 空间。实际 SQL 的连接策略、索引利用与排序落盘取决于执行计划，这里不声称数据库固定采用某种计划。

题目未给出 NULL 策略。MySQL 默认升序时 NULL 在前、降序时 NULL 在后；若扩展到其他数据库，应显式约定 NULL 位置。以下四语言参考限定为非 NULL 整数二元行，输入需符合该契约。

四语言完整语义参考

以下均为本地数组函数，非本题官方可提交接口；不会修改输入。每一行形如 [first_col, second_col]，使用两次排序再按位置配对。

Java · 本地语义参考
import java.util.Arrays;

class Solution {
    public int[][] orderTwoColumns(int[][] data) {
        int n = data.length;
        int[] first = new int[n];
        int[] second = new int[n];
        for (int i = 0; i < n; i++) {
            first[i] = data[i][0];
            second[i] = data[i][1];
        }
        Arrays.sort(first);
        Arrays.sort(second);
        int[][] result = new int[n][2];
        for (int i = 0; i < n; i++) {
            result[i][0] = first[i];
            result[i][1] = second[n - 1 - i];
        }
        return result;
    }
}
JavaScript · 本地语义参考
// data: 非 NULL 整数二元数组，数值在安全整数范围内。
function orderTwoColumns(data) {
    const first = data.map(row => row[0]).sort((a, b) => a - b);
    const second = data.map(row => row[1]).sort((a, b) => b - a);
    return first.map((value, i) => [value, second[i]]);
}
Python · 本地语义参考
def order_two_columns(data: list[list[int]]) -> list[list[int]]:
    first = sorted(row[0] for row in data)
    second = sorted((row[1] for row in data), reverse=True)
    return [[a, b] for a, b in zip(first, second)]
C++ · 本地语义参考
#include <algorithm>
#include <array>
#include <vector>
using namespace std;

vector<array<int, 2>> orderTwoColumns(
    const vector<array<int, 2>>& data) {
    vector<int> first, second;
    for (const auto& row : data) {
        first.push_back(row[0]);
        second.push_back(row[1]);
    }
    sort(first.begin(), first.end());
    sort(second.rbegin(), second.rend());
    vector<array<int, 2>> result;
    for (size_t i = 0; i < data.size(); ++i) {
        result.push_back({first[i], second[i]});
    }
    return result;
}

替代方案

可在同一个 CTE 中同时计算两个 ROW_NUMBER，再对该 CTE 按不同编号自连接，核心仍是位置对齐。支持数据框的环境可分别排序两列、重置索引后横向拼接；必须重置旧索引，否则可能按旧行标签对齐。没有窗口函数时的相关子查询方案更复杂，尤其需要妥善区分重复项，不作为首选。

常见错误

  • ORDER BY first_col, second_col DESC 排的是整行，只在第一列相等时考虑第二列，不能独立重排两列。
  • 用 RANK 或 DENSE_RANK 连接：重复值会共用编号，可能造成多对多匹配与行数膨胀。
  • 只在 CTE 末尾写 ORDER BY，却让 ROW_NUMBER 的窗口不指定排序，编号与目标顺序没有保证。
  • 使用 DISTINCT 会丢掉重复值；按原始行标识连接则保留了错误的旧配对。
  • 省略最外层 ORDER BY，不能依赖连接输出的偶然顺序。
  • JavaScript 的默认 sort 是字符串次序，数值排序必须传比较器。

面试追问

三列分别排序怎么做？
为每列按各自顺序编号，再按同一位置连接三列。
相同值需要稳定排序吗？
只输出这两列时无需；若还要携带来源信息，则应先定义同值间的确定性规则。
有索引能否免除排序？
可能帮助有序访问，但要看窗口计算和优化器计划，不能仅凭索引存在就下结论。
为什么必须先放弃旧行关系？
独立排序会产生新配对；若业务同时要求保留旧行关系，两个要求一般无法同时满足。
