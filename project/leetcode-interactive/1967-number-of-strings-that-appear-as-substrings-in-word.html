Number of Strings That Appear as Substrings in Word

一个单词，一组字符串。哪些字符串能在这个单词里连续地找到？
先读题并独立思考，再按需开启演示与底部题解。

01 / 题目

给定字符串数组 patterns 和字符串 word，返回数组中属于 word 子字符串的元素个数。子字符串要求字符在原字符串中连续出现。统计的是数组元素；相同内容的不同元素分别计数。

参数：patterns: string[]、word: string；返回值：整数。

官方示例

示例 1

patterns = ["a","abc","bc","d"], word = "abc"
输出：3

a、abc、bc 可以连续找到，d 不能。

示例 2

patterns = ["a","b","c"], word = "aaaaabbbbb"
输出：2

a 和 b 属于子字符串，c 不属于。

示例 3

patterns = ["a","a","a"], word = "ab"
输出：3

三个数组元素分别满足条件，因此返回 3。

约束

  • 1 ≤ patterns.length ≤ 100
  • 1 ≤ patterns[i].length ≤ 100
  • 1 ≤ word.length ≤ 100
  • patterns[i] 和 word 都只包含小写英文字母。

思考卡：字符串在 word 中出现多次，与 patterns 中有多个相同元素，是一回事吗？

04 / 独立题解

准备好后再打开：思路、证明与四语言代码。

核心洞察：每个元素只需要一个“是否存在”

对每个 pattern 判断它是否为 word 的连续片段。存在就加一，不存在就不加。成功后无需寻找同一元素的其他出现位置；不要去重数组，重复元素各自占一个计数名额。

完整过程

  1. 将计数器 answer 初始化为 0。
  2. 按数组下标遍历每个 pattern。
  3. 使用内置子串查找判断存在性；存在就令 answer 加一。
  4. 遍历结束返回 answer。

对于 ["a","abc","bc","d"] 和 "abc"，四次判断为 true、true、true、false，计数依次为 1、2、3、3。

观察台展开朴素窗口查找：从左到右尝试长度等于 pattern 的连续窗口，找到第一个完全相同的窗口后结束当前元素。内置函数提供同样的存在性语义，但内部实现可能更高效。

正确性证明

循环不变量：处理完前 k 个元素时，answer 恰好等于这 k 个元素中属于 word 子字符串的元素数。开始时 k = 0，answer = 0，不变量成立。下一元素满足条件时且仅在此时加一，因此不变量保持。最终所有元素处理完，answer 就是题目要求的数量。

窗口查找比较的是连续片段，并且覆盖所有合法起点。因此它不会将子序列误认为子串，也不会漏掉任何存在的子串。

边界与复杂度

  • pattern 比 word 长：不能匹配。
  • pattern 等于 word：整个 word 也是子串。
  • pattern 在 word 中多次出现：该元素只贡献 1。
  • patterns 中有重复元素：分别判断与计数。
  • 空数组、空字符串不属于本题输入范围。

设 n 为数组长度，m 为 word 长度，L 为最长 pattern 长度。按朴素子串查找分析，整体保守上界为 O(nmL)。具体地，长度 ℓ ≤ m 的模式最多比较 (m − ℓ + 1)ℓ 次字符。不同语言内置搜索可能更快，不应统一声称它们都是 O(m)。

显式计数循环使用 O(1) 额外空间，不创建子串副本；库函数内部空间取决于实现。若需算法层面严格 O(1) 空间，可手写下标逐字符比较。可视化存储的帧不计入提交算法复杂度。

四语言完整提交代码

Java

class Solution {
    public int numOfStrings(String[] patterns, String word) {
        int answer = 0;
        for (String pattern : patterns) {
            if (word.contains(pattern)) answer++;
        }
        return answer;
    }
}

JavaScript

/**
 * @param {string[]} patterns
 * @param {string} word
 * @return {number}
 */
var numOfStrings = function(patterns, word) {
    let answer = 0;
    for (const pattern of patterns) {
        if (word.includes(pattern)) answer++;
    }
    return answer;
};

Python 3

from typing import List

class Solution:
    def numOfStrings(self, patterns: List[str], word: str) -> int:
        answer = 0
        for pattern in patterns:
            if pattern in word:
                answer += 1
        return answer

C++

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int numOfStrings(vector<string>& patterns, string word) {
        int answer = 0;
        for (const string& pattern : patterns) {
            if (word.find(pattern) != string::npos) ++answer;
        }
        return answer;
    }
};

替代方案

手动枚举起点并逐字符比较最直观。若字符串很长，对每个 pattern 使用 KMP，可得到 O(nm + Σ|pattern|) 时间与 O(L) 额外空间。大量模式串可考虑 Aho–Corasick 自动机，为每个模式记录是否出现，并保留重复模式的频次。本题规模至多 100，内置查找更简洁。

面试追问

  • 如何返回匹配元素的下标？遍历时保存 patterns 的下标，重复元素仍保留。
  • 如果统计所有出现位置？成功后继续查找，先明确重叠是否允许。例如 aa 在 aaa 中重叠出现 2 次。
  • 如果 word 固定且查询很多？可缓存相同模式的查找结果，但仍按数组频次计数；也可讨论后缀自动机。
  • 如果改为子序列？需要双指针判断字符顺序，不能继续用子串查找。

常见错误

  • 将 patterns 去重，使示例 3 从 3 错算成 1。
  • 累加在 word 中的出现次数，混淆元素数与位置数。
  • 将 ac 当成 abc 的子串，忽略连续性。
  • JavaScript 使用 if (word.indexOf(pattern))：下标 0 为假，−1 反而为真。应比较 !== -1 或使用 includes。
  • C++ 把 find 的返回值直接当布尔值；应比较 != string::npos。
