766. 托普利茨矩阵

TOEPLITZ MATRIX

沿着左上到右下的方向观察矩阵：每一条这样的对角线，是否都保持同一个数字？先用实验台逐格观察，再决定要不要展开完整题解。

EASY 数组 矩阵 非付费题

Problem brief

题目说明

给定一个 m × n 整数矩阵 matrix，判断它是否满足托普利茨矩阵的定义。

准确转述

如果矩阵中每一条从左上延伸到右下的对角线，其所有元素都相等，则返回 true；只要存在一条对角线包含不同元素，就返回 false。

托普利茨矩阵：任意处于同一条左上 → 右下对角线上的元素值相同。

示例 1

输入：matrix = [[1,2,3,4],[5,1,2,3],[9,5,1,2]]
输出：true
解释：各条对角线分别为 [9]、[5,5]、[1,1,1]、
[2,2,2]、[3,3]、[4]，每条内部元素均相同。

示例 2

输入：matrix = [[1,2],[2,2]]
输出：false
解释：对角线 [1,2] 中出现了不同元素。

约束

  • m == matrix.length
  • n == matrix[i].length
  • 1 <= m, n <= 20
  • 0 <= matrix[i][j] <= 99

完整题解

核心洞察

除第一行与第一列外，每个元素都恰好拥有一个左上邻居。若所有这些元素都等于自己的左上邻居，那么相等关系会沿整条对角线传递，矩阵就是托普利茨矩阵。

matrix[i][j] == matrix[i - 1][j - 1]

因此不必先收集每条对角线，也不必额外记录对角线编号。

完整过程

  1. 从第 2 行开始遍历，即 i = 1 ... m - 1。
  2. 每行从第 2 列开始，即 j = 1 ... n - 1。
  3. 比较 matrix[i][j] 与 matrix[i-1][j-1]。
  4. 一旦不同，立即返回 false。
  5. 所有比较均相等，则返回 true。

正确性证明

若算法返回 true

算法确认每个非首行、非首列元素都等于其左上邻居。对任意一条左上到右下对角线，连续元素两两相等；由等式的传递性，整条对角线上的元素均相等，所以矩阵是托普利茨矩阵。

若矩阵是托普利茨矩阵

每个被比较的元素与其左上邻居处于同一条对角线。根据定义，它们必然相等，算法不会返回 false，最终返回 true。

因此，算法当且仅当矩阵是托普利茨矩阵时返回 true。

边界情况

  • 1 × 1：没有需要比较的元素，天然满足定义。
  • 单行或单列：每条对角线至多一个元素，同样返回 true。
  • 重复值矩阵：所有比较相等，正常通过。
  • 首个内部格即冲突：立即短路返回 false。
  • 最大 20 × 20：直接遍历足够，无需特殊优化。

复杂度

O(mn)时间：至多检查 (m−1)(n−1) 对元素
O(1)空间：只使用循环变量，不计输入矩阵

替代方案

  • 按对角线起点遍历：从第一行与第一列的每个起点出发逐条检查。直观，但循环结构更繁琐。
  • 哈希映射：用 i - j 作为对角线键并记录首值。易扩展，但需要 O(m+n) 额外空间。
  • 逐行流式：磁盘场景只保留上一行；当前行第 j 项与上一行第 j-1 项比较，空间 O(n)。
  • 分块流式：一行也放不下时按列块读取，并保留相邻块边界所需的前一行尾部值。

完整代码

四种实现采用同一策略：遍历所有拥有左上邻居的元素，发现不相等立即返回。

class Solution {
    public boolean isToeplitzMatrix(int[][] matrix) {
        int rows = matrix.length;
        int cols = matrix[0].length;

        for (int i = 1; i < rows; i++) {
            for (int j = 1; j < cols; j++) {
                if (matrix[i][j] != matrix[i - 1][j - 1]) {
                    return false;
                }
            }
        }

        return true;
    }
}

Interview follow-ups

面试追问

为什么从索引 1 开始？

第一行和第一列没有左上邻居，只有其余元素需要比较。

能否按对角线编号判断？

可以，位置 (i,j) 的 i-j 相同即处在同一对角线，但会引入额外存储。

磁盘矩阵如何节省内存？

一次读取一行，只需保存上一行并与当前行错位比较。

为什么可以提前返回？

定义要求所有对角线都成立；发现任意一对冲突就已经构成反例。

常见错误

  • 误把左上 → 右下对角线写成右上 → 左下，比较了 matrix[i-1][j+1]。
  • 从 i = 0 或 j = 0 开始访问左上邻居，造成越界。
  • 只检查主对角线；题目要求检查所有平行的对角线。
  • 把“同一条对角线元素相等”误解为“所有对角线之间的值也必须相等”。
  • 为了收集每条对角线而创建大量数组，增加了不必要的空间和代码复杂度。
