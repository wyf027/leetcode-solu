LEETCODE 256 · MEDIUM · PREMIUM

Paint House

每栋房子可涂红、蓝、绿三色，相邻房子不能相同。到达一栋房子的某种颜色时，只需记住上一栋“另外两色”的较小总成本——这正是滚动 DP。

题意与约束

🎨 DP · 三状态

给定 costs[i][j]，表示第 i 栋涂颜色 j 的成本。返回给所有房子上色且相邻颜色不同的最小总成本。

官方示例 1costs = [[17,2,17],[16,16,5],[14,3,19]]
output = 10
官方示例 2costs = [[7,6,2]]
output = 2
边界costs = []
output = 0
约束0 <= costs.length <= 100
costs[i].length = 3
1 <= costs[i][j] <= 20

题解 · 前一栋的另外两色

核心洞察

newRed = costRed + min(prevBlue, prevGreen)，另两色同理。这样天然禁止相邻同色，并且每栋只做常数次操作。

完整过程

  1. 空数组返回 0。
  2. 首栋三项成本初始化 DP。
  3. 逐栋用旧三元组计算新三元组。
  4. 最后返回三个状态的最小值。

复杂度与边界

时间 O(n)，滚动三状态额外空间 O(1)。

  • 单栋：取该行最小值。
  • 更新必须先保存旧值，不能原地串行污染后续计算。
  • 空数组没有房子，成本为 0。

替代方案

二维 DP 表更适合展示每栋状态，空间 O(n)；滚动 DP 只因转移依赖上一行而可压缩。

常见错误：允许新状态继承同色旧状态；原地更新时没缓存旧三色；或把每一行本身的最小成本误当全局答案。

面试追问

若有 k 种颜色？朴素转移 O(nk²)，记录前一行最小和次小可降为 O(nk)。若要恢复颜色方案？保留前驱选择。

class Solution {
    public int minCost(int[][] costs) {
        if (costs.length == 0) return 0;
        int r = costs[0][0], b = costs[0][1], g = costs[0][2];
        for (int i = 1; i < costs.length; i++) {
            int nr = costs[i][0] + Math.min(b, g);
            int nb = costs[i][1] + Math.min(r, g);
            int ng = costs[i][2] + Math.min(r, b);
            r = nr; b = nb; g = ng;
        }
        return Math.min(r, Math.min(b, g));
    }
}

  let [r, b, g] = costs[0];
  for (let i = 1; i < costs.length; i++) {
    [r, b, g] = [costs[i][0] + Math.min(b, g), costs[i][1] + Math.min(r, g), costs[i][2] + Math.min(r, b)];
  }
  return Math.min(r, b, g);
};
from typing import List

class Solution:
    def minCost(self, costs: List[List[int]]) -> int:
        if not costs:
            return 0
        red, blue, green = costs[0]
        for r, b, g in costs[1:]:
            red, blue, green = r + min(blue, green), b + min(red, green), g + min(red, blue)
        return min(red, blue, green)
