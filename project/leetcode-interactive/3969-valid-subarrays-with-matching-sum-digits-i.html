求和后首尾数字相同的有效子数组 I

把每个子数组的和看成一个“数位闸门”：它的最高位和最低位都必须等于 x。

题意

给定正整数数组 nums 与数字 x。连续非空子数组 nums[l..r] 的元素和若首位和末位都等于 x，它就是有效子数组；返回总数。

约束：1 ≤ nums.length ≤ 1500，1 ≤ nums[i] ≤ 10^9，1 ≤ x ≤ 9。I 版允许 O(n²) 枚举。

输入 输出 有效和
nums = [1,100,1]
x = 1		 4 1, 101, 101, 1
nums = [1]
x = 2		 0 没有匹配

主线算法

1. 前缀和

pref[i+1] = pref[i] + nums[i]，于是 sum(l,r) = pref[r+1] - pref[l]。

2. 枚举全部区间

枚举 0 ≤ l ≤ r < n。n 最多 1500，约 112 万个区间，可直接检查。

3. 数位过滤

最低位为 sum % 10；不断除以 10 直到小于 10，就得到最高位。

题解默认收起；可用 Enter 或空格展开。

题解：为什么 I 版用 O(n²) 就够

完整过程

  1. 先建立长度 n+1 的前缀和数组，避免每个区间重复累加。
  2. 外层确定左端点 l，内层枚举 r；每个区间和由两次前缀和相减得到。
  3. 判断 sum % 10 === x，再以循环取最高位并比较 x。
  4. 两个条件都成立时答案加一。

边界与复杂度

所有数均为正，因此区间和始终为正，无需处理负号或前导零。单元素区间也必须计入。前缀和 O(n)，双重枚举 O(n²)，空间 O(n)。

替代方案与面试追问

II 版通常需要利用数位范围、模 10 和数据结构来压缩枚举；本题约束小，优先给出清晰、可靠的 O(n²) 解法。若改为首位集合或末位集合，只需调整数位谓词。

常见错误

不要把最高位误写成 sum / 10（三位以上会错）；不要忽略单元素子数组；不要在内层循环重复求和，否则会退化为 O(n³)。
