模拟行走机器人Walking Robot Simulation

把命令拆成一个个格点动作：转向只改变朝向，前进则逐格试探障碍。真正要记录的不是终点距离，而是整段路程中曾达到的最大距离平方。

MEDIUM数组哈希表模拟非付费题
Problem

题意转述

机器人从无限 XY 平面的 (0, 0) 出发，初始面向北方。命令 -2 表示左转 90°，-1 表示右转 90°，正整数 k（1 到 9）表示向当前方向逐格前进 k 步。

若下一格是障碍物，机器人停在原地并立刻转到下一条命令。返回机器人沿途到原点的最大欧氏距离的平方，即最大 x² + y²。

原点特例：障碍物可以位于 (0, 0)。机器人起步时忽略脚下的障碍，但离开后不能再踏回原点。

函数参数：robotSim(commands: integer[], obstacles: integer[][]) → integer

Limits

方向与约束

  • 北 / 东 / 南 / 西分别对应 +Y / +X / -Y / -X。
  • 1 ≤ commands.length ≤ 10⁴
  • 每条命令为 -2、-1 或 [1, 9] 内整数。
  • 0 ≤ obstacles.length ≤ 10⁴
  • -3×10⁴ ≤ xᵢ, yᵢ ≤ 3×10⁴
  • 答案保证小于 2³¹。
Official examples

完整示例

示例 1

输入：commands = [4,-1,3], obstacles = [] 输出：25

先向北到 (0,4)，右转后向东到 (3,4)，最大距离平方为 3²+4²=25。

东行时在 (2,4) 前停于 (1,4)，左转向北到 (1,8)，最大距离平方为 65。

先到 (0,6)，两次右转后向南；因原点是障碍，最终停于 (0,1)，沿途最大值仍为 36。

Core insight

哈希障碍 + 逐格模拟

转向可以一次完成，移动必须逐格完成——因为障碍可能截断一条命令，而最大距离也可能出现在任意一步。

完整过程

  1. 把每个障碍坐标编码后存入哈希集合，支持 O(1) 期望时间查询。
  2. 用方向下标 0、1、2、3 表示北、东、南、西，并准备位移数组。
  3. 遇到 -1 或 -2 时只更新方向；遇到正数时循环逐格计算下一坐标。
  4. 若下一坐标是障碍，终止当前移动命令；否则更新位置和最大距离平方。

正确性说明

位置不变式：处理完每个单位步后，记录的位置恰好是机器人按题意可达的位置。转向命令按模 4 更新方向；移动命令只有在下一格无障碍时才前进，因此既不会穿越障碍，也不会少走可行的一步。

答案不变式：每次成功移动后都用当前位置的 x²+y² 更新最大值，所以变量始终等于已访问位置中的最大距离平方。全部命令结束后，它就是题目要求的答案。

边界

  • 无障碍、连续转向、负坐标都由统一方向数组处理。
  • 障碍紧邻机器人时，本条命令一步也不移动。
  • 原点是障碍时，初始位置合法；离开后若尝试返回，下一格查询会阻止进入原点。

复杂度

设障碍数为 m，所有正命令包含的单位步总数为 S（每条最多 9）。时间 O(m+S)，额外空间 O(m)。

替代方案

可以按 x、y 分组并排序障碍，利用二分搜索一次跳过整条移动命令；当单条命令距离非常大时更有价值。但本题每条移动最多 9，逐格模拟更直接，出错面也更小。

面试追问

  • 若单条命令可达 10⁹，如何用有序集合找到最近障碍？
  • 坐标范围未知时，如何设计无冲突的坐标编码？
  • 若要返回首次达到最大距离的时刻，需要额外维护什么？

常见错误

  • 只在每条命令结束后计算距离，忽略中途最大值。
  • 把整段移动直接加到坐标上，导致穿过障碍。
  • 左右转的模运算写反，或让负数取模产生错误方向。
  • 用字符串编码时分隔不清，造成坐标碰撞。

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int robotSim(int[] commands, int[][] obstacles) {
        Set<String> blocked = new HashSet<>();
        for (int[] o : obstacles) blocked.add(o[0] + "," + o[1]);

        int[][] dirs = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        int x = 0, y = 0, direction = 0, answer = 0;
        for (int command : commands) {
            if (command == -1) {
                direction = (direction + 1) % 4;
            } else if (command == -2) {
                direction = (direction + 3) % 4;
            } else {
                for (int step = 0; step < command; step++) {
                    int nx = x + dirs[direction][0];
                    int ny = y + dirs[direction][1];
                    if (blocked.contains(nx + "," + ny)) break;
                    x = nx;
                    y = ny;
                    answer = Math.max(answer, x * x + y * y);
                }
            }
        }
        return answer;
    }
}

from typing import List

class Solution:
    def robotSim(self, commands: List[int], obstacles: List[List[int]]) -> int:
        blocked = {(x, y) for x, y in obstacles}
        directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        x = y = direction = answer = 0

        for command in commands:
            if command == -1:
                direction = (direction + 1) % 4
            elif command == -2:
                direction = (direction - 1) % 4
            else:
                dx, dy = directions[direction]
                for _ in range(command):
                    nx, ny = x + dx, y + dy
                    if (nx, ny) in blocked:
                        break
                    x, y = nx, ny
                    answer = max(answer, x * x + y * y)

        return answer
