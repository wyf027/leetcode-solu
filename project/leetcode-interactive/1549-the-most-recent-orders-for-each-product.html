Problem brief

题意与返回格式

给定顾客、订单与商品三张表，找出每件至少产生过订单的商品在其最晚下单日期上的全部订单。若同一商品的最晚日期有多笔订单，必须全部保留。

返回列：product_name, product_id, order_id, order_date。先按 product_name 升序，再按 product_id 升序，最后按 order_id 升序。

约束与语义

  • customer_id、order_id、product_id 分别是对应表的主键。
  • 同一顾客在同一天不会重复订购同一种商品。
  • 商品可能从未被订购；这类商品不出现在结果中。
  • “最新”按 order_date 判断，不按更大的 order_id 猜测；并列最新订单全部输出。
  • 官方元数据未提供额外的数值范围，本页不虚构行数或取值上下界。

Solution

先锁定日期，再取回完整订单行

核心洞察

每个商品需要的不是“某一行”，而是一个最大日期。先按 product_id 聚合得到该日期，再用 product_id + order_date 回连原订单表，便能保留该日的所有并列订单。

为什么不用 MAX(order_id)

order_id 只是标识符，题意没有承诺它与日期单调一致。比较它会把“编号最大”误当成“日期最新”。

完整过程

  1. 从 Orders 按 product_id 分组，对每组求 MAX(order_date)。
  2. 将分组结果与 Orders 同时按商品编号、最新日期连接，取回订单编号；相同最新日期的行会全部命中。
  3. 连接 Products 取得商品名称。没有订单的商品从未进入分组，因此不会出现。
  4. 严格按名称、商品编号、订单编号三层升序排序。
官方提交语言 · MySQL主解
WITH latest_date AS (
    SELECT product_id, MAX(order_date) AS order_date
    FROM Orders
    GROUP BY product_id
)
SELECT
    p.product_name,
    o.product_id,
    o.order_id,
    o.order_date
FROM latest_date AS l
JOIN Orders AS o
  ON o.product_id = l.product_id
 AND o.order_date = l.order_date
JOIN Products AS p
  ON p.product_id = o.product_id
ORDER BY p.product_name ASC,
         o.product_id ASC,
         o.order_id ASC;

正确性说明

完备性：对任一有订单的商品 p，CTE 产生其最大订单日期 d；所有满足商品为 p 且日期为 d 的订单都会在双条件连接中匹配，因此并列最新订单无一遗漏。

排他性：任何被输出的订单都必须与其商品的最大日期相等，所以不可能输出更早订单。商品表连接只补充名称，不改变订单集合。最终排序满足题目规定。

复杂度

设订单数为 N、商品数为 P。逻辑扫描为 O(N)，最终排序为 O(R log R)（R 为结果行数）；数据库实际代价受执行计划与索引影响。CTE 及连接的中间空间约为 O(P)。

边界情况

  • 同一商品的最新日期存在多笔订单：全部保留。
  • 商品从未下单：排除。
  • 不同商品同名：仍按 product_id 分组，不串组。
  • 只有一笔订单：它自然就是最新订单。

替代方案

MySQL 8+ 可用 RANK() OVER (PARTITION BY product_id ORDER BY order_date DESC)，筛选排名 1。必须用 RANK 或 DENSE_RANK，不能用只保留一行的 ROW_NUMBER。也可使用相关子查询，但在大表上通常更依赖优化器与合适索引。

import java.util.*;

public class MostRecentOrders {
    record Product(int productId, String productName, int price) {}
    record Order(int orderId, String orderDate, int customerId, int productId) {}
    record Row(String productName, int productId, int orderId, String orderDate) {}

    public static List<Row> solve(
            List<?> customers,
            List<Order> orders,
            List<Product> products) {
        Map<Integer, String> latest = new HashMap<>();
        for (Order o : orders) {
            latest.merge(o.productId(), o.orderDate(),
                (a, b) -> a.compareTo(b) >= 0 ? a : b);
        }

        Map<Integer, Product> byId = new HashMap<>();
        for (Product p : products) byId.put(p.productId(), p);

        List<Row> answer = new ArrayList<>();
        for (Order o : orders) {
            if (o.orderDate().equals(latest.get(o.productId()))) {
                Product p = byId.get(o.productId());
                if (p != null) answer.add(new Row(
                    p.productName(), o.productId(), o.orderId(), o.orderDate()));
            }
        }
        answer.sort(Comparator.comparing(Row::productName)
            .thenComparingInt(Row::productId)
            .thenComparingInt(Row::orderId));
        return answer;
    }
}
function mostRecentOrders(customers, orders, products) {
  const latest = new Map();
  for (const order of orders) {
    const old = latest.get(order.product_id);
    if (old === undefined || order.order_date > old) {
      latest.set(order.product_id, order.order_date);
    }
  }

  const productById = new Map(
    products.map((product) => [product.product_id, product])
  );

  return orders
    .filter((order) =>
      order.order_date === latest.get(order.product_id)
    )
    .map((order) => ({
      product_name: productById.get(order.product_id).product_name,
      product_id: order.product_id,
      order_id: order.order_id,
      order_date: order.order_date,
    }))
    .sort((a, b) =>
      a.product_name.localeCompare(b.product_name) ||
      a.product_id - b.product_id ||
      a.order_id - b.order_id
    );
}
from typing import Any


def most_recent_orders(
    customers: list[dict[str, Any]],
    orders: list[dict[str, Any]],
    products: list[dict[str, Any]],
) -> list[dict[str, Any]]:
    latest: dict[int, str] = {}
    for order in orders:
        product_id = order["product_id"]
        latest[product_id] = max(
            latest.get(product_id, order["order_date"]),
            order["order_date"],
        )

    product_by_id = {p["product_id"]: p for p in products}
    answer = [
        {
            "product_name": product_by_id[o["product_id"]]["product_name"],
            "product_id": o["product_id"],
            "order_id": o["order_id"],
            "order_date": o["order_date"],
        }
        for o in orders
        if o["order_date"] == latest[o["product_id"]]
        and o["product_id"] in product_by_id
    ]
    return sorted(answer, key=lambda row: (
        row["product_name"], row["product_id"], row["order_id"]
    ))
#include <algorithm>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Product { int productId; string productName; int price; };
struct Order { int orderId; string orderDate; int customerId; int productId; };
struct Row { string productName; int productId; int orderId; string orderDate; };

vector<Row> mostRecentOrders(
    const vector<int>& customers,
    const vector<Order>& orders,
    const vector<Product>& products) {
    unordered_map<int, string> latest;
    for (const auto& order : orders) {
        auto it = latest.find(order.productId);
        if (it == latest.end() || order.orderDate > it->second)
            latest[order.productId] = order.orderDate;
    }

    unordered_map<int, Product> byId;
    for (const auto& product : products)
        byId.emplace(product.productId, product);

    vector<Row> answer;
    for (const auto& order : orders) {
        auto product = byId.find(order.productId);
        if (product != byId.end() &&
            order.orderDate == latest[order.productId]) {
            answer.push_back({product->second.productName,
                order.productId, order.orderId, order.orderDate});
        }
    }
    sort(answer.begin(), answer.end(), [](const Row& a, const Row& b) {
        if (a.productName != b.productName) return a.productName < b.productName;
        if (a.productId != b.productId) return a.productId < b.productId;
        return a.orderId < b.orderId;
    });
    return answer;
}

常见错误

  • 用 MAX(order_id) 替代最大日期。
  • 只按商品名分组，错误合并同名商品。
  • 用 ROW_NUMBER() 丢掉同日并列订单。
  • 聚合后直接选择非分组列，得到不确定值。
  • 漏掉第三层 order_id 排序。
