设计 Excel
求和公式

实现一个会记住公式的迷你电子表格：直接赋值、读取单元格，以及把单元格或矩形区域的和绑定到目标格。

#631图拓扑排序设计哈希表矩阵付费题

API surface

三个操作，一条语义链

set(row, column, val)覆盖
get(row, column)读取
sum(row, column, numbers)绑定并返回

公式不是一次性计算：它引用的单元格变化后，目标格的值也必须随之变化。

01 · Problem

题意与接口

准确转述

设计 Excel 类，维护一个 height 行、A 到 width 列的表格。行从 1 开始，列用大写字母标识，所有单元格初始值都是 0。

set 把某格设为整数，并移除该格原有公式；get 返回某格当前值；sum 为某格建立求和公式并立刻返回结果。

numbers 中每项要么是单格（如 A1），要么是闭区间矩形（如 A1:B2）。同一个单元格若被多个项或重叠区域覆盖，必须按出现次数重复计入。

动态语义：公式保留引用关系。被引用格之后发生变化时，再读取公式格应得到更新后的结果。输入保证不会形成循环引用。

官方类签名

Excel(int height, char width)构造
void set(int row, char column, int val)写值
int get(int row, char column)取值
int sum(int row, char column, String[] numbers)设公式

官方示例（完整参数形式）

输入
["Excel", "set", "sum", "set", "get"]
[[3, "C"], [1, "A", 2], [3, "C", ["A1", "A1:B2"]], [2, "B", 2], [3, "C"]]
输出
[null, null, 4, null, 6]

过程：Excel(3, 'C') 创建 A1:C3；set(1, 'A', 2) 令 A1=2；sum(3, 'C', ["A1", "A1:B2"]) 让 C3 引用 A1 两次、A2/B1/B2 各一次，所以返回 4。之后 B2 设为 2，get(3, 'C') 返回 6。

约束

  • 1 ≤ height ≤ 26
  • 'A' ≤ width ≤ 'Z'
  • 1 ≤ row ≤ height
  • 'A' ≤ column ≤ width
  • 0 ≤ val ≤ 100
  • 1 ≤ numbers.length ≤ 5
  • 引用格式为单格或合法的闭区间矩形
  • 引用位置始终在表格范围内
  • set / get / sum 总调用次数至多 100
  • 不会出现循环公式依赖

Solution · Lazy evaluation

把表格看成一张有向无环依赖图

选用“保存公式，读取时递归求值”的实现。题目规模很小，这条路线更紧凑，也天然保证公式引用始终读取最新值。

1

单元格有两种状态

常量格保存 value；公式格保存“被引用单元格 → 出现次数”的映射。二者互斥。

2

区间先展开

A1:B2 展成四个坐标。映射累计次数，正确处理重复项与重叠区域。

3

读取时沿边求值

公式格的值等于每个依赖格当前值乘以次数。一次读取内用 memo 避免共享子图被重复求值。

完整过程

  1. 统一坐标：把 (row, column) 转成一维编号，便于作为哈希键。
  2. set：写入常量值，并清空原公式映射。这样直接赋值会覆盖公式。
  3. sum：解析每个字符串；单格加入一次，矩形逐格展开；相同编号在映射中累加次数。
  4. get / evaluate：常量格直接返回；公式格递归求每个依赖的当前值并按次数加权。
  5. 单次记忆化：每次顶层读取创建新的 memo。它只缓存本次快照，不跨更新保留，因此不会产生脏缓存。

正确性说明

引理 1：解析后的映射中，每个单元格的计数恰等于它在 numbers 的单格项和所有矩形项中出现的总次数，因为每个闭区间位置被逐一枚举并累计。

引理 2：evaluate(x) 返回 x 的当前语义值。常量格显然成立；对公式格，依赖图无环，按拓扑深度归纳，所有依赖的递归结果正确，再按引理 1 的次数求和即为公式值。

定理：set 正确覆盖旧公式，sum 保存正确公式并返回其当前结果，get 返回目标格当前结果，所以所有接口都满足要求。

边界与细节

  • 单格区间如 A1:A1 与单格引用等价。
  • 重叠区域不能去重，必须累计 multiplicity。
  • set 之后目标格必须彻底失去旧公式。
  • 值为 0 仍是合法常量，不可用真假值判断状态。
  • 题目保证无环；若扩展为真实产品，应显式检测环。

复杂度

set
O(1)

清空目标公式并写常量。

sum 建式
O(K)

K 是 numbers 展开后的坐标总数。

get / sum 求值
O(V + E)

V、E 为本次可达依赖子图规模；单次 memo 后每格至多求值一次。

总空间为 O(HW + F)，其中 F 是所有公式中不同引用边的数量；单次求值另需 O(V) memo 与递归栈。

import java.util.HashMap;
import java.util.Map;

class Excel {
    private static class Cell {
        int value;
        Map<Integer, Integer> refs; // null means a constant cell
    }

    private final int height;
    private final int width;
    private final Cell[] cells;

    public Excel(int height, char width) {
        this.height = height;
        this.width = width - 'A' + 1;
        this.cells = new Cell[height * this.width];
        for (int i = 0; i < cells.length; i++) {
            cells[i] = new Cell();
        }
    }

    public void set(int row, char column, int val) {
        Cell cell = cells[id(row, column)];
        cell.value = val;
        cell.refs = null;
    }

    public int get(int row, char column) {
        return evaluate(id(row, column), new HashMap<>());
    }

    public int sum(int row, char column, String[] numbers) {
        Map<Integer, Integer> refs = new HashMap<>();
        for (String item : numbers) {
            String[] ends = item.split(":");
            int[] from = parseCell(ends[0]);
            int[] to = ends.length == 1 ? from : parseCell(ends[1]);
            for (int r = from[0]; r <= to[0]; r++) {
                for (int c = from[1]; c <= to[1]; c++) {
                    int refId = id(r, c);
                    refs.merge(refId, 1, Integer::sum);
                }
            }
        }

        Cell target = cells[id(row, column)];
        target.value = 0;
        target.refs = refs;
        return get(row, column);
    }

    private int evaluate(int cellId, Map<Integer, Integer> memo) {
        Integer cached = memo.get(cellId);
        if (cached != null) return cached;

        Cell cell = cells[cellId];
        if (cell.refs == null) return cell.value;

        int total = 0;
        for (Map.Entry<Integer, Integer> entry : cell.refs.entrySet()) {
            total += entry.getValue() * evaluate(entry.getKey(), memo);
        }
        memo.put(cellId, total);
        return total;
    }

    private int[] parseCell(String name) {
        int column = name.charAt(0) - 'A';
        int row = Integer.parseInt(name.substring(1)) - 1;
        return new int[]{row, column};
    }

    private int id(int row, char column) {
        return id(row - 1, column - 'A');
    }

    private int id(int zeroBasedRow, int zeroBasedColumn) {
        return zeroBasedRow * width + zeroBasedColumn;
    }
}
class Excel {
    constructor(height, width) {
        this.height = height;
        this.width = width.charCodeAt(0) - 64;
        this.cells = Array.from(
            { length: height * this.width },
            () => ({ value: 0, refs: null })
        );
    }

    set(row, column, val) {
        const cell = this.cells[this.id(row, column)];
        cell.value = val;
        cell.refs = null;
    }

    get(row, column) {
        return this.evaluate(this.id(row, column), new Map());
    }

    sum(row, column, numbers) {
        const refs = new Map();

        for (const item of numbers) {
            const ends = item.split(":");
            const from = this.parseCell(ends[0]);
            const to = ends.length === 1 ? from : this.parseCell(ends[1]);

            for (let r = from[0]; r <= to[0]; r++) {
                for (let c = from[1]; c <= to[1]; c++) {
                    const refId = this.rawId(r, c);
                    refs.set(refId, (refs.get(refId) || 0) + 1);
                }
            }
        }

        const target = this.cells[this.id(row, column)];
        target.value = 0;
        target.refs = refs;
        return this.get(row, column);
    }

    evaluate(cellId, memo) {
        if (memo.has(cellId)) return memo.get(cellId);

        const cell = this.cells[cellId];
        if (cell.refs === null) return cell.value;

        let total = 0;
        for (const [refId, count] of cell.refs) {
            total += count * this.evaluate(refId, memo);
        }
        memo.set(cellId, total);
        return total;
    }

    parseCell(name) {
        return [Number(name.slice(1)) - 1, name.charCodeAt(0) - 65];
    }

    id(row, column) {
        return this.rawId(row - 1, column.charCodeAt(0) - 65);
    }

    rawId(row, column) {
        return row * this.width + column;
    }
}
from collections import defaultdict
from typing import Dict, List, Optional


class Excel:
    def __init__(self, height: int, width: str):
        self.height = height
        self.width = ord(width) - ord("A") + 1
        self.values = [0] * (height * self.width)
        self.formulas: List[Optional[Dict[int, int]]] = [
            None for _ in range(height * self.width)
        ]

    def set(self, row: int, column: str, val: int) -> None:
        cell_id = self._id(row, column)
        self.values[cell_id] = val
        self.formulas[cell_id] = None

    def get(self, row: int, column: str) -> int:
        return self._evaluate(self._id(row, column), {})

    def sum(self, row: int, column: str, numbers: List[str]) -> int:
        refs: Dict[int, int] = defaultdict(int)

        for item in numbers:
            ends = item.split(":")
            start_row, start_col = self._parse_cell(ends[0])
            if len(ends) == 1:
                end_row, end_col = start_row, start_col
            else:
                end_row, end_col = self._parse_cell(ends[1])

            for current_row in range(start_row, end_row + 1):
                for current_col in range(start_col, end_col + 1):
                    refs[self._raw_id(current_row, current_col)] += 1

        target = self._id(row, column)
        self.values[target] = 0
        self.formulas[target] = dict(refs)
        return self.get(row, column)

    def _evaluate(self, cell_id: int, memo: Dict[int, int]) -> int:
        if cell_id in memo:
            return memo[cell_id]

        refs = self.formulas[cell_id]
        if refs is None:
            return self.values[cell_id]

        total = sum(
            count * self._evaluate(ref_id, memo)
            for ref_id, count in refs.items()
        )
        memo[cell_id] = total
        return total

    def _parse_cell(self, name: str):
        return int(name[1:]) - 1, ord(name[0]) - ord("A")

    def _id(self, row: int, column: str) -> int:
        return self._raw_id(row - 1, ord(column) - ord("A"))

    def _raw_id(self, row: int, column: int) -> int:
        return row * self.width + column
#include <bits/stdc++.h>
using namespace std;

class Excel {
private:
    struct Cell {
        int value = 0;
        bool isFormula = false;
        unordered_map<int, int> refs;
    };

    int height;
    int width;
    vector<Cell> cells;

    int rawId(int row, int column) const {
        return row * width + column;
    }

    int id(int row, char column) const {
        return rawId(row - 1, column - 'A');
    }

    pair<int, int> parseCell(const string& name) const {
        int column = name[0] - 'A';
        int row = stoi(name.substr(1)) - 1;
        return {row, column};
    }

    int evaluate(int cellId, unordered_map<int, int>& memo) {
        auto cached = memo.find(cellId);
        if (cached != memo.end()) return cached->second;

        Cell& cell = cells[cellId];
        if (!cell.isFormula) return cell.value;

        int total = 0;
        for (const auto& [refId, count] : cell.refs) {
            total += count * evaluate(refId, memo);
        }
        memo[cellId] = total;
        return total;
    }

public:
    Excel(int height, char width)
        : height(height), width(width - 'A' + 1), cells(height * this->width) {}

    void set(int row, char column, int val) {
        Cell& cell = cells[id(row, column)];
        cell.value = val;
        cell.isFormula = false;
        cell.refs.clear();
    }

    int get(int row, char column) {
        unordered_map<int, int> memo;
        return evaluate(id(row, column), memo);
    }

    int sum(int row, char column, vector<string> numbers) {
        unordered_map<int, int> refs;

        for (const string& item : numbers) {
            size_t colon = item.find(':');
            auto from = parseCell(item.substr(0, colon));
            auto to = colon == string::npos
                ? from
                : parseCell(item.substr(colon + 1));

            for (int r = from.first; r <= to.first; r++) {
                for (int c = from.second; c <= to.second; c++) {
                    refs[rawId(r, c)]++;
                }
            }
        }

        Cell& target = cells[id(row, column)];
        target.value = 0;
        target.isFormula = true;
        target.refs = move(refs);
        return get(row, column);
    }
};

替代方案

  • 反向依赖 + 增量传播：维护“谁依赖我”，每次 set 把差值沿图传播。读取 O(1)，但更新、公式替换和重复边管理更复杂。
  • 每次 DFS 不记忆化：代码最短，但共享子图会被反复计算，深层公式可能出现指数级重复。
  • 全表拓扑重算：适合批量刷新，不适合本题少量点查询。

面试追问

  • 如果输入不再保证无环，如何在写公式时检测环？
  • 表格扩大到百万单元格，如何改为稀疏存储？
  • 读多写少与写多读少，分别该选懒计算还是增量传播？
  • 如何支持多字母列名、公式撤销和批量更新事务？

常见错误

  • 只在 sum 时算一次，丢掉公式引用关系
  • 把引用放入 Set，错误消除重复次数
  • set 未清空目标格旧公式
  • 跨操作复用 memo，引用更新后仍返回旧值
  • 区间端点漏算，或混淆 0/1 基坐标
  • 递归未依赖“无环”保证，也没有自行检测环
