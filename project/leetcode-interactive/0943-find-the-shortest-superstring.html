LeetCode 943 · Bitmask DP

最短超级串

HARD

把每个单词都放进同一个字符串，并让最终长度尽可能短。先观察“相邻单词如何重叠”，再决定阅读完整题解。

题目

给定字符串数组 words，返回一个最短字符串，使数组中的每个字符串都是它的子串。若最短答案不唯一，返回任意一个即可。题目保证不存在某个单词是另一个单词的子串。

示例 1

输入：words = ["alex","loves","leetcode"]
输出："alexlovesleetcode"
解释：这些单词之间没有可利用的首尾重叠；任意排列拼接均可。

示例 2

输入：words = ["catg","ctaagt","gcta","ttca","atgcatc"]
输出："gctaagttcatgcatc"

约束

  • 1 <= words.length <= 12
  • 1 <= words[i].length <= 20
  • 每个单词只含小写英文字母，且所有单词互不相同。

完整题解

状态压缩动态规划

核心洞察

令 overlap[i][j] 为单词 i 的后缀与单词 j 的前缀能匹配的最大长度。所有单词总长度固定，所以最短超级串等价于寻找一条访问每个单词一次、且重叠收益总和最大的路径。

完整过程

  1. 枚举有序对 (i,j)，预计算最大首尾重叠。
  2. 定义 dp[mask][j]：集合 mask 中的单词均已使用，且最后一个单词是 j 时，能获得的最大重叠总和。
  3. 从 dp[mask][j] 转移到未使用的 k：候选值为 dp[mask][j] + overlap[j][k]，同时记录前驱。
  4. 在完整集合的所有终点中选收益最大的一个，沿前驱倒推排列，再按重叠长度补上每个单词未复用的后缀。

正确性

引理 1：给定一个单词排列，相邻两词使用最大首尾重叠不会使之后的拼接失去任何机会，因此该排列的最短拼接长度等于总长度减去相邻重叠之和。

引理 2：dp[mask][j] 枚举了所有恰好覆盖 mask 且以 j 结束的排列。其最后一步必由某个前驱 i 转移而来；对所有 i 取最大值，得到该状态的最优收益。

结论：完整 mask 上的最大收益对应全体单词的最短拼接；前驱恢复出的排列按最大重叠拼接，故构造结果最短且包含每个单词。

边界与复杂度

  • 单个单词时直接返回它；零重叠时任何 DP 选出的排列直接串联即可。
  • 答案不唯一时无需字典序最小；只需返回任意最短结果。
  • 重叠预计算最坏 O(n²L²)；DP 时间 O(2ⁿn²)，空间 O(2ⁿn)，其中 n<=12、L<=20。

替代方案与面试追问

全排列需要 O(n!)，即使预计算重叠也不如状态压缩 DP。若只求最短长度，可省去前驱数组；若要求字典序最小的最短答案，需要在收益相同的转移间比较完整构造串，成本会增加。若输入可能包含“某词是另一词子串”，应先去重并删除被包含项。

常见错误

  • 把重叠写成无向边；overlap[i][j] 与 overlap[j][i] 通常不同。
  • 恢复路径时漏掉第一个单词，或把前驱顺序反转两次。
  • 求最小新增长度却使用错误的初值；用“最大重叠收益”通常更清晰。

class Solution {
    public String shortestSuperstring(String[] words) {
        int n = words.length, size = 1 << n;
        int[][] ov = new int[n][n];
        for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) if (i != j)
            for (int k = Math.min(words[i].length(), words[j].length()); k >= 0; k--)
                if (words[i].endsWith(words[j].substring(0, k))) { ov[i][j] = k; break; }
        int[][] dp = new int[size][n], parent = new int[size][n];
        for (int[] row : parent) java.util.Arrays.fill(row, -1);
        for (int mask = 1; mask < size; mask++) for (int j = 0; j < n; j++)
            if ((mask & (1 << j)) != 0) {
                int prev = mask ^ (1 << j);
                for (int i = 0; i < n; i++) if ((prev & (1 << i)) != 0 && dp[prev][i] + ov[i][j] > dp[mask][j]) {
                    dp[mask][j] = dp[prev][i] + ov[i][j]; parent[mask][j] = i;
                }
            }
        int mask = size - 1, last = 0;
        for (int i = 1; i < n; i++) if (dp[mask][i] > dp[mask][last]) last = i;
        int[] order = new int[n];
        for (int p = n - 1; p >= 0; p--) { order[p] = last; int q = parent[mask][last]; mask ^= 1 << last; last = q; }
        StringBuilder ans = new StringBuilder(words[order[0]]);
        for (int p = 1; p < n; p++) ans.append(words[order[p]].substring(ov[order[p-1]][order[p]]));
        return ans.toString();
    }
}

  const dp=Array.from({length:size},()=>Array(n).fill(0));

class Solution:
    def shortestSuperstring(self, words: List[str]) -> str:
        n, size = len(words), 1 << len(words)
        ov = [[0] * n for _ in range(n)]
        for i in range(n):
            for j in range(n):
                if i != j:
                    for k in range(min(len(words[i]), len(words[j])), -1, -1):
                        if words[i].endswith(words[j][:k]):
                            ov[i][j] = k
                            break
        dp = [[0] * n for _ in range(size)]
        parent = [[-1] * n for _ in range(size)]
        for mask in range(1, size):
            for j in range(n):
                if mask & (1 << j):
                    prev = mask ^ (1 << j)
                    for i in range(n):
                        if prev & (1 << i) and dp[prev][i] + ov[i][j] > dp[mask][j]:
                            dp[mask][j] = dp[prev][i] + ov[i][j]
                            parent[mask][j] = i
        mask = size - 1
        last = max(range(n), key=lambda i: dp[mask][i])
        order = []
        while last != -1:
            order.append(last)
            nxt = parent[mask][last]
            mask ^= 1 << last
            last = nxt
        order.reverse()
        ans = words[order[0]]
        for a, b in zip(order, order[1:]): ans += words[b][ov[a][b]:]
        return ans
