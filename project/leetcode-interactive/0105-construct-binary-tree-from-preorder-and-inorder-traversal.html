题意

给定同一棵二叉树的前序遍历与中序遍历，构造并返回这棵树。输入保证有效，且节点值互不相同。

inorder = [9,3,15,20,7]

输出

inorder = [-1]

Constraints

约束与保证

  • 1 <= preorder.length <= 3000
  • inorder.length == preorder.length
  • -3000 <= preorder[i], inorder[i] <= 3000
  • 节点值唯一，两数组包含相同节点集合。
  • 两数组保证来自同一棵合法二叉树。
  • 本题没有字符串；字符串空格统一显示为 ␠。

        题解

        面试推荐主线：哈希表记录中序下标，递归窗口只传边界；全局前序指针按根、左、右自然推进。

        核心洞察

        前序遍历的第一个未使用节点一定是当前根。它在中序窗口中的位置唯一切出左右子树，左侧元素个数同时决定前序窗口边界。

        复杂度

        时间 O(n)哈希表 O(n)递归栈 O(h)

        退化链时 h = n；平衡树时 h = O(log n)。

        完整过程

        1. 预处理 inorder，建立“节点值 → 中序下标”哈希表。
        2. 进入合法中序窗口时，取 preorder[preIndex++] 为根。
        3. 由根的中序位置先递归构造左窗口，再构造右窗口。
        4. 空窗口返回 null，其余调用把左右子树接回根后返回。

        边界

        • 单节点的左右窗口都为空。
        • 全左/全右链会产生 O(n) 递归深度。
        • 负数可以直接作为哈希键。
        • 值若重复，单一下标映射不再足够。

        替代方案取舍

        • 每轮扫描中序：直观但最坏 O(n²)。
        • 显式栈迭代：规避调用栈，但推导更绕。
        • 复制子数组：代码短，却增加切片成本。

        面试追问

        • 为什么前序 + 中序能确定唯一树？
        • 后序 + 中序时根和递归顺序如何变化？
        • 只有前序 + 后序为何通常不唯一？
        • 如何改为迭代以避免深递归？

        常见错误

        • 先构造右子树，消费前序顺序错误。
        • 左右边界出现一位偏差。
        • 空窗口判断漏掉叶节点。
        • Python 忽略 3000 节点的递归限制。

        class Solution {
    private final Map<Integer, Integer> index = new HashMap<>();
    private int preIndex = 0;

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        for (int i = 0; i < inorder.length; i++) {
            index.put(inorder[i], i);
        }
        return build(preorder, 0, inorder.length - 1);
    }

    private TreeNode build(int[] preorder, int left, int right) {
        if (left > right) return null;
        int value = preorder[preIndex++];
        TreeNode root = new TreeNode(value);
        int split = index.get(value);
        root.left = build(preorder, left, split - 1);
        root.right = build(preorder, split + 1, right);
        return root;
    }
}
        var buildTree = function (preorder, inorder) {
    const index = new Map(inorder.map((value, i) => [value, i]));
    let preIndex = 0;

        const root = new TreeNode(value);
        const split = index.get(value);
        root.left = build(left, split - 1);
        root.right = build(split + 1, right);
        return root;

    return build(0, inorder.length - 1);
};

        pre_index = 0

            nonlocal pre_index
            if left > right:
                return None
            value = preorder[pre_index]
            pre_index += 1
            root = TreeNode(value)
            split = index[value]
            root.left = build(left, split - 1)
            root.right = build(split + 1, right)
            return root

        return build(0, len(inorder) - 1)
        class Solution {
private:
    unordered_map<int, int> index;
    int preIndex = 0;

    TreeNode* build(const vector<int>& preorder, int left, int right) {
        if (left > right) return nullptr;
        int value = preorder[preIndex++];
        TreeNode* root = new TreeNode(value);
        int split = index[value];
        root->left = build(preorder, left, split - 1);
        root->right = build(preorder, split + 1, right);
        return root;
    }

public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        for (int i = 0; i < static_cast<int>(inorder.size()); i++) {
            index[inorder[i]] = i;
        }
        return build(preorder, 0, static_cast<int>(inorder.size()) - 1);
    }
};
