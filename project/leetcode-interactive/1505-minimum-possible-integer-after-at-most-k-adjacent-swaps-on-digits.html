最多 K 次交换相邻数位后得到的最小整数

Minimum Possible Integer After at Most K Adjacent Swaps On Digits

核心标签贪心 · 树状数组
输入规模n ≤ 30,000
交换预算k ≤ 10⁹
Problem

题意

给定一个只包含数字的字符串 num，它表示一个非常大的整数；再给定整数 k。每次操作可以交换一对相邻数位，最多进行 k 次。

返回在预算内能够得到的字典序最小数字字符串。结果允许出现前导零。

  • 贪心
  • 树状数组
  • 线段树
  • 字符串
Examples

官方示例

输入：num = "4321", k = 4 输出："1342" 解释：使用 4 次相邻交换可得到最小结果。
输入：num = "100", k = 1 输出："010" 解释：输出可以包含前导 0。
输入：num = "36789", k = 1000 输出："36789" 解释：保持原数、不进行交换也是合法选择。
Constraints

约束

  • 1 ≤ num.length ≤ 3 × 10⁴
  • num 只包含数字，且输入不含前导零。
  • 1 ≤ k ≤ 10⁹

Full Solution

贪心选择 + 树状数组维护动态位置

关键不是模拟每一次相邻交换，而是计算某个原始位置的数字当前需要跨过多少个未使用数字。

核心洞察

字典序优先结果的第一处不同决定大小，所以每一位都应选择预算内能放到当前位置的最小数字。
同数字取最早若要选择数字 d，取它尚未使用的最早原始位置永远成本最低，也不会让后续更差。
成本会动态变化原下标为 p 的数字，其前方被取走的数量记为 removed；当前移动成本就是 p − removed。
Fenwick Tree树状数组记录哪些原始位置已经取走，可在 O(log n) 内求前缀删除数并更新单点。

完整过程

  1. 为 0…9 分别建立位置队列，按从左到右顺序保存它们在 num 中的原始下标。
  2. 构造答案的下一位时，从数字 0 开始枚举到 9。只查看该数字队首的原始位置 p。
  3. 树状数组查询 p 之前已经取走多少个位置，设为 removed；则当前成本 cost = p - removed。
  4. 遇到第一个满足 cost ≤ k 的数字，追加到答案、扣减预算、弹出队首，并在树状数组中标记位置 p 已取走。
  5. 重复 n 轮。每轮一定至少能选择当前剩余序列的第一个数字，因为它的移动成本为 0。
以 4321，k = 4 为例：先把 1 向左移动 3 格，得到前缀 1、预算剩 1；下一轮 2 需要 2 次，无法选择，而 3 只需 1 次，于是得到前缀 13；预算耗尽后保持剩余相对顺序，最终为 1342。

正确性证明

引理 1：同一数字选择最早出现者最优

同一数字的多个未使用位置中，越靠前者前方未使用数字不会更多，因此移动成本最小。选择更晚的相同数字既不会改善当前位，还会消耗不少于前者的预算。

引理 2：每轮选择可达的最小数字是安全的

设算法在当前位选择 x。任何比 x 更小的数字都因成本超过剩余预算而不可达；任何选择 y > x 的合法方案，在当前位已经字典序更大。选择 x 后，其余数字的相对顺序不变，剩余问题仍是相同形式。

定理：算法返回预算内的最小整数

由引理 1，可只检查每个数字的最早未使用位置；由引理 2，算法每一位的选择都与某个全局最优解一致。逐位应用该结论，归纳可得整个答案在所有合法结果中字典序最小。

复杂度

每个答案位置最多检查 10 个数字，每次前缀查询与更新为 O(log n)。

时间：O(10n log n) = O(n log n)
空间：O(n)

边界处理

  • 结果允许前导零，不能做整数解析。
  • k 很大时可自然得到全排序结果，无需特殊分支。
  • k 耗尽后算法仍可用成本 0 依次取剩余首位。
  • 位置与预算运算应覆盖 10⁹；四种实现所用整数范围均足够。

替代方案与取舍

线段树：同样可以维护已删除位置的区间和，复杂度相同，但常数与代码量通常更大。有序集合：能维护剩余位置，却不如前缀计数直接。朴素数组模拟：每次真实移动数字最坏达到 O(n²)，无法承受 3 × 10⁴ 的规模。

面试追问

为什么只枚举 10 个候选？字符集固定为十进制数字。每类只需看队首，候选总数恒为 10。
若字符集很大怎么办？可用维护“字符最小值 + 最早位置”的线段树，或按字符有序的数据结构寻找首个可达候选。
如何恢复交换序列？每次选中位置后，可按当前序列位置输出它与左邻位连续交换的操作；但输出本身可能长达 k。
为何不是 cost = 原下标 − 答案长度？已取走的位置未必都在 p 之前，只有 p 前方的删除才会缩短它到当前队首的距离。

常见错误

  • 直接排序所有可见数字，忽略把数字移到前面需要跨越的真实距离。
  • 对相同数字选择任意位置，而不是成本最低的最早位置。
  • 树状数组下标混用 0-based 与 1-based，导致前缀删除数多算或少算一个。
  • 将结果转换为数值，丢失合法的前导零，或因超大整数而溢出。

import java.util.*;

class Solution {
    static class Fenwick {
        int[] tree;

        Fenwick(int n) {
            tree = new int[n + 1];
        }

        void add(int index, int delta) {
            for (int i = index; i < tree.length; i += i & -i) {
                tree[i] += delta;
            }
        }

        int sum(int index) {
            int result = 0;
            for (int i = index; i > 0; i -= i & -i) {
                result += tree[i];
            }
            return result;
        }
    }

    public String minInteger(String num, int k) {
        int n = num.length();
        Deque<Integer>[] positions = new ArrayDeque[10];
        for (int d = 0; d < 10; d++) positions[d] = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            positions[num.charAt(i) - '0'].offerLast(i);
        }

        Fenwick removed = new Fenwick(n);
        StringBuilder answer = new StringBuilder(n);

        for (int placed = 0; placed < n; placed++) {
            for (int d = 0; d < 10; d++) {
                if (positions[d].isEmpty()) continue;

                int originalIndex = positions[d].peekFirst();
                int removedBefore = removed.sum(originalIndex);
                int cost = originalIndex - removedBefore;

                if (cost <= k) {
                    k -= cost;
                    answer.append(d);
                    positions[d].pollFirst();
                    removed.add(originalIndex + 1, 1);
                    break;
                }
            }
        }
        return answer.toString();
    }
}

var minInteger = function(num, k) {
    const n = num.length;
    const positions = Array.from({ length: 10 }, () => []);
    const heads = Array(10).fill(0);

    for (let i = 0; i < n; i++) {
        positions[Number(num[i])].push(i);
    }

    const tree = Array(n + 1).fill(0);

    function add(index, delta) {
        for (let i = index; i <= n; i += i & -i) tree[i] += delta;
    }

    function sum(index) {
        let result = 0;
        for (let i = index; i > 0; i -= i & -i) result += tree[i];
        return result;
    }

    const answer = [];
    for (let placed = 0; placed < n; placed++) {
        for (let digit = 0; digit < 10; digit++) {
            if (heads[digit] === positions[digit].length) continue;

            const originalIndex = positions[digit][heads[digit]];
            const cost = originalIndex - sum(originalIndex);

            if (cost <= k) {
                k -= cost;
                answer.push(String(digit));
                heads[digit]++;
                add(originalIndex + 1, 1);
                break;
            }
        }
    }
    return answer.join('');
};
from collections import deque


class Solution:
    def minInteger(self, num: str, k: int) -> str:
        n = len(num)
        positions = [deque() for _ in range(10)]
        for index, char in enumerate(num):
            positions[int(char)].append(index)

        tree = [0] * (n + 1)

        def add(index: int, delta: int) -> None:
            while index <= n:
                tree[index] += delta
                index += index & -index

        def prefix_sum(index: int) -> int:
            result = 0
            while index > 0:
                result += tree[index]
                index -= index & -index
            return result

        answer = []
        for _ in range(n):
            for digit in range(10):
                if not positions[digit]:
                    continue

                original_index = positions[digit][0]
                removed_before = prefix_sum(original_index)
                cost = original_index - removed_before

                if cost <= k:
                    k -= cost
                    answer.append(str(digit))
                    positions[digit].popleft()
                    add(original_index + 1, 1)
                    break

        return ''.join(answer)
#include <array>
#include <deque>
#include <string>
#include <vector>
using namespace std;

class Solution {
    class Fenwick {
        vector<int> tree;

    public:
        explicit Fenwick(int n) : tree(n + 1, 0) {}

        void add(int index, int delta) {
            for (int i = index; i < static_cast<int>(tree.size()); i += i & -i) {
                tree[i] += delta;
            }
        }

        int sum(int index) const {
            int result = 0;
            for (int i = index; i > 0; i -= i & -i) result += tree[i];
            return result;
        }
    };

public:
    string minInteger(string num, int k) {
        int n = static_cast<int>(num.size());
        array<deque<int>, 10> positions;
        for (int i = 0; i < n; ++i) positions[num[i] - '0'].push_back(i);

        Fenwick removed(n);
        string answer;
        answer.reserve(n);

        for (int placed = 0; placed < n; ++placed) {
            for (int digit = 0; digit < 10; ++digit) {
                if (positions[digit].empty()) continue;

                int originalIndex = positions[digit].front();
                int removedBefore = removed.sum(originalIndex);
                int cost = originalIndex - removedBefore;

                if (cost <= k) {
                    k -= cost;
                    answer.push_back(static_cast<char>('0' + digit));
                    positions[digit].pop_front();
                    removed.add(originalIndex + 1, 1);
                    break;
                }
            }
        }
        return answer;
    }
};
