TREASURE MAP · BFS + BITMASK DP

LCP 13. 寻宝

在迷宫中触发所有机关 M 后才能取得宝藏 T。每次至多搬一块石头；石堆 O 有无限石头。求从 S 开始的最短步数。

LCP 13困难关键点最短路 + TSP DP

题意

机关 M 必须放上一块来自石堆 O 的重石才会持续触发；搬起或放下不计步。墙 # 不可通过，其余格均可通行。S、T 各唯一，机关最多 16 个。

示例

maze = ["S#O", "M..", "M.T"]

输出 = 16

每触发一个机关，都要从当前关键点走到某个石堆，再携石走到目标机关。

关键拆分

只对 S 和每个 M 做 BFS。经石堆从 A 到 B 的最短“带石头”代价为 minO(dist(A,O)+dist(B,O))。这些代价组成机关间完全图，再做子集 DP。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

题解：将迷宫压缩为机关旅行问题

对起点 S 和每个机关 M 分别 BFS，得到它们到所有石堆、宝藏和机关的最短距离。首次触发机关 i 的成本为 minO(dist(S,O)+dist(Mi,O))；已在机关 i 时，转到未触发机关 j 的成本为 minO(dist(Mi,O)+dist(Mj,O))。最后从最后机关直接走到 T。

BFS

网格边权均为 1；BFS 给出关键点到石堆和 T 的最短距离。任一必需距离不可达即返回 -1。

状态

dp[mask][i]：已触发 mask 中机关，最后在 i 的最小步数。转移到 j 时加入经石堆的代价。

复杂度

BFS 为 O((M+1)RC)，DP 为 O(M²2^M)，M≤16；空间 O(M2^M+RC)。

边界、替代方案与面试追问

没有机关时不需石堆，答案就是 S 到 T。必须在机关间转移时经由石堆；直接用 M 到 M 的距离会漏掉取石成本。若石头有限或可携多块，关键点状态需加入剩余石头/携带量。

Python

from typing import List
from collections import deque
class Solution:
 def minimalSteps(self, maze: List[str]) -> int:
  R,C=len(maze),len(maze[0]); ms=[]; os=[]
  for i in range(R):
   for j,c in enumerate(maze[i]):
    if c=='M': ms.append((i,j))
    elif c=='O': os.append((i,j))
    elif c=='S': S=(i,j)
    elif c=='T': T=(i,j)
  def bfs(p):
   d=[[-1]*C for _ in range(R)]; d[p[0]][p[1]]=0; q=deque([p])
   while q:
    r,c=q.popleft()
    for x,y in ((r+1,c),(r-1,c),(r,c+1),(r,c-1)):
     if 0<=x<R and 0<=y<C and maze[x][y]!='#' and d[x][y]<0:d[x][y]=d[r][c]+1;q.append((x,y))
   return d
  sd=bfs(S); n=len(ms)
  if not n:return sd[T[0]][T[1]]
  bd=[bfs(p) for p in ms]; INF=10**9; st=[INF]*n; ed=[bd[i][T[0]][T[1]] for i in range(n)]; w=[[INF]*n for _ in range(n)]
  for i in range(n):
   for x,y in os:
    if sd[x][y]>=0 and bd[i][x][y]>=0: st[i]=min(st[i],sd[x][y]+bd[i][x][y])
    for j in range(n):
     if bd[i][x][y]>=0 and bd[j][x][y]>=0:w[i][j]=min(w[i][j],bd[i][x][y]+bd[j][x][y])
  dp=[[INF]*n for _ in range(1<<n)]
  for i in range(n):dp[1<<i][i]=st[i]
  for mask in range(1,1<<n):
   for i in range(n):
    for j in range(n):
     if not mask>>j&1:dp[mask|1<<j][j]=min(dp[mask|1<<j][j],dp[mask][i]+w[i][j])
  ans=min(dp[-1][i]+ed[i] for i in range(n));return -1 if ans>=INF else ans
