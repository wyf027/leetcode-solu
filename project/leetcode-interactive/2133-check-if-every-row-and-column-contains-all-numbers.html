01 / PROBLEM

题目与输入约定

给定整数方阵 matrix，大小为 n × n。当它的每一行、每一列都包含从 1 到 n 的全部整数（含端点）时，返回 true；否则返回 false。这里没有额外的子宫格或对角线条件。

参数：matrix: integer[][]；返回：boolean；入口：checkValid(matrix)。

  • n == matrix.length == matrix[i].length
  • 1 ≤ n ≤ 100
  • 1 ≤ matrix[i][j] ≤ n

官方示例 1

输入：matrix = [[1,2,3],[3,1,2],[2,3,1]]
输出：true

n = 3，每一行和每一列都能找到 1、2、3。

官方示例 2

输入：matrix = [[1,1,1],[1,2,3],[1,2,3]]
输出：false

n = 3，第一行与第一列都缺少 2、3，因此矩阵无效。

04 / SOLUTION

想清楚后，再打开题解

包含推导、正确性、复杂度和四语言实现。

核心洞察：n 个合法值，无重复就意味着全覆盖

一行只有 n 个位置，而每个值都落在 1…n。如果 n 个值互不相同，它们必然恰好就是 1…n。列也同理。因此，只需分别检查每一行、每一列是否存在重复。

完整过程

  1. 外层枚举下标 i，同时处理第 i 行和第 i 列，创建两份长度 n + 1 的布尔标记数组 row、col。
  2. 内层枚举 j，读取 a = matrix[i][j]、b = matrix[j][i]。
  3. 若 row[a] 或 col[b] 已标记，则对应行或列有重复，立即返回 false。否则分别标记 a、b。
  4. 处理下一组行列时重新创建标记；所有组完成后返回 true。

例如示例 1 的 i = 0：行轨依次收集 1、2、3，列轨依次收集 1、3、2。二者顺序不同，但均无重复。示例 2 在 i = 0、j = 1 时，行轨与列轨都再次读到 1，立刻返回 false。演示中的位置采用从 1 开始的编号，代码采用从 0 开始的下标。

正确性

循环不变式：固定 i，在处理第 j 个位置前，row 恰好标记这一行前 j 个值，col 恰好标记这一列前 j 个值，且此前未出现重复。初始两者为空，不变式成立；新值未出现时标记它们，不变式保持。

拒绝可靠：若某值已标记，则同一行或同一列确实重复；n 个位置中有重复就无法容纳 1…n 的全部 n 种值，所以返回 false 正确。接受完整：若全部循环结束，每一行和每一列均有 n 个互异的合法值，故都恰好覆盖 1…n，返回 true 正确。

边界与复杂度

n = 1 时唯一合法输入是 [[1]]，应返回 true。对角线元素会分别进入行标记与列标记，不算冲突。题目保证方阵和数值范围；提交代码依赖这些约束，通用接口若接收外部数据，应先校验形状、整数类型与范围。

时间 O(n²)：最多访问 n² 对行列元素，每轮初始化标记也是 O(n)，总量仍为 O(n²)。额外空间 O(n)：同时只保留当前行和列的两份标记；输入不修改。提前遇到重复可提前结束，以上为最坏界。

替代方案

  • 集合：为每行、每列分别维护 Set，检查大小是否为 n，思路直观；哈希实现下期望时间 O(n²)、额外空间 O(n)。
  • 排序：复制每条行列并排序，与 1…n 比较，时间 O(n² log n)，额外空间 O(n)，更慢但易解释。
  • 不能只检查总和。例如 [1,1,4,4] 与 [1,2,3,4] 总和同为 10，前者却缺少 2、3。也不要把 XOR 当作唯一性证明。

常见错误

  • 只验证行，漏掉所有行相同但列重复的反例。
  • 把列取值也写成 matrix[i][j]，相当于检查了两次行。
  • 使用全矩阵共用的标记，或更换 i 时忘记清空。
  • 将 row 与 col 共用同一数组，使对角线值引发错误冲突。
  • 标记数组仅分配 n 个位置，却直接用 1…n 作为下标。

面试追问

数值不保证在 1…n 怎么办？先做范围检查；只有“互异”不能排除 0 或 n + 1。能否 O(1) 空间？若允许修改输入，可研究原地符号标记并恢复，但必须处理提前返回的恢复问题；本题布尔数组更清晰。JavaScript 的普通位运算只有 32 位，不能直接用单个 Number 位掩码覆盖 n = 100。每次修改一个格子后立即查询呢？可维护各行列的频次及异常计数，以更多空间换取增量更新。

Java

class Solution {
    public boolean checkValid(int[][] matrix) {
        int n = matrix.length;
        for (int i = 0; i < n; i++) {
            boolean[] row = new boolean[n + 1];
            boolean[] col = new boolean[n + 1];
            for (int j = 0; j < n; j++) {
                int a = matrix[i][j], b = matrix[j][i];
                if (row[a] || col[b]) return false;
                row[a] = true;
                col[b] = true;
            }
        }
        return true;
    }
}

Python 3

from typing import List

class Solution:
    def checkValid(self, matrix: List[List[int]]) -> bool:
        n = len(matrix)
        for i in range(n):
            row = [False] * (n + 1)
            col = [False] * (n + 1)
            for j in range(n):
                a, b = matrix[i][j], matrix[j][i]
                if row[a] or col[b]:
                    return False
                row[a] = True
                col[b] = True
        return True

                col[b] = true;
            }
        }
        return true;
    }
