905. 按奇偶排序数组

Sort Array By Parity — 把偶数移动到数组前部、奇数放到后部；同一奇偶类别内无需保持原顺序。

题目

给定整数数组 nums，重新排列元素，使所有偶数都出现在所有奇数之前。返回任意一个满足条件的数组。

函数形式
sortArrayByParity(nums: integer[]) → integer[]

约束

  • 1 <= nums.length <= 5000
  • 0 <= nums[i] <= 5000

官方示例

输入：nums = [3,1,2,4]
输出：[2,4,3,1]
解释：[4,2,3,1]、[2,4,1,3]、[4,2,1,3] 也正确。
输入：nums = [0]
输出：[0]

输出不唯一；判定关键是分界点前全为偶数、之后全为奇数。

题解：相向双指针原地分区

O(n) 时间 · O(1) 额外空间

核心洞察

最终只要求“偶数区域在前、奇数区域在后”，不要求稳定顺序。让左指针寻找放错位置的奇数，右指针寻找放错位置的偶数，交换这一对即可同时修复两个位置。

完整过程

  1. left = 0，right = n - 1。
  2. 左端是偶数时右移 left；右端是奇数时左移 right。
  3. 若仍有 left < right，交换两端元素，再继续扫描。
  4. 指针相遇或交错时返回数组。

正确性

循环不变式：每轮开始时，left 左侧均为偶数，right 右侧均为奇数。扫描只越过已在正确区域的元素；交换时左侧奇数与右侧偶数各归其位，因此不变式继续成立。终止时未确定区间为空，于是所有偶数都位于所有奇数之前。

边界

  • 单元素数组直接满足条件。
  • 全偶或全奇时只有一个指针持续移动，无需交换。
  • 0 是偶数。
  • 答案不唯一，不应依赖稳定顺序。

复杂度

每个元素最多被指针访问常数次，时间 O(n)；原地交换，额外空间 O(1)。

四语言完整代码

Java

class Solution {
    public int[] sortArrayByParity(int[] nums) {
        int left = 0, right = nums.length - 1;
        while (left < right) {
            while (left < right && nums[left] % 2 == 0) left++;
            while (left < right && nums[right] % 2 == 1) right--;
            if (left < right) {
                int temp = nums[left];
                nums[left++] = nums[right];
                nums[right--] = temp;
            }
        }
        return nums;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number[]}
 */
var sortArrayByParity = function(nums) {
    let left = 0, right = nums.length - 1;
    while (left < right) {
        while (left < right && nums[left] % 2 === 0) left++;
        while (left < right && nums[right] % 2 === 1) right--;
        if (left < right) {
            [nums[left], nums[right]] = [nums[right], nums[left]];
            left++;
            right--;
        }
    }
    return nums;
};

C++

class Solution {
public:
    vector<int> sortArrayByParity(vector<int>& nums) {
        int left = 0, right = static_cast<int>(nums.size()) - 1;
        while (left < right) {
            while (left < right && nums[left] % 2 == 0) ++left;
            while (left < right && nums[right] % 2 == 1) --right;
            if (left < right) {
                swap(nums[left], nums[right]);
                ++left;
                --right;
            }
        }
        return nums;
    }
};

替代方案

新建结果数组，先追加偶数、再追加奇数，逻辑直观且能轻松做成稳定分区，但需要 O(n) 额外空间。直接按奇偶键排序通常为 O(n log n)，没有必要。

面试追问

  • 若要求保持原相对顺序，怎样实现？
  • 能否推广为“满足谓词的元素在前”？
  • 如果输入是链表，如何原地重连节点？

常见错误

  • 把 0 误判为奇数。
  • 交换后不移动指针，导致重复检查甚至死循环。
  • 用固定期望数组判断，忽略答案可以不唯一。
  • 内层扫描未同时检查 left < right，造成越界风险。
