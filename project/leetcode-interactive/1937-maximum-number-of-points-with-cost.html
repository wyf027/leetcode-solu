扣分后的最大得分

Maximum Number of Points with Cost

每行拿一个分数，跨列移动需要付费。看似更大的格子，扣掉路费后还值得选吗？先走一条自己的路线，再展开底部题解。

逐行选点距离扣分离线交互

01 / 题目规则

给定下标从 0 开始的 m × n 整数矩阵 points。从 0 分开始，必须在每一行恰好选择一个格子。选择第 r 行第 c 列会获得 points[r][c] 分；相邻两行选择列号 c₁、c₂ 时，再扣掉 |c₁ − c₂| 分。返回所有选法中的最大总得分，无需返回路线。绝对值表示两列之间的非负距离。

选择 c[0], c[1], …, c[m−1]
总分 = Σ points[r][c[r]] − Σ |c[r] − c[r−1]|
         r = 0 … m−1         r = 1 … m−1

约束

  • m == points.length
  • n == points[r].length，每行长度相同。
  • 1 ≤ m, n ≤ 10⁵
  • 1 ≤ m × n ≤ 10⁵
  • 0 ≤ points[r][c] ≤ 10⁵

05 / 独立题解

准备好后展开：推导、扫描演示与四语言代码。

用两次扫描消除枚举上一列

核心洞察

定义 dp[j] 为上一行以第 j 列结束的最大净分。当前行选 j，需从所有上一列 k 中寻找 dp[k] − |k−j| 的最大值。每向目标列走一步，候选得分恰好减少 1，因此可把最佳候选沿左右方向传播。

cur[j] = points[r][j] + max_k(dp[k] − |k − j|)

k ≤ j：dp[k] − (j−k) = (dp[k] + k) − j
k ≥ j：dp[k] − (k−j) = (dp[k] − k) + j

L[0] = dp[0]
L[j] = max(dp[j], L[j−1] − 1)         // 从左向右
R[n−1] = dp[n−1]
R[j] = max(dp[j], R[j+1] − 1)         // 从右向左
cur[j] = points[r][j] + max(L[j], R[j])

完整过程

  1. 首行无路费，初始化 dp = points[0] 的副本。
  2. 对每一后续行，从左向右填写 L，保留“从左侧任一列过来”的最优分数。
  3. 从右向左填写 R，保留“从右侧任一列过来”的最优分数。
  4. 每列取 max(L[j], R[j])，再加上当前格子的值，生成全新 cur。
  5. 本行全部算完后，令 dp = cur。最后返回 dp 中最大值。

双向衰减波 · 每步更新一列

使用实验室中已应用的矩阵。旧 dp 保持不变，L / R 是扣除距离后的候选，cur 才加入本行分值。绿色表示本步刚更新的列，“·”表示尚未计算。

示例 1：初始 dp = [1,2,3]；第 1 行 L = [1,2,3]、R = [1,2,3]，得到 dp = [2,7,4]；第 2 行 L = [2,7,6]、R = [6,7,4]，得到 dp = [9,8,7]，最大值为 9。

为什么正确

扫描不变式：L[j] = maxk≤j(dp[k] − (j−k))。j=0 时只有 k=0。若前一列成立，所有 k<j 的候选走到 j 都再扣 1，即 L[j−1]−1；与本列 dp[j] 比较便覆盖全部 k≤j。R 的证明左右对称。

行间归纳：首行 dp 正确。假设上一行 dp 已是各终点的最优值，任何当前行终点 j 的路线都有某个上一列 k。左右扫描覆盖所有 k，取较大者再加本行分值，恰好等于该终点的最优值。由归纳法，每行 dp 均正确；末行可在任意列结束，取最大值即答案。

边界与数值范围

  • m=1：直接取首行最大值。
  • n=1：始终同列，没有扣分，累加全部行。
  • 全零：一直保持同列即可得 0。
  • 并列最优无需指定路径；题目只返回分数。
  • 答案最多 10¹⁰，Java 使用 long，C++ 使用 long long。Python 整数足够；JS Number 的安全整数上限约 9×10¹⁵，足够精确。

复杂度

每行三次线性扫描，时间 O(mn)；dp、L、R、cur 都为长度 n，额外空间 O(n)。不会修改输入。

教学动画保存各扫描步骤的数组副本，并限制 8×8；该演示开销不等同于下面提交代码的复杂度。

替代方案

  • 朴素 DP：对每个 j 枚举所有 k，O(mn²) 时间、O(n) 空间；容易理解，但多行宽矩阵下会超时。
  • 前后缀最大值：预计算 dp[k]+k 的前缀最大值和 dp[k]−k 的后缀最大值，也是 O(mn)。与衰减扫描本质相同。
  • 更少数组：将左右传播合入一个候选数组再加本行值，可减小常数。这里保留显式 L/R 便于核对含义。

常见错误

  • 每行选最大值的贪心忽略了后续路费，例如 [[10,0,9],[0,0,100]] 应从 9 开始。
  • 写成 L[j−1]+1：移动是扣分，不是加分。
  • 在旧 dp 上提前叠加本行值，可能让同一行被重复取分；先完成转移，再换行。
  • 忘记右扫描，遗漏来自右边的最优前驱。
  • 返回最后一列而非整行最大值；或使用 32 位整数导致溢出。
  • JS 用 Math.max(...dp) 可能在很宽的行触发参数数量限制；代码改用 reduce。

面试追问

  • 移动成本变成 w·|k−j|？固定 w≥0 时，把每步 −1 改为 −w，仍然 O(mn)。
  • 需要恢复路线？扫描时同时保留最佳来源列，为每个状态存前驱；从末行最大状态倒推，常规实现需要 O(mn) 前驱空间。
  • 扣分为 (k−j)²？相邻位置的扣分增量不再恒为 1，当前扫描不能直接复用，可考虑凸包优化或平方距离变换。
  • 格子允许负数？状态定义仍成立；应以真实 dp 值初始化边界，避免把不存在的路径当成 0。

Java

class Solution {
    public long maxPoints(int[][] points) {
        int m = points.length, n = points[0].length;
        long[] dp = new long[n];
        for (int j = 0; j < n; j++) dp[j] = points[0][j];
        for (int r = 1; r < m; r++) {
            long[] left = new long[n], right = new long[n];
            long[] cur = new long[n];
            left[0] = dp[0];
            for (int j = 1; j < n; j++)
                left[j] = Math.max(dp[j], left[j - 1] - 1);
            right[n - 1] = dp[n - 1];
            for (int j = n - 2; j >= 0; j--)
                right[j] = Math.max(dp[j], right[j + 1] - 1);
            for (int j = 0; j < n; j++)
                cur[j] = points[r][j] + Math.max(left[j], right[j]);
            dp = cur;
        }
        long answer = dp[0];
        for (long value : dp) answer = Math.max(answer, value);
        return answer;
    }
}

/**

var maxPoints = function(points) {
    const n = points[0].length;
    let dp = points[0].slice();
    for (let r = 1; r < points.length; r++) {
        const left = Array(n), right = Array(n), cur = Array(n);
        left[0] = dp[0];
        for (let j = 1; j < n; j++)
            left[j] = Math.max(dp[j], left[j - 1] - 1);
        right[n - 1] = dp[n - 1];
        for (let j = n - 2; j >= 0; j--)
            right[j] = Math.max(dp[j], right[j + 1] - 1);
        for (let j = 0; j < n; j++)
            cur[j] = points[r][j] + Math.max(left[j], right[j]);
        dp = cur;
    }
    return dp.reduce((best, value) => Math.max(best, value), dp[0]);
};

from typing import List

class Solution:
    def maxPoints(self, points: List[List[int]]) -> int:
        n = len(points[0])
        dp = points[0][:]
        for r in range(1, len(points)):
            left, right, cur = [0] * n, [0] * n, [0] * n
            left[0] = dp[0]
            for j in range(1, n):
                left[j] = max(dp[j], left[j - 1] - 1)
            right[n - 1] = dp[n - 1]
            for j in range(n - 2, -1, -1):
                right[j] = max(dp[j], right[j + 1] - 1)
            for j in range(n):
                cur[j] = points[r][j] + max(left[j], right[j])
            dp = cur
        return max(dp)
