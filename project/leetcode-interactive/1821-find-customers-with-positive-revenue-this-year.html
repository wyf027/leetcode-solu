寻找今年具有正收入的客户

Find Customers With Positive Revenue this Year

从年度收入记录中找到符合要求的客户。先理解数据，再打开下方的筛选实验与题解。

01 / 任务与数据约定

表 Customers 记录客户在某年的收入。返回 2021 年收入严格大于 0 的客户编号，结果仅含 customer_id，顺序任意。题目中的“今年”固定指 2021，不随电脑日期变化。

字段类型含义
customer_idint客户编号
yearint记录年份
revenueint该年的收入

约束：(customer_id, year) 为联合主键，每位客户每年最多一条记录；收入可为负值或零。公开题面未列出行数与数值范围上限，不额外假设上限。

04 / 独立题解

准备好后展开，阅读推导和可提交 SQL。

核心洞察

联合主键保证“一位客户、一年、一条记录”。因此只需对单行检查两个条件，再选择编号列，无需聚合或去重。

完整过程

  1. 读取 Customers 的一行。
  2. 检查 year 是否等于 2021，其他年份直接排除。
  3. 检查 revenue 是否严格大于 0，零与负数排除。
  4. 两个条件均满足时输出 customer_id。

示例按行处理：2018 年客户 1 排除；2021 年客户 1 保留；2020 年客户 1 排除；2021 年客户 2 因 -50 排除；客户 3 的两条历史记录排除；2021 年客户 4 保留。最终为 {1,4}。SQL 优化器可能重排条件，这个顺序仅用于讲解。

正确性

可靠性：输出行必然同时满足 year = 2021 与 revenue > 0，所以输出客户符合题意。完整性：任意符合题意的客户，其 2021 年记录一定通过两个条件，因而不会遗漏。唯一性：联合主键使同一客户在 2021 年最多出现一次，投影不会产生重复编号。

边界与常见错误

  • 零收入不属于正收入，不能写 revenue >= 0。
  • 没有 2021 年记录的客户不应出现；不能选最大年份代替 2021。
  • 两个条件必须用 AND；OR 会放入往年收入或今年亏损客户。
  • 无需 SUM、GROUP BY 或 DISTINCT；跨年份求和会改变题意。
  • 若扩展数据允许 NULL，SQL 的比较结果可能为 UNKNOWN，WHERE 不保留它；四语言参考按题目整数行约定处理。

复杂度

以全表扫描模型计，n 行需要 O(n) 时间，流式筛选除输出外 O(1) 额外空间，输出 k 个编号需 O(k)。四语言代码保存结果需 O(k) 空间；JavaScript 的 filter 还会保存中间数组。实际数据库耗时受索引、统计信息与执行计划影响。

替代方案

可先在子查询中选出 2021 年，再在外层筛选正收入，结果相同但没有必要增加层级。若业务改成每位客户每年多条流水，则应先限定年份，再按客户分组并 HAVING SUM(revenue) > 0；那是不同的数据约束。

面试追问

① 数据量大怎么办？讨论以 year 开头的索引及覆盖索引的读写取舍，并查看执行计划。② 年份可选怎么办？将 2021 改为绑定参数，不拼接用户字符串。③ 为什么不用 DISTINCT？主键和固定年份共同保证唯一。④ 真正的“本年”怎么办？明确业务时区和日期定义后再绑定业务年份。

MySQL · 官方可提交解法

SELECT customer_id
FROM Customers
WHERE year = 2021 AND revenue > 0;

Java · 本地语义参考（非本题提交语言）

import java.util.*;
public class Main {
    // 每行依次为 customer_id, year, revenue。
    public static List<Integer> findCustomers(int[][] customers) {
        List<Integer> result = new ArrayList<>();
        for (int[] row : customers) {
            if (row[1] == 2021 && row[2] > 0) result.add(row[0]);
        }
        return result;
    }
    public static void main(String[] args) {
        int[][] customers = {{1,2018,50},{1,2021,30},{1,2020,70},
            {2,2021,-50},{3,2018,10},{3,2016,50},{4,2021,20}};
        System.out.println(findCustomers(customers));
    }
}

function findCustomers(customers) {
  return customers
    .filter(row => row[1] === 2021 && row[2] > 0)
    .map(row => row[0]);
}

  [2,2021,-50],[3,2018,10],[3,2016,50],[4,2021,20]];

Python · 本地语义参考（普通 Python，非 Pandas 提交）

def find_customers(customers):
    return [cid for cid, year, revenue in customers
            if year == 2021 and revenue > 0]

if __name__ == "__main__":
    customers = [[1,2018,50],[1,2021,30],[1,2020,70],
                 [2,2021,-50],[3,2018,10],[3,2016,50],[4,2021,20]]
    print(find_customers(customers))

C++ · 本地语义参考（非本题提交语言）

#include <array>
#include <iostream>
#include <vector>
using namespace std;
vector<int> findCustomers(const vector<array<int,3>>& customers) {
    vector<int> result;
    for (const auto& row : customers)
        if (row[1] == 2021 && row[2] > 0) result.push_back(row[0]);
    return result;
}
int main() {
    vector<array<int,3>> customers = {{1,2018,50},{1,2021,30},
        {1,2020,70},{2,2021,-50},{3,2018,10},{3,2016,50},{4,2021,20}};
    for (int id : findCustomers(customers)) cout << id << '\n';
}
