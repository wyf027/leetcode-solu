Stone Game II

Problem

题目描述

一列石子堆、一个会扩张的取石上限，以及两位始终做出最优选择的玩家。

Alice 和 Bob 面前有一列石子堆，第 i 堆含有正整数颗石子 piles[i]。两人轮流取石子，Alice 先手，目标都是让自己最终得到尽可能多的石子。

初始 M = 1。每回合，当前玩家必须从剩余队列的开头连续拿走 X 堆的全部石子，其中 1 ≤ X ≤ 2M；随后更新 M = max(M, X)。

当所有石子堆都被取走时游戏结束。假设双方都采用最优策略，返回 Alice 最多能得到的石子数。

关键规则：只能从当前剩余队列的最前面拿，拿走的是整堆，并且更新后的 M 对下一位玩家同样生效。
函数签名
stoneGameII(piles: integer[]) → integer
回合速记
1在合法范围 [1, 2M] 内选择 X。
2拿走剩余序列最前面的 X 堆。
3令 M = max(M, X)，交换行动方。
约束
  • 1 ≤ piles.length ≤ 100
  • 1 ≤ piles[i] ≤ 10⁴
示例 1完整参数
输入piles = [2,7,9,4,4]
输出10

Alice 先取 1 堆时，可在后续再取得最后两堆，总计 2 + 4 + 4 = 10；若先取 2 堆，Bob 能拿走其余三堆，Alice 只有 9。

示例 2完整参数
输入piles = [1,2,3,4,5,100]
输出104

最优策略会权衡眼前石子与扩大 M 后留给对手的选择空间，Alice 最终最多获得 104。

Dynamic Programming

后缀和 + 记忆化博弈 DP

不要试图猜 Alice 当下拿几堆；直接把“对手也最优”写进状态的定义里。

dp(i, M) = suffix[i] − min(dp(i + X, max(M, X)))，1 ≤ X ≤ min(2M, n − i)

等价实现会直接枚举 X，并最大化 suffix[i] - dp(next)。

核心洞察

定义 dp(i, M) 为：轮到当前玩家行动、剩余石子从下标 i 开始且当前参数为 M 时，当前玩家最多能拿到的石子数。

若当前玩家取 X 堆，剩余总数是 suffix[i]，对手在新状态最多拿 dp(i+X, max(M,X))。这是零和分配，所以当前玩家得到两者之差。

完整过程

  1. 从右向左计算后缀和 suffix。
  2. 从 dp(0, 1) 开始递归。
  3. 若剩余堆数不超过 2M，当前玩家直接拿完。
  4. 否则枚举所有合法 X，取收益最大值。
  5. 缓存每个 (i, M)，避免重复求解。

正确性证明

  1. 基例：当 n-i ≤ 2M，当前玩家可以拿走全部剩余正数石子，收益 suffix[i] 必然最优。
  2. 归纳假设：假设所有剩余堆数更少的状态，dp 都能给出当前玩家的最优收益。
  3. 归纳步骤：在状态 (i,M) 枚举每个合法 X。归纳假设保证新状态中对手会得到其最优值，因此当前玩家恰得 suffix[i]-dp(next)。取所有合法选择中的最大值，就覆盖并选中了当前玩家的最优策略。
  4. 结论：由归纳法，dp(0,1) 正是 Alice 在双方最优时能获得的最大石子数。

边界与复杂度

  • 单堆或两堆时，初始 2M = 2，Alice 直接拿完。
  • 所有石子数为正，因此能拿完时没有保留石子的收益。
  • M 无需超过 n；状态数量为 O(n²)。
时间 O(n³) 空间 O(n²) 递归深度 O(n)

替代方案

自底向上 DP：按 i 从右向左填表，状态与转移不变，可避免递归栈，但填表边界更容易写错。

分差 DP：也可以记录当前玩家相对对手的最大净胜分，最后由总和换算 Alice 收益；本题用“当前玩家最多拿多少”更直接。

贪心不可行：眼下拿最多会扩大 M，可能让对手在下一回合拿走更关键的大堆。

面试追问与常见错误

  • 如何还原双方取法？ 为每个状态额外保存取得最大值时的 X，再沿状态转移回放。
  • 规则改为最多取 kM 堆？ 把枚举上限和直接拿完条件中的 2M 攐为 kM。
  • 错误：把 M 更新成 X，而不是 max(M,X)。
  • 错误：返回“本回合拿到的石子 + 同一玩家的下一状态”；下一状态实际轮到对手。
  • 错误：只用 i 做缓存键；同一位置在不同 M 下合法选择不同。

class Solution {
    private int[] suffix;
    private int[][] memo;
    private int n;

    public int stoneGameII(int[] piles) {
        n = piles.length;
        suffix = new int[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            suffix[i] = suffix[i + 1] + piles[i];
        }

        memo = new int[n][n + 1];
        return dfs(0, 1);
    }

    private int dfs(int i, int m) {
        if (i >= n) {
            return 0;
        }
        if (2 * m >= n - i) {
            return suffix[i];
        }
        if (memo[i][m] != 0) {
            return memo[i][m];
        }

        int best = 0;
        int limit = Math.min(2 * m, n - i);
        for (int x = 1; x <= limit; x++) {
            int opponent = dfs(i + x, Math.max(m, x));
            best = Math.max(best, suffix[i] - opponent);
        }
        memo[i][m] = best;
        return best;
    }
}

/**
 * @param {number[]} piles
 * @return {number}
 */
var stoneGameII = function(piles) {
    const n = piles.length;
    const suffix = new Array(n + 1).fill(0);
    for (let i = n - 1; i >= 0; i--) {
        suffix[i] = suffix[i + 1] + piles[i];
    }

    const memo = Array.from(
        { length: n },
        () => new Array(n + 1).fill(-1)
    );

    const dfs = (i, m) => {
        if (i >= n) return 0;
        if (2 * m >= n - i) return suffix[i];
        if (memo[i][m] !== -1) return memo[i][m];

        let best = 0;
        const limit = Math.min(2 * m, n - i);
        for (let x = 1; x <= limit; x++) {
            const opponent = dfs(i + x, Math.max(m, x));
            best = Math.max(best, suffix[i] - opponent);
        }
        memo[i][m] = best;
        return best;
    };

    return dfs(0, 1);
};

from functools import lru_cache
from typing import List


class Solution:
    def stoneGameII(self, piles: List[int]) -> int:
        n = len(piles)
        suffix = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            suffix[i] = suffix[i + 1] + piles[i]

        @lru_cache(maxsize=None)
        def dfs(i: int, m: int) -> int:
            if i >= n:
                return 0
            if 2 * m >= n - i:
                return suffix[i]

            best = 0
            limit = min(2 * m, n - i)
            for x in range(1, limit + 1):
                opponent = dfs(i + x, max(m, x))
                best = max(best, suffix[i] - opponent)
            return best

        return dfs(0, 1)

class Solution {
private:
    vector<int> suffix;
    vector<vector<int>> memo;
    int n;

    int dfs(int i, int m) {
        if (i >= n) {
            return 0;
        }
        if (2 * m >= n - i) {
            return suffix[i];
        }
        if (memo[i][m] != -1) {
            return memo[i][m];
        }

        int best = 0;
        int limit = min(2 * m, n - i);
        for (int x = 1; x <= limit; ++x) {
            int opponent = dfs(i + x, max(m, x));
            best = max(best, suffix[i] - opponent);
        }
        return memo[i][m] = best;
    }

public:
    int stoneGameII(vector<int>& piles) {
        n = static_cast<int>(piles.size());
        suffix.assign(n + 1, 0);
        for (int i = n - 1; i >= 0; --i) {
            suffix[i] = suffix[i + 1] + piles[i];
        }

        memo.assign(n, vector<int>(n + 1, -1));
        return dfs(0, 1);
    }
};
