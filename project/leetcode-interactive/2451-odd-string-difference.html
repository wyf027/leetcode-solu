2451. 差值数组不同的字符串

Odd String Difference

字母的位置不同，变化的轨迹会一样吗？观察相邻字母之间的距离，找到那个例外。

LeetCode 官方题目 ↗

01 / 题目

给定等长字符串数组 words，每个字符串长度为 n。将小写字母映射为字母表位置（a = 0，b = 1，…，z = 25），对每一对相邻字母计算“后一个减前一个”，得到长度为 n − 1 的差值数组。

difference[i][j] = words[i][j + 1] - words[i][j]
0 ≤ j ≤ n - 2
例如："acb" → [2 - 0, 1 - 2] → [2, -1]

题目保证：恰好一个字符串的差值数组与其余字符串不同。返回这个字符串本身。

参数与返回值

oddString(words: string[]) → string

输入是完整字符串数组；输出是数组中的一个元素。

约束

  • 3 ≤ words.length ≤ 100
  • n == words[i].length
  • 2 ≤ n ≤ 20
  • words[i] 只含小写英文字母。

02 / 官方示例

示例 1

输入：words = ["adc","wzy","abc"]
输出："abc"

adc 与 wzy 的差值数组都是 [3, −1]；abc 的差值数组为 [1, 1]，所以返回 abc。

示例 2

输入：words = ["aaa","bob","ccc","ddd"]
输出："bob"

aaa、ccc、ddd 都对应 [0, 0]，只有 bob 对应 [13, −13]，所以返回 bob。

05 / 独立题解

准备好后，再展开推导与四语言实现。

核心洞察：用前三个字符串确定参照

比较的是相邻字母的变化，而不是字母本身。因为最多只有一个异常，前三个字符串里至少有两个正常。若 words[0] 与 words[1] 的差值相同，或者 words[0] 与 words[2] 的差值相同，则 words[0] 可以作为正常参照；否则 words[0] 必是异常，words[1] 是正常参照。

完整过程

  1. 定义 same(a, b)：逐个位置比较两个字符串的相邻差值，任一位置不同即返回 false。
  2. 通过前三个字符串确定正常参照 base。
  3. 按输入顺序比较每个字符串与 base 的差值。
  4. 找到第一个不相同者，返回该字符串。题目保证恰好存在一个。

示例 1：adc 和 wzy 相同，所以选 adc；adc、wzy 都与参照相同，abc 在第一个差值处就不同，返回 abc。交互为了展示完整形状会画出差值数组；提交代码直接比较字符差，不额外保存数组。

正确性说明

比较可靠：same 检查全部 n − 1 个相邻差，返回 true 当且仅当两个差值数组相等。

参照正常：如果 words[0] 与另外两者中的任意一个相同，这一差值至少出现两次，不能属于唯一异常。若它与两者都不同，则它不能是正常字符串，否则另外两个都会异常，与题意矛盾；此时 words[1] 正常。

返回唯一异常：正常参照与所有正常字符串的差值相等，只与异常字符串不同，顺序扫描一定且只会返回那个异常字符串。

边界与复杂度

  • m = 3 仍有两个正常字符串；n = 2 仅比较一个差值。
  • 差值可以为负数或 0，范围为 [−25, 25]；不要取绝对值。
  • 异常可以在任意位置；重复的正常字符串也合法。
  • 令 m = words.length。最坏时间 O(mn)；直接比较的额外空间 O(1)，不计输入与返回字符串。
  • 四份代码依赖官方保证（等长、小写、至少三个、唯一异常）。结尾空字符串是不可达的兜底，不是合法输入的预期答案。

替代方案

为每个字符串生成差值元组或带分隔符的键，用哈希表统计，返回计数为 1 的键所对应的单词。时间通常 O(mn)，一般空间上界 O(mn)；本题恰好两类差值，只保留每类代表和计数时可降为 O(n)。该方法更适合推广到多种模式统计；当前唯一异常条件允许直接用常量空间参照法。

常见错误

  • 始终把第一个字符串当正常值，忽略它可能就是异常。
  • 用前一个字母减后一个，或只检查第一个相邻差。
  • 判断字母是否相同，或只比较差值总和，丢失逐位置的信息。
  • JavaScript 用 === 比较两个数组，它比较引用而不是内容。
  • 哈希键直接拼接数字不加分隔符，会让 [1, 11] 与 [11, 1] 都变成 "111"。

面试追问

  • 差值相同意味着什么？所有位置的字符编码相差同一个常量，可由相邻差相等逐项推导。
  • 为什么两条数据不够？两者不同时无法确定谁正常；第三条提供多数信息。
  • 如果允许多个异常呢？前三条无法保证参照正常，需要先约定正常模式的判定标准，再考虑计数或多数投票。
  • 能流式处理吗？先缓存前三个字符串确定参照，再逐条比较；无需保存后续全部输入。

完整提交代码

四种官方支持语言，使用同一参照比较算法。代码尚未运行或编译。

Java

class Solution {
    private boolean same(String a, String b) {
        for (int j = 1; j < a.length(); j++) {
            if (a.charAt(j) - a.charAt(j - 1)
                    != b.charAt(j) - b.charAt(j - 1)) {
                return false;
            }
        }
        return true;
    }

    public String oddString(String[] words) {
        String base = same(words[0], words[1])
                || same(words[0], words[2]) ? words[0] : words[1];
        for (String word : words) {
            if (!same(word, base)) return word;
        }
        return "";
    }
}

from typing import List

class Solution:
    def oddString(self, words: List[str]) -> str:
        def same(a: str, b: str) -> bool:
            for j in range(1, len(a)):
                if (ord(a[j]) - ord(a[j - 1])
                        != ord(b[j]) - ord(b[j - 1])):
                    return False
            return True

        base = (words[0] if same(words[0], words[1])
                or same(words[0], words[2]) else words[1])
        for word in words:
            if not same(word, base):
                return word
        return ""

#include <string>
#include <vector>

class Solution {
    bool same(const string& a, const string& b) {
        for (int j = 1; j < static_cast<int>(a.size()); ++j) {
            if (a[j] - a[j - 1] != b[j] - b[j - 1]) {
                return false;
            }
        }
        return true;
    }
public:
    string oddString(vector<string>& words) {
        const string& base = same(words[0], words[1])
            || same(words[0], words[2]) ? words[0] : words[1];
        for (const string& word : words) {
            if (!same(word, base)) return word;
        }
        return "";
    }
};
