重排数字的最小值

Smallest Value of the Rearranged Number

同一组数字，不同的排列。保留符号，寻找数轴上最靠左的合法结果。

01 / 题目

给定整数 num，重新排列它的全部十进制数字，每个数字的出现次数保持不变，正负号保持不变。结果不能有前导零；数值 0 本身合法。返回满足这些条件的最小整数。

参数：num，整数；返回：整数。约束：−1015 ≤ num ≤ 1015。

官方示例 1

输入：num = 310
输出：103

013 和 031 有前导零，不能选；其余排列中 103 最小。

官方示例 2

输入：num = -7605
输出：-7650

符号保持为负；合法排列中 −7650 的数值最小。

04 / 独立题解

思考之后，再展开推导与四语言实现。

核心洞察：符号决定排列方向

正数要让绝对值尽量小，负数要让绝对值尽量大。同位数且无前导零的非负整数，其大小由第一个不同的数位决定：越靠左的数位优先级越高。

完整过程

  1. num = 0 时直接返回 0。
  2. 记录符号，把绝对值拆成字符数组并升序排序。
  3. 正数：若开头是 0，找到第一个非零数字，与首位交换。此时首位是最小非零数字，后缀仍为升序。
  4. 负数：反转升序数组，得到降序数字，使绝对值最大。
  5. 拼接并转换为整数，恢复符号。

例如 310 → [0,1,3] → [1,0,3] → 103；−7605 → [0,5,6,7] → [7,6,5,0] → −7650。装配台采用等价的逐位选择展示：从剩余数字中取当前最优的合法数字。

正确性：第一个不同的位置

对正数，任何合法答案的首位都非零。若首位不是最小非零数字，把更小的非零数字换到首位会严格减小结果，所以最优首位必然是最小非零数字。固定首位后，若后缀存在前大后小的逆序，将它们交换会减小结果；因此升序后缀最优。升序数组中首个非零数字前面全是零，将它与首位交换，正好得到该结构。

对负数，−a 随 a 的增大而减小。若绝对值的数位存在前小后大的位置，交换后绝对值变大、负数变小，因此降序排列最优。非零数至少含一个非零数字，降序不会产生前导零。算法只排序和交换，保持数字出现次数及原符号；结合零的单独处理，覆盖全部输入。

边界与整数范围

  • 0 必须提前处理，避免寻找不存在的非零数位；一位数和重复数字自然成立。
  • 正数允许内部零，但不能删除零。负数的零排到最后。
  • 设数位数为 d，本题 d ≤ 16；16 位输入只可能是 ±10¹⁵，其他输入至多 15 位。重排结果均处于 JavaScript 安全整数范围内。
  • Java 用 long，C++ 用 long long，不能使用 32 位 int 存储结果。Python 整数无该溢出问题。

复杂度

排序需要 O(d log d) 时间，扫描和拼接需要 O(d) 时间。整体 O(d log d) 时间、O(d) 额外空间（数位数组与结果字符串）。

替代方案

统计 0～9 的频次：正数先取最小非零数字，再从 0 到 9 输出剩余数字；负数从 9 到 0 输出。时间 O(d + 10)，计数表 O(1) 空间；若构造字符串，输出缓冲仍占 O(d)。本题数位很少，排序实现更直接。枚举排列可作小规模思路参考，但时间可达 O(d! · d)，不适合作为主解。

常见错误

  • 把负数也升序排列：这会让负数更接近零，而非最小。
  • 正数排序后直接转整数：前导零被丢弃，数字使用次数不再符合题意。
  • 把所有零移到末尾：例如 310 会得到 130，大于 103。
  • 把负号一起排序，或用 32 位类型接收结果。

面试追问

  • 如何避免排序？用固定大小的计数表逐位取数。
  • 若要求最大值？正数降序；负数让绝对值最小并处理前导零。
  • 输入超出安全整数范围怎么办？接收字符串并返回字符串，或使用 BigInt；不要先转 Number。
  • 为什么交换首个非零字符后，后缀仍有序？其前面全是零，被换回的零填补了这些零与其余非零字符之间的位置。

Java

import java.util.Arrays;

class Solution {
    public long smallestNumber(long num) {
        if (num == 0) return 0;
        char[] digits = Long.toString(Math.abs(num)).toCharArray();
        Arrays.sort(digits);
        if (num < 0) {
            for (int l = 0, r = digits.length - 1; l < r; l++, r--) {
                char t = digits[l];
                digits[l] = digits[r];
                digits[r] = t;
            }
        } else {
            int i = 0;
            while (digits[i] == '0') i++;
            char t = digits[0];
            digits[0] = digits[i];
            digits[i] = t;
        }
        long value = Long.parseLong(new String(digits));
        return num < 0 ? -value : value;
    }
}

JavaScript

/**
 * @param {number} num
 * @return {number}
 */
var smallestNumber = function(num) {
    if (num === 0) return 0;
    const digits = String(Math.abs(num)).split('').sort();
    if (num < 0) {
        digits.reverse();
    } else {
        const i = digits.findIndex(digit => digit !== '0');
        [digits[0], digits[i]] = [digits[i], digits[0]];
    }
    const value = Number(digits.join(''));
    return num < 0 ? -value : value;
};

class Solution:
    def smallestNumber(self, num: int) -> int:
        if num == 0:
            return 0
        digits = sorted(str(abs(num)))
        if num < 0:
            digits.reverse()
        else:
            i = 0
            while digits[i] == '0':
                i += 1
            digits[0], digits[i] = digits[i], digits[0]
        value = int(''.join(digits))
        return -value if num < 0 else value

C++

#include <algorithm>
#include <string>
using namespace std;

class Solution {
public:
    long long smallestNumber(long long num) {
        if (num == 0) return 0;
        string digits = to_string(num < 0 ? -num : num);
        sort(digits.begin(), digits.end());
        if (num < 0) {
            reverse(digits.begin(), digits.end());
        } else {
            size_t i = digits.find_first_not_of('0');
            swap(digits[0], digits[i]);
        }
        long long value = stoll(digits);
        return num < 0 ? -value : value;
    }
};
