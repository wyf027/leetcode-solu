大的国家 Big Countries

从 World 表中筛出满足任一“大国”门槛的记录，只返回国家名称、人口与面积。 先观察筛选过程；完整解法在页面底部，默认收起。

Problem

题意与条件

任一条件成立

World 的每一行描述一个国家的名称、所属大洲、面积、人口和 GDP。 当一个国家的面积至少为 300 万平方公里，或者人口至少为 2500 万时，它就是“大国”。 请找出所有大国的 name、population 和 area，结果可按任意顺序返回。

面积门槛（含等号） area ≥ 3,000,000 平方公里
人口门槛（含等号） population ≥ 25,000,000 人

OR两项中只要有一项成立，就保留该行。

约束与输出契约

  • name 是主键，因此每个国家名称唯一。
  • 每行都给出国家名称、洲、面积、人口和 GDP；字段类型分别见上方表结构。
  • 阈值比较为“至少”，所以恰好等于 3,000,000 或 25,000,000 的记录也要保留。
  • 输出列必须为 name、population、area，返回顺序不限。
  • 官方题面未额外给出行数或数值范围约束。

Solution

题解：一条布尔条件完成筛选

核心洞察： 每一行都可以独立判定。面积条件与人口条件是“或”关系，因此把两次含等号的比较用 OR 连接，再投影出题目要求的三列即可。

完整过程

  1. 从 World 读取记录。
  2. 对每行检查 area >= 3000000。
  3. 再检查 population >= 25000000。
  4. 两项至少一项为真时保留该行。
  5. 仅输出 name、population、area。

正确性说明

对任意国家行 r：若算法输出 r，筛选条件必有一个分支为真， 所以它满足至少一个“大国”标准。反之，若 r 是大国，它必满足面积或人口门槛， 对应筛选表达式为真，因此不会遗漏。故输出集合恰好是所有大国。

边界情况

  • 恰好等于任一阈值：必须保留。
  • 两项都满足：仍只返回一次。
  • 两项都不满足：排除。
  • 空表或没有大国：返回空结果集。
  • 无需排序；不要建立不必要的顺序依赖。

复杂度

时间O(n)无适用索引时扫描 n 行
额外空间O(1)不计数据库输出结果

本地语义参考 · 非本题 LeetCode 提交语言
import java.util.ArrayList;
import java.util.List;

public class BigCountries {
    public static final class Country {
        public final String name;
        public final String continent;
        public final int area;
        public final int population;
        public final long gdp;

        public Country(String name, String continent, int area,
                       int population, long gdp) {
            this.name = name;
            this.continent = continent;
            this.area = area;
            this.population = population;
            this.gdp = gdp;
        }
    }

    public static final class Result {
        public final String name;
        public final int population;
        public final int area;

        public Result(String name, int population, int area) {
            this.name = name;
            this.population = population;
            this.area = area;
        }
    }

    public static List<Result> bigCountries(List<Country> world) {
        List<Result> answer = new ArrayList<>();
        for (Country country : world) {
            if (country.area >= 3_000_000
                    || country.population >= 25_000_000) {
                answer.add(new Result(
                    country.name, country.population, country.area
                ));
            }
        }
        return answer;
    }
}
本地语义参考 · 非本题 LeetCode 提交语言
/**
 * @param {Array<{
 *   name: string,
 *   continent: string,
 *   area: number,
 *   population: number,
 *   gdp: number
 * }>} world
 * @returns {Array<{name: string, population: number, area: number}>}
 */
function bigCountries(world) {
  return world
    .filter(
      (country) =>
        country.area >= 3_000_000 ||
        country.population >= 25_000_000,
    )
    .map(({ name, population, area }) => ({
      name,
      population,
      area,
    }));
}

from dataclasses import dataclass
from typing import Iterable, List


@dataclass(frozen=True)
class Country:
    name: str
    continent: str
    area: int
    population: int
    gdp: int


@dataclass(frozen=True)
class Result:
    name: str
    population: int
    area: int


def big_countries(world: Iterable[Country]) -> List[Result]:
    return [
        Result(country.name, country.population, country.area)
        for country in world
        if country.area >= 3_000_000
        or country.population >= 25_000_000
    ]

替代方案

可以把面积条件和人口条件分别查询后用 UNION 合并；它会去重，能避免同一国家满足两项时重复。 但单个 WHERE ... OR ... 更短、更直观，也不需要额外集合合并。

常见错误

  • 误用 AND，只保留同时满足两项的国家。
  • 使用 > 而非 >=，漏掉恰好在阈值上的行。
  • 返回全部五列，而不是指定的三列。
  • 用 UNION ALL 合并两次查询，导致重复。

面试追问

  • 为什么不需要 DISTINCT？每个输入行只判断并输出一次，且 name 是主键。
  • 如何稳定输出顺序？按业务需要添加 ORDER BY。
  • 大表如何优化？考虑面积、人口索引，并通过执行计划判断 OR 的索引利用情况。
  • 阈值可配置时怎么办？使用参数或配置表，不要在多处硬编码。

结果投影为何重要

筛选决定“保留哪些行”，投影决定“返回哪些列”。虽然输入还包含 continent 与 gdp，最终结果只应带回题目指定的三列。
