3900. 一次交换后的最长平衡子串

把 '1' 记作 +1、'0' 记作 −1。一次跨边界交换只会把选中子串的差值改变 ±2，因此只需追踪差值 0、2、−2 的最长候选。

题意

给定只含 '0'、'1' 的字符串 s。最多交换任意两个位置的字符一次，再选择一个 0 与 1 数量相等的连续子串，返回可得到的最大长度。

示例：s = "100001"，可交换一次后取得长度 4；s = "111" 时答案为 0。

为什么只看 0、±2？

差为 0
区间自身已平衡，不需要交换。
差为 2
区间多一个 1 对；若区间外有 0，交换后差减 2。
差为 −2
区间多一个 0 对；若区间外有 1，交换后差加 2。

绝对差大于 2 时，一次交换不可能补齐。

复杂度

时间：O(n)

空间：O(n)

对每个前缀差保留最早、必要时次早的位置；越早起点通常代表越长区间。

题解：前缀和 + 前缀位置表

令 pre 为前缀中 1 的个数减 0 的个数。末尾在 i 的候选子串可以由相同 pre（无需交换）、pre − 2（子串差为 +2）、pre + 2（子串差为 −2）三类起点给出。对于 ±2 的候选，还要确认区间外有可换入的反向字符；最早位置不够时再考察第二早位置。

边界与替代方案

全相同字符串没有可修复的 ±2 区间，空子串使答案可以为 0。暴力枚举交换与子串是 O(n³)，不适合 n = 10⁵。

面试追问与常见错误

追问：若允许 k 次交换，哪些差值可修复？常见错误：只检查区间差为 ±2，却忘记交换必须从区间外取到反向字符；或仅保留一个起点，在它占满全部反向字符时漏掉次早起点。
