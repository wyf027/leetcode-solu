确定两个字符串
是否接近

两个字符串看起来不同，却可能拥有相同的“可变形能力”。先理解两种操作，再进入下方实验室观察变化；核心判定暂时留在折叠题解中。

阅读题目 打开交互实验室

官方函数：closeStrings(word1, word2) → boolean

01

题目说明

可以在任意一个字符串上不限次数地执行两种操作。

如果能够通过以下操作把一个字符串变成另一个字符串，就称这两个字符串是接近的：

  1. 交换位置：交换任意两个已有字符的位置。例如 abcde → aecdb。
  2. 交换字符身份：选取两种在字符串中已经存在的字符，把第一种的所有出现位置改成第二种，同时把第二种的所有出现位置改成第一种。例如 aacabb → bbcbaa。
给定字符串 word1 和 word2，若两者接近则返回 true，否则返回 false。

官方示例

示例 1true
输入：word1 = "abc",
      word2 = "bca"
输出：true
解释：通过交换字符位置，
可以把 "abc" 排列为 "bca"。
示例 2false
输入：word1 = "a",
      word2 = "aa"
输出：false
解释：无论执行多少次操作，
字符串长度都不会改变。
示例 3true
输入：word1 = "cabbba",
      word2 = "abbccc"
输出：true
解释：可结合位置交换与
字符身份交换完成转换。

约束

  • 1 <= word1.length, word2.length <= 105
  • word1 和 word2 只包含小写英文字母。

题解：比较不变量

操作能改变排列和字符标签，却无法改变两类关键信息。

核心洞察

不变量 A：出现过的字符集合 操作 1 不改变字符；操作 2 只能交换两种已经存在的字符，因此不能凭空增加或删除某个字符种类。
不变量 B：频次数值的多重集合 操作 2 会把两个字符的“名字”对调，也就是交换它们的频次归属；频次数值本身没有变化。

充要条件：两个字符串长度相同、出现字符集合相同，并且所有非零字符频次排序后相同。事实上后两个条件已隐含总长度相同，但先检查长度可快速失败。

完整过程

  1. 快速检查长度。不同则任何操作都无法互相转换，直接返回 false。
  2. 统计 26 个字母。分别得到 freq1 和 freq2。
  3. 比较字符集合。对每个字母检查 freq1[i] > 0 与 freq2[i] > 0 是否一致。
  4. 比较频率指纹。将两个长度为 26 的频次数组排序，并逐项比较。
  5. 全部一致则返回 true。这些条件既必要又足以构造出转换。

正确性证明

必要性

操作 1 只改变位置，不改变字符种类或频次。操作 2 只在两种已有字符之间交换身份，因此出现字符集合不变，两个频次数值只是交换归属，所以频次多重集合也不变。若字符串可互相转换，两项不变量必然相同。

充分性

若出现字符集合相同且频次多重集合相同，就能通过若干次操作 2，把 word1 中每个字符的频次归属重新排列为 word2 对应字符的频次。此时两边每个字符的计数完全相同，再通过操作 1 任意重排字符位置，即可得到 word2。因此条件充分。

结论

算法返回 true 当且仅当两个字符串接近，因此算法正确。

边界情况

  • 长度不同：立即为 false。
  • 单字符：只有字符相同才接近。
  • 字符集合不同：如 "aabb" 与 "ccdd"，频率虽相同仍不可转换。
  • 全为同一字符：另一字符串必须是同一字符且长度相同。
  • 最大长度 10^5：一次线性扫描足够。

复杂度

时间：O(n + m + 26 log 26)，固定字母表下可视为 O(n + m)。

空间：O(26)，固定字母表下为 O(1)。

替代方案

哈希表通用字符集：若字符不限于 26 个小写字母，可用两个 Map/Counter 统计。先比较键集合，再排序值列表。复杂度为 O(n + m + k log k)，其中 k 是不同字符数。

频次的频次：本题字母表固定，也可再统计“出现次数 x 有多少个字符”，从而避免排序。实现更绕，在 26 个槽位上几乎没有实际收益。

四语言完整代码

import java.util.Arrays;

class Solution {
    public boolean closeStrings(String word1, String word2) {
        if (word1.length() != word2.length()) {
            return false;
        }

        int[] freq1 = new int[26];
        int[] freq2 = new int[26];
        for (int i = 0; i < word1.length(); i++) {
            freq1[word1.charAt(i) - 'a']++;
            freq2[word2.charAt(i) - 'a']++;
        }

        for (int i = 0; i < 26; i++) {
            if ((freq1[i] == 0) != (freq2[i] == 0)) {
                return false;
            }
        }

        Arrays.sort(freq1);
        Arrays.sort(freq2);
        return Arrays.equals(freq1, freq2);
    }
}
/**
 * @param {string} word1
 * @param {string} word2

var closeStrings = function(word1, word2) {
    if (word1.length !== word2.length) {
        return false;
    }

    const freq1 = Array(26).fill(0);
    const freq2 = Array(26).fill(0);

    for (let i = 0; i < word1.length; i++) {
        freq1[word1.charCodeAt(i) - 97]++;
        freq2[word2.charCodeAt(i) - 97]++;
    }

    for (let i = 0; i < 26; i++) {
        if ((freq1[i] === 0) !== (freq2[i] === 0)) {
            return false;
        }
    }

    freq1.sort((a, b) => a - b);
    freq2.sort((a, b) => a - b);
    return freq1.every((count, i) => count === freq2[i]);
};
class Solution:
    def closeStrings(self, word1: str, word2: str) -> bool:
        if len(word1) != len(word2):
            return False

        freq1 = [0] * 26
        freq2 = [0] * 26
        for char in word1:
            freq1[ord(char) - ord("a")] += 1
        for char in word2:
            freq2[ord(char) - ord("a")] += 1

        for i in range(26):
            if (freq1[i] == 0) != (freq2[i] == 0):
                return False

        return sorted(freq1) == sorted(freq2)
class Solution {
public:
    bool closeStrings(string word1, string word2) {
        if (word1.size() != word2.size()) {
            return false;
        }

        vector<int> freq1(26, 0);
        vector<int> freq2(26, 0);
        for (char c : word1) {
            ++freq1[c - 'a'];
        }
        for (char c : word2) {
            ++freq2[c - 'a'];
        }

        for (int i = 0; i < 26; ++i) {
            if ((freq1[i] == 0) != (freq2[i] == 0)) {
                return false;
            }
        }

        sort(freq1.begin(), freq1.end());
        sort(freq2.begin(), freq2.end());
        return freq1 == freq2;
    }
};

面试追问

  • 为什么只比较频次排序还不够？请给反例。
  • 如果输入是 Unicode，数组方案如何调整？
  • 能否不排序？如何统计“频次的频次”？
  • 如何从充分性条件构造具体操作序列？

常见错误

  • 只比较字符集合，遗漏频次分布。
  • 只比较排序后的频次，遗漏字符集合。
  • 误以为操作 2 可以引入原本不存在的字符。
  • JavaScript 默认按字典序排序数字，忘记传 (a, b) => a - b。
