减小和重新排列数组后的
最大元素

Maximum Element After Decreasing and Rearranging

从 1 出发，每一步最多相差 1。你能让这条数字路径到达多高？

官方题目 ↗

01 / 题目与规则

给定正整数数组 arr，可以任意次执行两种操作：把某个元素减小为更小的正整数，或将所有元素任意重排；也可以不操作。

最终数组必须以 1 开头，并且对所有 1 ≤ i < arr.length，满足 |arr[i] − arr[i − 1]| ≤ 1。返回所有合法操作结果中，可能出现的最大元素值（返回整数，不是数组）。

约束
1 ≤ arr.length ≤ 10⁵
1 ≤ arr[i] ≤ 10⁹

允许保留重复值，允许相邻下降；不能增大元素，不能删除元素。

02 / 官方示例

示例 1

输入：arr = [2,2,1,2,1]
输出：2

一种合法结果为 [1,2,2,2,1]，其中最大元素是 2。

示例 2

输入：arr = [100,1,1000]
输出：3

重排为 [1,100,1000]，再将 100 减为 2、1000 减为 3，得到 [1,2,3]。

示例 3

输入：arr = [1,2,3,4,5]
输出：5

原数组已经满足条件，最大元素为 5。

03 / 思考入口

很大的数字一定有用吗？当数组只有三个位置时，即使出现 1000，从 1 出发又能走多远？先独立思考，再打开下方的推演和题解。

04 / 题解 · 搭建最高阶梯

核心洞察：将输入从小到大排序后，每个数都是当前位置的“材料上限”。已建到高度 h 时，下一个位置最多达到 h + 1，也不能超过材料原值 x。因此取 h = min(x, h + 1)。

阶梯工作台

灰色为未处理材料，绿色为已确定高度，橙框标记本步。柱高表示阶梯高度；未处理原值按 n + 1 截顶显示，数值标签保留原值。

每项为 1 到 10⁹ 的整数。编辑后点击“载入数组”。算法代码支持完整题目规模。

完整过程

  1. 将 arr 按数值升序排列。
  2. 设置虚拟前置高度 h = 0，让第一个正整数自动变为 1。
  3. 逐个读取 x，更新 h = min(x, h + 1)，相当于将当前元素保留或减到这个高度。
  4. 最终构造非递减数组，因此最后的 h 就是最大元素，返回它。

例如 [100,1,1000] 排序后为 [1,100,1000]，高度依次变为 1 → 2 → 3。对于 [1,1,2,2,2]，高度则是 1 → 1 → 2 → 2 → 2：重复材料不一定能向上搭一层。

为什么正确？

先证明只看有序结果足够。任何合法结果以 1 开头，邻接差至多 1，因此从 1 走到最大值 M 的途中，整数 1 到 M 都必然出现。把该结果排序，仍以 1 开头且相邻差至多 1，最大值也不变。

设排序后的原数组是 a，排序后的任意可行结果是 b。必有 b[i] ≤ a[i]：若某个位置反而更大，则 b 的后缀有至少 n − i 个值大于 a[i]，但原数组最多只有 n − i − 1 个这样的材料，减小操作不能补足它们。

再证明贪心逐项最优。构造 g[0] = 1，之后 g[i] = min(a[i], g[i−1] + 1)。因为 a 非递减且 g[i−1] ≤ a[i−1] ≤ a[i]，所以 g 非递减且相邻最多增加 1，并且不增大材料，故可行。对任何可行有序 b，基例 b[0] = g[0] = 1；若 b[i−1] ≤ g[i−1]，则 b[i] ≤ min(a[i], b[i−1]+1) ≤ g[i]。归纳可得所有位置均不超过贪心，尤其最大值不超过最后一项。贪心因此最优。

边界与复杂度

  • 长度为 1：无论原值多大，答案只能是 1。
  • 全是 1：答案为 1；全是大数：可以构造 1 到 n，答案为 n。
  • 缺少原始值 1 不影响可行性，任何正整数都能减为 1。
  • 排序耗时 O(n log n)，扫描 O(n)。扫描额外空间 O(1)，排序空间取决于语言实现：C++ 通常 O(log n) 栈，Java 的原始数组排序依实现，Python 最坏 O(n)，JavaScript 依引擎，常见为 O(n)。代码会原地排序输入。

替代方案：计数桶

答案最多 n，因此把材料值截为 min(x,n)，统计到 n 个桶中。按值 v = 1…n 遍历，整桶更新 h = min(v, h + count[v])，等价于逐个处理该值。时间 O(n)、额外空间 O(n)；适合需要线性时间时。不能直接开到 10⁹ 个桶。

常见错误

  • JavaScript 使用默认 sort() 会按字符串排序，必须提供数值比较器。
  • 不排序直接扫描，可能先消耗大材料，导致结果偏小。
  • 只返回 min(n, max(arr)) 会忽视小元素重复，例如 [1,1,1,100] 的答案为 2。
  • 强制每步加 1 等于非法增大材料；相邻差可以为 0。

面试追问

如何返回构造数组？每步将计算出的 h 写回当前槽位。如何保留输入？排序前复制，额外需要 O(n) 空间。能否不排序？使用截断计数桶。为什么答案不超过 n？第一个位置为 1，每走一个位置最多增加 1。

Java

import java.util.Arrays;

class Solution {
    public int maximumElementAfterDecrementingAndRearranging(int[] arr) {
        Arrays.sort(arr);
        int height = 0;
        for (int x : arr) {
            height = Math.min(x, height + 1);
        }
        return height;
    }
}

JavaScript

/**

var maximumElementAfterDecrementingAndRearranging = function(arr) {
    arr.sort((a, b) => a - b);
    let height = 0;
    for (const x of arr) {
        height = Math.min(x, height + 1);
    }
    return height;
};
