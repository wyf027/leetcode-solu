LeetCode 895 · Design

最大频率栈

像栈一样压入元素；弹出时，先选当前出现次数最多的值。如果并列，则选择其中最近一次被压入、也就是最靠近栈顶的值。

HARD栈哈希表有序集合非付费题

题目

实现 FreqStack：

  • FreqStack() 创建空频率栈。
  • void push(int val) 将 val 压入。
  • int pop() 删除并返回出现频率最高的元素；频率相同则返回最接近栈顶者。

官方示例（完整参数形式）

输入：
["FreqStack","push","push","push","push","push","push","pop","pop","pop","pop"]
[[],[5],[7],[5],[7],[4],[5],[],[],[],[]]

输出：
[null,null,null,null,null,null,null,5,7,5,4]

依次压入 5、7、5、7、4、5；四次弹出分别得到 5、7、5、4。

约束

  • 0 ≤ val ≤ 10⁹
  • push 与 pop 的调用总数最多为 2 × 10⁴
  • 调用 pop 前保证栈非空

频率楼层演示

先观察每次操作如何改变“频率楼层”。题解仍锁在页面底部。

准备开始：空栈

当前频次

每个楼层保存“达到该频率时”的入栈顺序；最高非空楼层的末尾就是下一次弹出目标。

先形成直觉，再查看完整题解

核心洞察：频率也可以成为“栈层”

维护 freq[value] 表示当前频率，维护 group[f] 表示所有“压入后频率恰好变为 f”的值，且它本身是栈；再用 maxFreq 记录当前最高频率。

完整过程

  1. push(val)：把频率加一，将值压入对应的新频率楼层，并更新最高频率。
  2. pop()：从最高频率楼层末尾弹出。这个末尾值既有最高频率，又是这些候选者中最近压入的。
  3. 降低该值频率；若最高楼层空了，就把 maxFreq 减一。

正确性

不变式一：每个值每次达到频率 f 时，都会按时间顺序进入 group[f]。因此该组栈顶是所有当前最高频候选中最近达到该频率、也即最近入栈的元素。

不变式二：maxFreq 始终指向非空的最高楼层。push 只可能把最高频率增加 1；pop 后若该层为空，最高频率恰好下降 1。故 pop 总能返回题目规定的元素。

边界与复杂度

  • 重复压入同一个值：它会出现在多个楼层，恰好记录频率成长历史。
  • 并列频率：由楼层内部的 LIFO 自动解决，无需时间戳。
  • 空间复杂度 O(n)；每次 push / pop 时间复杂度均为 O(1)。

替代方案

可用“频率 + 时间戳”的最大堆，每次操作为 O(log n)，概念直接但更慢且存储重复记录。平衡树也可实现相同排序。分组栈利用频率每次只变化 1 的特性，将操作降到 O(1)。

面试追问

  • 若要支持删除指定值，如何维护各频率层中的位置？
  • 若并列时返回最早压入者，组内结构应如何替换？
  • 为何最高频率在一次 pop 后最多下降 1？

常见错误

  • 只维护频率，遗漏并列时的最近性。
  • pop 后忘记降低值的频率或清理空的最高层。
  • 误以为必须从旧频率层删除该值；历史层记录将在未来频率下降时继续发挥作用。

四语言完整实现

class FreqStack {
    private final Map<Integer, Integer> freq = new HashMap<>();
    private final Map<Integer, Deque<Integer>> group = new HashMap<>();
    private int maxFreq = 0;

    public FreqStack() {}

    public void push(int val) {
        int f = freq.getOrDefault(val, 0) + 1;
        freq.put(val, f);
        maxFreq = Math.max(maxFreq, f);
        group.computeIfAbsent(f, k -> new ArrayDeque<>()).push(val);
    }

    public int pop() {
        int val = group.get(maxFreq).pop();
        freq.put(val, freq.get(val) - 1);
        if (group.get(maxFreq).isEmpty()) maxFreq--;
        return val;
    }
}
var FreqStack = function() {
  this.freq = new Map();
  this.group = new Map();
  this.maxFreq = 0;
};

FreqStack.prototype.push = function(val) {
  const f = (this.freq.get(val) || 0) + 1;
  this.freq.set(val, f);
  this.maxFreq = Math.max(this.maxFreq, f);
  if (!this.group.has(f)) this.group.set(f, []);
  this.group.get(f).push(val);
};

FreqStack.prototype.pop = function() {
  const stack = this.group.get(this.maxFreq);
  const val = stack.pop();
  this.freq.set(val, this.freq.get(val) - 1);
  if (stack.length === 0) this.maxFreq--;
  return val;
};
from collections import defaultdict

class FreqStack:
    def __init__(self):
        self.freq = defaultdict(int)
        self.group = defaultdict(list)
        self.max_freq = 0

    def push(self, val: int) -> None:
        self.freq[val] += 1
        f = self.freq[val]
        self.max_freq = max(self.max_freq, f)
        self.group[f].append(val)

    def pop(self) -> int:
        val = self.group[self.max_freq].pop()
        self.freq[val] -= 1
        if not self.group[self.max_freq]:
            self.max_freq -= 1
        return val
class FreqStack {
    unordered_map<int, int> freq;
    unordered_map<int, vector<int>> group;
    int maxFreq = 0;
public:
    FreqStack() = default;

    void push(int val) {
        int f = ++freq[val];
        maxFreq = max(maxFreq, f);
        group[f].push_back(val);
    }

    int pop() {
        auto &stack = group[maxFreq];
        int val = stack.back();
        stack.pop_back();
        --freq[val];
        if (stack.empty()) --maxFreq;
        return val;
    }
};
