半径为 k 的子数组平均值

K Radius Subarray Averages

以每个位置为中心，观察左右各 k 个邻居。哪些位置能形成完整区间？

01 / 理解任务

题意

给定下标从 0 开始的整数数组 nums 与整数 k，返回同样长度的数组 avgs。对于每个中心 i，取闭区间 [i-k, i+k] 内所有元素，求平均值并舍弃小数部分；只要左侧或右侧不足 k 个元素，就令 avgs[i] = -1。

整数除法向零截断，例如 (2 + 3 + 1 + 5) / 4 = 2.75，结果为 2。本题元素非负，因此也等价于向下取整。

参数与返回值

getAverages(nums, k) → 整数数组
nums：整数数组；k：非负整数半径。
返回值长度必须为 n。

官方约束

  • n == nums.length
  • 1 ≤ n ≤ 10⁵
  • 0 ≤ nums[i], k ≤ 10⁵

03 / 题解

固定长度滑动窗口

半径是 k，窗口长度就是 w = 2k + 1。相邻两个完整窗口重叠 w−1 个元素，只需减去离开的最左元素，加上新进入的最右元素，就能维护窗口和。

核心洞察：右端点为 r 的完整窗口对应中心 r-k，答案应写入这个中心，而不是 r。

窗口传送带

每一步移动到下一个完整窗口。绿色是窗口，粗边框标记中心；橙色虚线表示离开，蓝色表示进入。下排显示逐步写入的答案。

元素为 0–100000 的整数；k 为 0–100000 的整数。30 项限制仅用于演示，提交代码支持官方完整范围。

完整过程

  1. 创建长度 n 的答案数组，初始全部为 −1，设窗口长度 w = 2k + 1。
  2. 若 w > n，没有完整窗口，直接返回答案。
  3. 计算第一个窗口 nums[0..w−1] 的和 S，将 S / w 的整数部分写入 avgs[k]。
  4. 令右端点 r 从 w 移动到 n−1：更新 S = S − nums[r−w] + nums[r]，将整数平均值写入 avgs[r−k]。
  5. 返回答案。前后各 k 个位置从未被写入，保持 −1。

示例 1：第一窗 S=37，写 avgs[3]=5；右移时减 7 加 2，S=32，写 avgs[4]=4；再减 4 加 6，S=34，写 avgs[5]=4。

正确性

不变式：每次写入前，S 恰好等于当前长度为 w 的窗口内所有元素之和。

初始直接累加第一个窗口，因此成立。右移一步恰好移除旧窗口最左项、加入新窗口最右项，其余项不变，因此不变式保持。窗口 [r−w+1,r] 的中心是 r−k，所以写入值正是题目定义的平均值。

中心从 k 到 n−k−1 全部且仅被访问一次；其他中心不能构成完整窗口，保持 −1。若 w>n，所有中心均无效，提前返回亦正确。

边界与复杂度

  • k=0：窗口长度为 1，答案逐项等于原数组。
  • w=n：只有中心 k 有有效平均值。
  • w>n：全部返回 −1，不尝试读首窗。
  • 窗口和最多约 10¹⁰，Java 用 long，C++ 用 long long；JavaScript Number 的安全整数范围足够，Python 整数可自动扩展。
  • 时间 O(n)：初始化答案和遍历窗口均为线性。
  • 辅助空间 O(1)，不计 O(n) 的输出数组。演示为支持回退保存状态，与提交代码的空间用量不同。

Java

import java.util.Arrays;

class Solution {
    public int[] getAverages(int[] nums, int k) {
        int n = nums.length, w = 2 * k + 1;
        int[] ans = new int[n];
        Arrays.fill(ans, -1);
        if (w > n) return ans;
        long sum = 0;
        for (int i = 0; i < w; i++) sum += nums[i];
        ans[k] = (int) (sum / w);
        for (int r = w; r < n; r++) {
            sum -= nums[r - w];
            sum += nums[r];
            ans[r - k] = (int) (sum / w);
        }
        return ans;
    }
}

替代方案

前缀和：构造 P[0]=0、P[t+1]=P[t]+nums[t]，合法中心 i 的区间和为 P[i+k+1]−P[i−k]。时间 O(n)、额外空间 O(n)，适合还需要回答其他区间查询的情形。

逐窗重算：每个合法中心遍历 2k+1 项。时间 O(n+(n−2k)(2k+1))（存在合法中心时），通常记作 O(n(k+1))，最坏 O(n²)，辅助空间 O(1)。可用于手工理解，完整约束下不合适。

常见错误

  • 把窗口长度写成 2k，漏掉中心本身。
  • 把结果写到右端点 r，而不是 r−k。
  • 移除 nums[r−w+1]，导致旧最左项未被正确移除；应移除 nums[r−w]。
  • 使用 32 位整数求和，或在 JavaScript 用位运算强制截断窗口和。
  • 没有先判断 w>n，就初始化窗口而读越界。
  • 用四舍五入求平均；本题要求截断小数。

面试追问

  • 如果出现负数？仍可滑动求和，但要保持向零截断；Python 的 // 对负数向下取整，应改为符号处理后的整数除法。
  • 如果每个中心的 k 不同？长度不再固定，前缀和可在边界判断后用 O(1) 回答每个区间。
  • 如果输入是数据流？用长度 w 的队列维护窗口；必须等待中心右侧 k 项到齐才能输出，需要 O(w) 缓冲。
  • 如果数组会修改并反复查询？可考虑树状数组或线段树，维护区间和；固定一次扫描无需这些结构。
