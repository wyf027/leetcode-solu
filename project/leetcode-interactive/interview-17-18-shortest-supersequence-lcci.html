Brief

题意

给定长数组 big 与短数组 small，其中 small 的元素互不相同。请在 big 中寻找包含 small 全部元素的最短连续子数组，元素出现顺序不限。

返回该子数组的左右端点；若长度相同，返回左端点更小的一段；若不存在，返回空数组。

约束： big.length <= 100000， 1 <= small.length <= 100000。本题没有字符串参数；若其他题含空格，本系列用 ␠ 表示一个空格。

题解

Core insight

越长越容易合法，合法后只需收左边

右端点不断右移时，窗口只会获得新元素，不会丢失已经覆盖的目标；因此一旦覆盖 small，继续扩大没有意义，应立刻移动左端点压缩。

哈希表 count 只记录 small 中元素在当前窗口里的出现次数。变量 missing 记录计数仍为 0 的目标种类数。

当 missing 变为 0，窗口合法；每次移动左端点前先尝试更新答案。若移出的目标计数从 1 变成 0，窗口失效，恢复移动右端点。

Correctness

为什么不会漏掉最短窗口

固定右端点 R 时，内层 while 会把 L 推到窗口刚要失效的位置；过程中检查了所有以 R 结尾的合法窗口，最短者就是最后一个仍合法的窗口。

外层枚举了每个 R，因此全局最优窗口一定被检查。只在长度严格变短时更新，等长的后来窗口不会替换较早发现的窗口，从而保留更小左端点。

Full process

完整过程

  1. 1. 把 small 的每个值加入计数表，初始计数为 0，missing = small.length。
  2. 2. 右指针扫描 big；遇到目标且旧计数为 0，就让 missing 减 1。
  3. 3. missing = 0 时记录当前区间，并持续右移左指针。
  4. 4. 移出目标值后若计数归零，missing 加 1，停止收缩。
  5. 5. 所有右端点处理完后返回最佳区间；从未合法则返回 []。

Boundaries

边界情况

  • • big 为空或 small 比 big 长时自然返回空数组。
  • • small 只有一个元素时，首次命中即得到长度 1 的最优解。
  • • big 中目标可重复，计数大于 1 的副本可安全移出。
  • • small 元素互不相同，所以 missing 可按目标种类直接初始化。
  • • 严格使用 length < bestLength 保留最早等长解。

Complexity

复杂度

时间
O(B + S)
额外空间
O(S)

每个 big 元素最多被右指针加入一次、左指针移出一次。

Alternatives & mistakes

替代方案与常见错误

暴力枚举起点

对每个左端点向右找齐目标，最坏 O(B²)，会重复扫描同一片段。

目标位置列表 + 最小堆

把各目标在 big 中的出现位置合并，可做到 O(B log S)，但实现与空间更重，面试中不如滑动窗口直接。

预处理下一出现位置

查询快，但二维预处理可能达到 O(B·S) 空间，不适合 100000 级约束。

常见错误：把 small 之外的值加入计数表；missing 按窗口长度而非目标种类维护；更新答案后只收缩一次；等长时使用 ≤ 导致覆盖更早区间。

面试推荐：哈希计数滑动窗口一次扫描、边界语义清楚，也最容易证明正确。

Interview follow-ups

面试追问

为什么两个指针都是单调前进？

右指针负责补足覆盖，左指针只在合法时去除冗余。回退任何指针都只会重复处理已经证明过的状态。

若 small 允许重复元素怎么办？

计数表改存每个值的需求次数，missing 可维护仍缺的元素总数；右侧加入不超过需求时减 missing，左侧移出导致不足时加 missing。

为什么只在更短时更新就满足左端点最小？

右端点从小到大枚举；相同长度的窗口中，左端点更小者必然也更早结束，因此一定先被记录。

能否做到 O(1) 额外空间？

若值域有限可用定长数组代替哈希表；一般整数值域下仍需 O(S) 记录目标集合与计数。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] shortestSeq(int[] big, int[] small) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int value : small) {
            count.put(value, 0);
        }

        int missing = small.length;
        int left = 0;
        int bestStart = -1;
        int bestLength = Integer.MAX_VALUE;

        for (int right = 0; right < big.length; right++) {
            Integer current = count.get(big[right]);
            if (current != null) {
                if (current == 0) {
                    missing--;
                }
                count.put(big[right], current + 1);
            }

            while (missing == 0) {
                int length = right - left + 1;
                if (length < bestLength) {
                    bestLength = length;
                    bestStart = left;
                }

                Integer leftCount = count.get(big[left]);
                if (leftCount != null) {
                    count.put(big[left], leftCount - 1);
                    if (leftCount == 1) {
                        missing++;
                    }
                }
                left++;
            }
        }

        return bestStart == -1
            ? new int[0]
            : new int[] {bestStart, bestStart + bestLength - 1};
    }
}

var shortestSeq = function (big, small) {
    const count = new Map();
    for (const value of small) {
        count.set(value, 0);
    }

    let missing = small.length;
    let left = 0;
    let bestStart = -1;
    let bestLength = Infinity;

    for (let right = 0; right < big.length; right += 1) {
        if (count.has(big[right])) {
            const current = count.get(big[right]);
            if (current === 0) missing -= 1;
            count.set(big[right], current + 1);
        }

        while (missing === 0) {
            const length = right - left + 1;
            if (length < bestLength) {
                bestLength = length;
                bestStart = left;
            }

            if (count.has(big[left])) {
                const leftCount = count.get(big[left]);
                count.set(big[left], leftCount - 1);
                if (leftCount === 1) missing += 1;
            }
            left += 1;
        }
    }

    return bestStart === -1
        ? []
        : [bestStart, bestStart + bestLength - 1];
};
from typing import List


class Solution:
    def shortestSeq(self, big: List[int], small: List[int]) -> List[int]:
        count = {value: 0 for value in small}
        missing = len(small)
        left = 0
        best_start = -1
        best_length = float("inf")

        for right, value in enumerate(big):
            if value in count:
                if count[value] == 0:
                    missing -= 1
                count[value] += 1

            while missing == 0:
                length = right - left + 1
                if length < best_length:
                    best_length = length
                    best_start = left

                left_value = big[left]
                if left_value in count:
                    count[left_value] -= 1
                    if count[left_value] == 0:
                        missing += 1
                left += 1

        if best_start == -1:
            return []
        return [best_start, best_start + best_length - 1]
#include <climits>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> shortestSeq(vector<int>& big, vector<int>& small) {
        unordered_map<int, int> count;
        for (int value : small) {
            count[value] = 0;
        }

        int missing = static_cast<int>(small.size());
        int left = 0;
        int bestStart = -1;
        int bestLength = INT_MAX;

        for (int right = 0; right < static_cast<int>(big.size()); ++right) {
            auto rightIt = count.find(big[right]);
            if (rightIt != count.end()) {
                if (rightIt->second == 0) {
                    --missing;
                }
                ++rightIt->second;
            }

            while (missing == 0) {
                int length = right - left + 1;
                if (length < bestLength) {
                    bestLength = length;
                    bestStart = left;
                }

                auto leftIt = count.find(big[left]);
                if (leftIt != count.end()) {
                    --leftIt->second;
                    if (leftIt->second == 0) {
                        ++missing;
                    }
                }
                ++left;
            }
        }

        if (bestStart == -1) {
            return {};
        }
        return {bestStart, bestStart + bestLength - 1};
    }
};
