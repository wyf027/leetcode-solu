01 · Problem

题目要求

MEX 是数组中没有出现的最小非负整数。本题允许改变数组元素，但每次移动的距离固定。

给定一个下标从 0 开始的整数数组 nums 和一个正整数 value。一次操作可以选择任意元素，对它加上或减去 value；每个元素都可以被操作任意次。

例如，nums = [1,2,3]、value = 2 时，可以让 nums[0] 减去 2，得到 [-1,2,3]。

请返回经过任意次操作后，数组能够达到的最大 MEX。函数形式为 findSmallestInteger(nums, value)，返回一个整数。

示例 1

输入
nums = [1,-10,7,13,6,8], value = 5
输出
4

可以依次把 -10 变为 0、7 变为 2、13 变为 3，此时数组包含 0、1、2、3，MEX 为 4，且无法再提高。

示例 2

输入
nums = [1,-10,7,13,6,8], value = 7
输出
2

可以把 7 变为 0。数组已有 1，但无法同时得到 2，所以最大的 MEX 是 2。

  • 1 <= nums.length, value <= 105
  • -109 <= nums[i] <= 109

04 · Solution

一份元素，一张余数票

真正重要的不是元素当前有多大，而是它经过若干次固定步长移动后，能够落在哪一类整数上。

核心洞察

对任意元素加减 value 都不会改变它模 value 的余数。因此，一个元素能变成目标整数 x，当且仅当二者具有相同的归一化余数。

remainder = ((num % value) + value) % value
第二次取模用于把负数余数归一化到 [0, value - 1]。

把每种余数看成一种车票。为了让 MEX 至少为 m，必须分别构造出 0, 1, …, m-1；每构造一个目标，就消耗一张与它余数相同的票。

完整过程

  1. 统计数组中每个归一化余数出现的次数。
  2. 从 x = 0 开始递增，检查余数 x % value 的计数。
  3. 若还有票，消耗一张并继续检查 x + 1。
  4. 若计数为 0，就无法构造当前 x；它正是能够取得的最大 MEX。

正确性证明

可行性：当余数类 x % value 中还有元素时，该元素与 x 的差是 value 的整数倍，所以可以通过若干次加减操作把它变成 x。从 0 起逐个消耗后，所有更小的非负整数都能同时出现。

最优性：当算法停在 x 时，对应余数类已经没有未使用元素。任何等于 x 的最终元素都必须来自这个余数类；而已用元素又必须保留给更小的目标，否则 MEX 会更早中断。因此无法让数组同时包含 0…x，最大 MEX 不可能超过 x。

可行性说明答案至少是 x，最优性说明答案至多是 x，故算法正确。

替代方案

也可以直接计算每个余数类第一个供给不足的目标：若余数 r 有 count[r] 个元素，则该类首次缺少的是 r + count[r] × value，答案是所有余数类中的最小值。它同样需要计数，但从 0 开始模拟更直观，而且最多只走 nums.length + 1 步。

复杂度

时间O(n)
空间O(value)

边界情况

  • 负数必须归一化余数。
  • value = 1 时答案必为 nums.length。
  • 答案不会超过数组长度。
  • 重复值只影响对应余数的票数。

常见错误

  • 直接使用语言对负数的 % 结果。
  • 只记录某余数是否存在，而没有记录次数。
  • 把一个元素重复用于多个目标。
  • 真的修改、排序数组，增加无用工作。

面试追问

  • 为什么贪心按 0、1、2… 的顺序一定最优？
  • 如何推导 min(r + count[r] × value)？
  • 若操作次数有限，余数不变是否仍然足够？
  • 若每个元素有不同步长，模型会如何变化？

四语言完整代码

均采用计数 + 从 0 贪心消耗的同一实现。

JavaLeetCode
class Solution {
    public int findSmallestInteger(int[] nums, int value) {
        int[] count = new int[value];

        for (int num : nums) {
            int remainder = ((num % value) + value) % value;
            count[remainder]++;
        }

        for (int mex = 0; ; mex++) {
            int remainder = mex % value;
            if (count[remainder] == 0) {
                return mex;
            }
            count[remainder]--;
        }
    }
}

    }
};
Python 3LeetCode
from typing import List


class Solution:
    def findSmallestInteger(
        self, nums: List[int], value: int
    ) -> int:
        count = [0] * value

        for num in nums:
            count[num % value] += 1

        mex = 0
        while count[mex % value] > 0:
            count[mex % value] -= 1
            mex += 1

        return mex
C++LeetCode
class Solution {
public:
    int findSmallestInteger(
        vector<int>& nums, int value
    ) {
        vector<int> count(value);

        for (int num : nums) {
            int remainder = (num % value + value) % value;
            ++count[remainder];
        }

        for (int mex = 0; ; ++mex) {
            int remainder = mex % value;
            if (count[remainder] == 0) {
                return mex;
            }
            --count[remainder];
        }
    }
};
