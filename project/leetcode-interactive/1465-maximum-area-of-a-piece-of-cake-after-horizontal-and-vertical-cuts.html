Problem 1465

切割后面积最大的蛋糕

Maximum Area of a Piece of Cake After Horizontal and Vertical Cuts

一张矩形蛋糕被若干水平线和竖直线完整切开。先观察切口如何形成相邻间距，再尝试找出能组合成最大蛋糕块的高与宽。

难度 MEDIUM非付费题数组排序
Problem

题目描述

给定一个高度为 h、宽度为 w 的矩形蛋糕。horizontalCuts[i] 表示第 i 条水平切线距离蛋糕顶部的位置，verticalCuts[j] 表示第 j 条竖直切线距离蛋糕左侧的位置。

沿所有给定位置切割后，返回面积最大的那一块蛋糕的面积。由于结果可能很大，返回它对 10^9 + 7 取余后的值。

示例 1

输入：h = 5, w = 4, horizontalCuts = [1,2,4], verticalCuts = [1,3]
输出：4
解释：最大高度间距为 2，最大宽度间距为 2，最大面积为 4。

示例 2

输入：h = 5, w = 4, horizontalCuts = [3,1], verticalCuts = [1]
输出：6
解释：最大高度间距为 2，最大宽度间距为 3。

示例 3

输入：h = 5, w = 4, horizontalCuts = [3], verticalCuts = [3]
输出：9

Limits

约束

  • 2 ≤ h, w ≤ 10^9
  • 1 ≤ horizontalCuts.length ≤ min(h − 1, 10^5)
  • 1 ≤ verticalCuts.length ≤ min(w − 1, 10^5)
  • 1 ≤ horizontalCuts[i] < h
  • 1 ≤ verticalCuts[i] < w
  • 同一方向的切口位置互不相同。
返回值：整数，表示最大面积对 1,000,000,007 取余后的结果。

    Solution

    排序后寻找两个方向的最大间距

    核心洞察：每一块蛋糕的高度一定是两个相邻水平边界之间的距离，宽度一定是两个相邻竖直边界之间的距离。因为任意水平区间都能与任意竖直区间相交，所以最大面积就是“最大高度间距 × 最大宽度间距”。

    完整过程

    1. 分别对两个切口数组升序排序。
    2. 水平最大间距先取顶部到首切口、末切口到底部，再扫描所有相邻切口。
    3. 竖直方向同理，得到最大宽度。
    4. 用 64 位整数或大整数计算乘积，再对 10^9 + 7 取余。

    正确性证明

    引理 1：切割后的每块蛋糕，其高度属于相邻水平边界间距集合，宽度属于相邻竖直边界间距集合。

    引理 2：最大水平间距与最大竖直间距对应的条带必然相交，形成一块面积为二者乘积的蛋糕。

    结论：任意块的高、宽均不超过这两个最大值，因此没有更大的块；该乘积既可达到又是上界，算法正确。

    边界与数值

    • 必须纳入坐标 0 和 h / w 两侧边界。
    • 切口数组可能未排序。
    • 单方向只有一个切口时，也要比较它到两侧边界的距离。
    • 面积最大可接近 10^18；Java/C++ 使用 64 位整数，JavaScript 使用 BigInt。

    复杂度

    设水平切口数为 m，竖直切口数为 n。

    时间：O(m log m + n log n)，排序占主导。
    额外空间：若原地排序，除排序栈外为 O(1)；语言排序实现可能使用额外空间。

    替代方案与取舍

    可以把边界 0 和 h / w 直接追加到数组再排序，随后统一扫描，代码更直观，但会修改输入并增加两个元素。若坐标范围很小，也可用布尔桶线性扫描；本题坐标上限为 10^9，桶方案不现实。比较排序的下界可知，在没有额外结构或范围约束时，通用解法以排序最稳妥。

    Javalong 防溢出
    import java.util.Arrays;

class Solution {
    private static final long MOD = 1_000_000_007L;

    public int maxArea(int h, int w,
                       int[] horizontalCuts,
                       int[] verticalCuts) {
        Arrays.sort(horizontalCuts);
        Arrays.sort(verticalCuts);

        long maxHeight = horizontalCuts[0];
        for (int i = 1; i < horizontalCuts.length; i++) {
            maxHeight = Math.max(maxHeight,
                horizontalCuts[i] - horizontalCuts[i - 1]);
        }
        maxHeight = Math.max(maxHeight,
            h - horizontalCuts[horizontalCuts.length - 1]);

        long maxWidth = verticalCuts[0];
        for (int i = 1; i < verticalCuts.length; i++) {
            maxWidth = Math.max(maxWidth,
                verticalCuts[i] - verticalCuts[i - 1]);
        }
        maxWidth = Math.max(maxWidth,
            w - verticalCuts[verticalCuts.length - 1]);

        return (int) ((maxHeight * maxWidth) % MOD);
    }
}

    /**
 * @param {number} h
 * @param {number} w
 * @param {number[]} horizontalCuts
 * @param {number[]} verticalCuts
 * @return {number}
 */
var maxArea = function(h, w, horizontalCuts, verticalCuts) {
    horizontalCuts.sort((a, b) => a - b);
    verticalCuts.sort((a, b) => a - b);

    let maxHeight = horizontalCuts[0];
    for (let i = 1; i < horizontalCuts.length; i++) {
        maxHeight = Math.max(
            maxHeight,
            horizontalCuts[i] - horizontalCuts[i - 1]
        );
    }
    maxHeight = Math.max(
        maxHeight,
        h - horizontalCuts[horizontalCuts.length - 1]
    );

    let maxWidth = verticalCuts[0];
    for (let i = 1; i < verticalCuts.length; i++) {
        maxWidth = Math.max(
            maxWidth,
            verticalCuts[i] - verticalCuts[i - 1]
        );
    }
    maxWidth = Math.max(
        maxWidth,
        w - verticalCuts[verticalCuts.length - 1]
    );

    const MOD = 1000000007n;
    return Number((BigInt(maxHeight) * BigInt(maxWidth)) % MOD);
};

    #include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maxArea(int h, int w,
                vector<int>& horizontalCuts,
                vector<int>& verticalCuts) {
        sort(horizontalCuts.begin(), horizontalCuts.end());
        sort(verticalCuts.begin(), verticalCuts.end());

        long long maxHeight = horizontalCuts.front();
        for (int i = 1; i < horizontalCuts.size(); ++i) {
            maxHeight = max(
                maxHeight,
                static_cast<long long>(horizontalCuts[i])
                    - horizontalCuts[i - 1]
            );
        }
        maxHeight = max(
            maxHeight,
            static_cast<long long>(h) - horizontalCuts.back()
        );

        long long maxWidth = verticalCuts.front();
        for (int i = 1; i < verticalCuts.size(); ++i) {
            maxWidth = max(
                maxWidth,
                static_cast<long long>(verticalCuts[i])
                    - verticalCuts[i - 1]
            );
        }
        maxWidth = max(
            maxWidth,
            static_cast<long long>(w) - verticalCuts.back()
        );

        constexpr long long MOD = 1'000'000'007LL;
        return static_cast<int>((maxHeight * maxWidth) % MOD);
    }
};

    面试追问

    • 为什么两个方向的最大间距一定能组合在同一块中？
    • 如果切口是动态加入的，怎样快速维护最大间距？可考虑有序集合加间距多重集合。
    • 如果只允许执行部分切割，目标会怎样变化？此时需要重新定义选择策略，不能直接沿用本结论。
    • 为什么 JavaScript 这里建议使用 BigInt？

    常见错误

    • 只比较切口之间的距离，漏掉蛋糕边缘。
    • 未排序就直接计算相邻元素之差。
    • 先对高、宽分别取模再用普通 32 位整数相乘，发生溢出。
    • 误以为需要枚举所有小块，写出 O(mn)。
    • JavaScript 直接用 Number 计算接近 10^18 的乘积，失去整数精度。
