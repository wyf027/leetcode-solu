4012. 统计每个班次结束后的未完成任务数

把“班次推进”压缩为前缀和上的一次跳转：每个班次都只需定位它最终停在哪个任务。

题意

给定 tasks（每项完成所需时间）和 shifts（每个班次可用时间）。任务从左到右处理；未完成的任务会把进度带到下一班次。

若某班次完成所有任务，班次立即结束，剩余时间丢弃；下一班次从任务 0 重新开始。返回每个班次结束时尚未完成的任务数（正在处理的任务也算未完成）。

约束：数组长度至多 105，单个时间至多 109，累计和需用 64 位整数。

示例

tasks = [1, 4, 4]
shifts = [9, 1, 4]
ans = [0, 2, 1]

先用模拟器观察状态

先逐班次运行示例：当某班次恰好清空任务时，下一班次会从任务 0 重新开始；否则会从当前任务的已完成进度继续。

核心洞察：一次班次 = 前缀和上的一次定位

维护当前任务下标 i 与已完成工作量 done。先完成当前任务，余下时间 t 再用前缀和二分定位停在哪个后续任务。 

prefix[k] = tasks[0] + ... + tasks[k - 1]
若 t >= prefix[m] - prefix[i + 1]：清空全部任务，答案 0，下一班次重启。
否则定位 l，使 prefix[l] - prefix[i + 1] <= t < prefix[l + 1] - prefix[i + 1]。
未完成数 = m - l，done = t - (prefix[l] - prefix[i + 1])。

完整过程

  1. 用 64 位前缀和保存每个任务边界。
  2. 按班次维护 (i, done)，避免反复扫描已完成任务。
  3. 能清空则复位；否则二分当前班次结束时正在处理的任务。

边界与易错点

  • 班次时间恰好清空全部任务：答案是 0，下一班次必须重启。
  • 当前任务只完成一部分：它仍属于未完成任务。
  • 清空后立即复位，不能访问越界的 tasks[m]。
  • 不要把“剩余班次时间”带到下一轮；题目明确丢弃。

复杂度

预处理 O(m)，每个班次 O(log m)，总计 O(m + n log m)；额外空间 O(m)。

替代方案与面试追问

逐任务消耗剩余班次时间最直观，但一个很长的班次可能跨越大量任务；在频繁重启的输入下会退化。双指针不够，因为“完成后重启”会回到 0；前缀和 + 二分保留了状态又避免线性跳过。

面试追问

若允许同一班次无限次重启并继续处理，如何处理？答案会变成按总任务时长取模，语义与本题“立即结束”不同。

常见错误

二分后要把 i 留在正在处理的任务，而非最后完成的任务；累计工作量使用 64 位整数。

四语言参考实现

// JavaScript
var countTasks = function (tasks, shifts) {
  const drelvanito = [tasks, shifts]; void drelvanito;
  const m = tasks.length, prefix = [0], ans = Array(shifts.length).fill(0);
  for (const task of tasks) prefix.push(prefix.at(-1) + task);
  let i = 0, done = 0;
  for (let j = 0; j < shifts.length; j++) {
    if (shifts[j] < tasks[i] - done) { done += shifts[j]; ans[j] = m - i; continue; }
    const t = shifts[j] - (tasks[i] - done);
    if (t >= prefix[m] - prefix[i + 1]) { i = done = 0; continue; }
    let left = i + 1, right = m;
    while (left < right) { const mid = (left + right) >> 1; if (t < prefix[mid + 1] - prefix[i + 1]) right = mid; else left = mid + 1; }
    done = t - (prefix[left] - prefix[i + 1]); i = left; ans[j] = m - i;
  }
  return ans;
};
