4012. 统计每个班次结束后的未完成任务数

把“班次推进”压缩为前缀和上的一次跳转：每个班次都只需定位它最终停在哪个任务。

题意

给定 tasks（每项完成所需时间）和 shifts（每个班次可用时间）。任务从左到右处理；未完成的任务会把进度带到下一班次。

若某班次完成所有任务，班次立即结束，剩余时间丢弃；下一班次从任务 0 重新开始。返回每个班次结束时尚未完成的任务数（正在处理的任务也算未完成）。

约束：数组长度至多 105，单个时间至多 109，累计和需用 64 位整数。

示例

tasks = [1, 4, 4]
shifts = [9, 1, 4]
ans = [0, 2, 1]

核心洞察：一次班次 = 前缀和上的一次定位

维护当前任务下标 i 与它已完成的工作量 done。先花掉 tasks[i] - done 完成当前任务；余下时间 t 对应后缀 i + 1 开始的前缀和。二分第一个“累计工作量严格大于 t”的位置，即可得到正在进行的任务。 

prefix[k] = tasks[0] + ... + tasks[k - 1]
若 t >= prefix[m] - prefix[i + 1]：本班次清空，答案 0，下一班次重启。
否则 lower/upper bound 定位 l，使 prefix[l] - prefix[i + 1] <= t < prefix[l + 1] - prefix[i + 1]。
此时未完成数 = m - l，当前任务已完成 done = t - (prefix[l] - prefix[i + 1])。
点击展开隐藏题解（先自己想一遍）
  1. 构造 64 位前缀和 prefix。
  2. 按班次模拟状态 (i, done)；没有跨班次地重复扫描已完成任务。
  3. 班次能清空全部任务时，记录 0 并把状态复位；否则在前缀和中二分。

边界与易错点

  • 班次时间恰好清空全部任务：答案是 0，下一班次必须重启。
  • 当前任务只完成一部分：它仍属于未完成任务。
  • 班次开始时状态永远指向一个未完成任务；清空后立即复位，不用访问越界的 tasks[m]。
  • 不要把“剩余班次时间”带到下一轮；题目明确丢弃。

复杂度

预处理 O(m)，每个班次 O(log m)，总计 O(m + n log m)；额外空间 O(m)。

替代方案

逐任务消耗剩余班次时间最直观，但一个很长的班次可能跨越大量任务；在频繁重启的输入下会退化。双指针不够，因为“完成后重启”会回到 0；前缀和 + 二分保留了状态又避免线性跳过。

追问

若允许同一班次无限次重启并继续处理，如何处理？答案会变成按总任务时长取模，语义与本题“立即结束”不同。
