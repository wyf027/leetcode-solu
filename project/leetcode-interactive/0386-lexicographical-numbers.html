Deep Dive

把整数区间当成一棵十叉树

核心洞察完整过程正确性复杂度代码替代方案面试追问常见错误

核心洞察

字典序不是数值大小顺序，而是比较十进制字符串。从任意前缀 curr 出发，以它开头的下一层数字依次为 curr × 10, curr × 10 + 1, …。因此，字典序恰好对应十叉前缀树的先序遍历。

能下潜curr × 10 ≤ n 时，下一项就是 curr × 10。
能去右邻不能下潜但 curr + 1 ≤ n 且末位不是 9 时，下一项是 curr + 1。
必须回退没有合法右邻时，反复删除末位，直到祖先存在下一个兄弟，再加 1。

完整过程

  1. 令游标 curr = 1。
  2. 重复恰好 n 次：先把 curr 加入答案。
  3. 若 curr × 10 ≤ n，向最左孩子下潜：curr *= 10。
  4. 否则，当前子树已经走完。只要 curr 以 9 结尾，或 curr + 1 > n，就令 curr = floor(curr / 10) 回到父节点。
  5. 回退到存在右邻的位置后执行 curr += 1，进入下一个兄弟子树。

例如 n = 13：1 → 10 → 11 → 12 → 13。在 13 处无法下潜、14 又越界，于是回退到 1，再进入兄弟 2。

正确性证明

引理 1：算法给出的下一游标，是当前数之后字典序最小的合法整数。若左孩子存在，增加一位所得的 curr × 10 是当前前缀下最小后继；否则，最近的合法右兄弟是后继。若本层没有右兄弟，删除末位不会跳过任何数，因为当前前缀子树已遍历完毕，故应继续向祖先寻找右兄弟。

引理 2：任何整数都不会重复。下潜、进入右兄弟与向上回退后的右移，对应树上互不相同的边或节点，游标不会回到已完成的子树。

定理：从字典序最小的 1 开始，根据引理 1，每一步都访问尚未访问元素中的字典序最小者；根据引理 2 不会重复。循环输出恰好 n 项，而区间内也恰有 n 个整数，所以结果完整且严格符合字典序。

边界处理

  • n = 1：只进行一次输出，无须生成后继。
  • 当前数以多个 9 结尾时，可能连续回退多层，例如从 199 回到 2。
  • 右邻虽然末位不是 9，但仍可能大于 n；因此回退条件必须同时检查 curr + 1 > n。
  • 在本题上限内乘 10 不会超出 32 位整数；若约束扩大，判断下潜时可改用 curr ≤ n / 10 防止溢出。

复杂度

O(n)每个整数输出一次；所有回退的总次数可摊还到遍历过的树边上。
O(1)除题目要求返回的 O(n) 结果数组外，只维护游标和循环变量。

四语言完整实现

选择语言查看可提交实现。四份代码使用同一套迭代游标机制。

Java
class Solution {
    public List<Integer> lexicalOrder(int n) {
        List<Integer> answer = new ArrayList<>(n);
        int curr = 1;

        for (int i = 0; i < n; i++) {
            answer.add(curr);

            if (curr * 10 <= n) {
                curr *= 10;
            } else {
                while (curr % 10 == 9 || curr + 1 > n) {
                    curr /= 10;
                }
                curr++;
            }
        }
        return answer;
    }
}

替代方案

  • 转字符串后排序：写法直观，但排序需要 O(n log n) 次比较，并产生字符串与排序辅助开销，不满足目标复杂度。
  • 递归 DFS：从 1–9 依次展开十个孩子，时间为 O(n)，但递归栈需要 O(log n) 空间；它很适合理解结构，却不满足严格的常数额外空间要求。
  • 显式栈 DFS：避免递归，但仍需要额外栈，并且入栈顺序容易写反。

面试追问

为什么连续回退仍然是 O(n)？

下潜跨过一条树边，回退最多把这些已下潜的层级再走回来。整个遍历中，每条相关边只会被常数次处理，所以总回退次数是线性的。

如果要求第 k 个字典序数字，而不是完整列表？

可计算某个前缀子树中不超过 n 的节点数：若整棵子树都在 k 之前，就整段跳过；否则下潜。这样无需枚举全部元素。

如何推广到其他进制？

把乘 10、模 10 与除 10 替换为基数 b，并按该进制的符号顺序处理孩子，即可得到同样的前缀树遍历。

为什么返回数组不计入额外空间？

题目必须返回 n 个数，这部分是输出本身。复杂度约定通常单独报告工作空间；这里工作空间只有几个整数变量。

常见错误

  • 只在末位为 9 时回退，忘记 curr + 1 > n 也意味着当前层没有合法右邻。
  • 回退一次就停止；像 199 这样的节点可能需要连续删除多个末位。
  • 先更新游标再加入答案，导致遗漏 1 或多输出一个非法值。
  • 把完整递归 DFS 的栈空间误写成 O(1)。
  • 用字符串排序虽然结果正确，却没有达到题目要求的 O(n) 时间。
