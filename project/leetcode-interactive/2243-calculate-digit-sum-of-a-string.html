Calculate Digit Sum of a String

任务与规则

给定仅含数字的字符串 s 和整数 k。只要当前字符串长度大于 k，就执行一轮操作：

  1. 从左到右，每 k 个字符分成一组；最后一组可以少于 k 个。
  2. 把每组中的各个数字相加，用这个和的十进制字符串替换该组。
  3. 按原先顺序拼接各组结果，作为下一轮的字符串。

当长度不超过 k 时停止，返回此时的字符串。例如，一组 "346" 的结果是 "13"。

约束：1 ≤ s.length ≤ 100；2 ≤ k ≤ 100；s 的每个字符均为 0–9。函数：digitSum(s, k) → string。

官方示例 1

输入：s = "11111222223", k = 3
输出："135"

第一轮分组为 111、112、222、23，各组和为 3、4、6、5，拼接为 3465。第二轮分组为 346、5，得到 13、5，拼接为 135，长度等于 3，停止。

官方示例 2

输入：s = "00000000", k = 3
输出："000"

分组为 000、000、00，每组都变成字符串 0；拼接后为 000，长度等于 3，停止。结果中的零不能丢弃。

04 / 深入理解

准备好再看题解

核心洞察、证明与四种语言实现，按需展开。

题解：按轮模拟，保持组的顺序

核心洞察

每轮只依赖本轮开始时的字符串。用独立容器收集各组数字和，整轮完成后再替换 s，这样不会把刚写入的结果误当作本轮输入。和可能有多位，必须完整转成字符串，例如 3 + 4 + 6 = 13，保留 13。

完整过程

  1. 判断 s.length > k。不满足则直接返回。
  2. 建立空结果容器，从下标 0 开始，以 k 为步长枚举每组起点 i。
  3. 令本组 sum = 0，累加区间 [i, min(i + k, s.length)) 中的每个数字。
  4. 把 sum 的十进制字符串加入结果容器，按组顺序拼接。
  5. 将拼接结果赋给 s，重新判断长度。

示例一的整轮状态为 11111222223 → 3465 → 135。每一轮都从头分组，上一轮的组边界不会保留。

正确性与终止

组内不变式：处理完本组前 j 个字符后，sum 等于这些字符对应数字的总和，因此组处理结束时得到的就是题目规定的组和。

组间不变式：结果容器始终存放已处理各组的正确替换结果，且顺序与原字符串一致。所有组覆盖本轮字符串且互不重叠，所以拼接结果恰好是一轮合法操作。由轮数归纳，每轮 s 都与题目操作后的状态一致。

终止性：每组替换后的位数不超过原组长度，因此总长度不会增大。如果某组和至少为 10，替换后整个字符串的数字总和严格减少；如果所有组和都小于 10，每组都变成一位，且当前长度大于 k ≥ 2，故总长度严格减少。因此“字符串长度 + 各位数字总和”这个非负整数势能每轮严格下降，循环必然结束。退出时长度不超过 k，符合停止条件，返回值正确。

复杂度

设初始长度为 n，实际执行 R 轮，各轮开始长度为 n₀、n₁、…、nᵣ₋₁。代码时间为 O(n + Σnᵢ)，可写成 O(n(R + 1))，额外空间 O(n)。由上述势能初值不超过 10n，得 R = O(n)，因此一个通用且保守的时间上界为 O(n²)，并非声称这是紧确界。不要仅凭分组断言每轮长度减半：k = 2 时，9999 → 1818，长度暂时不变。

边界与常见错误

  • 长度等于 k 就停止，循环条件不能写成 ≥ k。
  • 最后不足 k 的一组也要处理，用 min 限定右端点。
  • 组和可以超过 9，不能只取个位，也不能在组内一直求数根。
  • 每组都要重新置零 sum；每轮都要清空结果容器。
  • 不能把整个 s 转为整数：这会丢失前导零，且长输入可能溢出。
  • 全零组输出一个 "0"，多个组输出的零需要按组数保留。
  • k 的合法下限是 2。若错误允许 k = 1，长度大于 1 时可能永不结束。

替代方案

可以用切片加 map/reduce 对每组求和，可读性良好但会创建额外切片。索引循环更直接，也适合四种语言统一理解。递归能表达按轮转换，但没有必要引入调用栈。全局数字和或数根不能替代分组过程，因为答案的位序、分组边界及停止长度都影响结果。

面试追问

  • 为何不直接原地替换？结果组长会变化，边读边写容易污染后续输入；若必须原地做，需要明确读写指针及容量管理。
  • 怎样证明 k = 2 也会停？长度不变时，至少一个组产生了多位和，其数字总和会下降；使用势能而非“每轮长度严格变短”。
  • 输入很大如何降低内存？按 k 个数字缓冲并依序输出组和；后续轮可继续流式处理，但需要知道每轮输出长度才能判断是否停止。

Java

class Solution {
    public String digitSum(String s, int k) {
        while (s.length() > k) {
            StringBuilder next = new StringBuilder();
            for (int i = 0; i < s.length(); i += k) {
                int sum = 0;
                for (int j = i; j < Math.min(i + k, s.length()); j++) {
                    sum += s.charAt(j) - '0';
                }
                next.append(sum);
            }
            s = next.toString();
        }
        return s;
    }
}

var digitSum = function(s, k) {
    while (s.length > k) {
        const parts = [];
        for (let i = 0; i < s.length; i += k) {
            let sum = 0;
            for (let j = i; j < Math.min(i + k, s.length); j++) {
                sum += Number(s[j]);
            }
            parts.push(String(sum));
        }
        s = parts.join('');
    }
    return s;
};

Python 3

class Solution:
    def digitSum(self, s: str, k: int) -> str:
        while len(s) > k:
            parts = []
            for i in range(0, len(s), k):
                total = 0
                for j in range(i, min(i + k, len(s))):
                    total += int(s[j])
                parts.append(str(total))
            s = ''.join(parts)
        return s
