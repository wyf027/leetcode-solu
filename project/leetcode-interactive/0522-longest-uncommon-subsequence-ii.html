最长特殊序列 IILongest Uncommon Subsequence II

在一组很短的字符串里，找出一个只属于其中某个字符串、却不是任何其他字符串子序列的最长序列。先用下面的“候选人审查台”感受判定过程，再按需展开完整题解。

字符串数 ≤ 50单串长度 ≤ 10候选串整体判定时间 O(n²L)

题意

给定字符串数组 strs。若某个序列是数组中某个字符串的子序列，但不是其余任何字符串的子序列，就称它为“特殊序列”。返回最长特殊序列的长度；若不存在则返回 -1。

子序列允许删除任意数量的字符，但剩余字符的相对顺序必须保持。例如 "abc" 是 "aebdc" 的子序列。

函数签名

findLUSlength(strs: string[]) → integer

官方示例与约束

示例 1 输入：strs = ["aba","cdc","eae"] 输出：3 示例 2 输入：strs = ["aaa","aaa","aa"] 输出：-1
  • 2 <= strs.length <= 50
  • 1 <= strs[i].length <= 10
  • strs[i] 仅含小写英文字母。

候选人审查台

按长度从大到小查看候选字符串。当前候选若能“藏进”另一个字符串，就会被淘汰；否则它的完整长度就是答案。

完整题解

核心洞察

答案一定可以取为数组中某个完整字符串，而无需枚举它的所有子序列。原因是：如果候选字符串 s 本身不是其他任何字符串的子序列，那么 s 已经是合法特殊序列；如果 s 是另一个字符串的子序列，那么 s 的任意子序列也同样是那个字符串的子序列，无法因为变短而翻盘。

因此只需把每个 strs[i] 当作候选，确认它是否不是所有 strs[j] (j ≠ i) 的子序列，并取合法候选的最大长度。

完整过程

  1. 令答案为 -1，逐个选择数组中的字符串 strs[i] 作为候选。
  2. 遍历所有其他字符串 strs[j]。用双指针判断候选是否为它的子序列：指针 p 指向候选，扫描目标串，字符相等时推进 p。
  3. 若扫描结束时 p == candidate.length，候选可以嵌入另一个字符串，立即淘汰。
  4. 若候选对所有其他字符串都无法完整匹配，它就是特殊序列，用其长度更新答案。

正确性证明

引理：若字符串 x 是字符串 y 的子序列，则 x 的任意子序列也都是 y 的子序列。子序列关系具有传递性。

完备性：设最优特殊序列 u 来自 strs[i]。如果完整的 strs[i] 是其他字符串的子序列，根据引理，u 也会是该字符串的子序列，与其特殊性矛盾。所以 strs[i] 本身也是特殊序列，且长度不小于 u。算法会检查并选中它。

可靠性：算法仅接受不为任何其他字符串子序列的完整候选，恰好满足特殊序列定义。因此返回值正是最长特殊序列长度；没有候选时返回 -1。

边界与复杂度

  • 完全相同的字符串会互为子序列，因此重复项不能成为答案。
  • 较长字符串不可能是较短字符串的子序列，可直接跳过该次匹配（代码中的双指针自然处理）。
  • 若所有候选都被覆盖，答案保持为 -1。
  • 设字符串数为 n、最大长度为 L：时间复杂度 O(n²L)，额外空间 O(1)（不计语言运行时迭代开销）。

替代方案

可先按长度降序排序，遇到第一个合法候选就返回，能在部分输入上提前结束；但排序会改变索引关系并增加 O(n log n) 步骤。也可先用哈希表排除重复字符串，再检查唯一候选，常数更小，但核心判定仍是双指针。

面试追问

  • 为什么不枚举 2L 个子序列？ 完整候选定理已经把搜索空间缩到 n 个字符串。
  • 能否按长度剪枝？ 可以：长度小于等于当前答案的候选无需再检查；目标比候选短时也无需匹配。
  • 若字符串非常长怎么办？ 仍可双指针线性匹配；若对同一长串有大量查询，可预处理字符的下一位置表。

常见错误

  • 把“子序列”误写成“子串”，要求字符连续。
  • 比较时没有排除同一个数组下标，导致候选总与自己匹配而被淘汰。
  • 只统计重复次数，却忘记唯一字符串仍可能是更长字符串的子序列。
  • 遇到相同长度不同内容就误判；同长度下只有内容完全相同才构成子序列。

class Solution {
    public int findLUSlength(String[] strs) {
        int answer = -1;
        for (int i = 0; i < strs.length; i++) {
            boolean uncommon = true;
            for (int j = 0; j < strs.length; j++) {
                if (i != j && isSubsequence(strs[i], strs[j])) {
                    uncommon = false;
                    break;
                }
            }
            if (uncommon) answer = Math.max(answer, strs[i].length());
        }
        return answer;
    }

    private boolean isSubsequence(String small, String large) {
        int p = 0;
        for (int i = 0; i < large.length() && p < small.length(); i++) {
            if (small.charAt(p) == large.charAt(i)) p++;
        }
        return p == small.length();
    }
}

from typing import List

class Solution:
    def findLUSlength(self, strs: List[str]) -> int:
        def is_subsequence(small: str, large: str) -> bool:
            p = 0
            for ch in large:
                if p < len(small) and small[p] == ch:
                    p += 1
            return p == len(small)

        answer = -1
        for i, candidate in enumerate(strs):
            uncommon = all(
                i == j or not is_subsequence(candidate, other)
                for j, other in enumerate(strs)
            )
            if uncommon:
                answer = max(answer, len(candidate))
        return answer

public:

                    uncommon = false;
                    break;
                }
            }
            if (uncommon) answer = max(answer, (int)strs[i].size());
        }
        return answer;
    }

private:
    bool isSubsequence(const string& small, const string& large) {
        int p = 0;
        for (char ch : large) {
            if (p < (int)small.size() && small[p] == ch) ++p;
        }
        return p == (int)small.size();
    }
