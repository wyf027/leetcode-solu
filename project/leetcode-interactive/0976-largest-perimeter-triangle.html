976. 三角形的最大周长

Largest Perimeter Triangle

三根木条，既要“站得住”，又要围得大。先在实验台上观察排序后的候选三元组，再决定是否展开完整题解。

EASY数组数学贪心排序

题目

给定一个正整数数组 nums，从中选出三个长度，组成面积非零的三角形。返回可以得到的最大周长；若不存在合法三角形，返回 0。

函数形式：largestPerimeter(nums: integer[]) → integer

官方示例

输入：nums = [2,1,2]
输出：5
解释：边长 1、2、2 可组成三角形。
输入：nums = [1,2,1,10]
输出：0
解释：任取三条边都无法组成面积非零的三角形。

约束

  • 3 <= nums.length <= 10⁴
  • 1 <= nums[i] <= 10⁶

三角形候选扫描实验台

示例数组排序后为 [2, 3, 3, 4, 6, 10]。扫描从最大的三条边开始。

扫描轨迹

排序后若当前最大的三条边不合法，就舍弃当前最大边。继续向左，直到第一次满足三角形不等式。

准备查看完整解法？

先尝试解释：为什么从大到小遇到的第一个合法三元组，一定给出最大周长？

题解

核心洞察

将边长升序排列。对连续三项 a ≤ b ≤ c，只需检查 a + b > c。从数组末端向前扫描，第一次合法的三元组就是答案。

完整过程

  1. 将 nums 升序排序。
  2. 令 i 从末尾开始，把 nums[i-2], nums[i-1], nums[i] 作为候选。
  3. 若前两边之和大于最大边，返回三边之和。
  4. 否则将 i 左移；扫描结束仍未找到则返回 0。

正确性说明

对固定最大边 c = nums[i]，它左侧最大的两条边就是 nums[i-2] 和 nums[i-1]。若它们之和仍不大于 c，换成更小的边也不可能成功，所以可以排除 c。若三者合法，因为扫描顺序按最大候选周长从右向左推进，任何尚未考察的三元组都无法取得更大的边组合及周长，因此当前周长最大。

边界情况

  • 恰好相等（如 1、1、2）面积为零，不合法，必须使用严格大于。
  • 只有三个元素时直接检查这一组。
  • 所有组合都不合法时返回 0。
  • 允许重复边长，等腰和等边三角形均有效。

复杂度

排序耗时 O(n log n)，扫描耗时 O(n)；总体时间 O(n log n)。除排序实现所需空间外，扫描使用 O(1) 额外空间。

替代方案

暴力枚举所有三元组需要 O(n³)；可以得到正确答案，却无法满足较大输入。也可使用计数排序优化特定值域，但这里最大值达到 10⁶，通用比较排序更直接。

面试追问

  • 为什么只检查排序后连续的三个元素？
  • 若不能修改输入数组，空间复杂度如何变化？
  • 如果要返回三条边本身或其原下标，如何调整？
  • 若求最大面积而不是最大周长，贪心结论还成立吗？

常见错误

  • 把条件写成 a + b >= c，错误接受退化三角形。
  • 排序方向与下标移动方向不一致。
  • 找到合法组合后仍继续扫描，或忘记无解返回 0。
  • 只检查原数组相邻元素，而没有先排序。

四种语言完整代码

JavaLeetCode
import java.util.Arrays;

class Solution {
    public int largestPerimeter(int[] nums) {
        Arrays.sort(nums);
        for (int i = nums.length - 1; i >= 2; i--) {
            if (nums[i - 2] + nums[i - 1] > nums[i]) {
                return nums[i - 2] + nums[i - 1] + nums[i];
            }
        }
        return 0;
    }
}

from typing import List

class Solution:
    def largestPerimeter(self, nums: List[int]) -> int:
        nums.sort()
        for i in range(len(nums) - 1, 1, -1):
            if nums[i - 2] + nums[i - 1] > nums[i]:
                return nums[i - 2] + nums[i - 1] + nums[i]
        return 0
C++LeetCode
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int largestPerimeter(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        for (int i = static_cast<int>(nums.size()) - 1; i >= 2; --i) {
            if (nums[i - 2] + nums[i - 1] > nums[i]) {
                return nums[i - 2] + nums[i - 1] + nums[i];
            }
        }
        return 0;
    }
};
