Minimum Jumps to Reach Home

Problem

先把规则读成一张地图

函数接收 forbidden、a、b、x，返回从 0 恰好到达 x 的最少跳数；无法到达时返回 -1。

一只跳蚤从数轴位置 0 出发，家在位置 x。每次可向右跳恰好 a，或向左跳恰好 b。它允许越过家后再折返，但任何落点都不能是负数或禁区。

请找到落在 x 的最少跳跃次数。若不存在合法路线，返回 -1。

minimumJumps(forbidden, a, b, x) → integer

四条移动规则

  1. 1向前恰好跳 a 个位置。
  2. 2向后恰好跳 b 个位置。
  3. 3不能连续两次向后跳。
  4. 4不能落在 forbidden 中，也不能落到负数位置。

Solution

把“方向记忆”放进 BFS 状态

核心洞察只记录位置不够。状态必须是 (position, canBack)：当前位置，以及下一步是否允许后跳。这样“不能连续后跳”就变成了普通的状态转移限制。

完整过程

  1. 把禁区放进集合，便于常数时间判断落点是否合法。
  2. 从状态 (0, true) 开始按层 BFS；队列中同时保存跳数。
  3. 向前跳到 position + a 后，下一次仍允许后跳，所以新状态为 (next, true)。
  4. 只有 canBack = true 时才尝试向后跳；后跳后的状态是 (next, false)。
  5. 位置不能为负、不能在禁区、不能越过有限搜索上界；同一完整状态只入队一次。
  6. 第一次取出位置 x 的状态时返回层数；队列耗尽则返回 -1。

为什么搜索可以有限？

令 M = max(x, max(forbidden))。只需搜索到 upper = M + a + b。在 M 右侧已没有目标或禁区；继续远离超过一次前跳与一次后跳可覆盖的缓冲区，不会产生更短的首次到达路线。该上界把无限数轴裁成有限状态图。

正确性说明

引理 1：状态完整表达所有合法后继

position 决定两个候选落点，canBack 决定后跳边是否存在。除这两项外，更早的路径历史不会影响下一步，因此状态信息充分。

引理 2：BFS 不漏掉合法最短路线

对每个出队状态，算法枚举所有合法的前跳，以及在允许时的后跳；非法落点被剔除，合法且未访问的完整状态被加入下一层。因此，按路径长度归纳，所有可达状态都会在对应层被发现。

定理：返回值是最少跳跃次数

BFS 按跳数从小到大访问状态。第一次到达 x 时，不存在跳数更少但尚未处理的路线；故此跳数最小。若队列耗尽，有限状态图中所有可达状态都已考察，返回 -1 正确。

边界情况

  • x = 0 时无需跳跃，直接返回 0。
  • 越过家是允许的，不能把上界错误地设为 x。
  • 后跳落点必须非负；后跳后不能再次后跳。
  • 同一位置的 canBack=true 与 false 必须分别访问。
  • 禁区限制的是落点；起跳轨迹跨过禁区没有问题。

复杂度

令 U = max(x, max(forbidden)) + a + b。至多有 2(U+1) 个状态，时间复杂度 O(U + n)，空间复杂度 O(U + n)，其中 n 是禁区数量。

替代方案

可用最短路建模后运行 Dijkstra，但所有边权都是 1，BFS 更直接。动态规划难以自然处理回跳形成的环；DFS 即使配合记忆化，也不能天然保证首次得到的是最短路线。

面试追问

  • 如果允许连续后跳最多 k 次？把状态扩展为连续后跳次数 0..k。
  • 如果向前、向后的代价不同？改用 Dijkstra。
  • 如何恢复具体路径？为每个状态记录父状态与本次方向。
  • 上界为何不能只取 2000？因为最短路线可能需要先越过目标再折返。

常见错误

  • visited 只按位置去重，错误合并了两个方向状态。
  • 后跳后仍标记为允许后跳。
  • 把“不能落在禁区”误解成“不能跨过禁区”。
  • 没有上界，导致向前状态无限增长。
  • 入队时不标记访问，造成重复状态大量堆积。

四语言完整代码

import java.util.*;

class Solution {
    public int minimumJumps(int[] forbidden, int a, int b, int x) {
        int maxForbidden = 0;
        Set<Integer> blocked = new HashSet<>();
        for (int position : forbidden) {
            blocked.add(position);
            maxForbidden = Math.max(maxForbidden, position);
        }

        int upper = Math.max(x, maxForbidden) + a + b;
        boolean[][] visited = new boolean[upper + 1][2];
        Deque<int[]> queue = new ArrayDeque<>();
        // state: position, canBack(1/0), jumps
        queue.offer(new int[]{0, 1, 0});
        visited[0][1] = true;

        while (!queue.isEmpty()) {
            int[] state = queue.poll();
            int position = state[0];
            int canBack = state[1];
            int jumps = state[2];
            if (position == x) return jumps;

            int forward = position + a;
            if (forward <= upper && !blocked.contains(forward)
                    && !visited[forward][1]) {
                visited[forward][1] = true;
                queue.offer(new int[]{forward, 1, jumps + 1});
            }

            int backward = position - b;
            if (canBack == 1 && backward >= 0
                    && !blocked.contains(backward)
                    && !visited[backward][0]) {
                visited[backward][0] = true;
                queue.offer(new int[]{backward, 0, jumps + 1});
            }
        }
        return -1;
    }
}

 * @param {number[]} forbidden
 * @param {number} a
 * @param {number} b
 * @param {number} x
 * @return {number}

var minimumJumps = function (forbidden, a, b, x) {
    const blocked = new Set(forbidden);
    const maxForbidden = Math.max(...forbidden);
    const upper = Math.max(x, maxForbidden) + a + b;
    const visited = Array.from(
        { length: upper + 1 },
        () => [false, false]
    );
    // state: [position, canBack(1/0), jumps]
    const queue = [[0, 1, 0]];
    let head = 0;
    visited[0][1] = true;

    while (head < queue.length) {
        const [position, canBack, jumps] = queue[head++];
        if (position === x) return jumps;

        const forward = position + a;
        if (forward <= upper && !blocked.has(forward)
                && !visited[forward][1]) {
            visited[forward][1] = true;
            queue.push([forward, 1, jumps + 1]);
        }

        const backward = position - b;
        if (canBack === 1 && backward >= 0
                && !blocked.has(backward)
                && !visited[backward][0]) {
            visited[backward][0] = true;
            queue.push([backward, 0, jumps + 1]);
        }
    }
    return -1;
};
from collections import deque
from typing import List


class Solution:
    def minimumJumps(
        self,
        forbidden: List[int],
        a: int,
        b: int,
        x: int
    ) -> int:
        blocked = set(forbidden)
        upper = max(x, max(forbidden)) + a + b
        # state: (position, can_back, jumps)
        queue = deque([(0, True, 0)])
        visited = {(0, True)}

        while queue:
            position, can_back, jumps = queue.popleft()
            if position == x:
                return jumps

            forward = position + a
            forward_state = (forward, True)
            if (forward <= upper
                    and forward not in blocked
                    and forward_state not in visited):
                visited.add(forward_state)
                queue.append((forward, True, jumps + 1))

            backward = position - b
            backward_state = (backward, False)
            if (can_back
                    and backward >= 0
                    and backward not in blocked
                    and backward_state not in visited):
                visited.add(backward_state)
                queue.append((backward, False, jumps + 1))

        return -1

class Solution {

    int minimumJumps(vector<int>& forbidden, int a, int b, int x) {
        unordered_set<int> blocked(forbidden.begin(), forbidden.end());
        int maxForbidden = *max_element(forbidden.begin(), forbidden.end());
        int upper = max(x, maxForbidden) + a + b;
        vector<array<bool, 2>> visited(upper + 1, {false, false});
        // state: position, canBack(1/0), jumps
        queue<tuple<int, int, int>> states;
        states.emplace(0, 1, 0);
        visited[0][1] = true;

            auto [position, canBack, jumps] = states.front();
            states.pop();

                    && !visited[forward][1]) {
                visited[forward][1] = true;

                    && !blocked.count(backward)
                    && !visited[backward][0]) {
                visited[backward][0] = true;
                states.emplace(backward, 0, jumps + 1);
            }
        }

  • 状态 = 位置 + 后跳许可
  • 前跳恢复许可
  • 后跳消耗许可
