交替数列的最大元素

不用构造长度可达 109 的数列。观察峰谷的最小回退量，把过程压缩成一个只含 n、s、m 的公式。

Medium · 数学贪心

题意

从 seq[0] = s 出发，构造长度为 n 的严格交替数列；任意相邻两项的差绝对值不超过 m。返回任意有效数列中能够出现的最大元素。

示例

n = 4, s = 3, m = 5，可取 [3, 8, 7, 12]，答案为 12。

约束

1 ≤ n, s ≤ 10⁹，1 ≤ m ≤ 10⁵；最终答案需用 64 位整数保存。

题解：让每次下坡只下降 1

n = 1：s；否则：s + k × m − (k − 1)，其中 k = ⌊n / 2⌋
1

第一次冲高。选择 s < s + m，立即获得第一个峰值 s + m。

2

回退最少。严格下降至少要减 1，因此从峰到谷只能尽量走 −1；再上升 +m，每多一个峰净增加 m − 1。

3

峰的数量。从下标 1 开始，每隔两项出现一个峰，共 k = ⌊n / 2⌋ 个。若 n = 1，唯一元素就是 s。

复杂度与边界

时间 O(1)，额外空间 O(1)。使用 64 位整数；n = 1 不应套入有峰值的通式。

替代思路与常见错误

模拟会在 n 很大时超时，也容易误以为每次可以净增 m；严格交替迫使每个相邻“下坡”至少少 1。不要把 ⌊n/2⌋ 写成 ⌈n/2⌉。

面试追问

若允许非严格交替，回退可以为 0，净增会变成 m；若元素不是整数，严格下降可无限接近 0，题目的整数条件正是公式中 “−1” 的来源。
