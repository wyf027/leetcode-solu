题目

一排共有 n 个座位，编号从 0 到 n - 1。每位新同学都选择一个座位，使其到最近已入座同学的距离最大；若有多个最优位置，选择编号最小的。空考场第一次入座固定选择 0。

ExamRoom(int n)：用座位总数初始化。
int seat()：安排新同学入座并返回座位编号。
void leave(int p)：座位 p 上的同学离开；调用时保证该座位有人。

官方示例

输入
["ExamRoom", "seat", "seat", "seat", "seat", "leave", "seat"]
[[10], [], [], [], [], [4], []]
输出
[null, 0, 9, 4, 2, null, 5]
解释
ExamRoom examRoom = new ExamRoom(10);
examRoom.seat(); // 0
examRoom.seat(); // 9
examRoom.seat(); // 4
examRoom.seat(); // 2
examRoom.leave(4);
examRoom.seat(); // 5

约束

  • 1 ≤ n ≤ 10⁹
  • leave(p) 调用时，p 上保证有人。
  • seat 与 leave 合计最多调用 10⁴ 次。

题解：扫描有序已占座位

只要按从小到大维护已占座位，就能一次扫描比较左端、相邻座位中点与右端三个候选来源。

核心洞察

设已占位置为 s₀ < s₁ < …。左端候选 0 到最近人的距离是 s₀；中间区间 (a,b) 的最优座位是 a + floor((b-a)/2)，最近距离为 floor((b-a)/2)；右端候选 n-1 的距离是 n-1-s_last。

从左到右扫描，并且只在新距离严格更大时更新答案，自然保留距离相同时的较小编号。

完整过程

  1. 若无人入座，加入并返回 0。
  2. 先把左端 0 作为候选，最佳距离初始化为首个已占座位编号。
  3. 依次枚举相邻已占座位，计算中点和它到任一端的距离；严格更优才替换。
  4. 最后比较右端 n-1，同样仅严格更优时替换。
  5. 将最终座位加入有序集合；离开时直接删除 p。

正确性

引理 1：左端空段中，越靠近 0 离首位同学越远，所以 0 最优；右端同理，n-1 最优。

引理 2：相邻已占座位 a,b 之间，座位 x 的最近距离为 min(x-a,b-x)，在两项尽量相等的中点达到最大；向下取整得到较小的最优编号。

定理：任一空座位必属于左端、某个相邻区间或右端。算法取每类局部最优并比较全部候选，因此得到全局最大最近距离；严格更新保留同距离下最小编号。

边界与复杂度

  • 空考场必须直接返回 0。
  • n = 1 时唯一座位可在离开后再次使用。
  • 奇数长度间隔有两个等价中点时，整数除法选择左边。
  • 右端距离相等时不能覆盖更小的旧答案。

时间：seat() 为 O(k)，其中 k 是当前人数；leave() 在有序树实现中 O(log k)，数组实现为 O(k)。
空间：O(k)。调用次数最多 10⁴，此方案清晰且足够。

完整代码

JavaTreeSet
import java.util.TreeSet;

class ExamRoom {
    private final int n;
    private final TreeSet<Integer> occupied = new TreeSet<>();

    public ExamRoom(int n) { this.n = n; }

    public int seat() {
        if (occupied.isEmpty()) {
            occupied.add(0);
            return 0;
        }
        int seat = 0;
        int best = occupied.first();
        int previous = -1;
        for (int current : occupied) {
            if (previous != -1) {
                int distance = (current - previous) / 2;
                if (distance > best) {
                    best = distance;
                    seat = previous + distance;
                }
            }
            previous = current;
        }
        int rightDistance = n - 1 - occupied.last();
        if (rightDistance > best) seat = n - 1;
        occupied.add(seat);
        return seat;
    }

    public void leave(int p) { occupied.remove(p); }
}
JavaScriptsorted array
var ExamRoom = function(n) {
    this.n = n;
    this.occupied = [];
};

ExamRoom.prototype.seat = function() {
    const seats = this.occupied;
    if (seats.length === 0) {
        seats.push(0);
        return 0;
    }
    let answer = 0;
    let best = seats[0];
    for (let i = 1; i < seats.length; i++) {
        const distance = Math.floor((seats[i] - seats[i - 1]) / 2);
        if (distance > best) {
            best = distance;
            answer = seats[i - 1] + distance;
        }
    }
    const rightDistance = this.n - 1 - seats[seats.length - 1];
    if (rightDistance > best) answer = this.n - 1;

    let i = 0;
    while (i < seats.length && seats[i] < answer) i++;
    seats.splice(i, 0, answer);
    return answer;
};

ExamRoom.prototype.leave = function(p) {
    const i = this.occupied.indexOf(p);
    this.occupied.splice(i, 1);
};
Pythonbisect
from bisect import insort

class ExamRoom:
    def __init__(self, n: int):
        self.n = n
        self.occupied = []

    def seat(self) -> int:
        if not self.occupied:
            self.occupied.append(0)
            return 0

        answer = 0
        best = self.occupied[0]
        for left, right in zip(self.occupied, self.occupied[1:]):
            distance = (right - left) // 2
            if distance > best:
                best = distance
                answer = left + distance

        right_distance = self.n - 1 - self.occupied[-1]
        if right_distance > best:
            answer = self.n - 1

        insort(self.occupied, answer)
        return answer

    def leave(self, p: int) -> None:
        self.occupied.remove(p)

#include <set>
using namespace std;

class ExamRoom {
    int n;
    set<int> occupied;
public:
    ExamRoom(int n) : n(n) {}

    int seat() {
        if (occupied.empty()) {
            occupied.insert(0);
            return 0;
        }
        int answer = 0;
        int best = *occupied.begin();
        int previous = -1;
        for (int current : occupied) {
            if (previous != -1) {
                int distance = (current - previous) / 2;
                if (distance > best) {
                    best = distance;
                    answer = previous + distance;
                }
            }
            previous = current;
        }
        int rightDistance = n - 1 - *occupied.rbegin();
        if (rightDistance > best) answer = n - 1;
        occupied.insert(answer);
        return answer;
    }

    void leave(int p) { occupied.erase(p); }
};

替代方案

可把空区间放进优先队列，按“可提供的距离降序、候选座位升序”排序；入座拆成两个区间，离开合并相邻区间。配合端点映射与懒删除，可让操作接近 O(log k)，但实现和不变量明显更复杂。

本题调用上限为 10⁴，面试中先写稳健的有序扫描往往更划算，再根据追问升级。

常见错误

  • 把两端空段也除以 2。
  • 用 >= 更新，破坏“编号最小”规则。
  • 空集合时仍读取首元素。
  • 数组插入后没有维持升序。
  • 优先队列方案中离开后未正确合并，或旧区间未做懒删除。

面试追问

如果调用次数扩大到 10⁶，怎样优化？

维护空区间最大堆，并用左右端点映射支持合并；堆内旧区间采用版本标记或有效性映射懒删除。

优先队列的比较键是什么？

先比较该区间能提供的最近距离（越大越优），再比较实际入座编号（越小越优）。边界区间与内部区间的距离公式不同。

怎样证明平局规则没有遗漏？

每个区间内部先选最小的局部最优编号；全局扫描又只在距离严格增大时更新，因此同距离的更早、更小候选被保留。
