01 / Problem

题目说明

下面是题意的准确转述；数组下标从 0 开始。

给定长度为 n 的整数数组 nums。你可以执行任意次操作，但同一个下标最多只能被选择一次：

选择下标 i，再选择一个严格小于 nums[i] 的质数 p，令 nums[i] = nums[i] - p。

如果能使最终数组严格递增，返回 true；否则返回 false。严格递增意味着每个元素都严格大于它前面的元素。

示例 1
输入：nums = [4,9,6,10]
输出：true

可依次在下标 0、1 减去 3、7，得到 [1,2,6,10]。

示例 2
输入：nums = [6,8,11,12]
输出：true

原数组已经严格递增，可以不执行操作。

示例 3
输入：nums = [5,8,3]
输出：false

不存在一种合法操作组合能让它严格递增。

约束

  • 1 <= nums.length <= 1000
  • 1 <= nums[i] <= 1000
  • nums.length == n

贪心：把当前值压到合法范围内的最小值

从左到右确定答案。当前位置越小，越容易给后面的元素留出严格递增的空间。

核心洞察

假设前一个确定值为 prev，当前原值为 x。若减去质数 p，必须满足：

x - p > prev　⇔　p < x - prev

因此应选择严格小于 x - prev 的最大质数。它让 x - p 尽可能小，同时仍然合法；若不存在这样的质数，就不减。若最终当前值不大于 prev，立即失败。

完整过程

  1. 用埃氏筛找出 [0, max(nums)] 内的所有质数。
  2. 预处理 best[v]：严格小于 v 的最大质数，不存在则为 0。
  3. 令 prev = 0，从左向右处理每个 x。
  4. 若 x <= prev，已经不可能变大，返回 false。
  5. 令 x -= best[x - prev]。若结果仍不大于 prev，返回 false；否则更新 prev。
  6. 全部位置处理成功后返回 true。

正确性证明

引理：在前驱值 prev 固定时，算法产生的是当前位置所有合法选择中的最小结果。因为合法质数都满足 p < x - prev，算法选其中最大的 p，所以 x - p 最小；不减等价于 p = 0。

归纳：处理第一个位置后，算法得到所有可行方案中最小的首值。假设算法在位置 i - 1 得到的前驱值不大于任意可行方案的对应值，那么它给位置 i 的合法空间至少一样大；再由引理，算法会取得该位置可行的最小值。因此，只要存在可行方案，算法不会更早失败。若算法失败，则任何其他方案的前驱只会更大，也无法使当前位置严格更大，故确实无解。

结论：算法返回 true 当且仅当能够通过合法操作把数组变为严格递增。

边界情况

  • 单元素数组天然严格递增。
  • x - prev <= 1 时没有可减的合法质数；只能检查原值是否已经大于前驱。
  • 质数必须严格小于原值，且每个下标最多操作一次；本算法每个位置恰好做零次或一次选择。
  • 重复值不一定失败，例如 [5,5] 可把第一个 5 减去 3，得到 [2,5]。

复杂度

设 M = max(nums)。筛质数需要 O(M log log M) 时间；构造查询表和扫描数组需要 O(M + n) 时间。空间复杂度为 O(M)。

替代方案

可以只保存质数列表，并对每个位置二分查找严格小于 x - prev 的最大质数，复杂度为 O(M log log M + n log π(M))。也可从右向左，为每个过大的元素寻找一个能让它小于后继的最小质数；实现边界更绕。

面试追问

  • 如果 nums[i] 上限变为 10^9，不能整段筛表时如何找前一个质数？
  • 为什么“选择最大可减质数”不会破坏后面的可行性？
  • 如果同一位置允许操作多次，问题会发生什么变化？
  • 如果允许减去任意合数，最优策略是否还能更简单？

常见错误

  • 把条件写成 p <= x - prev，会使新值等于前驱，不再严格递增。
  • 总是减去小质数；这样当前值偏大，会无谓压缩后续空间。
  • 先判断原数组相邻项，而没有使用已修改后的 prev。
  • 筛表范围不足，或误把 0、1 当成质数。

class Solution {
    public boolean primeSubOperation(int[] nums) {
        int max = 0;
        for (int x : nums) max = Math.max(max, x);

        boolean[] prime = new boolean[max + 1];
        java.util.Arrays.fill(prime, true);
        if (max >= 0) prime[0] = false;
        if (max >= 1) prime[1] = false;
        for (int p = 2; p * p <= max; p++) {
            if (prime[p]) {
                for (int multiple = p * p; multiple <= max; multiple += p) {
                    prime[multiple] = false;
                }
            }
        }

        int[] best = new int[max + 1];
        int lastPrime = 0;
        for (int value = 0; value <= max; value++) {
            best[value] = lastPrime;
            if (prime[value]) lastPrime = value;
        }

        int prev = 0;
        for (int i = 0; i < nums.length; i++) {
            int gap = nums[i] - prev;
            if (gap <= 0) return false;
            nums[i] -= best[gap];
            prev = nums[i];
        }
        return true;
    }
}

from typing import List


class Solution:
    def primeSubOperation(self, nums: List[int]) -> bool:
        maximum = max(nums)
        prime = [True] * (maximum + 1)
        prime[0] = False
        if maximum >= 1:
            prime[1] = False

        p = 2
        while p * p <= maximum:
            if prime[p]:
                for multiple in range(p * p, maximum + 1, p):
                    prime[multiple] = False
            p += 1

        best = [0] * (maximum + 1)
        last_prime = 0
        for value in range(maximum + 1):
            best[value] = last_prime
            if prime[value]:
                last_prime = value

        prev = 0
        for i, value in enumerate(nums):
            gap = value - prev
            if gap <= 0:
                return False
            nums[i] = value - best[gap]
            prev = nums[i]
        return True
