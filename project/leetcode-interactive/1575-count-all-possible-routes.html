Count All Possible Routes统计所有可行路径

城市散落在一条数轴上。油箱有限，但路线允许绕行、折返，甚至反复抵达终点——你的任务是数清所有合法路线。

题号 #1575函数 countRoutes答案模数 10⁹ + 7

Problem

题目说明

索引代表城市，数组值代表城市在数轴上的位置；位置互不相同。

任务

给定正整数数组 locations，其中 locations[i] 是城市 i 的位置。你从 start 出发，初始拥有 fuel 单位汽油，要统计最终停在 finish 的所有可能路线数量。

从城市 i 移动到不同的城市 j，消耗 |locations[i] - locations[j]| 单位汽油。任何时刻剩余汽油都不能为负；允许重复访问任意城市，包括起点与终点。答案对 1,000,000,007 取模。

约束

  • 2 ≤ locations.length ≤ 100
  • 1 ≤ locations[i] ≤ 10⁹
  • locations 中所有整数互不相同
  • 0 ≤ start, finish < locations.length
  • 1 ≤ fuel ≤ 200

Solution

记忆化搜索：城市与余油定义唯一状态

每次移动至少消耗 1 单位汽油，因此状态转移始终朝更少的余油前进。

核心洞察

到达终点并不意味着路线必须立刻结束：当前所在城市是终点时，“现在停止”贡献 1 条路线，同时仍可继续去别处并再次回来。因此每个状态要先计入这个停止选项，再累加所有可负担移动的后续路线。

dfs(i, f) = [i = finish] + Σ dfs(j, f − |loc[i] − loc[j]|)

求和只包含 j ≠ i 且移动成本不超过 f 的城市。

完整过程

  1. 定义 dfs(i, f)：当前位于城市 i、还剩 f 汽油时，最终以终点收尾的路线数。
  2. 若 i == finish，先把答案设为 1，代表不再移动；否则从 0 开始。
  3. 枚举每个不同城市 j，计算距离。距离不超过余油时，加上对应后继状态。
  4. 每次累加后取模，并缓存 (i, f)；最终返回 dfs(start, fuel)。

正确性证明

  1. 状态完备：后续能做的选择只由当前城市和剩余汽油决定，之前经过哪些城市不会限制未来，因为允许重复访问。
  2. 分类互斥：从状态 (i,f) 出发的合法路线，要么在 i=finish 时立即停止，要么第一步唯一地前往某个可达的 j。不同第一步对应的路线集合互不重叠。
  3. 转移穷尽：算法枚举全部 j≠i，恰好覆盖所有合法第一步，并递归统计每个后继状态的全部路线。
  4. 必然终止：位置互异使每步成本严格为正，余油严格减少，不可能形成递归环。

结论：由余油从小到大的归纳，每个缓存值都准确，故起始状态的返回值即所求。

边界与复杂度

  • 起点等于终点：空移动路线应计数 1，还可能存在离开后返回的路线。
  • 无法直达：如果所有边成本都大于余油，该状态只可能贡献“已在终点时停止”的 1。
  • 大坐标：只计算差值；32 位有符号整数足够容纳单次距离，但答案必须持续取模。
  • 重复到访：不能使用 visited 数组去重路线。
时间O(n² · fuel)至多 n(fuel+1) 个状态，每个枚举 n 个城市
空间O(n · fuel)缓存与递归栈

替代方案与面试追问

可以自底向上做吗？

可以。按剩余汽油从 0 到 fuel 递增，计算每个城市的状态。所有转移读取的余油严格更少，天然满足拓扑顺序；复杂度不变，且避免递归栈。

为什么“到达终点”后仍继续搜索？

题目允许重复访问任意城市。一条路线只要求最终停在终点，不要求第一次到达就结束，所以每次处于终点都同时拥有“停止”和“继续移动”两类选择。

如果 locations 允许重复会怎样？

两座不同城市之间可能出现 0 成本边，状态的余油不再严格下降，并形成零成本循环；路线数甚至可能无限。当前算法依赖“位置互异”这一约束保证有限与无环。

常见错误

在终点直接返回 1、使用 visited 禁止重复到访、忘记缓存余油维度、把坐标顺序误当作城市索引顺序、最后才取模导致溢出，都是典型失误。

Implementation

import java.util.Arrays;

class Solution {
    private static final int MOD = 1_000_000_007;
    private int[] locations;
    private int finish;
    private int[][] memo;

    public int countRoutes(int[] locations, int start, int finish, int fuel) {
        this.locations = locations;
        this.finish = finish;
        this.memo = new int[locations.length][fuel + 1];
        for (int[] row : memo) {
            Arrays.fill(row, -1);
        }
        return dfs(start, fuel);
    }

    private int dfs(int city, int fuelLeft) {
        if (memo[city][fuelLeft] != -1) {
            return memo[city][fuelLeft];
        }

        long routes = city == finish ? 1 : 0;
        for (int next = 0; next < locations.length; next++) {
            if (next == city) continue;
            int cost = Math.abs(locations[city] - locations[next]);
            if (cost <= fuelLeft) {
                routes += dfs(next, fuelLeft - cost);
                routes %= MOD;
            }
        }
        memo[city][fuelLeft] = (int) routes;
        return memo[city][fuelLeft];
    }
}

 * @param {number[]} locations
 * @param {number} start
 * @param {number} finish
 * @param {number} fuel
 * @return {number}

var countRoutes = function(locations, start, finish, fuel) {
    const MOD = 1_000_000_007;
    const memo = Array.from(
        { length: locations.length },
        () => new Int32Array(fuel + 1).fill(-1)
    );

    const dfs = (city, fuelLeft) => {
        if (memo[city][fuelLeft] !== -1) {
            return memo[city][fuelLeft];
        }

        let routes = city === finish ? 1 : 0;
        for (let next = 0; next < locations.length; next++) {
            if (next === city) continue;
            const cost = Math.abs(locations[city] - locations[next]);
            if (cost <= fuelLeft) {
                routes = (routes + dfs(next, fuelLeft - cost)) % MOD;
            }
        }
        memo[city][fuelLeft] = routes;
        return routes;
    };

    return dfs(start, fuel);
};
from functools import cache
from typing import List


class Solution:

        self,

        finish: int,
        fuel: int,

        mod = 1_000_000_007

        @cache
        def dfs(city: int, fuel_left: int) -> int:
            routes = int(city == finish)

            for next_city in range(len(locations)):
                if next_city == city:
                    continue
                cost = abs(locations[city] - locations[next_city])
                if cost <= fuel_left:

                    routes %= mod

            return routes

        return dfs(start, fuel)
class Solution {
    static constexpr int MOD = 1'000'000'007;
    vector<int>* locations;
    int finish;
    vector<vector<int>> memo;

    int dfs(int city, int fuelLeft) {
        int& cached = memo[city][fuelLeft];
        if (cached != -1) return cached;

        long long routes = city == finish ? 1 : 0;
        for (int next = 0; next < static_cast<int>(locations->size()); next++) {
            if (next == city) continue;
            int cost = abs((*locations)[city] - (*locations)[next]);
            if (cost <= fuelLeft) {
                routes += dfs(next, fuelLeft - cost);
                routes %= MOD;
            }
        }
        return cached = static_cast<int>(routes);
    }

public:
    int countRoutes(vector<int>& locations, int start, int finish, int fuel) {
        this->locations = &locations;
        this->finish = finish;
        memo.assign(locations.size(), vector<int>(fuel + 1, -1));
        return dfs(start, fuel);
    }
};
