CORE ROUTE

真正要模拟的是“行号”

  1. 1

    准备 numRows 个行缓冲区，当前行 row=0，方向 step=+1。

  2. 2

  3. 3

STOP 02 · ALGORITHM

完整解题过程

  1. A

    先做早退：numRows == 1 或 numRows ≥ s.length 时，轨迹不会改变读取顺序，直接返回 s。

  2. B

    创建 numRows 个缓冲区，初始化 row=0, step=1。

  3. C

    字符先追加到当前行；若 row==0 就令 step=1，若 row==numRows−1 就令 step=−1。

  4. D

    执行 row += step。遍历结束后依次拼接每行，即可还原逐行读取顺序。

DIRECTION TRACE

方向状态只有两种

row: 0 → 1 → 2 → 1 → 0 → 1 ...

step: +1 +1 −1 −1 +1 ...

cycle length = 2 × rows − 2

周期公式适合推导直接索引法；模拟法无需计算列坐标，代码更短、更稳定。

SAFETY CHECK

边界情况

ONE ROW

numRows = 1

必须直接返回，否则上下折返逻辑会让行号越界。

TOO MANY

行数 ≥ 字符数

每行至多一个字符，逐行读取仍是原串，可直接早退。

TWO ROWS

只有两行

行号在 0、1 间切换，中间行不存在，模拟仍自然成立。

PUNCTUATION

逗号与句点

字符内容不影响行走轨迹，按普通字符入队即可。

TIME

O(n)

每个字符入队一次，再被拼接一次。

SPACE

O(n)

行缓冲区总共保存 n 个字符。

ALTERNATIVE

周期直接索引

可按 cycle=2r−2 逐行取字符，辅助空间更少；中间行有两套步长，面试更容易出错。主推模拟。

class Solution {
    public String convert(String s, int numRows) {
        if (numRows == 1 || numRows >= s.length()) return s;

        StringBuilder[] rows = new StringBuilder[numRows];
        for (int i = 0; i < numRows; i++) rows[i] = new StringBuilder();

        int row = 0, step = 1;
        for (char ch : s.toCharArray()) {
            rows[row].append(ch);
            if (row == 0) step = 1;
            else if (row == numRows - 1) step = -1;
            row += step;
        }

        StringBuilder answer = new StringBuilder();
        for (StringBuilder buffer : rows) answer.append(buffer);
        return answer.toString();
    }
}
var convert = function (s, numRows) {
  if (numRows === 1 || numRows >= s.length) return s;

  const rows = Array.from({ length: numRows }, () => []);
  let row = 0;
  let step = 1;

  for (const char of s) {
    rows[row].push(char);
    if (row === 0) step = 1;
    else if (row === numRows - 1) step = -1;
    row += step;
  }
  return rows.flat().join("");
};

public:
    string convert(string s, int numRows) {
        if (numRows == 1 || numRows >= s.size()) return s;

        vector<string> rows(numRows);
        int row = 0, step = 1;

        for (char ch : s) {
            rows[row].push_back(ch);
            if (row == 0) step = 1;

            row += step;
        }

        string answer;
        answer.reserve(s.size());

面试高频追问

为什么不构造二维矩阵？

题目只需要逐行结果。保存列坐标和空格会增加实现与空间负担，行缓冲区已经保留所有必要顺序。

周期为什么是 2r−2？

从顶部走到底部需要 r−1 步，再从底部回到顶部需要 r−1 步，一个完整往返共 2r−2。

能做到 O(1) 额外空间吗？

忽略输出存储时，周期直接索引法可逐行追加到答案；但大多数语言仍需 O(n) 的结果容器。

常见错误告警

  • ❌ 漏掉 numRows==1：底部也是顶部，方向更新后行号会跑到不存在的第 1 行。
  • ❌ 先移动再放字符：首字符会被错误放到第 1 行。
  • ❌ 每步都反向：只在 row==0 或 row==numRows−1 时翻转。
  • ❌ 把题意理解成旋转字符串：Z 字形只是摆放路径，输出固定为逐行读取。
  • ❌ 字符串反复相加：JS/Python 用数组收集再 join，避免大量中间字符串。

60-SECOND RECAP

“我不构造二维画布，只维护 numRows 个行缓冲区。当前行从 0 开始，方向初始向下；每放入一个字符，在第 0 行把方向设为 +1，在最后一行设为 −1，然后移动行号。最后按行拼接。numRows 为 1 或不小于字符串长度时直接返回。时间 O(n)，空间 O(n)。”
