1110. 删点成林

Delete Nodes And Return Forest — 移除指定节点，让断开的孩子成为新树根。先观察森林如何生长，再展开完整题解。

MEDIUM树深度优先搜索哈希表非付费题

题目

给定二叉树根节点 root，其中所有节点值互不相同。删除值出现在 to_delete 中的全部节点后，剩余节点组成若干棵互不相交的树。返回这些树的根节点，顺序任意。

函数形式

delNodes(root: TreeNode, to_delete: integer[]) → List<TreeNode>
示例 1
输入：root = [1,2,3,4,5,6,7], to_delete = [3,5] 输出：[[1,2,null,4],[6],[7]]
示例 2
输入：root = [1,2,4,null,3], to_delete = [3] 输出：[[1,2,4]]

约束

  • 树中节点数最多为 1000。
  • 节点值互不相同，范围为 1 到 1000。
  • to_delete.length ≤ 1000。
  • to_delete 中的值互不相同，范围为 1 到 1000。

完整题解：后序 DFS + 新根标记

核心洞察

一个保留节点成为森林根，当且仅当它原本是根，或它的父节点被删除。DFS 携带 isRoot，并在后序阶段返回“删除后应接回父节点的子树根”。

完整过程

  1. 将 to_delete 放进哈希集合。
  2. 从 dfs(root, true) 开始。
  3. 判断当前节点是否删除；若会删除，它的孩子都成为候选新根。
  4. 递归处理左右子树，并用返回值改写左右指针。
  5. 候选新根且未删除时加入答案；删除节点返回空，保留节点返回自身。

正确性

连接正确：归纳来看，每次 DFS 返回的都是当前子树完成全部删除后的有效根；删除当前节点返回空，保留时返回已更新孩子指针的自身。

根集合正确：所有森林根恰为未删除的原根或“父节点被删”的未删除孩子，isRoot 精确覆盖这两类且不会加入其他节点。因此答案完整、无误且无重复。

边界情况

  • 空树返回空数组。
  • 删除原根时，未删除孩子成为新根。
  • 删除叶子只断开对应指针。
  • 连续删除父子时，只有最先保留的后代成为根。
  • 全部删除时返回空森林。

复杂度

每个节点访问一次，时间 O(n)。集合与答案占 O(n)，递归栈最坏 O(n)，平衡树为 O(log n)。

替代方案

可先记录父指针再逐个删除，但需额外维护根集合与断边顺序。后序 DFS 用返回值统一表达断边，更直接。

面试追问

  • 节点值若不唯一，需要按节点身份或重新定义删除条件。
  • 可用显式栈模拟后序遍历，避免递归栈限制。
  • 前序直接加入孩子可能误加同样待删除的孩子，因此仍需后续校正。

常见错误

  • 删除父节点后忘记收集保留孩子。
  • 未把递归返回值重新赋给左右指针。
  • 误将被删除的原根加入答案。
  • 用数组反复查询删除值，复杂度退化为 O(nm)。

class Solution {
    private Set<Integer> deleted;
    private List<TreeNode> forest;
    public List<TreeNode> delNodes(TreeNode root, int[] to_delete) {
        deleted = new HashSet<>();
        for (int x : to_delete) deleted.add(x);
        forest = new ArrayList<>();
        dfs(root, true);
        return forest;
    }
    private TreeNode dfs(TreeNode node, boolean isRoot) {
        if (node == null) return null;
        boolean remove = deleted.contains(node.val);
        if (isRoot && !remove) forest.add(node);
        node.left = dfs(node.left, remove);
        node.right = dfs(node.right, remove);
        return remove ? null : node;
    }
}
var delNodes = function(root, to_delete) {
    const deleted = new Set(to_delete), forest = [];
    function dfs(node, isRoot) {
        if (node === null) return null;
        const remove = deleted.has(node.val);
        if (isRoot && !remove) forest.push(node);
        node.left = dfs(node.left, remove);
        node.right = dfs(node.right, remove);
        return remove ? null : node;
    }
    dfs(root, true);
    return forest;
};
class Solution:
    def delNodes(self, root: Optional[TreeNode],
                 to_delete: List[int]) -> List[TreeNode]:
        deleted, forest = set(to_delete), []
        def dfs(node, is_root):
            if node is None:
                return None
            remove = node.val in deleted
            if is_root and not remove:
                forest.append(node)
            node.left = dfs(node.left, remove)
            node.right = dfs(node.right, remove)
            return None if remove else node
        dfs(root, True)
        return forest
class Solution {
    unordered_set<int> deleted;
    vector<TreeNode*> forest;
    TreeNode* dfs(TreeNode* node, bool isRoot) {
        if (!node) return nullptr;
        bool remove = deleted.count(node->val);
        if (isRoot && !remove) forest.push_back(node);
        node->left = dfs(node->left, remove);
        node->right = dfs(node->right, remove);
        return remove ? nullptr : node;
    }
public:
    vector<TreeNode*> delNodes(TreeNode* root, vector<int>& to_delete) {
        deleted.insert(to_delete.begin(), to_delete.end());
        dfs(root, true);
        return forest;
    }
};
