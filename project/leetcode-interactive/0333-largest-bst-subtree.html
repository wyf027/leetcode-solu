Largest BST Subtree

最大二叉
搜索子树

在一棵可能并不有序的二叉树里，寻找节点数最多、且整体满足严格二叉搜索树规则的子树。

函数签名

largestBSTSubtree(root: TreeNode): integer

输入二叉树根节点
输出最大节点数
Problem

题意

给定二叉树的根节点 root，返回其中最大二叉搜索子树所包含的节点数。“子树”必须选定某个节点，并包含该节点向下的全部后代。

一个严格二叉搜索树要求：每个节点左子树中的所有值都小于该节点值，右子树中的所有值都大于该节点值，左右子树也分别满足同样规则。因此重复值不能放入同一棵合法 BST。

约束

  • 树中节点数在 [0, 104] 范围内。
  • -104 ≤ Node.val ≤ 104。
  • 空树的答案为 0。
  • 比较是严格的小于与大于。

示例 1

输入：root = [10,5,15,1,8,null,7] 输出：3

以节点 5 为根的子树 [5,1,8] 是节点数最多的 BST。

示例 2

输入：root = [4,2,7,2,3,5,null,2,null,null,null,null,null,1]
输出：2

重复值会破坏严格 BST 条件；最大合法子树包含 2 个节点。

Solution

后序遍历：每棵子树只汇报一次

关键是让父节点用常数时间知道左右子树是否为 BST，以及它们的范围、大小和已有最优答案。

核心洞察

对每个节点返回五项信息：isBST、size、min、max、best。只有左右子树都是 BST，且满足 left.max < node.val < right.min，当前子树才是 BST。

当前合法大小 = left.size + right.size + 1

空树视为合法 BST：大小为 0，最小值为正无穷，最大值为负无穷。这样叶子节点能自然通过同一套比较。

完整过程

1
后序访问
先处理左子树，再处理右子树，最后处理当前节点。
2
读取摘要
从左右孩子获得合法性、范围、节点数与子树内最大答案。
3
合并或拒绝
范围严格匹配时合并为更大的 BST；否则标记当前子树非法。
4
向上传递最优值
合法时答案可取当前大小；非法时保留左右子树中较大的答案。

边界处理

  • 空树：直接得到 0。
  • 单节点：左右都是空树，因此答案为 1。
  • 重复值：严格不等式不成立，不能合并。
  • 极值：使用 long / long long / Infinity 作哨兵，避免和节点值冲突。
  • 退化链：递归深度可能达到 n。

复杂度

时间：O(n)，每个节点只计算一次。

空间：O(h) 递归栈；平衡树为 O(log n)，最坏退化树为 O(n)。

正确性证明

归纳命题：对任意节点 x，dfs(x) 返回的摘要准确描述以 x 为根的子树，并且 best 等于该子树内部最大 BST 的节点数。

基础情形：空节点返回合法、大小 0、空范围和答案 0，定义成立。

归纳步骤：假设左右孩子的摘要均准确。如果任一孩子不是 BST，或严格范围条件失败，则以 x 为根的整棵子树不可能是 BST；最大 BST 只能完全位于左右某一侧，取两侧 best 的最大值正确。反之，左右子树合法且范围条件成立，它们与 x 合并后满足 BST 定义；返回的大小、最小值和最大值显然准确，此时最大答案是当前整棵子树大小与两侧答案的最大值，而当前大小不会小于任一侧。故命题对 x 成立。

结论：由结构归纳，根节点返回的 best 即整棵输入树中的最大 BST 子树大小。

四语言完整代码

均采用相同的后序摘要模型。

class Solution {
    private static class Info {
        boolean isBST;
        int size;
        long min;
        long max;
        int best;

        Info(boolean isBST, int size, long min, long max, int best) {
            this.isBST = isBST;
            this.size = size;
            this.min = min;
            this.max = max;
            this.best = best;
        }
    }

    public int largestBSTSubtree(TreeNode root) {
        return dfs(root).best;
    }

    private Info dfs(TreeNode node) {
        if (node == null) {
            return new Info(true, 0, Long.MAX_VALUE, Long.MIN_VALUE, 0);
        }

        Info left = dfs(node.left);
        Info right = dfs(node.right);

        if (left.isBST && right.isBST
                && left.max < node.val && node.val < right.min) {
            int size = left.size + right.size + 1;
            long min = Math.min(left.min, (long) node.val);
            long max = Math.max(right.max, (long) node.val);
            return new Info(true, size, min, max, size);
        }

        return new Info(false, 0, 0, 0, Math.max(left.best, right.best));
    }
}

替代方案

对每个节点单独验证整棵子树并计数，思路直接，但会重复扫描；平衡情况下常被描述为 O(n log n)，退化树最坏达到 O(n²)。

面试追问

若要返回最大 BST 的根节点怎么办？摘要中再携带 bestRoot；若有并列，还需先约定按深度、数值或遍历顺序取舍。

常见错误

只比较父子节点而不维护整棵子树的最值；允许重复值；非法子树仍把自身 size 向上当作合法大小；哨兵与合法值域冲突。
