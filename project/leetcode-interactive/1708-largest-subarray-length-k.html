Largest Subarray Length K

长度为 K 的
最大子数组

在所有长度恰好为 k 的连续片段中，找到按字典序最大的那一个。先理解比较规则，再用交互演示观察候选窗口。

Problem

题目描述

给定一个由互不相同的整数组成的数组 nums，以及整数 k。请返回 nums 中长度恰好为 k 的字典序最大连续子数组。

比较两个等长数组时，从左到右寻找第一个不同的位置；该位置元素更大的数组，字典序更大。子数组必须连续。

示例 1
输入nums = [1,4,5,2,3], k = 3
输出[5,2,3]

长度为 3 的候选中，以 5 开头的片段字典序最大。

示例 2
输入nums = [1,4,5,2,3], k = 4
输出[4,5,2,3]

只有下标 0 和 1 能作为合法起点。

示例 3
输入nums = [1,4,5,2,3], k = 1
输出[5]

当 k = 1 时，每个单元素片段都是候选。

函数签名
largestSubarray(nums: integer[], k: integer): integer[]
约束
  • 1 ≤ k ≤ nums.length ≤ 105
  • 1 ≤ nums[i] ≤ 109
  • nums 中的整数互不相同

Solution

一次扫描最大合法首元素

核心洞察

长度为 k 的子数组起点只能落在 [0, n-k]。所有元素互不相同，因此任意两个候选子数组的第一个元素一定不同；字典序比较在第一个位置就会结束。于是，只需在合法起点范围内找到元素最大的下标 best，返回 nums[best..best+k-1]。

完整过程

  1. 令 best = 0。
  2. 从 i = 1 扫描到 n-k；若 nums[i] > nums[best]，更新 best = i。
  3. 复制并返回从 best 开始的连续 k 个元素。

正确性证明

引理：对于两个不同合法起点 i 与 j，对应子数组中字典序较大的一个，恰好是首元素较大的那个。

证明：因为 nums 元素互不相同，所以 nums[i] ≠ nums[j]。两个子数组在位置 0 已经不同，字典序只由 nums[i] 与 nums[j] 的大小决定。∎

定理：算法返回所有长度为 k 的子数组中字典序最大的子数组。

证明：扫描结束时，nums[best] 是全部合法起点元素的最大值。由引理，该起点对应的子数组胜过其他每个候选，因此返回结果正确。∎

复杂度

  • 时间：扫描 O(n-k+1)，复制答案 O(k)，合计 O(n)。
  • 额外空间：除返回数组外为 O(1)；返回值本身占 O(k)。

边界情况

  • k = 1：返回最大元素组成的单元素数组。
  • k = n：唯一候选就是原数组。
  • 最佳起点可能恰好为 n-k，循环上界必须包含它。

替代方案

可以枚举所有窗口并逐元素做字典序比较，但最坏可能需要 O((n-k+1)·k) 时间。也可以对合法起点排序后选最大值，却会增加到 O((n-k+1) log(n-k+1))，没有必要。本题的“元素互不相同”让一次线性扫描成为最直接的方案。

面试追问

  • 如果允许重复元素呢？首元素相同时必须继续比较后续元素；可讨论后缀数组、LCP、滚动哈希配合二分，或根据约束采用直接比较。
  • 能否不复制结果？如果接口允许返回视图，只需返回起点与长度；本题签名要求数组，所以通常需要构造结果。
  • 如果 k 不固定且有多次查询？每个 k 的合法起点上界不同，可进一步研究前缀最大下标等预处理方式。

常见错误

  • 扫描整个数组找最大值；位于 n-k+1 之后的元素不能作为长度 k 子数组的起点。
  • 把“子数组”误写成可跳跃选择的“子序列”。
  • 循环写成 i < n-k，漏掉最后一个合法起点。
  • 忽略互不相同这一条件，写出不必要的完整窗口比较。

class Solution {
    public int[] largestSubarray(int[] nums, int k) {
        int best = 0;

        for (int i = 1; i <= nums.length - k; i++) {
            if (nums[i] > nums[best]) {
                best = i;
            }
        }

        int[] answer = new int[k];
        System.arraycopy(nums, best, answer, 0, k);
        return answer;
    }
}

var largestSubarray = function(nums, k) {
    let best = 0;

    for (let i = 1; i <= nums.length - k; i++) {
        if (nums[i] > nums[best]) {
            best = i;
        }
    }

    return nums.slice(best, best + k);
};
from typing import List


class Solution:
    def largestSubarray(self, nums: List[int], k: int) -> List[int]:
        best = 0

        for i in range(1, len(nums) - k + 1):
            if nums[i] > nums[best]:
                best = i

        return nums[best:best + k]
class Solution {
public:
    vector<int> largestSubarray(vector<int>& nums, int k) {
        int best = 0;

        for (int i = 1; i <= static_cast<int>(nums.size()) - k; ++i) {
            if (nums[i] > nums[best]) {
                best = i;
            }
        }

        return vector<int>(nums.begin() + best, nums.begin() + best + k);
    }
};
