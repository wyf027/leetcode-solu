过滤数组中的元素

给一个数组和一把“筛子”：逐项询问过滤函数，只把得到真值的原元素放进新数组。先动手观察，再决定是否展开题解。

EASYFilter Elements from Array非付费题数组 · 高阶函数
Problem

题目说明

目标函数签名为 filter(arr, fn)。不得调用 JavaScript 内置的 Array.filter。

给定整数数组 arr 与过滤函数 fn，返回新数组 filteredArr。对于每个下标 i，调用 fn(arr[i], i)；仅当返回值转换为布尔值后为真时，保留原来的 arr[i]。

参数形式

arr: number[]，fn: (n: number, i: number) => any，返回 number[]。

约束

  • 0 <= arr.length <= 1000
  • -109 <= arr[i] <= 109
示例 1 · 按数值判断
输入：arr = [0,10,20,30],
fn = function greaterThan10(n) { return n > 10; }
输出：[20,30]
解释：不大于 10 的元素被过滤。
示例 2 · 使用下标
输入：arr = [1,2,3],
fn = function firstIndex(n, i) { return i === 0; }
输出：[1]
解释：仅下标 0 使 fn 返回 true。
示例 3 · 真值转换
输入：arr = [-2,-1,0,1,2],
fn = function plusOne(n) { return n + 1; }
输出：[-2,0,1,2]
解释：当 n = -1 时返回 0，是假值。

Solution

准备好核对思路了吗？

题解默认收起。建议先口述一次：需要维护什么状态，每一步如何决定保留或跳过。

Walkthrough

一次遍历，显式收集

核心洞察

过滤不改变元素，只决定是否把原元素写入新数组；一个结果数组就足够。

完整过程

按下标遍历，调用 fn(arr[i], i)，让条件判断完成真值转换；为真就追加。

边界

空数组得到空数组；不要写入回调返回值；传给回调的下标必须来自原数组。

正确性说明

循环不变式：处理下标 i 前，结果数组恰好包含原数组区间 [0, i) 中使回调结果为真值的全部元素，且顺序不变。

当前回调为真值就追加 arr[i]，否则跳过；两种情况都把不变式扩展一个元素。循环结束时覆盖整个数组，所以结果正确。

复杂度：时间 O(n)；除返回数组外额外空间 O(1)，返回值最多占 O(n)。

四语言完整代码

JavaScript 是本题官方可提交版本。Java、Python、C++ 为本地语义参考：静态语言版本使用布尔谓词；Python 的真值规则与 JavaScript 不完全相同。

JavaScript官方可提交
/**
 * @param {number[]} arr
 * @param {Function} fn
 * @return {number[]}
 */
var filter = function(arr, fn) {
  const filteredArr = [];

  for (let i = 0; i < arr.length; i++) {
    if (fn(arr[i], i)) {
      filteredArr.push(arr[i]);
    }
  }

  return filteredArr;
};
Java本地语义参考
import java.util.ArrayList;
import java.util.List;
import java.util.function.BiPredicate;

public class Solution {
  public static List<Integer> filter(
      int[] arr,
      BiPredicate<Integer, Integer> fn
  ) {
    List<Integer> result = new ArrayList<>();
    for (int i = 0; i < arr.length; i++) {
      if (fn.test(arr[i], i)) result.add(arr[i]);
    }
    return result;
  }
}
Python本地语义参考
from collections.abc import Callable
from typing import Any


def filter_elements(
    arr: list[int],
    fn: Callable[[int, int], Any],
) -> list[int]:
    result: list[int] = []
    for i, value in enumerate(arr):
        if fn(value, i):
            result.append(value)
    return result
C++本地语义参考
#include <cstddef>
#include <functional>
#include <vector>

std::vector<int> filterElements(
    const std::vector<int>& arr,
    const std::function<bool(int, std::size_t)>& fn
) {
  std::vector<int> result;
  for (std::size_t i = 0; i < arr.size(); ++i) {
    if (fn(arr[i], i)) result.push_back(arr[i]);
  }
  return result;
}

替代方案与常见错误

  • arr.filter(fn) 最直接，但题目明确禁止。
  • reduce 也能完成，但比“判断后追加”更绕。
  • 漏传下标会破坏依赖 i 的回调。
  • 应追加原元素，而不是 fn 的返回值。
  • fn(...) === true 会错误排除数字、对象等真值。

面试追问

  • 能原地过滤吗？ 可用读写指针覆盖前缀，但会修改输入。
  • 异步回调呢？ 顺序版逐项 await；并发版先 Promise.all 求判定，再按原顺序收集。
  • 为何稳定？ 遍历和追加都按原下标递增。
