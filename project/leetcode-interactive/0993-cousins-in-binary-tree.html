LEETCODE 993 · EASY

二叉树的
堂兄弟节点

同一层，不同父亲——一次逐层搜索就能判定。

题目

给定一棵节点值互不相同的二叉树 root，以及树中两个不同节点的值 x、y。若对应节点深度相同但父节点不同，返回 true；否则返回 false。根节点深度为 0。

函数： isCousins(root: TreeNode, x: integer, y: integer): boolean

示例 1
输入：root = [1,2,3,4], x = 4, y = 3
输出：false
示例 2
输入：root = [1,2,3,null,4,null,5], x = 5, y = 4
输出：true
示例 3
输入：root = [1,2,3,null,4], x = 2, y = 3
输出：false

约束

  • 节点数在 [2, 100] 内。
  • 1 ≤ Node.val ≤ 100，所有节点值唯一。
  • x ≠ y，且 x、y 均存在于树中。

逐层侦察实验室

示例 2：观察 BFS 如何同时确认深度和父节点。

准备：队列中只有根节点 1。

先完成交互推演，再揭开完整思路。

核心洞察与过程

堂兄弟关系等价于：深度相同且父节点不同。BFS 天然按层访问；让队列中的每一项同时携带节点和父节点。

  1. 将 (root, null) 入队。
  2. 每轮固定处理当前队列长度，即完整的一层。
  3. 在本层记录 x、y 的父节点。
  4. 本层结束：同时找到则比较父节点；只找到一个则返回 false；都没找到则进入下一层。

正确性

BFS 每轮中的节点深度相同。算法仅在同一轮找到 x、y 且父节点不同才返回 true，所以结果必满足定义。反之，任意堂兄弟节点会在同一轮出现并记录不同父节点，算法必返回 true。

边界与复杂度

亲兄弟同层但父节点相同；一方先出现意味着深度不同；根节点不可能成为堂兄弟。时间 O(n)，空间 O(n)。

替代方案

DFS 也可记录两个目标的 (depth, parent)，时间 O(n)、递归栈 O(h)；BFS 与“同层”更直接对应。

四语言完整代码

class Solution {
    public boolean isCousins(TreeNode root, int x, int y) {
        Queue<TreeNode[]> q = new LinkedList<>();
        q.offer(new TreeNode[]{root, null});
        while (!q.isEmpty()) {
            TreeNode px = null, py = null;
            for (int size = q.size(); size > 0; size--) {
                TreeNode[] a = q.poll(); TreeNode n = a[0], p = a[1];
                if (n.val == x) px = p;
                if (n.val == y) py = p;
                if (n.left != null) q.offer(new TreeNode[]{n.left, n});
                if (n.right != null) q.offer(new TreeNode[]{n.right, n});
            }
            if (px != null || py != null) return px != null && py != null && px != py;
        }
        return false;
    }
}

面试追问与常见错误

追问

  • 为何一层只找到一个即可停止？另一目标若稍后出现，深度必不同。
  • 值不唯一怎么办？接口需传节点引用，不能用值定位。
  • 如何改成 DFS？递归携带深度与父节点并记录目标。

常见错误

  • 只比较深度，忘记排除亲兄弟。
  • 在处理层时动态读取队列长度，把下一层混入本层。
  • 只记录节点，不记录父节点。
