RLE 迭代器

RLE Iterator · 用游程计数直接跳过元素，而不是展开序列。

MEDIUM

题目

偶数长度数组 encoding 按 [次数, 值, 次数, 值, …] 表示一个非负整数序列。实现 RLEIterator：构造器接收编码；next(n) 从当前位置耗尽接下来的 n 个元素，返回第 n 个被耗尽的值。若不足 n 个，仍耗尽所有剩余元素并返回 -1。

接口

构造
RLEIterator(int[] encoding)
调用
int next(int n)
编码示例
[3,8,0,9,2,5] 表示 [8,8,8,5,5]；次数为 0 的游程没有元素。

官方示例（完整参数形式）

输入：
["RLEIterator","next","next","next","next"]
[[[3,8,0,9,2,5]],[2],[1],[1],[2]]

输出：
[null,8,8,5,-1]

过程：构造后依次 next(2)、next(1)、next(1)、next(2)。
前三次分别返回 8、8、5；最后只剩一个 5，不足两个，返回 -1。

约束

  • 2 ≤ encoding.length ≤ 1000，且长度为偶数。
  • 0 ≤ encoding[i] ≤ 10⁹。
  • 1 ≤ n ≤ 10⁹。
  • next 最多调用 1000 次。

题解

核心洞察

一次 next(n) 只关心第 n 个元素落在哪个游程。维护当前游程下标；若该游程剩余次数小于 n，就从 n 中减掉它并移向下一对；否则在当前次数上直接减 n，返回其值。整个过程无需展开最多极大的原序列。

完整过程

  1. 指针 i 指向当前次数位置（偶数下标）。
  2. 当 i 未越界且 n > encoding[i]，令 n -= encoding[i]，再令 i += 2。次数为 0 的游程会自然跳过。
  3. 若指针越界，说明总剩余量不足，返回 -1。
  4. 否则第 n 个元素就在当前游程：扣除 n 并返回 encoding[i+1]。

正确性

循环不变式：每次检查游程前，n 恰为从当前游程起仍需耗尽的元素数，之前的游程均已完全耗尽。若当前次数小于 n，跳过整段并扣除其长度，不变式继续成立；否则目标元素位于当前段，扣除 n 后返回该段值，正是最后耗尽的元素。若所有段都被跳过，则不存在第 n 个元素，返回 -1 正确。

边界

  • 零次数游程：不返回其值，直接跳过。
  • n 恰等于当前次数：扣至 0，仍返回当前值；下次调用再跳过。
  • 总剩余量不足：全部状态被耗尽并返回 -1。
  • 大计数：不展开数组；Java 用 long 保存本次剩余需求更稳妥。

复杂度

每个游程至多被跨过一次。单次调用最坏 O(k)；全部调用合计 O(m+q)，其中 m=encoding.length/2、q 为调用数。若原地修改编码，额外空间 O(1)；复制数组则为 O(m)。

替代方案

可维护“累计已消费数量”并在前缀和中查找目标位置；若所有调用可离线处理，也可建立前缀和后二分，单次 O(log m)。但在线且游程只前进时，双指针摊还更简单、空间更少。直接展开序列会因计数达 10⁹ 而不可行。

面试追问

  • 若要求迭代器不可修改输入，如何复制或单独保存当前剩余次数？
  • 若支持回退、随机访问或多个独立游标，前缀和结构如何设计？
  • 计数总和可能超过 32 位时，各语言如何避免溢出？

常见错误

  • 使用 n > count 与 n ≥ count 混淆，导致恰好耗尽时返回错误。
  • 不足 n 时没有把剩余游程全部耗尽。
  • 把 RLE 展开，造成时间或内存爆炸。
  • 忘记零次数游程或把次数位置和值位置弄反。

class RLEIterator {
    private final int[] encoding;
    private int i = 0;

    public RLEIterator(int[] encoding) {
        this.encoding = encoding;
    }

    public int next(int n) {
        long need = n;
        while (i < encoding.length && need > encoding[i]) {
            need -= encoding[i];
            i += 2;
        }
        if (i == encoding.length) return -1;
        encoding[i] -= (int) need;
        return encoding[i + 1];
    }
}

from typing import List

class RLEIterator:
    def __init__(self, encoding: List[int]):
        self.encoding = encoding
        self.i = 0

    def next(self, n: int) -> int:
        while self.i < len(self.encoding) and n > self.encoding[self.i]:
            n -= self.encoding[self.i]
            self.i += 2
        if self.i == len(self.encoding):
            return -1
        self.encoding[self.i] -= n
        return self.encoding[self.i + 1]
class RLEIterator {
    vector<int> encoding;
    int i = 0;
public:
    RLEIterator(vector<int>& encoding) : encoding(encoding) {}

    int next(int n) {
        long long need = n;
        while (i < encoding.size() && need > encoding[i]) {
            need -= encoding[i];
            i += 2;
        }
        if (i == encoding.size()) return -1;
        encoding[i] -= static_cast<int>(need);
        return encoding[i + 1];
    }
};
