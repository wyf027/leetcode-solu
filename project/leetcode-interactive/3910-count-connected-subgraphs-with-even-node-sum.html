3910. 统计节点和为偶数的连通子图

从所有非空节点集合里，找出“诱导子图连通”且节点值之和为偶数的集合。节点最多 13 个，直接把集合编码成二进制掩码，逐个验证恰好可行。

题意速览

输入nums[i] 只会是 0 或 1；edges 给出无向图。集合只保留集合内两端都在集合中的边，即诱导子图。目标统计非空集合，且诱导子图连通、节点和为偶数。

示例

nums = [1, 0, 1]
edges = [[0, 1], [1, 2]]

可计数集合：[1]（和为 0）与 [0, 1, 2]（和为 2），答案为 2。

掩码检查器

用样例的 3 个节点体验：每次选择一个集合，先看奇偶性，再从最低位节点 DFS，只沿集合内部的边走。

核心洞察：枚举集合，而非构造子图

把集合 S 写成 mask：第 i 位为 1 就选节点 i。先累加被选节点值；奇数和立即跳过。偶数和时，从 mask 的最低位节点开始 DFS/BFS，只访问仍在 mask 内的邻点。最终访问掩码是否等于 mask，就是诱导子图是否连通。

完整过程

  1. 建无向邻接表。
  2. 枚举 1 .. (1<<n)-1 的每个非空掩码。
  3. 计算选中节点之和；若为奇数，跳过。
  4. 从最低位节点 DFS，把集合内可达节点并入 visited。
  5. visited == mask 时计入答案。

边界

单节点且值为 0 要计数；孤立多点集合不连通；没有边也仍可能存在合法的单节点 0。

复杂度

O(2^n × (n + m)) 时间，O(n + m) 空间；n ≤ 13 时最多 8191 个集合。

替代方案

可以用并查集替换 DFS 判连通，但每个掩码都要重建并查集，不如用位掩码 DFS 直接。预先把邻居也压成 bitmask 可进一步降低常数。

面试追问

若 n 增大到 30，枚举不再适用；需利用图的树宽、树结构或 meet-in-the-middle 等额外结构。这里的关键是先从约束识别指数枚举是被允许的。

常见错误

  • 把原图连通误认为诱导子图连通。
  • DFS 时跨过不在集合里的中间节点。
  • 从节点 0 固定起搜，掩码不含 0 时会误判。
  • 漏掉非空限制或把奇数和计入。
