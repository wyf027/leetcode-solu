1841. 联赛信息统计

League Statistics / 从赛程记录到一张联赛积分榜

阅读规则，先预测榜单。实现思路和代码收在页面底部，按需展开。

题目任务

给定球队表 Teams 与比赛表 Matches，编写 SQL 汇总每支球队参加的主场和客场比赛：胜得 3 分，平得 1 分，负得 0 分。报告队名、场次、积分、进球、失球与净胜球；按积分降序、净胜球降序、队名字典序升序排列。

Teams

team_id INT PRIMARY KEY
team_name VARCHAR(20)

Matches

home_team_id INT
away_team_id INT
home_team_goals INT
away_team_goals INT
PRIMARY KEY (home_team_id, away_team_id)

Teams 每行是一支球队；Matches 每行是一场主客场比赛。两个 goals 字段分别表示主队、客队进球。公开题面未给出数据行数或进球数的数值上限，不虚构范围。联合主键区分比赛，主客场互换属于不同记录。

结果字段依次为 team_name, matches_played, points, goal_for, goal_against, goal_diff，其中净胜球等于进球减失球。

题解 · 把赛果变成球队视角

核心洞察与完整过程

一场比赛贡献两条球队记录。主队记录为（主队 ID、主队进球、客队进球），客队记录反转视角。用 UNION ALL 拼接，按球队 ID 分组，场次计数、积分与进失球求和，最后按三个排序键排列。

  1. 生成统一的 (team_id, gf, ga) 明细，比分方向始终站在该球队视角。
  2. 每条明细贡献一次出场；gf > ga 得 3，相等得 1，否则得 0。
  3. Teams 左连接明细，按 ID 和名称分组，保留零出场球队。
  4. 进球总和减失球总和得到净胜球；按积分、净胜球、名字排序。

正确性

每场记录恰好生成主客双方各一条明细，所以每次出场只计一次，且双方进球与失球方向正确。CASE 与胜平负定义一一对应，求和得到全部已进行比赛的积分。按球队 ID 分组不会混淆同名队，聚合字段即题目要求，最终 ORDER BY 实现全部排名规则。

边界与常见错误

  • 用 UNION 会删除重复的球队统计明细，造成少计场次；必须 UNION ALL。
  • 客队视角要交换进失球，否则客队胜负颠倒。
  • 只按 team_name 分组会合并同名队；应包含 team_id。
  • LEFT JOIN 下 COUNT(*) 会把未匹配的占位行当一场；用 COUNT(p.team_id)。NULL 比分不进入平局分支。
  • 净胜球为负也必须按数值降序；不要按字符串排序。

复杂度与替代方案

设 T 支队、M 场比赛。采用哈希连接和聚合时，典型时间 O(M + T log T)，聚合状态 O(T)；若物化展开明细则额外 O(M) 空间。SQL 的实际计划受索引与数据库优化器影响。也可先分别聚合主客场再合并，或用带 OR 条件的连接与 CASE；后者表达式重复、计划可能较差。

面试追问

多赛季怎么办？分组与连接都加入 season_id。增量更新怎么办？新比赛给双方各加一份统计，比分更正先撤销旧贡献。积分规则变化怎么办？修改得分表达式。要求名次怎么办？按业务决定使用 ROW_NUMBER、RANK 或 DENSE_RANK，并确定名字是否仅作展示排序。

MySQL 8+ · 官方数据库语言提交解答

WITH appearances AS (
  SELECT home_team_id AS team_id,
         home_team_goals AS gf, away_team_goals AS ga
  FROM Matches
  UNION ALL
  SELECT away_team_id, away_team_goals, home_team_goals
  FROM Matches
)
SELECT t.team_name,
       COUNT(p.team_id) AS matches_played,
       SUM(CASE WHEN p.gf > p.ga THEN 3
                WHEN p.gf = p.ga THEN 1 ELSE 0 END) AS points,
       COALESCE(SUM(p.gf), 0) AS goal_for,
       COALESCE(SUM(p.ga), 0) AS goal_against,
       COALESCE(SUM(p.gf - p.ga), 0) AS goal_diff
FROM Teams t
LEFT JOIN appearances p ON p.team_id = t.team_id
GROUP BY t.team_id, t.team_name
ORDER BY points DESC, goal_diff DESC, team_name ASC;

以下四份均为完整可调用函数或类，属于本地语义参考，不能作为本题 SQL 提交。输入 Teams 为 [ID, 名称] 行，Matches 为四整数行；输出为六字段行。假设输入符合表结构、球队引用有效；示例中的 ASCII 队名排序与 SQL 一致，非 ASCII 名称需对齐数据库排序规则。

JavaScript · 本地语义参考

function leagueStatistics(teams, matches) {
  const rows = new Map(teams.map(([id, name]) => [id, [name, 0, 0, 0, 0, 0]]));
  for (const [h, a, x, y] of matches) {
    for (const [id, gf, ga] of [[h, x, y], [a, y, x]]) {
      const r = rows.get(id);
      r[1]++; r[2] += gf > ga ? 3 : gf === ga ? 1 : 0;
      r[3] += gf; r[4] += ga; r[5] += gf - ga;
    }
  }
  return [...rows.values()].sort((a, b) =>
    b[2] - a[2] || b[5] - a[5] || (a[0] < b[0] ? -1 : a[0] > b[0] ? 1 : 0));
}

Python · 本地语义参考

def league_statistics(teams, matches):
    rows = {i: [name, 0, 0, 0, 0, 0] for i, name in teams}
    for h, a, x, y in matches:
        for i, gf, ga in ((h, x, y), (a, y, x)):
            r = rows[i]
            r[1] += 1
            r[2] += 3 if gf > ga else 1 if gf == ga else 0
            r[3] += gf
            r[4] += ga
            r[5] += gf - ga
    return sorted(rows.values(), key=lambda r: (-r[2], -r[5], r[0]))

Java · 本地语义参考

import java.util.*;
public class Solution {
  // teams: Object[]{Integer id, String name}; matches: int[4]
  public static List<Object[]> leagueStatistics(Object[][] teams, int[][] matches) {
    Map<Integer, long[]> stats = new HashMap<>();
    Map<Integer, String> names = new HashMap<>();
    for (Object[] t : teams) {
      int id = (Integer)t[0];
      stats.put(id, new long[5]); names.put(id, (String)t[1]);
    }
    for (int[] m : matches) {
      int[][] sides = {{m[0], m[2], m[3]}, {m[1], m[3], m[2]}};
      for (int[] s : sides) {
        long[] r = stats.get(s[0]);
        r[0]++; r[1] += s[1] > s[2] ? 3 : s[1] == s[2] ? 1 : 0;
        r[2] += s[1]; r[3] += s[2]; r[4] += (long)s[1] - s[2];
      }
    }
    List<Integer> ids = new ArrayList<>(stats.keySet());
    ids.sort((a, b) -> {
      int c = Long.compare(stats.get(b)[1], stats.get(a)[1]);
      if (c == 0) c = Long.compare(stats.get(b)[4], stats.get(a)[4]);
      return c != 0 ? c : names.get(a).compareTo(names.get(b));
    });
    List<Object[]> out = new ArrayList<>();
    for (int id : ids) {
      long[] r = stats.get(id);
      out.add(new Object[]{names.get(id), r[0], r[1], r[2], r[3], r[4]});
    }
    return out;
  }
}

C++17 · 本地语义参考

#include <algorithm>
#include <array>
#include <string>
#include <tuple>
#include <unordered_map>
#include <vector>
using namespace std;
using Row = tuple<string, long long, long long, long long, long long, long long>;
vector<Row> leagueStatistics(const vector<pair<int,string>>& teams,
                             const vector<array<int,4>>& matches) {
  unordered_map<int, array<long long,5>> stats;
  for (const auto& t : teams) stats[t.first] = {};
  for (const auto& m : matches) {
    array<array<int,3>,2> sides = {{{m[0],m[2],m[3]}, {m[1],m[3],m[2]}}};
    for (const auto& s : sides) {
      auto& r = stats.at(s[0]);
      ++r[0]; r[1] += s[1] > s[2] ? 3 : s[1] == s[2] ? 1 : 0;
      r[2] += s[1]; r[3] += s[2]; r[4] += (long long)s[1] - s[2];
    }
  }
  vector<Row> out;
  for (const auto& t : teams) {
    const auto& r = stats.at(t.first);
    out.emplace_back(t.second,r[0],r[1],r[2],r[3],r[4]);
  }
  sort(out.begin(),out.end(),[](const Row& a,const Row& b) {
    if (get<2>(a) != get<2>(b)) return get<2>(a) > get<2>(b);
    if (get<5>(a) != get<5>(b)) return get<5>(a) > get<5>(b);
    return get<0>(a) < get<0>(b);
  });
  return out;
}
