重新排列后的最大按位异或值

从最高位开始，把 t 中仍可用、能让 XOR 变成 1 的比特优先送到这里；高位的 1 永远比任何低位的改进更重要。

题意

给定两个等长二进制字符串 s 与 t。允许任意重排 t，但 s 不变。返回 s XOR rearranged(t) 能得到的、数值最大的长度为 n 的二进制字符串。

示例 1

s = "101"
t = "011"

输出 "110"。

示例 2

s = "0110"
t = "1110"

输出 "1101"。

约束

1 ≤ n ≤ 2 × 10⁵；两个串均只含 '0' 与 '1'。

题解区域

默认隐藏；先在上方按高位优先的规则手动配对。

核心洞察

数值比较由最高不同位决定。扫描每一位 i：若 s[i] = '0'，优先取 t 的一个 '1'；若 s[i] = '1'，优先取一个 '0'。这样该位 XOR 为 1。若理想 bit 用尽，只能取另一种，结果为 0。

完整过程与复杂度

  1. 统计 t 中 0 和 1 的剩余个数。
  2. 从左到右（最高位到最低位）贪心选择与 s[i] 相反的 bit。
  3. 把每一步的 XOR bit 追加到答案。

时间 O(n)，额外空间（不计答案）O(1)。排序或枚举所有重排会做很多无意义工作。

边界、替代方案、面试追问与常见错误

边界：单字符和全相同字符都能由同一计数逻辑覆盖。常见错误：从低位优先，或只最大化 t 的排列本身；目标是 XOR 的字典序（也就是数值）。替代方案：可先写成排序匹配，但二进制字母表只有两类，两个计数器已经足够。追问：若字母表扩大且按位得分不再是 XOR，可把“最优补位”表建成匹配/贪心选择。
