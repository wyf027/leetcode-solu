Problem

题目

maxSumOfThreeSubarrays(nums, k)

给定整数数组 nums 和整数 k，请选择三个长度均为 k、彼此不重叠的连续子数组，使其中所有元素的总和最大。

返回三个子数组的起始下标 [i, j, l]（下标从 0 开始）。若最大总和对应多组答案，返回字典序最小的一组。

示例 1

输入：nums = [1,2,1,2,6,7,5,1], k = 2
输出：[0,3,5]
解释：选择 [1,2]、[2,6]、[7,5]，
      起始下标为 [0,3,5]。
      [1,3,5] 总和相同，但字典序更大。

示例 2

输入：nums = [1,2,1,2,1,2,1,2,1], k = 2
输出：[0,2,4]

约束

  • 1 ≤ nums.length ≤ 2 × 10⁴
  • 1 ≤ nums[i] < 2¹⁶
  • 1 ≤ k ≤ floor(nums.length / 3)

Solution vault

完整题解

先完成自己的推导，再展开核对思路、证明与代码。

核心洞察

把子数组压缩成窗口和。
先得到 W[i]，问题就变成在 W 中选三个下标 a < b < c，并满足相邻下标至少相差 k。
固定中间窗口。
中间起点为 b 时，最好的左窗口来自 [0, b-k]，最好的右窗口来自 [b+k, m-1]。

完整过程

  1. 用长度为 k 的滑动窗口计算 W。若 m = n-k+1，则 W 有 m 项。
  2. 从左到右构造 L[i]：记录 W[0..i] 中最大窗口和的下标。相等时不更新，保留更小下标。
  3. 从右到左构造 R[i]：记录 W[i..m-1] 中最大窗口和的下标。相等时更新为 i，从而保留更小下标。
  4. 枚举中间起点 b = k .. m-k-1。令 a=L[b-k]、c=R[b+k]，计算三段总和。
  5. 只在总和严格变大时替换答案。因为 b 从小到大枚举，配合 L/R 的平局规则，首次出现的最优解就是字典序最小解。

正确性证明

  1. 左右选择最优。固定中间起点 b 后，任何合法左窗口的起点至多为 b-k；L[b-k] 正是该范围内和最大的窗口。类似地，R[b+k] 是右侧合法范围内和最大的窗口。
  2. 固定 b 的组合最优。三段互不重叠，且中间窗口已固定，所以分别替换左段或右段不会影响合法性。由第一步，(L[b-k], b, R[b+k]) 在所有以 b 为中间起点的组合中总和最大。
  3. 覆盖全局最优。任意合法三窗口方案都有某个中间起点 b，枚举会访问它；第二步构造出的候选不会比该方案差，因此枚举所得最大值就是全局最大值。
  4. 字典序最小。L 在平局时保留较小左下标，R 在平局时取较小右下标；中间 b 按升序访问，且全局平局不覆盖旧答案。因此最终答案在所有最大和方案中字典序最小。

边界与细节

  • n = 3k 时只有一组合法起点：[0,k,2k]。
  • 窗口和可能远大于单个元素；Java 用 int 仍安全，因为最大约为 2×10⁴×(2¹⁶-1)。
  • 右侧数组的比较必须使用 >=，这是平局时取得更小下标的关键。
  • 答案更新必须使用严格大于 >，不能在总和相等时覆盖。

复杂度

时间：O(n)。窗口和、L、R 和中间枚举各扫描一次。

空间：O(n)，用于 W、L、R。若只保留必要信息还可调整常数，但会牺牲直观性。

替代方案

  • 动态规划：定义前 i 个窗口中选 t 段的最大和，并额外记录路径。可推广到任意段数，但字典序处理和路径恢复更复杂，空间通常更大。
  • 三重枚举：直接枚举三个起点，概念简单，但最坏达到 O(n³)，无法应对 n=2×10⁴。
  • 枚举中间 + 两侧线性搜索：如果每个 b 都重新搜索左右，复杂度退化为 O(n²)；L/R 正是在预处理这些重复查询。

面试追问

  • 如果要选的不是 3 段，而是 p 段，如何改成通用 DP？
  • 如果允许每段长度不同，L/R 方案还能否直接使用？
  • 为什么构造 R 时相等要更新，而构造 L 时相等不更新？
  • 若 nums 允许负数，算法和正确性是否需要变化？

常见错误

  • 把窗口结束下标当成起始下标，造成整体偏移 k-1。
  • 左右合法边界写成 b-1 和 b+1，导致子数组重叠。
  • 只求最大和，不设计平局规则，示例 2 一类数据会返回非最小字典序。
  • 中间起点上界写错；必须保证右侧至少还有一个长度 k 的窗口。

四种语言完整代码

实现保持同一套窗口和 + 左右最优逻辑，均符合官方函数签名。

JavaO(n)
class Solution {
    public int[] maxSumOfThreeSubarrays(int[] nums, int k) {
        int n = nums.length;
        int m = n - k + 1;
        int[] window = new int[m];

        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += nums[i];
            if (i >= k) sum -= nums[i - k];
            if (i >= k - 1) window[i - k + 1] = sum;
        }

        int[] left = new int[m];
        int best = 0;
        for (int i = 0; i < m; i++) {
            if (window[i] > window[best]) best = i;
            left[i] = best;
        }

        int[] right = new int[m];
        best = m - 1;
        for (int i = m - 1; i >= 0; i--) {
            if (window[i] >= window[best]) best = i;
            right[i] = best;
        }

        int[] answer = new int[3];
        int bestTotal = -1;
        for (int middle = k; middle < m - k; middle++) {
            int first = left[middle - k];
            int third = right[middle + k];
            int total = window[first] + window[middle] + window[third];
            if (total > bestTotal) {
                bestTotal = total;
                answer[0] = first;
                answer[1] = middle;
                answer[2] = third;
            }
        }
        return answer;
    }
}

from typing import List


class Solution:
    def maxSumOfThreeSubarrays(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)
        m = n - k + 1
        window = [0] * m

        total = 0
        for i, value in enumerate(nums):
            total += value
            if i >= k:
                total -= nums[i - k]
            if i >= k - 1:
                window[i - k + 1] = total

        left = [0] * m
        best = 0
        for i in range(m):
            if window[i] > window[best]:
                best = i
            left[i] = best

        right = [0] * m
        best = m - 1
        for i in range(m - 1, -1, -1):
            if window[i] >= window[best]:
                best = i
            right[i] = best

        answer = []
        best_total = -1
        for middle in range(k, m - k):
            first = left[middle - k]
            third = right[middle + k]
            candidate = window[first] + window[middle] + window[third]
            if candidate > best_total:
                best_total = candidate
                answer = [first, middle, third]

        return answer

class Solution {
public:
    vector<int> maxSumOfThreeSubarrays(vector<int>& nums, int k) {
        int n = nums.size();
        int m = n - k + 1;
        vector<int> window(m);

        int sum = 0;
        for (int i = 0; i < n; ++i) {
            sum += nums[i];
            if (i >= k) sum -= nums[i - k];
            if (i >= k - 1) window[i - k + 1] = sum;
        }

        vector<int> left(m), right(m);
        int best = 0;
        for (int i = 0; i < m; ++i) {
            if (window[i] > window[best]) best = i;
            left[i] = best;
        }

        best = m - 1;
        for (int i = m - 1; i >= 0; --i) {
            if (window[i] >= window[best]) best = i;

            int first = left[middle - k];

};
