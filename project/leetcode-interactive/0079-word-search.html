01 · 题意

布面、针脚与规则

从二维字符网格 board 中判断是否能拼出字符串 word。

相邻字符必须来自水平或垂直相邻格；一条路径中，同一个网格位置最多使用一次。找到任意一条合法路径就返回 true，否则返回 false。

输入记号：示例和测试中的输入会完整保留参数名、等号和值。若字符串含空格，页面使用 ␠ 让空格可见；本题官方输入只含英文字母。

官方样例 1

board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]
word = "ABCCED"

输出：true

官方样例 2

board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]
word = "SEE"

输出：true

官方样例 3

board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]]
word = "ABCB"

输出：false

m = board.length n = board[i].length 1 ≤ m, n ≤ 6 1 ≤ word.length ≤ 15

04 · 核心洞察

路径是一根可撤回的线

01

逐起点试针

答案可能从任意格开始，因此枚举每个网格位置作为 DFS 起点。

02

先占用，再延伸

当前字母匹配后临时标记格子，再向四邻搜索下一个字符，杜绝路径内复用。

03

离开前还原

本分支失败也要恢复字符，让其他起点或分支仍能使用该格；这正是回溯。

完整过程

  1. 1

    遍历所有 board[r][c]，调用 dfs(r, c, 0)。

  2. 2

    越界或字符不等于 word[index]，当前分支立即失败。

  3. 3

    若已匹配最后一个字符，整条路径成立，立即返回 true。

  4. 4

    把当前格临时改为哨兵 #，依次搜索四个方向的下一个字符。

  5. 5

    无论成功失败都先恢复原字符，再把搜索结果交还上层。任一起点成功即可结束。

复杂度

时间
O(m · n · 3^(L−1))

起点最多 4 个方向，之后不能回头，常用紧界写法；写成 O(mn·4^L) 也是安全上界。

额外空间
O(L)

原地标记省去访问矩阵；递归栈深度不超过单词长度 L。

关键边界

  • · 单格网格与单字符单词可以直接命中。
  • · 字母相同不代表可复用同一坐标。
  • · 匹配区分大小写。
  • · 每次返回前必须恢复被覆盖的字符。
  • · 找到路径后应短路，避免继续搜索。

替代方案

访问矩阵

额外维护 visited[m][n] 更直观，也避免改写输入，但空间为 O(mn + L)。面试中若允许临时修改网格，原地标记更精炼。

面试追问

怎样更早剪枝？

先统计网格与单词字符频次；若需求超出供给，直接返回。还可以比较单词首尾字符在网格中的频次，从更稀有的一端开始搜索。

进阶变化

一次找很多词？

对每个词单独 DFS 会重复扫描。Word Search II 通常用 Trie 共享前缀，并在 DFS 中按前缀剪枝。

常见错误

先递归、后标记：会立刻走回当前格，非法复用位置。

提前返回不恢复：输入网格残留哨兵，污染其他起点。

把对角线当相邻：本题只允许上下左右四个方向。

终止条件错一位：当前格匹配后，若 index === L - 1 就已成功。

class Solution {
    private int rows;
    private int cols;

    public boolean exist(char[][] board, String word) {
        rows = board.length;
        cols = board[0].length;
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                if (dfs(board, word, r, c, 0)) return true;
            }
        }
        return false;
    }

    private boolean dfs(char[][] board, String word, int r, int c, int index) {
        if (r < 0 || r >= rows || c < 0 || c >= cols
                || board[r][c] != word.charAt(index)) {
            return false;
        }
        if (index == word.length() - 1) return true;

        char saved = board[r][c];
        board[r][c] = '#';
        boolean found = dfs(board, word, r + 1, c, index + 1)
                || dfs(board, word, r - 1, c, index + 1)
                || dfs(board, word, r, c + 1, index + 1)
                || dfs(board, word, r, c - 1, index + 1);
        board[r][c] = saved;
        return found;
    }
}

    const cols = board[0].length;

    function dfs(r, c, index) {
        if (
            r < 0 || r >= rows || c < 0 || c >= cols ||
            board[r][c] !== word[index]
        ) return false;
        if (index === word.length - 1) return true;

        const saved = board[r][c];
        board[r][c] = "#";
        const found = dfs(r + 1, c, index + 1)
            || dfs(r - 1, c, index + 1)
            || dfs(r, c + 1, index + 1)
            || dfs(r, c - 1, index + 1);
        board[r][c] = saved;
        return found;
    }

    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            if (dfs(r, c, 0)) return true;
        }
    }
    return false;
};
