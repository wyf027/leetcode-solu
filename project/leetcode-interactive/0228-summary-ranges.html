汇总区间

在严格递增数组中，把相邻整数合并成最短、恰好覆盖所有输入的区间列表。

题意

给定排序且不重复的整数数组 nums。区间 [a, b] 包含 a 到 b 的每一个整数。返回按升序排列的最短区间列表，每个输入元素恰好被覆盖一次，且区间不能包含数组中不存在的整数。

官方样例 1

nums = [0, 1, 2, 4, 5, 7]

输出：["0->2", "4->5", "7"]

官方样例 2

nums = [0, 2, 3, 4, 6, 8, 9]

输出：["0", "2->4", "6", "8->9"]

约束：0 ≤ nums.length ≤ 20，−2³¹ ≤ nums[i] ≤ 2³¹−1；数组已升序且元素唯一。

观察要点

  1. 1. 每轮记住一个区间起点 start。
  2. 2. 当下一个数不是当前数加 1 时，当前区间结束。
  3. 3. 单元素输出 "a"；多元素输出 "a->b"。

题解

默认隐藏，展开后查看算法、边界与四语言提交代码。

核心洞察：只在断点封口

起点 start 固定后，向右走到最后一个连续数字。遇到数组结尾或 nums[i + 1] ≠ nums[i] + 1 时，nums[i] 就是终点；把区间写入答案，并令下一个数字成为新的起点。

边界值需要避免溢出：不要在 32 位整数上直接计算 Integer.MAX_VALUE + 1。先检查是否到末尾，或提升到更宽的整数类型比较。

完整过程：样例 1

  1. 1. 从 0 开始，0、1、2 连续；在 2 处发现下一项为 4，输出 0->2。
  2. 2. 从 4 开始，4、5 连续；下一项 7 断开，输出 4->5。
  3. 3. 7 是末尾且单独成段，输出 7。

边界

空数组返回空列表；单元素只输出自身；负数同样可连续；最小和最大 32 位整数需避免加一溢出。

复杂度

每个元素只读取一次：时间 O(n)。除结果列表外，额外空间 O(1)。

替代方案与错误

可用双指针寻找每段末尾，本质相同。常见错误是遗漏最后一段，或把单值范围误写成 a->a。

面试追问

若输入不保证有序且唯一？先排序并去重会改变为 O(n log n)；若要求保留原始语义，需要先澄清“连续”的定义和是否允许重排。 

import java.util.*;

class Solution {
    public List<String> summaryRanges(int[] nums) {
        List<String> ans = new ArrayList<>();
        for (int i = 0; i < nums.length; ) {
            int start = nums[i];
            while (i + 1 < nums.length && (long) nums[i + 1] == (long) nums[i] + 1) i++;
            int end = nums[i++];
            ans.add(start == end ? String.valueOf(start) : start + "->" + end);
        }
        return ans;
    }
}
