最小化网格中的最大值

Minimize Maximum Value in a Grid

数值可以改变，同行与同列的大小关系需要保留。
你能把整个网格的最高值压到多低？

01 / 题目与接口

给定 m × n 矩阵 grid，所有元素都是互不相同的正整数。为每个位置重新填写一个正整数：任意两个位置只要同行或同列，原来较大的位置在新矩阵中仍必须严格较大。在满足这些关系的前提下，让新矩阵的最大元素尽可能小。

返回一个达到最小最大值的矩阵，存在多个最优矩阵时可返回任意一个。新矩阵不要求所有元素互不相同；不同行且不同列的位置没有直接比较要求，但仍可能受间接关系约束。

minScore(grid: integer[][]) → integer[][]

官方示例 1

输入：grid = [[3,1],[2,5]]
输出：[[2,1],[1,2]]

两行、两列中的大小关系均保留。最大元素为 2；全部填 1 会破坏严格关系，所以最大值不能再小。

官方示例 2

输入：grid = [[10]]
输出：[[1]]

只有一个位置，最小正整数 1 就是最优选择。

约束

  • m == grid.length，n == grid[i].length
  • 1 ≤ m, n ≤ 1000
  • 1 ≤ m × n ≤ 105
  • 1 ≤ grid[i][j] ≤ 109
  • grid 中的整数两两不同。

04 / 深入题解

按需展开 · 含交互与四语言实现

核心洞察：只比已有约束多一层

先按原值从小到大处理位置。轮到 (r,c) 时，同行同列里比它小的元素已经全部赋值，比它大的元素尚未赋值。它只需要比所有这些已赋值元素大。

rowMax[r]：第 r 行已经写入的新值最大值
colMax[c]：第 c 列已经写入的新值最大值
新值 = max(rowMax[r], colMax[c]) + 1

两组最大值从 0 开始，保证第一个可用值为 1。算出新值后，同时更新对应的行、列最大值。不同位置可以复用同一个新值：例如官方示例中的原值 1 和 2，都可以变成 1。

完整过程

  1. 把每个元素记录为 [原值, 行号, 列号]，保留坐标。
  2. 按原值升序排序，建立处理顺序。
  3. 初始化行最大值、列最大值与结果矩阵为 0。
  4. 依次根据上式填写结果，并更新行列状态。
  5. 全部完成后返回结果矩阵。

交互 / 行列水位交汇

每步填一个位置：浅青标出当前行和列，深青标出本步格子，底部青线表示已经赋值。观察行、列水位如何共同决定下一层。

为什么正确？

1. 可行性：每个严格关系都被满足

取任意同行或同列的两个元素 a < b。a 先处理，处理 b 时，该行或列的最大值至少是 a 的新值。给 b 的新值比这个最大值大 1，因此新值也满足 a < b。所有新值至少为 1，所以所有要求成立。

2. 最优性：每一格都达到不可避免的下界

按处理顺序归纳。对于最小元素，任何可行解的新值至少为 1，算法恰好填 1。假设此前每个位置的算法值都不大于任意可行解在相同位置的值。当前位置在任何可行解中，都必须严格大于同行同列的所有较小原值位置，因此至少为这些前驱值的最大值加 1，也至少为算法算出的值。

归纳完成后，算法在每一个位置都不比任何可行解更大。因此算法结果的最大值也不大于任何可行解的最大值，达到全局最优。最优最大值是唯一数值，达到它的矩阵可以不唯一。

图的视角

从同行或同列的较小原值向较大原值连有向边，得到无环图。原值升序就是一种拓扑序，新值是“以当前点结束的最长路径的节点数”。行列最大值把大量前驱边压缩成了两个状态，不必显式建图。

复杂度

令 N = m × n。排序耗时 O(N log N)，扫描耗时 O(N)，总时间 O(N log N)。元素记录与结果各占 O(N)，行列数组占 O(m+n)，总空间 O(N)；排除输出后辅助空间仍为 O(N)。

边界

  • 单元素结果为 1；单行或单列退化成顺序排名。
  • 最大新值最多为 N；转弯链可能长于 m 或 n。
  • 原值最大 10⁹，但新值仅依赖大小顺序。
  • 本题无重复原值，无需同值分组。

替代方案

每行、每列分别排序，只连接相邻元素，得到 O(N) 条边，再用拓扑排序求最长路径；时间仍可达 O(N log N)，但要维护邻接表和入度。最小堆逐个取原值最小元素也可替代全量排序，通常没有优势。把所有数直接映射成全局排名虽然合法，却可能让最大值不必要地达到 N。

常见错误

  • 只按行处理：行内合法不代表列内合法。
  • 把新值设为两个水位的最小值，或忘记加 1：会违反另一方向的严格关系。
  • 以行列坐标顺序处理：较小原值的依赖可能尚未完成。
  • 只更新行或列之一：之后的格子会读取过期状态。
  • 覆盖原值后再据此排序：排序记录必须保留原始大小顺序。
  • JavaScript 用默认字符串排序，或用 fill 共享二维数组行：分别用数值比较器与独立建行。

面试追问

如果允许原值重复？
需先明确相等元素是否必须同秩。如果只要求严格大小关系，同值应分批计算、批末更新水位；如果同行同列相等还要求相同新值，就需要对同值连通组统一赋值，可用并查集。不能直接沿用当前逐个更新逻辑。
如何恢复决定最大值的那条链？
维护每行、每列最大值所来自的位置；更新当前点时记录较大水位的来源为父指针，再从全局最高点回溯。
能原地写入 grid 吗？
可以，前提是排序列表已经完整保存原值和坐标；这样减少一份结果矩阵，但排序记录仍使辅助空间为 O(N)。

Java

import java.util.Arrays;

class Solution {
    public int[][] minScore(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] cells = new int[m * n][3];
        int k = 0;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                cells[k++] = new int[]{grid[r][c], r, c};
            }
        }
        Arrays.sort(cells, (a, b) -> Integer.compare(a[0], b[0]));
        int[] rowMax = new int[m], colMax = new int[n];
        int[][] answer = new int[m][n];
        for (int[] cell : cells) {
            int r = cell[1], c = cell[2];
            int value = Math.max(rowMax[r], colMax[c]) + 1;
            answer[r][c] = value;
            rowMax[r] = colMax[c] = value;
        }
        return answer;
    }
}

from typing import List

class Solution:
    def minScore(self, grid: List[List[int]]) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        cells = sorted(
            (grid[r][c], r, c)
            for r in range(m)
            for c in range(n)
        )
        row_max = [0] * m
        col_max = [0] * n
        answer = [[0] * n for _ in range(m)]
        for _, r, c in cells:
            value = max(row_max[r], col_max[c]) + 1
            answer[r][c] = value
            row_max[r] = col_max[c] = value
        return answer
