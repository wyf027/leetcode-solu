魔塔游戏

初始血量为 1，依次访问房间时血量必须始终为正。每次只能把一个怪物房间移到末尾，求最少调整次数；即使调整也无法通关则返回 -1。

反悔贪心最小堆前缀血量

题意与示例

nums[i] > 0 表示补血，nums[i] < 0 表示怪物伤害，0 无影响。原计划按编号访问；一次调整只能把一个负数房间放到整个访问顺序末尾。

示例 1

nums = [100,100,100,-250,-60,-140,-50,-50,100,150]

输出：1

将 -250 对应房间延后即可。

示例 2

nums = [-200,-300,400,0]

输出：-1

所有变化总和为负，最终血量不可能保持正数。

约束：1 ≤ nums.length ≤ 10⁵，-10⁵ ≤ nums[i] ≤ 10⁵。累计血量必须使用 64 位整数。

用 [4,-5,3,-2] 展示血量跌至 0 时，延后过去最危险的怪物。

题解：前缀失血时延后最负房间

可行性先判定

移动只改变顺序，不改变总和。如果 1 + sum(nums) ≤ 0，访问完所有房间后的血量不为正，任何调整都无解，直接返回 -1。

反悔贪心

从左到右累加血量，并把遇到的负数加入最小堆。若血量 ≤ 0，就把堆中最小的数（绝对伤害最大）移到末尾，相当于当前血量减去这个负数；这样一次调整获得最多回血，为后续保留最大余量。

正确性与复杂度

发生危机时至少要延后一个已经出现的怪物；选择最负者让修复后的血量最大，不会比延后其他怪物更差。每个负数入堆一次、最多出堆一次，时间 O(n log n)，空间 O(n)。

常见错误与追问

  • 堆里存绝对值却使用了错误的堆方向。
  • 先判断血量再把当前怪物入堆，漏掉当前房间。
  • 仅检查总和，不处理前缀血量。
  • 用 32 位累计值导致溢出。
