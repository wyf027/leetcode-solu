统计星号

Count Asterisks

有些星号藏在竖线之间。先读清配对规则，再试着找出应该留下的星号。

官方题目 ↗进入交互实验 ↓单文件 · 离线可用

01 / 题目

给定字符串 s，按出现顺序把第 1、2 条竖线 | 配成一对，第 3、4 条配成一对，以此类推。返回位于这些竖线对外部的星号 * 数量。

这里的“连续竖线”指竖线的出现次序；两条竖线不必在字符串中相邻。每条竖线恰好属于一对。

参数与约束

  • countAsterisks(s: string) → integer
  • 1 ≤ s.length ≤ 1000。
  • 只含小写英文字母、| 和 *。
  • 竖线的数量一定为偶数，也可以是 0。

官方示例

输入：s = "l|*e*et|c**o|*de|"
输出：2

外部片段是 l 和 c**o，共 2 个星号。

输入：s = "iamprogrammer"
输出：0

字符串没有星号。

输入：s = "yo|uar|e**|b|e***au|tifu|l"
输出：5

外部片段为 yo、e**、e***au、l，共 5 个星号。

04 / 题解笔记

想好自己的方法后，再打开对照。

核心洞察：一个开关足够

扫描到奇数条竖线后处于区间内部，扫描到偶数条后处于外部。无需保存区间端点：用布尔值 inside 表示是否在一对竖线之间，每遇到 | 就翻转。

完整过程

  1. 初始化 inside = false、answer = 0。
  2. 从左向右访问每个字符；如果是竖线，翻转 inside。
  3. 否则，只有当前字符是星号且 inside == false 时，才把答案加 1。
  4. 扫描结束后返回答案。

示例 1：先读 l；首条竖线进入内部，忽略 *e*et；第二条竖线回到外部，在 c**o 中加 2；第三条竖线再次进入内部，忽略 *de；最后一条回到外部，返回 2。

正确性

循环不变式：处理任意长度的前缀后，inside 等于此前竖线数量是否为奇数，answer 等于该前缀中处于竖线对外部的星号数。

空前缀含 0 条竖线、0 个有效星号，不变式成立。遇竖线时翻转状态，正好反映奇偶性变化，计数不变；遇外部星号时增加 1；遇内部星号或字母时保持计数。因此每一步都保持不变式。处理整个字符串后，计数就是所求答案。

边界与复杂度

  • 没有竖线：全部星号均计入；没有星号：返回 0。
  • || 表示空的排除区间；首尾都是竖线也无需特殊处理。
  • 不合法的奇数条竖线不属于官方输入；实验输入会拒绝这种情况。
  • 时间 O(n)：每个字符访问一次；额外空间 O(1)：仅状态和计数。交互页面为回放存储的快照不属于提交算法。

替代方案

按 | 分割，统计下标为 0、2、4… 的片段中的星号。逻辑直观，时间仍为 O(n)，但通常需要 O(n) 额外空间来保存分割结果。也可维护竖线计数并取模 2，与布尔开关等价。

Java

class Solution {
    public int countAsterisks(String s) {
        boolean inside = false;
        int answer = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '|') inside = !inside;
            else if (c == '*' && !inside) answer++;
        }
        return answer;
    }
}

class Solution {

    int countAsterisks(string s) {

常见错误

  • 把相邻字符 || 才当作一对；实际按竖线出现次序配对。
  • 把第一条与最后一条竖线之间全排除，错误地漏掉中间外部片段。
  • 只统计星号总数，忘记先判断所在区间。
  • 用栈处理配对，保存了本题并不需要的端点。

面试追问

  • 输入来自字符流怎么办？保留开关与计数，跨数据块继续处理。
  • 竖线可能被转义怎么办？增加转义状态，先识别真正的分隔符。
  • 如果改为可嵌套的括号区间？用深度计数替代布尔值；深度为 0 时计入。
  • 需要返回有效星号的位置？外部遇星号时记录下标，额外空间变为 O(k)，k 为有效星号数。
