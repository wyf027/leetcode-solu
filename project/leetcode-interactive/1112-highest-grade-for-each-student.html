每位学生的最高成绩

Highest Grade For Each Student

先自己想一想：如果同一位学生的最高分出现在多门课程中，如何稳定地只留下课程编号最小的一门？

题目

给定表 Enrollments(student_id, course_id, grade)，每行表示一名学生在一门课程中的成绩。请为每位学生返回最高成绩对应的记录；若最高分并列，只保留其中 course_id 最小的课程。结果按 student_id 升序排列。

表结构与约束

  • student_id、course_id、grade 均为整数。
  • 一行唯一描述某位学生的一门课程成绩；同一学生可以有多行。
  • 输入至少包含一条选课记录，且每位出现在表中的学生都应恰好输出一行。
  • 排序与并列规则属于输出契约：先最大成绩，再最小课程编号。

官方示例（完整参数形式）

Enrollments = [
  [2, 2, 95], [2, 3, 95],
  [1, 1, 90], [1, 2, 99],
  [3, 1, 80], [3, 2, 75], [3, 3, 82]
]

输出：
student_id | course_id | grade
1          | 2         | 99
2          | 2         | 95
3          | 3         | 82

题解

核心洞察

把“每位学生最优的一行”转成组内排名：成绩越高越优；成绩相同时课程编号越小越优。窗口函数 ROW_NUMBER() 可以直接表达这个全序关系。

完整过程

  1. 按 student_id 分区。
  2. 分区内按 grade DESC, course_id ASC 排序并编号。
  3. 筛选编号为 1 的记录。
  4. 按 student_id 升序输出。

正确性说明

对任意学生，其分区内所有记录按“高分优先、同分小课程优先”形成确定顺序。第一条必然拥有该学生的最高分；若最高分有多条，它又必然拥有最小课程编号。因此筛选排名 1 对每位学生返回且仅返回正确记录。对所有分区同时成立，所以整体结果正确。

边界情况

  • 学生只有一门课：该行直接入选。
  • 最高分并列：由 course_id ASC 决胜。
  • 不同学生拥有相同分数或课程号：分区隔离，互不影响。

复杂度

设记录数为 n。排序窗口通常需要 O(n log n) 时间；排名中间结果需要 O(n) 空间（具体执行计划可能因数据库索引而异）。

官方可提交语言：SQL（MySQL 8+）

SELECT student_id, course_id, grade
FROM (
    SELECT student_id, course_id, grade,
           ROW_NUMBER() OVER (
               PARTITION BY student_id
               ORDER BY grade DESC, course_id ASC
           ) AS rn
    FROM Enrollments
) ranked
WHERE rn = 1
ORDER BY student_id;

import java.util.*;

class Solution {
    public int[][] highestGrade(int[][] rows) {
        Map<Integer, int[]> best = new TreeMap<>();
        for (int[] r : rows) {
            int[] old = best.get(r[0]);
            if (old == null || r[2] > old[2] ||
                (r[2] == old[2] && r[1] < old[1])) {
                best.put(r[0], r.clone());
            }
        }
        return best.values().toArray(new int[0][]);
    }
}

        (row[2] === old[2] && row[1] < old[1])) {
      best.set(row[0], [...row]);

  }

替代方案

可先求每位学生最高分，再连接原表，并对并列课程取最小编号；也可用相关子查询排除“比当前行更优”的记录。窗口函数通常最直观。

常见错误

  • 只取 MAX(grade)，却无法确定对应课程。
  • 漏写并列时的 course_id ASC。
  • 使用 RANK() 后筛选 1，导致并列时返回多行。
  • 忘记最终按学生编号排序。
