Problem

题目描述

给定一个整数数组 arr，按照每个整数的二进制表示中数字 1 的个数升序排列。

当两个或多个整数含有相同数量的 1 时，再按照整数本身的数值升序排列。返回排序后的数组。

排序优先级：第一关键字是二进制中 1 的个数，第二关键字是数值本身。

函数签名

sortByBits(arr: integer[]) → integer[]

约束

1 ≤ arr.length ≤ 500
0 ≤ arr[i] ≤ 10⁴

Full Solution

把排序规则写成一个二元键

核心洞察

每个数字都对应一个排序键 (popcount(x), x)。先比较二进制中 1 的数量；数量相同时，比较数字本身。把题意直接翻译成这个二元键，就能交给通用排序完成。

完整过程

  1. 为每个整数计算二进制中 1 的个数。
  2. 按 1 的个数升序比较。
  3. 若计数相同，按整数值升序比较。
  4. 返回排序后的数组。

Brian Kernighan 计数

表达式 x & (x - 1) 会消除 x 最低位的一个 1。不断执行直到 x 变为 0，循环次数恰好等于 1 的个数。

复杂度

设数组长度为 n，每个数最多含 b 个二进制位。计数总成本为 O(nb)，排序为 O(n log n)，合计 O(nb + n log n)。若排序就地进行，辅助空间通常取决于语言排序实现。

正确性证明

1

计数正确：每次执行 x & (x - 1) 都只删除最低位的一个 1，因此执行次数等于原数二进制中 1 的总数。

2

第一关键字正确：比较器在两个计数不同时返回计数差，所以 1 较少的数字必定位于 1 较多的数字之前。

3

第二关键字正确：计数相等时返回数值差，所以同组数字按数值升序排列。

4

结论：任意两个元素都遵守题目规定的优先级，因此整个排序结果满足要求。

边界情况

  • 0：二进制中没有 1，必然位于最前面的计数组。
  • 重复值：排序键完全相同，保留多少个就返回多少个。
  • 全部同权：退化为普通数值升序。
  • 单个元素：无需交换，直接返回。

替代方案

  • 使用语言内置 bitCount / bit_count，表达最简洁。
  • 把 count * 10001 + value 作为单一键；依赖题目上界，可读性较弱。
  • 预计算 0 到 10000 的计数表，适合多次重复调用。

常见错误

  • 只按 1 的个数排序，漏掉数值次序。
  • 把二进制字符串中的字符相加时忘记类型转换。
  • 比较器只返回布尔值，破坏排序契约。
  • JavaScript 对原数组排序却误以为会返回新数组。

面试追问

  • 如果数据范围极大，如何避免重复计算 popcount？
  • 能否利用分桶把排序改造成“按权重分组”？
  • 有符号负数应按固定位宽还是数学意义解释？
  • 排序是否必须稳定？本题为何不依赖稳定性？

import java.util.Arrays;

class Solution {
    public int[] sortByBits(int[] arr) {
        Integer[] values = Arrays.stream(arr).boxed().toArray(Integer[]::new);

        Arrays.sort(values, (a, b) -> {
            int countA = Integer.bitCount(a);
            int countB = Integer.bitCount(b);
            return countA != countB
                ? Integer.compare(countA, countB)
                : Integer.compare(a, b);
        });

        for (int i = 0; i < arr.length; i++) {
            arr[i] = values[i];
        }
        return arr;
    }
}

var sortByBits = function(arr) {
    const popcount = (value) => {
        let count = 0;
        while (value !== 0) {
            value &= value - 1;
            count++;
        }
        return count;
    };

    return arr.sort((a, b) => {
        const difference = popcount(a) - popcount(b);
        return difference !== 0 ? difference : a - b;
    });
};
