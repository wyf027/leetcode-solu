执行 K 次操作后的最大分数

Maximal Score After Applying K Operations

一次选择，一次得分，一次缩小。如何安排恰好 K 次机会？

01 / 题目

官方题目 ↗

给定下标从 0 开始的整数数组 nums 和整数 k，初始分数为 0。每次选择一个合法下标 i，先把当前的 nums[i] 加到分数中，再将这个位置改成 ceil(nums[i] / 3)。同一个位置可以重复选择。

求恰好执行 k 次后能得到的最大总分。ceil 表示向上取整，例如 ceil(10 / 3) = 4。

官方示例 1

输入：nums = [10,10,10,10,10], k = 5
输出：50

每个位置各选一次，总分为 10 + 10 + 10 + 10 + 10 = 50。

官方示例 2

输入：nums = [1,10,3,3,3], k = 3
输出：17

先选 i = 1，数组变为 [1,4,3,3,3]，得 10 分；再选 i = 1，变为 [1,2,3,3,3]，得 4 分；最后选 i = 2，变为 [1,2,1,3,3]，得 3 分。总分为 17。

约束与接口

  • 1 ≤ nums.length, k ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁹
  • 参数：maxKelements(nums, k)；返回最大总分（官方元数据类型为 long）。

04 / 题解实验室

洞察 · 操作回放 · 四语言实现

核心洞察：合并多条递减收益链

一个初始值 x 对应一条收益链：x → ceil(x/3) → ceil(ceil(x/3)/3) → … → 1 → 1。这条链单调不增；选择一个位置，就是取走链头并暴露下一个收益。因此，每次取当前最大的链头即可。

用最大堆维护所有当前值：取堆顶 x，累加 x，将 (x + 2) / 3 的整数商放回堆中。重复 k 次。堆只要求父节点不小于子节点，整个数组不需要全排序。

交互 / 堆顶收益回流

观察“取走链头 → 收益入账 → 缩小值回流 → 下沉恢复堆”。每一步对应一次完整操作；蓝框为下一次堆顶，虚线框为刚回流的元素。i 表示原数组下标。

完整过程
  1. 把 n 个初始值建成最大堆，分数设为 0。
  2. 重复 k 次：读取并移除最大值 x，将 x 加入分数。
  3. 计算新的当前值 floor((x + 2) / 3) 并放回堆。堆内始终有 n 个元素。
  4. 返回累计分数。原地替换堆顶的版本只需下沉，因为新值不会增大。
示例 2：初始最大值 10，第一轮得 10 并回流 4；第二轮最大值 4，得 4 并回流 2；第三轮最大值 3，得 3 并回流 1。累计 10 + 4 + 3 = 17。


正确性证明
将每个位置的后续收益写成单调不增的链。在任一状态，所有尚未暴露的链元素都不大于其当前链头，因此所有剩余收益中的最大值一定可以在某条链头取得。
考虑剩余 r 次操作的一个最优选择序列，令 g 为当前最大链头。若序列包含 g，则把它移到第一步仍然合法：它已是链头，没有未完成的前驱，其他链不受影响。若序列不含 g，则该序列也不会选择 g 所在链的后继；删除序列最后一步并在开头加入 g，仍然满足各链的前缀顺序。被删除的收益不大于 g，所以总分不会降低。
因此，总存在以 g 开头的最优序列。完成这一步后问题结构不变，对剩余 r − 1 步归纳，即得每次取最大值的策略最优。最大堆始终保存每条链当前的头部，准确实现了该策略。


边界与数值
  • n = 1 时不断选择同一元素；k 可以大于 n。
  • 值为 1 时回流仍是 1，不能提前停止计数。若堆顶为 1，可以直接加上剩余操作数。
  • 多个最大值并列时任选其一，不影响最终最大分数。
  • 总分上界为 k × 10⁹ ≤ 10¹⁴。Java 用 long、C++ 用 long long；Python 整数支持；JavaScript Number 可精确表示该范围整数（小于 2⁵³）。
  • 在本题范围内 x + 2 不会超过 32 位有符号整数上限。


复杂度
自底向上建堆 O(n)，k 次更新各 O(log n)，总时间 O(n + k log n)，空间 O(n)。严格包含 n = 1 时可写 O(n + k log(n + 1))。下方 Java 逐个插入建堆，总时间 O((n + k) log(n + 1))；JavaScript、Python、C++ 使用线性建堆。


替代方案
每轮遍历数组找最大值，时间 O(nk)，额外空间 O(1)（可修改输入时），适合小数据。每轮全排序需 O(kn log n)，维护了不必要的完整顺序。最大堆只维护所需的最大值信息。


常见错误
  • 只取原始数组前 k 大：忽略了回流值也可能再次成为最大值。
  • 用 x / 3 向下取整：10 应变为 4；Python 需先对正数取整再取负，避免负数整除方向混淆。
  • 先更新再加分：应累加旧值 x。
  • 取出后不放回：题目没有删除元素。
  • 用 32 位变量累计分数，或在 JavaScript 中用位运算截断总分。


面试追问
  • 除数换为整数 d ≥ 1 呢？收益链仍单调不增，策略成立，整数上取整为 (x + d − 1) / d，注意溢出。
  • 若更新后收益可能增大呢？证明失效。例如链 2 → 100 与 3 → 1，k = 2 时先选 2 更好。
  • 需要输出选择下标？堆中保存值和原下标，每轮记录堆顶下标即可。
  • 为什么只需下沉？替换值不大于旧堆顶，只有父节点相对子节点可能变小；与上方父节点的关系无需修复。




四语言完整实现
按官方 maxKelements 接口编写；以下代码均待补验证。代码区域可独立横向滚动。


Java
import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public long maxKelements(int[] nums, int k) {
        PriorityQueue<Integer> heap =
            new PriorityQueue<>(Collections.reverseOrder());
        for (int x : nums) heap.offer(x);
        long score = 0;
        for (int i = 0; i < k; i++) {
            int x = heap.poll();
            score += x;
            heap.offer((x + 2) / 3);
        }
        return score;
    }
}


JavaScript
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var maxKelements = function(nums, k) {
    const heap = nums.slice();
    const n = heap.length;
    function siftDown(i) {
        while (2 * i + 1 < n) {
            let child = 2 * i + 1;
            if (child + 1 < n && heap[child + 1] > heap[child]) child++;
            if (heap[i] >= heap[child]) break;
            [heap[i], heap[child]] = [heap[child], heap[i]];
            i = child;
        }
    }
    for (let i = Math.floor(n / 2) - 1; i >= 0; i--) siftDown(i);
    let score = 0;
    for (let i = 0; i < k; i++) {
        const x = heap[0];
        score += x;
        heap[0] = Math.floor((x + 2) / 3);
        siftDown(0);
    }
    return score;
};


Python
from typing import List
import heapq

class Solution:
    def maxKelements(self, nums: List[int], k: int) -> int:
        heap = [-x for x in nums]
        heapq.heapify(heap)
        score = 0
        for _ in range(k):
            x = -heap[0]
            score += x
            heapq.heapreplace(heap, -((x + 2) // 3))
        return score


C++
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    long long maxKelements(vector<int>& nums, int k) {
        priority_queue<int> heap(nums.begin(), nums.end());
        long long score = 0;
        for (int i = 0; i < k; ++i) {
            int x = heap.top();
            heap.pop();
            score += x;
            heap.push((x + 2) / 3);
        }
        return score;
    }
};
