简单数组枚举

重复至少 K 次
且长度为 M 的模式

在一串正整数中，判断是否存在一个长度恰为 m 的连续片段，它能不重叠地、首尾相接地重复至少 k 次。

输入arr, m, k
输出boolean
关键限定连续且不重叠
Problem

题意

给定正整数数组 arr，如果其中存在一个长度为 m 的模式，并且该模式连续、不重叠地重复了 k 次或更多次，返回 true；否则返回 false。同一模式出现多次但中间断开，不算连续重复。

官方示例

示例 1
输入：arr = [1,2,4,4,4,4], m = 1, k = 3

输出：true

模式 (4) 长度为 1，连续重复 4 次。

示例 2
输入：arr = [1,2,1,2,1,1,1,3], m = 2, k = 2

输出：true

模式 (1,2) 连续重复 2 次；(2,1) 也满足。

示例 3
输入：arr = [1,2,1,2,1,3], m = 2, k = 3

输出：false

(1,2) 只完整重复 2 次，达不到 3 次。

补充示例

示例 4
输入：arr = [1,2,3,1,2], m = 2, k = 2

输出：false

(1,2) 虽出现两次，但它们没有连续相接。

示例 5
输入：arr = [2,2,2,2], m = 2, k = 3

输出：false

不可通过重叠计数凑出 3 次完整的 (2,2)。

约束
  • 2 ≤ arr.length ≤ 100
  • 1 ≤ arr[i] ≤ 100
  • 1 ≤ m ≤ 100
  • 2 ≤ k ≤ 100

先在扫描轨上形成自己的判断方法，再展开实现细节。

题解：错位比较，累计连续匹配

核心洞察

若长度为 m 的模式连续重复，那么从第二段开始，每个元素都应等于它左侧距离 m 的元素，即 arr[i] == arr[i-m]。要得到 k 段，只需让这种关系连续成立 m × (k-1) 次。用一个计数器记录连续相等次数，遇到不等就清零。

完整过程

  1. 令 matched = 0，从下标 m 开始扫描。
  2. 若 arr[i] == arr[i-m]，令 matched++；否则令其归零。
  3. 一旦 matched >= m*(k-1)，说明当前连续区间涵盖一个基准段和其后的 k-1 个复制段，返回 true。
  4. 扫描结束仍未达到阈值，返回 false。

为什么正确

充分性：连续 m(k-1) 个位置满足与前方 m 格相等，可按长度 m 切成 k-1 组；每组都逐元素等于前一组，因此连同最前面的基准组，共有 k 个相同且不重叠的连续模式。

必要性：若某个长度为 m 的模式连续重复至少 k 次，那么从第二段的首元素到第 k 段的末元素，每个位置都等于左侧相距 m 的位置，恰好形成至少 m(k-1) 次连续相等。扫描一定会捕获它。

边界与复杂度

  • 当 m*k > arr.length 时，不可能容纳目标片段，可直接返回 false。
  • 相等序列在任意一次比较失败后必须清零，防止把两个分离的出现拼起来。
  • 时间复杂度 O(n)，额外空间复杂度 O(1)。

替代方案

直接枚举起点，并逐项检查长度为 m*k 的候选区间，写法直观，时间复杂度为 O(nmk)。在本题 n ≤ 100 时也能通过，但错位比较更紧凑。还可以逐段比较切片，但会引入额外数组或切片开销。

class Solution {
    public boolean containsPattern(int[] arr, int m, int k) {
        if (m * k > arr.length) return false;

        int matched = 0;
        int target = m * (k - 1);
        for (int i = m; i < arr.length; i++) {
            if (arr[i] == arr[i - m]) {
                matched++;
                if (matched >= target) return true;
            } else {
                matched = 0;
            }
        }
        return false;
    }
}

面试追问

  • 为什么阈值不是 m*k？ 第一段是基准，无需向左比较；只需验证后面 k-1 段。
  • 如果只要求出现 k 次但不要求连续？ 可对长度 m 的窗口编码并统计频次，但还需根据“不重叠”要求保存并筛选位置。
  • 若数据以流式到达？ 保存最近 m 个元素的环形缓冲区和连续匹配计数即可，空间为 O(m)。

常见错误

  • 只统计模式的全局出现次数，忽略“连续”。
  • 使用滑动窗口重叠计数，把 [2,2,2,2] 误判为长度 2 的模式重复 3 次。
  • 比较失败后只减一而不是清零，错误串联两个匹配区间。
  • 把阈值写成 m*k，漏掉刚好重复 k 次的答案。
