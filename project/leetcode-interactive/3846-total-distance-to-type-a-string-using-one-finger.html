使用单指输入字符串的总距离

从 'a' 出发，沿特殊 QWERTY 网格逐个敲下字符串。每一段成本就是两键坐标的曼哈顿距离。

题意与示例

键盘三行依次为 qwertyuiop、asdfghjkl、zxcvbnm。给定仅含小写字母的 s，手指起点是 'a'；从当前位置 (r₁,c₁) 到目标 (r₂,c₂) 的代价为 |r₁-r₂| + |c₁-c₂|。返回输入全串的累计距离。

示例

s = "hello"

期望输出：17。路径为 a → h → e → l → l → o；第二个 l 不移动，贡献 0。

约束

1 ≤ s.length ≤ 10⁴；s 只含小写英文字母。坐标表只有 26 项，可以预先建立。

逐步可视化：移动轨迹

只接受 a–z；空格不会参与计算。可按 ←/→ 逐步移动，按 Space 自动播放。

已输入字符0 / 5
累计距离0
起点：手指停在 a 的坐标 (1, 0)。

题解：坐标表 + 一次模拟

不需要搜索最短路：题目已定义两点间距离为曼哈顿距离。建立 char → (row,col)，维护 prev，每读一个字符就把 dist(prev,ch) 加到答案并更新 prev。

完整过程

  1. 扫描三行键盘，登记每个字符坐标。
  2. 令当前位置为 'a'。
  3. 遍历 s，累加横向差与纵向差的绝对值。
  4. 把当前位置换成当前字符。

边界与复杂度

单字符 "a" 的结果为 0；相邻相同字符贡献 0；首字符也要计算从 a 的移动。

时间 O(n)，空间 O(1)（26 个字符）。

替代方案、追问与常见错误

也可用两个长度 26 的数组存行、列，避免哈希表；面试追问可改成任意键盘布局或权重不同的按键。常见错误：把首字符当作无成本、把字母表顺序当作键盘顺序、遗漏重复字符的 0 成本。
