Count Negative Numbers in a Sorted Matrix

统计有序矩阵中的负数

给定一个 m × n 整数矩阵 grid。每一行从左到右、每一列从上到下都按非严格递减顺序排列，请返回矩阵中严格小于 0 的元素数量。

先观察，再推导。 0 不是负数；矩阵的双向有序性意味着负数会集中在右下区域。先尝试下面的阶梯实验，完整题解默认收起。

示例与约束

示例 1

输入：grid = [[4,3,2,-1],[3,2,1,-1],[1,1,-1,-2],[-1,-1,-2,-3]]
输出：8
解释：矩阵中共有 8 个负数。

示例 2

输入：grid = [[3,2],[1,0]]
输出：0

约束

  • m == grid.length
  • n == grid[i].length
  • 1 <= m, n <= 100
  • -100 <= grid[i][j] <= 100

进阶：能否在 O(m + n) 时间内完成？

题解：一次走过分界线

核心洞察

从左下角开始。若当前值小于 0，因为本行非严格递减，它右侧的 n - col 个元素必然都为负数，可以一次计入，然后向上移动；否则当前值及其上方同列元素都不会是负数，向右移动。

完整过程

  1. 令 row = m - 1、col = 0、answer = 0。
  2. 若 grid[row][col] < 0，累加 n - col，随后 row--。
  3. 否则执行 col++。
  4. 直到越过矩阵上边界或右边界，返回累计值。

正确性证明

不变式：每次循环开始时，指针左下方已离开矩阵；所有已跳过或已计数区域均已被正确分类，尚未分类的区域包含在指针右上方的阶梯形区域中。

若当前值为负，行递减性保证同一行右侧全部为负，因此整段计数不会漏计或错计，向上移动后不变式仍成立。若当前值非负，列递减性保证其上方同列元素均大于等于当前值，也必定非负，因此整列的剩余部分可安全排除，向右移动后不变式仍成立。每步都会向上或向右，最终退出；此时没有未分类元素，所以累计数就是全部负数数量。

复杂度

指针最多向上走 m 次、向右走 n 次，因此时间复杂度为 O(m + n)；只使用常数个变量，空间复杂度为 O(1)。

边界处理

  • 只有一个元素时，严格比较 < 0。
  • 全非负时一路向右，结果为 0。
  • 全为负时每行整段计数。
  • 含 0 时不可把 0 算作负数。

替代方案

逐格扫描简单但需要 O(mn)。也可以对每行二分查找第一个负数，时间为 O(m log n)；在矩阵仅保证行有序、不保证列有序时，这个方案仍然适用。

面试追问

  • 若只有行有序，怎样调整？答：逐行二分。
  • 若矩阵改为非严格递增，起点和方向怎样变化？
  • 如何统计小于任意阈值 k 的元素？把判断替换为 < k。
常见错误：从错误角落出发导致无法一次排除一整行/列；把 0 当成负数；遇到负数只加 1 而没有整段计数；累加 m - row 而非当前行剩余列数 n - col。

完整代码

JavaO(m+n)
class Solution {
    public int countNegatives(int[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;
        int row = rows - 1;
        int col = 0;
        int count = 0;

        while (row >= 0 && col < cols) {
            if (grid[row][col] < 0) {
                count += cols - col;
                row--;
            } else {
                col++;
            }
        }
        return count;
    }
}

from typing import List


class Solution:
    def countNegatives(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        row, col = rows - 1, 0
        count = 0

        while row >= 0 and col < cols:
            if grid[row][col] < 0:
                count += cols - col
                row -= 1
            else:
                col += 1

        return count
