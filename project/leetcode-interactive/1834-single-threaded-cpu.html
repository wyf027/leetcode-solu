单线程 CPU

Single-Threaded CPU · 中等 · 公开题

题目 · 遵循调度规则

输入二维整数数组 tasks，共 n 项。任务编号为原始下标 0 到 n−1；tasks[i] = [enqueueTimeᵢ, processingTimeᵢ]，表示该任务的到达时刻和执行时长。返回 CPU 处理任务的编号顺序。

  • CPU 同时最多执行一项任务；空闲且没有可用任务时继续等待。
  • 空闲且有任务可用时，选执行时长最短者；平局选原始下标最小者。
  • 开始执行后必须做完，后来到达的任务不能抢占。
  • 完成与下一项开始可以发生在同一时刻。

约束：tasks.length = n；1 ≤ n ≤ 10⁵；每项为两个整数；1 ≤ enqueueTimeᵢ, processingTimeᵢ ≤ 10⁹。

题解 · 事件推进与最小堆

核心洞察

到达顺序与执行优先级不同。按到达时刻排序并用指针扫描，用最小堆保存已到达但未执行的任务；堆的比较键是（执行时长，原始下标）。不需要逐秒模拟。

完整过程

  1. 为任务附上原始下标，再按到达时间排序。
  2. 堆为空时，把时间更新为当前时刻与下次到达时刻的最大值。
  3. 把所有到达时刻 ≤ 当前时刻的任务加入堆。
  4. 弹出堆顶，记录编号，将时间增加该任务的完整时长。
  5. 直到所有任务已入堆且堆已清空才结束。

示例 1 在 t=3 时，任务 1 的时长为 4、任务 2 为 2，所以选择任务 2。任务 3 虽然在 t=4 到达且只需 1 单位时间，也必须等待到 t=5。

正确性

每次选择前，堆恰好包含全部已到达且未执行的任务：排序指针只加入到达时刻不大于当前时刻的任务，而且一次加入全部；每次仅移除本次执行的任务。因此堆顶按时长、原始下标给出的选择与题目规则一致。执行完整时长后才再次选择，保证不可抢占。堆空时跳到下一次到达不会遗漏可执行任务。归纳得每次选择正确；每轮完成一个任务，最终得到全部 n 个编号。

边界与复杂度

单任务、同时到达、相同时长、执行结束时恰有新任务到达以及中间空闲都遵循同一流程。总时间 O(n log n)，额外空间 O(n)，含排序副本、堆和答案。累计时间可能达到约 10¹⁴：Java 使用 long，C++ 使用 long long；Python 整数与 JavaScript Number 的安全整数范围足够。

替代方案

每次扫描所有未执行任务可得 O(n²) 的直观模拟，适合少量任务。逐秒模拟会被巨大的时间值拖慢。只做全局时长排序会选到尚未到达的任务。有序集合也可维护双关键字，但最小堆已足够。

常见错误

  • 用 < 而不是 ≤ 判断到达，漏掉恰好此刻可用的任务。
  • 只入堆一项就弹出，没有纳入全部候选。
  • 丢失原始编号或平局时用到达顺序比较。
  • 让后到短任务抢占，或堆空时让时刻倒退。
  • 累计时间使用 32 位整数，或所有任务入堆后就提前结束。

面试追问

允许抢占时，需要在新任务到达事件比较剩余时长，并拆分执行区间。多个 CPU 时，需要额外维护处理器的空闲时刻与平局规则。等待时长可用开始时刻减去到达时刻计算。本题是模拟指定规则，并非自行设计最优调度策略。

Java

import java.util.*;
class Solution {
    public int[] getOrder(int[][] tasks) {
        int n = tasks.length;
        int[][] a = new int[n][3];
        for (int i=0; i<n; i++)
            a[i] = new int[]{tasks[i][0], tasks[i][1], i};
        Arrays.sort(a, (x,y)->Integer.compare(x[0],y[0]));
        PriorityQueue<int[]> q = new PriorityQueue<>((x,y)->
            x[1]!=y[1] ? Integer.compare(x[1],y[1]) : Integer.compare(x[2],y[2]));
        int[] ans = new int[n];
        int i=0, k=0;
        long time=0;
        while (i<n || !q.isEmpty()) {
            if (q.isEmpty()) time=Math.max(time,(long)a[i][0]);
            while (i<n && a[i][0]<=time) q.offer(a[i++]);
            int[] task=q.poll();
            ans[k++]=task[2];
            time+=task[1];
        }
        return ans;
    }
}

JavaScript

/** @param {number[][]} tasks @return {number[]} */
var getOrder = function(tasks) {
    const a=tasks.map(([e,p],i)=>[e,p,i]).sort((x,y)=>x[0]-y[0]);
    const h=[], ans=[];
    const less=(x,y)=>x[1]<y[1] || (x[1]===y[1] && x[2]<y[2]);
    function push(x) {
        h.push(x);
        let k=h.length-1;
        while(k>0) {
            const p=Math.floor((k-1)/2);
            if(!less(h[k],h[p])) break;
            [h[k],h[p]]=[h[p],h[k]]; k=p;
        }
    }
    function pop() {
        const first=h[0], last=h.pop();
        if(h.length) {
            h[0]=last;
            let k=0;
            while(2*k+1<h.length) {
                let c=2*k+1;
                if(c+1<h.length && less(h[c+1],h[c])) c++;
                if(!less(h[c],h[k])) break;
                [h[k],h[c]]=[h[c],h[k]]; k=c;
            }
        }
        return first;
    }
    let i=0, time=0;
    while(i<a.length || h.length) {
        if(!h.length) time=Math.max(time,a[i][0]);
        while(i<a.length && a[i][0]<=time) push(a[i++]);
        const task=pop();
        ans.push(task[2]); time+=task[1];
    }
    return ans;
};

Python

from typing import List
import heapq

class Solution:
    def getOrder(self, tasks: List[List[int]]) -> List[int]:
        a = sorted((e, p, i) for i, (e, p) in enumerate(tasks))
        heap, ans = [], []
        i, time = 0, 0
        while i < len(a) or heap:
            if not heap:
                time = max(time, a[i][0])
            while i < len(a) and a[i][0] <= time:
                e, p, index = a[i]
                heapq.heappush(heap, (p, index))
                i += 1
            p, index = heapq.heappop(heap)
            ans.append(index)
            time += p
        return ans

#include <vector>
#include <array>
#include <queue>
#include <algorithm>
#include <functional>
#include <utility>
using namespace std;
class Solution {
public:
    vector<int> getOrder(vector<vector<int>>& tasks) {
        vector<array<int,3>> a;
        for(int i=0;i<(int)tasks.size();++i)
            a.push_back({tasks[i][0],tasks[i][1],i});
        sort(a.begin(),a.end());
        priority_queue<pair<int,int>,vector<pair<int,int>>,greater<pair<int,int>>> q;
        vector<int> ans;
        int i=0,n=a.size();
        long long time=0;
        while(i<n || !q.empty()) {
            if(q.empty()) time=max(time,(long long)a[i][0]);
            while(i<n && a[i][0]<=time) {
                q.push({a[i][1],a[i][2]}); ++i;
            }
            auto [p,index]=q.top(); q.pop();
            ans.push_back(index); time+=p;
        }
        return ans;
    }
};
