相似字符串组Similar String Groups

不要被“字符串”迷惑：这是一道把单词看成节点、把一次交换看成边，再统计连通分量的图论题。

?

给定彼此互为字母异位词的字符串数组，最终形成多少个相似关系组？先观察关系如何生长，再展开题解。

Problem

题意转述

若两个字符串完全相同，或只需在其中一个字符串内交换两个不同位置的字符就能得到另一个字符串，则称它们“相似”。给定字符串数组 strs，其中所有字符串长度相同且彼此互为字母异位词，求相似关系形成的组数。相似组按传递连通理解：同组内两词不必直接相似，只要能经由若干相似关系连接即可。

函数形式： numSimilarGroups(strs: string[]) → integer

官方示例

输入：strs = ["tars","rats","arts","star"]
输出：2
示例 2

输出：1

Constraints

约束与语义边界

  • strs[i] 仅由小写英文字母组成。
  • strs 中所有字符串长度相同，并且互为字母异位词。

Solution

并查集：比较所有字符串对

建模字符串是图节点，直接相似的两词之间有无向边。
判定由于已知互为字母异位词，不同位置数量只能以合理配对出现；直接相似时为 0 或 2。
计数每次成功合并两个不同根，组数减一；最终即连通分量数。

完整过程

  1. 初始化。 令每个下标的父节点为自身，组数为 n。
  2. 枚举无序对。 对每个 i < j 比较 strs[i] 与 strs[j]。
  3. 判断相似。 扫描每个字符位置，累计不同数；超过 2 立即停止。最终不同数是 0 或 2才相似。
  4. 合并集合。 若相似且两词根节点不同，按秩/大小合并，组数减一。
  5. 返回答案。 所有字符串对处理后返回剩余组数。
正确性证明。 对任意两个直接相似的字符串，算法枚举到它们时会加入一条等价的并查集合并关系，因此图中的每条边都被并查集覆盖；沿相似边可达的任意两点会经由这些合并拥有同一根。反过来，并查集只在两个字符串直接相似时合并，不会跨越图中不存在的边，因此不同连通分量不会被错误合并。故最终并查集集合与相似图的连通分量一一对应，返回的组数正确。

Complexity

复杂度

设字符串数量为 n，每个字符串长度为 m。

  • 时间：O(n²m)，比较至多 n(n-1)/2 对字符串。
  • 空间：O(n)，用于并查集父节点和秅数组。

Edge cases

边界情况

  • 只有一个字符串：答案为 1。
  • 完全相同的字符串：0 个位置不同，仍应合并。
  • 形成传递链：首尾不直接相似，也可能属于同一组。
  • 所有字符串互不直接相似：答案为 n。
  • 比较中差异数一旦超过 2，可提前返回。

Alternatives & interview

替代方案与面试追问

替代方案

  • DFS / BFS：仍需按相似性建立或隐式遍历图，时间同为 O(n²m)，再统计访问启动次数。
  • 生成邻居：对每个词尝试所有一次交换并用哈希表查询，约 O(nm²)；当 m 显著小于 n 时可能更合适，但要处理重复字符串。

面试追问

  • 若不保证互为字母异位词，相似判定应怎样写？答案：记录两个差异位置，并验证交叉字符相等。
  • 为什么“同组”不是两两直接相似？因为分组定义的是相似图的传递闭包，即连通性。
  • 能否边比较边少做工作？若两节点已同根，可跳过字符比较或继续按实现权衡。

常见错误

  • 写成差异数 <= 2 却忘了输入前提；一般输入下差异为 1 并不代表可交换得到。
  • 只统计“直接相似的小团”，忽略 A~B、B~C 带来的传递连通。
  • 重复合并时仍把组数减一。
  • 双重循环从 j = 0 开始，造成不必要的重复比较。

class Solution {
    public int numSimilarGroups(String[] strs) {
        int n = strs.length;
        int[] parent = new int[n];
        int[] size = new int[n];
        for (int i = 0; i < n; i++) {
            parent[i] = i;
            size[i] = 1;
        }
        int groups = n;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (find(i, parent) != find(j, parent)
                        && similar(strs[i], strs[j])) {
                    int a = find(i, parent), b = find(j, parent);
                    if (size[a] < size[b]) { int t = a; a = b; b = t; }
                    parent[b] = a;
                    size[a] += size[b];
                    groups--;
                }
            }
        }
        return groups;
    }

    private int find(int x, int[] parent) {
        if (parent[x] != x) parent[x] = find(parent[x], parent);
        return parent[x];
    }

    private boolean similar(String a, String b) {
        int diff = 0;
        for (int i = 0; i < a.length(); i++) {
            if (a.charAt(i) != b.charAt(i) && ++diff > 2) return false;
        }
        return diff == 0 || diff == 2;
    }
}

var numSimilarGroups = function(strs) {
    const n = strs.length;
    const parent = Array.from({ length: n }, (_, i) => i);
    const size = Array(n).fill(1);
    let groups = n;

    const find = (x) => {
        if (parent[x] !== x) parent[x] = find(parent[x]);
        return parent[x];
    };
    const similar = (a, b) => {
        let diff = 0;
        for (let i = 0; i < a.length; i++) {
            if (a[i] !== b[i] && ++diff > 2) return false;
        }
        return diff === 0 || diff === 2;
    };

    for (let i = 0; i < n; i++) {
        for (let j = i + 1; j < n; j++) {
            let a = find(i), b = find(j);
            if (a !== b && similar(strs[i], strs[j])) {
                if (size[a] < size[b]) [a, b] = [b, a];
                parent[b] = a;
                size[a] += size[b];
                groups--;
            }
        }
    }
    return groups;
};
from typing import List

class Solution:
    def numSimilarGroups(self, strs: List[str]) -> int:
        n = len(strs)
        parent = list(range(n))
        size = [1] * n
        groups = n

        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def similar(a: str, b: str) -> bool:
            diff = 0
            for x, y in zip(a, b):
                if x != y:
                    diff += 1
                    if diff > 2:
                        return False
            return diff == 0 or diff == 2

        for i in range(n):
            for j in range(i + 1, n):
                a, b = find(i), find(j)
                if a != b and similar(strs[i], strs[j]):
                    if size[a] < size[b]:
                        a, b = b, a
                    parent[b] = a
                    size[a] += size[b]
                    groups -= 1
        return groups
class Solution {
    vector<int> parent, size;

    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }

    bool similar(const string& a, const string& b) {
        int diff = 0;
        for (int i = 0; i < (int)a.size(); ++i) {
            if (a[i] != b[i] && ++diff > 2) return false;
        }
        return diff == 0 || diff == 2;
    }

public:
    int numSimilarGroups(vector<string>& strs) {
        int n = strs.size(), groups = n;
        parent.resize(n);
        size.assign(n, 1);
        iota(parent.begin(), parent.end(), 0);
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                int a = find(i), b = find(j);
                if (a != b && similar(strs[i], strs[j])) {
                    if (size[a] < size[b]) swap(a, b);
                    parent[b] = a;
                    size[a] += size[b];
                    --groups;
                }
            }
        }
        return groups;
    }
};
