Problem

题目描述

给定仅由大小写英文字母组成的字符串 s。如果两个相邻字符是同一个字母，但大小写相反，那么这两个字符构成“坏相邻对”。你可以反复删除任意一个坏相邻对。

返回无法再删除坏相邻对时得到的字符串。题目保证答案唯一；空字符串也视为整理好的字符串。

函数形式：makeGood(s: string): string

约束

  • 1 <= s.length <= 100
  • s 只包含大写和小写英文字母。
示例 1
输入：s = "leEeetcode"
输出："leetcode"
解释：删除相邻的 "eE" 或 "Ee" 后，均得到 "leetcode"。
示例 2
输入：s = "abBAcC"
输出：""
解释：例如 "abBAcC" → "aAcC" → "cC" → ""。
示例 3
输入：s = "s"
输出："s"

Solution

准备好再看题解

建议先用上面的实验室解释一次：为什么删除后新形成的相邻字符也会继续被处理？

核心洞察

从左到右维护一个栈，栈中保存已经扫描且暂时无法再抵消的字符。新字符只可能和栈顶成为新的坏相邻对：

  • 若栈顶与当前字符是同一字母、大小写相反，则弹出栈顶，两者抵消。
  • 否则将当前字符压栈。

在英文字母的 ASCII 编码中，同一字母的大小写编码差为 32，因此可用 abs(a - b) == 32 判断。

完整过程

  1. 创建空栈。
  2. 依次读取 s 的每个字符。
  3. 检查栈顶；能抵消就弹栈，不能就入栈。
  4. 扫描结束后，将栈内字符按顺序拼接为答案。

示例：abBAcC 的栈依次为 a → ab → a → 空 → c → 空。

正确性证明

不变式：处理完前 i 个字符后，栈恰好是该前缀整理后的结果，且栈内不存在坏相邻对。

处理下一个字符 c 时，旧栈内部已经整理好，唯一可能新出现的坏相邻对只能位于旧栈顶与 c 之间。若两者抵消，弹栈得到正确的新结果；否则压入 c 仍保持整理状态。因此不变式继续成立。扫描完全部字符时，栈就是整个字符串的整理结果。

复杂度与边界

  • 时间复杂度：O(n)，每个字符至多入栈、出栈各一次。
  • 空间复杂度：O(n)，最坏情况下没有字符抵消。
  • 边界：单字符直接保留；全部连锁抵消时返回空串；同字母同大小写不会抵消。

替代方案

可以反复扫描字符串并删除坏相邻对，直到长度不再变化。实现直观，但每轮删除和重建字符串可能使时间复杂度达到 O(n²)。栈把所有轮次的连锁反应合并到一次扫描中。

面试追问

  • 若规则扩展为任意可配对字符，如何把判断逻辑抽成映射？
  • 能否复用字符数组原地模拟栈，把额外对象开销降到最低？
  • 为什么不同删除顺序最终仍得到同一个结果？

常见错误

  • 只删除原字符串中最初相邻的坏字符，遗漏删除后产生的连锁抵消。
  • 用 toLowerCase() 相等作为唯一条件，误把 aa 也当作可抵消。
  • 弹栈后跳过当前扫描位置，或在空栈时读取栈顶。
  • 把空字符串输出误写成一对引号字符；返回值应是真正的空串。

四语言完整代码

Java
class Solution {
    public String makeGood(String s) {
        StringBuilder stack = new StringBuilder();
        for (char c : s.toCharArray()) {
            int size = stack.length();
            if (size > 0
                    && Math.abs(stack.charAt(size - 1) - c) == 32) {
                stack.deleteCharAt(size - 1);
            } else {
                stack.append(c);
            }
        }
        return stack.toString();
    }
}

/**

var makeGood = function(s) {
    const stack = [];
    for (const char of s) {
        const top = stack[stack.length - 1];
        if (top !== undefined
                && Math.abs(top.charCodeAt(0) - char.charCodeAt(0)) === 32) {
            stack.pop();
        } else {
            stack.push(char);
        }
    }
    return stack.join("");
};
Python 3
class Solution:
    def makeGood(self, s: str) -> str:
        stack: list[str] = []
        for char in s:
            if stack and abs(ord(stack[-1]) - ord(char)) == 32:
                stack.pop()
            else:
                stack.append(char)
        return "".join(stack)
C++
class Solution {
public:
    string makeGood(string s) {
        string stack;
        for (char c : s) {
            if (!stack.empty()
                    && abs(stack.back() - c) == 32) {
                stack.pop_back();
            } else {
                stack.push_back(c);
            }
        }
        return stack;
    }
};
