寻找数组的中心下标

中心下标左侧元素和等于右侧元素和。返回最左侧中心下标；不存在则返回 -1。

前缀和O(n) 时间O(1) 空间

一次扫描

  1. 1. 先计算数组总和 total。
  2. 2. 维护左侧累计和 left。
  3. 3. 当前下标 i 的右侧和是 total - left - nums[i]。
  4. 4. 两者相等立即返回 i；否则将 nums[i] 加入 left。

不必真的构造前缀和数组，left 一个变量即可。

边界

  • 第 0 项可能是中心下标。
  • 最后一项也可能是中心下标。
  • 负数不影响公式。
  • 要求最左侧，因此从左到右首个命中即返回。

前缀和实验室

逗号分隔整数，点击计算即可观察每个位置的左右和。

验证清单

  • [1,7,3,6,5,6] 返回 3。
  • [1,2,3] 返回 -1。
  • [2,1,-1] 返回 0。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。 

class Solution {
 public int pivotIndex(int[] nums) { int total=0,left=0; for(int x:nums) total+=x; for(int i=0;i<nums.length;i++){ if(left==total-left-nums[i]) return i; left+=nums[i]; } return -1; }
}

 let total=nums.reduce((a,b)=>a+b,0), left=0;

class Solution:
 def pivotIndex(self, nums):
  total, left = sum(nums), 0
  for i, x in enumerate(nums):
   if left == total-left-x: return i
   left += x
  return -1
