珠玑妙算

四枚密码珠看起来只是一次猜色游戏，真正的陷阱却是“同一枚珠子不能被重复计分”。 这座检测台先封存位置正确的命中，再让剩余颜色进入四个库存抽屉。

面试主线：先排除同色同位，再对剩余颜色取两边库存的较小值——重复颜色自然不会多算。

01 / problem brief

题意：命中与伪猜中

solution 与 guess 都由四个字符组成，字符只可能是 R、Y、G、B。颜色和槽位都相同算一次“猜中”； 颜色存在但槽位错误算一次“伪猜中”。已经用于猜中的槽位不能再参与伪猜中统计。

官方示例

solution = "RGBY", guess = "GGRR"

第 2 个槽位（从 0 开始为索引 1）的 G 同色同位；剩余猜测中的 R 能与剩余答案中的 R 配成一次伪猜中。

输出：[1, 1]

约束与返回值

solution.length = guess.length = 4，字符集合固定为 {R,Y,G,B}。

answer[0] 是猜中数，answer[1] 是伪猜中数。

核心洞察：位置优先，颜色随后

伪猜中的前提是“没有在同一位置猜中”。因此先扫描四个槽位：相等就直接计入 hit；不相等时才把答案色和猜测色分别放入库存。最后对每种颜色贡献 min(solutionCount[color], guessCount[color])，四种颜色之和就是 pseudoHit。

完整过程

  1. 初始化 hit = 0，两组长度为 4 的颜色计数。
  2. 逐槽比较；相等就累加 hit。
  3. 不相等时，分别记录答案色和猜测色。
  4. 遍历四种颜色，把两边较小库存累加到 pseudoHit。
  5. 返回 [hit, pseudoHit]。

边界

  • 四个位置全部相等：返回 [4, 0]。
  • 颜色完全相同但全部错位：返回 [0, 4]。
  • 两边没有共同颜色：返回 [0, 0]。
  • 重复颜色：只能按两边剩余库存的较小值匹配。

复杂度

时间 O(n)
扫描字符串一次，再检查固定四种颜色。
空间 O(1)
只使用两个长度固定为 4 的计数数组。

替代方案

可以只维护一个颜色差值数组：遇到未命中位置时，根据当前余额判断答案色或猜测色能否与先前库存配对。 它同样是 O(n) / O(1)，但分支含义更绕；面试中优先推荐“两边分别计数”，更便于证明与复查。

面试追问

  • 颜色种类从 4 扩展为任意 Unicode 字符怎么办？改用哈希表。
  • 为什么必须先去掉命中？否则命中的珠子可能再次贡献伪猜中。
  • 能否一趟完成？可以，用差值数组在线配对，但证明成本更高。

常见错误

  • 直接统计两字符串颜色交集，忘记从中扣除命中。
  • 用“是否出现”代替计数，导致重复颜色被高估。
  • 对每个猜测珠独立搜索答案，却没有标记已使用位置。
  • 返回顺序写反：题目要求先猜中、后伪猜中。

class Solution {
    public int[] masterMind(String solution, String guess) {
        int hit = 0;
        int[] solutionCount = new int[4];
        int[] guessCount = new int[4];

        for (int i = 0; i < solution.length(); i++) {
            if (solution.charAt(i) == guess.charAt(i)) {
                hit++;
            } else {
                solutionCount[colorIndex(solution.charAt(i))]++;
                guessCount[colorIndex(guess.charAt(i))]++;
            }
        }

        int pseudoHit = 0;
        for (int i = 0; i < 4; i++) {
            pseudoHit += Math.min(solutionCount[i], guessCount[i]);
        }
        return new int[] {hit, pseudoHit};
    }

    private int colorIndex(char color) {
        if (color == 'R') return 0;
        if (color == 'Y') return 1;
        if (color == 'G') return 2;
        return 3;
    }
}
