Problem brief

题意与约束

设计一对互逆操作：把任意二叉树编码为字符串，再从该字符串还原出结构和值完全相同的树。编码格式可自定义，但两端规则必须一致。

任务

序列化把树转换为可存储或传输的连续字符串；反序列化读取该字符串并重建原树。

力扣的输入输出用层序数组展示树，但你的内部字符串不必沿用该格式。评测只关心 deserialize(serialize(root)) 是否与原树一致。

约束

  • 树中节点数在 [0, 10⁴] 范围内。
  • -1000 ≤ Node.val ≤ 1000。
  • 空树、重复值、负数与单支树都必须能够往返恢复。
示例 1
输入：root = [1,2,3,null,null,4,5]
输出：[1,2,3,null,null,4,5]
示例 2
输入：root = []
输出：[]

另外两个边界样例

[1] → [1]
[1,2] → [1,2]

    Solution

    前序 DFS + 空节点标记

    用固定顺序访问每个节点，并显式记录空子树；解码端按同一顺序消费 token，就能唯一恢复结构和值。

    核心洞察

    只记录非空节点值无法区分不同树形。前序遍历按“节点、左子树、右子树”展开，再用 # 记录每个空位置后，序列本身就携带了完整结构。

    完整过程

    1. 序列化：空节点写 #，非空节点写值。
    2. 递归处理左子树，再处理右子树。
    3. 用逗号连接全部 token。
    4. 反序列化：维护只增不减的读取下标。
    5. 读到 # 返回空；否则创建节点。
    6. 继续递归构建新节点的左、右孩子。

    边界情况

    • 空树编码为 #，可直接还原为 null。
    • 单节点编码为 7,#,#。
    • 负数和重复值不会破坏结构信息。
    • 极深单支树可能触及语言递归栈上限。

    为什么可逆

    每个数字 token 都会消费后续两段子树描述，每个 # 都结束一段空子树。解码过程与编码递归结构同构，因此不会发生左右位置歧义。

    复杂度

    O(n) 序列化和反序列化各访问每个节点与空位置一次。
    O(n) 结果字符串与拆分后的 token 数量都与节点数同阶。
    O(h) 递归调用栈取决于树高，最坏退化为 O(n)。

    替代方案

    • 层序遍历：用队列保留空位，尾部裁剪规则必须两端一致。
    • 括号表达式：可读性强，但解析逻辑更繁琐。
    • 二进制协议：更节省空间，但需定义长度、标志与字节序。
    • 显式栈：可以规避极深树的递归栈风险。

    面试追问

    • 为什么只有前序节点值不能还原树？
    • 为什么前序值加空标记已经足够？
    • 如果节点值本身可以包含分隔符，应如何编码？
    • 怎样把解码过程改成显式栈？

    常见错误

    • 遗漏空节点标记，导致树形信息丢失。
    • 解码顺序与编码顺序不一致。
    • 复用全局下标，却未在每次解码前重置。
    • 保留末尾分隔符后没有处理空 token。
    • 把节点值直接与特殊标记混在一起且未定义转义。
    • 忽略深度接近 10⁴ 时的递归栈风险。

    public class Codec {
    public String serialize(TreeNode root) {
        StringBuilder result = new StringBuilder();
        encode(root, result);
        result.setLength(result.length() - 1);
        return result.toString();
    }

    private void encode(TreeNode node, StringBuilder result) {
        if (node == null) {
            result.append("#,");
            return;
        }

        result.append(node.val).append(',');
        encode(node.left, result);
        encode(node.right, result);
    }

    public TreeNode deserialize(String data) {
        String[] tokens = data.split(",");
        int[] index = {0};
        return decode(tokens, index);
    }

    private TreeNode decode(String[] tokens, int[] index) {
        String token = tokens[index[0]++];
        if ("#".equals(token)) {
            return null;
        }

        TreeNode node = new TreeNode(Integer.parseInt(token));
        node.left = decode(tokens, index);
        node.right = decode(tokens, index);
        return node;
    }
}

    class Codec {
public:
    string serialize(TreeNode* root) {
        vector<string> tokens;
        encode(root, tokens);

        string result;
        for (int i = 0; i < static_cast<int>(tokens.size()); ++i) {
            if (i > 0) {
                result += ",";
            }
            result += tokens[i];
        }
        return result;
    }

    TreeNode* deserialize(string data) {
        vector<string> tokens;
        string token;
        stringstream input(data);

        while (getline(input, token, ',')) {
            tokens.push_back(token);
        }

        int index = 0;
        return decode(tokens, index);
    }

private:
    void encode(TreeNode* node, vector<string>& tokens) {
        if (node == nullptr) {
            tokens.push_back("#");
            return;
        }

        tokens.push_back(to_string(node->val));
        encode(node->left, tokens);
        encode(node->right, tokens);
    }

    TreeNode* decode(const vector<string>& tokens, int& index) {
        const string& token = tokens[index++];
        if (token == "#") {
            return nullptr;
        }

        TreeNode* node = new TreeNode(stoi(token));
        node->left = decode(tokens, index);
        node->right = decode(tokens, index);
        return node;
    }
};
