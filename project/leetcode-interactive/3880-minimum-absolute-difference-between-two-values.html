两个值之间的最小绝对差值

在只含 0、1、2 的数组中，找一个值为 1 的下标和一个值为 2 的下标，使二者距离最小。

Easy一次扫描O(n) 时间O(1) 空间

题意

给定整数数组 nums，每个元素只能是 0、1 或 2。合法下标对 (i, j) 满足 nums[i] = 1 且 nums[j] = 2。返回所有合法对中 |i - j| 的最小值；若不存在合法对，返回 -1。 

输入：nums = [1, 0, 0, 2, 0, 1]
输出：2
解释：(0, 3) 的距离为 3，(5, 3) 的距离为 2。
输入：nums = [1, 0, 1, 0]
输出：-1

约束：1 ≤ nums.length ≤ 100，0 ≤ nums[i] ≤ 2。数组中的空格在输入展示中用逗号分隔；本题没有字符串参数。

为什么只记最近位置？

当扫描到一个 1 时，离它最近的已出现 2 一定比更早的 2 更优；反过来也一样。因此只需要保留最近的 1 与最近的 2。

扫描不变量

处理完下标 i 后，lastOne、lastTwo 是各自最后一次出现的位置，best 是已处理前缀的最小合法距离。

第 0 步：尚未读取元素。

题解：维护最近的 1 与 2

从左到右扫描。遇到 1 时更新 lastOne，若已有 lastTwo 就尝试用二者距离更新答案；遇到 2 时对称处理。每个位置恰好访问一次。

  1. 令 lastOne = lastTwo = -1，best = +∞。
  2. 读到 1：若 lastTwo 已存在，比较 i - lastTwo；然后写入 lastOne = i。
  3. 读到 2：若 lastOne 已存在，比较 i - lastOne；然后写入 lastTwo = i。
  4. 扫描完成后，若 best 仍为无穷大，返回 -1。

边界

数组只有一种标记、长度为 1、相邻的 1/2（答案为 1）都能自然覆盖。

复杂度

时间 O(n)；额外空间 O(1)。

替代方案

双重循环易写但为 O(n²)；本题值域和“最近位置”性质允许线性扫描。

面试追问

若目标值更多，可维护每类最后位置；若要返回下标对，则在更新答案时一并记录两个位置。

常见错误

只在遇到 2 时比较、忘了从另一方向比较；或者把“不存在答案”的初始值误设为 0。 

class Solution {
    public int minimumDistance(int[] nums) {
        int lastOne = -1, lastTwo = -1;
        int best = Integer.MAX_VALUE;
        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == 1) {
                if (lastTwo != -1) best = Math.min(best, i - lastTwo);
                lastOne = i;
            } else if (nums[i] == 2) {
                if (lastOne != -1) best = Math.min(best, i - lastOne);
                lastTwo = i;
            }
        }
        return best == Integer.MAX_VALUE ? -1 : best;
    }
}
