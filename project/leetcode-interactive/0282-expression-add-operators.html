01 · Problem

题目描述

给定只含数字字符的字符串 num 与整数 target，在相邻数字之间选择插入二元运算符 +、-、*，返回所有计算结果恰好为目标值的表达式。

规则边界

数字的相对顺序不能改变；可以把连续多位数字作为一个操作数，但操作数不得含前导零。
  • 1 ≤ num.length ≤ 10
  • num 仅由字符 0–9 组成
  • -2³¹ ≤ target ≤ 2³¹ - 1
  • 插入的是二元运算符，不允许把 - 当作首位一元负号
  • 一个操作数可以包含多个数位，例如 "123" 可以整体作为 123

完整参数形式

输入
num: string, target: integer
输出
list<string>
输出顺序
题目不要求固定顺序；只需包含全部合法表达式。

官方示例

示例 1
输入：num = "123", target = 6
输出：["1+2+3", "1*2*3"]
解释：两个表达式的值都为 6。
示例 2
输入：num = "232", target = 8
输出：["2*3+2", "2+3*2"]
解释：两个表达式的值都为 8。
示例 3
输入：num = "3456237490",
      target = 9191
输出：[]
解释：不存在结果为 9191 的表达式。

03 · Solution

准备好后，再展开完整题解

包含核心洞察、证明、边界分析、复杂度与四语言实现。

Solution Unlocked

回溯枚举 + 末项修正

真正的难点不是枚举，而是在不重新解析整条表达式的前提下，实时维护乘法优先级。

核心洞察

递归在每个位置先切出下一个操作数，再分别尝试 +、-、*。状态同时保存当前表达式值 value 和上一段带符号贡献 last。

乘法：newValue = value - last + last × current

例如当前是 2 + 3，则 value = 5、last = 3。追加 * 2 时，撤销旧末项 3，换成 3 × 2，得到 5 - 3 + 6 = 8。新的 last 是 6，因此连续乘法也能正确处理。

递归状态

index

下一个尚未消费的数字下标。

path

已经构造的表达式文本。

value

按照正常优先级计算的当前表达式值。

last

当前表达式最后一个加法项的带符号贡献；乘法会替换它。

完整过程

  1. 切分操作数：从 index 开始枚举所有非空前缀作为 current，因此既覆盖单个数字，也覆盖多位数。
  2. 阻止前导零：如果起始字符为 0，只允许长度为 1 的操作数；更长切分立即停止。
  3. 处理首项：当 index = 0 时，直接把操作数放入表达式，避免生成非法的一元运算。
  4. 展开三条分支：加法更新为 (value + current, current)；减法更新为 (value - current, -current)；乘法使用末项修正。
  5. 收集答案：当所有数字都被消费，仅在 value == target 时加入结果。

正确性证明

完备性：对每个数字间隙，合法表达式只可能选择拼接、+、- 或 *。递归枚举每个位置开始的所有合法操作数，并在非首项尝试三种运算符，所以每个不含前导零的合法表达式都会对应唯一一条搜索路径。

状态不变式：进入任意递归节点时，value 等于 path 按正常优先级求得的值，last 等于最后一个加法项的带符号贡献。加、减显然保持不变式；乘法撤销 last 并替换为 last × current，也保持不变式。

可靠性：算法只在消费完全部数字且状态值等于目标时收集路径。由不变式可知，所有输出表达式都确实计算为 target。结合完备性，输出恰为全部合法答案。

复杂度

时间：每个数字间隙最多有拼接、加、减、乘四种选择，共 O(4ⁿ) 个候选结构；构造结果字符串计入复制成本后，可写为 O(n · 4ⁿ)。

空间：不计输出，递归深度与当前路径均为 O(n)；返回全部表达式所占空间取决于答案数量，最坏可达 O(n · 4ⁿ)。

边界处理

  • "0" 本身合法，"00" 作为单一操作数非法。
  • 减法分支把 last 记录为负数。
  • 使用 64 位整数；JavaScript 实现使用 BigInt。
  • 结果为空是合法返回值，不需要特殊补值。
Implementations

四语言完整代码

Solution.java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> addOperators(String num, int target) {
        List<String> answer = new ArrayList<>();
        dfs(num, target, 0, 0L, 0L, new StringBuilder(), answer);
        return answer;
    }

    private void dfs(String num, long target, int index,
                     long value, long last, StringBuilder path,
                     List<String> answer) {
        if (index == num.length()) {
            if (value == target) answer.add(path.toString());
            return;
        }

        long current = 0L;
        int originalLength = path.length();

        for (int end = index; end < num.length(); end++) {
            if (end > index && num.charAt(index) == '0') break;
            current = current * 10 + (num.charAt(end) - '0');
            String token = num.substring(index, end + 1);

            if (index == 0) {
                path.append(token);
                dfs(num, target, end + 1, current, current, path, answer);
                path.setLength(originalLength);
                continue;
            }

            path.append('+').append(token);
            dfs(num, target, end + 1, value + current, current, path, answer);
            path.setLength(originalLength);

            path.append('-').append(token);
            dfs(num, target, end + 1, value - current, -current, path, answer);
            path.setLength(originalLength);

            path.append('*').append(token);
            dfs(num, target, end + 1,
                value - last + last * current, last * current, path, answer);
            path.setLength(originalLength);
        }
    }
}
solution.js
/**
 * @param {string} num
 * @param {number} target
 * @return {string[]}
 */
var addOperators = function (num, target) {
    const answer = [];
    const goal = BigInt(target);

    function dfs(index, path, value, last) {
        if (index === num.length) {
            if (value === goal) answer.push(path);
            return;
        }

        for (let end = index; end < num.length; end++) {
            if (end > index && num[index] === "0") break;

            const token = num.slice(index, end + 1);
            const current = BigInt(token);

            if (index === 0) {
                dfs(end + 1, token, current, current);
                continue;
            }

            dfs(end + 1, path + "+" + token, value + current, current);
            dfs(end + 1, path + "-" + token, value - current, -current);
            dfs(
                end + 1,
                path + "*" + token,
                value - last + last * current,
                last * current
            );
        }
    }

    dfs(0, "", 0n, 0n);
    return answer;
};

solution.cpp
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> addOperators(string num, int target) {
        vector<string> answer;
        dfs(num, static_cast<long long>(target), 0, 0, 0, "", answer);
        return answer;
    }

private:
    void dfs(const string& num, long long target, int index,
             long long value, long long last, const string& path,
             vector<string>& answer) {
        if (index == static_cast<int>(num.size())) {
            if (value == target) answer.push_back(path);
            return;
        }

        long long current = 0;
        for (int end = index; end < static_cast<int>(num.size()); end++) {
            if (end > index && num[index] == '0') break;
            current = current * 10 + (num[end] - '0');
            string token = num.substr(index, end - index + 1);

            if (index == 0) {
                dfs(num, target, end + 1, current, current,
                    token, answer);
                continue;
            }

            dfs(num, target, end + 1, value + current, current,
                path + "+" + token, answer);
            dfs(num, target, end + 1, value - current, -current,
                path + "-" + token, answer);
            dfs(num, target, end + 1,
                value - last + last * current, last * current,
                path + "*" + token, answer);
        }
    }
};

替代方案

先生成、后求值：递归只构造字符串，到叶子再用表达式解析器计算。概念直观，但重复解析造成额外开销，还要独立保证优先级与安全性。

运算符槽位枚举：把每个间隙视为四态（拼接、加、减、乘），再逐个验证。结构规整，但仍离不开表达式求值，剪枝空间也较小。

栈式实时求值：维护项栈，乘法修改栈顶。含义清楚，但每条路径的栈复制/回退比只维护 value 与 last 更重。

面试追问

  • 如果再加入除法，如何定义整除、负数截断与除零？
  • 如果只要任意一个答案，怎样短路并减少搜索？
  • 如果加入括号，现有 last 状态为什么不再足够？
  • 如何按字典序返回，且避免最后再做全量排序？
  • 目标和操作数范围扩大时，怎样处理溢出？

常见错误

直接 value × current

这会把前面整个表达式都乘进去，破坏运算优先级。

允许 05、00

遇到起始零时必须停止扩展更长操作数，而不是跳过单个分支后继续。

首项也加运算符

会生成一元形式或开头多一个符号，不符合题目对二元运算符的限定。

减法 last 保持正数

随后乘法撤销的符号会错误；减法的末项贡献应为 -current。

只用 32 位整数

中间值可能超过目标范围，应使用更宽整数类型。

叶子才解析表达式

不仅更慢，也容易引入不安全的动态求值或另写一个有缺陷的解析器。
