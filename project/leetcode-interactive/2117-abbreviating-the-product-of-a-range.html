Abbreviating the Product of a Range

一个很长的乘积，最后只留下几位数字。先理解输出规则，再展开下面的题解，观察每一位如何被保留。

01 / THE CHALLENGE

题意与输出规则

输入两个正整数 left 和 right，计算闭区间 [left, right] 内所有整数的乘积，并按下面的规则返回字符串。区间的两个端点都参与乘法。

01

先去尾零

只删除末尾连续的 0，记删除数量为 C。中间的 0 不动。

02

再看位数

去尾零后超过 10 位，保留前 5 位与后 5 位，中间用三个点连接；不超过 10 位则全部保留。

03

附上 eC

无论是否缩写，都在末尾追加字母 e 与 C，包括没有尾零时的 e0。

约束：1 ≤ left ≤ right ≤ 10⁴。函数：abbreviateProduct(left, right) → string。这里的 eC 记录去掉的尾零数量。

官方示例

示例 1

输入：left = 1, right = 4
输出："24e0"

乘积为 24，没有尾零。剩下 2 位，原样输出并追加 e0。

示例 2

输入：left = 2, right = 11
输出："399168e2"

乘积为 39916800，删除两个尾零后是 399168，共 6 位。

示例 3

输入：left = 371, right = 375
输出："7219856259e3"

乘积为 7219856259000，删除 3 个尾零后恰好 10 位，不使用省略号。

03 / SOLUTION LAB

精确分块乘法：让每一位都有据可依

把十进制大整数按 9 位切块，使用基数 B = 10⁹，数组低位在前。对每个区间整数做一次“整条乘法”，最后拼回字符串，再执行题目的格式规则。这是一条无需浮点近似、便于证明的实现路线，代价是保存完整乘积。

核心洞察

机器整数装不下整个乘积，但可以装下一个分块的乘法。每次处理 t = a[j] × x + carry，当前块留下 t % B，进位传给下一块。

为什么用 9 位一块？

在 x ≤ 10000 时，进位小于 x，因此 t ≤ B × x − 1 < 10¹³，低于 JavaScript 的安全整数上限 2⁵³，也适合 Java long 与 C++ long long。不能用 32 位整型存 t。

完整过程
  1. 初始化数组 a = [1]，表示尚未乘入因子时的乘法单位元。
  2. 按闭区间从 left 到 right 遍历。每个 x 从最低块开始乘，先写回余数，再向高块传播商；最后追加非零进位。
  3. 逆序拼接数组。最高块直接转字符串，其余每块必须左侧补 0 至 9 位。
  4. 从字符串末尾向前数连续 0 并删除，得到 C 和剩余串 s。
  5. 如果 s 的长度大于 10，取前 5 位、三个点和后 5 位；否则保留 s。最后追加 e + C。


正确性证明
表示不变量：数组始终表示整数 Σ a[j]Bʲ，且每块在 [0, B) 内。乘入 x 时，由整除定理，t = (t mod B) + B⌊t/B⌋。因此写回的块恰好保留低位，而进位完整保存高位；逐块推进后得到原整数乘 x。初始值为 1，归纳可知循环结束时数组精确表示整个区间乘积。
字符串拼接中，非最高块补足 9 位保持各块的位权，因此得到精确的十进制乘积。乘积为正数，删除末尾最长的零串恰好得到题目定义的 C；按剩余串长度取完整数字或首尾五位，最后追加 eC，逐条满足输出规则。


边界与常见错误
  • left = right 也要执行一次乘法；[1,1] 返回 1e0。
  • 比较的是去掉尾零后的长度，且条件是 大于 10，10 位不缩写。
  • 不要把中间的 0 删除，不要将后五位转为整数，否则可能丢掉其前导 0。
  • 拼块必须补到 9 位，最高块不补；只取模保留末尾数字后再除 10 会丢失进位信息。
  • JavaScript 不对完整乘积使用 Number，也不用位运算求商；位运算会截成 32 位。
  • 本方案没有对数边界误差，但仍需补做四语言运行时间与提交环境验证。


复杂度
令 n = right − left + 1，D 为完整乘积的十进制位数，K = ⌈D/9⌉。按定宽整数运算计，乘法总时间 O(nK)，构造与裁剪字符串 O(D)，总计 O(nK + D)，额外空间 O(D)。题目范围内 D ≤ 40001，是保守上界。本方法不是 O(n) 时间、O(1) 空间方案。


替代方案
官方提示的方向是分别维护尾零、后五位和前五位：统计因子 2 与 5 的数量，配对数量给出 C；剥离配对因子后模 10⁵ 求后缀；用 Σlog₁₀(i) 的小数部分估算前缀。可减少空间与计算量，但要处理浮点误差、是否超过 10 位的可靠判断，以及后缀补零，不能只加一个固定 epsilon 就声称严格正确。
Java BigInteger、JavaScript BigInt、Python int 也能保存完整乘积，代码更短；Python 某些运行时对超长整数转十进制有限制。本页四份代码统一使用 9 位分块，避免依赖扩展大整数库或整体转换设置。


面试追问
  • 范围扩大到 10⁹ 怎么办？ 完整乘积存储不再合适，应改为独立求尾零、后缀与前缀，并讨论前缀的误差界。
  • 为什么最后最多新增一块？ 因为 carry < x ≤ 10000 < B，剩余进位本身就是合法块。
  • 能边乘边删尾零吗？ 若精确维护所有剩余位和累计零数，可以；若同时截断高位，则不能直接靠除 10 恢复丢掉的信息。
  • 如何让前缀严格可靠？ 使用完整整数，或采用带误差界的高精度计算，在跨越取整边界时提升精度或回退精确计算。

Java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public String abbreviateProduct(int left, int right) {
        final long BASE = 1_000_000_000L;
        List<Long> a = new ArrayList<>();
        a.add(1L); // 低位块在前
        for (int x = left; x <= right; x++) {
            long carry = 0;
            for (int j = 0; j < a.size(); j++) {
                long t = a.get(j) * x + carry;
                a.set(j, t % BASE);
                carry = t / BASE;
            }
            if (carry > 0) a.add(carry);
        }
        StringBuilder sb = new StringBuilder();
        sb.append(a.get(a.size() - 1));
        for (int j = a.size() - 2; j >= 0; j--) {
            String block = Long.toString(a.get(j));
            for (int k = block.length(); k < 9; k++) sb.append('0');
            sb.append(block);
        }
        int end = sb.length();
        while (sb.charAt(end - 1) == '0') end--;
        int zeros = sb.length() - end;
        String s = sb.substring(0, end);
        if (s.length() > 10)
            s = s.substring(0, 5) + "..." + s.substring(s.length() - 5);
        return s + "e" + zeros;
    }
}


JavaScript
/**
 * @param {number} left
 * @param {number} right
 * @return {string}
 */
var abbreviateProduct = function(left, right) {
    const BASE = 1_000_000_000;
    const a = [1]; // 低位块在前
    for (let x = left; x <= right; x++) {
        let carry = 0;
        for (let j = 0; j < a.length; j++) {
            const t = a[j] * x + carry;
            a[j] = t % BASE;
            carry = Math.floor(t / BASE);
        }
        if (carry > 0) a.push(carry);
    }
    let s = String(a[a.length - 1]);
    for (let j = a.length - 2; j >= 0; j--)
        s += String(a[j]).padStart(9, '0');
    const length = s.length;
    s = s.replace(/0+$/, '');
    const zeros = length - s.length;
    if (s.length > 10) s = s.slice(0, 5) + '...' + s.slice(-5);
    return s + 'e' + zeros;
};


Python
class Solution:
    def abbreviateProduct(self, left: int, right: int) -> str:
        base = 1_000_000_000
        a = [1]  # 低位块在前
        for x in range(left, right + 1):
            carry = 0
            for j in range(len(a)):
                carry, a[j] = divmod(a[j] * x + carry, base)
            if carry:
                a.append(carry)
        # 每次只转换至多 9 位，避开大整数整体转十进制的位数限制。
        s = str(a[-1]) + ''.join(f'{v:09d}' for v in reversed(a[:-1]))
        trimmed = s.rstrip('0')
        zeros = len(s) - len(trimmed)
        if len(trimmed) > 10:
            trimmed = trimmed[:5] + '...' + trimmed[-5:]
        return trimmed + 'e' + str(zeros)


C++
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string abbreviateProduct(int left, int right) {
        const long long BASE = 1000000000LL;
        vector<long long> a{1}; // 低位块在前
        for (int x = left; x <= right; ++x) {
            long long carry = 0;
            for (size_t j = 0; j < a.size(); ++j) {
                long long t = a[j] * x + carry;
                a[j] = t % BASE;
                carry = t / BASE;
            }
            if (carry) a.push_back(carry);
        }
        string s = to_string(a.back());
        for (int j = static_cast<int>(a.size()) - 2; j >= 0; --j) {
            string block = to_string(a[j]);
            s += string(9 - block.size(), '0') + block;
        }
        int zeros = 0;
        while (s.back() == '0') {
            s.pop_back();
            ++zeros;
        }
        if (s.size() > 10)
            s = s.substr(0, 5) + "..." + s.substr(s.size() - 5);
        return s + "e" + to_string(zeros);
    }
};
