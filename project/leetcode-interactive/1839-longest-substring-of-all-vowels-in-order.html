所有元音按顺序排布的
最长子字符串

Longest Substring Of All Vowels in Order

先理解连续与顺序，再打开下方实验室。题解默认收起，给自己留一点思考空间。

01 / 题目任务

给定仅由英文元音组成的字符串 word，找出最长的“美丽”连续子字符串，返回其长度；不存在时返回 0。

  • a、e、i、o、u 五种元音都至少出现一次。
  • 字符必须按字典序非递减排列：所有 a 在 e 前，所有 e 在 i 前，依次直到 u。同一种元音可以重复。
  • 子字符串必须连续，不能跳过中间字符。

参数：word: string → 返回：integer

约束：1 ≤ word.length ≤ 5 × 105；字符仅限 a、e、i、o、u。

官方示例 1

输入：word = "aeiaaioaaaaeiiiiouuuooaauuaeiu"
输出：13

其中连续片段 aaaaeiiiiouuu 满足要求，长度为 13。

官方示例 2

输入：word = "aeeeiiiioooauuuaeiou"
输出：5

最长符合要求的片段是末尾的 aeiou。

官方示例 3

输入：word = "a"
输出：0

只有一种元音，不满足五种都出现的条件。

04 / 独立题解

核心洞察：把下降点当作分界

美丽子串不可能跨越相邻字符下降的位置。维护以当前位置结尾的最长非递减片段，统计其中不同元音的种类。输入只有五种元音，因此“非递减且种类数等于 5”恰好等价于美丽。

完整过程

  1. 初始化片段起点 start、种类数 kinds、答案 best。
  2. 扫描到首字符或当前字符小于前一个字符时，从当前位置重新开始片段，kinds 设为 1。
  3. 若当前字符大于前一个字符，片段继续延长，kinds 加 1；若相同则只延长长度。
  4. 仅在 kinds 等于 5 时，用 i − start + 1 更新最大长度。

例如 aeiouu：到第一个 u 时有五种元音，长度为 5；下一个 u 不增加种类，但长度增至 6。再遇到 a，顺序下降，新的片段从 a 开始。

正确性

循环不变量：处理下标 i 后，[start, i] 是以 i 结尾的最长非递减片段，kinds 是该片段的不同字符数。下降时任何跨过 i−1 与 i 的子串都不合法，所以重置正确；不下降时可直接延长。严格上升必然引入新字符，因为片段已经非递减。

kinds = 5 时，片段包含全部元音且有序，必然是合法候选。任何合法子串都包含于某个非递减片段，在其右端点处理时，算法考察的最长片段至少一样长且同样包含五种元音。因此不会漏掉最优解；记录的所有候选又均合法，最终答案恰为最优值。

边界与常见错误

  • 长度小于 5、全是同一字符或缺任意元音，结果为 0。
  • 片段可以从 e 或 u 开始，但这种片段永远达不到五种；无需特殊过滤起始字符。
  • 重复字符不是下降点，也不增加种类数。
  • 仅判断有序不够，例如 aeiou 缺少任何一项后仍可能有序，但不能算美丽。
  • 下降时必须同时重置起点与种类；答案长度需加 1。
  • 不得排序 word；排序会破坏原始连续关系。

复杂度

时间 O(n)，每个字符处理一次；额外空间 O(1)。演示为支持回退保存快照，空间 O(m)，且 m ≤ 80；这与提交代码的空间开销不同。

替代方案

可以先按相同字符做游程分组，再寻找相邻的 a、e、i、o、u 五组并求长度和。时间仍为 O(n)，若保存全部组则空间 O(n)，使用五组滚动信息可降至 O(1)。也可用显式五阶段状态机处理重复和阶段切换。逐个枚举起点再向右扫描最坏为 O(n²)，不适合完整约束。

面试追问

  • 如何返回子串？更新 best 时额外记下 start，最后切片。
  • 如何处理数据流？保留前一字符、当前长度、种类数与最大长度即可。
  • 如果允许其他字母？将非法字符视为分界，并显式验证元音；不能直接沿用“种类数为 5”的充分条件。
  • 如果顺序是自定义的？先映射为顺序排名，再比较排名。

四语言提交代码

Java

class Solution {
    public int longestBeautifulSubstring(String word) {
        int start = 0, kinds = 0, best = 0;
        for (int i = 0; i < word.length(); i++) {
            if (i == 0 || word.charAt(i) < word.charAt(i - 1)) {
                start = i;
                kinds = 1;
            } else if (word.charAt(i) > word.charAt(i - 1)) {
                kinds++;
            }
            if (kinds == 5) best = Math.max(best, i - start + 1);
        }
        return best;
    }
}
