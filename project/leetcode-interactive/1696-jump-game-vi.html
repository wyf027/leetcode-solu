跳跃游戏 VI

每一次落点都计分。真正的难点不是“跳多远”，而是如何在不断滑动的可达窗口里，瞬间找到最有价值的前驱。

#1696数组动态规划单调队列非付费题

01 / Problem brief

在有限步长里，拿到最高总分

给定从 0 开始编号的整数数组 nums 和整数 k。你从下标 0 出发，每次可向前跳 1 到 k 步且不能越界，直到到达下标 n − 1。得分是所有到访位置的元素之和，返回可取得的最大得分。

起点必须从 index 0 开始，起点数值计入总分
转移范围从 i 可到 [i + 1, min(n − 1, i + k)]
目标必须到达 index n − 1，并最大化沿途元素和
Example 01
输入：nums = [1,-1,-2,4,-7,3], k = 2
输出：7
解释：选择 1 → -1 → 4 → 3，和为 7。
Example 02
输入：nums = [10,-5,-2,4,0,3], k = 3
输出：17
解释：选择 10 → 4 → 3，和为 17。
Example 03
输入：nums = [1,-5,-20,4,-1,3,-6,-3], k = 2
输出：0

约束

  • 1 ≤ nums.length, k ≤ 10⁵
  • −10⁴ ≤ nums[i] ≤ 10⁴
  • 函数参数：maxResult(nums: integer[], k: integer) → integer

03 / Full solution

动态规划 × 单调递减队列

核心洞察： 令 dp[i] 为到达 i 的最高得分，则 dp[i] = nums[i] + max(dp[j])，其中 i-k ≤ j < i。需要优化的正是“滑动窗口最大值”。

完整过程

初始化

设 dp[0] = nums[0]，把下标 0 放入双端队列。

移除过期前驱

处理 i 时，队首若小于 i-k 就不再可达，持续弹出。

计算当前位置

队首保存窗口内最大的 dp，下式直接得到 dp[i]。

维护单调性

从队尾删除所有 dp ≤ dp[i] 的下标，再把 i 入队。队列中的 dp 严格递减。

边界与不变量

  • n = 1 时无需跳跃，直接返回 nums[0]。
  • 数组可以全为负数；不能把 dp 初始化为 0 来逃避必经位置。
  • k ≥ n − 1 只是窗口更宽，算法无需特判。
  • 队列存下标而非仅存值，才能判断候选是否过期。
O(n)每个下标最多入队、出队各一次
O(n)dp 数组与队列；可原地复用 nums 降至队列 O(k)

Correctness

为什么队首一定可靠

1. 完整性

计算 i 前，所有仍可达且未被支配的下标都留在队列中；超出窗口的下标已从队首移除。

2. 最优性

队列按 dp 严格递减，所以队首是可达窗口中的最大 dp。被队尾移除的旧下标既更早过期，得分又不高于新下标，不可能成为更优前驱。

3. 归纳结论

假设此前 dp 均正确，转移取到了所有合法前驱中的最大值，故 dp[i] 正确。由起点归纳至 n − 1，返回值即全局最优。

Implementations

四种语言，完全相同的不变量

Java
class Solution {
    public int maxResult(int[] nums, int k) {
        int n = nums.length;
        int[] dp = new int[n];
        int[] deque = new int[n];
        int head = 0, tail = 0;
        dp[0] = nums[0];
        deque[tail++] = 0;

        for (int i = 1; i < n; i++) {
            while (head < tail && deque[head] < i - k) head++;
            dp[i] = nums[i] + dp[deque[head]];
            while (head < tail && dp[deque[tail - 1]] <= dp[i]) tail--;
            deque[tail++] = i;
        }
        return dp[n - 1];
    }
}

Python
from collections import deque
from typing import List

class Solution:
    def maxResult(self, nums: List[int], k: int) -> int:
        n = len(nums)
        dp = [0] * n
        dp[0] = nums[0]
        candidates = deque([0])

        for i in range(1, n):
            while candidates[0] < i - k:
                candidates.popleft()
            dp[i] = nums[i] + dp[candidates[0]]
            while candidates and dp[candidates[-1]] <= dp[i]:
                candidates.pop()
            candidates.append(i)
        return dp[-1]
C++
class Solution {
public:
    int maxResult(vector<int>& nums, int k) {
        int n = nums.size();
        vector<int> dp(n);
        deque<int> candidates;
        dp[0] = nums[0];
        candidates.push_back(0);

        for (int i = 1; i < n; ++i) {
            while (candidates.front() < i - k) candidates.pop_front();
            dp[i] = nums[i] + dp[candidates.front()];
            while (!candidates.empty() && dp[candidates.back()] <= dp[i]) {
                candidates.pop_back();
            }
            candidates.push_back(i);
        }
        return dp[n - 1];
    }
};

Alternatives

替代方案

朴素 DP逐个扫描 k 个前驱O(nk)，在 10⁵ 规模会超时
最大堆惰性移除过期下标O(n log n)，更直观但非最优
单调队列维护未被支配的候选O(n)，本题首选

Interview follow-ups

面试追问

  • 如何恢复一条最优跳跃路径？为每个 i 记录转移所用的队首下标，再从终点回溯。
  • 能否省掉 dp 数组？可以原地把 dp 写回 nums，但会修改输入；否则至少需保留队列候选的得分。
  • 为什么相等时也弹出队尾？更新的下标更晚过期，支配旧下标。

Common mistakes

常见错误

先算后过期

必须在读取队首之前删除所有小于 i − k 的下标。

队列存数值

只存 dp 值无法知道它何时离开窗口，应存下标。

误用贪心跳正数

局部最大的 nums 不等于最大的累计 dp，负数也可能是必经点。
