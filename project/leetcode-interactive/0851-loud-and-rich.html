Loud and Rich

财富关系像水流一样沿有向边传递。为每个人找出“确定不比他穷”的人群中，安静值最小的那一位。

中等 MEDIUM有向无环图记忆化 DFS非付费题
Problem

题意

有 n 个人，编号为 0 到 n-1。每个人的财富量不同，安静值也互不相同。

richer[i]=[a,b] 表示 a 比 b 更富；quiet[i] 是第 i 个人的安静值，数值越小越安静。财富关系逻辑自洽，不存在相互更富的矛盾。

返回：answer[x]=y，其中 y 是所有“确定财富不少于 x”的人（包括 x 自己）中安静值最小者。

官方函数形式

loudAndRich(richer: integer[][], quiet: integer[]) → integer[]

Examples

官方示例

示例 1

输入：richer = [[1,0],[2,1],[3,1],[3,7], [4,3],[5,3],[6,3]], quiet = [3,2,5,4,6,1,7,0] 输出：[5,5,2,5,4,5,6,7]

例如 5 比 3 富、3 比 1 富、1 比 0 富，所以 5 是 person 0 的候选人；该候选集合中 5 的安静值最小。

示例 2

输入：richer = [], quiet = [0] 输出：[0]
Bounds

约束

  • n == quiet.length
  • 1 ≤ n ≤ 500
  • 0 ≤ quiet[i] < n
  • quiet 的值互不相同
  • 0 ≤ richer.length ≤ n(n-1)/2
  • 0 ≤ aᵢ,bᵢ < n 且 aᵢ ≠ bᵢ
  • 所有关系对互不相同
  • 财富观察逻辑一致，关系图无环

Solution

记忆化 DFS：每个节点只求一次

核心洞察：将关系反向建图为“较穷 → 较富”。从 x 可达的节点正是确定财富不少于 x 的人；答案是自己与所有直接更富邻居答案中最安静者。

完整过程

01 · 建图对每条 [a,b] 添加边 b→a。
02 · 深搜先令 answer[x]=x，再递归更富邻居。
03 · 合并比较安静值并保留最小者，已有结果直接复用。

正确性证明

  1. 可达集合正确。每条边从较穷者指向较富者，沿路径可达者必然不比起点穷；题目可确定的财富关系也恰由这些边的传递闭包组成。
  2. 递推正确。从 x 可达的人，要么是自己，要么位于某个直接更富邻居的可达集合中。取各集合最优者与自己中安静值最小者，便得到全局最优者。
  3. 终止与完备。逻辑一致保证图无环，递归必然终止；记忆化只消除重复计算。对每个节点调用 DFS 后，所有答案都满足上述递推。

边界

  • 单人或无关系时，答案就是自己。
  • 多条路径汇聚到同一人时，记忆化只计算一次。
  • 链式关系的递归深度最多 n，本题 n≤500。

复杂度

设人数为 n，关系数为 m。

时间：O(n+m)
空间：O(n+m)，含图、答案与递归栈。

四语言完整代码

import java.util.*;
class Solution {
    private List<Integer>[] graph;
    private int[] quiet, answer;
    public int[] loudAndRich(int[][] richer, int[] quiet) {
        int n = quiet.length;
        this.quiet = quiet;
        answer = new int[n];
        Arrays.fill(answer, -1);
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : richer) graph[edge[1]].add(edge[0]);
        for (int i = 0; i < n; i++) dfs(i);
        return answer;
    }
    private int dfs(int x) {
        if (answer[x] != -1) return answer[x];
        answer[x] = x;
        for (int y : graph[x]) {
            int candidate = dfs(y);
            if (quiet[candidate] < quiet[answer[x]]) answer[x] = candidate;
        }
        return answer[x];
    }
}

    const n = quiet.length;
    const graph = Array.from({ length: n }, () => []);
    const answer = new Array(n).fill(-1);
    for (const [rich, poor] of richer) graph[poor].push(rich);
    const dfs = (x) => {
        if (answer[x] !== -1) return answer[x];
        answer[x] = x;
        for (const y of graph[x]) {
            const candidate = dfs(y);
            if (quiet[candidate] < quiet[answer[x]]) answer[x] = candidate;
        }
        return answer[x];
    };
    for (let i = 0; i < n; i++) dfs(i);
    return answer;
};

class Solution {
    vector<vector<int>> graph;
    vector<int> answer;
    vector<int>* quiet;
    int dfs(int x) {
        if (answer[x] != -1) return answer[x];
        answer[x] = x;
        for (int y : graph[x]) {
            int candidate = dfs(y);
            if ((*quiet)[candidate] < (*quiet)[answer[x]])
                answer[x] = candidate;
        }
        return answer[x];
    }
public:
    vector<int> loudAndRich(
        vector<vector<int>>& richer, vector<int>& quietValues
    ) {
        int n = quietValues.size();
        graph.assign(n, {});
        answer.assign(n, -1);
        quiet = &quietValues;
        for (const auto& edge : richer) graph[edge[1]].push_back(edge[0]);
        for (int i = 0; i < n; ++i) dfs(i);
        return answer;
    }

替代方案

拓扑排序：按从富到穷传播最安静者，同样是 O(n+m)，可避免递归栈。

每人独立搜索：直观但重复遍历，最坏约 O(n(n+m))。

面试追问

  • 关系若可能有环，如何用 SCC 缩点？
  • 安静值若重复，怎样定义稳定的平局规则？
  • 动态加入关系时，如何做增量更新？

常见错误

  • 将边建反：搜索方向应为“穷 → 富”。
  • 忘记自己也是候选人。
  • 比较编号而非 quiet[candidate]。
  • 只看直接邻居，忽略传递关系。
  • 不做记忆化，导致 DAG 汇聚处重复递归。
