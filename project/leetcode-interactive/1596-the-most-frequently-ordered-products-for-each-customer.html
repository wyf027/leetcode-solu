每位顾客最经常订购的商品

从订单流水中找出每位有订单顾客的最高频商品；若最高次数并列，必须完整保留所有并列商品。

Problem brief

题目描述

关系数据库

给定顾客表 Customers、订单表 Orders 和商品表 Products。一条订单记录表示某位顾客在给定日期订购了一件商品。

找出每位至少有一笔订单的顾客订购次数最多的商品，返回 customer_id、product_id、product_name。最高次数并列时全部返回；结果顺序不限。

关键语义：统计粒度是“顾客 × 商品”。顾客 2 的三件商品若各订购一次，三件都属于最高频结果。

Contract

约束与返回规则

  • 三张表分别以 customer_id、order_id、product_id 唯一标识记录。
  • Orders 中的顾客与商品编号对应各自主表中的有效记录；每行计为一次订购。
  • 只返回有订单的顾客；未下单顾客不产生结果。
  • 同一顾客最高频并列时必须保留全部并列项；返回顺序不限。
Solution vault

题解

默认隐藏

核心洞察

先得到每个 (customer_id, product_id) 的次数，再在每位顾客内部比较。窗口函数 RANK() 让并列第一都获得排名 1。

完整过程

  1. 按顾客和商品分组并 COUNT(*)。
  2. 按顾客分区、次数降序计算 RANK。
  3. 筛选排名 1，关联 Products 获取商品名。

正确性

分组计数精确得到每位顾客订购每种商品的次数。对固定顾客按次数降序排名，所有达到最大次数的商品且仅有这些商品排名为 1；筛选排名 1 因而恰好保留全部最高频商品。关联 Products 只补充由主键确定的商品名，不改变入选集合，所以结果正确。

边界

  • 只有一笔订单：对应商品入选。
  • 所有商品等频：全部入选。
  • 没有订单的顾客：不输出。
  • 各顾客独立：窗口按 customer_id 分区。

复杂度

设订单数为 n，典型逻辑工作量 O(n log n)，实际取决于数据库执行计划与索引；中间空间 O(g)，g 为出现过的“顾客 × 商品”组合数。

MySQL 8.0+（官方可提交方案）

WITH product_counts AS (
  SELECT customer_id, product_id, COUNT(*) AS order_count
  FROM Orders
  GROUP BY customer_id, product_id
),
ranked_products AS (
  SELECT customer_id, product_id,
         RANK() OVER (
           PARTITION BY customer_id
           ORDER BY order_count DESC
         ) AS frequency_rank
  FROM product_counts
)
SELECT r.customer_id, r.product_id, p.product_name
FROM ranked_products AS r
JOIN Products AS p ON p.product_id = r.product_id
WHERE r.frequency_rank = 1;

替代方案

不支持窗口函数时，可对分组计数结果使用相关子查询，以当前次数等于该顾客最大次数来过滤。DENSE_RANK() 筛第一名时等价；不要用 ROW_NUMBER()，它会拆散并列。

Java（本地语义参考）

import java.util.*;

class SolutionReference {
  record Order(int orderId, String date, int customerId, int productId) {}
  record Product(int productId, String name, int price) {}
  record Result(int customerId, int productId, String productName) {}

  static List<Result> solve(List<Order> orders, List<Product> products) {
    Map<Integer,String> names = new HashMap<>();
    for (Product p : products) names.put(p.productId(), p.name());
    Map<Integer,Map<Integer,Integer>> counts = new TreeMap<>();
    for (Order o : orders)
      counts.computeIfAbsent(o.customerId(), k -> new TreeMap<>())
            .merge(o.productId(), 1, Integer::sum);
    List<Result> answer = new ArrayList<>();
    for (var customer : counts.entrySet()) {
      int best = Collections.max(customer.getValue().values());
      for (var product : customer.getValue().entrySet())
        if (product.getValue() == best)
          answer.add(new Result(customer.getKey(), product.getKey(),
                                names.get(product.getKey())));
    }
    return answer;
  }
}

JavaScript（本地语义参考）

function mostFrequentProducts(orders, products) {
  const names = new Map(products.map(p => [p.product_id, p.product_name]));
  const counts = new Map();
  for (const order of orders) {
    if (!counts.has(order.customer_id)) counts.set(order.customer_id, new Map());
    const byProduct = counts.get(order.customer_id);
    byProduct.set(order.product_id, (byProduct.get(order.product_id) || 0) + 1);
  }
  const answer = [];
  for (const customerId of [...counts.keys()].sort((a, b) => a - b)) {
    const byProduct = counts.get(customerId);
    const best = Math.max(...byProduct.values());
    for (const [productId, count] of [...byProduct].sort((a, b) => a[0] - b[0]))
      if (count === best)
        answer.push({customer_id: customerId, product_id: productId,
                     product_name: names.get(productId)});
  }
  return answer;
}

Python（本地语义参考）

from collections import Counter, defaultdict

def most_frequent_products(orders, products):
    names = {p["product_id"]: p["product_name"] for p in products}
    counts = defaultdict(Counter)
    for order in orders:
        counts[order["customer_id"]][order["product_id"]] += 1

    answer = []
    for customer_id in sorted(counts):
        best = max(counts[customer_id].values())
        for product_id in sorted(counts[customer_id]):
            if counts[customer_id][product_id] == best:
                answer.append({
                    "customer_id": customer_id,
                    "product_id": product_id,
                    "product_name": names[product_id],
                })
    return answer

C++（本地语义参考）

#include <algorithm>
#include <map>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

struct Order { int orderId; string date; int customerId; int productId; };
struct Product { int productId; string name; int price; };
using Result = tuple<int,int,string>;

vector<Result> solve(const vector<Order>& orders,
                     const vector<Product>& products) {
  map<int,string> names;
  for (const auto& p : products) names[p.productId] = p.name;
  map<int,map<int,int>> counts;
  for (const auto& o : orders) ++counts[o.customerId][o.productId];

  vector<Result> answer;
  for (const auto& [customerId, byProduct] : counts) {
    int best = 0;
    for (const auto& [productId, count] : byProduct)
      best = max(best, count);
    for (const auto& [productId, count] : byProduct)
      if (count == best)
        answer.emplace_back(customerId, productId, names[productId]);
  }
  return answer;
}
