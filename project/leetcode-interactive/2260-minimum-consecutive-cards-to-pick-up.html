必须拿起的最小连续卡牌数

Minimum Consecutive Cards to Pick Up

一排卡牌，一段连续区间。你需要拿起多少张，才能至少得到一对相同的牌？

01 / PROBLEM

题目与约束

给定整数数组 cards，cards[i] 是第 i 张卡牌的值。值相同的两张牌组成一对匹配牌。请选择一个连续子数组，使其中至少有一对匹配牌，并返回这种子数组的最小长度。如果整副牌没有重复值，返回 -1。

必须把两端之间的所有牌一起拿起。只抽出两张相同的牌，不一定满足“连续”。

  • 1 <= cards.length <= 105
  • 0 <= cards[i] <= 106

参数：cards: integer[] · 返回：integer · 函数名：minimumCardPickup

官方示例 1

输入：cards = [3,4,2,3,4,7]
输出：4

连续拿起 [3,4,2,3]，其中两张 3 匹配；[4,2,3,4] 也是长度为 4 的最优选择。

官方示例 2

输入：cards = [1,0,5,3]
输出：-1

所有牌的值都不同，任何连续区间都无法包含匹配牌。

04 / SOLUTION LAB

只记住每个值最近出现的位置

若当前下标为 i，同值牌上次出现在 p，区间 [p,i] 的长度就是 i - p + 1。固定右端点时，越靠近它的同值牌，形成的区间越短。因此每个值只需要记住最近的下标。

完整过程

  1. 初始化空哈希表 last，最短长度设为无穷大。
  2. 从左到右枚举 cards[i]；若表中已存在该值，用 i - last[value] + 1 更新答案。
  3. 无论是否匹配，都把 last[value] 改为 i，留给下一次相同值使用。
  4. 遍历结束仍无候选区间则返回 -1，否则返回最小长度。

示例 1 中，i = 3 时，3 的上次位置是 0，得到长度 4；i = 4 时，4 的上次位置是 1，同样得到长度 4；最终答案为 4。

正确性证明

不变式：处理下标 i 之前，last 保存前缀 [0,i-1] 中每个已出现值的最大下标，答案保存此前所有候选区间长度的最小值。空前缀时成立；每一步先查询再更新，保持这一性质。

最优性：任何合法区间都包含某对相同值的牌，设它们在 p < i。这对牌之间的区间也合法，且不会比原区间更长。处理 i 时，最近同值位置 q 满足 q ≥ p，故候选长度 i-q+1 ≤ i-p+1。于是算法对任意最优区间都能找到一个不更长的合法候选，而所有候选本身都是合法区间，因此所取最小值恰为全局最优。没有候选就意味着没有重复值，返回 -1 正确。

边界与复杂度

  • 仅一张牌或所有值不同：返回 -1。
  • 相邻同值或全部同值：答案为 2，这是理论下界，可提前返回。
  • 数值 0 和下标 0 都有效，必须判断键是否存在。
  • 设 n 为牌数、k 为不同值个数：哈希表平均时间 O(n)，额外空间 O(k)，最多 O(n)。这是常规哈希操作期望 O(1) 下的分析，不是所有哈希实现最坏情形的保证。

替代方案

滑动窗口：用集合维护没有重复值的窗口。右端加入的值若已存在，不断移除左端，直到旧的相同值被移出；移出它之前的窗口长度就是候选长度。每个元素至多进入、移出一次，平均时间 O(n)、空间 O(k)。最近位置法更直接。

位置分组：为每个值保存全部出现位置，仅比较相邻位置之差加一；时间 O(n)、空间 O(n)，保存了更多信息。暴力枚举左端并寻找首次重复需要 O(n²) 最坏时间，不适合 10⁵ 的规模。

值域数组：使用长度 1000001、初始值为 -1 的位置数组替代哈希表；查询更新最坏 O(1)，但初始化和空间均与值域 U 相关，总时间 O(n+U)、空间 O(U)。

常见错误

  • 写成 i-p：漏掉一个端点，连续牌数应为 i-p+1。
  • 先更新 last 再计算：会和当前牌自身比较，错误得到 1。
  • 一直保留首次位置：如 [1,2,3,1,1]，会错过最后两张组成的长度 2。
  • JavaScript 用 if (last.get(value))：会漏掉下标 0；应使用 last.has(value)。
  • 排序 cards：破坏原始连续关系。

面试追问

  • 怎样返回区间？更新答案时同步保存 [last[value], i]；并列时按题目要求保留一个或收集全部。
  • 数据流能做吗？可以，保存当前位置、最近位置表和当前答案，无须保留全部卡牌。
  • 需要同值牌至少出现 m 次呢？为每个值维护最近 m 个位置的队列；数量达到 m 时，以队首和当前位置形成候选区间。
  • 为什么相邻出现位置足够？任何跨过中间同值牌的区间，都能缩短为相邻两次出现的位置区间。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int minimumCardPickup(int[] cards) {
        Map<Integer, Integer> last = new HashMap<>();
        int best = Integer.MAX_VALUE;
        for (int i = 0; i < cards.length; i++) {
            Integer previous = last.get(cards[i]);
            if (previous != null) {
                best = Math.min(best, i - previous + 1);
            }
            last.put(cards[i], i);
        }
        return best == Integer.MAX_VALUE ? -1 : best;
    }
}

    let best = Infinity;
    for (let i = 0; i < cards.length; i++) {
        const value = cards[i];

};

Python 3

from typing import List

class Solution:
    def minimumCardPickup(self, cards: List[int]) -> int:
        last = {}
        best = len(cards) + 1
        for i, value in enumerate(cards):
            if value in last:
                best = min(best, i - last[value] + 1)
            last[value] = i
        return -1 if best == len(cards) + 1 else best

C++

#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int minimumCardPickup(vector<int>& cards) {
        unordered_map<int, int> last;
        int n = static_cast<int>(cards.size());
        int best = n + 1;
        for (int i = 0; i < n; ++i) {
            auto it = last.find(cards[i]);
            if (it != last.end()) {
                best = min(best, i - it->second + 1);
            }
            last[cards[i]] = i;
        }
        return best == n + 1 ? -1 : best;
    }
};
