Problem 591标签验证器

判断一段类 XML 代码是否只有一个完整根标签，并且标签、嵌套与 CDATA 都严格闭合。先读规则、亲手拆解样例，再决定是否展开题解。

Official signature
isValid(code: string): boolean

输入长度最多 500。真正棘手的地方不是识别尖括号，而是确保根标签唯一、嵌套顺序正确，并让 CDATA 内的一切保持“不可解析”。

01 · Problem brief

合法代码的八条边界

给定字符串 code，实现验证器并返回它是否合法。下面是对官方规则的准确转述；这些条件需要同时成立。

01

必须有且仅有一个完整外壳

整段代码必须被一个合法闭合标签包住；根标签结束后不能再出现文字、CDATA 或第二个标签。

02

起止标签必须同名

闭合结构严格形如 <TAG_NAME>TAG_CONTENT</TAG_NAME>。起始与结束标签名一致，标签名和内容也都必须合法。

03

标签名只允许大写字母

TAG_NAME 长度为 1 到 9，且每个字符都在 A-Z 中；空名、小写、数字或超长名称都非法。

04

内容可混合三种成分

合法内容可以包含普通字符、其他合法闭合标签与 CDATA，但不能出现孤立的 <、无匹配标签或非法标签名。

05

嵌套顺序同样重要

起始标签必须由同名结束标签匹配；后打开的内层标签必须先关闭，交叉闭合不合法。

06

尖括号触发完整标签解析

遇到 < 或 </ 后，直到下一个 > 的全部字符都会作为标签名；找不到 > 则非法。

07

CDATA 在第一个终止符结束

CDATA 严格形如 <![CDATA[CDATA_CONTENT]]>，内容范围到后续第一个 ]]> 为止。

08

CDATA 内容完全不解析

CDATA 内可以出现任意字符。即便其中看起来像非法或未闭合标签，也只能当普通文本处理；但 CDATA 本身必须位于已打开标签内。

示例 1 · CDATA 隔离标签文本

输入

true

外层 DIV 合法闭合；CDATA 中的 <div> 不参与标签解析，因此不会因小写标签名而失败。

示例 2 · 第一个 CDATA 终止符

输入
code = "<DIV>>>  ![cdata[]] <![CDATA[<div>]>]]>]]>>]</DIV>"
输出
true

内容可拆为普通文本、<![CDATA[<div>]>]]> 与后续普通文本。CDATA 在遇到的第一个 ]]> 处结束。

示例 3 · 交叉闭合

输入
code = "<A>  <B> </A>   </B>"
输出
false

打开顺序是 A → B，因此必须先关闭 B。此处先遇到 </A>，嵌套不平衡。

约束

  • 1 <= code.length <= 500
  • code 只包含英文字母、数字、<、>、/、!、[、]、. 与空格。

核心洞察

从左到右扫描时，只有最近打开且尚未关闭的标签能被当前结束标签匹配。因此，用栈保存未闭合标签名：起始标签入栈，结束标签必须匹配栈顶后出栈；CDATA 则整体跳过。

扫描不变量：处理到位置 i 之前，栈从底到顶恰好记录从根到当前最内层、仍待关闭的合法标签。

还要额外维护“唯一根”规则：输入必须从标签开始；一旦根标签出栈，若字符串尚未结束，立即判为非法。CDATA 只有在栈非空时才允许出现。

完整过程

  1. 先排除空字符串或首字符不是 < 的情况。
  2. 令扫描指针 i = 0，并创建空栈。
  3. 每轮开始时，若 i > 0、栈已空但仍有未处理字符，说明根标签已经结束，返回 false。
  4. 若当前位置以 <![CDATA[ 开头：要求栈非空，查找第一个 ]]>；找不到则失败，找到后直接把指针移到其后。
  5. 若当前位置以 </ 开头：找到下一个 >，验证其中的标签名；它必须等于栈顶，然后弹栈。
  6. 若当前位置是普通 <：找到下一个 >，验证标签名并入栈。
  7. 否则当前位置是普通文本，指针右移；文本只有在根标签内部才能继续存在，这由轮首的栈检查保证。
  8. 扫描结束时，只有栈恰好为空才返回 true。

正确性证明

引理 1：栈始终准确表示未闭合标签

初始没有处理字符，栈为空，结论成立。处理合法起始标签时将其压入栈，它正是新出现的最内层未闭合标签；处理结束标签时，只允许它等于栈顶并弹出，因此不会发生交叉闭合。普通文本和 CDATA 不改变标签层级。由归纳法，不变量在每一步后成立。

引理 2：CDATA 不会误伤或放过外部结构

只有在某个标签已经打开时才接受 CDATA，并严格跳到后续第一个 ]]>。因此 CDATA 内字符从不被当作标签，而其外部任何字符也不会被过度吞掉。

引理 3：算法接受时存在且只存在一个根标签

输入必须以 < 开始；CDATA 不能作为根。根标签关闭后，只要还有字符，轮首检查就会拒绝。扫描完成又要求栈为空，所以存在一个完整闭合的根标签，且根外没有内容。

定理

若算法返回真，由三个引理可知标签名合法、嵌套匹配、CDATA 边界正确且唯一根完整，故代码合法。反之，任意合法代码按规则扫描时，每个分支都能找到对应终止位置，结束标签总匹配栈顶，根恰在末尾关闭，算法不会拒绝且最终栈空，故算法必返回真。

边界与复杂度

O(n)时间。每段标签或 CDATA 都使指针单调前进。
O(n)空间。最坏情况下全部字符组成深层嵌套标签。
  • 空输入、纯文本、CDATA 作为根：非法。
  • <A></A>：最短的典型合法结构。
  • 空标签名、长度超过 9、小写、数字或符号：非法。
  • 缺少 >、CDATA 缺少 ]]>：非法。
  • 根标签闭合后出现空格也非法，因为空格仍是根外内容。

替代方案

递归下降解析

可以写 parseTag 递归解析一个完整标签，逻辑贴近文法；但需要谨慎处理共享指针、CDATA 和根外内容，深嵌套还会占用调用栈。

先移除 CDATA，再用正则反复消去闭合标签

这种写法短，但很容易在 CDATA 首个终止符、标签名边界与嵌套替换上出错；反复替换也可能退化到 O(n²)。单次扫描更直接、可证且适合面试表达。

class Solution {
    public boolean isValid(String code) {
        int n = code.length();
        if (n == 0 || code.charAt(0) != '<') return false;

        java.util.Deque<String> stack = new java.util.ArrayDeque<>();
        int i = 0;

        while (i < n) {
            if (i > 0 && stack.isEmpty()) return false;

            if (code.startsWith("<![CDATA[", i)) {
                if (stack.isEmpty()) return false;
                int end = code.indexOf("]]>", i + 9);
                if (end == -1) return false;
                i = end + 3;
            } else if (code.startsWith("</", i)) {
                int end = code.indexOf('>', i + 2);
                if (end == -1) return false;
                String name = code.substring(i + 2, end);
                if (!validName(name) || stack.isEmpty()
                        || !stack.pop().equals(name)) {
                    return false;
                }
                i = end + 1;
            } else if (code.charAt(i) == '<') {
                int end = code.indexOf('>', i + 1);
                if (end == -1) return false;
                String name = code.substring(i + 1, end);
                if (!validName(name)) return false;
                stack.push(name);
                i = end + 1;
            } else {
                i++;
            }
        }

        return stack.isEmpty();
    }

    private boolean validName(String name) {
        if (name.length() < 1 || name.length() > 9) return false;
        for (int i = 0; i < name.length(); i++) {
            char c = name.charAt(i);
            if (c < 'A' || c > 'Z') return false;
        }
        return true;
    }
}

/**
 * @param {string} code
 * @return {boolean}

var isValid = function(code) {
    const n = code.length;
    if (n === 0 || code[0] !== '<') return false;

    const stack = [];
    let i = 0;

    const validName = (name) => {
        if (name.length < 1 || name.length > 9) return false;
        for (const ch of name) {
            if (ch < 'A' || ch > 'Z') return false;
        }
        return true;
    };

    while (i < n) {
        if (i > 0 && stack.length === 0) return false;

        if (code.startsWith('<![CDATA[', i)) {
            if (stack.length === 0) return false;
            const end = code.indexOf(']]>', i + 9);
            if (end === -1) return false;
            i = end + 3;
        } else if (code.startsWith('</', i)) {
            const end = code.indexOf('>', i + 2);
            if (end === -1) return false;
            const name = code.slice(i + 2, end);
            if (!validName(name) || stack.pop() !== name) return false;
            i = end + 1;
        } else if (code[i] === '<') {
            const end = code.indexOf('>', i + 1);
            if (end === -1) return false;
            const name = code.slice(i + 1, end);
            if (!validName(name)) return false;
            stack.push(name);
            i = end + 1;
        } else {
            i++;
        }
    }

    return stack.length === 0;
};

class Solution:
    def isValid(self, code: str) -> bool:
        n = len(code)
        if n == 0 or code[0] != '<':
            return False

        stack = []
        i = 0

        def valid_name(name: str) -> bool:
            return 1 <= len(name) <= 9 and all(
                'A' <= ch <= 'Z' for ch in name
            )

        while i < n:
            if i > 0 and not stack:
                return False

            if code.startswith('<![CDATA[', i):
                if not stack:
                    return False
                end = code.find(']]>', i + 9)
                if end == -1:
                    return False
                i = end + 3
            elif code.startswith('</', i):
                end = code.find('>', i + 2)
                if end == -1:
                    return False
                name = code[i + 2:end]
                if not valid_name(name) or not stack or stack.pop() != name:
                    return False
                i = end + 1
            elif code[i] == '<':
                end = code.find('>', i + 1)
                if end == -1:
                    return False
                name = code[i + 1:end]
                if not valid_name(name):
                    return False
                stack.append(name)
                i = end + 1
            else:
                i += 1

        return not stack

class Solution {
public:
    bool isValid(string code) {
        int n = static_cast<int>(code.size());
        if (n == 0 || code[0] != '<') return false;

        vector<string> stack;
        int i = 0;

        while (i < n) {
            if (i > 0 && stack.empty()) return false;

            if (code.compare(i, 9, "<![CDATA[") == 0) {
                if (stack.empty()) return false;
                size_t end = code.find("]]>", i + 9);
                if (end == string::npos) return false;
                i = static_cast<int>(end) + 3;
            } else if (code.compare(i, 2, "</") == 0) {
                size_t end = code.find('>', i + 2);
                if (end == string::npos) return false;
                string name = code.substr(i + 2, end - i - 2);
                if (!validName(name) || stack.empty()
                        || stack.back() != name) {
                    return false;
                }
                stack.pop_back();
                i = static_cast<int>(end) + 1;
            } else if (code[i] == '<') {
                size_t end = code.find('>', i + 1);
                if (end == string::npos) return false;
                string name = code.substr(i + 1, end - i - 1);
                if (!validName(name)) return false;
                stack.push_back(name);
                i = static_cast<int>(end) + 1;
            } else {
                ++i;
            }
        }

        return stack.empty();
    }

private:
    bool validName(const string& name) {
        if (name.empty() || name.size() > 9) return false;
        for (char ch : name) {
            if (ch < 'A' || ch > 'Z') return false;
        }
        return true;
    }
};

面试追问

  • 为什么根标签关闭时要立即结束？ 因为规则要求整段代码被一个闭合标签包围；任何后续字符都在根外。
  • 为什么结束标签只和栈顶比较？ 合法嵌套必须遵循后进先出；和更早的标签匹配会造成交叉闭合。
  • 如何流式处理超长输入？ 标签和普通文本可增量扫描，但 CDATA 终止符与标签尾部可能跨块，需要保留少量边界状态；栈仍然必要。
  • 能否做到 O(1) 额外空间？ 一般不能，因为需要记住任意深度的标签名；若允许修改输入，可讨论原地编码，但实现复杂且仍需保存边界信息。

常见错误

  • 只检查最终栈为空，误把 <A></A><B></B> 当作合法。
  • 允许 CDATA 出现在根外，或继续解析 CDATA 内看似标签的文本。
  • 寻找最后一个而不是第一个 ]]>，吞掉本应作为普通文本的内容。
  • 用宽泛正则验证标签名，意外接受小写、数字、下划线或 10 个以上字符。
  • 结束标签先弹栈再检查栈是否为空，导致空栈访问或错误匹配。
  • 忘记处理找不到 > 或 ]]> 的情况。
