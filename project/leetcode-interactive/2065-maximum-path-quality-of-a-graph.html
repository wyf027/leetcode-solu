01 / 任务说明

在时间限制内，找到价值最大的闭合行走

给定一张有 n 个节点的无向图，编号为 0 … n−1。数组 values[i] 表示节点 i 的价值；每条边 edges[j] = [u_j, v_j, time_j] 表示两个端点之间可双向通行，每次经过都消耗 time_j 秒。另给定时间上限 maxTime。返回所有从 0 出发、回到 0 且总耗时不超过上限的行走中，不同已访问节点价值之和的最大值。允许多次访问同一节点、重复经过同一条边，也允许停留在 0 不移动。

maximalPathQuality(values, edges, maxTime) → integer

规模与范围

  • n == values.length，1 ≤ n ≤ 1000
  • 0 ≤ values[i] ≤ 10⁸
  • 0 ≤ edges.length ≤ 2000
  • edges[j].length == 3
  • 0 ≤ u_j < v_j ≤ n−1
  • 10 ≤ time_j ≤ 100，10 ≤ maxTime ≤ 100

图的保证

  • 所有端点对 [u_j, v_j] 互不相同。
  • 每个节点最多连接 4 条边。
  • 图可能不连通。
  • 返回的是最大价值，不要求输出路径。

包含推导、证明与四语言完整提交代码。

有时间上限的 DFS 回溯

核心洞察：图很大，行走却很短

最多有 1000 个节点，不适合对全图节点集合做状态压缩。但每条边至少消耗 10 秒，总时间最多 100 秒，因此最多走 10 条边；每一步最多 4 个选择。直接枚举时间预算内的行走即可。无需禁止环，正的边权已经限制递归深度。

用 count[v] 记录节点 v 在当前递归路径中出现的次数。仅当进入前计数为 0，才把 values[v] 加入当前价值。离开分支时减回计数。每次到达 0 就尝试更新答案，随后仍可继续探索。

完整过程

  1. 建立双向邻接表，边同时存入两个端点的列表。
  2. 令 count[0] = 1，初始答案与价值均为 values[0]；从 dfs(0, 0, values[0]) 出发。
  3. 在 dfs(u, elapsed, score) 中，如果 u == 0，更新最大合法路径价值。不要在这里直接返回。
  4. 逐条考虑边 (u, v, cost)。如果 elapsed + cost > maxTime，跳过该边。
  5. 先根据 count[v] == 0 算出新增价值，再增加计数，递归探索下一个节点。
  6. 递归返回后执行 count[v]--，让同层下一个分支看到进入当前分支之前的访问状态。
路径 0 → 1 → 0 → 3 → 0 中，节点 0 的访问计数依次为 1、1、2、2、3，价值只在初始化计入一次。撤销最后一次递归时计数从 3 恢复成 2，而不是直接清零。

示例 1 的搜索片段

分支 0 → 1 得到价值 32、耗时 10；继续到 2 时价值 42、耗时 25，但这还不是答案，因为不在起点。即使回到 1，耗时也已达 40，再走向 0 会耗时 50，因此这一条回程被剪枝。

撤销该分支后，枚举 0 → 1 → 0，耗时 20，合法价值为 32。继续走 3 再返回 0，耗时 40，合法价值更新为 75。返回起点是一个可记录的候选状态，并非必须停止的终点。

正确性证明

不变量。每次进入 DFS 时，elapsed 等于当前行走所有边的耗时和，count 恰好记录当前行走各节点的出现次数，score 恰好是其中不同节点的价值之和。初始状态满足；转移按首次出现加分、按经过的边增加时间，并在递归后恢复计数，因此不变量始终成立。

合法性。算法只递归到未超时状态，且只在当前节点为 0 时记录答案。根据不变量，记录的每个候选值都来自一条符合要求的闭合行走。

完备性。任取合法行走，它的每个前缀耗时均不超过 maxTime，因为边权为正。DFS 枚举当前节点的全部邻边，并允许重访，所以不会跳过该行走的任何一步，最终必然枚举其终点并记录其价值。

终止与最优性。每次递归至少增加 10 秒，深度最多 10，搜索有限。所有候选合法且所有合法行走都被覆盖，对候选取最大值便得到最优答案。

边界处理

  • 没有边或起点孤立：答案是 values[0]。
  • 到邻居后无法返回：该状态不能更新答案。
  • 时间恰好等于上限：仍然合法，剪枝必须使用 >。
  • 价值为 0：仍按普通节点记录计数，不能用价值判断是否访问。
  • 不连通：只会遍历 0 所在连通分量。
  • 最多经过 10 条边，至多访问 11 个不同节点；价值上界 11 × 10⁸，小于 32 位有符号整数上限，Java/C++ 的 int 足够。

复杂度

设 n 为节点数、m 为边数、D = ⌊maxTime / 10⌋ ≤ 10。递归树节点数至多 1 + 4 + … + 4ᴰ。

时间：O(n + m + 4ᴰ)。每个递归状态最多检查 4 条邻边；建立邻接表需要 O(n + m)。

空间：O(n + m + D)。邻接表和计数数组占 O(n + m)，递归栈深度最多 D + 1。不保存所有路径。

替代方案与适用条件

Dijkstra + 回程剪枝：先求每个节点回到 0 的最短耗时 dist。准备走向 v 时，如果 elapsed + cost + dist[v] > maxTime，就可以跳过；连最短回程都来不及，该分支不可能构成合法答案。优先队列实现增加 O((n + m) log n) 预处理，可减少实际搜索，但不会消除最坏指数枚举。当前小深度约束下，下面代码使用直接时间剪枝。

状态压缩 DP：若可访问的节点总数很小，可以把已访问集合纳入状态；原题 n 可达 1000，不能直接开 2ⁿ 状态。只记 (节点, 时间) 会遗漏“哪些价值已经收过”，不能替代本题的路径状态。

常见错误

  • 把访问过的节点永久标记为不可进入，导致无法返回起点或重复经过中间节点。
  • 每次访问都累加价值，或进入起点时漏算起点价值。
  • 到 0 后立刻 return，错过经由起点串联多个分支的更好行走。
  • 在任意节点更新答案，把无法返回的高价值前缀当成解。
  • 回溯时忘记恢复 count，污染后续兄弟分支；或用赋值 0 破坏仍在路径上的重复节点。
  • 看到“图”就只求最短路；最短路可帮助剪枝，但不是最大去重价值的直接答案。

面试追问

如果 maxTime 很大呢？深度界失效，枚举会迅速膨胀，需要结合可达节点规模、状态压缩或更强剪枝重新设计，不能保证当前方法仍然高效。

为什么不用普通布尔 visited？可以在进入时记录“是否首次访问”并只在首次访问的退出处恢复；访问次数写法更直接地表达嵌套重访，避免错误清除祖先状态。

怎样返回一条最优路径？额外维护当前路径栈，只在回到 0 且价值严格改善时复制它。无需保存每一条搜索路径。

能缓存 (u, time, score) 吗？不够。分值相同也可能已收集了不同节点，后续新增价值不同；必须考虑影响未来收益的已访问集合。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    private List<int[]>[] graph;
    private int[] values, count;
    private int limit, answer;

    public int maximalPathQuality(int[] values, int[][] edges, int maxTime) {
        this.values = values;
        limit = maxTime;
        answer = values[0];
        int n = values.length;
        graph = new List[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : edges) {
            graph[edge[0]].add(new int[]{edge[1], edge[2]});
            graph[edge[1]].add(new int[]{edge[0], edge[2]});
        }
        count = new int[n];
        count[0] = 1;
        dfs(0, 0, values[0]);
        return answer;
    }

    private void dfs(int u, int elapsed, int score) {
        if (u == 0) answer = Math.max(answer, score);
        for (int[] edge : graph[u]) {
            int v = edge[0], cost = edge[1];
            if (elapsed + cost > limit) continue;
            int gain = count[v] == 0 ? values[v] : 0;
            count[v]++;
            dfs(v, elapsed + cost, score + gain);
            count[v]--;
        }
    }
}

/**
 * @param {number[]} values
 * @param {number[][]} edges
 * @param {number} maxTime
 * @return {number}
 */
var maximalPathQuality = function(values, edges, maxTime) {
    const graph = Array.from({ length: values.length }, () => []);
    for (const [u, v, time] of edges) {
        graph[u].push([v, time]);
        graph[v].push([u, time]);
    }
    const count = Array(values.length).fill(0);
    count[0] = 1;
    let answer = values[0];

    function dfs(u, elapsed, score) {
        if (u === 0) answer = Math.max(answer, score);
        for (const [v, cost] of graph[u]) {
            if (elapsed + cost > maxTime) continue;
            const gain = count[v] === 0 ? values[v] : 0;
            count[v]++;
            dfs(v, elapsed + cost, score + gain);
            count[v]--;
        }
    }

    dfs(0, 0, values[0]);
    return answer;
};

from typing import List


class Solution:
    def maximalPathQuality(self, values: List[int],
                           edges: List[List[int]], maxTime: int) -> int:
        graph = [[] for _ in values]
        for u, v, time in edges:
            graph[u].append((v, time))
            graph[v].append((u, time))
        count = [0] * len(values)
        count[0] = 1
        answer = values[0]

        def dfs(u: int, elapsed: int, score: int) -> None:
            nonlocal answer
            if u == 0:
                answer = max(answer, score)
            for v, cost in graph[u]:
                if elapsed + cost > maxTime:
                    continue
                gain = values[v] if count[v] == 0 else 0
                count[v] += 1
                dfs(v, elapsed + cost, score + gain)
                count[v] -= 1

        dfs(0, 0, values[0])
        return answer

C++

#include <algorithm>
#include <functional>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int maximalPathQuality(vector<int>& values,
                           vector<vector<int>>& edges, int maxTime) {
        vector<vector<pair<int, int>>> graph(values.size());
        for (const auto& edge : edges) {
            graph[edge[0]].push_back({edge[1], edge[2]});
            graph[edge[1]].push_back({edge[0], edge[2]});
        }
        vector<int> count(values.size(), 0);
        count[0] = 1;
        int answer = values[0];
        function<void(int, int, int)> dfs = [&](int u, int elapsed, int score) {
            if (u == 0) answer = max(answer, score);
            for (const auto& edge : graph[u]) {
                int v = edge.first, cost = edge.second;
                if (elapsed + cost > maxTime) continue;
                int gain = count[v] == 0 ? values[v] : 0;
                ++count[v];
                dfs(v, elapsed + cost, score + gain);
                --count[v];
            }
        };
        dfs(0, 0, values[0]);
        return answer;
    }
};
