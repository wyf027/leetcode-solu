一张客户与银行组成的资产表。你的任务只有一个：找出其中资产总量最大的客户，并返回这个总量。

非付费题 m × n 整数网格 返回整数

01 / PROBLEM

题目说明

给定整数矩阵 accounts，其中 accounts[i][j] 表示第 i 位客户在第 j 家银行中的资产。每位客户的资产总量等于该行所有数字之和；返回所有客户中最大的资产总量。

示例 1

输入：accounts = [[1,2,3],[3,2,1]]
输出：6

两位客户的资产总量都是 6，因此返回 6。

示例 2

输入：accounts = [[1,5],[7,3],[3,5]]
输出：10

三位客户分别拥有 6、10、8，最大值为 10。

示例 3

输入：accounts = [[2,8,7],[7,1,3],[1,9,5]]
输出：17

第一位客户的资产总量为 17，是全表最大值。

约束

  • m == accounts.length
  • n == accounts[i].length
  • 1 <= m, n <= 50
  • 1 <= accounts[i][j] <= 100

03 / EXPLANATION

准备好核对思路了吗？

完整题解、证明与四种语言代码默认收起。

SOLUTION

逐行求和，维护最大值

核心洞察：矩阵的一行就是一位客户的所有银行账户。求出每行之和，再在这些行和中取最大值即可；无需保存全部行和。

完整过程

  1. 初始化 maxWealth = 0。
  2. 从上到下访问每位客户，对当前行中的资产逐项累加，得到 currentWealth。
  3. 用 max(maxWealth, currentWealth) 更新已见客户中的最大资产。
  4. 全部行处理完成后返回 maxWealth。

正确性证明

处理第 i 行时，内层循环访问该客户在每家银行中的资产且恰好一次，因此 currentWealth 等于第 i 位客户的资产总量。更新后，maxWealth 是前 i 位客户资产总量的最大值。由循环不变式，处理完全部 m 位客户后，它就是所有客户资产总量的最大值，恰为题目要求的答案。

边界情况

  • 只有一位客户或一家银行时，过程仍然成立。
  • 多人并列最富有时只返回相同的最大资产值，无需返回客户编号。
  • 题目保证资产为正整数，因此以 0 初始化最大值安全。
  • 最大可能答案为 50 × 100 = 5000，常规整数类型足够。

复杂度与替代方案

时间复杂度 O(mn)：每个矩阵元素访问一次。除循环变量外不分配随输入增长的空间，空间复杂度 O(1)。

也可以先把每行和写入一个长度为 m 的数组，再取最大值，但会使用 O(m) 额外空间。函数式语言的一行式写法更短，本质仍是同一遍历。

四语言完整代码

class Solution {
    public int maximumWealth(int[][] accounts) {
        int maxWealth = 0;

        for (int[] customer : accounts) {
            int currentWealth = 0;
            for (int money : customer) {
                currentWealth += money;
            }
            maxWealth = Math.max(maxWealth, currentWealth);
        }

        return maxWealth;
    }
}

面试追问

  • 如果还要返回所有并列最富有的客户编号，如何修改？
  • 若矩阵非常大且按行流式到达，能否保持常数额外空间？
  • 若允许负资产，最大值应当怎样初始化？
  • 如果每家银行有不同汇率，数据模型和计算过程如何变化？

常见错误

  • 把每一列误当成一位客户，导致按银行求和。
  • 在外层循环之外忘记重置当前客户小计。
  • 返回客户下标而不是最大资产总量。
  • 只比较单个账户，而没有把整行资产相加。
