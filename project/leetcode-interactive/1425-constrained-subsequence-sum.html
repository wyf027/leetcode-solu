Constrained Subsequence Sum

带限制的
子序列和

从“选哪些数”转向“以哪个位置结束”。先读题，再通过逐帧探索器观察局部选择如何影响全局最优；完整方法默认收起。

Problem

题目描述

给定整数数组 nums 和整数 k，返回一个非空子序列的最大元素和。若子序列中两个连续被选元素在原数组中的下标为 i < j，必须满足 j - i <= k。

子序列可以删除任意数量的元素，但保留元素的相对顺序。限制只作用于子序列中相邻的两个被选位置。

官方示例

输入：nums = [10,2,-10,5,20], k = 2
输出：37
解释：选择子序列 [10, 2, 5, 20]。
输入：nums = [-1,-2,-3], k = 1
输出：-1
解释：子序列必须非空，因此选择最大元素。
输入：nums = [10,-2,-10,-5,20], k = 2
输出：23
解释：选择子序列 [10, -2, -5, 20]。

函数形式

constrainedSubsetSum(nums, k) -> integer
  • nums：整数数组
  • k：相邻所选下标的最大距离
  • 返回值：满足限制的非空子序列最大和

约束

  • 1 <= k <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4

Solution

动态规划 + 单调队列

核心洞察

定义 dp[i] 为“必须选择 nums[i] 且以它结尾”的合法子序列最大和。前一个被选下标只能在 [i-k, i-1] 中；若窗口内最佳值为负，则不接任何前缀、直接从 nums[i] 开始更优。

dp[i] = nums[i] + max(0, max(dp[j]))，i-k <= j < i

答案是所有 dp[i] 的最大值，而不是必然取 dp[n-1]。窗口最大值用一个按 dp 值从大到小保存下标的双端队列维护。

完整过程

  1. 从左到右枚举 i。
  2. 从队首移除所有下标小于 i-k 的过期候选。
  3. 队首就是当前窗口中最大的 dp；只在它为正时接到 nums[i] 前面。
  4. 不断弹出队尾中 dp 不大于 dp[i] 的下标，因为新下标更大、有效期更长且数值不差。
  5. 将 i 入队并更新全局答案。

正确性证明

引理 1：转移式正确。任一以 i 结尾且长度大于 1 的合法子序列，其倒数第二个下标必在 [i-k,i-1]，选择其中最大的 dp[j] 可得到最佳前缀；若所有前缀和都小于 0，丢弃它们并只选 nums[i] 更优。因此转移枚举了全部且仅全部合法情况。

引理 2：每次计算前，队首对应窗口内最大的 dp。过期下标已从队首删除；插入时删除的队尾下标值不大于新下标，且比新下标更早过期，之后不可能成为更优候选。队列因而保持值单调递减。

定理：由引理 1，每个 dp[i] 是以 i 结尾的最优值；由引理 2，所需窗口最大值被正确取得。每个非空合法子序列都有某个结尾位置，所以 max(dp) 即全局最优答案。

边界与复杂度

  • 全负数组：max(0, windowBest) 保证可以重新开始，答案仍取最大的单个元素。
  • k = 1：只能连接相邻下标，但仍可在任意位置重新开始。
  • k = n：所有更早位置都可作为前驱。
  • 每个下标最多入队、出队各一次，时间 O(n)，空间 O(n)；若只求答案且复用输入数组存 DP，可将额外 DP 空间降到 O(k) 量级。

替代方案

最大堆：保存 (dp[j], j)，每次懒删除过期堆顶，时间 O(n log n)，更易想到但不如单调队列紧致。

朴素 DP：每个位置扫描前 k 个状态，时间 O(nk)，在 10^5 规模下会超时，但适合用于理解和小规模参照。

四语言完整代码

Java
class Solution {
    public int constrainedSubsetSum(int[] nums, int k) {
        int n = nums.length;
        int[] dp = new int[n];
        int[] deque = new int[n];
        int head = 0, tail = 0;
        int answer = Integer.MIN_VALUE;

        for (int i = 0; i < n; i++) {
            while (head < tail && deque[head] < i - k) {
                head++;
            }

            int best = head < tail ? Math.max(0, dp[deque[head]]) : 0;
            dp[i] = nums[i] + best;
            answer = Math.max(answer, dp[i]);

            while (head < tail && dp[deque[tail - 1]] <= dp[i]) {
                tail--;
            }
            deque[tail++] = i;
        }
        return answer;
    }
}

Python 3
from collections import deque
from typing import List


class Solution:
    def constrainedSubsetSum(self, nums: List[int], k: int) -> int:
        n = len(nums)
        dp = [0] * n
        candidates = deque()
        answer = float("-inf")

        for i, value in enumerate(nums):
            while candidates and candidates[0] < i - k:
                candidates.popleft()

            best = max(0, dp[candidates[0]]) if candidates else 0
            dp[i] = value + best
            answer = max(answer, dp[i])

            while candidates and dp[candidates[-1]] <= dp[i]:
                candidates.pop()
            candidates.append(i)

        return answer
C++
class Solution {
public:
    int constrainedSubsetSum(vector<int>& nums, int k) {
        const int n = static_cast<int>(nums.size());
        vector<int> dp(n);
        deque<int> candidates;
        int answer = INT_MIN;

        for (int i = 0; i < n; ++i) {
            while (!candidates.empty() && candidates.front() < i - k) {
                candidates.pop_front();
            }

            const int best = candidates.empty()
                ? 0
                : max(0, dp[candidates.front()]);
            dp[i] = nums[i] + best;
            answer = max(answer, dp[i]);

            while (!candidates.empty() &&
                   dp[candidates.back()] <= dp[i]) {
                candidates.pop_back();
            }
            candidates.push_back(i);
        }
        return answer;
    }
};

面试追问

  • 为什么队列里存下标，而不是只存 dp 值？
  • 为什么相等时也可以弹出旧下标？
  • 怎样用父指针恢复一条达到最大和的实际子序列？
  • 如果下标距离限制改成每个位置不同，单调队列是否仍适用？
  • 最大堆方案如何处理窗口外的延迟删除？

常见错误

  • 返回 dp[n-1]，忽略最优子序列可能提前结束。
  • 强制连接负的窗口最优值，导致无法从当前位置重新开始。
  • 先计算再移除过期下标，错误使用距离大于 k 的前驱。
  • 按 nums 而非 dp 维护单调性。
  • 把“子序列中相邻”误解成“原数组中相邻”。
