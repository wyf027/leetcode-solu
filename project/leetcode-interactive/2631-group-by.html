分组 Group By

让数组自己完成归档：回调函数决定“抽屉标签”，原数组中的每一项按原有顺序落入对应分组。

Official signature 
Array.prototype.groupBy = function(fn) { … }

返回 Record<string, T[]>
键的顺序不限，组内顺序必须稳定。

Problem

题意

题号 2631 · 非付费题

扩展所有数组，使任意数组都能调用 array.groupBy(fn)。回调 fn 接收当前元素并返回一个字符串键；返回对象以这些字符串为键，每个键对应一个数组，收集所有生成该键的原数组元素。

每个分组内的元素必须保持其在原数组中的先后顺序；对象键的排列顺序不作要求。不得使用 Lodash 的 _.groupBy。

关键语义：这是为 Array.prototype 添加方法；调用时，this 就是待分组的数组。
0 ≤ array.length ≤ 105 fn(item) 返回 string 组内顺序与原数组一致

Solution

想清楚后，再看题解

先试着回答：如何在一次从左到右的扫描里，同时创建分组并保持组内顺序？

Walkthrough

题解：一次扫描，按键追加

官方可提交语言：JavaScript

核心洞察

分组就是“键 → 动态数组”的映射。顺序遍历原数组，用 fn(item) 得到键：桶不存在就创建，随后把当前元素追加到桶尾。

完整过程

  1. 创建空结果对象。
  2. 从左到右遍历 this。
  3. 计算字符串键并按需创建空数组。
  4. 把当前元素追加到该键对应的数组。
  5. 返回结果对象。

正确性

处理第 i 个元素时，它只会被加入 fn(this[i]) 对应的分组，因此归属正确且恰好出现一次。遍历顺序与原数组一致，而每次都追加到组尾，所以每个组内的相对顺序保持不变。全部元素处理后，结果正是所需分组。

边界与复杂度

空数组自然返回空对象；单元素和所有元素同键都不需要特殊分支。键可能与对象原型属性重名，因此 JavaScript 版本使用无原型对象。

时间 O(n)额外空间 O(n)

四种语言实现

官方可提交实现。使用无原型对象，避免 "__proto__" 等键与继承属性冲突。

/**
 * @param {Function} fn
 * @return {Object}
 */
Array.prototype.groupBy = function(fn) {
  const groups = Object.create(null);

  for (const item of this) {
    const key = fn(item);
    (groups[key] ??= []).push(item);
  }

  return groups;
};

本地语义参考：原题只提供 JavaScript / TypeScript 提交入口。

import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.function.Function;

public class GroupBy {
  public static <T> Map<String, List<T>> groupBy(
      List<T> array, Function<T, String> fn) {
    Map<String, List<T>> groups = new LinkedHashMap<>();
    for (T item : array) {
      groups.computeIfAbsent(fn.apply(item), key -> new ArrayList<>())
          .add(item);
    }
    return groups;
  }
}

from collections.abc import Callable, Iterable
from typing import TypeVar

T = TypeVar("T")

def group_by(array: Iterable[T], fn: Callable[[T], str]) -> dict[str, list[T]]:
    groups: dict[str, list[T]] = {}
    for item in array:
        groups.setdefault(fn(item), []).append(item)
    return groups

本地语义参考：原题只提供 JavaScript / TypeScript 提交入口；键顺序不要求固定。

#include <string>
#include <unordered_map>
#include <vector>

template <class T, class Fn>
std::unordered_map<std::string, std::vector<T>> groupBy(
    const std::vector<T>& array, Fn fn) {
  std::unordered_map<std::string, std::vector<T>> groups;
  for (const T& item : array) {
    groups[fn(item)].push_back(item);
  }
  return groups;
}

替代方案、面试追问与常见错误

替代方案与追问

  • reduce 也能完成，但不会改善复杂度；普通循环更直接。
  • 追问：若键不是字符串，可改用 Map 保留键类型。
  • 追问：若数据无法全部装入内存，可按流处理并把分组写入外部存储。
  • 追问：若要按多个字段分组，可让 fn 返回稳定序列化的复合键。

常见错误

  • 用箭头函数定义原型方法，导致没有自己的动态 this。
  • 直接 groups[key].push，却忘记先创建数组。
  • 在组头插入元素，破坏题目要求的原始顺序。
  • 使用普通对象却未考虑 "__proto__" 等特殊字符串键。
