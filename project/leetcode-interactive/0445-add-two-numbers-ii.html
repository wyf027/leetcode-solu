两数相加 II

445. Add Two Numbers II

给定两个非空链表，它们分别表示两个非负整数。每个节点存一位数字，并且数字的最高位位于链表开头。请计算两数之和，返回同样按最高位在前排列的新链表。

除数字 0 本身外，输入不会包含前导零。进阶要求：不翻转输入链表完成计算。

Complete solution

双栈模拟竖式加法

核心洞察

输入从最高位指向最低位，但加法必须从最低位开始。分别把两条链表的数字压栈，就能以弹栈顺序同时读取两数的个位、十位……每得到一位结果，就把新节点插到结果链表头部，从而保持最高位在前。

完整过程

  1. 遍历 l1、l2，数字分别压入两个栈。
  2. 只要任一栈非空或仍有进位，就继续一轮。
  3. 弹出存在的栈顶，与进位相加；个位作为新节点值，十位成为下一轮进位。
  4. 将新节点连接到当前答案头部，最后返回头节点。

正确性证明

不变式：每轮开始时，两个栈顶（若存在）分别是尚未处理部分的最低位；carry 是所有已处理低位向当前位产生的唯一进位；head 表示已经正确计算出的低位结果，且顺序为最高位在前。

保持：弹出当前最低位并加上 carry，sum % 10 正是这一位的结果，sum / 10 的整数部分正是下一位进位。把该结果位头插到 head 前，得到的链表仍按最高位在前表示全部已计算低位。

终止：两栈为空且进位为零时，所有输入位与最终进位均已处理。依据不变式，head 恰好表示两数之和，因此算法正确。

复杂度

设两链表长度为 m、n。时间复杂度 O(m+n)；两个栈占用 O(m+n) 额外空间。答案链表空间不计入辅助空间。

边界情况

  • 两数长度不同，缺失位按 0 处理。
  • 末轮仍有进位，例如 999 + 1。
  • 输入均为 [0]。
  • 节点数达到 100，不能转成内置整数。

替代方案

若允许修改输入，可先翻转两条链表，按常规方向求和后再翻转答案，辅助空间可降到 O(1)（不计输出）。也可递归对齐长度后回溯计算，但进位传播与实现复杂度更高，且递归栈仍需 O(m+n)。

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        Deque<Integer> first = new ArrayDeque<>();
        Deque<Integer> second = new ArrayDeque<>();

        for (ListNode node = l1; node != null; node = node.next) {
            first.push(node.val);
        }
        for (ListNode node = l2; node != null; node = node.next) {
            second.push(node.val);
        }

        ListNode head = null;
        int carry = 0;
        while (!first.isEmpty() || !second.isEmpty() || carry != 0) {
            int sum = carry;
            if (!first.isEmpty()) sum += first.pop();
            if (!second.isEmpty()) sum += second.pop();
            head = new ListNode(sum % 10, head);
            carry = sum / 10;
        }
        return head;
    }
}
/**
 * Definition for singly-linked list.
 * function ListNode(val, next) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.next = (next === undefined ? null : next);
 * }
 */
/**
 * @param {ListNode} l1
 * @param {ListNode} l2
 * @return {ListNode}
 */
var addTwoNumbers = function(l1, l2) {
    const first = [];
    const second = [];

    for (let node = l1; node !== null; node = node.next) {
        first.push(node.val);
    }
    for (let node = l2; node !== null; node = node.next) {
        second.push(node.val);
    }

    let head = null;
    let carry = 0;
    while (first.length > 0 || second.length > 0 || carry !== 0) {
        let sum = carry;
        if (first.length > 0) sum += first.pop();
        if (second.length > 0) sum += second.pop();
        head = new ListNode(sum % 10, head);
        carry = Math.floor(sum / 10);
    }
    return head;
};

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        vector<int> first;
        vector<int> second;

        for (ListNode* node = l1; node != nullptr; node = node->next) {
            first.push_back(node->val);
        }
        for (ListNode* node = l2; node != nullptr; node = node->next) {
            second.push_back(node->val);
        }

        ListNode* head = nullptr;
        int carry = 0;
        while (!first.empty() || !second.empty() || carry != 0) {
            int sum = carry;
            if (!first.empty()) {
                sum += first.back();
                first.pop_back();
            }
            if (!second.empty()) {
                sum += second.back();
                second.pop_back();
            }
            head = new ListNode(sum % 10, head);
            carry = sum / 10;
        }
        return head;
    }
};

常见错误

  • 只在“栈非空”时循环，漏掉最终进位。
  • 把节点追加到尾部，导致结果数字顺序反了。
  • 直接把 100 位数字转换为原生整数，发生溢出。
  • 为了省空间翻转输入，却没有确认允许修改原链表。
  • 计算下一轮前过早覆盖 carry。
