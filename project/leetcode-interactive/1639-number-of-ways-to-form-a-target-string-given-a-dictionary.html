目标字符串的方案数

Number of Ways to Form a Target String Given a Dictionary

阅读路线：先理解“列只能向右走”的限制，再进入交互实验。完整题解被收在页面底部，不会在首屏直接揭晓。
01

问题是什么

给定一组长度相同的字符串 words 和目标串 target。你要从左到右构造 target：构造第 i 个字符时，可以选任意单词在第 k 列的字符，只要它等于 target[i]。

一旦使用第 k 列，之后所有选择都必须来自严格更靠右的列；第 0..k 列在全部单词中都不能再用。同一个单词可以贡献多个字符，只要列下标持续递增。返回所有不同选择方案的数量，对 1,000,000,007 取模。

①目标从左到右依次完成 target[0]、target[1]……不能跳过目标字符。
②词典按列取字符同一列可从不同单词取得匹配字符，每个选择都形成不同方案。
③列下标严格递增选过第 k 列后，下一次只能看 k 右侧的列。
02

官方示例

示例 16 种
输入：words = ["acca","bbbb","caca"], target = "aba"
输出：6
解释：可使用的列序列包括 (0,1,3)、(0,2,3)、(1,2,3)，
每列中又可能有多个匹配字符，组合后共 6 种。
示例 24 种
输入：words = ["abba","baab"], target = "bab"
输出：4
解释：在保持列下标递增的前提下，匹配 b、a、b，
所有字符来源的组合共有 4 种。
示例 31 种
输入：words = ["abcd"], target = "abcd"
输出：1
示例 416 种
输入：words = ["abab","baba","abba","baab"], target = "abba"
输出：16

约束

  • 1 ≤ words.length ≤ 1000
  • 1 ≤ words[i].length ≤ 1000
  • 1 ≤ target.length ≤ 1000
  • words 中所有字符串长度相同
  • words[i] 与 target 只含小写英文字母
  • 答案对 10⁹ + 7 取模

    已经形成自己的思路了吗？

    完整题解含推导、证明、复杂度、替代方案、四种语言实现与面试追问。

    题解：列频次预处理 + 一维动态规划

    核心洞察完整过程正确性边界复杂度替代方案代码面试追问

    核心洞察

    具体选了哪一个单词并不会影响后续可用范围；真正决定后续的是最后使用到哪一列。因此，先把每列的 26 个字符频次统计出来。若第 col 列中字符 target[j] 出现 cnt 次，那么所有已经构成长度 j 前缀的方案，都能扩展出 cnt 倍的新方案。

    dp[j + 1] = dp[j + 1] + dp[j] × freq[col][target[j]]   (mod 1,000,000,007)

    dp[len] 表示只使用已经扫描过的列，构成 target 前 len 个字符的方案数。初始 dp[0] = 1，代表“什么都不选”有一种方式。

    完整过程

    1. 设每个单词长度为 m。建立 freq[m][26]，统计所有单词在每一列的字符频次。
    2. 建立长度为 target.length + 1 的数组 dp，令 dp[0] = 1。
    3. 从左到右枚举列 col。对于目标下标 j，从较大值向 0 倒序更新 dp[j+1]。
    4. 目标剩余字符数多于剩余列数时不可能完成；实现中可用 min(target.length-1, col) 限制内层循环。
    5. 所有列处理完毕后，dp[target.length] 即答案。
    为什么必须倒序？ 正序更新会让本列刚写入的 dp[j] 立刻参与本列后续计算，相当于同一列被使用多次。倒序确保转移来源仍是“处理本列之前”的状态。

    正确性证明

    循环不变式：处理完前 col 列后，dp[len] 等于仅从这些列中选择严格递增的列，并构成 target[0..len-1] 的方案数。

    初始化：未处理任何列时，空前缀恰有一种方案，非空前缀没有方案，所以 dp[0]=1、其余为 0，不变式成立。

    保持：处理新列时，每个旧方案有两类且互斥的选择：不用当前列，原值保留；或用当前列匹配下一个目标字符。后一类对每个旧方案恰有该字符在本列的频次种选择，故增加 dp[j] × freq。倒序更新保证每个新方案只使用当前列一次。两类合并后既无遗漏也不重复。

    终止：处理完全部列，不变式说明 dp[target.length] 正是使用所有可用列构造完整目标串的方案数，因此算法正确。

    边界情况

    • target.length > words[0].length 时答案必为 0。
    • 某个目标字符在所有可行列都不存在时，最终答案为 0。
    • 目标长度或列数为 1 时，同样适用统一转移。
    • 乘法中间值可能很大；Java/C++ 必须使用 64 位整数。
    • 每一步都取模，避免数值溢出或 JavaScript 精度风险。

    复杂度

    设单词数为 n，每个单词长度为 m，目标长度为 t。

    • 预处理：O(n × m)
    • 动态规划：O(m × t)
    • 总时间：O(nm + mt)
    • 空间：频次数组 O(26m)，DP O(t)

    替代方案

    二维 DP：令 ways[col][len] 表示用前 col 列形成长度 len 前缀的方案数，转移更直观，但空间达到 O(mt)。一维 DP 正是对它按列滚动压缩。

    记忆化搜索：状态为“当前列、目标下标”，每次跳过列或使用匹配字符。它和二维 DP 等价，但递归深度可达 1000，常数与栈风险更高。暴力枚举具体字符来源则会指数爆炸。

    四语言完整代码

    Java
    class Solution {
    private static final int MOD = 1_000_000_007;

    public int numWays(String[] words, String target) {
        int columns = words[0].length();
        int targetLength = target.length();
        if (targetLength > columns) return 0;

        int[][] frequency = new int[columns][26];
        for (String word : words) {
            for (int column = 0; column < columns; column++) {
                frequency[column][word.charAt(column) - 'a']++;
            }
        }

        long[] dp = new long[targetLength + 1];
        dp[0] = 1;
        for (int column = 0; column < columns; column++) {
            int last = Math.min(targetLength - 1, column);
            for (int j = last; j >= 0; j--) {
                int count = frequency[column][target.charAt(j) - 'a'];
                dp[j + 1] = (dp[j + 1] + dp[j] * count) % MOD;
            }
        }
        return (int) dp[targetLength];
    }
}

var numWays = function(words, target) {
    const MOD = 1_000_000_007n;
    const columns = words[0].length;
    const targetLength = target.length;
    if (targetLength > columns) return 0;

    const frequency = Array.from(
        { length: columns },
        () => new Array(26).fill(0)
    );
    for (const word of words) {
        for (let column = 0; column < columns; column++) {
            frequency[column][word.charCodeAt(column) - 97]++;
        }
    }

    const dp = new Array(targetLength + 1).fill(0n);
    dp[0] = 1n;
    for (let column = 0; column < columns; column++) {
        const last = Math.min(targetLength - 1, column);
        for (let j = last; j >= 0; j--) {
            const count = BigInt(frequency[column][target.charCodeAt(j) - 97]);
            dp[j + 1] = (dp[j + 1] + dp[j] * count) % MOD;
        }
    }
    return Number(dp[targetLength]);
};
    Python
    from typing import List


class Solution:
    def numWays(self, words: List[str], target: str) -> int:
        mod = 1_000_000_007
        columns = len(words[0])
        target_length = len(target)
        if target_length > columns:
            return 0

        frequency = [[0] * 26 for _ in range(columns)]
        for word in words:
            for column, char in enumerate(word):
                frequency[column][ord(char) - ord("a")] += 1

        dp = [0] * (target_length + 1)
        dp[0] = 1
        for column in range(columns):
            last = min(target_length - 1, column)
            for j in range(last, -1, -1):
                count = frequency[column][ord(target[j]) - ord("a")]
                dp[j + 1] = (dp[j + 1] + dp[j] * count) % mod

        return dp[target_length]
    C++
    class Solution {
public:
    int numWays(vector<string>& words, string target) {
        static constexpr long long MOD = 1'000'000'007LL;
        int columns = static_cast<int>(words[0].size());
        int targetLength = static_cast<int>(target.size());
        if (targetLength > columns) return 0;

        vector<array<int, 26>> frequency(columns);
        for (const string& word : words) {
            for (int column = 0; column < columns; ++column) {
                ++frequency[column][word[column] - 'a'];
            }
        }

        vector<long long> dp(targetLength + 1, 0);
        dp[0] = 1;
        for (int column = 0; column < columns; ++column) {
            int last = min(targetLength - 1, column);
            for (int j = last; j >= 0; --j) {
                long long count = frequency[column][target[j] - 'a'];
                dp[j + 1] = (dp[j + 1] + dp[j] * count) % MOD;
            }
        }
        return static_cast<int>(dp[targetLength]);
    }
};

    常见错误

    • 按目标字符正序更新 dp，导致同一列被重复使用。
    • 把“选择单词”误解为选中后必须一直使用同一个单词。
    • 统计全局字符频次，丢失列严格递增这一核心限制。
    • 忘记乘上当前列中匹配字符的出现次数。
    • 乘法前使用 32 位整数，尚未取模就已溢出。
    • JavaScript 直接用 Number 做超大中间乘法而失去精度。
