有序数组中的缺失元素

Missing Element in Sorted Array

任务：给定严格递增整数数组 nums 和正整数 k，返回从 nums[0] 向右数第 k 个未出现在数组中的整数。

参数形式

missingElement(nums, k) → integer

  • nums：严格递增整数数组。
  • k：缺失元素序号，从 1 开始。
  • 只统计大于 nums[0] 的整数；答案可能超过末尾。

约束

  • 1 ≤ nums.length ≤ 5 × 10⁴
  • 1 ≤ nums[i] ≤ 10⁷
  • nums 严格递增
  • 1 ≤ k ≤ 10⁸

官方示例（完整参数形式）

输入：nums = [4,7,9,10], k = 1
输出：5
解释：缺失序列为 5, 6, 8…

输出：8
解释：第 3 个缺失整数是 8。
输入：nums = [1,2,4], k = 3
输出：6
解释：缺失序列为 3, 5, 6…

题解：二分累计缺失数

核心洞察

若没有缺口，下标 i 应是 nums[0]+i，因此此前缺失数为 missing(i)=nums[i]-nums[0]-i。它单调不减，可以二分。

完整过程

  1. 若末尾累计缺失数小于 k，答案为 nums[n-1]+k-missing(n-1)。
  2. 否则二分维护：left 的缺失数小于 k，right 的缺失数至少为 k。
  3. 两者相邻后，从 nums[left] 补上 k-missing(left)。

正确性

由于 missing(i) 单调不减，结束时 left 是累计缺失数仍小于 k 的最后位置。目标在它之后，还差 k-missing(left) 个整数，相加即为第 k 个缺失值；末尾分支同理。

边界与复杂度

  • 单元素与目标超过末尾均由末尾公式处理。
  • 相邻元素没有缺口时，累计值可相等。
  • 时间 O(log n)，额外空间 O(1)。

替代方案

线性扫描相邻缺口并扣减 k，时间 O(n)、空间 O(1)，更直观但未利用单调性。

四语言完整代码

class Solution {
  public int missingElement(int[] a, int k) {
    int n=a.length, total=a[n-1]-a[0]-(n-1);
    if(total<k) return a[n-1]+k-total;
    int l=0,r=n-1;
    while(l+1<r){
      int m=l+(r-l)/2, miss=a[m]-a[0]-m;
      if(miss<k) l=m; else r=m;
    }
    return a[l]+k-(a[l]-a[0]-l);
  }
}
var missingElement = function(a, k) {
  const miss = i => a[i] - a[0] - i;
  const n = a.length;
  if (miss(n - 1) < k) return a[n - 1] + k - miss(n - 1);
  let l = 0, r = n - 1;
  while (l + 1 < r) {
    const m = l + Math.floor((r - l) / 2);
    if (miss(m) < k) l = m; else r = m;
  }
  return a[l] + k - miss(l);
};
class Solution:
    def missingElement(self, nums: List[int], k: int) -> int:
        miss = lambda i: nums[i] - nums[0] - i
        n = len(nums)
        if miss(n - 1) < k:
            return nums[-1] + k - miss(n - 1)
        left, right = 0, n - 1
        while left + 1 < right:
            mid = left + (right - left) // 2
            if miss(mid) < k:
                left = mid
            else:
                right = mid
        return nums[left] + k - miss(left)
class Solution {
public:
  int missingElement(vector<int>& a, int k) {
    auto miss = [&](int i){ return a[i]-a[0]-i; };
    int n=a.size();
    if(miss(n-1)<k) return a[n-1]+k-miss(n-1);
    int l=0,r=n-1;
    while(l+1<r){
      int m=l+(r-l)/2;
      if(miss(m)<k) l=m; else r=m;
    }
    return a[l]+k-miss(l);
  }
};

面试追问

  • 能否改为在答案值域上二分？搜索空间有何变化？
  • 若允许重复元素，累计缺失函数如何调整？
  • 流式输入时怎样尽早返回？

常见错误

  • 忘记在公式中减去下标 i。
  • 把第 k 个按 0 开始计算。
  • 遗漏答案超过数组末尾的分支。
  • 更新 left=mid 却未用相邻条件终止，造成死循环。
