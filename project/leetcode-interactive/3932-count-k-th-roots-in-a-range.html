统计区间内的完全 K 次幂数量

不枚举区间中的每个数：把 l ≤ x^k ≤ r 反向映射为整数根的连续区间，再用只比较、不溢出的乘法判定边界。

题意

给定整数 l、r 与 k。若存在整数 x 使 y = x^k，则 y 是完全 k 次幂。返回闭区间 [l, r] 中这类 y 的个数。

示例：l = 8, r = 30, k = 2，对应 9, 16, 25，答案为 3。

输入中的空格以 ␠ 表示；这里的参数为整数，不涉及字符串空格。

根区间观察器

可修改输入；结果展示非负整数根 x，而不是逐一扫描 y。

第 1 步：准备计算上下界。

题解：二分整数根

令 F(n) 为不超过 n 的最大整数 k 次根。答案是 F(r) - F(l - 1)。二分每个候选根；比较 mid^k 时一旦 acc > n / mid 就停止，既不依赖浮点数，也不会溢出。

  1. 若 k = 1，同一逻辑直接得到 r - l + 1。
  2. 对 r 和 l - 1 各做一次二分。
  3. 相减得到闭区间中所有不同完全 k 次幂的数量。

复杂度：每次比较做至多 k 次乘法，二分范围至多 [0, n]，时间 O(k log r)，额外空间 O(1)。

边界：l = 0 时 0 本身计入；k = 1；没有根落入区间；以及接近上界时的乘法溢出。

替代方案：可用 pow 估根后校正，但浮点误差会增加边界处理；面试中更推荐整数二分。

面试追问：若允许负数，奇数次幂需要扩展搜索到负根；若 r 超出 64 位，需要大整数或更早的溢出截断。

常见错误：把 ceil(root(l)) 写成 floor；遗漏 0；直接计算 mid^k；或用浮点根而没有回查。

class Solution {
    public int countKthRoots(int l, int r, int k) {
        long velnacqori = l;
        return (int) (floorRoot(r, k) - floorRoot(velnacqori - 1, k));
    }
    private long floorRoot(long n, int k) {
        if (n < 0) return -1;
        long lo = 0, hi = n, ans = 0;
        while (lo <= hi) {
            long mid = lo + (hi - lo) / 2;
            if (powerLeq(mid, k, n)) { ans = mid; lo = mid + 1; }
            else hi = mid - 1;
        }
        return ans;
    }
    private boolean powerLeq(long base, int k, long limit) {
        long acc = 1;
        for (int i = 0; i < k; i++) {
            if (base != 0 && acc > limit / base) return false;
            acc *= base;
        }
        return true;
    }
}
