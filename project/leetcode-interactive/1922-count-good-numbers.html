统计好数字的数目

Count Good Numbers · 数学与大规模计数

题目任务

给定整数 n，返回长度恰好为 n 的好数字字符串总数，对 10⁹ + 7 取余。

下标从 0 开始：偶数下标必须放偶数数字（0、2、4、6、8），奇数下标必须放质数数字（2、3、5、7）。字符串允许前导零。

例如 2582 满足要求；3245 的下标 0 为 3，因此不是好数字。

参数：n: long；返回：integer。完整约束：1 ≤ n ≤ 10¹⁵。

题解 · 配对积木与二进制幂块

核心洞察

偶数下标有 5 种选择，奇数下标有 4 种选择，各位置独立。乘法原理得到 5^⌈n/2⌉ × 4^⌊n/2⌋。把相邻的偶、奇下标配成一对，每对有 20 种选择，公式简化为 20^⌊n/2⌋ × (n 为奇数 ? 5 : 1)。

交互：逐轮拆开指数

r 是累计结果，b 是当前幂块，e 是剩余指数。每一步展示二进制最低位如何决定是否乘入 b。

范围 1 至 1000000000000000。图形最多展示前三对位置，计算包含所有位置。

Tab 切换焦点，Enter / 空格操作按钮。减少动态效果模式下，播放间隔为 2 秒。交互计算不代表已验证结果。

完整过程

  1. 初始化 e = n // 2，b = 20，r = 1，模数 M = 1000000007。
  2. 如果 e 为奇数，执行 r = r × b mod M。
  3. 执行 b = b × b mod M，e = e // 2；重复直到 e = 0。
  4. n 为奇数时，最后一个偶数下标多贡献因子 5，乘入并取模。

n = 4 时，e 初始为 2，最低位为 0，先将 b 平方为 400；下一轮 e = 1，乘入 400，最终答案为 400。

正确性

每一对位置都有且仅有 20 种合法组合，各对独立；若剩一位，它位于偶数下标，有且仅有 5 种选择，因此计数公式成立。

快速幂保持不变量 r × b^e ≡ 20^⌊n/2⌋ (mod M)。当 e = 2k 时，将 b 换成 b²、e 换成 k 后不变量保持；当 e = 2k + 1 时，先将 b 乘入 r，再做同样变换，也保持不变量。e 每次整除 2，必然到达 0，此时 r 就是目标幂的余数。乘入剩余位的选择数即可得到正确答案。

边界与复杂度

n = 1 时，幂指数为 0，初始 r = 1，最终乘 5。前导零合法，不能扣掉首位的 0。n 可达 10¹⁵，指数必须使用足够宽的整数类型。

时间 O(log n)，迭代实现额外空间 O(1)，按固定范围整数运算计。演示为支持回退保存 O(log n) 个快照，不属于提交算法的空间。

Java 与 C++ 的乘法使用 64 位整数，模内两数的乘积小于约 10¹⁸，不会超过有符号 64 位上限。JavaScript 输入 n 在安全整数范围内，但模乘结果可能超过此范围，必须使用 BigInt；返回值取模后可以安全转为 Number。

替代方案

分别对 5 和 4 做两次快速幂也可，复杂度相同。逐位相乘需要 O(n) 时间，不适合上限。递归快速幂会使用 O(log n) 栈空间。Python 的三参数 pow 已提供模幂，无须重写。

Java

class Solution {
    public int countGoodNumbers(long n) {
        final long MOD = 1_000_000_007L;
        long e = n / 2, b = 20, r = 1;
        while (e > 0) {
            if (e % 2 == 1) r = r * b % MOD;
            b = b * b % MOD;
            e /= 2;
        }
        return (int) (r * (n % 2 == 1 ? 5 : 1) % MOD);
    }
}

JavaScript

/**
 * @param {number} n
 * @return {number}
 */
var countGoodNumbers = function(n) {
    const N = BigInt(n), MOD = 1000000007n;
    let e = N / 2n, b = 20n, r = 1n;
    while (e > 0n) {
        if (e % 2n === 1n) r = r * b % MOD;
        b = b * b % MOD;
        e /= 2n;
    }
    return Number(r * (N % 2n === 1n ? 5n : 1n) % MOD);
};

Python 3

class Solution:
    def countGoodNumbers(self, n: int) -> int:
        mod = 1_000_000_007
        return pow(20, n // 2, mod) * (5 if n % 2 else 1) % mod

C++

class Solution {
public:
    int countGoodNumbers(long long n) {
        const long long MOD = 1000000007LL;
        long long e = n / 2, b = 20, r = 1;
        while (e > 0) {
            if (e % 2 == 1) r = r * b % MOD;
            b = b * b % MOD;
            e /= 2;
        }
        return static_cast<int>(r * (n % 2 ? 5 : 1) % MOD);
    }
};

常见错误

  • 从 1 开始计算下标，颠倒奇偶位数量。
  • 禁止前导零，或者误把 1 当作质数。
  • 先算完整幂再取模，造成溢出或巨大开销。
  • 用 JavaScript Number 做模乘，或用 32 位位运算处理大指数。

面试追问

模数必须是质数吗？ 不需要，这里仅做乘法与取模，不依赖模逆元。

如果规则每 k 位循环？ 先求完整周期的选择数乘积，对周期数量做快速幂，再乘入剩余前缀的选择数。

如果相邻数字不能相同？ 位置不再独立，需要按上一位记录状态做动态规划；极大长度下可以考虑矩阵快速幂。
