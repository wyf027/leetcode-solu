最优除法 / Optimal Division

不是计算所有括号，而是找到那个让“除数”尽可能小的结构。

题目

给你一个正整数数组 nums，相邻数字之间依次执行浮点除法。你可以添加括号改变运算优先级。请返回能使表达式值最大的字符串，且不能含有多余括号。

示例 1

输入：nums = [1000,100,10,2]
输出："1000/(100/10/2)"
解释：1000/(100/10/2) = 200
      1000/100/10/2 = 0.5

示例 2

输入：nums = [2,3,4]
输出："2/(3/4)"
解释：2/(3/4) = 8/3 ≈ 2.667

约束

  • 1 <= nums.length <= 10
  • 2 <= nums[i] <= 1000
  • 给定输入只有一种最优除法。

题解：让整个分母最小

核心洞察：若长度至少为 3，答案恒为 a/(b/c/d/...)。首项作为分子，其余所有数字放进同一个分母括号，且括号内部保持从左向右连除。

为什么这样做

所有数都大于 1。表达式可写成 a / X；要让整体最大，就要让正数 X 尽可能小。把后续数字按 b/c/d/... 计算，等价于 b / (c×d×...)，它能让 b 被尽可能多的因子除掉。于是原式等价于 a×c×d×.../b。

完整过程

  1. 长度为 1，直接返回唯一数字。
  2. 长度为 2，只能返回 a/b；加括号是冗余的。
  3. 长度至少为 3，输出首项、字符 /(、其余数字以 / 相连、最后的 )。

正确性证明

令首项为 a。任何表达式的最外层都可视作某个正值相除。为了保留最大的分子，a 不应被后续除法移入分母的分子侧；因此目标化为最小化由 b,c,... 构成的除数。由于所有数字均大于 1，每让一个后续数字从“除以它”转为“乘以它”，结果都会严格增大。结构 a/(b/c/d/...) 恰好使 c,d,... 全部成为整体的乘数，得到 a×c×d×.../b。其他括号结构至少会让其中一个数仍作为整体除数，值严格更小。因此该构造唯一最优。

边界与复杂度

  • n = 1：不出现除号和括号。
  • n = 2：不加冗余括号。
  • n ≥ 3：只给后缀添加一对必要括号。
  • 时间：O(n)；额外空间：除返回字符串外为 O(1)，构造结果占 O(n) 字符。

替代方案

区间动态规划可以为每段同时维护最大值、最小值及表达式，并枚举切分点，通常为 O(n³) 时间、O(n²) 空间。它适用于数字可为负数、零或运算符更多的泛化版本；在本题“全部大于 1”的约束下属于过度设计。

面试追问

  • 若允许 0 或负数，贪心为何失效？应如何用最大/最小双状态 DP？
  • 若要求返回最大值而非表达式，怎样避免浮点误差？
  • 若存在多个最优表达式，如何返回字典序最小者？

常见错误

  • 返回 (a)/(b/c) 等含冗余括号的字符串。
  • 漏掉长度为 1 或 2 的分支。
  • 实际计算浮点值再搜索，带来不必要的精度与复杂度问题。
  • 把后缀写成 a/(b/(c/d))，这会改变括号内的连除方向。

四语言实现

class Solution {
    public String optimalDivision(int[] nums) {
        if (nums.length == 1) return String.valueOf(nums[0]);
        if (nums.length == 2) return nums[0] + "/" + nums[1];

        StringBuilder ans = new StringBuilder();
        ans.append(nums[0]).append("/(").append(nums[1]);
        for (int i = 2; i < nums.length; i++) {
            ans.append('/').append(nums[i]);
        }
        return ans.append(')').toString();
    }
}

 * @param {number[]} nums

var optimalDivision = function(nums) {
    if (nums.length === 1) return String(nums[0]);
    if (nums.length === 2) return nums[0] + "/" + nums[1];
    return nums[0] + "/(" + nums.slice(1).join("/") + ")";
};
from typing import List

class Solution:
    def optimalDivision(self, nums: List[int]) -> str:
        if len(nums) == 1:
            return str(nums[0])
        if len(nums) == 2:
            return f"{nums[0]}/{nums[1]}"
        suffix = "/".join(map(str, nums[1:]))
        return f"{nums[0]}/({suffix})"
