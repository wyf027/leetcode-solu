最长理想子序列

Longest Ideal Subsequence

保留字符的顺序，让相邻字母的距离足够近。你最多能留下多少个字符？

01 / 读懂问题

顺序保留，间隔可以跳过

给定小写英文字母字符串 s 和整数 k。从 s 中删除任意多个字符（也可以不删），得到子序列 t，剩余字符的先后顺序不能改变。如果 t 中每一对相邻字母的字母表位次差的绝对值都不超过 k，它就是理想字符串。返回满足条件的最大长度。

相邻指的是选出的子序列中的相邻字符。字母表不循环：a 与 z 的距离是 25，不是 1。

参数与返回值

longestIdealString(s: string, k: integer) → integer

官方约束

  • 1 ≤ s.length ≤ 10⁵
  • 0 ≤ k ≤ 25
  • s 仅含小写英文字母。

示例 1

输入：s = "acfgbd", k = 2
输出：4

可以选择 acbd，相邻距离依次是 2、1、2，长度为 4。原串中的 c → f 距离为 3，因此不能完整保留原串。

示例 2

输入：s = "abcd", k = 3
输出：4

整个 abcd 都符合条件，长度为 4。

04 / 解法工作台

按需展开：推导、交互、四语言代码。

核心洞察：按结尾字母保存最佳长度

未来字符能否接上，只取决于当前子序列的最后一个字母。对于结尾相同的候选，较长的那条永远不差。因此只需要 26 个状态：dp[c] 表示已经处理的前缀中，以字母 c 结尾的最长理想子序列长度，初始全为 0。

当前字母编号 x = s[i] - 'a'
L = max(0, x - k), R = min(25, x + k)
best = max(dp[L], ..., dp[R])  // 必须先读完旧状态
dp[x] = best + 1
答案 = max(dp[0], ..., dp[25])

区间包含 x 自身，所以新值至少是旧 dp[x] + 1，可以直接覆盖；其他字母状态保持不变。所有字符均按原串顺序处理。

完整过程 · s = "acfgbd", k = 2

  1. 读 a，查询 a–c，全为 0，得到 dp[a] = 1。
  2. 读 c，查询 a–e，最大是 1，得到 dp[c] = 2。
  3. 读 f，查询 d–h，最大是 0，得到 dp[f] = 1。
  4. 读 g，查询 e–i，最大是 1，得到 dp[g] = 2。
  5. 读 b，查询 a–d，最大是 2，得到 dp[b] = 3。
  6. 读 d，查询 b–f，最大是 3，得到 dp[d] = 4。最终最大值为 4，一条对应子序列是 acbd。

正确性

归纳不变式：处理每个前缀后，26 个状态恰好分别记录该前缀中各结尾的最优长度。空前缀没有非空子序列，全部为 0，成立。

处理字母 x 时，任何使用该位置的合法子序列，要么只有它自己，要么去掉末尾后以区间 [x−k, x+k] 内的字母结束。根据不变式，其长度不可能超过区间最优值加 1。反过来，区间内任意已有最优子序列都可以合法接上 x，因此该上界可达。

不使用新位置的旧候选仍然有效。对其他结尾无需更新；对结尾 x，查询区间包含旧 dp[x]，新值更大，覆盖不会丢失最优解。不变式延续。最后每条非空子序列必有一个结尾，取所有状态最大值即为答案。

边界、复杂度与替代方案

  • k = 0：只能接同一个字母，答案等于最高字母频次。
  • k = 25：任意相邻字母均可连接，答案等于字符串长度。
  • 单字符答案是 1；a、z 附近的查询区间要裁剪到 0–25。
  • 设长度为 n，字母表大小为 Σ = 26。时间 O(n · min(26, 2k+1))，最坏 O(26n)，固定字母表下为 O(n)；额外空间 O(26)，即 O(1)。可视化为支持回退保存历史，与提交算法空间不同。
  • 替代方案：按位置记录最优长度，并扫描所有之前可连接的位置，时间 O(n²)、空间 O(n)，不适合 10⁵ 的规模。
  • 若字母表很大，可用线段树进行区间最大值查询与单点更新，时间 O(n log Σ)、空间 O(Σ)；这里只有 26 种字母，无需引入树结构。

常见错误

  • 把子序列当成连续子串，遇到大距离就截断。
  • 只比较原串相邻字符，或只保存全局最长值，丢失结尾信息。
  • 忽略绝对值，或错误地把字母表当作环。
  • 在区间扫描内反复更新 dp[x]，使同一位置参与自身计算；应先完整求出 best，再只写入一次。
  • 强制字母递增。c → b 同样可能合法。

面试追问

如何返回实际子序列？ 除长度外记录各结尾的代表位置，每个位置保存前驱索引。从最终最佳位置回溯并反转，额外空间 O(n)。
如何流式处理？ 保留 26 个状态即可继续接收字符，无需存储原串。
如果允许的相邻关系任意给定？ 将数字区间改成每个字母的合法前驱集合，仍按同样的不变式转移。

Java

class Solution {
    public int longestIdealString(String s, int k) {
        int[] dp = new int[26];
        int answer = 0;
        for (int i = 0; i < s.length(); i++) {
            int x = s.charAt(i) - 'a';
            int best = 0;
            for (int j = Math.max(0, x - k);
                 j <= Math.min(25, x + k); j++) {
                best = Math.max(best, dp[j]);
            }
            dp[x] = best + 1;
            answer = Math.max(answer, dp[x]);
        }
        return answer;
    }
}
