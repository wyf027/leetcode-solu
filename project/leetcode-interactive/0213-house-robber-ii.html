任何合法方案都属于两个线性子问题之一

核心洞察与完整过程

  1. 首宅与尾宅不能同时选择，因此任一合法方案至少排除其中一个。
  2. 排除尾宅后，问题变成区间 [0, n-2] 上的线性打家劫舍。
  3. 排除首宅后，问题变成区间 [1, n-1] 上的线性打家劫舍。
  4. 对每条线性街道维护 prev2 与 prev1，当前最优是 max(prev1, prev2 + nums[i])。
  5. 两个区间已经覆盖全部合法方案，取两者最大值即可。
answer = max(
  robLinear(nums, 0, n - 2),
  robLinear(nums, 1, n - 1)
)

边界与复杂度

  • 只有一宅时直接返回其金额，不能构造两个空区间。
  • 两宅时结果是两者较大值。
  • 全零时可以不选任何住宅，结果为 0。
  • 每条街道线性扫描，总时间 O(n)。
  • 只保留两个滚动状态，额外空间 O(1)。

替代方案与取舍

  • 二维 DP 可显式记录每个下标的选与不选，但需要 O(n) 空间。
  • 记忆化搜索容易写出状态，但递归栈也是 O(n)。
  • 直接对圆环做带首宅选择状态的 DP 可行，但状态更难解释。

面试追问

  • 为什么排除首宅与排除尾宅不会遗漏合法方案？
  • 若住宅构成树而不是环，应怎样定义状态？
  • 怎样恢复具体选择了哪些住宅？

Java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];
        return Math.max(robRange(nums, 0, n - 2),
                        robRange(nums, 1, n - 1));
    }

    private int robRange(int[] nums, int start, int end) {
        int prev2 = 0;
        int prev1 = 0;
        for (int i = start; i <= end; i++) {
            int current = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = current;
        }
        return prev1;
    }
}

from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        if n == 1:
            return nums[0]

        def rob_range(start: int, end: int) -> int:
            prev2 = prev1 = 0
            for i in range(start, end + 1):
                prev2, prev1 = prev1, max(prev1, prev2 + nums[i])
            return prev1

        return max(rob_range(0, n - 2), rob_range(1, n - 1))

class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];
        return max(robRange(nums, 0, n - 2),
                   robRange(nums, 1, n - 1));
    }

private:
    int robRange(const vector<int>& nums, int start, int end) {
        int prev2 = 0;
        int prev1 = 0;
        for (int i = start; i <= end; ++i) {
            int current = max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = current;
        }
        return prev1;
    }
};

常见错误

  • 直接运行线性版本，可能同时选择首宅与尾宅。
  • 只排除首宅或只排除尾宅，漏掉另一类最优解。
  • 没有单独处理 n == 1，导致区间越界。
  • 更新滚动变量顺序错误，让当前状态污染前两步状态。
  • 把两个区间结果相加；它们是互斥方案，应取最大值。
