队列中可以看到的人数

Number of Visible People in a Queue

站在队列里向右望去，哪些人会出现在你的视野中？
先想清楚「中间所有人都更矮」，再尝试把每个人的视野数出来。

01 / 题目与规则

有 n 个人从左到右排队，编号是 0…n−1。输入整数数组 heights，其中 heights[i] 是第 i 人的身高，所有身高互不相同。

第 i 人只能看向右边。他能看到第 j 人，当且仅当两人中间的每一个人都比这两个人矮。相邻两人之间没有阻挡，因此总能看到右侧相邻的人。

i < j 且对所有 i < k < j：heights[k] < min(heights[i], heights[j])

返回长度为 n 的数组 answer，answer[i] 表示第 i 人能看到的右侧人数。

输入约束

  • n == heights.length
  • 1 ≤ n ≤ 105
  • 1 ≤ heights[i] ≤ 105
  • heights 中的值两两不同。

官方示例 1

输入：heights = [10,6,8,5,11,9]
输出：[3,1,2,1,1,0]

编号 0 看到 1、2、4；编号 1 看到 2；编号 2 看到 3、4；编号 3 看到 4；编号 4 看到 5；编号 5 的右侧无人。

官方示例 2

输入：heights = [5,1,2,3,10]
输出：[4,1,1,1,0]

编号 0 能看到右边全部四人。身高 1、2、3 的人各自只能看到紧邻的右侧一人。

03 / 准备好再揭晓

包含逐步演示、推导与四语言实现。

题解 / 从右往左，维护视野轮廓

核心洞察

从某个人向右看，可见的矮人身高必须逐渐升高；遇到第一个比自己高的人，还能看到他，但更远的人都被他挡住。从右往左处理，用一个从栈底到栈顶严格递减的栈，保存右侧还可能被左边的人看到的轮廓。

  1. 弹出所有比当前人矮的栈顶。每弹出一个，当前人的计数加一。
  2. 若栈仍非空，栈顶是第一个更高的可见人，再计数一次；不能弹出这个遮挡者。
  3. 当前人入栈，继续处理左边的人。
栈保存的是候选轮廓，不是所有右侧的人。被弹出的人会被当前这个更近、更高的人遮住，后续左侧观察者再也不需要考虑他们。

一步只完成一次「选中 / 弹出并计数 / 计数遮挡者 / 入栈」。柱子按队列顺序排列；栈下方从左至右表示栈底至栈顶。

正确性：为什么既不遗漏，也不多算？

不变式：处理 i 之前，栈从顶到底对应右侧由近到远、身高严格升高的轮廓。任何已从栈中删除的人，左边都有一个更近且更高的人，因此对尚未处理的观察者不可能重新变得可见。

弹栈的可见性：栈顶比当前人矮时，它前面的轮廓都更矮且已被弹出；其余中间人也被这些轮廓遮住，所以中间最高身高小于两端的较小值。这个栈顶必须且只被当前人计数一次。

保留的遮挡者：停止弹栈后若栈非空，栈顶比当前人高。两者之间已扫过的轮廓都比当前人矮，所以它可见；它又比当前人高，足以挡住后面全部人，只能再加一。

保持与终止：弹出的矮人被当前人永久遮挡，当前人入栈后保持严格递减。最右侧初始栈为空，答案为 0；归纳到最左侧，每个人的可见人数均被准确记录。

边界与复杂度

  • 单人答案为 [0]；严格递增、严格递减队列都只看得到相邻右侧人。
  • 一个高人后面连续升高的矮人可以全部可见，计数可能达到 n−1。
  • 空栈时不能访问栈顶；原题没有相同身高，不需要处理重复值。
  • 时间 O(n)：每人入栈一次、最多出栈一次；嵌套 while 的总弹出次数不超过 n。
  • 辅助空间 O(n)，返回数组另占 O(n)。严格递增输入从右往左扫描时栈可达到 n。

替代方案

暴力对每个 i 扫描右侧，用 maxBetween 维护中间最大身高。若 min(heights[i], heights[j]) > maxBetween，则计数；再更新最大值，遇到比自己高的人即可结束。最坏 O(n²)、除输出外 O(1) 空间：如最高人在最左，右侧整体递减时，许多起点会扫描到末尾。

也可以从左往右维护递减栈：当前人出现时，被弹出的人各自答案加一；若栈非空，剩余栈顶的答案也加一。这是“当前人给左边观察者贡献答案”的 O(n) 写法。

常见错误

  • 只统计弹出的矮人，漏掉第一个更高的人。
  • 把更高的遮挡者也弹出，导致后续视野信息丢失。
  • 把所有右边的矮人都计数，忽略中间更高的人会挡住他们。
  • 混淆栈的方向：本方案从右到左扫描，栈底到栈顶递减。
  • 误将 O(n) 次弹栈当成每一轮都要 O(n)，从而错误判断复杂度。

面试追问

如果身高可以重复？原代码不能直接照搬。例如 [5,3,3]，左边的 5 只能看到第一个 3。应处理相等轮廓：当前人看到相等栈顶后，删除这个旧的同高候选，用更近的当前人替代；本题保证唯一值，提交代码不引入这项扩展。

若需要返回具体可见编号？栈保存索引，弹栈和看到首个更高者时记录索引即可。本算法总计数事件为 O(n)，总可见对数也是 O(n)，因为每人最多出栈一次、每轮至多增加一个未弹出的可见者。

为什么不用排序？可见性取决于队列中的相对位置，排序会改变遮挡关系。

Java

class Solution {
    public int[] canSeePersonsCount(int[] heights) {
        int n = heights.length;
        int[] answer = new int[n];
        int[] stack = new int[n];
        int size = 0;
        for (int i = n - 1; i >= 0; i--) {
            while (size > 0 && stack[size - 1] < heights[i]) {
                size--;
                answer[i]++;
            }
            if (size > 0) answer[i]++;
            stack[size++] = heights[i];
        }
        return answer;
    }
}

/**

var canSeePersonsCount = function(heights) {
    const answer = Array(heights.length).fill(0);
    const stack = [];
    for (let i = heights.length - 1; i >= 0; i--) {
        while (stack.length &&
               stack[stack.length - 1] < heights[i]) {
            stack.pop();
            answer[i]++;
        }
        if (stack.length) answer[i]++;
        stack.push(heights[i]);
    }
    return answer;
};

from typing import List

class Solution:
    def canSeePersonsCount(self, heights: List[int]) -> List[int]:
        answer = [0] * len(heights)
        stack = []
        for i in range(len(heights) - 1, -1, -1):
            while stack and stack[-1] < heights[i]:
                stack.pop()
                answer[i] += 1
            if stack:
                answer[i] += 1
            stack.append(heights[i])
        return answer

C++

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> canSeePersonsCount(vector<int>& heights) {
        int n = static_cast<int>(heights.size());
        vector<int> answer(n, 0), stack;
        stack.reserve(n);
        for (int i = n - 1; i >= 0; --i) {
            while (!stack.empty() && stack.back() < heights[i]) {
                stack.pop_back();
                ++answer[i];
            }
            if (!stack.empty()) ++answer[i];
            stack.push_back(heights[i]);
        }
        return answer;
    }
};
