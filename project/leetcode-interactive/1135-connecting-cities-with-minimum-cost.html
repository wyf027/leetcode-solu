PROBLEM 1135 最低成本连通所有城市

把候选道路看成一张带权无向图。你的任务不是让每两座城市都直接相连，而是选择一组道路，使任意城市之间都能互相到达，同时让总建设成本最小。

Problem

题目转述

城市编号为 1 到 n。每条 [x, y, cost] 表示在城市 x、y 之间修建一条双向道路的成本。返回让所有城市处于同一连通网络中的最小总成本；若做不到，返回 -1。

不可连通 
输入：n = 4, connections = [[1,2,3],[3,4,4]]
输出：-1

参数与约束

  • 1 <= n <= 10^4
  • 1 <= connections.length <= 10^4
  • connections[i].length == 3
  • 1 <= x_i, y_i <= n
  • x_i != y_i
  • 0 <= cost_i <= 10^5

道路是双向的；总成本等于被选道路成本之和。函数参数为 minimumCost(n, connections)，返回一个整数。

Solution

Kruskal + 并查集

核心洞察

要连通 n 座城市且不浪费道路，最终结构应当是一棵含 n - 1 条边的生成树。按成本递增审查道路，只在两端属于不同连通分量时采用，正好得到最小生成树。

完整过程

  1. 把 connections 按道路成本升序排序。
  2. 初始化并查集，每座城市先是一个独立连通分量。
  3. 依次检查道路；若两端根节点不同，则合并两组、累加成本，并记录采用一条道路。
  4. 一旦采用 n - 1 条道路，所有城市已经连通，可提前返回累计成本。
  5. 遍历结束仍不足 n - 1 条，说明原图不连通，返回 -1。

边界情况

  • n = 1：不需要修路，理论最小成本为 0。
  • 零成本道路：允许出现，应正常参与排序和合并。
  • 重复或成环道路：并查集会识别两端已连通并跳过。
  • 孤立城市：最终采用边数不足 n - 1，返回 -1。
  • 成本相同：同权边先后顺序不影响最小总成本。

正确性说明

安全性：每次准备加入道路 (u, v) 时，u 与 v 位于两个不同连通分量。当前尚未检查的道路成本不会更低。依据最小生成树的割性质，跨越这两个分量之间的当前最小可用边，可以安全地出现在某棵最小生成树中。

无环与连通：只有根节点不同才合并，因此选中道路始终不形成环。每次合并让连通分量数减少 1；从 n 个分量减少到 1 恰好需要 n - 1 次成功合并，此时选中边构成生成树。

最优性：上述每一步都保持“当前选中集合可扩展为某棵最小生成树”的不变量。成功选满 n - 1 条边时，该集合本身就是最小生成树，所以累计成本最小。若无法选满，则不存在覆盖所有城市的生成树。

时间 O(m log m)

排序 m 条道路占主导；并查集操作均摊接近常数，严格写作 O(m α(n))。

空间 O(n)

并查集的 parent 与 rank/size 数组需要 O(n)；排序额外空间取决于语言实现。

四种语言完整实现

均使用路径压缩与按秩合并；切换标签只改变当前展示的代码。

import java.util.Arrays;

class Solution {
    private int[] parent;
    private int[] rank;

    public int minimumCost(int n, int[][] connections) {
        if (n == 1) {
            return 0;
        }

        Arrays.sort(connections, (a, b) -> Integer.compare(a[2], b[2]));
        parent = new int[n + 1];
        rank = new int[n + 1];
        for (int city = 1; city <= n; city++) {
            parent[city] = city;
        }

        int totalCost = 0;
        int usedEdges = 0;

        for (int[] connection : connections) {
            int cityA = connection[0];
            int cityB = connection[1];
            int cost = connection[2];

            if (union(cityA, cityB)) {
                totalCost += cost;
                usedEdges++;
                if (usedEdges == n - 1) {
                    return totalCost;
                }
            }
        }

        return -1;
    }

    private int find(int city) {
        if (parent[city] != city) {
            parent[city] = find(parent[city]);
        }
        return parent[city];
    }

    private boolean union(int cityA, int cityB) {
        int rootA = find(cityA);
        int rootB = find(cityB);
        if (rootA == rootB) {
            return false;
        }

        if (rank[rootA] < rank[rootB]) {
            parent[rootA] = rootB;
        } else if (rank[rootA] > rank[rootB]) {
            parent[rootB] = rootA;
        } else {
            parent[rootB] = rootA;
            rank[rootA]++;
        }
        return true;
    }
}

/**
 * @param {number} n
 * @param {number[][]} connections
 * @return {number}

var minimumCost = function (n, connections) {
    if (n === 1) {
        return 0;
    }

    connections.sort((a, b) => a[2] - b[2]);
    const parent = Array.from({ length: n + 1 }, (_, city) => city);
    const rank = new Array(n + 1).fill(0);

    const find = (city) => {
        if (parent[city] !== city) {
            parent[city] = find(parent[city]);
        }
        return parent[city];
    };

    const union = (cityA, cityB) => {
        let rootA = find(cityA);
        let rootB = find(cityB);
        if (rootA === rootB) {
            return false;
        }

        if (rank[rootA] < rank[rootB]) {
            [rootA, rootB] = [rootB, rootA];
        }
        parent[rootB] = rootA;
        if (rank[rootA] === rank[rootB]) {
            rank[rootA]++;
        }
        return true;
    };

    let totalCost = 0;
    let usedEdges = 0;

    for (const [cityA, cityB, cost] of connections) {
        if (union(cityA, cityB)) {
            totalCost += cost;
            usedEdges++;
            if (usedEdges === n - 1) {
                return totalCost;
            }
        }
    }

    return -1;
};

from typing import List


class Solution:
    def minimumCost(self, n: int, connections: List[List[int]]) -> int:
        if n == 1:
            return 0

        connections.sort(key=lambda connection: connection[2])
        parent = list(range(n + 1))
        rank = [0] * (n + 1)

        def find(city: int) -> int:
            if parent[city] != city:
                parent[city] = find(parent[city])
            return parent[city]

        def union(city_a: int, city_b: int) -> bool:
            root_a = find(city_a)
            root_b = find(city_b)
            if root_a == root_b:
                return False

            if rank[root_a] < rank[root_b]:
                root_a, root_b = root_b, root_a
            parent[root_b] = root_a
            if rank[root_a] == rank[root_b]:
                rank[root_a] += 1
            return True

        total_cost = 0
        used_edges = 0

        for city_a, city_b, cost in connections:
            if union(city_a, city_b):
                total_cost += cost
                used_edges += 1
                if used_edges == n - 1:
                    return total_cost

        return -1

#include <algorithm>
#include <numeric>
#include <vector>
using namespace std;

class Solution {
private:
    vector<int> parent;
    vector<int> rankValue;

    int find(int city) {
        if (parent[city] != city) {
            parent[city] = find(parent[city]);
        }
        return parent[city];
    }

    bool unite(int cityA, int cityB) {
        int rootA = find(cityA);
        int rootB = find(cityB);
        if (rootA == rootB) {
            return false;
        }

        if (rankValue[rootA] < rankValue[rootB]) {
            swap(rootA, rootB);
        }
        parent[rootB] = rootA;
        if (rankValue[rootA] == rankValue[rootB]) {
            rankValue[rootA]++;
        }
        return true;
    }

public:
    int minimumCost(int n, vector<vector<int>>& connections) {
        if (n == 1) {
            return 0;
        }

        sort(connections.begin(), connections.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 return a[2] < b[2];
             });

        parent.resize(n + 1);
        rankValue.assign(n + 1, 0);
        iota(parent.begin(), parent.end(), 0);

        int totalCost = 0;
        int usedEdges = 0;

        for (const vector<int>& connection : connections) {
            int cityA = connection[0];
            int cityB = connection[1];
            int cost = connection[2];

            if (unite(cityA, cityB)) {
                totalCost += cost;
                usedEdges++;
                if (usedEdges == n - 1) {
                    return totalCost;
                }
            }
        }

        return -1;
    }
};

替代方案与面试追问

能否使用 Prim 算法？

可以。把道路建成邻接表，从任意城市出发，用最小堆反复选择连接到未访问城市的最便宜道路。复杂度约为 O(m log n)，稠密图也可用 O(n²) 版本。

为什么选中 n - 1 条边就能停止？

算法始终不形成环；n 个节点的无环连通图恰好有 n - 1 条边，因此达到该数量时已经是一棵生成树。

如果要返回具体道路怎么办？

每次 union 成功时，除累计成本外，再把当前道路加入结果数组；失败返回时丢弃该数组即可。

如果成本可能非常大？

本题约束下 32 位整数足够；若放宽成本或城市数量，应把累计值改为 64 位整数，例如 Java long、C++ long long。

常见错误

只挑最便宜的 n - 1 条道路

它们可能在局部形成环，同时留下孤立城市。必须在每次选择前判断两端是否属于不同连通分量。

用“检查过的边数”判断完成

完成条件是成功采用 n - 1 条边，而不是看过 n - 1 条边；被跳过的成环边不能计入。

城市编号与数组下标混用

题目城市从 1 开始。最简单的做法是创建长度 n + 1 的并查集数组，并忽略下标 0。

遍历结束直接返回累计成本

原图可能不连通。必须确认成功采用的道路数为 n - 1，否则返回 -1。
