花括号展开

把一段紧凑表达式看作一排“选择盒”：普通字母只有一个选项，花括号中的字母提供多个选项。先观察规则，再亲手展开搜索过程。

Brace Expansion付费题排序输出无嵌套花括号

题目

给定字符串 s，其中每一对花括号包围若干以逗号分隔、互不相同的小写字母。表达式没有嵌套。展开时，每个花括号恰好选择一个字母，普通字母保持不变；返回所有可能生成的字符串，并按字典序排列。

示例 1
输入：s = "{a,b}c{d,e}f"
输出：["acdf","acef","bcdf","bcef"]

两个选择组分别有 2 个选项，所以共有 2 × 2 = 4 个结果。

示例 2
输入：s = "abcd"
输出：["abcd"]

约束与接口

  • 1 ≤ s.length ≤ 50
  • s 仅包含小写英文字母、'{'、'}' 和 ','
  • 花括号内至少有两个互不相同的字母
  • 所有花括号均合法配对，且不会嵌套

官方函数形式

expand(s: string): string[]

标签：栈、广度优先搜索、字符串、回溯、排序

Solution

回溯：逐盒做选择

核心洞察

先把表达式解析成选项数组。例如 {a,b}c{d,e}f 变成 [[a,b],[c],[d,e],[f]]。答案就是从每个数组中各取一个字符形成的笛卡尔积。选项先排序，深度优先遍历自然产生字典序结果。

完整过程

  1. 从左到右扫描 s：遇到普通字母就建立单选组；遇到 { 就读到对应的 }，忽略逗号，收集并排序选项。
  2. 执行 DFS。第 i 层代表第 i 个选择盒，依次尝试其中每个字符，并追加到当前路径。
  3. 处理完全部选择盒时，路径就是一个完整答案；记录后回退，继续尝试其他分支。

正确性证明

  1. 合法性：DFS 每层只从对应选择盒中取一个字符，且按原顺序拼接，因此每个输出都符合表达式规则。
  2. 完备性：任意合法结果都对应“每盒一个选项”的唯一序列。DFS 会枚举每层的全部选项，因此必然访问该序列。
  3. 无重复：组内字母互不相同，而不同选择序列至少在一层选择不同，所以生成字符串不同。
  4. 顺序：各组选项升序遍历；DFS 会先穷尽较小前缀，故输出为字典序。

边界情况

没有花括号时只有原字符串一个结果；花括号位于开头或结尾不影响解析；连续选择组照常逐层展开；不要把逗号当作选项。

复杂度

设解析后有 m 个选择盒、答案数为 K、每个结果长度为 m。生成结果需要 O(Km) 时间和 O(m) 递归路径空间（不计输出）；解析与各组排序另需至多 O(n log n) 的宽松上界。

替代方案

也可用 BFS：维护当前前缀列表，每读一个选择盒就生成新列表。逻辑直观，但中间数组复制更多。也可扫描原串时直接 DFS，省去分组数组，不过解析与搜索耦合更紧。

面试追问

  • 如果允许嵌套与并集，应如何改成递归下降解析器？
  • 若答案数量巨大，如何用迭代器按需生成而不是一次性保存？
  • 若花括号内是字符串而非单字符，复杂度表达式如何变化？

常见错误

  • 忘记排序组内选项，导致最终结果不是字典序。
  • 遇到 } 后索引少前进或多前进一位。
  • 回溯后没有撤销路径末尾字符。
  • 先生成再盲目去重，掩盖了解析或状态恢复错误。
JavaDFS
import java.util.*;

class Solution {
    public String[] expand(String s) {
        List<List<Character>> groups = parse(s);
        List<String> ans = new ArrayList<>();
        dfs(groups, 0, new StringBuilder(), ans);
        return ans.toArray(new String[0]);
    }

    private List<List<Character>> parse(String s) {
        List<List<Character>> groups = new ArrayList<>();
        for (int i = 0; i < s.length();) {
            List<Character> group = new ArrayList<>();
            if (s.charAt(i) == '{') {
                i++;
                while (s.charAt(i) != '}') {
                    if (s.charAt(i) != ',') group.add(s.charAt(i));
                    i++;
                }
                i++;
                Collections.sort(group);
            } else {
                group.add(s.charAt(i++));
            }
            groups.add(group);
        }
        return groups;
    }

    private void dfs(List<List<Character>> groups, int i,
                     StringBuilder path, List<String> ans) {
        if (i == groups.size()) {
            ans.add(path.toString());
            return;
        }
        for (char c : groups.get(i)) {
            path.append(c);
            dfs(groups, i + 1, path, ans);
            path.deleteCharAt(path.length() - 1);
        }
    }
}
JavaScriptDFS
/** @param {string} s @return {string[]} */
var expand = function(s) {
  const groups = [];
  for (let i = 0; i < s.length;) {
    if (s[i] !== '{') {
      groups.push([s[i++]]);
      continue;
    }
    const group = [];
    i++;
    while (s[i] !== '}') {
      if (s[i] !== ',') group.push(s[i]);
      i++;
    }
    i++;
    groups.push(group.sort());
  }

  const ans = [];
  const path = [];
  function dfs(index) {
    if (index === groups.length) {
      ans.push(path.join(''));
      return;
    }
    for (const char of groups[index]) {
      path.push(char);
      dfs(index + 1);
      path.pop();
    }
  }
  dfs(0);
  return ans;
};

from typing import List

class Solution:
    def expand(self, s: str) -> List[str]:
        groups = []
        i = 0
        while i < len(s):
            if s[i] != "{":
                groups.append([s[i]])
                i += 1
                continue
            i += 1
            group = []
            while s[i] != "}":
                if s[i] != ",":
                    group.append(s[i])
                i += 1
            i += 1
            groups.append(sorted(group))

        ans, path = [], []
        def dfs(index: int) -> None:
            if index == len(groups):
                ans.append("".join(path))
                return
            for char in groups[index]:
                path.append(char)
                dfs(index + 1)
                path.pop()

        dfs(0)
        return ans
C++DFS
class Solution {
public:
    vector<string> expand(string s) {
        vector<vector<char>> groups;
        for (int i = 0; i < (int)s.size();) {
            vector<char> group;
            if (s[i] == '{') {
                ++i;
                while (s[i] != '}') {
                    if (s[i] != ',') group.push_back(s[i]);
                    ++i;
                }
                ++i;
                sort(group.begin(), group.end());
            } else {
                group.push_back(s[i++]);
            }
            groups.push_back(group);
        }
        vector<string> ans;
        string path;
        dfs(groups, 0, path, ans);
        return ans;
    }

private:
    void dfs(const vector<vector<char>>& groups, int i,
             string& path, vector<string>& ans) {
        if (i == (int)groups.size()) {
            ans.push_back(path);
            return;
        }
        for (char c : groups[i]) {
            path.push_back(c);
            dfs(groups, i + 1, path, ans);
            path.pop_back();
        }
    }
};
