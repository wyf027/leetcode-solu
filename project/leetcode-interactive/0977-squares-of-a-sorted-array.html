有序数组的平方

Squares of a Sorted Array — 观察序列两端，在不额外排序的情况下，把最大的平方倒着放回答案。

难度 简单

标签 数组 双指针 排序

提交函数
sortedSquares(nums)

01题目

给定一个按非递减顺序排列的整数数组 nums，将每个元素平方，并返回同样按非递减顺序排列的新数组。

示例 1
输入：nums = [-4,-1,0,3,10]
输出：[0,1,9,16,100]
解释：平方后为 [16,1,0,9,100]，
      排序后为 [0,1,9,16,100]。
示例 2
输入：nums = [-7,-3,2,3,11]
输出：[4,9,9,49,121]

约束

  • 1 <= nums.length <= 10⁴
  • -10⁴ <= nums[i] <= 10⁴
  • nums 已按非递减顺序排列。

进阶：请设计时间复杂度为 O(n) 的算法。

02双端竞速演示

绿色与橙色指针比较两端绝对值，把更大的平方放入答案最右侧。

STEP 0 / 5
准备开始：左右指针分别站在数组两端。

03核心洞察

平方后的最大值不一定来自原数组右端，但一定来自原数组的某一端。

数组有序时，负数越靠左绝对值可能越大，正数越靠右数值越大。比较两端的平方，较大者就是当前尚未处理元素中的最大平方。因此从答案末尾向前填写，两个指针只需单向靠拢。

04完整过程

  1. 令 left = 0、right = n - 1，并创建长度为 n 的答案数组。
  2. 从 write = n - 1 开始，比较 nums[left]² 与 nums[right]²。
  3. 把较大平方写入 answer[write]，并移动对应一端的指针。
  4. 令 write 左移；重复直到所有位置填满。

05正确性

循环不变式：每轮开始时，答案中 write 右侧已经是所有已处理元素的平方，并且按非递减顺序处于最终位置；未处理元素仍是原数组中 left..right 的连续区间。

区间内部元素的值位于两端值之间，所以其绝对值不会同时超过两端绝对值的最大者。两端平方中较大的一个必然是当前区间的最大平方，把它放入最右侧空位正确。移动对应指针后不变式继续成立。循环结束时所有位置均已正确填写，因此返回数组有序且包含每个输入元素的平方。

复杂度

时间：O(n)，每个元素处理一次。

空间：O(n)，用于返回数组；除返回值外额外空间为 O(1)。

边界情况

  • 仅一个元素或元素为 0。
  • 全为负数：左端平方通常先胜出。
  • 全为非负数：右端平方依次胜出。
  • 两端平方相等：选择任一端都正确。
  • 重复值不会影响非递减结果。

06四语言完整代码

class Solution {
    public int[] sortedSquares(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];
        int left = 0, right = n - 1;
        for (int write = n - 1; write >= 0; write--) {
            int leftSquare = nums[left] * nums[left];
            int rightSquare = nums[right] * nums[right];
            if (leftSquare > rightSquare) {
                answer[write] = leftSquare;
                left++;
            } else {
                answer[write] = rightSquare;
                right--;
            }
        }
        return answer;
    }
}

                answer[write] = leftSquare;

            } else {
                answer[write] = rightSquare;
                --right;
            }
        }
        return answer;

07替代方案与面试追问

替代方案

先逐项平方，再调用排序，代码很短，但时间复杂度为 O(n log n)。它能通过常见数据规模，却没有利用原数组有序这一关键条件。

也可以找到第一个非负数，从正负两段向外归并平方值，同样是 O(n)，但边界处理更繁琐。

面试追问

为什么要从答案末尾填？

两端比较最容易确定的是“当前最大值”，所以从大到小确定位置最自然。

能否原地完成？

若必须保留每个原值直到比较完成，直接覆盖会破坏信息。通常题目允许新建返回数组；若语言容器和输入所有权允许，可讨论额外编码或反转策略，但不再是同样清晰的方案。

整数会溢出吗？

本题上限平方为 10⁸，Java/C++ 的 32 位有符号整数可容纳；更大范围时应使用 64 位类型。

08常见错误

  • 从答案左侧写入较大平方，最终得到降序数组。
  • 比较两端原值而不是绝对值或平方，忽略大负数。
  • 循环条件写成 left < right，漏掉最后一个元素。
  • 移动了错误的一侧指针，导致重复使用或跳过元素。
  • 宣称额外空间为 O(1) 却没有说明“不计返回数组”。
