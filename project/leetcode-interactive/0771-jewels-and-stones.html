题目说明

先读题，再动手

给定字符串 jewels，其中每个字符表示一种宝石类型；再给定字符串 stones，其中每个字符表示你拥有的一颗石头。请返回这些石头中属于宝石的数量。

字母严格区分大小写，所以 "a" 与 "A" 是两种不同类型。

示例 1 输入：jewels = "aA", stones = "aAAbbbb" 输出：3
示例 2 输入：jewels = "z", stones = "ZZ" 输出：0

约束与签名

长度范围1 ≤ jewels.length, stones.length ≤ 50
字符范围两个字符串只包含英文字母
唯一性jewels 中的字符互不相同
函数形式numJewelsInStones(jewels, stones) → integer

Solution

准备好看题解了吗？

先尝试自己总结规则。题解区包含思路、证明、复杂度、追问与四种语言实现。

Core Idea

集合判定，一次扫描

核心洞察：先把所有宝石类型放入一个支持快速成员查询的集合，再逐颗扫描 stones；某颗石头的字符在集合中，就把答案加一。

完整过程

建立类型集合
遍历 jewels，把每个字符加入哈希集合。题目保证字符唯一，但集合也自然具有去重能力。
逐颗检查石头
从左到右遍历 stones，查询当前字符是否存在于宝石集合。
累计并返回
命中时计数加一。扫描结束后，计数就是所有宝石石头的数量。

正确性说明

宝石集合恰好包含 jewels 描述的全部类型。对 stones 中任意一颗石头，算法在且仅在它的类型属于该集合时将计数加一。因此，每颗宝石被计数一次，每颗非宝石都不会被计数。遍历覆盖所有石头，所以最终计数正好等于答案。

复杂度

时间O(J + S)J、S 为两字符串长度
空间O(J)保存宝石类型集合

边界情况

  • 只有一颗石头：根据一次成员查询返回 0 或 1。
  • 全部命中或全部不命中：计数分别为 stones.length 或 0。
  • 重复石头：每次出现都代表一颗实体石头，需要分别计数。
  • 大小写不同：集合按字符精确匹配，a 不会匹配 A。

替代方案

直接双重查找：对每颗石头遍历 jewels，时间为 O(J × S)，写法直观但没有利用快速查询。

固定长度布尔表：题目只含英文字母，可用大小为 128 的数组按字符编码标记，时间仍为 O(J + S)，常数更稳定，但通用性不如集合。

面试追问

  • 若字符扩展到 Unicode，语言中的“字符”遍历和哈希集合有何差异？
  • 若需要处理大量 stones 查询，宝石集合应如何复用？
  • 若输入以数据流到达，怎样做到在线累计且不保存全部石头？
  • 固定字符集下，布尔数组与哈希集合的工程取舍是什么？

常见错误

  • 把答案理解为“出现过的宝石类型数”，从而错误去重 stones。
  • 忽略大小写敏感，先统一转成小写或大写。
  • 遍历了 jewels，只判断每种类型是否在石头中出现，漏掉重复数量。
  • 用字符串拼接等方式累计结果，而不是整数计数。
Implementations

四语言完整代码

JavaHashSet<Character>
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int numJewelsInStones(String jewels, String stones) {
        Set<Character> jewelTypes = new HashSet<>();
        for (char jewel : jewels.toCharArray()) {
            jewelTypes.add(jewel);
        }

        int count = 0;
        for (char stone : stones.toCharArray()) {
            if (jewelTypes.contains(stone)) {
                count++;
            }
        }
        return count;
    }
}

var numJewelsInStones = function(jewels, stones) {
    const jewelTypes = new Set(jewels);
    let count = 0;

    for (const stone of stones) {
        if (jewelTypes.has(stone)) {
            count += 1;
        }
    }
    return count;
};

C++unordered_set
#include <string>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int numJewelsInStones(string jewels, string stones) {
        unordered_set<char> jewelTypes(
            jewels.begin(), jewels.end()
        );
        int count = 0;

        for (char stone : stones) {
            if (jewelTypes.count(stone) > 0) {
                ++count;
            }
        }
        return count;
    }
};
