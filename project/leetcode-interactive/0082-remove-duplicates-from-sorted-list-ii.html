检验任务

给定一个已经升序排列的单链表，删除所有出现次数大于 1 的值所对应的全部节点，并返回仍然升序的链表。

推荐主线 哨兵 + 双指针
目标复杂度 O(n) / O(1)

Sealed analysis

题解

核心洞察、完整推演和四语言代码默认封存。

01 / 核心洞察

判断的是“整段是否重复”

链表升序让相同值必然连续。令 prev 永远指向结果链的最后一个已确认节点，curr 指向待检验段首。若发现相邻值相等，先记住该值并让 curr 越过整个同值段，最后只做一次 prev.next = curr。

02 / 为什么要 dummy

头节点也可能整段消失

当重复段从 head 开始，结果链的新头未知。dummy 放在 head 前面，令 prev 从 dummy 起步，就不再需要“删除头部”这个特判，最终返回 dummy.next 即可。

03 / 完整过程

  1. 1. 建立哨兵dummy.next = head，prev = dummy，curr = head。
  2. 2. 识别重复段若 curr.next 存在且值相同，记录 duplicateValue。
  3. 3. 跨过整段while curr 存在且 curr.val 等于 duplicateValue，持续右移。
  4. 4. 重接链表prev.next = curr；prev 不动，继续检查新接上的节点。
  5. 5. 唯一值前进若 curr 不重复，prev = curr，curr = curr.next。
  6. 6. 返回新头扫描结束后返回 dummy.next。

边界

空链 / 单节点

循环自然不进入重复分支，直接返回原结果。

边界

全部重复

dummy.next 最终指向 null，结果为空链。

复杂度

O(n) / O(1)

每个节点最多被 curr 访问一次，只使用常数指针。

替代方案

哈希计数

易懂但需要 O(n) 空间，也没有利用升序信息，面试不优先。

面试追问

  • • 如果只保留每个值的一个节点，prev/curr 的更新要如何简化？
  • • 如果链表无序，怎样在时间、空间和是否允许修改值之间取舍？
  • • 为什么重复分支结束后 prev 不能跟着 curr 前进？

常见错误

  • • 只删除第二个重复节点，误做成第 83 题“每组保留一个”。
  • • 跳过重复段后移动 prev，导致新相邻节点未经检查。
  • • 没有 dummy，处理头部重复时丢失返回头或堆满特判。
