最小基因变化Minimum Genetic Mutation

一条基因由 8 个碱基组成。每次只能替换一个字符，而且变化后的序列必须得到基因库认可。你的任务，是判断能否抵达目标，并找出最少需要几次变化。

题号 433 难度 Medium 非付费题 字符串 · 图搜索
ACGT
TGCA
GENOME / 8 BASESA · C · G · T

Problem brief

先理解规则，再寻找路径

下面是对官方题意的准确转述。起点默认有效，但不要求出现在基因库中。

题意

给定两个长度均为 8 的基因字符串 startGene、endGene，以及有效基因列表 bank。每个字符只能是 A、C、G、T。

一次变化只允许改动一个位置，且每次变化后得到的基因都必须存在于 bank。返回从起点变为终点所需的最少变化次数；如果不存在合法变化序列，返回 -1。

例如，AACCGGTT → AACCGGTA 只改变了最后一个位置，因此算一次变化。

约束

  • 0 ≤ bank.length ≤ 10
  • startGene.length = 8
  • endGene.length = 8
  • bank[i].length = 8
  • 所有字符串只含 A/C/G/T

核心洞察

把每个合法基因视作图中的节点；两个字符串只差一个字符时，它们之间存在一条边。每条边都代表一次变化、代价都为 1，因此要找最少变化次数，本质上是在无权图中寻找从起点到终点的最短路。

为什么使用广度优先搜索

广度优先搜索按距离逐层扩展。第一次发现 endGene 时，当前层数就是最短距离；同层或更深层的路径不可能更短。

完整过程

  1. 若 startGene == endGene，答案为 0。否则，如果终点不在基因库中，直接返回 -1。
  2. 将基因库放入哈希集合，队列初始放入起点，并用集合记录已访问序列。
  3. 从队首取出一个基因，依次枚举 8 个位置，并把该位置尝试替换为 A、C、G、T 中不同于原字符的三种字符。
  4. 若候选序列等于终点，返回当前步数加 1；若候选存在于基因库且从未访问，则标记并加入队列。
  5. 队列耗尽仍未找到终点，说明合法序列构成的图中不存在可达路径，返回 -1。

正确性说明

  • 合法性：只有属于 bank 的候选才会入队，因此搜索中的每一步变化都合法。
  • 完备性：对每个出队基因枚举所有位置和所有可能碱基，因而不会漏掉任何一步可达的合法邻居。
  • 最优性：队列按距离递增处理节点。首次找到终点时，所有更短距离的节点都已处理完，所以得到的变化次数最少。
  • 终止性：每个合法基因最多入队一次，而基因库有限，因此算法必然终止。

边界情况

  • 起点与终点相同：返回 0。
  • 终点不在基因库：除起终点相同外，返回 -1。
  • 基因库为空：无法进行任何有效变化。
  • 存在环或重复项：访问集合避免重复搜索。
  • 终点在库中但与起点不连通：队列耗尽后返回 -1。

复杂度

设基因库中有 B 个序列，基因长度为 L，字符集大小为 Σ = 4。每个节点枚举 L × Σ 个变化；若把构造长度为 L 的新字符串计入，严格时间复杂度为 O(B × Σ × L²)，在字符串构造视为常数或本题固定 L = 8 的常用模型下写作 O(B × Σ × L)。空间复杂度为 O(B × L)。

替代方案

  • 双向 BFS：同时从起点和终点扩展较小的一侧，基因库较大时通常能显著减少搜索状态。
  • 预建邻接表：两两比较银行序列，预处理代价 O(B²L)；本题 B ≤ 10 时也可行，但不如现场生成邻居直接。
  • DFS：能判断可达，但要额外维护最优值并穷举路径，不适合单位权最短路。

JavaLeetCode 可提交
import java.util.*;

class Solution {
    public int minMutation(String startGene, String endGene, String[] bank) {
        if (startGene.equals(endGene)) return 0;

        Set<String> valid = new HashSet<>(Arrays.asList(bank));
        if (!valid.contains(endGene)) return -1;

        Queue<String> queue = new ArrayDeque<>();
        Set<String> seen = new HashSet<>();
        queue.offer(startGene);
        seen.add(startGene);
        char[] genes = {'A', 'C', 'G', 'T'};
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                String current = queue.poll();
                char[] chars = current.toCharArray();

                for (int pos = 0; pos < chars.length; pos++) {
                    char original = chars[pos];
                    for (char gene : genes) {
                        if (gene == original) continue;
                        chars[pos] = gene;
                        String next = new String(chars);

                        if (next.equals(endGene)) return steps + 1;
                        if (valid.contains(next) && seen.add(next)) {
                            queue.offer(next);
                        }
                    }
                    chars[pos] = original;
                }
            }
            steps++;
        }
        return -1;
    }
}
JavaScriptLeetCode 可提交
/**
 * @param {string} startGene
 * @param {string} endGene
 * @param {string[]} bank
 * @return {number}
 */
var minMutation = function(startGene, endGene, bank) {
    if (startGene === endGene) return 0;

    const valid = new Set(bank);
    if (!valid.has(endGene)) return -1;

    const queue = [startGene];
    const seen = new Set([startGene]);
    const genes = ['A', 'C', 'G', 'T'];
    let head = 0;
    let steps = 0;

    while (head < queue.length) {
        const levelEnd = queue.length;
        while (head < levelEnd) {
            const current = queue[head++];
            const chars = current.split('');

            for (let pos = 0; pos < chars.length; pos++) {
                const original = chars[pos];
                for (const gene of genes) {
                    if (gene === original) continue;
                    chars[pos] = gene;
                    const next = chars.join('');

                    if (next === endGene) return steps + 1;
                    if (valid.has(next) && !seen.has(next)) {
                        seen.add(next);
                        queue.push(next);
                    }
                }
                chars[pos] = original;
            }
        }
        steps++;
    }
    return -1;
};
Python 3LeetCode 可提交
from collections import deque
from typing import List


class Solution:
    def minMutation(
        self, startGene: str, endGene: str, bank: List[str]
    ) -> int:
        if startGene == endGene:
            return 0

        valid = set(bank)
        if endGene not in valid:
            return -1

        queue = deque([(startGene, 0)])
        seen = {startGene}
        genes = "ACGT"

        while queue:
            current, steps = queue.popleft()
            chars = list(current)

            for pos, original in enumerate(chars):
                for gene in genes:
                    if gene == original:
                        continue
                    chars[pos] = gene
                    nxt = "".join(chars)

                    if nxt == endGene:
                        return steps + 1
                    if nxt in valid and nxt not in seen:
                        seen.add(nxt)
                        queue.append((nxt, steps + 1))
                chars[pos] = original

        return -1
C++LeetCode 可提交
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int minMutation(string startGene, string endGene,
                    vector<string>& bank) {
        if (startGene == endGene) return 0;

        unordered_set<string> valid(bank.begin(), bank.end());
        if (!valid.count(endGene)) return -1;

        queue<string> q;
        unordered_set<string> seen;
        q.push(startGene);
        seen.insert(startGene);
        const string genes = "ACGT";
        int steps = 0;

        while (!q.empty()) {
            int size = static_cast<int>(q.size());
            while (size--) {
                string current = q.front();
                q.pop();

                for (int pos = 0; pos < static_cast<int>(current.size()); pos++) {
                    char original = current[pos];
                    for (char gene : genes) {
                        if (gene == original) continue;
                        current[pos] = gene;

                        if (current == endGene) return steps + 1;
                        if (valid.count(current) && !seen.count(current)) {
                            seen.insert(current);
                            q.push(current);
                        }
                    }
                    current[pos] = original;
                }
            }
            steps++;
        }
        return -1;
    }
};

常见错误

  • 允许中间基因不在 bank 中。
  • 忘记恢复被试改的字符，导致后续候选基于错误字符串生成。
  • 入队后才标记访问，使同一节点被多次加入队列。
  • 把起点也强制要求存在于基因库中。
  • 只判断终点是否在库中，却没有判断它是否实际可达。
