用栈实现队列

Implement Queue using Stacks：仅使用两个标准栈操作，实现 FIFO 队列的 push、peek、pop 与 empty。

in 栈：新元素out 栈：队首均摊 O(1)

题意

只靠两个 LIFO 栈得到 FIFO

实现 MyQueue：push(x) 加到队尾，peek() 看队首，pop() 移除队首，empty() 判断是否为空。只能使用 push/top/pop/size/isEmpty 这类栈操作。

输入：["MyQueue","push","push","peek","pop","empty"]

参数：[[],[1],[2],[],[],[]]

输出：[null,null,null,1,1,false]

队列写作 [front, ..., back]；字符串会保持成对直引号。

核心洞察

只在 out 为空时倒入

push 始终进入 in。peek/pop 需要队首时，若 out 为空，将 in 逐个弹出并压到 out，顺序正好反转；之后 out 栈顶就是最早入队的元素。

均摊分析：每个元素最多入/出 in 和入/出 out 各一次，n 次总操作 O(n)，所以每次均摊 O(1)。

题解：延迟转移

将所有入队元素放入 in。pop/peek 之前调用 move：只有 out 为空时才搬运 in→out。这样不重复搬运已就绪元素，也避免每次 push 都 O(n)。

完整过程

  1. push(x)：in.push(x)。
  2. move()：若 out 空，循环 in.pop() 后 out.push()。
  3. peek()：move 后 out.top()。
  4. pop()：move 后 out.pop()。

复杂度与边界

单次 move 可为 O(n)，但每个元素只转移一次，均摊 O(1)；空间 O(n)。注意 out 非空时绝不重新倒入，否则 FIFO 顺序会坏。

替代方案取舍

也可在每次 push 时搬运，令 pop O(1)，但 push 变 O(n)。延迟转移同时让 push O(1)，更符合 follow-up。

常见错误 / 追问

常见错误是每次 peek 都搬运，或 pop 直接从 in 弹出。追问：用两个队列模拟栈时，转移目标与时机相反。
