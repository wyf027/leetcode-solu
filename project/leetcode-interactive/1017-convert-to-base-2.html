题目

给定整数 n，返回它的 −2 进制表示字符串。除结果本身为 "0" 外，结果不能有前导零。

函数：baseNeg2(n: integer): string

示例 1
输入：n = 2
输出："110"
解释：(-2)² + (-2)¹ = 2
示例 2
输入：n = 3
输出："111"
解释：(-2)² + (-2)¹ + (-2)⁰ = 3
示例 3
输入：n = 4
输出："100"
解释：(-2)² = 4

约束：0 ≤ n ≤ 10⁹

先想想：为什么最低位只由奇偶性决定？

题解

核心洞察

任何整数可写成 n=(-2)q+r，最低位 r 只能为 0 或 1。用 r=n&1 得到合法余数，再令 n=(n-r)/(-2)，该除法必然整除。

完整过程

  1. n=0 时直接返回 "0"。
  2. 重复取 r=n&1 并记录。
  3. 更新 n=(n-r)/-2。
  4. 逆序全部余数得到答案。

正确性

每轮保持 旧n=(-2)×新n+r，且 r∈{0,1}，所以记录的是唯一合法最低位。逐轮代入后，原数等于各余数与对应 (-2)^i 的乘积之和；商归零时全部位已确定。最后产生的最高位非零，因此没有前导零。

边界

  • 零必须特判。
  • 商正负交替是正常现象。
  • 奇数的当前余数恒为 1。

复杂度

时间 O(log n)；答案占用 O(log n) 空间，除此之外为 O(1)。

替代方案

可直接对 −2 除法取模；若语言产生负余数，需要把余数加 2、商加 1。位运算方案避开不同语言的负数取模差异。

常见错误

  • 直接保留负余数，产生非法数字位。
  • 忘记零值特判，返回空串。
  • 未逆序余数，导致高低位颠倒。
