二叉树的所有路径

Binary Tree Paths：枚举从根到每一个叶子节点的路径。递归 DFS 把当前路径当作可撤销的足迹。

深度优先搜索叶子收集回溯弹出

题意

输出所有 root-to-leaf 路径

给定二叉树根节点，返回所有从根到叶子的路径，顺序不限。叶子节点是没有左右孩子的节点。

输入：root = [1, 2, 3, null, 5]

输出：["1->2->5", "1->3"]

数组层序表示中 null 表示空孩子；字符串保留成对直引号。

核心洞察

到叶子才复制一份路径

进入节点时将值放入 path。若是叶子，将 path 用 -> 连接后加入答案；否则继续左右子树。递归返回时 pop，保证兄弟子树不继承前一条路。

不变量：每次 dfs(node) 入口时，path 恰好是 root 到 node 的祖先路径；离开时必须恢复到进入前状态。

题解：DFS + 回溯

使用一个共享列表 path，进入节点 push；叶子处 join 并复制到结果；访问完孩子后 pop。也可向递归传递路径字符串，免去 pop 但每层创建字符串。

完整过程

  1. 空节点直接返回。
  2. 压入当前 node.val。
  3. 叶子则记录 joined path。
  4. 递归左右孩子，最后 pop。

复杂度与边界

遍历节点 O(n)，输出本身需要所有路径字符总量；递归栈 O(h)。单节点只有一条路径，偏斜树的递归深度为 n。

替代方案

BFS 队列携带节点与路径可避免深递归，但会保留更多中间路径。DFS 的路径栈最节省并符合“根到叶”结构。

常见错误 / 追问

叶子判断必须是左右都空；忘记 pop 会污染兄弟路径。追问：如何输出所有根到目标和的路径？在叶子收集前再加和条件。
