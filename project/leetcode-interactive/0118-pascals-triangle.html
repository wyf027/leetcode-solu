01 / Problem

先确定机器要印什么

输入行数 numRows，返回杨辉三角的前 numRows 行。每行首尾都是 1，内部数字等于上一行相邻两个数字之和。

题意与官方样例

给定整数 numRows，按从顶到底的顺序返回二维数组；第 i 行包含 i + 1 个数。

官方样例 1 · 输入
numRows = 5
输出
[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
官方样例 2 · 输入
numRows = 1
输出
[[1]]
约束与读法
1 <= numRows <= 30
第 0 行只有一个 1。
内部位置满足 row[j] = prev[j - 1] + prev[j]。
返回所有行，不是只返回最后一行。

Answer / Revealed

逐行动态构造

面试最推荐的主线：复用已经生成的上一行，先把当前行首尾设为 1，再计算所有内部位置。

核心洞察

第 i 行只依赖第 i - 1 行。把每行视为一次印刷任务，首尾是固定模板，内部格才需要从两个来源混色相加。

完整过程

  1. 创建空的二维结果 triangle。
  2. 从 i = 0 到 numRows - 1 建立长度 i + 1 的行。
  3. 令行首与行尾为 1。
  4. 对每个内部下标 j，写入上一行的 j - 1 与 j 之和。
  5. 把完成的一行加入结果。

边界

  • numRows = 1：循环只生成 [1]。
  • 前两行没有内部位置，内部循环自然执行零次。
  • numRows = 30 时整数仍在 32 位有符号范围内。
  • 注意题目保证 numRows ≥ 1，无需额外处理零行。

复杂度

O(n²) 总共生成 n(n + 1) / 2 个数字
O(n²) 返回值本身占用的空间；额外空间 O(1)

替代方案取舍

可以用组合数公式 C(i, j) 逐格递推，省去读取上一行；但乘除顺序更容易引入溢出与整数除法错误。逐行 DP 更直观、稳定，也最符合面试沟通习惯。

常见错误

  • 把内部循环写成覆盖行尾，导致最后一个 1 被改写。
  • 读取当前行而不是上一行，造成未初始化值参与计算。
  • 所有行复用同一个可变数组，最终结果变成多份最后一行。
  • 只返回最后一行，误做成第 119 题。

面试追问

  • 如果只需要第 rowIndex 行，怎样把额外空间降到 O(rowIndex)？从右向左原地更新一维数组。
  • 为什么内部循环边界是 1 ≤ j < i？因为下标 0 与 i 是固定边缘。
  • 能否使用组合数公式？可以，但需说明溢出和整除顺序。
  • 如何证明正确？用行号归纳：边缘正确，内部位置由上一行两个已正确值相加得到。

class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> triangle = new ArrayList<>();

        for (int i = 0; i < numRows; i++) {
            List<Integer> row = new ArrayList<>(
                Collections.nCopies(i + 1, 1)
            );
            for (int j = 1; j < i; j++) {
                row.set(
                    j,
                    triangle.get(i - 1).get(j - 1)
                        + triangle.get(i - 1).get(j)
                );
            }
            triangle.add(row);
        }

        return triangle;
    }
}
var generate = function (numRows) {
    const triangle = [];

    for (let i = 0; i < numRows; i++) {
        const row = new Array(i + 1).fill(1);
        for (let j = 1; j < i; j++) {
            row[j] = triangle[i - 1][j - 1] + triangle[i - 1][j];
        }
        triangle.push(row);
    }

    return triangle;
};
class Solution:
    def generate(self, numRows: int) -> List[List[int]]:
        triangle = []

        for i in range(numRows):
            row = [1] * (i + 1)
            for j in range(1, i):
                row[j] = triangle[i - 1][j - 1] + triangle[i - 1][j]
            triangle.append(row)

        return triangle
