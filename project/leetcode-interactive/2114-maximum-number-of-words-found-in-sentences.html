2114 · 句子中的最多单词数

Maximum Number of Words Found in Sentences

先理解输入与目标，再展开题解探索字符与单词之间的关系。

题目说明

给定字符串数组 sentences，每个元素是一句话。句子由一个或多个单词组成，相邻单词之间只有一个空格，首尾没有空格。请返回这些句子中，单个句子的最大单词数。

参数：sentences: string[]　返回值：integer

求的是单句最大值；多句话并列最多时，仍只返回这个数量。

约束

  • 1 ≤ sentences.length ≤ 100。
  • 1 ≤ sentences[i].length ≤ 100。
  • 每句话只包含小写英文字母和空格 ' '。
  • 每句话的开头和结尾都没有空格。
  • 相邻单词由恰好一个空格分隔。

题解 · 沿着空格寻找单词边界

核心洞察

若一句话有 k 个单词，则相邻单词之间恰有 k − 1 个空格。因此，单词数 = 空格数 + 1。题目的非空、单空格及无首尾空格保证这条关系成立。

完整过程

  1. 设最大值 best = 0。
  2. 对每句话，把当前单词数 words 重置为 1。
  3. 遍历字符，只在字符等于空格时增加 words。
  4. 当前句子遍历结束，执行 best = max(best, words)。
  5. 所有句子处理完，返回 best。

示例 1 中，三句话分别遇到 4、3、5 个空格，得到 5、4、6 个单词；全局最大值依次是 5、5、6。

正确性说明

内层不变式：处理当前句子的任意字符前缀后，words 等于 1 加上该前缀内的空格数。初值为 1；读到字母时不变，读到空格时加 1，所以不变式始终成立。扫描结束时，由单词与空格的对应关系，计数即该句单词数。

外层不变式：处理完前 i 句话后，best 是这 i 句话的最大单词数。初始 0 作为非负计数的起点；每次与准确的当前句计数取最大值，保持不变式。全部处理后得到题目要求的答案。

边界与复杂度

只有一个单词时没有空格，初始值 1 就是答案；并列最大时无需特殊处理；每句话都必须重新计数。单句长度最多 100，在合法格式下最多有 50 个单词。

设 T 为所有字符串的字符总数，时间复杂度 O(T)，额外空间复杂度 O(1)。下列实现只保留计数器，不分配分词数组。可视化保存步骤用于回退，其内存开销不属于提交算法的复杂度。

替代方案

对每句话用空格切分，再取数组长度的最大值，写法直接，时间仍为 O(T)，但通常需要 O(L) 的额外空间保存当前句子的分词结果，L 是最大句长。Python 也可用 sentence.count(' ') + 1。逐字符计数避免创建分词数组。

常见错误

  • 从 0 开始计单词却忘记最后加 1，导致所有句子少算一个。
  • 把不同句子的单词数相加；题目要单句最大值。
  • 新句子开始时没有把 words 重置为 1。
  • 用字符串长度比较句子：一个很长的单词也只算一个。
  • 把这个公式直接用于含首尾空格、连续空格或空字符串的其他题目。

面试追问

允许连续空白和空句怎么办？改为检测“空白 → 非空白”的状态转换，每次进入一个单词时计数，并明确空白字符的定义。

句子以流的方式到达怎么办？保留当前句计数和全局最大值；收到句末标记时更新最大值并重置当前计数。

还要返回句子下标怎么办？在严格大于最大值时记录下标即可保留最早获胜者；若要所有并列者，则在超过时清空列表，相等时追加下标。

Java

class Solution {
    public int mostWordsFound(String[] sentences) {
        int best = 0;
        for (String sentence : sentences) {
            int words = 1;
            for (int i = 0; i < sentence.length(); i++) {
                if (sentence.charAt(i) == ' ') words++;
            }
            best = Math.max(best, words);
        }
        return best;
    }
}

var mostWordsFound = function(sentences) {
    let best = 0;
    for (const sentence of sentences) {
        let words = 1;
        for (let i = 0; i < sentence.length; i++) {
            if (sentence[i] === ' ') words++;
        }
        best = Math.max(best, words);
    }
    return best;
};

Python 3

from typing import List

class Solution:
    def mostWordsFound(self, sentences: List[str]) -> int:
        best = 0
        for sentence in sentences:
            words = 1
            for char in sentence:
                if char == ' ':
                    words += 1
            best = max(best, words)
        return best
