886. 可能的二分法

Possible Bipartition

把“不喜欢”画成连线：能否把所有人放进两个组，让每条连线的两端永远分处两侧？先亲手走一遍，再决定是否展开题解。

PROBLEM

题目描述

01

有 n 个人，编号为 1 到 n。数组 dislikes 的每项 [aᵢ, bᵢ] 表示这两个人不能在同一组。请把所有人分进两个大小任意的组；存在合法分法时返回 true，否则返回 false。

参数：possibleBipartition(n, dislikes)；两个组可大小不同，也允许其中一组为空。

官方示例

示例 1
输入：n = 4,
dislikes = [[1,2],[1,3],[2,4]]
输出：true
解释：可分为 [1,4] 与 [2,3]。
示例 2
输入：n = 3,
dislikes = [[1,2],[1,3],[2,3]]
输出：false
解释：三人两两不能同组，两个组不够。
示例 3
输入：n = 5,
dislikes = [[1,2],[2,3],[3,4],
            [4,5],[1,5]]
输出：false

约束

  • 1 ≤ n ≤ 2000
  • 0 ≤ dislikes.length ≤ 10⁴
  • dislikes[i].length == 2
  • 1 ≤ aᵢ < bᵢ ≤ n
  • 每对 dislike 关系互不重复。

ANSWER

题解：连通分量内二染色

04

核心洞察

把人视为节点，把 dislike 关系视为无向边。每条边两端必须进入不同组，等价于判断图是否为二分图。以 1、-1 表示两组，0 表示未访问。

完整过程

  1. 建立无向邻接表。
  2. 遍历所有人，遇到未染色节点便赋色 1 并启动 BFS。
  3. 邻居未染色则赋相反颜色并入队；邻居同色则返回 false。
  4. 全部连通分量无冲突则返回 true。

正确性证明

  1. 异色不变量：首次发现邻居时，算法总把它染为当前节点的相反颜色，所以每条树边两端异色。
  2. 冲突必然无解：若一条边两端同色，染色路径与该边组成奇环；奇环不可能只用两色让相邻节点异色。
  3. 无冲突即可构造：算法检查每个分量的每条边。结束时把颜色 1 与 -1 的节点分别放入两组，全部限制均满足。

复杂度

设关系数为 m。时间为 O(n + m)；邻接表、颜色数组与队列合计空间为 O(n + m)。

边界情况

  • 无 dislike 时返回 true。
  • 图不连通时需逐个启动 BFS。
  • 孤立节点可任取颜色。
  • 奇环必然导致冲突。

替代方案

DFS 染色的时间、空间量级相同，递归实现需留意调用栈。也可使用带对立关系的并查集，但实现更绕。

面试追问

  • 为什么同色边对应奇环？
  • 如何返回具体两组？
  • 动态加入关系时如何维护答案？
  • 为什么只从节点 1 出发不够？

常见错误

  • 漏掉其他连通分量。
  • 误把 dislike 当成单向边。
  • 不检查已染色邻居是否同色。
  • 把颜色 0 当作有效分组。
  • JavaScript 用 shift() 做大队列，产生额外搬移成本。

完整代码

Java
import java.util.*;

class Solution {
    public boolean possibleBipartition(int n, int[][] dislikes) {
        List<Integer>[] graph = new ArrayList[n + 1];
        for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : dislikes) {
            graph[edge[0]].add(edge[1]);
            graph[edge[1]].add(edge[0]);
        }
        int[] color = new int[n + 1];
        Queue<Integer> queue = new ArrayDeque<>();
        for (int start = 1; start <= n; start++) {
            if (color[start] != 0) continue;
            color[start] = 1;
            queue.offer(start);
            while (!queue.isEmpty()) {
                int person = queue.poll();
                for (int neighbor : graph[person]) {
                    if (color[neighbor] == 0) {
                        color[neighbor] = -color[person];
                        queue.offer(neighbor);
                    } else if (color[neighbor] == color[person]) {
                        return false;
                    }
                }
            }
        }
        return true;
    }
}

var possibleBipartition = function(n, dislikes) {
    const graph = Array.from({ length: n + 1 }, () => []);
    for (const [a, b] of dislikes) {
        graph[a].push(b);
        graph[b].push(a);
    }
    const color = new Int8Array(n + 1);
    const queue = [];
    for (let start = 1; start <= n; start++) {
        if (color[start] !== 0) continue;
        color[start] = 1;
        queue.length = 0;
        queue.push(start);
        let head = 0;
        while (head < queue.length) {
            const person = queue[head++];
            for (const neighbor of graph[person]) {
                if (color[neighbor] === 0) {
                    color[neighbor] = -color[person];
                    queue.push(neighbor);
                } else if (color[neighbor] === color[person]) {
                    return false;
                }
            }
        }
    }
    return true;
};

from collections import deque
from typing import List

class Solution:
    def possibleBipartition(
        self, n: int, dislikes: List[List[int]]
    ) -> bool:
        graph = [[] for _ in range(n + 1)]
        for a, b in dislikes:
            graph[a].append(b)
            graph[b].append(a)
        color = [0] * (n + 1)
        for start in range(1, n + 1):
            if color[start] != 0:
                continue
            color[start] = 1
            queue = deque([start])
            while queue:
                person = queue.popleft()
                for neighbor in graph[person]:
                    if color[neighbor] == 0:
                        color[neighbor] = -color[person]
                        queue.append(neighbor)
                    elif color[neighbor] == color[person]:
                        return False
        return True

#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    bool possibleBipartition(int n, vector<vector<int>>& dislikes) {
        vector<vector<int>> graph(n + 1);
        for (const auto& edge : dislikes) {
            graph[edge[0]].push_back(edge[1]);
            graph[edge[1]].push_back(edge[0]);
        }
        vector<int> color(n + 1, 0);
        queue<int> pending;
        for (int start = 1; start <= n; ++start) {
            if (color[start] != 0) continue;
            color[start] = 1;
            pending.push(start);
            while (!pending.empty()) {
                int person = pending.front();
                pending.pop();
                for (int neighbor : graph[person]) {
                    if (color[neighbor] == 0) {
                        color[neighbor] = -color[person];
                        pending.push(neighbor);
                    } else if (color[neighbor] == color[person]) {
                        return false;
                    }
                }
            }
        }
        return true;
    }
};
