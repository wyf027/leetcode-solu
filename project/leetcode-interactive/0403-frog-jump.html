Frog Jump

青蛙过河

石头是落脚点，跳跃长度是惯性。每一次落地，都同时改变了位置与下一步的选择范围。

Problem

题意

一只青蛙要借助河中的石头到达对岸。给定严格递增的石头位置数组 stones，青蛙起初站在第一块石头 0 上，第一跳必须恰好为 1 个单位。

若上一次跳了 k 个单位，下一次只能向前跳 k - 1、k 或 k + 1 个单位，且落点必须存在石头。请判断它能否落到最后一块石头。

Function contract

canCross(stones: integer[]) → boolean

输入
严格递增的整数数组
输出
能否到达最后一块石头

示例 1

输入：stones = [0,1,3,5,6,8,12,17]
输出：true
解释：可依次跳跃 1、2、2、3、4、5 个单位，
      最终落到位置 17。

示例 2

输入：stones = [0,1,2,3,4,8,9,11]
输出：false
解释：位置 4 与 8 之间的间隔过大，
      现有跳跃长度无法跨越。

约束

  • 2 ≤ stones.length ≤ 2000
  • 0 ≤ stones[i] ≤ 2³¹ - 1
  • stones[0] == 0
  • stones 按严格升序排列

Solution

题解：石头位置 × 上一跳长度

位置本身不足以描述状态：同一块石头若以不同跳长抵达，下一步的选择也不同。因此要保存每块石头可由哪些“最后一跳长度”到达。

核心洞察

定义 reachable[i] 为到达 stones[i] 时，所有可能的最后一跳长度集合。初始把 0 放入第一块石头的集合。

从状态 (i, k) 出发，只尝试正数 k-1、k、k+1。如果位置 stones[i] + jump 有石头，就把 jump 加入对应集合。

为什么用哈希结构

用“位置 → 下标”的哈希表，可以在常数期望时间判断落点是否存在；每块石头的跳长集合也用哈希集合去重，避免重复扩散同一状态。

必要剪枝：跳长必须大于 0；只向前跳，绝不保留 0 或负数跳长。

完整过程

  1. 建立索引。 把每个石头位置映射到数组下标。
  2. 初始化。 在位置 0 的集合中放入最后跳长 0，这会自然地产生唯一合法的第一跳 1。
  3. 扩散状态。 枚举石头及其所有可达跳长，再枚举三个候选下一跳。
  4. 记录落点。 候选跳长为正且落点有石头时，加入目标石头的集合。
  5. 检查终点。 最后一块石头的集合非空，等价于存在一条合法过河路径。

正确性证明

不变式：对任意 i 与正整数 k，k ∈ reachable[i] 当且仅当存在一组合法跳跃，使青蛙以长度 k 的最后一跳落到 stones[i]。

可靠性：算法只从已可达状态扩展，并且只添加 k-1/k/k+1 中为正、且真实落在石头上的跳长，所以新增状态必然对应合法路径。

完备性：任意合法路径的下一跳必属于这三个候选之一；算法会枚举前一状态并检查对应落点，因此所有合法后继都会被加入。

由归纳可得不变式成立。于是终点集合非空，当且仅当青蛙能过河。

边界与复杂度

  • 若第二块石头不在位置 1，可直接返回 false。
  • 两块石头 [0,1] 可由第一跳直接到达。
  • 集合去重很重要，否则相同状态会被反复处理。
  • 坐标可能接近 32 位整数上界；Java/C++ 计算落点时用更宽整数避免溢出。

时间复杂度：O(n²) 最坏情况。

空间复杂度：O(n²) 最坏情况。

import java.util.*;

class Solution {
    public boolean canCross(int[] stones) {
        if (stones.length < 2 || stones[1] != 1) {
            return false;
        }

        Map<Integer, Integer> indexByPosition = new HashMap<>();
        List<Set<Integer>> reachable = new ArrayList<>();
        for (int i = 0; i < stones.length; i++) {
            indexByPosition.put(stones[i], i);
            reachable.add(new HashSet<>());
        }
        reachable.get(0).add(0);

        for (int i = 0; i < stones.length; i++) {
            for (int lastJump : reachable.get(i)) {
                for (int nextJump = lastJump - 1;
                     nextJump <= lastJump + 1; nextJump++) {
                    if (nextJump <= 0) continue;

                    long nextPosition = (long) stones[i] + nextJump;
                    if (nextPosition > Integer.MAX_VALUE) continue;
                    Integer nextIndex = indexByPosition.get((int) nextPosition);
                    if (nextIndex != null) {
                        if (nextIndex == stones.length - 1) return true;
                        reachable.get(nextIndex).add(nextJump);
                    }
                }
            }
        }
        return !reachable.get(stones.length - 1).isEmpty();
    }
}

var canCross = function(stones) {
    if (stones.length < 2 || stones[1] !== 1) {
        return false;
    }

    const indexByPosition = new Map();
    const reachable = stones.map(() => new Set());
    stones.forEach((position, index) => {
        indexByPosition.set(position, index);
    });
    reachable[0].add(0);

    for (let i = 0; i < stones.length; i++) {
        for (const lastJump of reachable[i]) {
            for (const nextJump of [lastJump - 1, lastJump, lastJump + 1]) {
                if (nextJump <= 0) continue;
                const nextIndex = indexByPosition.get(stones[i] + nextJump);
                if (nextIndex !== undefined) {
                    if (nextIndex === stones.length - 1) return true;
                    reachable[nextIndex].add(nextJump);
                }
            }
        }
    }
    return reachable[stones.length - 1].size > 0;
};

class Solution:
    def canCross(self, stones: List[int]) -> bool:
        if len(stones) < 2 or stones[1] != 1:
            return False

        index_by_position = {
            position: index for index, position in enumerate(stones)
        }
        reachable = [set() for _ in stones]
        reachable[0].add(0)

        for index, position in enumerate(stones):
            for last_jump in reachable[index]:
                for next_jump in (
                    last_jump - 1, last_jump, last_jump + 1
                ):
                    if next_jump <= 0:
                        continue
                    next_index = index_by_position.get(position + next_jump)
                    if next_index is not None:
                        if next_index == len(stones) - 1:
                            return True
                        reachable[next_index].add(next_jump)

        return bool(reachable[-1])
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    bool canCross(vector<int>& stones) {
        const int n = static_cast<int>(stones.size());
        if (n < 2 || stones[1] != 1) {
            return false;
        }

        unordered_map<long long, int> indexByPosition;
        vector<unordered_set<int>> reachable(n);
        for (int i = 0; i < n; ++i) {
            indexByPosition[stones[i]] = i;
        }
        reachable[0].insert(0);

        for (int i = 0; i < n; ++i) {
            for (int lastJump : reachable[i]) {
                for (int nextJump = lastJump - 1;
                     nextJump <= lastJump + 1; ++nextJump) {
                    if (nextJump <= 0) continue;
                    const long long nextPosition =
                        static_cast<long long>(stones[i]) + nextJump;
                    auto it = indexByPosition.find(nextPosition);
                    if (it != indexByPosition.end()) {
                        if (it->second == n - 1) return true;
                        reachable[it->second].insert(nextJump);
                    }
                }
            }
        }
        return !reachable.back().empty();
    }
};

替代方案

记忆化 DFS：状态同样是 (stoneIndex, lastJump)，递归尝试三个下一跳并缓存结果。它通常能更早找到成功路径，但需要留意递归深度。

二维布尔 DP：用 dp[i][k] 表示状态，查询直观但固定矩阵可能保存大量永远不可达的格子；集合版本更稀疏。

常见错误

  • 只记录“石头是否可达”，丢失上一跳长度。
  • 允许下一跳为 0，导致原地状态或重复处理。
  • 用线性扫描寻找落点，使复杂度额外升高。
  • 把“第一跳为 1”误写成第一块石头必须位于 1。
  • 在 32 位整数上直接相加，忽略潜在溢出。

面试追问

Q：能否提前判定必败？

可以检查相邻石头间距：到第 i 块石头前，跳长不可能超过 i；若当前间距大于 i，就无法跨越。

Q：为什么最坏仍是 O(n²)？

一块石头可能由多种跳长抵达；不同“位置 × 跳长”状态总数在最坏情况下是平方级。

Q：如何还原一条成功路径？

首次加入状态时保存父指针：从 (nextIndex,nextJump) 指回 (index,lastJump)，到终点后逆序回溯。

Q：集合 DP 与 DFS 如何选择？

只需布尔答案时两者都合适；迭代 DP 无递归栈风险，DFS 在成功路径较浅时可能更早退出。
