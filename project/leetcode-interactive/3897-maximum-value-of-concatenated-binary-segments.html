3897. 连接二进制片段得到的最大值

每段固定为若干个 1 后接若干个 0。改变段的顺序即可改变整串的数值；目标是找出让高位尽量早出现 1 的排列。

题意

先排片段，再把它们视作二进制数追加

第 i 段为 "1" × nums1[i] + "0" × nums0[i]。允许重新排列整段，不能拆开段内字符。

返回最终二进制串的最大十进制值，并对 1_000_000_007 取模。

示例
nums1 = [1, 2]
nums0 = [1, 0]
片段为 "10"、"11"；最优顺序为 "11" + "10" = "1110"，结果为 14。

题解

为什么这组排序一定最优？

比较任意两个段 A = 1ᵃ0ᵇ、B = 1ᶜ0ᵈ。先把 b = 0 的纯 1 段放在最前：它们延长最高位的连续 1。对其余两段（都含至少一个 0），若 a > c，AB 的第一个分歧位为 1 而 BA 为 0，所以 A 在前；若 a = c，零更少的段更早回到后一个段的前导 1，故 b 升序。

有了顺序，把长度为 L、数值为 V 的段接到当前答案后：ans = ans × 2ᴸ + V。其中 V = (2ᵃ − 1) × 2ᵇ。

复杂度

排序 O(n log n)；预处理幂和追加为 O(S)，其中 S 是所有位数之和（至多 2×10⁵）。空间 O(n + S)。

边界与常见错误

单段也要走追加公式；不能按原下标拼接；纯 1 段要整体优先；其余同样多的 1 才让 0 更少的段在前；乘法用 64 位或 BigInt 后再取模。

替代方案与追问

可直接用比较器比较字符串 A+B 和 B+A，但总位数较大时会构造大量字符串。追问：若段内不是全 1 再全 0，是否仍可只按计数排序？不能，需要回到拼接比较器。

import java.util.*;

class Solution {
    public int maxValue(int[] nums1, int[] nums0) {
        final long MOD = 1_000_000_007L;
        int total = 0, n = nums1.length;
        int[][] seg = new int[n][2];
        for (int i = 0; i < n; i++) { seg[i] = new int[]{nums1[i], nums0[i]}; total += nums1[i] + nums0[i]; }
        long[] pow2 = new long[total + 1]; pow2[0] = 1;
        for (int i = 1; i <= total; i++) pow2[i] = pow2[i - 1] * 2 % MOD;
        Arrays.sort(seg, (x, y) -> {
            if ((x[1] == 0) != (y[1] == 0)) return x[1] == 0 ? -1 : 1;
            return x[0] != y[0] ? Integer.compare(y[0], x[0]) : Integer.compare(x[1], y[1]);
        });
        long ans = 0;
        for (int[] s : seg) {
            int ones = s[0], zeros = s[1];
            long value = ((pow2[ones] - 1 + MOD) % MOD) * pow2[zeros] % MOD;
            ans = (ans * pow2[ones + zeros] + value) % MOD;
        }
        return (int) ans;
    }
}

var maxValue = function(nums1, nums0) {
  const MOD = 1000000007n;
  const total = nums1.reduce((s, x, i) => s + x + nums0[i], 0);
  const pow2 = Array(total + 1).fill(1n);
  for (let i = 1; i <= total; i++) pow2[i] = pow2[i - 1] * 2n % MOD;
  const seg = nums1.map((ones, i) => [ones, nums0[i]]);
  seg.sort((a, b) => (a[1] === 0) !== (b[1] === 0) ? (a[1] === 0 ? -1 : 1) : b[0] - a[0] || a[1] - b[1]);
  let ans = 0n;
  for (const [ones, zeros] of seg) {
    const value = (pow2[ones] - 1n + MOD) % MOD * pow2[zeros] % MOD;
    ans = (ans * pow2[ones + zeros] + value) % MOD;
  }
  return Number(ans);
};
