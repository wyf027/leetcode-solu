2248. 多个数组求交集

Intersection of Multiple Arrays

哪些数字，能在每一个数组里都找到？先理解题意，再亲手推进一次过程。

官方题目 ↗

题目与约束

给定二维整数数组 nums。每个 nums[i] 都非空，包含互不相同的正整数。返回同时出现在所有子数组中的整数，并将结果按升序排列；没有这样的整数时返回空数组。

  • 1 <= nums.length <= 1000
  • 1 <= sum(nums[i].length) <= 1000
  • 1 <= nums[i][j] <= 1000
  • 每个 nums[i] 内的所有元素互不相同。

官方示例 1

输入：nums = [[3,1,2,4,5],[1,2,3,4],[3,4,5,6]]
输出：[3,4]

3 和 4 在三个子数组中都出现，其余数字至少缺席一个数组。

官方示例 2

输入：nums = [[1,2,3],[4,5,6]]
输出：[]

两个子数组没有共同元素。

题解 · 用出现次数代表数组覆盖数

核心洞察

一个数组内没有重复值，所以一个数字的总出现次数，恰好等于包含它的数组数量。令 m = nums.length，数字 x 属于交集，当且仅当 count[x] == m。值域只有 1～1000，直接使用计数数组，并按数值升序取出答案。

完整过程

  1. 建立长度为 1001 的全零数组 count，下标直接表示数字。
  2. 遍历每个子数组中的每个数字 x，执行 count[x]++。
  3. 从 1 扫描到 1000。遇到计数等于子数组总数的数字，追加到结果。
  4. 返回结果。扫描顺序已确保升序，不需要排序，也不修改原数组。

以示例 1 为例：处理完三个数组后，1、2、5 各出现 2 次，3、4 各出现 3 次，6 出现 1 次。要求是覆盖 3 个数组，因此答案为 [3,4]。

正确性证明

不变式：处理完前 k 个数组时，count[x] 等于这 k 个数组中含有 x 的数组数。初始 k=0 时全为 0，成立。处理下一行时，每个值至多出现一次，恰好给该行包含的值加 1，因此不变式保持。

全部处理完成后，若 count[x]=m，它出现在全部 m 个数组中，加入结果不会多选。反过来，任何公共元素一定计数为 m，都会被扫描选中，不会遗漏。升序扫描每个值一次，保证结果递增且不重复。

边界与复杂度

单个数组时返回它的排序结果；交集为空时无元素入选；值 1000 需要可访问的下标 1000。官方不包含空子数组、重复行内值或非正整数。

设 S 为所有子数组元素总数，U=1000，答案长度为 K。时间复杂度 O(S+U)；辅助空间 O(U)，返回结果另占 O(K)。在本题固定值域下，辅助空间也可记为 O(1)，但保留 U 更能说明开销来源。

替代方案

  • 哈希计数：仅记录出现过的值，筛选后排序。设不同值数量为 D，平均时间 O(S + K log K)，辅助空间 O(D)；适合稀疏的大值域。
  • 集合逐行取交集：从第一行集合出发，与后续每行集合求交，最终排序。合理实现下平均时间 O(S + K log K)，额外空间 O(L)，L 为最长子数组长度。当前交集变空即可停止。

常见错误

  • 将 count[x] > 1 当作公共元素条件：这只能说明重复出现，不能说明覆盖所有数组。
  • 按首次出现顺序返回结果：题目要求升序。
  • 创建长度 1000 的数组或只扫描到 999：会遗漏值域上界。
  • 对二维数组整体去重：同一数字在不同数组的出现必须分别计数。
  • 在允许行内重复的变体中直接累加：此时次数不再等于覆盖数，需要先对每行去重。

面试追问

  • 值域变成任意整数？改用 Map / 字典计数，对最终公共元素排序。
  • 每行允许重复？遍历每行的集合；或用“上次出现的行号”防止同一行重复计数。
  • 只要求至少出现在 t 个数组？保留行内去重前提，将条件改为 count[x] >= t。
  • 数组以流形式到达且不知道总行数？维护当前公共集合，逐行求交；结束时再输出排序结果。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> intersection(int[][] nums) {
        int[] count = new int[1001];
        for (int[] row : nums) {
            for (int x : row) {
                count[x]++;
            }
        }
        List<Integer> result = new ArrayList<>();
        for (int x = 1; x <= 1000; x++) {
            if (count[x] == nums.length) result.add(x);
        }
        return result;
    }
}

    return result;
};

Python 3

from typing import List

class Solution:
    def intersection(self, nums: List[List[int]]) -> List[int]:
        count = [0] * 1001
        for row in nums:
            for x in row:
                count[x] += 1
        return [x for x in range(1, 1001)
                if count[x] == len(nums)]

C++

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> intersection(vector<vector<int>>& nums) {
        int count[1001] = {};
        for (const auto& row : nums) {
            for (int x : row) ++count[x];
        }
        vector<int> result;
        for (int x = 1; x <= 1000; ++x) {
            if (count[x] == static_cast<int>(nums.size())) {
                result.push_back(x);
            }
        }
        return result;
    }
};
