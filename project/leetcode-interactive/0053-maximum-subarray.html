题意转述

给定整数数组 nums，选择一个至少包含一个元素的连续子数组，使其元素总和最大，返回这个最大和。 “连续”意味着选中的下标必须首尾相接，不能跳过中间元素。

1 <= nums.length <= 10^5 · -10^4 <= nums[i] <= 10^4

Official sample 01

输入
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
输出
6

连续区间 [4, -1, 2, 1] 的和为 6。

Official sample 02

输入
nums = [1]
输出
1

只有一个元素时，唯一合法子数组就是自身。

Official sample 03

输入
nums = [5, 4, -1, 7, 8]
输出
23

整个数组的总和即最大值 23。

    题解

    默认封存；点击后再查看洞察、完整过程、边界、复杂度与四语言代码。

    CORE INSIGHT

    负贡献就地丢弃

    `current` 表示“必须以 nums[i] 结尾”的最大子数组和。到达 i 时只有两个合法选择： 接在上一段后面，或从 nums[i] 单独开始。二者取大即可。 

    current = max(nums[i], current + nums[i])
best = max(best, current)

    WHY IT WORKS

    最优子结构只需一个数

    如果前一段的和为负，把它拼到当前元素只会更差；如果为非负，拼接不会降低结果。 因此无需枚举所有左端点，只保留上一位置的最优结尾状态。

    完整过程

    1. 1. 用 nums[0] 初始化 current 与 best。
    2. 2. 从下标 1 开始线性扫描。
    3. 3. 比较重启值 nums[i] 与延续值 current + nums[i]。
    4. 4. 若重启更优，当前区间左端点改为 i。
    5. 5. current 刷新 best 时，同时记录最佳区间。

    边界与复杂度

    • 单元素数组：答案就是该元素。
    • 全为负数：必须选一个元素，答案是最大负数。
    • 包含零：零可以成为合法答案或区间连接点。
    • 时间 O(n)：每个元素处理一次。
    • 额外空间 O(1)：只维护常数个变量。

    替代方案

    • DP 数组：状态定义最清楚，但额外占 O(n) 空间。
    • 前缀和减最小前缀：同为 O(n)，适合从“区间和”角度推导。
    • 分治：O(n log n)，满足题目进阶，但实现更长。

    常见错误

    • 把 best 初始化为 0，错误地允许全负数组选择空子数组。
    • 最后返回 current，而不是扫描全程的 best。
    • 把“子数组”当成“子序列”，跳过中间负数元素。
    • 更新 current 后忘记同步更新最佳区间端点。

    面试追问

    • 如何同时返回最大和与具体左右端点？
    • 为什么状态必须定义为“以 i 结尾”？
    • 如何用前缀和重新推导同一个 O(n) 解法？
    • 分治解法需要维护哪四个区间信息？

    class Solution {
    public int maxSubArray(int[] nums) {
        int current = nums[0];
        int best = nums[0];

        for (int i = 1; i < nums.length; i++) {
            current = Math.max(nums[i], current + nums[i]);
            best = Math.max(best, current);
        }
        return best;
    }
}
