01 / 题目

问题陈述

输入格式始终有效，但序列表示的树结构未必有效。

二叉树可以用前序遍历序列化：遇到非空节点时记录节点值，遇到空指针时记录哨兵 #。例如，一棵树可能被写成 9,3,4,#,#,1,#,#,2,#,6,#,#。

给定一个由逗号分隔的字符串 preorder，如果它恰好是某棵二叉树的正确前序序列化，返回 true；否则返回 false。

每段内容保证是整数或 #，也不会出现连续逗号等格式错误。你需要判断结构是否合法。

! 限制：不允许为了验证而重建整棵树。

05 / 题解

槽位计数：只保留结构欠账

不建树、不递归，只维护接下来还需要填入多少个节点位置。

核心洞察

任何一棵树在读取根节点之前，都恰好需要一个位置。每读到一个标记，它先占用一个位置；若该标记是非空节点，它又提供左右两个新位置。于是：

#：slots -= 1　｜　数字：slots += 1

读取任意标记前，slots 都必须大于零；全部读取后，slots 必须恰好等于零。

完整过程

  1. 令 slots = 1，表示根节点的位置。
  2. 按逗号拆分并从左到右扫描。
  3. 若扫描前 slots == 0，树已经闭合，当前标记多余，返回 false。
  4. 当前标记占一个位置：slots--。
  5. 若不是 #，它是非空节点，再增加两个子节点位置。
  6. 扫描结束，仅当 slots == 0 时返回 true。

正确性

不变式：扫描任意前缀后，slots 等于该前缀所描述结构中尚未被后续标记填充的位置数。

初始根位置使不变式成立。每个标记必占一个待填位置；空节点不产生新位置，非空节点产生两个子位置，因此更新后不变式继续成立。若读取前位置为零，当前标记无处安放；若结束后位置非零，结构仍不完整。反之，所有标记都可安放且最终无欠账，序列恰好描述一棵二叉树。

边界与复杂度

  • 单个 # 是空树的有效序列化。
  • 只有非空根、没有两个子标记时，最终位置数不为零。
  • 结构提前闭合后还有标记，应立即判错。
  • 时间复杂度 O(n)；除拆分结果外，额外空间 O(1)。若手动扫描字符串，可做到严格 O(1) 额外空间。

替代方案

栈归约：每当栈顶出现“非空节点、#、#”时，将三者归约成一个 #。最终只剩一个 # 即有效。该方法直观，但需要 O(n) 空间，常数也更大。

出入度思想：根节点提供一个初始入度额度；非空节点贡献两个出度，空节点贡献零。它与槽位计数本质相同。

常见错误

  • 只检查最终 slots == 0，却不检查中途是否已经归零；这会漏掉“合法树后追加标记”的情况。
  • 把数字节点的净变化写成 +2，忘记它也先占用了一个位置；净变化应为 +1。
  • 真的构造二叉树，违反题目限制并引入不必要空间。
  • 按字符扫描而不是按逗号分隔的标记扫描，导致多位数被拆开。

四语言完整实现

均使用官方提交签名；代码容器可独立横向滚动。

JavaisValidSerialization(String preorder)
class Solution {
    public boolean isValidSerialization(String preorder) {
        int slots = 1;

        for (String token : preorder.split(",")) {
            if (slots == 0) {
                return false;
            }

            slots--;
            if (!token.equals("#")) {
                slots += 2;
            }
        }

        return slots == 0;
    }
}

class Solution {
public:
    bool isValidSerialization(string preorder) {
        int slots = 1;
        string token;
        stringstream input(preorder);

        while (getline(input, token, ',')) {
            if (slots == 0) {
                return false;
            }

            --slots;
            if (token != "#") {
                slots += 2;
            }
        }

        return slots == 0;
    }
};
FOLLOW-UP

面试追问

从实现继续追到空间、泛化与证明。

如何做到严格 O(1) 额外空间？

不要调用 split 保存全部标记，直接用索引扫描原字符串。每次跳过一个完整的数字或一个 #，再处理逗号即可；槽位变量仍然只有一个。

如果是 k 叉树，规则如何变化？

每个标记仍占用一个位置；空节点不新增位置，非空节点新增 k 个位置，因此非空节点的净变化是 k - 1。

为什么不能只比较非空节点数和空节点数？

对完整序列而言，二叉树确实满足空指针数比非空节点数多一，但仅检查总数无法保证前缀合法。例如一棵树已经闭合后再追加节点，总数可能被后续标记“补平”，结构顺序依旧无效。

槽位计数与图论中的度有什么联系？

它可视为入度/出度平衡：每个节点消耗一条指向自己的边位，非空二叉节点提供两条子边位；根节点没有真实入边，所以预先补一个根槽位。
