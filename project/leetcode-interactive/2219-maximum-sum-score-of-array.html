MAXIMUM SUM SCORE OF ARRAY

数组的最大总分

选一个位置，朝数组的两端分别求和。哪一侧的分数更高？沿着数组移动，寻找所有位置中的最高分。

阅读题目 ↓先独立思考，题解在页面底部按需展开。

01 / THE PROBLEM

题目与边界

给定从下标 0 开始的整数数组 nums，长度为 n。在位置 i，分别计算区间 [0, i] 与区间 [i, n − 1] 的元素和，取两者较大值作为该位置的总分。返回全部合法位置中最高的总分。

两个区间都包含 nums[i]。区间必须连到数组的一端，且不能是空区间。

参数：nums: integer[]；函数：maximumSumScore(nums)；返回：长整数语义的最高总分。

约束

  • n == nums.length
  • 1 ≤ n ≤ 105
  • −105 ≤ nums[i] ≤ 105

负数、单元素与两端位置都属于有效输入。答案也可能是负数。

官方示例 1

输入：nums = [4,3,-2,5]
输出：10

下标 0、1、2、3 的总分依次为 10、7、5、10，因此最大值为 10。

官方示例 2

输入：nums = [-3,-5]
输出：-3

下标 0 比较 −3 与 −8，得 −3；下标 1 比较 −8 与 −5，得 −5。最高分为 −3。

04 / EDITORIAL · OPTIONAL

独立题解

准备好后，再展开推导与四语言实现。

核心洞察：让当前元素同时留在两边

相邻位置的区间高度重叠，不必每次重新求和。先求总和作为右端和 right，左端和 left 从 0 开始。访问元素 x = nums[i] 时，先将 x 加入 left，比较两侧与答案，最后从 right 中移除 x，为下一个位置做准备。

left += x
answer = max(answer, left, right)
right -= x

设总和为 T，处理 i 之前的左端和为 P，则该位置的左端和为 P + nums[i]，右端和为 T − P。若先更新左端和再用总和相减，必须写成 T − left + nums[i]，才能保留当前元素。

完整过程

  1. 遍历数组求 right = 数组总和。初始化 left = 0，answer = nums[0]，保证答案来自非空合法区间。
  2. 依次访问 i = 0 到 n − 1；left 加上 nums[i] 后对应 [0, i]。此时 right 仍对应 [i, n − 1]。
  3. 用 left、right 更新 answer，再从 right 减去 nums[i]。
  4. 遍历结束返回 answer。最后一次减法得到的空后缀 0 不参与比较。

正确性证明

循环开始时保持：left 是 [0, i−1] 的和，right 是 [i, n−1] 的和。i = 0 时，left 为 0、right 为总和，成立。先加当前元素后，left 恰是 [0, i] 的和，而 right 尚未变化，因此取较大值恰好得到位置 i 的总分。更新答案后，再从 right 移除当前元素，两变量恢复为下一轮所需区间，归纳成立。

answer 初始为 nums[0]，它是位置 0 的合法候选，不会大于全局最优。每轮纳入当前位置两侧的候选后，answer 是已访问位置的最大总分。全部 n 个位置恰被访问一次，因此最终答案正是全局最高分。

边界与数值类型

  • n = 1：两侧和相同，返回唯一元素。
  • 全负数：仍须选择非空区间，不能让初始 0 获胜。
  • 全非负数：整个数组本身就是最大候选。
  • 累加值绝对值最多 10¹⁰；Java 使用 long，C++ 使用 long long。
  • JavaScript Number 的精确整数范围足够覆盖本题；Python int 可直接累加。

复杂度与替代方案

两次线性扫描，时间 O(n)，额外空间 O(1)，不修改输入。

前缀数组方案：定义 P[0] = 0，比较 P[i+1] 与 P[n] − P[i]；时间 O(n)，空间 O(n)，适合需要保留所有前缀信息的情况。

也可分别从左到右、从右到左求最大非空前缀和，取两者最大值，空间仍为 O(1)。逐位置重算两侧和则是 O(n²)。

四语言完整实现

Java · long

class Solution {
    public long maximumSumScore(int[] nums) {
        long right = 0;
        for (int x : nums) right += x;
        long left = 0, answer = nums[0];
        for (int x : nums) {
            left += x;
            answer = Math.max(answer, Math.max(left, right));
            right -= x;
        }
        return answer;
    }
}

class Solution:

        left = 0
        answer = nums[0]

            left += x
            answer = max(answer, left, right)

        return answer

常见错误

  • 先减 right 再比较，漏掉右侧区间中的 nums[i]。
  • 把左右两侧的和相加；题目要求取较大者。
  • 初始化答案为 0，在全负数组上错误地选择了空区间。
  • 套用最大子数组算法：本题合法区间必须接触至少一端。例如 [-10,−1,−10] 的答案是 −10，而任意最大子数组和为 −1。
  • Java/C++ 使用 32 位累加器，正数较多时会溢出。

面试追问

  • 还要返回下标和方向？更新最优值时同步保存 i 与左 / 右标记；并列时按约定保留最早位置。
  • 只允许从左向右读取一次数据流？维护总和、最大非空前缀和，以及 P[0] 到 P[n−1] 的最小前缀和。最大后缀和等于最终总和减该最小前缀和；注意不能把最终 P[n] 纳入，否则会引入空后缀。
  • 存在点更新与重复查询？可用线段树维护每段的总和、最大非空前缀和与最大非空后缀和，合并后根节点给出答案；每次更新 O(log n)。
