从题意开始

覆盖、空洞、重叠——外轮廓相同，内部可能完全不同。

Problem

题意与约束

给定二维整数数组 rectangles，其中 rectangles[i] = [xᵢ, yᵢ, aᵢ, bᵢ] 表示一个边与坐标轴平行的矩形：左下角为 (xᵢ, yᵢ)，右上角为 (aᵢ, bᵢ)。

如果这些小矩形不留空隙、互不重叠，恰好覆盖某个完整矩形区域，返回 true；否则返回 false。

函数签名： isRectangleCover(rectangles) → boolean

约束

  • 1 ≤ rectangles.length ≤ 2 × 10⁴
  • rectangles[i].length == 4
  • −10⁵ ≤ xᵢ < aᵢ ≤ 10⁵
  • −10⁵ ≤ yᵢ < bᵢ ≤ 10⁵

Solution

面积守恒 + 角点奇偶性

只看总面积不能排除“某处重叠、另一处等面积空缺”；只看外轮廓也无法确认内部。因此同时维护两类全局不变量。

核心洞察

设所有小矩形的最小外接矩形为 [minX,minY,maxX,maxY]：

  1. 所有小矩形面积之和必须等于外接矩形面积。
  2. 把每个小矩形四角放入集合：出现一次就加入，再出现就删除。
  3. 最终集合必须只剩外接矩形的四个角。

为什么用“翻转”

在无缝拼接中，内部顶点会被 2 次或 4 次共享，出现次数为偶数，经过加入/删除后全部抵消；最终大矩形的四个外角各出现奇数次，恰好留下。

角点集合记录的是出现次数的奇偶性，而不是完整计数。

完整过程

  1. 初始化外接边界、面积和与空角点集合。
  2. 遍历每个 [x1,y1,x2,y2]，更新边界并累加 (x2-x1)×(y2-y1)。
  3. 依次翻转四角 (x1,y1)、(x1,y2)、(x2,y1)、(x2,y2)。
  4. 比较面积和与外框面积，并确认角点集合正好等于外框四角。

正确性证明

必要性

若小矩形精确覆盖大矩形，则它们内部不重叠且没有空隙，所以面积可加，总面积等于大矩形面积。所有内部拼接点被偶数条矩形角贡献而抵消，只有大矩形四个外角留下。

充分性

角点条件保证拼接边界不存在未被配对的内部端点，面积条件保证所有小矩形的带重数覆盖面积与外框面积相等。若存在越界、空洞或重叠，就会导致面积不等，或在其边界产生额外奇数角点；因此两条件同时成立时，覆盖必然无缝且不重叠，恰为外接矩形。

结论

算法返回 true 当且仅当输入矩形构成完美矩形。

复杂度

  • 时间：平均 O(n)，每个矩形处理四个角。
  • 空间：O(n)，哈希集合最坏保存线性数量角点。

边界情况

  • 单个矩形应返回 true。
  • 坐标可为负数，键编码不能产生歧义。
  • 面积需使用 64 位整数；JavaScript 在本题约束内仍小于安全整数上限。
  • 题目约束已保证每个小矩形宽高为正。

四语言完整代码

import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean isRectangleCover(int[][] rectangles) {
        long areaSum = 0L;
        int minX = Integer.MAX_VALUE;
        int minY = Integer.MAX_VALUE;
        int maxX = Integer.MIN_VALUE;
        int maxY = Integer.MIN_VALUE;
        Set<Long> corners = new HashSet<>();

        for (int[] rect : rectangles) {
            int x1 = rect[0], y1 = rect[1];
            int x2 = rect[2], y2 = rect[3];

            minX = Math.min(minX, x1);
            minY = Math.min(minY, y1);
            maxX = Math.max(maxX, x2);
            maxY = Math.max(maxY, y2);
            areaSum += (long) (x2 - x1) * (y2 - y1);

            toggle(corners, encode(x1, y1));
            toggle(corners, encode(x1, y2));
            toggle(corners, encode(x2, y1));
            toggle(corners, encode(x2, y2));
        }

        long boundingArea = (long) (maxX - minX) * (maxY - minY);
        if (areaSum != boundingArea || corners.size() != 4) return false;

        return corners.contains(encode(minX, minY))
            && corners.contains(encode(minX, maxY))
            && corners.contains(encode(maxX, minY))
            && corners.contains(encode(maxX, maxY));
    }

    private long encode(int x, int y) {
        return ((long) x << 32) ^ (y & 0xffffffffL);
    }

    private void toggle(Set<Long> corners, long point) {
        if (!corners.add(point)) corners.remove(point);
    }
}
/**
 * @param {number[][]} rectangles
 * @return {boolean}
 */
var isRectangleCover = function(rectangles) {
    let minX = Infinity, minY = Infinity;
    let maxX = -Infinity, maxY = -Infinity;
    let areaSum = 0;
    const corners = new Set();

    const toggle = (x, y) => {
        const key = x + "," + y;
        if (corners.has(key)) corners.delete(key);
        else corners.add(key);
    };

    for (const [x1, y1, x2, y2] of rectangles) {
        minX = Math.min(minX, x1);
        minY = Math.min(minY, y1);
        maxX = Math.max(maxX, x2);
        maxY = Math.max(maxY, y2);
        areaSum += (x2 - x1) * (y2 - y1);

        toggle(x1, y1);
        toggle(x1, y2);
        toggle(x2, y1);
        toggle(x2, y2);
    }

    const boundingArea = (maxX - minX) * (maxY - minY);
    if (areaSum !== boundingArea || corners.size !== 4) return false;

    return [
        [minX, minY], [minX, maxY],
        [maxX, minY], [maxX, maxY]
    ].every(([x, y]) => corners.has(x + "," + y));
};
from typing import List


class Solution:
    def isRectangleCover(self, rectangles: List[List[int]]) -> bool:
        min_x = min_y = float("inf")
        max_x = max_y = float("-inf")
        area_sum = 0
        corners = set()

        def toggle(point):
            if point in corners:
                corners.remove(point)
            else:
                corners.add(point)

        for x1, y1, x2, y2 in rectangles:
            min_x = min(min_x, x1)
            min_y = min(min_y, y1)
            max_x = max(max_x, x2)
            max_y = max(max_y, y2)
            area_sum += (x2 - x1) * (y2 - y1)

            toggle((x1, y1))
            toggle((x1, y2))
            toggle((x2, y1))
            toggle((x2, y2))

        bounding_area = (max_x - min_x) * (max_y - min_y)
        expected = {
            (min_x, min_y), (min_x, max_y),
            (max_x, min_y), (max_x, max_y)

        return area_sum == bounding_area and corners == expected
#include <algorithm>
#include <climits>
#include <set>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    bool isRectangleCover(vector<vector<int>>& rectangles) {
        long long areaSum = 0;
        int minX = INT_MAX, minY = INT_MAX;
        int maxX = INT_MIN, maxY = INT_MIN;
        set<pair<int, int>> corners;

        auto toggle = [&](int x, int y) {
            pair<int, int> point = {x, y};
            auto it = corners.find(point);
            if (it == corners.end()) corners.insert(point);
            else corners.erase(it);
        };

        for (const auto& rect : rectangles) {
            int x1 = rect[0], y1 = rect[1];
            int x2 = rect[2], y2 = rect[3];

            minX = min(minX, x1);
            minY = min(minY, y1);
            maxX = max(maxX, x2);
            maxY = max(maxY, y2);
            areaSum += 1LL * (x2 - x1) * (y2 - y1);

            toggle(x1, y1);
            toggle(x1, y2);
            toggle(x2, y1);
            toggle(x2, y2);
        }

        long long boundingArea = 1LL * (maxX - minX) * (maxY - minY);
        set<pair<int, int>> expected = {
            {minX, minY}, {minX, maxY},
            {maxX, minY}, {maxX, maxY}
        };
        return areaSum == boundingArea && corners == expected;
    }
};

替代方案

扫描线：按 x 坐标处理矩形左右边，维护 y 区间覆盖，能更直接定位空洞或重叠，但实现和数据结构更复杂，通常为 O(n log n)。

网格离散化：仅适合坐标范围很小的变体；本题坐标跨度可达 2×10⁵，不能逐格标记。

  • 为什么仅比较面积不够？请构造“重叠 + 等面积空洞”。
  • 为什么内部角点一定出现偶数次？
  • 若坐标改为浮点数，角点键和等值判断如何处理？
  • 如何用扫描线输出第一个冲突位置？

常见错误

  • 面积使用 32 位整数，乘法或累加发生溢出。
  • 只检查总面积，漏掉重叠与空洞互相抵消的情况。
  • 字符串坐标键没有分隔符，导致 (1,23) 与 (12,3) 冲突。
  • 只判断角点集合大小为 4，却不核对它们是否正是外接矩形四角。
  • 误把“出现过的角点”永久保留，没有按奇偶性进行翻转。
