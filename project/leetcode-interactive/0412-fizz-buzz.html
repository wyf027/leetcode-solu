Solution

题解：一次遍历，按命中顺序拼接

模拟

核心洞察

每个位置互不依赖，只需从 1 遍历到 n。对当前 i，先判断 3，再判断 5，把命中的单词依次拼接；若一个都没命中，就把 i 转成字符串。

为什么“拼接”很自然

15 同时命中两条规则：先追加 Fizz，再追加 Buzz，自然得到 FizzBuzz，无需额外把 15 放在第一条分支。

完整过程

创建空结果列表 answer，遍历 i = 1..n。
为当前 i 创建空字符串 word；若 i % 3 == 0，向它追加 Fizz。
若 i % 5 == 0，继续追加 Buzz。这一步不能写成前一步的 else，因为两者可以同时成立。
如果 word 仍为空，写入 i 的字符串；否则写入 word。遍历结束后返回 answer。

正确性证明

任取 i ∈ [1,n]。若 i 同时被 3 和 5 整除，算法依次追加 Fizz 与 Buzz，得到 FizzBuzz；若只被 3 整除，仅追加 Fizz；若只被 5 整除，仅追加 Buzz；若二者均不整除，word 为空，算法写入 i 的十进制字符串。四种情况互斥且穷尽全部整数，所以每个位置都符合题意。遍历覆盖 1 到 n，因此返回数组整体正确。

时间复杂度
O(n)

每个整数执行常数次取模与判断。若严格计入整数转字符串所需位数，可写作 O(n log n)。

额外空间
O(1)

不计必须返回的 O(n) 结果数组，循环内只使用常数级临时变量。

四种语言完整实现

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> fizzBuzz(int n) {
        List<String> answer = new ArrayList<>(n);

        for (int i = 1; i <= n; i++) {
            StringBuilder word = new StringBuilder();
            if (i % 3 == 0) word.append("Fizz");
            if (i % 5 == 0) word.append("Buzz");

            answer.add(word.length() == 0
                    ? Integer.toString(i)
                    : word.toString());
        }
        return answer;
    }
}

var fizzBuzz = function(n) {
    const answer = [];

    for (let i = 1; i <= n; i++) {
        let word = "";
        if (i % 3 === 0) word += "Fizz";
        if (i % 5 === 0) word += "Buzz";

        answer.push(word || String(i));
    }
    return answer;
};

#include <string>

class Solution {
public:
    vector<string> fizzBuzz(int n) {
        vector<string> answer;
        answer.reserve(n);

        for (int i = 1; i <= n; ++i) {
            string word;
            if (i % 3 == 0) word += "Fizz";
            if (i % 5 == 0) word += "Buzz";

            answer.push_back(word.empty() ? to_string(i) : word);
        }
        return answer;
    }
};

边界情况

  • n = 1 时只返回 ["1"]。
  • n = 3、n = 5 分别覆盖首次单规则命中。
  • n = 15 覆盖首次双规则命中。
  • n = 10⁴ 时仍只需一次线性扫描。

替代方案

也可用 if (i % 15 == 0)、else if 链显式列出四种情况，常数更小、同样是 O(n)。拼接法更容易推广到更多“因子 → 单词”规则。

面试追问

  • 若规则从 2 条增加到 k 条，如何数据驱动？
  • 如何把结果做成惰性迭代器，避免一次保存全部元素？
  • 若多线程生成分段结果，怎样保持最终顺序？
  • 时间复杂度是否应计入整数转字符串的位数？

常见错误

  • 先判断 3，导致 15 过早落入 Fizz 分支。
  • 把第二个判断写成 else if，无法同时追加两个词。
  • 循环从 0 开始或漏掉 n，造成下标偏差。
  • 普通数字没有转成字符串，返回类型不一致。
