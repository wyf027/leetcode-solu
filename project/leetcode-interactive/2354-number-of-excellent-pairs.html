优质数对的数目

Number of Excellent Pairs

从二进制里的 1 出发，数清所有满足条件的有序数对。先理解规则，再打开题解，在矩阵中追踪每一次计数。

位运算数组哈希表非付费题

01 / 题目规则

给定正整数数组 nums 和正整数 k。从数组中选取两个数值组成 有序数对 (a, b)；若 a OR b 与 a AND b 的二进制中 1 的总数至少为 k，这个数对就是优质数对。求不同优质数对的数量。

  • OR 是按位或，AND 是按位与；统计的是二进制中 1 的个数，不是结果的数值之和。
  • 按数值区分数对，重复出现的同一数值不会产生新的数对。
  • (a, b) 与 (b, a) 在 a ≠ b 时分别计数。
  • 允许 a = b，即使该数在 nums 中仅出现一次。
约束
1 ≤ nums.length ≤ 10⁵
1 ≤ nums[i] ≤ 10⁹
1 ≤ k ≤ 60

接口：countExcellentPairs(nums, k)，返回整数计数（Java / C++ 使用 64 位返回类型）。题意与示例依据随任务提供的官方元数据转述。官方题目

02 / 官方示例

示例 1

nums = [1,2,3,1], k = 3
输出：5

符合条件的数对为 (3,3)、(2,3)、(3,2)、(1,3)、(3,1)。其中 (3,3) 的 OR 与 AND 各有 2 个 1，总计 4；其余四对的 OR 有 2 个 1，AND 有 1 个 1，总计 3。重复的 1 不重复计数。

示例 2

nums = [5,1,1], k = 10
输出：0

能够选择的数值为 5 和 1。所有数对均达不到阈值 10，因此结果为 0。

04 / 独立题解

核心洞察 · 计数矩阵 · 四语言代码

核心洞察：把位运算变成加法

记 pc(x) 为 x 的二进制 1 的数量。对任意两个数：

pc(a OR b) + pc(a AND b) = pc(a) + pc(b)

在每一位上，00 对两侧贡献都是 0；01 和 10 都贡献 1；11 都贡献 2。对所有位求和，等式成立。于是只需判断 pc(a) + pc(b) ≥ k，不再关心 1 具体在哪些位。

完整过程

  1. 先对 nums 按数值去重，得到集合 U。
  2. 建立 count[0..30]：count[t] 是 U 中恰有 t 个 1 的数值个数。nums[i] < 2³⁰，因此 31 个桶足够。
  3. 枚举所有有序桶对 (i,j)。若 i+j ≥ k，则把 count[i] × count[j] 加入答案。
  4. 返回总和。同桶用平方，因为同值自配对也允许；不同桶的两个方向都会枚举。

计数桶矩阵 / 跟随一次贡献

行是第一个数的 1 的数量，列是第二个数的 1 的数量。每一步处理一个非空桶对；绿色表示计入，浅棕色表示跳过，边框标记当前步骤。为便于阅读，演示最多接收 12 个数，正式代码支持完整约束。

为什么正确
  1. 去重不改变答案：题目按数值有序对区分答案，每个允许的数值仍且仅在 U 中保留一次。
  2. 条件等价：逐位恒等式保证每个数对优质当且仅当两个 1 的数量之和不少于 k。
  3. 计数完整且互斥：每个 (a,b) 唯一属于 (pc(a),pc(b))。这个桶对的笛卡尔积大小是 count[i] × count[j]，全部满足或全部不满足条件；遍历所有有序桶对恰好覆盖所有数对一次。


边界与数值范围
  • 只有一个数时，答案取决于它与自身配对是否达到 k。
  • 重复值只保留一次，但不同数值即使 popcount 相同，也必须各占一个计数。
  • 当 k 大于两倍最大 popcount 时，答案为 0；k=1 时所有正整数数对都符合。
  • 最多有 |U|² ≤ 10¹⁰ 个有序数对。Java / C++ 用 long / long long，并保证乘法本身在 64 位类型中进行。
  • JavaScript 的位运算会转为 32 位有符号整数，本题数值小于 2³⁰，安全；答案用 Number，10¹⁰ 小于 2⁵³，整数精确。不要对答案做位运算。


复杂度
令 n 为输入长度，u 为去重后大小，B=30 为位数上界。哈希集合构造期望 O(n)，清除最低位的 popcount 计算至多 O(uB)，桶对枚举 O(B²)；合计期望 O(n + uB + B²)，额外空间 O(u+B)。固定 30 位整数时通常写为期望 O(n) 时间、O(n) 空间。


四种语言实现
均使用官方方法签名的可提交形式，无本地输入驱动。以下代码尚未执行或编译；Python 为 Python 3，C++ 使用 LeetCode 常用编译器支持的 __builtin_popcount。
Java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public long countExcellentPairs(int[] nums, int k) {
        Set<Integer> unique = new HashSet<>();
        for (int x : nums) unique.add(x);
        long[] count = new long[31];
        for (int x : unique) count[Integer.bitCount(x)]++;
        long answer = 0;
        for (int a = 0; a <= 30; a++) {
            for (int b = 0; b <= 30; b++) {
                if (a + b >= k) answer += count[a] * count[b];
            }
        }
        return answer;
    }
}
JavaScript
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var countExcellentPairs = function(nums, k) {
    const count = Array(31).fill(0);
    for (let x of new Set(nums)) {
        let bits = 0;
        while (x !== 0) {
            x &= x - 1;
            bits++;
        }
        count[bits]++;
    }
    let answer = 0;
    for (let a = 0; a <= 30; a++) {
        for (let b = 0; b <= 30; b++) {
            if (a + b >= k) answer += count[a] * count[b];
        }
    }
    return answer;
};
Python
from typing import List

class Solution:
    def countExcellentPairs(self, nums: List[int], k: int) -> int:
        count = [0] * 31
        for x in set(nums):
            count[x.bit_count()] += 1
        answer = 0
        for a in range(31):
            for b in range(31):
                if a + b >= k:
                    answer += count[a] * count[b]
        return answer
C++
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    long long countExcellentPairs(vector<int>& nums, int k) {
        unordered_set<int> unique(nums.begin(), nums.end());
        long long count[31] = {};
        for (int x : unique) count[__builtin_popcount(x)]++;
        long long answer = 0;
        for (int a = 0; a <= 30; ++a) {
            for (int b = 0; b <= 30; ++b) {
                if (a + b >= k) answer += count[a] * count[b];
            }
        }
        return answer;
    }
};


替代方案与面试追问
  • 后缀和优化：预处理 suffix[t] 为 popcount 至少为 t 的数值个数，然后对每个 i 加 count[i] × suffix[max(0,k−i)]，超过 B 的阈值贡献为 0。桶统计后的 O(B²) 降为 O(B)，但本题只有 31 个桶，双循环已足够清晰。
  • 排序 + 二分：将去重后的 popcount 排序，对每个值 c 二分寻找第一个 ≥ k−c 的位置，累加后缀长度；总时间 O(n+u log u)，额外空间 O(u)，更适合分值范围很大时。
  • 若要求无序数对？设当前有序答案为 A，符合 2pc(x) ≥ k 的数值有 D 个。允许自配对时答案为 (A+D)/2；禁止自配对时为 (A−D)/2。
  • 若按不同下标计数且不允许相同下标？不去重，按每次出现统计桶；先算有序桶乘积，再减去满足 2pc(nums[i]) ≥ k 的 n 个潜在对角项中的合格项。
  • 如果数字超过 32 位？扩展桶范围；JavaScript 改用 BigInt 做位运算，并重新评估答案是否超出安全整数范围。


常见错误
  • 直接按数组下标枚举，会重复统计相同数值。
  • 把相同 popcount 的不同数值也去重，会漏掉合法组合。
  • 无条件除以 2，丢掉方向信息；使用 c(c−1)，则漏掉允许的自配对。
  • 使用 OR 的数值与 AND 的数值相加，没有统计置位数。
  • 在 Java / C++ 中先执行 int 乘法再转 long，溢出已经发生。
