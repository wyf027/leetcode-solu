查询活跃业务

把“高于同类平均值”变成一条可解释、可复用的 SQL 分析链路。

LeetCode 1126MediumDatabasePaid onlyActive Businesses

题目速读

给定事件汇总表 Events。对于某种事件，其平均活跃度是所有拥有该事件的业务在 occurrences 上的平均值。若某业务在至少两种事件上的次数都严格大于对应事件的平均值，则它是活跃业务。

请返回所有活跃业务的 business_id，结果顺序不限。

注意两个词：“more than one” 意味着至少 2 种；“strictly greater” 意味着等于平均值不计入。

表结构与约束

business_id · INT业务编号
event_type · VARCHAR(10)事件类型
occurrences · INT该业务上该事件的发生次数

(business_id, event_type) 为联合主键，因此一个业务的一种事件至多一行。官方公开题面未给出额外数值范围；本页不臆造行数上下界。

官方示例（完整参数形式）

输入：Events(business_id, event_type, occurrences)

business_idevent_typeoccurrences
1reviews7
3reviews3
1ads11
2ads7
3ads6
1page views3
2page views12

输出： [{ "business_id": 1 }]

reviews、ads、page views 的平均值分别为 5、8、7.5。业务 1 在 reviews（7 > 5）和 ads（11 > 8）两类中都高于均值，因此入选。

    题解

    Core insight

    先建立每种事件的基准，再做两层筛选

    窗口函数让每行同时拿到所属 event_type 的平均值。行级筛掉未超均值的记录后，按业务聚合；合格记录数大于 1 即为答案。

    完整过程

    1. 按 event_type 分区，计算 AVG(occurrences)。
    2. 保留 occurrences > avg_occurrences 的行；等于平均值必须淘汰。
    3. 按 business_id 分组，统计每个业务拥有多少条合格事件。
    4. 使用 HAVING COUNT(*) > 1 保留至少两类事件都超均值的业务。

    正确性说明

    引理 1：窗口平均值为每条记录附加的，恰好是其事件类型在所有相关业务上的平均活跃度，因为分区只包含相同 event_type 的行。

    引理 2：过滤后留下的每一行，且仅有这些行，代表一个业务在一种事件上的次数严格超过该事件平均值。

    结论：联合主键保证同一业务与事件类型只有一行，因此按业务计数就是其超均值事件类型数。COUNT(*) > 1 与“超过一种事件”完全等价，查询返回且只返回活跃业务。

    边界情况

    恰好 1 类超均值不入选；等于均值不入选；仅出现于一个业务的事件无法超越自己的均值；平均值可能是小数。

    复杂度

    逻辑上扫描 n 行并分组，时间 O(n)，中间分区/聚合空间 O(n)；实际代价由数据库执行计划、排序/哈希与索引决定。

    替代方案

    先用 CTE 按事件聚合均值，再回表 JOIN。语义同样清楚，也兼容不支持窗口函数的数据库。

    常见错误

    把 > 写成 ≥；使用 HAVING COUNT(*) > 0；按业务计算平均值；在 WHERE 中直接使用窗口别名；整数除法导致小数均值丢失。

    面试追问

    • 若联合主键不存在，为什么应使用 COUNT(DISTINCT event_type)？
    • 数据库不支持窗口函数时，如何用聚合 CTE + JOIN 改写？
    • 数据量极大时，可考虑哪些索引，怎样用执行计划判断是否有效？
    • 如果活跃定义改成“超过至少 k 类”，如何参数化阈值？

    提交代码与本地语义参考

    官方可提交语言：MySQL 8.0。

    WITH event_stats AS (
    SELECT
        business_id,
        occurrences,
        AVG(occurrences) OVER (
            PARTITION BY event_type
        ) AS avg_occurrences
    FROM Events
)
SELECT business_id
FROM event_stats
WHERE occurrences > avg_occurrences
GROUP BY business_id
HAVING COUNT(*) > 1;

    本地语义参考：数据库题不能将此 Java 代码提交到 LeetCode SQL 判题器。

    import java.util.*;

class Solution {
    static class Event {
        int businessId;
        String eventType;
        int occurrences;
        Event(int businessId, String eventType, int occurrences) {
            this.businessId = businessId;
            this.eventType = eventType;
            this.occurrences = occurrences;
        }
    }

    public List<Integer> activeBusinesses(List<Event> events) {
        Map<String, long[]> stats = new HashMap<>();
        for (Event e : events) {
            long[] s = stats.computeIfAbsent(e.eventType, k -> new long[2]);
            s[0] += e.occurrences;
            s[1]++;
        }
        Map<Integer, Integer> qualified = new HashMap<>();
        for (Event e : events) {
            long[] s = stats.get(e.eventType);
            if ((long) e.occurrences * s[1] > s[0]) {
                qualified.merge(e.businessId, 1, Integer::sum);
            }
        }
        List<Integer> answer = new ArrayList<>();
        for (Map.Entry<Integer, Integer> item : qualified.entrySet()) {
            if (item.getValue() > 1) answer.add(item.getKey());
        }
        Collections.sort(answer);
        return answer;
    }
}

    本地语义参考：以对象数组模拟 Events；不可提交到 SQL 判题器。

    function activeBusinesses(events) {
  const stats = new Map();
  for (const event of events) {
    const current = stats.get(event.event_type) ?? { sum: 0, count: 0 };
    current.sum += event.occurrences;
    current.count += 1;
    stats.set(event.event_type, current);
  }

  const qualified = new Map();
  for (const event of events) {
    const { sum, count } = stats.get(event.event_type);
    if (event.occurrences * count > sum) {
      qualified.set(event.business_id, (qualified.get(event.business_id) ?? 0) + 1);
    }
  }

  return [...qualified.entries()]
    .filter(([, count]) => count > 1)
    .map(([businessId]) => businessId)
    .sort((a, b) => a - b);
}

    本地语义参考：纯 Python 列表实现；不可提交到 SQL 判题器。

    from collections import defaultdict
from typing import Dict, List, TypedDict

class Event(TypedDict):
    business_id: int
    event_type: str
    occurrences: int

def active_businesses(events: List[Event]) -> List[int]:
    sums: Dict[str, int] = defaultdict(int)
    counts: Dict[str, int] = defaultdict(int)
    for event in events:
        kind = event["event_type"]
        sums[kind] += event["occurrences"]
        counts[kind] += 1

    qualified: Dict[int, int] = defaultdict(int)
    for event in events:
        kind = event["event_type"]
        if event["occurrences"] * counts[kind] > sums[kind]:
            qualified[event["business_id"]] += 1

    return sorted(
        business_id
        for business_id, count in qualified.items()
        if count > 1
    )

    本地语义参考：以结构体数组模拟 Events；不可提交到 SQL 判题器。

    #include <algorithm>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Event {
    int businessId;
    string eventType;
    int occurrences;
};

vector<int> activeBusinesses(const vector<Event>& events) {
    unordered_map<string, pair<long long, int>> stats;
    for (const Event& event : events) {
        stats[event.eventType].first += event.occurrences;
        stats[event.eventType].second++;
    }

    unordered_map<int, int> qualified;
    for (const Event& event : events) {
        const auto& [sum, count] = stats[event.eventType];
        if (1LL * event.occurrences * count > sum) {
            qualified[event.businessId]++;
        }
    }

    vector<int> answer;
    for (const auto& [businessId, count] : qualified) {
        if (count > 1) answer.push_back(businessId);
    }
    sort(answer.begin(), answer.end());
    return answer;
}
