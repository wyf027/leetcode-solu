Shortest Word Distance
双标记最近距离

目标词只需各记住最近一次出现的位置。当另一个目标词出现时，它与刚记录位置的差就是最新候选距离；因为位置持续更新，最小值不会漏掉。

题意

给定字符串数组 wordsDict 和两个不同的词 word1、word2，返回两个词在数组中出现位置的最短距离。

官方样例
wordsDict = ["practice", "makes", "perfect", "coding", "makes"]
word1 = "coding"，word2 = "practice"
输出：3

约束：1 ≤ wordsDict.length ≤ 3 × 10⁴；word1 与 word2 不同，且均存在于数组中。

交互：扫描词数组

寻找 word1 = "coding" 与 word2 = "practice"。

尚未命中

从左到右扫描

两个最近位置初始均为 -1。

lastCoding = -1；lastPractice = -1

题解：只保留最近位置

O(n) / O(1)

核心洞察

扫描到 word1 就更新 last1；扫描到 word2 就更新 last2。两者都已出现时，abs(last1-last2) 是当前终点下的最优距离，拿它更新答案即可。

完整过程

  1. last1、last2 初始化为 -1，答案初始化为数组长度。
  2. 从 i=0 到末尾扫描。
  3. 遇到任一目标词，更新其 last。
  4. 两个 last 都有效时更新最小绝对差。

边界与复杂度

题目保证目标词不同且都出现。若只出现一次，也会在第二个目标首次出现时算出正确距离。

时间：O(n)
空间：O(1)

替代方案取舍

先记录两个词的全部索引再双指针合并也正确，但额外空间 O(n)。若同一字典要反复查询不同词对，可预处理词到索引列表；本题一次查询直接扫描最简单。

常见错误

  • 在另一目标词尚未出现时就计算距离，-1 会污染答案。
  • 遇到重复目标词却不更新最近位置。
  • 误将数组下标差当字符距离。
  • 把本题和 word1==word2 的变体混用；本题目标词不同。

面试追问

若两个词可相同？ 需要记录前一次相同词位置，再用当前和前次的距离更新。
若查询很多次？ 建立倒排索引，每次在两条有序索引列表上双指针。

class Solution {
    public int shortestDistance(String[] wordsDict, String word1, String word2) {
        int last1 = -1, last2 = -1, answer = wordsDict.length;
        for (int i = 0; i < wordsDict.length; i++) {
            if (wordsDict[i].equals(word1)) last1 = i;
            if (wordsDict[i].equals(word2)) last2 = i;
            if (last1 != -1 && last2 != -1) answer = Math.min(answer, Math.abs(last1 - last2));
        }
        return answer;
    }
}
