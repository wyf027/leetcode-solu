删除重复的电子邮箱

Delete Duplicate Emails：每个邮箱只留下 id 最小的一行。不是查找，而是原地删除重复记录。

主线：自连接 DELETE保留最小 id可视化轨道

题意

每个 email 只留最小 id

表 Person(id, email) 中，id 是主键，邮箱只含小写字母。删除重复邮箱，只保留 id 最小的一行；结果顺序不限。

输入：Person =

[(1, "john@example.com"), (2, "bob@example.com"), (3, "john@example.com")]

输出：Person =

[(1, "john@example.com"), (2, "bob@example.com")]

字符串保留成对直引号；空格将用 ␠ 标识。

关键判断

大 id 就是待删目标

同表取别名 p1 与 p2。当邮箱相同且 p1.id > p2.id，p1 不可能是该邮箱最小 id，删掉 p1。

题解：让重复行自己暴露

DELETE p1
FROM Person p1, Person p2
WHERE p1.email = p2.email
  AND p1.id > p2.id;

完整过程

  1. 每个邮箱的记录彼此比较。
  2. 大 id 总会遇到更小的同邮箱 id。
  3. 最小 id 永远不满足删除条件。

边界与复杂度

单行、全唯一、一个邮箱重复多次都适用。朴素自连接最坏 O(n²)，索引与查询计划会影响实际表现。

替代方案

可按邮箱分组取最小 id 再删除其它行；MySQL 中要注意“修改且选择同一表”的派生表限制。自连接短且直观。

面试追问与常见错误

若保留最新记录，反转比较方向。常见错误：写 SELECT、使用 >= 删除自身、忘记 email 相等条件。
