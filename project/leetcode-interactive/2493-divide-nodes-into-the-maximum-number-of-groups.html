Divide Nodes Into the Maximum Number of Groups

让每条边都只跨越相邻的组。图可能断开，组数能走到哪里？

01 / PROBLEM

题目转述

给定无向图的节点数 n，节点编号为 1…n；edges[i] = [aᵢ, bᵢ] 表示一条双向边。图不保证连通。

把所有节点划入编号为 1…m 的非空组，每个节点恰好属于一个组。对每条边，其两端的组编号必须相差恰好 1：

|group[a] − group[b]| = 1

返回能得到的最大组数 m；如果不存在合法分组，返回 -1。同组可以有多个节点，无边相连的两点并不要求组号相邻。

函数参数

magnificentSets(n: integer, edges: integer[][]) → integer

约束

  • 1 ≤ n ≤ 500
  • 1 ≤ edges.length ≤ 10⁴
  • edges[i].length == 2
  • 1 ≤ aᵢ, bᵢ ≤ n，且 aᵢ ≠ bᵢ
  • 任意两点之间至多一条边；可以存在孤立节点。
02 / EXAMPLES

官方示例

示例 1

n = 6
edges = [[1,2],[1,4],[1,5],[2,6],[2,3],[4,6]]
输出：4

一种合法分法依次是 {5}、{1}、{2,4}、{3,6}。所有边的两端恰好相邻，最多可分成 4 组。

示例 2

n = 3
edges = [[1,2],[2,3],[3,1]]
输出：-1

若把节点 1、2、3 依次放入三个组，边 [3,1] 会跨两组。换一种安排也无法同时满足三条边。

准备好推导了吗？

先尝试解释：什么图无法分组？同一张图从不同节点出发，能得到相同的层数吗？

二分图判定 + 每个起点做 BFS

核心洞察：组号的奇偶性就是二分染色。合法分量的最大组数是「直径 + 1」；各连通分量的贡献相加。这里直径指任意两点之间最短路长度的最大值。

交互实验：看每个根节点能铺出多少层

先逐边染色，再枚举根节点逐层 BFS。圆点上方标记距离；浅红边表示同色冲突。层架只显示当前根的分层，汇总值只在分量完成时累加。

完整过程

  1. 建立无向邻接表，用 color = -1 表示未访问。
  2. 从未染色节点 BFS，收集连通分量并给邻点染相反颜色。遇到同色边立即返回 -1。
  3. 对分量内每个节点 s，重新初始化距离，从它做 BFS；本次层数是 max(dist) + 1。
  4. 取所有根的最大层数作为该分量贡献，累加到答案。
  5. 继续处理下一个分量，包含孤立点。

示例 1 从节点 1 出发有 3 层；从节点 5 出发得到 {5} → {1} → {2,4} → {3,6}，共 4 层。只有遍历所有根，才能保证找到最大值。

正确性证明

① 可行性等价于二分图。合法边的组号相差 1，所以两端组号奇偶性相反，形成二分染色；奇环无法满足这种交替。反过来，二分图一定可按下面的 BFS 距离分组。

② BFS 分层合法。固定根 s，任意边 (u,v) 满足 |dist(s,u) − dist(s,v)| ≤ 1。二分图中边的两端距离奇偶性不同，不能相等，因此差值恰好是 1。把距离 d 的节点放入第 d+1 组即可。

③ 一个分量至多 D+1 组。其中 D 是直径。设任意合法分法中最小、最大组号节点为 a、b。沿它们的最短路，每走一条边组号最多变化 1，所以最大组号减最小组号 ≤ dist(a,b) ≤ D。分量占据的不同组数因此至多 D+1。

④ 这个上界能达到。取直径端点作为 BFS 根，最大距离恰好为 D，得到 D+1 个非空层。枚举所有根必然包含这个根。

⑤ 分量可以相加。不同分量之间没有边，把它们各自的组号整体平移后首尾拼接，不影响任何约束。全图组数最多是各分量可用组数之和，这种拼接达到上界。任一分量不可行则整个图不可行。

复杂度

令 E 为边数。染色耗时 O(n+E)，最多 n 次 BFS，每次含距离数组初始化，时间 O(n(n+E))；邻接表、队列、颜色和距离数组占 O(n+E) 额外空间。

代码使用全长距离数组。交互为支持上一步保存了小型预设图的快照；上述空间复杂度指提交代码。

边界与常见错误

  • 孤立点贡献 1；不能只遍历 edges 里的节点。
  • 偶环合法，不要把所有环都拒绝。
  • 二分图可以分很多组，不是只能分 2 组。
  • 不同分量取总和，不是最大值。
  • 最大距离是边数，组数还要加 1。
  • 每次 BFS 都要清空距离，入队时标记访问。
  • 一般二分图不是树，两次 BFS 求直径没有通用保证。

替代方案

Floyd–Warshall：先染色判定，再计算所有点对最短路；每个分量取最大有限距离加 1。时间 O(n³)、空间 O(n²)，本题稀疏图通常更适合逐起点 BFS。

并查集：可用于划分连通分量，但仍需二分图判定与距离搜索；本解的染色 BFS 已同时完成分量收集，无须额外结构。

树的特例：如果题目保证每个分量都是树，才可以用两次 BFS 求直径，将总体时间降到 O(n+E)。

面试追问

  • 如何输出具体分组？保存每个分量的最佳根，再 BFS 一次，组号设为「已用组数 + 距离 + 1」。
  • 为什么不是最长简单路径？合法组号差受任何路径限制，尤其受最短路限制；偶环可能有很长的简单路径，但组数仍由直径约束。
  • 如何早停？染色一旦发现同色边立即返回；若某分量已取得与节点数相等的层数，也已达理论上限。

Java

import java.util.*;

class Solution {
    public int magnificentSets(int n, int[][] edges) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0] - 1).add(e[1] - 1);
            g.get(e[1] - 1).add(e[0] - 1);
        }
        int[] color = new int[n];
        Arrays.fill(color, -1);
        int answer = 0;
        for (int start = 0; start < n; start++) {
            if (color[start] != -1) continue;
            List<Integer> component = new ArrayList<>();
            ArrayDeque<Integer> q = new ArrayDeque<>();
            color[start] = 0;
            q.add(start);
            while (!q.isEmpty()) {
                int u = q.remove();
                component.add(u);
                for (int v : g.get(u)) {
                    if (color[v] == -1) {
                        color[v] = color[u] ^ 1;
                        q.add(v);
                    } else if (color[v] == color[u]) {
                        return -1;
                    }
                }
            }
            int best = 0;
            for (int root : component) {
                int[] dist = new int[n];
                Arrays.fill(dist, -1);
                dist[root] = 0;
                q.add(root);
                int farthest = 0;
                while (!q.isEmpty()) {
                    int u = q.remove();
                    for (int v : g.get(u)) {
                        if (dist[v] != -1) continue;
                        dist[v] = dist[u] + 1;
                        farthest = Math.max(farthest, dist[v]);
                        q.add(v);
                    }
                }
                best = Math.max(best, farthest + 1);
            }
            answer += best;
        }
        return answer;
    }
}

/**
 * @param {number} n
 * @param {number[][]} edges
 * @return {number}

var magnificentSets = function(n, edges) {
    const g = Array.from({ length: n }, () => []);
    for (const [a, b] of edges) {
        g[a - 1].push(b - 1);
        g[b - 1].push(a - 1);
    }
    const color = Array(n).fill(-1);
    let answer = 0;
    for (let start = 0; start < n; start++) {
        if (color[start] !== -1) continue;
        const component = [start];
        color[start] = 0;
        for (let head = 0; head < component.length; head++) {
            const u = component[head];
            for (const v of g[u]) {
                if (color[v] === -1) {
                    color[v] = color[u] ^ 1;
                    component.push(v);
                } else if (color[v] === color[u]) {
                    return -1;
                }
            }
        }
        let best = 0;
        for (const root of component) {
            const dist = Array(n).fill(-1), q = [root];
            dist[root] = 0;
            let farthest = 0;
            for (let head = 0; head < q.length; head++) {
                const u = q[head];
                for (const v of g[u]) {
                    if (dist[v] !== -1) continue;
                    dist[v] = dist[u] + 1;
                    farthest = Math.max(farthest, dist[v]);
                    q.push(v);
                }
            }
            best = Math.max(best, farthest + 1);
        }
        answer += best;
    }
    return answer;
};

from collections import deque
from typing import List

class Solution:
    def magnificentSets(self, n: int, edges: List[List[int]]) -> int:
        g = [[] for _ in range(n)]
        for a, b in edges:
            g[a - 1].append(b - 1)
            g[b - 1].append(a - 1)
        color = [-1] * n
        answer = 0
        for start in range(n):
            if color[start] != -1:
                continue
            component = []
            q = deque([start])
            color[start] = 0
            while q:
                u = q.popleft()
                component.append(u)
                for v in g[u]:
                    if color[v] == -1:
                        color[v] = color[u] ^ 1
                        q.append(v)
                    elif color[v] == color[u]:
                        return -1
            best = 0
            for root in component:
                dist = [-1] * n
                dist[root] = 0
                q = deque([root])
                farthest = 0
                while q:
                    u = q.popleft()
                    for v in g[u]:
                        if dist[v] != -1:
                            continue
                        dist[v] = dist[u] + 1
                        farthest = max(farthest, dist[v])
                        q.append(v)
                best = max(best, farthest + 1)
            answer += best
        return answer

class Solution {

    int magnificentSets(int n, vector<vector<int>>& edges) {
        vector<vector<int>> g(n);
        for (const auto& e : edges) {
            g[e[0] - 1].push_back(e[1] - 1);
            g[e[1] - 1].push_back(e[0] - 1);

        vector<int> color(n, -1);

            vector<int> component;
            queue<int> q;
            q.push(start);
            color[start] = 0;
            while (!q.empty()) {
                int u = q.front(); q.pop();
                component.push_back(u);
                for (int v : g[u]) {
                    if (color[v] == -1) {
                        color[v] = color[u] ^ 1;
                        q.push(v);
                    } else if (color[v] == color[u]) {
                        return -1;
                    }
                }
            }
            int best = 0;
            for (int root : component) {
                vector<int> dist(n, -1);
                dist[root] = 0;
                q.push(root);
                int farthest = 0;
                while (!q.empty()) {

                        if (dist[v] != -1) continue;

                        farthest = max(farthest, dist[v]);
