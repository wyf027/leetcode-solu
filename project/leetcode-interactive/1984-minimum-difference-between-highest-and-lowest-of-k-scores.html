学生分数的最小差值

Minimum Difference Between Highest and Lowest of K Scores

选出恰好 k 名学生，让他们的最高分与最低分尽可能接近。

打开 LeetCode 原题 ↗

题目与约束

给定下标从 0 开始的整数数组 nums，其中 nums[i] 是第 i 名学生的分数；另给一个整数 k。你可以从所有学生中任意选择恰好 k 名，返回这组分数的最大值与最小值之差所能达到的最小值。

选择的是学生，不要求他们在原数组中相邻；不同学生可以有相同分数。返回差值，无需返回选中的学生。

minimumDifference(nums, k) → 整数
1 ≤ k ≤ nums.length ≤ 1000
0 ≤ nums[i] ≤ 100000

官方示例

01 / 一名学生

输入：nums = [90], k = 1
输出：0

只能选择分数 90；最大值和最小值都是 90，差为 0。

02 / 任意选两名

输入：nums = [9,4,1,7], k = 2
输出：2

六种分数组合 [9,4]、[9,1]、[9,7]、[4,1]、[4,7]、[1,7] 的差分别为 5、8、2、3、3、6。选择 9 与 7 得到最小值 2。

独立题解

准备好后，展开思路与分数窗口实验。

核心洞察：排序后，只考察连续 k 个分数

按分数升序排列成 a。固定长度为 k 的窗口，其差值就是 a[l + k - 1] - a[l]。让左端点从 0 走到 n - k，记录最小差值。这里的连续是排序后的连续，不是原数组中的连续。

完整过程

  1. 复制并升序排序数组，保留输入不变。
  2. 将答案初始化为一个足够大的值。
  3. 枚举左端点 l = 0…n − k，令右端点 r = l + k − 1。
  4. 用 a[r] − a[l] 更新答案，扫描完 n − k + 1 个窗口后返回。

示例二排序为 [1,4,7,9]。三个长度为 2 的窗口差分别是 3、3、2，运行最小值依次为 3、3、2，最终返回 2。

为什么正确

任取排序后的一组 k 个位置 i₁ < i₂ < … < iₖ。因为它们是 k 个不同位置，所以 iₖ ≥ i₁ + k − 1。改选连续位置 i₁…i₁ + k − 1 后，最小值仍是 a[i₁]，最大值不超过 a[iₖ]，差值不会增大。该窗口合法，因为 i₁ + k − 1 ≤ iₖ < n。

因此，任意选择都能被一个差值不更大的连续窗口替代，最优解必可在这些窗口中找到。循环枚举所有合法窗口，并保持“答案等于已扫描窗口的最小差值”这一不变式，结束时就是全局最优值。

边界与复杂度

  • k = 1：每个窗口仅有一个值，差为 0；可直接提前返回。
  • k = n：只有一个窗口，答案是全局最大值减最小值。
  • 重复分数：学生仍不同，不可去重；有 k 个相同分数时答案为 0。
  • 差值范围为 0…100000，四种代码使用的数字类型均足够。

通常排序耗时 O(n log n)，扫描耗时 O(n)，总时间 O(n log n)。以下代码都复制数组，额外空间为 O(n)，其中也可容纳常见排序实现的辅助开销。JavaScript 的具体排序时间与空间实现依赖引擎。若允许修改原数组可省去副本，但不能一概把排序辅助空间声称为 O(1)。

四语言完整提交代码

均使用官方函数名及参数形式；代码尚未执行验证。

Java

import java.util.Arrays;

class Solution {
    public int minimumDifference(int[] nums, int k) {
        if (k == 1) return 0;
        int[] a = nums.clone();
        Arrays.sort(a);
        int ans = Integer.MAX_VALUE;
        for (int l = 0; l <= a.length - k; l++) {
            ans = Math.min(ans, a[l + k - 1] - a[l]);
        }
        return ans;
    }
}

    const a = [...nums].sort((x, y) => x - y);

    for (let l = 0; l <= a.length - k; l++) {
        ans = Math.min(ans, a[l + k - 1] - a[l]);
    }
    return ans;

Python

from typing import List

class Solution:
    def minimumDifference(self, nums: List[int], k: int) -> int:
        if k == 1:
            return 0
        a = sorted(nums)
        ans = a[-1] - a[0]
        for l in range(len(a) - k + 1):
            ans = min(ans, a[l + k - 1] - a[l])
        return ans

C++

#include <algorithm>
#include <climits>
#include <vector>
using namespace std;

class Solution {
public:
    int minimumDifference(vector<int>& nums, int k) {
        if (k == 1) return 0;
        vector<int> a = nums;
        sort(a.begin(), a.end());
        int ans = INT_MAX;
        for (int l = 0; l <= static_cast<int>(a.size()) - k; ++l) {
            ans = min(ans, a[l + k - 1] - a[l]);
        }
        return ans;
    }
};

替代方案

枚举所有 k 人组合，逐个计算极差：时间约 O(C(n,k) · k)，只适合很小的输入。若利用分数上限 U = 100000，可建立频次表，再用分数区间双指针寻找包含至少 k 人的最窄区间；时间 O(n + U)、空间 O(U)。本题 n ≤ 1000，直接排序通常更简洁。

常见错误

  • 在原数组上直接滑动窗口：会漏掉原位置不相邻的最优组合。
  • JavaScript 使用无比较器的 sort()：会按字符串顺序排序。
  • 右端点写成 l + k：窗口会多一人，且可能越界。
  • 循环使用 l < n − k：会漏掉最后一个窗口，k = n 时甚至完全不扫描。
  • 求相邻间隔的最小值：只适合 k = 2，不能代替一般 k 的窗口极差。
  • 用 Set 去重或求窗口总分：分别改变学生数量和优化目标。

面试追问

如何返回被选中的学生？ 排序 (分数, 原下标)，记录最优窗口左端点，再返回窗口内的原下标；有并列最优时任选一个，或按新增规则比较。

为什么不需要单调队列？ 升序排列后，每个窗口的最小值和最大值直接位于两端，O(1) 就可读取。

若必须选原数组中连续的 k 人？ 那是另一道题，排序会破坏约束；可用最大值、最小值两个单调队列维护原数组窗口。
