两个行程编码数组的积

Product of Two Run-Length Encoded Arrays

用少量的“值 × 次数”描述长数组。现在，把两个等长数组逐位相乘，再返回最精简的行程编码。

先读题并尝试自己的方案。交互推演、思路与四语言代码位于底部，默认收起。

01 / 题目

输入很短，展开后可能很长

行程编码中的一项 [value, frequency] 表示连续出现 frequency 次的 value。例如 [[4,2],[7,3]] 表示 [4,4,7,7,7]。

给定整数二维数组 encoded1 和 encoded2，它们展开后的数组长度相同。将两个展开数组在每个相同下标处的数字相乘，返回乘积数组的行程编码。返回编码的段数必须最少，即相邻同值段必须合并。

findRLEArray(encoded1: integer[][], encoded2: integer[][])
→ list<list<integer>>

约束

  • 1 ≤ encoded1.length, encoded2.length ≤ 10⁵。
  • encoded1[i].length == 2，encoded2[j].length == 2。
  • 两份编码每段的值与频次都满足 1 ≤ value, frequency ≤ 10⁴。
  • 两份编码所代表的完整数组长度相同。

题意为自行转述。官方元数据提供题名、参数签名与示例输入；付费题面字段为空，约束及示例输出参照公开题面镜像补齐。来源：LeetCode 原题 · 公开题面参考。

输入：
encoded1 = [[1,3],[2,3]]

输出：[[6,6]]

展开后分别是 [1,1,1,2,2,2] 与 [6,6,6,3,3,3]。六个位置的乘积均为 6，因此结果只有一段。

输入：

输出：[[2,3],[6,1],[9,2]]

展开后分别是 [1,1,1,2,3,3] 与 [2,2,2,3,3,3]。乘积为 [2,2,2,6,9,9]，编码成三段。

03 / 题解

双指针：只走到下一个段边界

两条编码流在当前重叠区间内的值都不变，因此乘积也不变。用两个段指针 i、j 与两个剩余频次 r1、r2，一次处理 min(r1,r2) 个位置，直接生成一段乘积。

核心洞察：相乘的是“同位置的值”，消耗的是“两段共同覆盖的长度”。段值相乘，段长取剩余频次的较小值。

完整过程
  1. 指针都从第 0 段开始；r1、r2 保存当前段还没处理的频次。
  2. 计算 take = min(r1, r2) 与 product = encoded1[i][0] × encoded2[j][0]。
  3. 若结果末段值等于 product，把 take 加到末段频次；否则追加 [product, take]。
  4. 两边剩余频次都减去 take。哪边减至 0，就推进哪边的段指针并装入新段频次；同时耗尽时两边都推进。
  5. 处理到末尾，返回结果。只修改局部剩余频次，不修改输入数组。


例：交错边界
A = [[2,2],[3,3]], B = [[4,3],[2,2]]
[0,2)：2 × 4 = 8，消费 2；A 换段，B 剩余 1
[2,3)：3 × 4 = 12，消费 1；A 剩余 2，B 换段
[3,5)：3 × 2 = 6，消费 2；两边同时结束
结果：[[8,2],[12,1],[6,2]]


正确性：保持已处理前缀不变式
每轮开始时，两条流已消费相同数量的位置；结果准确且最短地编码了该前缀，指针和剩余频次指向第一个未处理的位置。初始前缀为空，这些条件成立。
当前两段接下来的 take 个位置均未跨越任一段边界，故其乘积全部相同。追加这一段恰好覆盖下一个前缀，既不遗漏也不重复。若与末段同值就合并，否则形成必要的新边界，因此结果仍是该前缀的最短编码。更新剩余频次与指针后，不变式保持。
take 为正且每轮至少耗尽一段，所以过程必然结束。由于输入展开长度相同，结束时完整数组都已覆盖；结果编码准确，并且相邻段值不同，因此段数最少。


复杂度与数值边界
令 m、n 为两份输入的段数，k 为结果段数。每轮至少推进一个指针，时间 O(m+n)；排除返回结果的辅助空间 O(1)，输出空间 O(k)，最坏 O(m+n)。由于最后一次至少耗尽两边的末段，处理区间数最多 m+n−1。
最大展开长度为 10⁹，最大乘积为 10⁸；结果合并后的频次可超过 10⁴，但不会超过 10⁹。Java / C++ 的 32 位有符号整数足够，JavaScript Number 也可精确表示。不要将输入单段频次上限误用于输出频次。


边界与常见错误
  • 两段同时耗尽：必须用两个独立判断推进指针，不能用 if / else if。
  • 一段只消费部分：保留剩余频次，不能下一轮又加载原始完整频次。
  • 不同段组合也可能产生同一乘积：每轮必须检查结果末段是否可合并。
  • 频次取剩余值的最小值；不能把频次相乘，也不能只处理输入第 i 段和第 i 段。
  • 只合并相邻同值乘积。跨过不同乘积强行合并会改变原数组顺序。
  • 空输入不在官方约束内；不要在循环结束后读取越界的新段。


替代方案
直接展开、逐位相乘、再压缩最容易理解，时间 O(L)、存储展开数组需 O(L)，L 最多 10⁹，无法应对大输入。用生成器逐个吐出值可降低额外内存，但时间仍为 O(L)。也可对所有段的前缀边界做区间扫描，复杂度同为 O(m+n)，但无需额外边界数组，剩余频次写法更直接。


面试追问
  • 换成相加或任意逐点函数呢？ 相同的分段对齐成立；区间内输入不变，确定性逐点函数的输出也不变。
  • 两条输入作为流到来呢？ 只保留当前输入段与一个未定稿的输出末段；输出值变化后才能发出旧末段，避免无法合并。
  • 加入零或负数呢？ 对齐与合并逻辑不变；频次仍须为正，并重新审视溢出范围。
  • 长度可能不相等呢？ 应由接口契约指定拒绝输入或截断规则；本题保证等长。


四语言完整实现
统一使用局部剩余频次，不更改输入。以下为 LeetCode 提交形式，均待补验证。


Java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> findRLEArray(int[][] encoded1,
                                                 int[][] encoded2) {
        List<List<Integer>> ans = new ArrayList<>();
        int i = 0, j = 0, r1 = 0, r2 = 0;
        while (i < encoded1.length && j < encoded2.length) {
            if (r1 == 0) r1 = encoded1[i][1];
            if (r2 == 0) r2 = encoded2[j][1];
            int take = Math.min(r1, r2);
            int product = encoded1[i][0] * encoded2[j][0];
            if (!ans.isEmpty()
                    && ans.get(ans.size() - 1).get(0) == product) {
                List<Integer> last = ans.get(ans.size() - 1);
                last.set(1, last.get(1) + take);
            } else {
                ans.add(Arrays.asList(product, take));
            }
            r1 -= take;
            r2 -= take;
            if (r1 == 0) i++;
            if (r2 == 0) j++;
        }
        return ans;
    }
}

var findRLEArray = function(encoded1, encoded2) {
    const ans = [];
    let i = 0, j = 0, r1 = 0, r2 = 0;
    while (i < encoded1.length && j < encoded2.length) {
        if (r1 === 0) r1 = encoded1[i][1];
        if (r2 === 0) r2 = encoded2[j][1];
        const take = Math.min(r1, r2);
        const product = encoded1[i][0] * encoded2[j][0];
        const last = ans[ans.length - 1];
        if (last && last[0] === product) last[1] += take;
        else ans.push([product, take]);
        r1 -= take;
        r2 -= take;
        if (r1 === 0) i++;
        if (r2 === 0) j++;
    }
    return ans;
};

from typing import List

class Solution:
    def findRLEArray(self, encoded1: List[List[int]],
                     encoded2: List[List[int]]) -> List[List[int]]:
        ans = []
        i = j = r1 = r2 = 0
        while i < len(encoded1) and j < len(encoded2):
            if r1 == 0:
                r1 = encoded1[i][1]
            if r2 == 0:
                r2 = encoded2[j][1]
            take = min(r1, r2)
            product = encoded1[i][0] * encoded2[j][0]
            if ans and ans[-1][0] == product:
                ans[-1][1] += take
            else:
                ans.append([product, take])
            r1 -= take
            r2 -= take
            if r1 == 0:
                i += 1
            if r2 == 0:
                j += 1
        return ans
