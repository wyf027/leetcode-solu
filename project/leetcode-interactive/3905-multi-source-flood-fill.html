多源图像渲染

让多个颜色同时向四邻域扩散；同一时刻撞到同一格时，留下数值更大的颜色。

题意

给定 n 行、m 列网格，以及 sources = [r, c, color]。源格已着色，其他格为 0。每一单位时间，所有已着色格同时向上下左右的未着色邻格传播；同一层的竞争取最大颜色。返回最终网格。

示例输入
n = 3, m = 3
sources = [[0,0,1],[2,2,2]]
示例输出
[[1,1,2],[1,2,2],[2,2,2]]
数字 2 在同层碰撞中获胜。
约束摘要：1 ≤ n × m ≤ 10^5，源坐标互不相同，颜色范围为 1…10^6。逐层处理，不能把本层刚染色的格马上继续扩散。

推荐策略

多源 BFS：队列保存当前波前；本层的候选邻居暂存到映射中，对同一坐标取 max；整层结束后再写入网格与下一层队列。

时间：O(n × m)

空间：O(n × m)

题解：把“同时”锁在层边界

核心洞察

当前队列只代表同一个时间层。遍历它的四邻居时，不能直接入下一轮队列；应先在 next 中按坐标合并竞争颜色。这样同一时刻抵达才有机会比较最大值。

过程

  1. 初始化答案网格并加入所有源。
  2. 取当前整层队列，扫描四方向的未着色邻格。
  3. next[key] = max(next[key], color)。
  4. 层扫描结束，统一落盘 next，成为新波前。

边界与常见错误

  • 单个源时每格都继承该颜色。
  • 源点已经着色，不能被后续波覆盖。
  • 逐个直接写邻居会破坏“同时扩散”。
  • 不能把跨层竞争也拿来比较：只有同一层才竞争。

替代方案与追问

可用优先队列按距离和颜色排序，但本题规则是严格的层同步，普通分层 BFS 更直接。追问：若障碍格为 -1，只需在扩散时跳过即可。
