统计有效前缀数目

给定二进制字符串 s。一个前缀若能重排为相邻字符都不同的交替字符串，就称为有效。返回有效前缀的数量。

约束

1 ≤ s.length ≤ 100；只包含 0 与 1。

关键区别

不要求原前缀交替；允许把其中的 0 与 1 任意重排。

交互实验台

准备就绪

仅允许 0、1；实时枚举每个前缀并说明判断。

为什么只看数量？

  1. 长度为 L 的交替二进制串，0 和 1 的数量差至多为 1。
  2. 反过来，只要数量差至多为 1，按多的字符开头交替排列即可构造。
  3. 因此扫描每个前缀时维护 balance = #0 - #1，判断 |balance| ≤ 1。
复杂度：一次扫描，时间 O(n)，额外空间 O(1)。

题解与实现

默认收起，先自行观察实验台再展开验证思路。

核心洞察

  • 能重排成交替串，等价于 0 与 1 的数量差绝对值不超过 1。
  • 原始顺序无关：001 虽不是交替串，仍可重排为 010。
  • 扫描时只维护 balance = #0 − #1，不必枚举重排。

完整过程

  • 从左到右读入一个字符；读到 0 则 balance 加 1，读到 1 则减 1。
  • 若 |balance| ≤ 1，当前前缀可排成交替串，答案加 1。
  • 继续直到字符串末尾；每个字符只处理一次。

边界与复杂度

  • 长度为 1 的前缀总有效；偶数长度只能在数量相等时有效。
  • 全是同一字符时，只有第一个前缀有效。
  • 时间 O(n)，额外空间 O(1)。

替代方案与面试追问

  • 可为每个前缀重新统计再判断，但会退化为 O(n²)。
  • 若字符集扩大到 k 种，交替条件不再只由一个差值决定，需要维护频次。
  • 若要求输出一种重排结果，在差值合法后从数量较多的字符开始交替放置即可。

常见错误

  • 把“可重排”误解为原前缀本身必须交替。
  • 只在差为 0 时计数，漏掉奇数长度、差为 1 的合法前缀。
  • 对每个前缀排序或重新计数，制造不必要的二次复杂度。
function countValidPrefixes(s) {
  let balance = 0, answer = 0;
  for (const ch of s) {
    balance += ch === '0' ? 1 : -1;
    if (Math.abs(balance) <= 1) answer++;
  }
  return answer;
}
class Solution:
    def countValidPrefixes(self, s: str) -> int:
        balance = answer = 0
        for ch in s:
            balance += 1 if ch == '0' else -1
            if abs(balance) <= 1:
                answer += 1
        return answer
