Group Employees of the Same Salary

相同的工资，能组成怎样的团队？从一张员工表出发，为满足条件的每位员工补上组号，并保持输出有序。

数据库离线交互笔记仅生成 · 待补验证

01 / 题意与数据契约

输入为 Employees(employee_id INT, name VARCHAR(30), salary INT)。每行表示一名雇员，employee_id 唯一。输出能够组队的雇员，保留原三列并追加 team_id。

01

同薪成组

工资相同的所有人必须在同组，每组至少两人。工资只出现一次的雇员不分组，也不输出。

02

编号连续

有效团队按工资从低到高编号，从 1 开始；被排除的工资不参与编号。

03

有序返回

结果先按 team_id 升序，同一组再按 employee_id 升序。

约束：公开题意未另列行数、工资或 ID 的数值上下界，也未明确 NULL 规则，本页不虚构这些条件。表结构和示例输入来自官方元数据；缺失题意据公开题目资料简要转述。官方题目入口。

05 / 独立题解
准备好后再展开：核心思路、正确性、SQL 与四语言参考都在这里。
先决定谁入围，再给团队编号
核心洞察
编号对象是有效工资值，不是每一名员工。先统计同薪人数，去掉单人团队，再在剩余行上连续排名。
完整过程
  1. CTE 中使用 COUNT(*) OVER (PARTITION BY salary)，给每一行附上同薪人数。窗口统计保留所有员工明细。
  2. 外层 WHERE members >= 2 过滤掉不能组队的人。该 WHERE 在外层窗口排名之前生效。
  3. DENSE_RANK() OVER (ORDER BY salary) 给有效工资连续编号。同薪行同号，下个不同工资只加一。
  4. 选取原三列和 team_id；显式按 team_id、employee_id 排序。
正确性
保留集合：计数等于输入表中该工资的总人数，过滤恰好留下所有能组队的雇员，单人团队被完整排除。
组号：设剩余不同工资升序为 s₁…sₖ，DENSE_RANK 将工资 sᵢ 的全部行赋值 i，满足同薪同组、连续编号和工资顺序。
结果：窗口函数不合并或复制明细行，每位入围雇员只输出一次；最后的双字段排序保证组间、组内顺序。
边界与常见错误
  • 空表、仅一人、工资全唯一：输出空表；所有人同薪：组号全部为 1。
  • 先对所有工资排名再过滤，会让中间的唯一工资占号，产生空档。
  • RANK 在员工明细的并列排名后跳号；ROW_NUMBER 给每位员工不同号；此处应使用 DENSE_RANK。
  • 直接 GROUP BY salary 会丢失员工明细；找同薪伙伴的自连接若不去重，会在三人同薪时复制输出。
  • 名字可以相同；employee_id 才是唯一标识。不能把输入顺序当成结果顺序。
  • NULL 工资语义未明确；实际业务须另行约定。四语言参考仅接收非 NULL 整数工资。
复杂度
设 n 为输入人数、m 为入围人数、k 为工资种类数。SQL 实际成本取决于数据库执行计划和索引；常见排序方案为 O(n log n) 时间、O(n) 中间存储，这不是数据库保证。四语言参考使用哈希计数和排序，平均时间 O(n + m log m)，额外空间 O(n)，其中计数表 O(k)，入围列表与输出 O(m)。
替代方案
先 GROUP BY salary HAVING COUNT(*) >= 2 得到有效工资，再对该集合用 ROW_NUMBER 编号，最后 JOIN 回 Employees。这时 ROW_NUMBER 正确，因为每个工资只有一行。也可用 EXISTS 寻找另一位同薪员工后连续排名；大表需要结合索引与执行计划比较成本。
面试追问
  • 每组至少 q 人？调整计数门槛即可。
  • 按部门与工资共同分组？计数键改成 (department_id, salary)，并先明确组号是部门内编号还是全局编号。
  • 没有窗口函数？对每个有效工资统计比它小的有效工资数量，加一得到组号；朴素相关计数可能达到 O(k²)。
  • 数据更新后组号能固定吗？不能，这是结果排名，不是持久身份；新增低工资团队会移动后续组号。

MySQL 8+ · 官方可提交 SQL
WITH counted AS (
    SELECT employee_id, name, salary,
           COUNT(*) OVER (PARTITION BY salary) AS members
    FROM Employees
)
SELECT employee_id, name, salary,
       DENSE_RANK() OVER (ORDER BY salary) AS team_id
FROM counted
WHERE members >= 2
ORDER BY team_id, employee_id;

import java.util.*;

public class Main {
    record Employee(int employee_id, String name, int salary) {}
    record Result(int employee_id, String name, int salary, int team_id) {}

    static List<Result> groupEmployees(List<Employee> employees) {
        Map<Integer, Integer> counts = new HashMap<>();
        for (Employee e : employees) counts.merge(e.salary(), 1, Integer::sum);
        List<Employee> kept = new ArrayList<>();
        for (Employee e : employees)
            if (counts.get(e.salary()) >= 2) kept.add(e);
        kept.sort(Comparator.comparingInt(Employee::salary)
                            .thenComparingInt(Employee::employee_id));
        List<Result> result = new ArrayList<>();
        Integer previous = null;
        int team = 0;
        for (Employee e : kept) {
            if (previous == null || e.salary() != previous.intValue()) {
                ++team;
                previous = e.salary();
            }
            result.add(new Result(e.employee_id(), e.name(), e.salary(), team));
        }
        return result;
    }

    public static void main(String[] args) {
        var employees = List.of(new Employee(2, "Meir", 3000),
            new Employee(3, "Michael", 3000), new Employee(7, "Addilyn", 7400),
            new Employee(8, "Juan", 6100), new Employee(9, "Kannon", 7400));
        groupEmployees(employees).forEach(System.out::println);
    }
}

function groupEmployees(employees) {
    const counts = new Map();
    for (const e of employees)
        counts.set(e.salary, (counts.get(e.salary) ?? 0) + 1);
    const kept = employees.filter(e => counts.get(e.salary) >= 2)
        .sort((a, b) => a.salary - b.salary || a.employee_id - b.employee_id);
    let previous;
    let team = 0;
    return kept.map(e => {
        if (team === 0 || e.salary !== previous) {
            ++team;
            previous = e.salary;
        }
        return {employee_id: e.employee_id, name: e.name,
                salary: e.salary, team_id: team};
    });
}

from collections import Counter

def group_employees(employees):
    counts = Counter(e["salary"] for e in employees)
    kept = sorted((e for e in employees if counts[e["salary"]] >= 2),
                  key=lambda e: (e["salary"], e["employee_id"]))
    result = []
    previous = None
    team = 0
    for e in kept:
        if team == 0 or e["salary"] != previous:
            team += 1
            previous = e["salary"]
        result.append({"employee_id": e["employee_id"], "name": e["name"],
                       "salary": e["salary"], "team_id": team})
    return result

#include <algorithm>
#include <iostream>
#include <string>
#include <tuple>
#include <unordered_map>
#include <vector>
using namespace std;

struct Employee { int employee_id; string name; int salary; };
struct Result { int employee_id; string name; int salary; int team_id; };

vector<Result> groupEmployees(const vector<Employee>& employees) {
    unordered_map<int, int> counts;
    for (const auto& e : employees) ++counts[e.salary];
    vector<Employee> kept;
    for (const auto& e : employees)
        if (counts[e.salary] >= 2) kept.push_back(e);
    sort(kept.begin(), kept.end(), [](const auto& a, const auto& b) {
        return tie(a.salary, a.employee_id) < tie(b.salary, b.employee_id);
    });
    vector<Result> result;
    int team = 0, previous = 0;
    for (const auto& e : kept) {
        if (team == 0 || e.salary != previous) {
            ++team;
            previous = e.salary;
        }
        result.push_back({e.employee_id, e.name, e.salary, team});
    }
    return result;
}
int main() {
    vector<Employee> employees = {{2, "Meir", 3000}, {3, "Michael", 3000},
        {7, "Addilyn", 7400}, {8, "Juan", 6100}, {9, "Kannon", 7400}};
    for (const auto& r : groupEmployees(employees))
        cout << r.employee_id << ' ' << r.name << ' ' << r.salary
             << ' ' << r.team_id << '\n';
}
