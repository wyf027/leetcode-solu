计算每个销售人员的影响力

Calculate the Influence of Each Salesperson

一笔购买，属于一位客户；一位客户，由一名销售人员负责。如何为每位销售人员整理出完整的消费金额报告？

01 / PROBLEM

题意与数据契约

给定 Salesperson、Customer、Sales 三张表。对每名销售人员，统计其负责的所有客户在所有交易中支付的 price 之和，输出 salesperson_id, name, total。没有客户的销售人员也要出现，金额为 0；有客户但没有购买记录时同样记为 0。结果顺序不限。

05 / SOLUTION

先想一想，再展开

当某位销售人员没有任何交易时，报表还能保留他的名字吗？

从完整名单出发，沿关系汇总

核心洞察

输出的粒度是“每名销售人员一行”。让 Salesperson 成为起点，使用两次 LEFT JOIN 保留没有匹配的人员或客户；然后按销售人员分组，对真实交易求和，将没有可累加金额的结果从 NULL 转成 0。

完整过程

  1. 连接 sp.salesperson_id = c.salesperson_id，把客户挂到负责人员名下。没有客户的 Jerry 保留一行，客户列为 NULL。
  2. 连接 c.customer_id = s.customer_id，展开每个客户的全部交易。客户 3 有两笔，因此 Bob 对应两行；没有交易的行保留 NULL。
  3. 按 sp.salesperson_id, sp.name 分组，SUM 只累加非 NULL 的 price。
  4. 使用 COALESCE(SUM(s.price), 0)，确保没有金额时输出 0。无需 ORDER BY。

SQL · 官方可提交语言 / MySQL

SELECT
    sp.salesperson_id,
    sp.name,
    COALESCE(SUM(s.price), 0) AS total
FROM Salesperson AS sp
LEFT JOIN Customer AS c
    ON c.salesperson_id = sp.salesperson_id
LEFT JOIN Sales AS s
    ON s.customer_id = c.customer_id
GROUP BY sp.salesperson_id, sp.name;

上述使用标准连接与聚合语法；元数据也列出 PostgreSQL、SQL Server、Oracle SQL。未在任何数据库执行。

正确性说明

完整性：从人员表开始的左连接保证每位销售人员至少保留一行，即使两层关系都没有匹配。唯一归属：Customer 的唯一 customer_id 使每笔交易至多关联一个客户；该客户再通过 salesperson_id 归属一个销售人员，因此不会把同一笔交易重复计入不同人员。金额准确：同一组含该人员所属客户的全部交易，SUM 恰好计算这些 price 之和；左连接补出的 NULL 不贡献金额。输出粒度：唯一 ID 与姓名共同分组，每人恰好一行；全部为 NULL 时 COALESCE 得到 0。

边界与 NULL

  • 无客户、客户无交易：均输出 0；Salesperson 为空则无输出行。
  • 同名不同 ID：必须分开，不能只按 name 分组。
  • 不同交易可能价格相同：都要累加，不能使用 SUM(DISTINCT price)。
  • SUM 忽略真实 NULL price；整组没有非 NULL 值则补 0。NULL 外键不会匹配人员或客户，相关交易不属于任何可输出人员。
  • 通用语言参考采用有效、非空的 ID 外键模型，金额允许 null / None / optional；并非完整实现数据库的所有可空字段语义。

复杂度

令 P、C、S 分别为人员、客户、交易行数。有效唯一键关系下连接结果规模为 O(P + C + S)。采用哈希连接和哈希聚合时，典型期望时间为 O(P + C + S)，工作内存可达 O(P + C + S)；真实 SQL 成本取决于索引、连接算法、排序、内存与执行计划，不能无条件宣称线性或 O(1) 空间。下方本地哈希映射实现期望时间 O(P + C + S)，辅助空间 O(P + C)，返回结果 O(P)。

替代方案

可先按客户汇总 Sales，再关联 Customer，最终按销售人员汇总，适合一个客户有大量交易的情形；或先把 Customer 与 Sales 聚合为每位销售人员的金额，再左连接完整人员名单。相关子查询更直观，但缺少合适索引时容易重复扫描。没有性能证据时，两次 LEFT JOIN 已足够清楚。

常见错误

  • 从 Sales 出发或改用 INNER JOIN：丢失无交易人员。
  • LEFT JOIN 后在 WHERE 中写右表过滤条件：可能把保留的 NULL 行删掉；按意图放入 ON 或条件聚合。
  • 把 COUNT 当金额，或用 DISTINCT 消除合法的等价金额。
  • 仅使用 SUM 而不补零，或用 name 作为唯一身份。
  • 将其他一对多明细表一起连接造成交易倍增；先明确每张表的粒度，必要时预聚合。

面试追问

  • 只统计某个时间段且仍保留全部人员？给 Sales 增加时间列后，把条件放在第二个 JOIN 的 ON 中。
  • 怎样优化大表？考察 Customer(salesperson_id)、Sales(customer_id) 索引，并结合实际执行计划判断预聚合是否有益。
  • 客户后来换了销售人员，历史收入属于谁？当前模式只能按现在的归属统计；历史归因需要交易快照或带有效期的归属数据。
  • 如何计算影响力占比？先取得每人总额，再除以总销售额，并明确总销售额为 0 时的输出规则。

Java 17 · 本地语义参考

import java.util.*;

public class Main {
    record Person(int id, String name) {}
    record Customer(int id, int salespersonId) {}
    record Sale(int id, int customerId, Long price) {}
    record Result(int salespersonId, String name, long total) {}

    static List<Result> calculateInfluence(
            List<Person> people, List<Customer> customers,
            List<Sale> sales) {
        Map<Integer, Integer> owner = new HashMap<>();
        Map<Integer, Long> totals = new HashMap<>();
        for (Person p : people) totals.put(p.id(), 0L);
        for (Customer c : customers) owner.put(c.id(), c.salespersonId());
        for (Sale s : sales) {
            Integer id = owner.get(s.customerId());
            if (id != null && totals.containsKey(id) && s.price() != null)
                totals.put(id, Math.addExact(totals.get(id), s.price()));
        }
        List<Result> result = new ArrayList<>();
        for (Person p : people)
            result.add(new Result(p.id(), p.name(), totals.get(p.id())));
        return result;
    }

    public static void main(String[] args) {
        var people = List.of(new Person(1,"Alice"), new Person(2,"Bob"),
                             new Person(3,"Jerry"));
        var customers = List.of(new Customer(1,1), new Customer(2,1),
                                new Customer(3,2));
        var sales = List.of(new Sale(1,2,892L), new Sale(2,1,354L),
                            new Sale(3,3,988L), new Sale(4,3,856L));
        System.out.println(calculateInfluence(people, customers, sales));
    }
}

JavaScript · 本地语义参考

function calculateInfluence(Salesperson, Customer, Sales) {
  const owner = new Map(Customer);
  const totals = new Map(Salesperson.map(([id]) => [id, 0n]));
  for (const [, customerId, price] of Sales) {
    const id = owner.get(customerId);
    if (totals.has(id) && price != null) {
      // 大金额应传 BigInt 或整数字符串，避免 Number 先失去精度。
      if (typeof price === "number" && !Number.isSafeInteger(price))
        throw new RangeError("price must be an exact integer");
      totals.set(id, totals.get(id) + BigInt(price));
    }
  }
  return Salesperson.map(([id, name]) => ({
    salesperson_id: id, name, total: totals.get(id)
  }));
}

Python 3 · 本地语义参考

def calculate_influence(salesperson, customer, sales):
    owner = dict(customer)
    totals = {person_id: 0 for person_id, _ in salesperson}
    for _, customer_id, price in sales:
        person_id = owner.get(customer_id)
        if person_id in totals and price is not None:
            totals[person_id] += price
    return [
        {"salesperson_id": person_id, "name": name,
         "total": totals[person_id]}
        for person_id, name in salesperson
    ]

C++17 · 本地语义参考

#include <iostream>
#include <limits>
#include <optional>
#include <stdexcept>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Person { int id; string name; };
struct Customer { int id, salespersonId; };
struct Sale { int id, customerId; optional<long long> price; };
struct Result { int salespersonId; string name; long long total; };

vector<Result> calculateInfluence(const vector<Person>& people,
        const vector<Customer>& customers, const vector<Sale>& sales) {
    unordered_map<int, int> owner;
    unordered_map<int, long long> totals;
    for (const auto& p : people) totals[p.id] = 0;
    for (const auto& c : customers) owner[c.id] = c.salespersonId;
    for (const auto& s : sales) {
        auto c = owner.find(s.customerId);
        if (c == owner.end() || !s.price) continue;
        auto t = totals.find(c->second);
        if (t == totals.end()) continue;
        long long x = *s.price, a = t->second;
        if ((x > 0 && a > numeric_limits<long long>::max() - x) ||
            (x < 0 && a < numeric_limits<long long>::min() - x))
            throw overflow_error("total exceeds 64-bit range");
        t->second += x;
    }
    vector<Result> result;
    for (const auto& p : people)
        result.push_back({p.id, p.name, totals.at(p.id)});
    return result;
}

int main() {
    vector<Person> people = {{1,"Alice"},{2,"Bob"},{3,"Jerry"}};
    vector<Customer> customers = {{1,1},{2,1},{3,2}};
    vector<Sale> sales = {{1,2,892},{2,1,354},{3,3,988},{4,3,856}};
    for (const auto& r : calculateInfluence(people, customers, sales))
        cout << r.salespersonId << ' ' << r.name << ' ' << r.total << '\n';
}
