比赛中的
配对次数

从一组参赛队伍开始，逐轮观察配对、轮空与晋级。先亲手推进赛程，再决定是否展开完整题解。

难度：简单 数学 模拟 非付费题

Problem

题目

函数：numberOfMatches(n)

给定整数 n，表示参加淘汰赛的队伍数。比赛持续进行，直至只剩一支冠军队伍。

  • 当前队伍数为偶数时，所有队伍两两配对；本轮进行 n / 2 场比赛，并有 n / 2 支队伍晋级。
  • 当前队伍数为奇数时，一支队伍轮空晋级，其余队伍两两配对；本轮进行 (n - 1) / 2 场比赛，并有 (n - 1) / 2 + 1 支队伍晋级。

返回决出冠军之前一共进行的比赛场数。

参数与约束

numberOfMatches(n: integer): integer
  • 1 <= n <= 200
  • n 是初始参赛队伍数。
  • 返回值是整个赛事累计的比赛数。

Solution

题解

核心洞察：每场比赛恰好淘汰一支队伍。 初始有 n 支队伍，最终需要只剩 1 支冠军，因此必须淘汰 n - 1 支队伍。无论每轮是否出现轮空，淘汰一支队伍都对应且只对应一场比赛，所以总比赛数为 n - 1。

完整过程

  1. 确定初态：赛场上共有 n 支未被淘汰的队伍。
  2. 观察单场：一场淘汰赛由两队参加，赛后败者离开，所以存活队伍数恰好减少 1。
  3. 确定终态：冠军产生时只剩 1 支队伍，共减少了 n - 1 支。
  4. 建立对应：每减少一队就发生一场比赛，故比赛总数就是 n - 1。

正确性证明

命题：算法返回的 n - 1 等于赛事总比赛数。

证明：任意一场比赛都产生唯一败者，因此每场比赛恰好淘汰一支队伍；轮空不会产生比赛，也不会淘汰队伍。比赛开始时有 n 支队伍，结束时有且仅有 1 支冠军，整个过程正好淘汰 n - 1 支队伍。由于比赛与被淘汰队伍一一对应，赛事总比赛数必为 n - 1。算法返回该值，因此正确。证毕。

时间复杂度O(1)一次减法
空间复杂度O(1)无需额外空间

Boundaries

边界与特殊情况

n = 1

已经存在唯一冠军，不需要比赛，返回 0。公式 n - 1 同样成立。

奇数队伍

轮空只改变轮次的组织方式，不淘汰队伍，因此不改变“每场淘汰一队”的总量关系。

Alternative

替代方案：按轮模拟

也可以完全照题意循环：当 n > 1 时，本轮比赛数是 Math.floor(n / 2)，晋级数是 Math.ceil(n / 2)。把每轮比赛数加入答案，再更新队伍数。该方案直观且与交互演示一致，但需要 O(log n) 时间；数学解法更简洁。

Interview follow-ups

面试追问

如果一场比赛能淘汰多支队伍呢？

“一场比赛对应一个淘汰者”的不变量会失效，需要根据每场实际淘汰人数重新计数；若每场固定淘汰 k 队，还必须考虑剩余数量是否允许完整分组。

为什么按轮模拟是 O(log n)？

每轮晋级队伍数约为当前的一半，因此经过约 log₂ n 轮后只剩冠军。

能否从图论角度解释？

把队伍视为叶子、比赛视为产生晋级者的合并节点。形成单一冠军的淘汰树具有 n 个叶子与 n - 1 个内部合并节点，对应 n - 1 场比赛。

Pitfalls

常见错误

把轮空算作比赛

轮空队伍直接晋级，没有对手，也没有败者，所以不增加比赛数。

只计算首轮

Math.floor(n / 2) 只是当前轮比赛数，不是整个赛事总数。

更新奇数晋级数出错

模拟时下一轮队伍数应为 Math.ceil(n / 2)，而不是 Math.floor(n / 2)。

忽略最小边界

n = 1 时应返回 0；不要强制至少进行一轮。
