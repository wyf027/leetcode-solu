01题目与数据契约

输入关系表 Olympic，每行记录一个国家以及它获得的金、银、铜牌数量。返回原表的四列和全部记录，并按下面的优先级排列。

① 金牌更多的国家优先。
② 金牌相同，再比较银牌，多者优先。
③ 金银均相同，再比较铜牌，多者优先。
④ 三种奖牌均相同，国家名按字典序升序。

05独立题解

准备好后，展开 SQL 与多语言语义参考。

按优先级排列排序键

核心洞察

两行记录只由第一个不同的关键字决定顺序。金、银、铜分别降序，名称升序；低优先级奖牌再多，也不能抵消高优先级的一枚差距。数据库已有多列排序能力，一条查询即可表达。

完整过程

  1. 读取 Olympic 的四个字段，保留全部行。
  2. 以金牌为首要键，按降序排列。
  3. 在金牌相同的组内按银牌降序，再在金银相同的组内按铜牌降序。
  4. 对奖牌数完全一致的行，按国家名字典序升序。把四个键写进同一条 ORDER BY。

官方可提交主解 · SQL / MySQL

SELECT country, gold_medals, silver_medals, bronze_medals
FROM Olympic
ORDER BY gold_medals DESC,
         silver_medals DESC,
         bronze_medals DESC,
         country ASC;

正确性

任取两行：如果金牌数不同，第一排序键将金牌更多者排前；否则第一键相等，第二键按银牌决定。金银均相同则由铜牌决定；前三键均相同则由名称决定。这覆盖题目的全部比较分支，因此结果中任意两行的相对顺序都满足规则。查询既未筛选也未聚合，所以原来的四列和所有记录完整保留。

边界与复杂度

  • 空表返回空结果，单行顺序不变；零奖牌无需特殊分支。
  • country 是主键，不应产生同名重复记录；奖牌相同不代表可以去重。
  • 设 n 为行数，一般比较排序模型为 O(n log n) 次比较，物化结果和排序缓冲通常需要 O(n) 空间；实际数据库取决于执行计划、内存与索引。名称最大长度记为 L，则字符串比较最坏为 O(L)。
  • 匹配排序方向的可用索引可能避免额外排序；不应把某种 SQL 引擎的物理算法当作题目保证。
  • 题面没有约定 NULL 或复杂字符排序细节；生产环境须约定 NULL 位置与 collation。以下本地代码假设奖牌为非空整数、名称采用示例式 ASCII 字符，不能声称跨语言字符串顺序与任意数据库排序规则一致。

替代方案

可以用本地语言比较器完成同一排序，或以反优先级顺序做多次稳定排序（先名称，再铜、银、金）。后者依赖稳定性且重复排序，没有单个比较器或 SQL 多列 ORDER BY 直接。不建议把奖牌数乘权重相加：没有足够上界时，低级奖牌会压过高级奖牌。

常见错误

  • 按总奖牌数排序，或把 country 也设为 DESC。
  • 把 DESC 仅写在最后一个奖牌列后，误以为它作用于之前所有列。
  • 用 GROUP BY、DISTINCT 或排名函数替代原表排序，改变输出。
  • 认为表的输入顺序就是查询顺序；没有 ORDER BY 不保证返回顺序。
  • 比较器直接使用整数相减，在 Java/C++ 大值场景可能溢出；参考代码使用比较函数或分支。

面试追问

只取前十如何改？ 在确定排序后按目标数据库语法限制行数。并列也要全部保留？ 先说明并列是否仅按奖牌定义，再选 RANK 或 DENSE_RANK；名称不应被误用为奖牌并列键。要分页？ 保持四键确定顺序，并讨论数据变动与游标分页。排序性能如何查？ 阅读执行计划，确认是否存在额外排序以及索引是否匹配。

Java · Java 8+

import java.util.*;

public class Main {
    static class Row {
        String country;
        int gold, silver, bronze;
        Row(String c, int g, int s, int b) {
            country = c; gold = g; silver = s; bronze = b;
        }
        public String toString() {
            return country + ", " + gold + ", " + silver + ", " + bronze;
        }
    }
    static List<Row> sortOlympic(List<Row> rows) {
        List<Row> result = new ArrayList<>(rows);
        result.sort(Comparator.comparingInt((Row r) -> r.gold).reversed()
            .thenComparing(Comparator.comparingInt((Row r) -> r.silver).reversed())
            .thenComparing(Comparator.comparingInt((Row r) -> r.bronze).reversed())
            .thenComparing(r -> r.country));
        return result;
    }
    public static void main(String[] args) {
        List<Row> rows = Arrays.asList(
            new Row("China", 10, 10, 20),
            new Row("South Sudan", 0, 0, 1),
            new Row("USA", 10, 10, 20),
            new Row("Israel", 2, 2, 3),
            new Row("Egypt", 2, 2, 2));
        sortOlympic(rows).forEach(System.out::println);
    }
}

JavaScript · 数组行

function sortOlympic(rows) {
  return [...rows].sort((a, b) => {
    for (const key of [1, 2, 3]) {
      if (a[key] !== b[key]) return a[key] > b[key] ? -1 : 1;
    }
    return a[0] < b[0] ? -1 : a[0] > b[0] ? 1 : 0;
  });
}
const Olympic = [
  ["China", 10, 10, 20],
  ["South Sudan", 0, 0, 1],
  ["USA", 10, 10, 20],
  ["Israel", 2, 2, 3],
  ["Egypt", 2, 2, 2]
];
console.log(JSON.stringify(sortOlympic(Olympic)));

C++ · C++11+

#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Row {
    string country;
    int gold, silver, bronze;
};
vector<Row> sortOlympic(vector<Row> rows) {
    sort(rows.begin(), rows.end(), [](const Row& a, const Row& b) {
        if (a.gold != b.gold) return a.gold > b.gold;
        if (a.silver != b.silver) return a.silver > b.silver;
        if (a.bronze != b.bronze) return a.bronze > b.bronze;
        return a.country < b.country;
    });
    return rows;
}
int main() {
    vector<Row> olympic = {
        {"China", 10, 10, 20}, {"South Sudan", 0, 0, 1},
        {"USA", 10, 10, 20}, {"Israel", 2, 2, 3}, {"Egypt", 2, 2, 2}
    };
    for (const auto& r : sortOlympic(olympic))
        cout << r.country << ", " << r.gold << ", "
             << r.silver << ", " << r.bronze << '\n';
    return 0;
}
