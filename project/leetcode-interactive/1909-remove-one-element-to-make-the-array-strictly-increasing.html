1909. 删除一个元素使数组严格递增

Remove One Element to Make the Array Strictly Increasing

数组 · 非付费题

题目

给定从下标 0 开始的整数数组 nums，判断能否恰好删除一个元素，使剩下的元素按原顺序严格递增。能做到则返回 true，否则返回 false。原数组已经严格递增时，也返回 true。

严格递增表示每对相邻元素满足 nums[i−1] < nums[i]，相等不算递增。

约束：2 ≤ nums.length ≤ 1000，1 ≤ nums[i] ≤ 1000。

官方题目

官方示例

示例 1

输入：nums = [1,2,10,5,7]
输出：true

删除下标 2 的 10 后得到 [1,2,5,7]，严格递增。

示例 2

输入：nums = [2,3,1,2]
输出：false

依次删除下标 0、1、2、3，会得到 [3,1,2]、[2,1,2]、[2,3,2]、[2,3,1]。没有一种结果严格递增。

示例 3

输入：nums = [1,1,1]
输出：false

删除任意元素都得到 [1,1]，不满足严格递增。

示例 4（中文题面）

输入：nums = [1,2,3]
输出：true

原数组已严格递增，删除任意一个元素仍满足条件。

题解 · 首个冲突的两个端点

核心洞察

找到首个 nums[i−1] ≥ nums[i]。任何成功删除都必须删除这两个端点之一，否则这对坏邻居仍然存在。因此只检查删除 i−1 与删除 i 两种方案。

完整过程

  1. 从左到右找第一对不严格递增的相邻元素。
  2. 跳过左端点，从头扫描保留元素。prev 保存前一个保留值，当前值 ≤ prev 就失败。
  3. 若失败，再跳过右端点重新检查。任何一个方案成功就返回 true，否则返回 false。
  4. 没有冲突时直接返回 true，因为删除任意一个元素都可。

[1,2,10,5,7] 的首个冲突为 10 ≥ 5；跳过 10 后，1<2、2<5、5<7，成功。[1,2,1,2] 跳过冲突左端会出现 1=1，跳过右端会出现 2=2，两种都失败。

正确性证明

必要性：删除首个冲突之外的元素，冲突两端仍相邻，因此不可能成功。充分性：检查函数遍历所有保留元素，只有每一对相邻关系都严格递增才返回 true，且恰好跳过一个下标。两个候选覆盖全部可能方案。若原数组无冲突，删除产生的新邻接关系由严格小于的传递性保证。

边界与复杂度

长度为 2 时总可删除一个；重复值要使用 ≥ 判冲突；删除位置可以在首尾。代码不修改原数组。最多一次定位、两次完整检查，时间 O(n)，额外空间 O(1)。最小整数哨兵对题目正整数范围安全；推广到任意整数时可用“是否有前项”标记代替哨兵。

替代方案

枚举所有删除位置并逐个检查：时间 O(n²)，空间 O(1)。单遍贪心可维护前两个保留值与删除次数，同为 O(n)，但需要更细致地决定删除左端还是右端。

常见错误

  • 只统计原数组冲突数，忽略删除后新形成的相邻关系。
  • 始终删除较大值；[1,2,1,3] 应删除后面的 1。
  • 用 > 判断失败，漏掉相等情况。
  • 把已经递增的数组判 false，忽略删除后仍然递增。

面试追问

如何返回删除下标？返回检查成功的候选，无冲突时任取一个。允许至多删除 k 个？可以判断 n−LIS 长度 ≤ k。流式输入怎么做？用前两个保留值与一次删除预算实现单遍贪心。

JavaScript

/** @param {number[]} nums @return {boolean} */
var canBeIncreasing = function(nums) {
    function valid(skip) {
        let prev = -Infinity;
        for (let j = 0; j < nums.length; j++) {
            if (j === skip) continue;
            if (nums[j] <= prev) return false;
            prev = nums[j];
        }
        return true;
    }
    for (let i = 1; i < nums.length; i++) {
        if (nums[i - 1] >= nums[i])
            return valid(i - 1) || valid(i);
    }
    return true;
};

class Solution {
    public boolean canBeIncreasing(int[] nums) {
        for (int i = 1; i < nums.length; i++) {
            if (nums[i - 1] >= nums[i])
                return valid(nums, i - 1) || valid(nums, i);
        }
        return true;
    }
    private boolean valid(int[] nums, int skip) {
        int prev = Integer.MIN_VALUE;
        for (int j = 0; j < nums.length; j++) {
            if (j == skip) continue;
            if (nums[j] <= prev) return false;
            prev = nums[j];
        }
        return true;
    }
}

Python

from typing import List

class Solution:
    def canBeIncreasing(self, nums: List[int]) -> bool:
        def valid(skip: int) -> bool:
            prev = float('-inf')
            for j, value in enumerate(nums):
                if j == skip:
                    continue
                if value <= prev:
                    return False
                prev = value
            return True

        for i in range(1, len(nums)):
            if nums[i - 1] >= nums[i]:
                return valid(i - 1) or valid(i)
        return True

    bool canBeIncreasing(vector<int>& nums) {
        auto valid = [&](int skip) {
            int prev = numeric_limits<int>::min();
            for (int j = 0; j < (int)nums.size(); ++j) {
                if (j == skip) continue;
                if (nums[j] <= prev) return false;
                prev = nums[j];
            }
            return true;
        };
        for (int i = 1; i < (int)nums.size(); ++i) {
            if (nums[i - 1] >= nums[i])
                return valid(i - 1) || valid(i);
        }
        return true;
    }
};
