给定正整数 n，寻找一个不小于它的整数。这个整数的十进制表示中，值为偶数的数字个数与值为奇数的数字个数必须相同。在所有满足条件的整数里，返回最小的那个。

“奇偶”按每个数字的值判断：0、2、4、6、8 为偶数数字，1、3、5、7、9 为奇数数字。这里不统计奇数位置或偶数位置，也不按数字之和判断。

要求答案 ≥ n；如果 n 已经公平，可以直接返回 n。十进制表示不带前导零。

04 / Editorial

准备好再打开题解

包含推导、正确性与四种语言的完整实现。

核心洞察：偶数位枚举，奇数位直接构造

设总位数为 d。若两类数字一样多，则 d 必须为偶数。偶数位时从 n 开始逐一判断；奇数位时，这一整段位数的整数都无解，可以直接返回下一种位数的最小公平整数。

最小公平数如何构造

要构造 2h 位的最小公平数：首位必须非零，取 1；随后尽早放完 h 个 0；最后放 h−1 个 1。得到 1 + 0×h + 1×(h−1)（此处 + 表示字符串拼接）。例如 4 位得到 1001，6 位得到 100011，10 位得到 1000001111。

若当前 d 是奇数，则 h = (d+1)/2。首位 1 加末尾 h−1 个 1 共 h 个奇数，h 个 0 提供 h 个偶数。

完整过程

  1. 令候选 x = n，取十进制字符串并计算位数 d。
  2. 若 d 为奇数，构造 d+1 位最小公平整数并返回。
  3. 否则数出偶数数字 e；若 2e = d，返回 x。
  4. 若不满足，令 x 加一并回到第一步。加一后重新计算位数，处理进位。

例如 n = 99：99 不公平 → 100 是三位数 → 直接构造四位最小公平数 1001。无需枚举 100 到 999。交互分拣台将构造结果额外展示一帧，便于观察奇偶数量。

为什么正确

  1. 判定准确：每位要么奇数要么偶数，因此 2e = d 等价于两类数量相同。
  2. 构造最小：非零首位至少为 1；首位取 1 后，0 比其他可用数字小，故在不超过偶数配额的前提下尽早放 0；剩余奇数位最小只能取 1。任何首次不同位置取更大数字的方案，数值都更大。
  3. 不漏答案：偶数位区间按升序逐项检查；奇数位区间不可能公平，跳过它不会漏解。构造出的数是紧邻的偶数位长度中的最小解，比更长整数都小。
  4. 终止且全局最小：每次枚举递增，跨入奇数位就构造返回。返回前所有更小且不小于 n 的整数均已被排除，所以返回值就是所求。

复杂度与搜索距离

令 K 为实际检查的候选数，D 为过程中最大位数：时间 O(KD)，额外空间 O(D)（本页代码使用字符串）。奇数位输入仅需 O(D) 构造。

对于 2h 位整数，把它拆成 h 位前缀和 h 位后缀。任意固定前缀中若有 o 个奇数，后缀只需补 h−o 个奇数与 o 个偶数，总能用 0、1 实现（后缀允许零开头）。因此当前后缀块或下一个前缀块内必有解，最多扫描约 2×10ʰ 个整数；若进位溢出原长度则直接构造。偶数位搜索的上界可写成 O(D·10^(D/2))，无需把有界输入误写成普适 O(1)。

边界与常见错误

  • 0 是偶数数字，必须计数。
  • 公平整数的位数必须为偶数，但偶数位不保证公平。
  • 从 n 开始；不能从 n+1 开始漏掉自身。
  • n 为奇数值，不代表总位数为奇数。
  • 每次加一后重算位数，尤其是 99、9999。
  • 不要逐个递归调用，连续枚举可能导致栈溢出。
  • 答案可以大于 10⁹；本约束最大答案为 1000001111，仍在 32 位有符号整数范围内。

替代方案与面试追问

  • 纯枚举：实现短，但奇数位区间可能极长，需要跳过。
  • 数位 DP / 带约束回溯：记录位置、奇数数量与是否贴住下界，再按数字升序构造；适合超长字符串输入。
  • 如何进一步减少空间？用除 10 和取模统计，避免候选字符串。
  • 若输入扩展到 100 位？保留字符串，使用数位 DP；不再依赖机器整数。
  • 如何求区间内公平数个数？改成数位 DP 计数，计算 F(R)−F(L−1)。
  • 如何解释枚举不太远？利用前后各 h 位的配额补全论证。

Java

LeetCode 提交形式 · 无需 main

class Solution {
    public int closestFair(int n) {
        for (int x = n; ; x++) {
            String s = Integer.toString(x);
            int d = s.length();
            if (d % 2 == 1) {
                int h = (d + 1) / 2;
                StringBuilder answer = new StringBuilder("1");
                for (int i = 0; i < h; i++) answer.append('0');
                for (int i = 0; i < h - 1; i++) answer.append('1');
                return Integer.parseInt(answer.toString());
            }
            int even = 0;
            for (int i = 0; i < d; i++) {
                if ((s.charAt(i) - '0') % 2 == 0) even++;
            }
            if (even * 2 == d) return x;
        }
    }
}

/**

var closestFair = function(n) {
    for (let x = n; ; x++) {
        const s = String(x), d = s.length;
        if (d % 2 === 1) {
            const h = (d + 1) / 2;
            return Number('1' + '0'.repeat(h) + '1'.repeat(h - 1));
        }
        let even = 0;
        for (const digit of s) {
            if (Number(digit) % 2 === 0) even++;
        }
        if (even * 2 === d) return x;
    }
};

class Solution:
    def closestFair(self, n: int) -> int:
        x = n
        while True:
            s = str(x)
            d = len(s)
            if d % 2 == 1:
                h = (d + 1) // 2
                return int('1' + '0' * h + '1' * (h - 1))
            even = sum(int(digit) % 2 == 0 for digit in s)
            if even * 2 == d:
                return x
            x += 1

C++

LeetCode 提交形式 · 标准库字符串

#include <string>
using namespace std;

class Solution {
public:
    int closestFair(int n) {
        for (int x = n; ; ++x) {
            string s = to_string(x);
            int d = static_cast<int>(s.size());
            if (d % 2 == 1) {
                int h = (d + 1) / 2;
                return stoi(string("1") + string(h, '0')
                            + string(h - 1, '1'));
            }
            int even = 0;
            for (char digit : s) {
                if ((digit - '0') % 2 == 0) ++even;
            }
            if (even * 2 == d) return x;
        }
    }
};
