括号字符串路径

Check if There Is a Valid Parentheses String Path

从左上角出发，向右或向下走到右下角。把沿途格子的括号连起来，能否得到一串合法括号？只需回答是否存在。

START → END

(0, 0) → (m − 1, n − 1)

MOVEMENT

只向右 → 或向下 ↓

OUTPUT

存在 true / 不存在 false

先独立思考。算法、交互演示与四语言代码都在底部折叠题解中。

01 / 题意与约束

参数 grid 是一个 m × n 字符矩阵。路径必须包含起点和终点，每步只能向右或向下。若至少一条路径组成合法括号串，返回 true，否则返回 false。

合法括号串必须非空：() 合法；两个合法串拼接仍合法；在合法串外面加一对括号也合法，例如 (())、()()。

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 100
  • grid[i][j] 只能是 '(' 或 ')'。

函数：hasValidPath(grid) → boolean。题意、示例和约束依据本轮官方元数据转述。官方题目

02 / 官方示例

示例 1

grid = [["(","(","("],
        [")","(",")"],
        ["(","(",")"],

输出：true

04 / 题解 · 每格记住所有可能的余额

核心洞察

把 ( 当作 +1，把 ) 当作 −1。余额是尚未匹配的左括号数量。合法括号串等价于：任何前缀余额都非负，且最终余额为 0。

同一个格子可能由多条路径到达，余额也可能不同。只标记“可达”不够；状态必须包含 (行, 列, 余额)。相同状态的后续选择相同，可以合并。

完整过程

  1. 每条路径经过 L = m + n − 1 个格子。L 为奇数、起点为右括号或终点为左括号时，直接返回 false。
  2. dp[i][j] 保存读完当前格子后，可达且未被安全剪枝的余额集合。起点有一个余额为 0 的虚拟前驱。
  3. 逐行从左到右遍历；把上格和左格的集合取并集，作为候选余额 b。
  4. 读取当前字符得到 t = b + delta。若 t < 0，则前缀非法；若 t > R = m − 1 − i + n − 1 − j，剩余所有格子即使全是右括号也无法归零。舍弃这两类状态，其余存入当前集合。
  5. 终点集合包含 0，当且仅当存在合法路径。

R 不含当前格子。也可判断 (R − t) 的奇偶性，但在偶数路径长度与上述转移下它自动为偶数，所以实现不额外判断。

状态汇流实验室

紫色粗框为当前格，青色框为上方与左方来源。格内显示读完字符后的余额集合；∅ 表示无保留状态，· 表示未处理。一步处理一个格子，按行推进。这是算法演示，不是测试结果。

用 Tab 定位，Enter / 空格操作。减少动态效果偏好下可手动逐步阅读，自动播放仅在主动点击后开始。

正确性证明

不变式：每格保存的余额都对应一条走到该格的真实路径，其前缀余额均非负，且当前余额不超过剩余格子数。

初始：起点从虚拟余额 0 读取一个字符，与真实路径一致；长度及端点过滤都是合法串的必要条件。

归纳：到达某格的前一步只可能在其上方或左方。合并两处所有状态并读取当前字符，覆盖所有候选路径；每个转移也有真实前驱，不会生成虚假路径。

剪枝：负余额意味着已出现非法前缀；余额大于 R 时，后续每格至多减少 1，不可能归零。任何最终合法路径都不会被剪去。

终止：到达终点且余额为 0，结合前缀非负，恰好构成合法括号串。因此算法既不误报，也不漏解。

复杂度与边界

令 L = m + n − 1。每格最多处理 O(L) 个余额，时间 O(mnL)，空间 O(mnL)。集合版本按哈希操作平均 O(1) 计，布尔数组版本为同阶确定性遍历。数组使用 L + 1 个余额位置。

  • 单格长度为奇数，无解。单行和单列仍适用相同转移。
  • 合适的端点只是必要条件，不保证有解。
  • 左右括号总数一样仍可能非法，例如 ())(() 的第三个字符使余额变负。
  • 合并重复的 (i, j, b) 不影响存在性，因为未来路径只取决于当前位置和余额。

替代方案

  • 记忆化 DFS：缓存 (i, j, b)，向右或下搜索，遇到解可早停；状态上界相同，额外使用递归栈。
  • 滚动数组：只存每列的余额集合，空间降为 O(nL)。更新前 dp[j] 是上格，已更新的 dp[j−1] 是左格，必须先读取旧值再覆盖。
  • 位集合：上、左集合按位或，遇左括号左移，遇右括号右移，再清除超过 R 的位。JavaScript 需 BigInt；普通位运算仅支持 32 位。
  • 穷举路径：可能枚举 C(m+n−2,m−1) 条路径，只适用于很小的网格。

常见错误

  • 把 m + n − 2 次移动误当成路径字符数，遗漏起点。
  • 只保存每格一个任意余额，或只判断最终余额，丢失必要状态或非法前缀。
  • 混用读取当前格子前后的余额，重复或漏算字符。
  • R 误包含当前格子；或者未判断负数就访问 b−1 的数组下标。
  • DFS 只按坐标记忆，或者多个格子错误地共享一个可变集合。

面试追问

如何返回具体路径？首次到达每个 (i, j, b) 时存前驱，从终点余额 0 反向恢复。如何统计路径数？把布尔值改成计数，上、左贡献相加，按题目要求取模。若能向上或向左？图可能有环，路径长度不再固定，需要先明确能否重复访问，当前 DP 不能直接复用。

Java

class Solution {
    public boolean hasValidPath(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        int L = m + n - 1;
        if (L % 2 == 1 || grid[0][0] != '(' ||
            grid[m - 1][n - 1] != ')') return false;
        boolean[][][] dp = new boolean[m][n][L + 1];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int delta = grid[i][j] == '(' ? 1 : -1;
                int remaining = m - 1 - i + n - 1 - j;
                for (int b = 0; b <= L; b++) {
                    boolean reachable = (i == 0 && j == 0 && b == 0)
                        || (i > 0 && dp[i - 1][j][b])
                        || (j > 0 && dp[i][j - 1][b]);
                    int t = b + delta;
                    if (reachable && t >= 0 && t <= remaining)
                        dp[i][j][t] = true;
                }
            }
        }
        return dp[m - 1][n - 1][0];
    }
}

JavaScript

/**
 * @param {character[][]} grid
 * @return {boolean}
 */
var hasValidPath = function(grid) {
    const m = grid.length, n = grid[0].length;
    const L = m + n - 1;
    if (L % 2 || grid[0][0] !== '(' ||
        grid[m - 1][n - 1] !== ')') return false;
    const dp = Array.from({length: m}, () =>
        Array.from({length: n}, () => new Set()));
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            const source = new Set();
            if (i === 0 && j === 0) source.add(0);
            if (i > 0) for (const b of dp[i - 1][j]) source.add(b);
            if (j > 0) for (const b of dp[i][j - 1]) source.add(b);
            const delta = grid[i][j] === '(' ? 1 : -1;
            const remaining = m - 1 - i + n - 1 - j;
            for (const b of source) {
                const t = b + delta;
                if (t >= 0 && t <= remaining) dp[i][j].add(t);
            }
        }
    }
    return dp[m - 1][n - 1].has(0);
};

Python 3

from typing import List

class Solution:
    def hasValidPath(self, grid: List[List[str]]) -> bool:
        m, n = len(grid), len(grid[0])
        length = m + n - 1
        if (length % 2 or grid[0][0] != "("
                or grid[-1][-1] != ")"):
            return False
        dp = [[set() for _ in range(n)] for _ in range(m)]
        for i in range(m):
            for j in range(n):
                source = {0} if i == 0 and j == 0 else set()
                if i > 0:
                    source.update(dp[i - 1][j])
                if j > 0:
                    source.update(dp[i][j - 1])
                delta = 1 if grid[i][j] == "(" else -1
                remaining = m - 1 - i + n - 1 - j
                for b in source:
                    t = b + delta
                    if 0 <= t <= remaining:
                        dp[i][j].add(t)
        return 0 in dp[-1][-1]

                        || (i > 0 && dp[i - 1][j][b])
                        || (j > 0 && dp[i][j - 1][b]);
                    int t = b + delta;
                    if (reachable && t >= 0 && t <= remaining)
                        dp[i][j][t] = true;
                }
            }
        }
        return dp[m - 1][n - 1][0];
