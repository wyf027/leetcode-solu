划分字母区间

Partition Labels

把一条字符串切成尽可能多的连续片段，同时保证任意字母不会跨越两个片段。返回每个片段的长度。

贪心哈希表双指针字符串
输入 / 输出
输入参数
s: string
返回值
list<integer>

所有片段按原顺序拼接后，必须恰好还原为 s。

Problem

题目描述

给定一个仅含小写英文字母的字符串 s，请将它划分为尽可能多的非空连续片段，使同一个字母最多只出现在其中一个片段里。划分不能调整或遗漏字符；把全部片段按顺序连接后，结果仍须等于原字符串。

最终返回一个整数列表，第 i 个整数表示第 i 个片段的长度。例如，"ababcc" 可以划为 ["abab", "cc"]；而让字母 b 同时落入两个片段的划法不合法。

约束

  • 1 <= s.length <= 500
  • s 仅由小写英文字母组成。

示例 1

输入：s = "ababcbacadefegdehijhklij" 输出：[9,7,8]

三个片段依次为 "ababcbaca"、"defegde"、"hijhklij"。继续合并前两个片段虽合法，却无法得到最多片段数。

示例 2

输入：s = "eccbbbbdec" 输出：[10]

首尾字符的覆盖范围把所有位置连在一起，因此整个字符串只能作为一个片段。

Solution

准备好核对思路了吗？

题解、证明、复杂度与四种语言实现默认收起，先独立思考会更有收获。

Greedy Solution

贪心：扫描到当前区间的最远终点

核心洞察

如果某个片段包含字母 x，那么 x 的所有出现位置都必须落在同一片段中。因此，只要预先记录每个字母最后一次出现的位置，扫描片段时就能不断扩张“必须覆盖到”的右边界。

切分条件：当扫描位置 i 恰好等于当前右边界 end 时，从片段起点 start 到 end 已经封闭，可以立刻切分。

完整过程

  1. 第一次遍历字符串，记录每个字母的最后出现下标。
  2. 令当前片段起点 start = 0，动态右边界 end = 0。
  3. 从左到右扫描下标 i，用 end = max(end, last[s[i]]) 扩张边界。
  4. 若 i == end，记录长度 end - start + 1，并令下一片段起点为 i + 1。

为什么正确

1

边界内的字母不会越界

扫描区间 [start, end] 时，每遇到一个字母，都把 end 更新为它的最后出现位置。因此当扫描到 end，区间内所有已见字母的最后位置都不超过 end，它们不会出现在后续片段。

2

不能在更早位置合法切分

在任意 i < end 的位置切分时，当前区间中至少有一个字母的最后出现位置仍在 i 之后，该字母会跨越两个片段，违反条件。

3

每次都取最早合法切点

算法在第一个合法位置立即切分，使当前片段尽可能短，也就为剩余后缀保留了最多的潜在片段。对每个后续片段重复同样论证，最终片段数最大。

时间复杂度
O(n)

两次线性扫描。

空间复杂度
O(1)

固定 26 个字母的数组。

贪心选择
最早合法切点

扫描位置追上动态边界。

边界情况

  • 只有一个字符：立即形成长度为 1 的片段。
  • 所有字符相同：最后位置始终指向末尾，只能得到一个片段。
  • 所有字符互不相同：每个位置都是合法切点，答案全为 1。
  • 首字符在末尾再次出现：它可能把整个字符串锁在同一片段内。

替代方案

也可以先为每个字母建立首次与末次出现区间，再合并所有相交区间。它与本题的边界扩张本质相同，但需要额外整理区间，代码更长。若字符集不固定，可用哈希表保存最后位置，空间复杂度变为 O(k)，其中 k 是不同字符数。

四语言完整代码

选择语言查看对应的 LeetCode 可提交实现。

Java · O(n)固定 26 位数组
class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }

        List<Integer> answer = new ArrayList<>();
        int start = 0;
        int end = 0;

        for (int i = 0; i < s.length(); i++) {
            end = Math.max(end, last[s.charAt(i) - 'a']);
            if (i == end) {
                answer.add(end - start + 1);
                start = i + 1;
            }
        }
        return answer;
    }
}
JavaScript · O(n)固定 26 位数组
/**
 * @param {string} s
 * @return {number[]}
 */
var partitionLabels = function(s) {
    const last = new Array(26).fill(0);
    const base = "a".charCodeAt(0);

    for (let i = 0; i < s.length; i++) {
        last[s.charCodeAt(i) - base] = i;
    }

    const answer = [];
    let start = 0;
    let end = 0;

    for (let i = 0; i < s.length; i++) {
        end = Math.max(end, last[s.charCodeAt(i) - base]);
        if (i === end) {
            answer.push(end - start + 1);
            start = i + 1;
        }
    }
    return answer;
};
Python · O(n)字典记录最后位置
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        last = {char: index for index, char in enumerate(s)}
        answer = []
        start = 0
        end = 0

        for index, char in enumerate(s):
            end = max(end, last[char])
            if index == end:
                answer.append(end - start + 1)
                start = index + 1

        return answer
C++ · O(n)固定 26 位数组
class Solution {
public:
    vector<int> partitionLabels(string s) {
        vector<int> last(26, 0);
        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            last[s[i] - 'a'] = i;
        }

        vector<int> answer;
        int start = 0;
        int end = 0;

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            end = max(end, last[s[i] - 'a']);
            if (i == end) {
                answer.push_back(end - start + 1);
                start = i + 1;
            }
        }
        return answer;
    }
};

面试追问

  • 为什么“最早合法切点”一定能得到最多片段？
  • 如果字符串包含 Unicode 字符，数据结构应如何调整？
  • 能否只遍历一次？若不知道字符未来是否还会出现，切分依据是什么？
  • 这道题与“合并区间”的对应关系是什么？

常见错误

  • 只看当前字符的最后位置，没有保留区间内所有字符的最远位置。
  • 在更新 end 之前判断 i == end，导致过早切分。
  • 片段长度写成 end - start，遗漏两端均包含时的 +1。
  • 切分后忘记把 start 更新为 i + 1。
