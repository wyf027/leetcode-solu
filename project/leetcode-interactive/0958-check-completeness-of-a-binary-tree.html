二叉树的完全性检验

Check Completeness of a Binary Tree

先观察层序扫描中的“空位警戒线”，题解在页面底部按需展开。

题目

给定二叉树根节点 root，判断它是否为完全二叉树：除最后一层外，每层都被填满；最后一层的节点必须从左向右连续排列，不能在空位之后再次出现真实节点。

函数形式：boolean isCompleteTree(TreeNode root)

示例 1

输入：root = [1,2,3,4,5,6]
输出：true
解释：最后一层的 4、5、6 连续靠左。

示例 2

输入：root = [1,2,3,4,5,null,7]
输出：false
解释：空位之后又出现了节点 7。

约束

  • 树中节点数在 [1, 100] 内。
  • 1 <= Node.val <= 1000。

交互演示：空位警戒线

题解：BFS 遇空后不得再遇节点

核心洞察

完全二叉树的层序序列里，所有真实节点必定位于所有空指针之前。把空指针也加入 BFS：第一次取出空指针后设置 seenNull；之后若取出真实节点，立即返回 false。

完整过程

  1. 根节点入队，初始化 seenNull = false。
  2. 出队为空时设置标记。
  3. 出队为真实节点且已有标记时返回 false；否则将左右孩子（包括空）入队。
  4. 队列耗尽则返回 true。

正确性

必要性：完全二叉树逐层从左到右扫描时，空位后不会再有节点，算法不会拒绝合法树。充分性：若所有真实节点均在空位之前，则每层节点占据从左起的连续位置，并且非满层之后没有节点，所以树完全。

边界

  • 单节点树返回 true。
  • 只有左孩子可以完整；只有右孩子会在左空位后遇到节点，返回 false。
  • 最后一层右端连续缺失合法，中间缺口不合法。

复杂度

时间 O(n)，队列空间 O(n)。

替代方案

可按数组规则为节点编号：根为 1，左右孩子为 2i 和 2i+1；最大编号等于节点数时完整。该方法也为 O(n)，但极深树可能发生整数溢出。

面试追问

  • 为什么不能只排除“只有右孩子”？更深层仍可能在空位后出现节点。
  • 能否 DFS？可以结合节点编号、节点数与最大编号判断。
  • 若根为空？常见定义下可视为完整；本题约束至少一个节点。

常见错误

  • 跳过 null 入队，丢失中间缺口信息。
  • 只统计每层数量，忽略末层必须靠左。
  • 把遇到叶子误作警戒线；真正触发条件是遇到任意空孩子位置。

class Solution {
    public boolean isCompleteTree(TreeNode root) {
        java.util.Queue<TreeNode> q = new java.util.LinkedList<>();
        q.offer(root);
        boolean seenNull = false;
        while (!q.isEmpty()) {
            TreeNode node = q.poll();
            if (node == null) { seenNull = true; continue; }
            if (seenNull) return false;
            q.offer(node.left);
            q.offer(node.right);
        }
        return true;
    }
}
var isCompleteTree = function(root) {
    const queue = [root];
    let head = 0, seenNull = false;
    while (head < queue.length) {
        const node = queue[head++];
        if (node === null) { seenNull = true; continue; }
        if (seenNull) return false;
        queue.push(node.left, node.right);
    }
    return true;
};
from collections import deque

class Solution:
    def isCompleteTree(self, root: Optional[TreeNode]) -> bool:
        queue = deque([root])
        seen_null = False
        while queue:
            node = queue.popleft()
            if node is None:
                seen_null = True
                continue
            if seen_null:
                return False
            queue.append(node.left)
            queue.append(node.right)
        return True
