统计中位数为 K 的子数组

Count Subarrays With Median K

一个连续区间，排序后谁站在中间？从中位数的定义出发，先想一想，再展开推导。

01 / 题目

给定长度为 n 的数组 nums，元素是 1 到 n 之间互不相同的整数，以及整数 k。返回中位数恰好为 k 的非空连续子数组数量。

中位数是区间内元素升序排列后的中间元素；长度为偶数时，取两个中间元素中靠左的一个，不取平均值。排序只是用来确定中位数，子数组仍由原数组中的连续位置确定。

例如 [2,3,1,4] 的中位数是 2；[8,4,3,5,1] 的中位数是 4。

官方示例 1

输入：nums = [3,2,1,4,5], k = 4
输出：3

符合条件的子数组为 [4]、[4,5]、[1,4,5]。

官方示例 2

输入：nums = [2,3,1], k = 3
输出：1

只有子数组 [3] 符合条件。

约束

  • n == nums.length
  • 1 ≤ n ≤ 105
  • 1 ≤ nums[i], k ≤ n
  • nums 中元素互不相同，因此它是 1..n 的一个排列，k 必然恰好出现一次。

04 / 题解与实验室

核心洞察 · 配对动画 · 四语言实现

核心洞察：把大小关系变成平衡值

每个合法区间必须包含唯一的 k。将小于 k 的数记作 −1，大于它的数记作 +1，k 记作 0。设小数数量为 L，大数数量为 G，区间平衡值为 G − L。

  • 奇数长度 2m+1：k 排名为 m+1，所以 G = L，平衡值是 0。
  • 偶数长度 2m：左中位数排名为 m，所以 L = m−1、G = m，平衡值是 1。
包含 k 且平衡值属于 {0, 1}，恰好等价于中位数为 k。

完整过程：以 k 为支点，左右配对

  1. 找到 p = nums.indexOf(k)。任何候选区间都能唯一拆成 [l, p−1]、k、[p+1, r]。
  2. 初始化频次表 freq[0] = 1，表示左边不取元素，也就是 l = p。
  3. 从 p−1 向左扫描。维护 a = sum(sign(nums[l..p−1] − k))，把每个左端点的平衡值加入频次表。
  4. 从 r = p 向右扫描，维护右侧平衡值 b（包含 k，但 k 贡献为 0）。每一步累加 freq[−b] + freq[1−b]。
  5. 扫描结束返回累计结果。不需要对任何区间排序，也不改变原数组。

正确性证明

判定充要性。 对包含唯一 k 的区间，若中位数是 k，按奇偶长度可得 G−L 为 0 或 1。反过来，若 G=L，则 k 排在奇数长度的正中；若 G=L+1，则 k 排在偶数长度的左中位，故判定充分且必要。

频次不变量。 左扫描每加入一个位置 l，累计值恰好是 [l,p−1] 的平衡值。连同初始化的空左段，freq[a] 恰好统计所有平衡值为 a 的合法左端点。

完整性与无重复。 固定右端点 r，其右平衡值为 b。总和为 0 或 1 分别要求 a=−b 或 a=1−b，两个键不同，因此查询恰好计入所有合法左端点且不重叠。每个区间有唯一的 (l,r)，右扫描遍历所有 r≥p，所以每个答案恰好被计数一次。

边界与复杂度

  • n=1：空左段与 k 配对，答案为 1。
  • k 在任一端点：对应一侧为空，初始化仍然有效。
  • k=1：只可能是 [k] 或含相邻大数的长度 2 区间；k=n：只有 [k]。
  • 同一个平衡值可能对应多个左端点，必须保存次数。
  • 哈希表版本时间期望 O(n)，空间 O(n)；数组频次表可保证最坏 O(n) 时间。
  • 尽管所有子数组总数可能超过 32 位，本题答案不会：长度为 2m+1 或 2m 的合法区间必须有 m 个大数，所以长度 ≤ 2(n−k)+1；固定左端点，其右侧含大数的数量严格限制可行右端点。更直接的上界见下文。

常见错误

  • 把偶数长度按右中位数理解，误用平衡值 −1。
  • 只统计和为 0，漏掉所有偶数长度答案。
  • 忘记 freq[0]=1，漏掉从 k 开始的区间。
  • 将 freq 写成集合，重复平衡值被丢失。
  • 统计不包含 k 的零和区间；支点拆分自动排除它们。
  • 在右扫描阶段继续写入左表，破坏“左端点均在支点左侧或支点处”的不变量。

返回类型为什么能用 int？

每个右侧平衡值 b 只匹配两个相邻键 −b、1−b。左侧平衡值是一条每步 ±1 的路径，其奇偶性随步数交替；右侧同理。对于固定的一侧，连续两步的平衡值不同，因此同一键至多出现约一半次数。一个简洁上界是：右侧有 R=n−p 个端点、左侧有 A=p+1 个端点，区间总数最多 A·R ≤ floor((n+1)²/4)，这个粗界在 n=10⁵ 时仍偏大。进一步，固定任意两个相邻左端点，其平衡值相差 1；固定两个相邻右端点亦相差 1。在这四种配对中至多三种总和属于 {0,1}。两边分组并加上未配对边界，可得 answer ≤ 3AR/4 + (A+R)/4 ≤ 3(n+1)²/16 + (n+1)/4 < 2³¹−1（n≤10⁵）。四份代码沿用官方整数返回签名；JavaScript 的 Number 也能精确表示结果。

替代方案

  • 前缀和 + 是否见过 k：在遇到 k 之前收集前缀平衡值频次；遇到 k 之后，对当前前缀值 s 查询 freq[s] + freq[s−1]。同样是期望 O(n)，但必须冻结左侧频次表。
  • 偏移数组代替哈希表：平衡值范围为 [−n,n]，用长度 2n+3 的数组和偏移量 n+1 存频次，得到确定性 O(n) 时间。
  • 枚举区间并排序：适合手工理解或小规模参考，朴素总成本 O(n³ log n)，无法满足 n=10⁵。

面试追问

  • 若改成右中位数？合法平衡值变成 0 或 −1，查询 freq[−b] + freq[−1−b]。
  • 若允许重复值？唯一支点和三值平衡判定不再直接适用。可用“中位数 ≥ k 的数量 − 中位数 > k 的数量”，将阈值两侧映射为 ±1，按左中位数条件统计正和区间，再用树状数组维护前缀和顺序，时间 O(n log n)。
  • 为什么不能直接滑动窗口？加入或删除元素会让平衡值上下变化，合法性不随端点单调；无法靠单个窗口边界排除全部无效区间。
  • 能返回全部区间吗？把频次换成左端点列表并输出配对，复杂度变为 O(n+答案数)，输出本身可能很大。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int countSubarrays(int[] nums, int k) {
        int p = 0;
        while (nums[p] != k) p++;
        Map<Integer, Integer> freq = new HashMap<>();
        freq.put(0, 1);
        int balance = 0;
        for (int i = p - 1; i >= 0; i--) {
            balance += nums[i] > k ? 1 : -1;
            freq.put(balance, freq.getOrDefault(balance, 0) + 1);
        }
        int answer = 0;
        balance = 0;
        for (int r = p; r < nums.length; r++) {
            balance += Integer.compare(nums[r], k);
            answer += freq.getOrDefault(-balance, 0)
                    + freq.getOrDefault(1 - balance, 0);
        }
        return answer;
    }
}

var countSubarrays = function(nums, k) {
    const p = nums.indexOf(k);
    const freq = new Map([[0, 1]]);
    let balance = 0;
    for (let i = p - 1; i >= 0; i--) {
        balance += nums[i] > k ? 1 : -1;
        freq.set(balance, (freq.get(balance) ?? 0) + 1);
    }
    let answer = 0;
    balance = 0;
    for (let r = p; r < nums.length; r++) {
        balance += Math.sign(nums[r] - k);
        answer += (freq.get(-balance) ?? 0)
                + (freq.get(1 - balance) ?? 0);
    }
    return answer;
};

from typing import List

class Solution:
    def countSubarrays(self, nums: List[int], k: int) -> int:
        p = nums.index(k)
        freq = {0: 1}
        balance = 0
        for i in range(p - 1, -1, -1):
            balance += 1 if nums[i] > k else -1
            freq[balance] = freq.get(balance, 0) + 1
        answer = 0
        balance = 0
        for r in range(p, len(nums)):
            balance += (nums[r] > k) - (nums[r] < k)
            answer += freq.get(-balance, 0) + freq.get(1 - balance, 0)
        return answer

C++

#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int countSubarrays(vector<int>& nums, int k) {
        int p = 0;
        while (nums[p] != k) ++p;
        unordered_map<int, int> freq;
        freq[0] = 1;
        int balance = 0;
        for (int i = p - 1; i >= 0; --i) {
            balance += nums[i] > k ? 1 : -1;
            ++freq[balance];
        }
        auto get = [&](int value) {
            auto it = freq.find(value);
            return it == freq.end() ? 0 : it->second;
        };
        int answer = 0;
        balance = 0;
        for (int r = p; r < static_cast<int>(nums.size()); ++r) {
            balance += (nums[r] > k) - (nums[r] < k);
            answer += get(-balance) + get(1 - balance);
        }
        return answer;
    }
};
