求关注者的数量

Find Followers Count

把一张社交关系表变成一份清晰的用户关注者统计。先理解输入与目标，再通过逐行计数器观察数据如何汇聚；题解默认收起，不会在首屏直接泄露。

Problem

题目描述

给定社交应用中的 Followers 表，每一行表示 follower_id 对应的关注者关注了 user_id 对应的用户。请统计每位出现在表中的用户拥有多少名关注者，并按 user_id 升序返回结果。

表结构与约束

Followers
+-------------+------+
| Column Name | Type |
+-------------+------+
| user_id     | int  |
| follower_id | int  |
+-------------+------+

必须满足

  • (user_id, follower_id) 是联合主键，因此同一关注关系不会重复。
  • 每行都表示关注者 follower_id 关注用户 user_id。
  • 输出列为 user_id 与 followers_count。
  • 结果必须按 user_id 升序排列。

Deep Dive

题解：按用户分组计数

核心洞察

答案的粒度是“每个用户一行”。因此先依据 user_id 把关注关系归为若干组，再统计每组行数。联合主键已保证相同关注关系不会重复，直接计数即可。

完整过程

  1. 扫描 Followers。
  2. 按 user_id 分组。
  3. 对每组执行 COUNT(*)，别名设为 followers_count。
  4. 按 user_id ASC 排序。

官方可提交语言：SQL

SELECT
    user_id,
    COUNT(*) AS followers_count
FROM Followers
GROUP BY user_id
ORDER BY user_id ASC;

    user_id,

SELECT
    user_id,
    COUNT(*) AS followers_count
FROM Followers
GROUP BY user_id
ORDER BY user_id ASC;

正确性说明

  • 分组后，每个 user_id 的所有且仅有关注关系都位于同一组。
  • COUNT(*) 统计该组的全部行；由于联合主键唯一，这正好等于不同关注者的数量。
  • 每组生成一行，所以每位表中出现的用户恰有一条答案；最后排序满足输出顺序要求。

复杂度与边界

复杂度：设表有 n 行。分组聚合通常需要 O(n) 扫描；显式排序最多为 O(u log u)，其中 u 是不同用户数。额外工作空间通常为 O(u)，具体取决于数据库执行计划与索引。

边界：单个用户只有一名关注者；同一用户有多名关注者；输入顺序杂乱；用户编号不连续。空表通常返回空结果。

替代方案

COUNT(follower_id)

本题列未声明可空时可用，但 COUNT(*) 更直接地表达“关系行数”。

COUNT(DISTINCT ...)

若数据可能重复，它能去重；本题联合主键已保证唯一，因此是多余成本。

窗口函数

可为每行附加组计数，但仍需去重才能每位用户只保留一行，不如聚合简洁。

import java.util.*;

public class FollowersCounter {
    public static List<int[]> countFollowers(List<int[]> followers) {
        Map<Integer, Integer> counts = new TreeMap<>();
        for (int[] relation : followers) {
            int userId = relation[0];
            counts.merge(userId, 1, Integer::sum);
        }
        List<int[]> result = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : counts.entrySet()) {
            result.add(new int[]{entry.getKey(), entry.getValue()});
        }
        return result;
    }
}
function countFollowers(followers) {
  const counts = new Map();
  for (const [userId] of followers) {
    counts.set(userId, (counts.get(userId) ?? 0) + 1);
  }
  return [...counts.entries()].sort((a, b) => a[0] - b[0]);
}
from collections import Counter
from typing import List, Tuple

def count_followers(
    followers: List[Tuple[int, int]]
) -> List[Tuple[int, int]]:
    counts = Counter(user_id for user_id, _ in followers)
    return sorted(counts.items())
#include <map>
#include <utility>
#include <vector>

vector<pair<int, int>> countFollowers(
    const vector<pair<int, int>>& followers
) {
    map<int, int> counts;
    for (const auto& [userId, followerId] : followers) {
        (void)followerId;
        ++counts[userId];
    }
    return {counts.begin(), counts.end()};
}

常见错误

  • 按 follower_id 分组，统计成“每人关注了多少用户”。
  • 忘记 ORDER BY user_id，结果顺序不满足题目要求。
  • 选出未聚合列，却没有把它加入分组。
  • 误用 COUNT(user_id) 后忽略可空语义；本题用 COUNT(*) 最清晰。
