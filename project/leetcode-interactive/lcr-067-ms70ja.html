LCR 067 · MEDIUM

数组中两个数的最大异或值

在非负整数数组中选两个数，求它们按位异或的最大可能值。

题意

返回任意两个元素 nums[i] XOR nums[j] 的最大值。异或在某一位不同为 1、相同为 0，高位的 1 对结果更重要。

示例

[3,10,5,25,2,8] → 28
25 XOR 5 = 28

约束

2 ≤ nums.length ≤ 2×10⁴；0 ≤ nums[i] ≤ 2³¹ - 1。

分步交互：前缀贪心

从高位到低位尝试把答案当前位设为 1，并用前缀集合验证。

准备就绪。

核心洞察

从最高位到最低位贪心构造答案。已知前缀时，试探候选 candidate = ans | (1<<bit)；若存在两个前缀异或等于 candidate，则这一位可以保留为 1。

完整过程

  1. 从第 30 位向第 0 位循环。
  2. 把所有数字右移 bit 位，保存为当前前缀集合。
  3. 检查是否有 p 使得 (candidate>>bit) XOR p 也在集合中；有则接受候选。

边界

  • 数字可为 0，仍需纳入前缀集合。
  • 必须从高位开始，低位不能推翻高位最优性。
  • JavaScript 位运算为 32 位有符号，输入范围内应谨慎使用最高符号位。

复杂度

扫描固定的 31 位，每一位遍历数组，时间 O(31n)，空间 O(n)。

替代方案与追问

二进制字典树也能在插入每个数时寻找最优异或搭档，复杂度同为 O(31n)。追问：流式数据适合 Trie；若要求最大异或对本身，可在验证前缀或 Trie 查询时保留来源索引。

常见错误

  • 试探 candidate 后不验证就直接写入答案。
  • 集合保存完整数字却用前缀逻辑查询。
  • 从低位贪心，无法保证最大值。

官方签名代码

// Java
class Solution { public int findMaximumXOR(int[] a){int ans=0;for(int b=30;b>=0;b--){Set<Integer>s=new HashSet<>();for(int x:a)s.add(x>>b);int c=(ans>>b)|1;for(int p:s)if(s.contains(c^p)){ans|=1<<b;break;}}return ans;} }
// JavaScript
var findMaximumXOR = function(nums) { let ans=0; for(let b=30;b>=0;b--){const set=new Set(nums.map(x=>x>>b));const c=(ans>>b)|1;for(const p of set)if(set.has(c^p)){ans|=1<<b;break;}} return ans; };
# Python
class Solution:
    def findMaximumXOR(self, nums: list[int]) -> int:
        ans = 0
        for bit in range(30, -1, -1):
            seen = {x >> bit for x in nums}
            candidate = (ans >> bit) | 1
            if any((candidate ^ x) in seen for x in seen): ans |= 1 << bit
        return ans
// C++
