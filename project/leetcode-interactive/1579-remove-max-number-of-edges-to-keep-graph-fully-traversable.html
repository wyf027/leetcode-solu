共享的边，
要先用。

Alice 与 Bob 在同一张图上拥有不同的通行权限。目标不是直接“删边”，而是用尽可能少的边，为两个人各自搭出一张连通图。

HARD并查集贪心O(m α(n))

Problem

题意

给定一个含 n 个节点的无向图。类型 1 的边仅 Alice 可用，类型 2 仅 Bob 可用，类型 3 两人都可用。删除尽量多的边后，Alice 和 Bob 都必须能从任意节点到达其余所有节点。返回最大可删除边数；若无法同时满足两人，返回 -1。

Solution

核心洞察：最大化“双份连接”

类型 3 的边只占一条，却可能同时让两套并查集的分量数各减一。先建立尽可能大的共享森林，再用专属边分别补齐 Alice 和 Bob；所有无法触发合并的边都在环上，可以删除。

01 · 共享骨架类型 3 若有效，就在两套 DSU 中同步合并。
02 · 各自补齐类型 1 只给 Alice，类型 2 只给 Bob。
03 · 验收计数两者均只剩一个分量，答案为 m − used。

完整过程

  1. 初始化 Alice、Bob 两套含 n 个分量的并查集，used = 0。
  2. 先遍历类型 3。若 Alice 合并成功，则 Bob 同步合并，并把该边计入 used。
  3. 再遍历类型 1 和 2，分别尝试合并对应用户；只有成功合并才计数。
  4. 若两套 DSU 的分量数均为 1，返回 edges.length - used；否则返回 -1。

Why it works

正确性证明

共享边优先是安全的

一条有效的类型 3 边同时减少双方分量。若某可行解用专属边完成其中一个连接，可用共享边替换而不增加保留边数；对另一人只会更有利。因此该贪心不排除最优解。

保留边数最少

共享阶段结束后，把 k 个分量连成一个至少需要 k−1 次合并。DSU 只保留每次成功合并，恰好达到下界；失败的合并均形成环。

结论：算法保留的边最少，所以删除的边最多。最终若任一 DSU 仍有多个分量，则现有边无法让对应用户完全遍历。

Analysis

复杂度、边界与替代方案

复杂度

  • 时间 O(m α(n))
  • 空间 O(n)

边界

  • n = 1 时天然连通。
  • 端点相同、类型不同的边合法。
  • 合并失败的共享边也应删除。
  • 结尾必须同时检查两个人。

替代方案

可先用类型 3 建公共森林，再复制其状态，分别以 Kruskal 思路补齐；逻辑等价但状态复制更繁琐。DFS/BFS 只能验证某个结果是否连通，不能直接最大化删边；枚举边子集则是指数级。

class Solution {
    static class DSU {
        int[] p, size;
        int components;
        DSU(int n) {
            p = new int[n + 1];
            size = new int[n + 1];
            components = n;
            for (int i = 1; i <= n; i++) { p[i] = i; size[i] = 1; }
        }
        int find(int x) {
            if (p[x] != x) p[x] = find(p[x]);
            return p[x];
        }
        boolean union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return false;
            if (size[ra] < size[rb]) { int t = ra; ra = rb; rb = t; }
            p[rb] = ra;
            size[ra] += size[rb];
            components--;
            return true;
        }
    }
    public int maxNumEdgesToRemove(int n, int[][] edges) {
        DSU alice = new DSU(n), bob = new DSU(n);
        int used = 0;
        for (int[] e : edges) {
            if (e[0] == 3 && alice.union(e[1], e[2])) {
                bob.union(e[1], e[2]);
                used++;
            }
        }
        for (int[] e : edges) {
            if (e[0] == 1 && alice.union(e[1], e[2])) used++;
            if (e[0] == 2 && bob.union(e[1], e[2])) used++;
        }
        return alice.components == 1 && bob.components == 1
            ? edges.length - used : -1;
    }
}
var maxNumEdgesToRemove = function(n, edges) {
    class DSU {
        constructor(n) {
            this.p = Array.from({ length: n + 1 }, (_, i) => i);
            this.size = Array(n + 1).fill(1);
            this.components = n;
        }
        find(x) {
            if (this.p[x] !== x) this.p[x] = this.find(this.p[x]);
            return this.p[x];
        }
        union(a, b) {
            let ra = this.find(a), rb = this.find(b);
            if (ra === rb) return false;
            if (this.size[ra] < this.size[rb]) [ra, rb] = [rb, ra];
            this.p[rb] = ra;
            this.size[ra] += this.size[rb];
            this.components--;
            return true;
        }
    }
    const alice = new DSU(n), bob = new DSU(n);
    let used = 0;
    for (const [type, u, v] of edges) {
        if (type === 3 && alice.union(u, v)) {
            bob.union(u, v);
            used++;
        }
    }
    for (const [type, u, v] of edges) {
        if (type === 1 && alice.union(u, v)) used++;
        if (type === 2 && bob.union(u, v)) used++;
    }
    return alice.components === 1 && bob.components === 1
        ? edges.length - used : -1;
};
from typing import List

class DSU:
    def __init__(self, n: int):
        self.p = list(range(n + 1))
        self.size = [1] * (n + 1)
        self.components = n

    def find(self, x: int) -> int:
        if self.p[x] != x:
            self.p[x] = self.find(self.p[x])
        return self.p[x]

    def union(self, a: int, b: int) -> bool:
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.p[rb] = ra
        self.size[ra] += self.size[rb]
        self.components -= 1
        return True

class Solution:
    def maxNumEdgesToRemove(self, n: int, edges: List[List[int]]) -> int:
        alice, bob, used = DSU(n), DSU(n), 0
        for edge_type, u, v in edges:
            if edge_type == 3 and alice.union(u, v):
                bob.union(u, v)
                used += 1
        for edge_type, u, v in edges:
            if edge_type == 1 and alice.union(u, v):
                used += 1
            elif edge_type == 2 and bob.union(u, v):
                used += 1
        return len(edges) - used if (
            alice.components == 1 and bob.components == 1
        ) else -1
class DSU {
    vector<int> p, size;
public:
    int components;
    DSU(int n) : p(n + 1), size(n + 1, 1), components(n) {
        iota(p.begin(), p.end(), 0);
    }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (size[a] < size[b]) swap(a, b);
        p[b] = a;
        size[a] += size[b];
        components--;
        return true;
    }
};
class Solution {
public:
    int maxNumEdgesToRemove(int n, vector<vector<int>>& edges) {
        DSU alice(n), bob(n);
        int used = 0;
        for (const auto& e : edges) {
            if (e[0] == 3 && alice.unite(e[1], e[2])) {
                bob.unite(e[1], e[2]);
                used++;
            }
        }
        for (const auto& e : edges) {
            if (e[0] == 1 && alice.unite(e[1], e[2])) used++;
            if (e[0] == 2 && bob.unite(e[1], e[2])) used++;
        }
        return alice.components == 1 && bob.components == 1
            ? static_cast<int>(edges.size()) - used : -1;
    }
};

Interview notes

面试追问与常见错误

常见错误

  • 按输入顺序处理，让专属边抢先占据连接。
  • 把所有类型 3 都计入保留，未剔除环边。
  • 用一套 DSU 混合两人的权限。
  • 返回成功合并数，而非 m − used。
  • 只检查一人的连通性。

追问

  • 为何不是一套 Kruskal？ 两人的可用边集不同。
  • 扩展到 k 个用户？ 边覆盖用户子集后，简单贪心通常不再最优。
  • 避免递归栈？ 使用迭代 find 与路径压缩。
  • 动态删边？ 普通 DSU 不支持，需要离线回滚或动态连通结构。
