Problem

题目描述

给定商品表 Product 与销售周期表 Sales。对于每条销售记录，period_start 与 period_end 表示一个首尾都包含的连续日期区间，average_daily_sales 是该区间每天的平均销售额。

请按自然年统计每件商品在该年的销售总额，输出 product_id、product_name、report_year 与 total_amount，并按 product_id、report_year 升序排列。

日期年份保证落在 2018—2020。年度销售额 = 该销售期在该年覆盖的天数 × 日均销售额。

Core Insight

核心洞察：求两个闭区间的交集

把每个候选自然年看成闭区间 [year-01-01, year-12-31]。它和销售闭区间的交集起点是两者起点的较晚者，终点是两者终点的较早者。

overlap_start = MAX(period_start, year_start)
overlap_end = MIN(period_end, year_end)
days = DATEDIFF(overlap_end, overlap_start) + 1

只有在 overlap_start ≤ overlap_end 时才产生结果。额外的 +1 来自闭区间：同一天开始并结束也覆盖 1 天。

完整过程

1
构造年份表
题目只涉及 2018、2019、2020，因此创建三个候选年度及其首尾日期。
2
保留相交年份
连接条件为销售开始不晚于年末，并且销售结束不早于年初。
3
截断到年界
用 GREATEST 取交集起点，用 LEAST 取交集终点。
4
计算金额并排序
交集天数乘日均销售额，再按商品编号和年份升序输出。

MySQL 官方提交形式

WITH Calendar AS (
  SELECT 2018 AS report_year,
         DATE('2018-01-01') AS year_start,
         DATE('2018-12-31') AS year_end
  UNION ALL
  SELECT 2019, DATE('2019-01-01'), DATE('2019-12-31')
  UNION ALL
  SELECT 2020, DATE('2020-01-01'), DATE('2020-12-31')
)
SELECT
  s.product_id,
  p.product_name,
  c.report_year,
  (DATEDIFF(
     LEAST(s.period_end, c.year_end),
     GREATEST(s.period_start, c.year_start)
   ) + 1) * s.average_daily_sales AS total_amount
FROM Sales AS s
JOIN Product AS p
  ON p.product_id = s.product_id
JOIN Calendar AS c
  ON s.period_start <= c.year_end
 AND s.period_end >= c.year_start
ORDER BY s.product_id, c.report_year;

正确性证明

引理 1：连接条件恰好筛出与销售期有交集的自然年。两个闭区间相交，当且仅当前者起点不晚于后者终点，且前者终点不早于后者起点。

引理 2：[MAX(两起点), MIN(两终点)] 恰好是销售期与该年的交集。区间内每一天同时属于销售期与该年，区间外至少不属于其中之一。

引理 3：DATEDIFF(end, start) + 1 是闭区间的准确天数，因此乘以恒定的日均销售额就是该商品当年的销售总额。

结论：不同自然年互不重叠，所有被销售期覆盖的日期又必属于其中一个候选年。所以查询既不漏算也不重复计算，输出金额正确。

边界情况

  • 销售期只有一天：结果天数为 1。
  • 开始或结束恰在元旦/除夕：端点都要计入。
  • 销售期完全位于同一年：只生成一行。
  • 经过 2020-02-29：日期函数会自然包含闰日。
  • 跨两年或三年：每个相交年份分别生成一行。

复杂度

设销售记录数为 N，候选年份数为 Y。本题 Y = 3，时间复杂度为 O(NY) = O(N)，结果之外的辅助空间为 O(Y) = O(1)。

替代方案

可以递归生成每一天后再按年份聚合，但会把工作量扩大到销售天数；也可递归生成年份，适合年份范围不固定的通用场景。本题固定三年，常量年份表更直接。

面试追问

  • 年份范围未知怎么办？ 用递归 CTE 从最小开始年份生成到最大结束年份，或连接日历维表。
  • 日销售额会变化怎么办？ 必须把变化点也作为分段边界，不能再用单一 average_daily_sales。
  • 存在重叠销售记录怎么办？ 需先明确业务语义；若不能叠加，应先合并区间或进行去重。
  • 如何优化大表？ 为连接键与日期字段设计合适索引，并优先使用小型日历维表而不是逐日展开。

常见错误

  • 忘记 DATEDIFF + 1，导致每个年度片段少算一天。
  • 直接按 YEAR(period_start) 分组，漏掉后续年份。
  • 使用完整销售期天数计算每个年份，重复计算跨年日期。
  • 没有先判断区间相交，产生负天数或无关年份。
  • 把 report_year 返回为完整日期，或遗漏要求的排序。

import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.*;

class Solution {
  record Product(int id, String name) {}
  record Sale(int productId, LocalDate start, LocalDate end, long daily) {}
  record Row(int productId, String name, int year, long total) {}

  public List<Row> totalSales(List<Product> products, List<Sale> sales) {
    Map<Integer, String> names = new HashMap<>();
    for (Product p : products) names.put(p.id(), p.name());

    List<Row> answer = new ArrayList<>();
    for (Sale sale : sales) {
      for (int year = 2018; year <= 2020; year++) {
        LocalDate yearStart = LocalDate.of(year, 1, 1);
        LocalDate yearEnd = LocalDate.of(year, 12, 31);
        LocalDate left = sale.start().isAfter(yearStart) ? sale.start() : yearStart;
        LocalDate right = sale.end().isBefore(yearEnd) ? sale.end() : yearEnd;
        if (!left.isAfter(right)) {
          long days = ChronoUnit.DAYS.between(left, right) + 1;
          answer.add(new Row(sale.productId(), names.get(sale.productId()),
                             year, days * sale.daily()));
        }
      }
    }
    answer.sort(Comparator.comparingInt(Row::productId).thenComparingInt(Row::year));
    return answer;
  }
}
function totalSales(products, sales) {
  const names = new Map(products.map(p => [p.product_id, p.product_name]));
  const dayMs = 24 * 60 * 60 * 1000;
  const parseUtc = value => new Date(`${value}T00:00:00Z`);
  const result = [];

  for (const sale of sales) {
    const saleStart = parseUtc(sale.period_start);
    const saleEnd = parseUtc(sale.period_end);
    for (let year = 2018; year <= 2020; year++) {
      const yearStart = new Date(Date.UTC(year, 0, 1));
      const yearEnd = new Date(Date.UTC(year, 11, 31));
      const left = new Date(Math.max(saleStart, yearStart));
      const right = new Date(Math.min(saleEnd, yearEnd));
      if (left <= right) {
        const days = Math.round((right - left) / dayMs) + 1;
        result.push({
          product_id: sale.product_id,
          product_name: names.get(sale.product_id),
          report_year: year,
          total_amount: days * sale.average_daily_sales
        });
      }
    }
  }
  return result.sort((a, b) =>
    a.product_id - b.product_id || a.report_year - b.report_year
  );
}

def total_sales(products: Iterable[dict], sales: Iterable[dict]) -> list[dict]:
    names = {p["product_id"]: p["product_name"] for p in products}
    answer = []

            left = max(sale["period_start"], year_start)
            right = min(sale["period_end"], year_end)
            if left <= right:
                days = (right - left).days + 1
                answer.append({
                    "product_id": sale["product_id"],
                    "product_name": names[sale["product_id"]],
                    "report_year": year,
                    "total_amount": days * sale["average_daily_sales"],
                })

    return sorted(answer, key=lambda row: (row["product_id"], row["report_year"]))

struct Product { int id; string name; };
struct Sale { int productId; sys_days start; sys_days end; long long daily; };
struct Row { int productId; string name; int year; long long total; };

vector<Row> totalSales(const vector<Product>& products,
                       const vector<Sale>& sales) {
  map<int, string> names;
  for (const auto& p : products) names[p.id] = p.name;
  vector<Row> answer;

  for (const auto& sale : sales) {
    for (int y = 2018; y <= 2020; ++y) {
      sys_days yearStart = year{y}/January/1;
      sys_days yearEnd = year{y}/December/31;
      sys_days left = max(sale.start, yearStart);
      sys_days right = min(sale.end, yearEnd);
      if (left <= right) {
        long long days = (right - left).count() + 1;
        answer.push_back({sale.productId, names[sale.productId],
                          y, days * sale.daily});
      }
    }
  }
  ranges::sort(answer, {}, [](const Row& row) {
    return pair{row.productId, row.year};
  });
  return answer;
}
