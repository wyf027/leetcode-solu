整数之和

Sum of Numbers With Units Digit K

每一个数，都有相同的末尾。
给定一个总和，最少需要多少个这样的正整数？

先读题、自己思考，再展开底部题解与交互演示。

01 / 题目

给定整数 num 和个位数字 k。你可以选取若干个正整数，要求每个数的个位都是 k，并且它们的总和恰好为 num。求选取数字的最少个数；无法做到时返回 -1。

同一个数可以重复选取，因此这里使用的是多重集。允许不选任何数，空多重集的和为 0。

参数与返回值

minimumNumbers(num, k) → integer
num：目标总和；k：每个数的个位。返回最小个数或 −1。

约束

0 ≤ num ≤ 3000
0 ≤ k ≤ 9

02 / 官方示例

示例 1

输入：num = 58, k = 9
输出：2

可以选 [9, 49] 或 [19, 39]。总和为 58，每个数都以 9 结尾，最少需要 2 个数。

示例 2

输出：-1

只使用个位为 2 的正整数，不能组成总和 37。

示例 3

输入：num = 0, k = 7
输出：0

选择空多重集即可，总和为 0，大小也为 0。

04 / 题解与交互实验

准备好后，再揭开推导过程。

核心洞察：把每个数拆成底座与整十增量

令最小合法正整数 b = (k == 0 ? 10 : k)。所有合法数都可写为 b + 10q，其中 q ≥ 0。注意个位为 0 的最小正整数是 10，不能取 0。

如果选 c 个数，总和就是 c × b + 10Q。因此只需同时满足：

  • c × b ≤ num：有足够总量放下 c 个最小正整数；
  • (num − c × b) % 10 == 0：剩下的部分能拆成整十增量。

满足时，把所有余量加到第一个数上，其他数都取 b，就能直接构造答案。

完整过程

  1. 如果 num = 0，直接返回 0。
  2. 设置 b：k 为 0 时取 10，否则取 k。
  3. 按升序枚举 c = 1 到 10，检查总量条件和整十余量条件。
  4. 第一个满足条件的 c 就是最小个数。全部不满足则返回 −1。

以 num = 58、k = 9 为例：c = 1 时底座和为 9，余量 49 不是 10 的倍数；c = 2 时底座和为 18，余量 40，构造 [49, 9]，所以返回 2。

为什么只枚举到 10？

假设某个可行解有 c > 10 个数。取 c′ = (c − 1) % 10 + 1，则 1 ≤ c′ ≤ 10，且 c − c′ 是 10 的倍数。因此 c′b 与 cb 的个位相同，而 c′b ≤ cb ≤ num。余量仍是非负的 10 的倍数，所以 c′ 也可行。任何大于 10 的可行解，都对应一个不超过 10 的可行解。

正确性证明

  • 必要性：c 个合法正整数各为 b + 10q，其和至少为 cb，且与 cb 模 10 同余。
  • 充分性：若两条件满足，令 R = num − cb。构造 [b + R, b, …, b]，共有 c 项；每项为正数且个位为 k，总和恰为 num。
  • 最小性与完备性：从小到大返回首个可行 c，保证最小；上述缩减证明保证枚举 1 到 10 不会遗漏可能解。num = 0 的空多重集单独处理。

边界与复杂度

num = 0 优先返回 0；k = 0 且 num > 0 时，只有 num 是 10 的倍数才有解，且一个数就够。只满足个位条件可能因底座和过大而失败，例如 num = 1、k = 9。循环最多 10 次，时间 O(1)，额外空间 O(1)；可视化构造不计入提交代码。

替代方案

完全背包：把所有不超过 num、个位为 k 的正整数当作可重复硬币。令 dp[0] = 0，其余为无穷；对总和 s 枚举合法硬币 x，更新 dp[s] = min(dp[s], dp[s − x] + 1)。需要 O(num) 空间和 O(num × M) 时间，M 是合法硬币数量，约 num / 10。它更通用，但本题的十进制结构让常数枚举更直接。

常见错误

  • 把多重集当成不允许重复的集合。
  • 把 0 当成个位为 0 的合法正整数。
  • 只判断模 10 同余，遗漏 cb ≤ num。
  • 从 c = 0 开始处理正的 num，错误返回 0。
  • 只枚举到 9；num = 10、k = 1 必须取 10 个 1。

面试追问

  • 如何返回具体多重集？找到 c 后，取 c − 1 个 b，再取 num − (c − 1)b。
  • 换成 B 进制？把 10 换成 B；k = 0 时底座取 B，枚举 1 到 B，时间 O(B)。
  • 还能缩短枚举范围吗？当 k > 0 时，个位周期是 10 / gcd(k, 10)。固定最多十次已经足够简单。
  • 如果要求互不相同？原构造不再适用；最小底座和变为 cb + 10c(c − 1)/2，需重新分析可行个数。

Java

class Solution {
    public int minimumNumbers(int num, int k) {
        if (num == 0) return 0;
        int base = k == 0 ? 10 : k;
        for (int count = 1; count <= 10; count++) {
            int rest = num - count * base;
            if (rest >= 0 && rest % 10 == 0) return count;
        }
        return -1;
    }
}
