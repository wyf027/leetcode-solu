Primary Department for Each Employee

员工的直属部门

从员工—部门关系表中，为每位员工找出唯一应该汇报的部门。先理解规则，再通过交互演示观察每组记录如何产生答案。

本题训练

把“显式标记”与“仅有一个候选”的兜底规则合并成一次筛选。

01 / 题意

先读清数据规则

Employee 表的一行表示“某位员工属于某个部门”。同一员工可能出现多行。

Employee 表

列名类型含义
employee_idint员工 ID
department_idint员工所属部门 ID
primary_flagvarchar / ENUMY 表示直属部门，N 表示非直属

复合主键：(employee_id, department_id)，因此同一员工与同一部门的组合不会重复。

输出任务

为每位员工返回 employee_id 和他的直属 department_id，结果顺序不限。

特殊规则：如果员工只属于一个部门，即使该行的 primary_flag = 'N'，这个唯一部门也应被输出。

约束与保证

  • primary_flag 只能取 'Y' 或 'N'。
  • 员工可属于一个或多个部门；多部门员工通过 'Y' 指定直属部门。
  • 官方元数据未给出额外的数值范围；以上为题面提供的完整结构约束。

完整输入与输出

题解区

准备好看答案了吗？

先用上方分拣台形成自己的条件表达式，再展开完整思路、证明、代码与追问。

核心洞察

答案是两类行的并集

一类是明确标为 Y 的行；另一类是其员工在整张表中只出现一次的行。把这两个条件用 OR 连接即可。

官方提交主解：MySQL

SELECT employee_id, department_id
FROM Employee
WHERE primary_flag = 'Y'
   OR employee_id IN (
     SELECT employee_id
     FROM Employee
     GROUP BY employee_id
     HAVING COUNT(*) = 1
   );
04 / 完整过程

从业务规则翻译成筛选条件

识别显式直属部门

多部门员工已经用 primary_flag = 'Y' 标出直属部门，直接保留这些行。

找出单部门员工

按 employee_id 分组，使用 HAVING COUNT(*) = 1 找到只出现一次的员工。

合并两种合法来源

外层查询保留“标记为 Y”或“员工属于单部门集合”的记录，并只投影题目要求的两列。

05 / 正确性

为什么不会漏，也不会多？

完备性：任取一位员工。若他只属于一个部门，分组计数为 1，唯一行被第二个条件选中；若他属于多个部门，题意保证直属部门用 Y 标记，该行被第一个条件选中。因此每位员工的直属部门都会出现。
可靠性：任取一条被选中的行。它要么带 Y，按定义就是直属部门；要么其员工只有这一条部门记录，按特殊规则唯一部门就是直属部门。因此输出不会包含非直属部门。
唯一性：单部门员工只有一行；多部门员工的直属部门由 Y 唯一指定。复合主键又排除了员工—部门重复行，所以每位员工恰好得到一个结果。

复杂度

时间：概念上需扫描并按员工聚合，记记录数为 n，哈希聚合平均为 O(n)；数据库实际计划与索引、统计信息有关。

空间：聚合需要保存不同员工的计数，记员工数为 u，概念上 O(u)；数据库引擎可能使用内存或临时存储。

边界情况

  • 所有员工都只属于一个部门，所有标志都可能是 N。
  • 某员工属于多个部门，只有 Y 所在行可输出。
  • 结果无需排序，不应依赖数据库默认返回顺序。
  • 不要把单部门员工的 N 错当成无效数据。
06 / 替代方案

窗口函数：把计数贴回每一行

先用窗口函数计算每位员工的记录数，再筛选 Y 或计数为 1。表达直观，也便于继续使用行级其他列。

SELECT employee_id, department_id
FROM (
  SELECT employee_id,
         department_id,
         primary_flag,
         COUNT(*) OVER (PARTITION BY employee_id) AS dept_count
  FROM Employee
) ranked
WHERE primary_flag = 'Y' OR dept_count = 1;

四种本地语义实现

本题是数据库题，LeetCode 官方提交语言是 SQL / Pandas。下面 Java、JavaScript、Python、C++ 代码用于在内存数组上复现同一筛选语义，不能直接替代本站 SQL 提交。

本地语义参考 · 输入行结构为 employeeId / departmentId / primaryFlag
import java.util.*;

public class PrimaryDepartment {
  record Row(int employeeId, int departmentId, char primaryFlag) {}
  record Result(int employeeId, int departmentId) {}

  public static List<Result> findPrimaryDepartment(List<Row> employee) {
    Map<Integer, Integer> counts = new HashMap<>();
    for (Row row : employee) {
      counts.merge(row.employeeId(), 1, Integer::sum);
    }

    List<Result> answer = new ArrayList<>();
    for (Row row : employee) {
      if (row.primaryFlag() == 'Y' || counts.get(row.employeeId()) == 1) {
        answer.add(new Result(row.employeeId(), row.departmentId()));
      }
    }
    return answer;
  }
}
/**
 * @param {{employeeId:number, departmentId:number, primaryFlag:'Y'|'N'}[]} employee
 * @return {{employeeId:number, departmentId:number}[]}
 */
function findPrimaryDepartment(employee) {
  const counts = new Map();
  for (const row of employee) {
    counts.set(row.employeeId, (counts.get(row.employeeId) ?? 0) + 1);
  }

  return employee
    .filter((row) =>
      row.primaryFlag === 'Y' || counts.get(row.employeeId) === 1
    )
    .map(({ employeeId, departmentId }) => ({ employeeId, departmentId }));
}
from collections import Counter
from dataclasses import dataclass

@dataclass(frozen=True)
class Row:
    employee_id: int
    department_id: int
    primary_flag: str

def find_primary_department(employee: list[Row]) -> list[tuple[int, int]]:
    counts = Counter(row.employee_id for row in employee)
    return [
        (row.employee_id, row.department_id)
        for row in employee
        if row.primary_flag == "Y" or counts[row.employee_id] == 1
    ]
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

struct Row {
  int employeeId;
  int departmentId;
  char primaryFlag;
};

vector<pair<int, int>> findPrimaryDepartment(const vector<Row>& employee) {
  unordered_map<int, int> counts;
  for (const Row& row : employee) {
    ++counts[row.employeeId];
  }

  vector<pair<int, int>> answer;
  for (const Row& row : employee) {
    if (row.primaryFlag == 'Y' || counts[row.employeeId] == 1) {
      answer.emplace_back(row.employeeId, row.departmentId);
    }
  }
  return answer;
}

面试追问

  • 能用 UNION 吗？可以分别查询 Y 行与单部门行后用 UNION ALL；两类按合法数据互斥，但单条 OR 查询更紧凑。
  • 为什么不是 WHERE COUNT(*) = 1？聚合后的组条件要放在 HAVING；普通 WHERE 发生在分组之前。
  • 索引怎么考虑？以 employee_id 开头的索引有助于分组/关联；实际收益需结合执行计划与数据分布判断。
  • 数据不保证唯一 Y 呢？这变成数据质量规则，需要定义冲突处理策略，不能由本题查询擅自决定。

常见错误

  • 只写 primary_flag = 'Y'，漏掉只有一条 N 的员工。
  • 把“部门数为 1”误写成全表只有一行，没有按 employee_id 分组。
  • 在子查询中返回两列，却用单列 IN 比较。
  • 额外输出 primary_flag，不符合结果列契约。
  • 为了排序增加无要求的 ORDER BY，并误以为输出顺序具有语义。
