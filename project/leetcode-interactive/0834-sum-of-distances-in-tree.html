树中距离之和Sum of Distances in Tree

同一棵树，换一个观察点，所有距离都会改变。先别急着看答案：在实验台里亲手移动“根”，观察信息如何沿一条边传播。

困难树深度优先搜索图树形 DP
函数契约
sumOfDistancesInTree(n, edges) → integer[]

输入保证是一棵有效树。输出第 i 项表示节点 i 到其余全部节点的距离总和。

01 / Problem

先把任务说清楚

题意

给定一棵无向连通树，它有 n 个节点，编号为 0 到 n - 1，以及恰好 n - 1 条边。

数组 edges 中的每一项 [aᵢ, bᵢ] 表示节点 aᵢ 与 bᵢ 直接相连。树上两点间的距离，是连接它们的唯一路径所包含的边数。

返回：长度为 n 的数组 answer，其中 answer[i] = Σ distance(i, j)，求和范围为所有节点 j。

参数与约束

  • 1 ≤ n ≤ 3 × 10⁴
  • edges.length = n - 1
  • edges[i].length = 2
  • 0 ≤ aᵢ, bᵢ < n
  • aᵢ ≠ bᵢ
  • 输入保证构成一棵有效树

05 / Solution

换根动态规划：两次线性扫描

任选节点 0 作为临时根。第一遍从叶到根聚合子树信息，第二遍从根到叶把答案换到每个相邻节点。

核心洞察

若把根从父节点 p 移到它的子节点 u，u 子树中的 size[u] 个节点都近 1；其余 n - size[u] 个节点都远 1。

answer[u] = answer[p] - size[u] + (n - size[u])

所以只要先知道任意一个根的答案与所有子树大小，就能沿每条边 O(1) 推出新答案。

状态定义

  • parent[u]：临时根为 0 时，节点 u 的父节点。
  • size[u]：以 u 为根的子树节点数。
  • answer[u]：最终的全树距离和；第一遍中先用它累计子树内部距离。
  • order：从根展开得到的顺序；反向遍历等价于后序，正向遍历等价于先序。

完整过程

  1. 用邻接表保存无向树，从 0 出发构造 parent 与 order。
  2. 反向遍历 order。对子节点 u：令 size[p] += size[u]，并令 answer[p] += answer[u] + size[u]。
  3. 此时 answer[0] 已是节点 0 到所有节点的距离和。
  4. 再按正向 order 遍历每个非根节点，使用换根公式求 answer[u]。

正确性证明

  1. 子树聚合正确。 对叶节点，子树大小为 1、内部距离和为 0。若各孩子状态正确，那么孩子子树中的每个节点到父节点都比到孩子多 1，故增加 answer[child] + size[child]，归纳得根节点状态正确。
  2. 换根转移正确。 从父节点移到子节点后，子树内每个节点距离减少 1，共减 size[u]；子树外每个节点距离增加 1，共加 n - size[u]，公式成立。
  3. 覆盖全部答案。 树中根到任意节点路径唯一。第二遍按父子边传播，每个非根节点恰好由其父节点计算一次，因此所有 answer 都正确。

边界与复杂度

  • 单节点：order = [0]，两遍都无需转移，返回 [0]。
  • 链与星形树：状态转移不依赖树的形状。
  • 深树：代码采用显式遍历顺序，避免递归栈过深。
  • 时间复杂度：O(n)，每个节点和每条边只处理常数次。
  • 空间复杂度：O(n)，用于邻接表和状态数组。

替代方案

  • 每个起点各做一次 BFS/DFS：直观但需 O(n²)，在 n = 3 × 10⁴ 时不可接受。
  • 全源最短路：树上没有必要使用 Floyd–Warshall，O(n³) 更差。
  • 递归两遍 DFS：思路相同且代码短，但某些语言在链状树上可能栈溢出；可提高递归限制或改用迭代。

Java · 迭代遍历
import java.util.*;

class Solution {
    public int[] sumOfDistancesInTree(int n, int[][] edges) {
        List<Integer>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : edges) {
            graph[edge[0]].add(edge[1]);
            graph[edge[1]].add(edge[0]);
        }

        int[] parent = new int[n];
        Arrays.fill(parent, -2);
        parent[0] = -1;
        int[] order = new int[n];
        int orderSize = 1;
        order[0] = 0;

        for (int i = 0; i < orderSize; i++) {
            int node = order[i];
            for (int next : graph[node]) {
                if (next == parent[node]) continue;
                parent[next] = node;
                order[orderSize++] = next;
            }
        }

        int[] size = new int[n];
        int[] answer = new int[n];
        Arrays.fill(size, 1);

        for (int i = n - 1; i > 0; i--) {
            int node = order[i];
            int p = parent[node];
            size[p] += size[node];
            answer[p] += answer[node] + size[node];
        }

        for (int i = 1; i < n; i++) {
            int node = order[i];
            int p = parent[node];
            answer[node] = answer[p] - size[node] + (n - size[node]);
        }
        return answer;
    }
}

/**
 * @param {number} n
 * @param {number[][]} edges

var sumOfDistancesInTree = function(n, edges) {
    const graph = Array.from({ length: n }, () => []);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
    }

    const parent = new Array(n).fill(-2);
    parent[0] = -1;
    const order = [0];

    for (let i = 0; i < order.length; i++) {
        const node = order[i];
        for (const next of graph[node]) {
            if (next === parent[node]) continue;
            parent[next] = node;
            order.push(next);
        }
    }

    const size = new Array(n).fill(1);
    const answer = new Array(n).fill(0);

    for (let i = n - 1; i > 0; i--) {
        const node = order[i];
        const p = parent[node];
        size[p] += size[node];
        answer[p] += answer[node] + size[node];
    }

    for (let i = 1; i < n; i++) {
        const node = order[i];
        const p = parent[node];
        answer[node] = answer[p] - size[node] + (n - size[node]);
    }
    return answer;
};
Python · 迭代遍历
from typing import List


class Solution:
    def sumOfDistancesInTree(
        self, n: int, edges: List[List[int]]
    ) -> List[int]:
        graph = [[] for _ in range(n)]
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)

        parent = [-2] * n
        parent[0] = -1
        order = [0]

        for node in order:
            for nxt in graph[node]:
                if nxt == parent[node]:
                    continue
                parent[nxt] = node
                order.append(nxt)

        size = [1] * n
        answer = [0] * n

        for node in reversed(order[1:]):
            p = parent[node]
            size[p] += size[node]
            answer[p] += answer[node] + size[node]

        for node in order[1:]:
            p = parent[node]
            answer[node] = answer[p] - size[node] + (n - size[node])

        return answer

面试追问

  • 如果边带权，聚合公式与换根公式如何改变？
  • 为什么任意选择根节点都不影响最终答案？
  • 如何同时求每个节点到其他节点的距离平方和？

常见错误

  • 换根时把子树外节点数误写成 n - 1。
  • 忘记无向边的父节点过滤，导致重复访问。
  • 第一遍只累计子树大小，却漏掉孩子已有的距离和。

记忆锚点

先收后放。先让每棵子树把“人数与内部距离”交给根，再把根的全局答案沿边广播。跨过一条边，一边整体近 1，另一边整体远 1。
