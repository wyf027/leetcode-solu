三个有序数组的交集

Intersection of Three Sorted Arrays

简单 付费题 数组 · 哈希表 · 二分查找 · 计数
Problem

题目描述

给定三个严格递增排列的整数数组 arr1、arr2 和 arr3，返回一个升序列表，其中只包含同时出现在三个数组中的整数。

返回值：List<Integer> arraysIntersection(int[] arr1, int[] arr2, int[] arr3)；结果保持递增顺序。
示例 1
输入：arr1 = [1,2,3,4,5],
      arr2 = [1,2,5,7,9],
      arr3 = [1,3,4,5,8]
输出：[1,5]
解释：1 和 5 同时存在于三个数组中。
示例 2
输入：arr1 = [197,418,523,876,1356],
      arr2 = [501,880,1593,1710,1870],
      arr3 = [521,682,1337,1395,1764]
输出：[]

约束

  • 1 <= arr1.length, arr2.length, arr3.length <= 1000
  • 1 <= arr1[i], arr2[i], arr3[i] <= 2000
  • 三个数组中的元素都严格递增，因此每个数组内部没有重复值。

Solution

题解：三指针同步追赶

核心洞察

数组严格递增。若三个当前值不相等，那么小于当前最大值的元素不可能再与另外两个当前值匹配；它可以被安全跳过。三个值相等时，该值属于交集，记录后同时移动三个指针。

完整过程

  1. 令 i = j = k = 0，结果列表为空。
  2. 只要三个指针都未越界，就读取 arr1[i]、arr2[j]、arr3[k]。
  3. 若三者相等，加入结果并让三个指针都加一。
  4. 否则求当前最大值，让所有小于它的指针各前进一步。
  5. 任意数组耗尽后结束，返回结果。

正确性证明

不遗漏：当某个当前值 x 小于三者最大值 M 时，其他对应数组从当前位置起都不会再出现小于自身当前值的元素；而 x < M，所以 x 不可能同时出现在三个剩余区间中，跳过是安全的。

不误收：算法只在三个当前值完全相等时加入结果，因此每个加入值必然存在于三个数组。结合严格递增性，结果没有重复且保持升序。

边界情况

  • 三个数组只有一个元素：相等则返回该元素，否则返回空列表。
  • 完全无交集：某个指针先到末尾，结果为空。
  • 交集位于首项或末项：统一由相同的比较规则处理。
  • 长度差距很大：每个指针只前进，不会回退或越界访问。

复杂度

设三数组长度分别为 m、n、p。每个指针最多走完整个数组，时间复杂度为 O(m + n + p)；除返回结果外，额外空间复杂度为 O(1)。

替代方案

  • 哈希计数：统计每个数出现于多少个数组，计数为 3 时加入结果。思路直观，但需要额外空间，并需避免数组内重复时重复计数；本题严格递增可简化这一点。
  • 两次双数组求交：先求 arr1 与 arr2 的交集，再与 arr3 求交。仍是线性时间，但会产生中间列表。
  • 二分查找：遍历最短数组，在另外两个数组中二分查找。复杂度约为 O(s(log m + log n))，当数组长度极不均衡时可能有吸引力。

面试追问

  • 如果数组不是严格递增、允许重复，结果应保留重复次数还是去重？如何调整指针移动？
  • 如果有 K 个有序数组，如何把“追赶当前最大值”推广为 K 指针？
  • 如果数组以流式数据到达且不能全部放入内存，算法需要保留哪些状态？
  • 长度高度不均衡时，何时二分查找可能优于同时线性扫描？

常见错误

  • 三者不相等时只移动最小值的一个指针，忘记多个指针可能同为较小值；这样虽可能仍正确，但会做多余轮次。
  • 用 while (i < m || j < n || k < p)，导致某一数组结束后仍访问越界；这里必须使用逻辑与。
  • 找到相等值后只移动一个指针，从而停留在同一结果或造成死循环。
  • 为了“对齐”而回退指针，破坏单调前进的不变量。

四语言完整代码

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> arraysIntersection(
            int[] arr1, int[] arr2, int[] arr3) {
        List<Integer> answer = new ArrayList<>();
        int i = 0, j = 0, k = 0;

        while (i < arr1.length &&
               j < arr2.length &&
               k < arr3.length) {
            int a = arr1[i];
            int b = arr2[j];
            int c = arr3[k];

            if (a == b && b == c) {
                answer.add(a);
                i++;
                j++;
                k++;
            } else {
                int maxValue = Math.max(a, Math.max(b, c));
                if (a < maxValue) i++;
                if (b < maxValue) j++;
                if (c < maxValue) k++;
            }
        }
        return answer;
    }
}
