Count Positions on Street With Required Brightness

路灯的光照彼此重叠，每一格街道却有自己的亮度门槛。哪些位置足够明亮？先理解规则，再展开下方的交互题解。

The brief

题意与输入

街道由 0 … n − 1 共 n 个整数位置组成。lights[j] = [positionⱼ, rangeⱼ] 表示一盏灯的位置与照射半径；它为闭区间 [max(0, positionⱼ − rangeⱼ), min(n − 1, positionⱼ + rangeⱼ)] 内的每个位置增加 1 单位亮度。

一个位置的亮度就是覆盖它的灯的数量。requirement[i] 是位置 i 的最低亮度要求。返回亮度大于或等于对应要求的位置数量。这里只统计整数位置，不计算连续街道长度。

函数：meetRequirement(n, lights, requirement) → integer。相同位置的多盏灯分别贡献亮度。

官方示例 1

n = 5
lights = [[0,1],[2,1],[3,2]]
requirement = [0,2,1,4,1]
输出：4

各点亮度为 [1,3,2,2,1]；位置 0、1、2、4 满足要求，位置 3 的亮度 2 小于要求 4。

官方示例 2

n = 1
lights = [[0,1]]
requirement = [2]
输出：0

光照被裁剪到唯一的位置 0，亮度只有 1，达不到要求 2。

约束

  • 1 ≤ n ≤ 10⁵，1 ≤ lights.length ≤ 10⁵。
  • 每个 lights[j] 由位置与半径两个整数构成；0 ≤ positionⱼ < n，0 ≤ rangeⱼ ≤ 10⁵。
  • requirement.length = n，0 ≤ requirement[i] ≤ 10⁵。

把整段照明，化成两个边界事件

核心洞察：一盏灯对连续区间的贡献始终是 1，只有进入区间和离开区间时发生变化。用差分数组记录 diff[L] += 1、diff[R + 1] -= 1，随后从左到右累加，就能恢复每格亮度。

完整过程

  1. 令 m = lights.length，创建长度 n + 1 的零数组。
  2. 每盏灯先裁剪左右端点：L = max(0, p − r)，R = min(n − 1, p + r)。
  3. 在 L 加 1，在 R + 1 减 1。右端点 R 仍然被照亮，所以不能在 R 提前撤销。
  4. 令当前亮度和答案为 0。遍历 i = 0 … n − 1，先累加 diff[i]，再判断 brightness ≥ requirement[i]，成立则答案加 1。

示例 1 的三段是 [0,1]、[1,3]、[1,4]，最终差分含哨兵为 [1,2,-1,0,-1,-1]。只扫描前 5 项，恢复 [1,3,2,2,1]。位置 3 亮度保持 2，说明“差分为 0”不等于“亮度为 0”。

正确性

对任意一盏覆盖 [L,R] 的灯，差分前缀和在 i < L 时为 0，在 L ≤ i ≤ R 时为 1，在 i ≥ R + 1 时为 0，恰好等于它在位置 i 的照明贡献。

加法满足可叠加性，因此所有灯的差分前缀和等于所有覆盖灯的数量，即真实亮度。扫描时每个合法位置恰好比较一次；只在亮度不低于要求时计数，最终答案正是所求数量。

复杂度与边界

每盏灯只写两个事件，每个街道位置只扫描一次。时间 O(m + n)，额外空间 O(n)。

  • n = 1、半径为 0：闭区间仍有一个点。
  • 照射越界：先裁剪到街道边缘。
  • 要求为 0：即使亮度为 0 也达标。
  • 同位置多灯：分别累计，不能去重。
  • R = n − 1：减法写入哨兵 n；不比较 requirement[n]。

替代方案

逐灯逐格增加亮度直观，但最坏时间 O(mn)，不适合两个规模均为 10⁵ 的数据。也可对边界事件排序后扫描，时间 O(m log m + n)；本题位置连续且需要访问每个要求，数组方案更直接。

只有在加入动态增删灯与单点查询时，才考虑对差分使用树状数组：区间更新和单点亮度查询均可 O(log n)。动态维护“所有位置达标总数”需要额外结构，普通树状数组无法直接回答。

面试追问与常见错误

  • 灯有权重 w？把 +1 / −1 换成 +w / −w，并根据权重上界选择足够大的数值类型。
  • 为何无需排序？每个事件直接定位数组下标；扫描天然按位置顺序进行。
  • 为何不是 O(m)？还必须处理 n 个位置的要求。
  • 把撤销位置写成 R，会漏算右端点。
  • 将 ≥ 写成 >，会漏掉恰好满足的位置。
  • 未先累加就比较，会错用前一个位置的亮度。
  • 把结果当作灯数、亮度和或连续区间长度，都会偏离题意。

Java

class Solution {
    public int meetRequirement(int n, int[][] lights, int[] requirement) {
        int[] diff = new int[n + 1];
        for (int[] light : lights) {
            int left = Math.max(0, light[0] - light[1]);
            int right = Math.min(n - 1, light[0] + light[1]);
            diff[left]++;
            diff[right + 1]--;
        }
        int brightness = 0, answer = 0;
        for (int i = 0; i < n; i++) {
            brightness += diff[i];
            if (brightness >= requirement[i]) answer++;
        }
        return answer;
    }
}

from typing import List

class Solution:
    def meetRequirement(self, n: int, lights: List[List[int]],
                        requirement: List[int]) -> int:
        diff = [0] * (n + 1)
        for position, radius in lights:
            left = max(0, position - radius)
            right = min(n - 1, position + radius)
            diff[left] += 1
            diff[right + 1] -= 1
        brightness = answer = 0
        for i in range(n):
            brightness += diff[i]
            if brightness >= requirement[i]:
                answer += 1
        return answer

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int meetRequirement(int n, vector<vector<int>>& lights,
                        vector<int>& requirement) {
        vector<int> diff(n + 1, 0);
        for (const auto& light : lights) {
            int left = max(0, light[0] - light[1]);
            int right = min(n - 1, light[0] + light[1]);
            ++diff[left];
            --diff[right + 1];
        }
        int brightness = 0, answer = 0;
        for (int i = 0; i < n; ++i) {
            brightness += diff[i];
            if (brightness >= requirement[i]) ++answer;
        }
        return answer;
    }
};
