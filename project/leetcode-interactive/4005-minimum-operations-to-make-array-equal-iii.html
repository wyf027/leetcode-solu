使数组中所有元素相等的最小操作数 III

给定整数数组 nums。一次操作可把 nums[i] 乘以任意整数 k ≥ 2，或在 2 ≤ k < nums[i] 且可整除时除以 k。返回使所有元素相等的最少操作数。

可核验的单元素代价

  1. x = target：0 次。
  2. x | target：一次乘法可到达（target ≠ x）。
  3. target | x 且 target > 1：一次除法可到达。
  4. 其余情况：交互判定器用两步构造上界；例如 8 → 2 → 6。
1 的特例：除法的 k 必须小于当前数，故不能把大于 1 的数直接除到 1。判定器已单独处理。
