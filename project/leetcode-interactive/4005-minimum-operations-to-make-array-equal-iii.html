使数组中所有元素相等的最小操作数 III

把“能否一步到达”翻译为整除关系：对每个候选目标，统计它的倍数与因数出现了多少次，再从“全都两步”的基线中扣回收益。

精确待补：快速生成模式：UI、算法对拍、四语言编译和交互验收待补。题意实验室与四语言解法已同步修复，完整 UI 回归由后续批次统一补齐。

题意

给定正整数数组 nums。一次操作可任选一个元素：乘以任意 k ≥ 2，或在可整除且 2 ≤ k < 当前值 时除以 k。求把所有元素变成同一正整数的最少操作数。

范围：1 ≤ nums.length ≤ 10^5，1 ≤ nums[i] ≤ 10^9。

示例

nums = [6, 12, 8] → 3。选 6：12 / 2 = 6 用 1 步；8 / 4 = 2、2 × 3 = 6 用 2 步。

nums = [5, 15, 20] → 2；nums = [7, 7, 7] → 0。

可见实验室：比较候选目标

实验室会显式加入最小公倍数目标；正式算法不计算 LCM。

准备就绪。
目标 总操作 逐元素代价

完整过程

1
基线是 n。取所有数的最小公倍数作目标，每个元素都能乘一次到达，所以答案不超过 n。
2
只看数组内目标 t。x = t 省 2 步；x | t 或 t | x（目标不是 1）省 1 步。化简后 score(t) = countDivisors(t) + countMultiples(t)。
3
枚举每个不同值的全部因数。用频次表累加“谁整除当前数”，再查询当前数的因数频次；最大收益从 2n 的两步基线扣除。

边界与常见错误

  • 目标 1 特殊：不能直接 x / x，除数必须严格小于当前值。
  • 不能只枚举数组中的目标：[6,10,15] 选 30 每项只需 1 步。
  • 所以 n（LCM 目标）必须作为独立候选。

复杂度与替代方案

设不同值数为 U、枚举到的因数总数为 D。直接因数枚举为 O(U√A + D)，空间 O(U + D)。

小数据可枚举所有目标并逐项判断，但不能省略 LCM 候选。

题解（默认收起）

把两步基线变成“最大收益”

若目标不在数组内，取公共倍数便能让每个元素一乘到达，代价为 n。目标是出现过的 t > 1 时，相等元素各省两步，其他能整除比较的元素各省一步；收益恰化简为 因数频次和 + 倍数频次和。t = 1 仅相等元素能获两步收益。

面试追问：LCM 不会溢出吗？不用算，只用其存在性给出 n 上界。为什么两张统计？一个值既可能是别人的因数，也可能拥有数组中的因数。 

var minOperations = function(nums) {
  const f = new Map(); for (const x of nums) f.set(x, (f.get(x) || 0) + 1);
  const ds = x => { const a=[]; for(let d=1;d*d<=x;d++) if(x%d===0){a.push(d);if(d*d!==x)a.push(x/d)} return a };
  const mul = new Map(); for (const [x,c] of f) for (const d of ds(x)) mul.set(d,(mul.get(d)||0)+c);
  let best=0; for (const [t,c] of f) { let div=0; for(const d of ds(t)) div+=f.get(d)||0; best=Math.max(best,t===1?2*c:div+(mul.get(t)||0)); }
  return Math.min(nums.length, 2*nums.length-best);
};
from collections import Counter
class Solution:
 def minOperations(self, nums: list[int]) -> int:
  f=Counter(nums)
  def ds(x):
   a=[]; d=1
   while d*d<=x:
    if x%d==0: a.append(d); a.extend([] if d*d==x else [x//d])
    d+=1
   return a
  mul=Counter()
  for x,c in f.items():
   for d in ds(x): mul[d]+=c
  best=max((2*c if t==1 else sum(f[d] for d in ds(t))+mul[t]) for t,c in f.items())
  return min(len(nums),2*len(nums)-best)
