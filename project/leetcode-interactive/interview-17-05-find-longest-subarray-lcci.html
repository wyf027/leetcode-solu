Interview solution

题解

O(n)

核心洞察

把数字记为 +1、字母记为 −1。若两个前缀位置的累计差值相同，它们之间的增量和为 0，因此字母数与数字数相同。

完整过程

  1. 令差值 balance = 0，并记录差值 0 最早出现在前缀位置 0。
  2. 从左到右更新差值；首次出现的差值只记录，不覆盖。
  3. 若差值出现过，从其最早位置到当前前缀位置就是平衡区间。
  4. 只在长度严格更大时更新答案，自然保留左端点最小的同长答案。

边界与复杂度

  • 空数组或全为同类元素时返回空数组。
  • 初始化 first[0] = 0 才能识别从下标 0 开始的答案。
  • 时间复杂度 O(n)，哈希表与返回切片占 O(n) 空间。

替代方案取舍

  • 枚举区间：O(n²)，只适合小规模对拍。
  • 前缀差数组双循环：仍是 O(n²)，没有利用重复差值。
  • 哈希表最早位置：一次扫描，面试最推荐。

面试追问

  • 若要字母数是数字数的两倍，如何重定义权重？
  • 若元素分三类且要求三类数量相同，哈希键如何设计？
  • 若只需返回长度，空间与代码能否进一步简化？

常见错误

  • 覆盖某个差值的最早位置，导致区间变短。
  • 用 >= 更新答案，破坏“同长取左”。
  • 混淆数组下标和前缀位置，出现一位偏差。
  • 漏掉初始差值 0，无法找到从首元素开始的平衡区间。
class Solution {
    public String[] findLongestSubarray(String[] array) {
        Map<Integer, Integer> first = new HashMap<>();
        first.put(0, 0);
        int balance = 0;
        int bestStart = 0;
        int bestLength = 0;

        for (int i = 0; i < array.length; i++) {
            balance += Character.isDigit(array[i].charAt(0)) ? 1 : -1;
            int prefix = i + 1;
            if (!first.containsKey(balance)) {
                first.put(balance, prefix);
            } else {
                int start = first.get(balance);
                int length = prefix - start;
                if (length > bestLength) {
                    bestStart = start;
                    bestLength = length;
                }
            }
        }

        return Arrays.copyOfRange(array, bestStart, bestStart + bestLength);
    }
}
var findLongestSubarray = function (array) {
    const first = new Map([[0, 0]]);
    let balance = 0;
    let bestStart = 0;
    let bestLength = 0;

    for (let i = 0; i < array.length; i++) {
        const code = array[i].charCodeAt(0);
        balance += code >= 48 && code <= 57 ? 1 : -1;
        const prefix = i + 1;
        if (!first.has(balance)) {
            first.set(balance, prefix);
        } else {
            const start = first.get(balance);
            const length = prefix - start;
            if (length > bestLength) {
                bestStart = start;
                bestLength = length;
            }
        }
    }

    return array.slice(bestStart, bestStart + bestLength);
};
class Solution:
    def findLongestSubarray(self, array: List[str]) -> List[str]:
        first = {0: 0}
        balance = 0
        best_start = 0
        best_length = 0

        for i, token in enumerate(array):
            balance += 1 if token[0].isdigit() else -1
            prefix = i + 1
            if balance not in first:
                first[balance] = prefix
            else:
                start = first[balance]
                length = prefix - start
                if length > best_length:
                    best_start = start
                    best_length = length

        return array[best_start : best_start + best_length]
