按公因数计算
最大组件大小

Largest Component Size by Common Factor

题目

给定由互不相同正整数组成的数组 nums。每个数是一个节点；当两个数拥有大于 1 的公因数时，在它们之间连无向边。返回图中节点数最多的连通组件大小。两个数没有直接公共因数时，仍可能通过其他数字间接连通。

签名
largestComponentSize(nums: integer[]) → integer

约束

  • 1 ≤ nums.length ≤ 2 × 10⁴
  • 1 ≤ nums[i] ≤ 10⁵
  • 所有 nums[i] 互不相同

官方示例

输入：nums = [4,6,15,35]
输出：4

输入：nums = [20,50,9,63]
输出：2
输入：nums = [2,3,6,7,4,12,21,39]
输出：8

题解：质因数作为连接枢纽

核心洞察

两个数共享大于 1 的因数，当且仅当它们共享至少一个质因数。逐一分解数字，用哈希表记录每个质因数第一次出现的数组下标；再次遇到它时，用并查集合并两个下标。

完整过程

  1. 每个数组下标初始化为独立集合。
  2. 试除分解每个数，只处理不同质因数。
  3. 质因数首次出现则登记，否则连接到其代表下标。
  4. 按并查集根统计节点数量并取最大值。

正确性

充分性：每次合并的两数共享质因数，因此题图中有边，并查集不会错误连接。必要性：题图每条边的两端必共享某个质因数，处理该因数时必被合并；沿路径应用可知同一图组件最终同根。故两种组件完全一致，最大集合大小就是答案。

边界

  • [1] 没有质因数，但自身组件大小为 1。
  • 同一质因数的幂只处理一次。
  • 试除结束后剩余值大于 1 时，它本身是质因数。

复杂度

设 M=max(nums)。试除版本时间为 O(n√M+nα(n))，空间为 O(n+k)，k 是实际出现的不同质因数数。

替代方案

最小质因数筛可预处理后快速分解；数字—质因数二分图更直观但更重。枚举所有数对求 gcd 为 O(n² log M)，不可行。

面试追问

  • 允许重复值时如何把频次计入组件？
  • 如何用 SPF 筛改进分解？
  • 为什么每个质因数只保存一个代表就够？

常见错误

  • 忽略间接连通。
  • 漏掉最后一个大质因数。
  • 重复处理质因数幂。
  • 未路径压缩或按大小合并。

  void union(int a,int b){ a=find(a); b=find(b); if(a==b)return; if(s[a]<s[b]){int t=a;a=b;b=t;} p[b]=a;s[a]+=s[b]; }
  public int largestComponentSize(int[] nums){
    int n=nums.length; p=new int[n]; s=new int[n];
    for(int i=0;i<n;i++){p[i]=i;s[i]=1;}
    java.util.Map<Integer,Integer> own=new java.util.HashMap<>();
    for(int i=0;i<n;i++){int x=nums[i]; for(int q=2;q*q<=x;q++) if(x%q==0){if(own.containsKey(q))union(i,own.get(q));else own.put(q,i);while(x%q==0)x/=q;} if(x>1){if(own.containsKey(x))union(i,own.get(x));else own.put(x,i);}}
    int ans=1; for(int v:s)ans=Math.max(ans,v); return ans;
  }
}

class Solution:
    def largestComponentSize(self, nums: List[int]) -> int:
        n=len(nums); parent=list(range(n)); size=[1]*n; owner={}
        def find(x):
            while parent[x]!=x:
                parent[x]=parent[parent[x]]; x=parent[x]
            return x
        def union(a,b):
            a,b=find(a),find(b)
            if a==b: return
            if size[a]<size[b]: a,b=b,a
            parent[b]=a; size[a]+=size[b]
        for i,v in enumerate(nums):
            x=v; q=2
            while q*q<=x:
                if x%q==0:

                    while x%q==0: x//=q
                q+=1
