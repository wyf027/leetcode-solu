LEETCODE 1598文件夹操作
日志搜集器

从主文件夹出发，依次执行一串进入子文件夹、返回父文件夹或原地停留的日志。全部执行完后，求回到主文件夹至少还需要多少次操作。

Problem brief

题意与规则

函数形式：minOperations(logs: string[]): number。文件系统初始位于主文件夹。

三类日志

../
移动到父文件夹；若已经在主文件夹，则仍停留在主文件夹。
./
保持当前位置不变。
x/
进入名为 x 的子文件夹；该子文件夹保证存在。

官方示例

示例 1
输入：logs = ["d1/","d2/","../","d21/","./"] 输出：2 解释：再执行两次 "../" 即可回到主文件夹。
示例 2
输入：logs = ["d1/","d2/","./","d3/","../","d31/"] 输出：3
示例 3
输入：logs = ["d1/","../","../","../"] 输出：0

返回目标

执行完 logs 的全部操作后，返回从当前位置回到主文件夹所需的最少操作次数。

注意：多余的 "../" 不会让位置移动到主文件夹之外。

约束

  • 1 ≤ logs.length ≤ 10³
  • 2 ≤ logs[i].length ≤ 10
  • logs[i] 只含小写字母、数字、. 和 /
  • 每条日志都符合题目描述的格式
  • 文件夹名称由小写英文字母和数字组成

Solution

只记录“深度”就够了

文件夹的具体名称不会影响答案；最终只需要知道当前位置距离主文件夹有几层。

核心洞察

用整数 depth 表示当前层级。进入子文件夹时加一，原地停留时不变，返回父文件夹时在大于零的前提下减一。全部日志结束后，depth 就是答案。

子文件夹 x/depth + 1
当前目录 ./depth 不变
父目录 ../max(0, depth - 1)

完整过程

  1. 初始化 depth = 0，表示位于主文件夹。
  2. 从左到右遍历每条日志。
  3. 遇到 "../"：只有 depth > 0 时才减一。
  4. 遇到 "./"：什么也不做。
  5. 否则日志一定是合法的子文件夹名，令 depth++。
  6. 遍历结束，返回 depth。

示例 1 跟踪

0 → 1 → 2 → 1 → 2 → 2，所以还需要两次返回父文件夹操作。

正确性证明

循环不变式：处理完前 i 条日志后，depth 始终等于当前文件夹到主文件夹的路径边数。

初始化：未处理日志时位于主文件夹，路径边数与 depth 都是 0。

保持：进入子文件夹会新增一条边；"./" 不改变路径；"../" 在非根位置删去一条边，在根位置保持 0。三种更新都与真实移动一致。

终止：全部日志处理后，不变式表明 depth 是当前位置到主文件夹的边数。每次 "../" 至多跨一条边，因此恰好需要 depth 次，且不可能更少。

边界与复杂度

  • 开头或中途在主文件夹遇到任意多个 "../"，深度都保持 0。
  • 全部是 "./" 时答案为 0。
  • 全部进入子文件夹时，答案等于 logs.length。
  • 文件夹名可能含数字；只需区分两个特殊字符串，无需解析名称。
时间复杂度O(n)每条日志处理一次
空间复杂度O(1)只维护一个整数

替代方案、面试追问与常见错误

替代方案：显式栈

也可以用栈保存沿途的文件夹名：进入时入栈，返回时出栈，最后返回栈长。它同样正确，但需要 O(n) 额外空间，而本题不要求恢复完整路径，因此整数深度更精炼。

面试追问

  • 若要输出最终绝对路径？ 此时必须保留文件夹名，可改用栈。
  • 若日志允许连续路径如 a/b/？ 需先按分隔符解析各段，再逐段规范化。
  • 若输入以流的形式到达？ 深度方案天然支持在线处理，只需常数内存。

常见错误

  • 在深度为 0 时仍对 "../" 执行减一，产生负数。
  • 把 "./" 当作普通文件夹，错误地增加深度。
  • 用字符串前缀判断特殊操作；直接比较完整字符串更清晰可靠。
  • 维护完整路径却没有输出路径的需求，徒增空间和实现复杂度。
Implementations

四种语言完整实现

均采用同一个常数空间的深度模拟思路，签名与官方提交形式一致。

JavaJAVA
class Solution {
    public int minOperations(String[] logs) {
        int depth = 0;

        for (String log : logs) {
            if (log.equals("../")) {
                if (depth > 0) {
                    depth--;
                }
            } else if (!log.equals("./")) {
                depth++;
            }
        }

        return depth;
    }
}
