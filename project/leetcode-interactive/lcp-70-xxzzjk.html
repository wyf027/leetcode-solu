沙地治理

用最少的初始沙柳，把三角形沙地按“两个绿色邻居会传播”的规则全部变成绿地。

题意

第 i 行有 2i - 1 个单位小三角形。先任选一些位置种植沙柳（初始绿地）；任一沙地若与至少两片绿地共边，就会转化为绿地，并继续影响邻居。返回一组数量最少的初始坐标。

示例：size = 3

可返回 [[1,1],[2,1],[2,3],[3,1],[3,5]]。中间沙地先由两侧种子触发，再继续向下传播。

坐标采用 [row, column]，行和列均从 1 开始。

约束

1 <= size <= 1000；答案长度为 Θ(size²)，输出本身就是复杂度下界。

构造实验台

选择小尺寸，逐轮观察固定的 4 行周期种子如何传播。

题解区

首屏默认收起：展开后查看证明要点与四语言提交代码。

核心洞察：前 n−1 行每隔 4 格，最后一行用 8 格周期补边

构造把每个非末行的 1, 5, 9, ... 位置设为种子。最后一行必须照顾两条边，再按偏移 4, 7, 9 (mod 8) 放置。该图案恰好给每个待转化三角形留下两条可用的绿色传播边。

为什么是最少

每个初始种子有 3 条边可用于传播；一个后续转化三角形需要先消耗 2 条绿色边，只能把至多 1 条新边继续传给未来。结合整张三角形网格的内部边/外边计数，可得初始种子数下界为 floor((n² + 3n + 2) / 4)。上述构造恰好达到它，故为最优。

复杂度、边界与替代方案

时间与额外空间均为 O(k)（k 是输出坐标数），不能更低，因为必须写出答案。size = 1 只返回 [1,1]；末行的右端点只在 size > 1 时加入。暴力模拟/搜索只能验证小规模，不适合 size = 1000 的最优构造。

面试追问与常见错误

追问：如何证明下界？回答应从“后续传播净贡献至多一条边”开始进行边计数。常见错误：把末行也按 4 周期处理而漏掉边界；忘记 size=1 不应重复加入右端点；用 BFS 找“任意可行解”却无法保证最少。 

import java.util.*;
class Solution {
  public int[][] sandyLandManagement(int size) {
    List<int[]> ans = new ArrayList<>();
    for (int r = 1; r < size; r++)
      for (int c = 1; c <= 2 * r - 1; c += 4) ans.add(new int[]{r, c});
    ans.add(new int[]{size, 1});
    if (size > 1) ans.add(new int[]{size, 2 * size - 1});
    for (int c = 4; c < 2 * size - 1; c += 8) ans.add(new int[]{size, c});
    for (int c = 7; c < 2 * size - 1; c += 8) ans.add(new int[]{size, c});
    for (int c = 9; c < 2 * size - 1; c += 8) ans.add(new int[]{size, c});
    return ans.toArray(new int[ans.size()][]);
  }
}
