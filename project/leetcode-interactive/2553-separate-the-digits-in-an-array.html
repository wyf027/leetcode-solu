分割数组中数字的数位

Separate the Digits in an Array

给定一个正整数数组 nums，依次拆出每个整数的所有数位，并保持“数组中数字的顺序”和“数字内部的数位顺序”都不变，返回拼接后的数组 answer。

例：整数 10921 的数位依次是 [1,0,9,2,1]。任务只要求分开数位，不排序、不去重。

Problem

示例与约束

函数：separateDigits(nums)

示例 1

输入：nums = [13,25,83,77]
输出：[1,3,2,5,8,3,7,7]
解释：13、25、83、77 分别拆成
[1,3]、[2,5]、[8,3]、[7,7]，

输入：nums = [7,1,3,9]
输出：[7,1,3,9]
解释：每个整数都只有一位，

  • 1 <= nums[i] <= 105

先自己思考：怎样保证两个层级的顺序都不改变？

Answer

完整题解

核心洞察

十进制整数转成字符串后，字符顺序天然就是从最高位到最低位的顺序。按数组顺序遍历每个整数，再按字符串顺序遍历每个字符并转回数字，依次追加到答案即可。

完整过程

  1. 创建空数组 answer。
  2. 从左到右访问 nums 中的每个整数。
  3. 把当前整数转成十进制字符串。
  4. 从左到右读取每个字符，转为对应数位后追加到 answer。
  5. 返回 answer。

正确性说明

数字内部：一个正整数的十进制字符串从左到右恰好排列其从最高位到最低位的全部数位，因此内部顺序正确且没有遗漏。

数字之间：外层遍历按 nums 的下标递增进行，当前数字的全部数位追加完成后才处理下一个数字，因此不同整数的结果顺序也与输入一致。

所以最终数组正是所有整数数位按题意顺序连接而成的结果。

边界情况

  • 单个一位数：答案只有一个元素。
  • 全部是一位数：输出与输入相同。
  • 数字内部含 0：例如 100 必须保留两个 0。
  • 最大值 100000：产生 6 个数位。

复杂度

设所有整数的数位总数为 D。

  • 时间复杂度：O(D)
  • 结果之外的额外空间：字符串方案为 O(L)，其中 L 是单个整数的最大位数；返回数组为 O(D)

四语言完整代码

JavaLeetCode
class Solution {
    public int[] separateDigits(int[] nums) {
        int size = 0;
        for (int num : nums) {
            size += String.valueOf(num).length();
        }

        int[] answer = new int[size];
        int index = 0;
        for (int num : nums) {
            for (char digit : String.valueOf(num).toCharArray()) {
                answer[index++] = digit - '0';
            }
        }
        return answer;
    }
}
JavaScriptLeetCode
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var separateDigits = function(nums) {
    const answer = [];
    for (const num of nums) {
        for (const digit of String(num)) {
            answer.push(Number(digit));
        }
    }
    return answer;
};
Python 3LeetCode
from typing import List


class Solution:
    def separateDigits(self, nums: List[int]) -> List[int]:
        answer = []
        for num in nums:
            answer.extend(int(digit) for digit in str(num))
        return answer

class Solution {
public:
    vector<int> separateDigits(vector<int>& nums) {
        vector<int> answer;
        for (int num : nums) {
            for (char digit : to_string(num)) {
                answer.push_back(digit - '0');
            }
        }
        return answer;
    }

替代方案

也可以纯数学拆位：先找到不大于当前数的最大 10 的幂，再逐位整除并取余。这样不需要字符串，但代码更长，且要谨慎保留数字中间或末尾的 0。本题约束下，字符串方案更直接。

常见错误

  • 用连续取模得到逆序数位，却忘记反转。
  • 把字符直接放进答案，得到字符编码而非数字。
  • 对数位排序，破坏原有顺序。
  • 数学拆位时丢掉 100 中的 0。
