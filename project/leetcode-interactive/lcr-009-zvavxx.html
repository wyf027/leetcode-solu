乘积小于 K 的子数组

正整数数组中，计算乘积严格小于 k 的连续子数组数量。窗口右端每前进一步，所有新增合法子数组都以它结尾。

题意

给定正整数数组 nums 和整数 k，返回乘积小于 k 的连续子数组数目。1 ≤ nums.length ≤ 3 × 10⁴，且所有 nums[i] 为正整数。

nums = [10, 5, 2, 6], k = 100
答案 = 8
新增窗口
right 固定时新增 right - left + 1 个

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

交互实验室：滑动窗口计数

每次扩展右端；若乘积不再小于 k，就不断收缩左端。观察本轮新增的结尾子数组数量。

载入示例后按右端点逐步计数。

    核心洞察

    由于数组元素全为正数，扩大窗口只会使乘积不减，收缩窗口只会使乘积不增。维护一个乘积小于 k 的最小左边界后，以 right 结尾的合法子数组恰有 right - left + 1 个。

    过程与复杂度

    1. 令 left=0、product=1、answer=0。
    2. 右端加入一个数并更新 product。
    3. 只要 product ≥ k，移走左端并右移 left。
    4. 窗口合法后，answer 加上窗口长度。

    时间 O(n)，额外空间 O(1)。

    可提交代码

    var numSubarrayProductLessThanK = function(nums, k) {
  if (k <= 1) return 0;
  let left = 0, product = 1, answer = 0;
  for (let right = 0; right < nums.length; right++) {
    product *= nums[right];
    while (product >= k) product /= nums[left++];
    answer += right - left + 1;
  }
  return answer;
};
    class Solution:
    def numSubarrayProductLessThanK(self, nums: List[int], k: int) -> int:
        if k <= 1: return 0
        left = answer = 0; product = 1
        for right, value in enumerate(nums):
            product *= value
            while product >= k: product //= nums[left]; left += 1
            answer += right - left + 1
        return answer

    验证要点

    • k ≤ 1 时答案必为 0。
    • 单元素窗口是否被正确计入。
    • 多次收缩后再计数。
    • 全部元素都可构成合法窗口。
