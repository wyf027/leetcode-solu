字母大小写全排列

同一串字符，字母拥有两种形态，数字保持原样。你的任务是收集所有可能的字符串，输出顺序不限。

中等字符串回溯位运算非付费题

Problem

题目描述

给定字符串 s。可以独立地把其中每个英文字母变成小写或大写；数字不发生变化。返回由这些选择产生的全部字符串，答案可以按任意顺序排列。

官方示例

示例 1
输入：s = "a1b2"
输出：["a1b2", "a1B2", "A1b2", "A1B2"]

示例 2
输入：s = "3z4"
输出：["3z4", "3Z4"]

约束

  • 1 <= s.length <= 12
  • s 仅由大小写英文字母和数字组成。
  • 返回类型：List<String>。

Solution

回溯：让每个字母做一次二选一

核心洞察

扫描字符串时，数字只有“原样加入”这一条路；字母有“小写加入”和“大写加入”两条路。所有选择自然构成一棵决策树，抵达末尾的每条根到叶路径都是一个答案。

完整过程

  1. 维护字符数组 path 与位置 index。
  2. 若到达末尾，把当前路径加入答案。
  3. 若当前字符是数字，加入它并递归下一位。
  4. 若是字母，分别用小写和大写递归；返回后撤销本层字符。

正确性说明

对位置做归纳。处理第 i 位前，路径集合恰好包含前 i 位的全部合法形式。数字分支保留唯一合法形式；字母分支加入且仅加入两种合法大小写。因此处理后仍不重不漏。归纳至 n，得到全部合法字符串。

复杂度

设字母数为 k、字符串长度为 n。共有 2^k 个答案，每次复制长度为 n 的字符串，时间为 O(n · 2^k)；不计返回结果时，递归栈和路径空间为 O(n)。

边界情况

  • 全是数字：答案只有原字符串。
  • 只有一个字母：恰好两个答案。
  • 输入本来是大写：仍要产生其小写与大写形式。
  • 长度为 12 且全是字母：共有 4096 个答案。

常见错误

  • 只切换小写字母，漏掉原输入中的大写字母。
  • 把数字也建立两个相同分支，制造重复答案。
  • 复用可变路径却忘记回溯撤销。
  • 把 ASCII 位运算直接用于非字母字符。

替代方案

可从 [""] 开始迭代扩展候选集合；也可为 k 个字母枚举 0..2^k-1 的位掩码。两者复杂度同阶，迭代法避免递归，位掩码便于讨论状态编码。

面试追问

  • 如果只需要第 m 个答案，怎样按位直接构造？
  • 如何改为惰性迭代器，避免一次保存全部结果？
  • 若允许 Unicode 字母，ASCII 判定和大小写映射需要怎样改变？

class Solution {
    public List<String> letterCasePermutation(String s) {
        List<String> answer = new ArrayList<>();
        backtrack(s.toCharArray(), 0, answer);
        return answer;
    }

    private void backtrack(char[] chars, int index, List<String> answer) {
        if (index == chars.length) {
            answer.add(new String(chars));
            return;
        }
        if (Character.isDigit(chars[index])) {
            backtrack(chars, index + 1, answer);
            return;
        }
        chars[index] = Character.toLowerCase(chars[index]);
        backtrack(chars, index + 1, answer);
        chars[index] = Character.toUpperCase(chars[index]);
        backtrack(chars, index + 1, answer);
    }
}

var letterCasePermutation = function(s) {
    const answer = [];
    const chars = s.split('');

    function backtrack(index) {
        if (index === chars.length) {
            answer.push(chars.join(''));
            return;
        }
        if (/\d/.test(chars[index])) {
            backtrack(index + 1);
            return;
        }
        chars[index] = chars[index].toLowerCase();
        backtrack(index + 1);
        chars[index] = chars[index].toUpperCase();
        backtrack(index + 1);
    }

    backtrack(0);
    return answer;
};
from typing import List


class Solution:
    def letterCasePermutation(self, s: str) -> List[str]:
        answer: List[str] = []
        path: List[str] = []

        def backtrack(index: int) -> None:
            if index == len(s):
                answer.append("".join(path))
                return

            char = s[index]
            if char.isdigit():
                path.append(char)
                backtrack(index + 1)
                path.pop()
                return

            path.append(char.lower())
            backtrack(index + 1)
            path.pop()

            path.append(char.upper())
            backtrack(index + 1)
            path.pop()

        backtrack(0)
        return answer
class Solution {
public:
    vector<string> letterCasePermutation(string s) {
        vector<string> answer;
        backtrack(s, 0, answer);
        return answer;
    }

private:
    void backtrack(string& s, int index, vector<string>& answer) {
        if (index == static_cast<int>(s.size())) {
            answer.push_back(s);
            return;
        }
        unsigned char current = static_cast<unsigned char>(s[index]);
        if (isdigit(current)) {
            backtrack(s, index + 1, answer);
            return;
        }
        s[index] = static_cast<char>(tolower(current));
        backtrack(s, index + 1, answer);
        s[index] = static_cast<char>(toupper(current));
        backtrack(s, index + 1, answer);
    }
};
