题意

给定字符串 s，统计其中有多少个子字符串只由同一个字符组成。答案可能很大，返回它对 109 + 7 取余后的结果。

同质字符串
字符串里的所有字符完全相同，例如 "c"、"cc" 和 "ccc"。
子字符串
必须是原字符串中连续的一段；相同文本出现在不同位置时，需要分别计数。

Full solution

一次扫描：新字符贡献当前连续长度

核心洞察

处理到位置 i 时，只统计以 s[i] 结尾的新同质子字符串。若当前相同字符连续了 run 次，那么这些新子串的长度恰好是 1..run，数量就是 run。

完整过程

  1. 令 run = 0、answer = 0，从左到右扫描字符串。
  2. 若当前字符与前一个字符相同，令 run += 1；否则开始新的连续段，令 run = 1。
  3. 把 run 加进答案，并及时对 10⁹ + 7 取余。
  4. 扫描结束后返回答案。

为什么正确？

无遗漏：任一同质子字符串都有唯一的右端点。扫描到该右端点时，它一定包含在长度 1..run 的后缀中。

不重复：每个子字符串只在其右端点被计数一次；不同右端点的子字符串互不相同。

因此，每步新增 run 个，累加后恰好得到全部同质子字符串数量。

时间O(n)
每个字符一次
空间O(1)
常数个变量

四语言完整代码

class Solution {
    public int countHomogenous(String s) {
        final long MOD = 1_000_000_007L;
        long answer = 0;
        long run = 0;

        for (int i = 0; i < s.length(); i++) {
            if (i > 0 && s.charAt(i) == s.charAt(i - 1)) {
                run++;
            } else {
                run = 1;
            }
            answer = (answer + run) % MOD;
        }

        return (int) answer;
    }
}

边界与常见错误

  • 长度为 1：答案就是 1。
  • 全相同字符：长度为 n 的连续段贡献 n(n+1)/2。
  • 全不相同字符：每步 run = 1，答案为 n。
  • 不要把“相同字符”误当成“连续的相同字符”。
  • Java / C++ 的中间量应使用 64 位整数；不要等所有计算结束后才考虑溢出。

替代方案：按段求和

也可以先把字符串分成若干个最大同字符连续段。长度为 k 的一段贡献 k(k+1)/2，将所有段的贡献相加。

它和逐字符做法复杂度相同，但要在段结束时结算；逐字符写法通常更自然，也更不容易漏掉最后一段。

面试追问

Q：为什么每一步加的是 run，而不是整个三角数？
A：之前的短后缀已经在各自的右端点计数过；当前只需加入以当前字符为右端点的 run 个新子串。
Q：能用公式一次结算整段吗？
A：可以。长度为 k 的连续段共有 1 + 2 + … + k = k(k+1)/2 个同质子字符串。
Q：如果字符不只限于小写字母呢？
A：算法只依赖相邻字符是否相等，因此对任意可比较的字符序列都成立。
