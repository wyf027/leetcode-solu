LeetCode 1158 / Market Analysis I

市场分析 I

把全年订单穿过一个“2019 检票口”，再把每位买家的计数安全地贴回完整用户名册。

Medium 数据库 免费题

Problem brief

题目转述

给定用户、订单和商品三张表。请为每一位用户返回其用户编号、注册日期，以及该用户在 2019 年作为买家产生的订单数。结果可按任意顺序返回。

约束与输出要求

  • Users.user_id、Orders.order_id、Items.item_id 分别具有唯一值。
  • Orders.item_id 引用 Items；buyer_id 与 seller_id 引用 Users。
  • 必须保留所有用户，包括 2019 年没有下单的用户；他们的 orders_in_2019 应为 0。
  • 2019 年按日期区间 [2019-01-01, 2020-01-01) 判断，返回顺序不限。
  • 官方元数据未另外给出表行数范围；本页不虚构数值约束。

    Complete solution

    从完整名册出发

    最稳定的思路是先把 2019 年订单按买家聚合，再用 Users 做左表连接计数结果。

    核心洞察

    • 输出域由 Users 决定。“每个用户”意味着结果行集合必须从 Users 开始，而不是从订单开始。
    • 先筛年份，再聚合。只统计半开日期区间 [2019-01-01, 2020-01-01)，按 buyer_id 分组计数。
    • 缺失计数不是缺失用户。左连接后没有匹配聚合行时得到 NULL，用 COALESCE(..., 0) 转为零。

    为什么使用日期范围？

    相比 YEAR(order_date) = 2019，范围谓词通常更利于数据库利用日期索引；而且上下界清晰，不混入 2020 年。

    完整过程

    1. 扫描 Orders 中日期大于等于 2019-01-01 且小于 2020-01-01 的订单。
    2. 按 buyer_id 分组，用 COUNT(*) 得到每位活跃买家的年度订单数。
    3. 以 Users 为左表，按 user_id = buyer_id 左连接年度聚合表。
    4. 输出用户编号、注册日期，并把未匹配到的计数从 NULL 转为 0。

    正确性说明

    引理 1：年度聚合子查询对每个在 2019 年下过单的买家恰好生成一行，其计数恰好等于该买家 2019 年订单数。因为筛选条件排除了其他年份，分组把相同 buyer_id 的所有保留订单归入同一组，而 COUNT(*) 逐行计数。

    引理 2：左连接使每个用户恰好保留一行。Users.user_id 唯一；年度聚合结果中每个 buyer_id 也至多一行，因此连接不会复制用户。没有年度订单的用户仍被左连接保留。

    结论：有 2019 年订单的用户取得引理 1 的准确计数；没有的用户匹配值为 NULL 并被转为 0。因此输出对每位用户都给出正确注册日期和 2019 年买家订单数。

    边界情况

    • 用户从未下单：计数为 0。
    • 用户只在其他年份下单：计数为 0。
    • 订单恰好在 2019-01-01：计入。
    • 订单恰好在 2020-01-01：不计入。
    • 同一买家在 2019 年多单：全部计入。

    复杂度

    • 逻辑工作量：扫描用户与订单，约为 O(U + O)。
    • 聚合中间结果至多含 U 个买家，空间约为 O(U)。
    • 实际执行代价取决于优化器、索引与连接算法。

    替代方案

    • 直接左连接订单后用条件聚合 SUM(CASE ...)。
    • 对每个用户使用相关子查询计数，表达直观但大表上可能重复扫描。
    • 可用 YEAR(order_date) 筛选，但可能降低普通日期索引的利用率。

    常见错误

    • 从 Orders 出发，漏掉零订单用户。
    • 把年份条件写进外层 WHERE，意外把左连接变成内连接效果。
    • 忘记 COALESCE，输出 NULL 而非 0。
    • 按卖家 seller_id 统计，或不必要地连接 Items。

    面试追问

    如果要统计每个年份呢？

    先生成用户与年份的目标组合，再把订单按买家和年份聚合后左连接；或使用支持的日期维表。

    如何让日期索引更好用？

    避免在索引列上套函数，使用明确的起止日期范围，并考虑与 buyer_id 组合的索引是否符合业务查询。

    条件写在 ON 和 WHERE 有何区别？

    对左连接而言，写在 ON 中限制右表匹配；写在外层 WHERE 中常会剔除右表为空的行。

    Items 表为什么可以不使用？

    目标只依赖用户、注册日期、订单日期与买家编号；商品品牌不参与筛选、分组或输出。

    MySQL · 官方可提交主解：预聚合 + LEFT JOIN 
    SELECT
    u.user_id AS buyer_id,
    u.join_date,
    COALESCE(y.orders_in_2019, 0) AS orders_in_2019
FROM Users AS u
LEFT JOIN (
    SELECT
        buyer_id,
        COUNT(*) AS orders_in_2019
    FROM Orders
    WHERE order_date >= '2019-01-01'
      AND order_date <  '2020-01-01'
    GROUP BY buyer_id
) AS y
    ON y.buyer_id = u.user_id;
    Java · 本地语义参考非 LeetCode 本题提交语言 
    import java.time.LocalDate;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class MarketAnalysis {
    static final class User {
        final int userId;
        final LocalDate joinDate;
        final String favoriteBrand;

        User(int userId, String joinDate, String favoriteBrand) {
            this.userId = userId;
            this.joinDate = LocalDate.parse(joinDate);
            this.favoriteBrand = favoriteBrand;
        }
    }

    static final class Order {
        final int orderId;
        final LocalDate orderDate;
        final int itemId;
        final int buyerId;
        final int sellerId;

        Order(int orderId, String orderDate, int itemId, int buyerId, int sellerId) {
            this.orderId = orderId;
            this.orderDate = LocalDate.parse(orderDate);
            this.itemId = itemId;
            this.buyerId = buyerId;
            this.sellerId = sellerId;
        }
    }

    static final class Result {
        final int buyerId;
        final LocalDate joinDate;
        final long ordersIn2019;

        Result(int buyerId, LocalDate joinDate, long ordersIn2019) {
            this.buyerId = buyerId;
            this.joinDate = joinDate;
            this.ordersIn2019 = ordersIn2019;
        }

        @Override
        public String toString() {
            return buyerId + " | " + joinDate + " | " + ordersIn2019;
        }
    }

    static List<Result> marketAnalysis(List<User> users, List<Order> orders) {
        LocalDate start = LocalDate.of(2019, 1, 1);
        LocalDate end = LocalDate.of(2020, 1, 1);
        Map<Integer, Long> counts = new HashMap<>();

        for (Order order : orders) {
            boolean in2019 = !order.orderDate.isBefore(start)
                    && order.orderDate.isBefore(end);
            if (in2019) {
                counts.merge(order.buyerId, 1L, Long::sum);
            }
        }

        List<Result> result = new ArrayList<>();
        for (User user : users) {
            result.add(new Result(
                    user.userId,
                    user.joinDate,
                    counts.getOrDefault(user.userId, 0L)
            ));
        }
        return result;
    }
}
    JavaScript · 本地语义参考非 LeetCode 本题提交语言 
    /**
 * @param {Array<{user_id:number, join_date:string, favorite_brand:string}>} users
 * @param {Array<{order_id:number, order_date:string, item_id:number,
 *                buyer_id:number, seller_id:number}>} orders
 * @returns {Array<{buyer_id:number, join_date:string, orders_in_2019:number}>}
 */
function marketAnalysis(users, orders) {
  const start = "2019-01-01";
  const end = "2020-01-01";
  const counts = new Map();

  for (const order of orders) {
    if (order.order_date >= start && order.order_date < end) {
      const previous = counts.get(order.buyer_id) ?? 0;
      counts.set(order.buyer_id, previous + 1);
    }
  }

  return users.map((user) => ({
    buyer_id: user.user_id,
    join_date: user.join_date,
    orders_in_2019: counts.get(user.user_id) ?? 0,
  }));
}

// 本地使用：marketAnalysis(users, orders)
if (typeof module !== "undefined") {
  module.exports = { marketAnalysis };
}
    Python · 本地语义参考列表版；官方另支持 Pandas 
    from collections import Counter
from dataclasses import dataclass
from datetime import date
from typing import Iterable, List


@dataclass(frozen=True)
class User:
    user_id: int
    join_date: date
    favorite_brand: str


@dataclass(frozen=True)
class Order:
    order_id: int
    order_date: date
    item_id: int
    buyer_id: int
    seller_id: int


@dataclass(frozen=True)
class Result:
    buyer_id: int
    join_date: date
    orders_in_2019: int


def market_analysis(users: Iterable[User], orders: Iterable[Order]) -> List[Result]:
    start = date(2019, 1, 1)
    end = date(2020, 1, 1)
    counts = Counter(
        order.buyer_id
        for order in orders
        if start <= order.order_date < end
    )

    return [
        Result(
            buyer_id=user.user_id,
            join_date=user.join_date,
            orders_in_2019=counts[user.user_id],
        )
        for user in users
    ]
    C++ · 本地语义参考ISO 日期字符串保持字典序 
    #include <string>
#include <unordered_map>
#include <vector>

struct User {
    int userId;
    std::string joinDate;
    std::string favoriteBrand;
};

struct Order {
    int orderId;
    std::string orderDate;
    int itemId;
    int buyerId;
    int sellerId;
};

struct Result {
    int buyerId;
    std::string joinDate;
    int ordersIn2019;
};

std::vector<Result> marketAnalysis(
    const std::vector<User>& users,
    const std::vector<Order>& orders
) {
    const std::string start = "2019-01-01";
    const std::string end = "2020-01-01";
    std::unordered_map<int, int> counts;

    for (const Order& order : orders) {
        if (order.orderDate >= start && order.orderDate < end) {
            ++counts[order.buyerId];
        }
    }

    std::vector<Result> result;
    result.reserve(users.size());
    for (const User& user : users) {
        auto it = counts.find(user.userId);
        int count = it == counts.end() ? 0 : it->second;
        result.push_back({user.userId, user.joinDate, count});
    }
    return result;
}
