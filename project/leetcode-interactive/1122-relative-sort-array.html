数组的相对排序

Relative Sort Array · 计数桶交互讲解

数组哈希表计数排序排序

题目

给定整数数组 arr1 和 arr2。arr2 的值互不相同且均出现在 arr1 中。重排 arr1：其中出现在 arr2 的元素按 arr2 的先后次序排列；其余元素按升序置于末尾。

示例 1
输入：arr1 = [2,3,1,3,2,4,6,7,9,2,19]
      arr2 = [2,1,4,3,9,6]
输出：[2,2,2,1,4,3,3,9,6,7,19]
示例 2
输入：arr1 = [28,6,22,8,44,17]
      arr2 = [22,28,8,6]
输出：[22,28,8,6,17,44]

函数形式

relativeSortArray(arr1: integer[], arr2: integer[]): integer[]

约束

  • 1 ≤ arr1.length, arr2.length ≤ 1000
  • 0 ≤ arr1[i], arr2[i] ≤ 1000
  • arr2 中元素互不相同。
  • 每个 arr2[i] 都在 arr1 中。

交互：计数桶出队

先统计频次，按 arr2 清空指定桶，再从小到大清空剩余桶。

先自己想一想

如果已知每个数出现多少次，怎样一次性输出某个 arr2[i] 的全部副本？剩余值怎样自然保持升序？

题解

核心洞察

数值范围只有 0～1000，用 count[x] 记录频次。先依次展开 arr2 对应频次并清零，再递增扫描整个值域，展开剩余频次。

完整过程

  1. 遍历 arr1 建立频次表。
  2. 按 arr2 顺序，把每个值的全部副本写入答案并清零。
  3. 从 0 到 1000 扫描频次表，把剩余元素写入答案。
  4. 返回答案。

正确性

  1. 第二步严格按 arr2 顺序输出全部副本，指定部分顺序正确。
  2. 第三步递增扫描数值，剩余部分必为升序。
  3. 每个输入元素贡献一次计数，每份计数恰好输出一次，元素不丢失也不增加。

因此结果恰好满足题意。

边界

  • 单元素数组；所有元素都受 arr2 控制；大量未受控元素；重复值；值域端点 0 和 1000。

复杂度

令 n=arr1.length、m=arr2.length、U=1001。时间 O(n+m+U)；额外空间 O(U)（不计返回数组）。

替代方案

建立“值 → arr2 排名”的映射后自定义排序；更通用，但时间通常为 O(n log n)。值域很大时，也可用哈希频次表，只排序剩余键。

面试追问

  • 值域很大或有负数怎么办？
  • 能否原地完成，接口又有何限制？
  • 若 arr2 重复或含未知值，如何定义行为？

常见错误

  • 遗漏未受控值；输出后不清零导致重复；尾部沿用原顺序；比较器未处理两个未受控值。

Java

class Solution {
    public int[] relativeSortArray(int[] arr1, int[] arr2) {
        int[] count = new int[1001];
        for (int x : arr1) count[x]++;
        int[] ans = new int[arr1.length];
        int k = 0;
        for (int x : arr2) {
            while (count[x] > 0) {
                ans[k++] = x;
                count[x]--;
            }
        }
        for (int x = 0; x <= 1000; x++)
            while (count[x]-- > 0) ans[k++] = x;
        return ans;
    }
}

Python

from typing import List

class Solution:
    def relativeSortArray(
        self, arr1: List[int], arr2: List[int]
    ) -> List[int]:
        count = [0] * 1001
        for x in arr1:
            count[x] += 1
        ans = []
        for x in arr2:
            ans.extend([x] * count[x])
            count[x] = 0
        for x, freq in enumerate(count):
            ans.extend([x] * freq)
        return ans

C++

class Solution {
public:
    vector<int> relativeSortArray(
        vector<int>& arr1, vector<int>& arr2
    ) {
        vector<int> count(1001), ans;
        ans.reserve(arr1.size());
        for (int x : arr1) ++count[x];
        for (int x : arr2)
            while (count[x]-- > 0) ans.push_back(x);
        for (int x = 0; x <= 1000; ++x)
            while (count[x]-- > 0) ans.push_back(x);
        return ans;
    }
};
