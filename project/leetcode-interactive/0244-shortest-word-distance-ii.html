Distance II

先把每个单词出现过的下标收进有序列表；每次查询只让两条稀疏的下标轨道向前归并，不再反复扫描全文。

题意：为多次词距查询建立索引

实现 WordDistance：构造时接收 wordsDict；shortest(word1, word2) 返回两种不同单词在原数组中任意出现位置之间的最短绝对距离。

约束：1 ≤ wordsDict.length ≤ 3×10^4；单词长度 1–10，均为小写字母；两查询词一定存在且互不相同；最多 5000 次查询。
官方样例 
wordsDict = ["practice","makes","perfect",
             "coding","makes"]
shortest("coding","practice") = 3
shortest("makes","coding") = 1

构造后得到 makes → [1,4]、coding → [3]。第二次查询仅比较这三项。

交互分步：两条下标轨道的归并

查询 shortest("makes", "coding")。比较两端下标；谁更小就前进谁，因为它才可能靠近对方的未来位置。

题解区域

默认收起。先观察索引和双指针怎样丢弃不可能更优的下标。

核心洞察

构造阶段把同词的出现位置按原数组遍历顺序附加，天然有序。查询时在 a、b 两个有序列表上做双指针，记录 abs(a[i]-b[j])；较小下标向前移动。

  1. 预处理 Map<word, positions>。
  2. 取两个位置列表，i=j=0。
  3. 计算距离后移动较小一端，直到任一列表耗尽。

复杂度与边界

  • 构造时间/空间 O(n)。
  • 单次查询 O(freq(word1)+freq(word2))。
  • 单词出现多次时需比较全部可能近邻。
  • 题目保证 word1 != word2、两者存在。

替代方案

每次查询全文扫描为 O(n)，在 5000 次查询下浪费严重。预处理反向索引把一次成本转为后续稀疏列表归并；若只查一次，直接扫描反而更简单。

常见错误与追问

错误：只保存最后位置；未移动较小指针；构造时排序位置却遗漏同词。追问：允许相同 word？需在同一列表相邻出现位置求最小差（第 245 题）。

  private final Map<String, List<Integer>> pos = new HashMap<>();
  public WordDistance(String[] wordsDict) { for (int i = 0; i < wordsDict.length; i++) pos.computeIfAbsent(wordsDict[i], k -> new ArrayList<>()).add(i); }
  public int shortest(String word1, String word2) { List<Integer> a=pos.get(word1),b=pos.get(word2); int i=0,j=0,ans=Integer.MAX_VALUE; while(i<a.size()&&j<b.size()){ans=Math.min(ans,Math.abs(a.get(i)-b.get(j)));if(a.get(i)<b.get(j))i++;else j++;}return ans; }
}

  this.pos = new Map();
  wordsDict.forEach((w, i) => { if (!this.pos.has(w)) this.pos.set(w, []); this.pos.get(w).push(i); });

class WordDistance:
    def __init__(self, wordsDict: List[str]):
        self.pos = {}
        for i, w in enumerate(wordsDict): self.pos.setdefault(w, []).append(i)
    def shortest(self, word1: str, word2: str) -> int:
        a, b = self.pos[word1], self.pos[word2]
        i = j = 0; ans = float("inf")
        while i < len(a) and j < len(b):
            ans = min(ans, abs(a[i] - b[j]))
            if a[i] < b[j]: i += 1
            else: j += 1
        return ans
