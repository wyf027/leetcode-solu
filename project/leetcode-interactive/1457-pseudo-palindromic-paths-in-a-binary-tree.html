Pseudo-Palindromic Paths in a Binary Tree

给你一棵二叉树，其中每个节点的值都是 1 到 9 的数字。如果一条路径上的节点值可以重新排列成回文序列，就称它为「伪回文路径」。

请返回所有从根节点到叶子节点的路径中，伪回文路径的数量。函数参数形式：pseudoPalindromicPaths(root: TreeNode) → integer。

示例与约束

先准确理解输入输出，再进入交互推演。

示例 1

输入
root = [2,3,1,3,1,null,1]
输出
2

根到叶路径为 [2,3,3]、[2,3,1]、[2,1,1]；前后两条分别可重排为回文。

示例 2

输入
root = [2,1,1,1,3,null,null,null,null,null,1]
输出
1

三条根到叶路径中，只有 [2,1,1] 的节点值能重排为回文。

示例 3

输入
root = [9]
输出
1

单节点既是根也是叶，长度为 1 的序列本身就是回文。

约束

  • 树中节点数在 [1, 105] 范围内。
  • 1 <= Node.val <= 9。

完整题解：用 9 位掩码记录奇偶性

不需要保存完整频次，只需要知道每个数字出现了奇数次还是偶数次。

01
核心洞察

一个多重集合能排列成回文，当且仅当至多一个数字出现奇数次。节点值只有 1～9，因此用一个整数的第 v 位表示数字 v 的出现次数奇偶性；每访问值 v，执行 mask ^= 1 << v 即可翻转该位。

完整过程

  1. 栈中保存二元组 (node, mask)，初始为根节点和 0。
  2. 弹出节点后，把它的值对应位与当前掩码异或，得到从根到该节点的新奇偶状态。
  3. 若它是叶子，利用 mask & (mask - 1) == 0 判断掩码是否至多只有一个 1；成立就把答案加一。
  4. 若它不是叶子，把非空子节点连同当前掩码压栈，继续遍历。

为什么位运算判断成立？

对任意正整数，mask - 1 会把最低位的 1 变为 0，并把它右侧的 0 变为 1。因此 mask & (mask - 1) 会删除最低位的 1。结果为 0，说明原掩码只有一个 1；而 mask = 0 时也自然成立，正好覆盖“所有数字次数均为偶数”。

正确性证明

  1. 路径状态不变式：当栈项 (node, mask) 被处理并翻转 node.val 对应位后，掩码第 d 位为 1，当且仅当根到该节点路径上数字 d 出现奇数次。初始空路径全为偶数；异或恰好在每次加入一个值时翻转其奇偶性，所以不变式成立。
  2. 叶子判定充分且必要：回文中除中心位置外，其余位置成对出现，因此至多一个数字可出现奇数次；反过来，若至多一个数字为奇数次，可把所有偶数对称放置，把唯一的奇数数字放在中心，必能构成回文。
  3. 计数完整性：DFS 恰好访问每个节点一次，并在且仅在叶子处判定根到叶路径。结合前两点，算法对每条伪回文路径恰好计数一次，且不会计入其他路径。

边界情况

  • 只有一个节点：掩码只有一个 1，答案为 1。
  • 高度接近节点数的极端偏斜树：使用显式栈，避免语言递归栈溢出。
  • 所有节点值相同：任意根到叶路径都满足条件。
  • 掩码为 0：表示所有数字出现偶数次，也满足伪回文条件。

复杂度

设节点数为 n、树高为 h。每个节点处理一次，时间复杂度为 O(n)。显式 DFS 栈最坏占 O(h)；对完全二叉树，待处理节点也可达到 O(n) 量级，因此保守写作空间复杂度 O(n)。

替代方案

也可以沿路径维护长度为 10 的频次数组，在叶子扫描 1～9；因为值域固定，时间仍为 O(n)。回溯递归写法更短，但节点数可达 105，某些语言在偏斜树上存在调用栈溢出风险。位掩码更紧凑，也让叶子判定成为常数次位运算。

四种语言完整代码

JavaLeetCode 可提交
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    public int pseudoPalindromicPaths(TreeNode root) {
        java.util.ArrayDeque<State> stack = new java.util.ArrayDeque<>();
        stack.push(new State(root, 0));
        int answer = 0;

        while (!stack.isEmpty()) {
            State state = stack.pop();
            TreeNode node = state.node;
            int mask = state.mask ^ (1 << node.val);

            if (node.left == null && node.right == null) {
                if ((mask & (mask - 1)) == 0) {
                    answer++;
                }
                continue;
            }
            if (node.left != null) {
                stack.push(new State(node.left, mask));
            }
            if (node.right != null) {
                stack.push(new State(node.right, mask));
            }
        }
        return answer;
    }

    private static class State {
        TreeNode node;
        int mask;
        State(TreeNode node, int mask) {
            this.node = node;
            this.mask = mask;
        }
    }
}
JavaScriptLeetCode 可提交
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *   this.val = val;
 *   this.left = left;
 *   this.right = right;
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var pseudoPalindromicPaths = function(root) {
    const stack = [[root, 0]];
    let answer = 0;

    while (stack.length > 0) {
        const [node, previousMask] = stack.pop();
        const mask = previousMask ^ (1 << node.val);

        if (node.left === null && node.right === null) {
            if ((mask & (mask - 1)) === 0) {
                answer++;
            }
            continue;
        }
        if (node.left !== null) stack.push([node.left, mask]);
        if (node.right !== null) stack.push([node.right, mask]);
    }
    return answer;
};

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class Solution {
public:
    int pseudoPalindromicPaths(TreeNode* root) {
        std::stack<std::pair<TreeNode*, int>> stack;
        stack.push({root, 0});
        int answer = 0;

        while (!stack.empty()) {
            auto [node, previousMask] = stack.top();
            stack.pop();
            int mask = previousMask ^ (1 << node->val);

            if (node->left == nullptr && node->right == nullptr) {
                if ((mask & (mask - 1)) == 0) {
                    ++answer;
                }
                continue;
            }
            if (node->left != nullptr) {
                stack.push({node->left, mask});
            }
            if (node->right != nullptr) {
                stack.push({node->right, mask});
            }
        }
        return answer;
    }
};

面试追问

  • 为什么不需要记录具体频次？ 回文可行性只取决于奇偶性；偶数次增加或减少 2 不影响结论。
  • 如果节点值范围扩大怎么办？ 位数能容纳时使用更宽整数；否则用集合维护出现奇数次的值，访问时加入或删除。
  • 如何输出所有符合条件的路径？ 除掩码外维护当前路径，并在叶子处复制符合条件的路径；输出本身可能占用大量空间。
  • BFS 可以吗？ 可以，队列中保存节点和掩码即可，但宽树上的队列空间通常更大。

常见错误

  • 在每个节点而不是仅在叶子节点计数，误把“根到任意节点”当成“根到叶”。
  • 用加法设置位而不是异或翻转位，导致偶数次无法回到 0。
  • 把条件写成“必须恰好一个奇数”，遗漏掩码为 0 的合法情况。
  • 递归 DFS 未考虑 105 个节点形成的偏斜树可能造成调用栈溢出。
