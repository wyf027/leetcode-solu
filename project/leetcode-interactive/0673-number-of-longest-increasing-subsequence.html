最长递增子序列的个数

不只寻找最长的长度，还要回答：通往这个长度的路线，一共有多少条？先读懂问题，再亲手推进序列。

Problem brief

题目说明

给定整数数组 nums，返回其中最长严格递增子序列的个数。子序列保留原数组中的相对顺序，但不要求元素连续。

函数形式：findNumberOfLIS(nums: integer[]) -> integer

关键定义：若选出的每个后继元素都严格大于前驱元素，则为严格递增子序列；不同索引选择得到的子序列分别计数。

示例 1

输入
nums = [1,3,5,4,7]
输出
2
解释
两个最长递增子序列为 [1,3,4,7] 与 [1,3,5,7]。

示例 2

输入
nums = [2,2,2,2,2]
输出
5
解释
最长长度为 1；五个位置各自构成一个长度为 1 的子序列。

约束

  • 1 <= nums.length <= 2000
  • -106 <= nums[i] <= 106
  • 答案保证可存入 32 位整数。

“严格”是分水岭

只有当前值更大时才能接在前面。相等元素不能互相延长，但它们处于不同索引时，仍可能分别贡献一条路线。

可连接 ⇔ nums[j] < nums[i]
不可连接 ⇔ nums[j] ≥ nums[i]

Complete solution

双账本动态规划

核心洞察

一个状态不够：长度与数量必须成对维护。只记录“以 i 结尾的最长长度”会丢失达到该长度的路线数量；只记录数量又不知道哪些路线可以参与最终答案。

定义 length[i] 为以 nums[i] 结尾的最长严格递增子序列长度，count[i] 为达到该长度的子序列个数。每个元素单独成序列，因此两者初值都为 1。

完整转移过程

  1. 从左到右枚举终点 i。
  2. 枚举所有前驱 j < i；只有 nums[j] < nums[i] 时才允许连接。
  3. 若 length[j] + 1 > length[i]，发现了更长路线：覆盖长度，并把数量替换为 count[j]。
  4. 若 length[j] + 1 == length[i]，发现了另一批同样长的路线：把 count[j] 累加到 count[i]。
  5. 求出全局最长长度，再对所有达到它的终点累加 count[i]。
if nums[j] < nums[i]: candidate = length[j] + 1 candidate > length[i] → length[i] = candidate; count[i] = count[j] candidate = length[i] → count[i] += count[j] answer = Σ count[i], where length[i] = max(length)

正确性证明

  1. 状态覆盖所有可能前驱。任意以 i 结尾且长度大于 1 的严格递增子序列，其倒数第二个索引必为某个 j < i，且 nums[j] < nums[i]。内层循环枚举了所有这种 j。
  2. 长度最优。归纳假设所有更早位置的 length[j] 已正确。取所有合法前驱的 length[j] + 1 最大值，就得到以 i 结尾的最优长度；若没有合法前驱，单元素长度 1 正确。
  3. 计数无重无漏。当出现更长候选时，旧路线都不是最优，故数量应替换；当候选与当前最优等长时，不同末前索引 j 对应互不相交的路线集合，故数量可直接相加。
  4. 全局汇总正确。每条全局最长子序列有且只有一个末尾索引。只累加 length[i] 等于全局最大值的位置，恰好统计所有最长子序列。

复杂度

时间O(n²)
空间O(n)

边界情况

  • 只有一个元素：答案为 1。
  • 所有元素相等：最长长度为 1，答案为数组长度。
  • 严格递减：每个元素各自是一条最长路线。
  • 多个前驱汇入同一终点：只在候选长度相等时累加。
  • 负数不影响比较与状态定义。

常见错误

  • 把严格递增写成 <=。
  • 发现更长路线时仍做累加，而不是覆盖数量。
  • 只取某一个终点的数量，没有汇总全部最长终点。
  • 按数值去重，误把不同索引路径合并。

四语言完整代码

Solution.java
class Solution {
    public int findNumberOfLIS(int[] nums) {
        int n = nums.length;
        int[] length = new int[n];
        int[] count = new int[n];
        int maxLength = 0;

        for (int i = 0; i < n; i++) {
            length[i] = 1;
            count[i] = 1;

            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    int candidate = length[j] + 1;
                    if (candidate > length[i]) {
                        length[i] = candidate;
                        count[i] = count[j];
                    } else if (candidate == length[i]) {
                        count[i] += count[j];
                    }
                }
            }
            maxLength = Math.max(maxLength, length[i]);
        }

        int answer = 0;
        for (int i = 0; i < n; i++) {
            if (length[i] == maxLength) answer += count[i];
        }
        return answer;
    }
}

solution.py
from typing import List

class Solution:
    def findNumberOfLIS(self, nums: List[int]) -> int:
        n = len(nums)
        length = [1] * n
        count = [1] * n

        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:
                    candidate = length[j] + 1
                    if candidate > length[i]:
                        length[i] = candidate
                        count[i] = count[j]
                    elif candidate == length[i]:
                        count[i] += count[j]

        max_length = max(length)
        return sum(
            count[i] for i in range(n)
            if length[i] == max_length
        )

替代方案：值域数据结构

可对数值离散化，并使用树状数组或线段树维护“某个值域内的最佳长度与对应数量”。查询所有严格小于当前值的区间，再把得到的二元组扩展一位并合并到当前位置。

合并规则是：长度不同保留更长者；长度相同则数量相加。复杂度可降到 O(n log n)，但实现与正确性论证明显更复杂。对于 n ≤ 2000，二次动态规划通常是最稳妥的面试答案。
