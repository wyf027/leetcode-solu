数一数猜对的“位置”

给定长度均为 3 的 guess 与 answer。若 guess[i] === answer[i]，第 i 个位置得 1 分；返回总分。

输入

[1,2,3]

[1,2,3]

输出

3

全部位置相同

注意

数字相同但位置不同，不得分。

THINKING PATH

不需要哈希表，也不需要排序

  1. 01

    同步取值

    遍历每个下标 i，读取 guess[i] 与 answer[i]。

  2. 02

    比较位置

    仅当同一位置的两个值相等时，命中一次。

  3. 03

    返回计数

    循环结束后，累计值就是最终分数。

COMPLETE SOLUTIONS

四种语言，都是同一个循环 

class Solution {
    public int game(int[] guess, int[] answer) {
        int score = 0;
        for (int i = 0; i < guess.length; i++) {
            if (guess[i] == answer[i]) {
                score++;
            }
        }
        return score;
    }
}
