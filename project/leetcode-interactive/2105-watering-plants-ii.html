01题目说明

花园里有 n 株植物，从左到右编号为 0 … n − 1，第 i 株位于 x = i，需要 plants[i] 单位水。Alice 与 Bob 各有一个初始装满的水罐，容量分别为 capacityA 与 capacityB。

  • Alice 从最左端向右浇水，Bob 从最右端向左浇水，两人同时开始。
  • 每株植物的浇水耗时相同，与需求水量无关。
  • 剩余水足够时必须直接浇；不够时先瞬间把自己的水罐装满，再浇这一株。
  • 两人到达同一株时，由当前剩余水更多的人浇；剩余水相等时由 Alice 浇。

返回浇完全部植物时，两人重新装满水罐的总次数。初始装满不计入次数，不能把两个人的水合并。

参数与约束

minimumRefill(plants, capacityA, capacityB) → integer

  • n == plants.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ plants[i] ≤ 10⁶
  • max(plants[i]) ≤ capacityA, capacityB ≤ 10⁹

05思考之后，再打开题解

你会如何记录两人的剩余水量？相遇时有哪些特殊情况？

双指针，忠实模拟每一轮

核心洞察

补水瞬间完成，而每株浇水耗时一样，所以每一轮两人各处理一株，目标下标始终从两端向中间靠拢。只需保存左右下标、两人的剩余水与补水计数。不存在需要搜索的补水策略：不够才补，足够必须浇。

完整过程

  1. 令 i = 0, j = n - 1，剩余水 a = capacityA, b = capacityB，答案为 0。
  2. 当 i < j，若 a < plants[i]，恢复 a 到容量并累加一次；再减去需求。Bob 同理。
  3. 完成这一轮后 i++、j--。
  4. 若 i == j，仅当 max(a,b) < plants[i] 时再加一次，返回计数。

正确性论证

循环开始时，区间 [i,j] 恰好是未浇的植物，两端以外均已按规则浇完，a、b 与计数对应真实过程。初始显然成立。每轮严格按“足够直接浇，不足先补满”处理两端；容量保证每次补满后一定足够，因此水量和补水次数更新准确。指针内移后不变式保持。

循环结束时，若指针交错则全部完成；若相等则只剩一株。水更多的人负责，相等选 Alice；只有较大剩余水仍不足时才需补水一次。故返回值准确包含全部且仅包含必需的补水。

边界与复杂度

  • 单株直接进入相遇逻辑，初始水满且容量足够，答案为 0。
  • 偶数长度不会处理中间单株；奇数长度中间只计一次。
  • 水量等于需求时可以直接浇，因此比较使用 <。
  • 时间 O(n)，额外空间 O(1)；不修改输入数组。
  • 不累加所有需求，单个余量不超过 10⁹，计数不超过 n；常规 32 位整型即可。

替代方案

可以先独立模拟左半段，再独立模拟右半段，最后处理中心。两人水罐互不影响，所以计数等价，但需要额外说明半段边界。两端同步推进更贴近题意。无需动态规划、排序或逐单位水模拟；排序会破坏规定的浇水顺序。

常见错误

  • 将补水写成 a += capacityA；正确做法是恢复到容量。
  • 先扣水再判断或把 < 写成 <=，导致多补水。
  • 用 i <= j 处理两端，使中心被浇两次。
  • 中心比较水罐容量而非当前剩余水，或合并两罐余水。
  • 把初始装满也算一次，或把结果误算为行走距离。

面试追问

  • 为什么中心可以只比较 max？ 被规则选中的人正好拥有较大的剩余水，平局选谁不影响次数；若需输出操作者，仍应在相等时选 Alice。
  • 补水不再瞬间完成怎么办？ 两人可能不同步，固定的左右配对轮次不再可靠，需要结合新的时间规则设计事件模拟。
  • 如果单株需求可能大于容量？ 当前题目排除了该情况；必须先明确是否允许分次浇或判定无法完成，不能直接套用当前算法。

Java

class Solution {
    public int minimumRefill(int[] plants, int capacityA, int capacityB) {
        int i = 0, j = plants.length - 1;
        int a = capacityA, b = capacityB, answer = 0;
        while (i < j) {
            if (a < plants[i]) {
                a = capacityA;
                answer++;
            }
            if (b < plants[j]) {
                b = capacityB;
                answer++;
            }
            a -= plants[i++];
            b -= plants[j--];
        }
        if (i == j && Math.max(a, b) < plants[i]) answer++;
        return answer;
    }
}

        return answer;
    }
};
