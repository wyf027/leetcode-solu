MISSION BRIEF

用最少跳跃抵达末位

给定从 0 开始编号的整数数组 nums，初始站在索引 0。nums[i] 表示从 i 最多能向前跳多少格。返回抵达索引 n−1 的最少跳跃次数；题目保证末位可达。

区间贪心 = 压缩后的 BFS

farthest = max(farthest, i + nums[i])
i == currentEnd → jumps++, currentEnd = farthest

同一覆盖区间里的位置都属于同一“跳跃层”，因此只在层尾增加次数。

    CORE INSIGHT

    一次跳跃就是 BFS 的一层

    在当前可达区间内，下一跳可以从任意位置发起。逐点扫描并维护 farthest，就等于收集下一层的所有节点；扫描到 currentEnd 时，本层已全部看完，必须增加一次跳跃并把下一层边界设为 farthest。

    farthest = max(farthest, i + nums[i])
    if i == currentEnd:
      jumps++, currentEnd = farthest

    COMPLEXITY

    每个岩点只扫描一次

    循环只走到 n−2；最后一个位置无需再向外跳。只维护三个整数。

    TIME

    O(n)

    SPACE

    O(1)

    FULL PROCESS & PROOF

    完整过程与正确性

    1. 1. 初始化：jumps = currentEnd = farthest = 0。
    2. 2. 扫描当前层：对 i 从 0 到 n−2，用 i + nums[i] 更新下一层最远边界。
    3. 3. 层尾提交：当 i 等于 currentEnd，说明所有使用 jumps 次可达的位置已扫描完；要继续前进至少需要再跳一次。
    4. 4. 最优性：farthest 是这一层任意起点所能到达的最远位置，选择它不会丢失更短路线；按 BFS 层数首次覆盖末位时，跳跃次数最少。
    5. 5. 结束：不扫描末位，避免抵达后多加一次跳跃。

    BOUNDARIES

    边界情况

    • • 单元素数组：已经在终点，返回 0。
    • • 当前值为 0：题目仍保证能从更早位置跨过。
    • • 恰好抵达边界：仍在同一层内处理。
    • • 循环只到 n−2，防止终点再次起跳。

    ALTERNATIVES

    动态规划取舍

    DP 可令 dp[i] 表示抵达 i 的最少跳数，从每个前驱转移，直观但最坏 O(n²)。显式 BFS 还会保存队列。区间贪心保留 BFS 层边界，既正确又达到 O(n)。

    INTERVIEW FOLLOW-UPS

    面试高频追问

    Q：为什么不直接跳到当前能跳最远的位置？
    当前位置的最远落点未必拥有最好后续能力；应比较整层所有起点能形成的最远覆盖。
    Q：为什么 i 到 n−2？
    终点只需抵达，不需从终点继续跳；扫描它会额外计数。
    Q：若不保证可达怎么办？
    层尾发现 farthest == currentEnd 时无法扩展，可返回 −1 或按题意约定处理。

    COMMON MISTAKES

    常见错误

    • • 每更新一次 farthest 就增加 jumps，导致过度计数。
    • • 把 currentEnd 与 farthest 混成一个变量，丢失层边界。
    • • 循环到 n−1，抵达终点后又多跳一次。
    • • 贪心选择当前 nums[i] 最大的位置，而不是最大化 i+nums[i]。
    • • 单元素数组没有自然返回 0。
