只保留离当前位置最近的有效命中

核心洞察与完整过程

目标不同

  1. 维护 last1 与 last2，分别记录两个目标最近一次出现位置。
  2. 扫描到目标后更新相应位置；两个位置均有效时，用绝对差更新答案。
  3. 更早的同类位置离当前命中更远，不可能产生更小距离，因此可以丢弃。

目标相同

  1. 一次命中必须同时承担“当前出现”和“上一出现”两个角色，但不能与自己配对。
  2. 每次命中先计算当前下标与上一命中下标之差，再把当前下标保存为新的上一命中。
  3. 最短同词距离一定出现在相邻两次出现之间。
different: keep latest(word1), latest(word2)
same:      keep previous occurrence, then shift
answer:    minimum valid index gap

正确性要点

对不同目标，扫描至下标 i 时，与当前位置构成最近配对的另一目标必然是其最近一次历史出现；更早位置距离只会更大。对相同目标，任意非相邻的两次出现之间还夹着一次同词出现，因此至少有一个相邻间距不大于它。扫描全部位置后，所有可能成为全局最优的候选均被检查。

边界与复杂度

  • 相同目标保证代表两个独立出现位置。
  • 相邻命中时最短距离为 1，不存在 0。
  • 单次扫描时间 O(n)，额外空间 O(1)。

替代方案与取舍

  • 收集两组下标再双指针合并，时间仍为 O(n)，但空间升至 O(n)。
  • 枚举所有有效下标对直观但最坏 O(n²)，仅适合作为独立对拍 oracle。
  • 统一单个 last-hit 状态也能实现，但分支版本更容易证明同词语义。

面试追问

  • 若需要回答大量查询，怎样预处理每个词的下标表？
  • 若词流在线到达，怎样持续输出当前最短距离？
  • 怎样扩展到三个目标词的最短覆盖区间？

Java
class Solution {
    public int shortestWordDistance(
            String[] wordsDict, String word1, String word2) {
        int answer = wordsDict.length;

        if (word1.equals(word2)) {
            int previous = -1;
            for (int i = 0; i < wordsDict.length; i++) {
                if (wordsDict[i].equals(word1)) {
                    if (previous != -1) {
                        answer = Math.min(answer, i - previous);
                    }
                    previous = i;
                }
            }
            return answer;
        }

        int last1 = -1;
        int last2 = -1;
        for (int i = 0; i < wordsDict.length; i++) {
            if (wordsDict[i].equals(word1)) last1 = i;
            if (wordsDict[i].equals(word2)) last2 = i;
            if (last1 != -1 && last2 != -1) {
                answer = Math.min(answer, Math.abs(last1 - last2));
            }
        }
        return answer;
    }
}

            for i, word in enumerate(wordsDict):
                if word == word1:
                    if previous != -1:

                    previous = i

            if word == word1:
                last1 = i
            if word == word2:
                last2 = i
            if last1 != -1 and last2 != -1:
                answer = min(answer, abs(last1 - last2))
        return answer

常见错误

  • 目标相同时在同一命中下标更新两枚针，错误得到距离 0。
  • 相同目标只记录第一次出现，错过后续更小的相邻间距。
  • 不同目标每次都回看全部旧位置，把线性解写成 O(n²)。
  • 用单词值判断两个出现位置是否不同；真正要比较的是下标。
  • 把“距离”误解为两个单词之间夹着的元素个数，少算 1。
