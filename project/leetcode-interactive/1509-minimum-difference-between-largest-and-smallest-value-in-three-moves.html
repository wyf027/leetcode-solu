Problem

题目描述

给你一个整数数组 nums。一次操作中，可以选择数组里的任意一个元素，把它改成任意值。请返回执行最多三次操作后，数组最大值与最小值之差能够达到的最小值。

示例 1

输入：nums = [5,3,2,4]
输出：0
解释：依次把 2、4、5 改成 3，
最终 nums = [3,3,3,3]，差值为 0。

示例 2

输入：nums = [1,5,0,10,14]
输出：1
解释：可把 5、10 改成 0，
把 14 改成 1，最终差值为 1；
三次操作无法得到差值 0。

示例 3

输入：nums = [3,100,20]
输出：0
解释：把三个数都改成 7，
最终 nums = [7,7,7]，差值为 0。

约束

  • 1 <= nums.length <= 105
  • -109 <= nums[i] <= 109

Solution

排序后，只需比较四种边界

核心洞察

若数组长度不超过 4，可以把除一个元素外的所有数都改成相同值，答案一定是 0。否则，排序后真正影响极差的只有两端。一次操作改动中间元素不会缩小当前最小值与最大值之间的跨度；最优方案可视为从最小端移除若干个数、从最大端移除其余的数，移除总数为 3。

排序后记数组为 a，长度为 n： answer = min(a[n-4] - a[0], a[n-3] - a[1], a[n-2] - a[2], a[n-1] - a[3])

完整过程

  1. 若 n <= 4，直接返回 0。
  2. 将数组升序排序。
  3. 枚举最小端被修改的数量 i = 0,1,2,3；最大端相应修改 3-i 个。
  4. 未修改区间左端为 a[i]，右端为 a[n-4+i]，用两者之差更新答案。

正确性证明

引理：存在一个最优方案，其被修改元素全部来自排序后数组的两端。若被修改的是严格位于当前最小值与最大值之间的元素，它无论改成什么都不能缩小这两个端点决定的极差；把这次操作转用于某个端点不会更差。

枚举完备性：三次操作在左端使用的次数只能是 0、1、2、3，对应右端使用 3、2、1、0 次，恰好是公式中的四个区间。每种分配下，把被修改的端点调整到保留区间内即可达到该区间的极差。因此四者的最小值既可达，又不大于任何最优方案，算法正确。

边界情况

  • n <= 4：答案为 0。
  • 所有元素相等：四个候选差值均为 0。
  • 包含负数：排序与做差逻辑不变。
  • 数值可达 ±109，差值最大 2×109，题目范围内 32 位有符号整数仍可容纳。

复杂度

排序耗时 O(n log n)，枚举四个候选为 O(1)。除排序实现自身所需空间外，额外空间为 O(1)；部分语言的排序会使用 O(log n) 或 O(n) 辅助空间。

替代方案

无需完整排序也能在线性期望时间内找出最小的 4 个值和最大的 4 个值，再计算四个候选；也可以维护两个大小为 4 的堆，实现 O(n log 4) 时间和 O(1) 额外规模。不过完整排序更短、更直观，通常是面试中的首选。

面试追问

  • 若允许最多 k 次操作，公式如何推广？答案是排序后枚举 i=0..k，比较 a[n-1-(k-i)]-a[i]。
  • 若不能排序原数组怎么办？复制数组，或只维护两端各 k+1 个极值。
  • 为什么是“最多三次”却可以固定按三次枚举？因为无效操作可以不做，或把元素改成原值；额外操作不会迫使答案变差。

常见错误

  • 只比较“删掉三个最大值”和“删掉三个最小值”，遗漏两种左右混合分配。
  • 把操作误解为删除元素；实际上是改值，但对极差而言可等价分析为忽略被修改的端点。
  • 遗漏 n <= 4，导致索引越界。
  • 候选右端索引写成 n-3+i；正确的是 n-4+i。

import java.util.Arrays;

class Solution {
    public int minDifference(int[] nums) {
        int n = nums.length;
        if (n <= 4) return 0;

        Arrays.sort(nums);
        int answer = Integer.MAX_VALUE;
        for (int leftMoves = 0; leftMoves <= 3; leftMoves++) {
            int right = n - 4 + leftMoves;
            answer = Math.min(answer, nums[right] - nums[leftMoves]);
        }
        return answer;
    }
}

from typing import List

class Solution:
    def minDifference(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 4:
            return 0

        nums.sort()
        return min(
            nums[n - 4 + left_moves] - nums[left_moves]
            for left_moves in range(4)
        )
