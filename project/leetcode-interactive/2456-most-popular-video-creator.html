最流行的视频创作者

Most Popular Video Creator

一个平台，两种排名规则。找出最受欢迎的创作者，再为每人选出一条代表视频。

阅读题目 ↓交互演示 ↓测试与验证 ↓

01 / THE CHALLENGE

题目说明

给定等长数组 creators、ids 和 views。第 i 条视频的创作者是 creators[i]，标识为 ids[i]，播放量为 views[i]。

  • 创作者的流行度是其所有视频播放量的总和。返回总和最大的所有创作者。
  • 对每位入选创作者，选择其播放量最大的视频；如有并列，选择字典序最小的 ID。
  • 返回 [[创作者, 视频ID], …]，结果顺序不限。
  • 视频 ID 不保证唯一。即使 ID 相同，不同数组下标也代表独立视频，每条视频的播放量都要计入。

字典序按字符从左到右比较；前缀相同时较短的字符串更小，例如 a < aa < b。

官方示例 1

creators = ["alice","bob","alice","chris"]
ids = ["one","two","three","four"]
views = [5,10,5,4]
输出 = [["alice","one"],["bob","two"]]

alice 与 bob 的总播放量均为 10，chris 为 4。alice 的 one 和 three 均为 5，取字典序较小的 one；bob 选择 two。

官方示例 2

creators = ["alice","alice","alice"]
ids = ["a","b","c"]
views = [1,2,2]
输出 = [["alice","b"]]

只有 alice 一位创作者。b 和 c 的播放量均为 2，所以选择 b。

完整约束

  • n == creators.length == ids.length == views.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ creators[i].length, ids[i].length ≤ 5
  • creators[i] 和 ids[i] 只包含小写英文字母。
  • 0 ≤ views[i] ≤ 10⁵

04 / EDITORIAL

准备好查看解法了吗？

先想一想：为了代表一位创作者，最少需要记住哪些信息？

题解 · 一个分组，三项统计

核心洞察

用创作者名称作哈希表键，每人只保存 total（累计播放量）、bestViews（最大单条播放量）和 bestId（代表视频 ID）。总播放量与单条最大值是不同指标，分别维护即可。

完整过程

  1. 遇到新创作者，将总量设为 0，最佳播放量设为 −1。
  2. 每读取一条视频，把其播放量累加到对应创作者总量。
  3. 播放量更大，或播放量相同但 ID 字典序更小，才替换代表视频。
  4. 扫描全部创作者求最高总量，再收集所有总量等于该值的 [creator, bestId]。

正确性证明

维护不变式：处理完任意前缀后，每位已出现创作者的 total 等于该前缀中属于此人的播放量之和；bestViews 是此人已处理视频的最大播放量；bestId 是达到该播放量的视频中最小的 ID。

初始时尚无记录，不变式成立。读取新视频时，累加只影响其创作者的总量；代表视频只在播放量增大或同播放量的 ID 变小时替换，恰好维持后二项定义。其他创作者不变，所以不变式继续成立。

全部读取后，不变式覆盖所有视频。最后筛出 total 等于全局最大值的所有键，既不遗漏最高流行度创作者，也不包含较低者；每人的 bestId 又满足单条播放量和字典序规则，因此结果正确。

边界与数值范围

  • 播放量可为 0：bestViews 初始为 −1，确保第一条视频被选中。
  • 所有总量都为 0：所有创作者均需返回。
  • 同名 ID 不能合并去重，统计单位是数组中的记录。
  • 最大总量为 10¹⁰：Java 用 long，C++ 用 long long；Python 整数无需扩容处理，JS Number 可精确表示该范围。
  • 字符串只含小写字母，普通字典序比较即可，不需要本地化排序。

复杂度

令 n 为视频数，k 为创作者数，L 为字符串最大长度。按哈希操作期望常数次探测计算，时间为 O(nL + kL)，额外空间 O(kL)。本题 L ≤ 5，简写为期望 O(n) 时间、O(k) 额外空间（输出另占 O(k)）。这里的期望界依赖哈希表，未承诺碰撞最坏情形仍为线性。

替代方案

将记录按创作者、播放量降序、ID 升序排序，再按创作者累加。它也正确，但需 O(n log n) 次比较并可能改动输入；哈希表只保留必要统计。本题只需最大值，用堆增加维护成本。

常见错误

  • 用最大单条播放量给创作者排名，遗漏累计规则。
  • 相同播放量就无条件替换，忽略 ID 字典序。
  • 仅返回一名冠军，遗漏并列创作者。
  • 把同 ID 的播放量相加后参与代表视频比较。
  • Java / C++ 用 32 位类型累计导致溢出。

面试追问

  • 结果要按创作者排序？仅对最终 k′ 个结果排序，增加 O(k′ log k′)。
  • 只追加新视频？复用三项统计即可；要持续查询冠军可另维护有序统计结构。
  • 允许删除视频？三项摘要不足以恢复次优视频，需保存每人视频的有序集合及总量。
  • 若播放量可能为负？代表视频用负无穷初始化，全局最大总量不能默认从 0 开始。

JavaScript
/**
 * @param {string[]} creators
 * @param {string[]} ids
 * @param {number[]} views
 * @return {string[][]}
 */
var mostPopularCreator = function(creators, ids, views) {
    const stats = new Map();
    for (let i = 0; i < creators.length; i++) {
        const name = creators[i];
        if (!stats.has(name)) {
            stats.set(name, { total: 0, bestViews: -1, bestId: "" });
        }
        const s = stats.get(name);
        s.total += views[i];
        if (views[i] > s.bestViews ||
            (views[i] === s.bestViews && ids[i] < s.bestId)) {
            s.bestViews = views[i];
            s.bestId = ids[i];
        }
    }
    let highest = 0;
    for (const s of stats.values()) highest = Math.max(highest, s.total);
    const answer = [];
    for (const [name, s] of stats) {
        if (s.total === highest) answer.push([name, s.bestId]);
    }
    return answer;
};
Java
import java.util.*;

class Solution {
    public List<List<String>> mostPopularCreator(
            String[] creators, String[] ids, int[] views) {
        Map<String, Long> totals = new HashMap<>();
        Map<String, Integer> best = new HashMap<>();
        for (int i = 0; i < creators.length; i++) {
            String name = creators[i];
            totals.put(name, totals.getOrDefault(name, 0L) + views[i]);
            Integer j = best.get(name);
            if (j == null || views[i] > views[j] ||
                (views[i] == views[j] && ids[i].compareTo(ids[j]) < 0)) {
                best.put(name, i);
            }
        }
        long highest = 0L;
        for (long total : totals.values()) highest = Math.max(highest, total);
        List<List<String>> answer = new ArrayList<>();
        for (Map.Entry<String, Long> entry : totals.entrySet()) {
            if (entry.getValue() == highest) {
                String name = entry.getKey();
                answer.add(Arrays.asList(name, ids[best.get(name)]));
            }
        }
        return answer;
    }
}
Python 3
from typing import List

class Solution:
    def mostPopularCreator(self, creators: List[str], ids: List[str],
                           views: List[int]) -> List[List[str]]:
        stats = {}
        for name, video_id, count in zip(creators, ids, views):
            if name not in stats:
                stats[name] = [0, -1, ""]
            s = stats[name]
            s[0] += count
            if count > s[1] or (count == s[1] and video_id < s[2]):
                s[1] = count
                s[2] = video_id
        highest = max(s[0] for s in stats.values())
        return [[name, s[2]] for name, s in stats.items()
                if s[0] == highest]
C++
#include <algorithm>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<string>> mostPopularCreator(
        vector<string>& creators, vector<string>& ids, vector<int>& views) {
        unordered_map<string, long long> totals;
        unordered_map<string, int> best;
        for (int i = 0; i < (int)creators.size(); ++i) {
            const string& name = creators[i];
            totals[name] += views[i];
            auto it = best.find(name);
            if (it == best.end()) {
                best[name] = i;
            } else {
                int j = it->second;
                if (views[i] > views[j] ||
                    (views[i] == views[j] && ids[i] < ids[j])) {
                    it->second = i;
                }
            }
        }
        long long highest = 0;
        for (const auto& entry : totals) highest = max(highest, entry.second);
        vector<vector<string>> answer;
        for (const auto& entry : totals) {
            if (entry.second == highest) {
                answer.push_back({entry.first, ids[best.at(entry.first)]});
            }
        }
        return answer;
    }
};
