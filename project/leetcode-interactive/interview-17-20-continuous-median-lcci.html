Solution revealed

题解

Core insight

核心洞察：只需守住中线两侧

将所有数分成两半：大顶堆 lower 保存较小的一半，堆顶是左中位数；小顶堆 upper 保存较大的一半，堆顶是右中位数。其余元素无需全局有序。

Invariants

两个不变量

  • lower 中每个值都不大于 upper 中每个值。
  • lower.size() 等于 upper.size()，或恰好多 1。

Full process

完整过程

  1. 新数字先压入 lower，因此无需提前判断它属于哪一半。
  2. 弹出 lower 的最大值并压入 upper，自动恢复两半的大小关系。
  3. 若 upper 比 lower 多，则把 upper 的最小值移回，保证左侧数量不少于右侧。
  4. 总数为奇数时返回 lower.peek()；偶数时返回两个堆顶的平均值。

Edges

边界

  • 首次查询应在至少加入一个数字之后调用。
  • 重复值、负数和乱序输入不影响两个不变量。
  • 偶数个元素求和时先转为浮点或更宽类型，避免整数溢出。
  • 本题不能丢弃极端值：未来加入新数后，它们仍可能进入中间位置。

Complexity

复杂度

addNum

O(log n)

findMedian

O(1)

space

O(n)

Trade-offs

替代方案取舍

  • 有序数组：查询 O(1)，插入搬移 O(n)，数据流长时不推荐。
  • 平衡搜索树：配合秩统计可达 O(log n)，但标准库通常不直接支持按秩访问。
  • 计数桶：值域很小时很快；值域未知或很大时空间不可控。

Interview follow-ups

面试追问

为什么新值总能先放入 lower？
随后把 lower 最大值转移到 upper，相当于让两堆重新选出分界，顺序不变量自然恢复。
滑动窗口中位数怎么办？
堆不擅长删除任意元素，可增加延迟删除哈希表，出堆顶前清理失效值。
多线程写入如何处理？
两个堆和再平衡必须作为同一临界区；读中位数也要看到一致快照。

Failure modes

常见错误

  • 只平衡数量，却没有确保左堆所有值不大于右堆。
  • 偶数个元素仍只返回某个堆顶。
  • Java/C++ 先用整数相加再转 double，极值相加可能溢出。
  • Python 大顶堆忘记用负数模拟，或移动时漏掉一次取反。
  • JavaScript 手写堆的上浮/下沉比较方向写反。

import java.util.Collections;
import java.util.PriorityQueue;

class MedianFinder {
    private final PriorityQueue<Integer> lower;
    private final PriorityQueue<Integer> upper;

    public MedianFinder() {
        lower = new PriorityQueue<>(Collections.reverseOrder());
        upper = new PriorityQueue<>();
    }

    public void addNum(int num) {
        lower.offer(num);
        upper.offer(lower.poll());

        if (upper.size() > lower.size()) {
            lower.offer(upper.poll());
        }
    }

    public double findMedian() {
        if (lower.size() > upper.size()) {
            return lower.peek();
        }
        return ((double) lower.peek() + upper.peek()) / 2.0;
    }
}
class BinaryHeap {
  constructor(higherPriority) {
    this.data = [];
    this.higherPriority = higherPriority;
  }

  size() {
    return this.data.length;
  }

  peek() {
    return this.data[0];
  }

  push(value) {
    this.data.push(value);
    let index = this.data.length - 1;
    while (index > 0) {
      const parent = Math.floor((index - 1) / 2);
      if (!this.higherPriority(this.data[index], this.data[parent])) break;
      [this.data[index], this.data[parent]] = [this.data[parent], this.data[index]];
      index = parent;
    }
  }

  pop() {
    const top = this.data[0];
    const last = this.data.pop();
    if (this.data.length === 0) return top;
    this.data[0] = last;
    let index = 0;

    while (true) {
      const left = index * 2 + 1;
      const right = left + 1;
      let best = index;
      if (left < this.data.length && this.higherPriority(this.data[left], this.data[best])) best = left;
      if (right < this.data.length && this.higherPriority(this.data[right], this.data[best])) best = right;
      if (best === index) break;
      [this.data[index], this.data[best]] = [this.data[best], this.data[index]];
      index = best;
    }
    return top;
  }
}

var MedianFinder = function () {
  this.lower = new BinaryHeap((a, b) => a > b);
  this.upper = new BinaryHeap((a, b) => a < b);
};

MedianFinder.prototype.addNum = function (num) {
  this.lower.push(num);
  this.upper.push(this.lower.pop());
  if (this.upper.size() > this.lower.size()) {
    this.lower.push(this.upper.pop());
  }
};

MedianFinder.prototype.findMedian = function () {
  if (this.lower.size() > this.upper.size()) return this.lower.peek();
  return (this.lower.peek() + this.upper.peek()) / 2;
};
import heapq


class MedianFinder:
    def __init__(self):
        self.lower = []
        self.upper = []

    def addNum(self, num: int) -> None:
        heapq.heappush(self.lower, -num)
        heapq.heappush(self.upper, -heapq.heappop(self.lower))

        if len(self.upper) > len(self.lower):
            heapq.heappush(self.lower, -heapq.heappop(self.upper))

    def findMedian(self) -> float:
        if len(self.lower) > len(self.upper):
            return float(-self.lower[0])
        return (-self.lower[0] + self.upper[0]) / 2.0
#include <functional>
#include <queue>
#include <vector>

using namespace std;

class MedianFinder {
    priority_queue<int> lower;
    priority_queue<int, vector<int>, greater<int>> upper;

public:
    MedianFinder() = default;

    void addNum(int num) {
        lower.push(num);
        upper.push(lower.top());
        lower.pop();

        if (upper.size() > lower.size()) {
            lower.push(upper.top());
            upper.pop();
        }
    }

    double findMedian() {
        if (lower.size() > upper.size()) {
            return lower.top();
        }
        return (static_cast<double>(lower.top()) + upper.top()) / 2.0;
    }
};
