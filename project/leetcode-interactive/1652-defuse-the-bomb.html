01 / 题目

密钥决定观察方向

给定长度为 n 的循环数组 code 和整数 k，所有元素必须基于原数组同时替换，返回替换后的数组。

对每个位置 i，替换规则如下：

k > 0：换成其后 k 个数之和。
k < 0：换成其前 -k 个数之和。
k = 0：换成 0。

数组首尾相接：末尾元素的下一个是首元素，首元素的前一个是末尾元素。注意不要把已算出的答案写回原数组后再继续计算。

约束

  • n == code.length
  • 1 ≤ n ≤ 100
  • 1 ≤ code[i] ≤ 100
  • -(n - 1) ≤ k ≤ n - 1

示例 1 · 向后看

输入：code = [5,7,1,4], k = 3
输出：[12,10,16,13]
解释：[7+1+4, 1+4+5, 4+5+7, 5+7+1]

示例 2 · 静止

输入：code = [1,2,3,4], k = 0
输出：[0,0,0,0]
解释：k 为 0，每个位置都替换为 0。

示例 3 · 向前看

输入：code = [2,4,9,3], k = -2
输出：[12,5,6,13]
解释：[3+9, 2+3, 4+2, 9+4]

准备好核对思路了吗？

下面的独立区域包含完整算法、证明与四种语言实现。先自己想一遍，再打开会更有收获。

核心洞察

相邻的两个答案窗口只差两个元素：窗口离开一个旧元素，又进入一个新元素。因此先算出位置 0 的窗口和，之后让窗口沿环移动，每步做一次减法和一次加法。

统一把窗口表示为原数组上的连续区间，并用下标取模处理首尾连接。若 k = 0，直接返回全零数组。

完整过程

  1. 令 m = |k|。
  2. k > 0 时，初始窗口覆盖下标 1…k；k < 0 时，覆盖 n-m…n-1。
  3. 把当前窗口和写入答案。
  4. 滑动一格：减去左端元素，左右端同时加一，再加入新的右端元素；访问数组时对 n 取模。
  5. 重复直到得到全部 n 个答案。

正确性说明

初始成立：按 k 的符号选择的初始区间，恰好是位置 0 要求的后 k 个或前 -k 个元素。

归纳推进：假设窗口正确表示位置 i 的相邻元素。移除左端并加入右端后的下一个元素，窗口中的每个下标都沿圆环前进一格，恰好表示位置 i+1 的目标邻域。

因此每个答案都是题目规定的和；k=0 分支也直接符合定义。

边界与复杂度

  • 单元素数组只能配合 k=0，返回 [0]。
  • |k|=n-1 时，窗口包含除自身外的全部元素。
  • 负数 k 的初始窗口从数组尾部开始。
  • 时间复杂度 O(n)；除返回数组外，额外空间 O(1)。

替代方案

逐项枚举：对每个位置再枚举 |k| 个邻居，写法直观，时间为 O(n|k|)。当前约束下也能通过。

复制数组 + 前缀和：把数组拼接多次，用区间和回答每个位置，时间 O(n)，但会占用额外线性空间。

面试追问与常见错误

  • 追问：如果 |k| 允许大于 n，如何用整圈总和与余数优化？
  • 追问：如何把方案推广到动态变化的窗口大小？
  • 错误：边算边覆盖 code，破坏后续计算所需的原值。
  • 错误：负数取模产生负下标；可统一从非负下标开始。
  • 错误：k<0 时仍从位置 1 建窗，方向颠倒。

class Solution {
    public int[] decrypt(int[] code, int k) {
        int n = code.length;
        int[] ans = new int[n];
        if (k == 0) return ans;

        int m = Math.abs(k);
        int left = k > 0 ? 1 : n - m;
        int right = k > 0 ? m : n - 1;
        int sum = 0;
        for (int j = left; j <= right; j++) sum += code[j % n];

        for (int i = 0; i < n; i++) {
            ans[i] = sum;
            sum -= code[left % n];
            left++;
            right++;
            sum += code[right % n];
        }
        return ans;
    }
}

from typing import List

class Solution:
    def decrypt(self, code: List[int], k: int) -> List[int]:
        n = len(code)
        ans = [0] * n
        if k == 0:
            return ans

        m = abs(k)
        left = 1 if k > 0 else n - m
        right = m if k > 0 else n - 1
        window_sum = sum(code[j % n] for j in range(left, right + 1))

        for i in range(n):
            ans[i] = window_sum
            window_sum -= code[left % n]
            left += 1
            right += 1
            window_sum += code[right % n]
        return ans
