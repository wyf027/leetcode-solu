割绳子

Cutting Ribbons

把长短不一的绳子，切成同样长的 k 段。

1891
01 / Problem

你需要完成什么？

给定整数数组 ribbons，其中每个元素表示一根绳子的长度，以及目标数量 k。可以将每根绳子切成若干正整数长度的段，也可以保持原样；不同绳子不能拼接。

从得到的绳段中选出 k 段，使它们的长度相同且尽可能大，返回这个最大整数长度。多余的绳段或余料可以舍弃。如果连长度为 1 的 k 段都无法得到，返回 0。

思考入口

长度变大时，可得到的完整绳段会变多还是变少？先尝试手动切割，再查看下方题解。

Input / Output

接口与约束

maxLength(ribbons, k) → integer
  • 1 ≤ ribbons.length ≤ 10⁵
  • 1 ≤ ribbons[i] ≤ 10⁵
  • 1 ≤ k ≤ 10⁹

输入：整数数组、目标段数。
输出：每段的最大整数长度。

在长度上寻找最后一个可行值

核心洞察

设每段长为 x > 0，一根长为 r 的绳子最多提供 ⌊r / x⌋ 段。总段数 C(x) = Σ⌊ribbons[i] / x⌋。当 C(x) ≥ k 时，这个长度可行；多出来的段可以舍弃。随着 x 增大，C(x) 单调不增，因此可以二分寻找最大的可行长度。

完整过程

  1. 令 lo = 1、hi = max(ribbons)、answer = 0。0 仅表示无可行正长度，不参与除法。
  2. 只要 lo ≤ hi，取中点 mid = lo + floor((hi − lo) / 2)，累加各根绳子的完整段数。
  3. 若段数至少为 k，记录 answer = mid，令 lo = mid + 1 尝试更长；否则令 hi = mid − 1。
  4. 区间为空时返回 answer。判定中一旦累计达到 k 即可提前结束；演示为了呈现全部绳子会计算完整总数。

示例 1 的轨迹为：区间 [1,9] 尝试 5，得到 3 段，记录 5；[6,9] 尝试 7，只有 2 段；[6,6] 尝试 6，仍只有 2 段；最后返回 5。

正确性证明

计数准确：每段必须完全来自同一根绳子，长度 r 的绳子不可能提供超过 ⌊r/x⌋ 段；依次切出这些段能达到该数量。各根独立，求和就是最大可得段数。因此 C(x) ≥ k 是可行的充要条件。

单调性：若 x 可行，任何更短的正整数长度也可行；若 x 不可行，更长的长度同样不可行。

区间不变式：answer 是已记录的最大可行值；任何更优答案仍在 [lo,hi] 内。中点可行时，所有不超过 mid 的长度都不再优于新 answer；中点不可行时，不小于 mid 的长度全部不可行。两种更新都保留不变式，且区间严格缩小。终止后已无更优候选，answer 即最优解；从未找到正长度时返回 0。

边界与常见错误

  • 不能使用 floor(sum(ribbons) / x)：余料不能合并。例如 [5,5]、k=3，长度 3 实际只能得到两段。
  • 判断应为 count ≥ k，不是相等。多余段可舍弃。
  • 区间从 1 开始，避免除以 0；用 mid ± 1 更新，避免停在原地。
  • 总长度最多 10¹⁰，完整计数可能超出 32 位有符号整数。Java 用 long，C++ 用 long long；Python 整数无需额外处理，JavaScript Number 在本题范围内精确。
  • k=1 时答案是最长绳子；总长度小于 k 时答案为 0；单根绳子答案是 floor(r/k)。
  • JavaScript 用循环求最大值，避免对 10⁵ 个元素使用展开参数导致调用参数过多。

复杂度

令 n 为绳子数，M 为最大绳长。初始化 O(n)，每次判定 O(n)，共 O(log(M+1)) 轮，总时间 O(n log(M+1))，额外空间 O(1)。演示保存步骤和绘图节点的开销不计入提交算法。

替代方案与取舍

从 M 开始逐个枚举长度，最坏 O(nM)，容易理解但效率低。也可把二分上界收紧为 min(M, floor(sum/k))，需要安全地求和；当上界为 0 时直接返回。排序不改变可行性判定，且增加 O(n log n) 成本，本解无需排序。

面试追问

  • 要求恰好 k 段呢？本题允许舍弃多余段，所以至少 k 段即可选出恰好 k 段；若不允许舍弃，问题条件发生变化，当前判定不再充分。
  • 怎样给出切割方案？得到答案 x 后遍历绳子，每根选取 min(⌊r/x⌋, 剩余需求) 段，直到收集 k 段；x=0 时没有方案。
  • 允许小数长度呢？需指定误差范围，再对实数区间进行定轮数或精度控制的二分，并处理浮点误差。
  • 为何不能仅用平均长度？总长度/k 只给出上界，绳子之间不能拼接，零散余料会降低实际可切段数。

四语言完整实现

Java

class Solution {
    public int maxLength(int[] ribbons, int k) {
        int lo = 1, hi = 0, answer = 0;
        for (int r : ribbons) hi = Math.max(hi, r);
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            long count = 0;
            for (int r : ribbons) {
                count += r / mid;
                if (count >= k) break;
            }
            if (count >= k) {
                answer = mid;
                lo = mid + 1;
            } else {
                hi = mid - 1;
            }
        }
        return answer;
    }
}
