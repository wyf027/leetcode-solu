两个数组间的距离值

Find the Distance Value Between Two Arrays —— 把“离所有点都足够远”变成一个可以在数轴上观察、在有序数组中快速确认的问题。

计数条件
对 arr1[i]：
不存在 arr2[j] 使
|arr1[i] − arr2[j]| ≤ d

Problem

题目要求

给定两个整数数组 arr1、arr2 和整数 d，统计 arr1 中有多少个元素满足：在 arr2 中找不到任何一个元素与它的绝对差小于或等于 d。

换句话说，只要某个 arr1[i] 落进任意 arr2[j] 周围的闭区间 [arr2[j] − d, arr2[j] + d]，它就不能计入答案。

findTheDistanceValue(arr1, arr2, d) → integer

约束

  • 1 ≤ arr1.length, arr2.length ≤ 500
  • −10³ ≤ arr1[i], arr2[j] ≤ 10³
  • 0 ≤ d ≤ 100

      arr2 = [10,9,1,8]
      d = 2
输出：2

      d = 3

      d = 6

Solution

排序 + 二分查找

将 arr2 排序后，对每个 x 只需定位最可能落入区间 [x − d, x + d] 的那个元素。

核心洞察

设 p = lower_bound(arr2, x − d)，即 arr2 中第一个大于等于 x − d 的位置。所有在 p 之前的数都太小，不可能进入闭区间；如果 p 存在，它就是剩余元素中最小的。

因此，只有当 p 越界，或 arr2[p] > x + d 时，区间内才没有元素，x 才计入答案。

完整过程

  1. 升序排序 arr2。
  2. 依次取出 arr1 中的每个 x。
  3. 二分查找第一个满足 arr2[p] ≥ x − d 的位置 p。
  4. 若 p 不存在，或 arr2[p] > x + d，答案加一。
  5. 处理完所有 x 后返回答案。

正确性说明

引理：若 arr2 中存在落在 [x−d, x+d] 的元素，那么 lower_bound 得到的 arr2[p] 也落在该区间。

证明：p 之前的元素都小于 x−d；p 是所有不小于 x−d 的元素中最靠前、也最小的一个。既然存在某个区间内元素，arr2[p] 不会比它更大，因此 arr2[p] ≤ x+d。

结论：检查 p 是否存在且不超过 x+d，与检查区间内是否存在 arr2 元素等价。算法恰好统计所有区间为空的 x，因此返回正确距离值。

复杂度与边界

O(m log m + n log m)时间；n = arr1.length，m = arr2.length
O(log m)排序调用栈（具体依语言实现）
  • d = 0 时，只排除与 arr2 中某个值完全相等的元素。
  • 重复值不影响 lower_bound 的判定。
  • 负数与边界值使用同一套区间规则。
  • arr2 的原顺序不重要；若不能修改输入，应排序副本。

替代方案

直接枚举：对每个 arr1[i] 扫描整个 arr2，时间 O(nm)，实现最直观。在本题最大 500 × 500 的限制下也可接受。

排序 + 双指针：同时排序两个数组，让指针单向移动，可达到 O(n log n + m log m)，但要注意 arr1 重复元素仍应逐个计数。

面试追问与常见错误

  • 追问：arr2 动态插入时怎么办？可用支持 lower_bound 的有序集合或平衡树。
  • 追问：数据范围很窄时？可用频次数组和前缀和查询区间是否为空。
  • 错误：把条件写成 < d；题目排除的是 ≤ d。
  • 错误：找到一个远距离元素就计数；必须确认 arr2 的所有元素都足够远。
  • 错误：lower_bound 后只判断左边邻居；此处应直接检查第一个 ≥ x−d 的元素。

import java.util.Arrays;

class Solution {
    public int findTheDistanceValue(int[] arr1, int[] arr2, int d) {
        Arrays.sort(arr2);
        int answer = 0;

        for (int x : arr1) {
            int low = 0, high = arr2.length;
            int target = x - d;

            while (low < high) {
                int mid = low + (high - low) / 2;
                if (arr2[mid] < target) {
                    low = mid + 1;
                } else {
                    high = mid;
                }
            }

            if (low == arr2.length || arr2[low] > x + d) {
                answer++;
            }
        }
        return answer;
    }
}

var findTheDistanceValue = function(arr1, arr2, d) {
    const sorted = [...arr2].sort((a, b) => a - b);
    let answer = 0;

    for (const x of arr1) {
        let low = 0;
        let high = sorted.length;
        const target = x - d;

        while (low < high) {
            const mid = low + Math.floor((high - low) / 2);
            if (sorted[mid] < target) {
                low = mid + 1;
            } else {
                high = mid;
            }
        }

        if (low === sorted.length || sorted[low] > x + d) {
            answer++;
        }
    }
    return answer;
};
