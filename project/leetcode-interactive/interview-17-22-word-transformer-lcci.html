题意

给定两个等长单词与一个字典。每一步只能修改一个字符，修改后得到的新词必须存在于字典中。返回一条从起点到终点的可能转换序列；若不存在则返回空数组。

结果不要求唯一或最短

题目接受任意合法线路。本页使用 BFS，因此会额外保证返回最短转换序列之一。

官方样例 1

输入
beginWord = "hit", endWord = "cog", wordList = ["hot", "dot", "dog", "lot", "log", "cog"]
输出示例
["hit", "hot", "dot", "lot", "log", "cog"]

输出并不唯一；相邻两个单词均只差一个字符即可。

不可达条件

若终点不在字典中，或字典网络中没有连接起点与终点的路径，返回 []。

输入显示约定

字符串保留成对直引号；若词内存在空格，将使用 ␠ 显示。本题单词不含空格。

Route operations manual

题解

核心洞察、完整过程、边界、复杂度、取舍、追问、常见错误与四语言代码全部收纳在此，默认隐藏。

核心洞察

单词是节点，一字之差是边

把每个可用单词视作图节点。对当前单词的每个位置尝试替换为 a～z，若新词仍在字典集合中，就得到一条可走的边。BFS 按层扩展，第一次抵达终点时经过的边数最少。

前驱表让路径可恢复

发现新词时记录 parent[next] = current。到达终点后从后往前追溯，再反转得到完整序列。

完整过程

  1. 1. 把 wordList 放入哈希集合；终点不在集合则直接失败。
  2. 2. 起点入队，并从集合删除，表示已访问。
  3. 3. 出队一个单词，逐位置尝试 26 个小写字母。
  4. 4. 新词在集合中时记录前驱、删除并入队，避免重复访问。
  5. 5. 首次遇到终点，沿前驱链回溯并反转；队列耗尽则返回空数组。

边界与正确性

  • • 终点缺失：每一步的新词必须在字典中，因此必定无解。
  • • 起终点相同：稳健实现直接返回只含起点的序列。
  • • 删除时机：入队时立刻从集合删除，避免同层重复入队与前驱覆盖。
  • • 任意答案：BFS 返回的最短答案是题目所允许答案的子集。

BFS 会按路径长度从小到大访问节点；所有合法单字母变化都会被枚举，所以若终点可达必会被发现，且第一次发现对应最短路径。前驱链逐边对应真实转换，因此恢复出的序列合法。

复杂度与替代方案

时间

O(N · L · 26)

空间

O(N · L)

N 是字典单词数，L 是单词长度。面试主线推荐单向 BFS：代码和路径恢复都直观。双向 BFS 从两端扩展较小前沿，能显著减少实际搜索节点，但合并两侧前驱链更复杂。

DFS 回溯可以满足“任意序列”，却可能深入大量死路，最坏性能远差于 BFS；逐个扫描所有字典邻居则会增加到 O(N²L)。

面试追问

为什么不预先构建所有单词之间的边？

显式两两比较需 O(N²L)；按字符原位变形只生成最多 26L 个候选，更节省。

如何返回所有最短序列？

同层发现时保留多个前驱，BFS 完成终点所在层后，再从终点沿前驱 DAG 回溯所有路径。

字符集不是小写字母怎么办？

把候选字符表作为参数，或改用通配模式索引，例如把 hot 映射到 *ot、h*t、ho*。

常见错误

  • • 只记录访问状态，没有前驱信息，最终无法恢复序列。
  • • 出队时才标记访问，导致同一单词被多次入队。
  • • 修改字符后没有恢复原字符，后续位置从错误单词继续变形。
  • • 要求起点也必须存在于 wordList。
  • • 把本题误读为必须输出官方样例那一条固定路径。

class Solution {
    public List<String> findLadders(
        String beginWord,
        String endWord,
        List<String> wordList
    ) {
        if (beginWord.equals(endWord)) {
            return List.of(beginWord);
        }
        Set<String> dictionary = new HashSet<>(wordList);
        if (!dictionary.contains(endWord)) return new ArrayList<>();

        Queue<String> queue = new ArrayDeque<>();
        Map<String, String> parent = new HashMap<>();
        queue.offer(beginWord);
        dictionary.remove(beginWord);

        while (!queue.isEmpty()) {
            String current = queue.poll();
            char[] letters = current.toCharArray();
            for (int index = 0; index < letters.length; index++) {
                char original = letters[index];
                for (char letter = 'a'; letter <= 'z'; letter++) {
                    if (letter == original) continue;
                    letters[index] = letter;
                    String next = new String(letters);
                    if (!dictionary.remove(next)) continue;

                    parent.put(next, current);
                    if (next.equals(endWord)) {
                        return buildPath(beginWord, endWord, parent);
                    }
                    queue.offer(next);
                }
                letters[index] = original;
            }
        }
        return new ArrayList<>();
    }

    private List<String> buildPath(
        String beginWord,
        String endWord,
        Map<String, String> parent
    ) {
        LinkedList<String> path = new LinkedList<>();
        for (String word = endWord; word != null; word = parent.get(word)) {
            path.addFirst(word);
            if (word.equals(beginWord)) break;
        }
        return path;
    }
}

var findLadders = function (beginWord, endWord, wordList) {
  if (beginWord === endWord) return [beginWord];
  const dictionary = new Set(wordList);
  if (!dictionary.has(endWord)) return [];

  const queue = [beginWord];
  const parent = new Map();
  dictionary.delete(beginWord);

  for (let head = 0; head < queue.length; head++) {
    const current = queue[head];
    const letters = [...current];
    for (let index = 0; index < letters.length; index++) {
      const original = letters[index];
      for (let code = 97; code <= 122; code++) {
        const letter = String.fromCharCode(code);
        if (letter === original) continue;
        letters[index] = letter;
        const next = letters.join("");
        if (!dictionary.has(next)) continue;

        dictionary.delete(next);
        parent.set(next, current);
        if (next === endWord) {
          const path = [endWord];
          while (path[0] !== beginWord) path.unshift(parent.get(path[0]));
          return path;
        }
        queue.push(next);
      }
      letters[index] = original;
    }
  }
  return [];
};
from collections import deque
from typing import List


class Solution:
    def findLadders(
        self, beginWord: str, endWord: str, wordList: List[str]
    ) -> List[str]:
        if beginWord == endWord:
            return [beginWord]
        dictionary = set(wordList)
        if endWord not in dictionary:
            return []

        queue = deque([beginWord])
        parent = {}
        dictionary.discard(beginWord)

        while queue:
            current = queue.popleft()
            letters = list(current)
            for index, original in enumerate(letters):
                for code in range(ord("a"), ord("z") + 1):
                    letter = chr(code)
                    if letter == original:
                        continue
                    letters[index] = letter
                    next_word = "".join(letters)
                    if next_word not in dictionary:
                        continue

                    dictionary.remove(next_word)
                    parent[next_word] = current
                    if next_word == endWord:
                        path = [endWord]
                        while path[-1] != beginWord:
                            path.append(parent[path[-1]])
                        return path[::-1]
                    queue.append(next_word)
                letters[index] = original
        return []
class Solution {
public:
    vector<string> findLadders(
        string beginWord,
        string endWord,
        vector<string>& wordList
    ) {
        if (beginWord == endWord) return {beginWord};
        unordered_set<string> dictionary(wordList.begin(), wordList.end());
        if (!dictionary.count(endWord)) return {};

        queue<string> words;
        unordered_map<string, string> parent;
        words.push(beginWord);
        dictionary.erase(beginWord);

        while (!words.empty()) {
            string current = words.front();
            words.pop();
            string next = current;
            for (int index = 0; index < (int)next.size(); ++index) {
                char original = next[index];
                for (char letter = 'a'; letter <= 'z'; ++letter) {
                    if (letter == original) continue;
                    next[index] = letter;
                    if (!dictionary.erase(next)) continue;

                    parent[next] = current;
                    if (next == endWord) {
                        vector<string> path;
                        for (string word = endWord;; word = parent[word]) {
                            path.push_back(word);
                            if (word == beginWord) break;
                        }
                        reverse(path.begin(), path.end());
                        return path;
                    }
                    words.push(next);
                }
                next[index] = original;
            }
        }
        return {};
    }
};
