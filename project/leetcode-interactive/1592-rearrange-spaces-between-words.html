Problem

题目描述

非付费题 · 字符串

给定字符串 text，其中包含由空格分隔的若干单词。每个单词由一个或多个小写英文字母组成，相邻单词原本至少隔着一个空格，并保证至少有一个单词。

重新安排全部空格：每对相邻单词之间的空格数必须相等，并让这个数尽可能大；无法均分的剩余空格全部放到字符串末尾。返回的新字符串长度必须与 text 相同。

示例 1

输入：text = " this is a sentence " 输出："this is a sentence"

共有 9 个空格、4 个单词，因此 3 个间隔各放 3 个空格。

示例 2

输入：text = " practice makes perfect" 输出："practice makes perfect "

共有 7 个空格、3 个单词：每个间隔 3 个，余下 1 个放末尾。

示例 3

输入：text = "hello world" 输出："hello world"

示例 4

输入：text = " walks udp package into bar a" 输出："walks udp package into bar a "

示例 5

输入：text = "a" 输出："a"

函数签名

reorderSpaces(text: string): string

参数：text；返回：重排后的等长字符串。

约束

  • 1 <= text.length <= 100
  • text 仅由小写英文字母与普通空格字符组成。
  • text 至少包含一个单词。

Solution

          
一次统计，一次拼接


          

            
核心洞察

            
原空格的位置不重要，重要的是两个量：空格总数 S 与单词数 W。当 W > 1 时，共有 W - 1 个间隔；每个间隔放 floor(S / (W - 1)) 个空格，余数 S % (W - 1) 放在末尾。

          


          
完整过程

          
    
            
  1. 扫描 text，统计所有空格的数量 S。
    2. 
            
  2. 按空白切分并过滤空串，得到按原顺序排列的单词数组。
    3. 
            
  3. 若只有一个单词，单词后补足全部 S 个空格。
    4. 
            
  4. 否则计算每个间隔的空格数 between = S / (W - 1)（整数除法），以及末尾空格数 tail = S % (W - 1)。
    5. 
            
  5. 用 between 个空格连接所有单词，再追加 tail 个空格。
    6. 
          


          
正确性证明

          
引理 1：算法保留了全部单词及其顺序。扫描只移除原有空格，拼接按数组顺序使用每个单词一次，因此单词内容和相对顺序不变。

          
引理 2：相邻单词间的空格数相等且最大。当 W > 1 时有 W - 1 个间隔。每个间隔放 floor(S/(W-1)) 个空格。若每处再多放一个，总需求将超过 S，故该相等值已最大。

          
引理 3：算法使用全部空格且结果等长。间隔使用 (W-1) × floor(S/(W-1)) 个空格，末尾追加余数，两者之和恰为 S。结合引理 1，返回串长度与原串相同。

          
结论：算法满足题目要求。


          
边界情况

          
    
            
  • 只有一个单词：不存在相邻间隔，所有空格都追加到末尾，避免除以零。
    • 
            
  • 空格可整除：余数为 0，末尾不追加空格。
    • 
            
  • 字符串没有空格：根据约束只能是单个单词，原样返回。
    • 
            
  • 首尾有大量空格：统一计入总数，不需要特殊区分位置。
    • 
          


          
复杂度

          
设 n = text.length。扫描、切分和构造均为线性过程，时间复杂度 O(n)；保存单词与结果需要 O(n) 额外空间（若不计返回值，各语言的切分数组仍占 O(n)）。


          
替代方案

          
可以手写状态机，在一次扫描中同时收集单词和空格数，避免正则切分；也可以用语言提供的 trim + split。前者对解析细节控制更强，后者更短、更易读。无论选择哪一种，分配公式相同。


          
面试追问

          
    
            
  • 如果输入非常大，如何减少临时字符串？可用字符缓冲区或流式解析单词，再预分配结果容量。
    • 
            
  • 如果“空格”扩展为各种 Unicode 空白，应如何修改？需要明确空白判定与输出统一字符的规则。
    • 
            
  • 如何证明“尽可能大”？使用整除商的上界：所有间隔若至少为 k，必须满足 k(W-1) ≤ S。
    • 
          


          
常见错误

          
    
            
  • 直接对原字符串调用单空格切分，却没有过滤连续空格产生的空字符串。
    • 
            
  • 用单词数 W 作为除数，而不是间隔数 W - 1。
    • 
            
  • 遗漏单个单词分支，导致除以零。
    • 
            
  • 把余数散落在若干间隔中；题目明确要求全部放到末尾。
    • 
            
  • 忽略末尾空格，误以为视觉上相同就是字符串相同。
    •

class Solution {
    public String reorderSpaces(String text) {
        int spaces = 0;
        for (int i = 0; i < text.length(); i++) {
            if (text.charAt(i) == ' ') spaces++;
        }

        String trimmed = text.trim();
        String[] words = trimmed.split("\\s+");
        if (words.length == 1) {
            return words[0] + " ".repeat(spaces);
        }

        int between = spaces / (words.length - 1);
        int tail = spaces % (words.length - 1);
        String separator = " ".repeat(between);
        return String.join(separator, words) + " ".repeat(tail);
    }
}

var reorderSpaces = function(text) {
    const spaces = [...text].filter(char => char === ' ').length;
    const words = text.trim().split(/\s+/);

    if (words.length === 1) {
        return words[0] + ' '.repeat(spaces);
    }

    const between = Math.floor(spaces / (words.length - 1));
    const tail = spaces % (words.length - 1);
    return words.join(' '.repeat(between)) + ' '.repeat(tail);
};

          

          

            
class Solution:
    def reorderSpaces(self, text: str) -> str:
        spaces = text.count(' ')
        words = text.split()

        if len(words) == 1:
            return words[0] + ' ' * spaces

        between, tail = divmod(spaces, len(words) - 1)
        return (' ' * between).join(words) + ' ' * tail

          

          

            
class Solution {
public:
    string reorderSpaces(string text) {
        int spaces = count(text.begin(), text.end(), ' ');
        vector<string> words;
        string word;
        stringstream stream(text);
        while (stream >> word) words.push_back(word);

        if (words.size() == 1) {
            return words[0] + string(spaces, ' ');
        }

        int between = spaces / (words.size() - 1);
        int tail = spaces % (words.size() - 1);
        string result;
        for (int i = 0; i < static_cast<int>(words.size()); i++) {
            if (i > 0) result += string(between, ' ');
            result += words[i];
        }
        return result + string(tail, ' ');
    }
};
