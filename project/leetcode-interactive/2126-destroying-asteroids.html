摧毁小行星

Destroying Asteroids · 每一次碰撞，都改变下一步的可能。

先理解碰撞规则，试着安排顺序。推导与四种语言代码收在页面底部，按需展开。

01 / MISSION

任务与规则

整数 mass 是行星的初始质量，数组 asteroids 的每一项是一颗小行星的质量。你可以自由安排碰撞顺序，每颗小行星只碰撞一次。

碰撞前，若行星质量大于或等于小行星质量，小行星被摧毁，其质量加到行星上；否则行星被摧毁。判断是否存在一种顺序，能摧毁全部小行星，返回布尔值。

函数：asteroidsDestroyed(mass, asteroids) → boolean
约束：1 ≤ mass ≤ 10⁵；1 ≤ asteroids.length ≤ 10⁵；1 ≤ asteroids[i] ≤ 10⁵。

官方示例 1

输入：mass = 10, asteroids = [3,9,19,5,21]
输出：true

可行顺序之一是 [9,19,5,3,21]。行星质量依次变为 10 + 9 = 19、19 + 19 = 38、38 + 5 = 43、43 + 3 = 46、46 + 21 = 67。

官方示例 2

输入：mass = 5, asteroids = [4,9,23,4]
输出：false

即使先吸收其他三颗，质量也只有 5 + 4 + 9 + 4 = 22，仍小于 23，因此不存在可行顺序。

题解：先吸收最小的小行星

核心洞察

成功碰撞只会增加行星质量。先选剩余最小的一颗，不会损害后续选择；如果连它也无法吸收，剩余任何一颗都无法吸收。

完整过程

  1. 按质量非递减排序。
  2. 用累加变量记录当前质量。
  3. 依次检查每颗质量 a：当前质量小于 a 时返回 false，否则累加 a。
  4. 遍历结束返回 true。

示例 1 排序为 [3,5,9,19,21]，质量变化 10 → 13 → 18 → 27 → 46 → 67。示例 2 排序为 [4,4,9,23]，质量变化 5 → 9 → 13 → 22，遇到 23 失败。在实验室选择“提示：从小到大”可逐步观察排序队列与质量门槛。

正确性证明

不变式：每轮开始，已处理的小行星都已成功摧毁，当前质量等于初始质量与已吸收质量之和。

设剩余最小质量为 a，当前质量为 M。若 M ≥ a，可以先吸收 a。任意可行序列若把 a 放在后面，将其提前到最前，原来位于 a 前面的小行星都会在更大的行星质量下被吸收；经过原 a 的位置后，已吸收集合不变，质量也不变。因此这一交换保留可行性。

若 M < a，则所有剩余质量都大于 M，任何下一步都会失败。结合交换论证与不变式，成功的贪心步骤不会排除可行解，失败时确实无解，全部处理完成时返回 true 正确。

边界与数值

  • 相等可以吸收，失败判断必须使用严格小于。
  • 重复值不能去重，每颗都贡献质量。
  • 所有质量的总和足够大，不代表第一步可行。
  • 累计质量最大为 10⁵ + 10⁵ × 10⁵ = 10,000,100,000，超过 32 位有符号整数。Java 用 long，C++ 用 long long；JavaScript Number 在此范围内可精确表示整数，Python 整数无需额外处理。
  • 下列代码原地排序，修改输入数组。若需要保留原数组，先复制。

复杂度

设 n 为数组长度。排序 O(n log n)，扫描 O(n)，总时间 O(n log n)。扫描额外状态 O(1)，总辅助空间取决于排序实现：C++ 通常 O(log n) 栈；Java 原生数组排序随 JDK 实现而异；Python 最坏 O(n)；JavaScript 取决于引擎，常见为 O(n)。不能把总空间一概写为 O(1)。

Java

import java.util.Arrays;

class Solution {
    public boolean asteroidsDestroyed(int mass, int[] asteroids) {
        Arrays.sort(asteroids);
        long current = mass;
        for (int asteroid : asteroids) {
            if (current < asteroid) return false;
            current += asteroid;
        }
        return true;
    }
}

        mass += asteroid;
    }
    return true;
};

Python

from typing import List

class Solution:
    def asteroidsDestroyed(self, mass: int, asteroids: List[int]) -> bool:
        asteroids.sort()

            if mass < asteroid:
                return False

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    bool asteroidsDestroyed(int mass, vector<int>& asteroids) {
        sort(asteroids.begin(), asteroids.end());
        long long current = mass;
        for (int asteroid : asteroids) {
            if (current < asteroid) return false;
            current += asteroid;
        }
        return true;
    }
};

替代方案

最小堆每次取最小值，也能实现该贪心，时间 O(n log n)、空间 O(n)。本题无需动态插入，排序更直接。还可利用上界 U = 10⁵ 做计数：按质量从小到大扫描非空桶，若当前质量达到该桶质量，就累加“质量 × 频次”。时间 O(n + U)，空间 O(U)，乘法须使用足够宽的整数。

面试追问

  • 达到数组最大质量后能提前返回吗？可以，之后所有小行星都能被吸收，且质量只增不减。
  • 如果必须保持输入顺序？直接顺序扫描，无需排序，时间 O(n)。
  • 如何求最小初始质量？排序后，设某颗 a 之前的前缀和为 S，需满足初始质量 ≥ a − S。取这些差值与 1 的最大值。
  • 如果碰撞消耗质量？质量单调增加的前提失效，需要重新证明策略。

常见错误

  • 把按输入顺序失败当成不存在可行顺序。
  • JavaScript 忘记 sort 的数值比较器，得到字典序。
  • 先累加质量再比较，借用了还未吸收的质量。
  • 用 32 位变量累计，或把相等判断为失败。
  • 仅比较总质量与最大值，忽略每一步的门槛。
