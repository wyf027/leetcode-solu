题意转述

给定字符串 s 和等长单词数组 words。寻找所有起点，使从该位置开始的连续子串恰好使用 words 中每个单词一次；顺序可任意，重复单词必须按次数匹配。答案顺序不限。

    Core insight

    核心洞察：按余数分轨

    单词长度为 k，合法拼接只能从某个偏移量开始，每次移动恰好 k 个字符。因此把起点按 index mod k 分成 k 条互不干扰的轨道，在每条轨道上做普通滑动窗口。

    track 0
    0, 3, 6…
    track 1
    1, 4, 7…
    track 2
    2, 5, 8…

    Window invariant

    窗口不变量

    • • 窗口只包含 need 中出现的单词。
    • • 每个词的窗口次数不超过目标次数。
    • • used === words.length 时，窗口恰好是一份完整排列。
    • • 命中后左端弹出一词，继续寻找可重叠答案。

    Complete cut

    完整解题过程

    1. FRAME A

      建立目标清单

      统计 words 中每个单词需要几次。

    2. FRAME B

      枚举偏移轨道

      从 0 到 k − 1 分别扫描。

    3. FRAME C

      右端读词

      非法词清空；超额词推动左端退片。

    4. FRAME D

      记录并继续

      词数刚好时记录左端，再弹出一词允许重叠。

    边界情况

    • • 总拼接长度大于 s.length：直接返回空。
    • • 重复单词：词频必须逐个匹配。
    • • 遇到清单外单词：窗口整体重置。
    • • 同一答案可与下一个答案重叠。
    • • 答案顺序不限。

    复杂度

    Time
    O(|s| · k)
    Space
    O(u)

    k 是单词长度，计入切片与哈希成本；若把定长字符串操作视为常数，时间可写作 O(|s|)。u 是不同单词数。

    替代方案取舍

    • 枚举起点 + 重建词频：O(|s| · words.length)，直观但重复统计。
    • 枚举全部排列：阶乘爆炸，不能使用。
    • Trie：单词已等长，哈希分帧更简单直接。

    面试高频追问

    Q：为什么只枚举 k 个偏移？
    A：同一轨道上所有词边界相差 k，覆盖全部起点且轨道互不重叠。
    Q：为什么超额只需收缩到当前词合法？
    A：收缩前其他词已经合法；弹出左端只会降低次数，不会让它们超额。
    Q：若单词不等长怎么办？
    A：固定分帧失效，问题需改用 Trie、回溯或更复杂的匹配状态，已是不同题型。

    常见错误

    • ✗ 用集合代替词频表，丢失重复单词次数。
    • ✗ 只扫描偏移 0，漏掉从偏移 1…k − 1 开始的答案。
    • ✗ 遇到非法词后只移动左指针，却没有清空窗口词频。
    • ✗ 命中后完全清空，漏掉重叠答案。
    • ✗ 左端收缩时忘记同步减少 used。

    class Solution {
    public List<Integer> findSubstring(String s, String[] words) {
        List<Integer> answer = new ArrayList<>();
        int wordLength = words[0].length();
        int wordCount = words.length;
        int totalLength = wordLength * wordCount;
        if (totalLength > s.length()) return answer;

        Map<String, Integer> need = new HashMap<>();
        for (String word : words) {
            need.put(word, need.getOrDefault(word, 0) + 1);
        }

        for (int offset = 0; offset < wordLength; offset++) {
            Map<String, Integer> window = new HashMap<>();
            int left = offset;
            int used = 0;

            for (int right = offset; right + wordLength <= s.length(); right += wordLength) {
                String word = s.substring(right, right + wordLength);
                if (!need.containsKey(word)) {
                    window.clear();
                    used = 0;
                    left = right + wordLength;
                    continue;
                }

                window.put(word, window.getOrDefault(word, 0) + 1);
                used++;
                while (window.get(word) > need.get(word)) {
                    String leftWord = s.substring(left, left + wordLength);
                    window.put(leftWord, window.get(leftWord) - 1);
                    left += wordLength;
                    used--;
                }

                if (used == wordCount) {
                    answer.add(left);
                    String leftWord = s.substring(left, left + wordLength);
                    window.put(leftWord, window.get(leftWord) - 1);
                    left += wordLength;
                    used--;
                }
            }
        }
        return answer;
    }
}

    from collections import Counter, defaultdict
from typing import List


class Solution:
    def findSubstring(self, s: str, words: List[str]) -> List[int]:
        answer = []
        word_length = len(words[0])
        word_count = len(words)
        total_length = word_length * word_count
        if total_length > len(s):
            return answer

        need = Counter(words)
        for offset in range(word_length):
            window = defaultdict(int)
            left = offset
            used = 0

            for right in range(offset, len(s) - word_length + 1, word_length):
                word = s[right : right + word_length]
                if word not in need:
                    window.clear()
                    used = 0
                    left = right + word_length
                    continue

                window[word] += 1
                used += 1
                while window[word] > need[word]:
                    left_word = s[left : left + word_length]
                    window[left_word] -= 1
                    left += word_length
                    used -= 1

                if used == word_count:
                    answer.append(left)
                    left_word = s[left : left + word_length]
                    window[left_word] -= 1
                    left += word_length
                    used -= 1

        return answer
