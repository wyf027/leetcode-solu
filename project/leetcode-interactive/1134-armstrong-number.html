Problem brief

题目说明

给定一个正整数 n，判断它是否为阿姆斯特朗数。

定义

若 n 一共有 k 位，且它的十进制数字依次为 d₁, d₂, …, dₖ，当且仅当下式成立时，n 是阿姆斯特朗数：

n = d₁ᵏ + d₂ᵏ + … + dₖᵏ

函数应在等式成立时返回 true，否则返回 false。

函数签名

isArmstrong(n: integer) → boolean

约束

  • 1 <= n <= 10^8
  • n 为十进制正整数。
示例 1true
输入n = 153
输出true

说明：153 有 3 位，且 1³ + 5³ + 3³ = 153。

示例 2false
输入n = 123
输出false

说明：123 有 3 位，而 1³ + 2³ + 3³ = 36 ≠ 123。

逐位拆解与幂和

核心洞察

指数不是固定的 3，而是数字的十进制位数 k。因此先确定 k，再依次取出每一位 d，把 d^k 加入总和，最后与原数比较。

完整过程

  1. 保存原数 n，计算它的十进制位数 k。
  2. 令工作变量 x = n、累计值 sum = 0。
  3. 反复用 x % 10 取得最低位，用整数除法 x / 10 删除该位。
  4. 每取得一位 d，累计 d^k。
  5. 所有位处理完后返回 sum == n。

正确性证明

循环不变式：每次循环开始时，sum 恰好等于已经从 x 末尾移除的所有数字的 k 次幂之和。

初始化：尚未移除任何数字，sum = 0，不变式成立。

保持：一次循环取出最低位 d，把 d^k 加入 sum，再从 x 删除该位，因此不变式继续成立。

终止：当 x = 0 时，原数的每一位都已处理，所以 sum 等于所有数字的 k 次幂之和。此时 sum == n 当且仅当 n 是阿姆斯特朗数。

边界情况

  • 一位正整数总满足 d = d¹，因此都返回 true。
  • 数字内部的 0 必须保留在位数统计中；它的贡献是 0^k = 0。
  • 不要在拆位后用已经变为 0 的工作变量与结果比较，应保留原数。
  • 使用足够宽的累计类型，可避免幂和在更宽松约束下溢出。

复杂度

设 k 为十进制位数。按固定宽度整数运算模型，遍历每一位一次，时间复杂度为 O(k)，空间复杂度为 O(1)。若把快速幂内部的乘法次数也展开计入，则时间可写作 O(k log k)；本题位数很小。

替代方案

可以先把数字转为字符串，再遍历字符并求幂，写法直观但使用了 O(k) 的字符串空间。也可以预先计算 0 到 9 的 k 次幂表，避免相同数字重复求幂。

常见错误

  • 把指数写死为 3，只能碰巧处理三位数。
  • 先拆位再计算位数，导致工作变量已经被清空。
  • 用浮点结果直接参与更大整数比较，忽略精度或溢出风险。
  • 漏掉整数除法，使循环无法结束或产生小数。

面试追问

  • 不用字符串，如何求十进制位数？
  • 如果输入范围扩展到 64 位，应怎样处理溢出？
  • 连续判断很多个同位数整数，如何复用幂值？
  • 能否在累计和已经大于 n 时提前返回？为什么安全？
  • 若输入以字符串形式给出且超过机器整数范围，怎样实现？

class Solution {
    public boolean isArmstrong(int n) {
        int digits = String.valueOf(n).length();
        int current = n;
        long sum = 0;

        while (current > 0) {
            int digit = current % 10;
            sum += intPow(digit, digits);
            current /= 10;
        }

        return sum == n;
    }

    private long intPow(int base, int exponent) {
        long result = 1;
        for (int i = 0; i < exponent; i++) {
            result *= base;
        }
        return result;
    }
}
