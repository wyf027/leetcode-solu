面试题 05.08 中等 · 位运算 / 数组 / 数学

绘制直线 32 位像素冲印台

单色屏幕被压进一卷卷 32 位胶片。指定同一行中的 (x1, y) 到 (x2, y)，把这段像素从 0 曝光为 1，并返回完整整数数组。

Film specification

WORD / 32 PX
偏移 0 / 最高位偏移 31 / 最低位

坐标原点

左上角 (0, 0)

宽度要求

w % 32 === 0

Problem brief

题意与边界

长度为 length 的整数数组可容纳 length × 32 个像素。每行宽 w 像素，整数不会横跨两行。只修改第 y 行、从 x1 到 x2 的闭区间。

  • 1 <= length <= 10^5
  • 1 <= w <= 3 × 10^5，且 w 可被 32 整除
  • 0 <= x1 <= x2 < w
  • 0 <= y <= 10，用例保证目标行位于屏幕内

示例 1 · 同一整数末尾

输入
length = 1, w = 32, x1 = 30, x2 = 31, y = 0
输出
[3]

示例 2 · 整行三整数

输入
length = 3, w = 96, x1 = 0, x2 = 95, y = 0
输出
[-1, -1, -1]

本题没有字符串输入；若后续题目出现字符串，页面会用 ␠ 显示空格并保留成对直引号。

    Interview answer

    题解

    核心洞察、完整过程与四语言代码默认隐藏。

    核心洞察

    两扇快门 + 中间整卷

    像素偏移 0 对应整数最高位。先定位目标行，再构造从 x1 向右全开的左掩码、从最高位到 x2 全开的右掩码。同卷取交集；跨卷分别写两端，中间整卷直接写 -1。

    完整过程

    1. 1. wordsPerRow = w / 32。
    2. 2. rowBase = y × wordsPerRow。
    3. 3. 求起止整数下标与卷内偏移。
    4. 4. 同卷写 leftMask & rightMask。
    5. 5. 跨卷写两端掩码，中间写 -1。

    边界

    • x1 = x2：交集只保留一个像素。
    • x1 % 32 = 0：左掩码全为 1。
    • x2 % 32 = 31：右掩码全为 1。
    • 同卷必须取交集，不能先后覆盖。
    • JavaScript 与 Python 要处理 32 位有符号结果。

    复杂度

    设触及整数数为 k。绘制本身 O(k)；创建长度为 length 的输出后，总时间 O(length + k)，即 O(length)。输出空间 O(length)，额外空间 O(1)。

    替代方案

    逐像素模拟

    从 x1 枚举到 x2，逐个设置 1 << (31 - x % 32)。它直观但重复位运算更多，未利用整字批量处理。

    面试追问

    • 已有屏幕不全为 0 时，赋值如何改成按位或？
    • w 不能被 32 整除时如何屏蔽行尾无效位？
    • 画矩形时如何逐行复用掩码？
    • 压缩单位改为 64 位时类型如何调整？

    常见错误

    把像素偏移 0 当成最低位，整条线左右镜像。

    忘记加 rowBase，所有线都画在第 0 行。

    同卷时用按位或合并快门，错误地点亮整卷。

    在 C++ 中对负数左移，触发未定义或实现相关行为。

    class Solution {
    public int[] drawLine(int length, int w, int x1, int x2, int y) {
        int[] screen = new int[length];
        int wordsPerRow = w / 32;
        int startWord = y * wordsPerRow + x1 / 32;
        int endWord = y * wordsPerRow + x2 / 32;
        int leftMask = -1 >>> (x1 % 32);
        int rightMask = -1 << (31 - x2 % 32);
        if (startWord == endWord) {
            screen[startWord] = leftMask & rightMask;
            return screen;
        }
        screen[startWord] = leftMask;
        screen[endWord] = rightMask;
        for (int word = startWord + 1; word < endWord; word++) {
            screen[word] = -1;
        }
        return screen;
    }
}

 * @param {number} length

var drawLine = function (length, w, x1, x2, y) {
    const screen = new Array(length).fill(0);
    const wordsPerRow = w / 32;
    const startWord = y * wordsPerRow + Math.floor(x1 / 32);
    const endWord = y * wordsPerRow + Math.floor(x2 / 32);
    const leftMask = (-1 >>> (x1 & 31)) | 0;
    const rightMask = (-1 << (31 - (x2 & 31))) | 0;
    if (startWord === endWord) {
        screen[startWord] = (leftMask & rightMask) | 0;
        return screen;
    }
    screen[startWord] = leftMask;
    screen[endWord] = rightMask;
    for (let word = startWord + 1; word < endWord; word += 1) {
        screen[word] = -1;
    }
    return screen;
};
    from typing import List


class Solution:
    def drawLine(
        self, length: int, w: int, x1: int, x2: int, y: int
    ) -> List[int]:
        screen = [0] * length
        words_per_row = w // 32
        start_word = y * words_per_row + x1 // 32
        end_word = y * words_per_row + x2 // 32
        full = (1 << 32) - 1
        left_mask = full >> (x1 % 32)
        right_mask = (full << (31 - x2 % 32)) & full
        if start_word == end_word:
            screen[start_word] = left_mask & right_mask
        else:
            screen[start_word] = left_mask
            screen[end_word] = right_mask
            for word in range(start_word + 1, end_word):
                screen[word] = full
        sign_bit = 1 << 31
        return [
            value if value < sign_bit else value - (1 << 32)
            for value in screen
        ]
