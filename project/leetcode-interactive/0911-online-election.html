在线选举Online Election

把每一次投票压缩成一张“当时的领先者快照”，查询时只需沿时间轴找到不晚于 t 的最后一个时刻。

MEDIUM数组哈希表二分查找非付费题

题目转述

给定等长整数数组 persons 与 times：第 i 张票在严格递增的时刻 times[i] 投给候选人 persons[i]。

实现 TopVotedCandidate(persons, times)，并让 q(t) 返回时刻 t 的领先者。恰好在 t 投出的票计入统计；票数相同时，最近获得一票的候选人领先。

关键语义：平票不是保持旧领先者，而是让本次刚得票的人领先。

约束

  • 1 ≤ persons.length ≤ 5000
  • times.length == persons.length
  • 0 ≤ persons[i] < persons.length
  • 0 ≤ times[i] ≤ 10⁹，且严格递增
  • times[0] ≤ t ≤ 10⁹
  • q 最多调用 10⁴ 次

官方示例

输入
["TopVotedCandidate", "q", "q", "q", "q", "q", "q"]
[[[0,1,1,0,0,1,0], [0,5,10,15,20,25,30]], [3], [12], [25], [15], [24], [8]]

输出
[null, 0, 1, 1, 0, 0, 1]

例如 q(25) 统计前六票，候选人 0 与 1 各得三票；时刻 25 的最近一票投给 1，因此返回 1。

题解：预处理快照 + 二分查找

核心洞察

所有查询共享同一条投票时间轴。构造时维护每位候选人的累计票数，并把每一票发生后谁领先记录在 leaders[i]。查询无需重新计票。

处理第 i 票后，如果得票者的票数 大于或等于 当前领先者票数，就把他设为新领先者。这里的 ≥ 恰好编码了平票时“最近得票者胜出”。

完整过程

初始化计数表、当前领先者和 leaders 数组。
依次给 persons[i] 加一票；若其票数不少于当前领先者，更新领先者。
把当前领先者写入 leaders[i]。
对查询 t，二分找最大的 i 使 times[i] ≤ t，返回 leaders[i]。

正确性说明

构造不变式：处理完第 i 票后，计数表等于前 i+1 票的真实票数，leaders[i] 等于该时刻按规则选出的领先者。

第 i 票只增加其得票者的计数。若其票数超过当前领先者，他必然领先；若相等，他因刚获得最近一票而领先；若更少，领先者不变。因此不变式归纳成立。二分返回不晚于 t 的最后一票下标，而两票之间状态不变，所以查询结果正确。

边界与易错点

  • t == times[i] 时必须包含第 i 票。
  • 更新领先者使用 ≥，不能写成 >。
  • 二分要找“最后一个 ≤ t”，不是精确匹配。
  • 候选人编号不代表连续出现，使用哈希表或按约束大小的数组计数。

替代方案

每次查询从头计票需要 O(n)；记录领先者变化区间可减少快照数量，但实现更复杂，最坏仍为 O(n) 空间。当前方案更直接稳定。

class TopVotedCandidate {
    private final int[] times;
    private final int[] leaders;

    public TopVotedCandidate(int[] persons, int[] times) {
        this.times = times;
        this.leaders = new int[persons.length];
        int[] count = new int[persons.length];
        int leader = -1;
        for (int i = 0; i < persons.length; i++) {
            int person = persons[i];
            count[person]++;
            if (leader == -1 || count[person] >= count[leader]) {
                leader = person;
            }
            leaders[i] = leader;
        }
    }

    public int q(int t) {
        int left = 0, right = times.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (times[mid] <= t) left = mid + 1;
            else right = mid;
        }
        return leaders[left - 1];
    }
}

from bisect import bisect_right
from typing import List

class TopVotedCandidate:
    def __init__(self, persons: List[int], times: List[int]):
        self.times = times
        self.leaders = []
        count = {}
        leader = -1
        for person in persons:
            count[person] = count.get(person, 0) + 1
            if leader == -1 or count[person] >= count[leader]:
                leader = person
            self.leaders.append(leader)

    def q(self, t: int) -> int:
        index = bisect_right(self.times, t) - 1
        return self.leaders[index]

    vector<int> leaders;
public:
    TopVotedCandidate(vector<int>& persons, vector<int>& times)
        : times(times), leaders(persons.size()) {
        unordered_map<int, int> count;
        int leader = -1;
        for (int i = 0; i < (int)persons.size(); ++i) {
            int person = persons[i];
            ++count[person];
            if (leader == -1 || count[person] >= count[leader]) {
                leader = person;
            }
            leaders[i] = leader;
        }
    }

    int q(int t) {
        int index = upper_bound(times.begin(), times.end(), t)
                  - times.begin() - 1;
        return leaders[index];
    }

复杂度

构造遍历 n 张票，时间 O(n)、额外空间 O(n)。每次查询进行一次二分，时间 O(log n)。

常见错误

  • 平票时没有更新为本次得票者。
  • 查询落在两次投票之间时取了后一票。
  • 每次查询重新扫描全部历史。

面试追问

  • 如果投票实时到达，如何支持追加？
  • 如果还要撤销某张票，当前快照方案为何不再适用？
  • 如何把快照压缩为“领先者变化点”？
  • 为什么 upper_bound(t) - 1 正好包含时刻 t 的票？
