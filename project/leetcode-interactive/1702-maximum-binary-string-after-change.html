Problem

题目说明

非付费题

给定一个只由 0 和 1 组成的字符串 binary。你可以任意多次选取相邻的两个字符，并使用以下任一合法操作：

操作 1发现 00 时，可以替换成 10。
操作 2发现 10 时，可以替换成 01。

返回通过这些操作能够得到的最大二进制字符串。长度相同的二进制串按其对应的十进制数比较大小，也等价于从左到右比较字典序。

官方示例

示例 1
输入：binary = "000110"
输出："111011"
解释：一种可行过程为：
"000110" → "000101"
→ "100101" → "110101"
→ "110011" → "111011"
示例 2
输入：binary = "01"
输出："01"
解释："01" 无法再进行任何操作。

约束

  • 1 <= binary.length <= 10^5
  • binary 仅包含字符 '0' 与 '1'

Solution

贪心：最后只留下一个零

O(n) / O(n)
核心洞察：如果字符串含零，最优结果会只剩一个零。设第一个零的位置为 first，零的总数为 zeros，唯一的零最终位于 first + zeros - 1，其余位置全是 1。
answer = "1" × n；answer[first + zeros - 1] = '0'

完整过程

  1. 从左到右找到第一个 0。它前面的全 1 前缀不会被任何操作改变。
  2. 统计整个字符串中的零数 zeros。若没有零，原串已经最大，直接返回。
  3. 在第一个零之后，利用 10 → 01 可以把被 1 隔开的零向左聚拢，形成一段连续的零。
  4. 对连续零从左到右反复使用 00 → 10；每次消掉一个零，并让最后保留的零向右一格。
  5. 因此从 first 开始的 zeros 个零最终变成 zeros - 1 个 1 加一个 0，零停在 first + zeros - 1。

以 000110 为例

第一个零下标是 0，共有 4 个零，所以最终唯一零的下标是 0 + 4 - 1 = 3；把长度 6 的结果先填满 1，再把下标 3 改成 0，得到 111011。

正确性证明

引理 1：第一个零之前的全 1 前缀不可改变，因为两种操作都必须以 0 参与，且没有操作会把零移动到这个前缀中。

引理 2：若至少有一个零，则无法消掉最后一个零；10 → 01 不改变零数，而 00 → 10 需要两个零且每次仅减少一个。因此最优解至少保留一个零。

引理 3：通过 10 → 01 可将首个零之后的所有零跨过中间的 1 向左聚集。随后对零块连续执行 00 → 10，可构造出前 zeros - 1 位为 1、最后一位为 0 的形态。

结论：该构造保留不可变的全 1 前缀，消掉所有可能消掉的零，并让唯一零落在所能达到的最右位置 first + zeros - 1。因此得到的字符串字典序最大，也就是数值最大。

时间复杂度O(n)，一次扫描找首零并计数。
空间复杂度O(n)，构造可变结果字符数组。
关键边界全为 1、只有一个零、全为 0、零位于末尾。

替代方案

可以真的模拟两种替换，但操作次数可能很多，并且反复修改字符串代价高，难以满足 10^5 的规模。也可以先显式整理零块再替换，但这只是把同一贪心结论写得更绕；直接计算唯一零的位置更简洁。

class Solution {
    public String maximumBinaryString(String binary) {
        int first = binary.indexOf('0');
        if (first == -1) {
            return binary;
        }

        int zeros = 0;
        for (int i = first; i < binary.length(); i++) {
            if (binary.charAt(i) == '0') {
                zeros++;
            }
        }

        char[] answer = new char[binary.length()];
        java.util.Arrays.fill(answer, '1');
        answer[first + zeros - 1] = '0';
        return new String(answer);
    }
}

 * @param {string} binary

var maximumBinaryString = function(binary) {
    const first = binary.indexOf('0');
    if (first === -1) {
        return binary;
    }

    let zeros = 0;
    for (let i = first; i < binary.length; i++) {
        if (binary[i] === '0') {
            zeros++;
        }
    }

    const answer = Array(binary.length).fill('1');
    answer[first + zeros - 1] = '0';
    return answer.join('');
};
class Solution:
    def maximumBinaryString(self, binary: str) -> str:
        first = binary.find("0")
        if first == -1:
            return binary

        zeros = binary.count("0")

public:

面试追问

  • 为什么必须保留至少一个零？哪条操作决定了这个下界？
  • 如何从“局部替换”跳到“只算首零位置与零数”的整体结论？
  • 若把第二条规则改成 01 → 10，贪心方向会发生什么变化？
  • 能否原地修改输入？在 Java、JavaScript、Python 中字符串不可变会带来什么影响？

常见错误

  • 把最终零的位置误写成 first + zeros，产生下标偏一。
  • 没处理全 1 字符串，导致 first = -1 后访问非法位置。
  • 认为结果一定全为 1；最后一个零没有第二个零与它组成 00，无法消除。
  • 逐字符反复替换，既复杂又可能退化为平方时间。
