打家劫舍 IV

House Robber IV · 在不触发相邻警报的前提下，找出偷到至少 k 间房所需的最低能力。

◈先读题并动手调试；完整题解默认收起，不会在首屏剧透。

Problem

题目描述

一条街上有一排连续房屋，整数数组 nums 中的 nums[i] 表示第 i 间房内的现金。小偷不能进入两间相邻的房屋。

给定整数 k，小偷需要进入至少 k 间房。请返回所有合法方案中最小的窃取能力；题目保证总能选出至少 k 间互不相邻的房屋。

窃取能力：某个方案所选房屋金额的最大值。目标不是让总金额最小，而是让这个“单间最大金额”尽可能小。
约束
  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁹
  • 1 ≤ k ≤ (nums.length + 1) / 2

函数签名：minCapability(nums, k) → integer

示例 1能力 = 5
输入：nums = [2,3,5,9], k = 2 输出：5

选择下标 0、2，能力为 max(2,5)=5；另外两种至少选两间的合法方案能力均为 9，因此最小值是 5。

示例 2能力 = 2
输入：nums = [2,7,9,3,1], k = 2 输出：2

选择下标 0、4，两间不相邻，方案能力为 max(2,1)=2，且无法得到更低的能力。

完整题解

包含证明、复杂度、四语言代码与面试追问。

二分答案 + 贪心判定

1 · 转换问题猜一个能力上限 x，只允许选择金额不超过 x 的房屋，问题变为：能否选出至少 k 间互不相邻的房屋？
2 · 单调性若上限 x 可行，那么更大的上限也一定可行；若 x 不可行，更小的上限也不可能可行。
3 · 贪心判定从左向右扫描，遇到可选房屋就立刻选，并跳过其相邻房屋。这样能得到当前上限下最多的选择数。

完整过程

  1. 答案一定在 [min(nums), max(nums)] 内。
  2. 取中点 mid 作为能力上限，线性扫描街道。
  3. 若 nums[i] ≤ mid，选择第 i 间，并让下一个候选下标变为 i + 2；否则只前进一格。
  4. 若能选到至少 k 间，说明 mid 可行，继续搜索更小值；否则提高下界。
  5. 当左右边界重合时，该值就是最小可行能力。
正确性证明

贪心判定正确：对任意能力上限 x，设扫描到的第一间可选房屋为 i。任何合法选择的第一间房都不可能早于 i；若某个最优选择先选了更靠后的 j，将 j 替换为 i 不会破坏与后续房屋的不相邻关系，且选择数量不减。重复该交换，可得到与贪心一致且选择数同样多的方案，因此贪心能判断是否可选至少 k 间。

二分正确：可行性随能力上限单调不减。二分始终保留最小可行答案所在区间；可行时收缩右界，不可行时抬高左界。终止时两界相等，且该值可行、所有更小值不可行，因此它正是最小能力。

边界与复杂度

  • n = 1, k = 1：答案就是唯一金额。
  • k = (n+1)/2：可能被迫选择所有偶数位或奇数位的一组。
  • 重复金额不会影响单调性与判定。
  • 时间：O(n log V)，其中 V = max(nums)-min(nums)+1。
  • 额外空间：O(1)。

替代方案

也可对去重后的金额排序，再二分这些候选值，复杂度为 O(n log n) 且需要额外空间；数值区间二分通常更直接。

固定上限时也能用动态规划计算最多可选数量，但本题只关心能否达到 k，一维路径上的“尽早选”贪心已经足够。

常见错误

  • 把目标误解为最小化所选房屋的总金额。
  • 判定时选中一间后仍检查紧邻的下一间。
  • 可行时写成 left = mid + 1，搜索方向反了。
  • 用 0 到 10⁹ 作为边界虽可行，但没有利用输入缩小区间。
  • 只判断恰好选 k 间；题意是至少 k 间。

面试追问

  • 为什么最左优先不会让未来选择变少？请用交换论证回答。
  • 如果房屋首尾也相邻（环形街道），判定函数如何修改？
  • 如果相邻距离小于 d 都不能选，应如何跳步？
  • 若要求返回一组具体下标，在哪里记录选择最合适？

class Solution {
    public int minCapability(int[] nums, int k) {
        int left = nums[0], right = nums[0];
        for (int value : nums) {
            left = Math.min(left, value);
            right = Math.max(right, value);
        }

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (canRob(nums, k, mid)) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return left;
    }

    private boolean canRob(int[] nums, int k, int limit) {
        int count = 0;
        for (int i = 0; i < nums.length;) {
            if (nums[i] <= limit) {
                count++;
                if (count >= k) return true;
                i += 2;
            } else {
                i++;
            }
        }
        return false;
    }
}

        def can_rob(limit: int) -> bool:
            count = 0
            i = 0
            while i < len(nums):
                if nums[i] <= limit:
                    count += 1
                    if count >= k:
