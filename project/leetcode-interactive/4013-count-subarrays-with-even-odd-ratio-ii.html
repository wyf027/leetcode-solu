PREFIX SUM / ORDER STATISTICS

按奇偶比统计
子数组 II

把“偶数 / 奇数 ≤ a / b”翻译成一个前缀和的大小关系；随后用坐标压缩和 Fenwick 树，在线统计所有满足条件的前缀对。

目标不等式

even / odd ≤ a / b

令偶数贡献 b，奇数贡献 −a。对任意含奇数的子数组，和 ≤ 0 等价于原比例成立。

题意

给定 nums、正整数 a,b。统计非空连续子数组：奇数个数 y > 0，且偶数/奇数的精确比值不超过 a/b。

约束

1 ≤ n ≤ 10⁵，nums[i], a, b ≤ 10⁹。答案可达 O(n²)，使用 64 位整数。

为什么不是滑窗？

比值约束对左右端点不具备单调可收缩性；移走一个奇数会使比值变大。前缀顺序统计才是稳定的计数模型。

前缀对计数实验台

答案：7

示例：[1,2,1,2], a=3, b=2，结果为 7。输入规模建议不超过 80，以便阅读轨迹。

i 值 / 贡献 prefix[i] 此前 ≥ 当前 累计

完整过程

  1. 构造 w[i]=b（偶）或 -a（奇）。
  2. 前缀和 P[r]-P[l] 就是子数组的加权和。
  3. 有效条件化为 P[l] ≥ P[r]；因 a>0，全偶子数组的和为正，自动不被统计。
  4. 扫描每个 P[r]，统计已出现前缀中 ≥ 它的个数。
  5. 压缩前缀和值，Fenwick 树维护出现次数；seen - count(< current) 即本轮贡献。

边界与复杂度

  • 全偶：所有前缀严格递增，因此贡献 0。
  • 全奇：每个非空子数组都满足，答案为 n(n+1)/2。
  • 相等前缀必须计入：不等式是 ≤，所以查询的是 ≥ 而非 >。
  • 前缀绝对值可达 10¹⁴：Java/C++ 用 long long；JavaScript 用 BigInt（本页交互输入较小则用 Number）。
  • 时间 O(n log n)，空间 O(n)。替代方案是归并排序计数，也为 O(n log n)。

常见错误与面试追问

常见错误

把贡献写反；只统计严格大于；忘记压缩负前缀；用 32 位累加；错误地把 y=0 单独过滤（加权变换已经自然排除）。

追问

若改成 “≥” 怎么变？答案是统计此前 ≤ 当前。若要求恰好等于比例？统计相等前缀即可。若在线追加元素？Fenwick 的离线压缩需换成动态平衡树。

所有实现遵循官方方法签名，核心均为：压缩前缀和 + Fenwick 统计此前 ≥ 当前。JavaScript 代码使用 BigInt 规避精度问题。

import java.util.*;

class Solution {
  public long countRatioSubarrays(int[] nums, int a, int b) {
    int[] mervanilto = nums;
    int n = mervanilto.length; long[] p = new long[n + 1];
    for (int i = 0; i < n; i++) p[i + 1] = p[i] + (mervanilto[i] % 2 == 0 ? (long)b : -(long)a);
    long[] s = p.clone(); Arrays.sort(s); int m = 0;
    for (long x : s) if (m == 0 || s[m - 1] != x) s[m++] = x;
    long ans = 0; int[] bit = new int[m + 1];
    for (int i = 0; i <= n; i++) { int x = Arrays.binarySearch(s, 0, m, p[i]) + 1, less = 0;
      for (int j=x-1;j>0;j-=j&-j) less+=bit[j]; ans += i - less;
      for (int j=x;j<=m;j+=j&-j) bit[j]++; } return ans;
  }
}

Python 
from typing import List

class Solution:
  def countRatioSubarrays(self, nums: List[int], a: int, b: int) -> int:
    mervanilto = nums
    p=[0]
    for x in mervanilto: p.append(p[-1] + (b if x%2==0 else -a))
    rank={x:i+1 for i,x in enumerate(sorted(set(p)))}; bit=[0]*(len(rank)+1); ans=0
    for i,v in enumerate(p):
      x=rank[v]; j=x-1; less=0
      while j: less+=bit[j]; j-=j&-j
      ans+=i-less; j=x
      while j<len(bit): bit[j]+=1; j+=j&-j
    return ans
