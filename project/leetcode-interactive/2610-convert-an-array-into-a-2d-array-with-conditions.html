Problem

题意与约束

任务

给定整数数组 nums，构造一个二维数组，满足：

  • 二维数组中的元素与 nums 完全相同，每个元素按原有次数使用；
  • 每一行中的整数互不相同；
  • 使用的行数最少。

每行长度可以不同；若答案不唯一，返回任意一个合法结果。

函数形式
findMatrix(nums: integer[]) → integer[][]

约束

  • 1 <= nums.length <= 200
  • 1 <= nums[i] <= nums.length

这意味着可以直接用长度为 n + 1 的计数数组记录每个值已经出现的次数。

官方示例 01
输入：nums = [1,3,4,1,2,3,1] 输出：[[1,3,4,2],[1,3],[1]] 解释：三行分别可以是 1,3,4,2 / 1,3 / 1。 所有元素都被使用，且每行内部无重复；无法用少于 3 行完成。
官方示例 02
输入：nums = [1,2,3,4] 输出：[[4,3,2,1]] 解释：所有元素本来就互不相同，因此放在同一行即可。

Complete Solution

按出现次数分层

第 k 次遇到某个值，就把它放到第 k 行（下标 k - 1）。一遍扫描即可同时保证行内唯一和行数最少。

核心洞察

若数字 x 一共出现 f(x) 次，因为同一行不能重复出现 x，这些副本至少需要分布在 f(x) 行中。因此，任何答案的行数都不小于所有频次的最大值。

最少行数 ≥ max f(x)

扫描时，令 count[x] 表示此前已见过多少个 x。当前这个 x 放进第 count[x] 行，然后计数加一。构造出的行数恰好等于最大频次，于是命中下界。

完整过程

  1. 创建计数数组 count 和空答案 ans。
  2. 依次读取每个 x，取 row = count[x]。
  3. 若第 row 行尚不存在，就新建一行。
  4. 把 x 加到该行，再令 count[x]++。
  5. 扫描结束后返回 ans。

正确性证明

引理 1：每个输入元素被恰好放置一次

算法逐个遍历 nums，每次循环只把当前元素加入答案一次，不删除也不复制。因此答案包含且仅包含输入的全部元素，并保留每个值的出现次数。

引理 2：每一行中的元素互不相同

某个值 x 的第 1、2、…、k 次出现分别进入第 0、1、…、k-1 行，所以同一个值绝不会两次进入同一行。

引理 3：行数最少

设最大出现次数为 M。任意合法答案至少需要 M 行；本算法对出现 M 次的值只会创建到第 M-1 行，总行数正好为 M。因此行数达到下界，必然最少。

结论：算法返回的二维数组满足全部条件，并使用最少行数。

边界情况

  • 只有一个元素：答案只有一行。
  • 所有元素互不相同：全部进入第 0 行。
  • 所有元素相同：每个元素单独占一行。
  • 多种合法排列：题目允许返回任意一种，不要求保持示例顺序。

复杂度

时间：O(n)，每个元素处理一次。

额外空间：O(n)，计数数组最多使用 n + 1 个位置；返回结果本身也包含 n 个元素。

Java 
class Solution {
    public List<List<Integer>> findMatrix(int[] nums) {
        int[] count = new int[nums.length + 1];
        List<List<Integer>> ans = new ArrayList<>();

        for (int x : nums) {
            int row = count[x]++;
            if (row == ans.size()) {
                ans.add(new ArrayList<>());
            }
            ans.get(row).add(x);
        }
        return ans;
    }
}

var findMatrix = function(nums) {
    const count = Array(nums.length + 1).fill(0);
    const ans = [];

    for (const x of nums) {
        const row = count[x]++;
        if (row === ans.length) ans.push([]);
        ans[row].push(x);
    }
    return ans;
};
Python 
class Solution:
    def findMatrix(self, nums: list[int]) -> list[list[int]]:
        count = [0] * (len(nums) + 1)
        ans = []

        for x in nums:
            row = count[x]
            count[x] += 1
            if row == len(ans):
                ans.append([])
            ans[row].append(x)

        return ans

class Solution {
public:
    vector<vector<int>> findMatrix(vector<int>& nums) {
        vector<int> count(nums.size() + 1);

Trade-offs

替代方案

逐行尝试放置

对每个数字依次检查已有行，找到不含该值的第一行。容易想到，但若每行都线性查重，最坏可到 O(n²)；使用集合又会增加结构与常数。

先统计再按轮次分发

先统计频次，再让每个值向前 f(x) 行各放一个，同样是 O(n)。它需要两阶段处理；单次扫描的“第几次出现进第几行”更直接。

面试追问

  • 为什么一定最优？ 用最高频元素给出行数下界，再证明构造恰好达到它。
  • 若 nums[i] 不再受 n 限制？ 把计数数组换成哈希表，核心逻辑不变。
  • 若要求每行长度尽量均衡？ 当前构造本身会产生前缀形状；若还有额外排序或容量约束，需要重新定义分配策略。
  • 能否原地完成？ 返回二维结构本身不可避免；计数仍需保存，除非允许破坏输入并利用其值域编码。

常见错误

  • 把“行内不同”误读成整个二维数组不能重复。
  • 只判断答案最后一行，导致重复值仍进入同一行。
  • 先递增计数再直接使用，造成行下标整体偏一。
  • 强行让输出顺序与示例一致；题目实际接受任意合法答案。
  • 声称空间为 O(1)，忽略计数结构或返回结果。
