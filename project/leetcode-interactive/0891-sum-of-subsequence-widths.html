子序列宽度之和

Sum of Subsequence Widths

序列的宽度是其中最大值与最小值之差。给定整数数组 nums，求所有非空子序列的宽度总和，并对 10⁹ + 7 取模。子序列可以删除任意元素，但保留元素的相对顺序。

示例

示例 1

输入：nums = [2,1,3]

输出：6

7 个非空子序列的宽度依次为 0、0、0、1、1、2、2，总和为 6。

示例 2

输入：nums = [2]

输出：0

约束与签名

  • 1 <= nums.length <= 10⁵
  • 1 <= nums[i] <= 10⁵
  • 函数：sumSubseqWidths(nums)
  • 返回：整数（模 1,000,000,007）

Solution

排序后的正负贡献

核心洞察

将数组升序排序为 a。对位置 i：选它作为最大值时，左侧 i 个元素可任意选，共 2ⁱ 种；选它作为最小值时，右侧 n-1-i 个元素可任意选，共 2ⁿ⁻¹⁻ⁱ 种。因此它的净贡献是：

a[i] × (2ⁱ − 2ⁿ⁻¹⁻ⁱ)

完整过程

  1. 升序排序，使每个位置两侧的大小关系确定。
  2. 从左到右维护 2ⁱ mod MOD。
  3. 累加 (a[i] - a[n-1-i]) × 2ⁱ。这是将最大值正贡献与镜像位置的最小值负贡献合并后的等价写法。
  4. 每次取模，并在返回前把负余数调整到非负范围。

正确性说明

固定排序后的位置 i。包含 a[i] 且以它为最大值的子序列必须从其左侧任选元素，并且不能选择右侧元素，所以恰有 2ⁱ 个；同理，以它为最小值的子序列恰有 2ⁿ⁻¹⁻ⁱ 个。每个非空子序列在总和中恰好贡献一次最大值并减去一次最小值。对所有位置相加，正好得到全部子序列的宽度之和。重复值即使位置不同，贡献按下标计数后仍会相互正确抵消。

复杂度与边界

  • 排序：O(n log n)
  • 扫描：O(n)
  • 额外空间：取决于排序实现，幂值只需 O(1)
  • n = 1 时同一元素正负贡献抵消为 0。
  • JavaScript 乘法需用 BigInt 保证模运算精确。

替代方案与追问

  • 可预计算全部二次幂，写法更直观，但多用 O(n) 空间。
  • 面试追问：为什么原数组顺序不影响极值计数？
  • 面试追问：如何把两项公式合并成镜像下标写法？
  • 若要求动态插入元素，单次排序扫描不再够用，需要维护有序结构及幂权重。

常见错误

  • 枚举全部子序列，复杂度达到 O(2ⁿ)。
  • 最大值数量误写成 2ⁱ - 1；左侧全不选也是合法情况。
  • 忘记处理负余数，或在 Java / C++ 中使用 32 位整数相乘。
  • JavaScript 使用普通 Number 做大整数乘法，产生精度损失。

四语言完整代码

import java.util.Arrays;

class Solution {
    public int sumSubseqWidths(int[] nums) {
        final long MOD = 1_000_000_007L;
        Arrays.sort(nums);
        long ans = 0, power = 1;
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            ans = (ans + (nums[i] - (long) nums[n - 1 - i]) * power) % MOD;
            power = power * 2 % MOD;
        }
        return (int) ((ans + MOD) % MOD);
    }
}

var sumSubseqWidths = function(nums) {
    const MOD = 1000000007n;
    nums.sort((a, b) => a - b);
    let ans = 0n;
    let power = 1n;
    for (let i = 0; i < nums.length; i++) {
        const high = BigInt(nums[i]);
        const low = BigInt(nums[nums.length - 1 - i]);
        ans = (ans + (high - low) * power) % MOD;
        power = power * 2n % MOD;
    }
    return Number((ans + MOD) % MOD);
};
