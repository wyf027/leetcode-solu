Problem

题意

给定两棵可能很大的二叉树 T1 与 T2。判断能否在 T1 中找到一个节点，使以它为根的整棵子树与 T2 完全相同。

  • 相同意味着对应节点值相同，左右子树也分别相同。
  • 空节点的位置属于树的结构，不能忽略。
  • 节点数范围为 [0, 20000]。

Official examples

输入：t1 = [1,2,3], t2 = [2] 输出：true 输入：t1 = [1,null,2,4], t2 = [3,2] 输出：false

输入没有字符串参数；若使用序列化替代法，字符串须保留成对直引号，空格写作 ␠（可见空格）。

Core insight

先找切口，再验证整棵树

外层递归把 T1 的每个节点当作候选根；内层递归只回答一件事：从这两个根开始，值与左右结构是否完全相同。两种职责分开，最不容易漏掉“值相同但形状不同”的反例。

完整过程

  1. 若 T1 或 T2 为空，按题目“从某节点切下”的定义返回 false。
  2. 在当前 T1 节点调用 sameTree。
  3. 若完全一致立即返回 true；否则继续搜索 T1 的左右子树。
  4. sameTree 中，两空为 true；仅一空或值不同为 false。

边界

  • T2 为空：没有可作为切口的根节点，返回 false。
  • 重复值：不能在第一次值相等时失败后就停止搜索。
  • 只有部分节点相同：缺失或多出的孩子都会令匹配失败。
  • T1 与 T2 完全相同：根节点处直接成功。

复杂度

设 T1、T2 节点数为 n、m。最坏每个候选根都比较 T2，时间 O(nm)；递归栈最坏 O(h₁ + h₂)。

替代方案

用带空节点标记与分隔符的前序序列化，再用 KMP 查找，可做到 O(n + m)。例如 "4,#,6,5,#,#,7,#,#"；不能省略 #，否则不同结构会撞成同一序列。

面试追问

  • 节点值大量重复时，怎样降低重复比较？
  • 为何只有前序值序列不够？
  • 树深可能达到 20000 时，如何改成显式栈避免调用栈溢出？

常见错误

  • 只比较值集合或遍历序列，忽略空节点位置。
  • 遇到同值候选但结构不符后直接返回 false。
  • 把“包含 T2 的若干节点”误认为“完整子树”。
  • 内外两层递归共用错误的空树基线。
class Solution {
    public boolean checkSubTree(TreeNode t1, TreeNode t2) {
        if (t1 == null || t2 == null) {
            return false;
        }
        return sameTree(t1, t2)
                || checkSubTree(t1.left, t2)
                || checkSubTree(t1.right, t2);
    }

    private boolean sameTree(TreeNode a, TreeNode b) {
        if (a == null && b == null) {
            return true;
        }
        if (a == null || b == null || a.val != b.val) {
            return false;
        }
        return sameTree(a.left, b.left) && sameTree(a.right, b.right);
    }
}
var checkSubTree = function (t1, t2) {
  if (t1 === null || t2 === null) {
    return false;
  }

  const sameTree = (a, b) => {
    if (a === null && b === null) return true;
    if (a === null || b === null || a.val !== b.val) return false;
    return sameTree(a.left, b.left) && sameTree(a.right, b.right);
  };

  return (
    sameTree(t1, t2) ||
    checkSubTree(t1.left, t2) ||
    checkSubTree(t1.right, t2)
  );
};
class Solution:
    def checkSubTree(self, t1: TreeNode, t2: TreeNode) -> bool:
        if t1 is None or t2 is None:
            return False

        def same_tree(a: TreeNode, b: TreeNode) -> bool:
            if a is None and b is None:
                return True
            if a is None or b is None or a.val != b.val:
                return False
            return same_tree(a.left, b.left) and same_tree(a.right, b.right)

        return (
            same_tree(t1, t2)
            or self.checkSubTree(t1.left, t2)
            or self.checkSubTree(t1.right, t2)
        )
class Solution {
public:
    bool checkSubTree(TreeNode* t1, TreeNode* t2) {
        if (t1 == nullptr || t2 == nullptr) {
            return false;
        }
        return sameTree(t1, t2)
            || checkSubTree(t1->left, t2)
            || checkSubTree(t1->right, t2);
    }

private:
    bool sameTree(TreeNode* a, TreeNode* b) {
        if (a == nullptr && b == nullptr) {
            return true;
        }
        if (a == nullptr || b == nullptr || a->val != b->val) {
            return false;
        }
        return sameTree(a->left, b->left)
            && sameTree(a->right, b->right);
    }
};
