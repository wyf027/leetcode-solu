砍竹子 II

给定一根长度为 bamboo_len 的竹子，至少砍一刀，将其分成若干段正整数长度。求各段长度乘积的最大值，并对 1_000_000_007 取模。

题意与示例

你可以砍任意多刀，但必须至少砍一次。例如竹子长度为 12，分为 3 + 3 + 3 + 3 时乘积是 81，达到最大。

示例 1

输入：bamboo_len = 12
输出：81

示例 2

输入：bamboo_len = 2
输出：1

约束

  • 2 ≤ bamboo_len ≤ 1000
  • 答案需按 1,000,000,007 取模
  • 每一段长度均为正整数

分步交互

    核心洞察

    长度 ≥ 5 的一段，拆成 3 和剩余部分会使乘积变大：3 × (x - 3) ≥ x。因此不断取 3；但余数为 1 时不能留下 1，应把一个 3 与 1 合并为 2 + 2。最终只会出现若干个 3，外加一个 2 或 4。

    余数 0

    全部切成 3。

    余数 1

    保留一个 4，其余切成 3。

    余数 2

    保留一个 2，其余切成 3。

    完整过程

    1. 1. n ≤ 3 时必须砍一刀，答案是 n - 1。
    2. 2. 计算 n ÷ 3 的余数。
    3. 3. 按余数确定末尾乘数 1、2 或 4。
    4. 4. 用快速幂计算 3 的指数次方并取模。

    边界

    n = 2 → 1，n = 3 → 2；余数为 1 时必须调整，不能让乘积含有 1。

    复杂度

    快速幂时间 O(log n)，额外空间 O(1)。

    替代方案

    动态规划可枚举第一段长度，时间 O(n²)、空间 O(n)，更直观但不如贪心简洁。数学贪心依赖“3 最优”的结论。

    追问

    若不取模且 n 很大怎么办？需使用大整数；若允许不砍，则 n ≤ 3 的答案改为 n。

    常见错误

    • 忘记“至少砍一刀”，误返回 n。
    • 余数为 1 时直接乘 1。
    • 使用普通幂导致溢出或 O(n) 时间。

    题解与官方签名代码

    默认折叠；可用 Enter 或空格切换。

    下面四种实现均采用二分幂，将每次乘法立刻取模。 

    // Java
class Solution {
    public int cuttingBamboo(int bamboo_len) {
        if (bamboo_len <= 3) return bamboo_len - 1;
        final long MOD = 1_000_000_007L;
        int q = bamboo_len / 3, r = bamboo_len % 3;
        if (r == 1) return (int) (pow(3, q - 1, MOD) * 4 % MOD);
        if (r == 2) return (int) (pow(3, q, MOD) * 2 % MOD);
        return (int) pow(3, q, MOD);
    }
    private long pow(long a, int n, long mod) { long ans = 1; while (n > 0) { if ((n & 1) == 1) ans = ans * a % mod; a = a * a % mod; n >>= 1; } return ans; }
}
    // JavaScript
var cuttingBamboo = function(bamboo_len) {
  const MOD = 1000000007n;
  if (bamboo_len <= 3) return bamboo_len - 1;
  const pow = (a, n) => { let ans = 1n, base = BigInt(a); while (n) { if (n & 1) ans = ans * base % MOD; base = base * base % MOD; n >>= 1; } return ans; };
  const q = Math.floor(bamboo_len / 3), r = bamboo_len % 3;
  return Number(pow(3, q - (r === 1 ? 1 : 0)) * BigInt(r === 0 ? 1 : r === 1 ? 4 : 2) % MOD);
};

class Solution {
public:
    int cuttingBamboo(int bamboo_len) {
        const long long MOD = 1000000007LL;
        if (bamboo_len <= 3) return bamboo_len - 1;
        int q = bamboo_len / 3, r = bamboo_len % 3;
        if (r == 1) return power(3, q - 1) * 4 % MOD;
        if (r == 2) return power(3, q) * 2 % MOD;
        return power(3, q);
    }
private:
    long long power(long long a, int n) { long long ans = 1; while (n) { if (n & 1) ans = ans * a % 1000000007LL; a = a * a % 1000000007LL; n >>= 1; } return ans; }
};
