从树中删除边的最小分数

Minimum Score After Removals on a Tree

切断两条边，得到三个部分。如何让它们的异或值尽可能接近？

官方题目 ↗

01 / 题意与输入

给定一棵有 n 个节点的无向连通树，节点编号为 0 至 n − 1。数组 nums 存放各节点的值；edges 中的每个 [a, b] 表示连接 a 与 b 的一条边。

必须删除两条不同的边，形成三个连通分量。分别求每个分量内所有节点值的按位异或，然后用三个异或结果中的最大值减去最小值，作为这次切割的分数。返回所有合法切割方案中的最低分数。

异或不是求和。例如三个分量值为 [4,5,7]、[1,9]、[3,3,3] 时，异或分别为 6、8、3，分数是 8 − 3 = 5。

minimumScore(nums: integer[], edges: integer[][]) → integer

先尝试独立思考；算法、交互演示和代码均收在底部题解中。

示例 1

nums = [1,5,5,4,11]
edges = [[0,1],[1,2],[1,3],[3,4]]
输出：9

删除 [0,1]、[1,2] 后，分量节点为 [1,3,4]、[0]、[2]。对应异或为 5 ^ 4 ^ 11 = 10、1、5，分数为 10 − 1 = 9，不存在更低分数。

示例 2

nums = [5,5,2,4,4,2]
edges = [[0,1],[1,2],[5,2],[4,3],[1,3]]
输出：0

删除 [1,2]、[1,3] 后，分量节点为 [3,4]、[1,0]、[2,5]。异或分别为 4 ^ 4 = 0、5 ^ 5 = 0、2 ^ 2 = 0。分数为 0，已经无法更低。

输入约束

  • n == nums.length，3 ≤ n ≤ 1000。
  • 1 ≤ nums[i] ≤ 10⁸。
  • edges.length == n − 1，edges[i].length == 2。
  • 0 ≤ aᵢ, bᵢ < n，且 aᵢ ≠ bᵢ。
  • edges 保证描述一棵有效的树。

03 / 独立题解

洞察、切割实验与四语言实现

核心洞察：一条父边，对应一棵子树

以 0 为根，每个非根节点 u 唯一对应可删除的边 (parent[u], u)。预先求出子树异或 S[u]，之后只需枚举两个非根节点 a、b。两棵子树只可能互相包含或互不相交，利用 x ^ x = 0，在 O(1) 时间得到三个分量的异或。

DFS 进入 u 时记录 tin[u]，退出时记录 tout[u]，使子树对应半开区间 [tin[u], tout[u])。u 包含 v 当且仅当 tin[u] ≤ tin[v] < tout[u]。

T = S[0]
a 包含 b：S[b]，S[a] ^ S[b]，T ^ S[a]
b 包含 a：S[a]，S[b] ^ S[a]，T ^ S[b]
互不相交：S[a]，S[b]，T ^ S[a] ^ S[b]

完整过程

  1. 建立邻接表。用显式栈记录 DFS 进入和退出事件，从根 0 开始。
  2. 进入时分配 tin；退出时设置 tout，并将当前子树异或合并给父节点。退出时所有孩子已完成。
  3. 枚举 1 ≤ a < b < n，表示两条不同父子边。
  4. 判断三种子树关系，计算三个异或值，再计算最大值与最小值之差。
  5. 维护最低分，遍历所有边对后返回。若得到 0，可以选择提前返回。

示例 1 的第一对边

切 (0,1) 和 (1,2)：a=1 包含 b=2。T=14，S[1]=15，S[2]=5，因此三个异或为 5、15 ^ 5 = 10、14 ^ 15 = 1，分数是 9。不能因第一对得到 9 就提前结束；演示会继续枚举。

正确性证明

预处理正确：节点退出时，所有孩子都将完整子树异或合并给它。与节点自身值异或后，S[u] 就是 u 子树的异或。DFS 连续遍历一棵子树，故半开区间准确判断包含关系。

三种公式正确：a 包含 b 时，分量恰为 b 子树、a 子树去掉 b 子树、a 子树之外。异或消去性质给出第一组公式；反向包含同理。互不相交时，前两个分量就是两棵子树，第三个是总树去掉它们。

枚举完备：每条边对应唯一非根节点，每对不同边对应唯一 a < b。算法计算了全部合法方案的真实分数并取最小值，所以答案全局最优。

边界与复杂度

n=3 时只有一对切边；根 0 没有父边，不能参与枚举。链形有嵌套子树，星形有互斥子树。相同值会异或消去，但所有节点值相同不保证分数为 0。

预处理 O(n)，枚举 (n−1)(n−2)/2 对，时间 O(n²)，额外空间 O(n)。n=1000 时共有 498501 对。四语言均使用显式栈，避免链形导致递归深度问题。因为 nums[i] < 2²⁷，异或结果也小于 2²⁷，JavaScript 32 位位运算及 Java/C++ int 足够。

替代方案

枚举两边后每次重新遍历树，时间 O(n³)，容易理解但规模较大时开销高。也可以枚举第一条边，再在两部分中 DFS 枚举第二条边，维护子树异或做到 O(n²)；需要细心处理分量边界。区间预处理把每对边的工作压到常数时间。

常见错误

  • 所有边对都套用互斥公式，导致嵌套子树重复计算。
  • 用减法剔除子树：异或值应通过再次异或消去。
  • 把 tout 当闭区间，使用 ≤ 错把相邻子树算作后代。
  • 仅判断 a 包含 b：节点编号不等于 DFS 顺序，必须处理反向包含。
  • 把根也当作一条可删除父边，或枚举了同一条边两次。

面试追问

  • 根可以换吗？可以，改变的只是边与子树的表示，实际切割集合不变。
  • 能剪枝吗？遇到 0 可提前返回，因为分数非负；其他值没有通用的最优保证。
  • 扩展到 k 条边？有 k+1 个分量，直接枚举规模 C(n−1,k)，关系判断需要扩展。
  • 节点值在线更新？DFS 序加树状数组可处理单点更新、子树异或，但维护全局最低切割分数仍是另一个问题。

JavaScript

/**
 * @param {number[]} nums
 * @param {number[][]} edges
 * @return {number}
 */
var minimumScore = function(nums, edges) {
    const n = nums.length;
    const g = Array.from({length: n}, () => []);
    for (const [u, v] of edges) { g[u].push(v); g[v].push(u); }
    const tin = Array(n), tout = Array(n), sub = [...nums];
    let timer = 0;
    const stack = [[0, -1, false]];
    while (stack.length) {
        const [u, p, exit] = stack.pop();
        if (exit) {
            tout[u] = timer;
            if (p !== -1) sub[p] ^= sub[u];
        } else {
            tin[u] = timer++;
            stack.push([u, p, true]);
            for (const v of g[u]) if (v !== p) stack.push([v, u, false]);
        }
    }
    const ancestor = (u, v) => tin[u] <= tin[v] && tin[v] < tout[u];
    const total = sub[0];
    let ans = Infinity;
    for (let a = 1; a < n; a++) {
        for (let b = a + 1; b < n; b++) {
            let x, y, z;
            if (ancestor(a, b)) {
                x = sub[b]; y = sub[a] ^ sub[b]; z = total ^ sub[a];
            } else if (ancestor(b, a)) {
                x = sub[a]; y = sub[b] ^ sub[a]; z = total ^ sub[b];
            } else {
                x = sub[a]; y = sub[b]; z = total ^ sub[a] ^ sub[b];
            }
            ans = Math.min(ans, Math.max(x, y, z) - Math.min(x, y, z));
        }
    }
    return ans;
};

Python

from typing import List

class Solution:
    def minimumScore(self, nums: List[int], edges: List[List[int]]) -> int:
        n = len(nums)
        g = [[] for _ in range(n)]
        for u, v in edges:
            g[u].append(v)
            g[v].append(u)
        tin, tout, sub = [0] * n, [0] * n, nums[:]
        timer = 0
        stack = [(0, -1, False)]
        while stack:
            u, p, exiting = stack.pop()
            if exiting:
                tout[u] = timer
                if p != -1:
                    sub[p] ^= sub[u]
            else:
                tin[u] = timer
                timer += 1
                stack.append((u, p, True))
                for v in g[u]:
                    if v != p:
                        stack.append((v, u, False))

        def ancestor(u, v):
            return tin[u] <= tin[v] < tout[u]

        total, ans = sub[0], float('inf')
        for a in range(1, n):
            for b in range(a + 1, n):
                if ancestor(a, b):
                    x, y, z = sub[b], sub[a] ^ sub[b], total ^ sub[a]
                elif ancestor(b, a):
                    x, y, z = sub[a], sub[b] ^ sub[a], total ^ sub[b]
                else:
                    x, y, z = sub[a], sub[b], total ^ sub[a] ^ sub[b]
                ans = min(ans, max(x, y, z) - min(x, y, z))
        return ans

Java

import java.util.*;

class Solution {
    public int minimumScore(int[] nums, int[][] edges) {
        int n = nums.length;
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
        }
        int[] tin = new int[n], tout = new int[n], sub = nums.clone();
        int timer = 0;
        Deque<int[]> stack = new ArrayDeque<>();
        stack.push(new int[]{0, -1, 0});
        while (!stack.isEmpty()) {
            int[] f = stack.pop();
            int u = f[0], p = f[1];
            if (f[2] == 1) {
                tout[u] = timer;
                if (p != -1) sub[p] ^= sub[u];
            } else {
                tin[u] = timer++;
                stack.push(new int[]{u, p, 1});
                for (int v : g.get(u)) {
                    if (v != p) stack.push(new int[]{v, u, 0});
                }
            }
        }
        int total = sub[0], ans = Integer.MAX_VALUE;
        for (int a = 1; a < n; a++) {
            for (int b = a + 1; b < n; b++) {
                int x, y, z;
                if (tin[a] <= tin[b] && tin[b] < tout[a]) {
                    x = sub[b]; y = sub[a] ^ sub[b]; z = total ^ sub[a];
                } else if (tin[b] <= tin[a] && tin[a] < tout[b]) {
                    x = sub[a]; y = sub[b] ^ sub[a]; z = total ^ sub[b];
                } else {
                    x = sub[a]; y = sub[b]; z = total ^ sub[a] ^ sub[b];
                }
                ans = Math.min(ans, Math.max(x, Math.max(y, z))
                    - Math.min(x, Math.min(y, z)));
            }
        }
        return ans;
    }
}

class Solution {
public:
    int minimumScore(vector<int>& nums, vector<vector<int>>& edges) {
        int n = nums.size();
        vector<vector<int>> g(n);
        for (auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        vector<int> tin(n), tout(n), sub = nums;
        int timer = 0;
        vector<array<int, 3>> stack = {{0, -1, 0}};
        while (!stack.empty()) {
            auto f = stack.back(); stack.pop_back();
            int u = f[0], p = f[1];
            if (f[2]) {
                tout[u] = timer;
                if (p != -1) sub[p] ^= sub[u];
            } else {
                tin[u] = timer++;
                stack.push_back({u, p, 1});
                for (int v : g[u])
                    if (v != p) stack.push_back({v, u, 0});
            }
        }
        auto ancestor = [&](int u, int v) {
            return tin[u] <= tin[v] && tin[v] < tout[u];
        };
        int total = sub[0], ans = INT_MAX;
        for (int a = 1; a < n; ++a) {
            for (int b = a + 1; b < n; ++b) {
                int x, y, z;
                if (ancestor(a, b)) {
                    x = sub[b]; y = sub[a] ^ sub[b]; z = total ^ sub[a];
                } else if (ancestor(b, a)) {
                    x = sub[a]; y = sub[b] ^ sub[a]; z = total ^ sub[b];
                } else {
                    x = sub[a]; y = sub[b]; z = total ^ sub[a] ^ sub[b];
                }
                ans = min(ans, max({x, y, z}) - min({x, y, z}));
            }
        }
        return ans;
    }
