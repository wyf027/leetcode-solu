旅行终点站Destination City

一张只有单向车票的旅行线路图里，哪座城市只迎接到达，却没有下一班出发？先理解任务，再亲手操作线路扫描器。

简单数组哈希表字符串非付费题
01 · Read the map

题目说明

给定旅游线路数组 paths，其中 paths[i] = [cityAᵢ, cityBᵢ] 表示一条从 cityAᵢ 直接前往 cityBᵢ 的单向线路。

返回这次旅行的终点城市：它没有任何通往其他城市的出发线路。

题目保证：所有线路构成一条没有环的链，所以终点城市恰好只有一个。

函数签名

destCity(paths) → string

约束

  • 1 ≤ paths.length ≤ 100
  • paths[i].length == 2
  • 每个城市名长度为 1..10
  • cityAᵢ != cityBᵢ
  • 城市名仅含大小写英文字母与空格
02 · Official examples

完整示例

示例 1
输入：paths = [["London","New York"],["New York","Lima"],["Lima","Sao Paulo"]] 输出："Sao Paulo"

路线为 London → New York → Lima → Sao Paulo，最后一座城市没有后续线路。

示例 2
输入：paths = [["B","C"],["D","B"],["C","A"]] 输出："A"

无论从链上的哪座城市出发，最终都会抵达 A。

示例 3
输入：paths = [["A","Z"]] 输出："Z"

只有一条线路时，到达城市就是唯一终点。

已经形成自己的思路了吗？

题解被单独收起，避免在首屏直接泄露。展开后包含证明、复杂度、四种语言代码与面试延伸。

核心洞察：找集合差

终点城市会作为某张车票的到达城市出现，却绝不会作为任何车票的出发城市出现。先把所有出发城市放入哈希集合，再扫描每个到达城市，首个不在集合中的城市就是答案。

完整过程

  1. 创建空集合 outgoing。
  2. 遍历 paths，把每条线路的 path[0] 加入集合。
  3. 再次遍历，检查每条线路的 path[1]。
  4. 返回第一个不在 outgoing 中的到达城市。

正确性证明

对任意非终点城市，由于整张图是一条线路，它都有唯一的后继城市，因此必然作为某条边的起点并进入 outgoing。

唯一终点没有任何出边，所以不会进入 outgoing；同时它必然是最后一条边的到达城市。故第二次扫描一定且只会找到该终点，算法返回值正确。

复杂度

时间O(n)两次线性扫描
空间O(n)出发城市集合

其中 n = paths.length。

边界情况

  • 只有一条线路：直接返回它的到达城市。
  • 输入顺序被打乱：集合解法不依赖排列顺序。
  • 城市名含空格或区分大小写：按完整字符串保存。
  • 最长 100 条线路：线性方案留有充分余量。

替代方案

沿链追踪：建立“起点 → 终点”的映射，从任意起点不断向后走，直到找不到下一站。它同样是 O(n) 时间和 O(n) 空间，但步骤更多。

删除法：先收集所有到达城市，再删除所有起点，剩余唯一元素即答案。思想直观，但创建的集合稍多。

面试追问

  • 如果可能存在多个终点，应返回什么结构？
  • 如果图中可能有环，怎样检测并报告？
  • 如果数据以流式输入到达，能否维护起点、终点集合的差？
  • 若城市名规模巨大，如何权衡哈希冲突与内存？

常见错误

  • 误以为输入按旅行顺序排列，直接返回最后一条边的终点。
  • 把到达城市放入集合，却仍按相同方向查找，导致逻辑反转。
  • 返回集合中的任意城市，忽略“没有出边”的精确定义。

JavaHashSet
class Solution {
    public String destCity(List<List<String>> paths) {
        Set<String> outgoing = new HashSet<>();

        for (List<String> path : paths) {
            outgoing.add(path.get(0));
        }

        for (List<String> path : paths) {
            String arrival = path.get(1);
            if (!outgoing.contains(arrival)) {
                return arrival;
            }
        }

        return ""; // 题目保证一定存在唯一终点
    }
}

/**
 * @param {string[][]} paths
 * @return {string}
 */
var destCity = function(paths) {
    const outgoing = new Set();

    for (const [from] of paths) {
        outgoing.add(from);
    }

    for (const [, to] of paths) {
        if (!outgoing.has(to)) {
            return to;
        }
    }

    return ""; // 题目保证一定存在唯一终点
};
Python 3set
class Solution:
    def destCity(self, paths: List[List[str]]) -> str:
        outgoing = {start for start, _ in paths}

        for _, arrival in paths:
            if arrival not in outgoing:
                return arrival

        return ""  # 题目保证一定存在唯一终点

class Solution {
public:
    string destCity(vector<vector<string>>& paths) {
        unordered_set<string> outgoing;

        for (const auto& path : paths) {
            outgoing.insert(path[0]);
        }

        for (const auto& path : paths) {
            if (!outgoing.count(path[1])) {
                return path[1];
            }
        }

        return ""; // 题目保证一定存在唯一终点
    }
