题解

核心洞察、过程、边界、复杂度、追问、错误清单与四语言代码默认隐藏。

CORE INSIGHT

前缀必须逐列全票通过

最长公共前缀一定是首字符串的某个前缀。用首行字符作为每列基准，只要任一字符串在该列越界或字符不同，后面的列都不可能再属于公共前缀。

COLUMN CONTRACT

全员相同：prefix += current

越界 / 不同：return prefix

无需排序，也无需额外保存中间前缀。

FULL WALKTHROUGH

完整解题过程

  1. 1. 选基准：从首字符串第 0 列开始。
  2. 2. 横切一列：逐个读取其余字符串同一位置。
  3. 3. 全列一致：继续扫描下一列。
  4. 4. 发现分歧：返回首字符串在当前列之前的子串。
  5. 5. 首行扫描完成：说明整个首字符串都是公共前缀。

边界情况

  • 数组只有一个字符串时返回它本身。
  • 任一字符串为空，答案立即为空。
  • 第 0 列就不同，返回 ""。
  • 较短字符串完整匹配后，越界位置就是停止点。

复杂度

时间：O(S)

额外空间：O(1)

S 是停止前实际检查的字符总数；返回字符串不计额外空间。

替代方案

横向缩短前缀、排序后比较首尾、分治和 Trie 都能解决。纵向扫描最少依赖、可提前停止，面试表达也最直接。

class Solution {
    public String longestCommonPrefix(String[] strs) {
        String first = strs[0];

        for (int column = 0; column < first.length(); column++) {
            char expected = first.charAt(column);
            for (int row = 1; row < strs.length; row++) {
                if (column == strs[row].length()
                        || strs[row].charAt(column) != expected) {
                    return first.substring(0, column);
                }
            }
        }
        return first;
    }
}

面试高频追问

为什么只扫描首字符串的长度？
公共前缀不可能比任何字符串更长，更不可能超过首字符串。
为什么遇到一次不同就能立即返回？
前缀要求从位置 0 连续一致；当前列断裂后，任何更长候选都已失效。
海量字符串适合 Trie 吗？
若还要支持大量前缀查询，Trie 有价值；单次求解会增加不必要空间。

常见错误

  • 先访问 word[column]，后检查是否越界。
  • 只比较相邻两个字符串，没有维护全局共同前缀。
  • 把子串终点写成 column + 1，包含了失败列。
  • 忘记处理首字符串为空或数组只有一个元素。
