重排链表 链路折叠台

把一条直链拆成前后两轨：找到中点、反转后半段，再从两端交替抽取节点，原地折叠成目标顺序。

任务边界

只接收 head，函数原地重连节点。节点值必须保持不变， 返回类型为 void；节点数 1～5×10⁴。

Problem / 题意

原地重排节点顺序

给定单链表 L₀ → L₁ → … → Lₙ，将其改为 L₀ → Lₙ → L₁ → Lₙ₋₁ → …。只能改变节点之间的 next，不能修改节点值；节点值范围为 1～1000。

官方示例 1
head = [1,2,3,4]

输出：[1,4,2,3]

官方示例 2
head = [1,2,3,4,5]

输出：[1,5,2,4,3]

关键边界
head = [1]

输出：[1]

核心洞察

两端交替抽取，先把后半段方向翻过来

目标顺序本质是“前端一个、后端一个”。单链表不能从尾部向前走， 所以先用快慢指针切成两半，再反转后半段，让原尾节点成为第二条链的头。 最后像拉链一样交替连接两条链，全程只使用常数个指针。

完整过程

  1. 快慢指针找到前半段末尾。
  2. 断开链表，原地反转后半段。
  3. 保存两条链各自的 next。
  4. 前、后节点交替接入，直到后半链耗尽。

边界与复杂度

  • 单节点与双节点无需实质变化。
  • 奇数长度时，中间节点自然留在末尾。
  • 时间 O(n)，额外空间 O(1)，只重连节点。

替代方案取舍

数组或栈保存全部节点更直观，但额外空间 O(n)；递归也会占用调用栈。 面试主线推荐“中点 + 反转 + 合并”的常数空间方案。

常见错误

  • 没有断开前半段，合并后形成环。
  • 反转时丢失 next，后续节点断链。
  • 合并前未保存旧 next，覆盖后无法继续。
  • 通过改 val“伪重排”，违反题意。

面试追问

为什么 slow 停在前半末尾？循环条件让 fast 保留两步空间。
奇偶长度如何统一？后半段不长于前半段，合并到 second 为空。
能否返回新链表？接口要求 void，且必须复用原节点。 
public class Solution {
    public void reorderList(ListNode head) {
        if (head == null || head.next == null) return;
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        ListNode second = slow.next;
        slow.next = null;
        ListNode prev = null;
        while (second != null) {
            ListNode next = second.next;
            second.next = prev;
            prev = second;
            second = next;
        }
        ListNode first = head;
        second = prev;
        while (second != null) {
            ListNode nextFirst = first.next;
            ListNode nextSecond = second.next;
            first.next = second;
            second.next = nextFirst;
            first = nextFirst;
            second = nextSecond;
        }
    }
}
