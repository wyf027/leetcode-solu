LCR 081中等 MEDIUM回溯 · DFS

组合总和

给定无重复候选整数和目标值，找出所有和为 target 的组合；同一个数可重复选取。

交互演示

题意、示例与约束

输入：candidates=[2,3,6,7], target=7

输出：[[2,2,3],[7]]

  • 候选数互不相同，均为正整数。
  • 每个候选数可以无限次使用。
  • 组合顺序不同视为同一组合。

分步交互：目标 7

路径保持非递减索引，既允许复用当前数，也避免排列重复。

核心洞察

回溯树的状态是起始索引、剩余目标和当前路径。每层从 start 开始枚举：递归时仍传 i，表示可复用这个候选数；候选数组排序后，遇到大于剩余值的数字即可剪枝。

完整过程

  1. 1. 排序
    便于剪枝。
  2. 2. 选择
    将候选数加入路径。
  3. 3. 递归
    剩余目标减去它，起点传 i。
  4. 4. 回退
    弹出路径尾部，继续枚举。

边界、复杂度、替代与错误

边界：target 为 0 时收集当前路径；剩余值为负不再递归。
复杂度：输出敏感，最坏指数级；递归栈 O(target/min)。
替代：DP 可计数或列举，但组合重建更复杂。
追问：若每个数只能使用一次？若有重复候选如何去重？
常见错误：递归传 i+1 导致不能复用；每层从 0 开始造成重复排列；忘记回溯 pop。

// Java
class Solution { List<List<Integer>> ans=new ArrayList<>(); public List<List<Integer>> combinationSum(int[] c,int t){Arrays.sort(c);dfs(c,t,0,new ArrayList<>());return ans;} void dfs(int[] c,int t,int s,List<Integer> p){if(t==0){ans.add(new ArrayList<>(p));return;}for(int i=s;i<c.length&&c[i]<=t;i++){p.add(c[i]);dfs(c,t-c[i],i,p);p.remove(p.size()-1);}} }
// JavaScript
var combinationSum=function(candidates,target){candidates.sort((a,b)=>a-b);const ans=[];const dfs=(remain,start,path)=>{if(!remain){ans.push([...path]);return;}for(let i=start;i<candidates.length&&candidates[i]<=remain;i++){path.push(candidates[i]);dfs(remain-candidates[i],i,path);path.pop();}};dfs(target,0,[]);return ans;};
# Python
class Solution:
 def combinationSum(self, c, target):
  c.sort(); ans=[]
  def dfs(remain,start,path):
   if not remain: ans.append(path[:]); return
   for i in range(start,len(c)):
    if c[i]>remain: break
    dfs(remain-c[i],i,path+[c[i]])
  dfs(target,0,[]); return ans
