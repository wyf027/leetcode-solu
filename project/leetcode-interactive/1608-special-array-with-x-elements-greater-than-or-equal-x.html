Problem brief

题目说明

给定一个非负整数数组 nums。若存在整数 x，使数组中恰好有 x 个元素大于或等于 x，则数组是特殊数组，x 是它的特征值。

注意，x 不要求出现在数组中。存在特征值时返回它，否则返回 -1。题目保证：若答案存在，它是唯一的。

函数形式： specialArray(nums: integer[]) → integer

官方示例

示例 1 
输入：nums = [3,5]
输出：2
解释：3 和 5 都 ≥ 2，恰好 2 个。
示例 2 
输入：nums = [0,0]
输出：-1
解释：x = 0、1、2 均不满足。
示例 3 
输入：nums = [0,4,3,0,4]
输出：3
解释：4、3、4 都 ≥ 3，恰好 3 个。

约束

  • 1 ≤ nums.length ≤ 100
  • 0 ≤ nums[i] ≤ 1000

Solution

题解：排序后锁定分界线

核心洞察

答案最多是数组长度 n。把数组升序排列后，若候选答案为 x，那么最后 x 个数都必须不小于 x，而它们左边紧邻的数必须小于 x。

nums[n - x] ≥ x 且 (n - x = 0 或 nums[n - x - 1] < x)

完整过程

  1. 升序排序数组，记长度为 n。
  2. 依次枚举 x = 1 ... n。
  3. 查看下标 n - x，确认最后 x 个元素全部达到门槛。
  4. 再检查左邻元素，排除“实际达标元素多于 x”的情况。
  5. 满足两侧边界立即返回 x；遍历结束仍不满足则返回 -1。

正确性证明

充分性：若 nums[n-x] ≥ x，排序后的最后 x 个元素都大于等于 x；若左侧不存在，或 nums[n-x-1] < x，其余元素又都小于 x。因此恰好有 x 个元素达标，返回值正确。

必要性：若某个 x 是特征值，排序后恰好最后 x 个元素达标，所以第一个达标元素 nums[n-x] 必然不小于 x，其左邻若存在则必然小于 x。枚举到该 x 时算法一定能找到它。

由充分性与必要性，算法返回特征值当且仅当它存在；否则返回 -1。

边界与复杂度

  • x = n 时没有左邻元素，只需检查最小值是否至少为 n。
  • 数组含大量 0 时仍可直接用两侧边界判断。
  • x = 0 不可能成为答案：数组非空且所有元素都大于等于 0，达标数至少为 1。
  • 重复值不能只检查一个边界，否则容易把达标数更多的情况误判为答案。
时间 O(n log n)额外空间 O(1) 或 O(log n)

空间复杂度取决于语言的排序实现；复制数组再排序时需要 O(n) 额外空间。

四语言完整代码

import java.util.Arrays;

class Solution {
    public int specialArray(int[] nums) {
        Arrays.sort(nums);
        int n = nums.length;

        for (int x = 1; x <= n; x++) {
            int first = n - x;
            boolean rightSideQualifies = nums[first] >= x;
            boolean leftSideFails = first == 0 || nums[first - 1] < x;

            if (rightSideQualifies && leftSideFails) {
                return x;
            }
        }
        return -1;
    }
}

替代方案

直接计数：枚举 x = 0...n，每次扫描数组统计达标数，时间 O(n²)，最直观。

桶计数：把所有大于 n 的值归入桶 n，从右向左维护后缀数量；时间 O(n)，空间 O(n)。

二分查找：排序后可二分候选边界，但本题 n ≤ 100，线性枚举更清晰且足够快。

面试追问

为什么答案至多为 n？

数组总共只有 n 个元素，不可能有超过 n 个元素满足任何条件。

如何做到 O(n)？

建立大小为 n+1 的计数桶，将值截断为 min(value, n) 后累计后缀和。

为什么答案唯一？

令 f(x) 为不小于 x 的元素数。随着 x 增大，f(x) 单调不增，而直线 x 严格递增，因此二者至多相交一次。

常见错误

  • 误以为 x 必须是数组元素，从而漏掉示例 [3,5] → 2。
  • 只判断至少有 x 个元素达标，忘记题目要求恰好。
  • 把比较写成 > x，漏掉等于门槛的元素。
  • 排序后只检查 nums[n-x] ≥ x，没有检查左邻元素是否仍达标。
