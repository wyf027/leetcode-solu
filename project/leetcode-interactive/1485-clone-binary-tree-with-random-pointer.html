克隆含随机指针的二叉树

把一棵树完整复制到新的内存世界：左右孩子要保持结构，任意跳转的 random 指针也必须指向对应的克隆节点，而不是偷偷连回原树。

核心模型树 + 额外有向边
推荐工具DFS + 哈希表
目标复杂度O(n) 时间 / O(n) 空间

Problem

先弄清“深拷贝”

函数：copyRandomBinaryTree(root)

题意转述

给定一棵二叉树。每个原节点 Node 除了 val、left、right 外，还有一个 random 指针；它可以指向树中任意节点，也可以为 null。

返回由 NodeCopy 节点组成的深拷贝。克隆树的值、左右结构和 random 关系都必须与原树一致，但克隆树中的任何非空指针都只能指向克隆节点。

序列化中，非空节点写作 [val, random_index]；random_index 是 random 目标在层序数组中的下标，空位置仍以 null 占位。

输入、输出与约束

输入：root: Node | null
输出：NodeCopy | null

  • 节点数在 [0, 1000] 内。
  • 1 ≤ Node.val ≤ 10⁶。
  • random 指向树中任意节点或 null。
  • 节点值可以重复，不能用值充当节点身份。

题解、证明与代码刻意放在首屏之后。先尝试回答：为什么必须在递归处理 random 之前，把克隆节点放入哈希表？

Full solution

记忆化 DFS

核心洞察

把 left、right、random 全看成有向边后，结构本质上是一张从根可达的图。哈希表 memo[原节点] = 克隆节点 同时解决“同一节点只复制一次”和“环不会无限递归”。

完整过程

  1. 空节点直接返回空。
  2. 若原节点已在 memo，返回既有克隆。
  3. 创建只含值的新节点，并立即写入 memo。
  4. 递归复制 left、right、random，把结果接到克隆节点。
  5. 返回克隆根。

正确性

唯一性：每个原节点首次访问时创建且登记一个克隆；以后都复用它，因此恰好对应一个克隆对象。

边保持：对任意原节点 u 及其任一非空字段 p，赋值语句把 clone(u).p 设为 clone(u.p)，故三类边全部保持。

深拷贝：所有目标都来自 memo 中新建的 NodeCopy，不存在指回原树的边。于是返回结构是且仅是原结构的深拷贝。

边界与复杂度

  • 空树返回 null。
  • random 自环或环：先登记再递归即可终止。
  • 重复值：键必须是对象引用，不是 val。
  • 极度倾斜的 1000 节点树可能接近递归栈上限；可改 BFS。

时间：O(n)，每个节点处理一次。
空间：O(n)，哈希表与递归栈。

替代方案

两遍 BFS：第一遍沿 left/right 收集树节点并创建所有克隆；第二遍统一连接三种指针。复杂度同为 O(n)，避免递归栈，也更贴近“先建点、后连边”的工程实现。

不建议用节点值做映射；值不唯一。也无需尝试链表题常见的穿插节点技巧，树结构上的恢复与 random 连接更复杂。

面试追问

  • 若节点数达到百万，如何改为迭代 BFS 并控制队列内存？
  • 若要求检测 random 是否指向树外节点，如何先确定合法节点集合？
  • 如何验证没有任何克隆指针引用原对象？
  • 若只允许 O(h) 额外空间，是否仍能在有环 random 下完成？为什么哈希映射难以省掉？

常见错误

  • 递归完三个字段后才登记克隆：一遇 self-random 就无限递归。
  • 只克隆 left/right，再把 random 直接复制引用：得到的是浅拷贝。
  • 用 val 当哈希键：重复值节点会被错误合并。
  • JavaScript 使用普通对象做键：对象会被字符串化；应使用 Map。
  • 把序列化下标当作算法输入：在线评测传入的是节点对象，不是二维数组。

Implementations

四语言完整实现

均使用“创建即登记”不变量

/*
// Definition for a Node.
class Node {
    int val;
    Node left;
    Node right;
    Node random;
}

// Definition for a NodeCopy.
class NodeCopy {
    int val;
    NodeCopy left;
    NodeCopy right;
    NodeCopy random;
    NodeCopy(int val) { this.val = val; }
}
*/
class Solution {
    private final Map<Node, NodeCopy> memo = new HashMap<>();

    public NodeCopy copyRandomBinaryTree(Node root) {
        if (root == null) return null;
        if (memo.containsKey(root)) return memo.get(root);

        NodeCopy copy = new NodeCopy(root.val);
        memo.put(root, copy);
        copy.left = copyRandomBinaryTree(root.left);
        copy.right = copyRandomBinaryTree(root.right);
        copy.random = copyRandomBinaryTree(root.random);
        return copy;
    }
}
/**
 * // Definition for a Node.
 * function Node(val, left, right, random) {
 *   this.val = val;
 *   this.left = left;
 *   this.right = right;
 *   this.random = random;
 * }
 * // Definition for a NodeCopy is provided by the judge.
 */
/**
 * @param {Node|null} root
 * @return {NodeCopy|null}
 */
var copyRandomBinaryTree = function(root) {
  const memo = new Map();

  function clone(node) {
    if (node === null) return null;
    if (memo.has(node)) return memo.get(node);

    const copy = new NodeCopy(node.val);
    memo.set(node, copy);
    copy.left = clone(node.left);
    copy.right = clone(node.right);
    copy.random = clone(node.random);
    return copy;
  }

  return clone(root);
};
"""
# Definition for a Node.
class Node:
    def __init__(self, x=0, left=None, right=None, random=None):
        self.val = x
        self.left = left
        self.right = right
        self.random = random

# Definition for a NodeCopy is provided by the judge.
"""
class Solution:
    def copyRandomBinaryTree(
        self, root: 'Optional[Node]'
    ) -> 'Optional[NodeCopy]':
        memo = {}

        def clone(node):
            if node is None:
                return None
            if node in memo:
                return memo[node]

            copy = NodeCopy(node.val)
            memo[node] = copy
            copy.left = clone(node.left)
            copy.right = clone(node.right)
            copy.random = clone(node.random)
            return copy

        return clone(root)
/*
// Definition for a Node.
class Node {
public:
    int val;
    Node* left;
    Node* right;
    Node* random;
};

// Definition for a NodeCopy is provided by the judge.
*/
class Solution {
    unordered_map<Node*, NodeCopy*> memo;

public:
    NodeCopy* copyRandomBinaryTree(Node* root) {
        if (root == nullptr) return nullptr;
        auto it = memo.find(root);
        if (it != memo.end()) return it->second;

        NodeCopy* copy = new NodeCopy(root->val);
        memo[root] = copy;
        copy->left = copyRandomBinaryTree(root->left);
        copy->right = copyRandomBinaryTree(root->right);
        copy->random = copyRandomBinaryTree(root->random);
        return copy;
    }
};
