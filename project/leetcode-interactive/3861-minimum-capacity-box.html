3861. 容量最小的箱子

从能装下物品的箱子中，选择容量最小的那个；若容量相同，保留更靠前的下标。

一次线性扫描稳定的并列规则O(n) / O(1)

题意

给定整数数组 capacity，其中 capacity[i] 是第 i 个箱子的容量；另给定物品大小 itemSize。一个箱子仅在容量不少于物品大小时可用。返回所有可用箱子中容量最小者的下标；并列时返回最小下标；没有可用箱子则返回 -1。

示例 1

capacity = [1, 5, 3, 7]
itemSize = 3

输出：2

示例 2

capacity = [3, 5, 4, 3]
itemSize = 2

输出：0

约束：1 ≤ capacity.length ≤ 100，1 ≤ capacity[i], itemSize ≤ 100。输入中的空格以正常数组格式展示，不承载额外语义。

题解：维护当前最优箱子

核心洞察与过程

  1. 答案下标初始为 -1，表示尚无可用箱子。
  2. 扫描每个容量 x；若 x < itemSize，它不可用。
  3. 若可用且还没有答案，或 x < capacity[ans]，更新答案。
  4. 只在严格更小时更新，所以相同最小容量会保留第一次出现的下标。

边界、复杂度与替代方案

单元素、恰好装下、所有箱子不足以及相同最小容量都要覆盖。扫描耗时 O(n)，只保存一个下标，额外空间 O(1)。排序也能找到容量最小值，但会破坏原下标或增加映射与 O(n log n) 成本，不推荐。

面试追问与常见错误

若要返回所有并列下标，可在遇到相同最小容量时追加结果。常见错误是使用 <= 覆盖前面的下标，或忘记判断容量是否足够。
