Problem

题目描述

给定一棵非空二叉树的根节点 root，请按从上到下的层次顺序，返回每一层所有节点值的平均数，结果组成一个数组。

答案与真实值的误差不超过 10-5 即可接受。

示例 1

输入

root = [3,9,20,null,null,15,7]

输出

[3.00000,14.50000,11.00000]

第 0 层为 3；第 1 层为 (9 + 20) / 2 = 14.5；第 2 层为 (15 + 7) / 2 = 11。

示例 2

输入

root = [3,9,20,15,7]

输出

[3.00000,14.50000,11.00000]

树的连接方式不同，但三层分别包含 [3]、[9,20]、[15,7]，所以结果相同。

约束

  • 树中节点数量在 [1, 104] 范围内。
  • -231 ≤ Node.val ≤ 231 - 1。

Solution

题解：用队列锁定每一层

∑

核心洞察

进入一轮处理时，队列中已有的节点恰好属于同一层。先保存队列长度 levelSize，只弹出这固定数量的节点；过程中加入的孩子留给下一轮。这样就能得到本层的总和与节点数。

完整过程

  1. 把根节点放入队列，创建空的结果数组。
  2. 每轮开始先记录当前队列长度 levelSize，并把本层总和清零。
  3. 连续取出 levelSize 个节点，累加节点值，并把非空孩子加入队尾。
  4. 计算 sum / levelSize，追加到结果数组。
  5. 队列为空时，所有层都已处理完毕，返回结果。

为什么必须先保存层宽？

处理当前层时，下一层的孩子会不断进入同一个队列。如果循环条件直接使用不断变化的队列长度，就会把下一层也混进来。

边界快照：levelSize 像一道闸门，确保本轮恰好消费当前层，新增节点只能留到下一轮。

正确性证明

循环不变式：每一轮开始时，队列中的所有节点按从左到右顺序，恰好是尚未处理的最上面一层。

初始化：队列最初只有根节点，因此不变式成立。

保持：本轮弹出恰好 levelSize 个当前层节点，并按左右顺序加入它们的非空孩子。轮末队列恰好只含下一层节点，顺序仍正确。

终止：队列为空意味着每个节点都被处理一次。每轮记录的是该层所有节点之和除以节点数，所以返回数组逐项等于各层平均值。

边界与数值安全

  • 单节点树只有一轮，平均值就是根节点值。
  • 树可以极度不平衡；队列只保存实际存在的节点。
  • 节点值允许为负，求和与除法逻辑不变。
  • 最多 104 个 32 位整数；Java 使用 long、C++ 使用 long long 保存层和，避免 32 位整数溢出。
  • JavaScript 的 Number 可精确表示本题可能出现的整数总和，再执行浮点除法。
时间复杂度O(n)每个节点只入队、出队各一次。
空间复杂度O(w)w 为树的最大层宽；结果数组另占 O(h)。

JavaArrayDeque + long
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<Double> averageOfLevels(TreeNode root) {
        List<Double> averages = new ArrayList<>();
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            long sum = 0L;

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                sum += node.val;

                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }

            averages.add((double) sum / levelSize);
        }

        return averages;
    }
}
JavaScript逐层数组
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number[]}
 */
var averageOfLevels = function(root) {
    const averages = [];
    let level = [root];

    while (level.length > 0) {
        let sum = 0;
        const nextLevel = [];

        for (const node of level) {
            sum += node.val;

            if (node.left !== null) {
                nextLevel.push(node.left);
            }
            if (node.right !== null) {
                nextLevel.push(node.right);
            }
        }

        averages.push(sum / level.length);
        level = nextLevel;
    }

    return averages;
};

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val

class Solution:
    def averageOfLevels(
        self, root: Optional[TreeNode]
    ) -> List[float]:
        queue = deque([root])
        averages = []

        while queue:
            level_size = len(queue)
            level_sum = 0

            for _ in range(level_size):
                node = queue.popleft()
                level_sum += node.val

                if node.left is not None:
                    queue.append(node.left)
                if node.right is not None:
                    queue.append(node.right)

            averages.append(level_sum / level_size)

        return averages
C++queue + long long
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<double> averageOfLevels(TreeNode* root) {
        vector<double> averages;
        queue<TreeNode*> nodes;
        nodes.push(root);

        while (!nodes.empty()) {
            int levelSize = static_cast<int>(nodes.size());
            long long sum = 0;

            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = nodes.front();
                nodes.pop();
                sum += node->val;

                if (node->left != nullptr) {
                    nodes.push(node->left);
                }
                if (node->right != nullptr) {
                    nodes.push(node->right);
                }
            }

            averages.push_back(
                static_cast<double>(sum) / levelSize
            );
        }

        return averages;
    }
};

替代方案：深度优先搜索

用深度作为下标，为每层维护 sum[depth] 与 count[depth]。遍历结束后逐层相除，也能得到答案。

取舍：代码同样是 O(n)，但递归版本需要 O(h) 调用栈；极深的树可能触发栈深限制。层序遍历则天然贴合“按层统计”。

常见错误

  • 在循环中反复读取变化后的队列长度，导致跨层混算。
  • 先做整数除法再转浮点，丢失小数部分。
  • 用 32 位整数保存层和，在大节点值和宽层下溢出。
  • 把空孩子也计入节点数，使平均值分母错误。
  • JavaScript 使用 shift() 频繁移动数组，可能造成额外开销。

面试追问

  • 如果要返回每层的最大值、中位数或方差，状态需要怎样变化？
  • 若节点流式到达、无法一次得到完整树，层边界如何编码？
  • 如何用 DFS 完成，并比较 O(h) 与 O(w) 的空间含义？
  • 如果要求精确分数而不是浮点数，应如何表示并约分？

一句话记忆

每轮先拍一张队列长度的“快照”，只称快照里的节点；新入队的孩子留到下一层。
