栅栏涂色

有一排等待上色的栅栏柱。颜色可以重复，但连续相同的长度有限制。你能数出所有合法的涂色方案吗？

Problem

题目描述

给定 n 根排成一列的栅栏柱，以及 k 种不同颜色。请计算把所有柱子涂完的方案总数；每种方案都必须同时满足以下规则：

1

全部上色

每一根柱子恰好选择一种颜色，不能留空。

2

颜色可复用

相邻两根可以同色，不要求交替。

3

禁止三连同色

任意连续三根或更多柱子都不能使用同一种颜色。

返回所有满足规则的不同涂色方案数。

官方示例

示例 1

输入n = 3, k = 2
输出6
说明两种颜色共有 8 个长度为 3 的序列，去掉两种“三根全同色”的非法序列，剩 6 种。

示例 2

输入n = 1, k = 1
输出1

示例 3

输入n = 7, k = 2
输出42

约束

  • 1 ≤ n ≤ 50
  • 1 ≤ k ≤ 105
  • 给定输入的答案保证位于 [0, 231 − 1]。

函数签名

Before solution

展开题解前，先想三件事

01 · 最小状态

判断下一根能否安全上色，真的需要记住整段历史吗？

02 · 最后一次选择

新颜色和上一根相同、不同，各自从哪些旧方案产生？

03 · 边界

只有一根柱子，或者只有一种颜色时，规律还成立吗？

Solution

动态规划：只记录末尾关系

核心洞察

限制只关心是否出现连续三根同色，因此推进到第 i 根时，不必保存完整配色。把合法方案按末尾两根的关系分为两类即可：

  • same：第 i 根和第 i−1 根颜色相同。
  • diff：第 i 根和第 i−1 根颜色不同。

如果新柱子与前一根同色，旧方案末尾必须是异色，否则会形成三连同色；如果新柱子选异色，则任何旧合法方案都可以转移，并有 k−1 种颜色可选。

完整过程

  1. 当 n = 1 时，第一根有 k 种选择，直接返回 k。
  2. 初始化两根柱子：same = k，因为两根同色只需选一种颜色；diff = k × (k−1)。
  3. 从第 3 根开始，更新：newSame = diff，newDiff = (same + diff) × (k−1)。
  4. 把新值覆盖旧值，最终返回 same + diff。
sameᵢ = diffᵢ₋₁　｜　diffᵢ = (sameᵢ₋₁ + diffᵢ₋₁) × (k − 1)

也可把总数写成一维递推：total(i) = (total(i−1) + total(i−2)) × (k−1)，其中 total(1)=k、total(2)=k²。

正确性证明

不重不漏。 对任意第 i 根的合法方案，末尾两根要么同色，要么异色，两类互斥且覆盖全部方案。

同色转移正确。 要让第 i 根与第 i−1 根同色，第 i−2 根必须异色。因此每个旧 diff 方案有且只有一种延伸，得到 sameᵢ = diffᵢ₋₁。

异色转移正确。 新柱子与前一根异色时，不会增加末尾同色连续段的长度，所以任意旧合法方案都能延伸；排除前一根的颜色后恰有 k−1 种选择，得到 diffᵢ = (sameᵢ₋₁ + diffᵢ₋₁)(k−1)。

归纳结论。 初始化准确计数两根柱子的两类方案；上述转移在每一步准确生成全部且仅有合法方案。由数学归纳法，最终 same + diff 就是长度为 n 的合法方案总数。

边界情况

  • n = 1：答案是 k，不能直接套用两根柱子的初始化。
  • k = 1：当 n ≤ 2 时只有 1 种；当 n ≥ 3 时答案为 0，递推会自然得到这个结果。
  • 乘法中间值可能比 int 大；Java/C++ 实现用 64 位整数承接中间计算，再按题目返回类型返回。

复杂度

遍历柱子一次，时间复杂度 O(n)；只保留两个状态，额外空间复杂度 O(1)。

替代方案

  • DP 数组：保存每个位置的 same[i]、diff[i]，更直观，但空间为 O(n)。
  • 记忆化搜索：状态可设为位置、上一颜色、连续相同长度；容易理解，但颜色维度会让状态数膨胀，不如按末尾关系聚合。
  • 矩阵快速幂：把二状态转移写成矩阵，可将时间降到 O(log n)，适合 n 极大时；本题 n ≤ 50，没有必要。

面试追问

  • 若最多允许连续 m 根同色，状态应如何扩展？可记录当前同色段长度 1…m。
  • 若每根柱子可用的颜色集合不同，怎样修改转移？需要追踪颜色或用集合交集加速，原来的聚合状态不一定足够。
  • 若答案需要对大质数取模，在哪里取模？每次加法与乘法之后都应取模，并防止乘法溢出。

常见错误

  • 误写成相邻柱子不能同色，实际只禁止连续三根或更多同色。
  • 计算 newSame 后立刻覆盖 same，导致 newDiff 使用了新旧混合状态。
  • 忘记单独处理 n = 1。
  • 将 newSame 乘以 k；实际上同色延伸时颜色已由前一根确定，只有一种选择。

四语言完整代码

class Solution {
    public int numWays(int n, int k) {
        if (n == 1) {
            return k;
        }

        long same = k;
        long diff = (long) k * (k - 1);

        for (int i = 3; i <= n; i++) {
            long nextSame = diff;
            long nextDiff = (same + diff) * (k - 1);
            same = nextSame;
            diff = nextDiff;
        }

        return (int) (same + diff);
    }
}
