Word Ladder

每次只改变一个字母，并且落点必须在字典中。我们只问最短序列含几个单词；先看规则和实验，不在首屏提前展开题解。

Mission output

最短序列的单词数

可达时返回包含起点和终点的长度；不可达时返回 0。起点不必出现在字典中。

01 / Problem brief

任务边界先对齐

给定等长的小写单词起点、终点和不重复字典。转换序列中的相邻单词必须恰好只差一个字母，除起点外的每个落点都必须在字典里。

判定规则

  • 相邻单词只能修改一个位置。
  • beginWord 可以不在 wordList 中。
  • endWord 必须真正到达，序列才有效。
  • 返回最短序列的单词数，不是修改次数。

官方约束：单词长度 1–10；字典长度 1–5000；所有单词等长、由小写英文字母组成且互不相同。

官方示例 1 · 可达 输出 5 
beginWord = "hit"
endWord = "cog"
wordList = ["hot","dot","dog","lot","log","cog"]
官方示例 2 · 终点缺席 输出 0 
beginWord = "hit"
endWord = "cog"
wordList = ["hot","dot","dog","lot","log"]

本题输入没有空格字符串；若页面中需要表达空格，将统一写作可见符号“␠”。

04 / Interview solution

题解默认收起

核心洞察、完整过程、边界、复杂度、替代方案、追问、常见错误与四语言代码都集中在下方。

核心洞察

把每个单词看作图节点，两个只差一个字母的单词之间有边。边权都相同，所以最短路属于 BFS。面试更推荐双向 BFS：从两端同时搜索，并始终扩展较小前沿，通常能把指数增长的搜索半径近似砍半。

完整过程

  1. 把字典放入哈希集合；终点不在集合中直接返回 0。
  2. 建立起点前沿和终点前沿，当前序列长度设为 1。
  3. 每轮交换引用，确保扩展节点数更少的前沿。
  4. 枚举每个位置的 26 个字母；命中另一侧前沿时返回长度加 1。
  5. 新词若仍在未访问字典中，立即删除并加入下一层，避免重复搜索。
  6. 任一前沿耗尽仍未相遇，返回 0。

边界清单

  • endWord 不在字典：必然不可达。
  • 起点可不在字典，不能因此拒绝搜索。
  • 直接一字母可达时答案是 2，不是 1。
  • 同层产生同一单词时，只应把它加入下一层一次。
  • 检查另一侧前沿要早于检查未访问集合，因为前沿词可能已从集合删除。

替代方案取舍

  • 普通 BFS：最容易写对，也能通过；但分支多时会从单侧展开更大词域。
  • 通配模式建图：预先把 h*t 一类模式映射到单词，邻接查询直观，但额外占用映射空间。
  • DFS / 回溯：不能自然保证第一次抵达就是最短，不适合作为主线。

复杂度

时间 O(N · L · 26)

每个有效字典词至多进入前沿一次，每次枚举 L 个位置和 26 个字母。双向搜索改善实际展开量，但最坏渐进上界不变。

空间 O(N · L)

哈希集合和两侧前沿保存至多 N 个长度为 L 的单词；忽略字符串实现常数时也常记作 O(N)。

面试追问

  • 为什么双向 BFS 必须扩展较小前沿，而不是固定左右交替？
  • 若要返回全部最短序列，为什么不能立即删除所有父关系？
  • 若字符集不再是 26 个小写字母，邻居生成策略如何调整？
  • 如何用通配模式减少重复字符串构造？

常见错误

  • 把答案当作修改次数，返回 4 而不是 5。
  • 只在出队时标记访问，导致同一单词重复入队。
  • 交换前沿后仍错误地依赖“左边一定来自起点”。
  • 生成邻居时没有恢复字符，后续位置基于错误字符串继续修改。
  • 误用 DFS 穷举所有路径，引发超时。

class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> dictionary = new HashSet<>(wordList);
        if (!dictionary.contains(endWord)) {
            return 0;
        }

        Set<String> front = new HashSet<>();
        Set<String> back = new HashSet<>();
        front.add(beginWord);
        back.add(endWord);
        dictionary.remove(beginWord);
        dictionary.remove(endWord);
        int length = 1;

        while (!front.isEmpty() && !back.isEmpty()) {
            if (front.size() > back.size()) {
                Set<String> temp = front;
                front = back;
                back = temp;
            }

            Set<String> nextFront = new HashSet<>();
            for (String word : front) {
                char[] chars = word.toCharArray();
                for (int i = 0; i < chars.length; i++) {
                    char original = chars[i];
                    for (char letter = 'a'; letter <= 'z'; letter++) {
                        if (letter == original) continue;
                        chars[i] = letter;
                        String next = new String(chars);
                        if (back.contains(next)) return length + 1;
                        if (dictionary.remove(next)) nextFront.add(next);
                    }
                    chars[i] = original;
                }
            }
            front = nextFront;
            length++;
        }
        return 0;
    }
}
var ladderLength = function (beginWord, endWord, wordList) {
  const dictionary = new Set(wordList);
  if (!dictionary.has(endWord)) return 0;

  let front = new Set([beginWord]);
  let back = new Set([endWord]);
  dictionary.delete(beginWord);
  dictionary.delete(endWord);
  let length = 1;

  while (front.size > 0 && back.size > 0) {
    if (front.size > back.size) [front, back] = [back, front];
    const nextFront = new Set();

    for (const word of front) {
      const chars = [...word];
      for (let i = 0; i < chars.length; i++) {
        const original = chars[i];
        for (let code = 97; code <= 122; code++) {
          const letter = String.fromCharCode(code);
          if (letter === original) continue;
          chars[i] = letter;
          const next = chars.join("");
          if (back.has(next)) return length + 1;
          if (dictionary.has(next)) {
            dictionary.delete(next);
            nextFront.add(next);
          }
        }
        chars[i] = original;
      }
    }
    front = nextFront;
    length++;
  }
  return 0;
};

        dictionary = set(wordList)
        if endWord not in dictionary:
            return 0

        front = {beginWord}
        back = {endWord}
        dictionary.discard(beginWord)
        dictionary.discard(endWord)
        length = 1

        while front and back:
            if len(front) > len(back):
                front, back = back, front
            next_front = set()

            for word in front:
                chars = list(word)
                for index, original in enumerate(chars):
                    for letter in "abcdefghijklmnopqrstuvwxyz":
                        if letter == original:
                            continue
                        chars[index] = letter
                        candidate = "".join(chars)
                        if candidate in back:
                            return length + 1
                        if candidate in dictionary:
                            dictionary.remove(candidate)
                            next_front.add(candidate)
                    chars[index] = original
            front = next_front
            length += 1
        return 0

public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string> dictionary(wordList.begin(), wordList.end());
        if (!dictionary.count(endWord)) return 0;

        unordered_set<string> front{beginWord};
        unordered_set<string> back{endWord};
        dictionary.erase(beginWord);
        dictionary.erase(endWord);
        int length = 1;

        while (!front.empty() && !back.empty()) {
            if (front.size() > back.size()) swap(front, back);
            unordered_set<string> nextFront;

            for (string word : front) {
                for (int i = 0; i < static_cast<int>(word.size()); ++i) {
                    char original = word[i];
                    for (char letter = 'a'; letter <= 'z'; ++letter) {
                        if (letter == original) continue;
                        word[i] = letter;
                        if (back.count(word)) return length + 1;
                        if (dictionary.erase(word)) nextFront.insert(word);
                    }
                    word[i] = original;
                }
            }
            front = move(nextFront);
            ++length;
        }
        return 0;
    }
};
