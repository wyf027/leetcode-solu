2172 · 数组的最大与和

Maximum AND Sum of Array

每个篮子只有两个位置。把数字放在哪里，才能让按位与的总得分最大？先理解规则，再展开下方题解探索状态。

LeetCode 官方题目 ↗

题意与输入

给定整数数组 nums 和整数 numSlots。篮子编号从 1 到 numSlots，每个篮子至多容纳两个数。必须放入数组中的所有数字，允许篮子留空。每个数字的得分是它与所在篮子编号的按位与；返回所有合法分配中的最大得分和。

maximumANDSum(nums: integer[], numSlots: integer) → integer

按位与只保留两侧都是 1 的二进制位。例如 6 & 2 = 0110₂ & 0010₂ = 0010₂ = 2。这里不是逻辑与，也不是把同一篮子的数字互相做与运算。

约束

  • n == nums.length
  • 1 ≤ numSlots ≤ 9
  • 1 ≤ n ≤ 2 × numSlots
  • 1 ≤ nums[i] ≤ 15

官方示例

示例 1

nums = [1,2,3,4,5,6]
numSlots = 3
输出：9

篮子 1 放 [1,4]，篮子 2 放 [2,6]，篮子 3 放 [3,5]。

各项得分依次为 1、0、2、2、3、1，总和为 9。

示例 2

nums = [1,3,10,4,7,1]
numSlots = 9
输出：24

篮子 1 放 [1,1]，篮子 3 放 [3]，篮子 4 放 [4]，篮子 7 放 [7]，篮子 9 放 [10]。

得分为 1 + 1 + 3 + 4 + 7 + 8 = 24。篮子 2、5、6、8 可以为空。

题解 · 三进制状态压缩 DP

核心洞察

一个篮子只需记录放了 0、1、2 个数字。用一个三进制位表示一个篮子的占用数，全部篮子的状态只有 3^m 种，其中 m = numSlots。固定按数组顺序放数，状态的各位之和就是已经放入的数字个数，不需要再存一个索引维度。

到达同一占用状态的历史方案，剩余容量与待放数字完全一样；因此只保留得分最高的历史。数字此前具体放在哪里，无需进入 DP 状态。

目标篮子新增得分新状态本次候选值合并后的 DP 值
合并后的 DP 值包含其他前驱的贡献，可能高于本次候选值。高亮篮子表示刚放入的位置；多条最优路径时仅回放其中一条。




完整过程
  1. 预计算 p[j] = 3^j，篮子编号为 j + 1。
  2. 定义 dp[s] 为恰好形成占用状态 s 时，放完数组前 k 个数的最大得分，k 是 s 的三进制各位之和。初始化 dp[0] = 0，其余为 -1（不可达）。
  3. 从小到大遍历 s，跳过不可达状态。若 k 已等于 n，用 dp[s] 更新答案，不再继续放入。
  4. 否则尝试每个篮子 j。该位 floor(s / p[j]) % 3 < 2 时，令 t = s + p[j]。
  5. 更新 dp[t] = max(dp[t], dp[s] + (nums[k] & (j + 1)))。
  6. 返回所有放完 n 个数的状态中的最大值。因为 n 可能小于 2m，答案状态不一定是全 2。
篮子 1、2、3 的占用为 [1,2,0]
s = 1×3⁰ + 2×3¹ + 0×3² = 7，k = 3
再向篮子 3 放 nums[3]：t = 7 + 3² = 16
新占用为 [1,2,1]，新增得分 nums[3] & 3


为什么正确
状态充分：固定处理顺序后，k 由占用总数确定。同一 s 的后续数字和可用容量一致，只需保留最大历史得分。
归纳：空状态对应唯一空分配，得分为 0。假设所有 k 个数的可达状态均保存最优得分。任何 k+1 个数的合法分配，移除最后处理的数字后，都得到某个合法前驱状态；算法会枚举其对应篮子并加上该数字得分。反过来，每条转移只进入未满篮子，生成的分配都合法。取最大值即得到新状态的最优得分。
遍历顺序与终点：转移总使整数状态增大，因此顺序遍历时前驱已经处理完毕。枚举所有占用和为 n 的状态覆盖全部完整分配，取最大值就是答案。
边界与复杂度
单篮子直接容纳至多两个数；重复数字仍按不同数组位置处理；得分 0 是合法答案，不能与不可达状态混淆。最大状态数为 3⁹ = 19683。扫描各位与尝试篮子均为 O(m)，总时间 O(m × 3^m)，额外空间 O(3^m)。得分不超过 2 × (1 + … + m) ≤ 90，普通整数足够。

Java
import java.util.Arrays;

class Solution {
    public int maximumANDSum(int[] nums, int numSlots) {
        int[] pow = new int[numSlots];
        int size = 1;
        for (int j = 0; j < numSlots; j++) {
            pow[j] = size;
            size *= 3;
        }
        int[] dp = new int[size];
        Arrays.fill(dp, -1);
        dp[0] = 0;
        int answer = 0;
        for (int s = 0; s < size; s++) {
            if (dp[s] < 0) continue;
            int k = 0;
            for (int x = s; x > 0; x /= 3) k += x % 3;
            if (k == nums.length) {
                answer = Math.max(answer, dp[s]);
                continue;
            }
            for (int j = 0; j < numSlots; j++) {
                if (s / pow[j] % 3 == 2) continue;
                int t = s + pow[j];
                dp[t] = Math.max(dp[t], dp[s] + (nums[k] & (j + 1)));
            }
        }
        return answer;
    }
}

/**
 * @param {number[]} nums
 * @param {number} numSlots
 * @return {number}

var maximumANDSum = function(nums, numSlots) {
    const pow = Array.from({length: numSlots}, (_, j) => 3 ** j);
    const size = 3 ** numSlots;
    const dp = new Int32Array(size).fill(-1);
    dp[0] = 0;
    let answer = 0;
    for (let s = 0; s < size; s++) {
        if (dp[s] < 0) continue;
        let k = 0;
        for (let x = s; x > 0; x = Math.floor(x / 3)) k += x % 3;
        if (k === nums.length) {
            answer = Math.max(answer, dp[s]);
            continue;
        }
        for (let j = 0; j < numSlots; j++) {
            if (Math.floor(s / pow[j]) % 3 === 2) continue;
            const t = s + pow[j];
            dp[t] = Math.max(dp[t], dp[s] + (nums[k] & (j + 1)));
        }
    }
    return answer;
};


Python 3
from typing import List

class Solution:
    def maximumANDSum(self, nums: List[int], numSlots: int) -> int:
        powers = [3 ** j for j in range(numSlots)]
        size = 3 ** numSlots
        dp = [-1] * size
        dp[0] = 0
        answer = 0
        for s in range(size):
            if dp[s] < 0:
                continue
            k, x = 0, s
            while x:
                k += x % 3
                x //= 3
            if k == len(nums):
                answer = max(answer, dp[s])
                continue
            for j, power in enumerate(powers):
                if s // power % 3 == 2:
                    continue
                t = s + power
                dp[t] = max(dp[t], dp[s] + (nums[k] & (j + 1)))
        return answer

替代方案与常见错误
二进制座位 DP：把每个篮子拆成两个座位，共 2m 位，位数统计确定下一个数字，座位 q 对应篮子 floor(q/2)+1。时间 O(m × 2^(2m))、空间 O(2^(2m))，更容易利用位运算，但区分了同篮子的等价座位。
记忆化搜索：同样以三进制状态缓存，k 由状态确定，递归枚举下一篮子。渐近复杂度相同，递归深度至多 n。也可建数字到容量为 2 的篮子的最大费用流，但此规模下实现成本更高。
  • 不能用逻辑与 && 替代按位与 &；位运算表达式加括号，避免优先级问题。
  • 篮子编号从 1 开始，数组下标从 0 开始，得分必须使用 j+1。
  • 不得向占用为 2 的三进制位继续加 1，否则会进位污染相邻篮子。
  • 只读最终全满状态会在 n < 2m 时失败。
  • 贪心只看当前得分会抢占后续数字需要的位置。例如 nums=[1,3,3]、m=2，先把两个数放入篮子 1 可得到 4，而把 1 放篮子 1、两个 3 放篮子 2 可得 5。
  • 状态记录容量即可；把完整分配历史纳入缓存会造成重复状态。
面试追问
每篮容量为 c？改用 c+1 进制，时间 O(m(c+1)^m)。如何返回方案？更新更优 DP 值时保存前驱状态和篮子，最后倒序回溯，演示就是这种做法。数组能否重排？任意固定处理顺序都能枚举所有分配，因此最优值不受顺序影响。m 很大怎么办？指数状态不再适用，可转向有容量的二分图最大权匹配或费用流建模。
