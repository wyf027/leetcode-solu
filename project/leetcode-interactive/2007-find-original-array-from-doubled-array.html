Find Original Array From Doubled Array

一半是原来的数，一半是它们的两倍。打乱之后，还能还原吗？

01 / PROBLEM

题目说明

从整数数组 original 出发，把其中每个元素的两倍追加到数组，再将整体顺序打乱，得到 changed。给定 changed，请恢复任意一个符合这一过程的原数组；如果不存在，返回空数组 []。返回元素的顺序不限，但重复元素的数量必须准确。

参数：changed: integer[]　返回：integer[]
“双倍”指每个元素产生一个两倍值，原来的元素也保留在数组中。

约束

  • 1 ≤ changed.length ≤ 10⁵
  • 0 ≤ changed[i] ≤ 10⁵

04 / SOLUTION

准备好再揭开解法

展开后包含交互演示、证明与四语言代码。

排序 + 计数：让最小剩余值先配对

核心洞察

所有数都非负。设当前最小的剩余正数是 x，如果它只是某个原数的两倍，那么 x/2 也必须留在剩余数组里；这与 x 最小矛盾。因此可以把 x 当作原数，并消耗一个 2x。零需要特殊理解：0 的两倍仍是 0，所以每次必须消耗两个独立的零。

PAIRING WORKBENCH

双倍配对工作台

观察剩余频次如何变成一组组 x → 2x。每一步是一次完整配对；此处为算法演示，不是测试报告。为方便阅读，自定义演示限制为 1–24 个数。

完整过程

  1. 如果长度为奇数，直接返回 []。
  2. 升序排列 changed，并统计每个数剩余多少次。
  3. 从左到右遍历排序后的数 x。若其频次已经为 0，跳过，因为它已经在之前被配走。
  4. 先将 x 的频次减一，再检查 2x 是否还有库存。没有则返回 []；有则减一，并将 x 加入答案。先扣 x 的顺序也正确处理了 x = 0。
  5. 遍历完成返回答案。每次成功消耗两个元素，因此答案长度必为输入的一半。

示例 1 排序后为 [1,2,3,4,6,8]：取 (1,2)，跳过已消耗的 2；取 (3,6)，再取 (4,8)；最终得到 [1,3,4]。

正确性证明

不变式：已记录的每个 x 都对应两个真实消耗的元素 x 和 2x；计数表准确表示尚未使用的多重集合。

贪心选择：对剩余最小正数 x，任何合法划分都必须让它作为原数，否则还需更小的 x/2 与它配对。零只能与另一个零配对。故合法解存在时，消耗 (x,2x) 是强制选择；相等元素可以互换身份，不影响后续解。

失败与终止：缺少 2x 时，这个强制配对不存在，整个输入无解。若每轮配对都成功，剩余元素持续减少，最终全部消耗；记录数组及其两倍值的多重集合恰等于 changed，因此返回结果合法。

边界与常见错误

  • 长度为偶数只是必要条件，并不保证有解。
  • 零频次必须为偶数。先扣原数再找倍数，不能用同一个零两次。
  • 必须保存次数；Set 会丢失重复值。
  • 跳过已消耗元素，否则会把倍数再当原数。
  • JavaScript 默认 sort() 按字符串排序，必须写 (a,b) => a-b。
  • 某一步失败应返回 []，不能返回已有的部分结果。
  • 2x 最多为 200000；计数数组方案须检查索引或分配足够空间。

复杂度与替代方案

设 n 为数组长度。排序耗时 O(n log n)，频次操作按哈希表通常的均摊 O(1) 计，总时间 O(n log n)，额外空间 O(n)，包括计数表和输出。下方 Python 与 JavaScript 还会复制排序数组；Java 与 C++ 原地排序输入。

值域受限时可以使用计数数组，从 0 扫到最大值 U，总时间 O(n + U)、辅助计数空间 O(U)，另有 O(n) 输出。零单独检查奇偶，正数检查 cnt[2x] ≥ cnt[x] 后批量扣除。也可排序后用“待匹配倍数”队列，但需要维护队列顺序和零的处理，频次表更直观。

面试追问

  • 允许负数怎么办？应按绝对值从小到大处理，避免 -4 在 -2 之前被错误认作原数；倍数计算注意溢出。
  • 能否不改变输入？先复制数组再排序，增加 O(n) 复制空间；或只排序频次表的不同键。
  • 答案是否唯一？在本题非负约束下，原数组的多重集合由最小值配对逐步确定，排列可以不同。
  • 数据长度很大、值域很小？用计数数组省去比较排序。流式输入时可先累计频次，最后统一还原。

Java
import java.util.Arrays;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] findOriginalArray(int[] changed) {
        int n = changed.length;
        if (n % 2 != 0) return new int[0];
        Arrays.sort(changed);
        Map<Integer, Integer> count = new HashMap<>();
        for (int x : changed) {
            count.put(x, count.getOrDefault(x, 0) + 1);
        }
        int[] answer = new int[n / 2];
        int k = 0;
        for (int x : changed) {
            if (count.get(x) == 0) continue;
            count.put(x, count.get(x) - 1);
            if (count.getOrDefault(2 * x, 0) == 0) {
                return new int[0];
            }
            count.put(2 * x, count.get(2 * x) - 1);
            answer[k++] = x;
        }
        return answer;
    }
}

/**

var findOriginalArray = function(changed) {
    if (changed.length % 2 !== 0) return [];
    const sorted = [...changed].sort((a, b) => a - b);
    const count = new Map();
    for (const x of sorted) {
        count.set(x, (count.get(x) || 0) + 1);
    }
    const answer = [];
    for (const x of sorted) {
        if (count.get(x) === 0) continue;
        count.set(x, count.get(x) - 1);
        if (!count.get(2 * x)) return [];
        count.set(2 * x, count.get(2 * x) - 1);
        answer.push(x);
    }
    return answer;
};
Python 3
from collections import Counter
from typing import List

class Solution:
    def findOriginalArray(self, changed: List[int]) -> List[int]:
        if len(changed) % 2:
            return []
        count = Counter(changed)
        answer = []
        for x in sorted(changed):
            if count[x] == 0:
                continue
            count[x] -= 1
            if count[2 * x] == 0:
                return []
            count[2 * x] -= 1
            answer.append(x)
        return answer
C++
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> findOriginalArray(vector<int>& changed) {
        if (changed.size() % 2 != 0) return {};
        sort(changed.begin(), changed.end());
        unordered_map<int, int> count;
        for (int x : changed) ++count[x];
        vector<int> answer;
        answer.reserve(changed.size() / 2);
        for (int x : changed) {
            if (count[x] == 0) continue;
            --count[x];
            if (count[2 * x] == 0) return {};
            --count[2 * x];
            answer.push_back(x);
        }
        return answer;
    }
};
