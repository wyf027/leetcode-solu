Solution

计数，再找最短的那块木板

核心洞察

一个 balloon 需要 1 个 b、1 个 a、2 个 l、2 个 o 和 1 个 n。先统计这五种字母，再把双份需求折算为“能支持多少个单词”。最少的那一项决定答案。

min(count[b], count[a], count[l] / 2, count[o] / 2, count[n])，其中除法向下取整

完整过程

  1. 创建五个计数槽，遍历 text。
  2. 遇到 b、a、l、o、n 时增加对应计数；其余字符不影响结果。
  3. 对 l 和 o 的数量各除以 2 并向下取整。
  4. 取五个可供应份数的最小值。

为什么正确

上界：若能拼出 k 个单词，就至少需要 k 个 b、a、n 和 2k 个 l、o，因此 k 不会超过公式中的任何一项，也不会超过它们的最小值。

可达性：令公式最小值为 m。五类字母分别至少能满足 m 份需求，且不同类别互不争用字符，所以确实能取出 m 组 balloon。上下界相同，公式即为最大值。

边界与复杂度

  • 缺少任意必需字母时，最小值为 0。
  • l 或 o 只有奇数个时，多出的单个字符无法组成下一份。
  • 长度为 1 或全部是无关字母时，答案仍为 0。
  • 时间复杂度 O(n)；额外空间复杂度 O(1)。

替代方案、面试追问与常见错误

替代方案：可以先统计全部 26 个小写字母，再按目标词频计算；写法更通用，但本题只需五个槽。也可以不断尝试扣减一整组字符，但重复轮次不如一次计数直接。

面试追问：如果目标词不是固定的 balloon，先统计目标串各字符需求量，再对每种字符计算 sourceCount / targetCount 的向下取整并取最小值。若字符集扩展到 Unicode，可使用映射表而不是长度为 26 的数组。

常见错误：忘记 l 和 o 各需要两个；对除法结果四舍五入；把所有七个字符的总量除以 7；或在每轮扣减时允许同一个源字符重复使用。

四语言实现

可直接提交的代码

Java · LeetCode 提交格式
class Solution {
    public int maxNumberOfBalloons(String text) {
        int b = 0, a = 0, l = 0, o = 0, n = 0;

        for (char ch : text.toCharArray()) {
            switch (ch) {
                case 'b': b++; break;
                case 'a': a++; break;
                case 'l': l++; break;
                case 'o': o++; break;
                case 'n': n++; break;
                default: break;
            }
        }

        return Math.min(
            Math.min(Math.min(b, a), Math.min(l / 2, o / 2)),
            n
        );
    }
}
JavaScript · LeetCode 提交格式
/**
 * @param {string} text
 * @return {number}
 */
var maxNumberOfBalloons = function(text) {
    const count = { b: 0, a: 0, l: 0, o: 0, n: 0 };

    for (const ch of text) {
        if (Object.prototype.hasOwnProperty.call(count, ch)) {
            count[ch]++;
        }
    }

    return Math.min(
        count.b,
        count.a,
        Math.floor(count.l / 2),
        Math.floor(count.o / 2),
        count.n
    );
};

C++ · LeetCode 提交格式
class Solution {
public:
    int maxNumberOfBalloons(string text) {
        int b = 0, a = 0, l = 0, o = 0, n = 0;

        for (char ch : text) {
            if (ch == 'b') ++b;
            else if (ch == 'a') ++a;
            else if (ch == 'l') ++l;
            else if (ch == 'o') ++o;
            else if (ch == 'n') ++n;
        }

        return min({b, a, l / 2, o / 2, n});
    }
};
