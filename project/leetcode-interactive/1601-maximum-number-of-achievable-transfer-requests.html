Balance the city

最多可达成的换楼请求数目

从员工的换楼请求中选出尽可能多的一组，让每栋楼搬入与搬出的人数恰好相等。先理解平衡条件，再进入交互实验室。

阅读题目平衡实验室题解入口
01 / PROBLEM

题意

maximumRequests(n, requests)

共有 n 栋楼，编号 0 到 n - 1。requests[i] = [fromᵢ, toᵢ] 表示一名员工希望从 fromᵢ 搬到 toᵢ。

所有楼起初都满员。选中的请求只有在每栋楼的员工净变化均为 0 时才可实现，也就是对任意楼，搬出人数等于搬入人数。请返回最多能同时实现多少个请求。

参数形式
n: integer
requests: integer[][]
返回 integer

约束

  • 1 ≤ n ≤ 20
  • 1 ≤ requests.length ≤ 16
  • requests[i].length == 2
  • 0 ≤ fromᵢ, toᵢ < n

每个请求只能整体选取或放弃；从一栋楼到自身的请求也是合法请求。

02 / EXAMPLES

官方示例

示例 1

输入：n = 5
requests = [[0,1],[1,0],[0,1],
            [1,2],[2,0],[3,4]]
输出：5
解释：前五个请求形成两个闭合交换；
[3,4] 没有相应的回流请求。

示例 2

输入：n = 3
requests = [[0,0],[1,2],[2,1]]
输出：3
解释：[0,0] 不改变人数，楼 1 与楼 2
互换一人，因此全部请求都能实现。

示例 3

输入：n = 4
requests = [[0,3],[3,1],[1,2],[2,0]]
输出：4
解释：四个请求连成闭环，每栋楼恰好
搬出一人并搬入一人。

04 / SOLUTION

完整题解

独立折叠区域，准备好后再展开。

核心洞察

请求数 m ≤ 16，可以覆盖全部 2^m 个子集。选中 [from,to] 时，令 balance[from]--、balance[to]++。若最终所有余额都是 0，该子集可实现，用其请求数更新答案。

关键等价：所有楼的 balance == 0，当且仅当每栋楼搬入人数等于搬出人数。无需模拟搬迁顺序。

完整过程

定义状态

递归下标 i、当前已选数量、长度为 n 的余额数组和全局最优值。

选择请求

修改出发楼与目标楼余额，递归到 i + 1，已选数量加一。

撤销并放弃

选择分支返回后恢复余额，再搜索不选择当前请求的分支。

叶子判定

当所有请求都决定完，逐楼检查余额；全部为零才更新最优值。

安全剪枝

若“已选 + 剩余请求数”都不超过当前最优值，当前分支不可能更优，可直接返回。

正确性证明

引理 1：搜索覆盖所有子集。

每个请求都有选与不选两条分支，因此每条根到叶路径唯一对应一个子集，所有子集也各有一条路径。

引理 2：余额判定准确。

每个选中请求对出发楼贡献 −1、目标楼贡献 +1；余额正是员工净变化。所有余额为零与题目的可实现条件完全等价。

定理：算法返回最优答案。

由引理 1，算法检查所有候选；由引理 2，它只接受且不会漏掉可实现子集。对这些子集的大小取最大值，所得即最多可达成请求数。

复杂度

时间：O(2^m · n)，叶子处检查 n 栋楼。

空间：O(n + m)，来自余额数组和递归栈。

若维护非零余额楼数，可把叶子判定降为 O(1)，指数项不变。

边界情况

  • from == to 对余额净影响为 0，可以选择。
  • 没有非空可行组合时，空集保证答案至少为 0。
  • 全部请求构成闭环时，答案是 m。
  • 重复请求仍代表不同员工，必须按下标分别决策。

替代方案

位掩码枚举

遍历所有 mask，逐位累加余额。逻辑直观、没有递归栈，复杂度同阶。

Meet-in-the-middle

若请求数扩大到约 40，可分别枚举两半，以相反余额向量配对并最大化计数。

面试追问

  • 为什么贪心不可靠？ 单个请求能否纳入依赖全局是否闭环，局部最优没有稳定交换性质。
  • 如何加速余额判定？ 维护非零余额楼栋数，余额跨过 0 时同步更新。
  • 若每个请求有收益？ 把已选数量替换为收益和，在平衡子集中最大化总收益。

常见错误

  • 只检查余额总和；无论选什么，它都恒为 0，必须逐楼检查。
  • 选择分支结束后忘记撤销两个余额。
  • 忽略 [x,x] 请求，它不会破坏平衡且能增加答案。
  • 在不同代码位置混用“搬入 − 搬出”的正负约定。

class Solution {
    private int best;
    private int[][] requests;
    private int[] balance;

    public int maximumRequests(int n, int[][] requests) {
        this.requests = requests;
        this.balance = new int[n];
        best = 0;
        dfs(0, 0);
        return best;
    }

    private void dfs(int index, int chosen) {
        if (chosen + requests.length - index <= best) return;
        if (index == requests.length) {
            for (int value : balance) {
                if (value != 0) return;
            }
            best = chosen;
            return;
        }
        int from = requests[index][0], to = requests[index][1];
        balance[from]--;
        balance[to]++;
        dfs(index + 1, chosen + 1);
        balance[from]++;
        balance[to]--;
        dfs(index + 1, chosen);
    }
}
/**
 * @param {number} n
 * @param {number[][]} requests
 * @return {number}
 */
var maximumRequests = function(n, requests) {
    const balance = new Array(n).fill(0);
    let best = 0;

    function dfs(index, chosen) {
        if (chosen + requests.length - index <= best) return;
        if (index === requests.length) {
            if (balance.every(value => value === 0)) best = chosen;
            return;
        }
        const [from, to] = requests[index];
        balance[from]--;
        balance[to]++;
        dfs(index + 1, chosen + 1);
        balance[from]++;
        balance[to]--;
        dfs(index + 1, chosen);
    }
    dfs(0, 0);
    return best;
};
from typing import List


class Solution:
    def maximumRequests(self, n: int, requests: List[List[int]]) -> int:
        balance = [0] * n
        best = 0

        def dfs(index: int, chosen: int) -> None:
            nonlocal best
            if chosen + len(requests) - index <= best:
                return
            if index == len(requests):
                if all(value == 0 for value in balance):
                    best = chosen
                return
            from_building, to_building = requests[index]
            balance[from_building] -= 1
            balance[to_building] += 1
            dfs(index + 1, chosen + 1)
            balance[from_building] += 1
            balance[to_building] -= 1
            dfs(index + 1, chosen)

        dfs(0, 0)
        return best
class Solution {
    int best = 0;
    vector<int> balance;
    vector<vector<int>>* requests;

    void dfs(int index, int chosen) {
        int m = requests->size();
        if (chosen + m - index <= best) return;
        if (index == m) {
            for (int value : balance)
                if (value != 0) return;
            best = chosen;
            return;
        }
        int from = (*requests)[index][0];
        int to = (*requests)[index][1];
        --balance[from];
        ++balance[to];
        dfs(index + 1, chosen + 1);
        ++balance[from];
        --balance[to];
        dfs(index + 1, chosen);
    }

public:
    int maximumRequests(int n, vector<vector<int>>& req) {
        balance.assign(n, 0);
        requests = &req;
        dfs(0, 0);
        return best;
    }
};
