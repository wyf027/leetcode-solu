Problem

题意与输入约定

给定字符串数组 words，其中的单词已经按照某种未知语言的字典序升序排列。返回任意一个与该排序一致的字符顺序；如果不存在合法顺序，返回空字符串。

准确转述

未知语言使用小写英文字母，但字母之间的优先级未知。比较两个单词时，第一对不同字符决定二者的顺序；如果前面所有字符都相同，则较短单词必须排在较长单词之前。

可能存在多个合法字母表，返回其中任意一个即可。返回结果必须恰好包含输入中出现过的每个不同字符一次。若约束产生环，或出现“长词排在其严格前缀之前”的情况，则无解。

官方元数据给出的接口为 alienOrder，参数为 string[] words，返回值为 string。

约束

  • 1 ≤ words.length ≤ 100
  • 1 ≤ words[i].length ≤ 100
  • words[i] 仅由小写英文字母组成

Before the Answer

三个自检问题

为什么只看第一处分歧？

同前缀之后的首个不同字符已经决定两个单词的先后；其后的字符不能再推出跨词关系。

为什么要先登记全部字符？

只出现在孤立单词里的字符也必须进入答案，即使它没有任何入边或出边。

怎样同时识别两类无解？

建图时检查非法前缀；拓扑排序结束后检查输出字符数是否等于节点总数，以识别环。

Full Solution

从局部比较到全局字母表

核心路线：相邻词提取偏序边，Kahn 算法生成拓扑序；非法前缀与环分别在建图、出队结束时识别。

核心洞察

已排序单词表并不会直接告诉我们完整字母表，但每对相邻单词的第一处不同字符都给出一条可靠规则：左词字符必须位于右词字符之前。所有规则组成一张有向图，合法字母表就是这张图的任意拓扑序。

完整过程

  1. 扫描所有单词，先为每个出现过的字符建立节点，入度初始化为 0。
  2. 逐对比较相邻单词，找到第一处不同字符，添加一条“左字符 → 右字符”的边。
  3. 若前者更长且后者是前者的完整前缀，立即返回空字符串。
  4. 边要去重；只有首次添加时才增加终点入度。
  5. 把所有零入度字符放入队列，不断弹出并削减后继入度。
  6. 若最终输出数少于字符总数，说明有环；否则输出字符串即为一个合法答案。

正确性说明

引理 1 · 每条边都必要

相邻词的公共前缀相同，第一处分歧决定它们的字典序，因此左字符必须先于右字符。

引理 2 · 输出遵守所有边

Kahn 算法只选择当前入度为 0 的字符；选择某字符时，所有指向它的前驱都已输出。

结论 · 返回值正确

若输出覆盖全部节点，它遵守全部必要关系，是合法字母序；若未覆盖全部节点，剩余子图含环，无合法线性序。

边界情况

  • 单个单词：所有不同字符都应出现在结果中。
  • 重复单词：不产生新边，但字符仍已登记。
  • 合法前缀：如 ["ab", "abc"]，不产生边。
  • 非法前缀：如 ["abc", "ab"]，直接无解。
  • 重复边：必须去重，否则会错误增加入度。
  • 多个零入度字符：可能有多个正确答案；顺序任选。

复杂度

令 C 为所有单词的字符总数，V 为不同字符数，E 为去重后的关系数。

时间 O(C + E)
空间 O(V + E)

下方代码为获得稳定展示顺序使用最小堆或排序队列；若将其计入，可写成 O(C + E + V log V)。

四语言完整实现

四份代码均采用“去重邻接表 + 入度 + Kahn 拓扑排序”，并处理非法前缀。最小堆只用于让无约束字符的选择更稳定，不影响正确性。

import java.util.*;

class Solution {
    public String alienOrder(String[] words) {
        Map<Character, Set<Character>> graph = new HashMap<>();
        Map<Character, Integer> indegree = new HashMap<>();

        for (String word : words) {
            for (char ch : word.toCharArray()) {
                graph.putIfAbsent(ch, new HashSet<>());
                indegree.putIfAbsent(ch, 0);
            }
        }

        for (int i = 0; i + 1 < words.length; i++) {
            String first = words[i];
            String second = words[i + 1];
            int common = Math.min(first.length(), second.length());
            int j = 0;

            while (j < common && first.charAt(j) == second.charAt(j)) {
                j++;
            }

            if (j == common) {
                if (first.length() > second.length()) {
                    return "";
                }
                continue;
            }

            char from = first.charAt(j);
            char to = second.charAt(j);
            if (graph.get(from).add(to)) {
                indegree.put(to, indegree.get(to) + 1);
            }
        }

        PriorityQueue<Character> ready = new PriorityQueue<>();
        for (Map.Entry<Character, Integer> entry : indegree.entrySet()) {
            if (entry.getValue() == 0) {
                ready.offer(entry.getKey());
            }
        }

        StringBuilder order = new StringBuilder();
        while (!ready.isEmpty()) {
            char current = ready.poll();
            order.append(current);

            for (char next : graph.get(current)) {
                int nextDegree = indegree.get(next) - 1;
                indegree.put(next, nextDegree);
                if (nextDegree == 0) {
                    ready.offer(next);
                }
            }
        }

        return order.length() == indegree.size() ? order.toString() : "";
    }
}

var alienOrder = function (words) {
  const graph = new Map();
  const indegree = new Map();

  for (const word of words) {
    for (const ch of word) {
      if (!graph.has(ch)) graph.set(ch, new Set());
      if (!indegree.has(ch)) indegree.set(ch, 0);
    }
  }

  for (let i = 0; i + 1 < words.length; i += 1) {
    const first = words[i];
    const second = words[i + 1];
    const common = Math.min(first.length, second.length);
    let j = 0;

    while (j < common && first[j] === second[j]) {
      j += 1;
    }

    if (j === common) {
      if (first.length > second.length) return "";
      continue;
    }

    const from = first[j];
    const to = second[j];
    if (!graph.get(from).has(to)) {
      graph.get(from).add(to);
      indegree.set(to, indegree.get(to) + 1);
    }
  }

  const ready = [];
  for (const [ch, degree] of indegree) {
    if (degree === 0) ready.push(ch);
  }
  ready.sort();

  let order = "";
  while (ready.length > 0) {
    const current = ready.shift();
    order += current;

    for (const next of graph.get(current)) {
      indegree.set(next, indegree.get(next) - 1);
      if (indegree.get(next) === 0) {
        ready.push(next);
        ready.sort();
      }
    }
  }

  return order.length === indegree.size ? order : "";
};
from typing import List
import heapq


class Solution:
    def alienOrder(self, words: List[str]) -> str:
        graph = {}
        indegree = {}

        for word in words:
            for ch in word:
                graph.setdefault(ch, set())
                indegree.setdefault(ch, 0)

        for first, second in zip(words, words[1:]):
            common = min(len(first), len(second))
            index = 0

            while index < common and first[index] == second[index]:
                index += 1

            if index == common:
                if len(first) > len(second):
                    return ""
                continue

            source = first[index]
            target = second[index]
            if target not in graph[source]:
                graph[source].add(target)
                indegree[target] += 1

        ready = [ch for ch, degree in indegree.items() if degree == 0]
        heapq.heapify(ready)
        order = []

        while ready:
            current = heapq.heappop(ready)
            order.append(current)

            for nxt in graph[current]:
                indegree[nxt] -= 1
                if indegree[nxt] == 0:
                    heapq.heappush(ready, nxt)

        return "".join(order) if len(order) == len(indegree) else ""
#include <array>
#include <functional>
#include <queue>
#include <set>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string alienOrder(vector<string>& words) {
        array<set<int>, 26> graph;
        array<int, 26> indegree{};
        array<bool, 26> seen{};
        int nodeCount = 0;

        for (const string& word : words) {
            for (char ch : word) {
                int node = ch - 'a';
                if (!seen[node]) {
                    seen[node] = true;
                    ++nodeCount;
                }
            }
        }

        for (int i = 0; i + 1 < static_cast<int>(words.size()); ++i) {
            const string& first = words[i];
            const string& second = words[i + 1];
            int common = min(first.size(), second.size());
            int j = 0;

            while (j < common && first[j] == second[j]) {
                ++j;
            }

            if (j == common) {
                if (first.size() > second.size()) {
                    return "";
                }
                continue;
            }

            int from = first[j] - 'a';
            int to = second[j] - 'a';
            if (graph[from].insert(to).second) {
                ++indegree[to];
            }
        }

        priority_queue<int, vector<int>, greater<int>> ready;
        for (int node = 0; node < 26; ++node) {
            if (seen[node] && indegree[node] == 0) {
                ready.push(node);
            }
        }

        string order;
        while (!ready.empty()) {
            int current = ready.top();
            ready.pop();
            order.push_back(static_cast<char>('a' + current));

            for (int next : graph[current]) {
                --indegree[next];
                if (indegree[next] == 0) {
                    ready.push(next);
                }
            }
        }

        return static_cast<int>(order.size()) == nodeCount ? order : "";
    }
};

替代方案：DFS 三色标记

同一张图也可用 DFS：0 表示未访问，1 表示正在递归栈中，2 表示已完成。遇到指向状态 1 的节点即发现环；节点退出递归时压入答案，最后反转。DFS 很适合解释环检测，但 Kahn 算法同时呈现零入度选择，通常更直观。

面试追问

  • 怎样判断答案是否唯一？ Kahn 过程中任一步零入度候选超过一个，则拓扑序不唯一。
  • 怎样返回所有合法顺序？ 对零入度候选做回溯，每层选择一个并恢复入度；结果数可能指数级。
  • 若字符集不止 26 个字母？ 使用哈希映射存节点与入度，算法本身不变。
  • 能否比较所有单词对？ 不需要；已排序序列中，相邻对足以提供保证整体顺序所需的约束。
