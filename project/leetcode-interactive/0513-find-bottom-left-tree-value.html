找树左下角的值

一棵树向下生长，最后一层可能并不完整。你的任务只有一个：找出最深处、也最靠左的那个节点值。

Problem briefing

题目说明

给定二叉树根节点 root，返回二叉树最底层中最左侧节点的值。树中至少有一个节点。

官方示例

示例 1 
输入：root = [2,1,3]
输出：1
示例 2 
输入：root = [1,2,3,4,null,5,6,null,null,7]
输出：7

函数形式

findBottomLeftValue(root: TreeNode): integer

参数是二叉树根节点，返回值是一个整数。

约束

  • 节点数量在 [1, 10⁴] 范围内。
  • −2³¹ ≤ Node.val ≤ 2³¹ − 1。

Complete editorial

题解：按层锁定最左节点

我们选择广度优先搜索。队列天然按层组织节点；每一层开始时，队首就是这一层最左侧的节点。

1

核心洞察

每层处理前先记录队首值，然后完整弹出这一层，并按“左孩子、右孩子”的顺序加入下一层。层数越深，记录越新；遍历结束时留下的就是最底层最左值。

完整过程

  1. 将根节点放入队列。
  2. 队列非空时，先读取本层节点数。
  3. 把此刻的队首值保存为答案候选。
  4. 依次弹出本层所有节点，先左后右加入非空孩子。
  5. 队列清空后返回最后一次保存的候选值。

边界处理

  • 单节点：根节点既是最底层，也是最左节点。
  • 退化树：无论只向左还是只向右，逐层更新都成立。
  • 最值节点：只复制整数，不做算术运算，不会产生溢出。
  • 根节点：题目保证至少一个节点，无需处理空树返回值。

正确性证明

引理：每轮外层循环开始时，队列从左到右恰好包含当前深度的全部节点。初始时队列只有深度 0 的根节点，引理成立。若对某层从左到右出队，并把每个节点的左、右孩子依序入队，则得到的正是下一层从左到右的全部节点，因此引理对下一层仍成立。

结论：根据引理，每轮开始时的队首就是当前层最左节点，算法把它记录为候选值。外层循环按深度递增执行，最后一次记录来自最底层。因此返回值必为最底层最左节点值。

时间 O(n) · 每个节点进出队一次
空间 O(w) · w 为树的最大宽度，最坏 O(n)

Implementation

四语言完整代码

Java · LeetCode 可提交
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int findBottomLeftValue(TreeNode root) {
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int answer = root.val;

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            answer = queue.peek().val;

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
            }
        }
        return answer;
    }
}

/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var findBottomLeftValue = function(root) {
    const queue = [root];
    let head = 0;
    let answer = root.val;

    while (head < queue.length) {
        const levelSize = queue.length - head;
        answer = queue[head].val;

        for (let i = 0; i < levelSize; i++) {
            const node = queue[head++];
            if (node.left !== null) queue.push(node.left);
            if (node.right !== null) queue.push(node.right);
        }
    }
    return answer;
};
Python 3 · LeetCode 可提交
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional


class Solution:
    def findBottomLeftValue(self, root: Optional[TreeNode]) -> int:
        queue = deque([root])
        answer = root.val

        while queue:
            answer = queue[0].val
            for _ in range(len(queue)):
                node = queue.popleft()
                if node.left is not None:
                    queue.append(node.left)
                if node.right is not None:
                    queue.append(node.right)

        return answer
C++ · LeetCode 可提交
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    int findBottomLeftValue(TreeNode* root) {
        queue<TreeNode*> nodes;
        nodes.push(root);
        int answer = root->val;

        while (!nodes.empty()) {
            int levelSize = static_cast<int>(nodes.size());
            answer = nodes.front()->val;

            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = nodes.front();
                nodes.pop();
                if (node->left != nullptr) nodes.push(node->left);
                if (node->right != nullptr) nodes.push(node->right);
            }
        }
        return answer;
    }
};

Further thinking

替代方案与面试追问

替代方案：深度优先搜索

先访问左子树，再访问右子树，并记录当前最深深度。只有在首次到达更深层时才更新答案。时间仍为 O(n)，递归栈最坏为 O(n)。优势是代码短，风险是高度很大时可能触发调用栈限制。

追问 1：能否不显式记录每层大小？

可以。让队列按“右孩子先、左孩子后”入队，并持续覆盖答案；最后出队的节点就是最底层最左节点。不过按层记录的版本意图更直接。

追问 2：为什么不能看到叶子就立即返回？

较浅层的左叶子可能先出现，但题目优先要求“最底层”。必须确认不存在更深层后，才能确定答案。

常见错误有哪些？

把“最左叶子”误当成答案；在层末而非层初记录；孩子入队顺序写反；使用数组 shift 导致 JavaScript 队列退化；忘记题目保证根节点非空。
