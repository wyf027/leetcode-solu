String Matching in an Array —— 在单词之间寻找“藏起来”的完整片段。

简单数组字符串非付费题

题目描述

给定字符串数组 words，找出其中所有满足以下条件的字符串：它是数组里另一个字符串的非空子字符串。答案可以按任意顺序返回。

函数形式： stringMatching(words: string[]) → string[]

注意“另一个字符串”：不能用单词本身证明自己符合条件。题目保证数组中的字符串互不相同。

约束

  • 1 <= words.length <= 100
  • 1 <= words[i].length <= 30
  • words[i] 仅含小写英文字母
  • words 中每个字符串都互不相同

官方示例

输出顺序可以不同

示例 1
输入：words = ["mass","as","hero","superhero"]
输出：["as","hero"]
解释："as" 藏在 "mass" 中，"hero" 藏在 "superhero" 中；["hero","as"] 同样有效。
示例 2
输入：words = ["leetcode","et","code"]
输出：["et","code"]
解释："et" 和 "code" 都是 "leetcode" 的子字符串。
示例 3
输入：words = ["blue","green","bu"]
输出：[]
解释：没有任何单词是另一个单词的子字符串。

题解：枚举候选词与承载词

核心洞察

数据规模最多只有 100 个单词，每个单词最多 30 个字符。直接枚举两个不同位置 i、j，检查 words[j] 是否包含 words[i]，足够清晰且高效。

完整过程

  1. 依次把每个 words[i] 当作候选子串。
  2. 枚举另一个位置 j，跳过 i == j。
  3. 若 words[j] 包含候选词，把候选词加入答案并停止它的内层循环。
  4. 所有候选词处理完成后返回答案。
正确性证明。 对任意输出的单词 words[i]，算法仅在找到某个 j ≠ i 且 words[j] 包含它时加入答案，所以输出中的每个单词都满足题意（可靠性）。反之，若某个单词满足题意，则存在另一个位置 j 包含它；枚举到这对位置时检查必然成功，因此它一定会被加入答案（完备性）。故算法返回且仅返回所有合法单词。

复杂度

时间：O(n² · L²)额外空间：O(1)答案空间：O(n)

这里按朴素子串查找的最坏情况估计，L 是最长单词长度。不同语言的标准库可能采用更快的匹配实现。

边界情况

  • 数组只有一个单词：答案为空。
  • 候选词比承载词长：必然不匹配。
  • 同一候选词可能被多个单词包含：只加入一次。
  • 整个候选词等于另一个词才算包含，但题目保证单词唯一，因此不会出现。

替代方案

可以把所有单词拼接后做计数，也可以对每一对字符串使用 KMP；但拼接需谨慎处理分隔与自匹配，KMP 在本题极小长度下增加了实现复杂度。直接使用语言标准库的子串搜索最合适。

面试追问

  • 若字符串长度达到十万，如何改用 KMP、Z 函数或 Aho–Corasick？
  • 若允许重复字符串，“另一个”应按索引还是按值定义？
  • 如何保持答案严格按原数组顺序？当前写法天然保持。

常见错误

  • 没有跳过 i == j，导致所有词都匹配自身。
  • 匹配后不退出内层循环，向答案重复添加。
  • 误把“子序列”当作“子字符串”。
  • 因为答案顺序任意而错误地忽略内容完整性。

Javacontains
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> stringMatching(String[] words) {
        List<String> answer = new ArrayList<>();

        for (int i = 0; i < words.length; i++) {
            for (int j = 0; j < words.length; j++) {
                if (i != j && words[j].contains(words[i])) {
                    answer.add(words[i]);
                    break;
                }
            }
        }
        return answer;
    }
}

var stringMatching = function(words) {
    const answer = [];

    for (let i = 0; i < words.length; i++) {
        for (let j = 0; j < words.length; j++) {
            if (i !== j && words[j].includes(words[i])) {
                answer.push(words[i]);
                break;
            }
        }
    }
    return answer;
};
Python 3in
from typing import List

class Solution:
    def stringMatching(self, words: List[str]) -> List[str]:
        answer = []

        for i, candidate in enumerate(words):
            for j, container in enumerate(words):
                if i != j and candidate in container:
                    answer.append(candidate)
                    break

        return answer
C++find
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> stringMatching(vector<string>& words) {
        vector<string> answer;

        for (int i = 0; i < static_cast<int>(words.size()); ++i) {
            for (int j = 0; j < static_cast<int>(words.size()); ++j) {
                if (i != j &&
                    words[j].find(words[i]) != string::npos) {
                    answer.push_back(words[i]);
                    break;
                }
            }
        }
        return answer;
    }
};
