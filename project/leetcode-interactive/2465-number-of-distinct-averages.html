01 / THE CHALLENGE

题目

给定一个从下标 0 开始、长度为偶数的整数数组 nums。反复取出并删除当前最小值和最大值，记录这两个数的平均值 (a + b) / 2，直到数组为空。返回记录中不同平均值的个数。遇到相同的最小值或最大值时，任选其中一个元素删除；一次操作消耗两个元素。

先试着手算，再操作下面的实验台。完整算法与四语言代码在页面底部，默认收起。

约束

  • 2 ≤ nums.length ≤ 100
  • nums.length 为偶数。
  • 0 ≤ nums[i] ≤ 100，每个元素都是整数。

示例 1

输入：nums = [4,1,4,0,3,5]
输出：2

先取 0 与 5，平均值 2.5，剩余 [4,1,4,3]；再取 1 与 4，平均值仍为 2.5，剩余 [4,3]；最后取 3 与 4，平均值 3.5。三次记录中有 2 种不同的值。

示例 2

输入：nums = [1,100]
输出：1

仅有一对数，记录平均值 50.5，然后数组清空。因此不同平均值的数目为 1。

04 / EDITORIAL

把观察变成算法

准备好后，展开完整推导与实现。

题解：排序 + 两端配对 + 集合

核心洞察

排序后，未使用区间的两端就是当前最小值与最大值。无需实际删除元素，只需让两个指针相向移动。另一个关键是：x / 2 = y / 2 当且仅当 x = y。因此集合直接存两数之和，它的大小就等于不同平均值的个数。

完整过程

  1. 将 nums 按数值升序排列。
  2. 设 left = 0、right = n - 1，准备一个空集合。
  3. 当 left < right 时，把 nums[left] + nums[right] 加入集合，再让左指针加一、右指针减一。
  4. 完成恰好 n / 2 轮，返回集合大小。
nums = [4,1,4,0,3,5]
排序 → [0,1,3,4,4,5]
第 1 轮：0 + 5 = 5，集合 {5}
第 2 轮：1 + 4 = 5，集合 {5}
第 3 轮：3 + 4 = 7，集合 {5,7}
返回 2（平均值分别为 2.5 与 3.5）

正确性说明

循环不变式：每轮开始时，排序数组的闭区间 [left, right] 恰好表示尚未取走的元素；集合恰好包含此前所有配对的和。初始时整个数组都未使用、集合为空，不变式成立。当前区间有序，所以两个端点是剩余元素的最小值和最大值，选取它们满足题目要求。记录和并移动指针后，不变式继续成立。偶数长度保证每轮有两个元素且最终全部处理。最后，和与平均值之间的一一对应关系保证集合大小正是题目要求的答案。

边界与复杂度

  • 长度为 2：只有一次配对，答案必为 1。
  • 元素全相同：每次和相同，答案为 1；仍必须消耗两个位置。
  • 重复数字没有额外影响；相同值的任意两个实例在数值上可互换。
  • 半整数平均值不能截断；存整数和自然避免这一问题。
  • 和的范围为 0–200；本题不会溢出。答案介于 1 与 n/2 之间。

时间复杂度 O(n log n)：排序占主导，配对为 O(n)，哈希插入按期望 O(1) 计。额外空间 O(n)：集合最多存 n/2 个和，排序实现的辅助空间依语言而异，总量仍为 O(n)。以下代码均会原地排序输入数组；需要保留输入时先复制。

替代方案

直接反复扫描最小值、最大值并删除，容易理解，但总时间 O(n²)。利用元素只在 0–100 的条件，也可用长度 101 的频次表与两个值域指针配对，并用长度 201 的布尔表记录和：时间 O(n + U)，空间 O(U)，其中 U = 101。通用输入下，排序 + 集合更直接。

常见错误

  • JavaScript 使用无比较器的 sort()：默认按字符串排序，应传 (a, b) => a - b。
  • 使用整数除法计算平均值：会把 1 与 1.5 混为一类。
  • 把配对次数当答案：重复平均值只能计一次。
  • 循环写成 left <= right：泛化到奇数长度时会把中间元素配给自己；本题长度必须为偶数。
  • 只删除某个数值的所有副本：一次只能消耗最小和最大各一个实例。

面试追问

为什么不用浮点数？除以固定非零常数保持相等关系，存和更简单。本题平均值是整数或 .5，本身可精确表示，存和主要是消除不必要计算与整数除法误用。

负数能否支持？排序与等价关系依旧成立；若数值范围变大，需要考虑加法溢出，例如 Java 用 long、C++ 用 long long。

能否不修改输入？复制数组后排序，多用 O(n) 空间。若仅保留计数值域，可使用频次表。

Java

import java.util.Arrays;
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int distinctAverages(int[] nums) {
        Arrays.sort(nums);
        Set<Integer> sums = new HashSet<>();
        for (int left = 0, right = nums.length - 1;
             left < right; left++, right--) {
            sums.add(nums[left] + nums[right]);
        }
        return sums.size();
    }
}

Python 3

from typing import List

class Solution:
    def distinctAverages(self, nums: List[int]) -> int:
        nums.sort()
        sums = set()
        left, right = 0, len(nums) - 1
        while left < right:
            sums.add(nums[left] + nums[right])
            left += 1
            right -= 1
        return len(sums)

C++

#include <algorithm>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    int distinctAverages(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        unordered_set<int> sums;
        for (int left = 0, right = (int)nums.size() - 1;
             left < right; ++left, --right) {
            sums.insert(nums[left] + nums[right]);
        }
        return (int)sums.size();
    }
};
