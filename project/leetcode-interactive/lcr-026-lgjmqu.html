重排链表

把 L0 → L1 → … → Ln 原地改成 L0 → Ln → L1 → Ln-1 → …。三段动作：找中点、反转后半段、交替合并。

链表 / 双指针时间 O(n)额外空间 O(1)

题目

给定一个单链表的头节点 head，请将链表重排为首尾交错的顺序。必须修改节点链接，不能只改变节点值。

示例

1 → 2 → 3 → 4 → 5

1 → 5 → 2 → 4 → 3

约束
节点数范围 [1, 5 × 10⁴]

目标
原地重排，不新建结果链表。

面试一句话

慢指针定位后半段起点，反转后半段，再让前半段与反转后的后半段轮流接节点。

  1. ① 快慢指针找到中点。
  2. ② 原地反转后半段。
  3. ③ 保存 next 后交替穿插。

洞察与过程

中点：慢指针每次一步、快指针每次两步；快指针到尾部时，慢指针就在中间。

反转：用 prev / cur / next 三个指针，把后半段转为从尾到中的访问顺序。

合并不变量：每轮先保存两侧下一节点，连接 first → second → firstNext，避免丢失剩余链。

复杂度、边界、替代

复杂度
三个线性扫描，仍为 O(n) 时间；只有常数指针，O(1) 空间。
边界
空链或单节点直接返回；奇数长度时中点归前半段，后半段更短一个节点。
替代方案
用数组收集节点再双端连接更易写，但额外空间 O(n)，不满足进阶要求。

测试清单

  • 1 → 2 → 3 → 4：结果 1 → 4 → 2 → 3。
  • 1 → 2 → 3 → 4 → 5：结果 1 → 5 → 2 → 4 → 3。
  • 单节点和双节点：不应形成环，也不应丢节点。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

常见失误与追问

  • 未断开中点：可能在合并时制造环；反转时应从后半段起点开始。
  • 覆盖 next：每次连线前先保存两边下一节点。
  • 追问：如何判断是否有环？可用 Floyd 快慢指针；本题输入保证无环。
