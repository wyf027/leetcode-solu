LCP 064 · MEDIUM · TREE DP

二叉树灯饰

每个节点有三枚开关：只切当前灯、切整棵子树、切当前灯和两个孩子。目标是用最少操作熄灭所有灯。

题目规则

  1. 开关 1：只翻转当前节点的灯。
  2. 开关 2：翻转当前节点整棵子树的所有灯。
  3. 开关 3：翻转当前节点及其左右孩子的灯。
  4. 灯的值为 1 表示亮，0 表示灭；可以按任意顺序使用开关。
关键约束：祖先的开关 2 会影响整个后代；父亲的开关 3 只会额外影响当前节点。因此向下传递两个二进制状态就够了。
示例

root = [1,1,0,1,null,1,0]。用实验室可查看每个 DFS 状态及其局部开关选择。

约束

节点值仅为 0 或 1；每个状态固定枚举 8 种开关组合。

    测试与验证

    生成后待补

    快速生成模式：UI、算法对拍、四语言编译和交互验收待补。本页只完成内容生成、格式化与提交范围审计，不将这些待补项误报为通过。

    SOLUTION

    只需记住两种外部影响

    O(n) 时间 · O(n) 栈空间

    状态

    dfs(node, sub, parent)：祖先开关 2 的累计奇偶为 sub，父节点是否用了开关 3 为 parent。

    当前灯

    on = node.val ^ sub ^ parent。在该节点上，三枚开关各按 0/1 次即可，重复两次会抵消。

    枚举

    枚举 8 种开关组合，只保留让当前灯变灭的组合；对子节点传递 sub ^ sw2 与 sw3。 

    dfs(node, sub, parent):
  if node == null: return 0
  best = INF
  for mask in 0..7:                    # 三个开关是否按下
    sw1, sw2, sw3 = bits(mask)
    if node.val ^ sub ^ parent ^ sw1 ^ sw2 ^ sw3 == 0:
      best = min(best, popcount(mask)
        + dfs(node.left,  sub ^ sw2, sw3)
        + dfs(node.right, sub ^ sw2, sw3))
  return best

    完整转移过程

    1. 先把祖先开关 2 和父开关 3 对当前灯的影响异或进去。
    2. 枚举当前节点三枚开关是否各按一次。
    3. 若当前灯仍亮，舍弃；若熄灭，则把开关 2 的影响传到整棵孩子子树，把开关 3 的影响传给直接孩子。
    4. 加上左右子树代价并取最小值。

    边界与常见错误

    • 空节点的答案为 0。
    • 开关 2 是“整棵子树”，不是只切左右孩子。
    • 开关 3 只影响当前层和下一层，不能继续向孙节点传播。
    • 不要只按当前灯贪心：按开关 2/3 会改变后续子树状态。

    替代方案

    也可手推每个节点的 4 个状态，自底向上返回一个长度为 4 的数组。实现更短，但不如“两个外部影响 + 8 个局部组合”直观，面试中更容易解释正确性。

    面试追问

    为什么没有第三个祖先状态？因为祖先的开关 1 不影响后代，祖先开关 3 至多影响一层；只有开关 2 的累计奇偶需要跨多层保存。

    提交版代码

    四种实现均枚举 8 个局部开关组合，并以节点 + 两个影响位缓存结果。

    Java 
    class Solution {
    private final Map<TreeNode, int[][]> memo = new HashMap<>();
    public int closeLampInTree(TreeNode root) { return dfs(root, 0, 0); }
    private int dfs(TreeNode node, int sub, int parent) {
        if (node == null) return 0;
        int[][] dp = memo.computeIfAbsent(node, k -> new int[2][2]);
        if (dp[sub][parent] != 0) return dp[sub][parent] - 1;
        int best = 1_000_000;
        for (int mask = 0; mask < 8; mask++) {
            int a = mask & 1, b = (mask >> 1) & 1, c = (mask >> 2) & 1;
            if ((node.val ^ sub ^ parent ^ a ^ b ^ c) == 0)
                best = Math.min(best, Integer.bitCount(mask) + dfs(node.left, sub ^ b, c) + dfs(node.right, sub ^ b, c));
        }
        return dp[sub][parent] = best + 1;
    }
}

    var closeLampInTree = function(root) {
  const memo = new Map();
  function dfs(node, sub, parent) {
    if (!node) return 0;
    if (!memo.has(node)) memo.set(node, Array.from({ length: 2 }, () => Array(2)));
    const dp = memo.get(node);
    if (dp[sub][parent] !== undefined) return dp[sub][parent];
    let best = Infinity;
    for (let mask = 0; mask < 8; mask++) {
      const a = mask & 1, b = (mask >> 1) & 1, c = (mask >> 2) & 1;
      if ((node.val ^ sub ^ parent ^ a ^ b ^ c) === 0)
        best = Math.min(best, a + b + c + dfs(node.left, sub ^ b, c) + dfs(node.right, sub ^ b, c));
    }
    return dp[sub][parent] = best;
  }
  return dfs(root, 0, 0);
};

    class Solution {
    unordered_map<TreeNode*, array<array<int, 2>, 2>> memo;
    int dfs(TreeNode* node, int sub, int parent) {
        if (!node) return 0;
        int &ans = memo[node][sub][parent];
        if (ans) return ans - 1;
        int best = INT_MAX / 4;
        for (int mask = 0; mask < 8; ++mask) {
            int a = mask & 1, b = mask >> 1 & 1, c = mask >> 2 & 1;
            if ((node->val ^ sub ^ parent ^ a ^ b ^ c) == 0)
                best = min(best, a + b + c + dfs(node->left, sub ^ b, c) + dfs(node->right, sub ^ b, c));
        }
        return ans = best + 1;
    }
public:
    int closeLampInTree(TreeNode* root) { return dfs(root, 0, 0); }
};
