增减字符串匹配

把每个 I 和 D 看成对下一个数字的要求。在有限的数字池里，亲手观察“取最小 / 取最大”为什么总能留下退路。

EASY贪心双指针数组 · 字符串

题目说明

给定长度为 n、只含 I 与 D 的字符串 s。请构造一个由 0…n 恰好各出现一次组成的排列 perm，满足：

  • s[i] = 'I' 时，perm[i] < perm[i+1]；
  • s[i] = 'D' 时，perm[i] > perm[i+1]。

答案可能不唯一，返回任意一个有效排列。

官方示例

输入：s = "IDID" 输出：[0,4,1,3,2]
输入：s = "III" 输出：[0,1,2,3]
输入：s = "DDI" 输出：[3,2,0,1]

约束

  • 1 <= s.length <= 10^5
  • s[i] 只能是 'I' 或 'D'

题解：把选择压缩成两个端点

核心洞察
维护尚未使用的连续区间 [low, high]。遇到 I 就拿最小值，确保后面仍有更大的数；遇到 D 就拿最大值，确保后面仍有更小的数。最后放入唯一剩余值。

完整过程

  1. 令 low = 0，high = n。
  2. 从左到右扫描 s：I 加入 low 后令其加一；D 加入 high 后令其减一。
  3. 扫描结束时 low == high，将它追加到答案。

正确性

  1. 排列性：每一步取当前区间的一个端点并移除它，各数不会重复；最终共取出 n+1 个来自 [0,n] 的数。
  2. 满足 I：取出当时最小的 low 后，下一项必来自更大的剩余区间，所以严格递增。
  3. 满足 D：取出当时最大的 high 后，下一项必来自更小的剩余区间，所以严格递减。
  4. 因此构造结果是满足全部字符关系的合法排列。

边界与复杂度

最短字符串、全 I、全 D 都无需特殊分支。时间复杂度 O(n)；除返回数组外额外空间 O(1)。

替代方案

可以先生成 0…n，再对每段连续 D 对应的区间做反转，同样是 O(n)，但端点贪心更直接、代码更短。

面试追问

  • 为什么取中间值会让证明和状态更复杂？
  • 若要求字典序最小答案，应采用哪种构造？（本贪心恰好给出字典序最小合法排列。）
  • 能否流式处理输入？需要知道初始上界 n。

常见错误

  • 循环结束后忘记追加最后一个剩余数字。
  • 把 high 初始化为 n-1，导致少一个数。
  • 只检查相邻大小，却没有保证结果是 0…n 的排列。

四语言完整实现

class Solution {
    public int[] diStringMatch(String s) {
        int n = s.length(), low = 0, high = n;
        int[] answer = new int[n + 1];
        for (int i = 0; i < n; i++) {
            answer[i] = s.charAt(i) == 'I' ? low++ : high--;
        }
        answer[n] = low;
        return answer;
    }
}

from typing import List

class Solution:
    def diStringMatch(self, s: str) -> List[int]:
        low, high = 0, len(s)
        answer = []
        for ch in s:
            if ch == "I":
                answer.append(low)
                low += 1
            else:
                answer.append(high)
                high -= 1
        answer.append(low)
        return answer
class Solution {
public:
    vector<int> diStringMatch(string s) {
        int low = 0, high = static_cast<int>(s.size());
        vector<int> answer;
        answer.reserve(s.size() + 1);
        for (char ch : s) {
            answer.push_back(ch == 'I' ? low++ : high--);
        }
        answer.push_back(low);
        return answer;
    }
};
