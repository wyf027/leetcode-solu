Problem brief

题目要求

给定一个由 'A'（苹果）和 '.'（空格）组成的 rows × cols 矩形披萨，以及整数 k。你要切 k - 1 刀，把披萨分成 k 块。

每刀都沿格子边界水平或垂直切：垂直切时把左半块送出，水平切时把上半块送出；最后把剩余的一块送给最后一人。

计算每一块都至少含一个苹果的切法数，并对 109 + 7 取余。

函数形式

ways(pizza: string[], k: integer) → integer

约束

  • 1 ≤ rows, cols ≤ 50
  • rows == pizza.length
  • cols == pizza[i].length
  • 1 ≤ k ≤ 10
  • pizza 只包含 'A' 与 '.'

顺序有意义：每次送出的方向和切线决定了后续剩余披萨，因此不同的切割序列可能构成不同方案。

Editorial

后缀苹果计数 + 分层动态规划

核心洞察

无论怎样切，继续操作的那块披萨始终是一个以右下角为终点的矩形。

于是只需用左上角 (r, c) 表示它，再用“最终还要分成几块”表示进度；是否有苹果则交给二维后缀和 O(1) 回答。

状态与预处理

令 apples[r][c] 表示子矩形 [r..rows) × [c..cols) 内的苹果数。由右下向左上计算：

apples[r][c] = isApple(r,c)
              + apples[r+1][c]
              + apples[r][c+1]
              - apples[r+1][c+1]

定义 dp[p][r][c]：把以 (r,c) 为左上角的剩余披萨分成 p 块，且每块都有苹果的方案数。

转移

若水平切在 nr 前，只有被送出的上方条带含苹果时才合法；余下状态为 dp[p-1][nr][c]。

垂直切同理：左侧条带含苹果后，累加 dp[p-1][r][nc]。

dp[p][r][c] = Σ dp[p-1][nr][c]  // 上条带有苹果
             + Σ dp[p-1][r][nc]  // 左条带有苹果

完整过程

1
统计苹果。

建立带一圈哨兵的二维后缀和，任何右下角矩形及两个后缀矩形之差都能 O(1) 判断苹果数。

2
建立基线。

当 p = 1 时，不再切；当前余块有苹果则方案数为 1，否则为 0。

3
按块数递推。

从 2 到 k 枚举 p，再枚举状态左上角与所有水平、垂直切线；只让“立即送出的部分”有苹果的切线参与累加。

4
读取答案。

dp[k][0][0] 就是整张披萨分成 k 块的合法方案数，每次累加都对模数取余。

正确性证明

基例：当只需一块时，当前余块含苹果恰好对应唯一合法方案；不含苹果则无方案。

归纳假设：假设所有分成 p-1 块的状态值均正确。

归纳步骤：任何分成 p 块的合法方案都有唯一第一刀。若为水平刀，其上条带必须含苹果，剩余右下矩形的合法续切数由归纳假设准确给出；垂直刀同理。转移枚举所有切线且不同第一刀互斥，因此既不遗漏也不重复。

故由数学归纳法，dp[k][0][0] 等于全部合法方案数。

复杂度与边界

  • 时间：O(k · rows · cols · (rows + cols))
  • 空间：O(k · rows · cols)；滚动数组可降至 O(rows · cols)
  • k = 1：只判断整张披萨是否有苹果。
  • 总苹果数小于 k：递推自然得到 0，也可提前返回。
  • 空行/空列允许存在；切线合法性只取决于送出条带是否含苹果。

class Solution {
    private static final int MOD = 1_000_000_007;

    public int ways(String[] pizza, int k) {
        int rows = pizza.length;
        int cols = pizza[0].length();
        int[][] apples = new int[rows + 1][cols + 1];

        for (int r = rows - 1; r >= 0; r--) {
            for (int c = cols - 1; c >= 0; c--) {
                apples[r][c] = (pizza[r].charAt(c) == 'A' ? 1 : 0)
                        + apples[r + 1][c]
                        + apples[r][c + 1]
                        - apples[r + 1][c + 1];
            }
        }

        int[][][] dp = new int[k + 1][rows][cols];
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                dp[1][r][c] = apples[r][c] > 0 ? 1 : 0;
            }
        }

        for (int pieces = 2; pieces <= k; pieces++) {
            for (int r = rows - 1; r >= 0; r--) {
                for (int c = cols - 1; c >= 0; c--) {
                    long count = 0;
                    for (int nextRow = r + 1; nextRow < rows; nextRow++) {
                        if (apples[r][c] - apples[nextRow][c] > 0) {
                            count += dp[pieces - 1][nextRow][c];
                        }
                    }
                    for (int nextCol = c + 1; nextCol < cols; nextCol++) {
                        if (apples[r][c] - apples[r][nextCol] > 0) {
                            count += dp[pieces - 1][r][nextCol];
                        }
                    }
                    dp[pieces][r][c] = (int) (count % MOD);
                }
            }
        }
        return dp[k][0][0];
    }
}

var ways = function(pizza, k) {
    const MOD = 1_000_000_007;
    const rows = pizza.length;
    const cols = pizza[0].length;
    const apples = Array.from(
        { length: rows + 1 },
        () => Array(cols + 1).fill(0)
    );

    for (let r = rows - 1; r >= 0; r--) {
        for (let c = cols - 1; c >= 0; c--) {
            apples[r][c] = (pizza[r][c] === 'A' ? 1 : 0)
                + apples[r + 1][c]
                + apples[r][c + 1]
                - apples[r + 1][c + 1];
        }
    }

    const dp = Array.from(
        { length: k + 1 },
        () => Array.from({ length: rows }, () => Array(cols).fill(0))
    );

    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            dp[1][r][c] = apples[r][c] > 0 ? 1 : 0;
        }
    }

    for (let pieces = 2; pieces <= k; pieces++) {
        for (let r = rows - 1; r >= 0; r--) {
            for (let c = cols - 1; c >= 0; c--) {
                let count = 0;
                for (let nextRow = r + 1; nextRow < rows; nextRow++) {
                    if (apples[r][c] - apples[nextRow][c] > 0) {
                        count = (count + dp[pieces - 1][nextRow][c]) % MOD;
                    }
                }
                for (let nextCol = c + 1; nextCol < cols; nextCol++) {
                    if (apples[r][c] - apples[r][nextCol] > 0) {
                        count = (count + dp[pieces - 1][r][nextCol]) % MOD;
                    }
                }
                dp[pieces][r][c] = count;
            }
        }
    }
    return dp[k][0][0];
};
from typing import List


class Solution:
    def ways(self, pizza: List[str], k: int) -> int:
        MOD = 1_000_000_007
        rows, cols = len(pizza), len(pizza[0])
        apples = [[0] * (cols + 1) for _ in range(rows + 1)]

        for r in range(rows - 1, -1, -1):
            for c in range(cols - 1, -1, -1):
                apples[r][c] = (
                    (1 if pizza[r][c] == "A" else 0)
                    + apples[r + 1][c]
                    + apples[r][c + 1]
                    - apples[r + 1][c + 1]
                )

        dp = [
            [[0] * cols for _ in range(rows)]
            for _ in range(k + 1)
        ]
        for r in range(rows):
            for c in range(cols):
                dp[1][r][c] = 1 if apples[r][c] > 0 else 0

        for pieces in range(2, k + 1):
            for r in range(rows - 1, -1, -1):
                for c in range(cols - 1, -1, -1):
                    count = 0
                    for next_row in range(r + 1, rows):
                        if apples[r][c] - apples[next_row][c] > 0:
                            count += dp[pieces - 1][next_row][c]
                    for next_col in range(c + 1, cols):
                        if apples[r][c] - apples[r][next_col] > 0:
                            count += dp[pieces - 1][r][next_col]
                    dp[pieces][r][c] = count % MOD

        return dp[k][0][0]

public:

                    + apples[r + 1][c]
                    + apples[r][c + 1]
                    - apples[r + 1][c + 1];
            }
        }

        vector dp(
            k + 1,
            vector(rows, vector<int>(cols, 0))
        );
        for (int r = 0; r < rows; ++r) {
            for (int c = 0; c < cols; ++c) {
                dp[1][r][c] = apples[r][c] > 0 ? 1 : 0;
            }
        }

        for (int pieces = 2; pieces <= k; ++pieces) {
            for (int r = rows - 1; r >= 0; --r) {
                for (int c = cols - 1; c >= 0; --c) {

                            count += dp[pieces - 1][r][nc];

替代方案

记忆化搜索：用 dfs(r,c,p) 表示同一状态，代码更贴近“尝试下一刀”，复杂度相同。

朴素枚举：枚举所有切割序列后检查每块，会产生指数级分支，无法应对 50 × 50。

面试追问

  • 为什么状态只需左上角，不用四个边界？
  • 怎样用滚动数组降低空间？
  • 若每块至少要 t 个苹果，转移如何改变？
  • 若送出哪一边可自由选择，状态还成立吗？

常见错误

  • 只检查余块有苹果，却没检查本刀送出的块。
  • 把 p 混用成“已切刀数”和“剩余块数”。
  • 后缀和差值方向写反。
  • 忘记对每层累加取模。
  • 把同一条切线的后续多种方案误合并成一种。
