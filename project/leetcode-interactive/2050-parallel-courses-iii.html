并行课程 III

Parallel Courses III

课程可以同时开始，但依赖必须逐一满足。
你能找出完成整张课程表的最早时刻吗？

LeetCode 官方题目 ↗免费题 · 单文件离线阅读

01 / 题目

共有 n 门课程，编号为 1…n。二维数组 relations 中的每对 [prevCourse, nextCourse] 表示：必须先完成 prevCourse，才能开始 nextCourse。数组 time 从下标 0 开始，time[i] 是完成课程 i + 1 所需的月数。

所有先修课程完成后，该课程可立即开始；同时学习的课程数量没有上限。请返回完成全部课程所需的最少月数。输入保证课程依赖构成有向无环图，因此全部课程都能完成。

参数：minimumTime(n, relations, time) → 整数月数。注意课程编号与数组下标相差 1。

02 / 官方示例

示例 1 · 汇合

输入：n = 3
relations = [[1,3],[2,3]]
time = [3,2,5]
输出：8

课程 1、2 在第 0 月同时开始，分别在第 3、2 月结束。课程 3 等到第 3 月开始，再学习 5 个月，全部完成时为第 8 月。

示例 2 · 多重依赖

输入：n = 5
relations = [[1,5],[2,5],[3,5],[3,4],[4,5]]
time = [1,2,3,4,5]
输出：12

课程 1、2、3 在第 0 月开始，于第 1、2、3 月完成。课程 4 在第 3 月开始，第 7 月结束。课程 5 等所有先修课完成后，从第 7 月学习到第 12 月。

03 / 约束

  • 1 ≤ n ≤ 5 × 10⁴
  • 0 ≤ relations.length ≤ min(n × (n − 1) / 2, 5 × 10⁴)
  • relations[j].length = 2
  • 1 ≤ prevCourse, nextCourse ≤ n，且 prevCourse ≠ nextCourse
  • 所有先修课程对互不相同。
  • time.length = n，1 ≤ time[i] ≤ 10⁴
  • 先修课程图是有向无环图（DAG）。

先独立思考

当两门先修课耗时不同，一门后续课程应该等谁？如果还有别的课程正在进行，它是否一定需要等待？

04 / 题解 · 有权 DAG 上的最长路径

核心洞察

没有并行数量限制，因此互不依赖的课程无需等待彼此。课程 v 的最早开始时间取决于最晚完成的先修课；它的最早结束时间再加上自身耗时。

finish[v] = time[v] + max(finish[u])，其中 u → v
没有先修课时，max 的值为 0。
答案 = max(finish[v])。

把课程耗时看作点权，答案就是图中的最长路径权重。用拓扑排序让所有前驱先完成计算，再确定后继的最早结束时间。

课程耗时剩余入度finish状态

拓扑步骤表示计算顺序，不表示课程按出队顺序串行学习。剩余入度为 0 表示所有前驱的计算结果已汇合；真实学习时段看上方时间轴。

完整过程

  1. 建立邻接表与入度数组，将课程编号减 1。令每门课程的 finish 初值为自身耗时。
  2. 将入度为 0 的课程加入队列：它们在第 0 月就可以开始。
  3. 取出课程 u，此时其 finish[u] 已确定。对每条 u → v，执行 finish[v] = max(finish[v], finish[u] + time[v])。
  4. 将 v 的入度减 1；降至 0 才入队，确保其他前驱也已贡献自己的结果。
  5. 遍历结束，返回所有 finish 的最大值。示例 2 为 [1,2,3,7,12]，答案 12，决定总耗时的链为 3 → 4 → 5。

代码中的数组下标均从 0 开始；说明与可视化中的课程编号均从 1 开始。

正确性证明

递推下界：任何合法安排中，课程 v 必须等每个前驱 u 完成后才能开始，因此不能早于所有前驱最早结束时间的最大值；加上自身耗时便得到 finish[v] 的下界。

该下界可达：按拓扑顺序归纳。源课程从第 0 月开始可以达到自身耗时。对任意非源课程，假设所有前驱都达到各自最早结束时间，在最晚前驱结束时立即开始 v 即可达到递推值；无限并行保证没有额外资源冲突。

实现维护递推：每条入边依次更新最大值，只有全部入边处理后 v 才入队，故出队时 finish[v] 恰为递推值。DAG 保证全部课程都被处理。所有课程完成时间的最大值既是全局下界，也能由上述安排实现，所以是最优答案。

复杂度与边界

设 m = relations.length。建图和遍历合计时间 O(n + m)，邻接表、入度、队列与状态数组使用空间 O(n + m)。

  • 没有依赖：答案为最长单课耗时。
  • 单条链：答案为全部耗时之和。
  • 不连通的图：各部分并行，取最大完成时间。
  • 最大答案不超过 5×10⁴ × 10⁴ = 5×10⁸，32 位有符号整数足够。
  • 无需为合法输入检测环；若扩展为任意输入，可计数出队节点，数量小于 n 时报告有环。

替代方案

  • 记忆化 DFS：对前驱递归计算最早结束时间，同为 O(n+m)，但深链可达 50000，可能栈溢出；迭代拓扑更稳妥。
  • 最小堆事件模拟：维护正在学习课程的完成事件，依赖满足时启动课程，通常为 O(m+n log n)，本题无需这个额外开销。
  • 按层求和不可行：不同耗时的课程不共享统一“学期边界”，某条后续链可以在同一层的其他长课结束前继续推进。

常见错误

  • 把多个前驱耗时相加。它们可以并行，汇合处应取最晚结束时间。
  • 只累加拓扑层的最大耗时。这会人为让无关课程互相等待。
  • 每次更新都覆盖 finish[v]。必须取 max，否则结果会依赖遍历顺序。
  • 只处理完一个前驱就让后继入队。必须等剩余入度变成 0。
  • 把 JavaScript 的 shift() 用于大队列，或用 Math.max(...finish) 展开大数组。以下代码使用头指针与循环维护答案。
  • 把最大的课程编号当作最后完成的课程。应取所有课程完成时间的最大值。

面试追问

  • 如何还原关键路径？严格改进 finish[v] 时记录来源 u，最后从最大 finish 的课程反向追踪；并列时任选一条，若要全部路径需处理多前驱与输出规模。
  • 如果最多同时学习 k 门课？资源约束使最长路径只成为下界，当前递推不再足以给出最优安排；需结合新的 n、k 范围选择状态压缩或调度方法。
  • 耗时发生修改怎么办？可先考虑完整 O(n+m) 重算。若只重算受影响后继，必须重新比较它们所有前驱，尤其耗时缩短时不能只做 max 增量传播。

Java

import java.util.ArrayList;
import java.util.ArrayDeque;
import java.util.List;

class Solution {
    public int minimumTime(int n, int[][] relations, int[] time) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        int[] indegree = new int[n];
        for (int[] edge : relations) {
            int u = edge[0] - 1, v = edge[1] - 1;
            graph.get(u).add(v);
            indegree[v]++;
        }
        int[] finish = time.clone();
        ArrayDeque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            if (indegree[i] == 0) queue.addLast(i);
        }
        int answer = 0;
        while (!queue.isEmpty()) {
            int u = queue.removeFirst();
            answer = Math.max(answer, finish[u]);
            for (int v : graph.get(u)) {
                finish[v] = Math.max(finish[v], finish[u] + time[v]);
                if (--indegree[v] == 0) queue.addLast(v);
            }
        }
        return answer;
    }
}

/**
 * @param {number} n
 * @param {number[][]} relations
 * @param {number[]} time
 * @return {number}
 */
var minimumTime = function(n, relations, time) {
    const graph = Array.from({ length: n }, () => []);
    const indegree = Array(n).fill(0);
    for (const [a, b] of relations) {
        graph[a - 1].push(b - 1);
        indegree[b - 1]++;
    }
    const finish = time.slice();
    const queue = [];
    for (let i = 0; i < n; i++) {
        if (indegree[i] === 0) queue.push(i);
    }
    let answer = 0;
    for (let head = 0; head < queue.length; head++) {
        const u = queue[head];
        answer = Math.max(answer, finish[u]);
        for (const v of graph[u]) {
            finish[v] = Math.max(finish[v], finish[u] + time[v]);
            if (--indegree[v] === 0) queue.push(v);
        }
    }
    return answer;
};

Python 3

from collections import deque
from typing import List

class Solution:
    def minimumTime(self, n: int, relations: List[List[int]],
                    time: List[int]) -> int:
        graph = [[] for _ in range(n)]
        indegree = [0] * n
        for a, b in relations:
            graph[a - 1].append(b - 1)
            indegree[b - 1] += 1
        finish = time[:]
        queue = deque(i for i in range(n) if indegree[i] == 0)
        answer = 0
        while queue:
            u = queue.popleft()
            answer = max(answer, finish[u])
            for v in graph[u]:
                finish[v] = max(finish[v], finish[u] + time[v])
                indegree[v] -= 1
                if indegree[v] == 0:
                    queue.append(v)
        return answer

C++

#include <algorithm>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    int minimumTime(int n, vector<vector<int>>& relations,
                    vector<int>& time) {
        vector<vector<int>> graph(n);
        vector<int> indegree(n, 0), finish = time;
        for (const auto& edge : relations) {
            int u = edge[0] - 1, v = edge[1] - 1;
            graph[u].push_back(v);
            ++indegree[v];
        }
        queue<int> ready;
        for (int i = 0; i < n; ++i) {
            if (indegree[i] == 0) ready.push(i);
        }
        int answer = 0;
        while (!ready.empty()) {
            int u = ready.front();
            ready.pop();
            answer = max(answer, finish[u]);
            for (int v : graph[u]) {
                finish[v] = max(finish[v], finish[u] + time[v]);
                if (--indegree[v] == 0) ready.push(v);
            }
        }
        return answer;
    }
};
