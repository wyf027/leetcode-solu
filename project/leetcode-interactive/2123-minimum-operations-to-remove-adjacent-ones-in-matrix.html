使矩阵中的 1
互不相邻的最小操作数

Minimum Operations to Remove Adjacent Ones in Matrix

一次移除一个 1，让留下的每个 1 都没有上下左右的邻居。

01 / 任务与约束

给定从 0 开始编号的二进制矩阵 grid。一次操作可以把任意一个值为 1 的格子变为 0。要求最终任意两个值为 1 的格子都不共用一条边，返回最少操作次数。对角相接不算相邻，也无须移除全部 1。

参数与返回值

minimumOperations(grid: integer[][]) → integer

返回最少次数，不要求返回坐标。

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 300
  • grid[i][j] ∈ {0, 1}

02 / 官方示例

示例 1

grid = [[1,1,0],
        [0,1,1],
        [1,1,1]]
输出：3

移除 (0,1)、(1,2)、(2,1) 后满足要求。

示例 2

grid = [[0,0,0],
        [0,0,0],
        [0,0,0]]
输出：0

没有 1，无须操作。

示例 3

grid = [[0,1],
        [1,0]]
输出：0

只有对角相接，不属于四方向相邻。

先想一想

一个格子可能连接多个邻居。每次都优先移除邻居最多的格子，能保证最优吗？

03 / 从相邻冲突到最大匹配

核心洞察

把每个 1 看作顶点，四方向相邻的 1 之间连边。删除后没有冲突，等价于每条边至少删除一个端点，因此原题就是最小顶点覆盖。按 (r + c) % 2 棋盘染色，相邻格子必然异色，得到二分图。

Kőnig 定理：二分图最小顶点覆盖大小等于最大匹配大小。答案是匹配边数，不是匹配端点数。

完整过程

  1. 偶数坐标和作为左部 L，枚举四方向邻居构造邻接表。
  2. 用双向 mate 保存搭档，初值 −1。依次从每个空闲左顶点出发。
  3. BFS 走到右顶点 v 时记录 parent[v]。若 v 已有搭档，把旧搭档加入队列继续搜索；若 v 空闲，就找到增广路。
  4. 从空闲右端点沿 parent 和旧 mate 回溯，翻转整条路径，匹配数增加 1。
  5. 每轮用新的时间戳标记访问过的右顶点；处理所有左顶点后返回匹配数。

正确性证明
① 合法删除集合恰好覆盖所有冲突边；顶点覆盖删除后也必然合法，因此最优值相同。
② 棋盘染色使图二分，Kőnig 定理把最小覆盖转为最大匹配。
③ BFS 遍历交替路径。找到两个空闲端点后翻转路径，内部顶点仍只有一个搭档，两端新增搭档，匹配数恰好增加 1。
④ 按左顶点逐个加入归纳：加入前匹配最大，新增一个左顶点最多使最优值增加 1。若能增加，必有从该新顶点出发的增广路；BFS 能找到。否则原匹配仍最大。最终得到整张图的最大匹配，即最少删除次数。
复杂度与边界
N = mn，V 为 1 的个数，E 为冲突边数，E ≤ 2N。建图 O(N)，每个左顶点搜索 O(V + E)，总时间 O(N + |L|(V + E))，网格上最坏 O(N²)。空间 O(N + E)，即 O(N)。
四语言均使用迭代 BFS，避免长路径递归栈溢出。上限 300 × 300 下，最坏耗时仍可能较高；可升级为 Hopcroft–Karp 的 O(N + E√V)。本页没有提交或性能验证。
全 0、单个 1、只有对角相邻均返回 0；单行与单列正常处理；多个连通分量可独立配对。实现不修改 grid。


替代方案
  • Hopcroft–Karp：分层 BFS 与批量最短增广，适合更严格的时间要求。
  • 最大流：源→L、L→R、R→汇均设单位容量，用 Dinic 求最大匹配。
  • 枚举删除集合：O(2^V · (V + E))，仅适合很小的 V。按度数删除的贪心没有最优保证。
常见错误
  • 把对角线也连边，或把 0 当作冲突顶点。
  • 只找空闲邻居，不允许旧搭档改配，漏掉增广路。
  • 跨轮不更新 visited，错误剪枝；从两侧重复增广，重复计数。
  • 把匹配顶点数当答案；翻转前没有保存 mate[u]，回溯链断裂。
面试追问
如何输出删除位置？ 从未匹配的 L 出发，沿非匹配边 L→R、匹配边 R→L 得到可达集合 Z。最小覆盖是 (L ∖ Z) ∪ (R ∩ Z)，大小等于匹配数；演示最后显示该集合。
删除成本不同？ 用加权二分图最小顶点覆盖：源→L、R→汇容量设为各自成本，L→R 容量大于总成本，求最小割。
改成八方向相邻？ 图可能出现奇环，棋盘二分和 Kőnig 定理不再适用。

import java.util.*;

class Solution {
    public int minimumOperations(int[][] grid) {
        int m=grid.length, n=grid[0].length, size=m*n;
        List<List<Integer>> adj=new ArrayList<>();
        for (int i=0; i<size; i++) adj.add(new ArrayList<>());
        List<Integer> left=new ArrayList<>();
        int[][] dirs={{0,1},{1,0},{0,-1},{-1,0}};
        for (int r=0; r<m; r++) for (int c=0; c<n; c++) {
            if (grid[r][c]==0 || (r+c)%2!=0) continue;
            int u=r*n+c; left.add(u);
            for (int[] d:dirs) {
                int a=r+d[0], b=c+d[1];
                if (a>=0 && a<m && b>=0 && b<n && grid[a][b]==1)
                    adj.get(u).add(a*n+b);
            }
        }
        int[] mate=new int[size], seen=new int[size], parent=new int[size];
        Arrays.fill(mate,-1);
        int answer=0, stamp=0;
        for (int root:left) {
            if (mate[root]!=-1) continue;
            stamp++;
            Deque<Integer> q=new ArrayDeque<>();
            q.add(root);
            int end=-1;
            while (!q.isEmpty() && end==-1) {
                int u=q.remove();
                for (int v:adj.get(u)) {
                    if (seen[v]==stamp) continue;
                    seen[v]=stamp; parent[v]=u;
                    if (mate[v]==-1) { end=v; break; }
                    q.add(mate[v]);
                }
            }
            if (end==-1) continue;
            answer++;
            while (end!=-1) {
                int u=parent[end], old=mate[u];
                mate[u]=end; mate[end]=u; end=old;
            }
        }
        return answer;
    }
}

                adj[u].push(a*n+b);

Python
from typing import List
from collections import deque

class Solution:
    def minimumOperations(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        size = m * n
        adj = [[] for _ in range(size)]
        left = []
        for r in range(m):
            for c in range(n):
                if not grid[r][c] or (r + c) % 2:
                    continue
                u = r * n + c
                left.append(u)
                for dr, dc in ((0,1), (1,0), (0,-1), (-1,0)):
                    a, b = r + dr, c + dc
                    if 0 <= a < m and 0 <= b < n and grid[a][b]:
                        adj[u].append(a * n + b)
        mate = [-1] * size
        seen = [0] * size
        parent = [-1] * size
        answer = stamp = 0
        for root in left:
            if mate[root] != -1:
                continue
            stamp += 1
            q = deque([root])
            end = -1
            while q and end == -1:
                u = q.popleft()
                for v in adj[u]:
                    if seen[v] == stamp:
                        continue
                    seen[v] = stamp
                    parent[v] = u
                    if mate[v] == -1:
                        end = v
                        break
                    q.append(mate[v])
            if end == -1:
                continue
            answer += 1
            while end != -1:
                u = parent[end]
                old = mate[u]
                mate[u] = end
                mate[end] = u
                end = old
        return answer

#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    int minimumOperations(vector<vector<int>>& grid) {
        int m=grid.size(), n=grid[0].size(), size=m*n;
        vector<vector<int>> adj(size);
        vector<int> left;
        int dirs[4][2]={{0,1},{1,0},{0,-1},{-1,0}};
        for (int r=0; r<m; ++r) for (int c=0; c<n; ++c) {
            if (!grid[r][c] || (r+c)%2) continue;
            int u=r*n+c; left.push_back(u);
            for (auto& d:dirs) {
                int a=r+d[0], b=c+d[1];
                if (a>=0 && a<m && b>=0 && b<n && grid[a][b])
                    adj[u].push_back(a*n+b);
            }
        }
        vector<int> mate(size,-1), seen(size), parent(size);
        int answer=0, stamp=0;
        for (int root:left) {
            if (mate[root]!=-1) continue;
            ++stamp;
            queue<int> q; q.push(root);
            int end=-1;
            while (!q.empty() && end==-1) {
                int u=q.front(); q.pop();
                for (int v:adj[u]) {
                    if (seen[v]==stamp) continue;
                    seen[v]=stamp; parent[v]=u;
                    if (mate[v]==-1) { end=v; break; }
                    q.push(mate[v]);
                }
            }
            if (end==-1) continue;
            ++answer;
            while (end!=-1) {
                int u=parent[end], old=mate[u];
                mate[u]=end; mate[end]=u; end=old;
            }
        }
        return answer;
    }
};
