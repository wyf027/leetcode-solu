ALGORITHM LAB / 1847HARD非付费题

最近的房间

Closest Room · 当面积是门槛，房号是偏好。

先理解选择规则，独立尝试后再展开底部题解。

01 / 题目

酒店有 n 个房间，rooms[i] = [roomIdᵢ, sizeᵢ] 表示房号和面积，房号互不重复。

每个查询 queries[j] = [preferredⱼ, minSizeⱼ] 要求在面积至少为 minSizeⱼ 的房间中，选择使 |id − preferredⱼ| 最小的房号。距离相同选择房号更小者；没有合格房间返回 -1。

返回长度为 k 的整数数组，顺序与输入查询一致。不同查询互不影响，不会占用房间。

约束

  • n == rooms.length，1 ≤ n ≤ 10⁵
  • k == queries.length，1 ≤ k ≤ 10⁴
  • 1 ≤ roomIdᵢ, preferredⱼ ≤ 10⁷
  • 1 ≤ sizeᵢ, minSizeⱼ ≤ 10⁷

02 / 官方示例

示例 1 · 无房可选

rooms = [[2,2],[1,2],[3,2]]
queries = [[3,1],[3,3],[5,2]]
输出 = [3,-1,3]

第一个查询恰好选到房号 3；第二个查询要求面积至少 3，没有房间满足；第三个查询中，房号 3 距离偏好 5 最近。

示例 2 · 等距选小

rooms = [[1,4],[2,3],[3,5],[4,1],[5,2]]
queries = [[2,3],[2,4],[2,5]]
输出 = [2,1,3]

面积门槛为 3 时选房号 2；门槛为 4 时，房号 1 和 3 等距，选 1；门槛为 5 时只剩房号 3。

04 / 独立题解

准备好再查看思路、交互演示与四语言实现。

核心洞察：最近的合格前驱与后继

按房号排序。对偏好 p，左侧所有房号都小于 p，越靠右越近；右侧所有房号都大于等于 p，越靠左越近。因此只需找到左侧最右的合格房间和右侧最左的合格房间。

在线段树每个结点存储对应房号区间的最大面积。如果最大面积小于门槛，这整个区间都可跳过；否则按需要的方向优先下降，命中一个叶子就停止。

交互 / 面积上界剪枝

使用官方示例 2 的房间。结点显示“房号区间 / 最大面积”；绿色框标记当前访问结点。查询可独立选择，演示逐步记录边界排除、面积剪枝和叶子命中。

可使用 Tab 聚焦，Enter / 空格操作按钮。启用减少动态效果时，自动播放将保持关闭，可手动逐步查看。

完整过程

  1. 复制房间并按房号升序排序，以 O(n) 建立最大面积线段树。
  2. 二分找到第一个房号 ≥ preferred 的下标 pos。
  3. 在 [0, pos−1] 中优先走右子树，找最右的合格叶子；在 [pos, n−1] 中优先走左子树，找最左的合格叶子。
  4. 访问区间不相交或最大面积不足时返回 −1。找到叶子后立即返回，避免枚举其余合格房间。
  5. 两侧皆空返回 −1；仅一侧非空选它；两侧都有候选则比较距离，距离相等选左侧。

正确性

区间不变量：每个叶子的值是该房间面积，内部结点取两个子结点最大值，故结点值恰为区间最大面积。若该值小于门槛，区间没有合格房间，剪枝不会丢失答案。

方向搜索：区间外的结点被排除。在剩余结点中，先访问更靠近偏好的一半；若该半区没有解才访问另一半。归纳到叶子，返回的恰是查询区间内最右或最左的合格房间。

候选完备性：任何左侧房间都不比合格前驱更近，任何右侧房间都不比合格后继更近。比较这两个候选即可覆盖全局最优；等距选较小房号符合规则。每次查询独立执行，天然保留原查询顺序。

复杂度

排序 O(n log n)，建树 O(n)。一次二分及两次方向搜索均为 O(log n)：前缀或后缀范围只有 O(log n) 个规范区间，失败的完整区间由最大值一次排除，成功区间只沿首个解的路径下降。总时间 O(n log n + k log n)；辅助空间 O(n)，返回数组 O(k)，递归栈 O(log n)。

边界与常见错误

  • 面积条件是 ≥，只有 maxSize < minSize 才能剪枝。
  • 房号相等应落在右区间并可能以距离 0 命中。
  • pos 可以为 0 或 n；空区间必须直接返回 −1。
  • 不可只二分原数组最近的两个房间：它们可能面积不合格，更远处才有答案。
  • 不能取面积最接近门槛的房间；面积只是限制，优化目标是房号距离。
  • 两候选等距用 ≤ 选择左侧。不要把 −1 当真实房号参与距离计算。
  • 本题数值差不超过 10⁷，四语言中的相应整数或 Number 都足够。

替代方案

离线按 minSize 降序处理查询，房间按面积降序加入有序集合，查询集合中的前驱与后继，并按原索引填答案。Java 的 TreeSet、C++ 的 set 可直接实现；总时间 O(n log n + k log k + k log n)，空间 O(n+k)。JavaScript 与 Python 标准库没有直接对应的平衡有序集合，可用坐标压缩加树状数组维护排名；在普通数组中插入即使先二分，移动元素仍为 O(n)，会使总复杂度退化。

面试追问

  • 面积会更新怎么办？固定房号时在线段树单点更新面积，每次 O(log n)。
  • 如果查询必须在线返回？本页静态线段树方案无需重排查询。
  • 如果每次返回最近的多个房间？可迭代寻找两侧合格候选并合并，需讨论数量和输出成本。

JavaScript

/**
 * @param {number[][]} rooms
 * @param {number[][]} queries
 * @return {number[]}
 */
var closestRoom = function(rooms, queries) {
    const a = rooms.slice().sort((x,y) => x[0]-y[0]);
    const n = a.length, mx = new Array(4*n).fill(0);
    function build(v,l,r) {
        if (l===r) { mx[v]=a[l][1]; return; }
        const m=(l+r)>>1;
        build(v*2,l,m); build(v*2+1,m+1,r);
        mx[v]=Math.max(mx[v*2],mx[v*2+1]);
    }
    // Find the extreme eligible index in [ql, qr].
    function find(v,l,r,ql,qr,size,right) {
        if (ql>qr || r<ql || l>qr || mx[v]<size) return -1;
        if (l===r) return l;
        const m=(l+r)>>1;
        let x;
        if (right) {
            x=find(v*2+1,m+1,r,ql,qr,size,right);
            return x!==-1 ? x : find(v*2,l,m,ql,qr,size,right);
        }
        x=find(v*2,l,m,ql,qr,size,right);
        return x!==-1 ? x : find(v*2+1,m+1,r,ql,qr,size,right);
    }
    build(1,0,n-1);
    return queries.map(([preferred,size]) => {
        let lo=0,hi=n;
        while(lo<hi) {
            const m=(lo+hi)>>1;
            if(a[m][0]<preferred) lo=m+1; else hi=m;
        }
        const left=find(1,0,n-1,0,lo-1,size,true);
        const right=find(1,0,n-1,lo,n-1,size,false);
        if(left===-1) return right===-1 ? -1 : a[right][0];
        if(right===-1) return a[left][0];
        return preferred-a[left][0]<=a[right][0]-preferred
            ? a[left][0] : a[right][0];
    });
};

Python

from typing import List
from bisect import bisect_left

class Solution:
    def closestRoom(self, rooms: List[List[int]],
                    queries: List[List[int]]) -> List[int]:
        a = sorted(rooms)
        n = len(a)
        ids = [x[0] for x in a]
        mx = [0] * (4 * n)

        def build(v, l, r):
            if l == r:
                mx[v] = a[l][1]
                return
            m = (l + r) // 2
            build(v * 2, l, m)
            build(v * 2 + 1, m + 1, r)
            mx[v] = max(mx[v * 2], mx[v * 2 + 1])

        def find(v, l, r, ql, qr, size, right):
            if ql > qr or r < ql or l > qr or mx[v] < size:
                return -1
            if l == r:
                return l
            m = (l + r) // 2
            children = [(v * 2, l, m), (v * 2 + 1, m + 1, r)]
            if right:
                children.reverse()
            for w, x, y in children:
                hit = find(w, x, y, ql, qr, size, right)
                if hit != -1:
                    return hit
            return -1

        build(1, 0, n - 1)
        ans = []
        for preferred, size in queries:
            pos = bisect_left(ids, preferred)
            left = find(1, 0, n - 1, 0, pos - 1, size, True)
            right = find(1, 0, n - 1, pos, n - 1, size, False)
            candidates = [ids[i] for i in (left, right) if i != -1]
            ans.append(min(candidates, key=lambda x: (abs(x-preferred), x))
                       if candidates else -1)
        return ans

import java.util.*;

class Solution {
    private int[][] a;
    private int[] mx;
    private void build(int v, int l, int r) {
        if (l == r) { mx[v] = a[l][1]; return; }
        int m = (l+r)/2;
        build(v*2,l,m); build(v*2+1,m+1,r);
        mx[v] = Math.max(mx[v*2],mx[v*2+1]);
    }
    private int find(int v,int l,int r,int ql,int qr,int size,boolean right) {
        if (ql>qr || r<ql || l>qr || mx[v]<size) return -1;
        if (l==r) return l;
        int m=(l+r)/2, x;
        if (right) {
            x=find(v*2+1,m+1,r,ql,qr,size,true);
            return x!=-1 ? x : find(v*2,l,m,ql,qr,size,true);
        }
        x=find(v*2,l,m,ql,qr,size,false);
        return x!=-1 ? x : find(v*2+1,m+1,r,ql,qr,size,false);
    }
    public int[] closestRoom(int[][] rooms, int[][] queries) {
        a=rooms.clone();
        Arrays.sort(a,Comparator.comparingInt(x -> x[0]));
        int n=a.length;
        mx=new int[4*n]; build(1,0,n-1);
        int[] ans=new int[queries.length];
        for(int j=0;j<queries.length;j++) {
            int p=queries[j][0], size=queries[j][1], lo=0, hi=n;
            while(lo<hi) {
                int m=(lo+hi)/2;
                if(a[m][0]<p) lo=m+1; else hi=m;
            }
            int left=find(1,0,n-1,0,lo-1,size,true);
            int right=find(1,0,n-1,lo,n-1,size,false);
            if(left==-1) ans[j]=right==-1 ? -1 : a[right][0];
            else if(right==-1) ans[j]=a[left][0];
            else ans[j]=p-a[left][0]<=a[right][0]-p ? a[left][0] : a[right][0];
        }
        return ans;
    }
}

public:
    vector<int> closestRoom(vector<vector<int>>& rooms,
                            vector<vector<int>>& queries) {
        a=rooms; sort(a.begin(),a.end());

        vector<int> ans;
        for(auto &q:queries) {

        }
