数组形式的整数加法

Add to Array-Form of Integer · 数组 × 数学

题目

整数的数组形式，是把它的十进制数字按从左到右排列成数组。给定数组形式 num 和整数 k，返回 num + k 的数组形式。

1 ≤ num.length ≤ 10⁴0 ≤ num[i] ≤ 91 ≤ k ≤ 10⁴

除数字 0 本身外，num 不含前导零。

函数签名

addToArrayForm(num, k) → List<Integer> num: integer[] k: integer

不必把长数组转换成语言内置整数。

官方示例

输入：num = [1,2,0,0], k = 34 输出：[1,2,3,4] 解释：1200 + 34 = 1234
输入：num = [2,7,4], k = 181 输出：[4,5,5] 解释：274 + 181 = 455
输入：num = [2,1,5], k = 806 输出：[1,0,2,1] 解释：215 + 806 = 1021

逐位进位实验室

用 [2,7,4] + 181 观察从个位向左处理的过程。先自己预测每一步，再操作。

准备：从最右侧开始。

测试与验证

快速生成模式：待补验证

输入：num = [1,2,0,0], k = 34 期望输出：[1,2,3,4] 实际输出：待补验证 状态：待补验证
输入：num = [2,7,4], k = 181 期望输出：[4,5,5] 实际输出：待补验证 状态：待补验证
输入：num = [2,1,5], k = 806 期望输出：[1,0,2,1] 实际输出：待补验证 状态：待补验证

题解

核心洞察

把 k 看成尚未处理的“加数与进位”。从数组末尾开始，将当前数字加到 k：新数字是 k % 10，接着令 k = floor(k / 10)。这样一次同时完成加法与进位。

完整过程

  1. 指针从 num 末尾开始，结果先逆序收集。
  2. 只要数组还有位，或 k > 0，就把当前数组位（若存在）加进 k。
  3. 记录个位 k % 10，再丢掉该位。
  4. 反转结果，得到最高位到最低位的数组。

正确性

循环每轮恰好确定当前最低的一个未确定十进制位，因为取模得到该位，整除后留下所有更高位及进位。循环结束时，原数组各位与 k 的所有位都已处理；逆序收集的每一位均正确，反转后即为和的数组形式。

边界

  • 连续进位，如 [9,9,9] + 1
  • k 位数多于数组
  • 数组为 [0]
  • 数组处理完但仍有进位

复杂度

时间 O(max(n, log k))；结果数组占用 O(max(n, log k)) 空间。

替代方案

可逐位拆分 k 并维护独立 carry；逻辑等价但变量更多。把数组拼成整数会在长输入时溢出，不适用。

面试追问

  • 若 k 也用数组表示，如何改写为双指针？
  • 如何原地复用 num，减少额外空间？
  • 若进制从 10 改为任意 b，哪些表达式需要改变？

常见错误

  • 忘记数组耗尽后继续处理剩余 k。
  • 结果按低位到高位生成，却忘了反转。
  • 使用浮点数或普通整数承载最长的 num。

Java

class Solution {
    public List<Integer> addToArrayForm(int[] num, int k) {
        List<Integer> ans = new ArrayList<>();
        for (int i = num.length - 1; i >= 0 || k > 0; i--) {
            if (i >= 0) k += num[i];
            ans.add(k % 10);
            k /= 10;
        }
        Collections.reverse(ans);
        return ans;
    }
}

JavaScript

var addToArrayForm = function(num, k) {
    const ans = [];
    for (let i = num.length - 1; i >= 0 || k > 0; i--) {
        if (i >= 0) k += num[i];
        ans.push(k % 10);
        k = Math.floor(k / 10);
    }
    return ans.reverse();
};

Python

class Solution:
    def addToArrayForm(self, num: List[int], k: int) -> List[int]:
        ans = []
        i = len(num) - 1
        while i >= 0 or k > 0:
            if i >= 0:
                k += num[i]
            ans.append(k % 10)
            k //= 10
            i -= 1
        return ans[::-1]

C++

class Solution {
public:
    vector<int> addToArrayForm(vector<int>& num, int k) {
        vector<int> ans;
        for (int i = (int)num.size() - 1; i >= 0 || k > 0; --i) {
            if (i >= 0) k += num[i];
            ans.push_back(k % 10);
            k /= 10;
        }
        reverse(ans.begin(), ans.end());
        return ans;
    }
};
