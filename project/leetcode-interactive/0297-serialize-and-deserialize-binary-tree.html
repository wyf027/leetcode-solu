Serialize and Deserialize Binary Tree

让一棵树穿过只容得下字符串的通道，再在另一端恢复原貌。题目不限定编码格式，真正的契约只有一个：结构和值都不能丢。

HARD非付费题树深度优先搜索字符串
12345

Problem

把形状也写进字符串

序列化把树变成可存储、可传输的字符串；反序列化执行逆过程。编码方式由你设计，但同一套 Codec 必须能完成无损往返。

题意转述

设计 Codec：serialize(root) 接收二叉树根结点并返回字符串；deserialize(data) 接收该字符串并恢复一棵与原树在结点值和左右子树结构上完全一致的二叉树。

题目展示的输入输出采用 LeetCode 层序数组格式，但这只是题目表示法，不要求你的字符串也采用相同格式。评测会调用你的两个方法检查往返结果。

关键要求：只记录结点值不够。比如一条左链和一条右链可能拥有相同的访问值序列，因此编码必须保留空孩子或其他等价的结构边界。

约束

  • 树中结点数范围为 [0, 10⁴]。
  • -1000 <= Node.val <= 1000。
  • 输入参数形式：root: TreeNode；Codec 的序列化结果类型为 string。

准备好核对思路了吗？

题解默认收起，先独立思考如何消除“形状歧义”。

Solution

先序遍历 + 空结点标记

选择先序顺序“根、左、右”，并把每个空孩子写成 #。这样令牌流既包含值，也完整描述每个结点的两个孩子槽位。

Core Insight

空标记不是冗余，而是结构信息

对于任意非空令牌，先创建结点，再连续消费一段令牌构造它的左子树和右子树；遇到 # 就关闭当前孩子槽位。消费边界因此唯一，反序列化无需额外分隔树形。

完整过程

  1. 定义协议。用逗号分隔令牌；整数表示真实结点，# 表示空指针。协议的选择和解析必须严格一致。

  2. 序列化。先写当前结点值，再递归写左子树、右子树；当前结点为空时直接写 #。

  3. 反序列化。维护共享读取位置。读取 # 返回空；否则创建结点，并依次递归构造它的左右子树。

  4. 完成往返。每个真实结点和每个空孩子都恰好贡献一个令牌，所以读指针最终消费完整字符串。

正确性证明

命题

deserialize(serialize(T)) 对任意二叉树 T 都得到与 T 结构和值相同的树。

基础情形

若 T 为空，序列化输出 #；反序列化读取它并返回空，结论成立。

归纳步骤

若 T 非空，序列化首先输出根值，随后输出左右子树的完整编码。反序列化先用同一值创建根结点；根据归纳假设，接下来的两次递归分别准确恢复左右子树。因此根值、左右连接均与原树一致。

唯一消费

每次递归至少消费一个令牌，且先序协议明确下一段分别属于左、右子树，不会重复或跳过令牌。故完整树被唯一恢复，命题得证。

复杂度

时间：O(n)，序列化和反序列化都各访问每个结点一次。

空间：O(n) 存储令牌与结果；递归栈为 O(h)，其中 h 是树高。

边界条件

  • 空树只产生一个空标记。
  • 负数直接按整数令牌解析。
  • 重复值不影响结构恢复。
  • 单侧链必须保留另一侧的空标记。
  • 极深偏斜树可能触及语言递归深度。

协议示例

样例树编码为：

1,2,#,#,3,4,#,#,5,#,#

Implementations

四种语言完整实现

均遵循同一套逗号分隔先序协议；代码容器可独立横向、纵向滚动。

Codec.java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) { val = x; }
 * }
 */
public class Codec {
    private static final String NULL = "#";
    private static final String SEP = ",";

    public String serialize(TreeNode root) {
        StringBuilder out = new StringBuilder();
        encode(root, out);
        out.setLength(out.length() - 1); // remove final comma
        return out.toString();
    }

    private void encode(TreeNode node, StringBuilder out) {
        if (node == null) {
            out.append(NULL).append(SEP);
            return;
        }
        out.append(node.val).append(SEP);
        encode(node.left, out);
        encode(node.right, out);
    }

    public TreeNode deserialize(String data) {
        String[] tokens = data.split(SEP);
        int[] index = {0};
        return decode(tokens, index);
    }

    private TreeNode decode(String[] tokens, int[] index) {
        String token = tokens[index[0]++];
        if (NULL.equals(token)) return null;

        TreeNode node = new TreeNode(Integer.parseInt(token));
        node.left = decode(tokens, index);
        node.right = decode(tokens, index);
        return node;
    }
}
solution.js
/**
 * Definition for a binary tree node.
 * function TreeNode(val) {
 *     this.val = val;
 *     this.left = this.right = null;
 * }
 */

/** @param {TreeNode} root @return {string} */
var serialize = function(root) {
    const tokens = [];

    const encode = (node) => {
        if (node === null) {
            tokens.push("#");
            return;
        }
        tokens.push(String(node.val));
        encode(node.left);
        encode(node.right);
    };

    encode(root);
    return tokens.join(",");
};

/** @param {string} data @return {TreeNode} */
var deserialize = function(data) {
    const tokens = data.split(",");
    let index = 0;

    const decode = () => {
        const token = tokens[index++];
        if (token === "#") return null;

        const node = new TreeNode(Number(token));
        node.left = decode();
        node.right = decode();
        return node;
    };

    return decode();
};
solution.py
# Definition for a binary tree node.
# class TreeNode(object):
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Codec:
    def serialize(self, root):
        """Encodes a tree to a single string."""
        tokens = []

        def encode(node):
            if node is None:
                tokens.append("#")
                return
            tokens.append(str(node.val))
            encode(node.left)
            encode(node.right)

        encode(root)
        return ",".join(tokens)

    def deserialize(self, data):
        """Decodes the encoded string to a tree."""
        tokens = iter(data.split(","))

        def decode():
            token = next(tokens)
            if token == "#":
                return None
            node = TreeNode(int(token))
            node.left = decode()
            node.right = decode()
            return node

        return decode()
solution.cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode(int x) : val(x), left(NULL), right(NULL) {}
 * };
 */
class Codec {
    const string NULL_NODE = "#";

    void encode(TreeNode* node, string& out) {
        if (node == nullptr) {
            out += NULL_NODE + ",";
            return;
        }
        out += to_string(node->val) + ",";
        encode(node->left, out);
        encode(node->right, out);
    }

    TreeNode* decode(const vector<string>& tokens, int& index) {
        const string& token = tokens[index++];
        if (token == NULL_NODE) return nullptr;

        TreeNode* node = new TreeNode(stoi(token));
        node->left = decode(tokens, index);
        node->right = decode(tokens, index);
        return node;
    }

public:
    string serialize(TreeNode* root) {
        string out;
        encode(root, out);
        out.pop_back(); // remove final comma
        return out;
    }

    TreeNode* deserialize(string data) {
        vector<string> tokens;
        string token;
        stringstream stream(data);
        while (getline(stream, token, ',')) {
            tokens.push_back(token);
        }
        int index = 0;
        return decode(tokens, index);
    }
};

替代方案

层序遍历（BFS）

队列中连空孩子一起编码，反序列化时按父结点顺序成对挂接左右孩子。优点是无递归栈；缺点是末尾空标记较多，需要定义是否裁剪以及如何补全。

括号化递归表达式

例如 1(2(#)(#))(3...)，边界清晰但解析器更复杂。也可使用二进制协议压缩体积，但需额外处理版本、字节序和整数宽度。

常见错误

  • 遗漏空结点，导致左右形状无法区分。
  • 序列化与反序列化遍历顺序不一致。
  • 用全局读取下标却未在每次调用时重置。
  • 分隔负数时错误地把减号当分隔符。
  • 忘记空树协议，或对尾随逗号处理不一致。
  • 宣称空间为 O(1)，忽略字符串、令牌数组和递归栈。

Interview Follow-ups

面试追问

能否不写空标记？

如果只用一种普通遍历通常不行；但可以组合先序与中序（结点值需唯一），或把每个结点的度数、子树长度等边界信息编码进去。本质上仍要提供足够的结构信息。

如何避免 10⁴ 层偏斜树造成递归栈风险？

序列化使用显式栈；反序列化维护“结点 + 下一个待填孩子”的栈帧，逐令牌挂接。也可以改用 BFS 队列协议。

若字符串可能损坏，协议要怎样增强？

加入版本号、令牌数或长度前缀、校验和，并在解析时验证整数范围、令牌耗尽与多余数据。生产协议还应限制最大深度和总大小。

怎样缩小序列化结果？

可用变长整数编码结点值，用位图记录空/非空槽位，再压缩值序列。代价是可读性下降，且需要稳定的二进制格式约定。
