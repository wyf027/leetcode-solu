N 叉树的最大深度

Maximum Depth of N-ary Tree。先把树看成一张“逐层点亮的地图”，亲手走完层序遍历，再决定是否展开完整题解。

N 叉树DFSBFS节点数 ≤ 10⁴

题目

给定一棵 N 叉树的根节点 root，返回它的最大深度。最大深度是从根节点到最远叶子节点的最长路径所包含的节点数。

输入采用层序序列化；每组孩子之间以 null 分隔。函数形式：int maxDepth(Node root)（不同语言的空值与类型写法略有差异）。

示例 1

输入：root = [1,null,3,2,4,null,5,6] 输出：3

示例 2

输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14] 输出：5

约束

  • 节点总数在 [0, 10⁴] 范围内。
  • 树的深度不超过 1000。

先形成自己的递推关系

想一想：根的深度与所有子树深度的最大值有什么关系？空树应返回多少？

完整题解

核心洞察

空树深度是 0；非空树的最大深度等于 1 + max(每棵子树的最大深度)。这个定义本身就是递归式。

完整过程

  1. 若 root == null，返回 0。
  2. 遍历根节点的所有孩子，递归得到每棵子树的深度。
  3. 记录最大子树深度，最后加上根节点这一层。

正确性证明

归纳命题：算法对任意 N 叉树都返回其最大深度。

  • 基础：空树返回 0，符合定义；只有根的树，其孩子集合为空，返回 1 + 0 = 1。
  • 归纳：假设算法能正确求出根的每棵子树的最大深度。任意根到叶子的路径都先经过根，再进入且仅进入一棵子树，因此最长路径必为“根 + 最深子树的最长路径”。算法取所有子树深度最大值再加 1，恰好得到整棵树的最大深度。

边界

  • 空树：0。
  • 单节点：1。
  • children 为空列表：按叶子处理。
  • 链状树深度可达 1000，递归栈需留意语言限制。

复杂度

  • 时间：O(n)，每个节点访问一次。
  • 空间：O(h) 递归栈；h 为树高，最坏 O(n)。

替代方案

BFS 按层遍历也能求解：队列每处理完一整层，深度加 1。时间仍为 O(n)，空间为最宽一层的节点数 O(w)。链很深且担心递归栈时，BFS 更稳妥。

面试追问

  • 若同时返回一条最深路径，递归结果可携带深度与路径，或记录父指针。
  • 若节点数非常大，比较 DFS 栈深 h 与 BFS 队列宽度 w。
  • 若孩子列表可能为 null，遍历前做空列表兼容。

常见错误

  • 把深度误当成边数，导致单节点返回 0。
  • 把所有子树深度相加；正确操作是取最大值。
  • 忘记处理空根节点。
  • 在循环中提前返回，只计算了第一个孩子。

四语言实现

/*
// Definition for a Node.
class Node {
    public int val;
    public List<Node> children;
}
*/
class Solution {
    public int maxDepth(Node root) {
        if (root == null) return 0;
        int childMax = 0;
        if (root.children != null) {
            for (Node child : root.children) {
                childMax = Math.max(childMax, maxDepth(child));
            }
        }
        return childMax + 1;
    }
}
/**
 * function _Node(val, children) {
 *   this.val = val;
 *   this.children = children;
 * }
 * @param {_Node|null} root
 * @return {number}
 */
var maxDepth = function(root) {
    if (root === null) return 0;
    let childMax = 0;
    for (const child of (root.children || [])) {
        childMax = Math.max(childMax, maxDepth(child));
    }
    return childMax + 1;
};
"""
# Definition for a Node.
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children
"""
class Solution:
    def maxDepth(self, root: 'Node') -> int:
        if root is None:
            return 0
        return 1 + max(
            (self.maxDepth(child) for child in (root.children or [])),
            default=0
        )
/*
// Definition for a Node.
class Node {
public:
    int val;
    vector<Node*> children;
};
*/
class Solution {
public:
    int maxDepth(Node* root) {
        if (root == nullptr) return 0;
        int childMax = 0;
        for (Node* child : root->children) {
            childMax = max(childMax, maxDepth(child));
        }
        return childMax + 1;
    }
};
