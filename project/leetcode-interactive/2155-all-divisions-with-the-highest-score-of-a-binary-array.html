分组得分最高的所有下标

All Divisions With the Highest Score of a Binary Array

一条分界线，两种计分规则。先移动边界，观察每一次划分。

01题目任务

给定长度为 n、下标从 0 开始的二进制数组 nums。选择分割下标 i ∈ [0,n]，把数组划分为左侧 nums[0…i-1] 和右侧 nums[i…n-1]。

得分 = 左侧 0 的数量 + 右侧 1 的数量。返回能取得最高得分的所有不同分割下标，答案顺序不限。i=0 时左侧为空，i=n 时右侧为空。

约束：n == nums.length；1 ≤ n ≤ 10⁵；每个 nums[i] 只能为 0 或 1。

05独立题解

准备好之后，再展开思路、证明与四语言实现。

核心洞察：移动一个元素，只改变一分

在分割位置 0，左侧为空，得分等于整个数组中 1 的总数。边界从 i 移到 i+1 时，只有 nums[i] 从右侧进入左侧：如果它是 0，左侧多一个计分项，得分 +1；如果它是 1，右侧少一个计分项，得分 −1。

score(0) = sum(nums)
score(i+1) = score(i) + (nums[i] == 0 ? 1 : -1)

完整过程

  1. 统计全部 1，初始化当前得分 score、最大得分 best，并把下标 0 放入答案。
  2. 依次跨过 nums[j]，按元素值增加或减少得分；此时对应分割下标 j+1。
  3. 若得分大于 best，清空旧答案，更新 best；若等于 best，加入 j+1。用两个独立 if，也让新最高分的位置加入答案。
  4. 扫描结束，返回所有记录的下标。

例如 nums = [0,0,1,0]：初始 score=1、答案=[0]。跨过第一个 0 后更新为 2、[1]；再跨过 0 后为 3、[2]；跨过 1 后为 2，答案不变；最后跨过 0 后回到 3，追加 4，得到 [2,4]。

正确性证明

得分不变式：处理完前 i 个元素时，score 等于左侧 0 数与右侧 1 数之和。i=0 时由全部 1 的计数成立。下一元素若为 0，只增加左侧 0 数；若为 1，只减少右侧 1 数，因此递推保持不变式。

答案不变式：处理完分割位置 i 后，best 是位置 0…i 的最高分，答案恰好包含这些位置中所有达到 best 的下标。更高分清空旧答案，相同分追加，较低分忽略，三种情况均保持该性质。循环涵盖 0…n 共 n+1 个位置，最终答案完整且无重复。

边界与复杂度

全 0 时最高点是 n；全 1 时最高点是 0。n=1 仍有两个分割位置。空数组不属于题目输入。分数范围为 0…n，普通整数足够。两次线性扫描的时间复杂度为 O(n)；除返回结果外额外空间 O(1)，返回结果最坏为 O(n)。

替代方案

前缀计数法：设 P[i] 为前 i 项中 1 的数量，T 为全部 1 的数量，则 score(i) = i − P[i] + T − P[i]。存储前缀数组需要 O(n) 空间，适合多次查询任意分割点。直接对每个位置重新统计两侧是 O(n²)，不适用于 10⁵ 的长度。

常见错误

  • 只遍历 0…n−1，漏掉右侧为空的分割 n。
  • 把跨过的元素下标 j 当成分割下标；实际应记录 j+1。
  • 发现更高分时忘记清空答案，或相等时忘记追加。
  • 初始化 best=0、遗漏位置 0，会在全 1 等情况下失去正确答案。
  • 把“左侧 0 + 右侧 1”写反，或对 1 执行加分。

面试追问

只求下标、不求分数，能省掉第一次统计吗？可以。全部 1 的数量是所有分割得分的共同常量，令初始相对分数为 0，再按 ±1 扫描，最大值下标不变。此时变量是相对分数，不能当作真实得分展示。

计分有权重怎么办？若左侧 0 每项贡献 a、右侧 1 每项贡献 b，初始值为 b×总 1 数，跨 0 加 a，跨 1 减 b。若只要最高分？去掉答案数组，仅维护 best。

Java · LeetCode 提交代码

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> maxScoreIndices(int[] nums) {
        int score = 0;
        for (int x : nums) score += x;
        int best = score;
        List<Integer> answer = new ArrayList<>();
        answer.add(0);
        for (int j = 0; j < nums.length; j++) {
            score += nums[j] == 0 ? 1 : -1;
            if (score > best) {
                best = score;
                answer.clear();
            }
            if (score == best) answer.add(j + 1);
        }
        return answer;
    }
}

var maxScoreIndices = function(nums) {
    let score = nums.reduce((sum, x) => sum + x, 0);
    let best = score;
    const answer = [0];
    for (let j = 0; j < nums.length; j++) {
        score += nums[j] === 0 ? 1 : -1;
        if (score > best) {
            best = score;
            answer.length = 0;
        }
        if (score === best) answer.push(j + 1);
    }
    return answer;
};

Python 3 · LeetCode 提交代码

from typing import List

class Solution:
    def maxScoreIndices(self, nums: List[int]) -> List[int]:
        score = sum(nums)
        best = score
        answer = [0]
        for j, x in enumerate(nums):
            score += 1 if x == 0 else -1
            if score > best:
                best = score
                answer.clear()
            if score == best:
                answer.append(j + 1)
        return answer
