最接近原点的 K 个点

把二维距离问题压缩为一个可比较的数字，再用大小为 K 的最大堆守住当前最优集合。

MEDIUMK Closest Points to Origin非付费题

题目

给定二维整数数组 points，其中 points[i] = [xᵢ, yᵢ] 表示平面上的一个点，再给定整数 k。请返回距离原点 (0, 0) 最近的 k 个点。返回顺序不限；除顺序外，答案保证唯一。

d = √(x² + y²)　⇢　比较时只需用 d² = x² + y²

示例 1

输入：points = [[1,3],[-2,2]], k = 1
输出：[[-2,2]]
解释：(1,3) 的距离为 √10，(-2,2) 为 √8，后者更近。

示例 2

输入：points = [[3,3],[5,-1],[-2,4]], k = 2
输出：[[3,3],[-2,4]]
解释：[[-2,4],[3,3]] 也会被接受。

约束

  • 1 ≤ k ≤ points.length ≤ 10⁴
  • -10⁴ < xᵢ, yᵢ < 10⁴

距离雷达：最大堆如何守住 K 个名额

每一步扫描一个点。候选区满员后，只有比当前“最远入选点”更近的新点，才能完成替换。

题解：大小为 K 的最大堆

核心洞察

平方根严格单调，因此比较欧氏距离等价于比较 x² + y²，不必真的开平方。维护 K 个候选时，让其中最远的点位于堆顶，淘汰成本最低。

完整过程

  1. 依次计算每个点的平方距离。
  2. 把点放入最大堆；如果堆大小超过 k，弹出距离最大的堆顶。
  3. 扫描结束后，堆中恰好是最近的 k 个点，顺序任意。

正确性

  1. 不变式：扫描前 i 个点后，堆保存其中距离最小的至多 k 个点。
  2. 保持：加入新点后若数量超过 k，删除这 k+1 个候选中距离最大者；留下的正是前 i+1 个点里最近的 k 个。
  3. 终止：全部点扫描后，根据不变式，堆就是全体点中最近的 k 个，因此算法正确。

复杂度

时间 O(n log k)；堆的额外空间 O(k)（不计返回值）。

边界

k = 1、k = n、负坐标、坐标为 0、多个点等距均可处理；题目保证最终集合唯一。

替代方案

全排序时间 O(n log n)；快速选择平均 O(n)、最坏 O(n²)，原地实现更省空间但边界更难写。若 k 接近 n，排序或快速选择可能更合适。

面试追问

  • 数据流持续到来时怎么做？继续维护大小为 k 的最大堆。
  • 如何做到平均线性时间？使用按平方距离分区的 Quickselect。
  • 坐标范围更大怎么办？使用 64 位整数避免平方溢出。

常见错误

  • 误用最小堆后弹出最近点；固定容量时应弹出最远点。
  • 对距离开平方，增加无意义的浮点计算。
  • 把“答案顺序不限”误解成点内部坐标也可交换。
  • 整数平方可能溢出却没有提升数值类型。

四语言完整代码

import java.util.PriorityQueue;

class Solution {
    public int[][] kClosest(int[][] points, int k) {
        PriorityQueue<int[]> heap = new PriorityQueue<>(
            (a, b) -> Long.compare(dist(b), dist(a))
        );
        for (int[] point : points) {
            heap.offer(point);
            if (heap.size() > k) heap.poll();
        }
        int[][] answer = new int[k][2];
        for (int i = 0; i < k; i++) answer[i] = heap.poll();
        return answer;
    }
    private long dist(int[] p) {
        return (long) p[0] * p[0] + (long) p[1] * p[1];
    }
}
var kClosest = function(points, k) {
    const heap = [];
    const dist = p => p[0] * p[0] + p[1] * p[1];
    const swap = (i, j) => [heap[i], heap[j]] = [heap[j], heap[i]];
    const up = i => { while (i) { const p = (i - 1) >> 1; if (dist(heap[p]) >= dist(heap[i])) break; swap(p, i); i = p; } };
    const down = i => { while (true) { let m = i, l = i * 2 + 1, r = l + 1; if (l < heap.length && dist(heap[l]) > dist(heap[m])) m = l; if (r < heap.length && dist(heap[r]) > dist(heap[m])) m = r; if (m === i) break; swap(i, m); i = m; } };
    for (const point of points) {
        heap.push(point); up(heap.length - 1);
        if (heap.length > k) { swap(0, heap.length - 1); heap.pop(); down(0); }
    }
    return heap;
};
from typing import List
import heapq

class Solution:
    def kClosest(self, points: List[List[int]], k: int) -> List[List[int]]:
        heap = []
        for x, y in points:
            distance = x * x + y * y
            heapq.heappush(heap, (-distance, x, y))
            if len(heap) > k:
                heapq.heappop(heap)
        return [[x, y] for _, x, y in heap]
class Solution {
public:
    vector<vector<int>> kClosest(vector<vector<int>>& points, int k) {
        using Node = pair<long long, vector<int>>;
        priority_queue<Node> heap;
        for (const auto& p : points) {
            long long d = 1LL * p[0] * p[0] + 1LL * p[1] * p[1];
            heap.push({d, p});
            if (heap.size() > k) heap.pop();
        }
        vector<vector<int>> answer;
        while (!heap.empty()) { answer.push_back(heap.top().second); heap.pop(); }
        return answer;
    }
};
