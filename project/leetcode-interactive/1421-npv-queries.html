净现值查询

NPV Queries — 把每一条查询当作左侧主记录，用 id + year 这把复合钥匙寻找净现值；即使找不到，查询也不能消失。

题意

给定两张表：NPV 保存某个 id 在某个 year 的净现值，Queries 保存要查询的 (id, year) 组合。请返回每条查询对应的净现值；如果 NPV 表中没有匹配记录，则返回 0。结果顺序任意。

题解

核心洞察

Queries 决定必须返回哪些行，因此它必须放在 LEFT JOIN 左侧。连接条件不能只写 id，而要同时匹配 id 和 year。未命中时右表列是 NULL，再用 IFNULL / COALESCE 转成 0。

完整过程

  1. 从 Queries 读取每个复合键。
  2. 按 q.id = n.id AND q.year = n.year 左连接 NPV。
  3. 选择查询的 id、year。
  4. 把缺失的 n.npv 映射为 0。

正确性说明

对任意查询 q，LEFT JOIN 保证它在结果中恰有对应行。若存在相同复合键的 NPV 行，连接条件选择它并返回其 npv；若不存在，右侧为 NULL，而 COALESCE 返回 0。两种情况覆盖所有查询，因此结果符合要求。

边界

  • NPV 缺失：返回 0，而不是丢掉查询。
  • NPV 本身为 0：仍返回 0，语义正确。
  • 同 id 不同 year：不能互相匹配。
  • 结果顺序无要求，不必额外 ORDER BY。

复杂度

从关系模型看需要扫描 Queries 并按复合键查找 NPV。若 NPV(id, year) 有主键索引，设查询数为 Q、NPV 行数为 N，典型代价约为 O(Q log N)，输出空间 O(Q)。具体执行计划由数据库优化器决定。

替代方案

相关子查询也能完成，但通常不如 LEFT JOIN 直观。RIGHT JOIN 可通过交换表实现，却更容易写反保留侧。INNER JOIN 不适用，因为它会删除没有 NPV 的查询。

面试追问

  • 为什么过滤右表的条件放在 WHERE 里可能破坏 LEFT JOIN？
  • 如何区分“缺失后补 0”和“数据库中真实存储 0”？
  • 若复合键不唯一，结果行数会怎样膨胀？
  • 怎样设计索引来服务这个连接？

常见错误

  • 从 NPV 出发，导致缺失查询无法出现。
  • 仅连接 id，错误匹配其他年份。
  • 忘记 COALESCE，输出 NULL。
  • 把 n.npv = ... 等右表过滤写入 WHERE，意外变成内连接效果。

SELECT
    q.id,
    q.year,
    COALESCE(n.npv, 0) AS npv
FROM Queries AS q
LEFT JOIN NPV AS n
    ON q.id = n.id
   AND q.year = n.year;
import java.util.*;

class Solution {
    public int[][] npvQueries(int[][] npv, int[][] queries) {
        Map<String, Integer> valueByKey = new HashMap<>();
        for (int[] row : npv) {
            valueByKey.put(key(row[0], row[1]), row[2]);
        }

        int[][] answer = new int[queries.length][3];
        for (int i = 0; i < queries.length; i++) {
            int id = queries[i][0];
            int year = queries[i][1];
            answer[i] = new int[] {
                id, year, valueByKey.getOrDefault(key(id, year), 0)
            };
        }
        return answer;
    }

    private String key(int id, int year) {
        return id + "#" + year;
    }
}
/** 本地语义参考：数组行分别为 [id, year, npv] 与 [id, year]。 */
function npvQueries(npv, queries) {
  const valueByKey = new Map(
    npv.map(([id, year, value]) => [`${id}#${year}`, value])
  );

  return queries.map(([id, year]) => [
    id,
    year,
    valueByKey.get(`${id}#${year}`) ?? 0,
  ]);
}
from typing import List


class Solution:
    def npv_queries(
        self, npv: List[List[int]], queries: List[List[int]]
    ) -> List[List[int]]:
        value_by_key = {
            (identifier, year): value
            for identifier, year, value in npv
        }
        return [
            [identifier, year, value_by_key.get((identifier, year), 0)]
            for identifier, year in queries
        ]
#include <array>
#include <map>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    vector<array<int, 3>> npvQueries(
        const vector<array<int, 3>>& npv,
        const vector<pair<int, int>>& queries
    ) {
        map<pair<int, int>, int> valueByKey;
        for (const auto& row : npv) {
            valueByKey[{row[0], row[1]}] = row[2];
        }

        vector<array<int, 3>> answer;
        answer.reserve(queries.size());
        for (const auto& [id, year] : queries) {
            const auto it = valueByKey.find({id, year});
            const int value = it == valueByKey.end() ? 0 : it->second;
            answer.push_back({id, year, value});
        }
        return answer;
    }
};
