数组中的 k 个最强值

强，不是离中位数更大，而是离中位数更远。距离相同时，数值更大的那个胜出。

Problem

先定义“强度”

答案顺序任意

给定整数数组 arr 和整数 k。先把数组升序排列，令长度为 n，取下标 ⌊(n - 1) / 2⌋ 处的值作为中位数 m（偶数长度时取中间两个数中较小的一个）。

若下面任一条件成立，值 x 比值 y 更强：

|x − m| > |y − m|；或距离相等且 x > y

返回数组中最强的 k 个值，返回顺序不限；相同的值按其出现次数保留。

约束

  • 1 ≤ arr.length ≤ 10⁵
  • −10⁵ ≤ arr[i] ≤ 10⁵
  • 1 ≤ k ≤ arr.length
示例 1 · 距离相同看数值 
输入：arr = [1,2,3,4,5], k = 2
输出：[5,1]
解释：m = 3，强度顺序为 [5,1,4,2,3]。
      5 与 1 距离相同，5 更大，所以更强。
      [1,5] 也会被接受。
示例 2 · 重复值 
输入：arr = [1,1,3,5,5], k = 2
输出：[5,5]
解释：m = 3，两个 5 是最强的两个值。
示例 3 · 偶数长度 
输入：arr = [6,7,11,7,6,8], k = 5
输出：[11,8,6,6,7]
解释：排序后 m = 7，强度顺序为
      [11,8,6,6,7,7]。
      输出中这 5 个值的任意排列均可。

核心洞察

数组排序后，尚未选择区间里最强的值一定在最左端或最右端。因此每轮只比较两个端点，选走更强者即可。

完整过程

  1. 升序排序 arr，中位数为 m = arr[(n - 1) / 2]（整数下取整）。
  2. 令 left = 0、right = n - 1。此时未选择的元素始终组成一个连续区间。
  3. 比较两端到 m 的距离。距离更大的端点更强；若相等，则右端数值更大，所以选择右端。
  4. 移动被选择一侧的指针。重复 k 次，将每次选中的值加入答案。

为什么正确

引理：最强者在端点

排序后，对任意剩余元素 x：若 x ≤ m，越靠左距离越大；若 x ≥ m，越靠右距离越大。因此左侧候选不强于最左端，右侧候选不强于最右端。

归纳：每轮选择安全

由引理，全局最强的剩余值只能是两个端点之一。按题目规则比较两端便会选中它。移除后剩余部分仍是连续有序区间，引理继续成立。重复 k 轮，得到的正是最强的 k 个值。

边界处理

  • 偶数长度：严格取排序后下标 (n - 1) / 2，不是两个中间值的平均数。
  • 距离相等：选择数值更大的右端，比较条件写成“左距离严格大于右距离才选左”。
  • 重复元素：每个数组位置独立参与选择，不去重。
  • k = n：所有元素都会被选中，返回顺序仍可任意。

复杂度

时间 O(n log n)额外空间 O(log n)～O(n)，取决于语言排序实现双指针选择 O(k)

替代方案

也可以先求中位数，再按键 (|x-m|, x) 降序排序并取前 k 个，代码直观但仍为 O(n log n)。若使用快速选择找到中位数，并用大小为 k 的最小堆维护答案，可做到期望 O(n + n log k)，但实现与常数更复杂。

四语言完整代码

JavaLeetCode 可提交
import java.util.Arrays;

class Solution {
    public int[] getStrongest(int[] arr, int k) {
        Arrays.sort(arr);
        int median = arr[(arr.length - 1) / 2];
        int left = 0;
        int right = arr.length - 1;
        int[] answer = new int[k];

        for (int i = 0; i < k; i++) {
            int leftDistance = Math.abs(arr[left] - median);
            int rightDistance = Math.abs(arr[right] - median);

            if (leftDistance > rightDistance) {
                answer[i] = arr[left++];
            } else {
                // 距离相等时，右端值更大，因此右端更强。
                answer[i] = arr[right--];
            }
        }
        return answer;
    }
}

var getStrongest = function(arr, k) {
    arr.sort((a, b) => a - b);
    const median = arr[Math.floor((arr.length - 1) / 2)];
    const answer = [];
    let left = 0;
    let right = arr.length - 1;

    while (answer.length < k) {
        const leftDistance = Math.abs(arr[left] - median);
        const rightDistance = Math.abs(arr[right] - median);

        if (leftDistance > rightDistance) {
            answer.push(arr[left++]);
        } else {
            // 包含距离相等的情况：右端值更大。
            answer.push(arr[right--]);
        }
    }
    return answer;
};

from typing import List


class Solution:
    def getStrongest(self, arr: List[int], k: int) -> List[int]:
        arr.sort()
        median = arr[(len(arr) - 1) // 2]
        answer = []
        left, right = 0, len(arr) - 1

        while len(answer) < k:
            left_distance = abs(arr[left] - median)
            right_distance = abs(arr[right] - median)

            if left_distance > right_distance:
                answer.append(arr[left])
                left += 1
            else:
                # 距离相等时选择数值更大的右端。
                answer.append(arr[right])
                right -= 1

        return answer
C++LeetCode 可提交
class Solution {
public:
    vector<int> getStrongest(vector<int>& arr, int k) {
        sort(arr.begin(), arr.end());
        const int median = arr[(arr.size() - 1) / 2];
        int left = 0;
        int right = static_cast<int>(arr.size()) - 1;
        vector<int> answer;
        answer.reserve(k);

        while (static_cast<int>(answer.size()) < k) {
            int leftDistance = abs(arr[left] - median);
            int rightDistance = abs(arr[right] - median);

            if (leftDistance > rightDistance) {
                answer.push_back(arr[left++]);
            } else {
                // 距离相等时右端值更大。
                answer.push_back(arr[right--]);
            }
        }
        return answer;
    }
};

面试追问

能否不完整排序？

可以。快速选择期望线性时间求中位数，再用堆筛选最强的 k 个；需要仔细实现强度比较器。

为何相等时一定选右端？

升序数组中右端值不小于左端。两者到中位数距离相同，题目明确规定数值更大者更强。

若要求按强度顺序返回？

当前双指针每轮都取剩余全局最强值，因此产生的顺序本身就是从强到弱。

输入数组会被修改吗？

四份实现都会原地排序。若调用方要求保留原数组，需要先复制，再在副本上排序。

常见错误

  • 偶数长度时把中位数算成两个中间数的平均值。
  • 只按绝对距离排序，忘记距离相等时数值更大者优先。
  • 比较端点时使用 >= 选择左端，恰好把平局规则写反。
  • 用集合存答案导致重复值被错误去重。
  • 用减法式比较器处理远超题目范围的数据时忽略整数溢出风险。
