游乐园的游览计划

每条 A-B-C-A 路线就是一个包含重点 A 的三角形。问题变为：枚举图中所有三角形，并为每个中心点拼接两个三角形，最大化它们顶点并集的喜爱值。

题意

上午和下午各选择一个经过同一重点项目 A 的三角环。两个环可以重复顶点，但同一项目的喜爱值只计一次。若不存在三角形，返回 0。

edges=[[0,1],[1,2],[0,2]], value=[1,2,3]
输出=6

定向枚举三角形 + 候选压缩

预处理

每条边从小编号指向大编号，交集两个端点的出邻居，恰好一次枚举 i<j<k 的三角形。记录每个点的最大三角形、所有三角形，以及每条边分数最高的 3 个三角形。

候选证明

中心 A 的最大三角形 Aab 中，a、b 必须都出现在某个最优双环并集中，否则替换其中一环不会变差。于是只需检查最大三角形整体拼接，或分别沿边 Aa、Ab 取候选；每边前三名足以绕开至多两个冲突顶点。

三角形枚举上界 O(M√M)，合并与三角形数量线性同阶；N、M≤10000。

from collections import defaultdict
class Solution:
 def maxWeight(self,edges,value):
  n=len(value);out=[set() for _ in range(n)]
  for a,b in edges:
   if a>b:a,b=b,a
   out[a].add(b)
  at=defaultdict(list);best=[None]*n;top=defaultdict(list)
  for i in range(n):
   for j in out[i]:
    for k in out[i]&out[j]:
     if k<=j:continue
     t=(i,j,k,value[i]+value[j]+value[k])
     for x in t[:3]:at[x].append(t);best[x]=max(best[x] or t,t,key=lambda z:z[3])
     for e in ((i,j),(i,k),(j,k)):
      top[e].append(t);top[e].sort(key=lambda z:-z[3]);del top[e][3:]
  score=lambda a,b:sum(value[x] for x in set(a[:3])|set(b[:3]));ans=0
  for x,m in enumerate(best):
   if m is None:continue
   ans=max(ans,m[3],*(score(m,t) for t in at[x]));a,b=(y for y in m[:3] if y!=x);e1=tuple(sorted((x,a)));e2=tuple(sorted((x,b)))
   for p in top[e1]:
    for q in top[e2]:ans=max(ans,score(p,q))
  return ans
