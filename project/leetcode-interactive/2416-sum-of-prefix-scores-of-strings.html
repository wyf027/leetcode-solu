2416. 字符串的前缀分数和

Sum of Prefix Scores of Strings

同一个开头，被多少个单词共享？

先理解“前缀的分数”，再尝试独立思考。算法、交互演示与代码在页面底部按需展开。

字符串非付费题官方题目 ↗

01 / 题意

给定字符串数组 words。对于一个非空字符串 term，它的分数就是数组中以它开头的元素数量。对每个 words[i]，把它所有非空前缀的分数相加，按原顺序返回数组 answer。

字符串本身也算自己的前缀；相同字符串出现在不同下标时，要分别计数。空前缀不计分。

参数与返回值

sumPrefixScores(words: string[]) → integer[]

结果数组长度等于 words.length。

约束

  • 1 ≤ words.length ≤ 1000
  • 1 ≤ words[i].length ≤ 1000
  • 每个单词只含小写英文字母 a–z。

02 / 示例一

输入：words = ["abc","ab","bc","b"]
输出：[5,4,3,2]
  • abc：前缀 a / ab / abc，分数 2 + 2 + 1 = 5。
  • ab：前缀 a / ab，分数 2 + 2 = 4。
  • bc：前缀 b / bc，分数 2 + 1 = 3。
  • b：前缀 b，分数为 2。

03 / 示例二

输入：words = ["abcd"]
输出：[4]

abcd 的非空前缀依次是 a、ab、abc、abcd。每个前缀都只匹配一个数组元素，所以结果是 1 + 1 + 1 + 1 = 4。

思考：如果把这个单词再放入数组一次，每个前缀的分数会如何变化？

05 / 独立题解

准备好后再展开：核心思路、计数实验室、证明与四语言实现。

把每个前缀变成一个节点

用字典树（Trie）共享单词开头：从根走到某个节点的字符序列，恰好是一个非空前缀。插入每个单词时，经过节点就把它的 count 加一。全部插入后，节点的计数就是对应前缀的分数。

再沿每个单词的路径走一次，把沿途所有节点的计数加起来。根代表空前缀，不参与累加。无需记录单词结束标记，因为我们统计的是“经过”，不是“在此结束”。

前缀计数实验室

先逐字符插入，再逐字符求和。灰色节点尚未建立，绿色节点已有计数，橙色节点是当前访问位置；文字同步描述每一步。

节点标签：完整前缀 · 计数。按钮支持 Tab 聚焦、Enter / 空格激活。启用减少动态效果时自动播放间隔加长。

完整过程

  1. 建立空根节点，每个节点含字符到子节点的映射和计数。
  2. 按数组顺序插入所有单词：从根出发，必要时创建子节点，走到子节点后增加计数。重复单词也完整插入。
  3. 插入全部完成后，逐个查询单词。每读一个字符，就走到对应子节点并把它的计数加入当前答案。
  4. 按单词原顺序返回答案。例如 abc 经过计数为 2、2、1 的节点，得到 5。

正确性证明

计数不变式：插入前 k 个单词后，任意前缀节点的计数等于这 k 个单词中以该前缀开头的元素数。初始全部为零，成立；插入下一个单词时，恰好访问它的所有非空前缀节点，并各加一，其余不变，因此不变式保持。

求和完整性：所有单词插入结束时，上述计数已等于题目定义的前缀分数。查询一个单词时，路径上的非根节点与该单词的非空前缀一一对应，既不遗漏，也不重复。沿路径累加这些分数，就得到该单词的正确答案。对所有单词执行查询，所以返回数组正确。

复杂度

设 S = Σ|words[i]|，字母表大小固定为 26。每个字符插入和查询各一次，时间 O(S)；节点至多 S + 1，辅助空间 O(S)，输出为 O(n)。

Java/C++ 使用 26 槽数组；Python/JavaScript 使用稀疏字典或 Map。后者按均摊常数时间查找分析。实际内存常数取决于语言的对象开销。

边界与数值

  • 只有一个单词：答案等于它的长度。
  • 全部相同：每个答案为 n × 单词长度。
  • 一个词是另一个词的前缀：短词仍贡献沿途计数。
  • 单个答案最大 1000 × 1000 = 10⁶，32 位整数足够。
  • 使用循环，不依赖深度为 1000 的递归。

Java

class Solution {
    static class Node {
        Node[] next = new Node[26];
        int count;
    }

    public int[] sumPrefixScores(String[] words) {
        Node root = new Node();
        for (String word : words) {
            Node node = root;
            for (int i = 0; i < word.length(); i++) {
                int c = word.charAt(i) - 'a';
                if (node.next[c] == null) node.next[c] = new Node();
                node = node.next[c];
                node.count++;
            }
        }
        int[] answer = new int[words.length];
        for (int i = 0; i < words.length; i++) {
            Node node = root;
            for (int j = 0; j < words[i].length(); j++) {
                node = node.next[words[i].charAt(j) - 'a'];
                answer[i] += node.count;
            }
        }
        return answer;
    }
}

JavaScript

/**
 * @param {string[]} words
 * @return {number[]}
 */
var sumPrefixScores = function(words) {
    const root = { next: new Map(), count: 0 };
    for (const word of words) {
        let node = root;
        for (const ch of word) {
            if (!node.next.has(ch)) {
                node.next.set(ch, { next: new Map(), count: 0 });
            }
            node = node.next.get(ch);
            node.count++;
        }
    }
    return words.map(word => {
        let node = root, sum = 0;
        for (const ch of word) {
            node = node.next.get(ch);
            sum += node.count;
        }
        return sum;
    });
};

Python 3

from typing import List

class Node:
    __slots__ = ('next', 'count')

    def __init__(self):
        self.next = {}
        self.count = 0

class Solution:
    def sumPrefixScores(self, words: List[str]) -> List[int]:
        root = Node()
        for word in words:
            node = root
            for ch in word:
                if ch not in node.next:
                    node.next[ch] = Node()
                node = node.next[ch]
                node.count += 1

        answer = []
        for word in words:
            node = root
            total = 0
            for ch in word:
                node = node.next[ch]
                total += node.count
            answer.append(total)
        return answer

C++

#include <array>
#include <string>
#include <vector>
using namespace std;

class Solution {
    struct Node {
        array<int, 26> next{};
        int count = 0;
    };
public:
    vector<int> sumPrefixScores(vector<string>& words) {
        vector<Node> trie(1);
        for (const string& word : words) {
            int node = 0;
            for (char ch : word) {
                int c = ch - 'a';
                if (trie[node].next[c] == 0) {
                    int child = static_cast<int>(trie.size());
                    trie[node].next[c] = child;
                    trie.emplace_back();
                }
                node = trie[node].next[c];
                trie[node].count++;
            }
        }
        vector<int> answer;
        answer.reserve(words.size());
        for (const string& word : words) {
            int node = 0, sum = 0;
            for (char ch : word) {
                node = trie[node].next[ch - 'a'];
                sum += trie[node].count;
            }
            answer.push_back(sum);
        }
        return answer;
    }
};

替代方案

  • 两两最长公共前缀：answer[i] = Σ LCP(words[i], words[j])，因为一对单词共享几个非空前缀，就贡献几分。含自身项，朴素时间 O(n²L)，空间可为 O(n)；适合作为小数据参考。
  • 前缀字符串计数表：枚举所有前缀并统计出现次数，再查询求和。思路直接，但构造和哈希每个前缀可能扫描整个前缀，常规实现总时间与字符串存储量可达 O(Σ|word|²)。Trie 避免反复存储相同开头。
  • 排序 + LCP：相邻单词的最长公共前缀可刻画一段排序区间的共享开头，结合单调栈等结构聚合贡献；需要恢复原下标，实现和证明更复杂。

常见错误

  • 只在单词末尾计数，遗漏中间前缀。
  • 先查询后插入剩余单词，计数不完整。
  • 数组去重，导致重复元素贡献消失。
  • 累加根节点，误把空前缀算进去。
  • 查询每个词时未将节点与累加器复位。
  • C++ 保留 vector 元素引用后扩容，造成引用失效；示例代码使用下标重新访问。

面试追问

  • 支持删词？沿路径计数减一，且必须先确认该词存在；这时需要额外的终止计数。
  • 字符集扩大？用稀疏映射，按题目定义的字符单位遍历。
  • 内存紧张？用节点索引池、紧凑边结构或压缩 Trie，避免大量独立对象。
  • 在线插入后输出全部答案？原有词的答案也可能增加，不能只计算新词；需重新查询或额外维护共享前缀的影响。
