统计坏数对的数目

Count Number of Bad Pairs

两个下标之间的距离，是否等于它们对应数值的差？

先理解判定规则，再移动扫描指针。核心题解默认收起。

01 / PROBLEM

题目在问什么

给定从下标 0 开始的整数数组 nums。在所有满足 i < j 的下标对中，如果下标距离与对应元素的数值差不相等，就把它计为一个坏数对。返回坏数对总数。

i < j 且 j − i ≠ nums[j] − nums[i]

数对由下标确定；相同数值也可以来自不同位置。差值有方向，不能取绝对值。

参数与约束

countBadPairs(nums)

  • nums：整数数组
  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁹
  • 返回一个非负整数；Java / C++ 需要 64 位结果类型。

05 / SOLUTION

准备好看题解了吗？

先想一想：怎样避免逐个比较所有数对？

把相同的差值放进同一个桶

核心洞察

先数好数对。把等式移项：

j − i = nums[j] − nums[i]
⇔ nums[j] − j = nums[i] − i

key(i) = nums[i] − i

相同 key 的两个位置恰好构成好数对。扫描到 j 时，左侧共有 j 个位置，若相同 key 已出现 same 次，本步新增坏数对就是 j − same。

同步分组视图

与上方扫描同步。这里展示处理当前 j 之前的频次桶，避免把自己算入左侧。

使用上方扫描控件可观察每一步的桶状态。

完整过程

  1. 初始化频次表 freq 和累计答案 bad = 0。
  2. 按从左到右的顺序取下标 j，计算 key = nums[j] − j。
  3. 读取 same = freq[key]；不存在则为 0。
  4. 将 j − same 加入 bad。
  5. 最后让 freq[key] 增加 1，供后续右端点使用。

正确性证明

循环不变式：处理下标 j 之前，freq 只记录下标小于 j 的 key 频次；bad 恰好等于右端点小于 j 的所有坏数对数量。

初始 j = 0 时，两者都为空或为 0，不变式成立。当前 j 与此前 j 个位置组成全部新增候选对；由移项等价式可知，其中恰有 freq[key] 个好数对，所以 j − freq[key] 是全部新增坏数对。累加后再更新频次，不变式对下一步仍成立。

循环结束时每个合法数对都在其唯一右端点处被考虑一次，没有遗漏或重复，因此 bad 为所求答案。

复杂度与数值边界

哈希表操作平均 O(1)，整体期望时间 O(n)，额外空间 O(n)。这是平均/期望分析，并非任意哈希实现的最坏情况保证。

最大答案为 n(n−1)/2 = 4,999,950,000，超出 32 位有符号整数。Java 用 long，C++ 用 long long；Python 整数自然支持，JavaScript Number 在本题范围内可精确表示整数。

边界与常见错误

  • n = 1 时没有数对，返回 0。
  • 相邻数值都增加 1 时，全部 key 相同，答案为 0。
  • 所有值相同时，每个 key 不同，全部数对都坏。
  • key 可以为负数，不能直接当作非负数组下标。
  • 先查询、累加，再更新 freq；否则会把当前元素自己计入。
  • 不要取绝对差，也不要混用 nums[i]−i 与 i−nums[i]。

替代方案

  • 总对数减好数对：先统计每个 key 的次数 c，再用 n(n−1)/2 减去各组 c(c−1)/2。期望 O(n) 时间、O(n) 空间；Java/C++ 的乘法要先提升到 64 位。
  • 排序：生成全部 key 并排序，扫描连续相同段，统计好数对后相减。时间 O(n log n)，键数组空间 O(n)，不依赖哈希均摊性能。
  • 枚举：逐个判断所有 i < j，O(n²) 时间、O(1) 额外空间，适合小数据理解，不适合 10⁵ 的规模。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public long countBadPairs(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();
        long bad = 0;
        for (int j = 0; j < nums.length; j++) {
            int key = nums[j] - j;
            int same = freq.getOrDefault(key, 0);
            bad += (long) j - same;
            freq.put(key, same + 1);
        }
        return bad;
    }
}

        return bad

C++

#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    long long countBadPairs(vector<int>& nums) {
        unordered_map<int, int> freq;
        long long bad = 0;
        for (int j = 0; j < static_cast<int>(nums.size()); ++j) {
            int key = nums[j] - j;
            int same = freq[key];
            bad += static_cast<long long>(j) - same;
            freq[key] = same + 1;
        }
        return bad;
    }
};

面试追问

能边接收数据边计算吗？

可以。保留当前下标、频次表和累计答案，新增元素时做同样的一步更新，无须保存原数组。

为什么不用双指针？

原数组没有能让指针单调移动的大小关系；好数对由差值键相等决定。

若好数对条件改成 nums[j]−nums[i] = k(j−i)？

把键改成 nums[i]−k·i，仍可按相同键计数；同时重新评估键与乘法的整数范围。
