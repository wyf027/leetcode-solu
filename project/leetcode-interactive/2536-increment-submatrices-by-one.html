2536 / 子矩阵元素加 1

Increment Submatrices by One

一张全零方格纸，多次矩形覆盖。最后，每个格子被覆盖了几次？

01 / Problem

题目与输入

给定正整数 n，初始矩阵 mat 为 n × n，所有元素都是 0，行列下标从 0 开始。

对数组 queries 中的每项 [row1, col1, row2, col2]，将左上角 (row1, col1) 到右下角 (row2, col2) 之间的所有格子加 1。两个端点均包含；重叠区域会重复累加。返回全部操作结束后的矩阵。

函数：rangeAddQueries(n, queries) → 整数二维数组

约束

  • 1 ≤ n ≤ 500
  • 1 ≤ queries.length ≤ 10⁴
  • 0 ≤ row1ᵢ ≤ row2ᵢ < n
  • 0 ≤ col1ᵢ ≤ col2ᵢ < n

官方示例 1 · 重叠

输入：n = 3,
queries = [[1,1,2,2],[0,0,1,1]]
输出：[[1,1,0],[1,2,1],[0,1,1]]

先覆盖右下方 2 × 2 区域，再覆盖左上方 2 × 2 区域。中心格 (1,1) 被覆盖两次，值为 2。

官方示例 2 · 全覆盖

输入：n = 2,
queries = [[0,0,1,1]]
输出：[[1,1],[1,1]]

唯一的操作覆盖整张矩阵，因此每个格子的值都为 1。

04 / Solution

二维差分：一次覆盖，只留下四个角

核心洞察

把“给整个矩形加 1”变成四处边界标记，再统一做二维前缀和。一个 +1 标记在还原时会影响它右下方的所有格子；另外三个标记负责截断多余影响。

D[r1][c1]         += 1  // 开始覆盖
D[r1][c2 + 1]     -= 1  // 截断右侧
D[r2 + 1][c1]     -= 1  // 截断下侧
D[r2 + 1][c2 + 1] += 1  // 补回重复减去的右下方

分配 (n + 1) × (n + 1) 的差分矩阵。额外的第 n 行与第 n 列只存储终止标记，不属于答案。所有查询标记完成后，按行从左到右还原：

D[i][j] += 上方已还原值 + 左方已还原值 - 左上方已还原值

边界外的值视为 0；只有前 n 行、前 n 列参与还原并输出。

Interactive / Four corners

边界印章 → 前缀和扫描

每步落下一个角标记；全部标记后，每步还原一个格子。格内小字是 (行,列)，虚线格为哨兵边界。



还原阶段中，青色格已得到最终值，其他格仍存差分值；因此中间画面是混合状态。哨兵格始终保留边界标记。

完整过程
  1. 创建全零的 D，多留一行一列。
  2. 遍历每个查询，在四个边界角写入 +1, -1, -1, +1。重合标记直接相加。
  3. 按行扫描原矩阵区域，用上、左、左上三个已还原值更新当前格。
  4. 取前 n × n 个值作为答案。


例如示例 1 的第一个查询在 (1,1)、(1,3)、(3,1)、(3,3) 分别写入 +1、−1、−1、+1；第二个查询的四个点是 (0,0)、(0,2)、(2,0)、(2,2)。还原后，(1,1) 收到两次矩形覆盖，得到 2。


正确性
对单个查询，位置 (i,j) 的前缀和贡献为：
[i ≥ r1][j ≥ c1] − [i ≥ r1][j ≥ c2+1]
− [i ≥ r2+1][j ≥ c1] + [i ≥ r2+1][j ≥ c2+1]
= ([i ≥ r1] − [i ≥ r2+1])
  × ([j ≥ c1] − [j ≥ c2+1])
其中 [条件] 在条件为真时取 1，否则取 0。乘积恰好在目标矩形内为 1，在矩形外为 0。前缀和具有线性性质，因此多个查询的贡献相加，正好等于每个格子被覆盖的次数。按行还原时，上方、左方和左上方均已处理；减去左上方可以消除重复计数，所以扫描公式确实算出每个位置的二维前缀和。


边界与常见错误
  • r2、c2 包含在矩形中，终止标记必须放在 r2 + 1、c2 + 1。
  • 右下角必须加 1，否则会重复扣减。
  • 到达最后一行或列时，终止标记落在下标 n；不要把这行或列返回。
  • 前缀和要减去左上方；还原必须等全部查询标记完成。
  • 最小 n = 1、单行/单列矩形、完全重叠均适用。最终值不超过 queries.length，即 10⁴，32 位有符号整数足够。
  • JavaScript 与 Python 要独立分配每一行，避免共享同一个数组引用。


复杂度
记 q = queries.length。每个查询只改四个点，标记共 O(q)；还原与返回矩阵共 O(n²)。总时间 O(q + n²)，辅助空间 O(n²)，输出也为 O(n²)。


替代方案
  • 直接模拟：遍历每个矩形的格子，最坏 O(qn²) 时间，输出外可用 O(1) 空间。容易理解，但大输入代价高。
  • 逐行一维差分：每个查询遍历其涉及的行，在每行的 c1 加 1、c2+1 减 1，再做行前缀和。时间 O(qn + n²)，空间 O(n²)。这也是官方提示给出的方向。


面试追问
  • 每次加上任意 v？四个角改成 +v、−v、−v、+v，其他过程相同；按数值范围选择整数类型。
  • 查询顺序能改变吗？可以，所有操作都是整数加法，满足交换律。
  • 需要交替更新与查询单点？离线一次还原不再适合，可以用二维树状数组维护差分点更新和前缀查询。
  • 为什么最终还要 O(n²)？题目要求返回每个格子，输出本身就有 n² 个元素。

Java
class Solution {
    public int[][] rangeAddQueries(int n, int[][] queries) {
        int[][] d = new int[n + 1][n + 1];
        for (int[] q : queries) {
            int a = q[0], b = q[1], c = q[2], e = q[3];
            d[a][b]++;
            d[a][e + 1]--;
            d[c + 1][b]--;
            d[c + 1][e + 1]++;
        }
        int[][] ans = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (i > 0) d[i][j] += d[i - 1][j];
                if (j > 0) d[i][j] += d[i][j - 1];
                if (i > 0 && j > 0)
                    d[i][j] -= d[i - 1][j - 1];
                ans[i][j] = d[i][j];
            }
        }
        return ans;
    }
}

/**

var rangeAddQueries = function(n, queries) {
    const d = Array.from({length: n + 1},
        () => Array(n + 1).fill(0));
    for (const [a, b, c, e] of queries) {
        d[a][b]++;
        d[a][e + 1]--;
        d[c + 1][b]--;
        d[c + 1][e + 1]++;
    }
    for (let i = 0; i < n; i++) {
        for (let j = 0; j < n; j++) {
            if (i > 0) d[i][j] += d[i - 1][j];
            if (j > 0) d[i][j] += d[i][j - 1];
            if (i > 0 && j > 0)
                d[i][j] -= d[i - 1][j - 1];
        }
    }
    return d.slice(0, n).map(row => row.slice(0, n));
};

from typing import List

class Solution:
    def rangeAddQueries(
        self, n: int, queries: List[List[int]]
    ) -> List[List[int]]:
        d = [[0] * (n + 1) for _ in range(n + 1)]
        for a, b, c, e in queries:
            d[a][b] += 1
            d[a][e + 1] -= 1
            d[c + 1][b] -= 1
            d[c + 1][e + 1] += 1
        for i in range(n):
            for j in range(n):
                if i > 0:
                    d[i][j] += d[i - 1][j]
                if j > 0:
                    d[i][j] += d[i][j - 1]
                if i > 0 and j > 0:
                    d[i][j] -= d[i - 1][j - 1]
        return [row[:n] for row in d[:n]]


C++
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> rangeAddQueries(
        int n, vector<vector<int>>& queries) {
        vector<vector<int>> d(n + 1, vector<int>(n + 1));
        for (const auto& q : queries) {
            int a = q[0], b = q[1], c = q[2], e = q[3];
            ++d[a][b];
            --d[a][e + 1];
            --d[c + 1][b];
            ++d[c + 1][e + 1];
        }
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                if (i > 0) d[i][j] += d[i - 1][j];
                if (j > 0) d[i][j] += d[i][j - 1];
                if (i > 0 && j > 0)
                    d[i][j] -= d[i - 1][j - 1];
            }
            d[i].resize(n);
        }
        d.resize(n);
        return d;
    }
};
