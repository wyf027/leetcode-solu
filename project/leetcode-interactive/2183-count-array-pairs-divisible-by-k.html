Count Array Pairs Divisible by K

从数组中选出两个不同位置，使两个位置上的数值乘积恰好能被 k 整除。你能在十万个元素中，数清所有符合条件的组合吗？

官方题目 ↗
01 / Problem

题目与输入边界

给定从 0 开始索引的整数数组 nums 和正整数 k，返回满足 0 ≤ i < j < nums.length 且 (nums[i] × nums[j]) % k = 0 的下标对数量。

同一数值出现在不同下标时，仍是不同元素；每一对只计一次。注意判断的是元素乘积，不是下标乘积，也不是元素之和。

参数

nums: integer[]
k: integer
返回：long 语义的整数计数。

官方约束

1 ≤ nums.length ≤ 10⁵
1 ≤ nums[i] ≤ 10⁵
1 ≤ k ≤ 10⁵

Example 01

有七对符合条件

输入：nums = [1,2,3,4,5], k = 2
输出：7

下标对为 (0,1)、(0,3)、(1,2)、(1,3)、(1,4)、(2,3)、(3,4)，对应乘积为 2、4、6、8、10、12、20。

例如 (0,2) 的乘积为 3，(2,4) 的乘积为 15，均不计入。

Example 02

没有可行组合

输入：nums = [1,2,3,4], k = 5
输出：0

任意两个不同位置的元素相乘，都无法被 5 整除。

04 / Solution

把数值压缩为它与 k 的最大公约数

核心洞察

令 g = gcd(x, k)，还缺的因子是 need = k / g。于是 k | x·y 等价于 need | y。因为 need 本身是 k 的因子，它也等价于 need | gcd(y, k)。

因此只需按 gcd(数值, k) 分组统计之前的元素。当前元素遇到一个分组 d，如果 d % need === 0，该组里的每个元素都能与当前元素配对。

不是只找一个互补桶。例如 k = 12、x = 4，则 need = 3；历史 GCD 为 3、6、12 的桶都符合条件。

完整过程

  1. 初始化空频次表 freq 与答案 answer = 0。
  2. 按下标从左到右处理 x，计算 g = gcd(x,k)，need = k/g。
  3. 枚举已有的每个桶 d，若 d % need = 0，则把 freq[d] 加到答案。
  4. 查询全部结束后，再执行 freq[g] += 1。
  5. 处理完所有元素，返回 answer。

以 nums = [2,3,4,6,12], k = 12 为例，每个元素贡献的新增配对数依次是 0、0、1、2、4，因此总数为 7。处理 4 时配到 3；处理 6 时配到 2 和 4；处理 12 时配到全部四个历史元素。

正确性证明

等价变换：写成 x = g·a、k = g·b，则 gcd(a,b) = 1。k 整除 x·y 当且仅当 b 整除 a·y，由互素性可知这又等价于 b 整除 y。b = need 且 b 整除 k，所以 b 整除 y 当且仅当 b 整除 gcd(y,k)。桶判断恰好等同于题目条件。

循环不变式：处理下标 j 之前，freq 精确记录所有 i < j 的 GCD 分组数量，answer 精确记录右端点小于 j 的有效下标对。查询时只累加满足条件的历史桶，正好加入所有以 j 为右端点的有效下标对。随后插入当前元素，不变式继续成立。

无遗漏、无重复：每一对 (i,j) 仅在处理其较大的下标 j 时计数；当前元素先查询后入桶，永远不会与自身配对。遍历结束时，所有可能的右端点都已处理，故返回值正确。

边界与数值安全

  • n = 1 时，历史桶为空，答案为 0。
  • k = 1 时，全部 GCD 为 1，任意一对均有效，答案为 n(n−1)/2。
  • 重复元素按出现次数累加，不能用集合去重。
  • 所有元素与 k 互素且 k > 1 时，桶只有 1，没有有效配对。
  • 答案最大为 4,999,950,000。Java 使用 long，C++ 使用 long long；Python 整数自然支持，JavaScript Number 在本题范围内可精确表示。
  • 实现使用 d % (k/g) 避免计算乘积；如果改写为 g*d % k，Java/C++ 必须先扩展到 64 位，乘积可能达到 10¹⁰。

复杂度

设 D = τ(k)，即 k 的正因子数。每个 GCD 都是 k 的因子，因此历史桶至多 D 个。欧几里得算法每次 O(log k)，枚举桶至多 O(D)，总时间为 O(n(log k + D))，额外空间为 O(D)（采用哈希表通常的均摊分析）。演示为了回退保存小输入的历史状态，与提交算法的空间复杂度分开计算。

替代方案

  • 暴力枚举下标：O(n²) 时间、O(1) 空间，适合小输入理解条件，无法覆盖十万规模。
  • 离线 GCD 频次：先统计所有桶，再枚举无序桶对。不同桶贡献 freq[a]·freq[b]，相同桶贡献 freq[a]·(freq[a]−1)/2；时间 O(n log k + D²)，空间 O(D)，但需特别处理同桶与重复计数。
  • 预计算兼容桶：枚举 k 的所有因子并建立配对列表，之后按兼容列表累加；适合固定 k 的重复查询，需要额外存储和预处理。

常见错误

  • 把“乘积整除 k”误写成“和整除 k”，不能套用余数和配对公式。
  • 认为至少一个数必须能被 k 整除；例如 3×4 可被 12 整除，两者都不必单独满足。
  • 只检查 d = need，漏掉 need 的倍数桶。
  • 先插入再查询，导致统计 (j,j)。
  • 把 GCD 相同的元素当成一个元素，丢失频次。
  • 在枚举 Map 的同时更新它；应先完成查询，再插入当前 GCD。

面试追问

如果允许负数和零？对负数先取绝对值，k 仍要求为正；gcd(0,k)=k，零会与所有历史元素配对。还要注意固定宽度整数最小值取绝对值的溢出。

滑动窗口怎样删除元素？先减少待删除元素自己的桶频次，再用它的 need 统计它与剩余窗口的合法配对数，并从总数中扣除；避免把自身算作待删除配对。

如果 k 非常大？重新评估 GCD 桶数量、取模数值类型与因子预处理成本；当桶数接近 n 时，此方法可能退化为平方级。

四语言完整代码

使用官方 countPairs 签名；C++ 使用 C++17 的 std::gcd。以下代码尚未编译或运行。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    private int gcd(int a, int b) {
        while (b != 0) {
            int t = a % b;
            a = b;
            b = t;
        }
        return a;
    }

    public long countPairs(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        long answer = 0;
        for (int x : nums) {
            int g = gcd(x, k);
            int need = k / g;
            for (Map.Entry<Integer, Integer> e : freq.entrySet()) {
                if (e.getKey() % need == 0) {
                    answer += e.getValue();
                }
            }
            freq.put(g, freq.getOrDefault(g, 0) + 1);
        }
        return answer;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var countPairs = function(nums, k) {
    const gcd = (a, b) => {
        while (b !== 0) [a, b] = [b, a % b];
        return a;
    };
    const freq = new Map();
    let answer = 0;
    for (const x of nums) {
        const g = gcd(x, k);
        const need = k / g;
        for (const [d, count] of freq) {
            if (d % need === 0) answer += count;
        }
        freq.set(g, (freq.get(g) || 0) + 1);
    }
    return answer;
};

Python 3

from typing import List
from math import gcd

class Solution:
    def countPairs(self, nums: List[int], k: int) -> int:
        freq = {}
        answer = 0
        for x in nums:
            g = gcd(x, k)
            need = k // g
            for d, count in freq.items():
                if d % need == 0:
                    answer += count
            freq[g] = freq.get(g, 0) + 1
        return answer

C++17

#include <vector>
#include <unordered_map>
#include <numeric>
using namespace std;

class Solution {
public:
    long long countPairs(vector<int>& nums, int k) {
        unordered_map<int, int> freq;
        long long answer = 0;
        for (int x : nums) {
            int g = gcd(x, k);
            int need = k / g;
            for (const auto& [d, count] : freq) {
                if (d % need == 0) answer += count;
            }
            ++freq[g];
        }
        return answer;
    }
};
