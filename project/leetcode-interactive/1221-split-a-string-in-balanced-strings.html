分割平衡字符串

沿字符串从左向右走。每当 L 与 R 再次势均力敌，就落下一刀。

先读题、再操作可视化。完整解法被刻意放在页面底部并默认收起。

Problem

题目说明

非付费题

平衡字符串含有相同数量的 'L' 和 'R'。给定一个本身已经平衡的字符串 s，请把它切分为若干个连续子字符串，使每一段也都平衡，并返回能够得到的最大段数。

连续每段必须是原串中的连续区间
L = R每个子串中两种字符数量相等
最多目标不是任意切法，而是最大分段数
示例 01
输入：s = "RLRRLLRLRL"
输出：4
解释：可分为 "RL"、"RRLL"、"RL"、"RL"。
示例 02
输入：s = "RLRRRLLRLL"
输出：2
解释：可分为 "RL"、"RRRLLRLL"；不能把不平衡片段也算进去。
示例 03
输入：s = "LLLLRRRR"
输出：1
解释：只能保留完整字符串 "LLLLRRRR"。

约束

2 <= s.length <= 1000
s[i] 只能是 'L' 或 'R'
s 保证是平衡字符串

Solution

Greedy Solution

遇零即切

核心洞察

把 L 记为 +1、R 记为 -1。从左向右累计，和为 0 就说明当前片段中 L 与 R 一样多。为了让段数最大，应在每个最早出现的平衡位置立即切分。

完整过程

  1. 初始化 balance = 0、answer = 0。
  2. 依次扫描字符；遇到 L 给 balance 加 1，遇到 R 减 1。
  3. 每当 balance == 0，当前未切片段已经平衡，把答案加 1。
  4. 继续扫描剩余后缀；题目保证原串平衡，因此最终一定回到 0。

为什么正确

贪心选择：设从当前片段起点出发，最早回到 0 的位置是 p。区间到 p 已经构成一个非空平衡串，立即切分可确定获得 1 段。

不损失最优性：任何跨过 p 才切的方案，都会把这段平衡前缀和后面的字符合并。把它改为在 p 切开，后缀的 L/R 总差不变，因此后续仍可按原有边界切分，段数不会减少。

归纳：对切口后的后缀重复上述选择，所有最早平衡前缀都被保留，最终得到最大段数。

边界情况

  • 最短输入如 "LR"：扫描结尾首次回到 0，答案为 1。
  • 字符成块出现如 "LLLLRRRR"：只有末尾回到 0，答案为 1。
  • 频繁交替如 "LRLRLR"：每两个字符回到 0，可得到 3 段。
  • 中间的 balance 可以为正或负；只需关心是否为 0。

替代方案

也可以分别累计 leftCount 和 rightCount，两者相等时答案加一。它与单变量方法语义相同，但需要两个计数器。枚举所有切法或动态规划会引入不必要的指数级或高阶状态。

面试追问

  • 如果输入不保证整体平衡？ 可以照样统计已经完成的平衡前缀，但剩余尾部不能计入答案；需根据新题意决定是否报错。
  • 如果要返回具体片段？ 记录上一个切口位置，每次 balance == 0 时截取对应区间。
  • 为什么不能只比较全局数量？ 全局相等只能保证整体平衡，无法求出最多连续分段。

常见错误

  • 只在字符串末尾判断一次平衡，遗漏中途可切的平衡前缀。
  • 把 balance 的正负误当成是否合法；本题允许任一方向暂时更多。
  • 找到平衡点后手动清零计数却错误跳过当前或下一个字符。
  • 把子序列当成子字符串；切出的片段必须连续且覆盖原串。

复杂度

O(n)时间
O(1)额外空间

一句话模板

维护一维差值；每次差值归零，就完成一个最短平衡前缀。

不变量

  • balance 等于当前扫描前缀内 L 数量减 R 数量。
  • 每次计数时，自上个切口以来的片段恰好平衡。

Implementation

四语言完整代码

class Solution {
    public int balancedStringSplit(String s) {
        int balance = 0;
        int answer = 0;

        for (int i = 0; i < s.length(); i++) {
            balance += s.charAt(i) == 'L' ? 1 : -1;
            if (balance == 0) {
                answer++;
            }
        }
        return answer;
    }
}

 * @param {string} s

var balancedStringSplit = function(s) {
    let balance = 0;
    let answer = 0;

    for (const char of s) {
        balance += char === 'L' ? 1 : -1;
        if (balance === 0) {
            answer++;
        }
    }
    return answer;
};
