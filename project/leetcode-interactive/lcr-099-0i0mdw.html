最小路径和

只能向右或向下，在网格中走到右下角的最低累计代价。

开始演示

题意

给定非负整数网格 grid，从左上角出发，每次仅能向右或向下，返回到右下角路径上数字和的最小值。

示例

grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
路径：1 → 3 → 1 → 1 → 1

约束

  • 1 <= m, n <= 200
  • 0 <= grid[i][j] <= 100
  • 只能向右或向下移动。

核心洞察

到达格子 (i,j) 的最后一步只能来自上方或左方。因此当前最优值等于当前格子加上这两个前置最优值的较小者。

转移：dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])

分步交互

逐格填充 3×3 网格的最小累计代价。

快捷键：Enter

完整过程

  1. 起点的代价就是 grid[0][0]。
  2. 第一行只能从左侧到达，第一列只能从上方到达。
  3. 其余格子取上方和左方最小累计代价，再加本格数值。
  4. 右下角即为答案；可直接原地覆写 grid 节省空间。

边界

  • 单行、单列只存在唯一路径。
  • 不要把不可达方向当成 0，应使用边界初始化或无穷大。
  • 输入全为 0 时答案为 0。

复杂度

时间 O(mn)。

原地 DP 额外空间 O(1)；滚动数组为 O(n)。

替代方案

使用独立二维 dp 表更易于保留原网格；一维滚动数组在不修改输入时也能将空间降到 O(n)。

官方签名代码

class Solution {
    public int minPathSum(int[][] grid) {
        for (int i = 0; i < grid.length; i++) for (int j = 0; j < grid[0].length; j++) {
            if (i == 0 && j == 0) continue;
            int up = i > 0 ? grid[i - 1][j] : Integer.MAX_VALUE;
            int left = j > 0 ? grid[i][j - 1] : Integer.MAX_VALUE;
            grid[i][j] += Math.min(up, left);
        } return grid[grid.length - 1][grid[0].length - 1];
    }
}
var minPathSum = function(grid) {
  for (let i = 0; i < grid.length; i++) for (let j = 0; j < grid[0].length; j++) {
    if (i === 0 && j === 0) continue;
    grid[i][j] += Math.min(i ? grid[i - 1][j] : Infinity, j ? grid[i][j - 1] : Infinity);
  } return grid.at(-1).at(-1);
};
class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        for i in range(len(grid)):
            for j in range(len(grid[0])):
                if i == j == 0: continue
                grid[i][j] += min(grid[i - 1][j] if i else float('inf'), grid[i][j - 1] if j else float('inf'))
        return grid[-1][-1]
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        for (int i=0;i<grid.size();++i) for (int j=0;j<grid[0].size();++j) {
            if (!i && !j) continue;
            grid[i][j] += min(i ? grid[i-1][j] : INT_MAX, j ? grid[i][j-1] : INT_MAX);
        } return grid.back().back();
    }
};

追问与常见错误

追问

若允许四方向移动？普通 DP 不再适用，因为可能形成环；需要 Dijkstra 等最短路算法。

常见错误

  • 遗漏首行首列初始化。
  • 原地修改却又试图使用原始格子值。
  • 把最大值与格子相加造成溢出。

测试与验证区

建议覆盖单格、单行、单列、全零、以及多条候选路径。
