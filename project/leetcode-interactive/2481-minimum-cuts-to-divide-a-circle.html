Minimum Cuts to Divide a Circle

一张圆形纸片，两种合法刀法。怎样用最少的切割，得到指定的等份？

01 / 题目与规则

输入整数 n，把一个圆分成 n 个大小、形状相同的等份，返回所需的最少切割次数。每次切割只能使用以下一种线段：

直径切割

两个端点都在圆周上，并且经过圆心。

半径切割

一个端点在圆心，另一个端点在圆周上。

不经过圆心的弦不是合法切割。切割在原圆上完成，不移动或叠放圆片。

参数：n: integer　返回：integer　约束：1 ≤ n ≤ 100

官方示例 1

输入：n = 4
输出：2

两条互相垂直的直径，把圆分成四个相同的扇形。

官方示例 2

输入：n = 3
输出：3

三条等角间隔的半径可以得到三等份。少于三次不能实现；第一条半径只形成一道切痕，尚未分开圆片。

04 / 推导与题解

准备好后，展开查看完整证明与四种语言实现。

核心洞察：能否把边界成对切开？

当 n > 1 时，等分扇形需要 n 条径向边界，相邻边界夹角为 360° / n。一刀半径覆盖一条边界，一刀直径同时覆盖两条方向相反的边界。

  • n = 1：完整的圆已经是一份，不用切，答案为 0。
  • n 是偶数：每条边界都有相对边界。把两条配成一条直径，共切 n / 2 次。
  • n 是大于 1 的奇数：等分边界中没有方向相反的一对。只能逐条切半径，共 n 次。

完整过程

  1. 先判断是否为 1，直接返回 0。
  2. 否则判断 n % 2 == 0，成立时返回 n / 2。
  3. 其余情况返回 n。

例如 n = 6，边界角度可以是 0°、60°、120°、180°、240°、300°。配成 (0°,180°)、(60°,240°)、(120°,300°)，三次直径切割即可。n = 5 的边界间隔是 72°，180° 不是该间隔的整数倍，无法配对。

正确性证明

边界必要性：所有合法切痕都从圆心出发，因此最终各块是扇形。对 n > 1，要得到相同扇形，必须具有恰好 n 条不同的、等角间隔的径向边界。

偶数：每次最多增加两条所需边界，所以至少需要 n / 2 刀。两条相反边界正好相隔 n / 2 个扇形，逐对作直径达到该下界，因而最优。

奇数：如果相反边界都属于等分边界，必有整数 k 满足 k × 360° / n = 180°，即 k = n / 2，与 n 为奇数矛盾。直径会引入一条不属于目标的额外边界，切痕又无法消除，因此不能使用。每刀半径仅覆盖一条所需边界，至少 n 刀，逐条切割恰好达到。

特例：n = 1 的下界为 0，保持原圆即可达到。三类覆盖全部合法输入。

边界与复杂度

必须先处理 n = 1；n = 2 只需一条直径；n = 100 返回 50。算法仅执行常数次判断与算术运算，时间 O(1)，额外空间 O(1)。页面逐刀绘图最多使用 O(n) 条线段，不是提交算法的复杂度。

可提交代码

class Solution {
    public int numberOfCuts(int n) {
        if (n == 1) return 0;
        return n % 2 == 0 ? n / 2 : n;
    }
}

替代方案

可以枚举 n 条目标边界，寻找相反方向的配对，计算直径与单独半径的数量。这需要 O(n) 时间，且用浮点角度比较会带来不必要的误差。用整数下标描述配对后，就能直接化简为上述奇偶判断。

常见错误

  • 一律返回 ceil(n / 2)：奇数时没有相反边界可配对。
  • 把 n = 1 当作普通奇数：完整圆无需任何切割。
  • 认为每切一刀块数都增加 1：第一条半径不会断开圆，直径也可能一次补齐两条边界。
  • 套用任意直线切圆的最大块数公式：本题限制经过圆心，而且要求等分。

面试追问

  • 若只能切半径？n = 1 为 0，其他情况都需要 n 刀。
  • 若只能切直径？偶数 n 需要 n / 2 刀；n = 1 不切；大于 1 的奇数无法实现。
  • 为何不需要浮点计算？相反边界是否存在等价于 n / 2 是否为整数，只判断奇偶即可。
