单词规律 II Word Pattern II

一个字符可以代表一段字符串，但两边都不能“撞车”。在有限长度里，寻找一个覆盖完整输入的双射。

#291 MEDIUM 付费题 哈希表 字符串 回溯

01 / Problem

题目转述

给定字符串 pattern 和字符串 s，判断 s 是否完全遵循该模式。

“遵循”表示模式中的每个字符都能映射到一个非空字符串，替换所有模式字符后恰好得到 s。映射必须是双射：同一模式字符始终对应同一字符串，不同模式字符也不能对应同一字符串。

必须同时用完 pattern 和 s；前缀匹配不算成功。

函数签名

wordPatternMatch(pattern: string, s: string): boolean

约束

  • 1 <= pattern.length, s.length <= 20
  • pattern 与 s 仅包含小写英文字母。
  • 每个模式字符对应的字符串必须非空。
  • 匹配关系必须一一对应。
EXAMPLE 01
输入：pattern = "abab", s = "redblueredblue"
输出：true
解释：可取 a → "red"，b → "blue"。
EXAMPLE 02
输入：pattern = "aaaa", s = "asdasdasdasd"
输出：true
解释：可取 a → "asd"。
EXAMPLE 03
输入：pattern = "aabb", s = "xyzabcxzyabc"
输出：false
解释：不存在覆盖整个 s 的合法双射。

04 / Solution

准备好再揭晓

完整思路、证明、复杂度与四语言实现默认收起。

核心洞察

模式字符只有在第一次出现时才需要切分选择；之后出现时，其对应片段已经确定，只需从当前位置核对。一个映射表维护正向关系，一个集合阻止两个字符复用同一片段。

搜索状态

状态由模式下标 pi、字符串下标 si、当前映射与已占用片段构成。只有两个下标同时到达末尾才成功。

完整过程

  1. 若 pi == pattern.length，返回 si == s.length；模式未结束但字符串结束则失败。
  2. 若当前模式字符已有映射，检查 s 从 si 起是否以该片段开头。匹配则推进两个下标，否则剪枝。
  3. 若尚未映射，从 si 开始枚举所有非空前缀。已被其他字符占用的片段直接跳过。
  4. 临时加入映射和占用集合，递归处理剩余部分；若递归失败，删除这两项后尝试更长候选。

正确性说明

对任意搜索状态，算法对未映射字符枚举字符串当前位置开始的每一个非空候选，因此不会漏掉任何可能切分；对已映射字符只接受与既有映射相同的片段，保证一致性；占用集合保证不同模式字符不会映射到同一字符串。

当且仅当两个下标同时到达末尾时返回成功，所以得到的映射既覆盖完整模式，也恰好覆盖完整字符串。由枚举完备性与约束保持性，算法返回 true 当且仅当存在合法双射。

复杂度

设 m = pattern.length， n = s.length。最坏情况下需要枚举大量切分，时间为指数级，可宽松记为 O(n^m · n)，末尾的 n 来自子串构造或比较。

递归深度至多 m，映射中保存的不同片段总长度至多 n，辅助空间为 O(m + n)（不计临时候选子串的实现差异）。

边界情况

  • 单个模式字符可以映射到整个 s。
  • 同一模式字符反复出现时，每次必须消费完全相同的片段。
  • 不同字符不能共享候选，即使拼接结果暂时看似可行。
  • 模式和字符串必须同时结束；任一方有剩余都失败。
  • 候选始终非空，所以枚举终点从 si + 1 开始。

常见错误

  • 只维护字符到字符串的映射，忘记阻止两个字符映射到同一字符串。
  • 递归失败后未同时撤销映射与占用集合，污染后续分支。
  • 模式结束就直接返回真，没有检查字符串是否也恰好用完。
  • 用全局字符串替换模拟匹配，容易错误处理边界和重复关系。

替代方案与取舍

方案特点取舍
回溯 + 映射 + 占用集合 直接对应题意，状态清晰 指数级，但长度上限很小，是首选
先枚举全部切分再校验 实现概念简单 无法尽早利用重复字符剪枝，通常更慢
滚动哈希辅助比较 可降低长片段重复比较成本 实现复杂，需处理哈希碰撞；本题长度下收益有限
状态记忆化 理论上可复用某些失败状态 映射本身属于状态，编码成本和状态数量都很高

面试追问

如何安全剪枝？

根据剩余已映射字符所需的固定长度，加上每个未映射字符至少需要 1 个字符，计算剩余字符串的长度下界。

为什么需要 used 集合？

映射表只保证“一个字符对应一个片段”，集合补上“一个片段只属于一个字符”，两者共同构成双射。

若允许空串会怎样？

搜索会增加空候选并更容易产生歧义；仍需保证递归每一步推进模式下标，避免无限循环。

Java

Solution.javaHashMap + HashSet
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution {
    private final Map<Character, String> mapping = new HashMap<>();
    private final Set<String> used = new HashSet<>();

    public boolean wordPatternMatch(String pattern, String s) {
        mapping.clear();
        used.clear();
        return dfs(pattern, 0, s, 0);
    }

    private boolean dfs(String pattern, int pi, String s, int si) {
        if (pi == pattern.length()) {
            return si == s.length();
        }
        if (si == s.length()) {
            return false;
        }

        char symbol = pattern.charAt(pi);
        if (mapping.containsKey(symbol)) {
            String word = mapping.get(symbol);
            if (!s.startsWith(word, si)) {
                return false;
            }
            return dfs(pattern, pi + 1, s, si + word.length());
        }

        for (int end = si + 1; end <= s.length(); end++) {
            String candidate = s.substring(si, end);
            if (used.contains(candidate)) {
                continue;
            }

            mapping.put(symbol, candidate);
            used.add(candidate);

            if (dfs(pattern, pi + 1, s, end)) {
                return true;
            }

            mapping.remove(symbol);
            used.remove(candidate);
        }
        return false;
    }
}

JavaScript

solution.jsMap + Set
/**
 * @param {string} pattern
 * @param {string} s
 * @return {boolean}
 */
var wordPatternMatch = function (pattern, s) {
  const mapping = new Map();
  const used = new Set();

  function dfs(pi, si) {
    if (pi === pattern.length) {
      return si === s.length;
    }
    if (si === s.length) {
      return false;
    }

    const symbol = pattern[pi];
    if (mapping.has(symbol)) {
      const word = mapping.get(symbol);
      if (!s.startsWith(word, si)) {
        return false;
      }
      return dfs(pi + 1, si + word.length);
    }

    for (let end = si + 1; end <= s.length; end += 1) {
      const candidate = s.slice(si, end);
      if (used.has(candidate)) {
        continue;
      }

      mapping.set(symbol, candidate);
      used.add(candidate);

      if (dfs(pi + 1, end)) {
        return true;
      }

      mapping.delete(symbol);
      used.delete(candidate);
    }
    return false;
  }

  return dfs(0, 0);
};

Python

solution.pydict + set
class Solution:
    def wordPatternMatch(self, pattern: str, s: str) -> bool:
        mapping: dict[str, str] = {}
        used: set[str] = set()

        def dfs(pi: int, si: int) -> bool:
            if pi == len(pattern):
                return si == len(s)
            if si == len(s):
                return False

            symbol = pattern[pi]
            if symbol in mapping:
                word = mapping[symbol]
                if not s.startswith(word, si):
                    return False
                return dfs(pi + 1, si + len(word))

            for end in range(si + 1, len(s) + 1):
                candidate = s[si:end]
                if candidate in used:
                    continue

                mapping[symbol] = candidate
                used.add(candidate)

                if dfs(pi + 1, end):
                    return True

                del mapping[symbol]
                used.remove(candidate)

            return False

        return dfs(0, 0)

C++

solution.cppunordered_map + unordered_set
#include <string>
#include <unordered_map>
#include <unordered_set>
using namespace std;

class Solution {
private:
    unordered_map<char, string> mapping;
    unordered_set<string> used;

    bool dfs(const string& pattern, int pi, const string& s, int si) {
        if (pi == static_cast<int>(pattern.size())) {
            return si == static_cast<int>(s.size());
        }
        if (si == static_cast<int>(s.size())) {
            return false;
        }

        char symbol = pattern[pi];
        auto it = mapping.find(symbol);
        if (it != mapping.end()) {
            const string& word = it->second;
            if (s.compare(si, word.size(), word) != 0) {
                return false;
            }
            return dfs(pattern, pi + 1, s, si + static_cast<int>(word.size()));
        }

        for (int end = si + 1; end <= static_cast<int>(s.size()); ++end) {
            string candidate = s.substr(si, end - si);
            if (used.count(candidate)) {
                continue;
            }

            mapping[symbol] = candidate;
            used.insert(candidate);

            if (dfs(pattern, pi + 1, s, end)) {
                return true;
            }

            mapping.erase(symbol);
            used.erase(candidate);
        }
        return false;
    }

public:
    bool wordPatternMatch(string pattern, string s) {
        mapping.clear();
        used.clear();
        return dfs(pattern, 0, s, 0);
    }
};
