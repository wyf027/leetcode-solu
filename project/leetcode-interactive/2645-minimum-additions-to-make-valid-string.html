构造有效字符串的最少插入数

Minimum Additions to Make Valid String

给定只含 a、b、c 的字符串 word。你可以在任意位置插入这些字母任意次，求把它变成有效字符串所需的最少插入次数。

什么是“有效”？

有效字符串由若干个完整的 abc 首尾相接组成，例如 abc、abcabc。

  • 1原字符串中的字符顺序不能改变。
  • 2只能插入，不能删除或替换字符。
  • 3目标是让新增字符尽可能少。

Solution

顺着 abc 的时钟走

把目标串看成无限循环的 abcabcabc…。维护指针 j 表示下一个期待的字符；读到 word 的字符前，若它与期待值不同，就插入期待值并让指针前进一步。匹配后消费原字符。扫描完毕，再补齐最后一个未完成的 abc。

核心洞察：每一步都只能沿 a → b → c → a 前进。遇到不匹配时，被跳过的字符在任何有效答案里都必须出现，所以立即补上不会浪费插入次数。

完整过程

  1. 令 pattern = "abc"、j = 0、答案 ans = 0。
  2. 依次读取 word 中的字符 ch。
  3. 当 ch != pattern[j]，插入 pattern[j]，令 ans++，并循环推进 j。
  4. 两者相同时保留原字符，并推进 j。
  5. 扫描结束后继续插入，直到 j 回到 0，说明最后一组完整。

边界情况

  • 单个 a、b 或 c 都需要补两个字符。
  • 已经由若干个 abc 组成时，答案为 0。
  • 连续相同字符一定跨越不同分组，例如每个 a 都要开启新一组。
  • 末尾停在 a 或 b 时，别忘了补齐当前组。

正确性证明

循环不变式：处理每个原字符之前，已经构造的串是某个有效串的前缀，pattern[j] 正是继续该前缀时唯一允许出现的下一个字符。

若当前原字符不是 pattern[j]，由于不能删除、替换或调整原字符顺序，为使它最终出现在有效串中，所有从期待字符到它之前的字符都必须先被插入；算法恰好各插入一次，因此这一段最少。匹配后保留原字符仍维持不变式。全部原字符处理完后，算法只插入让最后一组完整所必需的后缀。每段都达到下界，故总插入次数最少。

时间 O(n)额外空间 O(1)

四语言完整代码

Java
class Solution {
    public int addMinimum(String word) {
        String pattern = "abc";
        int answer = 0;
        int j = 0;

        for (int i = 0; i < word.length(); i++) {
            while (word.charAt(i) != pattern.charAt(j)) {
                answer++;
                j = (j + 1) % 3;
            }
            j = (j + 1) % 3;
        }

        while (j != 0) {
            answer++;
            j = (j + 1) % 3;
        }
        return answer;
    }
}

替代方案

也可以统计目标中需要多少个 abc 分组：首字符开启第一组；每当相邻字符不再严格递增，即 word[i] <= word[i - 1]，就开启新组。若分组数为 groups，答案为 3 * groups - word.length。

这个写法更短，但指针法直接模拟“缺什么补什么”，更容易解释和扩展。

面试追问

  • 如果目标模式不是 abc，而是任意给定字符串，如何复用指针法？
  • 如果允许删除，怎样改成动态规划并定义状态？
  • 能否一次流式读取输入，而不保存整个 word？

常见错误

  • 只处理相邻两个字符之间的缺口，却漏掉开头需要补的 a 或末尾需要补的字符。
  • 把连续相同字符放进同一组；但一个 abc 分组里每种字符只能出现一次。
  • 指针到达 c 后没有对 3 取模，导致无法回到下一组的 a。
  • 使用栈或动态规划完成本题，虽然可行，但引入了不必要的空间或状态。
