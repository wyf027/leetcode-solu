二叉树中的第 K 大层和

Kth Largest Sum in a Binary Tree

中等 · Medium树广度优先搜索排序

题目

先读懂目标，再操作下面的逐层扫描器；题解默认收起。

给定二叉树根节点 root 和正整数 k。把与根节点距离相同的节点视作同一层，一层中全部节点值之和称为该层的层和。

返回所有层和中按从大到小排列后的第 k 个值；层和可以重复，重复值分别占据名次。如果整棵树不足 k 层，返回 -1。

约束

  • 树中节点数为 n
  • 2 ≤ n ≤ 105
  • 1 ≤ Node.val ≤ 106
  • 1 ≤ k ≤ n

准备好看完整解法了吗？

先试着说出：如何一次遍历得到每层的和，以及层数不足 k 时在哪里判断。

题解：BFS 分层 + 排序

用队列天然分层，记录每层和，再从大到小取第 k 个。

核心洞察

进入一轮 BFS 时，队列中恰好装着同一层的全部节点。先保存队列长度，再只弹出这么多个节点并累加，就不会把下一层混入当前层。所有层和收集完后降序排序，下标 k - 1 即为答案。

1 · 分层队列以根节点开始；每轮固定读取本轮开始时的队列长度。
2 · 求和弹出这一层的节点并累加，同时把非空左右孩子加入队尾。
3 · 取名次若层数少于 k 返回 -1；否则层和降序排序并取第 k 个。

正确性说明

  1. 分层正确：开始处理某层时，队列只含该层节点。处理固定数量的节点时，仅把孩子追加到队尾，因此本轮不会访问下一层，而下一轮队列恰好只含下一层节点。由归纳可知每轮对应且仅对应一层。
  2. 层和正确：本轮累加了该层每个节点一次且没有累加其他层节点，所以记录值就是该层层和。
  3. 答案正确：降序排序保留全部层和（包括重复值），排序后位置 k - 1 按定义就是第 k 大层和。若该位置不存在，树的层数不足 k，返回 -1。

复杂度与边界

时间：O(n + h log h)。每个节点访问一次，h 个层和排序。

空间：O(w + h)。w 是树的最大宽度，队列最多容纳一层附近的节点，另存 h 个层和。

  • 层数少于 k：返回 -1。
  • 层和相同：不去重，每个层和都参与排名。
  • 最宽层可能很大：层和最高可达约 1011，Java 用 long，C++ 用 long long。
  • k = 1：返回最大层和；链状树也由同一流程处理。

替代方案与面试追问

大小为 k 的最小堆：BFS 得到一个层和后放入最小堆，若堆大小超过 k 就弹出最小值；最终堆顶是第 k 大。时间为 O(n + h log k)，额外存储降为 O(w + k)。当层数很多且 k 很小时更合适；本题排序版更直接。

DFS 累加：递归到深度 d 时执行 sums[d] += node.val，之后同样排序。它省去显式队列，但高度可达 105 时递归可能栈溢出，因此迭代 BFS 更稳妥。

追问：若节点值允许负数，算法仍成立；不能把层和初值或答案默认成 0。若数据流逐层到达且只关心第 k 大，使用大小为 k 的最小堆即可不保存所有层和。

常见错误

  • 在处理一层的循环中读取不断增长的队列长度，导致多层节点被混在一起；必须先保存本层大小。
  • 对层和去重后再排名；题目明确层和不必互异。
  • 用 32 位整数保存层和，最大数据会溢出。
  • 使用会反复搬移数组的队首删除操作；JavaScript 用游标推进数组头部更稳妥。
  • 把 k 与节点数比较，却没有与实际层数比较。

四语言完整代码

均采用同一条 BFS 分层、收集层和、降序排序的主线。

Java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public long kthLargestLevelSum(TreeNode root, int k) {
        java.util.Queue<TreeNode> queue = new java.util.ArrayDeque<>();
        java.util.List<Long> sums = new java.util.ArrayList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            long sum = 0;
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                sum += node.val;
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            sums.add(sum);
        }

        if (sums.size() < k) return -1;
        sums.sort(java.util.Collections.reverseOrder());
        return sums.get(k - 1);
    }
}
JavaScript
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @param {number} k
 * @return {number}
 */
var kthLargestLevelSum = function(root, k) {
    const queue = [root];
    const sums = [];
    let head = 0;

    while (head < queue.length) {
        const end = queue.length;
        let sum = 0;
        while (head < end) {
            const node = queue[head++];
            sum += node.val;
            if (node.left) queue.push(node.left);
            if (node.right) queue.push(node.right);
        }
        sums.push(sum);
    }

    if (sums.length < k) return -1;
    sums.sort((a, b) => b - a);
    return sums[k - 1];
};
Python 3
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional

class Solution:
    def kthLargestLevelSum(
        self, root: Optional[TreeNode], k: int
    ) -> int:
        queue = deque([root])
        sums = []

        while queue:
            level_sum = 0
            for _ in range(len(queue)):
                node = queue.popleft()
                level_sum += node.val
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
            sums.append(level_sum)

        if len(sums) < k:
            return -1
        sums.sort(reverse=True)
        return sums[k - 1]
C++
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    long long kthLargestLevelSum(TreeNode* root, int k) {
        std::queue<TreeNode*> queue;
        std::vector<long long> sums;
        queue.push(root);

        while (!queue.empty()) {
            int size = queue.size();
            long long sum = 0;
            while (size--) {
                TreeNode* node = queue.front();
                queue.pop();
                sum += node->val;
                if (node->left) queue.push(node->left);
                if (node->right) queue.push(node->right);
            }
            sums.push_back(sum);
        }

        if (sums.size() < static_cast<size_t>(k)) return -1;
        std::sort(sums.begin(), sums.end(), std::greater<long long>());
        return sums[k - 1];
    }
};
