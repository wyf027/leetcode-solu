01 · 题目

给定字符串数组 nums，其中有 n 个互不相同的二进制字符串，每个字符串的长度也为 n。返回一个长度为 n、只包含 0 和 1 且未出现在 nums 中的字符串。符合要求的答案可能不唯一，返回任意一个即可。

参数与返回值

findDifferentBinaryString(nums: string[]) → string

保留前导零；返回值是字符串，不是整数。

约束

  • n == nums.length
  • 1 ≤ n ≤ 16
  • nums[i].length == n
  • 每个字符串中的字符都是 '0' 或 '1'。
  • nums 中所有字符串互不相同。

04 · 思考之后，展开题解

包含构造过程、逐步可视化、证明与代码。

对角线构造：给每一行一个不同点

令 answer[i] 与 nums[i][i] 相反。这样答案在第 i 位一定不同于第 i 行，因而不可能等于任何一行。

完整过程

  1. 准备长度为 n 的答案缓冲区。
  2. 从 i = 0 到 n − 1，只取第 i 行、第 i 列的字符。
  3. 读到 '0' 就写入 '1'；读到 '1' 就写入 '0'。
  4. 把这 n 个字符按顺序组成字符串返回，无需再搜索数组。

示例 3 的对角线为 1、1、1，构造结果是 “000”。它与官方示例的 “101” 不同，但同样符合题意。

正在构造的答案

    此处为教学演示，不能替代代码执行验证；测试与验证状态仍为待补验证。

    为什么一定正确？

    合法性：每轮产生一个二进制字符，共进行 n 轮，所以输出长度为 n，字符也符合要求。

    循环不变式：完成前 k 轮后，答案前缀在每一个 i < k 的位置都与 nums[i][i] 相反，因此无论后续位如何填写，都不可能等于前 k 行中的任何一行。

    终止结论：当 k = n 时所有行都已覆盖。假设答案等于某行 nums[j]，则第 j 位必须相等，而构造保证它们相反，矛盾。因此答案不在数组中。

    复杂度与边界

    • 时间 O(n)：只读 n 个对角线字符并生成 n 位答案，假设输入已驻留内存，字符串索引为常数时间。完整读取或校验输入另需 O(n²)。
    • 空间 O(n)：以下实现使用长度为 n 的字符缓冲区或字符串。除构造答案的存储外，循环状态只需 O(1)；Java/JavaScript/Python 的中间数组仍占 O(n)。
    • n = 1：翻转唯一的位即可。n = 16：相同处理，没有整数溢出问题。
    • 前导零无需特殊处理；始终用字符串保存结果。空数组和长度不匹配不属于官方合法输入。
    • 互不相同是题目保证；对角线证明本身并不依赖这一条件，只要求 n 行且每行长 n。

    替代方案

    哈希集合加枚举：把输入放入集合，依次尝试整数 0 到 n 的 n 位二进制表示，返回第一个未出现的值。n 个输入最多占用 n 个候选，n + 1 个候选中必有缺失；且 n ≥ 1 时 n < 2ⁿ，候选都能表示为 n 位。考虑字符串生成及哈希，常见实现时间、存储上界均为 O(n²)。

    回溯生成 0/1 字符串并查询集合也可行。完整搜索空间有 2ⁿ 个叶子，穷举上界 O(n·2ⁿ)；若找到第一个缺失项即停止，由于只有 n 个已占用字符串，最多查询 n + 1 个叶子。对本题直接构造更简洁。

    常见错误

    • 把第一行的所有位取反：只能保证不同于第一行，仍可能等于别的行。
    • 总是读取第 0 列：每行应有专属的答案位置，必须使用 nums[i][i]。
    • 对字符使用语言的真假取反：JavaScript 中 !'0' 并不会得到字符 '1'。
    • 转成数字返回或忘记补齐位数，会丢失前导零。
    • 要求输出与官方样例完全一致：本题允许任意合法结果。

    面试追问

    • 能保证字典序最小吗？不能。若要求最小，使用按数值递增的固定宽度候选枚举。
    • m 行、每行长 L 呢？当 m ≤ L 时可为每行分配一个不同位置，余下位任意填；当 m > L 时该构造不再直接适用。
    • 为什么答案一定存在？共有 2ⁿ 个长度为 n 的二进制串，且对 n ≥ 1 有 2ⁿ > n；对角线方法直接构造了其中一个缺失项。
    • 能扩展到其他字符集吗？字符集至少包含两个字符时，在每个对应位置选择一个不同字符即可。

    Java

    class Solution {
    public String findDifferentBinaryString(String[] nums) {
        int n = nums.length;
        char[] answer = new char[n];
        for (int i = 0; i < n; i++) {
            answer[i] = nums[i].charAt(i) == '0' ? '1' : '0';
        }
        return new String(answer);
    }
}

    JavaScript

    /**
 * @param {string[]} nums
 * @return {string}
 */
var findDifferentBinaryString = function(nums) {
    const answer = [];
    for (let i = 0; i < nums.length; i++) {
        answer.push(nums[i][i] === '0' ? '1' : '0');
    }
    return answer.join('');
};

    Python 3

    from typing import List

class Solution:
    def findDifferentBinaryString(self, nums: List[str]) -> str:
        answer = []
        for i, row in enumerate(nums):
            answer.append('1' if row[i] == '0' else '0')
        return ''.join(answer)
