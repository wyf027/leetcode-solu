排序数组

Sort an Array · 用堆的结构，观察无序区如何一步步收缩

数组堆排序原地O(n log n)

题目

给定整数数组 nums，请将数组按升序排列并返回。不能调用内置排序函数；目标时间复杂度为 O(n log n)，额外空间尽可能小。

函数签名

sortArray(nums: integer[]) → integer[]

约束

  • 1 ≤ nums.length ≤ 5 × 10⁴
  • -5 × 10⁴ ≤ nums[i] ≤ 5 × 10⁴

官方示例

示例 1 输入：nums = [5,2,3,1] 输出：[1,2,3,5] 解释：升序排列后，部分元素位置改变。
示例 2 输入：nums = [5,1,1,2,0,0] 输出：[0,0,1,1,2,5] 解释：数组中的值可以重复。

题解：原地堆排序

核心洞察

大顶堆能让当前最大值始终位于根节点（下标 0）。把根与无序区末尾交换，最大值便永久归位；缩小无序区并重新下沉根节点，重复即可得到升序数组。

完整过程

  1. 从最后一个非叶子节点开始向前执行下沉，在线性时间内建立大顶堆。
  2. 把堆顶与当前堆尾交换，堆尾进入有序区。
  3. 堆大小减一，对根执行下沉以恢复大顶堆。
  4. 直到堆大小为 1。

正确性

堆不变量：每次交换前，无序区是大顶堆，因此根是无序区最大值。交换后，该最大值位于无序区末端，且不小于此前已经归位的左侧边界元素，于是扩展后的尾部仍有序。下沉恢复下一轮的不变量。最终无序区只剩一个元素，整个数组升序。

边界情况

  • 空操作场景：长度为 1 时直接返回。
  • 重复值：比较使用“更大子节点”，相等元素不影响正确性。
  • 负数、已排序、逆序数组均无需特殊处理。

复杂度

建堆为 O(n)，随后最多 n-1 次下沉，每次 O(log n)；总时间 O(n log n)，额外空间 O(1)。堆排序通常不稳定。

替代方案

归并排序稳定且同为 O(n log n)，但普通数组实现需 O(n) 辅助空间；随机化快速排序平均更快，但最坏可退化为 O(n²)，递归栈也不是严格常数空间；计数排序可利用本题有限值域，但属于依赖值域的方案。

面试追问

为什么建堆是 O(n)，不是 O(n log n)？

多数节点靠近叶子，下沉高度很小；将各高度节点数量乘以高度求和，得到线性级别。

如何改成降序？

使用小顶堆并把最小值依次放到尾部，或先得到升序再反转；前者直接维持对应不变量。

能否保持稳定？

标准原地堆排序不能，因为远距离交换会改变相等元素的相对顺序。若必须稳定，通常选择归并排序。

常见错误

  • 孩子下标写错：左孩子 2*i+1，右孩子 2*i+2。
  • 下沉仍使用整个数组长度，误改已排序尾部。
  • 交换后没有从根重新下沉。
  • 递归下沉虽正确，但严格额外空间不再是 O(1)。

完整代码

class Solution {
    public int[] sortArray(int[] nums) {
        for (int i = nums.length / 2 - 1; i >= 0; i--) sift(nums, i, nums.length);
        for (int end = nums.length - 1; end > 0; end--) {
            int t = nums[0]; nums[0] = nums[end]; nums[end] = t;
            sift(nums, 0, end);
        }
        return nums;
    }
    private void sift(int[] a, int root, int size) {
        while (root * 2 + 1 < size) {
            int child = root * 2 + 1;
            if (child + 1 < size && a[child + 1] > a[child]) child++;
            if (a[root] >= a[child]) break;
            int t = a[root]; a[root] = a[child]; a[child] = t;
            root = child;
        }
    }
}

var sortArray = function(nums) {
  const sift = (root, size) => {
    while (root * 2 + 1 < size) {
      let child = root * 2 + 1;
      if (child + 1 < size && nums[child + 1] > nums[child]) child++;
      if (nums[root] >= nums[child]) break;
      [nums[root], nums[child]] = [nums[child], nums[root]];
      root = child;
    }
  };
  for (let i = Math.floor(nums.length / 2) - 1; i >= 0; i--) sift(i, nums.length);
  for (let end = nums.length - 1; end > 0; end--) {
    [nums[0], nums[end]] = [nums[end], nums[0]];
    sift(0, end);
  }
  return nums;
};

class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        int n = nums.size();
        for (int i = n / 2 - 1; i >= 0; --i) sift(nums, i, n);
        for (int end = n - 1; end > 0; --end) {
            swap(nums[0], nums[end]);
            sift(nums, 0, end);
        }
        return nums;
    }
private:
    void sift(vector<int>& a, int root, int size) {
        while (root * 2 + 1 < size) {
            int child = root * 2 + 1;
            if (child + 1 < size && a[child + 1] > a[child]) ++child;
            if (a[root] >= a[child]) break;
            swap(a[root], a[child]);
            root = child;
        }
    }
};
