移动 N 叉树的子树Move Sub-Tree of N-Ary Tree

一场关于父子关系、节点顺序与树结构完整性的精确变换。先读题、动手推演，再按需揭开题解。

困难 付费题 N 叉树 深度优先搜索

Problem

题意

给定一棵节点值互不相同的 N 叉树根节点 root，以及树中的两个不同节点 p 与 q。请移动以 p 为根的整棵子树，让 p 成为 q 的最后一个直接子节点，并返回调整后的根节点。

若 p 已经是 q 的直接子节点，整棵树保持不变。需要特别留意 q 位于 p 子树中的情况：直接连接会形成环，因此必须在保持所有节点连通的前提下重新接边；若 p 原本就是根，返回的新根也可能发生变化。

N 叉树用层序序列表示；每一组节点的子节点之间由 null 分隔。

示例 1 · p 位于 q 子树

输入：root = [1,null,2,3,null,4,5,null,6,null,7,8], p = 4, q = 1
输出：[1,null,2,3,4,null,5,null,6,null,7,8]

移动后 4 是 1 的最后一个子节点。

示例 2 · 已满足要求

输入：root = [1,null,2,3,null,4,5,null,6,null,7,8], p = 7, q = 4
输出：[1,null,2,3,null,4,5,null,6,null,7,8]

7 已是 4 的直接子节点，不做任何改动。

示例 3 · 分属不同分支

输入：root = [1,null,2,3,null,4,5,null,6,null,7,8], p = 3, q = 8
输出：[1,null,2,null,4,5,null,7,8,null,null,null,3,null,6]

将 3 的整棵子树从原位置摘下，再接到 8 的末尾。

示例 4 · q 位于 p 子树

输入：root = [1,null,2,3,null,4], p = 1, q = 4
输出：[4,null,1,null,2,3]

原根 1 移到 4 之下，4 成为新根，且不能形成环。

约束

  • 树中节点总数在 [2, 1000] 范围内。
  • 每个节点的值都唯一。
  • p != null 且 q != null。
  • p 与 q 是树中两个不同节点。

Case · q ∈ subtree(p)

红色为 p，绿色为 q；虚线表示即将切断，亮绿色表示新边。

  2. 确认 q 在 p 的子树内
  3. 先从原父节点断开 q
  4. 让 q 接替 p 的原位置
  5. 把 p 追加为 q 的最后子节点

你会怎样安排断边与接边？

先尝试写出处理三类祖先关系的步骤。准备好后，再展开完整题解与四语言实现。

Solution

题解：父节点表 + 分类接边

核心洞察：真正决定操作顺序的不是“谁更深”，而是 q 是否位于 p 的子树中。先用一次遍历记录每个节点的父节点，再沿 q 的父链向上走；若能遇到 p，说明普通的“摘下 p 再挂到 q”会造环，必须先把 q 摘出来。
1

建立 parent 映射

从 root 遍历整棵树，为每个非根节点记录父节点。之后删除或替换子节点时，无需再次搜索。

2

先处理无操作情形

若 parent[p] == q，题目要求整棵树保持原样，直接返回 root，连子节点顺序也不改变。

3

判断 q 是否在 p 下方

从 q 不断跳到父节点；若途中遇到 p，就是危险情形。父链判断只走树高，仍在总复杂度范围内。

4

按关系重新接边

危险情形先断开 q，再让 q 替换 p 的原位置（若 p 是根，则 q 成为新根），最后把 p 追加到 q.children。其他情形只需断开 p 并追加到 q。

正确性证明

  1. 父节点信息正确。遍历从根沿每条父子边访问节点，因此对每个非根节点记录的恰是其唯一父节点。
  2. 非危险情形保持为树。当 q 不在 p 子树中时，删除 parent[p] → p 后，p 子树与其余部分分离；增加 q → p 恰好将它重新连回，且不会形成环。追加操作也保证 p 是最后一个孩子。
  3. 危险情形不会成环或丢节点。先删除 parent[q] → q，就切断了从 p 到 q 的原路径。随后用 q 替换 p 的旧位置（或成为新根），再增加 q → p；此时不存在从 p 回到 q 的路径，所以无环，且两个被切开的部分重新连通。
  4. 覆盖全部情况。若 p 已是 q 的孩子则直接返回；否则，q 要么在 p 子树中，要么不在。两类分别由上述操作处理，因此算法总能得到符合要求的树。

边界情况

  • p 原本就是根。
  • q 是 p 的直接或深层后代。
  • p 已是 q 的直接子节点。
  • 二者位于互不包含的分支。
  • 保持所有未涉及孩子的相对顺序。

复杂度

时间：O(n)。建立父节点表访问每个节点一次；父链与子节点删除总计不超过线性规模。

空间：O(n)，用于父节点映射和显式遍历栈。

替代方案

可以递归 DFS，同时返回 p、q 的父节点并判断包含关系；代码可能更短，但状态耦合更强。父节点表把“查关系”和“改结构”拆开，更便于证明与面试讲解。

/*
// Definition for a Node.
class Node {
    public int val;
    public List<Node> children;
}
*/
class Solution {
    public Node moveSubTree(Node root, Node p, Node q) {
        Map<Node, Node> parent = new HashMap<>();
        Deque<Node> stack = new ArrayDeque<>();
        parent.put(root, null);
        stack.push(root);

        while (!stack.isEmpty()) {
            Node node = stack.pop();
            for (Node child : node.children) {
                parent.put(child, node);
                stack.push(child);
            }
        }

        if (parent.get(p) == q) {
            return root;
        }

        boolean qInsideP = false;
        for (Node node = q; node != null; node = parent.get(node)) {
            if (node == p) {
                qInsideP = true;
                break;
            }
        }

        Node parentP = parent.get(p);
        if (qInsideP) {
            Node parentQ = parent.get(q);
            parentQ.children.remove(q);

            if (parentP == null) {
                root = q;
            } else {
                int index = parentP.children.indexOf(p);
                parentP.children.set(index, q);
            }
            q.children.add(p);
        } else {
            parentP.children.remove(p);
            q.children.add(p);
        }

        return root;
    }
}

var moveSubTree = function(root, p, q) {
  const parent = new Map([[root, null]]);
  const stack = [root];

  while (stack.length) {
    const node = stack.pop();
    for (const child of node.children) {
      parent.set(child, node);
      stack.push(child);
    }
  }

  if (parent.get(p) === q) return root;

  let qInsideP = false;
  for (let node = q; node !== null; node = parent.get(node)) {
    if (node === p) {
      qInsideP = true;
      break;
    }
  }

  const parentP = parent.get(p);
  if (qInsideP) {
    const parentQ = parent.get(q);
    parentQ.children.splice(parentQ.children.indexOf(q), 1);

    if (parentP === null) {
      root = q;
    } else {
      parentP.children[parentP.children.indexOf(p)] = q;
    }
    q.children.push(p);
  } else {
    parentP.children.splice(parentP.children.indexOf(p), 1);
    q.children.push(p);
  }

  return root;
};

/*
// Definition for a Node.
class Node {
public:
    int val;
    vector<Node*> children;
};
*/
class Solution {
public:
    Node* moveSubTree(Node* root, Node* p, Node* q) {
        unordered_map<Node*, Node*> parent;
        vector<Node*> stack = {root};
        parent[root] = nullptr;

        while (!stack.empty()) {
            Node* node = stack.back();
            stack.pop_back();
            for (Node* child : node->children) {
                parent[child] = node;
                stack.push_back(child);
            }
        }

        if (parent[p] == q) return root;

        bool qInsideP = false;
        for (Node* node = q; node != nullptr; node = parent[node]) {
            if (node == p) {
                qInsideP = true;
                break;
            }
        }

        Node* parentP = parent[p];
        if (qInsideP) {
            Node* parentQ = parent[q];
            eraseChild(parentQ, q);

            if (parentP == nullptr) {
                root = q;
            } else {
                auto it = find(parentP->children.begin(),
                               parentP->children.end(), p);
                *it = q;
            }
            q->children.push_back(p);
        } else {
            eraseChild(parentP, p);
            q->children.push_back(p);
        }

        return root;
    }

private:
    void eraseChild(Node* parent, Node* child) {
        auto& children = parent->children;
        children.erase(find(children.begin(), children.end(), child));
    }
};

面试追问

  • 为什么必须先判断 q 是否在 p 子树中？
  • 若节点值不唯一，映射的键应该是什么？
  • 怎样在不使用额外 O(n) 映射的情况下完成？代价是什么？
  • 如果操作要执行很多次，怎样维护动态父子关系？

常见错误

  • 一律先摘 p，导致 q 随子树一起断开或接边成环。
  • 把 p 插到 q.children 开头，而不是末尾。
  • 忘记“已经是直接子节点”时必须完全不改动。
  • p 为根时仍访问空的 parent[p]。
  • 替换 p 时破坏其兄弟节点的原有相对顺序。
