环绕字符串中唯一的子字符串

字母表首尾相接，形成一条没有尽头的字符轨道。给定字符串 s，统计其中有多少个不同的非空子串能够沿这条轨道连续读出。

字符串 动态规划 时间目标 O(n) 空间目标 O(1)
Problem

题目

findSubstringInWraproundString(s)

令 base 为无限重复的环绕字符串 abcdefghijklmnopqrstuvwxyz，也就是形如 ...zabcdefghijklmnopqrstuvwxyzabcdefghijklmnopqrstuvwxyzabcd...。给定仅含小写英文字母的字符串 s，返回 s 的不同非空子串中，同时也出现在 base 里的数量。

Example 01
输入：s = "a"
输出：1

只有子串 "a" 符合。

Example 02
输入：s = "cac"
输出：2

符合的不同子串为 "a"、"c"。

Example 03
输入：s = "zab"
输出：6

符合的有 "z"、"a"、"b"、"za"、"ab"、"zab"。

约束

  • 1 <= s.length <= 105
  • s 只包含小写英文字母。

Editorial

题解：按结尾字符去重

动态规划 · 26 个状态
核心洞察：所有满足条件、且以同一个字母结尾的子串，内容完全由长度决定。如果已知以字符 c 结尾的最长合法连续段长度为 L，那么长度 1 到 L 的这 L 个后缀恰好贡献 L 个不同子串。

状态定义

best[c] 表示扫描到当前位置为止，以字母 c 结尾的合法连续子串的最大长度。最终答案是 sum(best)。

如何判断连续

若相邻字符满足 (cur - prev + 26) % 26 == 1，当前连续长度加一；否则从 1 重新开始。该式自然覆盖 z → a。

完整过程

  1. 建立长度为 26 的数组 best，初值均为 0。
  2. 从左到右扫描 s，维护以当前位置结尾的最长合法连续长度 run。
  3. 令当前字母下标为 idx，更新 best[idx] = max(best[idx], run)。
  4. 扫描结束后累加数组，得到不同合法子串总数。

为什么不会重复计数

对固定结尾字母，合法字符串由“结尾字母 + 长度”唯一确定。例如以 b 结尾且长度为 3 的字符串只能是 zab。不同结尾字母的集合互不相交；同一结尾字母只保留最大长度，就包含了其全部较短后缀。

正确性证明

  1. 扫描状态正确：每一步中，若当前字符恰为前一字符在环中的后继，则把此前最长合法后缀延长一位；否则任何跨过该边界的后缀都不合法，只能从当前单字符开始。因此 run 始终等于以当前位置结尾的最长合法后缀长度。
  2. 状态覆盖完整：当当前位置字符为 c 且 run = L 时，该后缀的最后 1 到 L 个字符都是合法子串，并且都以 c 结尾。取所有位置的最大 L，便覆盖了所有以 c 结尾的合法子串长度。
  3. 计数唯一：在无限环绕串中，结尾字符和长度唯一决定字符串内容，所以以 c 结尾的合法子串恰有 best[c] 个。各结尾字符不同，不会互相重复。故总和正好等于所有不同合法子串数量。

复杂度

  • 时间复杂度：O(n)，每个字符只处理一次。
  • 空间复杂度：O(1)，状态数组固定为 26 项。
  • 答案上界不超过 26 × n；在题目约束下 32 位整数足够。

边界情况

  • 单字符：只贡献它本身。
  • 重复同一字符：每次连续长度都会回到 1，最终只计一次。
  • z → a：必须视为合法相邻。
  • 连续段中同一结尾再次出现：只取更大的最大值，避免重复累计。

替代方案

  • 枚举所有子串并用集合去重：直观但需要 O(n²) 个候选，长度达 105 时不可行。
  • 后缀自动机或后缀数组：能处理更一般的不同子串问题，但这里的周期结构让 26 个状态足够，复杂度与实现成本都更低。

常见错误

  • 每次直接把 run 加到答案，导致相同后缀重复计数。
  • 只判断 cur == prev + 1，漏掉 z → a。
  • 记录全局最长值，而不是按结尾字符分别记录。
  • 把“子序列”误当成“子串”；这里字符必须连续。

面试追问

为什么最大长度就足以代表整个集合？

因为对固定结尾字母，较短合法串必然是最长串的后缀，长度区间连续为 1…L。

若基串不是 26 个互异字符的单周期呢？

“结尾字符 + 长度唯一确定内容”可能不再成立，需要把周期位置或更一般的自动机状态纳入去重键。

如何在线处理字符流？

保留前一字符、当前 run、26 项 best 与其和；每到一个字符即可 O(1) 更新当前答案。

能否不用最后再求和？

可以。若新 run 超过 best[idx]，只把差值加入 total，再更新 best[idx]。

JavaO(n) / O(1)
class Solution {
    public int findSubstringInWraproundString(String s) {
        int[] best = new int[26];
        int run = 0;

        for (int i = 0; i < s.length(); i++) {
            if (i > 0 &&
                (s.charAt(i) - s.charAt(i - 1) + 26) % 26 == 1) {
                run++;
            } else {
                run = 1;
            }

            int index = s.charAt(i) - 'a';
            best[index] = Math.max(best[index], run);
        }

        int answer = 0;
        for (int length : best) {
            answer += length;
        }
        return answer;
    }
}
JavaScriptO(n) / O(1)
/**
 * @param {string} s
 * @return {number}
 */
var findSubstringInWraproundString = function(s) {
    const best = new Array(26).fill(0);
    let run = 0;

    for (let i = 0; i < s.length; i++) {
        const current = s.charCodeAt(i) - 97;

        if (i > 0) {
            const previous = s.charCodeAt(i - 1) - 97;
            run = (current - previous + 26) % 26 === 1
                ? run + 1
                : 1;
        } else {
            run = 1;
        }

        best[current] = Math.max(best[current], run);
    }

    return best.reduce((sum, length) => sum + length, 0);
};
Python 3O(n) / O(1)
class Solution:
    def findSubstringInWraproundString(self, s: str) -> int:
        best = [0] * 26
        run = 0

        for i, char in enumerate(s):
            current = ord(char) - ord("a")

            if i > 0:
                previous = ord(s[i - 1]) - ord("a")
                run = run + 1 if (current - previous) % 26 == 1 else 1
            else:
                run = 1

            best[current] = max(best[current], run)

        return sum(best)

class Solution {

        vector<int> best(26, 0);
        int run = 0;

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {

                ++run;

                run = 1;
            }

            int index = s[i] - 'a';

        }
