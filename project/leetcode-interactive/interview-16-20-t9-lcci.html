01 / Call brief

题意：找出与数字序列完全匹配的单词

老式手机把字母分配到 2–9 数字键。给定数字串 num 和有效单词列表 words，返回所有逐位映射后恰好等于 num 的单词，结果保持原列表顺序。

官方样例 1

输入 num = "8733", words = ["tree", "used"]
输出 ["tree", "used"]

tree → 8733，used → 8733，两条线路都完整匹配。

官方样例 2

输入 num = "2", words = ["a", "b", "c", "d"]
输出 ["a", "b", "c"]

a、b、c 属于 2 键；d 属于 3 键，因此被过滤。

约束： num.length <= 1000，words.length <= 500， words[i].length == num.length；num 中不会出现 0 或 1。

04 / Sealed answer

题解默认隐藏

展开后查看核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码。

核心洞察：把字母映射成它所属的数字键

26 个小写字母的数字映射可以压成一个固定字符串。索引 0 对应 a，索引 25 对应 z；这样每个字符只需一次数组访问，不必每次搜索 “abc” 等分组。

map = "22233344455566677778889999"

若 map[word[i] - 'a'] != num[i]，当前单词立即失败；所有位置都通过才加入答案。

完整过程

  1. 准备长度为 26 的字母到数字映射串。
  2. 按原顺序枚举每个候选单词。
  3. 逐位比较当前字母映射出的数字与 num[i]。
  4. 遇到第一处不同就提前结束当前单词。
  5. 若没有任何不同，把单词加入结果。

边界处理

  • words 为空时直接返回空列表。
  • 同一数字可对应多个字母，因此多个单词都可能通过。
  • 7 对应 pqrs、9 对应 wxyz，二者都有四个字母。
  • 题目保证单词长度等于数字串长度，且数字串不含 0、1。
  • 保持候选列表的原始顺序，不对答案排序。

复杂度

设单词数为 W、每个单词长度为 L。

  • 时间：O(W × L)，最坏检查每个字符。
  • 额外空间：O(1)（不计返回列表）；映射串长度恒为 26。
  • 提前失败能减少平均检查次数，但不改变最坏复杂度。

替代方案取舍

  • 为每个单词生成完整数字串：更直观，但会产生 O(L) 临时字符串。
  • 数字到字母集合并 contains：可读，但每位还要在 3–4 个字母里查找。
  • Trie：单次查询明显过重；只有需要大量前缀查询时才值得维护。
  • 按签名建哈希表：适合固定词典、多次 num 查询。

面试追问

如果同一词典要处理很多个 num 呢？

预处理每个单词的 T9 签名，以签名为键、单词列表为值建立哈希表。预处理 O(总字符数)，之后每次查询只需 O(L + k)，k 为返回单词数。

如果允许前缀联想？

可把词典建成 Trie，按数字对应的 3–4 个字母扩展节点，并限制返回数量。

常见错误

  • 把 7 写成 pqr 或把 9 写成 wxy，漏掉 s / z。
  • 映射方向写反：需要字母 → 数字，才能 O(1) 校验。
  • 某一位通过就加入答案；正确条件是所有位置都通过。
  • 遇到失败后仍继续扫描，错失提前结束。
  • 把答案排序，破坏题目示例体现的原列表顺序。

一眼复述

“我用一个 26 位字符串保存字母到数字键的映射。对每个单词逐字符把字母转换为数字，与 num 同位置比较；有一位不同就淘汰，全相同则保留。时间 O(WL)，除答案外 O(1) 空间。” 

class Solution {
    public List<String> getValidT9Words(String num, String[] words) {
        String digitMap = "22233344455566677778889999";
        List<String> answer = new ArrayList<>();

        for (String word : words) {
            boolean matches = true;
            for (int i = 0; i < word.length(); i++) {
                int letterIndex = word.charAt(i) - 'a';
                if (digitMap.charAt(letterIndex) != num.charAt(i)) {
                    matches = false;
                    break;
                }
            }
            if (matches) {
                answer.add(word);
            }
        }
        return answer;
    }
}

var getValidT9Words = function (num, words) {
  const digitMap = "22233344455566677778889999";
  const answer = [];

  for (const word of words) {
    let matches = true;
    for (let i = 0; i < word.length; i += 1) {
      const letterIndex = word.charCodeAt(i) - 97;
      if (digitMap[letterIndex] !== num[i]) {
        matches = false;
        break;
      }
    }
    if (matches) answer.push(word);
  }
  return answer;
};

        answer = []

        for word in words:
            matches = True
            for index, char in enumerate(word):
                if digit_map[ord(char) - ord("a")] != num[index]:

                    break
            if matches:

        return answer

public:
    vector<string> getValidT9Words(string num, vector<string>& words) {

        vector<string> answer;

        for (const string& word : words) {
            bool matches = true;
            for (int i = 0; i < static_cast<int>(word.size()); ++i) {
                if (digitMap[word[i] - 'a'] != num[i]) {
                    matches = false;
                    break;
                }
            }
            if (matches) {
                answer.push_back(word);
            }
        }
