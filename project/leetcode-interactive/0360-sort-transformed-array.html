Solution

准备好再看题解

先尝试从曲线两端的大小关系推导线性做法。

Two Pointers

用抛物线形态决定填充方向

核心洞察

当 x 沿升序数组移动时，二次函数的值先沿一个方向变化，越过顶点后再反向变化。因此，当前未处理区间的最大值或最小值一定出现在左右端点之一。

  • a ≥ 0：曲线开口向上，两端更可能大。每次取两个端点中较大的值，从结果数组右侧向左写。
  • a < 0：曲线开口向下，两端更可能小。每次取两个端点中较小的值，从结果数组左侧向右写。
  • a = 0 是线性函数，也被 a ≥ 0 分支正确覆盖。

完整过程

  1. 令 left = 0、right = n - 1。
  2. 计算左右端点的函数值 lv、rv。
  3. 按 a 的符号选较大值或较小值，写入结果的对应一端。
  4. 移动被选中端点的指针，直到区间为空。

正确性证明

  1. 端点性质：二次函数在顶点两侧分别单调，所以任一连续未处理区间中的极端值可在区间端点找到。
  2. 开口向上：左右端点较大者就是未处理值中的最大值。把它放到最右空位，不会破坏最终非递减顺序。
  3. 开口向下：左右端点较小者就是未处理值中的最小值。把它放到最左空位，同样保持最终顺序。
  4. 归纳：每一步正确固定一个位置并缩小区间；重复至区间为空，结果数组全部位置均正确。

复杂度与边界

  • 时间复杂度：O(n)，每个元素恰好处理一次。
  • 空间复杂度：O(n)，用于返回结果数组；除返回值外为 O(1)。
  • 单元素、重复元素、顶点在数组范围外、a = 0、b = 0 均无需特殊分支。
  • 若题目扩大数值范围，应使用更宽的整数类型计算乘法，避免中间结果溢出。

四语言完整代码

class Solution {
    public int[] sortTransformedArray(int[] nums, int a, int b, int c) {
        int n = nums.length;
        int[] answer = new int[n];
        int left = 0;
        int right = n - 1;
        int write = a >= 0 ? n - 1 : 0;

        while (left <= right) {
            int leftValue = transform(nums[left], a, b, c);
            int rightValue = transform(nums[right], a, b, c);

            if (a >= 0) {
                if (leftValue >= rightValue) {
                    answer[write--] = leftValue;
                    left++;
                } else {
                    answer[write--] = rightValue;
                    right--;
                }
            } else {
                if (leftValue <= rightValue) {
                    answer[write++] = leftValue;
                    left++;
                } else {
                    answer[write++] = rightValue;
                    right--;
                }
            }
        }
        return answer;
    }

    private int transform(int x, int a, int b, int c) {
        return a * x * x + b * x + c;
    }
}

替代方案

  • 直接变换后排序：实现最直观，时间 O(n log n)；适合作为基线方案。
  • 按顶点拆分再归并：先定位离顶点最近的位置，再将两侧按函数值归并，也能达到 O(n)，但边界处理更繁琐。

面试追问

  • 为什么极值一定在未处理区间的端点？
  • a = 0 且 b < 0 时，这套写法为什么仍然成立？
  • 如果输入不是有序数组，复杂度下界和方案会怎样变化？
  • 若系数和元素达到 10⁹，如何处理溢出？

常见错误

  • 只根据 a 选择端点，却忘记同步改变结果数组的写入方向。
  • 移动了错误的指针，导致元素被重复处理或遗漏。
  • 循环条件写成 left < right，漏掉最后一个元素。
  • 先排序原数组的变换值，错失题目有序性带来的线性时间。

实现检查清单

  • 变换函数只写一次，避免四处复制公式。
  • 开口向上取较大值，写右侧；开口向下取较小值，写左侧。
  • 比较相等时任取一端都正确。
  • 更大数值范围下，将乘法提升到 64 位或更宽类型。
