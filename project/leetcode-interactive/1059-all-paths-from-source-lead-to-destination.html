从起点到终点的所有路径

All Paths from Source Lead to Destination

检查从起点出发的每一种可能走法，是否都必然在指定终点结束。

题目

给定含 n 个节点的有向图，节点编号为 0..n-1，有向边由 edges 给出。判断从 source 开始的所有路径是否最终都在 destination 停止。

等价地：从起点可达的区域不能有环；每个可达的无出边节点都必须恰好是 destination。

函数签名

boolean leadsToDestination(int n, int[][] edges, int source, int destination)

官方示例参数

输入：n = 3
edges = [[0,1],[0,2]]
source = 0
destination = 2
输出：false
路径 0→1 停在错误节点。
输入：n = 4
edges = [[0,1],[0,3],[1,2],[2,1]]
source = 0
destination = 3
输出：false
存在可达环 1↔2。
输入：n = 4
edges = [[0,1],[0,2],[1,3],[2,3]]
source = 0
destination = 3
输出：true
两条路径都在 3 结束。

约束

  • 1 ≤ n ≤ 10⁴
  • 0 ≤ edges.length ≤ 10⁴，每条边含两个合法节点编号
  • 0 ≤ source, destination < n
  • 图中可能存在自环或重边

题解：三色 DFS

核心洞察

失败只有两类：到达一个不是目标的叶子；或在当前递归路径再次遇到正在访问的节点，说明存在可达环。三色状态能同时识别环并记忆已验证安全的节点。

完整过程

  1. 建立邻接表。
  2. 无出边节点只有等于目标才安全。
  3. 状态 1 表示在递归栈中，再遇到即为环。
  4. 状态 2 表示所有后继均已证明安全，可直接复用。
  5. 所有后继返回真后，将当前节点改为状态 2。

正确性

必要性：错误叶子给出一条不在目标结束的路径；可达环允许无限行走，两者均应返回假。

充分性：若 DFS 返回真，可达子图无环且所有叶子都是目标。有限无环图中的任意路径最终到达叶子，因此每条路径都在目标结束。

边界

  • 起点等于目标时仍要检查目标是否有出边。
  • 不可达环不影响答案；自环属于环；重边不改变结论。

复杂度

时间 O(n+m)，邻接表、状态及递归栈空间 O(n+m)。

替代方案

可以对可达子图做拓扑消除，或先求强连通分量；三色 DFS 更直接。担心深递归时可改用显式栈。

面试追问

  • 输出反例路径：维护父节点并在失败时回溯。
  • 增量加边：同时维护环检测和可达叶子的变化。
  • 若到目标即可主动停止，目标有出边时的语义将不同。

常见错误

  • 只检查目标可达，漏掉错误叶子。
  • 只用 visited，无法区分递归栈与已安全节点。
  • 见到目标就返回真，漏查其出边。
  • 拒绝起点不可达的环，扩大检查范围。

class Solution {
  List<Integer>[] g; int[] state; int dest;
  public boolean leadsToDestination(int n, int[][] edges, int source, int destination) {
    dest=destination; g=new ArrayList[n];
    for(int i=0;i<n;i++) g[i]=new ArrayList<>();
    for(int[] e:edges) g[e[0]].add(e[1]);
    state=new int[n]; return dfs(source);
  }
  boolean dfs(int u) {
    if(g[u].isEmpty()) return u==dest;
    if(state[u]!=0) return state[u]==2;
    state[u]=1;
    for(int v:g[u]) if(!dfs(v)) return false;
    state[u]=2; return true;
  }
}
