找出数组中的幸运数

Find Lucky Integer in an Array

EASY数组哈希表计数

这是一道关于“数值与频次恰好相等”的小题。先观察计数过程，想一想：若有多个候选，怎样确保返回最大的那个？

题目描述

给定整数数组 arr。如果某个整数在数组中的出现次数恰好等于它本身，则称它为“幸运数”。返回数组中最大的幸运数；若不存在，返回 -1。

函数参数形式：findLucky(arr: integer[]) → integer

示例 1
输入：arr = [2,2,3,4]
输出：2
解释：2 出现 2 次，是唯一的幸运数。
示例 2
输入：arr = [1,2,2,3,3,3]
输出：3
解释：1、2、3 都是幸运数，返回最大的 3。
示例 3
输入：arr = [2,2,2,3,3]
输出：-1
解释：数组中不存在幸运数。
示例 4
输入：arr = [5]
输出：-1
示例 5
输入：arr = [7,7,7,7,7,7,7]
输出：7
约束
  • 1 <= arr.length <= 500
  • 1 <= arr[i] <= 500

Solution

计数后倒序寻找

核心洞察

幸运数的定义同时涉及“值”和“出现次数”，所以先把数组压缩成频次表。随后从可能的最大值向下扫描，第一个满足 count[x] == x 的数字自然就是最大幸运数。

完整过程

  1. 创建长度 501 的计数数组。
  2. 遍历 arr，让对应计数加一。
  3. 从 500 倒序到 1；若数值与其计数相等，立即返回。
  4. 扫描结束仍未命中，返回 -1。

正确性

计数阶段结束后，count[x] 等于 x 在原数组中的真实频次，因此条件 count[x] == x 与幸运数定义完全等价。检查顺序严格递减，首次命中的 x 大于所有尚未检查的值，也就大于其余可能的幸运数。若无命中，则不存在幸运数，返回 -1 正确。

复杂度与边界

设数组长度为 n，值域上界为 U=500。时间复杂度 O(n + U)，额外空间 O(U)；在本题固定值域下可视作 O(n) 时间、O(1) 额外空间。单元素、重复次数多于或少于数值、多个幸运数和无幸运数都由同一逻辑覆盖。

替代方案

也可用哈希表计数，再遍历键并维护最大合法值，复杂度 O(n) 时间、O(k) 空间，适合值域未知或很大时。还可以排序后按分组长度判断，时间 O(n log n)，但会修改数组或需要额外副本。

面试追问

  • 如果值允许负数或上界很大，计数数组还能用吗？
  • 如果要返回所有幸运数，如何保持升序？
  • 数据流持续到来时，怎样增量维护答案？
常见错误：把“出现次数最多”误认为幸运；从小到大扫描后过早返回；只检查频次值而没有核对对应数字；没有在无解时返回 -1。

class Solution {
    public int findLucky(int[] arr) {
        int[] count = new int[501];
        for (int value : arr) {
            count[value]++;
        }
        for (int value = 500; value >= 1; value--) {
            if (count[value] == value) {
                return value;
            }
        }
        return -1;
    }
}

from typing import List

class Solution:
    def findLucky(self, arr: List[int]) -> int:
        count = [0] * 501
        for value in arr:
            count[value] += 1

        for value in range(500, 0, -1):
            if count[value] == value:
                return value
        return -1
