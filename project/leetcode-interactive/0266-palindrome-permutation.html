回文排列Palindrome Permutation

判断一个字符串的字符能否经过重新排列，组成一个从左向右与从右向左读都相同的字符串。

先理解问题与样例；交互推演和完整题解都在下方。

Problem

题目说明

任务

给定字符串 s。你可以任意调整其中字符的顺序；如果存在至少一种排列是回文串，返回 true，否则返回 false。

函数形式：boolean canPermutePalindrome(string s)

约束

  • 1 <= s.length <= 5000
  • s 仅由小写英文字母组成。
  • 只需判断是否存在可行排列，无需构造该排列。
Example 01 
输入：s = "code"
输出：false

无论如何排列，都不能形成回文串。

Example 02 
输入：s = "aab"
输出：true

例如，排列为 "aba"。

Example 03 
输入：s = "carerac"
输出：true

例如，排列为 "racecar"。

核心洞察

回文串中，镜像位置的字符成对出现。因此，偶数长度的回文串不能有奇数频次字符；奇数长度的回文串只能让中心字符拥有奇数频次。

奇数频次字符数 <= 1

完整过程

  1. 创建集合 odd，表示当前出现奇数次的字符。
  2. 扫描字符：若字符已在集合中就删除，否则加入。
  3. 扫描结束后，判断集合大小是否不超过 1。

正确性证明

不变量：处理完任意前缀后，集合 odd 恰好包含该前缀中出现奇数次的字符。字符每出现一次，频次奇偶性翻转，集合的加入/删除操作正好维持该不变量。

必要性：若能组成回文串，除至多一个中心字符外，其余字符都分布在成对的镜像位置，因此奇数频次字符至多一个。

充分性：若奇数频次字符至多一个，把每种字符的一半放在左侧，镜像复制到右侧；若存在奇数频次字符，再把剩余的一个放在中心，即可构造回文串。因此算法返回值正确。

边界情况

  • 单字符：唯一字符可作为中心，返回 true。
  • 所有字符相同：一定可以组成回文串。
  • 所有字符互不相同且长度大于 1：奇数项超过一个，返回 false。
  • 偶数长度：最终集合必须为空。

复杂度

设字符串长度为 n，单次扫描时间复杂度为 O(n)。

哈希集合的空间复杂度为 O(k)，其中 k 是字符种类数；本题仅含 26 个小写字母，可视为 O(1)。

替代方案

  • 频次数组：用长度 26 的数组计数，最后统计奇数项；表达直接。
  • 位掩码：用一个整数的 26 位记录奇偶性，最后通过 mask & (mask - 1) 判断是否至多一位为 1。
  • 排序：排序后统计连续分组，时间为 O(n log n)，不如一次扫描。

面试追问

  • 如果字符集是完整 Unicode，空间复杂度如何描述？
  • 如果要求真正构造一个回文排列，应如何输出左右两半和中心？
  • 如何在字符流中持续维护当前答案？
  • 位掩码方案为何能判断“至多一个奇数项”？

常见错误

  • 误以为必须先枚举全部排列，导致阶乘级复杂度。
  • 要求所有频次都为偶数，漏掉奇数长度回文串的中心字符。
  • 把“原字符串是否回文”当成“是否存在回文排列”。
  • 计数完成后只看字符串长度奇偶，而没有统计奇数频次字符。

JavacanPermutePalindrome(String s)
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean canPermutePalindrome(String s) {
        Set<Character> odd = new HashSet<>();

        for (char ch : s.toCharArray()) {
            if (!odd.add(ch)) {
                odd.remove(ch);
            }
        }

        return odd.size() <= 1;
    }
}

var canPermutePalindrome = function (s) {
    const odd = new Set();

    for (const ch of s) {
        if (odd.has(ch)) {
            odd.delete(ch);
        } else {
            odd.add(ch);
        }
    }

    return odd.size <= 1;
};

C++canPermutePalindrome(string s)
#include <string>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool canPermutePalindrome(string s) {
        unordered_set<char> odd;

        for (char ch : s) {
            auto it = odd.find(ch);
            if (it == odd.end()) {
                odd.insert(ch);
            } else {
                odd.erase(it);
            }
        }

        return odd.size() <= 1;
    }
};
