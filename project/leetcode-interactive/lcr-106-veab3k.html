判断二分图

尝试给每个节点涂上两种不同颜色：每条边两端都必须异色。能完成涂色，就说明图可以二分。

题意

给定无向图的邻接表 graph，判断是否能把所有节点分为两个集合，使得每条边连接的两个节点分别属于不同集合。

示例

输入：[[1,3],[0,2],[1,3],[0,2]]

输出：true

解释：可将 {0,2} 与 {1,3} 分到两侧。

约束

  • 1 <= graph.length <= 100
  • 0 <= graph[i].length < graph.length
  • 图中没有自环，也没有重复边。

先设想从一个节点开始染色：遇到邻居时应该给它什么颜色？题解默认收起，避免首屏泄露。

核心洞察

把颜色视作阵营。每访问一条边，就要求另一端颜色与当前节点相反；若一个已染色邻居颜色相同，即产生矛盾。

过程

  1. color 初始为 0，表示未染色。
  2. 从每个未访问节点开始 DFS/BFS 并赋予颜色 1。
  3. 邻居未染色则赋相反色；已染色但同色则返回 false。

边界

图可能不连通，必须从每个未染色节点重新开始。孤立节点可任意染色，不会造成冲突。

复杂度

每个节点和每条边至多访问一次，时间 O(V+E)，颜色数组空间 O(V)。

替代方案

并查集可以把某个节点的所有邻居并到同一集合，并检查节点是否与邻居落在同集；DFS/BFS 的两色语义通常更直观。

常见错误

  • 漏掉不连通的分量。
  • 把邻居颜色写成当前颜色，而不是相反颜色。
  • 发现已染色节点时没有比较颜色是否冲突。

参考实现

Java

class Solution {
    public boolean isBipartite(int[][] graph) {
        int[] color = new int[graph.length];
        for (int i = 0; i < graph.length; i++)
            if (color[i] == 0 && !dfs(graph, color, i, 1)) return false;
        return true;
    }
    private boolean dfs(int[][] g, int[] color, int node, int c) {
        color[node] = c;
        for (int next : g[node]) {
            if (color[next] == 0 && !dfs(g, color, next, -c)) return false;
            if (color[next] == c) return false;
        }
        return true;
    }
}

JavaScript

var isBipartite = function(graph) {
  const color = Array(graph.length).fill(0);
  const dfs = (node, c) => {
    color[node] = c;
    for (const next of graph[node]) {
      if (color[next] === 0 && !dfs(next, -c)) return false;
      if (color[next] === c) return false;
    }
    return true;
  };
  return graph.every((_, node) => color[node] || dfs(node, 1));
};

Python

class Solution:
    def isBipartite(self, graph: List[List[int]]) -> bool:
        color = [0] * len(graph)
        def dfs(node: int, c: int) -> bool:
            color[node] = c
            for nxt in graph[node]:
                if color[nxt] == 0 and not dfs(nxt, -c): return False
                if color[nxt] == c: return False
            return True
        return all(color[i] or dfs(i, 1) for i in range(len(graph)))

C++

class Solution {
public:
    bool isBipartite(vector<vector<int>>& graph) {
        vector<int> color(graph.size());
        function<bool(int, int)> dfs = [&](int node, int c) {
            color[node] = c;
            for (int next : graph[node]) {
                if (!color[next] && !dfs(next, -c)) return false;
                if (color[next] == c) return false;
            }
            return true;
        };
        for (int i = 0; i < graph.size(); ++i)
            if (!color[i] && !dfs(i, 1)) return false;
        return true;
    }
};
