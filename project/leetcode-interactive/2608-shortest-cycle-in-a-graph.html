Graph · Breadth-First Search

最短环

给定一个无向简单图，找出其中边数最少的环；如果图里没有任何环，返回 -1。

n ≤ 1000 edges ≤ 1000 无向简单图

任务简报

Shortest Cycle
顶点编号0…n−1
返回值最少边数
Example signal

n = 7
edges = [[0,1],[1,2],[2,0], …]

最短环3

先理解目标，再进入下方实验台；本屏不展示解法。

01 / PROBLEM

题意与边界

图中的每条边都可以双向通行。任意顶点对之间至多有一条边，且没有自环。

准确转述

图有 n 个顶点，编号为 0 到 n - 1。数组 edges[i] = [uᵢ, vᵢ] 表示顶点 uᵢ 与 vᵢ 之间存在一条无向边。

环是一条从某个顶点出发、最终回到该顶点且每条边至多使用一次的路径。返回最短环包含的边数；不存在环时返回 -1。

约束

2 ≤ n ≤ 1000
1 ≤ edges.length ≤ 1000
edges[i].length = 2
0 ≤ uᵢ, vᵢ < n
uᵢ ≠ vᵢ
不存在重复边

示例 1

输出 3
输入n = 7, edges = [[0,1],[1,2],[2,0],[3,4],[4,5],[5,6],[6,3]]

环 0 → 1 → 2 → 0 只包含 3 条边，是最短环。

示例 2

输出 −1
输入n = 4, edges = [[0,1],[0,2]]

两条边只构成树形分支，没有路径能够回到起点。

04 / SOLUTION

从每个起点发出 BFS 波前

同一轮 BFS 中，一条非树边把两条最短路径接起来，它对应一个候选环。

核心等式
dist[u] + dist[v] + 1
复杂度

时间：O(n · (n + m))

空间：O(n + m)

其中 m = edges.length。

一句话记忆

枚举 BFS 起点；遇到已访问的非父子邻居，就用两端距离加一更新答案。

核心洞察

固定一个起点 s 做 BFS，dist[x] 是 s 到 x 的最短距离。扫描边 (u, v) 时，如果两端都已访问，并且它不是 BFS 树中的父子边，那么从 s 到两端的路径再加上这条边，就闭合了一个候选环。

枚举所有起点，便不会错过真正的最短环。图可能不连通，但每个顶点都作为起点，因此所有连通分量都会被覆盖。

完整过程

  1. 根据 edges 建立无向邻接表。
  2. 依次选取每个顶点 s 作为 BFS 起点，并把全部距离和父节点初始化为 -1。
  3. 首次遇到邻居 v 时，设置 dist[v] = dist[u] + 1、记录父节点并入队。
  4. 若 v 已访问，且 u、v 互不为父子，则用 dist[u] + dist[v] + 1 更新全局最小值。
  5. 全部 BFS 结束后，若答案仍为无穷大则返回 -1，否则返回答案。

正确性证明

候选值不会小于真实最短环。 每次更新来自一条非树边 (u,v)。两条 BFS 树路径与该边构成一个闭合游走；去掉它们的公共前缀后可得到一个简单环，其长度不超过 dist[u] + dist[v] + 1。因此候选值不可能小于图的最短环长度。

最短环一定能给出不大于自身的候选值。 设最短环长度为 g，选择环上任一顶点作为 BFS 起点。最短环上两点之间不存在比环上较短弧更短的外部路径，否则该路径与另一段环弧会组成长度小于 g 的环。于是 BFS 到环上顶点的距离与较短弧一致；当波前在环的对侧相遇时，某条非树边产生的候选值至多为 g。

结合两点，算法返回值既不小于也不大于最短环长度，所以恰好等于最短环长度；没有任何更新时，图无环，返回 -1。

四语言完整代码

import java.util.*;

class Solution {
    public int findShortestCycle(int n, int[][] edges) {
        List<Integer>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : edges) {
            graph[edge[0]].add(edge[1]);
            graph[edge[1]].add(edge[0]);
        }

        int answer = Integer.MAX_VALUE;
        for (int start = 0; start < n; start++) {
            int[] distance = new int[n];
            int[] parent = new int[n];
            Arrays.fill(distance, -1);
            Arrays.fill(parent, -1);

            Queue<Integer> queue = new ArrayDeque<>();
            queue.offer(start);
            distance[start] = 0;

            while (!queue.isEmpty()) {
                int node = queue.poll();
                for (int next : graph[node]) {
                    if (distance[next] == -1) {
                        distance[next] = distance[node] + 1;
                        parent[next] = node;
                        queue.offer(next);
                    } else if (parent[node] != next && parent[next] != node) {
                        answer = Math.min(answer, distance[node] + distance[next] + 1);
                    }
                }
            }
        }
        return answer == Integer.MAX_VALUE ? -1 : answer;
    }
}

var findShortestCycle = function(n, edges) {
    const graph = Array.from({ length: n }, () => []);
    for (const [u, v] of edges) {
        graph[u].push(v);
        graph[v].push(u);
    }

    let answer = Infinity;
    for (let start = 0; start < n; start++) {
        const distance = Array(n).fill(-1);
        const parent = Array(n).fill(-1);
        const queue = [start];
        let head = 0;
        distance[start] = 0;

        while (head < queue.length) {
            const node = queue[head++];
            for (const next of graph[node]) {
                if (distance[next] === -1) {
                    distance[next] = distance[node] + 1;
                    parent[next] = node;
                    queue.push(next);
                } else if (parent[node] !== next && parent[next] !== node) {
                    answer = Math.min(answer, distance[node] + distance[next] + 1);
                }
            }
        }
    }
    return answer === Infinity ? -1 : answer;
};

边界情况与常见错误

  • 图不连通：不能只从顶点 0 搜索；必须枚举所有起点。
  • 把树边当成环：回看父节点的无向边必须排除，否则会错误得到长度 2。
  • 复用距离数组：每个 BFS 起点都需要独立的 distance 与 parent。
  • 统计顶点数：题目要求环的边数，公式里的 +1 正是连接两端的当前边。
  • 无环返回值：全程未更新答案时返回 -1，而不是无穷大。

替代方案

逐边删除 + BFS

临时移除一条边，再求其两端最短路；若可达，则距离加一形成环。直观，但需要反复改图或跳过指定边。

Floyd–Warshall 变体

可在加入中间点前结合旧距离统计环，但时间为 O(n³)；本题稀疏图下不如 BFS 合适。

面试追问

  • 为什么 DFS 不自然？ DFS 深度不是最短距离，发现返祖边时无法直接保证环最短；BFS 分层天然提供无权最短路。
  • 能否提前结束单轮 BFS？ 已知全局答案后，可以在当前层深已经不可能改进答案时剪枝；但约束仅 1000，基础实现更清晰。
  • 若图有平行边或自环？ 自环答案可为 1，平行边可形成长度 2；本题明确排除了两者。
  • 若边带正权？ BFS 不再适用，可考虑从每个起点运行 Dijkstra，并重新定义非树边候选。
