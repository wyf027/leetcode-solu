最多能完成排序的块

Max Chunks To Make Sorted

把一个排列切成若干连续块，分别排序后再按原顺序拼接。你的目标不是找到一种切法，而是让块的数量尽可能多，同时拼接结果仍等于整个数组升序排序后的结果。

先自己想一想：每个切分点需要保证左侧已经“收齐”了哪些数字？页面首屏不会直接给出判定公式。

01 · Problem

题意与约束

准确转述

给定长度为 n 的整数数组 arr。它恰好是整数 0 到 n - 1 的一个排列。

将数组划分为若干个非空、连续、互不重叠的块。对每个块独立升序排序，再按原块顺序连接；连接结果必须等于对整个数组升序排序的结果。返回可划分出的最大块数。

约束

  • n == arr.length
  • 1 <= n <= 10
  • 0 <= arr[i] < n
  • arr 中所有元素互不相同

示例 1

输入：arr = [4,3,2,1,0] 输出：1

切成两块或更多块都无法得到全局有序结果。例如切为 [4,3] 与 [2,1,0]，各自排序并拼接会得到 [3,4,0,1,2]。

示例 2

输入：arr = [1,0,2,3,4] 输出：4

最多可切为 [1,0]、[2]、[3]、[4]。各块排序后拼接为 [0,1,2,3,4]。

03 · Solution

准备好核对思路了吗？

完整题解

前缀最大值决定切分点

因为数组是 0..n-1 的排列，理想有序数组中下标 0..i 恰好放置数值集合 {0..i}。

核心洞察

从左到右维护前缀最大值 maxValue。扫描到位置 i 时，若 maxValue == i，那么前缀中全部元素都不大于 i。

前缀长度又恰好是 i + 1，元素互不相同且都来自 0..n-1，所以它只能包含 0..i 的全部数字。这里可以安全切一刀。

完整过程

  1. 初始化答案 chunks = 0，前缀最大值 maxValue = 0。
  2. 依次扫描每个下标 i，更新 maxValue = max(maxValue, arr[i])。
  3. 若 maxValue == i，当前前缀已经收齐其最终位置所需的所有数字，答案加一。
  4. 扫描结束后返回 chunks。

正确性证明

充分性：当位置 i 的前缀最大值等于 i 时，前缀内有 i + 1 个互异值，且都位于 0..i，因此其集合就是 {0..i}。排序该前缀后，它与全局有序数组的同一前缀完全一致，所以可在此切分。

必要性：若在 i 后切分且最终能全局有序，左侧块们排序后必须占据有序数组的前 i + 1 位，因此左侧不能含有大于 i 的值，即前缀最大值必须是 i。

最优性：算法在每个且仅每个合法边界都切分，没有遗漏任何可行切分点，因此获得最大块数。

边界与复杂度

  • 单元素数组：在 i = 0 立即形成一个块。
  • 完全逆序：通常只有最后一个位置满足条件，因此只有一个块。
  • 已经升序：每个位置都满足条件，可切成 n 个单元素块。
时间
O(n)
额外空间
O(1)

class Solution {
    public int maxChunksToSorted(int[] arr) {
        int chunks = 0;
        int maxValue = 0;

        for (int i = 0; i < arr.length; i++) {
            maxValue = Math.max(maxValue, arr[i]);
            if (maxValue == i) {
                chunks++;
            }
        }

        return chunks;
    }
}

替代方案

前缀最大值 + 后缀最小值：预处理每个位置右侧的最小值，当左侧最大值不大于右侧最小值时切分。它能推广到包含重复值的版本，但本题会使用 O(n) 额外空间（也可优化）。

排序后比较前缀和：原数组与排序数组的前缀元素和相同处可作为候选边界。该方法需排序，时间为 O(n log n)，且依赖数值求和，表达不如集合边界直接。

单调栈：适合扩展题“最多能完成排序的块 II”（允许重复值），但对当前排列条件而言明显更复杂。

面试追问

  • 如果数组不是 0..n-1 的排列，这个等式为什么会失效？
  • 如果允许重复值，怎样利用单调栈或前后缀数组判断边界？
  • 如何不仅返回块数，还返回每个块的左右端点？
  • 若要求流式读取数组，当前方案还能保持 O(1) 额外空间吗？

常见错误

  • 只判断 arr[i] == i；真正需要的是整个前缀的最大值。
  • 把块当作可任意选取的子序列；题目要求每块都是连续子数组。
  • 先排序原数组再扫描，破坏了决定切分边界的原始顺序。
  • 把本题结论直接套到含重复值的扩展题，忽略“排列”这一关键前提。

一句话记忆

扫描到 i 时，前缀最大值若刚好等于 i，说明前缀已经把属于自己的数字全部收齐，于是可以封成一块。
