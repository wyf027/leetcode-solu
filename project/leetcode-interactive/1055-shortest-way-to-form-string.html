形成字符串的
最短路径

反复从同一份 source 中挑出子序列，把它们首尾拼接成 target。问题不是“能不能拼”，而是最少要重新启航多少次。

先观察，再揭晓。

下面的扫描器会把每一轮 source 当作一次从左到右的航行。你可以逐步观察匹配发生在哪里，但核心结论与代码默认藏在页面底部。

交互式贪心轨迹

题目转述

给定两个仅含小写英文字母的字符串 source 和 target。每次可以从 source 中按原有相对顺序选出若干字符，得到一个子序列。请用若干个这样的子序列依次拼接成 target，返回所需子序列的最少数量；如果无论如何都无法形成，则返回 -1。

子序列可以跳过字符，不能改变顺序。每轮都从完整的 source 重新开始选择。

官方示例与约束

示例 1

输入：source = "abc", target = "abcbc"
输出：2
解释：可拼接子序列 "abc" + "bc"。

示例 2

输入：source = "abc", target = "acdbc"
输出：-1
解释：target 中的字符 'd' 不在 source 中。

示例 3

输入：source = "xyz", target = "xzyxz"
输出：3
解释：可拼接 "xz" + "y" + "xz"。

约束

  • 1 <= source.length, target.length <= 1000
  • source 与 target 只含小写英文字母。
  • 函数签名：shortestWay(source, target) -> integer

核心洞察

每一轮都应尽可能从左到右匹配 target 尚未完成的最长前缀。因为更早地匹配一个所需字符，不会压缩本轮后续字符的可选位置；少匹配任何一个字符也不可能让总轮数更少。

完整过程

预判无解。
若 target 出现 source 中没有的字符，立即返回 -1。
开启一轮。
从 source[0] 向右扫描，同时盯住 target 的当前字符。
相等就收下。
字符相等时推进 target 指针，不等则只推进 source。
耗尽则重启。
target 未完成时，再扫描一份完整 source，答案加一。

边界情况

  • target 的首字符不存在：直接 -1。
  • target 本身是 source 的子序列：答案为 1。
  • 重复字符：每轮只能按 source 中出现顺序消费。
  • source 只有一个字符：答案可能等于 target 长度。

复杂度

设 m = source.length，n = target.length。直接贪心每轮扫描 source，时间 O(mn)（更精确为 O(m × 答案)），额外空间 O(1)；字符存在性预检使用常数级字母表空间。

正确性证明

引理：对于 target 当前未完成的后缀，一轮从左到右的贪心扫描能匹配出任意 source 子序列所能覆盖的最长前缀。

理由：逐个考虑待匹配字符。贪心总是选择 source 中可用的最早位置。若某个可行方案选择了更晚的同字符位置，把它换成贪心的更早位置不会妨碍后续选择，因此贪心至少能匹配同样多的字符。

结论：第一轮贪心留下的未完成后缀不长于任何其他第一轮选择。对余下后缀重复同样论证，贪心不会使用更多轮；因此得到最少子序列数。若某字符不在 source，任何轮都无法提供它，返回 -1 正确。

替代方案

可为 source 的每个字符保存有序下标。处理 target 时，对当前 source 位置二分查找下一个可用下标；找不到就开启新一轮。时间降为 O(n log m)，空间为 O(m)。若字母表固定，还可预处理“从位置 i 起某字符的下一位置”，做到 O(m·Σ + n)。

面试追问

  • 如何用二分查找将大 source 的重复扫描消除？
  • 若 source 会固定、target 查询很多次，怎样预处理？
  • 若允许重排 source，问题会变成什么？

常见错误

  • 把子序列误写成子串，要求字符连续。
  • 一轮结束时 target 指针没有前进，却继续死循环。
  • 每轮重新构造字符串，造成不必要的空间和时间。
  • 答案在错误的位置累加，产生多 1 或少 1。

四语言完整实现

class Solution {
    public int shortestWay(String source, String target) {
        boolean[] exists = new boolean[26];
        for (char c : source.toCharArray()) exists[c - 'a'] = true;
        for (char c : target.toCharArray()) {
            if (!exists[c - 'a']) return -1;
        }

        int answer = 0, targetIndex = 0;
        while (targetIndex < target.length()) {
            for (int i = 0; i < source.length()
                    && targetIndex < target.length(); i++) {
                if (source.charAt(i) == target.charAt(targetIndex)) {
                    targetIndex++;
                }
            }
            answer++;
        }
        return answer;
    }
}

var shortestWay = function(source, target) {
    const exists = new Set(source);
    for (const char of target) {
        if (!exists.has(char)) return -1;
    }

    let answer = 0;
    let targetIndex = 0;
    while (targetIndex < target.length) {
        for (let i = 0;
             i < source.length && targetIndex < target.length;
             i++) {
            if (source[i] === target[targetIndex]) targetIndex++;
        }
        answer++;
    }
    return answer;
};
class Solution:
    def shortestWay(self, source: str, target: str) -> int:
        available = set(source)
        if any(char not in available for char in target):
            return -1

        answer = 0
        target_index = 0
        while target_index < len(target):
            for char in source:
                if (target_index < len(target)
                        and char == target[target_index]):
                    target_index += 1
            answer += 1
        return answer

                    ++targetIndex;
                }
            }
            ++answer;
        }
