给定三个只含小写字母的字符串 s1、s2 和 s3。判断能否在保持 s1 与 s2 各自字符相对顺序不变的前提下，交替取出若干非空片段并拼成 s3。

官方样例 1 · 输入

s1 = "aabcc", s2 = "dbbca", s3 = "aadbbcbcac"

输出

true

官方样例 2 · 输入

s1 = "aabcc", s2 = "dbbca", s3 = "aadbbbaccc"

输出

false

官方样例 3 · 输入

s1 = "", s2 = "", s3 = ""

输出

true

交错字符串完整题解

Core insight

状态只需要两个前缀长度

dp[i][j] 表示 s1 前 i 个字符与 s2 前 j 个字符能否组成 s3 前 i+j 个字符。目标下标由 i+j 唯一确定，不必额外记录。

Transition

最后一个字符来自上方或左侧

若从上方来，需要 dp[i-1][j] 已可达且 s1[i-1] == s3[i+j-1]；从左侧来同理检查 s2[j-1]。两者取或。

Complete process

完整过程

  1. 长度不满足 |s1| + |s2| = |s3| 时立即返回 false。
  2. 令较短字符串作为一维数组的列，初始化 dp[0] = true。
  3. 先用第二个字符串初始化首行。
  4. 逐行更新：旧 dp[j] 是上方，新 dp[j-1] 是左侧。
  5. 最终返回 dp[n]。

Edges

边界

  • 三个字符串都为空时返回 true。
  • 其中一个源字符串为空时，问题退化为与目标串完全相等。
  • 重复字符会让两个来源同时可行，不能贪心地固定选择其中一边。
  • 先做长度检查，避免访问不存在的目标字符。

Complexity & alternatives

复杂度与替代方案

一维 DP 时间 O(mn)，额外空间 O(min(m,n))。二维 DP 更适合讲解与回溯具体路径，但空间为 O(mn)；记忆化 DFS 同样是 O(mn)，递归栈与缓存常数更大。纯贪心在重复字符处会误判。

Interview notes

面试追问与常见错误

  • 追问：如何输出一条实际交错路径？保留二维父指针并从右下角回溯。
  • 追问：为何一维数组必须从左到右更新？因为当前行需要最新的左侧状态与上一行尚未覆盖的上方状态。
  • 错误：把“交错”理解成严格逐字符轮流；实际允许连续取同一来源的若干字符。
  • 错误：只比较字符计数；相对顺序同样必须保持。
class Solution {
    public boolean isInterleave(String s1, String s2, String s3) {
        if (s1.length() + s2.length() != s3.length()) return false;
        if (s2.length() > s1.length()) return isInterleave(s2, s1, s3);

        int m = s1.length(), n = s2.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        for (int j = 1; j <= n; j++) {
            dp[j] = dp[j - 1] && s2.charAt(j - 1) == s3.charAt(j - 1);
        }
        for (int i = 1; i <= m; i++) {
            dp[0] = dp[0] && s1.charAt(i - 1) == s3.charAt(i - 1);
            for (int j = 1; j <= n; j++) {
                char target = s3.charAt(i + j - 1);
                dp[j] = (dp[j] && s1.charAt(i - 1) == target)
                    || (dp[j - 1] && s2.charAt(j - 1) == target);
            }
        }
        return dp[n];
    }
}

var isInterleave = function (s1, s2, s3) {
    if (s1.length + s2.length !== s3.length) return false;
    let a = s1, b = s2;
    if (b.length > a.length) [a, b] = [b, a];

    const dp = Array(b.length + 1).fill(false);
    dp[0] = true;
    for (let j = 1; j <= b.length; j++) {
        dp[j] = dp[j - 1] && b[j - 1] === s3[j - 1];
    }
    for (let i = 1; i <= a.length; i++) {
        dp[0] = dp[0] && a[i - 1] === s3[i - 1];
        for (let j = 1; j <= b.length; j++) {
            const target = s3[i + j - 1];
            dp[j] = (dp[j] && a[i - 1] === target)
                || (dp[j - 1] && b[j - 1] === target);
        }
    }
    return dp[b.length];
};
