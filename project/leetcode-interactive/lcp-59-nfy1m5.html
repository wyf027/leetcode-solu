搭桥过河

移动每条河道上的浮木，使相邻浮木的覆盖区间相交；求总平移距离最小值。答案来自一条凸函数的最低平坦区间。

打开力扣原题 ↗

连接条件

浮木 [Lᵢ,Rᵢ] 与下一条浮木必须有重叠坐标，勇者才能跨到下一条河道。

一次操作

只能在岸上把任意一条浮木沿河流平移 1 单位；平移距离就是自然之力消耗。

数据范围

n ≤ 10⁵、坐标 ≤ 10⁹，必须使用 64 位答案，不能做 O(n²) DP。

样例 1：逐段推演

当前平坦区间 = 到当前浮木时所有同样最优的左端点。

数学建模

  1. 1. 令第 i 段平移后的左端点为 xᵢ，长度 dᵢ = Rᵢ − Lᵢ 不变。
  2. 2. 相邻段重叠等价于 xᵢ ∈ [xᵢ₋₁ − dᵢ, xᵢ₋₁ + dᵢ₋₁]。
  3. 3. 固定 xᵢ 的最小总代价是凸函数；其最小值集合是一个区间 [A,B]。
  4. 4. 转移先依当前/上一段长度平移两侧，再把 Lᵢ 投影到 [A,B]。投影距离就是新增答案。

Slope Trick 双堆

最大堆存左侧折点，最小堆存右侧折点。两个 bias 记录整堆的懒平移，故区间移动不需要逐项更新。 

lo = max(left) + biasL
hi = min(right) + biasR
if x < lo: answer += lo - x
if x > hi: answer += x - hi

局部把某一段贴到前一段不是安全贪心：它会丢掉未来所需的其他最优落点；两堆精确保留整个平坦区间。

复杂度与细节

时间

O(n log n)

空间

O(n)

num 参数

它给出坐标边界；最优平移不会需要越出 [1,num]，实现不必显式使用它。

易错点

  • 答案、偏移和堆元素都用 64 位整数。
  • 更新时左 bias 减当前长度，右 bias 加上一段长度。
  • 第 0 段左右堆各放一次 L₀；从第 1 段开始转移。
