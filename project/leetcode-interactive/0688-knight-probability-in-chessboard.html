骑士在棋盘上的概率

Knight Probability in Chessboard

动态规划 概率传播 空间优化

Problem

题目描述

在一个 n × n 的国际象棋棋盘上，骑士从格子 (row, column) 出发，尝试恰好移动 k 次。行、列均从 0 开始编号。

每一步都会在 8 种骑士走法中等概率选择一种，即使该走法会离开棋盘。若骑士中途离盘，移动立即结束；否则一直走满 k 步。返回停止时仍位于棋盘内的概率。

关键语义：每一步的分母始终是 8，不能只在“仍在棋盘内”的走法中重新等概率选择。

示例 1

输入：n = 3, k = 2, row = 0, column = 0
输出：0.06250

第一步仅有 2 种走法留在棋盘；从这两个位置出发，各自又只有 2 种合法去向，因此最终概率为 4 / 8² = 0.0625。

示例 2

输入：n = 1, k = 0, row = 0, column = 0
输出：1.00000

不需要移动，初始位置在棋盘内，概率为 1。

函数签名

knightProbability(n, k, row, column) → double

约束

  • 1 ≤ n ≤ 25
  • 0 ≤ k ≤ 100
  • 0 ≤ row, column ≤ n - 1

Solution

准备好再揭晓题解

先用上面的传播动画形成直觉，再查看状态定义与实现。

Dynamic programming

题解：逐步传播概率

核心洞察

把概率看成会流动的“质量”。设当前格子 (r,c) 上有概率 p，它下一步会平均拆成 8 份，每份 p / 8。落在棋盘内的份额进入下一层；落在棋盘外的份额直接丢弃。

状态与转移

dp[r][c] 表示完成当前步数后，骑士恰好位于 (r,c) 的概率。初始仅 dp[row][column] = 1。

next[nr][nc] += dp[r][c] / 8

仅当 0 ≤ nr,nc < n 时转移。做完 k 轮后，把所有格子的概率求和。

完整过程

  1. 创建 n × n 的二维数组，起点置为 1，其余为 0。
  2. 重复 k 轮：新建全 0 数组，枚举每个当前格子及 8 个位移。
  3. 若新坐标仍在棋盘内，把当前概率的八分之一累加过去。
  4. 用新数组替换当前数组。最终求当前数组所有元素之和。

正确性证明

  1. 初始成立：移动 0 步时，骑士必然在起点，因此初始数组准确表示所有位置的概率分布。
  2. 归纳转移：假设完成第 t 步后数组准确。对任意仍在棋盘内的格子，其概率按题意等分给 8 个候选去向；算法把每份合法去向累加到下一数组，非法去向不再参与后续移动。因此下一数组准确表示第 t+1 步后仍在棋盘内的全部概率分布。
  3. 结论：归纳至第 k 步，数组覆盖且只覆盖所有仍在棋盘内的互斥位置事件。它们的概率之和就是所求答案。

复杂度

  • 时间：O(k · n² · 8) = O(k · n²)
  • 空间：O(n²)，用滚动数组只保存相邻两层

边界情况

  • k = 0 时直接得到 1。
  • n = 1 且 k > 0 时，第一步必定离盘。
  • 角落、边缘位置会在一次转移中损失更多概率质量。

替代方案

也可以使用记忆化搜索：f(steps,r,c) 表示从该位置再走指定步数仍留在棋盘的概率。它同样有 O(k · n²) 个状态，但递归栈和函数调用开销更高。矩阵快速幂在单次查询下结构复杂，且棋盘最多仅 625 个状态，不如本题的逐层 DP 直接。

常见错误

  • 只除以合法走法数；题意要求始终除以 8。
  • 原地更新同一数组，导致一轮内重复传播。
  • 把答案写成非零格子数量，而不是概率总和。
  • 忘记处理 k = 0。

面试追问

  • 如果不同走法的概率不同，如何修改？——把固定的 1/8 换成每条边自己的权重。
  • 如果要回答同一棋盘、同一起点的多个 k？——逐层预处理并记录每层的总概率。
  • 为什么滚动数组安全？——第 t+1 层只依赖完整的第 t 层。
  • 能否从“剩余步数”角度定义 DP？——可以，记忆化搜索正是这种等价定义。

Java滚动二维数组
class Solution {
    public double knightProbability(int n, int k, int row, int column) {
        int[][] directions = {
            {2, 1}, {2, -1}, {-2, 1}, {-2, -1},
            {1, 2}, {1, -2}, {-1, 2}, {-1, -2}
        };

        double[][] dp = new double[n][n];
        dp[row][column] = 1.0;

        for (int step = 0; step < k; step++) {
            double[][] next = new double[n][n];
            for (int r = 0; r < n; r++) {
                for (int c = 0; c < n; c++) {
                    if (dp[r][c] == 0.0) continue;
                    for (int[] d : directions) {
                        int nr = r + d[0];
                        int nc = c + d[1];
                        if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                            next[nr][nc] += dp[r][c] / 8.0;
                        }
                    }
                }
            }
            dp = next;
        }

        double answer = 0.0;
        for (double[] currentRow : dp) {
            for (double probability : currentRow) {
                answer += probability;
            }
        }
        return answer;
    }
}

var knightProbability = function(n, k, row, column) {
    const directions = [
        [2, 1], [2, -1], [-2, 1], [-2, -1],
        [1, 2], [1, -2], [-1, 2], [-1, -2]
    ];
    let dp = Array.from({ length: n }, () => Array(n).fill(0));
    dp[row][column] = 1;

    for (let step = 0; step < k; step++) {
        const next = Array.from({ length: n }, () => Array(n).fill(0));
        for (let r = 0; r < n; r++) {
            for (let c = 0; c < n; c++) {
                if (dp[r][c] === 0) continue;
                for (const [dr, dc] of directions) {
                    const nr = r + dr;
                    const nc = c + dc;
                    if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                        next[nr][nc] += dp[r][c] / 8;
                    }
                }
            }
        }
        dp = next;
    }

    return dp.reduce(
        (sum, currentRow) =>
            sum + currentRow.reduce((rowSum, value) => rowSum + value, 0),
        0
    );
};

class Solution:
    def knightProbability(
        self,
        n: int,
        k: int,
        row: int,
        column: int
    ) -> float:
        directions = (
            (2, 1), (2, -1), (-2, 1), (-2, -1),
            (1, 2), (1, -2), (-1, 2), (-1, -2)
        )
        dp = [[0.0] * n for _ in range(n)]
        dp[row][column] = 1.0

        for _ in range(k):
            next_dp = [[0.0] * n for _ in range(n)]
            for r in range(n):
                for c in range(n):
                    if dp[r][c] == 0.0:
                        continue
                    for dr, dc in directions:
                        nr, nc = r + dr, c + dc
                        if 0 <= nr < n and 0 <= nc < n:
                            next_dp[nr][nc] += dp[r][c] / 8.0
            dp = next_dp

        return sum(map(sum, dp))

class Solution {
public:
    double knightProbability(int n, int k, int row, int column) {
        const int directions[8][2] = {
            {2, 1}, {2, -1}, {-2, 1}, {-2, -1},
            {1, 2}, {1, -2}, {-1, 2}, {-1, -2}
        };

        vector<vector<double>> dp(n, vector<double>(n, 0.0));
        dp[row][column] = 1.0;

        for (int step = 0; step < k; ++step) {
            vector<vector<double>> next(n, vector<double>(n, 0.0));
            for (int r = 0; r < n; ++r) {
                for (int c = 0; c < n; ++c) {
                    if (dp[r][c] == 0.0) continue;
                    for (const auto& d : directions) {
                        int nr = r + d[0];
                        int nc = c + d[1];
                        if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
                            next[nr][nc] += dp[r][c] / 8.0;
                        }
                    }
                }
            }
            dp = move(next);
        }

        double answer = 0.0;
        for (const auto& currentRow : dp) {
            for (double probability : currentRow) {
                answer += probability;
            }
        }
        return answer;
    }
};
