把深深的括号，分给两支队伍。

有效括号的嵌套深度 · Maximum Nesting Depth of Two Valid Parentheses Strings。先理解目标，再通过逐帧实验发现分配规律；完整题解默认收起。

字符串栈 / 深度贪心时间 O(n)

题目

给定一个仅含左右括号的有效括号字符串 seq，把每个字符分到互不相交的两个子序列 A、B。两者都必须仍是有效括号字符串，并覆盖 seq 的全部字符。返回等长数组 answer：0 表示字符属于 A，1 表示属于 B；目标是让 max(depth(A), depth(B)) 尽可能小。答案不唯一。

有效括号字符串可由空串、两个有效串的连接、或在有效串外包一对括号递归构成。嵌套深度分别满足 0、取两段最大值、以及加 1。

示例 1

输入：seq = "(()())"
输出：[0,1,1,1,1,0]

示例 2

输入：seq = "()(())()"
输出：[0,0,0,1,1,0,1,1]

本例有多个合法最优答案。

约束

  • 1 <= seq.length <= 10000
  • seq 是有效括号字符串，只含 ( 与 )。

核心洞察

原串最大深度为 D，两组中至少一组深度不小于 ceil(D / 2)。让原串处于奇数层的括号去一组、偶数层的括号去另一组，就能把相邻嵌套层交替分开，令两组最大深度都不超过该下界。

实现时，对左括号先增加深度再取奇偶；对右括号先用当前深度取奇偶再减少。等价的极简写法是：左括号分组取 (++depth) % 2，右括号取 (depth--) % 2。

完整过程

  1. 令当前深度 depth = 0。
  2. 从左到右扫描。遇到 (，它属于进入后的层；先加一，再按层数奇偶分组。
  3. 遇到 )，它与当前层的左括号配对；先按当前层奇偶分组，再减一。
  4. 返回每个位置的 0/1 分组。

正确性

合法性：一对匹配括号位于同一层，因而奇偶性相同，会进入同一组；每组保留成对、顺序不变，所以都是 VPS。

最优性：深度 D 的嵌套链有 D 层，分给两组后至少一组承担 ceil(D/2) 层。奇偶分层让每组最多承担交替的层，达到该下界，因此最优。

复杂度与边界

时间 O(n)，除返回数组外额外空间 O(1)。

  • 最浅的 ()()... 仍可全部落在同组，最优最大深度为 1。
  • 纯嵌套串会被严格交替分层。
  • 输入保证有效；通用代码可额外检查负深度与末尾非零。

四种语言

Java

class Solution {
    public int[] maxDepthAfterSplit(String seq) {
        int[] ans = new int[seq.length()];
        int depth = 0;
        for (int i = 0; i < seq.length(); i++) {
            if (seq.charAt(i) == '(') ans[i] = (++depth) & 1;
            else ans[i] = (depth--) & 1;
        }
        return ans;
    }
}

Python

from typing import List

class Solution:
    def maxDepthAfterSplit(self, seq: str) -> List[int]:
        ans, depth = [], 0
        for ch in seq:
            if ch == '(':
                depth += 1
                ans.append(depth & 1)
            else:
                ans.append(depth & 1)
                depth -= 1
        return ans

C++

class Solution {
public:
    vector<int> maxDepthAfterSplit(string seq) {
        vector<int> ans(seq.size());
        int depth = 0;
        for (int i = 0; i < (int)seq.size(); ++i) {
            if (seq[i] == '(') ans[i] = (++depth) & 1;
            else ans[i] = (depth--) & 1;
        }
        return ans;
    }
};

替代方案

可直接按字符下标奇偶分组：有效括号串中每对匹配括号的下标奇偶相反，而字符也相反，使用 (i & 1) 与括号方向组合能得到等价方案。但“深度奇偶”更直观、证明也更贴近目标。

面试追问

  • 若拆成 k 组？按深度对 k 取模，最优上界是 ceil(D/k)。
  • 如何在线处理？只需维护当前深度，可流式输出分组。
  • 输入不保证有效时？扫描中深度不得为负，结束必须回到 0。

常见错误

  • 右括号先减深度再分组，导致与匹配左括号落入不同组。
  • 按连续区间切两半；子序列可能不合法，也无法均衡深层嵌套。
  • 误以为需要显式栈；这里只需要栈的高度。
  • 只让两个组数量相等，数量平衡不等于深度最小。
