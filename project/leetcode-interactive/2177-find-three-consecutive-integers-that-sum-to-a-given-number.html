04 / 独立题解

准备好后，再展开数学推导与代码。

核心洞察：中间数决定全部

设中间整数为 x，三数就是 x − 1、x、x + 1。左右两侧的 −1 和 +1 相互抵消，总和恰好是 3x。因此存在答案的充要条件是 num 能被 3 整除。

完整过程

  1. 计算 num % 3；余数不为 0 时，返回空数组。
  2. 余数为 0 时，令 x = num / 3。
  3. 返回 [x − 1, x, x + 1]，天然满足升序。

例如 num = 33：先分成 11、11、11，再从左格转移 1 到右格，得到 10、11、12。num = 4 的平均数不是整数，无法形成以整数为中心的三连数。

正确性证明

必要性：任意三个升序连续整数均可写成 x − 1、x、x + 1，其中 x 为整数。它们的和为 3x，所以 num 必须能被 3 整除。

充分性：若 num 能被 3 整除，则 x = num / 3 是整数。构造的三个整数相邻差为 1、严格递增，且和为 3x = num，因此满足要求。否则由必要性可知无解，返回空数组正确。x 被 num 唯一确定，所以答案也是唯一的。

边界与数值类型

  • num = 0 仍有答案 [-1,0,1]；题目没有要求结果非负。
  • Java 使用 long、C++ 使用 long long；32 位整数无法容纳 1015。
  • JavaScript 的 Number 安全整数上限为 253 − 1，高于本题上界。此处的取余、整数商与相邻结果均在安全范围；不要用位运算截断成 32 位整数。
  • Python 使用整数除法 //，避免得到浮点数。

复杂度

固定次数算术操作，时间 O(1)；辅助空间 O(1)，返回数组最多 3 个元素。这里采用固定宽度整数运算模型。

替代方案

设最小数为 a，可得 3a + 3 = num，即 a = num / 3 − 1，与中间数法等价。枚举中间数最坏需要 O(num) 时间；也能利用 3x 的单调性做 O(log num) 二分，但直接求商更简单。

四语言完整提交代码

Java

class Solution {
    public long[] sumOfThree(long num) {
        if (num % 3 != 0) return new long[0];
        long x = num / 3;
        return new long[]{x - 1, x, x + 1};
    }
}

JavaScript

/**
 * @param {number} num
 * @return {number[]}
 */
var sumOfThree = function(num) {
    if (num % 3 !== 0) return [];
    const x = num / 3;
    return [x - 1, x, x + 1];
};

常见错误

  • 先取整再构造，却没有检查余数，会为不可解输入返回错误答案。
  • 把“整数”理解成“正整数”，错误拒绝 num = 0 或 num = 3。
  • 使用 int、parseInt 或位运算处理大数，造成溢出或精度范围误用。
  • 返回 [x, x + 1, x + 2]，其总和变成 num + 3。

面试追问

如何推广到 k 个连续整数？设起点为 a，总和为 ka + k(k − 1)/2，因此检查 num − k(k − 1)/2 是否能被 k 整除，再求出 a。构造结果需要 O(k) 时间和输出空间；注意乘法溢出。

若结果要求非负？在可整除之外增加 x ≥ 1，即 num ≥ 3；若要求严格正数，则需 x ≥ 2，即 num ≥ 6。

若输入超过 JavaScript 安全整数范围？在输入阶段直接从十进制字符串构造 BigInt，使用 3n、1n 等同类型运算，并约定输出如何序列化，不能先转成 Number 再补救。
