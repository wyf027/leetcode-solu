有限重边的最小阈值路径

选择最小阈值 T，让 source 到 target 的某条路径中，权重大于 T 的“重边”数量不超过 k。

题意

无向带权图有 n 个节点。边 [u, v, w] 在阈值 T 下：轻边当且仅当 w ≤ T，否则是重边。返回使有效路径存在的最小整数 T；完全不可达返回 -1。

示例：n = 6，source = 0，target = 3，k = 1。当 T = 4，路径 0 → 1 → 4 → 3 仅含一条权重 5 的重边，答案为 4。

约束：n、edges.length 均至多 10³，边权可到 10⁹。

交互：检查一个阈值

准备就绪：T = 4。

题解：二分阈值 + 0-1 BFS

单调性：若 T 可行，任意更大阈值只会把重边变轻边，因此仍可行。只需在 0..maxWeight 上二分。

  1. 固定 T：轻边代价 0，重边代价 1。
  2. 用 deque 做 0-1 BFS，求每个点最少要走多少条重边。
  3. dist[target] ≤ k 即 T 可行；二分第一個可行 T。

复杂度：每次检查 O(n + m)，二分 O(log W)，总计 O((n + m) log W)，空间 O(n + m)。

边界与替代方案

  • source = target 时无需边，答案是 0。
  • 若最大阈值也不可达，返回 -1。
  • 可对不同边权排序后二分，或用 Dijkstra 替代 0-1 BFS；本题 0/1 代价下 deque 更直接。

面试追问与常见错误

  • 为什么普通 BFS 不够？它不能优先扩展重边数更少的状态。
  • 不要把路径长度当作目标；优化的是重边数。
  • 二分前不要遗漏图断开的情形。
