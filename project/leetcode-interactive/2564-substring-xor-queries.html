子字符串
异或查询

在一条二进制字符串里，为每个异或条件找出最短、最靠左的那段连续字符。先理解目标，再动手揭开题解。

位运算数组哈希表字符串非付费题
01 / PROBLEM

题目要求

官方函数：substringXorQueries

给定二进制字符串 s 与二维整数数组 queries，其中每个查询为 [first, second]。请寻找 s 的一个非空连续子字符串，其二进制值记为 val，并满足：

val ^ first == second

对每个查询返回子字符串的 0 下标端点 [left, right]。答案必须长度最短；长度相同时选择 left 最小的；不存在则返回 [-1, -1]。

返回形式
ans[i] = [leftᵢ, rightᵢ]，与 queries[i] 一一对应。

约束

  • 1 ≤ s.length ≤ 10⁴
  • s[i] 只能是 '0' 或 '1'
  • 1 ≤ queries.length ≤ 10⁵
  • 0 ≤ firstᵢ, secondᵢ ≤ 10⁹

示例 1

输入：s = "101101",
queries = [[0,5],[1,2]]
输出：[[0,2],[2,3]]

"101" = 5，有 5 ^ 0 = 5；"11" = 3，有 3 ^ 1 = 2。

示例 2

输入：s = "0101",
queries = [[12,8]]
输出：[[-1,-1]]

不存在满足异或条件的子字符串。

示例 3

输入：s = "1",
queries = [[4,5]]
输出：[[0,0]]

"1" = 1，且 1 ^ 4 = 5。

04 / SOLUTION

预处理所有可用值

O(30n + q)

核心洞察

异或等式可直接移项：每个查询需要的子串值唯一确定为 target = first ^ second。因为输入均不超过 10⁹，目标最多 30 个二进制位，所以只需预处理每个起点向右最多 30 位的取值。

正数的最短二进制表示不会以 0 开头；遇到 0 时只记录单字符值 0。其余起点必须是 1。

完整过程

  1. 建立“十进制值 → 端点”的哈希表。
  2. 从左到右枚举起点。若字符为 0，只尝试 [i,i]；否则向右扩展至多 30 位，并增量计算值。
  3. 某个值第一次出现时保存端点，之后不覆盖。
  4. 对查询计算 first ^ second，从表中 O(1) 取答案；缺失则返回 [-1,-1]。

正确性

  1. 覆盖性：任何查询目标不超过 30 位。其最短表示若为正数必以 1 开头，扫描会枚举到；目标为 0 时单字符 0 已被枚举。
  2. 最短性：正数去掉前导零后值不变且更短，因此只考虑以 1 开头的表示即可；同一正数的无前导零二进制长度唯一。0 的最短表示长度为 1。
  3. 最靠左：起点按升序扫描，哈希表只保留首次出现，所以保存的是最小左端点。
  4. 查询正确：val ^ first = second 当且仅当 val = first ^ second，查表所得端点恰好满足原式。

边界与复杂度

  • 全是 0：值 0 只保留最左单字符。
  • 重复值：不覆盖首次记录。
  • 目标不存在：返回 [-1,-1]。
  • 长度小于 30：自然在字符串末尾停止。
  • 预处理时间 O(30n)，查询时间 O(q)，空间 O(30n)。

替代方案

逐查询扫描所有子串会接近 O(q · n · 30)，在 10⁵ 个查询下不可行。也可先收集所有查询目标，再仅记录这些值，能降低部分空间，但增加集合判断与实现复杂度；本题直接预处理更清晰。

面试追问

  • 若查询值上界变成 64 位，应把窗口改为 64，并使用 64 位整数。
  • 为什么前导零可以跳过？它不会改变值，却一定让子串更长。
  • 若要求返回所有最短端点，可让哈希值保存端点列表。

常见错误

  • 直接寻找 second，忘记目标是 first ^ second。
  • 枚举前导零子串，既浪费时间又可能覆盖更短答案。
  • 重复值时覆盖已有端点，破坏“最小 left”。
  • JavaScript 使用字符串拼接转整数，产生额外开销。

Java

可提交
class Solution {
    public int[][] substringXorQueries(String s, int[][] queries) {
        java.util.Map<Integer, int[]> pos = new java.util.HashMap<>();
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '0') {
                pos.putIfAbsent(0, new int[]{i, i});
                continue;
            }
            int value = 0;
            for (int j = i; j < s.length() && j < i + 30; j++) {
                value = (value << 1) | (s.charAt(j) - '0');
                pos.putIfAbsent(value, new int[]{i, j});
            }
        }

        int[][] ans = new int[queries.length][2];
        for (int i = 0; i < queries.length; i++) {
            int[] range = pos.get(queries[i][0] ^ queries[i][1]);
            ans[i] = range == null
                ? new int[]{-1, -1}
                : new int[]{range[0], range[1]};
        }
        return ans;
    }
}

/**
 * @param {string} s
 * @param {number[][]} queries
 * @return {number[][]}

var substringXorQueries = function(s, queries) {
    const pos = new Map();
    for (let i = 0; i < s.length; i++) {
        if (s[i] === "0") {
            if (!pos.has(0)) pos.set(0, [i, i]);
            continue;
        }
        let value = 0;
        for (let j = i; j < s.length && j < i + 30; j++) {
            value = (value << 1) | Number(s[j]);
            if (!pos.has(value)) pos.set(value, [i, j]);
        }
    }
    return queries.map(([first, second]) =>
        pos.get(first ^ second) ?? [-1, -1]
    );
};

Python

from typing import List


class Solution:
    def substringXorQueries(
        self, s: str, queries: List[List[int]]
    ) -> List[List[int]]:
        pos = {}
        for left, bit in enumerate(s):
            if bit == "0":
                pos.setdefault(0, [left, left])
                continue

            value = 0
            for right in range(left, min(len(s), left + 30)):
                value = (value << 1) | int(s[right])
                pos.setdefault(value, [left, right])

        return [
            pos.get(first ^ second, [-1, -1])
            for first, second in queries
        ]

C++

可提交
class Solution {
public:
    vector<vector<int>> substringXorQueries(
        string s, vector<vector<int>>& queries
    ) {
        unordered_map<int, pair<int, int>> pos;
        for (int left = 0; left < static_cast<int>(s.size()); ++left) {
            if (s[left] == '0') {
                pos.emplace(0, make_pair(left, left));
                continue;
            }

            int value = 0;
            for (int right = left;
                 right < static_cast<int>(s.size()) && right < left + 30;
                 ++right) {
                value = (value << 1) | (s[right] - '0');
                pos.emplace(value, make_pair(left, right));
            }
        }

        vector<vector<int>> ans;
        ans.reserve(queries.size());
        for (const auto& query : queries) {
            auto it = pos.find(query[0] ^ query[1]);
            if (it == pos.end()) ans.push_back({-1, -1});
            else ans.push_back({it->second.first, it->second.second});
        }
        return ans;
    }
};
