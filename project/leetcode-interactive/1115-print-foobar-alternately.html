交替打印
FooBar

让两个异步线程共享同一个节拍：线程 A 每次打印 foo，线程 B 紧接着打印 bar，最终严格组成 n 个连续的 foobar。

MEDIUM多线程双信号量免费题

题目

给定类 FooBar 和整数 n。同一个实例会交给两个不同线程：线程 A 调用 foo(printFoo)，线程 B 调用 bar(printBar)。请补全同步逻辑，使输出无论线程如何调度，都恰好是 "foobar" 重复 n 次。

关键要求
不能只保证 foo、bar 的数量正确；顺序必须从 foo 开始，并严格一一交替。

约束

  • 1 <= n <= 1000
  • 两个方法由不同线程异步调用，共享同一个 FooBar 实例。

题解：两个信号量构成闭环

核心洞察

使用两个初值不同的同步信号：fooReady = 1、barReady = 0。唯一的许可就是接力棒：foo 获取后打印并交给 bar；bar 获取后打印并交回 foo。

不变量

任意时刻至多一个信号量可让线程前进。每次 foo 后只能轮到 bar，每次 bar 后只能轮到下一轮 foo。

完整过程

  1. 初始化 foo 许可为 1、bar 许可为 0，保证输出从 foo 开始。
  2. foo 循环 n 次：等待 foo 许可 → 打印 foo → 释放 bar 许可。
  3. bar 循环 n 次：等待 bar 许可 → 打印 bar → 释放 foo 许可。
  4. 最后一次 bar 仍会释放 foo 许可，但两个循环都结束，不会产生额外输出。

正确性证明

基础：开始只有 foo 可执行，所以首个片段必为 foo。归纳：假设第 i 轮打印了 foo；它只释放 bar，故下一个片段必为 bar。bar 完成后只释放 foo，故若还有下一轮，随后必为 foo。两个循环各执行 n 次，因此得到且仅得到 n 个连续的 foobar。

边界与复杂度

  • n = 1：一次完整交接即可结束。
  • n = 1000：同步状态仍是常数大小。
  • 时间复杂度：O(n) 次打印与同步操作；额外空间：O(1)。

替代方案

  • 条件变量 + 布尔轮次：通用但需用循环检查条件，以防虚假唤醒。
  • 锁 + Condition：Java 中表达清晰，但样板代码更多。
  • 忙等：即使配合原子变量也会浪费 CPU，通常不是好选择。

面试追问

  • 若改为三个线程依次打印 foo、bar、baz，如何扩展？——构造三个首尾相接的信号量。
  • 为什么不能只加一把互斥锁？——它只能防止同时执行，不能决定下一个获得锁的是谁。
  • 若打印回调抛出异常怎么办？——生产代码应在适当的 finally 路径处理许可，避免对端永久阻塞。

常见错误

  • 两个信号量都初始化为 1，导致开头顺序不确定。
  • 在打印前释放对方许可，可能让输出交错失序。
  • 条件变量使用 if 而非 while 检查条件。
  • 把计数器当作同步原语，产生数据竞争或忙等。

四种语言完整实现

import java.util.concurrent.Semaphore;

class FooBar {
    private final int n;
    private final Semaphore fooReady = new Semaphore(1);
    private final Semaphore barReady = new Semaphore(0);

    public FooBar(int n) { this.n = n; }

    public void foo(Runnable printFoo) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            fooReady.acquire();
            printFoo.run();
            barReady.release();
        }
    }

    public void bar(Runnable printBar) throws InterruptedException {
        for (int i = 0; i < n; i++) {
            barReady.acquire();
            printBar.run();
            fooReady.release();
        }
    }
}

class Semaphore {
  constructor(permits) { this.permits = permits; this.queue = []; }
  acquire() {
    if (this.permits > 0) { this.permits--; return Promise.resolve(); }
    return new Promise(resolve => this.queue.push(resolve));
  }
  release() {
    const next = this.queue.shift();
    if (next) next(); else this.permits++;
  }
}

class FooBar {
  constructor(n) {
    this.n = n;
    this.fooReady = new Semaphore(1);
    this.barReady = new Semaphore(0);
  }
  async foo(printFoo) {
    for (let i = 0; i < this.n; i++) {
      await this.fooReady.acquire();
      printFoo();
      this.barReady.release();
    }
  }
  async bar(printBar) {
    for (let i = 0; i < this.n; i++) {
      await this.barReady.acquire();
      printBar();
      this.fooReady.release();
    }
  }
}
from threading import Semaphore
from typing import Callable

class FooBar:
    def __init__(self, n: int):
        self.n = n
        self.foo_ready = Semaphore(1)
        self.bar_ready = Semaphore(0)

    def foo(self, printFoo: Callable[[], None]) -> None:
        for _ in range(self.n):
            self.foo_ready.acquire()
            printFoo()
            self.bar_ready.release()

    def bar(self, printBar: Callable[[], None]) -> None:
        for _ in range(self.n):
            self.bar_ready.acquire()
            printBar()
            self.foo_ready.release()
#include <condition_variable>
#include <functional>
#include <mutex>

using namespace std;

class FooBar {
private:
    int n;
    mutex m;
    condition_variable cv;
    bool fooTurn = true;

public:
    FooBar(int n) : n(n) {}

    void foo(function<void()> printFoo) {
        for (int i = 0; i < n; ++i) {
            unique_lock<mutex> lock(m);
            cv.wait(lock, [this] { return fooTurn; });
            printFoo();
            fooTurn = false;
            lock.unlock();
            cv.notify_all();
        }
    }

    void bar(function<void()> printBar) {
        for (int i = 0; i < n; ++i) {
            unique_lock<mutex> lock(m);
            cv.wait(lock, [this] { return !fooTurn; });
            printBar();
            fooTurn = true;
            lock.unlock();
            cv.notify_all();
        }
    }
};
