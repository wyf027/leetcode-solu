去除重复字母

Remove Duplicate Letters

留下每种字母的一次出现，同时守住原字符串的相对次序。你能找到所有可行结果中字典序最小的那个吗？先在实验台里观察，再决定是否展开题解。

输入s: string
输出string
长度1 ～ 104
字符集小写英文字母

Problem

题意

给定字符串 s，删除重复字母，使每个不同字母恰好保留一次。保留下来的字符必须维持它们在原字符串中的相对顺序；在全部满足条件的结果里，返回字典序最小者。

参数形式

removeDuplicateLetters(s: string) -> string

约束

  • 1 <= s.length <= 104
  • s 只包含小写英文字母 a-z。

Solution

贪心 + 单调栈

核心洞察

结果既要保持为原字符串的子序列，又要让较小字母尽量靠前。扫描到字符 c 时，如果候选序列尾部字符比 c 大，并且尾部字符在后面还会再次出现，那么现在删掉尾部字符是安全的：它可以稍后补回，而 c 能提前，从而改善字典序。

用栈保存当前候选序列，用 inStack 避免重复，用 last 记录每个字符最后出现的位置。弹栈条件必须同时满足：

stack.top > current 且 last[stack.top] > currentIndex
更小

当前字符能让前缀字典序变小。

还能补

被弹字符在后面仍有出现机会。

不重复

已经入栈的字符直接跳过。

完整过程

  1. 预处理每个字母的最后出现下标。
  2. 从左到右扫描；若当前字母已在栈中，跳过。
  3. 当栈顶更大且未来还能出现时，持续弹栈，并清除其在栈标记。
  4. 压入当前字母，并标记它已经在栈中。
  5. 扫描结束后，栈中字符顺序就是答案。

正确性说明

不重不漏：入栈标记保证每个字母最多出现一次。一个字母只有在未来仍会出现时才可能被弹出，因此所有原本存在的不同字母最终都会保留。

保持相对次序：算法只按从左到右的扫描顺序压栈，最终结果由某些原字符依次组成，所以一定是原字符串的子序列。

字典序最小：若栈顶比当前字母大且能在未来补回，交换为“当前较小字母先出现”不会破坏可行性，却严格改善最早不同位置的字符。算法穷尽所有这种安全改进。若无法弹栈，要么栈顶不大于当前字符，要么它之后不再出现；前者无需交换，后者不能交换。因此得到的可行序列无法再获得更小前缀，故为字典序最小。

复杂度与边界

时间O(n)

每个字符至多入栈、出栈各一次。

额外空间O(Σ)

Σ 为字符集大小；本题最多 26。

边界检查

  • 单字符：直接返回自身。
  • 全为同一字符：只保留一次。
  • 严格递增：不触发弹栈。
  • 严格递减且无重复：任何字符都不能弹，因为后面无法补回。
  • 重复字符已在栈中：必须跳过，不能再次压入。

class Solution {
    public String removeDuplicateLetters(String s) {
        int[] last = new int[26];
        boolean[] inStack = new boolean[26];

        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }

        StringBuilder stack = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            int index = c - 'a';
            if (inStack[index]) {
                continue;
            }

            while (stack.length() > 0) {
                char top = stack.charAt(stack.length() - 1);
                if (top <= c || last[top - 'a'] <= i) {
                    break;
                }
                inStack[top - 'a'] = false;
                stack.deleteCharAt(stack.length() - 1);
            }

            stack.append(c);
            inStack[index] = true;
        }
        return stack.toString();
    }
}

var removeDuplicateLetters = function(s) {
    const last = new Array(26).fill(-1);
    const inStack = new Array(26).fill(false);

    for (let i = 0; i < s.length; i++) {
        last[s.charCodeAt(i) - 97] = i;
    }

    const stack = [];
    for (let i = 0; i < s.length; i++) {
        const c = s[i];
        const index = c.charCodeAt(0) - 97;
        if (inStack[index]) continue;

        while (
            stack.length > 0 &&
            stack[stack.length - 1] > c &&
            last[stack[stack.length - 1].charCodeAt(0) - 97] > i
        ) {
            const removed = stack.pop();
            inStack[removed.charCodeAt(0) - 97] = false;
        }

        stack.push(c);
        inStack[index] = true;
    }
    return stack.join('');
};
class Solution:
    def removeDuplicateLetters(self, s: str) -> str:
        last = {char: index for index, char in enumerate(s)}
        in_stack = set()
        stack = []

        for index, char in enumerate(s):
            if char in in_stack:
                continue

            while (
                stack
                and stack[-1] > char
                and last[stack[-1]] > index
            ):
                in_stack.remove(stack.pop())

            stack.append(char)
            in_stack.add(char)

        return "".join(stack)
class Solution {
public:
    string removeDuplicateLetters(string s) {
        vector<int> last(26, -1);
        vector<bool> inStack(26, false);

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            last[s[i] - 'a'] = i;
        }

        string stack;
        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            char c = s[i];
            int index = c - 'a';
            if (inStack[index]) continue;

            while (!stack.empty() &&
                   stack.back() > c &&
                   last[stack.back() - 'a'] > i) {
                inStack[stack.back() - 'a'] = false;
                stack.pop_back();
            }

            stack.push_back(c);
            inStack[index] = true;
        }
        return stack;
    }
};

替代方案

递归贪心：在保证后缀仍包含全部不同字符的前提下，从可选前缀中挑最小字符作为首字符，再递归处理其后缀，并移除该字符的重复项。

思路直观，但反复构造子串可能达到 O(n²)，也更难写得稳健。

面试追问

  • 为什么弹栈必须检查“未来还会出现”？
  • 若字符集扩展为 Unicode，数据结构如何调整？
  • 能否把 last 改为剩余频次？
  • 这和普通单调栈有哪些相同与不同？

常见错误

  • 仅因栈顶更大就弹出，导致某字母永久丢失。
  • 弹栈后忘记清除 inStack 标记。
  • 当前字母已存在时仍重复压栈。
  • 把“排序去重”误当答案，破坏子序列约束。
  • 用 >= 替代 >，混淆重复字符处理。
