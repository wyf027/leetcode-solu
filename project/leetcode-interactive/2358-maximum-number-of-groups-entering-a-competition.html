分组的最大数量

Maximum Number of Groups Entering a Competition

人数与总分都要逐组上升。你能安排多少组？

先读题，再探索题解默认收起仅生成 · 待补验证

01 / 题目

给定正整数数组 grades，每个元素是一名大学生的成绩。把所有学生分到若干个有先后顺序的非空组中，每名学生恰好进入一个组。对于任意相邻两组，后一组必须同时满足：

  1. 学生人数严格大于前一组；
  2. 学生成绩之和严格大于前一组。

返回能组成的最大组数。学生可以重新安排，不要求保持原数组顺序，也不要求使用原数组的连续区间。

参数与返回值

maximumGroups(grades)：输入整数数组，返回整数；要求输出组数，无需输出具体分组。

约束

  • 1 ≤ grades.length ≤ 10⁵
  • 1 ≤ grades[i] ≤ 10⁵

04 / 解题工作台

准备好后，展开交互演示、证明与四语言实现。

核心洞察：最少的人，尽可能多的组

若有 k 组，人数至少是 1、2、…、k，所以至少需要 k(k+1)/2 名学生。这个上界真的能达到：将成绩升序排列，依次取 1、2、…、k 人，多余的人全部加入最后一组。因为成绩为正数，后一组的人更多、各对应成绩不小于前组，所以总分也严格更大。

答案 = 最大的 k，使 1 + 2 + … + k ≤ n

排序用于构造和证明；提交代码只需读取数组长度，不需要排序，也不需要计算成绩总和。

交互演示 / 学生排队，逐层入组

先排序，再观察人数阶梯和成绩总和，最后把余量并入末组。此演示仅接收 1–60 名学生，便于逐个展示；提交代码支持官方完整范围。

示例：[8,8,8]。每项必须是 1–100000 的整数。编辑后点击“应用数组”。

完整过程

  1. 读取 n = grades.length，令已组成组数 k = 0，剩余人数 remaining = n。
  2. 如果 remaining ≥ k + 1，则还有足够的人组成下一组：先增加 k，再从 remaining 减去 k。
  3. 重复直到剩余人数不足以组成下一组，返回 k。
  4. 若需要实际分组：升序排序后取人数 1 到 k 的连续块，将不足 k + 1 的剩余学生并入第 k 组。

例如 n = 8：依次使用 1、2、3 人，剩 2 人，不够再组 4 人。把这 2 人并入末组，最终人数为 1、2、5，答案仍是 3。

正确性证明

上界：任意可行的 k 组，设人数为 c₁ < c₂ < … < cₖ。每组非空且人数是整数，因此 cᵢ ≥ i，进而 n ≥ 1 + … + k。大于此上界的组数不可能实现。

可达：将成绩升序排列，先按 1、2、…、k 人切分。对于大小为 i 和 i+1 的相邻组，后一组任选 i 个元素与前组逐一配对，后一组每个对应元素都不小于前组元素；另有一个正成绩元素，所以后一组总和严格更大。

余量：所有剩余学生加入最后一组，只会增加它的人数和总分，不影响前面的组。k=1 时无需相邻比较。因此所有学生均被安置，且上界可达。

循环：每完成一轮，已使用人数等于 1 + … + k。停止时剩余人数小于 k+1，即无法达到下一组三角数门槛，故返回的 k 正是最大可行组数。

边界与复杂度

  • n=1 或 n=2：答案均为 1；n=3：答案为 2。
  • 全员同分仍能分多组，因为正分值乘以严格递增的人数，也严格递增。
  • n 正好为三角数时，余量为 0；不足下一门槛时，余量归最后一组。
  • n=100000：T₄₄₆=99681，T₄₄₇=100128，所以答案为 446。
  • 若允许 0 或负分，严格总分增长的证明不再适用；例如 [0,0,0] 不能分两组。官方约束保证正数。

提交算法：时间 O(√n)，额外空间 O(1)，不修改输入。循环最多执行 446 次；不计平台读入数组的成本。

演示构造：排序需 O(n log n) 时间，保留排序副本需 O(n) 空间，与仅求组数的提交算法不同。

四语言完整提交代码

均采用相同的整数减法循环，无浮点精度或乘法溢出问题。以下代码尚未运行。

Java

class Solution {
    public int maximumGroups(int[] grades) {
        int remaining = grades.length;
        int groups = 0;
        while (remaining >= groups + 1) {
            groups++;
            remaining -= groups;
        }
        return groups;
    }
}

替代方案

  • 二分答案：在 [0,n] 中找满足 k(k+1)/2 ≤ n 的最大 k。时间 O(log n)、额外空间 O(1)。Java/C++ 应用 64 位整数计算乘积，因为搜索过程中的 k 可能很大。
  • 公式：k = floor((√(8n+1)−1)/2)，按固定宽度运算模型为 O(1) 时间和空间。泛化到大整数时需处理浮点误差，可用整数不等式对候选值校正；Python 可使用整数平方根。
  • 排序并构造：若题目要求返回每组学生，排序后构造即可，时间 O(n log n)，保存分组结果需 O(n) 空间。

常见错误

  • 只检查成绩和，忘记人数也必须严格递增。
  • 把原数组顺序当作不可更改，直接切分后错误判断无解。
  • 将不够新建一组的余量丢弃，违反“所有学生都要入组”。
  • 把总分递增当作平均分递增；题目没有平均分要求。
  • 用 remaining > groups + 1，导致恰好够一组时少算，条件应为 ≥。
  • 为只返回组数的任务进行排序，增加时间成本并可能修改输入。

面试追问

为什么成绩数值不影响答案？正数与可重排保证人数上界可构造；数值只影响具体组内成员和总分。

如果必须保留学生原顺序？排序构造失效，单看长度不够。例如 [100,1,1] 按连续块分成 1 人、2 人时，总分不递增。

如果要求输出原学生编号？将成绩和原下标配对排序，再按上述分组规模分配，返回下标列表。

若成绩全部相同？只要成绩严格为正，仍只由人数决定；[8,8,8] 可组成 [8] 和 [8,8]。
