2411. 按位或最大的
最小子数组长度

Smallest Subarrays With Maximum Bitwise OR

固定每一个起点，先追求最大的按位或值，再追求最短的长度。

先读题、自己思考。算法与交互演示收在页面底部，按需展开。

LeetCode 官方题目 ↗

01 / PROBLEM

题意与约束

给定一个由非负整数组成、下标从 0 开始的数组 nums。对每个起点 i，考虑所有连续非空子数组 nums[i...j]（i ≤ j < n）。在按位或结果达到该起点所能取得的最大值的子数组中，返回最短长度。

返回长度为 n 的整数数组 answer，其中 answer[i] = j - i + 1。最大值是针对每一个起点分别定义的，不能要求所有起点达到全数组的按位或值。

按位或 |：对应二进制位中，只要至少一个是 1，结果该位就是 1。例如 1 | 2 = 01₂ | 10₂ = 11₂ = 3。

  • n == nums.length
  • 1 ≤ n ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁹

参数：nums: integer[]；返回值：integer[]；函数：smallestSubarrays(nums)。

04 / SOLUTION LAB

独立题解

展开后包含交互演示、证明、四语言代码及面试延伸。

核心洞察：每个二进制位，只需找到最近的 1

向右扩展只会增加为 1 的位，不会清除已有的位。因此起点 i 的最大或值就是整个后缀 nums[i...n-1] 的或值。对于这个后缀中出现过的每一位 b，记其最早出现位置为 near[b]，那么右端点必须至少到达这些位置中的最大值。

r = max(i, 所有 near[b] ≠ -1 的位置)
answer[i] = r - i + 1

从右向左扫描，遇到 nums[i] 的某一位为 1，就把那一位的最近位置更新成 i。其他位保留右侧已知的最近位置。

交互实验 · 位的最近位置接力

每个起点分两步：更新位位置 → 确定右端点。绿色表示候选区间，粗边框表示起点，金色表示最短右端点。表格按位展示“还要走到哪里”。

值域仍为 0～10⁹。16 个元素仅是演示显示限制，提交代码支持题目完整规模。

完整过程

  1. 建立 30 个最近位置，初始都是 -1（该位尚未出现）。
  2. 从 i = n - 1 扫描到 0，先令 r = i，保证子数组非空。
  3. 遍历 b = 0...29：若当前数的第 b 位为 1，则令 near[b] = i；同时让 r = max(r, near[b])。
  4. 填入 answer[i] = r - i + 1，最终按原下标顺序返回。

例如 nums = [1,0,2,1,3]：在起点 2，位 0 最近在位置 3，位 1 最近在位置 2，所以右端点取 3，长度是 2。移到起点 1，当前数是 0，位位置保持不变，长度变为 3。

正确性证明

  1. 最近位置不变式：处理起点 i 前，数组记录后缀 i+1 内每一位的最早位置。当前数有该位时更新为 i，否则保留；所以处理后恰好得到后缀 i 内每一位的最早位置。由逆序归纳成立。
  2. 必要性：后缀最大或值里的每一个 1 都必须被覆盖。若右端点小于某个位的最早位置，就缺少该位，无法达到最大值。因此任何有效右端点都至少为 r。
  3. 充分性：到达 r 后，每个出现过的位至少包含一次，所得或值等于后缀或值。后缀没有的位也不可能凭空出现。
  4. 最短性：r 满足必要下界且可行，因此长度 r-i+1 最小。若后缀全为零，r=i，长度 1 是最短非空长度。

边界与复杂度

  • 单元素：始终返回 [1]。
  • 全零：每个答案都是 1，不能返回 0。
  • 重复值：当前元素可能已经覆盖后缀全部位。
  • 10⁹ < 2³⁰，只需第 0～29 位。
  • 时间 O(30n)，固定值域下为 O(n)。
  • 辅助空间 O(30)；包含输出为 O(n + 30)。可视化为回放存储快照，不代表提交代码空间。

替代方案

  • 暴力枚举右端点：先求后缀或，再逐个扩展直到达到目标；最坏 O(n²)。
  • 按位计数的滑动窗口：利用目标后缀或值，删除左侧元素时减少每位计数，窗口或值由正计数位组成，可做到 O(30n)，但状态更多。
  • 区间或查询 + 二分右端点：满足目标的谓词单调；用线段树可做到 O(n log²n) 时间、O(n) 空间，适合已有区间查询结构的场景。

常见错误

  • 把整个数组的或值当作每个起点的目标：例如 [1,2] 的起点 1 只能得到 2。
  • 取最近位置的最小值：会漏掉较晚才出现的其他位，必须取最大值。
  • 累计按位或后用异或删除元素：OR 不可逆，重复出现的位会丢失。
  • 令 r=-1 且忘记非空条件：全零时会算错。
  • JavaScript 位运算会转为有符号 32 位整数；本题值域只用低 30 位，适用。扩大到更高整数时应改用 BigInt 并统一操作数类型。

四语言完整提交代码

均采用相同的逆序最近位置算法；以下代码未执行验证。

Java

import java.util.Arrays;

class Solution {
    public int[] smallestSubarrays(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];
        int[] near = new int[30];
        Arrays.fill(near, -1);
        for (int i = n - 1; i >= 0; i--) {
            int r = i;
            for (int b = 0; b < 30; b++) {
                if ((nums[i] & (1 << b)) != 0) {
                    near[b] = i;
                }
                r = Math.max(r, near[b]);
            }
            answer[i] = r - i + 1;
        }
        return answer;
    }
}

from typing import List

class Solution:
    def smallestSubarrays(self, nums: List[int]) -> List[int]:
        answer = [0] * len(nums)
        near = [-1] * 30
        for i in range(len(nums) - 1, -1, -1):
            r = i
            for b in range(30):
                if nums[i] & (1 << b):
                    near[b] = i
                r = max(r, near[b])
            answer[i] = r - i + 1
        return answer

#include <algorithm>
#include <array>
#include <vector>

class Solution {

    vector<int> smallestSubarrays(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        vector<int> answer(n);
        array<int, 30> near;
        near.fill(-1);
        for (int i = n - 1; i >= 0; --i) {
            int r = i;

                    near[b] = i;
                }
                r = max(r, near[b]);
            }
            answer[i] = r - i + 1;
        }
        return answer;
    }
};

面试追问

  • 为什么不能遇到非零就停止？非零只说明某些位已出现，后面可能还有新的位。
  • 如何返回子数组区间？记录 [i, i + answer[i] - 1] 即可，直接复制所有子数组可能产生二次规模输出。
  • 如果数字有 W 位？使用 W 个位置，复杂度为 O(nW)；选用支持该宽度的整数类型。
  • 能原地写回 nums 吗？逆序时读取完 nums[i] 的全部位后可以覆写该位置，后续只依赖 near；但这会修改调用者输入，应说明契约。
  • 若改成按位 AND？直接套用 OR 的“最大后缀”目标不成立。非负数的 AND 扩展不增，追求最大 AND 的最短子数组就是当前单元素；追求最小 AND 才需分析每位最近的 0。
