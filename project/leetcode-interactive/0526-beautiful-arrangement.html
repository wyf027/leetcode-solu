优美的排列
Beautiful Arrangement

一场关于“位置”和“数字”彼此整除的排列实验。先亲手走过搜索树，再决定是否揭开位掩码动态规划的答案。

中等位运算动态规划回溯位掩码

题目

有从 1 到 n 的 n 个整数。把它们排成下标从 1 开始的排列 perm。对每个位置 i，若 perm[i] % i === 0 或 i % perm[i] === 0，这个排列就是“优美的排列”。给定 n，返回所有优美排列的数量。

函数形式：countArrangement(n: integer) → integer

约束

  • 1 ≤ n ≤ 15
  • 每个数字恰好使用一次。
  • 所有位置都必须满足至少一种整除关系。

关键不是生成全部 n! 个排列后再检查，而是在数字放入某个位置的当下剪枝。

官方示例

输入： n = 2
输出： 2
解释：
[1, 2]：1↔1、2↔2 均满足
[2, 1]：2 可放位置 1，1 可放位置 2
输入： n = 1
输出： 1

核心洞察

状态只需要记录“哪些数字已经用过”

若掩码 mask 中有 k 个二进制位为 1，下一步固定填写位置 pos = k + 1。因此无需把位置放进状态。枚举未使用数字 x，仅当 x % pos == 0 || pos % x == 0 时转移。

dp[mask] 表示：恰好使用 mask 中数字，填好前 popcount(mask) 个位置的合法方案数。

完整过程

  1. 建立大小为 2^n 的数组，令 dp[0] = 1。
  2. 遍历每个 mask，由其置位数量得到待填位置 pos。
  3. 枚举数字 x=1..n；跳过已使用数字和不满足整除条件的数字。
  4. 把当前方案数累加到 dp[mask | (1 << (x-1))]。
  5. 答案为全部 n 位均置 1 的状态。

正确性证明

不遗漏

任一优美排列的每个前缀都满足局部条件。算法会沿排列顺序选择对应数字，因此它必能到达满掩码。

不误计

转移只加入未使用且与当前位置满足整除关系的数字，所以到达满掩码的每条路径都是优美排列。

不重复

一条状态转移路径唯一决定各位置所选数字；不同排列至少有一个位置不同，对应不同路径。

由以上三点，满掩码累计值恰好等于优美排列总数。

复杂度与边界

  • 时间：O(n · 2^n)
  • 空间：O(2^n)
  • n = 1 时仅有 [1]。
  • n = 15 时共有 32768 个状态，适合位掩码。

替代方案

回溯同样可行：按位置递归并用布尔数组去重，满足关系才深入。它更直观，也便于先预计算每个位置的候选数字；但最坏复杂度以阶乘规模描述，状态 DP 的上界更稳定。

常见错误

  • 把数组的 0 下标直接当作题目中的位置，导致除数偏移。
  • 只检查 x % pos == 0，漏掉 pos % x == 0。
  • 用 mask 的置位数作为位置，却忘记再加 1。
  • 更新状态时覆盖而不是累加方案数。
  • 原地遍历若方向或状态定义不清，可能重复消费新状态；这里每次只增加一个置位，按 mask 递增是安全的。

面试追问

  • 如何改成输出一个具体排列？为首次到达的状态记录父状态和选择。
  • 如何加入“相邻数字不能相等/需满足关系”？相邻约束需要把最后一个数字加入状态。
  • 为什么不需要保存 pos？因为 pos 可由 popcount(mask)+1 唯一确定。
  • 能否优化常数？预先为每个位置计算可选数字掩码，再迭代其低位。

四语言完整实现

Java
class Solution {
    public int countArrangement(int n) {
        int size = 1 << n;
        int[] dp = new int[size];
        dp[0] = 1;
        for (int mask = 0; mask < size; mask++) {
            int pos = Integer.bitCount(mask) + 1;
            for (int x = 1; x <= n; x++) {
                int bit = 1 << (x - 1);
                if ((mask & bit) == 0 &&
                    (x % pos == 0 || pos % x == 0)) {
                    dp[mask | bit] += dp[mask];
                }
            }
        }
        return dp[size - 1];
    }
}
JavaScript
/** @param {number} n @return {number} */
var countArrangement = function(n) {
    const size = 1 << n;
    const dp = new Int32Array(size);
    dp[0] = 1;
    for (let mask = 0; mask < size; mask++) {
        let used = 0;
        for (let bits = mask; bits; bits &= bits - 1) used++;
        const pos = used + 1;
        for (let x = 1; x <= n; x++) {
            const bit = 1 << (x - 1);
            if ((mask & bit) === 0 &&
                (x % pos === 0 || pos % x === 0)) {
                dp[mask | bit] += dp[mask];
            }
        }
    }
    return dp[size - 1];
};
Python 3
class Solution:
    def countArrangement(self, n: int) -> int:
        size = 1 << n
        dp = [0] * size
        dp[0] = 1
        for mask in range(size):
            pos = mask.bit_count() + 1
            for x in range(1, n + 1):
                bit = 1 << (x - 1)
                if not mask & bit and (x % pos == 0 or pos % x == 0):
                    dp[mask | bit] += dp[mask]
        return dp[-1]
C++
class Solution {
public:
    int countArrangement(int n) {
        int size = 1 << n;
        vector<int> dp(size);
        dp[0] = 1;
        for (int mask = 0; mask < size; ++mask) {
            int pos = __builtin_popcount((unsigned)mask) + 1;
            for (int x = 1; x <= n; ++x) {
                int bit = 1 << (x - 1);
                if (!(mask & bit) &&
                    (x % pos == 0 || pos % x == 0)) {
                    dp[mask | bit] += dp[mask];
                }
            }
        }
        return dp.back();
    }
};
