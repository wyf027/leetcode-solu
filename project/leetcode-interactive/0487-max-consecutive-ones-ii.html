487. 最大连续
1 的个数 II

在一串 0 与 1 里，你只有一次把 0 变成 1 的机会。最长的连续亮灯区间能有多长？先读题、动手观察，再按需展开完整题解。

Problem

题目描述

给定一个只包含 0 和 1 的整数数组 nums。你最多可以把其中一个 0 翻转成 1，返回经过选择后数组中连续 1 的最大个数。

“最多一次”意味着也可以不翻转；返回的是连续区间长度，而不是翻转位置。

参数

nums: integer[]

返回

integer

方法名

findMaxConsecutiveOnes

示例 1

输入
nums = [1,0,1,1,0]
输出
4
说明
翻转下标 1 的 0，可得到前四个元素连续为 1。

示例 2

输入
nums = [1,0,1,1,0,1]
输出
4
说明
翻转下标 4 的 0，末尾形成长度为 4 的连续段。

约束

  • 1 ≤ nums.length ≤ 105
  • nums[i] 只能是 0 或 1

Solution

滑动窗口：只容纳一个 0

核心洞察

翻转至多一个 0，等价于寻找一个最多包含一个 0 的最长连续子数组。因此可以维护左右边界 left、right 和窗口中的 0 的数量。

完整过程

  1. 让右边界从左向右扫描；若新元素为 0，就把窗口内的 0 计数加一。
  2. 若窗口中出现两个 0，持续移动左边界；移出的元素为 0 时，将计数减一。
  3. 收缩结束后，窗口至多含一个 0，它的整个长度都能在“最多翻转一次”后成为连续 1。
  4. 用当前窗口长度更新历史最大值，扫描结束后返回它。

正确性证明

不变式：每轮右边界处理并完成收缩后，窗口 [left, right] 至多包含一个 0；同时，left 是让当前右端点满足条件的最小可行左边界。

可行性：窗口若没有 0，本来就全是 1；若恰有一个 0，翻转它后整个窗口全为 1，所以记录的每个长度都可实现。

最优性：任意合法连续段至多包含一个 0。当其右端点被扫描到时，算法保留了以该端点结尾的最长合法窗口，因此算法记录的最大值不会小于最优段长度。结合可行性，最终答案恰为最优值。

时间复杂度O(n)每个下标至多被左右边界各访问一次。
额外空间O(1)只维护边界、计数和答案。

边界情况

  • 全为 1：无需翻转，答案就是数组长度。
  • 全为 0：非空数组中至多能得到一个 1，答案为 1。
  • 数组只有一个元素：无论是 0 还是 1，答案都是 1。
  • 两个 0 相邻：窗口收缩仍按 0 的数量判断，不需要特殊分支。

替代方案：双状态动态规划

扫描到每个位置时，维护“未使用翻转、且以当前位置结尾的连续 1 长度”和“已经使用翻转、且以当前位置结尾的最长长度”。它同样是 O(n) 时间、O(1) 空间，流式输入时尤其自然；但滑动窗口更直接地表达“至多一个 0”的区间约束。

四语言完整代码

JavaLeetCode 提交形式
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        int left = 0;
        int zeroCount = 0;
        int best = 0;

        for (int right = 0; right < nums.length; right++) {
            if (nums[right] == 0) {
                zeroCount++;
            }

            while (zeroCount > 1) {
                if (nums[left] == 0) {
                    zeroCount--;
                }
                left++;
            }

            best = Math.max(best, right - left + 1);
        }

        return best;
    }
}

C++LeetCode 提交形式
class Solution {
public:
    int findMaxConsecutiveOnes(vector<int>& nums) {
        int left = 0;
        int zeroCount = 0;
        int best = 0;

        for (int right = 0; right < static_cast<int>(nums.size()); ++right) {
            if (nums[right] == 0) {
                ++zeroCount;
            }

            while (zeroCount > 1) {
                if (nums[left] == 0) {
                    --zeroCount;
                }
                ++left;
            }

            best = max(best, right - left + 1);
        }

        return best;
    }
};

面试追问

  • 如果可以翻转 k 个 0？把窗口条件改成“0 的数量不超过 k”。
  • 如果输入是无限数据流？可用双状态 DP，只保留上一时刻的两个状态与答案。
  • 如果必须恰好翻转一次？需重新处理全 1 数组；本题是“最多一次”。

常见错误

  • 窗口有两个 0 时只移动左边界一次，而不是收缩到重新合法。
  • 把答案写成 1 的计数，漏掉窗口中可翻转的那个 0。
  • 按“必须翻转”处理，导致全 1 数组错误地减一。
  • 更新答案时出现 right - left 的少 1 错误。
