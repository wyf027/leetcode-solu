      The invariant

      四步守住
      合法窗口

      不需要枚举所有子串。我们只维护“以 right 结尾的最长合法窗口”。

      1. 01

        right 读取新字符

        从左到右扫描一次，当前字符记作 c。

      2. 02

        查询最近位置

        lastSeen[c] 告诉我们冲突可能来自哪里。

      3. 03

        left 只向右跳

        left = max(left, previous + 1)，消除冲突且永不回退。

      4. 04

        刷新位置与答案

        记录 c 的新下标，用 right - left + 1 更新 best。

      The abba trap

      为什么一定要 max？

      扫到最后一个 a 时，旧 a 在下标 0，但 left 已经是 2。它早已不在窗口里。

      错误

      left = 0 + 1 = 1

      left 从 2 退回 1，窗口重新包含两个 b。

      正确

      left = max(2, 1) = 2

      窗口保持 ba，左边界单调向右。

      Q1

      子串和子序列有什么不同？

      子串必须连续。pwwkew 中 pwke 不连续，不能作为答案；wke 可以。

      Q2

      为什么是 O(n)？

      right 只走 n 步，left 也只向右；哈希表查询与更新平均 O(1)。

      Q3

      Set 解法可以吗？

      可以，用 while 逐个移除重复字符，同为 O(n)；最近位置表能一步跳转，更适合口述。

      Q4

      空间复杂度怎么说？

      最多记录窗口或已见字符，O(min(n, |Σ|))；有限字符集下可写 O(|Σ|)。

      Bug radar

      • ×把 substring 当成可以跳字符的 subsequence。
      • ×直接写 left = previous + 1，导致 left 在 abba 中后退。
      • ×先覆盖 lastSeen，再读取旧位置；或窗口长度漏掉 +1。

      Boundary deck

      "" → 0 "a" → 1 "bbbbb" → 1 "abcdef" → 6 "abba" → 2 空格/符号照常处理
      “我用 lastSeen 记录每个字符的最近下标。right 扫描字符串；若当前字符出现过，就把 left 更新为 max(left, previous + 1)，保证左边界不回退。每轮记录最新下标，并用 right - left + 1 更新答案。”
