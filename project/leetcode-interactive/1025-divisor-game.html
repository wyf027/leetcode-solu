题目

假设双方都采用最优策略，返回且仅在爱丽丝能获胜时为 true。

题解：胜负藏在奇偶里

核心洞察

偶数是必胜态，奇数是必败态。偶数时，总可以选 x = 1，把对手送入奇数；奇数的所有因数都是奇数，因此奇数减去合法因数后必为偶数。

完整过程

从终点 n = 1 出发：它没有合法的真因数，是必败态。随后利用奇偶转换关系，所有偶数都有一步到奇数，而所有奇数只能走到偶数。于是只需判断 n % 2 == 0。

正确性证明

  1. 基础：n = 1 时无合法操作，当前玩家失败；1 是奇数。
  2. 偶数局面：1 是任何偶数的合法真因数。当前玩家选择 1 后得到奇数，因此能把对手送入奇数局面。
  3. 奇数局面：奇数的每个因数都是奇数；奇数减奇数得到偶数，所以任何合法操作都会把对手送入偶数局面。
  4. 结合基础局面并沿状态递推，奇数均为必败态、偶数均为必胜态。因此算法返回 n 是否为偶数，结论正确。

边界与复杂度

n = 1 返回 false；n = 2 返回 true；上界 1000 不影响算法。时间复杂度 O(1)，空间复杂度 O(1)。

替代方案

可用动态规划枚举每个状态的合法因数：若能转移到任一必败态，则当前为必胜态。它更通用，但本题复杂度约为 O(n√n)，不如数学结论简洁。

面试追问

若只能选择质因数会怎样？若改成 n + x 是否还会终止？若两人可选择不同操作集合，奇偶不变量是否仍成立？这些变化会破坏当前证明中的哪一步？

常见错误

把 x = n 当作合法选择；忽略 n = 1；只凭样例猜偶数结论却没有证明奇数的所有合法后继；写 DP 时把“存在一个必败后继”误写成“所有后继都必败”。
