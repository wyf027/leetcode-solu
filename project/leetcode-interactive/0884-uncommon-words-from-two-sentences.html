884. 两句话中的不常见单词

Uncommon Words from Two Sentences

EASY · 简单
哈希表字符串计数

01题目

句子由单个空格分隔的单词组成，每个单词只含小写英文字母。给定两个句子 s1 和 s2，找出所有“不常见单词”：它必须在两个句子的全部单词中总共只出现一次。答案可以按任意顺序返回。

关键定义：“在一个句子中恰好一次、另一个句子中零次”等价于“合并两个句子后总词频为 1”。

函数签名

uncommonFromSentences(s1: string, s2: string): string[]

官方示例

示例 1
输入s1 = "this apple is sweet"
s2 = "this apple is sour"
输出["sweet", "sour"]

sweet 只在 s1 出现一次，sour 只在 s2 出现一次；this、apple 均出现两次。

示例 2
输入s1 = "apple apple"
s2 = "banana"
输出["banana"]

apple 在 s1 内已重复，不符合“总共只出现一次”。

约束

  • 1 <= s1.length, s2.length <= 200
  • s1 和 s2 只包含小写英文字母与空格。
  • 两个句子均无前导或尾随空格。
  • 句子中的相邻单词恰好由一个空格分隔。

04完整题解

核心洞察

不要分别讨论“在哪一句出现一次”。把两个句子的单词全部放进同一个计数表：一个词是不常见单词，当且仅当它的总词频等于 1。

完整过程

  1. 按空格拆分 s1，逐词累加到哈希表。
  2. 按空格拆分 s2，继续累加到同一张表。
  3. 遍历哈希表，把计数值等于 1 的键加入答案。
  4. 返回答案；题目允许任意顺序，因此无需排序。

正确性证明

1
计数准确。两个句子中的每次单词出现都会且只会使对应计数增加一次，因此哈希表记录的是该词在两句中的总出现次数。
2
不会漏解。若单词是不常见的，它在一句中出现一次、另一句中出现零次，总词频必为 1，所以筛选时一定被加入答案。
3
不会误收。若某词被加入答案，它的总词频为 1；唯一一次出现只能属于其中一句，另一句中出现零次，因此它满足不常见定义。

结论：算法返回且仅返回所有不常见单词。

复杂度

时间复杂度O(n + m)n、m 为两个句子的字符长度；拆词、计数和筛选均为线性量级。
空间复杂度O(k)k 为不同单词数，哈希表与答案占用额外空间。

边界情况

  • 两个句子都只有一个词：相同则答案为空，不同则两个都返回。
  • 某词仅在一个句子中出现，但出现两次或更多：不是不常见词。
  • 所有词都在两句中重复出现：返回空数组。
  • 答案顺序不固定；判断结果时应按集合比较，或先排序再比较。

四语言完整代码

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    public String[] uncommonFromSentences(String s1, String s2) {
        Map<String, Integer> frequency = new HashMap<>();

        for (String word : (s1 + " " + s2).split(" ")) {
            frequency.put(word, frequency.getOrDefault(word, 0) + 1);
        }

        List<String> answer = new ArrayList<>();
        for (Map.Entry<String, Integer> entry : frequency.entrySet()) {
            if (entry.getValue() == 1) {
                answer.add(entry.getKey());
            }
        }
        return answer.toArray(new String[0]);
    }
}
/**
 * @param {string} s1
 * @param {string} s2
 * @return {string[]}
 */
var uncommonFromSentences = function(s1, s2) {
    const frequency = new Map();

    for (const word of `${s1} ${s2}`.split(" ")) {
        frequency.set(word, (frequency.get(word) ?? 0) + 1);
    }

    const answer = [];
    for (const [word, count] of frequency) {
        if (count === 1) answer.push(word);
    }
    return answer;
};
from collections import Counter
from typing import List


class Solution:
    def uncommonFromSentences(self, s1: str, s2: str) -> List[str]:
        frequency = Counter((s1 + " " + s2).split())
        return [word for word, count in frequency.items() if count == 1]
class Solution {
public:
    vector<string> uncommonFromSentences(string s1, string s2) {
        unordered_map<string, int> frequency;
        istringstream stream(s1 + " " + s2);
        string word;

        while (stream >> word) {
            ++frequency[word];
        }

        vector<string> answer;
        for (const auto& [currentWord, count] : frequency) {
            if (count == 1) answer.push_back(currentWord);
        }
        return answer;
    }

替代方案

可以分别统计两句话，再筛选“本句计数为 1 且另一句计数为 0”的词。它同样正确，但需要两张表和两次条件判断。合并计数把定义压缩为 count === 1，实现更短且更不易漏掉“同一句内重复”的情况。

常见错误

  • 只用集合做差，丢失单句内部的重复次数；例如 apple apple 会被误判。
  • 只判断一个词是否出现在另一句，却忘记它在本句也必须恰好出现一次。
  • 强制答案排序并把排序计入必要步骤；题目已经允许任意顺序。
  • 测试时直接比较数组顺序，导致正确的不同顺序被判为失败。

面试追问

Q：如果要保持单词第一次出现的顺序？

计数完成后，再按两个句子的原始词序扫描一次，把计数为 1 的词加入答案即可。

Q：如果输入非常大，能否流式处理？

可以逐词读取并更新哈希表，但在最终输出前仍需保存不同单词的计数；若词汇空间极大，可考虑外部排序或分桶。

Q：为什么集合不够？

集合只记录“出现过”，不能区分出现一次与多次，而题目定义依赖精确频次。

Q：若要支持大小写与标点怎么办？

在计数前增加明确的规范化和分词规则，例如统一小写、按语言规则去除或保留标点；算法主体仍是计数后筛选。
