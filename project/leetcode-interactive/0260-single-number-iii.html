260. 只出现一次的数字 III

先让成对数字在 XOR 中抵消，得到两个答案的异或值；再用其中最低位的 1 把所有数字分成两个组，每组各留下一个答案。

Medium位运算XOR 分组
官方标题
Single Number III
输入
nums: int[]
硬约束
线性时间、常数额外空间

题意

给定整数数组 nums：恰好两个元素只出现一次，其他元素都出现两次。找出这两个只出现一次的元素，顺序不限。算法必须为线性时间，并只使用常数额外空间。
示例 1
nums = [1,2,1,3,2,5]
输出：[3,5]
示例 2
nums = [-1,0]
输出：[-1,0]

约束：2 ≤ nums.length ≤ 3 × 10⁴；-2³¹ ≤ nums[i] ≤ 2³¹ - 1；恰有两个元素出现一次。

题解：利用两个答案“不同的那一位”

核心洞察

所有成对数 XOR 后为 0，因此总 XOR xor = a ^ b，其中 a、b 是答案。xor 至少有一个 1 位；取 mask = xor & -xor 得到最低 1 位。a、b 在这位不同，成对元素则总会进入同一组并抵消。

完整过程

  1. 遍历所有数求总 XOR，重复数抵消为 0。
  2. 取 mask = xor & -xor。
  3. 按 (num & mask) 是否为 0 分成两组。
  4. 每组独立 XOR；最终两个累积值就是答案。
时间复杂度
O(n)，两次线性遍历。
空间复杂度
O(1)，只用常数个整数。

替代方案与取舍

哈希计数实现容易，但需要 O(n) 额外空间，违背题目约束；排序也要 O(n log n)。XOR 恰好同时满足两项要求。

边界

  • 答案可为负数，补码 XOR 仍成立。
  • 两个答案不同，故 xor != 0，mask 必存在。
  • 答案顺序不重要。
  • 重复元素一定进同一组，才会抵消。

常见错误

直接返回总 XOR 得到的是两个答案的异或，不是两个答案本身；用最高位或最低位都可以，但必须用一位为 1 的 bit 来保证答案分居两组。

面试追问

若仅有一个数出现一次，直接全体 XOR 即可；若有更多单数且没有额外频次结构，不能只靠一个 mask 恢复所有答案。

可提交代码

class Solution {
    public int[] singleNumber(int[] nums) {
        int xor = 0; for (int num : nums) xor ^= num;
        int mask = xor & -xor;
        int a = 0, b = 0;
        for (int num : nums) if ((num & mask) == 0) a ^= num; else b ^= num;
        return new int[]{a, b};
    }
}

class Solution {
public:
    vector<int> singleNumber(vector<int>& nums) {
        int xr = 0; for (int x : nums) xr ^= x;
        int mask = xr & -xr, a = 0, b = 0;
        for (int x : nums) (x & mask ? b : a) ^= x;
        return {a, b};
    }
};
