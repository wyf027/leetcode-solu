矩阵查询可获得的最大分数

Maximum Number of Points From Grid Queries

一个起点，多种阈值。低数值的格子，一定能拿到分数吗？

LeetCode 官方题目 ↗

01 / 读懂规则

题意

给定 m × n 整数矩阵 grid 和长度为 k 的查询数组 queries。每个查询都独立从左上角 (0,0) 出发，以 queries[i] 为阈值。

  • 当前格子的值严格小于阈值时，首次访问该格获得 1 分，并可继续向上、下、左、右的相邻格移动。
  • 当前格子的值大于或等于阈值时，不能得分，且这次行走终止。
  • 允许重复走过同一格，但同一查询中每格最多计 1 分。你可以选择行走路线，使得分最大。

返回 answer，其中 answer[i] 是第 i 个查询可获得的最大分数；结果顺序与输入查询顺序一致。

参数与返回值

maxPoints(grid: integer[][], queries: integer[]) → integer[]

约束

  • m == grid.length；n == grid[i].length
  • 2 ≤ m, n ≤ 1000
  • 4 ≤ m × n ≤ 10⁵
  • k == queries.length；1 ≤ k ≤ 10⁴
  • 1 ≤ grid[i][j], queries[i] ≤ 10⁶

官方示例

示例 1

输入：grid = [[1,2,3],[2,5,7],[3,5,1]]
      queries = [5,6,2]
输出：[5,8,1]

阈值为 5、6、2 时，最多分别访问 5、8、1 个可计分格子。阈值 5 时，右下角的 1 虽小，却被无法通过的格子隔开。

示例 2

输入：grid = [[5,2,1],[1,1,2]]
      queries = [3]
输出：[0]

起点的值 5 大于等于 3，无法从起点得分或继续移动。

03 / 解法与交互

离线排序 + 最小堆：让可达区域生长

核心洞察

对固定阈值 q，答案就是仅保留值小于 q 的格子后，左上角所在连通块的大小。可以反复走回已访问格子，因此一条路线能够遍历整个连通块。

阈值增大时，原来可达的格子仍然可达。将查询按值递增处理，就可以累计计分，不必每次清空搜索。用最小堆保存已发现但尚未计分的边界格子，每次尝试解锁其中值最小的格子。

完整过程

  1. 记录查询的原始下标，按阈值升序排列。
  2. 起点入最小堆并标记 seen；此时计分 count 仍为 0。
  3. 对当前 q，只要堆顶值 < q，就弹出它、计分，并将四邻域中尚未发现的格子标记并入堆。
  4. 即使邻居值 ≥ q，也保留在堆中，等待更大阈值。若堆为空或堆顶值 ≥ q，当前查询结束。
  5. 把 count 写入该查询的原始下标，继续下一个阈值。

seen 表示“已入堆”，不表示“已得分”。分数只在满足严格不等式的弹出操作发生时增加。

正确性证明
不变式：已计分格子均可由起点沿当前阈值允许的路径到达；所有已计分格子的未计分邻居都在堆中。每个格子最多入堆一次。
安全扩张：起点仅在自身值 < q 时计分。其他被弹出的格子来自已计分格子的邻居，并且自身也满足值 < q，所以延长合法路径即可到达它。算法不会多算。
完整性：停止时假设还有合法可达格子未计分。沿起点到它的合法路径，取第一个未计分格子：它是起点或已计分格子的邻居，应已在堆中，而且值 < q。这与堆空或堆顶值 ≥ q 矛盾，因此算法没有漏算。
跨查询复用：查询递增使已有合法路径继续有效；尚未计分的边界留在堆中即可继续扩张。最后依据原下标写回，得到输入顺序所要求的答案。


边界与常见错误
  • q 等于格子值时不能通过；条件必须是 <，不是 ≤。
  • 起点值 ≥ q 时答案为 0，不能从其他低值格子重新出发。
  • 重复查询直接复用 count；无须重复计分。
  • 低值孤岛可能被高值边界挡住，不能统计全矩阵中所有小于 q 的格子。
  • 入堆就标记 seen，防止多个邻居把同一个格子重复加入；不可入堆就加分。
  • 当前不可通过的边界不能丢弃；它们可能在更大的查询下解锁。
  • 查询排序后必须保存原始索引；原输入不必被修改。


复杂度
记 N = m × n。每格最多入堆、出堆一次，各需 O(log N)；查询排序 O(k log k)。总时间 O(N log N + k log k)，辅助空间 O(N + k)（堆、标记、查询顺序及答案）。


替代方案
  • 每次 BFS：每个查询独立搜索，最坏 O(kN) 时间、O(N) 工作空间。直观但本题上限下开销很大。
  • 离线并查集：格子按值排序，按查询阈值激活所有值 < q 的格子，合并已激活邻居；若起点激活，返回其连通块大小，否则返回 0。时间 O(N log N + k log k + N α(N))，空间 O(N + k)。
  • 瓶颈路径预处理：用 minimax Dijkstra 计算每格路径上最大值的最小可能值，排序这些瓶颈值后，用二分统计 < q 的数量。适合查询后续在线到达，预处理 O(N log N)，每次查询 O(log N)。


面试追问
为何不是普通 BFS 队列？较大格子可能挡在队首，而别的边界较小；最小堆可准确判断是否仍有可扩张边界。
为什么提前 seen 安全？入堆不绑定最短路径距离；格子只需要从任一已可达邻居被发现一次。
查询在线且不能重排怎么办？预处理瓶颈值并二分；直接复用递增计数无法应对阈值下降。

import java.util.*;

class Solution {
    public int[] maxPoints(int[][] grid, int[] queries) {
        int m = grid.length, n = grid[0].length;
        Integer[] order = new Integer[queries.length];
        for (int i = 0; i < order.length; i++) order[i] = i;
        Arrays.sort(order, Comparator.comparingInt(i -> queries[i]));
        PriorityQueue<int[]> heap = new PriorityQueue<>(
            Comparator.comparingInt(a -> a[0]));
        boolean[][] seen = new boolean[m][n];
        heap.offer(new int[]{grid[0][0], 0, 0});
        seen[0][0] = true;
        int[] answer = new int[queries.length];
        int[] d = {1, 0, -1, 0, 1};
        int count = 0;
        for (int i : order) {
            while (!heap.isEmpty() && heap.peek()[0] < queries[i]) {
                int[] cell = heap.poll();
                count++;
                for (int t = 0; t < 4; t++) {
                    int r = cell[1] + d[t], c = cell[2] + d[t + 1];
                    if (r >= 0 && r < m && c >= 0 && c < n && !seen[r][c]) {
                        seen[r][c] = true;
                        heap.offer(new int[]{grid[r][c], r, c});
                    }
                }
            }
            answer[i] = count;
        }
        return answer;
    }
}

var maxPoints = function(grid, queries) {
    const m = grid.length, n = grid[0].length;
    const order = queries.map((q, i) => [q, i]).sort((a, b) => a[0] - b[0]);
    const heap = [];
    function push(cell) {
        let i = heap.length;
        heap.push(cell);
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (heap[p][0] <= cell[0]) break;
            heap[i] = heap[p];
            i = p;
        }
        heap[i] = cell;
    }
    function pop() {
        const root = heap[0], last = heap.pop();
        if (heap.length) {
            let i = 0;
            while (2 * i + 1 < heap.length) {
                let child = 2 * i + 1;
                if (child + 1 < heap.length && heap[child + 1][0] < heap[child][0]) child++;
                if (last[0] <= heap[child][0]) break;
                heap[i] = heap[child];
                i = child;
            }
            heap[i] = last;
        }
        return root;
    }
    const seen = new Uint8Array(m * n);
    const answer = Array(queries.length).fill(0);
    const d = [1, 0, -1, 0, 1];
    push([grid[0][0], 0, 0]);
    seen[0] = 1;
    let count = 0;
    for (const [q, index] of order) {
        while (heap.length && heap[0][0] < q) {
            const [, r, c] = pop();
            count++;
            for (let t = 0; t < 4; t++) {
                const nr = r + d[t], nc = c + d[t + 1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && !seen[nr * n + nc]) {
                    seen[nr * n + nc] = 1;
                    push([grid[nr][nc], nr, nc]);
                }
            }
        }
        answer[index] = count;
    }
    return answer;
};

from typing import List
from heapq import heappush, heappop

class Solution:
    def maxPoints(self, grid: List[List[int]], queries: List[int]) -> List[int]:
        m, n = len(grid), len(grid[0])
        order = sorted(range(len(queries)), key=lambda i: queries[i])
        heap = [(grid[0][0], 0, 0)]
        seen = [[False] * n for _ in range(m)]
        seen[0][0] = True
        answer = [0] * len(queries)
        count = 0
        for i in order:
            while heap and heap[0][0] < queries[i]:
                _, r, c = heappop(heap)
                count += 1
                for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < m and 0 <= nc < n and not seen[nr][nc]:
                        seen[nr][nc] = True
                        heappush(heap, (grid[nr][nc], nr, nc))
            answer[i] = count
        return answer

#include <vector>
#include <queue>
#include <array>
#include <algorithm>
#include <numeric>
#include <functional>
using namespace std;

class Solution {
public:
    vector<int> maxPoints(vector<vector<int>>& grid, vector<int>& queries) {
        int m = grid.size(), n = grid[0].size();
        vector<int> order(queries.size());
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int a, int b) {
            return queries[a] < queries[b];
        });
        using Cell = array<int, 3>;
        priority_queue<Cell, vector<Cell>, greater<Cell>> heap;
        vector<vector<bool>> seen(m, vector<bool>(n, false));
        heap.push({grid[0][0], 0, 0});
        seen[0][0] = true;
        vector<int> answer(queries.size());
        int d[] = {1, 0, -1, 0, 1};
        int count = 0;
        for (int i : order) {
            while (!heap.empty() && heap.top()[0] < queries[i]) {
                auto cell = heap.top();
                heap.pop();
                ++count;
                for (int t = 0; t < 4; ++t) {
                    int r = cell[1] + d[t], c = cell[2] + d[t + 1];
                    if (r >= 0 && r < m && c >= 0 && c < n && !seen[r][c]) {
                        seen[r][c] = true;
                        heap.push({grid[r][c], r, c});
                    }
                }
            }
            answer[i] = count;
        }
        return answer;
    }
};
