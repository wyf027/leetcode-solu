计算二叉树的深度

给定一棵表示公司架构的二叉树，返回从根节点到最深叶节点路径上的节点数量。先操作扫描仪观察输入，再到页面底部决定是否展开完整题解。

Easy树 · 二叉树节点总数 ≤ 10000

题意

某公司的架构以二叉树表示。给定根节点 root，返回从根到最深叶节点经过的层级数；空树深度为 0。

官方示例：root = [1, 2, 2, 3, null, null, 5, 4, null, null, 4]，输出 4

最长路径可以是 1 → 2 → 3 → 4 或 1 → 2 → 5 → 4。层序数组中的 null 表示该位置没有节点。

怎么操作

  1. 编辑层序数组；空树填 []。
  2. “下一步”扫描下一层节点。
  3. 按 ←/→ 回退或推进，空格切换自动播放。

层级扫描仪

输入使用完整参数格式：root = [1, 2, null, 3]。空格只用于阅读，含义不变。

题解：BFS 逐层扫描

队列里始终保存“还没扫描的节点”。每次先记下当前队列大小，这正是这一层的节点数；处理完这批节点后，深度加一，子节点已排入下一层。

完整过程

  1. 若 root = null，直接返回 0。
  2. 根节点入队；每轮取出当前队列长度 size。
  3. 恰好处理 size 个节点，并把孩子入队。
  4. 这一层结束，depth += 1；队列清空时返回深度。

边界与复杂度

空树为 0，单节点为 1，偏斜树也能正常逐层计数。每个节点只进出队一次：时间 O(n)，队列额外空间 O(w)，w 为最大层宽。

替代方案与面试追问

递归 DFS 返回 max(left, right) + 1，空间为递归树高 O(h)。追问超深树时，可优先选择本页的迭代 BFS 以避免递归调用栈风险。

常见错误

  • 每弹出一个节点就加深度，误把节点数当层数。
  • 在循环中直接用不断变化的队列长度，导致跨层处理。
  • 忘记空树这一条基线。
class Solution {
  public int calculateDepth(TreeNode root) {
    if (root == null) return 0;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    int depth = 0;
    while (!queue.isEmpty()) {
      for (int size = queue.size(); size > 0; size--) {
        TreeNode node = queue.poll();
        if (node.left != null) queue.offer(node.left);
        if (node.right != null) queue.offer(node.right);
      }
      depth++;
    }
    return depth;
  }
}
var calculateDepth = function(root) {
  if (root === null) return 0;
  const queue = [root];
  let head = 0, depth = 0;
  while (head < queue.length) {
    const end = queue.length;
    while (head < end) {
      const node = queue[head++];
      if (node.left) queue.push(node.left);
      if (node.right) queue.push(node.right);
    }
    depth++;
  }
  return depth;
};
from collections import deque

class Solution:
    def calculateDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        queue, depth = deque([root]), 0
        while queue:
            for _ in range(len(queue)):
                node = queue.popleft()
                if node.left: queue.append(node.left)
                if node.right: queue.append(node.right)
            depth += 1
        return depth

    int calculateDepth(TreeNode* root) {
        if (!root) return 0;
        queue<TreeNode*> q;
        q.push(root);
        int depth = 0;
        while (!q.empty()) {
            for (int size = q.size(); size--; q.pop()) {
                TreeNode* node = q.front();
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
