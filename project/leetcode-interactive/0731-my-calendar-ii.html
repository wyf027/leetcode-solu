我的日程安排表 II

My Calendar II · 允许时间重叠两次，但绝不能让任意一个时刻同时属于三个日程。先观察预订过程，再决定是否展开题解。

半开区间 [start, end)最多 1000 次调用非付费题前缀和 / 线段树 / 有序集合
Problem

题意与官方示例

先只看规则和行为，不在首屏透露实现策略。

要实现什么？

实现 MyCalendarTwo 日历。每次收到一个由整数 startTime、endTime 表示的新日程，其覆盖范围是半开区间 [startTime, endTime)。

如果加入后不存在“三重预订”，就保存该日程并返回 true；否则返回 false，且日历状态必须保持不变。三重预订指三个日程拥有非空的共同时间段。

边界语义：[5, 10) 与 [10, 20) 不重叠，因为前一个区间不包含时刻 10。

boolean book(int startTime, int endTime)

约束

  • 0 <= startTime < endTime <= 109
  • 最多调用 book 1000 次。

示例 1 · 完整参数形式

输入：
["MyCalendarTwo", "book", "book", "book",
 "book", "book", "book"]
[[], [10, 20], [50, 60], [10, 40],
 [5, 15], [5, 10], [25, 55]]

输出：
[null, true, true, true, false, true, true]

解释：
MyCalendarTwo calendar = new MyCalendarTwo();
calendar.book(10, 20); // true
calendar.book(50, 60); // true
calendar.book(10, 40); // true，可发生双重预订
calendar.book(5, 15);  // false，会产生三重预订
calendar.book(5, 10);  // true，半开区间不含时刻 10
calendar.book(25, 55); // true

三个观察方向

拒绝条件是什么？

新日程只有在与“已经被覆盖两次”的时间段相交时，才会制造第三层覆盖。

2

什么需要被记住？

思考日历是否既要保留所有成功日程，也要保留由它们产生的双重重叠区间。

3

相交怎么计算？

两个半开区间相交当且仅当 max(a,c) < min(b,d)，严格小于号保留端点语义。

Solution

维护已预订区间与双重区间

主解选择最贴合 1000 次调用上限、也最容易证明正确的区间列表方案。

核心洞察

维护两个列表：

  • bookings：所有已经成功加入的日程。
  • overlaps：任意两条已成功日程产生的交集；其中每一段时间都至少已被覆盖两次。

面对新区间 current，先检查它是否与 overlaps 中任一区间相交。相交就意味着该交集里的时刻会被覆盖三次，必须拒绝。

left = max(start1, start2)
right = min(end1, end2)
left < right ⇔ 存在非空交集

完整过程

  1. 遍历所有双重区间；若新区间与其中任何一个相交，立即返回 false，且不修改状态。
  2. 遍历所有已接受日程，把它与新区间产生的每个非空交集加入 overlaps。
  3. 把新区间加入 bookings，返回 true。

注意顺序：必须先完成拒绝检查，再写入两个列表，才能保证失败请求没有副作用。

正确性证明

  1. 不误接收：若算法接收新区间，它与所有已有双重区间都不相交。因此不存在已被两个旧日程覆盖、又被新区间覆盖的时刻，加入后不可能出现三重预订。
  2. 不误拒绝：若算法拒绝，新区间与某个双重区间有非空交集。该交集已属于两个成功日程，再加入新区间必然出现三重预订，所以拒绝是必要的。
  3. 状态完备：接收后，算法记录新区间与每个旧日程的所有非空交集，因此新的全部双重覆盖都进入 overlaps；旧的双重覆盖仍被保留。不变式持续成立。

边界与复杂度

  • 端点相接不算重叠：判断必须使用 left < right。
  • 被拒绝的请求不能进入任何列表。
  • 重复预订相同区间：前两次可成功，第三次会被拒绝。
  • 坐标可到 109，但这里只比较端点，不开辟坐标数组。

单次调用：最坏 O(n²) 时间，n 为此前成功日程数；因为双重区间数量最坏为 O(n²)。
累计空间：O(n²)。

替代方案

  • 扫描线差分：用有序映射记录 start +1、end -1，每次暂写后扫描前缀和；若达到 3 就回滚。实现短，但单次需要遍历全部端点。
  • 动态开点线段树：区间加一并维护区间最大值，越界时回滚；适合更大调用量，复杂度约 O(log C)，但实现更长。
  • 分段有序映射：维护不相交计数段，可控制扫描范围，但拆分与合并边界更易出错。

面试追问与常见错误

可能追问：若允许最多重叠 K 次怎么办？可把扫描线阈值改为 K+1，或在线段树中拒绝最大值超过 K 的更新。若调用量到 105，应讨论动态线段树或平衡树。

常见错误：

  • 只记录日程，却对所有三元组做暴力判断。
  • 使用 <= 判相交，错误地把端点接触当重叠。
  • 先写入再发现冲突，却没有完整回滚。
  • 误以为 overlaps 必须互不相交；本方案不要求合并，重复片段也不影响正确性。

四种语言完整代码

JavaMyCalendarTwo
import java.util.ArrayList;
import java.util.List;

class MyCalendarTwo {
    private final List<int[]> bookings;
    private final List<int[]> overlaps;

    public MyCalendarTwo() {
        bookings = new ArrayList<>();
        overlaps = new ArrayList<>();
    }

    public boolean book(int startTime, int endTime) {
        for (int[] overlap : overlaps) {
            int left = Math.max(startTime, overlap[0]);
            int right = Math.min(endTime, overlap[1]);
            if (left < right) {
                return false;
            }
        }

        for (int[] booking : bookings) {
            int left = Math.max(startTime, booking[0]);
            int right = Math.min(endTime, booking[1]);
            if (left < right) {
                overlaps.add(new int[] {left, right});
            }
        }

        bookings.add(new int[] {startTime, endTime});
        return true;
    }
}

MyCalendarTwo.prototype.book = function(startTime, endTime) {
    for (const [start, end] of this.overlaps) {
        const left = Math.max(startTime, start);
        const right = Math.min(endTime, end);
        if (left < right) {
            return false;
        }
    }

    for (const [start, end] of this.bookings) {
        const left = Math.max(startTime, start);

        }

    return true;
};

#include <algorithm>
#include <utility>
#include <vector>
using namespace std;

class MyCalendarTwo {
private:
    vector<pair<int, int>> bookings;
    vector<pair<int, int>> overlaps;

public:
    MyCalendarTwo() = default;

    bool book(int startTime, int endTime) {
        for (const auto& overlap : overlaps) {
            int left = max(startTime, overlap.first);
            int right = min(endTime, overlap.second);
            if (left < right) {
                return false;
            }
        }

        for (const auto& booking : bookings) {
            int left = max(startTime, booking.first);
            int right = min(endTime, booking.second);
            if (left < right) {
                overlaps.push_back({left, right});
            }
        }

        bookings.push_back({startTime, endTime});
        return true;
    }
};
