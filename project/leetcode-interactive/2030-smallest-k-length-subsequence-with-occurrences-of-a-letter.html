含特定字母的最小子序列

Smallest K-Length Subsequence With Occurrences of a Letter

保留顺序，选够长度，也别忘了指定字母的最低配额。

题目

给定字符串 s、整数 k、小写字母 letter 和整数 repetition，从 s 中选出长度恰好为 k 的子序列，使 letter 至少出现 repetition 次，并使结果的字典序最小。

子序列允许删除字符，但不能改变保留字符的先后次序。比较字典序时，以第一个不同位置的字母顺序决定大小。输入保证指定字母数量足够。

约束

  • 1 ≤ repetition ≤ k ≤ s.length ≤ 5 × 10⁴
  • s 只包含小写英文字母。
  • letter 是一个小写英文字母，在 s 中至少出现 repetition 次。
官方题目

官方示例

s = "leet", k = 3, letter = "e", repetition = 1
输出："eet"

符合条件的四种位置选择得到 lee、let、let、eet，其中 eet 最小。

s = "leetcode", k = 4, letter = "e", repetition = 2
输出："ecde"

ecde 保留原顺序，长度为 4，包含两个 e。

s = "bb", k = 2, letter = "b", repetition = 2
输出："bb"

必须保留全部字符，只有这一种结果。

题解 · 带配额约束的贪心栈

核心洞察

尽量让前面的字符小，但每次删除都必须保证答案还能补满，并且指定字母仍够用。维护结果栈，遇到更小字符时尝试撤销栈尾。这个栈受配额约束，不保证全局单调。

状态与完整过程

  • need = repetition − 栈中 letter 数量，允许为负；负数表示已超额。
  • remaining 为未处理后缀中的 letter 数量，在处理位置 i 时包含当前字符。
  • 若栈顶大于当前字符，并且 栈长 − 1 + n − i ≥ k，删除后仍能凑够长度。
  • 若栈顶是 letter，还要满足 remaining > need，否则删除会造成指定字母短缺。弹出 letter 后 need 加一，重复判断栈顶。
  • 栈未满时，letter 可以入栈并使 need 减一；普通字符只有在 k − 栈长 > need 时才能入栈，为欠缺的 letter 预留位置。
  • 当前字符处理结束后，若它是 letter，remaining 减一。最后栈即为答案。

正确性

可完成性不变式：栈与未处理后缀总能组成合法答案。弹出前的长度闸门保证剩余字符数足够；弹出 letter 前要求 remaining ≥ need + 1，保证补回配额。普通字符入栈前预留 max(need, 0) 个位置。因此结束时栈长为 k，且 need ≤ 0。

字典序的交换论证：当当前字符小于栈顶且两个闸门都允许时，撤销较大栈尾让较小字符更早出现，且仍有合法补全，答案只能变优。若被长度或配额闸门阻止，则撤销该栈顶无法完成合法答案；若栈顶不大于当前字符，撤销不会改善第一个不同位置。依次处理并反复撤销可改进的尾部，使最终结果在所有合法选择中字典序最小。

边界与常见错误

  • k = n：长度闸门禁止删除，返回原串。
  • repetition = k：普通字符不能占用保留位置，结果全是 letter。
  • letter 总数恰好为 repetition：这些目标字符都必须保留。
  • “至少”不是“恰好”：need 可以为负，不要拒绝额外的 letter。
  • remaining 必须在本轮末尾递减；提前减会与包含当前字符的判定口径冲突。
  • 弹栈配额判断是 remaining > need，不能写成 ≥；普通字符入栈也必须使用严格大于。
  • 遇到相等字符不弹栈；只比较大小而忽视两个可行性条件会产生非法答案。

复杂度

统计后缀数量 O(n)，每个字符至多入栈和出栈各一次，总时间 O(n)，辅助空间 O(k)。交互为展示保存快照，与提交算法的空间复杂度不同。

替代方案

可预计算每个位置之后 26 个字母的下一次出现位置与目标字母后缀计数，每个答案位置从 a 到 z 尝试最早可行出现点：保留它后必须还有足够字符填满剩余位置、足够目标字母满足需求，且需求不超过剩余槽位。时间 O(26n + 26k)、空间 O(26n)。也可用高维动态规划描述位置、已选长度和目标字母配额，但本题规模下代价过高。

面试追问

  • 为什么重复弹栈仍是线性时间？用每个字符仅入栈、出栈一次做摊还分析。
  • 若要求恰好 repetition 次？还要限制目标字符入栈上限，并重新维护非目标字符的补全可行性。
  • 若多个字母各有配额？需要跟踪每种剩余需求、后缀供给及总预留槽位，单个 need 不再足够。

JavaScript

var smallestSubsequence = function(s, k, letter, repetition) {
    const stack = [];
    let remaining = 0, need = repetition;
    for (const c of s) if (c === letter) remaining++;
    for (let i = 0; i < s.length; i++) {
        const c = s[i];
        while (stack.length && stack[stack.length - 1] > c &&
               stack.length - 1 + s.length - i >= k &&
               (stack[stack.length - 1] !== letter || remaining > need)) {
            if (stack.pop() === letter) need++;
        }
        if (stack.length < k) {
            if (c === letter) { stack.push(c); need--; }
            else if (k - stack.length > need) stack.push(c);
        }
        if (c === letter) remaining--;
    }
    return stack.join('');
};

Python

class Solution:
    def smallestSubsequence(self, s: str, k: int, letter: str, repetition: int) -> str:
        stack = []
        remaining, need = s.count(letter), repetition
        for i, c in enumerate(s):
            while (stack and stack[-1] > c
                   and len(stack) - 1 + len(s) - i >= k
                   and (stack[-1] != letter or remaining > need)):
                if stack.pop() == letter:
                    need += 1
            if len(stack) < k:
                if c == letter:
                    stack.append(c)
                    need -= 1
                elif k - len(stack) > need:
                    stack.append(c)
            if c == letter:
                remaining -= 1
        return ''.join(stack)

Java

class Solution {
    public String smallestSubsequence(String s, int k, char letter, int repetition) {
        char[] stack = new char[k];
        int size = 0, remaining = 0, need = repetition, n = s.length();
        for (int i = 0; i < n; i++) if (s.charAt(i) == letter) remaining++;
        for (int i = 0; i < n; i++) {
            char c = s.charAt(i);
            while (size > 0 && stack[size - 1] > c && size - 1 + n - i >= k
                    && (stack[size - 1] != letter || remaining > need)) {
                if (stack[--size] == letter) need++;
            }
            if (size < k) {
                if (c == letter) { stack[size++] = c; need--; }
                else if (k - size > need) stack[size++] = c;
            }
            if (c == letter) remaining--;
        }
        return new String(stack, 0, size);
    }
}

C++

#include <string>
#include <algorithm>
using namespace std;
class Solution {
public:
    string smallestSubsequence(string s, int k, char letter, int repetition) {
        string st;
        int n = s.size(), need = repetition;
        int remaining = count(s.begin(), s.end(), letter);
        for (int i = 0; i < n; ++i) {
            char c = s[i];
            while (!st.empty() && st.back() > c && (int)st.size() - 1 + n - i >= k
                   && (st.back() != letter || remaining > need)) {
                if (st.back() == letter) ++need;
                st.pop_back();
            }
            if ((int)st.size() < k) {
                if (c == letter) { st.push_back(c); --need; }
                else if (k - (int)st.size() > need) st.push_back(c);
            }
            if (c == letter) --remaining;
        }
        return st;
    }
};
