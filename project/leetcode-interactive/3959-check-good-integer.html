判定好整数

拆开每一位，同时累加“数字本身”和“数字平方”；两者差值达到 50 就通过闸门。

题意

给定正整数 n。令 digitSum 为各位之和，squareSum 为各位数字平方之和。当 squareSum - digitSum ≥ 50 时，n 是好整数。

约束：1 ≤ n ≤ 109。逐位处理至多 10 次。

输入 digitSum squareSum 输出
n = 1000 1 1 false
n = 19 10 82 true

交互：拆数位

点击“生成步骤”查看每一位的贡献。

分步可视化

从最低位起使用 n % 10 取数位，再通过 n = floor(n / 10) 进入下一位。

尚未生成步骤。

核心洞察与主线算法

取最低位

digit = value % 10；它既加入数位和，也贡献 digit²。

缩短数字

整数除法 value /= 10 去掉刚处理的最低位，循环直到 value 为 0。

比较阈值

最后判断 squareSum - digitSum ≥ 50；不需要字符串或额外数组。

digitSum += digit；squareSum += digit × digit；return squareSum - digitSum ≥ 50

题解默认收起；可用 Enter 或空格展开。

题解：逐位模拟

完整过程

  1. 复制输入到工作变量 value，这样可安全地不断除以 10。
  2. 循环中取 value % 10，分别累加 digitSum 与 squareSum。
  3. 执行 value /= 10；处理完所有数位后比较差值和 50。

边界、复杂度与替代方案

n 为正，故循环至少执行一次；0 不在输入范围。时间 O(log₁₀n)，额外空间 O(1)。转为字符串也可行，但数值模拟更直接、无字符转换成本。

面试追问

若阈值变成参数，比较最后一步即可；若要求平方和本身或任意进制，只需改每次取模和整除的基数。

常见错误

不要把数字平方误写成当前整数平方；不要忘记在更新后缩短 value；不要将 squareSum ≥ 50 当作条件，必须减去 digitSum。
