题意与编码规则

以下为依据官方元数据与公开题目信息整理的中文转述。

编码最短长度的字符串

给你一个非空字符串 s。你可以把某个连续重复的字符串写成 k[encoded_string]，其中方括号内的内容恰好重复 k 次。方括号内仍可继续使用同一规则编码。

返回 s 的最短合法编码。如果一次替换不能让表示变得更短，就保留原字符串；只要求长度最短，等长答案可能不唯一。

函数签名：encode(s: string) -> string

约束

  • 1 <= s.length <= 150
  • s 只包含小写英文字母
  • 重复次数 k 为正整数
  • 输出必须能无损还原为原字符串

官方示例（完整参数形式）

输入：s = "aaa"\n输出："aaa"

没有更短的合法写法，因此不编码。

输入：s = "aaaaa"\n输出："5[a]"

5[a] 比原字符串少 1 个字符。

输入：s = "aaaaaaaaaa"\n输出："10[a]"

"a9[a]"、"9[a]a" 也同为长度 5 的最短答案。

输入：s = "aabcaabcd"\n输出："2[aabc]d"

前 8 个字符由 aabc 连续重复两次。

输入：s = "abbbabbbcabbbabbbc"\n输出："2[2[abbb]c]"

整个字符串由 abbbabbbc 重复两次，而内部还能继续折叠为 2[abbb]c。

Solution

区间动态规划：先切分，再折叠

用子串的最优答案组成更长区间，并识别整个区间是否由更短周期重复得到。

核心洞察

最短编码具有最优子结构。对任意区间 s[i..j]，一个最优答案只可能来自三类选择：原样保留；在某个位置切成两个区间并拼接它们的最优编码；若整个区间存在周期，则写成“重复次数 + 已优化周期块”。

dp[i][j] = min(raw, dp[i][k] + dp[k+1][j], count + "[" + dp[i][i+p-1] + "]")

完整过程

  1. 令 dp[i][j] 表示子串 s[i..j] 的最短编码字符串。
  2. 按区间长度从 1 到 n 枚举，先把状态初始化为原子串。
  3. 枚举切分点 k，用 dp[i][k] + dp[k+1][j] 尝试更新。
  4. 对当前子串计算 KMP 前缀函数。若 p = len - pi[len-1] 且 len % p == 0，它由长度为 p 的最小周期重复。
  5. 用 (len / p)[dp[i][i+p-1]] 尝试更新；只有严格更短才替换，避免无收益编码。

正确性证明

命题：dp[i][j] 是 s[i..j] 的最短合法编码。

对区间长度归纳。长度为 1 时无法缩短，初始化显然最优。假设所有更短区间均已求得最优答案。对长度为 L 的区间，若最优表示顶层没有括号，它要么是原串，要么能在某个边界拆成两个编码串；算法枚举全部切分点，并由归纳假设取到两侧最优值。若最优表示顶层是 k[x]，原区间必由某个周期块重复组成；最小周期同样生成该字符串，而周期块的最优编码已由更短区间状态得到，算法会检查这一候选。三类覆盖全部合法顶层形式，算法取其中最短者，因此当前区间也最优。归纳完成。

边界与细节

  • 长度 1、无周期或编码不变短：直接保留原串。
  • 重复次数可能是两位或三位，比较时必须使用真实字符串长度。
  • 周期块也要使用 dp 中的最短编码，才能得到嵌套结果。
  • 只在候选严格更短时更新，等长时保留已有答案即可；题目允许最短答案不唯一。
  • 空串不在官方约束内；实现仍对空串作防御性返回。

复杂度

状态与转移：O(n²) 个区间，每个区间枚举 O(n) 个切分点，并用 O(n) 的前缀函数找周期，因此共有 O(n³) 次核心工作。

字符串成本：四份实现直接保存不可变字符串；若把拼接和复制的字符数也计入，保守最坏时间为 O(n⁴)、字符存储量为 O(n³)。只计表项引用时空间为 O(n²)。

替代方案

可只在 DP 中保存最短长度与 RAW / SPLIT / REPEAT 回溯指针，最后重建一次答案。这样避免反复复制字符串，可把时间严格控制在 O(n³)、DP 空间控制在 O(n²)，代价是实现更复杂。

常见错误

  • 只压缩整个字符串，遗漏“局部压缩后再拼接”。
  • 只用原始周期块，遗漏周期块本身的嵌套压缩。
  • 看到重复就替换，没有比较括号与数字带来的额外长度。
  • 用浮点或错误下标判断周期，导致越界或漏判。

面试追问

  • 如何用回溯节点避免 DP 过程中复制长字符串？
  • 为什么最小周期足以构造顶层重复候选？
  • 如果要返回所有最短编码，状态和去重策略如何变化？
  • 如果允许转义字符或数字出现在原串，语法该如何设计？

class Solution {
    public String encode(String s) {
        int n = s.length();
        if (n == 0) return "";

        String[][] dp = new String[n][n];
        for (int len = 1; len <= n; len++) {
            for (int i = 0; i + len <= n; i++) {
                int j = i + len - 1;
                String sub = s.substring(i, j + 1);
                dp[i][j] = sub;

                for (int k = i; k < j; k++) {
                    String candidate = dp[i][k] + dp[k + 1][j];
                    if (candidate.length() < dp[i][j].length()) {
                        dp[i][j] = candidate;
                    }
                }

                int period = smallestPeriod(sub);
                if (period < len) {
                    String candidate = (len / period) + "[" + dp[i][i + period - 1] + "]";
                    if (candidate.length() < dp[i][j].length()) {
                        dp[i][j] = candidate;
                    }
                }
            }
        }
        return dp[0][n - 1];
    }

    private int smallestPeriod(String text) {
        int m = text.length();
        int[] pi = new int[m];
        for (int i = 1; i < m; i++) {
            int j = pi[i - 1];
            while (j > 0 && text.charAt(i) != text.charAt(j)) {
                j = pi[j - 1];
            }
            if (text.charAt(i) == text.charAt(j)) j++;
            pi[i] = j;
        }
        int period = m - pi[m - 1];
        return m % period == 0 ? period : m;
    }
}

var encode = function (s) {
  const n = s.length;
  if (n === 0) return "";

  const dp = Array.from({ length: n }, () => Array(n).fill(""));

  const smallestPeriod = (text) => {
    const m = text.length;
    const pi = Array(m).fill(0);
    for (let i = 1; i < m; i += 1) {
      let j = pi[i - 1];
      while (j > 0 && text[i] !== text[j]) j = pi[j - 1];
      if (text[i] === text[j]) j += 1;
      pi[i] = j;
    }
    const period = m - pi[m - 1];
    return m % period === 0 ? period : m;
  };

  for (let len = 1; len <= n; len += 1) {
    for (let i = 0; i + len <= n; i += 1) {
      const j = i + len - 1;
      const sub = s.slice(i, j + 1);
      dp[i][j] = sub;

      for (let k = i; k < j; k += 1) {
        const candidate = dp[i][k] + dp[k + 1][j];
        if (candidate.length < dp[i][j].length) dp[i][j] = candidate;
      }

      const period = smallestPeriod(sub);
      if (period < len) {
        const candidate = `${len / period}[${dp[i][i + period - 1]}]`;
        if (candidate.length < dp[i][j].length) dp[i][j] = candidate;
      }
    }
  }
  return dp[0][n - 1];
};
class Solution:
    def encode(self, s: str) -> str:
        n = len(s)
        if n == 0:
            return ""

        dp = [[""] * n for _ in range(n)]

        def smallest_period(text: str) -> int:
            m = len(text)
            pi = [0] * m
            for i in range(1, m):
                j = pi[i - 1]
                while j > 0 and text[i] != text[j]:
                    j = pi[j - 1]
                if text[i] == text[j]:
                    j += 1
                pi[i] = j
            period = m - pi[-1]
            return period if m % period == 0 else m

        for length in range(1, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                sub = s[i : j + 1]
                dp[i][j] = sub

                for k in range(i, j):
                    candidate = dp[i][k] + dp[k + 1][j]
                    if len(candidate) < len(dp[i][j]):
                        dp[i][j] = candidate

                period = smallest_period(sub)
                if period < length:
                    candidate = f"{length // period}[{dp[i][i + period - 1]}]"
                    if len(candidate) < len(dp[i][j]):
                        dp[i][j] = candidate

        return dp[0][n - 1]
