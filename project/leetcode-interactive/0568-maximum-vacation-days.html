最大休假天数

一张航班网络、一份逐周假期表，以及从城市 0 出发的有限时间。你可以每周一移动一次，也可以留在原地——目标只是让总休假天数尽可能多。

Trip brief

规划一条 K 周行程

每周只有一次选择：留在当前城市，或乘一班直达航班。

0起始城市
K旅行周数
Problem statement

题意准确转述

有 n 个城市和 k 周时间。你在第 1 周开始前位于城市 0。flights[i][j] = 1 表示可以从城市 i 直飞城市 j；days[i][w] 表示第 w 周待在城市 i 最多能休假的天数。

每周的时间线

  1. 1

    周一早晨：从当前城市乘至多一班直达航班；也可以不飞，继续留在原城市。

  2. 2

    本周其余时间：在最终所在城市休假，最多获得 days[城市][本周] 天。

  3. 3

    下周继续：当前位置会延续到下一周。整个计划恰好覆盖全部 k 周。

任务：返回这 k 周内能够获得的最大休假天数。航班本身不消耗休假天数，且每周都允许原地停留。

函数签名

maxVacationDays(flights, days) -> integer

flights 是 n × n 的 0/1 矩阵；days 是 n × k 的非负整数矩阵。

重要细节

即使 flights[i][i] = 0，仍然可以选择不乘飞机而留在城市 i。

官方形式示例

示例 1
输入：flights = [[0,1,1],[1,0,1],[1,1,0]], days = [[1,3,1],[6,0,3],[3,3,3]] 输出：12

一种最优行程是：第 1 周从城市 0 飞到城市 1，休 6 天；第 2 周飞到城市 2，休 3 天；第 3 周留在城市 2，再休 3 天，共 12 天。

示例 2
输入：flights = [[0,0,0],[0,0,0],[0,0,0]], days = [[1,1,1],[7,7,7],[7,7,7]] 输出：3

没有任何航班可乘，因此只能一直留在起点城市 0，每周休 1 天，总计 3 天。

示例 3
输入：flights = [[0,1,1],[1,0,1],[1,1,0]], days = [[7,0,0],[0,7,0],[0,0,7]] 输出：21

三座城市两两可达，可以每周选择当周休假上限为 7 的城市，得到 21 天。

约束

n == flights.length == flights[i].length == days.length
k == days[i].length
1 <= n, k <= 100
flights[i][j] ∈ {0, 1}
flights[i][i] == 0
0 <= days[i][w] <= 7

Dynamic programming

题解：按周压缩的动态规划

把“周数”看作分层图的层，把“所在城市”看作每层的节点。每次只从上一周可达的城市转移到本周允许抵达的城市，因此无需枚举完整行程。

状态

dp[i] 表示处理完当前周、最终位于城市 i 时的最大累计休假天数。

合法移动

从 from 到 to，需要 from == to 或 flights[from][to] == 1。

初始化

开始时只有城市 0 可达：dp[0] = 0，其他城市设为负无穷。

状态转移

next[to] = max(next[to], dp[from] + days[to][week]) 条件：dp[from] 可达，且 from == to 或 flights[from][to] == 1

每一周都新建 next，遍历所有起点城市与终点城市。周末用 next 替换 dp。全部周结束后，答案是 max(dp)。

完整过程

  1. 创建长度为 n 的数组 dp，仅把城市 0 设为 0，其余设为不可达。

  2. 从第 0 周到第 k - 1 周依次处理；每周先创建全为不可达值的 next。

  3. 枚举上一周末所在城市 from。若不可达则跳过；再枚举本周要去的城市 to。

  4. 若可以原地停留或有直达航班，用上一状态加上 days[to][week] 更新 next[to]。

  5. 一周处理完后令 dp = next；最终取所有终点城市中的最大值。

正确性证明

不变式：处理完第 w 周后，dp[i] 恰好等于所有从城市 0 出发、遵守每周至多一班直达航班规则、并在第 w 周末位于城市 i 的行程中，累计休假天数的最大值。

  1. 基础：第 1 周开始前，只有城市 0 可达且累计为 0，初始化与实际状态完全一致。

  2. 归纳：假设上一周的不变式成立。任何本周末位于 to 的合法行程，上一周必位于某个可达的 from，且 from == to 或存在直达航班；转移会枚举它并加入本周在 to 的休假天数。反过来，每个被转移枚举的组合也都是合法行程。因此取最大值后，next[to] 恰为该终点的最优值。

  3. 结论：归纳覆盖全部 k 周。最终行程可结束在任意城市，所以 max(dp) 就是全局最大休假天数。

O(k · n²)时间复杂度：每周检查所有有序城市对
O(n)额外空间：仅保留前后两周状态

边界情况

  • 只有一个城市：每周都留在城市 0，答案是该行所有周的总和。
  • 没有航班：始终只能位于城市 0；其他城市即使假期更多也不可达。
  • 休假天数全为 0：任意合法行程答案都是 0，初始化的不可达值仍不可误当作 0。
  • 单向航班：矩阵不保证对称，必须严格使用 flights[from][to]。
  • 每周允许停留：不能只处理值为 1 的航班边，from == to 也始终合法。

import java.util.Arrays;

class Solution {
    public int maxVacationDays(int[][] flights, int[][] days) {
        int n = flights.length;
        int weeks = days[0].length;
        int unreachable = -1_000_000_000;
        int[] dp = new int[n];
        Arrays.fill(dp, unreachable);
        dp[0] = 0;

        for (int week = 0; week < weeks; week++) {
            int[] next = new int[n];
            Arrays.fill(next, unreachable);

            for (int from = 0; from < n; from++) {
                if (dp[from] == unreachable) {
                    continue;
                }
                for (int to = 0; to < n; to++) {
                    if (from == to || flights[from][to] == 1) {
                        next[to] = Math.max(
                            next[to],
                            dp[from] + days[to][week]
                        );
                    }
                }
            }
            dp = next;
        }

        int answer = 0;
        for (int value : dp) {
            answer = Math.max(answer, value);
        }
        return answer;
    }
}

var maxVacationDays = function(flights, days) {
    const n = flights.length;
    const weeks = days[0].length;
    let dp = new Array(n).fill(Number.NEGATIVE_INFINITY);
    dp[0] = 0;

    for (let week = 0; week < weeks; week++) {
        const next = new Array(n).fill(Number.NEGATIVE_INFINITY);

        for (let from = 0; from < n; from++) {
            if (!Number.isFinite(dp[from])) {
                continue;
            }
            for (let to = 0; to < n; to++) {
                if (from === to || flights[from][to] === 1) {
                    next[to] = Math.max(
                        next[to],
                        dp[from] + days[to][week]
                    );
                }
            }
        }
        dp = next;
    }

    return Math.max(...dp);
};

class Solution:

        self,
        flights: List[List[int]],
        days: List[List[int]],
    ) -> int:
        n = len(flights)
        weeks = len(days[0])
        dp = [float("-inf")] * n
        dp[0] = 0

        for week in range(weeks):
            next_dp = [float("-inf")] * n

            for from_city in range(n):
                if dp[from_city] == float("-inf"):
                    continue
                for to_city in range(n):
                    if (
                        from_city == to_city

                    ):
                        next_dp[to_city] = max(
                            next_dp[to_city],
                            dp[from_city] + days[to_city][week],
                        )

            dp = next_dp

        return int(max(dp))

替代方案

  • 记忆化搜索：状态为“当前城市 + 当前周”，同样有 O(k · n²) 时间与 O(k · n) 记忆空间；代码直观，但递归深度和常数略高。
  • 二维动态规划：保留 dp[week][city] 能直接还原完整路线，空间为 O(k · n)。仅求最大值时没有必要。
  • 按航班边优化：若航班矩阵非常稀疏，可预建邻接表，把时间降为 O(k · (n + E))。

常见错误

  • 把所有城市初值设为 0，等价于允许第一周从任意城市凭空出发。
  • 忘记 from == to 的停留转移，导致每周被迫乘飞机。
  • 在原 dp 上原地更新，使同一周内连续飞行多次。
  • 把单向航班矩阵误当作无向图，使用了反方向的边。
  • 将 days[from][week] 加入答案；休假发生在本周最终抵达的 to 城市。

实现检查点

  • 前后两周状态数组必须分离。
  • 不可达值要与合法的 0 天区分。
  • 循环顺序清楚表达 week → from → to。
  • 最终答案来自任意终点城市，而不是只取城市 0。
