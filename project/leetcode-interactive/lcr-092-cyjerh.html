将字符串翻转到单调递增

题意

给定二进制字符串 s，翻转若干字符，使结果满足若 i<j 则 s[i]≤s[j]，求最少翻转次数。

示例："00110" 输出 1。约束：1≤s.length≤100000。

互动

第 1 步：单调串由若干 0 后接若干 1 组成。

洞察

遍历时记录已见 1 的数量 ones 与最小翻转 flip。遇到 1 增加 ones；遇到 0 可翻当前 0 或翻此前所有 1，取最小。过程：初始化→遍历→更新最优。边界：全 0、全 1、单字符、交替串。复杂度 O(n) 时间 O(1) 空间。替代：前后缀计数。追问：为什么只需保存两个状态？错误：把单调误解为严格递增、未更新最小值。
