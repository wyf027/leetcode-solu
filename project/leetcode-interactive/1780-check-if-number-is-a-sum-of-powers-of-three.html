判断一个数字是否可以表示成三的幂的和

Check if Number is a Sum of Powers of Three

数学整数非付费题
Problem

题目说明

给你一个整数 n。如果它能够写成若干个互不相同的三的非负整数次幂之和，返回 true；否则返回 false。

整数 y 是三的幂，表示存在非负整数 x，使得 y = 3ˣ。同一个幂次不能重复使用。

函数签名

  • 可选项只能来自 3⁰, 3¹, 3², ...
  • 每一个三的幂至多选一次

完整题解

先完成自己的推导，再展开答案。

核心洞察

不同三的幂之和，本质上是一个三进制数：选用 3ⁱ 就让第 i 位为 1，不选则为 0。由于每个幂最多使用一次，合法表示的每一位只能是 0 或 1；一旦三进制中出现 2，答案必为 false。

完整过程

  1. 当 n > 0 时，计算 remainder = n % 3。
  2. 若余数为 2，立即返回 false。
  3. 否则令 n = floor(n / 3)，继续检查更高一位。
  4. 所有位都检查完成，返回 true。

正确性证明

必要性：若 n 是互不相同的三的幂之和，则每个 3ⁱ 只会出现零次或一次，因此其三进制第 i 位只能为 0 或 1，不可能为 2。

充分性：若 n 的每个三进制位均为 0 或 1，把所有值为 1 的第 i 位替换为 3ⁱ 并求和，正好得到 n；各幂次互不相同。因此算法返回值正确。

边界与复杂度

  • n = 1：三进制为 1，即 3⁰，合法。
  • n = 2：最低位立即为 2，不合法。
  • 恰为三的幂时，三进制形如 100...0，合法。
  • 时间复杂度 O(log₃ n)，额外空间复杂度 O(1)。

替代方案

也可以从不超过 n 的最大三次幂开始贪心减去。若每个幂最多减一次且最终余数为 0，即可得到答案；或者枚举幂集合的子集，但其状态数量呈指数增长，没有必要。直接检查三进制位最简洁。

面试追问

  • 如果每个三的幂最多可以使用两次，应允许哪些三进制位？
  • 把底数从 3 改成任意 k，判断规则如何变化？
  • 若要求返回实际选中的幂次，如何在扫描时同步记录？

常见错误

  • 只判断 n 本身是不是三的幂，遗漏多个不同幂相加的情况。
  • 忽略“不同”二字，错误地允许同一幂重复出现。
  • 将出现余数 2 后的进位当成可消除；标准三进制表示是唯一的，不能绕过该位。
  • 循环内忘记更新 n，造成死循环。

四语言完整代码

Java
class Solution {
    public boolean checkPowersOfThree(int n) {
        while (n > 0) {
            if (n % 3 == 2) {
                return false;
            }
            n /= 3;
        }
        return true;
    }
}

var checkPowersOfThree = function(n) {

            return false;
        }
        n = Math.floor(n / 3);
    }
    return true;
};
