Medium · 构造 / 网格 DP

3988. 创建一个恰好有 K 条路径的网格图 I

把「恰好 K 条」变成可观察的路径计数：先选一个小模块，再接一条唯一出口。

题意

给定 m、n、k，构造仅含 .（可走）和 #（障碍）的 m × n 网格。路径从 (0, 0) 到 (m - 1, n - 1)，每步只能向右或向下；需要恰好有 k 条路径，否则返回空数组。

官方示例（转述）

m = 2, n = 3, k = 2 时，["...", "#.."] 有两条路径。
m = 3, n = 3, k = 4 时可构造 ["..#", "...", "#.."]。
若 m = 1, n = 4, k = 2，只能有一条直线，故返回 []。

约束：1 ≤ m, n ≤ 10，1 ≤ k ≤ 4。这里的 k 很小，预备有限个小型路径模块即可。

构造实验室

目标：4实际路径：—

按“构造并计数”查看模块如何接入唯一出口。

测试与验证

  • 输入：m = 2, n = 3, k = 2；期望：存在 2 条路径；实际：实验室可复算。
  • 输入：m = 1, n = 4, k = 2；期望：[]；实际：模块放不下，返回空。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

核心洞察

任何已构造好的 p × q 模块只要有恰好 k 条到其右下角的路径，就能把模块外全部封死，仅从模块右下角延伸一条“先右后下”的走廊。出口没有分叉，因此不会改变路径数。

完整过程

  1. 为 k=1,2,3,4 预存最小模块：1×1、2×2、2×3、3×3。
  2. 选择能放进 m × n 的模块，放在左上角。
  3. 其他格子置障碍；从模块终点沿右边再沿底边开出唯一走廊。
  4. 不能放下模块则返回空数组。

边界与复杂度

单行或单列只有一条路径；k>1 时通常不可行。构造与输出均为 O(mn)，额外空间（除输出）为 O(1)。

替代方案

可按格子 DP 反向搜索障碍布局；本题 k≤4，固定模块更短、更容易证明。

面试追问

若 k 变大，可使用组合数模块、二进制拆分或 DP 状态搜索；若允许任意方向移动，路径可能出现环，计数模型也随之变化。

常见错误

  • 忘记封住模块外边界，额外路径会从侧面进入走廊。
  • 把出口走廊做成两条可选方向。
  • 未检查模块是否真的能放入 m、n。
