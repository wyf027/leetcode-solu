Problem brief

题目描述

先理解业务指标与输出规则；解法被收在页面底部，不会在首屏直接揭示。

SurveyLog 记录用户在问卷中对问题执行的动作。每一行表示某位用户在指定时间对某个问题进行了一次 show、answer 或 skip。

对每个问题，回答率定义为该问题被回答的次数除以被展示的次数。请返回回答率最高的问题编号；若多个问题并列，返回较小的 question_id。结果列名必须为 survey_log。

answer rate 回答次数 ÷ 展示次数

这是数据库题，在线判题的正式提交物是 SQL 查询。页面后部的 Java、JavaScript、Python 与 C++ 仅模拟相同分组语义，不能替代本站 SQL 提交。

准备好再揭晓

先自己写出分组与排序逻辑。点击后才会显示核心洞察、证明、复杂度以及五种实现。

Solution

题解：条件聚合 + 双重排序

01 / GROUP

按问题分桶

以 question_id 分组，让每个聚合结果只描述一个问题。

02 / COUNT

条件统计

分别累加 answer 与 show 行，skip 不进入任一计数。

03 / RANK

按规则取首行

先按回答率降序，再按问题编号升序，最后只保留第一行。

完整过程

  1. 扫描 SurveyLog，把相同 question_id 的动作放到同一组。
  2. 对每组使用两个条件和：一个统计 action = 'answer'，另一个统计 action = 'show'。
  3. 用 answer_count / show_count 得到回答率。SQL 中乘以 1.0 明确表达小数除法。
  4. 回答率从高到低排序；率相同则 question_id 从小到大排序。
  5. LIMIT 1 取排序后的第一项，并把输出列别名设为 survey_log。

正确性说明

引理 1 · 计数准确

按 question_id 分组后，条件和恰好遍历该问题的全部日志：满足 answer 的行各贡献 1，满足 show 的行各贡献 1。因此两个和分别等于题目定义中的回答次数与展示次数。

引理 2 · 排序准确

第一排序键把更高回答率放在更前；第二排序键在回答率相同时把更小编号放在更前。因此全局第一行正是题目要求的唯一返回项。

结论：结合两个引理，查询返回且只返回回答率最高、并在并列时编号最小的问题，所以算法正确。

边界与复杂度

O(N + Q log Q)概念时间：扫描 N 行并对 Q 个分组排序。数据库实际计划可用索引或 Top-N 优化。
O(Q)概念空间：保存每个问题的一组聚合值；具体内存由数据库执行器决定。
  • 并列：必须显式添加 question_id ASC，不能依赖数据库的默认行顺序。
  • 重复日志：题目说明表可能重复；每一行都代表一次待统计的日志，不能先 DISTINCT。
  • 跳过动作：skip 不等于 show，也不等于 answer，不进入两个分子/分母计数。
  • 零分母：题目业务语义以展示次数为分母；示例 SQL 用 NULLIF(..., 0) 防止异常数据触发除零。

完整代码

LeetCode 可提交 · MySQL
# Write your MySQL query statement below
SELECT question_id AS survey_log
FROM SurveyLog
GROUP BY question_id
ORDER BY
    SUM(CASE WHEN action = 'answer' THEN 1 ELSE 0 END) * 1.0
    / NULLIF(SUM(CASE WHEN action = 'show' THEN 1 ELSE 0 END), 0) DESC,
    question_id ASC
LIMIT 1;
本地语义参考 · 输入为事件列表，不是 LeetCode 本题提交格式
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    record Event(int questionId, String action) {}

    public int getHighestAnswerRate(List<Event> events) {
        Map<Integer, long[]> counts = new HashMap<>();

        for (Event event : events) {
            long[] value = counts.computeIfAbsent(
                event.questionId(), key -> new long[2]
            );
            if (event.action().equals("show")) {
                value[0]++;
            } else if (event.action().equals("answer")) {
                value[1]++;
            }
        }

        int bestId = Integer.MAX_VALUE;
        long bestShows = 1;
        long bestAnswers = -1;

        for (Map.Entry<Integer, long[]> entry : counts.entrySet()) {
            int id = entry.getKey();
            long shows = entry.getValue()[0];
            long answers = entry.getValue()[1];
            if (shows == 0) continue;

            long left = answers * bestShows;
            long right = bestAnswers * shows;
            if (left > right || (left == right && id < bestId)) {
                bestId = id;
                bestShows = shows;
                bestAnswers = answers;
            }
        }
        return bestId;
    }
}

function getHighestAnswerRate(events) {
  const counts = new Map();

  for (const { questionId, action } of events) {
    if (!counts.has(questionId)) counts.set(questionId, [0, 0]);
    const value = counts.get(questionId);
    if (action === "show") value[0] += 1;
    else if (action === "answer") value[1] += 1;
  }

  let bestId = Number.POSITIVE_INFINITY;
  let bestShows = 1;
  let bestAnswers = -1;

  for (const [id, [shows, answers]] of counts) {
    if (shows === 0) continue;
    const left = answers * bestShows;
    const right = bestAnswers * shows;
    if (left > right || (left === right && id < bestId)) {
      bestId = id;
      bestShows = shows;
      bestAnswers = answers;
    }
  }
  return bestId;
}

from collections import defaultdict
from typing import Iterable, Tuple


def get_highest_answer_rate(
    events: Iterable[Tuple[int, str]],
) -> int:
    counts = defaultdict(lambda: [0, 0])

    for question_id, action in events:
        if action == "show":
            counts[question_id][0] += 1
        elif action == "answer":
            counts[question_id][1] += 1

    best_id = float("inf")
    best_shows = 1
    best_answers = -1

    for question_id, (shows, answers) in counts.items():
        if shows == 0:
            continue
        left = answers * best_shows
        right = best_answers * shows
        if left > right or (left == right and question_id < best_id):
            best_id = question_id
            best_shows = shows
            best_answers = answers

    return int(best_id)

#include <array>
#include <climits>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Event {
    int questionId;
    string action;
};

class Solution {
public:
    int getHighestAnswerRate(const vector<Event>& events) {
        unordered_map<int, array<long long, 2>> counts;

        for (const Event& event : events) {
            auto& value = counts[event.questionId];
            if (event.action == "show") ++value[0];
            else if (event.action == "answer") ++value[1];
        }

        int bestId = INT_MAX;
        long long bestShows = 1;
        long long bestAnswers = -1;

        for (const auto& [id, value] : counts) {
            long long shows = value[0];
            long long answers = value[1];
            if (shows == 0) continue;

            long long left = answers * bestShows;
            long long right = bestAnswers * shows;
            if (left > right || (left == right && id < bestId)) {
                bestId = id;
                bestShows = shows;
                bestAnswers = answers;
            }
        }
        return bestId;
    }
};

替代方案、面试追问与常见错误

替代方案 · 窗口函数

可用 SUM(...) OVER (PARTITION BY question_id) 为每行附上分组计数，再去重、排序。但它会先保留更多中间行；本题只需要每组一行，直接 GROUP BY 更自然。

替代方案 · 两个聚合子查询

分别统计展示与回答后再连接也能得到比例，但查询更长，并且必须谨慎处理某一侧缺行。条件聚合一次扫描即可表达两个计数。

面试追问

如果要返回全部并列第一，应如何改写？可以先求每组回答率，再使用 DENSE_RANK 或与最大值比较；此时不再使用 LIMIT 1 消除并列。

数据极大时如何优化？可考虑以 question_id 为前导列的索引、预聚合，以及数据库的 Top-N 执行策略，并用执行计划确认。

常见错误

把 skip 计入展示次数；用整数除法导致比例被截断；只按比例排序而遗漏并列规则；使用 DISTINCT 擅自删除重复日志；返回列名不是 survey_log。
