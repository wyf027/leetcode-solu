最大交换Maximum Swap

一个数字、一次机会。交换任意两位，或者什么也不做，让最终数值尽可能大。

难度：中等 至多交换一次 非付费题
2 ⇄ 7

Problem

题目说明

给定非负整数 num，可以至多执行一次操作：选择其中任意两个数位并交换。返回能够得到的最大整数；如果任何交换都不会变大，可以保持原数不变。

示例 1

输入num = 2736
输出7236
解释交换数位 2 和 7。

示例 2

输入num = 9973
输出9973
解释不存在能让数值更大的交换，因此不交换。

约束

  • 0 <= num <= 108
  • 函数参数形式：maximumSwap(num: integer) -> integer

Greedy Strategy

贪心：让最左侧可改善的位置获得最大数字

核心洞察：两个等长十进制数比较大小时，最先不同的数位决定大小。因此应该优先改善最靠左的位置；在该位置，应换入它右侧能找到的最大数字。若最大数字重复出现，使用最右边的那个，能让被换走的小数字落到尽可能低的位权。

1 · 建表

遍历所有数位，用长度为 10 的数组 last 记录数字 0 到 9 的最右出现下标。

2 · 从左检查

对每个位置 i，从 9 递减到当前数字加一，寻找满足 last[d] > i 的最大数字。

3 · 交换即停

找到后与其最右出现位置交换并立刻返回。若全部扫描完仍未找到，原数已经最优。

完整过程：以 num = 98368 为例

  1. 最右位置表中，数字 9 在下标 0，8 在下标 4，6 在下标 3，3 在下标 2。
  2. 下标 0 的数字是 9，右侧没有比 9 更大的数位，跳过。
  3. 下标 1 的数字是 8，右侧没有 9，跳过；尽管右侧还有 8，但相等数字不会让结果变大。
  4. 下标 2 的数字是 3，右侧存在数字 8，且其最右下标是 4。交换得到 98863，立即结束。

正确性证明

引理 1：若存在能增大结果的交换，最优解必定改善最靠左的某个可改善位置。因为十进制数的高位优先于所有低位，任何更靠右位置的改善都无法弥补该位置选择了较小数字。

引理 2：在这个最靠左的位置换入其右侧最大数字是最优的。换入更小的候选数字会在第一个不同位直接得到更小结果。

引理 3：当最大候选数字有多个时，选择最右出现位置最优。换出的较小数字被放得越靠右，其负面影响的位权越低。

结论：算法按从左到右找到第一个可改善位置，再换入右侧最大数字的最右实例。根据三个引理，这次交换在所有至多一次交换的方案中最优；若没有可改善位置，则任何交换都无法增大原数。

时间复杂度：O(n) 空间复杂度：O(1) n 为十进制数位数，且 n ≤ 9

边界情况

  • 0 或只有一位：没有两个不同位置可交换，直接返回。
  • 数位非递增，如 9973：不存在右侧更大的数字，保持原数。
  • 候选数字重复，如 1993：应选择最右侧的 9，得到 9913。
  • 含前导零风险：输入整数本身没有前导零；算法只在能增大高位时交换，不会产生前导零。
  • 上界 100000000：仍只有 9 位，四种实现的整数类型都可安全容纳。

Implementations

四种语言完整代码

Java官方签名：maximumSwap(int num)
class Solution {
    public int maximumSwap(int num) {
        char[] digits = String.valueOf(num).toCharArray();
        int[] last = new int[10];

        for (int i = 0; i < digits.length; i++) {
            last[digits[i] - '0'] = i;
        }

        for (int i = 0; i < digits.length; i++) {
            int current = digits[i] - '0';
            for (int candidate = 9; candidate > current; candidate--) {
                if (last[candidate] > i) {
                    char temp = digits[i];
                    digits[i] = digits[last[candidate]];
                    digits[last[candidate]] = temp;
                    return Integer.parseInt(new String(digits));
                }
            }
        }

        return num;
    }
}
JavaScript官方签名：maximumSwap(num)
/**
 * @param {number} num
 * @return {number}
 */
var maximumSwap = function(num) {
    const digits = String(num).split('');
    const last = new Array(10).fill(-1);

    for (let i = 0; i < digits.length; i++) {
        last[Number(digits[i])] = i;
    }

    for (let i = 0; i < digits.length; i++) {
        const current = Number(digits[i]);
        for (let candidate = 9; candidate > current; candidate--) {
            if (last[candidate] > i) {
                const j = last[candidate];
                [digits[i], digits[j]] = [digits[j], digits[i]];
                return Number(digits.join(''));
            }
        }
    }

    return num;
};
Python 3官方签名：maximumSwap(self, num: int)
class Solution:
    def maximumSwap(self, num: int) -> int:
        digits = list(str(num))
        last = [-1] * 10

        for i, digit in enumerate(digits):
            last[int(digit)] = i

        for i, digit in enumerate(digits):
            current = int(digit)
            for candidate in range(9, current, -1):
                if last[candidate] > i:
                    j = last[candidate]
                    digits[i], digits[j] = digits[j], digits[i]
                    return int(''.join(digits))

        return num

class Solution {
public:
    int maximumSwap(int num) {
        string digits = to_string(num);
        int last[10] = {};

        for (int i = 0; i < static_cast<int>(digits.size()); ++i) {
            last[digits[i] - '0'] = i;
        }

        for (int i = 0; i < static_cast<int>(digits.size()); ++i) {
            int current = digits[i] - '0';
            for (int candidate = 9; candidate > current; --candidate) {
                if (last[candidate] > i) {
                    swap(digits[i], digits[last[candidate]]);
                    return stoi(digits);
                }
            }
        }

        return num;
    }
};

替代方案

后缀最大下标：先从右向左构造数组，记录每个位置右侧最大数位的下标，再从左找到第一个严格更大的候选并交换。同样是 O(n) 时间，但需要 O(n) 额外空间。

枚举所有交换：枚举所有下标对，生成结果并取最大值。数位最多 9 个时也能通过，思路直观，但通用复杂度为 O(n³)：O(n²) 对交换，每次构造或解析 O(n)。面试中更适合作为基线方案。

常见错误

  • 看到更大数字就立刻交换，而没有先选右侧最大的数字。
  • 最大候选重复时选择最左实例；例如 1993 会错过更优结果。
  • 扫描低位后还继续交换，违反“至多一次”限制。
  • 把 last[candidate] > i 写成仅判断该数字是否出现，导致与左侧数字交换。
  • 把“至多一次”误读为“必须一次”，从而破坏已经非递增的最优输入。

面试追问

为什么要记录最右出现位置，而不是最左？

换入高位的数字相同，区别只在被换走的小数字落在哪里。落得越靠右，对最终数值的损失越小。

如果允许交换最多 K 次，策略还能直接复用吗？

不能简单重复本题贪心，因为一次交换会改变后续候选位置。可根据数据范围考虑搜索、动态规划或带位置集合的逐位构造。

能否不用字符串完成？

可以用除法和取模提取数位，再按位权计算交换后的值；但字符串或字符数组更清晰，也避免复杂的位权更新。

为什么内层枚举 9 到当前数字仍算 O(n)？

十进制候选固定只有 10 种，内层最多检查 9 次，是常数，因此总时间仍为 O(n)。
