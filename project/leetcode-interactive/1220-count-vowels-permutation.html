1220. 统计元音字母序列的数目

在五个元音构成的有向规则中，统计恰好长度为 n 的合法字符串数量，并对 10⁹ + 7 取模。

HARD Count Vowels Permutation 非付费题
countVowelPermutation(n)

Problem

题目说明

每个位置只能放小写元音，且相邻字母必须遵守以下后继规则。

a

a 后面只能是 e

e

e 后面只能是 a 或 i

i

i 后面可以是除 i 外的任意元音

o

o 后面只能是 i 或 u

u

u 后面只能是 a

示例 1

输入：n = 1 输出：5

五个单字母字符串 a、e、i、o、u 都合法。

示例 2

输入：n = 2 输出：10

合法结果为 ae、ea、ei、ia、ie、io、iu、oi、ou、ua。

示例 3

输入：n = 5 输出：68

返回所有长度为 5 的合法序列数量。

约束： 1 ≤ n ≤ 2 × 10⁴；返回值对 1,000,000,007 取模。

题解入口

Solution

动态规划：只记住最后一个元音

O(n) 时间 · O(1) 空间

核心洞察

下一位能放什么，只取决于当前序列的最后一个字母，与更早的字符无关。因此，不必保存完整字符串；用五个状态分别表示“当前长度下，以 a、e、i、o、u 结尾的合法序列数”即可。

nextA = e + i + u nextE = a + i nextI = e + o nextO = i nextU = i + o

公式按“谁可以转移到当前结尾”反向整理。例如能接出 a 的前一个字母是 e、i、u，所以新的 a 状态等于旧的 e、i、u 之和。

完整过程

  1. 长度为 1 时，五个元音都各自形成一个序列，所以五个状态均为 1。
  2. 从长度 2 循环到 n，每轮依据固定的相邻规则计算五个新状态。
  3. 每次加法后对 1,000,000,007 取模，避免数值无限增长。
  4. 循环结束，将五个状态相加并取模，得到所有合法序列数。

正确性证明

基例

长度为 1 时，a、e、i、o、u 各有且仅有一个对应序列，初始化准确。

归纳假设

假设五个状态准确统计了所有长度为 k、并分别以五个元音结尾的合法序列。

归纳步骤

对每个目标元音，只把规则允许的长度 k 序列接上该元音。不同前驱集合互不重叠，且任意长度 k+1 的合法序列去掉末尾后必落入其中一个允许前驱，因此转移不重不漏。

结论

由数学归纳法，循环结束后五个状态准确覆盖长度为 n 的全部合法序列；求和即为答案。

边界与复杂度

n = 1

循环不执行，五个初始状态之和为 5。

大 n

每一轮都取模；JavaScript 使用 Number 时，中间只累加至几个模数，仍处于安全整数范围。

时间复杂度

共进行 n−1 轮常数次转移，因此是 O(n)。

空间复杂度

滚动保存五个旧状态和五个新状态，因此是 O(1)。

四种语言完整代码

class Solution {
    public int countVowelPermutation(int n) {
        final long MOD = 1_000_000_007L;
        long a = 1, e = 1, i = 1, o = 1, u = 1;

        for (int length = 2; length <= n; length++) {
            long nextA = (e + i + u) % MOD;
            long nextE = (a + i) % MOD;
            long nextI = (e + o) % MOD;
            long nextO = i;
            long nextU = (i + o) % MOD;
            a = nextA;
            e = nextE;
            i = nextI;
            o = nextO;
            u = nextU;
        }

        return (int) ((a + e + i + o + u) % MOD);
    }
}

替代方案

矩阵快速幂：把五个状态写成向量，固定转移写成 5×5 矩阵，再计算矩阵的 n−1 次幂，可将时间降为 O(log n)，空间为 O(1)（矩阵规模固定）。本题 n ≤ 2×10⁴，线性动态规划更短、更直观，也已经足够快。

面试追问

为什么按结尾分类？

因为限制发生在相邻字符之间，末尾就是决定下一步是否合法的最小充分状态。

若 n 扩大到 10¹⁸？

线性循环不可接受，应使用矩阵快速幂，并用 64 位整数承接乘法取模。

规则运行时可变呢？

把规则建成邻接表或转移矩阵，遍历所有允许边完成通用状态转移。

如何恢复一个合法序列？

计数状态不够；需额外保存可达前驱，或按剩余计数贪心构造第 k 个序列。

常见错误

  • 把题目给出的“后继规则”直接照抄成结尾状态公式，却忘记公式需要从目标字母的允许前驱反推。
  • 原地更新 a 后，又使用已经更新的 a 计算 e，导致同一轮混用了新旧状态。
  • 漏掉 i 可以跟 a、e、o、u 中的任意一个，只记成“不能跟 i”而未展开完整转移。
  • 只在最终答案处取模，使中间值在固定宽度语言中溢出。
  • 将 n=1 当作需要执行一次转移，产生长度偏移一位的问题。
