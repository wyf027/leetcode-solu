Reformat Date

转变日期格式

把带英文序数后缀的日期 Day Month Year 转换成标准的 YYYY-MM-DD。先理解格式，再动手拆解。

题目说明

给定字符串 date，其形式是 Day Month Year。其中日期带两字符序数后缀，月份使用三字母英文缩写，年份为四位数。请返回 YYYY-MM-DD 格式的字符串，月份和日期都必须补齐为两位。

函数签名

reformatDate(date: string): string

输入组成

Day ∈ 1st…31st；Month ∈ Jan…Dec；Year ∈ [1900, 2100]。

约束

  • 输入日期保证合法，不需要处理非法日期。
  • 日期末尾固定有两个序数后缀字符：st、nd、rd 或 th。
  • 结果中的年、月、日分别占 4、2、2 位。

官方示例

输入：date = "20th Oct 2052"
输出："2052-10-20"
输入：date = "6th Jun 1933"
输出："1933-06-06"
输入：date = "26th May 1960"
输出："1960-05-26"

完整题解

核心洞察

输入天然由空格分成日、月、年。日的末两位总是后缀，可直接删除；月是仅有 12 种取值的固定映射；最后统一补零并按目标顺序拼接。

边界要点

  • 1st 去后缀后只有一位，必须补成 01。
  • 10th 去后缀后已有两位，不应多补零。
  • 一月到九月的月份编号同样需要补零。

完整过程

  1. 按空格拆分字符串，得到 dayToken、monthToken 和 year。
  2. 移除 dayToken 最后两个字符，保留纯数字日期。
  3. 用月份表把英文缩写映射为 1 到 12，再格式化为两位。
  4. 将日也补为两位，按 year-month-day 顺序连接。

正确性说明

拆分后得到的三段与题目定义一一对应。删除日期末尾固定的两个后缀字符，不会删除任何日期数字，因此得到正确的日；固定月份表中每个缩写的位置恰好等于其月份编号，因此得到正确的月；年份原样保留。补零只改变表示宽度而不改变数值，最终按年、月、日拼接，结果必为正确的 YYYY-MM-DD。

复杂度

时间：O(n)，其中 n 为输入字符串长度；月份查找最多检查 12 项，可视为常数。
空间：O(n)，用于拆分和构造结果；若忽略返回字符串，则辅助空间为常数级。

四种语言完整代码

JAVA
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String reformatDate(String date) {
        String[] parts = date.split(" ");
        String day = parts[0].substring(0, parts[0].length() - 2);

        Map<String, String> months = new HashMap<>();
        String[] names = {
            "Jan", "Feb", "Mar", "Apr", "May", "Jun",
            "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"
        };
        for (int i = 0; i < names.length; i++) {
            months.put(names[i], String.format("%02d", i + 1));
        }

        return parts[2] + "-" + months.get(parts[1])
            + "-" + String.format("%02d", Integer.parseInt(day));
    }
}
JAVASCRIPT
/**
 * @param {string} date
 * @return {string}
 */
var reformatDate = function(date) {
    const [dayToken, monthToken, year] = date.split(" ");
    const months = [
        "Jan", "Feb", "Mar", "Apr", "May", "Jun",
        "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"
    ];

    const day = dayToken.slice(0, -2).padStart(2, "0");
    const month = String(months.indexOf(monthToken) + 1)
        .padStart(2, "0");

    return `${year}-${month}-${day}`;
};

C++
#include <iomanip>
#include <sstream>
#include <string>
#include <unordered_map>
using namespace std;

class Solution {
public:
    string reformatDate(string date) {
        string dayToken, monthToken, year;
        stringstream input(date);
        input >> dayToken >> monthToken >> year;

        unordered_map<string, int> monthNumber = {
            {"Jan", 1}, {"Feb", 2}, {"Mar", 3},
            {"Apr", 4}, {"May", 5}, {"Jun", 6},
            {"Jul", 7}, {"Aug", 8}, {"Sep", 9},
            {"Oct", 10}, {"Nov", 11}, {"Dec", 12}
        };

        int day = stoi(dayToken.substr(0, dayToken.size() - 2));
        ostringstream output;
        output << year << '-'
               << setw(2) << setfill('0') << monthNumber[monthToken]
               << '-' << setw(2) << setfill('0') << day;
        return output.str();
    }
};

替代方案

可以用字典直接保存 Jan → 01 等字符串映射，省去编号再补零；也可以用条件分支，但分支冗长且容易漏项。不建议依赖系统日期解析器，因为语言、地区和运行环境可能导致行为差异。

常见错误

  • 只删除一个后缀字符，把 20th 错误变成 20t。
  • 忘记给个位日期或一月至九月补零。
  • 月份数组下标从 0 开始，却忘记加 1。
  • 把结果拼成原输入顺序 DD-MM-YYYY。
