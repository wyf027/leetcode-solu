拼车

一辆只向东行驶的车，沿途有人上车、下车。真正的问题不是总共载过多少人，而是任意位置上的同时乘客数是否超过容量。

数组前缀和模拟

题意

车最初有 capacity 个空座位，并且只能向东行驶。每个行程 trips[i] = [numPassengers, from, to] 表示有相应人数在 from 上车、在 to 下车。

判断能否完成全部接送：在任何位置，车上人数都不能超过容量。到站时先下车再上车，因此在同一位置结束与开始的行程可以直接抵消。

示例 1
trips = [[2,1,5],[3,3,7]], capacity = 4
输出：false
示例 2
trips = [[2,1,5],[3,3,7]], capacity = 5
输出：true

约束

  • 1 ≤ trips.length ≤ 1000
  • trips[i].length == 3
  • 1 ≤ numPassengers ≤ 100
  • 0 ≤ from < to ≤ 1000
  • 1 ≤ capacity ≤ 10⁵

函数形式

carPooling(trips: integer[][], capacity: integer): boolean

准备好看题解了吗？

先想一想：如何把一次区间乘车，变成两个位置上的变化？

Solution

题解：差分数组 + 前缀和

核心洞察

行程 [p, from, to] 只产生两次变化：在 from 处增加 p，在 to 处减少 p。把变化记录进差分数组，从西向东求前缀和，就得到每个位置离开时的车内人数。

完整过程

  1. 创建长度 1001 的数组 change，初值全为 0。
  2. 对每个行程执行 change[from] += p 和 change[to] -= p。
  3. 从位置 0 扫到 1000，把本站变化累加到当前人数。
  4. 一旦当前人数大于 capacity，立即返回 false；扫描结束则返回 true。

正确性说明

对任一位置 x，差分数组在所有不晚于 x 的上车点加入乘客，又在所有不晚于 x 的下车点移除乘客。因此前缀和恰好等于经过 x 后仍在车上的人数。算法逐点检查这一人数，返回 true 当且仅当所有位置均未超载。

边界与复杂度

  • 同站下车和上车：正负变化合并后再检查，符合座位可立即复用。
  • 单个行程、起点为 0、终点为 1000 均自然覆盖。
  • 时间复杂度 O(n + U)，其中 U = 1001；空间复杂度 O(U)。

替代方案

可将上下车拆成事件后按位置排序，时间 O(n log n)；也可按起点排序并用最小堆维护最早下车的行程。坐标上界很小时，差分数组最直接。

面试追问

  • 如果位置达到 10⁹？改用事件排序或有序映射。
  • 如果还要返回首次超载位置？扫描时在首次超过容量时返回当前位置。
  • 为什么终点要减人数？区间语义是 [from, to)，到达终点即下车。

常见错误

  • 在 to + 1 才减人数，错误地把乘客留到终点之后。
  • 只比较总乘客数与容量，忽略行程不重叠时座位可复用。
  • 同地点事件排序时先上车后下车，造成假超载。

Java

class Solution {
    public boolean carPooling(int[][] trips, int capacity) {
        int[] change = new int[1001];
        for (int[] trip : trips) {
            change[trip[1]] += trip[0];
            change[trip[2]] -= trip[0];
        }
        int passengers = 0;
        for (int delta : change) {
            passengers += delta;
            if (passengers > capacity) return false;
        }
        return true;
    }
}

/**

 * @param {number} capacity

var carPooling = function(trips, capacity) {
    const change = new Array(1001).fill(0);
    for (const [passengers, from, to] of trips) {
        change[from] += passengers;
        change[to] -= passengers;
    }
    let passengers = 0;
    for (const delta of change) {
        passengers += delta;
        if (passengers > capacity) return false;
    }
    return true;
};

Python

from typing import List

class Solution:
    def carPooling(self, trips: List[List[int]], capacity: int) -> bool:
        change = [0] * 1001
        for passengers, start, end in trips:
            change[start] += passengers
            change[end] -= passengers

        passengers = 0
        for delta in change:
            passengers += delta
            if passengers > capacity:
                return False
        return True
