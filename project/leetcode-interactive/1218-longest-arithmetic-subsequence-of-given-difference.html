最长定差子序列

Longest Arithmetic Subsequence of Given Difference——一次从左到右的扫描，用哈希表接住每个数字的“前一个伙伴”。

中等 MEDIUM数组哈希表动态规划非付费题
01

问题是什么？

先理解目标，再决定如何保存历史。

给定整数数组 arr 和整数 difference，返回 arr 中最长子序列的长度，使得子序列中每一对相邻元素的差都恰好等于 difference。

子序列可以删除原数组中的任意元素，但剩余元素的相对顺序不能改变；不要求元素在原数组里连续。

输入 / 输出形式
longestSubsequence(arr: integer[], difference: integer) → integer
示例 1
输入：arr = [1,2,3,4], difference = 1
输出：4
解释：[1,2,3,4]
示例 2
输入：arr = [1,3,5,7], difference = 1
输出：1
解释：任意单个元素
示例 3
输入：arr = [1,5,7,8,5,3,4,2,1], difference = -2
输出：4
解释：[7,5,3,1]
约束
  • 1 ≤ arr.length ≤ 10⁵
  • −10⁴ ≤ arr[i], difference ≤ 10⁴

准备好看完整题解了吗？

题解包含状态定义、证明、复杂度、四种语言实现与常见错误。展开前不剧透核心推导。

核心洞察

1. 只看结尾值此前以值 x 结尾的最长合法序列长度，足以决定新元素能接多长。
2. 前驱唯一确定当前值为 x，相邻差要等于 d，前一个值只能是 x − d。
3. 用哈希表压缩dp[x] 表示扫描范围内以值 x 结尾的最大长度，无需保存每个下标的整条序列。

完整过程

  1. 建立空哈希表 dp，并令全局答案 answer = 0。
  2. 从左到右读取每个 x，计算唯一前驱值 prev = x - difference。
  3. 令 dp[x] = dp.get(prev, 0) + 1。若不存在前驱，就从长度 1 开始。
  4. 用 dp[x] 更新全局最大值，扫描结束后返回答案。
正确性说明

按数组下标归纳。处理 x 前，哈希表记录所有已扫描元素中、按结尾值分类的最长合法子序列。任何以当前 x 结尾且长度大于 1 的合法子序列，其倒数第二个值必为 x − difference；选择哈希表中该前驱的最长序列再接上 x，得到所有以当前元素结尾方案中的最优值。长度为 1 的情形由默认值 0 加 1 覆盖。因此每次更新都正确；全局最大值最终就是所有结尾方案的最大长度。

边界与复杂度

  • 数组只有一个元素时答案为 1。
  • difference = 0 时，算法等价于统计同一值出现的最大次数。
  • 差值为负数时公式仍是 x - difference，例如 x - (-2) = x + 2。
  • 重复值会覆盖为当前可达到的长度；按顺序扫描保证不会使用未来元素。
时间复杂度O(n) 平均
空间复杂度O(n) 最坏

替代方案

朴素动态规划可令 f[i] 表示以 arr[i] 结尾的答案，并向前检查所有 j < i，时间复杂度为 O(n²)。它直观但无法承受 10⁵ 个元素。由于本题差值固定，前驱值唯一，才可以把“查找所有前驱下标”压缩为一次哈希查询。

四语言完整实现

均遵循官方函数签名。

Java
class Solution {
    public int longestSubsequence(int[] arr, int difference) {
        java.util.Map<Integer, Integer> dp = new java.util.HashMap<>();
        int answer = 0;

        for (int value : arr) {
            int length = dp.getOrDefault(value - difference, 0) + 1;
            dp.put(value, length);
            answer = Math.max(answer, length);
        }
        return answer;
    }
}

04

面试追问与常见错误

把线性解法说清，也要知道它为什么成立。

面试追问

  • 若差值不固定？ 通常需要按下标和值差建立二维 DP，类似最长等差数列。
  • 如何还原序列？ 额外记录每次状态更新所对应的下标和前驱下标，最后从最佳结尾反向追踪。
  • 能否使用数组代替哈希表？ 本题值域较小，可以偏移下标实现，但哈希表更通用且不依赖值域。
  • 为何不用取最大再写回？ 当前 x 对应的唯一转移随前驱最佳值单调不减；直接覆盖即可。写成 max 也正确但非必要。

常见错误

  • 把子序列误认为连续子数组。
  • 前驱写成 x + difference；正确关系是 x - difference。
  • 先更新 dp[x] 再读取前驱；当差值为 0 时容易造成语义混乱，应先计算旧状态。
  • 只统计数值频次，忽略原数组的顺序。
  • 使用双重循环，导致 n = 10⁵ 时超时。
