LCR 113 · MEDIUM

课程表 II

现在你总共有 numCourses 门课需要选，给定课程之间的先修关系，请返回一个可行的修课顺序；若无法完成所有课程，返回空数组。

开始推演

首屏只呈现任务与依赖关系；题解默认隐藏。

题意

每个关系 [a, b] 表示学习课程 a 前必须先完成课程 b。返回任意一个满足全部依赖的顺序即可。

示例 1

输入：numCourses = 2, prerequisites = [[1,0]]
输出：[0,1]

示例 2

输入：numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
输出：[0,1,2,3]

约束

  • 1 <= numCourses <= 2000
  • 0 <= prerequisites.length <= numCourses * (numCourses - 1) / 2
  • prerequisites[i] = [ai, bi]，且 ai != bi
  • 所有先修关系互不重复。

先想一想

  1. 1哪门课可以最先学习？
  2. 2完成一门课程后，如何更新依赖它的课程？
  3. 3如果一直没有可学课程，意味着什么？

提示：记录每门课程还欠多少个前置条件，能直接暴露可开始的课程。

第 1 步：找到入度为 0 的课程

课程 0 没有前置条件，先将它加入队列。

第 2 步：取出 0 并削减后续入度

第 3 步：处理 1 和 2

第 4 步：课程 3 入队

SOLUTION

Kahn 拓扑排序

核心洞察

课程依赖是有向图。持续选择入度为 0 的课程，等价于每次选择没有未完成前置条件的课程。

过程

  1. 建立邻接表并统计每个节点的入度。
  2. 将所有入度为 0 的节点加入队列。
  3. 不断出队、加入答案、递减后继入度。
  4. 答案长度等于课程数则成功，否则有环。

边界

  • 没有依赖时，任意课程顺序都合法。
  • 存在环时，至少有一批节点永远无法入队。
  • 同一时刻的多个入度 0 节点可产生不同但均合法的答案。

复杂度

每个课程和每条依赖边最多处理一次，时间 O(V + E)，邻接表、入度数组和队列空间 O(V + E)。

四语言代码

class Solution {
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        List<List<Integer>> graph = new ArrayList<>(); int[] in = new int[numCourses];
        for (int i = 0; i < numCourses; i++) graph.add(new ArrayList<>());
        for (int[] p : prerequisites) { graph.get(p[1]).add(p[0]); in[p[0]]++; }
        Queue<Integer> q = new ArrayDeque<>(); for (int i = 0; i < numCourses; i++) if (in[i] == 0) q.offer(i);
        int[] ans = new int[numCourses]; int k = 0;
        while (!q.isEmpty()) { int c = q.poll(); ans[k++] = c; for (int next : graph.get(c)) if (--in[next] == 0) q.offer(next); }
        return k == numCourses ? ans : new int[0];
    }
}
var findOrder = function(numCourses, prerequisites) {
  const graph = Array.from({ length: numCourses }, () => []), inDegree = Array(numCourses).fill(0);
  for (const [course, pre] of prerequisites) { graph[pre].push(course); inDegree[course]++; }
  const queue = []; for (let i = 0; i < numCourses; i++) if (!inDegree[i]) queue.push(i);
  const order = []; for (let i = 0; i < queue.length; i++) { const course = queue[i]; order.push(course); for (const next of graph[course]) if (--inDegree[next] === 0) queue.push(next); }
  return order.length === numCourses ? order : [];
};
class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        graph = [[] for _ in range(numCourses)]; degree = [0] * numCourses
        for course, pre in prerequisites: graph[pre].append(course); degree[course] += 1
        queue = deque(i for i in range(numCourses) if degree[i] == 0); order = []
        while queue:
            course = queue.popleft(); order.append(course)
            for nxt in graph[course]:
                degree[nxt] -= 1
                if degree[nxt] == 0: queue.append(nxt)
        return order if len(order) == numCourses else []

public:
    vector<int> findOrder(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> graph(numCourses); vector<int> degree(numCourses), order; queue<int> q;
        for (auto& p : prerequisites) graph[p[1]].push_back(p[0]), degree[p[0]]++;
        for (int i = 0; i < numCourses; ++i) if (!degree[i]) q.push(i);
        while (!q.empty()) { int c = q.front(); q.pop(); order.push_back(c); for (int n : graph[c]) if (--degree[n] == 0) q.push(n); }
        return order.size() == numCourses ? order : vector<int>{};

替代方案与追问

DFS 三色标记也可检测环并在回溯时生成顺序。追问：若需字典序最小的课程顺序，可把队列替换为最小堆。

常见错误

  • 将关系 [a,b] 错建成 a → b。
  • 仅返回部分排序结果，却忽略未处理节点说明有环。
  • 入度降到 0 后忘记加入队列。
