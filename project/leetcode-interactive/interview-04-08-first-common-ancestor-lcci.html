INTERVIEW 04.08

首个共同祖先 让两路递归信号在最低处会合

一次后序 DFS 就能完成定位：每棵子树只向父节点回传一个最有价值的信号， 父节点根据左右返回值判断是继续中继，还是成为首个共同祖先。

进入信号站 ↓ 题解默认隐藏，可先独立推演

PROBLEM

题意

给定一棵普通二叉树，以及其中两个不同节点 p 和 q， 找到它们最深的共同祖先。祖先允许等于节点自身；树不保证是二叉搜索树， 并且不得把其他节点另存进额外数据结构。

输入保证

  • 所有节点值唯一。
  • p != q，并且两者都存在于树中。
  • 节点没有父指针，算法不能依赖 BST 的大小关系。

官方示例 1

输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1

输出：3

官方示例 2

输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4

输出：5

节点 5 是节点 4 的祖先，因此它也可以是答案。

可见字符说明：若输入字符串包含普通空格，本页统一显示为 ␠；本题示例没有字符串参数。

SOLUTION

题解：每棵子树只回传一个最有价值的节点

核心洞察

递归返回值不是“这一层的答案编号”，而是一条压缩后的信息： 当前子树里找到的目标节点，或已经确定的共同祖先。 左右都非空时，两条信号首次在当前节点相遇，因此这里就是最深的共同祖先。

为什么遇到目标就返回

如果当前节点就是 p 或 q，它一定可以代表这棵子树向上发送信号。 当另一个目标位于其后代时，题目“两个节点必定存在”的保证使得这个提前返回仍然正确， 当前目标自身最终会成为答案。

完整过程

  1. 空节点返回 null；遇到 p 或 q 返回当前节点。
  2. 递归求出 left 与 right。
  3. 若两者都非空，目标分居两侧，当前节点就是首次汇合点。
  4. 若只有一边非空，原样向上传递这条信号；两边都空则返回空。

正确性归纳

对任意子树，递归结果满足三选一：没有目标时为空；只含一个目标时返回该目标； 同时含两个目标时返回它们在该子树内的最近公共祖先。空树与单节点满足基例， 左右返回值的四种组合恰好保持该不变量，因此根调用返回全树答案。

边界

  • 共同祖先可以等于 p 或 q。
  • 树退化成链时，递归深度达到 n。
  • 题目保证目标都存在；若取消该条件，需要额外返回找到目标的数量。
  • 比较节点身份，不依赖节点值大小或 BST 性质。

复杂度

最坏访问每个节点一次，时间复杂度 O(n)。 只使用递归调用栈，空间复杂度 O(h)；平衡树为 O(log n)，链形树最坏为 O(n)。

替代方案

  • 分别记录根到 p、q 的路径，再找最后一个公共节点：直观，但需 O(h) 路径空间。
  • 建立父指针映射，再用祖先集合求交：适合多次查询，但额外占用 O(n)，不符合本题限制。
  • 反复判断目标属于左子树还是右子树：无需父指针，但会重复扫描，最坏 O(n²)。

常见错误

  • 把普通二叉树误当 BST，根据值大小选择方向。
  • 忘记“节点自身也是祖先”，导致示例 2 返回错误。
  • 只有左右都非空才返回节点，却没有把单侧信号继续上传。
  • 用节点值代替节点引用；当题目不保证值唯一时会失效。

面试追问

如果节点可能不存在？

返回结构体 {node, foundCount}，只有根结果计数为 2 才接受答案。

如果要回答很多次查询？

可预处理深度与倍增祖先表，每次查询降为 O(log n)，但需要 O(n log n) 空间。

如何避免递归栈溢出？

用显式栈模拟后序遍历并维护每个节点的处理阶段；实现更长，但可控制内存位置。

若树有父指针？

问题退化为两条父链求交，可用深度对齐或祖先集合解决。 

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) {
            return root;
        }

        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        if (left != null && right != null) {
            return root;
        }
        return left != null ? left : right;
    }
}

    if (root === null || root === p || root === q) {
        return root;
    }

    const left = lowestCommonAncestor(root.left, p, q);
    const right = lowestCommonAncestor(root.right, p, q);

    if (left !== null && right !== null) {
        return root;
    }
    return left !== null ? left : right;
};

public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (root == nullptr || root == p || root == q) {
            return root;
