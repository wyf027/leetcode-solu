不同字符的
最小子序列

从字符串里保留每种字符恰好一次，同时让结果的字典序尽可能小。先亲手观察选择过程，再决定是否展开完整题解。

栈贪心字符串单调栈非付费题
Problem

题目

给定字符串 s，返回它的一个子序列。这个子序列必须包含 s 中出现过的每一种字符，并且每种字符恰好出现一次；在所有满足条件的子序列中，返回字典序最小的那个。

子序列可通过删除若干字符得到，但不能改变剩余字符的相对顺序。

约束

  • 1 <= s.length <= 1000
  • s 仅由小写英文字母组成。
函数签名
smallestSubsequence(s: string) → string
Example 1
输入：s = "bcabc" 输出："abc"

可删除开头的 b、c，按原顺序留下 a、b、c。

Example 2
输入：s = "cbacdcbc" 输出："acdb"

结果包含 a、b、c、d 各一次，并满足可行子序列中的最小字典序。

Solution

贪心 + 单调栈

核心洞察

想让字典序更小，遇到较小字符时应尽量移除栈顶较大的字符；但只有当被移除字符在后面还会再次出现时，移除才安全。另用集合保证每种字符最多入栈一次。

完整过程

  1. 统计每个字符尚未扫描的出现次数。
  2. 从左到右扫描，先将当前字符的剩余次数减一。
  3. 若当前字符已在栈中，跳过它，避免重复。
  4. 否则，当栈顶字符比当前字符大，且栈顶在后面仍会出现，就弹出栈顶并清除其“已使用”标记。
  5. 将当前字符压栈并标记已使用。扫描结束后，栈中字符拼接即为答案。

正确性说明

合法性：已使用集合阻止重复字符入栈；某字符只有在未来仍有副本时才会被弹出，所以每个不同字符最终至少保留一次。因此结果恰好包含所有不同字符各一次。

最小性：当当前字符更小且弹出是安全的，保留较大的栈顶会让结果在首次差异处更大，弹出必然不劣；若栈顶后面不再出现，则它不能被弹出，否则答案不合法。算法在每个位置都执行所有安全的字典序改进，因此得到合法结果中的字典序最小者。

边界情况

  • 单字符：直接返回自身。
  • 全部相同：只保留一个字符。
  • 已严格递增：不会弹栈。
  • 严格递减且无重复：任何字符都不能安全弹出，保留原顺序。
  • 弹栈后再遇到被弹字符：它可重新入栈，保证字符不丢失。

复杂度

每个字符至多入栈、出栈各一次，时间复杂度 O(n)；计数、集合与栈占用 O(k)，其中 k 是不同字符数（本题最多 26）。

替代方案

可以递归地选取一个最小可行首字符：在保证后缀仍覆盖全部种类的最早边界内找最小字符，再删除后缀中该字符并递归。思路直观，但反复构造字符串可能达到 O(n²)；单调栈更直接高效。

面试追问

  • 若字符集扩展到 Unicode，如何替换固定长度计数数组？
  • 为什么判断条件必须是“栈顶未来仍会出现”，而不是“当前字符未来仍会出现”？
  • 如果要求字典序最大，应怎样改动比较方向？
  • 能否用最后出现位置代替剩余计数？可以，判断 last[top] > i 即可。

常见错误

  • 不检查未来是否还有栈顶字符，导致某种字符永久丢失。
  • 字符已在栈中仍重复压入。
  • 弹栈后忘记更新已使用集合。
  • 使用 >= 比较，破坏重复字符处理逻辑。

class Solution {
    public String smallestSubsequence(String s) {
        int[] remaining = new int[26];
        boolean[] used = new boolean[26];
        for (char c : s.toCharArray()) remaining[c - 'a']++;

        StringBuilder stack = new StringBuilder();
        for (char c : s.toCharArray()) {
            int x = c - 'a';
            remaining[x]--;
            if (used[x]) continue;

            while (stack.length() > 0) {
                char top = stack.charAt(stack.length() - 1);
                if (top <= c || remaining[top - 'a'] == 0) break;
                used[top - 'a'] = false;
                stack.deleteCharAt(stack.length() - 1);
            }
            stack.append(c);
            used[x] = true;
        }
        return stack.toString();
    }
}

var smallestSubsequence = function(s) {
    const remaining = new Array(26).fill(0);
    const used = new Array(26).fill(false);
    for (const c of s) remaining[c.charCodeAt(0) - 97]++;

    const stack = [];
    for (const c of s) {
        const x = c.charCodeAt(0) - 97;
        remaining[x]--;
        if (used[x]) continue;

        while (stack.length) {
            const top = stack[stack.length - 1];
            const topIndex = top.charCodeAt(0) - 97;
            if (top <= c || remaining[topIndex] === 0) break;
            used[topIndex] = false;
            stack.pop();
        }
        stack.push(c);
        used[x] = true;
    }
    return stack.join('');
};
class Solution:
    def smallestSubsequence(self, s: str) -> str:
        remaining = [0] * 26
        used = [False] * 26
        for c in s:
            remaining[ord(c) - ord('a')] += 1

        stack = []
        for c in s:
            index = ord(c) - ord('a')
            remaining[index] -= 1
            if used[index]:
                continue

            while stack:
                top_index = ord(stack[-1]) - ord('a')
                if stack[-1] <= c or remaining[top_index] == 0:
                    break
                used[top_index] = False
                stack.pop()
            stack.append(c)
            used[index] = True
        return ''.join(stack)
class Solution {
public:
    string smallestSubsequence(string s) {
        vector<int> remaining(26, 0);
        vector<bool> used(26, false);
        for (char c : s) remaining[c - 'a']++;

        string stack;
        for (char c : s) {
            int x = c - 'a';
            remaining[x]--;
            if (used[x]) continue;

            while (!stack.empty()) {
                char top = stack.back();
                if (top <= c || remaining[top - 'a'] == 0) break;
                used[top - 'a'] = false;
                stack.pop_back();
            }
            stack.push_back(c);
            used[x] = true;
        }
        return stack;
    }
};
