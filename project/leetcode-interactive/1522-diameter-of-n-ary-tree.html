N 叉树的直径

给定一棵 N 叉树，求任意两个节点之间最长路径的长度。路径不一定经过根节点，长度按经过的边数计算。

阅读题目 探索路径
输入N 叉树根节点
输出最长路径边数
注意可能不经过根

Problem

题目说明

任务

N 叉树节点由一个整数值和若干子节点组成。树的直径是树中任意两节点之间最长简单路径的长度；路径可以穿过根，也可以完全位于某棵子树中。请返回直径所包含的边数。

函数参数形式：diameter(root)，其中 root 是 N 叉树的根节点；空树返回 0。

数组示例使用层序序列化：null 用来分隔相邻节点的子节点列表。

约束

  • 树中节点总数在 0 到 10⁴ 之间。
  • N 叉树的深度不超过 1000。
  • 每个节点含有整数值 val 和子节点列表 children。
  • 返回值按边计数，因此单节点树的直径为 0。

示例 1

输入：root = [1,null,3,2,4,null,5,6] 输出：3 解释：例如 5 → 3 → 1 → 2，共经过 3 条边。

示例 2

输入：root = [1,null,2,null,3,4,null,5,null,6] 输出：4 解释：最长路径可连接两条较深的分支。

示例 3

输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14] 输出：7

核心洞察：每个节点只需要两条最深的向下分支

一条经过当前节点的最长路径，由不同子树中的两条最长向下分支拼成。后序 DFS 让我们先得到每个孩子的高度，再更新答案。

完整过程

  1. 对每个孩子递归求高度。这里节点高度定义为：从该节点向下到叶节点的最大边数。
  2. 孩子能贡献的分支长度为 dfs(child) + 1。
  3. 扫描所有孩子，只维护最大的 first 与次大的 second。
  4. 经过当前节点的候选直径是 first + second，用它更新全局答案。
  5. 向父节点返回 first，因为向上延伸的单条路径只能选择一个孩子。

正确性说明

引理：DFS 返回值等于当前节点到其子树任意节点的最大距离。叶节点没有孩子，返回 0；非叶节点选择所有孩子贡献中最大的一条，因此归纳成立。

定理：任意最长路径都有唯一的最高公共节点。路径在此处分成至多两条、分别进入不同子树的向下分支。算法在处理该节点时恰好取最长的两条分支，因此会考察到该路径；全局最大值即为整棵树的直径。

边界情况

  • 空树：直接返回 0。
  • 单节点：没有边，结果为 0。
  • 退化成链：每个节点最多一个孩子，次长分支始终为 0。
  • 根节点不在最长路径上：全局答案会在内部子树节点处更新。
  • 深树：递归深度可达 1000；若运行环境栈限制严格，可改写为显式栈后序遍历。

复杂度

每个节点与每条父子边只处理一次，时间复杂度为 O(n)。递归栈占用 O(h)，其中 h 是树高；最坏为 O(n)。

替代方案

可先任选节点寻找最远端点，再从该端点寻找最远距离，模拟无权树的“两次 BFS/DFS”。但 N 叉树节点通常只有孩子指针，需要先构建无向邻接表，空间为 O(n)。树形 DP 更直接，也无需父指针。

class Solution {
    private int answer = 0;

    public int diameter(Node root) {
        if (root == null) return 0;
        height(root);
        return answer;
    }

    private int height(Node node) {
        int first = 0;
        int second = 0;

        for (Node child : node.children) {
            int branch = height(child) + 1;
            if (branch > first) {
                second = first;
                first = branch;
            } else if (branch > second) {
                second = branch;
            }
        }

        answer = Math.max(answer, first + second);
        return first;
    }
}

class Node:

class Solution:
    def diameter(self, root: 'Node') -> int:
        answer = 0

        def height(node: 'Node') -> int:
            nonlocal answer
            first = second = 0

            for child in node.children:
                branch = height(child) + 1
                if branch > first:
                    second, first = first, branch
                elif branch > second:
                    second = branch

            answer = max(answer, first + second)
            return first

        if root is not None:
            height(root)
        return answer

常见错误

  • 把节点数当作路径长度，导致结果多 1。
  • 只取一条最大分支更新直径，遗漏穿过当前节点的两侧路径。
  • 只在根节点计算，遗漏完全位于某个子树内的最长路径。
  • 存下所有孩子高度再排序；虽正确，但没有必要，维护前两大即可。
  • 忘记处理 root == null。

面试追问

  1. 若边带权，如何修改？将 + 1 攸成加对应边权；若允许负权，还要明确空路径规则。
  2. 如何返回直径上的节点序列？记录每个节点的最佳向下端点，并在答案更新时保存两端点，再恢复路径。
  3. 递归可能栈溢出怎么办？用显式栈记录“进入/退出”状态，退出节点时进行同样的两大分支合并。
  4. 如果树会动态加边，如何维护直径？可讨论树的动态数据结构、重链分解或按批次重算的取舍。
