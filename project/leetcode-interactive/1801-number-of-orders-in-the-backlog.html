积压订单中的订单总数

Number of Orders in the Backlog

一批订单进入市场后，哪些能成交，哪些会留下？
先读规则，再推进订单簿，最后展开题解。

官方题目 ↗

01 / 交易规则

输入二维整数数组 orders，每批为 orders[i] = [price, amount, orderType]，分别表示价格、独立订单笔数、订单类型。0 是买单，1 是卖单。按数组顺序提交，前一批的全部订单先于后一批处理。积压订单簿初始为空。

买单到达

查看积压卖单的最低价。若卖价 ≤ 当前买价，双方匹配成交；继续处理剩余数量，直到买单耗尽或不能继续成交。剩余买单进入积压。

卖单到达

查看积压买单的最高价。若买价 ≥ 当前卖价，双方匹配成交；继续处理剩余数量，直到卖单耗尽或不能继续成交。剩余卖单进入积压。

全部提交后，返回积压订单的总笔数对 10⁹ + 7 取余的结果。不是批次数，也不是订单金额。

约束

  • 1 ≤ orders.length ≤ 10⁵
  • orders[i].length == 3
  • 1 ≤ price, amount ≤ 10⁹
  • orderType 为 0 或 1

官方示例 1

输入：orders = [[10,5,0],[15,2,1],[25,1,1],[30,4,0]]
输出：6

前三批均暂存。最后价格 30 的 4 笔买单先消耗价格 15 的 2 笔卖单，再消耗价格 25 的 1 笔卖单，剩 1 笔买单入簿。最终买单为价格 10 的 5 笔和价格 30 的 1 笔，共 6 笔。

官方示例 2

输入：orders = [[7,1000000000,1],[15,3,0],[5,999999995,0],[5,1,1]]
输出：999999984

价格 7 的卖单先被价格 15 的买单消耗 3 笔，剩 999999997 笔。价格 5 的买单无法匹配价格 7 的卖单，先入簿，再被最后的卖单消耗 1 笔，剩 999999994 笔。总量 1999999991，取余为 999999984。

04 / 独立题解

展开算法推导与四语言代码。

核心洞察：只访问两侧的最优价格

买方使用大顶堆，卖方使用小顶堆，每个节点存价格和剩余笔数。买单只需查最低卖价，卖单只需查最高买价。数量再大也只占一个节点。

完整过程

  1. 按原顺序读入当前批次，选择对侧堆。
  2. 对侧非空且最优价格可成交时，令 k 为双方剩余量的最小值，两侧同时减去 k。
  3. 对侧余量归零则弹出。当前仍有余量则继续找下一个最优价格。
  4. 无法继续成交时，将当前非零余量入本侧堆。
  5. 将两堆所有剩余笔数相加并取模。

示例 1 最后一批：买 (30,4) → 消耗卖 (15,2)，余 2 → 消耗卖 (25,1)，余 1 → 入买堆。原先买 (10,5) 保留，最终共 6 笔。

正确性

归纳不变量：每批处理完后，两堆恰好包含此前所有未成交订单。初始空堆成立。处理下一批时，堆顶就是题目指定的最低卖价或最高买价。批量扣除双方余量的最小值等价于逐笔执行相同匹配；每次扣减后保存真实余量。若堆顶不能成交，其他价格更差，也不能成交。循环结束后，本批耗尽或所有对手不兼容，将非零余量入堆恰好维护不变量。因此最后两堆剩余量之和就是答案。

复杂度

设 n 为批次数。每轮成交至少耗尽当前批次或一个积压批次，故成交循环总次数为 O(n)，不是 O(n²)。每次堆操作 O(log n)，总时间 O(n log n)，空间 O(n)。弹出后放回部分余量也只增加常数次堆操作。

边界与常见错误

  • 同价可以成交，比较必须包含等号。
  • 对侧为空或价格不兼容时直接入簿。部分成交要保留余量，零数量节点要删除。
  • 不能按笔数循环，单批可达 10⁹；不能统计堆大小代替笔数之和。
  • 不能把输入按价格重排，到达顺序决定此前的成交。
  • 撮合用真实数量，不可提前对余量取模；只对答案累计取模。
  • 最多 10¹⁴ 笔，Java/C++ 用 64 位累计。JavaScript Number 安全整数范围足够；Python 整数可自动扩展。
  • Java/JavaScript 只更新堆顶数量，排序键价格未变，因此无需重新调整堆。Python/C++ 示例弹出后重新插入余量。

替代方案

有序映射按价格聚合数量，维护最大买价和最小卖价，也可达到 O(n log n)。逐次线性扫描积压列表最坏 O(n²)，只适合小数据。本页演示固定最多 4 批，以排序列表保存快照便于回退；提交代码使用堆。

面试追问

  • 同价订单需要 FIFO 吗？本题只求总余量，不需要；若输出成交明细，可加入到达序号作为第二排序键。
  • 如何支持撤单？用订单 ID 索引剩余数量，结合惰性删除或可定位的堆。
  • 如何实时报告积压量？新批到达时加 amount，每成交 k 对减 2k，最后按需取模。
  • 为什么不展开每笔订单？空间和时间必须由批次数而不是 amount 决定。

Java

import java.util.PriorityQueue;

class Solution {
    public int getNumberOfBacklogOrders(int[][] orders) {
        PriorityQueue<int[]> buy = new PriorityQueue<>(
            (a, b) -> Integer.compare(b[0], a[0]));
        PriorityQueue<int[]> sell = new PriorityQueue<>(
            (a, b) -> Integer.compare(a[0], b[0]));
        for (int[] order : orders) {
            int price = order[0], amount = order[1], type = order[2];
            PriorityQueue<int[]> other = type == 0 ? sell : buy;
            while (amount > 0 && !other.isEmpty() &&
                   (type == 0 ? other.peek()[0] <= price : other.peek()[0] >= price)) {
                int[] top = other.peek();
                int k = Math.min(amount, top[1]);
                amount -= k;
                top[1] -= k;
                if (top[1] == 0) other.poll();
            }
            if (amount > 0) (type == 0 ? buy : sell).offer(new int[]{price, amount});
        }
        long answer = 0;
        for (int[] x : buy) answer = (answer + x[1]) % 1_000_000_007;
        for (int[] x : sell) answer = (answer + x[1]) % 1_000_000_007;
        return (int) answer;
    }
}

JavaScript

class Heap {
    constructor(before) { this.a = []; this.before = before; }
    peek() { return this.a[0]; }
    push(x) {
        const a = this.a;
        a.push(x);
        let i = a.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (!this.before(a[i], a[p])) break;
            [a[i], a[p]] = [a[p], a[i]];
            i = p;
        }
    }
    pop() {
        const a = this.a, root = a[0], last = a.pop();
        if (a.length) {
            a[0] = last;
            let i = 0;
            while (true) {
                let best = i, l = 2 * i + 1, r = l + 1;
                if (l < a.length && this.before(a[l], a[best])) best = l;
                if (r < a.length && this.before(a[r], a[best])) best = r;
                if (best === i) break;
                [a[i], a[best]] = [a[best], a[i]];
                i = best;
            }
        }
        return root;
    }
}
var getNumberOfBacklogOrders = function(orders) {
    const buy = new Heap((a,b) => a[0] > b[0]);
    const sell = new Heap((a,b) => a[0] < b[0]);
    for (let [price, amount, type] of orders) {
        const other = type === 0 ? sell : buy;
        while (amount > 0 && other.a.length &&
               (type === 0 ? other.peek()[0] <= price : other.peek()[0] >= price)) {
            const top = other.peek(), k = Math.min(amount, top[1]);
            amount -= k;
            top[1] -= k;
            if (top[1] === 0) other.pop();
        }
        if (amount > 0) (type === 0 ? buy : sell).push([price, amount]);
    }
    let answer = 0;
    for (const heap of [buy, sell])
        for (const [, amount] of heap.a)
            answer = (answer + amount) % 1000000007;
    return answer;
};

Python

from typing import List
import heapq

class Solution:
    def getNumberOfBacklogOrders(self, orders: List[List[int]]) -> int:
        buy, sell = [], []
        for price, amount, kind in orders:
            other = sell if kind == 0 else buy
            while amount and other:
                best = other[0][0] if kind == 0 else -other[0][0]
                if (kind == 0 and best > price) or (kind == 1 and best < price):
                    break
                key, remaining = heapq.heappop(other)
                k = min(amount, remaining)
                amount -= k
                remaining -= k
                if remaining:
                    heapq.heappush(other, (key, remaining))
            if amount:
                if kind == 0:
                    heapq.heappush(buy, (-price, amount))
                else:
                    heapq.heappush(sell, (price, amount))
        return sum(amount for heap in (buy, sell) for _, amount in heap) % 1_000_000_007

C++

#include <vector>
#include <queue>
#include <functional>
#include <utility>
#include <algorithm>
using namespace std;

class Solution {
public:
    int getNumberOfBacklogOrders(vector<vector<int>>& orders) {
        using Order = pair<int, int>;
        priority_queue<Order> buy;
        priority_queue<Order, vector<Order>, greater<Order>> sell;
        for (const auto& order : orders) {
            int price = order[0], amount = order[1];
            if (order[2] == 0) {
                while (amount > 0 && !sell.empty() && sell.top().first <= price) {
                    auto [p, left] = sell.top(); sell.pop();
                    int k = min(amount, left);
                    amount -= k; left -= k;
                    if (left > 0) sell.push({p, left});
                }
                if (amount > 0) buy.push({price, amount});
            } else {
                while (amount > 0 && !buy.empty() && buy.top().first >= price) {
                    auto [p, left] = buy.top(); buy.pop();
                    int k = min(amount, left);
                    amount -= k; left -= k;
                    if (left > 0) buy.push({p, left});
                }
                if (amount > 0) sell.push({price, amount});
            }
        }
        long long answer = 0;
        const long long MOD = 1000000007;
        while (!buy.empty()) { answer = (answer + buy.top().second) % MOD; buy.pop(); }
        while (!sell.empty()) { answer = (answer + sell.top().second) % MOD; sell.pop(); }
        return static_cast<int>(answer);
    }
};
