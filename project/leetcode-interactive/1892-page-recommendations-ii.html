朋友喜欢的页面，哪些值得推荐给你？从两张关系表出发，为每位用户找到新页面，并说明有多少位好友喜欢它。

01 / PROBLEM

两张输入表，一份推荐清单

Friendship 的每行表示两人互为好友；Likes 的每行表示一个用户喜欢一个页面。为所有用户找出：至少被一位直接好友喜欢，同时本人尚未喜欢的页面。每个用户和页面组合输出一行，附上喜欢该页面的不同好友人数。结果顺序不限。

Friendship

user1_id INT, user2_id INT

联合主键为 (user1_id, user2_id)。友情无方向，不可假定第一列 ID 总比第二列小。

Likes

user_id INT, page_id INT

联合主键为 (user_id, page_id)。同一用户对同一页的点赞不会重复。

输出与约束

  • user_id：接收推荐的人；page_id：被推荐页面；friends_likes：喜欢该页面的好友人数。
  • 只推荐直接好友喜欢的页面；没有可推荐页面的用户不输出行，不生成计数 0 的占位行。
  • 公开题面只提供整数类型和上述主键约束，没有给出行数或 ID 数值范围，此处不编造上限。

题解 · 双向关系与反连接

核心洞察

推荐证据是一条 (接收用户 u, 好友 v, 页面 p) 三元组。把所有好友的点赞展开，再去掉 u 自己已经喜欢的页面；按 (u,p) 汇总，就得到每页有多少好友支持。

完整过程

  1. 分别从 Friendship 两列看友情，把原方向与反方向投影为 (user_id, friend_id)，使用 UNION 去重。主键只保证有序对唯一，不能据此假定 (a,b) 和 (b,a) 不会共存。
  2. 按 friend_id 与 Likes.user_id 做内连接，每行代表一位好友喜欢一个页面。无点赞的好友不会生成空页面。
  3. 用 NOT EXISTS 检查接收用户是否喜欢该页面，同时比较 user_id 和 page_id；存在本人点赞则删除该证据。
  4. 按接收用户和页面分组并 COUNT(*)。方向关系和点赞对已唯一，每位好友只贡献一行。

正确性

可靠性：保留行由真实的直接好友点赞产生，并通过本人未点赞条件，因此输出的页面一定可推荐。

完整性：任取应推荐给 u 的页面 p，必存在好友 v 喜欢 p。双向关系必含 (u,v)，内连接会产生该证据，排除条件也不会删掉它，故 (u,p) 一定进入结果。

计数：UNION 使同一方向好友对唯一，Likes 联合主键使好友页面对唯一。每个 (u,p) 分组的行与喜欢 p 的不同好友一一对应，COUNT(*) 因而准确。

边界与常见错误

  • 只看 user1_id 会漏掉反向好友，示例 (6,1) 就说明了这一点。
  • UNION ALL 配合 COUNT(*) 可能重复计数；若不去重关系，可改 COUNT(DISTINCT friend_id)。
  • 只按页面分组会混合不同用户；COUNT(DISTINCT page_id) 则把每组人数错误算成 1。
  • 好友点赞使用 LEFT JOIN 可能制造 NULL 页面并被 COUNT(*) 计为一条；这里采用 INNER JOIN。
  • 排除本人点赞时必须同时匹配用户和页面；不能因任意人喜欢该页面就排除。
  • 空表、无好友、好友无点赞、本人全部已赞时都可返回空结果。无需输出 NULL 或计数 0；两跳好友不计入本题。

复杂度

令 F 为友情行数、L 为点赞行数、J 为双向友情连接点赞后的证据行数、G 为最终分组数。在哈希去重、索引和聚合的模型下，期望时间为 O(F + L + J)，J 最坏可达 O(F·L)。四语言参考实现的空间为 O(F + L + G)，包含返回结果；逐用户计数，无需存储全部证据。

数据库实际复杂度取决于执行计划。排序去重可能需 O(F log F)，排序聚合可能需 O(J log J)，物化连接可能占 O(J) 空间。Likes 的 (user_id, page_id) 主键索引可辅助查询好友点赞及本人点赞。这些是分析，未进行性能测量。

替代方案

用 LEFT JOIN 本人点赞表再筛选本人侧主键为 NULL，可以实现反连接；也可先聚合再 NOT EXISTS 排除已点赞组，因为排除条件只依赖分组键。不要对可能含 NULL 的子查询结果直接套用 NOT IN。

面试追问

  • 每人仅 Top K？先聚合，再按用户分区使用 ROW_NUMBER，以人数降序、页面 ID 升序取前 K；若并列全保留，需另定排名规则。
  • 仅推荐给一个用户？在双向展开的两个分支中先筛选接收用户，减少连接量。
  • 新增或取消点赞？更新该用户直接好友对该页面的支持计数，并同步处理本人是否还应收到该页推荐；计数归零后删除推荐。

MySQL 8 · 官方可提交语言

WITH friends AS (
    SELECT user1_id AS user_id, user2_id AS friend_id
    FROM Friendship
    UNION
    SELECT user2_id AS user_id, user1_id AS friend_id
    FROM Friendship
)
SELECT f.user_id, l.page_id, COUNT(*) AS friends_likes
FROM friends AS f
JOIN Likes AS l ON l.user_id = f.friend_id
WHERE NOT EXISTS (
    SELECT 1 FROM Likes AS own
    WHERE own.user_id = f.user_id
      AND own.page_id = l.page_id
)
GROUP BY f.user_id, l.page_id;

Java · 本地语义参考

import java.util.*;

class Solution {
    public List<int[]> recommendPage(int[][] friendship, int[][] likes) {
        Map<Integer, Set<Integer>> friends = new HashMap<>();
        Map<Integer, Set<Integer>> pages = new HashMap<>();
        for (int[] row : friendship) {
            friends.computeIfAbsent(row[0], k -> new HashSet<>()).add(row[1]);
            friends.computeIfAbsent(row[1], k -> new HashSet<>()).add(row[0]);
        }
        for (int[] row : likes)
            pages.computeIfAbsent(row[0], k -> new HashSet<>()).add(row[1]);
        List<int[]> result = new ArrayList<>();
        for (var entry : friends.entrySet()) {
            int user = entry.getKey();
            Set<Integer> own = pages.getOrDefault(user, Collections.emptySet());
            Map<Integer, Integer> counts = new HashMap<>();
            for (int friend : entry.getValue()) {
                for (int page : pages.getOrDefault(friend, Collections.emptySet())) {
                    if (!own.contains(page)) counts.merge(page, 1, Integer::sum);
                }
            }
            for (var count : counts.entrySet())
                result.add(new int[]{user, count.getKey(), count.getValue()});
        }
        return result;
    }
}

JavaScript · 本地语义参考

function recommendPage(friendship, likes) {
  const friends = new Map(), pages = new Map();
  const add = (map, key, value) => {
    if (!map.has(key)) map.set(key, new Set());
    map.get(key).add(value);
  };
  for (const [a, b] of friendship) {
    add(friends, a, b);
    add(friends, b, a);
  }
  for (const [user, page] of likes) add(pages, user, page);
  const result = [];
  for (const [user, neighbors] of friends) {
    const own = pages.get(user) || new Set();
    const counts = new Map();
    for (const friend of neighbors) {
      for (const page of pages.get(friend) || []) {
        if (!own.has(page)) counts.set(page, (counts.get(page) || 0) + 1);
      }
    }
    for (const [page, count] of counts) result.push([user, page, count]);
  }
  return result;
}

from collections import defaultdict, Counter

def recommend_page(friendship: list[list[int]],
                   likes: list[list[int]]) -> list[list[int]]:
    friends = defaultdict(set)
    pages = defaultdict(set)
    for a, b in friendship:
        friends[a].add(b)
        friends[b].add(a)
    for user, page in likes:
        pages[user].add(page)
    result = []
    for user, neighbors in friends.items():
        own = pages.get(user, set())
        counts = Counter()
        for friend in neighbors:
            for page in pages.get(friend, set()):
                if page not in own:
                    counts[page] += 1
        result.extend([user, page, count] for page, count in counts.items())
    return result

C++17 · 本地语义参考

#include <array>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    vector<array<int, 3>> recommendPage(
        const vector<array<int, 2>>& friendship,
        const vector<array<int, 2>>& likes) {
        unordered_map<int, unordered_set<int>> friends, pages;
        for (const auto& row : friendship) {
            friends[row[0]].insert(row[1]);
            friends[row[1]].insert(row[0]);
        }
        for (const auto& row : likes) pages[row[0]].insert(row[1]);
        vector<array<int, 3>> result;
        const unordered_set<int> empty;
        for (const auto& [user, neighbors] : friends) {
            auto ownIt = pages.find(user);
            const auto& own = ownIt == pages.end() ? empty : ownIt->second;
            unordered_map<int, int> counts;
            for (int friendId : neighbors) {
                auto it = pages.find(friendId);
                if (it == pages.end()) continue;
                for (int page : it->second)
                    if (!own.count(page)) ++counts[page];
            }
            for (const auto& [page, count] : counts)
                result.push_back({user, page, count});
        }
        return result;
    }
};
