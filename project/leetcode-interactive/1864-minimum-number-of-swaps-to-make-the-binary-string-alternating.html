Minimum Number of Swaps to Make the Binary String Alternating

把相同字符分开，让 0 与 1 交替出现。你会选择交换哪两个位置？

题目与规则

给定一个只包含 0 和 1 的字符串 s。每次可以交换其中任意两个位置的字符，两个位置不需要相邻。返回将它变成交替字符串所需的最少交换次数；如果无法做到，返回 -1。

交替字符串要求每一对相邻字符都不同。例如 010、1010 符合要求，0100 不符合。

参数与返回值

minSwaps(s: string) → integer

长度：1 ≤ s.length ≤ 1000
每个 s[i] 都是 '0' 或 '1'。

EDITORIAL

独立题解

准备好后，再展开推导与代码。

01 / 核心洞察：先确定目标，再数错位

交换不会改变 0 和 1 的数量。交替排列中的两种字符数量最多相差 1，因此数量差大于 1 时必然无解。若数量相同，两种开头都可行；若数量相差 1，只能由数量更多的字符开头。

固定一个数量匹配的交替目标后，错位只有两种：“当前为 0，目标要 1”和“当前为 1，目标要 0”。两种错位数量相等，每次交换一对相反错位，恰好修复两处。答案就是该目标的错位总数除以 2。

02 / 完整过程

  1. 统计 zeros 与 ones，若绝对差大于 1，返回 -1。
  2. 定义 cost(first)：下标 i 的目标位为 (first + i) % 2，逐位统计不同的位置，再除以 2。
  3. 若 0 更多，返回 cost(0)；若 1 更多，返回 cost(1)。
  4. 两种字符一样多时，返回 min(cost(0), cost(1))。

以 s = "111000" 为例：目标 010101 在下标 0、2、3、5 错位，需要 2 次；目标 101010 在下标 1、4 错位，只需交换这两个位置，答案为 1。代码只计数，不需要实际修改字符串。

03 / 正确性论证

可行目标完备：交替字符串的首位一旦确定，后续字符全部确定，所以只有 0 开头、1 开头两种候选。字符数量不匹配的候选无法通过交换获得，数量匹配的候选可通过重排获得。

下界：相对于固定目标，设有 m 个错位。一次交换只影响两个位置，最多修复两个错位，所以至少需要 m / 2 次交换。

可达：由于当前串与目标串的字符数量相同，两类相反错位必然等量。把它们逐对交换，每次都修复两个错位，恰好使用 m / 2 次，达到下界。枚举全部可行目标并取最小值，便得到全局最优解。

04 / 边界与复杂度

  • 单个字符天然交替，结果是 0。
  • 全相同且长度大于 1，无解。
  • 已经交替时，至少一个可行目标的代价为 0。
  • 奇数长度不能任选起点；数量更多的一方必须占据首尾。

时间 O(n)：统计一次，再扫描至多两个候选。额外空间 O(1)：提交代码仅存计数器，不创建目标数组。教学演示保存中间状态，其空间开销不代表提交算法。

05 / 替代方案

也可只统计偶数下标中“应放 0 却放 1”（或反向）的数量：每一处这样的错误都能与另一类错误配成一次交换，直接得到答案。它仍是 O(n) 时间、O(1) 空间。

显式存储两类错位下标并配对，可以输出具体交换方案，但需 O(n) 额外空间。本题只返回次数，无需保存交换列表。

06 / 常见错误

  • 把题目误读为只能相邻交换：这里任意两个位置都能直接交换，距离没有代价。
  • 把相邻相等的对数当作答案：一次交换会影响多个相邻关系，不能这样累计。
  • 没检查字符数量，就对不可行目标计算错位数除以 2。
  • 等量时只看一种起点；或者奇数长度时比较了不可行起点。
  • 只数一种错位后又除以 2：仅当统计了所有错位时才除以 2。

07 / 面试追问

若只允许相邻交换？固定可行目标，取所有 1 的当前位置与目标位置，按顺序配对，距离绝对值之和就是所需相邻交换数；此时远距离移动必须逐步完成。

若要返回具体交换序列？分别记录两类错位下标，再一一配对。序列长度等于最少交换次数。

能否一次遍历求两种代价？可以边统计字符数量边累计 0 开头目标的错位数 m；另一个互补目标的错位数是 n − m。仍要先确认候选数量可行，再计算对应代价。

Java

class Solution {
    public int minSwaps(String s) {
        int ones = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '1') ones++;
        }
        int zeros = s.length() - ones;
        if (Math.abs(ones - zeros) > 1) return -1;
        if (zeros > ones) return cost(s, 0);
        if (ones > zeros) return cost(s, 1);
        return Math.min(cost(s, 0), cost(s, 1));
    }

    private int cost(String s, int first) {
        int mismatch = 0;
        for (int i = 0; i < s.length(); i++) {
            int expected = (first + i) % 2;
            if (s.charAt(i) - '0' != expected) mismatch++;
        }
        return mismatch / 2;
    }
}

/**

var minSwaps = function(s) {
    let ones = 0;
    for (const ch of s) {
        if (ch === '1') ones++;
    }
    const zeros = s.length - ones;
    if (Math.abs(ones - zeros) > 1) return -1;

    function cost(first) {
        let mismatch = 0;
        for (let i = 0; i < s.length; i++) {
            const expected = (first + i) % 2;
            if (Number(s[i]) !== expected) mismatch++;
        }
        return mismatch / 2;
    }

    if (zeros > ones) return cost(0);
    if (ones > zeros) return cost(1);
    return Math.min(cost(0), cost(1));
};

#include <algorithm>
#include <cstdlib>
#include <string>
using namespace std;

class Solution {
public:
    int minSwaps(string s) {
        int ones = 0;
        for (char ch : s) {
            if (ch == '1') ++ones;
        }
        int zeros = static_cast<int>(s.size()) - ones;
        if (abs(ones - zeros) > 1) return -1;

        auto cost = [&](int first) {
            int mismatch = 0;
            for (int i = 0; i < static_cast<int>(s.size()); ++i) {
                int expected = (first + i) % 2;
                if (s[i] - '0' != expected) ++mismatch;
            }
            return mismatch / 2;
        };

        if (zeros > ones) return cost(0);
        if (ones > zeros) return cost(1);
        return min(cost(0), cost(1));
    }
};
