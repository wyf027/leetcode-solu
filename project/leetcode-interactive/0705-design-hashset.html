Design HashSet

不给你现成哈希表，只给三个操作。你要设计一个集合，让加入、删除与查询彼此一致，并正确处理重复值与不存在的键。

01 / Problem

题意

不使用任何内建哈希表库，实现 MyHashSet：

  • void add(int key)：把 key 插入集合；重复插入不产生多个副本。
  • void remove(int key)：删除 key；若不存在则什么也不做。
  • boolean contains(int key)：返回集合是否包含 key。

约束

  • 0 ≤ key ≤ 10⁶
  • add、remove 与 contains 合计最多调用 10⁴ 次。

Solution Unlocked

质数桶 + 单向链表

核心洞察

先用哈希函数 index = key % B 把大范围整数映射到固定数量的桶。不同键可能得到同一个桶索引，这叫碰撞；每个桶用一条链保存所有碰撞键。

取质数 B = 769，让常见规律键更不容易集中。题目最多 10⁴ 次调用，这个固定桶数足够简洁。

完整过程

  1. 定位：三个操作都先计算 key % 769。
  2. 查询：遍历对应链，找到相等节点即返回 true，走完返回 false。
  3. 加入：先查询桶内是否已有该键；没有才在链头插入，保证集合去重。
  4. 删除：用哨兵节点统一删除链头与中间节点；找不到则不改动。

正确性说明

不丢键：加入键 k 时，它只会被放进编号 h(k) 的桶。查询与删除同样只访问 h(k)，因此一定会检查到它可能存在的唯一桶。

不误判：桶内仍逐个比较完整键，哈希值相同但键不同不会被当成相等。

无重复：加入前先查找；已存在时不插入，所以任意键至多有一个节点。

删除正确：删除只断开值等于目标键的节点。若不存在，不修改链。于是三个操作始终满足集合语义。

复杂度

  • 平均时间：add/remove/contains = O(1)
  • 最坏时间：碰撞全进一桶时为 O(n)
  • 空间：O(B + n)，其中 B = 769

边界与不变量

  • key = 0 合法，会进入 0 号桶；不能用 0 代表“空”。
  • key = 10⁶ 仍在题目范围内，取模后安全。
  • 重复 add 不增加节点；重复 remove 不报错。
  • 每个节点永远位于 key % 769 对应的桶中。

常见错误

  • 加入时不去重，让同一键产生多个节点，导致一次删除后仍查询为真。
  • 删除链头时忘记更新桶头；使用哨兵节点可统一处理。
  • 只比较哈希值而不比较完整键，碰撞时产生误判。
  • 声称最坏也是 O(1)；拉链过长时必须诚实记为 O(n)。

替代方案

直接寻址：约 1,000,001 位的布尔数组，三个操作都是严格 O(1)，本题键范围固定时非常直接；但它依赖值域大小，值域巨大或稀疏时浪费空间。

开放寻址：所有键存在一个数组，用线性/二次探测解决碰撞，局部性更好；删除需要墓碑标记，扩容也更复杂。

动态扩容：根据负载因子增加桶数并重哈希，可保持更稳的平均性能，但本题调用规模不要求。

面试追问

  • 为什么桶数常选质数？哪些输入分布仍会攻击固定取模？
  • 如何在负载因子过高时扩容，并保证迁移期间正确？
  • 线程安全版本如何避免整张表一把大锁？
  • 如果键从整数变成字符串，如何设计稳定哈希函数？

class MyHashSet {
    private static final int BUCKETS = 769;
    private final Node[] table;

    private static class Node {
        int key;
        Node next;
        Node(int key, Node next) {
            this.key = key;
            this.next = next;
        }
    }

    public MyHashSet() {
        table = new Node[BUCKETS];
    }

    public void add(int key) {
        int index = key % BUCKETS;
        for (Node cur = table[index]; cur != null; cur = cur.next) {
            if (cur.key == key) return;
        }
        table[index] = new Node(key, table[index]);
    }

    public void remove(int key) {
        int index = key % BUCKETS;
        Node dummy = new Node(-1, table[index]);
        Node prev = dummy;
        while (prev.next != null) {
            if (prev.next.key == key) {
                prev.next = prev.next.next;
                break;
            }
            prev = prev.next;
        }
        table[index] = dummy.next;
    }

    public boolean contains(int key) {
        int index = key % BUCKETS;
        for (Node cur = table[index]; cur != null; cur = cur.next) {
            if (cur.key == key) return true;
        }
        return false;
    }
}

        self.buckets = [None] * self.bucket_count

        index = key % self.bucket_count
        current = self.buckets[index]
        while current is not None:
            if current.key == key:
                return
            current = current.next
        self.buckets[index] = Node(key, self.buckets[index])

        dummy = Node(-1, self.buckets[index])
        previous = dummy
        while previous.next is not None:
            if previous.next.key == key:
                previous.next = previous.next.next

class MyHashSet {
private:
    static const int BUCKETS = 769;

    struct Node {
        int key;
        Node* next;
        Node(int value, Node* nextNode) : key(value), next(nextNode) {}
    };

    Node* table[BUCKETS]{};

public:
    MyHashSet() = default;

    ~MyHashSet() {
        for (int i = 0; i < BUCKETS; ++i) {
            while (table[i] != nullptr) {
                Node* doomed = table[i];
                table[i] = table[i]->next;
                delete doomed;
            }
        }
    }

    void add(int key) {
        int index = key % BUCKETS;
        for (Node* cur = table[index]; cur != nullptr; cur = cur->next) {
            if (cur->key == key) return;
        }
        table[index] = new Node(key, table[index]);
    }

    void remove(int key) {
        int index = key % BUCKETS;
        Node dummy(-1, table[index]);
        Node* previous = &dummy;
        while (previous->next != nullptr) {
            if (previous->next->key == key) {
                Node* doomed = previous->next;
                previous->next = doomed->next;
                delete doomed;
                break;
            }
            previous = previous->next;
        }
        table[index] = dummy.next;
    }

    bool contains(int key) {
        int index = key % BUCKETS;
        for (Node* cur = table[index]; cur != nullptr; cur = cur->next) {
            if (cur->key == key) return true;
        }
        return false;
    }
};
