组合总和 III
Combination Sum III

限定 1 到 9、每个数字仅用一次；递增起点同时消除重复组合，让回溯树变得干净可剪枝。

题意

找出所有由 k 个不同数字构成、元素和为 n 的组合。数字只能来自 1 到 9，每个最多使用一次；返回的组合不能重复，顺序不限。

约束
2 ≤ k ≤ 9，1 ≤ n ≤ 60。

官方样例（转述）

输入k = 3, n = 7输出[[1, 2, 4]]
输入k = 3, n = 9输出[[1, 2, 6], [1, 3, 5], [2, 3, 4]]
输入k = 4, n = 1输出[]

演示 k = 3, n = 7。亮绿数字在路径中；黄色是本轮候选；粉色分支因长度或剩余和不可能而停止。

题解：递增候选把组合唯一化

从 start 开始枚举下一个数字；一旦选了 i，下一层只从 i + 1 开始。于是路径天然严格递增：[1, 2, 6] 会生成，而排列 [2, 1, 6] 没有入口。

  1. 若路径长度等于 k，仅当剩余和为 0 时收集它。
  2. 若剩余和小于 0，立即停止当前分支。
  3. 对每个 i ∈ [start, 9]：加入、递归、弹出，恢复现场。
可加强的剪枝：当 i > remain 时后续候选更大，可以直接结束循环；还可用最小/最大可达和提前判断不可能。

完整过程

从空路径尝试 1，接着 2，剩余为 4，选到 4 时获得 [1,2,4]。返回后继续试 3，最后一个数至少为 4，和会超过 7，于是剪掉。这种“入栈—探索—出栈”就是回溯。

边界与复杂度

k 个数的最小和大于 n 时结果为空，例如 k=4,n=1。搜索空间上界为 2⁹，输出本身也需要空间；递归深度为 O(k)。

替代方案

位掩码枚举 1..9 的所有子集也可行，且常数很小，但回溯更直接表达“恰好 k 个”与剪枝，也更容易推广到候选集更大的组合问题。

面试追问

若允许数字复用，递归下一层仍从 i 开始；若候选含重复值，需要先排序并在同层跳过相同数字；若只求计数，可用状态 DP。

常见错误

  • 递归后忘记删除最后一个路径元素，导致兄弟分支共享错误状态。
  • 下一层仍从 start 开始，产生重复使用与重复组合。
  • 路径长度到 k 时没有检查 remaining 是否为 0。
