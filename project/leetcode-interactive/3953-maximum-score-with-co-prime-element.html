互质元素的最大得分

可把任意元素改成不超过 maxVal 的正整数，代价为 1。最终选择一个位置，使它与所有其他元素互质；得分等于所选值减去总修改次数。

核心洞察与完整过程

固定所选值

固定最终选中值 x 后，所有与 x 不互质的“其他元素”必须改成 1。若数组已有 x（且 x > 1），选择它可少改一次；若没有冲突元素且也没有 x，则仍要改一个元素成为 x。

如何统计冲突

设 x 的不同质因子为 p₁…pₖ。元素与 x 不互质，当且仅当它能被至少一个 pᵢ 整除。预处理每个 d 的倍数频次，再用容斥求并集大小。

复杂度

筛最小质因子和倍数计数约为 O(V log V)，每个 x 的不同质因子至多 6 个，子集容斥总量可接受；V 是 max(max(nums), maxVal)。

替代方案、追问与错误

小范围可直接枚举 x 与数组元素求 gcd 作对照。常见错误：把选中元素也强制修改；忽略 x=1；以及把“至少一个公共质因子”误算成单个质因子的计数。
