Problem

题目说明

给你两个仅包含 1 到 9 的数字数组 nums1 和 nums2，每个数组内的元素互不相同。请返回一个最小的正整数，使它的数位中至少有一位来自 nums1，并且至少有一位来自 nums2。

示例 1

输入nums1 = [4,1,3], nums2 = [5,7]
输出15
解释数位 1 来自 nums1，数位 5 来自 nums2；15 是满足条件的最小数字。

示例 2

输入nums1 = [3,5,2,6], nums2 = [3,1,7]
输出3
解释数字 3 同时出现在两个数组中，单独一个数位就满足要求。

约束

  • 1 <= nums1.length, nums2.length <= 9
  • 1 <= nums1[i], nums2[i] <= 9
  • 每个数组中的数字互不相同。

Full Solution

完整题解

核心洞察

答案至多两位。若两数组有公共数字，最小的公共数字本身就是一位数答案；否则分别取两数组的最小数字，把较小者放在十位即可。

完整过程

  1. 记录 nums1 中出现过的数字，并找出两数组中最小的公共数字。
  2. 若公共数字存在，直接返回它。
  3. 否则记两数组最小值为 a、b，返回 min(a,b) * 10 + max(a,b)。

正确性证明

有公共数字：任意一位正整数都小于任意两位数。公共数字单独就同时满足两数组要求，因此最小公共数字是最优答案。

无公共数字：答案必须至少包含两个不同来源的数位。选择任一数组中更大的数位都不会使结果变小，所以两边各取最小值最优；将二者中较小者放在十位，又能使该两位数最小。两种情况覆盖全部输入，算法正确。

边界与复杂度

  • 两数组完全相交：仍取其中最小公共数字。
  • 每组只有一个数字：公共则返回一位数，否则按升序拼接。
  • 数字仅为 1～9，不会出现前导零。
时间 O(n + m)额外空间 O(1)

替代方案

可以枚举两数组的所有数对，同时比较 10a+b 与 10b+a，再额外检查公共数字。它同样可行，但时间为 O(nm)，没有必要。

常见错误

  • 发现公共数字后返回第一个，而不是最小的公共数字。
  • 无公共数字时固定按 nums1、nums2 顺序拼接。
  • 误把数组顺序当成数位优先级；题目允许任选数组中的数字。

面试追问

  • 若允许数字 0 呢？需要明确前导零规则；若整数不能有前导零，十位必须选择最小非零候选。
  • 若要求每个数组贡献不同数位呢？公共数字不能再单独成答案，需要枚举跨数组且数值不同的数对。
  • 若数字域很大呢？哈希集合空间会随输入增长，但主流程仍是一次扫描。

四语言完整代码

Java 
class Solution {
    public int minNumber(int[] nums1, int[] nums2) {
        boolean[] seen = new boolean[10];
        int min1 = 10, min2 = 10;

        for (int digit : nums1) {
            seen[digit] = true;
            min1 = Math.min(min1, digit);
        }

        int common = 10;
        for (int digit : nums2) {
            if (seen[digit]) common = Math.min(common, digit);
            min2 = Math.min(min2, digit);
        }

        if (common < 10) return common;
        return Math.min(min1, min2) * 10 + Math.max(min1, min2);
    }
}

/**
 * @param {number[]} nums1
 * @param {number[]} nums2
 * @return {number}
 */
var minNumber = function(nums1, nums2) {
    const seen = new Set(nums1);
    const common = nums2.filter(digit => seen.has(digit));

    if (common.length) return Math.min(...common);

    const a = Math.min(...nums1);
    const b = Math.min(...nums2);
    return Math.min(a, b) * 10 + Math.max(a, b);
};
Python 
from typing import List


class Solution:
    def minNumber(self, nums1: List[int], nums2: List[int]) -> int:
        common = set(nums1) & set(nums2)
        if common:
            return min(common)

        a, b = min(nums1), min(nums2)
        return min(a, b) * 10 + max(a, b)
