平均工资部门与公司比较

把每个月看作一张独立账页：同一批工资记录既形成公司的基准线，也形成各部门的局部均值。你的任务，是为每个“月份 × 部门”标记它位于基准线的哪一侧。

01 · Problem

题意与数据契约

以下依据本轮官方元数据的表结构和示例准确转述，不复刻付费题面。

给定员工归属表 Employee 与按月工资表 Salary。为每一个有工资记录的月份、部门组合，计算该部门当月员工平均工资，并与全公司当月所有员工的平均工资比较。

输出 pay_month（YYYY-MM）、department_id 与 comparison。比较结果只能是 higher、lower 或 same，结果顺序不限。

约束与输入保证

  • Salary 字段类型为 (INT, INT, INT, DATE)，Employee 字段类型为 (INT, INT)。
  • 参与计算的工资记录通过 employee_id 对应到员工所属部门。
  • 比较限定在同一个自然月，不混合不同月份。
  • 结果覆盖输入中实际出现的“月份 × 部门”组合，顺序不限。
本轮官方元数据没有提供行数、标识或工资数值的额外上下界，因此不虚构数值范围；以上是元数据能够确认的完整结构约束。

05 · Solution

双层聚合，再按月对齐

先补齐部门与月份，再分别得到公司、部门两种粒度的均值，最后比较。

核心洞察

两种均值来自同一份“员工—部门—月份—工资”事实，但分组键不同：公司按月份，部门按月份和部门。两者只通过月份连接。

monthly facts → company_avg(month) + department_avg(month, dept) → CASE

复杂度

时间：概念上 O(S + E + G)

空间：O(G)

S、E 是两表规模，G 是聚合分组数；实际代价受索引与执行计划影响。

完整过程

  1. 按 employee_id 连接两表，为工资补上部门。
  2. 将日期规范化为 YYYY-MM。
  3. 按月份计算公司平均。
  4. 按月份、部门计算部门平均。
  5. 按月份连接两种均值并用 CASE 输出三态标签。

正确性说明

事实完备：连接后每条工资都带所属部门，能同时参与公司级与部门级聚合。

分区正确：公司聚合覆盖同月全部工资；部门聚合只覆盖同月、同部门工资。

比较正确：两种均值按同月连接。任意两数恰好满足大于、小于、等于之一，所以 CASE 给出唯一正确标签。

MySQL · 官方可提交语言

CTE 分离事实整理、两层聚合和最终比较。

Primary answer
WITH monthly_salary AS (
    SELECT
        DATE_FORMAT(s.pay_date, '%Y-%m') AS pay_month,
        e.department_id,
        s.amount
    FROM Salary AS s
    INNER JOIN Employee AS e
        ON e.employee_id = s.employee_id
),
company_average AS (
    SELECT pay_month, AVG(amount) AS average_amount
    FROM monthly_salary
    GROUP BY pay_month
),
department_average AS (
    SELECT pay_month, department_id, AVG(amount) AS average_amount
    FROM monthly_salary
    GROUP BY pay_month, department_id
)
SELECT
    d.pay_month,
    d.department_id,
    CASE
        WHEN d.average_amount > c.average_amount THEN 'higher'
        WHEN d.average_amount < c.average_amount THEN 'lower'
        ELSE 'same'
    END AS comparison
FROM department_average AS d
INNER JOIN company_average AS c
    ON c.pay_month = d.pay_month;

Java · 本地语义参考

数据库题不支持提交 Java；此代码在集合上复现语义。

import java.time.LocalDate;
import java.time.YearMonth;
import java.util.*;

public class Main {
    record Salary(int id, int employeeId, long amount, LocalDate date) {}
    record Employee(int employeeId, int departmentId) {}
    record Key(YearMonth month, int departmentId) {}
    record Stats(long sum, long count) {
        Stats add(long value) { return new Stats(sum + value, count + 1); }
    }
    record Result(String payMonth, int departmentId, String comparison) {}

    static List<Result> solve(List<Salary> salary, List<Employee> employees) {
        Map<Integer, Integer> deptOf = new HashMap<>();
        for (Employee e : employees) deptOf.put(e.employeeId(), e.departmentId());

        Map<YearMonth, Stats> company = new HashMap<>();
        Map<Key, Stats> department = new HashMap<>();
        for (Salary row : salary) {
            YearMonth month = YearMonth.from(row.date());
            int dept = deptOf.get(row.employeeId());
            company.compute(month, (k, v) ->
                (v == null ? new Stats(0, 0) : v).add(row.amount()));
            Key key = new Key(month, dept);
            department.compute(key, (k, v) ->
                (v == null ? new Stats(0, 0) : v).add(row.amount()));
        }

        List<Result> answer = new ArrayList<>();
        for (var entry : department.entrySet()) {
            Key key = entry.getKey();
            Stats d = entry.getValue(), c = company.get(key.month());
            var left = java.math.BigInteger.valueOf(d.sum())
                .multiply(java.math.BigInteger.valueOf(c.count()));
            var right = java.math.BigInteger.valueOf(c.sum())
                .multiply(java.math.BigInteger.valueOf(d.count()));
            int order = left.compareTo(right);
            String label = order > 0 ? "higher" : order < 0 ? "lower" : "same";
            answer.add(new Result(key.month().toString(), key.departmentId(), label));
        }
        answer.sort(Comparator.comparing(Result::payMonth)
            .thenComparingInt(Result::departmentId));
        return answer;
    }

    public static void main(String[] args) {
        List<Salary> salary = List.of(
            new Salary(1, 1, 9000, LocalDate.parse("2017-03-31")),
            new Salary(2, 2, 6000, LocalDate.parse("2017-03-31")),
            new Salary(3, 3, 10000, LocalDate.parse("2017-03-31")),
            new Salary(4, 1, 7000, LocalDate.parse("2017-02-28")),
            new Salary(5, 2, 6000, LocalDate.parse("2017-02-28")),
            new Salary(6, 3, 8000, LocalDate.parse("2017-02-28"))
        );
        System.out.println(solve(salary, List.of(
            new Employee(1, 1), new Employee(2, 2), new Employee(3, 2))));
    }
}

JavaScript · 本地语义参考

BigInt 交叉相乘，避免浮点比较误差。

function add(map, key, amount) {
  const old = map.get(key) || { sum: 0n, count: 0n };
  map.set(key, {
    sum: old.sum + BigInt(amount),
    count: old.count + 1n
  });
}

function solve(salary, employees) {
  const deptOf = new Map(
    employees.map(function (e) { return [e.employeeId, e.departmentId]; })
  );
  const company = new Map();
  const department = new Map();

  salary.forEach(function (row) {
    const month = row.date.slice(0, 7);
    const dept = deptOf.get(row.employeeId);
    add(company, month, row.amount);
    add(department, month + "|" + dept, row.amount);
  });

  return Array.from(department.entries()).map(function (entry) {
    const parts = entry[0].split("|");
    const d = entry[1];
    const c = company.get(parts[0]);
    const left = d.sum * c.count;
    const right = c.sum * d.count;
    return {
      payMonth: parts[0],
      departmentId: Number(parts[1]),
      comparison: left > right ? "higher" : left < right ? "lower" : "same"
    };
  }).sort(function (a, b) {
    return a.payMonth.localeCompare(b.payMonth) ||
      a.departmentId - b.departmentId;
  });
}

Python · 本地语义参考

Fraction 保持精确有理数比较。

from collections import defaultdict
from fractions import Fraction


def solve(salary, employees):
    dept_of = dict(employees)
    company = defaultdict(lambda: [0, 0])
    department = defaultdict(lambda: [0, 0])

    for _id, employee_id, amount, pay_date in salary:
        month = pay_date[:7]
        dept = dept_of[employee_id]
        company[month][0] += amount
        company[month][1] += 1
        department[(month, dept)][0] += amount
        department[(month, dept)][1] += 1

    answer = []
    for (month, dept), (dept_sum, dept_count) in department.items():
        company_sum, company_count = company[month]
        dept_avg = Fraction(dept_sum, dept_count)
        company_avg = Fraction(company_sum, company_count)
        label = (
            "higher" if dept_avg > company_avg
            else "lower" if dept_avg < company_avg
            else "same"
        )
        answer.append((month, dept, label))
    return sorted(answer)

C++ · 本地语义参考

__int128 交叉相乘，保持精确比较。

#include <iostream>
#include <map>
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

struct Salary {
    int id, employeeId;
    long long amount;
    string date;
};
struct Result {
    string payMonth;
    int departmentId;
    string comparison;
};

vector<Result> solve(
    const vector<Salary>& salary,
    const vector<pair<int, int>>& employees) {
    unordered_map<int, int> deptOf;
    for (auto [employeeId, departmentId] : employees)
        deptOf[employeeId] = departmentId;

    using Stats = pair<long long, long long>;
    map<string, Stats> company;
    map<pair<string, int>, Stats> department;

    for (const auto& row : salary) {
        string month = row.date.substr(0, 7);
        int dept = deptOf.at(row.employeeId);
        company[month].first += row.amount;
        ++company[month].second;
        department[{month, dept}].first += row.amount;
        ++department[{month, dept}].second;
    }

    vector<Result> answer;
    for (const auto& entry : department) {
        const auto& key = entry.first;
        const auto& d = entry.second;
        const auto& c = company.at(key.first);
        __int128 left = static_cast<__int128>(d.first) * c.second;
        __int128 right = static_cast<__int128>(c.first) * d.second;
        string label = left > right ? "higher" : left < right ? "lower" : "same";
        answer.push_back({key.first, key.second, label});
    }
    return answer;
}

int main() {
    vector<Salary> salary = {
        {1, 1, 9000, "2017-03-31"}, {2, 2, 6000, "2017-03-31"},
        {3, 3, 10000, "2017-03-31"}, {4, 1, 7000, "2017-02-28"},
        {5, 2, 6000, "2017-02-28"}, {6, 3, 8000, "2017-02-28"}
    };
    for (const auto& row : solve(salary, {{1, 1}, {2, 2}, {3, 2}}))
        cout << row.payMonth << ' ' << row.departmentId
             << ' ' << row.comparison << '\n';
}

边界情况

单部门月份必然为 same；跨年必须保留年份；同月多个部门可能都为 same；不要把无工资事实的部门补进结果。

替代方案

可用窗口函数，或先求部门 SUM/COUNT 再汇总。切勿把“部门平均的简单平均”当作“公司员工平均”。

常见错误

按完整日期分组；公司平均误带部门键；漏掉等于分支；整数除法；连接月份不一致；忽略数据库日期函数方言。
