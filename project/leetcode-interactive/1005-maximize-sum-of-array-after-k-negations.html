K 次取反后最大化的数组和

Maximize Sum Of Array After K Negations

EASY

题目

给定整数数组 nums 和整数 k。一次操作可选择下标 i，将 nums[i] 替换为 -nums[i]。必须恰好操作 k 次，同一下标可以重复选择。返回操作后能得到的最大数组和。

示例 1
输入：nums = [4,2,3], k = 1
输出：5
解释：选择下标 1，数组变为 [4,-2,3]。
示例 2
输入：nums = [3,-1,0,2], k = 3
输出：6
解释：选择下标 (1,2,2)，数组变为 [3,1,0,2]。
示例 3
输入：nums = [2,-3,-1,5,-4], k = 2
输出：13
解释：选择下标 (1,4)，数组变为 [2,3,-1,5,4]。

约束

  • 1 <= nums.length <= 10⁴
  • -100 <= nums[i] <= 100
  • 1 <= k <= 10⁴

取反决策实验室

逐步观察：先翻转最负的数；若负数耗尽而剩余次数为奇数，再翻转绝对值最小的数。

步骤 剩余 k 数组和

题解

核心洞察

翻转负数 x 会让总和增加 -2x，所以越负的数越值得先翻。负数处理完后，偶数次操作可在同一位置互相抵消；若剩奇数次，只能让绝对值最小的元素变号，从而把损失降到最低。

完整过程

  1. 将数组升序排序。
  2. 从左向右，在 k > 0 且元素为负时取反。
  3. 扫描数组，求总和与最小绝对值。
  4. 剩余 k 为奇数时，从总和减去两倍最小绝对值。

正确性证明

若 a < b < 0，翻转 a 的收益 -2a 大于翻转 b 的收益 -2b。因此任何先翻 b 的方案都可交换为先翻 a 且不变差，升序翻转负数最优。之后成对操作不改变结果；若剩余次数为奇数，翻转 x 的损失为 2|x|，选择绝对值最小者损失最少。故算法得到最大和。

边界与常见错误

  • 有 0 时，多余奇数次操作也不会改变结果。
  • 只有一个元素或有重复值时规则不变。
  • 不要忘记操作必须恰好执行 k 次。
  • 剩奇数次要找绝对值最小，而不是数值最小。
  • 避免每次取反后重新排序。

复杂度与替代方案

排序为 O(n log n)，扫描为 O(n)；除排序空间外为 O(1)。

值域仅 [-100,100]，也可用 201 个桶计数，达到 O(n+k+201)；最小堆方案为 O((n+k) log n)。

面试追问

k 极大时只需保留剩余次数的奇偶性。若不允许重复选择下标，则需选择不同位置中收益最大的 k 个。若数组以数据流到达，可维护负数集合与最小绝对值。

四语言完整代码

import java.util.Arrays;

class Solution {
    public int largestSumAfterKNegations(int[] nums, int k) {
        Arrays.sort(nums);
        for (int i = 0; i < nums.length && k > 0 && nums[i] < 0; i++, k--)
            nums[i] = -nums[i];
        int sum = 0, minAbs = Integer.MAX_VALUE;
        for (int x : nums) { sum += x; minAbs = Math.min(minAbs, Math.abs(x)); }
        return k % 2 == 0 ? sum : sum - 2 * minAbs;
    }
}

    def largestSumAfterKNegations(self, nums: List[int], k: int) -> int:
        nums.sort()
        for i in range(len(nums)):
            if k == 0 or nums[i] >= 0:
                break
            nums[i] = -nums[i]
            k -= 1
        total = sum(nums)
        minimum = min(abs(x) for x in nums)
        return total if k % 2 == 0 else total - 2 * minimum
