题意：找到共享轨道的第一站

任务

给定两个无环单链表的头节点 headA 与 headB，返回二者开始相交的节点；若没有共享节点，返回 null。返回后必须保持原链表结构不变。

“相交”比较节点引用：即使两个不同节点都存着 8，它们也不算相交。

输入listA = [4,1,8,4,5]
输入listB = [5,0,1,8,4,5]
输入skipA = 2, skipB = 3
输出Intersected at '8'

题解候车室

先独立推演可视化，再展开答案。核心洞察、完整过程与四语言代码均默认隐藏。

核心洞察

设 A 独有段长 a、B 独有段长 b、共享段长 c。探针 pA 走 A 再走 B，总路程 a+c+b；pB 走 B 再走 A，总路程 b+c+a。长度差被交换路径自然抵消，因此相交时两者必在首个共享节点同步。

完整过程

  1. 令 pA = headA，pB = headB。
  2. 只要 pA !== pB，各前进一步。
  3. pA 到空后改从 headB 出发；pB 到空后改从 headA 出发。
  4. 相交时会合于首个公共节点；不相交时二者最终同时为 null。

边界

  • 任一链表为空：最终返回 null。
  • 两头节点就是同一对象：循环零次，直接返回头节点。
  • 只在最后一个节点相交：换路仍可正确对齐。
  • 不同节点保存相同值：必须继续前进，不能按值判断。
  • 题目保证无环；若允许有环，必须另行分类讨论。

复杂度

时间O(m+n)
额外空间O(1)

每枚探针最多遍历两个链表各一次，不修改任何 next 指针。

替代方案

哈希集合：记录 A 的所有节点，再遍历 B 找首个已出现引用，直观但额外空间 O(m)。

长度对齐：先求长度，让较长链先走差值步，再同步前进，同样是 O(m+n) 时间与 O(1) 空间，但代码分支更多。

面试追问

  • 为什么换路不会无限循环？两枚探针至多各切换一次，之后同为 null 或在交点相遇。
  • 为什么找到的是第一个交点？单链表一旦共享某节点，后续 next 链完全相同。
  • 若链表可能有环怎么办？先分别检测环入口，再按无环、单环、双环分支处理。

常见错误

  • 比较 pA.val === pB.val，误把同值不同节点当成交点。
  • 到 null 后切回自己的头，长度差永远无法抵消。
  • 为了做标记而改写节点值或 next，破坏题目要求的原始结构。
  • 写成 pA.next 前不检查 pA，导致空指针。

一句话证明

两枚探针分别走过 A + B 与 B + A，总长度相同；若存在共享后缀，它们必在该后缀入口同步，否则在相同总路程后一起抵达 null。 

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 * }
 */
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode pointerA = headA;
        ListNode pointerB = headB;

        while (pointerA != pointerB) {
            pointerA = pointerA == null ? headB : pointerA.next;
            pointerB = pointerB == null ? headA : pointerB.next;
        }

        return pointerA;
    }
}
/**
 * @param {ListNode} headA
 * @param {ListNode} headB
 * @return {ListNode}
 */
var getIntersectionNode = function (headA, headB) {
  let pointerA = headA;
  let pointerB = headB;

  while (pointerA !== pointerB) {
    pointerA = pointerA === null ? headB : pointerA.next;
    pointerB = pointerB === null ? headA : pointerB.next;
  }

  return pointerA;
};
