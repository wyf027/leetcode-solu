LeetCode · 面试题 08.13 · 困难

堆箱子 重力验箱塔

每个箱子都要通过宽、深、高三道闸门，才能成为更大的新底座。排序把候选关系变成一条单向轨道，动态规划记录每个底座能承载的最高塔。

时间
O(n²)
空间
O(n)
示例塔高
10

01 · 入库单

题意

箱子不可翻转

给定若干箱子，每个箱子用 [w, d, h] 表示宽、深、高。若箱子 A 放在箱子 B 上面，则 B 的三个尺寸都必须严格大于 A。求可搭出的最大总高度。

示例 1

三箱完全递增
输入
box = [[1, 1, 1], [2, 2, 2], [3, 3, 3]]
输出
6

示例 2

宽度相等会拦截
输入
box = [[1, 1, 1], [2, 3, 4], [2, 6, 7], [3, 4, 5]]
输出
10

约束：箱子数量不超过 3000。本题没有字符串输入；若页面出现空格，将使用 ␠ 明示。

04 · 工程图纸

题解

核心洞察、完整过程与提交代码默认收起。

核心洞察

把三维嵌套变成有向无环轨道

先按宽、深、高升序排序。随后只需从较小下标转移到较大下标，并显式检查三个尺寸都严格变大。令 dp[i] 表示以箱子 i 为最底层时的最大高度，则对所有 j < i：

dp[i] = max(dp[i], dp[j] + box[i][2])

转移条件是 w[j] < w[i] && d[j] < d[i] && h[j] < h[i]。

完整过程

  1. 1. 对箱子进行字典序升序排序。
  2. 2. 初始化 dp[i] = box[i][2]，表示只使用自己。
  3. 3. 枚举当前底座 i 与上方候选 j。
  4. 4. 三个尺寸均严格变大时，用 dp[j] 更新 dp[i]。
  5. 5. 所有 dp[i] 的最大值就是最高箱塔。

边界

  • 空数组返回 0。
  • 只有一个箱子时返回其高度。
  • 任一维相等都不能堆叠。
  • 输入箱子不可旋转，不能重排三个尺寸。

复杂度

时间
排序 O(n log n)，双层转移 O(n²)。
空间
dp 使用 O(n)。

替代方案

记忆化搜索同样可行，但递归深度可达 n，面试里更推荐迭代 DP。只有求“最多箱子数”且维度结构可进一步约化时，才容易借鉴俄罗斯套娃信封的 O(n log n)；本题目标是高度加权，不能直接套 LIS 长度模板。

常见错误

  • 只比较宽和深，忘记高度也必须严格增大。
  • 使用 <=，让相等尺寸错误通过。
  • 把 dp[i] 初始化为 0，漏掉单箱高度。
  • 返回箱子数量而不是高度总和。

面试追问

  • 如何恢复具体的箱塔方案？增加 parent[i] 记录前驱。
  • 如果允许旋转箱子？为每个箱子生成合法朝向，再处理同箱不可复用。
  • 如果目标改成箱子数量？权重从高度改成 1。
  • 为什么排序后仍要比较宽？因为相等宽度绝不能转移。

import java.util.Arrays;

class Solution {
    public int pileBox(int[][] box) {
        Arrays.sort(box, (a, b) -> {
            if (a[0] != b[0]) return Integer.compare(a[0], b[0]);
            if (a[1] != b[1]) return Integer.compare(a[1], b[1]);
            return Integer.compare(a[2], b[2]);
        });

        int n = box.length;
        int[] dp = new int[n];
        int answer = 0;
        for (int i = 0; i < n; i++) {
            dp[i] = box[i][2];
            for (int j = 0; j < i; j++) {
                if (box[j][0] < box[i][0]
                        && box[j][1] < box[i][1]
                        && box[j][2] < box[i][2]) {
                    dp[i] = Math.max(dp[i], dp[j] + box[i][2]);
                }
            }
            answer = Math.max(answer, dp[i]);
        }
        return answer;
    }
}
