LCR 028 / LINKED LIST / DFS

扁平化多级
双向链表

把每条 child 支链插入主链：先记住“回程地址”，再把 child 接在当前节点之后。最终顺序就是深度优先的先序遍历。

时间 O(n) 空间 O(n) 原地改指针 官方 slug：qv1da2

面试口令

30 SEC
  1. 1.遍历主链；遇到 child，先把原 next 压栈。
  2. 2.当前节点接 child，补齐 child.prev，清空 child。
  3. 3.走到链尾时，从栈顶弹出未处理的 next 并接回。

TOP

栈里保存“child 插入前的 next”。子链走完后，最后一个节点自然接回栈顶。

WHY IT WORKS

先序顺序由“延后 next”保证

当前节点的 child 必须先于原 next 出现在答案中。把原 next 入栈等同于写下“稍后回来”；立刻转入 child 则保证 child 整段优先展开。每次接边都同时维护双向约束：a.next = b 与 b.prev = a。

三个易错点

  • 先存 next：不先压栈，原主链后半段会丢失。
  • 清空 child：题目要求扁平后所有 child 指针都为 null。
  • 补 prev：只连 next 会破坏双向链表，可用反向遍历检查。

class Solution {
  public Node flatten(Node head) {
    if (head == null) return null;
    Deque<Node> stack = new ArrayDeque<>();
    Node cur = head;
    while (cur != null) {
      if (cur.child != null) {
        if (cur.next != null) stack.push(cur.next);
        cur.next = cur.child;
        cur.child.prev = cur;
        cur.child = null;
      }
      if (cur.next == null && !stack.isEmpty()) {
        Node next = stack.pop();
        cur.next = next;
        next.prev = cur;
      }
      cur = cur.next;
    }
    return head;
  }
}

class Solution {
public:
  Node* flatten(Node* head) {
    if (!head) return nullptr;
    stack<Node*> st;
    for (Node* cur = head; cur; cur = cur->next) {
      if (cur->child) {
        if (cur->next) st.push(cur->next);
        cur->next = cur->child;
        cur->child->prev = cur;
        cur->child = nullptr;
      }
      if (!cur->next && !st.empty()) {
        cur->next = st.top(); st.pop();
        cur->next->prev = cur;
      }
    }
    return head;
  }
};
