最少的后缀翻转次数Minimum Suffix Flips

从全 0 字符串出发，每次只允许翻转一个后缀。先读懂规则，再到实验室亲手观察每一次翻转波如何穿过字符串。

#1529 中等 贪心 字符串
Official signature
minFlips(target)

输入一个二进制字符串，返回把全 0 字符串变成目标串所需的最少操作数。题解在页面下方独立折叠，首屏不揭示结论。

Problem

题目描述

设 target 长度为 n，另有同长度字符串 s，初始每一位都是 0。

目标与操作

给定一个下标从 0 开始的二进制字符串 target。你需要通过若干次操作，使初始字符串 s 最终与 target 完全相同。

一次操作：选择任意下标 i（0 ≤ i < n），翻转闭区间 [i, n - 1] 的所有位；其中 0 变成 1，1 变成 0。

返回让 s 等于 target 所需的最少翻转次数。

约束

  • n == target.length
  • 1 ≤ n ≤ 105
  • target[i] 只能是 '0' 或 '1'
EXAMPLE 01
输入
target = "10111"
输出
3
解释
从 00000 出发，可依次在下标 2、0、1 翻转后缀，3 次得到 10111，且无法更少。
EXAMPLE 02
输入
target = "101"
输出
3
解释
从 000 出发，依次在下标 0、1、2 翻转后缀，即可得到 101。
EXAMPLE 03
输入
target = "00000"
输出
0
解释
初始字符串已经等于目标串，因此不需要任何操作。

Solution

一次从左到右的贪心扫描

无需真的反复修改整个后缀，只要记录当前位置看到的逻辑颜色。

核心洞察：每次变化的边界都必须响应

在 target 前补一个初始位 '0'。相邻字符不同，就代表从这里开始需要切换一次当前颜色；相邻字符相同则继续沿用。于是答案恰好是相邻变化次数。

answer = Σ [target[i] ≠ previous]，其中 previous 初始为 '0'

完整过程

  1. 令 previous = '0'，代表尚未操作时当前位置呈现 0。
  2. 从左到右访问 target[i]。
  3. 若 target[i] != previous，必须从 i 开始翻转一次，答案加 1，并把 previous 更新为当前目标位。
  4. 扫描结束后返回累计次数。

为什么只记一位状态？

此前发生的每一次后缀翻转都会统一改变当前位置及其右侧。对尚未处理的位置而言，所有历史影响只剩“翻转了奇数次还是偶数次”这一种状态；用当前逻辑位 previous 就足够表达。

正确性证明

不变量。处理下标 i 前，区间 [0, i-1] 已与目标串一致，后续从更右位置开始的操作不会再改变它。
必须翻转的情况。若当前位置的逻辑位与 target[i] 不同，任何起点大于 i 的操作都无法改变位置 i；因此至少要有一次操作从 i 开始。贪心正好执行这一次。
不应翻转的情况。若两者已经相同，在 i 翻转会立刻破坏这一位，并必然需要额外操作补救，因此最优方案不会在此多做一次。
归纳结束。每一步选择都是被当前位置强制决定的，并保持已处理前缀正确。扫描完成时整个字符串匹配，且没有任何步骤可减少，所以操作数最小。

复杂度与边界

  • 时间复杂度：O(n)，每个字符只访问一次。
  • 空间复杂度：O(1)，不计算输入本身。
  • 全 0：无边界变化，答案为 0。
  • 全 1：只在开头变化一次，答案为 1。
  • 0/1 交替：几乎每一位都触发一次翻转。
  • 长度为 1：答案由该位是否为 1 决定。

替代方案

显式模拟可以在不匹配时真的翻转整个后缀，思路直观，但最坏需要 O(n²) 时间。也可以直接统计 target 内部相邻变化次数，再加上首字符是否为 '1'；它与当前写法等价，但“前置 0”更统一。

常见错误

  • 把答案误写成 1 的个数；真正关键是颜色边界。
  • 只统计字符串内部变化，忘记初始状态是 0。
  • 每次创建并翻转后缀，导致超时或大量内存分配。
  • 更新状态的时机错误；遇到变化时应令 previous = target[i]。

面试追问

  • 如何返回具体操作下标？记录所有满足 target[i] != previous 的 i。
  • 若初始串全为 1？把哨兵状态改成 '1'。
  • 若允许翻转任意区间？操作会产生两个边界，模型与最优策略都将改变。
  • 能否在线处理流式输入？可以，只需保留上一目标位和累计答案。

Code

四种语言实现

JavaLeetCode 可提交
class Solution {
    public int minFlips(String target) {
        int flips = 0;
        char previous = '0';

        for (int i = 0; i < target.length(); i++) {
            char current = target.charAt(i);
            if (current != previous) {
                flips++;
                previous = current;
            }
        }

        return flips;
    }
}

};
