Solution

完整题解

包含核心洞察、证明、复杂度、替代方案与五种实现。

核心洞察

题目同时包含两个条件：先找出“频次恰好为 1”的分组，再在这些分组值中取最大值。SQL 中应让 GROUP BY num 与 HAVING COUNT(*) = 1 完成第一层筛选，再让外层聚合 MAX(num) 完成第二层选择。

外层使用聚合函数还有一个关键收益：即使子查询没有行，聚合查询仍返回一行，MAX 的值自然是 null，正好满足题目要求。

完整过程

  1. 按 num 分组，让相同数字进入同一个分组。
  2. 用 COUNT(*) 统计每组行数，并通过 HAVING COUNT(*) = 1 只保留单一数字。
  3. 在保留下来的 num 中计算 MAX(num)。
  4. 如果没有候选分组，外层聚合仍输出一行，其 num 为 null。

正确性说明

完备性：每个出现一次的值经分组后计数必为 1，因此一定被内层查询保留。排他性：每个被保留的值计数均为 1，因此不会混入重复数字。由此，子查询结果恰好等于所有单一数字的集合；对该集合取 MAX 得到最大的单一数字。集合为空时，SQL 聚合结果为 null，同样正确。

边界情况

  • 所有数字都重复：返回 null。
  • 只有一行：该数字就是答案。
  • 包含负数或零：仍按普通整数比较大小。
  • 最大原始数字重复：必须排除它，再看较小的单一数字。
  • 空表：外层 MAX 返回一行 null。

复杂度

设表中有 n 行、不同数字有 k 个。数据库实现通常需要一次分组聚合；基于哈希聚合时，期望时间为 O(n)、额外空间为 O(k)。若执行器采用排序聚合，时间可能为 O(n log n)。实际计划取决于数据库、统计信息与索引。

MySQL · 官方可提交实现

SELECT MAX(num) AS num
FROM (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(*) = 1
) AS singles;

Java · 本地语义参考

数据库题不能用 Java 直接提交；此实现仅模拟“分组计数 → 取最大单一数字”的本地语义。

import java.util.HashMap;
import java.util.Map;

public class BiggestSingleNumber {
    public static Integer biggestSingleNumber(int[] nums) {
        Map<Integer, Integer> frequency = new HashMap<>();
        for (int num : nums) {
            frequency.put(num, frequency.getOrDefault(num, 0) + 1);
        }

        Integer answer = null;
        for (Map.Entry<Integer, Integer> entry : frequency.entrySet()) {
            if (entry.getValue() == 1
                    && (answer == null || entry.getKey() > answer)) {
                answer = entry.getKey();
            }
        }
        return answer;
    }
}

JavaScript · 本地语义参考

数据库题不能用 JavaScript 直接提交；返回值用 null 表达没有单一数字。

function biggestSingleNumber(nums) {
  const frequency = new Map();

  for (const num of nums) {
    frequency.set(num, (frequency.get(num) ?? 0) + 1);
  }

  let answer = null;
  for (const [num, count] of frequency) {
    if (count === 1 && (answer === null || num > answer)) {
      answer = num;
    }
  }
  return answer;
}

Python · 本地语义参考

官方支持 Pandas，但下面是普通 Python 集合语义参考，并非本站数据库判题的提交格式。

from collections import Counter
from typing import Optional


def biggest_single_number(nums: list[int]) -> Optional[int]:
    frequency = Counter(nums)
    singles = (num for num, count in frequency.items() if count == 1)
    return max(singles, default=None)

C++ · 本地语义参考

数据库题不能用 C++ 直接提交；用 std::optional 对应 SQL 的可空结果。

#include <optional>
#include <unordered_map>
#include <vector>

class Solution {
public:
    static std::optional<int> biggestSingleNumber(
        const std::vector<int>& nums
    ) {
        std::unordered_map<int, int> frequency;
        for (int num : nums) {
            ++frequency[num];
        }

        std::optional<int> answer;
        for (const auto& [num, count] : frequency) {
            if (count == 1 && (!answer.has_value() || num > *answer)) {
                answer = num;
            }
        }
        return answer;
    }
};

替代方案

可以在相关子查询中为每个不同值检查计数，再取最大值；也可以使用窗口函数 COUNT(*) OVER (PARTITION BY num) 标注频次后筛选。

分组子查询最直接，也最清楚地表达题意。窗口函数在还要保留原始行的题目中更有价值，本题没有必要增加中间行。

常见错误

  • 直接 MAX(num)，没有排除重复数字。
  • 把聚合条件写进 WHERE；计数条件应放在 HAVING。
  • 内层查询按频次降序或数值降序，却没有可靠地限制结果。
  • 只返回空结果集，没有满足题目要求的单行 null。
  • 使用 COUNT(num) 时忽略了可空字段语义；本题字段定义未声明可空，COUNT(*) 仍更明确。

面试追问

  • 为什么外层 MAX 在没有候选时不会完全没有行？
  • 如果题目改成“出现不超过两次的最大数字”，应修改哪一层条件？
  • 哈希聚合与排序聚合的执行方式和空间代价有什么差别？
  • 如果还要输出最大单一数字对应的其他列，现有表为什么不足以唯一定位原始行？
  • 给 num 建索引可能如何影响分组与扫描计划？
