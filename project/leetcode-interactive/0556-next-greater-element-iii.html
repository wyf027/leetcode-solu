下一个更大元素 III

不枚举所有排列。先观察数字序列如何从“尽可能大”变成“刚好更大”。

题目

给定正整数 n，重新排列它的全部十进制数字，找到严格大于 n 的最小整数。若不存在，或结果超出 32 位有符号整数范围，返回 -1。

函数签名

nextGreaterElement(n: integer) → integer

约束

  • 1 ≤ n ≤ 2³¹ - 1
  • 每个数字必须使用且仅使用原数中的出现次数。

官方示例

示例 1
输入：n = 12
输出：21

示例 2
输入：n = 21
输出：-1

第二个数的数字已按降序排列，无法构造更大的排列。

排列手术台

当前数字 12443322。逐步观察：找转折点、找交换对象、交换、翻转后缀。

转折点交换对象待整理后缀

先自己想一想

  1. 从右往左看，什么时候说明后缀已是最大的排列？
  2. 为了让增幅最小，转折点应该和哪一位交换？
  3. 交换后，怎样让剩余后缀尽可能小？
提示：这个操作与求“字典序下一个排列”完全一致。

题解：下一个排列

核心洞察

从右向左找到第一个满足 a[i] < a[i+1] 的位置。其右侧必为非递增序列，已经是这些数字能组成的最大排列。要得到“刚好更大”的数，应提高尽可能靠右的这一位，并把后缀降到最小。

完整过程

  1. 从倒数第二位向左寻找转折点 i。
  2. 若不存在，所有数字非递增，返回 -1。
  3. 从末尾向左找第一个大于 a[i] 的数字 a[j]；因为后缀非递增，它就是可选数字中最小的那个。
  4. 交换 a[i] 与 a[j]。
  5. 反转区间 [i+1, end]，将原本非递增的后缀变成非递减，即最小排列。
  6. 转换成整数，超过 2³¹-1 则返回 -1。

正确性说明

转折点右侧是最大排列，因此只改变后缀无法变大；提高转折点是最靠右、影响最小的必要变化。选择后缀中最小的较大数字使该位增幅最小，随后把剩余数字升序排列使后缀最小。故结果严格大于原数，且不存在介于两者之间的同数字排列。

边界与复杂度

  • 单个数字或整体非递增：无答案。
  • 重复数字：寻找时使用严格比较，仍可正确跳过相等项。
  • 有合法排列但数值溢出：返回 -1。
  • 时间 O(d)，空间 O(d)；d 为十进制位数。

替代方案

可以调用语言库的 next permutation（若允许），也可枚举排列后排序，但后者为阶乘复杂度且会产生大量重复排列，不适合面试实现。

面试追问

  • 如何原地实现后缀反转？
  • 为什么末尾向左找到的第一个较大数字就是最优交换对象？
  • 如果输入是任意长度数字字符串，如何取消整数溢出限制？

常见错误

  • 转折点比较写成 <=，破坏重复数字场景。
  • 交换后对整个数组排序，而非仅处理后缀。
  • 在 JavaScript 中依赖位运算判断范围，导致 32 位截断。
  • 忘记结果必须严格大于原数以及 32 位上界。

四语言完整代码

Java
class Solution {
    public int nextGreaterElement(int n) {
        char[] a = String.valueOf(n).toCharArray();
        int i = a.length - 2;
        while (i >= 0 && a[i] >= a[i + 1]) i--;
        if (i < 0) return -1;
        int j = a.length - 1;
        while (a[j] <= a[i]) j--;
        char t = a[i]; a[i] = a[j]; a[j] = t;
        for (int l = i + 1, r = a.length - 1; l < r; l++, r--) {
            t = a[l]; a[l] = a[r]; a[r] = t;
        }
        long ans = Long.parseLong(new String(a));
        return ans > Integer.MAX_VALUE ? -1 : (int) ans;
    }
}

/** @param {number} n @return {number} */
var nextGreaterElement = function(n) {
    const a = String(n).split('');
    let i = a.length - 2;
    while (i >= 0 && a[i] >= a[i + 1]) i--;
    if (i < 0) return -1;
    let j = a.length - 1;
    while (a[j] <= a[i]) j--;
    [a[i], a[j]] = [a[j], a[i]];
    for (let l = i + 1, r = a.length - 1; l < r; l++, r--) {
        [a[l], a[r]] = [a[r], a[l]];
    }
    const ans = Number(a.join(''));
    return ans <= 2147483647 ? ans : -1;
};

class Solution:
    def nextGreaterElement(self, n: int) -> int:
        a = list(str(n))
        i = len(a) - 2
        while i >= 0 and a[i] >= a[i + 1]:
            i -= 1
        if i < 0:
            return -1
        j = len(a) - 1
        while a[j] <= a[i]:
            j -= 1
        a[i], a[j] = a[j], a[i]
        a[i + 1:] = reversed(a[i + 1:])
        ans = int(''.join(a))
        return ans if ans <= 2**31 - 1 else -1
C++
class Solution {
public:
    int nextGreaterElement(int n) {
        string a = to_string(n);
        int i = static_cast<int>(a.size()) - 2;
        while (i >= 0 && a[i] >= a[i + 1]) --i;
        if (i < 0) return -1;
        int j = static_cast<int>(a.size()) - 1;
        while (a[j] <= a[i]) --j;
        swap(a[i], a[j]);
        reverse(a.begin() + i + 1, a.end());
        long long ans = stoll(a);
        return ans > INT_MAX ? -1 : static_cast<int>(ans);
    }
};
