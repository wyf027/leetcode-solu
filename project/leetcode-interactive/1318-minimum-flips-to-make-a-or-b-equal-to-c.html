或运算的最小翻转次数

Minimum Flips to Make a OR b Equal to c

按位或 OR逐位观察正整数非付费题

题目

给定三个正整数 a、b 和 c。每次操作可以把 a 或 b 的二进制表示中的任意一位从 0 翻成 1，或从 1 翻成 0。

返回让 a OR b == c 成立所需的最少翻转次数。函数形式为 minFlips(a, b, c) -> integer。

示例 1
输入：a = 2, b = 6, c = 5
输出：3
解释：可将 a 变为 1、b 变为 4，
此时 1 OR 4 = 5。
示例 2
输入：a = 4, b = 2, c = 7
输出：1
示例 3
输入：a = 1, b = 2, c = 3
输出：0

约束

1 ≤ a ≤ 10⁹
1 ≤ b ≤ 10⁹
1 ≤ c ≤ 10⁹

位翻转实验台

输入三个数，然后逐位查看 OR 结果与目标位的关系。先亲手走一遍，再展开题解。

累计操作：0

从最低有效位向左观察
点击“下一步”观察第 0 位

每一步只关注同一列的 a、b、a OR b 与 c。

当前位需要翻转无需翻转

题解：把三个整数对齐后逐列结算

核心洞察：按位或的每个二进制位彼此独立。目标位是 0 时，a、b 在该位出现几个 1 就要翻几个；目标位是 1 时，只有 a、b 都为 0 才需要翻一次。

完整过程

  1. 循环读取 a & 1、b & 1、c & 1，得到当前最低位。
  2. 若 c 的当前位为 0，必须让 a、b 的当前位都为 0，因此答案增加 aBit + bBit。
  3. 若 c 的当前位为 1，a、b 至少有一个 1；当二者都是 0 时答案增加 1。
  4. 三个数同时右移一位，直到三者都变为 0。

为什么是最少的？

逐位下界：当目标位为 0，每个已有的 1 都必须单独翻成 0；当目标位为 1 且两个来源位都是 0，至少要把其中一个翻成 1。任何合法方案都不能少于这些操作。

可达性：上述规则恰好执行达到该目标位所需的操作，不多翻任何一位。不同二进制位互不影响，把每一位的最优代价相加，得到全局最优解。

边界情况

  • a OR b 已等于 c：每一列都匹配，结果为 0。
  • c 的某位为 0，而 a、b 同位都为 1：必须翻两次，不能只翻一次。
  • c 的高位为 1，而 a、b 没有该高位：仍会继续循环，并在该位计一次。
  • 输入上限为 10⁹，小于 2³⁰；标准 32 位整数位运算足够。

复杂度

令 M = max(a, b, c)。时间复杂度为 O(log M)，额外空间复杂度为 O(1)。

替代方案

可以固定检查 0 到 30 位，逻辑直观但略依赖约束；也可利用异或与掩码推导公式后统计置位数，代码更短却不如逐位法易于解释。面试中优先写逐位法，正确性边界最清晰。

四语言完整实现

class Solution {
    public int minFlips(int a, int b, int c) {
        int flips = 0;
        while (a != 0 || b != 0 || c != 0) {
            int bitA = a & 1;
            int bitB = b & 1;
            int bitC = c & 1;

            if (bitC == 0) {
                flips += bitA + bitB;
            } else if (bitA == 0 && bitB == 0) {
                flips++;
            }

            a >>= 1;
            b >>= 1;
            c >>= 1;
        }
        return flips;
    }
}

面试追问

  • 能否用位掩码一次表达？ 可以分别找出“c 为 0 时多出的 1”和“c 为 1 时缺失的 1”，再做置位计数。
  • 为什么不能只比较 (a | b) ^ c 的置位数？ 因为目标位为 0、a 与 b 同位都为 1 时，异或只显示一个不匹配位，但实际需要两次翻转。
  • 若允许翻转 c 呢？ 每一位需比较翻 a/b 的代价和翻 c 的代价，选择较小者，局部决策仍然独立。

常见错误

  • 目标位为 0 时只把答案加 1，遗漏 a、b 同位均为 1 要翻两次。
  • 循环条件只写 while (a || b)，遗漏 c 独有的高位。
  • 在 JavaScript 中对超出 32 位范围的数直接使用位运算；本题上限安全，但迁移题目时要重新确认。
  • 为了“凑出”某个整体数而跨位思考；按位或不产生进位，各位应独立处理。
