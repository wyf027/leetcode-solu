Minimum Adjacent Swaps to Make a Valid Array

每一步只能交换相邻元素。怎样让数组的两端满足要求，同时尽量少动几步？先理解目标，再在交换轨道上观察每一步。

01 / THE CHALLENGE

题目与目标

给定下标从 0 开始的整数数组 nums，一次操作可交换两个相邻位置的数。请返回最少操作次数，使数组的首项等于全局最小值，末项等于全局最大值。存在多个相同极值时，任意一个到达对应端点即可；中间部分的顺序没有额外要求。

参数与返回值

minimumSwaps(nums: integer[]) → integer

唯一参数为 nums；返回相邻交换的最少次数。

约束

1 ≤ nums.length ≤ 10⁵
1 ≤ nums[i] ≤ 10⁵

官方示例 1

输入：nums = [3,4,5,5,3,1]
输出：6

经过 6 次相邻交换，可得到 [1,3,4,5,3,5]，此时两端分别为最小值和最大值。最少需要 6 次。

官方示例 2

输入：nums = [9]
输出：0

唯一元素同时占据两端，也是最小值和最大值，数组已经有效。

04 / SOLUTION NOTES

准备好解释“为什么最少”了吗？

展开后查看思路、证明及四语言提交代码。

题解 · 两段距离，一次重叠

核心洞察

只需固定两端，无需排序。选择最靠左的最小值，原下标记为 left；选择最靠右的最大值，原下标记为 right。最小值需要左移 left 格，最大值需要右移 n - 1 - right 格。

答案 = left + (n - 1 - right) - (left > right ? 1 : 0)

当最小值在最大值右侧时，两者必然互相跨过一次。它们直接交换的那一步同时完成了双方各一格的移动，距离相加时重复计数一次，因此减 1。

完整过程

  1. 令 left = right = 0，从左到右扫描数组。
  2. 只有发现更小的值才更新 left（使用 <），保留最小值的第一次出现。
  3. 发现更大或相等的值就更新 right（使用 >=），保留最大值的最后一次出现。
  4. 相加两端距离；若 left > right，减去交叉时重复的一次。

示例 1 中 left = 5、right = 3，答案是 5 + 2 - 1 = 6。下面与演示一致，先移最小值，再移最大值：

初始  [3,4,5,5,3,1]
1     [3,4,5,5,1,3]  交换下标 4、5
2     [3,4,5,1,5,3]  交换下标 3、4：两个选中极值相遇
3     [3,4,1,5,5,3]  交换下标 2、3
4     [3,1,4,5,5,3]  交换下标 1、2
5     [1,3,4,5,5,3]  交换下标 0、1
6     [1,3,4,5,3,5]  交换下标 4、5

正确性证明

固定极值的下界：设最终到首位的最小元素原来位于 a，到末位的最大元素原来位于 b。前者至少要净左移 a 格，后者至少要净右移 n−1−b 格。若 a ≤ b，两者需要跨过的元素对不重叠；若 a > b，两组必需跨越只共享这两个极值组成的一对。因此至少需要 a + n−1−b − [a>b] 次相邻交换。无效往返不会减少这些必需跨越。

极值选择最优：固定 b，把 a 换成更靠左的最小值只会减少距离；即使失去一次交叉优惠，距离至少也少 1，不会变差。类似地，固定 a，把 b 换成更靠右的最大值不会增加代价。故最左最小值与最右最大值达到最优下界。

下界可以实现：先将所选最小值连续左移到首位，再将所选最大值连续右移到末位。如果 left > right，第一阶段已将最大值右推一格，第二阶段少用一次；否则最大值位置不变。总次数恰为公式，因此最优。全部相等时两端已满足要求，公式自然为 0。

边界与复杂度

  • 单元素：left 和 right 都是 0，返回 0。
  • 全部相等：left 保留 0，right 更新到 n−1，返回 0。
  • 极值重复：必须遵守最左最小与最右最大，不能任意选取。
  • 两端已有效：中间可以无序，返回 0。
  • 时间 O(n)，额外空间 O(1)，代码不修改输入数组。
  • n ≥ 2 时最多 2n−3 次，题目范围内使用 32 位整数足够。

替代方案

可实际执行两段相邻交换，操作数量仍为 O(n)，若原地模拟，额外空间也是 O(1)，但会修改输入且无需如此操作才能求次数。本页为展示历史帧而复制数组，演示空间和时间可到 O(n²)，所以限制 30 项。对极小数组做广度优先搜索也可寻找最短交换路径，但排列状态随规模急剧增长，不适合提交。完整排序会完成题目不要求的工作，排序交换数不能作为本题答案。

常见错误

  • 最小值用 <=，选成最后一次出现；最大值只用 >，选成第一次出现。
  • 所有情况都减 1，或在 left < right 时才减 1。
  • 把“相邻交换”当成任意两个位置交换。
  • 用反转对数量求完全排序的代价，忽略中间顺序自由。
  • 先修改数组，再把更新后的下标代入原始距离公式，混用两个状态。

面试追问

能否先移动最大值？可以，交叉时会把最小值左推一格，总数不变。
如果需要输出操作序列？用相邻冒泡构造两段路径，输出每次交换的下标对；记录结果需 O(n) 空间。
交换带不同权重时呢？距离不再直接等于代价，当前计数证明不足，需要按权重重新推导。
如果要整个数组有序？这是另一个目标，通常需要统计逆序对。

四语言完整代码

函数名遵循官方元数据 minimumSwaps，以下为 LeetCode 提交形式；均未执行验证。

Java

class Solution {
    public int minimumSwaps(int[] nums) {
        int left = 0, right = 0;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] < nums[left]) left = i;
            if (nums[i] >= nums[right]) right = i;
        }
        return left + nums.length - 1 - right
            - (left > right ? 1 : 0);
    }
}

from typing import List

class Solution:
    def minimumSwaps(self, nums: List[int]) -> int:
        left = right = 0
        for i in range(1, len(nums)):
            if nums[i] < nums[left]:
                left = i
            if nums[i] >= nums[right]:
                right = i
        return left + len(nums) - 1 - right - int(left > right)

C++

#include <vector>
using std::vector;

class Solution {
public:
    int minimumSwaps(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        int left = 0, right = 0;
        for (int i = 1; i < n; ++i) {
            if (nums[i] < nums[left]) left = i;
            if (nums[i] >= nums[right]) right = i;
        }
        return left + n - 1 - right - (left > right ? 1 : 0);
    }
};
