Problem

题目要求

实现 WordFilter 类，维护给定顺序的单词词典。一次查询必须同时检查单词的开头与结尾；多个下标满足时，答案不是任意一个，而是其中最大的下标。

WordFilter(string[] words)

使用数组 words 初始化词典；数组位置就是单词下标。

int f(string pref, string suff)

返回同时以 pref 开头、以 suff 结尾的单词的最大下标；不存在时返回 -1。

官方示例 · 完整调用形式

输入
["WordFilter", "f"]
[[["apple"]], ["a", "e"]]

输出
[null, 0]

解释
WordFilter wordFilter = new WordFilter(["apple"]);
wordFilter.f("a", "e"); // 返回 0

下标 0 的 "apple" 以 "a" 开头且以 "e" 结尾。

约束

  • 1 ≤ words.length ≤ 10⁴
  • 1 ≤ words[i].length ≤ 7
  • 1 ≤ pref.length, suff.length ≤ 7
  • words[i]、pref、suff 仅由小写英文字母组成。
  • 对 f 的调用次数最多为 10⁴。

Solution Unlocked

组合字典树：把双条件变成一条路径

为每个单词枚举所有后缀，把 suffix + "{" + word 插入同一棵字典树，并在沿途节点记录当前单词下标。查询只需走 suff + "{" + pref。

核心洞察

若单词 w 以后缀 suff 结尾，预处理时必然插入路径 suff + "{" + w。若它又以前缀 pref 开头，那么查询串 suff + "{" + pref 恰好就是这条路径的前缀。

字符 { 不会出现在小写单词中，因此能无歧义地区分后缀段与单词段。用 27 个分支即可容纳 a-z 和分隔符。

完整过程

  1. 创建根节点，每个节点保存 27 个子节点与一个 weight，初始为 -1。
  2. 按下标从小到大处理每个单词 w。
  3. 枚举 w 的每个后缀（包括空后缀），插入 suffix + "{" + w。
  4. 经过每个节点时都令 weight = index；后处理的较大下标自然覆盖较小下标。
  5. 查询时沿 suff + "{" + pref 行走。路径不存在返回 -1，否则返回终点节点的 weight。

正确性证明

充分性。 若下标 i 的单词 w 同时具有前缀 pref 和后缀 suff，预处理会插入 suff + "{" + w。因为 w 以 pref 开头，查询串 suff + "{" + pref 是该插入串的前缀，所以查询一定能经过记录了 i 的节点。

必要性。 若某条插入路径经过查询终点，则分隔符之前的内容必须恰为 suff，说明对应单词以 suff 结尾；分隔符之后又以 pref 开始，说明该单词以 pref 开头。因此该路径对应的单词必然满足两个条件。

最大下标。 单词按下标递增插入，且每次都覆盖沿途节点的 weight。查询终点最终保存的就是所有满足条件的单词中最大的下标。综上，算法返回正确答案。

O(n · L²)预处理时间；每个单词枚举 O(L) 个后缀，每条路径长度 O(L)
O(n · L²)最坏空间；字典树共享路径后通常更少
O(P + S)单次查询时间；P、S 分别是前后缀长度

class WordFilter {
    private static class TrieNode {
        TrieNode[] next = new TrieNode[27];
        int weight = -1;
    }

    private final TrieNode root = new TrieNode();

    public WordFilter(String[] words) {
        for (int index = 0; index < words.length; index++) {
            String word = words[index];
            for (int start = 0; start <= word.length(); start++) {
                String key = word.substring(start) + "{" + word;
                TrieNode node = root;
                node.weight = index;

                for (int i = 0; i < key.length(); i++) {
                    char ch = key.charAt(i);
                    int branch = ch == '{' ? 26 : ch - 'a';
                    if (node.next[branch] == null) {
                        node.next[branch] = new TrieNode();
                    }
                    node = node.next[branch];
                    node.weight = index;
                }
            }
        }
    }

    public int f(String pref, String suff) {
        String query = suff + "{" + pref;
        TrieNode node = root;

        for (int i = 0; i < query.length(); i++) {
            char ch = query.charAt(i);
            int branch = ch == '{' ? 26 : ch - 'a';
            if (node.next[branch] == null) {
                return -1;
            }
            node = node.next[branch];
        }
        return node.weight;
    }
}

var WordFilter = function(words) {
    this.root = { next: new Map(), weight: -1 };

    for (let index = 0; index < words.length; index++) {
        const word = words[index];

        for (let start = 0; start <= word.length; start++) {
            const key = word.slice(start) + "{" + word;
            let node = this.root;
            node.weight = index;

            for (const ch of key) {
                if (!node.next.has(ch)) {
                    node.next.set(ch, { next: new Map(), weight: -1 });
                }
                node = node.next.get(ch);
                node.weight = index;
            }
        }
    }
};

from typing import List


class TrieNode:
    def __init__(self) -> None:
        self.next = [None] * 27
        self.weight = -1


class WordFilter:
    def __init__(self, words: List[str]):
        self.root = TrieNode()

        for index, word in enumerate(words):
            for start in range(len(word) + 1):
                key = word[start:] + "{" + word
                node = self.root
                node.weight = index

                for ch in key:
                    branch = 26 if ch == "{" else ord(ch) - ord("a")
                    if node.next[branch] is None:
                        node.next[branch] = TrieNode()
                    node = node.next[branch]
                    node.weight = index

    def f(self, pref: str, suff: str) -> int:
        query = suff + "{" + pref
        node = self.root

            branch = 26 if ch == "{" else ord(ch) - ord("a")
            if node.next[branch] is None:
                return -1
            node = node.next[branch]

class WordFilter {
    struct TrieNode {
        std::array<int, 27> next{};
        int weight = -1;

        TrieNode() {
            next.fill(-1);
        }
    };

    std::vector<TrieNode> trie;

    static int branchOf(char ch) {
        return ch == '{' ? 26 : ch - 'a';
    }

public:
    WordFilter(std::vector<std::string>& words) : trie(1) {
        for (int index = 0; index < static_cast<int>(words.size()); index++) {
            const std::string& word = words[index];

            for (int start = 0; start <= static_cast<int>(word.size()); start++) {
                std::string key = word.substr(start) + "{" + word;
                int node = 0;
                trie[node].weight = index;

                for (char ch : key) {
                    int branch = branchOf(ch);
                    if (trie[node].next[branch] == -1) {
                        trie[node].next[branch] = static_cast<int>(trie.size());
                        trie.emplace_back();
                    }
                    node = trie[node].next[branch];
                    trie[node].weight = index;
                }
            }
        }
    }

    int f(std::string pref, std::string suff) {
        std::string query = suff + "{" + pref;
        int node = 0;

        for (char ch : query) {
            int branch = branchOf(ch);
            if (trie[node].next[branch] == -1) {
                return -1;
            }
            node = trie[node].next[branch];
        }
        return trie[node].weight;
    }
};

边界与常见错误

  • 必须按下标递增处理，并覆盖节点权重，否则无法保证返回最大下标。
  • 权重要写到路径沿途的每个节点，而不只是完整键的末端；查询串通常只是完整键的前缀。
  • 拼接顺序应为 suffix + "{" + word；查询则是 suff + "{" + pref。
  • 重复单词仍是不同下标，后出现的重复项应覆盖旧权重。
  • 不存在查询路径时要立即返回 -1。

替代方案与面试追问

  • 哈希表：枚举每个单词的所有前缀×后缀组合，直接映射到最大下标；代码更直观，查询接近 O(1)，空间同为 O(nL²)。
  • 双字典树：分别维护前缀树、反向后缀树及下标列表，再从尾部求交集；实现更复杂，查询与交集规模相关。
  • 追问：若单词长度从 7 增加到 10⁵，O(L²) 预处理将不可接受，应重新评估双树、倒排索引或离线查询。
  • 追问：若支持动态插入，组合字典树仍可增量写入，但删除需要维护计数或有序下标集合。
