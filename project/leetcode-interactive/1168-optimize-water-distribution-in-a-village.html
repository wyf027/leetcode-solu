Problem

题目描述

村庄中有 n 栋房屋，编号为 1 到 n。你需要让每栋房屋都获得水源。对房屋 i，可以支付 wells[i - 1] 在该房屋内打井；也可以铺设给定的双向水管，使它通过已接入水源的其他房屋取水。

pipes[j] = [house1, house2, cost] 表示以 cost 的费用连接两栋房屋。可以同时建若干口井并铺若干条管道。

目标：返回让所有房屋都能获得水的最小总费用。

函数签名

minCostToSupplyWater(n, wells, pipes) → integer

约束

  • 2 ≤ n ≤ 10⁴
  • wells.length = n
  • 0 ≤ wells[i] ≤ 10⁵
  • 1 ≤ pipes.length ≤ 10⁴
  • pipes[i].length = 3
  • 1 ≤ house1, house2 ≤ n
  • house1 ≠ house2
  • 0 ≤ cost ≤ 10⁵
示例 1
输入：n = 3, wells = [1,2,2], pipes = [[1,2,1],[2,3,1]]
输出：3

在 1 号房建井，再铺设 1–2 和 2–3 两条费用为 1 的水管，总费用为 3。

示例 2
输入：n = 2, wells = [1,1], pipes = [[1,2,1],[1,2,2]]
输出：2

可以各建一口井，也可以建一口井后铺费用为 1 的水管；最小费用均为 2。

Solution

从“任选多口井”到一棵树

本页目录 核心洞察 完整过程 正确性证明 边界情况 复杂度 四语言实现 替代方案 面试追问 常见错误 测试与验证

核心洞察：增加虚拟节点 0

普通管道天然是房屋之间的加权边。难点在于“每栋房都可以独立打井”看起来不像一条边。引入一个代表公共水源的虚拟节点 0，为每栋房屋 i 添加边 (0, i, wells[i-1])。选择这条边，就等价于在房屋 i 打井。

此时，每栋房屋有水等价于节点 0..n 全部连通；总费用最低且无需环路，正好就是增广图的最小生成树（MST）。

完整过程：Kruskal + 并查集

  1. 把所有原始水管边复制到统一边集合。
  2. 对每栋房屋 i，添加一条从 0 到 i、权重为建井费用的边。
  3. 将全部 pipes.length + n 条边按权重升序排列。
  4. 依次尝试每条边；若两个端点位于不同连通块，就合并它们并计入费用，否则跳过，避免形成环。
  5. 选满 n 条边时，n + 1 个节点已经连成一棵树，可提前结束。

正确性证明

引理 1：原问题中的任意可行供水方案，都可映射成增广图中连接所有节点的子图，费用不变。打井对应边 (0,i)，铺管对应原图边。

引理 2：增广图中任意连接所有节点的子图，也对应一个可行供水方案，费用不变。每栋房屋沿路径最终可到达虚拟水源 0。

引理 3：最优连通子图中可删除环上的任意一条边而仍保持连通，且费用不会增加，因此一定存在一棵最优生成树。

结论：Kruskal 按割性质得到增广图的最小生成树。由上述费用保持的一一映射，其费用就是原供水问题的最小费用。

边界情况

  • 所有水管都很贵：MST 会选择多条虚拟边，相当于每家或多家分别打井。
  • 某些井很贵但水管便宜：可以只在少数房屋打井，再通过管网供水。
  • 原始管道图不连通：虚拟节点仍为每栋房提供一条候选边，所以增广图必然连通。
  • 存在重边或相同费用：排序先后不影响最小总费用；并查集会自动拒绝成环边。
  • 费用为 0：算法无需特殊处理，零权边会被优先选择。

复杂度

时间O((n + p) log(n + p))排序主导，p 为水管数
空间O(n + p)增广边集与并查集

四语言完整实现

class Solution {
    public int minCostToSupplyWater(int n, int[] wells, int[][] pipes) {
        int[][] edges = new int[pipes.length + n][3];
        int index = 0;

        for (int[] pipe : pipes) {
            edges[index++] = new int[]{pipe[0], pipe[1], pipe[2]};
        }
        for (int house = 1; house <= n; house++) {
            edges[index++] = new int[]{0, house, wells[house - 1]};
        }

        java.util.Arrays.sort(edges,
            (a, b) -> Integer.compare(a[2], b[2]));

        UnionFind uf = new UnionFind(n + 1);
        int total = 0;
        int used = 0;

        for (int[] edge : edges) {
            if (uf.union(edge[0], edge[1])) {
                total += edge[2];
                if (++used == n) break;
            }
        }
        return total;
    }

    private static class UnionFind {
        private final int[] parent;
        private final int[] rank;

        UnionFind(int size) {
            parent = new int[size];
            rank = new int[size];
            for (int i = 0; i < size; i++) parent[i] = i;
        }

        int find(int x) {
            if (parent[x] != x) parent[x] = find(parent[x]);
            return parent[x];
        }

        boolean union(int a, int b) {
            int rootA = find(a);
            int rootB = find(b);
            if (rootA == rootB) return false;
            if (rank[rootA] < rank[rootB]) {
                parent[rootA] = rootB;
            } else if (rank[rootA] > rank[rootB]) {
                parent[rootB] = rootA;
            } else {
                parent[rootB] = rootA;
                rank[rootA]++;
            }
            return true;
        }
    }
}

var minCostToSupplyWater = function(n, wells, pipes) {
    const edges = pipes.map(([a, b, cost]) => [a, b, cost]);
    for (let house = 1; house <= n; house++) {
        edges.push([0, house, wells[house - 1]]);
    }
    edges.sort((a, b) => a[2] - b[2]);

    const parent = Array.from({ length: n + 1 }, (_, i) => i);
    const rank = new Array(n + 1).fill(0);

    const find = (x) => {
        if (parent[x] !== x) parent[x] = find(parent[x]);
        return parent[x];
    };

    const union = (a, b) => {
        let rootA = find(a);
        let rootB = find(b);
        if (rootA === rootB) return false;
        if (rank[rootA] < rank[rootB]) [rootA, rootB] = [rootB, rootA];
        parent[rootB] = rootA;
        if (rank[rootA] === rank[rootB]) rank[rootA]++;
        return true;
    };

    let total = 0;
    let used = 0;
    for (const [a, b, cost] of edges) {
        if (union(a, b)) {
            total += cost;
            if (++used === n) break;
        }
    }
    return total;
};
from typing import List


class Solution:
    def minCostToSupplyWater(
        self, n: int, wells: List[int], pipes: List[List[int]]
    ) -> int:
        edges = [pipe[:] for pipe in pipes]
        for house, cost in enumerate(wells, start=1):
            edges.append([0, house, cost])
        edges.sort(key=lambda edge: edge[2])

        parent = list(range(n + 1))
        rank = [0] * (n + 1)

        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(a: int, b: int) -> bool:
            root_a, root_b = find(a), find(b)
            if root_a == root_b:
                return False
            if rank[root_a] < rank[root_b]:
                root_a, root_b = root_b, root_a
            parent[root_b] = root_a
            if rank[root_a] == rank[root_b]:
                rank[root_a] += 1
            return True

        total = used = 0
        for a, b, cost in edges:
            if union(a, b):
                total += cost
                used += 1
                if used == n:
                    break
        return total
class Solution {
    class UnionFind {
        vector<int> parent, rank;
    public:
        explicit UnionFind(int size) : parent(size), rank(size, 0) {
            iota(parent.begin(), parent.end(), 0);
        }

        int find(int x) {
            if (parent[x] != x) parent[x] = find(parent[x]);
            return parent[x];
        }

        bool unite(int a, int b) {
            a = find(a);
            b = find(b);
            if (a == b) return false;
            if (rank[a] < rank[b]) swap(a, b);
            parent[b] = a;
            if (rank[a] == rank[b]) ++rank[a];
            return true;
        }
    };

public:
    int minCostToSupplyWater(
        int n, vector<int>& wells, vector<vector<int>>& pipes
    ) {
        vector<array<int, 3>> edges;
        edges.reserve(pipes.size() + n);

        for (const auto& pipe : pipes) {
            edges.push_back({pipe[0], pipe[1], pipe[2]});
        }
        for (int house = 1; house <= n; ++house) {
            edges.push_back({0, house, wells[house - 1]});
        }

        sort(edges.begin(), edges.end(),
             [](const auto& a, const auto& b) { return a[2] < b[2]; });

        UnionFind uf(n + 1);
        int total = 0, used = 0;
        for (const auto& edge : edges) {
            if (uf.unite(edge[0], edge[1])) {
                total += edge[2];
                if (++used == n) break;
            }
        }
        return total;
    }
};

替代方案：Prim

同样可以在增广图上运行 Prim：从虚拟节点 0 出发，用最小堆不断选择连接“树内”与“树外”的最便宜边。邻接表 + 二叉堆的时间复杂度为 O((n+p) log(n+p))，空间复杂度为 O(n+p)。

Kruskal 更贴合本题“将井与管道统一排序”的叙事，实现也直接；若图以邻接表给出、边不便统一收集，Prim 往往更自然。

面试追问

为什么一口井能表示成边？

它把房屋直接接入抽象水源，费用恰好是边权；选择该边与建井完全等价。

为什么最终恰好选 n 条边？

增广图有 n+1 个节点，任意生成树都恰有 n 条边。

能否只选一口井？

不能。管道图可能不连通，或多口便宜井比跨区管道更省。

若必须恰好建 k 口井呢？

普通 MST 不再直接满足计数约束，需要参数化边权、拉格朗日松弛或更专门的约束生成树方法。

常见错误

先选最便宜的单口井

这隐含假设所有房屋能靠管道连通，且忽略了再建井可能更便宜。

只对原始管道求 MST

没有把建井纳入同一优化空间，也无法处理原图不连通。

并查集只开 n 个位置

还需要容纳虚拟节点 0，因此数组长度必须为 n+1。

选满 n-1 条边就停

增广图有 n+1 个节点，生成树应选择 n 条边。
