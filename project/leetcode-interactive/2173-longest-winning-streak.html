最多连胜的次数

Longest Winning Streak

从一张比赛记录表，找出每位玩家最长的一段连胜。先读数据，尝试独立写出查询，再展开下方题解。

阅读题意 ↓

01 / 题意与数据契约

输入表 Matches 记录玩家在各比赛日的结果。按每位玩家的比赛时间，求没有被平局或失败打断的最长连续胜场数，输出 player_id 与 longest_streak。从未获胜的玩家也需保留，值为 0；输出行的顺序不限。

Matches 输入表结构
字段类型含义
player_idint玩家编号
match_daydate比赛日期
resultenumWin / Draw / Lose

约束

  • (player_id, match_day) 是复合主键，同一玩家同一天至多一条记录。
  • 结果限定为 Win、Draw、Lose。
  • “连续”按比赛场次计算；没有比赛的日期不会中断连胜。
  • 题面没有提供行数或玩家编号的数值上下界，不自行补造限制。

题名、表结构、示例输入来自本轮官方元数据；因付费题题面字段为空，规则转述参考 LeetCode Wiki 题面整理。官方题目入口。

04 / 独立题解

准备好后展开：分段演示、正确性推导与五份代码。

用非胜场给连胜分段

核心洞察：每遇到 Draw 或 Lose 就增加段号，遇到 Win 段号不变。同一玩家、同一段号里的胜场属于同一段连胜。非胜场本身计 0，保留所有行就自然保留了零胜场玩家。

段号 grp = 到当前行为止的非胜场数。
每段 wins = 该段 Win 的个数。
每位玩家的答案 = MAX(wins)。

比赛胶片 → 分段计数器

卡片按比赛顺序排列，卡片间距不代表日期差。绿色标记胜场，橙色标记断点；文字同时提供结果。每一步把一场比赛送入对应段号的计数器。

键盘：Tab 选择控件，Enter / 空格触发按钮。开启减少动态效果时，自动播放改为逐步操作。

完整过程

  1. 在每位玩家内按 match_day 升序，窗口累计非 Win 的数量，得到 grp。显式使用 ROWS 前缀窗口。
  2. 按 (player_id, grp) 分组，用条件求和统计 Win。切勿把段首的非胜场计入连胜。
  3. 按玩家对各段胜场数取最大值。无胜场的玩家仍有计数为 0 的分组。

玩家 1 的结果为 Win、Win、Win、Draw、Win；段号依次是 0、0、0、1、1，两个段的胜场数为 3 与 1，因此答案为 3。

为什么正确

任意两场属于同一段连胜的 Win 之间没有非胜场，前缀非胜场数不变，因此它们落在同一组。若两场 Win 被 Draw 或 Lose 隔开，后者的前缀非胜场数更大，必然属于不同组。于是每个含胜场的分组恰好对应一段极大的连续胜场区间。条件求和得到其长度，取最大值就是所求。没有胜场时所有分组的和均为 0，因此答案仍正确。

边界与常见错误

  • 全 Win：全部落入第 0 段；只有一个 Win：答案为 1。
  • 全 Draw / Lose：段号不断增加，但每段 wins 都为 0。
  • 最后一场获胜：不需要额外断点，最后一段照常参与聚合。
  • 日期跳跃：不能使用日期相减来识别连胜；顺序才是依据。
  • 不能先过滤 Win 再计算断点，否则断点消失；也不能使用 COUNT(*) 统计包含非胜场的整段。
  • 窗口和 GROUP BY 都要带玩家维度，否则会混合不同玩家。
  • 空 Matches 返回空结果；没有任何记录的玩家不在输入表中，不能凭空补行。

复杂度

设记录数为 n。一般执行计划中窗口排序为 O(n log n)，分组可通过哈希或排序实现，整体按常见排序计划计 O(n log n)，中间数据空间 O(n)。若索引或执行计划提供有序输入，可减少排序开销，实际取决于数据库。四语言参考采用排序后扫描，时间 O(n log n)，包含输入副本和结果的额外空间 O(n)。

替代方案

双 ROW_NUMBER：玩家内全场序号减去玩家内同结果序号，对 Win 行形成稳定段号；必须先在全表计算，再筛选 Win，且需要左连接所有玩家并 COALESCE 补 0。应用程序中可排序后维护 current / best：Win 时 current 加一，其他结果清零，并持续更新 best。四语言代码采用这一等价扫描方式。

面试追问

  • 最长不败如何改？仅 Lose 增加段号，Win 和 Draw 均计 1。
  • 如何返回连胜起止日期？对每段 Win 条件取 MIN / MAX 日期，筛选最长段，并说明并列段是全部返回还是择一。
  • 同一天允许多场怎么办？必须增加比赛编号或时间戳作为稳定排序键，再定义并列顺序。
  • 数据按时间流入怎么办？每个玩家保存 current 与 best；乱序事件则需重排或回算受影响记录。

MySQL 8 · 官方可提交语言

WITH marked AS (
    SELECT player_id, match_day, result,
           SUM(CASE WHEN result = 'Win' THEN 0 ELSE 1 END)
           OVER (PARTITION BY player_id ORDER BY match_day
                 ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS grp
    FROM Matches
), streaks AS (
    SELECT player_id, grp,
           SUM(CASE WHEN result = 'Win' THEN 1 ELSE 0 END) AS wins
    FROM marked
    GROUP BY player_id, grp
)
SELECT player_id, MAX(wins) AS longest_streak
FROM streaks
GROUP BY player_id;

Java · 本地语义参考（Java 17）

import java.util.*;

class Solution {
    record Match(int playerId, String matchDay, String result) {}
    record Answer(int playerId, int longestStreak) {}

    // 日期须为 YYYY-MM-DD；输入符合 Matches 表约束。
    public List<Answer> longestWinningStreak(List<Match> matches) {
        List<Match> rows = new ArrayList<>(matches);
        rows.sort(Comparator.comparingInt(Match::playerId)
                .thenComparing(Match::matchDay));
        List<Answer> answer = new ArrayList<>();
        int i = 0;
        while (i < rows.size()) {
            int player = rows.get(i).playerId(), current = 0, best = 0;
            while (i < rows.size() && rows.get(i).playerId() == player) {
                current = rows.get(i).result().equals("Win") ? current + 1 : 0;
                best = Math.max(best, current);
                i++;
            }
            answer.add(new Answer(player, best));
        }
        return answer;
    }
}

JavaScript · 本地语义参考

// matches: [{player_id: number, match_day: "YYYY-MM-DD", result: string}]
// 返回 [{player_id, longest_streak}]；输入符合 Matches 表约束。
function longestWinningStreak(matches) {
    const rows = [...matches].sort((a, b) =>
        a.player_id - b.player_id || a.match_day.localeCompare(b.match_day));
    const answer = [];
    let i = 0;
    while (i < rows.length) {
        const player = rows[i].player_id;
        let current = 0, best = 0;
        while (i < rows.length && rows[i].player_id === player) {
            current = rows[i].result === "Win" ? current + 1 : 0;
            best = Math.max(best, current);
            i++;
        }
        answer.push({player_id: player, longest_streak: best});
    }
    return answer;
}

from typing import List, Tuple

# 输入：(player_id, YYYY-MM-DD, result)；符合 Matches 表约束。
# 输出：(player_id, longest_streak)。
def longest_winning_streak(
    matches: List[Tuple[int, str, str]]
) -> List[Tuple[int, int]]:
    rows = sorted(matches, key=lambda row: (row[0], row[1]))
    answer = []
    i = 0
    while i < len(rows):
        player = rows[i][0]
        current = best = 0
        while i < len(rows) and rows[i][0] == player:
            current = current + 1 if rows[i][2] == "Win" else 0
            best = max(best, current)
            i += 1
        answer.append((player, best))
    return answer

#include <algorithm>
#include <string>
#include <tuple>
#include <utility>
#include <vector>
using namespace std;

struct Match {
    int player_id;
    string match_day; // YYYY-MM-DD
    string result;
};

// 输入符合 Matches 表约束；输出 (player_id, longest_streak)。
vector<pair<int, int>> longestWinningStreak(vector<Match> rows) {
    sort(rows.begin(), rows.end(), [](const Match& a, const Match& b) {
        return tie(a.player_id, a.match_day) < tie(b.player_id, b.match_day);
    });
    vector<pair<int, int>> answer;
    size_t i = 0;
    while (i < rows.size()) {
        int player = rows[i].player_id, current = 0, best = 0;
        while (i < rows.size() && rows[i].player_id == player) {
            current = rows[i].result == "Win" ? current + 1 : 0;
            best = max(best, current);
            ++i;
        }
        answer.emplace_back(player, best);
    }
    return answer;
}
