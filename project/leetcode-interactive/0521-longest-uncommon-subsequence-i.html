LeetCode 521 · String

最长特殊序列 Ⅰ

Longest Uncommon Subsequence I

EASY非付费题交互式推演

题目

给定两个字符串 a 和 b，返回二者之间最长特殊序列的长度；若不存在则返回 -1。特殊序列是指：它恰好只为两个字符串中一个的子序列。

子序列可以通过删除原字符串中的任意数量字符得到，同时保持剩余字符的相对顺序。

示例 1

输入：a = "aba", b = "cdc"
输出：3
解释："aba"（或 "cdc"）只属于自身的子序列。

示例 2

输入：a = "aaa", b = "bbb"
输出：3
解释：最长特殊序列可取 "aaa" 或 "bbb"。

示例 3

输入：a = "aaa", b = "aaa"
输出：-1
解释：任一方的所有子序列也都是另一方的子序列。

约束

  • 1 <= a.length, b.length <= 100
  • a、b 仅含小写英文字母。

先观察，再下结论

逐步查看“整个字符串”作为候选序列时会发生什么。答案不会在首屏直接给出。

题解

核心洞察

只有两种情况。若 a === b，它们拥有完全相同的子序列集合，因此不存在特殊序列。若两者不同，较长的完整字符串一定不是较短字符串的子序列；长度相同时，两个不同字符串也不可能互为子序列。因此答案就是较长字符串的长度。

完整过程

  1. 比较两个字符串是否完全相等。
  2. 相等则返回 -1。
  3. 不相等则返回 max(a.length, b.length)。

正确性证明

相等时：两个字符串相同，所以任意一个字符串的任意子序列也必然是另一个的子序列，无解。

不等时：设较长者为 s。若两者长度不同，较长字符串不可能是较短字符串的子序列；若长度相同，一个等长字符串要成为另一个的子序列，只能逐字符完全相同，与“不等”矛盾。因此 s 是特殊序列。任何子序列长度都不会超过 |s|，所以它也是最长的。

边界与复杂度

  • 两个长度为 1 的相同字符：返回 -1。
  • 长度相同但仅一处不同：返回该共同长度。
  • 复杂度：字符串相等比较最坏需 O(min(m,n)) 时间；额外空间 O(1)。

替代方案

可以枚举子序列再检查归属，但每个长度为 n 的字符串有指数级子序列，完全没有必要。本题的关键正是识别“完整字符串本身”已经是最优候选。

面试追问

  • 若输入扩展为多个字符串，应如何寻找最长特殊子序列？可按长度降序检查每个字符串是否为其他字符串的子序列。
  • 为什么等长不同字符串不能互为子序列？因为无法删除任何字符，只能逐位相同。
  • 语言中的字符串相等比较成本是多少？通常最坏为线性。

常见错误

  • 误把“子串”当“子序列”。
  • 不必要地生成所有子序列，导致指数复杂度。
  • 只比较长度，漏掉等长但内容不同的情况。

四种语言实现

class Solution {
    public int findLUSlength(String a, String b) {
        return a.equals(b) ? -1 : Math.max(a.length(), b.length());
    }
}
/**
 * @param {string} a
 * @param {string} b
 * @return {number}
 */
var findLUSlength = function(a, b) {
    return a === b ? -1 : Math.max(a.length, b.length);
};
class Solution:
    def findLUSlength(self, a: str, b: str) -> int:
        return -1 if a == b else max(len(a), len(b))
class Solution {
public:
    int findLUSlength(string a, string b) {
        return a == b ? -1 : max(a.size(), b.size());
    }
};
