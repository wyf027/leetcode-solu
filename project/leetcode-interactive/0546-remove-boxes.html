移除盒子

颜色相同的盒子未必要立刻消除。暂时保留它们，让原本分散的同色盒子在中间区间清空后汇合，可能得到更高的平方分数。

HARD记忆化搜索区间动态规划数组

题目

给定整数数组 boxes，每个正整数代表一种颜色。每轮可移除一段颜色相同、连续且长度为 k 的盒子，并获得 k² 分。重复操作直至没有盒子，求可获得的最大总分。

函数形式：removeBoxes(boxes: integer[]) → integer

约束

  • 1 ≤ boxes.length ≤ 100
  • 1 ≤ boxes[i] ≤ 100

官方示例

输入：boxes = [1,3,2,2,2,3,4,3,1]
输出：23
解释：移除 2,2,2 得 9 分；移除 4 得 1 分；
      合并后的 3,3,3 得 9 分；最后 1,1 得 4 分。
输入：boxes = [1,1,1]
输出：9
输入：boxes = [1]
输出：1

Editorial

题解：把区间外的同色盒子带进状态

核心洞察

普通的二维区间状态无法表达“当前区间右侧已经有若干个与右端同色的盒子”。定义 dp(l, r, k)：处理闭区间 [l,r]，且 r 右侧还紧跟着 k 个与 boxes[r] 同色的盒子时，能够得到的最大分数。那些盒子虽然不在区间中，却会与右端一起被消除。

先把右端连续同色段压缩进 k。随后有两类决策：立即移除右端组；或寻找区间内同色位置 i，先清空 (i,r) 中间的盒子，让 boxes[i] 与右端组汇合。

dp(l,r,k) = max( dp(l,r-1,0) + (k+1)²,　dp(l,i,k+1) + dp(i+1,r-1,0) )

完整过程

  1. 空区间返回 0；用三维缓存避免重复计算。
  2. 若 boxes[r-1] == boxes[r]，令 r--, k++，将相邻同色盒子统一并到右端组。
  3. 基线方案：现在移除右端组，得分为 dp(l,r-1,0) + (k+1)²。
  4. 枚举 l ≤ i < r。当 boxes[i] == boxes[r] 时，先独立清空 [i+1,r-1]，再把右端组作为额外同色盒子交给 dp(l,i,k+1)。
  5. 取所有方案最大值并写入缓存。

正确性说明

引理 1：右端连续同色盒子可合并进 k，因为在任何方案中它们之间没有其他颜色，分开消除不会比合并获得更多平方分。

引理 2：最优方案对右端组只有两种可能：它不与区间内更早的同色盒子合并；或者最先与某个位置 i 的同色盒子合并。前者由基线覆盖，后者必先清空 (i,r)，恰由枚举转移覆盖。

结论：依据区间长度归纳，子状态均返回对应子问题最优值；转移穷尽右端组的所有最终归宿，因此 dp(0,n-1,0) 是全局最优值。

边界与复杂度

  • 空区间返回 0；单盒自然得到 1。
  • 全同色数组在压缩后一次得到 n²。
  • 状态数至多 O(n³)，每个状态枚举 O(n) 个位置，时间 O(n⁴)，空间 O(n³)。实际压缩与颜色判断会剪去许多分支。

替代方案

可以写自底向上的三维区间 DP，但状态依赖与初始化更繁琐。暴力枚举每轮移除段会产生指数级分支；只做二维区间 DP 会丢失“区间外同色数量”，无法正确评估延迟合并的收益。

面试追问

  • 为什么额外维度是同色盒子的“数量”，而不是它们的位置？因为后续收益只取决于合并后的规模。
  • 能否将理论时间降到 O(n³)？讨论同色位置预处理与状态转移总次数，但需严谨证明界限。
  • 如何恢复具体消除顺序？缓存最优值时同步记录选择，再递归回溯。

常见错误

  • 把 k 理解为区间内右端组长度；它表示区间右侧额外携带的同色数量。
  • 合并转移写成 dp(l,i,k)，忘记右端当前盒子使携带数量增加 1。
  • 右端压缩后仍用压缩前的缓存键，导致状态含义与缓存不一致。
  • 使用固定值 0 表示“未计算”时忘记空区间也为 0；可用 Map、-1 或单独 visited。

class Solution {
    private int[] boxes;
    private int[][][] memo;

    public int removeBoxes(int[] boxes) {
        this.boxes = boxes;
        int n = boxes.length;
        memo = new int[n][n][n];
        return dfs(0, n - 1, 0);
    }

    private int dfs(int left, int right, int extra) {
        if (left > right) return 0;
        while (right > left && boxes[right] == boxes[right - 1]) {
            right--;
            extra++;
        }
        if (memo[left][right][extra] != 0) return memo[left][right][extra];

        int best = dfs(left, right - 1, 0) + (extra + 1) * (extra + 1);
        for (int i = left; i < right; i++) {
            if (boxes[i] == boxes[right]) {
                best = Math.max(best,
                    dfs(left, i, extra + 1) + dfs(i + 1, right - 1, 0));
            }
        }
        return memo[left][right][extra] = best;
    }
}

var removeBoxes = function(boxes) {
    const memo = new Map();

    function dfs(left, right, extra) {
        if (left > right) return 0;
        while (right > left && boxes[right] === boxes[right - 1]) {
            right--;
            extra++;
        }
        const key = left + "," + right + "," + extra;
        if (memo.has(key)) return memo.get(key);

        let best = dfs(left, right - 1, 0) + (extra + 1) ** 2;
        for (let i = left; i < right; i++) {
            if (boxes[i] === boxes[right]) {
                best = Math.max(best,
                    dfs(left, i, extra + 1) + dfs(i + 1, right - 1, 0));
            }
        }
        memo.set(key, best);
        return best;
    }
    return dfs(0, boxes.length - 1, 0);
};
from functools import lru_cache
from typing import List

class Solution:
    def removeBoxes(self, boxes: List[int]) -> int:
        @lru_cache(None)
        def dfs(left: int, right: int, extra: int) -> int:
            if left > right:
                return 0
            while right > left and boxes[right] == boxes[right - 1]:
                right -= 1
                extra += 1

            best = dfs(left, right - 1, 0) + (extra + 1) ** 2
            for i in range(left, right):
                if boxes[i] == boxes[right]:
                    best = max(
                        best,
                        dfs(left, i, extra + 1) + dfs(i + 1, right - 1, 0)
                    )
            return best

        return dfs(0, len(boxes) - 1, 0)
class Solution {
    int memo[100][100][100] = {};

    int dfs(const vector<int>& boxes, int left, int right, int extra) {
        if (left > right) return 0;
        while (right > left && boxes[right] == boxes[right - 1]) {
            --right;
            ++extra;
        }
        int& best = memo[left][right][extra];
        if (best != 0) return best;

        best = dfs(boxes, left, right - 1, 0) + (extra + 1) * (extra + 1);
        for (int i = left; i < right; ++i) {
            if (boxes[i] == boxes[right]) {
                best = max(best,
                    dfs(boxes, left, i, extra + 1) +
                    dfs(boxes, i + 1, right - 1, 0));
            }
        }
        return best;
    }

public:
    int removeBoxes(vector<int>& boxes) {
        return dfs(boxes, 0, static_cast<int>(boxes.size()) - 1, 0);
    }
};
