LeetCode 902 · 数位计数

最大为 N 的数字组合

Numbers At Most N Given Digit Set — 从“更短的数”到“与 N 等长的前缀决策”，逐位数清所有合法正整数。

HARD数组数学字符串动态规划

题目

给定一个按非递减顺序排列、元素互不相同的数字字符串数组 digits。每个数字可以重复使用任意次。返回仅用这些数字组成、且小于或等于整数 n 的正整数个数。

函数签名
atMostNGivenDigitSet(digits: string[], n: integer): integer

约束

  • 1 ≤ digits.length ≤ 9
  • 每个 digits[i] 恰为一位，范围为 '1'..'9'
  • 所有元素互不相同，且按非递减顺序排列
  • 1 ≤ n ≤ 10⁹

先观察，不急着看答案

假设 digits = [1,3,5,7]，而 n = 365。你会怎样把计数拆成互不重叠的几组？

提示：位数少于 3 的数必然小于 365；三位数则由第一个不同的位置决定大小。

下面的演示把这个决策过程画成一条前缀路径。先尝试预测每一步新增多少答案。

题解：按位分类计数

核心洞察

设 n 有 L 位、可用数字数为 m。长度小于 L 的合法数共有 m¹ + … + m^(L-1) 个。对于长度恰为 L 的数，从左向右和 n 比较：在第 i 位选择一个比 n[i] 小的数字后，剩余位可任意填，因此贡献 less × m^(L-i-1)。

完整过程

  1. 把 n 转成字符串，先累加所有较短长度的排列数。
  2. 逐位统计可用数字中小于当前目标位的数量，将它们对应的整棵后缀分支加入答案。
  3. 若当前目标位本身不在集合中，等长匹配路径已经断开，立即返回。
  4. 若每一位都能精确匹配，说明 n 本身合法，最后再加 1。

正确性证明

较短部分完整且不重复

每个长度为 k<L 的合法串恰对应 m^k 种选择；因无数字 0，它们都是合法正整数并且必小于 n。

等长部分完整且不重复

每个小于 n 的等长数都有唯一“首个小于”的位置。算法正好在该位置把它计入一次。

边界路径正确

缺少相等数字时不可能继续保持相同前缀；全部相等时，唯一遗漏的是 n 自身，故加 1。

边界情况

  • n 只有一位：较短部分为空，直接扫描首位。
  • 首位就无法相等：加入所有更小首位分支后立刻结束。
  • digits 只有一个数字：幂计数仍然成立。
  • n = 10⁹：字符串长度为 10；约束范围内 32 位整数足够容纳答案。

复杂度

直接扫描每一位的每个可用数字：时间 O(L·m)，额外空间 O(L)（来自 n 的字符串表示）。由于 digits 已排序，也可二分得到小于当前位的数量，将时间降为 O(L log m)。

替代方案

可写成标准数位 DP，状态为位置、是否贴紧上界、是否已开始。它更适合包含 0、允许前导零或有额外数字约束的泛化题；本题不含 0，用组合计数更短、更直接。

面试追问

  • 如果集合允许 0，如何排除前导零？
  • 如果要求区间 [low, high]，如何用两次前缀计数完成？
  • 如果某些数字有使用次数限制，状态需要增加什么？

常见错误

  • 忘记先统计所有位数更短的数。
  • 相等路径中断后仍继续处理后续位，导致重复或虚假计数。
  • 当 n 可由集合组成时忘记把 n 自身计入。
  • 误把数字当整数拼接，增加不必要的溢出风险。

class Solution {
    public int atMostNGivenDigitSet(String[] digits, int n) {
        String s = String.valueOf(n);
        int m = digits.length, ans = 0;
        for (int len = 1; len < s.length(); len++) {
            ans += pow(m, len);
        }
        for (int i = 0; i < s.length(); i++) {
            char target = s.charAt(i);
            boolean equal = false;
            for (String digit : digits) {
                char d = digit.charAt(0);
                if (d < target) ans += pow(m, s.length() - i - 1);
                else if (d == target) equal = true;
                else break;
            }
            if (!equal) return ans;
        }
        return ans + 1;
    }
    private int pow(int base, int exp) {
        int result = 1;
        while (exp-- > 0) result *= base;
        return result;
    }
}

from typing import List

class Solution:
    def atMostNGivenDigitSet(self, digits: List[str], n: int) -> int:
        s = str(n)
        m = len(digits)
        ans = sum(m ** length for length in range(1, len(s)))

        for i, target in enumerate(s):
            equal = False
            for digit in digits:
                if digit < target:
                    ans += m ** (len(s) - i - 1)
                elif digit == target:
                    equal = True
                else:
                    break
            if not equal:
                return ans
        return ans + 1
