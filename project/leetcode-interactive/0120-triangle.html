三角形Triangle · 山谷测绘站

给定一座由数字构成的三角山谷，从顶点出发，每次只能走到下一行相邻的两个位置之一。 任务是找到抵达最底部时的最小路径和。

难度：中等 数组 动态规划 目标空间 O(n)

Descent permit

每一步，只能进入正下方或右下方的相邻测点。

Route brief

题意转述

若当前位于第 i 行下标 j，可移动到下一行的 j 或 j + 1。 返回从顶到底能够取得的最小元素总和。

边界与约束

  • 三角形行数在 1 到 200 之间。
  • 首行只有一个元素，之后每行比上一行多一个元素。
  • 每个数字都在 -10⁴ 到 10⁴ 之间。
  • 进阶要求：只使用与行数成正比的额外空间。

官方样例

样例 1
输入 triangle = [[2],[3,4],[6,5,7],[4,1,8,3]] 输出 11 路径 2 → 3 → 5 → 1 的和最小。
样例 2
输入 triangle = [[-10]] 输出 -10

题解

核心洞察、完整过程、复杂度和四语言代码默认隐藏。

核心洞察

从底部向上看，每个位置只关心下一行两个相邻位置的最小累计代价。 因此可把最底行复制为 dp，并逐行用 dp[j] = triangle[i][j] + min(dp[j], dp[j + 1]) 覆盖。最后 dp[0] 就是答案。

复杂度

  • 时间复杂度：O(n²)，每个元素恰好处理一次。
  • 额外空间：O(n)，只保留一行累计代价。
  • 若允许修改输入，可直接在最后一行原地回填。

完整过程

  1. 复制最底行，作为每个底部测点到终点的最小代价。
  2. 从倒数第二行向上枚举行 i。
  3. 对当前行每个 j，比较 dp[j] 与 dp[j + 1]，取较小者加上当前值。
  4. 覆盖 dp[j]；处理完顶点后返回 dp[0]。

边界与常见错误

  • 单行三角形应直接返回唯一元素。
  • 存在负数，不能使用局部贪心选择较小的下一步。
  • dp 必须复制最底行，避免意外修改只读输入。
  • 自底向上时，dp[j + 1] 必须仍代表下一行的旧状态。

替代方案与取舍

  • 二维 DP：最直观，但需要 O(n²) 空间。
  • 自顶向下记忆化：便于从路径定义出发，但有递归栈。
  • 逐层滚动数组：同为 O(n) 空间，实现略繁琐。

面试追问

  • 为什么局部选择较小相邻数字不一定得到全局最优？
  • 如何恢复一条实际的最小路径，而不只返回路径和？
  • 如果三角形通过流式输入逐行到达，应选择哪个方向的 DP？
  • 允许修改输入时，怎样把额外空间降为 O(1)？

class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int n = triangle.size();
        int[] dp = new int[n];

        for (int j = 0; j < n; j++) {
            dp[j] = triangle.get(n - 1).get(j);
        }

        for (int i = n - 2; i >= 0; i--) {
            for (int j = 0; j <= i; j++) {
                dp[j] = triangle.get(i).get(j)
                    + Math.min(dp[j], dp[j + 1]);
            }
        }

        return dp[0];
    }
}

    def minimumTotal(self, triangle: List[List[int]]) -> int:
