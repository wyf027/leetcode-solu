数组的相对排序

按参考数组的出现顺序排列，再将剩余元素升序追加。

题意

给定 arr1 和无重复元素的 arr2，将 arr1 中在 arr2 出现的元素按 arr2 的顺序排列；其余元素按升序放在最后。

示例

arr1=[2,3,1,3,2,4,6,7,9,2,19]
arr2=[2,1,4,3,9,6]

输出：[2,2,2,1,4,3,3,9,6,7,19]

约束

1 ≤ arr1、arr2 长度 ≤ 1000；元素范围 0 到 1000；arr2 无重复元素。

分步交互

题解：计数与顺序输出

洞察

arr2 给出优先级；频次数组让每个数字可一次性输出对应次数。

过程
  1. 统计 arr1。
  2. 遍历 arr2，按频次写入。
  3. 升序扫描剩余频次。
边界

arr2 中不存在于 arr1 的值输出零次；未出现元素必须升序。

复杂度

时间 O(n+K)，空间 O(K)，K 是值域。

替代方案：自定义排序键。
常见错误：遗漏 arr2 之外元素或错误保留原序。
追问：值域很大时如何改用哈希表？

官方签名参考实现

// Java
class Solution { public int[] relativeSortArray(int[] a,int[] b){int[] c=new int[1001];for(int x:a)c[x]++;int k=0;for(int x:b)while(c[x]-->0)a[k++]=x;for(int x=0;x<1001;x++)while(c[x]-->0)a[k++]=x;return a;} }
// JavaScript
var relativeSortArray=function(a,b){const c=Array(1001).fill(0),r=[];for(const x of a)c[x]++;for(const x of b)while(c[x]--)r.push(x);for(let x=0;x<=1000;x++)while(c[x]--)r.push(x);return r;};
# Python
class Solution:
 def relativeSortArray(self,a:List[int],b:List[int])->List[int]:
  c=[0]*1001
  for x in a:c[x]+=1
  return [x for x in b for _ in range(c[x])] + [x for x in range(1001) for _ in range(c[x]) if x not in set(b)]
// C++
