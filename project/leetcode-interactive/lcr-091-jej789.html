LCR 091中等 MEDIUM动态规划

粉刷房子

有 n 栋房子，每栋可刷红、蓝、绿三色，且相邻房子颜色不同；求最低总花费。

交互演示

题意、示例与约束

输入：costs = [[17,2,17],[16,16,5],[14,3,19]]

输出：10

解释：蓝(2) → 绿(5) → 蓝(3)。

  • 0 ≤ costs.length ≤ 100，每行恰有 3 个非负花费。
  • 空数组没有房子，最小花费为 0。
  • 相邻两栋房子不能涂同一种颜色。

分步交互：滚动 DP

状态 r、b、g 分别表示当前房子涂红、蓝、绿的最低总价。

核心洞察

第 i 栋涂某色时，前一栋只能取另外两色中的较小花费。因此只需保存前一栋的三个最优值，不需要保留完整二维表。

完整过程

  1. 1. 初始化
    第一栋的三个价格就是状态。
  2. 2. 计算红
    cost红 + min(前蓝, 前绿)。
  3. 3. 同理
    更新蓝、绿，先用旧状态。
  4. 4. 收尾
    三种末色的最小值为答案。

边界、复杂度、替代与追问

边界：空数组返回 0；仅一栋时选其最小颜色。
复杂度：时间 O(n)，空间 O(1)。
替代：二维 dp[i][color] 更易理解，空间 O(n)。
追问：颜色扩展为 k 种如何优化？如何输出具体配色？
常见错误：用已经更新的红值计算蓝值；允许相邻同色；忘记空数组。

官方签名代码

// Java
class Solution { public int minCost(int[][] costs) { if(costs.length==0)return 0; int r=costs[0][0],b=costs[0][1],g=costs[0][2]; for(int i=1;i<costs.length;i++){int nr=costs[i][0]+Math.min(b,g),nb=costs[i][1]+Math.min(r,g),ng=costs[i][2]+Math.min(r,b);r=nr;b=nb;g=ng;} return Math.min(r,Math.min(b,g));} }
// JavaScript
var minCost = function(costs) { if(!costs.length)return 0; let [r,b,g]=costs[0]; for(let i=1;i<costs.length;i++){const [cr,cb,cg]=costs[i];[r,b,g]=[cr+Math.min(b,g),cb+Math.min(r,g),cg+Math.min(r,b)];} return Math.min(r,b,g); };
# Python
class Solution:
 def minCost(self, costs):
  if not costs: return 0
  r, b, g = costs[0]
  for cr, cb, cg in costs[1:]: r, b, g = cr + min(b,g), cb + min(r,g), cg + min(r,b)
  return min(r,b,g)
// C++
class Solution { public: int minCost(vector<vector<int>>& c) { if(c.empty())return 0; int r=c[0][0],b=c[0][1],g=c[0][2]; for(int i=1;i<c.size();++i){int nr=c[i][0]+min(b,g),nb=c[i][1]+min(r,g),ng=c[i][2]+min(r,b);r=nr;b=nb;g=ng;} return min(r,min(b,g)); } };
