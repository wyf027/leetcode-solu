每日新用户统计

New Users Daily Count · 从活动流水中识别每位用户的“第一次”，再按日期汇总。

题目

表 Traffic(user_id, activity, activity_date) 记录用户的活动，activity 可能为 login、logout、jobs、groups 或 homepage。

编写查询，统计截至 2019-06-30（含当日）最近 90 天内，每天首次登录网站的新用户数。某用户的“加入日期”是他所有记录中最早的 login 日期。结果列为 login_date 和 user_count，顺序不限。

日期窗口：2019-04-02 至 2019-06-30，首尾均包含。只出现其他活动而从未登录的用户不计入。

约束与字段

  • user_id 为整数。
  • activity_date 为日期。
  • 同一用户可在同一天或不同日期产生多条活动记录；统计单位是用户，而不是活动行。

题解

核心洞察

“新用户”由用户的首次登录决定。先过滤 activity='login'，对每个 user_id 求 MIN(activity_date)，再对首次日期做窗口过滤和分组。过滤必须发生在求最小值之后，否则窗口前注册、窗口内回访的老用户会被误判。

完整过程

  1. 内层查询仅保留登录记录。
  2. 按用户分组，得到唯一的首次登录日期。
  3. 保留 [2019-04-02, 2019-06-30] 内的首次日期。
  4. 按首次日期分组并计数。

正确性说明

对任意用户，内层 MIN 返回且只返回其最早登录日期，因此该行精确表示用户加入日。外层窗口条件保留且只保留目标 90 天内加入的用户。最后按加入日分组，COUNT 计算该日所有且仅有的新用户，故结果正确。

边界

  • 边界日期 2019-04-02 与 2019-06-30 都计入。
  • 一天多次登录仍只计一个用户。
  • 窗口前登录、窗口内再次登录不计。
  • 无登录记录的用户自然被过滤。
  • 没有新用户的日期无需补零。

复杂度

设登录记录数为 n。数据库通常通过分组/哈希或排序处理，逻辑复杂度约为 O(n)（哈希）或 O(n log n)（排序），额外空间约为不同用户数 O(u)。索引 (activity, user_id, activity_date) 可减少扫描成本。

替代方案

可用窗口函数 MIN(activity_date) OVER (PARTITION BY user_id) 或 ROW_NUMBER() 标识首登，再过滤。但本题派生表分组更直接。若要展示零值日期，则需日期维表或递归 CTE 补齐日期。

面试追问

  • 为何不能先筛 90 天再求 MIN？
  • 若“新用户”定义为首次任意活动，查询如何改？
  • 如何按时区处理时间戳边界？
  • 怎样输出窗口内每天（含 0）？

常见错误

  • 直接按所有 login 日期计数，把回访用户算成新用户。
  • 使用 DATEDIFF <= 90 却漏掉未来日期。
  • 把 90 天算成 2019-04-01 开始，产生 off-by-one。
  • 在同层 WHERE 中引用聚合别名。

官方可提交语言：MySQL

SELECT first_login AS login_date,
       COUNT(*) AS user_count
FROM (
    SELECT user_id, MIN(activity_date) AS first_login
    FROM Traffic
    WHERE activity = 'login'
    GROUP BY user_id
) AS first_logins
WHERE first_login BETWEEN '2019-04-02' AND '2019-06-30'
GROUP BY first_login;

import java.time.LocalDate;
import java.util.*;

class Solution {
    record Row(int userId, String activity, LocalDate date) {}
    record Daily(LocalDate loginDate, long userCount) {}

    List<Daily> newUsersDailyCount(List<Row> traffic) {
        LocalDate start = LocalDate.of(2019, 4, 2);
        LocalDate end = LocalDate.of(2019, 6, 30);
        Map<Integer, LocalDate> first = new HashMap<>();
        for (Row row : traffic) {
            if (row.activity().equals("login"))
                first.merge(row.userId(), row.date(),
                    (a, b) -> a.isBefore(b) ? a : b);
        }
        Map<LocalDate, Long> count = new TreeMap<>();
        for (LocalDate date : first.values())
            if (!date.isBefore(start) && !date.isAfter(end))
                count.merge(date, 1L, Long::sum);
        List<Daily> answer = new ArrayList<>();
        count.forEach((date, users) -> answer.add(new Daily(date, users)));
        return answer;
    }
}
function newUsersDailyCount(traffic) {
  const start = "2019-04-02", end = "2019-06-30";
  const first = new Map();
  for (const { user_id, activity, activity_date } of traffic) {
    if (activity !== "login") continue;
    const old = first.get(user_id);
    if (old === undefined || activity_date < old) first.set(user_id, activity_date);
  }
  const count = new Map();
  for (const date of first.values()) {
    if (date >= start && date <= end) count.set(date, (count.get(date) ?? 0) + 1);
  }
  return [...count].sort(([a], [b]) => a.localeCompare(b))
    .map(([login_date, user_count]) => ({ login_date, user_count }));
}
from collections import defaultdict

def new_users_daily_count(traffic):
    start, end = "2019-04-02", "2019-06-30"
    first = {}
    for user_id, activity, activity_date in traffic:
        if activity == "login":
            first[user_id] = min(first.get(user_id, activity_date), activity_date)
    count = defaultdict(int)
    for date in first.values():
        if start <= date <= end:
            count[date] += 1
    return [{"login_date": d, "user_count": count[d]} for d in sorted(count)]
#include <map>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

struct Daily { string loginDate; int userCount; };

vector<Daily> newUsersDailyCount(
    const vector<tuple<int, string, string>>& traffic) {
    map<int, string> first;
    for (const auto& [user, activity, date] : traffic) {
        if (activity != "login") continue;
        if (!first.count(user) || date < first[user]) first[user] = date;
    }
    map<string, int> count;
    for (const auto& [user, date] : first)
        if (date >= "2019-04-02" && date <= "2019-06-30") ++count[date];
    vector<Daily> answer;
    for (const auto& [date, users] : count) answer.push_back({date, users});
    return answer;
}
