和相等的子数组

Find Subarrays With Equal Sum

两个相邻元素组成一扇窗口。不同位置的窗口，能得到同一个和吗？

打开官方题目 ↗

01 / 题目

给定从下标 0 开始的整数数组 nums，判断是否存在两个长度恰好为 2、起始下标不同的连续子数组，使它们的元素和相等。存在返回 true，否则返回 false。

子数组必须连续。两个窗口可以重叠，元素内容也可以完全相同，只要起点不同即可。

参数与返回值

findSubarrays(nums) → boolean

nums：整数数组；返回值：是否存在满足条件的两个窗口。

约束

  • 2 ≤ nums.length ≤ 1000
  • −10⁹ ≤ nums[i] ≤ 10⁹

官方示例（完整输入）

输入：nums = [4,2,4]
输出：true

下标 [0,1] 的 [4,2] 与下标 [1,2] 的 [2,4] 的和均为 6。

输入：nums = [1,2,3,4,5]
输出：false

所有长度为 2 的窗口，其和都不同。

输入：nums = [0,0,0]
输出：true

[0,1] 与 [1,2] 两个窗口的和均为 0；内容相同但起点不同，仍是两个窗口。

04 / 独立题解

完成自己的推理后，再展开思路与四语言实现。

核心洞察：判断窗口和是否重复

长度固定为 2，起点 i 唯一确定窗口 [nums[i], nums[i+1]]。把问题化为：依次产生的 n−1 个窗口和里，是否有重复值？用哈希集合记录已经出现的和即可。

完整过程

  1. 建立空集合 seen，从 i = 0 遍历到 n−2。
  2. 计算 s = nums[i] + nums[i+1]。
  3. 若 seen 已包含 s，则存在更早起点的同和窗口，立即返回 true。
  4. 否则把 s 加入 seen，继续遍历；全部结束仍无重复，返回 false。

例如 [1,2,0,3]：起点 0 得到和 3，记录 3；起点 1 得到和 2，记录 2；起点 2 再次得到和 3，于是起点 0 与起点 2 配对。可视化额外记录首次起点以展示配对；提交代码只需集合。

正确性说明

不变式：处理起点 i 之前，seen 恰好保存所有起点小于 i 的窗口和。初始没有历史窗口，空集合满足条件。若当前和已出现，必有不同的更早起点与当前窗口同和，因此返回 true 正确。若未出现，将其加入便维持不变式。若存在满足条件的一对窗口，遍历到较晚的起点时必能在集合中找到较早的和。全部遍历仍未找到，说明任意两个起点的窗口和都不同，返回 false 正确。

边界与数值范围

  • n = 2 时只有一个窗口，无法配成两个，返回 false。
  • 允许重叠；[4,2,4] 的两个窗口共用中间元素。
  • 相同元素和负数都无需特殊处理，关键是和与起点。
  • 窗口和落在 [−2×10⁹, 2×10⁹]，Java 的 int 与常见 32 位 C++ int 可容纳；下方 C++ 使用 long long。JavaScript Number 可精确表示这些整数，Python 整数无此溢出问题。

复杂度

遍历 n−1 个窗口。哈希操作平均 O(1)，故平均时间 O(n)，额外空间 O(n)。极端哈希碰撞下不能保证每次操作常数时间；若追求确定的最坏界，可采用排序方案。

替代方案

  • 暴力两两比较窗口和：O(n²) 时间、O(1) 额外空间，适合理解题目。
  • 计算所有窗口和后排序，检查相邻值是否相同：O(n log n) 时间，需要 O(n) 保存窗口和。
  • 若维护窗口长度推广为 k，可先求第一个窗口和，再滑动时减去离开元素、加上进入元素。当前 k = 2 直接相加更简单。

常见错误

  • 先插入当前和再查询，会让窗口和自己匹配。
  • 只比较相邻两个窗口，会漏掉 [1,2,0,3] 中起点 0 与 2 的匹配。
  • 对 nums 排序会改变原有连续关系，不能这样做。
  • 把不同窗口理解为不重叠，或要求元素内容不同。
  • 遍历到 i = n−1 后仍访问 nums[i+1]，导致越界。

面试追问

如何返回两个起点？将集合换成 sum → 首次起点的映射。
如果不允许重叠？只把足够早的窗口加入可匹配集合，长度 2 时要求较早起点 ≤ i−2。
如何统计所有同和窗口对？维护每个和的频次；新窗口贡献此前该和的出现次数，然后频次加一。
如何处理流式输入？仅保留前一个元素和历史窗口和集合，逐个生成新的窗口和。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean findSubarrays(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int i = 0; i + 1 < nums.length; i++) {
            int sum = nums[i] + nums[i + 1];
            if (!seen.add(sum)) return true;
        }
        return false;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {boolean}
 */
var findSubarrays = function(nums) {
    const seen = new Set();
    for (let i = 0; i + 1 < nums.length; i++) {
        const sum = nums[i] + nums[i + 1];
        if (seen.has(sum)) return true;
        seen.add(sum);
    }
    return false;
};

Python 3

from typing import List

class Solution:
    def findSubarrays(self, nums: List[int]) -> bool:
        seen = set()
        for i in range(len(nums) - 1):
            total = nums[i] + nums[i + 1]
            if total in seen:
                return True
            seen.add(total)
        return False

C++

#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool findSubarrays(vector<int>& nums) {
        unordered_set<long long> seen;
        for (int i = 0; i + 1 < static_cast<int>(nums.size()); ++i) {
            long long sum = static_cast<long long>(nums[i]) + nums[i + 1];
            if (!seen.insert(sum).second) return true;
        }
        return false;
    }
};
