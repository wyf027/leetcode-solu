最小时间差

在一天的时钟上，找出任意两个时间点之间的最小分钟差。别忘了午夜：23:59 与 00:00 只相差 1 分钟。

题意

给定一个由 "HH:MM" 格式时间组成的数组 timePoints，返回任意两个不同时间点之间的最小分钟差。时间按 24 小时制循环。

示例

timePoints = ["23:59", "00:00"]

output = 1

将每个时间换算为从 00:00 起经过的分钟数并排序。相邻元素之差覆盖白天的间隔；最后一个与第一个跨越午夜的差也必须比较。

约束

2 ≤ timePoints.length ≤ 2 × 104；每个时间严格为 HH:MM，范围在 00:00 至 23:59。

      核心洞察

      一天只有 1440 分钟。把 HH:MM 解析为 hour × 60 + minute 后排序，最优的一对一定在排序后相邻的位置，或是首尾两项跨过午夜的位置。重复时间点会形成相邻差 0，立刻就是答案。

      完整过程

      1. 将每个字符串转成当天的分钟数。
      2. 按分钟数升序排序。
      3. 扫描相邻元素，更新最小差。
      4. 额外计算 minutes[0] + 1440 - minutes[n - 1]，处理午夜回环。

      边界与常见错误

      • 不能只比较普通相邻元素，否则会漏掉 23:59 与 00:00。
      • 同一时间出现两次时，排序后相邻差为 0。
      • 最多有 1440 种分钟值；若输入超过 1440 个，抽屉原理可直接返回 0。

      复杂度：解析与扫描为 O(n)，排序为 O(n log n)，总时间 O(n log n)，额外空间 O(n)。

      可提交代码

      Java

      class Solution {
    public int findMinDifference(List<String> timePoints) {
        int n = timePoints.size();
        if (n > 1440) return 0;
        int[] minutes = new int[n];
        for (int i = 0; i < n; i++) {
            String time = timePoints.get(i);
            minutes[i] = Integer.parseInt(time.substring(0, 2)) * 60
                + Integer.parseInt(time.substring(3));
        }
        Arrays.sort(minutes);
        int answer = minutes[0] + 1440 - minutes[n - 1];
        for (int i = 1; i < n; i++) answer = Math.min(answer, minutes[i] - minutes[i - 1]);
        return answer;
    }
}

      JavaScript

      var findMinDifference = function (timePoints) {
  if (timePoints.length > 1440) return 0;
  const minutes = timePoints
    .map((time) => Number(time.slice(0, 2)) * 60 + Number(time.slice(3)))
    .sort((a, b) => a - b);
  let answer = minutes[0] + 1440 - minutes.at(-1);
  for (let i = 1; i < minutes.length; i++) {
    answer = Math.min(answer, minutes[i] - minutes[i - 1]);
  }
  return answer;
};

      Python

      class Solution:
    def findMinDifference(self, timePoints: List[str]) -> int:
        if len(timePoints) > 1440:
            return 0
        minutes = sorted(
            int(time[:2]) * 60 + int(time[3:]) for time in timePoints
        )
        answer = minutes[0] + 1440 - minutes[-1]
        for i in range(1, len(minutes)):
            answer = min(answer, minutes[i] - minutes[i - 1])
        return answer

      C++

      class Solution {
public:
    int findMinDifference(vector<string>& timePoints) {
        if (timePoints.size() > 1440) return 0;
        vector<int> minutes;
        for (const string& time : timePoints) {
            minutes.push_back(stoi(time.substr(0, 2)) * 60 + stoi(time.substr(3)));
        }
        sort(minutes.begin(), minutes.end());
        int answer = minutes[0] + 1440 - minutes.back();
        for (int i = 1; i < minutes.size(); ++i) answer = min(answer, minutes[i] - minutes[i - 1]);
        return answer;
    }
};
