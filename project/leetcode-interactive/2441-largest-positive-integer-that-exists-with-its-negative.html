01 / 题目

给定不含 0 的整数数组 nums，找出最大的正整数 k，要求 k 与 -k 都出现在数组中。返回这个 k；如果不存在任何这样的正整数，则返回 -1。

参数：nums: integer[]　返回：integer　函数：findMaxK(nums)

官方示例

示例 1

输入：nums = [-1,2,-3,3]
输出：3

只有正整数 3 的对应负数 -3 也存在。

示例 2

输入：nums = [-1,10,6,7,-7,1]
输出：7

1 与 7 都满足条件，其中 7 更大。

示例 3

输入：nums = [-10,8,6,7,-2,-3]
输出：-1

没有任何正整数与其对应负数同时存在。

约束

  • 1 <= nums.length <= 1000
  • -1000 <= nums[i] <= 1000
  • nums[i] != 0

04 / 独立题解

准备好后，展开查看思路、证明与四语言实现。

核心洞察：在第二个数出现时识别配对

用集合 seen 保存之前出现的数。读取 x 时，如果 -x 已在集合中，就找到了一组相反数；它对应的正整数是 |x|。维护最大值即可，不受正负数出现顺序影响。

完整过程

  1. 令 seen 为空，ans = -1。
  2. 依次读取每个 x，查询 seen 是否包含 -x。
  3. 若包含，更新 ans = max(ans, abs(x))。
  4. 将 x 加入集合；继续读取。最终返回 ans。

对于 [-1,10,6,7,-7,1]：前四个数没有形成配对；读取 -7 时集合已有 7，答案更新为 7；读取 1 时集合已有 -1，候选值为 1，最大值仍是 7。

正确性证明

循环不变量：处理完前 i 个元素后，seen 恰好包含这个前缀中出现过的不同整数；ans 是该前缀内所有完整相反数对的最大正整数，没有配对时为 -1。

初始化：空前缀没有元素或配对，空集合和 -1 满足不变量。

保持：加入 x 后，新产生的配对只能涉及 x。如果 -x 已在集合中，取 |x| 与原答案的最大值恰好纳入这组配对；否则不会产生新配对。随后插入 x，集合也与新前缀一致。

终止：整个数组处理完后，不变量覆盖所有元素，因此返回值就是题目要求的最大正整数，或无解时的 -1。

边界与复杂度

  • 单个元素、全正数、全负数：均无法配对，返回 -1。
  • 重复数字不改变存在性；集合自动去重。
  • 0 被题目排除，因此不能把 0 当作答案。
  • 范围仅为 ±1000，四份代码取相反数和绝对值都不会溢出。
  • 哈希集合查询和插入平均 O(1)，总时间平均 O(n)；额外空间 O(n)，在本题范围下最多保存 2000 个不同值。哈希表不承诺所有碰撞情况下都维持常数时间。

替代方案

  • 先建完整集合，再遍历正数：检查 -x 是否存在，平均 O(n) 时间、O(n) 空间，思路同样直接。
  • 排序 + 双指针：将数组升序排序，左右端之和为 0 时发现配对；和小于 0 则左指针右移，否则右指针左移。有效相反数对中第一次找到的正数最大。时间 O(n log n)，空间取决于排序实现，且原地排序会改变输入。
  • 定长存在表：用长度 2001 的布尔表和偏移 1000 标记数值，再从 1000 向 1 查找成对位置。时间 O(n + U)、空间 O(U)，U = 2001，依赖已知范围。

四语言完整实现

与官方 findMaxK 签名对应；均为可提交形式，尚未执行验证。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int findMaxK(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        int ans = -1;
        for (int x : nums) {
            if (seen.contains(-x)) {
                ans = Math.max(ans, Math.abs(x));
            }
            seen.add(x);
        }
        return ans;
    }
}

C++

#include <vector>
#include <unordered_set>
#include <algorithm>
#include <cstdlib>
using namespace std;

class Solution {
public:
    int findMaxK(vector<int>& nums) {
        unordered_set<int> seen;
        int ans = -1;
        for (int x : nums) {
            if (seen.count(-x)) {
                ans = max(ans, abs(x));
            }
            seen.insert(x);
        }
        return ans;
    }
};

常见错误

  • 只返回数组中的最大正数，却没有确认对应负数是否存在。
  • 遇到第一组配对就返回：原数组无序，后面可能出现更大的配对。
  • 直接用 x 更新答案：如果后出现的是负数，会漏掉正确的正候选值，应取绝对值。
  • 将答案初始化为 0：无解返回值必须是 -1。
  • 每个数都用数组线性查找相反数：最坏 O(n²)，并非集合解法的平均 O(n)。

面试追问

数据是流式到达的怎么办？保留 seen 和 ans，每到一个新数处理一次，即可随时给出当前最大值。

能提前返回吗？在本题给定上界下，发现 1000 与 -1000 配对即可返回 1000，因为不可能有更大合法答案。

若扩展到任意 32 位整数？Java / C++ 对最小负整数取反或取绝对值可能溢出，应先转成更宽类型或处理该边界；当前题目约束没有这个风险。
