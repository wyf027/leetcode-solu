二叉树的 Z 字形层级和

按层交替方向扫描；在每层遇到第一个“不满足子节点条件”的节点前停止，并记录已经纳入的节点和。

题意（准确转述）

给定二叉树根节点。第 1、3、5… 层从左到右扫描；第 2、4、6… 层从右到左扫描。扫描某层时，遇到第一个不满足条件的节点就立刻停止：奇数层要求节点有左孩子，偶数层要求节点有右孩子。只有停止前已扫描的节点计入该层和，返回每层和组成的数组。

示例 1

root = [5, 2, 8, 1, null, 9, 6]

输出 = [5, 8, 0]

null 表示空孩子；数组按层序描述二叉树。

约束：节点数在 1 到 105；节点值在 −105 到 105。层和应使用 64 位整数保存。

题解：BFS 保留层边界，按方向检查

队列保证下一层仍以标准左到右顺序建立。取出一整层后，奇数层正向读取、偶数层逆向读取；每次先检查要求的孩子是否存在，再决定是否把当前节点加入层和。这样“第一个不合法节点不计入”的停机语义不会被误写成“先加后停”。

完整过程

  1. 按层取出节点。
  2. 同时把真实存在的左右孩子入队。
  3. 依层号选择正向或逆向索引。
  4. 遇到缺失指定孩子的节点立即停止。

边界

叶子层必会在第一个节点处停止，故该层和为 0；负值同样直接累加。

复杂度

每个节点至多入、出队一次：时间 O(n)，队列空间 O(n)。

替代方案：双端队列可在偶数层直接从尾部取节点，但会把“遍历方向”和“建下一层顺序”耦合，容易出错。
面试追问：若改成只求一个总和，可在每层处理完成后累加；仍应保留层边界。
常见错误：把停止节点也累加、偶数层仍正向检查、用 int 保存可能达 1010 的层和。 
class Solution { public List<Long> zigzagLevelSum(TreeNode root) { List<Long> ans = new ArrayList<>(); Queue<TreeNode> q = new ArrayDeque<>(); q.offer(root); boolean odd = true; while (!q.isEmpty()) { int n = q.size(); List<TreeNode> a = new ArrayList<>(); for (int i=0;i<n;i++) { TreeNode x=q.poll(); a.add(x); if(x.left!=null) q.offer(x.left); if(x.right!=null) q.offer(x.right); } long s=0; for(int k=0;k<n;k++){ TreeNode x=a.get(odd?k:n-1-k); if(odd?x.left==null:x.right==null) break; s+=x.val; } ans.add(s); odd=!odd; } return ans; } }

from collections import deque
class Solution:
    def zigzagLevelSum(self, root):
        ans, q, odd = [], deque([root]), True
        while q:
            layer = []
            for _ in range(len(q)):
                x = q.popleft(); layer.append(x)
                if x.left: q.append(x.left)
                if x.right: q.append(x.right)
            s = 0
            for k in range(len(layer)):
                x = layer[k] if odd else layer[-1-k]
                if (odd and not x.left) or (not odd and not x.right): break
                s += x.val
            ans.append(s); odd = not odd
        return ans
