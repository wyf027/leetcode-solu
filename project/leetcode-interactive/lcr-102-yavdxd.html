题意

给定非负整数数组 nums 和整数 target，为每个数添加 + 或 -，求表达式结果等于 target 的不同方式数。

示例：nums=[1,1,1,1,1]，target=3，输出 5。约束：1≤nums.length≤20，0≤nums[i]≤1000。

分步互动

第 1 步：每个数字有加或减两种选择。

洞察

设正号数字和为 P，总和为 S，则 P=(S+target)/2；问题转为子集和计数。过程：检查奇偶与范围→一维 DP 倒序更新→返回 dp[P]。边界：target 超过总和、奇偶不符、0 的双倍计数。复杂度 O(nS)，空间 O(S)。替代：回溯。追问：为何必须倒序？错误：正序重复使用元素、忽略 0、未处理负目标。
