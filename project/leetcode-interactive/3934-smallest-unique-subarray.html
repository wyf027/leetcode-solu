最短唯一子数组

找一个最短连续片段，使它不与数组中任何其他同长度片段的元素序列完全相同。

固定长度后，用双哈希把所有窗口分组；存在频次为 1 的指纹时，这个长度可行。

主线解法

二分最小可行长度。check(len) 线性统计该长度的双滚动哈希。

时间
O(n log n)
额外空间
O(n)

题意与示例

给定整数数组 nums，返回存在一个只出现一次的连续子数组的最小长度。两段子数组仅在长度和每个对应元素都相同时才相同。

  • nums = [3, 3, 3]：长度 1、2 都重复；完整数组唯一，输出 3。
  • nums = [2, 1, 2, 3, 3]：[1] 唯一，输出 1。
  • 约束：1 <= nums.length <= 100000，1 <= nums[i] <= 100000。

题解：二分长度，双哈希分组

核心洞察

“存在唯一窗口”对长度单调：长度 L 的唯一窗口扩展一个元素后仍唯一；否则两个相等的扩展窗口会包含两个相等的 L 窗口。因此可二分答案。

完整过程

  1. 预处理两组多项式前缀哈希和幂。
  2. 枚举每个候选长度的窗口，O(1) 取二元哈希并统计频次。
  3. 有频次 1 的键则缩小右界，否则增大左界。

边界、复杂度与替代方案

长度 1 被检查，长度 n 总可行。双模使碰撞风险极低；需要完全确定性时可用后缀数组与 LCP。复杂度 O(n log n)，空间 O(n)。

面试追问与常见错误

常见错误是未证明二分单调性、只用单哈希、或在 JavaScript 中不用 BigInt 导致精度丢失。
