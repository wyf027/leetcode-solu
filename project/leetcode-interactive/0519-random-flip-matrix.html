随机翻转矩阵

Random Flip Matrix · 用稀疏映射完成一次随机调用的虚拟 Fisher–Yates 抽样

哈希表数学随机化水塘抽样

题目

一个 m × n 二元矩阵初始全为 0。每次 flip() 必须在仍为 0 的格子中等概率随机选择一个坐标，将其翻为 1 并返回。reset() 将所有格子恢复为 0。目标是减少内置随机函数调用，并优化时间与空间。

接口：Solution(int m, int n)、int[] flip()、void reset()

约束

  • 1 ≤ m, n ≤ 10⁴
  • 每次调用 flip() 时至少还有一个 0。
  • flip 与 reset 合计最多调用 1000 次。

官方示例（随机输出之一）

输入 ["Solution", "flip", "flip", "flip", "reset", "flip"] [[3, 1], [], [], [], [], []] 输出 [null, [1, 0], [2, 0], [0, 0], null, [2, 0]]

输出坐标具有随机性；示例只是合法结果之一。前三次恰好取完 3×1 的所有格子；重置后它们重新可选。

亲手运行：虚拟数组的尾部交换

实验台会按所选测试用例装载矩阵与调用序列。每一步选取当前区间中的一个位置，并把它映射到尾部代表的值；真实算法的随机位置会变化，机制完全相同。

剩余虚拟区间

哈希表只记录“与身份映射不同”的位置；无需创建包含 m×n 个元素的真实数组。

题解：稀疏 Fisher–Yates

核心洞察

把二维坐标压成一维编号 x = i × n + j。设 remain 为尚未抽取的数量，随机选 r ∈ [0, remain)；返回虚拟数组位置 r 当前代表的值，然后用末尾位置 remain-1 的值覆盖 r。只需一次随机调用。

完整过程

  1. 初始虚拟数组为身份映射：位置 k 存值 k，但不实际分配它。
  2. flip() 随机生成 r，令 picked = map.getOrDefault(r,r)。
  3. 先令 remain 减一，再令 map[r] = map.getOrDefault(remain,remain)。
  4. 将 picked 解码为 [picked / n, picked % n]。
  5. reset() 清空映射并恢复 remain。

正确性

不变式：每次调用前，虚拟区间 [0, remain) 恰好一一对应所有未翻转格子。随机 r 因而等概率选中其中一个。将末尾元素移到 r 后，删除末尾，仍保持一一对应，故不变式归纳成立；返回值不会重复且始终均匀。

边界与复杂度

  • 1×1：唯一编号为 0；抽取后 remain 为 0。
  • 大矩阵：总格数最多 10⁸，仍在 32 位有符号整数内；JavaScript 数值也可精确表示。
  • 每次 flip 期望时间 O(1)，一次随机调用；reset 为 O(1)（清空表）。空间 O(k)，k 为重置后 flip 次数。

替代方案

显式数组后洗牌需 O(mn) 空间；拒绝采样在矩阵接近满时会严重退化；有序集合可做但每次通常 O(log k)。稀疏映射最贴合本题调用次数与大矩阵约束。

面试追问

  • 如何证明每个剩余格子概率相同？回答虚拟数组不变式。
  • 为何删除末尾映射不是必需的？它已落在有效区间之外，不再访问；也可删除以控制常数。
  • 多线程如何处理？需锁住随机选择、remain 与映射更新这一原子过程。

常见错误

  • 先更新 remain 后取错尾部编号。
  • 只记录已选集合并不断重试，导致后期退化。
  • 把 map 中不存在误认为值为 0；不存在代表身份映射。
  • reset 只恢复计数却忘记清空映射。

import java.util.*;
class Solution {
    private final int rows, cols, total;
    private int remain;
    private final Map<Integer, Integer> map = new HashMap<>();
    private final Random random = new Random();
    public Solution(int m, int n) { rows=m; cols=n; total=m*n; remain=total; }
    public int[] flip() {
        int r=random.nextInt(remain--);
        int picked=map.getOrDefault(r,r);
        map.put(r,map.getOrDefault(remain,remain));
        map.remove(remain);
        return new int[]{picked/cols,picked%cols};
    }
    public void reset() { remain=total; map.clear(); }
}
var Solution = function(m, n) {
  this.cols=n; this.total=m*n; this.remain=this.total; this.map=new Map();
};
Solution.prototype.flip = function() {
  const r=Math.floor(Math.random()*this.remain); this.remain--;
  const picked=this.map.has(r)?this.map.get(r):r;
  const tail=this.map.has(this.remain)?this.map.get(this.remain):this.remain;
  this.map.set(r,tail); this.map.delete(this.remain);
  return [Math.floor(picked/this.cols),picked%this.cols];
};
Solution.prototype.reset = function() { this.remain=this.total; this.map.clear(); };
