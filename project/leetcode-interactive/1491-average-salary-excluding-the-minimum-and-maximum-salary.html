去掉最低工资和最高工资后的工资平均值

先读题、观察数据，再亲手推进扫描过程。题解收在页面底部，准备好时再展开。

Problem

题目描述

给定一个由互不相同的整数组成的数组 salary，其中 salary[i] 表示第 i 位员工的工资。

返回去掉最低工资和最高工资后，剩余员工工资的平均值。结果与真实值的误差不超过 10⁻⁵ 即可。

约束

  • 3 ≤ salary.length ≤ 100
  • 1000 ≤ salary[i] ≤ 10⁶
  • salary[i] 两两不同
示例 1

输入：salary = [4000,3000,1000,2000]

输出：2500.00000

最低值是 1000，最高值是 4000；剩余 2000 与 3000 的平均值为 2500。

示例 2

输入：salary = [1000,2000,3000]

输出：2000.00000

去掉 1000 和 3000 后只剩 2000，其平均值仍为 2000。

示例 3

输入：salary = [6000,5000,4000,3000,2000,1000]

输出：3500.00000

示例 4

输入：salary = [8000,9000,2000,3000,6000,1000]

输出：4750.00000

Solution

一次扫描，同时维护三个量

核心洞察

最终需要的是“除去两个极值后的总和”。扫描数组时同时累计所有工资的总和，并维护最低工资与最高工资，就不必排序。

关键公式

(sum − minimum − maximum) / (n − 2)

完整过程

  1. 令总和为 0，最低值为正无穷，最高值为负无穷。
  2. 逐个遍历 salary：把当前工资加入总和，并更新最低值和最高值。
  3. 扫描结束后，从总和里减去最低值和最高值。
  4. 剩余员工数是 salary.length - 2；执行浮点除法并返回结果。

正确性证明

遍历完成后，sum 等于数组所有元素之和，minimum 与 maximum 分别等于唯一的最低工资和最高工资。因此 sum - minimum - maximum 恰好是所有应保留工资之和。数组共有 n 个元素，排除两个极值后恰有 n - 2 个元素；二者相除即为题目要求的平均值。

边界条件

  • 长度为 3：排除两端后只剩一个值，答案就是该值。
  • 顺序任意：极值可能位于数组任意位置，扫描方案不依赖顺序。
  • 浮点精度：除法前转为浮点类型，避免整数截断。
  • 值互不相同：最低值和最高值各只排除一次。

时间复杂度

O(n)：每个工资只访问一次。

空间复杂度

O(1)：只维护总和、最低值和最高值。

四语言完整代码

Java
class Solution {
    public double average(int[] salary) {
        int sum = 0;
        int minimum = Integer.MAX_VALUE;
        int maximum = Integer.MIN_VALUE;

        for (int value : salary) {
            sum += value;
            minimum = Math.min(minimum, value);
            maximum = Math.max(maximum, value);
        }

        return (double) (sum - minimum - maximum)
                / (salary.length - 2);
    }
}

C++
class Solution {
public:
    double average(vector<int>& salary) {
        int sum = 0;
        int minimum = INT_MAX;
        int maximum = INT_MIN;

        for (int value : salary) {
            sum += value;
            minimum = min(minimum, value);
            maximum = max(maximum, value);
        }

        return static_cast<double>(sum - minimum - maximum)
            / (salary.size() - 2);
    }
};

替代方案：排序

先按升序排序，再累加下标 1 到 n - 2 的元素，逻辑直观，但时间复杂度为 O(n log n)，还可能修改原数组。

常见错误

  • 分母误写为 n，而不是 n - 2。
  • 在 Java/C++ 中先做整数除法，导致小数部分被截断。
  • 只从总和中减去一个极值，或把数组端点误认为数值极值。
  • 用固定的 0 初始化最低值，导致所有正工资都无法更新它。

面试追问

  • 如果允许重复工资怎么办？若仍要求只删除一个最小元素和一个最大元素，公式不变；若要求删除所有极值，则还需统计极值出现次数。
  • 如果数据以流的形式到达？继续维护计数、总和、最小值和最大值即可，结束时仍能在 O(1) 额外空间内求解。
  • 如何规避超大输入的溢出？把累计总和提升为更宽的整数类型，例如 Java 的 long 或 C++ 的 long long。
  • 能否推广为去掉最低与最高的 k 个？可排序后截取，或使用两个大小为 k 的堆，在 O(n log k) 时间内维护两端元素。
