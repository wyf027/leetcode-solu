最长单词

把候选词送上排版轨道：观察哪些刻度能够被词库里的字块准确抵达。

01 · Brief

题意

字典树 · 数组 · 哈希表 · 字符串

给定单词数组 words， 找出其中最长、且能完全由数组中的其他单词拼成的单词。若多个答案长度相同，返回字典序最小者； 若不存在，返回空字符串。

“其他单词”是关键：

检查某个候选词时，不能把它自己直接当作一整块使用。

官方示例

输入
words = ["cat", "banana", "dog", "nana", "walk", "walker", "dogwalker"]
输出
"dogwalker"
解释
"dogwalker" 可以由 "dog" 与 "walker" 拼成。

数组长度

0 ≤ words.length ≤ 200

单词长度

1 ≤ words[i].length ≤ 100

可见空格约定

若输入含空格，以 ␠ 显示；本题单词无空格。

04 · Sealed notes

题解

核心思路、完整过程与代码默认封存，按需展开。

Core insight

核心洞察：排序定答案，动态规划验拼装

1. 先把候选顺序排对

按长度降序、字典序升序排列。这样第一个能够拼成的候选就是题目要求的唯一答案。

2. 检查时先移除候选本身

用哈希集合存词库；临时移除候选，避免它用自己一整块“证明”自己。

对候选词 word，令 dp[i] 表示前 i 个字符能否由词库拼成。 从所有已可达位置尝试下一块单词；若最终 dp[word.length] 为真，则候选有效。

Walkthrough

完整过程

  1. 1复制并排序单词：长度更长优先；同长度时字典序更小优先。
  2. 2把所有单词放入哈希集合。轮到候选 dogwalker 时先将它移除。
  3. 3初始化 dp[0] = true。发现前缀 dog 在词库中，于是 dp[3] = true。
  4. 4从可达位置 3 继续，后缀 walker 在词库中，于是 dp[9] = true。
  5. 5恢复候选到集合；因为末尾可达，立即返回 dogwalker。

边界情况

  • • 空数组：直接返回 ""。
  • • 没有任何词能由其他词拼成：返回 ""。
  • • 同长答案：排序规则保证返回字典序最小者。
  • • 多段或重复使用词块：动态规划都能覆盖。
  • • 候选自身：必须临时从集合移除。

复杂度

时间
排序为 O(n log n)；共有 O(n · L²) 次区间探测。计入子串创建与哈希的字符成本，当前实现严格最坏为 O(n · L³)。
空间
哈希集合保存全部字符，另需 O(L) 的 DP 数组；总体 O(Σ|word| + L)。

替代方案取舍

记忆化 DFS：表达自然，也能避免重复子问题；但递归栈和字符串切片更易写错。

Trie + DFS：可沿字符逐步匹配并减少哈希切片，适合更大数据；本题规模下实现成本偏高。

推荐主线：排序 + 哈希集合 + DP，代码短、边界清楚，面试中最稳妥。

面试追问

  • 问：为什么找到第一个就能返回？
    答：候选已按题目优先级排好。
  • 问：怎样禁止候选使用自己？
    答：检查前从集合移除，检查后恢复。
  • 问：若单词长度达到数万？
    答：考虑 Trie、索引视图或滚动哈希，减少子串创建。

常见错误

排序方向写反

同长度必须字典序升序，否则可能返回较大的词。

候选未移除

任何单词都会把自己当作整块，导致错误通过。

只尝试两段

答案可能由三段或更多单词组成，必须覆盖所有分割。

忘记恢复集合

会影响后续候选的检查结果。

空数组越界

不要默认至少存在一个候选。

复杂度描述失真

切片与哈希并非绝对 O(1)，应说明按字符处理的影响。

import java.util.*;

class Solution {
    public String longestWord(String[] words) {
        List<String> candidates = new ArrayList<>(Arrays.asList(words));
        candidates.sort((a, b) -> {
            if (a.length() != b.length()) {
                return Integer.compare(b.length(), a.length());
            }
            return a.compareTo(b);
        });

        Set<String> dictionary = new HashSet<>(Arrays.asList(words));
        for (String word : candidates) {
            dictionary.remove(word);
            if (canBuild(word, dictionary)) {
                return word;
            }
            dictionary.add(word);
        }
        return "";
    }

    private boolean canBuild(String word, Set<String> dictionary) {
        boolean[] dp = new boolean[word.length() + 1];
        dp[0] = true;

        for (int end = 1; end <= word.length(); end++) {
            for (int start = 0; start < end; start++) {
                if (dp[start] && dictionary.contains(word.substring(start, end))) {
                    dp[end] = true;
                    break;
                }
            }
        }
        return dp[word.length()];
    }
}

var longestWord = function (words) {
    const candidates = [...words].sort(
        (a, b) => b.length - a.length || a.localeCompare(b),
    );
    const dictionary = new Set(words);

    for (const word of candidates) {
        dictionary.delete(word);
        const dp = new Array(word.length + 1).fill(false);
        dp[0] = true;

        for (let end = 1; end <= word.length; end++) {
            for (let start = 0; start < end; start++) {
                if (dp[start] && dictionary.has(word.slice(start, end))) {
                    dp[end] = true;
                    break;
                }
            }
        }

        dictionary.add(word);
        if (dp[word.length]) return word;
    }
    return "";
};

class Solution:
    def longestWord(self, words: List[str]) -> str:
        candidates = sorted(words, key=lambda word: (-len(word), word))
        dictionary = set(words)

        for word in candidates:
            dictionary.remove(word)
            dp = [False] * (len(word) + 1)
            dp[0] = True

            for end in range(1, len(word) + 1):
                for start in range(end):
                    if dp[start] and word[start:end] in dictionary:
                        dp[end] = True
                        break

            dictionary.add(word)
            if dp[-1]:
                return word

        return ""
class Solution {
public:
    string longestWord(vector<string>& words) {
        vector<string> candidates = words;
        sort(candidates.begin(), candidates.end(),
             [](const string& a, const string& b) {
                 if (a.size() != b.size()) return a.size() > b.size();
                 return a < b;
             });

        unordered_set<string> dictionary(words.begin(), words.end());

        for (const string& word : candidates) {
            dictionary.erase(word);
            vector<bool> dp(word.size() + 1, false);
            dp[0] = true;

            for (int end = 1; end <= static_cast<int>(word.size()); ++end) {
                for (int start = 0; start < end; ++start) {
                    if (dp[start] &&
                        dictionary.count(word.substr(start, end - start))) {
                        dp[end] = true;
                        break;
                    }
                }
            }

            dictionary.insert(word);
            if (dp[word.size()]) return word;
        }
        return "";
    }
};
