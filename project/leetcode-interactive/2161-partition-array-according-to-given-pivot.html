根据给定数字划分数组

Partition Array According to Given Pivot

一条数组，三个大小区间。重新安排位置时，还要让同一侧的元素保持原来的先后关系。

数组相对顺序非付费题

先读题并预测结果，再操作演示。完整题解在页面底部，默认折叠。

01 / 题目要求

给定下标从 0 开始的整数数组 nums 和整数 pivot，返回一个重新排列后的数组，满足：

  • 所有小于 pivot 的元素放在左侧。
  • 所有等于 pivot 的元素位于中间。
  • 所有大于 pivot 的元素放在右侧。
  • 原本都小于 pivot 的两个元素，或原本都大于 pivot 的两个元素，先后顺序必须保留。即原下标 i < j 时，它们的新下标仍满足 pᵢ < pⱼ。

要求的是按与 pivot 的关系分区，并没有要求每个区间内部按数值递增。

官方示例 1

输入：nums = [9,12,5,10,14,3,10], pivot = 10
输出：[9,5,3,10,10,12,14]

左侧保留 9 → 5 → 3；右侧保留 12 → 14；两个 10 位于中间。

官方示例 2

输入：nums = [-3,4,3,2], pivot = 2
输出：[-3,2,4,3]

−3 在左，2 在中，4 和 3 在右；4 必须仍然在 3 前面。

约束与接口

  • 1 ≤ nums.length ≤ 10⁵
  • −10⁶ ≤ nums[i] ≤ 10⁶
  • pivot 必须是 nums 中出现过的一个元素。
pivotArray(nums: integer[], pivot: integer) → integer[]

04 / 独立题解

想清楚“相对顺序”之后，再展开。

核心洞察：分类时只向队尾追加

为小于、等于、大于 pivot 的元素分别准备一个列表。按原数组从左到右读取，每个元素进入对应列表的末尾；最后把三个列表顺次连接。列表内部的到达顺序就是原始顺序，因此稳定性自然成立。

完整过程

  1. 初始化三个空列表 less、equal、greater。
  2. 依次读取每个元素 x：x < pivot 进入 less，x = pivot 进入 equal，其余进入 greater。
  3. 示例 1 中：9 → less；12 → greater；5 → less；10 → equal；14 → greater；3 → less；最后的 10 → equal。
  4. 扫描后得到 less = [9,5,3]，equal = [10,10]，greater = [12,14]。
  5. 连接得到 [9,5,3,10,10,12,14]，并返回。

正确性证明

循环不变量：处理前 k 个元素后，每个列表恰好包含此前缀中属于该类的全部元素，且顺序与原数组一致。k = 0 时列表为空，性质成立。处理第 k 个下标的元素时，互斥且完备的比较将它恰好追加到一个列表的末尾；已有元素不移动，因此归类、完整性和顺序都被保留。扫描结束时所有元素被保留一次。按 less、equal、greater 连接后，三个区间的大小关系符合要求，同类元素的顺序也未改变，结果正确。

边界与复杂度

n = 1、全部等于 pivot、左侧或右侧为空都直接由空列表拼接处理。负数和重复元素只做比较，无需特殊分支。题目保证 pivot 存在，因此 equal 非空；也不要求修改原数组。

扫描和连接各需要 O(n) 时间，总时间 O(n)。三个列表合计保存 n 个元素，结果也最多保存 n 个元素，总额外空间 O(n)；即使不计返回数组，中间列表仍需 O(n) 空间。

四语言完整代码

均使用官方 pivotArray 接口与三列表方案；代码仅提供，待补执行验证。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] pivotArray(int[] nums, int pivot) {
        List<Integer> less = new ArrayList<>();
        List<Integer> equal = new ArrayList<>();
        List<Integer> greater = new ArrayList<>();
        for (int x : nums) {
            if (x < pivot) less.add(x);
            else if (x == pivot) equal.add(x);
            else greater.add(x);
        }
        int[] result = new int[nums.length];
        int i = 0;
        for (int x : less) result[i++] = x;
        for (int x : equal) result[i++] = x;
        for (int x : greater) result[i++] = x;
        return result;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @param {number} pivot
 * @return {number[]}
 */
var pivotArray = function(nums, pivot) {
    const less = [], equal = [], greater = [];
    for (const x of nums) {
        if (x < pivot) less.push(x);
        else if (x === pivot) equal.push(x);
        else greater.push(x);
    }
    return less.concat(equal, greater);
};

C++

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> pivotArray(vector<int>& nums, int pivot) {
        vector<int> less, equal, greater;
        for (int x : nums) {
            if (x < pivot) less.push_back(x);
            else if (x == pivot) equal.push_back(x);
            else greater.push_back(x);
        }
        vector<int> result;
        result.reserve(nums.size());
        result.insert(result.end(), less.begin(), less.end());
        result.insert(result.end(), equal.begin(), equal.end());
        result.insert(result.end(), greater.begin(), greater.end());
        return result;
    }
};

替代方案

  • 三次顺序扫描：依次只输出小于、等于、大于 pivot 的元素。仍为 O(n) 时间，只保存返回数组；不计输出时辅助空间可降为 O(1)。常数次重复扫描往往比多个中间列表更省内存。
  • 先计数再定位写入：统计小于和等于的数量，确定三段起点；第二遍从左到右将每个元素写到所属区间的下一个空位。O(n) 时间、O(n) 输出空间，且稳定。
  • 按类别稳定排序：用小于、等于、大于映射成 0、1、2 后稳定排序也可行，但通常需要 O(n log n) 时间；直接按数值排序会破坏题目要求。

面试追问

  • 为什么普通双指针交换不够？交换可能让同侧元素越过彼此。荷兰国旗分区能分成三段，但通常不稳定。
  • 相等元素也需要保序吗？题目只显式约束小于和大于两组；相等整数不可区分。本方案按原下标追踪时连相等组也保序。
  • 能否原地且稳定？可以用移动/旋转元素的办法保持稳定，但简单插入实现最坏 O(n²)；同时追求线性时间和极少额外空间需要更复杂的稳定分区技术，本题没有要求。
  • 如何减少列表内存？采用三次扫描，只构造一个结果数组。输出空间 O(n)，额外辅助空间 O(1)。

常见错误

  • 对 nums 做升序排序：示例 2 的右侧会变为 [3,4]，违反原顺序。
  • 用集合去重：相同元素的出现次数必须保留。
  • 从右端收集 greater 后直接拼接：会反转右侧顺序，应反转回来或从左到右追加。
  • 边遍历原数组边插入/删除：容易跳过元素，还可能把时间复杂度推到 O(n²)。
  • JavaScript 用 push(...hugeArray) 拼接大数组：可能触发参数数量限制；这里使用 concat。
  • 把三个中间列表的空间忽略，宣称辅助空间 O(1)：当前四份实现的额外空间都是 O(n)。
