同源字符串检测

Check if an Original String Exists Given Two Encoded Strings

两份不同的编码，能否指向同一个原字符串？

打开官方题目 ↗

01 / 题目

一个只含小写英文字母的原字符串，可以先切成若干非空连续片段，再任选其中一些片段替换为其长度的十进制表示，最后按原顺序拼接。也可以不替换任何片段。

例如，将 abcdefghijklmnop 切成 ab / cdefghijklmn / o / p，把中间两段替换为 12 和 1，可以得到 ab121p。

给定编码字符串 s1 和 s2，判断是否存在至少一个原字符串能分别编码为二者。存在返回 true，否则返回 false。

possiblyEquals(s1: string, s2: string) → boolean
  • 1 ≤ s1.length, s2.length ≤ 40。
  • 只包含小写英文字母和数字 1–9，不包含 0。
  • 每个字符串中连续数字的数量最多为 3。

先独立思考：连续数字在拼接后没有分隔符。页面底部可展开交互推演及完整题解。

04 / 独立题解

准备好之后，再展开长度差推演和四种语言实现。

用长度差连接两条编码带

数字代表一段任意字母，只要求长度，不要求具体内容。连续数字必须枚举切分：123 可以表示 123、1+23、12+3、1+2+3。不要真的展开通配字符。

核心状态

dfs(i, j, d) 表示两个编码前缀已经兼容，接下来从下标 i、j 继续；d 为 s1 已解析长度减去 s2 已解析长度。d > 0 表示 s1 还有 d 个未抵消通配位置，d < 0 表示 s2 还有 −d 个。长度相等时 d = 0。

交互 / 长度差天平

预设状态推演，非运行记录。选择成功或失败的数字切分，观察指针与剩余通配位置；完整搜索会继续尝试其他分支。

S1 / i
S2 / j
s2 剩余通配0s1 剩余通配

刻度显示方向，距离按当前路径最大 |d| 归一化；数值以状态文字为准。

完整转移过程

  1. 从 (0, 0, 0) 开始。两个指针均到末尾时，仅 d = 0 才成功。
  2. d ≤ 0 时，若 s1[i] 是数字，逐个枚举数字前缀值 v，转移到 (k+1, j, d+v)。每种前缀都代表一个可能的分段，后续递归继续解释剩余数字。
  3. d ≥ 0 时，对 s2 的数字前缀同理枚举，转移到 (i, k+1, d−v)。
  4. d < 0 时用 s1 当前字母消耗一个 s2 通配位置：i+1、d+1。d > 0 时用 s2 当前字母消耗一个 s1 通配位置：j+1、d−1。
  5. d = 0 时，只有两个当前字符都是相同字母，才能同时前进。字母不同则该分支失败。
  6. 任一后继成功即可返回 true；全部失败后缓存 (i,j,d)，避免重复搜索。Python 使用标准库缓存全部返回值，其余版本记录失败状态。

为什么可以只解析落后一侧的数字？

领先侧尚有未匹配的通配位置时，它后面的数字或字母尚未参与对齐，可以延后读取。先推进落后侧即可保持相同的相对位置。d = 0 时允许两侧的数字分支，因此不会漏掉任何合法切分；同时避免领先侧无意义地持续累加长度。

正确性

不变式：每个可达状态的已对齐部分都兼容，尚未对齐的领先部分只包含任意字母占位，数量由 |d| 描述。解析数字只追加任意占位，字母抵消只给其中一个位置赋值；平衡时比较字母保证固定字符一致，故所有转移均保持不变式。

完备性：对于任意共同原串及其两份分段方案，数字前缀枚举必然包含其下一段长度。优先读取落后侧只是调整读取顺序，不改变字符对齐。沿这些选择必能重现该原串的匹配过程。

终止与结论：每次递归至少增加 i 或 j，所以无环并必定终止。当二者都结束且 d = 0 时，所有固定字母相容且总长度相同，通配位置可以选择满足约束的小写字母，故存在共同原串。反之，若所有转移失败，则不存在这样的分段与匹配。

复杂度

令 n、m 为编码长度，L 为最大连续数字数（本题为 3），B = 10ᴸ − 1 = 999。因为只允许落后一侧解析数字，始终有 −B ≤ d ≤ B。状态数 O(nmB)，每个状态最多枚举两侧各 L 个数字前缀，时间 O(nmBL)，缓存空间 O(nmB)，递归栈 O(n+m)。对固定 L=3 可写为 O(nmB) 时间。字符串状态键的长度在题目界限内有固定上界。

边界与常见错误

  • 把 123 只读成 123 会漏掉 1+2+3 等分段。
  • 纯数字编码也合法；相同总长度即可兼容。
  • 只比较解码总长度会忽略固定字母的位置与冲突。
  • 一个指针结束后，另一侧仍可能用字母消耗通配位置，不应立即失败。
  • 仅 d = 0 不够，还必须两个指针均到末尾。
  • 缓存键必须包含 d，且符号转移需统一；s1 数字加、s2 数字减。
  • 本题无 0 且连续数字最多 3 位；若取消条件，数字边界和复杂度必须重新分析。

替代方案

可用迭代 DP，让 dp[i][j] 保存可达长度差集合。转移机制相同，避免递归但通常保留更多状态。也可以先预处理每段数字的所有切分总长度再搜索，减少重复解析但增加预处理代码。直接枚举原字符串会因通配字母和长度爆炸而不可行。

面试追问

  • 如何输出一个共同原串？记录成功路径，重建数字通配段，并用固定字母覆盖对应位置，其余位置填 a。
  • 如何减少状态？可预计算剩余后缀的最小与最大展开长度，用区间无法相交剪枝。
  • 为什么没有显式枚举所有字母？通配位置没有相互关联的取值限制，固定字母一致性由对齐转移局部保证。
  • 连续数字不设上限会怎样？数值上界指数增长，需要重新设计可行长度表示，当前有界长度差方案可能失效。

JavaScript

/**
 * @param {string} s1
 * @param {string} s2
 * @return {boolean}
 */
var possiblyEquals = function(s1, s2) {
    const n = s1.length, m = s2.length;
    const bad = new Set();
    const digit = c => c >= '1' && c <= '9';
    function dfs(i, j, d) {
        if (i === n && j === m) return d === 0;
        const key = `${i},${j},${d}`;
        if (bad.has(key)) return false;
        if (d <= 0) {
            let v = 0;
            for (let k = i; k < n && digit(s1[k]); k++) {
                v = v * 10 + Number(s1[k]);
                if (dfs(k + 1, j, d + v)) return true;
            }
        }
        if (d >= 0) {
            let v = 0;
            for (let k = j; k < m && digit(s2[k]); k++) {
                v = v * 10 + Number(s2[k]);
                if (dfs(i, k + 1, d - v)) return true;
            }
        }
        if (d < 0 && i < n && !digit(s1[i]) &&
            dfs(i + 1, j, d + 1)) return true;
        if (d > 0 && j < m && !digit(s2[j]) &&
            dfs(i, j + 1, d - 1)) return true;
        if (d === 0 && i < n && j < m &&
            !digit(s1[i]) && !digit(s2[j]) && s1[i] === s2[j] &&
            dfs(i + 1, j + 1, 0)) return true;
        bad.add(key);
        return false;
    }
    return dfs(0, 0, 0);
};

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    private String a, b;
    private final Set<String> bad = new HashSet<>();
    private boolean digit(char c) { return c >= '1' && c <= '9'; }

    public boolean possiblyEquals(String s1, String s2) {
        a = s1; b = s2;
        bad.clear();
        return dfs(0, 0, 0);
    }
    private boolean dfs(int i, int j, int d) {
        if (i == a.length() && j == b.length()) return d == 0;
        String key = i + "," + j + "," + d;
        if (bad.contains(key)) return false;
        if (d <= 0) {
            int v = 0;
            for (int k = i; k < a.length() && digit(a.charAt(k)); k++) {
                v = v * 10 + a.charAt(k) - '0';
                if (dfs(k + 1, j, d + v)) return true;
            }
        }
        if (d >= 0) {
            int v = 0;
            for (int k = j; k < b.length() && digit(b.charAt(k)); k++) {
                v = v * 10 + b.charAt(k) - '0';
                if (dfs(i, k + 1, d - v)) return true;
            }
        }
        if (d < 0 && i < a.length() && !digit(a.charAt(i)) &&
            dfs(i + 1, j, d + 1)) return true;
        if (d > 0 && j < b.length() && !digit(b.charAt(j)) &&
            dfs(i, j + 1, d - 1)) return true;
        if (d == 0 && i < a.length() && j < b.length() &&
            !digit(a.charAt(i)) && !digit(b.charAt(j)) &&
            a.charAt(i) == b.charAt(j) && dfs(i + 1, j + 1, 0)) return true;
        bad.add(key);
        return false;
    }
}

Python（Python 3）

from functools import lru_cache

class Solution:
    def possiblyEquals(self, s1: str, s2: str) -> bool:
        n, m = len(s1), len(s2)
        def digit(c):
            return '1' <= c <= '9'

        @lru_cache(None)
        def dfs(i, j, d):
            if i == n and j == m:
                return d == 0
            if d <= 0:
                v, k = 0, i
                while k < n and digit(s1[k]):
                    v = v * 10 + int(s1[k])
                    if dfs(k + 1, j, d + v):
                        return True
                    k += 1
            if d >= 0:
                v, k = 0, j
                while k < m and digit(s2[k]):
                    v = v * 10 + int(s2[k])
                    if dfs(i, k + 1, d - v):
                        return True
                    k += 1
            if d < 0 and i < n and not digit(s1[i]):
                if dfs(i + 1, j, d + 1):
                    return True
            if d > 0 and j < m and not digit(s2[j]):
                if dfs(i, j + 1, d - 1):
                    return True
            if (d == 0 and i < n and j < m and
                not digit(s1[i]) and not digit(s2[j]) and s1[i] == s2[j]):
                if dfs(i + 1, j + 1, 0):
                    return True
            return False

        return dfs(0, 0, 0)

#include <string>
#include <unordered_set>
using namespace std;

class Solution {
    string a, b;
    unordered_set<string> bad;
    bool digit(char c) { return c >= '1' && c <= '9'; }
    bool dfs(int i, int j, int d) {
        if (i == (int)a.size() && j == (int)b.size()) return d == 0;
        string key = to_string(i) + "," + to_string(j) + "," + to_string(d);
        if (bad.count(key)) return false;
        if (d <= 0) {
            int v = 0;
            for (int k = i; k < (int)a.size() && digit(a[k]); ++k) {
                v = v * 10 + a[k] - '0';
                if (dfs(k + 1, j, d + v)) return true;
            }
        }
        if (d >= 0) {
            int v = 0;
            for (int k = j; k < (int)b.size() && digit(b[k]); ++k) {
                v = v * 10 + b[k] - '0';
                if (dfs(i, k + 1, d - v)) return true;
            }
        }
        if (d < 0 && i < (int)a.size() && !digit(a[i]) &&
            dfs(i + 1, j, d + 1)) return true;
        if (d > 0 && j < (int)b.size() && !digit(b[j]) &&
            dfs(i, j + 1, d - 1)) return true;
        if (d == 0 && i < (int)a.size() && j < (int)b.size() &&
            !digit(a[i]) && !digit(b[j]) && a[i] == b[j] &&
            dfs(i + 1, j + 1, 0)) return true;
        bad.insert(key);
        return false;
    }
public:
    bool possiblyEquals(string s1, string s2) {
        a = s1; b = s2; bad.clear();
        return dfs(0, 0, 0);
    }
};
