最大的团队表现值

Maximum Performance of a Team

困难贪心排序堆（优先队列）数组
团队表现值=速度总和×团队最低效率

Problem

题目说明

有 n 名工程师，第 i 名工程师的速度为 speed[i]，效率为 efficiency[i]。请从中选择至多 k 名不同工程师组成团队，使团队表现值最大。

团队表现值等于团队内所有工程师的速度之和，乘以团队中的最低效率。返回最大表现值对 109 + 7 取余后的结果。

官方示例

01

k = 2

输入：n = 6 speed = [2,10,3,1,5,8] efficiency = [5,4,3,9,7,2] k = 2 输出：60

选择工程师 2 与 5：(10 + 5) × min(4, 7) = 60。

02

k = 3

输入：n = 6 speed = [2,10,3,1,5,8] efficiency = [5,4,3,9,7,2] k = 3 输出：68

选择工程师 1、2、5：(2 + 10 + 5) × min(5, 4, 7) = 68。

03

k = 4

输入：n = 6 speed = [2,10,3,1,5,8] efficiency = [5,4,3,9,7,2] k = 4 输出：72

最多可选 4 人，最优表现值为 72。

函数参数

maxPerformance( n: integer, speed: integer[], efficiency: integer[], k: integer ) → integer

约束

  • 1 ≤ k ≤ n ≤ 105
  • speed.length == n
  • efficiency.length == n
  • 1 ≤ speed[i] ≤ 105
  • 1 ≤ efficiency[i] ≤ 108

Insight

核心洞察

固定团队最低效率后，只需让速度总和尽可能大。将工程师按效率从高到低扫描，当前工程师的效率就是当前候选团队可能采用的最低效率；此前见过的人效率都不低于它。

为了让当前速度和最大，只保留扫描范围内速度最高的至多 k 人。用最小堆保存这些速度：加入新速度后若人数超过 k，弹出最小速度即可。

Procedure

完整过程

  1. 把每位工程师表示为 (efficiency, speed)，按效率降序排列。
  2. 维护一个至多含 k 个速度的最小堆，以及堆中速度之和 speedSum。
  3. 扫描当前工程师：先把其速度入堆并累加；若堆大小超过 k，弹出最小速度并扣除。
  4. 用当前效率作为团队最低效率，计算 speedSum × currentEfficiency 并更新全局最大值。
  5. 扫描结束后才将最大值对 10^9 + 7 取余；比较期间不能提前取模。

Proof

正确性说明

引理 1：扫描到效率 e 时，已扫描工程师的效率均不低于 e。

这是效率降序带来的直接结果。以当前效率为门槛时，已扫描成员都满足门槛；若团队包含当前工程师，其最低效率就是 e。

引理 2：已扫描工程师中，速度最高的至多 k 人具有最大速度和。

若候选团队包含较小速度却遗漏较大速度，交换二者不会降低效率门槛，却会增大速度和。因此最小堆保留的前 k 大速度构成该门槛下的最优候选。

结论

任意全局最优团队都有最低效率。扫描到该效率时，算法已纳入所有可选的更高效率成员，并取得合法人数内最大速度和，因此不会错过该最优值；每次计算又都对应一个合法候选团队，故最终最大值正确。

Analysis

复杂度、边界与替代方案

时间：O(n log n + n log k)
空间：O(n + k)（配对排序计入额外空间）。

边界

  • k = 1：逐人比较 speed × efficiency。
  • k = n：仍可能只选部分人，因为是“至多”。
  • 最大乘积约 10^18，Java/C++ 用 64 位整数，JavaScript 用 BigInt。
  • 只在最终返回时取模。

替代方案

枚举团队需要指数时间；对每个效率门槛重新排序速度会达到 O(n² log n)。有序多重集合也能维护前 k 大速度，但最小堆更直接且复杂度相同。

常见错误

  • 按速度排序，无法安全确定当前最低效率。
  • 堆超出 k 时弹出最大值而非最小值。
  • 只在堆大小等于 k 时计算，漏掉更优的小团队。
  • 比较前取模，破坏候选值的大小关系。
  • JavaScript 用普通 Number 计算乘积，超过安全整数范围。

面试追问

  • 为什么当前效率可以作为最低效率？
  • 为何最小堆中的团队不一定包含当前工程师仍不影响结论？
  • 如果要求“恰好 k 人”，计算时机如何改变？
  • 能否只排序索引以减少配对对象的开销？

四语言完整实现

import java.util.*;

class Solution {
    public int maxPerformance(int n, int[] speed, int[] efficiency, int k) {
        final long MOD = 1_000_000_007L;
        int[][] engineers = new int[n][2];
        for (int i = 0; i < n; i++) {
            engineers[i][0] = efficiency[i];
            engineers[i][1] = speed[i];
        }
        Arrays.sort(engineers, (a, b) -> Integer.compare(b[0], a[0]));

        PriorityQueue<Integer> minHeap = new PriorityQueue<>();
        long speedSum = 0L;
        long best = 0L;
        for (int[] engineer : engineers) {
            int currentEfficiency = engineer[0];
            int currentSpeed = engineer[1];
            minHeap.offer(currentSpeed);
            speedSum += currentSpeed;
            if (minHeap.size() > k) speedSum -= minHeap.poll();
            best = Math.max(best, speedSum * currentEfficiency);
        }
        return (int) (best % MOD);
    }
}
/**
 * @param {number} n
 * @param {number[]} speed
 * @param {number[]} efficiency
 * @param {number} k
 * @return {number}
 */
var maxPerformance = function(n, speed, efficiency, k) {
    const engineers = Array.from(
        { length: n },
        (_, i) => [efficiency[i], speed[i]]
    ).sort((a, b) => b[0] - a[0]);

    const heap = [];
    const push = (value) => {
        heap.push(value);
        let i = heap.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (heap[p] <= heap[i]) break;
            [heap[p], heap[i]] = [heap[i], heap[p]];
            i = p;
        }
    };
    const pop = () => {
        const root = heap[0];
        const last = heap.pop();
        if (heap.length) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let smallest = i;
                const left = i * 2 + 1;
                const right = left + 1;
                if (left < heap.length && heap[left] < heap[smallest]) smallest = left;
                if (right < heap.length && heap[right] < heap[smallest]) smallest = right;
                if (smallest === i) break;
                [heap[i], heap[smallest]] = [heap[smallest], heap[i]];
                i = smallest;
            }
        }
        return root;
    };

    let speedSum = 0n;
    let best = 0n;
    for (const [eff, spd] of engineers) {
        push(spd);
        speedSum += BigInt(spd);
        if (heap.length > k) speedSum -= BigInt(pop());
        const performance = speedSum * BigInt(eff);
        if (performance > best) best = performance;
    }
    return Number(best % 1000000007n);
};
from typing import List
import heapq

class Solution:
    def maxPerformance(
        self,
        n: int,
        speed: List[int],
        efficiency: List[int],
        k: int
    ) -> int:
        engineers = sorted(zip(efficiency, speed), reverse=True)
        min_heap = []
        speed_sum = 0
        best = 0

        for current_efficiency, current_speed in engineers:
            heapq.heappush(min_heap, current_speed)
            speed_sum += current_speed
            if len(min_heap) > k:
                speed_sum -= heapq.heappop(min_heap)
            best = max(best, speed_sum * current_efficiency)

        return best % (10**9 + 7)
class Solution {
public:
    int maxPerformance(int n, vector<int>& speed,
                       vector<int>& efficiency, int k) {
        const long long MOD = 1'000'000'007LL;
        vector<pair<int, int>> engineers;
        engineers.reserve(n);
        for (int i = 0; i < n; ++i) {
            engineers.push_back({efficiency[i], speed[i]});
        }
        sort(engineers.rbegin(), engineers.rend());

        priority_queue<int, vector<int>, greater<int>> minHeap;
        long long speedSum = 0;
        long long best = 0;
        for (const auto& [currentEfficiency, currentSpeed] : engineers) {
            minHeap.push(currentSpeed);
            speedSum += currentSpeed;
            if (static_cast<int>(minHeap.size()) > k) {
                speedSum -= minHeap.top();
                minHeap.pop();
            }
            best = max(best, speedSum * currentEfficiency);
        }
        return static_cast<int>(best % MOD);
    }
};
