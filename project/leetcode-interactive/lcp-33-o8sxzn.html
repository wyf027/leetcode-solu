LCP 33. 蓄水

每个水缸配一个水桶；可把任意水桶容量加一（一次操作），也可同时用所有水桶倒水一次（一次操作）。达到每个水缸目标水量的最少操作数是多少？

LCP 33简单枚举倒水次数

题意

给定 bucket[i] 与 vat[i]。升级水桶一次使容量加一；一次倒水会让每个水缸增加当前水桶容量。水缸只能通过其对应水桶加水，目标是至少达到 vat[i]。

示例

bucket = [1, 3], vat = [6, 8]

输出 = 4

枚举倒水 3 次：第一个桶需要升到 2（1 次），第二个桶维持 3；总操作 1 + 3 = 4。

水缸数量

≤ 100

目标容量

≤ 10000

关键转换

固定总倒水次数为 k 后，水桶 i 至少要有 ceil(vat[i] / k) 的容量。于是升级次数完全确定：max(0, ceil(vat[i]/k) - bucket[i])。

题解：把“倒几次”作为唯一枚举变量

若一次都不需要倒水（所有水缸目标均为零），答案是 0。否则枚举 k = 1..max(vat)。第 i 个水缸在 k 次后得到 k × capacity 水，所以最小所需桶容量是 (vat[i] + k - 1) / k。总成本为 k 加上所有升级量，取最小值。

为什么可行

一旦 k 固定，每个桶需要的最小容量独立确定；多升容量只会增加升级成本，不会带来收益。

复杂度

设 M 为最大目标水量、n 为水缸数，时间 O(Mn)，空间 O(1)（不计输入）。

常见错误

忘记 vat 为 0 的水缸无需升级；将向上取整写成整数除法；或只检查当前桶容量而不尝试更少倒水次数。

替代方案与面试追问

可以先用当前最优解剪枝：若 k 已不小于答案则停止。若目标容量上界很大，可按 ceil(vat/k) 的值分段枚举，但本题 10000 的上界让直接枚举更稳妥。

四语言可提交代码

Java

class Solution {
  public int storeWater(int[] bucket, int[] vat) {
    int max = 0; for (int x : vat) max = Math.max(max, x);
    if (max == 0) return 0;
    int ans = Integer.MAX_VALUE;
    for (int k = 1; k <= max; k++) {
      int cost = k;
      for (int i = 0; i < vat.length; i++) cost += Math.max(0, (vat[i] + k - 1) / k - bucket[i]);
      ans = Math.min(ans, cost);
    }
    return ans;
  }
}

JavaScript

var storeWater = function (bucket, vat) {
  const maxVat = Math.max(...vat);
  if (maxVat === 0) return 0;
  let ans = Infinity;
  for (let k = 1; k <= maxVat; k++) {
    let cost = k;
    for (let i = 0; i < vat.length; i++) cost += Math.max(0, Math.ceil(vat[i] / k) - bucket[i]);
    ans = Math.min(ans, cost);
  }
  return ans;
};

Python

from typing import List
class Solution:
    def storeWater(self, bucket: List[int], vat: List[int]) -> int:
        max_vat = max(vat)
        if max_vat == 0:
            return 0
        ans = float('inf')
        for k in range(1, max_vat + 1):
            cost = k + sum(max(0, (v + k - 1) // k - b) for b, v in zip(bucket, vat))
            ans = min(ans, cost)
        return ans

      ans = min(ans, cost);
    }
