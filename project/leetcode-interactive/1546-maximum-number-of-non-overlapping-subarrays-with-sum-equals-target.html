和为目标值且不重叠的非空子数组的最大数目

Maximum Number of Non-Overlapping Subarrays With Sum Equals Target

给定整数数组 nums 和整数 target，请返回能选出的非空、互不重叠子数组的最大数量，其中每个子数组的元素和都恰好等于 target。

函数签名：maxNonOverlapping(nums, target) → integer

官方示例

示例 1

输入：nums = [1,1,1,1,1], target = 2
输出：2

可以选取前两个 1 与后两个 1，得到两个互不重叠、和为 2 的子数组。

示例 2

输入：nums = [-1,3,5,1,4,2,-9], target = 6
输出：2

和为 6 的候选包括 [5,1]、[4,2] 和较长区间 [3,5,1,4,2,-9]；最多只能选两个互不重叠区间。

示例 3

输入：nums = [-2,6,6,3,5,4,1,2,8], target = 10
输出：3

示例 4

输入：nums = [0,0,0], target = 0
输出：3

约束

  • 1 <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4
  • 0 <= target <= 10^6

题解：前缀和识别 + 最早结束贪心

核心洞察

扫描当前尚未被选中区间的前缀和。若当前前缀和为 sum，此前出现过 sum - target，两者之间的子数组之和就是 target。

一旦找到合法子数组，立刻选择它，并把前缀和集合重置为 {0}。这相当于在它的右端点后切开数组，后续只处理未使用的后缀。

完整过程

  1. 初始化 seen = {0}、sum = 0、answer = 0。
  2. 从左到右读取每个数，把它加到 sum。
  3. 如果 seen 中存在 sum - target，说明在当前段内存在一个以当前位置结尾的目标子数组：答案加一，然后把 sum 清零、把 seen 重置为 {0}。
  4. 否则，把当前 sum 加入 seen，继续扫描。

为什么正确

  1. 识别是准确的。 前缀和之差等于一段连续子数组的和；因此 sum - target 出现过，当且仅当当前段里存在一个以当前下标结尾、和为 target 的非空子数组。
  2. 最早结束不会吃亏。 设扫描时最早发现的合法子数组在位置 r 结束。任何可行最优方案中的第一个子数组都不可能早于 r 结束；用当前子数组替换它后，留给后续选择的后缀只会更长，不会减少后续可选数量。
  3. 切分后问题独立。 选定当前子数组后，所有后续子数组都必须从其右侧开始。重置状态恰好丢弃已占用前缀，并在剩余后缀上重复同一问题。
  4. 归纳得到最优。 每一步都能安全地确定最优方案中的下一个区间；对剩余后缀反复应用，最终得到最大数量。

边界情况

  • target = 0：每个单独的 0 都可以立即形成新区间，例如 [0,0,0] 的答案为 3。
  • 数组含负数：不能使用滑动窗口；前缀和集合仍然有效。
  • 没有合法子数组：扫描结束后答案保持 0。
  • 连续出现多个合法短区间：每次命中即重置，确保它们互不重叠。
  • 数值范围：总前缀和的绝对值可能达到 10^9，Java 使用 long 更稳妥；JavaScript 的 Number 在本题范围内可精确表示整数。

复杂度

时间复杂度为 O(n)：每个元素只处理一次。空间复杂度为 O(n)：在一次重置之前，集合最多保存线性数量的前缀和。

四种语言完整代码

JavaLeetCode 提交
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int maxNonOverlapping(int[] nums, int target) {
        Set<Long> seen = new HashSet<>();
        seen.add(0L);

        long sum = 0L;
        int answer = 0;

        for (int num : nums) {
            sum += num;
            if (seen.contains(sum - target)) {
                answer++;
                sum = 0L;
                seen.clear();
                seen.add(0L);
            } else {
                seen.add(sum);
            }
        }
        return answer;
    }
}

    let sum = 0;

            answer += 1;
            sum = 0;

            seen.add(sum);
        }
    }

    return answer;
};

from typing import List


class Solution:
    def maxNonOverlapping(
        self,
        nums: List[int],
        target: int
    ) -> int:
        answer = 0
        prefix_sum = 0
        seen = {0}

        for num in nums:
            prefix_sum += num

            if prefix_sum - target in seen:
                answer += 1
                prefix_sum = 0
                seen = {0}
            else:
                seen.add(prefix_sum)

        return answer

#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    int maxNonOverlapping(
        vector<int>& nums,
        int target
    ) {
        unordered_set<long long> seen{0};
        long long sum = 0;
        int answer = 0;

        for (int num : nums) {
            sum += num;

            if (seen.count(sum - target)) {
                ++answer;
                sum = 0;
                seen.clear();
                seen.insert(0);
            } else {
                seen.insert(sum);
            }
        }

        return answer;
    }
};

替代方案

  • 前缀和 + 动态规划：可令 dp[i] 表示前 i 个元素的最大答案，并用哈希表记录某前缀和值对应的最佳状态，也能做到 O(n)。它更通用，但状态和证明更复杂。
  • 枚举所有区间后做区间调度：理论上先找出所有和为目标值的区间，再按右端点贪心；但合法区间可能有平方级数量，无法满足 10^5 的规模。
  • 滑动窗口：仅在元素非负等额外条件下可靠。本题允许负数，窗口和不具单调性，因此不能直接使用。

面试追问

  • 为什么“命中后立即切分”与经典的按右端点排序区间调度是同一种贪心？
  • 如果要求返回所有选中区间的下标，应如何把集合改成“前缀和 → 下标”的映射？
  • 如果数组元素全部为正数，能否把方案改为常数额外空间的滑动窗口？
  • 如果不是最大化数量，而是最大化各区间权重之和，贪心还成立吗？应改用什么状态？

常见错误

  • 命中目标后只清空集合，却忘记重新加入 0，导致无法识别从新段起点开始的子数组。
  • 命中后不重置累计和，使后续找到的区间仍可能跨过已选区间，破坏“不重叠”条件。
  • 看到“子数组和”就使用滑动窗口，忽略数组可能包含负数。
  • 先收集所有合法区间再排序，造成最坏 O(n^2) 的时间或空间开销。
  • 把子数组误当成子序列；子数组必须连续。
