Problem

题目

给定一个有效括号字符串 s，返回它的嵌套深度，也就是任意位置同时处于其中的括号层数的最大值。

函数形式：int maxDepth(string s)

输入保证是有效括号字符串；除括号外，还可能含数字与四则运算符。

约束

  • 1 <= s.length <= 100
  • s 仅由数字 0-9、+、-、*、/、(、) 组成。
  • 题目保证括号表达式 s 是有效括号字符串（VPS）。

Official examples

完整示例

s = "(1+(2*3)+((8)/4))+1"

输出 3
s = "(1)+((2))+(((3)))"

数字 3 位于 3 层括号之内。

输出 3
s = "()(())((()()))"
输出 3

Solution

一次扫描，记录水位

核心洞察：把尚未闭合的左括号数量视为当前深度。遇到 ( 时深度加一，并用它更新峰值；遇到 ) 时深度减一；其他字符跳过。

时间复杂度O(n)

每个字符只处理一次。

空间复杂度O(1)

只维护两个整数。

扫描方向→

从左到右，不回头。

完整过程

  1. 初始化当前深度 depth = 0 与最大深度 answer = 0。
  2. 从左到右遍历字符串。遇到左括号，先增加 depth，再更新 answer。
  3. 遇到右括号，将 depth 减一。数字与运算符不会改变嵌套关系，直接略过。
  4. 扫描结束后返回 answer。

边界情况

  • 完全没有括号，例如 "1+2"，答案为 0。
  • 括号并列，例如 "()()"，峰值仍为 1。
  • 连续嵌套，例如 "((()))"，答案等于左括号连续打开的最大层数。
  • 题目保证输入有效，因此扫描中深度不会为负，结束时会回到 0。

正确性证明

不变量：在处理完任意前缀后，depth 等于该前缀中左括号数量减去右括号数量，也就是此刻仍打开的括号数。

初始前缀为空，两者都是 0。不相关字符不改变该值；左括号使打开数量和 depth 同时加一；右括号使两者同时减一，所以不变量始终成立。每当深度可能上升时，算法都用它更新 answer，因此扫描结束后 answer 恰好记录所有位置深度的最大值，即所求最大嵌套深度。

替代方案：显式栈

遇到左括号入栈，遇到右括号出栈，用最大栈长作为答案。它同样是 O(n) 时间，但需要 O(n) 额外空间；由于栈中元素本身没有额外信息，计数器更直接。

常见错误

  • 在处理右括号前更新最大值，逻辑虽可能偶然通过，但状态语义混乱。
  • 把括号总数的一半当作答案；并列括号会立刻反例。
  • 只统计最长连续左括号；括号之间可夹着数字或运算符。

面试追问

若输入不保证有效？

扫描时检测深度是否变负，并在结束时检查是否回到 0。

若有多种括号？

需要栈来校验类型匹配；仅计数不能识别 (]。

能否在线处理字符流？

可以。只需保存当前深度与历史峰值，不必保留整个字符串。

class Solution {
    public int maxDepth(String s) {
        int depth = 0;
        int answer = 0;

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == '(') {
                depth++;
                answer = Math.max(answer, depth);
            } else if (ch == ')') {
                depth--;
            }
        }
        return answer;
    }
}
