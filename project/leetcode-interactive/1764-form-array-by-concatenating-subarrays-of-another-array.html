通过连接另一个数组的子数组得到一个数组

Problem

题意

给定长度为 n 的二维整数数组 groups 和整数数组 nums。请判断能否从 nums 中选出 n 个互不相交的连续子数组，使第 i 个子数组恰好等于 groups[i]，并且它们在 nums 中出现的先后顺序与 groups 一致。

若存在这样的选择，返回 true；否则返回 false。这里“不相交”表示没有任何 nums[k] 同时属于两个被选择的子数组。

Examples

官方示例

示例 1

输入：groups = [[1,-1,-1],[3,-2,0]],
      nums = [1,-1,0,1,-1,-1,3,-2,0]
输出：true

可依次选择下标 3–5 与 6–8 的片段；二者不相交。

示例 2

输入：groups = [[10,-2],[1,2,3,4]],
      nums = [1,2,3,4,10,-2]
输出：false

[1,2,3,4] 出现得更早，但题目要求 [10,-2] 在前。

示例 3

输入：groups = [[1,2,3],[3,4]],
      nums = [7,7,1,2,3,4,7,7]
输出：false

两个候选片段共享 nums[4]，不满足“不相交”。

Constraints

约束

  • groups.length == n
  • 1 <= n <= 10³
  • 1 <= groups[i].length，且 sum(groups[i].length) <= 10³
  • 1 <= nums.length <= 10³
  • -10⁷ <= groups[i][j], nums[k] <= 10⁷

Solution

从左到右，永远拿最早可用的位置

核心洞察

对于当前 group，选择它在剩余 nums 中最早出现的位置，绝不会让后面的 group 更难匹配。因为越早结束，就给后续片段留下越长的后缀。

完整过程

  1. 令指针 pos = 0，表示还未使用的 nums 后缀从这里开始。
  2. 按顺序处理每个 group，从 pos 起向右寻找与它完全相同的连续片段。
  3. 若当前位置不匹配，只把 pos 右移一格；若匹配，则让 pos 跳过整个 group，保证下一段不会与它相交。
  4. 某个 group 搜到数组末尾仍未匹配时返回 false；全部匹配后返回 true。

正确性证明

贪心选择安全

设当前 group 的最早匹配终点为 E。任何可行方案为它选择的匹配终点 E′ 都满足 E ≤ E′。把方案中的选择换成最早匹配，不影响已选片段，也只会扩大后续可用后缀，因此仍然可行。

归纳完成

处理第一个 group 后，算法留下的后缀至少不短于任意可行方案。对其余 groups 重复同一论证。若存在完整方案，算法就能逐个找到；若算法找不到当前 group，则更晚的位置同样不存在匹配，完整方案不可能存在。

边界与复杂度

边界
  • 单个 group：等价于普通连续子数组查找。
  • group 恰好贴在 nums 末尾：长度检查必须允许等号。
  • 数值重复或为负：只比较值，不依赖单调性。
  • 看似匹配但剩余长度不足：直接判定该起点失败。
复杂度

记 N = nums.length，L = max(groups[i].length)。直接逐起点比较的最坏时间为 O(N·L)，额外空间为 O(1)（不计输入）。在本题上限下足够稳妥。

替代方案与面试追问

KMP 加速

为每个 group 构建前缀函数，在当前后缀中做线性匹配，总体可做到约 O(N + Σ|group|)。代码更长，只有数据规模明显扩大时才值得。

可能追问
  • 为什么不能复用上一次匹配中的元素？
  • 如何返回每个匹配片段的下标范围？
  • 如果 groups 允许任意顺序，问题会怎样变化？
  • 怎样用 KMP 避免大量重复比较？

常见错误

  • 匹配成功后只右移一格，导致后续 group 与已选片段重叠。
  • 先独立查找每个 group，再排序位置；这样可能选到冲突片段，也破坏“从剩余后缀继续”的约束。
  • 只比较 group 的首元素，没有逐项确认整个连续片段。
  • 使用切片会产生额外数组；可以直接按下标逐元素比较。

class Solution {
    public boolean canChoose(int[][] groups, int[] nums) {
        int pos = 0;

        for (int[] group : groups) {
            boolean found = false;
            while (pos + group.length <= nums.length) {
                if (matches(nums, pos, group)) {
                    pos += group.length;
                    found = true;
                    break;
                }
                pos++;
            }
            if (!found) return false;
        }
        return true;
    }

    private boolean matches(int[] nums, int start, int[] group) {
        for (int i = 0; i < group.length; i++) {
            if (nums[start + i] != group[i]) return false;
        }
        return true;
    }
}

var canChoose = function(groups, nums) {
    let pos = 0;

    for (const group of groups) {
        let found = false;
        while (pos + group.length <= nums.length) {
            let matches = true;
            for (let i = 0; i < group.length; i++) {
                if (nums[pos + i] !== group[i]) {
                    matches = false;
                    break;
                }
            }
            if (matches) {
                pos += group.length;
                found = true;
                break;
            }
            pos++;
        }
        if (!found) return false;
    }
    return true;
};
from typing import List


class Solution:
    def canChoose(self, groups: List[List[int]], nums: List[int]) -> bool:
        pos = 0

        for group in groups:
            found = False
            while pos + len(group) <= len(nums):
                matches = True
                for i, value in enumerate(group):
                    if nums[pos + i] != value:
                        matches = False
                        break

                if matches:
                    pos += len(group)
                    found = True
                    break
                pos += 1

            if not found:
                return False

        return True
class Solution {
public:
    bool canChoose(vector<vector<int>>& groups, vector<int>& nums) {
        int pos = 0;

        for (const auto& group : groups) {
            bool found = false;
            while (pos + static_cast<int>(group.size()) <= nums.size()) {
                bool matches = true;
                for (int i = 0; i < group.size(); ++i) {
                    if (nums[pos + i] != group[i]) {
                        matches = false;
                        break;
                    }
                }
                if (matches) {
                    pos += group.size();
                    found = true;
                    break;
                }
                ++pos;
            }
            if (!found) return false;
        }
        return true;
    }
};
