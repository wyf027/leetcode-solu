二分查找Binary Search

在一个严格升序的整数数组中定位目标值：找到则返回下标，不存在则返回 -1。本页先保留思考空间，题解需要手动展开。

简单 EASY 数组 二分查找 非会员题

Problem

题目描述

给定一个由 n 个元素组成、按升序排列的整数数组 nums，以及整数 target。请编写函数，在数组中搜索目标值；若存在，返回它的下标，否则返回 -1。

算法的运行时间复杂度必须为 O(log n)。

示例 1命中目标
输入：nums = [-1,0,3,5,9,12], target = 9
输出：4
解释：9 存在于 nums 中，下标为 4。
示例 2目标不存在
输入：nums = [-1,0,3,5,9,12], target = 2
输出：-1
解释：2 不存在于 nums 中，因此返回 -1。

约束

  • 1 <= nums.length <= 104
  • -104 < nums[i], target < 104
  • nums 中的整数互不相同。
  • nums 按升序排列。

题解：闭区间二分查找

核心洞察 完整过程 正确性证明 边界与复杂度 四语言代码 替代方案 面试追问与常见错误

核心洞察

数组有序，因此比较中点 nums[mid] 与 target 后，可以一次排除至少一半不可能包含答案的区间。

完整过程

  1. 令 left = 0、right = nums.length - 1，维护两端都包含的候选区间 [left, right]。
  2. 当 left <= right 时，取 mid = left + floor((right - left) / 2)。
  3. 若 nums[mid] === target，直接返回 mid。
  4. 若中点值小于目标，答案只可能在右半边，令 left = mid + 1；否则令 right = mid - 1。
  5. 若循环结束仍未返回，说明候选区间为空，返回 -1。

正确性证明

循环不变量：每次迭代开始时，如果目标存在，那么它一定位于闭区间 [left, right] 内。

初始化：开始时区间覆盖整个数组，因此不变量成立。

保持：若中点不是答案，利用升序性质可知目标只可能位于其中一侧。更新边界时仅删除不可能包含目标的中点及另一侧，所以不变量继续成立。

终止：命中时返回的下标对应目标值；若 left > right，候选区间为空。由不变量可知数组中不存在目标，返回 -1 正确。

边界与复杂度

时间复杂度O(log n)
额外空间O(1)

应覆盖的边界

  • 数组只有一个元素
  • 目标在首位或末位
  • 目标小于最小值或大于最大值
  • 目标落在相邻元素之间

区间约定

  • 本解法使用闭区间 [left, right]
  • 循环条件必须是 left <= right
  • 更新时跳过已比较的 mid

四语言完整代码

class Solution {
    public int search(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) {
                return mid;
            }
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return -1;
    }
}

替代方案

线性扫描

从头逐个比较，实现直接，但最坏需要 O(n) 时间，不满足本题要求。

左闭右开写法

可维护 [left, right)，此时循环条件和边界更新必须整体配套，不能与闭区间模板混用。

面试追问与常见错误

可能的追问

  • 数组含重复值时，如何寻找第一个或最后一个目标？
  • 为什么中点写成 left + (right-left)/2？
  • 旋转有序数组还能否二分？
  • 如何把判断题改造成“二分答案”？

常见错误

  • 闭区间却使用 left < right，漏查最后一个元素
  • 更新为 left = mid 或 right = mid，造成死循环
  • 未利用升序前提，淘汰了错误的一侧
  • 空区间后返回边界，而不是 -1
