任务说明

网格有 width 列、height 行，左下角为 (0, 0)，右上角为 (width − 1, height − 1)。机器人从左下角出发，初始朝东 East。

每走一步，先尝试沿当前朝向前进一格；若下一格越界，就逆时针转 90° 后重试这一步。转向本身不消耗移动步数。完成指令后立即停下，等待下一次调用。

题解 · 把边界折叠成一个环

核心洞察

机器人从边界出发，依次走底边、右边、顶边和左边，永远不会进入内部。令 a = width − 1、b = height − 1，一圈有 P = 2(a + b) 步。用一个偏移量 p 记录累计步数对 P 的余数，即可直接定位，不必逐步模拟。

位置相同不一定意味着初始状态相同：尚未移动时原点朝东；走完整圈回到原点时朝南。额外保存 moved，表示是否执行过正步数移动。

完整过程

  1. 构造时保存 a、b、P，并令 p = 0、moved = false。
  2. 每次 step(num) 更新 p = (p + num) % P，令 moved = true。
  3. getPos 按下表将 p 映射回坐标。
  4. getDir 在从未移动时返回 East；否则返回该位置的“到达方向”。查询不修改任何状态。
到达拐角后，保留刚才的移动方向
偏移范围位置朝向（已移动）
p = 0(0, 0)South
0 < p ≤ a(p, 0)East
a < p ≤ a + b(a, p − a)North
a + b < p ≤ 2a + b(2a + b − p, b)West
2a + b < p < P(0, P − p)South

示例 width = 6、height = 3：a = 5、b = 2、P = 14。累计偏移依次为 2、4、6、7、11，坐标依次为 (2,0)、(4,0)、(5,1)、(5,2)、(1,2)。p = 7 正好到右上角，所以朝北；下一步才转向西。

正确性论证

路径不变式：从原点向东沿底边行走，到越界前才逆时针转向，接着依次沿右、上、左边行走，回到原点。四段的长度分别为 a、b、a、b，构成长度为 P 的确定环。

偏移不变式：初始偏移为 0。若此前累计步数为 S，新增 num 步后在环上的位置为 (S + num) mod P；更新式保持这一不变式。区间公式逐段还原各边的坐标，因此位置正确。

方向正确性：除初始原点外，每个边界位置的最后一步都有固定到达方向，拐角也不提前转弯。moved 区分初始原点与绕圈后的原点，因此方向也正确。两者合起来保证任意合法调用序列的返回结果正确。

边界与常见错误

  • 一圈是 2(width + height − 2)，不能用 2(width + height)。这里计算的是相邻格子间的步数。
  • 不能把 num % P = 0 当成“什么都没发生”：初始原点在整圈后由 East 变成 South。
  • 恰好抵达拐角时不主动转向，因此分段上界使用 ≤。
  • width 或 height 为 2 仍适用；题目不包含宽高为 1 的退化网格。
  • getPos 返回新的数组/列表，避免外部修改返回值影响内部状态。
  • 无需累计完整 S；保留余数可以避免长调用序列中的不必要大整数。
  • 题目保证 num ≥ 1；若扩展允许 step(0)，应直接返回，以保留初始朝向。

复杂度与替代方案

本方案构造、step、getPos、getDir 均为 O(1) 时间；除返回值外额外空间 O(1)。Q 次调用总时间 O(Q)。

直接逐格模拟每次 O(num)，最多可能需要 10⁹ 次移动。预先枚举 P 个边界状态也可做到移动与查询 O(1)，但初始化和额外空间都是 O(P)。还可以按边批量推进并跳过整圈，不过要额外维护转向逻辑。

面试追问

  • 为什么只有一个初始特例？第一次离开原点后，每个边界点的到达方向都唯一。
  • 允许内部起点怎么办？先处理到达边界的前缀路径，再用边界环；不能直接套用本题的原点映射。
  • 加上障碍物还能取模吗？固定矩形周期不再成立；应将 (x, y, dir) 作为状态，分析新的转移或循环。
  • 如果 num 是超大十进制字符串？逐字符计算 num mod P，同时单独判断是否为正，以更新 moved。

Java
class Robot {
    private final int a, b, perimeter;
    private int p = 0;
    private boolean moved = false;

    public Robot(int width, int height) {
        a = width - 1;
        b = height - 1;
        perimeter = 2 * (a + b);
    }

    public void step(int num) {
        p = (p + num) % perimeter;
        moved = true;
    }

    public int[] getPos() {
        if (p <= a) return new int[]{p, 0};
        if (p <= a + b) return new int[]{a, p - a};
        if (p <= 2 * a + b) return new int[]{2 * a + b - p, b};
        return new int[]{0, perimeter - p};
    }

    public String getDir() {
        if (!moved) return "East";
        if (p == 0) return "South";
        if (p <= a) return "East";
        if (p <= a + b) return "North";
        if (p <= 2 * a + b) return "West";
        return "South";
    }
}
