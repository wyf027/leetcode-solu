题意转述

给定一个以 / 开头的 Unix 风格绝对路径，将它转换为规范路径。单点表示当前目录，双点表示回到父目录，连续斜杠视为一个分隔符；三个或更多点则是普通目录名。

官方样例 2

输入
path = "/home//foo/"
输出
"/home/foo"

连续斜杠产生的空片段被忽略。

官方样例 5

输入
path = "/.../a/../b/c/../d/./"
输出
"/.../b/d"

... 是合法目录名，只有恰好两个点才表示返回父目录。

本题字符串不包含普通空格；页面若出现空片段，会用 ∅ 可视化。若未来输入含空格，则用 ␠ 表示。

Core insight

核心洞察：栈就是当前有效路径

扫描到普通目录就压栈；扫描到 .. 就弹出最近目录；空片段与 . 不改变位置。于是任意时刻，栈从底到顶都精确表示根目录到当前位置的规范路径。

Interview choice

为什么主推 split + 栈

它把“分隔符归一化”和“目录状态变化”拆开：先按 / 得到片段，再用栈处理四种规则。表达直接、边界清楚，也是面试中最稳妥的线性解法。

完整过程

  1. 按 / 切分路径。
  2. 空片段或 .：忽略。
  3. ..：栈非空时弹出栈顶。
  4. 其他片段：作为合法目录名压栈。
  5. 用单个斜杠连接栈内容，并在开头补 /。

边界与复杂度

  • 根目录与越过根目录的 .. 都保持 /。
  • ...、.... 是普通目录名。
  • 多重斜杠产生的空片段必须忽略。
  • 时间复杂度：O(n)。
  • 额外空间：O(n)。

替代方案取舍

  • 手写扫描器：可减少切分数组，但代码更长。
  • 正则替换：难以正确处理嵌套父目录，不推荐。
  • 递归：没有必要，且不如显式栈清晰。

常见错误

  • 看到任意点串都当作父目录，误删 ...。
  • 栈空时仍然弹出，导致越过根目录。
  • 忘记忽略空片段，输出中残留重复斜杠。
  • 拼接时保留尾随斜杠，或根路径返回空字符串。

面试追问

如果输入是相对路径呢？
必须保留无法消解的前导 ..，并区分是否补根斜杠。
如何不使用 split？
用双指针逐段读取目录名，遇到斜杠时处理当前片段。
目录名可能含空格怎么办？
空格属于片段内容，不能 trim；只按斜杠分割。

class Solution {
    public String simplifyPath(String path) {
        java.util.Deque<String> stack = new java.util.ArrayDeque<>();
        for (String part : path.split("/")) {
            if (part.isEmpty() || part.equals(".")) {
                continue;
            }
            if (part.equals("..")) {
                if (!stack.isEmpty()) {
                    stack.removeLast();
                }
            } else {
                stack.addLast(part);
            }
        }
        return "/" + String.join("/", stack);
    }
}
var simplifyPath = function (path) {
    const stack = [];
    for (const part of path.split("/")) {
        if (part === "" || part === ".") continue;
        if (part === "..") {
            if (stack.length) stack.pop();
        } else {
            stack.push(part);
        }
    }
    return "/" + stack.join("/");
};

class Solution {
public:
    string simplifyPath(string path) {
        vector<string> stack;
        string part;
        stringstream input(path);

        while (getline(input, part, '/')) {
            if (part.empty() || part == ".") continue;
            if (part == "..") {
                if (!stack.empty()) stack.pop_back();
            } else {
                stack.push_back(part);
            }
        }

        string answer;
        for (const string& directory : stack) {
            answer += "/" + directory;
        }
        return answer.empty() ? "/" : answer;
    }
};
