电话目录管理系统 Design Phone Directory

设计一组极小却严格的接口：分配号码、查询号码、释放号码。真正的难点不在某一次调用，而在让目录的状态始终可信。

设计 队列 数组 哈希表 链表

Interface contract

INIT PhoneDirectory(maxNumbers)
GET int get()
ASK boolean check(number)
FREE void release(number)

01 / Problem

管理一段有限号码池

以下内容依据官方元数据中的类签名与示例参数转述；付费题面正文未随元数据提供。

题意

实现 PhoneDirectory 类，维护编号范围 [0, maxNumbers - 1] 内的电话号码。每个号码只有“可用”或“已分配”两种状态。

  • PhoneDirectory(int maxNumbers)：初始化目录，开始时全部号码可用。
  • int get()：分配并返回任意一个可用号码；若已无可用号码，返回 -1。
  • boolean check(int number)：若该号码当前可用，返回 true，否则返回 false。
  • void release(int number)：把已分配的号码放回目录，使其重新可用。

官方示例参数

输入：
["PhoneDirectory", "get", "get", "check", "get", "check", "release", "check"]
[[3], [], [], [2], [], [2], [2], [2]]

输出：
[null, 0, 1, true, 2, false, null, true]

解释：创建容量为 3 的目录；依次取出 0、1，号码 2 此时仍可用；取出 2 后目录为空；释放 2 后，2 再次可用。由于 get() 可返回任意可用号码，其他合法分配顺序也可能成立。

约束

  • 1 <= maxNumbers <= 10^4
  • 0 <= number < maxNumbers
  • 对 get、check 与 release 的调用总数至多为 2 * 10^4。

Solution / Free pool + availability

让两个视角共享同一份事实

一个容器负责快速给出可用号码，一张布尔表负责常数时间查询。释放时只在号码确实已占用时重新入池，避免重复号码。

01

核心洞察

get() 需要“随手拿到一个可用号码”，check(number) 则需要“按号码直接判断”。单一线性结构很难同时让二者都稳定达到常数时间，因此使用可用号码队列 free 与布尔数组 available。

始终保持不变量：available[x] == true 当且仅当号码 x 在可用池中恰好出现一次。

完整过程

A
初始化
将所有号码依次放入队列，布尔表全部设为可用。
B
分配
队列为空则返回 -1；否则取出队首号码，并把对应布尔值改为 false。
C
查询
直接读取 available[number]，无需扫描目录。
D
释放
仅当号码当前已分配时，将其标记为可用并重新入队。

正确性证明

初始化：每个合法号码恰好进入可用池一次，布尔表均为真，不变量成立。

分配：取出的号码来自可用池，随后从池中消失且布尔值变为假；其他号码不变，因此不变量保持，返回号码必然先前可用。

查询：由不变量，布尔值为真恰好等价于号码可用，所以返回值正确。

释放：只有布尔值为假时才重新入池并设为真，所以号码恢复可用且不会重复入池。由归纳法，所有操作后不变量均成立。

边界处理

  • 目录为空时，get() 返回 -1。
  • 容量为 1 时仍按同一逻辑工作，不需要特判。
  • 重复释放同一号码必须是幂等操作，不能产生多个副本。
  • 约束保证号码在合法范围；参考代码仍加入范围保护，使本地调用更稳健。

复杂度

每次操作O(1)get / check / release
额外空间O(n)队列与状态数组

构造函数需要将 n 个号码写入可用池，因此初始化时间为 O(n)。

Implementation

四种语言，保持同一不变量

import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

class PhoneDirectory {
    private final boolean[] available;
    private final Deque<Integer> freeNumbers;

    public PhoneDirectory(int maxNumbers) {
        available = new boolean[maxNumbers];
        Arrays.fill(available, true);
        freeNumbers = new ArrayDeque<>();

        for (int number = 0; number < maxNumbers; number++) {
            freeNumbers.offerLast(number);
        }
    }

    public int get() {
        if (freeNumbers.isEmpty()) {
            return -1;
        }

        int number = freeNumbers.pollFirst();
        available[number] = false;
        return number;
    }

    public boolean check(int number) {
        return number >= 0
            && number < available.length
            && available[number];
    }

    public void release(int number) {
        if (number < 0 || number >= available.length || available[number]) {
            return;
        }

        available[number] = true;
        freeNumbers.offerLast(number);
    }
}
/**
 * @param {number} maxNumbers
 */
var PhoneDirectory = function (maxNumbers) {
    this.available = new Array(maxNumbers).fill(true);
    this.freeNumbers = Array.from(
        { length: maxNumbers },
        (_, number) => number
    );
    this.head = 0;
};

/**
 * @return {number}
 */
PhoneDirectory.prototype.get = function () {
    if (this.head === this.freeNumbers.length) {
        return -1;
    }

    const number = this.freeNumbers[this.head];
    this.head += 1;
    this.available[number] = false;
    return number;
};

/**
 * @param {number} number
 * @return {boolean}
 */
PhoneDirectory.prototype.check = function (number) {
    return Number.isInteger(number)
        && number >= 0
        && number < this.available.length
        && this.available[number];
};

/**
 * @param {number} number
 * @return {void}
 */
PhoneDirectory.prototype.release = function (number) {
    if (!Number.isInteger(number)
        || number < 0
        || number >= this.available.length
        || this.available[number]) {
        return;
    }

    this.available[number] = true;
    this.freeNumbers.push(number);
};
from collections import deque


class PhoneDirectory:
    def __init__(self, maxNumbers: int):
        self.available = [True] * maxNumbers
        self.free_numbers = deque(range(maxNumbers))

    def get(self) -> int:
        if not self.free_numbers:
            return -1

        number = self.free_numbers.popleft()
        self.available[number] = False
        return number

    def check(self, number: int) -> bool:
        return (
            0 <= number < len(self.available)
            and self.available[number]
        )

    def release(self, number: int) -> None:
        if not (0 <= number < len(self.available)):
            return
        if self.available[number]:
            return

        self.available[number] = True
        self.free_numbers.append(number)
#include <queue>
#include <vector>

class PhoneDirectory {
private:
    std::vector<bool> available;
    std::queue<int> freeNumbers;

public:
    PhoneDirectory(int maxNumbers)
        : available(maxNumbers, true) {
        for (int number = 0; number < maxNumbers; ++number) {
            freeNumbers.push(number);
        }
    }

    int get() {
        if (freeNumbers.empty()) {
            return -1;
        }

        int number = freeNumbers.front();
        freeNumbers.pop();
        available[number] = false;
        return number;
    }

    bool check(int number) {
        return number >= 0
            && number < static_cast<int>(available.size())
            && available[number];
    }

    void release(int number) {
        if (number < 0
            || number >= static_cast<int>(available.size())
            || available[number]) {
            return;
        }

        available[number] = true;
        freeNumbers.push(number);
    }
};

替代方案

  • 哈希集合：存全部可用号码，查询与增删平均 O(1)，但常数和内存开销更大，最坏复杂度依赖哈希实现。
  • 循环链表：可把空闲号码串成链，适合讨论 O(n) 预处理与 O(1) 操作，但按编号查询仍需额外状态表。
  • 顺序扫描：仅用布尔数组并记录扫描指针，释放较小号码后需要额外维护；处理不当会让 get 退化到 O(n)。

面试追问

  • 若目录规模扩大到十亿，如何改用分段位图或分层索引？
  • 多线程同时调用 get 和 release 时，怎样保证线性一致性？
  • 如果号码需要按最小编号分配，应选择什么结构，复杂度如何变化？
  • 进程重启后仍需保留分配状态时，如何设计持久化与恢复？

常见错误

  • 释放一个本来就可用的号码，导致同一号码重复进入池中。
  • get() 取出号码后忘记同步更新布尔状态。
  • 用数组头部删除实现 JavaScript 队列，使每次分配退化为 O(n)。
  • 误以为示例要求固定返回最小号码；题目只要求返回任意可用号码。

复盘清单
