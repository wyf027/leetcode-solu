圆形靶内的最大飞镖数量

在无限大的平面上放置一个半径固定的圆形靶，让尽可能多的飞镖落点位于圆内或圆周上。圆心可以是任意实数坐标。

Maximum Number of Darts Inside of a Circular Dartboard 非付费题 困难

题目

给定二维整数数组 darts，其中 darts[i] = [xᵢ, yᵢ] 表示第 i 支飞镖的位置；再给定整数半径 r。返回一个任意放置、半径恰为 r 的圆能够覆盖的最多飞镖数量。位于边界上的飞镖也算被覆盖。

官方示例 1
输入：darts = [[-2,0],[2,0],[0,2],[0,-2]], r = 2
输出：4
解释：圆心取 (0,0)，半径为 2，四个点都在圆周上。
官方示例 2
输入：darts = [[-3,0],[3,0],[2,6],[5,4],[0,9],[7,8]], r = 5
输出：5
解释：圆心取 (0,4)，除 (7,8) 外的五个点都位于圆内或圆周上。

函数签名

numPoints(darts, r) → integer

  • darts：二维整数数组，单个元素为 [x, y]
  • r：圆形靶的整数半径
  • 返回：圆内或圆周上的最大点数

约束

  • 1 ≤ darts.length ≤ 100
  • darts[i].length == 2
  • -10⁴ ≤ xᵢ, yᵢ ≤ 10⁴
  • 所有飞镖坐标互不相同
  • 1 ≤ r ≤ 5000

准备好看完整推导了吗？

题解包含几何推导、正确性证明、四语言实现和面试延伸。

题解：枚举边界点对，反求圆心

固定半径后，两点若能同时落在圆周上，最多对应两个圆心。枚举这些有限的候选圆，再逐点计数即可。

核心洞察

若某个最优圆只让零个或一个点接触边界，可以在不丢失圆内点的前提下平移，直到至少一个点碰到边界；继续绕该点调整，可得到一个同样最优、且至少两个点在边界上的圆（只有一个点时答案显然为 1）。因此，最优解一定会出现在某一对点共同位于圆周的候选圆中。

几何构造

  1. 选点 A(x₁,y₁)、B(x₂,y₂)，距离记为 d。
  2. 若 d > 2r，它们不可能同时在半径 r 的圆周上。
  3. 取弦中点 M=(A+B)/2，圆心到 M 的距离为 h=√(r²-d²/4)。
  4. 弦方向的单位法向量为 (-dy/d, dx/d)。
  5. 两个候选圆心为 M ± h·(-dy/d, dx/d)。
  6. 对每个候选圆心扫描所有点，距离不超过 r+ε 即计入。

边界处理

  • 单点：初始化答案为 1，无需构造点对。
  • 直径：d=2r 时 h=0，两个候选圆心重合，重复计算不影响答案。
  • 浮点误差：比较平方距离时加入 1e-7；根号参数用 max(0, ·) 截断。
  • 点唯一：官方约束保证没有重合点，因此点对距离 d 不为 0。
  • 圆内点：候选点对在边界上，其余点既可能在圆周，也可能严格位于圆内。

正确性证明

候选完备性。 对任意覆盖最多点的半径 r 圆，若答案大于 1，可连续移动圆心而不让已覆盖点离开，直到两个已覆盖点落到边界。因此至少存在一个最优圆，其圆心属于某个点对导出的两个候选圆心之一。
构造正确性。 对距离不超过 2r 的点对 A、B，垂直平分线上的两个构造点到 A、B 的距离均为 r；它们恰是所有半径 r 且同时经过 A、B 的圆心。
计数正确性。 对每个候选圆心逐点检查平方距离，得到的计数正是该圆内或圆周上的飞镖数。
结论。 算法枚举到了至少一个最优圆，并取所有候选计数的最大值，所以返回值等于可覆盖的最大飞镖数量。

复杂度

时间：O(n³)。共有 O(n²) 个点对，每个候选圆扫描 O(n) 个点；每对至多两个圆心。

空间：O(1) 额外空间，不计输入。

替代方案

固定某个点在圆周上，把其他点能被同一圆覆盖的圆心方向转换为角度区间，再做环形扫描线，可将时间降到 O(n² log n)。它更快，但跨越 -π/π、端点闭区间与浮点排序更容易出错；在 n ≤ 100 时，O(n³) 的点对枚举更直接。

class Solution {
    private static final double EPS = 1e-7;

    public int numPoints(int[][] darts, int r) {
        int n = darts.length;
        int answer = 1;
        double radius = r;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                double dx = darts[j][0] - darts[i][0];
                double dy = darts[j][1] - darts[i][1];
                double d2 = dx * dx + dy * dy;
                double diameter2 = 4.0 * radius * radius;
                if (d2 > diameter2 + EPS) continue;

                double d = Math.sqrt(d2);
                double mx = (darts[i][0] + darts[j][0]) / 2.0;
                double my = (darts[i][1] + darts[j][1]) / 2.0;
                double h = Math.sqrt(Math.max(0.0, radius * radius - d2 / 4.0));
                double ox = -dy / d * h;
                double oy = dx / d * h;

                answer = Math.max(answer, count(darts, mx + ox, my + oy, radius));
                answer = Math.max(answer, count(darts, mx - ox, my - oy, radius));
            }
        }
        return answer;
    }

    private int count(int[][] darts, double cx, double cy, double r) {
        int covered = 0;
        for (int[] point : darts) {
            double dx = point[0] - cx;
            double dy = point[1] - cy;
            if (dx * dx + dy * dy <= r * r + EPS) covered++;
        }
        return covered;
    }
}

class Solution {
public:
    int numPoints(vector<vector<int>>& darts, int r) {
        constexpr double EPS = 1e-7;
        int n = static_cast<int>(darts.size());
        int answer = 1;

        auto count = [&](double cx, double cy) {
            int covered = 0;
            for (const auto& point : darts) {
                double dx = point[0] - cx;
                double dy = point[1] - cy;
                if (dx * dx + dy * dy <= 1.0 * r * r + EPS) {
                    ++covered;
                }
            }
            return covered;
        };

        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                double dx = darts[j][0] - darts[i][0];
                double dy = darts[j][1] - darts[i][1];
                double d2 = dx * dx + dy * dy;
                if (d2 > 4.0 * r * r + EPS) continue;

                double d = sqrt(d2);
                double mx = (darts[i][0] + darts[j][0]) / 2.0;
                double my = (darts[i][1] + darts[j][1]) / 2.0;
                double h = sqrt(max(0.0, 1.0 * r * r - d2 / 4.0));
                double ox = -dy / d * h;
                double oy = dx / d * h;

                answer = max(answer, count(mx + ox, my + oy));
                answer = max(answer, count(mx - ox, my - oy));
            }
        }
        return answer;
    }
};

常见错误

  • 只把输入点当圆心，会漏掉圆心位于任意实数坐标的最优解。
  • 对一对点只构造垂直平分线一侧的圆心，会漏掉另一侧。
  • 用 d < 2r 排除等号，漏掉直径恰好为 2r 的情况。
  • 直接比较浮点距离与 r，不留误差，会把圆周点错误排除。
  • 用整数保存中点或圆心，导致小数部分被截断。
