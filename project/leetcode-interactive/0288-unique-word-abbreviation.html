01 / PROBLEM

题意与接口

一个单词的缩写按如下方式生成：长度不超过 2 时保持原词；否则保留首尾字符，并把中间字符的数量写在两者之间。例如，international 变为 i11l，it 仍是 it。

请设计 ValidWordAbbr：

  • ValidWordAbbr(String[] dictionary)：使用给定字典初始化对象。
  • boolean isUnique(String word)：如果字典里不存在另一个不同单词与 word 拥有相同缩写，返回 true；否则返回 false。
关键语义：若字典中唯一占用该缩写的单词恰好就是查询词，结果仍为 true。重复出现的同一个字典词不应制造“不同单词”的冲突。

官方示例的完整调用形式

输入 methods = ["ValidWordAbbr", "isUnique", "isUnique", "isUnique", "isUnique", "isUnique"]
输入 args    = [[["deer", "door", "cake", "card"]], ["dear"], ["cart"], ["cane"], ["make"], ["cake"]]
输出         = [null, false, true, false, true, true]

dear 与字典中的 deer/door 都缩写为 d2r；cane 与 cake 都是 c2e。cart 和 make 的缩写未被占用，而 cake 只与自身对应，所以后三种相应判断为 true。

约束

  • 1 <= dictionary.length <= 3 * 10^4
  • 1 <= dictionary[i].length <= 20
  • 1 <= word.length <= 20
  • 字典词与查询词仅含小写英文字母。
  • isUnique 最多被调用 5000 次。

SOLUTION / HASH BUCKETS

用缩写映射到“不同原词集合”

核心洞察

查询只关心同一缩写下有多少个不同的原词。预处理时建立 缩写 → Set<原词>：桶不存在时一定唯一；桶中只有查询词本身时也唯一；除此之外均不唯一。

1

构造 key

长度 ≤ 2 直接用原词；否则拼接首字符、中间数量和尾字符。

2

收集不同词

每个缩写对应一个集合，天然消除完全相同的重复词。

3

判定查询

返回 桶为空 || (桶大小为 1 且包含 word)。

完整过程

  1. 初始化空哈希表 groups。
  2. 遍历 dictionary，计算每个词的缩写，并把原词加入对应集合。
  3. 查询时计算 word 的缩写并读取集合。
  4. 集合不存在，表示没有字典词占用该缩写，返回 true。
  5. 集合恰好只含 word，表示不存在“另一个不同词”，返回 true；其余情况返回 false。

正确性证明

引理 1：预处理完成后，对任意缩写 a，groups[a] 恰好包含字典中所有缩写为 a 的不同单词。因为每个字典词都被加入其唯一计算出的桶，而集合只消除相同值的重复。

引理 2：查询词 w 唯一，当且仅当其桶不存在，或桶等于单元素集合 {w}。前者说明没有冲突词；后者说明唯一占用者就是自身。若桶含任意不同于 w 的词，则定义上不唯一。

结论：算法返回条件正是引理 2 的条件，因此对每次查询都返回正确结果。

边界情况

  • 长度 1 或 2：缩写就是原词，不能产生数字段。
  • 字典重复词：集合去重，不会把同一个词误判为冲突。
  • 查询词不在字典，但缩写已存在：应返回 false。
  • 查询词在字典，但桶里还有别的词：仍返回 false。
  • 缩写桶不存在：无需确认查询词是否在字典，直接返回 true。

复杂度

O(S)初始化时间

S 为字典字符总数（含哈希字符串的成本）。

O(L)单次查询时间

L 为查询词长度。

O(S)额外空间

最坏情况下保存所有不同字典词。

替代方案

可以让每个缩写只保存“唯一代表词”或一个冲突标记：第一次记录原词，再遇到不同原词便标为冲突；相同重复词不改变状态。它比集合更省常数空间，但要谨慎选择不会与合法单词混淆的标记。集合版语义直接，也更不易写错。

import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class ValidWordAbbr {
    private final Map<String, Set<String>> groups = new HashMap<>();

    public ValidWordAbbr(String[] dictionary) {
        for (String word : dictionary) {
            String key = abbreviate(word);
            groups.computeIfAbsent(key, ignored -> new HashSet<>()).add(word);
        }
    }

    public boolean isUnique(String word) {
        Set<String> words = groups.get(abbreviate(word));
        return words == null || (words.size() == 1 && words.contains(word));
    }

    private String abbreviate(String word) {
        int n = word.length();
        if (n <= 2) {
            return word;
        }
        return "" + word.charAt(0) + (n - 2) + word.charAt(n - 1);
    }
}
class ValidWordAbbr {
    /**
     * @param {string[]} dictionary
     */
    constructor(dictionary) {
        this.groups = new Map();

        for (const word of dictionary) {
            const key = this.abbreviate(word);
            if (!this.groups.has(key)) {
                this.groups.set(key, new Set());
            }
            this.groups.get(key).add(word);
        }
    }

    /**
     * @param {string} word
     * @return {boolean}
     */
    isUnique(word) {
        const words = this.groups.get(this.abbreviate(word));
        return words === undefined || (words.size === 1 && words.has(word));
    }

    abbreviate(word) {
        if (word.length <= 2) {
            return word;
        }
        return word[0] + String(word.length - 2) + word[word.length - 1];
    }
}
from collections import defaultdict
from typing import List, Set, Dict


class ValidWordAbbr:
    def __init__(self, dictionary: List[str]):
        self.groups: Dict[str, Set[str]] = defaultdict(set)

        for word in dictionary:
            self.groups[self._abbreviate(word)].add(word)

    def isUnique(self, word: str) -> bool:
        words = self.groups.get(self._abbreviate(word))
        return words is None or (len(words) == 1 and word in words)

    @staticmethod
    def _abbreviate(word: str) -> str:
        if len(word) <= 2:
            return word
        return f"{word[0]}{len(word) - 2}{word[-1]}"
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

class ValidWordAbbr {
private:
    unordered_map<string, unordered_set<string>> groups;

    string abbreviate(const string& word) const {
        int n = static_cast<int>(word.size());
        if (n <= 2) {
            return word;
        }
        return word.substr(0, 1) + to_string(n - 2) + word.substr(n - 1);
    }

public:
    ValidWordAbbr(vector<string>& dictionary) {
        for (const string& word : dictionary) {
            groups[abbreviate(word)].insert(word);
        }
    }

    bool isUnique(string word) {
        string key = abbreviate(word);
        auto it = groups.find(key);
        if (it == groups.end()) {
            return true;
        }
        const auto& words = it->second;
        return words.size() == 1 && words.count(word) == 1;
    }
};

常见错误

  • 把“缩写出现过”直接判为不唯一，导致字典中的 cake 查询错误。
  • 只保存缩写计数，完全相同的重复词会被误当成不同冲突词。
  • 长度为 1 或 2 时仍拼接数字，产生 a-1a 一类非法结果。
  • 只按长度分组，却忘记同时比较首字符和尾字符。
