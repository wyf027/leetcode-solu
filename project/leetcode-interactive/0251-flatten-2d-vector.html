题意

设计能展开二维整数向量的迭代器 Vector2D，支持 next() 与 hasNext()。next() 返回下一个元素并前进一步；题目保证所有 next() 调用有效；hasNext() 判断是否还有元素。

题解：把“找下一个有效格”收敛进 forward

核心洞察

行 i、列 j 是唯一状态。辅助函数 forward() 在当前行耗尽时移动到下一行并把列归零，连续空行也会被跳过。hasNext 和 next 都先调用它，避免边界逻辑分散。

完整过程

  1. 构造时保存二维数组，i = j = 0。
  2. forward()：只要当前行不存在或 j 越过行尾，就 i++、j=0。
  3. hasNext() 前移后检查 i < rows。
  4. next() 前移后读取 vec[i][j++]。
均摊时间
每格读取一次、每行跳过一次；每次操作均摊 O(1)。
空间复杂度
O(1) 额外空间，只保存两个游标。

替代方案与取舍

构造时扁平化到一维数组，next 更简单，但额外用 O(N) 空间并提前复制。双游标是迭代器的自然做法，也满足 follow-up 的迭代器思路。

边界

  • 二维数组为空：首次 hasNext() 即 false。
  • 中间或开头有空行：forward 连续跳过。
  • 多次调用 hasNext 不消费元素。
  • next 调用有效，因此无需定义空迭代器的返回值。

常见错误

只在 next 中跳过空行，会使 hasNext 误报；hasNext 跳过元素本身而不是行尾，会破坏“查询不消费”的契约。

面试追问

Java 可维护外层与内层 Iterator；内层耗尽后取下一个外层 iterator。C++ 可维护两个 vector iterator，以相同的不变量推进。

class Vector2D {
    private final int[][] vec; private int i, j;
    public Vector2D(int[][] vec) { this.vec = vec; }
    public int next() { forward(); return vec[i][j++]; }
    public boolean hasNext() { forward(); return i < vec.length; }
    private void forward() {
        while (i < vec.length && j >= vec[i].length) { i++; j = 0; }
    }
}

    def __init__(self, vec: List[List[int]]):
        self.vec, self.i, self.j = vec, 0, 0
    def forward(self) -> None:
        while self.i < len(self.vec) and self.j >= len(self.vec[self.i]):
            self.i += 1
            self.j = 0
    def next(self) -> int:
        self.forward()
        value = self.vec[self.i][self.j]
        self.j += 1
        return value
    def hasNext(self) -> bool:
        self.forward()
        return self.i < len(self.vec)
