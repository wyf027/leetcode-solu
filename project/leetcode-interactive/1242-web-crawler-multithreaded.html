多线程网络爬虫Web Crawler Multithreaded

从一个网址出发，沿链接探索同一主机名下的页面。页面读取可以并行进行，但重复访问、跨站链接与“所有任务何时真正结束”都必须被正确处理。

题目转述

任务

给定起始地址 startUrl 和接口 HtmlParser。调用 htmlParser.getUrls(url) 可以取得某页面中的全部链接。请使用多线程爬取：只访问与 startUrl 主机名相同的 URL，每个 URL 至多访问一次，返回所有已访问地址。返回顺序任意。

主机名是 URL 中协议之后、路径之前的部分。例如 http://news.yahoo.com/news 的主机名是 news.yahoo.com。评测环境保证 getUrls 可被并发调用。

标准接口

crawl(startUrl, htmlParser) → List<String> HtmlParser.getUrls(url) → List<String>
  • startUrl：爬取入口
  • htmlParser：评测器提供的解析器
  • 结果：同主机名且可达的 URL 集合

官方示例 1（完整参数形式）

urls = ["http://news.yahoo.com", "http://news.yahoo.com/news", "http://news.yahoo.com/news/topics/", "http://news.google.com", "http://news.yahoo.com/us"] edges = [[2,0], [2,1], [3,2], [3,1], [0,4]] startUrl = "http://news.yahoo.com/news/topics/" 输出（顺序任意）： ["http://news.yahoo.com/news/topics/", "http://news.yahoo.com", "http://news.yahoo.com/news", "http://news.yahoo.com/us"] 解释：从索引 2 可到达 0、1，再由 0 到达 4；它们都属于 news.yahoo.com。

官方示例 2（完整参数形式）

urls = ["http://news.yahoo.com", "http://news.yahoo.com/news", "http://news.yahoo.com/news/topics/", "http://news.google.com"] edges = [[0,2], [2,1], [3,2], [3,1], [3,0]] startUrl = "http://news.google.com" 输出：["http://news.google.com"] 解释：起点虽能链接到 Yahoo 页面，但主机名不同，所以全部跳过。

约束

  • URL 总数在 1 到 1000 之间，所有 URL 互不相同。
  • 每个 URL 长度在 1 到 300 之间，并使用 http:// 协议且不带端口。
  • startUrl 一定存在于 URL 集合中；getUrls(url) 返回该页面直接包含的链接。
  • 所有线程共享同一个解析器；答案顺序不作要求。

准备好再看解法

先尝试回答：为什么“取到 URL 后再加入 visited”会让两个线程重复抓取同一页面？

核心洞察 01

过滤域名。只把与起点主机名完全相同的链接加入工作集合；字符串前缀不够可靠，应解析 URL 的 host。

核心洞察 02

原子认领。线程在提交任务之前，以原子方式执行“若未访问则加入”。谁成功加入，谁拥有该 URL。

核心洞察 03

动态终止。队列暂时为空不等于结束；必须等队列为空且正在解析的任务数也为零。

完整过程

  1. 解析 startUrl 的主机名，初始化线程安全的 visited，并原子加入起点。
  2. 把起点交给线程池。工作线程调用 getUrls，并对每个结果先做主机名过滤。
  3. 对合法 URL 执行原子“加入 visited”。只有第一次加入成功的线程才能继续提交该页面。
  4. 用 Phaser、条件变量或待处理计数跟踪动态产生的任务；当计数归零时，安全关闭工作线程。
  5. 返回 visited。由于结果顺序任意，无须为输出额外排序。

正确性

可靠性：起点被加入。任一同域可达 URL 的前驱被处理时，该 URL 会被检查并首次加入，因此按路径长度归纳，所有同域可达 URL 都会加入。

安全性：跨域 URL 从不提交；原子集合保证每个同域 URL 至多被成功认领一次。因此结果恰好是全部同域可达页面。

终止性：URL 集合有限，每个 URL 至多产生一个任务；待处理计数最终归零，所有工作线程退出。

复杂度与边界

令 V 为被访问页面数，E 为这些页面返回链接的总数。总工作量 O(V + E)，共享集合、任务队列和结果占用 O(V) 空间；并行墙钟时间受线程数、网络延迟和图结构影响。

  • 起点没有链接：返回起点。
  • 自环、环、重复链接：原子 visited 去重。
  • 主机名相似但不同：例如 news.yahoo.com.evil.test 必须排除。
  • 解析异常：生产系统应定义重试、超时与失败策略；题目接口通常不要求。

四语言完整代码

ExecutorService + Phaser：注册动态子任务官方可提交语言
import java.net.URI;
import java.util.*;
import java.util.concurrent.*;

// interface HtmlParser {
//     List<String> getUrls(String url);
// }

class Solution {
    private final Set<String> visited = ConcurrentHashMap.newKeySet();
    private final ExecutorService pool = Executors.newFixedThreadPool(8);
    private HtmlParser parser;
    private String targetHost;

    public List<String> crawl(String startUrl, HtmlParser htmlParser) {
        parser = htmlParser;
        targetHost = URI.create(startUrl).getHost();
        Phaser phaser = new Phaser(1); // 主线程是初始参与者

        submitIfNew(startUrl, phaser);
        phaser.arriveAndAwaitAdvance();
        pool.shutdown();
        return new ArrayList<>(visited);
    }

    private void submitIfNew(String url, Phaser phaser) {
        if (!sameHost(url) || !visited.add(url)) return;

        phaser.register();
        pool.execute(() -> {
            try {
                for (String next : parser.getUrls(url)) {
                    submitIfNew(next, phaser);
                }
            } finally {
                phaser.arriveAndDeregister();
            }
        });
    }

    private boolean sameHost(String url) {
        return Objects.equals(targetHost, URI.create(url).getHost());
    }
}
有界异步批次；假定 getUrls 可返回值或 Promise本地语义参考
class Solution {
  async crawl(startUrl, htmlParser) {
    const targetHost = new URL(startUrl).hostname;
    const visited = new Set([startUrl]);
    let frontier = [startUrl];
    const concurrency = 8;

    while (frontier.length > 0) {
      const nextFrontier = [];

      for (let i = 0; i < frontier.length; i += concurrency) {
        const batch = frontier.slice(i, i + concurrency);
        const pages = await Promise.all(
          batch.map((url) => Promise.resolve(htmlParser.getUrls(url)))
        );

        for (const links of pages) {
          for (const next of links) {
            if (new URL(next).hostname !== targetHost || visited.has(next)) {
              continue;
            }
            // JavaScript 事件循环内，这段同步检查与写入不会被 await 打断。
            visited.add(next);
            nextFrontier.push(next);
          }
        }
      }
      frontier = nextFrontier;
    }

    return [...visited];
  }
}
ThreadPoolExecutor + Condition：等待 pending 归零官方可提交语言
from concurrent.futures import ThreadPoolExecutor
from threading import Condition
from urllib.parse import urlparse
from typing import List

# class HtmlParser:
#     def getUrls(self, url: str) -> List[str]: ...

class Solution:
    def crawl(self, startUrl: str, htmlParser: 'HtmlParser') -> List[str]:
        target_host = urlparse(startUrl).hostname
        visited = set()
        condition = Condition()
        pending = 0

        with ThreadPoolExecutor(max_workers=8) as executor:
            def submit_if_new(url: str) -> None:
                nonlocal pending
                if urlparse(url).hostname != target_host:
                    return
                with condition:
                    if url in visited:
                        return
                    visited.add(url)
                    pending += 1
                executor.submit(worker, url)

            def worker(url: str) -> None:
                nonlocal pending
                try:
                    for next_url in htmlParser.getUrls(url):
                        submit_if_new(next_url)
                finally:
                    with condition:
                        pending -= 1
                        if pending == 0:
                            condition.notify_all()

            submit_if_new(startUrl)
            with condition:
                condition.wait_for(lambda: pending == 0)

        return list(visited)
固定工作线程 + 条件变量 + 动态任务计数官方可提交语言
#include <condition_variable>
#include <mutex>
#include <queue>
#include <string>
#include <thread>
#include <unordered_set>
#include <vector>
using namespace std;

// class HtmlParser {
// public:
//     vector<string> getUrls(string url);
// };

class Solution {
    string hostname(const string& url) {
        size_t begin = url.find("//") + 2;
        size_t end = url.find('/', begin);
        return url.substr(begin, end == string::npos ? end : end - begin);
    }

public:
    vector<string> crawl(string startUrl, HtmlParser htmlParser) {
        const string target = hostname(startUrl);
        unordered_set<string> visited{startUrl};
        queue<string> jobs;
        jobs.push(startUrl);

        mutex mutex;
        condition_variable cv;
        int pending = 1; // 排队中或处理中的任务总数
        bool stopping = false;

        auto worker = [&]() {
            while (true) {
                string url;
                {
                    unique_lock<std::mutex> lock(mutex);
                    cv.wait(lock, [&] { return stopping || !jobs.empty(); });
                    if (stopping && jobs.empty()) return;
                    url = jobs.front();
                    jobs.pop();
                }

                vector<string> links = htmlParser.getUrls(url);
                {
                    lock_guard<std::mutex> lock(mutex);
                    for (const string& next : links) {
                        if (hostname(next) == target && visited.insert(next).second) {
                            jobs.push(next);
                            ++pending;
                        }
                    }
                    --pending;
                    if (pending == 0) stopping = true;
                }
                cv.notify_all();
            }
        };

        unsigned count = min(8u, max(2u, thread::hardware_concurrency()));
        vector<thread> threads;
        for (unsigned i = 0; i < count; ++i) threads.emplace_back(worker);
        for (thread& thread : threads) thread.join();

        return vector<string>(visited.begin(), visited.end());
    }
};

替代方案

  • 线程安全队列 + 固定 worker：控制线程数量直接，但终止检测要同时考虑队列和活跃任务。
  • 递归 Future：表达直观，却可能创建大量 Future，且在线程池中阻塞等待子任务会引发饥饿。
  • 单线程 BFS/DFS：逻辑最简单、同样正确，但无法隐藏 getUrls 的等待时间，不满足题目的并发重点。

常见错误

  • 先提交任务、后写入 visited：两个线程可能同时提交同一 URL。
  • 使用普通 Set 却只给单次操作加局部锁：“检查 + 加入”必须是一个原子临界区。
  • 看见队列为空便退出：此时活跃线程可能马上发现新链接。
  • 用 startsWith(startUrl) 判断同域：路径、子域和恶意相似前缀都会造成误判。
  • 在线程池任务中同步等待由同一小线程池执行的子任务，导致线程饥饿或死锁。
