Cells in a Range on an Excel Sheet

01 / THE PROBLEM

题目说明

单元格用“列字母 + 行号”表示，例如 B3 表示 B 列第 3 行。给定字符串 s = "<col1><row1>:<col2><row2>"，两个端点确定一个包含边界的矩形选区。请返回选区内所有单元格的字符串列表，顺序要求：列从小到大；同一列内，行号从小到大。参数为字符串 s，返回值为字符串数组。

官方示例 1

输入：s = "K1:L2"
输出：["K1","K2","L1","L2"]

选区含 K、L 两列和第 1、2 行；列表先列出 K 列，再列出 L 列。

官方示例 2

输入：s = "A1:F1"
输出：["A1","B1","C1","D1","E1","F1"]

选区只有第 1 行，覆盖 A 到 F 共 6 列。

约束

  • s.length == 5，格式固定为 列行:列行。
  • 'A' <= s[0] <= s[3] <= 'Z'。
  • '1' <= s[1] <= s[4] <= '9'。
  • s 仅包含大写英文字母、数字与冒号 ':'。

04 / SOLUTION

完成思考后，再查看题解

题解 · 按目标顺序枚举

核心洞察

结果要求“列优先，行次之”。直接让列作为外层循环、行作为内层循环，生成时就有序，无须排序。题目限定单字母列、单数字行，所以四个边界可直接从 s[0]、s[1]、s[3]、s[4] 读取。

完整过程

  1. 读取起止列与起止行，冒号固定在索引 2。
  2. 从起始列向终止列递增，每次选择一列。
  3. 在该列内从起始行到终止行递增，将列字母与行号拼为字符串并加入结果。
  4. 换到下一列时，行号回到起始行；所有列结束后返回列表。

对于 s = "K1:L2"：先固定 K，得到 K1、K2；再固定 L，得到 L1、L2。总计 2 × 2 = 4 格。

正确性

对外层当前列 c，内层循环恰好枚举范围内每个行号一次，因此生成该列所有合法单元格且无重复。外层又恰好枚举每个合法列一次，故所有合法单元格均被覆盖且不含范围外元素。同列内行号递增，不同列按列字母递增，拼接后的列表满足要求。循环边界均有限，所以算法终止并返回正确结果。

边界与复杂度

单格、单行、单列都由相同的包含端点循环处理。Z 列和第 9 行也无需特殊分支。设列数 C、行数 R，输出 N = C × R 个长度为 2 的字符串；时间 O(N)，结果空间 O(N)，除返回列表外的辅助空间 O(1)。本题 N 最大为 26 × 9 = 234。若把题目上限视为固定常量，也可认为绝对资源有常数上界，但按输出规模表达更清晰。

替代方案

可以任意顺序收集后排序，但需要 O(N log N) 时间，且多位行号扩展时必须按数值比较行号。也可用单循环 i = 0…N−1，列偏移为 ⌊i/R⌋，行偏移为 i mod R；它等价于双循环，阅读成本稍高。

常见错误

  • 行作为外层循环，得到按行优先的错误排列。
  • 使用严格小于边界，漏掉最后一行或一列。
  • Java 直接让两个 char 相加，结果变成数字；先转换为字符串。
  • JavaScript 没有字符自增；需要字符编码与 String.fromCharCode。
  • 误将真实 Excel 的 AA、10 等格式带入本题；固定下标解析仅适用于本题约束。

面试追问

  • 支持 AA10:BC25 怎么办？先按冒号拆端点，再分离字母前缀与数字后缀；列按无零位的 26 进制转换为整数，枚举后转换回来。
  • 范围很大怎么办？若接口允许，生成器可以逐项输出，避免保存完整列表；题目接口要求列表时，O(N) 输出空间不可省。
  • 要求按行优先怎么办？交换两层循环即可。
  • 需要避免枚举直接找第 k 项吗？令 k 从 0 开始，列偏移 k // R，行偏移 k % R，并先检查 0 ≤ k < N。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> cellsInRange(String s) {
        List<String> result = new ArrayList<>();
        for (char col = s.charAt(0); col <= s.charAt(3); col++) {
            for (char row = s.charAt(1); row <= s.charAt(4); row++) {
                result.add("" + col + row);
            }
        }
        return result;
    }
}

JavaScript

/**
 * @param {string} s
 * @return {string[]}
 */
var cellsInRange = function(s) {
    const result = [];
    for (let col = s.charCodeAt(0); col <= s.charCodeAt(3); col++) {
        for (let row = Number(s[1]); row <= Number(s[4]); row++) {
            result.push(String.fromCharCode(col) + row);
        }
    }
    return result;
};

Python

from typing import List

class Solution:
    def cellsInRange(self, s: str) -> List[str]:
        result = []
        for col in range(ord(s[0]), ord(s[3]) + 1):
            for row in range(int(s[1]), int(s[4]) + 1):
                result.append(chr(col) + str(row))
        return result

class Solution {

    vector<string> cellsInRange(string s) {
        vector<string> result;
        for (char col = s[0]; col <= s[3]; ++col) {
            for (char row = s[1]; row <= s[4]; ++row) {
                result.push_back(string(1, col) + row);
            }
        }
        return result;
    }
