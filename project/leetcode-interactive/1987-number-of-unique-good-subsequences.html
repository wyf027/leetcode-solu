Number of Unique Good Subsequences

同样的字符串，只计一次。

字符串子序列取模 1,000,000,007

01 / PROBLEM

题目与规则

给定二进制字符串 binary，可以删除任意个字符，但不能改变剩余字符的顺序。得到的字符串必须非空，并且不能有前导 0；唯一例外是单独的 "0"。

返回所有符合条件的不同字符串的数量，对 10⁹ + 7 取余。即使来自不同下标，只要字符内容相同，也只计一次。子序列不要求连续。

参数：binary: string → integer

约束：1 ≤ binary.length ≤ 10⁵；所有字符均为 '0' 或 '1'。

官方示例

示例 1

输入：binary = "001"
输出：2

两个位置的 0 都只能得到同一个字符串。去重后是 {"0", "1"}。

示例 2

输入：binary = "11"
输出：2

两个单字符 "1" 合并计数，结果是 {"1", "11"}。

示例 3

输入：binary = "101"
输出：5

不同结果为 {"0", "1", "10", "11", "101"}。

04 / EDITORIAL

准备好推导了吗？

展开后可阅读状态定义、去重证明与四语言完整代码。

只维护两个末位计数

核心洞察

把以 1 开头的不同子序列按末位分组：end0 与 end1。单独用 hasZero 表示是否见过 0，避免 "0" 参与后续拼接，生成非法的 "00" 或 "01"。无需保存每个字符串，只保存每组数量。

完整过程

  1. 初始化 end0 = end1 = hasZero = 0，表示空前缀。
  2. 读到 0：把所有以 1 开头的合法字符串追加 0，覆盖 0 结尾组。因此 end0 = (end0 + end1) % MOD，并将 hasZero = 1；end1 不变。
  3. 读到 1：把所有以 1 开头的合法字符串追加 1，再加入单字符 "1"，覆盖 1 结尾组。因此 end1 = (end0 + end1 + 1) % MOD；end0 不变。
  4. 最终返回 (end0 + end1 + hasZero) % MOD。更新式右侧使用当前字符处理前的状态，每轮只修改一个末位计数。

用 binary = "101" 走一遍

前缀    end0    end1    hasZero    总数
空       0       0       0         0
1        0       1       0         1
10       1       1       1         3
101      1       3       1         5

最后读到 1，新的 1 结尾组是 {"1", "11", "101"}，不是在旧组上再加 3；旧的 "1" 已经包含其中。

正确性证明：为什么覆盖不会漏掉旧字符串？

归纳不变量：处理完每个前缀后，两个状态分别等于该前缀中以 1 开头、以指定字符结尾的不同子序列数（模 MOD），标志记录单字符 "0" 是否存在。空前缀显然满足。

读入字符 c 时，新生成的 c 结尾字符串是“旧的以 1 开头的合法字符串 + c”；若 c 为 1，还包括单字符 "1"。追加相同字符是单射：不同前缀不可能变成相同结果；单字符 "1" 也不会与长度至少为 2 的结果重复。

任何旧的 c 结尾字符串也在新集合里：长度至少为 2 时，删去它的末位得到旧前缀中一个以 1 开头的合法字符串，可用当前 c 重新补回；长度为 1 的 "1" 则由单独加入项覆盖。所以新集合已经包含所有旧结果，只需覆盖计数。另一末位组无法由本轮追加生成，保持原值。

单字符 "0" 用布尔标志去重，三组两两不交且穷尽所有好子序列。不变量成立，最终求和正确。每步取模不改变最终余数。

边界与数值安全

  • 全是 0：两个末位计数始终为 0，答案为 1。
  • 全是 1：长度从 1 到 n 各有一种，答案为 n。
  • 开头连续 0 不能作为非零字符串的前导部分，只设置标志。
  • 单字符 "0" 和 "1" 的答案均为 1；空字符串不属于官方输入。
  • 每轮取模后，中间加法小于 2 × MOD + 1，JavaScript Number 可精确表示；Java / C++ 使用 64 位临时值更直观。

复杂度

提交算法时间 O(n)，辅助空间 O(1)（不计输入）。上方可视化为列举实际字符串使用集合与快照，最坏可有指数级结果，因此限制为 12 位；它不是提交实现。

替代方案

短串可以枚举所有非空下标子集，过滤前导 0 并放入集合，时间 O(n·2ⁿ)，集合存储最坏 O(n·2ⁿ)，不适用于 10⁵。也可保存每个前缀的两个状态数组以便回溯讲解，时间 O(n)、空间 O(n)；由于转移只依赖前一轮，滚动变量更合适。通用“不同子序列”DP 可以用上次出现位置扣重，但还需额外排除非法前导 0，状态更繁琐。

常见错误

  • 按下标方案数计数，导致 "11" 中单字符 "1" 被计两次。
  • 把 "0" 放进 end0 并参与拼接，生成带前导 0 的字符串。
  • 写成 end1 += end0 + end1 + 1，重复保留旧的 1 结尾结果。
  • 每遇到 0 就给答案加 1，忽略单字符 "0" 也需要去重。
  • 每轮同时更新两个末位状态，或只在最后取模而导致数值溢出。

面试追问

输入按流到达？保留三个状态即可在线更新。

如何扩展到十进制？维护 10 个末位计数；读到非零数字 d 时，将对应计数覆盖为所有合法非零开头计数之和加 1；读到 0 时不加单字符起点，仍单独维护 "0"。

为什么不能用答案大小比较集合是否包含？取模后的数值不保留大小关系，包含性必须在真实集合层面证明。

四语言提交代码

Java

class Solution {
    public int numberOfUniqueGoodSubsequences(String binary) {
        final long MOD = 1_000_000_007L;
        long end0 = 0, end1 = 0;
        int hasZero = 0;
        for (int i = 0; i < binary.length(); i++) {
            if (binary.charAt(i) == '0') {
                end0 = (end0 + end1) % MOD;
                hasZero = 1;
            } else {
                end1 = (end0 + end1 + 1) % MOD;
            }
        }
        return (int) ((end0 + end1 + hasZero) % MOD);
    }
}
