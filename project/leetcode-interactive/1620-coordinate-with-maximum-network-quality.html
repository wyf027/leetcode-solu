网络信号最好的坐标

Coordinate With Maximum Network Quality

数组枚举欧几里得距离非付费题

在一片离散坐标网格上，寻找所有可达信号叠加后最强的点。先理解传播规则，再观察扫描过程；完整解法收在页面底部。

Problem

题意

输入

每座塔用 [xᵢ, yᵢ, qᵢ] 表示：整数坐标 (xᵢ, yᵢ) 与质量参数 qᵢ。另给定最大传播半径 radius。

信号

点 (x,y) 与塔的欧几里得距离为 d。仅当 d ≤ radius 时，该塔贡献 ⌊qᵢ/(1+d)⌋。

输出

返回总信号质量最大的非负整数坐标 [cₓ,cᵧ]。若并列，先选更小的 x，再选更小的 y。

关键规则：半径边界上的塔仍然可达；每座塔的贡献先单独向下取整，再求和。
quality(x, y) = Σ ⌊qᵢ / (1 + √((x − xᵢ)² + (y − yᵢ)²))⌋，仅累加距离不超过 radius 的塔

官方示例

示例一

示例 1
输入：towers = [[1,2,5],[2,1,7],[3,1,9]], radius = 2
输出：[2,1]
解释：在 (2,1)，三座塔分别贡献 2、7、4，总质量为 13；不存在更高质量的整数坐标。

示例二

示例 2
输入：towers = [[23,11,21]], radius = 9
输出：[23,11]
解释：只有一座塔，塔自身坐标处距离为 0，信号质量最高。

示例三

示例 3
输入：towers = [[1,2,13],[2,1,7],[0,1,9]], radius = 2
输出：[1,2]
解释：(1,2) 的总信号质量最大。

约束

  • 1 ≤ towers.length ≤ 50
  • towers[i].length == 3
  • 0 ≤ xᵢ, yᵢ, qᵢ ≤ 50
  • 1 ≤ radius ≤ 50

Solution vault

完整题解

默认收起，准备好后再展开。

核心洞察：坐标范围很小，直接枚举

所有塔都位于 [0,50] × [0,50]。最优点可以限制在塔坐标的包围矩形内：若点跑到矩形外，把它投影回矩形只会让它到每座塔的距离不增，质量不会下降。于是枚举 0..maxX 与 0..maxY 的所有整数点即可。

完整过程

1
确定范围。取所有塔坐标的最大值 maxX、maxY。
2
按字典序扫描。外层枚举 x=0..maxX，内层枚举 y=0..maxY。
3
累加可达塔。使用平方距离判断 dx²+dy² ≤ radius²；可达时再开方计算并向下取整。
4
只在严格更优时更新。首次遇到某个最大值的点必然是字典序最小点，并列时保持原答案。

正确性证明

引理 1：包围矩形内存在一个全局最优解。任意矩形外的非负点投影到矩形后，到每座塔的横纵坐标差都不增加，所以欧几里得距离不增加；每座塔的贡献不会降低，总质量也不会降低。
引理 2：算法计算了每个候选点的真实总质量。它逐塔检查可达条件，并严格按照题目公式计算贡献，求和结果即该点网络质量。
定理：算法返回题目要求的坐标。由引理 1，枚举范围至少包含一个全局最优点；由引理 2，比较值准确。扫描顺序是字典序，且仅在严格更大时更新，因此最终保留所有最优点中字典序最小者。

复杂度

令 X=maxX+1、Y=maxY+1、塔数为 n。时间复杂度 O(XYn)；除返回值外，额外空间 O(1)。约束下最多约 51×51×50 次塔检查。

边界

  • 距离恰好等于半径时必须计入。
  • qᵢ=0 时贡献始终为 0。
  • 所有点质量均为 0 时答案为 [0,0]。
  • 距离比较先用平方值，避免无谓开方。

替代方案

也可以固定枚举整个 [0,50]²，证明更直观，复杂度同阶。按每座塔覆盖范围“撒贡献”仍要访问相似数量的网格点，代码更绕；本题无需空间索引或连续优化。

常见错误

  • 把各塔未取整的贡献先相加，最后统一向下取整。
  • 使用 distance < radius，错误排除半径边界。
  • 并列时使用 >= 更新，最后得到字典序更大的点。
  • 只枚举塔本身的坐标；多个塔的叠加峰值可能出现在其他整数点。
  • 没有把 [0,0] 纳入扫描，导致全零输入处理错误。

面试追问

  • 坐标上限变成 10⁹ 怎么办？需要利用影响半径局部化候选范围，或按覆盖区域建立空间索引；不能再扫完整包围盒。
  • 为什么可以只扫描包围矩形？矩形外点向矩形投影后，到所有塔的距离逐一不增。
  • 如何消除浮点边界风险？可达判断始终用整数平方距离；只有通过判断后，贡献公式才调用平方根。
  • 怎样支持动态增删塔？小网格可维护每个格点的总质量；更新一座塔时只修改其半径覆盖的格点。

class Solution {
    public int[] bestCoordinate(int[][] towers, int radius) {
        int maxX = 0, maxY = 0;
        for (int[] tower : towers) {
            maxX = Math.max(maxX, tower[0]);
            maxY = Math.max(maxY, tower[1]);
        }

        int bestX = 0, bestY = 0, bestQuality = -1;
        int radiusSquared = radius * radius;

        for (int x = 0; x <= maxX; x++) {
            for (int y = 0; y <= maxY; y++) {
                int quality = 0;
                for (int[] tower : towers) {
                    int dx = x - tower[0];
                    int dy = y - tower[1];
                    int distanceSquared = dx * dx + dy * dy;
                    if (distanceSquared <= radiusSquared) {
                        quality += (int) Math.floor(
                            tower[2] / (1.0 + Math.sqrt(distanceSquared))
                        );
                    }
                }
                if (quality > bestQuality) {
                    bestQuality = quality;
                    bestX = x;
                    bestY = y;
                }
            }
        }
        return new int[]{bestX, bestY};
    }
}
