矩形内船只的数目

Number of Ships in a Rectangle

Problem

题意转述

海面上的每艘船位于一个整数坐标点，任意一点最多一艘船。你不能直接读取船的坐标，只能调用 Sea.hasShips(topRight, bottomLeft)，询问一个闭合轴对齐矩形内是否至少有一艘船。请返回指定矩形内的船只总数。

矩形由右上角 topRight = [x₂, y₂] 与左下角 bottomLeft = [x₁, y₁] 给出，边界上的船也计入。交互接口有调用次数上限，因此不能逐点扫描。

评测接口：提交时实现 countShips(Sea sea, int[] topRight, int[] bottomLeft)（不同语言类型略有差异）。Sea 由评测器提供。

示例 1

ships = [[1,1],[2,2],[3,3],[5,5]] topRight = [4,4] bottomLeft = [0,0] 输出：3

询问范围覆盖前三艘船，不覆盖位于 [5,5] 的船。

示例 2

ships = [[1,1],[2,2],[3,3]] topRight = [1000,1000] bottomLeft = [0,0] 输出：3

整个给定海域包含三艘船。

约束

  • 0 ≤ bottomLeft[i] ≤ topRight[i] ≤ 1000
  • 所有船都位于整数坐标，且坐标互不重复。
  • 给定矩形内至多有 10 艘船。
  • hasShips 最多允许调用 400 次；超限会被判错。

Solution

题解：带空区剪枝的四分递归

核心洞察

接口只回答“有没有”，不能直接回答“有几艘”。但它非常适合剪枝：如果一个矩形没有船，整个分支立即贡献 0；如果矩形已经缩成一个整数点且有船，该点贡献 1。其余情况把矩形划为四个互不重叠的闭合整数子矩形，递归求和。

为什么不是二分一次？

船分布在二维平面。沿横纵中点同时切分，可以让宽和高一起缩小，并确保每个整数点恰好落入一个子矩形。空象限通过一次查询整体跳过。

完整过程

  1. 若 bottomLeft 超过 topRight，这是空矩形，返回 0。
  2. 调用 hasShips；若为假，返回 0。
  3. 若左右、上下边界都相等，矩形只剩一个整数点。此前已知有船，返回 1。
  4. 计算 midX = (left + right) / 2、midY = (bottom + top) / 2 的向下取整。
  5. 递归四个区间：左下、右下、左上、右上。用 mid + 1 开始右侧/上侧区间，避免重叠。

正确性证明

引理 1：若 hasShips 返回假，则当前矩形中的船数为 0。该结论直接来自接口定义，因此剪枝返回 0 正确。

引理 2：若当前矩形是单个整数点且 hasShips 为真，则其中恰有一艘船。因为每个坐标最多一艘船，所以返回 1 正确。

引理 3：四个子矩形两两不交，且并集恰为父矩形中的全部整数点。横坐标被分为 [left, midX] 与 [midX+1, right]，纵坐标同理，笛卡尔积正好得到四块。

定理：对矩形尺寸归纳。空区和单点由引理 1、2 正确处理；更大矩形依据引理 3 被无遗漏、无重复地划分，递归分别得到各块船数，求和即为父矩形船数。因此算法返回给定矩形中的准确船数。

复杂度

设坐标边长上限为 U，目标矩形内有 S 艘船。递归深度为 O(log U)；借助空区剪枝，常用上界写作 O(S log U) 次有效分裂量级，另含相邻空分支查询。空间为递归栈 O(log U)。在本题 S ≤ 10, U ≤ 1000 时可满足 400 次调用限制。

边界情况

  • 整个查询矩形没有船。
  • 矩形只有一个坐标点。
  • 船恰好位于边界或切分线附近。
  • 宽为 0 或高为 0 的线形矩形。
  • 四分后出现左边界大于右边界的空子矩形。

/**
 * // This is Sea's API interface.
 * // You should not implement it, or speculate about its implementation.
 * class Sea { public boolean hasShips(int[] topRight, int[] bottomLeft); }
 */
class Solution {
    public int countShips(Sea sea, int[] topRight, int[] bottomLeft) {
        int left = bottomLeft[0], bottom = bottomLeft[1];
        int right = topRight[0], top = topRight[1];
        if (left > right || bottom > top || !sea.hasShips(topRight, bottomLeft)) return 0;
        if (left == right && bottom == top) return 1;

        int midX = left + (right - left) / 2;
        int midY = bottom + (top - bottom) / 2;
        return countShips(sea, new int[]{midX, midY}, new int[]{left, bottom})
             + countShips(sea, new int[]{right, midY}, new int[]{midX + 1, bottom})
             + countShips(sea, new int[]{midX, top}, new int[]{left, midY + 1})
             + countShips(sea, new int[]{right, top}, new int[]{midX + 1, midY + 1});
    }
}
/**
 * @param {Sea} sea
 * @param {number[]} topRight
 * @param {number[]} bottomLeft
 * @return {number}
 */
var countShips = function (sea, topRight, bottomLeft) {
    const [right, top] = topRight;
    const [left, bottom] = bottomLeft;
    if (left > right || bottom > top || !sea.hasShips(topRight, bottomLeft)) return 0;
    if (left === right && bottom === top) return 1;

    const midX = Math.floor((left + right) / 2);
    const midY = Math.floor((bottom + top) / 2);
    return countShips(sea, [midX, midY], [left, bottom])
         + countShips(sea, [right, midY], [midX + 1, bottom])
         + countShips(sea, [midX, top], [left, midY + 1])
         + countShips(sea, [right, top], [midX + 1, midY + 1]);
};

        mid_y = (bottom + top) // 2

            self.countShips(sea, [mid_x, mid_y], [left, bottom])
            + self.countShips(sea, [right, mid_y], [mid_x + 1, bottom])
            + self.countShips(sea, [mid_x, top], [left, mid_y + 1])
            + self.countShips(sea, [right, top], [mid_x + 1, mid_y + 1])
        )

替代方案

也可每次只沿较长边二分，形成二叉递归。它同样正确，但二维均衡四分更贴合接口与坐标范围，推导也更直观。逐点扫描最多询问百万次，不可行。

面试追问

  • 若接口返回船数而非布尔值，怎样减少查询？
  • 若坐标不是整数，终止条件如何改？
  • 怎样缓存重复矩形查询？本方案为何本身不会重复？

常见错误

  • 四块都包含中点，导致重复计数。
  • 查询空矩形，浪费调用甚至触发接口异常。
  • 先判断单点却没有确认该点有船。
  • 枚举所有坐标，超过 400 次限制。
