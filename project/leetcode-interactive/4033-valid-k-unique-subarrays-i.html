OFFLINE RANGE QUERIES

有效 K 个不同元素
子数组 I

每个区间要同时过两道关：不同数字恰好为 k，并且每一种数字的出现次数都是偶数。查询多达 105 次，逐段统计会超时。

题目契约

输入
nums、k、queries[i] = [l, r]
输出
布尔数组；每项对应一个查询。
约束
n, queries.length ≤ 105，nums[i] ≤ 105
提交签名
validSubarrays(nums, k, queries)

WHY MO'S ALGORITHM?

把查询排成一条少走路的路线

莫队不按原输入顺序回答查询，而是按左端点分块、右端点蛇形排序。相邻查询的边界通常只移动很少几步；每移动一步，只更新一个数字的频次与两项全局计数。

TWO INVARIANTS

答案只看两只仪表

  • distinct：当前窗口内频次大于 0 的数字数量。
  • odd：当前窗口内频次为奇数的数字数量。
  • 查询有效当且仅当 distinct === k && odd === 0。

窗口移动时，先撤销旧状态，再加入新状态

操作 频次变化前 更新 频次变化后
add(x) 0 → 新出现 distinct++；若原频次为奇数，odd--；否则 odd++ freq[x]++
remove(x) 删除前为 1 → 消失 若原频次为奇数，odd--；否则 odd++；必要时 distinct-- freq[x]--

排序后处理每个查询：用 while 循环把当前窗口的四条边推到目标区间。答案记录在原查询编号处，因此输出顺序不会改变。

class Solution {
  public List<Boolean> validSubarrays(int[] nums, int k, int[][] queries) {
    int n = nums.length, m = queries.length, block = (int) Math.sqrt(n) + 1;
    int[][] q = new int[m][3];
    for (int i = 0; i < m; i++) { q[i] = new int[]{queries[i][0], queries[i][1], i}; }
    Arrays.sort(q, (a, b) -> a[0] / block != b[0] / block ? Integer.compare(a[0] / block, b[0] / block) : ((a[0] / block & 1) == 0 ? Integer.compare(a[1], b[1]) : Integer.compare(b[1], a[1])));
    int[] freq = new int[100001]; boolean[] ans = new boolean[m]; int l = 0, r = -1, distinct = 0, odd = 0;
    for (int[] x : q) { while (l > x[0]) { int v = nums[--l]; if (freq[v]++ == 0) distinct++; odd += (freq[v] & 1) == 1 ? 1 : -1; } while (r < x[1]) { int v = nums[++r]; if (freq[v]++ == 0) distinct++; odd += (freq[v] & 1) == 1 ? 1 : -1; } while (l < x[0]) { int v = nums[l++]; odd += (freq[v] & 1) == 1 ? -1 : 1; if (--freq[v] == 0) distinct--; } while (r > x[1]) { int v = nums[r--]; odd += (freq[v] & 1) == 1 ? -1 : 1; if (--freq[v] == 0) distinct--; } ans[x[2]] = distinct == k && odd == 0; }
    List<Boolean> out = new ArrayList<>(); for (boolean v : ans) out.add(v); return out;
  }
}

var validSubarrays = function(nums, k, queries) {
  const n = nums.length, block = Math.floor(Math.sqrt(n)) + 1;
  const q = queries.map(([l, r], id) => [l, r, id]).sort((a,b) => Math.floor(a[0]/block) - Math.floor(b[0]/block) || ((Math.floor(a[0]/block)&1) ? b[1]-a[1] : a[1]-b[1]));
  const freq = new Int32Array(100001), ans = Array(queries.length); let l=0,r=-1,distinct=0,odd=0;
  const add = v => { if (freq[v]++ === 0) distinct++; odd += freq[v] & 1 ? 1 : -1; };
  const remove = v => { odd += freq[v] & 1 ? -1 : 1; if (--freq[v] === 0) distinct--; };
  for (const [ql,qr,id] of q) { while(l>ql)add(nums[--l]); while(r<qr)add(nums[++r]); while(l<ql)remove(nums[l++]); while(r>qr)remove(nums[r--]); ans[id]=distinct===k && odd===0; }
  return ans;

class Solution:
    def validSubarrays(self, nums: List[int], k: int, queries: List[List[int]]) -> List[bool]:
        n, block = len(nums), int(len(nums) ** .5) + 1
        q = sorted(((l, r, i) for i, (l, r) in enumerate(queries)), key=lambda x: (x[0] // block, x[1] if (x[0] // block) % 2 == 0 else -x[1]))
        freq, ans, l, r, distinct, odd = [0] * 100001, [False] * len(q), 0, -1, 0, 0
        def add(v):
            nonlocal distinct, odd
            if freq[v] == 0: distinct += 1
            freq[v] += 1; odd += 1 if freq[v] & 1 else -1
        def remove(v):
            nonlocal distinct, odd
            odd += -1 if freq[v] & 1 else 1; freq[v] -= 1
            if freq[v] == 0: distinct -= 1
        for ql, qr, i in q:
            while l > ql: l -= 1; add(nums[l])
            while r < qr: r += 1; add(nums[r])
            while l < ql: remove(nums[l]); l += 1
            while r > qr: remove(nums[r]); r -= 1
            ans[i] = distinct == k and odd == 0
        return ans

复杂度与边界

时间

典型莫队复杂度约为 O((n + q)√n)。

空间

O(n + V)：查询数组与值域频次数组。

别踩坑

删除前先根据旧频次更新 odd；输出必须按原查询编号回填。
