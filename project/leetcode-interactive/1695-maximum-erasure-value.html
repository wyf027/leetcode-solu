01

题目

给定正整数数组 nums，请选择并删除一个元素互不相同的连续子数组。这次删除的得分等于子数组内所有元素之和，返回只删除一个子数组能够获得的最大得分。

子数组必须连续。也就是存在下标 l 与 r，所选内容恰好为 nums[l], nums[l+1], …, nums[r]。

输入

解释最优子数组为 [2,4,5,6]，元素互不相同，总和为 17。

题解

已经形成自己的思路了吗？

题解默认收起。展开后将看到核心洞察、证明、边界、复杂度、替代方案与四种语言的完整实现。

核心洞察：正数让窗口可以贪心保留

维护一个元素互不相同的窗口 [left, right] 和窗口和。右端加入 nums[right] 前，如果该值已在窗口中，就不断从左端移除元素，直到重复值离开窗口；再加入新值并更新最大和。

由于所有元素均为正数，在固定右端点时，满足“不重复”的最长窗口也拥有最大的元素和，因此无需枚举更短的合法后缀。

完整过程

  1. 建立集合 seen，记录当前窗口内的值；令 left = 0、sum = 0、best = 0。
  2. 从左到右枚举 right。若新值已经存在，循环移除 nums[left]，同步扣减窗口和并右移 left。
  3. 把新值加入集合与窗口和，用 best = max(best, sum) 更新答案。
  4. 扫描结束后返回 best。

正确性证明

不变式：每轮处理完 right 后，窗口 [left, right] 中的元素互不相同，而且它是以 right 结尾的最长合法窗口。

保持：若新值不重复，直接加入仍然合法；若重复，算法从左侧删除至旧的同值元素被移出，此时新值可安全加入。再少删除一个元素会保留重复，因此当前窗口确为最长。

最优性：所有数均为正，以同一右端点结尾的合法窗口越长，总和越大。所以该最长合法窗口就是该右端点下得分最高的窗口。算法比较了每个右端点的最优得分，最终得到全局最大值。

边界情况

  • 只有一个元素：该元素本身是唯一可选子数组。
  • 全部不同：窗口从不收缩，答案是全数组之和。
  • 全部相同：窗口长度始终至多为 1，答案等于该值。
  • 重复值相邻或隔得很远：都由同一段收缩循环处理。
  • 最大规模：总和至多 10^5 × 10^4 = 10^9，32 位有符号整数仍可容纳。

复杂度

时间O(n)每个元素至多进出窗口一次
空间O(k)k 为窗口内不同值数，最坏 O(n)

替代方案

最后出现位置 + 前缀和：记录每个值最近一次出现的下标，并令 left = max(left, last[value] + 1)；使用前缀和在 O(1) 内取得当前窗口和。时间同为 O(n)，但需要额外前缀数组。

暴力枚举：从每个起点向右扩展到首次重复，最坏 O(n²)，在 10^5 规模下不可行。

面试追问

  • 如果数组允许负数，为什么“最长合法窗口得分最高”不再成立？如何修改？
  • 能否用最近出现位置一次跳过重复段？怎样同步维护窗口和？
  • 如果要求返回最优子数组的左右下标，应保存哪些状态？
  • 如果元素值域很小，能否用计数数组替代哈希集合？

常见错误

  • 遇到重复值只移除一个左端元素；正确做法是持续收缩，直到重复值不在窗口。
  • 从集合删除了左端值，却忘记从 sum 中扣除它。
  • 在收缩之前就把重复值加入集合，导致集合状态与窗口不一致。
  • 误把“子数组”当成可跳跃选择的“子序列”。
  • 忽略题目全为正数这一条件；它是最长合法窗口同时最大和的关键。

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int maximumUniqueSubarray(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        int left = 0;
        int sum = 0;
        int best = 0;

        for (int right = 0; right < nums.length; right++) {
            while (seen.contains(nums[right])) {
                seen.remove(nums[left]);
                sum -= nums[left];
                left++;
            }
            seen.add(nums[right]);
            sum += nums[right];
            best = Math.max(best, sum);
        }
        return best;
    }
}

from typing import List


class Solution:
    def maximumUniqueSubarray(self, nums: List[int]) -> int:
        seen = set()
        left = 0
        window_sum = 0
        best = 0

        for value in nums:
            while value in seen:
                seen.remove(nums[left])
                window_sum -= nums[left]
                left += 1
            seen.add(value)
            window_sum += value
            best = max(best, window_sum)

        return best
#include <algorithm>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    int maximumUniqueSubarray(vector<int>& nums) {
        unordered_set<int> seen;
        int left = 0;
        int sum = 0;
        int best = 0;

        for (int right = 0; right < static_cast<int>(nums.size()); ++right) {
            while (seen.count(nums[right])) {
                seen.erase(nums[left]);
                sum -= nums[left];
                ++left;
            }
            seen.insert(nums[right]);
            sum += nums[right];
            best = max(best, sum);
        }
        return best;
    }
};
