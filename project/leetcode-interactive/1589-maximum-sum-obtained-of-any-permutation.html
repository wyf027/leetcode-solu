01 · Problem

题意与边界

每个请求都会读取一个闭区间。你只能重排数值，不能改变请求的区间。

准确转述

给定整数数组 nums 与请求数组 requests。每个 [start, end] 表示对当前排列中下标从 start 到 end（两端都包含）的元素求和。

允许任意排列 nums，求所有请求所得区间和的总和能够达到的最大值。答案对 1,000,000,007 取余。

约束

  • n == nums.length
  • 1 ≤ n ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁵
  • 1 ≤ requests.length ≤ 10⁵
  • requests[i].length == 2
  • 0 ≤ startᵢ ≤ endᵢ < n

示例 1

输入nums = [1,2,3,4,5], requests = [[1,3],[0,1]]
输出19

例如排列为 [3,5,4,2,1] 时，两个请求分别得到 11 与 8，总和为 19，且无法更大。

示例 2

输入nums = [1,2,3,4,5,6], requests = [[0,1]]
输出11

可将 6 和 5 放入唯一请求覆盖的两个位置。

示例 3

输入nums = [1,2,3,4,5,10], requests = [[0,2],[1,3],[1,1]]
输出47

一种最优排列为 [4,10,5,3,2,1]，三个区间和依次为 19、18、10。

04 · Solution

准备好揭晓规律了吗？

下面包含核心洞察、证明、完整代码与面试追问。

核心洞察

把区间和改写成“数值 × 出现次数”

所有请求的总和等于每个位置上的数值乘以该位置被请求覆盖的次数，再把这些乘积相加。先用差分数组在线性时间内求出每个位置的覆盖频次，然后将 nums 和频次数组都升序排序并逐项相乘。

完整过程

  1. 创建长度 n + 1 的差分数组 diff。
  2. 对每个闭区间 [l, r]，执行 diff[l]++ 与 diff[r + 1]--。
  3. 对 diff 求前缀和，得到每个下标的覆盖频次 freq。
  4. 分别升序排序 nums 和 freq。
  5. 累加 nums[i] × freq[i]，并在过程中取模。

为什么正确

等价变形。 每个请求对某位置的贡献是该位置的数值；一个位置被覆盖 freq[i] 次，就总共贡献 value[i] × freq[i]。
交换论证。 假设频次 a ≤ b 却给它们分配了数值 x > y。当前贡献为 ax + by；交换后为 ay + bx，差值是 (b-a)(x-y) ≥ 0。因此逆序配对不会更优。
全局最优。 不断交换所有逆序配对，最终得到数值和频次同序排列，贡献不减，所以同序排序达到最大值。

边界情况

  • 单元素数组：所有请求只能覆盖下标 0，直接累加其重复贡献。
  • nums 可含 0；零应自然匹配较小频次。
  • 请求端点包含 n - 1 时，使用长度 n + 1 的差分数组可安全写入 r + 1。
  • 乘积总和可能很大；Java/C++ 使用 64 位整数，JavaScript 使用 BigInt，最终再取模。

替代方案

可以对每个请求直接遍历区间来统计频次，但最坏复杂度达到 O(n · m)，无法承受 10⁵ 规模。也可用树状数组完成区间加、单点查，但这里只需离线统计一次，差分数组更短、更快且空间相同。

复杂度

时间O(n log n + m)
空间O(n)

常见错误

  • 忘记在 r + 1 处减一。
  • 只排序 nums，没有同步排序频次。
  • 把闭区间误当成半开区间。
  • 乘法前使用 32 位整数导致溢出。
  • 用取模后的值参与排序。

面试追问

  • 若 nums 允许负数，策略是否改变？
  • 若请求在线加入，如何维护频次？
  • 为什么同序配对最大，而非交错配对？
  • 能否恢复出一种具体最优排列？

四种语言实现

Java 
import java.util.Arrays;

class Solution {
    public int maxSumRangeQuery(int[] nums, int[][] requests) {
        final long MOD = 1_000_000_007L;
        int n = nums.length;
        int[] freq = new int[n + 1];

        for (int[] request : requests) {
            int left = request[0];
            int right = request[1];
            freq[left]++;
            freq[right + 1]--;
        }

        for (int i = 1; i < n; i++) {
            freq[i] += freq[i - 1];
        }

        Arrays.sort(nums);
        Arrays.sort(freq, 0, n);

        long answer = 0;
        for (int i = 0; i < n; i++) {
            answer = (answer + (long) nums[i] * freq[i]) % MOD;
        }
        return (int) answer;
    }
}

/**
 * @param {number[]} nums
 * @param {number[][]} requests
 * @return {number}

var maxSumRangeQuery = function(nums, requests) {
    const MOD = 1000000007n;
    const n = nums.length;
    const freq = new Array(n + 1).fill(0);

    for (const [left, right] of requests) {
        freq[left]++;
        freq[right + 1]--;
    }

    for (let i = 1; i < n; i++) {
        freq[i] += freq[i - 1];
    }

    nums.sort((a, b) => a - b);
    const sortedFreq = freq.slice(0, n).sort((a, b) => a - b);

    let answer = 0n;
    for (let i = 0; i < n; i++) {
        answer = (answer + BigInt(nums[i]) * BigInt(sortedFreq[i])) % MOD;
    }
    return Number(answer);
};
Python 
from typing import List

class Solution:
    def maxSumRangeQuery(
        self,
        nums: List[int],
        requests: List[List[int]]
    ) -> int:
        mod = 10**9 + 7
        n = len(nums)
        diff = [0] * (n + 1)

        for left, right in requests:
            diff[left] += 1
            diff[right + 1] -= 1

        for i in range(1, n):
            diff[i] += diff[i - 1]

        nums.sort()
        frequencies = sorted(diff[:n])

        answer = sum(
            value * frequency
            for value, frequency in zip(nums, frequencies)
        )
        return answer % mod
C++ 
class Solution {
public:
    int maxSumRangeQuery(
        vector<int>& nums,
        vector<vector<int>>& requests
    ) {
        static constexpr long long MOD = 1'000'000'007LL;
        const int n = static_cast<int>(nums.size());
        vector<int> freq(n + 1, 0);

        for (const auto& request : requests) {
            const int left = request[0];
            const int right = request[1];
            ++freq[left];
            --freq[right + 1];
        }

        for (int i = 1; i < n; ++i) {
            freq[i] += freq[i - 1];
        }

        sort(nums.begin(), nums.end());
        sort(freq.begin(), freq.begin() + n);

        long long answer = 0;
        for (int i = 0; i < n; ++i) {
            answer = (answer + 1LL * nums[i] * freq[i]) % MOD;
        }
        return static_cast<int>(answer);
    }
};
