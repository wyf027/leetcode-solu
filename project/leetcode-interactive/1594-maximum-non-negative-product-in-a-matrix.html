题意转述

给定一个 m × n 整数矩阵 grid。从左上角 (0, 0) 出发，每一步只能向右或向下，直到右下角 (m - 1, n - 1)。一条路径的乘积等于沿途所有单元格数字的乘积。

在全部合法路径中，返回最大的非负路径乘积对 10⁹ + 7 取余的结果。如果所有路径乘积都为负数，返回 -1。必须先比较出真实最大乘积，最后才取模。

  1. 01起点与终点
    从左上到右下，起终点都计入乘积。
  2. 02移动方向
    只能向右或向下，不能回退。
  3. 03返回规则
    答案非负才取模；负数答案返回 -1。
示例 1全为负
输入：grid = [[-1,-2,-3],
              [-2,-3,-3],
              [-3,-3,-2]]
输出：-1
解释：没有路径能得到非负乘积。
示例 2负负得正
输入：grid = [[1,-2,1],
              [1,-2,1],
              [3,-4,1]]
输出：8
解释：1 × 1 × -2 × -4 × 1 = 8。
示例 3零路径
输入：grid = [[1,3],
              [0,-4]]
输出：0
解释：1 × 0 × -4 = 0。

完整题解刻意与题面分开。展开后包含推导、证明、复杂度、四语言代码与面试追问。

01 / STATE

每格存两个极值

到达同一个格子的路径，只需保留当前最大乘积和最小乘积。

02 / SIGN

负数让角色互换

乘以负数后，原来的最小值可能变成新的最大值，因此不能只存最大值。

03 / MOD

最后再取模

中途取模会破坏大小与符号语义，必须先得到真实极值。

核心洞察

位置 (i, j) 只可能从上方 (i-1, j) 或左方 (i, j-1) 到达。若当前值是正数，前驱最大值仍倾向产生最大值；若当前值是负数，前驱最小值乘它反而可能最大。所以为每个格子同时维护最大乘积 maxDP 与最小乘积 minDP。

完整过程

  1. 起点的最大值与最小值都等于 grid[0][0]。
  2. 按行扫描。收集上方、左方已存在的最大值与最小值，各自乘当前格值。
  3. 全部候选中的最大值写入当前格的 maxDP，最小值写入 minDP。
  4. 观察终点最大值：若小于 0 返回 -1，否则对 1_000_000_007 取模后返回。
candidates = { maxDP[top] × grid[i][j], minDP[top] × grid[i][j], maxDP[left] × grid[i][j], minDP[left] × grid[i][j] } maxDP[i][j] = max(candidates) minDP[i][j] = min(candidates)

正确性证明

归纳命题：处理完任意格子 (i, j) 后，maxDP[i][j] 与 minDP[i][j] 分别等于所有从起点到该格子的路径乘积最大值与最小值。

基础：起点只有一条长度为 1 的路径，两种极值都等于起点元素，命题成立。

归纳：到达当前格子的任意路径，最后一步必来自上方或左方。对固定当前乘数，乘积关于前驱乘积是单调递增（当前值非负）或单调递减（当前值为负），因此每个前驱只需其最大、最小两个端点。枚举两个前驱的端点乘积后取最大与最小，恰好覆盖当前格的真实两端。由归纳法，终点最大状态即所有完整路径中的最大乘积。按题意处理负值与最终取模，返回值正确。

边界情况

  • 只有一行或一列：每格只有一个前驱，转移仍然成立。
  • 包含 0：最大值或最小值可以变为 0；若不存在正积，0 仍是合法非负答案。
  • 起点或终点为负：无需特判，双极值状态会自然处理。
  • 数值范围：路径最多经过 29 个格子，绝对值最多为 4²⁹ = 2⁵⁸；Java/C++ 的 64 位整数足够。JavaScript 必须使用 BigInt 避免超过安全整数范围。
  • 取模：不得在转移过程中取模，否则大小关系会改变。

复杂度

时间复杂度为 O(mn)，每个格子只处理常数个候选。二维写法空间复杂度为 O(mn)；还可压缩到 O(n)。下方代码采用二维状态以保持可读性。

替代方案

DFS 枚举全部路径会在最坏情况下呈指数级增长。记忆化搜索可以返回每个位置的最大/最小后缀乘积，本质与双状态动态规划相同。只存最大值则会在负数翻转时丢失未来可能成为最大值的最小负积。

class Solution {
    public int maxProductPath(int[][] grid) {
        final long MOD = 1_000_000_007L;
        int m = grid.length, n = grid[0].length;
        long[][] maxDp = new long[m][n];
        long[][] minDp = new long[m][n];

        maxDp[0][0] = grid[0][0];
        minDp[0][0] = grid[0][0];

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (i == 0 && j == 0) continue;
                long value = grid[i][j];
                long currentMax = Long.MIN_VALUE;
                long currentMin = Long.MAX_VALUE;

                if (i > 0) {
                    long a = maxDp[i - 1][j] * value;
                    long b = minDp[i - 1][j] * value;
                    currentMax = Math.max(currentMax, Math.max(a, b));
                    currentMin = Math.min(currentMin, Math.min(a, b));
                }
                if (j > 0) {
                    long a = maxDp[i][j - 1] * value;
                    long b = minDp[i][j - 1] * value;
                    currentMax = Math.max(currentMax, Math.max(a, b));
                    currentMin = Math.min(currentMin, Math.min(a, b));
                }
                maxDp[i][j] = currentMax;
                minDp[i][j] = currentMin;
            }
        }

        long answer = maxDp[m - 1][n - 1];
        return answer < 0 ? -1 : (int) (answer % MOD);
    }
}

 * @param {number[][]} grid
 * @return {number}

var maxProductPath = function(grid) {
    const MOD = 1000000007n;
    const m = grid.length;
    const n = grid[0].length;
    const maxDp = Array.from({ length: m }, () => Array(n));
    const minDp = Array.from({ length: m }, () => Array(n));

    maxDp[0][0] = BigInt(grid[0][0]);
    minDp[0][0] = BigInt(grid[0][0]);

    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            if (i === 0 && j === 0) continue;
            const value = BigInt(grid[i][j]);
            const candidates = [];

            if (i > 0) {
                candidates.push(maxDp[i - 1][j] * value);
                candidates.push(minDp[i - 1][j] * value);
            }
            if (j > 0) {
                candidates.push(maxDp[i][j - 1] * value);
                candidates.push(minDp[i][j - 1] * value);
            }

            maxDp[i][j] = candidates.reduce(
                (best, x) => x > best ? x : best
            );
            minDp[i][j] = candidates.reduce(
                (best, x) => x < best ? x : best
            );
        }
    }

    const answer = maxDp[m - 1][n - 1];
    return answer < 0n ? -1 : Number(answer % MOD);
};

from typing import List


class Solution:
    def maxProductPath(self, grid: List[List[int]]) -> int:
        MOD = 10**9 + 7
        m, n = len(grid), len(grid[0])
        max_dp = [[0] * n for _ in range(m)]
        min_dp = [[0] * n for _ in range(m)]

        max_dp[0][0] = grid[0][0]
        min_dp[0][0] = grid[0][0]

        for i in range(m):
            for j in range(n):
                if i == 0 and j == 0:
                    continue
                value = grid[i][j]
                candidates = []

                if i > 0:
                    candidates.append(max_dp[i - 1][j] * value)
                    candidates.append(min_dp[i - 1][j] * value)
                if j > 0:
                    candidates.append(max_dp[i][j - 1] * value)
                    candidates.append(min_dp[i][j - 1] * value)

                max_dp[i][j] = max(candidates)
                min_dp[i][j] = min(candidates)

        answer = max_dp[m - 1][n - 1]
        return -1 if answer < 0 else answer % MOD
class Solution {
public:
    int maxProductPath(vector<vector<int>>& grid) {
        static constexpr long long MOD = 1'000'000'007LL;
        int m = grid.size(), n = grid[0].size();
        vector<vector<long long>> maxDp(m, vector<long long>(n));
        vector<vector<long long>> minDp(m, vector<long long>(n));

        maxDp[0][0] = grid[0][0];
        minDp[0][0] = grid[0][0];

        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (i == 0 && j == 0) continue;
                long long value = grid[i][j];
                long long currentMax = LLONG_MIN;
                long long currentMin = LLONG_MAX;

                auto relax = [&](long long previous) {
                    long long product = previous * value;
                    currentMax = max(currentMax, product);
                    currentMin = min(currentMin, product);
                };

                if (i > 0) {
                    relax(maxDp[i - 1][j]);
                    relax(minDp[i - 1][j]);
                }
                if (j > 0) {
                    relax(maxDp[i][j - 1]);
                    relax(minDp[i][j - 1]);
                }

                maxDp[i][j] = currentMax;
                minDp[i][j] = currentMin;
            }
        }

        long long answer = maxDp[m - 1][n - 1];
        return answer < 0 ? -1 : static_cast<int>(answer % MOD);
    }
};

面试追问

为什么不能只存最大值？

乘以负数后，最小的负积可能变成最大的正积。丢掉最小值就无法恢复这条候选路径。

能否压缩空间？

可以。逐行扫描时，每列保留一对最大/最小值；更新当前列前，它代表上方，更新后的前一列代表左方，空间降为 O(n)。

为什么最后才取模？

取模不保持数值大小关系。提前取模后，“更大的真实乘积”可能得到更小的余数，从而选错路径。

是否需要记录具体路径？

本题只要求乘积，无需记录。若要求恢复路径，可为最大、最小状态分别保存前驱指针，再从终点回溯。

常见错误

  • 只记录最大乘积，忽略最小负积可能翻转为最大正积。
  • 在每一步取模，导致后续比较结果失真。
  • 把答案为 0 当成失败；0 是合法的非负乘积。
  • JavaScript 使用 Number 保存全部乘积，超过 Number.MAX_SAFE_INTEGER 后失去整数精度。
  • 首行、首列直接填前缀积却忘记同时更新最大和最小状态。
