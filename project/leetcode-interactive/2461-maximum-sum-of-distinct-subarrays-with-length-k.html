长度为 K 子数组中的最大和

Maximum Sum of Distinct Subarrays With Length K

从连续片段中做选择：长度恰好是 k，每个数都只出现一次。你能找出其中最大的和吗？

01 / 题意与输入

给定整数数组 nums 和整数 k。在所有长度恰好为 k、且元素两两不同的连续子数组中，返回最大的元素和。如果没有符合要求的子数组，则返回 0。

子数组必须连续、非空，不能跳过中间的元素。返回的是一个数值，并非子数组本身。

maximumSubarraySum(nums: integer[], k: integer) → long

官方约束

  • 1 ≤ k ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁵

04 / 独立题解

展开后可逐步观察窗口、频次与候选答案。

核心洞察：长度固定，移动时只换两端

相邻两个长度为 k 的窗口共享 k−1 个位置。维护当前和 sum 以及频次表 freq：右端加入一个数，超长时左端移出一个数，就能得到新窗口。

只保留频次大于 0 的键。窗口长度恰好为 k 时，freq.size === k 等价于所有元素互不相同。只有此时才能用当前和更新最大答案。

完整过程

  1. 初始化空频次表、窗口和 0、答案 0。
  2. 遍历右端下标 r，把 nums[r] 加入和与频次表。
  3. 若 r ≥ k，移出 nums[r−k]：从和中减去它，频次减 1；降到 0 时删除该键。
  4. 若 r ≥ k−1 且频次表键数为 k，说明窗口完整且无重复，更新答案。
  5. 遍历结束，返回答案；不存在合法窗口时答案保持为 0。

示例 1 的完整窗口和为 10 → 11 → 15 → 20 → 27。后两者虽然更大，却有重复值，不能更新答案；最终保留 15。

正确性：三个不变式

范围准确。每次处理 r 并完成必要的移出后，维护的范围恰好是 [max(0,r−k+1), r]。归纳地看，上一范围先向右增加一项，超出 k 时恰好去掉最左项。

统计准确。每次入窗与出窗都同步修改和与频次，零频键被删除。因此 sum 等于范围内元素之和，表中记录且仅记录当前存在的不同值。当长度为 k 时，k 个位置有 k 个不同值，恰好等价于无重复。

最优值准确。答案从 0 开始，只与合法完整窗口的和取最大值，因此始终等于已经扫描的所有合法窗口的最大和。每个长度为 k 的窗口均以唯一的右端 r 被判定一次，所以结束时覆盖所有候选。元素为正保证无合法窗口返回 0 的初始化也适用于最大值维护。

复杂度与边界

  • 哈希表操作按期望 O(1) 计，每个元素最多加入与移出各一次：期望时间 O(n)。
  • 表中最多暂存 k+1 个不同值：额外空间 O(k)。教学演示保存步骤快照，空间开销与提交版不同。
  • k=1 时每个单元素窗口都合法；k=n 时只判定完整数组一次。
  • 无合法窗口返回 0；同值进出也要分别加减次数，不能直接把这个值删除。
  • 和可超过 32 位有符号整数。例如 1 到 100000 的和为 5,000,050,000。Java 使用 long，C++ 使用 long long；Python 整数自动扩展，JavaScript Number 在本题范围内可精确表示整数（和不超过 10¹⁰，低于 2⁵³−1）。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public long maximumSubarraySum(int[] nums, int k) {
        Map<Integer, Integer> freq = new HashMap<>();
        long sum = 0, best = 0;
        for (int r = 0; r < nums.length; r++) {
            int x = nums[r];
            sum += x;
            freq.put(x, freq.getOrDefault(x, 0) + 1);
            if (r >= k) {
                int y = nums[r - k];
                sum -= y;
                int count = freq.get(y) - 1;
                if (count == 0) freq.remove(y);
                else freq.put(y, count);
            }
            if (r >= k - 1 && freq.size() == k) {
                best = Math.max(best, sum);
            }
        }
        return best;
    }
}

Python 3

from typing import List

class Solution:
    def maximumSubarraySum(self, nums: List[int], k: int) -> int:
        freq = {}
        total = best = 0
        for r, x in enumerate(nums):
            total += x
            freq[x] = freq.get(x, 0) + 1
            if r >= k:
                y = nums[r - k]
                total -= y
                freq[y] -= 1
                if freq[y] == 0:
                    del freq[y]
            if r >= k - 1 and len(freq) == k:
                best = max(best, total)
        return best

C++

#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    long long maximumSubarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> freq;
        long long sum = 0, best = 0;
        for (int r = 0; r < static_cast<int>(nums.size()); ++r) {
            int x = nums[r];
            sum += x;
            ++freq[x];
            if (r >= k) {
                int y = nums[r - k];
                sum -= y;
                if (--freq[y] == 0) freq.erase(y);
            }
            if (r >= k - 1 && static_cast<int>(freq.size()) == k) {
                best = max(best, sum);
            }
        }
        return best;
    }
};

替代方案

  • 逐窗口枚举：每个窗口重新求和并检查重复，时间 O(nk)、额外空间 O(k)。易理解，但在 n、k 较大时开销过高。
  • 值域频次数组：利用 nums[i] ≤ 100000，分配长度 100001 的数组，并维护不同值计数。时间 O(n+U)、空间 O(U)，U=100001；避免哈希，但固定占用更多空间。
  • 上次出现位置：维护最长无重复后缀的左边界；若后缀长度至少为 k，则以当前右端结束的最后 k 项合法。结合前缀和或固定长度滚动和可做到期望 O(n) 时间，表空间 O(min(n,U))。

常见错误

  • 只维护 Set，出窗时直接删除值：如果窗口里还有另一个相同值，集合会错误地丢失它。频次数组或 Map 才能区分多个副本。
  • 频次归零但不删键：Map 的 size 会把历史值算进去。
  • 在移出旧值前判定：临时 k+1 个元素的和不能当作答案。
  • 只检查“无重复”，忽略长度等于 k；或把子数组误解为可以跳选的子序列。
  • 窗口出现重复就清空全部统计：会丢失之后窗口需要的重叠部分。
  • Java / C++ 用 32 位变量保存和：大输入会溢出。

面试追问

如果允许负数？窗口维护照常，但不能用 0 作为“已经找到合法窗口”的最大值；需加 found 标记或用负无穷初始化，最后仅在未找到时返回 0。

如果还要返回窗口下标？更新最大值时同时保存 r−k+1 和 r，并事先约定相同和时选择最早还是最晚窗口。

如果数据流无法回看数组？用长度为 k 的队列或环形缓冲区保存即将出窗的值，继续维护频次与和。

如果窗口内允许最多一种值重复？额外维护“频次至少为 2 的值的数量”，在频次跨过 1↔2 时更新它，并替换合法性条件。
