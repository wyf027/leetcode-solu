1832. 判断句子是否为全字母句

Check if the Sentence Is Pangram

26 个字母，一个判断。先阅读题目，想想怎样识别一段文字是否覆盖整张字母表。

01 / 题目

给定字符串 sentence，其中只含小写英文字母。如果 a 到 z 每个字母都至少出现一次，返回 true；否则返回 false。同一个字母可以重复出现。

官方示例 1

输入：sentence = "thequickbrownfoxjumpsoverthelazydog"
输出：true

所有 26 个英文字母均至少出现一次。

官方示例 2

输入：sentence = "leetcode"
输出：false

有字母未出现，因此不是全字母句。

约束：1 ≤ sentence.length ≤ 1000；sentence 仅由小写英文字母组成。

参数：sentence: string · 返回：boolean · 官方题目

04 / 独立题解

准备好后再展开思路、证明与四种语言实现。

核心洞察：只关心是否出现

字母出现一次与出现十次，对答案的贡献相同。使用集合记录见过的字母；输入只允许 a–z，因此集合大小等于 26 就是充分且必要条件。

完整过程

  1. 建立空集合 seen。
  2. 从左到右读取 sentence，把当前字符加入 seen。集合自动去重。
  3. 全部读完后，判断 seen 的大小是否等于 26。

以 leetcode 为例，集合大小依次为 1、2、2、3、4、5、6、6，最终只有 6 种字母，返回 false。护照演示对应集合的状态；为支持后退，界面根据当前前缀重新生成展示状态。

正确性

不变式：处理前 k 个字符后，seen 恰好包含这 k 个字符中出现过的所有不同字母。初始 k=0，空集合满足条件；读入下一个字符时，将它加入集合，既不会丢失已有字母，也不会加入未读到的字母，因此条件保持。遍历结束后，seen 就是整个输入的字母集合。因为它是 26 个小写字母的子集，大小为 26 当且仅当全部字母都出现，返回值正确。

边界与复杂度

长度小于 26 时必为 false；长度大于等于 26 仍可能缺字母。重复出现不会影响集合大小。题目不包含空串、空格、大写字母或标点，提交实现直接使用该约束。

设 n 为字符串长度，集合插入按通常均摊 O(1) 计，时间 O(n)，额外空间 O(26)=O(1)。这是提交算法的复杂度；交互界面的字符带与前缀重建另需 O(n) 展示资源。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean checkIfPangram(String sentence) {
        Set<Character> seen = new HashSet<>();
        for (int i = 0; i < sentence.length(); i++) {
            seen.add(sentence.charAt(i));
        }
        return seen.size() == 26;
    }
}

JavaScript

/**

C++

#include <string>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool checkIfPangram(string sentence) {
        unordered_set<char> seen(sentence.begin(), sentence.end());
        return seen.size() == 26;
    }
};

替代方案

  • 布尔数组：用 26 个位置记录字符是否出现，索引为字符减去 'a'，最后检查全部为真。时间 O(n)，空间 O(1)，避免哈希开销。
  • 位掩码：对每个字符执行 mask |= 1 << (字符编号)，最终与 (1 << 26) - 1 比较。26 位可装入常见 32 位整数；JavaScript 的位运算在此范围也可用。
  • 提前返回：集合大小首次达到 26 时可直接返回 true；如果遍历结束仍未达到则返回 false。最坏时间仍是 O(n)。

面试追问

允许大小写和标点呢？先明确字母表，再将 ASCII 大写转小写并过滤非 a–z 字符，不能直接统计所有字符的种类数。输入是数据流呢？保留集合或位掩码即可，达到 26 就能确认 true；若未覆盖，只有流结束才能确认 false。要求每个字母出现两次呢？使用计数数组，集合不足以表达频次。

常见错误

  • 把长度 ≥ 26 当作充分条件，忽略重复字母。
  • 用总字符数代替不同字符数。
  • 位掩码用 XOR 更新，重复字母会被错误地清除；应使用 OR。
  • 把题外字符计入集合，导致“26 种字符”不再等价于全字母句。
