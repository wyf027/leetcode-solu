01 / 游戏规则

输入整数 n，构造阶数为 n 的斐波那契二叉树。Alice 先手，与 Bob 轮流选择当前树中的一个节点，移除它及它仍然存在的所有后代。被迫移除整棵树的根节点的人输。双方都采用最优策略，求 Alice 能否获胜。

order(0)

空树，没有节点。

order(1)

只含一个根节点。

order(n)，n ≥ 2

新根的左子树是 order(n−2)，右子树是 order(n−1)。

接口：findGameWinner(n: integer) → boolean。返回 true 表示 Alice 赢，false 表示 Bob 赢。约束：1 ≤ n ≤ 100；输入是阶数，不是节点数。子树包含被选节点自身，移除后不重新生成节点。

05 / 题解：把树压缩成一个数

核心洞察：只禁止全局根

把删除全局根视为立即认输，最优玩家会尽可能选择其他节点。因此可以等价地禁止删除全局根，并令无合法操作者输。根下的左右子树是两个独立的正常玩法游戏；它们自己的根可以被删除，且不会导致整场游戏立即失败。

定义 H(n)：允许删除子树根的 order(n) 的 Grundy 值。空树 H(0)=0，单节点 H(1)=1。由独立游戏的异或和与根部加一原理：

H(n) = 1 + (H(n−2) XOR H(n−1))          n ≥ 2
G(n) = H(n−2) XOR H(n−1) = H(n) − 1     n ≥ 2
G(1) = 0
Alice 获胜 ⇔ G(n) ≠ 0 ⇔ H(n) ≠ 1

为什么子树根让 Grundy 值加一？

设根下森林为 F，森林的 Grundy 值为 g。删除新根可到达值 0；保留新根并在森林中行动，得到某个后继森林 F′。对剩余节点数归纳，其带根游戏的值是 SG(F′)+1。于是新根游戏的后继值集合是 {0} ∪ {SG(F′)+1}，它的 mex（最小未出现非负整数）恰为 g+1。左右森林相互独立，所以 g 是两个子树值的异或。

完整过程：先递推，再证明周期

  1. 从 H(0)=0、H(1)=1 开始，按阶数递增计算 H。
  2. 每一步先异或前两项，再做普通整数加一。禁止根的真实局面值是加一前的结果。
  3. 找出 H(n)=1 的位置；利用下面的分组归纳可证明它们恰为 n≡1 (mod 6)。
  4. 最终无需建树或存储递推数组，返回 n % 6 != 1。

正确性：六项一组的归纳

对 k≥0，令 a=4k+4，b=((a−2) XOR a)+1。递推每组具有如下形式：

下标        6k+1   6k+2   6k+3   6k+4   6k+5   6k+6
H 值          1     a−2      a      b      a      a

a 是 4 的倍数，所以 a−2 的二进制末两位为 10、a 的末两位为 00；令 q=(a−2) XOR a，则 q 的末两位为 10，故 q+1=q XOR 1。由此 b XOR a=(a−2) XOR 1=a−1，随后的两项均为 a。两项 a 再异或，加一得到下一组开头的 1；随后得到 a+2、a+4，正好接上下一组。

初始一组为 1, 2, 4, 7, 4, 4，符合式子。并且 a≥4、a−2≥2，q 的末两位为 10 保证 b≥3，因此每组只有第一项等于 1。这证明仅在 n % 6 == 1 时 G(n)=0；结合 SG 定理，公式返回值正确。n=1 的单根必败情况也被公式包含。

边界与复杂度

  • n=1：没有非根节点，先手必败。n=2：先手删唯一孩子即获胜。
  • n=0 只是递推中表示空树的辅助下标，不是合法输入。
  • 不要构造 order(100)。实际节点数满足 N(n)=1+N(n−1)+N(n−2)，呈指数增长。
  • 最终周期公式：时间 O(1)，额外空间 O(1)。

替代方案

滚动保存前两个 H 值，循环计算到 n，返回最后的 H 是否不等于 1，时间 O(n)、空间 O(1)。这是更直接的 SG 递推方案，不必使用周期结论。完整数组则便于展示历史，空间 O(n)。仅对很小的树可枚举剩余节点状态做博弈搜索；状态规模指数增长，不适合本题上界。

常见错误

  • 认为所有 n≥2 都获胜：n=7 的两个子树 H 值均为 4，异或为 0，是反例。
  • 把“删除子树的根”也当成输：只有原始整棵树的根是失败节点。
  • 直接把左右子树的胜负布尔值异或：组合游戏需要完整 Grundy 数。
  • 把 XOR 换成加法，或写成 H(n−2) XOR (H(n−1)+1)：括号位置会改变递推。
  • 只观察几个小样例就猜周期：需要分组归纳，而不是将演示表当成证明。

面试追问

如何找第一步？ 非零 G 局面寻找一次移除，使整体 SG 变为 0；若要输出具体节点，需要额外追踪结构，单个胜负公式不提供走法。
换成任意根树呢？ 在子树根可删除的定义下，自底向上算 H(v)=1+XOR(H(child))，最后仅对全局根的孩子异或。
如果删全局根改成赢呢？ 根可在第一步直接删除，规则本身会让先手立即获胜。
