拆分字符串使唯一子字符串的数目最大

Split a String Into the Max Number of Unique Substrings

MEDIUM非付费题长度 ≤ 16
Problem brief

题意

给定一个只含小写英文字母的字符串 s，把它切成若干个连续、非空的子字符串。所有子字符串按原顺序拼接后必须恰好还原 s，并且任意两个子字符串都不能相同。返回可得到的最大子字符串数量。

函数签名：maxUniqueSplit(s: string) → integer

示例 1
输入：s = "ababccc"
输出：5
例如可拆成 ["a", "b", "ab", "c", "cc"]；每一段均不同。
示例 2
输入：s = "aba"
输出：2
一种最大拆分是 ["a", "ba"]。
示例 3
输入：s = "aa"
输出：1
若切成两个 "a" 会重复，所以只能保留整串。

约束

  • 1 ≤ s.length ≤ 16
  • s 仅含小写英文字母
  • 每段非空且连续
  • 所有段互不相同

一个拆分何时有效？

完整覆盖原串、保持字符顺序、没有重复片段。目标不是让每段最短，而是让有效片段的总数最多。

    Full solution

    回溯枚举所有切法，用集合守住“唯一”

    核心洞察

    在位置 start，下一段一定是 s[start..end] 中的某一个。逐个尝试所有 end；若候选片段尚未出现在集合 used 中，就加入集合并继续搜索。递归返回时移除该片段，恢复现场。

    到达字符串末尾时得到一种完整切法，用当前片段数更新答案。因为长度最多 16，枚举切分边界是可接受的。

    安全剪枝

    若当前已有 count 段，剩余字符数是 n - start，那么即便每个剩余字符都单独成段，最多也只能得到 count + n - start 段。

    当这个上界不超过当前最优值时，可以直接返回；它不可能产生更好的答案。

    完整过程

    1. 从下标 0 开始，维护已使用片段集合和当前片段数。
    2. 枚举当前位置结尾的所有可能位置，形成非空候选片段。
    3. 候选已在集合中则跳过；否则选择它并递归处理后缀。
    4. 递归结束后撤销选择，继续尝试更长的候选。
    5. 当位置到达 n 时，用当前段数更新全局最大值。

    正确性证明

    引理 1：搜索产生的每个完整方案都合法。

    算法只选择从当前位置开始的连续非空片段，并让下一次递归从其结尾继续，因此所有片段按序、无遗漏且无重叠地覆盖原串。加入前检查 used，所以片段互不相同。

    引理 2：每个合法拆分都会被搜索到。

    考虑任意合法拆分。在每个位置，它的下一段都是算法枚举的某个 s[start..end]。由于该方案合法，该片段此前未使用，算法不会跳过它。依次选择这些分支即可到达该完整拆分。

    引理 3：剪枝不会丢失更优方案。

    剩余每个字符至多贡献一个新片段，因此任何后续方案的片段总数都不超过 count + n - start。该上界不超过当前答案时，分支不可能改进答案。

    结论。

    由引理 1 与 2，算法恰好覆盖所有合法拆分；由引理 3，省略的分支不含更优解。因此最终记录的是唯一子字符串数目的最大值。

    复杂度

    长度为 n 的字符串有 2^(n-1) 种切分边界组合。考虑构造/哈希子串的成本，时间复杂度上界可写为 O(n · 2^n)；剪枝会改善实际运行。递归深度为 O(n)，集合中保存的片段字符总量最多 O(n)；若计入实现中的临时子串，保守空间上界为 O(n²)。

    边界情况

    • 单字符：答案必为 1。
    • 全部字符相同：仍可能用不同长度片段，但不能重复。
    • 全部字符不同：每个字符单独成段，答案为 n。
    • 重复模式：局部选最短片段未必最优，需要回溯。

    替代方案

    可以用位掩码枚举 n - 1 个间隙是否切开，再用集合检查每种拆分是否唯一；思路直接，复杂度同样约为 O(n · 2^n)，但无法像回溯那样早期拒绝重复候选。朴素记忆化不容易奏效，因为状态不仅取决于位置，还取决于整个 used 集合；把集合编码进状态通常得不偿失。

    四种语言完整代码

    import java.util.HashSet;
import java.util.Set;

class Solution {
    private int best = 0;

    public int maxUniqueSplit(String s) {
        dfs(s, 0, new HashSet<>());
        return best;
    }

    private void dfs(String s, int start, Set<String> used) {
        if (used.size() + s.length() - start <= best) return;
        if (start == s.length()) {
            best = Math.max(best, used.size());
            return;
        }

        for (int end = start + 1; end <= s.length(); end++) {
            String part = s.substring(start, end);
            if (!used.add(part)) continue;
            dfs(s, end, used);
            used.remove(part);
        }
    }
}
    /**
 * @param {string} s
 * @return {number}
 */
var maxUniqueSplit = function(s) {
    const used = new Set();
    let best = 0;

    function dfs(start) {
        if (used.size + s.length - start <= best) return;
        if (start === s.length) {
            best = Math.max(best, used.size);
            return;
        }

        for (let end = start + 1; end <= s.length; end++) {
            const part = s.slice(start, end);
            if (used.has(part)) continue;
            used.add(part);
            dfs(end);
            used.delete(part);
        }
    }

    dfs(0);
    return best;
};
    class Solution:
    def maxUniqueSplit(self, s: str) -> int:
        used = set()
        best = 0

        def dfs(start: int) -> None:
            nonlocal best
            if len(used) + len(s) - start <= best:
                return
            if start == len(s):
                best = max(best, len(used))
                return

            for end in range(start + 1, len(s) + 1):
                part = s[start:end]
                if part in used:
                    continue
                used.add(part)
                dfs(end)
                used.remove(part)

        dfs(0)
        return best
    class Solution {
    int best = 0;

    void dfs(const string& s, int start,
             unordered_set<string>& used) {
        if ((int)used.size() + (int)s.size() - start <= best) return;
        if (start == (int)s.size()) {
            best = max(best, (int)used.size());
            return;
        }

        for (int end = start + 1; end <= (int)s.size(); ++end) {
            string part = s.substr(start, end - start);
            if (used.count(part)) continue;
            used.insert(part);
            dfs(s, end, used);
            used.erase(part);
        }
    }

public:
    int maxUniqueSplit(string s) {
        unordered_set<string> used;
        dfs(s, 0, used);
        return best;
    }
};

    面试追问

    • 为什么不能只选当前最短且未使用的片段？
    • 剪枝上界为什么一定安全？还能否构造更紧的上界？
    • 如果字符串长度扩大到 30，如何重新设计状态或约束？
    • 如何返回所有最大拆分，而不只是数量？

    常见错误

    • 递归返回后忘记从集合中删除当前片段。
    • 把“子字符串”误当成可跳字符的子序列。
    • 到达末尾前就更新答案，计入了不完整方案。
    • 使用全局集合但没有按分支恢复现场。
    • 写成 end < n，漏掉延伸到末尾的片段。
