构造矩阵

把 1 到 k 安排到网格里，让每一条“上方”和“左侧”关系都成立。

01 / THE CHALLENGE

题意与输入

给定正整数 k，以及两组数字对：rowConditions[i] = [aboveᵢ, belowᵢ] 要求前一个数字所在行严格高于后一个数字所在行；colConditions[i] = [leftᵢ, rightᵢ] 要求前一个数字所在列严格位于后一个数字所在列的左侧。两组条件中的数字都在 1 到 k 内。

构造并返回一个 k × k 矩阵，其中 1 到 k 各出现一次，其余格子填 0，且全部条件同时成立。可以返回任意合法矩阵；无解则返回 []。上下关系不要求同列，左右关系不要求同行；“严格”意味着对应行号或列号不能相等。

完整约束

  • 2 ≤ k ≤ 400
  • 1 ≤ rowConditions.length, colConditions.length ≤ 10⁴
  • 每一条条件恰好包含两个整数，即各自有效下标范围内的 rowConditions[i].length == 2 与 colConditions[i].length == 2。
  • 1 ≤ aboveᵢ, belowᵢ, leftᵢ, rightᵢ ≤ k
  • aboveᵢ ≠ belowᵢ，leftᵢ ≠ rightᵢ。条件允许重复。

示例 1 · 可以构造

k = 3
rowConditions = [[1,2],[3,2]]
colConditions = [[2,1],[3,2]]
输出 = [[3,0,0],[0,0,1],[0,2,0]]

按从 0 开始的坐标，3、1、2 分别在第 0、1、2 行，所以 1 和 3 都在 2 上方。3、2、1 分别在第 0、1、2 列，所以 3 在 2 左侧，2 在 1 左侧。这只是多个合法答案之一。

示例 2 · 条件矛盾

k = 3
rowConditions = [[1,2],[2,3],[3,1],[2,3]]
colConditions = [[2,1]]
输出 = []

前两条行关系要求 1 高于 2、2 高于 3，但第三条又要求 3 高于 1，无法全部成立。重复出现的 [2,3] 不改变矛盾。

03 / THE SOLUTION

两条独立的顺序，合成一个坐标

行条件决定纵向次序，列条件决定横向次序。分别做拓扑排序，将数字 v 放在 (rowPos[v], colPos[v])。

核心洞察

数字是节点，[a,b] 是有向边 a → b。行图与列图必须分开处理。任意一张图有环就无解；如果都无环，各取一个包含全部 k 个节点的拓扑序即可。虽然题目允许多个数字同行，我们可以主动让每个数字占据独立的一行和一列，k × k 的空间完全足够。

完整过程

  1. 分别建立行图、列图和入度数组，纳入所有 1 到 k 的节点。
  2. 运行 Kahn 拓扑排序：把当前入度为 0 的节点放入队列。
  3. 取队首加入顺序，逐条移除其出边；后继入度刚变为 0 时入队。
  4. 处理节点数不足 k 就存在环，立即返回 []。两张图都要检查。
  5. 根据列顺序建立 colPos；创建 k × k 全 0 矩阵，遍历行序，将 rows[r] 写入 matrix[r][colPos[rows[r]]]。

交互实验 · 双轨排队 → 网格落位

观察待处理队列、剩余入度和被移除的边。先处理行图，再处理列图，最后合成坐标。初始队列按数字升序排列，后续按输入边的顺序入队，因此演示矩阵可能与官方示例不同。

正确性证明

  1. 顺序满足所有边：节点只有在全部入边被移除后才出队。因此每条 a → b 的 a 一定先于 b 出现在拓扑序中。无环图的任意非空剩余子图都存在零入度节点，所以无环时能输出全部节点。
  2. 无解判断可靠：队列为空但仍有未输出节点时，剩余图每个节点都有入边。沿前驱追溯必重复节点，形成环。严格行号或列号不可能沿环不断增大后回到原点，所以该方向存在环时原题无解。
  3. 没有格子冲突：行序和列序都是 1 到 k 的排列。不同数字拥有不同的行位置，写入坐标不会重合。每个数字写一次，其他格子保留 0。
  4. 同时满足两个方向：对于行条件 [a,b] 有 rowPos[a] < rowPos[b]；对于列条件 [a,b] 有 colPos[a] < colPos[b]。合成坐标保留这两组关系，因而矩阵合法。

所以，行图和列图都无环，是存在答案的充分必要条件。

复杂度

设 n、m 分别为两组条件数量。两次拓扑排序需要 O(k+n+m) 时间，初始化矩阵需要 O(k²)，总时间为 O(k²+n+m)。辅助空间为 O(k+n+m)；包含返回矩阵后，总空间为 O(k²+n+m)。教学动画保存逐步快照，额外占用空间，不属于提交代码复杂度。

边界与常见错误

  • 孤立数字也需要输出，不能只收集条件中出现过的节点。
  • 重复边可以直接保留，但入度增加和减少都要按重复次数进行；不能只对邻接表去重。
  • 不要把两张图合并：行上 1 → 2、列上 2 → 1 完全可以同时成立。
  • 必须检查两张图输出长度都是 k，部分顺序不能用于完成构造。
  • 使用“数字 → 位置”映射，避免把数字值和顺序下标弄反。
  • 多个零入度节点可以任选，不需要字典序最小，也不必输出和官方相同的矩阵。
  • JavaScript 和 Python 的矩阵行必须分别创建，避免多行共享一个数组引用。
  • 输出需要 k × k 个格子，时间和空间都不能漏掉 k²。

替代方案

可以对两张图做三色 DFS，遇到指向访问中节点的边时判环，后序结果逆序即拓扑序。时间同为 O(k+n+m)，需要处理递归栈。若要求每个方向的字典序最小拓扑序，可用最小堆代替普通队列，排序部分变为 O(k log k+n+m)，但本题无需付出这部分成本。枚举行列排列无法承受 k 最大 400 的规模。

面试追问

  • 两张图分别无环，组合后可能冲突吗？不会，给每个数字独立行、独立列就是明确的可行构造。
  • 如何判断某方向拓扑序唯一？每次取节点时，候选零入度节点数都必须为 1。拓扑序唯一性并不直接等同于所有合法矩阵的唯一性，因为原题允许无关系的数字共享行或列。
  • 如何给出具体的矛盾环？补充 DFS 颜色和父节点记录，遇到回边后还原环。Kahn 算法剩余节点不一定全部处于环上，也可能位于环的下游。
  • 怎样验证任意答案？提取每个数字坐标，核对尺寸、数字各出现一次、其余均为 0，再逐条检查严格行列关系。若返回 []，应独立确认至少一个方向存在环。

JavaScript

/**
 * @param {number} k
 * @param {number[][]} rowConditions
 * @param {number[][]} colConditions
 * @return {number[][]}
 */
var buildMatrix = function(k, rowConditions, colConditions) {
    function topo(edges) {
        const graph = Array.from({length: k + 1}, () => []);
        const degree = Array(k + 1).fill(0);
        for (const [a, b] of edges) {
            graph[a].push(b);
            degree[b]++;
        }
        const queue = [];
        for (let v = 1; v <= k; v++) {
            if (degree[v] === 0) queue.push(v);
        }
        // 队列同时保存拓扑序，用 head 避免 shift 搬移元素。
        for (let head = 0; head < queue.length; head++) {
            for (const next of graph[queue[head]]) {
                if (--degree[next] === 0) queue.push(next);
            }
        }
        return queue.length === k ? queue : [];
    }
    const rows = topo(rowConditions);
    if (rows.length !== k) return [];
    const cols = topo(colConditions);
    if (cols.length !== k) return [];
    const colPos = Array(k + 1).fill(0);
    cols.forEach((v, i) => { colPos[v] = i; });
    const matrix = Array.from({length: k}, () => Array(k).fill(0));
    rows.forEach((v, r) => { matrix[r][colPos[v]] = v; });
    return matrix;
};

Java

import java.util.*;

class Solution {
    private int[] topo(int k, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i <= k; i++) graph.add(new ArrayList<>());
        int[] degree = new int[k + 1];
        for (int[] edge : edges) {
            graph.get(edge[0]).add(edge[1]);
            degree[edge[1]]++;
        }
        int[] order = new int[k];
        int tail = 0;
        for (int v = 1; v <= k; v++) {
            if (degree[v] == 0) order[tail++] = v;
        }
        for (int head = 0; head < tail; head++) {
            for (int next : graph.get(order[head])) {
                if (--degree[next] == 0) order[tail++] = next;
            }
        }
        return tail == k ? order : new int[0];
    }

    public int[][] buildMatrix(int k, int[][] rowConditions,
                                int[][] colConditions) {
        int[] rows = topo(k, rowConditions);
        if (rows.length != k) return new int[0][0];
        int[] cols = topo(k, colConditions);
        if (cols.length != k) return new int[0][0];
        int[] colPos = new int[k + 1];
        for (int i = 0; i < k; i++) colPos[cols[i]] = i;
        int[][] matrix = new int[k][k];
        for (int r = 0; r < k; r++) matrix[r][colPos[rows[r]]] = rows[r];
        return matrix;
    }
}

Python

from typing import List
from collections import deque

class Solution:
    def buildMatrix(self, k: int, rowConditions: List[List[int]],
                    colConditions: List[List[int]]) -> List[List[int]]:
        def topo(edges):
            graph = [[] for _ in range(k + 1)]
            degree = [0] * (k + 1)
            for a, b in edges:
                graph[a].append(b)
                degree[b] += 1
            queue = deque(v for v in range(1, k + 1) if degree[v] == 0)
            order = []
            while queue:
                value = queue.popleft()
                order.append(value)
                for nxt in graph[value]:
                    degree[nxt] -= 1
                    if degree[nxt] == 0:
                        queue.append(nxt)
            return order if len(order) == k else []

        rows = topo(rowConditions)
        if len(rows) != k:
            return []
        cols = topo(colConditions)
        if len(cols) != k:
            return []
        col_pos = {value: i for i, value in enumerate(cols)}
        matrix = [[0] * k for _ in range(k)]
        for r, value in enumerate(rows):
            matrix[r][col_pos[value]] = value
        return matrix

C++

#include <vector>
#include <queue>
using namespace std;

class Solution {
    vector<int> topo(int k, const vector<vector<int>>& edges) {
        vector<vector<int>> graph(k + 1);
        vector<int> degree(k + 1, 0), order;
        for (const auto& edge : edges) {
            graph[edge[0]].push_back(edge[1]);
            ++degree[edge[1]];
        }
        queue<int> ready;
        for (int v = 1; v <= k; ++v)
            if (degree[v] == 0) ready.push(v);
        while (!ready.empty()) {
            int v = ready.front();
            ready.pop();
            order.push_back(v);
            for (int next : graph[v])
                if (--degree[next] == 0) ready.push(next);
        }
        if (static_cast<int>(order.size()) != k) return {};
        return order;
    }
public:
    vector<vector<int>> buildMatrix(int k, vector<vector<int>>& rowConditions,
                                    vector<vector<int>>& colConditions) {
        auto rows = topo(k, rowConditions);
        if (static_cast<int>(rows.size()) != k) return {};
        auto cols = topo(k, colConditions);
        if (static_cast<int>(cols.size()) != k) return {};
        vector<int> colPos(k + 1);
        for (int i = 0; i < k; ++i) colPos[cols[i]] = i;
        vector<vector<int>> matrix(k, vector<int>(k, 0));
        for (int r = 0; r < k; ++r) matrix[r][colPos[rows[r]]] = rows[r];
        return matrix;
    }
};
