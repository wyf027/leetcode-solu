Problem brief

题意与输出契约

固定列：America · Asia · Europe

给定 Student(name, continent) 表，请生成一张横向报告：三列依次为 America、Asia、Europe。

每一列内部按学生姓名升序排列；第 k 行放各洲排序后的第 k 个名字。某洲没有对应名字时，该单元格为 NULL。

约束与已知条件

  • name 是学生姓名，官方类型为 VARCHAR(50)。
  • continent 的官方类型为 VARCHAR(7)，取值属于 America、Asia、Europe。
  • 学生姓名唯一；每洲名单独立按字典序升序排列。
  • 输出列名与顺序固定；行数等于人数最多的大洲人数。
  • 官方元数据没有公开行数范围，因此不虚构数值上限。

Full solution

题解：给每个洲建立同一把“行尺”

INSIGHT 01

分区内排名

每个洲各自按姓名排序，用 ROW_NUMBER() 得到连续的 1、2、3……。

INSIGHT 02

序号成为公共坐标

不同洲的相同序号代表报告中的同一行，因此可以据此聚合。

INSIGHT 03

条件聚合完成转列

每个洲用一个 CASE 选出姓名；缺席的洲自然保留为 NULL。

完整过程

① 窗口编号

按 continent 分区、按 name 排序，生成 rn。

② 条件投影

把三洲姓名分别投到三个 CASE 表达式中。

③ 合并同序号

按 rn 分组，用 MAX 取出每列唯一的非 NULL 值。

partition + sort → rn → group by rn → max(case when continent = … then name end)

官方可提交语言：MySQL 8.0+

SQL · 主答案窗口函数 + 条件聚合
WITH ranked AS (
  SELECT
    name,
    continent,
    ROW_NUMBER() OVER (
      PARTITION BY continent
      ORDER BY name
    ) AS rn
  FROM Student
)
SELECT
  MAX(CASE WHEN continent = 'America' THEN name END) AS America,
  MAX(CASE WHEN continent = 'Asia'    THEN name END) AS Asia,
  MAX(CASE WHEN continent = 'Europe'  THEN name END) AS Europe
FROM ranked
GROUP BY rn
ORDER BY rn;

为什么正确

引理：序号准确表示洲内位置

ROW_NUMBER() 在每个洲的分区中按 name 升序从 1 连续编号，所以 rn = k 当且仅当该学生是该洲字典序第 k 名。

定理：每行恰好是目标报告的一行

固定 rn = k 后，每个洲最多只有一名学生。对应 CASE 只留下该姓名，MAX 返回它；若不存在第 k 名则所有值均为 NULL。按 rn 升序输出，正好得到完整报告。

边界与复杂度

  • 只有一个洲有学生：另外两列全为 NULL。
  • 三洲人数不同：短列在尾部自动补 NULL。
  • 空表：CTE 为空，最终查询返回 0 行。
  • 设总记录数为 n；窗口排序时间通常为 O(n log n)，聚合扫描为 O(n)，中间排名结果占 O(n) 空间。数据库执行计划和索引可能改变常数项。

Java 17 · 本地语义参考空缺以 null 表示
import java.util.*;

public class GeographyReport {
  public record Student(String name, String continent) {}

  public static List<List<String>> buildReport(List<Student> students) {
    Map<String, List<String>> groups = new LinkedHashMap<>();
    groups.put("America", new ArrayList<>());
    groups.put("Asia", new ArrayList<>());
    groups.put("Europe", new ArrayList<>());

    for (Student student : students) {
      List<String> names = groups.get(student.continent());
      if (names == null) {
        throw new IllegalArgumentException("Unknown continent");
      }
      names.add(student.name());
    }
    groups.values().forEach(Collections::sort);

    int rows = groups.values().stream().mapToInt(List::size).max().orElse(0);
    List<List<String>> report = new ArrayList<>();
    for (int i = 0; i < rows; i++) {
      List<String> row = new ArrayList<>();
      for (String continent : groups.keySet()) {
        List<String> names = groups.get(continent);
        row.add(i < names.size() ? names.get(i) : null);
      }
      report.add(row);
    }
    return report;
  }
}
JavaScript ES2022 · 本地语义参考空缺以 null 表示
function buildReport(students) {
  const continents = ["America", "Asia", "Europe"];
  const groups = new Map(continents.map((name) => [name, []]));

  for (const student of students) {
    if (!groups.has(student.continent)) {
      throw new Error("Unknown continent");
    }
    groups.get(student.continent).push(student.name);
  }

  for (const names of groups.values()) {
    names.sort((a, b) => a.localeCompare(b, "en"));
  }

  const rowCount = Math.max(0, ...continents.map((c) => groups.get(c).length));
  return Array.from({ length: rowCount }, (_, rowIndex) =>
    continents.map((continent) => groups.get(continent)[rowIndex] ?? null)
  );
}
Python 3.11 · 本地语义参考空缺以 None 表示
from collections.abc import Iterable
from typing import NamedTuple


class Student(NamedTuple):
    name: str
    continent: str


def build_report(students: Iterable[Student]) -> list[list[str | None]]:
    continents = ("America", "Asia", "Europe")
    groups: dict[str, list[str]] = {continent: [] for continent in continents}

    for student in students:
        if student.continent not in groups:
            raise ValueError("Unknown continent")
        groups[student.continent].append(student.name)

    for names in groups.values():
        names.sort()

    row_count = max((len(names) for names in groups.values()), default=0)
    return [
        [groups[continent][i] if i < len(groups[continent]) else None
         for continent in continents]
        for i in range(row_count)
    ]
C++17 · 本地语义参考空缺以 std::nullopt 表示
#include <algorithm>
#include <array>
#include <optional>
#include <stdexcept>
#include <string>
#include <unordered_map>
#include <vector>

struct Student {
  std::string name;
  std::string continent;
};

using Cell = std::optional<std::string>;

std::vector<std::array<Cell, 3>>
buildReport(const std::vector<Student>& students) {
  const std::array<std::string, 3> continents{"America", "Asia", "Europe"};
  std::unordered_map<std::string, std::vector<std::string>> groups;
  for (const auto& continent : continents) groups[continent] = {};

  for (const auto& student : students) {
    auto it = groups.find(student.continent);
    if (it == groups.end()) throw std::invalid_argument("Unknown continent");
    it->second.push_back(student.name);
  }
  for (auto& [continent, names] : groups) {
    std::sort(names.begin(), names.end());
  }

  std::size_t rowCount = 0;
  for (const auto& continent : continents) {
    rowCount = std::max(rowCount, groups[continent].size());
  }

  std::vector<std::array<Cell, 3>> report;
  for (std::size_t row = 0; row < rowCount; ++row) {
    std::array<Cell, 3> outputRow{};
    for (std::size_t col = 0; col < continents.size(); ++col) {
      const auto& names = groups[continents[col]];
      if (row < names.size()) outputRow[col] = names[row];
    }
    report.push_back(std::move(outputRow));
  }
  return report;
}

面试追问

如果洲名动态变化怎么办？固定 SQL 列无法直接动态扩展，通常需要动态 SQL 或让应用层返回行式数据再生成列。若姓名允许重复，应在窗口排序中加入稳定且唯一的第二排序键。

常见错误

  • 直接按 continent 分组，导致每洲只剩一行而不是完整名单。
  • 忘记在窗口函数里按 name 排序，输出顺序不满足要求。
  • 对三个洲分别查询后按姓名连接；姓名不是跨洲的对齐键。
  • 用 COUNT(*) 决定行数，却没有保留每洲第 k 名的对应关系。
  • 使用普通聚合而不按 rn 分组，最终只生成一行。
