Problem

题目说明

给定字符串 time，格式为 hh:mm。其中部分数字可能被 ? 隐藏。请将每个问号替换为一个十进制数字，使结果成为 00:00 到 23:59（含边界）之间尽可能晚的有效时间，并返回该时间字符串。

函数形式：maximumTime(time: string) -> string

1小时首位已固定
输入：time = "2?:?0"
输出："23:50"

以 2 开头的最晚小时为 23；分钟末位为 0 时，最晚分钟为 50。

2小时首位受次位影响
输入：time = "0?:3?"
输出："09:39"
3分钟无需修改
输入：time = "1?:22"
输出："19:22"

约束

  • time 的格式为 hh:mm。
  • 题目保证至少可以替换出一个有效时间。

输入与返回

唯一参数是长度为 5 的时间字符串；返回同样采用两位小时、冒号、两位分钟的字符串。

Solution

从高位到低位，局部取最大

核心洞察

时间字符串的字典序与时间先后顺序一致。只要每一步仍能形成合法时间，就应优先让更高位尽可能大：先处理小时十位，再处理小时个位，最后处理分钟十位和个位。

唯一的联动

小时十位与小时个位互相约束。十位为问号时，只有当个位也是问号或不超过 3，十位才能取 2；否则十位最多取 1。小时十位确定后，个位在十位为 2 时最多取 3，否则最多取 9。

完整过程

  1. 若 time[0] 是问号：当 time[1] 为问号或不大于 3 时填 2，否则填 1。
  2. 若 time[1] 是问号：小时十位为 2 时填 3，否则填 9。
  3. 若分钟十位 time[3] 是问号，填 5。
  4. 若分钟个位 time[4] 是问号，填 9。返回拼接后的字符串。

正确性证明

小时十位最优

若个位允许组成 20–23，选择 2 比 0 或 1 得到的任意小时都晚；若个位固定为 4–9，2 会非法，此时 1 是最大合法十位。

小时个位最优

十位确定后，合法范围固定：十位为 2 时个位至多为 3，其他情况下至多为 9。选择对应上界得到最大合法小时。

分钟最优

合法分钟范围是 00–59，因此分钟十位上界恒为 5，个位上界恒为 9；分别取上界即可得到最大分钟。

整体最优

算法依序最大化小时与分钟的每一高位，且每次选择保持合法。任何不同结果首次出现更小数字的位置都会使其时间更早，因此所得时间全局最晚。

边界情况

  • ??:?? 得到 23:59。
  • ?4:?? 的小时十位只能取 1。
  • 2?:?? 的小时个位最多取 3。
  • 没有问号时原样返回。

复杂度

字符串长度固定为 5。一般化描述为时间复杂度 O(1)，额外空间 O(1)；若语言因可变字符数组而复制字符串，仍只处理常数个字符。

替代方案

可以从 23:59 递减枚举所有 1440 个时间，找到首个与模板匹配者。它同样是常数上界且直观，但没有利用各位置的独立上界，表达不如贪心紧凑。

面试追问

  • 若允许 12 小时制与 AM/PM，约束如何变化？
  • 如何写一个通用模板匹配器并倒序枚举？
  • 为什么字典序在固定宽度时间格式下等价于时间顺序？
  • 若输入不保证可行，怎样返回失败状态？

常见错误

  • 小时十位无条件填 2，导致 ?4 变成非法的 24。
  • 先处理小时个位，遗漏它对十位选择的影响。
  • 把分钟十位填成 9，越过 59。
  • 转换为数字后丢失前导零。

class Solution {
    public String maximumTime(String time) {
        char[] chars = time.toCharArray();
        if (chars[0] == '?') {
            chars[0] = (chars[1] == '?' || chars[1] <= '3') ? '2' : '1';
        }
        if (chars[1] == '?') {
            chars[1] = chars[0] == '2' ? '3' : '9';
        }
        if (chars[3] == '?') chars[3] = '5';
        if (chars[4] == '?') chars[4] = '9';
        return new String(chars);
    }
}
