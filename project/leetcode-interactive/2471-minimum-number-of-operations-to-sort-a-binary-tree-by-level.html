01 / 题目

给定二叉树根节点 root，所有节点的值互不相同。一次操作可以选择同一层中的任意两个节点，只交换它们的值。

求最少操作次数，使每一层的节点值按从左到右的顺序严格递增。根节点的层数为 0；其余节点的层数等于根到该节点路径上的边数。

树的连边和节点位置不变；允许交换同层非相邻节点。数组输入采用按队列展开的层序表示，null 表示缺失子节点。

输入与边界

  • 参数：root: TreeNode。
  • 返回：整数 minimumOperations(root)。
  • 节点数：1 ≤ n ≤ 10⁵。
  • 节点值：1 ≤ Node.val ≤ 10⁵。
  • 整棵树的所有节点值互不相同。

先独立思考；可视化、证明和代码都收在底部题解中。

题解 / 每层都是一个排列

各层互不影响，因此分别求最优交换次数后相加。对某层排序，得到每个值应该去的目标下标：p[i] = 第 i 个值的排序名次。值互异，保证 p 是一个排列。

沿着 i → p[i] 走会形成若干个环。长度为 k 的环需要恰好 k − 1 次交换；长度 1 的环已经就位。

例如 [7,6,8,5] 的目标是 [5,6,7,8]，p = [2,1,3,0]。环为 (0 → 2 → 3 → 0) 和 (1 → 1)，代价为 (3−1)+(1−1)=2。

完整过程
  1. 用层序遍历维护当前层节点列表，按父节点顺序先收左孩子、再收右孩子，得到下一层。
  2. 取当前层值数组 values，对其副本升序排序，为每个值分配从 0 开始的目标下标。
  3. 构造排列 p。从每个未访问下标出发沿 p 前进，标记访问并统计环长。
  4. 将每个环的长度减 1 加入答案，处理下一层，直至没有节点。
示例 1 的逐层代价：[1] → 0、[4,3] → 1、[7,6,8,5] → 2、[9,10] → 0，总计 3。


为什么一定最少？
先看一层的 m 个位置。初始排列有 c 个环，目标恒等排列有 m 个长度 1 的环。一次交换至多使环数增加 1，所以至少需要 m−c 次。
对长度 k 的环，选择一个未就位位置，将应该在此处的值交换过来，每次固定一个位置，k−1 次即可消除该环。对所有环独立操作恰好达到下界 m−c。跨层交换不被允许，各层下界相加仍是全树下界，而逐层执行达到了它。


复杂度
设节点总数为 n，最大层宽为 W，各层宽度为 mₗ。时间为 O(n + Σ mₗ log mₗ)，可写为 O(n log(W+1))，最坏 O(n log n)。额外空间为 O(W)：仅保留相邻两层及当前层排序、映射、访问数组，不计输入树。哈希映射按平均 O(1) 查找计。


边界与常见错误
  • 单节点、链状树、已排序层：所有环长度为 1，贡献 0。
  • 稀疏树：null 不属于层内数组；不要按完整二叉树数组下标直接切层。
  • 不能只算逆序对：那对应相邻交换，本题允许同层任意两点交换。
  • 不要按“错位元素数 ÷ 2”计数：长度 3 的环有 3 个错位元素却要 2 次。
  • JavaScript 排序必须写数值比较函数；不要对 BFS 队列反复 shift。
  • 必须按层冻结边界，不能混入刚加入的下一层节点。深链避免递归导致栈溢出。


替代方案
可以维护“值 → 当前位置”哈希表，逐个把正确值换到前面；每次交换同时更新两个位置，仍为排序 O(m log m)、交换 O(m)。它容易输出操作序列，但比直接数环多了位置维护。DFS 也可收集每层值，但保存全树分组需 O(n) 空间，深树递归有栈风险。


面试追问
  • 如何输出交换序列？对每层用位置表完成上述就位交换，同时记录两个节点的位置。
  • 若要求相邻交换？应计算各层逆序对，可用归并排序或树状数组。
  • 允许重复值会怎样？严格递增目标无法容纳同层重复值；若改为非递减，目标位置不再唯一，任意稳定匹配未必给出最少交换，不能直接套用唯一值映射。
  • 节点可达 10⁵，如何避免栈溢出？使用迭代层序遍历；答案至多 n−1，32 位整数足够。

import java.util.*;

// TreeNode 由 LeetCode 提供，包含 int val、left 和 right。
class Solution {
    public int minimumOperations(TreeNode root) {
        if (root == null) return 0;
        List<TreeNode> level = new ArrayList<>();
        level.add(root);
        int answer = 0;
        while (!level.isEmpty()) {
            int m = level.size();
            int[] values = new int[m];
            Integer[] order = new Integer[m];
            List<TreeNode> next = new ArrayList<>();
            for (int i = 0; i < m; i++) {
                TreeNode node = level.get(i);
                values[i] = node.val;
                order[i] = i;
                if (node.left != null) next.add(node.left);
                if (node.right != null) next.add(node.right);
            }
            Arrays.sort(order, Comparator.comparingInt(i -> values[i]));
            int[] p = new int[m];
            for (int rank = 0; rank < m; rank++) p[order[rank]] = rank;
            boolean[] seen = new boolean[m];
            for (int i = 0; i < m; i++) {
                if (seen[i]) continue;
                int length = 0;
                for (int j = i; !seen[j]; j = p[j]) {
                    seen[j] = true;
                    length++;
                }
                answer += length - 1;
            }
            level = next;
        }
        return answer;
    }
}

/**

var minimumOperations = function(root) {
    if (!root) return 0;
    let level = [root], answer = 0;
    while (level.length) {
        const values = level.map(node => node.val);
        const sorted = [...values].sort((a, b) => a - b);
        const rank = new Map(sorted.map((value, i) => [value, i]));
        const p = values.map(value => rank.get(value));
        const seen = new Array(p.length).fill(false);
        for (let i = 0; i < p.length; i++) {
            if (seen[i]) continue;
            let length = 0;
            for (let j = i; !seen[j]; j = p[j]) {
                seen[j] = true;
                length++;
            }
            answer += length - 1;
        }
        const next = [];
        for (const node of level) {
            if (node.left) next.push(node.left);
            if (node.right) next.push(node.right);
        }
        level = next;
    }
    return answer;
};

from typing import Optional

# TreeNode 由 LeetCode 提供，包含 val、left 和 right。
class Solution:
    def minimumOperations(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0
        level, answer = [root], 0
        while level:
            values = [node.val for node in level]
            rank = {value: i for i, value in enumerate(sorted(values))}
            p = [rank[value] for value in values]
            seen = [False] * len(p)
            for i in range(len(p)):
                if seen[i]:
                    continue
                length, j = 0, i
                while not seen[j]:
                    seen[j] = True
                    length += 1
                    j = p[j]
                answer += length - 1
            next_level = []
            for node in level:
                if node.left is not None:
                    next_level.append(node.left)
                if node.right is not None:
                    next_level.append(node.right)
            level = next_level
        return answer

#include <algorithm>
#include <utility>
#include <vector>
using namespace std;

// TreeNode 由 LeetCode 提供，包含 val、left 和 right。
class Solution {
public:
    int minimumOperations(TreeNode* root) {
        if (!root) return 0;
        vector<TreeNode*> level{root};
        int answer = 0;
        while (!level.empty()) {
            int m = static_cast<int>(level.size());
            vector<pair<int, int>> order;
            vector<TreeNode*> next;
            for (int i = 0; i < m; ++i) {
                TreeNode* node = level[i];
                order.emplace_back(node->val, i);
                if (node->left) next.push_back(node->left);
                if (node->right) next.push_back(node->right);
            }
            sort(order.begin(), order.end());
            vector<int> p(m);
            for (int rank = 0; rank < m; ++rank)
                p[order[rank].second] = rank;
            vector<bool> seen(m, false);
            for (int i = 0; i < m; ++i) {
                if (seen[i]) continue;
                int length = 0;
                for (int j = i; !seen[j]; j = p[j]) {
                    seen[j] = true;
                    ++length;
                }
                answer += length - 1;
            }
            level = move(next);
        }
        return answer;
    }
};
