链表中的下一个
更大节点

从链表出发，观察“尚未等到更大值”的节点如何被一次性解决。

题目

给定含有 n 个节点的链表 head。对每个节点，找到它右侧第一个值严格更大的节点，并把该值放入答案；若不存在，答案为 0。返回按链表顺序排列的整数数组。

示例 1

输入：head = [2,1,5]
输出：[5,5,0]

示例 2

输入：head = [2,7,4,3,5]
输出：[7,0,5,5,0]

约束

  • 链表节点数为 n
  • 1 ≤ n ≤ 10⁴
  • 1 ≤ Node.val ≤ 10⁹

等待区：单调栈实验台

栈中保存仍在等待答案的下标；新值更大时，从栈顶开始结算。

题解：让更大值结算所有等待者

核心洞察

先把链表值依次放入数组。扫描数组时维护一个“值单调不增”的下标栈：栈内节点还没遇到右侧更大值。当前值大于栈顶对应值时，当前节点就是栈顶节点遇到的第一个更大节点。

完整过程

  1. 遍历链表得到数组 values，答案数组初始化为全 0。
  2. 从左到右扫描下标 i。
  3. 当栈非空且 values[i] > values[stack.top]，弹出下标 j，设置 answer[j] = values[i]。
  4. 把 i 入栈。扫描结束后，栈中剩余下标没有更大节点，答案保持 0。

正确性

栈中下标按出现顺序保存，且对应值单调不增。下标 j 被弹出前，所有已经扫描且位于它右侧的值都不大于 values[j]，否则它早已被弹出；触发弹出的当前值严格更大，因此它恰好是 j 右侧第一个更大值。最终未弹出的节点右侧不存在更大值，保留 0 正确。

边界与复杂度

  • 单节点、严格递减或全相等：答案全为 0。
  • 相等值不能触发弹栈，因为题目要求“严格更大”。
  • 每个下标最多入栈、出栈一次；时间 O(n)，数组与栈空间 O(n)。

替代方案

对每个节点向右暴力寻找需要 O(n²) 时间。也可反转链表后维护候选值栈，但会修改链表结构，恢复链表还增加实现负担。

面试追问

  • 若要求下一个“大于等于”，弹栈条件应如何改变？
  • 能否返回节点距离而非节点值？只需把答案改为 i - j。
  • 为何栈存下标而不是值？因为答案需要写回原位置。

常见错误

  • 用 >= 弹栈，误把相等值当作更大值。
  • 只弹一次，没有用 while 同时结算多个等待节点。
  • 栈里只存值，失去答案写回位置。

完整代码

class Solution {
    public int[] nextLargerNodes(ListNode head) {
        List<Integer> values = new ArrayList<>();
        for (ListNode p = head; p != null; p = p.next) values.add(p.val);
        int[] answer = new int[values.size()];
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < values.size(); i++) {
            while (!stack.isEmpty() && values.get(i) > values.get(stack.peek())) {
                answer[stack.pop()] = values.get(i);
            }
            stack.push(i);
        }
        return answer;
    }
}

class Solution:
    def nextLargerNodes(self, head: Optional[ListNode]) -> List[int]:
        values = []
        while head:
            values.append(head.val)
            head = head.next
        answer = [0] * len(values)
        stack = []
        for i, value in enumerate(values):
            while stack and value > values[stack[-1]]:
                answer[stack.pop()] = value
            stack.append(i)
        return answer
class Solution {
public:
    vector<int> nextLargerNodes(ListNode* head) {
        vector<int> values;
        for (auto* p = head; p != nullptr; p = p->next) values.push_back(p->val);
        vector<int> answer(values.size(), 0), stack;
        for (int i = 0; i < (int)values.size(); ++i) {
            while (!stack.empty() && values[i] > values[stack.back()]) {
                answer[stack.back()] = values[i];
                stack.pop_back();
            }
            stack.push_back(i);
        }
        return answer;
    }
};
