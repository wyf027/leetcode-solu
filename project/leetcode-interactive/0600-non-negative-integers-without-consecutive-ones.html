Digit DP · Fibonacci counting

从“枚举数字”改成“统计分支”

预先计算固定长度的合法二进制串数量，再从高位沿着 n 的边界行走。每遇到一个 1，就一次性收入把该位改成 0 的整棵合法分支。

核心洞察

设 f[i] 表示长度恰为 i 的 0/1 串中，不含连续 1 的串数。按首位分类：

  • 首位放 0：后面还有 f[i-1] 种。
  • 首位放 1：下一位只能是 0，后面还有 f[i-2] 种。
f[0] = 1, f[1] = 2, f[i] = f[i-1] + f[i-2]

它形似斐波那契，但真正关键是：f[i] 能在扫描上界时直接统计剩余 i 位的整支合法方案。

完整过程

  1. 计算 f[0..30]。
  2. 从 n 的最高可能位向最低位扫描，维护 prevBit 和答案 ans。
  3. 当前位为 1 时，把它改成 0 会得到严格小于 n 的前缀；后面 i 位可任取合法串，因此加上 f[i]。
  4. 若当前位与前一位都是 1，贴着 n 的边界已经非法，立即返回当前答案。
  5. 若全部位扫描完，说明 n 自身合法，最后加 1。

以 n = 5（二进制 101）为例

最高位 1：ans += f[2] = 3 → 收入 000, 001, 010 中间位 0：继续贴着上界 10… 最低位 1：ans += f[0] = 1 → 收入 100 扫描完成：101 自身合法，ans += 1，最终为 5

正确性证明

  1. 计数表正确。任意长度 i 的合法串，要么以 0 开头并对应一个长度 i-1 的合法串，要么以 10 开头并对应一个长度 i-2 的合法串；两类互斥且穷尽。
  2. 每次加法正确。扫描到 n 的某个 1 时，将该位取 0 的数字一定小于 n；此前前缀已固定，剩余 i 位的所有合法选择恰有 f[i] 个。
  3. 没有重复或遗漏。每个小于 n 的合法数字，与 n 第一次不同的位置唯一，因此只会归入一次对应分支。若边界出现 11，继续贴边的数字都不合法；若未出现，额外计入 n 本身。

结论：算法返回且仅返回区间 [0,n] 中二进制不含连续 1 的整数数量。

边界与复杂度

边界

  • n = 1：0 和 1 都合法，结果为 2。
  • 最高位不会有真实前导 1；扫描固定 31 位时，前导 0 不改变计数。
  • 若边界自身含 11，必须提前结束，不能再把 n 计入。
  • n <= 10^9，扫描 31 个二进制位足够。
时间复杂度O(log n)
空间复杂度O(log n)

由于题目整数位数上限固定，也常写作 O(1) 时间、O(1) 额外空间。

替代方案

记忆化数位 DP

状态可写成 (pos, prevOne, tight)：当前位置、上一位是否为 1、是否仍贴住上界。通用性强，适合扩展到“禁止某个模式”等问题，但本题状态很小，逐位计数更简洁。

按长度构造合法串

可以生成所有不含连续 1 的二进制串，再筛选不超过 n 的值。它比枚举 [0,n] 好，但仍生成了大量具体候选，不如直接统计。

有限状态自动机

把“上一位是 0 / 1”看成两个状态，用转移矩阵计数。适合把长度扩大到极大值，或推广到更复杂的禁用子串。

  • 如果禁止连续三个 1，计数递推和扫描状态怎样变化？
  • 为什么 JavaScript 中直接使用高位位运算要注意 32 位有符号语义？
  • 怎样将该思路抽象成通用数位 DP 模板？
  • 若上界是一个长达十万位的二进制字符串，哪些部分仍可线性处理？

常见错误

  • 把 f[i] 的含义混成“长度不超过 i”，导致下标偏一。
  • 遇到连续 1 后仍继续扫描，重复统计已经不可能贴边的分支。
  • 无条件执行最后的 ans + 1，错误计入本身不合法的 n。
  • 忽略数字 0；题目区间从 0 开始。
  • 枚举 0 到 n 并逐个检查，时间复杂度退化为 O(n log n)。

/**
 * @param {number} n
 * @return {number}
 */
var findIntegers = function(n) {
    const f = new Array(31).fill(0);
    f[0] = 1;
    f[1] = 2;

    for (let i = 2; i <= 30; i++) {
        f[i] = f[i - 1] + f[i - 2];
    }

    let ans = 0;
    let prevBit = 0;

    for (let i = 30; i >= 0; i--) {
        const bit = Math.floor(n / (2 ** i)) % 2;

        if (bit === 1) {
            ans += f[i];
            if (prevBit === 1) {
                return ans;
            }
            prevBit = 1;
        } else {
            prevBit = 0;
        }
    }

    return ans + 1;
};

    public int findIntegers(int n) {
