设计自助结算系统

把商品价格按到达顺序排队；每次询问都要立刻知道当前最高价。用下面的操作轨迹观察系统的状态变化，再在底部按需展开题解。

题意

实现 Checkout：add(value) 将价格加入队尾，remove() 移除并返回队首价格，get_max() 返回当前待结算商品的最高价格。空队列的 remove() 与 get_max() 返回 -1；三个操作的均摊复杂度都应为 O(1)。

题解

默认收起，避免首屏直接泄露思路。

核心洞察

普通队列保证先进先出。另维护一个从队首到队尾非递增的候选队列：新价格入队前，队尾所有更小价格已不可能再成为最大值，可以丢弃；相等价格不能丢弃，因为它们会在不同时间离开普通队列。

完整过程

  1. add(x)：把 x 放入普通队尾；持续移除候选队尾中小于 x 的价格，再把 x 追加到候选队尾。
  2. get_max()：空则 -1，否则候选队首就是答案。
  3. remove()：空则 -1；取出普通队首 x，若候选队首也为 x，同步移除它。

边界与复杂度

空队列必须先判断；重复最大值必须保留多个副本。每个元素最多进入并离开候选队列一次，因此三个操作均摊 O(1)，额外空间 O(n)。

替代方案

堆能查询最大值，但删除队首需要懒删除和计数，复杂度通常为 O(log n)。有序多重集合也为 O(log n)。题目要求均摊 O(1) 时，单调队列是更合适的选择。

面试追问

若要同时支持最小值？再维护一条单调递增候选队列。若允许按任意位置删除？需要额外的延迟删除记录，不能只靠这两条队列。

常见错误

  • 入队时删除 小于等于 新值的候选，导致重复最大值被提前抹掉。
  • 移除普通队首后忘记比较候选队首，留下已过期最大值。
  • 仅用一个变量记录最大值，删除它时无法恢复下一个最大值。
class Checkout {
    private final Deque<Integer> queue = new ArrayDeque<>();
    private final Deque<Integer> maxQ = new ArrayDeque<>();
    public int get_max() { return maxQ.isEmpty() ? -1 : maxQ.peekFirst(); }
    public void add(int value) {
        queue.offerLast(value);
        while (!maxQ.isEmpty() && maxQ.peekLast() < value) maxQ.pollLast();
        maxQ.offerLast(value);
    }
    public int remove() {
        if (queue.isEmpty()) return -1;
        int value = queue.pollFirst();
        if (value == maxQ.peekFirst()) maxQ.pollFirst();
        return value;
    }
}
class Checkout {
  constructor() { this.q = []; this.maxQ = []; this.head = 0; this.maxHead = 0; }
  get_max() { return this.maxHead === this.maxQ.length ? -1 : this.maxQ[this.maxHead]; }
  add(value) {
    this.q.push(value);
    while (this.maxQ.length > this.maxHead && this.maxQ.at(-1) < value) this.maxQ.pop();
    this.maxQ.push(value);
  }
  remove() {
    if (this.head === this.q.length) return -1;
    const value = this.q[this.head++];
    if (value === this.maxQ[this.maxHead]) this.maxHead++;
    return value;
  }
}

class Checkout:
    def __init__(self):
        self.q = deque()
        self.max_q = deque()
    def get_max(self) -> int:
        return self.max_q[0] if self.max_q else -1
    def add(self, value: int) -> None:
        self.q.append(value)
        while self.max_q and self.max_q[-1] < value:
            self.max_q.pop()
        self.max_q.append(value)
    def remove(self) -> int:
        if not self.q: return -1
        value = self.q.popleft()
        if value == self.max_q[0]: self.max_q.popleft()
        return value
