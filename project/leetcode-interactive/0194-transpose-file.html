04 / Solution

题解默认隐藏

展开后查看 awk 状态机、正确性、复杂度与兼容方案。

POSIX awk · one input pass

第 i 个字段只进入第 i 个缓冲

转置后的第 i 行，就是输入每行的第 i 个字段按原顺序连接。用 result[i] 保存，扫描一遍即可。

核心过程与正确性

  1. awk 每读一行，NR 加一，NF 是字段数。
  2. 枚举 i = 1..NF：首行初始化 result[i]，后续行追加空格和 $i。
  3. 文件读完后，按 i 顺序打印各缓冲。

不变式：处理前 r 行后，result[i] 恰由这 r 行的第 i 个字段按行序组成。追加下一行的第 i 字段保持不变式；结束时每个缓冲即目标转置行。

复杂度、边界与兼容取舍

  • 设总字段字符量为 S，时间为 O(S)，字段访问次数为 R × C。
  • 缓冲全部输出，额外空间 O(S)；拼接常数取决于 awk 实现。
  • 另存 columns = NF，不依赖 END 中最后一行的 NF；空文件不输出。
  • 默认 awk 会合并连续空白；官方恰好保证单个空格分隔，因此语义匹配。
  • 逐列重复扫描文件能降低状态，但 I/O 变为 C 遍，不作为主线。

官方 Bash 可提交主解

# Read from the file file.txt and print its transposed content to stdout.
awk '
{
    columns = NF
    for (i = 1; i <= NF; i++) {
        if (NR == 1) {
            result[i] = $i
        } else {
            result[i] = result[i] " " $i
        }
    }
}
END {
    for (i = 1; i <= columns; i++) {
        print result[i]
    }
}' file.txt

LeetCode 提交语言选 Bash；脚本主体使用可移植 awk 语法。

诚实的跨工具方案

多次扫描

先取列数，再对每列各运行一次 awk，可避免保存全部输出，但文件读取 C 遍，时间与 I/O 为 O(C·S)。

非官方提交语言

Python 的 zip(*rows) 或 Ruby 的 transpose 可表达等价语义，但本题编辑器只提供 Bash，不能标为官方可提交答案。

常见错误

  • 混淆 NR 与 NF。
  • 忘记输出字段间的空格。
  • 产生多余行尾空格。
  • 读取首行后立刻输出，后续字段尚未到达。
  • 硬编码列数。
