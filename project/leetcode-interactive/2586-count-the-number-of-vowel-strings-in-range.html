统计范围内的
元音字符串数Count the Number of Vowel Strings in Range

给定下标从 0 开始的字符串数组 words，只关注闭区间 [left, right]。如果字符串的首字母和尾字母都是元音，就把它计入答案。

什么是“元音字符串”？

首字符与尾字符都属于下面 5 个小写元音。长度为 1 的字符串，首尾是同一个字符，也要按同一规则判断。

aeiou

Official examples

题意与示例

返回满足条件的 words[i] 数量，其中 i 必须落在闭区间 [left, right] 内；区间之外的单词不参与统计。

示例 1

输入：words = ["are","amy","u"], left = 0, right = 2
输出：2
  • "are"：a 开头、e 结尾，计数。
  • "amy"：y 不是元音，不计数。
  • "u"：首尾都是 u，计数。

示例 2

输入：words = ["hey","aeo","mu","ooo","artro"], left = 1, right = 4
输出：3
  • "aeo"、"ooo"、"artro" 满足首尾条件。
  • "mu" 的首字母 m 不是元音。

约束

  • 1 <= words.length <= 1000
  • 1 <= words[i].length <= 10
  • words[i] 仅由小写英文字母组成
  • 0 <= left <= right < words.length

Solution

一次区间扫描，双端点判断

无需处理整个单词，也无需构造新字符串。对区间内每个单词只看第一个和最后一个字符。

核心洞察

“元音字符串”的定义只依赖两个端点。把 5 个元音放入集合，首尾都在集合中时答案加一。

完整过程

  1. 准备元音集合 a,e,i,o,u。
  2. 从 left 遍历到 right（含两端）。
  3. 读取当前单词首尾字符；若二者都是元音，计数加一。
  4. 返回计数。

正确性说明

循环恰好访问闭区间 [left, right] 中的每个索引一次，不访问区间外元素。对任意被访问的单词，算法在且仅在其首字符和尾字符都属于元音集合时将计数加一，这与元音字符串的定义完全一致。因此循环结束后，计数正好等于目标区间内元音字符串的数量。

边界情况

  • left == right：只判断一个单词。
  • 单词长度为 1：同一字符同时作为首尾。
  • 整个区间都满足或都不满足：自然得到区间长度或 0。
  • 题目保证单词非空且只含小写字母，无需额外清洗。

复杂度

时间 O(right − left + 1) 额外空间 O(1)

元音集合大小固定为 5，因此成员判断可视为常数时间。

替代方案

可以用字符串 "aeiou" 的包含判断代替集合；集合语义更直接。若同一数组上有大量区间查询，可预处理前缀和，让每次查询降为 O(1)，但本题只有一次查询，没有必要。

常见错误

  • 把右边界写成 i < right，漏掉 right。
  • 只检查首字母或只检查尾字母。
  • 误认为长度为 1 的单词没有独立的尾字符。
  • 扫描完整数组，忘记限制到给定区间。

四语言完整代码

class Solution {
    public int vowelStrings(String[] words, int left, int right) {
        int count = 0;
        for (int i = left; i <= right; i++) {
            String word = words[i];
            if (isVowel(word.charAt(0))
                    && isVowel(word.charAt(word.length() - 1))) {
                count++;
            }
        }
        return count;
    }

    private boolean isVowel(char c) {
        return c == 'a' || c == 'e' || c == 'i'
                || c == 'o' || c == 'u';
    }
}

 * @param {string[]} words
 * @param {number} left
 * @param {number} right

var vowelStrings = function(words, left, right) {
    const vowels = new Set(['a', 'e', 'i', 'o', 'u']);
    let count = 0;

    for (let i = left; i <= right; i++) {
        const word = words[i];
        if (vowels.has(word[0]) && vowels.has(word[word.length - 1])) {
            count++;
        }
    }

    return count;
};
from typing import List


class Solution:
    def vowelStrings(
        self, words: List[str], left: int, right: int
    ) -> int:
        vowels = set("aeiou")
        return sum(
            words[i][0] in vowels and words[i][-1] in vowels
            for i in range(left, right + 1)
        )
class Solution {
public:
    int vowelStrings(vector<string>& words, int left, int right) {

        for (int i = left; i <= right; ++i) {
            const string& word = words[i];
            if (isVowel(word.front()) && isVowel(word.back())) {
                ++count;
            }
        }
        return count;
    }

private:

    }

面试追问

追问：如果有很多次区间查询？

先构造前缀计数 prefix，第 i 位记录前 i 个单词中元音字符串的数量。查询答案为 prefix[right + 1] - prefix[left]。

追问：如果允许大写字母？

在判断前统一转为小写，或把大写元音也加入集合。若输入来自不可信边界，还应先检查空字符串。

追问：为什么不检查中间字符？

定义只约束首尾，中间字符是什么都不影响答案。读取更多字符不会提高正确性。

追问：能否一行完成？

可以用语言内置的切片、过滤和求和表达，但面试中应优先保持边界清楚、复杂度易解释。
