Brief / 权限清单

题意

明确传入的是什么，比写代码更重要。

任务

单向链表中，给定一个既不是头节点、也不是尾节点的中间节点 node。请原地删除它；函数不返回任何数据。

只拿到 node，没有 head，也没有前驱节点。题目保证 node.next 存在。

官方示例

输入 node = 5（位于 head = [4, 5, 1, 9]）
输出 head = [4, 1, 9]

节点 5 被删除后，链表从 4 → 5 → 1 → 9 变为 4 → 1 → 9。

输入展示约定：参数名、等号和值完整保留。本题没有字符串输入；若出现字符串空格，页面会用 ␠ 显示，并把它解释为一个真实空格。

题解封条

先独立思考：当你无法修改前驱的 next 指针时，能否让当前节点“看起来已经不是原来的它”？

Reveal / 剪辑原理

核心洞察

不能让前驱跨过当前节点，就让当前节点冒充它的后继。

复制内容，删除后继。

把 node.next.val 复制到 node.val，再令 node.next = node.next.next。从链表观察者的角度，原目标值消失，后续连接保持连续。

Cut list / 操作单

完整过程

以 4 → 5 → 1 → 9、node = 5 为例。

  1. 读取后继
    当前节点可访问 node.next，读到值 1。
  2. 覆盖当前值
    执行 node.val = node.next.val，局部看起来变成 4 → 1 → 1 → 9。
  3. 跨过后继
    执行 node.next = node.next.next，第一个值为 1 的节点直接连接到 9。
  4. 得到结果
    外部遍历结果为 4 → 1 → 9，原目标值 5 已消失。

Trim marks / 限制线

边界

这个技巧依赖非常具体的题目保证。

可以处理

  • 目标节点在链表内部，后继必然存在。
  • 节点值允许被修改，外部只关心链表最终值序列。
  • 目标后继即使是尾节点，也能复制后将指针设为 null。

不能照搬

  • 目标是尾节点：没有后继可复制，且没有前驱可断链。
  • 节点值不可修改或节点身份被外部引用：复制值会破坏语义。
  • 要求真正释放指定对象或保留后继对象身份时，需要重新审视接口。

Runtime / 成片成本

复杂度

两次赋值，不随链表长度变化。

O(1)时间复杂度
O(1)额外空间

Other cuts / 备选剪法

替代方案

接口一旦不同，最佳方案也会不同。

若给出 head

从头遍历找到目标前驱，令前驱的 next 指向目标后继。时间 O(n)，但能删除尾节点，也不会篡改目标节点内容。

若是双向链表

直接使用 prev 和 next 修复两侧连接，仍可 O(1) 删除，并真正断开指定节点。

Director notes / 深挖

面试追问

把两行代码背后隐藏的对象语义讲清楚。

为什么不能删除尾节点？

尾节点没有后继，无法通过“后继内容前移”伪装删除；又拿不到前驱，不能将前驱指针设为 null。

它真的删除了传入对象吗？

严格说没有。传入对象仍在链中，只是值变成后继值；真正从链中断开的是原后继对象。

若值很大，复杂度还是 O(1) 吗？

常规模型把值复制视作 O(1)。若值是需要深拷贝的大对象，则应把复制成本纳入分析。

外部持有后继引用会怎样？

后继对象会被断链，外部引用仍可指向它；这说明本技巧只保证链表的可观察序列，而非所有对象身份不变。

Outtakes / 废片

常见错误

最常见的失误来自误读参数和操作顺序。

把 node 当成 head

从 node 开始遍历无法找到它的前驱；题目刻意不给头指针。

只改 next，不复制值

node.next = node.next.next 删除的是后继值，目标值仍保留，结果错误。

先跨过再读取

若先修改 node.next，会丢失需要复制的直接后继值，操作顺序不可颠倒。

返回 head

官方签名要求 void / None，只原地修改；不要擅自改变返回契约。

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) { val = x; }
 * }
 */
class Solution {
    public void deleteNode(ListNode node) {
        node.val = node.next.val;
        node.next = node.next.next;
    }
}
/**
 * Definition for singly-linked list.
 * function ListNode(val) {
 *     this.val = val;
 *     this.next = null;
 * }
 */
var deleteNode = function (node) {
    node.val = node.next.val;
    node.next = node.next.next;
};

 * Definition for singly-linked list.
