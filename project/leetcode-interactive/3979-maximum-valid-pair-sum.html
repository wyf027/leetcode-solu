最大有效数对和

把“间距至少为 k”翻译成：当右端点走到 j 时，只能从下标 0…j-k 中挑左端点。维护这段可用前缀的最大值，即可在线得到每个右端点的最优数对。

题意

给定整数数组 nums 与整数 k。有效下标对 (i, j) 满足 0 ≤ i < j < n 且 j - i ≥ k；返回所有有效对中 nums[i] + nums[j] 的最大值。

示例 1
nums = [1, 3, 5, 2, 8]，k = 2
输出：13，来自 i = 2, j = 4。
示例 2
nums = [5, 1, 9]，k = 1
输出：14。

约束与取舍

2 ≤ nums.length ≤ 10⁵，1 ≤ nums[i] ≤ 10⁹，1 ≤ k ≤ n - 1。

无需枚举所有合法对。对固定的 j，只保留可用左半边的最大 nums[i] 就足够了。

空格在输入中以 ␠ 显示；数组逗号后可有空格。

题解：前缀最大值 + 右端点扫描

核心洞察

处理 j 前，所有满足 i ≤ j-k 的位置都已经被纳入候选池。候选池中最大值与 nums[j] 相加，就是右端点固定为 j 的最优答案。

完整过程

  1. 令 bestLeft = -∞、answer = -∞。
  2. 从 j = k 扫到 n-1。
  3. 先将 nums[j-k] 更新进 bestLeft。
  4. 用 bestLeft + nums[j] 更新 answer。

边界与复杂度

k = 1 时每一步都会解锁紧邻前一个元素；k = n-1 时只有一对有效。时间复杂度 O(n)，额外空间 O(1)。

替代方案、追问与常见错误

双重循环可做但为 O(n²)；排序会丢失下标距离信息。面试可追问：若要返回数对下标，同时维护最大值的下标即可。常见错误是先计算再解锁 j-k，会漏掉恰好距离为 k 的数对。
