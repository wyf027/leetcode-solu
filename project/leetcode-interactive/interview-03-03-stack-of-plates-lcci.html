Operating contract

题意

实现 StackOfPlates：由若干容量至多为 cap 的子栈组成；对外的 push/pop 行为应与一个普通栈一致。

接口

push(val) 把盘子放到最后一摞；pop() 从最后一摞弹出；popAt(index) 从指定子栈弹出。空集合、非法下标都返回 -1。

官方示例

输入：operations = ["StackOfPlates",␠"push",␠"push",␠"popAt",␠"pop",␠"pop"]
参数：arguments = [[1],␠[1],␠[2],␠[1],␠[],␠[]]
输出：[null,␠null,␠null,␠2,␠1,␠-1]

限制

  • 子栈达到 cap 后，新 push 必须创建下一摞。
  • 任意子栈弹空后都应立即删除，后续下标随之压缩。
  • cap = 0 时 push 不保存元素，所有弹出返回 -1。
  • 输入中的空格以 ␠ 显示，避免参数边界不可见。

推荐目标

用动态数组保存各子栈。普通 push/pop 只碰末尾；popAt 直接定位指定栈，弹空时删除该栈。题目不要求盘子向左滚动补位。

Modular rack operations manual

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误和四语言代码默认隐藏。

Core insight

把一个过高的栈切成若干个容量固定的子栈

用动态数组 stacks 保存所有子栈。最后一摞就是全局栈顶；满了才新建下一摞。popAt(i) 只弹出第 i 摞顶部，并在该摞为空时删除它。无需把右侧盘子逐个滚回补位。

完整过程

  1. cap = 0 时，push 直接忽略。
  2. 末栈不存在或已满时，新建一个空子栈。
  3. push(val) 把值压入最后一摞。
  4. pop() 等价于弹出最后一摞。
  5. popAt(index) 校验下标后弹出；若该摞变空，立即从集合中删除。

边界

  • cap = 0：集合始终为空。
  • 空集合执行 pop 返回 -1。
  • 负下标或越界下标执行 popAt 返回 -1。
  • 删除中间空栈后，右侧子栈下标向左压缩。

复杂度

push / pop摊还 O(1)
popAt 弹出O(1)
删除中间空栈O(s)
额外空间O(n)

替代方案

可用链表保存子栈，使删除已知节点 O(1)，但按 index 查找仍是 O(s)。若题目额外要求 rollover（弹出中间栈后从右边搬一个补位），实现和复杂度都会改变；本题没有该要求。

面试追问

  • 如果要求每个非末栈都保持满载，如何实现 rollover？
  • 怎样让 popAt 后删除中间栈接近 O(1)？
  • 线程安全时，新增/删除子栈如何同步？
  • 如何维护总元素数与当前子栈数？

常见错误

  • 没有处理 cap = 0，导致不断创建空栈。
  • 子栈弹空后没有删除，普通 pop 会命中空壳。
  • popAt 越界时访问数组，而不是返回 -1。
  • 误做 rollover，既增加复杂度又改变题目示例下标语义。

class StackOfPlates {
    private final int cap;
    private final java.util.List<java.util.Deque<Integer>> stacks =
        new java.util.ArrayList<>();

    public StackOfPlates(int cap) {
        this.cap = cap;
    }

    public void push(int val) {
        if (cap == 0) return;
        if (stacks.isEmpty() || stacks.get(stacks.size() - 1).size() == cap) {
            stacks.add(new java.util.ArrayDeque<>());
        }
        stacks.get(stacks.size() - 1).push(val);
    }

    public int pop() {
        return popAt(stacks.size() - 1);
    }

    public int popAt(int index) {
        if (index < 0 || index >= stacks.size()) return -1;
        int value = stacks.get(index).pop();
        if (stacks.get(index).isEmpty()) stacks.remove(index);
        return value;
    }
}
var StackOfPlates = function (cap) {
  this.cap = cap;
  this.stacks = [];
};

StackOfPlates.prototype.push = function (val) {
  if (this.cap === 0) return;
  const last = this.stacks[this.stacks.length - 1];
  if (!last || last.length === this.cap) this.stacks.push([]);
  this.stacks[this.stacks.length - 1].push(val);
};

StackOfPlates.prototype.pop = function () {
  return this.popAt(this.stacks.length - 1);
};

StackOfPlates.prototype.popAt = function (index) {
  if (index < 0 || index >= this.stacks.length) return -1;
  const value = this.stacks[index].pop();
  if (this.stacks[index].length === 0) this.stacks.splice(index, 1);
  return value;
};
class StackOfPlates:
    def __init__(self, cap: int):
        self.cap = cap
        self.stacks = []

    def push(self, val: int) -> None:
        if self.cap == 0:
            return
        if not self.stacks or len(self.stacks[-1]) == self.cap:
            self.stacks.append([])
        self.stacks[-1].append(val)

    def pop(self) -> int:
        return self.popAt(len(self.stacks) - 1)

    def popAt(self, index: int) -> int:
        if index < 0 or index >= len(self.stacks):
            return -1
        value = self.stacks[index].pop()
        if not self.stacks[index]:
            self.stacks.pop(index)
        return value
class StackOfPlates {
private:
    int cap;
    std::vector<std::vector<int>> stacks;

public:
    StackOfPlates(int cap) : cap(cap) {}

    void push(int val) {
        if (cap == 0) return;
        if (stacks.empty() || stacks.back().size() == cap) {
            stacks.push_back({});
        }
        stacks.back().push_back(val);
    }

    int pop() {
        return popAt(static_cast<int>(stacks.size()) - 1);
    }

    int popAt(int index) {
        if (index < 0 || index >= static_cast<int>(stacks.size())) return -1;
        int value = stacks[index].back();
        stacks[index].pop_back();
        if (stacks[index].empty()) stacks.erase(stacks.begin() + index);
        return value;
    }
};
