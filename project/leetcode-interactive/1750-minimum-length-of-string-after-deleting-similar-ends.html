删除字符串两端相同字符后的最短长度

Minimum Length of String After Deleting Similar Ends

字符串双指针最多 10⁵ 个字符

题目

给定只由 a、b、c 组成的字符串 s。你可以执行以下操作任意次（也可以一次都不执行）：

  1. 从当前字符串选择一个非空、且所有字符相同的前缀。
  2. 再选择一个非空、且所有字符相同的后缀。
  3. 前缀和后缀不能在任何下标相交。
  4. 两个被选区域中的字符必须相同。
  5. 同时删除此前缀和后缀。
RETURN

返回经过任意次操作后，字符串能够达到的最短长度。

官方示例

示例 1

输入：s = "ca" 输出：2

两端字符不同，无法执行删除。

示例 2

输入：s = "cabaabac" 输出：0

依次可去掉两端的 c、a、b、a，最终为空串。

示例 3

输入：s = "aabccabba" 输出：3

先删除前缀 aa 与后缀 a，再删除前缀 b 与后缀 bb，剩下 "cca"。

约束

  • 1 <= s.length <= 105
  • s 仅由 'a'、'b'、'c' 构成。

    Solution

    双指针：一次吃掉两端的同色块

    核心洞察

    只要当前首尾字符相同，这一轮就可以、也应该把两端连续的同字符块全部删除。少删没有收益：剩余的同色字符仍挡在边界，下轮只能继续删它们。

    因此令 left、right 指向当前区间两端。若字符相等，记住该字符并分别跳过左、右两端的整个连续块；若不等，任何操作都不再合法，答案就是区间长度。

    完整过程

    1. 初始化 left = 0、right = s.length - 1。
    2. 当 left < right 且 s[left] == s[right] 时，记录边界字符 c。
    3. 从左向右越过所有等于 c 的字符；从右向左越过所有等于 c 的字符。
    4. 重复，直到区间为空、只剩一个字符，或两端字符不同。
    5. 返回 right - left + 1。区间为空时该式自然得到 0。

    正确性证明

    引理：若当前两端字符不同，则不存在合法操作。因为任何非空前缀必含首字符，任何非空后缀必含尾字符，而合法操作要求两者字符相同。

    引理：若当前两端字符均为 c，删除两端完整的连续 c 块不会损失最优解。任何合法操作都只能从两端删除若干个 c；未删完的边界 c 仍会阻挡内部字符，之后还得继续删除。因此可把这些删除合并为一次完整块删除。

    结论：算法每轮执行一个不影响最优性的完整块删除；停止时由第一个引理已无操作可做，所以剩余区间长度正是最小长度。

    时间复杂度O(n)每个字符最多被指针越过一次
    空间复杂度O(1)只使用常数个变量

    边界情况

    • 长度为 1：不能选择不相交的前后缀，返回 1。
    • 首尾不同：不执行操作，返回原长度。
    • 所有字符相同且长度大于 1：可全部删除，返回 0。
    • 删除多轮后只剩一个字符：返回 1。

    替代方案

    可以真的反复截取新字符串，但切片与复制可能使总成本退化到 O(n²)，并产生额外空间。双端队列也能模拟，却需要 O(n) 空间；双指针更直接。

    常见错误

    • 只从左右各删一个字符，没有跳过完整同色块。
    • 循环条件写成 left <= right 后误删唯一剩余字符。
    • 用最初的边界字符扫描所有轮次，没有在每轮重新记录。
    • 空区间时硬编码分支，导致长度计算 off-by-one。

    四语言完整代码

    class Solution {
    public int minimumLength(String s) {
        int left = 0;
        int right = s.length() - 1;

        while (left < right && s.charAt(left) == s.charAt(right)) {
            char boundary = s.charAt(left);
            while (left <= right && s.charAt(left) == boundary) {
                left++;
            }
            while (left <= right && s.charAt(right) == boundary) {
                right--;
            }
        }
        return right - left + 1;
    }
}

    面试追问

    为什么能贪心删完整块？

    因为同色边界不删完就无法接触更内层字符，把多次同色删除合并不会改变后续可达状态。

    字符集扩大后还能用吗？

    可以。算法只比较字符是否相等，与字符种类数量无关。

    若要返回最终字符串？

    算法结束后返回 s.substring(left, right + 1)；但复制结果需要与剩余长度成正比的额外空间。
