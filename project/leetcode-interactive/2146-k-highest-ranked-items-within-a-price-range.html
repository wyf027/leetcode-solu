01题目与排名规则

给定一个从 0 开始编号的 m × n 网格 grid。值为 0 的格子是墙，不能进入；值为 1 的格子是空地；大于 1 的值表示该处物品的价格。空地和物品格子都可以通行。

从 start = [row, col] 出发，每次可以向上、下、左、右移动一格，花费一步。只选择价格落在闭区间 pricing = [low, high] 中且能够到达的物品。

比较两件物品时，按下列优先级找到第一个不同的指标，数值更小者排名更高：

01 / 首要最短路径步数
02 / 同距离物品价格
03 / 同价格行坐标
04 / 同行列坐标

返回排名最高的前 k 件物品的 [行, 列] 坐标，并按排名从高到低排列。如果可达的合格物品不足 k 件，返回全部；没有则返回空数组。

价格范围决定是否入选，不决定能否经过。起点可能就是物品格；墙会让实际最短路径长于直线方向的距离。

02官方示例

官方示例 1

输入：grid = [[1,2,0,1],[1,3,0,1],[0,2,5,1]], pricing = [2,5], start = [0,0], k = 3
输出：[[0,1],[1,1],[2,1]]

四件候选物品的距离依次为 1、2、3、4；取前三个坐标。

官方示例 2

输入：grid = [[1,2,0,1],[1,3,3,1],[0,2,5,1]], pricing = [2,3], start = [2,3], k = 2
输出：[[2,1],[1,2]]

(2,1) 与 (1,2) 距离均为 2，价格分别为 2、3，先选较便宜者；其余候选距离为 3、4。

官方示例 3

输入：grid = [[1,1,1],[0,0,1],[2,3,4]], pricing = [2,3], start = [0,0], k = 3
输出：[[2,1],[2,0]]

(2,1) 距离为 5，(2,0) 距离为 6；只有两件可达候选，因此返回两项。

03约束

  • m == grid.length，n == grid[i].length。
  • 1 ≤ m, n ≤ 10⁵，且 1 ≤ m × n ≤ 10⁵。
  • 0 ≤ grid[i][j] ≤ 10⁵。
  • pricing.length == 2，2 ≤ low ≤ high ≤ 10⁵。
  • start.length == 2，0 ≤ row ≤ m − 1，0 ≤ col ≤ n − 1。
  • grid[row][col] > 0，即起点不是墙。
  • 1 ≤ k ≤ m × n。

题解 · 先求距离，再按四元组排名

核心洞察

每次移动的代价都是 1，因而可用广度优先搜索（BFS）求出起点到每个可达格子的最短步数。物品的排名可以直接表示为四元组 (距离, 价格, 行, 列)，对全部候选按四元组升序排序，再取前 K 项。

距离的计算与价格筛选分开：所有非零格子都参与搜索，仅符合价格范围的格子加入候选列表。

距离波前 × 排名账本

斜纹：墙虚线框 / S：起点浅绿：已发现青色 / 波前：下一层金框 / 入选：前 K
候选四元组 · 距离 / 价格 / 行 / 列
候选物品排名账本
顺序距离价格行列
输出坐标
每步处理完整距离层，最后一步统一排序。聚焦推演区域可用 ← / → 切换；Tab 访问控件，Enter / 空格激活按钮。自动播放需主动开启。


完整过程
  1. 建立访问标记，把起点及距离 0 放进 FIFO 队列，并立即标记已访问。
  2. 取出队首 (r, c, d)。如果当前价格在范围内，记录 (d, grid[r][c], r, c)。
  3. 检查上下左右的邻格。坐标合法、不是墙、未访问时，将它标记并以距离 d + 1 入队。价格超出范围也照常入队。
  4. 队列耗尽后，候选已经包含所有可达且价格合格的物品。
  5. 按四元组字典序排序，取前 min(k, 候选数) 项，只输出各项的行、列坐标。
示例 2 的两项距离同为 2：(2,2,2,1) 排在 (2,3,1,2) 前面，因为第二个指标价格已经分出胜负，不能再优先比较行。


正确性说明
  1. 距离正确：起点距离为 0。BFS 按层扩展；若第 d 层的距离正确，其未访问邻格通过一条边可在 d+1 步到达。如果存在更短路径，该格会由更早的层发现，矛盾。因此首次入队时的距离就是最短距离。
  2. 候选不重不漏：所有可达非墙格子都会沿某条路径被发现；入队即标记保证每格只处理一次。只在价格位于闭区间时记录，因此候选集合恰为全部可达合格物品。
  3. 排名正确：四元组各分量的先后顺序与题目的四个排名指标完全一致。字典序升序排列就是题目要求的顺序；取前 K 项，或不足 K 时全部返回，必然得到所需结果。


边界与常见错误
  • 起点也需要筛选，合格时距离是 0。
  • 没有候选时返回 []；不足 K 时不要补位。
  • low、high 两端都包含。
  • 值 1 是空地，不是商品；官方下界 low ≥ 2 会自然排除它。
  • 范围外的商品不是墙；跳过它的扩展会漏掉后面的候选。
  • 不能用曼哈顿距离代替绕墙后的真实距离。
  • 不能把 BFS 的邻居入队顺序当作价格、行列排序。
  • 不要刚遇到 K 件就停，当前距离层的后续物品可能排名更高。
  • JavaScript 队列用 head 指针，避免反复 shift()；访问数组每一行单独创建。
复杂度
设 N = m × n，合格可达物品数为 P ≤ N。
  • BFS 与访问数组初始化：O(N)。每个格子至多入队一次，每次查看四个方向。
  • 候选排序：O(P log P)；截取坐标：O(min(k, P))。
  • 总时间：O(N + P log P)，最坏 O(N log N)。P 为 0 或 1 时，排序只需常数开销。
  • 辅助空间：O(N + P) = O(N)，用于访问标记、队列和候选。输出另占 O(min(k, P))。
四份代码采用相同的完整 BFS + 排序方案，不修改输入网格。推演为了回退保存历史快照，其额外空间仅用于小型示例，不代表提交代码的空间复杂度。


替代方案与面试追问
  • 怎样安全提前停止？逐层 BFS，只对当前层的候选按价格、行、列排序。把本层需要的部分加入答案后，若已有 K 项即可停止，不必扩展更远层；但必须先收集完整的当前层候选。
  • K 很小怎么办？完整 BFS 过程中，用大小不超过 K 的最大堆保存当前最优 K 个四元组，堆顶是最差者。候选维护 O(P log(k+1))，最后对最多 K 项排序。BFS 仍占 O(N) 空间。
  • 每一步代价不同呢？非负权重改用 Dijkstra 求最短距离；若权重只有 0 和 1，可考虑 0-1 BFS。排名后续三个指标不变。
  • 能把优先级塞进普通 BFS 的邻居顺序吗？不能。邻居只覆盖一个父节点周围，无法保证整个距离层的全局价格与坐标顺序。
  • 同一地图和起点，多次询问价格范围？距离可以预先计算复用；是否再建索引取决于询问规模与价格分布，先评估直接筛选并排序的成本。

Java
import java.util.*;

class Solution {
    public List<List<Integer>> highestRankedKItems(
            int[][] grid, int[] pricing, int[] start, int k) {
        int m = grid.length, n = grid[0].length;
        boolean[][] seen = new boolean[m][n];
        ArrayDeque<int[]> queue = new ArrayDeque<>();
        List<int[]> items = new ArrayList<>();
        queue.offer(new int[]{start[0], start[1], 0});
        seen[start[0]][start[1]] = true;
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int r = cur[0], c = cur[1], d = cur[2];
            int price = grid[r][c];
            if (price >= pricing[0] && price <= pricing[1]) {
                items.add(new int[]{d, price, r, c});
            }
            for (int[] dir : dirs) {
                int nr = r + dir[0], nc = c + dir[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n
                        && grid[nr][nc] != 0 && !seen[nr][nc]) {
                    seen[nr][nc] = true;
                    queue.offer(new int[]{nr, nc, d + 1});
                }
            }
        }
        items.sort((a, b) -> {
            for (int i = 0; i < 4; i++) {
                int cmp = Integer.compare(a[i], b[i]);
                if (cmp != 0) return cmp;
            }
            return 0;
        });
        List<List<Integer>> answer = new ArrayList<>();
        for (int i = 0; i < Math.min(k, items.size()); i++) {
            int[] item = items.get(i);
            answer.add(Arrays.asList(item[2], item[3]));
        }
        return answer;
    }
}

/**
 * @param {number[][]} grid
 * @param {number[]} pricing
 * @param {number[]} start
 * @param {number} k
 * @return {number[][]}
 */
var highestRankedKItems = function(grid, pricing, start, k) {
    const m = grid.length, n = grid[0].length;
    const seen = Array.from({ length: m }, () => Array(n).fill(false));
    const queue = [[start[0], start[1], 0]], items = [];
    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    seen[start[0]][start[1]] = true;
    for (let head = 0; head < queue.length; head++) {
        const [r, c, d] = queue[head], price = grid[r][c];
        if (price >= pricing[0] && price <= pricing[1]) {
            items.push([d, price, r, c]);
        }
        for (const [dr, dc] of dirs) {
            const nr = r + dr, nc = c + dc;
            if (nr >= 0 && nr < m && nc >= 0 && nc < n &&
                grid[nr][nc] !== 0 && !seen[nr][nc]) {
                seen[nr][nc] = true;
                queue.push([nr, nc, d + 1]);
            }
        }
    }
    items.sort((a, b) =>
        a[0] - b[0] || a[1] - b[1] || a[2] - b[2] || a[3] - b[3]);
    return items.slice(0, k).map(item => [item[2], item[3]]);
};


Python 3
from collections import deque
from typing import List

class Solution:
    def highestRankedKItems(self, grid: List[List[int]],
                           pricing: List[int], start: List[int],
                           k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        seen = [[False] * n for _ in range(m)]
        queue = deque([(start[0], start[1], 0)])
        seen[start[0]][start[1]] = True
        items = []
        while queue:
            r, c, d = queue.popleft()
            price = grid[r][c]
            if pricing[0] <= price <= pricing[1]:
                items.append((d, price, r, c))
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if (0 <= nr < m and 0 <= nc < n
                        and grid[nr][nc] != 0 and not seen[nr][nc]):
                    seen[nr][nc] = True
                    queue.append((nr, nc, d + 1))
        items.sort()
        return [[r, c] for _, _, r, c in items[:k]]

#include <algorithm>
#include <array>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> highestRankedKItems(vector<vector<int>>& grid,
            vector<int>& pricing, vector<int>& start, int k) {
        int m = grid.size(), n = grid[0].size();
        vector<vector<bool>> seen(m, vector<bool>(n, false));
        queue<array<int, 3>> q;
        vector<array<int, 4>> items;
        q.push({start[0], start[1], 0});
        seen[start[0]][start[1]] = true;
        const int dirs[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!q.empty()) {
            auto cur = q.front();
            q.pop();
            int r = cur[0], c = cur[1], d = cur[2];
            int price = grid[r][c];
            if (pricing[0] <= price && price <= pricing[1]) {
                items.push_back({d, price, r, c});
            }
            for (const auto& dir : dirs) {
                int nr = r + dir[0], nc = c + dir[1];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n &&
                        grid[nr][nc] != 0 && !seen[nr][nc]) {
                    seen[nr][nc] = true;
                    q.push({nr, nc, d + 1});
                }
            }
        }
        sort(items.begin(), items.end());
        vector<vector<int>> answer;
        for (int i = 0; i < min(k, (int)items.size()); ++i) {
            answer.push_back({items[i][2], items[i][3]});
        }
        return answer;
    }
};
