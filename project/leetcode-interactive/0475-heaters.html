供暖器HEATERS

一条水平线上，房屋与供暖器各自占据若干坐标。请为所有供暖器设定同一个尽可能小的加热半径，让每一栋房屋都落入至少一个覆盖范围。

Problem statement

题意与输入输出

给定两个整数数组 houses 与 heaters，元素表示它们在水平数轴上的位置。返回能够覆盖全部房屋时，所有供暖器共同采用的最小加热半径。

函数形式

findRadius(houses: integer[], heaters: integer[]) -> integer

若房屋与某个供暖器的坐标距离不超过半径，该房屋便能获得供暖。一个房屋只需被任意一个供暖器覆盖。

统一半径：不能为不同供暖器分别指定半径；最终返回值是全体供暖器共用的半径标准。

约束

  • 1 ≤ houses.length, heaters.length ≤ 3 × 10⁴
  • 1 ≤ houses[i], heaters[i] ≤ 10⁹
  • 数组不保证有序。
Example 01
输入：houses = [1,2,3] heaters = [2] 输出：1

供暖器位于 2，半径为 1 时能覆盖三个房屋。

Example 02
输入：houses = [1,2,3,4] heaters = [1,4] 输出：1

两个供暖器采用相同的半径 1，整段房屋均被覆盖。

Example 03
输入：houses = [1,5] heaters = [2] 输出：3

房屋 5 距唯一供暖器 2 的距离为 3。

Complete solution

排序 + 二分查找最近供暖器

把全局的最小统一半径，拆成每栋房屋的局部最小需求，再取其中的最大值。

INSIGHT 01

局部需求

一栋房屋只关心离它最近的供暖器；这段最短距离，就是覆盖该房屋所需的最小半径。

INSIGHT 02

统一标准

所有供暖器共用同一个半径，因此必须满足需求最大的那栋房屋。

INSIGHT 03

快速找最近点

供暖器排序后，对房屋做二分；最近供暖器只可能是插入位置右侧元素或其左邻居。

核心过程

  1. 将 heaters 升序排序。
  2. 遍历每个房屋坐标 house，二分找到第一个不小于它的供暖器下标 i。
  3. 若 i 存在，计算右侧距离；若 i - 1 存在，计算左侧距离。两者较小值是这栋房屋的最近距离。
  4. 用每栋房屋的最近距离更新全局最大值，遍历结束后返回该值。
answer = max over every house h { min over every heater t { |h - t| } }

为什么只检查二分位置两侧？

设二分找到的 i 是第一个满足 heaters[i] ≥ house 的位置。所有更靠右的供暖器坐标不小于 heaters[i]，距离不会更小；所有更靠左的供暖器坐标不大于 heaters[i-1]，距离也不会更小。因此最近点必在这两个边界候选中。

正确性证明

引理：局部距离正确

对任意房屋 h，二分边界左右两侧的最近候选分别是 i-1 与 i。由有序性，其他供暖器只会离 h 更远，所以算法得到的 d(h) 等于它到最近供暖器的距离。

定理：返回半径最小且可行

令 R = max d(h)。对每栋房屋都有 d(h) ≤ R，故半径 R 可覆盖全部房屋。若使用任意 R' < R，取得最大值的那栋房屋无法被覆盖。因此 R 是最小可行统一半径。

边界情况

  • 房屋恰好与供暖器同坐标时，局部需求为 0。
  • 房屋位于所有供暖器左侧或右侧时，二分只会留下一个有效候选，必须正确处理不存在的另一侧。
  • 只有一个供暖器时，答案是所有房屋到它距离的最大值。
  • 输入未排序；只需对供暖器排序，房屋遍历顺序不影响最大值。
  • 坐标上限为 10⁹，两坐标之差仍在 32 位有符号整数范围内；实现仍应避免用错误哨兵参与减法。

复杂度

设房屋数为 n，供暖器数为 m。排序耗时 O(m log m)，每栋房屋二分耗时 O(log m)，总时间为 O(m log m + n log m)。除排序所需空间外，额外工作空间为 O(1)（具体排序实现可能使用 O(log m) 栈空间）。

替代方案

  • 排序 + 双指针：同时排序房屋和供暖器，单调移动供暖器指针，寻找每栋房屋的最近点。时间为 O(n log n + m log m)，扫描阶段为线性，适合一次性批量处理。
  • 对答案二分：猜测半径并检查能否覆盖全部房屋。可行但多一层搜索，通常不如直接计算每栋房屋的最近距离简洁。

四种语言完整实现

Java · LeetCode 提交代码 
import java.util.Arrays;

class Solution {
    public int findRadius(int[] houses, int[] heaters) {
        Arrays.sort(heaters);
        int answer = 0;

        for (int house : houses) {
            int left = 0;
            int right = heaters.length;

            while (left < right) {
                int mid = left + (right - left) / 2;
                if (heaters[mid] < house) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }

            int distance = Integer.MAX_VALUE;
            if (left < heaters.length) {
                distance = Math.min(distance, heaters[left] - house);
            }
            if (left > 0) {
                distance = Math.min(distance, house - heaters[left - 1]);
            }
            answer = Math.max(answer, distance);
        }

        return answer;
    }
}

from bisect import bisect_left
from typing import List


class Solution:
    def findRadius(self, houses: List[int], heaters: List[int]) -> int:
        heaters.sort()
        answer = 0

        for house in houses:
            index = bisect_left(heaters, house)
            distance = float("inf")

            if index < len(heaters):
                distance = min(distance, heaters[index] - house)
            if index > 0:
                distance = min(distance, house - heaters[index - 1])

            answer = max(answer, distance)

        return answer

class Solution {
public:
    int findRadius(vector<int>& houses, vector<int>& heaters) {
        sort(heaters.begin(), heaters.end());
        int answer = 0;

        for (int house : houses) {
            auto it = lower_bound(heaters.begin(), heaters.end(), house);
            int distance = INT_MAX;

            if (it != heaters.end()) {
                distance = min(distance, *it - house);
            }
            if (it != heaters.begin()) {
                distance = min(distance, house - *prev(it));
            }

            answer = max(answer, distance);
        }

        return answer;
    }
};

常见错误

  • 取所有“最近距离”的最小值；统一半径必须能满足最难覆盖的房屋，所以应取最大值。
  • 二分后只检查右侧供暖器，遗漏更近的左邻居。
  • 没有排序供暖器就使用二分查找。
  • 把数组下标当作坐标距离，或用 Math.abs 掩盖错误的边界选择。
  • 用一个固定但不够大的数字作为无穷大哨兵。

面试追问

如果房屋持续新增呢？

供暖器集合不变时，只需保持供暖器有序；每个新房屋独立二分并更新已见最大距离。

如果每个供暖器允许不同半径呢？

目标函数必须重新定义，例如最小化最大半径或半径总和；这不再是本题的统一标准模型。

能否做到线性扫描？

可以。先把两个数组都排序，再用单调指针为每栋房屋选择最近供暖器，扫描部分为 O(n + m)。

为什么不二分答案？

答案具有单调可行性，确实能二分；但直接求最近距离已经给出精确答案，步骤更少、边界更清晰。
