LCP 77. 符文储备

从任意符文中挑出尽可能多的一组，重排后让相邻魔力值的差不超过 1。把数值排好序，答案就是最长的“无断层”连续段。

排序 + 双指针O(n log n)可重排

题意

给定整数数组 runes，其中 runes[i] 是第 i 枚符文的魔力值。选取若干枚并重新排列，使任意相邻两枚的魔力值之差不超过 1，返回最多能携带多少枚。

示例 1

runes = [1, 3, 5, 4, 1, 7]

输出：3，可排为 [3, 4, 5]。

示例 2

runes = [1, 1, 3, 3, 2, 4]

输出：6，排序后没有断层。

约束：1 ≤ runes.length ≤ 10⁴，0 ≤ runes[i] ≤ 10⁴。输入中的空格仅为可读性展示；代码参数仍是 runes = […]。

交互：寻找最长无断层段

输入整数，用逗号或空格分隔。

题解：排序后，断层决定必须分组

核心洞察

任意可行排列中，若出现两个相邻值差大于 1 的数，就不能跨过这个缺口。因此排序后，每个相邻差 ≤ 1 的连续区间可以整体携带，最长区间就是最优答案。

完整过程

  1. 升序排序。
  2. 扫描相邻元素；差 ≤ 1，当前窗口扩展。
  3. 差 > 1，窗口必须重启。
  4. 维护最大窗口长度。

边界与复杂度

单元素答案为 1；重复值的差为 0，属于同一段；值差正好 1 也能相邻。排序耗时 O(n log n)，扫描 O(n)，额外空间取决于排序实现。

替代方案

值域已知为 0…10⁴，可计数后线性扫描存在的值，得到 O(n + U)。

常见错误

  • 误以为只能选值相等或差 1 的两枚；题目允许形成链，如 3,4,5。
  • 断层后忘记把当前长度重置为 1。
  • 把“重排”忽略，直接在原数组连续子数组中寻找。

面试追问

若不允许重排，问题会变成原数组的最长连续子数组；若相邻允许差不超过 k，只需把判断从 ≤ 1 改为 ≤ k。

四语言可提交代码

// Java
class Solution {
  public int runeReserve(int[] runes) {
    java.util.Arrays.sort(runes);
    int best = 1, cur = 1;
    for (int i = 1; i < runes.length; i++) {
      if (runes[i] - runes[i - 1] <= 1) cur++;
      else cur = 1;
      best = Math.max(best, cur);
    }
    return best;
  }
}
// JavaScript
var runeReserve = function (runes) {
  runes.sort((a, b) => a - b);
  let best = 1, cur = 1;
  for (let i = 1; i < runes.length; i++) {
    cur = runes[i] - runes[i - 1] <= 1 ? cur + 1 : 1;
    best = Math.max(best, cur);
  }
  return best;
};

class Solution:
    def runeReserve(self, runes: List[int]) -> int:
        runes.sort()
        best = cur = 1
        for i in range(1, len(runes)):
            cur = cur + 1 if runes[i] - runes[i - 1] <= 1 else 1
            best = max(best, cur)
        return best
