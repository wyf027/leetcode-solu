统计可能的树根数目

同一棵无根树，换一个根就会改写父子关系。你的任务是找出：有多少个根能让 Bob 至少猜对 k 次。

HARD 2581 非会员题 最多 10⁵ 个节点
2581

Problem

题目说明

Alice 有一棵包含 n 个节点的无向树，节点编号为 0 到 n - 1。长度为 n - 1 的数组 edges 描述树的每条边。

Bob 给出若干互不重复的猜测 [u, v]，表示他认为以某个节点为根时，u 是 v 的父节点。每个猜测都对应树中真实存在的一条边。

已知至少有 k 个猜测正确，请返回所有可能成为根的节点数量；若没有符合条件的根，返回 0。

参数形式

rootCount(edges, guesses, k) → integer

其中 edges: integer[][]、guesses: integer[][]、k: integer。

示例 1

输入：edges = [[0,1],[1,2],[1,3],[4,2]],
      guesses = [[1,3],[0,1],[1,0],[2,4]],
      k = 3
输出：3
解释：根为 0、1、2 时均有 3 个猜测正确；
      根为 3、4 时只有 2 个猜测正确。

示例 2

输入：edges = [[0,1],[1,2],[2,3],[3,4]],
      guesses = [[1,0],[3,4],[2,1],[3,2]],
      k = 1
输出：5
解释：任意节点作为根时，都至少有 1 个猜测正确。

约束

  • edges.length == n - 1
  • 2 ≤ n ≤ 10⁵
  • 1 ≤ guesses.length ≤ 10⁵
  • 所有节点编号都在 [0, n - 1] 内
  • 每条边和每个猜测中的两个节点互不相同
  • edges 表示一棵有效的树
  • 每个 guesses[j] 都对应树中的边
  • guesses 中没有重复项
  • 0 ≤ k ≤ guesses.length

Solution

两遍遍历：先计数，再换根

关键不是为每个根重新检查所有猜测，而是只计算根跨过一条边时发生的局部变化。

核心洞察

先任选节点 0 为根，求出正确猜测数 score[0]。若把根从相邻节点 x 移到 y，整棵树中只有边 x—y 的父子方向翻转。

score[y] = score[x] - guess(x,y) + guess(y,x)

完整过程

  1. 建立无向邻接表，并把有向猜测放入哈希集合。
  2. 以 0 为根遍历，记录每个节点的父节点与遍历顺序。
  3. 按父子边统计根为 0 时的正确猜测数。
  4. 沿遍历顺序应用换根公式，得到每个节点作为根时的分数。
  5. 统计分数不少于 k 的节点。

复杂度

建图、两次线性扫描及哈希查询的期望总时间为 O(n + g)，其中 g = guesses.length；邻接表、父节点、分数和哈希集合占用 O(n + g) 空间。

边界处理

  • k = 0 时所有节点都满足条件。
  • 同一条无向边的两个方向都可能分别出现在猜测中。
  • n = 10⁵，实现采用显式栈或顺序数组，避开深递归风险。
  • 答案可能为 0，也可能为 n。

正确性证明

  1. 初始计数正确：以 0 为根遍历后，每个非根节点都有唯一父节点；逐一检查 (parent[v], v) 是否被猜过，恰好统计所有在根 0 下成立的猜测。
  2. 换根公式正确：根从 x 移到相邻的 y 时，删去边 x→y 的原方向并加入 y→x 的新方向；其他边相对根的父子方向不变。因此分数只需减去猜测 (x,y) 的贡献，再加上猜测 (y,x) 的贡献。
  3. 覆盖所有根：树从 0 出发可达每个节点。按父节点顺序传播分数时，每个节点恰好从其父节点获得一次正确分数，所以得到所有可能根的分数。
  4. 结论：算法对且仅对分数至少为 k 的节点计数，返回值正是可能的树根数量。

import java.util.*;

class Solution {
    public int rootCount(int[][] edges, int[][] guesses, int k) {
        int n = edges.length + 1;
        List<Integer>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : edges) {
            graph[edge[0]].add(edge[1]);
            graph[edge[1]].add(edge[0]);
        }

        Set<Long> guessed = new HashSet<>();
        for (int[] guess : guesses) guessed.add(key(guess[0], guess[1], n));

        int[] parent = new int[n];
        Arrays.fill(parent, -2);
        parent[0] = -1;
        int[] order = new int[n];
        int[] stack = new int[n];
        int size = 0, top = 0;
        stack[top++] = 0;
        while (top > 0) {
            int node = stack[--top];
            order[size++] = node;
            for (int next : graph[node]) {
                if (next == parent[node]) continue;
                parent[next] = node;
                stack[top++] = next;
            }
        }

        int[] score = new int[n];
        for (int node = 1; node < n; node++) {
            if (guessed.contains(key(parent[node], node, n))) score[0]++;
        }

        int answer = score[0] >= k ? 1 : 0;
        for (int i = 1; i < n; i++) {
            int node = order[i], p = parent[node];
            score[node] = score[p]
                    - (guessed.contains(key(p, node, n)) ? 1 : 0)
                    + (guessed.contains(key(node, p, n)) ? 1 : 0);
            if (score[node] >= k) answer++;
        }
        return answer;
    }

    private long key(int from, int to, int n) {
        return (long) from * n + to;
    }
}

var rootCount = function(edges, guesses, k) {
    const n = edges.length + 1;
    const graph = Array.from({ length: n }, () => []);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
    }

    const key = (a, b) => `${a}#${b}`;
    const guessed = new Set(guesses.map(([a, b]) => key(a, b)));
    const parent = new Int32Array(n);
    parent.fill(-2);
    parent[0] = -1;
    const order = [];
    const stack = [0];

    while (stack.length) {
        const node = stack.pop();
        order.push(node);
        for (const next of graph[node]) {
            if (next === parent[node]) continue;
            parent[next] = node;
            stack.push(next);
        }
    }

    const score = new Int32Array(n);
    for (let node = 1; node < n; node++) {
        if (guessed.has(key(parent[node], node))) score[0]++;
    }

    let answer = score[0] >= k ? 1 : 0;
    for (let i = 1; i < n; i++) {
        const node = order[i];
        const p = parent[node];
        score[node] = score[p]
            - Number(guessed.has(key(p, node)))
            + Number(guessed.has(key(node, p)));
        if (score[node] >= k) answer++;
    }
    return answer;
};
from typing import List


class Solution:
    def rootCount(
        self,
        edges: List[List[int]],
        guesses: List[List[int]],
        k: int,
    ) -> int:
        n = len(edges) + 1
        graph = [[] for _ in range(n)]
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)

        guessed = {tuple(guess) for guess in guesses}
        parent = [-2] * n
        parent[0] = -1
        order = []
        stack = [0]

        while stack:
            node = stack.pop()
            order.append(node)
            for nxt in graph[node]:
                if nxt == parent[node]:
                    continue
                parent[nxt] = node
                stack.append(nxt)

        score = [0] * n
        score[0] = sum((parent[node], node) in guessed for node in range(1, n))

        answer = int(score[0] >= k)
        for node in order[1:]:
            p = parent[node]
            score[node] = score[p] - ((p, node) in guessed) + ((node, p) in guessed)
            answer += score[node] >= k
        return answer
class Solution {
public:
    int rootCount(vector<vector<int>>& edges,
                  vector<vector<int>>& guesses,
                  int k) {
        int n = edges.size() + 1;
        vector<vector<int>> graph(n);
        for (const auto& edge : edges) {
            graph[edge[0]].push_back(edge[1]);
            graph[edge[1]].push_back(edge[0]);
        }

        auto key = [n](int from, int to) {
            return 1LL * from * n + to;
        };
        unordered_set<long long> guessed;
        for (const auto& guess : guesses) guessed.insert(key(guess[0], guess[1]));

        vector<int> parent(n, -2), order, stack = {0};
        parent[0] = -1;
        order.reserve(n);
        while (!stack.empty()) {
            int node = stack.back();
            stack.pop_back();
            order.push_back(node);
            for (int next : graph[node]) {
                if (next == parent[node]) continue;
                parent[next] = node;
                stack.push_back(next);
            }
        }

        vector<int> score(n);
        for (int node = 1; node < n; node++) {
            score[0] += guessed.count(key(parent[node], node));
        }

        int answer = score[0] >= k;
        for (int i = 1; i < n; i++) {
            int node = order[i], p = parent[node];
            score[node] = score[p]
                        - guessed.count(key(p, node))
                        + guessed.count(key(node, p));
            answer += score[node] >= k;
        }
        return answer;
    }
};

替代方案

可以把每个节点都当根并重新遍历整棵树，逻辑直观，但最坏时间为 O(n·(n+g))，在 10⁵ 规模下不可行。也可用递归 DFS 写两遍遍历，代码更短，但部分语言会遇到调用栈上限。

常见错误

  • 换根时只减去 (x,y)，忘记加上 (y,x)。
  • 把无向边集合和有向猜测集合混为一谈。
  • 为每个根重新检查所有猜测，导致超时。
  • 在 JavaScript 中用对象数组作为 Set 键，无法按值匹配。

面试追问

为什么只有一条边的方向会变化？

相邻换根等价于让 y 成为 x 的父节点；删除边 x—y 后的两个连通分量内部，其父子方向都保持不变。

若猜测允许重复，如何修改？

将哈希集合改成“有向边 → 出现次数”的哈希表，换根时加减对应次数即可。

若需要输出所有可行根而非数量呢？

传播每个节点的分数时，把满足 score[node] ≥ k 的节点加入结果数组。

能否在线处理新增猜测？

单次新增会影响一整侧子树的根分数；可结合欧拉序与树上区间更新结构。只有在确实存在在线查询需求时才值得引入。
