开幕式焰火 颜色集合焰火台

每个树节点是一团焰火，节点值就是颜色编号。沿树进行 DFS 或 BFS，把看见过的颜色放入集合，集合大小便是答案。

题意

给定二叉树 root，节点值是颜色种类。返回树中不同颜色的数量。节点数最多 1000，颜色范围 1 到 1000。

输入

root = [1,3,2,1,null,2]

期望输出

3

不同颜色

{1, 2, 3}

参数完整展示为 root = [...]。字符串若出现空格会显示为 ␠；本题输入是整数树。

为什么集合足够

  1. 遍历保证每个节点恰好被访问。
  2. 集合自动忽略重复颜色。
  3. 遍历结束后 set.size 正好是颜色种数。

核心洞察与完整过程

递归函数接收一个节点：空节点直接返回；非空节点先把 node.val 放进集合，再递归左、右孩子。无需关心颜色重复，因为 HashSet / Set 的插入是幂等的。

  1. 创建空集合。
  2. DFS(root)，对每个非空节点插入颜色。
  3. 返回集合大小。

边界与复杂度

单节点答案为 1；所有节点同色答案仍为 1。若允许空树，答案为 0。访问 n 个节点：时间 O(n)，集合最多 n 种颜色，空间 O(n)（递归栈额外 O(h)）。

替代方案、追问、错误

也可用 BFS 队列避免深树递归。颜色范围已知且很小时能用布尔数组。常见错误：忘记 null 判断、只遍历一侧子树、把节点数量误当颜色数量。

四语言可提交代码

// Java
class Solution {
  public int numColor(TreeNode root) {
    Set<Integer> colors = new HashSet<>();
    dfs(root, colors);
    return colors.size();
  }
  private void dfs(TreeNode node, Set<Integer> colors) {
    if (node == null) return;
    colors.add(node.val); dfs(node.left, colors); dfs(node.right, colors);
  }
}

var numColor = function(root) {

class Solution:
    def numColor(self, root: TreeNode) -> int:
        colors = set()
        def dfs(node):
            if not node: return
            colors.add(node.val)
            dfs(node.left); dfs(node.right)
        dfs(root)
        return len(colors)

class Solution {
 public:
  int numColor(TreeNode* root) {
    unordered_set<int> colors;
    function<void(TreeNode*)> dfs = [&](TreeNode* node) {
      if (!node) return;
      colors.insert(node->val);
      dfs(node->left); dfs(node->right);
    };
    dfs(root); return colors.size();
  }
};
