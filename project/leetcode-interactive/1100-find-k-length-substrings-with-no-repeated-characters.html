题目

给定只含小写英文字母的字符串 s 和整数 k，统计 s 中长度恰好为 k、且所有字符互不相同的连续子串数量。

相同文本若出现在不同起点，按不同位置分别计数。

函数签名
numKLenSubstrNoRepeats(s, k) → integer

约束

  • 1 ≤ s.length ≤ 10⁴
  • 1 ≤ k ≤ 10⁴
  • s 只含小写英文字母

k > s.length 或 k > 26 时答案为 0。

完整题解

核心洞察

相邻的定长窗口只相差左端移出的字符与右端加入的字符。维护字符频次和不同字符数，就不用为每个窗口重新扫描。

完整过程

  1. 若 k > s.length 或 k > 26，返回 0。
  2. 右指针逐字符前进，将新字符加入频次表。
  3. 窗口超过 k 时，删除位置 right-k 的字符。
  4. 窗口长度达到 k 且不同字符数为 k，答案加一。

正确性

不变式：处理下标 right 后，频次表恰好描述以它结尾、长度至多为 k 的窗口。加入右端并删除唯一过期的左端字符保持该不变式。长度为 k 的窗口无重复，当且仅当不同字符数为 k。算法逐一检查所有定长窗口，故结果正确。

边界

  • k=1 时每个字符都形成合法窗口。
  • k>s.length 时无完整窗口。
  • k>26 时小写字母不够用。
  • 字符频次归零时才减少不同字符数。

复杂度

时间 O(n)，26 位频次数组为 O(1) 额外空间。

替代方案

每个窗口重新建立集合是 O(nk)，直观但有重复工作。通用哈希表也可替代数组，以支持更大字符集。

面试追问

  • 扩展到 Unicode 时怎样维护频次？
  • 若返回所有合法起点，代码如何修改？
  • 条件改为“至多 k 个不同字符”时，窗口何时收缩？

常见错误

  • 在移除过期字符前检查窗口。
  • 频次归零却未减少 distinct。
  • 循环边界漏掉最后一个窗口。
  • 误把重复文本当成只能计数一次。

四语言完整代码

class Solution {
    public int numKLenSubstrNoRepeats(String s, int k) {
        if (k > s.length() || k > 26) return 0;
        int[] freq = new int[26];
        int distinct = 0, answer = 0;
        for (int right = 0; right < s.length(); right++) {
            int add = s.charAt(right) - 'a';
            if (freq[add]++ == 0) distinct++;
            if (right >= k) {
                int remove = s.charAt(right - k) - 'a';
                if (--freq[remove] == 0) distinct--;
            }
            if (right >= k - 1 && distinct == k) answer++;
        }
        return answer;
    }
}

                distinct += 1
            freq[add] += 1

                freq[remove] -= 1
                if freq[remove] == 0:
                    distinct -= 1

                answer += 1
        return answer
