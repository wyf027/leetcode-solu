Sort Array by Moving Items to Empty Space

一个空位，任意搬运。先思考：空位放在左端与右端，会影响最少移动次数吗？

题解与算法演示默认折叠 · 可离线打开

01 / 题意

输入数组 nums 是 0 … n − 1 的一个排列。正整数表示物品，0 表示唯一空位。每次可以把任意一个物品搬进空位，原位置随即成为新空位；等价于把该物品与 0 交换，距离不限。

要求非零物品从左到右递增，且空位在最左或最右。因此合法终态只有 [0,1,…,n−1] 和 [1,2,…,n−1,0]。返回达到任意合法终态的最少操作数。

函数契约

sortArray(nums: integer[]) → integer

只有 nums 一个参数；返回操作次数，不要求返回操作序列。

约束

  • n == nums.length
  • 2 ≤ n ≤ 10⁵
  • 0 ≤ nums[i] < n
  • 所有元素互不相同。

04 / 题解 · 让空位走完每一个环

核心洞察：元素的目标下标构成排列

固定一种终态后，定义 p[i] = target(nums[i])，表示下标 i 上的元素应该前往哪个下标。因为数字互不重复，p 可以分解成若干不相交的环。

  • 空位在左：target(v) = v。
  • 空位在右：target(v) = (v + n − 1) % n。其中 0 的目标下标为 n − 1。
  • 长度 1 的环：元素已经归位，代价 0。
  • 长度 m ≥ 2 且含空位的环：代价 m − 1。
  • 长度 m ≥ 2 且不含空位的环：代价 m + 1。

两种终态分别累加各环代价，最后取较小值。这里“含空位”指环上的某个下标当前存放原始值 0，不能在右端方案中把映射值 0 当作空位。

完整过程

  1. 分别设置左端、右端目标映射；每次重新分配 visited。
  2. 遍历尚未访问的下标 i，沿 i → p[i] → p[p[i]] 前进，直到遇到已访问下标。
  3. 记录环长及是否出现 nums[j] == 0。按 0、m−1、m+1 三种情况累加。
  4. 返回两种累计值的最小值；全程不修改 nums。

以示例 1 的左端目标为例：环 0 → 4 → 1 → 2 → 0 包含空位所在的下标 2，长度 4，需 3 次；下标 3 是长度 1 的环。实际搬运按“把空位目标物品搬来”的方向进行，因此搬动物品依次为 2、1、4。

正确性证明

含空位环：长度为 m 的环有 m−1 个错位物品，每个至少搬一次，所以下界是 m−1。持续把当前空位应放的物品搬来，每次归位一个物品，恰好 m−1 次完成这个环。

不含空位环：m 个物品都必须至少搬一次。空位首次进入该环时，必有一个物品被搬到环外，它的目标却在环内，之后还必须再搬一次，因此至少 m+1 次。先借空位移出一个物品，再依次填空，最后把借出的物品放回，恰好达到此下界。

可加性：每个错位物品的一次必需移动和每个非空位环的额外移动可以按物品所属的原始环分别计数，因此下界相加有效。构造时先处理空位所在环，再逐环借用已归位的空位；每次都把空位送回其目标，互不破坏已处理环。故各环代价之和是该目标的最优值。全部合法终态只有两种，取二者较小值即为全局最优。

边界与复杂度

  • 已处于任一合法终态时，该分支所有环长度为 1，结果为 0。
  • 空位归位不代表全数组归位；其他环依旧需要处理。
  • n = 2 的两个排列都合法，答案均为 0。
  • 多个独立环分别计数；不能按所有错位下标数统一加减常数。
  • 时间 O(n)：两个分支各访问每个下标一次。额外空间 O(n)：visited；没有递归栈。交互演示为保存历史会额外存储各帧数组，不属于提交算法的空间开销。

替代方案

维护 pos[value]，模拟把目标物品搬入空位；空位归位时借入一个错位物品。用单调扫描指针寻找新环可以达到 O(n) 时间、O(n) 空间，并直接输出移动序列。若每步从头搜索错位元素则可能退化到 O(n²)。BFS 能直接求最少次数，但状态数为 n!，只适合极小排列的后续对拍。

常见错误

  • 只计算 [0,1,…]，漏掉右端空位答案；示例 2 会出错。
  • 把操作当成任意两数交换，给所有环都计算 m−1。
  • 把单点环计算成 m+1，导致已排好也被加上操作数。
  • 右端映射直接用 v−1，导致 0 映射到 −1。
  • 两次目标计算复用未清空的 visited，漏数第二种情况。

面试追问

如果要求返回操作？ 用 pos 模拟法记录“物品、源下标、目标空位”。
如果空位必须在左端？ 只保留左端计算。
如果允许相邻移动或存在重复元素？ 当前“任意搬运”和排列映射前提失效，需要按新限制重新建模，不能直接使用环公式。

Java

class Solution {
    public int sortArray(int[] nums) {
        return Math.min(cost(nums, false), cost(nums, true));
    }

    private int cost(int[] nums, boolean right) {
        int n = nums.length, total = 0;
        boolean[] seen = new boolean[n];
        for (int i = 0; i < n; i++) {
            if (seen[i]) continue;
            int j = i, length = 0;
            boolean hasZero = false;
            while (!seen[j]) {
                seen[j] = true;
                length++;
                if (nums[j] == 0) hasZero = true;
                j = right ? (nums[j] + n - 1) % n : nums[j];
            }
            if (length > 1) total += hasZero ? length - 1 : length + 1;
        }
        return total;
    }
}

var sortArray = function(nums) {
    const n = nums.length;
    function cost(right) {
        const seen = new Uint8Array(n);
        let total = 0;
        for (let i = 0; i < n; i++) {
            if (seen[i]) continue;
            let j = i, length = 0, hasZero = false;
            while (!seen[j]) {
                seen[j] = 1;
                length++;
                if (nums[j] === 0) hasZero = true;
                j = right ? (nums[j] + n - 1) % n : nums[j];
            }
            if (length > 1) total += hasZero ? length - 1 : length + 1;
        }
        return total;
    }
    return Math.min(cost(false), cost(true));
};

Python

from typing import List

class Solution:
    def sortArray(self, nums: List[int]) -> int:
        n = len(nums)

        def cost(right: bool) -> int:
            seen = [False] * n
            total = 0
            for i in range(n):
                if seen[i]:
                    continue
                j, length, has_zero = i, 0, False
                while not seen[j]:
                    seen[j] = True
                    length += 1
                    if nums[j] == 0:
                        has_zero = True
                    j = (nums[j] + n - 1) % n if right else nums[j]
                if length > 1:
                    total += length - 1 if has_zero else length + 1
            return total

        return min(cost(False), cost(True))
