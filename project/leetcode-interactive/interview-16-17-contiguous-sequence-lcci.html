连续数列Contiguous Sequence

给每个元素一次选择：接在上一段后面，还是从自己重新起步。扫描完整条信号后，返回能量最高的连续区间之和。

峰值来自连续区间 [4, -1, 2, 1]。先观察信号，再决定是否展开题解。

Problem brief

题意与样例

连续意味着不能跳过中间元素；目标只要求返回最大总和，不要求返回区间下标。

任务

给定一个整数数组 nums，从中选择一段非空、下标连续的元素，使这段元素的总和最大，并返回该最大和。

输入 nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
期望输出 6
解释 连续子数组 [4, -1, 2, 1] 的和为 6

边界口径

  • 连续子数组必须至少包含一个元素。
  • 全为负数时，应返回其中最大的负数，而不是 0。
  • 官方页面未列出额外规模区间，函数签名返回整数。
  • 进阶要求：在线性解法之外，尝试分治法。

核心洞察

走到 nums[i] 时，以它结尾的最优连续段只有两种来源：从它自己重新开始，或把它接到上一位置的最优结尾段之后。只需比较这两个值。

ending = max(nums[i], ending + nums[i])

为什么推荐 Kadane

它是本题面试主线：一次扫描、常数额外空间，状态含义清晰。ending 负责“必须以 i 结尾”，best 负责记录所有结尾位置中的最大值。

best = max(best, ending)

完整过程

  1. 用 nums[0] 初始化 ending 与 best，保证全负数也正确。
  2. 从下标 1 开始，比较“单独起步”与“延续旧段”两种总和。
  3. 把较大值写回 ending；它始终代表以当前位置结尾的最大和。
  4. 用 ending 更新全局最大值 best。
  5. 扫描结束后返回 best。

边界与不变量

  • 全负数：不能把初值写成 0，否则会错误地选择空数组。
  • 单元素：初始化后无需进入循环，直接返回该元素。
  • 出现 0：它既可以保留旧段，也可以成为新段，最大和不受错误清零影响。
  • 不变量：处理完 i 后，ending 必须包含 nums[i]。

复杂度

  • 时间复杂度：O(n)，每个元素只处理一次。
  • 空间复杂度：O(1)，只保存两个滚动变量。
  • 若需要返回区间，再增加当前起点与最优起止下标，仍是 O(1) 空间。

替代方案取舍

分治法把区间答案拆成左侧、右侧与跨中点三类，复杂度 O(n log n)，适合回答官方进阶或讲解线段树合并信息；前缀和配合最小前缀也能做到 O(n)，但状态不如 Kadane 直接。

面试追问

  • 如何同时返回最优连续段的左右下标？
  • 如果数组形成环，最大连续和如何求？
  • 怎样设计支持区间更新与查询的节点合并信息？
  • 分治法为什么必须单独计算跨中点答案？

常见错误

  • 把 best 初始化为 0，导致全负数组返回 0。
  • 只在当前和小于 0 时清零，却忘记先更新历史最大值。
  • 把“连续子数组”误写成可跳过元素的子序列。
  • 返回最后的 ending，而不是扫描期间的 best。
