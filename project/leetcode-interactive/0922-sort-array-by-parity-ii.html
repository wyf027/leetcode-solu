01题目

给定非负整数数组 nums，其中恰好一半是偶数、一半是奇数。重新排列数组，使每个偶数下标放偶数、每个奇数下标放奇数；返回任意一个满足条件的数组。

函数形式：sortArrayByParityII(nums: integer[]) → integer[]
答案不唯一，元素只需重新排列，不要求数值有序。

官方示例

输入： nums = [4,2,5,7]
输出： [4,5,2,7]
解释： [4,7,2,5]、[2,5,4,7]、[2,7,4,5] 也满足要求。
输入： nums = [2,3]
输出： [2,3]

约束

  • 2 ≤ nums.length ≤ 2 × 10⁴
  • nums.length 是偶数
  • 数组中恰有一半元素为偶数
  • 0 ≤ nums[i] ≤ 1000

进阶：能否只使用常数额外空间，直接在原数组内完成？

完整题解

默认收起，避免首屏直接泄露答案。

核心洞察

只检查偶数下标。如果某个偶数下标装着奇数，它必然要与某个奇数下标上的偶数交换。题目保证两类数量相等，所以错位一定能成对消除。

完整过程

  1. even = 0 只走偶数下标，odd = 1 只走奇数下标。
  2. 跳过已经放对的元素。
  3. 找到一对错位元素后交换。
  4. 两个指针各自加 2，直到越界。

正确性

循环中，指针之前同奇偶性的下标均已合法。若当前两处错位，偶下标上的奇数与奇下标上的偶数交换后，两处同时合法，保持不变式。由于错位数量配对且指针持续前进，算法终止时所有下标均合法；交换不增删元素，因此结果是原数组的排列。

复杂度与边界

每个指针最多扫描半个数组，时间复杂度 O(n)；原地交换只使用两个指针，额外空间 O(1)。长度为 2、零（偶数）、重复值、数组原本合法时都无需特殊分支。

替代方案

新建长度为 n 的答案数组，用两个写指针分别放偶数和奇数，实现更直观，时间仍为 O(n)，但额外空间为 O(n)。也可顺序扫描并分别写入，但原地双指针更贴合进阶要求。

常见错误

  • 把“按奇偶排序”误解为偶数值需要升序。
  • 指针每次加 1，破坏它们各自负责的下标类别。
  • 仅找到一个错位点便交换相邻元素。
  • 用 x % 2 === 1 处理可含负数的泛化版本；本题元素非负，不受影响。

面试追问

  • 若奇偶数量不相等，接口应该报错还是尽量排列？
  • 如何证明交换次数不超过 n / 2？
  • 若输入不可修改，怎样用 O(n) 空间稳定保留相对顺序？

一句话记忆

两个指针只走自己负责的下标，遇到互补错位就交换。

class Solution {
    public int[] sortArrayByParityII(int[] nums) {
        int even = 0;
        int odd = 1;

        while (even < nums.length && odd < nums.length) {
            while (even < nums.length && nums[even] % 2 == 0) {
                even += 2;
            }
            while (odd < nums.length && nums[odd] % 2 == 1) {
                odd += 2;
            }
            if (even < nums.length && odd < nums.length) {
                int temp = nums[even];
                nums[even] = nums[odd];
                nums[odd] = temp;
                even += 2;
                odd += 2;
            }
        }
        return nums;
    }
}

var sortArrayByParityII = function(nums) {
    let even = 0;
    let odd = 1;

    while (even < nums.length && odd < nums.length) {
        while (even < nums.length && nums[even] % 2 === 0) {
            even += 2;
        }
        while (odd < nums.length && nums[odd] % 2 === 1) {
            odd += 2;
        }
        if (even < nums.length && odd < nums.length) {
            [nums[even], nums[odd]] = [nums[odd], nums[even]];
            even += 2;
            odd += 2;
        }
    }
    return nums;
};
