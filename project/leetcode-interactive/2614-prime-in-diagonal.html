Prime In Diagonal

两条对角线像两束交叉的扫描光。你的任务不是检查整张矩阵，而是从被光束照亮的数字里找到最大的质数。

Problem brief

题目说明

给定一个下标从 0 开始的 n × n 整数矩阵 nums。返回至少位于一条对角线上的最大质数；若两条对角线上都没有质数，返回 0。

对第 i 行，主对角线位置是 nums[i][i]，副对角线位置是 nums[i][n - 1 - i]。大于 1 且正因子只有 1 和自身的整数称为质数。

示例

示例 1

输入：nums = [[1,2,3],
              [5,6,7],
              [9,10,11]]
输出：11
解释：对角线元素为 1、3、6、9、11，
      其中最大质数是 11。

示例 2

输入：nums = [[1,2,3],
              [5,17,7],
              [9,11,10]]
输出：17
解释：对角线元素为 1、3、17、9、10，
      其中最大质数是 17。

约束

  • 1 ≤ nums.length ≤ 300
  • nums.length == nums[i].length
  • 1 ≤ nums[i][j] ≤ 4 × 10⁶

Full walkthrough

题解：只检查必要位置

O(n√M)

核心洞察

答案只可能出现在两条对角线上。矩阵每行至多贡献两个候选值，因此无需遍历其余 n² - O(n) 个位置。对每个候选做试除法：只需尝试到它的平方根，因为若 x = a × b，至少一个因子不大于 √x。

完整过程

按行提取候选

对每个 i，读取 nums[i][i] 与 nums[i][n-1-i]。

判断是否为质数

小于 2 直接排除；从 2 起检查因子，直到 d × d > x。发现整除因子即可提前返回。

维护最大值

候选为质数时，用它更新答案。中心格重复检查不会影响正确性，也无需为去重增加额外结构。

返回结果

初始答案为 0；若没有候选通过质数判断，它会自然保留为 0。

正确性证明

引理 1：算法会检查所有且仅有可能影响答案的矩阵位置。对任意行 i，两条对角线的列下标分别是 i 和 n-1-i；算法恰好读取这两个位置，因此没有遗漏对角线元素。

引理 2：质数判断返回真，当且仅当候选值为质数。若值有非平凡因子，则必有一个因子不大于其平方根，循环会找到它；若循环未找到因子，则不存在非平凡因子。

定理：算法返回对角线上的最大质数。根据引理 1，每个合法候选都会被检查；根据引理 2，只有质数用于更新答案。持续取最大值后，答案就是全部对角线质数中的最大者；集合为空时初值 0 被返回。

边界与复杂度

边界

  • n = 1 时同一个元素属于两条对角线。
  • 1 不是质数，必须排除。
  • 没有质数时返回 0。
  • 偶数 2 是质数，不能统一排除所有偶数。

复杂度

设矩阵边长为 n，元素最大值为 M。共检查 2n 个候选，每次最坏试除到 √M。

时间：O(n√M)
额外空间：O(1)

class Solution {
    public int diagonalPrime(int[][] nums) {
        int answer = 0;
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            int a = nums[i][i];
            int b = nums[i][n - 1 - i];
            if (isPrime(a)) answer = Math.max(answer, a);
            if (isPrime(b)) answer = Math.max(answer, b);
        }
        return answer;
    }

    private boolean isPrime(int x) {
        if (x < 2) return false;
        for (int d = 2; d * d <= x; d++) {
            if (x % d == 0) return false;
        }
        return true;
    }
}

class Solution:
    def diagonalPrime(self, nums: List[List[int]]) -> int:
        def is_prime(x: int) -> bool:
            if x < 2:
                return False
            d = 2
            while d * d <= x:
                if x % d == 0:
                    return False
                d += 1
            return True

        answer = 0
        n = len(nums)
        for i in range(n):
            for value in (nums[i][i], nums[i][n - 1 - i]):
                if is_prime(value):
                    answer = max(answer, value)
        return answer

替代方案与面试追问

先筛质数

可用埃氏筛预处理到矩阵最大值，再以 O(1) 判断每个候选。单题只有至多 600 次查询，筛到 4 × 10⁶ 通常增加了不必要的时间和空间；大量矩阵共享查询时才更合适。

降序检查候选

收集并排序对角线值，从大到小找到首个质数。逻辑直观，但需要 O(n) 空间和 O(n log n) 排序，直接维护最大值更简单。

可能的追问

  • 若矩阵不是方阵，如何定义并遍历两条最长对角线？
  • 若要回答许多次不同矩阵查询，何时值得预计算质数表？
  • 若元素上界扩展到 64 位整数，质数判断应如何升级？

常见错误

01

把 1 当作质数

质数判断必须先处理 x < 2。

02

副对角线下标偏一

正确列下标是 n - 1 - i，不是 n - i。

03

试除范围错误

必须包含平方根本身；使用 d × d ≤ x。
