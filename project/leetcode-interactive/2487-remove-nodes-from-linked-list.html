2487. 从链表中移除节点

Remove Nodes From Linked List

一条链表，一条删除规则。先判断哪些节点能留下，再展开推演。

01 / 题目

给定单链表头节点 head。如果某节点右侧任意位置存在一个值严格大于它的节点，就移除该节点。返回剩余节点按原顺序连接后链表的头节点。

右侧不限于相邻节点；相等的值不会触发移除。下方数组表示链表从头到尾的节点值。

官方示例 1

输入：head = [5,2,13,3,8]
输出：[13,8]

5 和 2 的右侧存在 13；3 的右侧存在 8，因此移除这三个节点。

官方示例 2

输入：head = [1,1,1,1]
输出：[1,1,1,1]

所有节点值相等，没有任何节点满足删除条件。

约束与接口

  • 节点数量：1 ≤ n ≤ 10⁵。
  • 节点值：1 ≤ Node.val ≤ 10⁵。
  • 参数：head: ListNode；返回：ListNode。

03 / 题解 · 用右侧新节点淘汰候选

核心洞察

从左到右扫描，栈保存还未被淘汰的节点。新值 x 到来时，栈尾所有小于 x 的节点都有了一个更大的右侧见证，必须弹出。然后压入当前节点。栈中数值始终从底到顶非递增。

相等时必须保留，所以比较符号是 <。扫描过程中先不改链表指针，结束后按栈中顺序重连节点。

交互 / 淘汰见证台

观察新节点如何淘汰栈尾。每次弹栈和入栈各占一步，最后才重连。节点下标从 0 开始。

输入逗号分隔的正整数，可带方括号；演示限制 24 个节点，提交算法支持题目全部范围。

原链表 · 扫描轨迹

琥珀：当前节点 · 青色：候选 · 玫红虚线：已淘汰（均附文字状态）

候选栈 · 左侧栈底 / 右侧栈顶

完整过程

  1. 创建空栈，按原链表的 next 依次访问节点。
  2. 若栈非空且栈顶值小于当前值，弹出栈顶；重复直到栈空或栈顶值大于等于当前值。
  3. 将当前节点引用压栈，继续扫描。
  4. 扫描结束，依次把相邻栈元素的 next 相连，最后一个节点指向空，返回栈底。
读取 5  → [5]
读取 2  → [5,2]
读取 13 → 弹出 2、5 → [13]
读取 3  → [13,3]
读取 8  → 弹出 3 → [13,8]
重连    → 13 → 8 → null

为什么正确

不变量：处理完任意前缀，栈恰好保存该前缀内右侧没有更大值的节点，保持原相对顺序，且值非递增。

  1. 初始：空前缀和空栈满足不变量。
  2. 推进：加入 x 后，旧候选中值小于 x 的都应删除。栈非递增，因此它们恰好构成栈的连续尾部，会被 while 全部弹出；其余候选值 ≥ x，不受 x 影响。以前已删除的节点已有更大见证，不会重新有效。x 在当前前缀没有右侧节点，应入栈。
  3. 结束：前缀成为整个链表，不变量说明栈内正是所有应保留节点。按原顺序重连，返回的链表满足要求。

被弹出的节点，即使它的见证之后也被淘汰，仍然应删除：题意针对原链表右侧存在性；更大的后续见证也能通过大小关系传递。

复杂度与边界

  • 时间 O(n)：每个节点入栈一次，至多出栈一次，重连至多 n−1 次。
  • 额外空间 O(n)：非递增链表会保留全部节点引用。
  • 单节点、全相等、非递增：全部保留。
  • 严格递增：只留下尾节点。
  • 尾节点一定保留；重复最大值全部保留。
  • 题目不允许空链表，代码仍防御性返回空。

替代方案

  • 反转链表：反转后维护已见最大值，删除比最大值小的节点，再反转回来。O(n) 时间、O(1) 额外空间，但需仔细处理指针。
  • 递归：先处理后缀，若当前值小于处理后后缀头值则丢弃当前节点。O(n) 时间和调用栈空间；10⁵ 节点存在栈溢出风险。
  • 逐节点向右找：直接实现定义，最坏 O(n²)，不适合上限。

常见错误

  • 只和右邻居比较，漏掉更远的较大节点。
  • 用 <= 弹栈，把相等节点误删。
  • 只弹一次，未清理整个较小的栈尾。
  • 把出栈顺序当答案，颠倒原链表顺序。
  • 扫描时贸然修改 next，丢失未访问的节点。
  • 返回栈数组而非链表头；重连时漏掉尾指针收尾。

面试追问

如何做到 O(1) 额外空间？反转、过滤、再反转。

若条件改为“大于等于”？栈顶比较改成 ≤，相等的左侧节点也会被移除。

为什么双重循环仍是线性？统计每个节点的入栈和出栈次数，而不是把两个循环上界直接相乘。

Java

// ListNode 由 LeetCode 提供：int val; ListNode next;
import java.util.ArrayList;

class Solution {
    public ListNode removeNodes(ListNode head) {
        ArrayList<ListNode> stack = new ArrayList<>();
        for (ListNode cur = head; cur != null; cur = cur.next) {
            while (!stack.isEmpty() &&
                   stack.get(stack.size() - 1).val < cur.val) {
                stack.remove(stack.size() - 1);
            }
            stack.add(cur);
        }
        for (int i = 1; i < stack.size(); i++) {
            stack.get(i - 1).next = stack.get(i);
        }
        if (stack.isEmpty()) return null;
        stack.get(stack.size() - 1).next = null;
        return stack.get(0);
    }
}

/**
 * @param {ListNode} head
 * @return {ListNode}
 */
var removeNodes = function(head) {
    const stack = [];
    for (let cur = head; cur !== null; cur = cur.next) {
        while (stack.length && stack[stack.length - 1].val < cur.val) {
            stack.pop();
        }
        stack.push(cur);
    }
    for (let i = 1; i < stack.length; i++) {
        stack[i - 1].next = stack[i];
    }
    if (!stack.length) return null;
    stack[stack.length - 1].next = null;
    return stack[0];
};

from typing import Optional

class Solution:
    def removeNodes(self, head: Optional[ListNode]) -> Optional[ListNode]:
        stack = []
        cur = head
        while cur is not None:
            while stack and stack[-1].val < cur.val:
                stack.pop()
            stack.append(cur)
            cur = cur.next
        for i in range(1, len(stack)):
            stack[i - 1].next = stack[i]
        if not stack:
            return None
        stack[-1].next = None
        return stack[0]

C++

// ListNode 由 LeetCode 提供：int val; ListNode* next;
#include <vector>
using namespace std;

class Solution {
public:
    ListNode* removeNodes(ListNode* head) {
        vector<ListNode*> stack;
        for (ListNode* cur = head; cur != nullptr; cur = cur->next) {
            while (!stack.empty() && stack.back()->val < cur->val) {
                stack.pop_back();
            }
            stack.push_back(cur);
        }
        for (size_t i = 1; i < stack.size(); ++i) {
            stack[i - 1]->next = stack[i];
        }
        if (stack.empty()) return nullptr;
        stack.back()->next = nullptr;
        return stack.front();
    }
};
