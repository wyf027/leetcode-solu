LeetCode 2559 MEDIUM 数组 字符串 前缀和

统计范围内的元音字符串数Count Vowel Strings in Ranges

给定字符串数组与若干闭区间查询，统计每个查询范围内首尾字符都是元音的字符串数量。

Problem

题目描述

数组下标从 0 开始；每个查询的左右端点都包含在统计范围内。

给你字符串数组 words 和二维整数数组 queries。对于每个查询 queries[i] = [lᵢ, rᵢ]，统计 words[lᵢ..rᵢ] 中同时以元音开头、以元音结尾的字符串个数。

请返回长度为 queries.length 的整数数组 ans，其中 ans[i] 是第 i 个查询的结果。

元音集合：'a'、'e'、'i'、'o'、'u'。长度为 1 的元音字符串，其首尾字符是同一个字符，也满足条件。

Examples

官方示例

示例 1

混合命中
输入：words = ["aba","bcb","ece","aa","e"],
      queries = [[0,2],[1,4],[1,1]]
输出：[2,3,0]

满足条件的是 "aba"、"ece"、"aa"、"e"。三个查询分别命中 2、3、0 个。

示例 2

全部命中
输入：words = ["a","e","i"],
      queries = [[0,2],[0,1],[2,2]]
输出：[3,2,1]

三个字符串都以元音开头和结尾，因此每个查询的答案就是对应区间的长度。

Limits

约束

  • 1 ≤ words.length ≤ 10⁵
  • 1 ≤ words[i].length ≤ 40
  • words[i] 仅由小写英文字母组成
  • Σ words[i].length ≤ 3 × 10⁵
  • 1 ≤ queries.length ≤ 10⁵
  • 0 ≤ queries[i][0] ≤ queries[i][1] < words.length

Editorial

前缀和：把区间统计变成两次查表

核心洞察

先把每个单词压缩成一个二进制值：首尾都是元音记为 1，否则记为 0。随后构造前缀数组 prefix，令 prefix[i] 表示前 i 个单词中合格单词的数量。

answer(l, r) = prefix[r + 1] − prefix[l]

右侧前缀包含下标 r，左侧前缀恰好排除下标 l 之前的所有元素。

完整过程

  1. 准备元音判定。 用字符串 "aeiou" 或集合保存五个元音。
  2. 扫描每个单词。 同时检查第一个字符和最后一个字符是否都属于元音集合。
  3. 建立前缀计数。 创建长度为 n + 1 的数组，保持 prefix[0] = 0；第 i 个单词的判定值累加到 prefix[i + 1]。
  4. 回答查询。 对每个闭区间 [l, r]，计算 prefix[r + 1] - prefix[l]。
  5. 按原顺序返回。 每个查询只做两次数组读取和一次减法。

正确性证明

1. 单点编码正确

判定值 good[i] 仅在 words[i] 的首字符和尾字符都为元音时等于 1，因此它准确表示该单词是否应被统计。

2. 前缀含义成立

由递推式 prefix[i + 1] = prefix[i] + good[i]，归纳可知 prefix[k] 恰好是下标 [0, k - 1] 中合格单词的数量。

3. 区间差值正确

prefix[r + 1] 统计了 [0, r]，减去统计 [0, l - 1] 的 prefix[l]，剩余部分正好是 [l, r]。

边界情况

  • 单字符单词："a" 的首尾都是 a，应计入；"b" 不计入。
  • 单点查询：[i, i] 仍使用同一公式，无需特判。
  • 全不满足：前缀数组保持为 0，所有查询结果自然为 0。
  • 覆盖整个数组：[0, n-1] 的答案为 prefix[n] - prefix[0]。

复杂度

时间复杂度O(n + q)
额外空间O(n)

其中 n = words.length，q = queries.length。每个单词只查看首尾字符，因此无需遍历单词的全部内容。

Implementations

四种语言完整代码

均遵循官方函数签名。

Java Java

class Solution {
    public int[] vowelStrings(String[] words, int[][] queries) {
        int[] prefix = new int[words.length + 1];

        for (int i = 0; i < words.length; i++) {
            String word = words[i];
            boolean good = isVowel(word.charAt(0))
                    && isVowel(word.charAt(word.length() - 1));
            prefix[i + 1] = prefix[i] + (good ? 1 : 0);
        }

        int[] answer = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int left = queries[i][0];
            int right = queries[i][1];
            answer[i] = prefix[right + 1] - prefix[left];
        }
        return answer;
    }

    private boolean isVowel(char c) {
        return c == 'a' || c == 'e' || c == 'i'
                || c == 'o' || c == 'u';
    }
}

JavaScript JavaScript

/**
 * @param {string[]} words
 * @param {number[][]} queries
 * @return {number[]}
 */
var vowelStrings = function(words, queries) {
    const vowels = new Set(['a', 'e', 'i', 'o', 'u']);
    const prefix = new Array(words.length + 1).fill(0);

    for (let i = 0; i < words.length; i++) {
        const word = words[i];
        const good = vowels.has(word[0])
            && vowels.has(word[word.length - 1]);
        prefix[i + 1] = prefix[i] + (good ? 1 : 0);
    }

    return queries.map(([left, right]) =>
        prefix[right + 1] - prefix[left]
    );
};

Python Python 3

from typing import List


class Solution:
    def vowelStrings(
        self,
        words: List[str],
        queries: List[List[int]]
    ) -> List[int]:
        vowels = set("aeiou")
        prefix = [0] * (len(words) + 1)

        for i, word in enumerate(words):
            good = word[0] in vowels and word[-1] in vowels
            prefix[i + 1] = prefix[i] + int(good)

        return [
            prefix[right + 1] - prefix[left]
            for left, right in queries
        ]

C++ C++

class Solution {
public:
    vector<int> vowelStrings(
        vector<string>& words,
        vector<vector<int>>& queries
    ) {
        const string vowels = "aeiou";
        vector<int> prefix(words.size() + 1);

        for (int i = 0; i < words.size(); ++i) {
            const string& word = words[i];
            bool good = vowels.find(word.front()) != string::npos
                     && vowels.find(word.back()) != string::npos;
            prefix[i + 1] = prefix[i] + good;
        }

        vector<int> answer;
        answer.reserve(queries.size());
        for (const auto& query : queries) {
            int left = query[0];
            int right = query[1];
            answer.push_back(prefix[right + 1] - prefix[left]);
        }
        return answer;
    }
};

替代方案

逐查询扫描

对每个 [l, r] 逐项检查，写法直观，但最坏会检查 10⁵ × 10⁵ 个位置，无法满足约束。

Fenwick 树 / 线段树

若题目允许在线修改单词，它们可以支持更新与范围求和；本题数组静态，前缀和更短、更快，也更容易证明。

常见错误

  • 只判断开头或只判断结尾，漏掉“双端都为元音”的条件。
  • 把答案写成 prefix[r] - prefix[l]，导致右端点未被包含。
  • 错误排除长度为 1 的元音字符串。
  • 为每个查询重新扫描区间，导致最坏时间复杂度退化到 O(nq)。
  • 令前缀数组长度为 n，从而被迫对 l = 0 做额外特判并增加越界风险。

面试追问

展开问题，检验是否真正掌握。

为什么前缀数组使用 n + 1 个元素？

把 prefix[0] 定义为空前缀后，任何查询都能统一写为 prefix[r + 1] - prefix[l]，包括 l = 0，不需要分支。

如果 words 会发生单点更新，如何改造？

将每个单词的 0/1 判定值维护在 Fenwick 树或线段树中。单点更新与区间查询都可在 O(log n) 时间完成。

为什么时间复杂度不是所有字符串总长度之和？

本题只访问每个非空字符串的首尾两个字符，不扫描中间字符，因此预处理关于单词数量是 O(n)。如果语言的字符访问语义不同，应相应说明成本。

能否把额外空间降到 O(1)？

若仍要求快速回答任意离线查询，一般需要保存累计信息。可以原地复用其他可修改数组，但那只是转移存储；清晰实现保留 O(n) 前缀数组最合适。
