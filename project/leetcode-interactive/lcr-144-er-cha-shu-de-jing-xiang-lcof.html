题意

Easy

给定一棵二叉树的根节点 root，请将这棵树翻转，并返回其根节点。翻转后，每个节点的左、右孩子交换位置。

示例 1

输入：root = [4,2,7,1,3,6,9]

输出：[4,7,2,9,6,3,1]

根节点仍为 4；每一层中，每个节点的左右分支都发生了交换。

示例 2

输入：root = [2,1,3]

输出：[2,3,1]

只有一个根和两个孩子时，也要记得两个孩子都要换位。

约束

树中节点数目范围是 [0, 100]；节点值范围是 [-100, 100]。

核心洞察

镜像操作是局部且可递归的：对任意节点，交换它的左右孩子，然后分别翻转两棵子树。空节点天然是递归终点。

过程

  1. 若当前节点为空，直接返回空。
  2. 暂存左孩子，将左孩子替换为右孩子，再将右孩子替换为暂存的左孩子。
  3. 递归处理交换后的左右孩子，最后返回当前根节点。

边界条件

空树；只有根节点；只有一侧孩子；不平衡树。交换对每个非空节点都恰好执行一次。

复杂度

时间 O(n)：每个节点访问一次。递归调用栈为 O(h)，其中 h 是树高；最坏情况为 O(n)。

替代方案

也可以使用队列或栈迭代遍历：每取出一个节点就交换其孩子，并把非空孩子加入容器。它避免了递归深度问题，但额外容器空间最坏为 O(n)。

常见错误

  • 先递归再错误地引用已交换前的孩子，导致漏翻转某一支。
  • 忘记空节点判断，访问 root.left 时抛异常。
  • 新建节点只复制值，丢失原有树结构或没有正确连接孩子。

追问

如果树非常深，如何改成显式栈？如果要求不修改原树，怎样构造一棵新的镜像树？能否证明翻转两次会还原原树？

Java

class Solution {
    public TreeNode mirrorTree(TreeNode root) {
        if (root == null) return null;
        TreeNode temp = root.left;
        root.left = root.right;
        root.right = temp;
        mirrorTree(root.left);
        mirrorTree(root.right);
        return root;
    }
}

JavaScript

/**
 * @param {TreeNode} root
 * @return {TreeNode}
 */
var mirrorTree = function(root) {
  if (root === null) return null;
  [root.left, root.right] = [root.right, root.left];
  mirrorTree(root.left);
  mirrorTree(root.right);
  return root;
};

Python

class Solution:
    def mirrorTree(self, root: TreeNode) -> TreeNode:
        if not root:
            return None
        root.left, root.right = root.right, root.left
        self.mirrorTree(root.left)
        self.mirrorTree(root.right)
        return root

C++

class Solution {
public:
    TreeNode* mirrorTree(TreeNode* root) {
        if (root == nullptr) return nullptr;
        swap(root->left, root->right);
        mirrorTree(root->left);
        mirrorTree(root->right);
        return root;
    }
};
