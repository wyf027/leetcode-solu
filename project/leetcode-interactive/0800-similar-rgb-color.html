相似 RGB 颜色

Similar RGB Color

先读题，再亲手把三个颜色通道逐步吸附到可简写的颜色。完整解法默认收起。

01 / PROBLEM

题意

一个 RGB 颜色写作 #AABBCC：红、绿、蓝三个通道分别是十六进制字节 AA、BB、CC。当每个字节的两个十六进制字符相同时，可以使用三位简写；例如 #15c 与 #1155cc 表示同一种颜色。

两种颜色 #ABCDEF 与 #UVWXYZ 的相似度定义为三个通道数值差的平方和取负：

−[(AB−UV)² + (CD−WX)² + (EF−YZ)²]

给定长格式字符串 color，返回与它相似度最高、且能写成三位简写的七字符颜色。若存在同样最优的答案，返回其中任意一个即可。

约束

  • color.length == 7
  • color[0] == '#'
  • color[1..6] 只包含小写十六进制字符 0-9、a-f

示例 1

输入 color = "#09f166"
输出 "#11ee66"

它可以简写为 #1e6，并使三个通道的总平方误差最小。

示例 2

输入 color = "#4e3fe1"
输出 "#5544dd"

对应的三位简写是 #54d。

准备好看完整推导了吗？

SOLUTION / REVEALED

把每个通道独立舍入到 17 的倍数

核心洞察：可简写的单个通道一定形如 xx。其十进制值为 16x + x = 17x，所以候选值只有 0, 17, 34, …, 255。相似度是三个通道误差平方之和取负，各通道之间没有耦合，因此分别选择最近的 17 的倍数即可。

完整过程

  1. 去掉开头的 #，每两个字符解析为一个十六进制字节。
  2. 对通道值 v，计算最近的索引 q = floor((v + 8) / 17)。
  3. q 本身正好是一个十六进制数位；把该数位重复两次。
  4. 连接三个通道，并在开头补回 #。

示例拆解

#09f166 的通道值是 9、241、102。最近的 17 倍数分别是 17、238、102，对应 11、ee、66，所以得到 #11ee66。

正确性证明

  1. 任何可简写颜色的每个通道都等于某个 17q，其中 q ∈ [0,15]。
  2. 最大化相似度等价于最小化三个非负平方误差之和。
  3. 每一项只包含一个输出通道，故独立最小化每项会同时最小化总和。
  4. floor((v+8)/17) 选择距 v 最近的索引；相邻候选中点落在半整数，整数输入不会产生平局。
  5. 算法为三个通道都选出最小误差候选，所以拼接结果具有最高相似度。

边界与复杂度

  • 0 与 255：舍入后仍落在索引 0 与 15，无需额外截断。
  • 已经可简写：通道本来就是 17 的倍数，保持不变。
  • 大小写：题目输入是小写；代码使用小写数字表输出。
  • 时间：O(1)，固定处理 3 个通道。
  • 额外空间：O(1)，返回字符串不计入额外空间。

替代方案

  • 枚举 4096 种简写色：遍历 16³ 个组合并计算距离，直观但没有利用通道独立性。
  • 每通道枚举 16 个值：总共比较 48 次，仍是常数时间，代码也容易证明。
  • 比较上下界：先取 v / 17 的商，再比较相邻两个倍数；比直接四舍五入更冗长。

四种语言完整代码

Java 
class Solution {
    public String similarRGB(String color) {
        final String digits = "0123456789abcdef";
        StringBuilder answer = new StringBuilder("#");

        for (int i = 1; i < color.length(); i += 2) {
            int value = Integer.parseInt(color.substring(i, i + 2), 16);
            int nearestIndex = (value + 8) / 17;
            char digit = digits.charAt(nearestIndex);
            answer.append(digit).append(digit);
        }

        return answer.toString();
    }
}

class Solution {

    string similarRGB(string color) {
        const string digits = "0123456789abcdef";
        string answer = "#";

        for (int i = 1; i < static_cast<int>(color.size()); i += 2) {
            int value = stoi(color.substr(i, 2), nullptr, 16);
            int nearestIndex = (value + 8) / 17;
            char digit = digits[nearestIndex];
            answer.push_back(digit);
            answer.push_back(digit);
        }

    }

面试追问

  • 为什么可以分别优化三个通道，而不是枚举完整颜色？
  • 公式中的 +8 从哪里来？为什么不是 +8.5？
  • 若相似度换成带权距离，例如绿色权重更大，算法是否改变？
  • 若允许的通道集合不是等差数列，如何用二分查找最近候选？

常见错误

  • 把十六进制数位的相邻关系当作字符编码的相邻关系。
  • 用向下取整 v / 17，遗漏更近的上方候选。
  • 把三个通道拼成一个大整数后整体求近似，破坏距离定义。
  • 输出三位形式；题目要求返回七字符长格式。
  • 使用浮点格式化导致大小写或补零行为不一致。
