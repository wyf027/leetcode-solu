Unique Substrings With Equal Digit Frequency

相同的内容，只算一次。先读题、观察，再展开解题思路。

01 / PROBLEM

题目在问什么？

给定仅由数字字符组成的字符串 s，统计其非空连续子串中，所有实际出现的数字出现次数相等的不同内容有多少种。两个子串即使来自不同位置，只要文本相同，就只计一次。没有出现的数字不参与频率比较。

子串必须连续。“不同”按字符序列区分，而不是按起止下标区分。数字 0 和其他数字一样，前导零不会被删除。

参数与返回值

equalDigitFrequency(s: string) → integer

返回满足条件的不同非空子串数量。

约束

  • 1 ≤ s.length ≤ 1000
  • s 只包含字符 '0' 到 '9'。

EXAMPLE 01

输入：s = "1212"

输出：5

符合条件的内容为 "1", "2", "12", "21", "1212"。"12" 出现两次，但只计一次。

EXAMPLE 02

输入：s = "12321"

输出：9

符合条件的内容为 "1", "2", "3", "12", "23", "32", "21", "123", "321"。

04 / EDITORIAL

准备好后，再看题解

确定性方案：枚举 + 频率统计 + Trie 去重

核心洞察

固定左端点，右端点每次扩展一位，维护 10 个数字的次数、出现种类数 k 和最大次数 m。长度为 L 时，所有正频率相等当且仅当 k × m = L。

Trie 的根到节点路径唯一对应一个字符串。重复内容走到同一终点，只需给节点打“已经计数”标记。此方案不复制完整子串，也不依赖哈希无碰撞假设。

完整过程

  1. 建立根编号为 0 的十叉 Trie。边值 0 表示边不存在，新节点从 1 开始编号。
  2. 枚举左端点 i，清空本轮频率、种类数和最大频率，回到根节点。
  3. 枚举右端点 j，更新新加入数字的频率；首次出现时种类数加一，并更新最大频率。
  4. 沿数字对应的边前进，没有边就创建节点。即使当前窗口无效也要保留路径并继续扩展。
  5. 若 k × m = j − i + 1 且终点尚未计数，则标记并将答案加一。
  6. 遍历完所有区间，返回答案。

以 s = "1212" 为例，i = 0 时依次收录 "1"、"12"，跳过 "121"，收录 "1212"。i = 1 时补入 "2"、"21"。之后遇到的 "1"、"12"、"2" 都已标记，答案为 5。

正确性证明

频率判定：k 个正频率都不超过最大值 m，因此总和 L ≤ k × m。等号成立时，没有频率能小于 m，否则总和严格更小；反过来，全部等于 m 时总和必为 k × m。

覆盖性：两层循环枚举每个非空连续区间，增量频率始终对应当前窗口。

唯一性：相同内容沿相同路径到同一节点，不同内容的终点不同。合法内容第一次到达时被计数，之后被标记拦住。不合法内容不会增加答案。因此计数不重不漏。

复杂度与存储

共 n(n+1)/2 个区间，每步更新、访问边和判定均为 O(1)。预分配初始化需要 O(10n²) 时间，数字集大小固定为 10，所以整体时间 O(n²)，额外空间 O(n²)。

最多 n(n+1)/2 + 1 个节点，每个节点 10 条整型边。n = 1000 时，4 字节整数的边数组约 20 MB，此外还有标记和语言开销。Python 使用紧凑 array('i')。这是预分配的上限，不随实际不同子串数量缩小。

边界与常见错误

  • 单字符总合法；全相同数字时答案为 n，而不是区间数量 n(n+1)/2。
  • 未出现数字的零频率不参与比较。
  • 不能把字符串转成整数："01" 与 "1" 是不同内容。
  • 遇到无效窗口不能提前退出："121" 无效，"1212" 有效。
  • 每个左端点要重置频率和当前节点，但全局 Trie 与计数标记需要保留。
  • 只统计合法区间会重复计算；只为合法区间建立路径会丢失必要前缀。

替代方案

字符串集合：枚举并保存合法子串，直观且精确；但复制和哈希一个长度 O(n) 的子串需要 O(n) 时间，最坏总时间和保存字符总量均可能达到 O(n³)。

滚动哈希：符合官方提示，O(1) 扩展指纹，哈希集合操作的期望时间为 O(1)，整体期望 O(n²) 时间、O(n²) 空间。应把长度放进键；双模数降低碰撞概率但不能保证绝对无碰撞。JavaScript 还需控制乘法的安全整数范围或使用 BigInt。本页用 Trie 提供确定性去重。

面试追问

  • 能否用普通滑动窗口？合法性不单调，扩展能有效→无效→有效，不能直接套用固定收缩规则。
  • 字符集变大？用映射维护频率与稀疏 Trie 边，判定等式仍成立。
  • 只统计区间，不去重？去掉 Trie，合法就加一，额外空间降为 O(10)。
  • 如何输出具体内容？首次计数时保存起点与长度，最后按需截取，避免循环内大量复制。

Java

class Solution {
    public int equalDigitFrequency(String s) {
        int n = s.length(), capacity = n * (n + 1) / 2 + 1;
        int[] next = new int[capacity * 10];
        boolean[] counted = new boolean[capacity];
        int nodes = 0, answer = 0;
        for (int i = 0; i < n; i++) {
            int[] count = new int[10];
            int node = 0, distinct = 0, maxFreq = 0;
            for (int j = i; j < n; j++) {
                int d = s.charAt(j) - '0';
                if (count[d]++ == 0) distinct++;
                maxFreq = Math.max(maxFreq, count[d]);
                int edge = node * 10 + d;
                if (next[edge] == 0) next[edge] = ++nodes;
                node = next[edge];
                if (distinct * maxFreq == j - i + 1 && !counted[node]) {
                    counted[node] = true;
                    answer++;
                }
            }
        }
        return answer;
    }
}

from array import array

class Solution:
    def equalDigitFrequency(self, s: str) -> int:
        n = len(s)
        capacity = n * (n + 1) // 2 + 1
        nxt = array('i', [0]) * (capacity * 10)
        counted = bytearray(capacity)
        nodes = answer = 0
        for i in range(n):
            count = [0] * 10
            node = distinct = max_freq = 0
            for j in range(i, n):
                d = ord(s[j]) - ord('0')
                if count[d] == 0:
                    distinct += 1
                count[d] += 1
                max_freq = max(max_freq, count[d])
                edge = node * 10 + d
                if nxt[edge] == 0:
                    nodes += 1
                    nxt[edge] = nodes
                node = nxt[edge]
                if distinct * max_freq == j - i + 1 and not counted[node]:
                    counted[node] = 1
                    answer += 1
        return answer
