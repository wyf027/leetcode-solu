01 / 题目

输入包裹尺寸数组 packages 和供应商规格数组 boxes。boxes[j] 列出第 j 家供应商提供的箱子尺寸；每种尺寸的箱子数量无限。每只箱子只能放一个包裹，且箱子尺寸必须大于或等于包裹尺寸。

你必须选定同一家供应商，为全部包裹选箱。一个包裹的浪费空间为“箱子尺寸 − 包裹尺寸”。返回最小总浪费空间对 1,000,000,007 取余的结果；若没有任何一家供应商能装下全部包裹，返回 -1。

先比较真实的总浪费空间，确定最小值后才取余。箱子的“无限供应”不意味着一只箱子可以装多个包裹。

参数与返回值

minWastedSpace(packages: integer[], boxes: integer[][]) → integer

完整约束

  • n == packages.length，m == boxes.length
  • 1 ≤ n ≤ 10^5，1 ≤ m ≤ 10^5
  • 1 ≤ packages[i] ≤ 10^5
  • 1 ≤ boxes[j].length ≤ 10^5
  • 1 ≤ boxes[j][k] ≤ 10^5
  • sum(boxes[j].length) ≤ 10^5
  • 同一个 boxes[j] 内的尺寸互不相同。

04 / 题解 · 按箱型覆盖连续区间

核心洞察

固定供应商后，每个包裹都选该供应商能装下它的最小箱子。箱子无限供应，所以一个包裹的选择不会占用另一个包裹的资源。把包裹和箱型分别升序排列，同一箱型负责的包裹就形成一个连续区间。

令 P[i] 为前 i 个包裹尺寸之和。已经分配了前 l 个包裹，当前箱型为 b，二分查找第一个 packages[r] > b 的位置 r，即 upper_bound。新覆盖区间为 [l,r)，无需逐个计算：

本段浪费 = b × (r − l) − (P[r] − P[l])

最大箱型小于最大包裹的供应商直接跳过。其余供应商累计全部区间的浪费，在原始整数范围内比较，最后取余。

分段装箱实验台

沿排序后的包裹带推进：绿色是包裹占用，斜纹是箱内空隙，橙色边框标记本步新增区间。每家供应商独立重新装箱。

演示限制：1–24 个包裹、1–8 家供应商，每家 1–12 种互异箱型，尺寸 1–100000。提交代码支持完整官方范围。

完整过程

  1. 升序排序 packages，构造长度 n+1 的前缀和 P，P[0]=0。
  2. 逐家排序箱型。若最大箱型小于最大包裹，跳过本家。
  3. 令 l=0、waste=0。对每个升序箱型 b，在 [l,n) 二分查找第一个大于 b 的包裹，得到 r。
  4. 累加 b*(r-l)-(P[r]-P[l])，并令 l=r。若 l=n，结束该供应商。
  5. 更新最小浪费。若没有可行供应商，返回 -1，否则对最小值取余。

示例 3 的分段账本

第三家的箱型排序为 [5,10,14]，前缀和为 [0,3,8,16,26,37,49]。箱型 5 覆盖 [0,2)，浪费 10−8=2；箱型 10 覆盖 [2,4)，浪费 20−18=2；箱型 14 覆盖 [4,6)，浪费 28−23=5。总计 9。第一家总计 23，第二家装不下尺寸 12 的包裹。

为什么正确

局部最优：固定供应商，任何包裹若使用了大于最小可用箱型的箱子，都可以换成最小可用箱型，浪费只会减少或不变；无限库存保证此替换不影响其他包裹。因此各包裹独立选最小可用箱型能得到该供应商的最优值。

循环不变式：处理箱型 b 前，前 l 个包裹已经按最小可用箱型分配，余下包裹均大于此前处理过的箱型。upper_bound 得到 r 后，[l,r) 都能放入 b，而且不能放入更早箱型，所以 b 恰好是它们的最小可用箱型。前缀和公式精确累计该区间浪费，不重不漏，更新 l=r 后不变式成立。

全局最优：最大箱型足够时最终 l=n，该供应商全部包裹得到最优分配；最大箱型不足时必然不可行。枚举所有可行供应商并取最小值，因此得到全局最优。若全都不可行，正确返回 -1。

复杂度

设 n 为包裹数，m 为供应商数，第 j 家有 kj 种箱型，总箱型数 K=Σkj。时间为 O(n log n + Σ kⱼ log kⱼ + K log n + m)。前缀和使用 O(n) 空间；计入语言排序辅助空间，保守上界为 O(n + max kⱼ)，不含输入。下方代码会原地排序输入；若需保留输入，可复制后排序。

边界与常见错误

  • 相同尺寸的多个包裹都要计数；箱型只出现一次，但可以使用无限只箱子。
  • 包裹等于箱型时可以放入，必须找“第一个 > b”，不是“第一个 ≥ b”。
  • 某箱型一个包裹也装不了时 r=l，贡献为 0，不能让 l 倒退。
  • 各家供应商的 l 和 waste 都从 0 重置，不能混用不同供应商的箱子。
  • 最大总空间可达 1010。Java 用 long，C++ 用 long long，乘法前先提升类型。
  • JavaScript Number 在本题范围内能精确表示整数，避免位运算处理总和；Python 整数可直接累计。
  • 取余会破坏大小关系，不能按取余后的浪费比较最优供应商；不可行的 -1 不参与取余。

替代方案

也可累加每段“箱子总空间”，最后减去全部包裹尺寸之和，省去前缀和。另一个直观方案是对每个包裹二分供应商箱型，但会产生约 O(Σ n log kⱼ) 的枚举开销，供应商很多时不合适。利用最大尺寸 U=105，还可构建尺寸频数与尺寸总和的前缀数组，使每个箱型的区间查询 O(1)，代价是 O(U) 空间及对值域上界的依赖。

面试追问

  • 允许混用供应商？合并所有箱型，每个包裹选全局最小可用箱型，无需枚举供应商方案。
  • 库存有限时还能独立贪心吗？资源不再独立，本题证明失效；需显式处理库存约束，重新分析排序匹配策略。
  • 如何返回实际装箱方案？记录最佳供应商，再按其箱型重做分段分配；要恢复原包裹顺序，应携带原下标。
  • 尺寸提升到 1012？重新计算累加上界；JavaScript 通常应使用 BigInt 处理乘积、前缀和及最终取余。

Java

import java.util.Arrays;

class Solution {
    public int minWastedSpace(int[] packages, int[][] boxes) {
        Arrays.sort(packages);
        int n = packages.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + packages[i];
        }
        long best = Long.MAX_VALUE;
        for (int[] sizes : boxes) {
            Arrays.sort(sizes);
            if (sizes[sizes.length - 1] < packages[n - 1]) continue;
            int left = 0;
            long waste = 0;
            for (int b : sizes) {
                int lo = left, hi = n;
                while (lo < hi) {
                    int mid = lo + (hi - lo) / 2;
                    if (packages[mid] <= b) lo = mid + 1;
                    else hi = mid;
                }
                int right = lo;
                waste += (long) b * (right - left)
                         - (prefix[right] - prefix[left]);
                left = right;
                if (left == n) break;
            }
            best = Math.min(best, waste);
        }
        return best == Long.MAX_VALUE ? -1 : (int) (best % 1_000_000_007L);
    }
}

var minWastedSpace = function(packages, boxes) {
    packages.sort((a, b) => a - b);
    const n = packages.length;
    const prefix = new Array(n + 1).fill(0);
    for (let i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + packages[i];
    }
    let best = Infinity;
    for (const sizes of boxes) {
        sizes.sort((a, b) => a - b);
        if (sizes[sizes.length - 1] < packages[n - 1]) continue;
        let left = 0, waste = 0;
        for (const b of sizes) {
            let lo = left, hi = n;
            while (lo < hi) {
                const mid = lo + Math.floor((hi - lo) / 2);
                if (packages[mid] <= b) lo = mid + 1;
                else hi = mid;
            }
            const right = lo;
            waste += b * (right - left) - (prefix[right] - prefix[left]);
            left = right;
            if (left === n) break;
        }
        best = Math.min(best, waste);
    }
    return best === Infinity ? -1 : best % 1000000007;

Python 3

from typing import List
from bisect import bisect_right

class Solution:
    def minWastedSpace(self, packages: List[int], boxes: List[List[int]]) -> int:
        packages.sort()
        n = len(packages)
        prefix = [0] * (n + 1)
        for i, p in enumerate(packages):
            prefix[i + 1] = prefix[i] + p
        best = None
        for sizes in boxes:
            sizes.sort()
            if sizes[-1] < packages[-1]:
                continue
            left = 0
            waste = 0
            for b in sizes:
                right = bisect_right(packages, b, left)
                waste += b * (right - left) - (prefix[right] - prefix[left])
                left = right
                if left == n:
                    break
            if best is None or waste < best:
                best = waste
        return -1 if best is None else best % 1_000_000_007
