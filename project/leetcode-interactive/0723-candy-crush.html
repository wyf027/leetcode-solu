723. 粉碎糖果 Candy Crush

在二维糖果棋盘上反复执行“同时粉碎”与“向下坠落”，直到再也找不到连续三个或更多同色糖果。

中等 MEDIUM 会员题 数组 双指针 矩阵 模拟

Problem

题目描述

以下为基于官方题名、函数签名与公开稳定信息的原创转述。

函数：candyCrush(board)

给定一个 m × n 的整数矩阵 board。每个正整数代表一种糖果，数值相同表示糖果颜色相同。

一轮中，所有横向或纵向连续出现至少三个的同色糖果都要被同时粉碎。粉碎后，每一列剩余的糖果在重力作用下向底部落下，顶部空位用 0 表示。

坠落可能形成新的连续糖果，因此要重复上述过程，直到棋盘稳定。返回最终棋盘。

  1. 1 识别本轮所有横向、纵向长度不少于 3 的连续同色段。
  2. 2 同一轮的所有命中位置同时变为空位，交叉位置只需粉碎一次。
  3. 3 逐列下落，保持每列剩余糖果原有的上下相对次序。
  4. 4 没有任何可粉碎糖果时，当前矩阵就是要返回的稳定状态。

准备好再揭晓题解

建议先在实验台中观察几轮变化，并思考如何保证同一轮的糖果“同时”消失。

Core insight

核心洞察：用符号位保存“待粉碎”状态

原矩阵只包含正整数，而最终空位用 0 表示。扫描时可把本轮命中的糖果改成负数：绝对值仍保留颜色，负号则充当标记。后续扫描统一比较绝对值，因此横向标记不会干扰纵向识别，也能让所有命中在扫描结束后同时清零。

完整过程

  1. 横向扫描每个长度为 3 的窗口。若三个非零绝对值相同，就把这三个位置都设为其绝对值的相反数。
  2. 纵向做同样扫描。比较时始终使用绝对值，使一个位置可以同时属于横向和纵向连续段。
  3. 若整轮没有发现任何连续段，棋盘已经稳定，直接返回。
  4. 对每一列从底向上收集所有仍为正数的糖果，用写指针把它们紧凑地写到列底，剩余顶部位置填 0。
  5. 回到第一步。每次进入下一轮之前，棋盘中只有非负数，因此负号仅在一轮扫描期间承担标记职责。

正确性证明

引理 1：标记集合恰好覆盖本轮所有应粉碎位置。

任意长度至少为 3 的连续同色段必包含一个或多个长度为 3 的窗口，因此其中每个位置会被相邻窗口覆盖并标负。反之，只有处在三个同色非零糖果窗口中的位置才会被标负。

引理 2：横纵扫描实现了同时粉碎。

标记阶段不删除糖果，只改变符号；比较使用绝对值，所以较早的标记不会改变后续扫描所见的颜色。扫描结束后统一移除负数，结果等价于同时粉碎全部命中位置。

引理 3：重力步骤得到唯一正确的列状态。

写指针从列底向上接收原列中自下而上遇到的正数，因此所有存活糖果落到最低可用位置，且它们的上下相对次序保持不变；其余顶部位置全部为 0。

结论：算法返回题目要求的稳定棋盘。

每个非稳定轮次至少粉碎一个糖果，正数糖果总数严格减少，所以过程必定终止。终止条件是不存在任何横向或纵向三连，结合前三个引理，返回值正是反复同时粉碎并下落后的稳定状态。

边界情况

  • 输入本来就稳定：第一次扫描没有标记，直接返回原棋盘。
  • 连续段长度大于 3：重叠的三元窗口会覆盖整段。
  • 十字交叉：同一位置可被横向、纵向重复标记，绝对值比较保持颜色信息。
  • 整列清空：写指针不写入任何糖果，整列被 0 填满。
  • 一次下落触发多轮连锁：外层循环会继续扫描，直到稳定。
  • 数值上限 2000 不影响符号标记；题目保证初始糖果值均为正。

复杂度

单轮扫描与重力 O(mn)
总时间（R 轮） O(R · mn)
最坏轮数上界 R ≤ mn / 3
额外空间 O(1)

忽略返回矩阵本身与少量标量变量。若以糖果总数给出粗略最坏上界，总时间可写为 O((mn)²)；实际通常远小于该上界。

Implementations

四语言完整代码

均采用“负号标记 + 列内写指针”的原地模拟。

官方提交形式：int[][] candyCrush(int[][] board)

class Solution {
    public int[][] candyCrush(int[][] board) {
        int rows = board.length;
        int cols = board[0].length;

        while (true) {
            boolean crushed = false;

            // Mark every horizontal triple. Overlapping triples cover longer runs.
            for (int row = 0; row < rows; row++) {
                for (int col = 0; col + 2 < cols; col++) {
                    int value = Math.abs(board[row][col]);
                    if (value != 0
                            && value == Math.abs(board[row][col + 1])
                            && value == Math.abs(board[row][col + 2])) {
                        board[row][col] = -value;
                        board[row][col + 1] = -value;
                        board[row][col + 2] = -value;
                        crushed = true;
                    }
                }
            }

            // Mark every vertical triple using absolute values.
            for (int row = 0; row + 2 < rows; row++) {
                for (int col = 0; col < cols; col++) {
                    int value = Math.abs(board[row][col]);
                    if (value != 0
                            && value == Math.abs(board[row + 1][col])
                            && value == Math.abs(board[row + 2][col])) {
                        board[row][col] = -value;
                        board[row + 1][col] = -value;
                        board[row + 2][col] = -value;
                        crushed = true;
                    }
                }
            }

            if (!crushed) {
                return board;
            }

            // Keep positive candies and compact each column downward.
            for (int col = 0; col < cols; col++) {
                int write = rows - 1;
                for (int row = rows - 1; row >= 0; row--) {
                    if (board[row][col] > 0) {
                        board[write][col] = board[row][col];
                        write--;
                    }
                }
                while (write >= 0) {
                    board[write][col] = 0;
                    write--;
                }
            }
        }
    }
}

var candyCrush = function (board) {
  const rows = board.length;
  const cols = board[0].length;

  while (true) {
    let crushed = false;

    // Mark horizontal triples. Absolute values preserve each candy color.
    for (let row = 0; row < rows; row += 1) {
      for (let col = 0; col + 2 < cols; col += 1) {
        const value = Math.abs(board[row][col]);
        if (
          value !== 0 &&
          value === Math.abs(board[row][col + 1]) &&
          value === Math.abs(board[row][col + 2])
        ) {
          board[row][col] = -value;
          board[row][col + 1] = -value;
          board[row][col + 2] = -value;
          crushed = true;
        }
      }
    }

    // Mark vertical triples without erasing the horizontal marks.
    for (let row = 0; row + 2 < rows; row += 1) {
      for (let col = 0; col < cols; col += 1) {
        const value = Math.abs(board[row][col]);
        if (
          value !== 0 &&
          value === Math.abs(board[row + 1][col]) &&
          value === Math.abs(board[row + 2][col])
        ) {
          board[row][col] = -value;
          board[row + 1][col] = -value;
          board[row + 2][col] = -value;
          crushed = true;
        }
      }
    }

    if (!crushed) {
      return board;
    }

    // Compact each column from bottom to top, then fill its prefix with zeroes.
    for (let col = 0; col < cols; col += 1) {
      let write = rows - 1;
      for (let row = rows - 1; row >= 0; row -= 1) {
        if (board[row][col] > 0) {
          board[write][col] = board[row][col];
          write -= 1;
        }
      }
      while (write >= 0) {
        board[write][col] = 0;
        write -= 1;
      }
    }
  }
};

            # Mark horizontal triples; overlapping windows cover longer runs.

                for col in range(cols - 2):
                    value = abs(board[row][col])
                    if (
                        value != 0
                        and value == abs(board[row][col + 1])
                        and value == abs(board[row][col + 2])
                    ):
                        board[row][col] = -value
                        board[row][col + 1] = -value
                        board[row][col + 2] = -value
                        crushed = True

            # Mark vertical triples using absolute values.
            for row in range(rows - 2):
                for col in range(cols):
                    value = abs(board[row][col])
                    if (
                        value != 0
                        and value == abs(board[row + 1][col])
                        and value == abs(board[row + 2][col])
                    ):
                        board[row][col] = -value
                        board[row + 1][col] = -value
                        board[row + 2][col] = -value
                        crushed = True

            if not crushed:
                return board

            # Move positive candies down and fill the remaining prefix with zeroes.
            for col in range(cols):
                write = rows - 1
                for row in range(rows - 1, -1, -1):
                    if board[row][col] > 0:
                        board[write][col] = board[row][col]
                        write -= 1

                while write >= 0:
                    board[write][col] = 0
                    write -= 1

替代方案

  • 独立布尔标记矩阵：逻辑直观，不修改扫描中的数值；每轮额外使用 O(mn) 空间。
  • 记录坐标集合：可只保存命中位置，但需要去重，最坏仍是 O(mn) 额外空间。
  • 增量维护候选区域：理论上能减少部分重复扫描，但下落会同时改变多行多列，状态维护复杂，面试中通常不如全盘模拟稳妥。

常见错误

  • 发现三连后立刻清零，导致同一轮后续扫描看不到原本应同时消除的糖果。
  • 标负后继续直接比较原值，没有取绝对值，遗漏交叉或重叠连续段。
  • 只标记三个端点中的一部分，或跳过重叠窗口，漏掉长度大于 3 的连续段。
  • 重力从上往下写，覆盖尚未读取的存活糖果。
  • 下落后忘记把列顶部剩余位置补 0。
  • 只执行一轮，没有处理下落后形成的连锁消除。

面试追问

  • 为什么负号标记是安全的？ 因为输入只含正糖果值，0 专门表示空位，符号位没有与业务数据冲突。
  • 为什么三元窗口足够？ 任意长度至少为 3 的连续段都能由相互重叠的长度 3 窗口完全覆盖。
  • 能否先横向粉碎再检查纵向？ 不能；题意要求同一轮同时粉碎，提前删除会改变本轮纵向判断所依据的棋盘。
  • 稳定结果是否确定？ 在每轮按题意同时删除全部命中糖果并确定性下落时，每个状态的下一状态唯一，因此最终结果确定。
  • 如何在不修改输入的前提下实现？ 复制一份棋盘，或使用布尔标记矩阵并在新矩阵上完成重力。
  • 如何输出动画过程？ 在每轮标记、清零、重力完成后各保存一个矩阵快照；本页实验台即采用这种时间线模型。
