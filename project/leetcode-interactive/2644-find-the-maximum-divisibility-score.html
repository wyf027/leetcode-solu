Problem 2644 Easy Array

找出可整除性得分最大的整数

给每个候选除数一轮“整除投票”：能整除的数组元素越多，得分越高；平分时，让更小的数获胜。

Problem

题目说明

函数签名：maxDivScore(nums, divisors) → 整数

给定两个整数数组 nums 和 divisors。对于每个 divisors[i]，统计有多少个下标 j 满足 nums[j] 能被它整除，这个数量就是该除数的可整除性得分。

返回得分最高的候选除数；如果多个候选除数得分相同，返回其中数值最小者。

得分：score(d) = 满足 nums[j] % d === 0 的 j 的数量。

约束

  • 1 <= nums.length, divisors.length <= 1000
  • 1 <= nums[i], divisors[i] <= 109

示例 1

输入：nums = [2,9,15,50], divisors = [5,3,7,2]

输出：2

5、3、2 都得 2 分，取其中最小的 2。

示例 2

输入：nums = [4,7,9,3,9], divisors = [5,2,3]

输出：3

得分依次为 0、1、3，因此返回 3。

示例 3

输入：nums = [20,14,21,10], divisors = [10,16,20]

输出：10

得分依次为 2、0、1，因此返回 10。

Solution

一次完整枚举就够了

核心不是“寻找某个神奇的除数”，而是忠实计算每个候选的得分。

核心洞察

约束最多为 1000 × 1000，直接对每个候选除数扫描整个 nums，最多做一百万次取模，足够直接。维护 bestScore 与 bestDivisor：分数更高时更新；分数相同且除数更小时也更新。

完整过程

  1. 用 -1 初始化最高分，答案初始化为任意占位值。
  2. 枚举 divisors 中的每个 d，统计满足 x % d == 0 的 x 数量。
  3. 若当前得分更高，或得分相同但 d 更小，则更新答案。
  4. 全部候选处理后返回答案。

正确性证明

1

得分计算准确。 对固定候选 d，算法恰好检查 nums 的每个元素一次，并且仅在余数为 0 时计数。因此所得计数正是题目定义的可整除性得分。

2

循环不变量。 每处理完一个候选，bestDivisor 都是已处理候选中得分最高者；如有并列，则是数值最小者。更新条件直接保持了这一性质。

3

结论。 所有候选处理完后，“已处理候选”就是整个 divisors，所以返回值必然满足最高得分与平分取小两个要求。

复杂度

时间 O(n × m)额外空间 O(1)

其中 n = nums.length，m = divisors.length。

边界情况

  • 所有候选得分都是 0：返回最小候选。
  • 只有一个候选或一个被除数：同一逻辑自然覆盖。
  • 候选值重复：会得到相同结果，不影响答案。
  • 值达到 109：只做取模与计数，四种语言的整数范围均足够。

替代方案

可以先将 divisors 升序排序，再只在得分严格变高时更新，这样自然保留最小者。但排序增加 O(m log m) 时间，还可能修改输入；本题直接比较更简单。

面试追问

  • 大量重复候选？ 用映射缓存已计算的得分。
  • 数值上界小但数组很长？ 统计频次，再按除数枚举其倍数。
  • 如何并行？ 每个候选的得分计算彼此独立，最后归并最优二元组。

常见错误

  • 平分时保留先出现者，而不是数值最小者。
  • 把条件写反成 d % x == 0。
  • 最高分初始化为 0，却没有正确初始化零分时的答案。

四语言完整代码

Java
class Solution {
    public int maxDivScore(int[] nums, int[] divisors) {
        int answer = 0;
        int bestScore = -1;

        for (int divisor : divisors) {
            int score = 0;
            for (int num : nums) {
                if (num % divisor == 0) score++;
            }

            if (score > bestScore ||
                (score == bestScore && divisor < answer)) {
                bestScore = score;
                answer = divisor;
            }
        }
        return answer;
    }
}

from typing import List


class Solution:
    def maxDivScore(
        self, nums: List[int], divisors: List[int]
    ) -> int:
        answer = 0
        best_score = -1

        for divisor in divisors:
            score = sum(num % divisor == 0 for num in nums)
            if score > best_score or (
                score == best_score and divisor < answer
            ):
                best_score = score
                answer = divisor

        return answer
