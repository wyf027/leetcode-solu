N-TH TRIBONACCI NUMBER 第 N 个
泰波那契数

T₀ = 0 T₁ = 1 T₂ = 1 Tₙ₊₃ = Tₙ + Tₙ₊₁ + Tₙ₊₂

04 / Solution

滑动窗口迭代

递推式只依赖紧邻的三项，因此无需保留整个序列：三个变量就足以承接每一次状态转移。

核心洞察

计算 Tᵢ 时只读取 Tᵢ₋₃、Tᵢ₋₂、Tᵢ₋₁。用 a、b、c 维护它们，得到新值后整体向前移动一格即可。

完整过程

  1. 若 n = 0，返回 0；若 n = 1 或 2，返回 1。
  2. 令 a = 0、b = 1、c = 1。
  3. 从 i = 3 到 n，计算 next = a + b + c。
  4. 更新 a = b、b = c、c = next，最终返回 c。

复杂度

每个下标只处理一次，并且始终只保存四个整数。

时间 O(n) 空间 O(1)

正确性证明

循环不变式：每次处理下标 i 之前，a、b、c 分别等于 Tᵢ₋₃、Tᵢ₋₂、Tᵢ₋₁。初始化 i = 3 时，三者为 T₀、T₁、T₂，不变式成立。 本轮 next = a + b + c，依据题目递推式可知 next = Tᵢ；更新后 a、b、c 分别成为 Tᵢ₋₂、Tᵢ₋₁、Tᵢ，恰好使下一轮不变式继续成立。循环结束时 i = n 已处理，c = Tₙ，因此返回值正确。n ≤ 2 的情形由基础分支直接返回，也正确。

边界处理

  • n = 0：不能落入“n ≤ 2 返回 1”的合并分支。
  • n = 1 或 2：循环无需启动。
  • n = 37：题目保证结果不超过 32 位有符号整数上限。

四语言完整实现

JavaLeetCode 可提交
class Solution {
    public int tribonacci(int n) {
        if (n == 0) {
            return 0;
        }
        if (n <= 2) {
            return 1;
        }

        int a = 0, b = 1, c = 1;
        for (int i = 3; i <= n; i++) {
            int next = a + b + c;
            a = b;
            b = c;
            c = next;
        }
        return c;
    }
}

class Solution:
    def tribonacci(self, n: int) -> int:
        if n == 0:
            return 0
        if n <= 2:
            return 1

        a, b, c = 0, 1, 1
        for _ in range(3, n + 1):
            a, b, c = b, c, a + b + c
        return c

替代方案

  • 动态规划数组：保存 T₀ 到 Tₙ，思路直观，但空间为 O(n)。
  • 记忆化递归：避免指数级重复计算，仍有递归栈与缓存开销。
  • 矩阵快速幂：可把时间降到 O(log n)，但本题 n ≤ 37，代码复杂度没有必要。

常见错误

  • 把 n = 0 与 n = 1、2 合并后错误返回 1。
  • 循环从 2 开始，或使用 i < n，造成一位偏差。
  • 依次覆盖 a、b、c，却没有先保存三项之和。
  • 只相加两个前驱值，误写成斐波那契递推。

面试追问

  • 如果 n 扩大到 10⁹，如何用 3×3 转移矩阵和快速幂求解？
  • 如果结果需要对某个整数取模，代码应修改在哪里？
  • 如何推广到“前 k 项之和”的 k-bonacci，并将单步更新优化到 O(1)？

一句话复盘

先单独处理三个基础项，再让 (a, b, c) 始终代表当前计算所需的连续三项；求和后同步右移，直到 c 到达 Tₙ。
