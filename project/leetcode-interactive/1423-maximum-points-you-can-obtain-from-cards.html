Problem

题目描述

给定整数数组 cardPoints，其中每个元素表示一张按顺序排放的卡牌点数。一次行动可以从当前序列的开头或末尾拿走一张卡牌。你必须正好行动 k 次，返回所有被拿走卡牌点数之和的最大值。

函数形式

maxScore(cardPoints, k) → integer
  • cardPoints：整数数组
  • k：必须拿取的卡牌数
  • 返回：可获得的最大整数点数

官方示例

示例 1 
输入：cardPoints = [1,2,3,4,5,6,1], k = 3
输出：12
解释：取右侧三张，点数为 1 + 6 + 5 = 12。
示例 2 
输入：cardPoints = [2,2,2], k = 2
输出：4
解释：任取两张，点数都为 4。
示例 3 
输入：cardPoints = [9,7,7,9,7,7,9], k = 7
输出：55
解释：必须拿走全部卡牌。
示例 4 
输入：cardPoints = [1,1000,1], k = 1
输出：1
解释：无法直接拿到中间的卡牌。
示例 5 
输入：cardPoints = [1,79,80,1,1,1,200,1], k = 3
输出：202

约束

  • 1 ≤ cardPoints.length ≤ 105
  • 1 ≤ cardPoints[i] ≤ 104
  • 1 ≤ k ≤ cardPoints.length

核心洞察

拿走 k 张以后，中间恰好留下一个长度为 n-k 的连续区间。因此，“让拿走的分数最大”等价于“让留下区间的分数最小”。

答案 = 全部点数和 − 长度 (n − k) 的最小窗口和

完整过程

  1. 累加所有卡牌，得到 total。
  2. 令窗口长度 windowSize = n - k，先计算第一个窗口。
  3. 窗口每次右移一格：加新元素、减离开元素，并更新最小窗口和。
  4. 返回 total - minWindow。

正确性证明

引理：从两端恰好取 k 张后，未取卡牌必定是一个连续区间，长度为 n-k；反之，每个这样的连续区间都能通过取走它左侧和右侧的卡牌实现。

结论：任一合法方案的得分都是 total - 留下区间和。算法检查了所有长度为 n-k 的连续区间并选择最小和，所以减去它得到的分数不小于任何合法方案。算法返回值即最大得分。

边界与复杂度

  • k = n：窗口长度为 0，直接返回总和。
  • k = 1：结果等价于比较首尾卡牌。
  • 所有点数为正，整数上界下总和在常见 32 位有符号整数范围内。
  • 时间复杂度 O(n)；额外空间复杂度 O(1)。

替代方案

也可以先求“全取左侧 k 张”的和，再逐个撤回左侧卡牌并补入右侧卡牌，枚举左取 k, k-1, …, 0 张的所有组合。该方法时间为 O(k)、空间为 O(1)，与上方实验台直接对应。

面试追问

  • 如果允许拿“至多” k 张，且点数可能为负，应如何改变状态？
  • 若每次能从两端各拿一段，问题是否仍可化为一个连续窗口？
  • 如何在线处理频繁变化的 k 查询？前缀和能带来什么权衡？

常见错误

  • 把可拿卡牌误解为数组中任意 k 张，从而直接选最大元素。
  • 滑窗更新时下标偏一：窗口右端加入 cardPoints[i]，左端移除 cardPoints[i-windowSize]。
  • 漏掉 k = n 导致窗口长度为 0 时访问越界。
  • 只比较“全从左”与“全从右”，遗漏左右混合的更优组合。

class Solution {
    public int maxScore(int[] cardPoints, int k) {
        int total = 0;
        for (int points : cardPoints) {
            total += points;
        }

        int windowSize = cardPoints.length - k;
        if (windowSize == 0) {
            return total;
        }

        int windowSum = 0;
        for (int i = 0; i < windowSize; i++) {
            windowSum += cardPoints[i];
        }

        int minWindowSum = windowSum;
        for (int right = windowSize; right < cardPoints.length; right++) {
            windowSum += cardPoints[right];
            windowSum -= cardPoints[right - windowSize];
            minWindowSum = Math.min(minWindowSum, windowSum);
        }

        return total - minWindowSum;
    }
}

var maxScore = function(cardPoints, k) {
    const total = cardPoints.reduce((sum, points) => sum + points, 0);
    const windowSize = cardPoints.length - k;

    if (windowSize === 0) {
        return total;
    }

    let windowSum = 0;
    for (let i = 0; i < windowSize; i++) {
        windowSum += cardPoints[i];
    }

    let minWindowSum = windowSum;

        windowSum += cardPoints[right];
        windowSum -= cardPoints[right - windowSize];
        minWindowSum = Math.min(minWindowSum, windowSum);
    }

    return total - minWindowSum;
};
from typing import List


class Solution:
    def maxScore(self, cardPoints: List[int], k: int) -> int:
        total = sum(cardPoints)
        window_size = len(cardPoints) - k

        if window_size == 0:
            return total

        window_sum = sum(cardPoints[:window_size])
        min_window_sum = window_sum

        for right in range(window_size, len(cardPoints)):
            window_sum += cardPoints[right]
            window_sum -= cardPoints[right - window_size]
            min_window_sum = min(min_window_sum, window_sum)

        return total - min_window_sum
class Solution {
public:
    int maxScore(vector<int>& cardPoints, int k) {
        int total = accumulate(cardPoints.begin(), cardPoints.end(), 0);
        int windowSize = static_cast<int>(cardPoints.size()) - k;

        if (windowSize == 0) {
            return total;
        }

        int windowSum = accumulate(
            cardPoints.begin(),
            cardPoints.begin() + windowSize,
            0
        );
        int minWindowSum = windowSum;

        for (int right = windowSize;
             right < static_cast<int>(cardPoints.size());
             ++right) {
            windowSum += cardPoints[right];
            windowSum -= cardPoints[right - windowSize];
            minWindowSum = min(minWindowSum, windowSum);
        }

        return total - minWindowSum;
    }
};
