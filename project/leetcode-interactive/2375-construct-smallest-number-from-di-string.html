根据模式串构造最小数字

Construct Smallest Number From DI String

在上升与下降之间，为每一个位置选择恰到好处的数字。

官方题目 ↗

01 / 题目

给定从下标 0 开始、长度为 n 的字符串 pattern。其中 I 表示相邻数字上升，D 表示相邻数字下降。请返回符合模式的、字典序最小的字符串 num。

  • num 长度必须为 n + 1。
  • 只能使用数字字符 '1' 到 '9'，每个数字至多出现一次，不能使用 0。
  • 对每个 0 ≤ i < n，若 pattern[i] = 'I'，则 num[i] < num[i + 1]；若为 'D'，则 num[i] > num[i + 1]。

字典序比较：从左往右找到第一个不同的位置，该位置数字较小的字符串更小。

参数与约束

smallestNumber(pattern: string) → string
1 ≤ pattern.length ≤ 8；pattern 只含大写 I、D。

官方示例 1

输入：pattern = "IIIDIDDD"
输出："123549876"

下标 0、1、2、4 处上升，3、5、6、7 处下降。该输出满足全部关系且字典序最小；重复使用数字的字符串不可行。

官方示例 2

输入：pattern = "DDD"
输出："4321"

四个数字需要连续下降。比如 9876 也符合关系，但 4321 的字典序更小。

04 / 题解与过程演示

核心洞察：让连续下降的数字暂缓输出

只需用 1…n+1。按升序取数字放入栈；遇到 I 或走到末尾，就把栈全部弹出。栈将一段连续数字倒序输出，恰好形成一段下降链。

下降链暂存台

橙色数字暂存在栈中（右侧为栈顶），绿色数字已经写入答案。每一步只执行一次入栈或出栈，蓝框标记当前关系；末尾用 END 表示。

输入 1–8 个大写 I / D；修改后点“应用模式”。

模式关系 / END

暂存栈 · 栈底 → 栈顶

已确定前缀 · 从左向右

键盘：Tab 切换控件，Enter / 空格激活按钮；控制区内可用 ← / → 切换步骤。减少动态效果偏好下，自动播放间隔为 2.4 秒。

完整过程

  1. 建立空栈和空答案，遍历 i = 0…n（包含 n）。
  2. 将数字 i + 1 入栈。
  3. 若 i = n 或 pattern[i] = 'I'，循环弹出栈顶并追加到答案；否则继续积累。
  4. 返回拼接后的字符串。

示例 IIIDIDDD 的输出块为 1 | 2 | 3 | 54 | 9876。在下标 3 遇到 D，先暂存 4；下标 4 放入 5 后遇到 I，依次输出 5、4。最后三个 D 对应四个位置，末尾统一弹出 9、8、7、6。

正确性：可行性与最小性

数字集合：任意可行解中，把第 k 小的数字替换成 k，所有大小关系不变，各位置数字不会增大。因此最优解可在 1…n+1 中寻找。

可行性：每个数字只入栈、出栈一次，所以无重复。栈内数字升序，弹出时降序，满足块内全部 D。相邻块由 I 分隔，后一个块使用的所有数字都更大，因此分界处必然上升。末尾清空保证总长度为 n+1。

字典序最小：假设前面各块已固定，下一个下降块含 k 个位置，最小未使用数字为 m。块首必须拥有 k−1 个可用的更小数字，所以至少为 m+k−1。取到这个下界后，后续下降位置只能使用 m 到 m+k−2，并且必须倒序排列。算法恰好输出这 k 个最小剩余数字的倒序，使当前块最小；对后续块重复该论证，整个字符串最小。任何首次偏离的可行解都会在该块更大。

边界与复杂度

  • 全 I：每次立即弹出，得到升序；全 D：末尾一起弹出，得到降序。
  • 长度 1：I → 12，D → 21。长度 8：恰好用完 1 到 9。
  • 末尾没有实际的模式字符，应先判断 i == n，再访问 pattern[i]。
  • 时间 O(n)：每个数字入栈、出栈各一次。辅助空间 O(n)，答案本身也占 O(n)。

Java

class Solution {
    public String smallestNumber(String pattern) {
        int n = pattern.length();
        int[] stack = new int[n + 1];
        int size = 0;
        StringBuilder answer = new StringBuilder();
        for (int i = 0; i <= n; i++) {
            stack[size++] = i + 1;
            if (i == n || pattern.charAt(i) == 'I') {
                while (size > 0) answer.append(stack[--size]);
            }
        }
        return answer.toString();
    }
}

var smallestNumber = function(pattern) {
    const stack = [], answer = [];
    for (let i = 0; i <= pattern.length; i++) {
        stack.push(i + 1);
        if (i === pattern.length || pattern[i] === 'I') {
            while (stack.length) answer.push(stack.pop());
        }
    }
    return answer.join('');
};

class Solution:
    def smallestNumber(self, pattern: str) -> str:
        stack, answer = [], []

        for i in range(n + 1):
            stack.append(i + 1)

C++

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string smallestNumber(string pattern) {
        int n = static_cast<int>(pattern.size());
        vector<int> stack;
        string answer;
        for (int i = 0; i <= n; ++i) {
            stack.push_back(i + 1);
            if (i == n || pattern[i] == 'I') {
                while (!stack.empty()) {
                    answer.push_back(char('0' + stack.back()));
                    stack.pop_back();
                }
            }
        }
        return answer;
    }
};

替代方案

区间反转：先排列 1…n+1；对模式中的每个极大连续 D 段 [l,r]，反转数字数组的 [l,r+1]。这是同一个构造的另一种实现，时间 O(n)，除结果数组外辅助空间 O(1)。回溯：按 1…9 升序枚举未用数字，检查相邻关系，首次完整解即最小解；最坏枚举规模为阶乘级，长度上限 9 使其可尝试，但没有线性构造直接。

常见错误

  • D 到来才试图给已经输出的最小数字找更小后继，导致无路可走；应延迟输出。
  • 遇到 I 只弹出一个数字；需要清空整个下降块。
  • 漏掉 i=n 的最后一次入栈与清空，返回长度只有 n。
  • 把长度 k 的 D 段当成 k 个数字；它实际连接 k+1 个位置。
  • 输出数值而非字符串，或使用 0 / 重复数字，违反返回形式与约束。

面试追问

如何不用显式栈？使用上述下降段反转。给定任意 n+1 个不同数字呢？先排序，再按相同分块规则安排，可得到最小的元素序列。若 n≥9？原题只有九个不重复数字，无法构造；若扩展为多位整数，应先明确比较的是整数序列还是拼接字符串，原证明不能直接套用。
