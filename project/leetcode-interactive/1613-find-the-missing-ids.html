一张客户表里的编号并不连续。请找出从 1 到当前最大客户 ID 之间，所有没有被使用的编号，并按升序返回。

题目描述

在连续范围里找空位

给定表 Customers，其中每一行保存一个客户的唯一编号与姓名。设表中最大的 customer_id 为 M，需要返回区间 [1, M] 中未出现在表里的所有整数。结果列名为 ids，并按升序排列。

Customers 表结构

把观察变成查询

下面的题解区域默认隐藏。建议先用扫描仪解释一次：如何构造完整范围，又如何识别不在客户表中的编号。

完整题解

递归生成范围，再做反连接

核心洞察

表里只有“已经存在”的 ID，却没有可直接查询的“缺失行”。因此先用递归 CTE 生成 1..M，再把这组完整编号与 Customers 做 LEFT JOIN。连接后客户侧为 NULL 的编号，恰好就是差集。

完整过程

  1. 查询表内最大 ID，记为 M。
  2. 递归 CTE 从 1 开始，每次加 1，直到生成 M。
  3. 用生成的编号左连接客户表。
  4. 保留没有匹配客户行的编号，并按升序输出。

MySQL 8.0+ 可提交答案

WITH RECURSIVE Ids AS (
    SELECT 1 AS id
    UNION ALL
    SELECT id + 1
    FROM Ids
    WHERE id < (SELECT MAX(customer_id) FROM Customers)
)
SELECT Ids.id AS ids
FROM Ids
LEFT JOIN Customers
    ON Customers.customer_id = Ids.id
WHERE Customers.customer_id IS NULL
ORDER BY ids;

正确性证明

完备性：递归 CTE 从 1 出发且每次恰好递增 1，并在 M 停止，所以区间 [1,M] 的每个整数都被生成一次。任一缺失 ID 与客户表连接时都找不到匹配行，因而会被筛选出来。

可靠性：查询只保留连接后 Customers.customer_id IS NULL 的生成编号，因此任何输出值都不在客户表中；又因为它来自 CTE，所以必定位于 [1,M]。故输出恰好是全部缺失 ID。

复杂度与边界

令 M=max(customer_id)，客户数为 N。生成序列需要 O(M) 行；在主键索引连接下，逻辑工作量可视为 O(M log N)，数据库优化器也可能采用近似 O(M+N) 的执行策略。递归结果占 O(M) 空间。本题 M≤100。

最大 ID 本身必在表中，因此不会输出 M。题目数据有客户记录；若迁移到允许空表的系统，应另行规定空表结果并处理 MAX 返回 NULL 的情况。

替代方案

  • 数字表：生产数据库若有持久化 numbers/calendar 表，可直接限制范围后反连接，通常比递归更通用。
  • PostgreSQL：使用 generate_series(1, MAX(...)) 更短，但不是 MySQL 通用语法。
  • NOT EXISTS：可替代 LEFT JOIN，表达“没有匹配行”更直接；避免 NOT IN 潜在的 NULL 语义陷阱。

常见错误

  • 从最小已有 ID 开始生成，导致遗漏 1 到最小 ID 之前的空位。
  • 递归停止条件写成 <= M，多生成 M+1。
  • 只比较相邻行的差值，却没有真正展开一个缺口中的全部数字。
  • 漏掉 ORDER BY ids，依赖数据库未承诺的自然顺序。

面试追问

如果最大 ID 很大？
讨论数字表、序列生成器、递归深度与输出规模；若必须输出每个缺失 ID，成本至少与输出量成正比。
为什么不用 NOT IN？
子查询一旦含 NULL，三值逻辑可能让结果意外为空；NOT EXISTS 或反连接更稳健。
如何只返回缺口区间？
用窗口函数 LAG 找相邻 ID 差值，再输出每段缺口的起止位置，避免展开每个整数。

本地语义参考 · Java 17 
import java.util.ArrayList;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

public class MissingIds {
    public static List<Integer> findMissingIds(int[] customerIds) {
        List<Integer> answer = new ArrayList<>();
        if (customerIds == null || customerIds.length == 0) return answer;

        Set<Integer> existing = new HashSet<>();
        int maxId = 0;
        for (int id : customerIds) {
            existing.add(id);
            maxId = Math.max(maxId, id);
        }
        for (int id = 1; id <= maxId; id++) {
            if (!existing.contains(id)) answer.add(id);
        }
        return answer;
    }

    public static void main(String[] args) {
        System.out.println(findMissingIds(new int[] {1, 4, 5}));
    }
}
本地语义参考 · JavaScript 
function findMissingIds(customerIds) {
  if (!Array.isArray(customerIds) || customerIds.length === 0) return [];

  const existing = new Set(customerIds);
  const maxId = Math.max(...customerIds);
  const answer = [];
  for (let id = 1; id <= maxId; id += 1) {
    if (!existing.has(id)) answer.push(id);
  }
  return answer;
}

console.log(findMissingIds([1, 4, 5])); // [2, 3]
本地语义参考 · Python 3 
from typing import List


def find_missing_ids(customer_ids: List[int]) -> List[int]:
    if not customer_ids:
        return []

    existing = set(customer_ids)
    max_id = max(customer_ids)
    return [customer_id for customer_id in range(1, max_id + 1)
            if customer_id not in existing]


if __name__ == "__main__":
    print(find_missing_ids([1, 4, 5]))  # [2, 3]
本地语义参考 · C++17 
#include <algorithm>
#include <iostream>
#include <unordered_set>
#include <vector>

std::vector<int> findMissingIds(const std::vector<int>& customerIds) {
    if (customerIds.empty()) return {};

    std::unordered_set<int> existing(customerIds.begin(), customerIds.end());
    const int maxId = *std::max_element(customerIds.begin(), customerIds.end());
    std::vector<int> answer;
    for (int id = 1; id <= maxId; ++id) {
        if (existing.find(id) == existing.end()) answer.push_back(id);
    }
    return answer;
}

    std::cout << '\n';
}
