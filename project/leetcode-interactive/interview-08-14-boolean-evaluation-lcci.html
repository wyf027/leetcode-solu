题意

给定一个由 0、1、 &、|、 ^ 交替组成的布尔表达式 s，以及期望结果 result。统计有多少种完整加括号方式，能让表达式的最终结果等于 result。

示例 1

目标为假
输入
s = "1^0|0|1", result = 0
输出
2
两种方式
1^(0|(0|1)) 1^((0|0)|1)

示例 2

目标为真
输入
s = "0&0&0&1^1|0", result = 1
输出
10
约束
运算符数量不超过 19 个。

Backstage · 题解区

先推演，再看完整解法

核心洞察、过程、复杂度、追问与四语言代码默认隐藏。

核心洞察

区间只需要保存两种结果

任意子表达式最终只可能是假或真。令 dp[i][j][0/1] 表示第 i 到第 j 个操作数构成的区间，得到假 / 真的完整加括号方案数。 枚举区间内最后一次执行的运算符，就能把问题拆成两个更短区间。

组合规则

四束灯光汇入真值表

  • &：只有 T × T 进入真计数。
  • |：只有 F × F 进入假计数。
  • ^：T × F 与 F × T 进入真计数。
  • 左右方案独立选择，因此组合数量使用乘法。

完整过程

从短区间铺到整段

  1. 拆出操作数数组与运算符数组。
  2. 单个操作数是基本区间，对应结果的方案数为 1。
  3. 按区间长度从 2 到 q 枚举。
  4. 枚举切点 k，组合左右两侧的真假计数。
  5. 答案是 dp[0][q-1][result]。

边界与复杂度

别把字符长度当操作数个数

  • 单字符表达式直接由初始化得到答案。
  • 操作数个数记为 q，运算符个数为 q - 1。
  • 三层枚举区间长度、左端点、切点：时间 O(q³)。
  • 保存所有区间的真假计数：空间 O(q²)。

替代方案

记忆化递归也很自然

递归枚举每个运算符作为最后切点，并缓存 (left, right) 的真假计数，复杂度与区间 DP 相同。它更贴近“最后一次运算”的思考过程；面试书写时，底向上的 DP 更容易证明计算顺序和空间边界。

常见错误

计数不是布尔值

  • 只保存区间能否为真，丢失了不同括号方式的数量。
  • 组合左右侧时做加法；独立选择应该先相乘，再累加。
  • 漏掉某个切点，或把运算符索引与操作数索引混用。
  • 原地复用临时计数，导致一个切点的贡献污染下一个切点。

面试追问

如果面试官继续追

为什么不会重复？

每棵完整括号树都有唯一的根运算符，因此恰好归入一个最后切点。

能否只算目标值？

不能稳定做到；父层组合通常同时需要左右区间的真、假计数。

如何恢复一种括号方案？

在正计数状态保存一个可行切点和左右目标值，再递归回溯拼接。

class Solution {
    public int countEval(String s, int result) {
        int q = (s.length() + 1) / 2;
        int[][][] dp = new int[q][q][2];

        for (int i = 0; i < q; i++) {
            dp[i][i][s.charAt(i * 2) - '0'] = 1;
        }

        for (int len = 2; len <= q; len++) {
            for (int left = 0; left + len <= q; left++) {
                int right = left + len - 1;
                for (int k = left; k < right; k++) {
                    int lf = dp[left][k][0], lt = dp[left][k][1];
                    int rf = dp[k + 1][right][0], rt = dp[k + 1][right][1];
                    char op = s.charAt(k * 2 + 1);
                    int total = (lf + lt) * (rf + rt);
                    int trueWays;

                    if (op == '&') {
                        trueWays = lt * rt;
                    } else if (op == '|') {
                        trueWays = total - lf * rf;
                    } else {
                        trueWays = lt * rf + lf * rt;
                    }

                    dp[left][right][1] += trueWays;
                    dp[left][right][0] += total - trueWays;
                }
            }
        }
        return dp[0][q - 1][result];
    }
}
