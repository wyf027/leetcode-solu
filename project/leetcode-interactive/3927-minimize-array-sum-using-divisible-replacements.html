可整除替换后的数组最小元素和

给定 nums，可任选 nums[a] % nums[b] == 0 的两个下标，把 nums[a] 替换为 nums[b]。求可得到的最小元素和。

n ≤ 10⁵nums[i] ≤ 10⁵Medium
题意示例

输入：nums = [4, 2, 8, 3]。2 能整除 4 和 8，所以二者都可换成 2；3 没有更小的数组内因子。

题解：枚举“目前还存在”的最小除数

核心洞察

处理值 d 时，若它仍在数组中，就让所有仍未处理、且是 d 倍数的原值直接降到 d。从小到大扫描保证第一次覆盖一个值的 d 就是数组内最小因子；每个位置只需计入一次。

完整过程

  1. 统计每个值的出现次数 freq。
  2. 从 1 到最大值扫描 d；若 freq[d] = 0，跳过。
  3. 枚举 d, 2d, 3d...：对每个仍有频次的倍数 x，累加 freq[x] × d 并将其频次清零。

边界与复杂度

只有一个值时只会被自己覆盖，结果不变；有 1 时所有值会被 1 覆盖。时间 O(M log M + n)，空间 O(M)，M 为最大数组值。

替代方案 / 面试追问

可为每个元素枚举因子，复杂度约 O(n√M)。追问“为什么不能先替换掉小因子？”：算法以当前仍存在的值为源，源一旦已经被更小值替换，正好不再需要参与后续选择。

常见错误

不要只用集合：重复元素必须按频次累加；不要在扫倍数后保留被覆盖的频次，否则会被更大因子重复计入。 

class Solution {
  public long minArraySum(int[] nums) {
    int max = 0; for (int x : nums) max = Math.max(max, x);
    long[] freq = new long[max + 1]; for (int x : nums) freq[x]++;
    long ans = 0;
    for (int d = 1; d <= max; d++) if (freq[d] > 0)
      for (int x = d; x <= max; x += d) if (freq[x] > 0) {
        ans += freq[x] * d; freq[x] = 0;
      }
    return ans;
  }
}

class Solution:
    def minArraySum(self, nums: list[int]) -> int:
        m = max(nums)
        freq = [0] * (m + 1)
        for x in nums: freq[x] += 1
        ans = 0
        for d in range(1, m + 1):
            if freq[d]:
                for x in range(d, m + 1, d):
                    if freq[x]:
                        ans += freq[x] * d
                        freq[x] = 0
        return ans
