01 / PROBLEM

题目说明

给定整数矩阵 grid，大小为 m × n。一步只能移动到上、下、左、右相邻格子，且新格子的值必须严格大于当前值。起点和终点都可以任意选择，路径至少包含一个格子。

统计全部不同的合法路径，返回路径数对 1,000,000,007 取余的结果。两条路径访问的格子序列不同，就视为不同路径；不能只按数字序列去重。

接口：countPaths(grid) → integer · 官方题目

示例 1

输入：grid = [[1,1],[3,4]]
输出：8

长度 1：四个格子分别构成一条路径。长度 2：左上 1 → 3、右上 1 → 4、3 → 4，共三条。长度 3：左上 1 → 3 → 4，共一条。合计 4 + 3 + 1 = 8。

示例 2

输入：grid = [[1],[2]]
输出：3

两条单格路径 [1]、[2]，加上路径 [1 → 2]，总计 3。

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 1000
  • 1 ≤ m × n ≤ 10⁵
  • 1 ≤ grid[i][j] ≤ 10⁵

03 / SOLUTION WORKSHOP

准备好展开思路了吗？

先想一想：相邻格子之间，哪些移动永远不可能发生？

题解 · 按依赖顺序传递路径数

核心洞察

把每个格子当作一个点，从较小值向相邻较大值连有向边。沿边数值始终增加，因此不可能绕回起点，整个图是一张有向无环图（DAG）。我们用拓扑排序确定处理次序，避免深递归。

设 dp[v] 为以格子 v 结尾的递增路径数。
dp[v] = 1 + Σ dp[u]，其中 u 是 v 的四邻接较小格子。
答案为所有 dp[v] 之和，每次加法均取模。

完整过程

  1. 所有 dp 初始化为 1，计入单格路径。令 indegree[v] 等于相邻较小格子的个数。
  2. 将入度为 0 的所有格子入队，它们没有尚未处理的前驱。
  3. 从队列取出 u，此时 dp[u] 已经完整，累加到答案。
  4. 对相邻较大格子 v：将 dp[u] 加到 dp[v]，再将 v 入度减一；减到 0 时将 v 入队。
  5. 队列耗尽后，所有格子的路径数恰好统计一次。

交互实验 · 依赖闸门与路径流

每步取出一个格子，将它的路径数送给所有较大邻居。格子显示「值 / 结尾路径数 / 剩余入度」。绿色实线为本步处理，虚线为待处理队列，灰色为此前已处理。坐标从 0 开始。

示例 1 推演

两个值为 1 的格子首先入队，路径数均为 1。左上 1 贡献给 3，使它的计数变成 2；右上 1 贡献给 4，使它的计数先变成 2，但 4 还要等待 3。处理 3 后，4 的计数变成 4。最终各格计数为 [[1,1],[2,4]]，总和为 8。

正确性证明

  1. 无环性：每条边都使数值严格增加，环会要求起点值严格大于自身，矛盾。因此拓扑排序可以覆盖全部格子。
  2. 递推完备且不重：以 v 结尾的路径，要么只有 v，要么有唯一的倒数第二个格子 u。去掉末尾 v 后，得到一条以 u 结尾的合法路径；反向追加 v 也必然合法。按倒数第二格分组互不重叠，故递推精确。
  3. 队列不变量：入度为 0 表示全部前驱都已贡献路径数。因此弹出时 dp[v] 等于递推的完整结果。由拓扑顺序归纳，每次处理都正确。
  4. 答案：每条路径有唯一终点，按终点累加不会遗漏或重复。取模与加法兼容，所以返回值正确。

边界与实现细节

  • 一个格子返回 1；全部相等时只存在单格路径，返回 m × n。
  • 四方向都可走，数组下标增加并不是递增条件；相等值不连边。
  • 长蛇形路径可能包含 10⁵ 个点，递归 DFS 在部分语言中会栈溢出。这里采用迭代队列。
  • 始终以一维编号 id = r × n + c 表示格子；邻居先验证行列，避免跨行串接。
  • Java 使用 long 累加；C++ 使用 long long；JavaScript 每步将两项模内整数相加，小于 2 × MOD，处于安全整数范围。

复杂度

令 N = m × n。每个格子检查至多四个邻居，建入度和出队传播都是 O(N) 时间；dp、入度和队列占 O(N) 额外空间，不需要显式存储所有边。

替代方案

  • 记忆化 DFS：定义从 v 出发的路径数为 1 加上所有较大邻居的结果，求和。时间、空间都是 O(N)，但最坏递归深度也是 O(N)。它的状态方向与本文「以 v 结尾」相反。
  • 按格子值排序：从小到大处理，直接向较大邻居贡献。实现直观，耗时 O(N log N)、空间 O(N)，相等值不互相转移。

常见错误

  • 套用最长递增路径的 max 递推：这里要求数量，必须求和。
  • 忘记初始化 1，漏掉所有单格路径。
  • 只从全局最小值出发，遗漏其他起点；或只统计局部最大值终点。
  • 把相同数值的格子合并，错误去重。
  • 只收到一个前驱贡献就入队，导致在结果完整前传播。
  • JavaScript 使用 queue.shift() 反复移动数组；应使用队首下标。

面试追问

如果允许相等值呢？图可能出现环；若允许重复访问，路径甚至可能无限。若禁止重复访问，则不再能直接用这个 DAG 递推。

只数长度至少 2 的路径？从答案减去 N，再用 (ans - N % MOD + MOD) % MOD 规范化。

只允许指定起点？dp 全置 0，仅指定起点置 1，仍按整图拓扑顺序传播，再按允许的终点求和。

Java

class Solution {
    public int countPaths(int[][] grid) {
        final long MOD = 1_000_000_007L;
        int m = grid.length, n = grid[0].length, size = m * n;
        int[] degree = new int[size], queue = new int[size];
        long[] dp = new long[size];
        int[] dr = {-1, 1, 0, 0}, dc = {0, 0, -1, 1};
        int head = 0, tail = 0;
        for (int id = 0; id < size; id++) {
            dp[id] = 1;
            int r = id / n, c = id % n;
            for (int k = 0; k < 4; k++) {
                int x = r + dr[k], y = c + dc[k];
                if (x >= 0 && x < m && y >= 0 && y < n
                        && grid[x][y] < grid[r][c]) degree[id]++;
            }
            if (degree[id] == 0) queue[tail++] = id;
        }
        long ans = 0;
        while (head < tail) {
            int id = queue[head++], r = id / n, c = id % n;
            ans = (ans + dp[id]) % MOD;
            for (int k = 0; k < 4; k++) {
                int x = r + dr[k], y = c + dc[k];
                if (x < 0 || x >= m || y < 0 || y >= n
                        || grid[x][y] <= grid[r][c]) continue;
                int v = x * n + y;
                dp[v] = (dp[v] + dp[id]) % MOD;
                if (--degree[v] == 0) queue[tail++] = v;
            }
        }
        return (int) ans;
    }
}

/**

var countPaths = function(grid) {
    const MOD = 1_000_000_007;
    const m = grid.length, n = grid[0].length, size = m * n;
    const degree = new Int32Array(size);
    const dp = new Array(size).fill(1), queue = [];
    const dirs = [[-1, 0], [1, 0], [0, -1], [0, 1]];
    for (let id = 0; id < size; id++) {
        const r = Math.floor(id / n), c = id % n;
        for (const [dr, dc] of dirs) {
            const x = r + dr, y = c + dc;
            if (x >= 0 && x < m && y >= 0 && y < n
                    && grid[x][y] < grid[r][c]) degree[id]++;
        }
        if (degree[id] === 0) queue.push(id);
    }
    let ans = 0;
    for (let head = 0; head < queue.length; head++) {
        const id = queue[head], r = Math.floor(id / n), c = id % n;
        ans = (ans + dp[id]) % MOD;
        for (const [dr, dc] of dirs) {
            const x = r + dr, y = c + dc;
            if (x < 0 || x >= m || y < 0 || y >= n
                    || grid[x][y] <= grid[r][c]) continue;
            const v = x * n + y;
            dp[v] = (dp[v] + dp[id]) % MOD;
            if (--degree[v] === 0) queue.push(v);
        }
    }
    return ans;
};

Python

from typing import List
from collections import deque

class Solution:
    def countPaths(self, grid: List[List[int]]) -> int:
        mod = 10**9 + 7
        m, n = len(grid), len(grid[0])
        size = m * n
        degree = [0] * size
        dp = [1] * size
        queue = deque()
        dirs = ((-1, 0), (1, 0), (0, -1), (0, 1))
        for node in range(size):
            r, c = divmod(node, n)
            for dr, dc in dirs:
                x, y = r + dr, c + dc
                if 0 <= x < m and 0 <= y < n and grid[x][y] < grid[r][c]:
                    degree[node] += 1
            if degree[node] == 0:
                queue.append(node)
        ans = 0
        while queue:
            node = queue.popleft()
            r, c = divmod(node, n)
            ans = (ans + dp[node]) % mod
            for dr, dc in dirs:
                x, y = r + dr, c + dc
                if not (0 <= x < m and 0 <= y < n):
                    continue
                if grid[x][y] <= grid[r][c]:
                    continue
                v = x * n + y
                dp[v] = (dp[v] + dp[node]) % mod
                degree[v] -= 1
                if degree[v] == 0:
                    queue.append(v)
        return ans

    int countPaths(vector<vector<int>>& grid) {
        const long long MOD = 1000000007LL;
        int m = grid.size(), n = grid[0].size(), size = m * n;
        vector<int> degree(size, 0), queue;
        vector<long long> dp(size, 1);
        queue.reserve(size);
        int dr[] = {-1, 1, 0, 0}, dc[] = {0, 0, -1, 1};
        for (int id = 0; id < size; ++id) {
            int r = id / n, c = id % n;
            for (int k = 0; k < 4; ++k) {
                int x = r + dr[k], y = c + dc[k];
                if (x >= 0 && x < m && y >= 0 && y < n
                        && grid[x][y] < grid[r][c]) ++degree[id];
            }
            if (degree[id] == 0) queue.push_back(id);
        }
        long long ans = 0;
        for (int head = 0; head < (int)queue.size(); ++head) {
            int id = queue[head], r = id / n, c = id % n;
            ans = (ans + dp[id]) % MOD;
            for (int k = 0; k < 4; ++k) {
                int x = r + dr[k], y = c + dc[k];

                        || grid[x][y] <= grid[r][c]) continue;
                int v = x * n + y;
                dp[v] = (dp[v] + dp[id]) % MOD;
                if (--degree[v] == 0) queue.push_back(v);
            }
        }
        return (int)ans;
    }
};
