Decode the Message

解密消息.

一把密钥，一段密文。观察字符的出现顺序，找回消息原来的样子。

阅读题目 ↓打开解密工作台 ↓官方题目 ↗

01 / Problem

题目任务

给定两个字符串 key 与 message，分别表示密钥和待解密消息。按 key 中每个小写字母第一次出现的先后顺序，依次对应普通字母表 a…z。用这张对应表替换消息里的字母，所有空格保持原样，返回解密后的字符串。

这里的顺序由密钥决定，不是对密钥中的字母进行字典序排序。

约束

  • 26 ≤ key.length ≤ 2000。
  • 1 ≤ message.length ≤ 2000。
  • 两个字符串都仅包含小写英文字母与空格 ' '。
  • key 保证至少包含一次 a 到 z 中的每个字母。

02 / Examples

官方示例

key = "the quick brown fox jumps over the lazy dog"
message = "vkbs bs t suepuv"

这个密钥的每个字母只出现一次，其顺序直接决定对应关系。

05 / Editorial

独立题解

先自己想一想，再展开推导与四语言代码。

核心洞察：首次出现才分配字母

只需记住“密文字母 → 明文字母”。遇到一个新密文字母，就给它分配下一个尚未使用的明文字母。之后再遇到它时保留原映射。

完整过程

  1. 建立空表，计数器 next = 0 表示已收集的不同字母数。
  2. 从左到右扫描 key：跳过空格；若字母已登记，也跳过；否则令其映射到 'a' + next，然后递增计数器。
  3. 从左到右扫描 message：空格直接加入结果，其他字符查表后加入结果。
  4. 拼接结果并返回。

示例 1 开头依次得到 t→a、h→b、e→c、q→d。消息开头 v、k、b、s 分别对应 t、h、i、s，因此得到 this。

正确性证明

建表不变式：扫描完密钥任意前缀后，表中恰好记录该前缀出现过的非空格字母，并按首次出现次序对应从 a 开始的连续字母。初始空表成立。空格或重复字母不改变表；新字母加入下一个位置，因此不变式继续成立。扫描结束后，题目保证 26 个字母均已出现，所以表完整且符合题意。

解密不变式：处理完消息前 i 个字符后，结果就是这段前缀的正确解密。下一字符若为空格则原样保留，否则用已证明正确的表替换；因此在 i + 1 处仍成立。遍历结束时整个结果正确。

边界与复杂度

只有空格的消息合法；连续空格、开头和结尾空格都必须保留。密钥中的重复字母不能改变之前的映射。题目保证消息中的字母都有映射，提交代码依赖这一约束。

设 n = key.length，m = message.length。时间复杂度 O(n + m)；映射表最多 26 项，辅助表空间 O(1)。若计入返回字符串及结果缓冲，总空间为 O(m)。

替代方案

可以先用保持插入顺序的集合对密钥去重，再把结果与字母表配对；步骤更直观，但多一道中间处理。也可以使用长度 26 的数组，按 c - 'a' 索引。不要排序去重，那会丢失首次出现顺序。

常见错误

  • 把映射方向写成明文到密文，得到加密过程而非解密。
  • 每遇到一个字符就递增计数器，导致重复字母或空格占位。
  • 用 trim、按单词拆分或合并空格，破坏原始间隔。
  • 数组以 0 表示未访问时，同时又用 0 表示 a，使首次映射状态混淆；可用 -1 或字符零值区分。

面试追问

  • 密钥未覆盖全部字母怎么办？应先约定缺失字符的错误处理策略；本题保证覆盖，交互输入则会拒绝不完整密钥。
  • 多条消息共享密钥？只建一次表，再依次解密各条消息。
  • 如何反向加密？反转这张一一对应表，空格仍不变。
  • 密钥很长可以提前停止吗？收集齐 26 个字母后即可停止建表；这不会影响后续解密。

Java

class Solution {
    public String decodeMessage(String key, String message) {
        char[] map = new char[26];
        char next = 'a';
        for (char c : key.toCharArray()) {
            if (c != ' ' && map[c - 'a'] == 0) {
                map[c - 'a'] = next++;
            }
        }
        StringBuilder result = new StringBuilder();
        for (char c : message.toCharArray()) {
            result.append(c == ' ' ? ' ' : map[c - 'a']);
        }
        return result.toString();
    }
}

Java 的 toCharArray() 会额外分配字符数组；此版本含转换数组的额外空间为 O(n + m)，映射表本身仍为 O(1)。

JavaScript

/**
 * @param {string} key
 * @param {string} message
 * @return {string}
 */
var decodeMessage = function(key, message) {
    const map = new Map();
    for (const c of key) {
        if (c !== ' ' && !map.has(c)) {
            map.set(c, String.fromCharCode(97 + map.size));
        }
    }
    const result = [];
    for (const c of message) {
        result.push(c === ' ' ? ' ' : map.get(c));
    }
    return result.join('');
};

Python 3

class Solution:
    def decodeMessage(self, key: str, message: str) -> str:
        mapping = {}
        for c in key:
            if c != ' ' and c not in mapping:
                mapping[c] = chr(ord('a') + len(mapping))
        return ''.join(' ' if c == ' ' else mapping[c]
                       for c in message)

C++

#include <string>
using namespace std;

class Solution {
public:
    string decodeMessage(string key, string message) {
        char mapping[26] = {};
        char next = 'a';
        for (char c : key) {
            if (c != ' ' && mapping[c - 'a'] == 0) {
                mapping[c - 'a'] = next++;
            }
        }
        for (char& c : message) {
            if (c != ' ') c = mapping[c - 'a'];
        }
        return message;
    }
};

C++ 沿用官方按值传参签名；若计入参数复制，空间为 O(n + m)。函数体中的映射表仅 O(1)，直接改写消息副本。
