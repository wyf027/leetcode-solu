Core insight

只生成“仍可能合法”的前缀

一个前缀只需维护两个计数：已放置的左括号 open 与右括号 close。

放 ( 的条件是 open < n；放 ) 的条件是 close < open。第二条保证任何前缀都不会出现“右括号无对象可配”的情况。

当路径长度达到 2n，两种括号必然各用了 n 个，此时直接收录答案。

Invariant

面试时先说不变量

0 <= close <= open <= n

balance = open - close >= 0

path.length = open + close

这三条在每次递归前后都成立，所以生成的终点天然合法，无需最后再过滤。

Process

完整过程

  1. 从空路径、open = close = 0 开始。
  2. 若 open < n，尝试添加左括号并递归。
  3. 回退一步；若 close < open，尝试添加右括号并递归。
  4. 长度到 2n 时复制当前路径到结果集。

Edges

边界情况

  • n = 1：唯一答案是 ["()"]。
  • 刚开局：) 必须封锁，因为 close = open。
  • 左括号用尽：后续只能连续补右括号直到平衡。
  • n = 8：共有 1430 个答案，输出本身已很大。

Complexity

复杂度

第 n 个 Catalan 数记为 Cn，共有 Cn 个答案，每个长度为 2n。

时间：O(n · Cn)

递归辅助空间：O(n)

输出空间：O(n · Cn)

替代方案取舍

可以枚举全部 2^(2n) 个括号串再检查，但会制造大量注定非法的前缀。动态规划也能按 "(" + left + ")" + right 组合答案，适合推导 Catalan 结构；面试主线仍推荐约束清晰、代码短的回溯。

面试高频追问

  • 为什么不是 close <= open？ 添加前必须严格小于，否则添加后会让右括号更多。
  • 结果顺序重要吗？题目通常不要求；先尝试左括号会得到常见字典式顺序。
  • 能否减少字符串复制？使用可变缓冲区，递归后删除末尾字符。

常见错误

  • 把右括号条件写成 close < n，生成非法前缀。
  • 递归返回后忘记撤销最后一个字符。
  • 直接把可变路径对象放进结果集，导致答案随后被修改。
  • 复杂度误写成 O(2^n)，忽略 Catalan 输出规模和字符串长度。

import java.util.*;

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        backtrack(n, 0, 0, new StringBuilder(), result);
        return result;
    }

    private void backtrack(
        int n,
        int open,
        int close,
        StringBuilder path,
        List<String> result
    ) {
        if (path.length() == 2 * n) {
            result.add(path.toString());
            return;
        }

        if (open < n) {
            path.append('(');
            backtrack(n, open + 1, close, path, result);
            path.deleteCharAt(path.length() - 1);
        }

        if (close < open) {
            path.append(')');
            backtrack(n, open, close + 1, path, result);
            path.deleteCharAt(path.length() - 1);
        }
    }
}

var generateParenthesis = function (n) {
    const result = [];
    const path = [];

    function backtrack(open, close) {
        if (path.length === 2 * n) {
            result.push(path.join(""));
            return;
        }

        if (open < n) {
            path.push("(");
            backtrack(open + 1, close);
            path.pop();
        }

        if (close < open) {
            path.push(")");
            backtrack(open, close + 1);
            path.pop();
        }
    }

    backtrack(0, 0);
    return result;
};

        }
    }
