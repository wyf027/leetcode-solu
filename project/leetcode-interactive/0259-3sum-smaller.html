3Sum Smaller

排序后固定第一个数，再用左右指针扫描。若三数和小于目标，左指针与右指针之间的所有第三个选择都有效，一次累计 right - left 个。

题意与约束

给定整数数组 nums 和 target，返回满足 i < j < k 且 nums[i] + nums[j] + nums[k] < target 的三元组数目。

官方样例 1nums = [-2, 0, 1, 3], target = 2
output = 2
官方样例 2nums = [], target = 0
output = 0
边界nums = [0], target = 0
output = 0
约束0 <= nums.length <= 3500
-100 <= nums[i], target <= 100

双指针计数器

准备：排序为 [-2, 0, 1, 3]，固定 i = 0。

当和小于 target 时，批量计数并左移。

题解 · 排序后的批量有效区间

核心洞察与过程

  1. 排序数组，依次固定 i。
  2. left=i+1、right=n-1。
  3. 若和小于目标，所有 k∈[left+1,right] 都有效，加入 right-left，再 left++。
  4. 否则 right-- 降低总和。

复杂度、边界与取舍

排序 O(n log n)，双指针扫描 O(n²)，额外空间取决于排序实现。少于三项返回 0。不能在未排序数组上使用“批量有效”结论；等于 target 不计入。

暴力三重循环是 O(n³)；此题排序单调性使双指针成为面试首选。

常见错误和小于目标时只加 1；把严格小于写成小于等于；固定 i 后未把 left 设为 i+1。

面试追问

若改成 3Sum 等于 0？需要跳过重复值并记录组合。若只问是否存在？命中后可立即返回。若求小于等于？只改比较符号。

 def threeSumSmaller(self, nums: List[int], target: int) -> int:

  for i in range(len(nums)-2):
   l,r=i+1,len(nums)-1
