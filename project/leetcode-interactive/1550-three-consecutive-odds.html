Problem

题目

给定一个整数数组 arr。如果数组中存在三个位置连续、且三个元素均为奇数，则返回 true；否则返回 false。

函数形式

threeConsecutiveOdds(arr: integer[]) → boolean

约束

  • 1 <= arr.length <= 1000
  • 1 <= arr[i] <= 1000

Solution

一次遍历：维护连续奇数长度

核心洞察

我们不必真的保存一个长度为 3 的窗口。只需维护变量 streak：当前元素为奇数时加一，为偶数时清零。一旦 streak === 3，立即返回 true。

完整过程

  1. 初始化 streak = 0。
  2. 从左到右读取每个元素。
  3. 若元素不能被 2 整除，则令 streak += 1；否则令 streak = 0。
  4. 每次更新后检查：若 streak == 3，返回 true。
  5. 遍历结束仍未找到，返回 false。

正确性证明

循环不变量：处理完下标 i 后，streak 等于以 arr[i] 结尾的最长连续奇数段长度。
保持：若 arr[i] 为奇数，它延长前一段，计数加一；若为偶数，不可能有以它结尾的奇数段，计数清零。因此不变量始终成立。
充分性：当计数达到 3 时，当前元素和前两个元素必然是位置连续的三个奇数，所以返回 true 正确。
必要性：若数组存在连续三个奇数，扫描到其中第三个时，根据不变量计数至少为 3，算法一定会返回 true。若遍历完未返回，就不存在这样的三元组。

边界情况

  • 数组长度小于 3：必然返回 false。
  • 开头或结尾恰有三个奇数：都会被扫描到。
  • 偶数会彻底打断连续性，计数必须清零。
  • 超过三个连续奇数：扫描到第三个时即可提前返回。

复杂度

时间：O(n)，最坏遍历整个数组。

空间：O(1)，只维护一个计数器。

替代方案

可以枚举每个长度为 3 的连续窗口，并同时检查三个元素是否为奇数。这同样是 O(n) 时间和 O(1) 空间，表达更直接；连续计数法更容易推广到“连续 k 个满足条件的元素”，也减少了重复检查。

面试追问

  • 如果改成连续 k 个奇数？ 将阈值 3 替换为参数 k。
  • 如果数据来自无限流？ 仍可在线处理，只保存计数器；找到后即可停止。
  • 能否返回起始下标？ 达到阈值时返回 i - 2；一般化后返回 i - k + 1。

常见错误

  • 只统计数组中奇数总数，却忽略“连续”条件。
  • 遇到偶数只减一而不是清零，导致跨越偶数拼接奇数。
  • 使用 x % 2 === 1 处理可能为负数的扩展输入；更稳妥的通用写法是 x % 2 !== 0。本题约束虽然全为正数，也建议保留稳健习惯。
  • 滑窗枚举时边界写成 i < n - 3，漏掉最后一个窗口。

JavaLeetCode 可提交
class Solution {
    public boolean threeConsecutiveOdds(int[] arr) {
        int streak = 0;
        for (int value : arr) {
            if (value % 2 != 0) {
                streak++;
                if (streak == 3) {
                    return true;
                }
            } else {
                streak = 0;
            }
        }
        return false;
    }
}

    let streak = 0;
    for (const value of arr) {
        if (value % 2 !== 0) {
            streak += 1;
            if (streak === 3) {
                return true;
            }
        } else {
            streak = 0;
        }
    }
    return false;
};
