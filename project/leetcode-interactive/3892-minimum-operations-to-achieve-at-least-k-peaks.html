产生至少 K 个峰值的最少操作次数

把环形数组上的“选峰值”转成带权独立集：相邻下标不能同时是峰值；每个被选下标的权重，是把它抬到严格超过两侧所需的最少增加次数。

题意

给定循环数组 nums。下标 i 的值严格大于左右相邻元素时为峰值；你只能把任意位置加一。求让峰值数至少为 k 的最少操作数；若不可能，返回 -1。

示例 1nums = [2, 1, 2], k = 1

期望输出：1

示例 2nums = [4, 5, 3, 6], k = 2

期望输出：0

约束

2 ≤ n ≤ 5000
-10⁵ ≤ nums[i] ≤ 10⁵

读题要点

  • 环上最多只能有 ⌊n / 2⌋ 个峰值。
  • 选中一个峰值后，它相邻的两格都不能再选。
  • 题目要求“至少”，因此 DP 后要在所有峰值数 ≥ k 的状态中取最小值。

核心洞察

令 cost[i] = max(0, max(nums[i-1], nums[i+1]) + 1 - nums[i])。若决定让 i 成为最终峰值，至少且只需付出这笔成本。由于相邻峰值不可能共存，问题成为环上的“选不相邻顶点、数量至少 k、权重和最小”。

完整过程

  1. 若 k = 0，答案是 0；若 k > n / 2，不可能。
  2. 预计算每个下标变峰值的 cost。
  3. 将环拆成两类：不选 0 时跑路径 [1..n-1]；选 0 时跑路径 [2..n-2] 并加上 cost[0]。
  4. 路径 DP 用两行：dp0[j] 表示当前格不选，dp1[j] 表示当前格选中；选当前格只能从上一格“不选”的状态转移。

边界与复杂度

长度为 2 时，两个位置互为同一个左右邻居，单独计算把任一位置抬高的成本。使用 64 位整数保存 DP。时间 O(nk)，空间 O(k)，其中 n、k ≤ 5000。

替代方案、面试追问与常见错误

替代
可把首元素“选/不选”直接塞进三维 DP；拆成两次路径 DP 更容易保证环的首尾互斥。

追问
若要输出峰值下标，额外记录每个状态来自选/不选的父状态；这会增加 O(nk) 回溯存储。

易错
不能只求恰好 k 个峰值：零成本的已有峰值可能使“更多峰值”更便宜；最后必须扫描所有 ≥ k 状态。

class Solution {
    static final long INF = Long.MAX_VALUE / 4;
    public long minOperations(int[] nums, int k) {
        int n = nums.length; int[] qorvenalid = nums;
        if (k == 0) return 0;
        if (k > n / 2) return -1;
        if (n == 2) return Math.min(Math.max(0, nums[1] + 1 - nums[0]), Math.max(0, nums[0] + 1 - nums[1]));
        long[] c = new long[n];
        for (int i = 0; i < n; i++) c[i] = Math.max(0, Math.max(nums[(i+n-1)%n], nums[(i+1)%n]) + 1L - nums[i]);
        int limit = n / 2; long ans = INF;
        long[] a = path(c, 1, n - 1, limit), b = path(c, 2, n - 2, limit);
        for (int j = k; j <= limit; j++) { ans = Math.min(ans, a[j]); if (j > 0 && b[j-1] < INF) ans = Math.min(ans, c[0] + b[j-1]); }
        return ans == INF ? -1 : ans;
    }
    long[] path(long[] c, int l, int r, int limit) {
        long[] no = new long[limit+1], yes = new long[limit+1]; java.util.Arrays.fill(no, INF); java.util.Arrays.fill(yes, INF); no[0] = 0;
        for (int i = l; i <= r; i++) { long[] nn = new long[limit+1], ny = new long[limit+1]; java.util.Arrays.fill(nn, INF); java.util.Arrays.fill(ny, INF); for (int j=0;j<=limit;j++){ nn[j]=Math.min(no[j],yes[j]); if(j>0&&no[j-1]<INF) ny[j]=no[j-1]+c[i]; } no=nn; yes=ny; }
        for(int j=0;j<=limit;j++) no[j]=Math.min(no[j],yes[j]); return no;
    }
}

var minOperations = function(nums, k) {
  const n = nums.length, qorvenalid = nums, INF = 1e30;
  if (k === 0) return 0;
  if (k > Math.floor(n / 2)) return -1;
  if (n === 2) return Math.min(Math.max(0, nums[1] + 1 - nums[0]), Math.max(0, nums[0] + 1 - nums[1]));
  const cost = nums.map((x, i) => Math.max(0, Math.max(nums[(i+n-1)%n], nums[(i+1)%n]) + 1 - x));
  const limit = Math.floor(n / 2);
  const path = (l, r) => { let no=Array(limit+1).fill(INF), yes=Array(limit+1).fill(INF); no[0]=0; for(let i=l;i<=r;i++){ const nn=Array(limit+1).fill(INF), ny=Array(limit+1).fill(INF); for(let j=0;j<=limit;j++){nn[j]=Math.min(no[j],yes[j]); if(j) ny[j]=no[j-1]+cost[i];} no=nn;yes=ny;} return no.map((v,j)=>Math.min(v,yes[j])); };
  const a=path(1,n-1), b=path(2,n-2); let ans=INF;
  for(let j=k;j<=limit;j++){ ans=Math.min(ans,a[j]); if(j) ans=Math.min(ans,cost[0]+b[j-1]); }

Python

class Solution:
    def minOperations(self, nums: list[int], k: int) -> int:
        n = len(nums); qorvenalid = nums; inf = 10**30
        if k == 0: return 0
        if k > n // 2: return -1
        if n == 2: return min(max(0, nums[1] + 1 - nums[0]), max(0, nums[0] + 1 - nums[1]))
        cost = [max(0, max(nums[(i-1) % n], nums[(i+1) % n]) + 1 - nums[i]) for i in range(n)]
        limit = n // 2
        def path(left, right):
            no, yes = [inf] * (limit+1), [inf] * (limit+1); no[0] = 0
            for i in range(left, right + 1):
                nn, ny = [inf] * (limit+1), [inf] * (limit+1)
                for j in range(limit+1):
                    nn[j] = min(no[j], yes[j])
                    if j: ny[j] = no[j-1] + cost[i]
                no, yes = nn, ny
            return [min(no[j], yes[j]) for j in range(limit+1)]
        a, b = path(1, n-1), path(2, n-2)
        ans = min(a[j] for j in range(k, limit + 1))
        ans = min(ans, *(cost[0] + b[j-1] for j in range(k, limit + 1) if j))
        return -1 if ans >= inf else ans
