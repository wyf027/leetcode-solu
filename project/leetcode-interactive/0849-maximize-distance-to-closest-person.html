Maximize Distance to Closest Person

849
Problem

先理解问题

一排座位中，1 表示有人，0 表示空位。选择一个空位，使它到最近已入座者的距离尽可能大，并返回这个最大距离。

题意

给定整数数组 seats，下标从 0 开始。保证至少有一个空位，也至少有一个已占座位。座位间距离按下标差的绝对值计算。

函数形式：maxDistToClosest(seats: integer[]) -> integer。

约束

  • 2 <= seats.length <= 2 * 10^4
  • seats[i] 只能是 0 或 1
  • 至少一个座位为空，至少一个座位有人

官方示例

示例 1
输入：seats = [1,0,0,0,1,0,1]
输出：2
解释：选择 seats[2]，最近的人相距 2。
示例 2
输入：seats = [1,0,0,0]
输出：3
解释：选择末尾 seats[3]。
示例 3
输入：seats = [0,1]
输出：1

Solution

一次扫描，三类空段

核心洞察

答案只可能来自三类位置：开头连续空位的最左端、两名乘客之间空段的中点、结尾连续空位的最右端。

记录上一位已入座者的下标 prev。扫描到新的已入座位置 i 时：若此前没人，候选距离是 i；否则中间空段的候选距离是 (i - prev) / 2 向下取整。扫描结束后再用 n - 1 - prev 结算尾段。

完整过程

  1. 初始化。令 prev = -1、answer = 0。
  2. 扫描。只有在 seats[i] == 1 时结算一段空位。
  3. 处理首段。若 prev == -1，从下标 0 到 i 前全为空，最远距离为 i。
  4. 处理中段。否则两端都有人，选中点，到较近端的距离为 (i - prev) / 2。
  5. 更新锚点。令 prev = i，继续扫描。
  6. 处理尾段。末尾只有左侧有人，候选值为 n - 1 - prev。

正确性证明

首段：空位越向左，离唯一相关的右侧乘客越远，因此最左端最优，距离为首位乘客下标。

中段：设两端乘客下标为 L、R。任意空位 x 的最近距离为 min(x-L, R-x)；两项一增一减，其最小值在中点达到最大，即 floor((R-L)/2)。

尾段：空位越向右，离左侧乘客越远，因此最右端最优，距离为 n-1-prev。

所有空位恰好属于上述某一类空段。算法取得每段最优值中的最大者，所以返回全局最优答案。

边界与复杂度

时间 O(n)额外空间 O(1)全程一次扫描
  • 首位为空：必须单独结算前导 0。
  • 末位为空：循环结束后必须结算尾随 0。
  • 相邻两人：中间候选为 0，但不会影响合法空位产生的答案。
  • 只有一个人：首段或尾段可以直接给出最大距离。

替代方案

方案做法复杂度取舍
连续 0 计数统计每段 0 的长度；中段用 (len+1)/2，边缘用 len。O(n) / O(1)同样优秀，但需明确判断段是否贴边。
左右距离数组两遍扫描记录每个空位到左右最近乘客的距离。O(n) / O(n)直观，空间更多。
逐空位搜索对每个 0 向两侧寻找最近的 1。最坏 O(n²)容易想到，但不适合上限 2×10⁴。

四语言完整代码

Java官方签名
class Solution {
    public int maxDistToClosest(int[] seats) {
        int prev = -1;
        int answer = 0;

        for (int i = 0; i < seats.length; i++) {
            if (seats[i] == 1) {
                if (prev == -1) {
                    answer = i;
                } else {
                    answer = Math.max(answer, (i - prev) / 2);
                }
                prev = i;
            }
        }

        return Math.max(answer, seats.length - 1 - prev);
    }
}

面试追问

如果座位变成圆环怎么办？

首段和尾段会连成同一个中间空段，需要把首尾已入座者之间的环形距离一起计算，不再把边缘视作单边。

如何返回最佳座位下标，而不只是距离？

更新答案时同步记录候选下标：首段取 0，中段取 prev + (i-prev)/2，尾段取 n-1；并提前约定并列时选较小还是较大下标。

如果有多次选座查询和动态入座？

静态一次查询用线性扫描即可；动态场景可维护相邻已占座位的间隔，并用有序集合与最大堆支持拆分间隔和查询最大候选。

常见错误

  • 把中间距离写成空位数的一半；更稳妥的表达是两名乘客下标差除以 2。
  • 所有空段都除以 2，导致首段、尾段答案偏小。
  • 忘记循环结束后处理尾随的 0。
  • 用四舍五入代替向下取整。
  • 按每个空位分别寻找最近乘客，造成 O(n²)。
