LCP 78. 城墙防线

把每段城墙都扩张同样的长度，同时不让相邻墙段重叠。这里的关键不是直接分配左右扩张量，而是把“能否扩张到 k”变成单调的可行性问题。

二分答案贪心扫描O(n log M)

题意（准确转述）

数组 rampart[i] = [x, y] 表示按位置升序排列、互不重叠的第 i 段城墙。所有墙同时水平膨胀相同长度；每段可把这段长度分到左、右任意两侧。两端城墙可向外无限延伸。求在所有城墙始终不重叠时，每段最多能膨胀多少。

示例 1

rampart = [[0,3],[4,5],[7,9]]

答案：3。中间墙左扩 1、右扩 2；首尾向外扩。

示例 2

rampart = [[1,2],[5,8],[11,15],[18,25]]

答案：4。

约束：3 ≤ rampart.length ≤ 10⁴，端点最大为 10⁸。输入已排序且初始无重叠。

先观察单调性

若每段可膨胀 k，就一定可膨胀任意 0…k-1。因此答案处在一条“可行 / 不可行”的边界上。

  1. 1. 猜一个长度 k。
  2. 2. 从左向右，让每一面中间城墙尽量先使用左侧空隙。
  3. 3. 左侧不够的部分只能向右借；若撞到下一段左端点，则该 k 不可行。

题解已折叠

题解：二分 + 左优先贪心

可行性检查

维护上一段墙已占用到的右端 last。对中间第 i 段，左空隙是 rampart[i][0] - last。若它不足 k，还差的 k - gap 必须向右膨胀，因此新右端为 rampart[i][1] + max(0, k-gap)。它不得越过下一墙左端。

为什么先用左边？

向左扩张只消耗已经无法被后面墙段使用的空间；把可用量留在右侧，给后续墙段更多选择。于是这个局部选择不会降低后缀可行性。

完整过程

  1. 二分 k，上界可取所有间隔总和除以 n-2。
  2. 首段可以无限向左扩，因此从它的原右端开始。
  3. 扫描中间墙段，优先使用左空隙，不足部分向右扩。
  4. 一旦右端超过下一段起点，当前 k 失败；否则二分尝试更大值。

边界

首尾墙向外无限；只有中间 n-2 段需要被夹在两个间隔中验证。

复杂度

每次检查 O(n)，二分 O(log 10⁸)，总计 O(n log M)，额外空间 O(1)。

替代方案

可以直接推导相邻空隙的传递关系，但二分+验证更直观，也更不易漏掉边界。

面试追问与常见错误

  • 为什么不是让每段均分左右间隔？因为上一步对左间隔的消耗会影响下一段，需保持一个可传递状态。
  • 不要验证最后一段向右的空间：它可以无限向外扩。
  • 不要将“本段右扩量”当成累计右端；必须用更新后的 last 计算下一段左空隙。

class Solution {
    public int rampartDefensiveLine(int[][] rampart) {
        int n = rampart.length, left = 0;
        long total = 0;
        for (int i = 1; i < n; i++) total += rampart[i][0] - rampart[i - 1][1];
        int right = (int) (total / (n - 2));
        while (left < right) {
            int mid = left + (right - left + 1) / 2;
            if (ok(rampart, mid)) left = mid;
            else right = mid - 1;
        }
        return left;
    }
    private boolean ok(int[][] a, int k) {
        long last = a[0][1];
        for (int i = 1; i < a.length - 1; i++) {
            long gap = a[i][0] - last;
            last = a[i][1] + Math.max(0L, k - gap);
            if (last > a[i + 1][0]) return false;
        }
        return true;
    }
}
