    SAFETY

    边界与不变量

    1. 1. 用 long / 64 位整数避免取绝对值溢出。
    2. 2. 每次只在 multiple ≤ remainder 时扣减。
    3. 3. 从大到小扫描一次即可累积二进制商。
    4. 4. MIN_VALUE / -1 截断为 MAX_VALUE。

    IDEA

    把除法变成减法

    例如 43 ÷ 5：先尝试 5×8=40，余数变为 3，商加 8；再尝试较小倍数。每个被选倍数对应商的一个二进制位。

    class Solution:
    def divide(self, dividend: int, divisor: int) -> int:
        negative = (dividend < 0) != (divisor < 0)
        a, b, ans = abs(dividend), abs(divisor), 0
        for i in range(31, -1, -1):
            if (a >> i) >= b:
                a -= b << i; ans += 1 << i
        ans = -ans if negative else ans
        return min(2**31 - 1, ans)
