MINIMUM FUEL COST TO REPORT TO THE CAPITAL

到达首都的
最少油耗

所有代表，都要抵达城市 0。
车辆有限座位，途中可以换乘。怎样规划这场集结？

阅读题目 ↓

01 / PROBLEM

任务说明

有 n 座城市，编号为 0 … n − 1，由 n − 1 条双向道路组成一棵树，城市 0 是首都。数组 roads[i] = [aᵢ, bᵢ] 表示一条连接这两座城市的道路。

每座城市有一名代表和一辆车；所有车的座位数均为 seats。代表需要前往首都开会，可以开本城的车，也可以在途中换乘、与其他代表拼车。每辆车每经过一条道路消耗 1 升汽油。求所有代表抵达首都所需的最少总油耗。

参数与返回值
minimumFuelCost(roads, seats) → 最少油耗
城市数由 roads.length + 1 得到；首都的代表已经在目的地。

完整约束

  • 1 ≤ n ≤ 10⁵，roads.length = n − 1。
  • roads[i].length = 2。
  • 0 ≤ aᵢ, bᵢ < n，且 aᵢ ≠ bᵢ。
  • roads 保证构成一棵合法的树。
  • 1 ≤ seats ≤ 10⁵。

03 / SOLUTION

每条边，都是一道必须通过的关口

以城市 0 为根。对非根城市 u，切断它与父亲之间的道路后，u 子树内的所有代表都必须跨过这条边。设人数为 size[u]，一辆车最多坐 seats 人，因此这条边至少需要 ceil(size[u] / seats) 辆车经过。

核心公式
答案 = Σ (u ≠ 0) ceil(size[u] / seats)
统计的是每一条边上的车辆次数；同一辆车走两条边就要贡献两次油耗。

完整过程 · 先定父子关系，再反向汇总

  1. 建立双向邻接表。用城市 0 起步，生成父亲数组 parent 和一个父亲早于孩子出现的遍历顺序 order。
  2. 每座城市的人数初始化为 1，代表本城的代表。
  3. 倒序处理 order，跳过根。处理 u 时，其所有孩子都已处理，所以当前人数等于整棵子树人数。
  4. 累加 ceil(size[u] / seats) 升油耗，再执行 size[parent[u]] += size[u]。
  5. 所有非根节点处理完毕即得到答案。整个过程使用数组，不依赖递归栈。

为什么一定最优？

① 每条边都有不可回避的下界

树上从任意城市到首都的路径唯一。非根节点子树内的 s 名代表都必须经过其父边；一次车辆穿越最多带 seats 人，所以至少消耗 ceil(s / seats) 升。这对每条父边同时成立，相加得到总油耗下界。

② 自底向上的拼车能够达到下界

叶子可以直接使用自己的车。假设各孩子已按最少车数把代表送到当前节点，孩子带来的车加本城的一辆车足以容纳所有到达的人。代表在这里重新分组，保留恰好 ceil(s / seats) 辆车向父亲出发，其他车停下即可。由叶子向上归纳，所有父边都能达到各自的下界，因此总和就是最优值。

③ 反向遍历保证人数正确

正向构造顺序时，父亲一定先于孩子；反转顺序后，所有后代都先于祖先汇总。每个节点只把自己的人数传给父亲一次，既不遗漏也不重复。

复杂度与数值范围

建图、遍历和汇总各为 O(n) 时间；邻接表、父亲、顺序及人数数组共 O(n) 额外空间。最坏链形树且 seats = 1 时，答案为 n(n−1)/2；当 n = 100000 时等于 4,999,950,000。Java 使用 long、C++ 使用 long long；Python 整数和 JavaScript 的 Number 在本题范围内可精确表示。

边界与常见错误

  • 只有首都：循环没有非根节点，返回 0。
  • 座位数为 1：油耗等于所有非根代表到首都的距离之和。
  • 座位充足：每条边依然至少需要一辆车，总计 n − 1 升。
  • 不要给根计费：根没有通往父亲的道路。
  • 不能把全体人数一次向上取整；不同分支在汇合前各有道路成本。
  • 人数必须包含当前城市自己的代表；不应只统计叶子。
  • 使用向上取整，不能用普通整数除法截断；先处理父亲会漏掉后代人数。
  • 无向图要跳过父亲；长链递归可能导致栈溢出。

替代方案

递归 DFS 可直接返回子树人数，逻辑简洁，但 10⁵ 节点长链可能超过语言栈深限制。也可以从非根叶子开始做拓扑式剥离：维护度数、人数与队列，每剥离一个叶子就向其唯一未处理邻居汇总；同样为 O(n)，需要谨慎保留根。

面试追问

  • 道路有不同油耗？ 若每辆车通过边 e 耗油 w[e]，将该边贡献乘以 w[e]，相同下界与构造仍成立。
  • 为什么不要求满座？ 余数对应最后一辆未坐满的车，因此要向上取整。
  • 如果路网有环？ 唯一路径与子树割边论证失效，不能直接套用本公式。
  • 车的座位数不一致呢？ 不能再用统一的除数，必须考虑可用车辆及其容量，原公式不适用。

Java

import java.util.*;

class Solution {
    public long minimumFuelCost(int[][] roads, int seats) {
        int n = roads.length + 1;
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] edge : roads) {
            graph.get(edge[0]).add(edge[1]);
            graph.get(edge[1]).add(edge[0]);
        }
        int[] parent = new int[n];
        int[] order = new int[n];
        parent[0] = -1;
        int length = 1;
        for (int i = 0; i < length; i++) {
            int u = order[i];
            for (int v : graph.get(u)) {
                if (v == parent[u]) continue;
                parent[v] = u;
                order[length++] = v;
            }
        }
        long[] size = new long[n];
        Arrays.fill(size, 1L);
        long fuel = 0;
        for (int i = n - 1; i > 0; i--) {
            int u = order[i];
            fuel += (size[u] + seats - 1) / seats;
            size[parent[u]] += size[u];
        }
        return fuel;
    }
}

var minimumFuelCost = function(roads, seats) {
    const n = roads.length + 1;
    const graph = Array.from({ length: n }, () => []);
    for (const [a, b] of roads) {
        graph[a].push(b);
        graph[b].push(a);
    }
    const parent = Array(n).fill(-1);
    const order = [0];
    for (let i = 0; i < order.length; i++) {
        const u = order[i];
        for (const v of graph[u]) {
            if (v === parent[u]) continue;
            parent[v] = u;
            order.push(v);
        }
    }
    const size = Array(n).fill(1);
    let fuel = 0;
    for (let i = n - 1; i > 0; i--) {
        const u = order[i];
        fuel += Math.ceil(size[u] / seats);
        size[parent[u]] += size[u];
    }
    return fuel;
};

Python

from typing import List

class Solution:
    def minimumFuelCost(self, roads: List[List[int]], seats: int) -> int:
        n = len(roads) + 1
        graph = [[] for _ in range(n)]
        for a, b in roads:
            graph[a].append(b)
            graph[b].append(a)

        parent = [-1] * n
        order = [0]
        i = 0
        while i < len(order):
            u = order[i]
            for v in graph[u]:
                if v == parent[u]:
                    continue
                parent[v] = u
                order.append(v)
            i += 1

        size = [1] * n
        fuel = 0
        for u in reversed(order[1:]):
            fuel += (size[u] + seats - 1) // seats
            size[parent[u]] += size[u]
        return fuel

#include <vector>
using namespace std;

class Solution {
public:
    long long minimumFuelCost(vector<vector<int>>& roads, int seats) {
        int n = static_cast<int>(roads.size()) + 1;
        vector<vector<int>> graph(n);
        for (const auto& e : roads) {
            graph[e[0]].push_back(e[1]);
            graph[e[1]].push_back(e[0]);
        }
        vector<int> parent(n, -1), order{0};
        for (int i = 0; i < static_cast<int>(order.size()); ++i) {
            int u = order[i];
            for (int v : graph[u]) {
                if (v == parent[u]) continue;
                parent[v] = u;
                order.push_back(v);
            }
        }
        vector<long long> size(n, 1);
        long long fuel = 0;
        for (int i = n - 1; i > 0; --i) {
            int u = order[i];
            fuel += (size[u] + seats - 1) / seats;
            size[parent[u]] += size[u];
        }
        return fuel;
    }
};
