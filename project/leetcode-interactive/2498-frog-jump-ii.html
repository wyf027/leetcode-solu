青蛙过河 II

Frog Jump II

一次出发，一次归来。如何让整个往返中最远的一跳尽可能短？

○ 严格递增的位置／ 石头至多到达一次／ 最小化最大跳跃

01 / 读懂任务

给定下标从 0 开始的整数数组 stones，它按严格递增顺序列出河中各块石头的位置。青蛙从第一块石头出发，必须到达最后一块石头，再回到第一块。

青蛙可以跳向任意石头，但每块石头最多作为落点一次。初始站在第一块石头上不算一次落地，因此最后可以跳回起点；中途不能重复落在某块石头上，也不要求使用所有石头。

从下标 i 跳到下标 j 的距离为 |stones[i] - stones[j]|。路径代价取所有跳跃距离的最大值，返回可行往返路径中的最小代价。

思考前先区分：目标是降低“最远的一跳”，不是最少跳跃次数，也不是最小总路程。

参数与返回值

maxJump(stones: integer[]) → integer

完整约束

  • 2 ≤ stones.length ≤ 10⁵
  • 0 ≤ stones[i] ≤ 10⁹
  • stones[0] == 0
  • stones 严格递增。

02 / 官方示例

示例 1
输入：stones = [0,2,5,6,7]
输出：5

一条最优路线按位置写作 0 → 5 → 7 → 6 → 2 → 0，跳跃距离依次为 5、2、1、4、2，最大值为 5；更小的代价无法完成往返。

示例 2
输入：stones = [0,3,9]
输出：9

可以直接从位置 0 跳到 9，再跳回 0。两次距离都是 9，代价为 9；位置 3 可以不用。

04 / 想好之后，再打开

题解包含分步河道、正确性证明及四语言代码。

核心洞察 / 给回程留一条路

去程若依次踩完中间石头，回程就只能从终点直接跳回起点。更好的构造是：去程走偶数下标，回程走奇数下标，终点只访问一次。这样绝大多数跳跃只跨过一块石头。

n = 2：答案 = stones[1] - stones[0]
n ≥ 3：答案 = max(stones[i] - stones[i-2]), 2 ≤ i < n

实现统一初始化 ans = stones[1] - stones[0]，再扫描所有相隔两个下标的位置差。无需保存实际路径。

交互 / 双通道河岸

先用三石窗口累计必要的距离下界，再播放达到该下界的往返路线。上弧为去程，下弧为回程；橙色为当前跳跃。石头按下标等距展示，距离以标注的真实坐标为准。

首项必须为 0，所有值为 0–10⁹ 的整数且严格递增。此数量限制仅用于图形展示，算法支持 10⁵ 块。

当前阶段

累计下界

已播放路线的最大跳跃

所有控件支持 Tab 聚焦，按钮使用 Enter / 空格操作。减少动态效果偏好开启时仍可手动逐步，自动播放使用较慢的离散帧。

完整过程

  1. 读取相邻第一对的距离作为初值，覆盖只有两块石头的情况。
  2. 令 i 从 2 到 n-1，计算 stones[i] - stones[i-2]。
  3. 把这个距离与当前答案取最大值，扫描结束返回答案。

示例 1：初值为 2；三个窗口的跨度依次为 5、4、2，累计最大值为 5、5、5。构造的路线 0 → 5 → 7 → 6 → 2 → 0 恰好达到代价 5。

为什么一定正确？

下界：把任意合法往返路线拆成从起点到终点的去程和反向看待的回程，两条路径不能共享中间石头。对任意 i ≥ 2，中间石头 i-1 最多属于一条路径，另一条路径一定避开它。该路径从下标不大于 i-2 的区域到达下标不小于 i 的区域时，必然有一跳直接跨越两个区域，距离至少为 stones[i]-stones[i-2]。因此所有这些跨度的最大值都是不可突破的下界；即使路径不单调，这个跨越仍然存在。

上界：去程按 0,2,4,… 前进，如果没有落在终点就再跳到终点；回程按小于终点的奇数下标递减，最后返回 0。所有中间石头各使用一次，所有跳跃的下标差不超过 2。相隔两块的距离受上述最大跨度限制，相邻距离也被包含它的某个三石窗口跨度覆盖。因此这条路线的代价不超过下界。

结论：当 n ≥ 3 时上下界相同，公式最优。n = 2 时只能两石往返，答案就是它们的距离。

复杂度与边界

  • 时间 O(n)，额外空间 O(1)；演示为画图保存路线，不属于提交算法的空间成本。
  • 大间隔无需特殊分支；循环会覆盖它附近的窗口。
  • 位置差最多 10⁹，Java/C++ 的 32 位有符号整数足够，JavaScript 的 Number 也能精确表示。
  • 数组已排序，不必再次排序，也不能修改下标顺序来“优化”答案。

四语言提交代码

Java

class Solution {
    public int maxJump(int[] stones) {
        int ans = stones[1] - stones[0];
        for (int i = 2; i < stones.length; i++) {
            ans = Math.max(ans, stones[i] - stones[i - 2]);
        }
        return ans;
    }
}

替代方案与面试追问

二分答案是否可行？

可以二分允许的最大距离 D，每次检查初始间距以及全部两下标跨度是否都不超过 D。由上述证明，这正是可行条件，且对 D 单调。复杂度为 O(n log U)，其中 U = stones[n-1]-stones[0]。既然检查条件已经是取最大值，直接线性扫描更简洁。

如果面试官要求返回路线？

输出偶数下标去程，补上尚未访问的终点，再倒序输出小于终点的奇数下标，最后输出 0。时间仍为 O(n)，保存输出需要 O(n) 空间。

如果允许重复落在石头上？

两程都可以相邻跳，答案变成最大相邻距离；本题的跨两下标公式依赖于不能复用中间石头。

如果必须访问所有石头？

最优值不变：这里的奇偶分路构造本来就访问了所有石头。

常见错误

  • 只求最大相邻距离：忽略了回程不能再使用去程石头。
  • 求跳跃总距离或次数：与题目要求的最大单跳距离不同。
  • 从答案 0 开始但只扫描两下标跨度：两块石头时循环为空，得到错误答案。
  • 以为每块石头必须访问：题目允许跳过；构造访问全部只是达到最优的一种方式。
  • 把题目与“青蛙过河 I”的前一跳长度限制混淆：这里没有 k−1、k、k+1 规则。
  • 构造时重复加入终点：终点可能已经在偶数下标序列里，需要判断后再补。
