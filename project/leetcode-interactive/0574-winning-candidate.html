574. 当选者

Winning Candidate

两张表，一场选举。先读懂数据契约，再亲手推进每张选票；完整 SQL 与证明暂不露出，留给你先形成自己的查询思路。

01 / Brief

题目与数据契约

你需要从候选人目录与逐票记录中，返回唯一获胜候选人的名字。下面是基于官方元数据的简洁转述，不大段复刻付费题面。

任务

报告获得最多选票的候选人

表 Candidate 保存候选人的唯一编号与姓名；表 Vote 的每一行代表一张选票，candidateId 指向得票候选人。

编写一条数据库查询，统计每位候选人的票数，并返回票数最高者的 name。测试数据保证获胜者唯一，因此结果只包含一行。

返回列名必须为 name。候选人即使没有得票，也可能存在于 Candidate 表中；决定胜负的是 Vote 中的真实记录。

Constraints

约束与保证

  • Candidate.id 在候选人表中唯一。
  • Vote.id 是自增主键，因此每张选票记录唯一。
  • Vote.candidateId 是引用 Candidate.id 的外键。
  • 每一行 Vote 恰好表示投给对应候选人的一票。
  • 测试数据保证只有一位候选人的票数严格最高，因此无需定义并列规则。

04 / Solution

准备好核对思路了吗？

完整题解包含 SQL、证明、复杂度、边界分析，以及四种通用语言的本地语义参考实现。

Solution revealed

从票箱到姓名

SQL 的关键不是复杂连接，而是把“每行一票”准确投影成“每位候选人的票数”，再取唯一最大值并映射回姓名。

Core insight

核心洞察与完整过程

01

连接

按 Candidate.id = Vote.candidateId 把每张票关联到候选人姓名。

02

分组计数

以候选人分组，COUNT(*) 就是该候选人获得的选票数。

03

降序取首

票数降序排列后取第一行；唯一获胜者保证这一行无歧义。

Primary submission

MySQL 查询

SQLLeetCode 官方提交语言
SELECT c.name
FROM Candidate AS c
INNER JOIN Vote AS v
    ON v.candidateId = c.id
GROUP BY c.id, c.name
ORDER BY COUNT(*) DESC
LIMIT 1;

使用内连接是安全的：获胜者必然至少获得一票，零票候选人不可能超过已有票候选人；题目又保证唯一胜者。

Why it works

正确性证明

  1. 连接后，Vote 的每一行仍恰好出现一次，并且被关联到其 candidateId 对应的唯一候选人；因此没有选票被重复或遗漏。
  2. 对候选人分组后，组内行数恰好等于该候选人的得票数，所以 COUNT(*) 得到正确票数。
  3. ORDER BY COUNT(*) DESC 将票数最大者放在首位。由于最大票数唯一， LIMIT 1 返回且只返回获胜者。
  4. 查询投影该行的 c.name，故最终结果正是唯一获胜候选人的姓名。

Cost & boundaries

复杂度与边界

  • 设候选人数为 C、选票数为 V。连接与聚合通常处理 V 行。
  • 概念时间复杂度约为 O(V + C log C)；实际执行代价取决于索引、哈希聚合和优化器。
  • 聚合需要至多 O(C) 的额外分组空间。
  • 只有一位候选人时仍适用；只要存在有效选票，他会自然成为唯一胜者。
  • 候选人可以零票；内连接不会保留他们，但不影响寻找正票数的唯一胜者。
  • 若业务允许所有人零票或最高票并列，就必须额外定义“无结果”或“返回所有并列者”的规则；本题无需处理。

Alternatives

替代方案

  • 先在 Vote 中按 candidateId 聚合、排序并取第一名，再与 Candidate 连接。语义更分阶段，结果相同。
  • 支持窗口函数的数据库可用 DENSE_RANK() OVER (ORDER BY COUNT(*) DESC)；它更适合扩展为“返回所有并列第一”，但对本题略显冗长。
  • 左连接可以显式保留零票候选人，但计票必须写 COUNT(v.id)，不能写 COUNT(*)，否则连接产生的占位行会被误计为一票。

Java本地语义参考
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class Solution {
    public static final class Candidate {
        public final int id;
        public final String name;

        public Candidate(int id, String name) {
            this.id = id;
            this.name = name;
        }
    }

    public static final class Vote {
        public final int id;
        public final int candidateId;

        public Vote(int id, int candidateId) {
            this.id = id;
            this.candidateId = candidateId;
        }
    }

    public String winningCandidate(
            List<Candidate> candidates,
            List<Vote> votes) {
        Map<Integer, Integer> counts = new HashMap<>();
        for (Vote vote : votes) {
            counts.merge(vote.candidateId, 1, Integer::sum);
        }

        int winnerId = counts.entrySet().stream()
                .max(Map.Entry.comparingByValue())
                .orElseThrow(() -> new IllegalArgumentException("No votes"))
                .getKey();

        return candidates.stream()
                .filter(candidate -> candidate.id == winnerId)
                .map(candidate -> candidate.name)
                .findFirst()
                .orElseThrow(() -> new IllegalArgumentException("Unknown candidate"));
    }
}
JavaScript本地语义参考
/**
 * @param {{id: number, name: string}[]} candidates
 * @param {{id: number, candidateId: number}[]} votes
 * @return {string}
 */
function winningCandidate(candidates, votes) {
  const counts = new Map();

  for (const vote of votes) {
    const current = counts.get(vote.candidateId) ?? 0;
    counts.set(vote.candidateId, current + 1);
  }

  let winnerId = null;
  let maxVotes = -1;
  for (const [candidateId, count] of counts) {
    if (count > maxVotes) {
      maxVotes = count;
      winnerId = candidateId;
    }
  }

  if (winnerId === null) throw new Error("No votes");
  const winner = candidates.find(({ id }) => id === winnerId);
  if (!winner) throw new Error("Unknown candidate");
  return winner.name;
}
Python本地语义参考
from collections import Counter
from typing import TypedDict


class Candidate(TypedDict):
    id: int
    name: str


class Vote(TypedDict):
    id: int
    candidateId: int


def winning_candidate(
    candidates: list[Candidate],
    votes: list[Vote],
) -> str:
    counts = Counter(vote["candidateId"] for vote in votes)
    if not counts:
        raise ValueError("No votes")

    winner_id, _ = max(counts.items(), key=lambda item: item[1])
    names = {candidate["id"]: candidate["name"] for candidate in candidates}

    if winner_id not in names:
        raise ValueError("Unknown candidate")
    return names[winner_id]
C++本地语义参考
#include <stdexcept>
#include <string>
#include <unordered_map>
#include <vector>

struct Candidate {
    int id;
    std::string name;
};

struct Vote {
    int id;
    int candidateId;
};

class Solution {
public:
    std::string winningCandidate(
            const std::vector<Candidate>& candidates,
            const std::vector<Vote>& votes) {
        std::unordered_map<int, int> counts;
        for (const Vote& vote : votes) {
            ++counts[vote.candidateId];
        }
        if (counts.empty()) throw std::invalid_argument("No votes");

        int winnerId = -1;
        int maxVotes = -1;
        for (const auto& [candidateId, count] : counts) {
            if (count > maxVotes) {
                winnerId = candidateId;
                maxVotes = count;
            }
        }

        for (const Candidate& candidate : candidates) {
            if (candidate.id == winnerId) return candidate.name;
        }
        throw std::invalid_argument("Unknown candidate");
    }
};

Interview room

面试追问与常见错误

面试追问

  • 如果允许并列第一，如何返回所有获胜者？
  • 如果需要展示所有候选人的票数，包括零票者，查询怎么改？
  • 在千万级选票表上，应该给哪些连接键或分组键建立索引？
  • MySQL 8 中如何用窗口函数写出可读性更强的版本？

常见错误

  • 只按姓名分组：不同候选人可能同名，应至少按唯一 id 分组。
  • 先 LIMIT 1 再排序：会在错误的数据范围内选结果。
  • 左连接后使用 COUNT(*)：零票候选人会被占位行误计。
  • 把 Vote.id 当候选人编号：正确外键是 candidateId。
  • 忽略唯一胜者保证，随意添加按姓名的次级排序，掩盖了业务并列规则。
