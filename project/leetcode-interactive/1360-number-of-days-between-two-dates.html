04 / 完整题解

把日期映射成唯一序号

核心洞察

分别计算两个日期从公历起点到当天的累计天数。日期一旦被映射到同一条整数轴，答案就是两个序号之差的绝对值。

完整过程

  1. 从字符串中解析年、月、日。
  2. 累加目标年份之前所有完整年份的天数。
  3. 累加目标月份之前所有完整月份的天数；闰年的二月多一天。
  4. 加上日，再对两个累计值作差并取绝对值。

正确性说明

完整年份之和恰好覆盖起点至目标年元旦前的每一天；完整月份之和继续覆盖到目标月月初前；最后加上日数后，每个有效日期都得到严格递增且唯一的序号。因此，两个序号间整数单位的数量恰好等于两个日期之间的天数，取绝对值可消除输入顺序影响。

边界

  • 相同日期：两个序号相等，结果为 0。
  • 跨月、跨年：统一由累计序号处理。
  • 闰年：能被 400 整除，或能被 4 整除但不能被 100 整除。
  • 2100 年能被 100 整除但不能被 400 整除，因此不是闰年。

复杂度与替代方案

按年份循环时，时间复杂度为 O(Y)，其中 Y ≤ 130；按公式直接计算完整年份时为 O(1)。两者额外空间均为 O(1)。

替代方案包括使用语言日期库，或从较早日期逐天推进。日期库写法短，但可能受到时区、夏令时和解析语义影响；逐天模拟直观，但不如序号法简洁稳定。

四种语言完整实现

均使用纯整数公历计算，不依赖本地时区。

Java
class Solution {
    public int daysBetweenDates(String date1, String date2) {
        return Math.abs(toSerial(date1) - toSerial(date2));
    }

    private int toSerial(String date) {
        int year = Integer.parseInt(date.substring(0, 4));
        int month = Integer.parseInt(date.substring(5, 7));
        int day = Integer.parseInt(date.substring(8, 10));
        int previousYear = year - 1;
        int total = previousYear * 365
                + previousYear / 4
                - previousYear / 100
                + previousYear / 400;
        int[] monthDays = {
            31, 28, 31, 30, 31, 30,
            31, 31, 30, 31, 30, 31
        };
        for (int i = 0; i < month - 1; i++) {
            total += monthDays[i];
        }
        if (month > 2 && isLeap(year)) {
            total++;
        }
        return total + day;
    }

    private boolean isLeap(int year) {
        return year % 400 == 0
                || (year % 4 == 0 && year % 100 != 0);
    }
}

/**
 * @param {string} date1
 * @param {string} date2
 * @return {number}
 */
var daysBetweenDates = function(date1, date2) {
    const isLeap = (year) =>
        year % 400 === 0
        || (year % 4 === 0 && year % 100 !== 0);

    const toSerial = (date) => {
        const [year, month, day] = date.split("-").map(Number);
        const previousYear = year - 1;
        let total = previousYear * 365
            + Math.floor(previousYear / 4)
            - Math.floor(previousYear / 100)
            + Math.floor(previousYear / 400);
        const monthDays = [
            31, 28, 31, 30, 31, 30,
            31, 31, 30, 31, 30, 31
        ];
        for (let i = 0; i < month - 1; i++) {
            total += monthDays[i];
        }
        if (month > 2 && isLeap(year)) total++;
        return total + day;
    };

    return Math.abs(toSerial(date1) - toSerial(date2));
};

class Solution:
    def daysBetweenDates(self, date1: str, date2: str) -> int:
        return abs(self.to_serial(date1) - self.to_serial(date2))

    def to_serial(self, date: str) -> int:
        year, month, day = map(int, date.split("-"))
        previous_year = year - 1
        total = (
            previous_year * 365
            + previous_year // 4
            - previous_year // 100
            + previous_year // 400
        )
        month_days = [
            31, 28, 31, 30, 31, 30,
            31, 31, 30, 31, 30, 31,
        ]
        total += sum(month_days[:month - 1])
        if month > 2 and self.is_leap(year):
            total += 1
        return total + day

    def is_leap(self, year: int) -> bool:
        return year % 400 == 0 or (
            year % 4 == 0 and year % 100 != 0
        )

    int toSerial(const string& date) {
        int year = stoi(date.substr(0, 4));
        int month = stoi(date.substr(5, 2));
        int day = stoi(date.substr(8, 2));
        int previousYear = year - 1;
        int total = previousYear * 365
                  + previousYear / 4
                  - previousYear / 100
                  + previousYear / 400;
        int monthDays[12] = {
            31, 28, 31, 30, 31, 30,
            31, 31, 30, 31, 30, 31
        };
        for (int i = 0; i < month - 1; ++i) {
            total += monthDays[i];
        }
        if (month > 2 && isLeap(year)) {
            ++total;
        }
        return total + day;
    }

    bool isLeap(int year) {
        return year % 400 == 0
            || (year % 4 == 0 && year % 100 != 0);

常见错误

  • 把“能被 4 整除”当作完整闰年规则，遗漏世纪年例外。
  • 月份数组下标偏移，或把当前月也计入完整月份。
  • 直接用毫秒差，却没有固定 UTC，遭遇时区或夏令时偏差。
  • 忘记取绝对值，导致逆序输入返回负数。
