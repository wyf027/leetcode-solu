列举单词的全部缩写 Generalized Abbreviation

一个单词、一组可替换的连续片段，以及所有可能的合法写法。先读清规则，再进入下方的“缩写轨道”亲手观察每次选择。

中等 会员题 回溯 字符串 位运算
w 1 r 2

01 / Problem

先定义什么是“合法缩写”

以下内容依据官方题名、函数元数据与公开题目信息转述；付费题面未作大段复制。

题意

给定一个只含小写英文字母的字符串 word，返回它的全部广义缩写，结果顺序不限。你可以把任意若干段连续字符替换为各自的长度数字。

  • 一段连续被替换的字符必须合并为一个数字。
  • 数字表示它代替了多少个原字符，不允许出现前导零。
  • 每个原字符都可选择保留或被缩写，因此长度为 n 时共有 2n 个结果。
  • 例如 word 中把 wo 替换后得到 2rd；全部替换得到 4。

官方函数形式

generateAbbreviations(word: string) → list<string>

示例 1

输入：word = "word"
输出：["4","3d","2r1","2rd","1o2","1o1d","1or1","1ord",
      "w3","w2d","w1r1","w1rd","wo2","wo1d","wor1","word"]
解释：共 2⁴ = 16 种；返回顺序可以不同。

示例 2

输入：word = "a"
输出：["1","a"]

约束与辨析

  • 1 <= word.length <= 15
  • word 仅由小写英文字母组成。
  • "1111" 不是 "word" 全部缩写后的合法表达；相邻计数应合并为 "4"。
  • 原单词本身也是一个合法结果。

注意：数字可能超过一位，例如长度为 15 的连续片段写成 15，而不是两个独立计数。

      准备好再揭开题解

      Complete Walkthrough

      回溯 + 延迟写入连续计数

      真正需要维护的不是“上一位是否缩写”，而是有多少个连续被缩写的字符还没有写进答案。

      核心洞察

      每位恰好二选一

      保留当前字符，或让它加入正在累计的缩写段。

      计数延迟落盘

      只有遇到保留字符或到达末尾时，才把连续计数写入路径。

      路径天然合法

      连续被缩写的字符始终合并为一个整数，不会生成相邻数字段。

      完整过程

      1. 状态使用 index、pending 和 path：当前下标、尚未写入的连续计数、已经确定的输出。
      2. 缩写当前字符：不修改 path，递归到 index + 1，并令 pending + 1。
      3. 保留当前字符：先把非零 pending 写进路径，再写当前字符，然后以计数 0 递归。
      4. 当 index == word.length，把剩余的非零计数追加到路径并收集结果。
      5. 若语言使用可变缓冲区，返回上一层前恢复原长度，继续探索另一条分支。

      正确性证明

      对单词的每个位置，递归恰好枚举“缩写”和“保留”两个互斥选择。因此，每条根到叶的路径与一个长度为 n 的二进制选择序列一一对应，所有选择序列都会被访问，不漏解；不同选择序列至少在一个原字符是否保留上不同，也不会产生重复结果。

      pending 始终等于当前路径末尾尚未写出的连续缩写字符数。保留字符前或递归结束时才写入它，所以每段连续缩写都被合并为一个无前导零的正整数。故每个生成结果合法，且全部合法结果均被生成。

      复杂度

      时间 O(n · 2ⁿ)

      有 2n 个结果，构造/复制每个最长需要 O(n) 时间。

      辅助空间 O(n)

      递归深度与路径缓冲区均为 O(n)；不计最终答案所占空间。

      边界情况

      • 单字符："a" 生成 "1" 与 "a"。
      • 全部保留：结果包含原单词本身。
      • 全部缩写：结果为原单词长度，例如 "word" → "4"。
      • 递归在缩写分支结束：必须追加剩余计数，否则会丢失末尾缩写段。
      • 计数达到两位数：应整体追加，例如连续 12 个字符缩写为 "12"。

      四语言完整代码

      Java · LeetCode 可提交形式

      import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generateAbbreviations(String word) {
        List<String> answer = new ArrayList<>();
        StringBuilder path = new StringBuilder();
        dfs(word, 0, 0, path, answer);
        return answer;
    }

    private void dfs(
            String word,
            int index,
            int pending,
            StringBuilder path,
            List<String> answer) {
        int oldLength = path.length();

        if (index == word.length()) {
            if (pending > 0) {
                path.append(pending);
            }
            answer.add(path.toString());
            path.setLength(oldLength);
            return;
        }

        // 选择 1：缩写当前字符，延迟写入连续计数。
        dfs(word, index + 1, pending + 1, path, answer);

        // 选择 2：保留当前字符，先刷新已有连续计数。
        if (pending > 0) {
            path.append(pending);
        }
        path.append(word.charAt(index));
        dfs(word, index + 1, 0, path, answer);
        path.setLength(oldLength);
    }
}

      JavaScript · LeetCode 可提交形式

      /**
 * @param {string} word
 * @return {string[]}
 */
var generateAbbreviations = function (word) {
    const answer = [];

    function dfs(index, pending, path) {
        if (index === word.length) {
            answer.push(path + (pending > 0 ? String(pending) : ""));
            return;
        }

        // 选择 1：缩写当前字符。
        dfs(index + 1, pending + 1, path);

        // 选择 2：保留当前字符。
        const countText = pending > 0 ? String(pending) : "";
        dfs(index + 1, 0, path + countText + word[index]);
    }

    dfs(0, 0, "");
    return answer;
};

      Python · LeetCode 可提交形式

      from typing import List


class Solution:
    def generateAbbreviations(self, word: str) -> List[str]:
        answer: List[str] = []

        def dfs(index: int, pending: int, path: str) -> None:
            if index == len(word):
                suffix = str(pending) if pending > 0 else ""
                answer.append(path + suffix)
                return

            # 选择 1：缩写当前字符。
            dfs(index + 1, pending + 1, path)

            # 选择 2：保留当前字符。
            count_text = str(pending) if pending > 0 else ""
            dfs(index + 1, 0, path + count_text + word[index])

        dfs(0, 0, "")
        return answer

      C++ · LeetCode 可提交形式

      #include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> generateAbbreviations(string word) {
        vector<string> answer;
        string path;
        dfs(word, 0, 0, path, answer);
        return answer;
    }

private:
    void dfs(
            const string& word,
            int index,
            int pending,
            string& path,
            vector<string>& answer) {
        const size_t oldLength = path.size();

        if (index == static_cast<int>(word.size())) {
            if (pending > 0) {
                path += to_string(pending);
            }
            answer.push_back(path);
            path.resize(oldLength);
            return;
        }

        // 选择 1：缩写当前字符。
        dfs(word, index + 1, pending + 1, path, answer);

        // 选择 2：保留当前字符。
        if (pending > 0) {
            path += to_string(pending);
        }
        path.push_back(word[index]);
        dfs(word, index + 1, 0, path, answer);
        path.resize(oldLength);
    }
};

      替代方案

      位掩码枚举

      用一个 n 位掩码表示每个字符“保留 / 缩写”，枚举 0 到 2^n - 1。扫描掩码时仍需累计连续缩写长度，并在遇到保留位时刷新计数。它避免递归，但构造规则与回溯本质相同。

      直接字符串拼接

      JavaScript、Python 可直接把新字符串传给下一层，代码更短且天然免回滚；代价是创建较多临时字符串。可变缓冲区则减少常数，但必须严格恢复长度。

      常见错误

      • 到终点忘记追加尚未写出的 pending。
      • 保留字符前没有先刷新计数，导致顺序错误。
      • 把连续缩写输出成多个数字，如 "11rd"。
      • 可变路径回溯后没有恢复原长度，污染兄弟分支。
      • 误把示例顺序当作必须满足的输出顺序。

      面试追问

      • 为什么恰好有 2n 个结果？ 每个位置独立选择保留或缩写，与二进制序列一一对应。
      • 可以不用递归吗？ 可以，用位掩码枚举所有选择，再线性扫描生成每个字符串。
      • 能否按字典序返回？ 可以在生成后排序，或设计分支顺序；排序会额外增加时间与空间开销。
      • 若输入允许数字怎么办？ 表达会产生歧义，需要转义、分隔符或更严格的编码规则；本题通过“小写字母”约束规避。
      • 怎样减少字符串复制？ 使用可变缓冲区并记录旧长度，在回溯时恢复。
