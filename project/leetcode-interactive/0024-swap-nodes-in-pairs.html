Problem brief

题意转述

给定单链表 head，把每两个相邻节点交换位置并返回新头节点。最后若只剩一个节点，保持原位。

硬性要求：不能修改节点中的值，只能改变节点连接。节点数 [0, 100]，节点值 [0, 100]。
可见字符：字符串空格统一写作 ␠；本题输入为链表数组，不含字符串空格。

Example 01

输入：head = [1,2,3,4]

输出：[2,1,4,3]

Example 02

输入：head = []

输出：[]

Example 03

输入：head = [1]

输出：[1]

Example 04

输入：head = [1,2,3]

输出：[2,1,3]

Solution backstage

题解只在需要时登场

先跟着舞谱完成一次三步换位，再展开洞察、复杂度、追问与四语言代码。

Core insight

dummy 统一头部，prev 统一每一对

头两个节点交换后，链表头会变化。用 dummy.next = head，就能把头部也当作普通的“前驱接回”处理。

每轮取 first = prev.next、second = first.next，严格按三次赋值换位，最后令 prev = first。

换位后 first 落在这一对的后面，恰好成为下一对之前的前驱。

Three assignments

first.next = second.next

second.next = first

prev.next = second

顺序不能乱：先保住 second 后面的链，再回指 first，最后让前驱接入新头。

Process

完整过程

  1. 创建 dummy，令 dummy.next = head。
  2. 只要 prev 后至少还有两个节点就继续。
  3. 保存 first、second，执行三次指针赋值。
  4. 把 prev 移到 first，处理下一对。
  5. 返回 dummy.next。

Edges

边界情况

  • 空链表：循环不进入，返回 null。
  • 单节点：没有完整一对，保持原样。
  • 奇数节点：最后一个节点不动。
  • 重复值：交换的是节点身份，不是值。

Complexity

复杂度

每个节点至多访问常数次。

时间 O(n)

辅助空间 O(1)

替代方案

递归可以先交换后续链表，再把当前两节点反接，代码更短但需要 O(n) 调用栈。面试主线推荐迭代法，空间严格为 O(1)，指针边界也更可控。

面试高频追问

  • 为什么要 dummy？统一头节点变化与普通分组接回。
  • prev 为什么移到 first？first 换位后是当前组尾。
  • 能扩展到 k 组翻转吗？可以，演变为第 25 题。

常见错误

  • 修改 val，违反题目要求。
  • 先写 second.next，导致丢失后续链。
  • 循环条件只检查一个后继，奇数尾部空指针。
  • 换位后把 prev 移到 second，下一轮位置错误。

class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummy = new ListNode(0, head);
        ListNode prev = dummy;

        while (prev.next != null && prev.next.next != null) {
            ListNode first = prev.next;
            ListNode second = first.next;

            first.next = second.next;
            second.next = first;
            prev.next = second;

            prev = first;
        }
        return dummy.next;
    }
}
