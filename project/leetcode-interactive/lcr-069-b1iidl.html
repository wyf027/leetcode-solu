山脉数组的峰顶索引

递增后递减的山脉数组中，用斜率方向以对数时间找到唯一峰顶。

开始演示

题意

山脉数组先严格递增后严格递减。返回峰顶元素所在下标。

示例

输入：arr = [0,2,5,3,1]
输出：2

约束

  • 3 <= arr.length <= 105
  • 存在唯一峰顶。

核心洞察

若 arr[mid] < arr[mid+1]，mid 位于上坡，峰顶必在右侧；否则位于下坡或峰顶，峰顶在 mid 或左侧。

区间：始终保留包含峰顶的闭区间 [left, right]。

分步交互

完整过程

  1. 设 left=0，right=n-1。
  2. 取 mid，比较 arr[mid] 与 arr[mid+1]。
  3. 上坡则 left=mid+1，否则 right=mid。
  4. 左右相遇时即为峰顶。

边界

  • 循环使用 left < right，保证 mid+1 合法。
  • 不可按最大值线性扫描，否则不满足对数要求。

复杂度

时间 O(log n)，空间 O(1)。

替代方案

线性扫描可找最大值，时间 O(n)，适合作为直观基线但不利用山脉性质。

官方签名代码

class Solution { public int peakIndexInMountainArray(int[] arr) { int l=0,r=arr.length-1; while(l<r){int m=l+(r-l)/2; if(arr[m]<arr[m+1]) l=m+1; else r=m;} return l; } }
var peakIndexInMountainArray = function(arr) { let l=0,r=arr.length-1; while(l<r){const m=l+Math.floor((r-l)/2); if(arr[m]<arr[m+1])l=m+1;else r=m;} return l; };
class Solution:
    def peakIndexInMountainArray(self, arr: List[int]) -> int:
        l, r = 0, len(arr)-1
        while l < r:
            m = (l+r)//2
            if arr[m] < arr[m+1]: l = m+1
            else: r = m
        return l

追问与常见错误

追问：含平台如何处理？需重新定义峰顶。常见错误：mid+1 越界、更新 right 为 mid-1 导致跳过峰顶、将二分条件写反。

测试与验证区

建议覆盖峰顶靠近两端、最短数组和很长数组。
