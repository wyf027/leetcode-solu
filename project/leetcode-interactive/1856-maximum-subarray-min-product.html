1856. 子数组最小乘积的最大值

Maximum Subarray Min-Product

在一个连续区间里，让「最小值 × 元素和」尽可能大。

正整数数组连续子数组先求最大，再取余
01 / PROBLEM

题目与约定

给定正整数数组 nums，从中选择一段非空且连续的子数组。该区间的最小乘积等于区间最小元素乘以区间元素总和。请返回所有候选区间中最大最小乘积对 1,000,000,007 取余的结果。

例如，[3,2,5] 的最小乘积为 2 × (3+2+5) = 20。输入参数只有 nums；函数名为 maxSumMinProduct，返回整数。

比较大小时必须使用取余前的乘积。题目保证最终的最大原始乘积可由 64 位有符号整数表示。

  • 1 ≤ nums.length ≤ 100,000
  • 1 ≤ nums[i] ≤ 10,000,000

04 / EXPLAINER

先独立思考，再展开题解

展开后可查看交互演示、推导与四种语言代码。

核心洞察：固定最小值，尽量扩张

所有数都大于零。固定最小值 nums[j] 后，只要新加入的数不小于它，扩张区间就会增加总和，乘积也随之增加。因此，问题变成：为每个最小值找到可负责的最长区间，再快速计算区间和。

用前缀和计算区间总和，用单调递增栈维护还未确定右边界的下标。下面采用遇到小于或等于栈顶的数就弹栈的规则；同值区间最终交给最右侧的相等元素负责。

完整过程

  1. 建立前缀和：P[0]=0，P[i+1]=P[i]+nums[i]。
  2. 从左向右扫描 i=0…n，在 i=n 时使用虚拟值 0，确保正数全部出栈。
  3. 当栈非空且栈顶值 ≥ 当前值，弹出下标 j。新栈顶记为 k；若空则 k=-1。
  4. 结算闭区间 [k+1, i-1]：总和为 P[i]-P[k+1]，乘积为 nums[j] × 总和，更新原始最大值。
  5. 若 i<n 则压入 i。扫描完成后，仅对最大值取模。

示例 [3,1,5,6,4,2]：扫描到 4 时，先结算 6 的单点区间，再结算以 5 为最小值的 [5,6]，得到 55；扫描到 2 时，结算以 4 为最小值的 [5,6,4]，得到 60。

正确性说明

1. 每次结算都是合法候选

栈中的下标递增、对应值严格递增。弹出 j 后的新栈顶 k 是左侧最近的严格更小值；i 是右侧首个小于等于 nums[j] 的位置。在开区间 (k,i) 内的所有值都不小于 nums[j]，且包含 j，所以计算出的最小值与区间和均正确。

2. 最优区间一定被覆盖

任选最优区间，并取其中最右侧的最小值位置 j。区间内部 j 右侧没有相等或更小的值，左侧没有严格更小的值。因此 j 被结算时的负责区间一定包含该最优区间。所有元素为正，扩张后总和不会变小，且最小值不变，所得乘积不会更小。

3. 取最大得到全局最优

每个结算值来自合法子数组，又至少有一个结算值不小于最优答案，所以最大结算值恰为全局最优值。最后取余符合题意。

边界、复杂度与常见错误

  • 重复值：使用 ≥ 弹栈时，左边界严格更小，右边界小于等于；较早同值元素可能只结算部分区间，最右同值元素会覆盖完整区间。
  • 递增数组：依赖末尾虚拟 0 清空栈；单元素自然返回该元素的平方。
  • 前缀和下标：闭区间 [L,R] 的和是 P[R+1]−P[L]；本算法 L=k+1、R=i−1。
  • 整数精度：前缀和最多 10¹²；乘积可能超出 JavaScript 的安全整数范围。Java/C++ 用 64 位整数，JavaScript 用 BigInt，Python 整数自动扩展。
  • 错误取模：不能逐个取模再比较大小；取模不保序。
  • 不是直方图面积：应乘区间和，不能乘区间长度。

时间 O(n)，空间 O(n)：每个下标只入栈、出栈各一次，前缀和与栈各占线性空间。复杂度按题目 64 位数值范围下的整数运算计；交互演示为可回退而保存快照，不是提交代码的空间实现。

替代方案与面试追问

暴力枚举：固定左端点，右移时增量维护和与最小值，时间 O(n²)、额外空间 O(1)，适合小规模推演，无法满足 10⁵ 的输入规模。

左右边界两遍栈：分别求边界，再用前缀和计算，同样 O(n)，但需要额外边界数组。相等值的归属规则必须一致。

按值降序激活 + 并查集：把相邻已激活位置合并并维护分量总和，按当前阈值计算乘积，排序使总时间为 O(n log n)，实现复杂度更高。

如果允许负数？

正数带来的“扩张必然增大乘积”不再成立，本证明和算法不能直接沿用，需要重新分析区间和的极值。

如果改用严格大于弹栈？

也可行：栈值非递减，左边界变为小于等于，右边界严格更小，相等值区间交由更左侧的元素负责，代码与证明必须一起调整。

如何返回区间？

更新 best 时一并记录 L=k+1、R=i−1；如有多个最优区间，应先约定长度或字典序等平局规则。

Java

class Solution {
    public int maxSumMinProduct(int[] nums) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        int[] stack = new int[n];
        int size = 0;
        long best = 0;
        for (int i = 0; i <= n; i++) {
            int current = i == n ? 0 : nums[i];
            while (size > 0 && nums[stack[size - 1]] >= current) {
                int j = stack[--size];
                int left = size == 0 ? 0 : stack[size - 1] + 1;
                long sum = prefix[i] - prefix[left];
                best = Math.max(best, sum * nums[j]);
            }
            if (i < n) stack[size++] = i;
        }
        return (int) (best % 1_000_000_007L);
    }
}

var maxSumMinProduct = function(nums) {
    const n = nums.length;
    const prefix = Array(n + 1).fill(0n);
    for (let i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + BigInt(nums[i]);
    }
    const stack = [];
    let best = 0n;
    for (let i = 0; i <= n; i++) {
        const current = i === n ? 0 : nums[i];
        while (stack.length && nums[stack[stack.length - 1]] >= current) {
            const j = stack.pop();
            const left = stack.length ? stack[stack.length - 1] + 1 : 0;
            const product = (prefix[i] - prefix[left]) * BigInt(nums[j]);
            if (product > best) best = product;
        }
        if (i < n) stack.push(i);
    }
    return Number(best % 1000000007n);
};

from typing import List

class Solution:
    def maxSumMinProduct(self, nums: List[int]) -> int:
        n = len(nums)
        prefix = [0] * (n + 1)
        for i, value in enumerate(nums):
            prefix[i + 1] = prefix[i] + value
        stack = []
        best = 0
        for i in range(n + 1):
            current = 0 if i == n else nums[i]
            while stack and nums[stack[-1]] >= current:
                j = stack.pop()
                left = stack[-1] + 1 if stack else 0
                total = prefix[i] - prefix[left]
                best = max(best, total * nums[j])
            if i < n:
                stack.append(i)
        return best % 1_000_000_007

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maxSumMinProduct(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        vector<long long> prefix(n + 1, 0);
        for (int i = 0; i < n; ++i) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        vector<int> stack;
        long long best = 0;
        for (int i = 0; i <= n; ++i) {
            int current = i == n ? 0 : nums[i];
            while (!stack.empty() && nums[stack.back()] >= current) {
                int j = stack.back();
                stack.pop_back();
                int left = stack.empty() ? 0 : stack.back() + 1;
                long long sum = prefix[i] - prefix[left];
                best = max(best, sum * nums[j]);
            }
            if (i < n) stack.push_back(i);
        }
        return static_cast<int>(best % 1000000007LL);
    }
};
