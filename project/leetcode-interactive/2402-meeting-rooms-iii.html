会议室 III

房间有限，会议接踵而至。谁需要等待，谁先获得房间，最终哪个房间最忙？

半开区间 [start, end)延期不改变时长编号优先

01 / 读懂规则

给每场会议一个房间

给定整数 n 和二维整数数组 meetings。房间编号为 0 … n−1，每个 meetings[i] = [startᵢ, endᵢ] 表示原计划在 [startᵢ, endᵢ) 举办的会议；所有原开始时间互不相同。

  1. 有空闲房间时，使用其中编号最小的房间。
  2. 全被占用时，会议推迟到有房间可用为止；会议时长仍为 endᵢ − startᵢ。
  3. 多场会议等待时，原开始时间更早的会议优先安排。

返回承办会议次数最多的房间编号；次数相同取编号更小的房间。区间包含起点、不包含终点，因此在时间 t 结束的房间可立即接待时间 t 开始的会议。

约束

  • 1 ≤ n ≤ 100
  • 1 ≤ meetings.length ≤ 10⁵
  • meetings[i].length = 2
  • 0 ≤ startᵢ < endᵢ ≤ 5 × 10⁵
  • 所有 startᵢ 互不相同。

接口：mostBooked(n, meetings) → integer · 官方题目

示例 1

输入：n = 2, meetings = [[0,10],[1,5],[2,7],[3,4]]
输出：0

前两场分别进入房间 0、1。第三场等到时间 5，在房间 1 举办 [5,10)；第四场等到时间 10，两个房间同时可用，选择房间 0，举办 [10,11)。两间各承办 2 场，答案为 0。

示例 2

输入：n = 3, meetings = [[1,20],[2,10],[3,5],[4,9],[6,8]]
输出：1

前三场分别进入房间 0、1、2。第四场在房间 2 延期至 [5,10)；第五场在时间 10 遇到房间 1、2 同时可用，选择房间 1，举办 [10,12)。次数为 [1,2,2]，答案为 1。

04 / 独立题解

先想清楚，再揭开实现

尝试解释：为什么“最早结束”和“最小编号”是两种不同的优先关系？

双最小堆：让两种优先级各司其职

核心洞察

按原开始时间排序后，当前会议永远比后续会议更早获得安排权。无需显式维护等待会议队列，只要记录每间房的最新预订结束时间，就能直接把当前会议安排到未来。空闲堆只按编号排序；占用堆按 (实际结束时间, 房间编号) 字典序排序。

完整过程

  1. 按 start 升序排列会议。将全部房间编号加入空闲最小堆，计数清零。
  2. 对当前会议 [s,e)，把占用堆中结束时间 ≤ s 的房间全部释放到空闲堆。
  3. 空闲堆非空：弹出最小编号，实际结束时间为 e。
  4. 否则从占用堆取出 (t,r)，把会议安排在 [t,t+e−s)。并列结束时自动取最小编号。
  5. 将新的 (finish,r) 放回占用堆，令 count[r]++。
  6. 从小到大扫描计数，只在次数严格更大时更新答案。

示例 1 的关键：第三场持续 5 个时间单位，延期后必须是 [5,10)，而不是 [5,7)。第四场遇到两个房间在时间 10 同时结束，选择编号 0。

正确性：维护已安排前缀

不变式：处理每场会议前，已处理会议的安排符合规则；每间房恰在一个堆中，占用堆记录该房间全部已安排会议之后的最新结束时间，计数等于已安排场次。

释放所有结束时间不大于 s 的记录后，空闲堆恰好包含当前会议原开始时可用的房间。选择其最小编号符合空闲分配规则；若堆为空，最小结束时间 t 就是最早可安排时间，第二关键字保证同一时刻选择最小编号。追加原持续时长保持会议长度。

所有更早原开始的会议已被安排，当前预订不会抢走它们的位置；后续会议也无法越过当前会议。因此每步保持不变式，由归纳得到所有安排正确。最后按次数取最大、并列保留较小编号，得到要求的房间。

边界与数值范围

  • 只有一个房间时，延期会连续累积；不能将结束时间限制在输入的 500000 内。
  • 累计时间保守上界约 5×10¹⁰：Java 用 long，C++ 用 long long，Python 整数自动扩展，JavaScript 的 Number 在此范围可精确表示整数。
  • 结束时间恰好等于开始时间也必须释放；条件为 ≤。
  • 同时空闲取编号最小，而非“最早变空闲”的房间。
  • 四份代码均原地排序输入；若调用方要保留顺序，应先复制 meetings。

复杂度

令 m = meetings.length。排序耗时 O(m log m)，堆初始化 O(n log(n+1))，每场会议产生常数次插入、弹出；释放循环总共弹出至多 m 条记录。总时间为 O(m log m + (m+n) log(n+1))。两个堆合计保存 n 个房间，计数为 n，调度结构空间 O(n)；另加语言排序实现的工作空间（Python/Java/JS 通常可达 O(m)，C++ std::sort 通常 O(log m) 栈）。

替代方案

为每个房间保存下一次可用时间：每场会议扫描所有 n 间房，先选所有可用房间中编号最小的，否则取可用时间最早且编号最小的。时间 O(m log m + mn)、状态空间 O(n)。n ≤ 100 时这是易写的方案；双堆在房间数较大时更适合。不应逐秒推进时间，延期后的时间跨度可能很大。

常见错误

  • 只释放一个结束的房间，忽略更小编号已经空闲。
  • 占用堆只比较结束时间，遗漏编号的次级排序。
  • 延期时沿用原 end，意外缩短会议。
  • 按结束时间排序会议，破坏原开始时间的等待优先级。
  • 答案用 ≥ 更新，导致并列时返回更大编号。
  • 用 32 位整数保存累计结束时间。

面试追问

允许相同开始时间？先明确同时到达的优先规则，再加入会议编号等稳定关键字。
需要输出完整安排？在每次分配时记录会议原索引、房间、实际起止时间，增加 O(m) 空间。
允许取消或变更会议？单纯追加预订不再够用，需要重新定义重排规则，并考虑版本号惰性删除或可修改的日程结构。

Java

import java.util.*;

class Solution {
    public int mostBooked(int n, int[][] meetings) {
        Arrays.sort(meetings, Comparator.comparingInt(a -> a[0]));
        PriorityQueue<Integer> free = new PriorityQueue<>();
        PriorityQueue<long[]> busy = new PriorityQueue<>((a, b) -> {
            int c = Long.compare(a[0], b[0]);
            return c != 0 ? c : Long.compare(a[1], b[1]);
        });
        for (int r = 0; r < n; r++) free.offer(r);
        int[] count = new int[n];
        for (int[] meeting : meetings) {
            long start = meeting[0], end = meeting[1];
            while (!busy.isEmpty() && busy.peek()[0] <= start)
                free.offer((int) busy.poll()[1]);
            int room;
            if (!free.isEmpty()) {
                room = free.poll();
            } else {
                long[] first = busy.poll();
                room = (int) first[1];
                end = first[0] + (end - start);
            }
            busy.offer(new long[]{end, room});
            count[room]++;
        }
        int answer = 0;
        for (int r = 1; r < n; r++)
            if (count[r] > count[answer]) answer = r;
        return answer;
    }
}

JavaScript

// 自包含二叉最小堆，无需平台额外依赖。
class MinHeap {
    constructor(less) { this.a = []; this.less = less; }
    get size() { return this.a.length; }
    peek() { return this.a[0]; }
    push(value) {
        const a = this.a;
        a.push(value);
        let i = a.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (!this.less(a[i], a[p])) break;
            [a[i], a[p]] = [a[p], a[i]];
            i = p;
        }
    }
    pop() {
        const a = this.a, root = a[0], last = a.pop();
        if (a.length) {
            a[0] = last;
            let i = 0;
            while (true) {
                let child = i * 2 + 1;
                if (child >= a.length) break;
                if (child + 1 < a.length && this.less(a[child + 1], a[child])) child++;
                if (!this.less(a[child], a[i])) break;
                [a[i], a[child]] = [a[child], a[i]];
                i = child;
            }
        }
        return root;
    }
}

/** @param {number} n @param {number[][]} meetings @return {number} */
var mostBooked = function(n, meetings) {
    meetings.sort((a, b) => a[0] - b[0]);
    const free = new MinHeap((a, b) => a < b);
    const busy = new MinHeap((a, b) => a[0] < b[0] || (a[0] === b[0] && a[1] < b[1]));
    const count = Array(n).fill(0);
    for (let r = 0; r < n; r++) free.push(r);
    for (const [start, end] of meetings) {
        while (busy.size && busy.peek()[0] <= start) free.push(busy.pop()[1]);
        let room, finish = end;
        if (free.size) room = free.pop();
        else {
            const [time, r] = busy.pop();
            room = r;
            finish = time + end - start;
        }
        busy.push([finish, room]);
        count[room]++;
    }
    let answer = 0;
    for (let r = 1; r < n; r++) if (count[r] > count[answer]) answer = r;
    return answer;
};

Python

from typing import List
import heapq

class Solution:
    def mostBooked(self, n: int, meetings: List[List[int]]) -> int:
        meetings.sort()
        free = list(range(n))
        heapq.heapify(free)
        busy = []  # (实际结束时间, 房间编号)
        count = [0] * n
        for start, end in meetings:
            while busy and busy[0][0] <= start:
                _, room = heapq.heappop(busy)
                heapq.heappush(free, room)
            if free:
                room = heapq.heappop(free)
                finish = end
            else:
                time, room = heapq.heappop(busy)
                finish = time + end - start
            heapq.heappush(busy, (finish, room))
            count[room] += 1
        return max(range(n), key=lambda room: count[room])

C++

#include <algorithm>
#include <functional>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int mostBooked(int n, vector<vector<int>>& meetings) {
        sort(meetings.begin(), meetings.end());
        priority_queue<int, vector<int>, greater<int>> free;
        using Entry = pair<long long, int>;
        priority_queue<Entry, vector<Entry>, greater<Entry>> busy;
        vector<int> count(n, 0);
        for (int r = 0; r < n; ++r) free.push(r);
        for (const auto& meeting : meetings) {
            long long start = meeting[0], end = meeting[1];
            while (!busy.empty() && busy.top().first <= start) {
                free.push(busy.top().second);
                busy.pop();
            }
            int room;
            if (!free.empty()) {
                room = free.top();
                free.pop();
            } else {
                auto [time, r] = busy.top();
                busy.pop();
                room = r;
                end = time + end - start;
            }
            busy.push({end, room});
            ++count[room];
        }
        return int(max_element(count.begin(), count.end()) - count.begin());
    }
};
