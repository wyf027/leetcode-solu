查询结果的
质量和占比

把每一行查询结果送进对应的分组桶：一边累计评分与位置的比值，一边数出低评分结果。最后，只需做两次除法。

quality = AVG(rating / position)
poor % = 100 × COUNT(rating < 3) / COUNT(*)
01

先读懂题目

这是一个典型的“按名称分组，再同时计算两个聚合指标”的问题。

题意转述

给定表 Queries，每一行记录查询名称、返回结果、结果出现的位置与评分。对每个 query_name 输出：

  • quality：该组所有 rating / position 的平均值；
  • poor_query_percentage：该组中 rating < 3 的行数占总行数的百分比。

两个指标均四舍五入到小数点后两位，结果行顺序任意。表中可能出现完全重复的行，因此不能擅自去重。

别忽略精度：必须使用小数除法；整数除法会在聚合之前丢失信息。

resultvarchar返回结果

ratingint评分，1～5

03

完整题解

核心只有一层分组，但类型转换、条件计数与舍入时机决定了答案是否可靠。

核心洞察

两项指标都只依赖同一组内的行，因此以 query_name 分组即可。AVG(rating / position) 直接得到质量；布尔表达式 rating < 3 在 MySQL 中可当作 1/0 求平均，再乘 100 得到百分比。

完整过程

  1. 使用 GROUP BY query_name 建立分组。
  2. 把评分转成小数后除以位置，并对比值求平均。
  3. 把“评分低于 3”映射为 1，否则为 0；求平均并乘 100。
  4. 分别用 ROUND(..., 2) 保留两位小数。

正确性说明

固定任意查询名 q。分组后，聚合函数恰好遍历所有且仅属于 q 的行。第一式累加每行的 rating / position 并除以行数，等于 quality 的定义。第二式只为低评分行贡献 1，其总和即低评分行数；除以该组行数并乘 100，正好是 poor query percentage。对每个分组均成立，因此输出正确。

边界情况

  • 一个分组只有一行：平均值就是该行贡献值。
  • 没有低评分：百分比为 0.00；全部低评分：为 100.00。
  • 重复行必须分别参与统计。
  • position ≥ 1，无需处理除零。
  • 不要先对单行比值舍入，应在聚合完成后统一舍入。

复杂度

设共有 n 行、k 个不同查询名。逻辑上扫描一次，时间复杂度 O(n)；哈希分组需要 O(k) 额外空间。数据库执行器可能按索引、哈希或排序完成聚合，实际计划依赖存储与统计信息。

替代方案

条件计数也可写成 SUM(CASE WHEN rating < 3 THEN 1 ELSE 0 END) * 100.0 / COUNT(*)，跨数据库更直观。Pandas 可使用 groupby 聚合；应用语言可用 Map 保存每组的比值和、总数与低评分数。

面试追问

  • 如何写成 PostgreSQL / SQL Server 可移植语法？
  • 如果 position 可能为 0 或 NULL，该如何防护？
  • 大表上应为哪些字段建索引，聚合是否一定使用它？
  • 若题目要求保留没有结果的查询名，应如何 LEFT JOIN？

常见错误

  • 写成 AVG(rating) / AVG(position)，这与“比值的平均”不同。
  • 发生整数除法，导致小于 1 的贡献全部变成 0。
  • 忘记乘 100，输出的是比例而不是百分比。
  • 使用 COUNT(rating < 3)；非 NULL 的 0 也会被计数。
  • 错误使用 DISTINCT 去除题目允许的重复行。

官方可提交语言：MySQL

SELECT
    query_name,
    ROUND(AVG(rating * 1.0 / position), 2) AS quality,
    ROUND(AVG(rating < 3) * 100, 2) AS poor_query_percentage
FROM Queries
GROUP BY query_name;

本题是数据库题，LeetCode 应提交上面的 SQL（或对应数据库方言）。以下 Java、JavaScript、Python、C++ 均是对“输入行数组做同等聚合”的完整本地语义参考，不是本题站内提交模板。

import java.util.*;

public class QueriesStats {
    public record Row(String queryName, String result, int position, int rating) {}
    public record Answer(String queryName, double quality, double poorPercentage) {}

    private static class Acc {
        double ratioSum;
        int count;
        int poor;
    }

    public static List<Answer> solve(List<Row> rows) {
        Map<String, Acc> groups = new LinkedHashMap<>();
        for (Row row : rows) {
            Acc acc = groups.computeIfAbsent(row.queryName(), key -> new Acc());
            acc.ratioSum += (double) row.rating() / row.position();
            acc.count++;
            if (row.rating() < 3) acc.poor++;
        }

        List<Answer> result = new ArrayList<>();
        for (Map.Entry<String, Acc> entry : groups.entrySet()) {
            Acc acc = entry.getValue();
            result.add(new Answer(
                entry.getKey(),
                round2(acc.ratioSum / acc.count),
                round2(100.0 * acc.poor / acc.count)
            ));
        }
        return result;
    }

    private static double round2(double value) {
        return Math.round(value * 100.0) / 100.0;
    }
}
function queriesStats(rows) {
  const groups = new Map();

  for (const row of rows) {
    const acc = groups.get(row.query_name) ?? { ratioSum: 0, count: 0, poor: 0 };
    acc.ratioSum += row.rating / row.position;
    acc.count += 1;
    if (row.rating < 3) acc.poor += 1;
    groups.set(row.query_name, acc);
  }

  return [...groups].map(([query_name, acc]) => ({
    query_name,
    quality: round2(acc.ratioSum / acc.count),
    poor_query_percentage: round2((acc.poor * 100) / acc.count),
  }));
}

function round2(value) {
  return Math.round((value + Number.EPSILON) * 100) / 100;
}

vector<Answer> queriesStats(const vector<Row>& rows) {
    unordered_map<string, Acc> groups;
    for (const Row& row : rows) {
        Acc& acc = groups[row.queryName];
        acc.ratioSum += static_cast<double>(row.rating) / row.position;
        ++acc.count;
        if (row.rating < 3) ++acc.poor;
    }

    vector<Answer> result;
    for (const auto& [name, acc] : groups) {
        result.push_back({
            name,
            round2(acc.ratioSum / acc.count),
            round2(100.0 * acc.poor / acc.count)
        });
    }
    return result;
}
