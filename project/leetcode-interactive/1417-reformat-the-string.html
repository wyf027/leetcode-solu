重新格式化字符串

Reformat The String · 把字母和数字排成一列严格交替的“车厢”。先判断数量是否允许，再让较多的一类先发车。

两类字符小写字母 / 数字
相邻异类字母与数字必须轮流出现
差值至多 1否则较多的一类无法被隔开

题目说明

给定一个只包含小写英文字母和数字的字符串 s。请重排其中的字符，使任意两个相邻字符类型不同：字母后接数字，数字后接字母。若无法做到，返回空字符串。满足条件的答案可能不唯一。

函数签名

reformat(s: string): string

输入字符必须全部保留且恰好使用一次；只允许改变顺序。

约束

  • 1 <= s.length <= 500
  • s 仅由小写英文字母和/或数字组成。

字母数字

先自己想一想

什么条件能保证两类字符可以严格交替？哪一类应该放在第一个位置？

题解：分组后交替合并

唯一真正的门槛是两类字符的数量差；顺序本身无需排序。

1. 分成两组

一次扫描，把小写字母放进 letters，数字放进 digits。

2. 判断可行

|L - D| ≤ 1

数量差大于 1 时，多出至少两个同类字符，无论如何都会相邻。

3. 较多者先放

若数量不等，让较多的一类占据下标 0、2、4…；另一类填入 1、3、5…。

完整过程

扫描字符串。按字符是否位于 '0'..'9' 将其放入数字组或字母组。
检查数量差。若 abs(letters.length - digits.length) > 1，直接返回空字符串。
决定起始类型。数量较多的组先放；相等时任一组先放均可。
交替取字符。每轮最多从首组、次组各取一个，直到所有字符均进入答案。

正确性证明

必要性：若两类数量差大于 1，较少的一类最多形成“数量 + 1”个间隔，无法容纳所有较多类字符，所以必有两个同类相邻。

充分性：若数量差至多 1，让数量较多（或任意等量）的一类先出现，并依次从两组各取一个。构造中每个相邻位置来自不同组；末尾至多多出首组的一个字符，仍与前一字符类型不同。因此所得排列合法，并使用全部字符。

复杂度

时间：O(n)，分类和合并各扫描一次。

空间：O(n)，两组与输出共保存线性数量字符。

边界情况

  • 长度为 1：原字符串直接合法。
  • 两组等长：字母或数字开头都可以。
  • 数量差恰为 1：必须由较多的一类开头和结尾。
  • 只有一种类型且长度大于 1：返回空串。

替代方案

按奇偶下标填充

先统计数量，再把较多一类写到偶数下标，另一类写到奇数下标。时间、空间复杂度相同，适合直接操作字符数组。

每步贪心选择类型

始终选择与上一个字符不同的类型。这里只有两类字符，因此最终仍归结为数量差判断；维护额外优先队列反而更复杂。

四语言完整代码

class Solution {
    public String reformat(String s) {
        StringBuilder letters = new StringBuilder();
        StringBuilder digits = new StringBuilder();

        for (char ch : s.toCharArray()) {
            if (Character.isDigit(ch)) {
                digits.append(ch);
            } else {
                letters.append(ch);
            }
        }

        if (Math.abs(letters.length() - digits.length()) > 1) {
            return "";
        }

        StringBuilder first = letters.length() >= digits.length()
                ? letters : digits;
        StringBuilder second = letters.length() >= digits.length()
                ? digits : letters;
        StringBuilder answer = new StringBuilder(s.length());

        for (int i = 0; i < first.length(); i++) {
            answer.append(first.charAt(i));
            if (i < second.length()) {
                answer.append(second.charAt(i));
            }
        }
        return answer.toString();
    }
}

var reformat = function (s) {
    const letters = [];
    const digits = [];

    for (const ch of s) {
        if (ch >= '0' && ch <= '9') {
            digits.push(ch);
        } else {
            letters.push(ch);
        }
    }

    if (Math.abs(letters.length - digits.length) > 1) {
        return '';
    }

    const first = letters.length >= digits.length ? letters : digits;
    const second = letters.length >= digits.length ? digits : letters;
    const answer = [];

    for (let i = 0; i < first.length; i++) {
        answer.push(first[i]);
        if (i < second.length) answer.push(second[i]);
    }
    return answer.join('');
};

面试追问

为什么差值不能超过 1？

较少类的每个字符只能分隔一对较多类字符。若多出两个及以上，至少有两个较多类字符无分隔地相邻。

能否原地完成？

在支持可变字符数组的语言里，可以先按类型收集，再写回原数组；仍需保存分组或使用双指针交换，通常空间分析取决于字符串可变性。

如果有三种字符类型？

条件推广为最大组大小不超过其余字符总数加 1。可用最大堆每次选择与上一步不同且剩余最多的类型。

答案需要字典序最小吗？

本题不要求。若增加该要求，需要分别排序两组，并在数量相等时比较两种起始类型形成的候选答案。

常见错误

  • 只判断两组是否都非空，却遗漏数量差大于 1 的情况。
  • 数量不等时仍让较少的一类开头，导致最后两个字符同类。
  • 用固定偶数位放字母，却没有根据哪一组更大来决定起始类型。
  • 误以为答案唯一，按字符串相等而不是“相邻异类且字符多重集一致”来判断。
