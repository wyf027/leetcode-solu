函数：sum(num1, num2) → integer · 约束：-100 ≤ num1, num2 ≤ 100。

输出：17

官方示例 2

输出：-6

04 / 独立题解

准备好了，再揭开实现。

核心洞察：一次整数加法

题目直接要求数学上的和，语言内置的 + 正好完成这一操作。无需数组、循环、递归或额外数据结构。

完整过程

  1. 接收两个整数参数 num1、num2。
  2. 计算表达式 num1 + num2。
  3. 将计算得到的整数直接返回。例如 -10 + 4 = -6。

为什么正确

对任意满足约束的输入 a、b，内置整数加法得到数学和 a + b。函数返回的恰好是这个值，与题目要求一致。结果落在 [-200, 200]，四种语言所用数值类型均能精确表示，因此没有溢出或精度损失。

边界与复杂度

负数、零、异号相加都由加法规则统一处理。返回值不能按输入范围截断：100 + 100 的合法结果是 200。

时间 O(1)，额外空间 O(1)：固定范围整数的一次加法与一次返回。数轴动画的步数只是教学设计，不是算法循环次数。

四语言完整提交代码

Java

class Solution {
    public int sum(int num1, int num2) {
        return num1 + num2;
    }
}

    return num1 + num2;

C++

public:

    }

替代方案

逐次加一或减一可以模拟加法，但需要 O(|num2|) 次更新（若扩大数值范围），没有收益。禁止使用加号时，可以研究“异或计算无进位和、按位与左移计算进位”，但负数与位宽处理更复杂，本题不需要。

面试追问

  • 输入扩大到任意大整数会怎样？应改用大整数；复杂度将随数字位数增长。
  • Java/C++ 可能溢出时怎么处理？根据新约束选择更宽的整数类型或大整数实现。
  • JavaScript 接收字符串怎么办？输入边界先验证并转换为数字；本题平台参数已经是数字。

常见错误

  • 把返回值打印出来却没有 return。
  • 从网页输入直接取字符串，导致 "12" + "5" 得到 "125"。
  • 对负数取绝对值，或把结果限制在 [-100, 100]。
  • 误当成“两数之和”题目，额外引入数组和目标值。
