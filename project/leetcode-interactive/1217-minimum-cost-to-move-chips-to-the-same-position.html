Minimum Cost to Move Chips to The Same Position

难度：简单函数：minCostToMoveChips返回：integer
01 / PROBLEM

题目

有 n 个筹码，第 i 个筹码位于 position[i]。目标是把所有筹码移动到同一个整数位置。

一次操作可把某个筹码移动 +2 或 -2，代价为 0；也可移动 +1 或 -1，代价为 1。

请返回完成聚拢所需的最小总代价。

参数与约束

输入
position: integer[]
输出
integer
  • 1 <= position.length <= 100
  • 1 <= position[i] <= 10^9
02 / EXAMPLES

官方示例

EXAMPLE 01
输入
position = [1,2,3]
输出
1

把 3 移到 1 的代价为 0，把 2 移到 1 的代价为 1，总代价为 1。

EXAMPLE 02
输入
position = [2,2,2,3,3]
输出
2

把位置 3 上的两个筹码分别移动到 2，每个代价为 1。

EXAMPLE 03
输入
position = [1,1000000000]
输出
1

位置很远也不代表代价很高；操作的计费规则才是关键。

05 / SOLUTION

准备好看题解了吗？

核心洞察、证明、复杂度与四种语言实现都收在这里。

CORE IDEA

只需要数奇偶

核心洞察

移动 2 格不会改变位置的奇偶性，而且完全免费。因此，所有奇数位置之间可以免费互达，所有偶数位置之间也可以免费互达。只有跨越奇偶性时才必须付出 1。

贪心选择

最终位置只可能选为“奇数类”或“偶数类”。选奇数时，每个偶数筹码付 1；选偶数时，每个奇数筹码付 1。取两类数量的较小值即可。

完整过程

1
遍历数组。

检查每个 position[i] 的奇偶性，累计奇数个数 odd 和偶数个数 even。

2
评估两个目标。

聚到任意奇数位置的成本是 even；聚到任意偶数位置的成本是 odd。

3
选择较小成本。

返回 min(odd, even)。

正确性证明

引理：同奇偶性的两个位置之差为偶数，可由若干次 ±2 免费移动到达；不同奇偶性的位置之间，任何路径都至少需要一次 ±1，且一次 ±1 后即可通过免费移动到达目标。

结论：若最终位置为奇数，恰好所有偶数筹码各付 1，总成本为 even；若最终位置为偶数，总成本为 odd。整数位置只有这两类，取二者最小值覆盖了全部可能目标，因此算法得到全局最优解。

复杂度

  • 时间复杂度：O(n)
  • 空间复杂度：O(1)

边界情况

  • 只有一个筹码：答案为 0。
  • 所有位置同奇偶：可免费聚拢，答案为 0。
  • 位置值很大：只做取模/位运算，不受距离影响。
  • 奇偶数量相同：聚到任一类都同样最优。
IMPLEMENTATIONS

四种语言

Java

class Solution {
    public int minCostToMoveChips(int[] position) {
        int odd = 0;
        int even = 0;
        for (int value : position) {
            if ((value & 1) == 0) {
                even++;
            } else {
                odd++;
            }
        }
        return Math.min(odd, even);
    }
}

JavaScript

/**
 * @param {number[]} position
 * @return {number}
 */
var minCostToMoveChips = function(position) {
    let odd = 0;
    let even = 0;

    for (const value of position) {
        if (value % 2 === 0) even++;
        else odd++;
    }

    return Math.min(odd, even);
};

Python

from typing import List


class Solution:
    def minCostToMoveChips(self, position: List[int]) -> int:
        odd = sum(value % 2 for value in position)
        even = len(position) - odd
        return min(odd, even)

C++

class Solution {
public:
    int minCostToMoveChips(vector<int>& position) {
        int odd = 0;
        int even = 0;
        for (int value : position) {
            if (value % 2 == 0) ++even;
            else ++odd;
        }
        return min(odd, even);
    }
};

替代方案

可以枚举候选目标位置并计算每枚筹码到该点是否跨奇偶类，但枚举所有输入位置会产生 O(n²) 工作。由于同类目标的成本完全相同，直接压缩成奇、偶两个候选更简洁。

常见错误

  • 按实际距离求和，忽略移动 2 格免费。
  • 寻找中位数；这是“每格都计费”时的思路，不适用于本题。
  • 误以为需要确定一个具体目标坐标，其实只需确定目标奇偶性。
  • 把奇数位置的“数值之和”与偶数位置的“数值之和”比较；应比较筹码数量。

面试追问

  • 如果 ±2 的成本不再为 0？ 奇偶类压缩会失效，需要重新建立距离成本模型。
  • 如果免费步长是 k？ 位置可按模 k 的余数分组，再根据跨组规则求最小成本。
  • 为什么不溢出？ 算法只统计不超过 100 的筹码数，不累计坐标或距离。
  • 能否一行完成？ 可以统计奇数数目后返回它与 n - odd 的较小值，但面试中清晰命名通常更易解释。
