找出数组的最大公约数

Find Greatest Common Divisor of Array

先理解两个端点的关系，再打开演示逐步探索。完整推导与四语言代码在页面底部。

01 / 题目

给定整数数组 nums，取其中的最小值和最大值，返回这两个数的最大公约数。最大公约数指能够同时整除两个数的最大正整数。

注意题目只要求数组最小值与最大值的最大公约数，并不要求答案整除数组中的每一个元素。

参数：nums: integer[]　返回：integer　方法：findGCD(nums)

示例 1

输入：nums = [2,5,6,9,10]
输出：2

最小值 2，最大值 10；它们的最大公约数是 2。

示例 2

输入：nums = [7,5,6,8,3]
输出：1

最小值 3，最大值 8；它们的最大公约数是 1。

示例 3

输入：nums = [3,3]
输出：3

最小值与最大值均为 3，答案为 3。

约束

  • 2 ≤ nums.length ≤ 1000
  • 1 ≤ nums[i] ≤ 1000

04 / 独立题解

准备好后，再展开推导与实现。

核心洞察：先取两端，再不断缩小问题

数组仅用于确定最小值 mn 与最大值 mx。一次遍历找出它们，再用欧几里得算法计算 gcd(mx, mn)。无需排序，也无需把中间元素纳入 GCD 运算。

完整过程

  1. 令 mn 和 mx 都等于第一个元素。遍历数组，每次分别更新较小值与较大值。
  2. 设 a = mx、b = mn。当 b ≠ 0 时计算 r = a % b，再同时把 (a, b) 替换为 (b, r)。
  3. b 为 0 时停止，返回 a。
nums = [7,5,6,8,3]
扫描后：mn = 3，mx = 8
8 = 2 × 3 + 2  → (a,b) = (3,2)
3 = 1 × 2 + 1  → (a,b) = (2,1)
2 = 2 × 1 + 0  → (a,b) = (1,0)
返回 1

为什么正确

扫描不变式：处理完前 k 个数后，mn、mx 分别是这 k 个数的最小值和最大值。初始化成立，比较更新后仍成立，因此遍历结束得到了整个数组的两端。

令 a = qb + r。若 d 同时整除 a 和 b，则也整除 r = a − qb；若 d 同时整除 b 和 r，则也整除 a = qb + r。因此 (a,b) 与 (b,r) 的公约数集合相同，最大公约数保持不变。每轮余数满足 0 ≤ r < b，第二个数严格减小，最终为 0。此时 gcd(a,0) = a，返回值就是原两端的最大公约数。

边界与复杂度

所有元素相等时，第一轮余数就是 0，返回该元素。最小值为 1 时答案为 1；只有两个元素时照常处理。输入保证非空且都是正整数，所以提交代码不需要处理空数组、负数或全零。

设 n 为数组长度，m 为最小值。扫描 O(n)，求 GCD 为 O(log m)（m = 1 时常数步），总时间可写为 O(n + log m)，额外空间 O(1)。本题数值上限为 1000，整体也可视为 O(n)。交互页面为支持回退而保存步骤，不属于提交算法的空间开销。

四语言完整提交代码

Java

class Solution {
    public int findGCD(int[] nums) {
        int mn = nums[0], mx = nums[0];
        for (int x : nums) {
            mn = Math.min(mn, x);
            mx = Math.max(mx, x);
        }
        int a = mx, b = mn;
        while (b != 0) {
            int r = a % b;
            a = b;
            b = r;
        }
        return a;
    }
}

from typing import List

class Solution:

            mn = min(mn, x)
            mx = max(mx, x)
        a, b = mx, mn
        while b:
            a, b = b, a % b
        return a

替代方案

从 mn 倒序枚举 d，找到第一个同时整除 mn 与 mx 的数即返回，时间 O(n + m)、空间 O(1)，在本题约束下可行。排序后取首尾会增加至 O(n log n)，且原地排序改变数组顺序。Python 可用 math.gcd，C++17 可用 std::gcd 简化最后一步；上述代码保留迭代过程便于理解。

常见错误

  • 对整个数组累积 GCD：示例 1 会得到 1，正确答案却是 2。
  • 把 mn 初始化为 0：正整数数组的最小值会被错误保留为 0，应从 nums[0] 开始。
  • 先执行 a = b 再计算 a % b：会丢失旧 a，必须先存余数或使用同时赋值。
  • 返回最后的 b：循环结束 b 是 0，应返回 a。
  • 在 b 为 0 时仍取模：应在循环条件中排除。

面试追问

  • 若要求整除所有元素呢？依次累积 gcd；这是另一道问题。
  • 数据以流形式到达呢？只维护当前最小、最大值，在流结束时求 GCD。
  • 若允许负数或 0 呢？先定义原数组端点语义，再对选出的两数取绝对值求 GCD；gcd(0,x)=|x|，全零需要单独约定返回值。
  • JavaScript 数值扩大呢？超过安全整数范围应统一使用 BigInt，包括 0n 比较与取模。
