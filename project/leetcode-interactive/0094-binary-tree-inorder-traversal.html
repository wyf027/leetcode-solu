Problem

题意

给定一棵二叉树的根节点 root，返回节点值的中序遍历结果。中序顺序固定为：先遍历左子树，再访问根节点，最后遍历右子树。

第 94 题完整题解

Core insight

栈保存“回头再访问”的根

只要 current 非空，就先压栈并继续向左。走到空指针后，弹出栈顶并访问；随后把 current 切到该节点的右孩子。循环在 current 为空且栈也为空时结束。

Complete process

完整过程

  1. 1. 初始化空栈、空答案与 current = root。
  2. 2. current 非空时持续压栈，然后 current = current.left。
  3. 3. 左侧到底后弹出栈顶，把节点值加入答案。
  4. 4. current = popped.right，继续处理右子树。
  5. 5. current 为空且栈空时返回答案。

Edges

边界条件

  • 空树：循环不执行，直接返回空数组。
  • 单节点：压栈一次、弹栈一次，得到该节点。
  • 全左链：栈深度达到节点数，访问顺序自底向上。
  • 全右链：每次压入后立即弹出，访问顺序自顶向下。
  • 节点值可为负数，与遍历控制逻辑无关。

Complexity

复杂度与替代方案

每个节点恰好压栈、弹栈一次，时间复杂度 O(n)；栈最多保存树高 h 个节点，空间复杂度 O(h)。递归写法更短，但隐式调用栈仍是 O(h)。Morris 遍历可降到 O(1) 额外空间，却会临时修改指针，面试中除非被追问通常不作为首选。

Interview follow-ups

面试追问

为什么不能只在 current 非空时循环？
走到左侧空指针后，栈中仍有待访问节点。
如何证明访问顺序正确？
弹出某节点前，它的整个左子树已处理；弹出后才进入右子树。
最坏空间何时达到 O(n)？
树完全向左倾斜时，所有节点会同时在栈中。
如何做到 O(1) 空间？
使用 Morris 线索化，访问后恢复临时右指针。

Common mistakes

常见错误

  • 把外层条件写成 current != null，漏掉栈内剩余节点。
  • 压栈后忘记转向 left，造成死循环。
  • 弹栈后先走 right、后记录值，误写成别的遍历顺序。
  • 把节点对象和值混入同一个栈，导致类型或状态混乱。
  • 认为二叉搜索树专属；中序遍历适用于任意二叉树。

import java.util.*;

class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> answer = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode current = root;

        while (current != null || !stack.isEmpty()) {
            while (current != null) {
                stack.push(current);
                current = current.left;
            }
            current = stack.pop();
            answer.add(current.val);
            current = current.right;
        }
        return answer;
    }
}
