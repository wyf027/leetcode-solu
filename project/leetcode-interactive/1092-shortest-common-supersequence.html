最短公共超序列

把两个字符串交织成尽可能短的新字符串，同时保持它们各自的字符顺序。先动手观察合并过程，再决定是否展开完整题解。

HARD字符串动态规划最长公共子序列

题目

给定两个仅含小写英文字母的字符串 str1 与 str2，返回一个最短字符串，使二者都是它的子序列。若最短答案有多个，返回任意一个。

子序列允许从目标串中删除任意数量（包括 0 个）字符，但剩余字符的相对顺序不能改变。

函数签名

shortestCommonSupersequence(str1: string, str2: string): string

约束

  • 1 ≤ str1.length, str2.length ≤ 1000
  • 两个字符串都只包含小写英文字母。
  • 返回任意一个长度最短的有效答案。

思考起点：哪些字符可以只放一次，同时服务于两个子序列？

官方示例

示例 1 输入：str1 = "abac", str2 = "cab" 输出："cabac" 解释：删除首个 c 可得到 abac；删除末尾 ac 可得到 cab，且不存在更短的有效字符串。
示例 2 输入：str1 = "aaaaaaaa", str2 = "aaaaaaaa" 输出："aaaaaaaa"

完整题解

核心洞察

把最长公共子序列（LCS）中的字符只写一次，其余字符按原顺序穿插进去，就能得到最短公共超序列。长度恒为 m + n - LCS(str1, str2)。更直接的做法是令 dp[i][j] 表示两段前缀的 LCS 长度，再从右下角逆向重建答案。

完整过程

  1. 建立 (m+1) × (n+1) 的 LCS 表。
  2. 字符相同时，令 dp[i][j] = dp[i-1][j-1] + 1。
  3. 不同时取上方与左方的较大值。
  4. 从 (m,n) 回溯：相同字符只追加一次；否则走向 LCS 值较大的邻格，并追加被越过的字符。
  5. 追加任一字符串剩余前缀，最后反转。

正确性

回溯时，每次都会消费 str1、str2 或二者的一个末尾字符，因此输出反转后保留两串原有顺序，二者均为其子序列。公共字符沿一条最长公共子序列路径仅加入一次，共节省 LCS 长度个字符；任意公共超序列至多如此复用字符，所以所得长度 m+n-LCS 已达到下界，必然最短。

边界情况

  • 两串完全相同：直接得到原串。
  • 没有公共字符：任意保持内部顺序的拼接都是最短答案。
  • 一串是另一串的子序列：较长串即答案。
  • 重复字符很多：不同回溯分支可能产生不同但同样最短的答案。

复杂度

时间复杂度 O(mn)；二维 DP 空间复杂度 O(mn)；重建结果长度最多 m+n。

替代方案

也可直接定义最短公共超序列长度 DP，并按较短分支回溯。若只求长度，可用滚动数组降到 O(min(m,n)) 空间；但要重建字符串，仍需保存路径、完整表，或采用 Hirschberg 分治。

面试追问

  • 如何只求最短长度并优化空间？
  • 如何返回字典序最小的最短答案？
  • 如何处理三个字符串？状态维度和复杂度会怎样变化？

常见错误

  • 误把子序列当作连续子串。
  • 回溯结束后漏掉某个字符串的剩余前缀。
  • 逆向收集后忘记反转。
  • 字符不同时随意选择方向，未依据 DP 值，导致答案不是最短。

四语言实现

class Solution {
    public String shortestCommonSupersequence(String a, String b) {
        int m = a.length(), n = b.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) for (int j = 1; j <= n; j++)
            dp[i][j] = a.charAt(i-1) == b.charAt(j-1)
                ? dp[i-1][j-1] + 1 : Math.max(dp[i-1][j], dp[i][j-1]);
        StringBuilder ans = new StringBuilder(); int i=m, j=n;
        while (i>0 && j>0) {
            if (a.charAt(i-1)==b.charAt(j-1)) { ans.append(a.charAt(--i)); j--; }
            else if (dp[i-1][j] >= dp[i][j-1]) ans.append(a.charAt(--i));
            else ans.append(b.charAt(--j));
        }
        while(i>0) ans.append(a.charAt(--i));
        while(j>0) ans.append(b.charAt(--j));
        return ans.reverse().toString();
    }
}

        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                dp[i][j] = dp[i-1][j-1] + 1 if a[i-1] == b[j-1] else max(dp[i-1][j], dp[i][j-1])
        i, j, ans = m, n, []
        while i and j:
            if a[i-1] == b[j-1]: ans.append(a[i-1]); i -= 1; j -= 1
            elif dp[i-1][j] >= dp[i][j-1]: i -= 1; ans.append(a[i])
            else: j -= 1; ans.append(b[j])
        while i: i -= 1; ans.append(a[i])
        while j: j -= 1; ans.append(b[j])
        return ''.join(reversed(ans))
