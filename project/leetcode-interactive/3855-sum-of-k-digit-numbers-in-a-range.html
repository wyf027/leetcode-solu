LEETCODE 3855 · HARD

给定范围内 K 位数字之和

每一位都从 [l, r] 独立选择，求所有恰好 k 位数的总和（模 109 + 7）。范围含 0 时允许前导零。

数学组合计数快速幂

题意与示例

设数字集合大小为 n = r - l + 1。一共可组成 nk 个长度固定的数字串；数字串的数值按十进制解释。

示例 1

l = 1, r = 2, k = 2

11 + 12 + 21 + 22 = 66

示例 2

l = 0, r = 1, k = 3

000 到 111 共 8 个串，总和为 444。

约束：0 ≤ l ≤ r ≤ 9，1 ≤ k ≤ 109。

位权贡献实验室

用小输入观察每一位的对称贡献。

步骤 1 / 3

测试与验证

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

核心洞察：每个位置完全对称

固定任意一位后，其余 k - 1 位有 nk−1 种填法。该位所有可选数字的和是 S = (l + r)n / 2；它在位置 i 的位权是 10i。所以答案为 S · n^(k-1) · (10^k - 1) / 9。

完整过程

  1. 计算 n 与 S。
  2. 快速幂得到 n^(k−1)。
  3. 乘以等比位权和。

边界

k = 1；l = r；l = 0 的前导零；所有乘法均在模域中进行。

复杂度

时间 O(log k)，额外空间 O(1)。

替代方案、追问与常见错误

  • 小 k 可枚举验证，但 k 到 109 时必须使用公式。
  • 追问：把十进制改成 b 进制时，将 10 和 9 换成 b 与 b−1。
  • 错误：逐位循环 k 次；忘记其余位的 nk−1 倍数；整数除法未在乘法前处理。
