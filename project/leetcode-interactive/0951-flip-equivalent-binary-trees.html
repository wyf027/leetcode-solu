翻转等价
不是长得一样

两棵树可以在任意节点交换左右子树。你的任务是判断：是否存在一组翻转，让它们最终完全相同？先观察递归如何在“两条配对路线”之间作选择，题解不会在首屏剧透。

题目

对二叉树的一次翻转，是选择任意节点并交换它的左右子树。给定两棵二叉树的根节点 root1 与 root2，若经过零次或多次翻转后能使两棵树相同，返回 true；否则返回 false。

函数签名

flipEquiv(root1: TreeNode, root2: TreeNode) → boolean

官方示例

示例 1
输入：root1 = [1,2,3,4,5,6,null,null,null,7,8]
      root2 = [1,3,2,null,6,4,5,null,null,null,null,8,7]
输出：true
解释：可以在值为 1、3、5 的节点处翻转。
示例 2
输入：root1 = [], root2 = []
输出：true
示例 3
输入：root1 = [], root2 = [1]
输出：false

约束

  • 每棵树的节点数在 [0, 100] 内。
  • 每棵树的节点值互不相同，且位于 [0, 99]。

核心洞察

节点 a 与 b 翻转等价，当且仅当根值相同，并且下面两种配对至少有一种成立：直连（左↔左、右↔右）或交叉（左↔右、右↔左）。

完整过程

  1. 若两个节点都为空，当前子树等价；若只有一个为空，则不等价。
  2. 两个节点都存在但值不同，立即返回 false。
  3. 递归检查直连配对；若失败，再检查交叉配对。
  4. 任一路线的两个子问题都成立，当前子树就翻转等价。

正确性证明

基础情形：两棵空树显然等价；仅一棵为空或根值不同，不可能通过交换子树修复。

归纳步骤：假设更小的子树都能被递归正确判断。根值相等时，根节点最终只有“不翻转”和“翻转”两种对应关系。算法穷尽二者，并借助归纳假设正确判断各对子树。因此算法返回真，当且仅当存在合法翻转序列。

复杂度

在节点值唯一的题目约束下，每对有效节点沿匹配方向访问，时间 O(n)；递归栈为 O(h)，最坏 O(n)。

边界情况

  • 两棵树都为空。
  • 仅一棵树为空。
  • 单节点且值相同/不同。
  • 极度倾斜的树。
  • 无需任何翻转就相同。

替代方案

可为每棵子树构造与左右顺序无关的规范序列（对子序列排序后拼接），再比较两棵树的规范表示。它便于哈希或批量比较，但会分配额外字符串/数组，通常不如直接 DFS 简洁。

面试追问

  • 若节点值不唯一？递归定义仍正确，但朴素分支可能产生大量重复搜索；可对节点对做记忆化。
  • 如何避免递归栈溢出？用显式栈维护待比较节点对，并在值唯一时根据孩子值决定配对。
  • 能否返回翻转位置？在交叉路线成功时记录当前节点，并让递归返回“是否成功 + 操作列表”。

常见错误

  • 只比较左对左、右对右，漏掉交叉配对。
  • 把“任一子问题为真”误写成整条路线为真；每条路线内部必须是两个 &&。
  • 先读取 val 再判空，导致空指针异常。
  • 实际修改树结构，增加恢复现场的复杂度；本题只需比较。

四语言完整代码

/** Definition for a binary tree node.
 * public class TreeNode {
 *   int val; TreeNode left; TreeNode right;
 * }
 */
class Solution {
    public boolean flipEquiv(TreeNode root1, TreeNode root2) {
        if (root1 == null || root2 == null) return root1 == root2;
        if (root1.val != root2.val) return false;

        boolean straight = flipEquiv(root1.left, root2.left)
                && flipEquiv(root1.right, root2.right);
        boolean crossed = flipEquiv(root1.left, root2.right)
                && flipEquiv(root1.right, root2.left);
        return straight || crossed;
    }
}
/**
 * @param {TreeNode} root1
 * @param {TreeNode} root2
 * @return {boolean}
 */
var flipEquiv = function (root1, root2) {
    if (root1 === null || root2 === null) return root1 === root2;
    if (root1.val !== root2.val) return false;

    const straight = flipEquiv(root1.left, root2.left)
        && flipEquiv(root1.right, root2.right);
    const crossed = flipEquiv(root1.left, root2.right)
        && flipEquiv(root1.right, root2.left);
    return straight || crossed;
};
class Solution:
    def flipEquiv(self, root1: Optional[TreeNode],
                  root2: Optional[TreeNode]) -> bool:
        if root1 is None or root2 is None:
            return root1 is root2
        if root1.val != root2.val:
            return False

        straight = (self.flipEquiv(root1.left, root2.left) and
                    self.flipEquiv(root1.right, root2.right))
        crossed = (self.flipEquiv(root1.left, root2.right) and
                   self.flipEquiv(root1.right, root2.left))
        return straight or crossed
class Solution {
public:
    bool flipEquiv(TreeNode* root1, TreeNode* root2) {
        if (root1 == nullptr || root2 == nullptr)
            return root1 == root2;
        if (root1->val != root2->val) return false;

        bool straight = flipEquiv(root1->left, root2->left)
                     && flipEquiv(root1->right, root2->right);

                    && flipEquiv(root1->right, root2->left);
        return straight || crossed;
    }
