01 / Problem

把规则说清楚

给定一个 n × n 整数矩阵 grid。从每一行恰好选择一个元素，且相邻两行选择的元素不能位于同一列。请返回所有合法选择中，元素总和的最小值。

参数与返回值

  • 参数：grid: integer[][]，一个 n 行 n 列的整数矩阵。
  • 选择：每一行必须且只能选择一个元素。
  • 限制：第 i 行和第 i + 1 行所选元素的列下标必须不同。
  • 返回：满足限制的下降路径的最小元素和，类型为整数。

示例 1

输入grid = [[1,2,3],[4,5,6],[7,8,9]]
输出13
解释可选择 [1,5,7]，相邻选择均不同列，总和为 13；不存在更小的合法路径。

示例 2

输入grid = [[7]]
输出7
解释矩阵只有一行，唯一元素本身就是答案。

容易看漏的点

“非零偏移”不是只能移动到相邻列。下一行可以选择任意列，只要与上一行的列不同。

元素可能为负数，因此不能使用“看起来越小越早选”的贪心。

n = grid.length且 n = grid[i].length
1 ≤ n ≤ 200最多 40,000 个格子
−99 ≤ grid[i][j] ≤ 99需要正确处理负数

04 / Solution

只记住上一行的冠亚军

朴素转移会为每个格子扫描上一行所有不同列，达到 O(n³)。关键是：排除一个列以后，最优前驱只可能是上一行的最小值，或最小值所在列被禁用时的次小值。

INSIGHT 01

状态

令 dp[i][j] 表示选中第 i 行第 j 列时，前 i + 1 行构成的合法路径最小和。

INSIGHT 02

两个极值

从上一行找最小值 min1、其列 min1Col，以及来自不同列的次小值 min2。

INSIGHT 03

常数时间转移

若 j ≠ min1Col，就接 min1；否则同列被禁用，接 min2。每个格子 O(1)。

完整过程

  1. 将第一行复制为 prev，其中 prev[j] 就是以第一行第 j 列结尾的最小和。
  2. 处理新一行前，单次扫描 prev，记录最小值 min1、其列 min1Col 和次小值 min2。相同数值也按不同列参与比较。
  3. 对当前行每个 j：若 j 与 min1Col 不同，curr[j] = grid[i][j] + min1；否则 curr[j] = grid[i][j] + min2。
  4. 令 prev = curr，继续下一行。最后返回 prev 中的最小值。
curr[j] = grid[i][j] + (j !== min1Col ? min1 : min2)

正确性证明

状态不变式。

处理完第 i 行后，prev[j] 等于所有以 (i,j) 结尾的合法下降路径中的最小总和。第一行显然成立。

转移覆盖所有合法前驱。

对当前列 j，合法前驱正是上一行除 j 外的所有列。若上一行全局最小值不在 j 列，它就是该集合的最小值；若它在 j 列，则删除它后，次小值就是合法集合的最小值。

保持不变式。

算法将 grid[i][j] 加到最优合法前驱上，所以得到以 (i,j) 结尾的最小合法路径和；由归纳，不变式对每一行成立。

得到全局答案。

任何完整路径都结束在最后一行的某一列，因此最后一行所有状态的最小值恰是全局最小路径和。

复杂度

时间 O(n²)：n 行，每行两次线性扫描。

空间 O(n)：只保留上一行和当前行。也可以原地复用输入矩阵，代价是修改参数。

边界处理

  • n = 1 时直接返回唯一元素。
  • 负数无需特殊分支，转移仍成立。
  • 最小值并列时，min2 可以与 min1 数值相等，但必须来自另一个列位置。
  • 题目范围内 int / Number 足够容纳答案。

替代方案

朴素动态规划：为每个 (i,j) 枚举上一行所有 k ≠ j，时间 O(n³)，空间 O(n)。逻辑直接，但 n = 200 时做了大量重复比较。

排序上一行：每行将 (值, 列) 排序，再选择第一个不同列的候选，时间 O(n² log n)。可行但没有必要；只找两个最小值即可在线性时间完成。

四语言完整代码

JavaO(n²) / O(n)
class Solution {
    public int minFallingPathSum(int[][] grid) {
        int n = grid.length;
        int[] prev = grid[0].clone();

        for (int i = 1; i < n; i++) {
            int min1 = Integer.MAX_VALUE;
            int min2 = Integer.MAX_VALUE;
            int min1Col = -1;

            for (int j = 0; j < n; j++) {
                if (prev[j] < min1) {
                    min2 = min1;
                    min1 = prev[j];
                    min1Col = j;
                } else if (prev[j] < min2) {
                    min2 = prev[j];
                }
            }

            int[] curr = new int[n];
            for (int j = 0; j < n; j++) {
                int bestPrev = (j == min1Col) ? min2 : min1;
                curr[j] = grid[i][j] + bestPrev;
            }
            prev = curr;
        }

        int answer = prev[0];
        for (int value : prev) answer = Math.min(answer, value);
        return answer;
    }
}

from typing import List


class Solution:
    def minFallingPathSum(self, grid: List[List[int]]) -> int:
        n = len(grid)
        prev = grid[0][:]

        for i in range(1, n):
            min1 = float("inf")
            min2 = float("inf")
            min1_col = -1

            for j, value in enumerate(prev):
                if value < min1:
                    min2 = min1
                    min1 = value
                    min1_col = j
                elif value < min2:
                    min2 = value

            curr = [0] * n
            for j in range(n):
                best_prev = min2 if j == min1_col else min1
                curr[j] = grid[i][j] + best_prev
            prev = curr

        return min(prev)

常见错误

  • 把规则误解为只能走左下或右下；本题可以跳到任意不同列。
  • 只记最小值，不记它所在的列，无法判断当前列能否使用。
  • 用“严格大于 min1”寻找 min2，导致并列最小时错误跳过合法的第二列。
  • 直接修改 prev 后又用它计算同一行后续格子，混淆新旧状态。
  • n = 1 时试图读取不存在的次小值。

面试追问

如果每次禁止的是 k 个列呢？
维护上一行最小的 k + 1 个、列互异的候选，查询时跳过被禁列。
如何恢复具体路径？
为每个状态记录本次选择的前驱列，最后从最小终点反向回溯；空间变为 O(n²)。
可以原地做吗？
可以将累计值写回 grid 的当前行，将额外空间降到 O(1)，但会改变输入。
