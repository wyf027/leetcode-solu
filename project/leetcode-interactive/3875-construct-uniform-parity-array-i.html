构造奇偶一致的数组 I

从每个位置保留原数，或减去另一个位置的数。观察奇偶性即可证明：所有合法输入都能完成构造。

构造实验室

切换两组输入，观察“同奇偶直接保留”与“混合奇偶统一变成奇数”这两个覆盖全部情况的构造。

奇数偶数

    ↓ 选择每个位置的合法操作

      题意

      给定互不相同的 nums1。对每个下标 i，任选保留 nums1[i]，或选择 nums1[i] - nums1[j]（j ≠ i）。目标是让 nums2 全为奇数或全为偶数。

      示例

      nums1 = [2, 3]：令结果为 [-1, 3]，均为奇数。

      nums1 = [4, 6]：直接保留，结果 [4, 6]，均为偶数。

      约束

      1 ≤ n ≤ 100；元素在 [1, 100] 且两两不同。

      测试与验证

      快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

      题解：分类构造

      核心洞察

      若数组原本全奇或全偶，直接保留即可。否则它同时含有奇数和偶数：每个奇数减去任一偶数、每个偶数减去任一奇数，差都为奇数；因此全部位置可构造成奇数。故答案不依赖具体输入，恒为 true。

      完整过程与边界

      1. 长度为 1 时，直接保留唯一元素，已经统一。
      2. 存在单一奇偶性时，原数组即是可行的 nums2。
      3. 存在两种奇偶性时，每个元素都能找到异奇偶参照元素；构造出的差全是奇数。

      复杂度

      提交函数只返回常量：时间 O(1)，额外空间 O(1)。

      替代方案

      可以扫描并计数奇、偶元素后按上面的两类显式构造；它有助于演示，但对本题返回值来说多做了工作，复杂度为 O(n)。

      面试追问

      若题目要求真正返回 nums2，而非布尔值，应保留一奇一偶的下标作为参照，再逐位写出差值。

      常见错误

      • 误以为混合奇偶时不能统一；恰好相反，异奇偶相减全为奇数。
      • 让 j = i；题目明确禁止，且这里不需要这样做。
      • 把“存在构造”误做成搜索所有构造。
