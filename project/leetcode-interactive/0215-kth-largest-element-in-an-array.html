数组中的第 K 个最大元素

不完整排序整个数组：每次选一个枢轴，把搜索范围缩小到唯一可能包含答案的一侧。

题意

给定整数数组 nums 与整数 k，返回按排序顺序的第 k 个最大元素。重复值分别计数：它不是第 k 个不同的元素。题目希望避免完整排序。

官方样例 1

nums = [3, 2, 1, 5, 6, 4], k = 2

输出：5

官方样例 2

nums = [3, 2, 3, 1, 2, 4, 5, 5, 6], k = 4

输出：4

约束：1 ≤ k ≤ nums.length ≤ 10⁵，−10⁴ ≤ nums[i] ≤ 10⁴。

演示的读法

  1. 1. 紫色数字是当前枢轴。
  2. 2. 三个桶按 < pivot、= pivot、> pivot 划分。
  3. 3. 第 k 大等价于升序下标 n − k；只保留能包含目标下标的桶。

题解

首屏不直接展示，使用按钮按需展开。

主线：三路快速选择

令目标为升序下标 target = n - k。任选枢轴，把当前区间分成小于、等于和大于三段。目标在小于段就向左，目标在大于段就向右；落在等于段时，枢轴值就是答案。三路划分同时正确处理重复值。

随机枢轴的期望时间为 O(n)，并且只解决一个秩，不必花 O(n log n) 排序所有元素。

过程：样例 1

  1. 1. target = 6 − 2 = 4。
  2. 2. 以 4 为枢轴：[3,2,1] | [4] | [5,6]，枢轴在位置 3。
  3. 3. 目标 4 在右段；在 [5,6] 中继续。
  4. 4. 以 5 为枢轴，目标落入等于段，答案为 5。

边界

k=1 求最大值；k=n 求最小值；负数无需特殊处理；大量重复值必须按元素个数计数。

替代方案

小顶堆保留 k 个元素，时间 O(n log k)、空间 O(k)，适合数据流。完整排序代码短，但不符合“无需排序”的追问。

常见错误

把第 k 大直接当下标 k；忘记转为 n-k。分区后也不要漏掉等于枢轴的整段。

面试追问

最坏情况为何是 O(n²)？固定坏枢轴会每次只缩小一个元素。随机化或 median-of-three 能降低该风险；若题目要求最坏线性时间，可提及 median of medians。 

class Solution {
    public int findKthLargest(int[] nums, int k) {
        int target = nums.length - k, left = 0, right = nums.length - 1;
        while (left <= right) {
            int pivot = nums[left + (int)(Math.random() * (right - left + 1))];
            int lt = left, i = left, gt = right;
            while (i <= gt) {
                if (nums[i] < pivot) swap(nums, lt++, i++);
                else if (nums[i] > pivot) swap(nums, i, gt--);
                else i++;
            }
            if (target < lt) right = lt - 1;
            else if (target > gt) left = gt + 1;
            else return nums[target];
        }
        throw new IllegalStateException();
    }
    private void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }
}

      else if (nums[i] > pivot) [nums[i], nums[gt--]] = [nums[gt], nums[i]];
      else i++;
    }
    if (target < lt) right = lt - 1;
    else if (target > gt) left = gt + 1;
    else return nums[target];

from typing import List
from random import randint

class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        target, left, right = len(nums) - k, 0, len(nums) - 1
        while left <= right:
            pivot = nums[randint(left, right)]
            lt = i = left
            gt = right
            while i <= gt:
                if nums[i] < pivot:
                    nums[lt], nums[i] = nums[i], nums[lt]
                    lt, i = lt + 1, i + 1
                elif nums[i] > pivot:
                    nums[i], nums[gt] = nums[gt], nums[i]
                    gt -= 1
                else:
                    i += 1
            if target < lt: right = lt - 1
            elif target > gt: left = gt + 1
            else: return nums[target]
