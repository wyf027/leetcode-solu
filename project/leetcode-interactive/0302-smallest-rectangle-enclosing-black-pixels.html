包含全部黑色像素的最小矩形Smallest Rectangle Enclosing Black Pixels

在一张由白色与黑色像素构成的图像里，找到刚好包住全部黑色像素的最小轴对齐矩形，并返回它的面积。

难度 · HARD 付费题 数组 矩阵 二分查找

Problem brief

题目说明

以下根据官方元数据中的函数签名与示例作准确转述；黑色像素用字符 "1" 表示，白色像素用字符 "0" 表示。

目标

给定一个大小为 m × n 的二值图像 image。所有黑色像素在水平或竖直方向上连成一个整体。另给出坐标 (x, y)，保证它指向一个黑色像素。

请返回一个边与坐标轴平行的最小矩形的面积，使这个矩形包含图像中的全部黑色像素。坐标 x 表示行号，y 表示列号。

官方参数形式

minArea(image: character[][], x: integer, y: integer) → integer

像素与坐标

0 · 白色像素
1 · 黑色像素
(x, y) · 已知黑色像素

返回值

矩形面积

结果为整数，不需要返回矩形坐标。

示例一

3 × 4
输入image = [["0","0","1","0"], ["0","1","1","0"], ["0","1","0","0"]], x = 0, y = 2
输出6
说明最小矩形覆盖第 0～2 行、第 1～2 列，面积为 3 × 2 = 6。

示例二

1 × 1
输入image = [["1"]], x = 0, y = 0
输出1
说明唯一像素本身就是最小包围矩形。

约束

  • m == image.length，n == image[i].length
  • 1 ≤ m, n ≤ 100
  • image[i][j] 为字符 "0" 或 "1"
  • 0 ≤ x < m，0 ≤ y < n，且 image[x][y] == "1"
  • 全部黑色像素通过上下左右相邻关系连通。

二分定位四条外边界

把几何问题拆成四个一维的“第一个满足条件的位置”：上边界、下边界、左边界、右边界。

核心洞察完整过程正确性复杂度四语言代码替代方案面试追问常见错误

核心洞察

01 / CONNECTED

连通性带来单调性

黑色像素整体连通，因此从最上黑行到最下黑行之间不会夹着整行空白；列方向同理。

02 / ANCHOR

已知点切开搜索区间

已知 (x,y) 为黑色：上界只需在 [0,x] 找，右界只需在 [y+1,n] 找。

03 / EXCLUSIVE

下、右采用开边界

令 bottom、right 指向矩形外的第一个位置，面积公式不需要额外加一。

完整过程

  1. 在行区间 [0, x] 中，二分找到第一条含黑色像素的行，记为 top。
  2. 在行区间 [x+1, m] 中，二分找到第一条不含黑色像素的行，记为开边界 bottom；若不存在则为 m。
  3. 在列区间 [0, y] 中，二分找到第一列含黑色像素的列，记为 left。
  4. 在列区间 [y+1, n] 中，二分找到第一列不含黑色像素的列，记为开边界 right；若不存在则为 n。
  5. 返回高度乘宽度。
height = bottom - top
width  = right - left
area   = height × width

正确性证明

1

行、列判定在各自搜索区间内单调

所有黑色像素连通。如果两条含黑像素的行之间存在整条空白行，那么黑色集合会被该行隔开，产生矛盾。因此含黑行形成连续区间；含黑列同理。

2

四次二分得到四个极值边界

top 与 left 分别是第一条含黑行、第一列含黑列；bottom 与 right 分别是连续黑色投影结束后的第一个位置。故所有黑色像素的行列坐标都落在半开矩形 [top,bottom) × [left,right) 内。

3

所得矩形最小

四条边界上紧贴着黑色投影的极值。若把任意一条边向内移动，至少会排除一个位于对应极值行或列上的黑色像素。因此不存在面积更小且仍包含全部黑色像素的轴对齐矩形。

4

面积公式正确

半开区间的行数为 bottom-top，列数为 right-left。两者相乘就是最小包围矩形面积，算法返回值正确。

边界情况

  • 单个黑像素：四个边界相差各为 1，面积为 1。
  • 黑色区域触碰图像边缘：开边界允许等于 m 或 n，无需访问越界位置。
  • 只有一行或一列：对应方向的二分区间可以立即收敛，另一方向照常工作。
  • 给定点不在边缘：它只作为保证落在黑色投影内部的锚点，不要求是边界像素。

复杂度

扫描行边界
O(n log m)
扫描列边界
O(m log n)
额外空间
O(1)

每次判断某一行是否含黑色需扫描 n 个像素，共进行对数次；列方向对称。总时间为 O(n log m + m log n)。

class Solution {
    public int minArea(char[][] image, int x, int y) {
        int m = image.length;
        int n = image[0].length;

        int top = searchRows(image, 0, x, true);
        int bottom = searchRows(image, x + 1, m, false);
        int left = searchColumns(image, 0, y, true);
        int right = searchColumns(image, y + 1, n, false);

        return (bottom - top) * (right - left);
    }

    private int searchRows(char[][] image, int low, int high,
                           boolean findBlack) {
        int columns = image[0].length;
        while (low < high) {
            int mid = low + (high - low) / 2;
            boolean hasBlack = false;
            for (int column = 0; column < columns; column++) {
                if (image[mid][column] == '1') {
                    hasBlack = true;
                    break;
                }
            }
            if (hasBlack == findBlack) {
                high = mid;
            } else {
                low = mid + 1;
            }
        }
        return low;
    }

    private int searchColumns(char[][] image, int low, int high,
                              boolean findBlack) {
        int rows = image.length;
        while (low < high) {
            int mid = low + (high - low) / 2;
            boolean hasBlack = false;
            for (int row = 0; row < rows; row++) {
                if (image[row][mid] == '1') {
                    hasBlack = true;
                    break;
                }
            }
            if (hasBlack == findBlack) {
                high = mid;
            } else {
                low = mid + 1;
            }
        }
        return low;
    }
}

var minArea = function(image, x, y) {
    const m = image.length;
    const n = image[0].length;

    const searchRows = (low, high, findBlack) => {
        while (low < high) {
            const mid = low + Math.floor((high - low) / 2);
            const hasBlack = image[mid].some(pixel => pixel === "1");
            if (hasBlack === findBlack) {
                high = mid;
            } else {
                low = mid + 1;
            }
        }
        return low;
    };

    const searchColumns = (low, high, findBlack) => {
        while (low < high) {
            const mid = low + Math.floor((high - low) / 2);
            let hasBlack = false;
            for (let row = 0; row < m; row++) {
                if (image[row][mid] === "1") {
                    hasBlack = true;
                    break;
                }
            }
            if (hasBlack === findBlack) {
                high = mid;
            } else {
                low = mid + 1;
            }
        }
        return low;
    };

    const top = searchRows(0, x, true);
    const bottom = searchRows(x + 1, m, false);
    const left = searchColumns(0, y, true);
    const right = searchColumns(y + 1, n, false);

    return (bottom - top) * (right - left);
};

class Solution:
    def minArea(self, image: List[List[str]], x: int, y: int) -> int:
        m, n = len(image), len(image[0])

        def search_rows(low: int, high: int, find_black: bool) -> int:
            while low < high:
                mid = low + (high - low) // 2
                has_black = any(pixel == "1" for pixel in image[mid])
                if has_black == find_black:
                    high = mid
                else:
                    low = mid + 1
            return low

        def search_columns(low: int, high: int, find_black: bool) -> int:
            while low < high:
                mid = low + (high - low) // 2
                has_black = any(image[row][mid] == "1" for row in range(m))
                if has_black == find_black:
                    high = mid
                else:
                    low = mid + 1
            return low

        top = search_rows(0, x, True)
        bottom = search_rows(x + 1, m, False)
        left = search_columns(0, y, True)
        right = search_columns(y + 1, n, False)

        return (bottom - top) * (right - left)

替代方案

扫描整张图

遍历所有 m × n 个像素，并维护黑色像素的最小/最大行列。逻辑最直接，也不依赖连通性；但没有利用已知黑色坐标。

时间 O(mn) · 空间 O(1)

DFS / BFS

从 (x,y) 出发访问连通的黑色像素，同时更新四个极值。若黑色像素数为 k，访问时间为 O(k)，但需要访问标记与队列或栈。

时间 O(k) · 空间 O(k)

面试追问

为什么连通性对二分查找至关重要？

它保证含黑行、含黑列各自形成连续区间，从而让“这一行/列是否含黑色”的判定在锚点两侧呈单调变化。若黑块不连通，中间可能出现空行或空列，二分边界会失效。

如果黑色像素不保证连通，怎么改？

使用全图扫描，直接统计全部黑像素的最小与最大行列，时间 O(mn)、额外空间 O(1)，不再依赖单调性。

为什么上界搜索传入 high = x，而不是 x + 1？

x 已知是含黑行，因此它可以直接作为“答案不超过此处”的有效闭合上界。若此前没有更早的含黑行，循环会返回 x。

能否把四次二分抽象成一个函数？

可以，但行扫描与列扫描的访问方式不同。面试中通常保留两个小函数更清晰，再用 findBlack 参数复用左侧边界与右侧开边界的二分模板。

常见错误

!

下、右边界多加或少加 1

统一使用半开区间：bottom 与 right 指向矩形外的第一个位置，面积直接作差。

!

把 x、y 的行列含义写反

x 是行，取值范围是 [0,m)；y 是列，取值范围是 [0,n)。

!

在 high = m 或 n 时读取矩阵

二分循环仅访问 mid < high 的有效位置。不要在循环外用开边界索引读取像素。

!

忽略题目的连通前提

二分方案的单调性证明依赖黑色像素连通。泛化到多个分离黑块时，应改用全图扫描。
