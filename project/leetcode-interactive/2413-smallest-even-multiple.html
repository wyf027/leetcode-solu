04 / 独立题解

准备好后再展开：包含证明、四语言实现与面试追问。

核心洞察

只需判断 n 的奇偶性：n 为偶数时返回 n；n 为奇数时返回 2n。即 n % 2 == 0 ? n : 2 * n。

完整过程

  1. 任何正的 n 的倍数都形如 kn，且 k ≥ 1。先考虑最小候选 n。
  2. 如果 n 为偶数，它已经能被 2 整除，直接返回。
  3. 如果 n 为奇数，n 不合格；下一个正倍数 2n 一定为偶数，返回 2n。

正确性证明

若 n 为偶数，n 同时是 2 与 n 的倍数；任何正的 n 的倍数都不小于 n，因此 n 最小。若 n 为奇数，第一个正倍数 n 不是偶数，第二个正倍数 2n 是偶数，两者之间不存在其他 n 的倍数，所以 2n 是最小满足条件的数。两种情况覆盖所有合法输入。

边界与复杂度

n = 1 返回 2，不能返回 0，因为结果必须为正数。n = 150 返回 150；范围内的最大答案为 n = 149 时的 298。整数运算在给定范围内安全。时间复杂度 O(1)，额外空间复杂度 O(1)；配对图中的圆点仅用于教学，不属于提交算法。

替代方案

通用公式为 lcm(2,n) = 2n / gcd(2,n)。一般可用欧几里得算法求 gcd；这里 gcd 只能是 1 或 2，直接判断奇偶更简单。也可从 n 开始逐次加 n，找到偶数即停，本题最多尝试两次；若从 1 逐个枚举，则最坏需要 O(n) 次判断。

Java

class Solution {
    public int smallestEvenMultiple(int n) {
        return n % 2 == 0 ? n : 2 * n;
    }
}

JavaScript

/**
 * @param {number} n
 * @return {number}
 */
var smallestEvenMultiple = function(n) {
    return n % 2 === 0 ? n : 2 * n;
};

class Solution:
    def smallestEvenMultiple(self, n: int) -> int:
        return n if n % 2 == 0 else 2 * n

面试追问

  • 若把 2 换成任意正整数 m？使用 m / gcd(m,n) × n，先除后乘可以减少中间乘积溢出风险，但仍需足够宽的整数类型。
  • 为什么无需排序或搜索？候选按正倍数天然递增，本题前两个候选中必有偶数。
  • 可以用位运算吗？可以检查最低位；取模更直观，JavaScript 位运算还会转为 32 位整数，推广到大数时需留意。

常见错误

  • 无条件返回 2n：当 n 为偶数时结果不是最小值。
  • 返回 n + 2：加 2 不保证仍然是 n 的倍数。
  • 返回 0：虽然可被整除，但违反正整数要求。
  • 混淆最小公倍数与最大公约数：这里找的是共同倍数。
