将一个字符串排序的最小操作次数

每次只能排序一个非整串子串。别急着模拟排序：观察全局最小字符和最大字符落在首、尾或中间的何处，答案会被压缩到少数几种情况。

题意

给定只含小写字母的 s。一次操作可选择任意非空且不是整个字符串的子串，把该子串按非降序排序。求把整个字符串变成非降序的最少操作数；无论如何也做不到时返回 -1。

示例 A

s = "dog"

输出：1

示例 B

s = "card"

输出：2

示例 C

s = "gf"

输出：-1

约束：1 ≤ s.length ≤ 105。空格在本题输入中不会出现；若在下面体验区输入空格，会被当作无效字符提示。

题解

默认收起，避免首屏直接泄露解法。

核心洞察

  1. 若已非降序，什么都不做，答案是 0。
  2. 长度为 2 且未排序时，唯一长度为 2 的子串就是整串，不能选择，所以是 -1。
  3. 若首字符就是全局最小值，排序后缀即可；若尾字符就是全局最大值，排序前缀即可，答案是 1。
  4. 否则，若中间出现全局最小或最大字符，先借一次局部排序把极值送向边界，之后一次收尾，答案是 2。
  5. 剩下的未排序情形是最大值卡在首位、最小值卡在尾位且中间没有极值；长度至少 3 时可用三次局部排序完成。

复杂度与边界

一次扫描判断有序、极值及其位置，时间 O(n)，额外空间 O(1)。

  • 长度 1 已经有序。
  • 重复的最小/最大字符要按“是否存在于中间”判断。
  • 不能把“排序整串”误当合法操作。

替代方案与追问

可以枚举子串并搜索状态，但字符串长度达到 105 时不可行。追问：为何只需看最小、最大字符？因为排序操作只会在选中区间内部重排，能否让两端最终稳定决定了所需阶段数。

常见错误

  • 没先判“已排序”，会把 "ab" 错判成 -1。
  • 只检查首尾，不检查中间是否还有最小/最大字符，会把答案 2 误写成 3。
  • 以为一次排序可以选择整个字符串，违反题设。
