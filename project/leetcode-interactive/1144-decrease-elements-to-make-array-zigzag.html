Problem statement

题目要求

只允许递减，不允许增大或交换。

给定整数数组 nums。一次操作可以选择任意元素，将它的值减少 1。如果数组满足下面任一严格大小关系，它就是锯齿数组：

偶数下标为峰 A[0] > A[1] < A[2] > A[3] < …
奇数下标为峰 A[0] < A[1] > A[2] < A[3] > …

返回把 nums 变为任意一种锯齿形态所需的最少操作次数。

movesToMakeZigzag(nums: integer[]) → integer

示例 1

输入：nums = [1,2,3]
输出：2
解释：可将 2 减到 0，或将 3 减到 1。

示例 2

输入：nums = [9,6,1,6,2]
输出：4

约束

  • 1 <= nums.length <= 1000
  • 1 <= nums[i] <= 1000

Core insight

把两种节拍分开计算

固定一种形态后，只需处理充当“谷底”的那一组下标。对于谷底 i，它必须严格小于左右邻居，因此允许的最大值是较小邻居再减一。把它降到这个上限，恰好使用最少操作。

cost(i) = max(0, nums[i] − min(left, right) + 1)

分别令偶数下标为谷底、奇数下标为谷底，累加各自成本，最终取较小值。

完整过程

  1. 写一个辅助过程，参数 parity 表示谷底下标的奇偶性。
  2. 从 parity 开始，每次跳过两个位置。
  3. 读取左右邻居；不存在的邻居视为正无穷。
  4. 计算当前谷底必须递减的次数并累加。
  5. 返回两种奇偶方案成本的较小值。

为什么不必真的修改数组？

同一种方案中的谷底下标相隔 2，它们不会相邻；它们的直接邻居都是峰值，而峰值不需要递减。因此每个谷底的上限始终由原数组中的邻居决定，成本可以独立计算。

正确性证明

1
固定一种目标形态。设奇偶性为 p 的所有位置都是谷底。
2
单点下界。谷底 i 最终必须至多为 min(left, right) - 1，所以至少要递减公式给出的次数。
3
下界可达。把每个谷底恰好降到该上限即可满足它与所有现存邻居的严格关系；同奇偶谷底互不相邻，操作之间不会冲突。
4
全局最优。辅助过程达到固定形态的成本下界，所以对该形态最优。所有合法答案必属两种形态之一，取二者最小值即为全局最优。

复杂度

时间复杂度O(n)
额外空间O(1)

边界情况

  • 长度为 1：无需操作，答案为 0。
  • 端点只有一个邻居，缺失侧按正无穷处理。
  • 相邻元素相等时仍不合法，因为不等式必须严格成立。
  • 已经满足某种锯齿形态时，对应方案成本为 0。

替代方案

原地构造两份数组：可以复制数组并依次真的执行递减，再比较两种结果。它更直观，但需要 O(n) 额外空间；若逐次减一模拟，还会把时间浪费在数值大小上。

直接累计所需差值更简洁，也不会改变输入。

常见错误

  • 忘记“严格小于”，把目标写成 min(left, right)。
  • 只计算一种峰谷节拍，没有对两种方案取最小。
  • 处理端点时越界，或错误地把缺失邻居当成 0。
  • 同时递减峰值；这不会帮助相邻谷底更容易变小。

面试追问

如果允许增加元素呢？

局部选择会互相影响，当前的独立成本不再直接成立，需要重新设计状态或贪心顺序。

为什么谷底可以独立计算？

同一奇偶性的谷底不相邻；它们只共享某个峰值邻居，而我们不会修改峰值。

能否一次循环完成两种方案？

可以维护两个累计值，根据下标奇偶分别加入对应成本；辅助函数写法通常更容易审阅。

JavaScriptLeetCode submission
/**
 * @param {number[]} nums
 * @return {number}
 */
var movesToMakeZigzag = function(nums) {
    const cost = (parity) => {
        let moves = 0;

        for (let i = parity; i < nums.length; i += 2) {
            const left = i > 0 ? nums[i - 1] : Infinity;
            const right = i + 1 < nums.length ? nums[i + 1] : Infinity;
            const limit = Math.min(left, right) - 1;
            moves += Math.max(0, nums[i] - limit);
        }

        return moves;
    };

    return Math.min(cost(0), cost(1));
};

}

from typing import List


class Solution:
    def movesToMakeZigzag(self, nums: List[int]) -> int:
        def cost(parity: int) -> int:
            moves = 0

            for i in range(parity, len(nums), 2):
                left = nums[i - 1] if i > 0 else float("inf")
                right = nums[i + 1] if i + 1 < len(nums) else float("inf")
                limit = min(left, right) - 1
                moves += max(0, nums[i] - limit)

            return moves

        return min(cost(0), cost(1))
C++LeetCode submission
class Solution {
public:
    int movesToMakeZigzag(vector<int>& nums) {
        return min(cost(nums, 0), cost(nums, 1));
    }

private:
    int cost(const vector<int>& nums, int parity) {
        int moves = 0;

        for (int i = parity; i < static_cast<int>(nums.size()); i += 2) {
            int left = i > 0 ? nums[i - 1] : INT_MAX;
            int right = i + 1 < static_cast<int>(nums.size())
                ? nums[i + 1]
                : INT_MAX;
            int limit = min(left, right) - 1;
            moves += max(0, nums[i] - limit);
        }

        return moves;
    }
};
