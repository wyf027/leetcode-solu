最大二叉树 II

Maximum Binary Tree II
MEDIUM

给定由数组 a 构造出的最大二叉树 root，把互不重复的 val 追加到数组末尾得到 b，返回 Construct(b)。

题目理解

最大树的递归规则是：空数组得到空树；否则以数组最大值为根，最大值左侧构造左子树，右侧构造右子树。题目只给树，不给原数组。函数形式为 insertIntoMaxTree(root, val) → TreeNode。

示例 1

输入：root = [4,1,3,null,null,2], val = 5
输出：[5,4,null,1,3,null,null,2]
说明：a=[1,4,2,3]，b=[1,4,2,3,5]

示例 2

输入：root = [5,2,4,null,1], val = 3
输出：[5,2,4,null,1,null,3]
说明：a=[2,1,5,4]，b=[2,1,5,4,3]

示例 3

输入：root = [5,2,3,null,1], val = 4
输出：[5,2,4,null,1,3]
说明：a=[2,1,5,3]，b=[2,1,5,3,4]
约束：节点数为 1～100；Node.val 与 val 均为 1～100；树中原值互不相同，追加后仍互不相同。

题解默认折叠，先独立想一想右链与追加位置的关系。

题解：只走右链

核心洞察

val 被追加在原数组末尾，因此它不可能进入任何节点对应区间的左半部分。若 val > root.val，它是整个新数组最大值：新节点成为根，旧树整体成为其左子树。否则根保持不变，问题完全落到原根的右子树。

完整过程

  1. 若树为空，返回新节点。
  2. 若 val > root.val，令新节点的左孩子为 root 并返回。
  3. 否则递归插入 root.right，再返回 root。

正确性

归纳证明：空树显然成立。非空时，若新值大于根，追加后的数组最大值就是新值；它位于末尾，所以左侧正是完整原数组，构造结果必为“新值作根、旧树作左子树”。若新值小于根，最大值仍是原根；其左侧数组不变，右侧数组恰是原右侧数组末尾追加新值，递归假设保证右子树正确。因此返回的整棵树等于 Construct(b)。

复杂度

时间 O(h)，递归栈空间 O(h)；h 为树高，最坏 O(n)。

边界与常见错误

  • val 大于根时，旧树应接到新节点的左侧。
  • 只遍历右链；遍历整棵树或还原原数组都多余。
  • 递归返回值必须重新赋给 root.right。
  • 空右子树是正常终点，需创建新节点。

替代方案与面试追问

可迭代扫描右链，用指针记录父节点；遇到首个小于 val 的节点后，将其挂到新节点左边，再把新节点接到父节点右边。追问常见于：如何消除递归栈？若插入在数组任意位置为何不能只看右链？能否用笛卡尔树/单调栈从数组线性构造？

class Solution {
    public TreeNode insertIntoMaxTree(TreeNode root, int val) {
        if (root == null) return new TreeNode(val);
        if (val > root.val) return new TreeNode(val, root, null);
        root.right = insertIntoMaxTree(root.right, val);
        return root;
    }
}
