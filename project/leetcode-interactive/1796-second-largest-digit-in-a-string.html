字符串中第二大的数字

Second Largest Digit in a String

数字可以反复出现，但排名只留给不同的数字。

官方题目 ↗

01 / 题目

给定字符串 s，其中只有小写英文字母和数字。找出其中出现过的第二大的不同数字，并返回它的整数值；如果不同数字不足两个，返回 -1。例如，连续的数字字符仍各自代表一位数字，并不组成多位整数。

官方示例 1

输入：s = "dfa12321afd"
输出：2

不同数字为 1、2、3，第二大为 2。

官方示例 2

输入：s = "abc1111"
输出：-1

只有数字 1，多次出现不产生第二个名次。

约束与接口

  • 1 ≤ s.length ≤ 500
  • s 仅包含 a–z 和 0–9。
  • 参数：s: string；返回值：整数。方法名：secondHighest。

04 / 独立题解

核心洞察：只维护两个不同的最大值

扫描过的前缀中，只需保存最大值 first 与第二大值 second。两者初始均为 −1；数字范围是 0–9，因此 −1 可以安全表示空席位。

完整过程

  1. 读取字符；如果不是 ASCII 数字，直接跳过。
  2. 把数字字符转成整数 d。
  3. 若 d > first，先把旧的 first 移到 second，再更新 first。
  4. 否则，只有 second < d < first 时才更新 second；重复最大值和其他较小值均不改变状态。
  5. 遍历完成后返回 second，空席位自然返回 −1。

示例 1 的数字阶段：(−1,−1) → (1,−1) → (2,1) → (3,2)。后续 2 和 1 不改变这两个席位，最终返回 2。

正确性

循环不变式：每次处理完一个字符，first 与 second 分别是已扫描前缀中第一、第二大的不同数字，不存在的排名记为 −1。空前缀满足该性质。字母和无关重复值不影响排名；新最大值出现时，旧最大值恰好降到第二位；介于两席位之间的新值只替换第二位；其余值不可能进入前二。每种更新均保持不变式，因此扫描结束时 second 就是所求。

边界与常见错误

  • 没有数字或只有一种数字：返回 −1；重复次数不影响排名。
  • 0 是合法答案，不能用 0 表示不存在。
  • 不要把“第二次出现的最大数字”当作第二大不同数字。
  • 更新最大值时先保留旧 first，否则两个席位可能变成同一个数。
  • 第二个分支须排除 d == first，使用严格不等式。

复杂度

扫描 n 个字符：时间 O(n)，额外空间 O(1)。页面为了回放保存每一步状态，使用 O(n) 空间；这不是提交算法的空间开销。

替代方案

用长度为 10 的布尔数组标记出现的数字，再从 9 到 0 找第二个标记，时间 O(n + 10)、空间 O(10)，同样可视为 O(n) 与 O(1)。也可以用集合去重后降序排序，时间 O(n + k log k)、空间 O(k)，其中 k ≤ 10。

Java

class Solution {
    public int secondHighest(String s) {
        int first = -1, second = -1;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c < '0' || c > '9') continue;
            int d = c - '0';
            if (d > first) {
                second = first;
                first = d;
            } else if (d < first && d > second) {
                second = d;
            }
        }
        return second;
    }
}

面试追问

  • 如何找第 k 大不同数字？数字域只有 10 个，优先标记数组并倒序计数。
  • 输入是无限字符流怎么办？两个变量可增量更新，无需保存整个字符串。
  • 能提前停止吗？当 first = 9、second = 8 时可以，因为数字域不存在更大的第二名。
  • 若输入改为任意整数流？第二大仍可维护两个值，但需用空值或存在标记替代可能冲突的 −1 哨兵。
