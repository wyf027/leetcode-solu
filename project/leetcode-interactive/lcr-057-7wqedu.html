存在重复元素 III

是否存在两个不同下标 i, j，同时满足下标距离不超过 k，数值差不超过 t？把“近不近”交给长度为 k 的窗口，把“值像不像”交给桶。

一句话建模

窗口：遍历到 j 时，只保留 j 左侧最多 k 个元素，自动保证 |i-j| ≤ k。

桶宽：令 w = t + 1。同一桶中任意两个数的差都小于 w，故一定 ≤ t。

邻桶：只检查当前桶和左右相邻桶；更远桶的最小差已至少为 w。

t + 1 必须用更宽的整数类型：Java 用 long，避免 Integer.MAX_VALUE + 1 溢出。

1. 映射到桶

桶号是 floor(x / w)。负数必须向下取整，不能直接使用 Java 的整数除法。

2. 查三个桶

当前桶、左邻桶、右邻桶各至多一个元素；比对绝对差后即可提前返回。

3. 缩窗口

插入当前位置后，若窗口超过 k，就删除下标 j − k 所在元素的桶。

时间：O(n)，每个元素只进出窗口一次。

空间：O(min(n, k))，桶表最多保存窗口内元素。

面试追问清单

  • 为什么桶宽是 t + 1？因为同桶差值严格小于桶宽。
  • 为什么只看邻桶？两个相隔至少两个桶的数差值一定大于 t。
  • TreeSet 可以吗？可以，窗口内做 ceiling(x − t)，复杂度 O(n log k)。
  • 最容易错什么？负数桶号、t 溢出、删除窗口左端元素的时机。
