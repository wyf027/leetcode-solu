Problem

题目说明

给定一个由 0（空地）和 1（墙）组成的二维迷宫 maze，以及球的起点 start 和目标位置 destination。球可以向上、下、左、右滚动；一旦选择方向，球会一直滚到下一步将撞墙或越界时才停下。每经过一个空格计一单位路程。求球恰好停在目标位置的最短路程；若无法停在那里，返回 -1。

目标格可以被球经过，但只有球能够在该格停下时才算到达。返回的是滚过的格边数量，不是转弯次数。
shortestDistance(maze: integer[][], start: integer[], destination: integer[]) → integer

  • maze[i][j] 只能是 0 或 1
  • start.length == destination.length == 2
  • 起点与目标的行坐标均在 [0, m - 1] 内

  • start 与 destination 均位于空地，且初始位置不同

Solution

把停止点看作带权图节点

核心洞察

球只能在撞墙前的最后一个空格做下一次决策。因此，真正的状态是“停止点”，从一个停止点沿四个方向滚动，会得到至多四条边；边权等于本次滚过的格数。边权均为正，问题就变成带非负权图上的单源最短路。

完整过程

  1. 将所有格的最短距离初始化为无穷大，起点距离设为 0，并压入最小堆。
  2. 每次取出堆中距离最小的停止点；若该记录已过期则跳过。
  3. 向四个方向持续滚动，直到下一步会撞墙或越界，得到新停止点和本段长度。
  4. 若“当前距离 + 本段长度”更小，就更新新停止点并压入堆。
  5. 目标第一次以有效最短距离出堆时即可返回；堆空仍未到达则返回 -1。

正确性说明

每次滚动都准确对应停止点图中的一条边，边权正是该次移动路程，所以原题合法路线与图中路径一一对应，且总路程相同。算法始终取出当前未确定节点中暂定距离最小者；由于所有边权非负，之后任何绕行都不可能得到更短距离。因此每个有效出堆距离都已最优，目标出堆时得到的就是全局最短路程。若堆耗尽，所有从起点可达的停止点均已处理，目标不可达。

边界与细节

  • 目标可能位于滚动路径中间；经过不等于到达。
  • 某方向一步也不能走时，不生成有效新边。
  • 同一格可能多次入堆，出堆时必须丢弃过期距离。
  • 边界等价于墙，滚动不能离开矩阵。
  • 即使终点已被松弛，也应等它以有效最短距离出堆后再返回。
时间复杂度 O(mn · max(m,n) + mn log(mn)) 朴素滚动时，每个停止点的四个方向最多扫描一整行或一整列。
空间复杂度 O(mn) 距离矩阵与最小堆至多保存与空格数同阶的状态。

替代方案

  • 队列式松弛（SPFA 风格）通常也能得到答案，但最坏复杂度和性能稳定性较差。
  • 普通 BFS 不适用：每次滚动的边权不一定为 1，先遇到目标不保证路程最短。
  • 可预处理每个格子四个方向的停止点与距离，减少重复滚动扫描，代价是额外空间和实现复杂度。
  • A* 可用到目标的曼哈顿距离作为不高估的启发式，但本题规模下 Dijkstra 更直接。

面试追问

  • 如果只问最少转弯次数，图的边权应如何定义？
  • 如何返回一条具体最短路径，而不只是距离？
  • 若迷宫频繁查询不同起终点，如何预处理滚动结果？
  • 为什么曼哈顿距离可作 A* 启发式？它是否始终一致？

常见错误

  • 每滚动一次就把距离加 1，误把路程当成操作次数。
  • 球一经过目标就返回，没有确认它能在目标停止。
  • 使用普通 FIFO 队列并在首次访问后永久标记，错过更短路径。
  • 滚动循环多走到墙上再回退时，步数补偿出错。
  • 忽略堆中的陈旧条目，造成大量重复计算或错误提前返回。

一句话记忆

格子不是每一步状态，停止点才是；滚动长度不是 1，必须按权值求最短路。

四语言完整代码

import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int shortestDistance(int[][] maze, int[] start, int[] destination) {
        int m = maze.length;
        int n = maze[0].length;
        int[][] dist = new int[m][n];
        for (int[] row : dist) {
            Arrays.fill(row, Integer.MAX_VALUE);
        }

        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        PriorityQueue<int[]> minHeap =
                new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));

        dist[start[0]][start[1]] = 0;
        minHeap.offer(new int[] {0, start[0], start[1]});

        while (!minHeap.isEmpty()) {
            int[] current = minHeap.poll();
            int distance = current[0];
            int row = current[1];
            int col = current[2];

            if (distance != dist[row][col]) {
                continue;
            }
            if (row == destination[0] && col == destination[1]) {
                return distance;
            }

            for (int[] direction : directions) {
                int nextRow = row;
                int nextCol = col;
                int steps = 0;

                while (isOpen(maze, nextRow + direction[0], nextCol + direction[1])) {
                    nextRow += direction[0];
                    nextCol += direction[1];
                    steps++;
                }

                int candidate = distance + steps;
                if (steps > 0 && candidate < dist[nextRow][nextCol]) {
                    dist[nextRow][nextCol] = candidate;
                    minHeap.offer(new int[] {candidate, nextRow, nextCol});
                }
            }
        }

        return -1;
    }

    private boolean isOpen(int[][] maze, int row, int col) {
        return row >= 0
                && row < maze.length
                && col >= 0
                && col < maze[0].length
                && maze[row][col] == 0;
    }
}
/**
 * @param {number[][]} maze
 * @param {number[]} start
 * @param {number[]} destination
 * @return {number}
 */
var shortestDistance = function (maze, start, destination) {
    const rows = maze.length;
    const cols = maze[0].length;
    const dist = Array.from({ length: rows }, () => Array(cols).fill(Infinity));
    const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];

    const heap = new MinHeap();
    dist[start[0]][start[1]] = 0;
    heap.push([0, start[0], start[1]]);

    while (heap.size > 0) {
        const [distance, row, col] = heap.pop();
        if (distance !== dist[row][col]) continue;
        if (row === destination[0] && col === destination[1]) return distance;

        for (const [dr, dc] of directions) {
            let nextRow = row;
            let nextCol = col;
            let steps = 0;

            while (
                nextRow + dr >= 0 &&
                nextRow + dr < rows &&
                nextCol + dc >= 0 &&
                nextCol + dc < cols &&
                maze[nextRow + dr][nextCol + dc] === 0
            ) {
                nextRow += dr;
                nextCol += dc;
                steps++;
            }

            const candidate = distance + steps;
            if (steps > 0 && candidate < dist[nextRow][nextCol]) {
                dist[nextRow][nextCol] = candidate;
                heap.push([candidate, nextRow, nextCol]);
            }
        }
    }

    return -1;
};

class MinHeap {
    constructor() {
        this.data = [];
    }

    get size() {
        return this.data.length;
    }

    push(value) {
        this.data.push(value);
        let index = this.data.length - 1;
        while (index > 0) {
            const parent = Math.floor((index - 1) / 2);
            if (this.data[parent][0] <= this.data[index][0]) break;
            [this.data[parent], this.data[index]] = [this.data[index], this.data[parent]];
            index = parent;
        }
    }

    pop() {
        const result = this.data[0];
        const last = this.data.pop();
        if (this.data.length === 0) return result;
        this.data[0] = last;

        let index = 0;
        while (true) {
            let smallest = index;
            const left = index * 2 + 1;
            const right = index * 2 + 2;

            if (left < this.data.length && this.data[left][0] < this.data[smallest][0]) {
                smallest = left;
            }
            if (right < this.data.length && this.data[right][0] < this.data[smallest][0]) {
                smallest = right;
            }
            if (smallest === index) break;
            [this.data[index], this.data[smallest]] = [this.data[smallest], this.data[index]];
            index = smallest;
        }

        return result;
    }
}
from typing import List
import heapq


class Solution:
    def shortestDistance(
        self,
        maze: List[List[int]],
        start: List[int],
        destination: List[int],
    ) -> int:
        rows, cols = len(maze), len(maze[0])
        distances = [[float("inf")] * cols for _ in range(rows)]
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

        distances[start[0]][start[1]] = 0
        min_heap = [(0, start[0], start[1])]

        while min_heap:
            distance, row, col = heapq.heappop(min_heap)
            if distance != distances[row][col]:
                continue
            if [row, col] == destination:
                return distance

            for dr, dc in directions:
                next_row, next_col = row, col
                steps = 0

                while (
                    0 <= next_row + dr < rows
                    and 0 <= next_col + dc < cols
                    and maze[next_row + dr][next_col + dc] == 0
                ):
                    next_row += dr
                    next_col += dc
                    steps += 1

                candidate = distance + steps
                if steps > 0 and candidate < distances[next_row][next_col]:
                    distances[next_row][next_col] = candidate
                    heapq.heappush(min_heap, (candidate, next_row, next_col))

        return -1

class Solution {

    int shortestDistance(
        vector<vector<int>>& maze,
        vector<int>& start,
        vector<int>& destination
    ) {
        const int rows = maze.size();
        const int cols = maze[0].size();
        vector<vector<int>> dist(rows, vector<int>(cols, INT_MAX));
        const array<array<int, 2>, 4> directions = {{{1, 0}, {-1, 0}, {0, 1}, {0, -1}}};

        using State = tuple<int, int, int>;
        priority_queue<State, vector<State>, greater<State>> minHeap;
        dist[start[0]][start[1]] = 0;
        minHeap.emplace(0, start[0], start[1]);

        while (!minHeap.empty()) {
            auto [distance, row, col] = minHeap.top();
            minHeap.pop();

            if (distance != dist[row][col]) {
                continue;
            }
            if (row == destination[0] && col == destination[1]) {
                return distance;
            }

            for (const auto& direction : directions) {
                int nextRow = row;
                int nextCol = col;
                int steps = 0;

                while (
                    nextRow + direction[0] >= 0 &&
                    nextRow + direction[0] < rows &&
                    nextCol + direction[1] >= 0 &&
                    nextCol + direction[1] < cols &&
                    maze[nextRow + direction[0]][nextCol + direction[1]] == 0
                ) {
                    nextRow += direction[0];
                    nextCol += direction[1];
                    steps++;

                const int candidate = distance + steps;
                if (steps > 0 && candidate < dist[nextRow][nextCol]) {
                    dist[nextRow][nextCol] = candidate;
