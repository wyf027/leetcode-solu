统计点对的数目Count Pairs Of Nodes

给定一个允许多重边的无向图，回答每个阈值下，有多少节点对连接到的不同边总数严格超过该阈值。

困难图计数排序双指针哈希表
Problem

先把“关联边”数清楚

一条同时连接 a 与 b 的边只能计入一次；多重边仍是多条独立的边。这一细节决定了题目的难度。

题意

图有 n 个节点，编号 1 到 n。每个 edges[i] = [uᵢ,vᵢ] 表示一条无向边，同一对节点之间可以出现多条边。

incident(a,b) = 与 a 或 b 相连的边数

对每个 queries[j]，统计满足 a < b 且 incident(a,b) > queries[j] 的节点对数量，并按查询顺序返回答案数组。

约束与签名

2 ≤ n ≤ 2 × 10⁴
1 ≤ edges.length ≤ 10⁵
1 ≤ uᵢ,vᵢ ≤ n，且 uᵢ ≠ vᵢ
1 ≤ queries.length ≤ 20
0 ≤ queries[j] < edges.length
函数：countPairs(n, edges, queries) → integer[]

Solution

核心洞察：先多算，再精准撤销

记节点 x 的度数为 deg[x]，节点对 (x,y) 间的边数为 shared[x,y]。度数相加时，两端之间的每条边被算了两次，而题目要求“与 x 或 y 相连”，它只能出现一次。

incident(x,y) = deg[x] + deg[y] - shared[x,y]

先忽略减项：排序全部度数后，用双指针统计 deg[x]+deg[y]>q。再只检查真正相邻的节点对；若某对通过初筛，却在减去公共边后不再严格大于 q，就从答案减一。

完整过程

  1. 扫描 edges，统计每个节点度数，并用哈希表统计每个无序节点对的多重边数。
  2. 复制度数数组并升序排序。
  3. 对每个 q 使用左右指针。若 sorted[l]+sorted[r]>q，则 l 到 r−1 都能与 r 配对，一次加入 r-l 并左移 r；否则右移 l。
  4. 枚举哈希表中的相邻点对 (x,y)。当 deg[x]+deg[y]>q 且 deg[x]+deg[y]-shared[x,y]≤q，答案减一。
  5. 按查询原顺序写入结果。
为什么只修正相邻点对？

不相邻时 shared=0，初筛值就是真实关联边数；只有 shared>0 的点对可能被多算。

正确性证明

1

初筛完整。 双指针恰好统计所有度数和大于 q 的无序节点对，每对只进入一次。

2

误差范围完整。 不相邻点对 shared=0，初筛条件与真实条件等价；相邻点对的真实值只可能小于初筛值。

3

修正精确。 哈希表将每个相邻无序点对枚举一次。初筛成立而真实条件失败时减一，恰好删除该假阳性。

4

结论。 修正后保留且仅保留所有满足 incident(x,y)>q 的点对，所以每个答案正确。

边界与复杂度

  • 严格大于：真实值等于 q 时不能计入。
  • 多重边必须保存出现次数，不能只记录是否相邻。
  • q 可以为 0；n 很大，不能枚举全部 O(n²) 点对。
  • 最大答案 n(n−1)/2 在本题范围内可用 32 位有符号整数。

设 m 为边数、Q 为查询数、P 为不同相邻节点对数。时间 O(m+n log n+Q(n+P))，空间 O(n+P)。

import java.util.*;

class Solution {
    public int[] countPairs(int n, int[][] edges, int[] queries) {
        int[] degree = new int[n];
        Map<Long, Integer> shared = new HashMap<>();
        for (int[] edge : edges) {
            int u = edge[0] - 1, v = edge[1] - 1;
            degree[u]++;
            degree[v]++;
            int a = Math.min(u, v), b = Math.max(u, v);
            long key = (long) a * n + b;
            shared.merge(key, 1, Integer::sum);
        }

        int[] sorted = degree.clone();
        Arrays.sort(sorted);
        int[] answer = new int[queries.length];

        for (int qi = 0; qi < queries.length; qi++) {
            int q = queries[qi], left = 0, right = n - 1, count = 0;
            while (left < right) {
                if (sorted[left] + sorted[right] > q) {
                    count += right - left;
                    right--;
                } else {
                    left++;
                }
            }
            for (Map.Entry<Long, Integer> entry : shared.entrySet()) {
                long key = entry.getKey();
                int u = (int) (key / n), v = (int) (key % n);
                int sum = degree[u] + degree[v];
                if (sum > q && sum - entry.getValue() <= q) count--;
            }
            answer[qi] = count;
        }
        return answer;
    }
}

/**
 * @param {number} n
 * @param {number[][]} edges
 * @param {number[]} queries
 * @return {number[]}
 */
var countPairs = function(n, edges, queries) {
    const degree = new Array(n).fill(0);
    const shared = new Map();
    for (const [from, to] of edges) {
        const u = from - 1, v = to - 1;
        degree[u]++;
        degree[v]++;
        const a = Math.min(u, v), b = Math.max(u, v);
        const key = a * n + b;
        shared.set(key, (shared.get(key) || 0) + 1);
    }

    const sorted = [...degree].sort((a, b) => a - b);
    const answer = [];
    for (const q of queries) {
        let left = 0, right = n - 1, count = 0;
        while (left < right) {
            if (sorted[left] + sorted[right] > q) {
                count += right - left;
                right--;
            } else {
                left++;
            }
        }
        for (const [key, multiplicity] of shared) {
            const u = Math.floor(key / n), v = key % n;
            const sum = degree[u] + degree[v];
            if (sum > q && sum - multiplicity <= q) count--;
        }
        answer.push(count);
    }
    return answer;
};
官方签名 · JavaScript
from collections import Counter
from typing import List


class Solution:
    def countPairs(
        self,
        n: int,
        edges: List[List[int]],
        queries: List[int]
    ) -> List[int]:
        degree = [0] * n
        shared = Counter()
        for x, y in edges:
            u, v = x - 1, y - 1
            degree[u] += 1
            degree[v] += 1
            if u > v:
                u, v = v, u
            shared[(u, v)] += 1

        sorted_degree = sorted(degree)
        answer = []
        for q in queries:
            left, right, count = 0, n - 1, 0
            while left < right:
                if sorted_degree[left] + sorted_degree[right] > q:
                    count += right - left
                    right -= 1
                else:
                    left += 1

            for (u, v), multiplicity in shared.items():
                degree_sum = degree[u] + degree[v]
                if degree_sum > q >= degree_sum - multiplicity:
                    count -= 1
            answer.append(count)
        return answer
官方签名 · Python 3
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> countPairs(
        int n,
        vector<vector<int>>& edges,
        vector<int>& queries
    ) {
        vector<int> degree(n);
        unordered_map<long long, int> shared;
        for (const auto& edge : edges) {
            int u = edge[0] - 1, v = edge[1] - 1;
            degree[u]++;
            degree[v]++;
            if (u > v) swap(u, v);
            shared[1LL * u * n + v]++;
        }

        vector<int> sortedDegree = degree;
        sort(sortedDegree.begin(), sortedDegree.end());
        vector<int> answer;
        for (int q : queries) {
            int left = 0, right = n - 1, count = 0;
            while (left < right) {
                if (sortedDegree[left] + sortedDegree[right] > q) {
                    count += right - left;
                    right--;
                } else {
                    left++;
                }
            }
            for (const auto& item : shared) {
                long long key = item.first;
                int u = key / n, v = key % n;
                int sum = degree[u] + degree[v];
                if (sum > q && sum - item.second <= q) count--;
            }
            answer.push_back(count);
        }
        return answer;
    }
};

替代方案

每个节点做二分

在排序数组中二分首个和大于 q 的位置，再排除自身。复杂度 O(Qn log n)，细节更多，通常不如双指针。

枚举全部点对

直接计算每个 (x,y) 的 incident，复杂度 O(Qn²)，只适合极小数据或作为对拍参考。

面试追问

排序后节点身份丢失，为什么不影响初筛？

初筛只依赖两个度数之和；需要身份的公共边修正仍使用原 degree 和节点对哈希表。

queries 很多时哪里最慢？

每个查询扫描 n 个度数和 P 个相邻点对。可研究离线查询、度数频次或按阈值组织修正事件；本题 Q≤20，当前方案更稳妥。

哈希键为何可用 u×n+v？

规范为 0≤u<v<n 后映射唯一；解码时分别整除 n 和取模 n。

常见错误

  • 直接把 deg[x]+deg[y] 当真实值，忘记减公共边。
  • 把多重边集合化，导致 shared 只记 1。
  • 修正条件使用 sum-shared<q，遗漏等于 q；题目要求严格大于。
  • 满足双指针条件时只加 1，错过整段 right-left 个点对。
  • 没有规范化端点顺序，使 (u,v) 与 (v,u) 分裂。
  • 为每个查询重新排序；度数不随查询变化，只需排序一次。
