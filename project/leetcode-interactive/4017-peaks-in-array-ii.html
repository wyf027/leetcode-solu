4017. 数组中的峰值 II

动态更新下，统计区间内「内部含峰」的子数组数量。

打开题目
n, q
均可达 10⁵
峰
严格大于左右邻居
目标
含至少一个内部峰的子数组

题意：峰属于子数组内部

查询 [1,l,r] 问的是完全落在 nums[l..r] 的、长度至少为 3 的子数组中，有多少个存在 i < k < j 且 nums[k] 大于相邻两数。更新 [2,index,val] 会影响后续查询。

容易混淆：不是数峰的个数；一个峰可使许多不同左右端点的子数组成立。

例子

[1,3,2,4] 在 [0,3] 中：[1,3,2] 与 [1,3,2,4] 都由位置 1 的峰成立，答案是 2。

交互实验室

修改数组或执行查询。黄色格是当前全局峰；范围查询仅把 l+1..r-1 的峰交给线段树。

准备就绪。

题解

核心推导、完整过程、边界、取舍与四语言实现默认收起。

核心洞察：按最左峰唯一归属

把一个合格子数组归给其中最左的峰。若查询区间 [l,r] 的内部峰依次为 p₁,p₂,…，答案是 (p₁-l)(r-p₁)+Σ(p-prev(p))(r-p)。线段树摘要保存峰数、首尾峰、相邻距离和 Σd 与 Σ(d·p) 即可计算。

过程：可合并的线段树摘要

每个节点保存 {count, first, last, sumD, sumDP}。合并左右节点时，若两边都有峰，新增跨边相邻对： 

d = right.first - left.last
sumD  += d
sumDP += d * right.first

点更新只可能让 index-1, index, index+1 的峰状态改变；逐一重算叶子后向上合并。范围查询把节点摘要按顺序合并，首峰的“前驱”无需存储，公式会用 l 覆盖它。

边界与复杂度

  • r-l<2：没有长度 ≥ 3 的子数组，答案为 0。
  • 查询结果没有峰：摘要 count=0，答案为 0。
  • 端点本身不能当内部峰，查询范围固定为 [l+1,r-1]。
  • 相等不算峰，条件必须使用严格 >。
操作 复杂度
建树 O(n)
更新 O(log n)
查询 O(log n)
空间 O(n)

  static class BIT { long[] a; BIT(int n){a=new long[n+2];} void add(int i,long v){for(i++;i<a.length;i+=i&-i)a[i]+=v;} long sum(int i){long r=0;for(i++;i>0;i-=i&-i)r+=a[i];return r;} long get(int l,int r){return l>r?0:sum(r)-sum(l-1);} }
  public long[] countOfPeaks(int[] nums, int[][] queries) {
    int n=nums.length; java.util.TreeSet<Integer> s=new java.util.TreeSet<>(); BIT d=new BIT(n), dp=new BIT(n);
    java.util.function.IntPredicate peak=i->i>0&&i+1<n&&nums[i]>nums[i-1]&&nums[i]>nums[i+1];
    class Edit { void go(int x,boolean on){ boolean had=s.contains(x); if(had==on)return; Integer p=s.lower(x), z=on?s.ceiling(x):s.higher(x); if(on){long dx=p==null?0:x-p; s.add(x);d.add(x,dx);dp.add(x,dx*x);if(z!=null){long old=p==null?0:z-p, now=z-x;d.add(z,now-old);dp.add(z,(now-old)*z);}}else{long old=p==null?0:x-p;d.add(x,-old);dp.add(x,-old*x);s.remove(x);if(z!=null){long was=z-x, now=p==null?0:z-p;d.add(z,now-was);dp.add(z,(now-was)*z);}}} }
    Edit edit=new Edit(); for(int i=1;i+1<n;i++)if(peak.test(i))edit.go(i,true); java.util.ArrayList<Long> out=new java.util.ArrayList<>();
    for(int[] q:queries)if(q[0]==2){nums[q[1]]=q[2];for(int i=q[1]-1;i<=q[1]+1;i++)if(i>0&&i+1<n)edit.go(i,peak.test(i));}else{int l=q[1],r=q[2],L=l+1,R=r-1;Integer f=s.ceiling(L);if(L>R||f==null||f>R){out.add(0L);continue;}Integer p=s.lower(f);long old=p==null?0:f-p, delta=(f-l)-old;out.add((long)r*(d.get(L,R)+delta)-(dp.get(L,R)+delta*f));}
    long[] ans=new long[out.size()];for(int i=0;i<ans.length;i++)ans[i]=out.get(i);return ans;
  }
}

Python 
class Solution:
    def countOfPeaks(self, nums: list[int], queries: list[list[int]]) -> list[int]:
        n=len(nums); t=[(0,-1,-1,0,0)]*(4*n)
        def join(a,b):
            c=a[0]+b[0]
            if not c:return (0,-1,-1,0,0)
            f=a[1] if a[0] else b[1]; z=b[2] if b[0] else a[2]; sd=a[3]+b[3]; sp=a[4]+b[4]
            if a[0] and b[0]: d=b[1]-a[2]; sd+=d; sp+=d*b[1]
            return c,f,z,sd,sp
        def pk(i): return 0<i<n-1 and nums[i]>nums[i-1] and nums[i]>nums[i+1]
        def put(p,l,r,i):
            if l==r: t[p]=(1,i,i,0,0) if pk(i) else (0,-1,-1,0,0); return
            m=(l+r)//2
            if i<=m: put(2*p,l,m,i)
            else: put(2*p+1,m+1,r,i)
            t[p]=join(t[2*p],t[2*p+1])
        def get(p,l,r,L,R):
            if L<=l and r<=R:return t[p]
            m=(l+r)//2
            if R<=m:return get(2*p,l,m,L,R)
            if L>m:return get(2*p+1,m+1,r,L,R)
            return join(get(2*p,l,m,L,R),get(2*p+1,m+1,r,L,R))
        for i in range(n): put(1,0,n-1,i)
        ans=[]
        for typ,x,y in queries:
            if typ==2:
                nums[x]=y
                for i in range(max(0,x-1),min(n,x+2)): put(1,0,n-1,i)
            elif y-x<2: ans.append(0)
            else:
                c,f,_,sd,sp=get(1,0,n-1,x+1,y-1); ans.append(0 if not c else (f-x)*(y-f)+y*sd-sp)
        return ans

替代方案与取舍

有序集合 + 两棵 Fenwick：维护峰位置及 d、d·p 的前缀和，也能 O(log n)，但更新插删峰时需细心修复后继峰的 d。线段树把相邻关系封装在 merge 中，代码更统一。

常见错误

  • 把所有含同一峰的区间直接相加，重复计数。
  • 把 l/r 本身纳入峰集合。
  • 更新后只检查 index，漏掉两侧。
  • 用 32 位整数保存乘积。

追问

  1. 若“至少一个峰”改成“恰好一个峰”，摘要还要增加什么？
  2. 若查询改为返回所有峰位置，线段树节点如何保存输出？
  3. 为什么按最左峰归属不会漏掉任何合格子数组？
