信封问题

给定若干不允许旋转的信封。只有当外层信封的宽和高都严格更大时，内层信封才能放进去。求一条嵌套链最多包含多少个信封。

>
两个维度都必须严格增大
相等不算更大；宽或高任一维不满足，就不能嵌套。信封也不能旋转。
↓先读题，再进入可视化实验
01 · Problem

题目说明

参数 envelopes[i] = [wᵢ, hᵢ] 表示第 i 个信封的宽和高。返回能组成俄罗斯套娃的最大信封数量。

如果信封 A 能放进信封 B，则必须同时满足 A.width < B.width 与 A.height < B.height。顺序可以重新安排，但任何信封都不能旋转。
Example 01
输入：envelopes = [[5,4],[6,4],[6,7],[2,3]]
输出：3
解释：[2,3] → [5,4] → [6,7]
Example 02
输入：envelopes = [[1,1],[1,1],[1,1]]
输出：1

约束

  • 1 ≤ envelopes.length ≤ 10⁵
  • envelopes[i].length == 2
  • 1 ≤ wᵢ, hᵢ ≤ 10⁵
函数签名：
maxEnvelopes(envelopes) → integer

03 · Solution

二维偏序，化为一维 LIS

困难之处不是写二分，而是处理“宽度相等”的信封：它们绝不能进入同一条合法链。

排序规则 宽度升序；宽度相同时，高度降序

核心洞察

排序后，后面的信封宽度不会更小。再对高度求严格最长上升子序列（LIS），就能同时满足两个维度严格增长。

为何同宽要按高度降序？

若同宽高度升序，它们会被高度 LIS 错选为递增链。改成降序后，同宽信封的高度不可能在严格上升子序列中连续出现。

完整过程

  1. 按 (width ↑, height ↓) 排序。
  2. 维护数组 tails，其中 tails[k] 是长度 k+1 的递增子序列可达到的最小尾部高度。
  3. 对每个高度，用二分找到第一个大于等于它的位置并替换；若不存在则追加。
  4. 最终 tails.length 就是答案。

边界情况

  • 只有一个信封：答案为 1。
  • 所有信封完全相同：答案仍为 1。
  • 宽度递增但高度递减：无法形成长度大于 1 的链。
  • 重复高度使用 lower_bound(≥)，保证 LIS 严格增长。

正确性证明

  1. 合法链一定对应严格递增的高度子序列。 排序后，任意合法嵌套链的宽度本就严格递增，因此其顺序与排序顺序一致；合法性又要求高度严格递增，所以它会出现在高度序列的某个严格递增子序列中。
  2. 高度 LIS 不会选择两个同宽信封。 同宽组内高度按降序排列，较早元素的高度不小于较晚元素，二者无法同时属于严格递增的高度子序列。
  3. 任意高度 LIS 都对应合法嵌套链。 LIS 中高度严格递增；由上一步知它不会选两个同宽信封，而整体宽度已升序，所以被选信封的宽度也严格递增。两个维度都满足，链合法。
  4. 结论。 合法链可映射到高度递增子序列，反之亦然；二者最大长度相同。耐心排序二分过程正确求得 LIS 长度，故算法返回最优答案。

四语言完整实现

代码遵循官方函数签名，二分均寻找第一个 ≥ 当前高度 的位置。

import java.util.Arrays;

class Solution {
    public int maxEnvelopes(int[][] envelopes) {
        Arrays.sort(envelopes, (a, b) -> {
            if (a[0] != b[0]) {
                return Integer.compare(a[0], b[0]);
            }
            return Integer.compare(b[1], a[1]);
        });

        int[] tails = new int[envelopes.length];
        int size = 0;

        for (int[] envelope : envelopes) {
            int height = envelope[1];
            int left = 0;
            int right = size;

            while (left < right) {
                int mid = left + (right - left) / 2;
                if (tails[mid] < height) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }

            tails[left] = height;
            if (left == size) {
                size++;
            }
        }

        return size;
    }
}
/**
 * @param {number[][]} envelopes

var maxEnvelopes = function(envelopes) {
    envelopes.sort((a, b) => {
        if (a[0] !== b[0]) return a[0] - b[0];
        return b[1] - a[1];
    });

    const tails = [];

    for (const [, height] of envelopes) {
        let left = 0;
        let right = tails.length;

        while (left < right) {
            const mid = left + Math.floor((right - left) / 2);
            if (tails[mid] < height) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        tails[left] = height;
    }

    return tails.length;
};
from typing import List


class Solution:
    def maxEnvelopes(self, envelopes: List[List[int]]) -> int:
        envelopes.sort(key=lambda envelope: (envelope[0], -envelope[1]))
        tails: List[int] = []

        for _, height in envelopes:
            left, right = 0, len(tails)

            while left < right:
                mid = left + (right - left) // 2
                if tails[mid] < height:
                    left = mid + 1
                else:
                    right = mid

            if left == len(tails):
                tails.append(height)
            else:
                tails[left] = height

        return len(tails)
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maxEnvelopes(vector<vector<int>>& envelopes) {
        sort(envelopes.begin(), envelopes.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 if (a[0] != b[0]) return a[0] < b[0];
                 return a[1] > b[1];
             });

        vector<int> tails;

        for (const vector<int>& envelope : envelopes) {
            int height = envelope[1];
            auto position = lower_bound(tails.begin(), tails.end(), height);

            if (position == tails.end()) {
                tails.push_back(height);
            } else {
                *position = height;
            }
        }

        return static_cast<int>(tails.size());
    }
};

替代方案与取舍

二维动态规划

排序后令 dp[i] 表示以 i 结尾的最长合法链，枚举所有 j < i 转移。直观、容易恢复路径，但时间复杂度 O(n²)，无法承受 n = 10⁵。

线段树 / 树状数组

将高度离散化后做前缀最大值，也能达到 O(n log n)。适合继续扩展计数或区间查询，但本题只求长度时，tails 更短、更清晰。

面试追问

  • 如何恢复一条实际的最长嵌套链？记录每个元素的前驱和 tails 对应下标。
  • 若允许旋转信封怎么办？先规范化每个信封的两边，再应用相同二维偏序思路。
  • 若要求最长链数量？单纯 tails 不足，需要按长度维护计数并处理重复状态。
  • 为何二分用 lower_bound 而不是 upper_bound？因为高度必须严格增长，相等值要替换而不能延长。

常见错误

  • 同宽时仍按高度升序，导致选入两个宽度相等的信封。
  • 把“宽和高都更大”误写成任一维更大。
  • 二分寻找第一个大于当前高度的位置，错误地允许重复高度增长。
  • 误以为 tails 本身始终是原数组中的一条可恢复路径；它首先是长度证明与最优尾部状态。
