题目

函数：outerTrees(trees)

给定二维整数数组 trees，其中 trees[i] = [xᵢ, yᵢ] 表示花园里一棵树的位置。请用最短的封闭围栏包围全部树木，并返回所有恰好位于围栏边界上的树坐标。

返回顺序不限。位于同一条围栏边上的共线树也必须全部返回；当所有树共线时，所有树都在边界上。

约束

  • 1 <= trees.length <= 3000
  • trees[i].length == 2
  • 0 <= xᵢ, yᵢ <= 100
  • 所有坐标互不相同

官方示例

示例 1一棵树在内部
输入：trees = [[1,1],[2,2],[2,0],[2,4],[3,3],[4,2]]
输出：[[1,1],[2,0],[4,2],[3,3],[2,4]]
解释：除 [2,2] 外，其余树都位于围栏边界。
示例 2全部共线
输入：trees = [[1,2],[2,2],[4,2]]
输出：[[4,2],[2,2],[1,2]]
解释：围栏退化为一条经过所有树的线段。

Solution

题解：单调链凸包

核心洞察

围栏就是所有点的凸包边界。本题与只求凸包顶点不同：同一条边上的树也算围栏点，所以只有出现严格顺时针转弯时才移除中间点；叉积等于 0 的共线点必须保留。

先按 x 升序、再按 y 升序排列点。正向扫描得到下边界，反向扫描得到上边界，最后去重合并两条链。

cross(a, b, c) = (b.x − a.x)(c.y − a.y) − (b.y − a.y)(c.x − a.x)
  • cross > 0：从 a → b → c 逆时针转弯。
  • cross < 0：顺时针转弯，当前链尾部的 b 不应保留。
  • cross = 0：三点共线；本题保留 b。

完整过程

  1. 若点数不超过 1，直接返回。
  2. 将所有点按 (x, y) 排序。
  3. 从左到右扫描。只要链末尾两点与当前点构成严格顺时针转弯，就持续弹出链尾；随后压入当前点，形成下边界。
  4. 从右到左用完全相同的规则扫描，形成上边界。
  5. 把上下边界放入集合去重后返回。去重处理两端点以及全体共线时的重复。

正确性证明

引理 1：弹出的点不需要出现在当前半边界上

设链尾为 a, b，当前点为 c。若 cross(a,b,c) < 0，路径 a → b → c 是顺时针转弯，b 位于线段 ac 对当前半边界的内侧。以 ac 替换这段折线仍能覆盖已扫描点，且不会遗漏该半边界，因此弹出 b 是安全的。

引理 2：每条凸包边上的共线点都会保留

当三点共线时叉积为 0。算法的弹出条件是严格小于 0，因此共线的链尾点不会被移除。正反两次扫描覆盖凸包的上下两部分，所以任意凸包边上的共线点至少进入其中一条链。

引理 3：合并结果中没有内部点

每条链在扫描结束后都不存在严格顺时针转弯，是包住相应半平面所有已扫描点的最外层链。严格位于凸包内部的点必然在构造至少一条链时造成不符合外边界方向的转弯并被移除，也不会同时属于最终上下边界。

结论

由引理 2，所有围栏边界点都被返回；由引理 3，没有内部点被返回。集合只消除重复坐标，不改变成员，因此算法返回的恰好是全部围栏边界树木。

复杂度

时间：O(n log n)，排序占主导；每个点在每条链中至多进出一次。

空间：O(n)，用于排序、上下链和答案集合。

边界情况

  • 只有一个点：直接返回。
  • 所有点共线：全部保留，合并时去重。
  • 多点位于同一条凸包边：叉积为 0，不弹出。
  • 坐标乘积可能放大：Java 的叉积使用 long。

import java.util.*;

class Solution {
    public int[][] outerTrees(int[][] trees) {
        if (trees.length <= 1) return trees;

        Arrays.sort(trees, (a, b) ->
            a[0] == b[0] ? Integer.compare(a[1], b[1])
                         : Integer.compare(a[0], b[0])
        );

        List<int[]> lower = new ArrayList<>();
        for (int[] point : trees) {
            while (lower.size() >= 2 &&
                   cross(lower.get(lower.size() - 2),
                         lower.get(lower.size() - 1), point) < 0) {
                lower.remove(lower.size() - 1);
            }
            lower.add(point);
        }

        List<int[]> upper = new ArrayList<>();
        for (int i = trees.length - 1; i >= 0; i--) {
            int[] point = trees[i];
            while (upper.size() >= 2 &&
                   cross(upper.get(upper.size() - 2),
                         upper.get(upper.size() - 1), point) < 0) {
                upper.remove(upper.size() - 1);
            }
            upper.add(point);
        }

        List<int[]> answer = new ArrayList<>();
        Set<Long> seen = new HashSet<>();
        for (int[] point : lower) addOnce(point, answer, seen);
        for (int[] point : upper) addOnce(point, answer, seen);
        return answer.toArray(new int[answer.size()][]);
    }

    private long cross(int[] a, int[] b, int[] c) {
        return (long) (b[0] - a[0]) * (c[1] - a[1])
             - (long) (b[1] - a[1]) * (c[0] - a[0]);
    }

    private void addOnce(int[] point, List<int[]> answer, Set<Long> seen) {
        long key = ((long) point[0] << 32) ^ (point[1] & 0xffffffffL);
        if (seen.add(key)) answer.add(point);
    }
}

var outerTrees = function(trees) {
    if (trees.length <= 1) return trees;

    const points = trees.slice().sort((a, b) =>
        a[0] === b[0] ? a[1] - b[1] : a[0] - b[0]
    );

    const cross = (a, b, c) =>
        (b[0] - a[0]) * (c[1] - a[1]) -
        (b[1] - a[1]) * (c[0] - a[0]);

    const build = sequence => {
        const chain = [];
        for (const point of sequence) {
            while (chain.length >= 2 &&
                   cross(chain[chain.length - 2], chain[chain.length - 1], point) < 0) {
                chain.pop();
            }
            chain.push(point);
        }
        return chain;
    };

    const lower = build(points);
    const upper = build(points.slice().reverse());
    const unique = new Map();
    for (const point of lower.concat(upper)) {
        unique.set(point[0] + "," + point[1], point);
    }
    return Array.from(unique.values());
};
from typing import List

class Solution:
    def outerTrees(self, trees: List[List[int]]) -> List[List[int]]:
        if len(trees) <= 1:
            return trees

        points = sorted(map(tuple, trees))

        def cross(a, b, c):
            return ((b[0] - a[0]) * (c[1] - a[1])
                    - (b[1] - a[1]) * (c[0] - a[0]))

        def build(sequence):
            chain = []
            for point in sequence:
                while (len(chain) >= 2 and
                       cross(chain[-2], chain[-1], point) < 0):
                    chain.pop()
                chain.append(point)
            return chain

        lower = build(points)
        upper = build(reversed(points))
        return [list(point) for point in set(lower + upper)]
class Solution {
public:
    vector<vector<int>> outerTrees(vector<vector<int>>& trees) {
        if (trees.size() <= 1) return trees;
        sort(trees.begin(), trees.end());

        vector<vector<int>> lower;
        for (const auto& point : trees) {
            while (lower.size() >= 2 &&
                   cross(lower[lower.size() - 2], lower.back(), point) < 0) {
                lower.pop_back();
            }
            lower.push_back(point);
        }

        vector<vector<int>> upper;
        for (auto it = trees.rbegin(); it != trees.rend(); ++it) {
            const auto& point = *it;
            while (upper.size() >= 2 &&
                   cross(upper[upper.size() - 2], upper.back(), point) < 0) {
                upper.pop_back();
            }
            upper.push_back(point);
        }

        set<vector<int>> boundary;
        boundary.insert(lower.begin(), lower.end());
        boundary.insert(upper.begin(), upper.end());
        return vector<vector<int>>(boundary.begin(), boundary.end());
    }

private:
    long long cross(const vector<int>& a,
                    const vector<int>& b,
                    const vector<int>& c) {
        return 1LL * (b[0] - a[0]) * (c[1] - a[1])
             - 1LL * (b[1] - a[1]) * (c[0] - a[0]);
    }
};

替代方案

Jarvis March（礼物包装法）每次从当前边界点寻找最逆时针的下一个点，时间复杂度为 O(nh)，其中 h 是边界点数量。当凸包点很少时很有吸引力，但本题还要细致收集每条边上的共线点，实现更容易遗漏或重复。单调链的 O(n log n) 更稳定。

常见错误

  • 使用 cross <= 0 弹出，导致边上的共线树被丢弃。
  • 只返回下链或上链，漏掉另一半边界。
  • 合并两条链时不去重，端点或全共线数据重复。
  • 依赖答案顺序；题目允许任意顺序，比较时应按集合处理。
  • 叉积使用过窄整数类型，扩大约束后可能溢出。
