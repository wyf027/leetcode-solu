Find the Longest Substring Containing Vowels in Even Counts

每个元音包含偶数次的最长子字符串

追踪的不是元音出现了多少次，而是它们此刻为奇数还是偶数。五盏状态灯，足以压缩整段前缀历史。

2⁵ = 32

题目描述

给定字符串 s，返回其中最长子字符串的长度，使得五个元音 a、e、i、o、u 在该子字符串内都出现偶数次。出现 0 次也属于偶数次。

示例 1

输入：s = "eleetminicoworoep"
输出：13
解释："leetminicowor" 最长；
e、i、o 各 2 次，a、u 各 0 次。

示例 2

输入：s = "leetcodeisgreat"
输出：5
解释：最长子字符串为 "leetc"，
其中 e 出现 2 次，其余元音 0 次。

示例 3

输入：s = "bcbcbc"
输出：6
解释：整个字符串没有元音，
五个元音均出现 0 次。

约束

  • 1 <= s.length <= 5 × 10⁵
  • s 仅包含小写英文字母。

Prefix parity mask

题解：前缀奇偶状态 + 最早位置

核心洞察

题目只关心每个元音次数的奇偶，不关心精确数量。用 5 位二进制数表示前缀状态：某位为 1 表示对应元音出现奇数次，为 0 表示偶数次。扫描到元音时，用异或翻转该位。

为什么记录最早位置

若状态 mask 在位置 j 和 i 后相同，则子串 (j, i] 内每个元音都翻转了偶数次。固定右端点 i 时，选择该状态最早的 j 才能得到最长候选。

完整过程

  1. 令 mask = 0，表示五种元音在空前缀中都是偶数次。
  2. 建立大小为 32 的最早位置表，初始化为未出现；特别设置 first[0] = -1，让从下标 0 开始的合法子串能被计算。
  3. 从左到右扫描字符串。若字符为元音，翻转其专属位：mask ^= 1 << bit。
  4. 若当前 mask 首次出现，记录当前位置；否则用 i - first[mask] 更新答案。
  5. 扫描完成后返回最大长度。

正确性证明

引理：两个前缀的掩码相同，当且仅当它们之间子串的每一种元音都出现偶数次。因为同一位相同，说明该元音在两段前缀中的次数奇偶相同；两者之差必为偶数。反向同理。

最优性：算法对每个右端点都检查其当前状态的最早出现位置，因此得到以该右端点结尾的最长合法子串。遍历所有右端点后，最大值就是全局最优答案。

边界与复杂度

  • 没有元音：掩码始终为 0，答案是整个字符串。
  • 单个元音：该字符令一位变为 1，不能单独组成合法子串。
  • 前缀本身合法：依靠 first[0] = -1 正确得到长度 i + 1。
  • 时间复杂度 O(n)；额外空间 O(1)，因为状态固定为 32 个。

替代方案

可以使用哈希表保存状态到最早位置，逻辑更通用；但这里只可能有 32 种状态，定长数组更直接。暴力枚举子串并统计元音需要 O(n²)，无法承受 5 × 10⁵ 的输入。

面试追问

  • 若要求某些字母出现次数对 3 取模为 0，如何编码状态？
  • 若字符集合动态变化，定长数组和哈希表如何取舍？
  • 如何返回最长子串本身，而不仅是长度？

常见错误

  • 忘记设置 first[0] = -1，导致漏掉从字符串开头起的合法子串。
  • 状态再次出现时覆盖最早位置，会让后续候选变短。
  • 使用加法更新位而非异或，无法在第二次出现时恢复偶数状态。
  • 把“每个元音出现偶数次”误解为“每个元音都必须出现”。0 次也是偶数。

四语言完整代码

import java.util.Arrays;

class Solution {
    public int findTheLongestSubstring(String s) {
        int[] first = new int[32];
        Arrays.fill(first, -2);
        first[0] = -1;

        int mask = 0;
        int answer = 0;
        for (int i = 0; i < s.length(); i++) {
            switch (s.charAt(i)) {
                case 'a': mask ^= 1 << 0; break;
                case 'e': mask ^= 1 << 1; break;
                case 'i': mask ^= 1 << 2; break;
                case 'o': mask ^= 1 << 3; break;
                case 'u': mask ^= 1 << 4; break;
                default: break;
            }
            if (first[mask] == -2) {
                first[mask] = i;
            } else {
                answer = Math.max(answer, i - first[mask]);
            }
        }
        return answer;
    }
}

var findTheLongestSubstring = function(s) {
    const first = new Array(32).fill(-2);
    first[0] = -1;
    const bit = { a: 0, e: 1, i: 2, o: 3, u: 4 };

    let mask = 0;
    let answer = 0;
    for (let i = 0; i < s.length; i++) {
        if (Object.prototype.hasOwnProperty.call(bit, s[i])) {
            mask ^= 1 << bit[s[i]];
        }
        if (first[mask] === -2) {
            first[mask] = i;
        } else {
            answer = Math.max(answer, i - first[mask]);
        }
    }
    return answer;
};
