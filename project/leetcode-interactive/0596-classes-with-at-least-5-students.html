完整题解

分组统计，再筛选聚合结果

官方提交语言：SQL

核心洞察

输出粒度是“一门课程一行”，所以先按 class 分组。联合主键保证同一学生不会在同一课程中重复出现，因此组内行数就是该课程的学生数。对聚合后的组做条件筛选，保留计数不少于 5 的课程。

MySQL / PostgreSQL / SQL Server / Oracle

SELECT class
FROM Courses
GROUP BY class
HAVING COUNT(*) >= 5;

完整过程

  1. 扫描 Courses 表中的选课记录。
  2. 用 GROUP BY class 将相同课程的记录归为同一组。
  3. 对每组执行 COUNT(*)，得到该课程的学生数。
  4. 用 HAVING COUNT(*) >= 5 过滤分组结果。
  5. 只输出满足条件的 class 列；题目不要求排序。

正确性证明

  1. 分组完整性：GROUP BY class 把且仅把课程名相同的行放入同一组，因此每门课程恰好对应一个组。
  2. 计数准确性：联合主键 (student, class) 保证同一学生在同一课程中至多出现一次，所以每组的 COUNT(*) 等于该课学生数。
  3. 筛选充分必要：HAVING COUNT(*) >= 5 保留且仅保留人数至少为 5 的组。
  4. 结论：输出的每门课程都满足要求，所有满足要求的课程也都会被输出，查询正确。

本地语义参考：LeetCode 本题不接受 Java；以下函数模拟同一分组计数逻辑。
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class Solution {
    public List<String> findClasses(List<String[]> courses) {
        Map<String, Integer> counts = new HashMap<>();

        for (String[] row : courses) {
            String className = row[1];
            counts.put(className, counts.getOrDefault(className, 0) + 1);
        }

        List<String> result = new ArrayList<>();
        for (Map.Entry<String, Integer> entry : counts.entrySet()) {
            if (entry.getValue() >= 5) {
                result.add(entry.getKey());
            }
        }
        return result;
    }
}
本地语义参考：LeetCode 本题不接受 JavaScript；以下函数模拟同一分组计数逻辑。
/**
 * @param {Array<[string, string]>} courses [student, class]
 * @return {string[]}
 */
function findClasses(courses) {
  const counts = new Map();

  for (const [, className] of courses) {
    counts.set(className, (counts.get(className) ?? 0) + 1);
  }

  const result = [];
  for (const [className, count] of counts) {
    if (count >= 5) result.push(className);
  }
  return result;
}

import pandas as pd


def find_classes(courses: pd.DataFrame) -> pd.DataFrame:
    counts = (
        courses.groupby("class", as_index=False)
        .size()
    )
    return counts.loc[counts["size"] >= 5, ["class"]]
本地语义参考：LeetCode 本题不接受 C++；以下函数模拟同一分组计数逻辑。
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>

class Solution {
public:
    std::vector<std::string> findClasses(
        const std::vector<std::pair<std::string, std::string>>& courses
    ) {
        std::unordered_map<std::string, int> counts;

        for (const auto& [student, className] : courses) {
            (void)student;
            ++counts[className];
        }

        std::vector<std::string> result;
        for (const auto& [className, count] : counts) {
            if (count >= 5) result.push_back(className);
        }
        return result;
    }
};

复杂度

时间概念上 O(n) 分组统计；实际由数据库执行计划决定。
空间概念上 O(k)，k 为不同课程数。

边界情况

  • 恰好 5 人：必须保留，因此是 >= 5。
  • 少于 5 人：不返回。
  • 多门课同时合格：全部返回，顺序不限。
  • 空表：返回空结果。

替代方案

COUNT(student)：本题 student 属于主键，因此非空，可与 COUNT(*) 得到相同计数；但 COUNT(*) 更直接表达“统计行数”。

COUNT(DISTINCT student)：若数据不保证学生与课程组合唯一，它更稳健；本题已有联合主键，使用它属于不必要的去重。

窗口函数：可以先计算分区计数再去重，但步骤和中间数据更多，不如分组聚合简洁。

常见错误

  • 把聚合条件写进 WHERE；聚合完成后的条件应写在 HAVING。
  • 误写为 > 5，漏掉恰好 5 人的课程。
  • 按 student 分组，导致输出粒度错误。
  • 返回额外的计数列，而题目只要求 class。

Follow-ups

面试追问

Q：为什么不能在 WHERE 中写 COUNT(*) ≥ 5？

WHERE 在分组聚合前过滤行，此时聚合计数尚未产生；HAVING 才负责过滤分组后的结果。

Q：如果联合主键不存在怎么办？

先确认业务口径。如果同一学生同一课程可能重复，应使用 COUNT(DISTINCT student)。

Q：怎样同时返回学生数？

在 SELECT 中加入 COUNT(*) AS student_count，并保留相同的 GROUP BY 与 HAVING。

Q：索引能如何帮助？

针对大表，可评估以 class 开头的索引是否减少分组成本；最终仍需依据数据分布与执行计划判断。
