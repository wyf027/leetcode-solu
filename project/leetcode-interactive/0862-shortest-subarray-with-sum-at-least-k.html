Shortest Subarray with Sum at Least K

和至少为 K 的最短子数组

在可能包含负数的整数数组中，找到元素和不小于 k 的最短非空连续子数组；不存在时返回 -1。

输入
nums: 整数数组，k: 整数
输出
最短长度或 -1
关键提醒
负数会破坏普通滑窗

题目说明

给定整数数组 nums 与整数 k，返回一个连续、非空子数组的最小长度，要求元素总和至少为 k；若不存在则返回 -1。子数组必须是原数组中连续的一段。

示例 1

输入：nums = [1], k = 1
输出：1

示例 2

输入：nums = [1, 2], k = 4
输出：-1

示例 3

输入：nums = [2, -1, 2], k = 3
输出：3

约束

  • 1 <= nums.length <= 10^5
  • -10^5 <= nums[i] <= 10^5
  • 1 <= k <= 10^9

独立题解

准备好后再展开；展开时焦点会进入题解。

核心洞察：前缀和 + 单调双端队列

令 P[i] 为前 i 个元素的和。区间 [j, i) 的和为 P[i] - P[j]，目标等价于寻找满足 P[i] - P[j] >= k 且 i - j 最小的一对下标。

从左到右扫描 i，双端队列保存仍可能成为最优左端点的前缀下标，并让对应的前缀和值严格递增。

完整过程

  1. 构造长度为 n + 1 的前缀和。
  2. 当队首 j 满足 P[i]-P[j] >= k，更新答案并持续弹出队首。
  3. 当队尾 t 满足 P[t] >= P[i]，持续弹出队尾。
  4. 把 i 加入队尾。

正确性

弹队首：它与当前右端点已形成可行区间；与更晚右端点组合只会更长，记录答案后无需保留。

弹队尾：若 i > t 且 P[i] <= P[t]，对任意未来右端点，从 i 开始的区间和不少且长度更短，因此 t 永远不会更优。

队列因此保留所有可能形成最优答案的候选，扫描结束时答案即为全局最短长度。

复杂度

时间 O(n)；每个下标至多入队、出队各一次。空间 O(n)。

边界

单元素命中、总和不足、大量负数、答案位于尾部、前缀和超出 32 位。

替代方案

堆或有序结构通常为 O(n log n)。普通双指针仅适用于元素非负。

面试追问

  • 为何维护前缀和值递增，而不是原数组递增？
  • 两个 while 循环各自维护什么不变量？
  • 如果所有元素非负，如何简化成滑动窗口？
  • 如何返回最短子数组的左右端点，而非仅长度？

常见错误

  • 在负数场景误用普通滑动窗口。
  • 队首满足条件时只弹一次，错过更短答案。
  • 队尾比较方向错误，破坏单调性。
  • Java/C++ 使用 32 位前缀和导致溢出。
  • 遗漏初始前缀和 P[0] = 0。

Java
class Solution {
    public int shortestSubarray(int[] nums, int k) {
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        int answer = n + 1;
        int[] deque = new int[n + 1];
        int head = 0, tail = 0;
        for (int i = 0; i <= n; i++) {
            while (head < tail && prefix[i] - prefix[deque[head]] >= k) {
                answer = Math.min(answer, i - deque[head++]);
            }
            while (head < tail && prefix[deque[tail - 1]] >= prefix[i]) {
                tail--;
            }
            deque[tail++] = i;
        }
        return answer <= n ? answer : -1;
    }
}

Python 3
from collections import deque
from typing import List

class Solution:
    def shortestSubarray(self, nums: List[int], k: int) -> int:
        prefix = [0]
        for value in nums:
            prefix.append(prefix[-1] + value)

        candidates = deque()
        answer = len(nums) + 1
        for i, current in enumerate(prefix):
            while candidates and current - prefix[candidates[0]] >= k:
                answer = min(answer, i - candidates.popleft())
            while candidates and prefix[candidates[-1]] >= current:
                candidates.pop()
            candidates.append(i)
        return answer if answer <= len(nums) else -1
C++
class Solution {
public:
    int shortestSubarray(vector<int>& nums, int k) {
        int n = static_cast<int>(nums.size());
        vector<long long> prefix(n + 1, 0);
        for (int i = 0; i < n; ++i) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
        deque<int> candidates;
        int answer = n + 1;
        for (int i = 0; i <= n; ++i) {
            while (!candidates.empty() &&
                   prefix[i] - prefix[candidates.front()] >= k) {
                answer = min(answer, i - candidates.front());
                candidates.pop_front();
            }
            while (!candidates.empty() &&
                   prefix[candidates.back()] >= prefix[i]) {
                candidates.pop_back();
            }
            candidates.push_back(i);
        }
        return answer <= n ? answer : -1;
    }
};
