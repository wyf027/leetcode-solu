数组的均值分割

Split Array With Same Average

805

把所有数字分给两个非空集合，寻找一条恰好平衡的分界线。

数组 数学 哈希表 中途相遇
Problem brief

题目要求

给定整数数组 nums，需要把其中每一个元素放入数组 A 或数组 B。两个数组都必须非空，并且二者的平均值相等。

如果存在这样的分割，返回 true；否则返回 false。

平均值定义：数组所有元素之和除以数组长度。这里分割的是元素位置，即使数值相同，也视为不同元素。

示例 1

可分
输入 nums = [1,2,3,4,5,6,7,8]
输出 true
解释 可取 A = [1,4,5,8]、B = [2,3,6,7]，两者平均值均为 4.5。

示例 2

不可分
输入 nums = [3,1]
输出 false

约束

  • 1 <= nums.length <= 30
  • 0 <= nums[i] <= 104

Step 01 · 原始任务

能否分成两个同均值集合？

1 / 7

先看数组整体：8 个数，总和为 36，整体平均值是 4.5。我们需要找到一个非空且非全集的子集，其平均值也为 4.5。

12 34 56 78
total = 36 · n = 8 · average = 36 / 8 = 4.5

如果子集长度为 k，它的元素和必须等于 36 × k / 8。只需考虑让这个值为整数的 k；例如 k = 2 时目标和为 9。

subsetSum = total × k / n → 36 × 2 / 8 = 9
k=1 ✕ k=2 → sum 9 k=3 ✕ k=4 → sum 18

为了避免小数，把每个值 x 改写成 x × 8 − 36。此后，寻找“同平均值子集”等价于寻找“和为 0 的非空真子集”。

−28−20 −12−4 +4+12 +20+28
y[i] = nums[i] × n − total

把变形数组从中间切开。每侧最多 15 个元素，因此可以各自枚举子集，而不必枚举最多 30 个元素的全部组合。

LEFT / 4 items
−28−20 −12−4
RIGHT / 4 items
+4+12 +20+28

先枚举右半边的非空子集，把它们的和登记在哈希集合中。这里只展示一部分代表值。

RIGHT SUBSET SUMS
+4+12 +16+20 +24+32 +36+40 …

左侧选中原值 1 和 4，对应变形值 −28 与 −4，总和 −32。右侧登记表中存在 +32，二者正好抵消。

LEFT SUM = −32
−28−20 −12−4
MATCH = +32
+4+12 +20+28

−32 + 32 = 0

匹配对应原数组子集 A = [1,4,5,8]，其补集 B = [2,3,6,7]。两边都非空，且平均值相同，因此返回 true。

A = [1,4,5,8]
(1+4+5+8) / 4 = 4.5
B = [2,3,6,7]
(2+3+6+7) / 4 = 4.5

中途相遇：把均值变成零和

核心洞察

01

只找一边

若非空真子集 A 的平均值等于整个数组平均值，则它的补集 B 也自动拥有同一平均值。

02

消掉除法

令 y[i] = nums[i] × n − total，问题等价于寻找变形后元素和为 0 的非空真子集。

03

左右会合

数组最多 30 项，分半后每侧最多 15 项。枚举两侧子集和，并用哈希集合匹配相反数。

完整过程

  1. 计算长度 n 与总和 total。先检查是否存在 1 ≤ k ≤ n/2，使 total × k 能被 n 整除；若不存在，任何子集大小都不可能得到所需整数和，直接返回 false。
  2. 把每个元素变换为 nums[i] × n − total。所有变形值的总和必为 0。
  3. 把变形数组分成左右两半。枚举右半边所有非空子集：若某个子集和为 0，立即返回 true；否则把非全集子集和加入哈希集合。
  4. 枚举左半边所有非空子集：若子集和为 0，立即返回 true；对于左侧非全集子集，检查右侧集合中是否存在其相反数。
  5. 若找到相反数，两侧子集合并后和为 0，对应原数组中的同均值真子集；若始终找不到，返回 false。
为什么不把半边全集放进交叉匹配集合？ 这样可以直接避开“左右都取全集”这一非法情况。若一个合法解取满某一半，它的补集会完整落在另一半并且同样为零和，单边零和检查仍能发现它。

正确性证明

  1. 变换等价性：对任意大小为 k 的子集 S，变形和为 n × sum(S) − k × total。它等于 0，当且仅当 sum(S) / k = total / n，即 S 与整个数组平均值相同。
  2. 找到的答案一定有效：算法只接受单边零和子集，或左右子集和互为相反数的组合。两种情况的变形总和都为 0；算法又排除了空集和整个数组，所以根据变换等价性，它对应一个合法分割。
  3. 任何有效答案都不会漏：合法零和真子集若只在一侧，会被单边枚举直接发现；若跨越两侧且两边都非全集，会在右侧登记后被左侧相反数查询发现；若取满某一侧，它的非空补集位于另一侧且也是零和，会被单边检查发现。

结论：算法返回 true 当且仅当存在题目要求的分割。

边界与复杂度

Time O(n · 2^(n/2))

每半边至多 15 项；这里为清晰起见，对每个掩码逐项累加。

Space O(2^(n/2))

哈希集合保存右半边的不同子集和。

  • n = 1：无法构造两个非空数组，整数可行性筛选会返回 false。
  • 全部元素相等：任意单元素真子集均与整体同均值，变形值为 0，可立即命中。
  • 包含 0 或重复值：算法按位置枚举，不依赖元素互异，仍然成立。
  • 整数安全：在本题约束内，变形值和子集和可安全放入 32 位有符号整数；JavaScript 的 Number 也精确表示这些整数。

Java · LeetCode submission
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean splitArraySameAverage(int[] nums) {
        int n = nums.length;
        int total = 0;
        for (int value : nums) {
            total += value;
        }

        boolean hasPossibleSize = false;
        for (int size = 1; size <= n / 2; size++) {
            if ((long) total * size % n == 0) {
                hasPossibleSize = true;
                break;
            }
        }
        if (!hasPossibleSize) {
            return false;
        }

        int[] transformed = new int[n];
        for (int i = 0; i < n; i++) {
            transformed[i] = nums[i] * n - total;
        }

        int mid = n / 2;
        int rightSize = n - mid;
        int rightFullMask = (1 << rightSize) - 1;
        Set<Integer> rightSums = new HashSet<>();

        for (int mask = 1; mask <= rightFullMask; mask++) {
            int subsetSum = 0;
            for (int bit = 0; bit < rightSize; bit++) {
                if ((mask & (1 << bit)) != 0) {
                    subsetSum += transformed[mid + bit];
                }
            }
            if (subsetSum == 0) {
                return true;
            }
            if (mask != rightFullMask) {
                rightSums.add(subsetSum);
            }
        }

        int leftFullMask = (1 << mid) - 1;
        for (int mask = 1; mask <= leftFullMask; mask++) {
            int subsetSum = 0;
            for (int bit = 0; bit < mid; bit++) {
                if ((mask & (1 << bit)) != 0) {
                    subsetSum += transformed[bit];
                }
            }
            if (subsetSum == 0) {
                return true;
            }
            if (mask != leftFullMask && rightSums.contains(-subsetSum)) {
                return true;
            }
        }

        return false;
    }
}

var splitArraySameAverage = function(nums) {
    const n = nums.length;
    const total = nums.reduce((sum, value) => sum + value, 0);

    let hasPossibleSize = false;
    for (let size = 1; size <= Math.floor(n / 2); size++) {
        if ((total * size) % n === 0) {
            hasPossibleSize = true;
            break;
        }
    }
    if (!hasPossibleSize) {
        return false;
    }

    const transformed = nums.map(value => value * n - total);
    const mid = Math.floor(n / 2);
    const rightSize = n - mid;
    const rightFullMask = (1 << rightSize) - 1;
    const rightSums = new Set();

    for (let mask = 1; mask <= rightFullMask; mask++) {
        let subsetSum = 0;
        for (let bit = 0; bit < rightSize; bit++) {
            if ((mask & (1 << bit)) !== 0) {
                subsetSum += transformed[mid + bit];
            }
        }
        if (subsetSum === 0) {
            return true;
        }
        if (mask !== rightFullMask) {
            rightSums.add(subsetSum);
        }
    }

    const leftFullMask = (1 << mid) - 1;
    for (let mask = 1; mask <= leftFullMask; mask++) {
        let subsetSum = 0;
        for (let bit = 0; bit < mid; bit++) {
            if ((mask & (1 << bit)) !== 0) {
                subsetSum += transformed[bit];
            }
        }
        if (subsetSum === 0) {
            return true;
        }
        if (mask !== leftFullMask && rightSums.has(-subsetSum)) {
            return true;
        }
    }

    return false;
};

from typing import List


class Solution:
    def splitArraySameAverage(self, nums: List[int]) -> bool:
        n = len(nums)
        total = sum(nums)

        has_possible_size = any(
            total * size % n == 0
            for size in range(1, n // 2 + 1)
        )
        if not has_possible_size:
            return False

        transformed = [value * n - total for value in nums]
        mid = n // 2
        right_size = n - mid
        right_full_mask = (1 << right_size) - 1
        right_sums = set()

        for mask in range(1, right_full_mask + 1):
            subset_sum = 0
            for bit in range(right_size):
                if mask & (1 << bit):
                    subset_sum += transformed[mid + bit]
            if subset_sum == 0:
                return True
            if mask != right_full_mask:
                right_sums.add(subset_sum)

        left_full_mask = (1 << mid) - 1
        for mask in range(1, left_full_mask + 1):
            subset_sum = 0
            for bit in range(mid):
                if mask & (1 << bit):
                    subset_sum += transformed[bit]
            if subset_sum == 0:
                return True
            if mask != left_full_mask and -subset_sum in right_sums:
                return True

        return False

class Solution {
public:
    bool splitArraySameAverage(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        int total = accumulate(nums.begin(), nums.end(), 0);

        bool hasPossibleSize = false;
        for (int size = 1; size <= n / 2; size++) {
            if (static_cast<long long>(total) * size % n == 0) {
                hasPossibleSize = true;
                break;
            }
        }
        if (!hasPossibleSize) {
            return false;
        }

        vector<int> transformed(n);
        for (int i = 0; i < n; i++) {
            transformed[i] = nums[i] * n - total;
        }

        int mid = n / 2;
        int rightSize = n - mid;
        int rightFullMask = (1 << rightSize) - 1;
        unordered_set<int> rightSums;

        for (int mask = 1; mask <= rightFullMask; mask++) {
            int subsetSum = 0;
            for (int bit = 0; bit < rightSize; bit++) {
                if (mask & (1 << bit)) {
                    subsetSum += transformed[mid + bit];
                }
            }
            if (subsetSum == 0) {
                return true;
            }
            if (mask != rightFullMask) {
                rightSums.insert(subsetSum);
            }
        }

        int leftFullMask = (1 << mid) - 1;
        for (int mask = 1; mask <= leftFullMask; mask++) {
            int subsetSum = 0;
            for (int bit = 0; bit < mid; bit++) {
                if (mask & (1 << bit)) {
                    subsetSum += transformed[bit];
                }
            }
            if (subsetSum == 0) {
                return true;
            }
            if (mask != leftFullMask && rightSums.count(-subsetSum)) {
                return true;
            }
        }

        return false;
    }
};

替代方案

按子集大小分组的动态规划：维护 dp[k]，其中记录恰好选择 k 个元素可得到的所有和；随后检查是否存在 total × k / n。这种写法直观，也能利用 n ≤ 30，但集合状态数量取决于数值范围，最坏情况下可能比中途相遇占用更多时间和空间。

排序加搜索：无法仅凭双指针解决，因为子集大小不固定且元素可以跳选；若继续做穷举，仍需要记忆化或中途相遇控制指数规模。

面试追问

  • 为什么只检查 k 到 n/2？若大小超过 n/2 的子集可行，它的补集大小小于 n/2，并且也可行。
  • 为什么变形后总和一定为 0？Σ(nums[i] × n − total) = n × total − n × total = 0。
  • 如何把枚举常数进一步降低？可用最低位递推子集和，或使用 Gray code 让相邻掩码只变化一个元素。
  • 如何返回具体分组？哈希表保存“子集和 → 掩码”，命中时组合左右掩码，再由未选位置构造补集。

常见错误

  • 直接比较浮点平均值，带来不必要的精度风险；应使用交叉相乘或整数变形。
  • 允许选中整个数组；它当然和整体同均值，但会使另一边为空，不符合题意。
  • 只枚举子集和，却忘了元素数量影响目标平均值。
  • 对 30 个元素直接枚举 2^30 个子集，而没有利用分半将规模降到约两个 2^15。
  • 把右半边全集放入集合，又没有在命中时排除左右全集组合。
