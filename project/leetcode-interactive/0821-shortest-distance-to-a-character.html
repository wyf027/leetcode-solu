最短距离

对字符串中的每一个位置，找到它与目标字符最近一次出现位置之间的距离。先读题、试着找规律，再打开底部题解。

Before the solution

先问自己三件事

  1. 只知道左侧最近的 c，答案一定完整吗？
  2. 每个位置都向两边搜索，会重复做多少工作？
  3. 能否让每个字符只被访问常数次？
Problem

题意与边界

距离按下标差的绝对值计算，且题目保证目标字符至少出现一次。

准确转述

给定字符串 s 和字符 c，其中 c 一定在 s 中出现。返回长度与 s 相同的整数数组 answer：对任意下标 i，answer[i] 等于 i 到字符串中最近的字符 c 的距离。

距离定义：distance(i, j) = abs(i - j)

约束

  • 1 ≤ s.length ≤ 104
  • s[i] 与 c 均为小写英文字母
  • c 在 s 中至少出现一次

示例 1

输入：s = "loveleetcode", c = "e"
输出：[3,2,1,0,1,0,0,1,2,2,1,0]

字符 e 位于下标 3、5、6、11。例如下标 4 到下标 3 或 5 的距离都为 1。

示例 2

输入：s = "aaab", c = "b"
输出：[3,2,1,0]

唯一的 b 在下标 3，其他位置与它的距离依次递减。

Solution gate

准备好核对思路了吗？

题解包含完整推导、正确性证明、复杂度、替代方案、面试追问与四种语言代码。

Core insight

两次线性扫描，拼出完整最近距离

对任意位置 i，最近的目标字符只可能来自两个方向：左侧最近的 c 或 右侧最近的 c。第一次从左到右记录左侧距离，第二次从右到左用右侧距离取更小值。

完整过程

  1. 创建长度为 n 的答案数组。
  2. 从左向右扫描；用 prev 保存最近一个 c 的下标，并写入 i - prev。
  3. 从右向左扫描；再次维护最近的 c 下标，并用 min(answer[i], prev - i) 更新。
  4. 每个下标恰好参与两次常数时间计算，返回答案数组。

正确性证明

引理 1：左向右扫描到 i 时，prev 是不大于 i 的最大目标下标。因此 i - prev 是 i 到左侧所有目标字符的最小距离。

引理 2：对称地，右向左扫描得到 i 到右侧所有目标字符的最小距离。

结论：任意目标字符必定位于 i 左侧、右侧或正好位于 i。取两个方向最小距离的较小值，恰好得到全局最近距离。

复杂度与边界

时间复杂度O(n)
额外空间O(1)

答案数组不计入额外空间。实现中可用 -n 与 2n 作为哨兵，避免扫描初期没有目标字符时产生无效下标。

  • 长度为 1 且字符就是 c：答案为 [0]。
  • c 连续出现：这些位置的距离都是 0。
  • c 只出现一次：两次扫描仍然成立。

替代方案

  • 逐位置向两边找：直观，但最坏需要 O(n²) 时间。
  • 记录全部目标下标 + 二分：每个位置二分最近目标，总时间 O(n log k)、额外空间 O(k)。
  • 多源 BFS：把所有 c 当作起点向左右扩散，也能做到 O(n)，但队列带来 O(n) 额外空间。

常见错误

  • 只做一次扫描，遗漏另一方向更近的目标字符。
  • 哨兵取值太小，导致开头位置得到错误的有限距离。
  • 第二次扫描覆盖答案，而不是与已有距离取最小值。
  • 误把字符值比较写成字符串下标或对象引用比较。

面试追问

  • 如果要回答很多个不同目标字符的查询，如何预处理？
  • 如果输入是流式字符，哪些位置的答案可以提前确定？
  • 如果距离改成环形字符串上的距离，扫描方式如何变化？
  • 能否原地复用返回数组并说明空间复杂度口径？

实现检查点

  • 遇到 c 时，先更新 prev = i，再计算距离。
  • 右扫公式是 prev - i，不会出现负数。
  • 两趟完成后所有答案都有限，因为 c 保证出现。
  • 不要在循环中截取字符串或反复搜索。
Implementations

四种语言完整代码

Java · 官方签名
class Solution {
    public int[] shortestToChar(String s, char c) {
        int n = s.length();
        int[] answer = new int[n];
        int prev = -n;

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == c) {
                prev = i;
            }
            answer[i] = i - prev;
        }

        prev = 2 * n;
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == c) {
                prev = i;
            }
            answer[i] = Math.min(answer[i], prev - i);
        }

        return answer;
    }
}

class Solution:
    def shortestToChar(self, s: str, c: str) -> List[int]:
        n = len(s)
        answer = [0] * n
        prev = -n

        for i in range(n):
            if s[i] == c:
                prev = i
            answer[i] = i - prev

        prev = 2 * n
        for i in range(n - 1, -1, -1):
            if s[i] == c:
                prev = i
            answer[i] = min(answer[i], prev - i)

        return answer
