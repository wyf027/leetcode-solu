Editorial

前序值序列 + 单调祖先栈

核心洞察：普通二叉树需要记录空孩子才能确定结构；二叉搜索树额外提供了大小关系。前序遍历先给出根，再给出左子树、右子树，因此仅保存节点值就足以恢复结构。

序列化

按“根 → 左 → 右”的前序顺序收集所有节点值，用逗号连接。空树编码为空字符串。实现使用显式栈，避免深度为 10⁴ 的斜树造成递归栈过深。

反序列化

按顺序读取值，并维护一条从根到最近节点的祖先栈。较小值是栈顶的左孩子；较大值会弹出已经完成右侧定位的祖先，最后弹出的节点就是它的父节点。

完整过程

  1. 若输入字符串为空，返回空树。
  2. 第一个值创建根节点并入栈。
  3. 对后续值 x：若 x < stack.top.val，将新节点接为栈顶的左孩子。
  4. 否则不断弹出值小于 x 的祖先；将新节点接为最后弹出节点的右孩子。
  5. 新节点入栈，继续处理下一个值。

正确性证明

1
序列化保留必要顺序。 前序遍历中，每棵子树的根都出现在其后代之前；BST 的大小关系又能区分左、右子树，所以值序列足以唯一确定原 BST。
2
左孩子连接正确。 当新值小于栈顶值时，前序遍历尚未离开栈顶子树；下一个更小的未处理节点只能是栈顶的左孩子。
3
右孩子连接正确。 当新值更大时，所有比它小且位于栈顶的祖先，其左子树和更深的右侧路径已经结束。最后一个被弹出的祖先，是仍允许该值进入其右子树的最近节点，因此连接为它的右孩子恰好恢复前序结构。
4
归纳结论。 根节点显然正确；假设前 k 个节点均正确连接，上述两种情况保证第 k+1 个节点也连接到唯一正确位置。因此全部节点恢复后，所得树与原树相同。

复杂度

设节点数为 n。序列化与反序列化均为 O(n) 时间：每个节点至多入栈、出栈一次。除输出和重建出的树外，辅助栈最坏为 O(n)；编码只存 n 个值和分隔符。

边界情况

  • 空树：空字符串与 null。
  • 单节点：序列只有一个值。
  • 完全左斜或右斜树：显式栈仍可处理。
  • 节点值包含 0 或 10⁴。

常见错误

  • 照搬普通二叉树方案，保存大量 null，不够紧凑。
  • 弹栈后把右孩子接到当前栈顶，而不是最后弹出的节点。
  • 空字符串直接分割，得到无法解析的空 token。
  • 递归版本忽略最坏深度 10⁴。

替代方案

前序 + 上下界递归：读取前序值时，只有落在当前 (lower, upper) 区间的值才属于该子树，写法很短，同样是 O(n)；但极端斜树可能触发语言递归深度限制。也可保存后序序列并从末尾按“根 → 右 → 左”恢复。保存层序和空标记更通用，却没有利用 BST 的有序性，字符串更长。

面试追问

  • 如果 BST 允许重复值，如何约定重复值统一进入左子树或右子树，并同步修改比较条件？
  • 如何进一步压缩数字：定长二进制、变长整数或差分编码各有什么权衡？
  • 如何校验外部输入确实是一段合法的 BST 前序序列？可在弹栈时维护全局下界。
  • 若反序列化输入可能损坏，怎样报告格式错误、越界与重复值，而不是构造部分树？

Java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) { val = x; }
 * }
 */
public class Codec {
    public String serialize(TreeNode root) {
        if (root == null) return "";
        StringBuilder out = new StringBuilder();
        java.util.Deque<TreeNode> stack = new java.util.ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            if (out.length() > 0) out.append(',');
            out.append(node.val);
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }
        return out.toString();
    }

    public TreeNode deserialize(String data) {
        if (data == null || data.isEmpty()) return null;
        String[] values = data.split(",");
        TreeNode root = new TreeNode(Integer.parseInt(values[0]));
        java.util.Deque<TreeNode> stack = new java.util.ArrayDeque<>();
        stack.push(root);
        for (int i = 1; i < values.length; i++) {
            TreeNode node = new TreeNode(Integer.parseInt(values[i]));
            if (node.val < stack.peek().val) {
                stack.peek().left = node;
            } else {
                TreeNode parent = null;
                while (!stack.isEmpty() && stack.peek().val < node.val) {
                    parent = stack.pop();
                }
                parent.right = node;
            }
            stack.push(node);
        }
        return root;
    }
}

/**
 * function TreeNode(val, left, right) {
 *   this.val = (val === undefined ? 0 : val);
 *   this.left = (left === undefined ? null : left);
 *   this.right = (right === undefined ? null : right);
 * }
 */
var serialize = function(root) {
    if (root === null) return "";
    const values = [];
    const stack = [root];
    while (stack.length > 0) {
        const node = stack.pop();
        values.push(String(node.val));
        if (node.right !== null) stack.push(node.right);
        if (node.left !== null) stack.push(node.left);
    }
    return values.join(",");
};

var deserialize = function(data) {
    if (data.length === 0) return null;
    const values = data.split(",").map(Number);
    const root = new TreeNode(values[0]);
    const stack = [root];
    for (let i = 1; i < values.length; i++) {
        const node = new TreeNode(values[i]);
        if (node.val < stack[stack.length - 1].val) {
            stack[stack.length - 1].left = node;
        } else {
            let parent = null;
            while (stack.length > 0 &&
                   stack[stack.length - 1].val < node.val) {
                parent = stack.pop();
            }
            parent.right = node;
        }
        stack.push(node);
    }
    return root;
};

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Codec:
    def serialize(self, root: Optional[TreeNode]) -> str:
        if root is None:
            return ""
        values = []
        stack = [root]
        while stack:
            node = stack.pop()
            values.append(str(node.val))
            if node.right is not None:
                stack.append(node.right)
            if node.left is not None:
                stack.append(node.left)
        return ",".join(values)

    def deserialize(self, data: str) -> Optional[TreeNode]:
        if not data:
            return None
        values = [int(value) for value in data.split(",")]
        root = TreeNode(values[0])
        stack = [root]
        for value in values[1:]:
            node = TreeNode(value)
            if value < stack[-1].val:
                stack[-1].left = node
            else:
                parent = None
                while stack and stack[-1].val < value:
                    parent = stack.pop()
                parent.right = node
            stack.append(node)
        return root
C++
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode(int x) : val(x), left(NULL), right(NULL) {}
 * };
 */
class Codec {
public:
    string serialize(TreeNode* root) {
        if (root == nullptr) return "";
        string data;
        vector<TreeNode*> stack{root};
        while (!stack.empty()) {
            TreeNode* node = stack.back();
            stack.pop_back();
            if (!data.empty()) data.push_back(',');
            data += to_string(node->val);
            if (node->right != nullptr) stack.push_back(node->right);
            if (node->left != nullptr) stack.push_back(node->left);
        }
        return data;
    }

    TreeNode* deserialize(string data) {
        if (data.empty()) return nullptr;
        vector<int> values;
        string token;
        stringstream input(data);
        while (getline(input, token, ',')) values.push_back(stoi(token));

        TreeNode* root = new TreeNode(values[0]);
        vector<TreeNode*> stack{root};
        for (int i = 1; i < static_cast<int>(values.size()); ++i) {
            TreeNode* node = new TreeNode(values[i]);
            if (node->val < stack.back()->val) {
                stack.back()->left = node;
            } else {
                TreeNode* parent = nullptr;
                while (!stack.empty() && stack.back()->val < node->val) {
                    parent = stack.back();
                    stack.pop_back();
                }
                parent->right = node;
            }
            stack.push_back(node);
        }
        return root;
    }
};
