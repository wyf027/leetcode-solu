查找用户活跃分钟数

Finding the Users Active Minutes

一条操作日志，是否一定增加一个活跃分钟？先理解统计对象，再动手推演。

官方题目 ↗

题意与输入约定

给定二维整数数组 logs 和整数 k。每条 logs[i] = [IDᵢ, timeᵢ] 表示用户 IDᵢ 在第 timeᵢ 分钟进行了一次操作。不同用户可以同时操作，同一用户也可以在同一分钟操作多次。

某用户的 UAM 是其有过操作的不同分钟的数量。返回长度为 k 的数组，第 j 个位置表示 UAM 恰好等于 j 的用户数量（1 ≤ j ≤ k）。

题面用 1 起始位置描述答案；实际编程数组从 0 开始，所以“活跃 j 分钟的人数”放在 answer[j - 1]。

约束

  • 1 ≤ logs.length ≤ 10⁴；每条记录为两个整数。
  • 0 ≤ IDᵢ ≤ 10⁹。
  • 1 ≤ timeᵢ ≤ 10⁵。
  • max(各用户 UAM) ≤ k ≤ 10⁵。

官方示例 1

输入：logs = [[0,5],[1,2],[0,2],[0,5],[1,3]], k = 5
输出：[0,2,0,0,0]

用户 0 在分钟 2 和 5 活跃；用户 1 在分钟 2 和 3 活跃。两人的 UAM 都是 2，因此第 2 项是 2。

官方示例 2

输入：logs = [[1,1],[2,2],[2,3]], k = 4
输出：[1,1,0,0]

用户 1 的 UAM 为 1，用户 2 的 UAM 为 2。这两个位置分别记录 1 人。

题解 · 按用户去重，再统计分布

核心洞察

答案统计的是用户数，中间需要的是每个用户的不同分钟数。用 Map<用户 ID, Set<分钟>> 保留用户边界并去重；最终每个用户只投一票到对应 UAM 桶。

交互 · 日志 → 用户分钟卡 → 人数桶

蓝色分钟卡代表唯一分钟；橙色提示代表重复记录。先处理全部日志，再逐个用户投票。演示输入限制为 60 条日志、k ≤ 20，便于观察；四语言解法覆盖官方范围。

用户的唯一分钟卡

UAM 分布桶 · 每个用户最终只投一票



完整过程
  1. 创建空哈希映射。遇到新用户就为其创建一个空集合。
  2. 遍历每条 [id, minute]，把 minute 加入该用户集合；已有分钟不会增加集合大小。
  3. 创建长度为 k 的全零答案数组。
  4. 遍历各用户集合，令 s 为集合大小，将 answer[s - 1] 加一。
  5. 返回答案。例如示例 1 的两个集合分别为 {5,2}、{2,3}，各给第 2 桶加一。


正确性说明
循环不变量：处理前 t 条日志后，每个用户的集合恰好包含该用户在这 t 条记录中出现的分钟。初始时集合为空，成立；加入下一条记录只把其分钟加入对应用户集合，集合去重语义确保既不遗漏也不重复，因此不变量保持。
处理全部日志后，每个集合大小恰好等于该用户的 UAM。随后每个用户恰好访问一次，并且仅使其 UAM 对应的桶加一，所以每个桶最终恰好等于所需用户数。约束保证 1 ≤ s ≤ k，索引 s - 1 始终有效。


边界与复杂度
完全重复的日志只产生一个活跃分钟；不同用户同一分钟分别保留；日志无需有序；用户 ID 很大，应使用映射而非按 ID 开巨型数组。没有日志的用户不参与统计，答案尾部可为零。
令 n 为日志数、u 为用户数、d 为不同 (用户, 分钟) 对数。哈希操作平均 O(1)，总时间为 O(n + k)（u ≤ n），辅助空间为 O(d + u) = O(n)，包含输出则为 O(n + k)。这是哈希表的平均复杂度，不承诺碰撞最坏情况仍为线性。


替代方案
按用户 ID、分钟依次排序，扫描相邻记录去重并计数，在用户切换时投票。时间 O(n log n + k)；额外空间取决于排序实现及是否复制输入。若输入已按这两个字段有序，可线性扫描，无需保存全部集合。
常见错误
  • 直接累加日志条数：同一分钟的重复操作会被多算。
  • 给所有用户共用一个集合：不同用户的分钟会混在一起。
  • 写成 answer[s]：会错位，s = k 时还会越界。
  • 处理一条日志就直接给最终桶加一：同一个用户会被重复计入，且其 UAM 尚未固定。
  • 返回每个用户的 UAM 列表：题目要的是按 UAM 分类的人数分布。
面试追问
如何实时维护分布？遇到新分钟时，若用户旧 UAM > 0，则旧桶减一，然后新桶加一；重复分钟不更新分布。
滚动时间窗口怎么办？需要记录用户每分钟的出现次数和过期事件，最后一条该分钟事件过期时再减少 UAM，单纯 Set 不足以删除重复事件。
能否只保存 UAM 数字？不能精确判断未来日志是否重复，除非输入提供排序或唯一性保证。


Java
import java.util.HashMap;
import java.util.HashSet;
import java.util.Map;
import java.util.Set;

class Solution {
    public int[] findingUsersActiveMinutes(int[][] logs, int k) {
        Map<Integer, Set<Integer>> minutes = new HashMap<>();
        for (int[] log : logs) {
            minutes.computeIfAbsent(log[0], id -> new HashSet<>())
                   .add(log[1]);
        }
        int[] answer = new int[k];
        for (Set<Integer> userMinutes : minutes.values()) {
            answer[userMinutes.size() - 1]++;
        }
        return answer;
    }
}


JavaScript
/**
 * @param {number[][]} logs
 * @param {number} k
 * @return {number[]}
 */
var findingUsersActiveMinutes = function(logs, k) {
    const minutes = new Map();
    for (const [id, minute] of logs) {
        if (!minutes.has(id)) minutes.set(id, new Set());
        minutes.get(id).add(minute);
    }
    const answer = Array(k).fill(0);
    for (const userMinutes of minutes.values()) {
        answer[userMinutes.size - 1]++;
    }
    return answer;
};


Python 3
from typing import List
from collections import defaultdict

class Solution:
    def findingUsersActiveMinutes(self, logs: List[List[int]], k: int) -> List[int]:
        minutes = defaultdict(set)
        for user_id, minute in logs:
            minutes[user_id].add(minute)
        answer = [0] * k
        for user_minutes in minutes.values():
            answer[len(user_minutes) - 1] += 1
        return answer


C++
#include <vector>
#include <unordered_map>
#include <unordered_set>
using namespace std;

class Solution {
public:
    vector<int> findingUsersActiveMinutes(vector<vector<int>>& logs, int k) {
        unordered_map<int, unordered_set<int>> minutes;
        for (const auto& log : logs) {
            minutes[log[0]].insert(log[1]);
        }
        vector<int> answer(k, 0);
        for (const auto& entry : minutes) {
            ++answer[entry.second.size() - 1];
        }
        return answer;
    }
};
