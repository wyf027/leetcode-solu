循环有序列表的插入

给定一个非递减循环链表，在保持循环与有序性的前提下插入一个值。真正的分界点只出现一次：最大值后接最小值。

题意与约束

链表的头节点可以是环中的任意节点；因此普通的“从头开始递增”判断不成立。请返回插入后任意一个原节点即可。若原链表为空，返回只含新值且指向自身的节点。

示例
3 → 4 → 1 ↺，insertVal = 2
一种合法结果
3 → 4 → 1 → 2 ↺
节点范围
0 ≤ 节点数 ≤ 5 × 10⁴；每个节点值与插入值均在 −10⁶ 到 10⁶。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

交互实验室：寻找插入缝隙

输入以逗号分隔的循环有序值（可从环上任一点开始）与待插入值。逐步检查每一条边 current → next。

载入示例后，沿环逐条检查插入位置。

    核心判断

    对每条边 cur → next，优先判断普通有序区间：cur.val ≤ insertVal ≤ next.val。若当前边跨越最大值到最小值，即 cur.val > next.val，则只有插入值不小于最大值或不大于最小值时放在这里。绕完一整圈仍未命中，说明全部节点相等或插入值落在等值区间，随意插入当前边即可。

    过程与复杂度

    1. 空表：新节点的 next 指向自身。
    2. 从任意节点开始，逐边查看 cur 与 next。
    3. 命中普通区间或跨越边界就插入并返回原节点。
    4. 遍历一圈未命中，则在最后一条边插入。

    时间 O(n)，额外空间 O(1)。

    可提交代码

    var insert = function(head, insertVal) {
  const node = new Node(insertVal);
  if (!head) { node.next = node; return node; }
  let cur = head;
  do {
    const next = cur.next;
    if ((cur.val <= insertVal && insertVal <= next.val) ||
        (cur.val > next.val && (insertVal >= cur.val || insertVal <= next.val))) {
      node.next = next; cur.next = node; return head;
    }
    cur = next;
  } while (cur !== head);
  node.next = cur.next; cur.next = node;
  return head;
};

                node.next, cur.next = nxt, node
                return head
            cur = nxt
            if cur == head:
                break
        node.next, cur.next = cur.next, node
        return head

    验证要点

    • 空链表：返回单节点自环。
    • 普通区间：3 → 4 → 1 插入 3，应落在 3 与 4 之间或任何相同值合法边。
    • 跨越边界：插入 0 或 5，应使用 4 → 1。
    • 全等值：2 → 2 → 2 可在任意边插入。
