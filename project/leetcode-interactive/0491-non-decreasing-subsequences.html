非递减子序列

从一个很短的数组里，找出所有长度至少为 2、保持原下标顺序且相邻值不下降的不同序列。

MEDIUM Non-decreasing Subsequences 非付费题 结果顺序不限
Problem

题意

官方函数：findSubsequences

给定整数数组 nums，返回其中所有不同的非递减子序列。每个子序列至少包含两个元素，答案可以按任意顺序返回。

子序列通过删除原数组中的若干元素（也可以不删）得到，剩余元素的相对顺序不能改变。这里“非递减”允许相邻元素相等。

两个关键词：“不同”要求答案去重；“子序列”要求保留原下标顺序，但不要求元素连续。
findSubsequences(nums: integer[]) → list<list<integer>>

示例 2

输出[[4,4]]

Solution

回溯 + 同层去重

把搜索过程看成一棵树：路径代表已选子序列，每一层决定下一个位置选谁。

核心洞察

  • 从左到右枚举下一个元素，天然保持原数组下标顺序。
  • 只有候选值不小于路径末尾时才能加入，保证非递减。
  • 每个递归层维护独立的 used 集合：同一父路径下，相同数值只作为“下一个元素”一次。
  • 路径长度达到 2 就记录；仍继续向下搜索更长答案。

为什么不能排序

排序会改变下标相对顺序，从而把并不存在的子序列制造出来。例如 [4,3] 排序后看似能得到 [3,4]，但它不是原数组的子序列。

正确做法是在原数组上推进起点 start。

Walkthrough

完整过程

搜索框架

  1. 进入 dfs(start)；若当前路径长度至少为 2，复制并加入答案。
  2. 创建只属于当前递归层的空集合 used。
  3. 遍历下标 i = start ... n - 1。
  4. 若 nums[i] 小于路径末尾，跳过；若已在本层 used 中，也跳过。
  5. 标记本层已用，选择该值并递归到 i + 1；返回后撤销选择。

同层去重示例

路径为 [4,6] 时，两个下标不同的 7 都能作为下一项。第一次选 7 已经覆盖以值 7 开头的这一分支；回到同一层后，第二个 7 被 used 拦住。

但进入更深一层会创建新的 used，因此另一个 7 仍可接在 [4,6,7] 后形成 [4,6,7,7]。

Correctness

正确性证明

生成的每个答案都合法。下标每次递归推进到 i + 1，所以保持原顺序；加入前检查不小于路径末尾，所以路径非递减；仅当长度至少为 2 时记录。
每个合法答案都能生成。任取一个合法子序列，按其下标从小到大看。DFS 在每层遍历当前起点后的全部位置，且该序列下一项满足非递减条件，因此存在一条分支依次选择这些下标并记录它。
答案不会重复。若两条搜索分支首次在同一父路径处分叉却选择了相同值，它们会被该层 used 合并，只保留第一次选择。不同值的分支显然不会产生相同的值序列，因此每个答案至多记录一次。
结合合法性、完备性与唯一性，算法恰好返回所有不同的非递减子序列。
Complexity

复杂度

时间

O(n · 2ⁿ)

最多枚举指数级子序列；复制一条路径最多花费 O(n)。

辅助空间

O(n²)

不计输出；递归路径 O(n)，同时存活的各层集合总量上界 O(n²)。

输出空间

O(n · 2ⁿ)

答案本身在最坏情况下就是指数规模。

Implementations

四种语言完整代码

JavaLeetCode 可提交
class Solution {
    private final List<List<Integer>> answer = new ArrayList<>();
    private final List<Integer> path = new ArrayList<>();

    public List<List<Integer>> findSubsequences(int[] nums) {
        dfs(nums, 0);
        return answer;
    }

    private void dfs(int[] nums, int start) {
        if (path.size() >= 2) {
            answer.add(new ArrayList<>(path));
        }

        Set<Integer> used = new HashSet<>();
        for (int i = start; i < nums.length; i++) {
            if ((!path.isEmpty() && nums[i] < path.get(path.size() - 1))
                    || used.contains(nums[i])) {
                continue;
            }

            used.add(nums[i]);
            path.add(nums[i]);
            dfs(nums, i + 1);
            path.remove(path.size() - 1);
        }
    }
}
JavaScriptLeetCode 可提交
/**
 * @param {number[]} nums
 * @return {number[][]}
 */
var findSubsequences = function(nums) {
    const answer = [];
    const path = [];

    const dfs = (start) => {
        if (path.length >= 2) {
            answer.push([...path]);
        }

        const used = new Set();
        for (let i = start; i < nums.length; i++) {
            if ((path.length > 0 && nums[i] < path[path.length - 1])
                    || used.has(nums[i])) {
                continue;
            }

            used.add(nums[i]);
            path.push(nums[i]);
            dfs(i + 1);
            path.pop();
        }
    };

    dfs(0);
    return answer;
};

class Solution:
    def findSubsequences(self, nums: List[int]) -> List[List[int]]:
        answer: List[List[int]] = []
        path: List[int] = []

        def dfs(start: int) -> None:
            if len(path) >= 2:
                answer.append(path.copy())

            used = set()
            for i in range(start, len(nums)):
                if (path and nums[i] < path[-1]) or nums[i] in used:
                    continue

                used.add(nums[i])
                path.append(nums[i])
                dfs(i + 1)
                path.pop()

        dfs(0)
        return answer
C++LeetCode 可提交
class Solution {
public:
    vector<vector<int>> findSubsequences(vector<int>& nums) {
        vector<vector<int>> answer;
        vector<int> path;
        dfs(nums, 0, path, answer);
        return answer;
    }

private:
    void dfs(const vector<int>& nums,
             int start,
             vector<int>& path,
             vector<vector<int>>& answer) {
        if (path.size() >= 2) {
            answer.push_back(path);
        }

        unordered_set<int> used;
        for (int i = start; i < static_cast<int>(nums.size()); i++) {
            if ((!path.empty() && nums[i] < path.back())
                    || used.count(nums[i]) > 0) {
                continue;
            }

            used.insert(nums[i]);
            path.push_back(nums[i]);
            dfs(nums, i + 1, path, answer);
            path.pop_back();
        }
    }
};
Edges & Follow-ups

边界、替代方案与面试追问

边界情况

  • 长度为 1：没有满足最小长度的答案。
  • 严格下降：没有答案，除非存在相等值可组成长度 2。
  • 全部相等：每种长度只保留一个值序列。
  • 负数与 0：比较逻辑不变，无需特殊处理。

替代方案

位掩码枚举：枚举 1...2ⁿ-1 的所有下标集合，过滤长度与非递减性，再用集合对完整序列去重。实现直观，但需要为序列设计可靠的哈希/序列化，且会生成大量无效候选。

值域数组去重：由于值域是 [-100,100]，每层可用长度 201 的布尔数组替代哈希集合，常数更稳定，但通用性稍差。

常见错误

  • 把 used 设成全局集合，误删不同深度的合法重复值。
  • 只在叶子节点记录，遗漏还能继续延长的较短合法路径。
  • 忘记复制路径，导致答案引用同一个可变对象。
  • 使用严格条件 >，错误排除相等元素。
  • 先排序数组，破坏子序列的原始顺序语义。

面试追问

  • 为什么去重集合必须是“每一层一个”，而不是全局一个？
  • 若只要求返回数量，是否仍能避免指数复杂度？值域较小时如何做状态压缩？
  • 若输入长度扩大到 10⁵，但只求最长非递减子序列长度，应换成什么算法？
  • 如何让结果按字典序输出？排序答案与控制搜索顺序各有什么代价？
