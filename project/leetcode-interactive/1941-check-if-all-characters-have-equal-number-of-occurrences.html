Check if All Characters Have Equal Number of Occurrences

一串字母，一条规则：每一种出现过的字符，次数是否一致？

01 / 题目与输入

给定字符串 s，判断其中实际出现过的所有字符是否出现同样多次。若是，返回布尔值 true；否则返回 false。没有出现的字母不参与判断。

参数：s: string　返回：boolean　函数：areOccurrencesEqual(s)

官方示例 1

输入：s = "abacbc"
输出：true

a、b、c 都出现 2 次，满足条件。

官方示例 2

输入：s = "aaabb"
输出：false

a 出现 3 次，b 出现 2 次，次数不同。

约束：1 ≤ s.length ≤ 1000，s 仅含小写英文字母 a–z。

04 / 独立题解

准备好后，展开推导与四语言实现。

核心洞察：比较最终的非零频次

排列顺序与答案无关。先用长度为 26 的数组统计每个小写字母的次数，再选第一个非零次数作为基准。其余非零次数必须全部等于基准。零表示该字母未出现，应跳过。

完整过程

  1. 初始化 26 个计数为 0。
  2. 从左至右读取字符 c，令 count[c - 'a'] 加 1。
  3. 遍历计数数组，跳过 0；用首个正数设置 target。
  4. 一旦遇到非零次数不等于 target，返回 false；比较完则返回 true。

例如 s = "abacbc" 的最终计数为 a:2、b:2、c:2，以 2 为基准，所有比较一致。s = "aaabb" 则以 3 为基准，b 的次数 2 不同，返回 false。

正确性说明

计数循环的不变式是：读取前 i 个字符后，数组每个位置恰好记录对应字母在该前缀中的出现次数。初始化时成立；每一步仅增加当前字符的计数，因而保持成立；循环结束得到完整字符串的真实频次。

比较循环只处理出现过的字母。若返回 false，已找到一个频次与基准不同的字母，题目条件不成立。若返回 true，则每个出现过的字母都已与同一个基准比较且相等，题目条件成立。非空约束保证至少存在一个基准。

边界与复杂度

  • 只有一个字符或一种字符时返回 true；全部字符各出现一次也返回 true。
  • 未出现字母的零频次必须排除。空串不属于官方输入域，四份代码不额外定义其业务含义。
  • 计数完成前不可因为暂时不一致而拒绝，例如 "aabb" 的前缀 "aab" 不均衡，但最终均衡。
  • 时间 O(n + 26) = O(n)，额外空间 O(26) = O(1)，n 为字符串长度。

替代方案

用哈希表统计出现过的字符，再比较所有值，时间 O(n + k)、空间 O(k)，适合字符集不固定的版本。也可将频次放入集合，集合大小为 1 即可；固定 26 个字母时，数组与单个基准更直接。排序后统计连续段也可完成，但通常需 O(n log n) 时间。

面试追问

  • 输入变成 Unicode？先确定“字符”是码点还是字素簇，再用对应分割方式与哈希表计数，不能继续用 26 槽数组。
  • 只判断长度能否整除字符种类数，可以吗？不可以；"aaab" 长度 4 能被种类数 2 整除，频次却为 3 和 1。
  • 流式输入能边读边做最终判断吗？可边读边累计，但普通做法要等输入结束才能据最终频次判定。若要查询每个前缀，可另维护“频次到字符种类数”的表。

常见错误

  • 把 count[0] 直接当作基准：当 a 未出现时，它是 0。
  • 将所有 26 个计数都纳入比较，导致不存在的字母影响答案。
  • 比较字符种类数和字符串长度，而没有比较每种字符的次数。
  • 在计数尚未完成时提前返回 false，错过后续字符补齐的可能。

Java

class Solution {
    public boolean areOccurrencesEqual(String s) {
        int[] count = new int[26];
        for (int i = 0; i < s.length(); i++) {
            count[s.charAt(i) - 'a']++;
        }
        int target = 0;
        for (int value : count) {
            if (value == 0) continue;
            if (target == 0) target = value;
            else if (value != target) return false;
        }
        return true;
    }
}

    for (const c of s) {
        count[c.charCodeAt(0) - 97]++;
    }
    let target = 0;

        if (value === 0) continue;
        if (target === 0) target = value;

    }
    return true;
};

Python 3

class Solution:
    def areOccurrencesEqual(self, s: str) -> bool:
        count = [0] * 26
        for c in s:
            count[ord(c) - ord('a')] += 1
        target = 0
        for value in count:
            if value == 0:
                continue
            if target == 0:
                target = value
            elif value != target:
                return False
        return True

C++

#include <string>
using namespace std;

class Solution {
public:
    bool areOccurrencesEqual(string s) {
        int count[26] = {};
        for (char c : s) {
            ++count[c - 'a'];
        }
        int target = 0;
        for (int value : count) {
            if (value == 0) continue;
            if (target == 0) target = value;
            else if (value != target) return false;
        }
        return true;
    }
};
