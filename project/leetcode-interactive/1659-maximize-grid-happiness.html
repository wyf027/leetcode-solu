最大化网格幸福感

在有限的房间里安排内向者与外向者，让每一条相邻关系都算得恰到好处。先理解计分，再通过交互账本观察一组最优安排。

位运算记忆化动态规划状态压缩
Problem

题目转述

给定整数 m、n、introvertsCount 和 extrovertsCount。你可以在 m × n 网格中放置不超过给定数量的内向者和外向者，每格至多一人，也可以让一些人不入住。

内向者初始幸福感为 120，每有一位上下左右相邻的邻居就减少 30；外向者初始幸福感为 40，每有一位邻居就增加 20。返回所有人幸福感总和的最大值。

计分事实：相邻关系同时影响两端，所以内—内、内—外、外—外三种边对总分的净变化依次为 -60、-10、+40。
Signature

函数形式

getMaxGridHappiness(m, n, introvertsCount, extrovertsCount)

返回最大网格幸福感（整数）。

Constraints
  • 1 ≤ m, n ≤ 5
  • 0 ≤ introvertsCount, extrovertsCount ≤ min(m × n, 6)

Solution

行状态压缩动态规划

核心洞察

每行用三进制编码。

每格只有 0 空、1 内向、2 外向三种状态。宽度至多 5，一行最多 3⁵ = 243 个状态。

上一行足够描述未来。

加入新行时，新增影响只来自本行左右边和它与上一行的上下边；更早的行无需保留。

旋转网格不改变邻接关系和答案，所以先让 n = min(m,n)，把指数项放在短边。

状态与转移

预处理每个行状态 s 的两类人数、基础分加水平边贡献 inside[s]，以及相邻两行的竖直边贡献 cross[p][s]。

dp[r][s][i][e] = 前 r 行处理完，最后一行状态为 s， 已使用 i 个内向者、e 个外向者的最大幸福感 dp[r][s][i + ic[s]][e + ec[s]] = max over p { dp[r-1][p][i][e] + inside[s] + cross[p][s] }

实现用滚动数组省去行维度。答案扫描最终所有合法使用量，因为允许少放人。

完整过程

  1. 必要时交换行列，令编码宽度最小。
  2. 枚举 0 到 3ⁿ−1，解码行状态，统计人数并计算基础分和水平边。
  3. 枚举上一行与当前行状态，预计算同列竖直边贡献。
  4. 从空的上一行、使用人数为 0、得分为 0 出发，逐行枚举合法状态。
  5. 处理完全部行后，扫描所有末行状态和使用量取最大值。

正确性证明

分数分解正确。

inside 为每人加入一次基础分，并为每条水平边加入一次两端净影响；cross 为每条竖直边加入一次净影响。所有基础分与相邻边都恰好计算一次。

状态信息充分。

未来只可能与当前最后一行产生新边；更早行已经封闭。最后一行状态与已用人数完整决定合法后继及其新增分数。

转移覆盖全部布局。

每个合法网格唯一对应一串行状态，DP 会枚举到它；每条合法 DP 路径也唯一还原为一个网格。

结论。

每条路径分数准确、全部布局被覆盖，且相同状态只保留较大值不会损失后继，因此最终最大值就是最优幸福感。

复杂度

设短边宽 w，长边 h，S=3ʷ，人数上限 I、E。

时间 O(h·S²·I·E)
空间 O(S² + S·I·E)。

边界

  • 两类人数均为 0 时答案为 0。
  • 单行或单列时一类边自然消失。
  • 不能强制用完所有人员。
  • 某类人数为 0 时仍使用同一框架。

替代方案

方案机制评价
逐格记忆化 DFS记录位置、最近 n 格、剩余人数同样正确且紧凑，状态含义略抽象。
按行状态 DP预处理行内、行间贡献拆分清晰，易证明和跨语言实现。
暴力枚举枚举 3^(m·n) 个布局最多 3²⁵，不可行。

面试追问

为什么能交换 m、n？

旋转保持邻接关系与人数约束，答案不变，却能减小 3ⁿ。

如何优化常数？

过滤人数超限的行状态、按人数分组，或改用逐格记忆化。

规则改变怎么办？

把基础分和配对净变化做成表，DP 框架无需变化。

为什么不能贪心？

多条共享边让当前放置改变后续边际收益，不具备局部交换性。

常见错误

  • 相邻边漏算一端，或重复计算整条边。
  • 把内—外净变化算错；正确值是 −30+20=−10。
  • 误以为必须用完人数。
  • 三进制位与列的顺序前后不一致。
  • 原地更新滚动数组，导致同一行被重复使用。

JavaLeetCode 提交代码
import java.util.Arrays;

class Solution {
    public int getMaxGridHappiness(int m, int n, int I, int E) {
        if (n > m) { int t=m; m=n; n=t; }
        int S=1; for(int k=0;k<n;k++) S*=3;
        int[] ci=new int[S], ce=new int[S], in=new int[S];
        int[][] a=new int[S][n];
        int[] base={0,120,40}, eff={0,-30,20};
        for(int s=0;s<S;s++){
            int x=s;
            for(int c=0;c<n;c++){
                int t=a[s][c]=x%3; x/=3;
                if(t==1) ci[s]++; if(t==2) ce[s]++;
                in[s]+=base[t];
                if(c>0 && t>0 && a[s][c-1]>0)
                    in[s]+=eff[t]+eff[a[s][c-1]];
            }
        }
        int[][] cross=new int[S][S];
        for(int p=0;p<S;p++) for(int s=0;s<S;s++)
            for(int c=0;c<n;c++) if(a[p][c]>0 && a[s][c]>0)
                cross[p][s]+=eff[a[p][c]]+eff[a[s][c]];
        int NEG=-1_000_000_000;
        int[][][] dp=new int[S][I+1][E+1];
        for(int[][] x:dp) for(int[] y:x) Arrays.fill(y,NEG);
        dp[0][0][0]=0;
        for(int r=0;r<m;r++){
            int[][][] nd=new int[S][I+1][E+1];
            for(int[][] x:nd) for(int[] y:x) Arrays.fill(y,NEG);
            for(int p=0;p<S;p++) for(int i=0;i<=I;i++)
                for(int e=0;e<=E;e++) if(dp[p][i][e]!=NEG)
                    for(int s=0;s<S;s++){
                        int ni=i+ci[s], ne=e+ce[s];
                        if(ni<=I && ne<=E)
                            nd[s][ni][ne]=Math.max(nd[s][ni][ne],
                                dp[p][i][e]+in[s]+cross[p][s]);
                    }
            dp=nd;
        }
        int ans=0;
        for(int[][] x:dp) for(int[] y:x) for(int v:y) ans=Math.max(ans,v);
        return ans;
    }
}

/**
 * @param {number} m
 * @param {number} n
 * @param {number} introvertsCount
 * @param {number} extrovertsCount
 * @return {number}
 */
var getMaxGridHappiness = function(m, n, I, E) {
    if (n > m) [m,n]=[n,m];
    const S=3**n, ci=new Int8Array(S), ce=new Int8Array(S);
    const inside=new Int16Array(S);
    const cell=Array.from({length:S},()=>new Int8Array(n));
    const base=[0,120,40], eff=[0,-30,20];
    for(let s=0;s<S;s++){
        let x=s;
        for(let c=0;c<n;c++){
            const t=x%3; x=Math.floor(x/3); cell[s][c]=t;
            if(t===1) ci[s]++; if(t===2) ce[s]++;
            inside[s]+=base[t];
            if(c && t && cell[s][c-1])
                inside[s]+=eff[t]+eff[cell[s][c-1]];
        }
    }
    const cross=Array.from({length:S},()=>new Int16Array(S));
    for(let p=0;p<S;p++) for(let s=0;s<S;s++)
        for(let c=0;c<n;c++) if(cell[p][c] && cell[s][c])
            cross[p][s]+=eff[cell[p][c]]+eff[cell[s][c]];
    const W=(I+1)*(E+1), idx=(s,i,e)=>s*W+i*(E+1)+e, NEG=-1e9;
    let dp=new Int32Array(S*W); dp.fill(NEG); dp[idx(0,0,0)]=0;
    for(let r=0;r<m;r++){
        const nd=new Int32Array(S*W); nd.fill(NEG);
        for(let p=0;p<S;p++) for(let i=0;i<=I;i++) for(let e=0;e<=E;e++){
            const old=dp[idx(p,i,e)]; if(old===NEG) continue;
            for(let s=0;s<S;s++){
                const ni=i+ci[s], ne=e+ce[s];
                if(ni>I || ne>E) continue;
                const at=idx(s,ni,ne), value=old+inside[s]+cross[p][s];
                if(value>nd[at]) nd[at]=value;
            }
        }
        dp=nd;
    }
    let ans=0; for(const v of dp) ans=Math.max(ans,v); return ans;
};

class Solution:
    def getMaxGridHappiness(self, m: int, n: int,
                            introvertsCount: int, extrovertsCount: int) -> int:
        if n > m:
            m, n = n, m
        S, base, eff = 3 ** n, (0, 120, 40), (0, -30, 20)
        cells, ci, ce, inside = [], [0]*S, [0]*S, [0]*S
        for s in range(S):
            x, row = s, []
            for _ in range(n):
                row.append(x % 3)
                x //= 3
            cells.append(row)
            for c, t in enumerate(row):
                ci[s] += t == 1
                ce[s] += t == 2
                inside[s] += base[t]
                if c and t and row[c-1]:
                    inside[s] += eff[t] + eff[row[c-1]]
        cross = [[0]*S for _ in range(S)]
        for p in range(S):
            for s in range(S):
                cross[p][s] = sum(
                    eff[x] + eff[y]
                    for x, y in zip(cells[p], cells[s]) if x and y
                )
        dp = {(0, 0, 0): 0}
        for _ in range(m):
            nd = {}
            for (p, i, e), old in dp.items():
                for s in range(S):
                    ni, ne = i + ci[s], e + ce[s]
                    if ni > introvertsCount or ne > extrovertsCount:
                        continue
                    key = (s, ni, ne)
                    nd[key] = max(nd.get(key, -10**9),
                                  old + inside[s] + cross[p][s])
            dp = nd
        return max(dp.values())

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int getMaxGridHappiness(int m, int n, int I, int E) {
        if(n>m) swap(m,n);
        int S=1; for(int k=0;k<n;k++) S*=3;
        vector<int> ci(S),ce(S),inside(S);
        vector<vector<int>> a(S,vector<int>(n));
        int base[3]={0,120,40}, eff[3]={0,-30,20};
        for(int s=0;s<S;s++){
            int x=s;
            for(int c=0;c<n;c++){
                int t=a[s][c]=x%3; x/=3;
                ci[s]+=t==1; ce[s]+=t==2; inside[s]+=base[t];
                if(c && t && a[s][c-1])
                    inside[s]+=eff[t]+eff[a[s][c-1]];
            }
        }
        vector<vector<int>> cross(S,vector<int>(S));
        for(int p=0;p<S;p++) for(int s=0;s<S;s++)
            for(int c=0;c<n;c++) if(a[p][c] && a[s][c])
                cross[p][s]+=eff[a[p][c]]+eff[a[s][c]];
        const int NEG=-1000000000;
        using Cube=vector<vector<vector<int>>>;
        Cube dp(S,vector<vector<int>>(I+1,vector<int>(E+1,NEG)));
        dp[0][0][0]=0;
        for(int r=0;r<m;r++){
            Cube nd(S,vector<vector<int>>(I+1,vector<int>(E+1,NEG)));
            for(int p=0;p<S;p++) for(int i=0;i<=I;i++)
                for(int e=0;e<=E;e++) if(dp[p][i][e]!=NEG)
                    for(int s=0;s<S;s++){
                        int ni=i+ci[s],ne=e+ce[s];
                        if(ni<=I && ne<=E)
                            nd[s][ni][ne]=max(nd[s][ni][ne],
                                dp[p][i][e]+inside[s]+cross[p][s]);
                    }
            dp.swap(nd);
        }
        int ans=0;
        for(auto &x:dp) for(auto &y:x) for(int v:y) ans=max(ans,v);
        return ans;
    }
};
