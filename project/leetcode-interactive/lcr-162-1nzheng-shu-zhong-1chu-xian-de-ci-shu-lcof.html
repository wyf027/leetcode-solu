数字 1 的个数

给定非负整数 num，统计从 0 到 num 的所有整数中数字 1 出现的总次数。

非负整数闭区间 [0, num]num < 10⁹

题意与示例

给定整数 num，计算所有小于等于它的非负整数中，数字 1 出现的总次数。 

num = 0
输出 = 0
num = 13
输出 = 6（1, 10, 11, 12, 13）

约束：0 <= num < 10⁹。

准备好再看题解

先观察每一位的周期性，再查看公式与四语言实现。

题解：高位 × 位因子，加当前位的尾段

核心洞察

考察因子 factor=1,10,100…。令 high=num/(factor×10)、current=(num/factor)%10、low=num%factor。完整周期贡献 high×factor；当前位为 1 时再加 low+1，大于 1 时再加完整 factor。

完整过程

  1. 从 factor=1 开始逐位分解。
  2. 先累加 high×factor。
  3. 根据 current 是 0、1 或大于 1 处理尾段，factor 乘 10。

边界与复杂度

num=0 直接返回 0。factor 需用 long 防止 factor×10 中间溢出。时间 O(log₁₀num)，空间 O(1)。

替代方案、面试追问与常见错误

  • 替代方案：逐个转字符串计数只适合小范围对拍，正式提交会达到 O(num log num)。
  • 面试追问：统计任意数字 d 时可复用位贡献思路，但统计 0 必须扣除前导零。
  • 常见错误：current=1 时漏掉 low+1、完整周期数量写错，或用 int 计算 factor×10 导致溢出。

可提交代码

class Solution {
    public int digitOneInNumber(int num) {
        long factor = 1, ans = 0;
        while (factor <= num) {
            long high = num / (factor * 10), cur = (num / factor) % 10, low = num % factor;
            ans += high * factor;
            if (cur == 1) ans += low + 1;
            else if (cur > 1) ans += factor;
            factor *= 10;
        }
        return (int) ans;
    }
}
var digitOneInNumber = function (num) {
  let ans = 0;
  for (let factor = 1; factor <= num; factor *= 10) {
    const high = Math.floor(num / (factor * 10)), cur = Math.floor(num / factor) % 10, low = num % factor;
    ans += high * factor;
    if (cur === 1) ans += low + 1;
    else if (cur > 1) ans += factor;
  }
  return ans;
};
