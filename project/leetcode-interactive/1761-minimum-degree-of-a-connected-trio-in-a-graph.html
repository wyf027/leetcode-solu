一个图中连通三元组的
最小度数

Minimum Degree of a Connected Trio in a Graph

困难 图 枚举 邻接矩阵 O(n³)
01 / PROBLEM

题目描述

给定一个含 n 个节点的无向图，以及边数组 edges。每条 edges[i] = [uᵢ, vᵢ] 表示节点 uᵢ 与 vᵢ 之间存在一条无向边。

若三个节点之间两两有边，则它们构成一个连通三元组。三元组的度数，是恰有一个端点位于该三元组内的边数。返回图中所有连通三元组的最小度数；若不存在连通三元组，返回 -1。

函数形式： minTrioDegree(n: integer, edges: integer[][]) → integer

示例 1

输入：n = 6, edges = [[1,2],[1,3],[3,2],[4,1],[5,2],[3,6]]
输出：3
解释：唯一的三元组是 [1,2,3]，它向外连接了 3 条边。

示例 2

输入：n = 7, edges = [[1,3],[4,1],[4,3],[2,5],[5,6],[6,7],[7,5],[2,6]]
输出：0
解释：[1,4,3] 的度数为 0；[2,5,6] 与 [5,6,7] 的度数均为 2。

约束

  • 2 ≤ n ≤ 400
  • edges[i].length == 2
  • 1 ≤ edges.length ≤ n × (n - 1) / 2
  • 1 ≤ uᵢ, vᵢ ≤ n，且 uᵢ != vᵢ
  • 图中没有重复边。

04 / SOLUTION

完整题解

核心洞察：若 (a,b,c) 构成三元组，则答案候选值为： degree[a] + degree[b] + degree[c] - 6

三条内部边各被两个端点的度数计算一次，总共多算 6 次；减掉后，恰好只剩向三元组外部延伸的边。

完整过程

  1. 建立 n × n 邻接矩阵，并统计每个节点的度数。
  2. 枚举所有严格递增的三元组 i < j < k。
  3. 若矩阵中 i-j、i-k、j-k 均有边，它就是连通三元组。
  4. 用度数和减 6，更新最小值；若始终没找到，则返回 -1。

边界与细节

  • 没有三角形：答案必须为 -1。
  • 孤立三角形：三元组度数为 0，这是合法的最小值。
  • 节点从 1 编号：可分配 n + 1 大小，减少下标转换。
  • 完整图：任意三个节点都是候选，公式仍成立。

正确性证明

  1. 枚举完整性。三重循环覆盖每个满足 i < j < k 的节点集合恰好一次，因此不会漏掉或重复处理任何三节点集合。
  2. 识别准确性。只有当三对节点在邻接矩阵中均相连时，集合才会被接受；这与连通三元组“两两有边”的定义等价。
  3. 度数公式正确。三个节点的度数总和包含全部向外边各一次，也包含三条内部边各两次。减去 3 × 2 = 6 后，恰好得到三元组的度数。
  4. 最优性。算法比较所有且仅有的连通三元组候选值，所以保存的最小值就是全局最小度数；若无候选，返回 -1 符合题意。

复杂度

时间复杂度 O(n³ + m)，其中 m = edges.length；空间复杂度 O(n²)，用于邻接矩阵。

替代方案

可以枚举一个节点的两位邻居，并检查邻居之间是否相连。稀疏图上通常更快，但最坏情况仍为 O(n³)。也可用位集加速公共邻居求交，代价是实现更复杂。

class Solution {
    public int minTrioDegree(int n, int[][] edges) {
        boolean[][] connected = new boolean[n + 1][n + 1];
        int[] degree = new int[n + 1];

        for (int[] edge : edges) {
            int u = edge[0], v = edge[1];
            connected[u][v] = true;
            connected[v][u] = true;
            degree[u]++;
            degree[v]++;
        }

        int answer = Integer.MAX_VALUE;
        for (int i = 1; i <= n; i++) {
            for (int j = i + 1; j <= n; j++) {
                if (!connected[i][j]) continue;
                for (int k = j + 1; k <= n; k++) {
                    if (connected[i][k] && connected[j][k]) {
                        answer = Math.min(answer,
                            degree[i] + degree[j] + degree[k] - 6);
                    }
                }
            }
        }
        return answer == Integer.MAX_VALUE ? -1 : answer;
    }
}

常见错误

  • 把连通三元组误解为任意三节点连通，而不是两两直接相连。
  • 度数和只减 3；实际上内部边被两端各统计一次，必须减 6。
  • 把“没有三元组”和“最小度数为 0”混为一谈。
  • 三重循环不保持严格递增，导致重复枚举。
