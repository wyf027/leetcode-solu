FLIGHT RULES

规则必须覆盖整个字符串

给定字符串 s 和模式 p，判断模式能否完整匹配字符串。普通字母必须相等；? 匹配任意一个字符；* 匹配任意长度序列，包括空串。

状态语义

dp[i][j] = p 的前 i 个字符
能否匹配 s 的前 j 个字符

右下角 dp[p.length][s.length] 才是最终答案。

    CORE INSIGHT

    星号只有两种合法动作

    定义 dp[i][j] 为模式前 i 个字符能否匹配字符串前 j 个字符。普通字符或 ? 只能由左上角转移；* 要么匹配空串，从上方继承，要么继续吞掉一个字符，从左侧继承。

    normal / ? → dp[i−1][j−1]
    * → dp[i−1][j] OR dp[i][j−1]

    COMPLEXITY

    二维语义，一维存储

    遍历模式与字符串的全部前缀组合；提交代码用长度 |s|+1 的滚动数组保存当前行。

    TIME

    O(mn)

    SPACE

    O(m)

    FULL PROCESS & PROOF

    完整过程与正确性

    1. 1. 空前缀：dp[0][0] = true；空模式不能匹配非空字符串。
    2. 2. 空字符串：只有连续的前导 * 能让 dp[i][0] 保持 true。
    3. 3. 普通字符 / ?：当前字符兼容且左上角为 true，当前格才为 true；这恰好消费双方各一个字符。
    4. 4. 星号：上方代表 * 匹配空串，左侧代表它再消费一个字符；两种完整且互斥的最后动作取或即可。
    5. 5. 归纳：初始化覆盖长度 0；每格枚举最后一步的全部可能，所以按前缀长度递增后右下角就是全串答案。

    BOUNDARIES

    边界情况

    • • s = "", p = ""：true。
    • • s = "", p = "***"：true。
    • • 空字符串遇到普通字符或 ?：false。
    • • 必须全串匹配，不能只匹配子串。

    ALTERNATIVES

    贪心检查点

    双指针记录最近一个 * 与当时的字符串位置，失败时让该星号多吞一个字符并回退模式，可达 O(m+n) 时间、O(1) 空间。它更快，但回退不变量的证明与边界更难；面试先给稳定 DP，再主动补充贪心优化。

    INTERVIEW FOLLOW-UPS

    面试高频追问

    Q：星号为什么看上方和左侧？
    上方丢掉星号，表示匹配空串；左侧保留星号，表示再吞一个字符。
    Q：滚动数组为什么方向不同？
    非星号要读取上一行左上值，因此从右向左；星号要读取当前行左值，因此从左向右。
    Q：和正则匹配有什么区别？
    本题 * 自己就匹配任意序列；正则中的 * 修饰前一个元素，语义完全不同。

    COMMON MISTAKES

    常见错误

    • • 把 * 当成只能匹配至少一个字符，漏掉上方转移。
    • • 忘记初始化模式前导星号匹配空字符串。
    • • 滚动数组所有字符都用同一遍历方向，覆盖尚未读取的旧值。
    • • 写成子串匹配，忽略必须覆盖整个输入。
    • • 混淆通配符与正则表达式中星号的含义。
