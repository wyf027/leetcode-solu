04 / Solution

条件聚合：一次分组同时证明“有”与“无”

将每位顾客的订单压缩成三个布尔事实：出现过 A、出现过 B、出现过 C。只保留前两者为真、第三者为假的分组。

Orders 扫描O(N)
概念模型下单次聚合
结果排序O(K log K)
K 为答案顾客数
聚合状态O(C)
C 为参与分组顾客数
核心洞察集合成员关系
  • 条件和大于 0，证明至少买过一次 A。
  • 对 B 使用相同的存在性判断。
  • C 的条件和等于 0，证明整个分组从未出现 C。
  • D 等无关产品不会改变三个目标标记。
完整过程GROUP BY
  1. 连接顾客和订单，取得姓名与产品记录。
  2. 按顾客分组，把多条订单收敛为一组。
  3. 在 HAVING 中验证 A、B 存在且 C 缺席。
  4. 按顾客编号升序输出。
官方可提交主解 · MySQL
条件聚合
SQL
-- Write your MySQL query statement below
SELECT c.customer_id, c.customer_name
FROM Customers AS c
JOIN Orders AS o
  ON o.customer_id = c.customer_id
GROUP BY c.customer_id, c.customer_name
HAVING SUM(CASE WHEN o.product_name = 'A' THEN 1 ELSE 0 END) > 0
   AND SUM(CASE WHEN o.product_name = 'B' THEN 1 ELSE 0 END) > 0
   AND SUM(CASE WHEN o.product_name = 'C' THEN 1 ELSE 0 END) = 0
ORDER BY c.customer_id;
正确性证明

充分性：被保留分组的 A、B 条件和均大于 0，所以顾客至少各有一条 A、B 订单；C 条件和为 0，所以没有任何 C 订单。因此每个输出都满足题意。

必要性：任意满足题意的顾客都至少各有一条 A、B 订单，且没有 C 订单，因此三个 HAVING 条件必然成立，不会被漏掉。充分性和必要性同时成立，查询恰好返回目标集合；ORDER BY 保证排序契约。

边界情况
  • 重复购买 A 或 B：只检查是否大于 0，不会误判。
  • 买过 A、B、C：C 条件和大于 0，必须排除。
  • 只买 A 或只买 B：另一项条件不成立。
  • 只买无关产品 D：A、B 条件均不成立。
  • 完全没有订单：内连接下不参与候选，也不可能满足 A 与 B。
  • 同名顾客：按唯一 customer_id 区分。
复杂度与数据库视角

将聚合视作哈希分组，扫描 N 条订单的期望时间为 O(N)，保存至多 C 个顾客的状态为 O(C)，对 K 条结果排序为 O(K log K)。真实数据库会根据统计信息、索引与排序/哈希聚合策略选择执行计划。

可考虑 Orders(customer_id, product_name) 复合索引；是否受益应以真实数据分布和执行计划为准。
替代方案

集合交差：分别取得购买 A、B、C 的顾客，计算 A ∩ B − C，表达直观但可能多次访问订单表。

EXISTS / NOT EXISTS：从 Customers 出发写两个存在子查询和一个不存在子查询，语义最贴近题目。

SELECT c.customer_id, c.customer_name
FROM Customers c
WHERE EXISTS (
  SELECT 1 FROM Orders o
  WHERE o.customer_id = c.customer_id AND o.product_name = 'A'
)
AND EXISTS (
  SELECT 1 FROM Orders o
  WHERE o.customer_id = c.customer_id AND o.product_name = 'B'
)
AND NOT EXISTS (
  SELECT 1 FROM Orders o
  WHERE o.customer_id = c.customer_id AND o.product_name = 'C'
)
ORDER BY c.customer_id;
面试追问
  • 产品条件改成动态“必须集合”和“排除集合”时如何建模？
  • 为什么 NOT IN 在子查询可能出现 NULL 时危险？
  • 只统计最近 90 天时，时间条件应放在哪里？
  • 高基数订单表上，哈希聚合与排序聚合如何权衡？
  • 怎样用位掩码表达相同条件？
常见错误
  • 写 product_name = 'A' AND product_name = 'B'：一行不能同时为两个值。
  • 先用 WHERE 只留下 A、B 再检查 C：C 已被删掉，无法证明缺席。
  • 用 COUNT(*) = 2：重复购买和无关产品都会破坏计数。
  • 漏掉 ORDER BY customer_id。
  • 按姓名分组：同名顾客会被错误合并。

import java.util.*;

public class Solution1398 {
    record Customer(int customerId, String customerName) {}
    record Order(int orderId, int customerId, String productName) {}

    public static List<Customer> findCustomers(
            List<Customer> customers, List<Order> orders) {
        Map<Integer, Set<String>> products = new HashMap<>();
        for (Order order : orders) {
            products.computeIfAbsent(
                order.customerId(), ignored -> new HashSet<>()
            ).add(order.productName());
        }

        List<Customer> answer = new ArrayList<>();
        for (Customer customer : customers) {
            Set<String> set = products.getOrDefault(
                customer.customerId(), Collections.emptySet()
            );
            if (set.contains("A") && set.contains("B") && !set.contains("C")) {
                answer.add(customer);
            }
        }
        answer.sort(Comparator.comparingInt(Customer::customerId));
        return answer;
    }
}
JavaScript 本地语义参考
/**
 * @param {{customer_id:number, customer_name:string}[]} customers
 * @param {{order_id:number, customer_id:number, product_name:string}[]} orders
 * @return {{customer_id:number, customer_name:string}[]}
 */
function findCustomers(customers, orders) {
  const products = new Map();

  for (const order of orders) {
    if (!products.has(order.customer_id)) {
      products.set(order.customer_id, new Set());
    }
    products.get(order.customer_id).add(order.product_name);
  }

  return customers
    .filter((customer) => {
      const set = products.get(customer.customer_id) ?? new Set();
      return set.has("A") && set.has("B") && !set.has("C");
    })
    .sort((a, b) => a.customer_id - b.customer_id);
}
Python 本地语义参考
from collections import defaultdict
from typing import TypedDict


class Customer(TypedDict):
    customer_id: int
    customer_name: str


class Order(TypedDict):
    order_id: int
    customer_id: int
    product_name: str


def find_customers(
    customers: list[Customer], orders: list[Order]
) -> list[Customer]:
    products: dict[int, set[str]] = defaultdict(set)
    for order in orders:
        products[order["customer_id"]].add(order["product_name"])

    answer = [
        customer
        for customer in customers
        if "A" in products[customer["customer_id"]]
        and "B" in products[customer["customer_id"]]
        and "C" not in products[customer["customer_id"]]
    ]
    return sorted(answer, key=lambda c: c["customer_id"])
C++ 本地语义参考
#include <algorithm>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>

struct Customer {
    int customerId;
    std::string customerName;
};

struct Order {
    int orderId;
    int customerId;
    std::string productName;
};

std::vector<Customer> findCustomers(
    const std::vector<Customer>& customers,
    const std::vector<Order>& orders
) {
    std::unordered_map<int, std::unordered_set<std::string>> products;
    for (const Order& order : orders) {
        products[order.customerId].insert(order.productName);
    }

    std::vector<Customer> answer;
    for (const Customer& customer : customers) {
        const auto it = products.find(customer.customerId);
        if (it == products.end()) continue;
        const auto& set = it->second;
        if (set.count("A") && set.count("B") && !set.count("C")) {
            answer.push_back(customer);
        }
    }
    std::sort(answer.begin(), answer.end(), [](const auto& a, const auto& b) {
        return a.customerId < b.customerId;
    });
    return answer;
}
