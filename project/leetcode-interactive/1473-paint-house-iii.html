粉刷房子 III

不是“每间房选最便宜颜色”这么简单：颜色的连续性会改变街区数。本页先让你看懂问题，再亲手沿着动态规划的状态层向前推进。

题号 1473困难非付费题Paint House III

Problem

题目

目标：恰好 target 个街区

一排共有 m 间房，每间最终必须使用编号 1..n 中的一种颜色。houses[i] = 0 表示尚未粉刷；非零则表示已经粉刷且不能改色。把未粉刷的第 i 间房涂为颜色 j + 1，花费为 cost[i][j]。

街区是颜色相同且连续的极大房屋段。例如 [1,2,2,3,3,2,1,1] 有 5 个街区：[1] [2,2] [3,3] [2] [1,1]。

请粉刷所有剩余房屋，使最终恰好形成 target 个街区，并返回最小总花费；若不存在方案，返回 -1。已粉刷房屋不产生花费。

函数
minCost(houses, cost, m, n, target)
返回
满足条件的最小总花费，无法完成时为 -1。

示例 1

输入：houses = [0,0,0,0,0]
cost = [[1,10],[10,1],[10,1],[1,10],[5,1]]
m = 5, n = 2, target = 3
输出：9
解释：[1,2,2,1,1] 形成 3 个街区，花费 1+1+1+1+5=9。

输入：houses = [0,2,1,2,0]
cost = [[1,10],[10,1],[10,1],[1,10],[5,1]]

输出：11
解释：[2,2,1,2,2] 形成 3 个街区，只粉刷首尾，花费 10+1=11。

约束

  • m == houses.length == cost.length
  • n == cost[i].length
  • 1 ≤ m ≤ 100
  • 1 ≤ n ≤ 20
  • 1 ≤ target ≤ m
  • 0 ≤ houses[i] ≤ n
  • 1 ≤ cost[i][j] ≤ 10⁴

Solution

准备好拆解三维状态了吗？

题解默认收起，先用上面的推进器猜一猜：为什么“末尾颜色”必须成为状态的一部分？

Core insight

核心洞察：记住前缀的末尾颜色

新房颜色与上一间相同时，街区数不变；不同时，街区数加一。所以处理完一个前缀后，只需保留两个影响未来的信息：已形成的街区数、最后一间房的颜色，并记录达到该状态的最小花费。

dp[k][c] = 处理当前前缀后，恰有 k 个街区且末尾颜色为 c 的最小花费

Process

完整过程

  1. 初始化一个“虚拟前缀”：还未处理房屋。
  2. 逐间扫描。若房屋已粉刷，只允许它的固定颜色，新增花费为 0；否则枚举全部 n 种颜色并加对应 cost。
  3. 从上一层的每个 (k, prevColor) 转移。新旧颜色相同则仍是 k 个街区，否则变为 k+1。
  4. 丢弃街区数超过 target 的状态；同一新状态只保留最小花费。
  5. 处理完 m 间房，在所有 dp[target][color] 中取最小值；不可达返回 -1。

Boundary

边界处理

  • 第一间房自然创建第 1 个街区，可用前置颜色 0 特判。
  • 固定颜色房屋绝不能枚举其他颜色，也不累加 cost。
  • 只保留 1..target 个街区，避免无效状态。
  • 使用足够大的无穷值，且只从可达状态转移，防止溢出。
  • 若所有目标状态均不可达，返回 -1。

Correctness

正确性证明

状态不变式。 处理完前 i 间房后，dp[k][c] 等于所有合法粉刷方案中，恰有 k 个街区且第 i 间颜色为 c 的最小花费。
基础。 第一间房选择允许的颜色 c 后形成一个街区，记录的正是该选择的粉刷花费（若已粉刷则为 0），故不变式成立。
归纳。 假设前 i-1 间的不变式成立。第 i 间选择颜色 c 时，任何合法方案都唯一来自某个末色 p 的前缀；p=c 时街区数不变，否则加一。转移枚举了所有 p 与所有允许的 c，并取最小值，因此既不遗漏合法方案，也不会引入非法方案，且得到最小花费。
终止。 处理全部 m 间后，枚举末色 c 的 dp[target][c] 正好覆盖全部恰有 target 个街区的完整方案；其中最小值即答案。若均不可达，则确实无方案。

Complexity

复杂度

时间复杂度 O(m · target · n²)：每间房、每个街区数、每个旧颜色枚举新颜色。使用滚动数组后，空间复杂度 O(target · n)。当房屋颜色固定时实际只枚举一个新颜色，但最坏界不变。

Alternative

替代方案

可定义三维记忆化搜索 dfs(i, prevColor, groups)，表达更贴近决策树，复杂度相同，但递归栈和缓存常数更大。还可维护每个 k 下最小与次小的前置颜色，把颜色转移优化至 O(n)，得到 O(m · target · n)，实现细节更易出错，面试中应先写稳健版本。

Interview

面试追问

  • 为什么仅记录街区数不够？请构造末色不同但街区数相同的前缀。
  • 如何把 n² 优化成 n？最小值与次小值分别何时使用？
  • 如果要求同时返回一种最优粉刷方案，需要保存什么父指针？
  • 若目标改为“不超过 target 个街区”，终态如何聚合？

Pitfalls

常见错误

  • 给已粉刷房屋重复计费或允许改色。
  • 颜色变化时忘记把街区数加一。
  • 第一间房按“与前色不同”处理却没有正确初始化。
  • 原地更新 dp，导致同一间房被使用多次。
  • 答案直接取某个固定末色，而非对所有颜色取最小。

import java.util.Arrays;

class Solution {
    public int minCost(int[] houses, int[][] cost, int m, int n, int target) {
        final int INF = 1_000_000_000;
        int[][] dp = new int[target + 1][n];
        for (int[] row : dp) Arrays.fill(row, INF);

        for (int color = 0; color < n; color++) {
            if (houses[0] == 0 || houses[0] == color + 1) {
                dp[1][color] = houses[0] == 0 ? cost[0][color] : 0;
            }
        }

        for (int i = 1; i < m; i++) {
            int[][] next = new int[target + 1][n];
            for (int[] row : next) Arrays.fill(row, INF);
            for (int groups = 1; groups <= target; groups++) {
                for (int prev = 0; prev < n; prev++) {
                    if (dp[groups][prev] == INF) continue;
                    for (int color = 0; color < n; color++) {
                        if (houses[i] != 0 && houses[i] != color + 1) continue;
                        int nextGroups = groups + (prev == color ? 0 : 1);
                        if (nextGroups > target) continue;
                        int paint = houses[i] == 0 ? cost[i][color] : 0;
                        next[nextGroups][color] = Math.min(
                            next[nextGroups][color], dp[groups][prev] + paint
                        );
                    }
                }
            }
            dp = next;
        }

        int answer = INF;
        for (int color = 0; color < n; color++) {
            answer = Math.min(answer, dp[target][color]);
        }
        return answer == INF ? -1 : answer;
    }
}
/**
 * @param {number[]} houses
 * @param {number[][]} cost
 * @param {number} m
 * @param {number} n
 * @param {number} target
 * @return {number}
 */
var minCost = function (houses, cost, m, n, target) {
    const INF = Number.MAX_SAFE_INTEGER;
    let dp = Array.from({ length: target + 1 }, () => Array(n).fill(INF));

    for (let color = 0; color < n; color++) {
        if (houses[0] === 0 || houses[0] === color + 1) {
            dp[1][color] = houses[0] === 0 ? cost[0][color] : 0;
        }
    }

    for (let i = 1; i < m; i++) {
        const next = Array.from({ length: target + 1 }, () => Array(n).fill(INF));
        for (let groups = 1; groups <= target; groups++) {
            for (let prev = 0; prev < n; prev++) {
                if (dp[groups][prev] === INF) continue;
                for (let color = 0; color < n; color++) {
                    if (houses[i] !== 0 && houses[i] !== color + 1) continue;
                    const nextGroups = groups + (prev === color ? 0 : 1);
                    if (nextGroups > target) continue;
                    const paint = houses[i] === 0 ? cost[i][color] : 0;
                    next[nextGroups][color] = Math.min(
                        next[nextGroups][color], dp[groups][prev] + paint
                    );
                }
            }
        }
        dp = next;
    }

    const answer = Math.min(...dp[target]);
    return answer === INF ? -1 : answer;
};

class Solution:
    def minCost(
        self,
        houses: List[int],
        cost: List[List[int]],
        m: int,
        n: int,
        target: int,
    ) -> int:
        inf = float("inf")
        dp = [[inf] * n for _ in range(target + 1)]

        for color in range(n):
            if houses[0] == 0 or houses[0] == color + 1:
                dp[1][color] = cost[0][color] if houses[0] == 0 else 0

        for i in range(1, m):
            nxt = [[inf] * n for _ in range(target + 1)]
            for groups in range(1, target + 1):
                for prev in range(n):
                    if dp[groups][prev] == inf:
                        continue
                    for color in range(n):
                        if houses[i] != 0 and houses[i] != color + 1:
                            continue
                        next_groups = groups + (prev != color)
                        if next_groups > target:
                            continue
                        paint = cost[i][color] if houses[i] == 0 else 0
                        nxt[next_groups][color] = min(
                            nxt[next_groups][color], dp[groups][prev] + paint
                        )
            dp = nxt

        answer = min(dp[target])
        return -1 if answer == inf else answer

            }

            vector<vector<int>> next(target + 1, vector<int>(n, INF));
            for (int groups = 1; groups <= target; ++groups) {
                for (int prev = 0; prev < n; ++prev) {
                    if (dp[groups][prev] == INF) continue;
                    for (int color = 0; color < n; ++color) {
                        if (houses[i] != 0 && houses[i] != color + 1) continue;

                        next[nextGroups][color] = min(
                            next[nextGroups][color], dp[groups][prev] + paint
                        );
                    }
                }
            }
            dp.swap(next);
        }

        int answer = *min_element(dp[target].begin(), dp[target].end());
        return answer == INF ? -1 : answer;
