3961. 设备评分的最大和

让每台设备至多送出一个单元；怎样把所有“拖后腿”的最小值集中到一台设备上？

打开题目

题意与示例

units[i][j] 是第 i 台设备的第 j 个单元容量；设备评分是其单元容量最小值。每台设备至多一次可送出一个单元给另一台设备，求最终评分和的最大值。

输入 操作 输出
units = [[1,3],[2,2]] 1 送到第二台 4
units = [[1,2,3],[4,5,6]] 4 送到第一台 6
units = [[5,5,5],[1,1,1]] 不操作 6

约束：1 ≤ m,n ≤ 10⁵，m × n ≤ 2 × 10⁵，容量不超过 10⁵。

可见交互：选择“汇集设备”

例如第一行 1,3 表示第 0 台设备。按 Ctrl/⌘ + Enter 或按钮计算。

输入矩阵后点击“计算最大评分和”。

题解与四语言实现

默认折叠；先观察交互，再展开核对贪心不变量。

每台先看两个最小值

若设备送走自身最小单元，它的评分最多提升到第二小值；其它单元对评分无影响。

把最小值集中

接收单元只能降低评分，所以所有送出的最小值应集中到同一台“汇集设备”。它最终贡献全局最小值。

只付一次最小损失

其他设备贡献各自第二小值；汇集设备放弃其第二小值，因此选择第二小值最小的设备作为汇集设备。

完整过程：当 n > 1，答案是 sum(secondMin[row]) - min(secondMin[row]) + min(firstMin[row])。若 n = 1，任何送出都会让源设备空掉，直接求每行唯一值之和。
边界、替代与错误：单列是特殊分支；答案可能达到 10¹⁰，Java/C++ 用 long/long long。排序每行是 O(m·n log n)；更推荐一次扫描维护两小值，时间 O(m·n)、额外空间 O(1)。常见错误是把每个第二小值直接相加，忘记一个接收设备必须承受全局最小值。
面试追问：若允许每台送出 k 个单元，需要维护第 k+1 小值并重新证明“损失集中”仍是否成立。 
class Solution {
    public long maxRatings(int[][] units) {
        if (units[0].length == 1) { long sum = 0; for (int[] row : units) sum += row[0]; return sum; }
        long sum = 0; int globalFirst = Integer.MAX_VALUE, smallestSecond = Integer.MAX_VALUE;
        for (int[] row : units) {
            int first = Integer.MAX_VALUE, second = Integer.MAX_VALUE;
            for (int value : row) { if (value < first) { second = first; first = value; } else if (value < second) second = value; }
            sum += second; globalFirst = Math.min(globalFirst, first); smallestSecond = Math.min(smallestSecond, second);
        }
        return sum - smallestSecond + globalFirst;
    }
}
function maxRatings(units) {
  if (units[0].length === 1) return units.reduce((sum, row) => sum + row[0], 0);
  let sum = 0, globalFirst = Infinity, smallestSecond = Infinity;
  for (const row of units) {
    let first = Infinity, second = Infinity;
    for (const value of row) { if (value < first) [first, second] = [value, first]; else if (value < second) second = value; }
    sum += second; globalFirst = Math.min(globalFirst, first); smallestSecond = Math.min(smallestSecond, second);
  }
  return sum - smallestSecond + globalFirst;
}
class Solution:
    def maxRatings(self, units: list[list[int]]) -> int:
        if len(units[0]) == 1:
            return sum(row[0] for row in units)
        total, global_first, smallest_second = 0, float("inf"), float("inf")
        for row in units:
            first = second = float("inf")
            for value in row:
                if value < first:
                    first, second = value, first
                elif value < second:
                    second = value
            total += second
            global_first = min(global_first, first)
            smallest_second = min(smallest_second, second)
        return total - smallest_second + global_first
