用三种不同颜色
为网格涂色

Painting a Grid With Three Different Colors

每一格都要有颜色，每一条相邻边都要保持不同。

先理解规则，再展开下方题解与交互实验。

01 / 题目

给定整数 m、n，为一个 m × n 网格的每个格子选择红、绿、蓝之一。任意上下或左右相邻的两个格子都必须颜色不同；对角线不算相邻。求不同完整涂色方案的数量，返回其对 1,000,000,007 取余的结果。

参数与返回值

colorTheGrid(m, n) → integer

m 是行数，n 是列数。位置固定，交换颜色后只要某个格子的颜色变化，就属于不同方案。

官方约束

  • 1 ≤ m ≤ 5
  • 1 ≤ n ≤ 1000
  • 每个格子必须涂色，颜色只有三种。

04 / 题解 · 把一列作为边界

核心洞察

列数很长，行数最多只有 5。一列内部先保证上下不同，合法列的数量只有 S = 3 × 2^(m−1) ≤ 48。追加下一列时，历史列中只有最后一列与它接壤，因此无需记住整个网格。

用三进制数字 0、1、2 表示红、绿、蓝，把一列从上到下的颜色保存为状态。列内相邻数字不能相等；两个列状态 A、B 能连接，当且仅当每一行都满足 A[r] ≠ B[r]。

完整过程

  1. 枚举 0 … 3^m−1，解码出 m 个三进制位；仅保留上下异色的列。
  2. 对所有合法列对逐行比较，预计算兼容邻接表 next[a]。
  3. 令 dp[b] 表示已涂 c 列、且第 c 列状态为 b 的方案数。第一列的每个合法状态对应恰好一种方案，所以全部初始化为 1。
  4. 追加一列：先把新数组清零，再对每条兼容边 a → b 执行 newDp[b] = (newDp[b] + dp[a]) % MOD。
  5. 重复 n−1 次，最后把所有末列状态的计数求和取模。
dp₁[b] = 1
compatible(a, b) ⇔ 对所有行 r，a[r] ≠ b[r]
dp꜀[b] = Σ dp꜀₋₁[a]  （仅对 compatible(a, b) 求和）
answer = Σ dpₙ[b] mod 1,000,000,007

为什么正确

状态合法：枚举覆盖每一种列涂色，过滤仅移除含竖向同色边的列。初始情况：一列的合法网格与合法列状态一一对应，计数为 1。

归纳步骤：假设 dp 精确统计前 c−1 列。添加 b 后，新增约束只涉及 b 的内部和它与上一列 a 之间的横向边，前者已由过滤保证，后者由兼容关系保证。因此每个转移都得到合法网格。反过来，任意 c 列合法网格都能唯一拆成前缀和末列 b，其前缀末列 a 必然兼容 b，故没有遗漏，也没有重复计数。最后按末列状态求和覆盖全部合法网格。取模与加法相容，不影响最终余数。

边界与复杂度

  • n = 1：不执行转移，答案是 3 × 2^(m−1)。
  • m = 1：三个状态，每个状态能连接另外两个，答案为 3 × 2^(n−1) 取模。
  • 令 E 为有向兼容边数量，E ≤ S²。时间为 O(m·3^m + m·S² + n·E)；最坏可写为 O(m·3^m + (m+n)·S²)。空间为 O(m·S + E + S)，包括状态、邻接表与两层 DP。
  • Java 使用 long、C++ 使用 long long 保存中间和。JavaScript 每次加法后立即取模，使单次和小于 2·MOD，处于 Number 的精确整数范围内。

替代方案

也可以用每格 2 位的位掩码编码列，仍然做相同的列状态 DP。逐格记忆化搜索可行，但需要维护边界信息并处理换列。若 n 远大于当前上限，可用兼容矩阵快速幂，将依赖 n 的部分变为 O(S³ log n)，代价是实现与常数更大。直接枚举所有格子有 3^(mn) 个候选，不适合本题。

常见错误

  • 只检查列内上下相邻，漏掉两列之间的左右相邻。
  • 认为两个列状态编号不同就兼容；必须每一行颜色都不同。
  • 在原 dp 数组上原地累加，混用新旧列的计数。
  • 把所有末列状态当作一种方案，或初始化为 0，丢失第一列基数。
  • 先累积很大的总数再取模，导致溢出或 JavaScript 精度丢失。

面试追问

换成 k 种颜色？列状态上限变为 k·(k−1)^(m−1)，用 k 进制或回溯生成，兼容规则不变。若横向首尾相邻？需额外约束末列与首列兼容，可固定首列后运行 DP；不能直接把当前终态求和。若 m、n 都很大？此算法依赖较短边很小；能交换维度时将较小者用作状态高度，否则状态数仍会指数增长。

Java

import java.util.*;

class Solution {
    public int colorTheGrid(int m, int n) {
        final long MOD = 1_000_000_007L;
        List<int[]> states = new ArrayList<>();
        int limit = 1;
        for (int r = 0; r < m; r++) limit *= 3;
        for (int mask = 0; mask < limit; mask++) {
            int[] col = new int[m];
            int x = mask;
            boolean valid = true;
            for (int r = 0; r < m; r++) {
                col[r] = x % 3;
                x /= 3;
                if (r > 0 && col[r] == col[r - 1]) valid = false;
            }
            if (valid) states.add(col);
        }
        int s = states.size();
        List<List<Integer>> next = new ArrayList<>();
        for (int a = 0; a < s; a++) {
            next.add(new ArrayList<>());
            for (int b = 0; b < s; b++) {
                boolean ok = true;
                for (int r = 0; r < m; r++) {
                    if (states.get(a)[r] == states.get(b)[r]) {
                        ok = false;
                        break;
                    }
                }
                if (ok) next.get(a).add(b);
            }
        }
        long[] dp = new long[s];
        Arrays.fill(dp, 1);
        for (int c = 1; c < n; c++) {
            long[] ndp = new long[s];
            for (int a = 0; a < s; a++)
                for (int b : next.get(a))
                    ndp[b] = (ndp[b] + dp[a]) % MOD;
            dp = ndp;
        }
        long ans = 0;
        for (long value : dp) ans = (ans + value) % MOD;
        return (int) ans;
    }
}

/**
 * @param {number} m
 * @param {number} n
 * @return {number}
 */
var colorTheGrid = function(m, n) {
    const MOD = 1000000007;
    const states = [];
    for (let mask = 0; mask < 3 ** m; mask++) {
        const col = [];
        let x = mask, valid = true;
        for (let r = 0; r < m; r++) {
            col.push(x % 3);
            x = Math.floor(x / 3);
            if (r > 0 && col[r] === col[r - 1]) valid = false;
        }
        if (valid) states.push(col);
    }
    const s = states.length;
    const next = Array.from({length: s}, () => []);
    for (let a = 0; a < s; a++) {
        for (let b = 0; b < s; b++) {
            if (states[a].every((color, r) => color !== states[b][r]))
                next[a].push(b);
        }
    }
    let dp = Array(s).fill(1);
    for (let c = 1; c < n; c++) {
        const ndp = Array(s).fill(0);
        for (let a = 0; a < s; a++) {
            for (const b of next[a]) ndp[b] = (ndp[b] + dp[a]) % MOD;
        }
        dp = ndp;
    }
    return dp.reduce((sum, value) => (sum + value) % MOD, 0);
};

Python 3

class Solution:
    def colorTheGrid(self, m: int, n: int) -> int:
        mod = 1_000_000_007
        states = []
        for mask in range(3 ** m):
            col = []
            x = mask
            for _ in range(m):
                col.append(x % 3)
                x //= 3
            if all(col[r] != col[r - 1] for r in range(1, m)):
                states.append(col)

        size = len(states)
        nxt = [[] for _ in range(size)]
        for a in range(size):
            for b in range(size):
                if all(states[a][r] != states[b][r] for r in range(m)):
                    nxt[a].append(b)

        dp = [1] * size
        for _ in range(n - 1):
            ndp = [0] * size
            for a in range(size):
                for b in nxt[a]:
                    ndp[b] = (ndp[b] + dp[a]) % mod
            dp = ndp
        return sum(dp) % mod

C++

#include <vector>
using namespace std;

class Solution {
public:
    int colorTheGrid(int m, int n) {
        const long long MOD = 1000000007;
        vector<vector<int>> states;
        int limit = 1;
        for (int r = 0; r < m; ++r) limit *= 3;
        for (int mask = 0; mask < limit; ++mask) {
            vector<int> col(m);
            int x = mask;
            bool valid = true;
            for (int r = 0; r < m; ++r) {
                col[r] = x % 3;
                x /= 3;
                if (r > 0 && col[r] == col[r - 1]) valid = false;
            }
            if (valid) states.push_back(col);
        }
        int s = states.size();
        vector<vector<int>> next(s);
        for (int a = 0; a < s; ++a) {
            for (int b = 0; b < s; ++b) {
                bool ok = true;
                for (int r = 0; r < m; ++r) {
                    if (states[a][r] == states[b][r]) {
                        ok = false;
                        break;
                    }
                }
                if (ok) next[a].push_back(b);
            }
        }
        vector<long long> dp(s, 1);
        for (int c = 1; c < n; ++c) {
            vector<long long> ndp(s, 0);
            for (int a = 0; a < s; ++a)
                for (int b : next[a])
                    ndp[b] = (ndp[b] + dp[a]) % MOD;
            dp.swap(ndp);
        }
        long long ans = 0;
        for (long long value : dp) ans = (ans + value) % MOD;
        return static_cast<int>(ans);
    }
};
