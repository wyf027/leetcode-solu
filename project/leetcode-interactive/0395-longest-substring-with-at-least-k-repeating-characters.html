至少有 K 个重复字符的最长子串

Longest Substring with At Least K Repeating Characters

字符串哈希表分治滑动窗口

题目

给定一个只包含小写英文字母的字符串 s 和整数 k，在 s 的所有连续子串中，找出满足“子串里的每一种字符都至少出现 k 次”的最长者，返回其长度；若不存在，返回 0。

示例 1

输入：s = "aaabb", k = 3
输出：3
解释：最长子串是 "aaa"，字符 'a' 出现 3 次。

示例 2

输入：s = "ababbc", k = 2
输出：5
解释：最长子串是 "ababb"，其中 'a' 出现 2 次，
      'b' 出现 3 次。

约束

  • 1 <= s.length <= 104
  • s 仅由小写英文字母组成。
  • 1 <= k <= 105

    题解：用“不合格字符”切开搜索空间

    这里选用分治。它与上方实验室的区间轨迹一一对应：检查当前区间，找到在该区间内出现次数少于 k 的字符，再围绕这些字符切分。

    核心洞察

    若字符 x 在整个候选区间里只出现了少于 k 次，那么任何包含 x 的子串都不可能让它达到 k 次。因此，合法答案绝不会跨过该区间中任意一个 x；这些位置天然是分隔点。

    完整过程

    1. 递归处理半开区间 [left, right)。如果区间长度小于 k，直接返回 0。
    2. 统计区间内 26 个小写字母的出现次数。
    3. 从左向右找第一个出现次数在 1..k-1 的字符位置 mid。
    4. 若找不到这样的字符，说明区间内每个实际出现的字符都已达标，返回区间长度。
    5. 答案不能包含 s[mid]。递归处理左侧；再跳过从 mid 开始的一段同类不合格字符，递归处理右侧，取两者最大值。

    正确性证明

    引理：设字符 c 在当前区间出现少于 k 次，则当前区间内任何包含 c 的子串都不合法。因为子串中 c 的次数不会超过整个区间中的次数。
    分割完备性：由引理，任何合法子串都不能跨越被选中的不合格字符位置，只能完整位于它左侧或跳过连续分隔位置后的右侧。递归考察两侧不会漏掉合法候选。
    归纳结论：若区间没有不合格字符，整个区间合法且显然是该区间最长答案；否则，根据更短区间上的递归结果与分割完备性，左右最大值就是当前区间的最优值。因此入口区间返回全局最优答案。

    边界情况

    • k = 1：任意非空输入的整个字符串都合法。
    • k > s.length：没有非空子串可能达标，返回 0。
    • 所有字符的总频次都小于 k：分隔会持续缩小区间，最终返回 0。
    • 整个字符串已经合法：第一次统计后直接返回其长度。

    复杂度

    每层递归会线性扫描所属区间。在小写字母固定为 26 种的条件下，沿任一路径每次有效切分都会排除至少一种不合格字符，常用分析为 O(26n) = O(n) 时间；若把字符集视为不受限且切分极不均匀，保守上界可写为 O(n²)。递归栈最坏 O(n)，固定 26 字符的典型深度则很小；频次数组为 O(1)。

    class Solution {
    public int longestSubstring(String s, int k) {
        if (s == null || s.length() == 0 || k > s.length()) {
            return 0;
        }
        return solve(s, 0, s.length(), k);
    }

    private int solve(String s, int left, int right, int k) {
        if (right - left < k) return 0;

        int[] count = new int[26];
        for (int i = left; i < right; i++) {
            count[s.charAt(i) - 'a']++;
        }

        int mid = left;
        while (mid < right && count[s.charAt(mid) - 'a'] >= k) {
            mid++;
        }
        if (mid == right) return right - left;

        int next = mid + 1;
        while (next < right && count[s.charAt(next) - 'a'] < k) {
            next++;
        }
        return Math.max(
            solve(s, left, mid, k),
            solve(s, next, right, k)
        );
    }
}

var longestSubstring = function(s, k) {
    if (s.length === 0 || k > s.length) return 0;

    function solve(left, right) {
        if (right - left < k) return 0;

        const count = new Array(26).fill(0);
        for (let i = left; i < right; i++) {
            count[s.charCodeAt(i) - 97]++;
        }

        let mid = left;
        while (mid < right && count[s.charCodeAt(mid) - 97] >= k) {
            mid++;
        }
        if (mid === right) return right - left;

        let next = mid + 1;
        while (next < right && count[s.charCodeAt(next) - 97] < k) {
            next++;
        }
        return Math.max(solve(left, mid), solve(next, right));
    }

    return solve(0, s.length);
};
    class Solution:
    def longestSubstring(self, s: str, k: int) -> int:
        if not s or k > len(s):
            return 0

        def solve(left: int, right: int) -> int:
            if right - left < k:
                return 0

            count = [0] * 26
            for i in range(left, right):
                count[ord(s[i]) - ord('a')] += 1

            mid = left
            while mid < right and count[ord(s[mid]) - ord('a')] >= k:
                mid += 1
            if mid == right:
                return right - left

            nxt = mid + 1
            while nxt < right and count[ord(s[nxt]) - ord('a')] < k:
                nxt += 1
            return max(solve(left, mid), solve(nxt, right))

        return solve(0, len(s))

public:

        for (int i = left; i < right; ++i) {
            ++count[s[i] - 'a'];

            ++mid;

        if (mid == right) return right - left;

            ++next;

            solve(s, left, mid, k),

    替代方案：枚举不同字符数的滑动窗口

    枚举窗口中允许出现的不同字符种类数 target = 1..26。对每个目标维护左右指针、窗口内不同字符数，以及达到 k 次的字符数；当两者都等于 target 时更新答案。这个方案同样是 O(26n) 时间、O(1) 空间，但状态变量更多，面试中更容易出现窗口收缩条件错误。

    面试追问

    • 如果字符集不是固定 26 个小写字母，复杂度结论和计数结构怎样变化？
    • 为什么不能只用一个普通滑动窗口直接维护“所有字符都至少出现 k 次”？
    • 如何把递归分治改成显式栈，避免极端情况下的调用栈风险？
    • 滑动窗口方案里为什么要枚举窗口的不同字符种类数？

    常见错误

    • 用全字符串频次判断所有递归子区间；频次必须按当前区间重新统计。
    • 把出现 0 次的字符也当成不合格字符；它根本不在当前区间中，不应成为分隔点。
    • 递归右半区间时没有跳过连续不合格位置，导致大量无意义调用。
    • 混用闭区间与半开区间，让长度、循环上界或递归边界出现 off-by-one。
    • 将“子串”误解为“子序列”；本题要求字符位置连续。
