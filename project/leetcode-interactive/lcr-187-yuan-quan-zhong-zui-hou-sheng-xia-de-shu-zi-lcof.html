破冰游戏

编号为 0 到 num - 1 的成员围成冰环，从 0 开始报数；报到 target 的成员离开，下一位重新从 1 开始。找出最后留下的编号。

题意与官方样例

社团共有 num 位成员，编号为 0 ... num - 1。从 0 号开始计数，每次数到第 target 位就让该成员离开，并从下一位重新计数；请返回最后留下的成员编号。

输出：1
官方示例 2num = 12, target = 5
输出：0

1 <= target <= 10^6

题解 · 倒着把编号映射回原冰环

核心洞察

先假设规模 i - 1 时的幸存编号已知。加入一个新成员、并把本轮开始位置旋转 target 步后，旧编号 x 映射为 (x + target) % i。因此从 i = 2 累加到 num 即可。

完整过程

  1. 令 answer = 0，对应只有一个成员时的答案。
  2. 对于 i 从 2 到 num，执行 answer = (answer + target) % i。
  3. 循环结束后 answer 是初始编号体系中的幸存者。

边界与复杂度

num = 1 直接返回 0。迭代递推时间 O(num)、额外空间 O(1)，可以承受 10⁵；target 很大也无需模拟其每次报数。

替代方案

用数组或队列逐个删除便于演示，却会产生 O(num²) 的移位代价（或需要更复杂的数据结构）。本题只要最终编号，递推最直接。

面试追问

若要输出完整淘汰顺序，可用循环链表或 Fenwick 树；若起始编号不是 0，最终答案再加起点后对 num 取模。

常见错误：把“报到 target 的成员离开”误写成 + target - 1 的递推；递推中的重新编号已经吸收了这一步。不要使用递归到 10⁵ 层，迭代更安全。

class Solution {

        int answer = 0;

        return answer;
    }
}
