Solution

把冲突拆成互不影响的链

差恰好为 k 的两个数一定拥有相同的模 k 余数。按余数分组后，每组只需统计一条有断点的冲突链，最后把各组方案数相乘。

1

按余数隔离

若 |a-b|=k，则 a mod k = b mod k。不同余数组之间绝不会冲突。

2

组内只看前一个

每组升序后，当前值只可能与紧邻的前一个值形成差为 k 的冲突。

3

乘法合并

各组选择互相独立，整题答案等于每组合法方案数的乘积，空集自然包含在内。

完整过程

  1. 将 nums 升序排序，并用 x mod k 分组。
  2. 对每组维护 skip（最后一个数不选）和 take（最后一个数选择）的方案数。
  3. 令 all = skip + take。新数不选时，新的 skip = all。
  4. 若新数与前一个数之差为 k，选择新数只能接在旧 skip 后；否则可接在全部旧方案后。
  5. 每组得到 skip + take，把所有组的结果相乘。

正确性

分组正确：任何冲突对的差是 k，所以两数同余；不同组之间选择独立。

组内 DP 正确：升序同余序列中，能与当前数相差 k 的旧元素只能是紧邻前驱。按“选 / 不选当前数”划分，递推覆盖全部方案且互不重叠。

合并正确：从每个独立组各取一个合法子集，与全局合法子集一一对应，因此使用乘法原理。

边界与复杂度

  • 空集计数为 1，初始化自然保留它。
  • 某组没有相差 k 的邻居时，每个元素都可自由选或不选。
  • 连续冲突链的方案数呈斐波那契式增长。
  • n ≤ 50，最大答案 2⁵⁰，可由 64 位整数承载；JavaScript 也仍在安全整数范围内。
时间 O(n log n)空间 O(n)

替代方案与追问

  • 回溯：枚举所有 2ⁿ 个子集，直观但无法通过上限。
  • 图视角：把差为 k 的数连边，本题是在数若干条路径的独立集。
  • 若允许重复：节点会带权；选择某值有 2^count - 1 种非空取法，递推需乘权。
  • 若只数非空：最终答案减 1。

常见错误

  • 忘记把空集算入答案。
  • 把不同余数组的方案数相加，而不是相乘。
  • 遇到组内间隔大于 k 时仍禁止相邻选择。
  • 使用 32 位整数保存最多 2⁵⁰ 的答案。
  • 未排序就只检查同组的前一个元素。

面试追问

  • 为什么模 k 分组足以隔离全部冲突？
  • 如何将状态压缩到两个计数器？
  • 数组动态加入元素时，怎样维护答案？
  • 如果禁止差值集合为多个数，冲突图还会是路径吗？

JavaLeetCode 提交格式
import java.util.*;

class Solution {
  public long countTheNumOfKFreeSubsets(int[] nums, int k) {
    Arrays.sort(nums);
    Map<Integer, List<Integer>> groups = new HashMap<>();
    for (int x : nums) {
      groups.computeIfAbsent(x % k, key -> new ArrayList<>()).add(x);
    }

    long answer = 1;
    for (List<Integer> group : groups.values()) {
      long skip = 1, take = 0;
      int previous = 0;
      boolean hasPrevious = false;
      for (int x : group) {
        long all = skip + take;
        long nextTake = hasPrevious && x - previous == k ? skip : all;
        skip = all;
        take = nextTake;
        previous = x;
        hasPrevious = true;
      }
      answer *= skip + take;
    }
    return answer;
  }
}
JavaScriptLeetCode 提交格式
var countTheNumOfKFreeSubsets = function(nums, k) {
  nums.sort((a, b) => a - b);
  const groups = new Map();
  for (const x of nums) {
    const remainder = x % k;
    if (!groups.has(remainder)) groups.set(remainder, []);
    groups.get(remainder).push(x);
  }

  let answer = 1;
  for (const group of groups.values()) {
    let skip = 1, take = 0, previous = null;
    for (const x of group) {
      const all = skip + take;
      const nextTake = previous !== null && x - previous === k
        ? skip : all;
      skip = all;
      take = nextTake;
      previous = x;
    }
    answer *= skip + take;
  }
  return answer;
};

from collections import defaultdict
from typing import List

class Solution:
    def countTheNumOfKFreeSubsets(self, nums: List[int], k: int) -> int:
        nums.sort()
        groups = defaultdict(list)
        for x in nums:
            groups[x % k].append(x)

        answer = 1
        for group in groups.values():
            skip, take, previous = 1, 0, None
            for x in group:
                all_ways = skip + take
                next_take = skip if previous is not None and x - previous == k else all_ways
                skip, take, previous = all_ways, next_take, x
            answer *= skip + take
        return answer

class Solution {
public:
  long long countTheNumOfKFreeSubsets(vector<int>& nums, int k) {
    sort(nums.begin(), nums.end());
    unordered_map<int, vector<int>> groups;
    for (int x : nums) groups[x % k].push_back(x);

    long long answer = 1;
    for (auto& [remainder, group] : groups) {
      long long skip = 1, take = 0;
      int previous = 0;
      bool hasPrevious = false;
      for (int x : group) {
        long long all = skip + take;
        long long nextTake = hasPrevious && x - previous == k ? skip : all;
        skip = all;
        take = nextTake;
        previous = x;
        hasPrevious = true;
      }
      answer *= skip + take;
    }
    return answer;
  }
};
