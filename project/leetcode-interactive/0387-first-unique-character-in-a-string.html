First Unique Character in a String

在一串字符留下的“出现记录”里，找到最早只出现一次的那个位置。答案需要的是索引，不是字符本身。

01 / Case brief

题目档案

给定字符串 s，找到其中第一个不重复字符的索引。如果每个字符都重复出现，返回 -1。

参数形式：firstUniqChar(s: string) -> integer

约束 1：1 <= s.length <= 10^5

约束 2：s 仅由小写英文字母组成。

示例一

输入：s = "leetcode"
输出：0

索引 0 的 l 没有在其他位置出现。

示例二

输入：s = "loveleetcode"
输出：2

最早满足条件的是索引 2。

示例三

输入：s = "aabb"
输出：-1

不存在只出现一次的字符。

03 / Sealed solution

先形成自己的判断，再打开答案

想一想：为什么仅从左向右看一遍时，你还不能立刻确认当前字符以后不会再次出现？

Solution dossier

两遍扫描：先知道次数，再确定最早

固定 26 格计数表，把“是否唯一”和“是否最早”拆成两个明确问题。

核心洞察

唯一性

先统计全局频次

字符是否唯一取决于完整字符串。先遍历一次，让每个字符的计数成为可靠证据。

最早性

再按原顺序寻找

第二次从左向右扫描，第一个计数等于 1 的位置天然就是所求最小索引。

完整过程

  1. 建立计数表。 由于输入只含小写英文字母，用长度为 26 的整数数组即可；字母 c 映射到 c - 'a'。
  2. 第一遍扫描。 每读到一个字符，就把对应格子的计数加一。
  3. 第二遍扫描。 按索引从 0 开始检查；一旦对应计数为 1，立即返回当前索引。
  4. 处理不存在。 如果扫描结束仍未返回，说明所有字符都重复，返回 -1。

正确性说明

命题：算法返回第一个不重复字符的索引；若不存在则返回 -1。

证明：第一遍扫描后，计数表精确记录了每个字符在整个字符串中的出现次数。因此，第二遍扫描中“计数为 1”等价于“该字符不重复”。第二遍按索引严格递增检查，首次命中的位置小于所有后续命中位置，所以它正是第一个不重复字符的索引。若没有命中，则没有字符的出现次数为 1，返回 -1 正确。

复杂度与边界

时间复杂度

O(n)：至多完整遍历字符串两次。

空间复杂度

O(1)：26 个计数格与输入长度无关。

单字符

"z" 的计数为 1，返回 0。

全部重复

第二遍没有命中，返回 -1。

class Solution {
    public int firstUniqChar(String s) {
        int[] frequency = new int[26];

        for (int i = 0; i < s.length(); i++) {
            frequency[s.charAt(i) - 'a']++;
        }

        for (int i = 0; i < s.length(); i++) {
            if (frequency[s.charAt(i) - 'a'] == 1) {
                return i;
            }
        }
        return -1;
    }
}

var firstUniqChar = function(s) {
    const frequency = new Array(26).fill(0);

    for (const char of s) {
        frequency[char.charCodeAt(0) - 97]++;
    }

    for (let i = 0; i < s.length; i++) {
        if (frequency[s.charCodeAt(i) - 97] === 1) {
            return i;
        }
    }
    return -1;
};
class Solution:
    def firstUniqChar(self, s: str) -> int:
        frequency = [0] * 26

        for char in s:
            frequency[ord(char) - ord('a')] += 1

        for index, char in enumerate(s):
            if frequency[ord(char) - ord('a')] == 1:
                return index

        return -1

public:

        array<int, 26> frequency{};

            ++frequency[c - 'a'];
        }

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            if (frequency[s[i] - 'a'] == 1) {
                return i;
            }
        }
        return -1;

替代方案

哈希表

当字符集不固定时，用 Map 存频次更通用，时间仍为 O(n)，额外空间为 O(k)。

队列 + 状态表

流式接收字符时，可以维护候选索引队列并淘汰已重复字符；逻辑更复杂，但适合数据流追问。

首尾索引比较

对每个字符比较首次和末次位置，写法短但可能反复扫描，最坏达到 O(n²)，不适合 10⁵ 规模。

存首次位置

计数时同时记首次索引，最后在所有唯一字符中取最小值；仍为 O(n)，但比第二遍扫描多维护一组状态。

面试追问

如果输入包含 Unicode 字符怎么办？

不能再用 26 长度数组。应按语言的 Unicode 字符或码点迭代并用哈希表计数；还要先确认返回的是字节索引、码点索引还是用户感知字符索引。

如果字符串以数据流形式到达怎么办？

维护频次表和候选队列。新字符首次出现时把它的索引入队；字符重复后，在查询时从队首持续移除已不唯一的候选。

能否只遍历一次字符串？

可以在一遍中同时记录频次和首次索引，结束后检查固定字符集并取最小首次索引。不过必须等数据读完，才能确认唯一性。

常见错误

  • 返回字符而不是索引：题目要求的是位置；不存在时必须返回 -1。
  • 第一遍看到新字符就返回：它可能在后面再次出现，当时还不能证明唯一。
  • 遍历计数表找第一个 1：字母序最小不等于原字符串中位置最早，必须按原串顺序确认。
  • 忽略字符集前提：长度 26 的数组依赖“小写英文字母”约束；约束变化时要换数据结构。
