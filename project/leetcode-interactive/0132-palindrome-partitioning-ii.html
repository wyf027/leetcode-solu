给定一个只含小写字母的字符串，把它切成若干回文子串；返回完成这种分割所需的最少切割次数。

题意转述

约束：1 ≤ s.length ≤ 2000，且 s 仅含小写英文字母。

CORE INSIGHT

把切割变成前缀最短路

若 s[j + 1…i] 是回文，那么在位置 j + 1 到 i + 1 之间存在一条直达边。令 cuts[i] 为前缀 s[0…i] 的最少切割：整段为回文时是 0，否则枚举最后一段的起点，用 cuts[j] + 1 更新。

FULL PROCESS

  1. 1. 从短区间到长区间预处理 pal[i][j]。
  2. 2. 从左到右枚举终点 i，初值 cuts[i] = i。
  3. 3. 若 pal[0][i]，直接令 cuts[i] = 0。
  4. 4. 否则枚举 j < i；若 pal[j + 1][i]，尝试 cuts[j] + 1。

BOUNDARY & COMPLEXITY

  • 单字符或整串回文：答案为 0。
  • 所有字符互异：每个字符单独一段，答案为 n - 1。
  • 相同字符很多：回文表中会出现大量可用区间，但状态仍只有平方级。
  • 时间：O(n²)；空间：O(n²)。

TRADE-OFF

替代方案取舍

每次临时检查回文会把复杂度拖到 O(n³)。中心扩展可以只在发现回文时更新切割，空间可降到 O(n)，但更新顺序与证明更绕；面试中优先给出回文表 + 一维 DP，清楚、稳健、易于核对。

FOLLOW-UP

面试追问

  • 如何恢复一种最优分割？ 记录每个终点的最佳前驱，再逆序回溯。
  • 为何长度差不超过 2 要单独处理？ 单字符与双字符没有内部区间。
  • 能否少用内存？ 可按中心扩展回文并更新前缀代价，换取更复杂的状态顺序。

COMMON MISTAKES

常见错误

  • 把“片段数量”直接当答案，忘记切割数要少 1。
  • 回文表遍历顺序错误，在 pal[i + 1][j - 1] 尚未计算时读取。
  • 漏掉整段 s[0…i] 为回文时的 0 切割。
  • 把 cuts[i] 初始成无穷，却没有处理所有候选为空的调试场景。 
class Solution {
    public int minCut(String s) {
        int n = s.length();
        boolean[][] pal = new boolean[n][n];
        for (int i = n - 1; i >= 0; --i) {
            for (int j = i; j < n; ++j) {
                pal[i][j] = s.charAt(i) == s.charAt(j)
                    && (j - i <= 2 || pal[i + 1][j - 1]);
            }
        }
        int[] cuts = new int[n];
        for (int i = 0; i < n; ++i) {
            cuts[i] = i;
            if (pal[0][i]) {
                cuts[i] = 0;
                continue;
            }
            for (int j = 0; j < i; ++j) {
                if (pal[j + 1][i]) {
                    cuts[i] = Math.min(cuts[i], cuts[j] + 1);
                }
            }
        }
        return cuts[n - 1];
    }
}

  const n = s.length;
  const pal = Array.from({ length: n }, () => Array(n).fill(false));
  for (let i = n - 1; i >= 0; i -= 1) {
    for (let j = i; j < n; j += 1) {
      pal[i][j] = s[i] === s[j] && (j - i <= 2 || pal[i + 1][j - 1]);
    }
  }
  const cuts = Array(n).fill(0);

      if (pal[j + 1][i]) cuts[i] = Math.min(cuts[i], cuts[j] + 1);
