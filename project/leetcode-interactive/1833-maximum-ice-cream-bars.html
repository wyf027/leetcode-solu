雪糕的最大数量

Maximum Ice Cream Bars

有限预算，无限清凉？先理解购买规则，再探索怎样买到最多的雪糕。

题目

商店有 n 支雪糕，整数数组 costs 的第 i 项是第 i 支的价格。你有 coins 枚硬币，可以任意选择购买顺序，每支雪糕至多购买一次。总花费不能超过预算，请返回能购买的最大支数，而不是最大花费。

官方额外要求：必须使用计数排序解决本题。

maxIceCream(costs: integer[], coins: integer) → integer

约束

  • costs.length == n
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ costs[i] ≤ 10⁵
  • 1 ≤ coins ≤ 10⁸

官方示例

示例 1
输入：costs = [1,3,2,4,1], coins = 7
输出：4

可选择下标 0、1、2、4，总价 1 + 3 + 2 + 1 = 7。

示例 2
输入：costs = [10,6,8,7,7,8], coins = 5
输出：0

预算低于每一支的价格，无法购买。

示例 3
输入：costs = [1,6,3,1,2,5], coins = 20
输出：6

全部买下需要 18 枚硬币，预算足够。

题解 · 按价格清空货架

核心洞察

每支雪糕的收益都是“数量 +1”。在数量相同的选择中，选更便宜的雪糕只会节省预算，因此可以先买低价雪糕。价格上限只有 10⁵，用 freq[p] 记录价格为 p 的支数，就能按价格顺序直接批量购买，不必重建排序后的数组。

完整过程

  1. 扫描 costs，找到最大价格 U，并统计每个价格出现的次数。
  2. 从 p = 1 到 U 遍历价格，空桶跳过。
  3. 本桶可买数量 take = min(freq[p], floor(coins / p))。
  4. 累计 answer += take，并扣除 coins -= take × p。
  5. 如果 take < freq[p]，说明连当前价格都无法再买一支，更贵的也买不起，立刻结束。

正确性 · 交换论证

将所有雪糕按价格非递减排列为 a₁,…,aₙ。任意 k 支雪糕的总价都不小于前 k 支的价格和：若某个选择遗漏了更便宜的雪糕却选择更贵的，将二者交换不会增加花费，重复交换即可得到前 k 支。

因此，存在可行的 k 支购买方案，当且仅当前 k 个最小价格之和不超过预算。算法按递增价格把预算能覆盖的支数尽量买完，等价于取最长可负担的前缀。当某个桶无法买完时，剩余预算小于当前价格，下一支以及更贵雪糕都不可负担，所得数量最大。计数桶批量处理相同价格不会改变这个前缀。

边界与复杂度

  • 一支也买不起时 take 为 0；刚好用完预算仍应计入最后一次购买。
  • 重复价格必须保留频次；买完所有库存后允许硬币有剩余。
  • 令 U = max(costs)，时间 O(n + U)，额外空间 O(U)。计数表分配 U + 1 项，覆盖最大价格。
  • 不必计算所有雪糕总价，那个和可能达到 10¹⁰。每步 take × p ≤ 当前 coins ≤ 10⁸，因此这里的乘法及答案在 Java/C++ 的 int 范围内；JavaScript Number 也能精确表示。

替代方案

普通排序后逐支购买，时间 O(n log n)，额外空间取决于排序实现；它能得到相同答案，但不满足本题必须使用计数排序的要求。当价格范围极大而 n 很小时，普通排序可作为变体选择。通用背包 DP 在这里忽略了所有商品收益均为 1 的性质，且 coins 可达 10⁸，开销不合适。

常见错误

  • 按输入顺序购买，可能先花钱买贵的而减少支数。
  • take 只用 coins / p，没有向下取整或没有限制到库存。
  • 使用去重集合丢失同价雪糕；或将 answer 累加为花费。
  • 将计数数组开成 U 项，导致最大价格越界。
  • 仅因为桶被买空就退出：应该在 take < freq[p] 时退出。

面试追问

价格范围增大怎么办？普通排序可避免巨大计数表，但题目要求需要相应调整。很多预算查询怎么办？预先建立有序价格的前缀和，每个预算二分可买数量；前缀和需使用 64 位整数。各雪糕收益不同呢？交换论证失效，可能变为背包问题，不能继续照搬低价优先。

Java

class Solution {
    public int maxIceCream(int[] costs, int coins) {
        int max = 0;
        for (int c : costs) max = Math.max(max, c);
        int[] freq = new int[max + 1];
        for (int c : costs) freq[c]++;
        int answer = 0;
        for (int p = 1; p <= max; p++) {
            if (freq[p] == 0) continue;
            int take = Math.min(freq[p], coins / p);
            answer += take;
            coins -= take * p;
            if (take < freq[p]) break;
        }
        return answer;
    }
}

var maxIceCream = function(costs, coins) {
    let max = 0;
    for (const c of costs) max = Math.max(max, c);

    return answer;

Python 3

from typing import List

class Solution:
    def maxIceCream(self, costs: List[int], coins: int) -> int:
        upper = max(costs)
        freq = [0] * (upper + 1)
        for c in costs:
            freq[c] += 1
        answer = 0
        for price in range(1, upper + 1):
            if freq[price] == 0:
                continue
            take = min(freq[price], coins // price)
            answer += take
            coins -= take * price
            if take < freq[price]:
                break
        return answer
