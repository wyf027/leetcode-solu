回旋镖的数量

Number of Boomerangs

同一个中心，若有多条半径落在同一距离上，它们能组成多少个有方向的点对？先观察，再决定如何计数。

Problem

题目描述

给定平面上 n 个互不相同的点 points，其中 points[i] = [xi, yi]。若有序三元组 (i, j, k) 满足点 i 到点 j 的欧式距离等于点 i 到点 k 的欧式距离，则它是一个回旋镖。

顺序很重要：(i, j, k) 与 (i, k, j) 是两个不同的回旋镖。返回所有回旋镖的数量。

Solution

按中心点统计等距有序点对

核心洞察

回旋镖的第一个点 i 是中心。固定 i 后，只要知道其余点到 i 的距离分组即可。若某个距离桶中有 m 个点，第二个位置有 m 种选法，第三个位置有 m - 1 种选法，因此贡献为 m × (m - 1)。

比较距离时无需开平方：平方距离 (x₁-x₂)² + (y₁-y₂)² 相等，当且仅当欧式距离相等。

完整过程

  1. 依次把每个点选作中心 i。
  2. 创建空哈希表，键为平方距离，值为该距离出现次数。
  3. 扫描所有 j ≠ i，计算平方距离并累加频次。
  4. 遍历频次 m，把 m(m-1) 加入答案。
  5. 清空哈希表，继续下一个中心。

正确性证明

完备性：任意合法回旋镖 (i,j,k) 中，j 与 k 到中心 i 的平方距离相同。因此处理中心 i 时，两点必定进入同一距离桶；该桶枚举有序的不同点对时一定会计入 (j,k)。

可靠性：每个被统计的有序点对 (j,k) 来自中心 i 的同一距离桶，且 j ≠ k，所以 dist(i,j)=dist(i,k)，它一定构成合法回旋镖。

不重不漏：每个三元组有唯一的第一个点 i，并对应桶内唯一的有序点对 (j,k)，故恰好统计一次。

时间复杂度

O(n²)

每个中心扫描其余所有点；桶汇总总计不超过 n 项。

空间复杂度

O(n)

单个中心最多产生 n−1 个不同平方距离。

数值范围

安全整数

坐标差最大 2×10⁴，平方距离最大 8×10⁸，32 位有符号整数可容纳。

边界情况

  • 只有一个点：不存在第二、第三个点，答案为 0。
  • 所有距离都不同：每个桶频次均为 1，贡献均为 0。
  • 多个点围绕同一中心等距：大桶会一次贡献多个有序组合。
  • 负坐标与重复距离：平方距离自然处理符号，哈希键只记录数值。
  • 题目保证点互不相同，因此不会出现由不同下标造成的零距离桶。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int numberOfBoomerangs(int[][] points) {
        int answer = 0;

        for (int[] center : points) {
            Map<Integer, Integer> frequency = new HashMap<>();

            for (int[] point : points) {
                if (point == center) {
                    continue;
                }
                int dx = center[0] - point[0];
                int dy = center[1] - point[1];
                int distanceSquared = dx * dx + dy * dy;
                frequency.merge(distanceSquared, 1, Integer::sum);
            }

            for (int count : frequency.values()) {
                answer += count * (count - 1);
            }
        }

        return answer;
    }
}

var numberOfBoomerangs = function(points) {
    let answer = 0;

    for (const [cx, cy] of points) {
        const frequency = new Map();

        for (const [x, y] of points) {
            const dx = cx - x;
            const dy = cy - y;
            const distanceSquared = dx * dx + dy * dy;
            frequency.set(
                distanceSquared,
                (frequency.get(distanceSquared) ?? 0) + 1
            );
        }

        for (const count of frequency.values()) {
            answer += count * (count - 1);
        }
    }

    return answer;
};

class Solution {
public:
    int numberOfBoomerangs(vector<vector<int>>& points) {
        int answer = 0;

        for (const auto& center : points) {
            unordered_map<int, int> frequency;

            for (const auto& point : points) {
                int dx = center[0] - point[0];
                int dy = center[1] - point[1];
                int distanceSquared = dx * dx + dy * dy;
                ++frequency[distanceSquared];
            }

            for (const auto& entry : frequency) {
                int count = entry.second;
                answer += count * (count - 1);
            }
        }

        return answer;
    }

替代方案

边扫描边累加：若当前距离此前出现 c 次，新点加入时会与已有点形成 2c 个新有序对，可立即把 2c 加入答案。它与最后计算 m(m-1) 等价，复杂度相同。

排序距离：为每个中心生成距离数组并排序，再统计连续相等段。空间仍为 O(n)，时间变为 O(n² log n)，通常不如哈希表。

常见错误

  • 写成组合数 m(m-1)/2，忽略顺序会少算一半。
  • 把不同中心的距离频次放在同一张哈希表中。
  • 使用浮点开平方，带来精度风险和额外开销。
  • 误以为中心也要排除；即使计入自身的零距离，在点互异时频次为 1、贡献仍为 0，但显式跳过更清晰。
  • 代码容器不设横向滚动，导致移动端整页溢出。

面试追问

为什么不是组合数？

因为三元组有序；交换 j、k 会产生不同答案。

能否在线统计？

可以。新点进入已有频次为 c 的桶时直接新增 2c。

为什么平方距离足够？

平方根在非负数上严格单调，平方距离相等与实际距离相等完全等价。

坐标更大怎么办？

若差值平方可能越过 32 位范围，应在乘法前提升为 64 位整数。
