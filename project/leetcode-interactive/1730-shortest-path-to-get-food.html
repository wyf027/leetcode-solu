获取食物的最短路径

Shortest Path to Get Food

在由墙、通路、起点和食物组成的网格中，每次向上下左右移动一格。你的任务是判断能否到达任意食物，并返回所需的最少步数。

Problem

题意

给定一个 m × n 的字符网格 grid。你从唯一的起点 '*' 出发，每一步可以移动到上下左右相邻的格子。

墙 'X' 不能进入；空地 'O' 可以经过；食物用 '#' 表示，可能不止一份。返回抵达任意食物所需的最少步数；如果全部食物都无法到达，返回 -1。

函数签名：
getFood(grid: character[][]): integer

字符图例

  • *：唯一的出发位置
  • #：食物，至少有一个
  • O：可以行走的空地
  • X：不可穿越的墙

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 200
  • 每格只可能是 '*'、'X'、'O' 或 '#'
  • 网格恰有一个起点，且至少有一个食物格

Solution

核心洞察

把每个可行走格子看作图上的节点，相邻格之间的移动代价都为 1。广度优先搜索按距离从小到大访问节点，因此第一次取到食物时，其距离必然是全局最短距离。

完整过程

  1. 扫描网格，找到唯一的 '*'。
  2. 将起点及距离 0 入队，并立刻标记为已访问。
  3. 反复取出队首；若它是 '#'，返回当前距离。
  4. 将未访问、未越界、不是墙的四邻格以距离加一入队。
  5. 队列清空仍未遇到食物，返回 -1。

正确性证明

引理：BFS 出队节点的距离单调不减。起点距离为 0；距离为 d 的节点只会把距离为 d+1 的节点放到所有已有节点之后。

结论：首次出队的食物距离为 d。若存在更短路径，其终点应在距离小于 d 的层中更早出队，矛盾。因此返回值是到任意食物的最短步数。

边界情况

  • 食物紧邻起点：返回 1。
  • 墙完全封闭起点或所有食物：返回 -1。
  • 多个食物：首次遇到的就是最近食物。
  • 单行、单列与最大 200 × 200 网格。

复杂度与替代方案

每格至多入队一次，时间复杂度 O(mn)；队列和访问标记占用 O(mn) 空间。

DFS 能判断可达性，但若要最短路需遍历并比较大量路径；Dijkstra 适合非等权边，本题所有边权相同，BFS 更直接。也可以从所有食物做多源 BFS，但单次查询没有必要。

常见错误

  • 入队时不标记，导致同一格重复入队。
  • 把 '#' 当障碍，永远无法命中答案。
  • 按 DFS 第一次遇到食物就返回，结果未必最短。
  • 逐层计数时层大小更新时机错误。
  • 行列下标或边界条件写反。

面试追问

  • 如果移动代价不同？改用 Dijkstra。
  • 如果允许八方向移动？扩充方向数组即可。
  • 如果网格持续变化且频繁查询？考虑维护反向距离场。
  • 如何还原路径？为每个首次访问节点记录父节点。
  • 能否原地标记？可以把已访问空地改成墙，降低额外常数。

JavaBFS
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int getFood(char[][] grid) {
        int m = grid.length, n = grid[0].length;
        Queue<int[]> queue = new ArrayDeque<>();
        boolean[][] seen = new boolean[m][n];
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == '*') {
                    queue.offer(new int[]{r, c, 0});
                    seen[r][c] = true;
                }
            }
        }
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            if (grid[cur[0]][cur[1]] == '#') return cur[2];
            for (int[] d : dirs) {
                int nr = cur[0] + d[0], nc = cur[1] + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n
                        || seen[nr][nc] || grid[nr][nc] == 'X') continue;
                seen[nr][nc] = true;
                queue.offer(new int[]{nr, nc, cur[2] + 1});
            }
        }
        return -1;
    }
}

/**
 * @param {character[][]} grid
 * @return {number}
 */
var getFood = function(grid) {
  const m = grid.length, n = grid[0].length;
  const queue = [];
  const seen = Array.from({ length: m }, () => Array(n).fill(false));
  for (let r = 0; r < m; r++) {
    for (let c = 0; c < n; c++) {
      if (grid[r][c] === '*') {
        queue.push([r, c, 0]);
        seen[r][c] = true;
      }
    }
  }
  const dirs = [[1,0],[-1,0],[0,1],[0,-1]];
  let head = 0;
  while (head < queue.length) {
    const [r, c, dist] = queue[head++];
    if (grid[r][c] === '#') return dist;
    for (const [dr, dc] of dirs) {
      const nr = r + dr, nc = c + dc;
      if (nr < 0 || nr >= m || nc < 0 || nc >= n ||
          seen[nr][nc] || grid[nr][nc] === 'X') continue;
      seen[nr][nc] = true;
      queue.push([nr, nc, dist + 1]);
    }
  }
  return -1;
};
PythonBFS
from collections import deque
from typing import List

class Solution:
    def getFood(self, grid: List[List[str]]) -> int:
        m, n = len(grid), len(grid[0])
        queue = deque()
        seen = [[False] * n for _ in range(m)]
        for r in range(m):
            for c in range(n):
                if grid[r][c] == '*':
                    queue.append((r, c, 0))
                    seen[r][c] = True

        for_pop = ((1, 0), (-1, 0), (0, 1), (0, -1))
        while queue:
            r, c, dist = queue.popleft()
            if grid[r][c] == '#':
                return dist
            for dr, dc in for_pop:
                nr, nc = r + dr, c + dc
                if (0 <= nr < m and 0 <= nc < n and
                        not seen[nr][nc] and grid[nr][nc] != 'X'):
                    seen[nr][nc] = True
                    queue.append((nr, nc, dist + 1))
        return -1
C++BFS
#include <array>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    int getFood(vector<vector<char>>& grid) {
        int m = grid.size(), n = grid[0].size();
        queue<array<int, 3>> q;
        vector<vector<bool>> seen(m, vector<bool>(n));
        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                if (grid[r][c] == '*') {
                    q.push({r, c, 0});
                    seen[r][c] = true;
                }
            }
        }
        int dirs[4][2] = {{1,0},{-1,0},{0,1},{0,-1}};
        while (!q.empty()) {
            auto [r, c, dist] = q.front();
            q.pop();
            if (grid[r][c] == '#') return dist;
            for (auto& d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n ||
                    seen[nr][nc] || grid[nr][nc] == 'X') continue;
                seen[nr][nc] = true;
                q.push({nr, nc, dist + 1});
            }
        }
        return -1;
    }
};
