给 N × 3 网格图
涂色的方案数

只用红、黄、绿三种颜色填满一个 n × 3 网格。任何共享水平边或垂直边的两个格子都不能同色，求不同涂色方案的数量。

函数：numOfWays(n) 返回：方案数 mod (10⁹ + 7) 1 ≤ n ≤ 5000

题目

给定行数 n，将每个格子恰好涂成红、黄、绿中的一种。若两个格子有公共边，它们的颜色必须不同。返回所有合法涂法的数量；由于结果可能很大，对 1,000,000,007 取余。

注意：斜对角格子不算相邻；只有上下、左右相邻会产生限制。

官方示例

示例 1输入：n = 1输出：12一行三个位置共有 12 种合法着色。
示例 2输入：n = 2输出：54
示例 3输入：n = 3输出：246
示例 4输入：n = 7输出：106494
示例 5输入：n = 5000输出：30228214

约束

  • n == grid.length
  • grid[i].length == 3
  • 1 <= n <= 5000

Solution

把 12 种行状态压成 2 类

核心洞察

一行三个格子相邻颜色不同，因此合法行只有两种结构。若第 1、3 格同色，记作 ABA 型；若不同，则三个格子必然各不相同，记作 ABC 型。两类各有 6 个具体方案。

ABA：6 种

首格 3 种选择，中格只能选另外 2 种，末格与首格相同：3 × 2 = 6。

ABC：6 种

依次选择三种互异颜色：3 × 2 × 1 = 6。

完整过程

设处理到当前行时，a 是以 ABA 型结尾的方案数，b 是以 ABC 型结尾的方案数。枚举下一行与上一行的相容关系：

  • 上一行是 ABA：下一行有 3 种 ABA、2 种 ABC。
  • 上一行是 ABC：下一行有 2 种 ABA、2 种 ABC。
nextA = 3 × a + 2 × b
nextB = 2 × a + 2 × b
answer = (a + b) mod 1,000,000,007

初始第一行 a = 6, b = 6。从第 2 行迭代到第 n 行，每次立刻取模。状态只依赖上一行，所以无需保存完整 DP 表。

正确性证明

  1. 状态完备。一行内相邻格不同。第 1、3 格要么相同（ABA），要么不同；后一种情况下三格两两不同（ABC）。二者互斥且覆盖全部合法行。
  2. 转移无重无漏。对每个具体上一行，逐格施加竖直不同与行内水平不同的限制，分别得到 ABA→ABA 为 3、ABA→ABC 为 2、ABC→ABA 为 2、ABC→ABC 为 2。每个新方案都有唯一上一行，因此不会重复。
  3. 归纳成立。第一行两类各 6 种。假设 a,b 准确统计前 i 行方案，按上述完整且互斥的转移求和，便准确得到前 i+1 行的两类方案数。
  4. 答案成立。最后一行必属且只属两类之一，所以 a + b 正好是全部合法涂色方案数。

边界与复杂度

  • n = 1：不进入循环，直接返回 6 + 6 = 12。
  • 每次乘加后取模，避免数值持续膨胀；JavaScript 使用的中间值远低于安全整数上限。
  • 时间复杂度 O(n)；额外空间复杂度 O(1)。

替代方案

12 状态 DP：枚举每行的 12 个合法颜色三元组，预计算任意两行是否竖直兼容，再做 O(12²n) 转移。更通用，但没有利用本题三列、三色带来的对称性。

矩阵快速幂：将两条转移写成 2 × 2 矩阵，可在 O(log n) 时间求解。对本题 n ≤ 5000 没有必要，却是当 n 极大时的自然延伸。

面试追问

  • 如果列数从 3 变成 m，如何用位掩码生成所有合法行状态并预计算兼容关系？
  • 如果 n 达到 10¹⁸，如何写出转移矩阵并进行快速幂？
  • 如果颜色数变成 k，两类状态的初值与转移系数如何变化？

常见错误

  • 误把 ABA、ABC 当成各 1 种，而忘记它们代表一组具体颜色排列。
  • 更新 a 后又用新 a 计算 b；应先算到临时变量。
  • 只在最后取模，导致固定宽度整数溢出。
  • 把斜对角也当作相邻，或漏掉同一列上下格不能同色。

Java

Java可直接提交
class Solution {
    public int numOfWays(int n) {
        final long MOD = 1_000_000_007L;
        long aba = 6;
        long abc = 6;

        for (int row = 2; row <= n; row++) {
            long nextAba = (3 * aba + 2 * abc) % MOD;
            long nextAbc = (2 * aba + 2 * abc) % MOD;
            aba = nextAba;
            abc = nextAbc;
        }

        return (int) ((aba + abc) % MOD);
    }
}
