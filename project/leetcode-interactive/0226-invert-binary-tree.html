226. 翻转二叉树

把二叉树的每个节点左右孩子交换，得到原树的镜像，并返回根节点。

二叉树递归DFS镜像变换

题意

给定二叉树根节点 root，翻转这棵二叉树并返回根节点。翻转意味着对每个非空节点交换它的 left 与 right。

官方样例 1

输入root = [4,2,7,1,3,6,9]
输出[4,7,2,9,6,3,1]

官方样例 2

输入root = [2,1,3]
输出[2,3,1]

官方样例 3

输入root = []
输出[]

约束：树中节点数范围为 [0,100]，-100 ≤ Node.val ≤ 100。

交互：访问一个节点，就交换它的两侧

按先序递归展示：先交换当前节点的孩子，再递归处理两棵子树。绿色表示该节点的交换已完成。

题解：递归交换

核心洞察

“翻转一棵树”可拆为：先交换根的左右指针，再分别翻转交换后的两棵子树。空节点是自然的递归终止条件。

完整过程

  1. 若 root == null，直接返回 null。
  2. 交换 root.left 和 root.right。
  3. 递归翻转当前的左、右子树。
  4. 返回 root。

边界与复杂度

空树：立即返回。

单节点：交换两个空指针，树不变。

不平衡树：每个节点仍恰好处理一次。

复杂度：时间 O(n)；递归栈为树高 O(h)。

替代方案

也可用队列 BFS，逐层交换每个节点的孩子，辅助空间最坏为 O(n)。递归更短，也更贴合问题定义。

常见错误：递归前后引用了错误的孩子；例如先递归左子树、再交换，会漏掉原右子树。应先交换，再递归两侧。

面试追问

如何改成迭代？用栈进行 DFS 或队列进行 BFS。如何判断两棵树互为镜像？成对比较 a.left 与 b.right、a.right 与 b.left。

四语言可提交代码

class Solution {
  public TreeNode invertTree(TreeNode root) {
    if (root == null) return null;
    TreeNode temp = root.left;
    root.left = root.right;
    root.right = temp;
    invertTree(root.left);
    invertTree(root.right);
    return root;
  }
}
var invertTree = function(root) {
  if (root === null) return null;
  [root.left, root.right] = [root.right, root.left];
  invertTree(root.left);
  invertTree(root.right);
  return root;
};
from typing import Optional

class Solution:
    def invertTree(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        if not root:
            return None
        root.left, root.right = root.right, root.left
        self.invertTree(root.left)
        self.invertTree(root.right)
        return root
class Solution {
public:
  TreeNode* invertTree(TreeNode* root) {
    if (!root) return nullptr;
    swap(root->left, root->right);
    invertTree(root->left);
    invertTree(root->right);
    return root;
  }
