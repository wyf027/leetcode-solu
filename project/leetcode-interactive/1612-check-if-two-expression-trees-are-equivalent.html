Binary Expression Tree · #1612

检查两棵二叉表达式树是否等价

树的形状可以不同，左右子树的次序也可以不同。你的任务是判断：无论变量取什么值，两棵树表示的表达式是否总能得到相同结果。

Binary TreeDepth-First SearchHash TableCounting
Problem

题目描述

二叉表达式树用二叉树表达算术式。每个节点恰有 0 个或 2 个子节点：叶节点表示变量，非叶节点表示运算符。本题只出现加法运算符 +。

给定两棵有效二叉表达式树的根节点 root1 与 root2。如果对变量的任意赋值，两棵树的计算结果始终相同，返回 true；否则返回 false。

函数签名

boolean checkEquivalence(Node root1, Node root2)

树的数组展示采用层序序列；null 表示该位置没有节点。

约束

  • 两棵树的节点数相等。
  • 节点数为奇数，范围是 [1, 4999]。
  • Node.val 为 '+' 或小写英文字母。
  • 输入保证是有效的二叉表达式树。
  • 每个节点的子节点数只能是 0 或 2。
Examples

官方示例

输入root1 = [x]
root2 = [x]
输出true

输入root1 = [+,a,+,null,null,b,c]

Core Insight

把树压平成变量频次

加法的结合律与交换律抹去了树形和次序。

一棵只含 + 的表达式树，本质上是所有叶变量之和。两棵树对任意赋值都等价，当且仅当每个变量在两棵树中出现的次数完全相同。

完整过程

  1. 建立长度为 26 的计数数组 count。
  2. DFS 遍历 root1；遇到叶变量时，对应计数加 1。
  3. DFS 遍历 root2；遇到叶变量时，对应计数减 1。
  4. 若 26 个位置全为 0，返回 true；否则返回 false。

为什么只看叶节点

内部节点全部是同一种运算符 +，只负责组合子表达式，不向最终线性表达式贡献变量。合法性由输入保证，因此 DFS 遇到非叶节点时继续访问两个孩子即可。

也可以分别生成两个频次数组再比较；用一个数组一加一减能少占一份常数空间。

Correctness

正确性证明

1
树对应一个线性和。
对任意节点，其子树值等于该子树所有叶变量之和。叶节点显然成立；内部节点为加法，若两个孩子成立，则二者相加后仍成立，因此由结构归纳可得整棵树成立。
2
计数数组刻画这个和。
变量 x 的计数就是线性和中 x 的系数。第一棵树加 1、第二棵树减 1 后，数组记录两棵树各变量系数之差。
3
零数组等价于恒等。
若所有系数差都为 0，两棵树的线性和完全相同，对任意赋值结果相等。若某个变量系数差非 0，只令该变量取 1、其余变量取 0，两棵树结果就不同。
4
结论。
算法返回 true 当且仅当计数数组全零，也就当且仅当两棵表达式树等价。
Analysis

复杂度与边界

O(n + m)时间：每个节点访问一次。
O(h₁ + h₂)递归栈；26 位数组为 O(1)。

边界情况

  • 两棵树都只有同一个叶节点。
  • 树形完全不同，但变量频次一致。
  • 变量集合相同，但某个变量重复次数不同。
  • 最多 4999 个节点且极度倾斜时，递归深度可能较大；工程环境可改成显式栈。

替代方案

  • 分别收集叶变量并排序，再比较两个序列：时间 O(L log L)。
  • 使用哈希表计数：适合变量字符集不固定的扩展版本。
  • 把表达式规范化成排序后的字符串：直观，但产生额外字符串与排序成本。
Implementations

四语言完整代码

Java · LeetCode 提交形式DFS + int[26]
// Definition for a binary tree node.
// class Node {
//     char val;
//     Node left;
//     Node right;
//     Node() { this.val = ' '; }
//     Node(char val) { this.val = val; }
//     Node(char val, Node left, Node right) {
//         this.val = val;
//         this.left = left;
//         this.right = right;
//     }
// }

class Solution {
    public boolean checkEquivalence(Node root1, Node root2) {
        int[] count = new int[26];
        collect(root1, 1, count);
        collect(root2, -1, count);

        for (int value : count) {
            if (value != 0) {
                return false;
            }
        }
        return true;
    }

    private void collect(Node node, int delta, int[] count) {
        if (node == null) {
            return;
        }
        if (node.val != '+') {
            count[node.val - 'a'] += delta;
            return;
        }
        collect(node.left, delta, count);
        collect(node.right, delta, count);
    }
}
JavaScript · LeetCode 提交形式DFS + Array(26)
/**
 * Definition for a binary tree node.
 * function Node(val, left, right) {
 *     this.val = val === undefined ? ' ' : val;
 *     this.left = left === undefined ? null : left;
 *     this.right = right === undefined ? null : right;
 * }
 */

/**
 * @param {Node} root1
 * @param {Node} root2
 * @return {boolean}
 */
var checkEquivalence = function(root1, root2) {
    const count = new Array(26).fill(0);

    const collect = (node, delta) => {
        if (node === null) {
            return;
        }
        if (node.val !== '+') {
            const index = node.val.charCodeAt(0) - 97;
            count[index] += delta;
            return;
        }
        collect(node.left, delta);
        collect(node.right, delta);
    };

    collect(root1, 1);
    collect(root2, -1);
    return count.every(value => value === 0);
};
Python 3 · LeetCode 提交形式DFS + list[26]
# Definition for a binary tree node.
# class Node:
#     def __init__(self, val=' ', left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def checkEquivalence(self, root1: 'Node', root2: 'Node') -> bool:
        count = [0] * 26

        def collect(node: 'Node', delta: int) -> None:
            if node is None:
                return
            if node.val != '+':
                count[ord(node.val) - ord('a')] += delta
                return
            collect(node.left, delta)
            collect(node.right, delta)

        collect(root1, 1)
        collect(root2, -1)
        return all(value == 0 for value in count)
C++ · LeetCode 提交形式DFS + array<int, 26>
/**
 * Definition for a binary tree node.
 * struct Node {
 *     char val;
 *     Node *left;
 *     Node *right;
 *     Node() : val(' '), left(nullptr), right(nullptr) {}
 *     Node(char x) : val(x), left(nullptr), right(nullptr) {}
 *     Node(char x, Node *left, Node *right)
 *         : val(x), left(left), right(right) {}
 * };
 */

class Solution {
public:
    bool checkEquivalence(Node* root1, Node* root2) {
        std::array<int, 26> count{};
        collect(root1, 1, count);
        collect(root2, -1, count);

        return std::all_of(
            count.begin(),
            count.end(),
            [](int value) { return value == 0; }
        );
    }

private:
    void collect(Node* node, int delta,
                 std::array<int, 26>& count) {
        if (node == nullptr) {
            return;
        }
        if (node->val != '+') {
            count[node->val - 'a'] += delta;
            return;
        }
        collect(node->left, delta, count);
        collect(node->right, delta, count);
    }
};
Interview

面试追问与常见错误

如果加入减法 -？

遍历时携带当前符号。对 + 的左右孩子都沿用符号；对 -，左孩子沿用符号，右孩子取反。最终仍比较各变量的有符号系数。注意：这建立在只有加减、没有乘法的前提下。

变量不止 26 个字母？

将固定数组换成 Map<String, Integer> 或其他哈希映射即可，算法结构不变。

常见错误

  • 逐节点比较树结构，错过结合律或交换律造成的等价。
  • 只比较变量集合，忽略重复次数。
  • 将内部的 + 也放进计数表。
  • 依赖若干随机变量赋值试算；随机测试不能证明“任意赋值”都相等。
  • 扩展到减法时错误地对整个右子树只翻转一层。
