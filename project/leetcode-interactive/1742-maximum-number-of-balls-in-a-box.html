1742. 盒子中小球的最大数量

Maximum Number of Balls in a Box

先观察每个编号如何“折叠”为数位和，再决定怎样统计。交互区不会先替你揭晓完整实现。

哈希表数学计数非付费题
Problem

题目描述

有一批编号连续的小球，编号从 lowLimit 到 highLimit，两端都包含在内。盒子编号从 1 开始且数量足够多。

对每个小球，把它放进“编号等于该小球编号各位数字之和”的盒子。例如，321 进入 3 + 2 + 1 = 6 号盒，10 进入 1 + 0 = 1 号盒。

返回装球数量最多的任一盒子中，小球的数量。

函数签名

countBalls(lowLimit, highLimit)

参数与返回

lowLimit: integer
highLimit: integer
return: integer

约束

1 ≤ lowLimit ≤ highLimit ≤ 105

Examples

官方示例

示例 1

输入：lowLimit = 1, highLimit = 10
输出：2
解释：1 与 10 都进入 1 号盒，
因此最多的小球数是 2。

示例 2

输入：lowLimit = 5, highLimit = 15
输出：2
解释：5 与 14 进入 5 号盒，
6 与 15 进入 6 号盒。

示例 3

输入：lowLimit = 19, highLimit = 28
输出：2
解释：19 与 28 的数位和均为 10，
10 号盒有 2 个小球。

Solution

核心洞察

题目并不要求找出盒子的编号，只要求最大装球数。遍历区间内的每个小球，求它的数位和，把对应盒子的计数加一，同时维护全局最大值即可。

关键映射：小球 x 唯一进入盒子 digitSum(x)。问题因此变成对映射结果做频次统计。

为什么数组足够？

最大编号不超过 100000，它的数位和最多为 1。小于 100000 的五位数数位和最多为 45。因此开一个略宽裕的固定数组（如 46 个元素）就能覆盖所有盒子编号。

Walkthrough

完整过程

建立计数容器

准备 boxes，其中 boxes[s] 表示数位和为 s 的小球数量；答案初始为 0。

遍历连续区间

对每个 x ∈ [lowLimit, highLimit]，不断取 x % 10 得到末位并累加，再用整数除法去掉末位。

更新对应盒子

数位和为 s 时执行 boxes[s]++，随后用这个新计数更新最大值。

返回最大频次

遍历结束后，最大值就是任一最拥挤盒子中的小球数量。

Correctness

正确性证明

引理：处理完任意前缀 [lowLimit, x] 后，boxes[s] 恰好等于这个前缀中数位和为 s 的小球数量。

证明：初始时尚未处理小球，所有计数均为 0，命题成立。处理新小球 x 时，算法准确算出唯一的数位和 s，且只将 boxes[s] 加一；其他盒子计数不变，所以命题继续成立。

结论：区间全部处理后，每个盒子的计数都准确。算法在每次增加计数时维护其中最大值，因此最终返回值正是装球最多的盒子中的小球数量。

Edges

边界情况

  • 单个小球：lowLimit == highLimit，答案必为 1。
  • 跨越十进制进位：如 9 到 10，数位和从 9 跳到 1，不可假设连续。
  • 出现并列：只返回最大数量，不必选择某个盒子。
  • 上界 100000：数位和为 1，固定计数数组仍安全。
Complexity

复杂度

时间O(n log H)n = highLimit-lowLimit+1，每个数处理其十进制位。
额外空间O(1)约束下盒子数组大小固定；一般化写法可记作 O(log H)。
Alternatives

替代方案与面试追问

替代方案

  • 哈希表：不推导数位和上界，直接以数位和为键，更通用但常数更大。
  • 递推数位和：可以利用相邻数关系增量更新，但遇到连续的 9 需要处理进位链，复杂且本题没有必要。
  • 数位 DP：若上界巨大且不能逐个枚举，可统计某个上界以内各数位和的出现次数；对本题约束属于过度设计。

面试追问

  • 如果 highLimit 达到 1018，如何用数位 DP 统计？
  • 如何推导十进制下最大数位和，从而精确分配数组？
  • 若改成二进制位数之和，算法和复杂度如何变化？
  • 若还要返回所有最拥挤盒子的编号，怎样扩展结果？
Pitfalls

常见错误

  • 循环写成 x < highLimit，漏掉右端点。
  • 求数位和时直接修改外层循环变量，造成跳号或死循环；应复制到临时变量。
  • 返回盒子编号而不是最大装球数量。
  • 只在遍历后检查某个盒子，遗漏并列或真正最大值。
  • 依据区间长度开数组，却没有依据数位和范围设计下标。
Implementations

JavaLeetCode
class Solution {
    public int countBalls(int lowLimit, int highLimit) {
        int[] boxes = new int[46];
        int answer = 0;

        for (int number = lowLimit; number <= highLimit; number++) {
            int sum = digitSum(number);
            boxes[sum]++;
            answer = Math.max(answer, boxes[sum]);
        }
        return answer;
    }

    private int digitSum(int number) {
        int sum = 0;
        while (number > 0) {
            sum += number % 10;
            number /= 10;
        }
        return sum;
    }
}

var countBalls = function(lowLimit, highLimit) {
    const boxes = new Array(46).fill(0);
    let answer = 0;

    for (let number = lowLimit; number <= highLimit; number++) {
        let current = number;
        let sum = 0;

        while (current > 0) {
            sum += current % 10;
            current = Math.floor(current / 10);
        }

        boxes[sum]++;
        answer = Math.max(answer, boxes[sum]);
    }
    return answer;
};
