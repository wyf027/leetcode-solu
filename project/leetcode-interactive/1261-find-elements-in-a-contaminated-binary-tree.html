01 · 题目

恢复规则与接口

下述内容依据官方中文题面转述，参数形式保留完整。

题意

原二叉树的节点值遵循固定编号规则，但污染后每个节点的值都变成 -1。你需要在初始化对象时恢复这棵树，并支持判断某个目标值是否存在。

  1. 根节点满足 root.val = 0。
  2. 值为 x 的节点若有左孩子，则左孩子值为 2x + 1。
  3. 值为 x 的节点若有右孩子，则右孩子值为 2x + 2。

类接口

FindElements(TreeNode root)
使用受污染的二叉树初始化，并先完成恢复。
boolean find(int target)
若恢复后的树中存在 target，返回 true；否则返回 false。

05 · 题解

一次恢复，常数时间查询

利用树的结构即可唯一确定每个节点原本的值。

核心洞察

污染只改变值，不改变父子结构。从根的 0 出发，父节点值一旦确定，孩子值也唯一确定。遍历恢复时把每个值放进哈希集合，之后的查询就变成集合成员判断。

为什么适合多次查询

最多有 10⁴ 次 find。把工作集中到构造阶段，只扫描每个节点一次，就能让每次查询的平均开销降到 O(1)。

状态设计

对象只需保存一个集合 values。DFS 参数携带当前恢复值；也可以直接写回 node.val，使树本身恢复为题目定义的状态。

06 · 过程

构造阶段的四步

DFS 与 BFS 都可行，这里以递归 DFS 表达。

  1. 根节点定为 0。
    从 dfs(root, 0) 开始。
  2. 记录当前值。
    将 value 写入当前节点，并加入哈希集合。
  3. 递归实际存在的孩子。
    左边传 2 × value + 1，右边传 2 × value + 2。
  4. 查询集合。
    find(target) 直接返回集合是否包含 target。
07 · 正确性

结构归纳证明

证明恢复值准确，并证明 find 的返回结果等价于目标是否存在。

命题

DFS 结束后，每个已有节点都被恢复为规则指定的唯一值，且集合 values 恰好包含树中全部恢复值。

基础情形

根节点由算法赋值为 0，与规则一致，同时 0 被加入集合。

归纳步骤

假设某节点已正确恢复为 x。若它的左孩子存在，算法赋值为 2x+1；若右孩子存在，算法赋值为 2x+2，均与规则一致。随后两个值都被加入集合。由结构归纳，所有可达节点都正确恢复且被记录。

查询结论

集合没有额外值，也不遗漏任何节点值，因此 values 包含 target 当且仅当恢复后的树存在 target；find 的结果正确。

08 · 复杂度与边界

为查询做预处理

令 n 为节点数，h 为树高。

O(n)构造时间：每个节点访问一次
O(1) 平均单次 find：哈希集合查询
O(n)额外空间：集合保存所有值
O(h)递归栈：题设 h ≤ 20

边界情况

  • 只有根节点：集合最终仅含 0。
  • 极度偏斜的树：只沿实际存在的一侧递归，不创建虚构节点。
  • 目标为 0：根一定存在，因此返回 true。
  • 目标远大于所有恢复值：集合查不到，返回 false。
  • 空孩子不递归；题设节点数至少为 1，因此构造参数代表非空树。
09 · 延伸

替代方案与面试追问

同一编号规则还隐藏着一条从 target 反推路径的方法。

替代：不使用哈希集合

对目标值不断做 target → floor((target−1)/2)，可反推出从目标到根的左右方向；逆序沿树走即可判断存在性。也可观察 target + 1 的二进制：去掉最高位 1 后，0 表示向左，1 表示向右。

空间可降到 O(h)，但每次查询需要 O(h)，且若题意严格要求“恢复二叉树”，构造时仍应写回节点值。

面试追问

  • 如果查询只有一次，是否还值得保存整个集合？
  • 怎样用迭代 BFS 避免递归？
  • 为什么不同节点不可能恢复成相同的值？
  • 如果树高没有上限，值类型可能出现什么问题？
  • 怎样根据 target+1 的二进制直接定位节点？

常见错误

  • 把左、右孩子公式写反，或漏掉常数项 1 / 2。
  • 只改 node.val，却没有把值存入支持快速查询的数据结构。
  • 递归空孩子，导致空指针异常。
  • 误以为数组层序下标中的 null 也占有一个真实节点并需要恢复。
  • 在 JavaScript 中忘记给实例创建独立的 Set。
10 · 代码

四种语言完整实现

均采用 DFS 恢复 + 哈希集合查询，符合对应官方类签名。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class FindElements {
    private final Set<Integer> values = new HashSet<>();

    public FindElements(TreeNode root) {
        recover(root, 0);
    }

    private void recover(TreeNode node, int value) {
        if (node == null) return;
        node.val = value;
        values.add(value);
        recover(node.left, value * 2 + 1);
        recover(node.right, value * 2 + 2);
    }

    public boolean find(int target) {
        return values.contains(target);
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/** @param {TreeNode} root */
var FindElements = function(root) {
    this.values = new Set();

    const recover = (node, value) => {
        if (node === null) return;
        node.val = value;
        this.values.add(value);
        recover(node.left, value * 2 + 1);
        recover(node.right, value * 2 + 2);
    };

    recover(root, 0);
};

/**
 * @param {number} target
 * @return {boolean}
 */
FindElements.prototype.find = function(target) {
    return this.values.has(target);
};

class FindElements:
    def __init__(self, root: Optional[TreeNode]):
        self.values = set()

        def recover(node: Optional[TreeNode], value: int) -> None:
            if node is None:
                return
            node.val = value
            self.values.add(value)
            recover(node.left, value * 2 + 1)
            recover(node.right, value * 2 + 2)

        recover(root, 0)

    def find(self, target: int) -> bool:
        return target in self.values
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 * };
 */
class FindElements {
private:
    unordered_set<int> values;

    void recover(TreeNode* node, int value) {
        if (node == nullptr) return;
        node->val = value;
        values.insert(value);
        recover(node->left, value * 2 + 1);
        recover(node->right, value * 2 + 2);
    }

public:
    FindElements(TreeNode* root) {
        recover(root, 0);
    }

    bool find(int target) {
        return values.count(target) > 0;
    }
};
