使数组中所有元素都等于零

Make Array Zero by Subtracting Equal Amounts

让每根数值柱落到零。一次同步削减，会发生什么？

01题目规则

给定非负整数数组 nums，每次选择一个正整数 x，它不能超过数组中当前最小的非零元素。将所有正数同时减去 x，已经是零的元素保持不变。

返回让整个数组变成零所需的最少操作次数。

参数与约束

  • 参数：nums: integer[]；返回：integer。
  • 1 ≤ nums.length ≤ 100
  • 0 ≤ nums[i] ≤ 100

05独立题解

准备好后，展开证明、代码与延伸问题。

核心洞察：数不同的正数

相同的正数每次同步减去相同的量，必然一起归零；不同的正数在都尚未归零时，差值始终不变，不能在同一次操作中一起归零。因此答案就是 nums 中不同正数的数量，无需真的修改数组。

完整过程

  1. 准备一个空集合 seen。
  2. 扫描 nums，仅将大于零的元素放入集合。
  3. 集合自动消除重复，返回集合大小。

例如 [1,5,0,3,5] 的不同正数是 {1,3,5}，答案为 3。若要展示具体操作，将这些值升序排列为 1、3、5，相邻层差分别为 1、2、2；每次取当前最小正数即可依次消除一层。实验台采用这一策略。

正确性证明

下界：设初始有 k 个不同正数。一次合法操作只能让当前值等于 x 的那一组变为零，不同正数组之间的差值保持不变，一次至多消除一组。消除所有组至少需要 k 次操作。

可达：每次令 x 等于当前最小正数，这个 x 合法，恰好使最小的正数组归零，其余正数组仍然为正且互异。每步减少一组，k 步后全部为零。上下界相等，最优答案为 k。

边界与复杂度

  • 全零数组返回 0；只有一个不同正数时返回 1，与重复次数无关。
  • 无须排序，不修改输入。零必须排除；负数不属于本题输入范围。
  • 集合解法：平均时间 O(n)，额外空间 O(k)，其中 k 是不同正数个数，k ≤ min(n,100)。哈希集合的操作按平均 O(1) 计算。
  • 利用值域 0–100，可改为长度 101 的布尔数组：时间 O(n + 100)，空间 O(100)，固定值域下视为 O(n) 时间、O(1) 额外空间。

四语言代码 · LeetCode 提交形式

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int minimumOperations(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int value : nums) {
            if (value > 0) seen.add(value);
        }
        return seen.size();
    }
}

from typing import List

class Solution:
    def minimumOperations(self, nums: List[int]) -> int:

C++

#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int minimumOperations(vector<int>& nums) {
        unordered_set<int> seen;
        for (int value : nums) {
            if (value > 0) seen.insert(value);
        }
        return static_cast<int>(seen.size());
    }
};

替代方案

  • 排序去重：排序后统计正数中与前一个数不同的项，时间 O(n log n)，排序空间依语言实现而定；直接原地排序会改变输入。
  • 直接模拟：重复寻找最小正数并削减所有正数，最多 k 轮，时间 O(nk)，最坏 O(n²)；原地模拟额外空间 O(1)，若保留输入需 O(n) 副本。
  • 布尔计数：固定小值域时可代替哈希集合，逐项标记，统计正数位置。

常见错误

  • 把 0 也计入集合大小，导致答案多 1。
  • 统计正数的出现次数，忽略重复值会同时归零。
  • 认为答案等于最大值；这相当于只做 x = 1，通常不是最优。
  • 给零也减去 x，产生负数；题目只允许对正数操作。
  • 选择大于最小正数的 x，不符合操作规则。

面试追问

  • 如何返回操作序列？将不同正数排序为 a₁…aₖ，返回 a₁、a₂−a₁、…、aₖ−aₖ₋₁，排序时间 O(k log k)。
  • 输入流能否处理？维护已见正数集合，新出现的正数使计数加 1。
  • 值域变成十亿怎么办？继续使用集合，避免按值域分配布尔数组。
  • 每次只能选择一个元素削减呢？同值元素无法同步归零；若仍限制 x 不超过全局最小正数，需要重新建模，这里的去重结论不再直接成立。
