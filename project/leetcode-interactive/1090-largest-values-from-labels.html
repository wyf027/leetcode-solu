受标签影响的最大值

Largest Values From Labels · 在“总数量上限”和“每个标签额度”之间做一次干净的贪心选择。

贪心排序哈希表计数

题目

有 n 个物品，values[i] 是第 i 个物品的价值，labels[i] 是它的标签。请选择一个子集，使价值总和最大，同时满足：

  • 最多选择 numWanted 个物品；
  • 任一相同标签最多使用 useLimit 次。

返回能够得到的最大价值和。

函数签名

largestValsFromLabels(values, labels, numWanted, useLimit) → integer

约束

  • n == values.length == labels.length
  • 1 ≤ n ≤ 2 × 10⁴
  • 0 ≤ values[i], labels[i] ≤ 2 × 10⁴
  • 1 ≤ numWanted, useLimit ≤ n
先观察交互演示，试着判断“按什么顺序看物品”最安全；完整题解默认收起。

准备开始：优先审阅价值最大的物品。

想好了吗？

关键问题：一件高价值物品若标签仍有额度，是否有理由把它留给后面更低价值的同标签物品？

完整题解

核心洞察

把物品按价值降序扫描。只要尚未选满且当前标签使用次数小于 useLimit，就选择该物品。标签计数用哈希表维护。

完整过程

  1. 将每个物品组织为 (value, label) 并按价值降序排序。
  2. 从大到小扫描；标签尚有额度时加入答案，并增加该标签计数。
  3. 选中数量达到 numWanted 后立即结束。

正确性证明

考虑排序后贪心选中的某个物品 g。任何可行最优解若在这个位置没有选 g，则要么已经选满同标签额度，此时此前同标签物品价值均不小于 g；要么可以用 g 替换其中一个不高于它的后选物品，且不破坏总数与标签约束，价值不会下降。逐步交换后可得到与贪心选择一致的最优解，因此算法最优。

边界情况

  • 所有物品同标签：最多取前 min(numWanted, useLimit) 个。
  • useLimit ≥ numWanted：标签限制实际不生效，取全局前若干大值。
  • 价值允许为 0；选择零不会降低答案，但不必超过数量上限。
  • 标签稀疏或数值很大时，哈希表比固定数组更通用。

复杂度

排序耗时 O(n log n)，扫描 O(n)；物品与计数结构占用 O(n) 空间。

替代方案

可按标签分别建立最大堆，再通过全局堆不断取最大值，但实现更复杂，整体仍常为 O(n log n)。在本题静态输入下，直接全局排序更清晰。

面试追问

  • 若物品流式到达且需要随时查询，如何用堆维护候选？
  • 若每个标签的上限不同，计数判断应如何修改？
  • 若必须恰好选择 numWanted 个且价值可为负数，答案与可行性如何处理？

常见错误

  • 按标签分组后依次取，错过跨标签的全局最大值。
  • 把 numWanted 和 useLimit 当成必须达到，而不是上限。
  • 达到某标签上限后错误地停止全部扫描，而非只跳过该标签。

四语言实现

import java.util.*;

class Solution {
    public int largestValsFromLabels(int[] values, int[] labels,
                                     int numWanted, int useLimit) {
        Integer[] order = new Integer[values.length];
        for (int i = 0; i < values.length; i++) order[i] = i;
        Arrays.sort(order, (a, b) -> Integer.compare(values[b], values[a]));
        Map<Integer, Integer> used = new HashMap<>();
        int answer = 0, picked = 0;
        for (int i : order) {
            int count = used.getOrDefault(labels[i], 0);
            if (count == useLimit) continue;
            answer += values[i];
            used.put(labels[i], count + 1);
            if (++picked == numWanted) break;
        }
        return answer;
    }
}
/**
 * @param {number[]} values
 * @param {number[]} labels
 * @param {number} numWanted
 * @param {number} useLimit
 * @return {number}
 */
var largestValsFromLabels = function(values, labels, numWanted, useLimit) {
  const items = values.map((value, i) => [value, labels[i]]);
  items.sort((a, b) => b[0] - a[0]);
  const used = new Map();
  let answer = 0, picked = 0;
  for (const [value, label] of items) {
    const count = used.get(label) || 0;
    if (count === useLimit) continue;
    answer += value;
    used.set(label, count + 1);
    if (++picked === numWanted) break;
  }
  return answer;
};

class Solution:
    def largestValsFromLabels(self, values: List[int], labels: List[int],
                              numWanted: int, useLimit: int) -> int:
        items = sorted(zip(values, labels), reverse=True)
        used = {}
        answer = picked = 0
        for value, label in items:
            if used.get(label, 0) == useLimit:
                continue
            answer += value
            used[label] = used.get(label, 0) + 1
            picked += 1
            if picked == numWanted:
                break
        return answer
#include <algorithm>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int largestValsFromLabels(vector<int>& values, vector<int>& labels,
                              int numWanted, int useLimit) {
        vector<pair<int, int>> items;
        for (int i = 0; i < values.size(); ++i)
            items.push_back({values[i], labels[i]});
        sort(items.rbegin(), items.rend());
        unordered_map<int, int> used;
        int answer = 0, picked = 0;
        for (auto [value, label] : items) {
            if (used[label] == useLimit) continue;
            answer += value;
            ++used[label];
            if (++picked == numWanted) break;
        }
        return answer;
    }
};
