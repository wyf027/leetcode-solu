点菜展示表

把散落的一张张订单，整理成餐厅后厨一眼就能读懂的餐桌 × 餐品统计表。

Display Table of Food Orders in a Restaurant
数组 · 哈希表 · 字符串 · 有序集合 · 排序

The brief

题目说明

难度：中等

给定二维字符串数组 orders，其中每项完整表示为 orders[i] = [customerNameᵢ, tableNumberᵢ, foodItemᵢ]，依次是顾客姓名、桌号和餐品名称。

返回餐厅的“点菜展示表”：首行是表头，第一列固定为 "Table"，其余列为所有出现过的餐品并按字母序排列；之后每一行对应一张餐桌，第一列是桌号，其余列是该桌订购对应餐品的数量（字符串形式）。顾客姓名不出现在结果中，餐桌行按桌号的数值升序排列。

数组哈希表字符串有序集合排序
  • ①餐品列：字母序
  • ②餐桌行：按数值升序
  • ③未点餐品：填字符串 "0"
  • ④忽略顾客姓名

Complete solution

哈希统计 + 双重排序

核心洞察

结果的行、列来自两个独立维度：桌号决定行，餐品决定列。扫描订单时，用一个集合收集所有餐品，同时用“桌号 →（餐品 → 数量）”的嵌套映射累计次数。扫描结束后分别排序桌号和餐品，再投影为二维字符串数组。

为什么忽略顾客姓名？

输出只关心每桌每种餐品的总数。同一桌的不同顾客、同一顾客的多份订单都归入同一个 (table, food) 计数，因此姓名不会影响任何单元格。

完整过程

  1. 初始化容器
    建立餐品集合 foods 和餐桌计数映射 counts。
  2. 单次扫描订单
    对每个 [name, table, food]，把 food 加入集合，并将 counts[table][food] 加一。
  3. 确定列与行的顺序
    餐品使用字符串字母序；桌号先转为数值后升序，避免字符串排序把 “10” 放在 “3” 前。
  4. 构造结果
    表头为 ["Table", ...foods]。逐个有序桌号生成行，缺失的餐品计数补 0，所有数字转成字符串。

正确性说明

计数正确：每张订单恰好被扫描一次，且只让其桌号与餐品对应的计数加一。因此扫描后，每个 counts[table][food] 正好等于该桌点该餐品的订单数。

结构正确：餐品集合包含且只包含出现过的餐品，排序后恰为要求的表头列顺序；计数映射的键包含且只包含出现过的桌号，按数值排序后恰为要求的数据行顺序。

单元格正确：构造每行时，已有计数取其准确值，没有记录则填 0。结合正确的行列顺序，所得二维数组就是唯一符合要求的展示表。

复杂度

时间O(n + f log f + t log t + tf)
空间O(tf + f + t)

其中 n 为订单数，f 为不同餐品数，t 为不同桌号数；结果本身需要 O(tf) 空间。

边界情况

  • 只有一张订单：仍需生成表头和一行计数。
  • 同桌重复点同一餐品：必须累计，不能只记录是否出现。
  • 多桌但餐品不重合：每行缺失列都要补字符串 "0"。
  • 桌号包含 2 与 10：必须数值排序，而非字典序。
  • 餐品名称含空格或大小写：按语言默认字符串字典序处理完整名称，不拆词。

JavaLeetCode 可提交
class Solution {
    public List<List<String>> displayTable(List<List<String>> orders) {
        Set<String> foodSet = new TreeSet<>();
        Map<Integer, Map<String, Integer>> counts = new TreeMap<>();

        for (List<String> order : orders) {
            int table = Integer.parseInt(order.get(1));
            String food = order.get(2);
            foodSet.add(food);
            counts.computeIfAbsent(table, key -> new HashMap<>())
                  .merge(food, 1, Integer::sum);
        }

        List<String> foods = new ArrayList<>(foodSet);
        List<List<String>> answer = new ArrayList<>();
        List<String> header = new ArrayList<>();
        header.add("Table");
        header.addAll(foods);
        answer.add(header);

        for (Map.Entry<Integer, Map<String, Integer>> entry : counts.entrySet()) {
            List<String> row = new ArrayList<>();
            row.add(String.valueOf(entry.getKey()));
            for (String food : foods) {
                row.add(String.valueOf(entry.getValue().getOrDefault(food, 0)));
            }
            answer.add(row);
        }
        return answer;
    }
}

/**
 * @param {string[][]} orders
 * @return {string[][]}
 */
var displayTable = function(orders) {
    const foodSet = new Set();
    const counts = new Map();

    for (const [, table, food] of orders) {
        foodSet.add(food);
        if (!counts.has(table)) counts.set(table, new Map());
        const tableCounts = counts.get(table);
        tableCounts.set(food, (tableCounts.get(food) || 0) + 1);
    }

    const foods = [...foodSet].sort();
    const tables = [...counts.keys()].sort((a, b) => Number(a) - Number(b));
    const answer = [["Table", ...foods]];

    for (const table of tables) {
        const tableCounts = counts.get(table);
        const row = [table];
        for (const food of foods) {
            row.push(String(tableCounts.get(food) || 0));
        }
        answer.push(row);
    }
    return answer;
};

from collections import defaultdict
from typing import List

class Solution:
    def displayTable(self, orders: List[List[str]]) -> List[List[str]]:
        foods = set()
        counts = defaultdict(lambda: defaultdict(int))

        for _, table, food in orders:
            foods.add(food)
            counts[int(table)][food] += 1

        sorted_foods = sorted(foods)
        answer = [["Table", *sorted_foods]]

        for table in sorted(counts):
            row = [str(table)]
            for food in sorted_foods:
                row.append(str(counts[table][food]))
            answer.append(row)

        return answer
C++LeetCode 可提交
class Solution {
public:
    vector<vector<string>> displayTable(vector<vector<string>>& orders) {
        set<string> foods;
        map<int, map<string, int>> counts;

        for (const auto& order : orders) {
            int table = stoi(order[1]);
            const string& food = order[2];
            foods.insert(food);
            ++counts[table][food];
        }

        vector<string> header = {"Table"};
        header.insert(header.end(), foods.begin(), foods.end());
        vector<vector<string>> answer = {header};

        for (const auto& [table, tableCounts] : counts) {
            vector<string> row = {to_string(table)};
            for (const string& food : foods) {
                auto it = tableCounts.find(food);
                int count = it == tableCounts.end() ? 0 : it->second;
                row.push_back(to_string(count));
            }
            answer.push_back(row);
        }
        return answer;
    }
};

替代方案

桌号范围只有 1～500，可用长度 501 的数组代替外层映射；若餐品先编号，也能用二维计数数组。但餐品种类与名称需先收集，且稀疏场景会浪费空间。嵌套哈希/有序映射更直接，也更容易表达。

常见错误

  • 直接按字符串排序桌号，得到 1、10、2。
  • 只统计餐品总数，没有区分桌号。
  • 表头未排序，依赖哈希容器迭代顺序。
  • 计数以数字写入结果，而题目要求二维字符串数组。
  • 漏掉某桌没点过的餐品列，没有补 0。

面试追问

如果订单以数据流持续到达，怎样实时维护展示表？

持续维护嵌套计数映射和有序餐品集合；每次查询时再按当前列集合投影。若查询频繁，可缓存结果并只更新受影响的行，但新增餐品仍会让所有行多一列。

为什么不能边扫描边直接构造最终二维数组？

在扫描完成前不知道全部餐品及最终列顺序。可以动态扩列，但维护成本更高；先聚合、后排序投影更清晰稳定。

若桌号范围扩大到任意长数字字符串怎么办？

需要大整数比较：先去除前导零，再按长度和字典序比较，或使用语言的大整数类型；不能依赖可能溢出的普通整数转换。
