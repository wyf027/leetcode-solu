志愿者调配

最终只有 0 号场馆人数未知。令它为 x，每个场馆人数都写成 a·x+b。倒序撤销每天的调配后，再用初始总人数解出 x。

题意

n 个场馆由无向通道相连。每天执行：① idx 人数减半；② idx 的每个邻居加上 idx 人数；③ idx 的每个邻居减去 idx 人数。已知初始总人数 totalNum 与最终 1..n-1 号人数 finalCnt，还原所有场馆的初始人数。

finalCnt=[1,16], totalNum=21
edges=[[0,1],[1,2]]
plans=[[2,1],[1,0],[3,0]]
输出=[5,7,9]

INTERACTIVE / 逆向撤销

每一步只改仿射系数

逆操作
  • 原操作 1：逆向将 idx 的 (a,b) 同时乘 2
  • 原操作 2：邻居减去 idx
  • 原操作 3：邻居加上 idx

测试与验证

样例 1

期望：[5,7,9]
实际：[5,7,9]
通过

复杂度

时间 O(n+|edges|+Σdeg(idx))，plans≤10；空间 O(n+|edges|)。

状态

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

SOLUTION / 默认隐藏

仿射表达式逆推

完整过程

  1. 最终 0 号设为 (1,0)，其余设为 (0,finalCnt[i-1])。
  2. 从最后一天倒序撤销 plans。
  3. 初始总和为 sumA·x+sumB=totalNum，求 x。
  4. 把 x 代回每个 (a,b)。

边界与错误

使用 64 位整数承载 totalNum 与中间量。操作 2/3 只更新 idx 的邻居，idx 自身不变。必须倒序，并将加法与减法互换。 

import java.util.*;
class Solution {
 public int[] volunteerDeployment(int[] finalCnt, long totalNum, int[][] edges, int[][] plans) {
  int n=finalCnt.length+1; List<Integer>[] g=new ArrayList[n]; for(int i=0;i<n;i++)g[i]=new ArrayList<>();
  for(int[] e:edges){g[e[0]].add(e[1]);g[e[1]].add(e[0]);}
  long[] a=new long[n],b=new long[n];a[0]=1;for(int i=1;i<n;i++)b[i]=finalCnt[i-1];
  for(int k=plans.length-1;k>=0;k--){int op=plans[k][0],x=plans[k][1];if(op==1){a[x]*=2;b[x]*=2;}else for(int y:g[x]){if(op==2){a[y]-=a[x];b[y]-=b[x];}else{a[y]+=a[x];b[y]+=b[x];}}}
  long sa=0,sb=0;for(int i=0;i<n;i++){sa+=a[i];sb+=b[i];}long unknown=(totalNum-sb)/sa;int[] ans=new int[n];for(int i=0;i<n;i++)ans[i]=(int)(a[i]*unknown+b[i]);return ans;
 }
}

class Solution:
 def volunteerDeployment(self, finalCnt, totalNum, edges, plans):
  n=len(finalCnt)+1; g=[[] for _ in range(n)]
  for u,v in edges:g[u].append(v);g[v].append(u)
  a=[0]*n;b=[0]+finalCnt[:];a[0]=1
  for op,x in reversed(plans):
   if op==1:a[x]*=2;b[x]*=2
   else:
    for y in g[x]:
     if op==2:a[y]-=a[x];b[y]-=b[x]
     else:a[y]+=a[x];b[y]+=b[x]
  unknown=(totalNum-sum(b))//sum(a)
  return [a[i]*unknown+b[i] for i in range(n)]
