镜面反射 / Mirror Reflection

让一束光在镜面房间里前进，观察它如何把几何反射问题变成整数奇偶性问题。

MEDIUMGeometryMathGCD / LCM

题目

一个边长为 p 的正方形房间，四面墙都是镜子。激光从西南角射出，第一次到达东墙时，落点距离东南角的接收器 0 为 q。除西南角外，其余三个角分别放置接收器：东南角为 0、东北角为 1、西北角为 2。

给定整数 p 和 q，返回激光最先遇到的接收器编号。题目保证激光最终会到达某个接收器。

函数签名： mirrorReflection(p: integer, q: integer) -> integer

约束

  • 1 <= q <= p <= 1000

示例 1

输入：p = 2, q = 1
输出：2
解释：光线第一次反射回左墙时到达接收器 2。

示例 2

输入：p = 3, q = 1
输出：1

先想一想

如果不反射墙呢？

可以把每次碰墙想象成房间向外复制：光线始终沿一条直线前进，而接收器会出现在某些网格交点上。

什么时候停？

当水平距离和竖直高度同时落在边长 p 的整数倍上，直线就到达了某个房间副本的角。

完整题解

Solution

把反射展开，再只看奇偶

核心洞察

将镜面反射等价为连续复制房间，光线就成为斜率为 q / p 的直线。设光线水平方向跨过 m 个房间、竖直方向跨过 n 个房间后首次到达角落，则：

m · p = n · q = lcm(p, q)

约去 g = gcd(p, q) 后，m = q / g、n = p / g。真正决定接收器的只有 m 与 n 的奇偶性。

完整过程

  1. 计算 gcd(p, q)，将二者同时除以最大公约数，得到互质的 P 与 Q。
  2. P 表示竖直方向跨过的房间数，Q 表示水平方向跨过的房间数。
  3. 若 P 为偶数，终点在下侧，只可能是接收器 2。
  4. 否则若 Q 为偶数，终点在左上角，对应接收器 0。
  5. 否则二者均为奇数，终点在右上角，对应接收器 1。
等价判定：若化简后的 p 为偶数返回 2；否则若化简后的 q 为偶数返回 0；否则返回 1。

正确性证明

展开房间不会改变光线相对于镜面的入射角与反射角，因此展开图中的直线与原房间中的折线路径一一对应。第一次同时满足水平坐标和竖直坐标均为 p 的倍数的位置是 lcm(p,q) 对应的网格角；所以约简后的跨房间次数分别为 Q 和 P。跨过奇数个房间会落在该方向的对侧，跨过偶数个房间会回到原侧，故两者奇偶性唯一确定三种可达角。由于 P、Q 互质，不可能同时为偶数，三条分支完整且互斥，算法返回的接收器必然正确。

边界与复杂度

  • q = p：光线直接到达东北角，返回 1。
  • 化简后 p = 1：仍按 q 的奇偶判断。
  • 欧几里得算法时间复杂度 O(log min(p,q))，空间复杂度 O(1)。

替代方案

可以不断除去 p 与 q 共同的因子 2，再根据剩余奇偶性判断；也可以显式计算最小公倍数与两个跨房间次数。前者更短，但 GCD 版本直接对应“首次公共网格角”，更容易证明。

面试追问

  • 为什么展开房间后光路必然是一条直线？
  • 为什么只看奇偶性，不需要模拟每次反射？
  • 若房间变成长方形，横纵边长不同，公式如何变化？
  • 若接收器位于墙边而不是角落，如何判断首次命中？

常见错误

  • 把化简后的 p、q 所代表的竖直/水平次数写反。
  • 直接计算大数最小公倍数时先做乘法，造成不必要的溢出风险。
  • 逐段浮点模拟反射，累积误差导致无法精确判断是否到角。
  • 误读接收器编号：0 在东南、1 在东北、2 在西北。
Java
class Solution {
    public int mirrorReflection(int p, int q) {
        int g = gcd(p, q);
        p /= g;
        q /= g;

        if (p % 2 == 0) return 2;
        if (q % 2 == 0) return 0;
        return 1;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int next = a % b;
            a = b;
            b = next;
        }
        return a;
    }
}
JavaScript
/**
 * @param {number} p
 * @param {number} q
 * @return {number}
 */
var mirrorReflection = function(p, q) {
    const gcd = (a, b) => {
        while (b !== 0) {
            [a, b] = [b, a % b];
        }
        return a;
    };

    const g = gcd(p, q);
    p /= g;
    q /= g;

    if (p % 2 === 0) return 2;
    if (q % 2 === 0) return 0;
    return 1;
};
