最长重复子串 Longest Duplicate Substring

先理解问题，再操作一台“长度探测器”：二分负责选择候选长度，滚动哈希负责在一次线性扫描中寻找重复窗口。

困难字符串二分查找滚动哈希可重叠
题目

寻找最长的重复片段

给定字符串 s，找出在其中至少出现两次的最长连续子串。两次出现可以重叠；若有多个最长答案，返回任意一个即可。不存在重复子串时返回空字符串。

约束

  • 2 ≤ s.length ≤ 3 × 10⁴
  • s 仅由小写英文字母组成。

longestDupSubstring(s: string) → string

关键提醒

“出现”允许重叠

例如 aaaa 中，长度为 3 的 aaa 分别从下标 0 和 1 开始，它们共享字符，却仍是两次合法出现。

答案只要求返回任意一个最长重复子串，因此无需对同长度答案做字典序排序。

官方示例（完整参数形式）

输入与输出

输入：s = "banana"
输出："ana"
解释："ana" 从下标 1 和 3 开始。
输入：s = "abcd"
输出：""
解释：没有非空子串出现两次。

核心洞察

把“最长”变成“某长度是否可行”

若存在长度为 L 的重复子串，则截短它便得到所有更小长度的重复子串。因此可行长度构成连续前缀，可二分最大值。

完整过程

  1. 在 [1, n-1] 二分候选长度 L。
  2. 用 Rabin–Karp 滚动哈希计算每个长度为 L 的窗口。
  3. 同一哈希值出现时，再比较原字符串片段，排除哈希碰撞。
  4. 若找到相同窗口，记录起点并向更长区间搜索；否则缩短。

正确性

判定正确：扫描覆盖全部长度为 L 的窗口。返回前进行了逐字符比较，所以返回的两个窗口确实相等；若未返回，则不存在两段相同窗口。

二分正确：可行性关于长度单调。二分始终保留最大可行长度所在区间，结束时记录的起点对应全局最大可行长度。

边界

  • 全部字符不同：最终返回空串。
  • 全部字符相同：重叠窗口有效，答案长度为 n-1。
  • 多个答案并列：返回最先确认的任意一个。

复杂度

期望时间 O(n log n)；哈希碰撞后的片段核验在对抗性输入下可能使最坏时间上升。空间 O(n)。

替代方案

后缀数组 + LCP 可做到 O(n log n)（优秀实现可更快）且无哈希碰撞；后缀自动机也能线性建模，但实现与“出现位置”统计更复杂。

面试追问

  • 怎样用双哈希降低碰撞概率？
  • 为什么二分上界是 n-1？
  • 如何改成返回所有并列最长答案？
  • 后缀数组中为什么最大 LCP 就是答案长度？

常见错误

  • 禁止重叠，误判 aaaa。
  • 使用 JS Number 直接做大整数乘法导致精度丢失。
  • 仅凭单哈希相等就返回，没有核验真实字符串。
  • 二分边界停滞或忘记保存最后一次可行答案。

class Solution {
    public String longestDupSubstring(String s) {
        int lo = 1, hi = s.length() - 1, bestLen = 0, bestStart = -1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int start = find(s, mid);
            if (start != -1) {
                bestLen = mid; bestStart = start; lo = mid + 1;
            } else hi = mid - 1;
        }
        return bestStart == -1 ? "" : s.substring(bestStart, bestStart + bestLen);
    }
    private int find(String s, int len) {
        long base = 26, mod = 1_000_000_007L, hash = 0, power = 1;
        for (int i = 0; i < len; i++) {
            hash = (hash * base + s.charAt(i) - 'a') % mod;
            if (i < len - 1) power = power * base % mod;
        }
        java.util.Map<Long, java.util.List<Integer>> seen = new java.util.HashMap<>();
        seen.computeIfAbsent(hash, k -> new java.util.ArrayList<>()).add(0);
        for (int i = len; i < s.length(); i++) {
            hash = (hash - (s.charAt(i-len)-'a') * power % mod + mod) % mod;
            hash = (hash * base + s.charAt(i)-'a') % mod;
            int start = i - len + 1;
            for (int old : seen.getOrDefault(hash, java.util.List.of()))
                if (s.regionMatches(old, s, start, len)) return start;
            seen.computeIfAbsent(hash, k -> new java.util.ArrayList<>()).add(start);
        }
        return -1;
    }
}

var longestDupSubstring = function(s) {
  const base = 26n, mod = 1000000007n;
  function find(len) {
    let hash = 0n, power = 1n;
    for (let i = 0; i < len; i++) {
      hash = (hash * base + BigInt(s.charCodeAt(i) - 97)) % mod;
      if (i < len - 1) power = power * base % mod;
    }
    const seen = new Map([[hash, [0]]]);
    for (let i = len; i < s.length; i++) {
      hash = (hash - BigInt(s.charCodeAt(i-len)-97) * power % mod + mod) % mod;
      hash = (hash * base + BigInt(s.charCodeAt(i)-97)) % mod;
      const start = i - len + 1, list = seen.get(hash) || [];
      for (const old of list)
        if (s.slice(old, old + len) === s.slice(start, start + len)) return start;
      list.push(start); seen.set(hash, list);
    }
    return -1;
  }
  let lo = 1, hi = s.length - 1, bestStart = -1, bestLen = 0;
  while (lo <= hi) {
    const mid = lo + Math.floor((hi - lo) / 2), start = find(mid);
    if (start !== -1) { bestStart = start; bestLen = mid; lo = mid + 1; }
    else hi = mid - 1;
  }
  return bestStart === -1 ? "" : s.slice(bestStart, bestStart + bestLen);
};
class Solution:
    def longestDupSubstring(self, s: str) -> str:
        def find(length: int) -> int:
            base, mod = 26, 1_000_000_007
            power = pow(base, length - 1, mod)
            h = 0
            for ch in s[:length]:
                h = (h * base + ord(ch) - 97) % mod
            seen = {h: [0]}
            for i in range(length, len(s)):
                h = (h - (ord(s[i-length])-97) * power) % mod
                h = (h * base + ord(s[i]) - 97) % mod
                start = i - length + 1
                for old in seen.get(h, []):
                    if s[old:old+length] == s[start:start+length]:
                        return start
                seen.setdefault(h, []).append(start)
            return -1

        lo, hi, best_start, best_len = 1, len(s) - 1, -1, 0
        while lo <= hi:
            mid = (lo + hi) // 2
            start = find(mid)
            if start != -1:
                best_start, best_len, lo = start, mid, mid + 1
            else:
                hi = mid - 1
        return "" if best_start == -1 else s[best_start:best_start+best_len]
class Solution {
public:
    string longestDupSubstring(string s) {
        int lo=1, hi=(int)s.size()-1, bestStart=-1, bestLen=0;
        while (lo <= hi) {
            int mid=lo+(hi-lo)/2, start=find(s, mid);
            if (start!=-1) bestStart=start, bestLen=mid, lo=mid+1;
            else hi=mid-1;
        }
        return bestStart==-1 ? "" : s.substr(bestStart, bestLen);
    }
private:
    int find(const string& s, int len) {
        const long long base=26, mod=1000000007;
        long long h=0, power=1;
        for (int i=0;i<len;i++) {
            h=(h*base+s[i]-'a')%mod;
            if (i<len-1) power=power*base%mod;
        }
        unordered_map<long long, vector<int>> seen;
        seen[h].push_back(0);
        for (int i=len;i<(int)s.size();i++) {
            h=(h-(s[i-len]-'a')*power%mod+mod)%mod;
            h=(h*base+s[i]-'a')%mod;
            int start=i-len+1;
            for (int old:seen[h])
                if (s.compare(old,len,s,start,len)==0) return start;
            seen[h].push_back(start);
        }
        return -1;
    }
};
