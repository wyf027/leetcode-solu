商店中每个成员的级别

The Category of Each Member in the Store

同样来过商店，会员的购买频率可能不同。根据三张记录表，为每位会员输出对应级别，包括从未到访的人。

01 / PROBLEM

题意与数据契约

输入关系表 Members(member_id, name)、Visits(visit_id, member_id, visit_date) 与 Purchases(visit_id, charged_amount)。为所有会员返回 (member_id, name, category)，结果顺序不限。

三张表的列类型及关系约束
表列及类型唯一键 / 引用
Membersmember_id int · name varchar(30)member_id 唯一
Visitsvisit_id int · member_id int · visit_date datevisit_id 唯一；member_id 引用 Members
Purchasesvisit_id int · charged_amount intvisit_id 唯一；引用 Visits.visit_id

有到访时，转化率 = 100 × 购买次数 ÷ 到访次数。按下列规则返回英文级别字符串：

Bronze · 青铜
从未到访。
Silver · 白银
有到访，转化率低于 50%。
Gold · 黄金
50% ≤ 转化率 < 80%。
Diamond · 钻石
转化率 ≥ 80%。

约束：一次到访最多对应一条购买记录；未购买的到访可以没有 Purchases 行。题面未给出行数或数值范围，不另造上限。日期和消费金额是完整输入字段，本题按次数分级。

题名、表结构、示例输入取自本地官方元数据；题面字段为空，分级及关系约束依据公开题面转录简要转述。官方题目需订阅阅读。

05 / SOLUTION

准备好后，再展开题解

包含查询过程、证明和代码。展开后焦点移至题解标题；收起回到按钮。

保留所有会员，再统计非空标识

核心洞察

让 Members 成为查询起点。两次 LEFT JOIN 保留“没有到访”和“没有购买”的行，用两种非空 ID 的数量分别得到 V 和 P。金额大小不参与分级。

完整过程

  1. 以 member_id 将 Members 左连接到 Visits，没有到访的会员仍留下一个空扩展行。
  2. 以 visit_id 左连接到 Purchases；每次到访最多配上一条购买，不会放大记录数。
  3. 按会员 ID 和姓名分组，COUNT(v.visit_id) 得到 V，COUNT(p.visit_id) 得到 P。COUNT 会忽略 NULL。
  4. 先判断 V = 0 返回 Bronze。其余分支按 Diamond、Gold、Silver 的顺序匹配。
  5. 使用 100P ≥ 80V、100P ≥ 50V 代替除法，避免除零与整数除法截断。

示例推演

Alice 的两行到访是 18、21，仅 18 有购买，所以 V = 2、P = 1：100 < 160，且 100 ≥ 100，因此 Gold。Narihan 的空扩展行两个 ID 都为 NULL，计数均为零，因此 Bronze。

为什么正确

对任意会员 m，第一层左连接保留其每次到访；没有到访时也保留 m。Purchases.visit_id 的唯一性保证第二层连接不复制到访，每条存在的购买又恰好对应一次到访。因此两种非空 ID 计数等于真实 V 与 P。

当 V = 0 时匹配专属 Bronze 分支。当 V > 0 时，将转化率的不等式乘以正数 V 不改变方向，因此交叉相乘与原规则等价。先检查 80，再检查 50，最终区间互斥且覆盖所有合法情况。每个会员分组产生一行，既不遗漏也不合并同名会员。

边界与常见错误

  • COUNT(*) 会把没有到访时的占位行算为 1；应该统计非空 visit_id。
  • INNER JOIN 或 WHERE p.visit_id IS NOT NULL 会丢掉未消费的到访，甚至丢失会员。
  • 先检查 50 会让钻石会员被归为 Gold；50 和 80 的边界使用 ≥。
  • 只按 name 分组会合并同名会员；完整写出 member_id 与 name。
  • COUNT(charged_amount) 依赖金额非空，SUM(charged_amount) 则是在统计钱；本题用购买标识计数更直接。
  • 不要先截断 P/V 再乘 100；零到访不能当成 0% 的 Silver。
  • 空表可返回空结果；相同日期的不同 visit_id 仍是多次到访。

复杂度

设 M、V、P 为三表行数。在哈希连接与哈希聚合的理想计划下，处理时间可为 O(M + V + P)，额外空间为 O(M + V + P) 的上界。SQL 实际代价由索引、连接顺序与执行计划决定；排序聚合或嵌套循环可能更慢，不能保证所有数据库都线性。

下方四语言参考先建立购买 ID 集合，再累计会员计数：哈希操作平均 O(1) 时，总时间 O(M + V + P)，额外空间 O(M + P)，包含结果数组。JavaScript 使用 Number，需保证计数乘 100 仍为安全整数；Java/C++ 使用 64 位计数，也有有限整数上界。它们依赖上述合法主外键输入，不额外实现数据库约束校验。

替代方案

先把 Visits 与 Purchases 按会员预聚合，再左连接 Members，可以把中间结果压缩到每会员一行。也可以用 EXISTS 判断每次到访是否购买；若业务变为每次到访多笔购买，EXISTS 或先按 visit_id 去重可避免连接放大。逐会员重复子查询更直观，但无合适索引时可能反复扫描。

面试追问

  • 允许一访多笔订单怎么办？先明确要统计“购买到访数”还是“订单数”，再决定去重与阈值定义。
  • 只看最近一个月呢？在 Visits 子查询或 JOIN ON 中筛选日期，保留窗口内无到访会员；不要用外层 WHERE 意外消除左连接空行。
  • 数据量大时如何优化？关注 Visits(member_id) 与 Purchases(visit_id) 的访问路径，并实际查看 EXPLAIN；不要仅凭 SQL 长度判断效率。

官方可提交语言：MySQL

下列完整查询为主要解法。无需输出转化率列，也无需排序。

SQL · LEFT JOIN + GROUP BY + CASE

SELECT m.member_id, m.name,
       CASE
         WHEN COUNT(v.visit_id) = 0 THEN 'Bronze'
         WHEN 100.0 * COUNT(p.visit_id) >= 80.0 * COUNT(v.visit_id)
           THEN 'Diamond'
         WHEN 100.0 * COUNT(p.visit_id) >= 50.0 * COUNT(v.visit_id)
           THEN 'Gold'
         ELSE 'Silver'
       END AS category
FROM Members AS m
LEFT JOIN Visits AS v ON v.member_id = m.member_id
LEFT JOIN Purchases AS p ON p.visit_id = v.visit_id
GROUP BY m.member_id, m.name;

Java · 本地语义参考

import java.util.*;

// 本地语义参考，Java 17+；日期和金额保留在输入类型中。
class Solution {
    record Member(int member_id, String name) {}
    record Visit(int visit_id, int member_id, String visit_date) {}
    record Purchase(int visit_id, int charged_amount) {}
    record Result(int member_id, String name, String category) {}

    static List<Result> findCategories(List<Member> members,
            List<Visit> visits, List<Purchase> purchases) {
        Set<Integer> bought = new HashSet<>();
        for (Purchase p : purchases) bought.add(p.visit_id());
        Map<Integer, long[]> counts = new HashMap<>();
        for (Member m : members) counts.put(m.member_id(), new long[2]);
        for (Visit v : visits) {
            long[] c = counts.get(v.member_id());
            c[0]++;
            if (bought.contains(v.visit_id())) c[1]++;
        }
        List<Result> result = new ArrayList<>();
        for (Member m : members) {
            long[] c = counts.get(m.member_id());
            String category = c[0] == 0 ? "Bronze"
                : 100L * c[1] >= 80L * c[0] ? "Diamond"
                : 100L * c[1] >= 50L * c[0] ? "Gold" : "Silver";
            result.add(new Result(m.member_id(), m.name(), category));
        }
        return result;
    }
}

JavaScript · 本地语义参考

// 本地语义参考：三张表使用对象数组，返回结果对象数组。
function findCategories(members, visits, purchases) {
  const bought = new Set(purchases.map(p => p.visit_id));
  const counts = new Map(members.map(m => [m.member_id, [0, 0]]));
  for (const v of visits) {
    const c = counts.get(v.member_id);
    c[0]++;
    if (bought.has(v.visit_id)) c[1]++;
  }
  return members.map(m => {
    const [v, p] = counts.get(m.member_id);
    const category = v === 0 ? 'Bronze'
      : 100 * p >= 80 * v ? 'Diamond'
      : 100 * p >= 50 * v ? 'Gold' : 'Silver';
    return {member_id: m.member_id, name: m.name, category};
  });
}

Python · 本地语义参考

# 本地语义参考：输入为字典列表，不是官方 Pandas 提交签名。
def find_categories(members, visits, purchases):
    bought = {p["visit_id"] for p in purchases}
    counts = {m["member_id"]: [0, 0] for m in members}
    for visit in visits:
        c = counts[visit["member_id"]]
        c[0] += 1
        c[1] += int(visit["visit_id"] in bought)
    result = []
    for member in members:
        v, p = counts[member["member_id"]]
        if v == 0:
            category = "Bronze"
        elif 100 * p >= 80 * v:
            category = "Diamond"
        elif 100 * p >= 50 * v:
            category = "Gold"
        else:
            category = "Silver"
        result.append({"member_id": member["member_id"],
                       "name": member["name"], "category": category})
    return result

C++ · 本地语义参考

#include <string>
#include <vector>
#include <array>
#include <unordered_map>
#include <unordered_set>
using namespace std;

// 本地语义参考，C++17；表按结构体数组传入。
struct Member { int member_id; string name; };
struct Visit { int visit_id, member_id; string visit_date; };
struct Purchase { int visit_id, charged_amount; };
struct Result { int member_id; string name, category; };

vector<Result> findCategories(const vector<Member>& members,
        const vector<Visit>& visits, const vector<Purchase>& purchases) {
    unordered_set<int> bought;
    for (const auto& p : purchases) bought.insert(p.visit_id);
    unordered_map<int, array<long long, 2>> counts;
    for (const auto& m : members) counts[m.member_id] = {0, 0};
    for (const auto& v : visits) {
        auto& c = counts.at(v.member_id);
        ++c[0];
        if (bought.count(v.visit_id)) ++c[1];
    }
    vector<Result> result;
    for (const auto& m : members) {
        const auto& c = counts.at(m.member_id);
        string category = c[0] == 0 ? "Bronze"
            : 100LL * c[1] >= 80LL * c[0] ? "Diamond"
            : 100LL * c[1] >= 50LL * c[0] ? "Gold" : "Silver";
        result.push_back({m.member_id, m.name, category});
    }
    return result;
}
