移除石子的最大得分Maximum Score From Removing Stones

三堆石子，每次必须选两堆各拿一颗。真正的限制不是你能拿多快，而是最后那一堆会不会“孤单地剩下”。

MEDIUM #1753非付费题贪心 · 数学 · 堆
01 · Problem

规则很短，选择很多

有三堆石子，数量分别为 a、b、c。每回合选择两个不同且非空的石子堆，从每堆各移除一颗，并获得 1 分。当非空堆少于两堆时游戏结束。

给定三个整数 a、b、c，返回能够获得的最大分数。函数形式：maximumScore(a, b, c) → integer。

Example 01
输入a = 2, b = 4, c = 6
输出6
  1. (2,4,6) → (1,4,5) → (0,4,4)
  2. 再让后两堆配对 4 次，得到 6 分。
Example 02
输入a = 4, b = 4, c = 6
输出7
  1. 先取第一、第二堆，变为 (3,3,6)。
  2. 持续从两堆取石子，最终三堆同时清空，共 7 分。
Example 03
输入a = 1, b = 8, c = 8
输出8
  1. 连续从第二、第三堆各取一颗，共 8 回合。
  2. 只剩第一堆，无法继续，得分为 8。
约束：1 ≤ a, b, c ≤ 10⁵

    03 · Solution

    准备好看穿这三堆石子了吗？

    题解包含公式、证明、四种语言实现与面试追问。展开前，不会在首屏直接透露答案。

    Answer Unlocked

    两个上限，较小者就是答案

    核心洞察

    设总数 S = a + b + c，最大堆为 M。每得 1 分消耗 2 颗，所以得分不超过 ⌊S/2⌋；每回合又至少消耗一颗“不属于最大堆”的石子，所以得分也不超过 S − M。

    answer = min(⌊S / 2⌋, S − M)

    完整过程

    1. 计算三堆总数 S。
    2. 找出最大堆数量 M。
    3. 比较“每回合消耗两颗”的上限与“其他两堆总量”的上限。
    4. 返回两者较小值；无需真的模拟每一步。

    正确性 · 上界

    总量上界

    一次操作恰好消耗两颗石子，因此进行 x 次需至少 2x 颗，故 x ≤ ⌊S/2⌋。

    配对上界

    任何一次操作都不可能同时从最大堆取两颗，必定消耗至少一颗来自另外两堆的石子，故 x ≤ S−M。

    正确性 · 可达

    最大堆压倒其余

    若 M ≥ S−M，把其他两堆的每颗石子分别与最大堆配对，恰好得到 S−M 分。

    三堆足够均衡

    若 M < S−M，反复选择当前最大的两堆不会提前只剩一堆；直到剩 0 或 1 颗为止，可得到 ⌊S/2⌋ 分。因此较小上界总能达到。

    边界情况

    • 极不均衡：(1,1,100000) 只能得 2 分，受其他两堆总量限制。
    • 完全均衡：(5,5,5) 总数为奇数，最多得 7 分，最后剩 1 颗。
    • 临界相等：最大堆恰等于其余两堆之和时，所有石子都能两两移除。

    复杂度

    时间：O(1)，只做固定次数的加法、比较和除法。

    空间：O(1)，不随输入规模增长。

    替代方案

    可以用最大堆每次取出最大的两堆、各减一后放回，复杂度为 O(answer · log 3)；也可对三个数排序后逐步模拟。它们直观但最多执行 150000 次，没有闭式公式简洁。

    常见错误

    • 只返回 ⌊S/2⌋，忽略最大堆无法与自身配对。
    • 误以为必须使用优先队列，增加实现和证明负担。
    • 把结束条件写成“任意一堆为空”；实际是少于两堆非空才结束。
    • 模拟时固定选择原始最大的两堆，没有随状态重新比较。

    面试追问

    • 为什么贪心选当前最大的两堆不会吃亏？它优先降低成为孤立剩余的风险；公式证明进一步说明其能达到紧上界。
    • 扩展到 k 堆呢？若每次仍从两堆各取一颗，答案仍由总数的一半和“除最大堆外总数”共同限制：min(⌊S/2⌋, S−M)。
    • 会溢出吗？本题三项各不超过 10⁵，32 位整数安全；若范围扩大，应使用 64 位整数。
    Implementations

    四种语言，都是同一个公式

    JavaLeetCode 可提交
    class Solution {
    public int maximumScore(int a, int b, int c) {
        int sum = a + b + c;
        int maxPile = Math.max(a, Math.max(b, c));
        return Math.min(sum / 2, sum - maxPile);
    }
}
