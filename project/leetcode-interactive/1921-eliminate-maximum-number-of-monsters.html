消灭怪物的最大数量

Eliminate Maximum Number of Monsters

每一分钟，只有一次开火机会。你能守住这座城市多久？

官方题目 ↗

任务说明

给定两个从 0 开始、长度相同的整数数组 dist 和 speed。第 i 个怪物距城市 dist[i] 千米，以每分钟 speed[i] 千米的恒定速度向城市移动。

武器初始已充满电，可以在第 0 分钟消灭一个怪物；每次开火后需要一分钟充电。任何存活怪物一旦抵达城市，游戏立即结束。若抵达与充电完成同时发生，先判定失败，不能再开火。

返回失败前最多能消灭的怪物数量；若可全部消灭，返回 n。

约束

  • n == dist.length == speed.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ dist[i], speed[i] ≤ 10⁵

官方示例

示例 1

dist = [1,3,4]
speed = [1,1,1]
输出：3

分别在 t=0、1、2 消灭三个怪物，可以全部消灭。

中文元数据将最后一次开火误写为第 3 分钟；这里按时间规则与英文示例采用第 2 分钟。

示例 2

dist = [1,1,2,3]
speed = [1,1,1,1]
输出：1

t=0 消灭一个怪物后，另一个初始距离为 1 的怪物在 t=1 抵达，立即失败。

示例 3

dist = [3,2,4]
speed = [5,3,2]
输出：1

前两个怪物都在一分钟内抵达，开火一次后，武器来不及再次充满。

题解 · 先处理最早的截止时间

核心洞察

距离和速度单独都不能衡量紧迫程度，真正的截止时间是 dist[i] / speed[i]。开火时刻只能是 0、1、2……，且必须严格早于抵达时间。用整数 arrival[i] = ceil(dist[i] / speed[i]) 表示第一个不能再开火的整数时刻，整数射击时刻 t 合法当且仅当 t < arrival[i]。

完整过程

  1. 计算每个怪物的整数截止时刻：(dist[i] + speed[i] - 1) / speed[i] 向下取整。
  2. 把这些截止时刻升序排序。
  3. 第 i 个怪物计划在第 i 分钟消灭。若 arrival[i] ≤ i，返回 i；否则继续。
  4. 全部通过则返回 n。

例如 dist=[3,1,2], speed=[1,1,1]：截止时刻为 [3,1,2]，排序后 [1,2,3]。在 0、1、2 分钟分别处理，每次均严格早于截止时刻，答案为 3。

正确性说明

交换论证：若某个可行顺序先消灭截止时间较晚的 B，再消灭较早的 A，交换二者后，A 提前消灭依然合法；B 被放在 A 原来的合法时刻，该时刻早于 A 的截止时间，也早于 B 的截止时间。因此不断交换逆序对，就能得到按截止时间排序的可行顺序。

失败是不可避免的：若排序后的第 i 项满足 arrival[i] ≤ i，则前 i+1 个怪物都必须在第 i 分钟前消灭，而可用射击时刻只有 0 到 i−1，共 i 次，无论如何安排都不够。此前贪心已消灭 i 个，因此返回 i 正好最优。若没有失败点，则 n 个都能消灭。

边界与常见错误

  • 初始武器已充满，首次开火在 0 分钟，不能从 1 开始计数。
  • 到达与充电同时发生时先失败，判断是 ≤，不是 <。
  • 正整数除法需要向上取整，直接截断会错误处理分数抵达时间。
  • 重复截止时间并不总是失败，例如 [2,2] 可在 0、1 分钟全部处理。
  • JavaScript 排序必须传 (a,b) => a-b；默认排序按字符串。
  • 只按距离或速度排序都不正确；不需要逐分钟移动所有怪物。
  • n=1 时总可在 t=0 消灭它；正数约束保证不会在初始时刻失败。

复杂度

时间 O(n log n)，由排序主导；额外空间 O(n)，用于保存截止时刻。四份实现都不修改原数组。

替代方案

可用最小堆逐个取出最早截止时刻，仍为 O(n log n)，适合流式加入任务。还可把截止时刻截断到 n，放入 n+1 个计数桶：若截至 t 的累计怪物数大于 t，返回 t；否则返回 n。桶法时间与空间均为 O(n)，但排序法更直观。

面试追问

  • 如何避免浮点误差？使用整数向上取整；若改用交叉乘法比较真实时间，要注意乘积溢出。
  • 每次充电需要 k 分钟？第 i 次开火时刻为 i·k，仍须严格早于真实抵达时间。
  • 若每个怪物需要不同的攻击次数？交换论证的单位任务前提不再成立，需要重新分析调度问题。

Java

import java.util.Arrays;

class Solution {
    public int eliminateMaximum(int[] dist, int[] speed) {
        int n = dist.length;
        int[] arrival = new int[n];
        for (int i = 0; i < n; i++) {
            arrival[i] = (dist[i] + speed[i] - 1) / speed[i];
        }
        Arrays.sort(arrival);
        for (int i = 0; i < n; i++) {
            if (arrival[i] <= i) return i;
        }
        return n;
    }
}

JavaScript

/**
 * @param {number[]} dist
 * @param {number[]} speed
 * @return {number}
 */
var eliminateMaximum = function(dist, speed) {
    const arrival = dist.map((d, i) =>
        Math.floor((d + speed[i] - 1) / speed[i]));
    arrival.sort((a, b) => a - b);
    for (let i = 0; i < arrival.length; i++) {
        if (arrival[i] <= i) return i;
    }
    return arrival.length;
};

Python

from typing import List

class Solution:
    def eliminateMaximum(self, dist: List[int], speed: List[int]) -> int:
        arrival = sorted((d + s - 1) // s for d, s in zip(dist, speed))
        for i, deadline in enumerate(arrival):
            if deadline <= i:
                return i
        return len(dist)

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int eliminateMaximum(vector<int>& dist, vector<int>& speed) {
        int n = dist.size();
        vector<int> arrival(n);
        for (int i = 0; i < n; ++i) {
            arrival[i] = (dist[i] + speed[i] - 1) / speed[i];
        }
        sort(arrival.begin(), arrival.end());
        for (int i = 0; i < n; ++i) {
            if (arrival[i] <= i) return i;
        }
        return n;
    }
};
