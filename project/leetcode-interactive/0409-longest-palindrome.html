01 / Problem

先把问题读准确

题目描述

给定字符串 s，其中只包含大写或小写英文字母。请返回：使用这些字母构造出的最长回文串的长度。

每个字符最多使用它在 s 中出现的次数；字符可以重新排列。字母区分大小写，所以 "Aa" 不能组成长度为 2 的回文串。

返回的是长度，不是具体回文串。
交互实验会展示一种可行构造，仅用于帮助理解题目。

函数签名

longestPalindrome(s: string) -> integer

约束

  • 1 <= s.length <= 2000
  • s 只由小写和/或大写英文字母组成。

官方示例

示例 1
输入：s = "abccccdd"
输出：7
解释：可构造 "dccaccd"，长度为 7。
示例 2
输入：s = "a"
输出：1
解释：最长回文串就是 "a"。
观察重点：回文串左右两边互为镜像，只有正中心最多可以单独放一个字符。

Core Insight

把频次拆成“成对部分 + 中心位”

01

偶数次全部使用

同一字符每两枚可以分别放在回文串左右两侧，不会破坏对称。

02

奇数次先取偶数部分

频次为奇数时，先使用 count - 1 枚，留下一个候选中心字符。

03

中心最多补一枚

只要仍有未使用字符，就能任选一枚放到唯一的中心位置。

answer = Σ floor(count[c] / 2) × 2
若 answer < s.length，则 answer += 1

完整过程

  1. 统计每个大小写字母的出现次数；大小写使用不同槽位。
  2. 对每个频次 count，将最大偶数部分 (count / 2) * 2 加入答案。
  3. 若累计长度小于原字符串长度，说明至少有字符被剩下；把其中一枚放到中心，答案加一。
  4. 返回累计长度。

边界情况

  • 单字符：成对部分为 0，中心补 1。
  • 全部字符均成对：直接使用全部字符，不再补中心。
  • 全部字符各不相同：只能任选一个作为中心，答案为 1。
  • 大小写混合：A 与 a 必须分别计数。

正确性说明

可行性：每个字符选出的偶数枚可以均分到左右两侧，因此所有这些字符一定能排列成对称结构；若有剩余，再把任意一枚放在中心，仍是回文串。
上界：除中心外，回文串中的每个字符都必须成对出现。所以字符 c 最多贡献不超过其频次的最大偶数；中心位置全串又至多只有一个。
最优性：算法恰好取满每个字符允许贡献的最大偶数，并在可能时使用唯一中心位，达到上述上界，因此长度最长。

复杂度

时间复杂度
O(n)
扫描字符串一次，再遍历固定大小计数表。
空间复杂度
O(1)
英文字母种类固定；若推广到任意字符集，则为 O(k)。

Implementations

四种语言完整代码

Java官方可提交
class Solution {
    public int longestPalindrome(String s) {
        int[] count = new int[128];
        for (char c : s.toCharArray()) {
            count[c]++;
        }

        int length = 0;
        for (int frequency : count) {
            length += (frequency / 2) * 2;
        }

        if (length < s.length()) {
            length++;
        }
        return length;
    }
}

var longestPalindrome = function(s) {
    const count = new Map();
    for (const char of s) {
        count.set(char, (count.get(char) || 0) + 1);
    }

    let length = 0;
    for (const frequency of count.values()) {
        length += Math.floor(frequency / 2) * 2;
    }

    return length < s.length ? length + 1 : length;
};

from collections import Counter


class Solution:
    def longestPalindrome(self, s: str) -> int:
        frequencies = Counter(s)
        length = sum(
            (frequency // 2) * 2
            for frequency in frequencies.values()
        )

        if length < len(s):
            length += 1
        return length

替代方案

  • 奇数字符集合：扫描时用集合记录尚未配对的字符；再次遇到就移除，并让答案加 2。结尾若集合非空再加 1。时间 O(n)，空间 O(k)。
  • 排序后计数：先排序，再统计连续相同字符。逻辑直观，但时间复杂度升为 O(n log n)，没有必要。
  • 按奇数频次扣减：从 n 出发，每个奇数频次先扣 1，最后若存在奇数频次再补回 1；本质与主解相同。

常见错误

  • 误以为只能寻找原字符串中的最长回文子串；本题允许重新排列字符。
  • 给每一种奇数频次都保留一个中心字符；中心位置全局只有一个。
  • 忽略大小写，错误地把 A 和 a 配成一对。
  • 无条件给答案加 1，导致全部字符都已成对时结果超过字符串长度。

面试追问

Q：如果字符集不是英文字母怎么办？
改用哈希表统计 Unicode 字符；复杂度表示为 O(n) 时间、O(k) 空间，其中 k 是不同字符数。
Q：如何真正构造一个最长回文串？
为每个字符取一半放到左侧，右侧放左侧的逆序；若存在奇数频次，再任选对应字符作为中心。
Q：能否一边扫描一边得到长度？
可以。每当某字符累计到偶数次，就说明新完成一对，长度加 2；结束后若还有未配对字符，再加 1。
Q：为什么不需要动态规划？
重新排列后，字符原位置不再重要；答案只由频次的奇偶性决定，不存在需要保留的区间状态。
