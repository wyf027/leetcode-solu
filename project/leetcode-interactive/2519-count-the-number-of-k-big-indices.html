COUNT THE NUMBER OF K-BIG INDICES

统计 K-Big
索引的数量

一个位置，两侧门槛。左右两边，是否都有足够多比它小的数？

01 / 题意与参数

给定从 0 开始编号的整数数组 nums 和正整数 k。对每个位置 i，分别统计它左侧和右侧有多少个元素严格小于 nums[i]。两侧数量都至少是 k 时，i 就是 K-Big 索引。返回这样的索引数量。

左侧门槛

满足 j < i 且 nums[j] < nums[i] 的下标至少有 k 个。

右侧门槛

满足 j > i 且 nums[j] < nums[i] 的下标至少有 k 个。

不同下标可以对应相同数值。相等值不算更小；不要求相邻或连续；左右必须同时满足。

kBigIndices(nums: integer[], k: integer) → integer

约束

  • 1 ≤ nums.length ≤ 100000
  • 1 ≤ nums[i] ≤ nums.length
  • 1 ≤ k ≤ nums.length

示例 1

输入：nums = [2,3,6,5,2,3], k = 2
输出：2

i = 2（值 6）：左边下标 0、1，右边下标 3、4、5 的值更小。i = 3（值 5）：左边下标 0、1，右边下标 4、5 的值更小。恰有这两个位置达标。

示例 2

输入：nums = [1,1,1], k = 3
输出：0

所有值都相等，没有严格更小的元素，因此没有符合条件的索引。

03 / 独立题解

算法、交互推演、证明与四语言实现。

核心洞察：双向扫描 + 值频次

记左侧更小数为 L[i]，右侧更小数为 R[i]。从左往右扫时，已经见过的就是左侧；从右往左扫时，已经见过的就是右侧。用树状数组（Fenwick Tree）保存已见元素的值频次，便可快速求两边的计数。

由于值域是 1 到 n，树可直接按数值编号。sum(nums[i] - 1) 得到所有严格更小值的频次总和；相等值被排除。重复的小值依然按每次出现分别计数。

  1. 创建长度 n + 1 的树，从左向右先查询 L[i]，再插入 nums[i]。
  2. 清空树，保留 L 数组。
  3. 从右向左先查询 R[i]。若 L[i] ≥ k 且 R[i] ≥ k，答案加 1。随后插入 nums[i]。

lowbit(x) = x & -x。节点 bit[x] 管理值区间 [x − lowbit(x) + 1, x]。查询沿 x -= lowbit(x) 拆分前缀；更新沿 x += lowbit(x) 维护覆盖该值的节点。

正确性证明

  1. 扫描不变量：左扫处理 i 之前，树中恰有所有下标小于 i 的值频次。空树满足初始状态；查询不修改树，插入当前值后下一步仍满足。清树后的右扫同理，树中恰有下标大于 i 的元素。
  2. 查询准确：树状数组把 [1, nums[i] − 1] 拆成互不重叠的节点区间并求和，恰好统计已见元素中严格更小的个数。每次出现只计一次，不受重复值影响。
  3. 判定等价：查询结果恰为 L[i]、R[i]，同时与 k 比较正是题目条件。每个位置仅在右扫时判断一次，因此无遗漏、无重复。

复杂度

两轮各 n 次查询与更新，每次 O(log n)，总时间 O(n log n)。树和 L 数组共 O(n) 额外空间；R 无需保存。演示为回放保存快照，限制为最多 20 项，不代表提交代码的空间开销。

边界条件

  • n = 1、全相等、严格单调：答案为 0。
  • 值为 1：查询前缀 0，返回 0。
  • 重复的小值按位置分别计数。
  • n < 2k + 1 时可提前返回 0；这里统一使用两轮扫描。
  • 单个计数和答案均不超过 n，常规整数足够。

替代方案

方法时间 / 空间取舍
逐个扫描两侧O(n²) / O(1)便于理解，不适合最大输入
两轮维护 k 个最小值的大根堆O(n log(k+1)) / O(n+k)堆满且堆顶 < 当前值，则该侧达标
线段树O(n log n) / O(n)统计值域频次，代码更多
归并排序计数O(n log n) / O(n)按原下标累计，注意相等值

有序数组配合二分查找，插入仍可能需要 O(n) 搬移，不能因此声称总复杂度 O(n log n)。值域若包含负数或达到 10⁹，先排序去重、映射为 1 基排名，再使用同样的频次树。

Java

class Solution {
    private int sum(int[] bit, int x) {
        int s = 0;
        for (; x > 0; x -= x & -x) s += bit[x];
        return s;
    }
    private void add(int[] bit, int x) {
        for (; x < bit.length; x += x & -x) bit[x]++;
    }
    public int kBigIndices(int[] nums, int k) {
        int n = nums.length, answer = 0;
        int[] left = new int[n], bit = new int[n + 1];
        for (int i = 0; i < n; i++) {
            left[i] = sum(bit, nums[i] - 1);
            add(bit, nums[i]);
        }
        bit = new int[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            int right = sum(bit, nums[i] - 1);
            if (left[i] >= k && right >= k) answer++;
            add(bit, nums[i]);
        }
        return answer;
    }
}

Python

from typing import List

class Solution:
    def kBigIndices(self, nums: List[int], k: int) -> int:
        n = len(nums)
        bit = [0] * (n + 1)
        left = [0] * n

        def query(x: int) -> int:
            total = 0
            while x > 0:
                total += bit[x]
                x -= x & -x
            return total

        def add(x: int) -> None:
            while x <= n:
                bit[x] += 1
                x += x & -x

        for i, value in enumerate(nums):
            left[i] = query(value - 1)
            add(value)

        bit = [0] * (n + 1)
        answer = 0
        for i in range(n - 1, -1, -1):
            right = query(nums[i] - 1)
            if left[i] >= k and right >= k:
                answer += 1
            add(nums[i])
        return answer

C++

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    int kBigIndices(vector<int>& nums, int k) {
        int n = static_cast<int>(nums.size());
        vector<int> bit(n + 1, 0), left(n, 0);
        auto query = [&](int x) {
            int s = 0;
            for (; x > 0; x -= x & -x) s += bit[x];
            return s;
        };
        auto add = [&](int x) {
            for (; x <= n; x += x & -x) ++bit[x];
        };
        for (int i = 0; i < n; ++i) {
            left[i] = query(nums[i] - 1);
            add(nums[i]);
        }
        fill(bit.begin(), bit.end(), 0);
        int answer = 0;
        for (int i = n - 1; i >= 0; --i) {
            int right = query(nums[i] - 1);
            if (left[i] >= k && right >= k) ++answer;
            add(nums[i]);
        }
        return answer;
    }
};

常见错误

  • 查询 sum(value)，误计相等值。
  • 对元素去重，丢掉不同位置的出现次数。
  • 两侧条件写成“或”；必须同时达标。
  • 第二轮忘记清树，混入上一轮的频次。
  • 按数组下标更新；树的轴应当是数值。
  • 从 0 开始更新，lowbit(0) = 0 会死循环。
  • 数满足条件的组合数，而不是索引数。

面试追问

  • 仅需判断是否 ≥ k？ 可用大小为 k 的堆，并仅保存左侧布尔结果。
  • 改为小于等于？ 查询 value，务必查询后插入以排除自己。
  • 多个 k 查询？ 预计算每个 min(L[i], R[i])，排序后按 k 二分计数。
  • 流式输入？ 左侧可在线统计，完整右侧计数需要未来数据。
