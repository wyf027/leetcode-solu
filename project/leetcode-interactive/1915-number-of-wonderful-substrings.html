1915. 最美子字符串的数目

Number of Wonderful Substrings · MEDIUM · 免费题

从连续字符中，找出符合“至多一个奇数”的片段。

题目

给定字符串 word，只包含 a 到 j。一个字符串若最多只有一种字母出现奇数次，就称为“最美”。返回所有最美非空连续子字符串的出现次数；内容相同但位置不同的片段要分别计数。

例如 ccjjc 和 abab 满足条件，ab 不满足。所有字母次数均为偶数也满足条件。

约束

  • 1 ≤ word.length ≤ 100000
  • word 中的字符仅为小写字母 a 至 j。

官方题目 · 内容依据本轮官方元数据转述。

输入：word = "aba"
输出：4

示例 2

输入：word = "aabb"
输出：9

按起点分组：a, aa, aab, aabb；a, abb；b, bb；b。

示例 3

输入：word = "he"
输出：2

只有 h 与 e 两个片段。

题解 · 十盏奇偶灯

核心洞察

每个字母只需要记录奇偶性。用 10 位二进制状态表示一个前缀：第 k 位为 1 表示对应字母出现奇数次。读取字符时翻转对应位。两个前缀状态异或，正好得到它们之间子串的奇偶状态。

因此，当前前缀只需要匹配历史中相同状态（零个奇数字母），以及只差一位的十个状态（一个奇数字母）。不必枚举所有子串。

交互 · 前缀状态匹配台

每一步处理一个字符，展示 11 个候选历史状态的命中次数。灯按 a → j 排列，黄色表示奇数；二进制数字按 j → a 排列。候选计数取自登记当前前缀之前。

候选历史状态（j → a）关系命中次数
演示为逐步计算轨迹，不代表已经通过验证。减少动态效果偏好开启时，自动播放间隔为 2 秒。


完整过程
  1. 建立 1024 个状态的频率数组，初始 freq[0] = 1，表示空前缀。
  2. 读入字母，用 mask ^= 1 << k 更新奇偶状态。
  3. 累加 freq[mask]；再依次累加十个 freq[mask ^ (1 << k)]。
  4. 最后执行 freq[mask]++，供后面的右端点使用。
例如 aba：读 a 后新增 1；读 b 后新增 1；读最后的 a 后，匹配空前缀得到 aba，匹配前缀 ab 得到最后的 a，新增 2，总计 4。


正确性
设 P[r] 为前 r 个字符的奇偶状态。子串 word[l:r] 的状态为 P[r] XOR P[l]，因为前 l 个字符出现两次，在奇偶计算中抵消。子串最美当且仅当异或结果为 0 或某个单比特值。因此上述 11 类匹配覆盖所有且仅覆盖合法左端点；各类互斥，不会重复。
处理右端点 r 前，频率数组恰好保存 P[0] 到 P[r−1]。查询后登记 P[r] 保持此不变式，并确保 l < r，不计空串。每个非空子串有唯一右端点，逐轮相加便得到全部答案。


边界与常见错误
  • 漏记空前缀会漏掉从索引 0 开始的子串。
  • 先登记再查询会把空串算进去。
  • 只匹配一位差异会漏掉所有字母均为偶数的子串。
  • 频率必须累加，不能仅使用集合；相同状态可对应多个左端点。
  • 单字符答案为 1；全相同字符时所有子串都合法，答案为 n(n+1)/2。
  • 最大答案 5000050000，Java 用 long，C++ 用 long long。JavaScript Number 可精确表示该范围，但不要把答案用于 32 位位运算。


复杂度与替代方案
时间 O(10n + 2¹⁰)，通常写 O(n)；额外空间 O(2¹⁰)。频率数组固定 1024 格。暴力枚举左右端点并增量维护奇偶状态需要 O(n²) 时间，仅适合短串。哈希表也能存前缀频率，但在这个固定小状态空间中，数组更直接。


面试追问
最多 k 个奇数字母？ 枚举与当前状态汉明距离不超过 k 的掩码，查询数量为 Σ C(10,i)，i 从 0 到 k。扩展到 26 个字母？ 仍可查询相同及 26 个单比特差异状态，使用哈希表避免分配 2²⁶ 个计数。能否重新排列为回文？ 可以，至多一种奇数频次正是这一条件，但题目统计的仍然是原字符串中的连续片段。


Java
class Solution {
    public long wonderfulSubstrings(String word) {
        long[] freq = new long[1024];
        freq[0] = 1;
        int mask = 0;
        long ans = 0;
        for (int i = 0; i < word.length(); i++) {
            mask ^= 1 << (word.charAt(i) - 'a');
            ans += freq[mask];
            for (int k = 0; k < 10; k++)
                ans += freq[mask ^ (1 << k)];
            freq[mask]++;
        }
        return ans;
    }
}

/** @param {string} word @return {number} */
var wonderfulSubstrings = function(word) {
    const freq = Array(1024).fill(0);
    freq[0] = 1;
    let mask = 0, ans = 0;
    for (const ch of word) {
        mask ^= 1 << (ch.charCodeAt(0) - 97);
        ans += freq[mask];
        for (let k = 0; k < 10; k++)
            ans += freq[mask ^ (1 << k)];
        freq[mask]++;
    }
    return ans;
};


Python
class Solution:
    def wonderfulSubstrings(self, word: str) -> int:
        freq = [0] * 1024
        freq[0] = 1
        mask = ans = 0
        for ch in word:
            mask ^= 1 << (ord(ch) - ord('a'))
            ans += freq[mask]
            for k in range(10):
                ans += freq[mask ^ (1 << k)]
            freq[mask] += 1
        return ans
