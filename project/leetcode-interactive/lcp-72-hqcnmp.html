LCP 72. 补给马车

把相邻、物资总量最小的一对马车合并；若总量并列，选择更靠左的一对。重复直到车队长度降为原来的一半（向下取整）。

编号：LCP 72难度：简单主线：模拟

题意

给定 supplies，每项代表一辆马车的物资。每次找出相邻两车中和最小的一对并合并成一车；和相同则优先左侧那对。最终保留 floor(n / 2) 辆车。

示例

supplies = [7, 3, 6, 1, 8]

输出 = [10, 15]

每次只合并一对；数组缩短后必须重新比较所有相邻对。

范围

2 ≤ n ≤ 1000

范围

1 ≤ supplies[i] ≤ 1000

如何读这道题

  1. 1扫描所有 i, i + 1，记录严格更小的和。
  2. 2严格小于而非小于等于：这样第一次出现的最小和自然保留，满足“编号最小”。
  3. 3将左车改为和，删除右车，继续直到目标长度。

题解：直接模拟每次合并

长度最多 1000，每轮线性扫描并删除一个元素足够可靠。初始长度为 n，需要合并 n - floor(n / 2) 次；每次扫描 O(n)、删除 O(n)，总复杂度 O(n²)，额外空间 O(1)（不计返回数组）。

完整过程

遍历 j = 0 到 size - 2，仅在 sum < bestSum 时更新 bestIndex。写回 a[bestIndex] = bestSum，再删除 bestIndex + 1。

边界与常见错误

奇数长度仍取 floor(n / 2)；并列时不能用 <= 覆盖先出现的答案；合并后相邻关系改变，不能预先排序或只扫描一次。

替代方案与面试追问

本范围内暴力模拟最清晰。若 n 极大，可考虑双向链表、最小堆和版本号来懒删除失效相邻对，但实现复杂度明显上升。追问：如何保证并列取最左？答：堆键使用 (pairSum, leftIndex)，并维护有效性版本。

四语言可提交代码

Java

import java.util.*;
class Solution {
  public int[] supplyWagon(int[] supplies) {
    List<Integer> a = new ArrayList<>();
    for (int x : supplies) a.add(x);
    int target = a.size() / 2;
    while (a.size() > target) {
      int best = 0, bestSum = Integer.MAX_VALUE;
      for (int i = 0; i + 1 < a.size(); i++) {
        int sum = a.get(i) + a.get(i + 1);
        if (sum < bestSum) { bestSum = sum; best = i; }
      }
      a.set(best, bestSum); a.remove(best + 1);
    }
    return a.stream().mapToInt(Integer::intValue).toArray();
  }
}

/** @param {number[]} supplies @return {number[]} */
var supplyWagon = function (supplies) {
  const a = [...supplies], target = Math.floor(a.length / 2);
  while (a.length > target) {
    let best = 0, bestSum = Infinity;
    for (let i = 0; i + 1 < a.length; i++) {
      const sum = a[i] + a[i + 1];
      if (sum < bestSum) { bestSum = sum; best = i; }
    }
    a.splice(best, 2, bestSum);
  }
  return a;
};

from typing import List

class Solution:
    def supplyWagon(self, supplies: List[int]) -> List[int]:
        a = supplies[:]
        target = len(a) // 2
        while len(a) > target:
            best = 0
            for i in range(1, len(a) - 1):
                if a[i] + a[i + 1] < a[best] + a[best + 1]:
                    best = i
            a[best:best + 2] = [a[best] + a[best + 1]]
        return a

C++

#include <vector>
#include <climits>
using namespace std;

class Solution {
 public:
  vector<int> supplyWagon(vector<int>& supplies) {
    int target = supplies.size() / 2;
    while ((int)supplies.size() > target) {
      int best = 0, bestSum = INT_MAX;
      for (int i = 0; i + 1 < (int)supplies.size(); ++i) {
        int sum = supplies[i] + supplies[i + 1];
        if (sum < bestSum) bestSum = sum, best = i;
      }
      supplies[best] = bestSum;
      supplies.erase(supplies.begin() + best + 1);
    }
    return supplies;
  }
};
