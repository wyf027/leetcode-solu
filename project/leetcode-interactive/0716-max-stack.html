最大栈 Max Stack

设计一种兼具普通栈语义与“最大值操作”的数据结构。先读清五个方法的行为，再用操作实验室观察重复最大值如何被处理；完整解法藏在页面底部。

push(x)压入元素
pop()弹出栈顶
top()读取栈顶
peekMax()读取最大值
popMax()删除最靠近栈顶的最大值

Problem brief

题目要求

实现 MaxStack 类。它像栈一样后进先出，同时能查看并移除当前最大元素。若最大值出现多次， popMax() 必须删除其中最靠近栈顶的那一个。

接口定义

  • MaxStack()：初始化空栈。
  • void push(int x)：将整数 x 压入栈顶。
  • int pop()：删除并返回栈顶元素。
  • int top()：返回栈顶元素，但不删除它。
  • int peekMax()：返回栈中最大元素，但不删除它。
  • int popMax()：删除并返回最大元素；有并列时删除最靠近栈顶者。
性能目标：top() 为 O(1)，其余操作为 O(log n)。其中 n 是当前栈内元素数量。

官方示例（完整参数形式）

输入：
["MaxStack","push","push","push","top","popMax","top","peekMax","pop","top"]
[[],[5],[1],[5],[],[],[],[],[],[]]

输出：
[null,null,null,null,5,5,1,5,1,5]

过程：依次压入 5、1、5。top() 得到 5；popMax() 删除靠近栈顶的那个 5；随后栈顶是 1，而栈中最大值仍是底部的 5。

约束

  • -107 ≤ x ≤ 107
  • 对五种方法的调用总数最多为 104。
  • 调用 pop、top、peekMax 或 popMax 时，栈中至少有一个元素。

读题关键

“最大值”只决定要删哪个数；“最靠近栈顶”决定重复最大值中的具体实例。示例里的两个 5 数值相同，却不是同一个栈节点。

题解 · 双向链表 + 有序值索引

核心洞察

一种结构很难同时快速回答“最后压入的是谁”和“最大值是谁”。因此把两个排序维度拆开：双向链表维护入栈顺序，有序映射维护数值顺序。映射的每个键对应一组同值链表节点，并按入栈顺序保存这些节点。

顺序不变量双向链表从头到尾始终等于从栈底到栈顶的元素顺序。
归属不变量每个有效链表节点恰好出现在其数值对应的索引桶中一次。
最近不变量每个值桶的末端节点，是该值当前最靠近栈顶的实例。

完整过程

  1. push(x)：在链表尾部插入新节点，并把节点追加到有序映射中键 x 的桶尾。
  2. top()：直接读取链表尾哨兵的前一个节点。
  3. pop()：取链表尾节点，从链表与对应值桶的尾部同时删除；空桶从映射移除。
  4. peekMax()：读取有序映射的最大键。
  5. popMax()：找到最大键，取该值桶末端节点。这个节点就是最靠近栈顶的最大值；再把它从链表和桶中删除。

正确性证明

初始化：链表只有首尾哨兵，有序映射为空，三个不变量显然成立。

保持：push 同时追加链表尾和对应桶尾，因此新节点既位于栈顶，也是该值最近的节点；三个不变量继续成立。pop 删除链表尾，而按顺序不变量它正是栈顶；同值节点的桶顺序与入栈顺序一致，所以它也在桶尾。两处同步删除后不变量不变。

最大值操作：有序映射的最大键等于栈中最大值。根据最近不变量，该键桶尾是所有最大值中最靠近栈顶的节点，所以 peekMax 返回正确数值，popMax 删除正确实例。同步移除后不变量仍成立。

结论：由归纳法，任意合法操作序列中五个方法都符合题目语义。

复杂度

操作时间原因
pushO(log n)有序索引插入；链表追加 O(1)
popO(log n)更新或删除有序索引键；链表删除 O(1)
topO(1)读取链表尾节点
peekMaxO(log n)读取有序结构最大键；部分标准库可视为 O(1) 取尾迭代器
popMaxO(log n)定位最大键并维护有序索引；链表删除 O(1)

空间复杂度为 O(n)：每个元素对应一个链表节点和一个索引桶引用。

边界情况

  • 只有一个元素时，pop 和 popMax 都会同时清空链表与其值桶。
  • 多个最大值并列时，必须取最大值桶的末端节点，而不是任意一个最大值节点。
  • 所有值为负数时不能把最大值默认成 0，应完全依赖有序索引。
  • 删除某值最后一个节点后要移除空桶，否则之后的 peekMax 可能看到幽灵键。
  • 链表中间删除节点后要同时修复前后两个方向的指针。

替代方案

  • 两个普通栈：popMax 时把最大值上方元素临时搬走，最坏 O(n)，实现简单但未达到目标复杂度。
  • 栈 + 最大堆 + 延迟删除：用唯一编号区分重复值，工程上常见；清理为摊还复杂度，证明与实现细节更多。
  • 平衡树存 (value, id)：用递增 id 表示入栈先后，配合按 id 排序的结构；概念统一，但需要维护两套有序集合。

常见错误

  • 只用一个最大值变量：最大值被弹出后无法快速找到次大值。
  • popMax 删除最早压入的最大值，违反“最靠近栈顶”规则。
  • 从链表删节点却忘记从值桶删除，或反过来，破坏归属不变量。
  • 用数组中间删除最大值节点，导致 popMax 退化为 O(n)。
  • JavaScript / Python 自写 Treap 时，同值键新建多个树节点，导致重复值顺序难以维护。

四语言完整实现

Java 与 C++ 使用标准库有序映射；JavaScript 与 Python 标准库没有等价容器，因此代码内实现 Treap，期望时间复杂度为 O(log n)。

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Map;
import java.util.TreeMap;

class MaxStack {
    private static class Node {
        int value;
        Node prev;
        Node next;

        Node(int value) {
            this.value = value;
        }
    }

    private final Node head;
    private final Node tail;
    private final TreeMap<Integer, Deque<Node>> byValue;

    public MaxStack() {
        head = new Node(0);
        tail = new Node(0);
        head.next = tail;
        tail.prev = head;
        byValue = new TreeMap<>();
    }

    public void push(int x) {
        Node node = new Node(x);
        addBeforeTail(node);
        byValue.computeIfAbsent(x, key -> new ArrayDeque<>())
               .addLast(node);
    }

    public int pop() {
        Node node = tail.prev;
        unlink(node);

        Deque<Node> nodes = byValue.get(node.value);
        nodes.removeLast();
        if (nodes.isEmpty()) {
            byValue.remove(node.value);
        }
        return node.value;
    }

    public int top() {
        return tail.prev.value;
    }

    public int peekMax() {
        return byValue.lastKey();
    }

    public int popMax() {
        Map.Entry<Integer, Deque<Node>> entry = byValue.lastEntry();
        int maxValue = entry.getKey();
        Deque<Node> nodes = entry.getValue();
        Node node = nodes.removeLast();

        if (nodes.isEmpty()) {
            byValue.remove(maxValue);
        }
        unlink(node);
        return maxValue;
    }

    private void addBeforeTail(Node node) {
        Node previous = tail.prev;
        previous.next = node;
        node.prev = previous;
        node.next = tail;
        tail.prev = node;
    }

    private void unlink(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }
}
class ListNode {
  constructor(value) {
    this.value = value;
    this.prev = null;
    this.next = null;
  }
}

class TreapNode {
  constructor(key, listNode) {
    this.key = key;
    this.priority = Math.random();
    this.items = [listNode];
    this.left = null;
    this.right = null;
  }
}

var MaxStack = function () {
  this.head = new ListNode(0);
  this.tail = new ListNode(0);
  this.head.next = this.tail;
  this.tail.prev = this.head;
  this.root = null;
};

MaxStack.prototype.push = function (x) {
  const node = new ListNode(x);
  this._addBeforeTail(node);
  this.root = this._insert(this.root, x, node);
};

MaxStack.prototype.pop = function () {
  const node = this.tail.prev;
  this._unlink(node);
  this.root = this._removeLatest(this.root, node.value);
  return node.value;
};

MaxStack.prototype.top = function () {
  return this.tail.prev.value;
};

MaxStack.prototype.peekMax = function () {
  let current = this.root;
  while (current.right !== null) current = current.right;
  return current.key;
};

MaxStack.prototype.popMax = function () {
  let current = this.root;
  while (current.right !== null) current = current.right;

  const node = current.items[current.items.length - 1];
  const maxValue = current.key;
  this._unlink(node);
  this.root = this._removeLatest(this.root, maxValue);
  return maxValue;
};

MaxStack.prototype._addBeforeTail = function (node) {
  const previous = this.tail.prev;
  previous.next = node;
  node.prev = previous;
  node.next = this.tail;
  this.tail.prev = node;
};

MaxStack.prototype._unlink = function (node) {
  node.prev.next = node.next;
  node.next.prev = node.prev;
};

MaxStack.prototype._insert = function (root, key, listNode) {
  if (root === null) return new TreapNode(key, listNode);

  if (key === root.key) {
    root.items.push(listNode);
    return root;
  }

  if (key < root.key) {
    root.left = this._insert(root.left, key, listNode);
    if (root.left.priority < root.priority) {
      root = this._rotateRight(root);
    }
  } else {
    root.right = this._insert(root.right, key, listNode);
    if (root.right.priority < root.priority) {
      root = this._rotateLeft(root);
    }
  }
  return root;
};

MaxStack.prototype._removeLatest = function (root, key) {
  if (key < root.key) {
    root.left = this._removeLatest(root.left, key);
    return root;
  }
  if (key > root.key) {
    root.right = this._removeLatest(root.right, key);
    return root;
  }

  root.items.pop();
  if (root.items.length > 0) return root;
  return this._merge(root.left, root.right);
};

MaxStack.prototype._merge = function (left, right) {
  if (left === null) return right;
  if (right === null) return left;

  if (left.priority < right.priority) {
    left.right = this._merge(left.right, right);
    return left;
  }
  right.left = this._merge(left, right.left);
  return right;
};

MaxStack.prototype._rotateRight = function (root) {
  const nextRoot = root.left;
  root.left = nextRoot.right;
  nextRoot.right = root;
  return nextRoot;
};

MaxStack.prototype._rotateLeft = function (root) {
  const nextRoot = root.right;
  root.right = nextRoot.left;
  nextRoot.left = root;
  return nextRoot;
};
import random


class ListNode:
    __slots__ = ("value", "prev", "next")

    def __init__(self, value: int):
        self.value = value
        self.prev = None
        self.next = None


class TreapNode:
    __slots__ = ("key", "priority", "items", "left", "right")

    def __init__(self, key: int, item: ListNode):
        self.key = key
        self.priority = random.random()
        self.items = [item]
        self.left = None
        self.right = None


class MaxStack:
    def __init__(self):
        self.head = ListNode(0)
        self.tail = ListNode(0)
        self.head.next = self.tail
        self.tail.prev = self.head
        self.root = None

    def push(self, x: int) -> None:
        node = ListNode(x)
        self._add_before_tail(node)
        self.root = self._insert(self.root, x, node)

    def pop(self) -> int:
        node = self.tail.prev
        self._unlink(node)
        self.root = self._remove_latest(self.root, node.value)
        return node.value

    def top(self) -> int:
        return self.tail.prev.value

    def peekMax(self) -> int:
        current = self.root
        while current.right is not None:
            current = current.right
        return current.key

    def popMax(self) -> int:
        current = self.root
        while current.right is not None:
            current = current.right

        node = current.items[-1]
        max_value = current.key
        self._unlink(node)
        self.root = self._remove_latest(self.root, max_value)
        return max_value

    def _add_before_tail(self, node: ListNode) -> None:
        previous = self.tail.prev
        previous.next = node
        node.prev = previous
        node.next = self.tail
        self.tail.prev = node

    @staticmethod
    def _unlink(node: ListNode) -> None:
        node.prev.next = node.next
        node.next.prev = node.prev

    def _insert(self, root, key: int, item: ListNode):
        if root is None:
            return TreapNode(key, item)

        if key == root.key:
            root.items.append(item)
            return root

        if key < root.key:
            root.left = self._insert(root.left, key, item)
            if root.left.priority < root.priority:
                root = self._rotate_right(root)
        else:
            root.right = self._insert(root.right, key, item)
            if root.right.priority < root.priority:
                root = self._rotate_left(root)
        return root

    def _remove_latest(self, root, key: int):
        if key < root.key:
            root.left = self._remove_latest(root.left, key)
            return root
        if key > root.key:
            root.right = self._remove_latest(root.right, key)
            return root

        root.items.pop()
        if root.items:
            return root
        return self._merge(root.left, root.right)

    def _merge(self, left, right):
        if left is None:
            return right
        if right is None:
            return left

        if left.priority < right.priority:
            left.right = self._merge(left.right, right)
            return left
        right.left = self._merge(left, right.left)
        return right

    @staticmethod
    def _rotate_right(root):
        next_root = root.left
        root.left = next_root.right
        next_root.right = root
        return next_root

    @staticmethod
    def _rotate_left(root):
        next_root = root.right
        root.right = next_root.left
        next_root.left = root
        return next_root
#include <map>
#include <vector>
using namespace std;

class MaxStack {
private:
    struct Node {
        int value;
        Node* prev;
        Node* next;

        explicit Node(int value) : value(value), prev(nullptr), next(nullptr) {}
    };

    Node* head;
    Node* tail;
    map<int, vector<Node*>> byValue;

    void addBeforeTail(Node* node) {
        Node* previous = tail->prev;
        previous->next = node;
        node->prev = previous;
        node->next = tail;
        tail->prev = node;
    }

    void unlink(Node* node) {
        node->prev->next = node->next;
        node->next->prev = node->prev;
    }

public:
    MaxStack() {
        head = new Node(0);
        tail = new Node(0);
        head->next = tail;
        tail->prev = head;
    }

    ~MaxStack() {
        Node* current = head;
        while (current != nullptr) {
            Node* next = current->next;
            delete current;
            current = next;
        }
    }

    void push(int x) {
        Node* node = new Node(x);
        addBeforeTail(node);
        byValue[x].push_back(node);
    }

    int pop() {
        Node* node = tail->prev;
        int value = node->value;
        unlink(node);

        auto it = byValue.find(value);
        it->second.pop_back();
        if (it->second.empty()) {
            byValue.erase(it);
        }
        delete node;
        return value;
    }

    int top() {
        return tail->prev->value;
    }

    int peekMax() {
        return byValue.rbegin()->first;
    }

    int popMax() {
        auto it = prev(byValue.end());
        int maxValue = it->first;
        Node* node = it->second.back();
        it->second.pop_back();

        if (it->second.empty()) {
            byValue.erase(it);
        }
        unlink(node);
        delete node;
        return maxValue;
    }
};
