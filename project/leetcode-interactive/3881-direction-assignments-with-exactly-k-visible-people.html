LEETCODE 3881 · COMBINATORICS

恰好看到 K 个人的方向选择

将每个人面向左 / 右的选择，压缩成一次“从其余 n − 1 人中选 k 人可见”的组合计数。

题意

有 n 个人按下标排成一行，每人独立选择 "L" 或 "R"。站在 pos 的人：左边选择 "L" 的人可见，右边选择 "R" 的人可见。求其恰好看到 k 人的完整方向分配数，模 1_000_000_007。

示例：n = 3, pos = 1, k = 0，左右两人都必须不可见，中间人可任选方向，答案为 2。

约束：1 ≤ n ≤ 100000，0 ≤ pos, k ≤ n − 1。

ONE-LINE COUNT

2 × C(n − 1, k)

可见的 k 人可以分配在左右任意位置；其余人方向随之唯一确定。目标位置本人的方向不影响可见数，提供独立的 2 倍。

方向选择实验台

选择 k 个高亮人；高亮规则由左右位置决定。键盘也可操作各按钮。

测试与验证

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

核心洞察

若左侧选 a 人可见，右侧须选 k − a 人，方案为 2 × C(pos, a) × C(n − pos − 1, k − a)。对所有 a 求和，Vandermonde 恒等式将和式化为 2 × C(n − 1, k)。

边界与复杂度

k 超出 [0, n − 1] 时为 0。n = 1, k = 0 时只有目标人自己的两种方向。预处理阶乘与逆阶乘：时间 O(n)，空间 O(n)；单次组合查询 O(1)。

替代方案、追问与常见错误

  • 可枚举左侧可见人数，得到 O(k) 求和；它更直观，但不如恒等式简洁。
  • 追问：多次查询同一个 n 时复用阶乘表；不同模数需要确认模数是否为质数。
  • 别遗漏目标人的 2 种方向；别把左侧可见条件误写成 R；组合数参数非法时必须返回 0。
