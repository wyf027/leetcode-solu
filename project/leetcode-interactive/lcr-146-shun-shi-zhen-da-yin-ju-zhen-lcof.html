螺旋遍历二维数组

从左上角出发，以顺时针方向逐层走过一个二维数组，并把经过的元素按顺序收集起来。

函数签名：spiralArray(array)

题意

给定一个二维数组 array，请返回按照顺时针螺旋顺序遍历该数组得到的一维数组。

示例

输入：array = [[1,2,3],[8,9,4],[7,6,5]]

输出：[1,2,3,4,5,6,7,8,9]

约束

  • 0 <= array.length <= 100
  • 0 <= array[i].length <= 100

核心洞察

把尚未遍历的区域看作一个矩形。每完成一圈，就将该矩形向内收缩一层。

过程

  1. 维护上、下、左、右四条边界。
  2. 依次走上边、右边、下边、左边。
  3. 每走完一边就收缩对应边界，并检查是否交叉。

边界

空数组直接返回空数组；仅剩一行或一列时，需在走下边、左边前再次确认边界有效，避免重复加入元素。

复杂度

每个元素只被访问一次：时间 O(m×n)。除返回结果外，只使用常数个边界变量：额外空间 O(1)。

替代思路

也可以使用 visited 标记和方向数组模拟转向；写起来直观，但会多占 O(m×n) 空间。边界收缩法更贴合题目结构。

常见错误

  • 忘记处理空数组。
  • 下边或左边在边界已交叉时仍然遍历，导致重复。
  • 循环条件写成固定轮数，无法自然覆盖奇数行列。

参考实现

Java

class Solution {
    public int[] spiralArray(int[][] array) {
        if (array.length == 0) return new int[0];
        int top = 0, bottom = array.length - 1;
        int left = 0, right = array[0].length - 1, k = 0;
        int[] ans = new int[array.length * array[0].length];
        while (top <= bottom && left <= right) {
            for (int j = left; j <= right; j++) ans[k++] = array[top][j]; top++;
            for (int i = top; i <= bottom; i++) ans[k++] = array[i][right]; right--;
            if (top <= bottom) for (int j = right; j >= left; j--) ans[k++] = array[bottom][j]; bottom--;
            if (left <= right) for (int i = bottom; i >= top; i--) ans[k++] = array[i][left]; left++;
        } return ans;
    }
}

Python

class Solution:
    def spiralArray(self, array: List[List[int]]) -> List[int]:
        if not array: return []
        ans = []; top, bottom = 0, len(array) - 1
        left, right = 0, len(array[0]) - 1
        while top <= bottom and left <= right:
            for j in range(left, right + 1): ans.append(array[top][j])
            top += 1
            for i in range(top, bottom + 1): ans.append(array[i][right])
            right -= 1
            if top <= bottom:
                for j in range(right, left - 1, -1): ans.append(array[bottom][j])
                bottom -= 1
            if left <= right:
                for i in range(bottom, top - 1, -1): ans.append(array[i][left])
                left += 1
        return ans

C++

class Solution {
public:
    vector<int> spiralArray(vector<vector<int>>& array) {
        if (array.empty()) return {};
        vector<int> ans; int top = 0, bottom = array.size() - 1;
        int left = 0, right = array[0].size() - 1;
        while (top <= bottom && left <= right) {
            for (int j = left; j <= right; ++j) ans.push_back(array[top][j]); ++top;
            for (int i = top; i <= bottom; ++i) ans.push_back(array[i][right]); --right;
            if (top <= bottom) { for (int j = right; j >= left; --j) ans.push_back(array[bottom][j]); --bottom; }
            if (left <= right) { for (int i = bottom; i >= top; --i) ans.push_back(array[i][left]); ++left; }
        } return ans;
    }
};
