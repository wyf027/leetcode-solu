图中的最长环

Longest Cycle in a Graph

一条出路，几种归宿。沿着箭头走，能否回到出发的地方？

有向图数组建模最长环长度

01 / 读题

你需要找什么？

给定包含 n 个节点的有向图，节点编号为 0 … n − 1。每个节点最多有一条出边。数组 edges 描述图：若 edges[i] = j，就有箭头 i → j；若值为 -1，节点 i 没有出边。

返回最长有向环的长度，即环上不同节点的数量；如果不存在环，返回 -1。环是沿箭头行走后回到同一节点的闭合路径，进入环之前的路径不算入环长。

参数与返回值
longestCycle(edges: integer[]) → integer
输入数组的下标是起点，数组的值是终点；箭头不能反向走。

约束

  • n == edges.length
  • 2 ≤ n ≤ 105
  • -1 ≤ edges[i] < n
  • edges[i] != i，因此不会出现长度为 1 的自环。

02 / 官方示例

示例 1 · 有环

输入：edges = [3,3,4,2,3]
输出：3

节点 2 → 4 → 3 → 2 形成长度为 3 的环。节点 0 和 1 指向 3，但不在环内。

示例 2 · 无环

输入：edges = [2,-1,3,1]
输出：-1

路径为 0 → 2 → 3 → 1 → -1，在没有出边的节点处结束，没有形成环。

04 / 独立题解

用时间戳划出「本轮路径」

每个节点至多一条出边，所以从一个节点出发，后续方向唯一。我们沿着出边走，直到没有出边，或遇到已经访问过的节点。

核心洞察：遇到旧节点不一定成环。只有遇到本轮刚刚访问过的节点，才形成一个新发现的环。用递增时间戳记录首次访问时刻，本轮开始时记下边界 start = clock，即可区分两者。

time[u] == 0 表示未访问；time[u] ≥ start 表示在本轮访问；0 < time[u] < start 表示属于之前的轮次。时间戳从 1 开始，clock 始终表示下一个可用时间戳。

完整过程

  1. 建立长度为 n 的 time 数组，初值全为 0。设置 clock = 1，答案 ans = -1。
  2. 枚举起点 i。如果已经访问，直接跳过；否则保存本轮边界 start = clock，令 u = i。
  3. 当 u != -1 且 time[u] == 0 时，记录 time[u] = clock++，然后沿唯一出边令 u = edges[u]。
  4. 循环结束：若 u 为 -1，没有环；若 time[u] < start，汇入以前处理过的路径，没有新环。
  5. 否则 time[u] ≥ start，u 是本轮环入口，环长为 clock - time[u]，据此更新最大值。
  6. 继续枚举其余未访问节点，最终返回 ans。

示例 1 的关键时刻

从 0 开始，给路径 0 → 3 → 2 → 4 依次盖上时间戳 1, 2, 3, 4。此时 clock 为 5，下一步回到 3，其时间戳为 2，所以环长为 5 − 2 = 3。之后从 1 开始，新边界为 5；走到 3 时发现其时间戳 2 小于 5，因此不会再次计环。

为什么正确？

  1. 路径不变量：本轮新访问节点拥有连续递增的时间戳，且顺序与沿出边行走的顺序完全一致。
  2. 成环判定：若终止于本轮节点 u，本轮从 u 到当前末尾的路径再指回 u，构成有向环；若终止于 -1 或旧轮节点，本轮没有闭合回路。
  3. 长度准确：环节点时间戳恰为 time[u] … clock − 1，节点数为两端之差加一，即 clock − time[u]。
  4. 不遗漏：每个未访问节点最终都会被探索。任一尚未发现的环一旦被首次进入，沿唯一出边必定在本轮重复节点，因此会被发现。取所有发现环长的最大值即可；无环时保留 -1。

边界与复杂度

  • 全部出边为 -1：答案为 -1。
  • 长链后接短环：链不计入长度。
  • 多个分量、多个环：枚举起点，维护全局最大值。
  • 两条路径合流：旧轮时间戳阻止误报成环。
  • 无自环：官方输入中最短环为 2。
  • n 达到 105：使用迭代，避免递归栈溢出。
时间 O(n)，额外空间 O(n)。
外层枚举 n 次，内层虽然嵌套，但每个节点只会被赋时间戳一次；time 数组占 O(n)，其余变量占 O(1)。演示为回放保存快照，属于展示开销，不计入提交算法。

Java

class Solution {
    public int longestCycle(int[] edges) {
        int n = edges.length;
        int[] time = new int[n];
        int clock = 1, ans = -1;
        for (int i = 0; i < n; i++) {
            if (time[i] != 0) continue;
            int start = clock, u = i;
            while (u != -1 && time[u] == 0) {
                time[u] = clock++;
                u = edges[u];
            }
            if (u != -1 && time[u] >= start) {
                ans = Math.max(ans, clock - time[u]);
            }
        }
        return ans;
    }
}

class Solution:

替代方案

  • 拓扑剥离：统计入度，把入度为 0 的节点放入队列并依次删除；由于每个节点最多一条出边，剩下的节点全在环上。逐环计数，时间和空间均为 O(n)。需要入度数组和队列。
  • 本轮位置表：为当前路径维护节点到路径下标的映射，配合全局 visited，也能在线性总时间内求环长；时间戳把两类信息合在一个数组中。
  • 强连通分量：Tarjan / Kosaraju 可找出环所在分量，但在本题出度限制下，实现比沿唯一出边追踪更复杂。

常见错误

  • 只用 visited：把汇入旧路径当成新环。
  • 答案初值设成 0：违反无环返回 -1 的约定。
  • 用整条路径长度：把入环前的尾巴算进去。
  • 每轮重新清空全局标记：导致重复遍历，最坏 O(n²)。
  • 先访问 time[u] 再判断 u 是否为 -1：可能越界，Python 还会错误读取末项。
  • 每轮重置 clock，却仍保留旧 time：破坏轮次边界。

面试追问

如何返回最长环的节点？
记录最长环的入口 u。遍历结束后从入口沿 edges 前进，直到回到入口，收集节点即可。无环时返回空列表。
如果允许一个节点有多条出边？
唯一后继性质消失，本解法不再适用。强连通分量能定位可能有环的区域，但分量大小不等于最长简单环长度；一般有向图的最长简单环问题是 NP-hard。
能否从每个节点独立使用快慢指针？
快慢指针能检测一条轨迹上的环，但不共享处理结果时，不同起点可能重复走长链，整体最坏 O(n²)。本题要利用全局访问状态避免重复。
如果允许自环？
提交算法仍可识别长度为 1 的环；当前演示按官方约束拒绝自环输入。
