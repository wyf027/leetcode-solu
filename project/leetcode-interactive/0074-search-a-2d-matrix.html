PROBLEM MANIFEST

题意转述

给定一个 m × n 整数矩阵：每行从左到右非严格递增，并且每一行的首元素严格大于上一行的末元素。判断整数 target 是否出现在矩阵中；要求时间复杂度达到 O(log(m × n))。

官方样例 1

输入

matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3

输出

true

官方样例 2

输入

matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13

输出

false

约束：1 ≤ m,n ≤ 100；matrix[i][j] 与 target 均在 [-10⁴, 10⁴]。输入不含字符串，因此无需使用 ␠ 表示空格。

CORE INSIGHT

核心洞察

因为下一行首元素严格大于上一行末元素，按行连接所有元素后得到一个整体非递减的一维序列。无需真的复制数组：索引 k 对应 matrix[k / n][k % n]。

INVARIANT

区间不变量

每轮开始时，若目标存在，它一定在闭区间 [left, right] 内。比较中点后，可安全丢弃中点一侧；区间为空时目标不存在。

FULL PROCESS

完整过程

  1. 01

    建立虚拟索引

    范围为 0 到 m·n−1。

  2. 02

    计算安全中点

    left + (right−left)/2。

  3. 03

    映射二维坐标

    行 mid/n，列 mid%n。

  4. 04

    收缩闭区间

    直到命中或 left>right。

边界

  • 单行、单列与单元素矩阵。
  • 目标小于最小值或大于最大值。
  • 行内允许重复；跨行边界仍严格递增。
  • 使用安全中点避免整数加法溢出。

复杂度

时间
O(log(m·n))
额外空间
O(1)

替代方案取舍

两次二分（先行后列）同样达标，但代码更长。逐行扫描或右上角阶梯搜索为 O(m+n)，更适合第 240 题的不同矩阵条件，不是本题最推荐面试答案。

常见错误

  • 把本题误当成仅“行列各自有序”的第 240 题。
  • 二维映射写反：应为 mid / n 与 mid % n。
  • 闭区间循环写成 left < right，漏查最后一个位置。
  • 比较后没有使用 mid±1，导致死循环。

面试追问

  • 若矩阵行列分别递增，但跨行不连续，如何搜索？
  • 为什么虚拟展开不会产生 O(m·n) 空间？
  • 如何改写为左闭右开区间？
  • 若矩阵为空或每行长度不同，接口如何防御？
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length;
        int n = matrix[0].length;
        int left = 0, right = m * n - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            int value = matrix[mid / n][mid % n];
            if (value == target) return true;
            if (value < target) left = mid + 1;
            else right = mid - 1;
        }
        return false;
    }
}
var searchMatrix = function (matrix, target) {
  const m = matrix.length;
  const n = matrix[0].length;
  let left = 0;
  let right = m * n - 1;

  while (left <= right) {
    const mid = left + Math.floor((right - left) / 2);
    const value = matrix[Math.floor(mid / n)][mid % n];
    if (value === target) return true;
    if (value < target) left = mid + 1;
    else right = mid - 1;
  }
  return false;
};
