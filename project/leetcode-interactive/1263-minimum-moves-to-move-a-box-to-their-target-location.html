Minimum Moves to Move a Box to Their Target Location

推箱子

人在迷宫里可以自由绕行，但计分只看箱子被推动了几次。真正的难点，是在每次推动前判断玩家能否绕到箱子正确的一侧。

#1263m, n ≤ 20只计算推动次数非付费题
Problem

题意与规则

函数：minPushBox(grid)

给定一个 m × n 字符网格，玩家从 S 出发，要把唯一的箱子 B 推到目标格 T。玩家能在可通行格中上下左右移动，不能穿墙，也不能穿过箱子。

只有玩家站在箱子相反方向的相邻格、且箱子前方也是可通行格时，才能把箱子向前推动一格。返回最少推动次数；若永远无法到达目标，返回 -1。玩家普通行走不计入答案。

玩家 S可在地板、目标格中四向行走，但不能越过箱子。
箱子 B只能被推，不能拉；每推动一格，答案加一。
墙 # / 地板 . / 目标 T墙不可通过；箱子首次到达目标即完成。

按推动次数分层的 BFS

核心洞察

把一次“边”定义为推动箱子一次。状态记录箱子位置和玩家位置；从当前状态尝试四个推动方向前，先做一次玩家可达性搜索，判断玩家是否能绕到箱子背后。

为什么普通 BFS 足够

每条状态边恰好对应一次推动，权重都是 1。因此第一次弹出箱子位于目标的状态，其层数就是最少推动数；玩家在两次推动之间走多少步都不影响层数。

完整过程

  1. 扫描网格，定位玩家 S、箱子 B 和目标 T。
  2. 队列从状态 (boxRow, boxCol, playerRow, playerCol) 开始，推动数为 0。
  3. 对当前状态，以箱子为障碍，从玩家位置做一次网格 BFS，得到玩家无需推动时能到达的所有格子。
  4. 枚举箱子向四个方向移动。若箱子前方可通行，且玩家能到达箱子反方向的相邻格，则本次推动合法。
  5. 推动后，箱子进入前方格；玩家必然站到箱子的旧位置。将新状态加入下一层。
  6. 箱子到达目标时返回当前推动数；队列耗尽仍未到达则返回 -1。

正确性说明

引理 1：算法生成的每条状态转移都是合法推动。因为转移前同时检查了箱子目的格可通行，以及玩家在不穿墙、不穿箱子的条件下能到达推动站位。

引理 2：任意合法推动序列都会被算法枚举。对序列中的每一步，玩家必然能从上一步结束位置走到对应推动站位；内部可达性搜索会发现该站位，因此算法会生成相同的后继状态。

定理：BFS 按推动数从小到大访问状态。由引理 1，首次到达目标的路径合法；由引理 2，所有更短合法序列都不可能被遗漏。因此首次到达目标时的层数就是最小推动次数。

边界与复杂度

状态数 O((mn)²)每状态可达性搜索 O(mn)最坏时间 O((mn)³)空间 O((mn)²)
  • 若箱子起点就是目标，直接返回 0（一般输入字符分离，但实现可自然覆盖）。
  • 箱子被推入非目标角落后通常无法离开；无需特判，搜索会自然终止。
  • 访问标记必须包含箱子与玩家两者的位置；同一箱位下，玩家所在侧不同，后续可推方向也可能不同。

import java.util.*;

class Solution {
    private int m, n;
    private char[][] grid;
    private final int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};

    public int minPushBox(char[][] grid) {
        this.grid = grid;
        m = grid.length;
        n = grid[0].length;
        int sr = 0, sc = 0, br = 0, bc = 0, tr = 0, tc = 0;
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (grid[r][c] == 'S') { sr = r; sc = c; }
                else if (grid[r][c] == 'B') { br = r; bc = c; }
                else if (grid[r][c] == 'T') { tr = r; tc = c; }
            }
        }

        Queue<int[]> queue = new ArrayDeque<>();
        boolean[][][][] seen = new boolean[m][n][m][n];
        queue.offer(new int[]{br, bc, sr, sc});
        seen[br][bc][sr][sc] = true;
        int pushes = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            while (size-- > 0) {
                int[] state = queue.poll();
                br = state[0]; bc = state[1];
                sr = state[2]; sc = state[3];
                if (br == tr && bc == tc) return pushes;
                boolean[][] reach = reachable(sr, sc, br, bc);

                for (int[] d : dirs) {
                    int nbr = br + d[0], nbc = bc + d[1];
                    int standR = br - d[0], standC = bc - d[1];
                    if (!free(nbr, nbc) || !free(standR, standC)
                            || !reach[standR][standC]) continue;
                    if (!seen[nbr][nbc][br][bc]) {
                        seen[nbr][nbc][br][bc] = true;
                        queue.offer(new int[]{nbr, nbc, br, bc});
                    }
                }
            }
            pushes++;
        }
        return -1;
    }

    private boolean[][] reachable(int sr, int sc, int br, int bc) {
        boolean[][] seen = new boolean[m][n];
        Queue<int[]> q = new ArrayDeque<>();
        q.offer(new int[]{sr, sc});
        seen[sr][sc] = true;
        while (!q.isEmpty()) {
            int[] p = q.poll();
            for (int[] d : dirs) {
                int r = p[0] + d[0], c = p[1] + d[1];
                if (free(r, c) && !(r == br && c == bc) && !seen[r][c]) {
                    seen[r][c] = true;
                    q.offer(new int[]{r, c});
                }
            }
        }
        return seen;
    }

    private boolean free(int r, int c) {
        return r >= 0 && r < m && c >= 0 && c < n
                && grid[r][c] != '#';
    }
}

JavaScript

/**
 * @param {character[][]} grid
 * @return {number}
 */
var minPushBox = function(grid) {
    const m = grid.length, n = grid[0].length;
    const dirs = [[1,0],[-1,0],[0,1],[0,-1]];
    let player, box, target;
    for (let r = 0; r < m; r++) {
        for (let c = 0; c < n; c++) {
            if (grid[r][c] === 'S') player = [r, c];
            else if (grid[r][c] === 'B') box = [r, c];
            else if (grid[r][c] === 'T') target = [r, c];
        }
    }

    const free = (r, c) =>
        r >= 0 && r < m && c >= 0 && c < n && grid[r][c] !== '#';
    const key = (br, bc, pr, pc) => `${br},${bc},${pr},${pc}`;

    function reachable(pr, pc, br, bc) {
        const seen = Array.from({length: m}, () => Array(n).fill(false));
        const queue = [[pr, pc]];
        seen[pr][pc] = true;
        for (let head = 0; head < queue.length; head++) {
            const [r, c] = queue[head];
            for (const [dr, dc] of dirs) {
                const nr = r + dr, nc = c + dc;
                if (free(nr, nc) && !(nr === br && nc === bc) && !seen[nr][nc]) {
                    seen[nr][nc] = true;
                    queue.push([nr, nc]);
                }
            }
        }
        return seen;
    }

    let queue = [[box[0], box[1], player[0], player[1]]];
    const seen = new Set([key(...queue[0])]);
    let pushes = 0;
    while (queue.length) {
        const next = [];
        for (const [br, bc, pr, pc] of queue) {
            if (br === target[0] && bc === target[1]) return pushes;
            const reach = reachable(pr, pc, br, bc);
            for (const [dr, dc] of dirs) {
                const nbr = br + dr, nbc = bc + dc;
                const sr = br - dr, sc = bc - dc;
                if (!free(nbr, nbc) || !free(sr, sc) || !reach[sr][sc]) continue;
                const stateKey = key(nbr, nbc, br, bc);
                if (!seen.has(stateKey)) {
                    seen.add(stateKey);
                    next.push([nbr, nbc, br, bc]);
                }
            }
        }
        queue = next;
        pushes++;
    }
    return -1;
};

Python

from collections import deque
from typing import List

class Solution:
    def minPushBox(self, grid: List[List[str]]) -> int:
        m, n = len(grid), len(grid[0])
        dirs = ((1, 0), (-1, 0), (0, 1), (0, -1))
        player = box = target = None
        for r in range(m):
            for c in range(n):
                if grid[r][c] == 'S':
                    player = (r, c)
                elif grid[r][c] == 'B':
                    box = (r, c)
                elif grid[r][c] == 'T':
                    target = (r, c)

        def free(r: int, c: int) -> bool:
            return 0 <= r < m and 0 <= c < n and grid[r][c] != '#'

        def reachable(pr: int, pc: int, br: int, bc: int):
            seen = {(pr, pc)}
            queue = deque([(pr, pc)])
            while queue:
                r, c = queue.popleft()
                for dr, dc in dirs:
                    nr, nc = r + dr, c + dc
                    if (free(nr, nc) and (nr, nc) != (br, bc)
                            and (nr, nc) not in seen):
                        seen.add((nr, nc))
                        queue.append((nr, nc))
            return seen

        queue = deque([(box[0], box[1], player[0], player[1], 0)])
        seen = {(box[0], box[1], player[0], player[1])}
        while queue:
            br, bc, pr, pc, pushes = queue.popleft()
            if (br, bc) == target:
                return pushes
            walkable = reachable(pr, pc, br, bc)
            for dr, dc in dirs:
                nbr, nbc = br + dr, bc + dc
                stand = (br - dr, bc - dc)
                state = (nbr, nbc, br, bc)
                if (free(nbr, nbc) and stand in walkable and state not in seen):
                    seen.add(state)
                    queue.append((nbr, nbc, br, bc, pushes + 1))
        return -1

C++

class Solution {
    int m, n;
    vector<vector<char>>* g;
    const int dirs[4][2] = {{1,0},{-1,0},{0,1},{0,-1}};

    bool freeCell(int r, int c) {
        return r >= 0 && r < m && c >= 0 && c < n && (*g)[r][c] != '#';
    }

    vector<vector<bool>> reachable(int sr, int sc, int br, int bc) {
        vector<vector<bool>> seen(m, vector<bool>(n, false));
        queue<pair<int,int>> q;
        q.push({sr, sc});
        seen[sr][sc] = true;
        while (!q.empty()) {
            auto [r, c] = q.front(); q.pop();
            for (auto &d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (freeCell(nr, nc) && !(nr == br && nc == bc) && !seen[nr][nc]) {
                    seen[nr][nc] = true;
                    q.push({nr, nc});
                }
            }
        }
        return seen;
    }

public:
    int minPushBox(vector<vector<char>>& grid) {
        g = &grid; m = grid.size(); n = grid[0].size();
        int sr = 0, sc = 0, br = 0, bc = 0, tr = 0, tc = 0;
        for (int r = 0; r < m; ++r) for (int c = 0; c < n; ++c) {
            if (grid[r][c] == 'S') sr = r, sc = c;
            else if (grid[r][c] == 'B') br = r, bc = c;
            else if (grid[r][c] == 'T') tr = r, tc = c;
        }

        using State = array<int, 4>;
        queue<State> q;
        set<State> seen;
        q.push({br, bc, sr, sc});
        seen.insert({br, bc, sr, sc});
        int pushes = 0;

        while (!q.empty()) {
            int size = q.size();
            while (size--) {
                auto [boxR, boxC, playerR, playerC] = q.front(); q.pop();
                if (boxR == tr && boxC == tc) return pushes;
                auto walkable = reachable(playerR, playerC, boxR, boxC);
                for (auto &d : dirs) {
                    int nbr = boxR + d[0], nbc = boxC + d[1];
                    int standR = boxR - d[0], standC = boxC - d[1];
                    if (!freeCell(nbr, nbc) || !freeCell(standR, standC)
                            || !walkable[standR][standC]) continue;
                    State next{nbr, nbc, boxR, boxC};
                    if (seen.insert(next).second) q.push(next);
                }
            }
            ++pushes;
        }
        return -1;
    }
};

替代方案

  • 0-1 BFS：把玩家每走一步视为权重 0、推动视为权重 1，在完整状态图上搜索。概念统一，但状态更多。
  • Dijkstra：同样能按推动代价求最短路，但所有有效推动权重都相同，普通 BFS 更直接。
  • 箱子位置 + 玩家所在连通分量：可压缩玩家位置，不过实现与去重逻辑更复杂。

面试追问

  • 为什么访问状态不能只记箱子位置？
  • 若同时最小化推动数和行走步数，状态与队列应怎样调整？
  • 如何利用“非目标角落”死锁剪枝？
  • 有多个箱子时，状态空间为什么会急剧膨胀？

常见错误

  • 把玩家行走步数也累计进答案，求成了普通最短路。
  • 只判断箱子前方为空，却忘记验证玩家能否到达箱子背后。
  • 推动后仍沿用旧玩家位置；实际上玩家会站在箱子的旧位置。
  • 可达性 BFS 没把箱子当作障碍，导致玩家“穿箱”。
  • 只用箱子位置去重，错误合并玩家位于箱子不同侧的状态。
