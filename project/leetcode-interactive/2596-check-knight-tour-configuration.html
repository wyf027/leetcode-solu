检查骑士巡视方案

棋盘里写的不是坐标，而是访问顺序。沿着数字从 0 走到 n² − 1，判断这串轨迹能否由骑士一步步走出。

题号 2596 难度 Medium 非付费题

Problem

题意与约束

函数：checkValidGrid(grid)

给定一个 n × n 整数矩阵 grid。矩阵由 [0, n² − 1] 中互不相同的整数组成，grid[row][col] 表示骑士第几次访问格子 (row, col)，访问编号从 0 开始。

有效巡视必须从左上角出发，棋盘上的每个格子恰好访问一次；相邻两次访问之间必须是骑士移动：一个方向跨 2 格，另一个方向跨 1 格。若矩阵描述了有效巡视，返回 true，否则返回 false。

约束

  • n == grid.length == grid[i].length
  • 3 <= n <= 7
  • 0 <= grid[row][col] < n * n
  • grid 中的所有整数互不相同
参数
grid: integer[][]
返回
boolean
合法位移
(±1, ±2) 或 (±2, ±1)
起点
grid[0][0] 必须为 0

Walkthrough

按访问编号还原路径

O(n²) 时间 · O(n²) 空间

核心洞察

矩阵是“坐标 → 访问编号”的映射；检查相邻编号时，更方便的形式是“访问编号 → 坐标”。先把每个编号的位置记录到 pos，再依次比较 pos[k - 1] 与 pos[k]。

两个坐标差的绝对值若分别为 1 和 2，就是骑士步；等价地，|Δrow| × |Δcol| == 2。

完整过程

  1. 若左上角不是 0，直接返回 false。
  2. 扫描棋盘，把编号 grid[r][c] 的位置存为 (r, c)。
  3. 从编号 1 到 n² − 1，检查它与前一编号的位置差。
  4. 任一步不合法就返回 false；全部合法则返回 true。

正确性证明

起点：第一步检查保证编号 0 位于左上角。

覆盖：题目保证矩阵恰好包含 0..n²−1 且互不相同，所以 pos 中每个访问编号都有且只有一个坐标。

移动：循环检查每一对连续编号；乘积为 2 当且仅当两个绝对坐标差是 1 和 2，因此每次移动都是骑士步。三点合在一起，算法返回 true 当且仅当给定方案是有效巡视。

边界与复杂度

  • 左上角不为 0：立即失败。
  • 最后一个编号无需再向外移动。
  • 输入的方阵、范围、唯一性由题目约束保证。
  • 建表和检查各扫描至多 n² 项，时间 O(n²)；位置表空间 O(n²)。

替代方案

可以对每个目标编号重新扫描整个棋盘来找坐标，只用常数额外空间，但总时间会变为 O(n⁴)。也可以从 0 出发尝试八个方向查找下一个编号，仍是 O(n²)，但分支更多；位置表更直接。

常见错误

  • 只检查相邻格子的数值，而没有按访问编号找坐标。
  • 忘记验证起点必须是左上角。
  • 把骑士步误写成曼哈顿距离为 3，导致 (0,3) 也被接受。
  • 用有符号坐标差判断，漏掉反方向移动。

面试追问

  • 如果不保证数字唯一或范围合法，怎样增加输入校验？
  • 能否做到 O(1) 额外空间？代价是什么？
  • 如果输入直接给出坐标序列，算法还能省掉哪一步？

class Solution {
    public boolean checkValidGrid(int[][] grid) {
        int n = grid.length;
        if (grid[0][0] != 0) return false;

        int[][] pos = new int[n * n][2];
        for (int r = 0; r < n; r++) {
            for (int c = 0; c < n; c++) {
                pos[grid[r][c]] = new int[] {r, c};
            }
        }

        for (int k = 1; k < n * n; k++) {
            int dr = Math.abs(pos[k][0] - pos[k - 1][0]);
            int dc = Math.abs(pos[k][1] - pos[k - 1][1]);
            if (dr * dc != 2) return false;
        }
        return true;
    }
}

var checkValidGrid = function(grid) {
    const n = grid.length;
    if (grid[0][0] !== 0) return false;

    const pos = Array.from({ length: n * n }, () => [0, 0]);
    for (let r = 0; r < n; r++) {
        for (let c = 0; c < n; c++) {
            pos[grid[r][c]] = [r, c];
        }
    }

    for (let k = 1; k < n * n; k++) {
        const dr = Math.abs(pos[k][0] - pos[k - 1][0]);
        const dc = Math.abs(pos[k][1] - pos[k - 1][1]);
        if (dr * dc !== 2) return false;
    }
    return true;
};

class Solution:
    def checkValidGrid(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        if grid[0][0] != 0:
            return False

        pos = [None] * (n * n)
        for r in range(n):
            for c in range(n):
                pos[grid[r][c]] = (r, c)

        for k in range(1, n * n):
            dr = abs(pos[k][0] - pos[k - 1][0])
            dc = abs(pos[k][1] - pos[k - 1][1])
            if dr * dc != 2:
                return False
        return True

class Solution {
public:
    bool checkValidGrid(vector<vector<int>>& grid) {
        int n = grid.size();
        if (grid[0][0] != 0) return false;

        vector<pair<int, int>> pos(n * n);
        for (int r = 0; r < n; ++r) {
            for (int c = 0; c < n; ++c) {
                pos[grid[r][c]] = {r, c};
            }
        }

        for (int k = 1; k < n * n; ++k) {
            int dr = abs(pos[k].first - pos[k - 1].first);
            int dc = abs(pos[k].second - pos[k - 1].second);
            if (dr * dc != 2) return false;
        }
        return true;
    }
};
