    题意与过程

    给定小写串 s 和 k。当前串中两处相同字符 s[i]、s[j]（i < j）在 j - i ≤ k 时称为 close。只要还有 close pair，就选最小 i，再选最小 j，删除右侧 s[j]。

    1. 扫描原串，维护已经幸存的 ans。
    2. 对新字符 c，只查看 ans 中 c 的最后位置。
    3. 距离 ≤ k：它就是必须合并的右字符，跳过。
    4. 否则附到 ans，更新最后位置。

    aabca, k=2：第二个 a 被跳过，ans 为 abca；两个 a 的距离是 3，停止合并。

    关键洞察

    扫描到一个字符时，ans 已等于此前所有强制删除后的字符串。相同字符最近的一次幸存位置最靠右；如果它超过 k，更早的只会更远。若它在 k 内，删当前字符恰好满足题目的 tie-break。

    O(n)时间
    O(26)额外表
    稳定保留顺序

    边界

    • 长度 1：直接返回。
    • k=1：只吞掉相邻同字符。
    • 连续重复：第一个保留，后续会因重编号继续被吞。
    • 不要用原始下标算距离；删除后下标已改变。

    隐藏题解：四语言同一不变量

    class Solution:
    def mergeCharacters(self, s, k):
        last, ans = [-1] * 26, []
        for c in s:
            p = ord(c) - ord('a')
            if last[p] != -1 and len(ans) - last[p] <= k: continue
            last[p] = len(ans); ans.append(c)
        return ''.join(ans)

    替代方案与常见错误

    暴力模拟

    每次枚举 pair、删除再重扫，移动字符会造成最坏 O(n²)，在 n ≤ 5×10⁵ 时不可取。

    错误 1：只比较上一字符

    close 是任意相同字符；abca 的两端 a 说明不能只看栈顶。

    错误 2：错误更新 last

    被删除字符不能覆盖 last；它必须仍指向幸存字符。

    追问

    • 字符集更大？以 HashMap 替换 26 长数组。
    • 输出删除序列？skip 时记录扫描次序和 ans 下标；原始索引另需顺序统计结构。
    • k 会变化？不能直接复用单次扫描，判定依赖删后长度。
    • 为何只看最后一次？它离当前最近；若它不 close，其他也不会。
