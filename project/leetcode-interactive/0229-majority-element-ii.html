229. 求众数 II Medium

超过 ⌊n/3⌋ 的数至多只有两个。保留两个候选席位；每当第三种不同数字出现时，让三种数字各抵消一次。

?题意

给定长度为 n 的整数数组 nums，找出所有出现次数严格大于 ⌊n / 3⌋ 的元素。

官方样例 1

nums = [3,2,3]
输出：[3]

官方样例 2

nums = [1]
输出：[1]

官方样例 3

nums = [1,2]
输出：[1,2]

约束：1 ≤ nums.length ≤ 5 × 10⁴，−10⁹ ≤ nums[i] ≤ 10⁹。追问：能否在线性时间、O(1) 额外空间内解决？

λ题解：推广的 Boyer–Moore 投票

核心洞察

如果有 3 个不同元素都各拿走一次票，它们不可能都属于出现次数大于 n/3 的元素；真正众数在这种三元抵消后仍会存活。因而仅需两个候选与两个计数器。

一般化：找出现次数大于 n/k 的元素时，保留 k−1 个候选席位。

完整过程

  1. 若当前值等于候选 A/B，增加其票数。
  2. 否则若 A/B 票数为 0，填入当前值。
  3. 否则两个票数同时减一（抵消三种不同值）。
  4. 重新扫描原数组，验证 A、B 的真实次数是否超过 n/3。

边界与复杂度

  • 长度 1、2：可能同时返回两个数。
  • 候选不一定是真众数，第二轮不可省略。
  • 负数、很大整数对算法无影响。

时间：O(n)，两次扫描；额外空间：O(1)。

替代方案、追问与常见错误

替代：哈希计数易写但 O(n) 空间；排序后计数 O(n log n)。
追问：为何至多两个？三个元素若都大于 n/3，总出现数会超过 n。
错误：漏掉验证轮；候选 A/B 相同导致重复输出；在比较候选前先填空席位。

import java.util.*;
class Solution { public List<Integer> majorityElement(int[] nums) {
    int a=0,b=1,ca=0,cb=0; for(int x:nums){
        if(x==a) ca++; else if(x==b) cb++; else if(ca==0){a=x;ca=1;}
        else if(cb==0){b=x;cb=1;} else {ca--;cb--;}
    } ca=0;cb=0; for(int x:nums){if(x==a)ca++;else if(x==b)cb++;}
    List<Integer> ans=new ArrayList<>(); if(ca>nums.length/3)ans.add(a); if(cb>nums.length/3)ans.add(b); return ans;
} }
