最长同值路径

在二叉树里寻找一条“颜色不变”的路。路径不必穿过根节点，答案按边计数——先理解任务，再通过后序扫描器观察每个节点如何被处理。

输入root: TreeNode
输出integer
路径长度边的数量

Problem

题目描述

给定一棵二叉树的根节点 root，返回一条最长路径的长度，要求路径上的每个节点都具有相同的值。这条路径可以经过根节点，也可以完全位于某棵子树中。

计数口径：两个节点之间的路径长度等于它们之间的边数。因此，单个节点形成的路径长度为 0。

示例 1

输入：root = [5,4,5,1,1,null,5]
输出：2

值为 5 的三个节点首尾相连，共经过 2 条边。

示例 2

输入：root = [1,4,5,4,4,null,5]
输出：2

最长路径由三个值为 4 的节点组成，共经过 2 条边。

约束

  • 树的节点数在 [0, 104] 范围内。
  • -1000 <= Node.val <= 1000。
  • 树的深度不超过 1000。

Full walkthrough

题解：后序遍历 + 树形 DP

核心洞察

经过某个节点的同值路径可能同时使用它的左、右两条分支；但向父节点汇报时只能选择其中较长的一条，否则就会产生分叉，不再是一条简单路径。

当前候选 = leftArm + rightArm；向上返回 = max(leftArm, rightArm)

状态定义

令 dfs(node) 表示：从 node 出发向下、且所有节点值等于 node.val 的最长单链边数。空节点返回 0。

完整过程

  1. 后序计算左右孩子各自能向下延伸的长度。
  2. 若孩子值与当前节点不同，对应分支清零；相同则在孩子结果上加 1 条边。
  3. 用两侧可延伸长度之和更新全局答案。
  4. 向父节点只返回两侧中的较大值。

为什么必须后序

当前节点是否能接上孩子，不仅取决于值是否相同，还取决于孩子下方已经形成的最长单链。因此要先得到两个子树的结果，再处理当前节点。

正确性证明

引理：dfs(node) 返回的确实是从当前节点向下的最长同值单链边数。对叶子成立，因为返回 0。假设左右孩子的返回值正确；只有与当前节点同值的孩子分支可以连接，加上父子之间的一条边后，取两者最大值正好得到可向上延续的最长单链。

全局最优：任意一条最长同值路径都有唯一的最高节点。它在该节点处由至多一条左分支与至多一条右分支组成，因此会在处理该节点时以 leftArm + rightArm 被枚举并更新。算法不会遗漏最优路径，也不会计入值不同的边，所以最终答案正确。

边界情况

  • 空树：没有边，答案为 0。
  • 单节点：同样返回 0，而不是 1。
  • 所有值不同：每条分支都被清零。
  • 所有值相同：退化为求树的直径。
  • 极深树：递归深度可到 1000，语言栈限制需要留意。

复杂度

时间：O(n)，每个节点只处理一次。

空间：O(h)，递归栈由树高 h 决定；最坏为 O(n)，平衡树为 O(log n)。

四语言完整代码

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int answer = 0;

    public int longestUnivaluePath(TreeNode root) {
        dfs(root);
        return answer;
    }

    private int dfs(TreeNode node) {
        if (node == null) return 0;

        int leftDown = dfs(node.left);
        int rightDown = dfs(node.right);

        int leftArm = 0;
        int rightArm = 0;
        if (node.left != null && node.left.val == node.val) {
            leftArm = leftDown + 1;
        }
        if (node.right != null && node.right.val == node.val) {
            rightArm = rightDown + 1;
        }

        answer = Math.max(answer, leftArm + rightArm);
        return Math.max(leftArm, rightArm);
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var longestUnivaluePath = function(root) {
    let answer = 0;

    function dfs(node) {
        if (node === null) return 0;

        const leftDown = dfs(node.left);
        const rightDown = dfs(node.right);
        const leftArm = node.left !== null && node.left.val === node.val
            ? leftDown + 1
            : 0;
        const rightArm = node.right !== null && node.right.val === node.val
            ? rightDown + 1
            : 0;

        answer = Math.max(answer, leftArm + rightArm);
        return Math.max(leftArm, rightArm);
    }

    dfs(root);
    return answer;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def longestUnivaluePath(self, root: Optional[TreeNode]) -> int:
        answer = 0

        def dfs(node: Optional[TreeNode]) -> int:
            nonlocal answer
            if node is None:
                return 0

            left_down = dfs(node.left)
            right_down = dfs(node.right)
            left_arm = (
                left_down + 1
                if node.left is not None and node.left.val == node.val
                else 0
            )
            right_arm = (
                right_down + 1
                if node.right is not None and node.right.val == node.val
                else 0
            )

            answer = max(answer, left_arm + right_arm)
            return max(left_arm, right_arm)

        dfs(root)
        return answer
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    int answer = 0;

    int dfs(TreeNode* node) {
        if (node == nullptr) return 0;

        int leftDown = dfs(node->left);
        int rightDown = dfs(node->right);
        int leftArm = 0;
        int rightArm = 0;

        if (node->left != nullptr && node->left->val == node->val) {
            leftArm = leftDown + 1;
        }
        if (node->right != nullptr && node->right->val == node->val) {
            rightArm = rightDown + 1;
        }

        answer = std::max(answer, leftArm + rightArm);
        return std::max(leftArm, rightArm);
    }

public:
    int longestUnivaluePath(TreeNode* root) {
        dfs(root);
        return answer;
    }
};

替代方案

迭代后序：使用显式栈与映射保存每个节点的向下结果，同样能做到 O(n)，并避开语言递归栈限制，但代码更长。

朴素起点枚举：从每个节点出发搜索同值路径容易重复遍历子树，最坏可退化为 O(n²)，不适合本题规模。

面试追问

  • 如果要返回具体路径节点，状态里还要记录什么？
  • 如何改写为完全迭代版本？
  • 若边带权，路径长度改为权重和，转移如何变化？
  • 若允许路径上最多出现两个不同值，当前状态为何不够？

常见错误

  • 把节点数当成路径长度，导致答案多 1。
  • 向父节点返回 leftArm + rightArm；这个和只能更新全局答案，不能继续向上。
  • 只从根节点寻找，遗漏完全位于子树内部的最优路径。
  • 没有先比较父子节点值就直接累加孩子结果。
  • 把全局答案写成局部变量，或在递归过程中重复清零。
