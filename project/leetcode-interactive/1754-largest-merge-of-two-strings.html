LeetCode 1754 · String duel

构造字典序最大的
合并字符串Largest Merge Of Two Strings

两条字符流，只能从队首取字符。每一步都像一次选择，而最终答案由最早出现的差异决定。

MEDIUM贪心双指针字符串非付费题
01 · Problem

题目

给定两个字符串 word1 与 word2，把它们交错合并，但必须保持每个字符串内部的原始顺序。

初始时 merge 为空。当两个单词中至少一个非空时，反复选择以下一种操作：

  1. 1若 word1 非空，取走它的第一个字符并追加到 merge 末尾。
  2. 2若 word2 非空，取走它的第一个字符并追加到 merge 末尾。
返回所有合法合并结果中字典序最大的字符串。等长字符串按从左到右第一个不同字符比较；该位置字符更大的字符串，字典序更大。

约束

  • 1 ≤ word1.length, word2.length ≤ 3000
  • word1 和 word2 只含小写英文字母。
  • 函数：largestMerge(word1, word2)
  • 返回值：string

官方示例 01

输入word1 = "cabaa", word2 = "bcaaa"输出"cbcabaaaaa"

一种最优取法依次得到 c → cb → cbc → cbca → cbcab，最后把剩余的 5 个 a 追加到末尾。

官方示例 02

输入word1 = "abcabc", word2 = "abdcaba"输出"abdcabcabcaba"

03 · Solution

让剩余后缀决胜

Greedy · Two Pointers · Suffix comparison

核心洞察

如果两个队首字符不同，显然应取较大的那个。真正关键的是队首相同：此时无论取哪一个，当前追加的字符都一样，差异会推迟到后续。

因此每一步直接比较两个尚未使用的完整后缀：较大后缀的第一个字符先进入答案。

若 word1[i:] > word2[j:]，取 word1[i]；否则取 word2[j]。一个字符串耗尽后，追加另一个的剩余部分。

复杂度

时间O(L²)L = n + m；朴素后缀比较最坏为线性，最多比较 L 次。
空间O(L)用于返回结果；除输出外，双指针只需 O(1) 额外状态。

部分语言若在循环中创建切片，会产生额外临时对象；下方 Java / JavaScript 代码用索引比较避免切片。

完整过程

  1. 令双指针 i = 0、j = 0，答案为空。
  2. 当两个字符串都还有字符时，从 i、j 开始逐字符比较剩余后缀。
  3. 把字典序更大后缀的首字符加入答案，并只移动对应指针。
  4. 循环结束后，直接追加尚未耗尽的后缀。

边界情况

  • 一个后缀是另一个的前缀：较长后缀更大。
  • 两个后缀完全相同：取任意一侧都不影响最终字符串。
  • 字符全部相同：任意交错的结果相同。
  • 某个字符串刚好耗尽：直接追加另一侧剩余字符。

正确性证明

引理：在状态 (i, j)，若 word1[i:] 大于 word2[j:]，则存在一个最优合并以 word1[i] 开始。

理由：若队首不同，选择较大字符会在当前位立即胜出。若队首相同，沿两后缀跳过相同前缀，首个不同字符较大的一侧应当更早出现；若一侧先结束，则另一侧较长并应先取。把较大后缀的首字符先放入不会让最早差异变小。

归纳：该选择固定了最优答案的首字符，问题缩小为对应指针前进后的同类子问题。重复引理直至某侧耗尽，再追加剩余串，所得合并在每个最早可区分位置都不小于其他合法合并，故为字典序最大。

JavaLeetCode 可提交
class Solution {
    public String largestMerge(String word1, String word2) {
        int i = 0, j = 0;
        StringBuilder ans = new StringBuilder(word1.length() + word2.length());

        while (i < word1.length() && j < word2.length()) {
            if (greater(word1, i, word2, j)) {
                ans.append(word1.charAt(i++));
            } else {
                ans.append(word2.charAt(j++));
            }
        }
        ans.append(word1, i, word1.length());
        ans.append(word2, j, word2.length());
        return ans.toString();
    }

    private boolean greater(String a, int i, String b, int j) {
        while (i < a.length() && j < b.length()
                && a.charAt(i) == b.charAt(j)) {
            i++;
            j++;
        }
        if (j == b.length()) return true;
        if (i == a.length()) return false;
        return a.charAt(i) > b.charAt(j);
    }
}
JavaScriptLeetCode 可提交
/**
 * @param {string} word1
 * @param {string} word2
 * @return {string}
 */
var largestMerge = function(word1, word2) {
    let i = 0;
    let j = 0;
    const answer = [];

    const greater = (a, startA, b, startB) => {
        let x = startA;
        let y = startB;
        while (x < a.length && y < b.length && a[x] === b[y]) {
            x++;
            y++;
        }
        if (y === b.length) return true;
        if (x === a.length) return false;
        return a[x] > b[y];
    };

    while (i < word1.length && j < word2.length) {
        if (greater(word1, i, word2, j)) {
            answer.push(word1[i++]);
        } else {
            answer.push(word2[j++]);
        }
    }
    answer.push(word1.slice(i), word2.slice(j));
    return answer.join('');
};

class Solution:
    def largestMerge(self, word1: str, word2: str) -> str:
        i = j = 0
        answer = []

        while i < len(word1) and j < len(word2):
            if word1[i:] > word2[j:]:
                answer.append(word1[i])
                i += 1
            else:
                answer.append(word2[j])
                j += 1

        answer.append(word1[i:])
        answer.append(word2[j:])
        return "".join(answer)
C++LeetCode 可提交
class Solution {
public:
    string largestMerge(string word1, string word2) {
        int i = 0, j = 0;
        string answer;
        answer.reserve(word1.size() + word2.size());

        while (i < word1.size() && j < word2.size()) {
            if (word1.compare(i, string::npos, word2, j, string::npos) > 0) {
                answer.push_back(word1[i++]);
            } else {
                answer.push_back(word2[j++]);
            }
        }
        answer.append(word1, i, string::npos);
        answer.append(word2, j, string::npos);
        return answer;
    }
};

替代方案

朴素搜索 / 动态规划：枚举每一步从哪边取会形成指数级分支；即使记忆化状态，也需要存储或比较很长的最优字符串，代价更高。

后缀数组 / LCP：把两个字符串用分隔符合并，预处理后缀排名或最长公共前缀，可把每次比较降到 O(1)，达到接近 O(L log L) 或 O(L) 的总复杂度，但实现明显更复杂。本题长度上限 3000，直接比较足够清晰。

常见错误

  • 队首相同时固定取 word1，忽略更深位置的差异。
  • 只比较下一个字符，而不是比较完整剩余后缀。
  • 一侧耗尽后忘记追加另一侧全部剩余字符。
  • 用严格大于比较时没有处理“后缀完全相同”；虽然任选均可，但循环边界必须安全。
  • 在 Java 中频繁 substring 造成大量临时字符串。

面试追问

  1. 为什么比较后缀，而不是只向后看一个字符？
  2. 两个剩余后缀完全相同时，从哪边取是否有区别？
  3. 如何用后缀数组、后缀排名或 rolling hash 优化比较？
  4. 若字符来自 Unicode，代码中的比较语义要如何定义？
  5. 能否在线输出答案，而不保存完整结果？

一句话复盘

字典序目标关注的是最早出现的差异。队首相等时，谁的未来更大，谁的当前字符就应先进入答案。

这也是许多“保持内部顺序、最大化合并序列”问题的通用贪心信号。
