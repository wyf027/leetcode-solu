LeetCode 2301

替换字符后匹配

Match Substring After Replacement

同一段字符，可以有不同的样子。
在有方向、仅一次的替换规则下，寻找一段连续匹配。

字符串哈希表免费题官方题目 ↗

01 / 题目与规则

给定字符串 s、sub 和二维字符数组 mappings。每个二元组 [old, new] 允许把 sub 中任意一个对应的 old 字符改成 new。不同位置可以独立决定是否替换，但每个位置最多替换一次。

判断能否通过零次或若干次这样的替换，让 sub 成为 s 中某一段连续、非空的子字符串，返回布尔值。原串 s 不作修改，大小写有区别。

约束

  • 1 ≤ sub.length ≤ s.length ≤ 5000
  • 0 ≤ mappings.length ≤ 1000
  • mappings[i].length == 2，且 oldᵢ != newᵢ。
  • s、sub 仅由大写字母、小写字母和数字组成。
  • 每个 oldᵢ、newᵢ 也是大写字母、小写字母或数字。

官方示例

官方示例 1

s = "fool3e7bar", sub = "leet", mappings = [["e","3"],["t","7"],["t","8"]]

输出：true

将第一个 e 改成 3、t 改成 7，得到连续片段 l3e7。

官方示例 2

s = "fooleetbar", sub = "f00l", mappings = [["o","0"]]

输出：false

只允许 o → 0，不能把 sub 中的 0 反向替换成 o。

官方示例 3

s = "Fool33tbaR", sub = "leetd", mappings = [["e","3"],["t","7"],["t","8"],["d","b"],["p","b"]]

输出：true

两个 e 各自替换为 3，d 替换为 b，得到 l33tb。

04 / 独立题解

先尝试提出自己的判定条件，再展开完整分析与实现。

核心洞察：每个位置只需判断一次直接关系

令 allow[a][b] 表示映射表中存在直接规则 a → b。某个窗口内的位置能够对应，当且仅当 sub[j] == s[i+j]，或 allow[sub[j]][s[i+j]] 为真。相同字符可不替换；每个位置独立选择规则，无需构造所有替换后的字符串。

完整过程

  1. 建立 128 × 128 的布尔表，先全设为 false，只填入已给出的有向映射。128 覆盖题目的 ASCII 字符域。
  2. 设 n = s.length、m = sub.length。依次尝试起点 i = 0 ... n-m。
  3. 从 j = 0 向右比较。相同或存在直接映射则继续；否则立即放弃当前窗口。
  4. 若某窗口全部 m 个位置可对应，返回 true。所有窗口均失败才返回 false。

以示例 1 为例：起点 0、1、2 都在首字符失败。起点 3 对齐 l3e7：l=l 保留，e→3 替换，e=e 保留，t→7 替换，全部满足条件。

正确性证明

单位置充要条件：一次也不替换时只能保留原字符；替换一次时只能沿输入中的直接边。因此判定条件恰好列举了该位置所有合法结果。

固定窗口：位置之间没有共享次数限制或相互影响。若每个位置可对应，可以逐一执行相应的零次或一次操作，得到整个窗口；若有一个位置不可对应，这个窗口一定无法得到。

全局结论：长度为 m 的子字符串起点恰好是 0 到 n−m，循环逐一覆盖。算法返回 true 必有合法窗口；存在合法窗口时算法也一定会找到。

复杂度

令 K 为映射数量，A 为表的字符容量（实现中 A = 128）。时间 O(A² + K + (n-m+1)m)，额外空间 O(A²)。固定字符集下可简写为时间 O(K + nm)、空间 O(1)。

不会复制每个窗口，也不生成指数数量的替换候选。最坏比较次数在 n = 5000 时最多约 625 万；这里只做理论分析，未执行性能测量。

边界

  • mappings 为空：退化为精确子串查找。
  • m = n：仅比较一个窗口；m = 1：逐字符查找。
  • 同一规则可用于多个位置；重复规则写入同一表项即可。
  • 最后起点 n−m 要包含；题目保证 m ≤ n 且字符串非空。

替代方案与取舍

  • 哈希集合：用字符对集合作直接映射表，额外空间 O(K)，查询平均 O(1)；固定 ASCII 布尔表更直观。
  • 位并行 Shift-And：为每个文本字符预计算可接受它的模式位置位图。扫描 s 时更新 D = ((D << 1) | 1) & mask[c]，若第 m−1 位为 1 则找到匹配。多机器字实现可将扫描降为 O(n⌈m/w⌉)，但位图构造与多字运算更复杂。
  • 不直接套普通 KMP：允许匹配关系不具备普通相等关系的对称性和传递性，简单把等号替换为 allow 检查会破坏失败跳转的依据。

常见错误

  • 把 allow[a][b] 同时写到 allow[b][a]，错误地把规则当成双向。
  • 求传递闭包，允许 a→b→c，违反每个位置最多一次替换。
  • 修改 s，或把 sub 在一个失败窗口中的修改带到下一个窗口。
  • 要求同一字母的所有出现都用同一替换；实际是每个位置独立。
  • 忘记原字符可以保留，或把子序列误当成连续子字符串。

面试追问

若每个位置允许无限次替换？此时才需要计算有向可达性，再用同样的窗口比较。

若全局只能替换 B 次？对每个可行窗口统计不同字符的位置数，判断是否不超过 B。

若要返回一个见证？记录成功起点 i，并列出窗口内所有不相等位置及其使用的直接映射，不必修改原输入。

采用官方函数签名；以下代码尚未编译或执行。Python 为 Python 3。

Java

class Solution {
    public boolean matchReplacement(String s, String sub, char[][] mappings) {
        boolean[][] allowed = new boolean[128][128];
        for (char[] p : mappings) allowed[p[0]][p[1]] = true;
        int n = s.length(), m = sub.length();
        for (int i = 0; i <= n - m; i++) {
            int j = 0;
            while (j < m) {
                char a = sub.charAt(j), b = s.charAt(i + j);
                if (a != b && !allowed[a][b]) break;
                j++;
            }
            if (j == m) return true;
        }
        return false;
    }
}

/**
 * @param {string} s
 * @param {string} sub
 * @param {character[][]} mappings
 * @return {boolean}
 */
var matchReplacement = function(s, sub, mappings) {
    const allowed = Array.from({ length: 128 }, () => new Uint8Array(128));
    for (const [a, b] of mappings) allowed[a.charCodeAt(0)][b.charCodeAt(0)] = 1;
    const n = s.length, m = sub.length;
    for (let i = 0; i <= n - m; i++) {
        let j = 0;
        while (j < m) {
            const a = sub.charCodeAt(j), b = s.charCodeAt(i + j);
            if (a !== b && !allowed[a][b]) break;
            j++;
        }
        if (j === m) return true;
    }
    return false;
};

Python

from typing import List

class Solution:
    def matchReplacement(self, s: str, sub: str,
                         mappings: List[List[str]]) -> bool:
        allowed = [[False] * 128 for _ in range(128)]
        for a, b in mappings:
            allowed[ord(a)][ord(b)] = True
        n, m = len(s), len(sub)
        for i in range(n - m + 1):
            for j in range(m):
                a, b = sub[j], s[i + j]
                if a != b and not allowed[ord(a)][ord(b)]:
                    break
            else:
                return True
        return False

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    bool matchReplacement(string s, string sub, vector<vector<char>>& mappings) {
        bool allowed[128][128] = {};
        for (const auto& p : mappings)
            allowed[static_cast<unsigned char>(p[0])]
                   [static_cast<unsigned char>(p[1])] = true;
        int n = static_cast<int>(s.size());
        int m = static_cast<int>(sub.size());
        for (int i = 0; i <= n - m; ++i) {
            int j = 0;
            while (j < m) {
                unsigned char a = sub[j], b = s[i + j];
                if (a != b && !allowed[a][b]) break;
                ++j;
            }
            if (j == m) return true;
        }
        return false;
    }
};
