最小移动总距离

HARD免费题机器人 × 工厂

一条数轴，有限的维修名额。如何让所有机器人都停在可维修的工厂，并让它们走过的路程之和最小？

01 / 读懂任务

选择启动时机与初始方向

整数数组 robot 记录各机器人的坐标。二维数组 factory 中的每个元素为 [position, limit]，分别表示工厂坐标及最多可维修的机器人数量。

机器人起初都损坏。你可以在任意时刻启动部分机器人，为它们设置向左或向右的初始移动方向；启动后持续沿该方向移动，遇到尚有名额的工厂就会被维修并停止。

  • 机器人速度相同，彼此相遇时直接穿过，不发生碰撞。
  • 满额工厂不会阻挡机器人。
  • 机器人之间坐标互异，工厂之间坐标也互异；机器人与工厂可以重合。
  • 从 x 到 y 的移动距离为 |y − x|。

返回修好所有机器人的最小总移动距离。输入保证存在可行方案。

输入边界

约束

  • 1 ≤ robot.length ≤ 100
  • 1 ≤ factory.length ≤ 100
  • factory[j].length = 2
  • −10⁹ ≤ robot[i], positionⱼ ≤ 10⁹
  • 0 ≤ limitⱼ ≤ robot.length
  • 所有机器人均能被修理。
先自己想一想：最近的工厂只有一个维修名额时，应该让谁使用它？

04 / 独立题解

排序后，每家工厂接收一个连续区间

核心洞察：交叉分配可以解开

设机器人坐标 a ≤ b，工厂坐标 x ≤ y。总有 |a−x| + |b−y| ≤ |a−y| + |b−x|。若较左的机器人去了较右工厂，而较右机器人去了较左工厂，交换它们的目标不会增加总距离，也不会改变两家工厂的占用数量。

不断消除这种逆序，就得到一种最优方案：按坐标排序后，每家工厂负责机器人序列中的连续一段，也可以不接收机器人。于是只需决定每家工厂接收多少个机器人。

状态、转移与完整过程

  1. 分别将机器人与工厂按坐标升序排序。
  2. 令 dp[j][i] 表示使用前 j 家工厂修好前 i 个机器人的最小距离。
  3. 初始化 dp[0][0] = 0；没有工厂时无法维修正数个机器人，其余为正无穷。
  4. 处理第 j 家工厂，位置 p、容量 c。枚举它接收的数量 k，范围为 0…min(c,i)；它接收最后 k 个机器人，即下标 i−k…i−1。
  5. 从上一层 dp[j−1][i−k] 转移，叠加这一段的绝对距离和，取最小值。
  6. 用两条数组滚动保存前后层，最终返回 dp[m][n]。
dp[j][i] = min { dp[j−1][i−k] + Σ |robot[t]−p| }
0 ≤ k ≤ min(c,i)，i−k ≤ t < i

枚举 k 时，每多接收一个机器人，只增加 |robot[i−k]−p|。k = 0 就是跳过当前工厂。

正确性说明
  1. 结构成立：交换交叉分配不增加费用且保持容量，因此至少存在按机器人顺序分段分配的最优解。
  2. 转移完备：前 i 个机器人的任何这种分配，其最后一家工厂必接收某个合法 k 对应的后缀；删除该后缀就得到上一层的子问题。
  3. 最优子结构：若前 i−k 个机器人的安排不是上一层最优，则替换它能减小总费用，与最优性矛盾。
  4. 归纳结论：初始状态正确，每次遍历全部合法 k 并取最小值，因此最终状态给出最优总距离。
为什么不必模拟时间？上述分配给出所有物理维修方案的距离下界。反过来，取一个最小距离分配并逐个启动机器人；若途中更近的工厂尚有空位，就在此维修，并将其目标改为该工厂。若该名额已分配给另一个尚未启动的机器人，将那个机器人的目标改为原目标；由三角不等式，总分配距离不会增加。若名额未分配，则直接改目标。重复此操作，总能选到沿途可直接到达目标的机器人并完成维修。因而存在可执行的方案达到该下界。


边界与数值安全
  • 容量为 0：仅允许 k = 0，整层原样继承。
  • 机器人与工厂重合：距离自然为 0；未用完的工厂名额可以留下。
  • 总容量保证足够，但中间状态仍可能不可达，需要保留正无穷。
  • 最大总距离不超过 100 × 2×10⁹ = 2×10¹¹。Java / C++ 使用 64 位整数；JavaScript Number 在此范围内可精确表示整数；Python 整数无需额外处理。
  • 代码会原地排序输入；若调用方要保留顺序，先复制数组或列表。


复杂度
n 为机器人数，m 为工厂数。排序 O(n log n + m log m)，动态规划 O(mn²)（更细为 O(n Σ min(limitⱼ,n))），滚动数组额外空间 O(n)，不计排序实现使用的栈或缓冲空间。


替代方案
  • 展开维修名额：把容量展开为相同坐标的槽位，依次选择“跳过槽位”或“匹配下一个机器人”，时间 O(nL)、空间 O(n)，L 为总容量；L 最多 mn，未必更快。
  • 记忆化搜索：同样按工厂与机器人前缀划分，表达直接，但需要递归和 O(mn) 状态存储。
  • 单调队列优化：用距离前缀和 S，将转移写成 S[i] + min(dpPrev[t]−S[t])，t 位于 [i−c,i]；维护滑动窗口最小值，可将 DP 优化到 O(mn)。本题 100 的规模下，直接枚举更容易解释。


常见错误
  • “谁离某家工厂最近就先维修谁”会抢掉他人需要的容量。例如 [0,4,5] 与 [[3,1],[10,2]]，让 4 先去 3 得到 16；让 0 去 3、4 和 5 去 10 得到 14。
  • 不排序就按连续区间分配，交换性质无法使用。
  • 更新时引用当前层，导致同一家工厂被重复计入并超出容量。
  • 漏掉 k = 0；或每次重算区间和，使时间退化为 O(mn³)。
  • 用 32 位整数累加距离，或将不可达状态初始化为 0。


面试追问
怎样输出具体分配？保存每个 (j,i) 的最优 k，再从 (m,n) 反向回溯，增加 O(mn) 空间。
机器人带有不同移动权重，还能直接套用吗？不能直接套用。交叉交换不等式可能失效，需要重新证明结构或使用更一般的最小费用流。
如何优化到 O(mn)？利用上面的前缀和变形，每加入一个新 t 就维护递增队列，移除窗口左侧过期候选。

Java
import java.util.*;

class Solution {
    public long minimumTotalDistance(List<Integer> robot,
                                     int[][] factory) {
        Collections.sort(robot);
        Arrays.sort(factory, Comparator.comparingInt(a -> a[0]));
        int n = robot.size();
        long inf = Long.MAX_VALUE / 4;
        long[] dp = new long[n + 1];
        Arrays.fill(dp, inf);
        dp[0] = 0;
        for (int[] f : factory) {
            long[] next = dp.clone();
            for (int i = 1; i <= n; i++) {
                long distance = 0;
                for (int k = 1; k <= Math.min(f[1], i); k++) {
                    distance += Math.abs((long) robot.get(i - k) - f[0]);
                    if (dp[i - k] != inf) {
                        next[i] = Math.min(next[i], dp[i - k] + distance);
                    }
                }
            }
            dp = next;
        }
        return dp[n];
    }
}

    robot.sort((a, b) => a - b);

            }
        }
        dp = next;
    }
    return dp[n];

Python
from typing import List

class Solution:
    def minimumTotalDistance(self, robot: List[int],
                             factory: List[List[int]]) -> int:
        robot.sort()
        factory.sort(key=lambda f: f[0])
        n = len(robot)
        dp = [float("inf")] * (n + 1)
        dp[0] = 0
        for position, limit in factory:
            nxt = dp.copy()
            for i in range(1, n + 1):
                distance = 0
                for k in range(1, min(limit, i) + 1):
                    distance += abs(robot[i - k] - position)
                    nxt[i] = min(nxt[i], dp[i - k] + distance)
            dp = nxt
        return dp[n]


C++
#include <algorithm>
#include <climits>
#include <cstdlib>
#include <vector>
using namespace std;

class Solution {
public:
    long long minimumTotalDistance(vector<int>& robot,
                                    vector<vector<int>>& factory) {
        sort(robot.begin(), robot.end());
        sort(factory.begin(), factory.end());
        int n = robot.size();
        const long long INF = LLONG_MAX / 4;
        vector<long long> dp(n + 1, INF);
        dp[0] = 0;
        for (const auto& f : factory) {
            auto next = dp;
            for (int i = 1; i <= n; ++i) {
                long long distance = 0;
                for (int k = 1; k <= min(f[1], i); ++k) {
                    distance += llabs((long long)robot[i - k] - f[0]);
                    if (dp[i - k] != INF) {
                        next[i] = min(next[i], dp[i - k] + distance);
                    }
                }
            }
            dp.swap(next);
        }
        return dp[n];
    }
};
