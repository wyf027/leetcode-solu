裁剪数字后查询
第 K 小的数字

Query Kth Smallest Trimmed Number

同一组数字，保留的位数不同，排名就可能改变。读懂“从右裁剪”与“同值时按原下标排序”，再尝试自己设计解法。

01 / 题目任务

给定数字字符串数组 nums，所有字符串等长，下标从 0 开始。另有二维数组 queries，每条查询的完整形式是 [k, trim]。

  1. 对每个原字符串，只保留最右侧的 trim 位。
  2. 按裁剪后的数值从小到大排名；相同时，原下标小的排在前面。
  3. 返回第 k 名对应的原数组下标，再独立处理下一条查询。

查询互不影响，不会永久改变原字符串。允许前导零，例如 "02" 表示 2。k 从 1 计数，返回下标从 0 计数。

完整约束

  • 1 ≤ nums.length ≤ 100
  • 1 ≤ nums[i].length ≤ 100，且所有字符串长度相同。
  • nums[i] 只包含数字字符 0–9。
  • 1 ≤ queries.length ≤ 100，queries[i].length == 2。
  • 1 ≤ kᵢ ≤ nums.length。
  • 1 ≤ trimᵢ ≤ nums[0].length。

02 / 官方示例

示例 1 · 排名随裁剪变化

nums = ["102","473","251","814"]
queries = [[1,1],[2,3],[4,2],[1,2]]
输出 = [2,2,1,0]
  • [1,1]：后缀为 2、3、1、4，最小值来自下标 2。
  • [2,3]：保留全部数位，第二小是 251，下标 2。
  • [4,2]：后缀为 02、73、51、14，第四小是 73，下标 1。
  • [1,2]：最小后缀 02 来自下标 0。

示例 2 · 相等时看原下标

nums = ["24","37","96","04"]
queries = [[2,1],[2,2]]
输出 = [3,0]
  • [2,1]：后缀为 4、7、6、4。两个 4 中，下标 0 排在下标 3 前，因此第二名的下标是 3。
  • [2,2]：从小到大为 04、24、37、96，第二名来自下标 0。

04 / 题解 · 稳定基数排序

核心洞察：已知后 t−1 位的顺序后，按左侧新增的一位做一次稳定排序，就得到后 t 位的顺序。每轮只有 0–9 十种键，依次分桶、按桶号收集即可。

最初让下标按 0,1,…,n−1 排列。同一桶按进入顺序取出，因此相同后缀始终保留原下标的先后关系。全程只处理字符，不需要把 100 位字符串转成整数。

完整过程

  1. 初始化 order = [0,1,…,n−1]；建立每种裁剪长度的排名表。
  2. 令 t 从 1 到字符串长度 L，当前字符位置是 L−t。
  3. 按旧 order 的顺序扫描，将下标放入对应数字桶。
  4. 按 0 到 9 的桶号收集，得到新 order，复制保存为 rank[t]。
  5. 每条查询 [k,t] 直接取 rank[t][k−1]，按查询的原顺序返回。

示例 1 的下标顺序：t=1 为 [2,0,1,3]，t=2 为 [0,3,2,1]，t=3 为 [0,2,1,3]。

正确性证明

不变式：完成第 t 轮后，order 按最后 t 位的值升序排列；同值时按原下标升序排列。

基础：t=0 时空后缀全部相同，初始下标升序满足规则。

归纳：第 t 轮中，新增字符更小的桶先收集，符合更高位优先比较的规则。同桶内新增字符相等，稳定收集保留了后 t−1 位的正确顺序；后缀全部相同时，也保留了下标顺序。

结论：不变式对每个 t 成立。取第 k−1 个元素，恰好返回查询要求的原下标。

复杂度、边界与替代方案

设 n 为数字个数、L 为字符串长度、q 为查询数。下面四份代码均保存全部裁剪长度的排名。

  • 时间：每轮分桶与收集为 O(n+10)，共 L 轮，查询 O(q)，总计 O(L(n+10)+q)，固定数字字符集下为 O(Ln+q)。
  • 额外空间：排名表 O(Ln)，桶与临时队列 O(n+10)。若计入返回数组，总计 O(Ln+q)。
  • 边界：n=1、全部相同、前导零、trim=1 或 L、k=1 或 n、重复查询都沿用同一逻辑。
  • 直接排序：对每次查询按“等长后缀字符串、原下标”排序，直观且满足本题规模。最坏时间 O(qLn log n)，无需整数转换。
  • 节省空间：按 trim 将查询分组，第 t 轮直接回答对应查询，无需保存历史排名；额外空间可降到 O(n+L+q)。还可只做到最大查询 trim。
  • 快速选择：单次查询可按同一比较规则选择第 k 项，平均 O(n·trim)，但通常不如复用各长度排名适合多次查询。

常见错误与面试追问

  • 把长字符串转成 Number / int / long：100 位会超范围。逐字符处理即可。
  • 每一轮重置为原下标顺序：丢失低位已经建立的顺序。只有最开始初始化一次。
  • 用栈倒序取桶内元素：破坏稳定性；桶内必须按进入顺序输出。
  • 返回后缀值或排序位置：题目要的是原数组下标。
  • 保存排名表时复用同一个可变数组：应保存副本，避免后续轮次覆盖。
  • 永久裁剪 nums：后续查询可能需要更多位，应始终读取原字符串。

追问

为什么字符串比较可以替代数值比较？同一查询的后缀等长，首次不同的数位决定大小，前导零不会改变结论。

为什么从右向左？先确定低位顺序，再让稳定排序把新增的高位放到主导位置；从左向右简单地反复稳定排序会让最后处理的低位成为主键。

查询乱序怎么办？排名表可随机访问；分组方案则保留查询编号，把答案写回原位置。

大量查询但裁剪长度很少？仍需经过必要低位轮次，但只保存被查询长度的排名，或在相应轮次直接回答。

JavaScript

/**
 * @param {string[]} nums
 * @param {number[][]} queries
 * @return {number[]}
 */
var smallestTrimmedNumbers = function(nums, queries) {
    const n = nums.length, L = nums[0].length;
    let order = Array.from({length: n}, (_, i) => i);
    const rank = Array(L + 1);
    for (let t = 1; t <= L; t++) {
        const buckets = Array.from({length: 10}, () => []);
        for (const i of order) {
            buckets[nums[i].charCodeAt(L - t) - 48].push(i);
        }
        order = buckets.flat();
        rank[t] = order.slice();
    }
    return queries.map(([k, t]) => rank[t][k - 1]);
};

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[] smallestTrimmedNumbers(String[] nums, int[][] queries) {
        int n = nums.length, len = nums[0].length();
        int[] order = new int[n];
        for (int i = 0; i < n; i++) order[i] = i;
        int[][] rank = new int[len + 1][];
        for (int t = 1; t <= len; t++) {
            List<List<Integer>> buckets = new ArrayList<>();
            for (int d = 0; d < 10; d++) buckets.add(new ArrayList<>());
            for (int i : order) {
                buckets.get(nums[i].charAt(len - t) - '0').add(i);
            }
            int pos = 0;
            for (List<Integer> bucket : buckets) {
                for (int i : bucket) order[pos++] = i;
            }
            rank[t] = order.clone();
        }
        int[] answer = new int[queries.length];
        for (int j = 0; j < queries.length; j++) {
            answer[j] = rank[queries[j][1]][queries[j][0] - 1];
        }
        return answer;
    }
}

Python 3

from typing import List

class Solution:
    def smallestTrimmedNumbers(self, nums: List[str],
                               queries: List[List[int]]) -> List[int]:
        n, length = len(nums), len(nums[0])
        order = list(range(n))
        rank = [None] * (length + 1)
        for t in range(1, length + 1):
            buckets = [[] for _ in range(10)]
            for i in order:
                buckets[ord(nums[i][length - t]) - ord('0')].append(i)
            order = [i for bucket in buckets for i in bucket]
            rank[t] = order[:]
        return [rank[t][k - 1] for k, t in queries]

C++

#include <array>
#include <numeric>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> smallestTrimmedNumbers(vector<string>& nums,
                                       vector<vector<int>>& queries) {
        int n = nums.size(), len = nums[0].size();
        vector<int> order(n);
        iota(order.begin(), order.end(), 0);
        vector<vector<int>> rank(len + 1);
        for (int t = 1; t <= len; ++t) {
            array<vector<int>, 10> buckets;
            for (int i : order) {
                buckets[nums[i][len - t] - '0'].push_back(i);
            }
            order.clear();
            for (const auto& bucket : buckets) {
                order.insert(order.end(), bucket.begin(), bucket.end());
            }
            rank[t] = order;
        }
        vector<int> answer;
        answer.reserve(queries.size());
        for (const auto& q : queries) answer.push_back(rank[q[1]][q[0] - 1]);
        return answer;
    }
};
