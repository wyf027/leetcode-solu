由子序列构造的
最长回文串的长度

从两个字符串各取一个非空子序列，按固定顺序拼接。目标不是输出回文串，而是求它能达到的最大长度。

困难字符串动态规划非付费题

PROBLEM

题目描述

函数
longestPalindrome

给定两个字符串 word1 和 word2。请分别从两者中选出一个非空子序列，再按 subsequence1 + subsequence2 的顺序连接。

返回按这种方式能够构造出的最长回文串长度；若不存在符合条件的回文串，返回 0。

定义：子序列可通过删除若干字符得到，但保留字符的相对顺序；回文串正读与反读相同。两个来源都必须至少贡献一个字符。

约束

1 <= word1.length, word2.length <= 1000

word1、word2 仅含小写英文字母。

参数与返回值

输入：String word1, String word2

返回：int，最长合法回文长度。

EXAMPLES

输出：5

SOLUTION

完整题解

建议先自己思考：怎样保证答案真的使用了两个字符串？

核心洞察

把两个字符串连接成 s = word1 + word2，先求每个区间的最长回文子序列（LPS）。但最终答案只在一对相等且跨越拼接边界的端点上更新：左端点来自 word1，右端点来自 word2。

这对端点被实际选入回文串，天然保证两个子序列都非空。区间内部则可自由选择最长回文子序列。

状态与转移

令 dp[i][j] 表示 s[i..j] 的最长回文子序列长度。

  • i == j 时，dp[i][i] = 1。
  • 若 s[i] == s[j]，则 dp[i][j] = dp[i+1][j-1] + 2。
  • 否则，dp[i][j] = max(dp[i+1][j], dp[i][j-1])。
  • 若相等端点还满足 i < word1.length 且 j >= word1.length，用 dp[i][j] 更新答案。

计算顺序

dp[i][j] 依赖更短区间，因此让 i 从右向左遍历，让 j 从 i + 1 向右遍历。

总长度最多为 2000，二维动态规划可直接覆盖全部区间。

复杂度：时间 O((m+n)^2)，空间 O((m+n)^2)。

正确性证明

  1. 区间状态正确。单字符区间的 LPS 为 1。对更长区间，相等端点可与内部最优回文组成更长回文；端点不等时，任意回文至多使用其中一个端点，故取去掉左端或右端后的较大值。按区间长度归纳，dp 正确。
  2. 记录的候选一定合法。更新答案时，所选相等端点分别来自两个字符串。它们构成回文的首尾，内部由原拼接串的子序列组成，所以两个来源均有贡献，且拼接顺序不变。
  3. 不会漏掉最优解。任意合法回文都使用两个来源。由于拼接后所有 word1 字符位于所有 word2 字符之前，它最外层那对跨来源字符必然相等。算法遍历到该端点对时，dp 至少能得到这个回文的长度，因此答案不小于最优值；结合候选合法性，答案恰为最优值。

边界情况

  • 两边不存在相同字符：没有跨边界端点对，答案保持 0。
  • 最优回文长度为 2：只取两边各一个相同字符。
  • 中心字符可来自任意一边；内部 LPS 会自动处理奇数长度。
  • 重复字符很多时仍按下标区分，转移无需特殊处理。

替代方案与取舍

可以用一维滚动数组把 LPS 空间压到 O(m+n)，但更新跨边界候选时要谨慎保存左下角旧值，代码更难解释与维护。

也可以枚举跨边界端点后再查询内部 LPS；本质仍是同一组区间状态，合并到一次 DP 更直接。

面试追问

  • 怎样把空间优化到一维？
  • 如果要求恢复一个具体回文串，需额外保存什么？
  • 若允许交换两个子序列的拼接顺序，答案是否变化？
  • 若要求恰好从两边各选 k 个字符，状态怎样扩展？

常见错误

  • 直接返回拼接串的 LPS，可能只使用一个字符串。
  • 看到相同端点时更新答案，却没检查端点是否跨越边界。
  • 把子序列误当子串，错误要求字符连续。
  • 区间遍历顺序不满足依赖，读取到尚未计算的状态。

class Solution {
    public int longestPalindrome(String word1, String word2) {
        String s = word1 + word2;
        int split = word1.length();
        int n = s.length();
        int[][] dp = new int[n][n];
        int answer = 0;

        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = (j == i + 1 ? 0 : dp[i + 1][j - 1]) + 2;
                    if (i < split && j >= split) {
                        answer = Math.max(answer, dp[i][j]);
                    }
                } else {
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        return answer;
    }
}

class Solution:
    def longestPalindrome(self, word1: str, word2: str) -> int:
        s = word1 + word2
        split = len(word1)
        n = len(s)
        dp = [[0] * n for _ in range(n)]
        answer = 0

        for i in range(n - 1, -1, -1):
            dp[i][i] = 1
            for j in range(i + 1, n):
                if s[i] == s[j]:
                    inside = 0 if j == i + 1 else dp[i + 1][j - 1]
                    dp[i][j] = inside + 2
                    if i < split <= j:
                        answer = max(answer, dp[i][j])
                else:
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])

        return answer
