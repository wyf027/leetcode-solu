LCP 28. 采购方案

从若干商品中选两件，价格和不超过目标值的方案有多少？排序后让左右指针相向移动，一次确认一整批合法配对。

题意

给定商品价格数组 nums 和预算 target，统计下标不同的二元组 (i,j)，满足 nums[i]+nums[j] ≤ target。结果对 1_000_000_007 取模。

约束：2 ≤ nums.length ≤ 10⁵，商品价格与 target 非负。

关键不变量

  1. 1. 排序后，若 nums[left]+nums[right] ≤ target，那么 left 与区间 (left,right] 的所有元素都合法，共 right-left 对。
  2. 2. 此时 left 右移；反之和太大，必须让 right 左移。
  3. 3. 每个指针单调移动，扫描 O(n)。

题解已折叠

题解：排序 + 双指针

将价格从小到大排序。固定最便宜的尚未处理商品 left，若它与最贵候选 right 的和仍不超预算，则它可以和中间所有商品配对；一次加入 right-left，并右移 left。否则最贵商品无法与当前 left 配对，左移 right。

正确性

排序保证中间值不大于 right，所以整批都合法。

复杂度

排序 O(n log n)，扫描 O(n)，空间取决于排序实现。

常见错误

合法时加的是 right-left，不是 1；累加须用长整型。
