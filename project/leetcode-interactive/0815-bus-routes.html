815. 公交路线Bus Routes

困难 HARD 广度优先搜索 数组 哈希表

在循环行驶的线路之间找到一段旅程。先理解“乘一辆车”如何扩大可达范围，再决定是否展开完整题解。

今日行程

从车站 source 出发，仅靠公交抵达 target，最少需要乘坐几辆车？

起点时你还没有上车；每换乘一条新线路，乘车数量增加 1。

01

Problem

题目描述

给定二维整数数组 routes，其中 routes[i] 是第 i 辆公交车循环行驶的线路。比如 [1, 5, 7] 表示它会不断按 1 → 5 → 7 → 1 → … 的顺序运行。

你从车站 source 出发，初始时不在任何公交车上，并且只能乘公交前往 target。返回到达终点至少要乘坐的公交车数量；如果无法到达，返回 -1。

官方示例 1

输入：routes = [[1,2,7],[3,6,7]], source = 1, target = 6
输出：2
解释：先乘第一辆公交车到车站 7，
      再乘第二辆公交车到车站 6。

官方示例 2

输入：routes = [[7,12],[4,5,15],[6],[15,19],[9,12,13]],
      source = 15, target = 12
输出：-1

约束

  • 1 ≤ routes.length ≤ 500
  • 1 ≤ routes[i].length ≤ 10⁵
  • 每个 routes[i] 内的车站值互不相同
  • sum(routes[i].length) ≤ 10⁵
  • 0 ≤ routes[i][j] < 10⁶
  • 0 ≤ source, target < 10⁶

04

Solution

题解：在线路之间做分层搜索

核心洞察 题目计算的是“乘了几辆公交”，所以把每一条公交线路看成搜索节点最自然。两条线路只要共享一个车站，就能在该站换乘；从包含 source 的线路同时出发，第一次遇到包含 target 的线路时，层数就是最少乘车数。

完整过程

  1. 处理零步情况。若 source == target，不需要上车，直接返回 0。
  2. 建立倒排索引。遍历全部线路，记录“每个车站由哪些线路经过”，即 stop → routes。
  3. 初始化第一层。将所有经过 source 的线路加入队列，乘车数都记为 1，并标记线路已访问。
  4. 按层扩展换乘。弹出一条线路，遍历它的车站；若车站是 target，返回当前乘车数。否则通过倒排索引找到能在该站换乘的线路，将未访问线路以“当前数量 + 1”入队。
  5. 避免重复扫描。同一车站的线路列表只展开一次。若队列耗尽仍未遇到终点，则返回 -1。

为什么正确

覆盖所有可行换乘

倒排索引列出了经过某站的全部线路。因此从当前线路的每个车站扩展时，不会遗漏任何下一辆可换乘的公交。

队列层数就是乘车数

初始线路的层数为 1；每跨到一条新线路只增加 1。广度优先队列按非递减层数处理线路。

首次到达必然最优

若首次在第 k 层发现终点，所有少于 k 辆车的线路状态已经处理完，均未到达终点，所以答案不可能更小。

去重不影响答案

某线路或车站第一次被访问时已经处于最小层数；以后再访问只会相同或更晚，跳过它们不会丢失更优路径。

复杂度

令 S = sum(routes[i].length)，即所有线路中的车站记录总数。

时间复杂度O(S)每条线路的车站与每个车站的倒排列表至多有效展开一次。
空间复杂度O(S + R)倒排索引、队列、已访问线路与已展开车站；R 为线路数。

边界情况

  • source == target：无需乘车，答案为 0。
  • 没有任何线路经过起点，或没有任何线路经过终点：无法到达。
  • 起点和终点位于同一条线路：只需乘 1 辆公交。
  • 线路可能形成环；必须记录已访问线路，避免反复换乘。
  • 车站编号可接近 10⁶，不应依赖按最大编号开大数组，哈希表更稳妥。

替代方案

以车站为 BFS 状态：队列保存当前可达车站和已乘车辆数，每次从车站找到经过它的线路，再把线路上的所有站加入下一层。只要同时维护“已乘线路”和“已处理车站”，也能做到线性复杂度；不过在线路层面建模时，“一层 = 乘一辆车”的含义更直接。

显式建立线路图：两条线路有公共车站就连边，然后对线路图 BFS。概念清晰，但若逐对比较最多 500 条线路，建图可能达到二次复杂度，而且公共站集合的求交也有额外成本。

双向 BFS：可分别从起点线路和终点线路扩展，在线路网络很宽时减少实际搜索量；实现与去重逻辑更复杂，题目给定总车站记录不超过 10⁵，单向 BFS 已足够。

四语言完整代码

import java.util.*;

class Solution {
    public int numBusesToDestination(int[][] routes, int source, int target) {
        if (source == target) {
            return 0;
        }

        Map<Integer, List<Integer>> stopToRoutes = new HashMap<>();
        for (int route = 0; route < routes.length; route++) {
            for (int stop : routes[route]) {
                stopToRoutes.computeIfAbsent(stop, key -> new ArrayList<>())
                            .add(route);
            }
        }

        List<Integer> starts = stopToRoutes.get(source);
        if (starts == null) {
            return -1;
        }

        Queue<int[]> queue = new ArrayDeque<>();
        boolean[] visitedRoute = new boolean[routes.length];
        Set<Integer> expandedStop = new HashSet<>();

        for (int route : starts) {
            visitedRoute[route] = true;
            queue.offer(new int[] {route, 1});
        }

        while (!queue.isEmpty()) {
            int[] state = queue.poll();
            int route = state[0];
            int buses = state[1];

            for (int stop : routes[route]) {
                if (stop == target) {
                    return buses;
                }
                if (!expandedStop.add(stop)) {
                    continue;
                }
                for (int nextRoute : stopToRoutes.get(stop)) {
                    if (!visitedRoute[nextRoute]) {
                        visitedRoute[nextRoute] = true;
                        queue.offer(new int[] {nextRoute, buses + 1});
                    }
                }
            }
        }

        return -1;
    }
}

var numBusesToDestination = function(routes, source, target) {
    if (source === target) {
        return 0;
    }

    const stopToRoutes = new Map();
    for (let route = 0; route < routes.length; route++) {
        for (const stop of routes[route]) {
            if (!stopToRoutes.has(stop)) {
                stopToRoutes.set(stop, []);
            }
            stopToRoutes.get(stop).push(route);
        }
    }

    if (!stopToRoutes.has(source)) {
        return -1;
    }

    const queue = [];
    const visitedRoute = new Set();
    const expandedStop = new Set();

    for (const route of stopToRoutes.get(source)) {
        visitedRoute.add(route);
        queue.push([route, 1]);
    }

    let head = 0;
    while (head < queue.length) {
        const [route, buses] = queue[head++];

        for (const stop of routes[route]) {
            if (stop === target) {
                return buses;
            }
            if (expandedStop.has(stop)) {
                continue;
            }
            expandedStop.add(stop);

            for (const nextRoute of stopToRoutes.get(stop)) {
                if (!visitedRoute.has(nextRoute)) {
                    visitedRoute.add(nextRoute);
                    queue.push([nextRoute, buses + 1]);
                }
            }
        }
    }

    return -1;
};
from collections import defaultdict, deque
from typing import List


class Solution:
    def numBusesToDestination(
        self,
        routes: List[List[int]],
        source: int,
        target: int
    ) -> int:
        if source == target:
            return 0

        stop_to_routes = defaultdict(list)
        for route_index, stops in enumerate(routes):
            for stop in stops:
                stop_to_routes[stop].append(route_index)

        if source not in stop_to_routes:
            return -1

        queue = deque()
        visited_route = set()
        expanded_stop = set()

        for route in stop_to_routes[source]:
            visited_route.add(route)
            queue.append((route, 1))

        while queue:
            route, buses = queue.popleft()

            for stop in routes[route]:
                if stop == target:
                    return buses
                if stop in expanded_stop:
                    continue
                expanded_stop.add(stop)

                for next_route in stop_to_routes[stop]:
                    if next_route not in visited_route:
                        visited_route.add(next_route)
                        queue.append((next_route, buses + 1))

        return -1

#include <unordered_map>
#include <unordered_set>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int numBusesToDestination(
        vector<vector<int>>& routes,
        int source,
        int target
    ) {
        if (source == target) {
            return 0;
        }

        unordered_map<int, vector<int>> stopToRoutes;
        for (int route = 0; route < static_cast<int>(routes.size()); ++route) {
            for (int stop : routes[route]) {
                stopToRoutes[stop].push_back(route);
            }
        }

        if (!stopToRoutes.count(source)) {
            return -1;
        }

        queue<pair<int, int>> bfs;
        vector<bool> visitedRoute(routes.size(), false);
        unordered_set<int> expandedStop;

        for (int route : stopToRoutes[source]) {
            visitedRoute[route] = true;
            bfs.push({route, 1});
        }

        while (!bfs.empty()) {
            auto [route, buses] = bfs.front();
            bfs.pop();

            for (int stop : routes[route]) {
                if (stop == target) {
                    return buses;
                }
                if (!expandedStop.insert(stop).second) {
                    continue;
                }

                for (int nextRoute : stopToRoutes[stop]) {
                    if (!visitedRoute[nextRoute]) {
                        visitedRoute[nextRoute] = true;
                        bfs.push({nextRoute, buses + 1});
                    }
                }
            }
        }

        return -1;
    }
};

面试追问

为什么不把每个车站当成普通最短路节点？
可以，但边的成本并不是“经过一个站”，而是“新乘一辆车”。直接以线路为节点，BFS 层数天然对应目标值，证明和实现都更简洁。
为什么需要同时记录已访问线路和已展开车站？
线路去重保证每辆公交只入队一次；车站去重保证某个倒排列表只扫描一次。前者确保搜索终止，后者把总扫描量压到与输入规模同阶。
如果要输出具体乘车线路和换乘站呢？
为每条首次入队的线路记录前驱线路与触发换乘的车站。到达终点后沿前驱回溯，再反转即可得到线路序列与换乘点。
如果每条公交的票价不同呢？
每次换乘不再具有相同成本，普通 BFS 失效。应把线路视为带权节点或边，使用 Dijkstra；若成本仅为 0 或 1，可使用 0-1 BFS。

常见错误

  • 把经过的车站数量当成目标，得到的是“最少站数”而不是“最少公交数”。
  • 只标记访问过的车站，却让同一条长线路被许多车站反复加入队列。
  • 忘记 source == target，错误地返回 1 或 -1。
  • 预先两两比较线路是否相交，在输入上限附近制造不必要的二次开销。
  • 在确认最短层数之前就按某条线路的站点顺序模拟公交行驶；本题同一线路内任意站均可到达，顺序不会增加乘车数量。
