Encode and Decode TinyURL

TinyURL 的加密与解密

把冗长地址映射成短链接，再无损找回原地址。先观察系统行为，再决定如何保存这段双向关系。

题意

TinyURL 是 URL 缩短服务。设计并实现一个系统对象，把给定的长 URL 编码为短 URL，并能把由同一对象生成的短 URL 解码回原始长 URL。编码规则不受限制，只需保证往返结果正确。

  • Solution() / Codec()：初始化系统。
  • String encode(String longUrl)：返回对应的短 URL。
  • String decode(String shortUrl)：返回原始 URL；输入保证由同一对象编码。

官方示例

输入：url = "https://leetcode.com/problems/design-tinyurl"

输出："https://leetcode.com/problems/design-tinyurl"

调用：
Solution obj = new Solution();
string tiny = obj.encode(url);
string ans = obj.decode(tiny);

约束
1 <= url.length <= 104
url 保证是有效 URL。

准备查看实现？

题解默认收起，建议先思考：短码怎样保证唯一？映射需要保存在哪里？

题解：递增 ID + 哈希映射

核心洞察

题目只要求同一实例内可逆。每次编码分配唯一递增 ID，把 base + ID 作为短链，同时在哈希表保存 ID → longUrl。解码时取出短链末尾 ID 并查表。

完整过程

  1. 初始化计数器、前缀和映射表。
  2. encode 取得当前 ID，写入映射并递增计数器。
  3. 拼接前缀与 ID，返回短链。
  4. decode 去掉前缀，得到 ID，查表返回长 URL。

正确性

唯一性：计数器每次严格递增，任意两次编码得到不同 ID，因此短链不同。可逆性：编码时把当前 ID 与原 URL 一同写入映射；解码同一短链会恢复同一 ID，并返回其唯一关联的原 URL，所以 decode(encode(url)) = url。

边界

最短和最长合法 URL 都只作为字符串值保存；重复编码同一 URL 会得到不同短链，但均可解码；题目保证 decode 输入有效，因此无需处理未知短码。

复杂度

哈希表操作平均 O(1)；若计入字符串复制，编码为 O(L)、解码返回结果为 O(L)。保存 n 个 URL 的空间为 O(ΣL)。

替代方案

可以随机生成 Base62 短码并在冲突时重试，短码更难预测，适合真实服务；也可把递增 ID 转成 Base62 来缩短长度。只用字符串哈希值可能碰撞，必须配合冲突检测。

面试追问

分布式环境如何发号？可使用号段、Snowflake 或数据库序列。如何支持过期、删除与统计？需要持久化存储、TTL、缓存、访问日志和防滥用策略。怎样避免枚举攻击？使用随机不可预测短码并限制访问频率。

常见错误

只返回哈希值却不保存映射；短码冲突时覆盖旧值；encode 与 decode 使用不同前缀解析规则；把哈希表或计数器声明成每次调用都会重建的局部变量。

四语言完整实现

Java

import java.util.HashMap;
import java.util.Map;

public class Codec {
    private final String base = "http://tinyurl.com/";
    private final Map<Integer, String> urls = new HashMap<>();
    private int nextId = 1;

    public String encode(String longUrl) {
        int id = nextId++;
        urls.put(id, longUrl);
        return base + id;
    }

    public String decode(String shortUrl) {
        int id = Integer.parseInt(shortUrl.substring(base.length()));
        return urls.get(id);
    }
}

Python

class Codec:
    def __init__(self):
        self.base = "http://tinyurl.com/"
        self.urls = {}
        self.next_id = 1

    def encode(self, longUrl: str) -> str:
        current = self.next_id
        self.next_id += 1
        self.urls[current] = longUrl
        return self.base + str(current)

    def decode(self, shortUrl: str) -> str:
        current = int(shortUrl[len(self.base):])
        return self.urls[current]

C++

class Solution {
private:
    const string base = "http://tinyurl.com/";
    unordered_map<int, string> urls;
    int nextId = 1;

public:
    string encode(string longUrl) {
        int id = nextId++;
        urls[id] = longUrl;
        return base + to_string(id);
    }

    string decode(string shortUrl) {
        int id = stoi(shortUrl.substr(base.size()));
        return urls[id];
    }
};
