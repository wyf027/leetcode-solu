回文串 II

给定一个只含小写英文字母的字符串，最多删除一个字符。判断它能否成为回文字符串。

Greedy / 贪心 Two Pointers / 双指针 String / 字符串
先别急着看题解

试着回答：第一次发现左右字符不同时，那一次删除必须发生在哪里？

Problem

题意与边界

“最多删除一个”也允许完全不删除；只需返回布尔值，不需要返回删除位置。

准确转述

给你字符串 s，你可以从中删除零个或一个字符。若操作后能得到回文字符串，返回 true；否则返回 false。

回文字符串从左向右与从右向左读完全相同，例如 aba、racecar。

约束

  • 1 <= s.length <= 105
  • s 只由小写英文字母组成。
  • 官方函数签名：validPalindrome(s) -> boolean
示例 1 
输入：s = "aba"
输出：true
示例 2 
输入：s = "abca"
输出：true
解释：可以删除字符 'c'。
示例 3 
输入：s = "abc"
输出：false

Spoiler Gate

准备好核对思路了吗？

下方题解包含完整算法、证明、复杂度、四种语言代码与面试追问，默认保持收起。

Solution

一次分叉，继续回文检查

外层找到第一次冲突，内层只验证两个可能的剩余区间。

核心洞察

  • 左右字符相同，就安全地同时向中间移动。
  • 第一次出现 s[left] != s[right] 时，若最终答案为真，唯一的删除只能是 s[left] 或 s[right]。
  • 因此只需检查 [left + 1, right] 与 [left, right - 1]，任一是回文即可。

完整过程

  1. 令 left = 0、right = s.length - 1。
  2. 当两端字符相同时，执行 left++ 与 right--。
  3. 若出现冲突，分别跳过左字符、跳过右字符，并检查两个闭区间是否为回文。
  4. 两条分支任一成立就返回 true；若从未冲突，也返回 true。

正确性证明

在第一次冲突之前，每一对外侧字符都相等，无需删除它们。冲突位置为 left、right 时，任何更内侧的删除都无法让当前这两个不同字符相等；任何更外侧的删除又会破坏已匹配部分。因此，可行解若存在，删除对象必为当前左字符或当前右字符。

算法完整检查了这两个且仅有的候选剩余区间：任一区间为回文时构造出合法方案；两者都不是回文时不存在合法方案。故返回值正确。

复杂度

时间 O(n) 外层与至多两次区间扫描，总量仍为线性。
额外空间 O(1) 只保存有限个下标与布尔值。

边界情况

  • 长度为 1：原串已经是回文。
  • 长度为 2：相同则不删，不同则删除任意一个，答案都为真。
  • 原串已经回文：允许零次删除，直接返回真。
  • 冲突后两条分支都失败：返回假，例如 abc。
  • 某条分支只剩零个或一个字符：该区间天然是回文。

替代方案

可以枚举每个删除位置，再判断剩余字符串是否回文，但若每次都构造新字符串，最坏时间和复制成本会达到 O(n²)。也可以用动态规划记录区间，但本题只允许删除一次，双指针已经利用了冲突位置的强约束，空间更省、实现更直接。

若改成“最多删除 k 个字符”，简单的两分支会指数增长，此时可考虑带备忘录的区间状态或最长回文子序列思路。

Implementations

四语言完整代码

均保持官方可提交函数签名；辅助函数只检查指定闭区间。

JavaLeetCode 提交版
class Solution {
    public boolean validPalindrome(String s) {
        int left = 0;
        int right = s.length() - 1;

        while (left < right) {
            if (s.charAt(left) == s.charAt(right)) {
                left++;
                right--;
            } else {
                return isPalindrome(s, left + 1, right)
                    || isPalindrome(s, left, right - 1);
            }
        }
        return true;
    }

    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}

var validPalindrome = function (s) {
    const isPalindrome = (left, right) => {
        while (left < right) {
            if (s[left] !== s[right]) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    };

    let left = 0;
    let right = s.length - 1;

    while (left < right) {
        if (s[left] === s[right]) {
            left++;
            right--;
        } else {
            return isPalindrome(left + 1, right)
                || isPalindrome(left, right - 1);
        }
    }
    return true;
};
Python 3LeetCode 提交版
class Solution:
    def validPalindrome(self, s: str) -> bool:
        def is_palindrome(left: int, right: int) -> bool:
            while left < right:
                if s[left] != s[right]:
                    return False
                left += 1
                right -= 1
            return True

        left, right = 0, len(s) - 1

        while left < right:
            if s[left] == s[right]:
                left += 1
                right -= 1
            else:
                return (
                    is_palindrome(left + 1, right)
                    or is_palindrome(left, right - 1)
                )
        return True
C++LeetCode 提交版
class Solution {
public:
    bool validPalindrome(string s) {
        int left = 0;
        int right = static_cast<int>(s.size()) - 1;

        while (left < right) {
            if (s[left] == s[right]) {
                ++left;
                --right;
            } else {
                return isPalindrome(s, left + 1, right)
                    || isPalindrome(s, left, right - 1);
            }
        }
        return true;
    }

private:
    bool isPalindrome(const string& s, int left, int right) {
        while (left < right) {
            if (s[left] != s[right]) {
                return false;
            }
            ++left;
            --right;
        }
        return true;
    }
};

Interview Notes

追问与易错点

面试追问

  • 若必须“恰好删除一个”而不是“最多删除一个”，原回文串如何处理？
  • 若允许删除至多 k 个字符，状态该怎样设计？
  • 若输入是 Unicode 字符串，按字节、码点还是字素簇比较？

常见错误

  • 冲突时只尝试删除左边，漏掉删除右边的可行解。
  • 用切片创建子串，误把额外空间写成 O(1)。
  • 把“最多一次”理解成“必须一次”。

表达要点

  • 先说明第一次冲突为何锁定两个删除候选。
  • 强调分支检查不递归，扫描总量仍是线性。
  • 用闭区间参数避免真正删除字符。
