625. 最小因式分解

把一个整数装进十进制数字里：每一位相乘必须恰好还原它，同时让这个新整数尽可能小。

英文标题 Minimum Factorization
难度 Medium
题目类型 付费题
返回类型 32 位整数

Problem

先读懂任务

给定一个正整数 num，寻找最小的正整数 x，使 x 的所有十进制数位之积恰好等于 num。

如果不存在这样的 x，或者最小答案超过有符号 32 位整数的上限 2³¹ − 1，返回 0。

smallestFactorization(num: integer) → integer

约束与判定

  • 1 ≤ num ≤ 2³¹ − 1
  • 答案必须是正整数。
  • 答案的每一位都只能是十进制数字。
  • 答案越短通常越小；位数相同时按数值比较。
  • 超过 32 位有符号整数范围时返回 0。

示例 1

输入：num = 48 输出：68

因为 6 × 8 = 48，且 68 是满足条件的最小正整数。

示例 2

输入：num = 15 输出：35

因为 3 × 5 = 15，按升序放置数位得到最小的 35。

Greedy Decomposition

从大数字向小数字提取因子

一个十进制数位只能贡献 2 到 9 之间的非平凡因子。把尽可能多的质因子压进较大的单个数位， 可以减少答案的位数；最后再把提取到的数位升序排列，得到同一组数位能组成的最小整数。

核心洞察

依次尝试 9, 8, …, 2。只要当前 num 能被某个数字整除， 就记录它并继续除。提取阶段从大到小，构造答案时必须反向读取。

完整过程

  1. 若 num < 10，它本身就是满足数位积条件的最小正整数，直接返回。
  2. 令候选数字 d 从 9 递减到 2。
  3. 当 num % d == 0 时，记录数位 d，再令 num /= d；同一个 d 可以重复提取。
  4. 遍历结束后，若剩余值不为 1，说明它无法由十进制数位之积表示，返回 0。
  5. 逆序读取已提取数位，相当于按升序拼接；每加入一位都检查是否超过 2³¹ − 1。
以 48 为例：提取顺序是 8, 6，反向拼接为 68，而不是 86。

正确性证明

引理 1：剩余值判定是充分的

遍历 9 到 2 后若还剩 r > 1，则 r 不含任何 2 到 9 的可除因子。 任意多位答案中，每个大于 1 的数位都属于 2 到 9，并必须整除尚未分配的乘积；因此不可能再构造答案。

引理 2：大数位优先不会变差

若当前可提取数位 d，它把若干质因子压入一个数位。任何把这些质因子拆成更多数位的方案都会增加位数， 因而数值更大；对位数相同的替代分组，可用 d 进行局部交换而不增大升序后的数位序列。

引理 3：反向拼接最小

对同一个数位多重集合，任意相邻逆序对交换后都会让整数变小。因此，将数位按非递减顺序排列得到最小整数。 提取顺序是非递增的，反向读取恰好得到非递减顺序。

结论

算法在可行时生成不多于任何其他方案的数位数，并在该数位集合上采用最小排列；不可行或溢出时返回 0。 所以返回值恰为题目要求的最小合法整数。

边界与复杂度

必须单独处理的边界

  • num = 1：答案是 1，而不是空数字或 11。
  • 2 ≤ num ≤ 9：答案就是 num 本身。
  • 含无法被 2、3、5、7 吸收的质因子：最终剩余值大于 1，返回 0。
  • 拼接过程中超过 2³¹ − 1：立即返回 0，避免窄整数溢出。

复杂度

O(log num) 时间。每次成功提取至少把剩余值除以 2，候选数字只有 8 个。
O(log num) 空间。保存最终答案的数位；若语言支持前插构造，可视实现调整。

替代方案、追问与常见错误

替代方案

  • 搜索所有整数：从 1 起逐个检查数位积，答案空间巨大，无法接受。
  • 质因数分解后枚举分组：可以得到正确答案，但需要处理大量分组与去重；贪心直接给出规范分组。
  • 动态规划：可把约数作为状态，但对本题固定数字集合来说结构过重。

面试追问

  • 为什么不是从 2 到 9 提取？这会产生更多、更大的前导数位。
  • 若输出允许任意精度，应如何改？用字符串直接保存升序数位即可。
  • 若进制改为 b，候选数位应改成 b − 1 到 2，并重新讨论溢出边界。
  • 如何避免语言整数溢出？先用更宽类型，或在乘 10 前做上界判断。

常见错误

  • 忘记给单数字输入直接返回，导致 num = 1 得到空答案。
  • 只除一次某个候选数字，没有使用 while 重复提取。
  • 按提取顺序直接拼接，得到最大的排列而不是最小排列。
  • 只在最终强制转型，没有在构造过程中检查 32 位上限。

实现检查清单

  • 候选循环：9 递减到 2。
  • 成功提取：记录后更新剩余值。
  • 可行性：最终剩余值必须为 1。
  • 排列：逆序读取提取数组。
  • 范围：答案不得超过 2147483647。

class Solution {
    public int smallestFactorization(int num) {
        if (num < 10) {
            return num;
        }

        int[] digits = new int[32];
        int size = 0;

        for (int d = 9; d >= 2; d--) {
            while (num % d == 0) {
                digits[size++] = d;
                num /= d;
            }
        }

        if (num != 1) {
            return 0;
        }

        long answer = 0;
        for (int i = size - 1; i >= 0; i--) {
            answer = answer * 10 + digits[i];
            if (answer > Integer.MAX_VALUE) {
                return 0;
            }
        }

        return (int) answer;
    }
}

    def smallestFactorization(self, num: int) -> int:
        if num < 10:
            return num

        digits = []

        for d in range(9, 1, -1):
            while num % d == 0:
                digits.append(d)
                num //= d

        if num != 1:
            return 0

        answer = 0
        for digit in reversed(digits):
            answer = answer * 10 + digit
            if answer > 2 ** 31 - 1:
                return 0

        return answer
#include <climits>
#include <vector>

using std::vector;

class Solution {
public:
    int smallestFactorization(int num) {
        if (num < 10) {
            return num;
        }

        vector<int> digits;

        for (int d = 9; d >= 2; --d) {
            while (num % d == 0) {
                digits.push_back(d);
                num /= d;
            }
        }

        if (num != 1) {
            return 0;
        }

        long long answer = 0;
        for (auto it = digits.rbegin(); it != digits.rend(); ++it) {
            answer = answer * 10 + *it;
            if (answer > INT_MAX) {
                return 0;
            }
        }

        return static_cast<int>(answer);
    }
};
