重构 2 行二进制矩阵

给定两行分别需要的 1 的数量，以及每一列的目标和，重构任意一个满足条件的二进制矩阵；若不可能，返回空矩阵。

Problem

题意与输入边界

返回任意可行解

你需要满足四件事

  • 矩阵固定为 2 × n，每个元素只能是 0 或 1。
  • 上行元素之和必须等于 upper。
  • 下行元素之和必须等于 lower。
  • 第 i 列两格之和必须等于 colsum[i]。
matrix[0][i] + matrix[1][i] = colsum[i]

若答案不唯一，返回任意一个；若不存在答案，返回空二维数组。

Solution

贪心：先处理不可选择的列

时间 O(n) · 空间 O(n)

核心洞察

列和为 2 时，上下两格只能都是 1。它会同时消耗两行额度，必须先处理；列和为 0 时两格只能都是 0；剩下列和为 1 的列，只需按两行剩余额度分配。

完整过程

  1. 创建两行全零数组，长度均为 n。
  2. 第一次扫描所有列。遇到 colsum[i] = 2，令上下两格均为 1，并让 upper、lower 各减一。
  3. 若任一剩余额度小于零，说明某行放不下所有强制的 1，返回空矩阵。
  4. 第二次扫描。遇到 colsum[i] = 1，若上行仍有额度就放到上行，否则放到下行。
  5. 最后两行剩余额度都必须恰好为零，否则列和总量与行和目标不匹配，返回空矩阵。

为什么正确

强制列正确：二进制格子的和为 2 只有 (1,1) 一种可能，和为 0 只有 (0,0) 一种可能，所以第一阶段不会错过任何解。

单一列正确：处理完所有强制列后，每个和为 1 的列都等价：可选 (1,0) 或 (0,1)。只要上下剩余额度非负且总和等于此类列数，任取恰好 upper 列给上行，其余给下行即可。

结论：算法成功返回时，格子是二进制、每列和正确、两行和也正确；算法拒绝的三种情况——强制列超额、下行无额度、最终额度未清零——都违反必要条件，因此不存在可行解。

边界与复杂度

  • upper = lower = 0：只有全零列才能成功。
  • 全是 2：两行目标都必须等于列数。
  • 行和总量不等于 sum(colsum)：最终额度不会同时清零。
  • 时间复杂度 O(n)：两次线性扫描。
  • 返回矩阵占用 O(n) 空间；除返回值外额外空间为 O(1)。

替代方案与常见错误

计数式方案：先统计 2 的数量与 1 的数量，再检查 upper + lower = sum(colsum) 和两行容量，之后构造；本质相同。

容易踩坑：按原顺序单次扫描，先把一个 1 列给上行，再遇到必须两行都放的 2 列，可能误判无解；因此必须预留强制列。

另一个错误：只检查 upper 与 lower 没有变负，却忘记检查最后是否都归零。

class Solution {
    public List<List<Integer>> reconstructMatrix(int upper, int lower, int[] colsum) {
        Integer[] top = new Integer[colsum.length];
        Integer[] bottom = new Integer[colsum.length];
        Arrays.fill(top, 0);
        Arrays.fill(bottom, 0);

        for (int i = 0; i < colsum.length; i++) {
            if (colsum[i] == 2) {
                top[i] = 1;
                bottom[i] = 1;
                upper--;
                lower--;
            }
        }
        if (upper < 0 || lower < 0) return new ArrayList<>();

        for (int i = 0; i < colsum.length; i++) {
            if (colsum[i] == 1) {
                if (upper > 0) {
                    top[i] = 1;
                    upper--;
                } else if (lower > 0) {
                    bottom[i] = 1;
                    lower--;
                } else {
                    return new ArrayList<>();
                }
            }
        }
        if (upper != 0 || lower != 0) return new ArrayList<>();
        return Arrays.asList(Arrays.asList(top), Arrays.asList(bottom));
    }
}

面试追问

能否一次扫描？

可以先统计或先知道所有 2 列数量后再构造；若完全不预知后续强制列，朴素单次贪心会误判。也可先依据计数校验，再做一次构造扫描。

如果扩展到 k 行？

每列和不再只对应两种局部选择，简单贪心未必成立，通常需要流模型、匹配或更强的可行性条件。

如何最小化两行差异？

本题行和已经固定；若行和不固定，可把和为 1 的列尽量均衡分配。

能否原地复用 colsum？

返回两行仍需 O(n) 空间；修改输入会降低可读性，且不改变渐进空间复杂度。
