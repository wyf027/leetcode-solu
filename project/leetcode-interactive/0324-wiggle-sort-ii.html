给定整数数组 nums，请原地重新排列，使其满足严格交替关系：

nums[0] < nums[1] > nums[2] < nums[3] > …

Solution · Sort & Weave

排序后，逆序切半再交错

稳妥实现选用 O(n log n) 排序与 O(n) 辅助数组；进阶方案另作比较。

核心洞察

1 · 分区

排序后，前 ceil(n/2) 个数作为低半区，其余数作为高半区。

2 · 反向

两个半区都从大到小取数，避免相同元素在分界附近相邻碰撞。

3 · 编织

低半区依次放偶数下标，高半区依次放奇数下标，让奇数位成为峰。

统一下标公式

设升序副本为 a，mid = (n + 1) / 2。偶数位读取 a[mid - 1 - i/2]，奇数位读取 a[n - 1 - i/2]。

完整过程

  1. 复制并排序。 对 nums 的副本升序排序，原数组留作最终写入。
  2. 确定低半区大小。 取 mid = (n + 1) / 2，奇数长度时让低半区多一个元素。
  3. 设置两个逆向指针。 left = mid - 1 指向低半区最大值，right = n - 1 指向全局最大值。
  4. 交错写回。 从下标 0 开始：偶数下标写 a[left--]，奇数下标写 a[right--]。
  5. 完成。 数组已经原地变为 低 < 高 > 低 < 高… 的严格摆动序列。

正确性说明

引理 1：峰值来自高半区

每个奇数位都取自排序数组的高半区，每个偶数位都取自低半区。因此峰位候选不会小于谷位候选。

引理 2：逆序错开重复值

两半均从大到小消费，使分界处的重复值被尽量拉开。若某对相邻峰谷仍只能相等，就意味着该重复值占据了无法分隔的位置，与题目“存在严格摆动答案”的保证矛盾。

引理 3：每个峰覆盖两侧

奇数位 2k+1 的高半区元素，分别大于左侧偶数位 2k 和存在时的右侧偶数位 2k+2。

结论

所有相邻对依次满足 <, >, <, >…，且每个元素恰好写入一次，所以输出既是原多重集合的排列，也是合法摆动序列。

复杂度

  • 时间：O(n log n)，主要来自排序；交错写回为 O(n)。
  • 空间：O(n)，保存排序副本；不计语言排序内部开销。

边界情况

  • n = 1：没有相邻不等式，直接保持不变。
  • 奇数长度：低半区多取一个元素，最后一个谷位仍有数可放。
  • 含大量重复值：必须逆序取两半，不能直接升序交错。
  • 答案不唯一：判定应检查摆动关系与元素频次，而非固定数组。

Javaclass Solution
import java.util.Arrays;

class Solution {
    public void wiggleSort(int[] nums) {
        int n = nums.length;
        int[] sorted = nums.clone();
        Arrays.sort(sorted);

        int left = (n + 1) / 2 - 1;
        int right = n - 1;

        for (int i = 0; i < n; i++) {
            if ((i & 1) == 0) {
                nums[i] = sorted[left--];
            } else {
                nums[i] = sorted[right--];
            }
        }
    }
}

var wiggleSort = function(nums) {
    const sorted = [...nums].sort((a, b) => a - b);
    let left = Math.floor((nums.length + 1) / 2) - 1;
    let right = nums.length - 1;

    for (let i = 0; i < nums.length; i += 1) {
        if (i % 2 === 0) {
            nums[i] = sorted[left];
            left -= 1;
        } else {
            nums[i] = sorted[right];
            right -= 1;
        }
    }
};

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    void wiggleSort(vector<int>& nums) {
        vector<int> sorted(nums);
        sort(sorted.begin(), sorted.end());

        int left = (static_cast<int>(nums.size()) + 1) / 2 - 1;
        int right = static_cast<int>(nums.size()) - 1;

        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            nums[i] = (i % 2 == 0) ? sorted[left--] : sorted[right--];
        }
    }
};

替代方案

  • 快速选择 + 虚拟下标：先找中位数，再按 (1 + 2i) % (n | 1) 映射做三向划分；期望 O(n) 时间、O(1) 额外空间，但实现更难。
  • 计数法：值域仅到 5000，可计数后从大到小填奇数位、再填偶数位；复杂度 O(n + V)，空间 O(V)。
  • 直接排序后相邻交换：对非严格 Wiggle Sort 常见，但面对重复值时不能保证本题的严格不等式。

常见错误

  • 两个半区按升序直接交错，导致分界处的相同元素相邻。
  • 奇数长度使用 n / 2 作为低半区大小，最后少一个谷值。
  • 只验证 <= / >=，漏掉本题要求的严格 < / >。
  • 返回新数组却没有修改传入的 nums。
  • 把某个示例输出当成唯一答案进行断言。
