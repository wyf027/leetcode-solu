LCR 087 · MEDIUM

复原 IP 地址

给定只包含数字的字符串，插入三个点把它还原为所有可能的有效 IPv4 地址。每段范围为 0 到 255，且不能有前导零。

题意

合法 IPv4 地址恰有四段。每段由 1 到 3 个数字组成，数值不超过 255；如 "0" 合法，"00" 和 "01" 不合法。

示例

"25525511135" → ["255.255.11.135","255.255.111.35"]

"0000" → ["0.0.0.0"]

约束

1 ≤ s.length ≤ 20；s 只包含数字字符。

分步交互：回溯切分

依次选择每段的 1、2 或 3 个字符，非法分段立即剪枝。

准备就绪。

核心洞察

四段 IP 的结构固定，因此只需深度优先搜索四层。每层尝试截取 1 到 3 位；遇到前导零或数值大于 255 时停止扩展。剩余字符数与剩余段数不匹配时也可提前剪枝。

完整过程

  1. 维护当前位置 index、已选段数及当前路径。
  2. 若段数已为 4，仅当字符串恰好用完时记录一个答案。
  3. 尝试 1 至 3 位子串；验证后加入路径、递归、再回退。

边界

  • 长度小于 4 或大于 12 时无解。
  • "0" 可作为一段，但以 0 开头的多位数不可用。
  • 选满四段却仍有剩余字符时不能记录答案。

复杂度

深度固定为 4，每层最多 3 个分支，搜索量有常数上界；额外空间为递归栈与路径的 O(1)（不计答案）。

替代方案与追问

可用三重循环枚举三个点的位置，但回溯更容易加入剪枝与泛化。追问：若要复原 IPv6，段数、十六进制规则和压缩写法都不同，应另行解析，不能套用 IPv4 的 1–3 位限制。

常见错误

  • 允许 "00"、"01" 等前导零段。
  • 只验证数值，忘记限制每段最多 3 位。
  • 未在递归返回后移除最后一段。

// Java
class Solution { List<String> ans=new ArrayList<>(); public List<String> restoreIpAddresses(String s){dfs(s,0,new ArrayList<>());return ans;} void dfs(String s,int i,List<String> p){if(p.size()==4){if(i==s.length())ans.add(String.join(".",p));return;}for(int l=1;l<=3&&i+l<=s.length();l++){String x=s.substring(i,i+l);if((x.length()>1&&x.charAt(0)=='0')||Integer.parseInt(x)>255)break;p.add(x);dfs(s,i+l,p);p.remove(p.size()-1);}} }

# Python
class Solution:
    def restoreIpAddresses(self, s: str) -> list[str]:
        ans = []
        def dfs(i, path):
            if len(path) == 4:
                if i == len(s): ans.append('.'.join(path))
                return
            for length in range(1, 4):
                part = s[i:i+length]
                if not part or (len(part)>1 and part[0]=='0') or int(part)>255: break
                dfs(i+length, path+[part])
        dfs(0, []); return ans
