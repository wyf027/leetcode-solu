实现 MapSum 类，将字符串键映射到整数值，并能返回所有键名以给定前缀开头的键值之和。

  • int sum(String prefix)：返回所有以 prefix 开头的键对应值的总和。

输入：

解释：插入 apple → 3 后，前缀 ap 的和为 3；再插入 app → 2，同一前缀下两项相加得到 5。

SOLUTION UNLOCKED

字典树维护前缀和

哈希表记旧值，字典树记路径累计值。

核心洞察

每个前缀天然对应字典树中的一个节点。若节点直接保存“经过它的所有完整键之值的总和”，查询只需走完前缀路径并读取该节点。

delta = newValue - oldValue
node.sum += delta

另用哈希表记录每个完整键的当前值。覆盖时不重复累加新值，而是把差量 delta 加到整条路径。

完整过程

  1. 初始化根节点与 values 哈希表。
  2. 插入时从哈希表取旧值，计算新旧差量。
  3. 更新哈希表，再沿键的字符路径创建或访问节点。
  4. 路径上的每个节点都把累计和增加该差量。
  5. 查询时沿前缀移动；路径缺失返回 0，否则返回终点累计和。

正确性说明

不变式：任意字典树节点 u 的 sum，始终等于所有以根到 u 的路径字符串为前缀的当前键值之和。

  1. 初始：没有键，所有累计和为 0，不变式成立。
  2. 插入新键：旧值为 0，沿该键路径增加 val；恰好让该键贡献到其所有前缀节点。
  3. 覆盖旧键：沿相同路径增加 new - old；节点总贡献由旧值准确替换为新值，其他键不受影响。
  4. 查询：若前缀路径不存在，没有匹配键，答案为 0；否则根据不变式，终点 sum 正是所有匹配键之和。

因此每次 sum(prefix) 都返回题目要求的结果。

边界情况

  • 查询前缀不存在：返回 0。
  • 前缀本身也是完整键：该键与更长匹配键都应计入。
  • 同一键反复覆盖：必须使用差量，不能直接累加新值。
  • 一个键是另一个键的前缀：两个值都贡献到短键对应节点。
  • 只有一个字符的键或前缀：处理方式不变。

复杂度

设键长度为 K，查询前缀长度为 P。

  • insert：时间 O(K)。
  • sum：时间 O(P)。
  • 空间：O(T + N)，其中 T 是字典树节点数，N 是不同键数；最坏可写作 O(所有不同键长度之和)。

替代方案

  • 纯哈希表扫描：插入 O(1)，每次查询遍历全部键并检查前缀，约 O(N·L)。调用上限只有 50 时也能接受，实现最简单。
  • 预存所有前缀的哈希表：插入 O(K)，查询 O(1)；同样要用差量处理覆盖，但会为每个前缀保存条目。
  • 标准字典树 + 查询 DFS：插入 O(K)，查询需要遍历前缀子树；不如在节点上维护累计和直接。

面试追问

  • 如何支持删除？把新值视为 0，沿路径加 -oldValue，必要时回收空节点。
  • 字符集扩大到 Unicode 怎么办？子节点从固定 26 数组改为哈希映射。
  • 若需要返回匹配键本身？节点还要保存终止标记，查询后遍历子树收集。
  • 如何处理并发更新？需要对哈希表和路径更新提供同一原子边界。

常见错误

  • 覆盖键时直接把新值再次累加，导致旧值残留。
  • 只在叶节点记录值，查询仍被迫遍历整棵子树。
  • 前缀路径缺失后继续访问空节点。
  • 把“前缀相等”误写成“键与前缀完全相等”。
  • 忘记完整键也可以是另一个键的前缀。
import java.util.HashMap;
import java.util.Map;

class MapSum {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        int sum;
    }

    private final TrieNode root;
    private final Map<String, Integer> values;

    public MapSum() {
        root = new TrieNode();
        values = new HashMap<>();
    }

    public void insert(String key, int val) {
        int oldValue = values.getOrDefault(key, 0);
        int delta = val - oldValue;
        values.put(key, val);

        TrieNode node = root;
        for (char ch : key.toCharArray()) {
            int index = ch - 'a';
            if (node.children[index] == null) {
                node.children[index] = new TrieNode();
            }
            node = node.children[index];
            node.sum += delta;
        }
    }

    public int sum(String prefix) {
        TrieNode node = root;
        for (char ch : prefix.toCharArray()) {
            int index = ch - 'a';
            if (node.children[index] == null) {
                return 0;
            }
            node = node.children[index];
        }
        return node.sum;
    }
}
var MapSum = function() {
    this.root = { children: new Map(), sum: 0 };
    this.values = new Map();
};

/**
 * @param {string} key
 * @param {number} val
 * @return {void}
 */
MapSum.prototype.insert = function(key, val) {
    const oldValue = this.values.get(key) ?? 0;
    const delta = val - oldValue;
    this.values.set(key, val);

    let node = this.root;
    for (const ch of key) {
        if (!node.children.has(ch)) {
            node.children.set(ch, { children: new Map(), sum: 0 });
        }
        node = node.children.get(ch);
        node.sum += delta;
    }
};

/**
 * @param {string} prefix
 * @return {number}
 */
MapSum.prototype.sum = function(prefix) {
    let node = this.root;
    for (const ch of prefix) {
        if (!node.children.has(ch)) {
            return 0;
        }
        node = node.children.get(ch);
    }
    return node.sum;
};
class TrieNode:
    def __init__(self):
        self.children = {}
        self.total = 0


class MapSum:
    def __init__(self):
        self.root = TrieNode()
        self.values = {}

    def insert(self, key: str, val: int) -> None:
        old_value = self.values.get(key, 0)
        delta = val - old_value
        self.values[key] = val

        node = self.root
        for ch in key:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
            node.total += delta

    def sum(self, prefix: str) -> int:
        node = self.root
        for ch in prefix:
            if ch not in node.children:
                return 0
            node = node.children[ch]
        return node.total
#include <array>
#include <memory>
#include <string>
#include <unordered_map>
using namespace std;

class MapSum {
    struct TrieNode {
        array<unique_ptr<TrieNode>, 26> children{};
        int sum = 0;
    };

    TrieNode root;
    unordered_map<string, int> values;

public:
    MapSum() = default;

    void insert(string key, int val) {
        int oldValue = values.count(key) ? values[key] : 0;
        int delta = val - oldValue;
        values[key] = val;

        TrieNode* node = &root;
        for (char ch : key) {
            int index = ch - 'a';
            if (!node->children[index]) {
                node->children[index] = make_unique<TrieNode>();
            }
            node = node->children[index].get();
            node->sum += delta;
        }
    }

    int sum(string prefix) {
        TrieNode* node = &root;
        for (char ch : prefix) {
            int index = ch - 'a';
            if (!node->children[index]) {
                return 0;
            }
            node = node->children[index].get();
        }
        return node->sum;
    }
};
