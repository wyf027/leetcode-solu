安排邮筒

一条街、若干栋房子、恰好 k 个邮筒。怎样让所有居民取信的总路程最短？

Problem

题目

函数签名：minDistance(houses, k)，返回一个整数。

给定整数数组 houses，其中每个元素表示一栋房子在同一条街上的坐标；再给定整数 k。请在街上设置恰好 k 个邮筒，使每栋房子到最近邮筒的距离之和最小，并返回这个最小值。答案保证落在 32 位有符号整数范围内。

示例 1

输入：houses = [1,4,8,10,20], k = 3
输出：5
解释：邮筒可放在 3、9、20。
总距离 = |1-3| + |4-3| + |8-9|
       + |10-9| + |20-20| = 5

示例 2

输入：houses = [2,3,5,12,18], k = 2
输出：9
解释：邮筒可放在 3、14。
总距离 = |2-3| + |3-3| + |5-3|
       + |12-14| + |18-14| = 9

示例 3

输入：houses = [7,4,6,1], k = 1
输出：8

示例 4

输入：houses = [3,6,14,10], k = 4
输出：0

约束

  • 1 ≤ n ≤ 100
  • 1 ≤ houses[i] ≤ 10⁴
  • 1 ≤ k ≤ n
  • houses 中的位置互不相同

题解：区间代价 + 分组动态规划

核心洞察完整过程正确性边界复杂度替代方案代码追问与错误测试与验证

核心洞察

01
一个邮筒服务一段连续房屋时，放在中位数位置最优。

将坐标排序。对区间 [i..j]，把邮筒放到中位房屋的位置，可最小化绝对距离之和。

02
全局最优解可以视为把有序房屋切成 k 个连续段。

若两个邮筒负责的房屋在顺序上交叉，交换负责关系不会增大距离。因此只需枚举连续分段。

03
预处理每一段的单邮筒代价，再做分组动态规划。

令 cost[i][j] 是区间 i..j 只放一个邮筒的最小距离；令 dp[g][i] 是前 i 栋房用 g 个邮筒的最小代价。

完整过程

  1. 升序排列 houses。
  2. 预处理所有 cost[i][j]。直接对中位数求和是 O(n³)；利用递推 cost[i][j] = cost[i+1][j-1] + houses[j] - houses[i] 可在 O(n²) 内完成。
  3. 初始化 dp[0][0] = 0，其余为无穷大。
  4. 枚举邮筒数 g = 1..k、已覆盖房屋数 i，再枚举最后一段起点 p。前 p 栋由 g-1 个邮筒覆盖，区间 p..i-1 由最后一个邮筒覆盖。
  5. 答案是 dp[k][n]。
dp[g][i] = min(dp[g - 1][p] + cost[p][i - 1])，其中 g - 1 ≤ p < i

示例一的最佳切分之一是 [1,4] | [8,10] | [20]，三段代价依次为 3、2、0，总计 5。

正确性证明

引理 1：中位数最优对于有序区间，邮筒从左向右移动时，左侧距离总增量与右侧距离总减量在中位数处取得平衡，因此绝对距离和在中位数处最小。
引理 2：最优负责区间连续街道是一维有序空间。若较左房屋分给较右邮筒、较右房屋分给较左邮筒，交换两者不会使总距离增大。反复消除交叉后，每个邮筒负责连续的一段房屋。
定理：状态转移完备且最优任一前 i 栋房、g 个邮筒的最优解都有某个最后分界点 p。其前缀必须是对应子问题的最优解，否则可替换为更优前缀；末段代价为 cost[p][i-1]。转移枚举所有 p，故既不遗漏最优解，也不会产生更小但不可行的值。

边界处理

  • k == n：每栋房旁放一个邮筒，答案为 0。
  • k == 1：答案就是全部房屋到整体中位数的距离和。
  • 输入可能无序，必须先排序；坐标互不相同，但算法不依赖这一点。
  • 偶数长度区间有两个中位数位置，区间中两者之间的任意点都最优；代码选其中一个房屋坐标即可。
  • DP 中不允许用多于房屋数量的邮筒覆盖前缀，因此循环边界从 g 开始。

复杂度

时间O(k · n²)

区间代价 O(n²)，DP 为 O(k·n²)。

空间O(n² + k·n)

保存区间代价与完整 DP 表；DP 可滚动到 O(n)。

替代方案

  • 直接计算区间代价：对每个 [i..j] 向中位数求和，代码直观但预处理为 O(n³)；在 n ≤ 100 时仍可能通过，不过不如二次递推干净。
  • 记忆化搜索：状态设为“从第 i 栋开始、还剩 g 个邮筒”，枚举下一段终点。与迭代 DP 等价，更贴近递归分段思维。
  • 滚动数组：只保留上一层和当前层 DP，把额外空间从 O(k·n) 降到 O(n)，区间代价表仍为 O(n²)。

四语言完整代码

Java · LeetCode 可提交O(k·n²)
import java.util.Arrays;

class Solution {
    public int minDistance(int[] houses, int k) {
        Arrays.sort(houses);
        int n = houses.length;
        int[][] cost = new int[n][n];

        for (int len = 2; len <= n; len++) {
            for (int left = 0; left + len - 1 < n; left++) {
                int right = left + len - 1;
                cost[left][right] = houses[right] - houses[left];
                if (left + 1 <= right - 1) {
                    cost[left][right] += cost[left + 1][right - 1];
                }
            }
        }

        int inf = 1_000_000_000;
        int[][] dp = new int[k + 1][n + 1];
        for (int[] row : dp) Arrays.fill(row, inf);
        dp[0][0] = 0;

        for (int used = 1; used <= k; used++) {
            for (int covered = used; covered <= n; covered++) {
                for (int split = used - 1; split < covered; split++) {
                    if (dp[used - 1][split] != inf) {
                        dp[used][covered] = Math.min(
                            dp[used][covered],
                            dp[used - 1][split] + cost[split][covered - 1]
                        );
                    }
                }
            }
        }
        return dp[k][n];
    }
}

from typing import List


class Solution:
    def minDistance(self, houses: List[int], k: int) -> int:
        houses.sort()
        n = len(houses)
        cost = [[0] * n for _ in range(n)]

        for length in range(2, n + 1):
            for left in range(n - length + 1):
                right = left + length - 1
                cost[left][right] = houses[right] - houses[left]
                if left + 1 <= right - 1:
                    cost[left][right] += cost[left + 1][right - 1]

        inf = float("inf")
        dp = [[inf] * (n + 1) for _ in range(k + 1)]
        dp[0][0] = 0

        for used in range(1, k + 1):
            for covered in range(used, n + 1):
                for split in range(used - 1, covered):
                    dp[used][covered] = min(
                        dp[used][covered],
                        dp[used - 1][split] + cost[split][covered - 1],
                    )

        return dp[k][n]
C++ · LeetCode 可提交O(k·n²)
class Solution {
public:
    int minDistance(vector<int>& houses, int k) {
        sort(houses.begin(), houses.end());
        int n = houses.size();
        vector<vector<int>> cost(n, vector<int>(n, 0));

        for (int len = 2; len <= n; ++len) {
            for (int left = 0; left + len - 1 < n; ++left) {
                int right = left + len - 1;
                cost[left][right] = houses[right] - houses[left];
                if (left + 1 <= right - 1) {
                    cost[left][right] += cost[left + 1][right - 1];
                }
            }
        }

        const int INF = 1e9;
        vector<vector<int>> dp(k + 1, vector<int>(n + 1, INF));
        dp[0][0] = 0;

        for (int used = 1; used <= k; ++used) {
            for (int covered = used; covered <= n; ++covered) {
                for (int split = used - 1; split < covered; ++split) {
                    if (dp[used - 1][split] != INF) {
                        dp[used][covered] = min(
                            dp[used][covered],
                            dp[used - 1][split] + cost[split][covered - 1]
                        );
                    }
                }
            }
        }
        return dp[k][n];
    }
};

面试追问与常见错误

可能追问

  • 为什么每个邮筒负责的房屋一定能构成连续段？
  • 如何把 DP 空间优化到 O(n)？
  • 若距离改为平方距离，邮筒应该放在哪里？（均值附近，而非中位数。）
  • 如果要求输出邮筒位置和具体分组，如何恢复路径？（记录每个状态的最优分界点。）

常见错误

  • 忘记排序，导致“连续区间”失去空间意义。
  • 把邮筒固定在区间平均数；绝对距离应使用中位数。
  • 状态下标混用“最后房屋下标”和“已覆盖数量”，产生一位偏移。
  • 允许空分组或在前 i 栋上使用超过 i 个邮筒。
  • 用过小的无穷大，转移相加后错误溢出。
