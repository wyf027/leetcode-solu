2055. 蜡烛之间的盘子

Plates Between Candles

一排餐具，一个闭区间。只数左右都有蜡烛的盘子。

官方题目 ↗先独立思考，再展开底部题解

题目说明

给定字符串 s，* 表示盘子，| 表示蜡烛，所有下标从 0 开始。每个查询 queries[i] = [leftᵢ, rightᵢ] 指定一个包含两端的子串。

对每个查询，计算该子串内满足条件的盘子数：它的左侧和右侧都至少存在一支同样位于子串内的蜡烛。返回整数数组 answer，按原查询顺序存放结果。两侧蜡烛不必紧邻盘子。

例如 s = "||**||**|*"，查询 [3,8] 的子串为 *||**|，只有后面的两个盘子满足条件，答案为 2。区间外的蜡烛不能参与判断。

官方示例

示例 1

s = "**|**|***|"
queries = [[2,5],[5,9]]
输出 = [2,3]

第一个区间中有 2 个符合条件的盘子，第二个有 3 个。

示例 2

s = "***|**|*****|**||**|*"
queries = [[1,17],[4,5],[14,17],[5,11],[15,16]]
输出 = [9,0,0,0,0]

第一个查询得到 9；其余四个查询都没有符合条件的盘子。

约束

  • 3 ≤ s.length ≤ 10⁵。
  • s 仅包含 * 与 |。
  • 1 ≤ queries.length ≤ 10⁵。
  • queries[i].length == 2。
  • 0 ≤ leftᵢ ≤ rightᵢ < s.length。

题解 · 将边界收缩到蜡烛

核心洞察

对区间 [l,r]，令 a 为区间内最左边的蜡烛，b 为最右边的蜡烛。所有合法盘子恰好处于 a 与 b 之间。只需快速找到这两个边界，再查询其中的盘子总数。

完整过程与数组约定

  1. 建立长度 n+1 的盘子前缀和：P[0]=0，P[i+1]=P[i]+(s[i]=='*')。P[k] 统计半开区间 [0,k)。
  2. 从左向右扫描，记录 L[i]：下标不超过 i 的最近蜡烛，没有则为 -1。
  3. 从右向左扫描，记录 R[i]：下标不小于 i 的最近蜡烛，没有则为 -1。
  4. 每个查询取 a=R[l]、b=L[r]。若任何一个不存在或 a≥b，答案为 0。
  5. 否则答案是 P[b]-P[a]，即半开区间 [a,b) 的盘子数。a 本身是蜡烛，不贡献盘子，因此与严格位于两个边界之间的计数一致。

以 s="**|**|***|"、[2,9] 为例：a=2,b=9，P[9]=7,P[2]=2，所以答案为 7-2=5。

正确性说明

辅助数组：正向扫描在每个位置保留最近一次遇到的蜡烛，因此 L 正确；反向同理得到 R。前缀和递推每次只加入当前是否为盘子，所以 P 正确。

必要性：任意合法盘子都有区间内的左、右蜡烛。它必在最左蜡烛 a 的右边、最右蜡烛 b 的左边，因此不会落在所计范围以外。

充分性：任何处于 a 与 b 之间的盘子，都可直接用 a 和 b 作为两侧蜡烛，所以一定合法。两集合相同，前缀和之差恰好计算答案。若边界缺失或 a≥b，区间内没有两支不同蜡烛，返回 0 正确。

边界与常见错误

  • 没有蜡烛、只有一支蜡烛、单点区间均返回 0。
  • 相邻蜡烛和全蜡烛串可能有两个有效边界，但盘子数仍是 0。
  • 不能直接用 P[r+1]−P[l]，否则会包含边缘未被蜡烛包围的盘子。
  • 左端要向右找蜡烛，右端要向左找；方向写反会使用区间外的蜡烛。
  • 先判断 -1 再访问数组；统一半开前缀定义，避免 off-by-one。

复杂度与替代方案

设字符串长度为 n，查询数为 q。预处理 O(n)，每次查询 O(1)，总时间 O(n+q)。辅助空间 O(n)，输出另占 O(q)。

替代方案：保存所有蜡烛下标，用两次二分找到查询内的边界，再用前缀和计数，总时间 O(n+q log n)。也可仅用蜡烛下标：若两个边界在蜡烛数组中的位置为 u、v，则盘子数为 (b-a)-(v-u)，省去盘子前缀数组。

逐查询扫描最直接，但最坏 O(nq)，不适合十万规模。

面试追问

  • 字符允许动态修改？静态前缀和与最近蜡烛数组会失效。可用线段树维护盘子数及区间最左、最右蜡烛，更新和查询都在 O(log n) 内完成。
  • 只做一次查询？直接扫描该区间，时间 O(r−l+1)、额外空间 O(1)，无需预处理整个字符串。
  • 为什么不用滑动窗口？查询端点不保证单调，无法自然复用窗口；静态预处理更直接。

Java

class Solution {
    public int[] platesBetweenCandles(String s, int[][] queries) {
        int n = s.length();
        int[] prefix = new int[n + 1];
        int[] left = new int[n], right = new int[n];
        int last = -1;
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + (s.charAt(i) == '*' ? 1 : 0);
            if (s.charAt(i) == '|') last = i;
            left[i] = last;
        }
        last = -1;
        for (int i = n - 1; i >= 0; i--) {
            if (s.charAt(i) == '|') last = i;
            right[i] = last;
        }
        int[] answer = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int a = right[queries[i][0]], b = left[queries[i][1]];
            if (a != -1 && b != -1 && a < b) {
                answer[i] = prefix[b] - prefix[a];
            }
        }
        return answer;
    }
}

var platesBetweenCandles = function(s, queries) {
    const n = s.length;
    const prefix = new Array(n + 1).fill(0);
    const left = new Array(n), right = new Array(n);
    let last = -1;
    for (let i = 0; i < n; i++) {
        prefix[i + 1] = prefix[i] + (s[i] === '*' ? 1 : 0);
        if (s[i] === '|') last = i;
        left[i] = last;
    }
    last = -1;
    for (let i = n - 1; i >= 0; i--) {
        if (s[i] === '|') last = i;
        right[i] = last;
    }
    return queries.map(([l, r]) => {
        const a = right[l], b = left[r];
        return a !== -1 && b !== -1 && a < b
            ? prefix[b] - prefix[a] : 0;
    });
};

from typing import List

class Solution:
    def platesBetweenCandles(self, s: str, queries: List[List[int]]) -> List[int]:
        n = len(s)
        prefix = [0] * (n + 1)
        left, right = [-1] * n, [-1] * n
        last = -1
        for i, ch in enumerate(s):
            prefix[i + 1] = prefix[i] + (ch == '*')
            if ch == '|':
                last = i
            left[i] = last
        last = -1
        for i in range(n - 1, -1, -1):
            if s[i] == '|':
                last = i
            right[i] = last
        answer = []
        for l, r in queries:
            a, b = right[l], left[r]
            answer.append(prefix[b] - prefix[a]
                          if a != -1 and b != -1 and a < b else 0)
        return answer

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> platesBetweenCandles(string s, vector<vector<int>>& queries) {
        int n = s.size();
        vector<int> prefix(n + 1, 0), left(n, -1), right(n, -1);
        int last = -1;
        for (int i = 0; i < n; ++i) {
            prefix[i + 1] = prefix[i] + (s[i] == '*');
            if (s[i] == '|') last = i;
            left[i] = last;
        }
        last = -1;
        for (int i = n - 1; i >= 0; --i) {
            if (s[i] == '|') last = i;
            right[i] = last;
        }
        vector<int> answer;
        answer.reserve(queries.size());
        for (const auto& query : queries) {
            int a = right[query[0]], b = left[query[1]];
            answer.push_back(a != -1 && b != -1 && a < b
                             ? prefix[b] - prefix[a] : 0);
        }
        return answer;
    }
};
