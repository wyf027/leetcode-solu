重新排列字符串以避免字符对

把 y 放到所有 x 的前面；其他字符可以维持自己的相对次序。

题意

给定小写字符串 s 和两个不同字符 x、y。重排 s 得到任意排列 t，要求 每一个 y 都出现在每一个 x 之前。

示例 1

s = "aabc"
x = "a"，y = "c"
一种输出：t = "cbaa"

示例 2

s = "dcab"
x = "d"，y = "b"
一种输出：t = "bcad"

约束：1 ≤ s.length ≤ 100；s 只含小写字母；x ≠ y。

可视化：三条队列再拼接

从左到右扫描：先收集 y，中间收集既不是 x 也不是 y 的字符，最后收集 x。输出 Y + middle + X 必然合法。

队列 Y

所有 y

中间队列

其余字符

队列 X

所有 x

题解：稳定的三段拼接

1

识别唯一的强制顺序

唯一约束是 y 必须全在 x 前；其他字符没有相对位置要求。

2

一次扫描分类

每个字符恰好进入 ys、middle、xs 三个字符串之一。

3

拼接得到答案

ys + middle + xs 保留了所有字符，且第一个 x 之前已经放完全部 y。

边界

x 或 y 不出现时，原串也可合法；三段拼接仍自然处理。

复杂度

时间 O(n)，输出与暂存空间 O(n)。

替代方案

可直接排序并定制比较器，但排序是 O(n log n)，且没必要改变其他字符顺序。

常见错误

只交换遇到的一对 x/y 不能保证全局顺序；也不要遗漏中间字符。

面试追问：若要求最少交换次数，应先确定目标位置，再比较当前 x/y 的错位；那是不同于本题“任意有效排列”的优化问题。
