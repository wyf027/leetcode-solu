题解闸门

核心洞察

定义 dp[i] 表示前 i 个字符 s[0..i) 能否被字典单词完整拆分。若存在一个已经可达的站点 j，且 s[j..i) 在字典中，那么站点 i 也可达。

dp[0] = true dp[i] = ∃ j < i: dp[j] && wordDict.contains(s[j..i))

完整过程

  1. 把字典放进哈希集合，并统计最长单词长度。
  2. 令 dp[0] 为 true，表示空前缀可达。
  3. 依次计算 i=1..n，只从 max(0, i-maxLen) 枚举 j。
  4. 遇到 dp[j] 为真且子串命中字典，就令 dp[i] 为真并结束本轮。
  5. 返回 dp[n]。

复杂度

  • 时间：常规表述 O(n²)，子串构造成本因语言而异；最大词长优化能减少无效枚举。
  • 空间：O(n + m)，dp 数组加字典集合，m 为字典总字符量。

替代方案取舍

记忆化 DFS 与 DP 本质相同，写法贴近“从当前位置试单词”；BFS 把索引看成图节点，也很自然。Trie 可减少重复子串查询，但实现更重。面试主线优先一维 DP：状态定义和证明最直接。

边界

  • 同一个单词可以反复使用，例如 apple 出现两次。
  • 值相同的前缀可能由多种切分方式到达，只需记录可达性。
  • 不能用最长匹配贪心；cars 选 car 会失败，但 ca + rs 成功。
  • 只在 dp[j] 为真时检查从 j 出发的单词，否则线路没有接通。

常见错误

  • 把 dp 数组长度写成 n，漏掉空前缀 dp[0]。
  • 子串边界混淆，把右端 i 当成包含端点。
  • 找到字典单词却没检查 dp[j]，拼接到不可达前缀上。
  • 用贪心选最长单词，遇到需要回退的用例即失败。

面试追问

  • 为什么 dp[0] 必须为 true？ 它是第一段单词能从索引 0 出发的逻辑起点。
  • 如何返回一种具体切分？ 额外记录 prev[i]=j，成功后从 n 反向恢复区间。
  • 如何返回所有切分？ 保存每个 i 的所有前驱，再做回溯；结果规模可能指数级。
  • 字典很大时怎么优化？ Trie、按首字母分桶或按长度分组，减少无效查询。

class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> words = new HashSet<>(wordDict);
        int maxLen = 0;
        for (String word : wordDict) {
            maxLen = Math.max(maxLen, word.length());
        }

        boolean[] dp = new boolean[s.length() + 1];
        dp[0] = true;
        for (int i = 1; i <= s.length(); i++) {
            for (int j = Math.max(0, i - maxLen); j < i; j++) {
                if (dp[j] && words.contains(s.substring(j, i))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[s.length()];
    }
}
var wordBreak = function (s, wordDict) {
  const words = new Set(wordDict);
  const maxLen = Math.max(...wordDict.map((word) => word.length));
  const dp = Array(s.length + 1).fill(false);
  dp[0] = true;

  for (let i = 1; i <= s.length; i += 1) {
    for (let j = Math.max(0, i - maxLen); j < i; j += 1) {
      if (dp[j] && words.has(s.slice(j, i))) {
        dp[i] = true;
        break;
      }
    }
  }
  return dp[s.length];
};
class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)
        max_len = max(map(len, wordDict))
        dp = [False] * (len(s) + 1)
        dp[0] = True

        for i in range(1, len(s) + 1):
            for j in range(max(0, i - max_len), i):
                if dp[j] and s[j:i] in words:
                    dp[i] = True
                    break
        return dp[len(s)]
class Solution {
public:
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> words(wordDict.begin(), wordDict.end());
        int maxLen = 0;
        for (const string& word : wordDict) {
            maxLen = max(maxLen, static_cast<int>(word.size()));
        }

        vector<bool> dp(s.size() + 1, false);
        dp[0] = true;
        for (int i = 1; i <= static_cast<int>(s.size()); i++) {
            for (int j = max(0, i - maxLen); j < i; j++) {
                if (dp[j] && words.count(s.substr(j, i - j))) {
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[s.size()];
    }
};
