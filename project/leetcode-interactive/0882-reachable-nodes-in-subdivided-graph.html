细分图中的
可到达节点

不要真的展开最多上亿个新节点。把每条细分链压缩成一条带权边，用最短路判断原节点，再从两端“夹逼”统计链内节点。

Problem

题意

给定一个包含 n 个原始节点（编号 0...n-1）的无向图。每条记录 [u, v, cnt] 表示把原边替换成一条链：在端点之间插入 cnt 个新节点，因此整条链含 cnt + 1 条单位长度边。

从原节点 0 出发，最多走 maxMoves 步。请返回细分后的整张图中，距离不超过该步数的节点总数；计数同时包含原节点和新插入节点。

函数形式： reachableNodes(edges, maxMoves, n) → integer
示例 1
edges = [[0,1,10],[0,2,1],[1,2,2]] maxMoves = 6 n = 3

输出：13

可达的原节点与三条细分链上被覆盖的新节点合计 13 个。

示例 2
edges = [[0,1,4],[1,2,6], [0,2,8],[1,3,1]] maxMoves = 10 n = 4

输出：23

示例 3
edges = [[1,2,4],[1,4,5], [1,3,1],[2,3,4], [3,4,5]] maxMoves = 17 n = 5

输出：1

节点 0 与其余图断开，所以只有节点 0 可达。

约束

  • 0 ≤ edges.length ≤ min(n × (n - 1) / 2, 10⁴)
  • edges[i].length = 3，且 0 ≤ uᵢ < vᵢ < n
  • 图中不存在平行边；0 ≤ cntᵢ ≤ 10⁴
  • 0 ≤ maxMoves ≤ 10⁹，1 ≤ n ≤ 3000

Solution

Dijkstra + 两端覆盖计数

核心洞察：不建立任何新节点。边 [u,v,cnt] 在原节点图中视为权重 cnt+1；求出原节点最短距离后，端点 u 最多能沿链走入 max(0, maxMoves-dist[u]) 个新节点。

完整过程

  1. 建压缩图。每条原边的通行代价设为 cnt+1。
  2. 从 0 跑 Dijkstra。得到到每个原节点的最短距离 dist。
  3. 计原节点。所有满足 dist[i] ≤ maxMoves 的原节点各贡献 1。
  4. 逐边计新节点。令两端剩余步数为 a=max(0,M-dist[u])、b=max(0,M-dist[v])，该链贡献 min(cnt,a+b)。

正确性说明

引理 1：压缩图中走过边的代价是 cnt+1，与细分图中从一个原端点走到另一个原端点的真实距离完全相同。因此 Dijkstra 得到的原节点距离正确。

引理 2：从端点 u 可覆盖链首连续 a 个新节点，从 v 可覆盖链尾连续 b 个。两段的并集大小恰为 min(cnt,a+b)：未相遇时相加，相遇后最多覆盖全链。

结论：原节点与各条边内部的新节点互不重叠，分别正确计数后相加，即得到全部可达节点数。

复杂度与边界

  • 设原图节点数为 n、边数为 m。
  • 邻接表 + 二叉堆：时间 O((n+m) log n)，空间 O(n+m)。
  • maxMoves=0 时只有节点 0 可达。
  • 孤立点、空边集自然成立。
  • 距离可能超过 32 位整数；Java 用 long，JS Number 在本题范围安全。

常见错误

  • 把压缩边权写成 cnt，漏掉穿出链所需的最后一步。
  • 直接生成所有细分节点，时间与内存都会失控。
  • 每条边直接加 a+b，忘记用 cnt 截断。
  • 只从距离更短的一端统计，漏掉另一端可覆盖的链尾。
  • 用普通 BFS 处理不同权重的压缩边。

替代方案与面试追问

替代方案：可以用邻接矩阵实现朴素 Dijkstra，时间 O(n²+m)、空间 O(n²)；在 n=3000 时通常不如邻接表。若边权全相同才适合 BFS，本题不满足。

  • 为什么不需要记录“从每个方向使用了多少细分节点”？——最短距离直接确定每个端点的最大覆盖长度。
  • 若图是有向图如何改？——Dijkstra 建有向边，链内统计也只允许沿合法方向覆盖。
  • 如果多次查询不同 maxMoves？——可复用一次最短距离，但每次仍需扫描边；可进一步研究离线排序与分段函数。

import java.util.*;

class Solution {
    public int reachableNodes(int[][] edges, int maxMoves, int n) {
        List<int[]>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] e : edges) {
            int w = e[2] + 1;
            graph[e[0]].add(new int[]{e[1], w});
            graph[e[1]].add(new int[]{e[0], w});
        }

        long[] dist = new long[n];
        Arrays.fill(dist, Long.MAX_VALUE);
        dist[0] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(Comparator.comparingLong(a -> a[0]));
        pq.offer(new long[]{0, 0});

        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long d = cur[0];
            int u = (int) cur[1];
            if (d != dist[u]) continue;
            for (int[] next : graph[u]) {
                int v = next[0], w = next[1];
                if (d + w < dist[v]) {
                    dist[v] = d + w;
                    pq.offer(new long[]{dist[v], v});
                }
            }
        }

        long answer = 0;
        for (long d : dist) if (d <= maxMoves) answer++;
        for (int[] e : edges) {
            long fromU = dist[e[0]] <= maxMoves ? maxMoves - dist[e[0]] : 0;
            long fromV = dist[e[1]] <= maxMoves ? maxMoves - dist[e[1]] : 0;
            answer += Math.min((long) e[2], fromU + fromV);
        }
        return (int) answer;
    }
}
/**
 * @param {number[][]} edges
 * @param {number} maxMoves
 * @param {number} n
 * @return {number}
 */
var reachableNodes = function(edges, maxMoves, n) {
    const graph = Array.from({ length: n }, () => []);
    for (const [u, v, cnt] of edges) {
        const w = cnt + 1;
        graph[u].push([v, w]);
        graph[v].push([u, w]);
    }

    const dist = Array(n).fill(Infinity);
    dist[0] = 0;
    const heap = [[0, 0]];
    const push = item => {
        heap.push(item);
        let i = heap.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (heap[p][0] <= heap[i][0]) break;
            [heap[p], heap[i]] = [heap[i], heap[p]];
            i = p;
        }
    };
    const pop = () => {
        const root = heap[0], last = heap.pop();
        if (heap.length) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let s = i, l = i * 2 + 1, r = l + 1;
                if (l < heap.length && heap[l][0] < heap[s][0]) s = l;
                if (r < heap.length && heap[r][0] < heap[s][0]) s = r;
                if (s === i) break;
                [heap[s], heap[i]] = [heap[i], heap[s]];
                i = s;
            }
        }
        return root;
    };

    while (heap.length) {
        const [d, u] = pop();
        if (d !== dist[u]) continue;
        for (const [v, w] of graph[u]) {
            if (d + w < dist[v]) {
                dist[v] = d + w;
                push([dist[v], v]);
            }
        }
    }

    let answer = dist.reduce((sum, d) => sum + (d <= maxMoves ? 1 : 0), 0);
    for (const [u, v, cnt] of edges) {
        const a = Math.max(0, maxMoves - dist[u]);
        const b = Math.max(0, maxMoves - dist[v]);
        answer += Math.min(cnt, a + b);
    }
    return answer;
};
from typing import List
import heapq

class Solution:
    def reachableNodes(self, edges: List[List[int]], maxMoves: int, n: int) -> int:
        graph = [[] for _ in range(n)]
        for u, v, cnt in edges:
            weight = cnt + 1
            graph[u].append((v, weight))
            graph[v].append((u, weight))

        dist = [float("inf")] * n
        dist[0] = 0
        heap = [(0, 0)]

        while heap:
            d, u = heapq.heappop(heap)
            if d != dist[u]:
                continue
            for v, weight in graph[u]:
                new_dist = d + weight
                if new_dist < dist[v]:
                    dist[v] = new_dist
                    heapq.heappush(heap, (new_dist, v))

        answer = sum(d <= maxMoves for d in dist)
        for u, v, cnt in edges:
            from_u = max(0, maxMoves - dist[u])
            from_v = max(0, maxMoves - dist[v])
            answer += min(cnt, from_u + from_v)
        return answer

class Solution {
public:
    int reachableNodes(vector<vector<int>>& edges, int maxMoves, int n) {
        vector<vector<pair<int, int>>> graph(n);
        for (const auto& e : edges) {
            int w = e[2] + 1;
            graph[e[0]].push_back({e[1], w});
            graph[e[1]].push_back({e[0], w});
        }

        const long long INF = numeric_limits<long long>::max() / 4;
        vector<long long> dist(n, INF);
        priority_queue<pair<long long, int>,
                       vector<pair<long long, int>>,
                       greater<pair<long long, int>>> pq;
        dist[0] = 0;
        pq.push({0, 0});

        while (!pq.empty()) {
            auto [d, u] = pq.top();
            pq.pop();
            if (d != dist[u]) continue;
            for (auto [v, w] : graph[u]) {
                if (d + w < dist[v]) {
                    dist[v] = d + w;
                    pq.push({dist[v], v});
                }
            }
        }

        long long answer = 0;
        for (long long d : dist) answer += (d <= maxMoves);
        for (const auto& e : edges) {
            long long a = max(0LL, (long long)maxMoves - dist[e[0]]);
            long long b = max(0LL, (long long)maxMoves - dist[e[1]]);
            answer += min((long long)e[2], a + b);
        }
        return (int)answer;
    }
};
