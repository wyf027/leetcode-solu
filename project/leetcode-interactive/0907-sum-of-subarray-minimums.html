最小值之和

Sum of Subarray Minimums

题目

给定整数数组 arr。枚举它的每一个连续非空子数组，取出各自的最小值并求和。由于结果可能很大，返回结果对 10⁹ + 7 取模后的值。

函数参数：sumSubarrayMins(arr: integer[]) → integer

约束

  • 1 ≤ arr.length ≤ 3 × 10⁴
  • 1 ≤ arr[i] ≤ 3 × 10⁴

先观察规律，再按下方“查看题解”。交互区会展示栈的动作，但不会先告诉你推导结论。

题解：把枚举子数组变成计算贡献

核心洞察

不逐个子数组找最小值，而是反过来问：每个 arr[i] 能成为多少个子数组的最小值？找到它向左、向右能统治的边界后，贡献就是 arr[i] × 左侧选择数 × 右侧选择数。

重复值的归属必须打破平局：这里取左侧严格更小，右侧小于等于。在线扫描时，当新值 ≤ 栈顶值便弹栈。这样每个含重复最小值的子数组只归属于一个位置。

完整过程

  1. 维护下标严格对应值递增的栈，并在数组末尾追加哨兵 0。
  2. 扫描到 cur 时，只要 arr[栈顶] ≥ cur，弹出下标 mid。
  3. 弹出后新的栈顶是左边界 left；当前下标 i 是右边界。
  4. 以 arr[mid] 为唯一代表最小值的子数组共有 (mid-left) × (i-mid) 个。
  5. 加入贡献并取模。哨兵会结算所有尚未弹出的元素。

正确性

对每个位置 mid，算法找到左侧第一个严格小于它的位置，以及右侧第一个小于等于它的位置。区间起点可从左边界之后到 mid，终点可从 mid 到右边界之前，因此恰有两侧选择数乘积个子数组以它为代表最小值。严格/非严格边界使重复最小值不会重算；所有非空子数组都有且仅有一个代表，求和即为答案。

边界与复杂度

  • 单元素：贡献为自身。
  • 严格递增：元素最终由哨兵从右向左结算。
  • 严格递减：每次扫描都会结算此前栈顶。
  • 全部相等：≥ 弹栈负责唯一归属。
  • 时间 O(n)：每个下标至多入栈、出栈一次；空间 O(n)。

替代方案与面试追问

也可分别预处理 previous less 与 next less-or-equal 两个数组，仍为 O(n) 时间但需要更多空间。动态规划版本可维护“所有以当前位置结尾子数组的最小值之和”。追问常包括：为何一边严格一边非严格？如何改成子数组最大值之和？如何进一步计算子数组范围和（最大值减最小值）？

常见错误

  • 两侧都使用严格比较，重复值会漏算；两侧都非严格则会重算。
  • 忘记哨兵或末尾清栈。
  • 乘法完成后才转换为宽整数，Java/C++ 会先溢出。
  • JavaScript 用普通 Number 做大整数连乘存在精度风险；下方实现使用 BigInt。

四语言完整代码

class Solution {
    public int sumSubarrayMins(int[] arr) {
        final long MOD = 1_000_000_007L;
        int n = arr.length;
        int[] stack = new int[n];
        int top = -1;
        long answer = 0;
        for (int i = 0; i <= n; i++) {
            int current = (i == n) ? 0 : arr[i];
            while (top >= 0 && arr[stack[top]] >= current) {
                int mid = stack[top--];
                int left = (top >= 0) ? stack[top] : -1;
                answer = (answer + (long) arr[mid] * (mid - left) * (i - mid)) % MOD;
            }
            if (i < n) stack[++top] = i;
        }
        return (int) answer;
    }
}

var sumSubarrayMins = function(arr) {
  const MOD = 1000000007n;
  const stack = [];
  let answer = 0n;
  for (let i = 0; i <= arr.length; i++) {
    const current = i === arr.length ? 0 : arr[i];
    while (stack.length && arr[stack.at(-1)] >= current) {
      const mid = stack.pop();
      const left = stack.length ? stack.at(-1) : -1;
      answer = (answer + BigInt(arr[mid]) * BigInt(mid - left) * BigInt(i - mid)) % MOD;
    }
    if (i < arr.length) stack.push(i);
  }
  return Number(answer);
};
from typing import List

class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        mod = 10**9 + 7
        stack = []
        answer = 0
        for i in range(len(arr) + 1):
            current = 0 if i == len(arr) else arr[i]
            while stack and arr[stack[-1]] >= current:
                mid = stack.pop()
                left = stack[-1] if stack else -1
                answer += arr[mid] * (mid - left) * (i - mid)
            if i < len(arr):
                stack.append(i)
        return answer % mod

public:
    int sumSubarrayMins(vector<int>& arr) {
        const long long MOD = 1'000'000'007;
        vector<int> stack;
        long long answer = 0;
        for (int i = 0; i <= (int)arr.size(); ++i) {
            int current = i == (int)arr.size() ? 0 : arr[i];
            while (!stack.empty() && arr[stack.back()] >= current) {

                int left = stack.empty() ? -1 : stack.back();
                answer = (answer + 1LL * arr[mid] * (mid - left) * (i - mid)) % MOD;
            }
            if (i < (int)arr.size()) stack.push_back(i);
        }
        return (int)answer;
