翻转子数组得到最大的数组值

一次翻转看似会打乱许多元素，但相邻差之和真正发生变化的地方非常少。先从题目和可交互实验出发，再决定是否展开完整推导。

参数：nums: integer[] 返回：integer 仅允许翻转一次
Problem

题意

把数组值定义为所有相邻元素差的绝对值之和。

给定整数数组 nums，其数组值为：

Σ |nums[i] − nums[i + 1]|，其中 0 ≤ i < nums.length − 1

选择任意一个连续子数组并翻转，操作恰好允许一次。长度为 1 的子数组也可视为一次不改变数组的翻转。求操作后可能得到的最大数组值。

约束

  • 2 ≤ nums.length ≤ 3 × 10⁴
  • −10⁵ ≤ nums[i] ≤ 10⁵
  • 答案保证在 32 位整数范围内。
Example 01
输入：nums = [2,3,1,5,4] 输出：10 解释：翻转 [3,1,5] 后得到 [2,5,1,3,4]，数组值为 10。
Example 02
输入：nums = [2,4,9,24,2,1,10] 输出：68

Full solution

O(n) 边界增益法

把一次翻转的影响压缩到至多两条边，再分别处理触碰数组端点与完全位于内部的情况。

核心洞察

01 · 不变量

翻转区间内部的相邻元素只是顺序颠倒，绝对差不变。只有区间左右边界可能改变。

02 · 端点情况

翻转前缀或后缀时，只替换一条边。枚举每条边即可得到最优端点增益。

03 · 内部情况

每条边可视为数轴区间 [min(a,b), max(a,b)]。两区间之间的最大空隙会贡献两倍增益。

完整过程

  1. 计算基线。令 base = Σ |nums[i] − nums[i+1]|。
  2. 扫描端点翻转。对边 (nums[i], nums[i+1])，翻转前缀 [0..i] 的增益是 |nums[0]−nums[i+1]|−|nums[i]−nums[i+1]|；翻转后缀 [i+1..n−1] 的增益类似。
  3. 压缩内部选择。扫描所有边，维护 maxLow = max(min(a,b)) 与 minHigh = min(max(a,b))。内部最优增益为 2 × (maxLow − minHigh)；若为负，取 0。
  4. 合并答案。答案为 base + max(0, 最优端点增益, 最优内部增益)。
internalGain = max(0, 2 × ( maxᵢ min(nums[i], nums[i+1]) − minᵢ max(nums[i], nums[i+1]) ))

为什么正确

引理 1：仅边界变化

区间内每一对相邻值在翻转后仍然相邻，只是方向相反；由于 |x−y|=|y−x|，它们对总和的贡献不变。

引理 2：端点枚举完备

若翻转区间接触数组左端或右端，恰好只有另一侧的一条边被替换。算法对所有可能的这条边都计算了增益，因此不会遗漏最优端点翻转。

引理 3：内部最大增益

内部翻转会移除两条边并交叉重连。利用绝对值的四种符号组合，最大增益等价于让两条边对应数轴区间的间隙最大，即 2(maxLow−minHigh)。

定理

所有合法翻转不是接触端点，就是完全位于内部。算法分别求出两类的最优增益并与 0 取最大，因此加回基线后得到全局最优数组值。

边界情况

  • 长度为 2：任何整段翻转都不改变唯一的绝对差。
  • 所有元素相同：基线与全部增益均为 0。
  • 严格单调数组：端点翻转仍可能增加总值，不能只计算内部情况。
  • 含负数：算法只依赖大小关系与绝对差，无需特殊处理。

复杂度

时间 O(n)：只扫描所有相邻边一次。
空间 O(1)：仅维护若干标量。

替代方案

枚举所有 [L,R] 并计算边界增益可做到 O(n²)，适合理解公式或小规模对拍，但不满足 n ≤ 3×10⁴。不需要真的翻转数组。

四语言完整代码

Java · 官方签名
class Solution {
    public int maxValueAfterReverse(int[] nums) {
        int n = nums.length;
        int base = 0;
        int bestGain = 0;
        int maxLow = Integer.MIN_VALUE;
        int minHigh = Integer.MAX_VALUE;

        for (int i = 0; i < n - 1; i++) {
            int a = nums[i];
            int b = nums[i + 1];
            int oldDiff = Math.abs(a - b);
            base += oldDiff;

            bestGain = Math.max(bestGain,
                    Math.abs(nums[0] - b) - oldDiff);
            bestGain = Math.max(bestGain,
                    Math.abs(nums[n - 1] - a) - oldDiff);

            maxLow = Math.max(maxLow, Math.min(a, b));
            minHigh = Math.min(minHigh, Math.max(a, b));
        }

        bestGain = Math.max(bestGain, 2 * (maxLow - minHigh));
        return base + bestGain;
    }
}

class Solution:
    def maxValueAfterReverse(self, nums: List[int]) -> int:
        n = len(nums)
        base = 0
        best_gain = 0
        max_low = float("-inf")
        min_high = float("inf")

        for i in range(n - 1):
            a, b = nums[i], nums[i + 1]
            old_diff = abs(a - b)
            base += old_diff

            best_gain = max(
                best_gain, abs(nums[0] - b) - old_diff
            )
            best_gain = max(
                best_gain, abs(nums[-1] - a) - old_diff
            )

            max_low = max(max_low, min(a, b))
            min_high = min(min_high, max(a, b))

        best_gain = max(best_gain, 2 * (max_low - min_high))
        return base + best_gain

常见错误

  • 真的翻转每个区间，导致 O(n³) 或 O(n²)。
  • 只计算内部两条边，遗漏翻转前缀或后缀。
  • 把 maxLow−minHigh 忘记乘 2。
  • 没有与 0 取最大；长度为 1 的翻转可以保证答案不变差。
  • 用排序破坏相邻边信息，既不必要也会增加复杂度。

面试追问

为什么四种绝对值符号最后能压缩成两个极值？因为每条边只需贡献其较小端点或较大端点，四种定向组合互为对称，合并后就是数轴区间间隙。
怎样恢复一个最优翻转区间？在更新端点增益、maxLow 与 minHigh 时同步记录边下标，再按获胜类别还原前缀、后缀或两条内部边之间的区间。
若允许翻转两次呢？两次操作的边界可能相互影响，单次的独立极值不再直接成立，需要更丰富的状态或分类讨论。
