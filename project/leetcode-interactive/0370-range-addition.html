Problem

题目描述

给定整数 length，先构造一个长度为 length、所有元素均为 0 的数组。

每个更新 updates[i] = [startIdx, endIdx, inc] 表示：把闭区间 [startIdx, endIdx] 内的每个元素都增加 inc。更新按给定顺序全部执行后，返回最终数组。

函数签名：getModifiedArray(length, updates)

Limits

约束

  • 1 ≤ length ≤ 10⁵
  • 0 ≤ updates.length ≤ 10⁴
  • updates[i].length = 3
  • 0 ≤ startIdx ≤ endIdx < length
  • -1000 ≤ inc ≤ 1000
注意：区间两端都包含在更新范围内，增量也可能是负数。

Solution

差分数组：只登记变化发生的边界

核心洞察

一次区间更新不必立刻修改区间里的每个元素。令 diff[i] 表示位置 i 相对前一位置的变化：在 start 处加入 inc，并在区间结束后的 end + 1 处减去 inc。最后做一次前缀和，就会让增量恰好覆盖整个闭区间。

01 · 登记起点

diff[start] += inc

从起点开始，后续前缀和值都多出这份增量。

02 · 抵消终点外

diff[end+1] -= inc

若该位置存在，在区间外立刻撤销增量。

03 · 一次汇总

计算前缀和

从左向右累加，恢复每个位置的最终值。

完整过程

  1. 创建长度为 length 的全零数组 diff。
  2. 对每个 [start, end, inc]，执行 diff[start] += inc。
  3. 如果 end + 1 < length，执行 diff[end + 1] -= inc；若区间到达末尾，则无需登记抵消点。
  4. 让 diff[i] += diff[i - 1]，此时 diff 原地变为答案。

正确性证明

引理 1：对更新 [s, e, inc] 做两次边界登记后，它对前缀和位置 i 的贡献是：当 s ≤ i ≤ e 时为 inc，其他位置为 0。

证明：当 i < s，前缀和尚未包含起点登记，贡献为 0；当 s ≤ i ≤ e，它包含 +inc 但未包含 -inc，贡献为 inc；当 i > e，两项都已包含且相互抵消，贡献重新为 0。若 e 是末尾，数组内不存在区间外位置，也无需抵消。

引理 2：所有更新登记在同一差分数组中，再统一求前缀和，等价于逐个执行所有区间更新。

证明：加法满足交换律与结合律。由引理 1，每次更新在每个位置的贡献都正确；将所有贡献相加，就得到该位置经历全部更新后的值。

定理：算法返回的数组正是执行全部更新后的最终数组。由引理 2 直接成立。

复杂度

时间：O(k + n)，其中 k 是更新数量，n = length。

空间：O(n) 用于返回数组；若将返回数组视为必需输出空间，则额外空间为 O(1)。

边界处理

  • updates 为空时，答案保持全零。
  • end = length - 1 时不要写入 end + 1。
  • 负增量与正增量使用完全相同的逻辑。
  • 单点区间 start = end 仍登记两个相邻边界。

Java

class Solution {
    public int[] getModifiedArray(int length, int[][] updates) {
        int[] diff = new int[length];

        for (int[] update : updates) {
            int start = update[0];
            int end = update[1];
            int increment = update[2];

            diff[start] += increment;
            if (end + 1 < length) {
                diff[end + 1] -= increment;
            }
        }

        for (int i = 1; i < length; i++) {
            diff[i] += diff[i - 1];
        }
        return diff;
    }
}

替代方案

逐区间修改：对每个更新遍历 start..end，实现直接，但最坏时间复杂度达到 O(k·n)，在本题规模下可能过慢。

线段树 / 树状数组：如果题目要求更新与查询在线交错进行，可以考虑更强的数据结构；但本题先接收所有更新、最后只输出一次完整数组，差分更简单且复杂度更优。

常见错误

  • 在 end 而不是 end + 1 处抵消。
  • 忘记判断 end + 1 < length，造成越界。
  • 登记完边界后忘记计算前缀和。
  • 把闭区间误当成左闭右开区间。
