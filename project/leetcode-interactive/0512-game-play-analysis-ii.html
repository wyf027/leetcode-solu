题意

表 Activity 记录玩家每次登录游戏时使用的设备、登录日期以及当次游玩的局数。请为每个玩家找出其第一次登录时使用的设备，结果返回 player_id 与 device_id；结果顺序不限。

“第一次”由最小的 event_date 决定，而不是最小设备号，也不是输入行的物理顺序。

Activity 表参数

  • player_id INT：玩家编号
  • device_id INT：本次登录设备编号
  • event_date DATE：登录日期
  • games_played INT：本次登录游玩的局数

约束与数据保证

  • (player_id, event_date) 是表的主键，因此同一玩家同一天至多一条记录。
  • 每行表示某位玩家在某日通过某台设备登录，并在退出前完成若干局游戏；局数可以为 0。
  • 每位出现在表中的玩家都应恰好输出一行，输出列为 player_id、device_id。
  • 官方元数据未提供数值范围；本页不虚构行数、编号或日期上下界。

Solution

把“最早日期”接回原始行

这是数据库题，官方可提交语言以 SQL 为主。关键不是只求出最小日期，而是用玩家编号和最小日期共同定位那条原始记录，从而取回设备编号。

核心洞察

GROUP BY player_id 配合 MIN(event_date) 能得到每位玩家的首登日期，但聚合后没有可靠的 device_id。把这份二列表与 Activity 按玩家、日期等值连接，即可取回唯一匹配行的设备。

完整过程

  1. 按 player_id 分组。
  2. 对每组取 MIN(event_date)，命名为 first_login。
  3. 用 player_id 和日期将聚合结果连接回 Activity。
  4. 投影 player_id、device_id。

MySQL 主解（可提交）

SELECT a.player_id,
       a.device_id
FROM Activity AS a
JOIN (
    SELECT player_id,
           MIN(event_date) AS first_login
    FROM Activity
    GROUP BY player_id
) AS first_activity
  ON first_activity.player_id = a.player_id
 AND first_activity.first_login = a.event_date
ORDER BY a.player_id;

正确性证明

对任意玩家 p，子查询在 p 的全部记录中取最小日期，所以 first_login 正是 p 的第一次登录日期。

连接条件同时要求玩家相同且日期等于 first_login，因此只会保留玩家 p 的首登记录。

主键 (player_id, event_date) 保证该记录唯一。投影出的 device_id 因而恰是首登设备；对每位玩家均成立，结果正确。

复杂度与边界

  • 设表有 n 行；典型执行计划需要一次聚合和一次连接，概念时间为 O(n)，实际取决于索引与数据库优化器。
  • 聚合结果至多每位玩家一行，额外空间可视为 O(p)，其中 p 是玩家数。
  • 单条记录玩家：该条自然就是首登记录。
  • games_played = 0 不影响日期比较。
  • 同一玩家同日重复记录被主键约束排除。

替代方案

MySQL 8+ 可用 ROW_NUMBER() OVER (PARTITION BY player_id ORDER BY event_date) 编号，并筛选 rn = 1。窗口函数表达直接，也容易扩展为“前 k 次登录”；本题的聚合连接兼容性更广。 

SELECT player_id, device_id
FROM (
    SELECT player_id,
           device_id,
           ROW_NUMBER() OVER (
               PARTITION BY player_id
               ORDER BY event_date
           ) AS rn
    FROM Activity
) AS ranked
WHERE rn = 1;

常见错误

  • 直接 GROUP BY player_id 却选择未聚合的 device_id；设备值可能任意或直接报错。
  • 只按最小日期连接，遗漏 player_id；不同玩家同日登录会交叉匹配。
  • 把最小 device_id 当作首登设备；设备编号没有时间含义。
  • 依赖表的输入顺序；关系表没有可依赖的天然行序。

本地语义参考 · 完整 Java 17 程序
import java.time.LocalDate;
import java.util.*;

public class Main {
    record Activity(int playerId, int deviceId,
                    LocalDate eventDate, int gamesPlayed) {}
    record Result(int playerId, int deviceId) {}

    static List<Result> firstLoginDevice(List<Activity> rows) {
        Map<Integer, Activity> earliest = new HashMap<>();

        for (Activity row : rows) {
            Activity saved = earliest.get(row.playerId());
            if (saved == null
                    || row.eventDate().isBefore(saved.eventDate())) {
                earliest.put(row.playerId(), row);
            }
        }

        return earliest.values().stream()
                .sorted(Comparator.comparingInt(Activity::playerId))
                .map(row -> new Result(row.playerId(), row.deviceId()))
                .toList();
    }

    public static void main(String[] args) {
        List<Activity> rows = List.of(
            new Activity(1, 2, LocalDate.parse("2016-03-01"), 5),
            new Activity(1, 2, LocalDate.parse("2016-05-02"), 6),
            new Activity(2, 3, LocalDate.parse("2017-06-25"), 1),
            new Activity(3, 1, LocalDate.parse("2016-03-02"), 0),
            new Activity(3, 4, LocalDate.parse("2018-07-03"), 5)
        );
        firstLoginDevice(rows).forEach(System.out::println);
    }
}

function firstLoginDevice(activity) {
  const earliest = new Map();

  for (const row of activity) {
    const saved = earliest.get(row.player_id);
    if (!saved || row.event_date < saved.event_date) {
      earliest.set(row.player_id, row);
    }
  }

  return [...earliest.values()]
    .sort((a, b) => a.player_id - b.player_id)
    .map(({ player_id, device_id }) => ({ player_id, device_id }));
}

const activity = [

];

from dataclasses import dataclass
from datetime import date


@dataclass(frozen=True)
class Activity:
    player_id: int
    device_id: int
    event_date: date
    games_played: int


def first_login_device(rows: list[Activity]) -> list[tuple[int, int]]:
    earliest: dict[int, Activity] = {}

    for row in rows:
        saved = earliest.get(row.player_id)
        if saved is None or row.event_date < saved.event_date:
            earliest[row.player_id] = row

    return [
        (player_id, earliest[player_id].device_id)
        for player_id in sorted(earliest)
    ]


if __name__ == "__main__":
    rows = [
        Activity(1, 2, date.fromisoformat("2016-03-01"), 5),
        Activity(1, 2, date.fromisoformat("2016-05-02"), 6),
        Activity(2, 3, date.fromisoformat("2017-06-25"), 1),
        Activity(3, 1, date.fromisoformat("2016-03-02"), 0),
        Activity(3, 4, date.fromisoformat("2018-07-03"), 5),
    ]
    for result in first_login_device(rows):
        print(result)
本地语义参考 · 完整 C++17 程序
#include <algorithm>
#include <iostream>
#include <map>
#include <string>
#include <utility>
#include <vector>

struct Activity {
    int playerId;
    int deviceId;
    std::string eventDate;
    int gamesPlayed;
};

std::vector<std::pair<int, int>> firstLoginDevice(
    const std::vector<Activity>& rows) {
    std::map<int, Activity> earliest;

    for (const Activity& row : rows) {
        auto it = earliest.find(row.playerId);
        if (it == earliest.end() || row.eventDate < it->second.eventDate) {
            earliest.insert_or_assign(row.playerId, row);
        }
    }

    std::vector<std::pair<int, int>> result;
    for (const auto& [playerId, row] : earliest) {
        result.emplace_back(playerId, row.deviceId);
    }
    return result;
}

int main() {
    std::vector<Activity> rows{
        {1, 2, "2016-03-01", 5}, {1, 2, "2016-05-02", 6},
        {2, 3, "2017-06-25", 1}, {3, 1, "2016-03-02", 0},
        {3, 4, "2018-07-03", 5}
    };
    for (const auto& [playerId, deviceId] : firstLoginDevice(rows)) {
        std::cout << playerId << ' ' << deviceId << '\n';
    }
}

面试追问

  • 如果需要每位玩家前 3 次登录，应如何用窗口函数改写？
  • 若主键不保证同日唯一，产品希望任选、全保留，还是按第二字段打破并列？
  • 哪些索引有助于分组与回表连接？可讨论 (player_id, event_date, device_id) 覆盖索引。
  • 如何计算首登设备在全部首登设备中的占比？

一句话记忆

当题目要“每组最早一行的其他列”时：先求每组最早键，再连接回原表；或用窗口函数为组内行编号。
