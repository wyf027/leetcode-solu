两球之间的磁力Magnetic Force Between Two Balls

把 m 个球放进不同位置的篮子，让任意两球之间的最小距离尽可能大。先读懂目标，再用下面的实验台观察距离变化。

Problem

题目说明

数组排序二分查找

有 n 个空篮子，第 i 个篮子位于 position[i]。需要将 m 个球分别放入不同篮子。位于 x 和 y 的两个球，其磁力定义为 |x - y|。

请选择放置方案，使所有球对中的最小磁力尽可能大，并返回这个最大值。

约束

  • n == position.length
  • 2 ≤ n ≤ 10⁵
  • 1 ≤ position[i] ≤ 10⁹
  • position 中的整数互不相同
  • 2 ≤ m ≤ position.length
Example 01
输入：position = [1,2,3,4,7], m = 3
输出：3
解释：放在 1、4、7，三对磁力为 3、3、6；
其中最小值为 3，且无法让这个最小值更大。
Example 02
输入：position = [5,4,3,2,1,1000000000], m = 2
输出：999999999
解释：选择位置 1 与 1000000000。

Solution

排序 + 二分答案 + 贪心判定

核心洞察

不要枚举放球方案，而是询问：“给定最小距离 D，能否放下 m 个球？”可行性关于 D 单调：若 D 可行，则所有更小距离都可行；若不可行，则所有更大距离也不可行。于是可以二分最大的可行 D。

完整过程

  1. 升序排序 position。
  2. 二分答案区间 [1, max - min]。
  3. 检查候选距离 D 时，先在最左篮子放球，然后从左到右把下一球放到第一个与上一球距离至少为 D 的篮子。
  4. 若放球数达到 m，记录 D 并尝试更大值；否则缩小右边界。

为什么贪心正确

对固定 D，每次选择最靠左且合法的篮子，不会比任何其他合法选择更晚，因此为后续球保留的空间最大。用交换观点看，任意可行方案的当前球都可左移到贪心位置，而不会破坏与前一球的距离，也不会减少后方可用空间。所以若贪心都放不下 m 个球，就不存在其他可行放法。

结合可行性的单调性，二分结束时记录的就是最大可行最小距离。

边界处理

  • m = 2 时，答案就是排序后首尾之差。
  • m = n 时，所有篮子都要使用，答案是相邻位置的最小差。
  • 坐标最大到 10⁹；本题差值仍在 32 位有符号整数范围内，但计算中使用语言的正常整数比较即可。
  • 输入位置无序，必须先排序。

复杂度与替代方案

时间O(n log n + n log R)
额外空间O(1) / O(log n)

R = max(position) - min(position)。排序可能使用语言实现所需的栈或辅助空间。暴力枚举距离会达到 O(nR)；枚举所有放置组合更不可行。也可采用“开区间”二分模板，但要清晰维护不变量。

面试追问

  • 为什么只检查相邻已选球的距离？ 排序后，任意非相邻已选球距离不小于中间相邻间距；最小值必出现在相邻已选球之间。
  • 二分边界还能更紧吗？ 可以把右边界设为 (max - min) / (m - 1) 的下取整，因为总跨度要容纳 m - 1 个间隔。
  • 如果要返回一种最优放法？ 先求最优距离，再以该距离运行一次相同贪心并记录篮子位置。
  • 这类模型还有哪些题？ 常见于“最大化最小值”，如安排间隔、路由器放置、牛棚分配。

常见错误

  • 忘记排序，导致贪心的“从左到右”失去意义。
  • 可行时错误地收缩右边界；本题寻找最大可行值，应向右继续搜索。
  • 用“相邻原始篮子的最小间距”作为答案，忽略了可以跳过篮子。
  • 二分循环与边界更新模板混用，造成死循环或漏掉答案。

class Solution {
    public int maxDistance(int[] position, int m) {
        Arrays.sort(position);
        int left = 1;
        int right = position[position.length - 1] - position[0];
        int answer = 0;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (canPlace(position, m, mid)) {
                answer = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return answer;
    }

    private boolean canPlace(int[] position, int m, int distance) {
        int count = 1;
        int last = position[0];
        for (int i = 1; i < position.length; i++) {
            if (position[i] - last >= distance) {
                count++;
                last = position[i];
                if (count >= m) return true;
            }
        }
        return false;
    }
}

class Solution {
public:
    int maxDistance(vector<int>& position, int m) {
        sort(position.begin(), position.end());
        int left = 1;
        int right = position.back() - position.front();
        int answer = 0;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (canPlace(position, m, mid)) {
                answer = mid;
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return answer;
    }

private:
    bool canPlace(const vector<int>& position, int m, int distance) {
        int count = 1;
        int last = position[0];
        for (int i = 1; i < static_cast<int>(position.size()); ++i) {
            if (position[i] - last >= distance) {
                ++count;
                last = position[i];
                if (count >= m) return true;
            }
        }
        return false;
    }
