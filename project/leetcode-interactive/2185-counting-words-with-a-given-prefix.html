2185. 统计包含给定前缀的字符串

Counting Words With a Given Prefix

从字符串的起点出发，辨认它是否拥有指定的开头。

打开官方题目 ↗

01 / 读题

题目与约束

给定字符串数组 words 和字符串 pref，返回数组中以 pref 开头的字符串数量。前缀必须是从下标 0 开始的连续片段；只在字符串中间出现不算。

参数：words: string[]，pref: string；返回：integer。

  • 1 ≤ words.length ≤ 100
  • 1 ≤ words[i].length, pref.length ≤ 100
  • words[i] 和 pref 仅包含小写英文字母。

官方示例 1

输入：words = ["pay","attention","practice","attend"], pref = "at"
输出：2

符合条件的是 attention 与 attend。

官方示例 2

输入：words = ["leetcode","win","loops","success"], pref = "code"
输出：0

没有单词以 code 开头；leetcode 中间的 code 不满足要求。

04 / 独立题解

准备好后，再揭开解法

核心洞察：只看开头，不搜索中间

对每个单词独立检查 word.startsWith(pref)。每找到一个匹配就把计数加一。重复单词占据不同数组位置，应分别计数；本题不需要去重、排序或建立字典树。

完整过程

  1. 初始化计数 count = 0。
  2. 依次取出 words 中的单词。如果长度小于 pref，一定无法匹配。
  3. 从下标 0 比较前 pref.length 个字符；有任意一处不同就判定失败。全部相同则计数加一。标准库前缀函数已封装此逻辑。
  4. 处理完全部单词，返回计数。

示例 1 的计数依次是：pay → 0，attention → 1，practice → 1，attend → 2。

正确性

循环不变式：处理完前 k 个单词后，count 等于这 k 个位置中具有 pref 前缀的位置数。初始 k = 0 时计数为 0，成立。对第 k + 1 个单词，前缀检查恰好判断其开头是否与 pref 完全一致：成立则加一，否则不变，因此不变式继续成立。当 k = words.length 时，count 就是所求总数。

边界与复杂度

  • 单词等于 pref：匹配；单词更短：不匹配；重复单词：逐个计数。
  • 仅包含 pref 子串但起点不为 0：不匹配。官方输入不含空字符串，无需为本题额外定义空前缀。
  • 设 n 为单词数，m 为 pref 长度，最坏时间复杂度为 O(nm)，额外空间为 O(1)。以下代码不建立切片或结果数组。教学演示保存步骤，其开销不代表提交算法。

替代方案

手写双层循环可以精确控制提前退出，复杂度相同，但更易写错边界。切片比较也可行，部分语言会产生额外字符串。若固定词库要处理大量前缀查询，可考虑字典树并在节点保存经过次数：建树 O(S)，单次查询 O(m)，空间 O(S)，S 为词库总字符数；对本题单次查询没有必要。

面试追问

  • 词库很大但只有一次查询？逐个读取并判断即可，无需保存整个词库。
  • 需要忽略大小写？先约定字符集与规范化规则；本题只有小写英文字母。
  • 大量查询还要动态新增单词？字典树节点计数可以随插入更新；删除时也要同步减少。

常见错误

  • 用 includes / contains：会把中间出现误当成前缀。
  • 交换单词与前缀的位置：应问“单词是否以 pref 开头”。
  • 先放进 Set：会漏算重复字符串。
  • 手动比较时没检查长度，或把 j < m 写成 j <= m。

Java

class Solution {
    public int prefixCount(String[] words, String pref) {
        int count = 0;
        for (String word : words) {
            if (word.startsWith(pref)) count++;
        }
        return count;
    }
}

Python 3

from typing import List

class Solution:
    def prefixCount(self, words: List[str], pref: str) -> int:
        count = 0
        for word in words:
            if word.startswith(pref):
                count += 1
        return count

C++

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int prefixCount(vector<string>& words, string pref) {
        int count = 0;
        for (const string& word : words) {
            if (word.size() >= pref.size() &&
                word.compare(0, pref.size(), pref) == 0) {
                ++count;
            }
        }
        return count;
    }
};
