01 · Problem

题意

矩形必须由连续的行和连续的列组成。返回数组 [r1, c1, r2, c2]， 分别表示左上角和右下角；若最优答案不唯一，返回任意一个即可。

约束

  • • 1 ≤ matrix.length ≤ 200
  • • 1 ≤ matrix[0].length ≤ 200
  • • 矩阵元素可为正数、负数或 0

官方样例

输入
matrix = [[-1, 0], [0, -1]]
输出
[0, 1, 0, 1]

坐标对应单个元素 0，总和为 0；另一个 0 也是同样合法的最优答案。

坐标约定

行、列均从 0 开始计数，且边界包含在子矩阵中。

可见字符约定

若输入含空格，将以 ␠ 显示；本题矩阵输入不含字符串。

04 · Solution vault

题解

核心洞察、完整过程、边界、复杂度、取舍、追问、常见错误与四语言代码均收纳在此。

核心洞察

把二维矩形折叠成一维连续段

枚举上边界 top 和下边界 bottom。对每一列，把这段行带中的元素累加成 columnSum[col]。此时，选择连续列区间的最大和，恰好就是经典的一维最大子数组问题。

主线选择：行带枚举 + Kadane

代码短、状态清楚、易在面试中证明；每扩展一次下边界，只需 O(C) 更新列和并扫描一次。

完整过程

  1. 1. 固定每一个上边界，清空列和。
  2. 2. 下边界逐行向下，把新行加进每列。
  3. 3. 对列和运行 Kadane：若旧连续和 ≤ 0，从当前列重新开始；否则继续累加。
  4. 4. 发现更大总和时，记录四个边界坐标。
  5. 5. 所有行带扫描结束后返回答案。

边界与正确性

  • • 全负矩阵：最大值必须初始化为负无穷，不能初始化为 0。
  • • 单行 / 单列：算法自然退化为一维最大子数组。
  • • 并列最优：题目允许任意一个；代码仅在严格变大时覆盖答案。
  • • 坐标闭区间：更新最大值的当下，当前列就是右边界。

正确性来自一一对应：任意子矩阵都唯一对应某个行带和其中一段连续列；枚举覆盖全部行带，而 Kadane 对每个行带找到最优连续列，所以全局最优不会遗漏。

复杂度与替代方案

时间

O(R² · C)

额外空间

O(C)

若行数远大于列数，可按较短维枚举边界，把复杂度优化为 O(min(R,C)² · max(R,C))；但转置后要谨慎映射坐标。面试中优先写清晰的行带版本，再说明该优化。

二维前缀和可 O(1) 求任意矩形和，但仍需枚举四条边，时间 O(R²C²)，不如压缩法。

面试追问

为什么 Kadane 在这里仍然成立？

固定行带后，每列贡献一个数，连续列区间与一维连续子数组完全等价。

如何返回所有并列的最大矩形？

先确定最大和，再在扫描中把所有等于最大和的坐标追加到结果；输出量本身可能很大。

元素很大时怎么办？

列和、当前和与最大和使用 64 位整数；坐标仍可用普通整数。

常见错误

  • • 每次改变上边界时忘记清空 columnSum。
  • • Kadane 重启时只重置和，没同步更新左边界。
  • • 用 0 初始化最大和，导致全负矩阵返回不存在的空矩形。
  • • 在当前和更新之前记录右边界，产生一列偏移。
  • • 把返回顺序写成 [r1, r2, c1, c2]。

class Solution {
    public int[] getMaxMatrix(int[][] matrix) {
        int rows = matrix.length;
        int cols = matrix[0].length;
        long best = Long.MIN_VALUE;
        int[] answer = new int[4];

        for (int top = 0; top < rows; top++) {
            long[] columnSum = new long[cols];
            for (int bottom = top; bottom < rows; bottom++) {
                for (int col = 0; col < cols; col++) {
                    columnSum[col] += matrix[bottom][col];
                }

                long current = 0;
                int left = 0;
                for (int col = 0; col < cols; col++) {
                    if (current <= 0) {
                        current = columnSum[col];
                        left = col;
                    } else {
                        current += columnSum[col];
                    }

                    if (current > best) {
                        best = current;
                        answer = new int[] {top, left, bottom, col};
                    }
                }
            }
        }
        return answer;
    }
}

class Solution:
    def getMaxMatrix(self, matrix: List[List[int]]) -> List[int]:
        rows, cols = len(matrix), len(matrix[0])
        best = float("-inf")
        answer = [0, 0, 0, 0]

        for top in range(rows):
            column_sum = [0] * cols
            for bottom in range(top, rows):
                for col in range(cols):
                    column_sum[col] += matrix[bottom][col]

                current = 0
                left = 0
                for col, value in enumerate(column_sum):
                    if current <= 0:
                        current = value
                        left = col
                    else:
                        current += value

                    if current > best:
                        best = current
                        answer = [top, left, bottom, col]

        return answer
