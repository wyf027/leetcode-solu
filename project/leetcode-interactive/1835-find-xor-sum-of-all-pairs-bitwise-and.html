所有数对按位与结果的异或和

Find XOR Sum of All Pairs Bitwise AND

两组数字交叉相遇，每次按位与，再把结果异或起来。先观察每一对数字的贡献。

官方题目 ↗

01 / 题目与示例

给定两个从下标 0 开始的非负整数数组 arr1、arr2。对于所有合法下标组合 (i, j)，计算 arr1[i] & arr2[j]，然后将这些结果全部按位异或，返回最后的整数。只有一个结果时，异或和就是它本身。

函数：getXORSum(arr1, arr2) → integer。& 表示按位与，^ 表示按位异或，均不是逻辑运算。

官方示例 1

输入：arr1 = [1,2,3], arr2 = [6,5]
输出：0

数对结果依次为 [0,1,2,0,2,1]，全部异或得到 0。

官方示例 2

输入：arr1 = [12], arr2 = [4]
输出：4

只有一个数对：12 & 4 = 4。

约束：1 ≤ arr1.length, arr2.length ≤ 105；0 ≤ arr1[i], arr2[j] ≤ 109。

04 / 独立题解
先思考：能否避免真的生成全部数对？准备好后再展开。


核心洞察：按位与对异或满足分配律
(a & b) ^ (a & c) = a & (b ^ c)
答案 = (arr1 所有元素的异或和) & (arr2 所有元素的异或和)
不要把 n × m 个数对显式保存下来。只需把两个数组各压缩为一个异或值，最后做一次按位与。
完整过程
  1. 初始化 x = 0，逐个执行 x ^= arr1[i]。
  2. 初始化 y = 0，逐个执行 y ^= arr2[j]。
  3. 返回 x & y。
示例 1：x 的变化是 0 → 1 → 3 → 0；y 的变化是 0 → 6 → 3，最终 0 & 3 = 0。示例 2：x = 12，y = 4，12 & 4 = 4。
正确性证明
单独观察任意一位：若 a 的这一位为 0，分配律两侧都为 0；若为 1，两侧都等于 b 与 c 在该位的异或。因此该恒等式对每一位成立，对整个整数也成立。
⊕ᵢ ⊕ⱼ (arr1[i] & arr2[j])
= ⊕ᵢ (arr1[i] & (⊕ⱼ arr2[j]))
= (⊕ᵢ arr1[i]) & (⊕ⱼ arr2[j])
第一步将每一行中的 arr1[i] 提取出来；第二步利用按位与的交换律，再将固定的 arr2 异或和提取出来。循环结束后，x 和 y 分别是两组的完整异或和，所以返回值恰为题目要求。
边界与复杂度
  • 单元素数组直接退化成一次按位与；全零数组的结果是 0。
  • 同一个数出现两次会在异或中抵消，但不能直接去重。
  • 时间 O(n + m)，额外空间 O(1)，不含输入数组。
  • 元素最大为 10⁹，小于 2³⁰，JavaScript 的有符号 32 位位运算在本题安全。更大整数需改用 BigInt 并统一操作数类型。
替代方案
直接枚举所有数对并累计异或：时间 O(nm)、额外空间 O(1)，便于理解但最大输入有 10¹⁰ 对。另一种方法是对 30 个二进制位分别统计两组中 1 的个数：只有两个计数都为奇数，该位才为 1。其时间 O(30(n+m))、空间 O(1)，不必真的计算计数乘积。
常见错误
  • 把 & 写成 &&，把 ^ 当成乘方，或把异或和误认为算术和。
  • 只配对相同下标；题目要求的是笛卡尔积。
  • 构造长度 n × m 的列表，导致内存和时间失控。
  • 用数组长度奇偶替代每一位的 1 的数量奇偶；这是不同条件。
面试追问
流式输入怎么办？两边各维护一个异或累积器即可。单点更新怎么办？用 x ^= oldValue ^ newValue 更新该数组的异或和，再计算 x & y。为什么不能直接换成求和？算术和存在进位，上面的按位分配律证明不能直接套用。


Java
class Solution {
    public int getXORSum(int[] arr1, int[] arr2) {
        int x = 0, y = 0;
        for (int a : arr1) x ^= a;
        for (int b : arr2) y ^= b;
        return x & y;
    }
}
