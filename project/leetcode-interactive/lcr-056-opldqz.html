两数之和 IV - 输入二叉搜索树

给定二叉搜索树根节点和目标值 k，判断树中是否存在两个不同节点，且它们的值之和恰好等于 k。

题意

每个节点只能使用一次。返回 true 表示存在一对不同节点的和为 k；否则返回 false。

示例

root = [5,3,6,2,4,null,7]
k = 9
输出 = true（2 + 7 或 3 + 6）
k = 28
输出 = false

约束

节点数在 2 到 10⁴ 之间，节点值与 k 均在 -10⁴ 到 10⁴ 之间。

交互实验室

以层序数组输入树，使用 null 表示空节点；逐步查看 DFS 访问与补数查找。

例如：[5,3,6,2,4,null,7]

载入示例后开始观察。

    测试与验证

    快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

    核心洞察

    深度优先遍历时维护已经见过的节点值集合。访问当前值 x 时，若集合中已有 k - x，两者就是答案；否则把 x 放入集合，继续遍历。

    完整过程

    1. 初始化空集合 seen，从根开始 DFS（或 BFS）。
    2. 对当前节点值 x，计算补数 k - x。
    3. 若补数已在 seen 中，立即返回 true。
    4. 否则记录 x，继续访问左右子树；遍历结束仍未命中则返回 false。

    边界与常见错误

    • 先查补数、后插入当前值，避免同一个节点被使用两次。
    • 节点值可以为负数，集合查找不依赖值域或排序方向。
    • BST 性质并非必需；它也可以支持中序双指针的 O(h) 额外空间方案。

    复杂度：访问每个节点至多一次，时间 O(n)，集合空间 O(n)。替代方案：中序遍历得到有序数组后双指针为 O(n) 时间、O(n) 空间；使用两个 BST 迭代器可把额外空间降为 O(h)，实现更复杂。

    面试追问：若只允许一次遍历，哈希集合方案最直接；若内存紧张且必须利用 BST，可维护最小、最大两个迭代器，确保它们始终指向不同节点。

    可提交代码

    Java

    class Solution {
    private final Set<Integer> seen = new HashSet<>();
    public boolean findTarget(TreeNode root, int k) {
        if (root == null) return false;
        if (seen.contains(k - root.val)) return true;
        seen.add(root.val);
        return findTarget(root.left, k) || findTarget(root.right, k);
    }
}

    var findTarget = function (root, k) {
  const seen = new Set();
  const dfs = (node) => {
    if (!node) return false;
    if (seen.has(k - node.val)) return true;
    seen.add(node.val);
    return dfs(node.left) || dfs(node.right);
  };
  return dfs(root);
};

    class Solution:
    def findTarget(self, root: Optional[TreeNode], k: int) -> bool:
        seen = set()

        def dfs(node):
            if not node:
                return False
            if k - node.val in seen:
                return True
            seen.add(node.val)
            return dfs(node.left) or dfs(node.right)

        return dfs(root)
