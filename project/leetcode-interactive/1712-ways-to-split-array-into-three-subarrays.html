Ways to Split Array Into Three Subarrays

将数组分成
三个子数组的方案数

两道切口，三个非空连续区间。你要数出所有满足“左和不大于中和，中和不大于右和”的分法。

结构left | mid | right
顺序sum(left) ≤ sum(mid)
平衡sum(mid) ≤ sum(right)

Problem

题意与边界

任务

给定非负整数数组 nums，选择两个切口，把它分成从左到右的三个非空连续子数组 left、mid、right。

  • 只有同时满足 sum(left) ≤ sum(mid) ≤ sum(right) 才是好分割。
  • 返回好分割的总数；由于答案可能很大，结果对 10⁹ + 7 取模。

函数与约束

waysToSplit(nums) → integer

  • 3 ≤ nums.length ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁴
  • 三个子数组都必须非空

示例 1

最小规模
输入：nums = [1,1,1]
输出：1

唯一好分割：[1] | [1] | [1]

示例 2

多解
输入：nums = [1,2,2,2,5,0]
输出：3

[1] | [2] | [2,2,5,0]
[1] | [2,2] | [2,5,0]
[1,2] | [2,2] | [5,0]

示例 3

无解
输入：nums = [3,2,1]
输出：0

任意合法切口都无法让三个区间和保持非递减。

先自己想，再打开推导

为什么“非负”是关键？固定第一刀后，第二刀的合法位置会呈现什么形状？

Solution

前缀和 × 单调双指针

把切口写成前缀下标：第一刀在 i，第二刀在 m。三个区间分别是 [0,i)、[i,m)、[m,n)。

01

把区间和变成前缀差

设 P[x] 为前 x 个数之和，总和为 T=P[n]。

left=P[i] · mid=P[m]-P[i] · right=T-P[m]
02

合法第二刀是一段连续区间

两个不等式分别给第二刀一个下界和上界。

2P[i] ≤ P[m] 且 2P[m] ≤ T+P[i]
03

指针只向右走

nums 非负，所以前缀和单调；当 i 右移，两条边界都不会左退。

本轮贡献 = max(0, upperExclusive − lower)

Mechanism

完整过程

  1. 建前缀和。 用 P[x] 在 O(1) 时间得到任意连续区间和。
  2. 枚举第一刀。 i 从 1 到 n−2，确保左、中、右都有元素。
  3. 推进 lower。 找到首个满足 P[lower] ≥ 2P[i] 的第二刀。
  4. 推进 upper。 找到首个不满足 2P[upper] ≤ T+P[i] 的位置；它是右开边界。
  5. 累计区间长度。 加上 max(0, upper−lower) 并取模。
关键： 即使数组含 0，前缀和仍是非递减的，两个指针仍无需回退；但比较必须保留等号。

复杂度

时间 O(n)： 外层扫描一次，lower、upper 各自最多走 n 步。

空间 O(n)： 保存前缀和。也可用累计和配合其他结构，但会牺牲清晰度。

边界检查

  • n=3 时仅有一个切法。
  • 全 0 数组的所有切法都合法。
  • m<n，否则右数组为空。
  • Java/C++ 前缀和应使用 64 位整数。
  • 贡献为负时按 0 处理。

Correctness

正确性证明

引理 1：固定 i 后，所有合法 m 构成连续区间

左和不大于中和等价于 P[m] ≥ 2P[i]；中和不大于右和等价于 2P[m] ≤ T+P[i]。因元素非负，P[m] 随 m 非递减，所以满足第一式的位置是一个后缀，满足第二式的位置是一个前缀；二者交集必为连续区间。

引理 2：双指针找到该区间的精确边界

lower 停在第一式首次成立处，故其左侧均不合法；upper 停在第二式首次失败处，故 [lower,upper) 内每个位置同时满足两式，其右侧均不合法。随着 i 增大，两式阈值不减，边界不可能左移，因此复用指针不会跳过答案。

定理：算法返回且仅返回全部好分割数

外层枚举了每个可能的第一刀；根据引理 1、2，本轮加入的恰是该第一刀对应的全部合法第二刀，既不遗漏也不重复。所有第一刀贡献之和因此等于全部好分割数，最后取模不改变题目要求下的结果。

Implementation

四语言完整代码

class Solution {
    public int waysToSplit(int[] nums) {
        final long MOD = 1_000_000_007L;
        int n = nums.length;
        long[] prefix = new long[n + 1];
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        long total = prefix[n];
        long answer = 0;
        int lower = 2;
        int upper = 2;

        for (int i = 1; i <= n - 2; i++) {
            lower = Math.max(lower, i + 1);
            while (lower < n && prefix[lower] < 2L * prefix[i]) {
                lower++;
            }

            upper = Math.max(upper, lower);
            while (upper < n && 2L * prefix[upper] <= total + prefix[i]) {
                upper++;
            }

            if (upper > lower) {
                answer = (answer + upper - lower) % MOD;
            }
        }
        return (int) answer;
    }
}

Deep Dive

替代方案与面试延伸

替代方案

前缀和 + 二分查找

对每个 i，分别用 lower bound 找第一个 P[m] ≥ 2P[i]，再用 upper bound 找最后一个 2P[m] ≤ T+P[i]。更直观，时间 O(n log n)，空间 O(n)。

为何不用

枚举两道切口

共有 O(n²) 对切口，即使用前缀和把每次判断降为 O(1)，在 n=10⁵ 时仍远超可接受范围。

面试追问

如果允许负数？

前缀和不再单调，合法第二刀未必连续，双指针与直接二分都失效。需要重新建模，可能借助有序统计结构处理区间计数。

面试追问

如果分成 k 段？

约束从两个切口扩展为多层边界，通常考虑动态规划与前缀累计；能否继续线性推进取决于段和约束是否保持单调。

常见错误

  • 把第二刀允许到 n，导致右子数组为空。
  • 上界使用 < 而不是 ≤，漏掉段和相等的方案。
  • upper 没有先与 lower 对齐，出现负贡献或重复扫描。
  • 在 Java/C++ 中使用 32 位前缀和，乘 2 时存在溢出风险。
  • 忘记答案取模；或对每一步边界而非累计结果取模。
