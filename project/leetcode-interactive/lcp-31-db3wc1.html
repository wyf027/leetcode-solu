变换的迷宫

在时间分层图上走五种动作，用三枚状态位记录临时卷轴、永久卷轴，以及是否仍站在永久清除格。

题意

maze[t] 是时刻 t 的迷宫。小力从 (0,0) 出发，每个时刻可上下左右移动一格或原地等待，必须在最后时刻前到达出口。. 可通行，# 是陷阱。

临时消除术

使用一次，使指定位置仅在下一个时刻成为空地，适合跨过一次陷阱。

永久消除术

使用一次，使一个位置永久为空地；只要仍停在该格，就可无视以后各层该处的地形。

示例：maze = [[".#.","#.."],["...",".#."],[".##",".#."],["..#",".#."]]

存在使用卷轴与等待相结合的路径，输出 true。

1 ≤ T ≤ 100，行列均不超过 50；起点、终点在所有时刻均为空地。

时间切片观察器

切换官方示例 1 的四个时刻，观察同一坐标如何在空地与陷阱间变化。

为什么只要三枚状态位

tempUsed

临时卷轴是否已经消耗。遇到下一层的陷阱且尚未用过时，可跨入并将该位设为 1。

permUsed

永久卷轴是否已消耗。首次跨入陷阱时可使用，并进入“站在永久格”状态。

onPerm

是否仍站在永久清除格。原地等待时保持；一旦离开就清零。无需保存具体坐标，因为离开后不必回头：所需等待可提前在安全的永久格完成。

转移：从每个状态尝试上、下、左、右、停留。下一层是空地即可进入；是陷阱则用剩余的临时或永久卷轴；若选择停留且 onPerm=1，无论下一层地形都可继续停留。

题解区

默认隐藏；展开查看分层 DP/BFS 与四语言提交代码。

核心洞察与完整过程

把时刻作为 BFS 层。集合中的状态由位置和三位卷轴状态组成。初始为 (0,0,0,0,0)；每层向下一时刻的五个候选位置转移并去重。任意层到达出口即可返回真，处理完最后一层仍未到达则返回假。

复杂度、边界与替代方案

每个时间层至多 n·m·8 个状态，每个尝试 5 个动作，时间 O(T·n·m)（常数 40），滚动集合空间 O(n·m)。记忆化 DFS 也可表达同样状态，但迭代分层更贴合“下一时刻”并避免深递归。

面试追问与常见错误

为何离开永久格后可丢掉其坐标？若路径未来还要回到该格，把离开到返回之间的时间改为在永久格等待，不会更差。常见错误：用当前层而非下一层判断目的地；忘记“原地等待”；永久格等待时错误检查 #；把临时卷轴当成永久；到达出口后还要求撑到最后时刻。 

import java.util.*;
class Solution {
  private static final int[][] D = {{0,0},{1,0},{-1,0},{0,1},{0,-1}};
  public boolean escapeMaze(String[][] maze) {
    int T=maze.length,n=maze[0].length,m=maze[0][0].length(); Set<Integer> cur=new HashSet<>(); cur.add(0);
    if(n==1 && m==1)return true;
    for(int t=0;t<T-1;t++){Set<Integer> next=new HashSet<>();
      for(int state:cur){int bits=state&7,pos=state>>3,r=pos/m,c=pos%m,temp=bits&1,perm=(bits>>1)&1,on=(bits>>2)&1;
        for(int[]d:D){int nr=r+d[0],nc=c+d[1];if(nr<0||nr>=n||nc<0||nc>=m)continue;boolean stay=nr==r&&nc==c;
          if(stay&&on==1)add(next,nr,nc,m,temp,perm,1);

          else {if(temp==0)add(next,nr,nc,m,1,perm,0);if(perm==0)add(next,nr,nc,m,temp,1,1);}
        }
      }
      for(int s:next)if((s>>3)==(n*m-1))return true;cur=next;
    } return false;
  }
  private void add(Set<Integer>s,int r,int c,int m,int a,int b,int d){s.add((((r*m+c)<<3)|a|(b<<1)|(d<<2)));}

from typing import List
class Solution:
    def escapeMaze(self, maze: List[List[str]]) -> bool:
        T,n,m=len(maze),len(maze[0]),len(maze[0][0]); cur={(0,0,0,0,0)}
        if n==m==1: return True
        for t in range(T-1):
            nxt=set()
            for r,c,temp,perm,on in cur:
                for dr,dc in ((0,0),(1,0),(-1,0),(0,1),(0,-1)):
                    nr,nc=r+dr,c+dc
                    if not (0<=nr<n and 0<=nc<m): continue
                    stay=(nr,nc)==(r,c)
                    if stay and on: nxt.add((nr,nc,temp,perm,1))
                    if maze[t+1][nr][nc]=='.': nxt.add((nr,nc,temp,perm,on if stay else 0))
                    else:
                        if not temp: nxt.add((nr,nc,1,perm,0))
                        if not perm: nxt.add((nr,nc,temp,1,1))
            if any(r==n-1 and c==m-1 for r,c,*_ in nxt): return True
            cur=nxt
        return False
