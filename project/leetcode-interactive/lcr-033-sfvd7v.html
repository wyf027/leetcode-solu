字母异位词分组

把字符组成相同、排列不同的单词装进同一个桶。核心不是两两比较，而是为每个单词制造稳定的“指纹”。

10 秒记忆

key = sort(word)
groups[key].push(word)

题意与约束

给定字符串数组 strs，把所有字母异位词分到一起，分组顺序和组内顺序都不要求固定。

若两个单词每个字母出现次数完全相同，它们就是字母异位词。例如 eat、tea、ate。

示例

["eat","tea","tan","ate","nat","bat"]

输出：[["eat","tea","ate"],["tan","nat"],["bat"]]

为什么键能相同？

排序会把 eat、tea、ate 都压缩成 aet。同一“多重集合”只有一个排序结果，所以可直接作为 Map 的键。

01 / 发现等价类

不要两两比较

暴力法要比较所有单词对。我们真正需要的是把同一类元素映射到同一个代表值。

02 / 生成指纹

排序后的字符串

复制单词字符并排序，得到唯一的规范化形式。它简单、直观，面试中优先写它。

03 / 归入桶中

Map 累积答案

键不存在就创建新数组；存在则追加当前原词。最后取所有 Map 的 values。

复杂度与取舍

排序键（本页实现）

设 n 为单词数，k 为平均长度：时间 O(n · k log k)，额外空间 O(n · k)（含结果和键）。

计数键（可选优化）

若确定只含小写英文字母，用 26 位频次数组序列化为键，时间可降到 O(n · k)；实现较长，字符集变化时也需调整。

四语言提交版

排序生成键，哈希表收集原字符串。

  1. 遍历每个单词，排序后的副本就是分组键。
  2. 在映射中初始化该键对应的数组，再推入未排序的原单词。
  3. 返回映射的所有值；组与组内排列均无需固定。

提交前验证清单

  • ✓ 空数组：返回空数组
  • ✓ 单个单词：独立成组
  • ✓ 重复单词：保留重复元素
  • ✓ 长度不同的字符串：不会错误合并
