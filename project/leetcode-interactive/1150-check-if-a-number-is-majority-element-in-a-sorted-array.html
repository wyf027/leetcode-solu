01 / PROBLEM

题目描述

关注“严格超过一半”与“非递减排列”这两个条件。

给定一个按非递减顺序排列的整数数组 nums 和一个整数 target。当且仅当 target 是数组的绝大多数元素时返回 true，否则返回 false。

绝大多数元素：在长度为 n 的数组中，出现次数严格大于 n / 2 的元素。恰好出现一半不算。
Official signature
boolean isMajorityElement(int[] nums, int target)
EXAMPLE 01
输入nums = [2,4,5,5,5,5,5,6,6], target = 5
输出true

5 出现 5 次，数组长度为 9；因为 5 > 9 / 2，所以它占绝大多数。

EXAMPLE 02
输入nums = [10,100,101,101], target = 101
输出false

101 出现 2 次，数组长度为 4；2 并没有严格大于 4 / 2。

03 / SOLUTION

一次二分，一次定点检查

↦

核心洞察

相同元素在有序数组里必然连续。先用二分找到 target 的首次出现位置 first；若它真的出现超过一半，那么向右移动 ⌊n / 2⌋ 后仍然必须是 target。

完整过程

  1. 在半开区间 [0, n) 上做 lower bound，找到第一个大于等于 target 的位置。
  2. 令 probe = first + ⌊n / 2⌋。
  3. 若 probe < n 且 nums[probe] == target，返回 true；否则返回 false。

边界处理

  • 目标不存在：lower bound 可能落在别的值上或落到 n，定点检查自然失败。
  • 恰好一半：向右移动 ⌊n/2⌋ 已越过目标连续段，所以返回 false。
  • 单元素数组：若唯一元素等于 target，则探测位置仍为 0，返回 true。
  • 探测越界：必须先判断 probe < n，利用短路求值避免非法访问。

正确性证明

lower bound 循环始终保留“第一个大于等于 target 的位置”在当前半开区间中；终止时 first 正是该位置。
若 target 出现次数严格大于 n/2，它从 first 开始的连续段至少包含 ⌊n/2⌋ + 1 项，因此 nums[first + ⌊n/2⌋] 必为 target。
反之，若该探测位置仍为 target，则从 first 到 probe 已连续包含 ⌊n/2⌋ + 1 个 target，严格超过数组的一半。故判定当且仅当成立。

复杂度

二分收缩搜索区间，最后只做一次数组访问。

时间 O(log n)空间 O(1)

替代方案

  • 线性计数：逐项统计 target，时间 O(n)、空间 O(1)，直观但没有利用有序性。
  • 双边界二分：分别求 lower bound 与 upper bound，以两者之差得到频次；同为 O(log n)，表达更通用，但多做一次二分。
  • 中点候选：多数元素必覆盖中点，可先检查中点再数边界；实现通常不如“首位 + 半长”简洁。

四语言完整实现

均使用官方函数名 isMajorityElement，核心逻辑保持一致。

JAVALeetCode 提交格式
class Solution {
    public boolean isMajorityElement(int[] nums, int target) {
        int left = 0;
        int right = nums.length;

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] >= target) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }

        int probe = left + nums.length / 2;
        return probe < nums.length && nums[probe] == target;
    }
}

};

04 / INTERVIEW

面试追问与常见错误

追问：为什么不必找到最后一次出现位置？

因为题目只问是否超过一半。知道首次位置后，只需检查“相隔半个数组”的位置是否仍在同一连续块内，无须精确计算完整频次。

追问：数组无序时怎么办？

这一技巧依赖相同值连续。无序时可线性统计 target；若题目改为寻找未知多数元素，可用 Boyer–Moore 找候选，再二次计数验证。

错误：把“多数”写成大于等于一半

定义要求严格大于 n/2。偶数长度时，恰好一半必须返回 false，第二个官方示例正是这个边界。

错误：先访问再检查 probe 是否越界

应先写 probe < n，再依靠逻辑与的短路特性访问数组。顺序颠倒可能越界。

错误：二分区间语义混用

这里始终使用半开区间 [left, right)，因此初始 right = n，且命中条件时令 right = mid。

追问：如何获得 target 的确切频次？

再做一次 upper bound，找第一个严格大于 target 的位置；upper - lower 即为频次，仍是 O(log n)。
