合并两个链表

从第一条链表中剪去一段连续节点，再把第二条链表严丝合缝地接入空位。先读清边界，再用演示器观察每一次指针变化。

MEDIUM 链表 原地重连 Merge In Between Linked Lists

任务摘要

删除区间[a, b]
插入对象整个 list2
返回结果链表头节点
下标从 0 开始，且区间两端都要删除。

Problem

题目说明

给定两个单链表 list1 和 list2，长度分别为 n 与 m。删除 list1 中下标从 a 到 b（含两端）的全部节点，并在这个位置接入完整的 list2。

构造连接后的链表，并返回它的头节点。

示例 1

删除 2 个节点
输入
list1 = [10,1,13,6,9,5], a = 3, b = 4, list2 = [1000000,1000001,1000002]
输出
[10,1,13,1000000,1000001,1000002,5]
解释移除下标 3、4 的节点，再把 list2 接到原位置。

示例 2

删除 4 个节点
输入
list1 = [0,1,2,3,4,5,6], a = 2, b = 5, list2 = [1000000,1000001,1000002,1000003,1000004]
输出
[0,1,1000000,1000001,1000002,1000003,1000004,6]
解释下标 2 至 5 的连续区间由 list2 整体替换。

Constraints

约束

  • 3 ≤ list1.length ≤ 10⁴
  • 1 ≤ a ≤ b < list1.length - 1
  • 1 ≤ list2.length ≤ 10⁴

Solution

找到三个节点，改动两条边

目标不是“搬运值”，而是保留节点并重连指针。定位 a - 1 位置、b + 1 位置以及 list2 尾节点后，拼接就只剩两次赋值。

核心洞察

  • preA 指向 list1 下标 a - 1 的节点，代表保留前缀的末端。
  • afterB 指向 list1 下标 b + 1 的节点，代表保留后缀的开端。
  • tail2 指向 list2 最后一个节点。
  • 令 preA.next = list2，再令 tail2.next = afterB。

完整过程

1从 list1 头节点走 a - 1 步，得到 preA。
2从原删除段首节点继续越过下标 a...b，得到 afterB。
3遍历 list2，找到其尾节点 tail2。
4按“前缀 → list2 → 后缀”的顺序重连，并返回 list1。

正确性证明

引理 1：第一次遍历结束后，preA 正好位于下标 a - 1。因为它从下标 0 开始前进了 a - 1 次。

引理 2：跳过区间中 b - a + 1 个节点后，afterB 正好指向下标 b + 1。

引理 3：tail2 是 list2 唯一满足 next = null 的末节点，因此可连接保留后缀而不遗漏 list2 的任何节点。

结论：两次重连后，从 list1 头节点出发依次经过原前缀、list2 全部节点、原后缀，且不再进入被删区间，所以返回链表恰为题目要求。

边界与复杂度

  • a = 1：preA 就是 list1 头节点。
  • b = n - 2：afterB 是原链表最后一个节点。
  • a = b：只替换一个节点，过程不变。
  • list2.length = 1：list2 的头尾是同一节点。
  • 时间复杂度 O(b + m)，额外空间复杂度 O(1)。

Implementations

四种语言完整代码

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode mergeInBetween(ListNode list1, int a, int b, ListNode list2) {
        ListNode preA = list1;
        for (int i = 0; i < a - 1; i++) {
            preA = preA.next;
        }

        ListNode afterB = preA.next;
        for (int i = a; i <= b; i++) {
            afterB = afterB.next;
        }

        ListNode tail2 = list2;
        while (tail2.next != null) {
            tail2 = tail2.next;
        }

        preA.next = list2;
        tail2.next = afterB;
        return list1;
    }
}

替代方案

哑节点写法：在 list1 前添加 dummy，可统一处理 a = 0 的扩展情形。但本题约束保证 a ≥ 1，直接从头节点定位更精简。

数组重建：先提取值再创建新链表虽然直观，却需要 O(n + m) 额外空间，也丢失了原地操作链表的核心意义。

常见错误

  • 把 b 当成开区间，少删除一个节点。
  • 定位到下标 a 而不是 a - 1，导致无法保留前缀连接点。
  • 修改 preA.next 后才寻找 afterB，从而丢失原后缀入口。
  • 只接上 list2 的头，却忘记让 list2 尾节点连接原后缀。
  • 误以为必须显式释放被替换区间；托管语言会在节点不可达后回收，C++ 在线评测通常只要求重连。

面试追问

  • 若允许 a = 0，怎样用 dummy 节点避免特判头节点？
  • 如果必须释放被删除节点的内存，C++ 中何时遍历并 delete 才安全？
  • 若链表可能有环，当前遍历会发生什么？如何先检测并处理？
  • 能否在只扫描 list1 一次的过程中同时得到两侧边界？

快速心智模型

把三段看成火车车厢：保留前缀、list2、保留后缀。先记住后缀车头，再让前缀车尾挂上 list2，最后让 list2 车尾挂上后缀。

顺序口诀：先存后缀，再接头尾。
