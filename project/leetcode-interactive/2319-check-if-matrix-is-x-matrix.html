Check if Matrix Is X-Matrix

01 / THE CHALLENGE

题目要求

给定整数方阵 grid，大小为 n × n。当两条对角线上的每一个元素都非零，且其余位置的元素全部为零时，这个方阵就是 X 矩阵。满足全部条件返回 true，否则返回 false。

参数：grid: integer[][]　返回：boolean。位置采用从 0 开始的行、列下标。

约束

  • n == grid.length == grid[i].length
  • 3 ≤ n ≤ 100
  • 0 ≤ grid[i][j] ≤ 10⁵

官方示例 1

grid = [[2,0,0,1],[0,3,1,0],[0,5,2,0],[4,0,0,2]]
输出：true

两条对角线上的值均非零，其余位置均为零。

官方示例 2

grid = [[5,7,0],[0,3,1],[0,5,0]]
输出：false

例如位置 (0,1) 不在对角线上，但值为 7；同时也存在对角线元素为零。

04 / EXPLANATION

想好后，再展开题解

题解：位置决定该不该为零

核心洞察

下标 (i,j) 位于主对角线时 i == j，位于副对角线时 i + j == n - 1。只要满足其中任意一个，就属于 X。于是每格都必须满足：属于对角线 == (值 != 0)。

完整过程

  1. 保存方阵阶数 n，按行遍历全部位置。
  2. 计算 diagonal = (i == j || i + j == n - 1)。
  3. 如果 diagonal 与 grid[i][j] != 0 不一致，立即返回 false。
  4. 所有格都符合要求后，返回 true。

示例 1 中，(0,0) 的 2 与 (0,3) 的 1 位于 X 上，(0,1) 和 (0,2) 为零，第一行符合要求。依次检查剩余三行，最终返回 true。示例 2 在 (0,1) 遇到非对角线上的 7，即可返回 false。

正确性

循环不变式：每次访问一个新位置前，已经访问的全部位置都满足 X 矩阵的对应条件。初始没有访问位置，不变式成立。若当前格的对角线归属与非零性不一致，它直接违反定义，因此返回 false 正确；否则加入当前格后，不变式仍成立。若遍历结束，所有位置均满足条件，定义中的两项要求同时成立，返回 true 正确。

边界与常见错误

  • 奇数阶中心同时属于两条对角线，但只需检查一次非零；判断用“或”，不要用“与”。
  • 副对角线下标和是 n - 1，不是 n。
  • 只检查两条对角线会漏掉外围非零元素，必须覆盖全部格。
  • 对角线的值可以不同，也可以大于 1；题目只要求非零。
  • 全零矩阵不是 X 矩阵。偶数阶不存在两条对角线重合的中心格。

复杂度

最坏时间 O(n²)，最多访问 n² 格；首格就冲突时可在 O(1) 时间返回。额外空间 O(1)，不修改输入。页面可视化保存格节点和扫描步骤，其空间开销与提交算法不同。

替代方案

可以先检查两条对角线，再遍历外围检查是否全为零，仍是 O(n²) 时间、O(1) 额外空间，但需要两段循环。也可以构造 X 布尔掩码再比较，会额外使用 O(n²) 空间，这道题没有必要。

面试追问

  • 为什么不能只花 O(n) 检查对角线？ 未访问的任意外围格可能藏着一个非零数；对任意稠密输入，最坏仍需读取所有格。
  • X 上一共有多少格？ 偶数阶为 2n，奇数阶为 2n−1，因为中心重合。
  • 若允许负数呢？ 仍用非零判断，不能替换成大于零。
  • 若矩阵逐行到达？ 已知 n 时，保留行号并即时检查每格即可，无需缓存整张矩阵。

Java

class Solution {
    public boolean checkXMatrix(int[][] grid) {
        int n = grid.length;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                boolean diagonal = i == j || i + j == n - 1;
                if (diagonal != (grid[i][j] != 0)) {
                    return false;
                }
            }
        }
        return true;
    }
}

var checkXMatrix = function(grid) {
    const n = grid.length;
    for (let i = 0; i < n; i++) {
        for (let j = 0; j < n; j++) {
            const diagonal = i === j || i + j === n - 1;
            if (diagonal !== (grid[i][j] !== 0)) {
                return false;
            }
        }
    }
    return true;
};

from typing import List

class Solution:
    def checkXMatrix(self, grid: List[List[int]]) -> bool:
        n = len(grid)
        for i in range(n):
            for j in range(n):
                diagonal = i == j or i + j == n - 1
                if diagonal != (grid[i][j] != 0):
                    return False
        return True
