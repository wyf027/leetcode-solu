大小为 K 的
不重叠线段的数目

在一条离散数轴上，线段可以接触，却不能交叠。这里考验的不是画线，而是如何精确刻画“共享端点”这条微妙规则。

Number of Sets of K Non-Overlapping Line Segments非付费题取模 10⁹ + 7
01 · Problem

题意与边界

先把几何语言翻成严格条件。此处只呈现题目，不提前给出解法。

准确转述

一维平面上有 n 个点，第 i 个点位于整数坐标 x = i（编号为 0…n−1）。请画出恰好 k 条互不重叠的线段，每条线段必须覆盖至少两个点，且两端点均为整数坐标。

线段不必覆盖全部点；相邻线段允许共享端点。返回不同画法的数量，并对 1,000,000,007 取模。

输入约束

  • 2 ≤ n ≤ 1000
  • 1 ≤ k ≤ n − 1
  • 函数签名：numberOfSets(n, k)
  • 返回值：整数（取模后）

示例 1

共享端点是合法的
输入：n = 4, k = 2
输出：5
解释：5 种方案为
{(0,2),(2,3)}、{(0,1),(1,3)}、{(0,1),(2,3)}、
{(1,2),(2,3)}、{(0,1),(1,2)}。

示例 2

输入：n = 3, k = 1
输出：3
解释：{(0,1)}、{(0,2)}、{(1,2)}。

示例 3

输入：n = 30, k = 7
输出：796297179
解释：原数 3796297200 对 10⁹ + 7 取模。

示例 4

输入：n = 5, k = 3
输出：7

示例 5

输入：n = 3, k = 2
输出：1

04 · Insight

把弱不等号变成严格不等号

关键不在二维 DP，而在于发现端点序列与一个普通组合选择之间存在双射。

① 排序

记端点为 a₁ < b₁ ≤ a₂ < b₂ ≤ … ≤ aₖ < bₖ。

② 位移

第 t 条线段的两个端点都加上 t−1。

③ 选择

得到 2k 个严格递增整数，落在 0…n+k−2。

answer = C(n + k − 1, 2k) mod (10⁹ + 7)

扩展坐标一共有 n+k−1 个位置，从中选择 2k 个即可。由于上界不足 2000 且模数为质数，可以用乘法公式配合费马小定理求逆元。

完整过程

  1. 把每个方案按从左到右写成端点序列。
  2. 对第 t 条线段的两个端点加 t−1。原本段间的 ≤ 因多加了 1，变为严格 <。
  3. 新序列是从 0…n+k−2 选出的 2k 个严格递增位置。
  4. 用组合数乘法公式计算，逐项乘上分子，再乘分母的模逆元。

正确性证明

正向：段内本就严格递增；相邻线段之间即使共享端点，后一段整体多平移 1，因此转换后所有相邻端点都严格递增。

反向：任取扩展坐标中的 2k 个严格递增值，将第 t 对端点同时减去 t−1。段内仍严格递增；两段之间最多从严格关系退化为相等，因此不交叠且允许共享端点。

双射：两种变换互为逆操作，所以合法线段集合与这些端点选择一一对应，组合数即为答案。

边界与复杂度

  • k = 1：答案为 C(n,2)，即任意选两个不同端点。
  • k = n−1：只有所有相邻点连线这一种方案。
  • 利用 C(N,R)=C(N,N−R) 缩短循环。
  • 时间复杂度 O(min(2k,n−k−1))，空间复杂度 O(1)。

替代方案与面试追问

  • DP：可按点位置、已完成线段数、是否处于开放线段来转移，时间约 O(nk)、空间可压缩。
  • 追问：若禁止共享端点，端点直接是从 n 个点中选 2k 个。
  • 追问：若模数不是质数，费马逆元失效，应改用质因数分解、扩展欧几里得或 Pascal DP。
  • 追问：若点坐标不连续但只在给定点上取端点，计数仍只依赖点的相对顺序。
常见错误：把“线段不重叠”误读为“端点不能相同”；把组合数写成 C(n,2k)；使用普通除法代替模逆元；JavaScript 在更大范围中直接连乘导致精度丢失；或忘记每次乘法都取模。

四语言完整实现

均使用官方函数签名；核心是组合数与快速幂求模逆元。

Javalong 防止乘法溢出
class Solution {
    private static final long MOD = 1_000_000_007L;

    public int numberOfSets(int n, int k) {
        int top = n + k - 1;
        int choose = 2 * k;
        int r = Math.min(choose, top - choose);
        long answer = 1L;

        for (int i = 1; i <= r; i++) {
            answer = answer * (top - r + i) % MOD;
            answer = answer * modPow(i, MOD - 2) % MOD;
        }
        return (int) answer;
    }

    private long modPow(long base, long exponent) {
        long result = 1L;
        while (exponent > 0) {
            if ((exponent & 1L) == 1L) {
                result = result * base % MOD;
            }
            base = base * base % MOD;
            exponent >>= 1;
        }
        return result;
    }
}

    const MOD = 1000000007;
    const top = n + k - 1;
    const choose = 2 * k;
    const r = Math.min(choose, top - choose);
    let answer = 1;

    const modPow = (base, exponent) => {
        let result = 1;

            if (exponent % 2 === 1) {
                result = (result * base) % MOD;

            base = (base * base) % MOD;

class Solution {
private:
    static constexpr long long MOD = 1'000'000'007LL;

    long long modPow(long long base, long long exponent) {
        long long result = 1;
        while (exponent > 0) {
            if (exponent & 1LL) {
                result = result * base % MOD;
            }
            base = base * base % MOD;
            exponent >>= 1;
        }
        return result;
    }

public:
    int numberOfSets(int n, int k) {
        int top = n + k - 1;
        int choose = 2 * k;
        int r = min(choose, top - choose);
        long long answer = 1;

        for (int i = 1; i <= r; ++i) {
            answer = answer * (top - r + i) % MOD;
            answer = answer * modPow(i, MOD - 2) % MOD;
        }
        return static_cast<int>(answer);
    }
};
