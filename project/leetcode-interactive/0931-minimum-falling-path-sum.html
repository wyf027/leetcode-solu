LeetCode 931 · Matrix route study

下降路径
最小和

Minimum Falling Path Sum

参数：matrix: integer[][]返回：integer非付费题

题目

先理解移动规则，再打开题解

给定一个 n × n 的整数方阵 matrix。一条下降路径可以从第一行任意位置出发；从坐标 (row, col) 到下一行时，只能走向 (row + 1, col - 1)、(row + 1, col) 或 (row + 1, col + 1) 中仍在矩阵范围内的位置。请返回所有合法下降路径中，元素总和的最小值。

示例 1

输入：matrix = [[2,1,3],[6,5,4],[7,8,9]]
输出：13
解释：存在两条总和为 13 的最优下降路径。

示例 2

输入：matrix = [[-19,57],[-40,-5]]
输出：-59
解释：选择 -19 后向左下到 -40。

约束

  • n == matrix.length == matrix[i].length
  • 1 <= n <= 100
  • -100 <= matrix[i][j] <= 100

题解

动态规划 · 滚动数组

核心洞察

到达当前格的最小代价，只依赖上一行相邻的至多三个格。把“走过哪些完整路径”压缩为“到每个位置的最优前缀”，就不必枚举指数级路径。

状态与转移

dp[j] 表示处理到上一行时，以第 j 列结尾的最小路径和。处理新行时：

next[j] = matrix[i][j] + min(dp[j-1], dp[j], dp[j+1])

越界邻居不参与比较；最后答案是末行状态的最小值。

完整过程

  1. 复制第一行作为初始 dp，因为路径可以从第一行任何位置开始。
  2. 从第二行起，为每一列读取上一行合法的左上、正上、右上状态，并加上当前格。
  3. 一整行计算完后，用 next 替换 dp。不能边读边覆盖，否则右侧格可能读到本行数据。
  4. 所有行处理完，返回 min(dp)。

正确性证明

  1. 基础：第一行中，以每格结尾的唯一路径只包含它自身，因此初始状态正确。
  2. 归纳：假设上一行各状态均为对应终点的最小路径和。任何到当前格的合法路径，倒数第二格必在其三个上方邻居之一；取这些最优值的最小者再加当前值，恰得当前格最小路径和。
  3. 结论：归纳至末行后，每个状态都正确；任意完整下降路径必终止于末行某格，故末行最小状态即全局答案。

边界与复杂度

  • n = 1：直接返回唯一元素。
  • 首末列只有两个合法前驱。
  • 负数无需特殊处理，转移仍成立。
  • 时间复杂度 O(n²)；额外空间 O(n)。

替代方案

可直接在输入矩阵上逐行累加，将额外空间降为 O(1)，但会修改参数。也可用二维 DP，思路直观但空间为 O(n²)。自顶向下记忆化同为 O(n²)，但有递归开销。

面试追问

  • 若允许修改输入，怎样原地转移？
  • 如何同时还原一条最优路径？——保存每格选择的前驱列。
  • 矩阵不是方阵是否仍适用？——适用，只需分别处理行列数。
  • 若可移动范围扩展到左右各 k 列，如何优化最小值查询？——考虑滑动窗口最小值。

常见错误

  • 把转移写成同一行左右移动。
  • 更新滚动数组时原地覆盖，污染后续转移。
  • 对首列或末列读取越界索引。
  • 把答案误写为右下角状态，而非末行最小值。
  • 将初值设为 0，导致全负或全正数据出现虚构路径。
