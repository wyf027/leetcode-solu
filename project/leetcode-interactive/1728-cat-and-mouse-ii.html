猫和老鼠 Cat & Mouse II

不是追逐速度的直觉题，而是一场带截止时间的完全信息博弈。先观察“剩余操作数”如何反向传播，再决定是否揭开完整题解。

01 / Problem

题意与规则

给定 rows × cols 网格：C 是猫、M 是老鼠、F 是食物、. 是地板、# 是墙。老鼠先手，双方轮流行动并采用最优策略。

  • 每次可原地不动，或沿上下左右跳 1 到自己的最大距离。
  • 不能越墙或出界；老鼠允许越过猫，猫碰到老鼠即获胜。
  • 猫与老鼠重合，或猫先到食物：猫赢；老鼠先到食物：老鼠赢。
  • 老鼠未能在 1000 次操作以内到达食物，猫赢。

函数签名

canMouseWin(grid, catJump, mouseJump) → boolean

约束

  • 1 ≤ rows, cols ≤ 8
  • 每格只含 C M F . #，且 C、M、F 各一个。
  • 1 ≤ catJump, mouseJump ≤ 8

04 / Spoiler gate

准备好再看完整题解

核心洞察

状态写成 dp[t][m][c][turn]：已经进行 t 次操作、双方位置和行动者确定时，老鼠能否保证获胜。题目有硬截止线 1000，因此从 t = 1000 反向滚动到 0，最直接地刻画规则。

只保存相邻两层，把空间从 1000 倍压到 O(V²)，V 是非墙格数。

胜负递推

  • 终止态优先：重合或猫在食物处为 false；老鼠在食物处为 true。
  • 老鼠回合：存在一个后继为 true，当前即为 true。
  • 猫回合：所有后继都为 true，老鼠才仍能保证赢。
  • 截止层的非终止态全是 false，表示超时猫胜。

完整过程

  1. 将所有格子编号，记录猫、老鼠和食物位置。
  2. 分别预计算每格的跳跃落点，包含原地；射线遇墙或边界停止。
  3. 初始化 t = 1000 层：只有老鼠已安全到食物的状态为 true。
  4. 从 t = 999 到 0，枚举老鼠位置、猫位置和行动者，按极大/极小选择计算。
  5. 猫沿射线若先碰到老鼠，可落到该格捕获，但不能越过；老鼠允许越过猫。
  6. 返回 dp[0][mouseStart][catStart][MOUSE]。

正确性

基例：截止层中，老鼠已安全到食物才获胜，其余未结束状态超时，定义正确。

归纳：若 t+1 层正确，老鼠能选择任一获胜后继；猫只需选择任一使老鼠失败的后继。两条递推恰好覆盖双方最优选择，所以 t 层正确。反向归纳至初始层，返回值正确。

复杂度与边界

令 V ≤ 64，每格落点数 D ≤ 33。时间 O(1000·V²·D)，空间 O(V²+V·D)。

包含原地；射线遇墙停止；终止判断先处理捕获/猫到食物，再处理老鼠到食物。

替代方案

也可从终止态在有限状态图上逆向拓扑染色，未染色环判猫胜。它通常更快，但需要额外论证 1000 次截止与图收敛关系，并处理猫移动对老鼠位置的依赖。面试时，截止层 DP 更容易严谨解释。

面试追问

  • 上限改为 K：把 1000 参数化。
  • 双方不能停留：删除移动表中的自身。
  • 为何可滚动：第 t 层只依赖 t+1 层。
  • 如何降常数：压平状态并预计算移动。

常见错误

  • 用普通最短路比较距离，忽略双方最优对抗。
  • 忘记原地不动，或让跳跃越墙。
  • 错误禁止老鼠越过猫，或允许猫越过老鼠。
  • 把猫回合也写成“存在一个 true”。
  • 分配 1001 个完整对象层，导致内存浪费。

import java.util.*;

class Solution {
    private int rows, cols, food;
    private String[] grid;

    public boolean canMouseWin(String[] grid, int catJump, int mouseJump) {
        this.grid = grid;
        rows = grid.length;
        cols = grid[0].length();
        int n = rows * cols, mouse = -1, cat = -1;
        for (int r = 0; r < rows; r++) {
            for (int c = 0; c < cols; c++) {
                int p = r * cols + c;
                char ch = grid[r].charAt(c);
                if (ch == 'M') mouse = p;
                else if (ch == 'C') cat = p;
                else if (ch == 'F') food = p;
            }
        }
        List<Integer>[] mouseMoves = buildMoves(mouseJump);
        List<Integer>[] catMoves = buildMoves(catJump);
        boolean[][][] next = new boolean[n][n][2];
        fillDeadline(next, n);

        for (int step = 999; step >= 0; step--) {
            boolean[][][] cur = new boolean[n][n][2];
            for (int m = 0; m < n; m++) {
                for (int c = 0; c < n; c++) {
                    if (!open(m) || !open(c) || m == c || c == food) continue;
                    if (m == food) {
                        cur[m][c][0] = cur[m][c][1] = true;
                        continue;
                    }
                    for (int to : mouseMoves[m]) {
                        if (next[to][c][1]) {
                            cur[m][c][0] = true;
                            break;
                        }
                    }
                    boolean allWin = true;
                    for (int to : legalCatMoves(c, m, catMoves[c])) {
                        if (!next[m][to][0]) {
                            allWin = false;
                            break;
                        }
                    }
                    cur[m][c][1] = allWin;
                }
            }
            next = cur;
        }
        return next[mouse][cat][0];
    }

    private boolean open(int p) {
        return grid[p / cols].charAt(p % cols) != '#';
    }

    @SuppressWarnings("unchecked")
    private List<Integer>[] buildMoves(int jump) {
        int n = rows * cols;
        List<Integer>[] moves = new List[n];
        int[][] directions = {{1,0},{-1,0},{0,1},{0,-1}};
        for (int p = 0; p < n; p++) {
            moves[p] = new ArrayList<>();
            if (!open(p)) continue;
            moves[p].add(p);
            int r = p / cols, c = p % cols;
            for (int[] d : directions) {
                for (int k = 1; k <= jump; k++) {
                    int nr = r + d[0] * k, nc = c + d[1] * k;
                    if (nr < 0 || nr >= rows || nc < 0 || nc >= cols
                            || grid[nr].charAt(nc) == '#') break;
                    moves[p].add(nr * cols + nc);
                }
            }
        }
        return moves;
    }

    private List<Integer> legalCatMoves(int from, int mouse, List<Integer> raw) {
        List<Integer> result = new ArrayList<>();
        int fr = from / cols, fc = from % cols;
        int mr = mouse / cols, mc = mouse % cols;
        for (int to : raw) {
            if (to == from) {
                result.add(to);
                continue;
            }
            int tr = to / cols, tc = to % cols;
            boolean crosses = fr == tr
                    ? mr == fr && (mc - fc) * (tc - fc) > 0
                      && Math.abs(mc - fc) < Math.abs(tc - fc)
                    : mc == fc && (mr - fr) * (tr - fr) > 0
                      && Math.abs(mr - fr) < Math.abs(tr - fr);
            if (!crosses) result.add(to);
        }
        return result;
    }

    private void fillDeadline(boolean[][][] layer, int n) {
        for (int m = 0; m < n; m++) {
            for (int c = 0; c < n; c++) {
                if (open(m) && open(c) && m == food && m != c && c != food) {
                    layer[m][c][0] = layer[m][c][1] = true;
                }
            }
        }
    }
}

var canMouseWin = function(grid, catJump, mouseJump) {
  const R = grid.length, C = grid[0].length, N = R * C;
  let mouse = -1, cat = -1, food = -1;
  for (let r = 0; r < R; r++) for (let c = 0; c < C; c++) {
    const p = r * C + c;
    if (grid[r][c] === 'M') mouse = p;
    else if (grid[r][c] === 'C') cat = p;
    else if (grid[r][c] === 'F') food = p;
  }
  const open = p => grid[Math.floor(p / C)][p % C] !== '#';
  const build = jump => Array.from({length: N}, (_, p) => {
    if (!open(p)) return [];
    const out = [p], r = Math.floor(p / C), c = p % C;
    for (const [dr, dc] of [[1,0],[-1,0],[0,1],[0,-1]]) {
      for (let k = 1; k <= jump; k++) {
        const nr = r + dr * k, nc = c + dc * k;
        if (nr < 0 || nr >= R || nc < 0 || nc >= C || grid[nr][nc] === '#') break;
        out.push(nr * C + nc);
      }
    }
    return out;
  });
  const mouseMoves = build(mouseJump), catMoves = build(catJump);
  const legalCat = (from, m) => catMoves[from].filter(to => {
    if (to === from) return true;
    const fr = Math.floor(from/C), fc = from%C, tr = Math.floor(to/C), tc = to%C;
    const mr = Math.floor(m/C), mc = m%C;
    return !(fr === tr
      ? mr === fr && (mc-fc)*(tc-fc) > 0 && Math.abs(mc-fc) < Math.abs(tc-fc)
      : mc === fc && (mr-fr)*(tr-fr) > 0 && Math.abs(mr-fr) < Math.abs(tr-fr));
  });
  const make = () => new Uint8Array(N * N * 2);
  const id = (m, c, turn) => (m * N + c) * 2 + turn;
  let next = make();
  for (let m = 0; m < N; m++) for (let c = 0; c < N; c++) {
    if (open(m) && open(c) && m === food && m !== c && c !== food) {
      next[id(m,c,0)] = next[id(m,c,1)] = 1;
    }
  }
  for (let step = 999; step >= 0; step--) {
    const cur = make();
    for (let m = 0; m < N; m++) for (let c = 0; c < N; c++) {
      if (!open(m) || !open(c) || m === c || c === food) continue;
      if (m === food) {
        cur[id(m,c,0)] = cur[id(m,c,1)] = 1;
        continue;
      }
      if (mouseMoves[m].some(to => next[id(to,c,1)])) cur[id(m,c,0)] = 1;
      if (legalCat(c,m).every(to => next[id(m,to,0)])) cur[id(m,c,1)] = 1;
    }
    next = cur;
  }
  return Boolean(next[id(mouse,cat,0)]);
};
from typing import List

class Solution:
    def canMouseWin(self, grid: List[str], catJump: int, mouseJump: int) -> bool:
        rows, cols = len(grid), len(grid[0])
        n = rows * cols
        mouse = cat = food = -1
        for r in range(rows):
            for c, ch in enumerate(grid[r]):
                p = r * cols + c
                if ch == 'M': mouse = p
                elif ch == 'C': cat = p
                elif ch == 'F': food = p

        def is_open(p):
            return grid[p // cols][p % cols] != '#'

        def build(jump):
            moves = [[] for _ in range(n)]
            for p in range(n):
                if not is_open(p): continue
                moves[p].append(p)
                r, c = divmod(p, cols)
                for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
                    for k in range(1, jump + 1):
                        nr, nc = r + dr * k, c + dc * k
                        if not (0 <= nr < rows and 0 <= nc < cols) or grid[nr][nc] == '#':
                            break
                        moves[p].append(nr * cols + nc)
            return moves

        mouse_moves, cat_moves = build(mouseJump), build(catJump)

        def legal_cat_moves(pos, m):
            fr, fc = divmod(pos, cols)
            mr, mc = divmod(m, cols)
            for to in cat_moves[pos]:
                if to == pos:
                    yield to
                    continue
                tr, tc = divmod(to, cols)
                crosses = (
                    fr == tr and mr == fr and (mc-fc)*(tc-fc) > 0
                    and abs(mc-fc) < abs(tc-fc)
                ) or (
                    fc == tc and mc == fc and (mr-fr)*(tr-fr) > 0
                    and abs(mr-fr) < abs(tr-fr)
                )
                if not crosses: yield to

        nxt = [[[False, False] for _ in range(n)] for _ in range(n)]
        for m in range(n):
            for c in range(n):
                if is_open(m) and is_open(c) and m == food and m != c and c != food:
                    nxt[m][c] = [True, True]

        for _ in range(999, -1, -1):
            cur = [[[False, False] for _ in range(n)] for _ in range(n)]
            for m in range(n):
                for c in range(n):
                    if not is_open(m) or not is_open(c) or m == c or c == food: continue
                    if m == food:
                        cur[m][c] = [True, True]
                        continue
                    cur[m][c][0] = any(nxt[to][c][1] for to in mouse_moves[m])
                    cur[m][c][1] = all(nxt[m][to][0] for to in legal_cat_moves(c, m))
            nxt = cur
        return nxt[mouse][cat][0]
class Solution {
public:
    bool canMouseWin(vector<string>& grid, int catJump, int mouseJump) {
        int R = grid.size(), C = grid[0].size(), N = R * C;
        int mouse = -1, cat = -1, food = -1;
        for (int r=0; r<R; r++) for (int c=0; c<C; c++) {
            int p=r*C+c;
            if (grid[r][c]=='M') mouse=p;
            else if (grid[r][c]=='C') cat=p;
            else if (grid[r][c]=='F') food=p;
        }
        auto open = [&](int p) { return grid[p/C][p%C] != '#'; };
        auto build = [&](int jump) {
            vector<vector<int>> moves(N);
            int ds[4][2]={{1,0},{-1,0},{0,1},{0,-1}};
            for (int p=0; p<N; p++) if (open(p)) {
                moves[p].push_back(p);
                int r=p/C, c=p%C;
                for (auto &d:ds) for (int k=1; k<=jump; k++) {
                    int nr=r+d[0]*k, nc=c+d[1]*k;
                    if (nr<0 || nr>=R || nc<0 || nc>=C || grid[nr][nc]=='#') break;
                    moves[p].push_back(nr*C+nc);
                }
            }
            return moves;
        };
        auto mouseMoves=build(mouseJump), catMoves=build(catJump);
        auto legalCat = [&](int from, int m) {
            vector<int> out;
            int fr=from/C, fc=from%C, mr=m/C, mc=m%C;
            for (int to:catMoves[from]) {
                if (to==from) { out.push_back(to); continue; }
                int tr=to/C, tc=to%C;
                bool crosses = fr==tr
                    ? mr==fr && (mc-fc)*(tc-fc)>0 && abs(mc-fc)<abs(tc-fc)
                    : mc==fc && (mr-fr)*(tr-fr)>0 && abs(mr-fr)<abs(tr-fr);
                if (!crosses) out.push_back(to);
            }
            return out;
        };
        using Layer = vector<vector<array<char,2>>>;
        Layer next(N, vector<array<char,2>>(N, {0,0}));
        for (int m=0;m<N;m++) for (int c=0;c<N;c++)
            if (open(m)&&open(c)&&m==food&&m!=c&&c!=food) next[m][c]={1,1};

        for (int step=999; step>=0; step--) {
            Layer cur(N, vector<array<char,2>>(N, {0,0}));
            for (int m=0;m<N;m++) for (int c=0;c<N;c++) {
                if (!open(m)||!open(c)||m==c||c==food) continue;
                if (m==food) { cur[m][c]={1,1}; continue; }
                for (int to:mouseMoves[m]) if (next[to][c][1]) {
                    cur[m][c][0]=1; break;
                }
                cur[m][c][1]=1;
                for (int to:legalCat(c,m)) if (!next[m][to][0]) {
                    cur[m][c][1]=0; break;
                }
            }
            next.swap(cur);
        }
        return next[mouse][cat][0];
    }
};
