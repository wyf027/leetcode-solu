1738. 找出第 K 大的异或坐标值

Find Kth Largest XOR Coordinate Value

MEDIUM二维前缀位运算矩阵排序 / 堆

Problem

题意

给定一个由非负整数组成的 m × n 矩阵 matrix 和整数 k。坐标 (a, b) 的目标值，是左上角 (0, 0) 到该坐标的矩形内所有元素的异或结果：

value(a,b) = matrix[0][0] XOR … XOR matrix[a][b]

收集全部 m × n 个坐标值，返回其中第 k 大的值；k 从 1 开始计数。

示例 1
输入：matrix = [[5,2],[1,6]], k = 1
输出：7
解释：(0,1) 的值为 5 XOR 2 = 7，是最大值。
示例 2
输入：matrix = [[5,2],[1,6]], k = 2
输出：5
解释：(0,0) 的值为 5，是第 2 大。
示例 3
输入：matrix = [[5,2],[1,6]], k = 3
输出：4
解释：(1,0) 的值为 5 XOR 1 = 4，是第 3 大。
示例 4
输入：matrix = [[5,2],[1,6]], k = 4
输出：0
解释：(1,1) 的值为 5 XOR 2 XOR 1 XOR 6 = 0。

约束

  • m == matrix.length
  • n == matrix[i].length
  • 1 <= m, n <= 1000
  • 0 <= matrix[i][j] <= 10⁶
  • 1 <= k <= m × n

Solution

完整题解（默认隐藏）

先独立思考，再展开核对二维异或前缀的推导。

核心洞察

如果为每个坐标重新扫描左上矩形，总工作量会远超矩阵规模。令 pre[i][j] 表示从 (0,0) 到 (i-1,j-1) 的异或值，并在顶部、左侧各补一圈 0。异或满足结合律，而且 x XOR x = 0，所以重叠区域出现两次会自动抵消：

pre[i][j] = matrix[i-1][j-1] XOR pre[i-1][j] XOR pre[i][j-1] XOR pre[i-1][j-1]

每格只需常数次运算。将全部前缀值收集并降序排列，答案就是下标 k - 1。

完整过程

  1. 创建 (m+1) × (n+1) 的全零前缀矩阵，避免边界分支。
  2. 按行从左到右计算每个 pre[i][j]。
  3. 把每个真实坐标对应的前缀异或值加入一维数组。
  4. 将数组降序排序并返回第 k 项。

正确性

pre[i-1][j] 覆盖去掉末行的矩形，pre[i][j-1] 覆盖去掉末列的矩形。左上重叠区被包含两次，异或后抵消；再异或 pre[i-1][j-1] 恢复一次，最后异或当前元素，恰好得到整个目标矩形。补出的第 0 行、第 0 列都是 0，归纳可知公式对所有坐标成立。结果数组包含且只包含全部坐标值，因此降序后的第 k-1 项就是第 k 大。

边界

  • 单行或单列：补零边界让同一公式直接生效。
  • 零元素：x XOR 0 = x，无需特判。
  • 重复值：按多重集合计数，不能去重。
  • k = 1 或 m×n：分别返回最大或最小值。
  • JavaScript：输入小于 2²⁰，异或结果仍在安全的非负 32 位范围。

复杂度

设 N = m × n。计算前缀是 O(N)，排序是 O(N log N)，总时间 O(N log N)，空间 O(N)。前缀表可滚动压缩为 O(n)，但排序数组仍需 O(N)。

替代方案

大小为 k 的最小堆：只保留最大的 k 个值，时间 O(N log k)、额外空间 O(k+n)，适合 k 较小。快速选择：平均 O(N)，最坏 O(N²)，需谨慎处理枢轴和下标。

面试追问

  • 如何压缩前缀表？保存当前列上方旧值和左上旧值，逐列滚动。
  • 为什么无需“减”重叠？XOR 自身就是逆运算。
  • 流式读入且 k 很小怎么办？滚动前缀数组配最小堆。
  • 多个 k 查询？一次排序后每次 O(1) 回答。

常见错误

  • 遗漏左上重叠项 pre[i-1][j-1]。
  • 把 XOR 误写成加减或逻辑运算。
  • 返回排序数组下标 k，产生一位偏差。
  • 用集合去重，破坏重复值的排名。

import java.util.Arrays;

class Solution {
    public int kthLargestValue(int[][] matrix, int k) {
        int m = matrix.length, n = matrix[0].length;
        int[][] pre = new int[m + 1][n + 1];
        int[] values = new int[m * n];
        int index = 0;
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                pre[i][j] = matrix[i - 1][j - 1]
                    ^ pre[i - 1][j] ^ pre[i][j - 1]
                    ^ pre[i - 1][j - 1];
                values[index++] = pre[i][j];
            }
        }
        Arrays.sort(values);
        return values[values.length - k];
    }
}

var kthLargestValue = function(matrix, k) {
    const m = matrix.length, n = matrix[0].length;
    const pre = Array.from(
        { length: m + 1 }, () => Array(n + 1).fill(0)
    );
    const values = [];
    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            pre[i][j] = matrix[i - 1][j - 1]
                ^ pre[i - 1][j] ^ pre[i][j - 1]
                ^ pre[i - 1][j - 1];
            values.push(pre[i][j]);
        }
    }
    values.sort((a, b) => b - a);
    return values[k - 1];
};
from typing import List


class Solution:
    def kthLargestValue(
        self, matrix: List[List[int]], k: int
    ) -> int:
        m, n = len(matrix), len(matrix[0])
        pre = [[0] * (n + 1) for _ in range(m + 1)]
        values = []
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                pre[i][j] = (
                    matrix[i - 1][j - 1]
                    ^ pre[i - 1][j] ^ pre[i][j - 1]
                    ^ pre[i - 1][j - 1]
                )
                values.append(pre[i][j])
        values.sort(reverse=True)
        return values[k - 1]

class Solution {
public:
    int kthLargestValue(vector<vector<int>>& matrix, int k) {
        int m = matrix.size(), n = matrix[0].size();
        vector<vector<int>> pre(m + 1, vector<int>(n + 1));
        vector<int> values;
        values.reserve(m * n);
        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {
                pre[i][j] = matrix[i - 1][j - 1]
                    ^ pre[i - 1][j] ^ pre[i][j - 1]
                    ^ pre[i - 1][j - 1];
                values.push_back(pre[i][j]);
            }
        }
        sort(values.begin(), values.end(), greater<int>());
        return values[k - 1];
    }
};
