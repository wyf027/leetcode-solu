两个回文子序列
长度的最大乘积

Maximum Product of the Length of Two Palindromic Subsequences

同一条字符串，两条互不抢占位置的回文。你能让它们的长度乘积达到多大？

01 / 题目

给定字符串 s，选出两个非空回文子序列，使它们的长度乘积最大，返回这个最大整数。两条子序列不能使用原字符串的同一个下标，但可以包含相同字母，也可以交错选取位置。

子序列可以跳过字符，但必须保留原有顺序；回文表示正着读与反着读相同。不要求用完全部字符。

参数与返回值

maxProduct(s: string) → integer

输入只有一个参数：字符串 s。

约束

  • 2 ≤ s.length ≤ 12
  • s 仅由小写英文字母组成。

04 / 题解 · 为第一条回文留出补集

核心洞察

字符串最多 12 个字符，所有位置集合只有 2¹² = 4096 个。用一个整数掩码标记选择的下标，位 i 为 1 表示使用 s[i]。两条子序列不相交等价于 (a & b) === 0。

固定第一条回文的掩码 a 后，第二条只能从 full ^ a 中选。提前求出每个集合内部能选出的最长回文长度，就能一次查表得到最佳搭档。

完整过程

  1. 枚举全部掩码，按下标递增收集字符，判断是否回文。令 pal[mask] 为该掩码自身的回文长度，不是回文则为 0，空集合也为 0。
  2. 复制得到 best = pal。目标是让 best[mask] 表示 mask 的任意子集能组成的最长回文长度。
  3. 按位 i 从 0 到 n−1 传播：若 mask 含第 i 位，执行 best[mask] = max(best[mask], best[mask ^ (1 << i)])。这是子集最大值 DP。
  4. 枚举非空回文 a，计算 pal[a] × best[full ^ a]，取最大值。

不能直接用补集的长度。 补集本身可能不是回文；第二条还可以丢掉补集中的一些字符。best 查询的是补集内部的最长回文。

下标分配实验室

预处理回文与子集 DP 后，每一步固定一个非空回文 A，展示补集中的最佳 B。按 A 的掩码递增播放；预处理只展示汇总，不逐一播放 DP 更新。

为什么正确？


  1. 回文枚举完整：每条子序列都对应一个下标集合，所有掩码覆盖所有集合；按原顺序读取并判断回文，因此 pal 准确描述每个集合自身。
  2. 子集 DP 正确：初始 best 只允许保留全部位。处理第 i 位时，一个可选子集要么保留该位，值已在当前 best 中；要么去掉该位，由 best[mask 去掉 i] 提供。逐位处理后，所有位都可保留或去掉，故得到全部子集的最大回文长度。
  3. 配对合法且最优：B 来自 A 的补集，必与 A 不相交。任意最优方案 (A*, B*) 中，A* 一定被枚举，B* 是其补集的子集，查表得到的长度不会小于 B*。同时查表只产生合法回文，因此所得最大值恰好为全局最优。


复杂度
回文预处理 O(n · 2ⁿ)，子集 DP O(n · 2ⁿ)，最终枚举 O(2ⁿ)。总时间 O(n · 2ⁿ)，数组占用 O(2ⁿ)，构造单条子序列的临时空间 O(n)。演示额外保存每个候选 A 的快照，仍为 O(2ⁿ)。


边界与数值
  • n = 2 时，两条单字符回文给出 1；即使字母不同也成立。
  • 没有重复字母时，最大乘积为 1；全部相同时，均分字符可达 ⌊n²/4⌋。
  • 某个 A 占满全部位置时，补集为空，乘积为 0，不会影响正确答案。空回文只作为 DP 哨兵，最终正数对应两条非空回文。
  • n ≤ 12，JavaScript 32 位位运算足够，最大答案为 36。更大 n 会首先遇到指数级时间与空间限制。


替代方案
对每个回文 A 枚举其补集的所有子掩码 B，总计 O(3ⁿ + n · 2ⁿ) 时间、O(2ⁿ) 空间，实现直观，但会重复查询补集中的回文。也可把每个字符分配给 A、B 或不用，做 3ⁿ 种回溯分配，在叶子判断两个回文，时间 O(n · 3ⁿ)、递归空间 O(n)。


常见错误
  • 把子序列当成连续子串，遗漏跳跃与交错的合法方案。
  • 按字母值判断冲突。冲突由下标决定，相同字母可以分别选。
  • 使用 ~a 直接当补集，混入有效 n 位以外的位。使用 full ^ a。
  • 先贪心选全局最长回文。它可能用掉第二条需要的位置，乘积不一定最大。
  • 混淆 pal 与 best：一个检查当前集合自身，一个允许继续删除字符。


面试追问
如何返回两条序列？在 best 更新时同步记录来源掩码；记录取得最大乘积的 A 和 B，再按位读取字符。下面的演示即用此方法恢复 B。
能否扩展到三条？需要同时决定更多互斥集合，仅查一次补集最长回文不足以描述剩余两条的最优乘积，可改用集合划分 DP，代价更高。
n 增大还能用吗？不能简单放大位宽解决指数状态数，需要新的限制或算法；普通最长回文子序列 DP 也无法直接解决两个互斥序列的乘积目标。

JavaScript


/**
 * @param {string} s
 * @return {number}
 */
var maxProduct = function(s) {
    const n = s.length, size = 1 << n;
    const pal = new Array(size).fill(0);
    for (let mask = 1; mask < size; mask++) {
        let t = '';
        for (let i = 0; i < n; i++) {
            if (mask & (1 << i)) t += s[i];
        }
        let ok = true;
        for (let l = 0, r = t.length - 1; l < r; l++, r--) {
            if (t[l] !== t[r]) { ok = false; break; }
        }
        if (ok) pal[mask] = t.length;
    }
    const best = pal.slice();
    for (let i = 0; i < n; i++) {
        for (let mask = 0; mask < size; mask++) {
            if (mask & (1 << i)) {
                best[mask] = Math.max(best[mask], best[mask ^ (1 << i)]);
            }
        }
    }
    let answer = 0;
    for (let a = 1; a < size; a++) {
        answer = Math.max(answer, pal[a] * best[(size - 1) ^ a]);
    }
    return answer;
};

class Solution {
    public int maxProduct(String s) {
        int n = s.length(), size = 1 << n;
        int[] pal = new int[size];
        for (int mask = 1; mask < size; mask++) {
            StringBuilder t = new StringBuilder();
            for (int i = 0; i < n; i++) {
                if ((mask & (1 << i)) != 0) t.append(s.charAt(i));
            }
            boolean ok = true;
            for (int l = 0, r = t.length() - 1; l < r; l++, r--) {
                if (t.charAt(l) != t.charAt(r)) { ok = false; break; }
            }
            if (ok) pal[mask] = t.length();
        }
        int[] best = pal.clone();
        for (int i = 0; i < n; i++) {
            for (int mask = 0; mask < size; mask++) {
                if ((mask & (1 << i)) != 0) {
                    best[mask] = Math.max(best[mask], best[mask ^ (1 << i)]);
                }
            }
        }
        int answer = 0;
        for (int a = 1; a < size; a++) {
            answer = Math.max(answer, pal[a] * best[(size - 1) ^ a]);
        }
        return answer;
    }
}

class Solution:
    def maxProduct(self, s: str) -> int:
        n = len(s)
        size = 1 << n
        pal = [0] * size
        for mask in range(1, size):
            t = ''.join(s[i] for i in range(n) if mask & (1 << i))
            if t == t[::-1]:
                pal[mask] = len(t)
        best = pal[:]
        for i in range(n):
            for mask in range(size):
                if mask & (1 << i):
                    best[mask] = max(best[mask], best[mask ^ (1 << i)])
        answer = 0
        for a in range(1, size):
            answer = max(answer, pal[a] * best[(size - 1) ^ a])
        return answer
