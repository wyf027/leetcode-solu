给定字符串 s，它是一个整数嵌套列表的合法序列化结果。请实现解析器，将它反序列化并返回对应的 NestedInteger。

每个元素只能是一个整数，或一个列表；列表中的元素仍可递归地是整数或列表。

  • 所有整数值均在 [-106, 106] 范围内。

Full Solution

迭代栈：完成一层，再交给上一层

字符串天然按从左到右的顺序给出元素；真正需要记住的，只有尚未遇到右括号的那些列表。

核心洞察

把每个尚未闭合的列表放进栈。遇到左括号就新建一个空列表并入栈；遇到整数就把它加入栈顶列表；遇到右括号就弹出已经完成的列表，并把它加入新的栈顶（它的父列表）。

栈不变量

处理完任意前缀后，栈从底到顶依次保存所有已打开但尚未闭合的列表；每个栈帧已经包含该层中完整读完的所有元素。

完整过程

1 · 特判若首字符不是左括号，整个输入就是单个整数，直接构造结果。
2 · 开层读到 [，构造空 NestedInteger 列表并压栈。
3 · 收数字连续读取可选负号与数字；在逗号或右括号前加入栈顶。
4 · 闭层读到 ]，弹出完成层；若仍有父层，就把完成层加入父层。

使用 inNumber 区分“当前确实读到了数字 0”和“当前没有待提交的数字”。负号只修改符号，数字字符负责累积绝对值。对逗号与右括号采用同一套“先提交数字”逻辑，可以避免遗漏列表末尾的整数。

正确性证明

初始化：扫描开始前栈为空，没有打开的列表，也没有遗漏的完整元素，因此栈不变量成立。

保持：左括号创建一个新的未闭合列表，压栈后开放层级顺序正确；整数结束时被加入栈顶，恰好属于当前最内层列表；右括号先提交可能存在的末尾整数，再弹出当前层。弹出的层已经包含其全部元素，加入父层后父层仍包含所有完整读完的元素。因此每类记号都保持不变量。

终止：输入合法。最后一个右括号处理后，最外层列表被弹出，栈为空；按照不变量，它包含输入描述的全部元素及准确嵌套关系。单整数输入由特判直接正确构造，所以算法对所有合法输入都正确。

边界情况

  • 单个整数："324" 或 "-7" 没有任何括号，不能假设栈一定存在。
  • 空列表："[]" 中没有待提交数字，右括号直接完成空列表。
  • 数字 0：不能用 num != 0 判断是否读到数字，应使用布尔标记。
  • 负数：负号不属于数值位，累积绝对值后再乘符号。
  • 极深嵌套：迭代栈避开递归调用栈溢出的额外风险；显式栈仍需要与嵌套深度同阶的空间。
  • 相邻闭括号：每个右括号都完成一层，并立即把该层挂到父层。

复杂度

时间 · O(n)

每个字符只被扫描一次；每个构造出的元素只加入所属列表一次。

辅助空间 · O(d)

d 为最大嵌套深度，表示显式栈大小；返回对象自身占用的空间不计入辅助空间。

JavaOfficial signature
class Solution {
    public NestedInteger deserialize(String s) {
        if (s.charAt(0) != '[') {
            return new NestedInteger(Integer.parseInt(s));
        }

        Deque<NestedInteger> stack = new ArrayDeque<>();
        NestedInteger result = null;
        int number = 0;
        int sign = 1;
        boolean inNumber = false;

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == '[') {
                stack.push(new NestedInteger());
            } else if (ch == '-') {
                sign = -1;
            } else if (Character.isDigit(ch)) {
                number = number * 10 + (ch - '0');
                inNumber = true;
            } else if (ch == ',' || ch == ']') {
                if (inNumber) {
                    stack.peek().add(new NestedInteger(sign * number));
                    number = 0;
                    sign = 1;
                    inNumber = false;
                }
                if (ch == ']') {
                    NestedInteger completed = stack.pop();
                    if (stack.isEmpty()) {
                        result = completed;
                    } else {
                        stack.peek().add(completed);
                    }
                }
            }
        }
        return result;
    }
}

/** @param {string} s @return {NestedInteger} */
var deserialize = function(s) {
    if (s[0] !== '[') {
        const integer = new NestedInteger();
        integer.setInteger(Number(s));
        return integer;
    }

    const stack = [];
    let result = null;
    let number = 0;
    let sign = 1;
    let inNumber = false;

    for (const ch of s) {
        if (ch === '[') {
            stack.push(new NestedInteger());
        } else if (ch === '-') {
            sign = -1;
        } else if (ch >= '0' && ch <= '9') {
            number = number * 10 + Number(ch);
            inNumber = true;
        } else if (ch === ',' || ch === ']') {
            if (inNumber) {
                const integer = new NestedInteger();
                integer.setInteger(sign * number);
                stack[stack.length - 1].add(integer);
                number = 0;
                sign = 1;
                inNumber = false;
            }
            if (ch === ']') {
                const completed = stack.pop();
                if (stack.length === 0) result = completed;
                else stack[stack.length - 1].add(completed);
            }
        }
    }
    return result;
};

class Solution {
public:
    NestedInteger deserialize(string s) {
        if (s[0] != '[') {
            return NestedInteger(stoi(s));
        }

        vector<NestedInteger> stack;
        NestedInteger result;
        int number = 0;
        int sign = 1;
        bool inNumber = false;

        for (char ch : s) {
            if (ch == '[') {
                stack.emplace_back();
            } else if (ch == '-') {
                sign = -1;
            } else if (isdigit(ch)) {
                number = number * 10 + (ch - '0');
                inNumber = true;
            } else if (ch == ',' || ch == ']') {
                if (inNumber) {
                    stack.back().add(NestedInteger(sign * number));
                    number = 0;
                    sign = 1;
                    inNumber = false;
                }
                if (ch == ']') {
                    NestedInteger completed = stack.back();
                    stack.pop_back();
                    if (stack.empty()) result = completed;
                    else stack.back().add(completed);
                }
            }
        }
        return result;
    }
};

替代方案

递归下降解析

用共享下标解析“整数或列表”，代码贴近文法、表达清楚；但极深输入会占用递归调用栈，且需要谨慎推进下标。

语言内置 JSON 解析

部分语言能先解析成普通数组，再转换成 NestedInteger，但面试中通常失去对解析机制的考察，也增加一次中间结构转换。

面试追问

  1. 如果输入不再保证合法，如何报告“多余逗号、括号不匹配、非法字符、数字越界”的准确位置？
  2. 如果输入来自流而不是完整字符串，怎样让解析器跨数据块保留数字与栈状态？
  3. 递归版本的最大风险是什么？如何在保留递归文法可读性的同时避免调用栈过深？
  4. 若 NestedInteger 的 add 会复制对象而不是保留引用，构造与挂接的时机需要怎样调整？

常见错误

  • 只在逗号处提交数字，导致右括号前的最后一个整数丢失。
  • 用数值是否为 0 判断是否存在待提交数字，从而漏掉合法的 0。
  • 忘记单整数输入没有栈帧，直接访问栈顶。
  • 在 C++ 中把尚未完成的空子列表先复制进父列表，后续对子列表的修改不会反映到父列表副本。
  • 完成子列表后没有挂到父层，最终只得到最外层空壳或最后一层。
  • 错误地把算法空间写成 O(n) 而不说明返回结构；辅助栈应按最大嵌套深度 O(d) 描述。
