一次达标，就算一位

给定账单表 Store，统计至少有一张账单金额严格大于 500的客户有多少位。返回一行一列，列名为 rich_count。这里判断的是单张账单金额，不是客户累计消费额。

04 / 独立题解

想清楚统计的是“人”还是“账单”了吗？

展开后查看 SQL、证明与四语言语义参考。

先筛账单，再数不同客户

核心洞察

“至少一张”是存在性条件：只要出现一次合格记录，对应客户就应被计入；第二次出现不能增加人数。筛选 amount > 500 后，对 customer_id 去重计数恰好表达这件事。

完整过程

  1. 读取 Store 的账单，保留金额严格大于 500 的行。
  2. 官方示例留下账单 6、8、11，其客户编号依次为 1、1、3。
  3. 不同客户编号为 {1, 3}，数量为 2。
  4. 以别名 rich_count 返回单个聚合值，即使没有合格行也返回一行 0。

SQL · 主要提交答案

使用官方元数据明确列出的 MySQL 表结构。以下仅为查询，不包含建表和样例插入语句。

SELECT COUNT(DISTINCT customer_id) AS rich_count
FROM Store
WHERE amount > 500;

正确性说明

若某客户被计入，则筛选结果中至少有一行带有该客户编号，该行金额大于 500，因此该客户符合条件。反之，任何符合条件的客户都至少有一张金额大于 500 的账单，这一行会被保留，因此其编号会被聚合计入。DISTINCT 保证每个编号最多计一次，所以结果既不漏计，也不重复计数。

对应动画的不变式：处理前 k 行后，名册恰好包含这些行里拥有达标账单的不同客户。空前缀成立；新的一行不达标时名册不变，达标时加入其客户编号，均保持不变式。处理完所有行即得到答案。

边界与数据语义

  • 500 不满足严格大于；501 满足。
  • 客户总额再高，若没有单张达标账单也不计入。
  • 重复出现的客户只计一次；bill_id 唯一不代表 customer_id 唯一。
  • 空表和全不达标均得到 rich_count = 0。
  • 扩展 SQL 空值语义：NULL 金额不会通过 WHERE，COUNT(DISTINCT customer_id) 忽略 NULL 编号。下方本地参考使用普通整数记录；可编辑演示器不接收 NULL。

复杂度

令 n 为账单行数，u 为合格客户数。集合实现期望时间 O(n)、额外空间 O(u)。SQL 需要扫描与去重；哈希聚合通常对应期望 O(n) 时间、O(u) 内存，排序去重可能需要 O(n log n) 时间。实际执行取决于数据库计划、索引与数据分布，不承诺固定执行计划。

替代方案

可先按 customer_id 分组，使用 HAVING MAX(amount) > 500，再对分组结果 COUNT(*)。也可以对筛选后的客户使用 SELECT DISTINCT 子查询再计数。对正常非空客户编号，两者语义一致；若允许 NULL 编号，子查询方案需显式排除它才能与 COUNT(DISTINCT) 一致。直接 COUNT(DISTINCT) 更短。

四语言完整代码 · 仅本地语义参考

本题是数据库题，以下 Java / JavaScript / Python / C++ 不是该题官方提交接口。统一输入 Store 二维数组，每行是 [bill_id, customer_id, amount]，返回整数 rich_count；各示例均包含可运行入口，页面未执行这些代码。

Java

import java.util.HashSet;
import java.util.Set;

public class Main {
    public static int countRichCustomers(int[][] store) {
        Set<Integer> customers = new HashSet<>();
        for (int[] row : store) {
            if (row[2] > 500) customers.add(row[1]);
        }
        return customers.size();
    }

    public static void main(String[] args) {
        int[][] store = {
            {6, 1, 549}, {8, 1, 834}, {4, 2, 394},
            {11, 3, 657}, {13, 3, 257}
        };
        System.out.println(countRichCustomers(store));
    }
}

Python

def count_rich_customers(store):
    return len({
        customer_id
        for _, customer_id, amount in store
        if amount > 500
    })


if __name__ == "__main__":

#include <array>

std::size_t countRichCustomers(

常见错误

  • 用 COUNT(*)：数到的是合格账单数量，示例会误得 3。
  • 把 > 写成 >=：金额恰好 500 被误计。
  • 按客户 SUM(amount) > 500：把单笔条件改成累计条件。
  • 对 bill_id 去重：订单唯一，仍会重复统计客户。
  • 遗漏 rich_count 别名，或返回客户列表而不是人数。

面试追问

至少两张达标账单？先 WHERE 过滤，再按客户分组 HAVING COUNT(*) >= 2，最后计组数。统计累计金额大于 500？按客户聚合 SUM(amount)，再筛分组。数据量很大？结合真实执行计划评估 (amount, customer_id) 覆盖索引；范围选择性不高时，索引未必比全表扫描更好。
