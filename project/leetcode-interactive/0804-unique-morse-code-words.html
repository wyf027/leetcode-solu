唯一摩尔斯密码词

Unique Morse Code Words — 把每个单词沿字母顺序转换为点与短线组成的信号，判断最终出现了多少种不同的信号串。

输入：String[] words 输出：int 非付费题

01 / Problem

题目理解

先读题，再发报

国际摩尔斯密码为每个小写英文字母规定了一段由点 . 和短线 - 组成的编码。给定字符串数组 words，依次把一个单词中的每个字母替换为对应编码，再按原顺序连接，得到这个单词的“转换结果”。

请返回数组中一共出现了多少种不同的转换结果。不同单词可能产生完全相同的信号串，此时它们只算一种。

例如 "cab" 会转换为 "-.-." + ".-" + "-..." = "-.-..--..."。

官方示例 1
输入：words = ["gin", "zen", "gig", "msg"] 输出：2

转换结果依次为 --...-.、--...-.、--...--.、--...--.，所以不同结果有 2 种。

官方示例 2
输入：words = ["a"] 输出：1

唯一单词 a 的转换结果是 .-，因此只有 1 种。

约束

  • 1 <= words.length <= 100
  • 1 <= words[i].length <= 12
  • words[i] 仅由小写英文字母组成。

Solution unlocked

哈希集合：让每种信号只出现一次

O(S) 时间

核心洞察

题目比较的不是原单词，而是它们的完整摩尔斯转换串。逐字映射并拼接后，把结果放进集合；集合会自动去重，最后的集合大小就是答案。

完整过程

1
准备映射

按 a...z 顺序保存 26 个编码。字符 c 的下标可由 c - 'a' 得到。

2
转换单词

遍历单词的每个字符，查表取得编码，并按字符原顺序追加到临时字符串。

3
加入集合

每完成一个单词，把它的完整转换串插入哈希集合；重复值不会增加集合大小。

4
返回计数

全部单词处理完后，返回集合中元素的数量。

正确性证明

对任意单词，算法按原字符顺序查出且仅查出每个字母的官方编码，再依次拼接，因此生成的字符串恰好是该单词定义中的转换结果。集合包含每个单词的转换结果，并且相等结果只保留一次、不等结果分别保留。因此集合元素与所有不同转换结果一一对应，集合大小即题目所求。

复杂度

设所有单词的字符总数为 S。每个字符只转换一次，时间复杂度为 O(S)；集合保存转换串，额外空间复杂度为 O(S)。题目下单个编码最长 4，常数受控。

边界情况

  • 只有一个单词：答案一定是 1。
  • 多个相同单词：转换串相同，只计一次。
  • 不同单词可能碰巧生成同一转换串。
  • 最短与最长单词均按同一映射流程处理。

替代方案

也可以先收集全部转换串，排序后统计相邻不同项；时间约为 O(S + n log n · L)，实现更绕。哈希集合直接表达“去重计数”，更贴合题意。

面试追问

  • 若字符集不再连续，如何组织映射？使用字典。
  • 若输入是数据流，能否在线处理？可以，持续向集合插入。
  • 若内存受限怎么办？可排序外部文件，或讨论概率型去重结构的误差。

常见错误

  • 统计不同单词，而不是不同转换串。
  • 忘记每处理新单词时清空临时拼接器。
  • 把单词内部字母排序，破坏原始顺序。
  • 手写编码表时顺序或符号抄错。

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int uniqueMorseRepresentations(String[] words) {
        String[] codes = {
            ".-", "-...", "-.-.", "-..", ".", "..-.", "--.",
            "....", "..", ".---", "-.-", ".-..", "--", "-.",
            "---", ".--.", "--.-", ".-.", "...", "-", "..-",
            "...-", ".--", "-..-", "-.--", "--.."
        };

        Set<String> unique = new HashSet<>();
        for (String word : words) {
            StringBuilder transformed = new StringBuilder();
            for (char letter : word.toCharArray()) {
                transformed.append(codes[letter - 'a']);
            }
            unique.add(transformed.toString());
        }
        return unique.size();
    }
}

    }
