二叉树的前序遍历 栈调度台

弹栈即访问当前节点，再依次压入右、左孩子；后进先出的调度让左子树先执行，稳定得到“根 → 左 → 右”。

任务边界

输入是二叉树根节点 root，返回节点值的前序序列。 节点数 0～100，节点值 −100～100；空树返回空数组。

Problem / 题意

按“根、左、右”访问所有节点

给定二叉树根节点，返回它的前序遍历结果。主线使用显式栈模拟递归： 每次弹出并记录节点，先压右孩子、再压左孩子，从而让左孩子先出栈。

root = [1,null,2,3]

输出：[1,2,3]

官方示例 2
root = []

输出：[1]

核心洞察

栈是待办队列：右先入栈，左先执行

前序遍历要求根、左、右。弹出节点时立刻记录它，再先压右孩子、 后压左孩子。由于栈后进先出，左孩子会先被处理，顺序自然满足要求。

完整过程

  1. 空树直接返回空列表。
  2. 将根节点压入栈。
  3. 循环弹栈、记录节点值。
  4. 先压右孩子，再压左孩子，直到栈空。

边界与复杂度

  • 空树返回 []；单节点返回自身值。
  • 极度倾斜树的栈空间为 O(n)。
  • 时间 O(n)，空间 O(h)，h 为树高。

替代方案取舍

递归写法更短，但会隐式占用调用栈；Morris 遍历可做到 O(1) 额外空间，却会临时修改树且更难解释。面试主线推荐显式栈。

常见错误

  • 先压左再压右，结果变成根、右、左。
  • 入栈时就记录，容易与访问时机混淆。
  • 空 root 仍直接入栈，引发空指针。
  • 误用队列，得到层序遍历。

面试追问

为什么右先入栈？LIFO 保证后入的左孩子先执行。
递归复杂度如何算？时间 O(n)，隐式栈最坏 O(n)。
如何改成中序？延迟访问，持续沿左链压栈。 
public class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            result.add(node.val);
            if (node.right != null) stack.push(node.right);
            if (node.left != null) stack.push(node.left);
        }
        return result;
    }
}

    vector<int> preorderTraversal(TreeNode* root) {
        if (root == nullptr) return {};
        vector<int> result;
        stack<TreeNode*> nodes;
        nodes.push(root);
        while (!nodes.empty()) {
            TreeNode* node = nodes.top();
            nodes.pop();
            result.push_back(node->val);
            if (node->right != nullptr) nodes.push(node->right);
            if (node->left != nullptr) nodes.push(node->left);
        }
