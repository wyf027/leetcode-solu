LCR 008 / SLIDING WINDOW

长度最小的子数组

数组元素全为正数：右指针扩张使总和达到目标，左指针随即收缩，直到窗口再次不合法。每个元素只进窗、出窗一次。

时间 O(n)空间 O(1)官方 slug：2vg8kg

CORE IDEA

达标后，尽力缩左边

  1. 1.不断右移 right，把 nums[right] 加入 sum。
  2. 2.当 sum ≥ target，更新最短答案。
  3. 3.移走 nums[left] 并 left++，继续寻找更短窗口。

关键前提

元素都是正数，所以右移 right 时 sum 只增不减；左移 left 时 sum 只减不增。这让窗口不用回退，才能线性扫描。

若存在负数：窗口和不再单调，不能直接使用这个模板。

为何先扩张？

未达 target 的窗口不可能是答案，必须由 right 加入新元素才能变合法。

为何马上收缩？

当前窗口既然已达标，删除最左正数会使长度更短，是唯一可能改进答案的方向。

边界处理

若整个数组都未达标，答案保持哨兵值，最后返回 0。

四语言模板

class Solution {
  public int minSubArrayLen(int target, int[] nums) {
    int left = 0, sum = 0, ans = Integer.MAX_VALUE;
    for (int right = 0; right < nums.length; right++) {
      sum += nums[right];
      while (sum >= target) {
        ans = Math.min(ans, right - left + 1);
        sum -= nums[left++];
      }
    }
    return ans == Integer.MAX_VALUE ? 0 : ans;
  }
}
