所有子数组最小值中的最大值

Maximum of Minimum Values in All Subarrays

1950

每一种窗口长度，都有自己的“最强下限”。

先理解每个答案代表什么，再展开下方题解探索计算过程。

01 题目与输入输出

给定长度为 n 的整数数组 nums。对每个长度 k = 1, 2, …, n，列出所有长度恰好为 k 的连续子数组，分别取最小值，再从这些最小值中选出最大值。

返回长度为 n 的数组 ans，其中 ans[k - 1] 对应长度 k 的结果。子数组必须连续，不能跳过中间元素。

想清楚两层选择：
窗口内部取最小；同长度窗口之间取最大。

Function contract

findMaximums(nums: integer[]) → integer[]

约束

  • n == nums.length
  • 1 ≤ n ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁹
  • 答案按长度从 1 到 n 排列，下标从 0 开始。

04 题解 · 从元素反看窗口

Core insight

固定一个位置 i。只要窗口没有跨过严格小于 nums[i] 的元素，并且包含 i，它的最小值就是 nums[i]。因此，先求每个元素能够担当最小值的最大连续范围。

令 L[i] 和 R[i] 分别是左右最近的严格更小元素下标，不存在时取 -1 和 n。有效闭区间为 [L[i]+1, R[i]-1]，长度 m = R[i]-L[i]-1。

ans[m-1] = max(ans[m-1], nums[i])
先将元素贡献放到它能覆盖的最大长度，再从大长度向小长度传递答案。

两次扫描都在栈顶值 ≥ 当前值 时弹栈，留下的栈顶才是严格更小的元素。相等元素可以共享范围：本题只取最大值，不统计次数，不需要给相等元素分配唯一归属。

完整过程

  1. 从左到右，维护值严格递增的下标栈。弹出所有不小于当前值的栈顶，记录 L[i]，再入栈。
  2. 清空栈，从右到左执行相同操作，得到 R[i]。
  3. 遍历每个元素，将它写入最大覆盖长度的候选桶，冲突时取最大值。由于元素非负，候选数组可以初始化为 0。
  4. 从 n-2 递减至 0：ans[j] = max(ans[j], ans[j+1])。这样所有未直接命中的长度也得到完整答案。

为什么反向补齐成立？

记长度 k 的答案为 F(k)。任取长度 k+1 的最优窗口，删掉一个端点后得到长度 k 的窗口，它的最小值不会下降。因此 F(k) ≥ F(k+1)，大窗口的候选值可以作为所有较短窗口答案的下界。

正确性证明

  1. 边界正确。 扫描时，被当前元素弹出的下标不可能再成为后续位置的最近更小元素：当前元素更近，且值不大于它。弹栈后剩余的栈顶就是当前方向最近的严格更小元素。
  2. 贡献可行。 开区间 (L[i],R[i]) 内没有比 nums[i] 小的值，因此整个范围的最小值正是它。对于任意 1 ≤ k ≤ m，都能在这个范围内选择一个包含 i 的长度 k 窗口，最小值也为它。
  3. 不会漏掉最优值。 取任意长度 k 的最优窗口，并选其中一个最小元素 i。其严格更小边界必在窗口外，所以它的最大覆盖长度 m 至少为 k。该值进入 m 桶后，经从右向左传播必能抵达 k 桶。
  4. 合并结论。 进入和传播到 k 桶的值都来自可行长度 k 窗口，且至少包含最优窗口的最小值，所以最后的 ans[k-1] 恰好是所求最大值。

手推示例二

nums=[10,20,50,10] 得到 L=[-1,0,1,-1]、R=[4,3,3,4]，最大长度为 [4,2,1,4]。初始桶为 [50,20,0,10]，从右往左补齐为 [50,20,10,10]。长度 3 没有直接贡献，但可以继承长度 4 的 10。

边界与复杂度

  • 单元素：两端哨兵为 -1 和 1，覆盖长度 1，答案就是自身。
  • 全相等：两次扫描都会弹掉相等栈顶，每个位置的覆盖长度都是 n，反向传播得到全部相同的答案。
  • 递增、递减：某一方向的栈可能达到 n，不能误把栈空间视为常数。
  • 零值合法，初始化 0 不影响本题。若题目扩展到负数，需要用负无穷或最小整数初始化候选桶。
  • 时间 O(n)：每次扫描每个下标最多入栈、出栈各一次，加上两次线性处理。辅助空间 O(n)：左右边界与栈；返回数组也为 O(n)。数值只参与比较，10⁹ 在四种语言所用数值类型中都可精确表示。

替代方案

  • 枚举左端点、向右维护最小值：每加入一个元素更新当前最小值和对应长度答案，O(n²) 时间、O(n) 空间。易懂，但 n=10⁵ 时不适合。
  • 每种长度使用单调队列：一个固定 k 的滑动窗口最小值可 O(n) 求出；遍历所有 k 仍然是 O(n²)。
  • 按值降序激活 + 并查集：相邻激活点连成块，当前值提供连通块长度的候选，再传播答案。排序通常 O(n log n)，实现更长。

常见错误

  • 写成“所有窗口最大值的最小值”，或把连续子数组当成子序列。
  • 把长度 m 写到 ans[m]；正确下标是 m-1。
  • 两侧都保留相等元素，导致全相等数组每个范围被缩成长度 1。本实现两次扫描都使用 ≥ 弹栈。
  • 第二次扫描前没有清空栈，或者不存在右边界时错用 n-1。
  • 漏掉补齐、从左往右补齐，或用相加代替取最大值。

面试追问

  • 只问一个 k 呢？ 使用单调队列计算固定窗口最小值，再取最大，O(n) 时间、O(k) 空间。
  • 还能返回一个最优窗口吗？ 桶中同时保留贡献元素及其边界。传递来源后，在其覆盖范围内选取包含该元素的长度 k 子区间。
  • 和柱状图最大矩形有什么关系？ 都利用严格更小元素划定一个值的有效跨度；矩形题取“高度 × 宽度”，这里按宽度聚合最小值候选。
  • 可以减少边界数组吗？ 可以单次扫描，在弹栈时计算左右边界并直接更新桶，末尾用虚拟边界清栈；相等值的归属规则必须与证明一致。

Java

class Solution {
    public int[] findMaximums(int[] nums) {
        int n = nums.length;
        int[] left = new int[n], right = new int[n];
        int[] stack = new int[n], ans = new int[n];
        int top = 0;
        for (int i = 0; i < n; i++) {
            while (top > 0 && nums[stack[top - 1]] >= nums[i]) top--;
            left[i] = top == 0 ? -1 : stack[top - 1];
            stack[top++] = i;
        }
        top = 0;
        for (int i = n - 1; i >= 0; i--) {
            while (top > 0 && nums[stack[top - 1]] >= nums[i]) top--;
            right[i] = top == 0 ? n : stack[top - 1];
            stack[top++] = i;
        }
        for (int i = 0; i < n; i++) {
            int len = right[i] - left[i] - 1;
            ans[len - 1] = Math.max(ans[len - 1], nums[i]);
        }
        for (int j = n - 2; j >= 0; j--)
            ans[j] = Math.max(ans[j], ans[j + 1]);
        return ans;
    }
}

/**

var findMaximums = function(nums) {
    const n = nums.length;
    const left = Array(n), right = Array(n);
    const stack = [], ans = Array(n).fill(0);
    for (let i = 0; i < n; i++) {
        while (stack.length && nums[stack[stack.length - 1]] >= nums[i])
            stack.pop();
        left[i] = stack.length ? stack[stack.length - 1] : -1;
        stack.push(i);
    }
    stack.length = 0;
    for (let i = n - 1; i >= 0; i--) {
        while (stack.length && nums[stack[stack.length - 1]] >= nums[i])
            stack.pop();
        right[i] = stack.length ? stack[stack.length - 1] : n;
        stack.push(i);
    }
    for (let i = 0; i < n; i++) {
        const len = right[i] - left[i] - 1;
        ans[len - 1] = Math.max(ans[len - 1], nums[i]);
    }
    for (let j = n - 2; j >= 0; j--)
        ans[j] = Math.max(ans[j], ans[j + 1]);
    return ans;

Python

from typing import List

class Solution:
    def findMaximums(self, nums: List[int]) -> List[int]:
        n = len(nums)
        left, right = [-1] * n, [n] * n
        stack = []
        for i in range(n):
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            if stack:
                left[i] = stack[-1]
            stack.append(i)
        stack.clear()
        for i in range(n - 1, -1, -1):
            while stack and nums[stack[-1]] >= nums[i]:
                stack.pop()
            if stack:
                right[i] = stack[-1]
            stack.append(i)
        ans = [0] * n
        for i in range(n):
            length = right[i] - left[i] - 1
            ans[length - 1] = max(ans[length - 1], nums[i])
        for j in range(n - 2, -1, -1):
            ans[j] = max(ans[j], ans[j + 1])
        return ans

C++

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> findMaximums(vector<int>& nums) {
        int n = static_cast<int>(nums.size());
        vector<int> left(n, -1), right(n, n), stack, ans(n, 0);
        for (int i = 0; i < n; ++i) {
            while (!stack.empty() && nums[stack.back()] >= nums[i])
                stack.pop_back();
            if (!stack.empty()) left[i] = stack.back();
            stack.push_back(i);
        }
        stack.clear();
        for (int i = n - 1; i >= 0; --i) {
            while (!stack.empty() && nums[stack.back()] >= nums[i])
                stack.pop_back();
            if (!stack.empty()) right[i] = stack.back();
            stack.push_back(i);
        }
        for (int i = 0; i < n; ++i) {
            int len = right[i] - left[i] - 1;
            ans[len - 1] = max(ans[len - 1], nums[i]);
        }
        for (int j = n - 2; j >= 0; --j)
            ans[j] = max(ans[j], ans[j + 1]);
        return ans;
    }
};
