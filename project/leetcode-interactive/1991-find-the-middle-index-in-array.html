找到数组的中间位置

Find the Middle Index in Array

寻找一个分界点，让左右两侧的数字之和相等。

先读题、自己推演，再按需打开底部题解。

01 / 题目

给定从 0 开始编号的整数数组 nums。请找出一个下标，使它左侧所有元素的和与右侧所有元素的和相等；当前下标对应的元素不计入任何一侧。如果有多个答案，返回最小的下标；如果没有，返回 -1。某一侧没有元素时，该侧的和为 0。

“中间位置”是左右和相等的位置，不一定在数组几何中心。返回的是下标，不是元素值。

参数与约束

  • 输入：整数数组 nums；输出：整数下标。
  • 1 ≤ nums.length ≤ 100
  • -1000 ≤ nums[i] ≤ 1000

示例 1

输入：nums = [2,3,-1,8,4]
输出：3

下标 3 左侧：2 + 3 − 1 = 4；右侧：4。

示例 2

输入：nums = [1,-1,4]
输出：2

下标 2 左侧：1 − 1 = 0；右侧为空，和为 0。

示例 3

输入：nums = [2,5]
输出：-1

两个下标都无法让左右两侧的和相等。

示例 4

输入：nums = [1]
输出：0

唯一元素的左右两侧都为空，和均为 0。

04 / 题解

准备好后再展开思路与四语言代码。

核心洞察 · 总和只需要求一次

设总和为 total，当前下标为 i，左侧和为 left。因为当前元素不能计入两侧，所以右侧和为 total - left - nums[i]。检查两侧相等后，再把当前元素加入左侧，交给下一个候选位置。

  1. 遍历数组求出 total，初始化 left = 0。
  2. 从下标 0 向右枚举，计算 right = total - left - nums[i]。
  3. 若 left == right，立即返回 i。
  4. 否则执行 left += nums[i]，继续枚举。
  5. 所有位置都不满足时，返回 -1。

完整过程 · nums = [2,3,-1,8,4]

total = 16，left 初始为 0
 i   当前值   left   right = total - left - 当前值
 0      2       0      14    不等，left 更新为 2
 1      3       2      11    不等，left 更新为 5
 2     -1       5      12    不等，left 更新为 4
 3      8       4       4    相等，返回 3

正确性

循环开始检查下标 i 时，保持不变式：left 恰为所有下标小于 i 的元素和。初始 i = 0，左侧为空，left = 0 成立。总和减去左侧和与当前元素，恰好得到右侧和，因此相等判断与题目定义等价。失败后加入当前元素，不变式对下一个位置仍成立。按下标递增枚举并在第一次相等时返回，保证答案最左；如果扫描结束，每个位置均被排除，故返回 -1 正确。

边界与复杂度

单元素时两侧都是 0，返回 0。端点也参与枚举，空侧自然得到 0。全零数组返回 0。负数不影响等式，但会破坏基于大小的单调性。两次线性遍历，时间 O(n)；仅保存总和、左和、下标，额外空间 O(1)。约束内总和绝对值不超过 100000，四种语言的所用数值类型均足够。

替代方案

每个下标分别遍历左右两侧求和：时间 O(n²)，额外空间 O(1)，思路直接但重复计算多。构建长度 n + 1 的前缀和数组：左右和为 prefix[i] 和 prefix[n] - prefix[i + 1]，时间 O(n)、空间 O(n)，适合后续还需要大量区间和查询的情形。

常见错误

  • 在比较前更新 left，把当前元素错误地算进左侧。
  • 计算 right 时忘记减 nums[i]，把候选元素算进右侧。
  • 跳过首尾下标，遗漏空侧为 0 的有效答案。
  • 遍历全部后保留最后一个解，违反“最左边”。
  • 按两侧和大小移动双指针；负数使这种判断缺少单调依据。

面试追问

返回所有中间位置？ 相等时收集下标而不提前返回，仍要更新 left；空间增加为 O(k)。只读流式输入能直接用这个方法吗？ 需要预先知道总和并再次遍历，通常需缓存或允许重读。数值范围扩大怎么办？ Java/C++ 改用 long/long long；JavaScript 超出安全整数范围时，输入与运算统一使用 BigInt。

Java

class Solution {
    public int findMiddleIndex(int[] nums) {
        int total = 0, left = 0;
        for (int value : nums) total += value;
        for (int i = 0; i < nums.length; i++) {
            if (left == total - left - nums[i]) return i;
            left += nums[i];
        }
        return -1;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number}
 */
var findMiddleIndex = function(nums) {
    const total = nums.reduce((sum, value) => sum + value, 0);
    let left = 0;
    for (let i = 0; i < nums.length; i++) {
        if (left === total - left - nums[i]) return i;
        left += nums[i];
    }
    return -1;
};

Python 3

from typing import List

class Solution:
    def findMiddleIndex(self, nums: List[int]) -> int:
        total = sum(nums)
        left = 0
        for i, value in enumerate(nums):
            if left == total - left - value:
                return i
            left += value
        return -1

#include <vector>
#include <numeric>
using namespace std;

class Solution {
public:
    int findMiddleIndex(vector<int>& nums) {
        int total = accumulate(nums.begin(), nums.end(), 0);
        int left = 0;
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            if (left == total - left - nums[i]) return i;
            left += nums[i];
        }
        return -1;
    }
};
