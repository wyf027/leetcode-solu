最长的字母序连续
子字符串的长度

Length of the Longest Alphabetical Continuous Substring

先理解什么是“连续”，再尝试自己找出最长的一段。

01 / 题目

给定只包含小写英文字母的字符串 s，求其中最长的字母序连续子字符串的长度。这里的字符既要在原字符串中相邻，也要按字母表顺序逐个递增，不允许跳过字母。

例如 abc、xyz 符合要求，acb 和 za 不符合。字母表在 z 处结束，不会循环接回 a。

官方示例 1

输入：s = "abacaba"
输出：2

不同的合法子字符串有 a、b、c、ab，其中 ab 最长，长度为 2。

官方示例 2

输入：s = "abcde"
输出：5

整个 abcde 都按字母顺序连续，长度为 5。

参数与约束

  • 参数：s: string；返回：integer。
  • 1 ≤ s.length ≤ 100000。
  • s 仅由小写英文字母组成。

03 / 思考完成后，再打开题解

包含逐步演示、推导与四种语言实现。

核心洞察：只看相邻两字母

当前字符的编码减去前一个字符的编码恰好等于 1，当前连续段才能延长；否则，新段从当前字符重新开始。用 cur 记录当前段长度，用 best 保留已经发现的最大长度。

连续段是“以当前位置结尾”的合法最长后缀。旧段断开时，历史最大值仍然保留。

字母接力轨道

青色底：当前段；粗青框：正在处理的字符；橙色底边：历史最优段。每一步检查一次相邻字符能否接力。

完整过程

  1. 字符串非空，令 cur = best = 1。
  2. 从下标 1 扫描到末尾。如果 s[i] - s[i-1] == 1，令 cur += 1；否则令 cur = 1。
  3. 每轮都执行 best = max(best, cur)。
  4. 扫描结束返回 best。

以 abacaba 为例，逐字符的 cur 为 1, 2, 1, 1, 1, 2, 1，best 为 1, 2, 2, 2, 2, 2, 2，因此结果为 2。

正确性

循环不变式：处理完下标 i 后，cur 等于以 i 结尾的最长合法子字符串长度，best 等于前缀 s[0..i] 中的最优长度。

起点：i = 0 时单字符合法，两个值均为 1。归纳：若当前相邻字符差为 1，前一位置的合法最长后缀可以且只能延长一位；如果差不为 1，任何跨过这条相邻边界的子字符串都不合法，只能从当前字符开始，长度为 1。更新 best 后，它覆盖了原前缀最优解与所有在当前下标结束的候选。遍历全部下标后，best 就是全局最优长度。

边界与复杂度

  • 长度为 1 时循环不执行，返回 1；空串不在题目输入范围内。
  • 重复、下降、跳字母都断开；z → a 的编码差不是 1。
  • 末尾出现最优段时，每轮更新 best 已覆盖，无需额外收尾。
  • 合法段最多包含 26 个字母，返回值范围为 [1, min(n, 26)]。
  • 时间 O(n)，额外空间 O(1)。可视化保存历史帧和显示节点，额外使用 O(n) 空间，不属于提交算法。

替代方案

从每个起点向右延伸，遇到不连续立即停止。小写字母表使每段最多延伸 26 位，因此时间上界 O(26n)，额外空间 O(1)。也可以用 dp[i] 保存以 i 结尾的最长长度，递推相同但占 O(n) 空间；由于仅依赖上一项，用 cur 即可。

常见错误

  • 只要求字符变大：a → c 递增但不连续，必须恰好加 1。
  • 把子字符串当成子序列，跳过原串中的字符。
  • 断开时把 cur 清为 0；当前字母本身仍是长度为 1 的合法段。
  • 返回 cur 而非 best，或只在断开时更新 best，漏掉末尾最优段。
  • 对编码差取绝对值或取模，会错误接受倒序或 z → a。

面试追问

如何返回最优子字符串？当 cur 严格超过 best 时，同时记录起点 i − cur + 1；最后截取。严格大于保留最早的并列最优段。

能处理流式输入吗？可以。保存前一个字符、cur、best，每到一个字符更新一次，无需保留整个输入。

如果允许字母循环呢？相邻条件改为模 26 的后继关系；此时段长可能超过 26，原有长度上界不再成立。

Java

class Solution {
    public int longestContinuousSubstring(String s) {
        int cur = 1, best = 1;
        for (int i = 1; i < s.length(); i++) {
            cur = s.charAt(i) - s.charAt(i - 1) == 1 ? cur + 1 : 1;
            best = Math.max(best, cur);
        }
        return best;
    }
}

class Solution:
    def longestContinuousSubstring(self, s: str) -> int:
        cur = best = 1
        for i in range(1, len(s)):
            if ord(s[i]) - ord(s[i - 1]) == 1:
                cur += 1
            else:
                cur = 1
            best = max(best, cur)
        return best

class Solution {
