03 / What to observe

实验观察点

先扩大样本空间

一次 rand7() 只有 7 种结果；组合多次独立调用，可以构造更大的等概率空间。

只保留可整分区域

要均匀分给 10 个结果，被采用的等概率状态数必须是 10 的倍数。

尾部仍有信息

首轮未采用的状态依旧均匀。它们可以与新调用组合，再次尝试产生结果。

05 / Solution

拒绝采样 + 尾部回收

从 49 个等概率状态中先取 40 个；若落入尾部，则复用剩余均匀状态，继续扩展到 63 和 21 个状态。

“

核心洞察

不能把 1…7 直接取模映射到 1…10。正确做法是先构造一个等概率样本空间，再只从能被 10 整除的那部分映射；剩余尾部也保持均匀，可以回收后继续抽样。

完整过程

  1. 调用两次 rand7()，令 idx = (a−1)×7+b，得到 1…49 的均匀整数。
  2. 若 idx ≤ 40，返回 1+(idx−1)%10。
  3. 否则令 idx -= 40，尾部变成 1…9；再调用 rand7()，扩展为 1…63。
  4. 若 idx ≤ 60，按相同方式映射；否则将 61…63 回收成 1…3。
  5. 再调用 rand7() 扩展为 1…21；若 idx ≤ 20 则映射，唯一剩余状态 21 重新开始。

正确性说明

每次 rand7() 的 7 个结果等概率且调用彼此独立。因此，将一个均匀的 m 状态变量与新一次 rand7() 组合后，会得到 7m 个等概率状态。

每一轮采用的状态数分别为 40、60、20，均可分成 10 个等大的同余类；映射后每个 1…10 都对应相同数量的状态。条件拒绝后的尾部状态仍彼此等概率，因此回收不会引入偏差。唯一最终拒绝状态只会让流程独立重启，不改变返回值分布。

边界与复杂度

  • 时间：期望 O(1)，理论最坏调用次数无上界（但长时间连续拒绝的概率指数下降）。
  • 空间：O(1)。
  • 值域：所有返回路径都经过模 10 映射，结果严格位于 1…10。
  • 调用期望：尾部回收版本约为 2.193 次 rand7()；简单 49→40 重试版为 2×49/40=2.45 次。

期望调用次数

设尾部回收版本的期望调用数为 E。首轮必调 2 次；以 9/49 的概率需要第 3 次，以 3/343 的概率需要第 4 次，以 1/2401 的概率完全重启：

E = 2 + 9/49 + 3/343 + E/2401 ≈ 2.193

这个推导也解释了为什么回收尾部比直接丢弃 41…49 更省调用。

Implementations

四语言完整代码

Java · LeetCode 可提交SolBase 提供 rand7()
/**
 * The rand7() API is already defined in the parent class SolBase.
 * public int rand7();
 */
class Solution extends SolBase {
    public int rand10() {
        while (true) {
            int idx = (rand7() - 1) * 7 + rand7(); // 1..49
            if (idx <= 40) {
                return 1 + (idx - 1) % 10;
            }

            idx = (idx - 40 - 1) * 7 + rand7();  // 1..63
            if (idx <= 60) {
                return 1 + (idx - 1) % 10;
            }

            idx = (idx - 60 - 1) * 7 + rand7();  // 1..21
            if (idx <= 20) {
                return 1 + (idx - 1) % 10;
            }
        }
    }
}

替代方案与常见错误

  • 简单拒绝采样：仅使用 1…40，遇到 41…49 直接重来。正确、易写，但期望调用更多。
  • 位构造：可从 rand7() 构造随机位再组合，但通常更绕，且需严谨处理拒绝区。
  • 错误：直接取模。状态总数不是 10 的倍数时，余数类大小不同，会产生偏差。
  • 错误：使用 Math.random/random。违反题目只允许 rand7() 的约束。
  • 错误：把 n 写进签名。n 是评测器内部调用次数，不是 rand10() 参数。
  • 错误：把“看起来接近”当均匀。有限样本频率接近不能替代理论等概率证明。

面试追问

为什么拒绝后仍然均匀？

原空间每个原子状态等概率。在已知落入某个子集的条件下，子集中的各状态条件概率仍相同。

为什么最坏时间不是 O(1)？

理论上可能连续命中拒绝状态任意多次；虽然概率极低，但不存在有限的确定上界，所以只说期望 O(1)。

能否从 randM() 推广到 randN()？

可以。选择 k 使 M^k 足够大，构造 M^k 个等概率状态，取其中最大的 N 的倍数映射，拒绝或回收其余状态。

如何验证实现没有明显偏差？

在理论证明之外，可大量采样并检查值域、频数和卡方统计量；但统计测试只能发现偏差迹象，不能替代证明。
