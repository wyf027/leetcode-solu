Problem

题目说明

给你一个正整数 num。如果存在某个整数 x，使 x × x = num，则 num 是完全平方数，返回 true；否则返回 false。

限制：不能使用 sqrt 等任何内置开方函数。

⌁1 <= num <= 231 - 1

示例 1

输入：num = 16
输出：true
解释：4 × 4 = 16，且 4 是整数。

示例 2

输入：num = 14
输出：false
解释：不存在整数 x 使 x × x = 14。

Solution

二分查找整数答案

核心洞察

正整数上的平方函数严格递增。若候选值 mid 的平方小于 num，答案只可能在右侧；若更大，答案只可能在左侧。因此每轮都能排除一半候选。

为了避免 mid × mid 在固定宽度整数中溢出，比较时使用 mid <= num / mid 或提升乘法类型。本文主实现采用除法比较，并在相等时检查 num % mid == 0。

01 · Range

确定候选区间

由于 num ≥ 1，平方根若为整数，一定在 [1, num] 中。还可把右边界缩到 num / 2（除 1 外），但不是必要条件。

02 · Compare

选中点并比较

令 mid = left + (right - left) / 2。若 mid 整除 num 且商等于 mid，就找到了整数平方根。

03 · Shrink

丢弃不可能的一半

若 mid < num / mid，令 left = mid + 1；否则令 right = mid - 1。区间为空时返回 false。

完整过程

  1. 初始化：令 left = 1、right = num，覆盖所有可能的正整数平方根。
  2. 检查中点：计算安全中点 mid。若 num / mid == mid 且余数为 0，返回 true。
  3. 收缩区间：当 mid < num / mid 时，说明 mid² < num，向右搜索；反之向左搜索。
  4. 结束：若 left > right 仍未命中，就不存在整数平方根，返回 false。

正确性证明

循环不变式：每轮开始时，如果整数平方根存在，它必定位于闭区间 [left, right]。

初始化时区间覆盖所有正整数候选。不命中中点时，因为平方函数严格递增：中点平方偏小可安全排除 [left, mid]；偏大可安全排除 [mid, right]。故不变式保持。循环结束时区间为空；按不变式，整数平方根不可能存在，所以返回 false 正确。若中途命中，等式直接证明返回 true 正确。

边界与复杂度

  • num = 1：首轮命中 1 × 1。
  • num = 2：区间最终为空，返回 false。
  • num = 2³¹ - 1：除法比较避免乘法溢出。
  • 时间复杂度：O(log num)。
  • 空间复杂度：O(1)。

四种语言完整代码

JavaLeetCode
class Solution {
    public boolean isPerfectSquare(int num) {
        int left = 1;
        int right = num;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            int quotient = num / mid;

            if (quotient == mid && num % mid == 0) {
                return true;
            }
            if (mid < quotient) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return false;
    }
}

替代方案

  • 牛顿迭代：更新 x = (x + num / x) / 2，收敛很快，但推导和终止条件更难讲清。
  • 连续奇数求和：利用前 k 个奇数之和为 k²，不断减去 1、3、5……；直观但最坏需要 O(√num) 时间。
  • 内置开方：本题明确禁止，并且浮点精度还可能带来边界判断问题。

常见错误

  • 直接用 mid * mid 且没有扩展整数类型，导致溢出。
  • 写成 left = mid 或 right = mid，区间可能无法缩小。
  • 只判断整数除法的商等于 mid，却忘记检查余数为 0。
  • 使用浮点近似再直接比较相等，忽视精度风险。
