二进制手表Binary Watch

十枚 LED、两个数值区域，以及对时间格式的严格要求。先读懂表盘，再用交互面板观察每一个候选时间。

EASY非付费题函数：readBinaryWatch(turnedOn)
01 / 题目

读懂这块表

顶部 4 枚 LED 表示小时，底部 6 枚 LED 表示分钟；每一排最右侧都是最低有效位。

给定整数 turnedOn，它表示当前点亮的 LED 总数（忽略上午/下午）。请返回这块二进制手表能够表示的所有时间，答案顺序任意。

  • 小时范围是 0–11，不能有前导零，例如写作 1:00，而不是 01:00。
  • 分钟范围是 0–59，必须始终保留两位，例如写作 10:02。

示例 2 输入：turnedOn = 9 输出：[]

03 / 题解

枚举所有合法时刻

合法表盘只有 720 种状态，直接枚举小时与分钟，再比较二进制中 1 的数量，逻辑短且边界清晰。

核心洞察

某个数的二进制中，每个 1 恰好对应一枚点亮的 LED。因此，时刻 h:m 满足条件，当且仅当：

popcount(h) + popcount(m) = turnedOn

完整过程

  1. 枚举小时 h = 0..11。
  2. 枚举分钟 m = 0..59。
  3. 计算两者的置位数之和。
  4. 相等时按 h:mm 格式加入答案。

正确性证明

充分性：若两部分置位数之和等于 turnedOn，表盘恰有指定数量的 LED 点亮，且枚举范围保证时间合法，所以该时刻应加入答案。

必要性：任何符合条件的时间，其小时必在 0–11、分钟必在 0–59，枚举一定会访问它；它的点亮 LED 数就是两部分置位数之和，因此一定会被收录。

故算法返回且仅返回全部合法时间。

边界与复杂度

  • turnedOn = 0 时只有 0:00。
  • 较大的点亮数可能没有合法时刻，返回空数组。
  • 分钟必须用两位，不给小时补零。
  • 遍历 720 个候选：时间 O(12 × 60)，除返回结果外空间 O(1)；若将表盘规模视作固定，则均为常数级。

替代方案

也可对 10 枚 LED 做回溯，选择恰好 turnedOn 枚后解码并过滤非法小时/分钟；还可预计算 0–11 与 0–59 的置位数并分组组合。二者更贴近“选灯”，但代码和非法状态处理都更繁琐。

面试追问

  • 如何用 x & (x - 1) 手写置位计数？
  • 若小时制、LED 数量或合法范围可变，复杂度如何表达？
  • 如何在不排序的前提下按时间先后输出？
  • 能否按置位数预分组，减少不必要比较？

常见错误

  • 把小时枚举到 15，或把分钟枚举到 63，导致非法时间混入。
  • 输出 01:00 或 10:2，破坏格式约束。
  • 把分钟接在小时二进制后直接作为普通数字处理，忽略两个字段的合法范围。
  • 误认为答案需要固定顺序；题目允许任意顺序。
04 / 代码

四语言完整实现

均保持官方函数签名，使用对应语言的置位计数能力。

JavaInteger.bitCount
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> readBinaryWatch(int turnedOn) {
        List<String> answer = new ArrayList<>();

        for (int hour = 0; hour < 12; hour++) {
            for (int minute = 0; minute < 60; minute++) {
                int lit = Integer.bitCount(hour)
                        + Integer.bitCount(minute);
                if (lit == turnedOn) {
                    answer.add(hour + ":"
                            + String.format("%02d", minute));
                }
            }
        }
        return answer;
    }
}
JavaScriptKernighan
/**
 * @param {number} turnedOn
 * @return {string[]}
 */
var readBinaryWatch = function(turnedOn) {
    const answer = [];

    const bitCount = (value) => {
        let count = 0;
        while (value !== 0) {
            value &= value - 1;
            count++;
        }
        return count;
    };

    for (let hour = 0; hour < 12; hour++) {
        for (let minute = 0; minute < 60; minute++) {
            if (bitCount(hour) + bitCount(minute) === turnedOn) {
                answer.push(
                    String(hour) + ":" + String(minute).padStart(2, "0")
                );
            }
        }
    }
    return answer;
};

from typing import List


class Solution:
    def readBinaryWatch(self, turnedOn: int) -> List[str]:
        answer: List[str] = []

        for hour in range(12):
            for minute in range(60):
                lit = hour.bit_count() + minute.bit_count()
                if lit == turnedOn:
                    answer.append(f"{hour}:{minute:02d}")

        return answer
C++__builtin_popcount
#include <cstdio>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> readBinaryWatch(int turnedOn) {
        vector<string> answer;

        for (int hour = 0; hour < 12; ++hour) {
            for (int minute = 0; minute < 60; ++minute) {
                int lit = __builtin_popcount(hour)
                        + __builtin_popcount(minute);
                if (lit == turnedOn) {
                    char time[6];
                    snprintf(time, sizeof(time), "%d:%02d", hour, minute);
                    answer.emplace_back(time);
                }
            }
        }
        return answer;
    }
};
