文物朝代判断朝代展柜

展柜恰好摆放 5 件文物，编号 0 代表未知朝代。先观察不同摆法，再判断未知编号能否让五件文物来自连续朝代。

排序扫描0 = 通配O(1) 规模

官方题面核实

每排展柜展示 5 个文物，places[i] 为所属朝代编号；0 表示未知朝代。判断能否视为连续五个朝代。

约束：places.length = 5，0 ≤ places[i] ≤ 13。

Bottom solution

题解与可提交代码

核心洞察

排序后，0 一定在最前。已知朝代一旦重复就无法成为连续集合；若最大和最小已知朝代跨度至多为 4，未知文物就能填满缺口。

完整过程

  1. 将五个编号升序排列。
  2. 跳过开头所有 0，定位第一个已知朝代。
  3. 扫描已知部分；出现相邻重复立即返回 false。
  4. 全是 0，或最大值减最小已知值不超过 4，则返回 true。

边界与复杂度

全部为 0 时必然可行；重复的非 0 编号必然失败；跨度恰为 4 仍可行，超过 4 失败。本题长度恒为 5，时间与额外空间均为 O(1)；泛化到 n 个元素时，排序为 O(n log n)。

替代方案

可用 Set 检查非 0 重复，同时维护最小值与最大值，不排序即可在 O(n) 时间、O(n) 空间完成；当前固定五格下，排序实现更简洁。

面试追问

若展柜长度不固定，判定条件如何变化？若编号允许环形衔接，如何处理跨越边界的连续区间？能否在不修改输入数组的前提下实现？

常见错误

只比较跨度却漏掉重复编号；把 0 也参与重复判断；将“跨度不超过 4”误写为严格小于 4；全 0 时错误访问第一个已知元素。

四语言可提交代码

var checkDynasty = function(places) {
  places.sort((a, b) => a - b);
  let first = 0;
  while (first < 5 && places[first] === 0) first++;
  for (let i = first + 1; i < 5; i++) {
    if (places[i] === places[i - 1]) return false;
  }
  return first === 5 || places[4] - places[first] <= 4;
};

class Solution:
    def checkDynasty(self, places: List[int]) -> bool:
        places.sort()
        first = next((i for i, x in enumerate(places) if x), 5)
        return (all(places[i] != places[i - 1] for i in range(first + 1, 5))
