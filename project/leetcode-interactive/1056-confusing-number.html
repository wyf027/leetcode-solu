易混淆数

Confusing Number

简单付费题数字旋转

把一个正整数的每个数字旋转 180°，同时让整个数字的顺序反转。若所有数字都能合法旋转，且旋转后的数与原数不同，则它是易混淆数。

0 → 01 → 16 → 98 → 89 → 6

包含 2、3、4、5、7 的数不能完成合法旋转。

函数与约束

boolean confusingNumber(int n)

  • 输入：整数 n
  • 输出：是否为易混淆数
  • 1 ≤ n ≤ 10⁹
关键区别：能旋转只是“有效”；旋转后还必须与原数不同，才是“易混淆”。

旋转装配台

观察算法如何从右往左取位，并把旋转后的数字依次接到结果末尾。

仅接受 1 到 1,000,000,000。

示例

输入：n = 6
输出：true
解释：6 旋转后得到 9，与原数不同。
输入：n = 89
输出：true
解释：从右向左旋转并重组：9 → 6，8 → 8，得到 68，与 89 不同。
输入：n = 11
输出：false
解释：11 虽能合法旋转，但结果仍为 11。

题解：取末位，旋转，再重组

核心洞察

数字整体旋转后，原数最右侧的一位会来到新数最左侧。因此反复取 n % 10，用固定映射旋转，并执行 rotated = rotated * 10 + mappedDigit，天然同时完成了“反序”和“旋转”。

完整过程

  1. 保存原数，结果初始化为 0。
  2. 从右向左取出每一位。
  3. 若该位不在 {0,1,6,8,9} 中，立即返回 false。
  4. 将映射后的位追加到结果。
  5. 处理完后，比较结果与原数；不同才返回 true。

正确性

循环不变式：处理完原数最右侧的 k 位后，rotated 恰好等于这 k 位旋转 180° 后按出现顺序组成的整数。初始 k=0 时成立；每轮把下一位的旋转映射追加到末尾，因此不变式保持。循环结束时全部位已处理，结果就是完整旋转数。非法数字会被拒绝；合法情况下，最终比较又精确判断其是否改变，所以算法返回值正确。

边界与复杂度

  • 仅由 0、1、8 组成的数也可能旋转后改变，例如 10 → 01（数值为 1）。
  • 包含非法数字时立即结束。
  • 末尾的 0 会在旋转后成为前导 0，整数运算会自然忽略它。
  • 时间复杂度 O(log n)，额外空间 O(1)。

替代方案

也可转成字符串，从尾到头查表并拼接，再与原字符串对应的数值比较。它更直观，但需要 O(log n) 额外空间。

面试追问

  • 如果要统计区间内易混淆数，怎样用 DFS 只生成合法数字？
  • 若输入超过 64 位整数范围，如何用字符串避免溢出？
  • 易混淆数与中心对称数（strobogrammatic number）的判断条件有什么不同？

常见错误

  • 忘记反转位序，只逐位替换。
  • 把“旋转有效”直接当作 true，漏掉 11、88 等不变情况。
  • 错误地把 2 或 5 当作旋转映射。
  • 用字符串直接比较而未处理旋转结果的前导 0。

Java

class Solution {
    public boolean confusingNumber(int n) {
        int original = n;
        int rotated = 0;
        int[] map = {0, 1, -1, -1, -1, -1, 9, -1, 8, 6};
        while (n > 0) {
            int digit = n % 10;
            if (map[digit] == -1) return false;
            rotated = rotated * 10 + map[digit];
            n /= 10;
        }
        return rotated != original;
    }
}

JavaScript

/**
 * @param {number} n
 * @return {boolean}
 */
var confusingNumber = function(n) {
    const original = n;
    const map = [0, 1, -1, -1, -1, -1, 9, -1, 8, 6];
    let rotated = 0;
    while (n > 0) {
        const digit = n % 10;
        if (map[digit] === -1) return false;
        rotated = rotated * 10 + map[digit];
        n = Math.floor(n / 10);
    }
    return rotated !== original;
};

Python

class Solution:
    def confusingNumber(self, n: int) -> bool:
        original = n
        rotated = 0
        mapping = {0: 0, 1: 1, 6: 9, 8: 8, 9: 6}
        while n > 0:
            digit = n % 10
            if digit not in mapping:
                return False
            rotated = rotated * 10 + mapping[digit]
            n //= 10
        return rotated != original
