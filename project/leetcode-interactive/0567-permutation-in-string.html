Permutation in String

字符串的排列

在一条很长的字符带上，寻找一个长度固定、字母配比恰好吻合的小窗口。先亲手移动窗口，再决定是否展开完整题解。

Problem

题意

给定两个字符串 s1 和 s2。如果 s2 中存在一个连续子串，它与 s1 含有完全相同的字符及出现次数，就返回 true；否则返回 false。这个子串也就是 s1 的某一种排列。

示例 1
输入：s1 = "ab", s2 = "eidbaooo"
输出：true

"ba" 是 "ab" 的一种排列。

示例 2
输入：s1 = "ab", s2 = "eidboaoo"
输出：false

没有任何长度为 2 的子串具有相同字符频次。

约束

  • 1 <= s1.length, s2.length <= 104
  • s1 和 s2 仅由小写英文字母组成。

Complete solution

题解：定长滑动窗口 + 频次差值

核心洞察

排列只改变字符顺序，不改变字符频次。候选子串的长度必须恰好等于 s1.length，所以只需在 s2 上维护一个固定长度的窗口。

diff[c] = count(s1, c) − count(window, c)

当且仅当 26 个差值全为 0，窗口与 s1 的频次完全相同。

完整过程

  1. 若 s1 比 s2 长，任何子串都放不下它，直接返回 false。
  2. 用前 m = s1.length 个字符建立首个窗口，计算 26 项 diff。
  3. 维护 mismatch：当前不为 0 的差值项数量。
  4. 窗口右移时，离开字符使差值加 1，进入字符使差值减 1；只更新这两个字符对 mismatch 的影响。
  5. 任一步出现 mismatch == 0 即返回 true；所有窗口结束仍未出现则返回 false。

正确性证明

引理 1：差值数组始终正确 首窗口直接按定义构造。每次右移只删除一个旧字符、加入一个新字符；分别对差值做 +1 和 −1 后，仍有 diff[c] = count(s1,c) − count(window,c)。
引理 2：mismatch 精确计数 每次修改字符差值前后，只在它跨过 0 时增减 mismatch，因此该变量始终等于非零差值项数量。
充分性 若 mismatch == 0，所有字符频次差都为 0。窗口与 s1 等长且每种字符数量一致，所以窗口是 s1 的排列。
必要性与结论 若某窗口是 s1 的排列，各字符频次必相同，于是所有差值为 0。算法枚举每个定长窗口，因此返回值正确。

边界与复杂度

时间复杂度O(|s1| + |s2|)
额外空间O(1)固定 26 项数组
关键边界|s1| > |s2|立即返回 false
更多边界：最短字符串长度为 1；重复字符如 s1 = "aab" 必须按次数比较；命中窗口可能出现在开头、结尾或中间；约束保证只有小写英文字母，可安全使用长度为 26 的数组。

替代方案

每个窗口排序

把 s1 和每个候选子串排序后比较，直观但会重复排序，最坏约为 O((n-m+1) · m log m)。

双频次数组 / 26 项全比较

维护目标与窗口两个数组，每移动一步比较 26 项。因为字母表固定，渐进复杂度仍是 O(n)，代码也很清楚；mismatch 只是避免重复扫描 26 项。

常见错误

窗口长度写成可变排列匹配要求候选长度等于 s1.length，无需像“最小覆盖子串”那样收缩窗口。
只检查字符是否出现"aab" 与 "abb" 字符集合相似，但频次不同，必须计数。
更新方向颠倒采用“目标 − 窗口”时，离开窗口的字符应令差值 +1，进入字符应令差值 −1。
漏查首窗口或末窗口首窗口应在循环前判断；右端点要移动到 s2.length - 1。

面试追问

字符集不再是 26 个小写字母？改用哈希表存储差值，只跟踪实际出现的字符；Unicode 场景还要明确按码点还是字素簇处理。
s2 是持续到来的字符流？用长度为 |s1| 的队列保存当前窗口，流入一个字符时弹出最旧字符，差值与 mismatch 的更新方式不变。
需要返回所有起点？命中时记录 right - m + 1，继续滑动而不是立即返回。
为什么不用哈希值？滚动哈希可能碰撞；固定字母表的精确频次数组空间小、无碰撞，且同样线性。

class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int m = s1.length();
        int n = s2.length();
        if (m > n) {
            return false;
        }

        int[] diff = new int[26];
        for (int i = 0; i < m; i++) {
            diff[s1.charAt(i) - 'a']++;
            diff[s2.charAt(i) - 'a']--;
        }

        int mismatch = 0;
        for (int value : diff) {
            if (value != 0) mismatch++;
        }
        if (mismatch == 0) return true;

        for (int right = m; right < n; right++) {
            int leaving = s2.charAt(right - m) - 'a';
            if (diff[leaving] == 0) mismatch++;
            diff[leaving]++;
            if (diff[leaving] == 0) mismatch--;

            int entering = s2.charAt(right) - 'a';
            if (diff[entering] == 0) mismatch++;
            diff[entering]--;
            if (diff[entering] == 0) mismatch--;

            if (mismatch == 0) return true;
        }
        return false;
    }
}

/**
 * @param {string} s1
 * @param {string} s2
 * @return {boolean}

var checkInclusion = function(s1, s2) {
    const m = s1.length;
    const n = s2.length;
    if (m > n) return false;

    const diff = new Array(26).fill(0);
    const index = (ch) => ch.charCodeAt(0) - 97;

    for (let i = 0; i < m; i++) {
        diff[index(s1[i])]++;
        diff[index(s2[i])]--;
    }

    let mismatch = diff.reduce(
        (total, value) => total + (value !== 0 ? 1 : 0),
        0
    );
    if (mismatch === 0) return true;

    const adjust = (letterIndex, delta) => {
        if (diff[letterIndex] === 0) mismatch++;
        diff[letterIndex] += delta;
        if (diff[letterIndex] === 0) mismatch--;
    };

    for (let right = m; right < n; right++) {
        adjust(index(s2[right - m]), 1);
        adjust(index(s2[right]), -1);
        if (mismatch === 0) return true;
    }
    return false;
};
Python 3
class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        m, n = len(s1), len(s2)
        if m > n:
            return False

        diff = [0] * 26
        for i in range(m):
            diff[ord(s1[i]) - ord('a')] += 1
            diff[ord(s2[i]) - ord('a')] -= 1

        mismatch = sum(value != 0 for value in diff)
        if mismatch == 0:
            return True

        def adjust(letter_index: int, delta: int, count: int) -> int:
            if diff[letter_index] == 0:
                count += 1
            diff[letter_index] += delta
            if diff[letter_index] == 0:
                count -= 1
            return count

        for right in range(m, n):
            leaving = ord(s2[right - m]) - ord('a')
            entering = ord(s2[right]) - ord('a')
            mismatch = adjust(leaving, 1, mismatch)
            mismatch = adjust(entering, -1, mismatch)
            if mismatch == 0:
                return True

        return False
C++
class Solution {
public:
    bool checkInclusion(string s1, string s2) {
        int m = static_cast<int>(s1.size());
        int n = static_cast<int>(s2.size());
        if (m > n) return false;

        array<int, 26> diff{};
        for (int i = 0; i < m; ++i) {
            ++diff[s1[i] - 'a'];
            --diff[s2[i] - 'a'];
        }

        int mismatch = 0;
        for (int value : diff) {
            if (value != 0) ++mismatch;
        }
        if (mismatch == 0) return true;

        auto adjust = [&](int index, int delta) {
            if (diff[index] == 0) ++mismatch;
            diff[index] += delta;
            if (diff[index] == 0) --mismatch;
        };

        for (int right = m; right < n; ++right) {
            adjust(s2[right - m] - 'a', 1);
            adjust(s2[right] - 'a', -1);
            if (mismatch == 0) return true;
        }
        return false;
    }
};
