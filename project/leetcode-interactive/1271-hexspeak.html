题意与规则

准确转述 · 非原文复制

题目

给定一个只表示正整数的十进制字符串 num。先得到它的大写十六进制表示， 再将其中的数字 0 写成字母 O，将数字 1 写成字母 I。字母 A 到 F 保持不变。

如果十六进制表示中出现 2 到 9 的任一数字，则它无法成为 Hexspeak，返回 "ERROR"；否则返回替换后的字符串。

约束

  • num 是合法的十进制正整数字符串。
  • 1 ≤ 整数值(num) ≤ 10¹²。
  • 输出中的合法字符仅为 A–F、I、O。

示例 1

输入：num = "257"
输出："IOI"
解释：257 的十六进制形式是 101，依次替换 1、0、1 后得到 IOI。

示例 2

输入：num = "3"
输出："ERROR"
解释：十六进制形式 3 含有不允许的数字，因此返回 ERROR。

Solution

题解

逐位转换 + 合法性审计

核心洞察

这道题并不需要在十进制上模拟复杂的字符串运算，因为上界 10¹² 能被常见语言的 64 位整数安全容纳。反复除以 16，余数就是从低位到高位的十六进制数字。

余数 0 → O，余数 1 → I，余数 10…15 → A…F；余数 2…9 → ERROR

完整过程

  1. 把输入字符串解析为整数 n。
  2. 当 n > 0 时，取 n % 16 并记录对应十六进制字符。
  3. 令 n = n / 16，继续处理下一位。
  4. 若记录中存在 2…9，返回 "ERROR"。
  5. 否则逆序输出，并把 0/1 转成 O/I。

正确性证明

对任意当前整数 n，除法算法给出唯一的 n = 16q + r，其中 0 ≤ r < 16。因此 r 正是 n 的最低十六进制位。
将 n 更新为商 q 后重复，依次得到从低到高的全部十六进制位； 商最终变为 0，逆序这些余数便得到唯一的标准十六进制表示。
对每一位应用题目规定的映射。若出现 2…9，该位没有合法 Hexspeak 表示，返回 ERROR 必然正确；若从未出现，则每一位都被准确映射为 A…F/I/O，返回字符串也必然正确。

边界与复杂度

  • 最小值 1 会得到 I。
  • 只要任意一位落在 2…9，最终结果就是 ERROR。
  • 字母位统一使用大写 A…F。
  • 时间复杂度：O(log₁₆ N)。
  • 空间复杂度：O(log₁₆ N)，用于保存结果字符。

替代方案

可直接调用语言内置的十六进制转换，再扫描字符串，将 0/1 替换为 O/I 并检查 2…9。它更短，但面试中手写除 16 的版本更能说明 进制转换机制，也更容易控制大小写和错误判断。

面试追问

  • 若输入可能远超 64 位整数，怎样直接对十进制字符串做除 16？
  • 怎样把规则推广到任意进制与任意字符映射表？
  • 能否边转换边提前返回 ERROR，还保持结果正确？

常见错误

  • 把字母 O 与数字 0、字母 I 与数字 1 混淆。
  • 忘记余数按低位到高位产生，最终结果必须逆序。
  • 仅替换 0/1，却没有检查 2…9。
  • 输出小写 a…f，与要求的大写形式不一致。

Implementations

四种语言完整代码

Java · LeetCode 提交格式
class Solution {
    public String toHexspeak(String num) {
        long n = Long.parseLong(num);
        StringBuilder reversed = new StringBuilder();

        while (n > 0) {
            int remainder = (int) (n % 16);
            if (remainder >= 2 && remainder <= 9) {
                return "ERROR";
            }

            if (remainder == 0) {
                reversed.append('O');
            } else if (remainder == 1) {
                reversed.append('I');
            } else {
                reversed.append((char) ('A' + remainder - 10));
            }

            n /= 16;
        }

        return reversed.reverse().toString();
    }
}

Python · LeetCode 提交格式
class Solution:
    def toHexspeak(self, num: str) -> str:
        n = int(num)
        reversed_chars = []

        while n > 0:
            remainder = n % 16
            if 2 <= remainder <= 9:
                return "ERROR"

            if remainder == 0:
                reversed_chars.append("O")
            elif remainder == 1:
                reversed_chars.append("I")
            else:
                reversed_chars.append(chr(ord("A") + remainder - 10))

            n //= 16

        return "".join(reversed(reversed_chars))
C++ · LeetCode 提交格式
class Solution {
public:
    string toHexspeak(string num) {
        unsigned long long n = stoull(num);
        string reversed;

        while (n > 0) {
            int remainder = static_cast<int>(n % 16);
            if (remainder >= 2 && remainder <= 9) {
                return "ERROR";
            }

            if (remainder == 0) {
                reversed.push_back('O');
            } else if (remainder == 1) {
                reversed.push_back('I');
            } else {
                reversed.push_back(static_cast<char>('A' + remainder - 10));
            }

            n /= 16;
        }

        reverse(reversed.begin(), reversed.end());
        return reversed;
    }
};
