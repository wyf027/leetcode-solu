2335. 装满杯子需要的最短总时长

Minimum Amount of Time to Fill Cups

三种水温，两个出水位。试着安排每一秒，再思考哪些限制决定了总时长。

01 / 理解任务

把所有需求装满

给定整数数组 amount，三个位置依次表示冷水、温水、热水的待装杯数。饮水机每秒可装满一杯任意类型的水，或同时装满两杯不同类型的水。求完成全部需求的最少秒数。

同一秒不能装两杯相同类型的水；杯数为 0 的类型无需处理。

约束
  • amount.length == 3
  • 0 <= amount[i] <= 100
  • 返回值：整数秒数；参数：amount: integer[]

官方示例

输入：amount = [1,4,2]
输出：4

一种安排：第 1 秒冷＋温，第 2 秒温＋热，第 3 秒温＋热，第 4 秒温。

输入：amount = [5,4,4]
输出：7

一种安排：冷＋热 → 冷＋温 → 冷＋温 → 温＋热 → 冷＋热 → 冷＋温 → 热，共 7 秒。

输入：amount = [5,0,0]
输出：5

只需要冷水，每秒一杯，连续装 5 秒。

04 / 独立题解

先观察，再揭晓

准备好后展开推导、正确性说明与四语言代码。

核心洞察：两个无法绕过的下界

记总杯数为 S，最多的一种水的杯数为 M。每秒至多装两杯，因此至少要 ⌈S / 2⌉ 秒；同一种水每秒至多一杯，因此至少要 M 秒。

最少秒数 = max(M, ⌈S / 2⌉)

这两个下界不仅必要，还可以同时达到。无需排序、堆或真正模拟每一秒。

完整过程

  1. 将三个元素相加，得到总杯数 S。
  2. 取三个元素的最大值 M。
  3. 计算向上取整的一半：整数语言可写为 (S + 1) / 2，Python 使用 //，JavaScript 使用 Math.ceil(S / 2)。
  4. 返回 M 与上述数值中较大的一个。

例如 amount = [1,4,2]：S = 7，M = 4，总量下界为 4，因此答案为 4。[5,4,4] 的 S = 13、M = 5，答案为 7；[5,0,0] 由冷水需求决定，答案为 5。

演示如何选杯

调度台每秒选择剩余需求最多的两种非空水温；只剩一种时，每秒装一杯。相同杯数按冷、温、热顺序选取。它展示达到最少秒数的一种实际安排；提交代码直接计算公式。

正确性证明

令 T = max(M, ⌈S / 2⌉)。前述两条限制说明任何方案至少需要 T 秒。下面用归纳证明演示策略至多需要 T 秒。

  1. 没有杯子时 T = 0，直接结束。只剩一种水时，每秒一杯，恰好需要 M = T 秒。
  2. 至少有两种非空需求时，对剩余杯数最多的两种各装一杯，剩余总量变为 S − 2。因为 S ≤ 2T，剩余总量至多 2(T − 1)。
  3. 所有类型原来都不超过 T。杯数恰好等于 T 的类型最多两种，否则 S ≥ 3T > 2T；这些类型一定在本次选中的两种之中。因此装水后每类最多 T − 1 杯。
  4. 新状态的两项下界都不超过 T − 1，由归纳假设剩余需求可在至多 T − 1 秒完成。加上当前一秒，总共至多 T 秒。

结合“至少 T 秒”和“至多 T 秒”，公式成立。每次总杯数减少，归纳最终到达全零状态。

边界与复杂度

  • 全零返回 0；只有一种水时返回该杯数；总量为奇数时须向上取整。
  • 某一种特别多时，不能只看总量的一半；例如 [8,1,1] 需要 8 秒。
  • 固定只有 3 个元素，时间复杂度 O(1)，额外空间 O(1)；以下代码不修改输入。
  • 约束下 S ≤ 300，不会造成下方整数类型溢出。

四语言提交代码

采用官方 fillCups 签名；均为完整提交实现，尚未编译或运行。

Java

class Solution {
    public int fillCups(int[] amount) {
        int total = amount[0] + amount[1] + amount[2];
        int largest = Math.max(amount[0], Math.max(amount[1], amount[2]));
        return Math.max(largest, (total + 1) / 2);
    }
}

JavaScript

/**
 * @param {number[]} amount
 * @return {number}
 */
var fillCups = function(amount) {
    const total = amount[0] + amount[1] + amount[2];
    return Math.max(...amount, Math.ceil(total / 2));
};

Python

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int fillCups(vector<int>& amount) {
        int total = amount[0] + amount[1] + amount[2];
        int largest = max({amount[0], amount[1], amount[2]});
        return max(largest, (total + 1) / 2);
    }
};

替代方案

每秒将三个剩余杯数排序，减少最大的两个正数，计时直到全零。这与演示一致，时间为 O(S)，额外空间可为 O(1)。使用最大堆也能模拟，但对于固定三类会增加实现成本。公式只适用于当前“每秒一杯或两杯不同类型”的规则。

常见错误

  • 仅返回 ⌈S/2⌉，忽略单类不能并行装两杯。
  • 仅返回 M，忽略 [1,1,1] 需要两秒。
  • 对奇数总量向下取整，导致少算最后一杯。
  • 随便挑两种：对 [2,1,1] 先装两种较少的水，会留下两杯同类而多用一秒。
  • 模拟中把零减成负数，或把同一种水放在两个出水位。

面试追问

  • 需要输出具体日程怎么办？逐秒选择最大的两个非空需求，记录水温；日程长度为 T，输出本身需要 O(T) 空间。
  • 扩展到 n 种水，每秒仍至多两种？同样的下界与归纳可推广，公式通过一次扫描求和、求最大值，时间 O(n)。
  • 每秒允许两杯同温水？单类下界不再成立，只剩 ⌈S/2⌉。
  • 不同水温装满耗时不同？逐秒每杯的模型已改变，需要重新描述机器并行和占用规则，不能直接套用本题公式。
