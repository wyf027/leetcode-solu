子数组范围和

Sum of Subarray Ranges

同一段数组里，最大值与最小值能相差多少？
把每一段连续区间的这个差值，加在一起。

非空子数组整数数组进阶挑战 O(n)

01 / 题目

给定整数数组 nums，对每个连续且非空的子数组，计算其中最大元素减去最小元素的差，称为该子数组的范围。返回所有子数组范围的总和。不同位置的子数组分别计数，即使它们的元素相同。

参数与返回值

subArrayRanges(nums)
输入：整数数组 nums
返回：所有非空连续子数组的范围和（长整数语义）。

约束

  • 1 ≤ nums.length ≤ 1000
  • −10⁹ ≤ nums[i] ≤ 10⁹

进阶：能否做到 O(n) 时间？

04 / 独立题解

先自行思考；展开后可阅读推导、操作演示与四语言代码。

核心洞察：让每个元素认领区间

把每个区间的 max − min 分开累加：

答案 = 所有子数组最大值之和 − 所有子数组最小值之和
元素贡献 = 元素值 × 左端点选择数 × 右端点选择数

对下标 j，找到左边界 L 与右边界 R。让它负责左端点在 [L+1,j]、右端点在 [j,R−1] 的区间。数量就是 (j−L) × (R−j)。

最小值一遍

L：左侧最近的严格更小元素。
R：右侧最近的小于或等于元素。
遇到 nums[top] ≥ nums[i] 时弹栈。

最大值一遍

L：左侧最近的严格更大元素。
R：右侧最近的大于或等于元素。
遇到 nums[top] ≤ nums[i] 时弹栈。

两遍都把相同极值区间交给最右侧的那个极值元素，因此不会重复认领。

交互实验 / 边界 × 贡献

每次弹栈固定一个元素的右边界；弹出后栈顶就是左边界。观察重复值如何被右侧同值元素接管。演示分别播放两遍，最终用最大值总和减去最小值总和。

使用 JSON 数组；元素范围 −10⁹ 至 10⁹。12 个元素仅为演示界面上限。

深绿 + j：本次认领者；浅绿：可用区间；虚线 + L/R：阻挡边界。下标从 0 开始。

当前单调栈 · 栈底 → 栈顶

本次区间认领

当前累计贡献：0

所有按钮支持 Tab 聚焦与 Enter / 空格激活；控制区内可用 ← / → 单步。自动播放每 1.2 秒前进，减少动态效果偏好下为 2.4 秒。

完整过程

  1. 定义 sum(maximum)，栈内保存下标，累计值从 0 开始。
  2. 从左到右扫描 i。求最大值时弹出所有值 ≤ 当前值的栈顶；求最小值时弹出所有值 ≥ 当前值的栈顶。
  3. 每次弹出 j 后，取新栈顶为 L，若栈空则 L = −1；当前 i 即 R。增加 nums[j] × (j−L) × (i−j)。
  4. 处理完弹栈，把 i 压入栈。扫描额外的 i = n 时只清空栈，不读取 nums[n]，也不把它压入栈。
  5. 返回 sum(true) − sum(false)。

沿着 [1,3,3] 推一遍

最大值贡献：下标 0 贡献 1×1×1 = 1，下标 1 贡献 3×2×1 = 6，下标 2 贡献 3×3×1 = 9，总计 16。最小值贡献：下标 1 为 3，下标 2 为 6，下标 0 为 3，总计 12。答案为 16−12 = 4。

正确性论证

边界正确：以最小值为例，弹栈后栈中值严格递增，因此新栈顶是左侧最近的严格更小元素。当前元素是第一个使 j 弹出的元素，即右侧第一个小于或等于它的元素。扫描结束清栈对应右边界 n。

认领恰好一次：任意子数组选择其最右侧最小值所在位置 j。左端点不能越过 L，右端点不能到达 R；反之这两个范围内任意端点组合都保证 j 是该子数组最右侧最小值。因此每个子数组与一个认领者、一个端点组合一一对应。最大值同理。

相减得到目标：两次遍历分别完整且不重叠地累加所有区间的最大值与最小值。求和的线性性质保证相减等于全部范围之和。

复杂度与数值边界

每个下标每遍只入栈、出栈各一次，所以两遍总时间 O(n)，辅助空间 O(n)。最多 500500 个子数组；范围最多 2×10⁹，总和上界 1.001×10¹⁵。Java 使用 long，C++ 使用 long long，并在乘法前提升类型；JavaScript Number 在此约束内小于 2⁵³，整数可精确表示；Python 整数无需额外处理。

单元素与全相等数组的两项贡献和相同，结果为 0；负数无需取绝对值；单调数组末尾必须完成清栈。题目不允许空数组。

四语言实现

Java

class Solution {
    public long subArrayRanges(int[] nums) {
        return sum(nums, true) - sum(nums, false);
    }

    private long sum(int[] a, boolean maximum) {
        int n = a.length, size = 0;
        int[] stack = new int[n];
        long total = 0;
        for (int i = 0; i <= n; i++) {
            while (size > 0 && (i == n ||
                    (maximum ? a[stack[size - 1]] <= a[i]
                             : a[stack[size - 1]] >= a[i]))) {
                int j = stack[--size];
                int left = size == 0 ? -1 : stack[size - 1];
                total += (long) a[j] * (j - left) * (i - j);
            }
            if (i < n) stack[size++] = i;
        }
        return total;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number}
 */
var subArrayRanges = function(nums) {
    function sum(maximum) {
        const stack = [];
        let total = 0;
        for (let i = 0; i <= nums.length; i++) {
            while (stack.length && (i === nums.length ||
                (maximum ? nums[stack[stack.length - 1]] <= nums[i]
                         : nums[stack[stack.length - 1]] >= nums[i]))) {
                const j = stack.pop();
                const left = stack.length ? stack[stack.length - 1] : -1;
                total += nums[j] * (j - left) * (i - j);
            }
            if (i < nums.length) stack.push(i);
        }
        return total;
    }
    return sum(true) - sum(false);
};

Python 3

from typing import List

class Solution:
    def subArrayRanges(self, nums: List[int]) -> int:
        def total(maximum: bool) -> int:
            stack = []
            result = 0
            n = len(nums)
            for i in range(n + 1):
                while stack and (i == n or
                    (nums[stack[-1]] <= nums[i] if maximum
                     else nums[stack[-1]] >= nums[i])):
                    j = stack.pop()
                    left = stack[-1] if stack else -1
                    result += nums[j] * (j - left) * (i - j)
                if i < n:
                    stack.append(i)
            return result

        return total(True) - total(False)

C++

#include <vector>
using namespace std;

class Solution {
    long long sum(const vector<int>& a, bool maximum) {
        int n = static_cast<int>(a.size());
        vector<int> stack;
        long long total = 0;
        for (int i = 0; i <= n; ++i) {
            while (!stack.empty() && (i == n ||
                   (maximum ? a[stack.back()] <= a[i]
                            : a[stack.back()] >= a[i]))) {
                int j = stack.back();
                stack.pop_back();
                int left = stack.empty() ? -1 : stack.back();
                total += 1LL * a[j] * (j - left) * (i - j);
            }
            if (i < n) stack.push_back(i);
        }
        return total;
    }
public:
    long long subArrayRanges(vector<int>& nums) {
        return sum(nums, true) - sum(nums, false);
    }
};

替代方案与面试追问

直接枚举：O(n²) 时间，O(1) 额外空间

固定左端点，将右端点不断右移，同时更新当前区间的最小值与最大值，并累加二者之差。n ≤ 1000 时这是清晰可行的基础方案。若对每个区间重新扫描求极值，则会退化为 O(n³)。进阶要求用上述单调栈降到 O(n)。

先存四组边界

也可以先求每个位置的最大值左右边界、最小值左右边界，再统一累加贡献。时间与空间仍为 O(n)，边界容易观察，但比弹栈时直接结算多用几组数组。

为什么不能两侧都严格，或者两侧都非严格？

同值元素会使两侧都严格的规则重复认领区间，而两侧都非严格会漏掉跨越同值元素的区间。比如 [3,3] 的整个区间需要恰好一个所有者。一侧严格、一侧非严格建立确定的归属。

可以把区间交给最左侧的相同极值吗？

可以。把比较规则整体反过来：最小值取左侧 ≤、右侧 <；最大值取左侧 ≥、右侧 >。需要成对调整，不能只改一处边界解释。

如果所有值都加上常数 c，答案怎样变化？

不变。每个区间的最大值与最小值都增加 c，相减后抵消；两个贡献总和也都增加 c×n(n+1)/2。

为什么 while 循环嵌套仍是线性时间？

一次扫描可以弹出多个元素，但一个下标被弹出后不会再次入栈。把整遍扫描的入栈和出栈次数合计，最多各 n 次，这是摊还分析。

常见错误

  • 把子数组当成可跳过元素的子序列。
  • 左右端点数量写成 j−L+1 或 R−j+1：L、R 是不能纳入的边界。
  • 先乘 int 再转 long；溢出已发生，必须在第一次乘法前提升。
  • 使用负数时取绝对值，破坏最大值和最小值贡献的代数意义。
  • 漏掉 i=n 的清栈，或者在判断哨兵之前访问 nums[n]。
  • 弹栈前读取左边界，误把 j 自己当作 L。
