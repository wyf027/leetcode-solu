水壶问题

Water and Jug Problem

先把每一次装水、倒水和清空看成状态变化。你可以在不查看题解的情况下，亲手推进一个完整测量过程。

函数签名

canMeasureWater(x, y, target) → boolean

离线单文件 · 原生交互 · 390px 适配

Problem

题目描述

给定两个容量分别为 x 升和 y 升的水壶，以及无限水源。判断能否通过允许的操作，使两个水壶中的水量之和恰好达到 target 升。

每一步可以执行以下一种操作：

  • 将任意一个水壶完全装满；
  • 将任意一个水壶完全清空；
  • 从一个水壶向另一个水壶倒水，直到接水壶装满，或倒水壶倒空。

官方示例

示例 1

输入：x = 3, y = 5, target = 4
输出：true

例如最终可到达状态 (0, 4)，两壶水量之和为 4。

示例 2

输入：x = 2, y = 6, target = 5
输出：false

示例 3

输入：x = 1, y = 2, target = 3
输出：true

装满两个水壶后，总水量正好为 3。

约束

1 ≤ x, y, target ≤ 10³

Solution

完整题解

核心洞察：裴蜀定理

设 g = gcd(x, y)。装满、清空和相互倒水，本质上让水量发生若干次 x 与 y 的整数加减。因此能够得到的总量必须是 g 的倍数。同时，两个水壶最多只能容纳 x + y 升水。

反过来，裴蜀定理说明：如果 target 是 gcd(x, y) 的倍数，就存在整数 a, b 使 ax + by = target。当 target ≤ x + y 时，可以通过反复装满、倾倒和清空把这种整数线性组合落实为合法水壶操作。

判定条件

target ≤ x + y 且 target % gcd(x, y) = 0

完整过程

  1. 先判断容量上界：若 target > x + y，两个水壶同时装满也不够，返回 false。
  2. 用欧几里得算法计算 gcd(x, y)。
  3. 若 target 能被最大公约数整除，返回 true；否则返回 false。

正确性证明

必要性

初始水量为 0。每次从无限水源引入或排出的水量，都可表示为 x、y 的整数线性组合，所以任一可达目标都是 gcd(x, y) 的倍数；此外总量显然不能超过 x + y。

充分性

若 target ≤ x + y 且 gcd(x, y) | target，裴蜀定理保证目标可写成 x、y 的整数线性组合。反复执行“装满一个壶并倒入另一个壶，满则清空”的过程，会遍历对应公约数步长的可达水量，因而可以达到目标总量。

结论

算法返回 true 当且仅当目标总量可通过合法操作得到，因此判定正确。

边界情况

  • target = x + y：直接装满两个水壶即可，且条件自然成立。
  • target = x 或 target = y：装满对应水壶即可。
  • 一个容量整除另一个容量：只能得到该较小容量公约数的倍数。
  • x 与 y 互质：不超过容量总和的每个正整数目标都可测得。

复杂度

欧几里得算法的时间复杂度为 O(log(min(x, y)))，空间复杂度为 O(1)。

替代方案：状态图 BFS / DFS

把状态记为 (a, b)，其中 0 ≤ a ≤ x、0 ≤ b ≤ y。从 (0, 0) 出发，枚举装满、清空、相互倾倒六种转移，搜索是否存在 a + b = target 的状态。该方案直观、可构造具体步骤，时间和空间复杂度均为 O(xy)；上方可视化正是用这种方式寻找演示路径。

面试追问

  • 如果要求输出一条最短操作序列，如何用 BFS 的父节点记录还原路径？
  • 如果目标要求“某一个水壶中恰好有 target 升”而不是两壶总量，判定和搜索终止条件如何调整？
  • 为什么欧几里得算法与反复倒水产生的余数序列具有相同结构？
  • 如果有三个水壶，二元裴蜀条件是否仍足以刻画所有受容量上界限制的可达状态？

常见错误

  • 只检查 target % gcd(x, y)，忘记判断 target ≤ x + y。
  • 误以为目标必须完整地落在某一个水壶中；本题允许两个水壶中的总量达到目标。
  • BFS 时没有记录访问状态，导致状态之间反复循环。
  • 倾倒转移写错：转移量应为 min(倒水壶现有水量, 接水壶剩余容量)。

四语言完整代码

Java 
class Solution {
    public boolean canMeasureWater(int x, int y, int target) {
        if (target > x + y) {
            return false;
        }
        return target % gcd(x, y) == 0;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }
}
JavaScript 
/**
 * @param {number} x
 * @param {number} y
 * @param {number} target
 * @return {boolean}

var canMeasureWater = function (x, y, target) {
    if (target > x + y) {
        return false;
    }

    const gcd = (a, b) => {
        while (b !== 0) {
            const remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    };

    return target % gcd(x, y) === 0;
};
