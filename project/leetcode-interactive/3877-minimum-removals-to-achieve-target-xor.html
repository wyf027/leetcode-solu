达到目标异或值的最少删除次数

删除得越少，留下的元素就越多。把“最少删除”翻译成“寻找异或值为 target 的最长子序列”，再把 40 个元素平分为两半。

数组长度 ≤ 40数值 ≤ 10⁴折半枚举O(2^(n/2))

题意

保留任意子序列

给定 nums 与 target，可移除任意个元素。要求剩余元素的按位异或和等于 target，返回最少移除次数；不存在则返回 -1。空数组的异或和为 0。

示例输出1

为什么不能直接枚举？

2⁴⁰ 个子集约为一万亿；平分后仅需各枚举 2²⁰ 个子集。对每个 XOR，只保留“元素数最大”的那一条记录即可。

状态的含义

bestLeft[x]
左半边异或为 x 时最多保留几项。
需要的右侧异或
rightXor = target XOR leftXor。

边界

  • 所有元素都可保留时答案是 0。
  • target = 0 时空子序列也合法。
  • 0 不改变异或值，却能增加保留长度。
  • 找不到匹配异或值则为 -1。

核心洞察

删除 n - kept 项。因此最大化保留数。将数组拆为 L、R：若左侧子集异或为 x，右侧必须为 target XOR x。两个哈希表均只存某个 XOR 的最大子集大小。

完整过程

  1. 把数组分成大小近似相等的两半。
  2. DFS / 位掩码枚举左半边所有子集，更新 bestLeft[xor]。
  3. 枚举右半边每个子集，查询 bestLeft[target XOR rightXor]。
  4. 最大保留数为两边数量之和；若不存在匹配则返回 -1。

复杂度

时间 O(2^(n/2))，空间 O(2^(n/2))。这比 O(2^n) 的整数组枚举可行得多。

替代方案与面试追问

值域较小时也可做 XOR 背包，复杂度约 O(n · 2^k)。若追问“输出一组保留下标”，哈希表额外存掩码即可回溯。

常见错误

  • 最小化删除却在表中保存最小子集长度。
  • 遗漏空子集（它对应 XOR 0）。
  • 只枚举左右两侧之一，忘了组合条件。
  • 对相同 XOR 覆盖了更长的保留方案。
