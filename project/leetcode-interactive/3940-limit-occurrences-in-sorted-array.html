3940. 限制有序数组中的元素出现次数

已排序让相同元素相邻。用一个写入指针，只保留每个值最前面的 k 次出现。

打开力扣题目

题意

给定按非递减顺序排列的 nums 与 k，返回一个新数组：每个不同元素最多保留 k 次，且相对顺序不变。

输入 输出 说明
nums = [1,1,1,2,2,3], k = 2 [1,1,2,2,3] 第 3 个 1 被跳过
nums = [1,2,3], k = 1 [1,2,3] 每个值都只出现一次

提示：1 ≤ nums.length ≤ 100，1 ≤ nums[i] ≤ 100，1 ≤ k ≤ nums.length。

首屏观察

  1. 排序保证同一个值连成一段。
  2. 读到第 i 个数时，若写入长度 w < k，必可保留。
  3. 否则只要 nums[i] ≠ ans[w-k]，它就是新值，仍可保留。

核心洞察与完整过程

维护答案 ans。遍历当前值 x：当 ans.length < k 时直接加入。否则比较 x 与 ans[ans.length-k]：相等说明当前这段已经保留了 k 个，跳过；不等说明进入下一段，加入即可。

这正是原地双指针的等价写法：令 w 为写位置，扫描 x；仅当 w < k || x != nums[w-k] 时写入 nums[w++] = x，最后返回前 w 项。

边界、复杂度与替代方案

  • k = 1 时退化为去重。
  • 整个数组都相等时只保留前 k 项。
  • 数组少于 k 项时全部保留。
  • 时间 O(n)，原地写法额外空间 O(1)；返回数组不计入额外空间。

面试追问

如果输入并非有序？可以用哈希表计数，但顺序保留、空间会变为 O(u)。如果每个数的上限不同？把“与 w-k 比较”的统一规则改为查询该值的剩余额度。

常见错误

  • 用全局计数而不是按值计数。
  • 在 w < k 时访问 nums[w-k] 导致越界。
  • 把返回值误写成保留长度，而题目要求数组。

代码语言选择

class Solution {
    public int[] limitOccurrences(int[] nums, int k) {
        int w = 0;
        for (int x : nums) {
            if (w < k || x != nums[w - k]) nums[w++] = x;
        }
        return java.util.Arrays.copyOf(nums, w);
    }
}
var limitOccurrences = function(nums, k) {
  const ans = [];
  for (const x of nums) {
    if (ans.length < k || x !== ans[ans.length - k]) ans.push(x);
  }
  return ans;
};
