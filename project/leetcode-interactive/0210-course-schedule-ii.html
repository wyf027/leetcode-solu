210. 课程表 II

给出课程总数及先修关系，返回一条能修完所有课程的顺序；如果依赖关系存在环，则返回空数组。

拓扑排序Kahn 算法入度有向图

题意

prerequisites[i] = [a, b] 表示学习课程 a 之前必须先完成 b。返回任意一条可行顺序；若无法完成全部 numCourses 门课程，返回 []。

官方样例 1

输入numCourses = 2prerequisites = [[1,0]]
输出[0,1]

官方样例 2

输入numCourses = 4prerequisites = [[1,0],[2,0],[3,1],[3,2]]
输出[0,1,2,3]

约束：1 ≤ numCourses ≤ 2000，0 ≤ prerequisites.length ≤ numCourses × (numCourses − 1)；每一对课程互不相同。

交互：入度归零，才能进入队列

示例边：0 → 1、0 → 2、1 → 3、2 → 3。每弹出一门课，就减少其后继的入度。

题解：Kahn 拓扑排序

核心洞察

一门课程的入度表示尚未满足的先修数。入度为 0 的课程现在就可以学习；学习它会使所有后继的入度减一。不断重复这个过程。

过程

  1. 建立 pre → course 邻接表，并统计每门课入度。
  2. 所有入度为 0 的课入队。
  3. 出队并写入答案；遍历后继，入度减一。
  4. 后继入度降到 0 时入队。
  5. 答案长度等于课程数才有可行序，否则图中有环。

边界与复杂度

没有先修：所有课初始入队。

孤立课程：也会被安排进结果。

环：环内课程永远无法入度归零，结果长度不足。

复杂度：时间 O(V+E)，空间 O(V+E)。

替代方案

DFS 三色标记同样可检测环并在回溯时生成逆拓扑序；Kahn 的队列过程更直观，且避免深递归栈风险。

常见错误：把 [a,b] 建成 a → b（方向反了）；或只返回已处理的一部分，却没有检查长度是否等于 numCourses。

面试追问

如何判断顺序唯一？每次队列里恰好只有一个可选节点。如何输出字典序最小顺序？把普通队列替换为最小堆。

import java.util.*;

class Solution {
  public int[] findOrder(int n, int[][] pre) {
    List<List<Integer>> g = new ArrayList<>();
    int[] in = new int[n], ans = new int[n];
    for (int i = 0; i < n; i++) g.add(new ArrayList<>());
    for (int[] p : pre) { g.get(p[1]).add(p[0]); in[p[0]]++; }
    Queue<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (in[i] == 0) q.offer(i);
    int k = 0;
    while (!q.isEmpty()) { int u = q.poll(); ans[k++] = u; for (int v : g.get(u)) if (--in[v] == 0) q.offer(v); }
    return k == n ? ans : new int[0];
  }
}

  const queue = []; for (let i = 0; i < n; i++) if (indegree[i] === 0) queue.push(i);

from typing import List
from collections import deque

class Solution:
    def findOrder(self, n: int, prerequisites: List[List[int]]) -> List[int]:
        graph = [[] for _ in range(n)]
        indegree = [0] * n
        for course, before in prerequisites:
            graph[before].append(course)
            indegree[course] += 1
        queue = deque(i for i in range(n) if indegree[i] == 0)
        answer = []
        while queue:
            u = queue.popleft(); answer.append(u)
            for v in graph[u]:
                indegree[v] -= 1
                if indegree[v] == 0: queue.append(v)
        return answer if len(answer) == n else []
