题意

答案保证在 32 位有符号整数范围内

给定二叉树根节点 root，返回这棵树所有层中的最大宽度。

一层的宽度，是该层最左与最右两个非空节点之间覆盖的完整槽位数。把树想象成嵌在一棵完整二叉树中：两个端点之间即使存在 null 空位，也必须计入宽度。

约束

  • 树中节点数量在 [1, 3000] 内。
  • -100 <= Node.val <= 100。
  • 最终答案处于 32 位有符号整数范围内。

输出7

示例 3

Solution

准备好再看题解

先问自己：怎样只保存真实节点，却仍能计算它们在完整二叉树中的距离？

Breadth-first indexing

完整二叉树编号 + 按层 BFS

每层归一化，抑制编号增长

核心洞察

给完整二叉树中的节点编号：父节点位置为 i 时，左右孩子位置分别为 2i 与 2i+1。同一层的宽度就是 最右位置 - 最左位置 + 1，中间缺失的节点会自然包含在差值中。

编号安全

绝对编号会随深度指数增长。处理每层时，先减去这一层首节点的位置，让本层从 0 开始，再生成下一层编号；这不改变同层任意两个位置的差。

完整过程

  1. 初始化队列。 放入根节点与位置 0，答案初始化为 0。
  2. 锁定一层。 记录当前队列长度，并取队首位置作为这一层的偏移基准。
  3. 逐个出队。 对每个位置减去基准，记下该层第一个与最后一个归一化位置。
  4. 加入孩子。 左孩子携带 2i，右孩子携带 2i+1；空孩子不入队。
  5. 更新答案。 用 last - first + 1 更新最大宽度，直到队列为空。

正确性证明

引理 1：按上述规则编号后，任何节点的编号都等于它在对应完整二叉树层中的槽位，因此同层两端编号之差加一正好包含两端及所有中间空位。

引理 2：整层统一减去同一个基准，不改变两节点的编号差，所以归一化后的宽度与原始宽度相同。

结论：BFS 恰好遍历每一层的全部非空节点，并计算该层真实宽度；对全部层取最大值，得到整棵树的最大宽度。

边界与复杂度

  • 单节点树：首尾位置相同，宽度为 1。
  • 单侧链：每层只有一个节点，宽度始终为 1。
  • 大量中间空位：由位置差自动计入，无需真的把 null 入队。
  • 时间复杂度 O(n)；空间复杂度 O(w)，其中 w 是队列中同时存在的最大节点数，最坏为 O(n)。

四语言完整代码

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    private static class Entry {
        TreeNode node;
        long index;

        Entry(TreeNode node, long index) {
            this.node = node;
            this.index = index;
        }
    }

    public int widthOfBinaryTree(TreeNode root) {
        if (root == null) return 0;

        java.util.Queue<Entry> queue = new java.util.ArrayDeque<>();
        queue.offer(new Entry(root, 0L));
        long answer = 0L;

        while (!queue.isEmpty()) {
            int size = queue.size();
            long base = queue.peek().index;
            long first = 0L;
            long last = 0L;

            for (int i = 0; i < size; i++) {
                Entry current = queue.poll();
                long index = current.index - base;
                if (i == 0) first = index;
                if (i == size - 1) last = index;

                if (current.node.left != null) {
                    queue.offer(new Entry(current.node.left, index * 2));
                }
                if (current.node.right != null) {
                    queue.offer(new Entry(current.node.right, index * 2 + 1));
                }
            }
            answer = Math.max(answer, last - first + 1);
        }

        return (int) answer;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var widthOfBinaryTree = function(root) {
    if (root === null) return 0;

    let queue = [[root, 0]];
    let answer = 0;

    while (queue.length > 0) {
        const base = queue[0][1];
        const next = [];
        let first = 0;
        let last = 0;

        for (let i = 0; i < queue.length; i++) {
            const [node, rawIndex] = queue[i];
            const index = rawIndex - base;
            if (i === 0) first = index;
            if (i === queue.length - 1) last = index;

            if (node.left !== null) {
                next.push([node.left, index * 2]);
            }
            if (node.right !== null) {
                next.push([node.right, index * 2 + 1]);
            }
        }

        answer = Math.max(answer, last - first + 1);
        queue = next;
    }

    return answer;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional


class Solution:
    def widthOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0

        queue = deque([(root, 0)])
        answer = 0

        while queue:
            level_size = len(queue)
            base = queue[0][1]
            first = last = 0

            for i in range(level_size):
                node, raw_index = queue.popleft()
                index = raw_index - base
                if i == 0:
                    first = index
                if i == level_size - 1:
                    last = index

                if node.left is not None:
                    queue.append((node.left, index * 2))
                if node.right is not None:
                    queue.append((node.right, index * 2 + 1))

            answer = max(answer, last - first + 1)

        return answer
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class Solution {
public:
    int widthOfBinaryTree(TreeNode* root) {
        if (root == nullptr) return 0;

        using ULL = unsigned long long;
        std::queue<std::pair<TreeNode*, ULL>> queue;
        queue.push({root, 0});
        ULL answer = 0;

        while (!queue.empty()) {
            int size = static_cast<int>(queue.size());
            ULL base = queue.front().second;
            ULL first = 0;
            ULL last = 0;

            for (int i = 0; i < size; ++i) {
                auto [node, rawIndex] = queue.front();
                queue.pop();
                ULL index = rawIndex - base;

                if (i == 0) first = index;
                if (i == size - 1) last = index;

                if (node->left != nullptr) {
                    queue.push({node->left, index * 2});
                }
                if (node->right != nullptr) {
                    queue.push({node->right, index * 2 + 1});
                }
            }
            answer = std::max(answer, last - first + 1);
        }

        return static_cast<int>(answer);
    }
};

替代方案：DFS

深度优先遍历也可携带位置编号，并为每个深度保存第一次遇到的最左编号。当前节点宽度为 index - leftmost[depth] + 1。时间同为 O(n)，额外空间主要是递归栈和每层首位置；极深树需注意递归栈溢出。

常见错误

  • 直接用本层非空节点数量当宽度，漏掉中间空位。
  • 使用不断翻倍的绝对编号，深树发生整数溢出。
  • 只记录相邻节点距离，没有使用最左与最右端点。
  • JavaScript 混用 Number 与 BigInt；本题在逐层归一化与答案范围保证下可统一使用 Number。

面试追问

  • 如何把 BFS 改为 DFS，并证明首次访问节点一定是该层最左节点？
  • 如果没有 32 位答案保证，四种语言分别怎样选择编号类型？
  • 为什么按层减去基准不会改变下一层的相对位置？
  • 队列空间由“逻辑宽度”还是“真实节点数”决定？

一句话记忆

空节点不用入队，但要让真实节点携带它们在完整二叉树中的位置；宽度藏在两端位置之差里。
