Solution

完整题解

核心洞察

把名字拆成“第一个字符”和“剩余字符”两段：第一段转大写，第二段转小写，再拼接。最后使用 ORDER BY user_id 固定输出顺序。

完整过程

  1. 用 LEFT(name, 1) 取得首字符，并用 UPPER 转成大写。
  2. 用 SUBSTRING(name, 2) 取得后缀，并用 LOWER 转成小写。
  3. 用 CONCAT 拼接两段，结果别名设为 name。
  4. 按 user_id 升序排序并返回。

复杂度

时间：O(S + n log n)

S 是所有名字的字符总数；若数据库可利用主键索引输出有序结果，排序代价可能降低。

额外空间：O(S)

用于结果字符串；数据库内部排序空间取决于执行计划。

正确性说明

对任意名字，首字符经 UPPER 处理，所以结果首字符一定大写；其余字符经 LOWER 处理，所以后缀一定小写。两段按原顺序拼接，不会遗漏或调换字符。因此每行名字都满足要求。最后的排序子句保证结果按用户编号升序返回。

边界情况

  • 单字符名字：后缀为空，结果仍正确。
  • 原本已规范：转换保持相同结果。
  • 全大写或全小写：两段分别规范化。
  • 输入顺序混乱：由 ORDER BY 纠正。
Official submit language

MySQL

SELECT
    user_id,
    CONCAT(
        UPPER(LEFT(name, 1)),
        LOWER(SUBSTRING(name, 2))
    ) AS name
FROM Users
ORDER BY user_id;

Java · 本地语义参考

import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.Locale;

public class FixNamesInATable {
    record User(int userId, String name) {}

    public static List<User> fixNames(List<User> users) {
        List<User> result = new ArrayList<>();
        for (User user : users) {
            String name = user.name();
            String fixed = name.substring(0, 1).toUpperCase(Locale.ROOT)
                    + name.substring(1).toLowerCase(Locale.ROOT);
            result.add(new User(user.userId(), fixed));
        }
        result.sort(Comparator.comparingInt(User::userId));
        return result;
    }

    public static void main(String[] args) {
        List<User> users = List.of(
                new User(1, "aLice"),
                new User(2, "bOB")
        );
        fixNames(users).forEach(System.out::println);
    }
}

JavaScript · 本地语义参考

function fixNames(users) {
  return users
    .map(({ user_id, name }) => ({
      user_id,
      name: name.slice(0, 1).toUpperCase()
        + name.slice(1).toLowerCase(),
    }))
    .sort((a, b) => a.user_id - b.user_id);
}

const users = [
  { user_id: 1, name: "aLice" },
  { user_id: 2, name: "bOB" },
];

console.log(fixNames(users));

Python · 本地语义参考

from typing import TypedDict


class User(TypedDict):
    user_id: int
    name: str


def fix_names(users: list[User]) -> list[User]:
    result: list[User] = []
    for user in users:
        name = user["name"]
        fixed = name[:1].upper() + name[1:].lower()
        result.append({"user_id": user["user_id"], "name": fixed})
    return sorted(result, key=lambda user: user["user_id"])


users: list[User] = [
    {"user_id": 1, "name": "aLice"},
    {"user_id": 2, "name": "bOB"},
]
print(fix_names(users))

C++ · 本地语义参考

#include <algorithm>
#include <cctype>
#include <iostream>
#include <string>
#include <vector>

struct User {
    int userId;
    std::string name;
};

std::vector<User> fixNames(std::vector<User> users) {
    for (User& user : users) {
        user.name[0] = static_cast<char>(
            std::toupper(static_cast<unsigned char>(user.name[0]))
        );
        for (std::size_t i = 1; i < user.name.size(); ++i) {
            user.name[i] = static_cast<char>(
                std::tolower(static_cast<unsigned char>(user.name[i]))
            );
        }
    }
    std::sort(users.begin(), users.end(),
              [](const User& a, const User& b) {
                  return a.userId < b.userId;
              });
    return users;
}

int main() {
    std::vector<User> users{{1, "aLice"}, {2, "bOB"}};
    for (const User& user : fixNames(users)) {
        std::cout << user.userId << " " << user.name << '\n';
    }
}

替代方案

INITCAP(name) 在部分数据库里能把单词首字母大写，但可能把分隔符后的多个单词都首字母大写，且并非所有方言一致支持。显式拆分首字符与后缀更贴合题意。

常见错误

  • 只大写首字母，却忘记把其余字符转小写。
  • 使用固定长度截取后缀，导致长名字被截断。
  • 遗漏 ORDER BY user_id。
  • 执行 UPDATE 修改原表，而题目要求返回查询结果。

面试追问

如果允许空字符串或 NULL？

说明当前约束未给出这种数据；扩展场景可用 CASE 并保留 NULL 语义。

如何处理 Unicode 名字？

需确认数据库字符集、排序规则与大小写函数的区域语义，不能假设 ASCII 行为。

排序为什么必须显式写？

关系表没有默认顺序；即使主键索引让结果看似有序，也不构成查询契约。
