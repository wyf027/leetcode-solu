设计食物评分系统

Design a Food Rating System

评分会变，冠军也会变。相同分数时，名字决定胜负。

01 / 题目契约

为每一种菜系找到最高分食物

实现 FoodRatings 类。三个等长数组给出初始数据：foods[i] 是食物名字，cuisines[i] 是它的菜系（烹饪方式），ratings[i] 是它的评分。系统支持修改现有食物的评分，并查询某一菜系的最高分食物。

修改评分

changeRating(food, newRating) 将 food 的分数替换为 newRating，无返回值。

查询冠军

highestRated(cuisine) 返回最高分食物名；并列时返回字典序最小的名字。

完整接口

FoodRatings(String[] foods, String[] cuisines, int[] ratings)
void changeRating(String food, int newRating)
String highestRated(String cuisine)

字典序从左到右比较字符，第一个不同字符较小的名字在前；若一个名字是另一个的前缀，则较短者在前，例如 a < aa。

约束

  • 1 ≤ n ≤ 2 × 10⁴，n = foods.length = cuisines.length = ratings.length。
  • foods[i] 和 cuisines[i] 的长度均为 1～10，且只含小写英文字母。
  • 1 ≤ ratings[i] ≤ 10⁸。
  • 所有食物名字互不相同。
  • changeRating 调用中的 food 保证是现有食物。
  • highestRated 调用中的 cuisine 保证至少有一种食物。
  • 两种方法的总调用次数最多为 2 × 10⁴。

官方元数据没有单独列出 newRating 的范围；评分范围按原字段 ratings[i] 保留。

04 / 独立题解

先想一想，再打开答案

怎样避免每次查询都遍历全部食物？展开后可查看逐步演示、正确性证明和四语言实现。

题解：按菜系分堆，延迟清理旧评分

核心洞察

用哈希表保存食物的菜系和当前评分；为每个菜系建立一个堆，按评分降序、名字升序排列。堆内保存不可变的评分快照。更新时修改当前表，再插入一条新快照，不必去堆中寻找旧记录。

查询时核对堆顶：快照评分与当前评分不同，就弹出并继续检查。遇到有效堆顶后返回名字。旧记录可以留在堆里，但不能冒充答案。

交互 / 评分快照工作台

当前表与历史堆，分开观察

堆按数组层序展示，父节点优先于子节点，同层不保证排序。绿色标记有效，红色标记过期。Tab 聚焦按钮，Enter / 空格操作。

减少动态效果偏好开启时禁用自动播放，可使用上一步和下一步。

当前评分表 · 唯一真实值

菜系堆 · 历史快照

完整过程

  1. 初始化：登记 food → {cuisine, rating}，把 {food, rating} 插入对应菜系堆。
  2. 更新：先修改映射中的当前评分，再插入新评分快照；旧条目保持不变。
  3. 查询：只访问目标菜系堆，循环弹出评分不匹配的堆顶。
  4. 返回：第一个有效堆顶的名字就是答案，不删除有效堆顶。

正确性证明

有效记录不丢失：初始化为每种食物放入当前记录；更新添加新的当前记录；查询只删除不匹配的记录。因此每种食物在其菜系堆中始终至少有一条匹配当前评分的记录。

有效堆顶必最优：堆比较规则为评分高者优先、同分名字小者优先。一个有效堆顶优先于所有堆内记录；每种食物的当前记录都在堆中，所以没有食物的当前状态能排在它前面。

查询会终止：每轮删除一个过期记录，记录数有限；目标菜系非空且保留有效记录，最终必遇到有效堆顶。

边界与常见错误

  • 同分必须按名字升序，不能按插入先后。前缀关系也要正确处理。
  • 不要原地修改堆中对象的分数：堆不会因此自动重排。映射状态与堆快照要分开。
  • 降分后旧高分可能仍在顶部；必须用 while 清理，不能只弹出一个。
  • 同分重复更新会产生重复有效记录，但答案仍正确。分数恢复后，旧快照重新匹配也无害；本题不需要版本号。
  • 不能弹出有效冠军，否则多次查询或单食物菜系会出错。
  • 不同菜系独立维护。JavaScript 对小写英文名使用 < 比较，不依赖区域化排序。

复杂度

设 n 为食物数，U 为更新次数，Q 为查询次数，M = n + U。名字长度最多 10，以下视比较为常数；哈希访问按平均 O(1) 计。

  • 四份代码均逐条入堆：初始化 O(n log n)。
  • 一次更新 O(log M)。
  • 查询清理 k 条记录时为 O(1 + k log M)；不清理时 O(1)，单次最坏可达 O(M log M)。
  • 过期记录最多被删除一次。全部操作总时间 O(n log n + U log M + Q)，空间 O(n + U)。清理成本可摊还到更新，不能声称每次查询都保证 O(log n)。
  • 若计入名称长度 L，排序比较部分再乘 O(L)。

替代方案

有序集合：每菜系保存 (-rating, food)，更新先删旧键、再插新键。Java TreeSet / C++ set 支持 O(log n) 更新、读取首元素，空间 O(n)。Python 与 JavaScript 标准库缺少同等有序集合，延迟清理堆容易统一实现。

直接扫描：按菜系记录食物，更新 O(1)，查询 O(m)，m 为该菜系食物数。适合查询很少的场景，最坏总查询时间 O(nQ)。

面试追问

  • 如何限制历史条目占用？堆大小超过当前食物数的固定倍数时，用当前记录重建并 heapify；也可以改用有序集合。
  • 前 K 名怎么查？需要按食物去重，临时弹出有效记录后恢复；有序集合可直接遍历。
  • 如果食物能改菜系？有效性检查还需比较当前菜系，或使用版本号，仅比较分数不够。
  • 如果并发更新？当前表更新与新记录入堆需要同步，避免查询读到没有对应有效记录的中间状态。

import java.util.*;

class FoodRatings {
    private static class Entry {
        final String food;
        final int rating;
        Entry(String food, int rating) {
            this.food = food;
            this.rating = rating;
        }
    }
    private final Map<String, String> cuisineOf = new HashMap<>();
    private final Map<String, Integer> current = new HashMap<>();
    private final Map<String, PriorityQueue<Entry>> heaps = new HashMap<>();

    public FoodRatings(String[] foods, String[] cuisines, int[] ratings) {
        Comparator<Entry> order = (a, b) -> {
            int cmp = Integer.compare(b.rating, a.rating);
            return cmp != 0 ? cmp : a.food.compareTo(b.food);
        };
        for (int i = 0; i < foods.length; i++) {
            cuisineOf.put(foods[i], cuisines[i]);
            current.put(foods[i], ratings[i]);
            heaps.computeIfAbsent(cuisines[i], k -> new PriorityQueue<>(order))
                 .offer(new Entry(foods[i], ratings[i]));
        }
    }
    public void changeRating(String food, int newRating) {
        current.put(food, newRating);
        heaps.get(cuisineOf.get(food)).offer(new Entry(food, newRating));
    }
    public String highestRated(String cuisine) {
        PriorityQueue<Entry> heap = heaps.get(cuisine);
        while (heap.peek().rating != current.get(heap.peek().food)) heap.poll();
        return heap.peek().food;
    }
}

JavaScript

自带二叉堆，不依赖平台优先队列库。

class Heap {
  constructor() { this.a = []; }
  better(x, y) {
    return x.rating > y.rating ||
      (x.rating === y.rating && x.food < y.food);
  }
  push(x) {
    const a = this.a;
    a.push(x);
    let i = a.length - 1;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (!this.better(a[i], a[p])) break;
      [a[i], a[p]] = [a[p], a[i]];
      i = p;
    }
  }
  pop() {
    const a = this.a, top = a[0], last = a.pop();
    if (a.length) {
      a[0] = last;
      let i = 0;
      while (true) {
        let best = i, l = 2 * i + 1, r = l + 1;
        if (l < a.length && this.better(a[l], a[best])) best = l;
        if (r < a.length && this.better(a[r], a[best])) best = r;
        if (best === i) break;
        [a[i], a[best]] = [a[best], a[i]];
        i = best;
      }
    }
    return top;
  }
  peek() { return this.a[0]; }
}
class FoodRatings {
  constructor(foods, cuisines, ratings) {
    this.current = new Map();
    this.heaps = new Map();
    for (let i = 0; i < foods.length; i++) {
      const food = foods[i], cuisine = cuisines[i], rating = ratings[i];
      this.current.set(food, { cuisine, rating });
      if (!this.heaps.has(cuisine)) this.heaps.set(cuisine, new Heap());
      this.heaps.get(cuisine).push({ food, rating });
    }
  }
  changeRating(food, newRating) {
    const info = this.current.get(food);
    info.rating = newRating;
    this.heaps.get(info.cuisine).push({ food, rating: newRating });
  }
  highestRated(cuisine) {
    const heap = this.heaps.get(cuisine);
    while (heap.peek().rating !== this.current.get(heap.peek().food).rating) {
      heap.pop();
    }
    return heap.peek().food;
  }
}

Python 3

from typing import List
from collections import defaultdict
import heapq

class FoodRatings:
    def __init__(self, foods: List[str], cuisines: List[str], ratings: List[int]):
        self.cuisine_of = {}
        self.current = {}
        self.heaps = defaultdict(list)
        for food, cuisine, rating in zip(foods, cuisines, ratings):
            self.cuisine_of[food] = cuisine
            self.current[food] = rating
            heapq.heappush(self.heaps[cuisine], (-rating, food))

    def changeRating(self, food: str, newRating: int) -> None:
        self.current[food] = newRating
        heapq.heappush(self.heaps[self.cuisine_of[food]], (-newRating, food))

    def highestRated(self, cuisine: str) -> str:
        heap = self.heaps[cuisine]
        while -heap[0][0] != self.current[heap[0][1]]:
            heapq.heappop(heap)
        return heap[0][1]

C++

#include <string>
#include <vector>
#include <queue>
#include <unordered_map>
using namespace std;

class FoodRatings {
    struct Entry { int rating; string food; };
    struct Worse {
        bool operator()(const Entry& a, const Entry& b) const {
            if (a.rating != b.rating) return a.rating < b.rating;
            return a.food > b.food;
        }
    };
    unordered_map<string, string> cuisineOf;
    unordered_map<string, int> current;
    unordered_map<string, priority_queue<Entry, vector<Entry>, Worse>> heaps;
public:
    FoodRatings(vector<string>& foods, vector<string>& cuisines, vector<int>& ratings) {
        for (int i = 0; i < (int)foods.size(); ++i) {
            cuisineOf[foods[i]] = cuisines[i];
            current[foods[i]] = ratings[i];
            heaps[cuisines[i]].push({ratings[i], foods[i]});
        }
    }
    void changeRating(string food, int newRating) {
        current[food] = newRating;
        heaps[cuisineOf[food]].push({newRating, food});
    }
    string highestRated(string cuisine) {
        auto& heap = heaps[cuisine];
        while (heap.top().rating != current[heap.top().food]) heap.pop();
        return heap.top().food;
    }
};
