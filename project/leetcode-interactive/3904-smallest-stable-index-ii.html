3904. 最小稳定下标 II

Medium · 数组

题意

找第一个“不稳定值”不超过 k 的位置

给定 nums 和 k。下标 i 的不稳定值为前缀最大值减去后缀最小值：max(nums[0..i]) - min(nums[i..n-1])。返回最小的稳定下标（不稳定值 ≤ k），没有则返回 -1。

长度

1 ≤ n ≤ 10⁵

元素

0 ≤ nums[i] ≤ 10⁹

阈值

0 ≤ k ≤ 10⁹

示例

  1. 示例 1
    nums = [5, 0, 1, 4], k = 3
    输出：3。在下标 3 时，5 − 4 = 1。
  2. 示例 2
    nums = [3, 2, 1], k = 1
    输出：-1。每个位置都是 3 − 1 = 2。
  3. 示例 3
    nums = [0], k = 0
    输出：0。

底部题解区域

先自己观察，再打开讲解

核心洞察

每个位置需要的两项信息互相独立：左边只需要“截至 i 的最大值”，右边只需要“从 i 开始的最小值”。把所有后缀最小值预处理进数组，再线性扫描即可在第一次满足时立即返回。

  1. 从右到左计算 suffixMin[i]。
  2. 从左到右更新 prefixMax。
  3. 若 prefixMax - suffixMin[i] ≤ k，返回 i。

边界与复杂度

  • 单元素：前、后缀都等于该元素，答案一定是 0。
  • 无解：扫描完仍未命中，返回 -1。
  • 数值：nums[i] 和 k 最多 10⁹，差值用 64 位整数更稳妥（Java/C++ 的 long）。
  • 时间：O(n)；空间：O(n)。

替代方案：用前缀最大数组和后缀最小数组同样是 O(n)，但维护一个前缀最大值可节省一半辅助空间。面试可追问：若允许原数组覆写，如何复用空间？

常见错误

  • 后缀最小值写成从 i + 1 开始，漏掉当前元素。
  • 用 < k，忘了题目允许等于 k。
  • 先找到任意稳定下标却继续覆盖答案，失去“最小”的保证。
