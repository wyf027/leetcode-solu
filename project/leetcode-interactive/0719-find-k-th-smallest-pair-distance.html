找出第 K 小的数对距离

Find K-th Smallest Pair Distance

困难 数组 排序 二分查找 双指针

在所有下标不同的数对里，我们不需要真的生成并排序每一个距离。先观察问题、再操作下方实验台；完整解法被刻意收在页面底部。

首屏无题解剧透 · 先建立直觉
01 / PROBLEM

题意与边界

整数 a 与 b 的数对距离是 |a - b|。给定整数数组 nums 和整数 k，考虑所有满足 0 ≤ i < j < nums.length 的数对 (nums[i], nums[j])，返回这些距离按非递减顺序排列后的第 k 个值。

官方函数形式

smallestDistancePair(nums: integer[], k: integer) → integer

注意：相同数值位于不同下标时仍构成合法数对，因此距离 0 可能出现多次。

约束

  • n == nums.length
  • 2 ≤ n ≤ 104
  • 0 ≤ nums[i] ≤ 106
  • 1 ≤ k ≤ n × (n - 1) / 2

规模提示：数对总数最多约五千万，直接枚举的代价需要谨慎评估。

示例 1

输入：nums = [1,3,1], k = 1 输出：0

三个距离为 2、0、2，第 1 小是 0。

示例 2

输入：nums = [1,1,1], k = 2 输出：0

三个数对的距离都为 0，第 2 小仍是 0。

示例 3

输入：nums = [1,6,1], k = 3 输出：5

距离为 5、0、5，第 3 小是 5。

03 / SOLUTION VAULT

准备好揭晓机制了吗？

下面包含完整思路、证明、四种语言代码与面试追问。展开前，建议先用实验台走完一次阈值变化。

SOLUTION / REVEALED

值域二分 + 双指针计数

Core insight A

二分的不是下标，而是答案

答案一定落在 [0, max(nums) - min(nums)]。对一个阈值 d，定义 count(d) 为距离不超过 d 的数对个数。随着 d 增大，count(d) 单调不减，因此可以寻找第一个满足 count(d) ≥ k 的 d。

Core insight B

排序让计数变成滑动窗口

排序后固定右端点 right，不断右移 left，直到 nums[right] - nums[left] ≤ d。此时从 left 到 right - 1 都能与 right 配对，一次贡献 right - left 个数对。

排序并确定答案边界

将 nums 升序排序。最小距离下界为 lo = 0，最大距离上界为 hi = nums[n - 1] - nums[0]。

试探中点距离

当 lo < hi 时，令 mid = lo + floor((hi - lo) / 2)，统计所有距离不超过 mid 的数对数量。

用双指针线性计数

right 从左到右移动；若窗口两端差值超过 mid，就右移 left。每个右端点贡献 right - left，整个计数过程为 O(n)。

保留满足条件的最小阈值

若计数 ≥ k，说明第 k 小距离不超过 mid，令 hi = mid；否则令 lo = mid + 1。最终 lo == hi 即答案。

正确性证明

引理 1：对任意阈值 d，双指针计数恰好得到距离不超过 d 的数对数。固定 right 后，算法找到最小的合法 left；因数组有序，区间内每个更靠右的左端点都合法，而区间外的都不合法，所以贡献恰为 right - left。

引理 2：count(d) 关于 d 单调不减。因为阈值增大只会纳入更多数对，不会排除已有数对。

定理：二分始终保留“第一个使 count(d) ≥ k 的距离”。计数足够时收缩右界，计数不足时排除 mid 及其左侧。终止时区间只剩一个值，它正是第 k 小距离。

复杂度与边界

时间 O(n log n + n log W) · 空间 O(log n) 或 O(1)*

其中 W = max(nums) - min(nums) ≤ 106。额外空间取决于语言排序实现。

  • 重复元素：自然产生距离 0。
  • k = 1：寻找全局最小距离。
  • k 为总数对数：答案是最大差值。
  • 所有元素相同：搜索上界为 0，直接返回。
  • 计数最多约 n(n-1)/2；Java 使用 long 更稳妥。

四种语言完整代码

Solution.java官方签名
import java.util.Arrays;

class Solution {
    public int smallestDistancePair(int[] nums, int k) {
        Arrays.sort(nums);
        int lo = 0;
        int hi = nums[nums.length - 1] - nums[0];

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (countPairs(nums, mid) >= k) {
                hi = mid;
            } else {
                lo = mid + 1;
            }
        }
        return lo;
    }

    private long countPairs(int[] nums, int limit) {
        long count = 0;
        int left = 0;
        for (int right = 0; right < nums.length; right++) {
            while (nums[right] - nums[left] > limit) {
                left++;
            }
            count += right - left;
        }
        return count;
    }
}

var smallestDistancePair = function(nums, k) {
    nums.sort((a, b) => a - b);
    let lo = 0;
    let hi = nums[nums.length - 1] - nums[0];

    const countPairs = (limit) => {
        let count = 0;
        let left = 0;
        for (let right = 0; right < nums.length; right++) {
            while (nums[right] - nums[left] > limit) {
                left++;
            }
            count += right - left;
        }
        return count;
    };

    while (lo < hi) {
        const mid = lo + Math.floor((hi - lo) / 2);
        if (countPairs(mid) >= k) hi = mid;
        else lo = mid + 1;
    }
    return lo;
};

from typing import List

class Solution:
    def smallestDistancePair(self, nums: List[int], k: int) -> int:
        nums.sort()
        lo, hi = 0, nums[-1] - nums[0]

        def count_pairs(limit: int) -> int:
            count = 0
            left = 0
            for right in range(len(nums)):
                while nums[right] - nums[left] > limit:
                    left += 1
                count += right - left
            return count

        while lo < hi:
            mid = lo + (hi - lo) // 2
            if count_pairs(mid) >= k:
                hi = mid
            else:
                lo = mid + 1
        return lo

class Solution {
public:
    int smallestDistancePair(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        int lo = 0;
        int hi = nums.back() - nums.front();

        auto countPairs = [&](int limit) {
            long long count = 0;
            int left = 0;
            for (int right = 0; right < nums.size(); ++right) {
                while (nums[right] - nums[left] > limit) {
                    ++left;
                }
                count += right - left;
            }
            return count;
        };

        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (countPairs(mid) >= k) hi = mid;
            else lo = mid + 1;
        }
        return lo;
    }
};

替代方案

枚举所有距离后排序：需要 O(n²) 个距离和 O(n² log n) 排序时间，n = 10⁴ 时不可取。

最小堆逐个弹出：可把每一行有序差值视作序列，但实现更复杂，且当 k 很大时成本接近 O(k log n)。值域二分更贴合本题 W ≤ 10⁶ 的约束。

面试追问

为什么是 lower bound？因为要找最小的可行距离，即第一个让累计数对数达到 k 的阈值。

能否提前停止计数？可以；计数一旦达到 k 即可返回，有时能减少常数，但不改变渐进复杂度。

若数值范围极大？log W 仍通常很小；同时要防止计算差值和中点时溢出。

常见错误

把二分写成“找到任意 count(mid) == k”——计数可能跨越 k，目标应是首个 count(mid) ≥ k 的阈值。

每次二分都重新排序，或为每个右端点重置并向左暴力扫描，会分别浪费排序成本或退化到 O(n² log W)。

实现细节

双指针中的 left 只向右移动，不必随 right 重置。二分更新使用 hi = mid 与 lo = mid + 1，匹配闭区间 lower-bound 模板。

JavaScript 的本题计数上限远小于安全整数上限；Java / C++ 示例仍使用更宽的计数类型，便于迁移到更大约束。
