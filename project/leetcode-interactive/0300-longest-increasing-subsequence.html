Solution / O(n log n)

贪心尾部 + 二分查找

核心题解

核心洞察

对相同长度的递增子序列，结尾越小，后面越容易接入新数字。维护数组 tails： tails[i] 表示“长度为 i + 1 的递增子序列，目前能得到的最小结尾”。 tails 始终严格递增，因此可以二分定位。

位置 p = tails 中第一个满足 tails[p] ≥ x 的下标（lower_bound）

完整过程

  1. 初始化空数组 tails。
  2. 从左到右读取每个数字 x，在 tails 中二分查找第一个大于等于 x 的位置 p。
  3. 若 p == tails.length，说明 x 大于所有尾部，把它追加到末尾，最长长度增加 1。
  4. 否则令 tails[p] = x，用更小或相等的结尾提升未来延伸机会，但当前最长长度不变。
  5. 扫描结束后，tails.length 就是最长严格递增子序列的长度。

注意：tails 通常不是某一条真实的最长递增子序列；它压缩保存的是不同长度下的最优尾部。

正确性说明

使用归纳不变式：处理完任意前缀后，对每个合法下标 i，tails[i] 都是该前缀中所有长度为 i + 1 的严格递增子序列的最小结尾。

  • 初始：前缀为空，tails 为空，不变式成立。
  • 保持：读入 x 时，二分得到第一个 tails[p] ≥ x 的位置。 若存在前一位，则 tails[p - 1] < x，所以能用 x 构成长度 p + 1 的递增子序列；把该位置替换为 x 后，它仍是此长度可达到的最小结尾。其他长度的最小结尾不受影响。
  • 终止：tails 的每个位置都对应一个可实现的递增长度，且只有发现更长序列时才会扩容。 因此最终长度既不会高估也不会低估答案。

边界处理

  • 单个元素：首次读取时追加，答案为 1。
  • 全部相等：每次都替换位置 0；“严格递增”不允许相等值扩容。
  • 严格递减：每次都刷新最小结尾，tails 长度始终为 1。
  • 严格递增：每个数字都追加，答案等于数组长度。
  • 负数无需特殊处理，比较关系与正数完全一致。

复杂度

每个数字执行一次二分查找，时间复杂度为 O(n log n)；tails 最长保存 n 个元素，空间复杂度为 O(n)。

替代方案：动态规划

定义 dp[i] 为“必须以 nums[i] 结尾”的最长递增子序列长度。 枚举所有 j < i，若 nums[j] < nums[i]，则用 dp[j] + 1 更新 dp[i]。它直观且容易恢复路径，但时间复杂度为 O(n²)，在本题上不满足进阶目标。

面试追问

  • 如何恢复一条实际 LIS？ 同时记录每个元素放入的层级、该层级的前驱下标和各层最新下标，最后从最高层回溯。
  • 若改成非递减子序列？ 把 lower_bound 改为 upper_bound，即寻找第一个严格大于 x 的位置。
  • 能否原地复用输入数组？ 可以把 nums 的前缀作为 tails 存储区，将额外空间降为 O(1)，但会修改输入。
  • 为什么贪心不会丢失答案？ 替换只让同一长度的结尾更小，不会抹去该长度的可达性，也不会阻碍未来扩展。

常见错误

  • 用“第一个大于 x”的位置处理严格递增，导致重复值被错误扩容。
  • 把 tails 直接当作真实 LIS 输出；本题只要求长度，恢复路径需要额外前驱信息。
  • 二分区间边界混用闭区间和左闭右开区间，造成死循环或越界。
  • 误把子序列当成连续子数组，只检查相邻元素。
  • 在 O(n²) DP 中返回 dp[n - 1]，而不是所有 dp[i] 的最大值。

class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;

        for (int x : nums) {
            int left = 0;
            int right = size;

            while (left < right) {
                int mid = left + (right - left) / 2;
                if (tails[mid] < x) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }

            tails[left] = x;
            if (left == size) {
                size++;
            }
        }

        return size;
    }
}

    const tails = [];

    for (const x of nums) {
        let left = 0;
        let right = tails.length;

        while (left < right) {
            const mid = left + Math.floor((right - left) / 2);
            if (tails[mid] < x) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }

        tails[left] = x;
    }

    return tails.length;
};
from bisect import bisect_left
from typing import List


class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        tails: List[int] = []

        for x in nums:
            position = bisect_left(tails, x)
            if position == len(tails):
                tails.append(x)
            else:
                tails[position] = x

        return len(tails)
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        vector<int> tails;

        for (int x : nums) {
            auto position = lower_bound(tails.begin(), tails.end(), x);
            if (position == tails.end()) {
                tails.push_back(x);
            } else {
                *position = x;
            }
        }

        return static_cast<int>(tails.size());
    }
};
