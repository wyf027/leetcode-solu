O(1) 时间插入、删除和获取随机元素

用一个可随机下标访问的数组保存元素，再用哈希表反查元素的位置。删除时把末尾元素搬到空位，避免数组中间移位。

Reasoning / 为什么这样设计

把三个 O(1) 需求拆开，再拼回一个结构

数组负责随机

数组支持按下标读取。随机生成 0..n-1 的下标，返回对应元素，每个元素的概率都是 1/n。

哈希表负责定位

删除前先用 indexOf[val] 找到位置；它也让重复插入能立刻返回 false。

交换末尾避免移位

不能调用数组中间删除，因为那会移动 O(n) 个元素。末尾覆盖目标位置后 pop，代价固定。

删除流程

  1. 若哈希表没有 value，返回 false。
  2. 读取其下标 i 和数组末尾值 last。
  3. 令 values[i] = last，并令 indexOf[last] = i。
  4. 删除数组末尾与 indexOf[value]，返回 true。

边界与易错点

  • 删除的就是末尾时，覆盖动作可以照常执行。
  • 必须在删除 last 的映射前更新它的新下标。
  • 集合为空时不能调用 getRandom；题目保证调用合法。
  • 哈希表平均 O(1)，最坏冲突情形不作为本题复杂度目标。

import java.util.*;

class RandomizedSet {
    private final List<Integer> values = new ArrayList<>();
    private final Map<Integer, Integer> indexOf = new HashMap<>();
    private final Random random = new Random();

    public RandomizedSet() {}

    public boolean insert(int val) {
        if (indexOf.containsKey(val)) return false;
        indexOf.put(val, values.size());
        values.add(val);
        return true;
    }

    public boolean remove(int val) {
        Integer index = indexOf.get(val);
        if (index == null) return false;
        int last = values.get(values.size() - 1);
        values.set(index, last);
        indexOf.put(last, index);
        values.remove(values.size() - 1);
        indexOf.remove(val);
        return true;
    }

    public int getRandom() {
        return values.get(random.nextInt(values.size()));
    }
}
var RandomizedSet = function () {
  this.values = [];
  this.indexOf = new Map();
};

RandomizedSet.prototype.insert = function (val) {
  if (this.indexOf.has(val)) return false;
  this.indexOf.set(val, this.values.length);
  this.values.push(val);
  return true;
};

RandomizedSet.prototype.remove = function (val) {
  if (!this.indexOf.has(val)) return false;
  const index = this.indexOf.get(val);
  const last = this.values[this.values.length - 1];
  this.values[index] = last;
  this.indexOf.set(last, index);
  this.values.pop();
  this.indexOf.delete(val);
  return true;
};

RandomizedSet.prototype.getRandom = function () {
  return this.values[Math.floor(Math.random() * this.values.length)];
};
import random

class RandomizedSet:
    def __init__(self):
        self.values = []
        self.index_of = {}

    def insert(self, val: int) -> bool:
        if val in self.index_of:
            return False
        self.index_of[val] = len(self.values)
        self.values.append(val)
        return True

    def remove(self, val: int) -> bool:
        if val not in self.index_of:
            return False
        index = self.index_of[val]
        last = self.values[-1]
        self.values[index] = last
        self.index_of[last] = index
        self.values.pop()
        del self.index_of[val]
        return True

    def getRandom(self) -> int:
        return random.choice(self.values)
#include <vector>
#include <unordered_map>
#include <cstdlib>
using namespace std;

class RandomizedSet {
    vector<int> values;
    unordered_map<int, int> indexOf;
public:
    RandomizedSet() {}
    bool insert(int val) {
        if (indexOf.count(val)) return false;
        indexOf[val] = values.size();
        values.push_back(val);
        return true;
    }
    bool remove(int val) {
        if (!indexOf.count(val)) return false;
        int index = indexOf[val], last = values.back();
        values[index] = last;
        indexOf[last] = index;
        values.pop_back();
        indexOf.erase(val);
        return true;
    }
    int getRandom() { return values[rand() % values.size()]; }
};

复杂度：insert、remove、getRandom 都是平均 O(1) 时间；数组与哈希表各保存一份索引信息，总空间 O(n)。
