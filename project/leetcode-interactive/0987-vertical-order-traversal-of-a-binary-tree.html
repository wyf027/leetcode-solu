二叉树深度优先搜索哈希表排序

题目

根结点位于 (0, 0)。若某结点位于 (row, col)，它的左、右孩子分别位于 (row + 1, col - 1) 与 (row + 1, col + 1)。

请从最左列到最右列输出每列结点；同列时由上到下，同一行且同一列时按结点值升序。

函数形式： verticalTraversal(root: TreeNode) → List<List<Integer>>

示例 1

输入root = [3,9,20,null,null,15,7]输出[[9],[3,15],[20],[7]]说明列 -1 到 2 依次收集；结点 3 与 15 同列但行不同。

示例 2

输入root = [1,2,3,4,5,6,7]输出[[4],[2],[1,5,6],[3],[7]]说明5 与 6 同处 (2,0)，因此按值升序。

示例 3

输入root = [1,2,3,4,6,5,7]输出[[4],[2],[1,5,6],[3],[7]]说明即使树中 5、6 交换位置，它们坐标相同，最终仍按值排序。

约束

  • 树中结点数在 [1, 1000] 内。
  • 0 <= Node.val <= 1000。

题解：坐标化 + 全局排序

核心洞察

题目的三条先后规则恰好组成字典序键：(col, row, val)。遍历方式只负责采集所有结点及坐标，真正的输出次序交给一次排序。

完整过程

标记坐标
从根的 (0,0) 出发，递归到左孩子时 row+1、col-1；右孩子 row+1、col+1。
收集三元组
为每个结点保存 (col,row,val)，DFS 或 BFS 都可以。
字典序排序
先比较 col，再比较 row，最后比较 val。
按列归并
顺序扫描已排序数组；col 改变时新建一列，否则追加到当前列。

正确性证明

引理 1：坐标递推准确记录每个结点相对根的位置，因为每条根到结点的唯一路径逐边应用题目给定的坐标变化。

引理 2：按 (col,row,val) 升序后，所有较小列必在较大列之前；同列中较小行在前；同行同列中较小值在前，完全对应题意。

结论：扫描排序结果并按 col 分组，得到的每一列及列之间顺序都满足垂序遍历定义，因此算法正确。

复杂度

  • 时间：O(n log n)，排序占主导。
  • 空间：O(n)，保存三元组与答案；递归栈最坏 O(n)。

边界

  • 只有根结点。
  • 完全向左或向右的链。
  • 多个结点同行同列且值重复。
  • 最多 1000 个结点的深树。

替代方案

可以用嵌套映射 col → row → 最小堆 边遍历边分桶，最后按列、行依次取值。它更贴近定义，但数据结构与实现更复杂；在本题规模下，全局排序更清楚稳健。

面试追问

  • 若同行同列不按值排序，而按 BFS 到达顺序，应如何改？
  • 如何消除递归导致的最坏 O(n) 调用栈？
  • 为何仅按列分桶后保持 DFS 顺序会出错？

常见错误

  • 排序键写成 (row,col,val)，导致先按层而非按列输出。
  • 只按 (col,row) 排序，遗漏同行同列的值规则。
  • 把“垂序遍历”误认为普通 BFS 分列，依赖了不可靠的访问顺序。
