划分技能点相等的团队

Divide Players Into Teams of Equal Skill

每队两人，技能总和相等。你能把每位玩家都安排进团队吗？

先理解题目，再展开底部题解探索过程。页面可离线打开。

01 / 题目

给定正整数数组 skill，长度 n 为偶数。每个元素表示一位玩家的技能点。请把所有玩家恰好分入 n / 2 个双人团队，要求每队的技能点之和相同。

一支团队的「化学反应」是两位玩家技能点的乘积。若存在符合要求的划分，返回所有团队化学反应的总和；若无法划分，返回 -1。

参数与返回值

dividePlayers(skill: integer[]) → long

约束

  • 2 ≤ skill.length ≤ 100000
  • skill.length 是偶数。
  • 1 ≤ skill[i] ≤ 1000

02 / 官方示例

示例 1

输入：skill = [3,2,5,1,3,4]
输出：22

可组成 (1,5)、(2,4)、(3,3)，每队总和为 6。化学反应之和为 5 + 8 + 9 = 22。

示例 2

输入：skill = [3,4]
输出：12

只有一个团队，总技能为 7，化学反应为 3 × 4 = 12。

示例 3

输入：skill = [1,1,2,3]
输出：-1

不存在让所有双人团队技能总和相同的划分。

04 / 独立题解

准备好后展开：包含交互配对台、证明和四语言代码。

排序后，从两端向中间配对

核心洞察

最小技能必须与最大技能配对。设最小值为 m、最大值为 M、每队总和为 T：最小值的搭档不超过 M，所以 T ≤ m + M；最大值的搭档不小于 m，所以 T ≥ m + M。因此 T = m + M。

完整过程

  1. 将数组升序排序，设置目标总和 T = skill[0] + skill[n-1]。
  2. 左右指针从两端出发，检查两人的技能和。
  3. 若不等于 T，立即返回 -1；否则把两人的乘积计入答案。
  4. 左右指针各向内移动一格，直到所有玩家被使用，返回累计值。

正确性证明

必要性：任何可行划分的目标和都等于当前最小值与最大值之和。若二者原先分别与其他同值搭档配对，可以交换同技能玩家，使这两个极值配为一队而不影响其他团队。

归纳：去掉极值组成的团队后，剩余玩家仍须按同一 T 配对。重复应用极值结论，排序后的每对首尾元素都必须满足该目标。如果某对不满足，则不存在可行划分。

充分性：所有检查均满足 T 时，指针遍历让每位玩家恰好参加一次，所有团队人数为二且总技能相等。每个乘积只累计一次，所以返回值正是所需总和。

边界与数值安全

  • 只有两位玩家时，一定能组成唯一团队。
  • 允许重复技能值；相同数值仍代表不同玩家。
  • 总技能能被团队数整除只是必要条件。例如 [1,1,1,3] 的目标平均为 3，但无法配对。
  • 最大答案是 50000 × 1000² = 5 × 10¹⁰。Java 使用 long，C++ 使用 long long；JavaScript Number 在此范围可精确表示整数，Python 整数自动扩展。

复杂度

排序 O(n log n)，双指针 O(n)，总时间 O(n log n)。扫描额外空间 O(1)。完整实现的排序空间依语言库：Python 的 sorted 副本与排序共 O(n)，C++ std::sort 通常使用 O(log n) 栈；Java、JavaScript 应计入运行时排序实现的空间，不统一宣称 O(1)。Java、JavaScript、C++ 版本会原地修改输入顺序。

替代方案：频次统计

技能值仅在 1–1000，可用大小为 1001 的频次数组。先计算 T = 总技能 / (n/2)，非整数时返回 -1。每取走一个值 x，就消耗一个 T−x；补数越界或不存在时失败。x = T−x 时必须有两名玩家。时间 O(n + U)，空间 O(U)，其中 U = 1000；稀疏或更大值域可改用哈希表。

面试追问

  • 答案会因不同合法划分改变吗？不会；每个技能 x 的搭档技能被 T−x 唯一确定，交换同技能玩家不影响乘积。
  • 如何输出玩家原始编号？排序 (技能, 下标) 对，然后输出两端下标。
  • 能推广到每队三人吗？两端配对的必要性证明不再适用，不能直接套用该贪心。
  • 不能修改输入怎么办？先复制数组，增加 O(n) 空间。

常见错误

  • JavaScript 忘记数值排序比较器，导致按字符串字典序排序。
  • 只检查总和整除，未验证每个玩家能否找到搭档。
  • 用 32 位整数累计答案，或把团队技能和误当作化学反应。
  • 循环写成左右指针分别遍历整个数组，重复累计每队。

Java

import java.util.Arrays;

class Solution {
    public long dividePlayers(int[] skill) {
        Arrays.sort(skill);
        int left = 0, right = skill.length - 1;
        int target = skill[left] + skill[right];
        long answer = 0;
        while (left < right) {
            if (skill[left] + skill[right] != target) return -1;
            answer += (long) skill[left] * skill[right];
            left++;
            right--;
        }
        return answer;
    }
}

from typing import List

class Solution:
    def dividePlayers(self, skill: List[int]) -> int:
        a = sorted(skill)
        left, right = 0, len(a) - 1
        target = a[left] + a[right]
        answer = 0
        while left < right:
            if a[left] + a[right] != target:
                return -1
            answer += a[left] * a[right]
            left += 1
            right -= 1
        return answer

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    long long dividePlayers(vector<int>& skill) {
        sort(skill.begin(), skill.end());
        int left = 0, right = static_cast<int>(skill.size()) - 1;
        int target = skill[left] + skill[right];
        long long answer = 0;
        while (left < right) {
            if (skill[left] + skill[right] != target) return -1;
            answer += 1LL * skill[left] * skill[right];
            ++left;
            --right;
        }
        return answer;
    }
};
