祖玛游戏Zuma Game

一排彩球、至多五颗手牌，以及会连续触发的消除反应。请找出清空桌面所需的最少插入次数。

广度优先搜索记忆化搜索字符串栈式消除动态规划

Problem

题目描述

桌面上有一排彩球，每颗球用 R（红）、Y（黄）、B（蓝）、G（绿）或 W（白）表示；你手中还有若干可用彩球。

1任选并插入每回合从手牌任选一球，插到相邻两球之间或整排任一端。
2连续消除出现至少 3 颗连续同色球时将整组移除；新形成的组继续消除。
3求最少次数返回清空桌面的最少插球数；手牌不足以完成时返回 -1。
注意：一次插入后，所有可消除的同色连续组都会连锁消失，直到局面重新稳定。

函数签名

findMinStep(board: string, hand: string) -> integer

官方示例

Example 01
输入：board = "WRRBBW", hand = "RB"
输出：-1

Example 02
输入：board = "WWRRBBWW", hand = "WRBRW"
输出：2

依次插入 R、B，触发红、蓝、白三段连锁消除，两步清空。

Example 03
输入：board = "G", hand = "GGGGG"
输出：2

连续插入两颗绿球形成 GGG，随后整组消除。

Example 04
输入：board = "RBYYBBRRB", hand = "YRBGB"
输出：3

先补一颗黄球触发多段连锁，局面只剩 B；再补两颗蓝球即可清空。

约束

  • 1 <= board.length <= 16
  • 1 <= hand.length <= 5
  • board 与 hand 只包含 R / Y / B / G / W。
  • 初始桌面中不存在长度至少为 3 的同色连续组。

Solution · spoiler

记忆化搜索：按同色段补球并消除

手牌最多只有 5 颗，适合搜索所有真正有意义的插入。关键不是枚举每个位置与每颗球，而是把稳定桌面分成同色连续段：长度为 2 的段只需补 1 颗，长度为 1 的段需补 2 颗。补够后立刻消除，再统一处理连锁反应。

核心洞察

状态要完整同一桌面配上不同剩余手牌，后续答案可能不同；记忆键必须同时编码两者。
只搜索有效补球在稳定局面中，向某个同色段补到 3 颗，代表最终让该段消失所需的一组连续插入。
消除必须闭包一段消失后，两侧可能拼成新段。反复压缩直到没有长度至少为 3 的组。

完整过程

  1. 统计手牌中五种颜色的数量，并先将桌面压缩为稳定状态。
  2. 若桌面为空，当前分支不再需要插球，返回 0；若状态已记录，直接复用答案。
  3. 从左到右枚举每个最大同色连续段。设段长为 len，令 need = 3 - len。
  4. 若手中该颜色至少有 need 颗，就暂时消耗它们、删除这一段，并对拼接后的桌面执行完整连锁压缩。
  5. 递归求剩余局面的最少插入数，用 need + subAnswer 更新最优值，随后恢复手牌计数。
  6. 所有段都无法得到可行结果时返回 -1；否则返回最小消耗。

正确性说明

引理 1（消除闭包）：shrink 每轮删除所有当前长度至少为 3 的最大同色段。每轮都严格缩短字符串，所以必定终止；终止时恰好没有可继续消除的组，得到规则要求的稳定局面。

引理 2（候选完备）：稳定局面中的每个现有同色段长度只能是 1 或 2。任何成功方案若最终让该段参与首次消除，在首次消除前必须为它补足至至少 3 颗；这些同色补球在消除发生前不会触发别的变化，因此可连续执行并合并成一次花费 3-len 的决策。搜索枚举了每个段的这一决策。

引理 3（最优子结构）：选定首次消除的段后，手牌扣减、该段删除及全部连锁压缩唯一确定下一个状态。后续若不用该状态的最优方案，就可替换为更优方案，从而改进原方案，产生矛盾。

结论：搜索覆盖某个最优方案的首次有效决策，并递归选择其后最优解；对所有可行首次决策取最小值，因此返回的正是清空桌面的最少插入次数。无可行分支时返回 -1。

边界与复杂度

边界
  • 单球需要两颗同色手牌才能消除。
  • 一次删除可能让两侧同色段连接并继续消除。
  • 相同桌面、不同手牌必须视为不同状态。
  • 不可达状态使用一个足够大的哨兵值，最终再转成 -1。
复杂度

设可达且去重后的状态数为 S，桌面最大长度为 n。每个状态枚举至多 O(n) 个段，朴素压缩与字符串拼接最坏 O(n²)，总时间可记为 O(S·n³) 的保守上界，空间为 O(S·n)。由于搜索本质上对手牌选择分支，S 的最坏增长是指数级；本题 hand.length ≤ 5 使其可控。

Java · LeetCode 提交格式
import java.util.*;

class Solution {
    private static final int INF = 1_000_000;
    private final Map<String, Integer> memo = new HashMap<>();

    public int findMinStep(String board, String hand) {
        int[] count = new int[128];
        for (char c : hand.toCharArray()) count[c]++;
        int answer = dfs(shrink(board), count);
        return answer >= INF ? -1 : answer;
    }

    private int dfs(String board, int[] count) {
        if (board.isEmpty()) return 0;
        String key = board + "#" + count['R'] + ',' + count['Y'] + ','
                + count['B'] + ',' + count['G'] + ',' + count['W'];
        if (memo.containsKey(key)) return memo.get(key);

        int best = INF;
        for (int i = 0; i < board.length();) {
            int j = i + 1;
            while (j < board.length() && board.charAt(j) == board.charAt(i)) j++;
            char color = board.charAt(i);
            int need = 3 - (j - i);
            if (count[color] >= need) {
                count[color] -= need;
                String next = shrink(board.substring(0, i) + board.substring(j));
                int sub = dfs(next, count);
                if (sub < INF) best = Math.min(best, need + sub);
                count[color] += need;
            }
            i = j;
        }
        memo.put(key, best);
        return best;
    }

    private String shrink(String s) {
        boolean changed = true;
        while (changed) {
            changed = false;
            StringBuilder next = new StringBuilder();
            for (int i = 0; i < s.length();) {
                int j = i + 1;
                while (j < s.length() && s.charAt(j) == s.charAt(i)) j++;
                if (j - i >= 3) changed = true;
                else next.append(s, i, j);
                i = j;
            }
            s = next.toString();
        }
        return s;
    }
}

/**
 * @param {string} board
 * @param {string} hand
 * @return {number}
 */
var findMinStep = function(board, hand) {
    const COLORS = ['R', 'Y', 'B', 'G', 'W'];
    const INF = 1_000_000;
    const count = { R: 0, Y: 0, B: 0, G: 0, W: 0 };
    for (const color of hand) count[color]++;
    const memo = new Map();

    function shrink(s) {
        let changed = true;
        while (changed) {
            changed = false;
            let next = '';
            for (let i = 0; i < s.length;) {
                let j = i + 1;
                while (j < s.length && s[j] === s[i]) j++;
                if (j - i >= 3) changed = true;
                else next += s.slice(i, j);
                i = j;
            }
            s = next;
        }
        return s;
    }

    function dfs(current) {
        if (current.length === 0) return 0;
        const key = current + '#' + COLORS.map(c => count[c]).join(',');
        if (memo.has(key)) return memo.get(key);

        let best = INF;
        for (let i = 0; i < current.length;) {
            let j = i + 1;
            while (j < current.length && current[j] === current[i]) j++;
            const color = current[i];
            const need = 3 - (j - i);
            if (count[color] >= need) {
                count[color] -= need;
                const sub = dfs(shrink(current.slice(0, i) + current.slice(j)));
                if (sub < INF) best = Math.min(best, need + sub);
                count[color] += need;
            }
            i = j;
        }
        memo.set(key, best);
        return best;
    }

    const answer = dfs(shrink(board));
    return answer >= INF ? -1 : answer;
};

from functools import lru_cache


class Solution:
    def findMinStep(self, board: str, hand: str) -> int:
        colors = "RYBGW"
        index = {color: i for i, color in enumerate(colors)}
        initial = [0] * 5
        for color in hand:
            initial[index[color]] += 1

        def shrink(s: str) -> str:
            changed = True
            while changed:
                changed = False
                pieces = []
                i = 0
                while i < len(s):
                    j = i + 1
                    while j < len(s) and s[j] == s[i]:
                        j += 1
                    if j - i >= 3:
                        changed = True
                    else:
                        pieces.append(s[i:j])
                    i = j
                s = "".join(pieces)
            return s

        @lru_cache(None)
        def dfs(current: str, counts: tuple[int, ...]) -> int:
            if not current:
                return 0
            best = float("inf")
            i = 0
            while i < len(current):
                j = i + 1
                while j < len(current) and current[j] == current[i]:
                    j += 1
                color_id = index[current[i]]
                need = 3 - (j - i)
                if counts[color_id] >= need:
                    rest = list(counts)
                    rest[color_id] -= need
                    next_board = shrink(current[:i] + current[j:])
                    sub = dfs(next_board, tuple(rest))
                    if sub != float("inf"):
                        best = min(best, need + sub)
                i = j
            return best

        answer = dfs(shrink(board), tuple(initial))
        return -1 if answer == float("inf") else answer

class Solution {
    static constexpr int INF = 1'000'000;
    unordered_map<string, int> memo;

    string shrink(string s) {
        bool changed = true;
        while (changed) {
            changed = false;
            string next;
            for (int i = 0; i < static_cast<int>(s.size());) {
                int j = i + 1;
                while (j < static_cast<int>(s.size()) && s[j] == s[i]) ++j;
                if (j - i >= 3) changed = true;
                else next.append(s, i, j - i);
                i = j;
            }
            s = move(next);
        }
        return s;
    }

    string makeKey(const string& board, const array<int, 128>& count) {
        return board + "#" + to_string(count['R']) + ','
             + to_string(count['Y']) + ',' + to_string(count['B']) + ','
             + to_string(count['G']) + ',' + to_string(count['W']);
    }

    int dfs(const string& board, array<int, 128>& count) {
        if (board.empty()) return 0;
        string key = makeKey(board, count);
        if (auto it = memo.find(key); it != memo.end()) return it->second;

        int best = INF;
        for (int i = 0; i < static_cast<int>(board.size());) {
            int j = i + 1;
            while (j < static_cast<int>(board.size()) && board[j] == board[i]) ++j;
            unsigned char color = board[i];
            int need = 3 - (j - i);
            if (count[color] >= need) {
                count[color] -= need;
                string next = shrink(board.substr(0, i) + board.substr(j));
                int sub = dfs(next, count);
                if (sub < INF) best = min(best, need + sub);
                count[color] += need;
            }
            i = j;
        }
        return memo[key] = best;
    }

public:
    int findMinStep(string board, string hand) {
        array<int, 128> count{};
        for (unsigned char color : hand) ++count[color];
        int answer = dfs(shrink(board), count);
        return answer >= INF ? -1 : answer;
    }
};

替代方案

  • BFS：逐层枚举插球位置，首次清空即为最少步数；直观但分支多，需要认真去重。
  • 位压缩状态：可将短桌面与手牌编码成整数，常数更小，但实现复杂、可读性差。
  • 区间动态规划：可围绕合并与消除设计状态，但手牌颜色和跨区间连锁使状态更难组织。

常见错误

  • 只消除一次，没有处理删除后形成的新同色连续段。
  • 记忆键只有 board，遗漏剩余手牌颜色分布。
  • 递归扣减手牌后忘记回溯恢复，污染兄弟分支。
  • 枚举每个插入位置却不去除等价动作，导致状态爆炸。
  • 用 -1 直接参与取最小值，使不可达分支被误认为最优。
