出租车的最大盈利

Maximum Earnings From Taxi

一路向前，一次一单。怎样安排接送，才能把这段路的收益最大化？

前往官方题目 ↗

题目

道路上有编号从 1 到 n 的地点。出租车从地点 1 开往地点 n，只能向编号增大的方向行驶，可以空驶，也可以跳过订单。

二维整数数组 rides 的每项为 [startᵢ, endᵢ, tipᵢ]，表示乘客的上车点、下车点和小费。接下这笔订单可赚取 endᵢ − startᵢ + tipᵢ。车上同时最多有一位乘客；允许在同一个地点先下客再接客。

返回能够获得的最大总盈利。函数参数是 n, rides，返回值为整数收益。

约束

  • 1 ≤ n ≤ 10⁵
  • 1 ≤ rides.length ≤ 3 × 10⁴
  • rides[i].length = 3
  • 1 ≤ startᵢ < endᵢ ≤ n
  • 1 ≤ tipᵢ ≤ 10⁵

虽然 n 的独立范围包含 1，但结合非空订单与 start < end，有效输入实际需要 n ≥ 2。

官方示例

示例 1

n = 5
rides = [[2,5,4],[1,5,1]]
输出：7

选择下标 0 的订单，从 2 到 5，收益为 5 − 2 + 4 = 7。

示例 2

n = 20
rides = [[1,6,1],[3,10,2],[10,12,3],
         [11,12,2],[12,15,2],[13,18,1]]
输出：20

依次接订单 1、2、5，收益分别是 9、5、6。地点 12 到 13 空驶，总计 20。

独立题解

包含算法推演、证明与四语言实现

核心洞察：按下车地点归档

设 dp[x] 表示行驶到地点 x、车上没有乘客时能取得的最大收益。最后一步只有两种情况：从 x − 1 空驶过来，或完成一笔在 x 下车的订单。后者可以接在地点 start 的最优方案之后。

dp[0] = dp[1] = 0
对于 x = 1 ... n：
    dp[x] = dp[x-1]
    对每笔 [s,x,t]：
        dp[x] = max(dp[x], dp[s] + x-s+t)
答案 = dp[n]

先把每笔订单放入对应终点的桶中。所有订单都满足 start < end，所以计算 dp[x] 时，所需的 dp[start] 已经最终确定。无需对订单排序。

完整过程

  1. 创建 n + 1 个终点桶，把订单的起点和单笔收益存入桶。
  2. 初始化 dp 数组为 0，从地点 1 向 n 扫描。
  3. 先令 dp[x] = dp[x − 1]，代表空驶到 x。
  4. 枚举终点为 x 的订单，以 dp[start] 加上该单收益更新 dp[x]。
  5. 返回 dp[n]。如要恢复订单序列，再保存前驱地点和选择的订单下标。

示例 2 的关键状态：dp[6] = 6；dp[10] = 9；dp[12] = 14；dp[15] = 19；dp[18] = 20。地点 13 没有下车订单，继承 dp[12] = 14，因此订单 [13,18,1] 可以接在此前方案后面。最后空驶到 20，收益不变。

正确性证明

按地点归纳。初始没有完成订单，收益为 0。假设所有小于 x 的状态均最优。任一到 x 且空车的合法方案，如果没有在 x 下客，其最后收益至多为 dp[x − 1]；否则最后订单为 [s,x,t]，在 s 上车前的收益至多为 dp[s]，总收益至多为 dp[s] + x − s + t。转移枚举了这两类的全部可能，故不会漏掉最优值。

反过来，继承方案可通过空驶到达 x；订单候选可在 s 的最优空车方案后接上该订单，且 s < x，不发生重叠。所有候选都可实现，因此取最大值得到的 dp[x] 恰为最优收益。归纳得 dp[n] 正确。

复杂度与数值

令 m = rides.length。分桶 O(n + m)，扫描 O(n + m)，总时间 O(n + m)，额外空间 O(n + m)。

所选订单的总路程不超过 n − 1，小费和不超过 m × 10⁵，收益可能超过 2³¹ − 1。Java 用 long，C++ 用 long long；Python 整数足够，JavaScript Number 在本题上界内可精确表示整数。

边界与常见错误

  • 同地点下客后可接客，应允许 end = nextStart。
  • 同终点的多笔订单要取最大值，不能累加。
  • 无订单结束的地点也要继承收益。
  • 不要按小费或单笔收益贪心。
  • 收益是距离加小费，不是只有小费。
  • 分桶索引应取 end，不能误放到 start。

替代方案与面试追问

按终点排序 + 二分：令 f[i] 为前 i 笔订单的最优值。对第 i 笔订单，二分找到已处理订单中终点 ≤ 当前起点的数量 k，转移 f[i] = max(f[i − 1], f[k] + 当前收益)。时间 O(m log m)，空间 O(m)，适合 n 非常大而订单稀疏的情况。

  • 如何返回具体订单？记录每个状态的前驱地点与订单编号，从 n 向前回溯，再反转。
  • 有多种最优方案怎么办？只求收益时任选；若要求最少订单，可在状态中增加订单数作平局规则。
  • 坐标达到 10⁹ 怎么办？改用排序二分方案，或压缩所有起终点。
  • 下客后需要休息一段距离？兼容性改成上一订单终点加休息距离 ≤ 下一起点。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public long maxTaxiEarnings(int n, int[][] rides) {
        List<List<int[]>> ends = new ArrayList<>(n + 1);
        for (int x = 0; x <= n; x++) {
            ends.add(new ArrayList<>());
        }
        for (int[] r : rides) {
            ends.get(r[1]).add(new int[]{r[0], r[1] - r[0] + r[2]});
        }
        long[] dp = new long[n + 1];
        for (int x = 1; x <= n; x++) {
            dp[x] = dp[x - 1];
            for (int[] ride : ends.get(x)) {
                dp[x] = Math.max(dp[x], dp[ride[0]] + ride[1]);
            }
        }
        return dp[n];
    }
}

var maxTaxiEarnings = function(n, rides) {
    const ends = Array.from({length: n + 1}, () => []);
    for (const [start, end, tip] of rides) {
        ends[end].push([start, end - start + tip]);
    }
    const dp = Array(n + 1).fill(0);
    for (let x = 1; x <= n; x++) {
        dp[x] = dp[x - 1];
        for (const [start, gain] of ends[x]) {
            dp[x] = Math.max(dp[x], dp[start] + gain);
        }
    }
    return dp[n];
};

#include <algorithm>

class Solution {

    long long maxTaxiEarnings(int n, vector<vector<int>>& rides) {
        vector<vector<pair<int, int>>> ends(n + 1);
        for (const auto& r : rides) {
            ends[r[1]].push_back({r[0], r[1] - r[0] + r[2]});
        }
        vector<long long> dp(n + 1, 0);
        for (int x = 1; x <= n; ++x) {
            dp[x] = dp[x - 1];
            for (const auto& ride : ends[x]) {
                dp[x] = max(dp[x], dp[ride.first] + ride.second);
            }
        }
        return dp[n];
    }
};
