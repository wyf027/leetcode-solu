shift briefing

为什么统一转负数？

32 位整数的负数范围多一个：−2³¹ 没有对应正数。保留负数可避免 abs(INT_MIN) 溢出。

    01 · core insight

    核心洞察：减法也能跳着走

    连减一次只前进 1 份，最坏要做约 2³¹ 次。把除数用加法翻倍，得到 1、2、4、8… 份；再从大到小选能放下的块，相当于用二进制拼出商。

    02 · overflow firewall

    溢出防火墙

    • 统一负数：避免把 −2³¹ 转成不存在的正数。
    • 翻倍前守卫：current ≥ INT_MIN / 2 时，current + current 才安全。
    • 唯一正溢出：INT_MIN ÷ −1 直接返回 INT_MAX。

    03 · complete process

    完整解题过程

    1. STEP 1

      处理溢出特例

      MIN / -1 返回 MAX。

    2. STEP 2

      记录符号并转负

      内部所有数保持非正，商也先记为负数。

    3. STEP 3

      构造倍增货块

      只用自加得到除数倍数与对应的负权重。

    4. STEP 4

      从大到小装载

      能放下就更新余量和负商，最后恢复符号。

    边界情况

    • • dividend = 0：商为 0。
    • • dividend = divisor：商为 1。
    • • 异号：最后保持负商。
    • • 同号：最后取负得到正商。
    • • INT_MIN / -1：钳制到 INT_MAX。

    复杂度

    Time
    O(log |dividend|)
    Space
    O(log |dividend|)

    32 位环境中货块最多约 32 个，实际是常数级。

    替代方案取舍

    • 逐次减法：O(|商|)，会超时。
    • 每轮重新倍增：O(log² n)、O(1) 空间，代码略短但重复工作。
    • 从高位试减：O(log n)、O(1)，但依赖更宽整数或要格外处理移位溢出。

    面试高频追问

    Q：为什么不直接使用 abs？
    A：32 位中 abs(INT_MIN) 无法用 int 表示。
    Q：为什么负数比较看起来反了？
    A：若货块 chunk ≥ remainder，其绝对值才不超过剩余绝对值，所以可以装载。
    Q：如何做到 O(1) 额外空间？
    A：从最高安全倍数开始，逐位缩小；或每轮临时翻倍，但需权衡实现与复杂度。

    常见错误

    • ✗ 转正后才发现 INT_MIN 溢出。
    • ✗ 用 << 翻倍，却没有证明移位安全。
    • ✗ 忘记 INT_MIN / -1 是唯一正向溢出。
    • ✗ 负数条件写成 chunk <= remainder，导致错误装载。
    • ✗ 使用浮点计算符号或期望值，边界处损失精度。

    class Solution {
    public int divide(int dividend, int divisor) {
        final int MIN = Integer.MIN_VALUE;
        final int MAX = Integer.MAX_VALUE;
        final int HALF_MIN = MIN / 2;

        if (dividend == MIN && divisor == -1) {
            return MAX;
        }

        boolean sameSign = (dividend < 0) == (divisor < 0);
        if (dividend > 0) dividend = -dividend;
        if (divisor > 0) divisor = -divisor;

        int[] multiples = new int[32];
        int[] powers = new int[32];
        int size = 1;
        multiples[0] = divisor;
        powers[0] = -1;

        while (multiples[size - 1] >= HALF_MIN
                && multiples[size - 1] + multiples[size - 1] >= dividend) {
            multiples[size] = multiples[size - 1] + multiples[size - 1];
            powers[size] = powers[size - 1] + powers[size - 1];
            size++;
        }

        int quotient = 0;
        for (int i = size - 1; i >= 0; i--) {
            if (multiples[i] >= dividend) {
                dividend -= multiples[i];
                quotient += powers[i];
            }
        }

        return sameSign ? -quotient : quotient;
    }
}
