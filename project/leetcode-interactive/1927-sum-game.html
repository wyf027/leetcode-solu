Sum GameMEDIUM双人博弈 · 数字平衡

一边想让天平平衡，一边想打破平衡。每个问号，都是一次选择。

游戏规则

输入偶数长度字符串 num，字符只能是数字或 ?。Alice 先手，双方轮流选择一个问号，将它替换成 0 到 9 中任意数字。

问号全部填完后，比较左右两半的数字和：相等则 Bob 胜，不相等则 Alice 胜。假设双方都采用最优策略，返回 Alice 是否能获胜：能则 true，否则 false。

约束：2 ≤ num.length ≤ 10⁵；长度为偶数；仅包含 '0'–'9' 与 '?'。函数：sumGame(num) → boolean。

官方示例

num = "5023" → false

无需操作，5 + 0 = 2 + 3，Bob 获胜。

num = "25??" → true

Alice 在右侧填 9，右侧至少为 9，已经超过左侧的 7，Bob 无法追平。

num = "?3295???" → false

Bob 可以保证获胜。一条可能路径：?3295??? → 93295??? → 932959?? → 9329592? → 93295927。最终左右均为 23。

题解 · 给问号一个中间值

核心洞察

记已知数字的左右和之差为 D = sL − sR，问号数量为 qL、qR。先把每个问号想象成 4.5，定义两倍的“中点差”：T = 2D + 9(qL − qR)。它只是分析工具，不需要真的填小数。

填左侧 x 时 T 改变 2x − 9；填右侧 x 时改变 9 − 2x。无论选哪一侧，可用变化量都是 −9、−7、…、7、9。

完整过程

  1. 扫描字符串，统计 D、qL、qR。
  2. 问号总数为奇数：Alice 拿到最后一手，可以避开唯一可能使两边相等的数字，因此返回 true。
  3. 总数为偶数：T = 0 时 Bob 能保持平衡，返回 false；T ≠ 0 时 Alice 能保持偏差，返回 true。

代码条件：(qL + qR) % 2 != 0 || 2 * D != 9 * (qR - qL)。

正确性证明

偶数问号、T = 0：Alice 让 T 变化 δ 后，Bob 在任意剩余问号选择造成 −δ 的数字即可归零。如果双方选同侧，填入数字之和为 9；若选不同侧，填相同数字。每两手归零，直到结束，此时 T = 2D = 0，故 Bob 必胜。

偶数问号、T > 0：Alice 每次令 T 增加 9（左填 9 或右填 0），Bob 一手最多减少 9，所以每两手结束 T 仍严格大于 0。T < 0 时取对称策略，每次减少 9。最终和不等，Alice 必胜。

奇数问号：Alice 最后一手有十个数字可选，至多一个能让最终和相等。她总能选择另一个，因此必胜。三种情形覆盖全部合法输入。

示例推导与边界

对于 ?3295???，D = 14 − 5 = 9，qL = 1，qR = 3，T = 18 − 18 = 0，所以 Bob 胜。对于 25??，T = 14 − 18 = −4，Alice 胜。

没有问号时，判断直接退化为左右和是否相等；全是问号且左右等长时 Bob 胜。数字 0 也必须计入已知数字分支。最大长度下这些整数在四种语言的常用整数范围内安全。

复杂度

一次扫描，时间 O(n)，额外空间 O(1)。不需要排序、递归或存储每个问号的位置。

替代方案

极小输入可用极小化极大搜索枚举位置与数字，但分支随问号数爆炸，不能处理 10⁵ 长度。也可以直接使用 4.5 的中点公式；整数倍形式更直观地避免小数运算与除法截断。

常见错误

  • 只比较当前数字和，忽略剩余问号的影响。
  • 把 qR − qL 写成 qL − qR，却没有同时改变 D 的符号。
  • 把某条演示路径当成双方最优策略的证明。
  • 用整数除法先计算问号差的一半，导致奇数问号判断出错。

面试追问

若数字范围变成 0…m？将 9 换成 m，m ≥ 1 时同样可用中点与抵消证明。若两侧允许的数字集合不同？可用变化量未必对称，Bob 的反向抵消策略不再自动成立，需要重新分析。

Java

class Solution {
    public boolean sumGame(String num) {
        int d = 0, left = 0, right = 0;
        for (int i = 0; i < num.length(); i++) {
            char c = num.charAt(i);
            if (c == '?') {
                if (i < num.length() / 2) left++;
                else right++;
            } else {
                d += (i < num.length() / 2 ? 1 : -1) * (c - '0');
            }
        }
        return (left + right) % 2 != 0 || 2 * d != 9 * (right - left);
    }
}

Python

class Solution:
    def sumGame(self, num: str) -> bool:
        d = left = right = 0
        half = len(num) // 2
        for i, c in enumerate(num):
            if c == '?':
                if i < half:
                    left += 1
                else:
                    right += 1
            else:
                d += (1 if i < half else -1) * int(c)
        return (left + right) % 2 != 0 or 2 * d != 9 * (right - left)

C++

#include <string>
using namespace std;
class Solution {
public:
    bool sumGame(string num) {
        int d = 0, left = 0, right = 0;
        int n = static_cast<int>(num.size());
        for (int i = 0; i < n; ++i) {
            if (num[i] == '?') {
                if (i < n / 2) ++left;
                else ++right;
            } else {
                d += (i < n / 2 ? 1 : -1) * (num[i] - '0');
            }
        }
        return (left + right) % 2 != 0 || 2 * d != 9 * (right - left);
    }
};
