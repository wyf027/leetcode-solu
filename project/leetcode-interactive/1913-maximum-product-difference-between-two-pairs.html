两个数对之间的最大乘积差

Maximum Product Difference Between Two Pairs

四个位置，两次乘法，一次相减。

题目

给定正整数数组 nums，选择四个互不相同的下标 w、x、y、z，使 nums[w] × nums[x] − nums[y] × nums[z] 最大，返回最大差值。数值可以重复，下标不能重复。

参数 nums: integer[]；返回 integer。约束：4 ≤ nums.length ≤ 10⁴；1 ≤ nums[i] ≤ 10⁴。

官方示例 1

输入：nums = [5,6,2,7,4]
输出：34

选择下标 (1,3) 和 (2,4)：6 × 7 − 2 × 4 = 34。

官方示例 2

输入：nums = [4,2,5,9,7,4,8]
输出：64

选择下标 (3,6) 和 (1,5)：9 × 8 − 2 × 4 = 64。

题解：只保留四个极值

核心洞察

所有元素为正数。最大化前一个乘积，最小化后一个乘积：取最大的两个数相乘，再减去最小的两个数的乘积。

完整过程

  1. 初始化 hi1 = hi2 = 0，lo1 = lo2 = 无穷大。
  2. 扫描 x：若 x ≥ hi1，先令 hi2 = hi1，再令 hi1 = x；否则只在 x > hi2 时更新 hi2。
  3. 独立维护最小组：若 x ≤ lo1，先令 lo2 = lo1，再令 lo1 = x；否则只在 x < lo2 时更新 lo2。
  4. 返回 hi1 × hi2 − lo1 × lo2。示例 1 最终为 7 × 6 − 2 × 4 = 34。

正确性证明

扫描不变量：两组变量分别是已处理前缀的两个最大值与两个最小值，重复值按出现次数保留。新值要么成为第一极值并把旧第一位后移，要么只可能替换第二位，因此每一步保持不变量。

设排序后 a₀ ≤ … ≤ aₙ₋₁。任意数对乘积不超过 aₙ₋₁aₙ₋₂，也不小于 a₀a₁，所以任何合法差值都不超过 aₙ₋₁aₙ₋₂ − a₀a₁。n ≥ 4，排序位置 0、1、n−2、n−1 互不相同，这个上界可以达到。即使值相等也可以选不同出现位置。扫描返回的正是这个上界。

边界与复杂度

长度 4 时成立；全部相等返回 0；重复极值不能去重。时间 O(n)，额外空间 O(1)，不修改输入。最大乘积 10⁸，结果在 0 到 99,999,999 之间，32 位有符号整数足够。实验台为展示下标使用小候选列表，提交代码仅维护四个值。

替代方案

排序后取两端，时间 O(n log n)，额外空间取决于排序实现和是否复制数组。暴力枚举四个不同下标为 O(n⁴)，仅适用于很小数据。

常见错误

  • 使用同一下标两次，或对重复值去重。
  • 先覆盖第一极值，导致第二极值拿到错误的旧值。
  • 将最大组和最小组的更新写成互斥分支。
  • JavaScript 排序未传 (a,b) => a-b，发生字典序排序。

面试追问

允许负数时怎么办？正数的乘积单调性失效，需重新考虑符号与数对下标冲突，不能直接套用本公式。要求返回下标时怎么办？对 (值,下标) 排序取首尾四个位置，或者扫描保留下标并统一打破平局。流式输入呢？四个极值足够，不必保存整个输入。

Java

class Solution {
    public int maxProductDifference(int[] nums) {
        int hi1 = 0, hi2 = 0;
        int lo1 = Integer.MAX_VALUE, lo2 = Integer.MAX_VALUE;
        for (int x : nums) {
            if (x >= hi1) { hi2 = hi1; hi1 = x; }
            else if (x > hi2) hi2 = x;
            if (x <= lo1) { lo2 = lo1; lo1 = x; }
            else if (x < lo2) lo2 = x;
        }
        return hi1 * hi2 - lo1 * lo2;
    }
}

from typing import List

class Solution:
    def maxProductDifference(self, nums: List[int]) -> int:
        hi1 = hi2 = 0
        lo1 = lo2 = float('inf')
        for x in nums:
            if x >= hi1:
                hi2, hi1 = hi1, x
            elif x > hi2:
                hi2 = x
            if x <= lo1:
                lo2, lo1 = lo1, x
            elif x < lo2:
                lo2 = x
        return hi1 * hi2 - lo1 * lo2
