题解 · 保留每行，条件决定奖金

核心洞察

条件决定的是输出列的值，而不是哪些员工能出现在结果里。使用 CASE WHEN 为每一行计算奖金；不满足要求的行仍保留，并得到 0。两个条件用 AND 连接，最后单独排序。

完整过程

  1. 逐行读取 Employees，用 MOD(employee_id, 2) <> 0 判断奇数。
  2. 用 name NOT LIKE 'M%' 判断姓名不是以 M 开头；百分号表示其后的任意长度字符。
  3. 当两项都成立时返回 salary，否则返回 0，并将列命名为 bonus。
  4. 仅输出编号与奖金，使用 ORDER BY employee_id ASC 排序。

官方可提交主解 · MySQL

SELECT employee_id,
       CASE
           WHEN MOD(employee_id, 2) <> 0
                AND name NOT LIKE 'M%'
           THEN salary
           ELSE 0
       END AS bonus
FROM Employees
ORDER BY employee_id ASC;

这是 MySQL 主解。迁移到其他数据库时，需按方言调整取模语法。LIKE 的大小写行为取决于数据库及列的排序规则；题面只描述字符 M，未提供排序规则。上面的 SQL 使用数据库默认比较语义；下方本地参考与演示器按大写 M 精确比较。含小写 m 的扩展数据应先约定语义，再选择区分大小写的排序规则。

官方可提交补充 · Pandas

import pandas as pd

def calculate_special_bonus(employees: pd.DataFrame) -> pd.DataFrame:
    eligible = (employees["employee_id"] % 2 != 0) & (
        ~employees["name"].str.startswith("M", na=True)
    )
    result = employees[["employee_id"]].copy()
    result["bonus"] = employees["salary"].where(eligible, 0)
    return result.sort_values("employee_id")

Pandas 版本按大写 M 精确判断；缺失姓名按不满足资格处理。题面未定义缺失值的业务规则。

正确性说明

对于任意员工，条件表达式当且仅当“编号为奇数且姓名不以 M 开头”成立时选中工资分支，故合格员工奖金等于工资。条件为假时选中 0 分支，故其余员工奖金为 0。查询不使用筛选、分组或连接，因此每个输入员工恰好贡献一行，不会遗漏或重复。最后按主键升序排列，满足结果顺序要求。

边界与复杂度

  • 空表输出空结果，但保留列结构；单行照常计算。
  • 奇数编号且姓名为 M 仍不合格；M 位于姓名中间不影响资格。
  • 工资为 0 时，合格与不合格员工都可能输出 0，不能由奖金反推资格。
  • 输入顺序无保证，主键唯一也不代表查询默认有序，必须显式排序。
  • 扫描和条件计算为 O(n)；若需要通用排序，总时间为 O(n log n)。若执行计划利用合适的有序索引，可能省去显式排序，实际依数据库计划而定。
  • 结果含 n 行；本地参考占用 O(n) 结果空间。SQL 的排序内存、磁盘使用及额外空间依执行计划而定，不能笼统承诺 O(1)。

替代方案

MySQL 可用 IF(条件, salary, 0)，但 CASE 更便于跨数据库迁移。将条件转数值后乘工资更短，却依赖布尔转换和 NULL 语义。用两个查询分别取合格和不合格员工再 UNION ALL 也能表达，但更冗长且容易漏掉条件分支，无须使用。

常见错误

  • 在 WHERE 中写奖金条件：会把奖金为 0 的员工直接删掉。
  • 将 AND 写成 OR：只满足一项要求的员工也会获奖。
  • 使用 NOT LIKE '%M%'：错误排除姓名中间含 M 的员工。
  • 省略 ELSE：不合格员工可能得到 NULL，而不是 0。
  • 忘记列别名 bonus 或 ORDER BY：输出格式或顺序不满足要求。

面试追问

奖金等级变多怎么办？ 使用多个 WHEN，按业务优先级排列，并保留明确的 ELSE。
需要区分 m 与 M 吗？ 先明确需求，再显式配置比较语义。
大表如何优化？ 查询必须输出所有员工，仍需遍历；观察执行计划是否能利用 employee_id 的有序索引减少排序，而不是给资格条件加 WHERE。
姓名可能为 NULL 呢？ SQL 三值逻辑会让条件不为 TRUE，CASE 进入 ELSE；若业务要求不同，需要显式定义 NULL 策略。

Java · 本地语义参考（Main.java）
import java.util.*;

public class Main {
    static class Employee {
        final int employeeId;
        final String name;
        final long salary;
        Employee(int employeeId, String name, long salary) {
            this.employeeId = employeeId;
            this.name = name;
            this.salary = salary;
        }
    }

    static List<long[]> calculateSpecialBonus(List<Employee> employees) {
        List<long[]> result = new ArrayList<>();
        for (Employee e : employees) {
            long bonus = e.employeeId % 2 != 0 && !e.name.startsWith("M")
                    ? e.salary : 0;
            result.add(new long[]{e.employeeId, bonus});
        }
        result.sort(Comparator.comparingLong(row -> row[0]));
        return result;
    }

    public static void main(String[] args) {
        List<Employee> employees = Arrays.asList(
            new Employee(2, "Meir", 3000),
            new Employee(3, "Michael", 3800),
            new Employee(7, "Addilyn", 7400),
            new Employee(8, "Juan", 6100),
            new Employee(9, "Kannon", 7700)
        );
        for (long[] row : calculateSpecialBonus(employees))
            System.out.println(Arrays.toString(row));
    }
}

def calculate_special_bonus(employees):
    result = [
        {"employee_id": employee_id,
         "bonus": salary if employee_id % 2 != 0
                  and not name.startswith("M") else 0}
        for employee_id, name, salary in employees
    ]
    return sorted(result, key=lambda row: row["employee_id"])

C++ · 本地语义参考（C++17）
#include <algorithm>
#include <iostream>
#include <string>
#include <utility>
#include <vector>
using namespace std;

struct Employee {
    int employee_id;
    string name;
    long long salary;
};

vector<pair<int, long long>> calculateSpecialBonus(
    const vector<Employee>& employees) {
    vector<pair<int, long long>> result;
    for (const auto& e : employees) {
        bool startsM = !e.name.empty() && e.name.front() == 'M';
        long long bonus = e.employee_id % 2 != 0 && !startsM
                             ? e.salary : 0;
        result.emplace_back(e.employee_id, bonus);
    }
    sort(result.begin(), result.end());
    return result;
}

int main() {
    vector<Employee> employees = {
        {2, "Meir", 3000}, {3, "Michael", 3800}, {7, "Addilyn", 7400},
        {8, "Juan", 6100}, {9, "Kannon", 7700}
    };
    for (const auto& [id, bonus] : calculateSpecialBonus(employees))
        cout << id << ' ' << bonus << '\n';
}
