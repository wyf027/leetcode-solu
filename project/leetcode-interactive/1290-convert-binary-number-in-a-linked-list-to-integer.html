一条只含 0 与 1 的单链表，从头结点开始记录一个二进制数。你的任务，是返回它对应的十进制值。

函数：getDecimalValue(head)结点 ≤ 30空间目标：O(1)非付费题
Problem

题目说明

最高位在链表头部

给定单链表的头结点 head。每个结点的值只能是 0 或 1，整条链表表示一个二进制整数。请返回这个数的十进制值；链表头结点对应最高有效位。

函数参数形式
getDecimalValue(head: ListNode) → integer

示例 1

输入：head = [1,0,1] 输出：5 解释：(101)₂ = (5)₁₀

示例 2

输入：head = [0] 输出：0

约束

  • 链表不为空。
  • 结点总数不超过 30。
  • 每个结点值均为 0 或 1。

注意：链表顺序就是位序，不能先把它当作普通十进制数字理解。

Solution

一次遍历，逐位累积

核心洞察

从左向右读二进制位时，读入一个新位等价于：先把已得到的数整体左移一位（乘 2），再加上当前位。

value = value × 2 + bit

完整过程

  1. 令累积值 value = 0。
  2. 从 head 开始遍历链表。
  3. 对每个结点执行 value = value * 2 + node.val。
  4. 指针后移；遍历结束后返回 value。

正确性证明

循环不变式：处理完前 k 个结点后，value 恰好等于这 k 位组成的二进制前缀的十进制值。

初始时处理 0 位，值为 0，结论成立。若前 k 位成立，下一位为 b，则新前缀值是旧值乘 2 再加 b，更新式正好得到它。因此不变式继续成立。处理全部结点后，value 就是整条链表表示的数。

边界与复杂度

  • 单结点 [0] 返回 0。
  • 前导零不影响更新式。
  • 30 个结点的最大结果为 2³⁰ − 1，符合题目常用整数范围。
  • 时间复杂度：O(n)。
  • 额外空间复杂度：O(1)。

替代方案

位运算：value = (value << 1) | bit，语义与乘 2 加当前位相同。

字符串转换：先收集所有位，再调用进制转换函数；更直观，但需要 O(n) 额外空间，也弱化了链表遍历与位权规律。

常见错误

  • 把头结点误当成最低位。
  • 使用 value += bit，忘记旧前缀需要左移。
  • 先反转链表，造成不必要的修改。
  • 循环中漏写 head = head.next。
  • JavaScript 用位运算时忽略其有符号 32 位语义；本题 30 位约束下安全。

面试追问

如果链表超过机器整数范围？

使用 BigInt、大整数类，或保留二进制字符串，不要压入固定宽度整数。

能否递归处理？

可以先递归到尾部并回传位权，但会使用 O(n) 调用栈；迭代更直接。

如果最低位在头部？

需要同步维护位权 power，累加 bit × power，每步令位权乘 2。

四语言完整实现

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) {
 *         this.val = val;
 *         this.next = next;
 *     }
 * }
 */
class Solution {
    public int getDecimalValue(ListNode head) {
        int value = 0;
        while (head != null) {
            value = value * 2 + head.val;
            head = head.next;
        }
        return value;
    }
}
/**
 * Definition for singly-linked list.
 * function ListNode(val, next) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.next = (next === undefined ? null : next);
 * }
 */
/**
 * @param {ListNode} head
 * @return {number}
 */
var getDecimalValue = function(head) {
    let value = 0;
    while (head !== null) {
        value = value * 2 + head.val;
        head = head.next;
    }
    return value;
};
