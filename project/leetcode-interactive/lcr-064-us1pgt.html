LCR 064 · MEDIUM

实现一个魔法字典

先装载一组小写单词；随后判断查询词能否只替换其中一个字符，变成词典里的某个单词。

题意

设计 MagicDictionary：buildDict 接收字典，search 只在恰好改动一个字符时返回 true。不能不改就命中，也不能改两个字符。

示例

dictionary = ["hello", "leetcode"]
searchWord = "hello"
期望 = false
searchWord = "hhllo"
期望 = true
searchWord = "hell"
期望 = false

约束

字典和查询只含小写英文字母；单词长度及操作次数均不超过 100。

交互实验室

载入后逐个位置观察一次替换。输入有误会清空上一次过程。

载入示例后开始观察。

    测试与验证

    核心洞察

    查询词只可能与同长度单词匹配。逐字符比较并计数：差异恰为 1 才接受；因此无需真的生成所有替换后的字符串。

    完整过程

    1. 按长度把词典分组，避免无意义的比较。
    2. 查询时只遍历相同长度的一组单词。
    3. 从左到右统计不同字符；超过一次立即放弃该候选。
    4. 任一候选的差异恰为一次，返回 true；否则返回 false。

    边界与常见错误

    • 原词存在也应返回 false：这不是“修改”。
    • 长度不同不可能靠一次字符替换得到。
    • 差异计数必须是 恰好 一次，不能用“至多一次”。

    复杂度：设同长度候选数为 n、单词长度为 m，单次查询最坏为 O(nm)，额外空间为 O(1)（不计词典）。替代方案：可将每个位置替换成通配模式并索引；查询更快，但要小心原词命中与模式计数，且占用更多空间。

    面试追问：若查询极多，可使用通配模式索引；若字母表扩大，比较流程不变；若要支持编辑、插入、删除，需要重新定义允许的编辑距离。

    可提交代码

    Java

    class MagicDictionary {
    private String[] words;
    public MagicDictionary() {}
    public void buildDict(String[] dictionary) { words = dictionary; }
    public boolean search(String searchWord) {
        for (String word : words) {
            if (word.length() != searchWord.length()) continue;
            int diff = 0;
            for (int i = 0; i < word.length(); i++) if (word.charAt(i) != searchWord.charAt(i)) diff++;
            if (diff == 1) return true;
        }
        return false;
    }
}

MagicDictionary.prototype.search = function (searchWord) {
  return this.words.some(word => {
    if (word.length !== searchWord.length) return false;
    let diff = 0;
    for (let i = 0; i < word.length; i++) diff += word[i] !== searchWord[i];
    return diff === 1;

    Python

    class MagicDictionary:
    def __init__(self):
        self.words = []

    def buildDict(self, dictionary: List[str]) -> None:
        self.words = dictionary

    def search(self, searchWord: str) -> bool:
        for word in self.words:
            if len(word) == len(searchWord) and sum(a != b for a, b in zip(word, searchWord)) == 1:
                return True
        return False
