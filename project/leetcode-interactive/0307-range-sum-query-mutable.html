Problem brief

题目要求

给定整数数组 nums，实现一个支持单点修改与闭区间求和的数据结构。调用顺序由平台给出，构造函数会先于其余方法执行。

接口定义

  • NumArray(int[] nums)

    用整数数组 nums 初始化对象。

  • void update(int index, int val)

    把 nums[index] 的值更新为 val。

  • int sumRange(int left, int right)

    返回 nums[left] + nums[left + 1] + … + nums[right]。

官方示例

  4. 再次查询 sumRange(0, 2)，返回 8。

约束

1 ≤ nums.length ≤ 3 × 10⁴
-100 ≤ nums[i] ≤ 100
0 ≤ index < nums.length
-100 ≤ val ≤ 100
0 ≤ left ≤ right < nums.length
update 与 sumRange 的调用总数不超过 3 × 10⁴

    核心洞察：把任意区间拆成两个前缀

    sumRange(left, right) = prefix(right + 1) - prefix(left)。难点因此转化为：如何同时让“前缀和查询”和“单点增量更新”都足够快。

    01 / INDEX

    一基索引

    令树状数组下标比原数组大 1，使最低有效位可以直接描述节点覆盖长度。

    02 / LOWBIT

    定位责任区间

    lowbit(x) = x & -x，节点 x 维护长度为 lowbit(x) 的后缀和。

    03 / DELTA

    只传播差值

    更新时计算 delta = val - nums[index]，沿父节点链累加差值。

    完整过程

    1. 初始化：创建长度为 n + 1 的树状数组。依次把每个 nums[i] 当作增量加入位置 i + 1。
    2. 单点更新：先从保存的原数组得到差值，再同步写回原数组；从 index + 1 开始，不断令 i += lowbit(i)，给所有包含该点的节点加上差值。
    3. 前缀查询：从前缀长度 end 开始，累加 tree[end]，再令 end -= lowbit(end)，直至归零。
    4. 区间查询：返回右侧前缀减去左侧之前的前缀，即 prefix(right + 1) - prefix(left)。
    为什么保存原数组？因为接口给的是“把某点设置为 val”，而树状数组天然处理的是“给某点增加 delta”。原数组负责把赋值转换为增量。

    正确性证明

    引理 1：节点区间和始终正确

    初始化把每个元素加入所有覆盖它的节点。更新时，相同节点只增加真实差值，因此每个节点仍等于其责任区间的当前元素和。

    引理 2：prefix(end) 返回前 end 项之和

    每次减去 lowbit(end) 取走一个以 end 结尾的责任区间。这些区间互不重叠，连续覆盖一基区间 [1, end]，因此累加结果完整且无重复。

    定理：sumRange 正确

    prefix(right + 1) 覆盖原数组 [0, right]，减去覆盖 [0, left - 1] 的 prefix(left)，恰好留下 [left, right]。

    复杂度与边界

    初始化O(n log n)
    更新 / 查询O(log n)
    额外空间O(n)

    边界检查

    • 单元素数组：一基索引仍然成立，前缀查询最多访问一个节点。
    • 查询从 0 开始：prefix(left) 此时为 prefix(0) = 0。
    • 负数与零：节点保存代数和，不依赖单调性，可以直接处理。
    • 更新为相同值：差值为 0，结果不变；实现仍然正确。
    • 数值范围：本题最大绝对区间和不超过 3 × 10⁶，32 位有符号整数足够。

    class NumArray {
    private final int[] nums;
    private final int[] tree;

    public NumArray(int[] nums) {
        this.nums = nums.clone();
        this.tree = new int[nums.length + 1];
        for (int i = 0; i < nums.length; i++) {
            add(i + 1, nums[i]);
        }
    }

    public void update(int index, int val) {
        int delta = val - nums[index];
        nums[index] = val;
        add(index + 1, delta);
    }

    public int sumRange(int left, int right) {
        return prefix(right + 1) - prefix(left);
    }

    private void add(int i, int delta) {
        while (i < tree.length) {
            tree[i] += delta;
            i += i & -i;
        }
    }

    private int prefix(int end) {
        int sum = 0;
        while (end > 0) {
            sum += tree[end];
            end -= end & -end;
        }
        return sum;
    }
}

    from typing import List


class NumArray:
    def __init__(self, nums: List[int]):
        self.nums = nums[:]
        self.tree = [0] * (len(nums) + 1)

        for i, value in enumerate(nums):
            self._add(i + 1, value)

    def _add(self, i: int, delta: int) -> None:
        while i < len(self.tree):
            self.tree[i] += delta
            i += i & -i

    def _prefix(self, end: int) -> int:
        total = 0
        while end > 0:
            total += self.tree[end]
            end -= end & -end
        return total

    def update(self, index: int, val: int) -> None:
        delta = val - self.nums[index]
        self.nums[index] = val
        self._add(index + 1, delta)

    def sumRange(self, left: int, right: int) -> int:
        return self._prefix(right + 1) - self._prefix(left)
    #include <vector>
using namespace std;

class NumArray {
private:
    vector<int> nums;
    vector<int> tree;

    void add(int i, int delta) {
        while (i < static_cast<int>(tree.size())) {
            tree[i] += delta;
            i += i & -i;
        }
    }

    int prefix(int end) const {
        int sum = 0;
        while (end > 0) {
            sum += tree[end];
            end -= end & -end;
        }
        return sum;
    }

public:
    NumArray(vector<int>& values)
        : nums(values), tree(values.size() + 1, 0) {
        for (int i = 0; i < static_cast<int>(values.size()); ++i) {
            add(i + 1, values[i]);
        }
    }

    void update(int index, int val) {
        int delta = val - nums[index];
        nums[index] = val;
        add(index + 1, delta);
    }

    int sumRange(int left, int right) const {
        return prefix(right + 1) - prefix(left);
    }
};

    常见错误

    • 把赋值 val 直接加到树上，忘记计算旧值到新值的差值。
    • 混淆零基原数组与一基树状数组，尤其是 right + 1 和 index + 1。
    • 写成 prefix(right) - prefix(left)，导致左右边界都发生偏移。
    • 更新辅助结构后忘记同步保存的 nums[index]，让下一次差值基于旧数据。
    • 查询循环使用 i += lowbit(i) 或更新循环使用减法，方向恰好写反。

    面试追问

    能把初始化优化到 O(n) 吗？

    可以。先令 tree[i] += nums[i - 1]，再把当前节点值累加到 parent = i + lowbit(i)，若 parent 不越界即可。每个节点只传播一次。

    为什么树状数组不直接支持区间最小值？

    区间和存在可逆的“减法”，可由两个前缀得到任意区间。最小值一般没有对应逆运算，删除左侧前缀无法恢复剩余区间的最小值。

    何时应该改用线段树？

    当聚合信息更复杂、需要区间更新、懒标记，或要维护最大子段等组合状态时，线段树更通用。

    怎样支持区间加、单点查？

    维护差分数组的树状数组：对区间 [l, r] 执行 difference[l] += delta 与 difference[r + 1] -= delta，单点值由差分前缀和得到。
