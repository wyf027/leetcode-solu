722. 删除注释Remove Comments

01 / Problem brief

题目要你做什么？

输入是字符串数组 source，每个元素就是源代码的一行。按照从上到下、每行从左到右的阅读顺序，删除第一个生效的注释内容。

行注释由 // 开始，该标记和同一行右侧的所有字符都被忽略。块注释由 /* 开始，直到下一个不重叠的 */ 为止；它可以跨越多行，并会一并删除块内的隐式换行。

注释标记只有在当前上下文允许时才生效：块注释里的 // 与 /* 都只是普通的被忽略字符。像 /*/ 这样的重叠组合不能同时作为开始和结束。

//

删除当前行剩余部分；下一行重新正常读取。

/*

进入块注释；可能跨行，直到遇见非重叠的结束标记。

*/

只在块注释中有效；退出后继续读取同一物理行的剩余字符。

返回规则

保持按行数组的格式；注释删除后为空字符串的行不加入答案。

没有单双引号和控制字符；每个开启的块注释最终都会闭合，宏等内容不会干扰。

State machine

用一个跨行状态，完成一次线性扫描

真正需要跨行保存的只有两件事：当前是否位于块注释中，以及块开始前已经收集但尚未提交的代码缓冲区。

核心洞察

把输入看成带有物理换行的字符流。扫描器只有 NORMAL 与 IN_BLOCK 两种状态；// 不需要成为跨行状态，因为它只影响当前行。

状态优先级

  1. 块内只检查 */。
  2. 块外先识别 /* 与 //。
  3. 否则把当前字符加入缓冲区。

什么时候清空缓冲区？

只有在一条新的、且起点不处于块注释中的物理行开始时清空。若上一行仍在块内，就必须保留块开始前的前缀，等待后续后缀接上。

什么时候提交结果？

一条物理行扫描结束时，如果不在块注释中且缓冲区非空，就把它加入答案。空字符串永远不输出，但空格组成的字符串并不为空。

关键例子： ["a/*x", "y*/b"] 的第一行结束时仍在块内，所以不能提交 "a"；第二行退出块后补上 "b"，最终提交 "ab"。

完整过程

  1. 维护布尔量 inBlock、当前输出行缓冲区 buffer 和结果数组 answer。
  2. 逐行扫描。若进入当前行时不在块注释中，先清空缓冲区；否则保留跨行块开始前的内容。
  3. 块外遇到 // 时直接停止本行；遇到 /* 时进入块并跳过两个字符。
  4. 块内仅在遇到 */ 时退出块并跳过两个字符，其他字符全部忽略。
  5. 普通字符只在块外加入缓冲区。本行结束且已回到块外时，若缓冲区非空就提交。

正确性证明

扫描不变量：处理到任意位置前，inBlock 精确表示该位置是否位于尚未闭合的块注释内；buffer 恰好包含当前逻辑输出行中已经扫描、且不属于任何注释的字符。

保持：块外遇到普通字符时加入缓冲区；遇到 // 后本行余下全属于行注释；遇到 /* 后切换为块内。块内字符均被忽略，只有非重叠的 */ 能切回块外。每种转移都与题目定义一致，所以不变量保持。

换行：块外的物理换行结束一个逻辑输出行，因此提交非空缓冲区；块内换行属于被块注释删除的内容，因此既不提交也不清空，正确连接开始前的前缀与结束后的后缀。

终止：所有字符被处理后，题目保证块注释已闭合。由不变量，答案包含且仅包含所有未被注释覆盖的字符，并按规则排除了空字符串，故算法正确。

边界情况

  • 整行都是行注释或块注释：不输出空行。
  • 注释前只有空格：空格仍是有效字符，应保留。
  • /*/：开头占用前两个字符，最后的 / 不能与其重叠构成结束。
  • 块内出现 // 或新的 /*：全部忽略。
  • 同一行先结束块，再出现代码或行注释：退出后继续扫描。

复杂度

设所有输入行的字符总数为 N。每个字符最多被常数次查看。

时间 O(N) 额外空间 O(N)

额外空间包含返回结果与当前缓冲区；若不计输出，工作空间为最长逻辑输出行的长度。

替代方案

先拼成一个大字符串：可以统一按字符流处理，但之后仍要正确恢复未被块注释吞掉的换行，状态并不会消失，且额外构造整段文本。

正则表达式：单独处理 //.* 看似简单，但跨行块、标记优先级、非重叠 /*/ 与换行删除让单个正则既难读又容易出错。两状态扫描器更直接、可证明。

四种语言完整代码

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> removeComments(String[] source) {
        List<String> answer = new ArrayList<>();
        StringBuilder buffer = new StringBuilder();
        boolean inBlock = false;

        for (String line : source) {
            if (!inBlock) {
                buffer.setLength(0);
            }

            int i = 0;
            while (i < line.length()) {
                if (inBlock) {
                    if (i + 1 < line.length()
                            && line.charAt(i) == '*'
                            && line.charAt(i + 1) == '/') {
                        inBlock = false;
                        i += 2;
                    } else {
                        i++;
                    }
                } else if (i + 1 < line.length()
                        && line.charAt(i) == '/'
                        && line.charAt(i + 1) == '*') {
                    inBlock = true;
                    i += 2;
                } else if (i + 1 < line.length()
                        && line.charAt(i) == '/'
                        && line.charAt(i + 1) == '/') {
                    break;
                } else {
                    buffer.append(line.charAt(i));
                    i++;
                }
            }

            if (!inBlock && buffer.length() > 0) {
                answer.add(buffer.toString());
            }
        }

        return answer;
    }
}

from typing import List


class Solution:
    def removeComments(self, source: List[str]) -> List[str]:
        answer: List[str] = []
        buffer: List[str] = []
        in_block = False

        for line in source:
            if not in_block:
                buffer = []

            i = 0
            while i < len(line):
                if in_block:
                    if i + 1 < len(line) and line[i:i + 2] == "*/":
                        in_block = False
                        i += 2
                    else:
                        i += 1
                elif i + 1 < len(line) and line[i:i + 2] == "/*":
                    in_block = True
                    i += 2
                elif i + 1 < len(line) and line[i:i + 2] == "//":
                    break
                else:
                    buffer.append(line[i])
                    i += 1

            if not in_block and buffer:
                answer.append("".join(buffer))

        return answer

常见错误

  • 每到新物理行都清空缓冲区，导致跨行块两侧不能拼接。
  • 一看到 // 就截断，即使它位于块注释中。
  • 把只含空格的结果误判为空行。
  • 结束块后直接结束本行，漏掉 */ 后面的代码。
  • 匹配标记后只移动一个字符，错误制造重叠匹配。

实现检查清单

  • 访问双字符标记前检查 i + 1 边界。
  • 识别标记后一次跳过两个字符。
  • 块内与块外使用不同的判定顺序。
  • 只在块外行尾提交非空缓冲区。

面试追问

如果输入可能包含字符串字面量呢？

需要增加字符串与转义状态，使 //、/* 在字符串内部不生效；字符字面量也要独立处理。

可以流式处理超大文件吗？

可以。状态和缓冲区天然跨行保存；逐行读取、逐行产出即可，工作内存取决于最长逻辑输出行。

为什么不支持嵌套块注释？

题目按 C++ 注释语义，块注释不嵌套。若题目要求嵌套，可把布尔状态改成深度计数器。

怎样返回原始位置映射？

缓冲字符旁同步保存其行列坐标；提交时把文本与坐标序列一并输出。
