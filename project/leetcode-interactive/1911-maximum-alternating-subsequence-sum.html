1911. 最大交替子序列和

Maximum Alternating Subsequence Sum MEDIUM

保留相对顺序，重新编号，再计算正负交替的和。

题目

给定正整数数组 nums。你可以删除任意位置的元素，但不能改变保留元素的相对顺序。将得到的子序列从 0 重新编号：偶数位置相加，奇数位置相减。返回所有子序列中最大的交替和。

例如 [4,2,5,3] 的交替和是 4 − 2 + 5 − 3 = 4。符号取决于子序列的新位置，不是原数组下标；子序列也不要求连续。

参数：nums: integer[]；返回：最大交替和（长整数语义）。

约束：1 ≤ nums.length ≤ 105；1 ≤ nums[i] ≤ 105。

官方题目

官方示例

示例 1

输入：nums = [4,2,5,3]
输出：7

选取 [4,2,5]，得到 4 − 2 + 5 = 7。

示例 2

输入：nums = [5,6,7,8]
输出：8

只选 [8] 即可。

示例 3

输入：nums = [6,2,1,2,4,5]
输出：10

选取 [6,1,5]，得到 6 − 1 + 5 = 10。

题解 · 两条奇偶状态轨道

核心洞察

下一次选取的符号，只依赖已经选了奇数个还是偶数个元素。用 O 表示选了奇数个元素的最大和（末项为正），E 表示选了偶数个元素的最大和（末项为负，包含空序列）。

初始：O = −∞，E = 0
读取 x 时（右侧均使用旧状态）：
newO = max(O, E + x)
newE = max(E, O − x)

每条轨道可以“留在原地”：跳过 x；也可以从另一条轨道转入：选取 x，并按新位置加或减。最终返回 O。

交互 · 前缀扫描与轨道转移

黄色为最近处理的数字；两条轨道保留各自最优值。开启减少动态效果偏好时，仍可手动逐步操作。


完整过程
对 [4,2,5,3]，初始 (O,E) = (−∞,0)。读入 4 后为 (4,0)，读入 2 后为 (4,2)，读入 5 后为 (7,2)，读入 3 后为 (7,4)。最终 O = 7，对应 [4,2,5]。最后的 3 虽然改善偶数状态，但没有改善答案。
正确性
归纳不变量：处理完任意前缀后，O 与 E 分别是该前缀内相应长度奇偶性的最优交替和。空前缀仅有空序列，因此初始化成立。任意新子序列要么不选 x，继承旧状态；要么选 x，其去掉末项后必属于相反奇偶状态，因此候选分别为 E+x 与 O−x。取最大值覆盖全部情况，并且每个候选都可构造，所以不变量保持。
所有数字为正。任何非空偶数长度子序列的末项都被减去，删除该末项会严格提高交替和。因此最优答案一定可以取奇数长度，返回 O 正确。
边界与复杂度
单元素直接得到它本身；全相等或单调下降时只选最大值；上升序列只选最后的最大值。时间 O(n)，额外空间 O(1)。答案可能超过 32 位：Java 用 long，C++ 用 long long；JavaScript Number 对此题不超过 10¹⁰ 的整数范围可精确表示。
替代方案
利用正整数条件，还可以用贪心：答案为 nums[0] + Σ max(0, nums[i] − nums[i−1])。把每段上涨的差值累加，可合并成峰值减谷值的交替选择；下降段用于分开相邻上涨段。状态 DP 对推广到不同约束更直观；保存每一步的前驱可恢复实际子序列，但需要 O(n) 空间。
常见错误
  • 按原数组下标分配正负号。
  • 把子序列误当作连续子数组。
  • 将“奇数长度”与“奇数下标”混淆：奇数长度的末项下标是偶数。
  • 覆盖旧状态后继续使用它；用临时变量明确同时转移。
  • 使用 32 位整数累计答案。
面试追问
允许负数时怎么办？仍可用严格奇偶状态，但最后应比较 O 与 E，并明确是否允许空序列；不能继续使用正数下的奇数长度结论。要求输出所选下标时怎么办？记录状态转移前驱，再从最终状态回溯。要求恰好选 k 个时怎么办？增加所选数量维度，做 O(nk) 动态规划。


四语言可提交代码
四份代码均使用上述严格奇偶状态；以第一个元素初始化，避免整数负无穷哨兵。


Java
class Solution {
    public long maxAlternatingSum(int[] nums) {
        long odd = nums[0], even = 0;
        for (int i = 1; i < nums.length; i++) {
            long x = nums[i];
            long nextOdd = Math.max(odd, even + x);
            long nextEven = Math.max(even, odd - x);
            odd = nextOdd;
            even = nextEven;
        }
        return odd;
    }
}

Python
from typing import List

class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        odd, even = nums[0], 0
        for i in range(1, len(nums)):
            x = nums[i]
            odd, even = max(odd, even + x), max(even, odd - x)
        return odd
