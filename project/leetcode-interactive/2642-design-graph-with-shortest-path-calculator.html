返回两点间最低代价；不可达返回 -1。

Editorial

邻接表 + 朴素 Dijkstra

核心洞察完整过程正确性复杂度四语言代码面试追问

核心洞察

所有边权均为正数，所以每次查询都可以从 node1 出发执行 Dijkstra。n ≤ 100，直接线性扫描未确定节点即可找到当前距离最小者，不需要手写堆；加边只需追加到邻接表。

关键取舍：约束很小，O(n² + m) 的单次查询简单且足够；设计题里，可靠的状态更新比复杂的数据结构更重要。

完整过程

  1. 构造时建立邻接表：对每条 [u,v,w] 保存 (v,w)。
  2. addEdge 将新边直接追加到 u 的出边列表。
  3. 查询时令源点距离为 0，其余为无穷大。
  4. 重复至多 n 次：在线性扫描中选择尚未确定且距离最小的节点 x。
  5. 若找不到 x，目标不可达；若 x 正是终点，当前距离就是答案。
  6. 将 x 标记为确定，并用它的所有出边松弛相邻节点。

正确性

  1. 不变式：每次选择节点前，dist[v] 是已发现的从源点到 v 的最小路径代价；对所有已确定节点，该值已是全局最短距离。
  2. 贪心安全性：设当前未确定节点中 x 的距离最小。若存在更短路径到 x，该路径上从已确定集合离开的第一个节点会拥有更小的候选距离，与 x 最小矛盾。正边权保证后续绕行无法降低已确定距离。
  3. 松弛完备性：确定 x 后检查它的每条出边，因此所有以 x 为倒数第二个节点的候选路径都会被纳入。
  4. 结论：终点被选中时其距离已是最短路径代价；若再也选不到有限距离节点，则不存在从源点到终点的路径，返回 -1。

边界情况

  • node1 == node2：空路径代价为 0。
  • 源点没有出边或图不连通：扫描耗尽后返回 -1。
  • 新增边只影响之后的查询；邻接表必须是对象的持久状态。
  • 路径和可能大于单条边权，Java/C++ 内部距离用 64 位整数更稳妥。

复杂度

构造O(n + m)
加边O(1)
单次查询O(n² + m)

空间复杂度为 O(n + m)，查询额外使用 O(n)。

替代方案

最小堆 Dijkstra：把线性选点替换为优先队列，查询降为 O((n+m) log n)，适合节点更多、图较稀疏时。

动态 Floyd：初始化全源最短路 O(n³)，查询 O(1)；加入 u→v、权重 w 后，可用 dist[i][u] + w + dist[v][j] 在 O(n²) 更新所有点对。查询远多于加边时值得考虑。

四语言完整代码

均采用同一套邻接表与朴素 Dijkstra 逻辑。

Java 
class Graph {
    private final java.util.List<int[]>[] graph;

    @SuppressWarnings("unchecked")
    public Graph(int n, int[][] edges) {
        graph = new java.util.ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new java.util.ArrayList<>();
        for (int[] edge : edges) addEdge(edge);
    }

    public void addEdge(int[] edge) {
        graph[edge[0]].add(new int[]{edge[1], edge[2]});
    }

    public int shortestPath(int node1, int node2) {
        int n = graph.length;
        long[] dist = new long[n];
        java.util.Arrays.fill(dist, Long.MAX_VALUE);
        boolean[] used = new boolean[n];
        dist[node1] = 0;

        for (int round = 0; round < n; round++) {
            int x = -1;
            for (int i = 0; i < n; i++)
                if (!used[i] && (x == -1 || dist[i] < dist[x])) x = i;
            if (x == -1 || dist[x] == Long.MAX_VALUE) return -1;
            if (x == node2) return (int) dist[x];
            used[x] = true;
            for (int[] edge : graph[x]) {
                int to = edge[0], cost = edge[1];
                dist[to] = Math.min(dist[to], dist[x] + cost);
            }
        }
        return -1;
    }
}

var Graph = function(n, edges) {
    this.graph = Array.from({ length: n }, () => []);
    for (const edge of edges) this.addEdge(edge);
};

Graph.prototype.addEdge = function([from, to, cost]) {
    this.graph[from].push([to, cost]);
};

Graph.prototype.shortestPath = function(node1, node2) {
    const n = this.graph.length;
    const dist = Array(n).fill(Infinity);
    const used = Array(n).fill(false);
    dist[node1] = 0;

    for (let round = 0; round < n; round++) {
        let x = -1;
        for (let i = 0; i < n; i++) {
            if (!used[i] && (x === -1 || dist[i] < dist[x])) x = i;
        }
        if (x === -1 || dist[x] === Infinity) return -1;
        if (x === node2) return dist[x];
        used[x] = true;
        for (const [to, cost] of this.graph[x]) {
            dist[to] = Math.min(dist[to], dist[x] + cost);
        }
    }
    return -1;
};
Python 3 
from typing import List


class Graph:
    def __init__(self, n: int, edges: List[List[int]]):
        self.graph = [[] for _ in range(n)]
        for edge in edges:
            self.addEdge(edge)

    def addEdge(self, edge: List[int]) -> None:
        source, target, cost = edge
        self.graph[source].append((target, cost))

    def shortestPath(self, node1: int, node2: int) -> int:
        n = len(self.graph)
        dist = [float("inf")] * n
        used = [False] * n
        dist[node1] = 0

        for _ in range(n):
            candidates = (i for i in range(n) if not used[i])
            current = min(candidates, key=dist.__getitem__)
            if dist[current] == float("inf"):
                return -1
            if current == node2:
                return dist[current]
            used[current] = True
            for target, cost in self.graph[current]:
                dist[target] = min(dist[target], dist[current] + cost)
        return -1
C++ 
class Graph {
    std::vector<std::vector<std::pair<int, int>>> graph;

public:
    Graph(int n, std::vector<std::vector<int>>& edges) : graph(n) {
        for (const auto& edge : edges) addEdge(edge);
    }

    void addEdge(std::vector<int> edge) {
        graph[edge[0]].push_back({edge[1], edge[2]});
    }

    int shortestPath(int node1, int node2) {
        int n = graph.size();
        const long long INF = std::numeric_limits<long long>::max();
        std::vector<long long> dist(n, INF);
        std::vector<bool> used(n, false);
        dist[node1] = 0;

        for (int round = 0; round < n; ++round) {
            int x = -1;
            for (int i = 0; i < n; ++i)
                if (!used[i] && (x == -1 || dist[i] < dist[x])) x = i;
            if (x == -1 || dist[x] == INF) return -1;
            if (x == node2) return static_cast<int>(dist[x]);
            used[x] = true;
            for (auto [to, cost] : graph[x])
                dist[to] = std::min(dist[to], dist[x] + cost);
        }
        return -1;
    }
};

面试追问

  • 如果查询有十万次？ 比较动态 Floyd、缓存源点结果或更复杂的动态最短路。
  • 如果允许负边？ Dijkstra 不再成立，可考虑 Bellman–Ford；若有负环，还需定义答案语义。
  • 如果支持删除边？ 当前增量更新思路不足，需要失效缓存或重新计算受影响路径。
  • 为何能在终点被选中时提前返回？ 因为它此时已是所有未确定节点中距离最小者，正权条件保证该值不会再下降。

常见错误

  • 把图当成无向图，同时加入反向边。
  • 每次查询后没有重置 dist 和 used。
  • 新增边只改了局部变量，没有写入对象持久状态。
  • 不可达时返回无穷大而不是 -1。
  • 用 32 位距离累加更大约束下的路径，造成溢出。
