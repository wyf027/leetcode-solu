LeetCode 715 · Range Module

Range 模块

维护一组连续的实数范围，并回答一个半开区间是否被完整覆盖。关键不是记录点，而是精确处理区间的合并、切割与边界。

非会员题最多 10⁴ 次调用坐标上限 10⁹
Problem

题目要求

设计 RangeModule，跟踪若干由实数组成的范围。范围统一表示成半开区间 [left, right)，也就是包含 left、不包含 right。

这个数据结构要支持添加一段范围、查询一段范围是否每一点都已被跟踪，以及停止跟踪一段范围。

addRange(left, right)

添加 [left, right) 中尚未被跟踪的所有实数。

queryRange(left, right)

仅当整个 [left, right) 都被跟踪时返回 true。

removeRange(left, right)

停止跟踪 [left, right) 内当前已跟踪的所有实数。

RangeModule()

初始化一个尚未跟踪任何范围的对象。

Contract

约束与边界

半开区间的端点语义

删除 [14, 16) 会移除 14，但不会移除 16。相邻的 [10, 14) 与 [14, 20) 可以无缝合并。

  • 1 ≤ left < right ≤ 10⁹
  • addRange、queryRange 与 removeRange 的调用总数不超过 10⁴。
  • 区间描述的是实数范围，不能用逐点枚举处理。

Full solution

维护排序且互不相交的区间

核心洞察

任何时刻，都把已跟踪范围压缩成一组按左端点升序、彼此不重叠也不相邻的半开区间。这样，查询只需找到“左端点不大于查询左端点”的最后一个区间；添加负责合并，删除负责保留两侧残片。

完整过程

  1. 添加：跳过完全在左侧的区间；把所有与新区间重叠或相邻的区间并入新区间；在越过新区间前插入合并结果。
  2. 查询：二分找到最后一个满足 start ≤ left 的区间，检查其 end ≥ right。
  3. 删除：与删除范围无交集的区间原样保留；有交集时，分别保留可能存在的 [start,left) 和 [right,end)。

边界处理

  • end == left 或 start == right 表示半开区间不相交。
  • 添加时，相邻区间可以合并；删除时，相邻于删除范围的区间不应被裁剪。
  • 一次删除可能把一个区间切成左右两个区间。
  • 坐标可达 10⁹，但只保存端点，不按坐标开数组。

正确性证明

1

表示不变量

初始列表为空，显然有序且互不相交。添加会把所有重叠或相邻区间合成唯一并集；删除仅输出原区间未被删去的左右残片。因此每次操作后不变量仍成立。

2

更新正确

添加保留所有旧区间并加入新区间中的每一点；删除保留且仅保留旧区间落在删除范围外的部分。所以更新后的区间并集与题意要求完全相同。

3

查询正确

在互不相交的有序表示中，若 [left,right) 被完整覆盖，它必然全部落在左端点不大于 left 的最后一个区间里；反过来该区间右端点达到 right 就足以覆盖查询。

复杂度

以下四份实现都用动态数组保存至多 n 个区间：查询二分为 O(log n)；添加和删除需要扫描并重建数组，为 O(n)；空间为 O(n)。

替代方案

  • 平衡树 / TreeMap：只访问受影响的 k 个区间，更新可做到 O((k+1) log n)。
  • 动态开点线段树：适合坐标范围巨大且操作密集的场景，单次约 O(log C)，但实现更复杂、常数更大。
  • 端点有序集合：用端点奇偶性表达覆盖状态，代码紧凑但边界推理更易出错。

import java.util.*;

class RangeModule {
    private List<int[]> ranges;

    public RangeModule() {
        ranges = new ArrayList<>();
    }

    public void addRange(int left, int right) {
        List<int[]> next = new ArrayList<>();
        boolean inserted = false;

        for (int[] range : ranges) {
            if (range[1] < left) {
                next.add(range);
            } else if (right < range[0]) {
                if (!inserted) {
                    next.add(new int[]{left, right});
                    inserted = true;
                }
                next.add(range);
            } else {
                left = Math.min(left, range[0]);
                right = Math.max(right, range[1]);
            }
        }
        if (!inserted) next.add(new int[]{left, right});
        ranges = next;
    }

    public boolean queryRange(int left, int right) {
        int lo = 0, hi = ranges.size() - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (ranges.get(mid)[0] <= left) lo = mid + 1;
            else hi = mid - 1;
        }
        return hi >= 0 && ranges.get(hi)[1] >= right;
    }

    public void removeRange(int left, int right) {
        List<int[]> next = new ArrayList<>();
        for (int[] range : ranges) {
            if (range[1] <= left || range[0] >= right) {
                next.add(range);
                continue;
            }
            if (range[0] < left) next.add(new int[]{range[0], left});
            if (range[1] > right) next.add(new int[]{right, range[1]});
        }
        ranges = next;
    }
}

from bisect import bisect_right

class RangeModule:
    def __init__(self):
        self.ranges = []

    def addRange(self, left: int, right: int) -> None:
        next_ranges = []
        inserted = False

        for start, end in self.ranges:
            if end < left:
                next_ranges.append([start, end])
            elif right < start:
                if not inserted:
                    next_ranges.append([left, right])
                    inserted = True
                next_ranges.append([start, end])
            else:
                left = min(left, start)
                right = max(right, end)

        if not inserted:
            next_ranges.append([left, right])
        self.ranges = next_ranges

    def queryRange(self, left: int, right: int) -> bool:
        starts = [interval[0] for interval in self.ranges]
        index = bisect_right(starts, left) - 1
        return index >= 0 and self.ranges[index][1] >= right

    def removeRange(self, left: int, right: int) -> None:
        next_ranges = []
        for start, end in self.ranges:
            if end <= left or start >= right:
                next_ranges.append([start, end])
                continue
            if start < left:
                next_ranges.append([start, left])
            if end > right:
                next_ranges.append([right, end])
        self.ranges = next_ranges
#include <algorithm>
#include <utility>
#include <vector>
using namespace std;

class RangeModule {
private:
    vector<pair<int, int>> ranges;

public:
    RangeModule() = default;

    void addRange(int left, int right) {
        vector<pair<int, int>> next;
        bool inserted = false;

        for (auto [start, end] : ranges) {
            if (end < left) {
                next.push_back({start, end});
            } else if (right < start) {
                if (!inserted) {
                    next.push_back({left, right});
                    inserted = true;
                }
                next.push_back({start, end});
            } else {
                left = min(left, start);
                right = max(right, end);
            }
        }
        if (!inserted) next.push_back({left, right});
        ranges = move(next);
    }

    bool queryRange(int left, int right) {
        int lo = 0, hi = static_cast<int>(ranges.size()) - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (ranges[mid].first <= left) lo = mid + 1;
            else hi = mid - 1;
        }
        return hi >= 0 && ranges[hi].second >= right;
    }

    void removeRange(int left, int right) {
        vector<pair<int, int>> next;
        for (auto [start, end] : ranges) {
            if (end <= left || start >= right) {
                next.push_back({start, end});
                continue;
            }
            if (start < left) next.push_back({start, left});
            if (end > right) next.push_back({right, end});
        }
        ranges = move(next);
    }
};

常见错误

  • 混淆 < 和 <=，错误删除右端点或遗漏相邻合并。
  • 查询只检查端点，而没有确认中间不存在空洞。
  • 删除覆盖区间内部时只保留一侧，漏掉另一侧残片。
  • 原地遍历同时修改容器，导致迭代器失效或跳过元素。
