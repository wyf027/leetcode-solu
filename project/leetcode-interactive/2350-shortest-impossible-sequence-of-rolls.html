最短骰子序列

Shortest Impossible Sequence of Rolls

有些顺序，出现过所有数字也拼不出来。
先理解“子序列”，再寻找最短的缺失长度。

01 / 题目

给定整数数组 rolls 和整数 k。数组记录了一个面值为 1…k 的骰子投掷 n 次的结果。考虑所有由这些面值组成的有限序列：返回其中无法成为 rolls 子序列的序列的最短长度。

子序列可以跳过元素，但不能改变先后顺序。例如 [1,2,1] 能取出 [2,1]，却不能取出 [2,2]。题目返回长度，不要求返回具体序列。

参数与约束

  • shortestSequence(rolls, k) → integer
  • n == rolls.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ rolls[i] ≤ k ≤ 10⁵

02 / 官方示例

示例 1

输入：rolls = [4,2,1,2,3,3,2,4,1], k = 4
输出：3

长度 1 和长度 2 的所有可能序列都能取出；[1,4,2] 无法取出，因此最短缺失长度是 3。

示例 2

输入：rolls = [1,1,2,2], k = 2
输出：2

[1] 和 [2] 都存在，但第一个 2 后面没有 1，无法取出 [2,1]。

示例 3

输入：rolls = [1,1,3,2,2,2,3,3], k = 4
输出：1

面值 4 从未出现，单元素序列 [4] 已经无法取出。

04 / 推导与交互实验

准备好后，展开分步可视化、正确性证明和四语言代码。

核心洞察：每凑齐一套面值，就多保证一层

从左到右扫描，把数组贪心切成尽可能短的完整段：每段都包含 1…k。每凑齐一次，就清空当前集合，开始下一段。设完整段数为 m，则答案是 m + 1。

任意长度为 m 的目标序列，都能从第 1 段取第 1 个值、第 2 段取第 2 个值……因为每段都含全部面值，而且段与段的先后顺序天然正确。

完整过程

  1. 初始化空集合 seen，令 answer = 1。
  2. 依次把 rolls 中每个面值加入集合；重复出现的值不增加集合大小。
  3. 如果 seen.size == k，说明当前段完整：答案加 1，集合清空。
  4. 扫描结束，返回 answer。结尾未凑齐的部分不增加完整段数。
rolls = [4,2,1,2,3 | 3,2,4,1], k = 4

第二段在下标 8 收齐：完整段数 2
剩余后缀为空：答案 2 + 1 = 3

正确性：下界与上界必须同时成立

① 长度不超过 m 的序列都存在

每个完整段都有全部 k 种值。对任意长度 ℓ ≤ m 的序列，从前 ℓ 个完整段各取一个对应值，就得到有序的匹配。因此缺失序列的长度至少是 m + 1。

② 构造一个长度 m + 1 的缺失序列

记第 j 段的终点为 eⱼ，终点面值为 cⱼ。贪心在“首次凑齐”时切段，所以 cⱼ 在本段终点之前从未出现。依次匹配 c₁、c₂、…、cₘ 时，最早能到达的位置恰好是 e₁、e₂、…、eₘ。

最后的剩余后缀不完整，选取它缺少的一个面值 x。序列 [c₁,c₂,…,cₘ,x] 无法匹配：前 m 个值最早也只能匹配到 eₘ，之后却没有 x。任何更晚的匹配都不会有更多选择。因此确实存在长度 m + 1 的缺失序列。

两边合起来：最短缺失长度恰好等于 m + 1。m = 0 时，直接取整个数组缺少的面值即可。

边界与复杂度

  • k = 1：每次投掷都构成完整段，答案为 n + 1。
  • 某面完全缺失：一个完整段也没有，答案为 1；k > n 也一定如此。
  • 重复值很多：集合去重，段内重复不会产生额外“层”。
  • 恰好在末尾凑齐：该段仍然计数；空后缀缺少全部面值，答案照常加 1。
  • 空数组：不在官方输入范围内；本页输入会拒绝。

以下四份代码使用哈希集合，期望时间 O(n)，额外空间 O(k)（更紧为 O(min(n,k))）。清空的总元素数不超过累计插入次数，因此总计仍为线性；这里的时间结论以哈希操作平均 O(1) 为前提。

答案上界为 ⌊n / k⌋ + 1，在约束内使用普通整数即可。

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int shortestSequence(int[] rolls, int k) {
        Set<Integer> seen = new HashSet<>();
        int answer = 1;
        for (int value : rolls) {
            seen.add(value);
            if (seen.size() == k) {
                answer++;
                seen.clear();
            }
        }
        return answer;
    }
}

class Solution {

    int shortestSequence(vector<int>& rolls, int k) {
        unordered_set<int> seen;
        int answer = 1;
        for (int value : rolls) {
            seen.insert(value);
            if (seen.size() == static_cast<size_t>(k)) {
                ++answer;
                seen.clear();
            }
        }
        return answer;
    }
};

替代方案

  • 轮次标记数组：使用长度 k + 1 的数组记录各面值最近属于哪个段，再维护当前种类数。切段时只递增轮次，免去清空。初始化 O(k)，总时间 O(n + k)，空间 O(k)，可避开哈希平均性能假设。
  • 枚举目标序列：从短到长枚举 kˡ 个候选，再用双指针判断子序列。适合极小规模人工理解；候选数量指数增长，无法处理官方规模。
  • 按面值统计频次：不能替代顺序扫描。[1,1,2,2] 的两个值各出现两次，但 [2,1] 已缺失。

常见错误

  • 把子序列当成连续子数组，使用普通固定窗口。
  • 按读取了 k 个元素切段；应按出现了 k 种不同面值切段。
  • 凑齐后不清空集合，导致后续每个元素都重复增加答案。
  • 返回完整段数 m，遗漏最终的 +1。
  • 只证明“所有长度 m 都存在”，却没有证明“长度 m + 1 一定有缺失”。

面试追问

如何返回一个具体缺失序列？
记录每段终点面值，再追加最终后缀缺少的面值；上面的上界证明就是构造方法。
能否流式处理？
可以。仅维护当前集合和完整段数；每接收一个值，都能给出当前前缀的答案。
为什么尽早切段不会损失最优性？
任何完整第一段都不可能早于首次收齐的位置。提前结束只会给后面留下更多元素；并且这一定义让终点面值构造的最早匹配位置可被精确证明。
