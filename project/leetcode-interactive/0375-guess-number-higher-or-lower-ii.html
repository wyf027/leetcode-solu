01 · Game brief

你要买的，是“最坏情况保险”

对手先在闭区间 [1, n] 中选定一个整数。每轮你猜一个数；猜对立即获胜且不付费，猜错则支付本次猜测值，并获知秘密数字更大还是更小。

规则

  1. 秘密数字始终位于当前候选区间内。
  2. 若猜测 x 错误，支付 x 元，再按“更大 / 更小”缩小区间。
  3. 若猜测正确，该轮不产生费用。

目标

给定整数 n，返回无论对手选择哪个秘密数字，都能保证获胜的最小现金数。

注意：“保证”意味着优化所有分支中的最大损失，而不是平均损失。

官方示例

01主示例
输入n = 10
输出16

一种最优开局先猜 7。向上分支再猜 9，最坏支付 7 + 9 = 16；向下分支也能把最坏费用控制在 16，因此 16 足以保证获胜，且无法用更少现金覆盖所有情况。

02边界
输入n = 1
输出0

唯一可能值是 1，直接猜中，不会因猜错而付费。

03最小博弈
输入n = 2
输出1

先猜 1：猜错最多支付 1，随后秘密数字只能是 2。

04 · Full solution

区间动态规划：把最坏分支压到最低

核心洞察

设 dp[l][r] 为秘密数字位于 [l, r] 时，保证获胜所需的最少现金。若首猜 x，猜错立即支付 x；对手会让游戏进入左右子区间中成本更高的一侧。

dp[l][r] = min₍l≤x≤r₎ { x + max(dp[l][x−1], dp[x+1][r]) }

边界：当 l ≥ r 时，至多只剩一个数字，可以直接猜中，因此费用为 0。

完整过程

  1. 定义状态。 用闭区间的两端点唯一描述尚未排除的秘密数字集合。
  2. 枚举首猜。 对当前区间内每个 x，计算“本次错误费用 + 两侧较大子问题”。
  3. 选择最稳策略。 在所有 x 中取总成本最小者。
  4. 按长度填表。 从长度 2 递增到 n，确保转移依赖的短区间已经求出。
  5. 读取答案。 最终返回 dp[1][n]。

正确性证明

命题：dp[l][r] 等于区间 [l,r] 上保证获胜的最小费用。

基础情形：l ≥ r 时无须承担猜错费用，状态值 0 正确。

归纳步骤：假设所有更短区间的状态都正确。任取首猜 x，若猜错必须支付 x，随后对手可选择左右两个可行分支中成本更高者，所以该首猜保证获胜的成本恰为 x + max(left, right)。算法枚举所有可能首猜并取最小值，因此既覆盖全部策略，又选出最小的最坏成本。由区间长度归纳，命题成立；故 dp[1][n] 是答案。

边界与复杂度

  • n = 1：答案为 0。
  • 空区间和单点区间都按 0 处理，转移时无需额外分支判断。
  • 答案在 n ≤ 200 范围内可安全使用普通整数类型。
  • 时间复杂度：O(n³)，区间数为 O(n²)，每个区间枚举 O(n) 个首猜。
  • 空间复杂度：O(n²)。

class Solution {
    public int getMoneyAmount(int n) {
        int[][] dp = new int[n + 2][n + 2];

        for (int length = 2; length <= n; length++) {
            for (int left = 1; left + length - 1 <= n; left++) {
                int right = left + length - 1;
                dp[left][right] = Integer.MAX_VALUE;

                for (int guess = left; guess <= right; guess++) {
                    int lowerCost = dp[left][guess - 1];
                    int higherCost = dp[guess + 1][right];
                    int worstCost = guess + Math.max(lowerCost, higherCost);
                    dp[left][right] = Math.min(dp[left][right], worstCost);
                }
            }
        }

        return dp[1][n];
    }
}

替代方案

  • 自顶向下记忆化：递归定义更贴近博弈过程，复杂度同为 O(n³)，但有函数调用开销。
  • 朴素递归：重复计算大量区间，会指数爆炸，不适用于本题范围。
  • 普通二分：优化猜测次数而非带权费用；猜大数更贵，因此不保证最优。

面试追问

  • 若目标改为最小化期望费用，如何按分支概率重写转移？
  • 若每个数字的猜错成本由数组给出，状态和转移是否改变？
  • 能否利用最优决策的结构，减少首猜枚举范围？需要怎样证明？

常见错误

  • 把左右分支相加，而不是取 max。
  • 猜错成本误写成秘密数字，而不是本次猜测 x。
  • 按区间起点填表，导致所依赖的短区间尚未计算。
  • 把“猜中”也计费，令单点区间错误地大于 0。
