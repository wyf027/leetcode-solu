PROBLEM BRIEF

柱宽均为 1，雨后能存多少水？

给定非负整数数组 height 表示高程图，每根柱子的宽度为 1。返回下雨后这些柱子之间能够储存的水量。

单格公式

water[i] = min(leftMax, rightMax) - height[i]

双指针的关键不是改变公式，而是只维护“当前可确定的一侧”。

    CORE INSIGHT

    较矮一侧先结算

    若 height[left] ≤ height[right]，右侧至少存在当前右柱这么高的边界。左侧水位只受 leftMax 限制：更新它后加入 leftMax - height[left]，再移动 left。另一侧完全对称。

    lower side → known boundary
    water += sideMax − height[pointer]

    COMPLEXITY

    每根柱只访问一次

    两个指针只向中间移动，总共不超过 n 步。只保存指针、左右最大值和答案，不建立前后缀数组。

    TIME

    O(n)

    SPACE

    O(1)

    FULL PROCESS

    完整解题过程

    1. 1. 初始化：left=0、right=n-1、leftMax=rightMax=water=0。
    2. 2. 选定侧：比较两端当前高度，较矮侧的水位可以立即确定。
    3. 3. 更新并累加：先更新该侧最大值，再加 max−当前高度；结果不会为负。
    4. 4. 收缩：只移动已结算侧的指针，直到左右相遇。

    BOUNDARIES

    边界情况

    • • 少于 3 根柱：必为 0。
    • • 单调上升或下降：没有封闭低谷。
    • • 相等端点：处理任意一侧都正确。
    • • 0 高柱：只要两侧有墙即可蓄水。

    ALTERNATIVES

    替代方案

    前后缀最大值最易推导，但空间 O(n)；单调栈按横向层结算，适合“下一个更大元素”延伸，但公式更易写错。面试优先双指针。

    COMMON ERRORS

    常见错误

    • • 移动较高侧，无法保证另一边界足够高。
    • • 先累加再更新 sideMax，产生负水量。
    • • 把本题当“最大容器面积”，忽略每个低谷都要累计。
    • • while 条件与指针更新不一致，漏算相遇前一格。

    INTERVIEW FOLLOW-UPS

    高频追问

    为什么无需知道远端最高柱？
    较矮端已给出保底边界；该侧最大值是当前水位瓶颈。
    能否修改输入？
    本算法只读数组，不修改输入。
    如何扩展到二维？
    二维要从边界用最小堆向内扩张，不能直接套两个指针。
