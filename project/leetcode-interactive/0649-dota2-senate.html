Problem brief

议事规则

Dota2 参议院中有两个阵营：Radiant（天辉，R）和 Dire（夜魇，D）。给定字符串 senate，其中每个字符按顺序代表一名参议员所属阵营。

投票按轮进行，每轮从当前顺序中的第一名参议员走到最后一名；已经失去权利的人会被跳过。有权利的参议员行动时可以选择：

剥夺权利

让另一名参议员从当前轮开始永久失去所有权利。

宣布胜利

当仍有权利的人全部属于同一阵营时，宣布本阵营获胜。

所有参议员都会为自己的阵营采取最佳策略。请预测最终胜方，并返回 "Radiant" 或 "Dire"。

函数签名
predictPartyVictory(senate: string): string
示例 1
输入senate = "RD"
输出"Radiant"
解释首位 R 在第 1 轮剥夺后面的 D；D 被跳过。第 2 轮只剩 R 有权行动，因此 Radiant 宣布胜利。
示例 2
输入senate = "RDD"
输出"Dire"
解释R 先剥夺第一个 D，剩余 D 随后剥夺 R。进入第 2 轮时只有最后一名 D 仍有权，Dire 获胜。

约束

  • n == senate.length
  • 1 <= n <= 104
  • senate[i] 只能是 'R' 或 'D'

Full solution

两支队列，比较下一次行动时刻

核心洞察

对当前参议员而言，剥夺最近将要行动的对手始终最优：如果放过这个对手，对方会更早获得一次剥夺本方的机会，不会带来任何收益。

因此分别维护 R、D 尚有权者的“下一次行动位置”。每次取两边队首，位置更小者先行动并剥夺另一方；胜者把自己的位置加上 n 后重新入队，表示他会在下一轮再次行动。

完整过程

  1. 扫描字符串，把所有 R 的下标放入天辉队列，把所有 D 的下标放入夜魇队列。
  2. 当两队都非空时，同时取出队首下标 r 和 d。
  3. 若 r < d，R 先行动并剥夺 D，将 r + n 放回 R 队尾；否则做对称操作。
  4. 某个队列为空后，另一阵营就是最终胜方。

正确性证明

  1. 引理 1：当前最早行动的参议员剥夺对方最早将行动者是安全且最优的。任何更晚的对手都不会比最早对手更早威胁本方；保留最早对手只会让其多获得一次有效行动机会。
  2. 引理 2：两队队首中下标较小者一定先行动。下标是沿原始顺序不断递增的绝对行动时刻，加 n 正好把存活者排到下一轮相同席位。
  3. 保持性：一次比较后，较早者存活并以 index + n 进入后续顺序，较晚者被永久移除。这与实际投票过程的剩余行动顺序完全一致。
  4. 终止与结论：每次循环永久剥夺一人，参议员有限，过程必然终止。某队为空时，仍有权者全属另一阵营，故该阵营可以宣布胜利。算法返回值正确。
时间复杂度O(n)每位被剥夺者只离队一次，存活者的有效重排总量也是线性的。
空间复杂度O(n)两支队列合计最多保存 n 个仍有权的行动位置。

Implementations

四种语言完整代码

Java官方可提交签名
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public String predictPartyVictory(String senate) {
        int n = senate.length();
        Deque<Integer> radiant = new ArrayDeque<>();
        Deque<Integer> dire = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            if (senate.charAt(i) == 'R') {
                radiant.offerLast(i);
            } else {
                dire.offerLast(i);
            }
        }

        while (!radiant.isEmpty() && !dire.isEmpty()) {
            int r = radiant.pollFirst();
            int d = dire.pollFirst();

            if (r < d) {
                radiant.offerLast(r + n);
            } else {
                dire.offerLast(d + n);
            }
        }

        return radiant.isEmpty() ? "Dire" : "Radiant";
    }
}

var predictPartyVictory = function(senate) {
    const n = senate.length;
    const radiant = [];
    const dire = [];

    for (let i = 0; i < n; i++) {
        if (senate[i] === 'R') {
            radiant.push(i);
        } else {
            dire.push(i);
        }
    }

    let rHead = 0;
    let dHead = 0;

    while (rHead < radiant.length && dHead < dire.length) {
        const r = radiant[rHead++];
        const d = dire[dHead++];

        if (r < d) {
            radiant.push(r + n);
        } else {
            dire.push(d + n);
        }
    }

    return rHead < radiant.length ? 'Radiant' : 'Dire';
};

from collections import deque


class Solution:
    def predictPartyVictory(self, senate: str) -> str:
        n = len(senate)
        radiant = deque()
        dire = deque()

        for index, party in enumerate(senate):
            if party == "R":
                radiant.append(index)
            else:
                dire.append(index)

        while radiant and dire:
            r = radiant.popleft()
            d = dire.popleft()

            if r < d:
                radiant.append(r + n)
            else:
                dire.append(d + n)

        return "Radiant" if radiant else "Dire"
C++官方可提交签名
#include <queue>
#include <string>
using namespace std;

class Solution {
public:
    string predictPartyVictory(string senate) {
        int n = static_cast<int>(senate.size());
        queue<int> radiant;
        queue<int> dire;

        for (int i = 0; i < n; ++i) {
            if (senate[i] == 'R') {
                radiant.push(i);
            } else {
                dire.push(i);
            }
        }

        while (!radiant.empty() && !dire.empty()) {
            int r = radiant.front();
            int d = dire.front();
            radiant.pop();
            dire.pop();

            if (r < d) {
                radiant.push(r + n);
            } else {
                dire.push(d + n);
            }
        }

        return radiant.empty() ? "Dire" : "Radiant";
    }
};

边界情况

  • 字符串只有一个阵营时，无需循环，直接返回该阵营。
  • 长度为 1 时，唯一参议员立即满足宣布胜利条件。
  • 连续大量相同字符时，必须保持所有人的原始先后次序。
  • 行动位置可能超过 n - 1；它表示未来轮次，不应取模后再比较。

替代方案

也可以只用一支循环队列保存字符，并维护 banR、banD 两个“待执行剥夺”计数。弹出参议员时，如果其阵营有待执行剥夺就丢弃，否则让他给对方增加一次剥夺并重新入队。

这种写法同为 O(n) 时间、O(n) 空间，但状态转移更绕；双队列直接表达“谁先行动”，通常更适合面试讲解。

常见错误

  • 按阵营总人数直接判断胜负，忽略行动顺序。
  • 存活者回队时加入原下标，而不是 index + n。
  • 用数组 shift() 反复搬移元素，导致 JavaScript 退化；应使用头指针。
  • 循环条件写成“任一队列非空”，造成访问空队首。
