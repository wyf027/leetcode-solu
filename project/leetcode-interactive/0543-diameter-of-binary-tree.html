二叉树的直径

Diameter of Binary Tree · 树 / 深度优先搜索 / 树形 DP

本题要找的是
最长路径的边数

题目

给定二叉树根节点 root，返回树中任意两个节点之间最长路径的长度。路径不一定经过根节点，长度按路径包含的边数计算。

示例 1
输入：root = [1,2,3,4,5]
输出：3
解释：路径 [4,2,1,3] 或 [5,2,1,3]
      包含 3 条边。
示例 2
输入：root = [1,2]
输出：1

约束

  • 树中节点数为 [1, 10⁴]
  • -100 ≤ Node.val ≤ 100

题解：一次后序遍历，同时算高度与直径

核心洞察：对每个节点，经过它的最长路径边数是“左子树高度 + 右子树高度”；而它能向父节点贡献的高度是 1 + max(左高度, 右高度)。

完整过程

  1. 定义 DFS 返回当前节点到最深叶子的边数贡献；空节点返回 0，这也可理解为按节点数表示的向下长度。
  2. 递归获得左右贡献 left、right。
  3. 用 left + right 更新全局最大直径。
  4. 向父节点返回 1 + max(left, right)。

正确性

任意一条最长路径都有一个最高节点（路径两端的最低公共祖先）。当后序遍历处理该节点时，左右子树的最深向下路径均已被准确计算，它们之和正好覆盖以该节点为最高点的最长路径。算法对每个节点都计算这一候选并取最大值，因此不会漏掉全局最长路径；返回给父节点的又只选一侧最长分支，符合树中简单路径不能分叉的性质。

边界

  • 单节点树：左右贡献均为 0，直径为 0。
  • 链状树：直径为节点数减 1。
  • 直径可能完全位于某个子树内，不经过根。
  • 节点值与答案无关。

复杂度

  • 时间：O(n)，每个节点访问一次。
  • 空间：O(h) 递归栈；最坏链状树为 O(n)，平衡树为 O(log n)。

四种语言完整代码

Java

class Solution {
    private int diameter = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        depth(root);
        return diameter;
    }

    private int depth(TreeNode node) {
        if (node == null) return 0;
        int left = depth(node.left);
        int right = depth(node.right);
        diameter = Math.max(diameter, left + right);
        return 1 + Math.max(left, right);
    }
}

JavaScript

var diameterOfBinaryTree = function(root) {
    let diameter = 0;
    function depth(node) {
        if (node === null) return 0;
        const left = depth(node.left);
        const right = depth(node.right);
        diameter = Math.max(diameter, left + right);
        return 1 + Math.max(left, right);
    }
    depth(root);
    return diameter;
};

Python

class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        diameter = 0

        def depth(node: Optional[TreeNode]) -> int:
            nonlocal diameter
            if node is None:
                return 0
            left = depth(node.left)
            right = depth(node.right)
            diameter = max(diameter, left + right)
            return 1 + max(left, right)

        depth(root)
        return diameter

C++

class Solution {
    int diameter = 0;

    int depth(TreeNode* node) {
        if (node == nullptr) return 0;
        int left = depth(node->left);
        int right = depth(node->right);
        diameter = max(diameter, left + right);
        return 1 + max(left, right);

    int diameterOfBinaryTree(TreeNode* root) {
        depth(root);
        return diameter;
    }
};

替代方案

可以让 DFS 一次返回二元组 [高度, 子树直径]，避免使用全局变量，更适合纯函数风格；渐进复杂度不变。为每对节点求距离或从每个节点重复求高度会退化到 O(n²)，不推荐。

面试追问

  • 如果边有权重，如何改为累加权重而不是边数？
  • 如何同时恢复直径所经过的节点序列？
  • 递归深度可能达到 10⁴ 时，如何改写为显式栈后序遍历？
  • 若要求 N 叉树的直径，应保留每个节点最大的哪两条子链？

常见错误

  • 把节点数当成边数，导致答案多 1。
  • 只计算经过根节点的路径，漏掉完全位于子树中的直径。
  • DFS 向父节点返回 left + right；这会让路径分叉，不再是简单路径。
  • 把直径状态写成跨测试共享，却没有在每次调用入口重置。
