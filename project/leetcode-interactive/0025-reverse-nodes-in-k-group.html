01 · Problem manifest

题意转述

给定单链表 head 和正整数 k，从头开始每 K 个节点组成一组并反转节点连接。若最后剩余节点不足 K 个，必须维持原顺序。只能改变节点的 next 指针，不能交换节点值。

官方样例 1

输入：head = [1,2,3,4,5], k = 2

输出：[2,1,4,3,5]

官方样例 2

输入：head = [1,2,3,4,5], k = 3

输出：[3,2,1,4,5]

约束：1 ≤ k ≤ n ≤ 5000；0 ≤ Node.val ≤ 1000。进阶目标：O(1) 额外空间。

Core insight

先圈定闭区间，再反转

01 / PROBE

从 groupPrev 向前走 K 步找到 kth；找不到就保留尾段并结束。

02 / REVERSE

令 prev = groupNext，在 [groupPrev.next, groupNext) 内原地反转。

03 / RECONNECT

groupPrev.next 接 kth；旧组头成为下一轮 groupPrev。

Complete process

完整解题过程

  1. 1. 建 dummy，并让 groupPrev 指向 dummy。
  2. 2. 用 getKth 检查下一组是否凑满 K 个节点。
  3. 3. 保存 groupNext = kth.next，作为反转后的尾部出口。
  4. 4. prev 从 groupNext 开始，curr 从组头开始，逐个反转 next。
  5. 5. 保存旧组头，接上 kth，再把 groupPrev 移到旧组头。
  6. 6. 重复直到不足 K 个，返回 dummy.next。

Boundary & complexity

边界与复杂度

  • k = 1：每组只有一个节点，结构保持不变。
  • n = k：整条链恰好翻转一次。
  • n % k ≠ 0：不足 K 个的尾段原样保留。
  • 重复值：算法操作节点身份，与值是否相同无关。
  • 时间：O(n)，每个节点探测与反转次数为常数。
  • 额外空间：O(1)，只使用固定数量指针。

Alternative

递归方案

代码更短，但调用栈最坏 O(n/k)，不满足进阶的 O(1) 额外空间；面试主线更推荐迭代。

Common mistakes

常见错误

  • 未确认 K 个节点就开始反转。
  • 忘记保存 groupNext，导致尾链丢失。
  • 重连后把 groupPrev 移到新组头，而不是旧组头。
  • 交换节点值，违反题目要求。

Interview follow-up

高频追问

  • 为什么 prev 要初始化为 groupNext？
  • 如何证明不足 K 个时尾段不会被改动？
  • 能否只遍历一次？实际仍是 O(n)。
  • 若要求最后不足 K 个也反转，改哪里？

class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode dummy = new ListNode(0, head);
        ListNode groupPrev = dummy;

        while (true) {
            ListNode kth = getKth(groupPrev, k);
            if (kth == null) break;
            ListNode groupNext = kth.next;

            ListNode prev = groupNext;
            ListNode curr = groupPrev.next;
            while (curr != groupNext) {
                ListNode next = curr.next;
                curr.next = prev;
                prev = curr;
                curr = next;
            }

            ListNode oldGroupHead = groupPrev.next;
            groupPrev.next = kth;
            groupPrev = oldGroupHead;
        }
        return dummy.next;
    }

    private ListNode getKth(ListNode curr, int k) {
        while (curr != null && k > 0) {
            curr = curr.next;
            k--;
        }
        return curr;
    }
}
