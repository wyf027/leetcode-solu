连通两组点的最小成本

Minimum Cost to Connect Two Groups of Points

题号 1595非付费题参数 cost: number[][]返回 integer
01 / PROBLEM

题意与约束

有两组点，第一组有 size1 个点，第二组有 size2 个点，且 size1 ≥ size2。矩阵 cost[i][j] 表示连接第一组点 i 与第二组点 j 的成本。

需要选择若干条跨组连线，使两组中的每一个点都至少连接到对方组的一个点。求所有所选连线的最小总成本。

函数签名语义：connectTwoGroups(cost) -> integer。同一点可以连接多条边，边没有数量上限。

约束

  • size1 == cost.length
  • size2 == cost[i].length
  • 1 ≤ size1, size2 ≤ 12
  • size1 ≥ size2
  • 0 ≤ cost[i][j] ≤ 100
02 / EXAMPLES

官方示例

EXAMPLE 01
输入：cost = [[15, 96], [36, 2]] 输出：17

连接第一组点 1 到 A、点 2 到 B，总成本为 15 + 2 = 17。

EXAMPLE 02
输入：cost = [[1, 3, 5], [4, 1, 1], [1, 5, 3]] 输出：4

可选择 1–A、2–B、2–C、3–A。允许一个点连接多个对方点。

EXAMPLE 03
输入：cost = [[2, 5, 1], [3, 4, 7], [8, 1, 2], [6, 2, 4], [3, 8, 8]] 输出：10

五个第一组点与三个第二组点全部至少被一条选中边覆盖。

04 / SOLUTION

位掩码动态规划

核心洞察

先让第一组的每个点恰好选择一条“主连接”。用一个 size2 位掩码记录第二组哪些点已被这些主连接覆盖。第一组全部处理后，第二组仍未覆盖的每个点，只需补上连接它的最便宜边。

预处理 minCost[j] = min(cost[i][j])，表示补覆盖第二组点 j 的最低代价。

状态与转移

dp[mask] 表示处理完当前若干个第一组点，并令第二组主连接覆盖集合为 mask 时的最小成本。

next[mask | (1 << j)] = min(next[...], dp[mask] + cost[i][j])

处理完所有行后，对每个 mask 加上所有未置位列的 minCost[j]，取全局最小值。

完整过程

  1. 计算第二组每个点与第一组相连的最小成本。
  2. 初始化 dp[0] = 0，其余状态为无穷大。
  3. 逐个处理第一组点；枚举旧掩码以及本行要连接的第二组点，更新新掩码。
  4. 所有第一组点都有主连接后，枚举最终掩码。
  5. 对未覆盖的第二组点补最便宜边，更新答案。

复杂度与边界

  • 时间：O(size1 × size2 × 2^size2)。
  • 空间：滚动数组为 O(2^size2)。
  • size2 = 1 时，每个第一组点都必须连向唯一的第二组点。
  • 成本可以为 0；不要把 0 当作“没有边”。
  • 所有成本最大时答案仍很小，但无穷大常量应留出安全余量。

正确性证明

转移覆盖全部主连接方案。 对每个第一组点，转移枚举它连接的任意一个第二组点。因此处理完全部行后，dp[mask] 是所有主连接覆盖集合恰为 mask 的方案中的最小成本。

补边成本最优。 对于 mask 中未覆盖的第二组点 j，至少需要添加一条与它相连的边；最小可能成本就是 minCost[j]。不同未覆盖点的补边彼此不冲突，所以这些最小值可独立相加。

不遗漏全局最优解。 从任意合法解中，为每个第一组点保留一条入选边作为主连接。任何未被主连接覆盖的第二组点，都必须由其余边覆盖；把这些边分别替换成该列最便宜的边不会变差。该结构必被某个 dp[mask] 加补边的候选表示。

结论。 每个候选都覆盖两组的所有点，同时至少有一个候选不劣于任意合法解；取最小值即得到最优答案。

替代方案

也可以使用二维递归记忆化 dfs(i, mask)，在 i == size1 时计算未覆盖列的补边成本；逻辑与滚动 DP 完全相同。最小费用流也能建模，但实现更长，且本题规模直接指向位掩码 DP。

常见错误

  • 只保证第二组被覆盖，忘了每个第一组点也必须连接。
  • 误以为是一一匹配，不允许同一点连接多条边。
  • 把“未覆盖列的最小边”加在每一层，导致重复计费。
  • 原地更新同一行 dp，混淆已处理行数。

面试追问

  • 为什么只对较小的一组做位掩码？若没有 size1 ≥ size2 应如何交换维度？
  • 如果每个点要求至少连接两条边，状态需要增加什么信息？
  • 如果边存在容量或互斥限制，为什么独立补边不再成立？

实现要点

每处理一行都创建新的 next 数组，确保每个最终状态正好为该行选择过一次主连接。最终补边时枚举位即可，无需重建实际边集合。

import java.util.*;

class Solution {
    public int connectTwoGroups(List<List<Integer>> cost) {
        int n = cost.size();
        int m = cost.get(0).size();
        int states = 1 << m;
        int inf = 1_000_000_000;

        int[] minCost = new int[m];
        Arrays.fill(minCost, inf);
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                minCost[j] = Math.min(minCost[j], cost.get(i).get(j));
            }
        }

        int[] dp = new int[states];
        Arrays.fill(dp, inf);
        dp[0] = 0;

        for (int i = 0; i < n; i++) {
            int[] next = new int[states];
            Arrays.fill(next, inf);
            for (int mask = 0; mask < states; mask++) {
                if (dp[mask] == inf) continue;
                for (int j = 0; j < m; j++) {
                    int newMask = mask | (1 << j);
                    next[newMask] = Math.min(
                        next[newMask], dp[mask] + cost.get(i).get(j)
                    );
                }
            }
            dp = next;
        }

        int answer = inf;
        for (int mask = 0; mask < states; mask++) {
            int total = dp[mask];
            for (int j = 0; j < m; j++) {
                if ((mask & (1 << j)) == 0) total += minCost[j];
            }
            answer = Math.min(answer, total);
        }
        return answer;
    }
}

from typing import List


class Solution:
    def connectTwoGroups(self, cost: List[List[int]]) -> int:
        n, m = len(cost), len(cost[0])
        states = 1 << m
        min_cost = [min(cost[i][j] for i in range(n)) for j in range(m)]

        dp = [float("inf")] * states
        dp[0] = 0

        for i in range(n):
            nxt = [float("inf")] * states
            for mask in range(states):
                if dp[mask] == float("inf"):
                    continue
                for j in range(m):
                    new_mask = mask | (1 << j)
                    nxt[new_mask] = min(nxt[new_mask], dp[mask] + cost[i][j])
            dp = nxt

        answer = float("inf")
        for mask in range(states):
            total = dp[mask]
            for j in range(m):
                if mask & (1 << j) == 0:
                    total += min_cost[j]
            answer = min(answer, total)

        return int(answer)

class Solution {
public:
    int connectTwoGroups(vector<vector<int>>& cost) {
        int n = cost.size();
        int m = cost[0].size();
        int states = 1 << m;
        const int INF = 1e9;

        vector<int> minCost(m, INF);
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < m; ++j) {
                minCost[j] = min(minCost[j], cost[i][j]);
            }
        }

        vector<int> dp(states, INF);
        dp[0] = 0;

        for (int i = 0; i < n; ++i) {
            vector<int> next(states, INF);
            for (int mask = 0; mask < states; ++mask) {
                if (dp[mask] == INF) continue;
                for (int j = 0; j < m; ++j) {
                    int newMask = mask | (1 << j);
                    next[newMask] = min(next[newMask], dp[mask] + cost[i][j]);
                }
            }
            dp.swap(next);
        }

        int answer = INF;
        for (int mask = 0; mask < states; ++mask) {
            int total = dp[mask];
            for (int j = 0; j < m; ++j) {
                if ((mask & (1 << j)) == 0) total += minCost[j];
            }
            answer = min(answer, total);
        }
        return answer;
    }
};
