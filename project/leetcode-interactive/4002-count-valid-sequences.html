统计有效序列数目

把“乘积为偶数”换成它的补集：至少有一个偶数 = 全部正整数拆分 − 全部奇数拆分。

题意

给定正整数 n、k，统计长度为 k 的正整数序列；元素和为 n，且元素乘积为偶数。位置不同即是不同序列，答案对 109 + 7 取模。

1 ≤ k ≤ n ≤ 5 × 105

输入 输出 说明
5, 3 3 [1,2,2] 的三个排列
3, 2 2 [1,2]、[2,1]
5, 5 0 唯一拆分全为 1

可交互计数器

三步推导

全部正整数拆分

xi ≥ 1，隔板法：

总数 = C(n-1, k-1)
全奇数拆分

xi = 2yi + 1。

Σy = (n-k) / 2
有效答案

若 n-k 为奇数，全奇数不存在。

C(n-1,k-1) − C((n+k)/2-1,k-1)

预处理阶乘、逆阶乘后组合数 O(1)，总时间 O(n)，空间 O(n)。

题解默认收起；按 Enter 或空格可展开。

题解：补集 + 隔板法

核心洞察

乘积为偶数等价于序列中至少一个元素为偶数。直接枚举“第一个偶数在哪”会重复计数；改数补集：所有正整数序列减去每个元素都为奇数的序列。

answer = C(n - 1, k - 1) - oddOnly

完整过程

  1. 令 x1 + … + xk = n，且 xi ≥ 1；隔板法给出 C(n - 1, k - 1)。
  2. 全奇数时写成 xi = 2yi + 1，得到 Σyi = (n - k) / 2。
  3. 若 n - k 为奇数，全奇数方案为 0；否则 yi ≥ 0 的方案为 C((n + k) / 2 - 1, k - 1)。
  4. 预处理阶乘和逆阶乘，用费马小定理求逆元，组合数查询 O(1)。
边界

k = n 时只有全 1，答案为 0。n - k 为奇数时不可能全奇数，因此答案就是全部拆分数。

复杂度

阶乘和逆阶乘预处理 O(n)，空间 O(n)；单次组合数和最终答案均为 O(1)。

替代方案与追问

小 n 可 DP 按和与奇偶性转移，但 O(nk) 不适合 5×105。若要求“恰好 t 个偶数”，可再枚举偶数位置并组合计数。

常见错误

不要把“乘积为偶数”误当成“和为偶数”；不要遗漏 n-k 为奇数时的全奇数计数为 0；组合数下标必须使用 (n+k)/2 - 1，并在模运算减法后加 MOD。
