统计有效序列数目

把“乘积为偶数”换成它的补集：至少有一个偶数 = 全部正整数拆分 − 全部奇数拆分。

题意

给定正整数 n、k，统计长度为 k 的正整数序列；元素和为 n，且元素乘积为偶数。位置不同即是不同序列，答案对 109 + 7 取模。

1 ≤ k ≤ n ≤ 5 × 105

输入 输出 说明
5, 3 3 [1,2,2] 的三个排列
3, 2 2 [1,2]、[2,1]
5, 5 0 唯一拆分全为 1

可交互计数器

三步推导

全部正整数拆分

xi ≥ 1，隔板法：

总数 = C(n-1, k-1)
全奇数拆分

xi = 2yi + 1。

Σy = (n-k) / 2
有效答案

若 n-k 为奇数，全奇数不存在。

C(n-1,k-1) − C((n+k)/2-1,k-1)

预处理阶乘、逆阶乘后组合数 O(1)，总时间 O(n)，空间 O(n)。

设 s = (n-k)/2。若 s 是整数，非负解 y1 + … + yk = s 的数量是 C(s+k-1,k-1)，也就是 C((n+k)/2-1,k-1)。k=n 时唯一序列是全 1，答案自然为 0。
