执行交换操作后的
最小汉明距离

Minimize Hamming Distance After Swap Operations

并查集连通分量频次抵消数组
Problem

问题描述

给定两个长度均为 n 的整数数组 source 与 target，以及交换对数组 allowedSwaps。每个 [aᵢ, bᵢ] 表示可交换 source 中这两个下标的元素；交换可以按任意顺序执行任意多次。

两个等长数组的汉明距离是满足 source[i] ≠ target[i] 的下标数量。返回完成任意次允许交换后可达到的最小汉明距离。

函数形式： minimumHammingDistance(source, target, allowedSwaps) → integer

示例 1

输入：
source = [1,2,3,4]
target = [2,1,4,5]
allowedSwaps = [[0,1],[2,3]]

输出：1

交换下标 0/1、2/3 后可得到 [2,1,4,3]，仅下标 3 不同。

示例 2

输入：
source = [1,2,3,4]
target = [1,3,2,4]
allowedSwaps = []

输出：2

没有允许的交换，因此下标 1、2 仍不同。

示例 3

输入：
source = [5,1,2,4,3]
target = [1,5,4,2,3]
allowedSwaps =
[[0,4],[4,2],[1,3],[1,4]]

输出：0

所有下标最终连通，元素可重排成 target。

约束

  • n == source.length == target.length
  • 1 ≤ n ≤ 10⁵
  • 1 ≤ source[i], target[i] ≤ 10⁵
  • 0 ≤ allowedSwaps.length ≤ 10⁵
  • allowedSwaps[i].length == 2
  • 0 ≤ aᵢ, bᵢ ≤ n - 1
  • aᵢ ≠ bᵢ

Core Insight

并查集 + 分量内频次抵消

把下标视作节点，允许交换对视作无向边。因为边能反复使用，同一连通分量内的元素可经过路径交换形成任意排列；不同分量之间则不能交换元素。

为每个分量维护 source 值频次。遍历下标 i：若该分量仍有一个 target[i]，就消耗库存；否则答案加一。

一句话模型

交换边决定货物能送到哪些位置，频次表决定仓库里有没有目标货物。

无需构造最终排列，也无需模拟交换。

完整过程

  1. 初始化并查集，每个下标自成一组。
  2. 遍历 allowedSwaps，合并每对下标。
  3. 把每个 source[i] 计入根节点对应的频次表。
  4. 遍历 target；若当前根的库存含 target[i] 则频次减一，否则答案加一。
  5. 返回无法由所在分量满足的位置数。

正确性证明

引理 1：同分量内可以任意重排。沿连通路径逐边交换，可以把任一元素移到同分量任一节点，进而构造任意排列。
引理 2：元素不能跨分量。两个分量间不存在允许交换边组成的路径，任何操作序列都无法让元素跨越边界。
引理 3：频次抵消达到最大匹配。每个值的最大匹配数等于 source 与 target 在该分量中出现次数的较小者，逐次消耗库存恰好取得此数。
结论。算法对每个独立分量都取得最大匹配，因此所有未匹配位置之和就是全局最小汉明距离。

复杂度与边界

  • 时间：O((n + m) α(n))
  • 空间：O(n)
  • 无交换：退化为逐位比较。
  • 全连通：比较整体多重集合。
  • 重复值：必须记录频次。
  • 两数组相等：答案为 0。

替代方案

DFS / BFS：建立邻接表并搜索分量，再比较分量内频次，时间 O(n+m)、空间 O(n+m)。分量内排序：分别收集 source 与 target 的值并排序比较，较直观但总时间可达 O(n log n)。

class Solution {
    public int minimumHammingDistance(int[] source, int[] target,
                                      int[][] allowedSwaps) {
        int n = source.length;
        DSU dsu = new DSU(n);
        for (int[] e : allowedSwaps) dsu.union(e[0], e[1]);

        Map<Integer, Map<Integer, Integer>> counts = new HashMap<>();
        for (int i = 0; i < n; i++) {
            int root = dsu.find(i);
            counts.computeIfAbsent(root, k -> new HashMap<>())
                  .merge(source[i], 1, Integer::sum);
        }

        int answer = 0;
        for (int i = 0; i < n; i++) {
            Map<Integer, Integer> bag = counts.get(dsu.find(i));
            int have = bag.getOrDefault(target[i], 0);
            if (have == 0) answer++;
            else if (have == 1) bag.remove(target[i]);
            else bag.put(target[i], have - 1);
        }
        return answer;
    }

    static class DSU {
        int[] parent, size;
        DSU(int n) {
            parent = new int[n]; size = new int[n];
            for (int i = 0; i < n; i++) { parent[i] = i; size[i] = 1; }
        }
        int find(int x) {
            if (parent[x] != x) parent[x] = find(parent[x]);
            return parent[x];
        }
        void union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return;
            if (size[ra] < size[rb]) { int t = ra; ra = rb; rb = t; }
            parent[rb] = ra; size[ra] += size[rb];
        }
    }
}

var minimumHammingDistance = function(source, target, allowedSwaps) {
    const n = source.length;
    const parent = Array.from({length: n}, (_, i) => i);
    const size = Array(n).fill(1);

    const find = x => {
        if (parent[x] !== x) parent[x] = find(parent[x]);
        return parent[x];
    };
    const union = (a, b) => {
        let ra = find(a), rb = find(b);
        if (ra === rb) return;
        if (size[ra] < size[rb]) [ra, rb] = [rb, ra];
        parent[rb] = ra;
        size[ra] += size[rb];
    };
    for (const [a, b] of allowedSwaps) union(a, b);

    const counts = new Map();
    for (let i = 0; i < n; i++) {
        const root = find(i);
        if (!counts.has(root)) counts.set(root, new Map());
        const bag = counts.get(root);
        bag.set(source[i], (bag.get(source[i]) || 0) + 1);
    }

    let answer = 0;
    for (let i = 0; i < n; i++) {
        const bag = counts.get(find(i));
        const have = bag.get(target[i]) || 0;
        if (have === 0) answer++;
        else bag.set(target[i], have - 1);
    }
    return answer;
};
from collections import defaultdict, Counter
from typing import List

class Solution:
    def minimumHammingDistance(
        self,
        source: List[int],
        target: List[int],
        allowedSwaps: List[List[int]]
    ) -> int:
        n = len(source)
        parent = list(range(n))
        size = [1] * n

        def find(x: int) -> int:
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a: int, b: int) -> None:
            ra, rb = find(a), find(b)
            if ra == rb:
                return
            if size[ra] < size[rb]:
                ra, rb = rb, ra
            parent[rb] = ra
            size[ra] += size[rb]

        for a, b in allowedSwaps:
            union(a, b)

        counts = defaultdict(Counter)
        for i, value in enumerate(source):
            counts[find(i)][value] += 1

        answer = 0
        for i, needed in enumerate(target):
            bag = counts[find(i)]
            if bag[needed] == 0:
                answer += 1
            else:
                bag[needed] -= 1
        return answer
class Solution {
    class DSU {
        vector<int> parent, size;
    public:
        DSU(int n) : parent(n), size(n, 1) {
            iota(parent.begin(), parent.end(), 0);
        }
        int find(int x) {
            return parent[x] == x ? x : parent[x] = find(parent[x]);
        }
        void unite(int a, int b) {
            a = find(a); b = find(b);
            if (a == b) return;
            if (size[a] < size[b]) swap(a, b);
            parent[b] = a; size[a] += size[b];
        }
    };
public:
    int minimumHammingDistance(vector<int>& source,
                               vector<int>& target,
                               vector<vector<int>>& allowedSwaps) {
        int n = source.size();
        DSU dsu(n);
        for (const auto& e : allowedSwaps) dsu.unite(e[0], e[1]);

        unordered_map<int, unordered_map<int, int>> counts;
        for (int i = 0; i < n; i++) ++counts[dsu.find(i)][source[i]];

        int answer = 0;
        for (int i = 0; i < n; i++) {
            auto& bag = counts[dsu.find(i)];
            if (bag[target[i]] == 0) ++answer;
            else --bag[target[i]];
        }
        return answer;
    }
};

Interview Notes

面试追问与常见错误

为什么连通就意味着可以任意重排？

沿路径逐边交换可将任意元素移到同分量任一节点，重复操作即可构造任意排列。

为什么不能用 Set 记录值？

重复值需要被消耗多次，Set 会丢失出现次数；必须使用频次表。

常见实现错误有哪些？

按下标而非根节点分组；匹配后未扣频次；把交换边误认为只能用一次；忘记路径压缩；混淆根节点和值的键。

交换关系动态追加时怎么办？

只追加边仍可用并查集，但合并时还要合并两组频次；若频繁查询，则需额外维护每组差额和全局贡献。
