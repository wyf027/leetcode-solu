Problem 566

重塑矩阵

Reshape the Matrix — 改变矩阵的行列形状，同时保持所有元素原有的逐行遍历顺序。

函数：matrixReshape(mat, r, c) 返回：integer[][] 非付费题
Problem

题目说明

给定一个由二维数组 mat 表示的 m × n 矩阵，以及目标行数 r 和列数 c。请把全部元素按它们在原矩阵中的逐行读取顺序，依次填入一个 r × c 的新矩阵。

只有当新旧矩阵的元素总数一致时才允许重塑；如果尺寸不合法，直接返回原矩阵。

官方示例

示例 1 · 可以重塑
输入mat = [[1,2],[3,4]], r = 1, c = 4
输出[[1,2,3,4]]
示例 2 · 无法重塑
输入mat = [[1,2],[3,4]], r = 2, c = 4
输出[[1,2],[3,4]]
Limits

约束

  • m == mat.length
  • n == mat[i].length
  • 1 <= m, n <= 100
  • -1000 <= mat[i][j] <= 1000
  • 1 <= r, c <= 300
本题只改变“形状”

元素值不变，数量不变，相对次序也不变。尝试下面的交互实验，观察不同目标尺寸的结果。

Solution

题解：用同一个线性下标连接两种形状

核心洞察

矩阵逐行展开后就是长度为 m × n 的序列。线性下标 k 在原矩阵中对应 [⌊k / n⌋][k % n]，在目标矩阵中对应 [⌊k / c⌋][k % c]。只要总元素数相等，就能一一映射。

先判断合法性

若 m × n != r × c，两个矩阵的格子数不同，无法既不丢失也不新增元素。因此必须原样返回 mat。

完整过程

  1. 读取原矩阵的行数 m 与列数 n。
  2. 比较 m × n 和 r × c；不相等时立即返回原矩阵。
  3. 创建 r × c 的结果矩阵。
  4. 让线性下标 k 从 0 遍历到 m × n - 1，把原位置 [k / n][k % n] 的值写入目标位置 [k / c][k % c]。
  5. 遍历结束后返回结果矩阵。

正确性证明

  • 完整性：当总数相等时，k 恰好遍历全部 m × n 个线性位置，所以每个原元素都会被读取一次。
  • 唯一性：不同的 k 通过除法与取模得到不同的目标坐标，因此每个目标格恰好被写入一次。
  • 顺序性：原坐标和目标坐标都由同一个递增的 k 计算，故逐行遍历顺序保持不变。
  • 非法尺寸：总数不等时算法返回原矩阵，符合题目要求。

复杂度与边界

时间复杂度：O(mn)，每个元素处理一次。

空间复杂度：O(rc)，用于返回新矩阵；若不计返回结果，额外空间为 O(1)。

边界：单行、单列、1 × 1、目标形状与原形状相同、负数元素，以及总元素数不匹配。

替代方案

可以先把元素复制到一维数组，再按 c 个一组装回二维矩阵。它更直观，但额外使用 O(mn) 的中间空间；直接坐标映射更紧凑。

常见错误

  • 忘记先比较元素总数，导致越界或缺失。
  • 原坐标错误地使用目标列数 c。
  • 目标坐标错误地使用原列数 n。
  • 非法重塑时返回空数组，而不是原矩阵。

面试追问

  • 如果底层矩阵支持“视图”而非复制，怎样只修改形状元数据？
  • 如何把坐标映射推广到三维或任意维数组？
  • 如果输入规模大到无法一次装入内存，怎样按流式逐行产生结果？
  • 若遍历顺序改为按列，两个坐标公式需要怎样变化？

class Solution {
    public int[][] matrixReshape(int[][] mat, int r, int c) {
        int m = mat.length;
        int n = mat[0].length;
        if (m * n != r * c) {
            return mat;
        }

        int[][] result = new int[r][c];
        for (int k = 0; k < m * n; k++) {
            result[k / c][k % c] = mat[k / n][k % n];
        }
        return result;
    }
}

var matrixReshape = function(mat, r, c) {
    const m = mat.length;
    const n = mat[0].length;
    if (m * n !== r * c) {
        return mat;
    }

    const result = Array.from({ length: r }, () => Array(c));
    for (let k = 0; k < m * n; k++) {
        result[Math.floor(k / c)][k % c] =
            mat[Math.floor(k / n)][k % n];
    }
    return result;
};
from typing import List

class Solution:
    def matrixReshape(
        self, mat: List[List[int]], r: int, c: int
    ) -> List[List[int]]:
        m, n = len(mat), len(mat[0])
        if m * n != r * c:
            return mat

        result = [[0] * c for _ in range(r)]
        for k in range(m * n):
            result[k // c][k % c] = mat[k // n][k % n]
        return result
