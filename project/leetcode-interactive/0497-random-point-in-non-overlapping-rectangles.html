非重叠矩形中的随机点

Random Point in Non-overlapping Rectangles

在离散网格上观察随机选择：边界也属于矩形，而每一个被覆盖的整数点都应拥有完全相同的机会。

中等 数组 数学 二分查找 前缀和
Problem

题目要求

先把输入理解为有限的整数点集合。注意，矩形是轴对齐的，四条边上的整数点也包含在内。

准确转述

给定一组互不重叠的轴对齐矩形 rects。其中 rects[i] = [aᵢ, bᵢ, xᵢ, yᵢ]，前两个数是左下角坐标，后两个数是右上角坐标。

实现一个对象，使每次调用 pick() 都返回任意一个矩形覆盖的整数坐标点 [u, v]。矩形边界上的点也算被覆盖，并且所有合法整数点被返回的概率必须相同。

整数点是横、纵坐标都为整数的点。题目要求的是“点等概率”，并非“矩形等概率”。

Solution

前缀和，把每个点变成一张票

核心洞察

如果先等概率选择矩形，就会让小矩形里的点获得更高概率。正确的抽样单位必须是整数点：矩形覆盖多少个整数点，它就占多少个连续票号。

count = (x₂ − x₁ + 1) × (y₂ − y₁ + 1)

对各矩形点数做前缀和；随后从 [1, total] 均匀抽一个票号，用二分查找定位所属矩形，再把矩形内的局部编号映射回二维坐标。

完整过程

  1. 构造时计算每个矩形的整数点数，并保存累计点数数组 prefix。
  2. 每次 pick() 均匀生成整数票号 ticket ∈ [1, total]。
  3. 二分查找第一个满足 prefix[i] ≥ ticket 的矩形。
  4. 令 offset = ticket - prefix[i-1] - 1，它是矩形内从 0 开始的局部编号。
  5. 设宽度为 w，返回 [x₁ + offset % w, y₁ + ⌊offset / w⌋]。

正确性证明

引理 1：对任意矩形，公式中的宽和高分别等于可选整数横坐标数与纵坐标数，因此乘积恰为该矩形覆盖的整数点数。

引理 2：前缀和把所有矩形分配到互不相交且无空洞的连续票号区间，每个合法整数点都对应唯一票号。

引理 3：局部编号通过取模与整除映射到矩形中的坐标是双射：不同编号不会产生同一点，每个点也都能由一个编号得到。

结论：票号从总计 total 个值中等概率抽取，而票号与合法点一一对应，所以每个合法整数点被返回的概率均为 1 / total。

边界与复杂度

  • 包含边界：宽、高计算必须加 1。
  • 负坐标：局部偏移始终非负，再加回左下角即可。
  • 随机上界：必须保证票号范围不多一个也不少一个。
  • 数值类型：累计点数宜使用足够宽的整数类型，避免迁移约束后溢出。

预处理：O(n) 时间、O(n) 额外空间。

每次 pick：O(log n) 时间、O(1) 额外空间。

常见错误

矩形等概率

矩形大小不同时会破坏点等概率。

忘记 +1

把连续面积当成整数点数，漏掉右边界和上边界。

二分边界错位

1-based 票号与 0-based offset 混用，导致首尾点偏移。

分别随机 x、y 后拒绝

包围盒很大而矩形稀疏时，拒绝采样可能极慢。

Java · ThreadLocalRandom
import java.util.concurrent.ThreadLocalRandom;

class Solution {
    private final int[][] rects;
    private final long[] prefix;
    private final long total;

    public Solution(int[][] rects) {
        this.rects = rects;
        this.prefix = new long[rects.length];

        long sum = 0;
        for (int i = 0; i < rects.length; i++) {
            long width = (long) rects[i][2] - rects[i][0] + 1;
            long height = (long) rects[i][3] - rects[i][1] + 1;
            sum += width * height;
            prefix[i] = sum;
        }
        this.total = sum;
    }

    public int[] pick() {
        long ticket = ThreadLocalRandom.current().nextLong(total) + 1;

        int left = 0;
        int right = prefix.length - 1;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (prefix[mid] >= ticket) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }

        int[] rect = rects[left];
        long previous = left == 0 ? 0 : prefix[left - 1];
        long offset = ticket - previous - 1;
        long width = (long) rect[2] - rect[0] + 1;

        int x = (int) (rect[0] + offset % width);
        int y = (int) (rect[1] + offset / width);
        return new int[] {x, y};
    }
}

/**
 * @param {number[][]} rects
 */
var Solution = function(rects) {
    this.rects = rects;
    this.prefix = [];

    let sum = 0;
    for (const [x1, y1, x2, y2] of rects) {
        const width = x2 - x1 + 1;
        const height = y2 - y1 + 1;
        sum += width * height;
        this.prefix.push(sum);
    }
    this.total = sum;
};

/**
 * @return {number[]}
 */
Solution.prototype.pick = function() {
    const ticket = Math.floor(Math.random() * this.total) + 1;

    let left = 0;
    let right = this.prefix.length - 1;
    while (left < right) {
        const mid = left + Math.floor((right - left) / 2);
        if (this.prefix[mid] >= ticket) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }

    const [x1, y1, x2] = this.rects[left];
    const previous = left === 0 ? 0 : this.prefix[left - 1];
    const offset = ticket - previous - 1;
    const width = x2 - x1 + 1;

    return [
        x1 + (offset % width),
        y1 + Math.floor(offset / width)
    ];
};
Python 3 · bisect_left
from bisect import bisect_left
from random import randrange
from typing import List


class Solution:
    def __init__(self, rects: List[List[int]]):
        self.rects = rects
        self.prefix = []

        total = 0
        for x1, y1, x2, y2 in rects:
            width = x2 - x1 + 1
            height = y2 - y1 + 1
            total += width * height
            self.prefix.append(total)

        self.total = total

    def pick(self) -> List[int]:
        ticket = randrange(1, self.total + 1)
        index = bisect_left(self.prefix, ticket)

        x1, y1, x2, _ = self.rects[index]
        previous = 0 if index == 0 else self.prefix[index - 1]
        offset = ticket - previous - 1
        width = x2 - x1 + 1

        return [
            x1 + offset % width,
            y1 + offset // width,
        ]
C++17 · lower_bound
#include <algorithm>
#include <random>
#include <vector>
using namespace std;

class Solution {
private:
    vector<vector<int>> rects;
    vector<long long> prefix;
    mt19937_64 generator;

public:
    Solution(vector<vector<int>>& rects)
        : rects(rects), generator(random_device{}()) {
        long long sum = 0;
        for (const auto& rect : rects) {
            long long width = static_cast<long long>(rect[2]) - rect[0] + 1;
            long long height = static_cast<long long>(rect[3]) - rect[1] + 1;
            sum += width * height;
            prefix.push_back(sum);
        }
    }

    vector<int> pick() {
        uniform_int_distribution<long long> distribution(1, prefix.back());
        long long ticket = distribution(generator);

        int index = static_cast<int>(
            lower_bound(prefix.begin(), prefix.end(), ticket) - prefix.begin()
        );

        const auto& rect = rects[index];
        long long previous = index == 0 ? 0 : prefix[index - 1];
        long long offset = ticket - previous - 1;
        long long width = static_cast<long long>(rect[2]) - rect[0] + 1;

        return {
            static_cast<int>(rect[0] + offset % width),
            static_cast<int>(rect[1] + offset / width)
        };
    }
};

替代方案

线性扫描前缀和：抽到票号后逐个矩形累减点数，代码更短，每次调用为 O(n)。当矩形数很少时足够实用。

蓄水池式加权选择：可在一次扫描里按权重选择矩形，然后在矩形内随机取点；每次仍需 O(n)，但无需保存前缀和。

包围盒拒绝采样：理论上可行，但当矩形很稀疏时接受率极低，不适合作为稳健方案。
