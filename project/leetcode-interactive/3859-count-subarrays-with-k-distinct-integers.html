统计包含 K 个不同整数的子数组

给定整数数组 nums 和整数 k，返回恰好包含 k 个不同整数的非空连续子数组数量。

关键等式：恰好 K 种 = 至多 K 种 − 至多 K−1 种。

示例

nums = [1, 2, 1, 2, 3]

k = 2

输出：7

相同集合的多个左端点都可以形成合法子数组，因此每次右端点扩展时累计窗口长度。

题意速读

“不同整数的数量”看的是窗口中的不同值，不是元素数量。比如 [1, 2, 1] 含 2 个不同整数。

输入中的空格均以 ␠ 显示；本页数组输入采用标准 nums = [..] 形式，字符串场景会保留成对直引号。

推荐面试解：维护 atMost(K) 与 atMost(K−1) 两个线性滑窗，避免枚举所有子数组。

题解

核心洞察

直接求“恰好 K 种”时左边界不容易累计。把问题改写为 atMost(k) - atMost(k - 1)：每个右端点上，至多 K 种的合法左端点数减去至多 K−1 种的合法左端点数，恰好留下 K 种。

完整过程

  1. 写辅助函数 atMost(limit)。
  2. 右端点依次加入一个值，并增加频次。
  3. 当不同值超过 limit 时，不断收缩左端点。
  4. 当前右端点能形成 right - left + 1 个至多 limit 的子数组。
  5. 两次辅助函数结果相减。

边界与常见错误

  • k = 1 时仍要计算 atMost(0)，其结果应为 0。
  • 不要把频次降为 0 的键继续计为不同值。
  • 答案可能超出 32 位范围；JavaScript 使用 Number 在常见题目约束下安全，Java/C++ 用 long。

替代方案与面试追问

也可用一个窗口加“前导重复元素”计数，但实现更易错。追问：如果值域很小，可将哈希表替换为定长数组；如果需要统计至少 K 种，可用总子数组数减至多 K−1 种。
