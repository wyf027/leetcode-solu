    Solution unlocked

    聚合天然保留 NULL

    MAX(...) 在没有匹配行时仍返回一行 NULL，正好满足输出契约。

    主线

    先求最高薪资，再过滤出更低的行，对其求 MAX。重复最高值不会影响过滤；不存在第二档时聚合返回 NULL。 

    SELECT MAX(salary) AS SecondHighestSalary
FROM Employee
WHERE salary < (SELECT MAX(salary) FROM Employee);

    替代方案比较

    • DISTINCT + ORDER BY ... LIMIT/OFFSET 简洁，但必须包成标量子查询才能在无第二行时输出 NULL。
    • DENSE_RANK() 适合扩展到任意第 N 高，但本题略重；仍需条件聚合保证一行。
    • 普通 ROW_NUMBER() 不先去重会把重复最高薪资误当第二名。

    import pandas as pd

def second_highest_salary(employee: pd.DataFrame) -> pd.DataFrame:
    salaries = employee["salary"].drop_duplicates().sort_values(ascending=False)
    value = salaries.iloc[1] if len(salaries) >= 2 else None
    return pd.DataFrame({"SecondHighestSalary": [value]})

    窗口函数扩展

    WITH ranked AS (
  SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
  FROM Employee
)
SELECT MAX(CASE WHEN rnk = 2 THEN salary END) AS SecondHighestSalary
FROM ranked;

    面试追问

    • 如何推广到第 N 高？
    • 索引对聚合与排序方案有何影响？
    • salary 可为 NULL 时语义是否变化？

    常见错误

    • 忘记 DISTINCT，重复最高值占据第二名。
    • LIMIT 查询无行，而不是一行 NULL。
    • 列别名拼写不符合契约。
    • 用 ROW_NUMBER 处理重复薪资。
