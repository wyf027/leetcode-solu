Problem 639 · Decode Ways II

解码方法 II把一个星号，拆成可计算的选择数。

数字可以映射为 A–Z，而 * 可以代表 1–9。你的任务不是列出所有展开结果，而是统计整条消息有多少种合法解码，并对 10⁹ + 7 取模。

Official signature
numDecodings(s: string): integer

输入只包含数字与 *；输出为解码方法数。

01 · Problem

题目在问什么？

一条由数字和 * 组成的消息，需要从左到右切分成一位或两位的编码片段。合法片段必须对应 1–26；其中 * 可独立选择 1–9，但不能表示 0。统计所有可能的星号取值与所有合法分组共同产生的解码数量。

1 → A最小的合法编码
…每段只能取 1–26
26 → Z最大的合法编码
关键规则：0 不能单独解码，只能出现在 10 或 20 中；带前导零的片段（如 06）无效。
Example 01
输入：s = "*"
输出：9

* 可取 1–9，分别对应 A–I，共 9 种。

Example 02
输入：s = "1*"
输出：18

9 种星号取值都可按一位拆分，也都能与 1 合并为两位，共 18 种。

Example 03
输入：s = "2*"
输出：15

21–26 可整体解码，27–29 不可；加上 9 种逐位拆分，共 15 种。

约束

  • 1 ≤ s.length ≤ 10⁵
  • s[i] 是数字 0–9 或字符 *
  • 答案按 1,000,000,007 取模

04 · Full Solution

动态规划：数选择，不展开字符串

星号会让具体字符串数量指数膨胀，但每个位置对答案的影响只取决于当前字符、前一个字符，以及前两级前缀答案。因此，只需把“这个字符能产生几种合法一位/两位编码”压缩成两个常数。

核心洞察

令 dp[i] 表示前 i 个字符的解码方法数。任何完整解码的最后一段长度只能是 1 或 2，这两类方案互不重叠。

dp[i] = dp[i-1] × one(s[i-1])
+ dp[i-2] × two(s[i-2], s[i-1])

一位计数 one(c)

  • c = '*'：可取 1–9，计数为 9。
  • c = '0'：不能单独解码，计数为 0。
  • c = '1'..'9'：计数为 1。

两位计数 two(a, b)

  • **：11–19 有 9 个，21–26 有 6 个，共 15。
  • *d：若 d ≤ 6，十位可为 1 或 2，共 2；否则只能为 1，共 1。
  • 1* 为 9，2* 为 6，其余 d* 为 0。
  • 两个数字：组成的数在 10–26 时为 1，否则为 0。

完整过程

  1. 设 dp[0] = 1，表示空前缀有一种“什么都不选”的构造方式。
  2. 初始化 dp[1] = one(s[0])。
  3. 从第二个字符起，分别累加单字符与双字符贡献，并立即取模。
  4. 转移只依赖前两项，用两个变量滚动保存，空间降为常数。

正确性证明

命题：对任意 i ≥ 0，转移得到的 dp[i] 等于前 i 个字符的合法解码方法数。

基础：dp[0] = 1 对应空前缀的唯一空方案；dp[1] = one(s[0]) 精确枚举第一个字符能够表示的合法单字符编码。

归纳：假设长度小于 i 的状态正确。长度为 i 的任一合法解码，其最后一段要么只使用第 i 个字符，要么使用最后两个字符。第一类有 dp[i-1] × one(s[i-1]) 种，第二类有 dp[i-2] × two(s[i-2], s[i-1]) 种。两类按最后一段长度划分，互斥且覆盖全部方案，因此相加正好得到 dp[i]。归纳成立。

复杂度

时间：O(n)，每个字符只处理一次。

额外空间：O(1)，只保留连续两个 DP 状态。

边界处理

  • 字符串以 0 开头时，第一项就是 0。
  • *0 只有 10、20 两种两位取值。
  • 连续星号时必须同时计算 9 种单值与 15 种双值。
  • 每一步都取模；乘法中间值需使用足够宽的整数类型。

替代方案

可以保存完整 dp 数组，时间仍是 O(n)，空间为 O(n)，更便于教学或回溯状态。显式展开每个 * 会产生最多 9^k 个字符串，不适用于本题规模。

面试追问

  • 若通配符还能表示 0，计数函数应如何变化？
  • 若映射范围扩展到 1–999，状态需要回看几项？
  • 如何用矩阵乘法处理超长重复片段？

四语言完整实现

class Solution {
    private static final long MOD = 1_000_000_007L;

    public int numDecodings(String s) {
        long prev2 = 1;                 // dp[0]
        long prev1 = single(s.charAt(0)); // dp[1]

        for (int i = 1; i < s.length(); i++) {
            long current = (
                prev1 * single(s.charAt(i))
                + prev2 * pair(s.charAt(i - 1), s.charAt(i))
            ) % MOD;
            prev2 = prev1;
            prev1 = current;
        }
        return (int) prev1;
    }

    private long single(char c) {
        if (c == '*') return 9;
        return c == '0' ? 0 : 1;
    }

    private long pair(char a, char b) {
        if (a == '*' && b == '*') return 15;
        if (a == '*') return b <= '6' ? 2 : 1;
        if (b == '*') {
            if (a == '1') return 9;
            if (a == '2') return 6;
            return 0;
        }
        int value = (a - '0') * 10 + (b - '0');
        return value >= 10 && value <= 26 ? 1 : 0;
    }
}

class Solution {
public:
    int numDecodings(string s) {
        const long long MOD = 1'000'000'007LL;
        long long prev2 = 1;
        long long prev1 = single(s[0]);

        for (int i = 1; i < static_cast<int>(s.size()); ++i) {
            long long current = (
                prev1 * single(s[i])
                + prev2 * pairCount(s[i - 1], s[i])
            ) % MOD;
            prev2 = prev1;
            prev1 = current;
        }
        return static_cast<int>(prev1);
    }

private:
    long long single(char c) {
        if (c == '*') return 9;
        return c == '0' ? 0 : 1;
    }

    long long pairCount(char a, char b) {
        if (a == '*' && b == '*') return 15;
        if (a == '*') return b <= '6' ? 2 : 1;
        if (b == '*') {
            if (a == '1') return 9;
            if (a == '2') return 6;
            return 0;
        }
        int value = (a - '0') * 10 + (b - '0');
        return value >= 10 && value <= 26 ? 1 : 0;
    }
};

常见错误

  • 把 * 当成 0–9 共 10 个数字；本题明确排除 0。
  • 认为 ** 有 18 种两位组合；实际只有 11–19 与 21–26，共 15 种。
  • 漏掉 *0 的 10、20，或错误地让 0 单独解码。
  • 先算完整大整数、最后才取模，导致固定宽度整数溢出。
  • 显式枚举星号展开结果，使复杂度随星号数量指数增长。
