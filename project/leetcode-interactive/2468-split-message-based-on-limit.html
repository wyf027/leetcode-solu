根据限制分割消息

Split Message Based on Limit

每段消息都有长度预算，编号也会占用空间。
将原文装入尽可能少的段落，保留每一个字符与空格。

01 / THE BRIEF

题目规则

  1. 给定字符串 message 和正整数 limit，把消息按原顺序分成若干连续部分。
  2. 若总共有 b 段，第 a 段末尾追加 <a/b>，编号从 1 到 b。
  3. 计入后缀后，前 b−1 段的长度必须等于 limit；最后一段长度不超过 limit。
  4. 去掉所有后缀后按顺序拼接，必须恢复原消息。返回段数最少的字符串数组，无法分割则返回 []。
完整约束
1 ≤ message.length ≤ 10⁴
message 只包含英文小写字母和普通空格。
1 ≤ limit ≤ 10⁴
参数：splitMessage(message: string, limit: integer) → string[]

05 / EDITORIAL
独立题解
核心洞察：确定分母，再切正文
后缀长度是 3 + digits(a) + digits(b)，三个固定符号分别是左右尖括号与斜杠。固定总段数 b 后，各段能放多少正文就确定了。


完整过程
  1. 令 n 为原文长度，按升序枚举 b=1…n。维护 S(b)=Σ digits(a)，每次只加上新编号 b 的位数。
  2. 令 d=digits(b)。所有段的总正文容量为 C=b×(limit−3−d)−S(b)，最后一段的正文容量为 L=limit−3−2d。
  3. 若 L≤0，当前及后续编号的尾段都放不下正文，停止搜索。
  4. 候选精确可行条件是 C−L < n ≤ C：前 b−1 段填满后至少剩一个字符，且尾段能装下剩余正文。
  5. 找到第一个可行 b 后，依次生成后缀，从原文游标取出 limit−suffix.length 个字符，再附上后缀。尾段截断到 n。
  6. 没有可行候选时返回空数组。


位数跳变：为什么不能直接全局二分？
limit=9 时，b=9 的正文总容量为 36；b=10 时所有分母都多一位，总容量反而降到 29。b=13 的容量是 35，b=14 才达到 37。容量并非全局单调。
示例 1 的原文长 37；b=14 时前 9 段各装 3 个正文字符，后 5 段各装 2 个，共 27+10=37。枚举会先跳过 b=1…13，然后构造 14 段。


正确性证明
  1. 固定 b 的必要条件：前 b−1 段必须恰好填满，它们消耗 C−L 个字符；剩余字符必须在 1 到 L 之间，因此需要 C−L<n≤C，且 L>0。
  2. 固定 b 的充分条件：按各段容量顺序切片时，前面各段都能填满，最后剩余正文不超过 L。切片连续且不重叠，去掉后缀后恰好恢复原文。
  3. 最小性：升序检查所有候选，首个可行 b 就是最少段数。最优方案不需要空正文的尾段：删除这样的尾段后，总数减少、后缀不增长，可重新顺序装填并在原文耗尽处结束。因此只考虑每段至少一个正文字符即可，b≤n。
  4. 提前终止：L 随编号位数增加只会减小；L≤0 后，更大 b 的尾段也无法承载正文。


边界与常见错误
  • limit≤5，最短后缀已占完预算。
  • 9→10、99→100 会改变所有分母的位数。
  • 空格计入长度；不能 trim，也不能按单词分段。
  • 除了尾段，其他段必须填满。
  • 别漏算斜杠：固定符号一共三个。
  • Java substring 尾段必须截断到 n。
  • 先切后补编号会导致正文容量计算失效。
复杂度
代码用字符串转换计算位数，保守时间复杂度 O(n log n)；返回内容占 O(n+b log b) 字符空间。除输出数组和输出字符串外，临时编号等辅助空间为 O(log n)。
用十进制阈值维护位数，可将枚举部分降为 O(n)、辅助空间降为 O(1)；构造最终字符串仍需与实际输出长度成正比的时间。


替代方案与面试追问
  • 能分区间二分吗？能。固定分母位数 d 后，在 L>0 的区间中，每新增一段使容量增加 L；可二分 C≥n 的首个候选，再检查精确可行条件。
  • 还能更直接吗？用各位数区间内的线性容量公式直接求首个候选，但边界处理比本题 n≤10⁴ 下的枚举复杂。
  • 为什么不每次试切？每个 b 都逐段统计可能达 O(n²)；维护位数和避免重复计算。
  • 如果后缀格式改变？重新推导长度函数，检查容量的单调区间，不能照搬固定常数 3。
  • 如果输入含 Unicode？先约定字符、码点或字节长度。当前仅小写英文和空格，四语言的长度语义一致。

JavaScript
/**
 * @param {string} message
 * @param {number} limit
 * @return {string[]}
 */
var splitMessage = function(message, limit) {
    const n = message.length;
    let digitSum = 0;
    for (let b = 1; b <= n; b++) {
        const d = String(b).length;
        digitSum += d;
        const last = limit - 3 - 2 * d;
        if (last <= 0) break;
        const total = b * (limit - 3 - d) - digitSum;
        if (total < n || total - last >= n) continue;
        const answer = [];
        let pos = 0;
        for (let a = 1; a <= b; a++) {
            const suffix = `<${a}/${b}>`;
            const take = limit - suffix.length;
            answer.push(message.slice(pos, pos + take) + suffix);
            pos += take;
        }
        return answer;
    }
    return [];
};


Java
class Solution {
    public String[] splitMessage(String message, int limit) {
        int n = message.length(), digitSum = 0;
        for (int b = 1; b <= n; b++) {
            int d = Integer.toString(b).length();
            digitSum += d;
            int last = limit - 3 - 2 * d;
            if (last <= 0) break;
            int total = b * (limit - 3 - d) - digitSum;
            if (total < n || total - last >= n) continue;
            String[] answer = new String[b];
            int pos = 0;
            for (int a = 1; a <= b; a++) {
                String suffix = "<" + a + "/" + b + ">";
                int end = Math.min(n, pos + limit - suffix.length());
                answer[a - 1] = message.substring(pos, end) + suffix;
                pos = end;
            }
            return answer;
        }
        return new String[0];
    }
}

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> splitMessage(string message, int limit) {
        int n = static_cast<int>(message.size()), digitSum = 0;
        for (int b = 1; b <= n; ++b) {
            int d = static_cast<int>(to_string(b).size());
            digitSum += d;
            int last = limit - 3 - 2 * d;
            if (last <= 0) break;
            int total = b * (limit - 3 - d) - digitSum;
            if (total < n || total - last >= n) continue;
            vector<string> answer;
            int pos = 0;
            for (int a = 1; a <= b; ++a) {
                string suffix = "<" + to_string(a) + "/" + to_string(b) + ">";
                int take = limit - static_cast<int>(suffix.size());
                answer.push_back(message.substr(pos, take) + suffix);
                pos += take;
            }
            return answer;
        }
        return {};
    }
};
