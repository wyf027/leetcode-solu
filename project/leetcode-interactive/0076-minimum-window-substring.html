    Core insight

    核心洞察：有效窗口只需向内收

    右指针单调右移，把字符加入窗口；当所有目标频次满足后，继续右扩只会更长，所以让左指针右移，直到刚好破坏覆盖条件。每个字符最多加入、移出各一次。

    Window invariant

    循环不变量

    • • need[c] 保存 t 对字符 c 的需求次数。
    • • window[c] 只统计当前区间 [left,right]。
    • • formed == required 当且仅当全部不同目标字符已达标。
    • • 只在窗口有效时记录答案，并在每次左移前比较长度。

    完整过程

    1. 1. 统计 t 的需求频次和不同字符数。
    2. 2. 右移 right；字符首次达到需求时 formed 加一。
    3. 3. formed 达标后更新最优解，并移出 s[left]。
    4. 4. 某字符跌破需求时停止收缩，继续右扩。

    边界与复杂度

    • • t 比 s 长时必然返回空串。
    • • 重复字符按次数匹配；大小写敏感。
    • • 时间 O(m+n)，空间 O(|Σ|)，英文字符集下可视为 O(1)。

    替代方案取舍

    暴力枚举至少 O(m²)，无法承受 10⁵。可过滤 s 中只属于 t 的字符以减少常数，但主线优先写清晰的标准滑动窗口。

    常见错误

    • • 用集合代替频次表，遗漏重复字符。
    • • 移出左端字符后再错误地判断旧区间。
    • • 以 formed == t.length 判断，混淆不同字符数与总数。

    面试追问

    • • 为什么两层 while 仍是 O(m+n)？
    • • Unicode 字符集下数组与哈希表如何取舍？
    • • 若答案不保证唯一，如何返回全部最短窗口？
    class Solution {
    public String minWindow(String s, String t) {
        int[] need = new int[128], window = new int[128];
        for (char c : t.toCharArray()) need[c]++;
        int missing = t.length(), left = 0;
        int bestStart = 0, bestLength = Integer.MAX_VALUE;
        for (int right = 0; right < s.length(); right++) {
            char current = s.charAt(right);
            if (window[current] < need[current]) missing--;
            window[current]++;
            while (missing == 0) {
                int length = right - left + 1;
                if (length < bestLength) {
                    bestLength = length;
                    bestStart = left;
                }
                char removed = s.charAt(left++);
                window[removed]--;
                if (window[removed] < need[removed]) missing++;
            }
        }
        return bestLength == Integer.MAX_VALUE
            ? "" : s.substring(bestStart, bestStart + bestLength);
    }
}

  const need = new Map();
  for (const c of t) need.set(c, (need.get(c) || 0) + 1);
  const window = new Map();
  let missing = t.length, left = 0;

    const c = s[right];

    if (before < (need.get(c) || 0)) missing--;

      const length = right - left + 1;

        bestStart = left;

      const removed = s[left++];

    }

                length = right - left + 1
