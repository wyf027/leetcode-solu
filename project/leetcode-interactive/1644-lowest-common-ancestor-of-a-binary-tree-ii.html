01 / PROBLEM

题意

给定一棵二叉树的根节点 root，以及两个互不相同的节点引用 p、q。只有当二者都实际存在于树中时，返回它们的最近公共祖先；只要有一个不存在，就返回 null。

“最近公共祖先”是什么？

在同时包含 p 与 q 的祖先中，深度最大的那个节点。按照通常定义，节点也可以是自己的祖先。

与经典 LCA 的关键差异

不能假设 p、q 都在树里。某个搜索结果“长得像答案”，并不代表两个目标都被找到。

判断按节点身份，而不是只按值。 题目保证树内节点值唯一，但函数参数本质上仍是节点引用；代码使用 node == p / node == q。
1

分处根节点两侧

输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3

节点 5 和节点 1 的最低汇合点是根节点 3。

2

一个目标是另一个的祖先

输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5

节点可以是自己的祖先，因此最近公共祖先是节点 5。

3

目标不完整

输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 10
输出：null

节点 10 不在树中，即使找到了节点 5，也必须返回空。

约束

  • 树中节点数在 [1, 10⁴] 范围内。
  • -10⁹ ≤ Node.val ≤ 10⁹。
  • 树中所有节点值互不相同。
  • p != q。
  • p 和 q 不保证都存在于树中。

04 / SOLUTION

题解：让子树带回证据

一次后序 DFS 同时计算候选祖先和目标出现数量。最终只有 found == 2 才放行候选。

本节目录 核心洞察 完整过程 正确性 边界与复杂度 四语言代码 替代方案 面试追问 常见错误

核心洞察

经典 LCA 递归可以产生一个候选节点，但当只有一个目标存在时，它也可能返回那个唯一目标。于是每棵子树需要额外返回 found：该子树里发现了多少个目标。

State = { found: 0 | 1 | 2, lca: TreeNode | null }

当某节点汇总左右子树和自己后首次得到 found == 2，该节点就是最低的汇合点。更深子树若已得到 LCA，则一路原样向上传递。

完整过程

  1. 空节点返回 (0, null)。
  2. 后序递归左右子树，得到 left 与 right 状态。
  3. 若当前节点身份等于 p 或 q，为计数加一。
  4. 优先继承左右子树已经确定的 LCA；若二者都没有，而当前汇总计数恰为 2，则把当前节点设为 LCA。
  5. 根节点最终状态若找到 2 个目标，返回 LCA；否则返回 null。

正确性证明

引理 1：对任意节点 x，DFS 返回的 found 等于 x 子树中属于 {p, q} 的节点数。空树显然为 0；非空树由左右子树计数与当前节点是否命中相加得到，因此由结构归纳成立。

引理 2：若 x 的某个真子树已经返回非空 LCA，该 LCA 仍是 x 子树内的最近公共祖先。两个目标已经同时落在更深的同一子树，提升到 x 不会更近，所以应直接继承。

引理 3：若左右子树都没有 LCA，而 x 汇总后首次得到 found=2，则两个目标要么分处左右子树，要么一个就是 x、另一个在其下方。两种情况下 x 都是最低公共祖先。

定理：由引理 1，根状态的 found=2 当且仅当两个目标都存在；由引理 2、3，此时 lca 是最近公共祖先。否则算法返回 null，符合题意。

边界情况

  • 只有 p 存在：候选不会被放行。
  • 两者都不存在：found 为 0。
  • p 是 q 的祖先：LCA 为 p。
  • 树退化成链：递归深度达到 n。
  • 比较节点引用，避免把同值对象误当作目标。

复杂度

时间：O(n)，每个树节点访问一次。

额外空间：O(h)，递归栈深度为树高 h；平衡树是 O(log n)，最坏链状树是 O(n)。

四语言完整实现

四份代码均按 LeetCode 的 TreeNode 环境编写，返回的是节点引用而非节点值。

class Solution {
    private static class State {
        int found;
        TreeNode lca;

        State(int found, TreeNode lca) {
            this.found = found;
            this.lca = lca;
        }
    }

    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        State state = dfs(root, p, q);
        return state.found == 2 ? state.lca : null;
    }

    private State dfs(TreeNode node, TreeNode p, TreeNode q) {
        if (node == null) {
            return new State(0, null);
        }

        State left = dfs(node.left, p, q);
        State right = dfs(node.right, p, q);

        int self = (node == p || node == q) ? 1 : 0;
        int found = Math.min(2, left.found + right.found + self);

        TreeNode lca = left.lca != null ? left.lca : right.lca;
        if (lca == null && found == 2) {
            lca = node;
        }
        return new State(found, lca);
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *   this.val = (val === undefined ? 0 : val);
 *   this.left = (left === undefined ? null : left);
 *   this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @param {TreeNode} p
 * @param {TreeNode} q
 * @return {TreeNode}
 */
var lowestCommonAncestor = function(root, p, q) {
  function dfs(node) {
    if (node === null) return { found: 0, lca: null };

    const left = dfs(node.left);
    const right = dfs(node.right);
    const self = (node === p || node === q) ? 1 : 0;
    const found = Math.min(2, left.found + right.found + self);

    let lca = left.lca !== null ? left.lca : right.lca;
    if (lca === null && found === 2) lca = node;

    return { found, lca };
  }

  const state = dfs(root);
  return state.found === 2 ? state.lca : null;
};

# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

    def lowestCommonAncestor(
        self,
        root: 'TreeNode',
        p: 'TreeNode',

        def dfs(node):
            if node is None:
                return 0, None

        return lca if found == 2 else None
class Solution {
    struct State {
        int found;
        TreeNode* lca;
    };

    State dfs(TreeNode* node, TreeNode* p, TreeNode* q) {
        if (node == nullptr) return {0, nullptr};

        State left = dfs(node->left, p, q);
        State right = dfs(node->right, p, q);

        int self = (node == p || node == q) ? 1 : 0;
        int found = min(2, left.found + right.found + self);

        TreeNode* lca = left.lca != nullptr ? left.lca : right.lca;
        if (lca == nullptr && found == 2) lca = node;
        return {found, lca};
    }

public:
    TreeNode* lowestCommonAncestor(
        TreeNode* root,
        TreeNode* p,
        TreeNode* q
    ) {
        State state = dfs(root, p, q);
        return state.found == 2 ? state.lca : nullptr;
    }
};

替代方案

经典 LCA + 全局计数

递归仍返回经典候选，同时每遇到 p 或 q 就累加全局计数，最终计数为 2 才返回候选。代码更短，但“结果”和“证据”分散在返回值与外部变量里，复用与证明稍弱。

父指针 + 祖先集合

遍历全树建立每个节点的父指针，并记录是否见过 p、q；确认都存在后，从 p 向上构造祖先集合，再从 q 向上找第一个交点。时间 O(n)、空间 O(n)，递归深度风险更小，也更适合后续多次查询。

多查询场景

如果同一棵静态树上有大量 LCA 查询，可预处理倍增表或 Euler Tour + RMQ；但仍须先维护节点是否属于该树。单次查询使用它们属于过度设计。

面试追问

如果树可能有 10⁵ 层怎么办？递归可能爆栈，改用显式栈模拟后序遍历，或用父指针方案。
为什么不能找到 p 后就提前返回？还必须确认 q 是否存在；若 p 是 q 的祖先，也只有搜索到 q 后才能证明答案成立。
如果 p 和 q 允许相同呢？题目保证不同。若放宽条件，需要重新定义“找到两个目标”的计数语义；通常 p==q 且该节点存在时直接返回它。
如果节点值不唯一呢？本解法不受影响，因为比较的是节点对象身份，不是 val。

常见错误

  • 直接提交 LeetCode 236 的经典递归，漏掉“节点可能不存在”的条件。
  • 用 node.val == p.val 判断身份，把值和节点引用混淆。
  • 一发现某个目标就剪枝，导致无法确认另一个目标是否存在。
  • 只看某个局部子树的 found，不在根节点对总 found 做最终门禁。
  • 忽略最坏 O(n) 的递归深度，在极端链状树上产生栈溢出风险。
