查找总价格为目标值的两个商品

价格已按升序记录。请在购物车中找到总价恰好等于目标的一对商品，并观察候选范围如何逐步缩小。

官方题意

购物车内商品价格按升序记录于数组 price。寻找两个商品，使它们的价格和恰好为 target；若有多种答案，返回任意一对价格即可。不存在时返回空数组。

示例 1price = [3, 9, 12, 15]
target = 18
输出：[3, 15] 或 [15, 3]
示例 2price = [8, 21, 27, 34, 52, 66]
target = 61
输出：[27, 34] 或 [34, 27]
约束1 ≤ price.length ≤ 10⁵
1 ≤ price[i] ≤ 10⁶
1 ≤ target ≤ 2 × 10⁶

输入完整参数：price = [3, 9, 12, 15]、target = 18。价格必须为升序正整数；无效输入会恢复官方示例。

题解：从两端收缩的双指针

核心洞察

数组已升序。最小端与最大端的和若偏小，左指针右移才能让和变大；若偏大，右指针左移才能让和变小。每次都排除了不可能配对的一端。

完整过程

  1. 令 left = 0、right = price.length - 1。
  2. 计算 price[left] + price[right]。
  3. 相等即返回两项；偏小则 left++，偏大则 right--。
  4. 指针相遇仍未命中，返回空数组。

边界与复杂度

仅一个商品时无解；题目允许不存在或多解，任意一对即可。两个指针各只单向移动一次，时间 O(n)，额外空间 O(1)。

替代方案、面试追问与常见错误

替代方案是哈希表，适用于未排序输入，时间 O(n) 但空间 O(n)。追问：若要返回全部不重复数对，命中后跳过重复值。常见错误：返回下标而非价格、无序数组仍套双指针、或比较后移动了错误一侧。 
/** @param {number[]} price @param {number} target @return {number[]} */
var twoSum = function(price, target) {
  let left = 0, right = price.length - 1;
  while (left < right) {
    const sum = price[left] + price[right];
    if (sum === target) return [price[left], price[right]];
    if (sum < target) left++;
    else right--;
  }
  return [];
};
