Check if There is a Valid Path in a Grid

题目

固定街道上的连通性

给定一个 m × n 的整数网格，每个数字代表一种不能旋转或更改的街道。

你从左上角 (0, 0) 出发，目标是右下角 (m - 1, n - 1)。每一步只能沿当前格子的街道出口进入相邻格子，并且相邻格子必须在相反方向也有接口。

如果存在一条完全沿街道连接的路径，返回 true；否则返回 false。不能修改任何街道。

关键规则：“当前格能出去”还不够，“邻格能接住”才构成一次合法移动。

核心洞察：把网格看成隐式图

节点与边

每个格子是一个节点。若当前街道在方向 d 上有出口，并且相邻街道在反方向 opp(d) 上也有出口，两格之间才存在边。

搜索目标

从 (0,0) 做 BFS 或 DFS。只要访问到 (m-1,n-1) 就返回 true；搜索耗尽仍未到达则返回 false。

完整过程

  1. 编码街道接口。为 1～6 建立方向集合：左右、上下、左下、右下、左上、右上。
  2. 初始化搜索。将起点加入队列并标记已访问，避免环路导致重复扩展。
  3. 检查四个方向。先确认当前格有该方向出口，再检查边界与邻格的反向接口。
  4. 推进搜索。合法且未访问的邻格入队；一旦取出终点即可成功结束。
  5. 处理失败。队列清空说明起点所在连通分量不包含终点，返回 false。

正确性证明

引理 1：搜索加入的每个格子都能由起点沿有效街道到达。起点显然成立；若当前格可达，算法仅在双方接口匹配时加入邻格，因此拼接这一步后邻格也可达。

引理 2：从起点可达的每个格子最终都会被搜索访问。对任意有效路径按长度归纳：起点已访问；路径上前一格被扩展时，双方接口匹配，后一格必会入队。

定理：算法返回 true 当且仅当存在有效路径。返回 true 时由引理 1，终点可达；存在路径时由引理 2，终点必被访问并触发 true。

边界与复杂度

边界

  • 1 × 1：起点即终点，直接为 true。
  • 细长单行或单列：仍使用相同的边界与接口规则。
  • 成环街道：visited 防止无限循环。
  • 出口指向网格外：忽略该方向。

复杂度

每个格子最多入队一次，每次检查至多 4 个方向。

时间：O(mn)
空间：O(mn)

四语言完整代码

import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    private static final int[][] DIRS = {
        {-1, 0}, {0, 1}, {1, 0}, {0, -1}
    };
    private static final boolean[][] OPEN = {
        {},
        {false, true, false, true},   // 1: right, left
        {true, false, true, false},   // 2: up, down
        {false, false, true, true},   // 3: down, left
        {false, true, true, false},   // 4: right, down
        {true, false, false, true},   // 5: up, left
        {true, true, false, false}    // 6: up, right
    };

    public boolean hasValidPath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        boolean[][] visited = new boolean[m][n];
        Queue<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{0, 0});
        visited[0][0] = true;

        while (!queue.isEmpty()) {
            int[] cell = queue.poll();
            int r = cell[0], c = cell[1];
            if (r == m - 1 && c == n - 1) return true;

            for (int d = 0; d < 4; d++) {
                if (!OPEN[grid[r][c]][d]) continue;
                int nr = r + DIRS[d][0], nc = c + DIRS[d][1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n || visited[nr][nc]) continue;
                int opposite = (d + 2) % 4;
                if (!OPEN[grid[nr][nc]][opposite]) continue;
                visited[nr][nc] = true;
                queue.offer(new int[]{nr, nc});
            }
        }
        return false;
    }
}

var hasValidPath = function(grid) {
    const dirs = [[-1, 0], [0, 1], [1, 0], [0, -1]];
    const open = [
        [],
        [false, true, false, true],
        [true, false, true, false],
        [false, false, true, true],
        [false, true, true, false],
        [true, false, false, true],
        [true, true, false, false]
    ];
    const m = grid.length;
    const n = grid[0].length;
    const visited = Array.from({ length: m }, () => Array(n).fill(false));
    const queue = [[0, 0]];
    let head = 0;
    visited[0][0] = true;

    while (head < queue.length) {
        const [r, c] = queue[head++];
        if (r === m - 1 && c === n - 1) return true;

        for (let d = 0; d < 4; d++) {
            if (!open[grid[r][c]][d]) continue;
            const nr = r + dirs[d][0];
            const nc = c + dirs[d][1];
            if (nr < 0 || nr >= m || nc < 0 || nc >= n || visited[nr][nc]) continue;
            if (!open[grid[nr][nc]][(d + 2) % 4]) continue;
            visited[nr][nc] = true;
            queue.push([nr, nc]);
        }
    }
    return false;
};
from collections import deque
from typing import List

class Solution:
    def hasValidPath(self, grid: List[List[int]]) -> bool:
        dirs = [(-1, 0), (0, 1), (1, 0), (0, -1)]
        opened = [
            (),
            (False, True, False, True),
            (True, False, True, False),
            (False, False, True, True),
            (False, True, True, False),
            (True, False, False, True),
            (True, True, False, False),
        ]
        m, n = len(grid), len(grid[0])
        queue = deque([(0, 0)])
        visited = {(0, 0)}

        while queue:
            r, c = queue.popleft()
            if (r, c) == (m - 1, n - 1):
                return True

            for d, (dr, dc) in enumerate(dirs):
                if not opened[grid[r][c]][d]:
                    continue
                nr, nc = r + dr, c + dc
                if not (0 <= nr < m and 0 <= nc < n):
                    continue
                if (nr, nc) in visited:
                    continue
                if not opened[grid[nr][nc]][(d + 2) % 4]:
                    continue
                visited.add((nr, nc))
                queue.append((nr, nc))
        return False

class Solution {

    bool hasValidPath(vector<vector<int>>& grid) {
        const array<array<int, 2>, 4> dirs = {{{-1,0},{0,1},{1,0},{0,-1}}};
        const bool open[7][4] = {
            {false,false,false,false},
            {false,true,false,true},
            {true,false,true,false},
            {false,false,true,true},
            {false,true,true,false},
            {true,false,false,true},
            {true,true,false,false}
        };
        int m = grid.size(), n = grid[0].size();
        vector<vector<bool>> visited(m, vector<bool>(n, false));
        queue<pair<int,int>> q;
        q.push({0, 0});
        visited[0][0] = true;

        while (!q.empty()) {
            auto [r, c] = q.front();
            q.pop();
            if (r == m - 1 && c == n - 1) return true;

            for (int d = 0; d < 4; ++d) {
                if (!open[grid[r][c]][d]) continue;
                int nr = r + dirs[d][0], nc = c + dirs[d][1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n || visited[nr][nc]) continue;
                if (!open[grid[nr][nc]][(d + 2) % 4]) continue;
                visited[nr][nc] = true;
                q.push({nr, nc});
            }
        }
        return false;

替代方案与取舍

DFS

递归或显式栈均可，时间与空间复杂度相同。最大可达 90,000 个格子，递归实现可能触发语言栈深限制，显式栈更稳妥。

并查集

扫描每格，将接口匹配的相邻格合并，最后判断起终点是否同属一组。适合批量连通性查询，但本题单次查询下结构更重。

面试追问

  • 为什么只检查当前格的出口会得到错误答案？请给出反例。
  • 如果允许旋转街道，状态定义会发生什么变化？
  • 若要回答大量起点—终点连通查询，如何用并查集预处理？
  • 若街道动态修改，如何维护连通性？

常见错误

  • 只验证当前格有出口，漏掉邻格的反向接口。
  • 方向编号与反方向公式不一致；这里固定为上、右、下、左，反向为 (d + 2) % 4。
  • 出队后才标记访问，导致同一格被多次入队；应在入队时标记。
  • 忘记 1 × 1 时无需移动也已经到达终点。
