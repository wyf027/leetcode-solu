Problem 2633 / Serialization

将对象转换为
JSON 字符串

不调用 JSON.stringify，把一个合法 JSON 值递归编码成紧凑字符串，并保持 Object.keys() 给出的键顺序。

递归类型分派字符串构造 
input  → { key: { a: 1, b: […] } }
walk   → object → object → array
emit   → {"key":{"a":1,"b":[{},null,"Hello"]}}

spaces  0
order   preserved
method  recursive descent

01 / 题目

任务说明

给定参数 object，它可以是字符串、数字、数组、对象、布尔值或 null。返回该值的合法 JSON 字符串表示。

结果不能包含多余空格；对象键的顺序必须与 Object.keys(object) 的结果一致。不得使用内置的 JSON.stringify。

function jsonStringify(object: any): string
示例 1 · 对象顺序 
输入：object = {"y":1,"x":2}
输出：{"y":1,"x":2}

按 Object.keys() 的顺序依次输出 y、x。

示例 2 · 基本类型 
输入：object = {"a":"str","b":-12,"c":true,"d":null}
输出：{"a":"str","b":-12,"c":true,"d":null}

字符串加双引号；数字、布尔值和 null 使用 JSON 字面量。

示例 3 · 嵌套结构 
输入：object = {"key":{"a":1,"b":[{},null,"Hello"]}}
输出：{"key":{"a":1,"b":[{},null,"Hello"]}}

数组和对象可以继续包含任意合法 JSON 值。

示例 4 · 根节点为基本类型 
输入：object = true
输出：true

根值不一定是对象或数组，基本类型同样是合法输入。

约束

  • object 是合法 JSON 值。
  • 1 ≤ JSON.stringify(object).length ≤ 105。
  • 最大嵌套层级不超过 1000。
  • 所有字符串只包含英文字母和数字，因此本题范围内不需要处理引号、反斜杠或控制字符转义。

    04 / 完整题解
    
        
    递归定义，就是实现
    

        
    
          
    1
    先分类型
    null、字符串、数字/布尔、数组、对象各有唯一的 JSON 形态。
    
          
    2
    子值递归
    数组元素与对象的值本身仍是合法 JSON 值，交回同一个函数即可。
    
          
    3
    父层组装
    子片段用逗号连接，再加对应括号；对象还要把键与值用冒号连接。
    
        
    

        
    
          
    完整过程
    
          
      
            
    1. 若值为 null，直接返回 "null"；必须先判断，因为 JavaScript 中 typeof null === "object"。
      2. 
            
    2. 若为字符串，按本题“仅含字母和数字”的约束，在两侧加双引号。
      3. 
            
    3. 若为数字或布尔值，用 String(value) 得到紧凑字面量。
      4. 
            
    4. 若为数组，递归序列化每个元素，以逗号连接并包在 [ ] 中。
      5. 
            
    5. 否则它是对象：按 Object.keys() 枚举键，把每项变成 "key":value，以逗号连接并包在 { } 中。
      6. 
          
    
        
    

        
    
          
    
            
    正确性
    
            
    对 JSON 值的结构做归纳。基本类型分支直接产生其唯一合法表示。假设所有直接子值都能被正确序列化，则数组把正确子片段按规则置于方括号中，对象把有序键和正确子片段按规则置于花括号中，所得仍是准确的 JSON 表示。因此算法对任意允许的嵌套结构都正确。
    
          
    
          
    
            
    复杂度
    
            
      
              
    • 时间：O(n)，其中 n 为输出字符串长度，每个值与结构符号被处理常数次。
      • 
              
    • 额外空间：O(n + d)，输出/片段占 O(n)，递归栈深度为 d。
      • 
            
    
          
    
        
    

        
    
          
    
            
    边界
    
            
      
              
    • 空数组输出 []，空对象输出 {}。
      • 
              
    • 根节点可以是字符串、数字、布尔值或 null。
      • 
              
    • 必须保留对象键的枚举顺序，不可排序。
      • 
              
    • 嵌套深度可达 1000；某些运行时可能接近递归栈上限。
      • 
              
    • 题目保证字符串仅含字母和数字；通用 JSON 序列化器还必须正确转义特殊字符。
      • 
            
    
          
    
          
    
            
    替代方案
    
            
      
              
    • JSON.stringify 最直接，但题目明确禁止。
      • 
              
    • 显式栈可以规避极深递归造成的调用栈风险，代价是状态管理更复杂。
      • 
              
    • 生产级实现应增加完整字符串转义与非有限数字策略；本题约束不需要。
      •

            JavaScript · 官方可提交
            
    
              
    利用题目保证的字母数字字符串，无需额外转义分支。
    
              
    /**
 * @param {any} object
 * @return {string}
 */
var jsonStringify = function(object) {
  if (object === null) return "null";
  if (typeof object === "string") return `"${object}"`;
  if (typeof object !== "object") return String(object);

  if (Array.isArray(object)) {
    return `[${object.map(jsonStringify).join(",")}]`;
  }

  const entries = Object.keys(object).map(
    key => `"${key}":${jsonStringify(object[key])}`
  );
  return `{${entries.join(",")}}`;
};
    
            
    
          
    

          
    
            Java · 本地语义参考
            
    
              
    对象应使用保持插入顺序的 LinkedHashMap。
    
              
    import java.util.List;
import java.util.Map;
import java.util.StringJoiner;

public class Solution {
  public static String jsonStringify(Object value) {
    if (value == null) return "null";
    if (value instanceof String s) return "\"" + s + "\"";
    if (value instanceof Number || value instanceof Boolean) {
      return value.toString();
    }

    if (value instanceof List<?> list) {
      StringJoiner result = new StringJoiner(",", "[", "]");
      for (Object item : list) result.add(jsonStringify(item));
      return result.toString();
    }

    if (value instanceof Map<?, ?> map) {
      StringJoiner result = new StringJoiner(",", "{", "}");
      for (Map.Entry<?, ?> entry : map.entrySet()) {
        String key = (String) entry.getKey();
        result.add(jsonStringify(key) + ":" + jsonStringify(entry.getValue()));
      }
      return result.toString();
    }

    throw new IllegalArgumentException("Not a JSON value");
  }
}
    
            
    
          
    

          
    
            Python · 本地语义参考
            
    
              
    Python 3.7+ 字典保留插入顺序；布尔值要在整数之前判断。
    
              
    from typing import Any


def json_stringify(value: Any) -> str:
    if value is None:
        return "null"
    if isinstance(value, str):
        return f'"{value}"'
    if isinstance(value, bool):
        return "true" if value else "false"
    if isinstance(value, (int, float)):
        return str(value)
    if isinstance(value, list):
        return "[" + ",".join(json_stringify(item) for item in value) + "]"
    if isinstance(value, dict):
        entries = (
            json_stringify(key) + ":" + json_stringify(item)
            for key, item in value.items()
        )
        return "{" + ",".join(entries) + "}"
    raise TypeError("Not a JSON value")
    
            
    
          
    

          
    
            C++ · 本地语义参考
            
    
              
    用有序键值对数组表示对象；数字保留合法 JSON 数字的原始文本。
    
              
    #include <memory>
#include <stdexcept>
#include <string>
#include <utility>
#include <variant>
#include <vector>

struct Json;
using JsonPtr = std::shared_ptr<Json>;
using JsonArray = std::vector<JsonPtr>;
using JsonObject = std::vector<std::pair<std::string, JsonPtr>>;

struct JsonNumber {
  std::string text;
};

struct Json {
  using Value = std::variant<std::nullptr_t, bool, JsonNumber,
                             std::string, JsonArray, JsonObject>;
  Value value;

  template <class T>
  explicit Json(T input) : value(std::move(input)) {}
};

std::string jsonStringify(const Json& json) {
  const Json::Value& value = json.value;

  if (std::holds_alternative<std::nullptr_t>(value)) return "null";
  if (const auto* boolean = std::get_if<bool>(&value)) {
    return *boolean ? "true" : "false";
  }
  if (const auto* number = std::get_if<JsonNumber>(&value)) {
    return number->text;
  }
  if (const auto* text = std::get_if<std::string>(&value)) {
    return "\"" + *text + "\"";
  }
  if (const auto* array = std::get_if<JsonArray>(&value)) {
    std::string result = "[";
    for (std::size_t i = 0; i < array->size(); ++i) {
      if (i) result += ',';
      result += jsonStringify(*(*array)[i]);
    }
    return result + ']';
  }
  if (const auto* object = std::get_if<JsonObject>(&value)) {
    std::string result = "{";
    for (std::size_t i = 0; i < object->size(); ++i) {
      if (i) result += ',';
      result += "\"" + (*object)[i].first + "\":";
      result += jsonStringify(*(*object)[i].second);
    }
    return result + '}';
  }
  throw std::invalid_argument("Not a JSON value");
}
