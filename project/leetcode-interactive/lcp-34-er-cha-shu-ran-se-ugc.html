二叉树染色 树形背包染色台

染蓝节点的每个连通块不能超过 k 个。以节点为根维护“包含该节点的蓝色连通块恰有 i 个节点”的最优值，合并左右子树时像背包一样分配容量。

题意

二叉树初始白色，任选节点染蓝；每个蓝色连通部分的节点数最多为 k。求被染蓝节点 val 之和最大值。

输入

root = [5,2,3,4]k = 2

期望输出

12

最优蓝色

{5, 3, 4}

参数完整显示为 root = [...]、k = 2；空格若出现用 ␠ 表示。

状态定义

dp[i]：当前节点所在的蓝色连通块大小为 i 时，整棵子树的最大价值。dp[0] 表示当前节点不染蓝，因此子树中可能有多个彼此分离的蓝色块。

核心洞察与过程

  1. 后序 DFS，先得到左右孩子的 dp。
  2. 初始化当前节点白色：dp[0] = 左右子树各自最优；蓝色：dp[1] = val + left[0] + right[0]。
  3. 逐个合并孩子：若父节点已蓝，可把孩子根的蓝色块接上，枚举 i+j ≤ k；也可让孩子根保持白色。
  4. 根的 max(dp) 即答案。

边界与复杂度

k=1 时相邻蓝点不能同时出现；叶子只有 dp[0]=0、dp[1]=val。每个节点合并两个孩子，状态枚举 O(k²)，总时间 O(nk²)，空间 O(nk)（递归实现可回收子数组）。

替代方案、追问、错误

可改为迭代后序避免深递归。常见错误：把 dp[0] 当成“子树全白”、合并时不限制 i+j≤k，或漏掉孩子独立成块（孩子 dp[0] 已包含它的最优独立选择）。

class Solution:
 def maxValue(self,root,k):
  def dfs(u):
   if not u:return [0]*(k+1)
   d=[0]*(k+1);d[1]=u.val
   for c in (dfs(u.left),dfs(u.right)):
    old=d[:];d=[0]*(k+1);d[0]=old[0]+max(c)
    for i in range(1,k+1):
     d[i]=old[i]+c[0]
     for j in range(1,k-i+1):d[i+j]=max(d[i+j],old[i]+c[j])
   return d
  return max(dfs(root))
