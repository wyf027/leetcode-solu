01 / 题目

找出可以连续重复的同一段子序列

给定字符串 s 与整数 k。选择一个字符串 seq，将它连续拼接 k 次；如果拼接后的字符串能从 s 中按原顺序选出，就称 seq 在 s 中重复了 k 次。允许跳过字符，但不能改变顺序或重复使用同一位置。

返回满足条件的 最长 seq；长度相同时返回字典序最大的字符串。不存在非空答案时返回 ""。子序列不要求连续；“重复”要求按轮串联，而不是任意找出几个可能交叠的副本。

定义示意：s = "bababcba", k = 2, seq = "bba"。拼接得到 "bbabba"，可选取原串下标 [0, 2, 3, 4, 6, 7]（从 0 开始）。这里仅说明候选可行，不要求它就是最优答案。

输入：s = "letsleetcode", k = 2
输出："let"

示例 3

输入：s = "ab", k = 2
输出：""

完整约束与签名

  • n == s.length
  • 2 ≤ k ≤ 2000
  • 2 ≤ n < min(2001, k × 8)
  • s 只包含小写英文字母。

04 / 独立题解

准备好看搜索思路了吗？

展开后包含推导、正确性论证、复杂度与四种语言的完整提交代码。

题解：字符配额 + 可行前缀搜索

核心洞察：答案很短，关键在于 n < 8k

若答案长度为 ℓ，重复 k 次至少占用 kℓ 个位置，因此 ℓ ≤ ⌊n/k⌋ ≤ 7。字符 c 在答案里最多出现 ⌊freq[c]/k⌋ 次；把这些上限称为“配额”。配额总和 M = Σ⌊freq[c]/k⌋ ≤ ⌊n/k⌋ ≤ 7，搜索范围由这七个以内的字符名额决定。

频次仅提供必要条件。例如 s = "aabb", k = 2 中 a、b 的配额各为 1，但 "ab" × 2 = "abab" 无法按顺序选出。每个候选仍需扫描原串确认。

完整过程

  1. 统计 26 个字母出现次数，计算每个字母剩余配额。
  2. 从空前缀开始 DFS。依次尝试 z 到 a 中仍有配额的字符，将其接在当前前缀后，形成非空候选 p。
  3. 用原串指针向右扫描，用 j 记录 p 中下一个待匹配位置。遇到相同字符时 j 加一；匹配完整个 p 后令 j 回到 0，完成轮数加一。达到 k 轮立即返回可行，否则扫描结束判为不可行。
  4. 候选不可行则不向下扩展。可行时扣减相应配额，递归探索，返回后恢复配额。
  5. 在每个可行节点比较答案：先比长度，再比字典序。降序枚举能先访问较大候选，但代码仍显式比较，不能遇到第一个可行串就停止。

对官方示例 s = "letsleetcode", k = 2，可用名额为 e 两次、l 一次、t 一次。候选 "let" 的两轮贪心匹配下标为 [0,1,2] 与 [4,5,7]；"ete" 也可行且长度为 3，但 "let" 的字典序更大。

为什么正确

  • 配额剪枝安全：候选若使用 c 共 t 次，其 k 轮需要至少 kt 个 c，因此 t 不可能超过 ⌊freq[c]/k⌋。
  • 扫描判定正确：每次取最早可匹配的位置。对于目标串的任意匹配方案，可逐个将所选位置前移到贪心选择的位置，不会挤掉后续匹配空间。因此贪心能完成 k 轮当且仅当重复串是原串子序列。
  • 前缀剪枝安全：若 p 是 q 的前缀，从 q 的每一轮中删除后缀即可得到 p 的对应轮，所以 q 重复 k 次可行必然推出 p 重复 k 次可行。p 不可行时，它的所有扩展也不可行。
  • 搜索完整：任何可行答案的每个前缀都满足配额且通过判定，故 DFS 必然沿这条路径访问它。
  • 择优正确：记录所有访问到的可行候选中的最长者，同长取字典序最大者；结合搜索完整性，返回值就是目标答案。无非空可行候选时保留空串。

复杂度：显式保留搜索项

令 A 为尝试判定的非空候选数，V 为可行节点数（含根），L 为最大搜索深度（≤ 7）。每个候选判定 O(n)，构造与比较 O(L)，每个可行节点遍历 26 个字母。总时间为 O(n + (n + L)A + 26V)；由于 L ≤ n 且 V ≤ A + 1，可写作 O(n + (n + 26)A + 26)。

把 M 个配额名额视为互不相同，长度 d 的排列数给出一个上界，因此 A ≤ Σ(d=1..M) M!/(M−d)!。当 M = 7 时上界为 13699；同字母重复与可行性剪枝会减小实际搜索量。这不是对一般输入规模的多项式结论，而是利用了题目的小配额限制。

四份代码使用递归，并在每层保存候选字符串，额外空间为 O(26 + L²)（不计输入输出；递归栈深 O(L)）。判定不构造重复 k 次的长串，也不保存整个 BFS 队列。

边界与常见错误

  • 某字符频次不足 k 时配额为 0，不应参与枚举；所有配额均为 0 时直接得到空答案。
  • 同一个字符可占多个名额，如 "aaaaaa", k = 2 的答案为 "aaa"，不能只枚举字母集合的排列。
  • 不能将 k 个副本各自从原串起点匹配：这样会重复利用位置。扫描原串必须连续前进，轮次切换只重置候选指针。
  • 不能用频次代替顺序判定，也不能用子串查找代替子序列匹配。
  • 字典序只在同长度时比较；"z" 不能因为字典序大就击败更长答案。
  • 递归结束必须恢复配额；空前缀只作为根，不传入需要读取 p[0] 的判定函数。

替代方案

BFS 按长度扩展：保留当前长度全部可行候选，再生成下一层；最后非空层取字典序最大者。正确性相同，但保留整层字符串会增加空间。降序定长回溯：从长度上界开始按字典序降序生成，第一次找到可行串即可返回，但要谨慎区分定长枚举与普通 DFS。下一位置表：预处理每个下标之后 26 个字母的首次出现位置，让一次判定进行至多 kL 次跳转，代价是 O(26n) 预处理时间与空间；在本题规模下，顺序扫描更直接。

面试追问

  • 若去掉 n < 8k 呢？配额总和可能很大，排列搜索会迅速膨胀，不能照搬本题的复杂度保证。
  • 既然降序搜索，为什么不立即返回？普通 DFS 的第一个可行节点可能只有一个字符，长度优先级更高；需要遍历并比较，或改成严格定长搜索。
  • 为什么不直接求 k 份原串的 LCS？副本之间的位置必须在同一个 s 中按轮严格递增，独立字符串上的匹配并不能直接表达这个位置约束。

JavaScript · 官方可提交

/**
 * @param {string} s
 * @param {number} k
 * @return {string}
 */
var longestSubsequenceRepeatedK = function(s, k) {
    const left = Array(26).fill(0);
    for (const ch of s) left[ch.charCodeAt(0) - 97]++;
    for (let i = 0; i < 26; i++) left[i] = Math.floor(left[i] / k);
    let best = "";
    function valid(p) {
        let j = 0, rounds = 0;
        for (const ch of s) {
            if (ch === p[j]) {
                j++;
                if (j === p.length) {
                    j = 0;
                    if (++rounds === k) return true;
                }
            }
        }
        return false;
    }
    function dfs(p) {
        if (p.length > best.length ||
            (p.length === best.length && p > best)) best = p;
        for (let i = 25; i >= 0; i--) {
            if (left[i] === 0) continue;
            const q = p + String.fromCharCode(97 + i);
            if (!valid(q)) continue;
            left[i]--;
            dfs(q);
            left[i]++;
        }
    }
    dfs("");
    return best;
};

Java · 官方可提交

class Solution {
    private String source;
    private String best;
    private int repeat;
    private int[] left;

    public String longestSubsequenceRepeatedK(String s, int k) {
        source = s;
        repeat = k;
        best = "";
        left = new int[26];
        for (int i = 0; i < s.length(); i++) {
            left[s.charAt(i) - 'a']++;
        }
        for (int i = 0; i < 26; i++) left[i] /= k;
        dfs("");
        return best;
    }

    private boolean valid(String p) {
        int j = 0, rounds = 0;
        for (int i = 0; i < source.length(); i++) {
            if (source.charAt(i) == p.charAt(j)) {
                j++;
                if (j == p.length()) {
                    j = 0;
                    if (++rounds == repeat) return true;
                }
            }
        }
        return false;
    }

    private void dfs(String p) {
        if (p.length() > best.length() ||
            (p.length() == best.length() && p.compareTo(best) > 0)) {
            best = p;
        }
        for (int i = 25; i >= 0; i--) {
            if (left[i] == 0) continue;
            String q = p + (char) ('a' + i);
            if (!valid(q)) continue;
            left[i]--;
            dfs(q);
            left[i]++;
        }
    }
}

Python 3 · 官方可提交

class Solution:
    def longestSubsequenceRepeatedK(self, s: str, k: int) -> str:
        left = [0] * 26
        for ch in s:
            left[ord(ch) - ord('a')] += 1
        left = [count // k for count in left]
        best = ""

        def valid(p):
            j = rounds = 0
            for ch in s:
                if ch == p[j]:
                    j += 1
                    if j == len(p):
                        j = 0
                        rounds += 1
                        if rounds == k:
                            return True
            return False

        def dfs(p):
            nonlocal best
            if len(p) > len(best) or (len(p) == len(best) and p > best):
                best = p
            for i in range(25, -1, -1):
                if left[i] == 0:
                    continue
                q = p + chr(ord('a') + i)
                if not valid(q):
                    continue
                left[i] -= 1
                dfs(q)
                left[i] += 1

        dfs("")
        return best

C++17 · 官方可提交

#include <array>
#include <functional>
#include <string>
using namespace std;

class Solution {
public:
    string longestSubsequenceRepeatedK(string s, int k) {
        array<int, 26> left{};
        for (char ch : s) left[ch - 'a']++;
        for (int& count : left) count /= k;
        string best;

        auto valid = [&](const string& p) {
            int j = 0, rounds = 0;
            for (char ch : s) {
                if (ch == p[j]) {
                    ++j;
                    if (j == static_cast<int>(p.size())) {
                        j = 0;
                        if (++rounds == k) return true;
                    }
                }
            }
            return false;
        };

        function<void(const string&)> dfs = [&](const string& p) {
            if (p.size() > best.size() ||
                (p.size() == best.size() && p > best)) best = p;
            for (int i = 25; i >= 0; --i) {
                if (left[i] == 0) continue;
                string q = p + static_cast<char>('a' + i);
                if (!valid(q)) continue;
                --left[i];
                dfs(q);
                ++left[i];
            }
        };
        dfs("");
        return best;
    }
};
