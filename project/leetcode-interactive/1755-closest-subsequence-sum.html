最接近目标值的子序列和

给定整数数组 nums 和整数 goal，可以保留任意一些元素（也可以全不选），让所选元素的总和尽可能接近目标。返回两者绝对差的最小值。

HARD数组位运算排序二分查找

先理解输入与目标，再向下探索。解法正文在页面底部，默认收起。

Problem brief

示例与约束

子序列只关心选了哪些位置，不要求元素连续；空子序列的和为 0。

输入：nums = [5,-7,3,5], goal = 6
输出：0
解释：选择全部元素，总和为 6，
与目标完全相等。

示例 2

输入：nums = [7,-9,15,-2], goal = -5
输出：1
解释：选择 [7,-9,-2]，总和为 -4，
绝对差为 |-4-(-5)| = 1。

示例 3

输入：nums = [1,2,3], goal = -7
输出：7
解释：空子序列的和为 0，
得到绝对差 |0-(-7)| = 7。

Complete solution

中途相遇：把 2⁴⁰ 变成 2 × 2²⁰

核心不是逐个枚举整个数组的子序列，而是让两半在目标值附近“相遇”。

核心洞察

把 nums 分成左右两半，分别枚举全部子集和。任意原数组子序列都唯一对应“一份左子集 + 一份右子集”，其总和就是两个子集和相加。

将右侧子集和排序。对每个左和 x，只需在右侧寻找最接近 goal - x 的值；二分位置及其前一个位置就是唯一需要检查的候选。

完整过程

  1. 在中点把数组分为 left 与 right。
  2. 用逐步扩展或位掩码生成两边所有子集和，空集贡献 0。
  3. 排序右侧子集和。
  4. 遍历每个左和 x，二分第一个不小于 goal - x 的右和。
  5. 检查该位置与前驱，更新最小绝对差；若差为 0 可立即返回。

正确性证明

  1. 覆盖性：任意子序列按元素所在半区拆成左右子集，因此其和必为某个 L[i] + R[j]；反之每一对左右子集也构成合法子序列。
  2. 局部最优：固定 L[i] 后，目标右和为 t = goal - L[i]。在已排序的 R 中，最接近 t 的值只能是 lower_bound 指向的首个不小于 t 的值或它的前驱。
  3. 全局最优：算法对每个左和都检查其最佳右侧搭档，因而检查了所有可能左选择对应的最优组合，所得最小差即全局最小差。

边界与复杂度

  • 空子序列必须包含在候选中，所以子集和列表从 0 开始。
  • 目标或元素可以为负数；排序后二分仍然成立。
  • 若任一组合正好命中目标，答案为 0，可提前结束。
  • 令两半大小约为 n/2。时间复杂度 O(2^(n/2) · n)（排序主导可写作 O(2^(n/2) log 2^(n/2))），空间复杂度 O(2^(n/2))。

替代方案

全量枚举：O(2^n)，当 n = 40 时不可行。值域动态规划：元素绝对值总和可能达到 4 × 10⁸，状态范围过大。排序后双指针：左右子集和都排序后，可以从两端移动指针，同样可求最接近目标的配对；时间为生成与排序加上线性扫描，思路也很漂亮，但二分版本通常更直接。

import java.util.Arrays;

class Solution {
    public int minAbsDifference(int[] nums, int goal) {
        int mid = nums.length / 2;
        long[] left = subsetSums(nums, 0, mid);
        long[] right = subsetSums(nums, mid, nums.length);
        Arrays.sort(right);

        long answer = Math.abs((long) goal); // 空子序列
        for (long x : left) {
            long target = (long) goal - x;
            int index = lowerBound(right, target);
            if (index < right.length) {
                answer = Math.min(answer, Math.abs(x + right[index] - goal));
            }
            if (index > 0) {
                answer = Math.min(answer, Math.abs(x + right[index - 1] - goal));
            }
            if (answer == 0) return 0;
        }
        return (int) answer;
    }

    private long[] subsetSums(int[] nums, int from, int to) {
        int size = 1 << (to - from);
        long[] sums = new long[size];
        int count = 1;
        for (int i = from; i < to; i++) {
            for (int j = 0; j < count; j++) {
                sums[count + j] = sums[j] + nums[i];
            }
            count <<= 1;
        }
        return sums;
    }

    private int lowerBound(long[] values, long target) {
        int low = 0, high = values.length;
        while (low < high) {
            int mid = low + (high - low) / 2;
            if (values[mid] < target) low = mid + 1;
            else high = mid;
        }
        return low;
    }
}

var minAbsDifference = function(nums, goal) {
    const mid = Math.floor(nums.length / 2);
    const left = makeSums(nums.slice(0, mid));
    const right = makeSums(nums.slice(mid)).sort((a, b) => a - b);
    let answer = Math.abs(goal);

    for (const x of left) {
        const target = goal - x;
        let low = 0;
        let high = right.length;
        while (low < high) {
            const m = low + Math.floor((high - low) / 2);
            if (right[m] < target) low = m + 1;
            else high = m;
        }
        if (low < right.length) {
            answer = Math.min(answer, Math.abs(x + right[low] - goal));
        }
        if (low > 0) {
            answer = Math.min(answer, Math.abs(x + right[low - 1] - goal));
        }
        if (answer === 0) return 0;
    }
    return answer;
};

function makeSums(values) {
    const sums = [0];
    for (const value of values) {
        const size = sums.length;
        for (let i = 0; i < size; i++) sums.push(sums[i] + value);
    }
    return sums;
}
from bisect import bisect_left
from typing import List


class Solution:
    def minAbsDifference(self, nums: List[int], goal: int) -> int:
        mid = len(nums) // 2
        left = self.subset_sums(nums[:mid])
        right = sorted(self.subset_sums(nums[mid:]))
        answer = abs(goal)

        for x in left:
            target = goal - x
            index = bisect_left(right, target)
            if index < len(right):
                answer = min(answer, abs(x + right[index] - goal))
            if index > 0:
                answer = min(answer, abs(x + right[index - 1] - goal))
            if answer == 0:
                return 0
        return answer

    def subset_sums(self, values: List[int]) -> List[int]:
        sums = [0]
        for value in values:
            sums += [current + value for current in sums]
        return sums
#include <algorithm>
#include <cstdlib>
#include <vector>
using namespace std;

class Solution {
public:
    int minAbsDifference(vector<int>& nums, int goal) {
        int mid = static_cast<int>(nums.size()) / 2;
        vector<long long> left = subsetSums(nums, 0, mid);
        vector<long long> right = subsetSums(nums, mid, nums.size());
        sort(right.begin(), right.end());

        long long answer = llabs(static_cast<long long>(goal));
        for (long long x : left) {
            long long target = static_cast<long long>(goal) - x;
            auto it = lower_bound(right.begin(), right.end(), target);
            if (it != right.end()) {
                answer = min(answer, llabs(x + *it - goal));
            }
            if (it != right.begin()) {
                --it;
                answer = min(answer, llabs(x + *it - goal));
            }
            if (answer == 0) return 0;
        }
        return static_cast<int>(answer);
    }

private:
    vector<long long> subsetSums(const vector<int>& nums,
                                  int from, int to) {
        vector<long long> sums{0};
        for (int i = from; i < to; ++i) {
            int size = static_cast<int>(sums.size());
            for (int j = 0; j < size; ++j) {
                sums.push_back(sums[j] + nums[i]);
            }
        }
        return sums;
    }
};

常见错误

  • 忘记把 0 放入子集和，导致漏掉空子序列或只选一侧的情况。
  • 只检查 lower_bound 位置，不检查前驱；最近值可能在目标左边。
  • JavaScript 排序忘记传 (a, b) => a - b，结果变成字符串字典序。
  • 使用 32 位中间值做减法时忽略溢出风险；用 long/long long 承载计算更稳妥。

面试追问

  • 为什么是 n = 40？ 因为每半最多 20 个元素，约一百万个子集和可处理。
  • 能改成双指针吗？ 可以。两侧子集和都排序，左指针从头、右指针从尾，根据当前和与 goal 的大小移动。
  • 如何恢复具体子序列？ 子集和旁保存位掩码；最佳配对更新时同时记录两侧掩码。
  • 若只允许选恰好 k 个元素？ 按选择数量给两侧子集和分组，再匹配数量之和为 k 的组。
