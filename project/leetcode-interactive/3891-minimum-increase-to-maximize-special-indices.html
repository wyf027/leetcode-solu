最大化特殊下标数目的最少增加次数

先把特殊下标数做到上限，再在全部达标布局中选择增量代价最小的一种。

题意

对 0 < i < n - 1，若 nums[i] 严格大于相邻两项，i 是特殊下标。一次操作可任选元素加一。返回特殊下标数最大时的最少操作数。

示例：nums = [5, 2, 1, 4, 3]，把下标 1 增至 6，便可达到两个特殊下标，成本为 4。

核心洞察

相邻位置不可能同时是峰。内部位置最多隔一个选一个。选中 i 的局部成本为：

need(i)=max(0,max(nums[i-1],nums[i+1])+1-nums[i])

被选峰不相邻，因此只增加峰本身不会改变其他峰的邻居，成本可累加。

题解

默认收起，避免首屏直接剧透。

状态 DP

上限是 floor((n - 1) / 2)。n 为奇数时无需跳过；n 为偶数时必须在内部链上跳过一次。令 dfs(i, skip) 表示从 i 开始的最小代价：选 i 付 need(i) 后到 i+2；如果还可跳过，跳 i 后到 i+1。

复杂度：O(n) 时间、O(n) 空间。边界：n=3 只有一个候选峰，答案用 64 位整数。替代方案：前后缀拼接也可做，但状态 DP 更直观。常见错误：让相邻位置同时成为峰、贪心选局部最小成本、用 int 累加总成本。
