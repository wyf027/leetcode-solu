给按照绝对值排序的链表排序

Sort Linked List Already Sorted Using Absolute Values

给定单链表的头节点 head。沿链表前进时，节点值的绝对值非递减。请重新排列链表，使节点的实际数值非递减，并返回排序后的头节点。

数组写法用于展示链表：head = [a,b,c] 表示 a → b → c → null。思考：已知绝对值有序，能否在线性时间内完成？

先观察，再推演
head →0→2→−5→5→10→−10→ null

绝对值序列：0, 2, 5, 5, 10, 10。相同绝对值允许出现。

包含指针实验、正确性推导和四语言实现。

01 / 核心洞察：负数向前，非负数保留

原链表中，非负数的实际值已经非递减；负数随着绝对值变大，实际值反而变小。因此，从原链表第二个节点开始，每遇到一个负数，就将它摘下并插入当前链表头部。其余节点留在原位。

用 prev 记住当前节点的前驱，curr 指向待处理节点。头节点作为最初已处理的一个节点，不必单独移动。遇到负数时先保留后继，再断开、头插；prev 保持原位，继续检查它后面的节点。

03 / 完整过程与正确性

  1. 初始化：若为空链表则直接返回；否则 prev = head、curr = head.next。
  2. 非负节点：保持链接，prev = curr，再令 curr = curr.next。
  3. 负节点：保存 next = curr.next；令 prev.next = next 摘除；令 curr.next = head、head = curr 头插；最后 curr = next。此分支不移动 prev。
  4. 结束：curr 为空，所有原始节点处理完毕，返回新的 head。

循环不变量

每轮开始时，从 head 到 prev 是已处理节点组成的有序前缀；prev.next 等于 curr。curr 及之后仍按原输入次序排列。初始前缀只有一个节点，所以成立。

若 curr 非负，它不小于已处理的非负节点，也不小于任何负节点，可以追加到有序前缀。若 curr 为负，它的绝对值不小于已处理节点的绝对值，因此不大于任意已处理负数，并且小于所有非负数，故可以放到前缀最前端。两种分支均保持不变量与剩余链表的完整性。

每轮恰好处理一个原始节点，并通过保存的原后继前进，故最终终止；结束时整个链表都是有序前缀。断开后再头插，不复制或丢弃节点，也不会形成环。

复杂度

时间 O(n)，每个节点仅处理一次；算法额外空间 O(1)，只有固定数量的指针，没有递归栈或新节点。演示页面为可回退操作保存快照，不计入提交算法。

04 / 边界、替代方案与面试追问

边界与常见错误

  • 单节点、全非负数：不需要重连。
  • 全负数：逐个头插后数值有序。
  • 零属于非负数，保持原位。
  • 绝对值相等与重复值均合法。
  • 移动后让 prev 跟着 curr 走，会破坏前驱关系。
  • 先改 curr.next 再读取原后继，会走回已处理区。
  • 忘记断开 prev.next，可能制造环。
  • 输入保证非空；代码保留空链表防御分支。

替代方案

  • 负数头插到独立链表，非负数尾插到另一链表，最后连接：O(n) 时间、O(1) 额外指针空间，但需维护更多首尾指针。
  • 通用链表归并排序：O(n log n) 时间，适用于没有绝对值有序保证的输入；递归实现通常需 O(log n) 栈空间。
  • 拷贝节点引用到数组并排序再重连：O(n log n) 时间、O(n) 额外空间。

面试追问

算法稳定吗？非负数相对顺序保持；相同负数的节点身份可能逆序，因此整体不稳定。若要求稳定，可以将连续相等的负值作为组处理，保持组内顺序再前插，仍可在线性时间完成。

如果输入不再保证绝对值有序？头插不再保证正确，应改用通用排序；也可先用 O(n) 扫描检查前提。

为什么不能直接反转整个链表？反转会同时颠倒原本已经有序的非负节点。

class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}
*/
class Solution {
    public ListNode sortLinkedList(ListNode head) {
        if (head == null) return null;
        ListNode prev = head;
        ListNode curr = head.next;
        while (curr != null) {
            ListNode next = curr.next;
            if (curr.val < 0) {
                prev.next = next;
                curr.next = head;
                head = curr;
            } else {
                prev = curr;
            }
            curr = next;
        }
        return head;
    }
}
