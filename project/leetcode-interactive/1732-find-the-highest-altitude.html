Find the Highest Altitude

找到最高海拔

从海拔 0 出发，每个数只告诉你“这一段升了或降了多少”。先理解旅程，再决定怎样找到最高点。

函数 largestAltitude(gain)返回整数非付费题
Problem

题目说明

一名骑行者要经过 n + 1 个点。起点是点 0，海拔为 0。

给定长度为 n 的整数数组 gain，其中 gain[i] 表示从点 i 到点 i + 1 的净海拔变化。请返回整条路线所有点中的最高海拔。

约束

  • n == gain.length
  • 1 <= n <= 100
  • -100 <= gain[i] <= 100
示例 1
输入
gain = [-5,1,5,0,-7]
输出
1
说明
各点海拔为 [0,-5,-4,1,1,-6]，最高为 1。
示例 2
输入
gain = [-4,-3,-2,-1,4,3,2]
输出
0
说明
各点海拔为 [0,-4,-7,-9,-10,-6,-3,-1]，最高为起点的 0。

Solution

一次扫描，维护两个数

核心洞察

点 i + 1 的海拔，等于起点到这一点之前所有 gain 的前缀和。无需保存整个海拔数组：用 altitude 累加当前海拔，用 highest 记录扫描至今的最大值。

关键初始化：altitude = highest = 0。起点也是路线中的一个点，不能漏掉。

完整过程

  1. 从海拔 0 开始，并把最高值初始化为 0。
  2. 依次读取每段变化 delta，令 altitude += delta。
  3. 每到达一个新点，用当前海拔更新 highest。
  4. 遍历完成后返回 highest。

正确性说明

循环不变量：处理完前 k 个变化后，altitude 恰好是点 k 的海拔，highest 是点 0..k 中的最高海拔。

初始时 k = 0，两者均为 0，不变量成立。处理下一段变化后，累加得到新点的准确海拔，再取最大值即可覆盖新点。因此不变量持续成立。遍历结束覆盖所有 n + 1 个点，返回值就是全程最高海拔。

边界与复杂度

  • 所有变化都为负：答案仍可能是起点 0。
  • 变化为 0：海拔与最高值保持不变。
  • 先下降后上升：比较的是累计海拔，不是单段最大增益。
  • 时间复杂度 O(n)，额外空间复杂度 O(1)。

四种语言实现

class Solution {
    public int largestAltitude(int[] gain) {
        int altitude = 0;
        int highest = 0;

        for (int delta : gain) {
            altitude += delta;
            highest = Math.max(highest, altitude);
        }

        return highest;
    }
}

替代方案

可以先构造长度为 n + 1 的前缀和数组，再取最大值。思路直观，也方便后续查询每个点的海拔；但本题只问最大值，额外的 O(n) 空间没有必要。

常见错误

  • 把答案初始化为负无穷而遗漏起点 0。
  • 直接取 gain 的最大元素；单段变化不等于绝对海拔。
  • 只在循环前比较一次最高值，未在每次累加后更新。
  • 返回最终海拔，而不是途中最高海拔。

面试追问

如果要返回最高点的下标呢？

更新 highest 时同步记录当前点下标。若有多个最高点，还需先明确返回最早还是最晚出现的位置。

如果数据以流的形式不断到来呢？

仍只需保留当前海拔和最高海拔，逐项更新即可；这说明该算法天然支持流式处理。

如果频繁查询任意区间的净海拔变化呢？

可保存完整前缀和数组，区间 [l, r] 的累计变化可由两个前缀和相减得到，以空间换查询速度。
