01 / 题目与数据契约

给定购买记录表 Purchases，以及日期参数 startDate、endDate 和金额门槛 minAmount。某位用户只要有一笔购买同时处于指定闭区间内，且该笔金额不少于门槛，就享有折扣。返回符合条件的用户人数，结果列名为 user_cnt。

Purchases 表结构
字段类型含义
user_idINT用户编号
time_stampDATETIME购买时刻
amountINT本次支付金额
时间边界：两个 DATE 参数都转换为当天 00:00:00。endDate 当日午夜包含在区间内，午夜之后的购买不包含。

参数与约束

  • 函数形式：getUserIDs(startDate DATE, endDate DATE, minAmount INT) RETURNS INT。
  • 联合主键为 (user_id, time_stamp)；同一用户可在不同时间多次购买。
  • 金额条件针对单笔购买，且包含等于门槛的情形；时间区间包含两个端点。
  • 现有题面资料未列出记录数、金额或日期的额外数值范围；此处不补造范围。

05 / 独立题解

准备好后，再展开完整推导与代码。

核心洞察：先筛选记录，再去重计数

资格要求“存在一笔合格购买”，无需求和。筛选同时满足时间与金额条件的记录，再对用户编号去重，计算不同用户数。

完整过程

  1. 把起止日期解释为各自当天午夜，并使用闭区间比较。
  2. 逐条检查购买时间和单笔金额，两者同时满足才保留。
  3. 把合格记录的 user_id 加入集合；重复编号不增加人数。
  4. 返回集合大小。SQL 用 WHERE 加 COUNT(DISTINCT user_id) 表达这个过程。

正确性

处理前 k 条记录后，集合恰好包含这 k 条记录中拥有合格购买的用户。初始集合为空，结论成立。下一条记录不合格时无需改变集合；合格时加入其用户，恰好补充这条记录带来的资格，去重保证已有用户不会重复计数。由归纳，扫描全部记录后，集合与有资格的用户一一对应，其大小就是所求人数。

边界与常见错误

  • 金额恰好等于 minAmount 也合格，不能使用严格大于。
  • 开始午夜和结束午夜都合格；结束日 00:00:01 不合格。不要把结束范围改成全天，也不要用 DATE(time_stamp) 抹掉时间。
  • COUNT(*) 统计的是记录数，重复用户会被多计。COUNT(DISTINCT amount) 则去重了错误字段。
  • SUM(amount) 会把多笔低额购买累计，改变题意。
  • 空结果应返回 0；COUNT 聚合本身提供 0，无需额外补行。
  • 联合主键保证用户编号非空。本地参考面向有效、非空的题目数据，不扩展未规定的空值规则。

复杂度

令 n 为购买记录数、u 为符合条件的不同用户数。本地哈希集合方案期望时间 O(n)，额外空间 O(u)。数据库的真实代价受索引、扫描方式、去重策略影响；排序去重可能达到 O(n log n)，不能保证 SQL 额外空间为 O(1)。

替代方案

先 SELECT DISTINCT user_id 得到派生表，再 COUNT(*)；或过滤后 GROUP BY user_id，再统计组数，都能表达相同语义。直接 COUNT(DISTINCT) 更简洁。有独立用户表时，也可以用 EXISTS 判断是否存在合格购买。

面试追问

  • 改为累计消费达到门槛？时间筛选后按用户分组，用 HAVING SUM(amount) 判断。
  • 返回用户清单？改成 SELECT DISTINCT user_id，按要求排序。本题只返回人数。
  • 如何优化大表？根据时间与金额的选择性考虑索引，用实际执行计划判断，不能假设两个范围条件都能充分利用同一个复合索引。
  • 业务要求结束日期全天有效？改用小于次日午夜的半开区间；那是新的业务规则。

提交与参考实现

本题为数据库题，MySQL 为主要提交形式。函数名 getUserIDs 虽含 IDs，返回值却是整数人数。Java、JavaScript、Python、C++ 均为完整本地语义参考函数，不是本题官方可提交模板。

MySQL · 提交版本

CREATE FUNCTION getUserIDs(startDate DATE, endDate DATE, minAmount INT)
RETURNS INT
BEGIN
    RETURN (
        SELECT COUNT(DISTINCT user_id) AS user_cnt
        FROM Purchases
        WHERE time_stamp BETWEEN startDate AND endDate
          AND amount >= minAmount
    );
END

DATE 参数与 DATETIME 比较时使用午夜边界。函数返回一个整数；外部以 user_cnt 展示。代码未执行。

Java 17+ · 本地语义参考

import java.time.LocalDate;
import java.time.LocalDateTime;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
    record Purchase(int userId, LocalDateTime timeStamp, int amount) {}

    public static int getUserIDs(List<Purchase> purchases,
            LocalDate startDate, LocalDate endDate, int minAmount) {
        LocalDateTime start = startDate.atStartOfDay();
        LocalDateTime end = endDate.atStartOfDay();
        Set<Integer> users = new HashSet<>();
        for (Purchase p : purchases) {
            if (!p.timeStamp().isBefore(start)
                    && !p.timeStamp().isAfter(end)
                    && p.amount() >= minAmount) {
                users.add(p.userId());
            }
        }
        return users.size();
    }
}

JavaScript · 本地语义参考

时间必须为固定宽度、零补齐的 YYYY-MM-DD HH:mm:ss，日期为 YYYY-MM-DD；均无时区。这样字典序与时间顺序一致。

function getUserIDs(purchases, startDate, endDate, minAmount) {
    const start = startDate + " 00:00:00";
    const end = endDate + " 00:00:00";
    const users = new Set();
    for (const { user_id, time_stamp, amount } of purchases) {
        if (start <= time_stamp && time_stamp <= end
                && amount >= minAmount) {
            users.add(user_id);
        }
    }
    return users.size;
}

Python 3.9+ · 本地语义参考

from datetime import date, datetime, time
from typing import Iterable

# Each row: (user_id, timezone-free datetime, amount)
def getUserIDs(purchases: Iterable[tuple[int, datetime, int]],
               startDate: date, endDate: date, minAmount: int) -> int:
    start = datetime.combine(startDate, time.min)
    end = datetime.combine(endDate, time.min)
    users = set()
    for user_id, time_stamp, amount in purchases:
        if start <= time_stamp <= end and amount >= minAmount:
            users.add(user_id)
    return len(users)

C++11+ · 本地语义参考

与 JavaScript 一样，字符串时间须采用固定宽度、零补齐、无时区的规范格式。

#include <string>
#include <vector>
#include <unordered_set>
using namespace std;

struct Purchase {
    int user_id;
    string time_stamp; // YYYY-MM-DD HH:mm:ss, no timezone
    int amount;
};

int getUserIDs(const vector<Purchase>& purchases,
               const string& startDate, const string& endDate, int minAmount) {
    const string start = startDate + " 00:00:00";
    const string end = endDate + " 00:00:00";
    unordered_set<int> users;
    for (const auto& p : purchases) {
        if (start <= p.time_stamp && p.time_stamp <= end
                && p.amount >= minAmount) {
            users.insert(p.user_id);
        }
    }
    return static_cast<int>(users.size());
}
