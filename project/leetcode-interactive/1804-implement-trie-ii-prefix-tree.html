1804. 实现 Trie
（前缀树）II

Implement Trie II (Prefix Tree)

MEDIUM设计付费题 · 自述题意

同一个词可以存多份，删除时只减一份。先理解接口行为，再展开实现。

题目要求

实现存储字符串多重集合的 Trie。精确查询统计完整单词的份数，前缀查询统计以给定字符串开头的所有单词份数，重复项也计入。

  • Trie()：初始化空树。
  • void insert(string word)：添加一份 word。
  • int countWordsEqualTo(string word)：返回 word 的重数。
  • int countWordsStartingWith(string prefix)：返回以 prefix 开头的份数。
  • void erase(string word)：删除一份 word。

约束

  • 1 ≤ word.length, prefix.length ≤ 2000。
  • word 和 prefix 仅包含小写英文字母。
  • 四种操作的调用总数不超过 3 × 10⁴。
  • 每次 erase 都保证指定 word 至少存在一份。

官方示例 · 完整参数

输入：
["Trie","insert","insert","countWordsEqualTo","countWordsStartingWith","erase","countWordsEqualTo","countWordsStartingWith","erase","countWordsStartingWith"]
[[],["apple"],["apple"],["apple"],["app"],["apple"],["apple"],["app"],["apple"],["app"]]
输出：
[null,null,null,2,2,null,1,1,null,0]

两次插入后有两份 apple；删除一次后剩一份；再删除一次，前缀 app 的计数归零。构造及无返回值操作以 null 表示。

题解 · 两种计数对应两种问题

每个非根节点代表一个前缀。pass 是经过该前缀的单词份数，end 是恰好在此结束的份数。根不维护计数，本题没有空串参数。

逐字符计数实验室

缩进表示字符深度，卡片显示完整前缀及 pass / end；青色粗边框表示当前节点。每一步处理一个字符或词尾，操作完成后才恢复完整不变量。

零计数节点保留以便复用。所有按钮支持 Tab 聚焦及 Enter / 空格操作。

完整过程
  1. 插入：沿字符行走，缺节点就创建；进入节点时 pass 加一，走完单词后 end 加一。
  2. 精确查询：沿 word 找到末节点，返回 end；缺路径返回零。
  3. 前缀查询：沿 prefix 找到末节点，返回 pass；缺路径返回零。
  4. 删除：沿 word 每个非根节点的 pass 减一，末节点 end 减一。一次只减一份。
正确性证明
不变量：每个非根节点的 pass 等于当前集合中以其路径为前缀的份数，end 等于完整词为其路径的份数。空树满足不变量。
插入一个词恰好增加其所有非空前缀的份数和唯一词尾的份数，更新与定义一致。删除已存在单词执行相反更新，因此不会出现负数。查询不改变状态，直接由不变量获得答案；路径不存在说明对应份数为零。归纳可知任意合法操作序列均保持正确。
边界与常见错误
  • 只存布尔 isWord 会丢失重复次数。
  • apple 存在时 app 不一定是完整词，不能把 pass 当 end。
  • 删除不能清空整条共享路径，app、apple、apt 可能共享节点。
  • 计数为零而节点仍存在是合法状态，查询会返回零。
  • 最长 2000 字符，使用迭代避免递归深度问题。
  • 若改为允许删除不存在的词，应先精确查询再修改，不能沿途部分减一后退出。
复杂度
单次操作 O(L)，L 是参数长度。数组子节点访问为 O(1)，哈希子节点访问为期望 O(1)。插入最多新建 O(L) 节点，其他操作使用 O(1) 迭代状态。Java 的 toCharArray 额外需要 O(L) 临时空间；C++ 参数按接口以值传递，字符串复制也需要 O(L) 空间。
本实现不物理删除节点，总空间 O(S)，S 为历史插入字符串总长度上界；更精确为历史不同前缀的节点数。固定 26 字母数组含常数 26。C++ 下标节点池的扩容费用按所有插入均摊计入。
替代方案
哈希表存完整词的频次，精确查询简单，但前缀查询需要扫描 D 个不同词，最坏 O(D·L)。显式维护所有前缀哈希计数可加速查询，但构造前缀字符串带来复制开销。Trie 共享路径，在访问过程中直接更新计数。
面试追问
  • 如何回收空间？删除后自底向上剪掉 pass 为零的子树，并处理内存所有权。
  • 如何支持空字符串？根也维护 pass，空词结束于根的 end。
  • 如何支持 Unicode？统一字符单位并改用哈希子节点，注意不同语言的字符遍历语义。
  • 如何自动补全？先定位前缀，再遍历其子树，收集 end 大于零的完整词。

Java
class Trie {
    private static class Node {
        Node[] next = new Node[26];
        int pass, end;
    }
    private final Node root = new Node();
    public Trie() {}
    public void insert(String word) {
        Node n = root;
        for (char c : word.toCharArray()) {
            int i = c - 'a';
            if (n.next[i] == null) n.next[i] = new Node();
            n = n.next[i];
            n.pass++;
        }
        n.end++;
    }
    private Node find(String s) {
        Node n = root;
        for (char c : s.toCharArray()) {
            n = n.next[c - 'a'];
            if (n == null) return null;
        }
        return n;
    }
    public int countWordsEqualTo(String word) {
        Node n = find(word);
        return n == null ? 0 : n.end;
    }
    public int countWordsStartingWith(String prefix) {
        Node n = find(prefix);
        return n == null ? 0 : n.pass;
    }
    public void erase(String word) {
        Node n = root;
        for (char c : word.toCharArray()) {
            n = n.next[c - 'a'];
            n.pass--;
        }
        n.end--;
    }
}


JavaScript
class Trie {
    constructor() {
        this.root = { next: new Map(), pass: 0, end: 0 };
    }
    insert(word) {
        let n = this.root;
        for (const c of word) {
            if (!n.next.has(c))
                n.next.set(c, { next: new Map(), pass: 0, end: 0 });
            n = n.next.get(c);
            n.pass++;
        }
        n.end++;
    }
    find(s) {
        let n = this.root;
        for (const c of s) {
            n = n.next.get(c);
            if (!n) return null;
        }
        return n;
    }
    countWordsEqualTo(word) {
        return this.find(word)?.end ?? 0;
    }
    countWordsStartingWith(prefix) {
        return this.find(prefix)?.pass ?? 0;
    }
    erase(word) {
        let n = this.root;
        for (const c of word) {
            n = n.next.get(c);
            n.pass--;
        }
        n.end--;
    }
}


Python
class Node:
    def __init__(self):
        self.next = {}
        self.pass_count = 0
        self.end = 0

class Trie:
    def __init__(self):
        self.root = Node()

    def insert(self, word: str) -> None:
        n = self.root
        for c in word:
            if c not in n.next:
                n.next[c] = Node()
            n = n.next[c]
            n.pass_count += 1
        n.end += 1

    def _find(self, s):
        n = self.root
        for c in s:
            n = n.next.get(c)
            if n is None:
                return None
        return n

    def countWordsEqualTo(self, word: str) -> int:
        n = self._find(word)
        return n.end if n else 0

    def countWordsStartingWith(self, prefix: str) -> int:
        n = self._find(prefix)
        return n.pass_count if n else 0

    def erase(self, word: str) -> None:
        n = self.root
        for c in word:
            n = n.next[c]
            n.pass_count -= 1
        n.end -= 1


C++
#include <array>
#include <string>
#include <vector>
using namespace std;

class Trie {
    struct Node {
        array<int, 26> next;
        int pass = 0, end = 0;
        Node() { next.fill(-1); }
    };
    vector<Node> nodes;
    int find(const string& s) const {
        int u = 0;
        for (char c : s) {
            u = nodes[u].next[c - 'a'];
            if (u == -1) return -1;
        }
        return u;
    }
public:
    Trie() : nodes(1) {}
    void insert(string word) {
        int u = 0;
        for (char c : word) {
            int i = c - 'a';
            if (nodes[u].next[i] == -1) {
                int v = static_cast<int>(nodes.size());
                nodes.emplace_back();
                nodes[u].next[i] = v;
            }
            u = nodes[u].next[i];
            nodes[u].pass++;
        }
        nodes[u].end++;
    }
    int countWordsEqualTo(string word) {
        int u = find(word);
        return u == -1 ? 0 : nodes[u].end;
    }
    int countWordsStartingWith(string prefix) {
        int u = find(prefix);
        return u == -1 ? 0 : nodes[u].pass;
    }
    void erase(string word) {
        int u = 0;
        for (char c : word) {
            u = nodes[u].next[c - 'a'];
            nodes[u].pass--;
        }
        nodes[u].end--;
    }
};
