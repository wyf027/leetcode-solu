分割等和子集

判断能否把一个只包含正整数的数组分成元素和相等的两个子集。

查看交互

题意、示例与约束

输入：nums = [1,5,11,5]

输出：true

解释：[1,5,5] 与 [11] 的和均为 11。

输入：nums = [1,2,3,5]

输出：false

  • 1 ≤ nums.length ≤ 200。
  • 1 ≤ nums[i] ≤ 100。
  • 两个子集必须覆盖所有元素，且都可以非空。

分步交互：目标和 11

dp[s] 表示是否能选出若干数、其和恰好为 s。每个数只能选一次，所以从大到小更新。

核心洞察

若总和为奇数，必不可能平分。否则问题变成：能否选出一部分数字，其和恰为总和的一半。这正是容量为 target 的 0/1 背包可达性问题。

完整过程

  1. 1. 求和
    奇数总和直接 false。
  2. 2. 初始化
    dp[0] = true。
  3. 3. 倒序
    s 从 target 降至 num。
  4. 4. 返回
    dp[target] 即答案。

边界、复杂度、替代与追问

边界：单元素不可能；总和奇数立即失败；数字大于 target 时自然不会更新。
复杂度：时间 O(n·target)，空间 O(target)。
替代：二维 DP 更直观但多用一维空间；回溯会指数爆炸。
追问：如何恢复具体子集？如何在允许负数时处理？
常见错误：正序更新导致一个数字被重复使用；忘记 dp[0]；误把奇数总和向下取整继续计算。

官方签名代码

// Java
class Solution { public boolean canPartition(int[] nums) { int sum=0; for(int x:nums)sum+=x; if((sum&1)==1)return false; int t=sum/2; boolean[] dp=new boolean[t+1]; dp[0]=true; for(int x:nums)for(int s=t;s>=x;s--)dp[s]|=dp[s-x]; return dp[t]; } }
// JavaScript
var canPartition = function(nums) { const sum=nums.reduce((a,b)=>a+b,0); if(sum%2)return false; const t=sum/2,dp=Array(t+1).fill(false); dp[0]=true; for(const x of nums)for(let s=t;s>=x;s--)dp[s]=dp[s]||dp[s-x]; return dp[t]; };
# Python
class Solution:
    def canPartition(self, nums):
        total = sum(nums)
        if total % 2: return False
        target = total // 2; dp = [False] * (target + 1); dp[0] = True
        for num in nums:
            for s in range(target, num - 1, -1): dp[s] |= dp[s - num]
        return dp[target]
// C++
class Solution { public: bool canPartition(vector<int>& nums) { int sum=accumulate(nums.begin(),nums.end(),0); if(sum%2)return false; int t=sum/2; vector<bool> dp(t+1); dp[0]=true; for(int x:nums)for(int s=t;s>=x;--s)dp[s]=dp[s]||dp[s-x]; return dp[t]; } };
