Rotate Array

右旋不是搬运每个元素，而是重新切分两个连续区间。先翻转全体，再分别扶正新的前段与后段，三次翻转完成原地旋转。

    04 / Algorithm

    题解默认隐藏

    展开后查看洞察、过程、边界、复杂度、替代方案与四语言代码。

    Solution unlocked

    翻转改变块顺序，也改变块内方向

    原数组写成 A + B，右旋结果是 B + A。全翻转得到 rev(B)+rev(A)，再分别翻转两块即可。

    核心洞察与完整过程

    1. 令 n = nums.length，先做 k %= n。
    2. 翻转整个区间 [0,n-1]。
    3. 翻转新的前 k 个元素 [0,k-1]。
    4. 翻转剩余元素 [k,n-1]。
    5. 翻转函数只交换两端并向中间收缩，所以全程原地。

    复杂度、边界与替代方案

    三段总交换量为线性级别，时间 O(n)，额外空间 O(1)。

    • k = 0 时两次全数组翻转互相抵消，空前缀翻转安全。
    • n = 1、k > n 都由取模统一处理。
    • 复制数组按新下标写回最直观，但额外空间 O(n)。
    • 环状替换同样 O(1) 空间，需要用 gcd 或已移动计数避免漏环，代码更易错。
    • 每次右移一步会退化到 O(nk)，不推荐。

    四语言可提交代码

    class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k %= n;
        reverse(nums, 0, n - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, n - 1);
    }

    private void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left++] = nums[right];
            nums[right--] = temp;
        }
    }
}
    var rotate = function (nums, k) {
    const n = nums.length;
    k %= n;

    const reverse = (left, right) => {
        while (left < right) {
            [nums[left], nums[right]] = [nums[right], nums[left]];
            left++;
            right--;
        }
    };

    reverse(0, n - 1);
    reverse(0, k - 1);
    reverse(k, n - 1);
};

class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n

        def reverse(left: int, right: int) -> None:
            while left < right:
                nums[left], nums[right] = nums[right], nums[left]
                left += 1
                right -= 1

        reverse(0, n - 1)
        reverse(0, k - 1)
        reverse(k, n - 1)

class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = static_cast<int>(nums.size());
        k %= n;
        reverse(nums.begin(), nums.end());
        reverse(nums.begin(), nums.begin() + k);
        reverse(nums.begin() + k, nums.end());
    }

    面试追问

    • 如何证明三次翻转恰好得到 B + A？
    • 环状替换为何有 gcd(n,k) 个环？
    • 如果输入是链表，如何右旋？
    • 数组极大且在外存时如何处理？

    常见错误

    • 忘记 k %= n，导致区间越界。
    • 把第二段写成 [0,k]，产生 off-by-one。
    • 只翻转全体，块内顺序仍是反的。
    • 返回新数组而没有原地修改 nums。
    • 环状替换没有处理多个独立环。
