Problem

题目说明

给定整数数组 nums 与 multipliers，长度分别为 n 和 m，且 n ≥ m。初始分数为 0，必须恰好执行 m 次操作。

第 i 次操作（从 0 开始）

  1. 从当前 nums 的开头或末尾选出整数 x。
  2. 把 multipliers[i] × x 加到分数中。
  3. 从 nums 中移除 x。
目标：完成恰好 m 次操作后，返回能够取得的最大总分。乘数必须依次使用，不能跳过或重排。

官方提交签名

maximumScore(nums, multipliers) → integer

约束

  • n == nums.length
  • m == multipliers.length
  • 1 ≤ m ≤ 300
  • m ≤ n ≤ 10⁵
  • -1000 ≤ nums[i], multipliers[i] ≤ 1000
示例 1全取右端
输入nums = [1,2,3], multipliers = [3,2,1]
输出14

依次从末尾取 3、2、1，得分为 3×3 + 2×2 + 1×1 = 14。

示例 2左右混合
输入nums = [-5,-3,-3,-2,7,1], multipliers = [-10,-5,3,4,6]
输出102

依次取左 -5、左 -3、左 -3、右 1、右 7，得分 50 + 15 - 9 + 4 + 42 = 102。

Solution

把指数级选择压缩成二维状态

核心洞察

做了 i 次操作后，若其中有 left 次从左端取数，那么从右端取数的次数必然是 i - left。因此当前可用的左端下标是 left，右端下标是 n - 1 - (i - left)。不必记录整个剩余数组。

rightIndex = n - 1 - (i - left)

状态与转移

定义 dp[i][left]：已经完成 i 次操作、其中从左端取了 left 次时的最大分数。当前乘数为 multipliers[i]，有两个去向：

  • 取左：转到 dp[i+1][left+1]，增加 multipliers[i] × nums[left]。
  • 取右：转到 dp[i+1][left]，增加 multipliers[i] × nums[n-1-(i-left)]。

初始只有 dp[0][0] = 0 可达，其余为负无穷。完成 m 轮后，答案是 dp[m][0…m] 的最大值。代码使用一维数组滚动压缩空间。

完整过程

  1. 建立长度 m + 1 的数组 dp，令 dp[0] = 0，其他位置不可达。
  2. 按顺序处理每个乘数 multipliers[i]。
  3. 建立新的 next，枚举本轮前可能的 left = 0…i。
  4. 分别尝试拿左端和右端，用较大的分数更新 next[left+1] 与 next[left]。
  5. 以 next 替换 dp；最后返回最大值。

正确性证明

状态完备：完成 i 轮且左取 left 次后，左右两端下标由这两个数唯一决定，所以具有相同状态的所有选择序列面对完全相同的后续问题。

转移无遗漏：任一合法的下一步只能取当前左端或右端；两条转移分别覆盖它们，且使用正确的第 i 个乘数。

最优子结构：若到达某状态的前缀不是最高分，用同状态的更高分前缀替换后，后续可选动作不变而总分只会更高。因此每个状态只保留最高分不会丢失全局最优解。

结论：由初始状态出发，逐轮枚举全部合法动作并保留每个状态的最优分数，归纳可知第 m 层包含所有完整方案的最优值，取其最大值即为答案。

边界与常见错误

  • 负数：不能把未访问状态初始化为 0；负无穷用于区分“不可达”和“分数为负”。
  • 右端下标：当前已经右取 i-left 次，所以右端是 n-1-(i-left)，最容易出现差一错误。
  • 操作次数：必须用完全部 m 个乘数，不能在中途分数较高时提前结束。
  • 贪心陷阱：只比较当前两个乘积会忽略拿走端点后对后续选择的影响。
  • 数值范围：JavaScript 使用 Number 足够；Java/C++ 的题目范围下 int 也足够，代码仍以明确的负无穷初始化。

替代方案与面试追问

自顶向下记忆化：递归参数同样只需 (i, left)，直观但有函数调用与递归深度开销。完整二维 DP：更适合还原具体取数路径，空间为 O(m²)。滚动数组只求分数最简洁。

  • 如何还原一条最优路径？——保留二维表，并记录每个状态来自左还是右。
  • 为什么复杂度不依赖 n²？——只有前后各最多 m 个数可能被取到，中间区域永远不会成为端点。
  • 能否原地更新一维数组？——可以谨慎选择遍历方向，但用独立 next 更不易混入本轮新值。
  • 如果每轮允许跳过乘数？——状态需要增加已用乘数/操作规则，终止条件也会改变。

复杂度

状态数O(m²)
每状态转移O(1)
时间O(m²)
额外空间O(m)

记忆句

“做了几步 + 左边拿了几个”，就能推出右边拿了几个，也就能确定当前两个端点。

import java.util.Arrays;

class Solution {
    public int maximumScore(int[] nums, int[] multipliers) {
        int n = nums.length;
        int m = multipliers.length;
        int negativeInfinity = Integer.MIN_VALUE / 4;
        int[] dp = new int[m + 1];
        Arrays.fill(dp, negativeInfinity);
        dp[0] = 0;

        for (int i = 0; i < m; i++) {
            int[] next = new int[m + 1];
            Arrays.fill(next, negativeInfinity);

            for (int left = 0; left <= i; left++) {
                int right = n - 1 - (i - left);
                next[left + 1] = Math.max(
                    next[left + 1],
                    dp[left] + multipliers[i] * nums[left]
                );
                next[left] = Math.max(
                    next[left],
                    dp[left] + multipliers[i] * nums[right]
                );
            }
            dp = next;
        }

        int answer = Integer.MIN_VALUE;
        for (int left = 0; left <= m; left++) {
            answer = Math.max(answer, dp[left]);
        }
        return answer;
    }
}

from typing import List


class Solution:
    def maximumScore(
        self, nums: List[int], multipliers: List[int]
    ) -> int:
        n = len(nums)
        m = len(multipliers)
        dp = [float("-inf")] * (m + 1)
        dp[0] = 0

        for i, multiplier in enumerate(multipliers):
            next_dp = [float("-inf")] * (m + 1)

            for left in range(i + 1):
                right = n - 1 - (i - left)
                next_dp[left + 1] = max(
                    next_dp[left + 1],
                    dp[left] + multiplier * nums[left],
                )
                next_dp[left] = max(
                    next_dp[left],
                    dp[left] + multiplier * nums[right],
                )
            dp = next_dp

        return max(dp)

class Solution {
public:
    int maximumScore(
        vector<int>& nums,
        vector<int>& multipliers
    ) {
        const int n = nums.size();
        const int m = multipliers.size();
        const int negativeInfinity = numeric_limits<int>::min() / 4;
        vector<int> dp(m + 1, negativeInfinity);
        dp[0] = 0;

        for (int i = 0; i < m; ++i) {
            vector<int> next(m + 1, negativeInfinity);

            for (int left = 0; left <= i; ++left) {
                int right = n - 1 - (i - left);
                next[left + 1] = max(
                    next[left + 1],
                    dp[left] + multipliers[i] * nums[left]
                );
                next[left] = max(
                    next[left],
                    dp[left] + multipliers[i] * nums[right]
                );
            }
            dp.swap(next);
        }
