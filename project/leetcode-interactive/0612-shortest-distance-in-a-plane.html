平面上的
最近距离

在二维坐标表中枚举不重复点对，比较欧氏距离，并把最短值保留两位小数。先亲手走完三次比较，再决定是否展开题解。

Problem

题意

给定数据库表 Point2D，每一行表示平面上的一个整数坐标点 (x, y)。请返回表中任意两个不同点之间的最短欧氏距离，结果列名为 shortest，并四舍五入到小数点后两位。

两点 (x₁, y₁) 与 (x₂, y₂) 的欧氏距离为 √((x₁-x₂)² + (y₁-y₂)²)。

表结构：Point2D

列名类型说明
xINT NOT NULLx 坐标
yINT NOT NULLy 坐标

约束与输出契约

  • (x, y) 组合唯一，同一坐标不会重复出现。
  • 问题成立时至少有两个点；否则不存在可比较的点对。
  • 只比较不同点；返回恰好一行、一列 shortest。
  • 最终结果四舍五入到两位小数。
  • 本轮官方元数据未提供坐标数值范围，因此不虚构额外边界。

Solution

题解：把点表与自己配对

核心洞察

距离取决于两个点，所以让 Point2D 自连接成 a 与 b。用字典序条件：

a.x < b.x OR (a.x = b.x AND a.y < b.y)

它只保留“较小点 → 较大点”的方向：不会把点与自身配对，也不会同时生成 A-B 和 B-A。

完整过程

  1. 自连接并按坐标字典序筛出每个无序点对一次。
  2. 对每对计算平方距离 (Δx)² + (Δy)²。
  3. 用 MIN 取最小平方距离。
  4. 最后开平方，并用 ROUND(..., 2) 保留两位小数。

正确性证明

引理 1：字典序连接条件恰好生成每个无序点对一次。对于任意两个不同点，字典序必有且仅有一个较小者，因此二者只有“较小者作为 a”这一方向满足条件；自配对不满足严格小于。

引理 2：查询为每个生成的点对计算其真实欧氏距离的平方。平方根在非负数上严格单调，所以最小平方距离对应且只对应最小欧氏距离。

定理：由引理 1，候选集合包含全部且仅包含不重复的合法点对；由引理 2，对候选平方距离取最小再开平方，得到全局最短欧氏距离。最后的 ROUND 只按输出契约格式化结果。因此查询正确。

复杂度

时间：O(n²)，最坏需要考察 n(n-1)/2 个点对。

额外空间：算法视角为 O(1)；数据库执行器可能为连接/聚合使用内部工作区。

边界

  • 同 x 或同 y 的点仍能被正确比较。
  • 负坐标不影响差值平方。
  • 仅两点时只有一个合法点对。
  • 少于两点会聚合为 NULL，但这不属于题目有效前提。
  • 若坐标极大，应先转高精度数值以防特定数据库整数溢出。

替代方案

可直接交叉连接并用“不等坐标”过滤，答案仍对，但每对会出现两次。应用层可用分治最近点对把时间降至 O(n log n)，却不符合这道 SQL 题的简洁目标。

MySQL · 官方提交语言

PRIMARY 
SELECT
    ROUND(
        SQRT(
            MIN(
                POWER(a.x - b.x, 2) +
                POWER(a.y - b.y, 2)
            )
        ),
        2
    ) AS shortest
FROM Point2D AS a
JOIN Point2D AS b
  ON a.x < b.x
  OR (a.x = b.x AND a.y < b.y);

Java · 本地语义参考

LOCAL REFERENCE
public final class ShortestDistanceInAPlane {
    public static double shortestDistance(int[][] points) {
        if (points == null || points.length < 2) {
            throw new IllegalArgumentException("at least two points are required");
        }

        double best = Double.POSITIVE_INFINITY;
        for (int i = 0; i < points.length; i++) {
            for (int j = i + 1; j < points.length; j++) {
                double dx = (double) points[i][0] - points[j][0];
                double dy = (double) points[i][1] - points[j][1];
                best = Math.min(best, Math.hypot(dx, dy));
            }
        }
        return Math.round(best * 100.0) / 100.0;
    }

    private ShortestDistanceInAPlane() {}
}

function shortestDistance(points) {
  if (!Array.isArray(points) || points.length < 2) {
    throw new TypeError("at least two points are required");
  }

  let best = Number.POSITIVE_INFINITY;
  for (let i = 0; i < points.length; i += 1) {
    for (let j = i + 1; j < points.length; j += 1) {
      const dx = points[i][0] - points[j][0];
      const dy = points[i][1] - points[j][1];
      best = Math.min(best, Math.hypot(dx, dy));
    }
  }
  return Math.round((best + Number.EPSILON) * 100) / 100;
}

Python · 本地语义参考

LOCAL REFERENCE
from math import hypot
from typing import Sequence


def shortest_distance(points: Sequence[Sequence[int]]) -> float:
    if len(points) < 2:
        raise ValueError("at least two points are required")

    best = float("inf")
    for i in range(len(points)):
        for j in range(i + 1, len(points)):
            dx = points[i][0] - points[j][0]
            dy = points[i][1] - points[j][1]
            best = min(best, hypot(dx, dy))
    return round(best + 1e-12, 2)

面试追问

  1. 为什么比较平方距离即可决定最短点对？
  2. 如何证明字典序条件不会漏掉同 x 的点对？
  3. 数据量很大时，应用层最近点对分治如何做到 O(n log n)？
  4. 坐标可能超出 32 位整数时，SQL 中应怎样安全转换类型？

常见错误

  • 只用 a.x < b.x，会漏掉 x 相同但 y 不同的点。
  • 用 AND 连接 x、y 的不等条件，会漏掉同轴点对。
  • 误用曼哈顿距离 |Δx| + |Δy|。
  • 先分别取最小 Δx 与最小 Δy，它们可能来自不同点对。
  • 忘记结果列别名 shortest 或忘记两位小数。
