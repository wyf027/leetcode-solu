971. 翻转二叉树
以匹配先序遍历

沿着目标行程逐站核对：当左孩子不是下一站时，在当前节点交换左右子树。页面先给你一张可操作的“航线图”，题解则留到最后按需展开。

Flip Binary Tree To Match Preorder Traversal · 非付费题

Problem

题目

flipMatchVoyage(root, voyage)

给定一棵含 n 个节点的二叉树 root。节点值各不相同，均在 1..n 内。数组 voyage 长度同样为 n，表示希望得到的先序遍历（根 → 左 → 右）。

你可以选择任意节点并交换它的左右子树。请用最少的翻转次数让树的先序遍历与 voyage 完全一致，返回所有被翻转节点的值，顺序任意；若无法做到，返回 [-1]。

接口：输入 TreeNode root 与 int[] voyage，返回整数列表。一次“翻转”交换某个节点的整棵左、右子树。
Examples

官方示例

示例 1 · 无法匹配

输入root = [1,2], voyage = [2,1]
输出[-1]
解释先序第一项必须是根 1，无法变成 2。

示例 2 · 翻转根

输入root = [1,2,3], voyage = [1,3,2]
输出[1]
解释在节点 1 交换左右子树，先访问 3。

示例 3 · 无需翻转

输入root = [1,2,3], voyage = [1,2,3]
输出[]
解释原树先序已经与目标一致。

约束

  • 树中节点数为 n，且 n == voyage.length
  • 1 <= n <= 100
  • 1 <= Node.val, voyage[i] <= n
  • 树中节点值互不相同，voyage 中的值也互不相同

Solution

准备好核对思路了吗？

下方内容默认收起，包含证明、边界和四语言完整实现。

Greedy DFS

题解：让下一站决定方向

核心洞察

先序遍历到达节点时，当前值必须等于 voyage[index]，否则无论怎样翻转子树都无法补救。当前节点匹配后，如果左孩子存在但它不是 voyage[index + 1]，为了让下一站正确，只能先走右子树，也就是翻转当前节点。

为什么是最少翻转？

值互不相同，因此目标的下一项唯一。左孩子已是下一项时，翻转会立即走错；左孩子不是下一项时，不翻转也会立即走错。每个决定都是被目标序列强制的，没有额外翻转。

完整过程

维护全局指针

指向 voyage 中尚未匹配的元素。

先核对根值

不相等立刻失败；相等后指针前移。

按下一项选择访问顺序

若左孩子存在且不等于下一项，记录当前节点，并递归右、左；否则递归左、右。

传播失败

任一递归不匹配，最终统一返回 [-1]。

正确性证明

引理：处理节点 u 时，若其值匹配当前目标，则目标下一项（若存在子节点）唯一确定先访问哪棵非空子树。因为所有值唯一，下一项等于左孩子时必须左先；否则若可行，就只能右先并翻转 u。

归纳：根节点先被准确匹配。依据引理选择正确的第一棵子树后，递归调用以同样规则匹配其完整先序片段，再匹配第二棵子树。因此成功时产生的整体先序恰为 voyage；出现值不匹配时不存在可行方案。

最优性：每次记录的翻转都是避免下一步立即不匹配所必需；算法不做任何非必要翻转，所以翻转数最少。

复杂度

时间：O(n)，每个节点一次。
空间：O(h) 递归栈；最坏 O(n)，平衡树为 O(log n)。答案数组不计入辅助空间。

边界情况

  • 根值就不匹配，直接 [-1]
  • 叶节点仅核对自身
  • 只有一个孩子时，不能通过翻转改变该孩子作为下一访问节点的事实
  • 完全匹配时返回空数组

替代方案

可以真的交换左右指针再 DFS，但会修改输入树且没有必要。也可先构造所有翻转组合，复杂度指数级。用索引切分目标片段也能递归，不过需要额外定位或映射，状态更复杂。

常见错误

  • 在访问当前节点之前比较孩子
  • 右孩子为空时仍盲目判断翻转
  • 失败后返回已累积的局部答案
  • 实际修改树后忘记恢复
  • 只检查局部顺序，未传播深层失败

面试追问

  • 若节点值可重复？ 下一项不再唯一决定子树，贪心失效，可能需要带区间的回溯或动态规划。
  • 能否迭代？ 可以用栈模拟先序；遇到需要翻转的节点时将左、右按相反顺序压栈。
  • 为什么无需检查指针最终等于 n？ 题设保证节点数与 voyage 长度相等；若每个访问节点均匹配，最终自然耗尽。工程实现也可补最终检查。

class Solution {
    private int index;
    private List<Integer> flipped;

    public List<Integer> flipMatchVoyage(TreeNode root, int[] voyage) {
        index = 0;
        flipped = new ArrayList<>();
        if (!dfs(root, voyage)) return Arrays.asList(-1);
        return flipped;
    }

    private boolean dfs(TreeNode node, int[] voyage) {
        if (node == null) return true;
        if (index >= voyage.length || node.val != voyage[index]) return false;
        index++;

        if (node.left != null &&
            index < voyage.length &&
            node.left.val != voyage[index]) {
            flipped.add(node.val);
            return dfs(node.right, voyage) && dfs(node.left, voyage);
        }
        return dfs(node.left, voyage) && dfs(node.right, voyage);
    }
}
var flipMatchVoyage = function(root, voyage) {
    let index = 0;
    const flipped = [];

    function dfs(node) {
        if (node === null) return true;
        if (index >= voyage.length || node.val !== voyage[index]) return false;
        index++;

        if (node.left !== null &&
            index < voyage.length &&
            node.left.val !== voyage[index]) {
            flipped.push(node.val);
            return dfs(node.right) && dfs(node.left);
        }
        return dfs(node.left) && dfs(node.right);
    }

    return dfs(root) ? flipped : [-1];
};

        if (index >= voyage.size() || node->val != voyage[index]) {
            return false;

        ++index;

            index < voyage.size() &&
            node->left->val != voyage[index]) {
            flipped.push_back(node->val);
            return dfs(node->right, voyage) && dfs(node->left, voyage);
        }
        return dfs(node->left, voyage) && dfs(node->right, voyage);
    }
