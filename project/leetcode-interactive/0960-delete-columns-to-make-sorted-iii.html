960. 删列造序 III

Delete Columns to Make Sorted III

题目

给定 n 个长度相同的小写字母字符串 strs。选取若干列，并在每一行同时删除这些列。要求删除后每一行自身从左到右按非递减字典序排列，返回最少删除列数。

约束的是每一行内部有序，并不要求字符串数组按行排序。

参数与约束

minDeletionSize(strs: string[]): number

  • n == strs.length
  • 1 ≤ n ≤ 100
  • 1 ≤ strs[i].length ≤ 100
  • 所有字符串等长且只含小写字母

官方示例

输入：strs = ["babca","bbazb"]
输出：3
解释：删除第 0、1、4 列，剩下 ["bc","az"]，每行均非递减。
输入：strs = ["edcba"]
输出：4
解释：至少删除 4 列才能使唯一一行有序。
输入：strs = ["ghi","def","abc"]
输出：0
解释：所有行本来就已非递减。

列链实验室

若对所有行都有 strs[r][j] ≤ strs[r][i]，列 j 才能连接到列 i。

题解：最长可保留列链

核心洞察

反过来寻找能保留的最长列子序列。两列 j < i 能相邻保留，当且仅当每一行均满足 strs[r][j] ≤ strs[r][i]，于是得到一个自定义偏序下的最长递增子序列。

dp[i] = 1 + max(dp[j])；答案 = 列数 − max(dp)

完整过程

  1. 初始化每个 dp[i] 为 1。
  2. 从左到右枚举终点列 i，再枚举 j < i。
  3. 逐行检查 j 到 i 是否都非递减；合法则用 dp[j]+1 更新 dp[i]。
  4. 用总列数减去最长链长度。

正确性

合法链的每对相邻列在所有行上均非递减，由传递性可知保留后的每一行有序。任意合法保留方案的相邻列也必满足转移条件，所以它对应 DP 中的一条链；DP 又只生成合法链，因此最长链恰是最多可保留列数，取补集即为最少删除数。

边界与复杂度

  • 单列答案为 0；完全无法连接时仅保留一列。
  • 相等字符允许连接。
  • 时间 O(n·m²)，空间 O(m)。

替代方案与追问

可将每列看作 n 维向量，在逐坐标不下降的偏序下求最长链，本质仍是此 DP。若需恢复列，记录 parent 前驱并回溯；若要求严格递增，将 ≤ 改为 <。

常见错误

  • 误以为要让数组按行排序。
  • 只检查一行，或把相等字符判为非法。
  • 直接返回最长链而忘记用总列数相减。

四语言实现

class Solution {
  public int minDeletionSize(String[] s) {
    int m=s[0].length(), best=1; int[] dp=new int[m];
    for(int i=0;i<m;i++){ dp[i]=1;
      for(int j=0;j<i;j++){ boolean ok=true;
        for(String x:s) if(x.charAt(j)>x.charAt(i)){ok=false;break;}
        if(ok) dp[i]=Math.max(dp[i],dp[j]+1);
      } best=Math.max(best,dp[i]);
    } return m-best;
  }
}

class Solution:
    def minDeletionSize(self, strs: List[str]) -> int:
        m = len(strs[0])
        dp = [1] * m
        for i in range(m):
            for j in range(i):
                if all(s[j] <= s[i] for s in strs):
                    dp[i] = max(dp[i], dp[j] + 1)
        return m - max(dp)
