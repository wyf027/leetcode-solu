根据身高
重建队列 Queue Reconstruction by Height

每个人由 [h, k] 描述：身高是 h，前方恰好有 k 位身高不低于他的人。请把打乱的人群恢复成合法队列。

#406 1 ≤ n ≤ 2000 保证存在答案 本地交互演示
01 / Problem

题目描述

输入中的人并未按队列顺序排列；返回数组的第 0 项代表队首。

给定二维数组 people，其中 people[i] = [hᵢ, kᵢ] 表示一个身高为 hᵢ 的人，并且在他的前面恰好有 kᵢ 个人的身高大于或等于 hᵢ。

请重新构造这个队列并返回。返回值 queue 中，queue[j] = [hⱼ, kⱼ] 表示队列第 j 个位置上的人， queue[0] 位于队首。

约束

  • 1 <= people.length <= 2000
  • 0 <= hᵢ <= 10⁶
  • 0 <= kᵢ < people.length
  • 题目保证队列可以被重建。

示例 1

输入 
people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
输出 
[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]

例如 [6,1] 前方只有 [7,0] 的身高不低于 6；[4,4] 前方则恰有 4 人的身高不低于 4。

示例 2

输入 
people = [[6,0],[5,0],[4,0],[3,2],[2,2],[1,4]]
输出 
[[4,0],[5,0],[2,2],[3,2],[1,4],[6,0]]

每个二元组都必须同时满足自己的身高与前方计数条件。

题解包含贪心选择为何成立、正确性证明、复杂度、四种语言实现与面试追问。默认收起，避免提前泄露答案。

核心洞察

先安排高个子，再按 k 插入

先按身高 h 降序排列；身高相同的人按 k 升序排列。随后从左到右处理， 把每个人直接插入当前队列的下标 k。

排序键：(-h, k)　→　依次执行 queue.insert(k, [h, k])

当处理 [h, k] 时，队列里已经存在的人都不矮于 h，因此插到下标 k，前方恰有 k 个“身高 ≥ h”的人。 后续加入的人只会更矮，不会改变这一计数。同身高时先放较小的 k，也保证当前人的插入位置合法。

完整过程

  1. 将 people 按身高从高到低排序。
  2. 身高相同时，让 k 较小的人先处理。
  3. 初始化空列表 queue。
  4. 按排序结果遍历，把 [h, k] 插到 queue[k]。
  5. 遍历结束后返回 queue。

正确性证明

不变式：每次插入结束后，当前队列中所有已处理者的 k 条件都成立。

基础情形为空队列，显然成立。假设插入 [h, k] 前不变式成立。由于已处理者身高都 ≥ h， 将其插到下标 k 后，它前面恰有 k 位身高 ≥ h 的人，所以新人的条件成立。

对已有成员，新人不比他们高；若同高，则排序保证新人拥有不小的 k，插入不会破坏先前同高成员的前方计数。 因而原条件保持成立。由归纳法，全部插入后返回队列合法。

复杂度与边界

  • 排序耗时 O(n log n)。
  • 数组列表中间插入最坏 O(n)，总计 O(n²)。
  • 结果列表占 O(n) 额外空间；排序额外空间依语言实现而定。
  • 单个元素 [h, 0] 会直接成为答案。
  • 全部同高时，按 k 升序插入即可。
  • k 可以为 0，也可以接近当前队列末尾。

替代方案

也可以按身高升序、同高 k 降序处理，并用树状数组或线段树查找“第 k+1 个空位”。 这样可把插入位置查询降到 O(log n)，整体达到 O(n log n)，但实现更复杂。

在本题 n ≤ 2000 时，降序排序配合数组插入通常更短、更清晰，也更适合面试现场说明。

面试追问

  • 为什么不能按身高升序后仍然直接插入下标 k？
  • 同身高时为什么必须让 k 小的先处理？
  • 若 n 扩大到 10⁵，如何用树状数组找第 k 个空位？
  • 输入不保证可重建时，怎样验证最终队列？

常见错误

  • 误把 k 理解为前方所有人的数量，而忽略身高过滤条件。
  • 身高相同时按 k 降序，导致插入位置尚不存在或打乱计数。
  • 排序比较器使用减法时忽略潜在溢出；Java 可用 Integer.compare。
  • 原地排序会改变输入；若题目外部要求保留输入，应先复制。
  • 只返回排序结果，漏掉“按 k 插入”的核心步骤。

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public int[][] reconstructQueue(int[][] people) {
        Arrays.sort(people, (a, b) -> {
            if (a[0] != b[0]) {
                return Integer.compare(b[0], a[0]);
            }
            return Integer.compare(a[1], b[1]);
        });

        List<int[]> queue = new ArrayList<>();
        for (int[] person : people) {
            queue.add(person[1], person);
        }

        return queue.toArray(new int[people.length][]);
    }
}

 * @param {number[][]} people

var reconstructQueue = function (people) {
    people.sort((a, b) => {
        if (a[0] !== b[0]) {
            return b[0] - a[0];
        }
        return a[1] - b[1];
    });

    const queue = [];
    for (const person of people) {
        queue.splice(person[1], 0, person);
    }
    return queue;
};

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        sort(people.begin(), people.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 if (a[0] != b[0]) {
                     return a[0] > b[0];
                 }
                 return a[1] < b[1];
             });

        vector<vector<int>> queue;
        for (const auto& person : people) {
            queue.insert(queue.begin() + person[1], person);
        }
        return queue;
    }
};
