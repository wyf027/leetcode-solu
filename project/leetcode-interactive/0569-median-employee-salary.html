Problem brief

题意与数据结构

给定员工表，按公司分别寻找薪资排序后位于中央位置的员工。公司人数为奇数时返回一位，为偶数时返回中央相邻的两位；结果顺序不限。

Employee 表

每一行是一名员工；id 标识员工，company 指明公司，salary 是薪水。

字段类型含义
idINT员工编号
companyVARCHAR(255)公司标识
salaryINT员工薪水

目标与约束

  • 以 company 为独立分组，不混合不同公司的薪资。
  • 输出列为 id, company, salary；结果行顺序不限。
  • 偶数人数公司的中间两名员工都要返回，不把两份薪水求平均。
  • 官方元数据只给出上述 SQL 字段类型，未提供额外数值范围。

Solution

窗口编号锁定中央行

核心不是计算“中央薪资的平均数”，而是准确找出每个公司薪资有序序列中的中央员工行。

核心洞察

对每家公司分别按 salary, id 升序编号，同时统计公司人数。奇数与偶数两种情况，可以由同一对位置公式统一表达。

左侧中央位置floor((n + 1) / 2)
右侧中央位置floor((n + 2) / 2)

当 n 为奇数，两式相等，只选择一行；当 n 为偶数，两式相邻，恰好选择两行。

完整过程

  1. 用 PARTITION BY company 隔离公司。
  2. 以 salary, id 升序生成稳定的 ROW_NUMBER()。
  3. 在同一分区用 COUNT(*) OVER 得到人数 n。
  4. 仅保留行号等于左、右中央位置的记录。
  5. 投影回题目要求的三列；无需额外排序。

边界处理

  • n = 1：两个位置公式都为 1，只返回该员工一次。
  • n 为偶数：返回两条员工记录，而非返回薪资平均值。
  • 薪资并列：加入 id 作为第二排序键，保证位置确定。
  • 多家公司：编号和计数均在公司分区内重置。

正确性证明

分区完整性：窗口函数按 company 分区，因此每行的 rn 与 cnt 只由同公司员工决定。
排序位置正确：ROW_NUMBER 按 salary、id 升序给出 1 到 n 的连续位置，每个位置唯一对应一名员工。
奇数情形：若 n = 2k + 1，两条公式都等于 k + 1，正是唯一中央位置。
偶数情形：若 n = 2k，两条公式分别等于 k 与 k + 1，正是中央相邻位置。
结论：筛选上述位置，恰好返回每家公司定义所需的全部中位员工，且不含额外行。
官方提交语言 · MySQL 8+Primary answer
WITH ranked AS (
    SELECT
        id,
        company,
        salary,
        ROW_NUMBER() OVER (
            PARTITION BY company
            ORDER BY salary ASC, id ASC
        ) AS rn,
        COUNT(*) OVER (
            PARTITION BY company
        ) AS cnt
    FROM Employee
)
SELECT id, company, salary
FROM ranked
WHERE rn IN (
    FLOOR((cnt + 1) / 2),
    FLOOR((cnt + 2) / 2)
);

复杂度

时间：总员工数为 N 时，窗口排序通常为 O(N log N)。
空间：通常需要 O(N) 级中间空间；实际取决于优化器、索引与分区分布。

替代方案

旧版 MySQL 可用自连接统计每行两侧人数，或以用户变量模拟分组编号，但更复杂，也更易受并列值和求值顺序影响。支持窗口函数时，ROW_NUMBER + COUNT 更直接稳定。

Java · 完整本地语义参考

按公司分组后排序，选择零基中央下标。

import java.util.*;

public class MedianEmployeeSalary {
    public record Employee(int id, String company, int salary) {}

    public static List<Employee> medianEmployees(List<Employee> employees) {
        Map<String, List<Employee>> groups = new TreeMap<>();
        for (Employee employee : employees) {
            groups.computeIfAbsent(employee.company(), key -> new ArrayList<>())
                  .add(employee);
        }

        Comparator<Employee> order = Comparator
            .comparingInt(Employee::salary)
            .thenComparingInt(Employee::id);
        List<Employee> answer = new ArrayList<>();

        for (List<Employee> group : groups.values()) {
            group.sort(order);
            int left = (group.size() - 1) / 2;
            int right = group.size() / 2;
            answer.add(group.get(left));
            if (right != left) answer.add(group.get(right));
        }
        return answer;
    }

    public static void main(String[] args) {
        List<Employee> data = List.of(
            new Employee(1, "A", 2341), new Employee(2, "A", 341),
            new Employee(3, "A", 15), new Employee(4, "A", 15314),
            new Employee(5, "A", 451), new Employee(6, "A", 513)
        );
        medianEmployees(data).forEach(System.out::println);
    }
}
JavaScript · 完整本地语义参考

返回新数组，不改写输入记录；薪资相同时按 id 升序。

function medianEmployees(employees) {
  const groups = new Map();
  for (const employee of employees) {
    if (!groups.has(employee.company)) groups.set(employee.company, []);
    groups.get(employee.company).push({ ...employee });
  }

  const answer = [];
  const companies = [...groups.keys()].sort();
  for (const company of companies) {
    const group = groups.get(company).sort(
      (a, b) => a.salary - b.salary || a.id - b.id,
    );
    const left = Math.floor((group.length - 1) / 2);
    const right = Math.floor(group.length / 2);
    answer.push(group[left]);
    if (right !== left) answer.push(group[right]);
  }
  return answer;
}

const employees = [
  { id: 1, company: "A", salary: 2341 },
  { id: 2, company: "A", salary: 341 },
  { id: 3, company: "A", salary: 15 },
  { id: 4, company: "A", salary: 15314 },
  { id: 5, company: "A", salary: 451 },
  { id: 6, company: "A", salary: 513 },
];
console.log(medianEmployees(employees));
Python · 完整本地语义参考

使用 dataclass 表示员工记录，返回各公司中央员工。

from collections import defaultdict
from dataclasses import dataclass
from typing import Iterable


@dataclass(frozen=True)
class Employee:
    id: int
    company: str
    salary: int


def median_employees(employees: Iterable[Employee]) -> list[Employee]:
    groups: dict[str, list[Employee]] = defaultdict(list)
    for employee in employees:
        groups[employee.company].append(employee)

    answer: list[Employee] = []
    for company in sorted(groups):
        group = sorted(groups[company], key=lambda e: (e.salary, e.id))
        left = (len(group) - 1) // 2
        right = len(group) // 2
        answer.append(group[left])
        if right != left:
            answer.append(group[right])
    return answer


if __name__ == "__main__":
    data = [
        Employee(1, "A", 2341), Employee(2, "A", 341),
        Employee(3, "A", 15), Employee(4, "A", 15314),
        Employee(5, "A", 451), Employee(6, "A", 513),
    ]
    print(median_employees(data))
C++ · 完整本地语义参考

使用 map 保持公司遍历稳定，以 salary、id 排序。

#include <algorithm>
#include <iostream>
#include <map>
#include <string>
#include <vector>

struct Employee {
    int id;
    std::string company;
    int salary;
};

std::vector<Employee> medianEmployees(
    const std::vector<Employee>& employees
) {
    std::map<std::string, std::vector<Employee>> groups;
    for (const Employee& employee : employees) {
        groups[employee.company].push_back(employee);
    }

    std::vector<Employee> answer;
    for (auto& [company, group] : groups) {
        std::sort(group.begin(), group.end(), [](const auto& a, const auto& b) {
            if (a.salary != b.salary) return a.salary < b.salary;
            return a.id < b.id;
        });
        const std::size_t left = (group.size() - 1) / 2;
        const std::size_t right = group.size() / 2;
        answer.push_back(group[left]);
        if (right != left) answer.push_back(group[right]);
    }
    return answer;
}

int main() {
    std::vector<Employee> data{
        {1, "A", 2341}, {2, "A", 341}, {3, "A", 15},
        {4, "A", 15314}, {5, "A", 451}, {6, "A", 513}
    };
    for (const auto& e : medianEmployees(data)) {
        std::cout << e.id << ' ' << e.company << ' '
                  << e.salary << '\n';
    }
}

面试追问

  • 如果数据库不支持窗口函数，如何用自连接表达“左右人数平衡”？
  • 为什么不能直接改用 RANK()？薪资并列时会怎样？
  • 若业务要求返回所有“薪资等于中位薪资”的人，查询应如何改变？
  • 什么复合索引可能帮助按 company、salary、id 访问数据？

常见错误

  • 把偶数公司的两位员工薪资取平均，导致无法返回原始员工行。
  • 遗漏 company 分区，得到整张表的全局中位数。
  • 只按 salary 排序却不处理并列值，结果依赖不稳定顺序。
  • 把零基下标公式直接用于 SQL，产生一位偏移。
  • 用 GROUP BY 后丢失 id，无法还原对应员工。
