从先序遍历还原二叉树

Recover a Tree From Preorder Traversal · 树 / 深度优先搜索 / 字符串 / 二叉树

题目

对一棵二叉树进行先序 DFS。每访问一个深度为 D 的节点，先写出 D 个短划线，再写节点值；根深度为 0，子节点深度比父节点大 1。给定字符串 traversal，还原并返回根节点。若某节点只有一个孩子，保证它是左孩子。

函数：recoverFromPreorder(traversal: string) → TreeNode

约束：原树节点数为 [1, 1000]；1 ≤ Node.val ≤ 10⁹。

示例 1

输入：traversal = "1-2--3--4-5--6--7"
输出：[1,2,5,3,4,6,7]

示例 2

输入：traversal = "1-2--3---4-5--6---7"
输出：[1,2,5,3,null,6,null,4,null,7]

示例 3

输入：traversal = "1-401--349---90--88"
输出：[1,401,null,349,88,90]

题解：解析 + 深度栈

核心洞察

短划线数量就是节点深度。先序顺序保证新节点的父节点一定是栈中深度 d-1 的节点；连接前把栈截断到长度 d，栈顶就是父节点。父节点没有左孩子时接左侧，否则接右侧。

完整过程

  1. 数连续短划线得到 depth。
  2. 读取连续数字得到节点值。
  3. 弹栈直到长度等于 depth。
  4. 将新节点接到栈顶的左空位或右空位，再入栈。

正确性

对解析次序归纳。先序遍历中，当前节点之前最近的深度 depth-1 节点必为父节点；栈截断后栈顶恰是它。先序先访问左子树，且单孩子必为左孩子，所以首个孩子接左侧、第二个接右侧与原树一致。根节点无需连接，因此所有节点与边都被正确恢复。

边界与复杂度

单节点直接返回；多位数要连续读取；深度可能一次回退多层。每个字符读取一次、节点入栈出栈至多一次，时间 O(|traversal|)，辅助空间 O(h)。

替代方案

递归解析可携带“期望深度”，只在短划线数量匹配时消费节点；写法贴近树结构，但必须正确处理输入指针不匹配时不前进，并承担最坏 O(n) 递归深度。

面试追问

  • 为什么不能表达只有右孩子？编码不区分单独右孩子，故题目必须保证单孩子为左孩子。
  • 能否流式处理？可以，保留祖先栈和当前数字解析状态。
  • 若值允许负数？负号会与深度短划线冲突，需要改变编码或添加分隔符。

常见错误

  • 栈长度与深度错一位。
  • 只读一位数字，无法处理 401。
  • 回退深度时只弹一次。
  • 无条件覆盖左孩子，丢失右子树。

Java

class Solution {
    public TreeNode recoverFromPreorder(String s) {
        java.util.List<TreeNode> st = new java.util.ArrayList<>();
        int i = 0;
        while (i < s.length()) {
            int d = 0, v = 0;
            while (i < s.length() && s.charAt(i) == '-') { d++; i++; }
            while (i < s.length() && Character.isDigit(s.charAt(i)))
                v = v * 10 + s.charAt(i++) - '0';
            TreeNode node = new TreeNode(v);
            while (st.size() > d) st.remove(st.size() - 1);
            if (!st.isEmpty()) {
                TreeNode p = st.get(st.size() - 1);
                if (p.left == null) p.left = node; else p.right = node;
            }
            st.add(node);
        }
        return st.get(0);
    }
}

JavaScript

var recoverFromPreorder = function(s) {
  const stack = [];
  let i = 0;
  while (i < s.length) {
    let depth = 0, value = 0;
    while (i < s.length && s[i] === '-') { depth++; i++; }
    while (i < s.length && s[i] >= '0' && s[i] <= '9')
      value = value * 10 + Number(s[i++]);
    const node = new TreeNode(value);
    while (stack.length > depth) stack.pop();
    if (stack.length) {
      const p = stack[stack.length - 1];
      if (p.left === null) p.left = node; else p.right = node;
    }
    stack.push(node);
  }
  return stack[0];
};

class Solution:
    def recoverFromPreorder(self, traversal: str) -> Optional[TreeNode]:
        stack, i, n = [], 0, len(traversal)
        while i < n:
            depth = value = 0
            while i < n and traversal[i] == '-':
                depth, i = depth + 1, i + 1
            while i < n and traversal[i].isdigit():
                value = value * 10 + int(traversal[i])
                i += 1
            node = TreeNode(value)
            while len(stack) > depth:
                stack.pop()
            if stack:
                if stack[-1].left is None:
                    stack[-1].left = node
                else:
                    stack[-1].right = node
            stack.append(node)
        return stack[0]

C++

class Solution {
public:
    TreeNode* recoverFromPreorder(string s) {
        vector<TreeNode*> st;
        int i = 0, n = s.size();
        while (i < n) {
            int depth = 0, value = 0;
            while (i < n && s[i] == '-') depth++, i++;
            while (i < n && isdigit(s[i]))
                value = value * 10 + s[i++] - '0';
            TreeNode* node = new TreeNode(value);
            while ((int)st.size() > depth) st.pop_back();
            if (!st.empty()) {
                TreeNode* p = st.back();
                if (!p->left) p->left = node; else p->right = node;
            }
            st.push_back(node);
        }
        return st[0];
    }
};
