修剪二叉搜索树

在一棵有序的树里划定边界，保留区间内的节点，并维持它们原有的祖先—后代关系。先读题、再动手观察；完整题解不会在首屏泄露。

LeetCode 669Medium函数：trimBST(root, low, high)非付费题
Problem

题意与边界

返回值是修剪后的新根节点

给定二叉搜索树根节点 root，以及闭区间的下界 low 和上界 high。请修剪这棵树，使所有留下节点的值都位于 [low, high]。

修剪不能改变保留节点之间的相对结构：原本是某节点后代的保留节点，修剪后仍应是它的后代。答案唯一；由于原根可能不在区间内，结果的根节点也可能改变。

函数形式
TreeNode trimBST(TreeNode root, int low, int high)

约束

  • 树中节点数为 [1, 10⁴]。
  • 0 ≤ Node.val ≤ 10⁴。
  • 每个节点值互不相同。
  • root 保证是一棵有效的二叉搜索树。
  • 0 ≤ low ≤ high ≤ 10⁴。
示例 1 
输入：root = [1,0,2], low = 1, high = 2
输出：[1,null,2]
示例 2 
输入：root = [3,0,4,null,2,null,null,1], low = 1, high = 3
输出：[3,2,null,1]
读题提醒

数组采用层序序列化，null 表示对应位置没有节点。输出只要求结构和值正确。

Complete solution

题解：让 BST 的有序性替你剪枝

核心洞察

BST 中，某节点左子树的所有值更小，右子树的所有值更大。因此一旦根值低于 low，根和整棵左子树都不可能保留；高于 high 时同理可整体舍弃右侧。

一句话状态定义

trimBST(root) 返回：以 root 为根的子树修剪完成后，应接回父节点的那棵树。

完整过程

  1. 空树：返回 null，它已经满足要求。
  2. 根值小于 low：根和左子树全部过小；递归修剪右子树，并直接返回右侧结果。
  3. 根值大于 high：根和右子树全部过大；递归修剪左子树，并直接返回左侧结果。
  4. 根值落在区间：保留根，分别修剪左右子树，再把返回的新根接回 root.left 与 root.right。
  5. 返回当前根：局部修剪完成；递归返回值会自动完成“删除节点后的重新接线”。

正确性证明

命题：算法返回的树恰好包含原子树中值位于 [low, high] 的全部节点，并保持这些节点原有的祖先—后代关系。

证明：对输入子树高度做归纳。空树显然成立。设非空子树根为 r：若 r.val < low，由 BST 性质，r 及其左子树全部越界，所有可能保留的节点只在右子树；递归结果依据归纳假设正确。r.val > high 的情形对称。若根值在区间内，则根必须保留；左右子树经递归分别得到正确修剪结果，再接回根，不会改变任何保留节点的相对祖先关系。三种情况覆盖全部输入，命题成立。

边界情况

  • 根节点本身越界，答案根会改变。
  • low = high 时最多保留一个值。
  • 全部节点越界时返回 null。
  • 单链树可能产生很深的递归栈。
  • 边界值等于节点值时，该节点应保留。

复杂度

时间
O(n)

最坏访问全部 n 个节点；整侧剪枝时会更少。

空间
O(h)

递归栈高度 h；最坏退化为 O(n)。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode trimBST(TreeNode root, int low, int high) {
        if (root == null) {
            return null;
        }
        if (root.val < low) {
            return trimBST(root.right, low, high);
        }
        if (root.val > high) {
            return trimBST(root.left, low, high);
        }

        root.left = trimBST(root.left, low, high);
        root.right = trimBST(root.right, low, high);
        return root;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @param {number} low
 * @param {number} high
 * @return {TreeNode}
 */
var trimBST = function(root, low, high) {
    if (root === null) {
        return null;
    }
    if (root.val < low) {
        return trimBST(root.right, low, high);
    }
    if (root.val > high) {
        return trimBST(root.left, low, high);
    }

    root.left = trimBST(root.left, low, high);
    root.right = trimBST(root.right, low, high);
    return root;
};

class Solution:

        self,

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* trimBST(TreeNode* root, int low, int high) {
        if (root == nullptr) {
            return nullptr;
        }
        if (root->val < low) {
            return trimBST(root->right, low, high);
        }
        if (root->val > high) {
            return trimBST(root->left, low, high);
        }

        root->left = trimBST(root->left, low, high);
        root->right = trimBST(root->right, low, high);
        return root;
    }
};
递归返回值可能是新的子树根，因此必须重新赋给父节点指针。

替代方案：迭代修剪

先沿 BST 有序方向寻找一个落在区间内的新根；再分别修剪左链上过小的节点、右链上过大的节点。

什么时候考虑迭代？

当树可能退化为很深的单链，且语言递归栈较小。迭代能把额外空间降为 O(1)，但指针处理更容易出错。

面试追问

  • 为什么可以整棵丢弃一侧子树？
  • 如果输入不是 BST，这个剪枝还成立吗？
  • 如何改写成 O(1) 额外空间的迭代版本？
  • 能否保持节点对象复用、不新建节点？

常见错误

  • 只删除越界根，却忘了接回它可能保留的子树。
  • 把严格比较写成 ≤ / ≥，误删边界节点。
  • 递归修剪后没有给 root.left/right 重新赋值。
  • 按普通二叉树逐节点过滤，错过 BST 的整侧剪枝。

思维模型

每次递归都回答一个连接问题：“这棵子树修剪后，父节点应该连向谁？”返回新根，比在父层猜测删除后的替代节点更自然。
