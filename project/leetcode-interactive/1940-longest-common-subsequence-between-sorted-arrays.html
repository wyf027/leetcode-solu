Longest Common Subsequence Between Sorted Arrays

多个有序序列，寻找它们都能保留的最长序列。

01 / 题目

给定二维整数数组 arrays，其中每个 arrays[i] 都严格递增。请返回一个整数数组，表示所有输入数组的最长公共子序列。

子序列允许删除任意元素，但保留下来的元素不能改变原有顺序，也不要求连续。返回的是序列本身，而不是它的长度；若没有共同元素，返回空数组。

longestCommonSubsequence(arrays: integer[][]) → list<integer>

输入约束

  • 2 ≤ arrays.length ≤ 100
  • 1 ≤ arrays[i].length ≤ 100
  • 1 ≤ arrays[i][j] ≤ 100
  • 每一个内层数组严格递增，因此同一数组中不会出现重复值。

04 / 思路实验室

准备好后再打开；包含完整题解。

核心洞察 / 把顺序条件用起来

严格递增让所有公共值的相对顺序天然一致。所以，按从小到大排列的全体公共元素，就是最长公共子序列。

值域只有 1～100。用 count[x] 记录数值 x 一共出现了多少次。每个数组内部没有重复值，因此次数恰好等于包含 x 的数组数。只有 count[x] === arrays.length 的值能进入结果。

完整过程

  1. 建立长度 101、初始为 0 的计数数组，第 0 项不用。
  2. 扫描每个内层数组；读到 x 时执行 count[x]++。
  3. 枚举 x = 1, 2, …, 100；如果次数等于数组数量，就把 x 加入结果。
  4. 返回递增结果。例如示例 2 中，2、3、6 的次数都为 3，其他出现过的数次数不足 3，结果为 [2,3,6]。

正确性论证

计数不变量：扫描任意前缀后，count[x] 等于该前缀中 x 的出现次数。扫描结束后，由每行无重复可知，这也等于含 x 的数组数。

合法性：被选中的每个 x 都出现在全部数组里。按升序输出后，顺序与每个严格递增数组一致，所以结果是所有数组的公共子序列。

最优性：任何公共子序列中的元素都必须出现在全部数组里，因此一定属于我们收集的集合。算法收集了这个集合的全部元素且可同时保留，所以不可能存在更长的公共子序列。

边界与复杂度

交集为空时自然得到 []；完全相同时保留所有值；长度为 1 的数组同样适用。计数数组必须容纳下标 100。空外层数组或带重复值的内层数组不在本题输入契约内。

设 N 为所有内层数组元素总数，U = 100，L 为答案长度。时间 O(N + U)，辅助空间 O(U)，返回结果额外占 O(L)；固定值域下可写作 O(N) 时间、O(1) 辅助空间。

替代方案

按照官方提示，可从第一个数组开始，逐个与后续数组用双指针求交集；较小值向前移动，相等则保留。每轮的交集作为下一轮输入，交集为空即可停止。设第一行长度为 m，各轮交集长度不超过 m，时间上界 O(N + km)，辅助空间 O(m)，k 为数组数。它不依赖小值域，适合很大的整数。

也可用哈希表计数，再按第一个数组的顺序筛选公共值，避免排序。普通二维 LCS 动态规划能处理两个无序序列，但本题的排序条件让集合交集就足够。

常见错误

  • 返回公共元素个数：本题要求返回整数数组。
  • 只求前两行的交集：还必须满足剩余所有数组。
  • 遍历无序哈希键直接返回：必须保证答案顺序。
  • 仅分配 100 个计数槽：无法访问下标 100。
  • 将本解直接用于允许重复值的数组：同一行的重复会错误增加“包含它的数组数”。

面试追问

值域变成 10⁹？改用哈希计数或逐轮双指针交集。允许重复但仍非递减？每个值的答案重数应为各数组重数的最小值，可用双指针保留这些匹配；若只要求不同公共值，则每行先去重。取消排序？交集不再保证顺序兼容，如 [1,2] 和 [2,1]；两个数组可用 LCS 动态规划，多数组需要重新设计状态，不能直接沿用本解。

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> longestCommonSubsequence(int[][] arrays) {
        int[] count = new int[101];
        for (int[] row : arrays) {
            for (int x : row) {
                count[x]++;
            }
        }
        List<Integer> answer = new ArrayList<>();
        for (int x = 1; x <= 100; x++) {
            if (count[x] == arrays.length) {
                answer.add(x);
            }
        }
        return answer;
    }
}

Python

from typing import List

class Solution:
    def longestCommonSubsequence(self, arrays: List[List[int]]) -> List[int]:
        count = [0] * 101
        for row in arrays:
            for x in row:
                count[x] += 1
        return [x for x in range(1, 101) if count[x] == len(arrays)]

C++

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> longestCommonSubsequence(vector<vector<int>>& arrays) {
        int count[101] = {};
        for (const auto& row : arrays) {
            for (int x : row) ++count[x];
        }
        vector<int> answer;
        for (int x = 1; x <= 100; ++x) {
            if (count[x] == static_cast<int>(arrays.size())) {
                answer.push_back(x);
            }
        }
        return answer;
    }
};
