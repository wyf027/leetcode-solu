检查「好数组」

从“任取子集、任乘整数”的自由组合出发，判断一个正整数数组能否拼出恰好为 1 的和。

输入
正整数数组 nums
输出
boolean
规模
最多 10⁵ 个数
01

题目

先只看目标，不急着看结论。

给你一个正整数数组 nums。你可以任选其中若干元素，并让每个被选中的元素分别乘以一个任意整数（整数可以为正、负或零），最后把这些乘积相加。

如果存在某种选择和整数系数，使最终的和等于 1，那么这个数组就是「好数组」。是则返回 true，否则返回 false。

EXAMPLE 01
输入nums = [12,5,7,23]
输出true

选 5 和 7：5×3 + 7×(-2) = 1。

EXAMPLE 02
输入nums = [29,6,10]
输出true

29×1 + 6×(-3) + 10×(-1) = 1。

EXAMPLE 03
输入nums = [3,6]
输出false

不存在满足要求的子集与整数系数组合。

约束

  • 1 <= nums.length <= 105
  • 1 <= nums[i] <= 109

03

题解

核心是裴蜀定理：问题不需要搜索子集，也不需要真的求出系数。

核心洞察

设所有元素的最大公约数为 g。任意整数线性组合都一定是 g 的倍数；反过来，裴蜀定理保证存在一组整数系数，让线性组合恰好等于 g。

数组是好数组 ⇔ gcd(nums) = 1

为什么“任选子集”不碍事？

没有选中的元素可以视为系数取 0，因此“子集”与“给全体元素分配整数系数”完全等价。我们只要连续计算最大公约数；一旦得到 1，就可以提前返回。

g ← gcd(g, nums[i])

完整过程

  1. 初始化。令 g = 0。利用 gcd(0, x) = x，可以统一处理第一个元素。
  2. 逐项合并。对每个 x，更新 g = gcd(g, x)。用欧几里得算法求两数最大公约数。
  3. 提前结束。如果某一步 g == 1，后续再与任何正整数取 gcd 都仍然是 1，立即返回 true。
  4. 最终判定。遍历结束后，返回 g == 1。

正确性证明

必要性：记 g = gcd(nums)。由于 g 整除每个数组元素，所以它也整除这些元素的任何整数线性组合。若某个线性组合等于 1，则 g | 1；又因为 g 为正整数，只能有 g = 1。

充分性：若 gcd(nums) = 1，根据裴蜀定理，存在整数系数 x₁, x₂, …, xₙ，使 nums[0]×x₁ + … + nums[n−1]×xₙ = 1。系数为 0 的元素视作未选入子集，因此题目要求可以实现。

结论：算法当且仅当所有元素的最大公约数为 1 时返回 true，所以算法正确。

Time
O(n log M)
M 为数组中的最大值；每次 gcd 使用欧几里得算法。
Space
O(1)
只保存滚动的最大公约数，不计输入数组。

边界情况

  • 数组仅有一个数：只有该数为 1 时返回 true。
  • 数组中含有 1：答案立刻为 true。
  • 所有数相同：只有它们都为 1 时才是好数组。
  • 公共因子大于 1：任何整数线性组合都无法得到 1。
  • 乘积可能溢出不是问题：算法只做取模，不显式构造系数或乘积。

替代方案

  • 扩展欧几里得：可以真的构造出整数系数，但题目只要求布尔值，额外维护系数没有必要。
  • 枚举子集或系数：搜索空间无限或指数级，不可行；题目的“任意整数”正是在提示数论性质。
  • 质因数分解：可判断是否存在全体公共质因子，但对每个大数分解成本更高，也比滚动 gcd 复杂。

面试追问

  • 如果还要输出一组可行系数，如何用扩展欧几里得逐步合并？
  • 如果系数必须非负，gcd = 1 还足够吗？为什么问题会变成另一类？
  • 数据流持续到来时，如何在线维护答案？什么时候能永久停止读取？
  • 若允许输入 0 或负数，gcd 实现应怎样规范化？

常见错误

  • 只检查是否存在两个数互质；整体 gcd 可能为 1，但任意一对都不互质，例如 6、10、15。
  • 误以为系数只能是正数，漏掉负系数提供的抵消。
  • 尝试真的枚举系数，忽略系数没有上下界。
  • JavaScript 用递归 gcd 时忘记保证余数终止，或把输入文本直接拼入 HTML。

四语言完整代码

均匹配 LeetCode 官方函数签名；实现滚动 gcd，并在结果为 1 时提前返回。

JavaO(n log M)
class Solution {
    public boolean isGoodArray(int[] nums) {
        int g = 0;
        for (int x : nums) {
            g = gcd(g, x);
            if (g == 1) return true;
        }
        return false;
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }
}
JavaScriptO(n log M)
/**
 * @param {number[]} nums
 * @return {boolean}
 */
var isGoodArray = function(nums) {
    const gcd = (a, b) => {
        while (b !== 0) {
            [a, b] = [b, a % b];
        }
        return a;
    };

    let g = 0;
    for (const x of nums) {
        g = gcd(g, x);
        if (g === 1) return true;
    }
    return false;
};
Python 3O(n log M)

                return True
        return False
