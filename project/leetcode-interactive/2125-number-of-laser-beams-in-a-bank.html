2125. 银行中的
激光束数量

Number of Laser Beams in a Bank

一张由 0 与 1 组成的银行平面图。哪些设备之间能连接激光？先理解连接规则，再打开题解追踪每一行。

数组 / 数学 / 字符串 / 矩阵

01 / 问题

设备之间，何时出现一束光？

输入字符串数组 bank，代表一个 m × n 的网格，下标从 0 开始。bank[i][j] = '1' 表示该位置有安全设备，'0' 表示空位。

两个设备之间恰好有一条激光束，当且仅当：

  1. 它们处于不同行 r₁ < r₂。
  2. 两行之间的每一行都没有设备，即所有 r₁ < i < r₂ 的行均为全 0。

设备不必位于同一列。每束激光独立计数，交叉不会抵消或合并；同一行的设备之间不产生激光。返回激光束的总数。

接口：numberOfBeams(bank)；参数 bank: string[]，返回整数。

约束

  • m == bank.length
  • n == bank[i].length，所有行等长。
  • 1 ≤ m, n ≤ 500
  • bank[i][j] 只能为 '0' 或 '1'。

04 / 独立题解

准备好，再揭开思路

展开后可逐行观察激光连接，并查看证明与四种语言实现。

核心洞察：只记住上一条非空行

删除所有空行后，只有相邻两条非空行之间能连接。若两行分别有 a、b 个设备，每个上方设备都能连接每个下方设备，因此贡献是 a × b。

用 prev 记录上一条非空行的设备数；当前行数出 cur。当 cur > 0 时，累加 prev × cur 并令 prev = cur。当 cur = 0 时保留 prev。

激光扫描台

青色设备：正在扫描的行；橙色设备：它之前最近的非空行。实线为本步新增连接，暗线为已计入连接。演示输入限制为 12 × 12，便于辨认；提交代码支持官方上限。

完整过程

  1. 初始化 prev = 0、ans = 0。
  2. 扫描每行字符，统计该行的 '1' 数量 cur。
  3. 如果当前行为空，直接处理下一行，不能清零 prev。
  4. 否则将 prev × cur 加入答案，再更新 prev = cur。
  5. 遍历完成，返回 ans。
示例 1：行设备数 = [3, 0, 2, 1]
第 0 行：0 × 3 = 0，ans = 0，prev = 3
第 1 行：空行跳过，ans = 0，prev = 3
第 2 行：3 × 2 = 6，ans = 6，prev = 2
第 3 行：2 × 1 = 2，ans = 8，prev = 1

正确性证明

循环不变量：处理完前若干行后，prev 等于其中最后一条非空行的设备数（尚不存在时为 0）；ans 等于两端都在已处理行中的合法激光数。

初始时没有设备被处理，不变量成立。若新行为空，它既不能充当端点，也不会阻断连接，两个变量保持不变。若新行非空，能与它连接的已处理行只有最近一条非空行：更早的非空行会被这条行隔开。最近非空行与当前行之间全部为空，因此恰有 prev × cur 个合法设备对。加上这些连接并更新 prev 后，不变量仍成立。

每条连接仅在扫描到下端点所在行时计入一次，不重不漏。扫描结束后所有行均已处理，故答案正确。

边界与数值范围

全空、单行、只有一条非空行时答案均为 0。连续空行不会清除上一非空行。单列依然适用。最多有 499 对相邻非空行，每对至多贡献 500²，故答案不超过 124,750,000，Java/C++ 的 32 位有符号整数足够。

复杂度

时间 O(mn)：每个字符读一次。额外空间 O(1)：只保存计数器，不构造行计数数组。下方演示为了回退保存过程并绘制连线，其资源开销与提交算法不同。

替代方案

先收集每条非空行的设备数，再求相邻乘积之和：时间仍为 O(mn)，额外空间为 O(m)，便于单独检查计数序列。直接枚举任意设备对并检查中间行更繁琐，朴素最坏可达 O(m³n³)，无需使用。

常见错误

  • 空行时设置 prev = 0，导致跨空行的连接丢失。
  • 先更新 prev 再相乘，错误地计算当前行设备数的平方。
  • 只连接同列设备，漏掉斜线；或将交叉激光当作一条。
  • 让所有非空行两两相乘，忽略中间非空行的阻断。
  • 只处理原矩阵中物理相邻的行，遗漏隔着空行的有效连接。

面试追问

  • 输入按行流式到达？ 保留 prev 与累计值即可，每行处理完即可丢弃。
  • 列位置是否重要？ 本题只约束行，列位置不影响数量；若增加“同列”限制，应统计列交集，乘法不再适用。
  • 某一行设备数动态改变？ 在有序非空行集合中找前驱、后继，移除旧的局部贡献并加入新贡献；行从空变非空或反过来时，需要拆分或合并相邻关系。

Java

class Solution {
    public int numberOfBeams(String[] bank) {
        int prev = 0, ans = 0;
        for (String row : bank) {
            int cur = 0;
            for (int j = 0; j < row.length(); j++) {
                if (row.charAt(j) == '1') cur++;
            }
            if (cur > 0) {
                ans += prev * cur;
                prev = cur;
            }
        }
        return ans;
    }
}

class Solution:
