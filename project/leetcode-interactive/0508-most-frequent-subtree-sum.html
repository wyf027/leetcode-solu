01 / Problem

题目说明

给定二叉树根结点 root，返回出现频率最高的所有子树元素和。若多个和并列最高，可以按任意顺序返回。

结点的子树元素和，是以该结点为根的整棵子树中，所有结点值的总和，且包含该结点本身。

官方函数参数形式
findFrequentTreeSum(root: TreeNode) -> integer[]

约束

  • 树中结点数位于 [1, 104]。
  • -105 ≤ Node.val ≤ 105。
  • 返回值中的并列答案不要求固定顺序。

输入使用 LeetCode 的二叉树层序数组表示法。

Example 01

输入
root = [5,2,-3]
输出
[2,-3,4]
说明
三个子树和的频率均为 1，因此全部返回；顺序不限。

Core Insight

一次后序遍历，一本频次账

父结点的子树和依赖左右子树的和，因此必须先得到孩子的答案。每结算一个结点，就把它的子树和写入哈希表，并维护最高频次。

sum(node) = node.val + sum(node.left) + sum(node.right)
frequency[sum(node)] += 1

完整过程

  1. 以后序顺序处理左右孩子，再处理当前结点。
  2. 空结点贡献 0；当前和等于结点值加左右子树和。
  3. 在哈希表中增加该和的计数，并更新全局最高频次。
  4. 遍历结束后，收集计数等于最高频次的所有键。

为什么必须“先孩子、后父亲”

父结点需要左右子树的完整总和；先序或中序在访问父结点时，至少有一个孩子尚未结算。后序遍历天然满足数据依赖。

可视化中的“回传”就是递归返回值，也可以用显式栈模拟。

正确性证明

  1. 引理：对任意结点 u，过程返回的值等于以 u 为根的真实子树元素和。叶结点的左右贡献均为 0，结论成立；若左右孩子均返回正确子树和，将二者与 u.val 相加，恰好覆盖且仅覆盖该子树的全部结点。
  2. 计数完整性：遍历恰好访问每个非空结点一次，并在该次访问中登记一次由引理保证正确的子树和。因此哈希表对每个和的计数，正好等于它在所有结点子树中出现的次数。
  3. 结果正确性：最高频次始终是所有已登记计数的最大值。遍历结束后，筛选计数等于该最大值的键，得到且仅得到所有出现次数最多的子树元素和。

复杂度

  • 时间：O(n)，每个结点访问一次，最终至多扫描 n 个不同的和。
  • 空间：O(n)，频次表最坏保存 n 个键；递归版本另需 O(h) 调用栈。

边界处理

  • 单结点树：唯一结点值就是唯一答案。
  • 负数与零：必须把和当普通整数键，不可只处理正数。
  • 并列最高频：收集全部键，不能只保留一个。
  • 极深树：递归可能触及语言栈限制；显式栈版本更稳健。

四种语言完整代码

以下代码均遵循官方签名。Java 使用递归后序；JavaScript、Python 与 C++ 使用显式栈模拟后序，以覆盖深度接近结点数的退化树。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private final Map<Integer, Integer> frequency = new HashMap<>();
    private int maxFrequency = 0;

    public int[] findFrequentTreeSum(TreeNode root) {
        if (root == null) return new int[0];
        postorder(root);

        List<Integer> answer = new ArrayList<>();
        for (Map.Entry<Integer, Integer> entry : frequency.entrySet()) {
            if (entry.getValue() == maxFrequency) {
                answer.add(entry.getKey());
            }
        }

        int[] result = new int[answer.size()];
        for (int i = 0; i < answer.size(); i++) {
            result[i] = answer.get(i);
        }
        return result;
    }

    private int postorder(TreeNode node) {
        if (node == null) return 0;
        int sum = node.val + postorder(node.left) + postorder(node.right);
        int count = frequency.getOrDefault(sum, 0) + 1;
        frequency.put(sum, count);
        maxFrequency = Math.max(maxFrequency, count);
        return sum;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number[]}
 */
var findFrequentTreeSum = function(root) {
    if (root === null) return [];

    const frequency = new Map();
    const subtreeSum = new Map();
    const stack = [[root, false]];
    let maxFrequency = 0;

    while (stack.length > 0) {
        const [node, visited] = stack.pop();
        if (node === null) continue;

        if (!visited) {
            stack.push([node, true]);
            stack.push([node.right, false]);
            stack.push([node.left, false]);
            continue;
        }

        const leftSum = node.left === null ? 0 : subtreeSum.get(node.left);
        const rightSum = node.right === null ? 0 : subtreeSum.get(node.right);
        const sum = node.val + leftSum + rightSum;
        subtreeSum.set(node, sum);

        const count = (frequency.get(sum) || 0) + 1;
        frequency.set(sum, count);
        maxFrequency = Math.max(maxFrequency, count);
    }

    const answer = [];
    for (const [sum, count] of frequency) {
        if (count === maxFrequency) answer.push(sum);
    }
    return answer;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def findFrequentTreeSum(self, root: Optional[TreeNode]) -> List[int]:
        if root is None:
            return []

        frequency = {}
        subtree_sum = {}
        stack = [(root, False)]
        max_frequency = 0

        while stack:
            node, visited = stack.pop()
            if node is None:
                continue

            if not visited:
                stack.append((node, True))
                stack.append((node.right, False))
                stack.append((node.left, False))
                continue

            left_sum = 0 if node.left is None else subtree_sum[node.left]
            right_sum = 0 if node.right is None else subtree_sum[node.right]
            total = node.val + left_sum + right_sum
            subtree_sum[node] = total

            frequency[total] = frequency.get(total, 0) + 1
            max_frequency = max(max_frequency, frequency[total])

        return [
            total
            for total, count in frequency.items()
            if count == max_frequency
        ]
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<int> findFrequentTreeSum(TreeNode* root) {
        if (root == nullptr) return {};

        unordered_map<int, int> frequency;
        unordered_map<TreeNode*, int> subtreeSum;
        vector<pair<TreeNode*, bool>> stack = {{root, false}};
        int maxFrequency = 0;

        while (!stack.empty()) {
            auto [node, visited] = stack.back();
            stack.pop_back();
            if (node == nullptr) continue;

            if (!visited) {
                stack.push_back({node, true});
                stack.push_back({node->right, false});
                stack.push_back({node->left, false});
                continue;
            }

            int leftSum = node->left == nullptr ? 0 : subtreeSum[node->left];
            int rightSum = node->right == nullptr ? 0 : subtreeSum[node->right];
            int sum = node->val + leftSum + rightSum;
            subtreeSum[node] = sum;

            int count = ++frequency[sum];
            maxFrequency = max(maxFrequency, count);
        }

        vector<int> answer;
        for (const auto& [sum, count] : frequency) {
            if (count == maxFrequency) answer.push_back(sum);
        }
        return answer;
    }
};

替代方案

  • 两遍扫描：第一遍计算所有子树和并计数，第二遍求最高频再收集。结构直观，但一遍遍历配合实时维护最高频已经足够。
  • 递归与显式栈：两者时间复杂度相同。递归更简洁；显式栈避免极深树导致调用栈溢出。
  • 排序所有子树和：可通过排序后分组计数，但会把时间提升到 O(n log n)，不如哈希计数。

常见错误

  • 只统计叶结点，漏掉每个内部结点对应的子树。
  • 把“元素和最大”误读成“出现频次最高”。
  • 遇到并列频次时覆盖旧答案，而非保留全部。
  • 使用全局状态，却没有在每次调用前重新初始化。
  • 用错误的遍历顺序，在孩子的和尚未得到时计算父结点。

面试追问

Q1. 为什么不能只保存当前最高频的和？

可以同时维护候选集合，但某个和的计数增加后，仍需它之前的次数，因此完整频次表不可省。

Q2. 子树和会溢出 32 位整数吗？

当前约束下绝对值上界为 104 × 105 = 109，在有符号 32 位整数范围内。

Q3. 如果要求按升序返回呢？

收集候选后排序即可，额外耗时为 O(k log k)，其中 k 是并列答案数。

Q4. 如何支持动态修改结点值？

单次修改会影响该结点到根路径上的子树和。需撤销旧频次、更新路径并写入新频次；若频繁查询，可进一步维护频次的有序结构。
