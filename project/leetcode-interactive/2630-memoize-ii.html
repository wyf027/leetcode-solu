记忆函数 II Memoize II

让同一组参数只触发一次真实计算——关键是严格理解“同一”在 JavaScript 中意味着什么。

题号 2630Hard免费题官方语言：JavaScript / TypeScript

01 · Problem

题目描述

给定函数 fn，返回它的记忆化版本。对一组此前出现过的输入，包装后的函数不再调用 fn，而是直接返回第一次计算得到的缓存值。

函数可以接收任意数量、任意类型的参数。逐个参数使用 JavaScript 的 === 判断相同：两个内容一样但引用不同的对象并不相同；重复传入同一对象引用才相同。

函数形式： function memoize(fn) { return function (...args) { /* ... */ } }

数值参数复用

EXAMPLE 01
输入：
getInputs = () => [[2,2],[2,2],[1,2]]
fn = function (a, b) { return a + b; }
输出：
[{"val":4,"calls":1},{"val":4,"calls":1},{"val":3,"calls":2}]
说明：
第一次 (2,2) 计算 4；第二次直接取缓存；
(1,2) 是新参数，fn 累计调用 2 次。

不同对象引用

EXAMPLE 02
输入：
getInputs = () => [[{},{}],[{},{}],[{},{}]]
fn = function (a, b) { return ({...a, ...b}); }
输出：
[{"val":{},"calls":1},{"val":{},"calls":2},{"val":{},"calls":3}]
说明：
每次创建的空对象引用都不同，因此三次均未命中。

同一对象引用

EXAMPLE 03
输入：
getInputs = () => { const o = {}; return [[o,o],[o,o],[o,o]]; }
fn = function (a, b) { return ({...a, ...b}); }
输出：
[{"val":{},"calls":1},{"val":{},"calls":1},{"val":{},"calls":1}]
说明：
三次都传入同一引用 o，后两次命中缓存。

约束

  • 1 <= inputs.length <= 105
  • 0 <= inputs.flat().length <= 105
  • inputs[i][j] != NaN

参数列表可以为空；参数总量上限要求方案按参数个数近似线性推进。

04 · Solution

准备好再揭晓

题解独立收起，避免在理解题意之前直接看到实现。

题解：用 Map 组成参数前缀树

核心洞察：不要序列化参数。让每一层 Map 对应一个参数位置，参数本身就是键；一组参数沿着多层 Map 形成一条唯一路径，末端保存计算结果。

完整过程

  1. 创建根 Map，它代表尚未读取任何参数的空前缀。
  2. 调用包装函数时，从根开始逐个读取参数；当前层没有对应键就创建下一层 Map。
  3. 全部参数走完后到达末端节点。若该节点已有专用结果键，直接返回缓存。
  4. 否则使用原参数调用 fn，把结果写到末端，再返回它。

为什么不能 JSON.stringify

对象的序列化文本相同，不代表引用相同；键顺序、循环引用、函数、Symbol 等也会让序列化不可靠。Map 原生支持对象引用键，恰好匹配题目的身份判断。

专用结果键

用闭包内不可见的 Symbol 标记结果是否存在，所以即使结果本身是 undefined，也不会被误判成未缓存。

正确性证明

  1. 路径唯一性：每层 Map 用第 i 个参数作键。两次调用仅当每个位置的参数均按题意相同，才会走过完全相同的路径。
  2. 首次调用：某条完整路径的末端没有结果标记时，算法调用一次 fn 并保存其返回值，所以该路径得到正确结果。
  3. 后续调用：相同参数必然抵达同一末端并读到已保存值，不会再次调用 fn；不同参数至少在一层分叉，不会误取另一组结果。
  4. 结论：对所有调用按发生顺序归纳，包装函数返回值与首次真实计算一致，且每组相同输入最多调用 fn 一次。

复杂度

单次时间：平均 O(k)，k 为参数个数。

空间：O(P)，P 为所有不同参数序列产生的前缀节点总数；最坏可写作 O(调用数 × k)。

边界情况

  • 零参数调用停在根节点。
  • 返回 undefined 仍需记录“已缓存”。
  • 相同内容的新对象不命中。
  • 同一对象引用会命中。
  • 不同参数个数形成不同末端。

替代方案

线性扫描历史参数：语义直接，但每次可能扫描全部记录，最坏 O(nk)。

字符串键：代码短，却无法保持对象引用语义，因此不适用于本题。

四语言完整代码

官方提交语言只有 JavaScript / TypeScript。Java、Python、C++ 版本为本地语义参考：用值表示 JS 原始值、用身份表示对象；它们不是 LeetCode 本题可直接提交的官方签名。

JavaScript · 官方可提交
/**
 * @param {Function} fn
 * @return {Function}
 */
function memoize(fn) {
  const root = new Map();
  const VALUE = Symbol("cached value");

  return function (...args) {
    let node = root;
    for (const arg of args) {
      if (!node.has(arg)) node.set(arg, new Map());
      node = node.get(arg);
    }

    if (node.has(VALUE)) return node.get(VALUE);
    const result = fn.apply(this, args);
    node.set(VALUE, result);
    return result;
  };
}
Java · 本地语义参考
以 List<Object> 表示参数；字符串、数字、布尔值按值比较，其他对象按引用比较。
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Objects;
import java.util.function.Function;

public final class MemoizeII {
  private static final class Key {
    private final Object value;
    private final boolean primitive;

    Key(Object value) {
      this.value = value;
      this.primitive = value == null
          || value instanceof String
          || value instanceof Number
          || value instanceof Boolean
          || value instanceof Character;
    }

    @Override
    public boolean equals(Object other) {
      if (!(other instanceof Key key) || primitive != key.primitive) return false;
      if (!primitive) return value == key.value;
      if (value instanceof Number && key.value instanceof Number) {
        double a = ((Number) value).doubleValue();
        double b = ((Number) key.value).doubleValue();
        return a == b;
      }
      return Objects.equals(value, key.value);
    }

    @Override
    public int hashCode() {
      if (!primitive) return System.identityHashCode(value);
      if (value instanceof Number) {
        double number = ((Number) value).doubleValue();
        return Double.hashCode(number == 0.0 ? 0.0 : number);
      }
      return Objects.hashCode(value);
    }
  }

  private static final class Node {
    final Map<Key, Node> children = new HashMap<>();
    boolean hasValue;
    Object value;
  }

  public static Function<List<Object>, Object> memoize(
      Function<List<Object>, Object> fn) {
    Node root = new Node();
    return args -> {
      Node node = root;
      for (Object arg : args) {
        node = node.children.computeIfAbsent(new Key(arg), ignored -> new Node());
      }
      if (!node.hasValue) {
        node.value = fn.apply(args);
        node.hasValue = true;
      }
      return node.value;
    };
  }
}
Python · 本地语义参考
原始值按“类型 + 值”比较，对象键保留强引用并按身份比较。
class IdentityKey:
    __slots__ = ("value",)

    def __init__(self, value):
        self.value = value

    def __hash__(self):
        return id(self.value)

    def __eq__(self, other):
        return isinstance(other, IdentityKey) and self.value is other.value


def js_key(value):
    if value is None:
        return ("null", None)
    if isinstance(value, bool):
        return ("boolean", value)
    if isinstance(value, (int, float)):
        return ("number", float(value))
    if isinstance(value, str):
        return ("string", value)
    return ("object", IdentityKey(value))


class Node:
    __slots__ = ("children", "has_value", "value")

    def __init__(self):
        self.children = {}
        self.has_value = False
        self.value = None


def memoize(fn):
    root = Node()

    def memoized(*args):
        node = root
        for arg in args:
            node = node.children.setdefault(js_key(arg), Node())
        if not node.has_value:
            node.value = fn(*args)
            node.has_value = True
        return node.value

    return memoized
C++ · 本地语义参考
JsValue 用 variant 表示原始值，用 shared_ptr<void> 表示按身份比较的对象。
#include <cstddef>
#include <functional>
#include <memory>
#include <optional>
#include <string>
#include <type_traits>
#include <unordered_map>
#include <variant>
#include <vector>

using Object = std::shared_ptr<void>;
using JsValue = std::variant<std::nullptr_t, double, bool, std::string, Object>;

struct JsHash {
  std::size_t operator()(const JsValue& value) const {
    std::size_t hash = std::visit([](const auto& item) -> std::size_t {
      using T = std::decay_t<decltype(item)>;
      if constexpr (std::is_same_v<T, std::nullptr_t>) return 0;
      else if constexpr (std::is_same_v<T, Object>)
        return std::hash<const void*>{}(item.get());
      else return std::hash<T>{}(item);
    }, value);
    return hash ^ (value.index() + 0x9e3779b9 + (hash << 6) + (hash >> 2));
  }
};

class Memoizer {
 public:
  using Args = std::vector<JsValue>;
  using Fn = std::function<JsValue(const Args&)>;

  explicit Memoizer(Fn fn) : fn_(std::move(fn)) {}

  JsValue operator()(const Args& args) {
    Node* node = &root_;
    for (const JsValue& arg : args) {
      auto& child = node->children[arg];
      if (!child) child = std::make_unique<Node>();
      node = child.get();
    }
    if (!node->value) node->value = fn_(args);
    return *node->value;
  }

 private:
  struct Node {
    std::unordered_map<JsValue, std::unique_ptr<Node>, JsHash> children;
    std::optional<JsValue> value;
  };

  Fn fn_;
  Node root_;
};

面试追问

缓存能否自动回收对象键？

这份实现不能：Map 会持有对象强引用。若业务要求回收，需要重设数据结构或提供显式清理策略；多参数混合 WeakMap 会更复杂。

异步函数并发调用怎么办？

首次调用时立即缓存 Promise，可让并发的相同参数共享同一个进行中的请求；若失败后允许重试，应在 reject 时删除该路径的缓存。

如何支持 LRU 或过期时间？

末端除结果外再保存时间和访问顺序，并在读取时检查；但这属于额外产品语义，不是本题要求。

常见错误

  • 用 JSON.stringify 作为键，破坏对象身份语义。
  • 用普通对象作缓存，键会被强制转成字符串。
  • 用 value === undefined 判断是否存在，导致 undefined 被重复计算。
  • 只按单个参数建 Map，无法区分多参数组合。
  • 把参数数组本身作为 Map 键；每次 rest 参数都会创建新数组，永远无法命中。
