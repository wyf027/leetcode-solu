Full solution

计数 + 余数修正的贪心

核心洞察

一个十进制整数能被 3 整除，当且仅当它的各位数字之和能被 3 整除。数字的排列不会改变数位和，所以问题变成：删除尽量少、且尽量小的数字，使剩余数字之和对 3 的余数为 0；最后降序拼接。

完整过程

  1. 统计 0–9 的出现次数，同时计算全部数字之和 sum。
  2. 若 sum % 3 == 1，优先删除一个余数为 1 的最小数字；若不存在，则删除两个余数为 2 的最小数字。
  3. 若 sum % 3 == 2，对称地优先删除一个余数为 2 的最小数字；否则删除两个余数为 1 的最小数字。
  4. 按 9 到 0 输出剩余数字。若没有剩余数字，返回空串；若最大位是 0，说明全是 0，只返回 "0"。
为什么“少删”优先于“删得小”？ 位数更多的非负十进制数一定大于位数更少的数（排除统一归一化为单个 0 的情况）。因此先保住长度；删除数量相同时，再删除更小的数字，保留更大的高位。

正确性证明

引理 1：修正充分

数位和余数只可能为 0、1、2。余数为 1 时，删除一个余 1 或两个余 2 即可归零；余数为 2 时完全对称。因此候选修正覆盖所有最少删除方案。

引理 2：删除最优

算法先尝试删除一个数字，只有不可行时才删除两个，故删除数量最少。固定删除数量与余数类别后，删除可选数字中最小者，会让保留数字的降序序列字典序最大。

定理：结果最大

由引理 1，剩余数位和可被 3 整除；由引理 2，剩余位数最多且同长度下数位集合最优。将其降序排列得到该集合能形成的最大数，因此最终答案全局最大。

边界情况

  • 无法保留任何可被 3 整除的数字：返回空字符串。
  • 剩余数字全部为 0：必须返回 "0"，而不是多个零。
  • 本身数位和已整除 3：不删除任何数字。
  • 输入规模达 10^4：用长度 10 的计数数组即可，无需通用排序。

复杂度

设输入长度为 n。统计与输出各遍历一次，时间复杂度 O(n)；计数数组为固定大小，除返回字符串外的额外空间复杂度 O(1)。

替代方案

可以做三状态动态规划：维护余数 0/1/2 下的最佳字符串，每读入一个数字就更新。但字符串比较和复制更重；也可以先排序再分组，复杂度为 O(n log n)。本题数字值域只有 10，计数贪心更直接。

面试追问

  • 为什么十进制数模 3 等于数位和模 3？因为 10 ≡ 1 (mod 3)。
  • 如果目标改为 9 的倍数，方法如何变化？整除判定仍适用，但余数修正不再保证至多删除两个数字，需要更一般的选择策略。
  • 如果每个数字带删除成本，如何处理？“少删”不再代表最优，可按余数设计最小成本 DP。

常见错误

  • 余数为 1 时只尝试删除余 1 的数字，漏掉删除两个余 2 的方案。
  • 删除最大的候选数字，导致同位数答案变小。
  • 直接把结果解析成整数，发生溢出。
  • 忘记把多个前导零归一化成单个 "0"。

class Solution {
    public String largestMultipleOfThree(int[] digits) {
        int[] count = new int[10];
        int sum = 0;
        for (int digit : digits) {
            count[digit]++;
            sum += digit;
        }

        int remainder = sum % 3;
        if (remainder == 1) {
            if (!remove(count, 1, 1)) remove(count, 2, 2);
        } else if (remainder == 2) {
            if (!remove(count, 2, 1)) remove(count, 1, 2);
        }

        StringBuilder answer = new StringBuilder();
        for (int digit = 9; digit >= 0; digit--) {
            for (int i = 0; i < count[digit]; i++) answer.append(digit);
        }
        if (answer.length() == 0) return "";
        return answer.charAt(0) == '0' ? "0" : answer.toString();
    }

    private boolean remove(int[] count, int remainder, int amount) {
        int[] picked = new int[amount];
        int size = 0;
        for (int digit = 0; digit <= 9 && size < amount; digit++) {
            if (digit % 3 != remainder) continue;
            for (int k = 0; k < count[digit] && size < amount; k++) {
                picked[size++] = digit;
            }
        }
        if (size < amount) return false;
        for (int digit : picked) count[digit]--;
        return true;
    }
}

/**
 * @param {number[]} digits
 * @return {string}

var largestMultipleOfThree = function(digits) {
    const count = Array(10).fill(0);
    let sum = 0;
    for (const digit of digits) {
        count[digit]++;
        sum += digit;
    }

    const remove = (remainder, amount) => {
        const picked = [];
        for (let digit = 0; digit <= 9 && picked.length < amount; digit++) {
            if (digit % 3 !== remainder) continue;
            for (let k = 0; k < count[digit] && picked.length < amount; k++) {
                picked.push(digit);
            }
        }
        if (picked.length < amount) return false;
        for (const digit of picked) count[digit]--;
        return true;
    };

    const remainder = sum % 3;
    if (remainder === 1) {
        if (!remove(1, 1)) remove(2, 2);
    } else if (remainder === 2) {
        if (!remove(2, 1)) remove(1, 2);
    }

    let answer = "";
    for (let digit = 9; digit >= 0; digit--) {
        answer += String(digit).repeat(count[digit]);
    }
    if (answer === "") return "";
    return answer[0] === "0" ? "0" : answer;
};
Python 3官方签名
from typing import List

class Solution:
    def largestMultipleOfThree(self, digits: List[int]) -> str:
        count = [0] * 10
        total = 0
        for digit in digits:
            count[digit] += 1
            total += digit

        def remove(remainder: int, amount: int) -> bool:
            picked = []
            for digit in range(10):
                if digit % 3 != remainder:
                    continue
                take = min(count[digit], amount - len(picked))
                picked.extend([digit] * take)
                if len(picked) == amount:
                    break
            if len(picked) < amount:
                return False
            for digit in picked:
                count[digit] -= 1
            return True

        remainder = total % 3
        if remainder == 1:
            if not remove(1, 1):
                remove(2, 2)
        elif remainder == 2:
            if not remove(2, 1):
                remove(1, 2)

        answer = ''.join(str(d) * count[d] for d in range(9, -1, -1))
        if not answer:
            return ''
        return '0' if answer[0] == '0' else answer
C++官方签名
class Solution {
public:
    string largestMultipleOfThree(vector<int>& digits) {
        array<int, 10> count{};
        int sum = 0;
        for (int digit : digits) {
            ++count[digit];
            sum += digit;
        }

        auto remove = [&](int remainder, int amount) {
            vector<int> picked;
            for (int digit = 0; digit <= 9 && (int)picked.size() < amount; ++digit) {
                if (digit % 3 != remainder) continue;
                for (int k = 0; k < count[digit] && (int)picked.size() < amount; ++k) {
                    picked.push_back(digit);
                }
            }
            if ((int)picked.size() < amount) return false;
            for (int digit : picked) --count[digit];
            return true;
        };

        int remainder = sum % 3;
        if (remainder == 1) {
            if (!remove(1, 1)) remove(2, 2);
        } else if (remainder == 2) {
            if (!remove(2, 1)) remove(1, 2);
        }

        string answer;
        for (int digit = 9; digit >= 0; --digit) {
            answer.append(count[digit], char('0' + digit));
        }
        if (answer.empty()) return "";
        return answer[0] == '0' ? "0" : answer;
    }
};
