无限集中的最小数字

Smallest Number in Infinite Set

从所有正整数出发：取走最小值，再把数字放回。试着观察，每一次操作究竟改变了什么。

官方题目 ↗

01 / 题目与接口

初始集合包含每个正整数：{1, 2, 3, …}。实现一个支持下列操作的类，同一个数字在集合中最多出现一次。

  • SmallestInfiniteSet()：构造一个包含所有正整数的集合。
  • int popSmallest()：取出当前最小的数，将它从集合中移除并返回。
  • void addBack(int num)：把 num 放回集合；如果它本来就在集合里，集合保持不变。

先自己想一想：集合永远有数可取，但是否真的需要存下每个正整数？题解在页面底部，默认收起。

约束

  • 1 ≤ num ≤ 1000。
  • popSmallest 与 addBack 两种方法合计最多调用 1000 次。

官方示例（完整操作名与参数）

参数 = [[], [2], [], [], [], [1], [], [], []]
输出 = [null, null, 1, 2, 3, null, 1, 4, 5]

04 / 独立题解




核心洞察：一段连续尾部 + 一小袋放回的数


用 next 表示从未被弹出的最小整数，则 next、next+1、… 全部还在。小于 next 的整数中，只有已经放回且尚未再次弹出的那些还在集合中，用去重集合 back 保存它们。


S = back ∪ {next, next+1, …}，且 back 中的每个数都严格小于 next。本页四种语言统一采用“指针 + 哈希集合扫描最小值”，适合最多 1000 次操作的规模。


当前回放的内部表示
上方数轴展示 S；这里把相同状态压缩成有限的 back 和无限尾部。返回上方切换步骤即可观察表示如何改变。


完整过程
  1. 初始化 next = 1、back 为空。不分配一个无限数组。
  2. 放回 num：若 num ≥ next，它已经在连续尾部，不做操作；否则插入 back。集合自然去重。
  3. 取最小值：back 非空时，扫描出其中最小值，删除并返回它，next 保持不变。
  4. back 为空时，返回 next，然后把 next 加一。


官方示例中，前三次弹出后 next = 4；放回 1 得到 back = {1}；再次弹出 1 后 back 为空、next 仍是 4，后续才依次返回 4、5。


正确性说明
用归纳法维护上述集合表示。初始 back 为空、next = 1，表示的正是所有正整数。放回 num ≥ next 时 num 已存在；num < next 时，向 back 插入恰好恢复该数，重复插入没有影响。弹出时，若 back 非空，其所有元素都小于尾部任意元素，所以删除 back 的最小值就是删除 S 的最小值；若 back 为空，S 的最小值为 next，将指针加一恰好移除它。因此每次操作都保持表示成立，返回值符合要求。


边界与复杂度
  • 集合不会耗尽；空的是 back，不是整个无限集合。
  • 重复放回、放回 num = next、放回从未取走的大数均不会产生多余副本。
  • 令 k 为 back 当前大小：弹出在 back 非空时需 O(k) 扫描，空时 O(1)；放回期望 O(1)，空间 O(k)。初始化 O(1)。
  • 对 Q 次操作，总体期望上界 O(Q²)，空间 O(Q)；哈希操作按通常平均模型计，单次插入在扩容或碰撞时可能线性。这是有意选取的简单实现；规模增大时升级为堆或有序集合。


替代方案
  • 最小堆 + 哈希集合 + 指针：堆负责最小值，哈希集合防止重复放回。弹出与有效插入 O(log(k+1))，空间 O(k)。弹出后必须同步删除哈希集合中的记录。
  • 有序集合 + 指针：Java TreeSet、C++ set 可同时提供去重与有序性，插入/删除为 O(log(k+1))，不再扫描。
  • 约束内有限布尔表：合计只有 1000 次操作，第 t 次弹出值不超过 t，因此记录 1～1000 的状态足以覆盖当前约束；每次扫描最小可用数为 O(1000)。这依赖调用上限，不是通用无限集表示。


常见错误
  • 把放回的数存进普通数组却不去重，导致同一个整数被额外弹出。
  • 把 num ≥ next 也存到 back，破坏两部分互不重叠的约束。
  • 从 back 弹出后也增加 next，会把尾部的数字跳过去。
  • 仅维护一个最小值并在放回时重置它，会丢失哪些数字已被移除的信息。
  • 使用哈希集合，却声称取最小值是 O(log k)；集合本身并不排序。

Java
import java.util.HashSet;
import java.util.Set;

class SmallestInfiniteSet {
    private int next = 1;
    private final Set<Integer> back = new HashSet<>();

    public SmallestInfiniteSet() {}

    public int popSmallest() {
        if (back.isEmpty()) return next++;
        int smallest = Integer.MAX_VALUE;
        for (int x : back) smallest = Math.min(smallest, x);
        back.remove(smallest);
        return smallest;
    }

    public void addBack(int num) {
        if (num < next) back.add(num);
    }
}

var SmallestInfiniteSet = function() {
    this.next = 1;
    this.back = new Set();
};

SmallestInfiniteSet.prototype.popSmallest = function() {
    if (this.back.size === 0) return this.next++;
    let smallest = Infinity;
    for (const x of this.back) smallest = Math.min(smallest, x);
    this.back.delete(smallest);
    return smallest;
};

SmallestInfiniteSet.prototype.addBack = function(num) {
    if (num < this.next) this.back.add(num);
};


Python
class SmallestInfiniteSet:
    def __init__(self):
        self.next = 1
        self.back = set()

    def popSmallest(self) -> int:
        if self.back:
            smallest = min(self.back)
            self.back.remove(smallest)
            return smallest
        smallest = self.next
        self.next += 1
        return smallest

    def addBack(self, num: int) -> None:
        if num < self.next:
            self.back.add(num)


C++
#include <unordered_set>
#include <algorithm>

class SmallestInfiniteSet {
    int next = 1;
    std::unordered_set<int> back;
public:
    SmallestInfiniteSet() = default;

    int popSmallest() {
        if (back.empty()) return next++;
        int smallest = *std::min_element(back.begin(), back.end());
        back.erase(smallest);
        return smallest;
    }

    void addBack(int num) {
        if (num < next) back.insert(num);
    }
};


面试追问
  • 操作次数扩大到百万级？保留无限尾部指针，把扫描集合替换为最小堆与去重集合或有序集合。
  • 为什么不用把所有正整数压入堆？无限集合不能穷举存储，连续尾部可以由一个边界表示。
  • 允许删除任意整数呢？尾部不再始终连续，必须另外记录缺口或维护区间，现有不变量需要重设计。
  • 支持并发操作呢？指针与 back 的读写必须作为同一次原子操作，使用锁或其他同步机制维护不变量。
