LeetCode 916 · MEDIUM

单词子集
Word Subsets

把一组“逐项要求”压缩成一张字母需求表，再用它筛选所有候选单词。

题目

给定两个字符串数组 words1 和 words2。若字符串 b 中每个字母在 a 中出现的次数都不少于它在 b 中的次数，则称 b 是 a 的子集。

若 words2 中每个单词都是 words1 中某个单词 a 的子集，则 a 是通用单词。返回 words1 中全部通用单词，顺序不限。

注意重复次数："wrr" 是 "warrior" 的子集，却不是 "world" 的子集。

约束

  • 1 ≤ words1.length, words2.length ≤ 10⁴
  • 1 ≤ words1[i].length, words2[i].length ≤ 10
  • 所有单词仅含小写英文字母
  • words1 中字符串互不相同

数组 哈希表 字符串

官方示例

示例 1
输入：words1 = ["amazon","apple","facebook","google","leetcode"], words2 = ["e","o"]
输出：["facebook","google","leetcode"]
示例 2
输入：words1 = ["amazon","apple","facebook","google","leetcode"], words2 = ["lc","eo"]
输出：["leetcode"]
示例 3
输入：words1 = ["acaac","cccbb","aacbb","caacc","bcbbb"], words2 = ["c","cc","b"]
输出：["cccbb"]

准备好看完整题解了吗？

题解独立收起，先思考：多个 words2 是否真的需要被逐一比较？

核心洞察

对每个字母，只需记录它在所有 words2 单词中的最大出现次数。这张长度为 26 的需求表等价于全部条件：候选单词覆盖它，就一定同时覆盖每个 words2 单词。

完整过程

  1. 建立 need[26]，初始为 0。
  2. 统计每个 b ∈ words2 的字母频次，并用逐位最大值更新 need。
  3. 逐个统计 a ∈ words1；若每个位置都有 countA[i] ≥ need[i]，将其加入答案。

正确性证明

充分性：若候选 a 覆盖 need，对任意 b 和字母 x，都有 count(a,x) ≥ need[x] ≥ count(b,x)，所以每个 b 都是 a 的子集。

必要性：若 a 是通用单词，对每个字母 x，取在 words2 中该字母次数最大的单词 b；因为 b 是 a 的子集，必有 count(a,x) ≥ need[x]。故判定恰好等价。

边界与复杂度

  • 重复字母必须按次数比较，不能只用集合。
  • 某字母未出现在 words2 时需求为 0。
  • 设输入字符总数为 S，时间复杂度 O(S + 26·|words1|)，额外空间 O(26)（不计答案）。

替代方案

朴素做法会对每个 words1 单词逐一匹配全部 words2，产生约 O(|words1|·|words2|·L) 的工作。把条件合并为最大频次数组，可消除笛卡尔积式比较。

面试追问

  • 若字符集不是 26 个小写字母，可将数组替换为哈希表。
  • 若 words2 动态增加，可维护逐字母最大值；删除则需为每个字母维护频次计数或堆。
  • 能否提前失败？统计候选后，一旦发现某字母不足即可停止比较。

常见错误

  • 把所有 words2 的频次相加；实际应取逐字母最大值。
  • 忽略重复字母，例如需求 "cc" 不能由一个 c 满足。
  • 复用频次数组但忘记清零。

Java

完整可提交代码
import java.util.*;

class Solution {
    public List<String> wordSubsets(String[] words1, String[] words2) {
        int[] need = new int[26];
        for (String b : words2) {
            int[] count = frequency(b);
            for (int i = 0; i < 26; i++) need[i] = Math.max(need[i], count[i]);
        }
        List<String> answer = new ArrayList<>();
        for (String a : words1) {
            int[] count = frequency(a);
            boolean ok = true;
            for (int i = 0; i < 26; i++) if (count[i] < need[i]) { ok = false; break; }
            if (ok) answer.add(a);
        }
        return answer;
    }
    private int[] frequency(String s) {
        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c - 'a']++;
        return count;
    }
}

JavaScript

/**
 * @param {string[]} words1
 * @param {string[]} words2
 * @return {string[]}
 */
var wordSubsets = function(words1, words2) {
    const need = Array(26).fill(0);
    const frequency = word => {
        const count = Array(26).fill(0);
        for (const ch of word) count[ch.charCodeAt(0) - 97]++;
        return count;
    };
    for (const word of words2) {
        const count = frequency(word);
        for (let i = 0; i < 26; i++) need[i] = Math.max(need[i], count[i]);
    }
    return words1.filter(word => {
        const count = frequency(word);
        return need.every((required, i) => count[i] >= required);
    });
};

Python

完整可提交代码
from typing import List

class Solution:
    def wordSubsets(self, words1: List[str], words2: List[str]) -> List[str]:
        need = [0] * 26
        for word in words2:
            count = [0] * 26
            for ch in word:
                count[ord(ch) - ord('a')] += 1
            for i in range(26):
                need[i] = max(need[i], count[i])

        answer = []
        for word in words1:
            count = [0] * 26
            for ch in word:
                count[ord(ch) - ord('a')] += 1
            if all(count[i] >= need[i] for i in range(26)):
                answer.append(word)
        return answer

#include <array>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> wordSubsets(vector<string>& words1, vector<string>& words2) {
        array<int, 26> need{};
        for (const string& b : words2) {
            array<int, 26> count{};
            for (char c : b) count[c - 'a']++;
            for (int i = 0; i < 26; i++) need[i] = max(need[i], count[i]);
        }
        vector<string> answer;
        for (const string& a : words1) {
            array<int, 26> count{};
            for (char c : a) count[c - 'a']++;
            bool ok = true;
            for (int i = 0; i < 26; i++) if (count[i] < need[i]) { ok = false; break; }
            if (ok) answer.push_back(a);
        }
        return answer;
    }
};
