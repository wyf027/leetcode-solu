Solution

完整题解：模拟竖式加法

∑
核心洞察字符串不能整体转成整数，但每个字符都能安全地转成一位数字。用两个指针从末尾向前扫描，把“当前两位 + 上一列进位”拆成一连串常数规模的小加法。

完整过程

  1. 令 i、j 分别指向两个字符串的末尾，进位 carry = 0。
  2. 只要任一指针仍有效，读取对应数字；越界的一侧按 0 处理。
  3. 计算 sum = x + y + carry，当前位为 sum % 10，新进位为 sum / 10 的整数部分。
  4. 由于计算顺序是从低位到高位，先逆序收集答案，最后翻转。
  5. 循环后若 carry ≠ 0，把它补到最高位。

正确性说明

  1. 局部正确：第 k 列使用两个输入的第 k 位及低一列产生的进位，因此写出的 sum % 10 正是该列结果。
  2. 进位正确：单列最大为 9 + 9 + 1 = 19，所以 ⌊sum / 10⌋ 恰好是传给下一列的 0 或 1。
  3. 覆盖完整：指针扫描了两个字符串的全部数字，并在最后处理剩余进位，所以没有遗漏最高位。
  4. 结论：所有列从低到高均正确，拼接并翻转后得到的字符串就是两数之和。

边界情况

  • 两个输入都是 "0"。
  • 两个字符串长度不同，较短的一侧提前越界。
  • 最高位仍产生进位，如 "9999" + "1"。
  • 长度达到 10⁴，不能依赖普通数值类型。
  • 题目保证无非法字符和多余前导零，无需额外规范化。

复杂度

设 n = num1.length，m = num2.length。

时间 O(max(n, m))
额外空间 O(max(n, m))

结果本身需要线性空间；除输出缓冲区外，只使用指针、进位等常数状态。

替代方案

  • 头部插入：每次把新数字插到字符串开头，逻辑直观，但多次搬移字符可能退化为平方时间。
  • 递归：可以按列递归处理，但 10⁴ 层可能造成栈溢出。
  • 大整数库：最短但被题目明确禁止，也绕开了考察点。

面试追问与常见错误

  • 追问：如何扩展到任意进制？把 10 替换为基数，并增加字符与数值的映射。
  • 追问：如何实现字符串乘法？使用每对数位的乘积累加到对应位置。
  • 错误：循环只写 i ≥ 0 && j ≥ 0，遗漏较长字符串的高位。
  • 错误：循环结束后忘记追加最终进位。
  • 错误：直接用语言数值类型转换，遇到超长输入或 JavaScript 精度边界就失真。

class Solution {
    public String addStrings(String num1, String num2) {
        int i = num1.length() - 1;
        int j = num2.length() - 1;
        int carry = 0;
        StringBuilder reversed = new StringBuilder();

        while (i >= 0 || j >= 0) {
            int x = i >= 0 ? num1.charAt(i) - '0' : 0;
            int y = j >= 0 ? num2.charAt(j) - '0' : 0;
            int sum = x + y + carry;

            reversed.append(sum % 10);
            carry = sum / 10;
            i--;
            j--;
        }

        if (carry != 0) {
            reversed.append(carry);
        }
        return reversed.reverse().toString();
    }
}

/**
 * @param {string} num1
 * @param {string} num2
 * @return {string}
 */
var addStrings = function(num1, num2) {
    let i = num1.length - 1;
    let j = num2.length - 1;
    let carry = 0;
    const reversed = [];

    while (i >= 0 || j >= 0) {
        const x = i >= 0 ? num1.charCodeAt(i) - 48 : 0;
        const y = j >= 0 ? num2.charCodeAt(j) - 48 : 0;
        const sum = x + y + carry;

        reversed.push(String(sum % 10));
        carry = Math.floor(sum / 10);
        i--;
        j--;
    }

    if (carry !== 0) {
        reversed.push(String(carry));
    }
    return reversed.reverse().join("");
};

class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        i = len(num1) - 1
        j = len(num2) - 1
        carry = 0
        reversed_digits = []

        while i >= 0 or j >= 0:
            x = ord(num1[i]) - ord("0") if i >= 0 else 0
            y = ord(num2[j]) - ord("0") if j >= 0 else 0
            total = x + y + carry

            reversed_digits.append(str(total % 10))
            carry = total // 10
            i -= 1
            j -= 1

        if carry:
            reversed_digits.append(str(carry))
        return "".join(reversed(reversed_digits))

class Solution {
public:
    string addStrings(string num1, string num2) {
        int i = static_cast<int>(num1.size()) - 1;
        int j = static_cast<int>(num2.size()) - 1;
        int carry = 0;
        string reversed;

        while (i >= 0 || j >= 0) {
            int x = i >= 0 ? num1[i] - '0' : 0;
            int y = j >= 0 ? num2[j] - '0' : 0;
            int sum = x + y + carry;

            reversed.push_back(static_cast<char>('0' + sum % 10));
            carry = sum / 10;
            --i;
            --j;
        }

        if (carry != 0) {
            reversed.push_back(static_cast<char>('0' + carry));
        }
        reverse(reversed.begin(), reversed.end());
        return reversed;
    }
};
