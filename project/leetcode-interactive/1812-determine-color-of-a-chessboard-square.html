判断国际象棋棋盘中
一个格子的颜色

Determine Color of a Chessboard Square

观察棋盘，先做判断，再展开推导。

01 / 题目

给定字符串 coordinates，代表 8 × 8 棋盘上的一个有效格子。第一位是列字母，第二位是行数字。列从左到右为 a 到 h，行从下到上为 1 到 8；左下角 a1 为黑色，相邻格子颜色交替。

格子为白色时返回 true，黑色时返回 false。

官方示例

输入：coordinates = "a1"
输出：false
解释：a1 为黑色。

输入：coordinates = "h3"
输出：true
解释：h3 为白色。

输入：coordinates = "c7"
输出：false

约束与签名

  • coordinates.length == 2
  • 'a' <= coordinates[0] <= 'h'
  • '1' <= coordinates[1] <= '8'
  • 坐标有效，字母在前，数字在后。

squareIsWhite(coordinates)
参数：string；返回：boolean。

04 / 独立题解

准备好后再展开规律与代码。

核心洞察：坐标和的奇偶性

将 a…h 映射为 1…8，行号也使用 1…8。相邻格子颜色翻转，同时坐标和的奇偶性翻转。a1 的和为 2，是黑色，因此和为奇数时白色，为偶数时黑色。

完整过程

  1. 列号 x = 首字符减去 'a' 再加 1。
  2. 行号 y = 第二个字符对应的数字。
  3. 返回 (x + y) % 2 == 1。

h3 → x = 8，y = 3，和为 11，返回 true。交互中先右移 7 步再上移 2 步，总共翻转 9 次颜色。

正确性证明

从黑色起点 a1 到 (x, y)，先向右再向上共需 (x − 1) + (y − 1) = x + y − 2 步。每步翻转一次颜色，所以奇数步到白色，偶数步到黑色。减去 2 不改变奇偶性，故 x + y 为奇数恰好等价于目标是白色，算法正确。

边界与复杂度

a1 移动 0 步，返回 false；h8 移动 14 步，返回 false；a8、h1 均移动 7 步，返回 true。题目保证合法输入；提交代码无需处理空串、大写或越界坐标。只读取两个字符并做常数次运算，时间 O(1)，额外空间 O(1)。可视化模拟用于解释，提交代码无需走格子。

替代方案

比较列号与行号的奇偶性是否不同，即 x % 2 != y % 2，同样是 O(1)。逐格模拟也能完成，但泛化到大棋盘时需 O(x + y) 次移动；不必创建棋盘数组。

Java

class Solution {
    public boolean squareIsWhite(String coordinates) {
        int x = coordinates.charAt(0) - 'a' + 1;
        int y = coordinates.charAt(1) - '0';
        return (x + y) % 2 == 1;
    }
}

JavaScript

/**
 * @param {string} coordinates
 * @return {boolean}
 */
var squareIsWhite = function(coordinates) {
    const x = coordinates.charCodeAt(0) - 'a'.charCodeAt(0) + 1;
    const y = Number(coordinates[1]);
    return (x + y) % 2 === 1;
};

常见错误

  • true 表示白色，别把黑白对应关系反过来。
  • 列从 0 开始而行从 1 开始，会使当前奇偶公式反转；两个坐标应使用同一基准。
  • JavaScript 中行号若不转数字，加法可能变成字符串拼接。
  • 棋盘行号自下向上递增，a1 是左下角。

面试追问

  • 如何判断两个格子同色？比较两个坐标和的奇偶性是否相同。
  • 棋盘扩大后公式还成立吗？相邻异色、起点为黑色时仍成立。
  • 若 a1 是白色？对结果取反。
  • 允许多位行号？解析首字母之后的完整数字串。
