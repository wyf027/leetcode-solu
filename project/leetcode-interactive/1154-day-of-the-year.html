Day of the Year · 把日期拆开，让月份像里程碑一样逐段累加。

题目

给定一个按 YYYY-MM-DD 格式表示公历日期的字符串 date，返回它是该年的第几天。

函数：dayOfYear(date: string): integer

约束

  • date.length == 10
  • 下标 4、7 为 -，其余字符均为数字
  • 日期范围：1900-01-01 至 2019-12-31，且输入一定是合法日期

示例 1

输入：date = "2019-01-09"
输出：9
解释：这是 2019 年的第 9 天。

示例 2

输入：date = "2019-02-10"
输出：41

独立题解

先自己推演，再打开完整分析。

核心洞察

答案等于“目标月之前所有月份的天数”加上“当月日”。唯一特殊点是闰年的二月有 29 天。

完整过程

  1. 从固定位置解析年、月、日。
  2. 用月份天数数组保存平年数据。
  3. 若年份可被 400 整除，或可被 4 整除但不能被 100 整除，则将二月改为 29 天。
  4. 累加下标 0..month-2，最后加 day。

为什么正确

一年按月份不重不漏地分割。目标日期之前的完整月份恰好是 1 月到目标月前一月；数组给出这些月份在该年份的准确长度。再加目标日在当月的序号，所得正是从元旦起包含目标日的总天数。

边界

1 月无需累加前置月份；闰日只影响 2 月之后的答案；世纪年必须满足“能被 400 整除”才是闰年；12 月 31 日应得到 365 或 366。

复杂度

最多遍历 11 个月，时间 O(12)，按常量看是 O(1)；月份数组占 O(12)，亦即 O(1) 空间。

替代方案

可用前缀和直接查表，或构造日期对象计算与元旦的差值。但日期库可能受时区、语言环境影响；面试中显式数组更可控。

面试追问

  • 如何扩展到任意两个日期间隔？
  • 为何 1900 不是闰年，而 2000 是？
  • 若输入可能非法，如何校验月份和日数？

常见错误

  • 只用 year % 4 == 0 判断闰年。
  • 把目标月本身也完整累加。
  • 用本地时区日期对象导致夏令时或跨日偏差。

四语言实现

Java
class Solution {
    public int dayOfYear(String date) {
        int year = Integer.parseInt(date.substring(0, 4));
        int month = Integer.parseInt(date.substring(5, 7));
        int day = Integer.parseInt(date.substring(8, 10));
        int[] days = {31, 28, 31, 30, 31, 30,
                      31, 31, 30, 31, 30, 31};
        if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)) days[1] = 29;
        for (int i = 0; i < month - 1; i++) day += days[i];
        return day;
    }
}

var dayOfYear = function(date) {
  const year = Number(date.slice(0, 4));

  let day = Number(date.slice(8, 10));
  const days = [31, 28, 31, 30, 31, 30,

};
Python
class Solution:
    def dayOfYear(self, date: str) -> int:
        year, month, day = map(int, date.split('-'))
        days = [31, 28, 31, 30, 31, 30,
                31, 31, 30, 31, 30, 31]
        if year % 400 == 0 or (year % 4 == 0 and year % 100 != 0):
            days[1] = 29
        return day + sum(days[:month - 1])
C++
class Solution {
public:
    int dayOfYear(string date) {
        int year = stoi(date.substr(0, 4));
        int month = stoi(date.substr(5, 2));
        int day = stoi(date.substr(8, 2));
        vector<int> days{31, 28, 31, 30, 31, 30,
                         31, 31, 30, 31, 30, 31};
        if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)) days[1] = 29;
        for (int i = 0; i < month - 1; ++i) day += days[i];
        return day;
    }
};
