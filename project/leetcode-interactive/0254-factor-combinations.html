把 n 拆成不小于 2 的因子乘积。递归时强制下一个因子不小于上一个，排列式重复便在树根被剪掉。

进入分叉演示查看验证
12→2×6→2×2×3

题意：枚举所有合法因子组合

给定整数 n，返回它的所有因子组合；因子范围是 [2, n - 1]，结果顺序不限。例如 8 = 2×2×2 = 2×4。

约束：1 ≤ n ≤ 10^7。n = 1 或质数没有组合；完整组合不可只写 [n]。
官方样例 
n = 1  → []
n = 12 → [[2,6],[3,4],[2,2,3]]
n = 37 → []

组合内部按非递减排列：[2,6] 收录，而 [6,2] 不再重复生成。

交互分步：只向右生长的因子树

以 n = 12 为例。每一层枚举从 start 开始的约数；选择 d 后，递归处理 remaining / d，并让下一层 start = d。

题解区域

默认收起。先看树如何保证因子顺序，再展开完整回溯代码。

核心洞察

路径存已选因子。对余数 rem 枚举 d ∈ [start, √rem]；若 d 整除 rem，则 path + [d, rem/d] 是一组答案，且可继续递归拆分 rem/d。下一层从 d 开始，保证路径非递减。

  1. 从 2 枚举可整除因子到平方根。
  2. 立即记录配对 path+[d, rem/d]。
  3. 递归拆分右因子，start 仍为 d。

复杂度与边界

  • 枚举输出本身可能很大；时间为输出敏感的回溯复杂度。
  • 递归深度至多 log₂n，路径空间同级。
  • n=1、质数：空列表。
  • 循环只到 √rem，因子对不会重复。

替代方案

暴力生成所有乘积拆分会产生大量排列重复。允许非递减的 start 参数在生成阶段去重，不需要结果集哈希去重，是面试更清晰的选择。

常见错误与追问

错误：允许下一层回到 2 导致 [2,6] 和 [6,2]；把 [n] 当答案；循环上界写到 rem 而非平方根。追问：想只返回因子数量 k？在递归增加 remaining-depth 剪枝。

class Solution {
  List<List<Integer>> ans = new ArrayList<>(); List<Integer> path = new ArrayList<>();
  public List<List<Integer>> getFactors(int n) { dfs(n, 2); return ans; }
  void dfs(int rem, int start) { for (int d = start; d * d <= rem; d++) if (rem % d == 0) { path.add(d); List<Integer> x = new ArrayList<>(path); x.add(rem / d); ans.add(x); dfs(rem / d, d); path.remove(path.size() - 1); } }
}
var getFactors = function(n) {
  const ans = [], path = [];
  const dfs = (rem, start) => { for (let d = start; d * d <= rem; d++) if (rem % d === 0) { path.push(d); ans.push([...path, rem / d]); dfs(rem / d, d); path.pop(); } };
  dfs(n, 2); return ans;
};
class Solution:
    def getFactors(self, n: int) -> List[List[int]]:
        ans, path = [], []
        def dfs(rem, start):
            for d in range(start, int(rem ** 0.5) + 1):
                if rem % d == 0:
                    path.append(d); ans.append(path[:] + [rem // d])
                    dfs(rem // d, d); path.pop()
        dfs(n, 2)
        return ans
