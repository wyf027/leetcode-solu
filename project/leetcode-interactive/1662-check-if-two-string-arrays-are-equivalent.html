检查两个字符串数组是否相等

两个数组可以切成完全不同的片段。真正需要比较的，是把各自片段按原顺序连接后，是否得到同一个字符串。

Problem

题目说明

给定字符串数组 word1 与 word2。数组表示的字符串，是其所有元素按顺序连接的结果；两者相同返回 true，否则返回 false。

示例 1true
输入：word1 = ["ab", "c"],
      word2 = ["a", "bc"]
输出：true
解释："ab" + "c" = "abc"
      "a" + "bc" = "abc"
示例 2false
输入：word1 = ["a", "cb"],
      word2 = ["ab", "c"]
输出：false
示例 3true
输入：word1 = ["abc", "d", "defg"],
      word2 = ["abcddefg"]
输出：true
1 ≤ word1.length, word2.length ≤ 10³
1 ≤ word1[i].length, word2[i].length ≤ 10³
1 ≤ Σ word1[i].length, Σ word2[i].length ≤ 10³
word1[i] 与 word2[i] 仅含小写英文字母

把分段边界变成透明的

核心洞察

数组如何切段不重要。用两组“片段下标 + 片段内下标”定位当前字符，每次比较后分别前进，就能像读取连续字符串一样扫描，而无需真的拼接。

循环不变量

每轮开始时，两套游标之前的所有字符已经一一相等；当前游标都指向各自尚未检查的第一个字符。

完整过程

初始化两套游标。

(i, p) 指向 word1[i][p]，(j, q) 指向 word2[j][q]，四个下标均从 0 开始。

比较当前字符。

只要两个数组都还有字符，若当前字符不同，立即返回 false；否则两边的片段内下标各加 1。

跨越片段边界。

某个片段内下标到达该片段长度时，将它归零，并把对应的片段下标加 1。两侧边界可以在完全不同的时刻出现。

检查是否同时结束。

循环退出后，仅当两个片段下标都到达各自数组末尾时返回 true；一边残留字符意味着总字符串不同。

正确性证明

保持性：初始时尚无字符被比较，不变量成立。若一轮当前字符相等，两套游标各前进一步；越过片段边界只改变定位方式，不改变字符顺序，因此新游标之前的字符仍逐一相等，不变量继续成立。

终止性：每轮至少消费两侧各一个字符，所以扫描必然结束。若中途字符不同，两个连接结果在该位置不同，返回 false 正确。若未失配且双方同时结束，全部字符一一相等且长度相同，返回 true；若只有一方结束，另一方仍有后缀，返回 false。故算法总能给出正确答案。

时间：O(N + M)额外空间：O(1)N、M 为两侧总字符数

边界情况

需要特别留意

  • 只有一个片段或每个片段只有一个字符。
  • 一边先耗尽，但此前所有字符都相同。
  • 失配恰好发生在跨片段边界之后。
  • 两边切分方式不同，但连接结果相同。

常见错误

  • 一侧结束就直接返回 true，忽略另一侧残留字符。
  • 跨段后忘记把片段内下标归零。
  • 把数组片段数不同误判为字符串不同。
  • 宣称 O(1) 空间，却实际创建了两个拼接字符串。

四种语言实现

Java 双游标
class Solution {
    public boolean arrayStringsAreEqual(String[] word1, String[] word2) {
        int i = 0, p = 0;
        int j = 0, q = 0;

        while (i < word1.length && j < word2.length) {
            if (word1[i].charAt(p) != word2[j].charAt(q)) {
                return false;
            }

            p++;
            q++;

            if (p == word1[i].length()) {
                i++;
                p = 0;
            }
            if (q == word2[j].length()) {
                j++;
                q = 0;
            }
        }

        return i == word1.length && j == word2.length;
    }
}

var arrayStringsAreEqual = function(word1, word2) {
    let i = 0, p = 0;
    let j = 0, q = 0;

    while (i < word1.length && j < word2.length) {
        if (word1[i][p] !== word2[j][q]) {
            return false;
        }

        p++;
        q++;

        if (p === word1[i].length) {
            i++;
            p = 0;
        }
        if (q === word2[j].length) {
            j++;
            q = 0;
        }
    }

    return i === word1.length && j === word2.length;
};
Python 3 双游标
from typing import List


class Solution:
    def arrayStringsAreEqual(
        self, word1: List[str], word2: List[str]
    ) -> bool:
        i = p = 0
        j = q = 0

        while i < len(word1) and j < len(word2):
            if word1[i][p] != word2[j][q]:
                return False

            p += 1
            q += 1

            if p == len(word1[i]):
                i += 1
                p = 0
            if q == len(word2[j]):
                j += 1
                q = 0

        return i == len(word1) and j == len(word2)

替代方案：直接拼接

分别执行 join 或逐段追加，再比较两个完整字符串。它最短、最直观，时间仍为 O(N + M)，但通常会额外占用 O(N + M) 空间。数据规模仅 10³ 时完全可接受；双游标版本更能体现流式处理能力。
