井字游戏

面对一个已经停下来的 3 × 3 棋盘，判断它是否可能来自一局严格轮流、胜出即停的真实游戏。先亲手审计状态，题解会留到页面底部。

参数：board: string[] 返回：boolean 首手：X

01 · 题目

从终局快照，反推它是否真实发生过

题意转述：给定字符串数组 board，其中三行共同构成一个 3 × 3 井字棋盘。每个格子只能是 'X'、'O' 或空格 ' '。当且仅当这个局面能够在一局合法的井字游戏中出现时，返回 true。

玩家严格轮流落子，X 永远先手，O 后手；只能落在空格。一旦任意行、列或对角线出现三个相同的非空符号，或棋盘填满，游戏立即结束，之后不能继续落子。

约束

  • board.length == 3
  • board[i].length == 3
  • board[i][j] 是 'X'、'O' 或 ' '
示例 1 · 首手错误
输入：board = ["O  ","   ","   "]
输出：false
解释：第一步必须由 X 落子。
示例 2 · 轮次错误
输入：board = ["XOX"," X ","   "]
输出：false
解释：X 与 O 必须轮流落子。
示例 3 · 合法局面
输入：board = ["XOX","O O","XOX"]
输出：true

04 · 完整题解

只需守住两个不变量

落子数量

X 先手且双方轮流，因此只可能满足 xCount == oCount 或 xCount == oCount + 1。

X 获胜

X 的三连线由 X 刚刚完成，所以此时必须有 xCount == oCount + 1。

O 获胜

O 的三连线由 O 刚刚完成，所以此时必须有 xCount == oCount。

完整过程

  1. 遍历 9 个格子，统计 X 和 O 的数量。
  2. 若双方数量既不相等、X 也不比 O 恰好多一个，立即判为非法。
  3. 分别检查 X、O 是否占满任意一行、一列或一条对角线。
  4. 若 X 获胜但 X 没有比 O 多一个，说明胜局之后还有额外落子，非法。
  5. 若 O 获胜但双方数量不相等，同样说明胜者与时间线不一致，非法。
  6. 其余状态均可由某个合法落子顺序到达，返回 true。
核心洞察：“谁该落子”和“胜出即停”已经把历史压缩成数量关系与当前胜线。无需枚举所有下棋顺序。

正确性证明

必要性：合法游戏中 X 先手且双方轮流，所以 X 数量只能等于 O，或恰好多 1。若 X 获胜，最后一步一定由 X 下，因此 X 必须多 1；若 O 获胜，最后一步一定由 O 下，因此数量必须相等。算法拒绝所有违反这些条件的局面。

充分性：若数量关系合法，且任何胜者都与其应有的落子时刻一致，则可把非胜线棋子安排在更早的交替回合，把形成胜线的最后一枚棋子放在最后；若无人获胜，按数量关系交替安排已有棋子即可到达当前局面。因此存在合法历史。

结论：算法返回 true 当且仅当给定棋盘可以由合法井字游戏到达。

边界与复杂度

  • 空棋盘合法。
  • 只有一个 X 合法；只有一个 O 非法。
  • 双方同时有胜线会被胜者轮次条件排除。
  • 满盘但无人获胜可能是合法和局。
  • 固定 3 × 3 棋盘：时间 O(1)，空间 O(1)。
  • 推广到 n × n 扫描：时间 O(n²)。

Java

class Solution {
    public boolean validTicTacToe(String[] board) {
        int x = 0, o = 0;
        for (String row : board) {
            for (char cell : row.toCharArray()) {
                if (cell == 'X') x++;
                if (cell == 'O') o++;
            }
        }
        if (x != o && x != o + 1) return false;
        boolean xWins = wins(board, 'X');
        boolean oWins = wins(board, 'O');
        if (xWins && x != o + 1) return false;
        if (oWins && x != o) return false;
        return true;
    }

    private boolean wins(String[] board, char p) {
        for (int i = 0; i < 3; i++) {
            if (board[i].charAt(0) == p
                    && board[i].charAt(1) == p
                    && board[i].charAt(2) == p) return true;
            if (board[0].charAt(i) == p
                    && board[1].charAt(i) == p
                    && board[2].charAt(i) == p) return true;
        }
        return (board[0].charAt(0) == p
                    && board[1].charAt(1) == p
                    && board[2].charAt(2) == p)
            || (board[0].charAt(2) == p
                    && board[1].charAt(1) == p
                    && board[2].charAt(0) == p);
    }
}

var validTicTacToe = function(board) {
    let x = 0, o = 0;
    for (const row of board) {
        for (const cell of row) {
            if (cell === "X") x++;
            if (cell === "O") o++;
        }

    if (x !== o && x !== o + 1) return false;

    const wins = function(player) {
        for (let i = 0; i < 3; i++) {
            if (board[i][0] === player
                    && board[i][1] === player
                    && board[i][2] === player) return true;

                    && board[1][i] === player
                    && board[2][i] === player) return true;

from typing import List


class Solution:
    def validTicTacToe(self, board: List[str]) -> bool:
        x = sum(row.count("X") for row in board)
        o = sum(row.count("O") for row in board)
        if x != o and x != o + 1:
            return False

        def wins(player: str) -> bool:
            for i in range(3):
                if all(board[i][j] == player for j in range(3)):
                    return True
                if all(board[j][i] == player for j in range(3)):
                    return True
            return (
                all(board[i][i] == player for i in range(3))
                or all(board[i][2 - i] == player for i in range(3))
            )

        x_wins = wins("X")
        o_wins = wins("O")
        if x_wins and x != o + 1:
            return False
        if o_wins and x != o:
            return False
        return True

替代方案

回溯模拟：从空棋盘出发，轮流尝试在目标棋盘允许的位置落子；一旦出现胜者就停止扩展，检查能否抵达目标状态。固定 3 × 3 时可行，但状态管理更复杂。

预生成合法状态：用 DFS 枚举全部合法棋盘并存入哈希集合，之后查询为 O(1)。适合大量重复查询，不适合一次性判定。

常见错误

  • 只检查棋子数量，不检查胜者对应的最后一步。
  • 看到三连线就直接判非法。
  • 允许 O 比 X 多，或 X 比 O 多两枚以上。
  • 漏掉列或两条对角线。
  • 胜出后继续落子仍误判为合法。

面试追问

  • 能否恢复具体落子序列？可以，从空盘回溯构造；每步只能落在目标棋盘中同符号的位置，并在提前获胜时剪枝。
  • 推广到 n × n 且连续 n 个获胜？计数不变量不变，胜线扫描为 O(n²)。
  • 大量查询怎么做？预生成所有合法状态并哈希存储，查询摊销 O(1)。
  • 双方同时获胜为何必然非法？X 胜要求 X 比 O 多 1，O 胜要求二者相等，无法同时满足。
