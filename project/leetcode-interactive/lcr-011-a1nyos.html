连续数组

在只含 0 和 1 的数组里，找出 0、1 数量相等的最长连续子数组。将 0 看作 −1、1 看作 +1，问题就变成“两个相同前缀和之间的最长距离”。

0 → −1
抵消一个 1
1 → +1
累积一个 1
相同 sum
中间和为 0

INTERACTIVE LAB

扫描前缀和

    当前位置 −1
    前缀和 0
    最佳长度 0

    firstSeen[0] = −1：空前缀是起点。

    INVARIANT

    只记录最早位置

    1. 1. sum 是已扫描元素的 ±1 总和。
    2. 2. 同一 sum 的两个位置之间，0 和 1 数量相等。
    3. 3. 相同 sum 首次出现得越早，区间越长。
    4. 4. 因此 Map 只在 sum 首次出现时写入。

    不要把后续位置覆盖首次位置，否则可能丢失最长答案。

    PROOF IDEA

    相同前缀和为何有效？

    设位置 i 与 j 的前缀和相同，则区间 (i, j] 的元素和为 0。因为每个 0 被映射为 −1、每个 1 映射为 +1，和为 0 恰好说明两种元素数量相等。

    class Solution {
    public int findMaxLength(int[] nums) {
        java.util.Map<Integer, Integer> first = new java.util.HashMap<>();
        first.put(0, -1); int sum = 0, ans = 0;
        for (int i = 0; i < nums.length; i++) {
            sum += nums[i] == 0 ? -1 : 1;
            if (first.containsKey(sum)) ans = Math.max(ans, i - first.get(sum));
            else first.put(sum, i);
        }
        return ans;
    }
}
