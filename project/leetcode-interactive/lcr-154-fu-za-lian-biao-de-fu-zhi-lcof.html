LCR 154 · Pointer identity

复杂链表的复制

每个节点除了 next，还有一条可能指向任意节点或 null 的 random 指针。请返回整条链表的深拷贝： 结构相同，但所有节点都必须是新对象。

输入表示

第 i 项写作 [val, randomIndex]；下标仅用于描述， 并不是节点值。

[[7,null],[13,0],[11,4],[10,2],[1,0]]

先看清“深拷贝”

示例 1

随机指针跨越前后节点

输入 / 输出：[[7,null],[13,0],[11,4],[10,2],[1,0]]

复制后，下标 1 的新节点仍指向下标 0 的新节点，不能指回原链表。

示例 2

相同值不代表同一节点

输入 / 输出：[[3,null],[3,0],[3,null]]

值可以重复；random 关系由对象身份决定，不能按 val 猜目标。

约束

  • 节点数 0 ≤ n ≤ 1000
  • -10⁴ ≤ Node.val ≤ 10⁴
  • random 指向链内节点或 null

核心洞察

把副本放在原节点旁边

在每个原节点后插入它的副本，临时形成 old → copy → oldNext。这样任意原节点 x 的副本都是 x.next，无需额外哈希表。

关键不变式

相邻位置就是一一映射

穿插完成后，每个旧节点与唯一新节点相邻。因此若 old.random 不为空，其副本就是 old.random.next。

完整过程

穿插、补 random、拆分

  1. 处理空链表。若 head == null，直接返回空。
  2. 穿插副本。沿原链表遍历，为每个节点创建同值副本，并插到它后面。
  3. 连接 random。执行 copy.random = old.random == null ? null : old.random.next。
  4. 拆分并恢复。旧节点重新连接下一个旧节点，副本连接下一个副本。

边界

身份比数值更重要

  • 空链表；单节点 random 为空或指向自己
  • 多个 random 指向同一节点
  • random 回指前驱或跨越多个节点
  • 多个节点值相同，不能按 val 配对

复杂度

三次线性扫描

时间复杂度 O(n)。除返回链表本身外，只使用常数个指针，额外空间 O(1)。

替代方案

两遍哈希映射

第一遍建立 old → copy，第二遍翻译 next 与 random。它不会临时修改原链表， 更直观，但需要 O(n) 额外空间。

常见错误

拆分时最容易断链

  • 让 copy.random 直接指向旧节点
  • 访问空 random 的 next
  • 未恢复原链表，或漏接副本 next
  • 穿插遍历步长错误，再次处理副本节点

面试追问

从链表推广到图

  • 如何证明新旧节点身份独立、指针关系同构？
  • 如果不允许临时修改原链表，应选择哪种方法？
  • 如果 next 也可能成环，如何改为 visited + 工作队列？
  • 如何证明拆分结束后原链表被完整恢复？

class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) return null;

        for (Node cur = head; cur != null; cur = cur.next.next) {
            Node copy = new Node(cur.val);
            copy.next = cur.next;
            cur.next = copy;
        }

        for (Node cur = head; cur != null; cur = cur.next.next) {
            if (cur.random != null) {
                cur.next.random = cur.random.next;
            }
        }

        Node dummy = new Node(0);
        Node copyTail = dummy;
        Node cur = head;
        while (cur != null) {
            Node copy = cur.next;
            cur.next = copy.next;
            copyTail.next = copy;
            copyTail = copy;
            cur = cur.next;
        }
        return dummy.next;
    }
}
