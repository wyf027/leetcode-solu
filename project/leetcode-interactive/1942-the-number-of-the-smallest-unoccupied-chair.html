最小未被占据
椅子的编号

The Number of the Smallest Unoccupied Chair

一场派对，一排从 0 开始的椅子。目标朋友到来时，会坐在哪里？

01 / 规则与输入

有 n 位朋友，编号为 0 … n − 1，以及编号从 0 起的无限张椅子。每位朋友到达时，总是选择当前空闲椅子中编号最小的一张。朋友离开的瞬间，椅子就可以被再次使用；同一时刻到达的人也可以坐下。

输入二维整数数组 times，其中 times[i] = [arrivalᵢ, leavingᵢ] 表示朋友 i 到达与离开的时间，以及整数 targetFriend。所有到达时间互不相同。返回目标朋友坐过的椅子编号。

约束

  • n == times.length，2 ≤ n ≤ 10⁴
  • times[i].length == 2
  • 1 ≤ arrivalᵢ < leavingᵢ ≤ 10⁵
  • 0 ≤ targetFriend ≤ n − 1
  • 所有 arrivalᵢ 两两不同。

02 / 官方示例

示例 1 · 同时离开与到达

times = [[1,4],[2,3],[4,6]]
targetFriend = 1
输出：1

时刻 1，朋友 0 坐椅子 0；时刻 2，朋友 1 坐椅子 1。时刻 3，朋友 1 离开；时刻 4，朋友 0 离开，随后朋友 2 坐椅子 0。目标朋友 1 坐的是椅子 1。

示例 2 · 编号不代表到达顺序

times = [[3,10],[1,5],[2,6]]
targetFriend = 0
输出：2

朋友 1、2、0 分别在时刻 1、2、3 到达，依次坐椅子 0、1、2；之后分别在时刻 5、6、10 离开。目标朋友 0 坐的是椅子 2。

05 / 独立题解
准备好后，展开思路、证明和完整代码。




两个最小值，两种排序


到达顺序决定处理顺序；离开时间决定哪些座位能释放；椅子编号决定谁被选中。后两者的排序依据不同，因此维护两个最小堆：空闲堆 free 按椅子编号排序，占用堆 busy 按 (离开时间, 椅子编号) 排序。


核心洞察
最多只有 n 位朋友，因此初始化编号 0 … n−1 的 n 张椅子就足够。某位朋友到达前，最多 n−1 位朋友在场，编号 0 … n−1 中至少有一张空椅子。无限空间由一个有限集合精确表示。


完整过程
  1. 构造 [到达时间, 离开时间, 原始朋友编号]，按到达时间递增排序。必须保留原始编号。
  2. 将 0 … n−1 放入空闲最小堆，占用堆初始为空。
  3. 对当前朋友的到达时刻 a，反复取出占用堆里所有 leaving ≤ a 的记录，将对应椅子归还空闲堆。
  4. 弹出空闲堆的堆顶作为该朋友的椅子。如果此朋友是目标，立即返回该编号。
  5. 否则把 [leaving, chair] 放入占用堆，继续处理下一位朋友。


当前回放 · free
当前回放 · busy
这里将堆元素按优先级排序展示，便于阅读，不代表二叉堆内部数组布局。busy 项为“离开时间 : 椅子编号”。回放为展示复用会继续，提交代码则在目标入座时返回。


示例 1 的状态转移
初始 free = [0,1,2]。时刻 1 分配椅子 0，busy 加入 (4,0)。时刻 2 没有座位到期，分配椅子 1，目标朋友已入座，返回 1。如果继续回放，到时刻 4 必须先释放 (3,1) 和 (4,0)，再为朋友 2 分配椅子 0。


正确性证明
不变量：每次分配座位之前，busy 恰好保存已到达且尚未离开的朋友的离开时间与椅子，free 恰好保存编号 0 … n−1 中其他椅子，两者不重不漏。
初始化：尚无人到达，busy 为空，所有 n 张椅子在 free 中，不变量成立。
保持：朋友按到达时间处理。busy 的堆顶是最早离开者，循环移除所有离开时间不晚于当前到达时间的记录，正好释放所有应空闲的座位。free 的最小值因此就是本题规定的最小空闲椅子；将它取出并与新的离开时间加入 busy 后，分配状态仍然准确。
结论：归纳可知每位朋友得到的椅子均符合规则，所以处理到原始编号为 targetFriend 的朋友时返回的编号正确。后续朋友不会改变这个已确定的答案。


边界与常见错误
  • 离开与到达同一时刻：条件是 ≤，不能用 <。
  • 可能有多位朋友已经离开：必须用 while，不能只释放一位。
  • 多个朋友同时离开不影响答案：先将他们全部释放，再从 free 中选最小编号。
  • 不要把排序后数组下标当作朋友编号；原始编号必须随记录保留。
  • 不能直接挑“最早离开者”的椅子：已释放椅子中可能有更小编号。
  • 目标最先到达时答案为 0；全部区间重叠时，最后到达者会坐 n−1。
  • 不能在目标到达前返回某次空闲堆顶；需先释放目标到达时刻已经到期的所有占用。


复杂度
排序 O(n log n)。每个朋友至多产生一次占用堆入堆与出堆，每张分配椅子至多对应一次取出和归还，堆操作总计 O(n log n)。总体时间 O(n log n)，额外空间 O(n)。即使提前返回，排序仍可能需要处理全部输入。


替代方案
  • 直接扫描椅子：为每个编号维护释放时间，每次从 0 起找第一个释放时间不晚于当前到达时间的椅子。易理解，最坏 O(n²) 时间、O(n) 空间。
  • 事件排序：把到达与离开拆成事件，同一时刻离开优先，配合空闲编号堆与朋友到椅子的映射；同样 O(n log n)。
  • 动态新椅子：空闲堆只保存被释放的椅子，并维护 nextChair。空闲堆为空时使用 nextChair++，无需预放 n 张椅子；渐近复杂度不变。


面试追问
若允许同时到达？必须先明确朋友的处理优先级，再在排序中加入对应规则；当前题目保证到达时间不同。
若要求返回每位朋友的椅子？去掉提前返回，把结果写入原始编号对应的位置。
如果输入已按到达时间排序？可省去排序，但堆操作仍是 O(n log n)。
为什么 busy 的时间并列时用椅子编号打破平局？便于确定展示顺序；正确性只要求所有已到期记录在入座前都被释放。

import java.util.*;

class Solution {
    public int smallestChair(int[][] times, int targetFriend) {
        int n = times.length;
        int[][] people = new int[n][3];
        for (int i = 0; i < n; i++) {
            people[i] = new int[]{times[i][0], times[i][1], i};
        }
        Arrays.sort(people, Comparator.comparingInt(p -> p[0]));
        PriorityQueue<Integer> free = new PriorityQueue<>();
        PriorityQueue<int[]> busy = new PriorityQueue<>((a, b) ->
            a[0] == b[0] ? Integer.compare(a[1], b[1])
                         : Integer.compare(a[0], b[0]));
        for (int chair = 0; chair < n; chair++) free.offer(chair);
        for (int[] p : people) {
            while (!busy.isEmpty() && busy.peek()[0] <= p[0]) {
                free.offer(busy.poll()[1]);
            }
            int chair = free.poll();
            if (p[2] == targetFriend) return chair;
            busy.offer(new int[]{p[1], chair});
        }
        return -1;
    }
}


JavaScript · 可提交实现（自带最小堆，无外部依赖）
class MinHeap {
    constructor(compare) {
        this.data = [];
        this.compare = compare;
    }
    get size() { return this.data.length; }
    peek() { return this.data[0]; }
    push(value) {
        const a = this.data;
        a.push(value);
        let i = a.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (this.compare(a[p], a[i]) <= 0) break;
            [a[p], a[i]] = [a[i], a[p]];
            i = p;
        }
    }
    pop() {
        const a = this.data;
        if (!a.length) return undefined;
        const result = a[0], last = a.pop();
        if (a.length) {
            a[0] = last;
            let i = 0;
            while (2 * i + 1 < a.length) {
                let child = 2 * i + 1;
                if (child + 1 < a.length &&
                    this.compare(a[child + 1], a[child]) < 0) child++;
                if (this.compare(a[i], a[child]) <= 0) break;
                [a[i], a[child]] = [a[child], a[i]];
                i = child;
            }
        }
        return result;
    }
}

/**
 * @param {number[][]} times
 * @param {number} targetFriend
 * @return {number}
 */
var smallestChair = function(times, targetFriend) {
    const people = times.map(([a, b], i) => [a, b, i])
                        .sort((x, y) => x[0] - y[0]);
    const free = new MinHeap((a, b) => a - b);
    const busy = new MinHeap((a, b) => a[0] - b[0] || a[1] - b[1]);
    for (let i = 0; i < times.length; i++) free.push(i);
    for (const [arrival, leaving, friend] of people) {
        while (busy.size && busy.peek()[0] <= arrival) {
            free.push(busy.pop()[1]);
        }
        const chair = free.pop();
        if (friend === targetFriend) return chair;
        busy.push([leaving, chair]);
    }
    return -1;
};

from typing import List
from heapq import heapify, heappush, heappop

class Solution:
    def smallestChair(self, times: List[List[int]], targetFriend: int) -> int:
        people = sorted((a, b, i) for i, (a, b) in enumerate(times))
        free = list(range(len(times)))
        heapify(free)
        busy = []
        for arrival, leaving, friend in people:
            while busy and busy[0][0] <= arrival:
                _, chair = heappop(busy)
                heappush(free, chair)
            chair = heappop(free)
            if friend == targetFriend:
                return chair
            heappush(busy, (leaving, chair))
        return -1

#include <algorithm>
#include <array>
#include <functional>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int smallestChair(vector<vector<int>>& times, int targetFriend) {
        int n = static_cast<int>(times.size());
        vector<array<int, 3>> people;
        for (int i = 0; i < n; ++i)
            people.push_back({times[i][0], times[i][1], i});
        sort(people.begin(), people.end());
        priority_queue<int, vector<int>, greater<int>> free;
        using P = pair<int, int>;
        priority_queue<P, vector<P>, greater<P>> busy;
        for (int c = 0; c < n; ++c) free.push(c);
        for (const auto& p : people) {
            while (!busy.empty() && busy.top().first <= p[0]) {
                free.push(busy.top().second);
                busy.pop();
            }
            int chair = free.top();
            free.pop();
            if (p[2] == targetFriend) return chair;
            busy.push({p[1], chair});
        }
        return -1;
    }
};
