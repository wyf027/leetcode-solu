01 / 题目

顺时针转 90°，然后让石头落稳

给定 m × n 字符矩阵 boxGrid，表示盒子的侧视图。'#' 是石头，'*' 是固定障碍物，'.' 是空格。将整个盒子顺时针旋转 90° 后，石头沿竖直方向下落，直到被障碍物、其他石头或盒子底部支撑。

障碍物随盒子旋转，但不会因重力下落；旋转没有惯性效应，因此石头在旋转后不会横向漂移。初始状态保证每块石头都有障碍物、其他石头或底部支撑。返回最终稳定状态的 n × m 字符矩阵。

参数与返回值
rotateTheBox(boxGrid: character[][]) → character[][]

约束

  • m == boxGrid.length
  • n == boxGrid[i].length
  • 1 ≤ m, n ≤ 500
  • boxGrid[i][j] 只能为 '#'、'*' 或 '.'。

以下示例使用官方签名的参数名 boxGrid（中文旧题面也写作 box）。

04 / 独立题解

准备好再展开

核心洞察：旋转是坐标映射，下落是分段压紧

将原格子 (i, j) 放到 (j, m - 1 - i)，就完成顺时针旋转。旋转后每一列互不影响，障碍物又把列分成独立区间。每个区间内的石头只需要紧贴区间底部排列，石头之间无需区分身份。

完整过程

  1. 创建 n × m 的结果矩阵，按映射复制所有字符。
  2. 对于结果的每一列 c，从底部向上扫描。令 write = n - 1 表示下一块石头的落点。
  3. 遇到障碍物时不移动它，令 write = r - 1，进入障碍物上方的新区间。
  4. 遇到石头时，先把当前位置清空，再在 (write, c) 写入石头，最后 write--。若原位置就是落点，先清空再写回仍然正确。
  5. 遇到空格时跳过。处理完所有列即得到答案。

示例 2：旋转后右列为 [#, ., *, .]。从下往上扫描，遇到第 3 行的障碍物，落点改为第 2 行；顶部石头落到第 2 行，得到 [., #, *, .]。左列 [#, #, *, .] 已经稳定。

正确性证明

旋转正确：映射使旧行变成新列、旧列变成新行，并将新列顺序反转，恰好对应顺时针 90°；每个格子唯一对应一个新位置。

扫描不变量：在当前无障碍区间中，已扫描到的石头全部紧贴区间底部；write 是它们上方下一处可落位置。处理石头时 write 的行下标不小于当前 r。空格不改变排列；石头放到 write 后仍保持紧凑；遇障碍则重新开始独立区间。

结束：各区间石头数不变，障碍物不变，且没有石头下方留下可达空格。这就是重力下唯一稳定的排列。各列独立，因此整体结果正确。

边界与复杂度

  • 单格、全空、全障碍：照常映射与扫描。
  • 单行输入：旋转为单列；单列输入：旋转为单行。
  • 连续障碍物：每次重置 write，不会跨障碍放置。
  • 落点等于原位置：清空在前、写入在后。
  • 时间：旋转与扫描各遍历所有格子，O(mn)。
  • 空间：返回矩阵 O(mn)；排除输出后辅助空间 O(1)。不修改输入。

替代方案

先在原矩阵中把每行石头向右压紧，再旋转，利用“原图向右 = 新图向下”的方向关系，也可达到 O(mn)。原地压紧会修改输入，应事先说明。另一种逐块石头逐格下落的物理模拟更直观，但最坏可达 O(mn²)，不适合大矩阵。

常见错误

  • 把顺时针映射写成 (n - 1 - j, i)，导致逆时针旋转。
  • 输出仍分配为 m × n，非方阵越界。
  • 遇到障碍没有重置 write，石头穿墙。
  • 先写落点再清空原位，原位等于落点时丢失石头。
  • JavaScript 用 fill 复用同一个子数组，引发行间串改。

面试追问

  • 能合并两遍遍历吗？可以从原矩阵每行右向左扫描，维护右侧落点 k，将石头直接写到结果的 (k, m - 1 - i)，障碍物按原 j 映射，输出预填空格。
  • 为什么不需要记录石头的身份？输出仅关心字符占位；同一区间的石头相同，计数与排列已确定结果。
  • 可以原地旋转吗？一般矩形旋转会改变行列长度；本题返回新矩阵最直接，方阵才有常见的原地转置与反转方案。

Java

class Solution {
    public char[][] rotateTheBox(char[][] boxGrid) {
        int m = boxGrid.length, n = boxGrid[0].length;
        char[][] ans = new char[n][m];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                ans[j][m - 1 - i] = boxGrid[i][j];
            }
        }
        for (int c = 0; c < m; c++) {
            int write = n - 1;
            for (int r = n - 1; r >= 0; r--) {
                if (ans[r][c] == '*') {
                    write = r - 1;
                } else if (ans[r][c] == '#') {
                    ans[r][c] = '.';
                    ans[write][c] = '#';
                    write--;
                }
            }
        }
        return ans;
    }
}

var rotateTheBox = function(boxGrid) {
    const m = boxGrid.length, n = boxGrid[0].length;
    const ans = Array.from({ length: n }, () => Array(m).fill('.'));
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            ans[j][m - 1 - i] = boxGrid[i][j];
        }

        let write = n - 1;

                write--;
            }
        }
    }

from typing import List

class Solution:
    def rotateTheBox(self, boxGrid: List[List[str]]) -> List[List[str]]:
        m, n = len(boxGrid), len(boxGrid[0])
        ans = [['.'] * m for _ in range(n)]
        for i in range(m):
            for j in range(n):
                ans[j][m - 1 - i] = boxGrid[i][j]
        for c in range(m):
            write = n - 1
            for r in range(n - 1, -1, -1):
                if ans[r][c] == '*':
                    write = r - 1
                elif ans[r][c] == '#':
                    ans[r][c] = '.'
                    ans[write][c] = '#'
                    write -= 1
        return ans

class Solution {
public:
    vector<vector<char>> rotateTheBox(vector<vector<char>>& boxGrid) {
        int m = boxGrid.size(), n = boxGrid[0].size();
        vector<vector<char>> ans(n, vector<char>(m, '.'));
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                ans[j][m - 1 - i] = boxGrid[i][j];
            }
        }
        for (int c = 0; c < m; ++c) {
            int write = n - 1;
            for (int r = n - 1; r >= 0; --r) {
                if (ans[r][c] == '*') {
                    write = r - 1;
                } else if (ans[r][c] == '#') {
                    ans[r][c] = '.';
                    ans[write][c] = '#';
                    --write;
                }
            }
        }
        return ans;
    }
};
