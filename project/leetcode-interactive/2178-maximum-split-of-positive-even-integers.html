LeetCode 2178 · Maximum Split of Positive Even Integers

拆分成最多数目的
正偶数之和

一份总额，多种拆分。怎样让互不相同的正偶数尽可能多？

读题 → 自主思考 → 交互推演离线单文件 · 四语言

01题目与约束

给定整数 finalSum，把它表示为若干个互不相同的正偶数之和。在所有合法方案中，返回元素数量最多的一个整数数组。元素顺序不限；若无法拆分，返回空数组。

例如，12 可以拆成 12、2 + 10、4 + 8 或 2 + 4 + 6。最后一种含有 3 个数；2 + 2 + 4 + 4 虽然总和相同，但存在重复数字，不合法。

  • 参数：finalSum，一个整数。
  • 约束：1 ≤ finalSum ≤ 1010。
  • 返回：整数数组，每个元素为正偶数、两两不同、总和等于输入，并使数组长度最大。

先思考：总和相同，为什么某些拆分能容纳更多不同的数？题解默认折叠，可在页面底部展开。

04题解 · 先铺最小台阶，再安放余量

核心洞察

奇数不可能由偶数相加得到。对正偶数，想拆得最多，就先选最小且不重复的 2, 4, 6, …，让每新增一个数的消耗尽量小。剩余部分不足以选下一个偶数时，把它加到已选的最大数上。

余量也是偶数；增大最大元素不会产生重复，也不会减少元素个数。

完整过程

  1. 若 finalSum 为奇数，立即返回空数组。
  2. 令余量等于输入，从 x = 2 开始。
  3. 只要余量不少于 x，就把 x 放进数组，余量减去 x，令 x 增加 2。
  4. 循环结束后，余量小于下一个候选。把余量加到数组最后一个元素，再返回数组。

以 28 为例：先取 2、4、6、8，共消耗 20，余量为 8，小于下一个候选 10。将 8 加到当前最大值 8 上，得到 [2,4,6,16]，数量为 4。它与官方示例的答案不同，但同样最优。

正确性：数量上界与可行构造相遇

将任意 k 个互不相同的正偶数升序排列，第 i 个数至少为 2i。因此总和至少为 2 + 4 + … + 2k = k(k + 1)。任何合法拆分都必须满足 k(k + 1) ≤ finalSum。

循环恰好选出最大的 k，使 k(k + 1) 不超过总额。否则还可以放入 2(k + 1)，循环就不会结束。于是 (k + 1)(k + 2) > finalSum，任何 k + 1 项的拆分都不可能存在。

选出的前 k 项为 2 到 2k，余量 r 非负且为偶数。将最后一项改为 2k + r 后，所有元素仍为正偶数，最后一项大于之前所有元素，总和精确等于输入。因此构造合法且达到数量上界，最优性成立。奇数输入则由偶数和的奇偶性直接判定无解。

边界与复杂度

  • 1 及其他奇数返回空数组；2 返回 [2]。正偶数至少会选入 2，因此访问最后一项安全。
  • 余量为 0 时不需要改变最大数；仍可直接加 0。
  • 时间 O(√finalSum)；返回数组占 O(√finalSum)，不计输出的额外空间为 O(1)。
  • Java 使用 long / Long，C++ 使用 long long。JavaScript Number 可精确表示本题全部整数（10¹⁰ 远小于 2⁵³ − 1），Python int 可直接使用。

替代方案

用二次不等式估算 k = floor((√(1 + 4S) − 1) / 2)，再用整数比较修正边界，构造前 k − 1 个最小偶数，最后一项取剩余总和。求数量近似 O(1)，但输出 k 个数依然需要 O(k) 时间。也可二分查找 k，适合只问最大数量时使用。回溯枚举方案存在大量分支，动态规划按总和建表也无法适配 10¹⁰，均无必要。

常见错误

  • 将余量直接追加：它可能是 0，或与已有数字重复。
  • 将余量加到第一个元素：可能撞上中间某个数。加到最大元素最直接。
  • 漏掉奇数判定，或用 32 位整数接收 10¹⁰。
  • 仅把输出与官方数组逐项比较：本题解不唯一，应检查正偶数、互异性、总和和最优长度。

面试追问

  • 只返回最多数量？ 找到满足 k(k + 1) ≤ S 的最大 k，奇数返回 0；可用二分避免浮点边界。
  • 改为互异的正 m 倍数？ 首先要求 S 能被 m 整除，依次取 m、2m、3m，再将余量加到最大数；最小和为 mk(k + 1)/2。
  • 允许重复会怎样？ 正偶数总额可以全部拆成 2，最多 S/2 项；互不相同的条件决定了这道题的结构。

四语言完整实现

Java

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Long> maximumEvenSplit(long finalSum) {
        List<Long> answer = new ArrayList<>();
        if (finalSum % 2 != 0) return answer;
        for (long x = 2; x <= finalSum; x += 2) {
            answer.add(x);
            finalSum -= x;
        }
        int last = answer.size() - 1;
        answer.set(last, answer.get(last) + finalSum);
        return answer;
    }
}

from typing import List

class Solution:
    def maximumEvenSplit(self, finalSum: int) -> List[int]:
        answer = []
        if finalSum % 2:
            return answer
        x = 2
        while x <= finalSum:
            answer.append(x)
            finalSum -= x
            x += 2
        answer[-1] += finalSum
        return answer

C++

#include <vector>
using std::vector;

class Solution {
public:
    vector<long long> maximumEvenSplit(long long finalSum) {
        vector<long long> answer;
        if (finalSum % 2 != 0) return answer;
        for (long long x = 2; x <= finalSum; x += 2) {
            answer.push_back(x);
            finalSum -= x;
        }
        answer.back() += finalSum;
        return answer;
    }
};
