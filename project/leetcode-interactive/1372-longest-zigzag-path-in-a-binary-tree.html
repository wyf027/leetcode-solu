二叉树中的最长交错路径

Longest ZigZag Path in a Binary Tree

先读题、动手走一遍，再按需展开底部题解。

Problem

题意

给定一棵以 root 为根的二叉树。可以从树中任意节点出发，并先选择向左或向右移动；每移动一条边后必须切换方向，如此反复，直到无法继续。这样的路径称为交错路径。

路径长度按经过的边数计算，也就是访问节点数减一；因此只有一个节点时长度为 0。请返回整棵树中最长交错路径的长度。

约束

  • 树中节点数在 [1, 5 × 10⁴] 范围内。
  • 1 ≤ Node.val ≤ 100。

Deep Dive

题解：后序 DFS + 树形 DP

状态要带方向

对每个节点记录两个值：从它出发，第一步向左或第一步向右时，最多能走多少条边。

方向必须翻转

如果第一步走左边，抵达左孩子后下一步必须向右；因此父状态依赖孩子的相反方向状态。

答案可能在任意处

最长路径不必经过根节点，所以处理每个节点时，都要用两个方向状态更新全局最大值。

状态转移与完整过程

令 leftStart(u) 表示从节点 u 出发且第一条边向左的最长交错路径长度，rightStart(u) 同理。空孩子无法贡献边，因此对应值为 0。

leftStart(u) = u.left ? 1 + rightStart(u.left) : 0 rightStart(u) = u.right ? 1 + leftStart(u.right) : 0 answer = max(answer, leftStart(u), rightStart(u))
  1. 用后序 DFS 先递归处理左右子树，取得左右孩子的两个方向状态。
  2. 根据“走一条边后必须换向”，计算当前节点的 leftStart 与 rightStart。
  3. 用当前两个值更新全局答案，再把这一对状态返回给父节点。
  4. 根节点处理完毕后，全局答案已经覆盖树中所有可能的起点。

正确性证明

引理：DFS 返回的 leftStart(u) 与 rightStart(u) 分别等于从 u 出发、第一步走相应方向的最长合法交错路径长度。

证明：对以 u 为根的子树高度归纳。若对应孩子为空，该方向无法走出边，状态为 0，结论成立。若左孩子存在，第一步向左必消耗一条边，此后根据交错规则只能从左孩子向右走；归纳假设保证该后缀最优长度为 rightStart(u.left)，故总长恰为 1 + rightStart(u.left)。向右情况完全对称。

定理：算法返回整棵树的最长交错路径。任意合法路径都有唯一的起点及第一步方向；处理该起点时，引理保证对应状态就是该方向的最优长度。算法对所有节点的两个状态取最大值，既不会漏掉任何路径，也不会计入非法路径，因此结果正确。

边界情况

  • 单节点树：两个方向长度都为 0，答案为 0。
  • 只有一侧的链：第一条边后若没有相反方向孩子，最长长度通常为 1。
  • 极度偏斜且节点数达到 5 × 10⁴：递归实现可能触发语言的调用栈限制，可改用显式栈做迭代后序遍历。
  • 节点值与路径长度无关；只使用树的结构。

复杂度

每个节点只处理一次，时间复杂度为 O(n)。除递归栈外只保存常数状态，额外空间为 O(h)，其中 h 是树高；最坏为 O(n)。

替代方案

也可以从每个节点分别尝试左右方向并继续交错，但若不复用状态，会重复遍历子树，最坏可能达到 O(n²)。另一种等价写法是自顶向下 DFS，把“上一条边方向”和当前累计长度传下去，并在同一节点重新以另一方向从长度 1 开始；它同样是 O(n)，但状态重置更容易写错。为规避深树递归风险，可用栈记录节点与访问阶段，完成迭代后序 DP。

面试追问

  • 如果要求返回具体路径而非长度，如何保存下一跳或端点并重建答案？
  • 如何把递归后序改成显式栈，以支持 5 × 10⁴ 层的偏斜树？
  • 如果允许连续两次同方向后再换向，状态应增加什么维度？
  • 能否用自顶向下写法保持同样的时间复杂度？它与自底向上状态如何对应？

常见错误

  • 把节点数当作长度，导致答案多 1；本题长度是边数。
  • 计算向左状态时继续读取左孩子的向左状态，没有切换方向。
  • 只返回根节点的最大值，遗漏起点位于子树内部的更长路径。
  • 对空孩子使用负数却忘记统一状态含义，造成叶子状态错误。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    private int answer = 0;

    public int longestZigZag(TreeNode root) {
        dfs(root);
        return answer;
    }

    // 返回 [从当前节点向左起步, 从当前节点向右起步]
    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0};

        int[] left = dfs(node.left);
        int[] right = dfs(node.right);
        int leftStart = node.left == null ? 0 : 1 + left[1];
        int rightStart = node.right == null ? 0 : 1 + right[0];

        answer = Math.max(answer, Math.max(leftStart, rightStart));
        return new int[]{leftStart, rightStart};
    }
}

        const left = dfs(node.left);
        const right = dfs(node.right);

        const rightStart = node.right === null ? 0 : 1 + right[0];

        answer = Math.max(answer, leftStart, rightStart);
        return [leftStart, rightStart];

    return answer;

            if node is None:

            left_start = 0 if node.left is None else 1 + left[1]
            right_start = 0 if node.right is None else 1 + right[0]

            return (left_start, right_start)

class Solution {
    int answer = 0;

    // 返回 {从当前节点向左起步, 从当前节点向右起步}
    pair<int, int> dfs(TreeNode* node) {
        if (node == nullptr) return {0, 0};

        auto left = dfs(node->left);
        auto right = dfs(node->right);
        int leftStart = node->left == nullptr ? 0 : 1 + left.second;
        int rightStart = node->right == nullptr ? 0 : 1 + right.first;

        answer = max({answer, leftStart, rightStart});
        return {leftStart, rightStart};
    }

public:
    int longestZigZag(TreeNode* root) {
        dfs(root);
        return answer;
    }
};
