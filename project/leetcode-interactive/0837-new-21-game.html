新 21 点 New 21 Game

先把随机抽牌过程看清楚：每一个分数都是一束概率流，抵达停止线后不再向后传播。试着操作演示，再决定是否展开完整题解。

MEDIUM数学动态规划滑动窗口概率与统计
Problem

题目

返回值允许误差 ≤ 10−5

规则转述

爱丽丝从 0 分开始。只要当前分数小于 k，她就独立、等概率地抽取一个 [1, maxPts] 内的整数并加到总分；总分达到或超过 k 后立即停止。

给定 n、k 与 maxPts，求她最终总分不超过 n 的概率。

参数形式

double new21Game(int n, int k, int maxPts)

过程中的三个区域

  1. 1继续区：score < k，到达这里的概率还会平均流向后续分数。
  2. 2成功停止区：k ≤ score ≤ n，计入答案。
  3. 3失败停止区：score > n，不计入答案。
Examples & Constraints

官方示例与约束

示例 1
输入：n = 10, k = 1, maxPts = 10
输出：1.00000
解释：只抽一次，所有可能分数都不超过 10。
示例 2
输入：n = 6, k = 1, maxPts = 10
输出：0.60000
解释：只抽一次，10 种等可能结果中有 6 种不超过 6。
示例 3
输入：n = 21, k = 17, maxPts = 10
输出：0.73278

约束

  • 0 ≤ k ≤ n ≤ 10⁴
  • 1 ≤ maxPts ≤ 10⁴

停止后的最大分数

最后一次抽取前最多为 k − 1，一次最多增加 maxPts，所以最终分数不会超过 k − 1 + maxPts。

Solution

动态规划 + 滑动窗口

核心洞察

dp[x] 表示游戏过程中“恰好到达分数 x”的概率。只有 x < k 的状态会继续抽取，因此它们才有资格向后传播概率。

若直接枚举每个 x 的至多 maxPts 个前驱，复杂度是 O(n · maxPts)。相邻的 x 所需前驱区间只移动一格，可以维护窗口和，把每个状态降到 O(1)。

dp[x] = (dp[x−1] + dp[x−2] + … + dp[x−maxPts]) / maxPts（仅统计下标 ≥ 0 且前驱分数 < k）

完整过程

  1. 初始化 dp[0] = 1，窗口和 windowSum = 1。
  2. 按分数 x = 1..n 递增计算：dp[x] = windowSum / maxPts。
  3. 若 x < k，它还会抽牌，把 dp[x] 加入窗口；否则它是停止状态，若 x ≤ n 就累加到答案。
  4. 把已经离开长度 maxPts 覆盖范围的 dp[x − maxPts] 移出窗口。
  5. 特殊情况：k = 0 时一开始就停止；或 n ≥ k − 1 + maxPts 时所有可能终点都成功，直接返回 1。

正确性证明

引理 1：计算 dp[x] 前，windowSum 恰好包含所有能够一步到达 x 的继续状态概率之和。初始化时对 x=1 成立；每轮加入尚可继续的当前状态，并移除距离超过 maxPts 的状态，因此归纳成立。

引理 2：dp[x] = windowSum / maxPts 是到达 x 的概率。每个合法前驱以相同概率 1/maxPts 抽到对应增量，且这些互斥路径的概率可以相加。

定理：算法返回最终分数不超过 n 的概率。所有停止状态恰为 x ≥ k；算法将其中 k ≤ x ≤ n 的到达概率各累加一次，既无遗漏也无重复，所以答案正确。

边界与复杂度

项目结论
k = 0无需抽牌，最终为 0；由约束 k ≤ n，答案为 1。
n ≥ k−1+maxPts最坏终点也不超过 n，答案为 1。
时间O(n)，每个分数只进出窗口一次。
空间O(n) 保存 dp；也可用长度 maxPts 的环形数组降为 O(maxPts)。

替代方案与取舍

朴素 DP：对每个分数枚举所有前驱，最直观但最坏需要 10⁸ 次转移，容易超时。

反向 DP：定义“从当前分数出发最终成功”的概率，也能用窗口从高分向低分计算；正确但边界更容易写错。

递归 + 记忆化：贴近游戏描述，却仍需对每个状态枚举抽牌结果，且有递归深度与常数开销。

面试追问

  • 为什么窗口中不能保留 x ≥ k 的状态？
  • 怎样把空间优化到 O(maxPts)？
  • 若每个点数不是等概率，滑动窗口还能否直接使用？
  • 为什么可以在 n ≥ k−1+maxPts 时提前返回 1？

常见错误

  • 把已停止状态重新加入窗口，等价于让爱丽丝越过停止线后继续抽牌。
  • 窗口移除下标差一位，混淆当前窗口与下一轮窗口。
  • 只累加到 n，却没有处理 k=0。
  • 用整数除法计算概率，或过早四舍五入。

四语言完整代码

class Solution {
    public double new21Game(int n, int k, int maxPts) {
        if (k == 0 || n >= k - 1 + maxPts) return 1.0;

        double[] dp = new double[n + 1];
        dp[0] = 1.0;
        double windowSum = 1.0;
        double answer = 0.0;

        for (int score = 1; score <= n; score++) {
            dp[score] = windowSum / maxPts;
            if (score < k) windowSum += dp[score];
            else answer += dp[score];

            int expired = score - maxPts;
            if (expired >= 0 && expired < k) {
                windowSum -= dp[expired];
            }
        }
        return answer;
    }
}
