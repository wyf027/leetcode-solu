子树中标签相同的节点数

Number of Nodes in the Sub-Tree With the Same Label

一棵以 0 为根的树，每个节点携带一个小写字母。你的任务是为每个节点回答：它自己的子树里，有多少节点与它拥有相同标签？

题目描述

给定一棵包含 n 个节点的树。节点编号为 0 到 n - 1，根为节点 0；数组 edges 恰有 n - 1 条无向边，edges[i] = [aᵢ, bᵢ] 表示两点相连。

长度为 n 的字符串 labels 给出节点标签，节点 i 的标签是 labels[i]。返回长度为 n 的数组 ans，其中 ans[i] 是节点 i 的子树中标签等于 labels[i] 的节点数。节点自身也属于自己的子树。

函数签名： countSubTrees(n, edges, labels) → int[]
示例 1
输入：
n = 7
edges = [[0,1],[0,2],[1,4],
         [1,5],[2,3],[2,6]]
labels = "abaedcd"

输出：
[2,1,1,1,1,1,1]

说明：
节点 0 与其子树中的节点 2
标签同为 a，因此计数为 2；
节点 1 的子树为 {1,4,5}，
只有节点 1 的标签为 b。
示例 2
输入：
n = 4
edges = [[0,1],[1,2],[0,3]]
labels = "bbbb"

输出：
[4,2,1,1]

说明：
所有标签均为 b。节点 0 的子树
包含 4 个节点，节点 1 的子树
包含节点 1 和 2。
示例 3
输入：
n = 5
edges = [[0,1],[0,2],
         [1,3],[0,4]]
labels = "aabab"

输出：
[3,2,1,1,1]

约束

  • 1 ≤ n ≤ 10⁵
  • edges.length = n - 1，且每条边恰含两个端点
  • 0 ≤ aᵢ, bᵢ < n，且 aᵢ ≠ bᵢ
  • labels.length = n，只包含小写英文字母
  • 输入保证构成一棵连通无环树

独立题解区

准备好再揭晓方法

题解默认收起，展开后包含推导、证明与四种语言实现。

核心洞察

父节点的子树，恰好由“父节点自身 + 各个孩子的子树”组成。因此每个节点向父节点上交一个长度 26 的频次数组；把所有孩子的数组逐项相加，再计入自身标签，就得到当前子树的完整标签分布。

答案只取分布中与当前节点标签对应的那一格。这是典型的后序树形 DP：必须先完成孩子，再结算父亲。

为什么使用迭代遍历

n 可达 10⁵，极深的链可能让部分语言的递归调用栈溢出。四份实现统一使用显式栈：第一次遍历记录父子关系与访问顺序，再逆序处理节点，从而得到后序效果。

完整过程

建图并定根。 将每条无向边加入邻接表，从 0 出发，用 parent 排除回边。
生成父先子后的顺序。 显式栈访问每个节点一次，并记录到 order。
逆序汇聚。 反向扫描 order；先把自身标签计数加一，再将本节点 26 格计数合并到父节点。
写入答案。 当前节点汇聚完成后，读取其自身标签对应的频次作为 ans[u]。

正确性证明

引理：逆序处理到节点 u 时，u 的每个孩子都已处理完成。因为正向顺序中父节点先于由它发现的孩子，所以逆序后孩子先于父节点。

归纳：叶节点没有孩子，计数数组只加入自身标签，准确描述其子树。假设每个孩子的数组都准确描述对应子树；这些孩子子树互不相交，且与 u 自身共同构成 u 的整棵子树。逐项相加并加入 u 后，u 的数组便准确描述其子树标签分布。

结论：根据结构归纳，所有节点的计数数组均正确；读取 labels[u] 对应频次，得到的正是题目要求的 ans[u]。

复杂度

建图与遍历为 O(n)，每个节点合并固定 26 格，总时间 O(26n)=O(n)。邻接表、父数组、顺序和计数表占 O(n) 空间。

边界

单节点答案为 1；链状树需避免递归栈风险；所有标签相同时，答案等于各自子树大小；所有标签不同时，每项都是 1。

替代方案

递归 DFS 更短，也可在返回时合并 26 格数组，但在深树上需确保足够的调用栈。还可使用进入/退出标记的单栈后序遍历。

常见错误

  • 无向图遍历未记录父节点，导致沿边来回访问。
  • 在孩子尚未汇聚完成前计算父节点答案，顺序颠倒。
  • 忘记把当前节点自身计入频次。
  • 为每个节点复制或扫描整棵子树，使复杂度退化为 O(n²)。
  • 递归实现未考虑 10⁵ 深度的链。

面试追问

如果字符集非常大？

用哈希表保存实际出现的标签；配合小表并入大表，可减少不必要的全字符集扫描。

如果标签会动态修改并频繁查询？

静态树形 DP 不再够用，可将子树映射到 Euler 序连续区间，再结合树状数组、线段树或离线查询处理。

import java.util.*;

class Solution {
    public int[] countSubTrees(int n, int[][] edges, String labels) {
        List<Integer>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : edges) {
            graph[edge[0]].add(edge[1]);
            graph[edge[1]].add(edge[0]);
        }

        int[] parent = new int[n];
        Arrays.fill(parent, -2);
        parent[0] = -1;
        int[] order = new int[n];
        int size = 0;
        ArrayDeque<Integer> stack = new ArrayDeque<>();
        stack.push(0);
        while (!stack.isEmpty()) {
            int u = stack.pop();
            order[size++] = u;
            for (int v : graph[u]) {
                if (v == parent[u]) continue;
                parent[v] = u;
                stack.push(v);
            }
        }

        int[][] count = new int[n][26];
        int[] answer = new int[n];
        for (int i = n - 1; i >= 0; i--) {
            int u = order[i];
            int label = labels.charAt(u) - 'a';
            count[u][label]++;
            answer[u] = count[u][label];
            if (parent[u] != -1) {
                for (int c = 0; c < 26; c++) {
                    count[parent[u]][c] += count[u][c];
                }
            }
        }
        return answer;
    }
}

var countSubTrees = function(n, edges, labels) {
    const graph = Array.from({ length: n }, () => []);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
    }

    const parent = new Int32Array(n);
    parent.fill(-2);
    parent[0] = -1;
    const order = [];
    const stack = [0];
    while (stack.length) {
        const u = stack.pop();
        order.push(u);
        for (const v of graph[u]) {
            if (v === parent[u]) continue;
            parent[v] = u;
            stack.push(v);
        }
    }

    const count = Array.from({ length: n }, () => new Int32Array(26));
    const answer = new Array(n).fill(0);
    for (let i = order.length - 1; i >= 0; i--) {
        const u = order[i];
        const label = labels.charCodeAt(u) - 97;
        count[u][label]++;
        answer[u] = count[u][label];
        const p = parent[u];
        if (p !== -1) {
            for (let c = 0; c < 26; c++) count[p][c] += count[u][c];
        }
    }
    return answer;
};
from typing import List

class Solution:
    def countSubTrees(
        self, n: int, edges: List[List[int]], labels: str
    ) -> List[int]:
        graph = [[] for _ in range(n)]
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)

        parent = [-2] * n
        parent[0] = -1
        order = []
        stack = [0]
        while stack:
            u = stack.pop()
            order.append(u)
            for v in graph[u]:
                if v == parent[u]:
                    continue
                parent[v] = u
                stack.append(v)

        count = [[0] * 26 for _ in range(n)]
        answer = [0] * n
        for u in reversed(order):
            label = ord(labels[u]) - ord("a")
            count[u][label] += 1
            answer[u] = count[u][label]
            p = parent[u]
            if p != -1:
                for c in range(26):
                    count[p][c] += count[u][c]
        return answer
#include <array>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> countSubTrees(
        int n, vector<vector<int>>& edges, string labels
    ) {
        vector<vector<int>> graph(n);
        for (const auto& edge : edges) {
            graph[edge[0]].push_back(edge[1]);
            graph[edge[1]].push_back(edge[0]);
        }

        vector<int> parent(n, -2), order, stack{0};
        parent[0] = -1;
        order.reserve(n);
        while (!stack.empty()) {
            int u = stack.back();
            stack.pop_back();
            order.push_back(u);
            for (int v : graph[u]) {
                if (v == parent[u]) continue;
                parent[v] = u;
                stack.push_back(v);
            }
        }

        vector<array<int, 26>> count(n);
        vector<int> answer(n);
        for (int i = n - 1; i >= 0; i--) {
            int u = order[i];
            int label = labels[u] - 'a';
            count[u][label]++;
            answer[u] = count[u][label];
            int p = parent[u];
            if (p != -1) {
                for (int c = 0; c < 26; c++) count[p][c] += count[u][c];
            }
        }
        return answer;
    }
};
