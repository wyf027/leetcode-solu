数组 · 队列 · 链表 · 设计

任务

设计并实现一个循环双端队列。构造时给出最大容量 k；队首、队尾都支持插入与删除。插入或删除无法执行时返回 false，查询空队列的首尾元素时返回 -1。

  • MyCircularDeque(int k)创建容量为 k 的双端队列。
  • insertFront(int value)向队首插入，成功返回 true。
  • insertLast(int value)向队尾插入，成功返回 true。
  • deleteFront()删除队首元素，成功返回 true。
  • deleteLast()删除队尾元素，成功返回 true。
  • getFront()返回队首元素；空队列返回 -1。
  • getRear()返回队尾元素；空队列返回 -1。
  • isEmpty()判断队列是否为空。
  • isFull()判断队列是否已满。

约束

  • 1 <= k <= 1000
  • 0 <= value <= 1000
  • 八类公开方法合计最多调用 2000 次。

方法签名以官方元数据为准；插入方法均接收完整参数 value。

Solution

环形数组 + front + size

核心洞察

用长度为 k 的数组保存元素，只维护队首下标 front 与当前元素数 size。下标越过数组边界时对 k 取模，于是数组首尾在逻辑上连接成环。队尾下标无需单独存储，可由现有状态推导。

队首位置front非空时直接读取。
队尾位置(front + size - 1) % k最后一个逻辑元素的位置。
队尾插入位(front + size) % k当前逻辑序列之后的位置。

完整过程

  1. 构造：分配长度为 k 的数组，令 front = 0、size = 0。
  2. 队首插入：若未满，先令 front = (front - 1 + k) % k，写入元素并增加 size。
  3. 队尾插入：若未满，写入 (front + size) % k，再增加 size。
  4. 队首删除：若非空，将 front 前移一格并减少 size。
  5. 队尾删除：若非空，只需减少 size；队尾由公式自动回退。
  6. 查询与判空/判满：使用 front、size 和容量直接判断。

边界处理

  • 空队列：删除失败，首尾查询返回 -1。
  • 满队列：两种插入均失败，不改变任何状态。
  • 容量为 1：同一个槽位同时是队首和队尾。
  • 向前绕回：front - 1 可能为负，先加 k 再取模。
  • 删除至空：front 无需复位；下一次插入仍可从当前环位置继续。

正确性说明

表示不变式。任意时刻，逻辑上第 i 个元素都存放在 (front + i) % k，其中 0 <= i < size。
插入保持不变式。队首插入把 front 逆时针移动一格，新值成为第 0 个元素，旧元素的逻辑序号统一加 1；队尾插入恰好写入 i = size 的位置。两者增加 size 后都满足表示不变式。
删除保持不变式。队首删除将 front 移到原第 1 个元素，剩余元素逻辑序号减 1；队尾删除只缩小有效区间，前面的映射不变。
查询正确。由不变式，第一个元素位于 front，最后一个位于 (front + size - 1) % k；空队列先被显式拦截。因此所有操作均符合双端队列语义。

复杂度与替代方案

方案单次操作空间取舍
环形数组（本解）O(1)O(k)连续内存、常数小；容量固定，最贴合题意。
双向链表O(1)O(k)首尾操作直观，但每个节点有额外指针与分配开销；仍需记录容量。
普通动态数组队首操作最坏 O(k)O(k)实现简单，但队首插入/删除会搬移元素，不满足理想复杂度。

class MyCircularDeque {
    private final int[] data;
    private final int capacity;
    private int front;
    private int size;

    public MyCircularDeque(int k) {
        data = new int[k];
        capacity = k;
        front = 0;
        size = 0;
    }

    public boolean insertFront(int value) {
        if (isFull()) return false;
        front = (front - 1 + capacity) % capacity;
        data[front] = value;
        size++;
        return true;
    }

    public boolean insertLast(int value) {
        if (isFull()) return false;
        int index = (front + size) % capacity;
        data[index] = value;
        size++;
        return true;
    }

    public boolean deleteFront() {
        if (isEmpty()) return false;
        front = (front + 1) % capacity;
        size--;
        return true;
    }

    public boolean deleteLast() {
        if (isEmpty()) return false;
        size--;
        return true;
    }

    public int getFront() {
        return isEmpty() ? -1 : data[front];
    }

    public int getRear() {
        if (isEmpty()) return -1;
        return data[(front + size - 1) % capacity];
    }

    public boolean isEmpty() {
        return size == 0;
    }

    public boolean isFull() {
        return size == capacity;
    }
}

常见错误

  • 用 front == rear 同时表示空与满，却没有额外状态进行区分。
  • 队首插入直接计算 (front - 1) % k，在部分语言里得到负数下标。
  • 队尾读取使用 front + size，误读到了下一个插入位置。
  • 失败的插入/删除仍修改了 front 或 size。
  • 为简化逻辑分配 k + 1 个槽，却没有清楚解释容量与判满条件。
