Course Schedule

先修关系构成有向图。每次选择一门入度为 0的课完成，并让它解锁后续课程；如果最终能取走全部课程，图就没有环。

🧭 Kahn 拓扑排序 · 入度队列

题意

有 numCourses 门课，编号从 0 到 numCourses - 1。prerequisites[i] = [a, b] 表示想上课 a 前必须先修 b。能否修完所有课程？

官方样例 1numCourses = 2 prerequisites = [[1, 0]]

0 → 1，先选 0 可解锁 1。期望输出：true。

官方样例 2numCourses = 2 prerequisites = [[1, 0], [0, 1]]

0 与 1 互相等待，期望输出：false。

约束：1 ≤ numCourses ≤ 2000，0 ≤ prerequisites.length ≤ 5000，每对关系唯一。

入度清零调度台

准备：把所有入度为 0 的课程放进队列。

测试与验证

数组的空格保留为常规代码格式；若输入含空格，会以 ␠ 作为可见符号说明。输入、期望输出和实际输出彼此独立。

页面验证

Prettier、HTML Validate 和内联 JavaScript 语法：通过。交互、键盘、390px 与控制台检查由主流程真实 Chrome 执行。

算法验证

题解保持折叠，先观察解锁链条。

题解：Kahn 拓扑排序

核心洞察

有环时，环中的所有节点都至少还有一个来自环内的先修边，永远不会出现入度 0。反过来，如果逐步删除所有入度 0 节点后计数正好是课程总数，便能完成。

完整过程

  1. 建立 prerequisite → course 邻接表和每门课的入度。
  2. 把所有入度 0 课程放进队列。
  3. 弹出一门课程，计数加一，并让相邻课程入度减一；新为 0 的课程入队。
  4. 比较已完成计数与 numCourses。

边界

没有先修关系时全部课程一开始都可选；自环是立即无法完成；不连通的多个子图要同时初始化各自的入度 0 节点。

复杂度与替代方案

建图和队列扫描均为 O(V+E)，空间 O(V+E)。替代方案是 DFS 三色标记：访问中再次访问表示环；Kahn 法更直观地给出可修的顺序。

面试追问

若要返回一个课程顺序，记录每次出队顺序即可（对应第 210 题）。如果出现重复边，需要明确是否应当重复增加入度；本题保证关系对唯一。

常见错误

把 [a,b] 的方向建反；只从节点 0 开始；入度降至 0 却忘记入队；只看队列是否为空而不比较完成数量。

class Solution {
    public boolean canFinish(int n, int[][] pre) {
        List<List<Integer>> g = new ArrayList<>();
        int[] deg = new int[n];
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] p : pre) { g.get(p[1]).add(p[0]); deg[p[0]]++; }
        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 0; i < n; i++) if (deg[i] == 0) q.offer(i);
        int done = 0;
        while (!q.isEmpty()) { int u = q.poll(); done++; for (int v : g.get(u)) if (--deg[v] == 0) q.offer(v); }
        return done == n;
    }
}
var canFinish = function(numCourses, prerequisites) {
  const graph = Array.from({ length: numCourses }, () => []), deg = Array(numCourses).fill(0);
  for (const [course, pre] of prerequisites) { graph[pre].push(course); deg[course]++; }
  const queue = []; for (let i = 0; i < numCourses; i++) if (deg[i] === 0) queue.push(i);
  let head = 0; while (head < queue.length) for (const next of graph[queue[head++]]) if (--deg[next] === 0) queue.push(next);
  return head === numCourses;
};
from collections import deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: list[list[int]]) -> bool:
        graph = [[] for _ in range(numCourses)]
        degree = [0] * numCourses
        for course, prerequisite in prerequisites:
            graph[prerequisite].append(course)
            degree[course] += 1
        queue = deque(i for i in range(numCourses) if degree[i] == 0)
        done = 0
        while queue:
            course = queue.popleft(); done += 1
            for nxt in graph[course]:
                degree[nxt] -= 1
                if degree[nxt] == 0: queue.append(nxt)
        return done == numCourses
class Solution {
public:
    bool canFinish(int n, vector<vector<int>>& pre) {
        vector<vector<int>> graph(n); vector<int> deg(n);
        for (auto& p : pre) { graph[p[1]].push_back(p[0]); ++deg[p[0]]; }
        queue<int> q; for (int i = 0; i < n; ++i) if (!deg[i]) q.push(i);
        int done = 0;
        while (!q.empty()) { int u = q.front(); q.pop(); ++done; for (int v : graph[u]) if (--deg[v] == 0) q.push(v); }
        return done == n;
