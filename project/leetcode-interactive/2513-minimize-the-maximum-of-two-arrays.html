2513 · 最小化两个数组中的最大值

Minimize the Maximum of Two Arrays

两份数组，一组互不重叠的正整数。让它们都满足限制，并把最大的数字压到尽可能小。

题目说明

给定四个整数 divisor1、divisor2、uniqueCnt1、uniqueCnt2，向最初为空的两个数组中选择正整数：

  • arr1 恰好有 uniqueCnt1 个不同的数，且每个数都不能被 divisor1 整除。
  • arr2 恰好有 uniqueCnt2 个不同的数，且每个数都不能被 divisor2 整除。
  • 两个数组也不能共享任何元素。

返回所有合法选择中，两个数组的最大元素的最小可能值。只返回这个整数，不要求返回数组。

约束

  • 2 ≤ divisor1, divisor2 ≤ 10⁵
  • 1 ≤ uniqueCnt1, uniqueCnt2 < 10⁹
  • 2 ≤ uniqueCnt1 + uniqueCnt2 ≤ 10⁹

题解实验室

计数 · 可行性 · 最小边界

核心洞察：查容量，无需构造数组

假设最大元素不超过 x。候选数字是 [1,x]。令 L = lcm(divisor1, divisor2)，可行性等价于三个条件同时成立：

A = x - floor(x / divisor1) ≥ uniqueCnt1
B = x - floor(x / divisor2) ≥ uniqueCnt2
U = x - floor(x / L) ≥ uniqueCnt1 + uniqueCnt2

前两项保证各数组单独有足够候选；第三项保证候选的并集足够大，避免共享数字被重复计算。两边都不能用的数字恰好是 L 的倍数。

完整过程
  1. 使用欧几里得算法计算最大公约数，再求 L = divisor1 / gcd × divisor2，用宽整数存放。
  2. 令总需求 S = uniqueCnt1 + uniqueCnt2。在闭区间 [S, 2S] 中查找答案。
  3. 取向下取整的中点 mid，计算 A、B、U。三项都够，则令 right = mid；否则令 left = mid + 1。
  4. 直到 left == right，返回这个最小可行上限。
为什么 2S 一定可行？
除数和 L 都至少为 2。在 [1,2S] 中，每个单独候选集以及候选并集都至少有 S 个数，三项条件必然满足。下界 S 来自两个数组合计需要 S 个不同正整数。
示例 3 的二分轨迹
[10,20] → mid=15 → A=8, B=12, U=12 → 可行，right=15
[10,15] → mid=12 → A=6, B=9,  U=9  → 不可行，left=13
[13,15] → mid=14 → A=7, B=11, U=11 → 不可行，left=15

正确性证明
1. 三个条件必要
arr1 的选择只能来自 A 集合，arr2 只能来自 B 集合，所以各自容量不能小于需求。两数组不能重叠，它们合计 S 个数必须位于 A∪B 中，因此并集容量也必须不少于 S。
2. 三个条件充分
把候选分成仅 A 可用的 p 个数、仅 B 可用的 q 个数、两边可用的 c 个数，以及两边都不可用的数。先尽量给每组使用自己的专属候选，剩余需求分别为 r1=max(0,n1-p)、r2=max(0,n2-q)。
若两个剩余需求都大于 0，则 r1+r2=n1+n2-p-q≤c，这由并集条件保证。若仅一个为正，它不超过 c，由相应单组条件保证。若都为 0 则已经完成。因此共享池总能提供足够的互不重复数字，得到合法分配。
3. 二分找到最小值
增大 x 只会增加候选数字，可行性单调不减。初始区间包含答案且右端可行；中点可行时保留它和左半区，不可行时排除所有不大于中点的值。区间严格缩小，收敛值就是最小可行值。


边界与复杂度
  • 除数相同：候选完全重合，并集条件尤其关键。
  • 一个除数整除另一个：L 等于较大除数，不可误用乘积。
  • L 大于 x：floor(x/L)=0，没有同时禁用的数。
  • L 最大可接近 10¹⁰：Java/C++ 使用 64 位整数。JavaScript 的 Number 在本题范围内能精确表示所需整数；不要用位运算代替取整。
  • 时间 O(log min(d1,d2) + log S)，每次判定 O(1)；额外空间 O(1)。可视化保存轨迹和展示格子，不属于提交算法空间。
常见错误
  • 只检查 A、B：如 d1=d2=2、n1=n2=1，x=1 对两边都够，却无法分给两组。
  • 把并集写成“两边都不能整除的数量”：那是交集，误删了专属候选。
  • 把所有倍数都排除：某个数组禁用的数，可能恰好是另一组的专属资源。
  • 把 0 计入候选：题目只允许正整数。
  • 可行时写成 right=mid−1 后仍用闭区间收敛模板，容易丢失正确答案。


替代方案与面试追问
直接反解容量：对 d≥2、k≥1，满足 x-floor(x/d)≥k 的最小 x 是 f(k,d)=k+floor((k-1)/(d-1))。因为每 d 个整数中只有 d−1 个可用，按完整块计数即可得到第 k 个非倍数的位置。因此答案也可直接写为 max(f(n1,d1), f(n2,d2), f(S,L))，总时间只剩计算 gcd 的复杂度。下面四语言统一展示较易推广的二分方案。
另一种判定：用专属池和共享池，检查 max(0,n1-p)+max(0,n2-q)≤c，与三个容量条件等价。
  • 如果要求返回数组？ 在最小上限内先分专属候选，再分共享候选；显式输出至少需要 Ω(S) 时间与输出空间。
  • 如果变成三个数组？ 单组加总并集不再充分，还要考虑任意两组的联合需求；可借助 Hall 条件或流模型分析。
  • 为什么不用暴力枚举上限？ 上限可能接近 2×10⁹，逐个枚举无法应对规模。

Java
class Solution {
    private long gcd(long a, long b) {
        while (b != 0) {
            long t = a % b;
            a = b;
            b = t;
        }
        return a;
    }

    public int minimizeSet(int divisor1, int divisor2,
                           int uniqueCnt1, int uniqueCnt2) {
        long lcm = (long) divisor1 / gcd(divisor1, divisor2) * divisor2;
        long sum = (long) uniqueCnt1 + uniqueCnt2;
        long left = sum, right = 2 * sum;
        while (left < right) {
            long mid = left + (right - left) / 2;
            if (mid - mid / divisor1 >= uniqueCnt1
                    && mid - mid / divisor2 >= uniqueCnt2
                    && mid - mid / lcm >= sum) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return (int) left;
    }
}

/**
 * @param {number} divisor1
 * @param {number} divisor2

var minimizeSet = function(divisor1, divisor2, uniqueCnt1, uniqueCnt2) {
    let a = divisor1, b = divisor2;
    while (b !== 0) {
        [a, b] = [b, a % b];
    }
    const lcm = divisor1 / a * divisor2;
    const sum = uniqueCnt1 + uniqueCnt2;
    let left = sum, right = 2 * sum;
    while (left < right) {
        const mid = left + Math.floor((right - left) / 2);
        if (mid - Math.floor(mid / divisor1) >= uniqueCnt1
            && mid - Math.floor(mid / divisor2) >= uniqueCnt2
            && mid - Math.floor(mid / lcm) >= sum) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left;
};

class Solution:
    def minimizeSet(self, divisor1: int, divisor2: int,
                    uniqueCnt1: int, uniqueCnt2: int) -> int:
        lcm = divisor1 // gcd(divisor1, divisor2) * divisor2
        total = uniqueCnt1 + uniqueCnt2
        left, right = total, 2 * total
        while left < right:
            mid = (left + right) // 2
            if (mid - mid // divisor1 >= uniqueCnt1
                    and mid - mid // divisor2 >= uniqueCnt2
                    and mid - mid // lcm >= total):
                right = mid
            else:
                left = mid + 1
        return left

#include <numeric>

class Solution {
public:
    int minimizeSet(int divisor1, int divisor2,
                    int uniqueCnt1, int uniqueCnt2) {
        long long lcm = 1LL * divisor1 / std::gcd(divisor1, divisor2)
                        * divisor2;
        long long sum = 1LL * uniqueCnt1 + uniqueCnt2;
        long long left = sum, right = 2 * sum;
        while (left < right) {
            long long mid = left + (right - left) / 2;
            if (mid - mid / divisor1 >= uniqueCnt1
                && mid - mid / divisor2 >= uniqueCnt2
                && mid - mid / lcm >= sum) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        return static_cast<int>(left);
    }
};
