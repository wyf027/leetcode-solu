二叉树寻路

在编号方向逐层翻转的无限满二叉树里，从目标标号逆向追踪至根节点。先观察规律，再展开完整题解。

树数学二叉树Path In Zigzag Labelled Binary Tree

题目

一棵无限满二叉树逐行编号。奇数层从左到右递增，偶数层从右到左递增，形成“之”字形。给定节点标号 label，返回从根节点到它的路径上所有标号。

函数签名

pathInZigZagTree(label: integer) → integer[]

约束

  • 1 ≤ label ≤ 10⁶

官方示例

示例 1 输入：label = 14 输出：[1,3,4,14]
示例 2 输入：label = 26 输出：[1,2,6,10,26]

层号从 1 开始。相邻两层的编号方向相反，但每层占用的数值区间仍是连续的。

交互实验：镜像后再找父节点

输入 1–31 内的标号以观察前五层。高亮将从目标逐步回到根；这里只展示机制，不提前给出通用实现。

完整题解

核心洞察：第 d 层的普通顺序编号范围是 [2^(d-1), 2^d-1]。同层镜像标号之和恒为区间两端之和。把当前之字形标号镜像成普通标号，再除以 2，就得到父节点对应的位置；合并后可直接写成 parent = (lo + hi - label) / 2。

完整过程

  1. 用 floor(log2(label)) 定位目标所在的零基层 level。
  2. 将当前标号加入答案尾部。
  3. 当前层边界是 lo = 2^level、hi = 2^(level+1)-1。
  4. 当前标号的同层镜像是 lo + hi - label；它在普通编号树中的父节点为镜像值除以 2。
  5. 逐层重复直至根节点，最后反转收集结果。

正确性证明

引理 1

同一层两端为 lo、hi，某普通位置标号 x 的之字形镜像标号为 lo+hi-x。

引理 2

普通顺序编号中，节点 x 的父节点编号必为 floor(x/2)。

结论

每轮公式都得到当前节点真实父节点的之字形标号。循环逐层上移且终于根，反转后正是根到目标的唯一路径。

边界与复杂度

  • label = 1 时循环只记录根。
  • 层边界均用整数幂计算；题目上限下不会触及常见 32 位整数风险。
  • 时间复杂度 O(log label)；除返回数组外额外空间 O(1)。

替代方案

可以先根据层数显式把奇偶层的标号转换成普通编号，沿普通父链上溯，再逐层转换回来。它同样是 O(log label)，但状态更多；合并后的镜像公式更简洁。

面试追问

  • 若根层从右向左编号，公式是否变化？层内镜像关系不变，只需重新定义方向约定。
  • 为什么不需要构造树？路径长度只有对数级，标号的位数已经编码了层级。
  • 如何避免浮点对数误差？可用循环右移或语言提供的最高位位置函数求层数。

常见错误

  • 直接使用 label / 2，忽略偶数层反向编号。
  • 混淆一基层号与零基指数，导致边界整体偏一层。
  • 忘记反转逆向收集的答案。
  • 镜像公式少写一端：必须是 lo + hi - label。

四语言实现

class Solution {
    public List<Integer> pathInZigZagTree(int label) {
        LinkedList<Integer> path = new LinkedList<>();
        int level = 31 - Integer.numberOfLeadingZeros(label);
        while (label >= 1) {
            path.addFirst(label);
            int lo = 1 << level;
            int hi = (1 << (level + 1)) - 1;
            label = (lo + hi - label) / 2;
            level--;
        }
        return path;
    }
}

var pathInZigZagTree = function(label) {
    const path = [];
    let level = Math.floor(Math.log2(label));
    while (label >= 1) {
        path.push(label);
        const lo = 2 ** level;
        const hi = 2 ** (level + 1) - 1;
        label = Math.floor((lo + hi - label) / 2);
        level--;
    }
    return path.reverse();
};

class Solution:

            path.append(label)
