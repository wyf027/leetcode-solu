先看清放映清单

给定 Cinema 表，每一行记录一部电影。请报告 ID 为奇数且描述不等于 boring 的电影，并将结果按评分从高到低排列。

任务转述

结果需要保留原表的四列：id、movie、description、rating。筛选条件必须同时满足，最后再决定输出顺序。

输出要求
仅返回合格影片；评分更高的记录排在更前面。
  • id 是主键，每个值唯一。
  • rating 位于 [0, 10]，精确到小数点后两位。
  • 每行包含电影名、描述（类型）与评分。

04 · Solution

准备好看完整题解了吗？

建议先自己写出筛选条件与排序方向，再展开对照。题解默认收起，不影响独立思考。

Core insight

一次筛选，一次排序

这是一道典型的单表查询：用 WHERE 同时约束奇数 ID 与非 boring 描述，再用 ORDER BY 决定结果顺序。两个筛选条件之间是逻辑与（AND），任何一个不满足都不能进入结果集。

FILTER 01奇偶判断
MOD(id, 2) = 1
FILTER 02排除描述
description <> 'boring'
ORDER评分降序
rating DESC

完整过程

  1. 从 Cinema 读取题目要求输出的四列。
  2. 保留 id 除以 2 余数为 1 的记录。
  3. 在这些记录中继续排除 description = 'boring' 的记录。
  4. 对最终结果按 rating 从高到低排序。

正确性说明

  1. 第一条谓词只允许奇数 ID 通过，因此输出中不会出现偶数 ID。
  2. 第二条谓词排除描述严格等于 boring 的记录，因此每条输出记录的描述都满足要求。
  3. 两条谓词用 AND 连接，所以输出记录同时满足题目的两个条件；反之，任何同时满足条件的记录都会被保留，不会遗漏。
  4. ORDER BY rating DESC 将保留下来的记录按评分非递增排列，因此输出顺序符合题意。

边界情况

  • 没有记录同时满足条件时，结果为空。
  • 全部记录都满足条件时，只执行评分降序排列。
  • 多个评分相同时，题目没有指定它们之间的次序；如业务需要稳定顺序，可再追加 id ASC，但本题无需擅自增加。
  • SQL 的字符串比较通常受数据库排序规则影响；本题按给定字面值 boring 判断。

复杂度

过滤：O(n) 排序：O(k log k) 结果空间：O(k)

其中 n 是输入行数，k 是筛选后行数。数据库执行计划可能借助索引优化，但题目未给出索引条件。

可提交 SQL 与四语言本地语义参考

本题是数据库题，MySQL 查询才是官方可提交形式。Java、JavaScript、Python、C++ 代码仅在本地用集合模拟相同的“筛选 + 排序”语义，不能直接提交到该 SQL 题。

官方提交语言：MySQL

SELECT id, movie, description, rating
FROM Cinema
WHERE MOD(id, 2) = 1
  AND description <> 'boring'
ORDER BY rating DESC;

本地语义参考：用 List 模拟数据表

import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

public class NotBoringMovies {
    public record Movie(
        int id,
        String movie,
        String description,
        double rating
    ) {}

    public static List<Movie> notBoringMovies(List<Movie> cinema) {
        List<Movie> result = new ArrayList<>();

        for (Movie row : cinema) {
            if (row.id() % 2 != 0
                    && !"boring".equals(row.description())) {
                result.add(row);
            }
        }

        result.sort(
            Comparator.comparingDouble(Movie::rating).reversed()
        );
        return result;
    }
}

本地语义参考：输入为对象数组

/**
 * @param {{id:number, movie:string,
 *   description:string, rating:number}[]} cinema
 * @returns {{id:number, movie:string,
 *   description:string, rating:number}[]}
 */
function notBoringMovies(cinema) {
  return cinema
    .filter((row) =>
      row.id % 2 !== 0 && row.description !== "boring"
    )
    .slice()
    .sort((a, b) => b.rating - a.rating);
}

本地语义参考：dataclass 列表；官方也支持 Pandas

from dataclasses import dataclass
from typing import Iterable, List

@dataclass(frozen=True)
class Movie:
    id: int
    movie: str
    description: str
    rating: float

def not_boring_movies(cinema: Iterable[Movie]) -> List[Movie]:
    selected = [
        row
        for row in cinema
        if row.id % 2 == 1 and row.description != "boring"
    ]
    return sorted(
        selected,
        key=lambda row: row.rating,
        reverse=True,
    )

本地语义参考：vector 模拟数据表

#include <algorithm>
#include <string>
#include <vector>
using namespace std;

struct Movie {
    int id;
    string movie;
    string description;
    double rating;
};

vector<Movie> notBoringMovies(const vector<Movie>& cinema) {
    vector<Movie> result;

    for (const Movie& row : cinema) {
        if (row.id % 2 != 0 && row.description != "boring") {
            result.push_back(row);
        }
    }

    sort(result.begin(), result.end(),
         [](const Movie& a, const Movie& b) {
             return a.rating > b.rating;
         });
    return result;
}

替代方案

  • 位运算：某些数据库可用 id & 1 = 1 判断奇数，但可移植性不如 MOD。
  • 取余运算符：可写 id % 2 = 1，但不同 SQL 方言支持度不同。
  • 子查询：先筛选再外层排序也能得到结果，但这里没有必要增加层级。

面试追问

  • 若 description 允许 NULL，是否要把它视为“不等于 boring”？
  • 评分相同时如何得到完全确定的顺序？
  • 数据量很大时，筛选列和排序列应如何设计索引？
  • 如何改写为返回每个评分区间的合格影片数量？

常见错误

  • 把两个条件写成 OR，导致只满足其中一项的记录也被保留。
  • 使用 id % 2 = 0，误选了偶数 ID。
  • 漏写引号，把 boring 当成列名。
  • 写成 ORDER BY rating 而漏掉 DESC，默认得到升序。
  • 用 NOT LIKE '%boring%' 扩大了语义；题目只要求不等于精确值 boring。
