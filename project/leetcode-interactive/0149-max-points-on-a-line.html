直线上最多的点数 斜率观测站

固定一个锚点，向其余点发射射线；把方向向量约成唯一整数对，相同键就代表落在同一条直线上。

任务边界

输入互不相同的平面点 points，返回同一直线上的最大点数。点数 1～300，坐标范围 -10⁴～10⁴。

Problem / 题意

用整数方向表示斜率

给定二维点集 points，求最多有多少点共线。固定锚点 i，枚举 j > i，计算 dx 与 dy；用 gcd 约分并统一符号后，以 "dy/dx" 作为哈希键，出现次数最多的方向再加上锚点本身。

官方示例 1
points = [[1,1],[2,2],[3,3]]

输出：3

官方示例 2
points = [[1,1],[3,2],[5,3],[4,1],[2,3],[1,4]]

输出：4

关键边界
points = [[0,0]]

输出：1

核心洞察

不用浮点数：约分方向向量

浮点斜率存在精度与正负零问题。对每个锚点，把 (dy, dx) 同除以 gcd，并强制 dx 为正；垂直线统一为 (1,0)，水平线统一为 (0,1)。这样相同直线方向拥有完全相同的哈希键。

完整过程

  1. 少于 3 个点时直接返回点数。
  2. 依次选择每个点作为锚点，清空斜率计数表。
  3. 计算 dy、dx，gcd 约分并统一符号。
  4. 更新当前方向计数与全局最大值。

边界与复杂度

  • 题目保证点互不相同，无需统计重合点。
  • 垂直、水平和负斜率必须规范到唯一键。
  • 时间 O(n² log C)，空间 O(n)。

替代方案取舍

枚举两点再检查所有点需要 O(n³)；浮点斜率哈希写法短却有精度风险。整数 gcd 归一化是面试最稳妥的主线。

常见错误

  • 直接用 double 作为键，近似值可能分桶错误。
  • (1,1) 与 (-1,-1) 没有统一符号。
  • 忘记给斜率桶计数加上锚点本身。
  • 跨锚点复用计数表，混合了不同直线。

面试追问

为什么不需要截距？固定锚点后，相同方向唯一确定一条直线。
如何剪枝？当前答案不小于剩余点数时可结束外层循环。
如何处理垂直线？令 dx=0 时统一方向为 (1,0)。 
class Solution {
    public int maxPoints(int[][] points) {
        int n = points.length, answer = Math.min(n, 2);
        for (int i = 0; i < n; i++) {
            Map<String, Integer> count = new HashMap<>();
            for (int j = i + 1; j < n; j++) {
                int dx = points[j][0] - points[i][0];
                int dy = points[j][1] - points[i][1];
                int g = gcd(Math.abs(dx), Math.abs(dy));
                dx /= g; dy /= g;
                if (dx < 0 || (dx == 0 && dy < 0)) {
                    dx = -dx; dy = -dy;
                }
                String key = dy + "/" + dx;
                answer = Math.max(answer, count.merge(key, 1, Integer::sum) + 1);
            }
        }
        return answer;
    }

    private int gcd(int a, int b) {
        while (b != 0) { int t = a % b; a = b; b = t; }
        return a;
    }
}
var maxPoints = function (points) {
  const gcd = (a, b) => {
    while (b !== 0) [a, b] = [b, a % b];
    return a;
  };
  let answer = Math.min(points.length, 2);
  for (let i = 0; i < points.length; i++) {
    const count = new Map();
    for (let j = i + 1; j < points.length; j++) {
      let dx = points[j][0] - points[i][0];
      let dy = points[j][1] - points[i][1];
      const g = gcd(Math.abs(dx), Math.abs(dy));
      dx /= g; dy /= g;
      if (dx < 0 || (dx === 0 && dy < 0)) {
        dx = -dx; dy = -dy;
      }
      const key = `${dy}/${dx}`;
      const next = (count.get(key) ?? 0) + 1;
      count.set(key, next);
      answer = Math.max(answer, next + 1);
    }
  }
  return answer;
};
