    04 / SQL solution

    题解默认上锁

    洞察、过程、边界、复杂度、方言代码与面试追问都在这里。

    Solution unlocked

    去重后只取第 N 行

    DISTINCT 决定名次， ORDER BY DESC 决定方向， OFFSET N - 1 决定目标楼层。

    核心洞察与完整过程

    1. 从 Employee 读取薪资列。
    2. 用 DISTINCT 合并重复薪资。
    3. 按 salary DESC 从高到低排列。
    4. 第 N 高之前恰有 N - 1 个不同值，因此 OFFSET N - 1。
    5. LIMIT 1 取目标；外层标量子查询让“无行”成为 NULL。

    主线复杂度与索引

    设表有 m 行、不同薪资数为 k。一般排序实现时间为 O(m + k log k)，排序/去重工作空间约 O(k)。数据库执行计划受统计信息与索引影响； salary 上的索引可能减少排序或扫描成本，但不改变题目语义。

    边界与替代方案

    • 空表或不同薪资少于 N 档：返回 NULL。
    • 重复薪资：必须去重，不能按员工行计名次。
    • 官方函数契约把 N 视为正整数；生产代码可另行防御 N ≤ 0。
    • DENSE_RANK() 更直观且便于扩展到同时展示所有排名，但会给每行计算窗口值。
    • 相关子查询可数出“比当前薪资高的不同值个数”，兼容老版本数据库，但通常更难读。

    数据库方言实现

    这是 Database 题。下面给 MySQL 主提交、三个等价 SQL 方言和官方 Pandas 提交；Java、JavaScript、C++ 不是本题的 LeetCode 提交语言，因此不伪装成可提交答案。 

    CREATE FUNCTION getNthHighestSalary(N INT) RETURNS INT
BEGIN
  DECLARE offset_rows INT;
  SET offset_rows = N - 1;

  RETURN (
    SELECT (
      SELECT DISTINCT salary
      FROM Employee
      ORDER BY salary DESC
      LIMIT 1 OFFSET offset_rows
    )
  );
END
    CREATE OR REPLACE FUNCTION NthHighestSalary(N INT)
RETURNS TABLE (Salary INT) AS $$
BEGIN
  RETURN QUERY (
    SELECT MAX(ranked.salary)::INT
    FROM (
      SELECT DISTINCT e.salary
      FROM Employee AS e
      ORDER BY e.salary DESC
      OFFSET (N - 1) LIMIT 1
    ) AS ranked
  );
END;
$$ LANGUAGE plpgsql;
    CREATE FUNCTION dbo.getNthHighestSalary(@N INT)
RETURNS INT
AS
BEGIN
  DECLARE @result INT;

  SELECT @result = salary
  FROM (SELECT DISTINCT salary FROM Employee) AS d
  ORDER BY salary DESC
  OFFSET (@N - 1) ROWS FETCH NEXT 1 ROWS ONLY;

  RETURN @result;
END;
    CREATE OR REPLACE FUNCTION getNthHighestSalary(N IN NUMBER)
RETURN NUMBER
IS
  result NUMBER;
BEGIN
  SELECT MAX(salary)
  INTO result
  FROM (
    SELECT salary,
           DENSE_RANK() OVER (ORDER BY salary DESC) AS salary_rank
    FROM Employee
  )
  WHERE salary_rank = N;

  RETURN result;
END;

    import pandas as pd

def nth_highest_salary(employee: pd.DataFrame, N: int) -> pd.DataFrame:
    column = f"getNthHighestSalary({N})"
    salaries = employee["salary"].drop_duplicates().sort_values(ascending=False)
    value = salaries.iloc[N - 1] if N > 0 and len(salaries) >= N else None
    return pd.DataFrame({column: [value]})

    常见错误

    • 漏掉 DISTINCT，让重复薪资占多个名次。
    • 写 OFFSET N，产生一位偏移错误。
    • 无结果时返回零行，而不是标量 NULL。
    • 在 MySQL LIMIT 中直接使用不被接受的表达式，未先声明变量。
