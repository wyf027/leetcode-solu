1361 / MEDIUM验证二叉树

给你的不是一棵现成的树，而是一组“父节点 → 子节点”关系。任务是审查：它们是否恰好拼成一棵完整、唯一、无环的二叉树。

先理解结构是否合法，再决定如何遍历。页面首屏只呈现问题与实验入口；完整解法藏在文末。

Problem

题目说明

01

你需要判断什么？

有 n 个节点，编号为 0 到 n - 1。节点 i 的左、右子节点分别由 leftChild[i] 和 rightChild[i] 给出；值为 -1 表示对应孩子不存在。

当且仅当所有给定节点能够共同构成恰好一棵有效二叉树时返回 true，否则返回 false。节点没有额外的值，仅使用编号。

!
“恰好一棵”是关键。
不能有两个根、不能让一个节点有两个父节点、不能成环，也不能留下与根断开的节点。

参数与约束

validateBinaryTreeNodes(n, leftChild, rightChild) → boolean

  • n == leftChild.length == rightChild.length
  • 1 <= n <= 104
  • -1 <= leftChild[i], rightChild[i] <= n - 1

Core insight

把二叉树条件拆成两道闸门

04
∴
一棵包含全部节点的有效树 = 唯一父节点关系 + 从唯一根可达全部节点。
先统计入度，排除多父节点并找唯一根；再从根遍历，排除环与断开的分量。

扫描所有孩子

遇到非 -1 的孩子就将其入度加一。任意入度超过 1，立即返回 false。

锁定唯一根

入度为 0 的节点必须恰好有一个。没有根通常意味着成环；多个根意味着不止一个连通分量。

从根遍历

用队列访问左右孩子。若重复访问则存在环；最后访问数必须等于 n。

Correctness

正确性证明

05

充分性

若算法返回 true，恰有一个入度为 0 的根，其他节点不会有多个父节点；从根又访问了全部 n 个节点且无重复。因此所有节点连通、无环，并且每个非根节点恰有一个父节点，父子关系构成一棵二叉树。

必要性

若给定结构确实是一棵包含全部节点的二叉树，则根的入度为 0 且唯一，每个非根节点的入度恰为 1。由树的连通性，从根能够且只会访问每个节点一次，所以算法一定返回 true。

Edges & cost

边界与复杂度

06
O(n)

时间：每个左右孩子关系扫描一次，每个节点最多入队一次。

O(n)

空间：入度数组、访问数组和最坏情况下的 BFS 队列。

必须照顾的边界

  • n = 1 且两个孩子均为 -1：唯一节点就是根。
  • 同一个孩子出现在不同父节点下，或同时成为某节点的左右孩子：入度超过 1。
  • 所有节点入度都为 1：不存在根，通常形成环。
  • 存在唯一根但另有封闭环：从根访问数小于 n。
  • 多个入度为 0 的节点：结构被拆成多棵树。

import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public boolean validateBinaryTreeNodes(
            int n, int[] leftChild, int[] rightChild) {
        int[] indegree = new int[n];

        for (int parent = 0; parent < n; parent++) {
            int[] children = {leftChild[parent], rightChild[parent]};
            for (int child : children) {
                if (child == -1) continue;
                if (++indegree[child] > 1) return false;
            }
        }

        int root = -1;
        for (int node = 0; node < n; node++) {
            if (indegree[node] == 0) {
                if (root != -1) return false;
                root = node;
            }
        }
        if (root == -1) return false;

        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(root);
        visited[root] = true;
        int count = 0;

        while (!queue.isEmpty()) {
            int parent = queue.poll();
            count++;
            int[] children = {leftChild[parent], rightChild[parent]};
            for (int child : children) {
                if (child == -1) continue;
                if (visited[child]) return false;
                visited[child] = true;
                queue.offer(child);
            }
        }
        return count == n;
    }
}
/**
 * @param {number} n
 * @param {number[]} leftChild
 * @param {number[]} rightChild
 * @return {boolean}
 */
var validateBinaryTreeNodes = function(n, leftChild, rightChild) {
    const indegree = new Array(n).fill(0);

    for (let parent = 0; parent < n; parent++) {
        for (const child of [leftChild[parent], rightChild[parent]]) {
            if (child === -1) continue;
            indegree[child]++;
            if (indegree[child] > 1) return false;
        }
    }

    const roots = [];
    for (let node = 0; node < n; node++) {
        if (indegree[node] === 0) roots.push(node);
    }
    if (roots.length !== 1) return false;

    const visited = new Array(n).fill(false);
    const queue = [roots[0]];
    visited[roots[0]] = true;
    let head = 0;

    while (head < queue.length) {
        const parent = queue[head++];
        for (const child of [leftChild[parent], rightChild[parent]]) {
            if (child === -1) continue;
            if (visited[child]) return false;
            visited[child] = true;
            queue.push(child);
        }
    }
    return queue.length === n;
};
from collections import deque
from typing import List


class Solution:
    def validateBinaryTreeNodes(
        self,
        n: int,
        leftChild: List[int],
        rightChild: List[int],
    ) -> bool:
        indegree = [0] * n

        for parent in range(n):
            for child in (leftChild[parent], rightChild[parent]):
                if child == -1:
                    continue
                indegree[child] += 1
                if indegree[child] > 1:
                    return False

        roots = [node for node in range(n) if indegree[node] == 0]
        if len(roots) != 1:
            return False

        root = roots[0]
        queue = deque([root])
        visited = [False] * n
        visited[root] = True
        count = 0

        while queue:
            parent = queue.popleft()
            count += 1
            for child in (leftChild[parent], rightChild[parent]):
                if child == -1:
                    continue
                if visited[child]:
                    return False
                visited[child] = True
                queue.append(child)

        return count == n

Alternatives

替代方案与取舍

08

入度 + BFS / DFS

语义最直接：入度验证父节点唯一性，遍历验证连通性与无环。容易证明，也方便定位失败原因。

并查集

把每条父子边看作连接操作；若两端已经连通则出现环，同时仍需检查孩子入度与最终只有一个连通分量。可行，但状态更多。

Interview follow-ups

面试追问

09
为什么“边数等于 n - 1”还不够？

边数只是必要条件。仍可能存在一个环和一个断开的分量，合计边数依然是 n - 1。还要验证唯一根、父节点唯一性和整体可达。

只检查入度与唯一根，能否省掉遍历？

不能。可能有一个合法根所在的小树，外加一个所有节点入度均为 1 的封闭环；全局仍只有一个入度为 0 的节点，却没有覆盖全部节点。

BFS 能换成 DFS 吗？

可以。两者的时间与辅助空间量级相同。递归 DFS 在 n = 10^4 时需要留意语言的递归深度，因此迭代 BFS 更稳妥。

Pitfalls

常见错误

10
  • 把节点 0 默认当根；题目没有保证根的编号。
  • 只找唯一根，不检查某个孩子是否被多个父节点指向。
  • 只防重复访问，却忘记确认最终访问数是否为 n。
  • 将 -1 当作节点下标参与入度统计。
  • 用 Array.shift() 实现 JavaScript 大队列，造成不必要的移动开销；应使用头指针。
