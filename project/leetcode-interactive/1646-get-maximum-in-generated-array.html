获取生成数组中的最大值

Get Maximum in Generated Array — 从一对种子数字出发，按照下标的奇偶规则逐项生成数组，最后返回其中的最大值。

简单数组模拟0 ≤ n ≤ 100
01 / 题目

生成规则

给定整数 n，生成一个长度为 n + 1、下标从 0 开始的整数数组 nums：

  • nums[0] = 0
  • 当 n ≥ 1 时，nums[1] = 1
  • 若 2 ≤ 2 × i ≤ n，则 nums[2 × i] = nums[i]
  • 若 2 ≤ 2 × i + 1 ≤ n，则 nums[2 × i + 1] = nums[i] + nums[i + 1]

返回生成数组 nums 中的最大整数。

函数签名

getMaximumGenerated(n: integer): integer

约束

0 ≤ n ≤ 100

输入只有一个整数 n；输出同样是一个整数。

05 / 题解

准备好核对你的思路了吗？

题解默认收起。建议先操作上方生长台，尝试用一句话概括偶数下标与奇数下标的来源。

SOLUTION

一次从左到右的模拟

核心洞察

规则已经直接定义了每个位置的值。生成下标 i 时，它依赖的下标约为 i / 2，一定比 i 小，因此从左到右计算即可；同时维护最大值，无需第二次扫描。

完整过程

  1. 若 n = 0，数组只有 [0]，直接返回 0。
  2. 创建长度为 n + 1 的数组，写入种子 nums[0] = 0、nums[1] = 1。
  3. 依次处理 i = 2…n。若 i 为偶数，复制 nums[i / 2]；若为奇数，相加 nums[⌊i / 2⌋] 与 nums[⌊i / 2⌋ + 1]。
  4. 每生成一项就更新最大值，循环结束后返回它。

正确性证明

初始化：算法写入的 nums[0] 和 nums[1] 与定义一致。

归纳步骤：假设下标小于 i 的项均正确。若 i 为偶数，算法取 nums[i/2]；若为奇数，取 nums[⌊i/2⌋] + nums[⌊i/2⌋+1]。这些来源下标都小于 i，由归纳假设值正确，故生成的 nums[i] 也正确。

最大值：变量 answer 在每一步都等于已生成前缀的最大值。处理完 0…n 后，它就是整个数组的最大值。

复杂度

时间 O(n)空间 O(n)每个位置只计算一次

边界情况

  • n = 0 时不能写入 nums[1]，应直接返回 0。
  • n = 1 时答案为 1，无需进入循环。
  • 奇数下标使用相邻的两个来源，第二项是 ⌊i/2⌋ + 1。
  • 约束上界很小，但线性模拟对整个范围都适用。

替代方案

可以先完整生成数组，再单独扫描最大值；仍是 O(n) 时间和 O(n) 空间，但多一次遍历。也可以分别枚举原定义里的 i 并写入 2i 与 2i+1，不过按目标下标顺序更直观，也更不容易漏掉边界。

由于后续位置依赖多个旧值，若不保留数组就难以稳定取得所需来源；这里不强求 O(1) 空间。

class Solution {
    public int getMaximumGenerated(int n) {
        if (n == 0) return 0;

        int[] nums = new int[n + 1];
        nums[1] = 1;
        int answer = 1;

        for (int i = 2; i <= n; i++) {
            if (i % 2 == 0) {
                nums[i] = nums[i / 2];
            } else {
                nums[i] = nums[i / 2] + nums[i / 2 + 1];
            }
            answer = Math.max(answer, nums[i]);
        }
        return answer;
    }
}

常见错误

  • 没有先处理 n = 0，导致访问越界。
  • 把目标下标 i 与原规则中的来源下标混淆。
  • 计算奇数位置时漏加右侧来源 nums[i/2 + 1]。
  • 循环写成 i < n，遗漏最后一个元素。
  • 初始化最大值为 1，却忘记 n 可能为 0。

面试追问
