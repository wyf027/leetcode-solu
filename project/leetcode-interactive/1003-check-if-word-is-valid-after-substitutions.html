检查替换后的词是否有效

Check If Word Is Valid After Substitutions
栈字符串非付费题

题目

从空字符串 t = "" 开始，每次可以在任意位置插入字符串 "abc"。给定只含 a、b、c 的字符串 s，判断能否经过任意次这种插入得到 s。

函数：isValid(s: string): boolean

官方示例

输入：s = "aabcbc" 输出：true 解释："" → "abc" → "aabcbc"
输入：s = "abcabcababcc" 输出：true 解释：可依次插入四个 "abc" 得到该字符串。
输入：s = "abccba" 输出：false 解释：无法通过规定操作得到该字符串。

约束

  • 1 ≤ s.length ≤ 2 × 10⁴
  • s 只由 'a'、'b'、'c' 组成。

消除实验室

逐字符入栈；栈顶形成 abc 时立即消除。先观察，再决定是否查看题解。

题解：用栈模拟逆向消除

核心洞察

与其猜每次把 abc 插在哪里，不如反向操作：只要字符串中出现连续的 abc 就删除。用栈扫描时，任何刚形成的新 abc 一定在栈顶，因此无需反复全串搜索。

完整过程

  1. 准备空栈。
  2. 从左到右把字符压栈。
  3. 若栈顶三个字符依次为 a,b,c，弹出这三个字符。
  4. 扫描结束后，栈为空则有效，否则无效。

正确性

不变式：处理完任意输入前缀后，栈保存的内容等价于对该前缀反复删除可删除的 abc 后的剩余串。

新字符加入后，旧栈内部已经没有待消除结构；唯一可能新出现的 abc 必然以新字符结尾，即位于栈顶，算法恰好将其删除。不变式因此保持。最终为空，说明原串能完全逆向删除，也就能从空串正向插入得到；不为空则至少有内容无法由插入操作产生。

边界与复杂度

  • 长度不是 3 的倍数时最终不会清空。
  • abc、嵌套结构如 aabcbc 均可自然处理。
  • 时间复杂度 O(n)，空间复杂度 O(n)。

替代方案

可以循环查找并替换 abc，但频繁移动字符串最坏可能达到 O(n²)。也可用字符数组加栈顶指针，把额外分配降到一次。

面试追问

  • 若模式串从 abc 变成长串，如何匹配栈顶？可比较后缀，或结合 KMP 状态。
  • 能否原地做？在可变字符数组中用写指针模拟栈。
  • 为什么删除顺序不影响结论？栈算法给出了一个确定且完备的删除序列。

常见错误

  • 只统计 a/b/c 数量相同，忽略顺序与嵌套关系。
  • 遇到一个 c 只检查前两个输入字符，而不是当前未消除栈顶。
  • 重复使用字符串替换导致超时。

四语言完整实现

class Solution {
    public boolean isValid(String s) {
        char[] stack = new char[s.length()];
        int top = 0;
        for (char ch : s.toCharArray()) {
            stack[top++] = ch;
            if (top >= 3 && stack[top - 3] == 'a'
                    && stack[top - 2] == 'b' && stack[top - 1] == 'c') {
                top -= 3;
            }
        }
        return top == 0;
    }
}

var isValid = function(s) {
    const stack = [];

        stack.push(ch);
        const n = stack.length;
        if (n >= 3 && stack[n - 3] === 'a' &&
            stack[n - 2] === 'b' && stack[n - 1] === 'c') {
            stack.length -= 3;
        }
    }
    return stack.length === 0;
};

class Solution {
public:
    bool isValid(string s) {
        string stack;
        for (char ch : s) {
            stack.push_back(ch);
            int n = stack.size();
            if (n >= 3 && stack[n - 3] == 'a' &&
                stack[n - 2] == 'b' && stack[n - 1] == 'c') {
                stack.resize(n - 3);
            }
        }
        return stack.empty();
    }
};
