二叉搜索树迭代器 II

Binary Search Tree Iterator II

先想一想：普通中序迭代器只向前走；如果允许后退，哪些状态必须被保留下来？先操作可视化，再按需展开题解。

题目

请实现 BSTIterator，它表示一棵二叉搜索树的中序遍历迭代器。游标开始时位于序列第一个元素之前。

  • BSTIterator(TreeNode root)：用 BST 根节点初始化迭代器。
  • boolean hasNext()：游标右侧还有元素时返回 true。
  • int next()：向右移动一位，并返回该位置的值。
  • boolean hasPrev()：游标左侧还有元素时返回 true。
  • int prev()：向左移动一位，并返回该位置的值。

题目保证调用 next() 或 prev() 时，对应移动一定有效。

官方示例

输入：
["BSTIterator","next","next","prev","next","hasNext","next","next","next","hasNext","hasPrev","prev","prev"]
[[[7,3,15,null,null,9,20]],[null],[null],[null],[null],[null],[null],[null],[null],[null],[null],[null],[null]]

输出：
[null,3,7,3,7,true,9,15,20,false,true,15,9]

树的中序序列为 [3, 7, 9, 15, 20]。例如两次 next() 到达 7，随后 prev() 回到 3，再次 next() 又到达 7。

约束

  • 树中节点数在 [1, 10⁵] 范围内。
  • 0 ≤ Node.val ≤ 10⁶。
  • hasNext、next、hasPrev 和 prev 总调用次数不超过 10⁵。

进阶：不要在初始化时预先计算整棵树的中序序列。

题解：懒加载中序遍历 + 历史缓存

核心洞察

BST 的中序遍历天然有序。只向前时，用一个栈保存“下一批可能访问的节点”即可；允许向后时，还要保存已经返回过的值。于是将状态拆成三部分：

  • stack：尚未发现的中序节点前沿。
  • values：已经发现、曾可到达的有序历史。
  • index：当前游标在 values 中的位置，初始为 -1。
关键分支：next() 若走向缓存中的旧位置，只移动下标；只有越过缓存末尾时，才从栈中懒加载一个新节点。

完整过程

  1. 构造时把从根到最左节点的整条链压栈；不遍历其他节点。
  2. hasNext()：缓存右侧有值，或者遍历栈非空，即可向右。
  3. next()：下标先加一。若进入尚未发现的位置，弹出栈顶节点、写入缓存，再把其右子树的左链压栈；返回缓存当前值。
  4. hasPrev()：当前下标大于 0 时，左侧存在前一个值。
  5. prev()：下标减一，返回缓存当前值。

正确性说明

不变式一：缓存始终是整棵树中序序列的一个前缀。初始化与每次压入右子树左链后，栈顶都是尚未发现节点中的最小者；因此每次新加入缓存的节点恰好是中序序列的下一个节点。

不变式二：index 始终指向最后一次移动后的位置。向缓存内部前进或后退只改变一位；越过末尾时恰好追加一个下一个中序值。故 next() 和 prev() 都返回定义要求的位置。

两个不变式共同说明，所有四种操作的布尔判断与返回值都正确。

边界情况

  • 只有一个节点：初始可 next，到达后既不可前进也不可后退。
  • 完全倾斜树：栈最多达到树高，逻辑不依赖平衡性。
  • 反复 prev → next：再次前进直接读取缓存，绝不重复展开树节点。
  • 值可为 0 或 10⁶；算法只保存与返回值，不做算术。

复杂度

构造耗时 O(h)、占用 O(h) 栈空间。每个树节点只进栈和出栈一次，因此新节点相关的 next() 摊还 O(1)；缓存内的 next()、prev() 和两个判断均为 O(1)。若一共发现 k 个值，总空间为 O(h + k)，最坏为 O(n)。

替代方案

  • 预先完整中序遍历：初始化 O(n)，之后所有操作 O(1)；实现最简单，但不满足“不预计算”的进阶要求。
  • 维护当前节点到根的路径：可以尝试求后继与前驱，空间靠近 O(h)；状态切换更复杂，单次操作可能为 O(h)，反复折返时也更难保证简洁的摊还界。

面试追问

  • 为什么只缓存“值”就够？因为接口只返回整数；若接口要返回节点，应缓存节点引用。
  • 如果树在迭代期间会修改怎么办？当前设计假设树不变；可选择快照语义、版本检测，或定义并发修改异常。
  • 如何支持跳过多步？在缓存内可直接改下标；越过已发现边界时仍需逐个懒加载。

常见错误

  • 把 hasNext() 只写成“栈非空”，漏掉游标右侧已有缓存的情形。
  • prev() 后再次 next() 时重新访问树，导致重复值。
  • 误写 hasPrev() 为 index ≥ 0；当前值本身不是“前一个值”，正确条件是 index > 0。
  • 弹出节点后忘记把其右子树的左链压栈。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class BSTIterator {
    private final Deque<TreeNode> stack = new ArrayDeque<>();
    private final List<Integer> values = new ArrayList<>();
    private int index = -1;

    public BSTIterator(TreeNode root) {
        pushLeft(root);
    }

    public boolean hasNext() {
        return index + 1 < values.size() || !stack.isEmpty();
    }

    public int next() {
        index++;
        if (index == values.size()) {
            TreeNode node = stack.pop();
            values.add(node.val);
            pushLeft(node.right);
        }
        return values.get(index);
    }

    public boolean hasPrev() {
        return index > 0;
    }

    public int prev() {
        index--;
        return values.get(index);
    }

    private void pushLeft(TreeNode node) {
        while (node != null) {
            stack.push(node);
            node = node.left;
        }
    }
}
/**
 * @param {TreeNode} root
 */
var BSTIterator = function(root) {
  this.stack = [];
  this.values = [];
  this.index = -1;
  this.pushLeft(root);
};

BSTIterator.prototype.pushLeft = function(node) {
  while (node !== null) {
    this.stack.push(node);
    node = node.left;
  }
};

BSTIterator.prototype.hasNext = function() {
  return this.index + 1 < this.values.length || this.stack.length > 0;
};

BSTIterator.prototype.next = function() {
  this.index += 1;
  if (this.index === this.values.length) {
    const node = this.stack.pop();
    this.values.push(node.val);
    this.pushLeft(node.right);
  }
  return this.values[this.index];
};

BSTIterator.prototype.hasPrev = function() {
  return this.index > 0;
};

BSTIterator.prototype.prev = function() {
  this.index -= 1;
  return this.values[this.index];
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class BSTIterator:
    def __init__(self, root: Optional[TreeNode]):
        self.stack = []
        self.values = []
        self.index = -1
        self._push_left(root)

    def _push_left(self, node: Optional[TreeNode]) -> None:
        while node:
            self.stack.append(node)
            node = node.left

    def hasNext(self) -> bool:
        return self.index + 1 < len(self.values) or bool(self.stack)

    def next(self) -> int:
        self.index += 1
        if self.index == len(self.values):
            node = self.stack.pop()
            self.values.append(node.val)
            self._push_left(node.right)
        return self.values[self.index]

    def hasPrev(self) -> bool:
        return self.index > 0

    def prev(self) -> int:
        self.index -= 1
        return self.values[self.index]
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class BSTIterator {
private:
    stack<TreeNode*> pending;
    vector<int> values;
    int index = -1;

    void pushLeft(TreeNode* node) {
        while (node != nullptr) {
            pending.push(node);
            node = node->left;
        }
    }

public:
    BSTIterator(TreeNode* root) {
        pushLeft(root);
    }

    bool hasNext() {
        return index + 1 < static_cast<int>(values.size()) || !pending.empty();
    }

    int next() {
        ++index;
        if (index == static_cast<int>(values.size())) {
            TreeNode* node = pending.top();
            pending.pop();
            values.push_back(node->val);
            pushLeft(node->right);
        }
        return values[index];
    }

    bool hasPrev() {
        return index > 0;
    }

    int prev() {
        --index;
        return values[index];
    }
};
