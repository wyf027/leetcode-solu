和可被 K 整除的子数组

Subarray Sums Divisible by K

中等数组哈希表前缀和

题目

给定整数数组 nums 和整数 k，返回元素和可被 k 整除的非空连续子数组数量。子数组是原数组中连续的一段。

示例 1
输入：nums = [4,5,0,-2,-3,1], k = 5
输出：7
解释：符合条件的子数组是
[4,5,0,-2,-3,1]、[5]、[5,0]、
[5,0,-2,-3]、[0]、[0,-2,-3]、[-2,-3]
示例 2
输入：nums = [5], k = 9
输出：0

约束

  • 1 ≤ nums.length ≤ 3 × 10⁴
  • -10⁴ ≤ nums[i] ≤ 10⁴
  • 2 ≤ k ≤ 10⁴

题解：前缀和同余计数

核心洞察

令前缀和为 P[i]。区间 (j,i] 的和能被 k 整除，当且仅当 P[i] % k = P[j] % k。所以当前余数过去出现几次，就新增几个答案。

完整过程

  1. 创建 k 个余数频次，令 count[0]=1 表示空前缀。
  2. 扫描元素并更新前缀和。
  3. 用 ((sum % k)+k)%k 规范负余数。
  4. 先把相同余数频次加入答案，再增加该频次。

正确性

对每个右端点 i，算法枚举的是所有余数与当前前缀相同的旧前缀 j。模运算保证这些且仅有这些 j 对应和可被 k 整除的子数组；每个区间有唯一端点对，因此不重不漏。

边界与复杂度

  • 预置空前缀，否则漏掉从下标 0 开始的区间。
  • 负数取模必须规范化。
  • 时间 O(n)，空间 O(k)。

替代方案

枚举全部区间即使用前缀和仍需 O(n²)，无法覆盖最大数据。k 特别大时可用哈希表保存出现过的余数。

四语言完整代码

class Solution {
    public int subarraysDivByK(int[] nums, int k) {
        int[] count = new int[k]; count[0] = 1;
        int sum = 0, answer = 0;
        for (int x : nums) {
            sum += x;
            int r = ((sum % k) + k) % k;
            answer += count[r]++;
        }
        return answer;
    }
}

class Solution:
    def subarraysDivByK(self, nums: List[int], k: int) -> int:
        count = [0] * k
        count[0] = 1
        total = answer = 0
        for x in nums:
            total += x
            r = total % k
            answer += count[r]
            count[r] += 1
        return answer

面试追问

  • 目标余数不是 0 时，两个前缀余数如何匹配？
  • 数据流持续到达时怎样在线更新答案？
  • 为何频次更新必须放在答案累加之后？

常见错误

  • 忘记 count[0]=1。
  • 把当前前缀先加入频次，错误计入空子数组。
  • 在 Java、JavaScript、C++ 中直接使用负余数下标。
