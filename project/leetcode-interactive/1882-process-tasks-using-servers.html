使用服务器处理任务

Process Tasks Using Servers

一秒一个新任务。忙碌的服务器，等待中的队列，下一项该交给谁？

阅读规则进入调度台测试与验证

01 / 任务说明

按到达顺序，为任务选择空闲服务器

输入两个从 0 开始编号的数组：servers 长度为 n，元素是对应服务器的权重；tasks 长度为 m，元素是对应任务的处理时长（秒）。服务器权重只决定选择优先级，不影响处理速度。

  1. 初始所有服务器空闲。任务 j 在第 j 秒到达；待处理任务按照到达顺序排队。
  2. 只要队列非空且存在空闲服务器，就将队首任务分配给权重最小的空闲服务器；权重相同时，选择下标最小的。
  3. 没有空闲服务器时等待下一次释放。同一时刻释放的服务器都可以参加本轮分配；积压任务仍按下标递增顺序分配，可以有多个任务同时开始。
  4. 若任务 j 在 t 秒开始处理，则服务器在 t + tasks[j] 秒恢复空闲，并能立即承接新任务。

返回长度为 m 的数组 ans，其中 ans[j] 是处理任务 j 的服务器下标。

约束与函数形式

  • servers.length == n，tasks.length == m
  • 1 ≤ n, m ≤ 2 × 10⁵
  • 1 ≤ servers[i], tasks[j] ≤ 2 × 10⁵
assignTasks(servers: integer[], tasks: integer[]) → integer[]

05 / 独立题解
准备好解释你的调度策略了吗？
先思考：选服务器与等待服务器，需要的是同一种排序吗？




双优先队列 + 事件驱动


核心洞察
任务顺序已固定，无需另建真实任务队列。遍历下标 j 就是在取队首。服务器却有两种不同的排序需求：空闲时按 (权重, 下标) 选最优；忙碌时按 (结束时间, 下标) 找下一次释放。用两个最小堆分别维护它们。
忙碌堆的同时间次序不需要按权重排序，因为每次选服务器前，所有结束时间 ≤ 当前时间的服务器都会转入空闲堆，由空闲堆统一裁决。


完整过程
  1. 将所有服务器放入空闲堆，忙碌堆为空，当前时间 t=0。
  2. 遍历任务 j，令 t = max(t, j)，既不回到过去，也不在任务到达前处理它。
  3. 将忙碌堆中所有结束时间 ≤ t 的服务器取出，放回空闲堆。
  4. 若空闲堆为空，将 t 跳到忙碌堆顶的结束时间，再释放所有结束时间 ≤ t 的服务器。
  5. 弹出空闲堆顶的服务器 i，记录 ans[j] = i，并将 (t + tasks[j], i) 加入忙碌堆。
例：servers=[2,1]、tasks=[3,2,1,1]。前两项分别在 0、1 秒启动，均在 3 秒结束。任务 2 到达时无空闲服务器，时间跳到 3；两台一起释放，权重更小的服务器 1 先接任务 2，随后服务器 0 在同一秒接任务 3。结果为 [1,0,1,0]。


正确性论证
不变式：分配每项任务前，释放步骤结束后，空闲堆恰好包含 t 时刻所有可用服务器；忙碌堆包含其余服务器，结束时间均大于 t。已分配任务的顺序与下标顺序一致。
初始所有服务器空闲，不变式成立。任务 j 只有在 j 秒或之后才能开始；若当时有空闲服务器，马上分配就是最早可行时刻。否则忙碌堆顶给出最早释放时刻，在此之前不存在可用服务器，跳到该时刻仍满足“尽可能早”。
释放全部到期服务器后，空闲堆顶恰好是权重最小、同权重下下标最小的候选。将它移入忙碌堆并设置正确结束时间，恢复不变式。按 j 归纳，每次分配都符合题目规则，因此返回数组正确。


复杂度与数值边界
逐个插入初始化时，时间复杂度为 O((n + m) log(n + 1))。每项任务至多导致一次忙碌堆入堆、出堆及空闲堆出入；两个堆中的服务器总数始终为 n。Python 的 heapify 初始化为 O(n)，总时间为 O(n + m log(n + 1))。
辅助空间 O(n)，输出占 O(m)，合计 O(n+m)。只有一台服务器时，累计时间可达 200000 × 200000 = 40,000,000,000：Java 使用 long，C++ 使用 long long，Python 整数与 JavaScript Number 在本题范围内可精确表示。


边界与常见错误
  • 释放条件是 ≤ t，不能写成 < t：结束瞬间即可承接新任务。
  • 同一时刻释放多台时必须全部移入空闲堆；仅取忙碌堆顶可能错过权重更小的服务器。
  • 时间不能每轮重置为 j：积压任务的实际开始时刻可能远大于到达时刻。
  • 服务器权重相等时比较下标；结果存下标而不是权重。
  • 一台服务器、大量积压、每项时长为 1 都应遵守同一逻辑，不需要特殊分支。
  • 分配结束即可返回答案，不必等最后一项任务真正执行完毕。


替代方案
扫描所有服务器也能找到当前最优空闲服务器，或在全部忙碌时求最早结束时间；其 O(nm) 时间适合小数据规则演示，无法应对 2×10⁵ 规模。逐秒模拟还会受累计时间影响。另一种双堆写法可在无空闲时直接取按“结束时间、权重、下标”排序的忙碌堆顶，但平局规则更容易写错；本页采用先批量释放再选择的统一流程。


面试追问
  • 任务不按固定秒数到达？使用给定到达时间替代 j；如输入未排序，需先按到达时间及约定顺序组织任务。
  • 需要输出等待时间？分配时记录 t - j；完成时间为 t + tasks[j]。
  • 允许抢占或服务器动态变更权重？当前不变式依赖任务不可抢占与权重固定；需要增加状态版本或可更新的优先队列，并重新定义中断及剩余时间规则。
  • 为什么不按处理时长挑任务？题目要求 FIFO；更短任务也不能越过队首。

Java
import java.util.PriorityQueue;

class Solution {
    public int[] assignTasks(int[] servers, int[] tasks) {
        PriorityQueue<Integer> idle = new PriorityQueue<>((a, b) -> {
            int c = Integer.compare(servers[a], servers[b]);
            return c != 0 ? c : Integer.compare(a, b);
        });
        // [finishTime, index]; ties need not use weight:
        // all finished servers move to idle before selection.
        PriorityQueue<long[]> busy = new PriorityQueue<>((a, b) -> {
            int c = Long.compare(a[0], b[0]);
            return c != 0 ? c : Long.compare(a[1], b[1]);
        });
        for (int i = 0; i < servers.length; i++) idle.offer(i);
        int[] ans = new int[tasks.length];
        long time = 0;
        for (int j = 0; j < tasks.length; j++) {
            time = Math.max(time, (long) j);
            while (!busy.isEmpty() && busy.peek()[0] <= time)
                idle.offer((int) busy.poll()[1]);
            if (idle.isEmpty()) {
                time = busy.peek()[0];
                while (!busy.isEmpty() && busy.peek()[0] <= time)
                    idle.offer((int) busy.poll()[1]);
            }
            int i = idle.poll();
            ans[j] = i;
            busy.offer(new long[]{time + tasks[j], i});
        }
        return ans;
    }
}


JavaScript
class MinHeap {
    constructor(less) { this.a = []; this.less = less; }
    get size() { return this.a.length; }
    peek() { return this.a[0]; }
    push(x) {
        const a = this.a;
        a.push(x);
        let i = a.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (!this.less(a[i], a[p])) break;
            [a[i], a[p]] = [a[p], a[i]];
            i = p;
        }
    }
    pop() {
        const a = this.a, root = a[0], last = a.pop();
        if (a.length) {
            a[0] = last;
            let i = 0;
            while (true) {
                let k = i, l = i * 2 + 1, r = l + 1;
                if (l < a.length && this.less(a[l], a[k])) k = l;
                if (r < a.length && this.less(a[r], a[k])) k = r;
                if (k === i) break;
                [a[i], a[k]] = [a[k], a[i]];
                i = k;
            }
        }
        return root;
    }
}
/**
 * @param {number[]} servers
 * @param {number[]} tasks
 * @return {number[]}
 */
var assignTasks = function(servers, tasks) {
    // idle: [weight, index]; busy: [finishTime, index]
    const idle = new MinHeap((a,b) => a[0] < b[0] ||
        (a[0] === b[0] && a[1] < b[1]));
    const busy = new MinHeap((a,b) => a[0] < b[0] ||
        (a[0] === b[0] && a[1] < b[1]));
    servers.forEach((w,i) => idle.push([w,i]));
    const ans = [];
    let time = 0;
    for (let j = 0; j < tasks.length; j++) {
        time = Math.max(time, j);
        while (busy.size && busy.peek()[0] <= time) {
            const [,i] = busy.pop();
            idle.push([servers[i],i]);
        }
        if (!idle.size) {
            time = busy.peek()[0];
            while (busy.size && busy.peek()[0] <= time) {
                const [,i] = busy.pop();
                idle.push([servers[i],i]);
            }
        }
        const [,i] = idle.pop();
        ans.push(i);
        busy.push([time + tasks[j],i]);
    }
    return ans;
};


Python 3
from typing import List
import heapq

class Solution:
    def assignTasks(self, servers: List[int], tasks: List[int]) -> List[int]:
        idle = [(weight, i) for i, weight in enumerate(servers)]
        heapq.heapify(idle)
        busy = []  # (finish_time, index)
        ans = []
        time = 0
        for j, duration in enumerate(tasks):
            time = max(time, j)
            while busy and busy[0][0] <= time:
                _, i = heapq.heappop(busy)
                heapq.heappush(idle, (servers[i], i))
            if not idle:
                time = busy[0][0]
                while busy and busy[0][0] <= time:
                    _, i = heapq.heappop(busy)
                    heapq.heappush(idle, (servers[i], i))
            _, i = heapq.heappop(idle)
            ans.append(i)
            heapq.heappush(busy, (time + duration, i))
        return ans


C++
#include <vector>
#include <queue>
#include <utility>
#include <functional>
#include <algorithm>
using namespace std;

class Solution {
public:
    vector<int> assignTasks(vector<int>& servers, vector<int>& tasks) {
        using Idle = pair<int, int>;       // weight, index
        using Busy = pair<long long, int>; // finishTime, index
        priority_queue<Idle, vector<Idle>, greater<Idle>> idle;
        priority_queue<Busy, vector<Busy>, greater<Busy>> busy;
        for (int i = 0; i < (int)servers.size(); ++i)
            idle.emplace(servers[i], i);
        vector<int> ans;
        ans.reserve(tasks.size());
        long long time = 0;
        for (int j = 0; j < (int)tasks.size(); ++j) {
            time = max(time, (long long)j);
            while (!busy.empty() && busy.top().first <= time) {
                int i = busy.top().second;
                busy.pop();
                idle.emplace(servers[i], i);
            }
            if (idle.empty()) {
                time = busy.top().first;
                while (!busy.empty() && busy.top().first <= time) {
                    int i = busy.top().second;
                    busy.pop();
                    idle.emplace(servers[i], i);
                }
            }
            int i = idle.top().second;
            idle.pop();
            ans.push_back(i);
            busy.emplace(time + tasks[j], i);
        }
        return ans;
    }
};
