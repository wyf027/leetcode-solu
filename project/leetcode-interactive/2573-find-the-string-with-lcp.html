Find the String with LCP

找出对应 LCP
矩阵的字符串

从两两后缀的最长公共前缀长度，恢复字典序最小的小写字母字符串；若矩阵自相矛盾，返回空字符串。

Problem

题意

定义与目标

给定一个 n × n 矩阵 lcp。对任意下标 i, j，lcp[i][j] 表示后缀 word[i..n-1] 与 word[j..n-1] 的最长公共前缀长度。

请返回能够产生该矩阵的、字典序最小的长度为 n 的小写英文字母字符串；若不存在，返回空字符串。

函数形式：findTheString(lcp: int[][]): string

约束

  • 1 ≤ n = lcp.length = lcp[i].length ≤ 1000
  • 0 ≤ lcp[i][j] ≤ n
  • word 只能使用 26 个小写英文字母。

字典序比较：从左到右第一个不同位置上，字母更靠前的字符串更小。

示例 1

输入
lcp = [[4,0,2,0],[0,3,0,1],[2,0,2,0],[0,1,0,1]]
输出
"abab"
解释
矩阵要求两个字母交替出现，满足条件的字符串中字典序最小的是 "abab"。

示例 2

输入
lcp = [[4,3,2,1],[3,3,2,1],[2,2,2,1],[1,1,1,1]]
输出
"aaaa"
解释
四个位置必须是同一字母，选择最小字母得到 "aaaa"。

示例 3

输入
lcp = [[4,3,2,1],[3,3,2,1],[2,2,2,1],[1,1,1,3]]
输出
""
解释
word[3..3] 长度仅为 1，故 lcp[3][3] 不可能为 3。

Solution

完整题解

核心洞察

lcp[i][j] > 0 当且仅当 word[i] = word[j]。因此，正数项先把位置划入相同字符组；为了让答案字典序最小，按位置从左到右发现新组，并依次赋予 'a'、'b'……。

但只恢复首字符关系还不够。完整 LCP 必须满足递推：

word[i] == word[j] ? lcp[i][j] == 1 + (i+1<n && j+1<n ? lcp[i+1][j+1] : 0) : lcp[i][j] == 0

完整过程

  1. 准备长度为 n 的未赋值字符数组，当前字母从 'a' 开始。
  2. 从左到右扫描 i。若位置 i 尚未赋值，就把当前字母赋给所有满足 lcp[i][j] > 0 的位置 j ≥ i，然后使用下一个字母。
  3. 若需要超过 26 个不同字符，直接返回空字符串。
  4. 枚举所有 (i,j)，用上面的递推式核对矩阵；任一项不符即返回空字符串。
  5. 全部相符，返回构造出的字符串。

正确性证明

引理 1：构造阶段把所有必须具有相同首字符的位置赋为同一字母。因为任意合法答案中，lcp[i][j] > 0 恰好意味着两后缀首字符相同。

引理 2：若构造结果通过递推核验，则其 LCP 矩阵等于输入。按 i,j 从右下向左上看：首字符不同则公共前缀为 0；首字符相同则公共前缀为 1 加后一对后缀的公共前缀。边界外贡献为 0。递推逐项成立，故所有值均正确。

引理 3：通过核验的构造结果字典序最小。扫描到最左侧未赋值位置时，该位置属于一个此前未出现的字符组；给新组分配尚未使用的最小字母，不会改变更早位置，并使当前关键位置尽可能小。

定理：算法返回空串时不存在可用的 26 字母答案，或输入不满足 LCP 必要递推；否则由引理 2 得到合法性，由引理 3 得到字典序最小性。

边界情况

  • n = 1 时唯一合法矩阵为 [[1]]。
  • 对角线必须满足 lcp[i][i] = n-i。
  • 矩阵不对称、正值越过后缀边界等问题都会被递推核验发现。
  • 不同字符组超过 26 个时无解。

复杂度

  • 时间：O(n²)，构造和核验各扫描矩阵一次。
  • 额外空间：O(n)，用于答案字符数组；不计输入矩阵。

替代方案

可以用并查集把所有 lcp[i][j] > 0 的位置合并，再按每组最小下标分配字母，最后同样进行递推核验。它仍需扫描 O(n²) 个矩阵项，却额外引入并查集；直接贪心分组更短、更清晰。

面试追问

  • 为什么必须二次核验？正负关系只约束首字符是否相等，无法保证 LCP 的具体长度。
  • 为何不用重新计算一张矩阵？输入自身的右下递推值已经足够验证，能省下 O(n²) 额外空间。
  • 字母表大小变成 k 怎么办？把 26 替换为 k；其余逻辑不变。
  • 能否快于 O(n²)？输入本身有 n² 个元素，完整判断通常至少需要读取它们。

常见错误

  • 只依据 lcp[i][j] > 0 分组，不核验精确 LCP 长度。
  • 忽略 26 个小写字母的上限。
  • 核验时访问越界的 lcp[i+1][j+1]。
  • 按组大小而非最小位置分配字母，导致结果不是字典序最小。

四语言完整实现

Java
class Solution {
    public String findTheString(int[][] lcp) {
        int n = lcp.length;
        char[] word = new char[n];
        char next = 'a';

        for (int i = 0; i < n; i++) {
            if (word[i] != 0) continue;
            if (next > 'z') return "";
            for (int j = i; j < n; j++) {
                if (lcp[i][j] > 0) word[j] = next;
            }
            next++;
        }

        for (int i = n - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                int suffix = i + 1 < n && j + 1 < n
                        ? lcp[i + 1][j + 1] : 0;
                int expected = word[i] == word[j] ? 1 + suffix : 0;
                if (lcp[i][j] != expected) return "";
            }
        }
        return new String(word);
    }
}

/**

var findTheString = function(lcp) {
    const n = lcp.length;
    const word = Array(n).fill('');
    let code = 97;

    for (let i = 0; i < n; i++) {
        if (word[i]) continue;
        if (code > 122) return '';
        for (let j = i; j < n; j++) {
            if (lcp[i][j] > 0) word[j] = String.fromCharCode(code);
        }
        code++;
    }

    for (let i = n - 1; i >= 0; i--) {
        for (let j = n - 1; j >= 0; j--) {
            const suffix = i + 1 < n && j + 1 < n
                ? lcp[i + 1][j + 1] : 0;
            const expected = word[i] === word[j] ? 1 + suffix : 0;
            if (lcp[i][j] !== expected) return '';
        }
    }
    return word.join('');
};
Python
from typing import List


class Solution:
    def findTheString(self, lcp: List[List[int]]) -> str:
        n = len(lcp)
        word = [''] * n
        code = ord('a')

        for i in range(n):
            if word[i]:
                continue
            if code > ord('z'):
                return ''
            for j in range(i, n):
                if lcp[i][j] > 0:
                    word[j] = chr(code)
            code += 1

        for i in range(n - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                suffix = lcp[i + 1][j + 1] \
                    if i + 1 < n and j + 1 < n else 0
                expected = 1 + suffix if word[i] == word[j] else 0
                if lcp[i][j] != expected:
                    return ''
        return ''.join(word)
