超级洗衣机

Super Washing Machines

先理解“每轮可以让多台机器同时送出一件衣服”的规则，再用沙盘观察衣物流量。首屏不会直接展示解法。

题意

一排有 n 台洗衣机，machines[i] 是第 i 台中的衣服数。每一步可同时选择任意多台机器；每台被选中的机器恰好向相邻的一台机器送出一件衣服。求使所有机器衣服数相等的最少步数；若无法均分，返回 -1。

函数签名

findMinMoves(machines: integer[]) → integer

约束

  • n == machines.length
  • 1 ≤ n ≤ 10⁴
  • 0 ≤ machines[i] ≤ 10⁵

官方示例

示例 1
输入：machines = [1,0,5]
输出：3
过程：[1,0,5] → [1,1,4] → [2,1,3] → [2,2,2]

示例 2
输入：machines = [0,3,0]
输出：2
过程：[0,3,0] → [1,2,0] → [1,1,1]

示例 3
输入：machines = [0,2,0]
输出：-1
解释：总数 2 无法被 3 台机器均分。

题解：前缀流量与单点吞吐的双重下界

核心洞察

设平均值为 avg，令 diff = machines[i] - avg。扫描到位置 i 时，balance += diff 表示左侧整体必须跨过当前边界净流出（正）或净流入（负）多少件。一轮同一边界最多贡献一件净流量，所以至少需 |balance| 轮。另一方面，一台机器每轮最多送出一件；若它多出 diff > 0 件，也至少需 diff 轮。

答案：max(answer, abs(balance), diff)。缺衣机器可在同一轮从左右同时接收，故无需对单点负盈余取绝对值。

完整过程

  1. 求总数；若不能被 n 整除，返回 -1。
  2. 初始化平均值、累计盈亏和答案。
  3. 逐台计算 diff、更新 balance，用边界流量和正盈余更新答案。

正确性

下界：前缀盈亏的绝对值件衣服必须跨过相应边界，而每轮至多一件；一台机器的正盈余也因每轮至多送一件而构成下界。可达性：在线性路径上，可按这些净流量流水并行传递；所需轮数不超过最大边界负载和最大单机发送负载。因此算法取得的最大下界恰为最优值。

边界与复杂度

  • 单台、本已均衡或全零：返回 0。
  • 总数不可整除：返回 -1。
  • 时间 O(n)，额外空间 O(1)；总和使用宽整数。

替代方案

可显式保存每条边的净流量再求最大负载，本质相同但需 O(n) 空间。逐轮模拟直观，却可能极慢且难以保证每轮选择最优。

面试追问

  • 为什么对 balance 取绝对值，却只取正的 diff？
  • 若机器排成环，边界流量还唯一吗？
  • 若每台每轮可发送 k 件，两个下界如何变化？

常见错误

  • 只取最大前缀绝对值，漏掉单机向两侧分发的吞吐限制。
  • 把 |diff| 也作为下界，忽略缺口可由两侧同时填补。
  • 误把一步理解为只能有一台机器行动。
  • 未先判断能否整除。

四语言完整代码

Java

class Solution {
    public int findMinMoves(int[] machines) {
        long sum = 0;
        for (int x : machines) sum += x;
        if (sum % machines.length != 0) return -1;
        long avg = sum / machines.length, balance = 0, answer = 0;
        for (int x : machines) {
            long diff = x - avg;
            balance += diff;
            answer = Math.max(answer, Math.max(Math.abs(balance), diff));
        }
        return (int) answer;
    }
}

Python

from typing import List

class Solution:
    def findMinMoves(self, machines: List[int]) -> int:
        total = sum(machines)
        if total % len(machines):
            return -1
        avg = total // len(machines)
        balance = answer = 0
        for x in machines:
            diff = x - avg
            balance += diff
            answer = max(answer, abs(balance), diff)
        return answer

C++

class Solution {
public:
    int findMinMoves(vector<int>& machines) {
        long long sum = accumulate(machines.begin(), machines.end(), 0LL);
        if (sum % machines.size() != 0) return -1;
        long long avg = sum / machines.size(), balance = 0, answer = 0;
        for (int x : machines) {
            long long diff = x - avg;
            balance += diff;
            answer = max(answer, max(llabs(balance), diff));
        }
        return static_cast<int>(answer);
    }
};
