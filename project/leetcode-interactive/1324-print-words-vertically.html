竖直打印单词Print Words Vertically

把横向排列的单词变成一行行纵向读出的文字。先理解输出规则，再用交互实验观察字符如何移动。

MEDIUM
01

题目

给你一个字符串 s，其中包含若干个以单个空格分隔的大写英文单词。请按这些单词在 s 中的出现顺序，将它们分别放在一列，然后逐行读出并返回字符串列表。

空格规则：当某个单词在当前行已经没有字符时，需要用空格补位；但每个输出字符串的末尾不允许保留空格。

函数参数：printVertically(s: string) → list<string>

05

题解：按行模拟转置

核心洞察

单词是“列”，输出字符串是“行”。答案的行数等于最长单词的长度。对每个行号 r，依次查看每个单词：有第 r 个字符就追加字符，否则追加空格，最后删除这一行右侧的空格。

坐标关系

answer[row][column] ← words[column][row]

这正是一次不规则字符矩阵的“转置读取”。

完整过程

  1. 用空格切分 s，得到按原顺序排列的单词数组 words。
  2. 求所有单词长度的最大值 maxLen，它就是输出行数。
  3. 枚举 row = 0..maxLen-1；对每个单词，取 words[col][row]，越界则补一个空格。
  4. 移除当前行右侧连续空格，再把该行加入答案。只删右侧，不能删左侧或中间的占位空格。

正确性证明

行内容正确：固定输出行 r。算法按原顺序遍历每个单词，也就是按列从左到右读取其第 r 个字符；不存在该字符时补空格，因此每个有效字符及其横向位置都与题意一致。

空格正确：中间缺失字符产生的空格会保留，所以后续较长单词的字符仍在正确列；右侧空格之后没有任何有效字符，删除它们恰好满足“不允许尾随空格”。

覆盖完整：共有 maxLen 行。最长单词的每个字符都被处理，其他单词也不会有更高位置的字符，因此无遗漏、无多余行。综上，算法返回的列表正确。

复杂度

时间：O(W × L)，其中 W 为单词数，L 为最长单词长度；也可理解为输出矩阵规模。

额外空间：不计答案为 O(W)（切分后的单词数组）；构造答案需要 O(W × L) 的最坏空间。

边界情况

  • 只有一个单词：每个字符单独成为一行。
  • 所有单词等长：完全不需要补位。
  • 最右单词较短：其缺位只形成尾随空格，必须删除。
  • 中间单词较短：空格必须保留，不能对整行调用普通 trim()。

四语言完整实现

Java · 官方签名
class Solution {
    public List<String> printVertically(String s) {
        String[] words = s.split(" ");
        int maxLen = 0;
        for (String word : words) {
            maxLen = Math.max(maxLen, word.length());
        }

        List<String> answer = new ArrayList<>();
        for (int row = 0; row < maxLen; row++) {
            StringBuilder line = new StringBuilder();
            for (String word : words) {
                line.append(row < word.length() ? word.charAt(row) : ' ');
            }
            while (line.length() > 0 && line.charAt(line.length() - 1) == ' ') {
                line.deleteCharAt(line.length() - 1);
            }
            answer.add(line.toString());
        }
        return answer;
    }
}

/**
 * @param {string} s
 * @return {string[]}
 */
var printVertically = function(s) {
    const words = s.split(' ');
    const maxLen = Math.max(...words.map(word => word.length));
    const answer = [];

    for (let row = 0; row < maxLen; row++) {
        let line = '';
        for (const word of words) {
            line += row < word.length ? word[row] : ' ';
        }
        answer.push(line.replace(/\s+$/, ''));
    }
    return answer;
};
Python 3 · 官方签名
from typing import List

class Solution:
    def printVertically(self, s: str) -> List[str]:
        words = s.split()
        max_len = max(map(len, words))
        answer = []

        for row in range(max_len):
            line = ''.join(
                word[row] if row < len(word) else ' '
                for word in words
            )
            answer.append(line.rstrip())

        return answer
C++ · 官方签名
class Solution {
public:
    vector<string> printVertically(string s) {
        istringstream input(s);
        vector<string> words;
        string word;
        size_t maxLen = 0;

        while (input >> word) {
            maxLen = max(maxLen, word.size());
            words.push_back(word);
        }

        vector<string> answer;
        for (size_t row = 0; row < maxLen; ++row) {
            string line;
            for (const string& current : words) {
                line += row < current.size() ? current[row] : ' ';
            }
            while (!line.empty() && line.back() == ' ') {
                line.pop_back();
            }
            answer.push_back(line);
        }
        return answer;
    }
};

替代方案

预建矩阵：先创建 maxLen × W 的空格矩阵，再把字符填入，最后逐行去掉右侧空格。它更直观，但会显式保存整个中间矩阵。

按行流式构造：本题解直接构造每一行，步骤更少，额外中间空间也更小。

常见错误

  • 用 trim() 删除两端空格，误删了合法的前导占位。
  • 只遍历第一个单词的长度，遗漏更长单词的后续字符。
  • 遇到短单词就跳过，不补中间空格，导致后面的字符左移。
  • 把单词排序或改变列顺序，破坏题目要求的出现顺序。
