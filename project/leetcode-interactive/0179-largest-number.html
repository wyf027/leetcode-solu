    Solution unlocked

    比较 a+b 与 b+a

    若 a+b > b+a，就把字符串 a 放在 b 前面。

    核心洞察与正确性

    普通数值大小或字典序都不够，因为局部前后次序对整体的影响只体现在两种相邻拼接 a+b 与 b+a。若后者更大，交换相邻项就能严格增大完整结果；因此最终不存在可改进的逆序对，排序后的拼接全局最大。

    完整过程

    1. 把每个整数转为十进制字符串。
    2. 按 (b+a) 与 (a+b) 的降序关系排序。
    3. 若排序后首项为 "0"，说明全部为零，直接返回 "0"。
    4. 否则拼接所有字符串。
    时间 O(n log n · k)

    k 为数字字符串平均长度。

    空间 O(nk)

    保存字符串与结果。

    替代与追问

    • 暴力枚举排列仅适合小数组验证。
    • 为何比较器满足排序需要的一致性？可用无限周期串直观理解。
    • 若输入是已经给出的超长数字字符串，算法如何变化？

    常见错误

    • 按数值或普通字典序降序。
    • 比较 a 与 b，而不是两种拼接。
    • 把结果转整数导致溢出。
    • 返回 "000" 而不是 "0"。

    Java
    import java.util.Arrays;

class Solution {
    public String largestNumber(int[] nums) {
        String[] values = new String[nums.length];
        for (int i = 0; i < nums.length; i++) {
            values[i] = String.valueOf(nums[i]);
        }
        Arrays.sort(values, (a, b) -> (b + a).compareTo(a + b));
        if (values[0].equals("0")) return "0";
        return String.join("", values);
    }
}

    var largestNumber = function (nums) {
    const values = nums.map(String);

    return values.join("");
};
    Python 3
    from functools import cmp_to_key
from typing import List

class Solution:
    def largestNumber(self, nums: List[int]) -> str:
        values = list(map(str, nums))
        values.sort(
            key=cmp_to_key(
                lambda a, b: -1 if a + b > b + a else 1 if a + b < b + a else 0
            )
        )
        return "0" if values[0] == "0" else "".join(values)
    C++
    #include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string largestNumber(vector<int>& nums) {
        vector<string> values;
        for (int value : nums) values.push_back(to_string(value));
        sort(values.begin(), values.end(),
             [](const string& a, const string& b) {
                 return a + b > b + a;
             });
        if (values[0] == "0") return "0";
        string answer;
        for (const string& value : values) answer += value;
        return answer;
    }
};
