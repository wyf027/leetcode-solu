Listing notice · 01

题意转述

给定整数数组 prices，其中 prices[i] 表示第 i 天的股票价格。求在整个时间段内最多完成 两笔完整买卖能够获得的最大利润。

一笔交易由一次买入和之后的一次卖出组成；卖出第一笔持仓之后才能开始第二笔。若没有盈利机会，答案为 0。

页面中的负数不是亏损答案，而是“持有股票后账户的最大现金余额”。最后只读取不持仓的 sell2。
  • 1 <= prices.length <= 10^5
  • 0 <= prices[i] <= 10^5
  • 最多持有一股；交易次数不超过两次。

题解

核心洞察、完整推导、边界、复杂度、替代方案、面试追问、常见错误和四语言代码默认隐藏。

核心洞察

“最多两笔”可以拆成四个有序动作：第一次买、第一次卖、第二次买、第二次卖。每个状态只关心截至今天能拥有的最大现金余额，不必保存具体交易日。

buy1 = max(buy1, -price) sell1 = max(sell1, buy1 + price) buy2 = max(buy2, sell1 - price) sell2 = max(sell2, buy2 + price)

复杂度

只扫描一次价格数组；四个状态都是标量。

时间O(n)
额外空间O(1)

完整过程

  1. 用首日价格初始化两个买入状态为 -prices[0]，两个卖出状态为 0。
  2. 从第二日开始遍历；每个状态在“保持昨天结果”和“今天执行动作”之间取最大值。
  3. buy2 的资金来自 sell1，因此天然保证先完成第一笔交易。
  4. 返回 sell2。即使只做一笔，它也不会小于 sell1。

边界情况

  • 只有一天：无法卖出，答案为 0。
  • 全程下跌或持平：所有卖出状态保持 0。
  • 一路上涨：一笔跨全区间的交易已经最优。
  • 价格可为 0；买入状态也可能为非负数。

替代方案与取舍

可计算“左侧一次交易最大利润”和“右侧一次交易最大利润”，再枚举分割点，时间 O(n)、空间 O(n)，可视化直观但内存更多。二维 DP 能自然推广到 k 笔交易，却比固定两笔的四状态写法更冗长。面试中优先四状态压缩。

面试追问

  • 若最多允许 k 笔交易，如何扩展为 buy[t] / sell[t]？
  • 为什么同一天卖出后再买入不会制造额外利润？
  • 若每次交易收手续费，应该在哪个状态扣除？
  • 若卖出后必须冷冻一天，状态转移如何改变？

常见错误

  • 把第 122 题的所有正差价相加，实际上允许了无限次交易。
  • 把两笔交易分别求最优，却没有保证两段时间不重叠。
  • 错误地把买入状态初始化为 0，等价于免费获得股票。
  • 只返回 sell1，遗漏第二笔交易带来的收益。

class Solution {
    public int maxProfit(int[] prices) {
        int buy1 = -prices[0];
        int sell1 = 0;
        int buy2 = -prices[0];
        int sell2 = 0;

        for (int i = 1; i < prices.length; i++) {
            int price = prices[i];
            buy1 = Math.max(buy1, -price);
            sell1 = Math.max(sell1, buy1 + price);
            buy2 = Math.max(buy2, sell1 - price);
            sell2 = Math.max(sell2, buy2 + price);
        }
        return sell2;
    }
}
