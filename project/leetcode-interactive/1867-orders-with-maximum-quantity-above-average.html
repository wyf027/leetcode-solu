LEETCODE 1867 / ORDER ANALYTICS

最大数量高于
平均水平的订单

Orders With Maximum Quantity Above Average

MEDIUM数据库 · SQL付费题

从订单明细出发，找出符合“不平衡”定义的订单。先理解比较对象，再打开底部题解探索计算过程。

01 / 问题定义

一个订单，要与所有订单比较

给定表 OrdersDetails(order_id INT, product_id INT, quantity INT)。每一行记录某订单中某种产品的订购数量，一个订单可以占多行。

订单的平均数量等于该订单的数量总和除以产品种类数；订单最大数量是其单行 quantity 的最大值。若这个最大数量严格大于每个订单的平均数量（包含本订单），该订单即为不平衡订单。

编写 SQL，返回这些订单的 order_id，返回顺序不限。

字段类型含义
order_idINT订单编号
product_idINT产品编号
quantityINT该产品的订购数量

约束与数据契约

  • (order_id, product_id) 是复合主键；同订单中每种产品只占一行。
  • 同一种产品可以出现在不同订单中。
  • 比较是严格大于；相等不满足条件。
  • 公开题面没有给出行数或字段取值的数值上限，本页不虚构范围；也未提供额外 NULL 情况说明。语义参考和演示按非 NULL 整数数量处理。

04 / 独立题解

准备好后，展开推导

包含分步动画、SQL、四语言语义参考，以及正确性与边界分析。

把“所有平均值”压缩成一条阈值线

记订单 i 的最大值为 Mᵢ、总数量为 Sᵢ、产品数为 Cᵢ，平均值 Aᵢ = Sᵢ / Cᵢ。只需找到 T = max Aᵢ，返回 Mᵢ > T 的订单。注意 T 不是全表所有行的平均数量。

逐步演示：订单汇总 → 最高均值 → 筛选

蓝色条代表订单最大数量，橙色线代表已确定的全局阈值。演示采用手动推进的默认状态，不会自动开始；图中小数仅为显示值，比较使用整数交叉相乘。

编辑演示数据

填写 JSON 二维数组，每行依次为 order_id、product_id、quantity。演示限制为 1–80 行、每个值 1–1000000 的整数，主键不能重复；这是交互限制，不是官方约束。

完整过程

  1. 按 order_id 分组，计算 MAX(quantity) 和 AVG(quantity)。
  2. 在分组结果上再次聚合，获得最大的订单平均数量。
  3. 筛选最大数量严格大于该阈值的分组，投影订单编号。

官方示例：订单 1–5 的平均值分别为 37/3、22/4、43/3、10/2、18/2。最高平均值来自订单 3，为 43/3 ≈ 14.3333。五个最大值依次是 15、8、20、8、9，所以仅订单 1 和 3 入选。

正确性证明

分组覆盖且只覆盖同一订单的所有明细。复合主键保证每组的行数等于产品种类数，因此 AVG 得到题意定义的平均值，MAX 得到订单最大数量。令 T 为所有平均值中的最大者：若 Mᵢ > T，则对任何订单 j，都有 Aⱼ ≤ T < Mᵢ，条件成立；反之，若 Mᵢ 大于每个 Aⱼ，它也必然大于取得最大值的那个 Aⱼ，即 Mᵢ > T。筛选条件与原定义等价，不漏选也不误选。

边界与常见错误

  • 最大数量恰好等于阈值时不入选，不能写 >=。
  • 只有一种产品的订单，其最大值等于自身均值，所以一定不入选。
  • 只有一个订单但包含不同数量的多个产品时，它可以入选。
  • 不能只与自身平均值比较，也不能取全表平均值或所有平均值的平均值。
  • AVG(DISTINCT quantity) 会错误去掉相同数量的不同产品；这里应按明细行求平均。
  • 空表没有可输出订单。通用语言先处理空分组；SQL 外层无行，结果为空。
  • 不要整数除法截断，也不要先四舍五入再筛选。现实业务允许 NULL 时，需要先明确平均值分母和缺失数量语义。

复杂度

设 N 为明细行数，K 为订单数。哈希聚合通常需要 O(N + K) 时间与 O(K) 聚合空间；SQL 若采用排序聚合，可能达到 O(N log N)，实际取决于执行计划与索引。Java、JavaScript、Python 参考采用映射，按算术操作计为期望 O(N + K)；C++ 使用有序 map，为 O(N log K + K)，空间均为 O(K)。任意精度整数的位运算成本随数值位长增长，不视为无条件常数。

正式 SQL 与完整代码

本题是数据库题，MySQL 8 查询可用于官方 SQL 提交。以下 Java、JavaScript、Python、C++ 是同一关系运算的本地语义参考，并非本题官方函数签名或通用语言提交入口。示例 main/调用只展示使用方式，本轮未执行。

MySQL 8 · 官方可提交语言

WITH per_order AS (
    SELECT order_id,
           MAX(quantity) AS max_quantity,
           AVG(quantity) AS avg_quantity
    FROM OrdersDetails
    GROUP BY order_id
)
SELECT order_id
FROM per_order
WHERE max_quantity > (SELECT MAX(avg_quantity) FROM per_order);

Java · 本地语义参考

import java.util.*;
import java.math.BigInteger;

public class Main {
    static class Stat {
        BigInteger sum = BigInteger.ZERO;
        long count = 0;
        int max = Integer.MIN_VALUE;
    }
    // 每行依次为 order_id, product_id, quantity；输入满足复合主键。
    static List<Integer> ordersAboveAverage(int[][] rows) {
        Map<Integer, Stat> groups = new LinkedHashMap<>();
        for (int[] row : rows) {
            Stat s = groups.computeIfAbsent(row[0], k -> new Stat());
            s.sum = s.sum.add(BigInteger.valueOf(row[2]));
            s.count++;
            s.max = Math.max(s.max, row[2]);
        }
        Stat top = null;
        for (Stat s : groups.values()) {
            if (top == null || s.sum.multiply(BigInteger.valueOf(top.count))
                    .compareTo(top.sum.multiply(BigInteger.valueOf(s.count))) > 0)
                top = s;
        }
        List<Integer> result = new ArrayList<>();
        if (top == null) return result;
        for (Map.Entry<Integer, Stat> entry : groups.entrySet()) {
            BigInteger left = BigInteger.valueOf(entry.getValue().max)
                    .multiply(BigInteger.valueOf(top.count));
            if (left.compareTo(top.sum) > 0) result.add(entry.getKey());
        }
        return result;
    }
    public static void main(String[] args) {
        int[][] rows = {{1,1,12},{1,2,10},{1,3,15},{2,1,8},
            {2,4,4},{2,5,6},{3,3,5},{3,4,18},{4,5,2},
            {4,6,8},{5,7,9},{5,8,9},{3,9,20},{2,9,4}};
        System.out.println(ordersAboveAverage(rows));
    }
}

JavaScript · 本地语义参考

// quantity 可为安全整数或整数字符串；主键须唯一。
function ordersAboveAverage(rows) {
  const groups = new Map();
  for (const [id, product, value] of rows) {
    const q = BigInt(value);
    const s = groups.get(id) ?? { sum: 0n, count: 0n, max: q };
    s.sum += q;
    s.count += 1n;
    if (q > s.max) s.max = q;
    groups.set(id, s);
  }
  let top = null;
  for (const s of groups.values()) {
    if (top === null || s.sum * top.count > top.sum * s.count) top = s;
  }
  if (top === null) return [];
  return [...groups].filter(([, s]) => s.max * top.count > top.sum)
                    .map(([id]) => id);
}
const rows = [[1,1,12],[1,2,10],[1,3,15],[2,1,8],[2,4,4],

  [5,8,9],[3,9,20],[2,9,4]];
console.log(ordersAboveAverage(rows));

Python 3 · 本地语义参考

def orders_above_average(rows):
    # 每行：(order_id, product_id, quantity)，主键唯一。
    groups = {}
    for order_id, product_id, quantity in rows:
        s = groups.setdefault(order_id, [0, 0, quantity])
        s[0] += quantity
        s[1] += 1
        s[2] = max(s[2], quantity)
    top = None
    for s in groups.values():
        if top is None or s[0] * top[1] > top[0] * s[1]:
            top = s
    if top is None:
        return []
    return [order_id for order_id, s in groups.items()
            if s[2] * top[1] > top[0]]

C++17 · 本地语义参考

#include <array>
#include <iostream>
#include <map>
#include <vector>
#include <algorithm>
using namespace std;
// __int128 是 GCC/Clang 扩展；本地参考以 int 字段输入。
struct Stat { __int128 sum = 0, count = 0; int maximum = 0; };
vector<int> ordersAboveAverage(const vector<array<int, 3>>& rows) {
    map<int, Stat> groups;
    for (const auto& r : rows) {
        auto& s = groups[r[0]];
        if (s.count == 0) s.maximum = r[2];
        s.sum += r[2];
        ++s.count;
        s.maximum = max(s.maximum, r[2]);
    }
    const Stat* top = nullptr;
    for (const auto& entry : groups) {
        const auto& s = entry.second;
        if (!top || s.sum * top->count > top->sum * s.count) top = &s;
    }
    vector<int> result;
    if (!top) return result;
    for (const auto& [id, s] : groups)
        if ((__int128)s.maximum * top->count > top->sum)
            result.push_back(id);
    return result;
}
int main() {
    vector<array<int,3>> rows = {{1,1,12},{1,2,10},{1,3,15},
        {2,1,8},{2,4,4},{2,5,6},{3,3,5},{3,4,18},{4,5,2},
        {4,6,8},{5,7,9},{5,8,9},{3,9,20},{2,9,4}};
    for (int id : ordersAboveAverage(rows)) cout << id << ' ';
    cout << '\n';
}

通用语言使用分数交叉相乘：比较 S₁ × C₂ 与 S₂ × C₁，最终比较 M × C 与 S，避免浮点误差。Java/JavaScript/Python 用任意精度整数；C++ 参考使用 GCC/Clang 的 128 位扩展，并要求中间结果不超出其范围，超大输入应改为大整数。

替代方案

可使用 HAVING MAX(quantity) > ALL (SELECT AVG(quantity) FROM OrdersDetails GROUP BY order_id) 直接表达“高于全部均值”（MySQL 支持）。也可在每单聚合结果上使用 MAX(avg_quantity) OVER () 窗口函数求阈值。逐对比较订单也正确，但需要 O(K²) 次比较，没有利用最大值压缩。

面试追问

  • 若改为“高于至少一个订单的均值”？比较最小均值即可。
  • 若排除本订单后再比较？应维护最大与次大平均值及最大值的出现次数，单订单时还需明确空集合语义。
  • 若同产品出现多行？需先按订单与产品归并数量，再按订单统计，不能沿用行数作为产品种类数。
  • 如何处理新增明细？维护每单总量、计数和最大值，并维护可更新的全局均值集合；删除当前最大值还需要额外结构。
