环形链表 II

给定链表头节点，若链表中存在环，返回环开始的第一个节点；否则返回 null。要求不额外使用集合，空间复杂度为 O(1)。

Floyd 判圈O(n) 时间O(1) 空间

两阶段：相遇，再找入口

  1. 阶段 1慢指针每次走 1 步，快指针每次走 2 步。无环时快指针会到达空节点；有环时两者一定在环内相遇。
  2. 阶段 2相遇后将一个指针放回头节点，两个指针都改为每次走 1 步。它们下次相遇的位置就是环入口。
设头到入口距离为 a，入口到首次相遇距离为 b，环长为 c。快慢相遇时快指针比慢指针多走整数圈，因此从头与相遇点同步前进会在入口相遇。

常见误区

  • 只判断有环不够：本题要返回入口节点。
  • 快指针每轮必须先确认 fast 与 fast.next 非空。
  • 第二阶段不需要重置快指针；重置其中任意一个即可。
  • 无环、单节点自环、入口为头节点都要正确处理。

Floyd 指针演示

输入节点数与环入口下标。入口填 -1 表示无环。

准备中

验证清单

  • [3,2,0,-4]，入口下标 1：返回值为 2 的节点。
  • [1,2]，入口下标 0：环入口就是头节点。
  • [1]，入口下标 -1：返回 null。
  • 禁止改写节点的 next 指针；返回原链表中的节点对象。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

Java

public class Solution {
  public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
      slow = slow.next; fast = fast.next.next;
      if (slow == fast) { ListNode p = head;
        while (p != slow) { p = p.next; slow = slow.next; }
        return p;
      }
    }
    return null;
  }
}

class Solution {
public:
  ListNode *detectCycle(ListNode *head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
      slow = slow->next; fast = fast->next->next;
      if (slow == fast) {
        ListNode *p = head;
        while (p != slow) p = p->next, slow = slow->next;
        return p;
      }
    }
    return nullptr;
  }
};
