Two Sum II

给定一个按非递减顺序排列的整数数组 numbers，找出和为 target 的两个不同元素，返回它们的 1-based 下标。测试保证恰好一个解。

返回规则

找到 1 ≤ index₁ < index₂ ≤ numbers.length，使两个位置的值相加等于目标。返回 [index₁,index₂]；同一元素不能使用两次。

额外保证

数组已按非递减顺序排列，测试恰好有一个解；正式解法只能使用常数额外空间。

约束

  • 2 ≤ numbers.length ≤ 3 × 10⁴
  • -1000 ≤ numbers[i] ≤ 1000
  • -1000 ≤ target ≤ 1000
  • numbers 非递减，且答案唯一

Solution unlocked

左右双指针

别忘了：内部使用 0-based 指针，返回时必须各加一；并且 left < right 保证不重复使用元素。

核心洞察与移动理由

令 left = 0、right = n − 1。排序让当前和的变化方向可预测：固定右端时，左指针右移不会让和变小；固定左端时，右指针左移不会让和变大。

  • 当前和偏小：右端已经是窗口内最大值，任何更小的右端都不可能补足；所以排除当前左值，令 left++。
  • 当前和偏大：左端已经是窗口内最小值，任何更大的左端只会更大；所以排除当前右值，令 right--。
  • 相等时返回 [left + 1,right + 1]。

完整过程与正确性

  1. 指针从数组两端开始，循环条件为 left < right。
  2. 计算两端之和，与目标比较。
  3. 和偏小就左移；和偏大就右移；相等立即返回 1-based 下标。
  4. 每次移动都只排除不可能参与答案的一端，因此唯一解始终留在闭区间中；窗口严格缩小，最终必定命中。

边界与复杂度

重复值

非递减而非严格递增，比较逻辑仍成立。

负数

只依赖有序性，不依赖正负。

时间 O(n)

每轮至少移动一个指针。

空间 O(1)

仅保存指针与当前和。

二分替代方案

枚举第一个位置 i，在右侧区间二分查找 target − numbers[i]。时间 O(n log n)、额外空间 O(1)。

它同样利用排序，也容易扩展为“对每个候选值查询补数”；但本题左右双指针更快、更短，并直接满足常数空间要求。哈希表虽可做到 O(n)，却需要 O(n) 额外空间，不符合题目要求。

面试追问

  • 输入未排序时，如何在保留下标的前提下处理？
  • 若需要返回所有不重复数值对，怎样跳过重复值？
  • 为什么哈希解违反本题空间约束？
  • 怎样把思路扩展到 3Sum？

常见错误

  • 返回 0-based 下标，忘记加一。
  • 和偏小时误移动右指针，或偏大时误移动左指针。
  • 循环写成 left ≤ right，可能重复使用同一元素。
  • 误以为数组严格递增，忽略重复值。
  • 使用哈希表而违反常数额外空间要求。

Java

class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int left = 0;
        int right = numbers.length - 1;

        while (left < right) {
            int sum = numbers[left] + numbers[right];
            if (sum == target) {
                return new int[] {left + 1, right + 1};
            }
            if (sum < target) {
                left++;
            } else {
                right--;
            }
        }
        return new int[0];
    }
}

class Solution {
public:
    vector<int> twoSum(vector<int>& numbers, int target) {
        int left = 0;
        int right = static_cast<int>(numbers.size()) - 1;

        while (left < right) {
            int sum = numbers[left] + numbers[right];
            if (sum == target) {
                return {left + 1, right + 1};
            }
            if (sum < target) {
                ++left;
            } else {
                --right;
            }
        }
        return {};
    }
