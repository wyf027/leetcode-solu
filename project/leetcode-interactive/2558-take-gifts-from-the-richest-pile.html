从数量最多的堆
取走礼物

每秒选一堆数量最多的礼物，把它缩减为原数量平方根的向下取整值。求恰好进行 k 秒后，所有堆还剩多少礼物。

Problem

题目转述

给定整数数组 gifts，其中每个元素是一堆礼物的数量。连续执行 k 次：选出当前数量最多的一堆（并列时任取），将其数量替换为 ⌊√x⌋。返回最终各堆数量之和。

示例 1

输入：gifts = [25,64,9,4,100], k = 4
输出：29
过程：100→10，64→8，25→5，10→3
最终为 [5,8,9,4,3]，总和为 29。

示例 2

输入：gifts = [1,1,1,1], k = 4
输出：4
过程：每次操作后，被选中的 1 仍然是 1。

约束

  • 1 ≤ gifts.length ≤ 10³
  • 1 ≤ gifts[i] ≤ 10⁹
  • 1 ≤ k ≤ 10³

Solution

最大堆：始终快速拿到当前最大值

核心洞察

每一秒只关心“当前最大的那一堆”。最大堆正好能反复以 O(log n) 取出最大值并放回新值，因此无需每轮扫描或重排全部数组。

完整过程

  1. 把所有 gifts[i] 建成最大堆，同时计算总和 sum。
  2. 重复 k 次：弹出最大值 x。
  3. 计算 y = ⌊√x⌋，令 sum += y - x。
  4. 将 y 放回堆；循环结束后返回 sum。

正确性

循环不变式：每次循环开始前，堆中恰好保存当前所有礼物堆的数量，堆顶是其中最大值，sum 等于这些值的总和。

初始化建堆与求和后不变式成立。一次循环弹出的正是题目要求选择的最大堆；用 ⌊√x⌋ 替换并放回，同时按差值更新总和，所以不变式继续成立。执行满 k 次后，sum 即题目所求。

边界情况

  • 多个最大值并列：取任意一个，产生的新多重集合相同。
  • 所有值都是 1：⌊√1⌋ = 1，总和保持不变。
  • 只有一堆：连续对同一个值开平方即可。
  • 总和最大可达 10¹²，Java/C++ 必须使用 64 位整数。

复杂度

线性建堆为 O(n)；每次弹出和放回为 O(log n)，共 k 次，因此总时间为 O(n + k log n)，空间为 O(n)。

替代方案

每轮线性扫描最大值可做到 O(kn) 且代码直观；每轮排序则是 O(kn log n)。本题约束下都可能通过，但最大堆更贴合重复取最大值的机制。

四种语言完整代码

Java 
import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public long pickGifts(int[] gifts, int k) {
        PriorityQueue<Integer> heap = new PriorityQueue<>(Collections.reverseOrder());
        long sum = 0;

        for (int gift : gifts) {
            heap.offer(gift);
            sum += gift;
        }

        while (k-- > 0) {
            int before = heap.poll();
            int after = (int) Math.sqrt(before);
            sum += after - before;
            heap.offer(after);
        }

        return sum;
    }
}
JavaScript 
/**
 * @param {number[]} gifts
 * @param {number} k
 * @return {number}
 */
var pickGifts = function(gifts, k) {
    const heap = gifts.slice();

    const down = (i) => {
        while (true) {
            let largest = i;
            const left = i * 2 + 1;
            const right = left + 1;

            if (left < heap.length && heap[left] > heap[largest]) largest = left;
            if (right < heap.length && heap[right] > heap[largest]) largest = right;
            if (largest === i) return;

            [heap[i], heap[largest]] = [heap[largest], heap[i]];
            i = largest;
        }
    };

    for (let i = Math.floor(heap.length / 2) - 1; i >= 0; i--) down(i);

    while (k-- > 0) {
        heap[0] = Math.floor(Math.sqrt(heap[0]));
        down(0);
    }

    return heap.reduce((sum, value) => sum + value, 0);
};
Python 3 
from heapq import heapify, heappop, heappush
from math import isqrt
from typing import List


class Solution:
    def pickGifts(self, gifts: List[int], k: int) -> int:
        heap = [-gift for gift in gifts]
        heapify(heap)

        for _ in range(k):
            largest = -heappop(heap)
            heappush(heap, -isqrt(largest))

        return -sum(heap)
C++ 
#include <cmath>
#include <queue>
#include <vector>
using namespace std;

class Solution {
public:
    long long pickGifts(vector<int>& gifts, int k) {
        priority_queue<int> heap(gifts.begin(), gifts.end());
        long long sum = 0;
        for (int gift : gifts) sum += gift;

        while (k-- > 0) {
            int before = heap.top();
            heap.pop();
            int after = static_cast<int>(sqrt(before));
            sum += after - before;
            heap.push(after);
        }

        return sum;
    }
};

常见错误

  • 把开平方后的值误写成“取走的数量”，而不是“剩余数量”。
  • 只建一次有序数组，却没有在每次替换后恢复顺序。
  • 忘记向下取整，或在 Java/C++ 中用 32 位整数保存总和。
  • 使用最小堆时忘记取负数，导致每次处理最小值。

面试追问

  • 若 k 极大，何时可以提前停止？答：堆顶为 1 时所有值均为 1。
  • 若变换函数从平方根改为任意单调函数，结构是否仍适用？
  • 能否只维护总和而不保存全部值？为什么选择下一堆仍需要有序结构？
  • 如果礼物堆持续流式加入，如何维护当前最大值与总和？
