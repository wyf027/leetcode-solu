2138. 将字符串拆分为
若干长度为 k 的组

Divide a String Into Groups of Size k

把字符按顺序装入等长小组，看看最后一组会发生什么。

字符串模拟官方题目 ↗

01 / 任务说明

给定字符串 s、每组长度 k 和补位字符 fill，从左到右把字符串分成连续的组。每个原字符必须且只能出现一次，原有顺序不能改变。仅当最后一组不足 k 个字符时，在它的末尾添加 fill，直到长度为 k。返回按顺序排列的字符串数组。

只移除最后一组中新添加的补位字符，再连接各组，应恰好还原 s。原字符串中本来就存在的 fill 字符必须保留。

官方示例 1 · 刚好分完

输入：s = "abcdefghi", k = 3, fill = "x"
输出：["abc","def","ghi"]

三组都已有 3 个字符，无需补位。

官方示例 2 · 尾组补位

输入：s = "abcdefghij", k = 3, fill = "x"
输出：["abc","def","ghi","jxx"]

前三组与示例 1 相同，剩下 j，在末尾添加两个 x。

约束

  • 1 ≤ s.length ≤ 100，s 仅包含小写英文字母。
  • 1 ≤ k ≤ 100。
  • fill 是一个小写英文字母。

04 / 独立题解

准备好后再展开推导与四语言代码。

核心洞察 · 固定步长，不需要搜索

每一组的起点已经确定：0、k、2k……。从起点 i 取到 min(i + k, n)，得到当前组；如果长度不足 k，就在右侧补 fill。按组循环即可。

完整过程

  1. 准备结果数组，令 n = s.length。
  2. 从 i = 0 开始，只要 i < n，截取半开区间 [i, min(i + k, n))。
  3. 设截取长度为 m，追加 k − m 个 fill，把长度恰为 k 的字符串加入结果。
  4. 令 i 增加 k，继续下一组，最终返回结果。

abcdefghij / k=3 → abc → def → ghi → j + xx

为什么正确

循环开始时，已有组按顺序、无重叠地覆盖原字符串前 i 个字符（对尚未结束的迭代成立）。下一次截取正好覆盖从 i 开始、至多 k 个尚未使用的字符，因而保持原顺序且不重复、不遗漏。只有末组可能不足 k，补位只添加在该组末尾，不会改变原字符。循环结束后全部 n 个原字符均已覆盖，每个返回组长度均为 k；去除新增补位并连接便得到 s。

边界与常见错误

  • n 能被 k 整除：不补位，也不能额外生成一组。循环条件是 i < n。
  • n < k：只有一组，补 k − n 个字符；k = 1：每个字符独立一组。
  • 补位数应为 k − 当前组长度，不能无条件补 k − n % k。
  • 原始字符等于 fill 时也必须保留，不能按字符值删除“补位”。
  • 截取右端是开区间，Java 的右端不能超过 n；fill 只能加在右侧。

复杂度

令 g = ⌈n / k⌉，最终字符总数 L = gk。四份实现均为 O(L)，也可写作 O(n + k) 时间；当 k 可能大于 n 时，不宜直接忽略补位成本。返回结果占 O(L) 空间，除返回结果外，逐组构造所需临时空间至多 O(k)。

替代方案

可以先给整个字符串补 (k − n % k) % k 个 fill，再按 k 截取；逻辑直接，但会构造整段补齐后的中间字符串。也可以逐字符写入长度为 k 的缓冲区，满了便输出，适合流式输入。

Java

class Solution {
    public String[] divideString(String s, int k, char fill) {
        int n = s.length();
        String[] answer = new String[(n + k - 1) / k];
        for (int i = 0; i < n; i += k) {
            StringBuilder group = new StringBuilder(k);
            group.append(s, i, Math.min(i + k, n));
            while (group.length() < k) group.append(fill);
            answer[i / k] = group.toString();
        }
        return answer;
    }
}

JavaScript

/**
 * @param {string} s
 * @param {number} k
 * @param {character} fill
 * @return {string[]}
 */
var divideString = function(s, k, fill) {
    const answer = [];
    for (let i = 0; i < s.length; i += k) {
        answer.push(s.slice(i, i + k).padEnd(k, fill));
    }
    return answer;
};

Python 3

from typing import List

class Solution:
    def divideString(self, s: str, k: int, fill: str) -> List[str]:
        return [s[i:i + k].ljust(k, fill)
                for i in range(0, len(s), k)]

C++

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> divideString(string s, int k, char fill) {
        vector<string> answer;
        for (int i = 0; i < static_cast<int>(s.size()); i += k) {
            string group = s.substr(i, k);
            group.append(k - group.size(), fill);
            answer.push_back(group);
        }
        return answer;
    }
};

面试追问

  • 如何处理无限字符流？ 保留至多 k 个字符，满组便输出；只有流结束时才补最后一组。
  • 怎样无损恢复原字符串？ 同时记录原长度或补位数量；仅凭结果和 fill 无法区分原有字符与补位。
  • 如果字符串包含 emoji？ 先明确按字节、Unicode 码点还是字素簇分组。本题仅有小写英文字母，四语言的索引含义在此一致。
