LEETCODE 3971 · HARD

最大总价值

把每个下标看成一条不断下降的价值序列；要选至多 m 次，本质是在所有正数项中取最大的若干项。

题意

第 i 个下标首次被选中得到 value[i]；每多选一次，收益减少 decay[i]。第 t 次选择它的收益是 value[i] − decay[i] × (t − 1)。总操作数不超过 m，求最大总收益（对 1_000_000_007 取模）。负收益永远不选。

示例：value = [6, 5, 4]，decay = [2, 1, 1]，m = 4

可取 6, 5, 4, 4，所以答案为 19。

约束：n ≤ 10⁵，value[i], decay[i], m ≤ 10⁹。不能逐项放入堆：一条序列本身就可能长达十亿项。

实验室：阈值切分

调节阈值，观察每条等差序列中不小于它的项数。二分的目标是找到“第 k 大正收益”。

题解默认收起

题解：二分第 k 大收益

核心洞察

每个下标产生一条严格递减等差数列。若给定阈值 T，第 i 条中满足收益 ≥ T 的项数为 max(0, floor((value[i]−T)/decay[i])+1)。该计数随 T 增大单调不增，因此可二分。

完整过程

  1. 令 k = min(m, 正收益总数)。
  2. 二分最大的 T，使得“≥ T”的项数至少为 k。
  3. 用等差数列求和累加所有 > T 的项。
  4. 剩余的 k − count(>T) 项都恰为 T。

边界与复杂度

收益 ≤ 0 的项不应取；m 大于正收益项数时提前停止。计数与求和用 64 位整数。时间 O(n log V)，空间 O(1)，其中 V=max(value)。

替代方案 / 面试追问 / 常见错误

小 m 可用最大堆，但 m 可达 10⁹。追问：若 decay 为 0，要单独处理无限相等项。常见错误：把阈值等于 T 的项全加进来；正确做法是先加严格大于 T 的，再补所需个数。
