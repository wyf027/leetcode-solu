二叉树中
第二小的节点

Second Minimum Node In a Binary Tree

一棵拥有特殊父子关系的二叉树里，根节点已经告诉了我们最小值。先理解规则，再亲手观察一次搜索过程；完整解法暂时收在页面底部。

EASY 二叉树 深度优先搜索 非付费题

Problem

题意

给定一棵非空的特殊二叉树。每个节点的值都是正整数，并且每个节点恰好拥有 0 个或 2 个子节点。对任意内部节点，它的值等于两个子节点值中的较小者。

请在整棵树所有节点值组成的集合中找出严格大于最小值的最小值，也就是第二小的不同值。如果这样的值不存在，返回 -1。

Invariant / 固有性质

node.val = min(node.left.val, node.right.val)

函数参数：root: TreeNode
返回值：integer

示例 1

输入：root = [2,2,5,null,null,5,7]
输出：5
解释：最小值为 2，第二小的不同值为 5。

示例 2

输入：root = [2,2,2]
输出：-1
解释：所有节点值都为 2，不存在第二小值。

约束

  • 树中节点数在 [1, 25] 范围内。
  • 1 <= Node.val <= 231 - 1。
  • 每个节点有 0 个或 2 个子节点。
  • 对树中每个内部节点，都有 root.val == min(root.left.val, root.right.val)。

Solution

利用特殊性质剪枝

核心洞察：父节点等于两个子节点的较小值，因此根节点就是全树最小值。若某个节点值已经大于根值，它本身就是该子树能提供的最小候选；其后代不可能给出更小的候选，可以直接停止深入。

完整过程

  1. 记录 minimum = root.val，答案初始化为无穷大。
  2. DFS 访问节点；若值等于最小值，继续搜索左右子树。
  3. 若值大于最小值，用它更新答案，并剪掉这个节点的整棵子树。
  4. 搜索结束后，无候选则返回 -1，否则返回答案。

复杂度

  • 时间：最坏 O(n)；剪枝时可能少访问许多节点。
  • 空间：递归栈 O(h)，其中 h 是树高。

正确性说明

根值最小。每个内部节点都等于两个孩子中的较小值；沿树向下，节点值不会小于祖先值，所以没有节点小于根值。
剪枝安全。当节点值 v 大于根值时，该子树所有后代值都不小于 v；v 已经是该子树能贡献的最小合法候选，继续向下不会得到更优答案。
不会漏解。值等于根值的节点仍会递归展开，因此所有可能首次变大的分支边界都会被访问并参与答案比较。
结果成立。答案收集了每个相关子树的最小合法候选并取全局最小；若集合为空，整棵树只有一种值，应返回 -1。

边界情况

  • 只有根节点：不存在第二小值。
  • 所有节点都等于根值：返回 -1。
  • 合法答案可能等于 231 - 1，哨兵不能与它混淆。
  • 退化得很深的满分支结构：递归空间取决于树高。

替代方案

可以遍历全树，把不同值放入有序集合，再取第二个值。逻辑直观，但需要 O(n) 额外空间，也没有利用特殊树的剪枝性质。

常见错误

  • 把“第二小”误解为排序后的第二个节点，忽略值必须不同。
  • 遇到等于根值的节点就停止，导致漏掉更深处的候选。
  • 用 32 位最大整数作“无答案”标记，和合法节点值冲突。
  • 对普通二叉树照搬剪枝；该剪枝依赖题目给出的特殊性质。

面试追问

  • 如果去掉父节点取两个孩子最小值的性质，算法如何调整？
  • 如何改写为显式栈，避免递归？
  • 如何返回第 k 小的不同值？此时还能怎样剪枝？

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int minimum;
    private long answer;

    public int findSecondMinimumValue(TreeNode root) {
        minimum = root.val;
        answer = Long.MAX_VALUE;
        dfs(root);
        return answer == Long.MAX_VALUE ? -1 : (int) answer;
    }

    private void dfs(TreeNode node) {
        if (node == null) {
            return;
        }
        if (node.val > minimum) {
            answer = Math.min(answer, (long) node.val);
            return;
        }
        dfs(node.left);
        dfs(node.right);
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var findSecondMinimumValue = function(root) {
    const minimum = root.val;
    let answer = Infinity;

    const dfs = (node) => {
        if (node === null) {
            return;
        }
        if (node.val > minimum) {
            answer = Math.min(answer, node.val);
            return;
        }
        dfs(node.left);
        dfs(node.right);
    };

    dfs(root);
    return answer === Infinity ? -1 : answer;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def findSecondMinimumValue(self, root: Optional[TreeNode]) -> int:
        minimum = root.val
        answer = float("inf")

        def dfs(node: Optional[TreeNode]) -> None:
            nonlocal answer
            if node is None:
                return
            if node.val > minimum:
                answer = min(answer, node.val)
                return
            dfs(node.left)
            dfs(node.right)

        dfs(root)
        return -1 if answer == float("inf") else answer
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    int minimum;
    long long answer;

    void dfs(TreeNode* node) {
        if (node == nullptr) {
            return;
        }
        if (node->val > minimum) {
            answer = std::min(answer, static_cast<long long>(node->val));
            return;
        }
        dfs(node->left);
        dfs(node->right);
    }

public:
    int findSecondMinimumValue(TreeNode* root) {
        minimum = root->val;
        answer = LLONG_MAX;
        dfs(root);
        return answer == LLONG_MAX ? -1 : static_cast<int>(answer);
    }
};
