如果相邻两个颜色均相同
则删除当前颜色

Remove Colored Pieces if Both Neighbors are the Same Color

两种颜色，一条队列。先观察每一步允许删除的位置，再思考谁能坚持到最后。

官方题目 ↗

01 / 游戏规则

输入字符串 colors 表示从左到右排列的颜色片段，每个字符是 A 或 B。Alice 先手，两人交替行动，删除后剩余片段自动靠拢。

  • Alice 只能删除 A，且该片段的左右邻居都必须是 A。
  • Bob 只能删除 B，且该片段的左右邻居都必须是 B。
  • 队列最左端和最右端的片段不能删除。
  • 轮到某人时，如果没有合法操作，该人立即输掉游戏。

双方都采用最优策略。返回布尔值：Alice 获胜为 true，Bob 获胜为 false。

参数：colors: string　返回：boolean
约束：1 ≤ colors.length ≤ 10⁵，且只包含字符 'A'、'B'。

05 / 独立题解

准备好后，再展开思路与四语言实现。

核心洞察：统计可用步数

把队列分成极大的连续同色段。长度为 L 的段，能贡献 max(0, L − 2) 次删除。删除内部片段只会缩短这一段，不会使其他颜色的段消失，也不会改变对手能走的总步数。

设 Alice 总步数为 a，Bob 总步数为 b。Alice 先手，只有 a > b 时才能获胜；步数相等时，Alice 会先遇到无步可走的回合。

完整过程

  1. 初始化 a = 0、b = 0。
  2. 让 i 从 1 扫描到 n − 2，检查 colors[i − 1] == colors[i] == colors[i + 1]。
  3. 三者相等时，中心为 A 则 a 加一，否则 b 加一。三字符窗口可以重叠。
  4. 返回 a > b，无需真的删除字符串，也无需搜索策略。

例如 AAAABBBAAA 分为 AAAA / BBB / AAA，Alice 有 2 + 1 = 3 步，Bob 有 1 步，因此结果为 true。连续段里的每个内部位置都对应一个初始同色三连窗口，这些窗口数量恰好是 L − 2。

正确性证明

引理 1：合法删除只能发生在某个同色段内部。该段长度至少为 3，删除后至少留下 2 个片段，边界仍在；因而段的排列和颜色保持不变，不会跨颜色合并。

引理 2：长度 L ≥ 3 的同色段，每次操作将长度减一，直到长度为 2 恰好不能继续，故总步数为 L − 2；长度 1 或 2 的段贡献零步。各段独立，玩家的总步数为其颜色所有段贡献之和。

计数：长度 L 的段恰有 max(0, L − 2) 个同色三连中心，扫描算法准确统计双方的总步数。

胜负：若 a ≤ b，Bob 能回应 Alice 的每一步，随后 Alice 无法行动而输。若 a > b，经过 b 轮双方操作后 Alice 仍可走一步，接着 Bob 无法行动而输。因此返回 a > b 正确；任何合法删除顺序都不改变这个结论。

边界与复杂度

  • n 为 1 或 2：扫描不执行，返回 false。
  • 没有连续三片同色：Alice 无法起步，返回 false。
  • 全部是 A：n ≥ 3 时返回 true；全部是 B 总是 false。
  • 相同步数也返回 false，先手不能跳过回合。
  • 时间 O(n)，只扫描一次；额外空间 O(1)。

替代方案

可以直接进行连续段计数，遇到颜色变化时累加 max(0, L − 2)，最后补上尾段，时间 O(n)、空间 O(1)。

逐步删除适合可视化，但每次查找和复制字符串可能花 O(n)，总计 O(n²)。极小输入也能递归枚举，但会重复探索状态；本题的独立步数性质使博弈搜索没有必要。

常见错误

  • 只比较 A/B 字符总数：孤立片段与长度 2 的段无法贡献操作。
  • 用 a ≥ b 判断：忘记 Alice 先手，相等时 Alice 输。
  • 跳过重叠三连：AAAA 有两个可用步数，而非一个。
  • 认为删除后会连通其他同色段：被删除的段永远至少剩两片，不能整体消失。
  • 扫描到端点或在扫描中修改字符串：前者越界，后者混淆初始窗口与总步数。

面试追问

如果 Bob 先手？仍以 a、b 表示两人总步数，则 Alice 获胜条件变为 a ≥ b。

能否流式处理？可以。保留前两个字符，每到一个新字符判断是否形成同色三连，额外空间仍为 O(1)。

如果允许删除端点？段可能被删光并使其他段合并，当前的独立段证明不再成立，需要重新分析规则。

Java

class Solution {
    public boolean winnerOfGame(String colors) {
        int a = 0, b = 0;
        for (int i = 1; i < colors.length() - 1; i++) {
            char c = colors.charAt(i);
            if (colors.charAt(i - 1) == c &&
                c == colors.charAt(i + 1)) {
                if (c == 'A') a++;
                else b++;
            }
        }
        return a > b;
    }
}

#include <string>
using namespace std;

class Solution {
public:
    bool winnerOfGame(string colors) {
        int a = 0, b = 0;
        int n = static_cast<int>(colors.size());
        for (int i = 1; i < n - 1; ++i) {
            if (colors[i - 1] == colors[i] &&
                colors[i] == colors[i + 1]) {
                if (colors[i] == 'A') ++a;
                else ++b;
            }
        }
        return a > b;
    }
};
