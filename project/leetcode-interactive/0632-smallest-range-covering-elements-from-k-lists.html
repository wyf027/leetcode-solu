最小区间Smallest Range Covering Elements from K Lists

从 k 条非递减整数序列中各取至少一个数，用尽可能短的闭区间同时覆盖它们；若长度相同，左端点更小者优先。

先读题目打开交互演示
目标

输入 nums: number[][]，返回满足覆盖条件的最小闭区间 [a, b]。

nums = [
  [4,10,15,24,26],
  [0,9,12,20],
  [5,18,22,30]
]

return [20,24]

Problem

题目说明

给定 k 个已按非递减顺序排列的整数列表，寻找一个最小闭区间，使每个列表都至少有一个元素落在区间内。

比较规则

区间 [a,b] 与 [c,d] 比较时，先比较长度；若长度相同，再比较左端点。

[a,b] 更小 ⇔ b-a < d-c，或 b-a = d-c 且 a < c。

示例 1

输入：nums = [[4,10,15,24,26],
             [0,9,12,20],
             [5,18,22,30]]
输出：[20,24]
解释：24、20、22 分别来自三个列表，
      且都位于 [20,24]。

示例 2

输入：nums = [[1,2,3],
             [1,2,3],
             [1,2,3]]
输出：[1,1]

约束

  • nums.length == k
  • 1 <= k <= 3500
  • 1 <= nums[i].length <= 50
  • -105 <= nums[i][j] <= 105
  • 每个 nums[i] 均按非递减顺序排列。

Min-heap frontier

题解：用最小堆维护 k 条前沿

同时保留每个列表的一个“当前代表”。它们中的最小值决定左端点，已见的最大值决定右端点；每轮只推进最小值所属的列表。

01

覆盖不变量

堆中始终恰有每个列表的一个当前元素。只要堆大小为 k，区间 [堆顶, currentMax] 就覆盖所有列表。

02

只推进最小值

若想抬高左端点来缩短区间，必须淘汰当前最小元素；为了继续覆盖它所属的列表，只能换入该列表的下一个元素。

03

首个耗尽即结束

某个列表没有下一个元素时，再也无法在更右侧形成覆盖全部列表的候选区间，因此当前最佳值就是答案。

完整过程

  1. 将每个列表的第一个元素连同其列表编号、元素下标放入最小堆，同时记录最大值 currentMax。
  2. 堆顶 currentMin 与 currentMax 构成合法候选区间；按“长度更短，长度相同则左端点更小”的规则更新答案。
  3. 弹出堆顶，仅把它所属列表的下一个元素压入堆，并更新 currentMax。
  4. 若该列表已经耗尽，停止；否则回到步骤 2。

正确性证明

引理 1：每轮更新答案时，[currentMin, currentMax] 一定覆盖全部 k 个列表。因为堆中每个列表恰有一个代表，堆顶是这些代表的最小值，而 currentMax 不小于所有代表。

引理 2：从当前状态出发，任何左端点严格大于 currentMin 的后续合法区间，都必须先推进 currentMin 所属列表。否则该列表仍只能由当前最小元素代表，左端点无法越过它。

引理 3：当某个列表耗尽后，不会遗漏更优区间。根据引理 2，要继续提高左端点必须为该列表选取更靠后的元素，但这样的元素不存在。

结论：算法按必要顺序枚举了所有可能改善答案的前沿状态；每个状态都按题目规则比较并保留最佳区间，因此返回全局最小区间。

复杂度与边界

时间 O(N log k)

N 是所有列表的元素总数。每个被访问的元素至多入堆、出堆一次，堆大小最多为 k。

空间 O(k)

最小堆只保存每个列表的一个当前元素；其余状态为常数空间，不计输入和返回值。

  • 只有一个列表：答案为 [nums[0][0], nums[0][0]]。
  • 重复值：多个列表若共享同一数值，可得到长度为 0 的区间。
  • 负数：比较区间长度仍使用 right-left。
  • 同长度候选：必须显式比较左端点。
  • 列表耗尽：先评估当前合法候选，再尝试推进。

import java.util.*;

class Solution {
    public int[] smallestRange(List<List<Integer>> nums) {
        PriorityQueue<int[]> heap =
            new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));
        int currentMax = Integer.MIN_VALUE;

        for (int row = 0; row < nums.size(); row++) {
            int value = nums.get(row).get(0);
            heap.offer(new int[] {value, row, 0});
            currentMax = Math.max(currentMax, value);
        }

        int bestLeft = heap.peek()[0];
        int bestRight = currentMax;

        while (heap.size() == nums.size()) {
            int[] node = heap.poll();
            int currentMin = node[0];
            int currentWidth = currentMax - currentMin;
            int bestWidth = bestRight - bestLeft;

            if (currentWidth < bestWidth
                    || (currentWidth == bestWidth && currentMin < bestLeft)) {
                bestLeft = currentMin;
                bestRight = currentMax;
            }

            int nextIndex = node[2] + 1;
            List<Integer> source = nums.get(node[1]);
            if (nextIndex == source.size()) break;

            int nextValue = source.get(nextIndex);
            heap.offer(new int[] {nextValue, node[1], nextIndex});
            currentMax = Math.max(currentMax, nextValue);
        }

        return new int[] {bestLeft, bestRight};
    }
}

 * @param {number[][]} nums
 * @return {number[]}

var smallestRange = function(nums) {
    const heap = [];
    const swap = (i, j) => {
        [heap[i], heap[j]] = [heap[j], heap[i]];
    };
    const push = (node) => {
        heap.push(node);
        let i = heap.length - 1;
        while (i > 0) {
            const parent = Math.floor((i - 1) / 2);
            if (heap[parent][0] <= heap[i][0]) break;
            swap(parent, i);
            i = parent;
        }
    };
    const pop = () => {
        const root = heap[0];
        const last = heap.pop();
        if (heap.length > 0) {
            heap[0] = last;
            let i = 0;
            while (true) {
                let smallest = i;
                const left = i * 2 + 1;
                const right = left + 1;
                if (left < heap.length && heap[left][0] < heap[smallest][0]) {
                    smallest = left;
                }
                if (right < heap.length && heap[right][0] < heap[smallest][0]) {
                    smallest = right;
                }
                if (smallest === i) break;
                swap(i, smallest);
                i = smallest;
            }
        }
        return root;
    };

    let currentMax = -Infinity;
    for (let row = 0; row < nums.length; row++) {
        push([nums[row][0], row, 0]);
        currentMax = Math.max(currentMax, nums[row][0]);
    }

    let bestLeft = heap[0][0];
    let bestRight = currentMax;

    while (heap.length === nums.length) {
        const node = pop();
        const currentMin = node[0];
        const row = node[1];
        const index = node[2];
        const currentWidth = currentMax - currentMin;
        const bestWidth = bestRight - bestLeft;

        if (currentWidth < bestWidth
                || (currentWidth === bestWidth && currentMin < bestLeft)) {
            bestLeft = currentMin;
            bestRight = currentMax;
        }

        const nextIndex = index + 1;
        if (nextIndex === nums[row].length) break;

        const nextValue = nums[row][nextIndex];
        push([nextValue, row, nextIndex]);
        currentMax = Math.max(currentMax, nextValue);
    }

    return [bestLeft, bestRight];
};
from typing import List
import heapq


class Solution:
    def smallestRange(self, nums: List[List[int]]) -> List[int]:
        heap = []
        current_max = float("-inf")

        for row, values in enumerate(nums):
            value = values[0]
            heapq.heappush(heap, (value, row, 0))
            current_max = max(current_max, value)

        best_left = heap[0][0]
        best_right = current_max

        while len(heap) == len(nums):
            current_min, row, index = heapq.heappop(heap)
            current_width = current_max - current_min
            best_width = best_right - best_left

            if (current_width < best_width or
                    (current_width == best_width and current_min < best_left)):
                best_left = current_min
                best_right = current_max

            next_index = index + 1
            if next_index == len(nums[row]):
                break

            next_value = nums[row][next_index]
            heapq.heappush(heap, (next_value, row, next_index))
            current_max = max(current_max, next_value)

        return [best_left, best_right]
#include <algorithm>
#include <functional>
#include <queue>
#include <tuple>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> smallestRange(vector<vector<int>>& nums) {
        using Node = tuple<int, int, int>;
        priority_queue<Node, vector<Node>, greater<Node>> heap;

        int currentMax = nums[0][0];
        for (int row = 0; row < static_cast<int>(nums.size()); ++row) {
            heap.emplace(nums[row][0], row, 0);
            currentMax = max(currentMax, nums[row][0]);
        }

        int bestLeft = get<0>(heap.top());
        int bestRight = currentMax;

        while (heap.size() == nums.size()) {
            auto [currentMin, row, index] = heap.top();
            heap.pop();
            int currentWidth = currentMax - currentMin;
            int bestWidth = bestRight - bestLeft;

            if (currentWidth < bestWidth
                    || (currentWidth == bestWidth && currentMin < bestLeft)) {
                bestLeft = currentMin;
                bestRight = currentMax;
            }

            int nextIndex = index + 1;
            if (nextIndex == static_cast<int>(nums[row].size())) break;

            int nextValue = nums[row][nextIndex];
            heap.emplace(nextValue, row, nextIndex);
            currentMax = max(currentMax, nextValue);
        }

        return {bestLeft, bestRight};
    }
};

替代方案：合并排序 + 滑动窗口

把所有元素转换为 (value, listIndex) 后整体排序，再用滑动窗口维护窗口内覆盖的列表种数。当覆盖数达到 k 时收缩左边界并更新答案。

它更容易复用经典滑窗模板，但需要保存并排序全部 N 个元素：时间复杂度 O(N log N)，空间复杂度 O(N)。最小堆方案利用了各列表已排序这一条件，通常更节省空间。

常见错误

  • 不维护全局 currentMax，每轮重新扫描堆，复杂度退化。
  • 发现列表耗尽后立刻退出，忘了先评估弹出前仍合法的候选区间。
  • 同长度时没有选择左端点更小的区间。
  • 推进的不是堆顶所属列表，破坏必要的前沿顺序。
  • Java 用减法写比较器，在更宽值域问题中可能溢出，应使用 Integer.compare。

Interview follow-ups

面试追问

为什么不推进当前最大值所在列表？

右端点只会不降；推进最大值通常让右端点更大，却不能移除决定左端点的最小元素。

找到长度 0 时能否提前结束？

可以。区间长度不可能小于 0，当前候选已是全局最优。

列表无序时怎么办？

可先分别排序，或使用“全部元素合并排序 + 滑动窗口”。

如何支持数据流？

每个来源提供有序迭代器，堆仅保存各迭代器当前值；任一来源结束时终止。
