一堵墙，许多气球，多少支箭？

把每个气球看成 x 轴上的一个闭区间。你可以在任意横坐标垂直射箭；箭会穿过所有覆盖该坐标的气球。先观察区间关系，再进入交互实验。

Problem

题目描述

下面保留官方参数形式，并以中文准确转述题意。

二维整数数组 points 描述贴在 XY 平面墙面上的球形气球，其中 points[i] = [xStart, xEnd] 表示第 i 个气球的水平直径覆盖闭区间 [xStart, xEnd]，气球的 y 坐标未知。

你可以从 x 轴任意位置 x 沿正 y 方向垂直射箭。只要 xStart ≤ x ≤ xEnd，这支箭就会引爆该气球；箭会无限向上飞行，因此同一横坐标上的多个气球都可被引爆。返回引爆全部气球所需的最少箭数。

示例 1

输入：points = [[10,16],[2,8],[1,6],[7,12]]
输出：2
解释：可在 x = 6 和 x = 11 各射一箭。

示例 2

输入：points = [[1,2],[3,4],[5,6],[7,8]]
输出：4
解释：区间互不相交，每个气球各需一箭。

示例 3

输入：points = [[1,2],[2,3],[3,4],[4,5]]
输出：2
解释：可在 x = 2 和 x = 4 各射一箭。

约束

  • 1 ≤ points.length ≤ 10⁵
  • points[i].length == 2
  • -2³¹ ≤ xStart < xEnd ≤ 2³¹ - 1

Greedy Solution

按右端点排序，把箭射在最早结束处

核心洞察：面对尚未被覆盖且右端点最小的气球，把箭射在它的右端点，既能引爆它，又为命中后续气球保留了尽可能大的机会。

完整过程

  1. 按每个区间的右端点从小到大排序。
  2. 第一支箭放在第一个区间的右端点，答案初始化为 1。
  3. 依次扫描后续区间：若其左端点 ≤ 当前箭位置，这个气球已被该箭引爆。
  4. 若其左端点 > 当前箭位置，必须增加一支箭，并把新箭放在该区间右端点。

为什么正确

贪心选择：设当前最早结束的未处理区间为 [s, e]。任何可行方案都必须用某支位于 [s, e] 内的箭引爆它。若该箭位于 x < e，将它右移到 e 不会失去任何尚未处理的区间：这些区间的右端点都不小于 e，而能覆盖 x 且尚未被排除的区间，其左端点也不大于 x < e。因此总能得到一个同样优的方案，在 e 射箭。

归纳：移除所有覆盖 e 的区间后，剩余区间构成同类子问题。每一步都存在采用当前贪心选择的最优方案，重复后得到的箭数即为全局最小值。

边界与复杂度

  • 题目保证至少一个区间，因此可从答案 1 开始；若用于更通用场景，可额外处理空数组。
  • 端点相等算命中，因为区间是闭区间；只有 start > arrow 才新增箭。
  • 坐标可到 32 位整数边界。比较器应避免直接相减导致溢出，Java 使用 Integer.compare。
  • 排序耗时 O(n log n)，扫描耗时 O(n)；除排序栈/实现开销外，额外空间 O(1)。

替代方案

也可以按左端点排序并维护当前重叠组的交集右边界；遇到不相交区间时增加箭数并开启新组。这同样是 O(n log n)，但状态和边界判断更复杂。按右端点排序直接固定箭位，证明和实现通常更简洁。

若坐标范围很小，可考虑计数或扫描结构；但本题坐标范围巨大且 n ≤ 10⁵，比较排序更适合。

常见错误

  • 按左端点排序后仍固定箭在当前右端点，却没有维护重叠交集。
  • 使用 start ≥ arrow 新增箭，错误地把端点相接视为不相交。
  • Java/C++ 比较器写成端点相减，在极值坐标下溢出。
  • 只统计相邻区间是否重叠，忽略一支箭必须位于整个重叠组的公共交集。

面试追问

  • 如果区间改为开区间，端点相等时的判断如何变化？
  • 如何返回所有箭的具体坐标，而不仅是数量？
  • 如果区间在线到达且不能重排，能否保持最优？需要哪些额外假设？
  • 本题与“无重叠区间”“活动选择”之间有什么共同的贪心结构？

import java.util.Arrays;

class Solution {
    public int findMinArrowShots(int[][] points) {
        Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));

        int arrows = 1;
        int arrowX = points[0][1];
        for (int i = 1; i < points.length; i++) {
            if (points[i][0] > arrowX) {
                arrows++;
                arrowX = points[i][1];
            }
        }
        return arrows;
    }
}

from typing import List

class Solution:
    def findMinArrowShots(self, points: List[List[int]]) -> int:
        points.sort(key=lambda interval: interval[1])

        arrows = 1
        arrow_x = points[0][1]
        for start, end in points[1:]:
            if start > arrow_x:
                arrows += 1
                arrow_x = end
        return arrows
