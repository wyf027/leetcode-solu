转换字符串的最少操作次数

Minimum Moves to Convert String

三个相邻位置，一次转换。怎样用最少的操作完成整条字符串？

题目

给定字符串 s，只包含 X 和 O。每次选出恰好三个连续字符，将它们全部变为 O；原本为 O 的字符保持不变。返回使整个字符串都为 O 的最少操作次数。

参数：s: string；返回：integer。

约束：3 ≤ s.length ≤ 1000；每个 s[i] 为 X 或 O。

输出：0

题解 · 最左侧 X 的三格覆盖

核心洞察与完整过程

从左到右，找到尚未覆盖的第一个 X，让操作尽量覆盖它右侧的位置。令 i = 0，ans = 0；遇到 O 时 i 加 1，遇到 X 时 ans 加 1、i 加 3，直到 i ≥ n。被跳过的字符已覆盖，无需修改原字符串。

当 i 在最后两格时，实际选择 [n−3, n−1]。这个区间严格包含三个位置，只与已处理区域重叠。代码的 i += 3 表示结束扫描，不表示允许操作区间越界。

正确性：交换论证

设 i 是最左侧尚未处理的 X，任何可行解必须有一个区间覆盖 i。当 i ≤ n−3 时，把该区间替换成 [i,i+2]，其右端不会比原区间更靠左。被舍弃的左侧位置已经处理，因此不会丢失任何必要覆盖；操作数也不增加。当 i > n−3 时，最后三个位置覆盖所有剩余的 X。

所以存在一个最优解以贪心选择开始。对剩余后缀重复此论证，所有贪心选择都可以属于一个最优解；跳过 O 不会遗漏需要处理的位置，最终答案最少。

边界与复杂度

全 O 返回 0；长度为 3 且存在 X 时返回 1；全 X 返回 ⌈n/3⌉；尾部不足三格时使用末尾合法窗口。提交算法时间 O(n)，辅助空间 O(1)。演示为支持回退保存快照，使用额外空间。

替代方案

动态规划：dp[i] 为从 i 起的后缀所需操作次数。O 位置取 dp[i+1]；X 位置取 1 + dp[min(n,i+3)]，dp[n] = 0。自右向左计算，时间 O(n)、空间 O(n)。贪心免去数组。

常见错误

  • 按 X 总数除以 3：XOOX 的两个 X 无法被一个区间同时覆盖。
  • 遇到 X 只移动一格，重复统计已覆盖字符。
  • 认为尾部可以只选一两个字符；实际必须选三个。
  • 不允许区间重叠；覆盖 O 是合法操作。

面试追问

窗口改为 k 且 n ≥ k？遇到 X 跳 k 格，实际窗口起点为 min(i,n−k)。需要输出操作方案？记录每次窗口的起止下标。若不同窗口代价不同？交换操作可能改变代价，当前证明失效，需要重新考虑动态规划等方案。

Java

class Solution {
    public int minimumMoves(String s) {
        int ans = 0;
        for (int i = 0; i < s.length();) {
            if (s.charAt(i) == 'X') {
                ans++;
                i += 3;
            } else {
                i++;
            }
        }
        return ans;
    }
}

C++

#include <string>
using namespace std;

class Solution {
public:
    int minimumMoves(string s) {
        int ans = 0;
        for (int i = 0; i < static_cast<int>(s.size());) {
            if (s[i] == 'X') {
                ++ans;
                i += 3;
            } else {
                ++i;
            }
        }
        return ans;
    }
};
