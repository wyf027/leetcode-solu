01 · Problem

题目要你找什么

返回两个下标列表：第一组是关键边，第二组是伪关键边；组内顺序任意。

题意转述

给定一个有 n 个节点（编号 0 到 n - 1）的带权无向连通图。edges[i] = [aᵢ, bᵢ, weightᵢ] 表示第 i 条边。最小生成树（MST）用恰好 n - 1 条边连通所有节点、不含环，并让总权重最小。

返回 [critical, pseudoCritical]
下标始终对应输入数组的原始位置。
必

关键边

删掉这条边后，图无法生成 MST，或能生成的最小权重严格变大。它出现在所有 MST 中。

可

伪关键边

至少存在一棵 MST 包含它，但并非每棵 MST 都必须包含它。

02 · Examples

官方示例

参数形式完整保留，输出中的编号是输入边的索引。

01

存在必选边与可替换边

输入：n = 5, edges = [[0,1,1],[1,2,1],[2,3,2],[0,3,2],[0,4,3],[3,4,3],[1,4,6]]
输出：[[0,1],[2,3,4,5]]

边 0、1 出现在所有 MST 中；边 2、3、4、5 各自能进入某棵 MST，但不是每棵都包含。

02

等权环上的边都可替换

输入：n = 4, edges = [[0,1,1],[1,2,1],[2,3,1],[0,3,1]]
输出：[[],[0,1,2,3]]

四条边权重相同，任选其中能连通四点的三条即可得到 MST，因此没有关键边，四条边都是伪关键边。

约束

  • 2 <= n <= 100
  • 1 <= edges.length <= min(200, n × (n - 1) / 2)
  • edges[i].length == 3
  • 0 <= aᵢ < bᵢ < n
  • 1 <= weightᵢ <= 1000
  • 所有 (aᵢ, bᵢ) 数对互不相同

Kruskal 排除 / 强制法

01

建立基线

为每条边附上原始下标，按权重排序，运行一次 Kruskal，记最小总权重为 base。

02

排除实验

跳过边 i 再求 MST。若无法连通，或权重大于 base，边 i 是关键边。

03

强制实验

若不关键，先把边 i 加入并查集与总权重，再继续 Kruskal。若最终仍等于 base，它是伪关键边。

Complete process

完整过程

保留原始下标并排序

把 [u,v,w] 扩为 [u,v,w,index]。排序只改变处理顺序，返回值仍使用 index。

封装可跳过、可强制的 Kruskal

mst(skip, force) 先处理强制边（若有），然后按权重扫描全部边，跳过指定边与已经强制的边；每次只合并不同连通分量。

先求 base

调用 mst(-1, -1) 得到原图 MST 权重。题目保证图连通，因此基准一定存在。

依次分类每条边

先做排除实验。只有“不关键”时才做强制实验，避免把关键边同时放入伪关键集合。

用边数识别不连通

生成树必须恰好合并 n - 1 次。若扫描结束不足，返回一个无穷大哨兵值。

正确性：关键边

排除边 e 后，若无法连通或最佳权重变大，就不存在不含 e 且权重为 base 的生成树。因此每棵 MST 都必须包含 e，它是关键边。反之，若排除后仍得到 base，已构造出一棵不含 e 的 MST，所以它不关键。

正确性：伪关键边

先强制加入非关键边 e，再由 Kruskal 补全。若得到 base，这棵树就是包含 e 的 MST；又因为它已被证明不关键，故它只出现在部分 MST 中，正是伪关键边。若结果大于 base，则不存在包含它的 MST。

边界情况

  • 所有边权相等的环：通常没有关键边，环上的边均可伪关键。
  • 删除某边后图断开：返回无穷大，该边直接判为关键。
  • 平行端点不会出现：题目保证每个点对互异。
  • 强制边加入后，扫描时必须跳过它，避免重复计权。
  • 返回原始下标，不能返回排序后的下标。

复杂度

时间O(E² log E)至多执行约 2E 次 Kruskal，每次 O(E α(V))；加上排序，宽松写作 O(E² log E)。
空间O(V + E)存储扩展边数组与并查集；每次实验使用 O(V) 辅助空间。
Alternatives

替代方案与取舍

按权重分组 + 缩点 + 桥

逐组处理相同权重的边，在当前并查集连通分量构成的临时多重图上找桥：桥是关键边，其他连接不同分量的边是伪关键边。可做到接近 O(E log E)，但实现更复杂，尤其要正确处理临时图中的平行边。

枚举所有生成树

理论上可从定义出发验证，却有指数级组合爆炸，只适合极小数据或作为理解工具，不适合本题约束。

class Solution {
    static class DSU {
        int[] parent, size;
        DSU(int n) {
            parent = new int[n];
            size = new int[n];
            for (int i = 0; i < n; i++) {
                parent[i] = i;
                size[i] = 1;
            }
        }
        int find(int x) {
            if (parent[x] != x) parent[x] = find(parent[x]);
            return parent[x];
        }
        boolean union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return false;
            if (size[ra] < size[rb]) { int t = ra; ra = rb; rb = t; }
            parent[rb] = ra;
            size[ra] += size[rb];
            return true;
        }
    }

    public List<List<Integer>> findCriticalAndPseudoCriticalEdges(
            int n, int[][] edges) {
        int m = edges.length;
        int[][] sorted = new int[m][4];
        for (int i = 0; i < m; i++) {
            sorted[i] = new int[]{edges[i][0], edges[i][1], edges[i][2], i};
        }
        Arrays.sort(sorted, Comparator.comparingInt(e -> e[2]));

        int base = mst(n, sorted, -1, -1);
        List<Integer> critical = new ArrayList<>();
        List<Integer> pseudo = new ArrayList<>();

        for (int i = 0; i < m; i++) {
            if (mst(n, sorted, i, -1) > base) {
                critical.add(sorted[i][3]);
            } else if (mst(n, sorted, -1, i) == base) {
                pseudo.add(sorted[i][3]);
            }
        }
        return Arrays.asList(critical, pseudo);
    }

    private int mst(int n, int[][] edges, int skip, int force) {
        DSU dsu = new DSU(n);
        int weight = 0, used = 0;
        if (force != -1) {
            int[] e = edges[force];
            if (dsu.union(e[0], e[1])) {
                weight += e[2];
                used++;
            }
        }
        for (int i = 0; i < edges.length; i++) {
            if (i == skip || i == force) continue;
            int[] e = edges[i];
            if (dsu.union(e[0], e[1])) {
                weight += e[2];
                used++;
            }
        }
        return used == n - 1 ? weight : Integer.MAX_VALUE;
    }
}

var findCriticalAndPseudoCriticalEdges = function(n, edges) {
    const sorted = edges
        .map(([u, v, w], index) => [u, v, w, index])
        .sort((a, b) => a[2] - b[2]);

    class DSU {
        constructor(size) {
            this.parent = Array.from({ length: size }, (_, i) => i);
            this.size = Array(size).fill(1);
        }
        find(x) {
            if (this.parent[x] !== x) this.parent[x] = this.find(this.parent[x]);
            return this.parent[x];
        }
        union(a, b) {
            let ra = this.find(a), rb = this.find(b);
            if (ra === rb) return false;
            if (this.size[ra] < this.size[rb]) [ra, rb] = [rb, ra];
            this.parent[rb] = ra;
            this.size[ra] += this.size[rb];
            return true;
        }
    }

    const mst = (skip = -1, force = -1) => {
        const dsu = new DSU(n);
        let weight = 0, used = 0;
        if (force !== -1) {
            const [u, v, w] = sorted[force];
            if (dsu.union(u, v)) {
                weight += w;
                used++;
            }
        }
        for (let i = 0; i < sorted.length; i++) {
            if (i === skip || i === force) continue;
            const [u, v, w] = sorted[i];
            if (dsu.union(u, v)) {
                weight += w;
                used++;
            }
        }
        return used === n - 1 ? weight : Infinity;
    };

    const base = mst();
    const critical = [], pseudo = [];
    for (let i = 0; i < sorted.length; i++) {
        if (mst(i, -1) > base) critical.push(sorted[i][3]);
        else if (mst(-1, i) === base) pseudo.push(sorted[i][3]);
    }
    return [critical, pseudo];
};
from typing import List


class Solution:
    def findCriticalAndPseudoCriticalEdges(
        self, n: int, edges: List[List[int]]
    ) -> List[List[int]]:
        sorted_edges = sorted(
            [u, v, w, i] for i, (u, v, w) in enumerate(edges)
        )
        sorted_edges.sort(key=lambda edge: edge[2])

        def mst(skip: int = -1, force: int = -1) -> int:
            parent = list(range(n))
            size = [1] * n

            def find(x: int) -> int:
                while parent[x] != x:
                    parent[x] = parent[parent[x]]
                    x = parent[x]
                return x

            def union(a: int, b: int) -> bool:
                ra, rb = find(a), find(b)
                if ra == rb:
                    return False
                if size[ra] < size[rb]:
                    ra, rb = rb, ra
                parent[rb] = ra
                size[ra] += size[rb]
                return True

            total = used = 0
            if force != -1:
                u, v, w, _ = sorted_edges[force]
                if union(u, v):
                    total += w
                    used += 1

            for i, (u, v, w, _) in enumerate(sorted_edges):
                if i == skip or i == force:
                    continue
                if union(u, v):
                    total += w
                    used += 1

            return total if used == n - 1 else float("inf")

        base = mst()
        critical, pseudo = [], []
        for i, edge in enumerate(sorted_edges):
            if mst(skip=i) > base:
                critical.append(edge[3])
            elif mst(force=i) == base:
                pseudo.append(edge[3])
        return [critical, pseudo]
class Solution {
    struct DSU {
        vector<int> parent, size;
        explicit DSU(int n) : parent(n), size(n, 1) {
            iota(parent.begin(), parent.end(), 0);
        }
        int find(int x) {
            return parent[x] == x ? x : parent[x] = find(parent[x]);
        }
        bool unite(int a, int b) {
            a = find(a);
            b = find(b);
            if (a == b) return false;
            if (size[a] < size[b]) swap(a, b);
            parent[b] = a;
            size[a] += size[b];
            return true;
        }
    };

public:
    vector<vector<int>> findCriticalAndPseudoCriticalEdges(
        int n, vector<vector<int>>& edges
    ) {
        vector<array<int, 4>> sorted;
        for (int i = 0; i < static_cast<int>(edges.size()); ++i) {
            sorted.push_back({edges[i][0], edges[i][1], edges[i][2], i});
        }
        sort(sorted.begin(), sorted.end(), [](const auto& a, const auto& b) {
            return a[2] < b[2];
        });

        auto mst = [&](int skip, int force) {
            DSU dsu(n);
            int weight = 0, used = 0;
            if (force != -1) {
                const auto& e = sorted[force];
                if (dsu.unite(e[0], e[1])) {
                    weight += e[2];
                    ++used;
                }
            }
            for (int i = 0; i < static_cast<int>(sorted.size()); ++i) {
                if (i == skip || i == force) continue;
                const auto& e = sorted[i];
                if (dsu.unite(e[0], e[1])) {
                    weight += e[2];
                    ++used;
                }
            }
            return used == n - 1 ? weight : INT_MAX;
        };

        const int base = mst(-1, -1);
        vector<int> critical, pseudo;
        for (int i = 0; i < static_cast<int>(sorted.size()); ++i) {
            if (mst(i, -1) > base) {
                critical.push_back(sorted[i][3]);
            } else if (mst(-1, i) == base) {
                pseudo.push_back(sorted[i][3]);
            }
        }
        return {critical, pseudo};
    }
};

常见错误

  • 排序后忘了原始下标，导致返回错误编号。
  • 只比较权重，没检查是否用了 n - 1 条边。
  • 强制边既预先加入，又在主循环中加入一次。
  • 把所有能进入某棵 MST 的边都归为伪关键，遗漏“关键边不能重复归类”。
  • 并查集每次实验没有重新初始化。

面试追问

  • 为什么排除实验足以证明“所有 MST 都包含它”？
  • 强制一条边后继续 Kruskal，为什么能得到包含它的最小生成树？
  • 如何用“同权边分组 + 桥”优化到近似 O(E log E)？
  • 临时缩点图为什么可能出现平行边？找桥时如何区分边 ID？
  • 如果图不保证连通，接口与返回语义应如何调整？
