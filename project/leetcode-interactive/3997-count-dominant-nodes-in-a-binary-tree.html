3997. 统计二叉树中支配节点的数量

把“子树最大值”沿后序遍历向上返回：节点值恰好等于其子树最大值时，它就是支配节点。

题意

给定一棵完全二叉树 root。若节点 x 的值等于以 x 为根的整棵子树中的最大值，则 x 为支配节点；返回支配节点总数。

示例：root = [5, 3, 8, 2, 4, 7, 1]，输出 5。叶子 2、4、7、1 都成立；8 是其子树 [8, 7, 1] 的最大值。

约束：1 ≤ 节点数 ≤ 10^5；1 ≤ Node.val ≤ 10^9；输入保证为完全二叉树。

后序实验室

准备从叶子开始返回子树最大值。

题解：后序遍历返回子树最大值

对空节点返回负无穷。递归先取得左右子树最大值 leftMax、rightMax，再算 mx = max(node.val, leftMax, rightMax)。若 mx === node.val，该节点支配自己的整棵子树，答案加一；最后把 mx 返回给父节点。

完整过程

  1. 访问左、右孩子，保证孩子已报告其子树最大值。
  2. 合并两个最大值与当前节点值。
  3. 比较合并结果与当前值，命中则计数。
  4. 将最大值向父节点上交。

边界：叶子的两个孩子均为空，因此必定支配；相等最大值允许多个节点同时支配。递归深度最坏为树高 O(log n)（完全二叉树）。

复杂度：每节点仅处理一次，时间 O(n)，递归栈 O(log n)。替代方案：可用显式栈实现迭代后序，避免语言递归栈限制。面试追问：若树不完整，复杂度与高度分别如何变化？常见错误：按前序就立刻判断、把“祖先最大”误作“子树最大”、对相等值使用严格大于。
