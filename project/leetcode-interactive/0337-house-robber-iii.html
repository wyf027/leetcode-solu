House Robber III

打家劫舍 III

房屋连成一棵二叉树；相邻房屋不能在同一晚被盗。你能拿到的最高金额是多少？

非付费题 函数：rob(root) 返回：integer

01 · 题目

警报规则

一片区域只有一个入口 root。除入口外，每栋房屋都恰好与一个父房屋相连，因此所有房屋构成一棵二叉树。每个节点的值表示该房屋内的金额。

如果同一晚盗取两栋直接相连的房屋，系统会报警。给定二叉树根节点 root，返回在不触发警报的前提下可盗取的最高总金额。

示例 1

输入：root = [3,2,3,null,3,null,1]
输出：7
解释：选择根节点 3、左子树叶子 3 和右子树叶子 1，
      总金额为 3 + 3 + 1 = 7。

示例 2

输入：root = [3,4,5,1,3,null,1]
输出：9
解释：选择金额为 4 和 5 的两栋房屋，
      总金额为 4 + 5 = 9。

约束

  • 树的节点数在 [1, 10⁴] 范围内。
  • 0 ≤ Node.val ≤ 10⁴。

04 · 完整题解

每个节点只需要两个答案

把父节点的限制变成当前节点的状态：当前房屋“选”或“不选”。后序遍历让每个节点先拿到左右子树的结果，再一次性完成合并。

核心洞察

对每个节点返回二元组 [take, skip]：

  • take：选择当前节点时的最大金额；它的两个孩子必须跳过。
  • skip：跳过当前节点时的最大金额；每棵子树可独立选择更优状态。

状态转移

take = node.val + left.skip + right.skip

skip = max(left.take, left.skip) + max(right.take, right.skip)

最终答案是根节点二元组中的较大值。

完整过程

  1. 定义 DFS；空节点返回 [0, 0]，表示选择与跳过的收益都为 0。
  2. 递归计算左孩子与右孩子的二元状态。
  3. 若选择当前节点，只能加左右孩子的 skip。
  4. 若跳过当前节点，左右子树互不影响，各自取 take 与 skip 的较大值。
  5. 把当前二元组交给父节点；在根节点取两种状态的最大值。

正确性说明

归纳基础：空树没有金额，返回 [0,0] 正确；叶子节点的状态为 [val,0]。

归纳步骤：假设左右子树的二元组都已最优。选择当前节点时，相邻孩子必不选，因此唯一合法最优组合是当前值加两侧 skip。不选当前节点时，两棵子树没有相互约束，各自取最优状态即可。

结论：由结构归纳，每个节点的两种状态都最优；根节点取二者较大值即为整棵树的全局最优解。

复杂度

  • 时间复杂度：O(n)，每个节点只计算一次。
  • 空间复杂度：O(h)，递归栈深度等于树高；最坏退化为 O(n)。

边界情况

  • 单节点与金额为 0 的节点。
  • 只有左链或右链的退化树。
  • 父节点金额很大，必须跳过整层孩子。
  • 节点数达到 10⁴ 时递归栈可能较深。

四语言完整实现

Java

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public int rob(TreeNode root) {
        int[] state = dfs(root);
        return Math.max(state[0], state[1]);
    }

    // state[0] = take, state[1] = skip
    private int[] dfs(TreeNode node) {
        if (node == null) {
            return new int[] {0, 0};
        }

        int[] left = dfs(node.left);
        int[] right = dfs(node.right);

        int take = node.val + left[1] + right[1];
        int skip = Math.max(left[0], left[1])
                 + Math.max(right[0], right[1]);
        return new int[] {take, skip};
    }
}

JavaScript

/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var rob = function(root) {
    const dfs = (node) => {
        if (node === null) return [0, 0];

        const [leftTake, leftSkip] = dfs(node.left);
        const [rightTake, rightSkip] = dfs(node.right);

        const take = node.val + leftSkip + rightSkip;
        const skip = Math.max(leftTake, leftSkip)
                   + Math.max(rightTake, rightSkip);
        return [take, skip];
    };

    const [take, skip] = dfs(root);
    return Math.max(take, skip);
};

Python

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def rob(self, root: Optional[TreeNode]) -> int:
        def dfs(node: Optional[TreeNode]) -> tuple[int, int]:
            if node is None:
                return 0, 0

            left_take, left_skip = dfs(node.left)
            right_take, right_skip = dfs(node.right)

            take = node.val + left_skip + right_skip
            skip = max(left_take, left_skip) \
                 + max(right_take, right_skip)
            return take, skip

        take, skip = dfs(root)
        return max(take, skip)

C++

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
    pair<int, int> dfs(TreeNode* node) {
        if (node == nullptr) return {0, 0};

        auto [leftTake, leftSkip] = dfs(node->left);
        auto [rightTake, rightSkip] = dfs(node->right);

        int take = node->val + leftSkip + rightSkip;
        int skip = max(leftTake, leftSkip)
                 + max(rightTake, rightSkip);
        return {take, skip};
    }

public:
    int rob(TreeNode* root) {
        auto [take, skip] = dfs(root);
        return max(take, skip);
    }
};

替代方案

带父节点状态的记忆化搜索：定义 dfs(node, parentTaken)。如果父节点已选，当前节点只能跳过；否则比较选与不选。状态语义直观，但同一节点会有两类状态，需要哈希表或二维缓存。

按层奇偶取和不可行：局部高价值节点会改变不同分支的最佳选择，简单比较奇数层与偶数层会遗漏混合方案。

常见错误

  • 只返回子树最大值，导致父节点无法区分孩子到底选没选。
  • 选择当前节点时仍加入孩子的最大值，违反相邻节点限制。
  • 跳过当前节点时误以为必须选择两个孩子；实际上每个孩子都应独立取最优。
  • 忽略空节点基线，或把二元组中 take/skip 顺序写反。

面试追问

  1. 如何还原具体选择了哪些节点？ 在状态中记录决策，或在第二次遍历中根据父节点状态回溯选择。
  2. 如果节点金额允许为负数？ 空集应被允许时，当前转移仍可工作，因为 skip 最低为 0；需先确认是否必须至少选择一栋房屋。
  3. 如何避免深度为 10⁴ 的递归栈风险？ 用显式栈模拟后序遍历，并以映射保存每个节点的二元状态。
  4. 如果警报范围扩大到距离不超过 2 的节点？ 状态需要携带从当前节点向下的禁选距离，状态数随约束距离增加。
