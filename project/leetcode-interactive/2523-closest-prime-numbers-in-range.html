2523. 范围内最接近的两个质数

Closest Prime Numbers in Range

在一段整数区间中，寻找距离最近的一对质数。

题意

给定两个正整数 left 和 right，返回 [num1, num2]：两者均为质数，且满足 left ≤ num1 < num2 ≤ right，同时差值 num2 − num1 在所有合法质数对中最小。

若最小差值对应多对答案，选择 num1 最小的一对。区间内不足两个质数时，返回 [-1, -1]。

质数是大于 1、只有 1 和自身两个正因数的整数。区间两端均包含在内。

约束：1 ≤ left ≤ right ≤ 106

官方示例 1

输入：left = 10, right = 19
输出：[11, 13]

区间内质数为 11、13、17、19。[11,13] 与 [17,19] 的差值都是 2，选择起点较小的 [11,13]。

官方示例 2

输入：left = 4, right = 6
输出：[-1, -1]

区间内仅有质数 5，无法选出两个不同质数。

筛出质数，再比较相邻间距

核心洞察

把区间内的质数从小到大排列，最小差值一定出现在相邻两个质数之间。如果一对质数之间还有另一个质数，拆出的间距会更小。因此只需记住上一个质数，不必枚举所有质数对。

完整过程

  1. 建立覆盖 0…right 的合数标记，显式排除 0 与 1。
  2. 从 2 开始筛选。对于尚未标记的数 p，从 p² 开始标记其倍数，直到 right；只需处理 p² ≤ right 的 p。
  3. 从 left 到 right 升序扫描。遇到质数 x，将其与上一个质数 prev 比较。
  4. 仅当新差值严格小于当前最小差值时更新答案，再令 prev = x。
  5. 初始答案为 [-1,-1]；若没有形成质数对，直接返回初始答案。

正确性证明

  1. 筛选正确：任意合数 n 都有一个不大于 √n 的质因数 p。遍历该 p 时，n 会被标记。被标记的数字都是两个大于 1 的整数之积，所以不会误删质数。小于 p² 的 p 的合数倍数已有更小质因数处理。
  2. 候选完整：任意非相邻质数对 a、c 中间若存在 b，则 b − a < c − a，因此非相邻对不可能优于所有相邻对。
  3. 扫描不变式：每次处理一个质数后，prev 是已访问的最后一个质数，答案是所有已访问相邻对中差值最小且起点最小的一对。新质数仅新增一个相邻对；严格变小才更新，保持该性质。
  4. 终止：所有区间内质数处理完后，不变式覆盖全部有效候选。升序扫描保留最早出现的并列最优答案；不足两质数时从未更新，返回 [-1,-1]。

边界与常见错误

  • 1 不是质数；left = right 时无法形成不同数字组成的数对。
  • right 是闭区间端点，筛除和扫描都必须使用 ≤ right。
  • prev 必须只记录区间内的质数，不能用 left 之前的质数参与比较。
  • 用 ≤ 更新最小差值会覆盖起点更小的并列答案，应使用 <。
  • 不能从 p 自身开始标记，否则会删除质数。代码从 p² 开始。
  • [2,3] 的差值为 1，是特殊的最小可能间距；其余质数对间距至少为 2。

复杂度

令 R = right，W = right − left + 1。埃氏筛时间为 O(R log log R)，扫描为 O(W)，合计 O(R log log R + W)；额外空间为 O(R)，答案和 prev 仅占常量空间。交互演示为回退保存小范围快照，不代表提交实现的存储方式。

替代方案

逐个试除判定质数：额外空间 O(1)，时间约 O(W√R)，区间宽时较慢。分段筛：先筛出 √R 内的质数，再标记目标区间，空间降为 O(√R + W)，适合端点巨大但区间较窄的扩展问题；本题上限下普通埃氏筛更直接。

面试追问

  • 可以提前返回吗？若区间包含 [2,3]，可直接返回；排除此情况后，按升序扫描首次找到差值 2 即已最优。下面代码不提前返回，以保持流程统一。
  • 很多区间查询怎么办？预计算质数及相邻差值，再通过二分定位候选索引，配合区间最小值结构回答查询；相同差值按较小索引优先。
  • 端点超出 32 位范围呢？考虑分段筛或合适的素性测试，并避免 p*p 溢出，可用 p ≤ R/p 或更宽整数类型。

四语言完整实现

与官方 closestPrimes(left, right) 签名对应。以下代码均待补验证。

Java

class Solution {
    public int[] closestPrimes(int left, int right) {
        boolean[] composite = new boolean[right + 1];
        composite[0] = composite[1] = true;
        for (int p = 2; p * p <= right; p++) {
            if (!composite[p]) {
                for (int x = p * p; x <= right; x += p) {
                    composite[x] = true;
                }
            }
        }
        int prev = -1, best = Integer.MAX_VALUE;
        int[] ans = {-1, -1};
        for (int x = left; x <= right; x++) {
            if (composite[x]) continue;
            if (prev != -1 && x - prev < best) {
                best = x - prev;
                ans[0] = prev;
                ans[1] = x;
            }
            prev = x;
        }
        return ans;
    }
}

Python 3

from typing import List
from math import isqrt

class Solution:
    def closestPrimes(self, left: int, right: int) -> List[int]:
        composite = bytearray(right + 1)
        composite[0] = composite[1] = 1
        for p in range(2, isqrt(right) + 1):
            if not composite[p]:
                for x in range(p * p, right + 1, p):
                    composite[x] = 1
        prev = -1
        best = float("inf")
        ans = [-1, -1]
        for x in range(left, right + 1):
            if composite[x]:
                continue
            if prev != -1 and x - prev < best:
                best = x - prev
                ans = [prev, x]
            prev = x
        return ans
