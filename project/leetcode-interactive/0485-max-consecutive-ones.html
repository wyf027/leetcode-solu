最大连续 1 的个数

先读题，再用交互扫描器观察二进制数组中的连续片段。完整解法独立放在页面底部，默认保持折叠。

Max Consecutive Ones · 函数 findMaxConsecutiveOnes(nums)

01 · Problem

题目说明

给定一个二进制数组 nums，返回数组中连续出现的 1 的最大个数。

示例 1

输入：nums = [1,1,0,1,1,1]

输出：3

解释：开头的两个 1 与末尾的三个 1 分别连续，最长连续片段的长度为 3。

示例 2

输入：nums = [1,0,1,1,0,1]

输出：2

参数与约束

函数形式

findMaxConsecutiveOnes(nums)

  • nums：整数数组
  • 返回值：整数
  • 1 ≤ nums.length ≤ 10⁵
  • nums[i] 只可能是 0 或 1

阅读提示

连续意味着元素必须相邻；遇到 0 后，之前的连续片段不能与后面的 1 合并。

04 · Full solution

一次扫描，维护两段记忆

核心洞察

从左到右扫描时，只需保存两个整数：current 表示以当前位置结尾的连续 1 长度，best 表示已经见过的最大长度。读到 1 就让 current + 1；读到 0 就将 current 清零；每步用它更新 best。

为什么不需要保存片段

未来是否还能延长一个片段，只取决于“当前后缀中连续 1 的长度”。更早、且已经被 0 截断的片段只需把最大长度留在 best 中，具体位置无需继续保存。

完整过程

  1. 初始化 current = 0、best = 0。
  2. 按顺序读取数组中的每个值。值为 1 时延长当前连续片段；值为 0 时结束当前片段并把长度归零。
  3. 每处理一个元素，都令 best = max(best, current)。
  4. 扫描结束后返回 best。末尾连续 1 也会在逐步更新时被计入，无需额外收尾。

正确性证明

循环不变量：处理完索引 i 后，current 等于前缀 nums[0..i] 中以 i 结尾的连续 1 长度，best 等于该前缀内任意连续 1 片段的最大长度。

初始空前缀两者都为 0，不变量成立。若当前值为 1，以当前位置结尾的片段恰由上一片段延长一位；若为 0，则不存在以当前位置结尾的 1 片段，长度应为 0。随后取最大值，使 best 覆盖旧片段与新后缀片段。因此每一步不变量保持成立。

终止时处理了整个数组，best 就是全数组中最大连续 1 的个数。

复杂度与边界

时间：O(n)，每个元素只访问一次。

额外空间：O(1)，只使用两个计数器。

  • 全为 0：结果为 0。
  • 全为 1：结果为数组长度。
  • 单元素数组：分别得到 0 或 1。
  • 最长片段在数组末尾：逐步更新保证不会遗漏。

四语言完整代码

Java

O(n) / O(1) 
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        int current = 0;
        int best = 0;

        for (int value : nums) {
            if (value == 1) {
                current++;
                best = Math.max(best, current);
            } else {
                current = 0;
            }
        }

        return best;
    }
}

var findMaxConsecutiveOnes = function(nums) {
    let current = 0;
    let best = 0;

    for (const value of nums) {
        if (value === 1) {
            current += 1;
            best = Math.max(best, current);
        } else {
            current = 0;
        }
    }

    return best;
};

    int findMaxConsecutiveOnes(vector<int>& nums) {

        int best = 0;

替代方案

也可以在遇到 0 或扫描结束时才把当前长度与答案比较。这仍是 O(n) 时间、O(1) 空间，但要特别处理末尾连续 1。

分割字符串、创建所有连续片段或额外数组也能得到答案，却引入不必要的转换与空间，且不适合长度达到 10⁵ 的输入。

面试追问

  • 若最多能把一个 0 翻转成 1，如何改成滑动窗口？
  • 若数组以数据流形式到达，当前方法是否仍可在线计算？
  • 若要同时返回最长片段的起止下标，需要额外记录什么？
  • 若目标值不是 1，而是任意指定值，接口如何泛化？

常见错误

  • 遇到 0 后只跳过，却忘记把当前连续长度清零。
  • 只在遇到 0 时更新答案，导致遗漏数组末尾的最长片段。
  • 统计了所有 1 的总数，而不是相邻连续 1 的个数。
  • 为了记录片段建立额外数组，使空间从常数级退化。
