最小绝对差

先给数字排好队，再只看相邻者。一次线性扫描，就能同时找到最小差值与全部答案。

Problem 1200
Minimum Absolute Difference
完整参数：arr: integer[] → integer[][]
Problem

题意

元素互不相同

给定一个由互不相同的整数组成的数组 arr，找出任意两个元素之间的最小绝对差，并返回所有达到该差值的元素对。

  • 每个答案写作 [a, b]，其中 a < b。
  • a 和 b 都来自原数组，且 b - a 等于全局最小绝对差。
  • 答案中的元素对按升序返回。
示例 1
输入：arr = [4,2,1,3]
输出：[[1,2],[2,3],[3,4]]
解释：最小绝对差为 1，三个相邻对都达到它。
示例 2
输入：arr = [1,3,6,10,15]
输出：[[1,3]]
示例 3
输入：arr = [3,8,-10,23,19,-4,-14,27]
输出：[[-14,-10],[19,23],[23,27]]
约束
  • 2 ≤ arr.length ≤ 105
  • -106 ≤ arr[i] ≤ 106
  • 数组中的元素互不相同。

Core Insight

核心洞察

排序后，若 x < y 且二者中间还夹着某个数 z，那么 y - x = (z - x) + (y - z)，必然不小于其中任一相邻差。因此全局最小差一定出现在排序数组的相邻元素之间。

一句话算法

升序排序；从左到右计算相邻差。遇到更小差值就清空旧答案，遇到相同差值就追加当前元素对。

Process

完整过程

1

排序

将 arr 升序排列。

2

初始化

最小差设为正无穷，答案为空。

3

扫描

计算每对相邻元素之差。

4

更新

更小则替换，相等则追加。

正确性证明

引理：排序数组中任意非相邻元素 a[i] < a[j]（j > i + 1）的差，不会小于区间内所有相邻差。因为它等于这些正的相邻差之和。

完备性：由引理，全局最小差必在某个相邻对中。算法检查全部相邻对，所以不会遗漏最小差。

答案正确性：算法仅保留差等于当前最小值的相邻对；发现更小值时清空旧对。扫描结束时当前最小值就是全局最小差，答案恰好包含全部满足条件的元素对。排序顺序也保证返回结果按升序排列。

边界与复杂度

  • 只有两个元素时，唯一元素对就是答案。
  • 负数不影响排序与作差逻辑。
  • 元素互不相同，所以相邻差始终为正。
  • 多个相邻对可能共享同一个最小差，必须全部收集。

时间复杂度：O(n log n)，排序占主导；扫描为 O(n)。

空间复杂度：不计返回值时取决于语言排序实现，通常为 O(log n) 到 O(n)。

Implementations

四种语言完整代码

Java 官方签名

import java.util.*;

class Solution {
    public List<List<Integer>> minimumAbsDifference(int[] arr) {
        Arrays.sort(arr);
        int minDiff = Integer.MAX_VALUE;
        List<List<Integer>> answer = new ArrayList<>();

        for (int i = 1; i < arr.length; i++) {
            int diff = arr[i] - arr[i - 1];
            if (diff < minDiff) {
                minDiff = diff;
                answer.clear();
                answer.add(Arrays.asList(arr[i - 1], arr[i]));
            } else if (diff == minDiff) {
                answer.add(Arrays.asList(arr[i - 1], arr[i]));
            }
        }
        return answer;
    }
}

    }
    return answer;

Python 3 官方签名

from typing import List

class Solution:
    def minimumAbsDifference(
        self, arr: List[int]
    ) -> List[List[int]]:
        arr.sort()
        min_diff = float("inf")
        answer = []

        for left, right in zip(arr, arr[1:]):
            diff = right - left
            if diff < min_diff:
                min_diff = diff
                answer = [[left, right]]
            elif diff == min_diff:
                answer.append([left, right])

        return answer

        vector<vector<int>> answer;

替代方案

暴力枚举：检查所有 O(n²) 个元素对，再收集达到最小值的对。它直观但无法承受 10⁵ 的数组长度。

计数/值域扫描：题目值域有限，可用存在性数组扫描相邻出现值，达到近似 O(n + R)。但它依赖值域约束，占用额外空间，通用性不如排序。

面试追问

  • 为什么不需要检查排序后的非相邻元素？请用反证或差值分解说明。
  • 若数组允许重复，最小差会变成什么？输出是否需要去重？
  • 如果数据流持续到来、不能一次性排序，该如何维护当前最小差？
  • 如果只需要最小差值而不需要元素对，空间能否进一步降低？

常见错误

  • 用默认字典序对 JavaScript 数字数组排序；必须传入 (a, b) => a - b。
  • 发现更小差值时忘记清空此前答案。
  • 只返回一个最小差元素对，漏掉并列答案。
  • 先做绝对值再排序元素对，徒增逻辑；升序数组中右减左天然为正。
  • 写成双重循环，导致大输入超时。
