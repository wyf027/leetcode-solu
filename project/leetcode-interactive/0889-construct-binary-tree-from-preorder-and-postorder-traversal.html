先别急着看题解：观察前序的“根在前”和后序的“根在后”，尝试找出左右子树的分界。

MEDIUM树数组分治

题目

给定两个整数数组 preorder 与 postorder，它们分别是同一棵值互不相同的二叉树的前序遍历和后序遍历。请重建并返回这棵树。若存在多个合法答案，返回任意一个即可。

示例 1

输入：preorder = [1,2,4,5,3,6,7]
      postorder = [4,5,2,6,7,3,1]
输出：[1,2,3,4,5,6,7]

输出采用二叉树的层序数组表示。

示例 2

输入：preorder = [1]
      postorder = [1]
输出：[1]

约束

  • 1 <= preorder.length <= 30
  • postorder.length == preorder.length
  • 两数组中的值均在 [1, n] 内且各自互不相同。
  • 保证它们来自同一棵二叉树。

题解：用左根定位子树边界

核心洞察

当前区间的根是 preorder[preL]。若区间不止一个节点，则 preorder[preL + 1] 必然是我们选择的左子树根；在后序区间中找到它的位置 k，左子树节点数就是 k - postL + 1。由此可切开两段并递归。只有一个孩子时左右方向无法仅凭两种遍历唯一确定，把它放在左侧仍是合法答案。

完整过程

  1. 预处理哈希表，记录每个值在 postorder 中的下标。
  2. 以四个边界描述当前前序、后序区间。
  3. 创建当前根；区间长度为 1 时直接返回。
  4. 以前序中的下一个值作为左根，在后序中定位并计算 leftSize。
  5. 递归构造左区间与剩余的右区间，挂到根上。

正确性证明

归纳基础：区间只有一个节点时，两种遍历都只含同一根，算法返回正确单节点树。归纳步骤：假设更短区间可被正确构造。当前根由前序首项确定；前序第二项是第一棵子树的根，它在后序中的位置恰为该子树的末尾，因此算法计算的左子树大小正确。切出的左右两对子区间分别包含对应子树完全相同的节点集合与遍历顺序。由归纳假设，两棵子树均正确，连接当前根后所得整棵树的前序和后序正好等于输入。故算法正确。

复杂度

哈希表让每次定位为 O(1)，每个节点创建一次：时间 O(n)。哈希表与递归栈合计空间 O(n)；树本身不计入辅助空间时，最坏递归栈仍为 O(n)。

边界情况

  • 单节点。
  • 完全偏斜，答案不唯一。
  • 恰有一个子树时右区间为空。
  • 最大长度 30，递归深度可控。

替代方案

可以在线性扫描后序区间寻找左根，写法更短但最坏为 O(n²)；也可用两个全局游标配合“停止值”递归，不过边界语义更绕。哈希定位的分治写法更适合面试解释。

面试追问

  • 为何答案不唯一？ 一个节点只有一个孩子时，前序和后序无法区分它是左孩子还是右孩子。
  • 怎样保证唯一？ 若已知树是满二叉树，或再提供中序遍历，通常可唯一确定。
  • 如何降到 O(n)？ 用哈希表避免递归中反复线性查找分界。

常见错误

  • 把后序中的 k - postL 当成左树大小，漏掉左根自身。
  • 右子树边界忘记排除后序末尾的当前根。
  • 错误地要求输出必须等于示例的唯一形态。
  • 空右区间仍递归，造成越界。

Java

class Solution {
    private int[] pre, post;
    private java.util.Map<Integer, Integer> pos = new java.util.HashMap<>();
    public TreeNode constructFromPrePost(int[] preorder, int[] postorder) {
        pre = preorder; post = postorder;
        for (int i = 0; i < post.length; i++) pos.put(post[i], i);
        return build(0, pre.length - 1, 0, post.length - 1);
    }
    private TreeNode build(int pl, int pr, int ql, int qr) {
        if (pl > pr) return null;
        TreeNode root = new TreeNode(pre[pl]);
        if (pl == pr) return root;
        int k = pos.get(pre[pl + 1]);
        int leftSize = k - ql + 1;
        root.left = build(pl + 1, pl + leftSize, ql, k);
        root.right = build(pl + leftSize + 1, pr, k + 1, qr - 1);
        return root;
    }
}

C++

class Solution {
    vector<int> *pre, *post;
    unordered_map<int, int> pos;
    TreeNode* build(int pl, int pr, int ql, int qr) {
        if (pl > pr) return nullptr;
        TreeNode* root = new TreeNode((*pre)[pl]);
        if (pl == pr) return root;
        int k = pos[(*pre)[pl + 1]];
        int leftSize = k - ql + 1;
        root->left = build(pl + 1, pl + leftSize, ql, k);
        root->right = build(pl + leftSize + 1, pr, k + 1, qr - 1);
        return root;
    }
public:
    TreeNode* constructFromPrePost(vector<int>& preorder, vector<int>& postorder) {
        pre = &preorder; post = &postorder;
        for (int i = 0; i < (int)postorder.size(); ++i) pos[postorder[i]] = i;
        return build(0, preorder.size() - 1, 0, postorder.size() - 1);
    }
};
