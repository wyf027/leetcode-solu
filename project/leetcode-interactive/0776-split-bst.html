拆分二叉搜索树 Split BST

沿着一条边界路径，把一棵 BST 分成“值不大于目标”和“值大于目标”的两棵树，同时尽可能保留原有亲子关系。

Tree Binary Search Tree Recursion Binary Tree

Problem

题目说明

以下为基于官方元数据与公开题意的精炼转述，不复刻付费题面原文。

给定二叉搜索树的根节点 root 和整数 target，把原树拆成两个 BST，并返回两个根节点组成的数组 [small, large]：

  • small 中所有节点值都小于或等于 target。
  • large 中所有节点值都严格大于 target。
  • 不要求树中一定存在值为 target 的节点。
  • 若原来父节点与子节点最终进入同一棵树，这对亲子关系应继续保留。

约束与签名

  • 树中节点数在 [1, 50] 内。
  • 0 <= Node.val, target <= 1000。
  • splitBST(root: TreeNode, target: integer): TreeNode[]
  • 输入满足二叉搜索树性质。

示例 1

输入
root = [4,2,6,1,3,5,7], target = 2
输出
[[2,1],[4,3,6,null,null,5,7]]

节点 3 从 2 的右侧断开，转而成为较大结果树中节点 4 的左孩子。

示例 2

输入
root = [1], target = 1
输出
[[1],[]]

唯一节点属于“不大于 target”的结果，另一棵树为空。

Solution

递归拆分：只改边界上的指针

核心洞察

对任意节点 root，BST 有一侧能被立刻整体归类。若 root.val <= target，则根和整个左子树都属于第一棵树，只需递归拆分右子树；若 root.val > target，情形完全对称。

返回值约定

每层递归都返回 [small, large]。这份约定保持不变：索引 0 永远是不大于 target 的根，索引 1 永远是更大值的根，因此重连时无需额外分类。

完整过程

  1. 空节点返回 [null, null]。
  2. 若 root.val <= target，递归拆分 root.right 得到 [a, b]。令 root.right = a，返回 [root, b]。
  3. 否则递归拆分 root.left 得到 [a, b]。令 root.left = b，返回 [a, root]。
  4. 递归回溯时仅重写搜索边界上的一个孩子指针；没有跨越分界的其他边保持原样。

正确性证明

  1. 归纳基础：空树返回两棵空树，显然满足分类、BST 和结构要求。
  2. 较小根分支：当根值 ≤ target 时，根的左子树也全部 ≤ target。由归纳假设，右子树被正确拆成 a 与 b；把 a 接回根的右侧仍满足 BST，b 则全部 > target。
  3. 较大根分支：当根值 > target 时对称成立；递归结果 b 接回根的左侧，a 独立作为较小树。
  4. 结构保持：算法只断开跨分界的边并用递归返回的同侧根重连，所以最终同属一棵结果树的原亲子关系保持不变。

复杂度与边界

  • 时间：O(h)，每层只沿一个孩子递归，h 为树高；最坏退化为 O(n)。
  • 额外空间：O(h) 递归栈；结果复用原节点，不新建树节点。
  • target 小于最小值时返回 [null, root]；大于等于最大值时返回 [root, null]。
  • 算法会原地修改部分孩子指针；若调用者还需要原树，应先深拷贝。

替代方案

可用两个哑节点迭代维护较小树的右边界与较大树的左边界，同样做到 O(h) 时间和 O(1) 额外指针空间。中序遍历后重建虽然直观，但会访问全部节点、破坏“尽量保持原结构”的约束，不是优选。

面试追问

  • 能否改成无递归版本，并说明两个尾指针分别为何沿右链与左链前进？
  • 若 BST 允许重复值，应如何明确等于 target 的归属规则？
  • 若要求不修改原树，怎样用持久化路径复制把新增节点数控制在 O(h)？

常见错误

  • 递归拆完右子树后，把较大部分误接回 root.right；正确的是接回较小部分。
  • 在 root.val == target 时放入第二棵树，违背“第一棵树 ≤ target”的定义。
  • 返回数组的两个位置在不同分支中含义不一致，导致上层重连颠倒。
  • 先收集值再新建节点，既增加空间，也可能改变本应保留的亲子关系。

Java

LeetCode
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 * }
 */
class Solution {
    public TreeNode[] splitBST(TreeNode root, int target) {
        if (root == null) {
            return new TreeNode[] {null, null};
        }

        if (root.val <= target) {
            TreeNode[] parts = splitBST(root.right, target);
            root.right = parts[0];
            return new TreeNode[] {root, parts[1]};
        }

        TreeNode[] parts = splitBST(root.left, target);
        root.left = parts[1];
        return new TreeNode[] {parts[0], root};
    }
}

/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @param {number} target
 * @return {TreeNode[]}
 */
var splitBST = function (root, target) {
    if (root === null) {
        return [null, null];
    }

    if (root.val <= target) {
        const [small, large] = splitBST(root.right, target);
        root.right = small;
        return [root, large];
    }

    const [small, large] = splitBST(root.left, target);
    root.left = large;
    return [small, root];
};

/**

 *     int val;
 *     TreeNode *left;

class Solution {
public:
    vector<TreeNode*> splitBST(TreeNode* root, int target) {
        if (root == nullptr) {
            return {nullptr, nullptr};
        }

        if (root->val <= target) {
            auto parts = splitBST(root->right, target);
            root->right = parts[0];
            return {root, parts[1]};
        }

        auto parts = splitBST(root->left, target);
        root->left = parts[1];
        return {parts[0], root};
    }
};
