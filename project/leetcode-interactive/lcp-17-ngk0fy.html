LCP 17. 速算机器人

无论执行 A 还是 B，x+y 都会恰好翻倍。初始和为 1，所以答案是 2 的指令长度次方。

题意

机器人初始 x = 1, y = 0。指令 A 令 x = 2x + y，指令 B 令 y = 2y + x。给定只含 A、B 的字符串 s，返回执行结束时的 x + y。

s = "AB"

执行 A 后和为 2；执行 B 后和为 4，输出 4。

约束：1 ≤ s.length ≤ 10，s[i] 为 A 或 B。

交互：和每步翻倍

准备就绪。

测试与验证

s = "A"

期望：2；实际：2；通过

s = "AB"

期望：4；实际：4；通过

s = "BBBB"

期望：16；实际：16；通过

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

题解：只维护不变量 x+y

A 后的新和是 (2x+y)+y=2(x+y)；B 后的新和是 x+(2y+x)=2(x+y)。因此不用区分字符，直接返回 1 << s.length()。

复杂度与边界

时间 O(1)，空间 O(1)。长度为 1 时答案 2；题目长度至多 10，不会溢出。

替代方案与易错点

可逐字符模拟 x、y，时间 O(n)。常见错误是误以为 A/B 会影响总和增长率；它们只影响 x、y 的分配。

面试追问

若更新系数变为 a、b，可寻找线性组合 px+qy 的特征不变量；本题恰好令 p=q=1。

四语言可提交代码

// Java
class Solution { public int calculate(String s) { return 1 << s.length(); } }
// JavaScript
var calculate = function (s) { return 1 << s.length; };
# Python
class Solution:
    def calculate(self, s: str) -> int:
        return 1 << len(s)
// C++
class Solution { public: int calculate(string s) { return 1 << s.size(); } };
