MINIMUM SUBARRAYS IN A VALID SPLIT

有效分割中的
最少子数组数目

从连续数组中划出尽可能少的段，让每段的首尾满足要求。

01 / 题目

给定正整数数组 nums，把整个数组分割为若干个非空、连续的子数组。每个元素必须恰好属于其中一段，且顺序不能改变。

一个分割有效，当且仅当每一段的第一个元素与最后一个元素的最大公约数大于 1。返回有效分割所需的最少段数；如果无法完成，返回 -1。

只判断一段的两个端点。单元素段的两个端点相同，因此值大于 1 时合法，值为 1 时不合法。

官方示例 · 完整参数

示例 1

输入：nums = [2,6,3,4,3]
输出：2

可以分成 [2,6] 与 [3,4,3]，首尾最大公约数分别为 2、3。整段的首尾 2 和 3 互质，不能只分成一段。

示例 2

输入：nums = [3,5]
输出：2

分成 [3] 与 [5]；整段首尾互质。

示例 3

输入：nums = [1,2,1]
输出：-1

第一段一定以 1 开始，它与任何正整数的最大公约数都是 1，因此无解。

输入约束

  • 1 ≤ nums.length ≤ 1000
  • 1 ≤ nums[i] ≤ 10⁵

函数接口

validSubarraySplit(nums)
nums: integer[]
返回: integer

03 / 推演与题解

端点桥梁 · 前缀状态 · 四语言实现

核心洞察：最后一段从哪里开始？

一段是否合法只由端点决定；一旦选定最后一段 nums[j..i-1]，剩余问题就是如何最优分割前 j 个元素。把这类重复的前缀问题记录下来。

dp[i] 表示前 i 个元素的最少合法段数。
dp[0] = 0，其他状态初始为 ∞。
对每个 0 ≤ j < i，若 gcd(nums[j], nums[i-1]) > 1 且前缀可达，则尝试 dp[i] = min(dp[i], dp[j] + 1)。

交互推演 / 把两个端点连成一座桥

依次固定右端点，枚举左端点。绿色标记候选段的端点；浅绿为内部；黄色标记正在更新的前缀。每步尝试一条从前缀 j 到前缀 i 的边。

演示限制为 12 个元素；提交代码支持题目完整约束。

数组 · 闭区间 [j, i − 1]
DP · 前缀长度 0 … n

完整过程

  1. 准备长度为 n+1 的 dp 数组，以 n+1 作为不可达标记；合法答案最多为 n。
  2. 按 i 从 1 到 n 处理前缀，枚举最后一段的起点 j，从 0 到 i−1。
  3. 通过欧几里得算法求两个端点的最大公约数。只有 gcd 大于 1 且 dp[j] 可达时，才用 dp[j]+1 更新 dp[i]。
  4. 若 dp[n] 仍不可达，返回 −1；否则返回 dp[n]。要恢复具体分段，可在严格变优时保存起点 j，再逆向追溯。

示例 1 最终的前缀表是 [0,1,1,2,1,2]。前 4 项可以整段分割，而前 3 项需要 2 段，说明最优段数并不随前缀长度单调增加。

正确性

基础情形：空前缀不需要子数组，故 dp[0]=0 正确。

归纳步骤：假设所有更短前缀的最优值已正确。任意有效分割的最后一段必有某个起点 j，其端点 gcd 大于 1；移除这一段后，前 j 个元素的段数至少为 dp[j]。算法枚举到这个 j，因此不会漏掉最优分割。反过来，每次转移都把合法最后一段接在可达前缀后，构成覆盖整个前缀的有效分割，所以不会产生比最优值更小的非法答案。取全部候选的最小值，即得 dp[i] 的最优值。

终止：所有依赖都来自更短前缀，按长度递增计算后，dp[n] 就是所求；没有候选能到达它时无解。

边界与复杂度

  • n=1 时，值为 1 返回 −1，其他值返回 1。
  • 首项或末项为 1 时必然无解；内部出现 1 可以跨过去，例如 [2,1,2]。
  • 首尾 gcd 大于 1 时整段合法，答案就是 1；所有元素均大于 1 时至少可以逐个分段。
  • 令 M=max(nums)。共枚举 n(n+1)/2 个端点组合，每次 gcd 为 O(log M)，时间 O(n² log M)，额外空间 O(n)。动画保存步骤快照，仅用于最多 12 项的教学演示，不计入提交算法。

替代方案与面试追问

记忆化搜索：从某个起点枚举下一段的终点，缓存后缀答案。复杂度相同，但递归深度可能达到 n；迭代 DP 避免栈深限制。

更大规模：gcd>1 等价于端点共享某个质因子。维护每个质因子 p 对应的最小可达 dp[j]，把枚举所有左端点改为查询当前数的不同质因子。处理右端点 r 时应先用 dp[r] 登记 nums[r] 的质因子，再计算 dp[r+1]，以允许单元素段。用最小质因子筛表，可将时间降为 O(M log log M + n log M)，空间 O(M+n)。

追问：如何输出分段？记录前驱。如何数最优方案？增加方案数数组，严格改善时替换，打平时累加。为什么不能用前缀 gcd 相减？gcd 不具备这种逆运算，而且本题只看端点。

常见错误

  • 求整段所有元素的 gcd：[2,3,2] 的整体 gcd 是 1，但首尾 gcd 为 2，整段合法。
  • 把“段内存在 1”当成无解：只有作为端点的 1 才阻止该段合法。
  • 贪心取最长首段：[2,3,2,1,3] 若先取 [2,3,2]，剩余 [1,3] 无解；正确分割为 [2] 和 [3,2,1,3]。
  • 把 dp[i] 当成截至下标 i 的结果：这里 i 是元素数量，右端点下标为 i−1。
  • 将不可达值直接加一并当作可行候选；使用有限哨兵并显式判断可达。

Java

import java.util.Arrays;

class Solution {
    public int validSubarraySplit(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n + 1];
        Arrays.fill(dp, n + 1);
        dp[0] = 0;
        for (int i = 1; i <= n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] <= n && gcd(nums[j], nums[i - 1]) > 1) {
                    dp[i] = Math.min(dp[i], dp[j] + 1);
                }
            }
        }
        return dp[n] > n ? -1 : dp[n];
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }
}

from typing import List

class Solution:
    def validSubarraySplit(self, nums: List[int]) -> int:
        n = len(nums)
        dp = [n + 1] * (n + 1)
        dp[0] = 0
        for i in range(1, n + 1):
            for j in range(i):
                if dp[j] <= n and gcd(nums[j], nums[i - 1]) > 1:
                    dp[i] = min(dp[i], dp[j] + 1)
        return -1 if dp[n] > n else dp[n]
