击败所有怪物的最小初始强度

给出若干怪物 [need, gain]：当前强度至少为 need 才能击败它，击败后强度增加 gain。你可以任意安排顺序，求保证全部击败所需的最小初始强度。

按 need 升序挑战；答案 = max(need[i] - 已累计 gain, 0)

关键洞察

  • 收益永远非负时，先打需求更小的怪物不会让后续变差：它更容易满足，并且只会增加当前强度。
  • 排序后，前面获得的所有收益都是后面的“免费垫高”。第 i 个怪物唯一可能抬高初始值的量是 need - gained。
  • 不要逐次二分初始值，也不要用“当前不够就失败”的贪心顺序；顺序本身才是可优化的变量。

边界与复杂度

单个怪物时答案就是它的需求；收益为 0 时答案为最大需求；若初始值刚好等于需求，也可以击败。使用 64 位整数保存累计收益，避免大输入溢出。

时间复杂度 O(n log n)（排序），额外空间 O(n)（保存并展示怪物）。

显示题解与四语言实现

将怪物按需求升序排列。令 gained 为已击败怪物的收益和，initial 为答案。扫描时令 initial = max(initial, need - gained)，再加上本怪物收益。最后取非负值。
