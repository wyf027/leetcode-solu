击败所有怪物的最小初始强度

按从左到右顺序击败 monsters[i]。区间加成 [l, r, v] 只在对应怪物开战时临时生效；击败后当前强度减去怪物强度，最低为 0。

answer = max(monsters[i] > bonus[i] ? prefix + monsters[i] − bonus[i] : 0)

关键洞察

  • 战斗顺序固定，唯一要预处理的是每个位置的区间加成总和。用差分数组在 O(n + m) 时间得到 bonus[i]。
  • 战斗到 i 前，初始强度已经被前缀怪物总强度消耗；如果仍为正，它恰好等于 initial - prefix。因此第 i 个约束直接给出 initial ≥ prefix + monsters[i] - bonus[i]；只有当 monsters[i] > bonus[i] 时才需要该约束。
  • 只取所有位置约束的最大值和 0 即可；不需要二分答案，也不能把临时加成错误地累积到下一场战斗。

边界与复杂度

空加成等价于按固定顺序逐个消耗；多个区间可以重叠且加成可能远大于怪物强度。前缀和、差分和与答案均使用 64 位整数。

时间复杂度 O(n + m)，额外空间 O(n)。

先对每个 [l, r, v] 执行 diff[l] += v、 diff[r + 1] -= v。扫描时累加差分得到临时 bonus，同时维护前面已消耗的 prefix；以 monsters[i] > bonus ? prefix + monsters[i] - bonus : 0 更新答案，再把 monsters[i] 加入前缀。四份代码均使用这个 O(n + m) 解法。
