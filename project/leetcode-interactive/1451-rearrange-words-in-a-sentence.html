重新排列句子中的单词

Rearrange Words in a Sentence

把一句话交给长度这把尺子，同时保留同长度单词原本的先后关系。

题目要求

按长度重排，保持句子格式

给定字符串 text，它由单个空格分隔的若干单词组成，且原句首字母大写、其余字母小写。

请让所有单词按照长度升序排列；长度相同的单词必须保持它们在原句中的相对顺序。返回的新句子仍需满足：仅第一个单词首字母大写，其余单词全部小写。

函数签名： arrangeWords(text: string): string

约束

  • text 以大写字母开头，之后仅包含小写字母和单词间的单个空格。
  • 1 <= text.length <= 10^5

交互可视化

稳定排序轨道

编辑句子，然后逐步观察单词如何被标记、重排并恢复句子格式。

先把整句转为小写，避免原句首字母影响最终格式。

独立题解

准备好再揭晓

核心洞察

排序键只有长度，平局交给原顺序

先把原句整体转成小写并切分成单词。随后进行稳定排序：只比较单词长度；当长度相同，不交换先后位置。最后拼接，并仅把结果的第一个字符改为大写。

稳定性是这道题的关键语义。若所用排序不保证稳定，可把原始下标作为第二排序键，效果完全等价。

完整过程

规范大小写
把 text 转成全小写。
切分单词
按单个空格拆分，并记住原始下标。
稳定排序
优先比较长度；相同长度比较原下标或保留原顺序。
恢复格式
用空格连接，把结果首字符大写。

正确性说明

引理 1：排序后，任意相邻单词的长度均为非递减，因此结果满足长度升序要求。

引理 2：对于长度相同的两个单词，稳定排序不改变它们的相对位置；若显式比较原下标，也会让较早出现者排在前面。

结论：由两个引理可知，全部单词既按长度升序，又在长度相同时保持原顺序。最后的大小写处理只改变字符形式，不改变单词次序，因此返回值符合题意。

边界情况

  • 只有一个单词：顺序不变，只需保持首字母大写。
  • 所有单词等长：结果顺序与原句完全一致。
  • 多个最短单词：原本最靠前的最短单词成为句首。
  • 最大长度输入：避免反复拼接字符串，使用数组收集后一次连接。

复杂度

设单词数为 n，总字符数为 L。

  • 时间：O(L + n log n)
  • 空间：O(L + n)，用于单词数组及排序辅助空间。

替代方案

由于单词长度不超过 text.length，可以按长度建立桶，再按原顺序把单词放进对应桶，最后从短到长输出。

桶排序可做到 O(L) 时间，但可能创建很多空桶，代码也更繁琐。常规稳定排序更直观，通常是面试中的优先选择。

面试追问

如果排序库不稳定？

为每个单词保存原始下标，比较器先看长度，再看下标。

能否线性完成？

可以用按长度分桶；遍历原序入桶天然保留平局顺序。

若允许多个空格或标点？

需要先明确“单词”的解析规则，不能继续直接按单个空格切分。

常见错误

  • 直接排序原单词，导致原句第一个单词仍带大写字母，最终出现错误大小写。
  • 比较器在长度相同时继续按字典序排序，破坏相对顺序。
  • 只把新句首变大写，却忘记把原句首单词变回小写。
  • 依赖不稳定排序，却没有把原始下标作为第二关键字。

import java.util.*;

class Solution {
    public String arrangeWords(String text) {
        String[] words = text.toLowerCase().split(" ");

        // Arrays.sort 对对象数组使用稳定排序。
        Arrays.sort(words, Comparator.comparingInt(String::length));

        String result = String.join(" ", words);
        return Character.toUpperCase(result.charAt(0))
                + result.substring(1);
    }
}
/**
 * @param {string} text

var arrangeWords = function(text) {
    const words = text.toLowerCase().split(" ");

    // 带上原始下标，显式保证长度相同时的顺序。
    const ordered = words
        .map((word, index) => ({ word, index }))
        .sort((a, b) => a.word.length - b.word.length
            || a.index - b.index)
        .map(item => item.word);

    const result = ordered.join(" ");
    return result[0].toUpperCase() + result.slice(1);
};

        while (stream >> word) {
            words.push_back(word);
        }

        stable_sort(words.begin(), words.end(),
            [](const string& a, const string& b) {
                return a.size() < b.size();
            });

        string result;
        for (int i = 0; i < words.size(); ++i) {
            if (i > 0) result += ' ';
            result += words[i];
        }
        result[0] = toupper(result[0]);
