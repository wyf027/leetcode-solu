最大股票收益

Maximum Profit From Trading Stocks

有限的预算，独立的股票。你会如何挑选今天的投资？

每支最多买一次预算不能超支可以什么都不买

01问题与规则

有 n 支股票。两个等长数组 present 和 future 分别给出每支股票现在的价格与一年后的价格。你现在拥有 budget 的资金，每支股票最多购买一份，买入总价不能超过预算。一年后卖出所选股票，返回能得到的最大净利润，即卖出总价减去买入总价。

预算约束作用于现在的买入支出；未来的卖出收入不能提前用于买入。无需花完预算，选择空集合也合法。数组下标从 0 开始。

maximumProfit(present: integer[], future: integer[], budget: integer) → integer

约束

  • n == present.length == future.length
  • 1 ≤ n ≤ 1000
  • 0 ≤ present[i], future[i] ≤ 100
  • 0 ≤ budget ≤ 1000

04独立题解

把投资选择变成 0/1 背包

每支股票就是一个只能取一次的物品：成本 w = present[i]，价值 v = future[i] - present[i]。目标是在总成本不超过预算时最大化价值之和。收益为零或负数的股票可以跳过，因为去掉它不会降低利润，还可能节约预算。

状态与完整过程

  1. 令 dp[b] 表示：只使用已经处理过的股票、花费不超过 b 时，最多可得的净利润。初始化全部为 0，代表不买。
  2. 逐支处理股票。若净利润不为正，直接跳过。
  3. 预算 b 从 budget 递减到 w。比较“不买它”的原值和“买它”的剩余预算最优利润加 v。
  4. 所有股票处理完后，返回 dp[budget]。
dp[b] = max(dp[b], dp[b - w] + v)

逆序是关键：当 w > 0 时，较小预算位置尚未被当前股票更新，因此读取的仍是上一轮结果，不会重复买同一支股票。w = 0 时，来源和目标是同一个格子；赋值右侧先读取旧值，每个格子只更新一次，所以也只加一次该股票的利润。

正确性：每一轮保留所有可能的最优选择

归纳假设：处理前 i 支股票后，每个 dp[b] 都是该范围内的最优利润。对下一支股票，任意合法方案只有两类：不买，最优值为旧 dp[b]；买，则剩余股票成本不超过 b−w，最优值为旧 dp[b−w]+v。取两类中的最大值恰好覆盖所有方案。逆序保证读取上一轮状态，零成本项则每格仅更新一次。初始空集合满足假设，归纳至全部股票，dp[budget] 即答案。跳过非正利润项不会失去更优解。

边界与复杂度

  • budget = 0：仍需处理成本为 0 的正利润股票，不能直接返回 0。
  • 股票成本超过 budget：内层循环自然不执行；全部亏损或不可买时答案为 0。
  • 相同价格的不同下标代表不同股票，可以各选一次。
  • 时间 O(n × (budget + 1))，空间 O(budget + 1)；预算为正时常写作 O(nB)、O(B)。
  • 利润最多为 1000 × 100 = 100000，四份代码的数值类型足够。

替代方案

二维动态规划显式保存“股票数 × 预算”状态，易于回溯选择，空间为 O(n(B+1))。记忆化搜索同样依赖这两个状态，但递归深度可达 n。枚举子集需要 O(2ⁿ) 个组合，仅适合很小的 n。按利润或利润率排序不保证得到正确组合。

常见错误

  • 预算正序更新：例如 present=[2]、future=[5]、budget=4，会错误地重复买同一支股票，得到 6 而非 3。
  • 把 future[i] 当成净利润，忘记减去买入成本。
  • 把 dp[b] 定义为“必须恰好花完 b”，却仍全部初始化为 0；本题使用“不超过 b”的语义。
  • 把股票问题套成按天买卖的状态机：本题是在同一预算下选择股票集合。
  • 无条件略过零成本项，或认为预算为 0 就不可能获利。

面试追问

  • 如何输出买了哪些股票？ 保存二维表，从最后一行向前比较买与不买的来源，相等时任选一种合法方案。
  • 每支可以无限买呢？ 正成本项改为预算正序；若存在零成本正利润项且没有购买上限，利润无上界。
  • 预算很大而股票数很小呢？ 可讨论折半枚举与成本、利润的支配剪枝，避免对整个预算范围开表。
  • 为什么利润率贪心不行？ 股票不能拆分。例如成本 [3,4,4]、未来价格 [8,10,10]、预算 8，先拿利润率最高的第一支只能赚 11，后两支合计赚 12。

Java

class Solution {
    public int maximumProfit(int[] present, int[] future, int budget) {
        int[] dp = new int[budget + 1];
        for (int i = 0; i < present.length; i++) {
            int cost = present[i];
            int profit = future[i] - cost;
            if (profit <= 0) continue;
            for (int b = budget; b >= cost; b--) {
                dp[b] = Math.max(dp[b], dp[b - cost] + profit);
            }
        }
        return dp[budget];
    }
}

Python

from typing import List

class Solution:
    def maximumProfit(self, present: List[int], future: List[int], budget: int) -> int:
        dp = [0] * (budget + 1)
        for cost, sale in zip(present, future):
            profit = sale - cost
            if profit <= 0:
                continue
            for b in range(budget, cost - 1, -1):
                dp[b] = max(dp[b], dp[b - cost] + profit)
        return dp[budget]
