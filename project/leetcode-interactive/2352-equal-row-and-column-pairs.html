相等行列对

Equal Row and Column Pairs

一行向右，一列向下。把它们按顺序展开，哪些序列会完全重合？

01 / 理解问题

相同元素，还要相同顺序

给定下标从 0 开始的 n × n 整数矩阵 grid。统计所有行列下标对 (i, j)：第 i 行从左到右的序列，必须与第 j 列从上到下的序列逐项相等。返回这样的下标对数量。

行列下标可以相同；内容重复但下标不同的行或列仍分别计数。不是比较集合，也不是只比较交叉位置。

官方示例 1

输入：grid = [[3,2,1],[1,7,6],[2,7,7]]
输出：1

只有 (第 2 行，第 1 列) 相等，二者都是 [2,7,7]。

官方示例 2

输入：grid = [[3,1,2,2],[1,4,4,5],[2,4,2,2],[2,4,2,2]]
输出：3

(0,0) 对应 [3,1,2,2]；(2,2)、(3,2) 都对应 [2,4,2,2]，共 3 对。

约束
n == grid.length == grid[i].length
1 ≤ n ≤ 200
1 ≤ grid[i][j] ≤ 10⁵

04 / 独立题解

想清楚后，再打开

思路、证明、复杂度与四种语言的完整代码。

从定义出发：枚举行列对

核心洞察

固定第 i 行和第 j 列后，唯一要检查的是：对每个 k，都有 grid[i][k] == grid[k][j]。只要某个位置不同，这一对就失败；全部 n 个位置相同才计数。

完整过程

  1. 令答案 ans = 0。
  2. 枚举行下标 i，再枚举列下标 j，覆盖全部 n² 个下标对。
  3. 从 k = 0 起比较 grid[i][k] 与 grid[k][j]。遇到不同立刻停止这一对的比较。
  4. 若 k 到达 n，说明整条序列相等，将 ans 加 1；最后返回 ans。

交互区按同一顺序枚举 (i,j)，同时展示所有对应位置以便观察；提交代码会在第一个不同的位置提前停止。示例 2 中，第 2、3 行分别与第 2 列相等，所以必须增加两次。

正确性证明

单对判断：内层循环到达位置 k 时，前 k 个对应元素均相等。初始 k=0 时自然成立；当前元素相同才能继续，使该性质保持。出现不同则两序列不相等；循环到达 n 则全部元素相等。因此每一对的判定恰好符合定义。

整体计数：外层两重循环恰好访问每个 (i,j) 一次，只对判定相等的下标对加 1。故所有合法对都会被计入，且不会多计或重复访问同一下标对。

边界与复杂度

  • n=1 时唯一一行必然等于唯一一列，答案为 1。
  • 矩阵全部为同一值时，答案是 n²；n=200 时最大为 40000，32 位整数足够。
  • 重复的行列不能去重；对称矩阵至少有 n 对，但重复内容可能使答案更多。
  • 最坏时间 O(n³)：n² 对，每对最多 n 次比较。n=200 时最多 800 万次对应元素比较。
  • 额外空间 O(1)：直接访问原矩阵，仅保留循环下标与计数器。提前停止改善部分输入的耗时，不改变最坏复杂度。

替代方案：用哈希表统计完整序列

把每行转换为不可变的完整序列键，保存出现次数；再构造每列的键，把对应行频次加到答案。若同一序列出现 a 行、b 列，它贡献 a × b 对。

Python 可以使用 tuple；JavaScript 可用 JSON.stringify 或带分隔符的整数序列；Java 可用有内容相等语义的列表或字符串。不要直接以 Java 数组或 JavaScript 数组对象作为内容键。C++ 可用带自定义哈希的 vector 键或带分隔符的字符串。

在常规哈希表假设和题目整数范围下，时间期望 O(n²)、额外空间 O(n²)。哈希冲突时仍需比较完整键，不能只存一个可能碰撞的数值哈希并直接当作相等。也可以使用字典树，按整数依次插入行并查找列，但实现更复杂。本页四份代码统一使用直接枚举，便于与演示逐步对应。

常见错误

  • 写成 grid[j][k]：这是比较另一行；列应是 grid[k][j]。
  • 只比较行列交叉格，或比较元素和：都无法证明整条有序序列相同。
  • 排序后比较：会丢失顺序，改变题意。
  • 匹配后跳过剩余列，或用集合去重行：会漏掉不同下标组成的有效对。
  • 序列键直接拼接而没有分隔符：[1,23] 与 [12,3] 都会成为 “123”。

面试追问

n 再增大怎么办？改成“行序列 → 次数”的哈希表，避免逐对比较。
怎样返回全部下标对？匹配时追加 (i,j)；哈希方案则为每个键保存行下标列表，再与列下标配对，输出最多 n² 项。
空间要求非常严格呢？保留直接枚举，额外空间 O(1)。
仅矩阵对称就只有 n 对吗？不一定，重复行列可能形成更多对；全 1 矩阵就是 n² 对。

Java

class Solution {
    public int equalPairs(int[][] grid) {
        int n = grid.length, ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                int k = 0;
                while (k < n && grid[i][k] == grid[k][j]) {
                    k++;
                }
                if (k == n) ans++;
            }
        }
        return ans;
    }
}
