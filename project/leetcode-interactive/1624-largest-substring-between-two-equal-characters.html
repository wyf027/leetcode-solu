Largest Substring Between Two Equal Characters

给定字符串 s，找出两个相同字符之间最长的连续子字符串，并返回其长度；边界上的两个相同字符不计入长度。若不存在这样的字符对，返回 -1。

函数签名

maxLengthBetweenEqualCharacters(s: string): integer

示例与约束

子字符串必须连续；答案只计算两个相同端点之间的字符数量。

Complete solution

题解：记住第一次出现

一次从左到右的扫描，就能覆盖每个字符可能形成的最远距离。

01

核心洞察

对于右端点 i 上的字符 c，要让区间尽可能长，左端点应选择 c 的第一次出现位置。于是候选长度就是 i - first[c] - 1。

完整过程

  1. 准备长度为 26 的数组 first，初值全部为 -1。
  2. 从左到右访问位置 i，将字符映射到 0…25。
  3. 若该字符从未出现，记录 first[c] = i。
  4. 否则用 i - first[c] - 1 更新最大值。
  5. 扫描结束后返回最大值，初始值 -1 自然覆盖无解情况。

正确性说明

固定某个字符及任意右端点 i。在所有同字符左端点中，位置越靠左，i - left - 1 越大，因此第一次出现位置产生该右端点下的最优区间。扫描会把每个位置都作为右端点处理，并对全部候选取最大值，所以最终答案等于全局最优解。

边界与复杂度

  • 所有字符只出现一次：保持 -1。
  • 相邻的相同字符：候选长度为 0。
  • 同一字符出现多次：永远保留第一次位置。
  • 长度为 1：不存在合法字符对。

时间 O(n) · 空间 O(1)（26 个槽位）

替代方案

可以枚举所有下标对并检查字符是否相同，时间复杂度为 O(n²)；也可以为每个字符记录首次和末次位置后统一计算。本题字符集固定时，数组比哈希表更直接。

面试追问

  • 字符集扩展到 Unicode 时如何处理？改用哈希表记录首次位置。
  • 如果要返回子字符串本身？同时保存最佳左右端点，最后切片。
  • 如果要统计达到最大长度的字符对？更新答案时同步维护计数。

常见错误

  • 忘记排除两个端点，误写成 i - first[c]。
  • 重复出现时覆盖首次位置，导致后续距离变短。
  • 答案初始化为 0，无法区分“相邻相等”和“完全无解”。
  • 把子序列当成子字符串，忽略连续性。

为什么不是滑动窗口？

窗口内没有需要动态满足的单调约束；我们只关心相同字符的两个端点。记录最早端点即可直接算距离，滑动窗口反而会引入不必要的移动规则。

import java.util.Arrays;

class Solution {
    public int maxLengthBetweenEqualCharacters(String s) {
        int[] first = new int[26];
        Arrays.fill(first, -1);
        int answer = -1;

        for (int i = 0; i < s.length(); i++) {
            int index = s.charAt(i) - 'a';
            if (first[index] == -1) {
                first[index] = i;
            } else {
                answer = Math.max(answer, i - first[index] - 1);
            }
        }
        return answer;
    }
}

class Solution:
    def maxLengthBetweenEqualCharacters(self, s: str) -> int:
        first = [-1] * 26
        answer = -1

        for i, char in enumerate(s):
            index = ord(char) - ord("a")
            if first[index] == -1:
                first[index] = i
            else:
                answer = max(answer, i - first[index] - 1)

        return answer
