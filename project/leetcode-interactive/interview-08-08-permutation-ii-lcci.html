01 / 任务单

同样的字母，
只算一种排列。

给定字符串 S，返回它所有不重复的排列组合。 字符均为英文字母，字符串长度在 [1, 9] 之间。

示例 1 · 输入 S = "qqe" 输出 ["eqq", "qeq", "qqe"]
示例 2 · 输入 S = "ab" 输出 ["ab", "ba"]

Sort

把相同字符排在一起

只有相邻，才能用 O(1) 条件识别同层的重复候选。

Use once

下标是资源，不是字面值

Prune

跳过镜像搜索树

规则在生成前剪枝，不需要先制造重复答案再交给 Set。

Invariant

同一层，相同字符只让最靠前的可用副本先出发。

排序让副本相邻，used 区分“同层未选”与“上一层已选”。因此镜像分支在入口处被拦截，答案天然唯一。

04 / 完整题解

排序 + used + 同层去重

核心洞察

排序

让重复字符相邻

例如 "qqe" 先变为 "eqq"，相同 q 连在一起。

占用

used 管理字符下标

一次排列中每个下标只能选择一次；回溯时恢复占用状态。

剪枝

前一个副本未用就跳过

chars[i] === chars[i - 1] && !used[i - 1] 表示当前层已由前一个副本代表过。

完整过程

  1. 1. 将字符数组排序，创建同长度的 used。
  2. 2. 在每层遍历全部下标，已使用的下标直接跳过。
  3. 3. 若当前字符与前一个相同，且前一个在当前路径中尚未使用，跳过当前字符。
  4. 4. 选择字符、标记使用、递归；返回后删除字符并恢复标记。
  5. 5. 路径长度等于原串长度时收集答案。
关键不是“两个 q 永远有固定先后”，而是“同一层只让第一个可用 q 代表这个选择”。若前一个 q 已在更高层使用，当前 q 仍然可以选择。

复杂度

时间
O(n log n + U · n)

U 是不重复排列数；每个答案长度为 n，排序另需 O(n log n)。最坏 U = n!。

辅助空间
O(n)

used、路径与递归深度均为 O(n)，不计输出。

边界

  • • 长度 1：直接返回原字符。
  • • 全部相同：无论长度多大都只有 1 个答案。
  • • 全部不同且长度 9：最多 9! = 362880 个答案。
  • • 字符区分大小写，排序按语言字符顺序执行。

替代方案

  • • 频次数组 / Map：每层选择仍有库存的字符，天然去重。
  • • 原地交换 + 每层 Set：少一个 used 数组，但每层需额外集合。
  • • 全排列后全局 Set：能过小数据，却浪费重复分支与内存。

常见错误

  • • 忘记排序，导致相邻去重条件失效。
  • • 把条件写成 used[i - 1]，改变剪枝语义。
  • • 回溯后只删路径，忘记恢复 used。
  • • 用 Set 去重后仍声称没有重复搜索。

面试追问

为什么条件是 !used[i - 1]？

前一个相同字符未在路径中，说明它和当前字符处于同一层候选；前一条等价分支已经代表过当前选择。

能改成 used[i - 1] 吗？

某些写法也能形成另一种固定次序，但必须整体证明且保持一致；面试中推荐使用更常见的 !used 模板。

如何只返回第 k 个字典序排列？

用多重集合排列计数计算每个前缀的子树大小，跳过整段分支。

若字符集很小怎么优化？

使用固定频次数组代替排序下标，状态更紧凑，也天然避免同层重复。

四种语言，同一盏去重信号灯 

class Solution {
    public String[] permutation(String S) {
        char[] chars = S.toCharArray();
        Arrays.sort(chars);
        boolean[] used = new boolean[chars.length];
        List<String> answer = new ArrayList<>();
        backtrack(chars, used, new StringBuilder(), answer);
        return answer.toArray(new String[0]);
    }

    private void backtrack(char[] chars, boolean[] used,
                           StringBuilder path, List<String> answer) {
        if (path.length() == chars.length) {
            answer.add(path.toString());
            return;
        }

        for (int i = 0; i < chars.length; i++) {
            if (used[i]) {
                continue;
            }
            if (i > 0 && chars[i] == chars[i - 1] && !used[i - 1]) {
                continue;
            }

            used[i] = true;
            path.append(chars[i]);
            backtrack(chars, used, path, answer);
            path.deleteCharAt(path.length() - 1);
            used[i] = false;
        }
    }
}

var permutation = function (S) {
  const chars = [...S].sort();
  const used = Array(chars.length).fill(false);
  const answer = [];

  function backtrack(path) {
    if (path.length === chars.length) {
      answer.push(path.join(""));
      return;
    }

    for (let i = 0; i < chars.length; i += 1) {
      if (used[i]) continue;
      if (i > 0 && chars[i] === chars[i - 1] && !used[i - 1]) {
        continue;
      }

      used[i] = true;
      path.push(chars[i]);
      backtrack(path);
      path.pop();
      used[i] = false;
    }
  }

  backtrack([]);
  return answer;
};
class Solution:
    def permutation(self, S: str) -> List[str]:
        chars = sorted(S)
        used = [False] * len(chars)
        path = []
        answer = []

        def backtrack() -> None:
            if len(path) == len(chars):
                answer.append("".join(path))
                return

            for i, char in enumerate(chars):
                if used[i]:
                    continue
                if i > 0 and chars[i] == chars[i - 1] and not used[i - 1]:
                    continue

                used[i] = True
                path.append(char)
                backtrack()
                path.pop()
                used[i] = False

        backtrack()
        return answer
class Solution {
public:
    vector<string> permutation(string S) {
        sort(S.begin(), S.end());
        vector<bool> used(S.size(), false);
        vector<string> answer;
        string path;
        backtrack(S, used, path, answer);
        return answer;
    }

private:
    void backtrack(const string& chars, vector<bool>& used,
                   string& path, vector<string>& answer) {
        if (path.size() == chars.size()) {
            answer.push_back(path);
            return;
        }

        for (int i = 0; i < static_cast<int>(chars.size()); ++i) {
            if (used[i]) {
                continue;
            }
            if (i > 0 && chars[i] == chars[i - 1] && !used[i - 1]) {
                continue;
            }

            used[i] = true;
            path.push_back(chars[i]);
            backtrack(chars, used, path, answer);
            path.pop_back();
            used[i] = false;
        }
    }
};
