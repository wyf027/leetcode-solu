删除字符使字符串变好

Delete Characters to Make Fancy String

一条字符串，一次精简。你能用最少的删除，让它满足规则吗？

01 / PROBLEM

题目与目标

如果字符串中不存在连续三个相同字符，就称它为「好字符串」。给定字符串 s，删除尽可能少的字符，使剩余字符按原顺序组成好字符串，并返回这个结果。题目保证最优结果唯一。

允许删除字符；剩余字符的相对顺序不变。返回值是字符串，而不是删除数量。

参数：s: string　返回：string
函数：makeFancyString(s)

BOUNDARIES

  • 1 ≤ s.length ≤ 105
  • s 仅含小写英文字母。

04 / EDITORIAL

独立题解

准备好后展开，阅读思路、证明和四种语言实现。

核心洞察：每个连续段最多留下两个字符

设某个极大连续相同字符段长度为 L。它最多保留两个字符，因此至少删除 max(0, L − 2) 个。对每个段都保留 min(L, 2) 个字符，就恰好达到这个下界。

单次扫描的完整过程

  1. 准备结果缓冲区 ans，从左到右遍历 s。
  2. 读取当前字符 c。若 ans 长度至少为 2，且末尾两个字符都等于 c，则跳过 c。
  3. 否则将 c 追加到 ans。长度不足 2 时直接追加，无需访问不存在的位置。
  4. 遍历结束，将缓冲区转换为字符串并返回。

判断的是「当前结果末尾两个字符」，无需执行真实的中间删除操作，也无需回退扫描指针。

示例 2 的逐字符过程

输入：s = "aaabaaaa"
i    c    决策    ans
0    a    保留    a
1    a    保留    aa
2    a    删除    aa
3    b    保留    aab
4    a    保留    aaba
5    a    保留    aabaa
6    a    删除    aabaa
7    a    删除    aabaa
返回 "aabaa"，删除 3 个字符。

正确性与最少删除证明

合法性：空结果合法。假设扫描前的结果合法，跳过字符不改变结果；追加字符时，仅可能在新末尾形成三个相同字符，而条件明确阻止了这种情况。因此每一步及最终结果都合法。

最优性：对于原字符串中的每个连续段，任何合法子序列都不能保留该段的三个字符，因为它们之间没有别的字符可作为分隔。故每段至少删除 max(0, L − 2) 个。算法在每段恰好保留 min(L, 2) 个，且每段至少保留一个，相邻段的不同字符仍作为边界，不会合并。总删除数达到所有段下界之和，因而最少。

唯一性：达到最少删除数时，每段都必须保留 min(L, 2) 个。段内字符相同，选择保留哪几个下标不会改变最终字符串。

边界与复杂度

  • 长度为 1 或 2：全部保留。
  • 连续三个相同字符：只删第三个；更长连续段也只留两个。
  • 字符交替或每段不超过 2：原样返回。
  • 时间 O(n)：每个字符处理一次，最后拼接 O(n)。
  • 空间 O(n)：存储结果缓冲区；判断逻辑只需 O(1) 额外状态。下方四份实现均使用结果缓冲区。

四语言可提交代码

统一使用结果缓冲区判断末尾两个字符；以下代码仅生成，尚未编译或执行。

Java

class Solution {
    public String makeFancyString(String s) {
        StringBuilder ans = new StringBuilder();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            int n = ans.length();
            if (n >= 2 && ans.charAt(n - 1) == c
                    && ans.charAt(n - 2) == c) {
                continue;
            }
            ans.append(c);
        }
        return ans.toString();
    }
}

var makeFancyString = function(s) {
    const ans = [];
    for (const c of s) {
        const n = ans.length;
        if (n >= 2 && ans[n - 1] === c && ans[n - 2] === c) {
            continue;
        }
        ans.push(c);
    }
    return ans.join("");
};

C++

#include <string>
using namespace std;

class Solution {
public:
    string makeFancyString(string s) {
        string ans;
        ans.reserve(s.size());
        for (char c : s) {
            int n = static_cast<int>(ans.size());
            if (n >= 2 && ans[n - 1] == c && ans[n - 2] == c) {
                continue;
            }
            ans.push_back(c);
        }
        return ans;
    }
};

替代方案

可以统计原输入的当前连续段长度，仅当长度 ≤ 2 时追加字符，仍为 O(n) 时间、O(n) 结果空间。也可先分段，再输出每段最多两个字符。若输入是可修改字符数组，可用读写双指针原地压缩，工作空间 O(1)；返回不可变字符串时仍需考虑创建结果的开销。

常见错误

  • 把全局字符出现次数当成连续次数，例如 "aabaa" 中有四个 a，但它已经合法。
  • 把两个相同字符也删除：规则只禁止连续三个。
  • 在遍历时直接删除输入字符且仍递增下标，漏掉移到当前位置的字符。
  • 反复拼接不可变字符串或做中间删除，可能导致 O(n²) 开销。
  • 访问末尾两个字符前未处理结果长度不足 2 的情况。
  • 返回删除数量，而题目要求返回处理后的字符串。

面试追问

  • 如果禁止连续 k 个相同字符？对 k ≥ 2，每段最多保留 k − 1 个，使用连续计数即可。
  • 能否流式处理？可以，只记住最后输出字符和其连续次数；输出写入外部流时，内部工作状态 O(1)。
  • 怎样求最少删除数量？用 s.length 减去结果长度，或累计各段 max(0, L − 2)。
  • 如果每个字符删除代价不同？按个数贪心不再直接回答代价问题，需要重新分析目标及段间可能的影响。
