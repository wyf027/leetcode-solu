相等的有理数

两个长得完全不同的循环小数，可能站在数轴的同一个点。先自己观察它们的展开规律，再决定是否查看精确解法。

HARD数学字符串非付费题

题目

给定字符串 s 与 t，它们各自表示一个非负有理数。括号包住无限循环的小数部分。仅当两种写法代表完全相同的数时返回 true。

合法形式为整数 I、有限小数 I.N，或循环小数 I.N(R)。其中整数部分长度 1～4 且除 0 外无前导零；非循环部分长度 0～4；若存在循环部分，其长度 1～4；各部分均只含数字。

示例 1
输入：s = "0.(52)", t = "0.5(25)"
输出：true
二者都展开为 0.525252…
示例 2
输入：s = "0.1666(6)", t = "0.166(66)"
输出：true
示例 3
输入：s = "0.9(9)", t = "1."
输出：true
0.999… 精确等于 1。
函数签名
isRationalEqual(s: string, t: string): boolean
注意：这是精确相等，不是浮点近似。

循环小数解剖台

用内置样例逐帧观察字符串如何变成不可约的精确分数。

s = 0.(52)
?
t = 0.5(25)

题解：把无限写法压缩成一个分数

核心洞察

不要展开无限位，也不要使用浮点数。将每个字符串严格转换成整数分子与分母，再交叉相乘比较。设整数部分为 I，非循环串长度为 m、对应整数为 A，循环串长度为 n、对应整数为 B：

无循环：(I × 10^m + A) / 10^m
有循环：[I×10^m×(10^n−1) + A×(10^n−1) + B] / [10^m×(10^n−1)]

这个表达式自然处理空非循环部分，也会让 0.9(9) 得到 1。实现中用大整数，避免交叉乘法溢出。

完整过程

  1. 按小数点和括号解析 I、A、B。
  2. 计算 10^m；有循环时再算 10^n−1。
  3. 按公式构造分子、分母。
  4. 无需约分：判断 p₁q₂ == p₂q₁。

正确性

有限部分是 A/10^m。循环部分由几何级数得到 B/[10^m(10^n−1)]。公式把整数、有限部分、循环部分相加到同一分母，因此所得分数与原串精确相等。两个有理数相等当且仅当它们交叉乘积相等，故算法返回值正确。

边界与复杂度

  • 1. 的非循环部分为空，按 0 位处理。
  • .(9) 型循环可产生整数进位。
  • 循环节可有前导零，如 0.(01)。
  • 时间 O(|s|+|t|)，额外空间 O(|s|+|t|)（大整数位数）。

替代方案

也可把小数展开到足够多位后比较；题目长度有限时可行，但证明阈值更绕，且容易漏掉 0.999…=1。精确分数更直接、可证明，也不依赖误差常量。

四语言完整代码

import java.math.BigInteger;

class Solution {
    private BigInteger[] parse(String s) {
        String[] halves = s.split("\\.", -1);
        BigInteger integer = new BigInteger(halves[0]);
        String decimal = halves.length == 1 ? "" : halves[1];
        int open = decimal.indexOf('(');
        String non = open < 0 ? decimal : decimal.substring(0, open);
        String rep = open < 0 ? "" : decimal.substring(open + 1, decimal.length() - 1);
        BigInteger tenM = BigInteger.TEN.pow(non.length());
        BigInteger a = non.isEmpty() ? BigInteger.ZERO : new BigInteger(non);
        if (rep.isEmpty()) return new BigInteger[]{integer.multiply(tenM).add(a), tenM};
        BigInteger factor = BigInteger.TEN.pow(rep.length()).subtract(BigInteger.ONE);
        BigInteger b = new BigInteger(rep);
        BigInteger den = tenM.multiply(factor);
        BigInteger num = integer.multiply(den).add(a.multiply(factor)).add(b);
        return new BigInteger[]{num, den};
    }
    public boolean isRationalEqual(String s, String t) {
        BigInteger[] x = parse(s), y = parse(t);
        return x[0].multiply(y[1]).equals(y[0].multiply(x[1]));
    }
}
/** @param {string} s @param {string} t @return {boolean} */
var isRationalEqual = function(s, t) {
  const parse = (text) => {
    const [whole, raw = ""] = text.split(".");
    const open = raw.indexOf("(");
    const non = open < 0 ? raw : raw.slice(0, open);
    const rep = open < 0 ? "" : raw.slice(open + 1, -1);
    const tenM = 10n ** BigInt(non.length);
    const a = non ? BigInt(non) : 0n;
    if (!rep) return [BigInt(whole) * tenM + a, tenM];
    const factor = 10n ** BigInt(rep.length) - 1n;
    const den = tenM * factor;
    const num = BigInt(whole) * den + a * factor + BigInt(rep);
    return [num, den];
  };
  const [p, q] = parse(s), [r, u] = parse(t);
  return p * u === r * q;
};
class Solution:
    def isRationalEqual(self, s: str, t: str) -> bool:
        def parse(text: str):
            whole, dot, raw = text.partition('.')
            if '(' in raw:
                non, rep = raw.split('(')
                rep = rep[:-1]
            else:
                non, rep = raw, ''
            ten_m = 10 ** len(non)
            a = int(non) if non else 0
            if not rep:
                return int(whole) * ten_m + a, ten_m
            factor = 10 ** len(rep) - 1
            den = ten_m * factor
            num = int(whole) * den + a * factor + int(rep)
            return num, den
        p, q = parse(s)
        r, u = parse(t)
        return p * u == r * q
#include <string>
#include <utility>
#include <boost/multiprecision/cpp_int.hpp>
using namespace std;
using boost::multiprecision::cpp_int;

class Solution {
    cpp_int number(const string& s) {
        cpp_int x = 0;
        for (char c : s) x = x * 10 + (c - '0');
        return x;
    }
    cpp_int pow10(int n) {
        cpp_int x = 1;
        while (n--) x *= 10;
        return x;
    }
    pair<cpp_int, cpp_int> parse(const string& s) {
        size_t dot = s.find('.'), open = s.find('(');
        string whole = s.substr(0, dot);
        string non = dot == string::npos ? "" : s.substr(dot + 1,
            (open == string::npos ? s.size() : open) - dot - 1);
        string rep = open == string::npos ? "" : s.substr(open + 1, s.size() - open - 2);
        cpp_int tenM = pow10(non.size()), a = non.empty() ? 0 : number(non);
        if (rep.empty()) return {number(whole) * tenM + a, tenM};
        cpp_int factor = pow10(rep.size()) - 1, den = tenM * factor;
        return {number(whole) * den + a * factor + number(rep), den};
    }
public:
    bool isRationalEqual(string s, string t) {
        auto [p, q] = parse(s); auto [r, u] = parse(t);
        return p * u == r * q;
    }
};

面试追问

  • 为什么无需先约分？
  • 若允许负数，解析和比较要改什么？
  • 如何不借助大整数仍保证安全？
  • 能否证明有限展开比较所需的最少位数？

常见错误

  • 用 double 或误差阈值判断。
  • 把空非循环部分当成非法输入。
  • 忘记循环节前要乘 10^m。
  • 固定展开位数却没有给出充分证明。
  • 普通整数交叉相乘发生溢出。
