最接近的
二叉搜索树值

给定一棵非空二叉搜索树的根节点 root 和浮点目标值 target，返回树中与目标值绝对差最小的节点值；若距离相同，返回较小的值。

树深度优先搜索二叉搜索树二分查找二叉树

Problem

题目说明

函数形式：closestValue(root: TreeNode, target: double) -> integer。输入保证 root 是一棵合法且非空的二叉搜索树。

示例 1

输入：root = [4,2,5,1,3], target = 3.714286
输出：4
解释：|4 - 3.714286| 小于其他节点与目标的距离。

输入：root = [1], target = 4.428571
输出：1

约束

  • 树中节点数在 [1, 10⁴] 范围内。
  • 0 <= Node.val <= 10⁹。
  • -10⁹ <= target <= 10⁹。
  • 输入树满足二叉搜索树性质。

Solution

利用 BST 的单路径迭代

核心洞察

在任一节点 x，先用它更新目前的最近值。若 target < x，右子树所有值都大于 x，不可能比继续向左更有必要；反之只需向右。于是搜索始终沿一条根到叶的路径进行。

更新最近值时比较二元组 (|value-target|, value)：先看距离，再在等距时选数值较小者。

完整过程

  1. 令 closest = root.val，node = root。
  2. 比较当前值与 closest 到目标的距离；更近或等距但更小时更新。
  3. 目标更小则进入左子树，目标更大则进入右子树；若相等则立即返回。
  4. 走到空节点时，返回记录的 closest。

正确性说明

循环不变量：每次迭代开始时，closest 是所有已访问节点中按“距离优先、数值次优先”规则最优的值。当前节点经过比较后，不变量继续成立。

剪枝安全性：若目标小于当前值，当前节点右子树的值都更大，和目标的差也严格大于当前值与目标的差；当前值已经参与候选比较，因此右子树无需访问。目标大于当前值时对左子树同理。

终止与结论：每轮下降一层，最终命中目标或到达空节点。被舍弃的子树不可能产生优于已比较当前节点的答案，因此结束时 closest 即全树最优答案。

复杂度

时间：O(h)，其中 h 为树高；平衡树为 O(log n)，退化树最坏为 O(n)。额外空间：O(1)。

边界情况

  • 只有一个节点：初始值就是答案。
  • 目标小于最小值或大于最大值：路径会走到最左或最右节点。
  • 目标恰好等于某节点：距离为零，可立即返回。
  • 两个节点等距：显式使用数值较小者，避免依赖遍历顺序。
  • 树高接近节点数：迭代写法不会产生递归栈溢出。

四语言完整代码

均按 LeetCode 提供 TreeNode 定义的环境编写。

Java

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    public int closestValue(TreeNode root, double target) {
        int closest = root.val;
        TreeNode node = root;

        while (node != null) {
            double currentDiff = Math.abs(node.val - target);
            double bestDiff = Math.abs(closest - target);

            if (currentDiff < bestDiff ||
                (currentDiff == bestDiff && node.val < closest)) {
                closest = node.val;
            }

            if (target == node.val) {
                return node.val;
            }
            node = target < node.val ? node.left : node.right;
        }

        return closest;
    }
}

替代方案

中序遍历 + 二分：先把 BST 转为递增数组，再二分目标附近的两个值。单次查询需要 O(n) 时间和空间；如果同一棵树要处理很多目标，可以预处理一次后让每次查询降至 O(log n)。

全树 DFS：逐个比较所有节点，时间 O(n)、递归空间 O(h)。写法直观，但没有利用 BST 有序性。

面试追问

  • 如果要返回最接近的 k 个值，怎样结合双栈前驱/后继迭代器？
  • 如果查询非常多，是否值得缓存中序数组？如何权衡更新成本？
  • 若树允许重复值或题目改变等距规则，比较器应如何调整？
  • 如何证明只走一条分支仍不会错过更近的值？

常见错误

  • 先移动到子节点再更新答案，导致漏掉当前节点。
  • 只比较距离，没有处理等距时取较小值。
  • 把浮点目标强制转换为整数，破坏距离比较。
  • 无条件递归整棵树，失去 BST 带来的单路径优势。
  • 在退化树上使用深递归，却没有考虑调用栈上限。
