范围内的数字计数

Digit Count in Range · 数学 / 动态规划

用十进制位置的完整周期，快速统计目标数字。

题目

给定数字 d 与正整数 low、high，统计 d 在闭区间 [low, high] 所有整数的十进制表示中总共出现多少次。

官方参数形式： digitsCount(d, low, high) → integer

示例 1

输入：d = 1, low = 1, high = 13
输出：6
解释：1、10、11、12、13 中共有 6 个 1。

示例 2

输入：d = 3, low = 100, high = 250
输出：35

约束

  • 0 ≤ d ≤ 9
  • 1 ≤ low ≤ high ≤ 2 × 10⁸

    题解
    核心洞察
    定义 count(n,d) 为 1 到 n 中 d 的出现次数，答案为 count(high,d) - count(low-1,d)。前缀计数可按十进制位置分解。
    完整过程
    1. factor 依次取 1、10、100……
    2. higher=floor(n/(factor×10))，current=floor(n/factor)%10，lower=n%factor。
    3. d 非零时，完整周期贡献 higher×factor；尾段按 current 小于、等于、大于 d 分别补 0、lower+1、factor。
    4. d 为零时排除前导零：higher 为 0 时不计；否则完整周期改为 (higher-1)×factor，再加入尾段。
    正确性
    每连续 10×factor 个数形成一个完整周期，目标非零数字在固定位置恰出现 factor 次。higher 覆盖完整周期，current 与 lower 覆盖唯一尾段；零的公式再删除不存在的前导位。所有位置互不重叠且覆盖全部数字位，故前缀计数正确；两前缀相减正好得到闭区间。
    边界与复杂度
    • n≤0 返回 0；d=0 不可统计前导零；low=1 时左前缀为 0。
    • 中间乘法使用足够宽的整数类型。
    • 时间 O(log high)，额外空间 O(1)。

    替代方案
    数位 DP 可记录位置、上界限制、是否开始、累计出现次数，扩展性更强；本题的周期公式更短且只需常数空间。
    面试追问
    如何同时统计 0..9？
    每个位置更新十个计数桶，零仍单独排除前导位。
    若区间包含整数 0？
    先约定 0 的表示是否贡献一个零，再作为特殊项加入。
    为何不逐个转字符串？
    枚举与区间长度成正比，本算法只与位数成正比。
    常见错误
    • 漏掉两个前缀相减。
    • 把前导零计入答案。
    • current=d 时漏掉 lower+1 中的 1。
    • factor×10 整数溢出。
