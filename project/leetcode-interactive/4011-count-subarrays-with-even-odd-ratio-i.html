按奇偶比统计子数组 I

把每个元素只看成“奇”或“偶”。本题要在所有非空连续片段中，找出偶数/奇数 的精确比例不超过给定比例 a / b 的片段。

题目

给你整数数组 nums 以及正整数 a、b。 对非空子数组 nums[l..r]，令 x 为偶数个数、 y 为奇数个数；当 y > 0 且 x / y ≤ a / b（精确有理数比较）时，该子数组有效。

示例 1
nums = [1, 2, 1, 2], a = 3, b = 2
输出：7。只含偶数的子数组不合法，因为 y = 0。
约束
1 ≤ nums.length ≤ 1000
1 ≤ nums[i], a, b ≤ 1000

核心洞察：交叉相乘，不做除法

当 y > 0 时，x / y ≤ a / b 等价于 x × b ≤ y × a。所有数都非负且范围很小， 交叉相乘既精确又不会受到浮点误差影响。

判定公式
odd > 0 && even × b ≤ odd × a

完整过程

固定左端点 l，向右扩展 r；每加入一个数， 更新 odd 或 even，再按公式判断并累加答案。

边界与替代方案

全偶数组始终无效；a / b 不必约分。I 的 n ≤ 1000 适合 O(n²)；II 可把偶数映射为 b、 奇数映射为 -a，用前缀和 + 树状数组计数。
