省份数量 Number of Provinces

把邻接矩阵还原成城市网络，再亲手数出彼此独立的连通块。

题目

有 n 个城市。直接相连关系可形成间接连通：若 A 与 B 直接相连、B 与 C 直接相连，那么 A 与 C 间接相连。“省份”是内部直接或间接相连、且与集合外城市不连通的一组城市。

给定 n × n 邻接矩阵 isConnected，isConnected[i][j] = 1 表示城市 i、j 直接相连，否则为 0。返回省份总数。

示例 1

输入：isConnected = [[1,1,0],[1,1,0],[0,0,1]]
输出：2

城市 0、1 为一省；城市 2 单独为一省。

示例 2

输入：isConnected = [[1,0,0],[0,1,0],[0,0,1]]
输出：3

三个城市互不相连，各自构成一个省份。

约束

  • 1 <= n <= 200
  • n == isConnected.length == isConnected[i].length
  • 元素只能为 0 或 1
  • isConnected[i][i] == 1
  • isConnected[i][j] == isConnected[j][i]

完整题解

建议先操作上面的实验，再展开分析。

核心洞察

矩阵描述一张无向图，省份数量就是图的连通分量数。从左到右检查城市；遇到未访问城市，答案加一，并用 DFS 一次标记它能到达的全部城市。

完整过程

  1. 创建长度为 n 的访问数组。
  2. 枚举城市 i。
  3. 若未访问，省份数加一，从 i 启动 DFS。
  4. DFS 扫描当前城市对应的完整矩阵行，递归访问相连且未访问的邻居。
  5. 枚举结束后返回计数。

正确性

覆盖：每座城市都会由外层循环发现，或由某次 DFS 到达。

恰计一次：一次 DFS 恰好访问起点所在的整个连通分量；访问标记使同一分量不再启动 DFS。不同启动点属于不同分量，所以每个省份不重不漏地计数一次。

边界

  • 单个城市：1
  • 全部独立：n
  • 全部连通：1
  • 对角线的 1 不改变结果

复杂度

邻接矩阵的每行都可能被扫描，时间 O(n²)；访问数组和最坏递归栈空间 O(n)。

替代方案

BFS 同为 O(n²)。并查集适合动态增加连接，静态矩阵中时间为 O(n² α(n)) 且代码略长。

四种语言实现

class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length, provinces = 0;
        boolean[] visited = new boolean[n];
        for (int city = 0; city < n; city++) {
            if (!visited[city]) {
                provinces++;
                dfs(city, isConnected, visited);
            }
        }
        return provinces;
    }
    private void dfs(int city, int[][] graph, boolean[] visited) {
        visited[city] = true;
        for (int next = 0; next < graph.length; next++)
            if (graph[city][next] == 1 && !visited[next])
                dfs(next, graph, visited);
    }
}

面试追问

  • 邻接表输入？时间变为 O(n + e)。
  • 避免递归栈过深？改用显式栈或 BFS。
  • 连接在线增加？维护并查集。
  • 矩阵不对称？先明确弱连通还是强连通。

常见错误

  • 把 1 或边的数量当作省份数。
  • DFS 返回后才标记，导致环上重复递归。
  • 未扫描完整矩阵行。
  • 对已访问城市重复加一。
  • 忽略间接连通关系。
