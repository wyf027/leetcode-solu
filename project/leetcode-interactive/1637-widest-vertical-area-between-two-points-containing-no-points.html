Vertical Gap Explorer

两点之间不包含任何点的
最宽垂直区域

在二维点阵中寻找一条沿 y 轴无限延伸、内部没有任何给定点的最宽竖直带。先理解“区域内部”和“边界”的含义，再动手探索。

Problem

题目描述

给定二维平面上的 n 个点，points[i] = [xᵢ, yᵢ]。请返回由两条竖直边界围成、且内部不包含任何给定点的区域所能达到的最大宽度。

垂直区域的宽度固定，并沿 y 轴向上下无限延伸。因此，一个点是否落入区域只取决于它的 x 坐标。

边界约定：落在两条竖直边界上的点不算位于区域内部，所以它们可以作为区域的边界。

函数签名

maxWidthOfVerticalArea(points: integer[][]) -> integer

约束

  • n == points.length
  • 2 <= n <= 10⁵
  • points[i].length == 2
  • 0 <= xᵢ, yᵢ <= 10⁹

示例 1

输入points = [[8,7],[9,9],[7,4],[9,7]]
输出1
解释宽度为 1 的最优区域不止一个，例如 x = 7 与 x = 8 之间。

示例 2

输入points = [[3,1],[9,0],[1,0],[1,4],[5,3],[8,8]]
输出3

排序横坐标，检查相邻间隔

核心洞察完整过程正确性代码测试与验证

核心洞察

1

y 坐标不影响宽度

区域沿 y 轴无限延伸，只要点的 x 坐标严格位于左右边界之间，它就在区域内部；点有多高并不重要。

2

只看排序后的相邻 x

把所有 x 坐标升序排列。任意内部无点的竖直带，其左右边界都能移动到两个相邻 x 上而不缩小，所以最优宽度必是某个相邻差。

3

重复 x 自然得到 0

同一竖线上可以有多个点。排序后重复坐标的差为 0，不会错误增大答案，也无需专门去重。

完整过程

  1. 从每个点取出横坐标 x。
  2. 将 x 坐标按非递减顺序排序。
  3. 从第二个坐标开始，计算 xs[i] - xs[i - 1]。
  4. 维护这些相邻差的最大值并返回。
示例 2：x 坐标排序后是 [1, 1, 3, 5, 8, 9]，相邻差为 [0, 2, 2, 3, 1]，最大值为 3。

正确性证明

引理：排序后的任意两个相邻横坐标 xs[i-1] 与 xs[i] 之间，区域内部没有给定点。否则，该点的横坐标会严格位于两者之间，与“相邻”矛盾。因此每个相邻差都是一个合法垂直区域的宽度。

上界：考虑任意合法区域。若其左右边界之间存在某个点的横坐标，该点会落在区域内部，区域便不合法。因此两条边界不能跨过排序序列中的中间横坐标；该区域宽度不会超过某一对相邻横坐标之差。

结论：算法枚举了全部相邻差，既只产生合法宽度，又包含最优解的上界，所以返回值恰为最宽合法垂直区域。

复杂度

时间：O(n log n)，排序占主导。

空间：O(n)，四份实现都额外保存横坐标数组；语言排序本身还可能使用额外栈或缓冲空间。

边界情况

  • 仅两个点：答案就是两个 x 的差。
  • 所有 x 相同：所有相邻差为 0。
  • 存在重复 x：无需去重。
  • 坐标到 10⁹：32 位有符号整数足够容纳单次差值。

替代方案

可以直接按 x 排序整个 points，避免单独构造横坐标数组，但会改变输入顺序。还可基于鸽巢原理做桶划分，达到期望的 O(n) 时间；实现明显更复杂，且本题排序方案已经清晰可靠。

常见错误

  • 把 y 坐标纳入距离计算。
  • 计算任意两点的欧氏距离。
  • 只找不同 x，却错误处理重复坐标。
  • 排序后忘记比较最后一对相邻坐标。
  • 误认为边界上的点会使区域非法。

面试追问

能否原地完成？

按每个点的 x 对 points 原地排序，再扫描相邻点，可省去横坐标数组，但会修改输入。

为什么只看相邻点？

非相邻横坐标之间至少还有一个横坐标，对应的点会落在区域内部。

若区域高度有限呢？

此时 y 坐标重新相关，问题会变成二维空矩形或区间查询，当前降维方法不再成立。

import java.util.Arrays;

class Solution {
    public int maxWidthOfVerticalArea(int[][] points) {
        int[] xs = new int[points.length];
        for (int i = 0; i < points.length; i++) {
            xs[i] = points[i][0];
        }

        Arrays.sort(xs);
        int answer = 0;
        for (int i = 1; i < xs.length; i++) {
            answer = Math.max(answer, xs[i] - xs[i - 1]);
        }
        return answer;
    }
}

from typing import List

class Solution:
    def maxWidthOfVerticalArea(self, points: List[List[int]]) -> int:
        xs = sorted(x for x, _ in points)
        return max(xs[i] - xs[i - 1] for i in range(1, len(xs)))
class Solution {
public:
    int maxWidthOfVerticalArea(vector<vector<int>>& points) {
        vector<int> xs;
        xs.reserve(points.size());
        for (const auto& point : points) {
            xs.push_back(point[0]);
        }

        sort(xs.begin(), xs.end());
        int answer = 0;
        for (int i = 1; i < static_cast<int>(xs.size()); ++i) {
            answer = max(answer, xs[i] - xs[i - 1]);
        }
        return answer;
    }
};
