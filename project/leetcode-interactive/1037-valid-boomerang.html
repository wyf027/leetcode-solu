有效的
回旋镖

三个点，两个方向，一个决定：它们究竟撑开了一个三角形，还是悄悄落在同一条直线上？

先阅读题目并动手观察。核心判定与代码被收在页面底部，不会在首屏直接泄露。

题目

给定三个位于 X-Y 平面上的点 points，其中 points[i] = [xᵢ, yᵢ]。如果三个点互不相同，并且不在同一直线上，返回 true；否则返回 false。

函数形式：boolean isBoomerang(int[][] points)（不同语言的容器类型相应变化）

约束

  • points.length == 3
  • points[i].length == 2
  • 0 <= xᵢ, yᵢ <= 100

坐标范围很小，但判定方法同样适用于更大的整数坐标；使用乘法交叉比较还能避免浮点斜率问题。

官方示例

示例 1
输入：points = [[1,1],[2,3],[3,2]]
输出：true
示例 2
输入：points = [[1,1],[2,2],[3,3]]
输出：false

几何实验台

逐步观察两条从 A 出发的向量如何决定图形是否“撑开”。你也可以输入三个坐标重新演示。

准备观察三个点。
演示进度
1. 标出 A、B、C
2. 连接向量 AB
3. 连接向量 AC
4. 比较方向并下结论

题解：用有向面积拒绝共线

不要算斜率。计算二维向量的叉积：结果不为 0，就意味着两个方向不同，三点构成的三角形面积也不为 0。

核心洞察与完整过程

  1. 把第一个点记为 A，构造向量 AB 与 AC。
  2. 计算叉积 (Bx−Ax)(Cy−Ay) − (By−Ay)(Cx−Ax)。
  3. 叉积等于 0：两向量平行，三点共线（重合点也自然包含在内）。
  4. 叉积不等于 0：三点互异且不共线，返回 true。

正确性说明

二维叉积的绝对值等于由 AB、AC 张成的平行四边形面积。若结果为 0，该面积为 0，两向量线性相关，因此 A、B、C 共线；若不为 0，面积为正，三个点形成非退化三角形，也必然互不相同，所以恰好满足回旋镖定义。

边界与常见错误

  • 三个点中存在重合点：叉积为 0，返回 false。
  • 水平线、竖直线和负斜率都无需特殊处理。
  • 不要比较浮点斜率：竖线需要除零处理，浮点数也会引入误差。
  • 不要只检查点是否不同；三个不同点仍可能共线。
  • 更大坐标范围下，乘积应使用 64 位整数防止溢出。

复杂度与替代方案

时间：O(1)；空间：O(1)。

替代方案可比较 AB 与 AC 的斜率，但需要交叉相乘才能避开除法；化简后其实就是同一个叉积等式。也可用鞋带公式求三角形面积，本质仍相同。

面试追问

如果扩展为判断多个点是否全部共线，可固定前两个不同点，并逐个检查其与后续点的叉积是否都为 0。

四语言完整代码

class Solution {
    public boolean isBoomerang(int[][] points) {
        int ax = points[0][0], ay = points[0][1];
        int abx = points[1][0] - ax;
        int aby = points[1][1] - ay;
        int acx = points[2][0] - ax;
        int acy = points[2][1] - ay;
        return abx * acy - aby * acx != 0;
    }
}
/**
 * @param {number[][]} points
 * @return {boolean}
 */
var isBoomerang = function(points) {
    const [a, b, c] = points;
    const abx = b[0] - a[0];
    const aby = b[1] - a[1];
    const acx = c[0] - a[0];
    const acy = c[1] - a[1];
    return abx * acy - aby * acx !== 0;
};
from typing import List

class Solution:
    def isBoomerang(self, points: List[List[int]]) -> bool:
        (ax, ay), (bx, by), (cx, cy) = points
        abx, aby = bx - ax, by - ay
        acx, acy = cx - ax, cy - ay
        return abx * acy - aby * acx != 0
