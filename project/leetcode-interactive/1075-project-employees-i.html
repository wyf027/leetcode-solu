项目员工 I

把“员工属于哪个项目”和“员工有多少年经验”连接起来，再按项目求平均值。先亲手走完数据流，再决定是否展开题解。

EASYSQL分组聚合Project Employees I

题意

Project 记录项目与员工的隶属关系，Employee 记录员工姓名及工作年限。请查询每个项目中所有员工的平均工作年限，将结果四舍五入到小数点后两位；结果顺序不限。

目标列： project_id、average_years

约束与表关系

  • Project(project_id, employee_id) 为联合主键。
  • Project.employee_id 外键关联 Employee.employee_id。
  • Employee.employee_id 为主键。
  • experience_years 保证非空。

因此每条项目成员记录都能唯一匹配一名员工，聚合时不会因员工表重复键而放大行数。

题解

核心洞察

需要的分组键来自 Project，需要聚合的数值来自 Employee。先按 employee_id 连接两表，再按 project_id 分组，对 experience_years 求平均并保留两位小数。

完整过程

  1. 用内连接为每条项目成员关系补上工作年限。
  2. 以项目编号划分聚合组。
  3. 对每组的工作年限使用 AVG。
  4. 用 ROUND(..., 2) 得到要求的精度，并命名为 average_years。

正确性

外键保证每条 Project 记录都匹配到对应员工，员工主键保证恰好匹配一次。因此，连接后项目 p 的行集合与其成员集合一一对应，其中每行携带该成员的真实工作年限。按 p 分组后，AVG 计算的正是全部成员年限之和除以成员数；最后的 ROUND 只改变展示精度。所以输出对每个项目给出了所求平均值。

边界与复杂度

  • 单成员项目的平均值就是该员工年限。
  • 同一员工可以参与多个项目，应在每个项目中分别计入。
  • 结果允许任意顺序，不必添加 ORDER BY。
  • 概念上扫描 P 条项目成员关系及 E 名员工；哈希连接与聚合期望时间 O(P + E)，额外空间 O(E + K)，其中 K 为项目数。实际由数据库优化器决定。

替代方案

也可写相关子查询，对每个项目查员工经验平均值，但通常会重复访问数据，表达也不如“JOIN + GROUP BY”直接。若数据库有合适索引，优化器可能将两者改写为相近计划。

面试追问

  • 若要保留没有员工的项目，需要独立的项目主表并使用左连接。
  • 若 experience_years 可为 NULL，AVG 默认忽略 NULL；业务是否接受需明确。
  • 若要求按员工薪资加权，应使用 SUM(years * weight) / SUM(weight)。

常见错误

  • 忘记 GROUP BY project_id，只得到全局平均。
  • 连接键写成 project_id，导致错误关联。
  • 使用整数除法手写平均值，丢失小数。
  • 只格式化显示却没有按题意四舍五入。

代码

MySQL 是官方可提交语言。Java、JavaScript、Python、C++ 不是本数据库题的 LeetCode 提交语言，仅作为“对两张内存表执行同等语义”的本地参考。

SELECT
    p.project_id,
    ROUND(AVG(e.experience_years), 2) AS average_years
FROM Project AS p
INNER JOIN Employee AS e
    ON p.employee_id = e.employee_id
GROUP BY p.project_id;
import java.util.*;

class Solution {
    record ProjectRow(int projectId, int employeeId) {}
    record Employee(int id, String name, int years) {}
    record Result(int projectId, double averageYears) {}

    static List<Result> projectEmployeesI(
            List<ProjectRow> project, List<Employee> employee) {
        Map<Integer, Integer> years = new HashMap<>();
        for (Employee e : employee) years.put(e.id(), e.years());
        Map<Integer, long[]> groups = new TreeMap<>();
        for (ProjectRow p : project) {
            long[] value = groups.computeIfAbsent(p.projectId(), k -> new long[2]);
            value[0] += years.get(p.employeeId());
            value[1]++;
        }
        List<Result> answer = new ArrayList<>();
        for (var entry : groups.entrySet()) {
            double avg = Math.round(entry.getValue()[0] * 100.0 / entry.getValue()[1]) / 100.0;
            answer.add(new Result(entry.getKey(), avg));
        }
        return answer;
    }
}
function projectEmployeesI(project, employee) {
  const years = new Map(employee.map(e => [e.employee_id, e.experience_years]));
  const groups = new Map();
  for (const row of project) {
    const value = groups.get(row.project_id) ?? { sum: 0, count: 0 };
    value.sum += years.get(row.employee_id);
    value.count += 1;
    groups.set(row.project_id, value);
  }
  return [...groups].map(([project_id, value]) => ({
    project_id,
    average_years: Math.round((value.sum / value.count + Number.EPSILON) * 100) / 100
  }));
}
from collections import defaultdict

def project_employees_i(project: list[dict], employee: list[dict]) -> list[dict]:
    years = {e["employee_id"]: e["experience_years"] for e in employee}
    groups = defaultdict(list)
    for row in project:
        groups[row["project_id"]].append(years[row["employee_id"]])
    return [
        {"project_id": pid, "average_years": round(sum(values) / len(values), 2)}
        for pid, values in groups.items()
    ]
#include <cmath>
#include <map>
#include <string>
#include <tuple>
#include <utility>
#include <vector>
using namespace std;

struct Result { int projectId; double averageYears; };

vector<Result> projectEmployeesI(
    const vector<pair<int, int>>& project,
    const vector<tuple<int, string, int>>& employee) {
    map<int, int> years;
    for (const auto& [id, name, experience] : employee) years[id] = experience;
    map<int, pair<long long, int>> groups;
    for (const auto& [projectId, employeeId] : project) {
        groups[projectId].first += years[employeeId];
        groups[projectId].second++;
    }
    vector<Result> answer;
    for (const auto& [id, aggregate] : groups) {
        double avg = round(aggregate.first * 100.0 / aggregate.second) / 100.0;
        answer.push_back({id, avg});
    }
    return answer;
}
