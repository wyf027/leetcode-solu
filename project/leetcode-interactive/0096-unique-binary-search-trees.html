Core insight

节点值不重要，左右规模才重要

固定根后，左子树只能使用更小的值，右子树只能使用更大的值。相同节点数量能形成的结构数相同，因此状态只需要记录规模。

Complete process

完整过程

  1. 定义 dp[k] 为 k 个节点可形成的 BST 数。
  2. 设置 dp[0] = 1，让空子树能参与乘法。
  3. 枚举总节点数 nodes，再枚举左子树规模 left。
  4. 令 right = nodes − 1 − left，累加 dp[left] × dp[right]。

Boundary

边界条件

  • dp[0] = 1 表示“唯一的空结构”。
  • n = 1 时只有单节点树。
  • n = 19 的答案为 1767263190，仍在 32 位有符号整数范围内。

Complexity & alternative

复杂度与替代方案

DP 时间 O(n²)，空间 O(n)。卡特兰递推可在 O(n) 时间、O(1) 空间计算，但乘除顺序与溢出更容易出错；面试中 DP 更便于解释和扩展。

Interview follow-ups

面试追问

  • 为什么左右子树方案数要相乘？
  • 如何利用左右对称减少常数？
  • 怎样推导 O(n) 的卡特兰递推？
  • 如果 n 很大并要求取模，类型和公式如何调整？

Common mistakes

常见错误

  • 把 dp[0] 设为 0，导致所有乘积都变成 0。
  • 右子树规模写成 nodes − left，忘记扣除根。
  • 把左右方案相加而不是相乘。
  • 直接用阶乘公式，忽略中间值溢出。

class Solution {
    public int numTrees(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;

        for (int nodes = 1; nodes <= n; nodes++) {
            for (int left = 0; left < nodes; left++) {
                int right = nodes - 1 - left;
                dp[nodes] += dp[left] * dp[right];
            }
        }
        return dp[n];
    }
}
