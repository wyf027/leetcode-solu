01 / 题目与数据契约

公司有 $70,000 薪资预算。候选人分为资深职员 Senior 和初级职员 Junior。先持续录用当前薪资最低的 Senior，直到无法再录用；然后用余额，以同样规则录用 Junior。返回所有被录用者的 employee_id，结果行顺序不限。

Candidates 输入表结构
字段类型含义
employee_idINT唯一候选人 ID
experienceENUMSenior 或 Junior
salaryINT月薪
  • 每行表示一位候选人；employee_id 唯一，所有候选人的 salary 也互不相同。
  • 总预算固定为 70000，薪资恰好等于可用余额时可以录用。
  • 输出只有 employee_id 列，不是 Senior / Junior 的人数统计。
  • 可获得的题面没有单独列出行数、ID 或薪资的数值上下界，故不编造范围。

05 / 独立题解

准备好后，再展开思路、证明与代码。

核心洞察：每一组的录用结果都是薪资前缀

规则已经指定了选择顺序，无需做背包。组内按薪资升序排列，前 k 人的薪资和就是录用这 k 人的费用。资深组先与 70000 比较；初级组再与资深招聘结束后的余额比较。

完整过程与 SQL 对应

  1. running 按 experience 分区、salary 排序，用窗口 SUM 为每一行计算包含自己的前缀费用 cost。
  2. seniors 保留 cost ≤ 70000 的 Senior；每一行仍携带 employee_id。
  3. budget 取已录用 Senior 的最大 cost，得到其总支出。没有 Senior 入选时 MAX 为 NULL，用 COALESCE 转成 0。
  4. 在 Junior 分区中选择 cost ≤ remaining 的行，与 Senior 的 ID 用 UNION ALL 合并。

不能对 seniors.cost 再求 SUM：每个 cost 已经包含前面薪资，累加这些前缀会重复计费。应取 MAX(cost)。

示例 1 的前缀

Senior 队列为 11 → 2 → 13，费用前缀为 16000 → 36000 → 86000，因此选前两人。余额 34000；Junior 队列为 1 → 9 → 4，费用前缀为 10000 → 25000 → 65000，因此也选前两人。

正确性

对任一薪资从低到高排列的组，设前缀费用为 P(k)。逐人招聘第 k 人成功，当且仅当前 k 人总费用 P(k) 不超过该组起始预算。薪资费用非负时，前缀费用单调不减；一旦失败，更长前缀也无法支付。因此窗口条件恰好筛出按规则能录用的连续前缀。

Senior 使用完整预算，得到规则要求的资深集合。其最大可支付前缀正是实际总支出；空集合支出为 0。扣除它得到正确 Junior 预算，再应用同一结论，得到规则要求的初级集合。两组互斥，合并不会重复 ID，且涵盖全部录用者。

边界与常见错误

  • 预算恰好用尽：比较必须是 ≤，写成 < 会少录用。
  • 没有可录用 Senior：COALESCE 防止 NULL 余额导致 Junior 全部被过滤。
  • Senior / Junior 一组为空，甚至整表为空：自然返回另一组结果或空结果。
  • 不能先比较全部候选人薪资，也不能按 experience 字符串升序处理：Junior 的字母顺序靠前，却没有招聘优先权。
  • 不能返回两组人数；II 要求的是员工 ID。
  • 窗口必须按经验分区，Junior 的前缀不应包含 Senior 薪资。明确 ROWS 避免并列值时默认窗口框架带来的歧义；本题薪资唯一。
  • 使用整数存钱。Java / C++ 参考代码用 64 位金额；JavaScript 参考限定金额为安全整数。实际业务需按金额范围选择 DECIMAL 或其他精确类型。

复杂度

n 为候选人数。一般执行模型中窗口排序耗时 O(n log n)，后续聚合和筛选 O(n)；中间结果与排序空间按 O(n) 估计。实际 SQL 内存、物化及索引使用取决于执行计划。四语言参考同样为 O(n log n) 时间、O(n) 额外空间（含分组副本与输出）。

替代方案

过程式实现直接排序并维护余额，最贴近招聘规则，下面四语言均采用此法。旧数据库可通过相关子查询计算组内薪资不大于当前薪资的总和，但朴素执行可能达到 O(n²)；支持窗口函数时优先使用窗口 SUM。递归 CTE 也能逐行模拟，但这里没有必要。

面试追问

  • 薪资相同时如何选 ID？题目目前保证唯一；业务若放宽条件，需要定义确定性规则，如 salary、employee_id 双列排序。
  • 如果目标改成总人数最多呢？Senior 优先规则改变，不能直接复用当前分阶段策略；可考虑所有人按薪资排序。
  • 若可负薪资或分期费用？前缀单调性和逐人预算含义需重新定义，不能直接套用证明。
  • 若存在多个预算账户？需要按账户分别分区与扣减，同时确认 Senior 优先级是全局还是账户内。

代码

本题为数据库题，SQL 是主解。下面 Java、JavaScript、Python、C++ 提供完整的本地语义函数，均返回 ID 列表，不是官方可提交接口。Python 版本也不是 Pandas 答案。所有代码待补验证。

MySQL 8+ · 官方可提交语言

WITH running AS (
    SELECT employee_id, experience,
           SUM(salary) OVER (
               PARTITION BY experience ORDER BY salary
               ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
           ) AS cost
    FROM Candidates
), seniors AS (
    SELECT employee_id, cost
    FROM running
    WHERE experience = 'Senior' AND cost <= 70000
), budget AS (
    SELECT 70000 - COALESCE(MAX(cost), 0) AS remaining
    FROM seniors
)
SELECT employee_id FROM seniors
UNION ALL
SELECT r.employee_id
FROM running AS r CROSS JOIN budget AS b
WHERE r.experience = 'Junior' AND r.cost <= b.remaining;

Java · 本地语义参考

import java.util.*;

// 本地语义参考；不是本题的官方 Java 提交接口。
public class Solution {
    public static class Candidate {
        public final int employeeId;
        public final String experience;
        public final long salary;
        public Candidate(int id, String exp, long pay) {
            employeeId = id; experience = exp; salary = pay;
        }
    }
    public static List<Integer> numberOfJoiners(List<Candidate> candidates) {
        List<Integer> hired = new ArrayList<>();
        long remaining = 70000;
        for (String group : new String[]{"Senior", "Junior"}) {
            List<Candidate> rows = new ArrayList<>();
            for (Candidate c : candidates)
                if (group.equals(c.experience)) rows.add(c);
            rows.sort(Comparator.comparingLong(c -> c.salary));
            for (Candidate c : rows) {
                if (c.salary > remaining) break;
                remaining -= c.salary;
                hired.add(c.employeeId);
            }
        }
        return hired;
    }
}

JavaScript · 本地语义参考

// 本地语义参考；输入对象对应 Candidates 的一行。
function numberOfJoiners(candidates) {
  let remaining = 70000;
  const hired = [];
  for (const group of ['Senior', 'Junior']) {
    const rows = candidates.filter(c => c.experience === group)
      .sort((a, b) => a.salary - b.salary);
    for (const c of rows) {
      if (c.salary > remaining) break;
      remaining -= c.salary;
      hired.push(c.employee_id);
    }
  }
  return hired;
}

# 本地语义参考；输入为行字典列表，不是官方 Pandas 接口。
def number_of_joiners(candidates):
    remaining = 70000
    hired = []
    for group in ("Senior", "Junior"):
        rows = sorted(
            (c for c in candidates if c["experience"] == group),
            key=lambda c: c["salary"]
        )
        for c in rows:
            if c["salary"] > remaining:
                break
            remaining -= c["salary"]
            hired.append(c["employee_id"])
    return hired

C++ · 本地语义参考

#include <algorithm>
#include <string>
#include <vector>
using namespace std;

// 本地语义参考；不是本题的官方 C++ 提交接口。
struct Candidate {
    int employee_id;
    string experience;
    long long salary;
};
vector<int> numberOfJoiners(const vector<Candidate>& candidates) {
    long long remaining = 70000;
    vector<int> hired;
    for (const string& group : {string("Senior"), string("Junior")}) {
        vector<Candidate> rows;
        for (const auto& c : candidates)
            if (c.experience == group) rows.push_back(c);
        sort(rows.begin(), rows.end(), [](const Candidate& a, const Candidate& b) {
            return a.salary < b.salary;
        });
        for (const auto& c : rows) {
            if (c.salary > remaining) break;
            remaining -= c.salary;
            hired.push_back(c.employee_id);
        }
    }
    return hired;
}
