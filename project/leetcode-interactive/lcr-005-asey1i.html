最大单词长度乘积

用一个 26 位二进制掩码表示单词出现过哪些小写字母；两个掩码按位与为 0，就说明它们没有共同字母。

题意

给定字符串数组 words，找出两个不含共同字母的单词，返回它们长度的最大乘积；找不到则返回 0。

示例

words = ["abcw","baz","foo","bar","fxyz","abcdef"]

output = 16

约束

2 ≤ words.length ≤ 1000；每个单词仅含小写字母，长度不超过 1000。

交互实验室

输入逗号分隔的小写单词。每一步比较一对单词的位掩码，绿色代表可相乘的合法组合。

    核心洞察

    将字母 a 到 z 映射到二进制第 0 到 25 位。一个单词的掩码由所有字母的位或得到；若 maskA & maskB == 0，两词没有重合字符，可以更新长度乘积。

    完整过程

    1. 遍历每个单词，构建它的 26 位掩码。
    2. 枚举所有不同单词对。
    3. 按位与为 0 时，计算并更新长度乘积。

    边界与常见错误

    • 同一字母重复出现只需设置一次对应位。
    • 按位与不为 0 即有公共字母，不能纳入答案。
    • 没有合法单词对时，初始化答案 0 会自然返回正确结果。

    复杂度：构建掩码 O(总字符数)，两两比较 O(n²)，每次比较 O(1)；额外空间 O(n)。

    可提交代码

    Java

    class Solution { public int maxProduct(String[] words) { int n=words.length, ans=0; int[] masks=new int[n]; for(int i=0;i<n;i++) for(char c:words[i].toCharArray()) masks[i]|=1<<(c-'a'); for(int i=0;i<n;i++) for(int j=0;j<i;j++) if((masks[i]&masks[j])==0) ans=Math.max(ans,words[i].length()*words[j].length()); return ans; } }

    Python

    class Solution:
    def maxProduct(self, words: List[str]) -> int:
        masks = [sum(1 << (ord(c) - 97) for c in set(word)) for word in words]
        ans = 0
        for i in range(len(words)):
            for j in range(i):
                if masks[i] & masks[j] == 0: ans = max(ans, len(words[i]) * len(words[j]))
        return ans
