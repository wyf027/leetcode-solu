交替位二进制数

Binary Number with Alternating Bits

把一个正整数转换成二进制信号，判断每一对相邻位是否始终不同。先在实验台里观察信号，再决定是否展开完整题解。

难度：简单 标签：位运算 非会员题 函数：hasAlternatingBits(n)
Problem brief

题意与输入范围

给定一个正整数 n。如果它的二进制表示中任意两个相邻位都不同，也就是始终以 0、1 交替出现，则返回 true；否则返回 false。

约束
1 <= n <= 231 - 1
参数形式：n 为整数；返回值为布尔值。
示例 1
输入：n = 5
输出：true
解释：5 的二进制表示为 101。
示例 2
输入：n = 7
输出：false
解释：7 的二进制表示为 111。
示例 3
输入：n = 11
输出：false
解释：11 的二进制表示为 1011。

Complete solution

完整题解：逐位扫描

核心洞察

“交替”是一个局部条件：只要逐对检查相邻位即可。位运算能从最低位开始取出每一位，因此不必构造字符串；保存上一位，每次取当前最低位并比较，如果二者相同就立即返回 false。

完整过程

  1. 用 n & 1 取得最低位，记录为 previous。
  2. 将 n 右移一位，丢弃刚刚记录的位。
  3. 只要 n > 0，就取新的最低位 current。若 current == previous，相邻位重复，立即返回 false。
  4. 否则更新 previous，继续右移。循环结束说明所有相邻位都不同，返回 true。

正确性证明

循环不变量：每次循环开始时，previous 等于已经移除部分中最靠近尚未检查部分的那一位，并且所有已经比较过的相邻位都互不相同。

  • 初始化：首先记录原数最低位，还没有需要比较的位对，因此不变量成立。
  • 保持：循环取出的 current 与 previous 在原二进制表示中相邻。若二者相同，算法正确返回 false；若不同，更新上一位并右移后，已检查范围增加一对，不变量继续成立。
  • 终止：循环结束时所有二进制位都已处理。由不变量，所有相邻位均不同，因此返回 true 正确。

边界情况

  • n = 1 只有一位，没有冲突的相邻位，应返回 true。
  • 若最低两位已经相同，可以在第一次循环比较时提前结束。
  • 输入上界为 2³¹ - 1，使用 32 位整数位运算即可。

复杂度

  • 时间：O(log n)，每个二进制位最多访问一次。
  • 空间：O(1)，只使用常数个变量。

四种语言完整代码

Java位扫描
class Solution {
    public boolean hasAlternatingBits(int n) {
        int previous = n & 1;
        n >>= 1;

        while (n > 0) {
            int current = n & 1;
            if (current == previous) {
                return false;
            }
            previous = current;
            n >>= 1;
        }

        return true;
    }
}

替代方案

  • 字符串检查：先把 n 转成二进制字符串，再比较相邻字符。思路直观，时间仍为 O(log n)，但需要 O(log n) 额外空间。
  • 异或性质：令 x = n ^ (n >> 1)。若 n 的位交替，则 x 的有效位全为 1；可用 (x & (x + 1)) == 0 判断。它更短，但面试中需要清晰说明全 1 形态为何成立。

面试追问

  • 能否写出异或的一行解法，并证明它不会把非交替位误判为交替位？
  • 如果输入扩展为任意长度的二进制字符串，如何流式处理而不保存完整输入？
  • 如果要统计相邻位相同的位置数量，而不是只返回布尔值，怎样调整状态？

常见错误

  • 把“0 和 1 的数量接近”误当成交替；数量关系不能保证相邻位不同。
  • 右移后才保存上一位，导致第一对相邻位被跳过。
  • 循环条件写成 n > 1，可能漏掉最高位参与的最后一次比较。
  • 把只有一个二进制位的 n = 1 判为 false；题意下它没有违反条件的相邻位。
