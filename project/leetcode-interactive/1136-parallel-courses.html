Problem brief

题目描述

下面是基于官方题名、参数签名和示例的准确转述；不复刻付费题原文。

任务

共有 n 门课程，编号从 1 到 n。每个学期可以同时学习任意数量的课程，但只有当一门课的所有直接先修课都已经在更早的学期完成时，才能选择它。

二维数组 relations 中的每个二元组 [prevCourse, nextCourse] 表示：必须先完成 prevCourse，之后才能学习 nextCourse。

返回修完全部课程所需的最少学期数。如果依赖关系导致无法完成所有课程，返回 -1。

函数形式： minimumSemesters(n, relations) -> integer

约束

  • 1 <= n <= 5000
  • 1 <= relations.length <= 5000
  • 每个关系都含两个合法课程编号。
  • relations[i][0] != relations[i][1]
  • 同一条先修关系不会重复出现。

标签：Graph · Topological Sort · Directed Acyclic Graph

官方示例 1可完成
输入n = 3, relations = [[1,3],[2,3]]
输出2
说明第 1 学期可并行学习课程 1、2；第 2 学期学习课程 3。
官方示例 2存在环
输入n = 3, relations = [[1,2],[2,3],[3,1]]
输出-1
说明三门课互相形成循环依赖，任何一门都无法先开始。

Solution

按学期分层的拓扑排序

把课程看成节点、先修关系看成有向边。每轮同时处理当前所有没有未完成先修课的课程。

核心洞察

1

入度代表门槛

课程的入度就是尚未完成的直接先修课数量；入度为 0 才能在当前学期学习。

2

一层就是一学期

同一轮开始时已经入度为 0 的课程彼此可以并行，整批处理后学期数加一。

3

计数识别环

若队列耗尽时处理课程数少于 n，剩余节点必在环上或被环阻塞，答案是 -1。

完整过程

  1. 为每门课程建立后继列表，并统计每个节点的入度。
  2. 把所有入度为 0 的课程加入队列，作为第一学期可选课程。
  3. 每轮先固定队列长度，只处理这一批课程；这样后续刚被解锁的课程会留到下一学期。
  4. 每处理一门课程，就遍历其后继并将对应入度减 1；新入度为 0 的课程入队。
  5. 记录已处理课程数。全部处理完返回轮数，否则返回 -1。
关键细节： 每学期必须先保存当前队列长度。若直接处理到队列为空，会把多个依赖层错误地合并进同一学期。

正确性证明

引理 1：每轮队列中的课程都能在该学期合法学习。

进入队列时该课程入度为 0，说明它的每一门直接先修课都已在之前轮次被处理。因此在当前学期学习它满足全部先修条件。

引理 2：任意合法安排都不能比算法更早学习某一层课程。

第一层课程无需先修。对后续层归纳：某课程只有在所有先修课所属层结束后才能学习；算法恰好在这些条件首次全部满足后的下一轮处理它，所以不存在更早的合法学期。

定理：若可修完全部课程，算法返回最少学期数；否则返回 -1。

由引理 1，算法产生的安排合法；由引理 2，每层出现时间都是可达到的最早时间，因此总层数最小。若处理数小于 n，剩余有向子图不存在入度为 0 的节点，必含环，无法开始其中所有课程，返回 -1 正确。

复杂度

时间 O(n + m) 空间 O(n + m)

其中 m = relations.length。每个节点至多进出队列一次，每条边只遍历一次。

边界情况

  • 依赖链：每学期只能学一门，答案等于链长。
  • 多条分支汇入同一课程：必须等最后一条分支完成，后继才会入队。
  • 多个互不相连的子图：各子图可并行推进，总答案由最长依赖层数决定。
  • 存在环：即便图中其他课程可以完成，只要处理数不足 n，仍返回 -1。
  • 只有一门课程且没有先修关系时，语义上的答案为 1。

完整代码

JAVA
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;

class Solution {
    public int minimumSemesters(int n, int[][] relations) {
        List<List<Integer>> graph = new ArrayList<>(n + 1);
        for (int i = 0; i <= n; i++) {
            graph.add(new ArrayList<>());
        }

        int[] indegree = new int[n + 1];
        for (int[] relation : relations) {
            int previous = relation[0];
            int next = relation[1];
            graph.get(previous).add(next);
            indegree[next]++;
        }

        Deque<Integer> queue = new ArrayDeque<>();
        for (int course = 1; course <= n; course++) {
            if (indegree[course] == 0) {
                queue.offer(course);
            }
        }

        int semesters = 0;
        int completed = 0;

        while (!queue.isEmpty()) {
            int semesterSize = queue.size();
            semesters++;

            for (int i = 0; i < semesterSize; i++) {
                int course = queue.poll();
                completed++;

                for (int next : graph.get(course)) {
                    indegree[next]--;
                    if (indegree[next] == 0) {
                        queue.offer(next);
                    }
                }
            }
        }

        return completed == n ? semesters : -1;
    }
}

/**
 * @param {number} n
 * @param {number[][]} relations
 * @return {number}
 */
var minimumSemesters = function (n, relations) {
    const graph = Array.from({ length: n + 1 }, () => []);
    const indegree = new Array(n + 1).fill(0);

    for (const [previous, next] of relations) {
        graph[previous].push(next);
        indegree[next]++;
    }

    const queue = [];
    for (let course = 1; course <= n; course++) {
        if (indegree[course] === 0) {
            queue.push(course);
        }
    }

    let head = 0;
    let semesters = 0;
    let completed = 0;

    while (head < queue.length) {
        const semesterEnd = queue.length;
        semesters++;

        while (head < semesterEnd) {
            const course = queue[head++];
            completed++;

            for (const next of graph[course]) {
                indegree[next]--;
                if (indegree[next] === 0) {
                    queue.push(next);
                }
            }
        }
    }

    return completed === n ? semesters : -1;
};
PYTHON
from collections import deque
from typing import List


class Solution:
    def minimumSemesters(
        self, n: int, relations: List[List[int]]
    ) -> int:
        graph = [[] for _ in range(n + 1)]
        indegree = [0] * (n + 1)

        for previous, nxt in relations:
            graph[previous].append(nxt)
            indegree[nxt] += 1

        queue = deque(
            course
            for course in range(1, n + 1)
            if indegree[course] == 0
        )

        semesters = 0
        completed = 0

        while queue:
            semesters += 1

            for _ in range(len(queue)):
                course = queue.popleft()
                completed += 1

                for nxt in graph[course]:
                    indegree[nxt] -= 1
                    if indegree[nxt] == 0:
                        queue.append(nxt)

        return semesters if completed == n else -1
C++
#include <queue>
#include <vector>

using namespace std;

class Solution {
public:
    int minimumSemesters(
        int n,
        vector<vector<int>>& relations
    ) {
        vector<vector<int>> graph(n + 1);
        vector<int> indegree(n + 1, 0);

        for (const auto& relation : relations) {
            int previous = relation[0];
            int next = relation[1];
            graph[previous].push_back(next);
            indegree[next]++;
        }

        queue<int> courses;
        for (int course = 1; course <= n; course++) {
            if (indegree[course] == 0) {
                courses.push(course);
            }
        }

        int semesters = 0;
        int completed = 0;

        while (!courses.empty()) {
            int semesterSize = courses.size();
            semesters++;

            while (semesterSize-- > 0) {
                int course = courses.front();
                courses.pop();
                completed++;

                for (int next : graph[course]) {
                    indegree[next]--;
                    if (indegree[next] == 0) {
                        courses.push(next);
                    }
                }
            }
        }

        return completed == n ? semesters : -1;
    }
};

替代方案

DFS + 记忆化最长路径

用三色标记检测环，并令每个节点的最早完成学期等于其所有后继路径的最大深度。时间、空间同为 O(n + m)，但递归深度在不同语言中需要额外留意。

拓扑序 + 动态规划

先得到拓扑序，再做 semester[next] = max(semester[next], semester[cur] + 1)。它方便扩展为输出每门课的最早学期，但当前题用分层 BFS 更直接。

面试追问

  • 如果每学期最多只能选 k 门课？ “所有可学课程全选”不再总是最优；n 较小时可考虑状态压缩与子集枚举。
  • 如果每门课耗时不同？ 在 DAG 上计算带权最长路径；每个节点记录最早开始或完成时间。
  • 如何返回具体排课表？ 在每一轮保存固定队列中的课程列表即可。
  • 如何给出环的证据？ 可追加 DFS 颜色标记与父指针，恢复一条具体循环路径。
  • 依赖动态加入怎么办？ 小规模可重算；高频更新则需要动态拓扑序或专门的增量图算法。

常见错误

  • 把关系方向建反：应当从先修课指向后续课程，并增加后续课程的入度。
  • 没有固定每轮的队列长度，导致刚解锁的课程在同一学期立即被处理。
  • 只看队列是否曾为空，没有比较最终处理数与 n，因而漏判局部环。
  • 使用 JavaScript 的 shift() 反复删除数组头，可能退化；用头指针即可保持线性复杂度。
  • 把最长“边数”直接当成学期数；本题按课程节点层数计数。
