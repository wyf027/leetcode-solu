01 / READ

题意与输入契约

输入为 Orders 表。对每个客户，仅考察其首次下单年到最后下单年的闭区间。某年的购买量是这一年所有订单的 price 总和；没有订单的年份计作 0。找出在此区间内，年度购买总额逐年严格变大的客户，输出单列 customer_id，行顺序不限。

字段类型含义
order_idint订单唯一标识（主键）
customer_idint客户标识
order_datedate下单日期
priceint订单价格

约束与语义

  • 一个客户可有多张订单，同一年可出现多行；不能把订单条数当作购买量。
  • “严格”排除相等；首次年份之前和最后年份之后无需考虑。
  • 只覆盖一个年份的客户没有相邻年比较，因此满足条件。
  • 已取得资料未列出行数、年份跨度或价格大小的数值上界，也未明确价格正负范围；此处不编造约束。

05 / SOLUTION

准备好拆解了吗？

先明确“每一年”的范围，再展开完整推导与代码。

题解 · 补全年度，再比较相邻项

核心洞察

输入按订单存储，要求按自然年比较。先把订单压缩成“客户 × 年份”的总额，再补齐缺失年份，才能得到题目真正要求检查的序列。用 LAG(total) 取前一年的值，将“全部严格增长”改写成“不存在 total ≤ prev 的反例”。

完整过程

  1. annual：按客户和年份分组，求 SUM(price)。
  2. bounds：求每个客户的起止年份。
  3. calendar：使用 PostgreSQL 的 generate_series 生成闭区间内所有整数年份。
  4. filled：左连接年度总额，缺失项用 0 填充。
  5. compared：窗口按客户分区、按年份排序，取上一年的金额。
  6. 每位客户统计不满足严格增长的相邻年；反例数为 0 才返回该客户。

正确性

年度值完整：分组求和恰好覆盖某客户某年的所有订单。日历序列恰好覆盖首尾年份之间的每一年，左连接补 0 后与定义一致。

比较完整：窗口排序确保每个非首年都与紧邻的上一自然年比较，既不会跨过空年，也不会混入其他客户。首年没有前驱，prev 为 NULL，不被反例过滤条件计数。

充要性：返回的客户没有任何相邻年满足当前总额小于等于前值，所以每一步都严格增长；满足严格增长的客户不会产生反例，必然被返回。

边界处理

  • 单年客户保留；空表无输出；一年多单必须先求和。
  • 同额或下降都淘汰；缺年必须体现为 0。
  • 本解不依赖价格为正的隐含假设，即使扩展到负数，也按补零后的实际序列判断。
  • 假定输入遵循有效日期和整数价格语义；题面未定义 NULL 价格的业务含义。四语言参考用四位年份日期字符串；Java/C++ 总额使用 64 位整数并在溢出时抛错，Python/JavaScript 使用任意精度整数。

复杂度与适用范围

设 N 为订单数，A 为实际客户年分组数，K 为补齐后所有客户的年份总数。哈希聚合模型下，SQL 约为 O(N + K log K) 时间、O(A + K) 中间存储；排序聚合、执行计划和索引会影响实际开销。K 可能远大于 A。

参考代码直接按年份读取缺省值，不存整张日历：Java/C++ 使用有序映射，时间上界 O((N + K) log(N + 1))；JavaScript/Python 按哈希映射模型为 O(N + A log(A + 1) + K + C log(C + 1)) 的宽松上界，C 是客户数。四者额外空间 O(A + C)。所有复杂度忽略大整数位数成本。

替代方案

若业务明确保证年度金额非负，可用 LAG(yr) 和 LAG(total) 同时检查年份差为 1、金额增大，避免展开日历：遇到断年时前一个实际年份到 0 不可能严格增长。未确认非负前，不宜使用这一简化。另一直接写法是补齐年份后自连接前一年，并用 NOT EXISTS 排除反例。

常见错误

  • 只比较有订单的年份，会把 700 → 缺年 → 1000 错当成增长。
  • 按金额排序再比较，丢失时间顺序。
  • 用订单数量或单笔最大金额，替代年度总价。
  • 使用 < 排除下降却忘记排除相等，或者把第一年的前驱强设为 0。
  • 用全表统一的起止年份，会添加客户范围以外的无关年份。

面试追问

跨度很大怎么办？确认非负条件后用年份连续性检查；或复用日历维度，并评估生成行数。为什么相邻比较就够？严格小于具有传递性。月份版本如何改？使用连续月份序号或按月生成日期，不能直接给 YYYYMM 加 1。新增订单如何维护？先更新客户年度聚合，再检查受影响年份的前后关系及首尾范围变化。

完整代码

主解使用官方元数据列出的 PostgreSQL 方言，可作为数据库提交代码。下方 Java、JavaScript、Python、C++ 是完整的本地函数 / 类型定义，不是本题官方提交语言或评测签名；输入行顺序与 Orders 一致，返回客户 ID 列表。所有代码待补验证。

PostgreSQL · 官方数据库方言主解

WITH annual AS (
    SELECT customer_id, EXTRACT(YEAR FROM order_date)::int AS yr,
           SUM(price) AS total
    FROM Orders
    GROUP BY customer_id, EXTRACT(YEAR FROM order_date)::int
), bounds AS (
    SELECT customer_id, MIN(yr) AS first_year, MAX(yr) AS last_year
    FROM annual
    GROUP BY customer_id
), calendar AS (
    SELECT b.customer_id, s.yr
    FROM bounds b
    CROSS JOIN LATERAL
         generate_series(b.first_year, b.last_year) AS s(yr)
), filled AS (
    SELECT c.customer_id, c.yr, COALESCE(a.total, 0) AS total
    FROM calendar c
    LEFT JOIN annual a
      ON a.customer_id = c.customer_id AND a.yr = c.yr
), compared AS (
    SELECT customer_id, yr, total,
           LAG(total) OVER (PARTITION BY customer_id ORDER BY yr) AS prev
    FROM filled
)
SELECT customer_id
FROM compared
GROUP BY customer_id
HAVING COUNT(*) FILTER (WHERE total <= prev) = 0;

Java · 本地语义参考

import java.util.*;

public class Solution {
    // 每行：order_id, customer_id, "YYYY-MM-DD", price
    public static List<Integer> findSpecificCustomers(Object[][] orders) {
        Map<Integer, TreeMap<Integer, Long>> totals = new TreeMap<>();
        for (Object[] row : orders) {
            int id = ((Number) row[1]).intValue();
            int year = Integer.parseInt(((String) row[2]).substring(0, 4));
            long price = ((Number) row[3]).longValue();
            totals.computeIfAbsent(id, k -> new TreeMap<>())
                  .merge(year, price, Math::addExact);
        }
        List<Integer> answer = new ArrayList<>();
        for (var entry : totals.entrySet()) {
            TreeMap<Integer, Long> years = entry.getValue();
            Long previous = null;
            boolean ok = true;
            for (int y = years.firstKey(); y <= years.lastKey(); y++) {
                long total = years.getOrDefault(y, 0L);
                if (previous != null && total <= previous) {
                    ok = false;
                    break;
                }
                previous = total;
            }
            if (ok) answer.add(entry.getKey());
        }
        return answer;
    }
}

JavaScript · 本地语义参考

// 每行：[order_id, customer_id, "YYYY-MM-DD", price]
// price 接受安全整数或整数字符串；总额使用 BigInt。
function findSpecificCustomers(orders) {
  const customers = new Map();
  for (const [, id, date, price] of orders) {
    if (typeof price === "number" && !Number.isSafeInteger(price))
      throw new RangeError("price 必须为安全整数或整数字符串");
    const year = Number(date.slice(0, 4));
    if (!customers.has(id)) customers.set(id, new Map());
    const years = customers.get(id);
    years.set(year, (years.get(year) ?? 0n) + BigInt(price));
  }
  const answer = [];
  for (const [id, years] of customers) {
    const keys = [...years.keys()].sort((a, b) => a - b);
    let previous = null, ok = true;
    for (let y = keys[0]; y <= keys[keys.length - 1]; y++) {
      const total = years.get(y) ?? 0n;
      if (previous !== null && total <= previous) {
        ok = false;
        break;
      }
      previous = total;
    }
    if (ok) answer.push(id);
  }
  return answer.sort((a, b) => a - b);
}

Python · 本地语义参考（非 pandas 提交接口）

from collections import defaultdict

def find_specific_customers(orders):
    """每行：(order_id, customer_id, 'YYYY-MM-DD', price)。"""
    customers = defaultdict(lambda: defaultdict(int))
    for _, customer_id, order_date, price in orders:
        customers[customer_id][int(order_date[:4])] += price
    answer = []
    for customer_id, years in customers.items():
        previous = None
        ok = True
        for year in range(min(years), max(years) + 1):
            total = years.get(year, 0)
            if previous is not None and total <= previous:
                ok = False
                break
            previous = total
        if ok:
            answer.append(customer_id)
    return sorted(answer)

C++ · 本地语义参考

#include <map>
#include <string>
#include <vector>
#include <limits>
#include <stdexcept>
using namespace std;

struct Order {
    int order_id, customer_id;
    string order_date;
    long long price;
};

vector<int> findSpecificCustomers(const vector<Order>& orders) {
    map<int, map<int, long long>> customers;
    for (const auto& row : orders) {
        int year = stoi(row.order_date.substr(0, 4));
        auto& sum = customers[row.customer_id][year];
        if ((row.price > 0 && sum > numeric_limits<long long>::max() - row.price) ||
            (row.price < 0 && sum < numeric_limits<long long>::min() - row.price))
            throw overflow_error("annual total overflow");
        sum += row.price;
    }
    vector<int> answer;
    for (const auto& [id, years] : customers) {
        bool first = true, ok = true;
        long long previous = 0;
        for (int y = years.begin()->first; y <= years.rbegin()->first; ++y) {
            auto it = years.find(y);
            long long total = it == years.end() ? 0 : it->second;
            if (!first && total <= previous) { ok = false; break; }
            first = false;
            previous = total;
        }
        if (ok) answer.push_back(id);
    }
    return answer;
}
