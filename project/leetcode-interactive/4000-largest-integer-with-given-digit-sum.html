给定数位和的最大整数

用至多 n 位数字凑出数位和 s。想让整数最大，最值应尽可能靠左：每一位优先放 9，再把剩余和交给后面的位置。

题意

给定非负整数 n 与 s，返回数位和恰好为 s、且至多有 n 位的最大整数；若不存在则返回 -1。

示例 1
n = 2, s = 9 → 90。把 9 放在十位比放在个位更大。
示例 2
n = 2, s = 19 → -1，两位最多贡献 9 + 9 = 18。
示例 3
n = 5, s = 0 → 0，唯一可行的非负整数是 0。

约束

1 ≤ n ≤ 5可用位数
0 ≤ s ≤ 100目标和
9n可行上界

输入中的空格在页面内会保留为 ␠；本题参数均为整数。

从最高位往最低位走。每次拿走 min(9, remaining)，剩余数位和只会变小。

核心洞察

同样长度的数字，最高位更大就一定更大。因此没有必要回溯：每一位都取不超过剩余和的最大值 9。先判断 s > 9 × n；若成立无解。若 s = 0，直接返回 0，避免构造出一串前导零。

完整过程

  1. 若 s > 9n 返回 -1。
  2. 若 s = 0 返回 0。
  3. 重复至多 n 次：附加 min(9, s)，并从 s 中减掉该数。
  4. 剩余为 0 时停止；拼接结果就是最大值。

边界、复杂度与替代方案

当 s 恰为 9n 时得到 n 个 9；当 s 很小则会以一位数结束。时间 O(n)，额外空间 O(n)（输出）。枚举所有数字或动态规划都能做，但会忽略本题的最高位贪心结构。

面试追问与常见错误

追问：若要求最小 n 位正整数，第一位需预留 1 给后续，策略会变化。常见错误：把 9 全放到低位、忘记先判 s > 9n、或把 s=0 返回空字符串。
