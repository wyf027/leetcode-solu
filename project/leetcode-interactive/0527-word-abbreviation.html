单词缩写

Word Abbreviation · 用最短且唯一的前缀，消解彼此冲突的缩写。

贪心字典树字符串排序
函数签名
wordsAbbreviation(words: List<String>) → List<String>

输出顺序与输入一致；每个结果要尽可能短，并在结果集合中唯一。

题意

给定一组互不相同的小写英文单词，为每个单词生成缩写。缩写保留某个非空前缀和最后一个字符，并把中间省略的字符数写成十进制数字，例如 internal → i6l。

所有生成结果必须彼此唯一。若同一缩写对应多个单词，就逐步增加这些单词保留的前缀长度，直到冲突消失。若缩写并不比原词短，则直接返回原词。

规则公式：长度为 n、前缀长度为 p 时，候选为 word[0:p] + (n-p-1) + word[n-1]；只有候选长度严格小于原词时才采用。

示例 1

输入：words = ["like","god","internal","me","internet","interval","intension","face","intrusion"] 输出：["l2e","god","internal","me","i6t","interval","inte4n","f2e","intr4n"]

示例 2

输入：words = ["aa","aaa"] 输出：["aa","aaa"]

约束

  • 1 ≤ words.length ≤ 400
  • 2 ≤ words[i].length ≤ 400
  • 每个单词只包含小写英文字母，且所有单词互不相同。

题解

核心洞察

每个单词从前缀长度 1 开始尝试。某轮只需处理仍然得到相同缩写的单词：把它们的前缀长度各增加 1，再重新计算。已经唯一的缩写无需改变。这是一个单调过程——前缀只会变长，最多增长到原词长度附近。

完整过程

  1. 为所有单词设置前缀长度 prefix[i] = 1。
  2. 按当前前缀长度计算每个候选缩写；不更短时保留原词。
  3. 用映射把相同候选的下标收集到一起。
  4. 对大小大于 1 的冲突组，将组内所有 prefix 加 1。
  5. 重复，直到没有冲突，按原下标返回结果。

正确性

终止性：每次存在冲突时，相关单词的前缀长度严格增加；前缀达到使缩写不再更短的位置后会返回互不相同的原词，因此循环必然结束。

唯一性：算法只在所有候选缩写分组大小均为 1 时结束，所以最终结果两两不同。

最短性：每个单词从最短允许前缀开始，且只有其当前候选发生冲突时才增加前缀；冲突消失后的首次候选就是该同步消解规则下能取得的最短唯一结果。若缩写不更短，题意要求返回原词。

边界与复杂度

  • 长度很短、数字位数变多导致不省字符、或前缀过长时，返回原词。
  • 不同长度或首尾字母不同的单词通常在很早阶段就分离。
  • 设单词数为 N、最大长度为 L。朴素轮次实现最多进行 O(L) 轮，每轮构造与分组总计 O(NL)，上界 O(NL²)；空间 O(NL)（含结果字符串）。

替代方案

可先按“首字符、尾字符、长度”分组，再为每组建立 Trie，利用节点计数直接找到每个词的最短唯一前缀，时间可收敛到所有字符总量级。排序相邻词并计算最长公共前缀也能完成，但实现时要同时比较前驱与后继。

面试追问

  • 如何用 Trie 将复杂度优化到 O(Σ|word|)？
  • 为什么只需在相同长度、相同首尾字符的单词间寻找冲突？
  • 如果允许重复输入，唯一性与输出规则应如何重新定义？

常见错误

  • 无论缩写是否更短都强制使用数字形式。
  • 只增加冲突组中的一个单词，导致选择依赖遍历顺序。
  • 用缩写字符串覆盖原下标，破坏输出顺序。
  • 判断冲突后没有重新构造同组所有候选。

class Solution {
    public List<String> wordsAbbreviation(List<String> words) {
        int n = words.size();
        int[] prefix = new int[n];
        Arrays.fill(prefix, 1);
        List<String> answer = new ArrayList<>(Collections.nCopies(n, ""));
        while (true) {
            Map<String, List<Integer>> groups = new HashMap<>();
            for (int i = 0; i < n; i++) {
                String a = abbreviate(words.get(i), prefix[i]);
                answer.set(i, a);
                groups.computeIfAbsent(a, k -> new ArrayList<>()).add(i);
            }
            boolean conflict = false;
            for (List<Integer> group : groups.values()) {
                if (group.size() > 1) {
                    conflict = true;
                    for (int i : group) prefix[i]++;
                }
            }
            if (!conflict) return answer;
        }
    }

    private String abbreviate(String word, int p) {
        int omitted = word.length() - p - 1;
        if (omitted <= 1) return word;
        return word.substring(0, p) + omitted + word.charAt(word.length() - 1);
    }
}

var wordsAbbreviation = function(words) {
  const n = words.length;
  const prefix = Array(n).fill(1);
  const answer = Array(n);
  const abbreviate = (word, p) => {
    const omitted = word.length - p - 1;
    return omitted <= 1 ? word : word.slice(0, p) + omitted + word.at(-1);
  };
  while (true) {
    const groups = new Map();
    for (let i = 0; i < n; i++) {
      answer[i] = abbreviate(words[i], prefix[i]);
      if (!groups.has(answer[i])) groups.set(answer[i], []);
      groups.get(answer[i]).push(i);
    }
    let conflict = false;
    for (const group of groups.values()) {
      if (group.length > 1) {
        conflict = true;
        for (const i of group) prefix[i]++;
      }
    }
    if (!conflict) return answer;
  }
};
from typing import List

class Solution:
    def wordsAbbreviation(self, words: List[str]) -> List[str]:
        n = len(words)
        prefix = [1] * n
        answer = [""] * n

        def abbreviate(word: str, p: int) -> str:
            omitted = len(word) - p - 1
            return word if omitted <= 1 else word[:p] + str(omitted) + word[-1]

        while True:
            groups = {}
            for i, word in enumerate(words):
                answer[i] = abbreviate(word, prefix[i])
                groups.setdefault(answer[i], []).append(i)
            conflict = False
            for group in groups.values():
                if len(group) > 1:
                    conflict = True
                    for i in group:
                        prefix[i] += 1
            if not conflict:
                return answer
class Solution {
public:
    vector<string> wordsAbbreviation(vector<string>& words) {
        int n = words.size();
        vector<int> prefix(n, 1);
        vector<string> answer(n);
        while (true) {
            unordered_map<string, vector<int>> groups;
            for (int i = 0; i < n; ++i) {
                answer[i] = abbreviate(words[i], prefix[i]);
                groups[answer[i]].push_back(i);
            }
            bool conflict = false;
            for (auto& [key, group] : groups) {
                if (group.size() > 1) {
                    conflict = true;
                    for (int i : group) ++prefix[i];
                }
            }
            if (!conflict) return answer;
        }
    }
private:
    string abbreviate(const string& word, int p) {
        int omitted = static_cast<int>(word.size()) - p - 1;
        if (omitted <= 1) return word;
        return word.substr(0, p) + to_string(omitted) + word.back();
    }
};
