01 / 题意与约束

找共享节点，不是相同数值

给定两个无环单链表的头节点 headA 与 headB，返回两条链表开始相交的节点；若从未共享同一节点引用，返回 null。函数返回后不得改变原链表结构。

  • • 相交指向同一内存节点，节点值相同并不足够。
  • • 共享一个节点后，后续整段尾链也必然共享。
  • • 链式结构中没有环。
1 ≤ m, n ≤ 3 × 10⁴
1 ≤ Node.val ≤ 10⁵

A 中的 1 ≠ B 中的 1；共享从 8 开始

04 / INTERVIEW SOLUTION

题解

洞察、过程、边界、复杂度、替代方案与四语言代码默认隐藏。

CORE INSIGHT

换头让两人走过相同总路程

A 的独占前缀长 a，B 的独占前缀长 b，共享尾部长 c。指针 A 走 a + c + b，指针 B 走 b + c + a；若存在交点，它们会在共享尾部入口同时到达。若不存在，最终同时到达 null。

COMPLETE PROCESS

  1. 1. pA、pB 分别从 headA、headB 出发。
  2. 2. 未相遇时各前进一步；到 null 就切换到另一条链表头。
  3. 3. pA === pB 时结束；返回该引用，可能是交点，也可能是 null。

BOUNDARIES

  • • 头节点相同：循环不执行，直接返回头节点。
  • • 只有尾节点共享：换头后仍会在尾节点相遇。
  • • 不相交：两指针最终同时为 null。
  • • 值重复：必须比较节点引用，不能比较 val。

COMPLEXITY

时间

O(m+n)

额外空间

O(1)

替代方案取舍

哈希集合可先记录 A 的所有节点，再扫描 B，直观但需要 O(m) 空间。先计算两链长度、让长链先走长度差也能做到 O(1) 空间，但代码更长。面试首选换头双指针：短、对称、证明清晰。

面试追问与常见错误

  • • 为什么不会无限循环？每个指针最多走完 A 与 B 各一次。
  • • 有环怎么办？本题保证无环；有环需先做环检测并分类讨论。
  • • 错误：比较 pA.val === pB.val，会把同值不同节点误判为相交。
  • • 错误：换头写成 pA = headA，导致指针只在原链循环。
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode pointerA = headA;
        ListNode pointerB = headB;

        while (pointerA != pointerB) {
            pointerA = pointerA == null ? headB : pointerA.next;
            pointerB = pointerB == null ? headA : pointerB.next;
        }

        return pointerA;
    }
}
