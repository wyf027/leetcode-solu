分割数组使乘积互质

Split the Array to Make Coprime Products

先理解“有效分割”的含义，再通过交互图观察质因数如何跨越分割线。完整题解默认收起。

题目描述

给定一个长度为 n、下标从 0 开始的整数数组 nums。在下标 i（0 ≤ i ≤ n - 2）之后分割数组：左侧包含前 i + 1 个元素，右侧包含其余元素。

若左右两部分元素乘积的最大公约数为 1，该分割有效。请返回最小的有效分割下标；不存在时返回 -1。

函数形式：findValidSplit(nums) → integer

官方示例

示例 1
输入：nums = [4,7,8,15,3,5]
输出：2
解释：仅在下标 2 之后分割有效。
示例 2
输入：nums = [4,7,15,8,3,5]
输出：-1
解释：不存在有效分割。

约束

  • n == nums.length
  • 1 ≤ n ≤ 10⁴
  • 1 ≤ nums[i] ≤ 10⁶

题解

Solution

质因数的最后出现位置

核心洞察

不需要计算巨大乘积。左右乘积不互质，当且仅当某个质因数同时出现在左右两侧。因此，可把每个质因数看成覆盖“首次出现位置到最后出现位置”的区间；有效分割线不能切穿任何这样的区间。

完整过程

对每个数做质因数分解，并记录每个质因数最后一次出现的下标 last[p]。同一个数内的重复质因数只处理一次。
从左到右扫描到 n - 2。遇到当前位置的每个质因数 p，令 right = max(right, last[p])。
若扫描到 i == right，说明左侧出现过的所有质因数都不会在右侧再次出现，立即返回 i。扫描结束仍未找到则返回 -1。

正确性证明

必要性

若 i < right，则已有某个左侧质因数的最后位置在 i 右边。该质因数同时整除左右乘积，所以二者不互质，分割无效。

充分性

若 i == right，左侧出现过的每个质因数最后位置都不超过 i，右侧不含这些质因数。左右乘积没有公共质因数，最大公约数为 1，分割有效。

算法按下标递增，并在首个满足条件的位置返回，因此答案也是最小有效下标。

边界情况

  • nums[i] = 1 没有质因数，不会扩展右边界。
  • 只能在 0...n-2 分割，不能把右侧留空。
  • 同一元素含 p²、p³ 时，只需记录一次质因数 p。
  • 若某个质因数从数组开头一直延伸到末尾，则任何分割都无效。

复杂度

设数组最大值为 M。试除分解的最坏时间复杂度为 O(n√M)，两次扫描额外为所有不同质因数出现次数之和；空间复杂度为 O(n + P)，其中 P 为不同质因数数量。这里 M ≤ 10⁶，试除足够。

替代方案

可先筛出不超过 √M 的质数，再仅用质数试除，常数更小；也可用最小质因数筛做到更快分解。但当前约束下会增加实现量，面试中先给出试除版本更稳妥。直接计算前后缀乘积会溢出；即使使用大整数，数值也会急剧膨胀。

面试追问

  • 为什么只记录最后位置，不必显式记录首次位置？——扫描首次遇到该因子时才会把它纳入当前边界。
  • 如何优化大量重复值？——缓存“数值 → 不同质因数列表”。
  • 若要求返回所有有效分割点？——不要首个返回，扫描时收集每个 i == right 的位置。

常见错误

  • 计算真实乘积或前缀乘积，造成溢出或不必要的大整数开销。
  • 只比较相邻元素的质因数，遗漏跨越多个位置的公共因子。
  • 扫描到 n - 1 并把末尾当作合法分割点。
  • 质因数分解后忘记处理最后一个大于 1 的剩余质因数。

Java

class Solution {
    public int findValidSplit(int[] nums) {
        Map<Integer, Integer> last = new HashMap<>();
        List<int[]> factors = new ArrayList<>();

        for (int i = 0; i < nums.length; i++) {
            int[] fs = factorize(nums[i]);
            factors.add(fs);
            for (int p : fs) last.put(p, i);
        }

        int right = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            for (int p : factors.get(i)) {
                right = Math.max(right, last.get(p));
            }
            if (i == right) return i;
        }
        return -1;
    }

    private int[] factorize(int value) {
        List<Integer> result = new ArrayList<>();
        for (int p = 2; p * p <= value; p++) {
            if (value % p != 0) continue;
            result.add(p);
            while (value % p == 0) value /= p;
        }
        if (value > 1) result.add(value);
        return result.stream().mapToInt(Integer::intValue).toArray();
    }
}

/**
 * @param {number[]} nums
 * @return {number}

var findValidSplit = function(nums) {
    const factorize = value => {
        const factors = [];
        for (let p = 2; p * p <= value; p++) {
            if (value % p !== 0) continue;
            factors.push(p);
            while (value % p === 0) value /= p;
        }
        if (value > 1) factors.push(value);
        return factors;
    };

    const allFactors = nums.map(factorize);
    const last = new Map();
    allFactors.forEach((factors, i) => {
        factors.forEach(p => last.set(p, i));
    });

    let right = 0;
    for (let i = 0; i < nums.length - 1; i++) {
        for (const p of allFactors[i]) {
            right = Math.max(right, last.get(p));
        }
        if (i === right) return i;
    }
    return -1;
};

Python

from typing import List


class Solution:
    def findValidSplit(self, nums: List[int]) -> int:
        def factorize(value: int) -> List[int]:
            factors = []
            p = 2
            while p * p <= value:
                if value % p:
                    p += 1
                    continue
                factors.append(p)
                while value % p == 0:
                    value //= p
                p += 1
            if value > 1:
                factors.append(value)
            return factors

        all_factors = [factorize(value) for value in nums]
        last = {}
        for i, factors in enumerate(all_factors):
            for p in factors:
                last[p] = i

        right = 0
        for i in range(len(nums) - 1):
            for p in all_factors[i]:
                right = max(right, last[p])
            if i == right:
                return i
        return -1

C++

class Solution {
public:
    int findValidSplit(vector<int>& nums) {
        vector<vector<int>> factors;
        unordered_map<int, int> last;

        for (int i = 0; i < nums.size(); ++i) {
            factors.push_back(factorize(nums[i]));
            for (int p : factors.back()) last[p] = i;
        }

        int right = 0;
        for (int i = 0; i + 1 < nums.size(); ++i) {
            for (int p : factors[i]) right = max(right, last[p]);
            if (i == right) return i;
        }
        return -1;
    }

private:
    vector<int> factorize(int value) {
        vector<int> result;
        for (int p = 2; p * p <= value; ++p) {
            if (value % p != 0) continue;
            result.push_back(p);
            while (value % p == 0) value /= p;
        }
        if (value > 1) result.push_back(value);
        return result;
    }
};
