二叉树的最大深度 Maximum Depth of Binary Tree

给定一棵二叉树，测量从根节点到最远叶子节点的最长路径包含多少个节点。先读题、亲手推进探测，再决定是否展开题解。

阅读题意 进入深度声呐
? maximum depth

Mission brief

题意

二叉树的最大深度，是从根节点向下到最远叶子节点的最长路径中，节点的数量。空树深度为 0；题目要求返回这个整数。

官方样例

输入 root = [3, 9, 20, null, null, 15, 7] 输出 3
输入 root = [1, null, 2] 输出 2

约束与记号

  • 树中节点数量在 [0, 10⁴] 范围内。
  • 每个节点满足 -100 ≤ Node.val ≤ 100。
  • null 表示该位置没有节点；本题输入不含字符串，因此没有空格可视化歧义。

    Solution

    题解

    面试主线选择显式栈 DFS：状态只有“节点 + 深度”，逻辑清楚，并且能够覆盖 10⁴ 个节点的极端单支树而不依赖语言调用栈。

    核心洞察

    深度必须随节点一起移动。弹出节点时，用它携带的深度更新答案；把孩子压栈时，深度加一。遍历完成后，见过的最大深度就是答案。

    stack ← [(root, 1)]
    answer ← max(answer, currentDepth)

    完整过程

    1. 空树直接返回 0；非空树把 (root, 1) 压入栈。
    2. 弹出一个 (node, depth)，用 depth 更新最大值。
    3. 若右孩子存在，压入 (right, depth + 1)。
    4. 若左孩子存在，压入 (left, depth + 1)；后压入，因此先被探测。
    5. 栈为空时返回记录的最大深度。

    边界情况

    • 空树：根节点为 null，直接返回 0。
    • 单节点树：初始项深度为 1，弹出一次后答案就是 1。
    • 完全偏斜树：显式栈不会触发语言调用栈溢出。
    • 节点值可为负数，但深度只与结构有关，与数值无关。

    复杂度

    时间 O(n) 每个节点恰好访问一次。
    空间 O(h) 显式栈与树高 h 成正比。

    平衡树中 h = O(log n)；最坏的单支树中 h = O(n)。

    替代方案取舍

    递归 DFS 只需写出 1 + max(left, right)，最贴近数学定义，但极深树可能耗尽调用栈。BFS 层序遍历也能逐层计数，时间同为 O(n)，空间为最宽一层的节点数 O(w)。本页用显式栈 DFS 在表达清晰与极端输入安全之间取平衡。

    常见错误

    • 把根节点初始深度写成 0，导致答案整体少一层。
    • 只压节点、不同时保存深度，弹出时无法知道所在层数。
    • 压入孩子时忘记使用 depth + 1。
    • 用节点值判断深度，忽略本题答案只与树结构有关。

    面试追问

    • 如果要求最小深度，为什么只有一个子树为空时不能直接取 min(left, right)？
    • 如何把显式栈版本改写为递归 DFS？递归函数应返回什么含义？
    • 如何同时返回最大深度以及一条通往最深叶子的路径？
    • 如果输入是一棵拥有父指针的树，怎样避免重复访问形成环？

    /**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 * }
 */
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }

        java.util.Deque<TreeNode> nodes = new java.util.ArrayDeque<>();
        java.util.Deque<Integer> depths = new java.util.ArrayDeque<>();
        nodes.push(root);
        depths.push(1);
        int answer = 0;

        while (!nodes.isEmpty()) {
            TreeNode node = nodes.pop();
            int depth = depths.pop();
            answer = Math.max(answer, depth);

            if (node.right != null) {
                nodes.push(node.right);
                depths.push(depth + 1);
            }
            if (node.left != null) {
                nodes.push(node.left);
                depths.push(depth + 1);
            }
        }

        return answer;
    }
}
    /**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = val;
 *     this.left = left;
 *     this.right = right;
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number}
 */
var maxDepth = function (root) {
    if (root === null) {
        return 0;
    }

    const stack = [[root, 1]];
    let answer = 0;

    while (stack.length > 0) {
        const [node, depth] = stack.pop();
        answer = Math.max(answer, depth);

        if (node.right !== null) {
            stack.push([node.right, depth + 1]);
        }
        if (node.left !== null) {
            stack.push([node.left, depth + 1]);
        }
    }

    return answer;
};

# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0

        stack = [(root, 1)]
        answer = 0

        while stack:
            node, depth = stack.pop()
            answer = max(answer, depth)

            if node.right is not None:
                stack.append((node.right, depth + 1))
            if node.left is not None:
                stack.append((node.left, depth + 1))

        return answer
    /**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (root == nullptr) {
            return 0;
        }

        std::vector<std::pair<TreeNode*, int>> stack = {{root, 1}};
        int answer = 0;

        while (!stack.empty()) {
            auto [node, depth] = stack.back();
            stack.pop_back();
            answer = std::max(answer, depth);

            if (node->right != nullptr) {
                stack.push_back({node->right, depth + 1});
            }
            if (node->left != nullptr) {
                stack.push_back({node->left, depth + 1});
            }
        }

        return answer;
    }
};
