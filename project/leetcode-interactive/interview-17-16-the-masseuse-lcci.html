TODAY / 08 SLOTS 不可相邻

每根柱子是一段预约分钟数。相邻柱子不能同时被选中。

PROBLEM BRIEF

题意

给定整数数组 nums， 其中每个元素表示一项连续到来的预约时长。按摩师不能接受相邻的两项预约； 请返回她能接受的预约总分钟数最大值。

输入约定

官方当前题面未单列数值范围；函数签名给出整数数组。空数组应返回 0。

官方样例 1

输入
nums = [1, 2, 3, 1]
输出
4

官方样例 2

输入
nums = [2, 7, 9, 3, 1]
输出
12

官方样例 3

输入
nums = [2, 1, 4, 5, 3, 1, 1, 3]
输出
12

SOLUTION VAULT

准备好核对思路了吗？

核心洞察、完整推导、边界、复杂度、追问与四语言代码都收在这里。

01 / CORE

核心洞察：只需要记住前两拍

处理第 i 项预约时，最优方案只有两类：不接当前项，答案沿用前 i − 1 项的最优值； 接当前项，则必须跳过相邻的第 i − 1 项，用前 i − 2 项的最优值加上当前时长。 因而有 dp[i] = max(dp[i − 1], dp[i − 2] + nums[i]) 。

02 / PROCESS

完整过程

  1. 初始化：前两拍的最优值均视作 0。
  2. 枚举预约：计算跳过当前与接下当前两种收益。
  3. 取较大者：得到扫描到当前位置的最优值。
  4. 滚动更新：将前两项状态向前移动，无需保存整张表。

03 / BOUNDARIES

边界

  • 空数组：没有预约，返回 0。
  • 单项预约：直接接受该项即可。
  • 两项预约：只能取较大的一个。
  • 相同最优值：题目只要求分钟数，不必恢复具体方案。

时间复杂度

O(n)

每项预约只处理一次。

空间复杂度

O(1)

仅保留两个滚动状态。

推荐程度

首选

状态清晰，代码短，便于追问。

ALTERNATIVES

替代方案取舍

完整 DP 数组：同样是 O(n) 时间，但需要 O(n) 空间； 优点是便于恢复具体选择，若只返回最大分钟数则没有必要。

递归枚举：思路直观，但会重复计算同一后缀， 朴素版本达到 O(2ⁿ)，不适合作为面试主线。

COMMON MISSTEPS

常见错误

  • 把“不能接相邻预约”误解为每隔固定两项必须接一项。
  • 更新滚动变量时顺序错误，覆盖了仍要使用的前两项状态。
  • 只比较当前两个元素，忽略更早选择形成的累计最优值。
  • 空数组直接访问首元素，造成越界。

INTERVIEW FOLLOW-UPS

面试追问

如何恢复预约集合？

保留完整 dp，并从末尾比较 dp[i] 与 dp[i − 1] 回溯。

如果首尾也相邻？

拆成“不选首项”和“不选尾项”两次线性 DP。

如果允许负数？

以 0 初始化仍可选择全部跳过，返回不小于 0 的最优值。

class Solution {
    public int massage(int[] nums) {
        int prevTwo = 0;
        int prevOne = 0;

        for (int minutes : nums) {
            int current = Math.max(prevOne, prevTwo + minutes);
            prevTwo = prevOne;
            prevOne = current;
        }

        return prevOne;
    }
}
