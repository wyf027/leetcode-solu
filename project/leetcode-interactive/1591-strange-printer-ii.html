给定一个初始无色的 m × n 网格 targetGrid，每个数字表示该位置最终应有的颜色。判断能否按规则得到目标网格：

一次印一个实心矩形选择一种颜色和矩形区域，该颜色覆盖区域内已有颜色。
每种颜色最多使用一次某颜色完成一次矩形打印后，不能再用它打印。

返回：存在合法打印顺序时返回 true，否则返回 false。

04

题解：把覆盖关系变成 DAG

外接矩形 + 建图 + 拓扑排序

颜色 c 只能打印一次，因此可把它的打印区域取为覆盖全部 c 格子的最小外接矩形。若矩形内部最终出现另一颜色 d，那么 d 必须在 c 之后打印。

完整过程

  1. 扫描边界：对每个出现的颜色记录最小/最大行列，得到最小外接矩形。
  2. 建立依赖：枚举颜色 c 的矩形；若格子最终为 d != c，加入边 c → d。重复边只计一次入度。
  3. 拓扑消除：所有入度为零的已出现颜色入队，不断取出并删除出边。
  4. 判断：处理数等于实际颜色数说明无环、可打印；否则剩余颜色形成环。

必要性

若 d 位于 c 的外接矩形内，打印 c 会覆盖该格。为使它最终为 d，只能稍后打印 d。所以每条边都是合法顺序必须满足的约束，有环时不可能全部满足。

充分性

图无环时按拓扑序打印各外接矩形。当前矩形内不属于当前颜色的目标格，对应颜色都在它之后，会覆盖回来；任何可能影响当前颜色的后续矩形也已由相应依赖约束顺序，最终恰好得到目标网格。

边界与复杂度

  • 单色网格没有边，必然可打印。
  • 重复依赖必须去重，否则入度会被多算。
  • 只统计实际出现的颜色；编号虽在 1..60，中间可缺失。
  • 双向依赖或更长的环都表示不可打印。

设颜色数为 C ≤ 60。扫描边界 O(mn)，扫描所有外接矩形最坏 O(Cmn)，邻接矩阵拓扑排序 O(C²)；总时间 O(Cmn + C²)，空间 O(C²)。

import java.util.*;

class Solution {
    public boolean isPrintable(int[][] g) {
        int m=g.length,n=g[0].length,count=0;
        int[] t=new int[61],b=new int[61],l=new int[61],r=new int[61],in=new int[61];
        boolean[] seen=new boolean[61];
        Arrays.fill(t,m); Arrays.fill(l,n); Arrays.fill(b,-1); Arrays.fill(r,-1);
        for(int i=0;i<m;i++) for(int j=0;j<n;j++){
            int c=g[i][j];
            if(!seen[c]){seen[c]=true;count++;}
            t[c]=Math.min(t[c],i); b[c]=Math.max(b[c],i);
            l[c]=Math.min(l[c],j); r[c]=Math.max(r[c],j);
        }
        boolean[][] edge=new boolean[61][61];
        for(int c=1;c<=60;c++) if(seen[c])
            for(int i=t[c];i<=b[c];i++) for(int j=l[c];j<=r[c];j++){
                int d=g[i][j];
                if(d!=c && !edge[c][d]){edge[c][d]=true;in[d]++;}
            }
        ArrayDeque<Integer> q=new ArrayDeque<>();
        for(int c=1;c<=60;c++) if(seen[c]&&in[c]==0) q.offer(c);
        int done=0;
        while(!q.isEmpty()){
            int c=q.poll(); done++;
            for(int d=1;d<=60;d++) if(edge[c][d]&&--in[d]==0) q.offer(d);
        }
        return done==count;
    }
}

var isPrintable = function(targetGrid) {
    const m=targetGrid.length,n=targetGrid[0].length;
    const top=Array(61).fill(m),bottom=Array(61).fill(-1);
    const left=Array(61).fill(n),right=Array(61).fill(-1);
    const seen=Array(61).fill(false),indegree=Array(61).fill(0);
    let count=0;
    for(let i=0;i<m;i++) for(let j=0;j<n;j++){
        const c=targetGrid[i][j];
        if(!seen[c]){seen[c]=true;count++;}
        top[c]=Math.min(top[c],i); bottom[c]=Math.max(bottom[c],i);
        left[c]=Math.min(left[c],j); right[c]=Math.max(right[c],j);
    }
    const edge=Array.from({length:61},()=>Array(61).fill(false));
    for(let c=1;c<=60;c++) if(seen[c])
        for(let i=top[c];i<=bottom[c];i++)
            for(let j=left[c];j<=right[c];j++){
                const d=targetGrid[i][j];
                if(d!==c && !edge[c][d]){edge[c][d]=true;indegree[d]++;}
            }
    const queue=[];
    for(let c=1;c<=60;c++) if(seen[c]&&indegree[c]===0) queue.push(c);
    let head=0,done=0;
    while(head<queue.length){
        const c=queue[head++]; done++;
        for(let d=1;d<=60;d++)
            if(edge[c][d] && --indegree[d]===0) queue.push(d);
    }
    return done===count;
};

from collections import deque
from typing import List

class Solution:
    def isPrintable(self, targetGrid: List[List[int]]) -> bool:
        m, n = len(targetGrid), len(targetGrid[0])
        top, bottom = [m]*61, [-1]*61
        left, right = [n]*61, [-1]*61
        seen, indegree = [False]*61, [0]*61
        count = 0
        for i in range(m):
            for j in range(n):
                c = targetGrid[i][j]
                if not seen[c]:
                    seen[c], count = True, count + 1
                top[c], bottom[c] = min(top[c], i), max(bottom[c], i)
                left[c], right[c] = min(left[c], j), max(right[c], j)
        edge = [[False]*61 for _ in range(61)]
        for c in range(1, 61):
            if not seen[c]:
                continue
            for i in range(top[c], bottom[c]+1):
                for j in range(left[c], right[c]+1):
                    d = targetGrid[i][j]
                    if d != c and not edge[c][d]:
                        edge[c][d] = True
                        indegree[d] += 1
        q = deque(c for c in range(1,61) if seen[c] and indegree[c] == 0)
        done = 0
        while q:
            c = q.popleft()
            done += 1
            for d in range(1, 61):
                if edge[c][d]:
                    indegree[d] -= 1
                    if indegree[d] == 0:
                        q.append(d)
        return done == count

替代方案

可反向剥离矩形：反复寻找一种颜色，使其外接矩形内只含自己或已移除的格子，再清空矩形；某轮找不到即可判定循环依赖。它很直观，但朴素实现每轮重扫，最坏为 O(C²mn)。

面试追问

为什么最小外接矩形足够？

任何合法区域都必须覆盖该颜色的所有目标格，至少包含最小外接矩形。扩大矩形只会增加约束，不会消除已有约束。

拓扑序唯一吗？

不一定。多个零入度颜色之间没有强制顺序，可能对应多条合法打印序列。

能否用 DFS 判环？

可以。三色标记遇到指向搜索中节点的边即发现环；Kahn 算法还能直接给出一条拓扑序。

常见错误

  • 边方向写反：矩形属于 c、内部看到 d 时应为 c → d。
  • 重复边未去重，导致入度无法正确归零。
  • 把“区域不是纯色”直接判错，忽略后续覆盖本来就是允许的。
  • 把未出现颜色计入总数。
  • 认为嵌套必然非法；真正非法的是依赖成环。
