我的日程安排表 I

My Calendar I

像真正的日历一样接收预约：只有新日程与所有已接受日程都没有非空交集时，才能把它写进日历。

关键语义

结束时刻可以紧接下一场开始时刻

[startTime, endTime)

01题目说明

实现 MyCalendar 类来保存日程。每项日程由整数 startTime 和 endTime 表示，占用半开区间 [startTime, endTime)。

若新日程与任一已接受日程存在非空时间交集，就会造成重复预订：此时返回 false，并且不能保存新日程；否则保存并返回 true。

构造函数

MyCalendar()

初始化一个空日历对象。

预订方法

boolean book(int startTime, int endTime)

成功保存返回 true；发生冲突返回 false 且保持日历不变。

为什么 20 可以同时作为结束与开始？

区间 [10, 20) 不包含 20，所以它与 [20, 30) 没有共同的时刻。

官方示例

输入
["MyCalendar", "book", "book", "book"]
[[], [10, 20], [15, 25], [20, 30]]

输出
[null, true, false, true]

解释
MyCalendar myCalendar = new MyCalendar();
myCalendar.book(10, 20); // true
myCalendar.book(15, 25); // false，时间 15 已被已有日程占用
myCalendar.book(20, 30); // true，前一项不包含结束时刻 20

约束

  • 0 <= startTime < endTime <= 109
  • 每个测试用例最多调用 book 1000 次。

Solution unlocked

有序区间 + 二分定位

核心题解

核心洞察

始终让已接受区间按开始时间升序排列。新日程 [start, end) 的插入位置确定后，它只可能与左侧紧邻区间或右侧紧邻区间发生冲突；更远的区间会被这两个邻居隔开。

两个半开区间不重叠，当且仅当一个在另一个左侧：end <= otherStart 或 otherEnd <= start。

完整过程

  1. 二分找到第一个开始时间不小于 start 的位置 i。
  2. 若右邻居存在，要求 end <= intervals[i].start。
  3. 若左邻居存在，要求 intervals[i-1].end <= start。
  4. 两个条件都满足时插入该位置并返回 true；否则返回 false，原数组不变。

正确性证明

必要性：若新日程能加入，它与所有旧日程都不重叠，当然也与插入位置两侧的邻居不重叠，因此两项边界检查必然成立。

充分性：右侧所有区间的开始时间都不早于右邻居；只要新日程在右邻居开始前结束，就不会碰到更右区间。左侧所有区间的结束时间都不晚于左邻居的结束时间；只要左邻居在新日程开始前结束，就不会碰到更左区间。因此检查通过即可安全插入。

不变式：每次成功插入都放在二分得到的位置，所以区间仍按开始时间有序；失败时集合不变。由归纳法，所有已保存日程始终两两不重叠。

边界与细节

  • 空日历：左右邻居都不存在，直接接受。
  • 插在最前或最后：只需检查存在的一侧。
  • 端点相接：previousEnd == start 与 end == nextStart 都合法，因为区间右端不包含。
  • 完全相同、包含或被包含的区间都会冲突。
  • 时间可到 109，比较本身不会超出题目所用整数范围。

复杂度

O(log n)二分定位
O(n)数组插入，因此单次 book 总计 O(n)
O(n)保存所有已接受日程

四语言完整代码

以下实现均遵循官方类与方法签名。Java、C++ 使用有序映射/集合把单次操作降至 O(log n)；JavaScript、Python 使用有序数组，单次插入为 O(n)。

Java · TreeMap官方可提交
import java.util.Map;
import java.util.TreeMap;

class MyCalendar {
    private final TreeMap<Integer, Integer> calendar;

    public MyCalendar() {
        calendar = new TreeMap<>();
    }

    public boolean book(int startTime, int endTime) {
        Map.Entry<Integer, Integer> previous =
                calendar.floorEntry(startTime);
        if (previous != null && previous.getValue() > startTime) {
            return false;
        }

        Map.Entry<Integer, Integer> next =
                calendar.ceilingEntry(startTime);
        if (next != null && endTime > next.getKey()) {
            return false;
        }

        calendar.put(startTime, endTime);
        return true;
    }
}
JavaScript · sorted array官方可提交
var MyCalendar = function() {
    this.intervals = [];
};

/**
 * @param {number} startTime
 * @param {number} endTime
 * @return {boolean}
 */
MyCalendar.prototype.book = function(startTime, endTime) {
    let left = 0;
    let right = this.intervals.length;

    while (left < right) {
        const middle = left + Math.floor((right - left) / 2);
        if (this.intervals[middle][0] < startTime) {
            left = middle + 1;
        } else {
            right = middle;
        }
    }

    const index = left;
    if (index > 0 && this.intervals[index - 1][1] > startTime) {
        return false;
    }
    if (index < this.intervals.length &&
        endTime > this.intervals[index][0]) {
        return false;
    }

    this.intervals.splice(index, 0, [startTime, endTime]);
    return true;
};
Python 3 · bisect官方可提交
from bisect import bisect_left
from typing import List


class MyCalendar:
    def __init__(self):
        self.intervals: List[List[int]] = []

    def book(self, startTime: int, endTime: int) -> bool:
        index = bisect_left(self.intervals, [startTime, -1])

        if index > 0 and self.intervals[index - 1][1] > startTime:
            return False

        if (index < len(self.intervals)
                and endTime > self.intervals[index][0]):
            return False

        self.intervals.insert(index, [startTime, endTime])
        return True
C++ · ordered set官方可提交
#include <set>
#include <utility>
using namespace std;

class MyCalendar {
private:
    set<pair<int, int>> calendar;

public:
    MyCalendar() = default;

    bool book(int startTime, int endTime) {
        auto next = calendar.lower_bound({startTime, endTime});

        if (next != calendar.end() && endTime > next->first) {
            return false;
        }

        if (next != calendar.begin()) {
            auto previous = prev(next);
            if (previous->second > startTime) {
                return false;
            }
        }

        calendar.insert({startTime, endTime});
        return true;
    }
};

替代方案

  • 线性扫描：逐个检查全部区间，最直观；每次 O(n)，无需维护顺序。
  • 平衡搜索树：如 Java TreeMap、C++ set，只查前驱与后继，单次 O(log n)。
  • 动态线段树：能处理更复杂的区间计数，但本题仅 1000 次调用，工程与常数开销偏大。

面试追问

  • 如果允许最多双重预订，如何扩展？可转向差分映射或动态线段树。
  • 如何支持取消日程？有序树中按起点定位并删除，同时要定义重复起点的规则。
  • 并发调用 book 时怎么办？检查与插入必须处于同一个临界区或事务。
  • 为什么只看相邻区间足够？回答应基于有序性与“已保存区间两两不重叠”的不变式。

常见错误

  • 把端点相接误判为冲突：应使用严格的 > 判断重叠，而不是 >=。
  • 预订失败后仍把区间插入集合，污染后续结果。
  • 只检查前驱、不检查后继，或在数组首尾访问越界。
  • 二分目标与检查条件不一致，导致插入位置偏一。
  • 宣称数组方案单次 O(log n)，却忽略中间插入需要搬移元素的 O(n) 成本。
