官方题目 ↗

01 / 题目与接口

实现一个固定长度的位集。下标从 0 开始，初始所有位均为 0。重复设置为已有值时，状态不变；字符串的顺序必须与下标顺序一致。

Bitset(int size)
创建长度为 size 的全 0 位集。
void fix(int idx)
将第 idx 位设为 1。
void unfix(int idx)
将第 idx 位设为 0。
void flip()
将所有位同时取反。
boolean all()
每一位都是 1 时返回 true。
boolean one()
至少一位是 1 时返回 true。
int count()
返回值为 1 的位数。
String toString()
返回当前完整的 01 字符串。

约束

  • 1 ≤ size ≤ 10⁵，0 ≤ idx ≤ size − 1。
  • 上述七种方法的调用总数不超过 10⁵。
  • all / one / count / toString 中至少有一种被调用一次。
  • toString() 最多调用 5 次。

官方示例（完整参数）

操作：
["Bitset","fix","fix","flip","all","unfix","flip","one","unfix","count","toString"]
参数：
[[5],[3],[1],[],[],[0],[],[],[0],[],[]]
[null,null,null,null,false,null,null,true,null,2,"01010"]

构造和无返回值操作在示例输出中用 null 占位。逐步状态为：00000 → 00010 → 01010 → 10101 →（all 为 false）→ 00101 → 11010 →（one 为 true）→ 01010 →（count 为 2）→（toString 为 "01010"）。

    04 / 独立题解

    准备好后，再展开实现思路、内部状态与四语言代码。

    核心洞察：翻转的是解释方式

    连续翻转两次会还原。用原始数组 raw 与一个全局翻转标记 rev 表示状态，逻辑位满足 value[i] = raw[i] XOR rev。再维护逻辑 1 的数量 ones。翻转时无需逐位修改：令 rev ^= 1，ones = size - ones。

    内部视图 · 与上方回放同步

    使用上方“上一步 / 下一步”观察同一操作如何影响两层数据。

    原始存储 00000

    翻转标记 0

    逻辑输出 00000

    完整过程

    1. 构造：raw 全为 0，rev = 0，ones = 0。
    2. fix(idx)：先算 raw[idx] XOR rev。仅当它为 0 时，翻转 raw[idx] 并令 ones 加 1。
    3. unfix(idx)：仅当逻辑位为 1 时，翻转 raw[idx] 并令 ones 减 1。
    4. flip()：只翻转 rev，将计数更新为 size − ones。
    5. all() 判断 ones == size；one() 判断 ones > 0；count() 直接返回 ones。
    6. toString() 按下标从 0 到 size − 1 计算 XOR，写入字符串。

    例如 fix(3)、fix(1) 后，raw = 01010，rev = 0，ones = 2。flip 后 raw 不变，rev = 1，逻辑值为 10101，ones = 3。随后 unfix(0) 把 raw[0] 从 0 改为 1，raw = 11010，逻辑值为 00101，ones = 2。

    正确性证明

    维护不变量：每一位的实际值等于 raw[i] XOR rev，ones 等于实际值为 1 的位数。初始状态显然成立。fix / unfix 先判断实际值，若无需改变则保留不变量；否则只切换目标 raw 位，目标实际值随之切换，并将计数准确增减 1。flip 切换 rev，使每一位实际值取反，新的 1 数量恰好为 size − ones。因此所有更新保持不变量。查询由正确计数和正确逻辑位得到结果，故任意合法调用序列均满足接口定义。

    边界与常见错误

    • 重复 fix / unfix 是幂等操作，不能无条件修改计数。
    • 翻转后必须判断逻辑位，而不是直接判断 raw[idx]。
    • flip 必须同步更新 ones；重复翻转两次应完全还原。
    • size = 1、全 0、全 1 与 idx = size − 1 都沿用相同公式。
    • 字符串顺序是下标顺序，不是把数组当二进制整数后的反向输出。
    • 不要用 JavaScript 的一个位运算整数装下 10⁵ 位；位运算整数只有 32 位语义。这里 XOR 仅作用于单个 0 / 1。

    复杂度

    令 n = size。构造时间 O(n)，fix、unfix、flip、all、one、count 均为 O(1)，toString 为 O(n)。持久空间 O(n)，字符串生成需要 O(n) 输出空间。q 次方法调用中若含 s 次 toString，总时间为 O(n + q + sn)，且 s ≤ 5。下列数组实现没有把每个逻辑位压缩成一个物理位。

    替代方案

    直接修改数组可使思路最直观，但每次 flip 都是 O(n)，最坏总时间 O(nq)。维护正串和反串并交换引用也能常数时间翻转，但应使用可变数组，否则字符串的单点更新仍可能 O(n)。按机器字打包可节省内存；仍可结合全局翻转标记，但需处理末尾不足一个机器字的无效位。

    面试追问

    • 如果新增区间翻转和区间计数？考虑维护区间 1 数量的懒标记线段树，操作 O(log n)。
    • 如何减少存储？按字节或机器字打包 raw；全局 rev 与 ones 的语义保持不变。
    • toString 能否 O(1)？显式返回长度 n 的新字符串本身需要 Ω(n) 时间，除非改变接口为惰性视图。

    Java

    class Bitset {
    private final int[] raw;
    private int rev = 0;
    private int ones = 0;

    public Bitset(int size) {
        raw = new int[size];
    }

    public void fix(int idx) {
        if ((raw[idx] ^ rev) == 0) {
            raw[idx] ^= 1;
            ones++;
        }
    }

    public void unfix(int idx) {
        if ((raw[idx] ^ rev) == 1) {
            raw[idx] ^= 1;
            ones--;
        }
    }

    public void flip() {
        rev ^= 1;
        ones = raw.length - ones;
    }

    public boolean all() { return ones == raw.length; }
    public boolean one() { return ones > 0; }
    public int count() { return ones; }

    public String toString() {
        StringBuilder result = new StringBuilder(raw.length);
        for (int bit : raw) result.append(bit ^ rev);
        return result.toString();
    }
}

    JavaScript

    class Bitset {
    constructor(size) {
        this.raw = new Uint8Array(size);
        this.rev = 0;
        this.ones = 0;
    }

    fix(idx) {
        if ((this.raw[idx] ^ this.rev) === 0) {
            this.raw[idx] ^= 1;
            this.ones++;
        }
    }

    unfix(idx) {
        if ((this.raw[idx] ^ this.rev) === 1) {
            this.raw[idx] ^= 1;
            this.ones--;
        }
    }

    flip() {
        this.rev ^= 1;
        this.ones = this.raw.length - this.ones;
    }

    all() { return this.ones === this.raw.length; }
    one() { return this.ones > 0; }
    count() { return this.ones; }

    toString() {
        return Array.from(this.raw, bit => bit ^ this.rev).join('');
    }
}

    Python 3

    class Bitset:
    def __init__(self, size: int):
        self.raw = bytearray(size)
        self.rev = 0
        self.ones = 0

    def fix(self, idx: int) -> None:
        if (self.raw[idx] ^ self.rev) == 0:
            self.raw[idx] ^= 1
            self.ones += 1

    def unfix(self, idx: int) -> None:
        if (self.raw[idx] ^ self.rev) == 1:
            self.raw[idx] ^= 1
            self.ones -= 1

    def flip(self) -> None:
        self.rev ^= 1
        self.ones = len(self.raw) - self.ones

    def all(self) -> bool:
        return self.ones == len(self.raw)

    def one(self) -> bool:
        return self.ones > 0

    def count(self) -> int:
        return self.ones

    def toString(self) -> str:
        return ''.join(str(bit ^ self.rev) for bit in self.raw)

    C++

    #include <vector>
#include <string>
using namespace std;

class Bitset {
    vector<int> raw;
    int rev = 0;
    int ones = 0;
public:
    Bitset(int size) : raw(size, 0) {}

    void fix(int idx) {
        if ((raw[idx] ^ rev) == 0) {
            raw[idx] ^= 1;
            ++ones;
        }
    }

    void unfix(int idx) {
        if ((raw[idx] ^ rev) == 1) {
            raw[idx] ^= 1;
            --ones;
        }
    }

    void flip() {
        rev ^= 1;
        ones = static_cast<int>(raw.size()) - ones;
    }

    bool all() { return ones == static_cast<int>(raw.size()); }
    bool one() { return ones > 0; }
    int count() { return ones; }

    string toString() {
        string result(raw.size(), '0');
        for (size_t i = 0; i < raw.size(); ++i)
            result[i] = static_cast<char>('0' + (raw[i] ^ rev));
        return result;
    }
};
