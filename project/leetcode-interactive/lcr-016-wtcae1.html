无重复字符的最长子串

用一个始终没有重复字符的滑动窗口扫描字符串。右指针扩张；一旦遇到窗口内已有的字符，就移动左指针越过它上次出现的位置。

滑动窗口 / 哈希表O(n) 时间O(字符集) 空间

题目

给定字符串 s，找出其中不含重复字符的最长连续子串长度。

s = "abcabcbb"

输出：3，子串为 "abc"

约束：0 ≤ s.length ≤ 5 × 10⁴。空串答案为 0。

面试一句话

Map 记录每个字符最后出现的下标。若重复字符仍在当前窗口中，把 left 更新为 last[ch] + 1，而不是回退。

  1. ① right 从左到右扫描。
  2. ② 更新 left，维护窗口无重复。
  3. ③ 用 right - left + 1 更新最大值。

洞察、过程与边界

不变量：区间 [left, right] 中每个字符至多出现一次。

关键：重复字符可能在旧窗口之外，所以取 left = max(left, last[ch] + 1)。

边界：空字符串、全部相同字符、Unicode 字符都应被正常处理。

复杂度与替代方案

复杂度：左右指针只前进，每字符 O(1) 哈希操作，总计 O(n)。

替代：用 Set 并逐步删除左端字符也可行；Map 直接跳过重复位置更紧凑。

追问：若求最多 K 个不同字符的窗口？改为计数表并在超限时收缩。

常见失误

  • left 回退：必须用 max，旧重复字符不能让窗口倒退。
  • 长度少一：闭区间长度是 right - left + 1。
  • 只用 Set：可做，但遗漏删除过程就会产生错误窗口。
