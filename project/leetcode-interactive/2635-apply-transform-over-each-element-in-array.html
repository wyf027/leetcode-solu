2635EASY非付费题Apply Transform Over Each Element in Array
01 · Problem

题目说明

给定整数数组 arr 与映射函数 fn，返回逐项转换后的新数组，并保留原数组。

任务

创建一个新数组，使新数组下标 i 处的值由原元素和当前索引共同决定：

returnedArray[i] = fn(arr[i], i)

转换函数可能使用元素、索引、两者，或忽略全部参数。请不要调用 JavaScript 内置的 Array.map。

约束

  • 0 <= arr.length <= 1000
  • -109 <= arr[i] <= 109
  • fn 返回一个整数

04 · Solution

一次遍历，逐项写入

关键不在复杂算法，而在准确复刻映射语义：把元素值与索引都交给回调，并把返回值放到相同位置。

01 / 建新数组

不改动输入

先准备结果数组，所有转换结果都写入这里，原数组保持不变。

02 / 顺序扫描

索引天然可用

用普通循环访问每个位置，当前下标就是回调需要的第二个参数。

03 / 收集结果

一次调用对应一项

计算 fn(arr[i], i)，将返回值追加或写入结果的第 i 位。

完整过程

  1. 初始化空结果数组 result。
  2. 令索引 i 从 0 递增到 arr.length - 1。
  3. 每轮调用 fn(arr[i], i)，把返回值放入结果数组。
  4. 遍历结束后返回 result。

正确性说明

循环不变量：开始处理下标 i 前，结果数组前 i 项都满足 result[j] = fn(arr[j], j)。

初始时结果为空，不变量自然成立。第 i 轮把恰好需要的 fn(arr[i], i) 写入结果，因此不变量继续成立。循环终止时所有下标都已处理，所以整个返回数组满足题意。

边界情况

  • 空数组：循环不执行，返回空数组。
  • 单元素：仍会把索引 0 传给函数。
  • 负数和大整数：遍历逻辑不受数值正负影响。
  • 函数忽略参数：照常调用并收集其常量结果。

复杂度

时间O(n)
额外空间O(n)

返回的新数组本身需要 O(n) 空间；除此之外只使用常数个变量。

/**

var map = function(arr, fn) {
    const result = [];
    for (let i = 0; i < arr.length; i++) {
        result.push(fn(arr[i], i));
    }
    return result;
};
Java本地语义参考 
import java.util.function.IntBinaryOperator;

class Solution {
    public static int[] map(int[] arr, IntBinaryOperator fn) {
        int[] result = new int[arr.length];
        for (int i = 0; i < arr.length; i++) {
            result[i] = fn.applyAsInt(arr[i], i);
        }
        return result;
    }
}
Python本地语义参考 
from collections.abc import Callable


def map_array(arr: list[int], fn: Callable[[int, int], int]) -> list[int]:
    result = []
    for i, value in enumerate(arr):
        result.append(fn(value, i))
    return result
C++本地语义参考 
#include <functional>
#include <vector>
using namespace std;

vector<int> mapArray(
    const vector<int>& arr,
    const function<int(int, int)>& fn
) {
    vector<int> result;
    result.reserve(arr.size());
    for (int i = 0; i < static_cast<int>(arr.size()); i++) {
        result.push_back(fn(arr[i], i));
    }
    return result;
}

替代方案与面试追问

  • 预分配：创建等长数组后按索引赋值，可明确表达输出长度固定。
  • 递归：可以实现，但数组最长 1000，递归栈没有收益。
  • 为何禁用 Array.map？题目考察的是高阶函数、回调参数与手写遍历。
  • 能否原地改数组？不能保持标准 map 的“返回新数组”语义，也可能破坏调用者数据。
  • 回调抛错怎么办？本题没有恢复约定；错误应自然向调用方传播。

常见错误

  • 只调用 fn(arr[i])，漏传索引。
  • 把索引和值的顺序写反。
  • 忘记返回结果数组。
  • 直接改写 arr，没有创建新数组。
  • 误用题目明确禁止的 Array.map。
