01 / PROBLEM

题意与输入约定

给定字符串数组 nums 和整数 k。每个字符串表示一个非负整数，且没有前导零。返回数组中数值排名第 k 大的元素，返回类型仍是字符串。

重复值各占一个名次。例如 ["1","2","2"] 的第一大和第二大都是 "2"，第三大是 "1"。

  • 1 ≤ k ≤ nums.length ≤ 10⁴
  • 1 ≤ nums[i].length ≤ 100
  • nums[i] 仅包含数字字符 0–9。
  • 所有字符串都不含前导零，单独的 "0" 合法。

函数：kthLargestNumber(nums, k) → string

官方示例

示例 1

nums = ["3","6","7","10"]
k = 4
输出 = "3"

从大到小是 10、7、6、3，因此第四大为 "3"。

示例 2

nums = ["2","21","12","1"]
k = 3
输出 = "2"

从大到小是 21、12、2、1，因此第三大为 "2"。

示例 3

nums = ["0","0"]
k = 2
输出 = "0"

两个零分别占据第一名和第二名。

02 / INSIGHT

把整数比较变成字符串比较

无需将字符串转换为数值。无前导零时，位数越多，数值越大；位数相同时，按字典序比较就等同于按数值比较。

将数组按这个规则降序排列，答案就是 nums[k - 1]。相同字符串比较结果为 0，但每一个元素仍保留在数组中。

第一关：位数

"100" > "99"
3 位大于 2 位，无需逐位比较。

第二关：首个不同字符

"21" > "12"
同为 2 位，首位 2 大于 1。

完整过程与正确性

  1. 定义降序比较器：长度不同则长串在前；长度相同则字典序较大的在前。
  2. 对整个数组排序，既不转为固定精度数值，也不去重。
  3. 取下标 k - 1，返回该字符串。

为什么比较器正确？

对于无前导零的正整数，m 位数至少是 10^(m−1)，任何不足 m 位的数都小于它；零单独作为一位数，与规则一致。同位数若首个不同字符在某一位置，较大的该位带来的差值超过所有低位能抵消的差值，因此字典序与数值序一致。

为什么第 k 个元素就是答案？

比较器精确表达数值顺序，排序后序列满足非递增关系。按出现次数计数时，第一个位置是第一大，第二个是第二大，依次类推，第 k 个位置即答案。等值元素无论怎样互换都不影响答案。

归并演示的不变量

每条待合并队列均已降序排列。每次取两队首中较大的值，它必然是两个剩余队列中的最大值；因此结果前缀始终有序。长度为 1 的段天然有序，逐轮加倍段宽直至覆盖全数组，得到降序排列。

复杂度与边界

设 n 为元素数，L 为最大字符串长度（≤ 100）。一次比较最坏 O(L)，采用 O(n log n) 次比较的排序时，总时间为 O(n L log n)。

Java 对象数组排序的辅助空间最坏 O(n)；Python 的键与排序缓冲为 O(n)，键引用原字符串；C++ std::sort 通常使用 O(log n) 栈空间。JavaScript 标准不保证 sort 的时间和空间复杂度，常见实现为 O(n log n) 次比较、O(n) 辅助空间。这里均不计输入字符串自身存储。

可视化归并本身需 O(n) 缓冲，另保存步骤快照以支持回退；快照占用比提交算法更高，因此限制演示规模。

  • n = 1：唯一元素就是答案；k = 1 取最大，k = n 取最小。
  • 全部相等、多个零：均保留，不去重。
  • 100 位整数：始终以字符串表示，不存在固定整数类型溢出。
  • Java、JavaScript、C++ 代码会原地重排输入；Python 的 sorted 返回新列表。
  • 题目保证没有负号和前导零；若输入协议改变，需先规范化并增加符号比较。

Java

import java.util.Arrays;

class Solution {
    public String kthLargestNumber(String[] nums, int k) {
        Arrays.sort(nums, (a, b) -> {
            if (a.length() != b.length()) {
                return Integer.compare(b.length(), a.length());
            }
            return b.compareTo(a);
        });
        return nums[k - 1];
    }
}

JavaScript

/**
 * @param {string[]} nums
 * @param {number} k
 * @return {string}
 */
var kthLargestNumber = function(nums, k) {
    nums.sort((a, b) => {
        if (a.length !== b.length) return b.length - a.length;
        return a === b ? 0 : a > b ? -1 : 1;
    });
    return nums[k - 1];
};

Python 3

from typing import List

class Solution:
    def kthLargestNumber(self, nums: List[str], k: int) -> str:
        ordered = sorted(nums, key=lambda s: (len(s), s), reverse=True)
        return ordered[k - 1]

C++

#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string kthLargestNumber(vector<string>& nums, int k) {
        sort(nums.begin(), nums.end(), [](const string& a, const string& b) {
            if (a.size() != b.size()) return a.size() > b.size();
            return a > b;
        });
        return nums[k - 1];
    }
};

替代方案与面试追问

  • k 很小或数据流？维护容量为 k 的最小堆，堆内保留当前最大的 k 个数，堆顶即答案。时间 O(n L log(k+1))，空间 O(k)。
  • 只需一个名次？随机快速选择，平均 O(nL)，最坏 O(n²L)；大量重复值时可用三路划分。
  • 多次查询不同 k？先排序一次，后续每次按下标 O(1) 查找。
  • 可以用大整数吗？Python int、Java BigInteger、JavaScript BigInt 可以精确表示，但本题直接比较字符串即可，省去解析及数值对象开销。
  • 需要稳定排序吗？只返回数值字符串时不需要；若额外要求相等值按原位置排序，则需稳定性或索引作为次关键字。

常见错误

  • 只按字典序排序：会让 "9" 排在 "10" 前面。
  • 用 Number、long 或 long long 强制转换：100 位输入会丢精度或溢出。
  • 先用 Set 去重：改变了重复值的名次。
  • 降序后取 nums[k]：下标偏移一位。
  • 比较器仅返回布尔值：JavaScript 排序需要负数、零或正数。
  • C++ 比较器写成 a >= b：不满足严格弱序，等值必须返回 false。
  • 忽略长度上限 L：字符串比较最坏需要逐位扫描。
