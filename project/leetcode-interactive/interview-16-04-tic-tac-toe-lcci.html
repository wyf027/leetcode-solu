Problem

题意

给定由 "X"、"O" 与空格组成的 N × N 棋盘。若任一行、列或对角线全是同一非空字符，返回赢家； 无赢家且棋盘已满返回 "Draw"，仍有空位则返回 "Pending"。

官方示例

board = ["O X"," XO","X O"] "X"
board = ["OOX","XXO","OXO"] "Draw"
board = ["OOX","XXO","OX "] "Pending"

空格在页面中可写成 ␠ 以便看见；代码与 JSON 输入仍保留成对直引号。

规则与约束

  • 1 ≤ board.length = board[i].length ≤ 100。
  • 输入保证遵循井字棋规则，落子后不会继续非法行动。
  • 任一完整行、列或对角线即可结束比赛。
  • 交互台为保证可读性展示 1 ≤ N ≤ 10；提交代码支持官方上限。

Solution locker

题解

核心洞察

可能获胜的线路只有 N 行、N 列和两条对角线。 每条线用首字符作候选，逐格确认“非空且全部相同”；扫描行时顺便记录是否存在空位。

复杂度

行和列各访问 N² 个格子，对角线再访问 2N 个格子， 时间复杂度 O(N²)；只维护常数个变量，额外空间 O(1)。

完整过程

  1. 逐行检查同字符，并同时记录任意空格。
  2. 若行无赢家，逐列做同样的一致性检查。
  3. 检查主对角线和副对角线。
  4. 仍无赢家时，有空位返回 Pending，否则返回 Draw。

边界

  • N = 1 时，["O"] 直接返回 O。
  • 首格为空时，该线路不能获胜，但仍要继续记录空位。
  • 满盘不等于 Draw：必须先完成所有胜负检查。

替代方案

  • 把 O 记为 +1、X 记为 -1，维护行列计数；代码短，但需要 O(N) 额外空间。
  • 若已知最后一步坐标，只检查对应行、列和对角线，可把单次判断降到 O(N)。

面试追问

  • 多次调用 hasWon：落子时增量维护行、列、对角线计数，可 O(1) 更新与查询。
  • 若胜利条件改为连续 K 子：按四个方向维护连续段，而不是只看整条边长 N。

常见错误

  • 只检查行列，漏掉两条对角线之一。
  • 遇到空格立即返回 Pending，错过后续已经形成的胜线。
  • 用 trim() 处理棋盘字符串，意外删除合法空位。

为什么推荐直接扫描

题目只要求对一张最终棋盘判定一次。直接枚举所有合法胜线，证明路径最短、空间最省， 也最容易在面试现场口述正确性。

class Solution {
    public String tictactoe(String[] board) {
        int n = board.length;
        boolean hasSpace = false;

        for (int row = 0; row < n; row++) {
            char first = board[row].charAt(0);
            boolean same = first != ' ';
            for (int col = 0; col < n; col++) {
                char cell = board[row].charAt(col);
                if (cell == ' ') hasSpace = true;
                if (cell != first) same = false;
            }
            if (same) return String.valueOf(first);
        }

        for (int col = 0; col < n; col++) {
            char first = board[0].charAt(col);
            boolean same = first != ' ';
            for (int row = 1; row < n; row++) {
                if (board[row].charAt(col) != first) same = false;
            }
            if (same) return String.valueOf(first);
        }

        char main = board[0].charAt(0);
        boolean sameMain = main != ' ';
        char anti = board[0].charAt(n - 1);
        boolean sameAnti = anti != ' ';
        for (int i = 1; i < n; i++) {
            if (board[i].charAt(i) != main) sameMain = false;
            if (board[i].charAt(n - 1 - i) != anti) sameAnti = false;
        }
        if (sameMain) return String.valueOf(main);
        if (sameAnti) return String.valueOf(anti);
        return hasSpace ? "Pending" : "Draw";
    }
}

        has_space = False

        for row in range(n):
            first = board[row][0]
            same = first != " "
            for col in range(n):
                if board[row][col] == " ":

                if board[row][col] != first:
                    same = False
            if same:
                return first

        for col in range(n):
            first = board[0][col]
            same = first != " "
            for row in range(1, n):
                if board[row][col] != first:
                    same = False
            if same:
                return first

        main, anti = board[0][0], board[0][n - 1]
        same_main = main != " "
        same_anti = anti != " "
        for i in range(1, n):
            if board[i][i] != main:
                same_main = False
            if board[i][n - 1 - i] != anti:
                same_anti = False
        if same_main:
            return main
        if same_anti:
            return anti
        return "Pending" if has_space else "Draw"
