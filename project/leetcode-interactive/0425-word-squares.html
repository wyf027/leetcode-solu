单词方块

让每一行也成为对应的每一列。你要从同一份单词集合中，找出所有满足镜像读取关系的方阵。

01 / Problem

题意与输入边界

给你一个由互不相同、等长的小写英文单词组成的数组 words。请返回能用这些单词构成的全部单词方块；集合中的同一个单词可以在一个方块里重复使用，答案顺序任意。

若一个单词序列构成边长为 n 的方块，则对任意 0 ≤ r,c < n，都必须有 square[r][c] = square[c][r]。换句话说，第 k 行与第 k 列读出的字符串相同。

示例 1

Inputwords = ["area","lead","wall","lady","ball"]
Output[["ball","area","lead","lady"], ["wall","area","lead","lady"]]
Why

两个结果逐行读取与逐列读取一致；两个方块的返回顺序可以互换。

示例 2

Inputwords = ["abat","baba","atan","atal"]
Output[["baba","abat","baba","atal"], ["baba","abat","baba","atan"]]
Why

最后一行分别选择 atal 或 atan，都会保持行列一致。

约束

  • 1 ≤ words.length ≤ 1000
  • 1 ≤ words[i].length ≤ 4
  • 所有 words[i] 长度相同
  • 每个单词只含小写英文字母，且互不相同

前缀索引 + 回溯

核心洞察：当方块已有 k 行时，第 k 行并非任意选择。它的前 k 个字符已经由现有各行的第 k 个字符唯一确定，即 square[0][k]…square[k-1][k]。只搜索拥有这个前缀的单词，就能大幅剪枝。
01

先建前缀索引

把每个单词的所有前缀映射到以该前缀开头的单词列表；空前缀对应全部单词。

02

按行补齐

深度 k 就是在选择第 k 行。根据已选行提取必需前缀，再枚举索引中的候选。

03

到边长即收集

所有单词长度均为 n。路径达到 n 行时，行列约束已经全部满足，复制路径作为答案。

完整过程

  1. 令 n = words[0].length，为每个单词登记长度从 0 到 n 的全部前缀。
  2. 从空路径开始回溯。设当前路径长度为 k，依次读取 square[i][k]（0 ≤ i < k），拼成下一行需要的前缀。
  3. 只枚举前缀索引返回的候选，把候选加入路径并递归；返回后移除它，继续尝试同层其他候选。
  4. 路径长度等于 n 时记录答案。题目允许重复使用单词，因此不需要 used 集合。

正确性证明

  • 不变式：进入深度 k 时，当前 k 行之间的所有已确定对称位置都相等。初始空路径显然成立。
  • 保持：算法构造前缀 p[i] = square[i][k]。任何选中的候选 w 都满足 w[i] = p[i] = square[i][k]，因此新增位置 (k,i) 与 (i,k) 相等，原有位置不变，不变式继续成立。
  • 完备：任意合法单词方块在深度 k 的第 k 行必然拥有算法构造的前缀，所以该行一定在候选列表中；回溯会枚举它。由归纳可知，每个合法方块都能被访问。
  • 终止与可靠性：深度每次增加一，达到 n 即停止。此时不变式覆盖全部坐标，因此收集到的每个结果都是合法单词方块。

复杂度

设单词数为 W、统一长度为 L，搜索实际访问的部分路径数为 S。构建字符串前缀索引在常见切片语义下为 O(W·L²) 时间与字符存储；若以 Trie 节点保存候选引用，则结构本身可按 O(W·L) 计。每个搜索状态构造必需前缀需 O(L)，因此回溯主体可输出敏感地写成 O(S·L + E)，其中 E 是实际枚举的候选边数。极端情况下候选几乎不被剪枝，会呈指数增长（粗略上界 O(W^L·L)）。

递归路径占 O(L²) 个字符；除此之外是前缀索引及返回答案所占空间。输出本身不可省略。

边界与常见错误

误加去重集合

输入单词互异，不代表构造时不可复用。题目明确允许同一个单词出现多次。

前缀方向写反

第 k 行前缀来自每个已有行的第 k 列：square[i][k]，不是 square[k][i]。

只检查完整方块

枚举所有 W^L 组合后再验证会丢失剪枝优势；约束应在加入每一行之前使用。

忘记复制路径

答案中要保存路径快照；直接保存同一个可变列表会在回溯时被后续修改。

长度为 1

每个单字符单词都能单独构成一个 1 × 1 方块，通用回溯无需特判。

结果顺序

方块之间的顺序不限；比较测试结果时应按集合语义处理，但方块内部行顺序不能改变。

替代方案

Trie：沿必需前缀逐字符走到对应节点，再读取节点保存的候选单词索引。它避免显式保存前缀字符串键，适合更长单词或更大的词表。

哈希前缀表：本页代码采用这一版，长度最多为 4 时更短、更直观，查询平均为常数级加前缀构造成本。

暴力组合：枚举长度为 L 的所有单词序列再检查对称性，概念简单但最坏需要 W^L 个组合，无法利用部分路径已经失败的信息。

四语言完整实现

统一使用“所有前缀 → 候选单词”的索引；方法签名对应 wordSquares(words)。

Solution.javaPrefix map + DFS
import java.util.*;

class Solution {
    private Map<String, List<String>> prefixMap;
    private List<List<String>> answer;
    private int size;

    public List<List<String>> wordSquares(String[] words) {
        size = words[0].length();
        prefixMap = new HashMap<>();
        answer = new ArrayList<>();

        for (String word : words) {
            for (int len = 0; len <= size; len++) {
                String prefix = word.substring(0, len);
                prefixMap.computeIfAbsent(prefix, key -> new ArrayList<>())
                         .add(word);
            }
        }

        backtrack(new ArrayList<>());
        return answer;
    }

    private void backtrack(List<String> square) {
        int row = square.size();
        if (row == size) {
            answer.add(new ArrayList<>(square));
            return;
        }

        StringBuilder prefix = new StringBuilder();
        for (String chosen : square) {
            prefix.append(chosen.charAt(row));
        }

        for (String candidate :
                prefixMap.getOrDefault(prefix.toString(), Collections.emptyList())) {
            square.add(candidate);
            backtrack(square);
            square.remove(square.size() - 1);
        }
    }
}
solution.jsPrefix map + DFS
/**
 * @param {string[]} words
 * @return {string[][]}
 */
var wordSquares = function(words) {
    const size = words[0].length;
    const prefixMap = new Map();
    const answer = [];

    for (const word of words) {
        for (let len = 0; len <= size; len++) {
            const prefix = word.slice(0, len);
            if (!prefixMap.has(prefix)) {
                prefixMap.set(prefix, []);
            }
            prefixMap.get(prefix).push(word);
        }
    }

    const square = [];

    function backtrack() {
        const row = square.length;
        if (row === size) {
            answer.push([...square]);
            return;
        }

        let prefix = "";
        for (const chosen of square) {
            prefix += chosen[row];
        }

        for (const candidate of prefixMap.get(prefix) ?? []) {
            square.push(candidate);
            backtrack();
            square.pop();
        }
    }

    backtrack();
    return answer;
};
solution.pyPrefix map + DFS
from collections import defaultdict
from typing import List


class Solution:
    def wordSquares(self, words: List[str]) -> List[List[str]]:
        size = len(words[0])
        prefix_map = defaultdict(list)

        for word in words:
            for length in range(size + 1):
                prefix_map[word[:length]].append(word)

        answer: List[List[str]] = []
        square: List[str] = []

        def backtrack() -> None:
            row = len(square)
            if row == size:
                answer.append(square.copy())
                return

            prefix = "".join(chosen[row] for chosen in square)
            for candidate in prefix_map.get(prefix, []):
                square.append(candidate)
                backtrack()
                square.pop()

        backtrack()
        return answer
solution.cppPrefix map + DFS
#include <bits/stdc++.h>
using namespace std;

class Solution {
private:
    unordered_map<string, vector<string>> prefixMap;
    vector<vector<string>> answer;
    int size = 0;

    void backtrack(vector<string>& square) {
        int row = static_cast<int>(square.size());
        if (row == size) {
            answer.push_back(square);
            return;
        }

        string prefix;
        prefix.reserve(row);
        for (const string& chosen : square) {
            prefix.push_back(chosen[row]);
        }

        auto it = prefixMap.find(prefix);
        if (it == prefixMap.end()) {
            return;
        }

        for (const string& candidate : it->second) {
            square.push_back(candidate);
            backtrack(square);
            square.pop_back();
        }
    }

public:
    vector<vector<string>> wordSquares(vector<string>& words) {
        size = static_cast<int>(words[0].size());
        prefixMap.clear();
        answer.clear();

        for (const string& word : words) {
            for (int len = 0; len <= size; ++len) {
                prefixMap[word.substr(0, len)].push_back(word);
            }
        }

        vector<string> square;
        backtrack(square);
        return answer;
    }
};

面试追问

如果单词长度提升到几十？

优先使用 Trie，并在节点保存候选索引；还可按首字符分桶，减少根节点候选。

如果单词不等长？

这会变成单词矩形或更一般的约束搜索，需要先明确行数、列数及横纵词典，当前不变式要随之调整。

如何避免存储所有前缀字符串？

用 Trie 共享公共前缀字符；节点只保留经过它的单词下标列表。

可以并行吗？

可以按第一行拆分独立搜索任务，最后合并结果；每个任务使用自己的回溯路径，前缀索引只读共享。
