LCR 085 · MEDIUM

括号生成

生成 n 对合法括号的所有组合。

题意

给定 n，返回所有由 n 对括号组成的有效括号组合。任意前缀中右括号数量都不能超过左括号数量。

示例

n = 3

["((()))","(()())","(())()","()(())","()()()"]

约束

1 ≤ n ≤ 8；返回所有合法方案。

分步交互

先选择下一步规则，再展开题解。

题解：回溯剪枝

洞察

状态只需记录已放入的左右括号数；非法前缀可在搜索中直接剪掉。

过程
  1. 左括号未满时加入左括号。
  2. 右括号少于左括号时加入右括号。
  3. 长度达到 2n 时收集答案。
边界

不能让 right 超过 left；n 对全部用完才是完整方案。

复杂度

输出敏感，时间 O(Cn)，额外递归空间 O(n)。

替代方案：暴力枚举再校验会产生大量无效字符串。
常见错误：允许右括号数超过左括号数。
追问：如何求第 k 个合法组合？

// Java
class Solution { List<String> ans=new ArrayList<>(); public List<String> generateParenthesis(int n){dfs("",0,0,n);return ans;} void dfs(String s,int l,int r,int n){if(s.length()==2*n){ans.add(s);return;}if(l<n)dfs(s+"(",l+1,r,n);if(r<l)dfs(s+")",l,r+1,n);} }

# Python
class Solution:
 def generateParenthesis(self,n:int)->List[str]:
  ans=[]
  def dfs(s,l,r):
   if len(s)==2*n: ans.append(s); return
   if l<n: dfs(s+'(',l+1,r)
   if r<l: dfs(s+')',l,r+1)
  dfs('',0,0); return ans
