丑数

只含质因数 2、3 和/或 5 的正整数称为丑数，1 也是丑数。给定 n，返回第 n 个丑数。

正整数质因数 2 / 3 / 51 ≤ n ≤ 1690

题意与示例

丑数是只包含质因数 2、3 和/或 5 的正整数，1 也是丑数。给定 n，返回第 n 个丑数。 

n = 10
输出 = 12
前 10 个：1, 2, 3, 4, 5, 6, 8, 9, 10, 12

约束：1 <= n <= 1690。

题解：三指针 DP 合并三个有序流

核心洞察

已生成的丑数序列递增。下一个新丑数一定是某个已生成数乘 2、3 或 5；三个指针分别指向“尚未产出过的最小 2/3/5 倍候选”。取三者最小值，并让所有等于它的候选指针前进。

完整过程

  1. dp[0] = 1，三个指针都从 0 开始。
  2. 计算 dp[p2]×2、dp[p3]×3、dp[p5]×5，取最小者写入下一个格。
  3. 任一候选等于新值，其指针都加 1；循环到第 n 项。

边界与复杂度

n = 1 直接得到 1。由于上限为 1690，最终答案为 2123366400，使用 Java int、JavaScript Number 均安全。时间 O(n)，DP 数组 O(n)。

替代方案、追问与常见错误

最小堆 + 集合也能生成，但多了 O(n log n) 和去重开销。追问：若乘数集合可变，可为每个质因数维护指针。常见错误：只移动一个最小指针，导致 6、10、15 等重复；或把 1 排除在丑数外。

class Solution {
    public int nthUglyNumber(int n) {
        int[] dp = new int[n]; dp[0] = 1;
        int p2 = 0, p3 = 0, p5 = 0;
        for (int i = 1; i < n; i++) {
            int next = Math.min(dp[p2] * 2, Math.min(dp[p3] * 3, dp[p5] * 5));
            dp[i] = next;
            if (next == dp[p2] * 2) p2++;
            if (next == dp[p3] * 3) p3++;
            if (next == dp[p5] * 5) p5++;
        }
        return dp[n - 1];
    }
}
