题解：按位数块减法定位

核心洞察

先单独处理 0–9 这 10 位。此后 d 位正整数有 9×10^(d−1) 个，整块长度为 d×9×10^(d−1)。不断减去完整块，直到 k 落入目标块；再用除法和取模定位具体数字及数字内偏移。

完整过程

  1. 若 k<10，直接返回 k；否则先减去 0–9 占据的 10 位。
  2. 从 d=2、count=90、start=10 开始；只要 k 大于等于 d×count，减去该块并进入下一块。
  3. 目标数字为 start + k/d，返回它的字符串第 k%d 位。

边界与复杂度

k=0 返回 0；块边界如 k=9 是 9、k=10 是 1（数字 10 的首位）。只有约 10 次块跳跃，时间 O(log₁₀k)、空间 O(1)。

替代方案、面试追问与常见错误

  • 替代方案：逐个拼接整数可作为小范围对拍基准，但 k 很大时会超时并耗费线性空间。
  • 面试追问：可以对位数块的前缀长度做二分查找，不过块数仅约 10，逐块跳过更直接。
  • 常见错误：把 k 当成 1 基、漏掉 0–9 的 10 位，或计算块长度时忘记乘位数 d。

class Solution {
    public int findKthNumber(int k) {
        if (k < 10) return k;
        k -= 10;
        long digits = 2, count = 90, start = 10;
        while (k >= digits * count) { k -= digits * count; digits++; count *= 10; start *= 10; }
        long number = start + k / digits;
        return String.valueOf(number).charAt((int)(k % digits)) - '0';
    }
}
var findKthNumber = function (k) {
  if (k < 10) return k;

  let digits = 2, count = 90, start = 10;
  while (k >= digits * count) { k -= digits * count; digits++; count *= 10; start *= 10; }
  const number = start + Math.floor(k / digits);
  return Number(String(number)[k % digits]);
