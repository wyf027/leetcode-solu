可被三整除的偶数的平均值

Average Value of Even Numbers That Are Divisible by Three

从一组数字中找到符合条件的成员，再计算它们的平均值。

01 / 题目

给定正整数数组 nums，只选择其中同时满足“是偶数”和“能被 3 整除”的元素，返回这些元素平均值向下取整后的整数。如果没有符合条件的元素，返回 0。相同数值出现在不同位置时，每次出现都要计入。

参数：nums（整数数组） · 返回值：整数 · 方法名：averageValue

官方示例 1

输入：nums = [1,3,6,10,12,15]
输出：9

符合条件的是 6 和 12，平均值为 (6 + 12) / 2 = 9。

官方示例 2

输入：nums = [1,2,4,7,10]
输出：0

没有元素同时满足两个条件，因此返回 0。

约束

  • 1 <= nums.length <= 1000
  • 1 <= nums[i] <= 1000

04 / 独立题解

准备好后，再展开核心思路与四语言代码。

一次遍历，维护总和与数量

核心洞察

2 和 3 互质，它们的最小公倍数是 6。因此，“是偶数且可被 3 整除”等价于 x % 6 == 0。平均值只依赖合格元素的总和与个数，不必保存它们。

完整过程

  1. 初始化 sum = 0、count = 0。
  2. 依次读取每个 x；若 x 能被 6 整除，则把 x 加入 sum，并将 count 加 1。
  3. 遍历结束后，若 count 为 0，返回 0；否则返回 sum / count 向下取整。

示例 1：1、3 被跳过；6 使 (sum, count) 变为 (6, 1)；10 被跳过；12 使状态变为 (18, 2)；15 被跳过。最终返回 18 / 2 = 9。

正确性说明

循环不变式：处理完前 k 个元素后，sum 等于这 k 个元素中所有合格值之和，count 等于其出现次数。初始没有处理元素，两者为 0，成立。处理下一个元素时，合格就同时更新总和与数量，不合格就保持不变，因此不变式继续成立。循环结束覆盖整个数组：count 为 0 时按题意返回 0；否则对准确的总和与数量做除法并向下取整，得到所求结果。

边界与数值安全

  • 没有命中时，必须在除法前判断 count，避免除零。
  • 数组只有一项时：合格则返回该值，否则返回 0。
  • 重复值按出现次数累计，不能去重。
  • 平均值不一定为整数，例如 [6,6,6,12] 得到 7.5，返回 7。
  • 总和不超过 1000 × 1000 = 1,000,000，四种语言的这里所用数值类型都足够。
  • 题目只有正整数；Java/C++ 的正整数除法截断与向下取整一致。

复杂度

设 n 为 nums 的长度。时间复杂度 O(n)，每个元素只访问一次；额外空间复杂度 O(1)，只维护两个计数变量。演示界面保存的列表和状态不属于提交算法。

替代方案

直接判断 x % 2 == 0 && x % 3 == 0 也正确，复杂度相同。先 filter 得到合格数组再求和可读性不错，但通常需要 O(n) 额外空间；本题无需排序或建立集合。

Java

class Solution {
    public int averageValue(int[] nums) {
        int sum = 0, count = 0;
        for (int x : nums) {
            if (x % 6 == 0) {
                sum += x;
                count++;
            }
        }
        return count == 0 ? 0 : sum / count;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @return {number}
 */
var averageValue = function(nums) {
    let sum = 0, count = 0;
    for (const x of nums) {
        if (x % 6 === 0) {
            sum += x;
            count++;
        }
    }
    return count === 0 ? 0 : Math.floor(sum / count);
};

Python 3

from typing import List

class Solution:
    def averageValue(self, nums: List[int]) -> int:
        total = count = 0
        for x in nums:
            if x % 6 == 0:
                total += x
                count += 1
        return total // count if count else 0

C++

#include <vector>
using namespace std;

class Solution {
public:
    int averageValue(vector<int>& nums) {
        int sum = 0, count = 0;
        for (int x : nums) {
            if (x % 6 == 0) {
                sum += x;
                ++count;
            }
        }
        return count == 0 ? 0 : sum / count;
    }
};

常见错误

  • 用“或”连接两个条件，会误选 2 或 3。
  • 用 nums.length 作为分母，把不合格元素计入了数量。
  • 使用四舍五入，或忘记对 JavaScript 的除法结果向下取整。
  • 先把每项分别整除再相加，会丢失精度；应先求和，再统一除法。
  • 把当前平均值与新值简单取平均，忽略已有元素数量。

面试追问

若要求同时被 a 和 b 整除？用它们的最小公倍数筛选；扩大范围时需考虑求最小公倍数的溢出。

数据以流的形式到来？继续维护 sum 和 count，无需保留历史元素。

若允许负数？筛选条件不变，但 Java/C++ 整数除法向零截断，需额外实现向下取整；Python // 与 JavaScript Math.floor 可直接表达向下取整。

能不能提前返回？一般不能，剩余的任意元素都可能符合条件并改变最终平均值。
