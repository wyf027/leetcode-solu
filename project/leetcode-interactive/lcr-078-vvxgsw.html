合并 K 个升序链表

把 k 条已排序链表接成一条仍然有序的链表：每一轮只从所有“当前头节点”中取最小值。

开始演示

题意

给定一个链表数组 lists，其中每条链表都按升序排列。请把所有链表合并成一条升序链表并返回头节点。

示例

输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：每次接入所有链表当前节点中的最小值。

约束

  • k == lists.length
  • 0 <= k <= 10^4
  • 0 <= lists[i].length <= 500
  • 节点值范围为 -10^4 到 10^4，且各链表升序排列。

核心洞察

每条有序链表只有头节点可能成为全局下一个最小值。用最小堆保存至多 k 个候选节点，弹出最小节点后，仅把它的 next 放回堆。

不变量：堆始终包含每条尚未耗尽链表的最前节点；因此堆顶一定是合并结果的下一个节点。

      完整过程

      1. 建立虚拟头节点 dummy 和最小堆。
      2. 把每条非空链表的头节点放入堆；堆的比较键是节点值。
      3. 重复弹出堆顶，把它接到 tail 后；这一步保证输出仍然升序。
      4. 若弹出节点有后继，把后继压入堆；最后返回 dummy.next。

      边界

      • lists 为空或所有链表都为空时，直接返回 null。
      • 节点值可以相同；只要比较器允许相等，任意稳定次序都是正确答案。
      • 不要新建每个数据节点；复用原节点能保持 O(1) 除堆外额外节点空间。

      复杂度

      设总节点数为 N。每个节点入堆、出堆各一次，时间 O(N log k)；堆最多保存 k 个节点，空间 O(k)。

      替代方案

      分治两两合并：每一轮把 k 条链表减半，和归并排序一样总时间也是 O(N log k)，不需要优先队列。

      官方签名代码

      class Solution {
  public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode node : lists) if (node != null) pq.offer(node);
    ListNode dummy = new ListNode(), tail = dummy;
    while (!pq.isEmpty()) { ListNode node = pq.poll(); tail.next = node; tail = tail.next; if (node.next != null) pq.offer(node.next); }
    return dummy.next;
  }
}
      var mergeKLists = function(lists) {
  const heap = [];
  const push = node => { heap.push(node); let i = heap.length - 1; while (i > 0) { const p = (i - 1) >> 1; if (heap[p].val <= node.val) break; heap[i] = heap[p]; i = p; } heap[i] = node; };
  const pop = () => { const top = heap[0], last = heap.pop(); if (heap.length) { let i = 0; while (i * 2 + 1 < heap.length) { let c = i * 2 + 1; if (c + 1 < heap.length && heap[c + 1].val < heap[c].val) c++; if (heap[c].val >= last.val) break; heap[i] = heap[c]; i = c; } heap[i] = last; } return top; };
  for (const node of lists) if (node) push(node);
  const dummy = new ListNode(0); let tail = dummy;
  while (heap.length) { const node = pop(); tail.next = node; tail = node; if (node.next) push(node.next); }
  return dummy.next;
};

      追问与常见错误

      追问

      若内存紧张且 k 很大？分治合并避免堆比较器开销；若链表是流式到达，则最小堆更自然。

      常见错误

      • 把 null 头节点压入堆。
      • 弹出节点后忘记压入它的 next。
      • Java 用 a.val - b.val 在更大数值范围下可能溢出，应改用 Integer.compare。

      测试与验证区

      覆盖空数组、全空链表、单条链表、重复值、负数以及长度差异极大的链表。每次测试后确认输出单调非降且节点总数不变。
