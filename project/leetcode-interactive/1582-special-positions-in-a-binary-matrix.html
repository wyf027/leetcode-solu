01 · Brief

题目说明

下标从 0 开始。重点在“当前元素为 1”以及它所在行、列的其余位置。

任务

给定一个 m × n 的二进制矩阵 mat，返回其中特殊位置的数量。

位置 (i, j) 是特殊位置，当且仅当：

  • mat[i][j] == 1；
  • 第 i 行除它之外的元素全为 0；
  • 第 j 列除它之外的元素全为 0。
参数形式：numSpecial(mat: integer[][]) → integer

约束

  • m == mat.length
  • n == mat[i].length
  • 1 <= m, n <= 100
  • mat[i][j] 只能是 0 或 1

官方示例 1

输出 1
输入：mat = [[1,0,0],[0,0,1],[1,0,0]] 输出：1

位置 (1, 2) 为特殊位置：该处是 1，且对应行、列中的其他元素均为 0。

官方示例 2

输出 3
输入：mat = [[1,0,0],[0,1,0],[0,0,1]] 输出：3

主对角线上的 (0,0)、(1,1)、(2,2) 都满足条件。

Solution · Counting

题解：先统计，再筛选

O(mn) 时间

核心洞察

一个值为 1 的位置 (i,j) 是否特殊，只取决于两个数字：第 i 行有多少个 1，以及第 j 列有多少个 1。若两者都恰好为 1，那么这唯一的 1 就是当前位置本身。

mat[i][j] == 1 && rowCount[i] == 1 && colCount[j] == 1
1

完整过程

  1. 建立长度为 m 的行计数数组和长度为 n 的列计数数组。
  2. 第一次遍历矩阵；遇到 1，就把对应行计数与列计数各加一。
  3. 第二次遍历矩阵；对每个 1 检查所在行、列计数是否都等于 1。
  4. 满足条件就累加答案，最后返回。
2

边界情况

  • 单元素矩阵：[[1]] 返回 1，[[0]] 返回 0。
  • 全零：没有候选位置，答案为 0。
  • 同一行多个 1：该行所有 1 都不可能特殊。
  • 同一列多个 1：该列所有 1 都不可能特殊。
  • 非方阵：行数和列数分别处理，不可混用。

正确性证明

  1. 统计准确：第一次遍历遇到每个 1 时，恰好给它所属的行与列各计数一次，因此 rowCount 和 colCount 分别准确记录每行、每列的 1 的总数。
  2. 不会误收：若算法计入 (i,j)，则该处为 1，且行计数和列计数均为 1。因为当前位置已经占据这唯一一次，所以同行、同列的其他位置必全为 0；它确实特殊。
  3. 不会漏收：若 (i,j) 是特殊位置，定义保证它是 1，且所在行、列都没有其他 1。因此两项计数都等于 1，第二次遍历一定会将它计入。
  4. 结论：算法计入的位置集合与所有特殊位置的集合完全相同，返回数量正确。

复杂度

设矩阵有 m 行、n 列。两次完整扫描均为 O(mn)，总时间复杂度仍是 O(mn)；两个计数数组占用 O(m+n) 额外空间。

替代方案

可以对每个 1 现场扫描整行与整列，额外空间降为 O(1)，但最坏时间会升到 O(mn(m+n))。也可原地复用矩阵首行/首列存计数，不过会修改输入、分支更多，在本题规模下可读性收益不高。

四种语言实现

均使用相同的两次扫描策略，签名与官方提交形式一致。

Java LeetCode 
class Solution {
    public int numSpecial(int[][] mat) {
        int m = mat.length;
        int n = mat[0].length;
        int[] rowCount = new int[m];
        int[] colCount = new int[n];

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (mat[i][j] == 1) {
                    rowCount[i]++;
                    colCount[j]++;
                }
            }
        }

        int answer = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (mat[i][j] == 1 && rowCount[i] == 1 && colCount[j] == 1) {
                    answer++;
                }
            }
        }
        return answer;
    }
}

常见错误

  • 只检查行唯一，却忘记检查列。
  • 把计数条件写成 <= 1，但没有先确认当前位置是 1。
  • 列计数数组误用行数初始化，非方阵时越界或算错。
  • 发现某行有多个 1 就提前修改矩阵，破坏后续列判断。
  • 把“其余元素为 0”误解成整行、整列的和为 0；实际总和应为 1。

面试追问

能否一次扫描？

若要立刻判定通常不行，因为右侧或下方尚未读取；可以一次收集计数与候选，再只复查候选。

能否降低空间？

可以现场扫描行列换取更高时间，或修改输入来复用存储；需说明副作用。

若矩阵是稀疏的？

只遍历 1 的坐标并用映射计数，时间可与非零元素数量相关。

若数据流分块到达？

第一阶段聚合行列计数并保存 1 的坐标，结束后再过滤候选。
