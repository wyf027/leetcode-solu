设计最近使用（MRU）队列

Design Most Recently Used Queue

把“取出第 k 个元素并放到队尾”理解为一次位置迁移。先用交互过程建立直觉，再按需展开完整题解。

题目

实现 MRUQueue。初始化时，队列按顺序包含 1, 2, …, n。调用 fetch(k) 时，返回当前队列中从前往后第 k 个元素，并把该元素移动到队尾；其余元素保持相对顺序。

构造函数
MRUQueue(int n)
创建初始序列 [1, n]。
查询
int fetch(int k)
取第 k 个、移至末尾并返回它。

官方示例（完整参数形式）

输入：
["MRUQueue", "fetch", "fetch", "fetch", "fetch"]
[[8], [3], [5], [2], [8]]

输出：
[null, 3, 6, 2, 2]

过程：
MRUQueue(8) → [1, 2, 3, 4, 5, 6, 7, 8]
fetch(3)   → 返回 3，队列变为 [1, 2, 4, 5, 6, 7, 8, 3]

fetch(2)   → 返回 2，队列变为 [1, 4, 5, 7, 8, 3, 6, 2]
fetch(8)   → 返回 2，队列不变

约束

  • 1 ≤ k ≤ n
  • fetch 最多调用 2000 次。

题解：把移动改写成“删旧位 + 加新位”

核心洞察

元素无需在数组中真的整体搬动。为每次出现分配一个只增不减的“时间槽位”：初始元素占据槽位 1…n；取出元素后，把旧槽位置为未占用，再把同一个值放进最右侧的新槽位。树状数组只记录每个槽位是否被占用，因此能在 O(log(n+q)) 时间内找到当前第 k 个元素。

排名 → 槽位

树状数组二进制提升寻找第 k 个 1。

删除旧位置

对旧槽位执行 add(pos, -1)。

追加新位置

记录值并执行 add(++tail, +1)。

完整过程

  1. 预留 n + 2000 个槽位；初始化槽位 1…n 的占用值为 1，并保存对应数字。
  2. fetch(k) 用树状数组查找最小槽位 pos，使前缀占用数达到 k。
  3. 读取 value[pos]，在树状数组中删除旧槽位。
  4. 尾指针右移，在新槽位保存该值并标记占用，最后返回它。

正确性说明

不变式：所有占用槽位按槽位编号递增后，对应的值序列始终等于当前 MRU 队列。初始化显然成立。一次 fetch(k) 找到第 k 个占用槽位，删除它不会改变其他元素的相对顺序；随后在全部现有槽位右侧加入同一值，恰好把它放到队尾，所以不变式继续成立，返回值也正是调用前的第 k 个元素。由归纳法，所有操作均正确。

复杂度与边界

  • 构造：O(n log(n+q))；每次 fetch：O(log(n+q))；空间：O(n+q)，其中 q ≤ 2000。
  • n = 1 时，每次都是删除唯一元素再追加，逻辑队列不变。
  • k = n 时取到队尾；返回后队列顺序不变，但底层槽位仍会迁移。
  • 容量按题目最多 2000 次调用预留；若约束改变，应改为动态树或离线获知操作数。

替代方案

直接数组删除并追加最简单，每次 O(n)；平方根分块把序列拆为约 √n 个块，可做到每次约 O(√n)。树状数组实现更紧凑，渐进复杂度也更好，但依赖“操作次数上界可预留槽位”。

面试追问

  • 如果操作数无上界怎么办？可动态扩容并重建树状数组，或使用带子树大小的平衡树。
  • 为什么不能只用值到位置的映射？因为查询给的是动态排名 k，而不是元素值。
  • 若还要支持任意位置插入？应考虑隐式 Treap / Splay，以子树大小维护排名。

常见错误

  • 把第 k 个写成下标 k，遗漏 1-based 排名。
  • 找到槽位后忘记更新树状数组，导致同一槽位再次被计数。
  • 二进制提升返回的是“前缀和小于 k 的最大下标”，最终答案需再加 1。
  • 新槽位只写值却没有标记占用，或数组容量未覆盖全部调用。
Java
class MRUQueue {
    private final int[] bit;
    private final int[] values;
    private int tail;

    public MRUQueue(int n) {
        int capacity = n + 2000 + 2;
        bit = new int[capacity];
        values = new int[capacity];
        tail = n;
        for (int i = 1; i <= n; i++) {
            values[i] = i;
            add(i, 1);
        }
    }

    public int fetch(int k) {
        int pos = kth(k);
        int answer = values[pos];
        add(pos, -1);
        values[++tail] = answer;
        add(tail, 1);
        return answer;
    }

    private void add(int index, int delta) {
        for (int i = index; i < bit.length; i += i & -i) bit[i] += delta;
    }

    private int kth(int k) {
        int index = 0;
        int jump = Integer.highestOneBit(bit.length - 1);
        for (; jump != 0; jump >>= 1) {
            int next = index + jump;
            if (next < bit.length && bit[next] < k) {
                index = next;
                k -= bit[next];
            }
        }
        return index + 1;
    }
}

Python
class MRUQueue:
    def __init__(self, n: int):
        capacity = n + 2002
        self.bit = [0] * capacity
        self.values = [0] * capacity
        self.tail = n
        for i in range(1, n + 1):
            self.values[i] = i
            self._add(i, 1)

    def fetch(self, k: int) -> int:
        pos = self._kth(k)
        answer = self.values[pos]
        self._add(pos, -1)
        self.tail += 1
        self.values[self.tail] = answer
        self._add(self.tail, 1)
        return answer

    def _add(self, index: int, delta: int) -> None:
        while index < len(self.bit):
            self.bit[index] += delta
            index += index & -index

    def _kth(self, k: int) -> int:
        index = 0
        jump = 1 << ((len(self.bit) - 1).bit_length() - 1)
        while jump:
            nxt = index + jump
            if nxt < len(self.bit) and self.bit[nxt] < k:
                index = nxt
                k -= self.bit[nxt]
            jump >>= 1
        return index + 1
C++
class MRUQueue {
    vector<int> bit, values;
    int tail;

    void add(int index, int delta) {
        for (int i = index; i < (int)bit.size(); i += i & -i) bit[i] += delta;
    }

    int kth(int k) {
        int index = 0, jump = 1;
        while ((jump << 1) < (int)bit.size()) jump <<= 1;
        for (; jump; jump >>= 1) {
            int next = index + jump;
            if (next < (int)bit.size() && bit[next] < k) {
                index = next;
                k -= bit[next];
            }
        }
        return index + 1;
    }

public:
    MRUQueue(int n) : bit(n + 2002), values(n + 2002), tail(n) {
        for (int i = 1; i <= n; ++i) {
            values[i] = i;
            add(i, 1);
        }
    }

    int fetch(int k) {
        int pos = kth(k);
        int answer = values[pos];
        add(pos, -1);
        values[++tail] = answer;
        add(tail, 1);
        return answer;
    }
};
