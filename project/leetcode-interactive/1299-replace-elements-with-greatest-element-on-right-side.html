将每个元素替换为右侧最大元素

Replace Elements with Greatest Element on Right Side

简单数组非付费题
01

题目说明

先理解目标，再尝试从不同方向观察数组。

任务

给定整数数组 arr，把每个位置的值替换成它右侧所有元素中的最大值；最后一个位置右侧没有元素，因此替换为 -1。完成后返回数组。

函数形式：replaceElements(arr: integer[]) → integer[]

示例 1

输入：arr = [17,18,5,4,6,1]
输出：[18,6,6,6,1,-1]
解释：每个位置取其右侧最大值；末位改为 -1。

示例 2

输入：arr = [400]
输出：[-1]
解释：唯一元素右侧为空。

约束

  • ✓1 ≤ arr.length ≤ 10⁴
  • ✓1 ≤ arr[i] ≤ 10⁵

核心洞察

从右向左扫描时，在处理下标 i 之前，只需保存区间 arr[i+1…n-1] 的最大值。它正是要写入 arr[i] 的答案。

完整过程

  1. 令 rightMax = -1。
  2. 从末尾向左，先暂存当前位置原值。
  3. 把 rightMax 写入当前位置。
  4. 用原值更新 rightMax。

正确性

循环不变量：每轮开始时，rightMax 等于当前位置右侧所有原始元素的最大值。于是写入值正确；再将当前位置原值纳入最大值后，不变量对下一位置仍成立。末位开始时右侧为空，约定答案为 -1。因此全部位置均正确。

复杂度与边界

  • 时间：O(n)，每个元素访问一次。
  • 额外空间：O(1)，原地修改。
  • 单元素数组直接得到 [-1]。
  • 严格递增、严格递减和重复值都无需特殊分支。
1 · 暂存
保存当前原值
2 · 写入
填入右侧最大值
3 · 更新
纳入当前原值
4 · 左移
处理前一个位置

替代方案

可以预处理后缀最大值数组，再逐项写回，时间同为 O(n)，但需要 O(n) 额外空间。逐位置扫描右侧则是 O(n²)，在长度达到 10⁴ 时不理想。

常见错误

  • 先更新最大值再写入，误把当前元素算进“右侧”。
  • 覆盖当前值后才保存，丢失更新最大值所需的原值。
  • 忘记最后一个位置必须是 -1。

一句话记忆

“先写旧灯塔，再用原值点亮新灯塔。”顺序不可颠倒。

class Solution {
    public int[] replaceElements(int[] arr) {
        int rightMax = -1;
        for (int i = arr.length - 1; i >= 0; i--) {
            int current = arr[i];
            arr[i] = rightMax;
            rightMax = Math.max(rightMax, current);
        }
        return arr;
    }
}

class Solution:
    def replaceElements(self, arr: List[int]) -> List[int]:
        right_max = -1
        for i in range(len(arr) - 1, -1, -1):
            current = arr[i]
            arr[i] = right_max
            right_max = max(right_max, current)
        return arr
