尽可能使字符串相等

Get Equal Substrings Within Budget

两个对齐字符串，一笔有限预算。你能连续改动多长的一段？先读题、观察变化，再决定如何把搜索缩到一次扫描。

Problem

题目说明

函数：equalSubstring(s, t, maxCost)

给定两个长度相同的字符串 s、t 和整数预算 maxCost。把 s[i] 改为 t[i] 的开销，是两个字符 ASCII 码之差的绝对值 |s[i] - t[i]|。

请选择 s 的一个连续子字符串，并将它改成 t 中相同位置的子字符串。总开销不能超过预算，返回可完成转换的最大长度；若没有任何可行子字符串，返回 0。

  • 输入：两个等长小写字符串 + 非负预算
  • 代价：对应字符差值的绝对值
  • 目标：最长连续、总费用不超预算
Examples

官方示例

示例 1

输入：s = "abcd", t = "bcdf", maxCost = 3
输出：3

"abc" 可改为 "bcd"，费用恰好是 3。

示例 2

输入：s = "abcd", t = "cdef", maxCost = 3
输出：1

每个位置费用都是 2，预算只能容纳一个字符。

示例 3

输入：s = "abcd", t = "acde", maxCost = 0
输出：1

位置 0 的 a → a 费用为 0，所以答案仍为 1。

约束

  • 1 ≤ s.length ≤ 105
  • t.length == s.length
  • 0 ≤ maxCost ≤ 106
  • s、t 仅含小写英文字母

Solution

滑动窗口：把字符串题变成费用数组

核心洞察完整过程正确性边界与复杂度替代方案四语言代码面试追问与常见错误

核心洞察

先令 cost[i] = |s[i] - t[i]|。问题立即等价为：在一个非负整数数组中，寻找元素和不超过 maxCost 的最长连续子数组。

所有费用都非负，因此右端加入新元素后，窗口和只会增加；若超出预算，持续右移左端即可恢复合法。这个单调性正是滑动窗口成立的原因。

完整过程

  1. 初始化左端 left = 0、窗口费用 sum = 0、答案 best = 0。
  2. 让 right 从左到右扫描，把当前位置的转换费用加入 sum。
  3. 当 sum > maxCost，反复减去 left 位置的费用并令 left++。
  4. 窗口重新合法后，用 right - left + 1 更新最长长度。
扫描动作费用和调整合法窗口best
加入 0 (1)1无[0,0]1
加入 1 (1)2无[0,1]2
加入 2 (1)3无[0,2]3
加入 3 (2)5移除费用 1、1[2,3]3

正确性证明

引理 1：每轮收缩结束后，窗口 [left, right] 的费用不超过预算。因为循环只在超预算时执行，并一直删除左端非负费用，直到满足条件。

引理 2：固定右端 right 时，算法保留以它结尾的最长合法窗口。收缩停止时当前窗口合法；任何更小的左端都已在超预算状态下被排除，不可能合法。

定理：算法返回全局最长合法子字符串长度。每个右端都会被访问一次，并由引理 2 计算该右端下的最大合法长度；取所有这些长度的最大值，正是全局最优解。

边界与复杂度

  • maxCost = 0：只有费用为 0 的连续位置可保留。
  • 完全相同的字符串：所有费用为 0，答案是整个长度。
  • 单个字符费用超预算：加入后窗口可被收缩为空，本轮长度为 0。
  • 长度为 1：相同逻辑无需特殊分支。

时间复杂度：O(n)。左右指针各至多移动 n 次。
额外空间：O(1)，可在扫描时直接计算费用，无需保存数组。

替代方案

前缀和 + 二分答案：先求费用前缀和，再二分长度 len，检查是否存在费用不超预算的长度为 len 的区间。由于“某长度可行”对更短长度保持可行，可得到 O(n log n) 时间、O(n) 空间。

它是正确的通用思路，但本题费用非负、目标是连续区间，滑动窗口更直接且更优。

四语言完整代码

class Solution {
    public int equalSubstring(String s, String t, int maxCost) {
        int left = 0;
        int cost = 0;
        int best = 0;

        for (int right = 0; right < s.length(); right++) {
            cost += Math.abs(s.charAt(right) - t.charAt(right));

            while (cost > maxCost) {
                cost -= Math.abs(s.charAt(left) - t.charAt(left));
                left++;
            }

            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}

#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    int equalSubstring(string s, string t, int maxCost) {
        int left = 0;
        int cost = 0;
        int best = 0;

        for (int right = 0; right < static_cast<int>(s.size()); ++right) {
            cost += abs(s[right] - t[right]);

            while (cost > maxCost) {
                cost -= abs(s[left] - t[left]);
                ++left;
            }

            best = max(best, right - left + 1);
        }
        return best;
    }
};

面试追问与常见错误

为什么可以丢掉左端？

费用全为非负数。当前和已超预算时，继续保留旧左端并扩张右端只会更差，因此旧左端不可能参与任何以当前或更后位置为右端的合法窗口。

若费用允许负数呢？

滑动窗口的单调性会失效；删除左端未必降低总和，需要考虑前缀和、有序结构等不同方法。

错误：只收缩一次

新字符可能让费用超出很多，必须使用 while，而不是 if。

错误：按字母表环形距离

题目要求 ASCII 差的绝对值，a 到 z 的费用是 25，不是 1。

错误：更新答案时机

应在窗口恢复合法后更新，否则可能把超预算区间计入答案。

能否不建 cost 数组？

可以。右端加入和左端移除时即时计算差值，即可将额外空间降为常数。
