移动后的最大曼哈顿距离

把每个 _ 独立替换为 U、D、L 或 R；做完全部移动后，离原点最远能有多远？

题意

U/D/L/R 分别使纵/横坐标增减 1；_ 可以任选一个方向。返回最终位置到原点的最大 |x| + |y|。

示例：moves = "L_D_"，可把两个空位选成 L 与 D，终点为 (-3,-1)，答案是 4。

交互

只允许 U、D、L、R、_；空位显示为金色。

可见计算

水平：R = 0，L = 0，净值 0
垂直：U = 0，D = 0，净值 0

输入一个合法 moves 后计算。

完整题解

核心洞察

固定非空字符后，坐标为 x = R - L、y = U - D。曼哈顿距离是 |x| + |y|。每个 _ 都能选择朝当前最优象限的一个方向（例如 x≥0 时选 R，否则选 L；纵向同理），因此它必定把距离恰好增加 1。答案就是 |R-L| + |U-D| + count(_)。

完整过程与正确性

1. 扫描统计 R/L/U/D/_。
2. 已固定移动的最远距离为 |R-L|+|U-D|。
3. 任一个空位总能选到使其中一个绝对值增加 1 的方向，故上界可达；所有空位独立，累加即可。

边界、替代方案、常见错误

  • 全是 _：答案等于长度。
  • 不要模拟四的幂次替换；空位之间没有冲突。
  • 不要把“最大最终距离”误作“任意前缀距离”。
  • 枚举四个象限的线性表达式也正确，但比计数公式冗长。

复杂度：时间 O(n)，空间 O(1)。
