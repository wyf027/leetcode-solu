2095. 删除链表的中间节点

Delete the Middle Node of a Linked List

先理解删除的位置，再观察指针如何找到它。题解与动画默认收起。

官方题目 ↗
01 / PROBLEM

题意与输入输出

给定单链表的头节点 head，删除中间节点，返回修改后链表的头节点。下方数组只是链表的展示形式；函数接收和返回的都是链表节点引用。

长度为 n 时，要删除的节点下标是 ⌊n / 2⌋，下标从 0 开始。偶数长度有两个居中的节点，本题选择右边那个。

n = 1、2、3、4、5 时，对应删除的下标分别为 0、1、1、2、2。若只有一个节点，删除后返回空链表。

约束

  • 链表节点数：1 ≤ n ≤ 10⁵。
  • 每个节点的值：1 ≤ Node.val ≤ 10⁵。

官方示例

示例 1 · 奇数长度
输入：head = [1,3,4,7,1,2,6]
输出：[1,3,4,1,2,6]

n = 7，删除下标 3、值为 7 的节点，其他节点顺序不变。

示例 2 · 偶数长度
输入：head = [1,2,3,4]
输出：[1,2,4]

n = 4，删除下标 2、值为 3 的节点。

示例 3 · 两个节点
输入：head = [2,1]
输出：[2]

n = 2，删除下标 1、值为 1 的节点，头节点保留。

03 / SOLUTION

准备好看题解了吗？

可先想一想：如何定位要删除的节点，并让它的前一个节点跳过它？

题解 · 快慢指针与前驱重连

核心洞察：让 fast 每轮前进两步、slow 每轮前进一步。fast 无法再走两步时，slow 恰好位于下标 ⌊n / 2⌋。同时用 prev 记录 slow 的前驱，最后令 prev.next = slow.next。

完整过程

  1. 若 head.next 为空，只有一个节点，直接返回空引用。
  2. 令 slow、fast 都从 head 出发，prev 初始化为空。
  3. 当 fast 及 fast.next 均非空时，按顺序执行 prev = slow、slow = slow.next、fast = fast.next.next。
  4. 退出循环时，slow 是中间节点，prev 是它的前驱。将 prev.next 指向 slow.next。
  5. 返回原来的 head。除单节点情况外，头节点不变。

指针轨道 · 看见定位与断链

青色边框 = slow；紫色外框 = fast；文字标签 = prev。删除步骤会显示被跳过的原节点及新链路。

为什么正确
循环不变量：完成 k 轮后，slow 位于下标 k，fast 位于下标 2k（若到达 n 则为空）；k ≥ 1 时，prev 位于下标 k − 1。初始化 k = 0 成立，每轮的三次赋值维持这个关系。
若 n = 2m，完成 m 轮时 fast 为空；若 n = 2m + 1，完成 m 轮时 fast 位于尾节点，其 next 为空。两种情况都在 k = ⌊n / 2⌋ 时终止，所以 slow 指向题目规定的节点。
对 n ≥ 2，至少执行一轮，因此 prev 存在。把 prev.next 改为 slow.next，仅从头节点的可达路径中移除 slow，保留其余节点的相对顺序。n = 1 单独返回空引用也符合定义。


边界与常见错误
  • 单节点：没有 prev，必须提前处理，否则会对空引用赋值。
  • 偶数节点：本题选右中间节点，不能误用 ⌊(n − 1) / 2⌋。
  • 两个节点：slow 最终位于尾节点，prev.next 应变为空。
  • 重复值：删除的是节点位置，不是所有等于某个值的节点。
  • 循环守卫：先判断 fast，再判断 fast.next，防止空引用访问。
  • 前驱更新：prev = slow 必须发生在 slow 前进之前。
  • 修改引用：给 slow 变量赋新值不会修改链表，必须写 prev.next。


复杂度
时间 O(n)：循环约 n / 2 次，每次常数操作。额外空间 O(1)：仅使用三个节点引用，不复制节点。教学动画保存步骤和使用数组绘图，其空间开销不属于提交算法。

Java
/** LeetCode 提供 ListNode：int val; ListNode next; */
class Solution {
    public ListNode deleteMiddle(ListNode head) {
        if (head.next == null) return null;
        ListNode slow = head, fast = head, prev = null;
        while (fast != null && fast.next != null) {
            prev = slow;
            slow = slow.next;
            fast = fast.next.next;
        }
        prev.next = slow.next;
        return head;
    }
}

class Solution {
public:
    ListNode* deleteMiddle(ListNode* head) {
        if (head->next == nullptr) return nullptr;
        ListNode* slow = head;
        ListNode* fast = head;
        ListNode* prev = nullptr;
        while (fast != nullptr && fast->next != nullptr) {
            prev = slow;
            slow = slow->next;
            fast = fast->next->next;
        }
        prev->next = slow->next;
        return head;
    }
};

面试追问
  • 如果要求删除左中间节点？目标改为 ⌊(n − 1) / 2⌋；可将 fast 初始化为 head.next，并处理 prev 仍为空时删除头节点的情况。
  • 是否可以只给中间节点而不给 head？若该节点不是尾节点，可复制后继值并跳过后继，但实际移除的节点身份不同；若是尾节点，单链表中无法据此找到前驱。
  • 输入可能含环怎么办？本题按普通有限链表处理；若放宽为可能含环，需先检测并定义环上的“中间”语义。
  • 如果不能修改原链表？需创建新链表并跳过目标位置，额外空间变为 O(n)。
