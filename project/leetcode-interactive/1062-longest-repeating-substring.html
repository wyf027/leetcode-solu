最长重复子串的长度

Longest Repeating Substring · 找出同一个字符串中出现至少两次（允许重叠）的最长连续片段，并返回它的长度。

MEDIUM付费题二分答案滚动哈希

题目

给定只含小写英文字母的字符串 s，返回其中最长重复子串的长度。重复子串必须是连续字符；两次出现的位置可以互相重叠。若不存在重复子串，返回 0。

函数签名

longestRepeatingSubstring(s: string): integer

约束

  • 1 ≤ s.length ≤ 1500
  • s 仅由小写英文字母组成

官方示例形式

输入：s = "abcd" 输出：0 解释：没有出现两次的非空子串。
输入：s = "abbaba" 输出：2 解释："ab" 出现了两次。
输入：s = "aabcaabdaab" 输出：3 解释："aab" 出现了三次。
Interactive mechanism

二分长度 × 滚动窗口

观察固定长度的窗口如何扫描 abbaba，并用哈希桶寻找相同片段。

步骤 1 / 8
当前窗口发现重复

先动手推演，再揭开完整解法。

Solution

题解：对答案二分

核心洞察

若存在长度为 L 的重复子串，那么删去末尾字符后，一定存在长度为 L-1 的重复子串。这个单调性允许二分最大可行长度。

完整过程

  1. 二分候选长度 L。
  2. 用滚动哈希枚举所有长度为 L 的窗口。
  3. 同哈希值的候选再比较原字符串，排除碰撞。
  4. 若找到重复，提高下界；否则降低上界。
为什么要二次比较？ 哈希值相同不绝对代表字符串相同。保存起点并逐字符核对，可让答案不依赖“碰撞概率很低”的假设。

正确性

判定正确：检查长度 L 时，算法遍历每个该长度子串。若返回真，必有两个经逐字符核对后相同的窗口；若存在重复窗口，后出现者一定会与此前保存的同哈希候选相遇并被识别。

二分正确：可行长度集合是从 0 开始的连续区间；二分始终保留最大可行长度，终止时下界即答案。

边界

  • 长度 1：答案只能为 0。
  • 字符全不同：所有正长度均不可行。
  • 字符全相同：窗口允许重叠，答案为 n-1。
  • 哈希冲突：由二次比较处理。

复杂度

滚动更新哈希为 O(1)，二分约 log n 轮。通常时间 O(n log n)；计入冲突核对，最坏可退化。空间 O(n)。

替代方案

动态规划令 dp[i][j] 表示以两位置结尾的最长公共后缀，时间与空间均为 O(n²)（空间可压缩）；后缀数组相邻后缀的最大 LCP 也能求解，结构更复杂但理论稳定。

面试追问

  • 怎样用双哈希降低候选比较次数？
  • 怎样用后缀数组与 LCP 解决？
  • 若要求返回子串本身或所有起点，数据结构如何调整？

常见错误

  • 把“子串”写成可跳字符的“子序列”。
  • 错误禁止两个出现位置重叠。
  • 二分中点与边界更新不一致，导致死循环。
  • 只看单个哈希值却不处理碰撞。

四语言完整实现

class Solution {
    private String s;
    private long[] pow, pre;
    private final long MOD = 1_000_000_007L, BASE = 911382323L;
    public int longestRepeatingSubstring(String s) {
        this.s = s; int n = s.length(); pow = new long[n + 1]; pre = new long[n + 1]; pow[0] = 1;
        for (int i = 0; i < n; i++) { pow[i + 1] = pow[i] * BASE % MOD; pre[i + 1] = (pre[i] * BASE + s.charAt(i)) % MOD; }
        int lo = 0, hi = n - 1;
        while (lo < hi) { int mid = lo + (hi - lo + 1) / 2; if (has(mid)) lo = mid; else hi = mid - 1; }
        return lo;
    }
    private long hash(int l, int r) { return (pre[r] - pre[l] * pow[r-l] % MOD + MOD) % MOD; }
    private boolean has(int len) {
        java.util.Map<Long, java.util.List<Integer>> seen = new java.util.HashMap<>();
        for (int i = 0; i + len <= s.length(); i++) { long h = hash(i, i + len); for (int j : seen.getOrDefault(h, java.util.List.of())) if (s.regionMatches(i, s, j, len)) return true; seen.computeIfAbsent(h, k -> new java.util.ArrayList<>()).add(i); }
        return false;
    }
}
var longestRepeatingSubstring = function(s) {
  const has = len => {
    const seen = new Map();
    for (let i = 0; i + len <= s.length; i++) {
      const part = s.slice(i, i + len);
      if (seen.has(part)) return true;
      seen.set(part, i);
    }
    return false;
  };
  let lo = 0, hi = s.length - 1;
  while (lo < hi) {
    const mid = lo + Math.floor((hi - lo + 1) / 2);
    if (has(mid)) lo = mid; else hi = mid - 1;
  }
  return lo;
};

class Solution {
public:
    int longestRepeatingSubstring(string s) {
        auto has = [&](int len) {
            unordered_set<string> seen;
            for (int i = 0; i + len <= (int)s.size(); ++i) {
                string part = s.substr(i, len);
                if (seen.count(part)) return true;
                seen.insert(part);
            }
            return false;
        };
        int lo = 0, hi = (int)s.size() - 1;
        while (lo < hi) { int mid = lo + (hi - lo + 1) / 2; if (has(mid)) lo = mid; else hi = mid - 1; }
        return lo;
    }
};
