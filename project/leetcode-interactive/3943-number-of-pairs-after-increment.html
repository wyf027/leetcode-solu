递增后的数对数量

在 nums2 上做区间加；每次询问统计 nums1[j] + nums2[k] = tot 的有序数对数。

区间更新目标值频次查询分块 / sqrt decomposition

题意

给定 nums1、nums2 和查询。[1, x, y, val] 把 nums2[x..y] 每项加上 val；[2, tot] 返回所有满足目标和的 (j, k) 数量。

nums1.length ≤ 5枚举它很便宜。
nums2 / queries ≤ 5×10⁴不能逐项扫描整段。

示例：nums1 = [1, 2]，nums2 = [3, 4]，queries = [[2, 5], [1, 0, 0, 2], [2, 5]]，输出 [2, 1]。

题解：每块保存“真实值频次 + 懒加值”

把 nums2 分成约 √n 大小的块。整块更新只累加 lazy[b]；边界块先下推 lazy、逐元素修改，再重建频次表。查询目标 tot 时，枚举最多 5 个 a ∈ nums1，对每块累加 freq[b][tot - a - lazy[b]]。

  1. 初始化每块的频次 map，元素实际值先不含 lazy。
  2. 区间加：中间完整块 O(√n) 改 lazy，至多两个边界块重建。
  3. 目标和查询：对每个 a 遍历所有块，查频次键 tot-a-lazy。
时间单次更新 O(√n)，单次计数 O(|nums1|·√n)。
空间O(n)，所有块的频次总和不超过元素数。

边界与替代方案

注意目标值可达 10⁹，频次 map 的键必须是整数；答案最大约 2.5×10⁵，JavaScript number 安全。若只有点更新，可维护全局频次；若 nums1 很大，需要改用更强的数据结构。

面试追问与常见错误

追问：若查询改为区间查询，可在块内维护更多统计。常见错误：完整块更新后忘记在查询时减 lazy；边界块修改后不重建频次；把 query type 2 当成修改操作。
