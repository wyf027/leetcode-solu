包含所有前缀的最长单词

Longest Word With All Prefixes

一个单词能走多远，取决于它之前的每一步是否都存在。

01 / THE CHALLENGE

题目与约定

给定字符串数组 words，从中挑出一个单词：从首字母开始、逐次增加一个字母得到的每个非空前缀，都必须也是数组中的完整单词。返回符合条件的最长单词；如果长度并列，返回字典序最小的那个。没有符合条件的单词时，返回空字符串 ""。

前缀必须从第一个字符开始且连续。单词自身已在数组中；长度为 1 的单词自然符合要求，不需要数组包含空字符串。

longestWord(words: string[]) → string

官方示例 1

输入：words = ["k","ki","kir","kira","kiran"]
输出："kiran"

由 k 到 kiran 的每一层都能在输入中找到。

官方示例 2

输入：words = ["a","banana","app","appl","ap","apply","apple"]
输出："apple"

apple 和 apply 都符合条件且同长；apple 的字典序更小。

官方示例 3

输入：words = ["abc","bc","ab","qwe"]
输出：""

每个候选都缺少所需的单字母前缀。

约束

  • 1 ≤ words.length ≤ 10⁵
  • 1 ≤ words[i].length ≤ 10⁵
  • 1 ≤ Σ words[i].length ≤ 10⁵
  • 每个单词只含小写英文字母。

04 / SOLUTION NOTES

独立题解

完成自己的思考后再展开。

核心洞察：路径存在，还要沿途都是单词

Trie 的一个节点代表从根走到它的前缀。插入所有输入后，只有恰好对应一个完整输入单词的节点，才设置 end = true。候选单词有效，当且仅当它路径上的每个非根节点都有这个标记。只创建节点而不标记终点，会把“某个词的前缀”误认为“输入中的词”。

完整过程

  1. 建立空根节点。逐字插入每个词，只在词末设置终止标记。全部插入后才开始判断，避免依赖输入顺序。
  2. 答案初始化为 ""，按原输入顺序检查每个词。从根开始逐字符前进；节点存在由第一遍插入保证。
  3. 遇到 end = false 即停止当前候选。它有一个缺失前缀，后面再长也无法补救。
  4. 所有位置都通过后，长度更大则更新答案；长度相等时仅在字典序更小时更新。
  5. 遍历结束返回答案。整个过程只用迭代，无深递归调用。

示例 2：a 先成为答案；banana 在 b 处停止；app、appl 逐步更新答案；ap 更短不更新；apply 更新到长度 5，随后 apple 以更小字典序替换它。

正确性证明

构建不变式：插入任意一批词后，节点终止标记为真当且仅当对应字符串是已插入的完整词。插入只在词尾置真，且不会清除已有标记，因此全部插入后准确表示输入集合。

候选判定：走完前 k 个字符时，所到节点恰好代表长度 k 的前缀。每一步检查终止标记，因此接受等价于所有非空前缀均在输入中；任一步失败就有反例，拒绝必然正确。

答案不变式：检查前 i 个词后，best 是其中有效词按“长度降序、字典序升序”比较的最优值；没有有效词时为空。无效词不改变答案，有效词只在优于 best 时替换。归纳可知遍历结束返回全局所求。

复杂度

令 S 为全部词长之和。构建与逐词查询共访问 O(S) 个字符，等长字典序比较最多再计 O(S)。固定 26 字母下，总时间 O(S)，辅助空间 O(S)；Python 字典与 JavaScript Map 按通常均摊查找计算。Java / C++ 每节点的 26 个槽位是固定常数。

提交代码不为每层生成前缀副本，避免大量切片开销。可视化为了便于阅读存储小规模快照，其开销不代表提交代码。

边界与常见错误

  • 没有单字母词 → 任何候选都过不了第一关，返回空字符串。
  • 单字母词有效；不要求空前缀出现在数组中。
  • 中间缺词，即使字符节点已建立也必须拒绝。
  • 重复输入只会重复设置标记，不影响结果。
  • 忽略等长字典序比较，会让答案错误依赖输入顺序。
  • 边插入边查询会过早拒绝；递归还需考虑深度，单个词长可达 10⁵。

替代方案

按长度排序 + 有效词集合：短词先处理，词长为 1 或去掉末字符后的词已在“有效集合”时接受。集合保存已确认有效的词，不能直接拿全部输入集合替代。只按长度排序时，排序与字符串处理共 O(N log N + S)，哈希操作按均摊计算，辅助空间 O(S)。若同时按字典序排序，还需计入字符串比较成本。

Trie 剪枝遍历：从根只进入终止标记为真的孩子，未标记分支整体跳过；记录最优候选。可用显式栈避免递归栈溢出，路径维护要避免反复复制长字符串。

枚举前缀 + 哈希集合：容易表达，但每次切片和哈希需要读取字符，朴素实现可能达到 O(Σ|w|²)，不能直接声称为线性算法。

面试追问

  • 可以提前返回吗？原顺序不行，后续可能更长或同长字典序更小；需额外排序及相应停止条件。
  • 怎样返回全部最长有效词？发现更长词时清空结果，同长时追加；如果要求唯一列表，另行去重。
  • 在线插入一个词后只判断它自身够吗？不够，它可能补齐多个已有长词的缺口，需要重新评估受影响的后代。
  • 换成 Unicode 呢？使用稀疏映射，明确字符及字典序定义；不再使用减去 'a' 的索引。

Java

class Solution {
    private static class Node {
        Node[] next = new Node[26];
        boolean end;
    }

    public String longestWord(String[] words) {
        Node root = new Node();
        for (String word : words) {
            Node node = root;
            for (int i = 0; i < word.length(); i++) {
                int c = word.charAt(i) - 'a';
                if (node.next[c] == null) node.next[c] = new Node();
                node = node.next[c];
            }
            node.end = true;
        }
        String best = "";
        for (String word : words) {
            Node node = root;
            boolean valid = true;
            for (int i = 0; i < word.length(); i++) {
                node = node.next[word.charAt(i) - 'a'];
                if (!node.end) {
                    valid = false;
                    break;
                }
            }
            if (valid && (word.length() > best.length()
                    || (word.length() == best.length()
                        && word.compareTo(best) < 0))) {
                best = word;
            }
        }
        return best;
    }
}

/**
 * @param {string[]} words
 * @return {string}

var longestWord = function(words) {
    const makeNode = () => ({ next: new Map(), end: false });
    const root = makeNode();
    for (const word of words) {
        let node = root;
        for (const c of word) {
            if (!node.next.has(c)) node.next.set(c, makeNode());
            node = node.next.get(c);
        }
        node.end = true;
    }
    let best = "";
    for (const word of words) {
        let node = root;
        let valid = true;
        for (const c of word) {
            node = node.next.get(c);
            if (!node.end) {
                valid = false;
                break;
            }
        }
        if (valid && (word.length > best.length ||
            (word.length === best.length && word < best))) {
            best = word;
        }
    }
    return best;
};

Python

from typing import List

class Solution:
    def longestWord(self, words: List[str]) -> str:
        # None is a terminal marker; characters are a-z.
        root = {}
        for word in words:
            node = root
            for char in word:
                if char not in node:
                    node[char] = {}
                node = node[char]
            node[None] = True

        best = ""
        for word in words:
            node = root
            valid = True
            for char in word:
                node = node[char]
                if None not in node:
                    valid = False
                    break
            if valid and (len(word) > len(best) or
                          (len(word) == len(best) and word < best)):
                best = word
        return best

C++

#include <array>
#include <string>
#include <vector>
using namespace std;

class Solution {
    struct Node {
        array<int, 26> next;
        bool end = false;
        Node() { next.fill(-1); }
    };
public:
    string longestWord(vector<string>& words) {
        vector<Node> trie(1);
        for (const string& word : words) {
            int node = 0;
            for (char ch : word) {
                int c = ch - 'a';
                if (trie[node].next[c] == -1) {
                    int id = static_cast<int>(trie.size());
                    trie[node].next[c] = id;
                    trie.emplace_back();
                }
                node = trie[node].next[c];
            }
            trie[node].end = true;
        }
        string best;
        for (const string& word : words) {
            int node = 0;
            bool valid = true;
            for (char ch : word) {
                node = trie[node].next[ch - 'a'];
                if (!trie[node].end) {
                    valid = false;
                    break;
                }
            }
            if (valid && (word.size() > best.size() ||
                (word.size() == best.size() && word < best))) {
                best = word;
            }
        }
        return best;
    }
};
