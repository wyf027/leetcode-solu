差的绝对值为 K 的
数对数目

Count Number of Pairs With Absolute Difference K

相同的值，能组成不同的数对吗？从下标出发，观察每一次配对。

官方题目 ↗

01 / 题目

给定整数数组 nums 和整数 k，统计满足 i < j 且 |nums[i] - nums[j]| = k 的下标对 (i, j) 数量，并返回这个整数。绝对值表示距离：非负数保持原值，负数取相反数。

数对按下标区分。两个位置上的值相同，也仍是两个不同元素；每个下标对只计一次。

约束

  • 1 <= nums.length <= 200
  • 1 <= nums[i] <= 100
  • 1 <= k <= 99

官方示例 · 下标从 0 开始

nums = [1,2,2,1], k = 1
输出：4

有效下标对：(0,1)、(0,2)、(1,3)、(2,3)。值虽然重复，四个下标对各不相同。

nums = [1,3], k = 3
输出：0

唯一的下标对距离为 2，不等于 3。

nums = [3,2,1,5,4], k = 2
输出：3

有效下标对：(0,2)、(0,3)、(1,4)，分别对应值 (3,1)、(3,5)、(2,4)。

04 / 独立题解

先自己思考，再展开过程和四种语言实现。

核心洞察：只访问下标矩阵的上三角

题目只要求计数，长度最多 200。让 i 从左向右移动，并只枚举 j = i + 1 ... n - 1，最多检查 200 × 199 / 2 = 19900 对。无需排序，也无需去重集合；对每一对直接检查绝对差即可。

完整过程

  1. 初始化 answer = 0。
  2. 枚举左下标 i，再枚举所有右下标 j，始终保持 i < j。
  3. 若 abs(nums[i] - nums[j]) == k，将答案加 1。
  4. 全部数对检查完毕后返回答案。

以 nums = [1,2,2,1], k = 1 为例：i=0 时检查 (0,1)、(0,2)、(0,3)，累计 2；i=1 时检查 (1,2)、(1,3)，累计 3；i=2 时检查 (2,3)，累计 4。演示中的绿色与黄色下标正好对应这两层循环。

正确性

循环不变式：每次检查前，answer 等于此前已访问下标对中符合条件的数量。初始没有已访问数对，answer=0。当前数对满足条件才加一，因此不变式始终成立。任何合法下标对 (a,b) 都满足 a<b，会在 i=a、j=b 时被访问，且只被访问一次。循环结束时已覆盖全部合法下标对，所以答案准确。

复杂度

时间：O(n²)，精确进行 n(n−1)/2 次比较。

额外空间：O(1)。只维护下标与计数器。

页面为回放保留数对状态；该展示存储不属于提交算法的空间复杂度。

边界

n=1 时内层循环不执行，返回 0。全相同且 k≥1 时返回 0。最大绝对差为 99。

重复值不能去重。答案不超过总下标对数 19900，四种实现使用的数值类型足够。

替代方案：边遍历边记录频次

遍历当前数 x，在此前出现的元素中查找 x−k 和 x+k，将两者频次加入答案，然后再记录 x。之前的下标天然小于当前下标；k>0 保证两种目标值不同，因此既不漏计，也不重复计数。值域为 1…100 时可用长度 101 的数组，越界查询视为 0，时间 O(n+100)、空间 O(100)；哈希表方案的期望时间 O(n)、空间 O(min(n,100))。本题规模下双循环更直接。

常见错误

  • j 从 0 开始：把 (i,j) 和 (j,i) 各算一次；应从 i+1 开始。
  • 只比较 nums[j] - nums[i] == k：遗漏无序数组里的另一种方向。
  • 把 nums 转为集合：丢失位置及出现次数，导致重复值少算。
  • 遇到第一个匹配就 break：同一个 i 可以有多个符合条件的 j。
  • 频次数组不做目标值边界判断：x−k 可能小于 1，x+k 可能大于 100。

面试追问

如果允许 k=0？双循环无需修改；频次方案只查询 x 一次，不能把两份相同频次重复相加。离线频次法可用 f(x)(f(x)−1)/2。

如果数组长到一百万？改用在线频次统计，避免平方级枚举。若只需数量，不必保存所有匹配下标。

如果必须返回所有下标对？频次表需要改为“值 → 已出现下标列表”，并输出匹配列表中的各对；当答案数量为 m 时，至少需要 O(m) 输出时间和空间。

Java

class Solution {
    public int countKDifference(int[] nums, int k) {
        int answer = 0;
        for (int i = 0; i < nums.length; i++) {
            for (int j = i + 1; j < nums.length; j++) {
                if (Math.abs(nums[i] - nums[j]) == k) {
                    answer++;
                }
            }
        }
        return answer;
    }
}

Python 3

from typing import List

class Solution:
    def countKDifference(self, nums: List[int], k: int) -> int:
        answer = 0
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if abs(nums[i] - nums[j]) == k:
                    answer += 1
        return answer

C++

#include <vector>
#include <cstdlib>
using namespace std;

class Solution {
public:
    int countKDifference(vector<int>& nums, int k) {
        int answer = 0;
        int n = static_cast<int>(nums.size());
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                if (std::abs(nums[i] - nums[j]) == k) {
                    ++answer;
                }
            }
        }
        return answer;
    }
};
