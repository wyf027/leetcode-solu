题意与约束

给定二叉树根节点 root，返回节点值的层序遍历：从顶层到底层，每层从左到右组成一个数组。

官方样例 1 · 三层剧目

输入root␠=␠[3,9,20,null,null,15,7]
输出[[3],[9,20],[15,7]]

官方样例 2 · 单节点

输入root␠=␠[1]
输出[[1]]

官方样例 3 · 空树

输入root␠=␠[]
输出[]

约束

  • 节点数为 [0, 2000]。
  • -1000 <= Node.val <= 1000。
  • 同一层必须保持从左到右的顺序。

␠ 表示一个可见空格；输入完整保留参数名、等号与数组值。

Solution backstage

题解在后台

先操作队列，再展开核心洞察、边界、复杂度、追问和四语言可提交代码。

核心洞察 · 先锁定本层人数

每轮开始时保存 levelSize = queue.size()。随后只出队这么多个节点；期间新入队的孩子自然留给下一层。

完整过程

  1. 空树直接返回空数组。
  2. 根节点入队。
  3. 循环开始时记录当前队列长度。
  4. 连续弹出 levelSize 个节点并收集值。
  5. 按左、右顺序将非空孩子入队。
  6. 本层数组加入答案，直到队列为空。

边界

  • 空树返回 []，不要返回 [[]]。
  • 单节点返回 [[root.val]]。
  • 非完全树也只入队真实节点，不需要空占位。
  • 必须左孩子先入队，才能保持层内从左到右。

复杂度

O(n)每个节点入队、出队各一次
O(w)队列最大宽度；答案空间不计

替代方案

DFS 也能按深度把值追加到对应数组，递归空间为 O(h)。但题目本质是逐层遍历，BFS 的队列状态和输出层级一一对应，面试表达更直接。

常见错误

  • 在 for 循环条件里动态读取 queue.size()，把下一层一起消费。
  • 先入右孩子再入左孩子，层内顺序反转。
  • 忘记对空根节点提前返回。
  • 每出队一个节点就立刻加入答案，失去分层结构。

面试追问

  • 锯齿形层序遍历？偶数层反向写入或使用双端队列。
  • 求每层平均值？把层数组改为计数与求和。
  • 只看右视图？保留每层最后一个出队节点。
  • 流式输出？每层完成后立即交给回调，不保存全部答案。

class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> answer = new ArrayList<>();
        if (root == null) {
            return answer;
        }

        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            List<Integer> level = new ArrayList<>(levelSize);
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            answer.add(level);
        }
        return answer;
    }
}
var levelOrder = function (root) {
    if (root === null) return [];
    const answer = [];
    const queue = [root];
    let head = 0;

    while (head < queue.length) {
        const levelSize = queue.length - head;
        const level = [];
        for (let i = 0; i < levelSize; i++) {
            const node = queue[head++];
            level.push(node.val);
            if (node.left !== null) queue.push(node.left);
            if (node.right !== null) queue.push(node.right);
        }
        answer.push(level);
    }
    return answer;
};

class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        if (root == nullptr) return {};
        vector<vector<int>> answer;
        queue<TreeNode*> nodes;
        nodes.push(root);

        while (!nodes.empty()) {
            int levelSize = nodes.size();
            vector<int> level;
            level.reserve(levelSize);
            for (int i = 0; i < levelSize; i++) {
                TreeNode* node = nodes.front();
                nodes.pop();
                level.push_back(node->val);
                if (node->left != nullptr) nodes.push(node->left);
                if (node->right != nullptr) nodes.push(node->right);
            }
            answer.push_back(std::move(level));
        }
        return answer;
    }
};
