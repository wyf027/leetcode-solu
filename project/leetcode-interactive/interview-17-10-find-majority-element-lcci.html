Interview 17.10 · Array / Counting

主要元素 让候选票互相抵消，再验一次真多数

不建哈希表，也不先排序。只保留一个候选人和一张净票数：相同就加票，不同就抵消；第一轮找到可能的赢家，第二轮确认它真的超过半数。

O(n) 一次选候选人，一次验票
额外空间 O(1)
Problem brief

题意

简单 · 官方页面核实

任务

给定整数数组 nums，找出出现次数严格超过数组长度一半的元素；若不存在，返回 -1。要求设计时间复杂度 O(n)、额外空间复杂度 O(1) 的算法。

“严格超过一半”意味着计数必须满足 frequency > floor(nums.length / 2)。

官方样例

输入 nums = [1, 2, 5, 9, 5, 9, 5, 5, 5]
输出 5
输入 nums = [3, 2]
输出 -1
输入 nums = [2, 2, 1, 1, 1, 2, 2]
输出 2

Core insight

核心洞察

Boyer–Moore 多数投票

成对抵消不会消灭真多数

每次拿一个候选元素和一个不同元素配对删除。如果某个值原本超过一半，删掉任意数量的“它 + 非它”之后，它仍然是剩余元素中的多数；因此第一轮最后留下的候选人只可能是真正答案。

“只可能”不等于“必然”

没有主要元素时，投票过程依然会产生候选人。因此必须再扫描一次，统计候选人的真实出现次数，并检查是否严格大于 floor(n / 2)。

相同票 +1 · 不同票 −1 · 票数归零就更换候选人
Full process

完整过程

1

初始化 candidate = 0、count = 0。候选值在计数为 0 时才会被读取并替换。

2

依次扫描数组；若 count == 0，把当前元素设为新的 candidate。

3

当前元素等于候选人时 count++，否则 count--，等价于消去一对不同元素。

4

第一轮结束后再次遍历，统计 candidate 的出现次数；超过 n / 2 才返回，否则返回 -1。

Edges & trade-offs

边界、复杂度与替代方案

时间复杂度 O(n)

候选扫描一次，真实性验证再扫描一次，常数轮遍历。

额外空间 O(1)

只维护候选值、净票数和最终出现次数。

关键边界

  • 空数组：防御性返回 -1。
  • 单元素数组：该元素天然超过一半。
  • 恰好一半：不满足“严格超过”，返回 -1。
  • 候选人在后半段才建立：投票仍能正确保留它。
  • 元素可以为 -1；不要用返回值兼任“无候选”状态。

替代方案取舍

  • 哈希计数：O(n) 时间、O(n) 空间，直观但不满足空间要求。
  • 排序取中位数：O(n log n)，仍需验证且会修改数组或复制数组。
  • 随机采样：期望较快但非确定性，不适合作为面试主线。
  • Boyer–Moore：唯一同时贴合 O(n) 与 O(1) 的推荐主线。
Interview follow-up

面试追问与常见错误

面试追问

  1. 为什么抵消后真多数一定还能成为候选人？
  2. 如果题目保证主要元素存在，能否省略第二轮？可以。
  3. 若阈值改为超过 n/3 呢？维护至多两个候选人，再统一验证。
  4. 数据以流形式到达时怎么办？第一轮可流式完成，验证需要重放或额外计数。

常见错误

  • 直接返回第一轮候选人，忘记题目允许不存在主要元素。
  • 使用 >= n / 2，把“恰好一半”误判为主要元素。
  • 先比较再在 count == 0 时换人，导致本轮票数更新错误。
  • 用 -1 表示“候选为空”，与合法元素值冲突。

class Solution {
    public int majorityElement(int[] nums) {
        int candidate = 0;
        int count = 0;

        for (int num : nums) {
            if (count == 0) {
                candidate = num;
            }
            count += num == candidate ? 1 : -1;
        }

        int occurrences = 0;
        for (int num : nums) {
            if (num == candidate) {
                occurrences++;
            }
        }

        return occurrences > nums.length / 2 ? candidate : -1;
    }
}
