路径加密

首屏不泄题解，先自行推演。

题意

将字符串 path 中的每个空格替换为 %20 并返回结果。

示例：输入 "We are happy."，输出 "We%20are%20happy."
约束：0 ≤ path.length ≤ 10000；仅含字母、数字与空格。

分步互动

第 1 步：读取字符；空格应替换成什么？

洞察

扫描字符，非空格追加原字符，空格追加 %20。

过程：初始化结果→逐字符判断→返回结果。边界：空串、无空格、全空格、首尾空格。复杂度：时间 O(n)，空间 O(n)。替代：内置 replace；追问：字符数组原地替换如何从后向前？错误：只替换首个空格、遗漏首尾、结果顺序错乱。

Java

class Solution { public String pathEncryption(String path) { return path.replace(" ", "%20"); } }

JavaScript

var pathEncryption = function(path) { return path.replaceAll(' ', '%20'); };

Python

class Solution: def pathEncryption(self, path: str) -> str: return path.replace(' ', '%20')

C++

class Solution { public: string pathEncryption(string path) { string a; for(char c:path) a+=c==' '?"%20":string(1,c); return a; } };
