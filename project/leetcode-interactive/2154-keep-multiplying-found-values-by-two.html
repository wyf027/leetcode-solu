将找到的值
乘以 2

Keep Multiplying Found Values by Two

一个不断变化的目标，一组始终不变的数字。它会在哪里停下？

01 / 题目

给定整数数组 nums 和初始整数 original。每轮在数组中寻找当前的 original：若存在，将它乘以 2，再继续寻找新值；若不存在，立即停止。返回停止时的 original。

数组本身不会改变，也不需要删除已找到的元素。

参数与返回值
findFinalValue(nums: integer[], original: integer) → integer
约束：1 ≤ nums.length ≤ 1000；1 ≤ nums[i], original ≤ 1000（original 的限制指初始值）。

官方示例 1

输入：nums = [5,3,6,1,12], original = 3
输出：24

3、6、12 依次能被找到，目标依次变为 6、12、24；24 不存在，因此返回 24。

官方示例 2

输入：nums = [2,7,9], original = 4
输出：4

最初的目标 4 就不存在，因此直接返回 4。

04 / 独立题解

想清楚查找规则后，再展开实现与证明。

核心洞察：只关心“是否存在”

每轮都可能查找数组任意位置，位置和重复次数都不影响答案。先把数组放进集合，再不断判断当前值是否属于集合；命中就翻倍，缺失就返回。

完整过程

  1. 用 nums 构建集合 seen。
  2. 只要 seen 含有 original，更新 original *= 2。
  3. 循环退出时，返回当前值。

例如示例 1：集合包含 3 → 更新为 6；包含 6 → 更新为 12；包含 12 → 更新为 24；不含 24 → 返回 24。无需修改或移除集合中的值。

正确性与终止性

不变式：每次循环判断前，original 都等于按题目规则完成此前所有成功查找后的目标。初始时显然成立；每次命中后乘以 2，正好执行题目的一次操作，因此继续成立。退出时当前值不在数组中，恰好满足题目的停止条件，返回值正确。

所有值均为正数，每次成功后目标严格增大。设数组最大值为 M，一旦目标超过 M 就一定缺失，所以循环必然终止。重复元素不改变这个结论。

复杂度

设 n 为数组长度，k 为成功翻倍次数。采用哈希集合时，期望时间 O(n + k)，额外空间 O(n)；哈希查询按平均 O(1) 计。若初值 a ≤ M，则 k ≤ ⌊log₂(M/a)⌋ + 1，否则 k = 0。成功查找的值互不相同，故 k ≤ n，期望总时间也可写作 O(n)。本题最多成功翻倍 10 次。

边界与常见错误

  • 初值不存在：立即返回初值，不应先翻倍。
  • 重复值只表达存在，不是每个副本都触发一次翻倍。
  • 只遍历一次未排序数组会漏掉前面出现的新目标，如 [8,4,2,1]。
  • 遇到断链必须停止，不能跳过缺失目标去找更大的数。
  • 答案可以超过 1000，但最多为 2000；四种语言的这里所用数值类型均能表示。
  • 0 与负数不在约束内；若允许 0，存在 0 时直接倍增会无限循环，需要另行定义终止语义。

四语言可提交代码

JavaScript

/**
 * @param {number[]} nums
 * @param {number} original
 * @return {number}
 */
var findFinalValue = function(nums, original) {
    const seen = new Set(nums);
    while (seen.has(original)) original *= 2;
    return original;
};

Java

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int findFinalValue(int[] nums, int original) {
        Set<Integer> seen = new HashSet<>();
        for (int value : nums) seen.add(value);
        while (seen.contains(original)) original *= 2;
        return original;
    }
}

Python 3

from typing import List

class Solution:
    def findFinalValue(self, nums: List[int], original: int) -> int:
        seen = set(nums)
        while original in seen:
            original *= 2
        return original

C++

#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    int findFinalValue(vector<int>& nums, int original) {
        unordered_set<int> seen(nums.begin(), nums.end());
        while (seen.count(original)) original *= 2;
        return original;
    }
};

替代方案

  • 反复线性查找：每轮遍历原数组，时间 O(n(k + 1))，额外空间 O(1)。本题 k 很小，实现也很直接。
  • 排序后单次遍历：先升序排序，遇到等于目标的值就翻倍。正数保证新目标更大，后续只需向右找。时间 O(n log n)，排序辅助空间依语言实现而定；原地排序会改变输入顺序。
  • 布尔存在表：利用最大值 1000，建立 1001 个槽。访问前先判断目标 ≤ 1000，避免答案超界时越界。时间 O(n + M + k)，空间 O(M)。

面试追问

同一数组需要回答大量不同初值？复用一次构建的集合；更多重复查询时可缓存最终答案。倍数换为正整数 c > 1？同样按存在性查询并相乘，终止性仍成立。数组在查询间会改变？更新存在性结构；若有删除和重复元素，需用计数维护是否仍存在。
