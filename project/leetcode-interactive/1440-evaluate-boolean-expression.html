计算布尔表达式的值Evaluate Boolean Expression

把表达式两端的变量各映射成整数，再按运算符完成比较。先观察数据关系与交互实验；完整解法默认收在页面底部。

Problem

题目转述

给定变量表 Variables 与表达式表 Expressions。对每条表达式，查出左右变量对应的整数值，依据 >、< 或 = 求值，并返回原表达式三列及字符串结果列 value。条件成立输出 true，否则输出 false；结果顺序不限。

Variables

列名类型含义
namevarchar(3)变量名，主键
valueint变量的整数值

Expressions

列名类型含义
left_operandvarchar(3)左变量名
operatorenum>、< 或 =
right_operandvarchar(3)右变量名

约束与保证

  • Variables.name 是主键。
  • (left_operand, operator, right_operand) 是 Expressions 的联合主键。
  • operator 只会是 '>'、'<'、'=' 之一。
  • 每个左右操作数都保证能在 Variables 中找到。

注意：这是数据库题，= 是 SQL 相等运算符，不是赋值。

+--------------+----------+---------------+-------+

例如 x < y 会被替换为 66 < 77，因此结果是 true。

Solution

双自连接 + 条件求值

核心洞察一条表达式有两个“变量名 → 数值”的查询需求。因此把 Variables 当作两份逻辑别名：一份连接左操作数，一份连接右操作数；之后用 CASE 根据运算符比较两边数值。

完整过程

  1. 从 Expressions e 出发，保留每条待求值表达式。
  2. 连接 Variables l，条件为 e.left_operand = l.name，取得左值。
  3. 再次连接 Variables r，条件为 e.right_operand = r.name，取得右值。
  4. 在 CASE 中将运算符和值的比较配对；任一对应条件成立时返回 true，否则返回 false。
表达式行 e → 左值 l.value + 右值 r.value → CASE(operator, l.value, r.value) → true / false

正确性说明

对任意表达式行 e，题目保证左右变量名都存在，且 Variables.name 唯一，所以两次连接各自恰好得到一个正确的整数值。运算符仅有三种；CASE 分别检查相等、大于和小于，并且每个分支都直接对应题目定义。因此输出的 value 当且仅当原表达式成立时为 true。逐行成立，故整个结果正确。

边界情况

  • 左右操作数相同，如 x = x。
  • 不同变量拥有相同值。
  • 整数为负数或零。
  • 同一变量参与多条不同表达式。

复杂度

设表达式数为 E、变量数为 V。典型数据库在主键索引下执行两次点查，直观工作量约为 O(E log V)；优化器也可能选择哈希连接，使平均工作量接近 O(E + V)。结果集本身占 O(E)。

官方可提交方案 · MySQL

这是数据库题，以下 SQL 才是与官方签名匹配的提交内容。

SELECT
    e.left_operand,
    e.operator,
    e.right_operand,
    CASE
        WHEN e.operator = '=' AND l.value = r.value THEN 'true'
        WHEN e.operator = '>' AND l.value > r.value THEN 'true'
        WHEN e.operator = '<' AND l.value < r.value THEN 'true'
        ELSE 'false'
    END AS value
FROM Expressions AS e
JOIN Variables AS l ON l.name = e.left_operand
JOIN Variables AS r ON r.name = e.right_operand;

四语言本地语义参考

Java、JavaScript、Python、C++ 不是本题的官方数据库提交语言。下面四份完整函数仅用于在本地表达相同的数据映射和比较语义，不能直接提交到该 SQL 题。

import java.util.*;

class Solution {
    record Expression(String left, String operator, String right) {}
    record Result(String left, String operator, String right, String value) {}

    public List<Result> evaluate(
            Map<String, Integer> variables,
            List<Expression> expressions) {
        List<Result> answer = new ArrayList<>();
        for (Expression e : expressions) {
            int leftValue = variables.get(e.left());
            int rightValue = variables.get(e.right());
            boolean ok = switch (e.operator()) {
                case ">" -> leftValue > rightValue;
                case "<" -> leftValue < rightValue;
                case "=" -> leftValue == rightValue;
                default -> throw new IllegalArgumentException("unknown operator");
            };
            answer.add(new Result(e.left(), e.operator(), e.right(),
                    ok ? "true" : "false"));
        }
        return answer;
    }
}
function evaluateBooleanExpressions(variables, expressions) {
  const values = new Map(variables.map(({ name, value }) => [name, value]));

  return expressions.map(({ left_operand, operator, right_operand }) => {
    const left = values.get(left_operand);
    const right = values.get(right_operand);
    let result;

    if (operator === ">") result = left > right;
    else if (operator === "<") result = left < right;
    else if (operator === "=") result = left === right;
    else throw new Error("unknown operator");

    return {
      left_operand,
      operator,
      right_operand,
      value: result ? "true" : "false",
    };
  });
}
from typing import Dict, List, TypedDict


class Expression(TypedDict):
    left_operand: str
    operator: str
    right_operand: str


def evaluate_boolean_expressions(
    variables: Dict[str, int], expressions: List[Expression]
) -> List[dict]:
    answer = []
    for expression in expressions:
        left = variables[expression["left_operand"]]
        right = variables[expression["right_operand"]]
        operator = expression["operator"]
        if operator == ">":
            result = left > right
        elif operator == "<":
            result = left < right
        elif operator == "=":
            result = left == right
        else:
            raise ValueError("unknown operator")
        answer.append({**expression, "value": str(result).lower()})
    return answer
#include <stdexcept>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

struct Expression { string left, op, right; };
struct Result { string left, op, right, value; };

vector<Result> evaluateBooleanExpressions(
    const unordered_map<string, int>& variables,
    const vector<Expression>& expressions) {
    vector<Result> answer;
    for (const auto& e : expressions) {
        int left = variables.at(e.left);
        int right = variables.at(e.right);
        bool ok;
        if (e.op == ">") ok = left > right;
        else if (e.op == "<") ok = left < right;
        else if (e.op == "=") ok = left == right;
        else throw invalid_argument("unknown operator");
        answer.push_back({e.left, e.op, e.right, ok ? "true" : "false"});
    }
    return answer;
}

替代方案

可以用相关子查询分别取左右值，但每一行会写两次子查询，表达意图较分散；也可以把运算符拆成三个 UNION ALL 分支，但会重复扫描或重复连接。双别名连接配合一个 CASE 更直接。

常见错误

  • 只连接一次 Variables，拿不到两端值。
  • 把变量名字符串直接互相比较。
  • 用 == 表示 SQL 相等。
  • 输出布尔值或 0/1，而非题目要求的小写字符串。
  • 遗漏 ELSE 'false'，产生空值。
