心算挑战

从 N 张卡牌中恰好选出 cnt 张。只有总和为偶数时成绩有效，求最大的有效得分；不存在方案返回 0。

排序贪心一次反悔奇偶修正

题意与示例

数组 cards 给出每张牌的正整数分值，必须选满 cnt 张。偶数总和才有效，因此答案既要尽量大，也要满足奇数牌的数量为偶数。

示例 1

cards = [1,2,8,9], cnt = 3

输出：18

选择 1、8、9，总分 18。

示例 2

cards = [3,3,1], cnt = 1

输出：0

所有牌都是奇数，选一张无法得到偶数和。

约束：1 ≤ cnt ≤ cards.length ≤ 10⁵，1 ≤ cards[i] ≤ 1000。

题解：降序选满，再做最优异性替换

核心洞察

降序排序后先拿前 cnt 张，它们是不考虑奇偶时的最大和。若和为偶数，直接返回。若为奇数，只需一次“奇偶不同”的替换：删选中最小奇数、补未选最大偶数，或删选中最小偶数、补未选最大奇数。

为什么一次替换足够

总和从奇变偶，增减差必须为奇数，因此换入与换出必须异性。排序保证：对每种替换类型，移除最小者、补入最大者损失最小；两种候选取最大即为全局最优。

复杂度与边界

排序时间 O(n log n)；之后线性扫描 O(n)。排序若原地则额外空间取决于语言实现。没有合法异性替换时返回 0；cnt=n 时也适用。

常见错误与追问

  • 删除选中最大牌，而非同奇偶的最小牌。
  • 未选区取到较小的候选。
  • 只尝试一种奇偶替换。
  • 误以为偶数和要求所有牌都是偶数。
