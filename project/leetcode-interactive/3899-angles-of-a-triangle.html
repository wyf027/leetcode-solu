三角形的内角度数

给定 sides（恰好三条正整数边）。若能围成面积为正的三角形，返回三个内角的度数并按非递减顺序排列；否则返回空数组。

约束：sides.length = 3，1 ≤ sides[i] ≤ 1000。允许与真实角度相差 10⁻⁵。

sides = [3, 4, 5]
期望输出：[36.86990, 53.13010, 90.00000]
3 + 4 > 5，能构成直角三角形。
sides = [2, 4, 2]
期望输出：[]

题解：排序 + 三角不等式 + 余弦定理

令排序后的边长为 a ≤ b ≤ c。只需检查 a + b > c：不成立时面积为零或无法闭合。成立时，对每条边 x，其对角满足 cos θ = (y² + z² - x²) / (2yz)；用 acos 后换算为角度。

完整过程

  1. 复制并排序三条边，避免修改调用者的数组。
  2. 检查最短两边之和是否严格大于最长边。
  3. 分别求三条边的对角；浮点误差可把余弦值夹到 [-1, 1]。
  4. 对三个角排序后返回。

边界、复杂度与替代方案

等边、等腰、直角和接近退化的情形都由同一公式覆盖；严格不等式是关键。排序规模固定为 3，时间与额外空间均为 O(1)。替代方案是先由海伦公式判断面积，但仍需余弦定理得到角度。

常见错误 / 面试追问

不要把 a + b = c 当作三角形；不要忘记弧度转角度；acos 的输入应夹紧以抵抗舍入。若边数扩大到多边形，存在性条件变为最长边小于其余边之和。
