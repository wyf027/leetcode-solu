280. 摆动排序

Wiggle Sort

把一组无序数字排成高低交错的节奏。你需要原地修改数组；相邻位置允许相等，因此这是非严格摆动。

阅读题目 打开交互演示

Problem

题目描述

给定整数数组 nums，请原地重新排列其中的元素，使它满足：

nums[0] <= nums[1] >= nums[2] <= nums[3] ...

输入保证存在有效答案。函数不返回数组，而是直接修改 nums。

示例 1

输入：nums = [3,5,2,1,6,4]

输出：[3,5,1,6,2,4]

说明：答案不唯一，例如 [1,6,2,5,3,4] 也满足要求。

示例 2

输入：nums = [6,6,5,6,3,8]

输出：[6,6,5,6,3,8]

相邻值可以相等，原数组已经满足非严格摆动关系。

数组长度

1 ≤ nums.length ≤ 5 × 10⁴

元素范围

0 ≤ nums[i] ≤ 10⁴

进阶目标

O(n) 时间复杂度

先尝试解释：为什么修复当前相邻关系不会破坏刚刚确认的上一组关系？

Greedy Solution

一次扫描，局部修复

O(n) · O(1)

核心洞察

索引 i 为奇数时，它应当是局部“峰”，需要 nums[i - 1] ≤ nums[i]；索引 i 为偶数时，它应当是局部“谷”，需要 nums[i - 1] ≥ nums[i]。如果当前关系反了，只交换这一对相邻元素。

完整过程

  1. 从索引 1 开始向右扫描。
  2. 按 i 的奇偶性确定当前位置应为峰还是谷。
  3. 若相邻关系不符合要求，交换 nums[i - 1] 与 nums[i]。
  4. 扫描结束时，所有相邻关系都满足交替不等式。

正确性证明

循环不变式：处理完索引 i 后，前缀 nums[0..i] 已满足摆动关系。

初始化：在处理 i = 1 时，若 nums[0] ≤ nums[1] 已成立则保持不动，否则交换二者；因此长度为 2 的前缀合法。

保持：假设 nums[0..i-1] 合法。若当前相邻关系不合法就交换两者。对奇数 i，交换后新的 nums[i-1] 是这对数中较小者；它不会破坏左侧要求 nums[i-2] ≥ nums[i-1]。对偶数 i 同理，新的 nums[i-1] 是较大者，不会破坏左侧要求 nums[i-2] ≤ nums[i-1]。当前关系也被修复，故不变式保持。

终止：最后处理 i = n - 1 后，整个数组都是合法摆动序列。

边界情况

  • 空扫描范围：长度为 1 时无需操作。
  • 重复元素：使用非严格不等号，相等无需交换。
  • 已满足摆动：所有位置保持原样。
  • 单调数组：仍只需一次线性扫描。

复杂度

  • 时间：O(n)，每个相邻位置检查一次。
  • 空间：O(1)，只进行原地交换。
  • 交换次数：最坏不超过 n - 1。

替代方案

可以先排序，再交换排序后索引 1 与 2、3 与 4 等相邻位置，得到摆动序列。它更直观，但时间为 O(n log n)；某些语言的排序还需要额外空间。

class Solution {
    public void wiggleSort(int[] nums) {
        for (int i = 1; i < nums.length; i++) {
            boolean wrongPeak = (i % 2 == 1) && nums[i] < nums[i - 1];
            boolean wrongValley = (i % 2 == 0) && nums[i] > nums[i - 1];
            if (wrongPeak || wrongValley) {
                int temp = nums[i];
                nums[i] = nums[i - 1];
                nums[i - 1] = temp;
            }
        }
    }
}
/**
 * @param {number[]} nums
 * @return {void} Do not return anything, modify nums in-place instead.
 */
var wiggleSort = function(nums) {
    for (let i = 1; i < nums.length; i++) {
        const wrongPeak = i % 2 === 1 && nums[i] < nums[i - 1];
        const wrongValley = i % 2 === 0 && nums[i] > nums[i - 1];
        if (wrongPeak || wrongValley) {
            [nums[i - 1], nums[i]] = [nums[i], nums[i - 1]];
        }
    }
};

class Solution {
public:
    void wiggleSort(vector<int>& nums) {
        for (int i = 1; i < static_cast<int>(nums.size()); ++i) {
            bool wrongPeak = (i % 2 == 1) && nums[i] < nums[i - 1];
            bool wrongValley = (i % 2 == 0) && nums[i] > nums[i - 1];
            if (wrongPeak || wrongValley) {
                swap(nums[i - 1], nums[i]);
            }
        }
    }
};

常见错误

  • 把非严格关系误写成严格关系，导致重复元素处理错误。
  • 奇偶条件写反：奇数索引应为峰，偶数索引应为谷。
  • 返回新数组而没有原地修改传入的 nums。
  • 认为答案唯一，并按固定输出做数组全等比较。
  • 交换后回退扫描；这里的局部性质保证无需回退。
