求出 MK 平均值

Finding MK Average

关注最近的一段数据，去掉两端的极值。你能让每一次更新都足够快吗？

官方题目 ↗

01 / 题目

设计一个接收正整数流的数据结构。数据不足 m 个时返回 −1；否则只取最近 m 个数，按数值大小去除最小 k 个和最大 k 个，再对剩余 m − 2k 个数求平均并向下取整。重复值按出现次数计数，查询不会真的删除流中的元素。

  • MKAverage(int m, int k)：用固定参数创建空数据流。
  • void addElement(int num)：追加一个整数。
  • int calculateMKAverage()：返回当前 MK 平均值。

约束

3 ≤ m ≤ 100000；1 ≤ 2k < m，k 为整数；1 ≤ num ≤ 100000；两种方法的调用总数不超过 100000。

元数据中英文约束的左端分别写为 1 ≤ 2k 和 1 < 2k；对整数 k，两者均要求 k ≥ 1。

02 / 官方示例

输入：操作名与完整参数

["MKAverage","addElement","addElement","calculateMKAverage","addElement","calculateMKAverage","addElement","addElement","addElement","calculateMKAverage"]
[[3,1],[3],[1],[],[10],[],[5],[5],[5],[]]

输出

[null, null, null, -1, null, 3, null, null, null, 5]

m = 3，k = 1。加入 3、1 后查询返回 −1；加入 10 后，窗口为 [3,1,10]，只保留 3，返回 3。再加入三个 5，窗口变成 [5,5,5]，去掉两次出现的 5 后还剩一个 5，返回 5。

03 / 先想一想

如果每次查询都排序，十万次操作会怎样？相同值跨越删除边界时，应该删除“一个值”还是“若干次出现”？

04 / 题解 · 从时间窗口到值域排名

核心洞察：设 F(t) 为当前窗口里最小 t 个数的总和，那么中间部分恰好是 F(m−k) − F(k)。值域只有 1…100000，可以用两棵树状数组分别记录出现次数和数值和；再用环形队列删除最早的元素。

窗口与排名截断实验台

每个数分四步：入窗与过期 → 按值观察 → 标记两端 → 计算排名前缀差。色块文字同时标识分区。演示按排序展示排名语义，提交代码用树状数组维护，不会每次排序。

演示 m 限 3…20；数值仍为 1…100000；以英文逗号分隔。修改后点击“应用输入”。

数值排名 · 小 → 大

完整过程

  1. 初始化计数树 C、求和树 S 和容量 m 的环形队列。树状数组节点 i 管理长度为 lowbit(i) 的值域区间。
  2. 加入 x 前，若队列已满，对被覆盖的旧值执行次数 −1、和 −旧值；随后写入 x，并沿树状数组更新次数 +1、和 +x。
  3. 查询时先检查窗口是否满。未满立即返回 −1。
  4. 求 F(t)：从最大二进制步长 65536 向下试探，接受使累计次数仍严格小于 t 的树节点，同时累加对应和。最终得到最大值域下标 idx，使 ≤ idx 的元素数 cnt < t。
  5. 第 t 小的值是 v = idx + 1。若这些重复值只有部分需要计入，补上 (t−cnt) × v，于是 F(t) = 已累加的和 + 该补量。t = 0 时直接返回 0。
  6. 返回 floor((F(m−k)−F(k))/(m−2k))。

为什么正确

窗口不变式：每次追加仅在满窗时删除队首，再加入新数，所以队列和两棵树始终恰好表示最近 min(m,已加入数) 个元素的多重集合。

排名前缀：计数非负，按值的前缀次数单调。二进制提升寻找最后一个次数少于 t 的前缀；跳过的树节点互不重叠，对应和一起累加。剩余所需次数一定来自 idx+1，因此补量精确，即使边界处有重复值也成立。

截断结果：F(m−k) 包含排序后第 1…m−k 项，减去 F(k) 正好留下第 k+1…m−k 项，共 m−2k 项。除以项数并下取整就是定义中的答案。

边界与常见错误

  • 不足 m 个返回 −1；查询不修改窗口。不能把历史所有元素一起统计。
  • 重复值必须按次数裁切，不能用普通 Set；F(t) 不能直接取到边界值为止的全体总和。
  • 最大和达到 10¹⁰，Java 用 long、C++ 用 long long；JavaScript 求和用 Number / Float64Array，不可用 Int32Array 或位运算截断结果。
  • 正整数保证 Java / C++ 整数除法等于向下取整。若扩展到负数，要重新处理值域与取整语义。
  • 2k < m 保证分母正数；最小窗口和全部相同数同样适用。

复杂度

设 V = 100000。初始化 O(V+m) 时间与空间；每次 addElement 为 O(log V)，每次 calculateMKAverage 为 O(log V)，总辅助空间 O(V+m)。二进制提升直接在树上定位排名，避免“二分值 + 前缀查询”的 O(log² V)。

替代方案与面试追问

  • 每次复制窗口并排序：实现直接，但查询 O(m log m)，适合解释题意，不能据此保证满足最大规模。
  • 维护低、中、高三个有序多重集合并缓存中段和：更新 O(log m)、查询 O(1)，需要仔细维护大小和平衡以及重复值删除。
  • 若值域巨大且在线未知？可用带子树大小与和的平衡搜索树；离线已知所有值则可坐标压缩，求和必须使用原值。
  • 若查询远多于更新？可以在每次满窗更新后缓存答案，使查询 O(1)，更新仍为 O(log V)。
  • 若 k 可变？排名前缀方法可按每次给定 k 查询；三个集合需要重新平衡。

JavaScript

class MKAverage {
  constructor(m, k) {
    this.m = m; this.k = k; this.V = 100000;
    this.c = new Int32Array(this.V + 1);
    this.s = new Float64Array(this.V + 1);
    this.q = new Int32Array(m);
    this.pos = 0; this.size = 0;
  }
  update(x, delta) {
    for (let i = x; i <= this.V; i += i & -i) {
      this.c[i] += delta;
      this.s[i] += x * delta;
    }
  }
  addElement(num) {
    if (this.size === this.m) this.update(this.q[this.pos], -1);
    else this.size++;
    this.q[this.pos] = num;
    this.pos = (this.pos + 1) % this.m;
    this.update(num, 1);
  }
  // Sum of the smallest t elements, counting duplicates.
  first(t) {
    if (t === 0) return 0;
    let idx = 0, count = 0, sum = 0;
    for (let step = 65536; step; step >>= 1) {
      const next = idx + step;
      if (next <= this.V && count + this.c[next] < t) {
        idx = next; count += this.c[next]; sum += this.s[next];
      }
    }
    return sum + (t - count) * (idx + 1);
  }
  calculateMKAverage() {
    if (this.size < this.m) return -1;
    return Math.floor((this.first(this.m - this.k) - this.first(this.k))
      / (this.m - 2 * this.k));
  }
}

Java

class MKAverage {
    private static final int V = 100000;
    private final int m, k;
    private final int[] count = new int[V + 1];
    private final long[] sum = new long[V + 1];
    private final int[] queue;
    private int pos = 0, size = 0;

    public MKAverage(int m, int k) {
        this.m = m; this.k = k;
        queue = new int[m];
    }
    private void update(int x, int delta) {
        for (int i = x; i <= V; i += i & -i) {
            count[i] += delta;
            sum[i] += (long) x * delta;
        }
    }
    public void addElement(int num) {
        if (size == m) update(queue[pos], -1);
        else size++;
        queue[pos] = num;
        pos = (pos + 1) % m;
        update(num, 1);
    }
    private long first(int t) {
        if (t == 0) return 0;
        int idx = 0, cnt = 0;
        long result = 0;
        for (int step = 65536; step > 0; step >>= 1) {
            int next = idx + step;
            if (next <= V && cnt + count[next] < t) {
                idx = next;
                cnt += count[next];
                result += sum[next];
            }
        }
        return result + (long) (t - cnt) * (idx + 1);
    }
    public int calculateMKAverage() {
        if (size < m) return -1;
        return (int) ((first(m - k) - first(k)) / (m - 2 * k));
    }
}

Python

class MKAverage:
    def __init__(self, m: int, k: int):
        self.m, self.k = m, k
        self.V = 100000
        self.count = [0] * (self.V + 1)
        self.total = [0] * (self.V + 1)
        self.queue = [0] * m
        self.pos = self.size = 0

    def _update(self, x: int, delta: int) -> None:
        i = x
        while i <= self.V:
            self.count[i] += delta
            self.total[i] += x * delta
            i += i & -i

    def addElement(self, num: int) -> None:
        if self.size == self.m:
            self._update(self.queue[self.pos], -1)
        else:
            self.size += 1
        self.queue[self.pos] = num
        self.pos = (self.pos + 1) % self.m
        self._update(num, 1)

    def _first(self, t: int) -> int:
        if t == 0:
            return 0
        idx = count = result = 0
        step = 65536
        while step:
            nxt = idx + step
            if nxt <= self.V and count + self.count[nxt] < t:
                idx = nxt
                count += self.count[nxt]
                result += self.total[nxt]
            step >>= 1
        return result + (t - count) * (idx + 1)

    def calculateMKAverage(self) -> int:
        if self.size < self.m:
            return -1
        return (self._first(self.m - self.k) - self._first(self.k)) // (self.m - 2 * self.k)

C++

#include <vector>
using namespace std;

class MKAverage {
    static constexpr int V = 100000;
    int m, k, pos = 0, size = 0;
    vector<int> count, queue;
    vector<long long> sum;
    void update(int x, int delta) {
        for (int i = x; i <= V; i += i & -i) {
            count[i] += delta;
            sum[i] += 1LL * x * delta;
        }
    }
    long long first(int t) {
        if (t == 0) return 0;
        int idx = 0, cnt = 0;
        long long result = 0;
        for (int step = 65536; step; step >>= 1) {
            int next = idx + step;
            if (next <= V && cnt + count[next] < t) {
                idx = next;
                cnt += count[next];
                result += sum[next];
            }
        }
        return result + 1LL * (t - cnt) * (idx + 1);
    }
public:
    MKAverage(int m, int k)
        : m(m), k(k), count(V + 1), queue(m), sum(V + 1) {}
    void addElement(int num) {
        if (size == m) update(queue[pos], -1);
        else ++size;
        queue[pos] = num;
        pos = (pos + 1) % m;
        update(num, 1);
    }
    int calculateMKAverage() {
        if (size < m) return -1;
        return (first(m - k) - first(k)) / (m - 2 * k);
    }
};
