01 / 题目

保持行序，补全 drink

输入表 CoffeeShop 记录订单编号和饮料名称。对每一行缺失的 drink，取它上方距离最近、原本有饮料名称的那一行的值；已有名称保持不变。输出仍为 id, drink 两列，行顺序与输入完全一致。

字段类型含义
idINT主键，订单编号唯一
drinkVARCHAR(20)饮料名称，允许 NULL

约束与输入边界

  • 第一行的 drink 保证不是 NULL。
  • 原始行序有意义；不要按 id 数值重排行。id 不要求递增或连续。
  • 返回结果表，不要求修改原始表。
  • 官方元数据 DDL 为 CoffeeShop(id int, drink varchar(20))；可获取资料没有给出行数或 id 数值范围，不补造数值上限。
  • NULL 与字符串 "null"、空字符串 "" 不同。

来源：本地官方元数据提供表结构与示例；缺失的题面语义参考公开题目整理作简要转述。官方题目需要订阅查看。

题解 · 让最近的有效值向下延续

核心洞察

从上到下看，每个非 NULL 行开启一段，后续连续 NULL 行都属于这一段。维护最近的有效名称即可逐行填充；SQL 则用“非 NULL 累计计数”编号，再从每段第一行取值。

完整过程：有序行 → 段号 → 段首值

  1. 为输入位置生成序号 rn。演示中 rn 就是数组下标加一。
  2. 累计统计非 NULL：COUNT(drink) OVER (...)。官方示例的段号依次为 1, 1, 1, 2, 3, 3。
  3. 按段号分区，按 rn 取 FIRST_VALUE(drink)；同一段所有行共享同一来源。
  4. 最终按 rn 返回 id、drink，去掉辅助列。
SQL 的关键前提：原表没有定义排序字段。

数据库关系本身无固有行序，ROW_NUMBER() OVER () 也不能保证恢复输入或插入顺序。下方 MySQL 题库惯用写法依赖读出顺序恰好等于题目给定顺序的假设，不能据此宣称对任意数据库执行计划都正确。实际系统必须在导入时保存唯一的顺序字段，例如 input_pos，并在第一个窗口中写 ROW_NUMBER() OVER (ORDER BY input_pos)。不要把它擅自改成 ORDER BY id。

关于无排序编号的不确定性、窗口取值和 NULL 处理，参考 MySQL 8.0 窗口函数文档。题面缺少排序字段的问题无法仅靠这两个业务字段一般性地修复。

正确性证明（给定稳定输入行序）

循环不变量：处理完前 k 行后，保存的名称是这 k 行中最后一个非 NULL 的名称，且前 k 行输出满足题意。第一行非 NULL，初始化成立。第 k+1 行若非 NULL，则更新保存值并原样输出；若为 NULL，则沿用保存值，它正是之前最近的非 NULL。两种情况都保持不变量。遍历结束时所有行正确，且逐行追加保留顺序。

SQL 中，计数只在非 NULL 行增加。因此每一段恰从一个非 NULL 开始，到下一个非 NULL 之前结束；段首就是段内每个空行之前最近的有效来源。按段取首值与上述循环等价。

边界与复杂度

  • 只有一行、没有空值：每行原样返回；连续多个空值：共享同一来源。
  • 连续相同饮料也各自开启新段，输出不受影响。字符串空值 "" 仍是非 NULL。
  • 若扩展到首行 NULL，无法向前补出值；四语言参考保留前导 NULL。官方保证排除此情况，演示器拒绝它。
  • 空输入是扩展边界，四语言参考返回空结果；演示器只接受非空输入。
  • 有序数组扫描：时间 O(n)，除输出外额外空间 O(1)，输出占 O(n)。饮料长度按题目字段上限视为常数。
  • SQL 窗口通常需要排序，典型时间 O(n log n)、中间空间 O(n)，具体依赖优化器、索引和执行计划；不能一概声称 SQL 只需 O(n)。

替代方案

  • 支持 IGNORE NULLS 的方言可在从起点到当前行的窗口上取最后有效值。MySQL 8.0 不支持这种 NULL 忽略语法。
  • 段号形成后，也可在段内取 MAX(drink)：每段只有一个非 NULL 原始值。这与全表前缀 MAX 不同。
  • 有真实顺序键时，可用相关子查询查找前方最近的非 NULL 行；无合适索引时可能退化为 O(n²)。

常见错误

  • 只用一次 LAG(drink)：第二个连续空行看到的还是 NULL。
  • 按 id 排序：官方示例已说明 id 与输入顺序不同。
  • 直接对名称做累计 MAX：取到的是字典序最大名称，不是最近名称。
  • 使用 COUNT(*)：NULL 行也会增加段号，应使用 COUNT(drink)。
  • 用真假值判断名称：会错误忽略空字符串；必须显式判断 NULL。
  • 只给窗口排序而省略最终 ORDER BY：不能保证结果展示顺序。

面试追问

按门店分别填充？ 累计计数窗口按 shop_id 分区，取值窗口按 shop_id 与 grp 分区，每个门店定义稳定行序。

多列独立补全？ 每列维护各自的最近值或段号；一个列的有效值不应重置其他列。

流式数据怎么办？ 有序到达时只保留最近名称；乱序到达必须先定义排序、迟到数据和回填策略。

MySQL 8.0 · 题库形式（存在输入顺序假设）

可放入 MySQL 编辑器的完整查询；OVER () 的限制见上文，未验证平台提交结果。

-- Assumption: enumeration order matches the supplied row order.
-- For real data with input_pos, use OVER (ORDER BY input_pos).
WITH numbered AS (
    SELECT id, drink, ROW_NUMBER() OVER () AS rn
    FROM CoffeeShop
), grouped AS (
    SELECT id, drink, rn,
           COUNT(drink) OVER (
               ORDER BY rn
               ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
           ) AS grp
    FROM numbered
)
SELECT id,
       FIRST_VALUE(drink) OVER (
           PARTITION BY grp
           ORDER BY rn
           ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
       ) AS drink
FROM grouped
ORDER BY rn;

Java 17 · 本地语义参考

import java.util.ArrayList;
import java.util.List;

public class Solution {
    public record Row(int id, String drink) {}

    // rows must already be in the intended input order.
    public static List<Row> changeNullValues(List<Row> rows) {
        List<Row> result = new ArrayList<>(rows.size());
        String previous = null;
        for (Row row : rows) {
            if (row.drink() != null) previous = row.drink();
            result.add(new Row(row.id(), previous));
        }
        return result;
    }
}

JavaScript · 本地语义参考

// Input: ordered rows [[id, drink], ...]. Does not mutate input.
function changeNullValues(rows) {
  let previous = null;
  return rows.map(([id, drink]) => {
    if (drink !== null) previous = drink;
    return [id, previous];
  });
}

Python 3 · 本地语义参考（不是 Pandas 提交模板）

from typing import List, Optional, Tuple

Row = Tuple[int, Optional[str]]

def change_null_values(rows: List[Row]) -> List[Row]:
    previous = None
    result = []
    for order_id, drink in rows:
        if drink is not None:
            previous = drink
        result.append((order_id, previous))
    return result

C++17 · 本地语义参考

#include <optional>
#include <string>
#include <utility>
#include <vector>

using Row = std::pair<int, std::optional<std::string>>;

std::vector<Row> changeNullValues(const std::vector<Row>& rows) {
    std::optional<std::string> previous;
    std::vector<Row> result;
    result.reserve(rows.size());
    for (const auto& [id, drink] : rows) {
        if (drink.has_value()) previous = drink;
        result.emplace_back(id, previous);
    }
    return result;
}
