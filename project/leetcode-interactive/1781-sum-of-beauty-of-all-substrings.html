所有子字符串
美丽值之和

把每个子字符串放到“频次天际线”上：最高柱与最低非零柱之间的高度差，就是它的美丽值。

难度：中等非付费题参数：s: string返回：integer
Problem

题意

字符串的美丽值定义为：其中出现次数最多的字符频次，减去出现次数最少的字符频次。给定只包含小写英文字母的字符串 s，返回 s 的所有连续子字符串的美丽值总和。

“最少”只在出现过的字符中选择。频次为 0 的字母不参与最小值。例如 abaacc 中，a 出现 3 次，b 出现 1 次，c 出现 2 次，因此美丽值为 3 − 1 = 2。
beauty(t) = maxFreq(t)
− minPositiveFreq(t)

示例 1

输入s = "aabcb"
输出5
解释"aab"、"aabc"、"aabcb"、"abcb"、"bcb" 的美丽值均为 1，其余子字符串为 0。

示例 2

输入s = "aabcbaa"
输出17

Decoded

枚举左端点，增量维护频次

固定左端点后逐步扩展右端点，新加入一个字符时只需更新它的计数；再扫描 26 个字母得到当前子字符串的最大频次和最小非零频次。

核心洞察

所有子字符串都能由一对端点 (left, right) 唯一表示。固定 left 后，right 每右移一步，频次数组可以从上一个子字符串增量更新，而不必重新统计整个片段。

完整过程

  1. 枚举左端点 left，并清空 26 位频次数组。
  2. 让右端点 right 从 left 走到末尾，每次给 s[right] 的频次加 1。
  3. 扫描频次数组，求最大值与最小正数，将两者之差加入答案。

正确性说明

覆盖性：外层选定每个可能的左端点，内层遍历从该位置开始的每个右端点，因此每个连续子字符串恰好对应一次迭代，不重不漏。

统计正确：在固定左端点时，频次数组初始为 0；右端点每前进一步只新增当前字符，所以数组始终准确表示 s[left..right] 的字符频次。

贡献正确：扫描所有正频次得到定义要求的最大值与最小非零值，其差正是当前子字符串的美丽值。把所有迭代的贡献相加，即得到全部子字符串的美丽值总和。

边界情况

  • 长度为 1：最大频次与最小频次相同，贡献为 0。
  • 全部字符相同：每个子字符串都只有一种正频次，贡献均为 0。
  • 全部字符互异：各字符频次都是 1，贡献也均为 0。
  • 最小频次不能把尚未出现的字母的 0 算进去。

常见错误

  • 把子序列误当子字符串，枚举了不连续字符。
  • 直接取 26 位数组最小值，得到错误的 0。
  • 切换左端点时忘记清空频次数组。
  • 只统计不同内容的子字符串；题目要求按位置统计全部子字符串。
时间复杂度O(26 · n²) = O(n²)两层端点枚举，每个子字符串扫描固定大小字母表。
空间复杂度O(26) = O(1)频次数组大小与输入长度无关。

替代方案：前缀频次

可以为 26 个字母分别建立前缀计数，用两次前缀值之差得到任意子字符串的频次，再扫描字母表计算美丽值。时间仍为 O(26·n²)，空间变为 O(26·n)；它更适合需要反复随机查询某个区间频次的场景。本题按固定左端点扩展时，增量计数更直接且更省空间。

class Solution {
    public int beautySum(String s) {
        int answer = 0;

        for (int left = 0; left < s.length(); left++) {
            int[] frequency = new int[26];
            for (int right = left; right < s.length(); right++) {
                frequency[s.charAt(right) - 'a']++;

                int maximum = 0;
                int minimum = Integer.MAX_VALUE;
                for (int count : frequency) {
                    if (count > 0) {
                        maximum = Math.max(maximum, count);
                        minimum = Math.min(minimum, count);
                    }
                }
                answer += maximum - minimum;
            }
        }
        return answer;
    }
}

class Solution:
    def beautySum(self, s: str) -> int:
        answer = 0

        for left in range(len(s)):
            frequency = [0] * 26
            for right in range(left, len(s)):
                frequency[ord(s[right]) - ord("a")] += 1

                positive = [count for count in frequency if count > 0]
                answer += max(positive) - min(positive)

        return answer

面试追问

为什么不维护一个实时最小频次？

字符频次增加后，旧的最小值可能不再存在；维护频次的频次可以做到，但字母表只有 26 个，直接扫描更简单稳妥。

能否做到优于 O(n²)？

本题需要聚合所有 O(n²) 个子字符串的非线性频次极值，常规解法就是二次枚举；固定字母表扫描的常数很小。

若字符集很大怎么办？

用哈希表保存当前出现字符的计数；极值可扫描已出现项，或用额外有序结构维护，但更新逻辑会更复杂。

答案会溢出 int 吗？

在本题 n ≤ 500 的约束下，官方返回类型为整数，四份实现使用各语言常规整型即可；若约束显著扩大，应改用 64 位整数。
