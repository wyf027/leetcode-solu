螺旋矩阵 III

从一个格子出发，向东迈步，在无限平面上画出不断扩张的顺时针螺旋；只有落回网格时，才把坐标收入答案。

中等ArrayMatrixSimulation非付费题
步长 1, 1, 2, 2…
01 / 题目

先理解行走规则

重点不是“只在矩阵里走”，而是在无限平面上持续走；越界的脚步照常发生，只是不计入结果。

题意转述

给定一个 rows × cols 网格，左上角坐标为 (0, 0)。你从网格内的 (rStart, cStart) 出发，初始面朝东，以顺时针螺旋路线移动，直到访问完网格内全部 rows × cols 个位置。

越界也要继续：路径可以走到网格外，之后再回到网格中。请只按首次走到网格内位置的先后顺序，返回所有坐标。

函数形式：

spiralMatrixIII(rows, cols, rStart, cStart) → int[][]

约束

  • 1 ≤ rows, cols ≤ 100
  • 0 ≤ rStart < rows
  • 0 ≤ cStart < cols

返回值

长度恰为 rows × cols 的二维坐标数组，每项为 [row, col]。

官方示例

示例 1

输入：rows = 1, cols = 4, rStart = 0, cStart = 0

输出：[[0,0],[0,1],[0,2],[0,3]]

示例 2

输入：rows = 5, cols = 6, rStart = 1, cStart = 4

输出：[[1,4],[1,5],[2,5],[2,4],[2,3],[1,3],[0,3],[0,4],[0,5],[3,5],[3,4],[3,3],[3,2],[2,2],[1,2],[0,2],[4,5],[4,4],[4,3],[4,2],[4,1],[3,1],[2,1],[1,1],[0,1],[4,0],[3,0],[2,0],[1,0],[0,0]]

03 / 题解

准备好后，再揭开规律

先用演示观察每两个方向后的变化。题解保持收起，不会在首屏直接泄露。

核心提示：关注每一段的长度

你能写出前八段移动长度吗？

核心洞察

方向循环，步长每两段加一

① 固定方向

始终按东、南、西、北循环，天然形成顺时针转向。

② 扩张步长

每段长度依次为 1、1、2、2、3、3……每完成两段就加一。

③ 只筛选，不截断

每迈一步都更新坐标；仅当坐标在网格内时追加到答案。

完整过程

记录起点

题目保证起点在网格内，所以答案先加入 [rStart, cStart]。

走两段相同长度

先向当前方向走 stepLen 步，再右转；重复两次。

扩大外圈

两段完成后令 stepLen++，继续下一对方向。

收满即停

每步都做边界判断，答案长度达到 rows × cols 时立即返回。

正确性说明

路径一致性：方向按东南西北循环，且段长为 1,1,2,2,…，因此生成的正是以起点为中心不断向外扩张的顺时针方形螺旋。记录准确性：算法对路径上的每一个位置做且只做一次边界判断，网格内位置按到达顺序加入，网格外位置忽略。必然结束：螺旋包围的方形边界持续扩大，最终会覆盖有限网格中的每个格子；收集到 rows × cols 个坐标后返回。因此结果完整且顺序正确。

边界与复杂度

单行、单列、起点位于角落都无需特判。越界距离可能较长，但不能跳过路径推进；只要答案未满就继续。

时间：O(max(rows, cols)²)
返回数组外空间：O(1)
结果空间：O(rows × cols)

说明：最坏情况下需走完一个边长与最大维度同阶的外接方形；若把输出本身计入空间，则总空间为 O(rows × cols)。

四语言完整实现

class Solution {
    public int[][] spiralMatrixIII(int rows, int cols, int rStart, int cStart) {
        int[][] answer = new int[rows * cols][2];
        int[][] directions = {{0, 1}, {1, 0}, {0, -1}, {-1, 0}};
        int count = 0;
        int row = rStart, col = cStart;
        answer[count++] = new int[]{row, col};

        for (int stepLen = 1, direction = 0; count < rows * cols; stepLen++) {
            for (int segment = 0; segment < 2; segment++, direction = (direction + 1) % 4) {
                for (int step = 0; step < stepLen; step++) {
                    row += directions[direction][0];
                    col += directions[direction][1];
                    if (0 <= row && row < rows && 0 <= col && col < cols) {
                        answer[count++] = new int[]{row, col};
                        if (count == rows * cols) return answer;
                    }
                }
            }
        }
        return answer;
    }
}

var spiralMatrixIII = function(rows, cols, rStart, cStart) {
    const answer = [[rStart, cStart]];
    const directions = [[0, 1], [1, 0], [0, -1], [-1, 0]];
    let row = rStart;
    let col = cStart;
    let direction = 0;

    for (let stepLen = 1; answer.length < rows * cols; stepLen++) {
        for (let segment = 0; segment < 2; segment++) {
            const [dr, dc] = directions[direction];
            for (let step = 0; step < stepLen; step++) {
                row += dr;
                col += dc;
                if (row >= 0 && row < rows && col >= 0 && col < cols) {
                    answer.push([row, col]);
                    if (answer.length === rows * cols) return answer;
                }
            }
            direction = (direction + 1) % 4;
        }
    }
    return answer;
};

class Solution:
    def spiralMatrixIII(
        self, rows: int, cols: int, rStart: int, cStart: int
    ) -> List[List[int]]:
        answer = [[rStart, cStart]]
        directions = ((0, 1), (1, 0), (0, -1), (-1, 0))
        row, col = rStart, cStart
        direction = 0
        step_len = 1

        while len(answer) < rows * cols:
            for _ in range(2):
                dr, dc = directions[direction]
                for _ in range(step_len):
                    row += dr
                    col += dc
                    if 0 <= row < rows and 0 <= col < cols:
                        answer.append([row, col])
                        if len(answer) == rows * cols:
                            return answer
                direction = (direction + 1) % 4
            step_len += 1

        return answer

替代方案

  • 按环公式生成：可以直接枚举每一圈的四条边，但边界和段长下标更容易写错。
  • 逐步模拟：状态最少、逻辑最贴合题意，也是面试中更稳妥的方案。

常见错误

  • 一越界就转向，误把网格边界当作螺旋边界。
  • 每段都增加步长，写成 1、2、3、4，而非 1、1、2、2。
  • 忘记先记录起点，或在答案收满后仍继续写入。

面试追问

  • 为什么答案外的额外空间可以是 O(1)？
  • 怎样证明螺旋最终一定覆盖矩阵四角？
  • 若要求逆时针且初始向北，需要改哪些常量？

边界清单

  • 1 × 1：起点即完整答案。
  • 单行/单列：路径仍会在外部绕行后回来。
  • 角落起步：最初几步可能大多越界，照常推进。
