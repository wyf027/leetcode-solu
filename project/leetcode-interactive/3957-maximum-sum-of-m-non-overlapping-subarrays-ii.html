M 个非重叠子数组最大和 II

把“最后一段从哪里开始”的长度窗口，压缩为一个持续滑动的最大值队列。

题意

给定整数数组 nums 与整数 m、l、r。选择至少一个、至多 m 个互不重叠子数组，每段长度属于 [l,r]，最大化所有选中元素之和。

示例 1

nums = [4,1,-5,2]
m = 2, l = 1, r = 3
输出：7

示例 2

nums = [1,0,3,4]
m = 2, l = 1, r = 2
输出：8

约束：1 ≤ n ≤ 10^5；-10^5 ≤ nums[i] ≤ 10^5；1 ≤ m ≤ n；1 ≤ l ≤ r ≤ n。即使全为负数，也必须选择至少一段。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补

题解：O(mn) 滑动窗口最大值

核心洞察：固定选段数 t 和右端前缀 i，若最后一段从 j 开始，则候选值为 prev[j] - pre[j] + pre[i]，其中 j ∈ [i-r, i-l]。随 i 右移，候选 prev[j]-pre[j] 正好是滑动窗口最大值。

完整过程

1

状态

prev[i] 表示在前 i 个元素中恰好选 t-1 段的最大和；cur[i] 对应恰好选 t 段。

2

加入候选

处理右端 i 时，把新起点 j=i-l 的值 prev[j]-pre[j] 加入递减队列。

3

移出过期起点

队首若小于 i-r，对应区间已经过长，必须弹出。

4

两类转移

cur[i] = max(cur[i-1], pre[i] + queue.max)：前者跳过位置 i-1，后者让一段在这里结束。

复杂度

每个索引每轮最多入队、出队一次，时间 O(mn)；滚动 DP、前缀和与队列空间 O(n)。

边界

不可达状态用负无穷；答案要对恰好选 1..m 段取最大，不能把“空选 0”混入答案。

替代方案

枚举最后一段长度是 O(mn(r-l+1))，只适合规模较小的 I。

常见错误

  • 先取队首再删除过期索引。
  • 把 cur 初始化为 0，导致全负数组错误空选。
  • 只返回恰好选 m 段。
面试追问：若每段还有固定费用 fee，只需把新段转移减去 fee；若长度集合不连续，单调队列不再直接适用。
