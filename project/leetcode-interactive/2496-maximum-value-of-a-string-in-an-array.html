数组中字符串的最大值

Maximum Value of a String in an Array

同样是字符串，值却有两种定义。先读规则，试着判断哪一项最大。

前往 LeetCode 原题 ↗

01 / 题意与输入

给定字符串数组 strs。每个字符串只含小写英文字母和数字，按以下规则确定它的值，返回数组里最大的那个值：

  • 全部字符都是数字：值为它表示的十进制整数。
  • 包含任意字母：值为字符串的字符数。

参数：strs（字符串数组）　返回：integer（整数）。这里求的是数值最大值，不是字典序最大的字符串。

约束

  • 1 <= strs.length <= 100
  • 1 <= strs[i].length <= 9
  • strs[i] 只含 a–z 和 0–9。

示例 1

输入：strs = ["alic3","bob","3","4","00000"]
输出：5

各项的值依次为 5、3、3、4、0；其中 “alic3” 的长度为 5，取得最大值。

示例 2

输入：strs = ["1","01","001","0001"]
输出：1

前导零不改变十进制数值，四个字符串的值都是 1。

下面包含逐字符演示、推导和四种语言代码。

核心洞察：先确定值，再更新最大值

每个字符串的值只由它自己决定。扫描字符时维护十进制累积值：value = value * 10 + digit。一旦遇到字母，之前累积的数值就不再有意义，直接改用整个字符串的长度并结束本项扫描。

每处理完一个字符串，执行 best = max(best, value)。所有值均非负，因此 best 从 0 开始。

完整过程

  1. 把答案 best 设为 0。
  2. 取出下一个字符串，将本项的 value 置 0。
  3. 从左到右扫描：数字就乘 10 加当前数字；遇到字母就把 value 设为字符串长度，然后跳出内层循环。
  4. 用本项的值更新 best，继续下一项。
  5. 所有字符串处理完成后返回 best。

例如 “123a”：前缀数值依次为 1、12、123；读到 a 后改为长度 4。此时不能把 123 拿来比较。对于 “001”，累积值依次为 0、0、1。

正确性说明

单项定值：扫描数字前缀后，累积器等于该前缀的十进制数值，因为追加一位就是原数乘 10 再加该位。若全部扫描完而未遇字母，所得数值符合定义；若遇字母，整个字符串不再是纯数字，直接使用长度符合另一条定义，剩余字符不影响这个结论。

全局不变量：处理完前 k 项后，best 等于这 k 项的最大值（k = 0 时使用非负值的下界 0）。下一项被正确求值后，取二者最大值即可保持不变量。循环结束时 k 等于数组长度，因此返回值就是所求。

复杂度

令 n 为字符串数，L 为最长字符串长度，S 为所有字符串长度之和。最坏时间 O(S) = O(nL)，额外空间 O(1)。本题 L ≤ 9，因此也可写成 O(n)。遇字母可提前结束本项。交互演示为回退保存快照，其额外开销不属于提交算法。

边界

  • 全零字符串值为 0，答案不能用字符串长度初始化。
  • 前导零不改变值，九位纯数字最大为 999999999，Java/C++ 的 32 位有符号整数可容纳，JavaScript Number 也可精确表示。
  • 首位或末位字母都意味着使用完整长度；纯字母字符串同理。
  • 数组非空，字符串非空，题内无需处理空串或负号。演示输入会按官方约束拒绝这些内容。

替代方案

先用完整匹配 ^[0-9]+$ 判断，再转换整数或取长度，也很直接；它可能扫描两遍，但仍是 O(S)。先收集所有值再求最大值需要额外 O(n) 存储，没有必要。排序会增加到 O(n log n) 次比较，也不适合只求最大值。

常见错误

  • 用字符串字典序比较：“9” 会排在 “10” 后面，但数值小于 10。
  • 直接用 parseInt("123a")：会接受数字前缀，得到 123，而正确值为 4。
  • 只要含数字就转换：必须是全部字符都为数字。
  • 遇字母后仍继续累积，或每项开始时忘记清零。

面试追问

  • 字符串变得非常长怎么办？纯数字值可能溢出，需要大整数；或去除前导零后先比较位数、再比较字典序，并统一与长度候选的表示。
  • 还要返回最大值所在下标？更新最大值时记录下标，先约定并列时保留第一个还是最后一个。
  • 输入以流到达？处理完一项立即更新答案，无需保留整个数组。

四语言提交代码

统一使用逐字符累积与字母提前结束；代码尚未执行验证。

Java

class Solution {
    public int maximumValue(String[] strs) {
        int best = 0;
        for (String s : strs) {
            int value = 0;
            for (int i = 0; i < s.length(); i++) {
                char c = s.charAt(i);
                if (c < '0' || c > '9') {
                    value = s.length();
                    break;
                }
                value = value * 10 + (c - '0');
            }
            best = Math.max(best, value);
        }
        return best;
    }
}

from typing import List

class Solution:
    def maximumValue(self, strs: List[str]) -> int:
        best = 0
        for s in strs:
            value = 0
            for c in s:
                if not ('0' <= c <= '9'):
                    value = len(s)
                    break
                value = value * 10 + int(c)
            best = max(best, value)
        return best

        for (const string& s : strs) {
