长度为三且各字符不同的子字符串

Substrings of Size Three with Distinct Characters

连续的三个字符，有多少次互不相同？先读题并预测，再开启观察。

01 / 题目任务

给定字符串 s，返回其中长度恰好为 3、内部没有重复字符的连续子字符串数量。相同内容在不同位置出现时，每一次都要计数。

子字符串必须连续，不能跳过字符拼接。

参数与约束

  • 参数：s: string；返回：整数。
  • 1 ≤ s.length ≤ 100。
  • s 只包含小写英文字母。

输出：1

04 / 独立题解

完成自己的思考后，再展开推导与代码。

核心洞察：三个字符，三组比较

设窗口内字符为 a、b、c。它们互不相同，当且仅当 a != b、a != c、b != c 同时成立。长度固定为 3，无须额外维护哈希表。

完整过程

  1. 计数 answer 初始化为 0。
  2. 从 i = 0 开始，保持 i + 2 < n，读取 s[i]、s[i+1]、s[i+2]。
  3. 三组比较都不相等时，answer 增加 1。
  4. 起点 i 每次增加 1，直到没有完整窗口，返回 answer。

xyzzaz 的四步分别是：xyz 合法，累计 1；yzz 重复，累计 1；zza 重复，累计 1；zaz 首尾相同，累计 1。窗口可以重叠，不按内容去重。

正确性

判定等价：三个位置共有三对不同位置。所有配对均不相等，等价于不存在重复字符，故当前窗口的判定准确。

循环不变式：处理起点 i 前，answer 正好等于起点位于 [0,i) 的合法窗口数。初始没有处理窗口，计数 0 正确。每步仅在当前窗口合法时增加 1，因此保持不变式。

终止：每个长度为 3 的子字符串出现位置都对应唯一的合法起点，循环不重不漏地遍历全部起点。结束时 answer 即所有合法出现次数。

边界与复杂度

  • n < 3：循环不进入，答案 0；n = 3：只检查一个窗口。
  • 首尾重复也不合法；相同内容出现在不同位置要重复计数。
  • 答案范围为 0 到 max(0,n−2)；长度 100 最多得到 98。
  • 时间 O(n)，每个窗口最多做三次比较；额外空间 O(1)。演示页面的记录不属于提交算法的空间开销。

替代方案

每个三字符窗口创建一个集合，集合大小为 3 就计数，同样是 O(n) 时间、O(1) 额外空间，但存在重复分配的开销。若长度推广为 k，可用滑动窗口维护字符频次和不同字符数，每步更新移入、移出的字符；小写字母表下时间 O(n)、额外空间 O(26)。

四语言完整代码

使用官方函数签名，可用于对应语言提交；仅生成，尚未编译或执行。

Java

class Solution {
    public int countGoodSubstrings(String s) {
        int answer = 0;
        for (int i = 0; i + 2 < s.length(); i++) {
            char a = s.charAt(i);
            char b = s.charAt(i + 1);
            char c = s.charAt(i + 2);
            if (a != b && a != c && b != c) {
                answer++;
            }
        }
        return answer;
    }
}

C++

#include <string>
using std::string;

class Solution {
public:
    int countGoodSubstrings(string s) {
        int answer = 0;
        int n = static_cast<int>(s.size());
        for (int i = 0; i + 2 < n; ++i) {
            char a = s[i], b = s[i + 1], c = s[i + 2];
            if (a != b && a != c && b != c) {
                ++answer;
            }
        }
        return answer;
    }
};

常见错误

  • 只比较相邻字符会漏掉 aba 的首尾重复。
  • 对窗口内容去重会漏计多次出现的 abc。
  • 每次移动三格会漏掉重叠窗口，应只移动一格。
  • 循环边界应保证 i+2 < n，既不越界也不遗漏末尾窗口。
  • C++ 中无符号 size() 直接减 2 可能下溢；代码先转为 int，再使用安全条件。

面试追问

推广到长度 k？维护频次数组和不同字符数；窗口长度达到 k 且不同字符数为 k 时计数。只有 26 个小写字母时，k > 26 的答案必为 0。

输入是字符流？只需保留最近两个字符，与新字符组成窗口，仍是常数额外空间。

如果只统计不同内容？把合法窗口放入集合，最终返回集合大小；这是另一种计数要求。

如果包含 Unicode？先明确“字符”指码点还是用户感知字符，再选择相应分割方式；本题小写英文字母约束下可直接下标访问。
