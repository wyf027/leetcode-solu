01 / PROBLEM

题目要你做什么

输入整数数组 books，下标从 0 开始，books[i] 是第 i 个书架的库存。选择连续区间 [l, r]，从各架取书，数量不能超过库存；区间内相邻两架的取书数必须满足左边严格小于右边。返回可拿走的最大总数。

可以只选一个书架。空库存也可能出现；全为 0 时答案是 0。有效取书区间可去掉最左端的 0，因此推导时只统计正数取书段。

输入books: integer[]1 ≤ books.length ≤ 100,000
输出maximumBooks(books) → long0 ≤ books[i] ≤ 100,000

04 / SOLUTION

把取书阶梯，接在已经算好的前缀上

核心洞察 · 固定右端点

设右端点为 i。最优方案一定可以把第 i 架拿满；向左每一步取 min(books[k], 右邻取书数 − 1)，直到数量不再为正。库存充足时形成公差为 1 的阶梯；遇到更低库存时，阶梯被截断并向下平移。

从 i 向左延伸的理想高度是 books[i] − (i − k)。第一处低于该高度的书架 j 满足：

books[j] < books[i] − (i − j)
⇔ books[j] − j < books[i] − i

所以维护 key[k] = books[k] − k 的严格递增栈，寻找左边最近的更小值。栈顶 key 大于或等于当前 key 就弹出。剩下的栈顶 j 是连接点：它右侧可直接按等差数列求和，左侧复用 dp[j]。

完整过程与状态定义

dp[i] 表示以 i 为最右端的最优取书总数；当 books[i]=0 时用 0 作为空段哨兵。正库存的最优段必定取满该右端点。

  1. 从左到右枚举 i，计算 key = books[i] − i。
  2. 不断弹出 key 大于或等于当前 key 的栈顶，留下最近的严格更小位置 j；没有则 j = −1。
  3. 令 count = min(books[i], i − j)，仅统计正数阶梯项，避免取出 0 或负数。
  4. 阶梯和 sum = count × (2 × books[i] − count + 1) / 2。
  5. dp[i] = sum + (j == −1 ? 0 : dp[j])；更新答案，再将 i 入栈。
示例 1：books = [8,5,2,7,9]
key             = [8,4,0,4,5]
最近更小的 j    = [-1,-1,-1,2,3]
dp              = [8,9,3,10,19]
最终取书        = [0,1,2,7,9]，总数 19

i=2 时，前两个候选弹出，长度被库存 2 截为 2，形成 [1,2]；i=3 连接 dp[2] 并增加 7；i=4 连接 dp[3] 并增加 9。这里的 [0,1,2,7,9] 用 0 标记未选架，实际正数区间为 [1,4]。

为什么正确

  1. 固定终点的贪心最优。取满右端不会妨碍左边；向左每次取允许的最大值，只会放宽更左边的上限。逐个位置得到最大可行取法。
  2. 阶梯段可行且达到上界。最近更小位置 j 之后的库存都不低于理想阶梯；严格递增限制又使这些高度成为上界，因此取阶梯是最优的。
  3. 连接前缀合法。j 的库存严格低于阶梯延伸到 j 的高度，所以取满 j 后仍小于 j+1 的取量；左边正好等同于以 j 结尾的子问题。j 为零库存时 dp[j]=0，从其右侧开始即可。
  4. 截断不漏解。无连接点时，阶梯达到 0 就不能再向左取正数。若 j 存在，非负库存与严格更小条件保证阶梯能一直覆盖到 j+1。
  5. 栈不漏瓶颈。被当前 i 弹掉的位置 p 更靠左且 key[p] ≥ key[i]；以后若 p 足够小，i 也足够小且更近，因此 p 不可能再成为最近瓶颈。遍历所有右端点并取最大值，覆盖全局最优。

边界与复杂度

  • 全零：count 和 dp 都是 0，答案为 0。
  • 单架：直接取该架全部库存。
  • 相同库存：不能全拿；如 [2,2,2] 最多取 [1,2]。
  • 等 key：弹栈用 ≥，保持严格更小的边界定义。
  • 零库存：切断左侧正数区间，dp=0 可作为后续连接哨兵。
  • 总数可达 5,000,050,000；Java 用 long，C++ 用 long long。JavaScript Number 可精确表示本题全部整数，勿用位运算取整。
时间 O(n)，空间 O(n)

每个下标最多入栈一次、出栈一次。dp 与栈各占 O(n)。演示为支持回退而保存帧，并重建少量取书柱；其额外开销不属于提交算法。

Java

class Solution {
    public long maximumBooks(int[] books) {
        int n = books.length;
        int[] stack = new int[n];
        int size = 0;
        long[] dp = new long[n];
        long answer = 0;
        for (int i = 0; i < n; i++) {
            while (size > 0 &&
                   books[stack[size - 1]] - stack[size - 1] >= books[i] - i) {
                size--;
            }
            int j = size == 0 ? -1 : stack[size - 1];
            long count = Math.min(books[i], i - j);
            long sum = count * (2L * books[i] - count + 1) / 2;
            dp[i] = sum + (j == -1 ? 0 : dp[j]);
            answer = Math.max(answer, dp[i]);
            stack[size++] = i;
        }
        return answer;
    }
}

/**

var maximumBooks = function(books) {
    const dp = Array(books.length).fill(0);
    const stack = [];
    let answer = 0;
    for (let i = 0; i < books.length; i++) {
        while (stack.length) {
            const top = stack[stack.length - 1];
            if (books[top] - top < books[i] - i) break;
            stack.pop();
        }
        const j = stack.length ? stack[stack.length - 1] : -1;
        const count = Math.min(books[i], i - j);
        const sum = count * (2 * books[i] - count + 1) / 2;
        dp[i] = sum + (j === -1 ? 0 : dp[j]);
        answer = Math.max(answer, dp[i]);
        stack.push(i);
    }
    return answer;
};

Python

from typing import List

class Solution:
    def maximumBooks(self, books: List[int]) -> int:
        dp = [0] * len(books)
        stack = []
        answer = 0
        for i, value in enumerate(books):
            while stack and books[stack[-1]] - stack[-1] >= value - i:
                stack.pop()
            j = stack[-1] if stack else -1
            count = min(value, i - j)
            total = count * (2 * value - count + 1) // 2
            dp[i] = total + (dp[j] if j != -1 else 0)
            answer = max(answer, dp[i])
            stack.append(i)
        return answer

C++

#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    long long maximumBooks(vector<int>& books) {
        int n = static_cast<int>(books.size());
        vector<int> stack;
        vector<long long> dp(n);
        long long answer = 0;
        for (int i = 0; i < n; ++i) {
            while (!stack.empty() &&
                   books[stack.back()] - stack.back() >= books[i] - i) {
                stack.pop_back();
            }
            int j = stack.empty() ? -1 : stack.back();
            long long count = min(books[i], i - j);
            long long sum = count * (2LL * books[i] - count + 1) / 2;
            dp[i] = sum + (j == -1 ? 0 : dp[j]);
            answer = max(answer, dp[i]);
            stack.push_back(i);
        }
        return answer;
    }
};

替代方案

枚举右端 + 向左贪心：每个右端逐架计算 min(库存, 右邻取量−1) 并累加，遇到非正数停止。实现直观，最坏 O(n²) 时间、O(1) 额外空间，适合小规模理解，n=10⁵ 时不合适。

区间最小值结构：维护 key 的线段树，向右优先查找左侧最后一个小于当前 key 的位置，再用同样 DP；可达 O(n log n) 时间、O(n) 空间。本题无动态更新，单调栈更直接。

常见错误

  • 按 books 的原值维护栈，漏掉位置距离；应比较 books[i]−i。
  • 把严格递增误当成全段公差为 1；只有不受库存截断的局部段才是阶梯。
  • 忘记 count ≤ books[i]，把非正数项计入总和。
  • 只返回最后一项 dp，错过中间结束的最优区间。
  • 先用 32 位数乘完再转 long，溢出已发生；乘法前就要提升类型。
  • 用普通子序列选法跨过零库存，违反连续区间要求。

面试追问

如何返回实际取书方案？记录最大 dp 对应的右端点，最后从该点向左按贪心恢复，直到不能取正数；额外 O(n) 时间。

如果相邻至少相差 d 本？对固定正整数 d，改用 key[i]=books[i]−d×i；正数项数为 min(i−j, floor((books[i]−1)/d)+1)，零库存单独令项数为 0，等差数列公差也改为 d。

能否在线追加书架？可以把每个栈元素存为 (下标、库存、dp)，追加时仍按同一规则弹栈并计算；每次追加摊还 O(1)，最坏累计空间 O(n)。
