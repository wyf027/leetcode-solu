子数组的最大频率分数

Maximum Frequency Score of a Subarray

同样长度的片段，重复次数会怎样改变得分？先理解定义，再探索过程。

01题目

给定整数数组 nums 和正整数 k。对于一个连续片段，每个不同数字 x 只贡献一项：若它出现 c 次，该项为 xᶜ。所有项相加后对 M = 1,000,000,007 取模，得到频率分数。

在 nums 中，求所有长度恰好为 k 的连续子数组的分数最大值。比较的是各片段取模之后的分数。

score(W) = (Σ xcountW(x)) mod M　（仅累加 W 中实际出现的 x）

参数：maxFrequencyScore(nums: integer[], k: integer) → integer

官方示例 1

输入：nums = [1,1,1,2,1,2], k = 3
输出：5

片段 [2,1,2] 的分数为 2² + 1¹ = 5，是所有合法片段中的最高值。

官方示例 2

输入：nums = [1,1,1,1,1,1], k = 4
输出：1

每个合法片段只有数字 1，分数均为 1⁴ = 1。

约束

  • 1 ≤ k ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁶

04独立题解

核心洞察、证明与四种语言实现。

核心洞察：保存每层幂，撤销时直接退一层

窗口向右移动时，只有移出、移入两个值的频次可能改变。为每个当前出现的数字 x 保存栈 [0, x mod M, x² mod M, …, xᶜ mod M]，栈顶就是贡献。加一个 x，只需用旧栈顶乘 x 并取模；删一个 x，弹出栈顶即可。首次加入直接压入 x。这样每次更新无需重新快速幂，也无需模逆元。

S ← (S − oldTop + newTop + M) mod M

完整过程

  1. 初始化空哈希表、当前分数 S = 0、最大值 ans = 0。
  2. 扫描右端点 r。如果 r ≥ k，先移出 nums[r−k]：取旧栈顶、弹栈、读取新栈顶，替换贡献；只剩哨兵 0 时删除该键。
  3. 加入 nums[r]：不存在则建立 [0]；首次贡献为 x，否则为 top × x mod M。压入新贡献，再更新 S。
  4. 当 r ≥ k−1 时，窗口恰好长 k，用已规范化到 [0,M) 的 S 更新 ans。

示例 1 的四个完整窗口分数依次是 1、3、3、5。第二次滑动移出与移入的数字都是 1，弹栈再压栈恢复相同频次，得分仍是 3。无需特殊分支。

正确性证明

幂栈不变量：一个数字当前出现 c 次时，其栈有 c+1 层，第 j≥1 层等于 xʲ mod M。空状态用哨兵表示。首次入栈正确建立 x¹，后续乘 x 建立下一层，弹栈恢复前一层，故不变量由归纳成立。

分数不变量：S 是所有栈顶之和模 M。每次仅用新栈顶替换旧栈顶，其他项不变，因此 S 始终等于当前片段的定义分数。频次降到 0 时栈顶为 0，不会多算 x⁰。

覆盖与最优性：每轮先删过期左端点再加入右端点。首次达到 k 后，每个长度为 k 的连续窗口恰好记录一次。ans 对所有这些模后分数取最大，故返回题目要求的答案。

复杂度与数值边界

哈希操作期望 O(1)，动态数组压入为摊还 O(1)。每个元素最多压入、弹出一次，因此总时间期望 O(n)，辅助空间 O(k)：所有有效幂层总数不超过 k，每个活跃值再占一个哨兵；空栈立刻删除。此结论采用固定宽度模运算的常见计费方式。

栈顶小于 M，乘数不超过 10⁶，乘积小于约 10¹⁵，Java 的 long 和 C++ 的 long long 足够。JavaScript 的 Number 无法保证该范围内所有乘法都精确，代码使用 BigInt；Python 整数可精确计算。各语言都把相减结果规范化为非负余数。

边界与常见错误

  • k=1 比较各个元素；k=n 只记录一个窗口；最小输入 nums=[1], k=1 返回 1。
  • 频次从 1 降到 0 必须贡献 0，不能留下 x⁰=1。数字 x=1 也必须保留频次层数，不能按相同幂值合并栈层。
  • 不要累加每次出现的数字各自的幂；每个不同值只取一项。不要用“最高频次”替代本题分数。
  • 不能先比较未取模的大整数再对最大值取模；取模不保持大小顺序。不能排序数组，连续片段的定义依赖原顺序。
  • 移出和移入相同可以照常执行；只在移除与加入都完成后记录答案。部分窗口分数不参与最大值。
  • 删除空栈，避免空间随历史出现过的不同值累积到 O(n)。不要用普通整数除法撤销已经取模的乘法。

替代方案

频次表 + 快速幂：每次变更重新计算旧、新幂，时间 O(n log(k+1))，空间 O(k)，思路直接但重复计算更多。也可为每个值预计算模逆元，以乘逆元撤销一层；需要值与模数互质，本题满足该条件，但实现和解释更复杂。逐窗口重建频次并计算幂适合小数据参考，最坏 O(nk log(k+1))。

面试追问

  • 模数不是质数还能使用幂栈吗？可以，幂栈只用乘法和已保存的历史层，不需要逆元。
  • 可以支持 nums[i]=0 吗？幂栈仍能处理，因为首次贡献直接设为 0，且按栈长度区分频次；逆元方案无法直接处理 0。
  • 如果窗口长度可变呢？维护贡献的增删操作仍可复用，但模后分数没有单调性，不能据分数大小贪心移动双指针。
  • 可以减少每个值的存储吗？仅维护当前幂加模逆元可减少幂层，但要付出逆元计算、缓存与适用条件的成本。

Java

import java.util.ArrayList;
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int maxFrequencyScore(int[] nums, int k) {
        final long MOD = 1_000_000_007L;
        Map<Integer, ArrayList<Long>> stacks = new HashMap<>();
        long score = 0, answer = 0;
        for (int r = 0; r < nums.length; r++) {
            if (r >= k) {
                int x = nums[r - k];
                ArrayList<Long> s = stacks.get(x);
                long old = s.remove(s.size() - 1);
                long next = s.get(s.size() - 1);
                score = (score - old + next + MOD) % MOD;
                if (s.size() == 1) stacks.remove(x);
            }
            int x = nums[r];
            ArrayList<Long> s = stacks.get(x);
            if (s == null) {
                s = new ArrayList<>();
                s.add(0L);
                stacks.put(x, s);
            }
            long old = s.get(s.size() - 1);
            long next = s.size() == 1 ? x : old * x % MOD;
            s.add(next);
            score = (score - old + next + MOD) % MOD;
            if (r >= k - 1) answer = Math.max(answer, score);
        }
        return (int) answer;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var maxFrequencyScore = function(nums, k) {
    const MOD = 1000000007n;
    const stacks = new Map();
    let score = 0n, answer = 0n;
    for (let r = 0; r < nums.length; r++) {
        if (r >= k) {
            const x = nums[r - k];
            const s = stacks.get(x);
            const old = s.pop();
            score = (score - old + s[s.length - 1] + MOD) % MOD;
            if (s.length === 1) stacks.delete(x);
        }
        const x = nums[r];
        if (!stacks.has(x)) stacks.set(x, [0n]);
        const s = stacks.get(x);
        const old = s[s.length - 1];
        const next = s.length === 1 ? BigInt(x) : old * BigInt(x) % MOD;
        s.push(next);
        score = (score - old + next + MOD) % MOD;
        if (r >= k - 1 && score > answer) answer = score;
    }
    return Number(answer);
};

Python

from typing import List

class Solution:
    def maxFrequencyScore(self, nums: List[int], k: int) -> int:
        mod = 1_000_000_007
        stacks = {}
        score = answer = 0
        for r, x in enumerate(nums):
            if r >= k:
                leaving = nums[r - k]
                s = stacks[leaving]
                old = s.pop()
                score = (score - old + s[-1]) % mod
                if len(s) == 1:
                    del stacks[leaving]
            if x not in stacks:
                stacks[x] = [0]
            s = stacks[x]
            old = s[-1]
            new = x if len(s) == 1 else old * x % mod
            s.append(new)
            score = (score - old + new) % mod
            if r >= k - 1:
                answer = max(answer, score)
        return answer

C++

#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int maxFrequencyScore(vector<int>& nums, int k) {
        const long long MOD = 1000000007LL;
        unordered_map<int, vector<long long>> stacks;
        long long score = 0, answer = 0;
        for (int r = 0; r < static_cast<int>(nums.size()); ++r) {
            if (r >= k) {
                int x = nums[r - k];
                auto& s = stacks.at(x);
                long long old = s.back();
                s.pop_back();
                score = (score - old + s.back() + MOD) % MOD;
                if (s.size() == 1) stacks.erase(x);
            }
            int x = nums[r];
            auto& s = stacks[x];
            if (s.empty()) s.push_back(0);
            long long old = s.back();
            long long next = s.size() == 1 ? x : old * x % MOD;
            s.push_back(next);
            score = (score - old + next + MOD) % MOD;
            if (r >= k - 1) answer = max(answer, score);
        }
        return static_cast<int>(answer);
    }
};
