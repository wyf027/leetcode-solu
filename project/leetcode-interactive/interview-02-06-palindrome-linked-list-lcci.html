回文链表

不借助数组，把链表沿中点“折叠”：翻转后半段，让两侧节点像书页一样逐对贴合。 最后再把装订线复原，调用者看到的链表仍保持原样。

简单 双指针 原地反转 O(n) / O(1)
1 2 3 2 1

题意

检查链表是否正反一致

给定单链表头节点 head，若从头到尾读取的值与从尾到头完全相同，返回 true；否则返回 false。进阶要求使用线性时间和常数额外空间。

示例 1

输入
head = [1, 2]
输出
false

示例 2

输入
head = [1, 2, 2, 1]
输出
true

目标

不复制节点值；只改变少量指针。比较结束后恢复后半段，避免函数留下隐藏副作用。

题解

先自己推一遍，再揭开装订线

核心洞察

只需让两半方向一致

快慢指针定位前半段末尾；反转后半段后，从链头和反转后的链头同步前进。右侧长度不超过左侧，所以只需遍历右侧。

复杂度

时间 O(n)，空间 O(1)

找中点、反转、比较、恢复均为线性扫描，常数次访问每个节点；只使用若干指针变量。

边界

  • 空链或单节点天然回文。
  • 奇数长度时中点留在前半段，不参与成对比较。
  • 偶数长度时两半长度相等。
  • 即使发现不匹配，也先恢复链表再返回。

替代方案

  • 数组收集节点值后双指针判断：直观，但需 O(n) 空间。
  • 栈保存前半段：仍需 O(n) 空间。
  • 递归左右配对：代码巧妙，但递归栈最坏 O(n)。

完整过程

  1. 1. 找中点
    slow 一步、fast 两步，slow 停在前半段末尾。
  2. 2. 翻转右半
    从 slow.next 原地反转后半段。
  3. 3. 镜像比较
    左右指针同步走，任一值不同即记录失败。
  4. 4. 恢复现场
    再次反转右半，并重新接回前半段。

常见错误

  • 用 fast != null 作为唯一循环条件，随后访问 fast.next.next。
  • 比较时走到前半段结束，而不是以较短的后半段为界。
  • 直接反转整条链表，导致原始头节点的结构被破坏。
  • 发现不匹配立即返回，漏掉恢复步骤。

面试追问

  • 为什么 slow 最终是前半段末尾？
  • 如何证明奇偶长度都只比较正确的节点对？
  • 若允许 O(n) 空间，你会选择数组还是栈？
  • 恢复链表是否改变渐进复杂度？

class Solution {
    public boolean isPalindrome(ListNode head) {
        if (head == null || head.next == null) return true;

        ListNode firstHalfEnd = endOfFirstHalf(head);
        ListNode secondHalfStart = reverse(firstHalfEnd.next);
        ListNode left = head;
        ListNode right = secondHalfStart;
        boolean result = true;

        while (result && right != null) {
            if (left.val != right.val) result = false;
            left = left.next;
            right = right.next;
        }

        firstHalfEnd.next = reverse(secondHalfStart);
        return result;
    }

    private ListNode endOfFirstHalf(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }

    private ListNode reverse(ListNode head) {
        ListNode previous = null;
        while (head != null) {
            ListNode next = head.next;
            head.next = previous;
            previous = head;
            head = next;
        }
        return previous;
    }
}

class Solution {
public:
    bool isPalindrome(ListNode* head) {
        if (head == nullptr || head->next == nullptr) return true;

        ListNode* slow = head;
        ListNode* fast = head;
        while (fast->next != nullptr && fast->next->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }

        ListNode* secondHalfStart = reverse(slow->next);
        ListNode* left = head;
        ListNode* right = secondHalfStart;
        bool result = true;
        while (result && right != nullptr) {
            if (left->val != right->val) result = false;
            left = left->next;
            right = right->next;
        }

        slow->next = reverse(secondHalfStart);
        return result;
    }

private:
    ListNode* reverse(ListNode* head) {
        ListNode* previous = nullptr;
        while (head != nullptr) {
            ListNode* next = head->next;
            head->next = previous;
            previous = head;
            head = next;
        }
        return previous;
    }
};
