Perform String Shifts

字符串的左右移

在一连串左移与右移指令中，观察字符串如何一步步改变。先动手探索，题解留到最后。

题目

给定字符串 s 与二维整数数组 shift。每个 shift[i] = [direction, amount] 表示一次操作：

  • direction = 0：把字符串向左移动 amount 位，移出的开头字符依次接到末尾。
  • direction = 1：把字符串向右移动 amount 位，移出的末尾字符依次接到开头。

按给定顺序执行全部操作，返回最终字符串。函数签名：stringShift(s, shift) → string。

示例 1

输入：s = "abc", shift = [[0,1],[1,2]]

输出："cab"

先左移 1 位得到 "bca"，再右移 2 位得到 "cab"。

示例 2

输入：s = "abcdefg", shift = [[1,1],[1,1],[0,2],[1,3]]

输出："efgabcd"

依次执行四条指令后，最终得到 "efgabcd"。

约束

  • 1 ≤ s.length ≤ 100，且 s 只含小写英文字母。
  • 1 ≤ shift.length ≤ 100，且 shift[i].length = 2。
  • shift[i][0] 为 0 或 1。
  • 0 ≤ shift[i][1] ≤ 100。

题解：合并成一次净位移

核心洞察

左移与右移会相互抵消。把左移记为负数、右移记为正数，累加得到净右移量，再对字符串长度取模，只旋转一次即可。

完整过程

  1. 遍历所有 [direction, amount]。
  2. 右移就加 amount，左移就减。
  3. 将净位移规范到 [0,n)。
  4. 把末尾 k 个字符接到其余字符前面。

正确性

每次循环移位只改变字符下标，不改变相对循环顺序；连续两次移位等价于位移量相加。方向相反的等量位移互相抵消，因此所有操作等价于净位移 k。按 k 切分并拼接恰好将每个字符放到其最终循环下标，所以算法返回正确结果。

边界与复杂度

长度为 1、位移为 0、位移远大于长度、净位移为负都由取模处理。遍历指令耗时 O(m)，构造答案耗时 O(n)，总计 O(n+m)；除返回字符串外额外空间通常为 O(n)（取决于语言切片实现）。

替代方案

可以逐条模拟，每次切片后拼接，直观但最坏会反复复制字符串，复杂度可达 O(nm)。也可使用双端队列逐字符移动，但总移动次数很大时仍不如合并位移。

常见错误

  • 混淆 0/1 所代表的方向。
  • 负数取模在 Java/JavaScript/C++ 中仍可能为负。
  • k = 0 时错误切片。
  • 忘记先对字符串长度取模。

面试追问

  • 如果指令是流式到达，如何维护净位移？
  • 如果字符串极大且只需查询某个最终位置的字符，能否避免构造新串？
  • 如何原地旋转字符数组？提示：三次翻转。

class Solution {
    public String stringShift(String s, int[][] shift) {
        int net = 0;
        for (int[] op : shift) {
            net += op[0] == 1 ? op[1] : -op[1];
        }
        int n = s.length();
        int k = ((net % n) + n) % n;
        if (k == 0) return s;
        return s.substring(n - k) + s.substring(0, n - k);
    }
}

var stringShift = function(s, shift) {
    let net = 0;
    for (const [direction, amount] of shift) {
        net += direction === 1 ? amount : -amount;
    }
    const n = s.length;
    const k = ((net % n) + n) % n;
    if (k === 0) return s;
    return s.slice(n - k) + s.slice(0, n - k);
};
from typing import List

class Solution:
    def stringShift(self, s: str, shift: List[List[int]]) -> str:
        net = 0
        for direction, amount in shift:
            net += amount if direction == 1 else -amount

        k = net % len(s)
        if k == 0:
            return s
        return s[-k:] + s[:-k]
