Dynamic Unpivoting of a Table

店铺名字会变，结果的结构不变。把一张横向展开的商品价格表，转换成统一的「商品、店铺、价格」记录。

先理解输入与输出，再展开下方题解与交互推演。

01 / 题目与数据契约

实现无参数存储过程 UnpivotProducts()。输入来自数据库中的 Products 表：每行代表一个商品，除 product_id 外，其余列名都是店铺名，列值是该店的价格。返回列为 product_id、store、price 的结果集，只保留有价格的商品与店铺组合。结果顺序不限；无需更新原表。

  • 不同用例的店铺名称可能不同。
  • product_id 为主键。
  • NULL 表示该店不出售此商品，不能产生结果行。
  • 公开题面未给出商品行数或价格的额外数值上下界；不自行补造。

04 / 题解 · 先读列名，再生成查询

核心洞察

每个店铺列都可以独立变成一个三列结果。难点在于店名未知，不能把示例中的四个名字写死。先从元数据读取实际列名，再为每家店生成一个 SELECT，最后用 UNION ALL 拼接。列名既要作为字符串出现在输出中，也要作为标识符读取价格，这两种用途必须分开处理。

动态 SQL · 生成过程

完整过程

  1. 读取 information_schema.columns，限定当前数据库及 Products 表，排除 product_id；按列序号排列只是为了展示稳定。
  2. 对每个店铺构造 SELECT：输出商品 ID、店铺名常量、该列价格，并用 IS NOT NULL 过滤缺货记录。
  3. 用 GROUP_CONCAT 和 UNION ALL 组合语句，扩大连接字符串上限以容纳最多 30 列。
  4. 把 SQL 放入会话变量，依次 PREPARE、EXECUTE、DEALLOCATE PREPARE，返回查询结果。

元数据字段含义参见 MySQL COLUMNS 文档；动态执行机制参见 MySQL Prepared Statements 文档。下面的代码是依据这些机制独立组织的实现，未执行验证。

MySQL · 本题主实现 / 可提交过程形式

提交完整过程；本地命令行若需要 DELIMITER，应在客户端另行设置，它不属于过程逻辑。店铺常量使用十六进制编码再转为 utf8mb4 字符串，避免店名引号与反斜杠影响 SQL 字面量；标识符使用反引号并将内部反引号加倍。

CREATE PROCEDURE UnpivotProducts()
BEGIN
    DECLARE old_limit BIGINT UNSIGNED;
    SET old_limit = @@SESSION.group_concat_max_len;
    SET SESSION group_concat_max_len = 1000000;

    SELECT GROUP_CONCAT(
        CONCAT(
            'SELECT `product_id`, CONVERT(0x',
            HEX(CONVERT(COLUMN_NAME USING utf8mb4)),
            ' USING utf8mb4) AS `store`, `',
            REPLACE(COLUMN_NAME, '`', '``'),
            '` AS `price` FROM `Products` WHERE `',
            REPLACE(COLUMN_NAME, '`', '``'),
            '` IS NOT NULL'
        ) ORDER BY ORDINAL_POSITION SEPARATOR ' UNION ALL '
    ) INTO @unpivot_sql
    FROM information_schema.columns
    WHERE TABLE_SCHEMA = DATABASE()
      AND TABLE_NAME = 'Products'
      AND COLUMN_NAME <> 'product_id';

    SET SESSION group_concat_max_len = old_limit;
    PREPARE unpivot_stmt FROM @unpivot_sql;
    EXECUTE unpivot_stmt;
    DEALLOCATE PREPARE unpivot_stmt;
END;

正确性证明

单列正确：某店铺的 SELECT 只返回该列非 NULL 的记录，因此每一行确实对应一件在此店出售的商品，店名和价格也来自同一列。

覆盖完整：元数据枚举所有店铺列，每个非空价格必然属于其中一个 SELECT，不会遗漏合法组合。

恰好一次：product_id 唯一，店铺列名唯一，同一个 (product_id, store) 只属于一个分支中的一行。UNION ALL 保留这些行而无需去重。因此结果恰好是要求的集合。

复杂度

设商品数为 R，店铺数为 S，所有店名总长度为 L，输出行数为 K。构造语句长度为 O(S + L)，按列序排序的抽象成本至多 O(S log S)。执行 S 个分支通常需要 O(RS) 的逻辑扫描工作，K ≤ RS；实际时间依赖数据库执行计划与索引。

动态 SQL 的额外字符串空间 O(S + L)；若保存完整结果，还需 O(K)。不把数据库内部缓冲区和优化器开销承诺为常数。四语言参考的扫描时间 O(RS)，结果空间 O(K)。

边界与常见错误

  • NULL 必须过滤；0 是有效价格，不能用 truthy 判断或 price > 0。
  • 空表仍有元数据，生成的 SELECT 返回带三列结构的空结果。题目保证至少一店，不需要处理零店铺模式。
  • 不可固定 LC_Store 等列名，不可把 product_id 也当成店铺。
  • 必须限定 TABLE_SCHEMA，否则其他数据库的同名表会污染列集合。
  • 不能把列名当参数占位符绑定；参数代表值，标识符需安全构造。
  • GROUP_CONCAT 截断会造成无效或不完整 SQL；语句长度限制是动态生成的实际风险。
  • 不要强加输出排序。相同价格出现在不同店铺时，两行都必须保留。

替代方案与面试追问

  • 列名固定时？手写 UNION ALL 最简单，但不满足本题动态结构要求。
  • 不用 GROUP_CONCAT？可以用元数据游标逐段拼接 LONGTEXT，控制更细，但过程更长。
  • SQL Server / Oracle？可动态构造 UNPIVOT 列列表；仍要发现列名，并遵守对应方言的引用与 NULL 规则。
  • 为什么不 UNION？完整三元组本就不会重复，去重通常带来不必要的成本。
  • 数百万商品怎么办？观察执行计划与 I/O，比较引擎原生 UNPIVOT、分批读取；若可改模型，直接存储 (product_id, store, price) 长表。
  • 生产化还需什么？补充异常资源清理、元数据与查询期间的模式变更策略、权限和语句长度控制。本页实现面向题目的固定调用环境。

Java · Java 8+

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class Main {
    static List<List<Object>> unpivotProducts(
            String[] headers, Integer[][] rows) {
        List<List<Object>> result = new ArrayList<>();
        for (int j = 1; j < headers.length; j++) {
            for (Integer[] row : rows) {
                if (row[j] != null) {
                    result.add(Arrays.<Object>asList(
                        row[0], headers[j], row[j]));
                }
            }
        }
        return result;
    }

    public static void main(String[] args) {
        String[] headers = {"product_id", "LC_Store", "Nozama", "Shop", "Souq"};
        Integer[][] rows = {
            {1, 100, null, 110, null},
            {2, null, 200, null, 190},
            {3, null, null, 1000, 1900}
        };
        System.out.println(unpivotProducts(headers, rows));
    }
}

function unpivotProducts(headers, rows) {
  const result = [];
  for (let j = 1; j < headers.length; j++) {
    for (const row of rows) {
      if (row[j] !== null) {
        result.push([row[0], headers[j], row[j]]);
      }
    }
  }
  return result;
}

C++ · C++17

#include <iostream>
#include <optional>
#include <string>
#include <tuple>
#include <vector>
using namespace std;

using Row = vector<optional<int>>;
using Result = tuple<int, string, int>;

vector<Result> unpivotProducts(
    const vector<string>& headers, const vector<Row>& rows) {
    vector<Result> result;
    for (size_t j = 1; j < headers.size(); ++j) {
        for (const auto& row : rows) {
            if (row[j].has_value()) {
                result.emplace_back(row[0].value(), headers[j], row[j].value());
            }
        }
    }
    return result;
}

int main() {
    vector<string> headers = {"product_id", "LC_Store", "Nozama", "Shop", "Souq"};
    vector<Row> rows = {
        {1, 100, nullopt, 110, nullopt},
        {2, nullopt, 200, nullopt, 190},
        {3, nullopt, nullopt, 1000, 1900}
    };
    for (const auto& [id, store, price] : unpivotProducts(headers, rows)) {
        cout << id << " | " << store << " | " << price << '\n';
    }
}
