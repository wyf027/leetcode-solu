Largest Number At Least Twice of Others

先别急着展开答案。用一把“×2 标尺”观察：谁是最大值，以及它和其余数字之间究竟隔了多远？

Problem

题目要求

给定整数数组 nums，数组中存在唯一的最大整数。检查这个最大元素是否至少是数组中每一个其他数字的两倍。

若条件成立，返回最大元素的下标；否则返回 -1。

函数签名： dominantIndex(nums: integer[]) -> integer
题目要返回的是最大值的原始下标，不是最大值本身。

Examples

官方示例

示例 1

输入
nums = [3,6,1,0]
输出
1
解释
最大整数是 6；对每个其他数字 x，都有 6 ≥ 2 × x。6 的下标是 1。

示例 2

输入
nums = [1,2,3,4]
输出
-1
解释
最大整数是 4，但 4 < 2 × 3，不满足要求。

Constraints

约束

  • 2 <= nums.length <= 50
  • 0 <= nums[i] <= 100
  • nums 中的最大元素唯一。

准备好看完整题解了吗？

下面会展开核心洞察、证明、边界、复杂度、替代方案与四种语言的完整代码。

Solution

只盯住前两名

最大值若能压过“最强的其他数字”的两倍，自然也能压过所有更小数字的两倍。因此全部比较可以浓缩为一次扫描中的两个候选值。

核心洞察

×2

设最大值为 M，除它以外的最大值（即次大值）为 S。只需判断 M ≥ 2 × S。如果这条成立，那么对任意其他元素 x ≤ S，必有 M ≥ 2S ≥ 2x；反之，连次大值都无法满足时，答案一定是 -1。

完整过程

  1. 用 maxValue、secondValue 和 maxIndex 分别记录当前最大值、次大值及最大值的原始下标。
  2. 从左到右扫描：若当前值大于 maxValue，旧最大值降为次大值，当前值成为新最大值，同时记录下标。
  3. 否则，若当前值大于 secondValue，只更新次大值。相等值也会被正确保留在前两名中。
  4. 扫描结束后比较 maxValue 与 2 × secondValue；成立返回 maxIndex，否则返回 -1。

正确性证明

引理：扫描后保留的是全局前两名

初始化时结论对第一个元素成立。每读入一个新值：若它超过当前最大值，就让旧最大值降为次大值；否则只在它超过当前次大值时更新次大值。因此每一步后，这两个变量始终是已扫描前缀的最大值和次大值。由归纳法，扫描结束时结论对整个数组成立。

定理：最终返回值正确

若 M ≥ 2S，由于任意其他元素 x ≤ S，可得 M ≥ 2x，返回最大值下标正确。若 M < 2S，次大值本身就是反例，返回 -1 正确。两种情况覆盖全部输入。

边界情况

长度为 2

仍然只有最大值与次大值，统一逻辑即可，无需特殊分支。例如 [1,0] 返回 0。

包含 0

约束允许 0。若除最大值外均为 0，则两倍仍为 0，条件成立。

最大值位置任意

必须同步保存原始下标；最大值可能位于开头、中间或结尾。

相等的非最大值

只有最大值保证唯一。其他数字可以重复，次大值仍应取其中的最大数值。

复杂度

O(n)时间：数组只扫描一次。
O(1)空间：只维护固定数量的变量。

替代方案

两次扫描

第一次找最大值及其下标，第二次逐个验证其他元素。时间仍为 O(n)、空间 O(1)，逻辑直观，也是非常稳妥的面试答案。

排序

排序后比较最大值和次大值，但会变为 O(n log n)，还需额外保存原始下标。除非复用排序结果，否则不如扫描。

四种语言完整代码

四份实现均采用一次扫描维护最大值、次大值和最大值下标。

Java
class Solution {
    public int dominantIndex(int[] nums) {
        int maxValue = -1;
        int secondValue = -1;
        int maxIndex = -1;

        for (int i = 0; i < nums.length; i++) {
            int value = nums[i];
            if (value > maxValue) {
                secondValue = maxValue;
                maxValue = value;
                maxIndex = i;
            } else if (value > secondValue) {
                secondValue = value;
            }
        }

        return maxValue >= 2 * secondValue ? maxIndex : -1;
    }
}

面试追问

如果最大值不保证唯一呢？

需要先明确语义。若相同最大值出现两次且最大值大于 0，则其中一个最大值不可能至少是另一个的两倍，答案应为 -1；实现上可统计最大值出现次数。

如果允许负数呢？

初始化为 -1 将失效，应改为负无穷或从数组元素初始化；同时要重新审视“至少两倍”在负数上的业务含义。

能否先找最大值，再检查全部元素？

可以。这是两次扫描方案，渐进复杂度相同，代码也很清楚；一次扫描主要减少一次遍历。

如何避免乘法溢出？

本题上限 100，不会溢出。若范围很大，可用更宽整数类型，或在非负前提下比较 M / 2 ≥ S 并谨慎处理整除。

常见错误

  • 返回最大值而不是最大值的原始下标。
  • 更新最大值时忘记先把旧最大值放入次大值。
  • 只和某一个相邻元素比较，而不是与“所有其他元素中的最大者”比较。
  • 使用严格大于 >；题目说“至少是两倍”，相等时也应成立，所以必须使用 >=。
  • 排序后丢失原始下标，或为了找前两名付出不必要的 O(n log n) 时间。
