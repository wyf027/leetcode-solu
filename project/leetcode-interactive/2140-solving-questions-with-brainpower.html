01 / 题目

给定从下标 0 开始的二维整数数组 questions，每一项 questions[i] = [pointsᵢ, brainpowerᵢ] 表示一道题的分数与做完后必须跳过的题数。你从第 0 题开始，按原顺序处理题目。

  • 解决第 i 题：得到 pointsᵢ 分，接下来的 brainpowerᵢ 道题不能做；下一次可选择的位置是 i + brainpowerᵢ + 1。
  • 主动跳过第 i 题：不得分，直接在第 i + 1 题重新选择。

返回这场考试能够获得的最高总分。不能重排题目，也不能回头做已经跳过的题。

官方约束
  • 1 ≤ questions.length ≤ 10⁵
  • questions[i].length == 2
  • 1 ≤ pointsᵢ, brainpowerᵢ ≤ 10⁵

05 / 独立题解

准备好后再展开，查看推导、正确性与可提交代码。

从考试末尾，向前做决定

核心洞察

到达第 i 题时，历史得分不会改变后续题目的可行选择。只要知道“从每个后续位置出发能取得多少分”，就能比较做与不做。令 dp[i] 表示从第 i 题开始、当前没有冷却限制时的最高后续得分。

j = min(n, i + questions[i][1] + 1)
dp[n] = 0
dp[i] = max(dp[i + 1], questions[i][0] + dp[j])

跳过读取 dp[i+1]；解决读取跳跃落点的 dp[j]。两个依赖都在右侧，因此按 n−1 → 0 填表，最后返回 dp[0]。

逐格推演：两条边汇入一个最优值

固定使用官方示例 1。绿色边框代表本步刚计算的位置，“·”表示尚未计算。此处展示递推机制，并非测试执行记录。

完整过程

  1. 创建长度 n+1、初值为 0 的数组，末尾位置代表没有题可做。
  2. i=3：解决得 2+0，跳过得 0，取 2。
  3. i=2：解决得 4+0，跳过得 2，取 4。
  4. i=1：解决得 4+0，跳过得 4，取 4。
  5. i=0：解决得 3+dp[3]=5，跳过得 dp[1]=4，取 5。
  6. 返回 dp[0]=5。如要恢复方案，从 0 开始比较两分支，选择解决则跳到 j，否则向前一题。示例可得到题号 0、3。

正确性证明

基础：i=n 时没有剩余题，最优分数为 0，故 dp[n] 正确。归纳：假设所有下标大于 i 的状态正确。从 i 开始的任何可行方案，第一步必然是跳过或解决。跳过后的最佳收益恰为 dp[i+1]；解决后获得当前分数，接下来的冷却区间无法作答，剩余最佳收益恰为 dp[j]。两类覆盖所有方案，且各自都可实现，取最大值就是 dp[i]。由逆向归纳，dp[0] 为全局最优。

边界与数值

  • 跳跃到达或超过 n 时统一落在 dp[n]，不能直接读越界位置。
  • 只有一道题时直接得到其分数。
  • 并列最优时取任意分支，返回值一致。
  • 总分粗上界 10¹⁰；Java 用 long，C++ 用 long long。JavaScript Number 可精确表示该范围，Python 整数无需额外处理。
  • 官方保证非空且每项两个正整数；上方编辑器单独验证输入。

复杂度

时间 O(n)：每个下标比较两个分支。空间 O(n)：存储 n+1 个后缀最优值。

常见错误

  • 跳转漏写 +1，把最后一道冷却题当作可做。
  • 正向填写后缀状态，读取尚未计算的值。
  • 用 32 位整数累计分数而溢出。
  • 贪心选当前最高分或最高“分数/冷却”比值。
  • 仅保留两个滚动变量：跳跃依赖可能在任意后续位置。

替代方案

自顶向下记忆化搜索使用同一递推，时间与空间均为 O(n)，但最深递归可达 n，Python、JavaScript 等语言会面临调用栈限制。正向 DP 也可行：以 best[i] 表示到达位置 i 时的最高已得分，向 i+1 传播跳过收益，向 j 传播解决收益，最终取 best[n]。朴素枚举分支最坏指数级，不适合 10⁵ 道题。

面试追问

  • 如何输出具体题号？从 dp[0] 顺着达到最优值的分支走，相等时固定优先级即可，额外输出空间 O(n)。
  • 为何不能按分数排序？冷却作用于原下标区间，排序改变了合法方案集合。
  • brainpower 可以为 0 呢？j=i+1，递推仍成立，但当前官方约束不包含 0。
  • 分数可以为负数呢？若允许全部跳过，末尾仍置 0，取最大值会自动避开不划算的题。

Java

class Solution {
    public long mostPoints(int[][] questions) {
        int n = questions.length;
        long[] dp = new long[n + 1];
        for (int i = n - 1; i >= 0; i--) {
            int j = Math.min(n, i + questions[i][1] + 1);
            dp[i] = Math.max(dp[i + 1], questions[i][0] + dp[j]);
        }
        return dp[0];
    }
}

var mostPoints = function(questions) {
    const n = questions.length;
    const dp = new Array(n + 1).fill(0);
    for (let i = n - 1; i >= 0; i--) {
        const [points, brainpower] = questions[i];
        const j = Math.min(n, i + brainpower + 1);
        dp[i] = Math.max(dp[i + 1], points + dp[j]);
    }
    return dp[0];
};

from typing import List

class Solution:
    def mostPoints(self, questions: List[List[int]]) -> int:
        n = len(questions)
        dp = [0] * (n + 1)
        for i in range(n - 1, -1, -1):
            points, brainpower = questions[i]
            j = min(n, i + brainpower + 1)
            dp[i] = max(dp[i + 1], points + dp[j])
        return dp[0]
