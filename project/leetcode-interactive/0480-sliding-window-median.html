滑动窗口中位数Sliding Window Median

一扇固定宽度的窗口从数组左端逐格滑过。你要在每个位置观察窗口内排序后的“中心”，并把所有中位数组成答案。

题号480
参数nums, k
返回double[]
01 · Problem

题意与输入输出

误差 ≤ 10−5
中位数是有序整数序列的中心值：长度为奇数时取中间元素；长度为偶数时取中间两个元素的平均数。

任务

给定整数数组 nums 和整数 k。长度为 k 的窗口从最左端开始，每次向右移动一位。返回每个窗口内元素的中位数，顺序与窗口出现顺序一致。

函数签名

medianSlidingWindow(nums: integer[], k: integer) → double[]

约束

  • 1 ≤ k ≤ nums.length ≤ 105
  • −231 ≤ nums[i] ≤ 231 − 1
  • 答案允许 10−5 内误差

示例 1

输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[1.00000,-1.00000,-1.00000,3.00000,5.00000,6.00000]
说明：
[1, 3,-1] -3  5  3  6  7  →  1
 1 [3,-1,-3]  5  3  6  7  → -1
 1  3 [-1,-3,5] 3  6  7   → -1
 1  3 -1 [-3,5,3] 6  7    →  3
 1  3 -1 -3 [5,3,6] 7     →  5
 1  3 -1 -3  5 [3,6,7]    →  6

示例 2

输入：nums = [1,2,3,4,2,3,1,4,2], k = 3
输出：[2.00000,3.00000,3.00000,3.00000,2.00000,3.00000,2.00000]

04 · Editorial

题解：双堆 + 延迟删除

O(n log k)

核心洞察

把窗口分成两个“有效元素半区”：

  • small 是最大堆，保存较小的一半；堆顶是该半区最大值。
  • large 是最小堆，保存较大的一半；堆顶是该半区最小值。
  • 始终维持 smallSize = largeSize 或 smallSize = largeSize + 1。

奇数窗口取 small.top；偶数窗口取两个堆顶的平均数。

延迟删除

普通堆只能高效删除堆顶，而滑出窗口的数可能埋在堆内部。哈希表 delayed[value] 记录某个值“应该被删除”的次数。

逻辑大小立即减少，物理元素暂留堆中。每当待删除值抵达堆顶，prune 才真正弹出它。

完整过程

  1. add(x)：若 small 为空或 x ≤ small.top，放入 small；否则放入 large，随后平衡。
  2. erase(x)：增加 x 的待删次数，根据 x 与 small.top 的关系减少对应半区的逻辑大小；若它正位于堆顶，立即清理。
  3. balance()：small 多出两个有效元素时，把堆顶移到 large；large 更大时，把堆顶移到 small。移动后清理来源堆顶。
  4. median()：k 为奇数时读取 small 堆顶；k 为偶数时计算两个堆顶的平均数。
  5. 滑动：先初始化前 k 个数；之后每步加入新值、延迟删除旧值，再输出中位数。

正确性

分区不变式：small 中每个有效元素都不大于 large 中每个有效元素。加入时按边界分区，平衡时只搬移边界堆顶，因此该性质持续成立。

大小不变式：平衡后 small 与 large 等大，或仅多一个有效元素。

有效堆顶：prune 反复弹出所有已标记的堆顶，所以读取的边界元素仍在窗口内。

于是奇数时 small 堆顶是唯一中心；偶数时两个堆顶是中间两数。因此每个输出都是对应窗口的中位数。

复杂度与边界

  • 每个元素至多入堆、出堆常数次，单次堆操作 O(log k)。
  • 总时间 O(n log k)，空间 O(k)。
  • k = 1 时元素本身就是中位数。
  • 重复值必须记录待删除“次数”，不能只用布尔标记。
  • 偶数窗口求和前转为浮点或宽类型，避免 32 位溢出。

替代方案

方案单次滑动总时间特点
每窗排序O(k log k)O(nk log k)直观，但无法应对 105 规模
有序数组 + 二分O(k)O(nk)查找快，移动元素仍昂贵
平衡树 / multisetO(log k)O(n log k)需维护两个集合或中点迭代器
双堆 + 延迟删除摊还 O(log k)O(n log k)跨语言通用，中位数 O(1) 读取

常见错误

  • 拿堆容器物理长度当有效大小，幽灵元素破坏平衡。
  • 延迟删除后不清理堆顶，读到已滑出窗口的值。
  • 只清理一次；连续过期堆顶必须循环弹出。
  • 重复值只记录“是否删除”，丢失多个相同值的待删次数。
  • 用 int 先计算 a + b，极值相加溢出。

面试追问

  • 为什么 erase 时比较 x ≤ small.top 足以决定逻辑归属？重复值为何不影响答案？
  • 如何证明延迟删除总清理次数是 O(n)？
  • 若要求 P90 而非中位数，如何调整两个半区的目标大小？
  • 没有“移出”操作的无限数据流中，可以删去哪些机制？

import java.util.*;

class Solution {
    private PriorityQueue<Integer> small;
    private PriorityQueue<Integer> large;
    private Map<Integer, Integer> delayed;
    private int smallSize, largeSize, k;

    public double[] medianSlidingWindow(int[] nums, int k) {
        small = new PriorityQueue<>(Collections.reverseOrder());
        large = new PriorityQueue<>();
        delayed = new HashMap<>();
        this.k = k;

        for (int i = 0; i < k; i++) add(nums[i]);

        double[] answer = new double[nums.length - k + 1];
        answer[0] = median();
        for (int right = k; right < nums.length; right++) {
            add(nums[right]);
            erase(nums[right - k]);
            answer[right - k + 1] = median();
        }
        return answer;
    }

    private void add(int num) {
        if (small.isEmpty() || num <= small.peek()) {
            small.offer(num);
            smallSize++;
        } else {
            large.offer(num);
            largeSize++;
        }
        balance();
    }

    private void erase(int num) {
        delayed.merge(num, 1, Integer::sum);
        if (num <= small.peek()) {
            smallSize--;
            if (num == small.peek()) prune(small);
        } else {
            largeSize--;
            if (!large.isEmpty() && num == large.peek()) prune(large);
        }
        balance();
    }

    private void balance() {
        if (smallSize > largeSize + 1) {
            large.offer(small.poll());
            smallSize--;
            largeSize++;
            prune(small);
        } else if (smallSize < largeSize) {
            small.offer(large.poll());
            smallSize++;
            largeSize--;
            prune(large);
        }
    }

    private void prune(PriorityQueue<Integer> heap) {
        while (!heap.isEmpty()) {
            int num = heap.peek();
            int count = delayed.getOrDefault(num, 0);
            if (count == 0) break;
            heap.poll();
            if (count == 1) delayed.remove(num);
            else delayed.put(num, count - 1);
        }
    }

    private double median() {
        if ((k & 1) == 1) return small.peek();
        return ((double) small.peek() + (double) large.peek()) / 2.0;
    }
}
JavaScript 
class Heap {
    constructor(higherPriority) {
        this.data = [];
        this.higherPriority = higherPriority;
    }
    size() { return this.data.length; }
    peek() { return this.data[0]; }

    push(value) {
        this.data.push(value);
        let i = this.data.length - 1;
        while (i > 0) {
            const parent = (i - 1) >> 1;
            if (!this.higherPriority(this.data[i], this.data[parent])) break;
            [this.data[i], this.data[parent]] = [this.data[parent], this.data[i]];
            i = parent;
        }
    }

    pop() {
        const top = this.data[0];
        const last = this.data.pop();
        if (this.data.length > 0) {
            this.data[0] = last;
            let i = 0;
            while (true) {
                let best = i;
                const left = i * 2 + 1;
                const right = left + 1;
                if (left < this.data.length &&
                    this.higherPriority(this.data[left], this.data[best])) best = left;
                if (right < this.data.length &&
                    this.higherPriority(this.data[right], this.data[best])) best = right;
                if (best === i) break;
                [this.data[i], this.data[best]] = [this.data[best], this.data[i]];
                i = best;
            }
        }
        return top;
    }
}

var medianSlidingWindow = function(nums, k) {
    const small = new Heap((a, b) => a > b);
    const large = new Heap((a, b) => a < b);
    const delayed = new Map();
    let smallSize = 0;
    let largeSize = 0;

    function prune(heap) {
        while (heap.size() > 0) {
            const num = heap.peek();
            const count = delayed.get(num) || 0;
            if (count === 0) break;
            heap.pop();
            if (count === 1) delayed.delete(num);
            else delayed.set(num, count - 1);
        }
    }

    function balance() {
        if (smallSize > largeSize + 1) {
            large.push(small.pop());
            smallSize--;
            largeSize++;
            prune(small);
        } else if (smallSize < largeSize) {
            small.push(large.pop());
            smallSize++;
            largeSize--;
            prune(large);
        }
    }

    function add(num) {
        if (small.size() === 0 || num <= small.peek()) {
            small.push(num);
            smallSize++;
        } else {
            large.push(num);
            largeSize++;
        }
        balance();
    }

    function erase(num) {
        delayed.set(num, (delayed.get(num) || 0) + 1);
        if (num <= small.peek()) {
            smallSize--;
            if (num === small.peek()) prune(small);
        } else {
            largeSize--;
            if (large.size() > 0 && num === large.peek()) prune(large);
        }
        balance();
    }

    function median() {
        return (k & 1) === 1
            ? small.peek()
            : (small.peek() + large.peek()) / 2;
    }

    for (let i = 0; i < k; i++) add(nums[i]);
    const answer = [median()];
    for (let right = k; right < nums.length; right++) {
        add(nums[right]);
        erase(nums[right - k]);
        answer.push(median());
    }
    return answer;
};
Python 
from collections import defaultdict
from heapq import heappop, heappush
from typing import List


class DualHeap:
    def __init__(self, k: int):
        self.small = []
        self.large = []
        self.delayed = defaultdict(int)
        self.small_size = 0
        self.large_size = 0
        self.k = k

    def prune(self, heap) -> None:
        while heap:
            num = -heap[0] if heap is self.small else heap[0]
            if self.delayed[num] == 0:
                break
            self.delayed[num] -= 1
            if self.delayed[num] == 0:
                del self.delayed[num]
            heappop(heap)

    def balance(self) -> None:
        if self.small_size > self.large_size + 1:
            heappush(self.large, -heappop(self.small))
            self.small_size -= 1
            self.large_size += 1
            self.prune(self.small)
        elif self.small_size < self.large_size:
            heappush(self.small, -heappop(self.large))
            self.small_size += 1
            self.large_size -= 1
            self.prune(self.large)

    def add(self, num: int) -> None:
        if not self.small or num <= -self.small[0]:
            heappush(self.small, -num)
            self.small_size += 1
        else:
            heappush(self.large, num)
            self.large_size += 1
        self.balance()

    def erase(self, num: int) -> None:
        self.delayed[num] += 1
        if num <= -self.small[0]:
            self.small_size -= 1
            if num == -self.small[0]:
                self.prune(self.small)
        else:
            self.large_size -= 1
            if self.large and num == self.large[0]:
                self.prune(self.large)
        self.balance()

    def median(self) -> float:
        if self.k % 2 == 1:
            return float(-self.small[0])
        return (-self.small[0] + self.large[0]) / 2.0


class Solution:
    def medianSlidingWindow(self, nums: List[int], k: int) -> List[float]:
        heaps = DualHeap(k)
        for num in nums[:k]:
            heaps.add(num)

        answer = [heaps.median()]
        for right in range(k, len(nums)):
            heaps.add(nums[right])
            heaps.erase(nums[right - k])
            answer.append(heaps.median())
        return answer
C++ 
#include <bits/stdc++.h>
using namespace std;

class Solution {
    priority_queue<int> small;
    priority_queue<int, vector<int>, greater<int>> large;
    unordered_map<int, int> delayed;
    int smallSize = 0;
    int largeSize = 0;
    int k = 0;

    template <typename Heap>
    void prune(Heap& heap) {
        while (!heap.empty()) {
            int num = heap.top();
            auto it = delayed.find(num);
            if (it == delayed.end()) break;
            if (--it->second == 0) delayed.erase(it);
            heap.pop();
        }
    }

    void balance() {
        if (smallSize > largeSize + 1) {
            large.push(small.top());
            small.pop();
            --smallSize;
            ++largeSize;
            prune(small);
        } else if (smallSize < largeSize) {
            small.push(large.top());
            large.pop();
            ++smallSize;
            --largeSize;
            prune(large);
        }
    }

    void add(int num) {
        if (small.empty() || num <= small.top()) {
            small.push(num);
            ++smallSize;
        } else {
            large.push(num);
            ++largeSize;
        }
        balance();
    }

    void erase(int num) {
        ++delayed[num];
        if (num <= small.top()) {
            --smallSize;
            if (num == small.top()) prune(small);
        } else {
            --largeSize;
            if (!large.empty() && num == large.top()) prune(large);
        }
        balance();
    }

    double median() {
        if (k & 1) return static_cast<double>(small.top());
        return (static_cast<double>(small.top()) +
                static_cast<double>(large.top())) / 2.0;
    }

public:
    vector<double> medianSlidingWindow(vector<int>& nums, int windowSize) {
        k = windowSize;
        for (int i = 0; i < k; ++i) add(nums[i]);

        vector<double> answer;
        answer.reserve(nums.size() - k + 1);
        answer.push_back(median());

        for (int right = k; right < static_cast<int>(nums.size()); ++right) {
            add(nums[right]);
            erase(nums[right - k]);
            answer.push_back(median());
        }
        return answer;
    }
};
