找出和为指定值的下标对

Finding Pairs With a Certain Sum

两个数组、一组不断变化的数。设计一个对象，让更新与计数可以交替进行。

先理解操作与下标对，再在页面底部展开题解和交互演示。

01 / 题目与接口

给定整数数组 nums1 和 nums2。第一个数组保持不变；第二个数组支持按下标累加。每次计数时，返回当前两个数组中所有满足指定和的下标组合数量。即使数值相同，只要下标不同，就属于不同的下标对。

  • FindSumPairs(int[] nums1, int[] nums2)：用这两个数组初始化对象。
  • void add(int index, int val)：执行 nums2[index] += val，没有返回值。
  • int count(int tot)：返回满足 nums1[i] + nums2[j] == tot 的 (i, j) 数量，两个下标分别属于各自数组。

约束

  • 1 ≤ nums1.length ≤ 1000
  • 1 ≤ nums2.length ≤ 10⁵
  • 1 ≤ nums1[i] ≤ 10⁹
  • 1 ≤ nums2[i] ≤ 10⁵（初始化时）
  • 0 ≤ index < nums2.length
  • 1 ≤ val ≤ 10⁵
  • 1 ≤ tot ≤ 10⁹
  • add 与 count 各至多调用 1000 次；累加后的元素可能大于初始上界。

题意依据提供的官方元数据转述。查看官方题目

04 / 准备好再打开题解

先想一想：两个数组的长度上限相差很大，这会怎样影响你的设计？

题解 / 将大数组变成频次查询表

核心洞察

把 nums2 中每个数出现的次数记录在哈希表 freq 中。对 nums1 的每个下标 i，只需查找 tot - nums1[i] 在 nums2 里出现多少次。nums1 最多 1000 项，适合每次查询扫描；nums2 最多 10 万项，适合预处理后按值查询。

count(tot) = Σ freq[tot − nums1[i]]

完整过程

  1. 构造：保存两个数组的副本，遍历 nums2，建立数值到出现次数的映射。
  2. 更新：先取 old = nums2[index]，把 freq[old] 减一；若变成零就删除旧键。将数组该位置改为 old + val，再把新值的频次加一。
  3. 计数：答案从零开始，逐项读取 nums1，为每项查询其补数频次并累加。不存在的键按零处理，不修改哈希表。

为什么正确

  1. 频次不变式：每次公共操作结束后，freq[v] 等于当前 nums2 中值为 v 的下标数。构造时逐项计数成立；一次 add 仅改变一个下标，因此旧值少一个、新值多一个，其他频次不变，不变式得以保持。
  2. 单个下标的贡献：固定 i 后，合法 j 必须且只需满足 nums2[j] = tot − nums1[i]。不变式保证查到的频次正好是这些 j 的数量。
  3. 不重不漏：不同 i 对应的下标对集合互不相交。扫描 nums1 的每个下标并求和，覆盖所有合法下标对，且每对恰好被计入一次。

边界与数值范围

  • 重复的 nums1 值仍须按每个下标累加，不能直接使用 Set 去重。
  • 补数不存在、为零或为负，均贡献零；nums2 始终为正。
  • 连续更新同一下标时，必须读取最新 nums2[index]。频次为零时删除键，避免历史键持续累积。
  • 单个 nums2 元素最多增至 100100000；答案最多 1000 × 100000 = 10⁸。当前约束下 Java/C++ 的 int 与 JavaScript 的 Number 均可精确保存相关整数。扩大约束后应重新评估 64 位整数或 BigInt。

复杂度

令 n = nums1.length，m = nums2.length，u 为 nums2 当前不同数值数。哈希操作按平均 O(1) 计：构造 O(n + m)，add 平均 O(1)，count 平均 O(n)。下面代码复制并保存数组，空间 O(n + m + u)，即 O(n + m)；只计算额外索引时，哈希表占 O(u)。哈希表最坏碰撞情况下不保证常数时间。

替代方案

  • 双重枚举：更新 O(1)，每次查询 O(nm)，最大规模一次查询可涉及 10⁸ 个组合。
  • 两个数组都建频次表：查询遍历 nums1 的不同值 x，并累加 freq1[x] × freq2[tot − x]。nums1 重复值多时能减少查询工作量。
  • 对 nums2 排序后用二分查找补数区间：静态查询可行，但每次按原下标更新还要维护有序结构，通常不如频次哈希表直接。

常见错误

  • 只检查补数是否存在，漏算重复 j。
  • 先覆盖数组元素，再用新值去扣旧频次。
  • 只更新哈希表而忘记更新 nums2，导致下一次 add 使用错误旧值。
  • 把“加上 val”误写为“赋值为 val”。
  • 缓存 count(tot) 却没有在 add 后失效，返回过期答案。

面试追问

  • nums1 也允许更新？两侧均保存数组与频次表；更新各自频次，查询遍历不同值较少的一侧并将频次相乘。
  • count 比 add 多得多？可讨论缓存热门 tot 并在更新时维护其增量，但维护代价与缓存目标数有关，不能无条件加速。
  • 支持减法会怎样？频次不变式仍成立，哈希表也支持负数；只需重新确认元素与答案的数值范围。

Java

import java.util.HashMap;
import java.util.Map;

class FindSumPairs {
    private final int[] a;
    private final int[] b;
    private final Map<Integer, Integer> freq = new HashMap<>();

    public FindSumPairs(int[] nums1, int[] nums2) {
        a = nums1.clone();
        b = nums2.clone();
        for (int x : b) freq.put(x, freq.getOrDefault(x, 0) + 1);
    }

    public void add(int index, int val) {
        int old = b[index];
        int left = freq.get(old) - 1;
        if (left == 0) freq.remove(old);
        else freq.put(old, left);
        b[index] += val;
        int next = b[index];
        freq.put(next, freq.getOrDefault(next, 0) + 1);
    }

    public int count(int tot) {
        int answer = 0;
        for (int x : a) answer += freq.getOrDefault(tot - x, 0);
        return answer;
    }
}

/** @param {number[]} nums1 @param {number[]} nums2 */
var FindSumPairs = function(nums1, nums2) {
    this.a = nums1.slice();
    this.b = nums2.slice();
    this.freq = new Map();
    for (const x of this.b) {
        this.freq.set(x, (this.freq.get(x) || 0) + 1);
    }
};

/** @param {number} index @param {number} val @return {void} */
FindSumPairs.prototype.add = function(index, val) {
    const old = this.b[index];
    const left = this.freq.get(old) - 1;
    if (left === 0) this.freq.delete(old);
    else this.freq.set(old, left);
    this.b[index] += val;
    const next = this.b[index];
    this.freq.set(next, (this.freq.get(next) || 0) + 1);
};

/** @param {number} tot @return {number} */
FindSumPairs.prototype.count = function(tot) {
    let answer = 0;
    for (const x of this.a) answer += this.freq.get(tot - x) || 0;
    return answer;
};

Python 3

from collections import Counter
from typing import List


class FindSumPairs:
    def __init__(self, nums1: List[int], nums2: List[int]):
        self.a = nums1.copy()
        self.b = nums2.copy()
        self.freq = Counter(self.b)

    def add(self, index: int, val: int) -> None:
        old = self.b[index]
        self.freq[old] -= 1
        if self.freq[old] == 0:
            del self.freq[old]
        self.b[index] += val
        self.freq[self.b[index]] += 1

    def count(self, tot: int) -> int:
        return sum(self.freq.get(tot - x, 0) for x in self.a)

C++

#include <vector>
#include <unordered_map>
using namespace std;

class FindSumPairs {
    vector<int> a, b;
    unordered_map<int, int> freq;

public:
    FindSumPairs(vector<int>& nums1, vector<int>& nums2)
        : a(nums1), b(nums2) {
        for (int x : b) ++freq[x];
    }

    void add(int index, int val) {
        int old = b[index];
        if (--freq[old] == 0) freq.erase(old);
        b[index] += val;
        ++freq[b[index]];
    }

    int count(int tot) {
        int answer = 0;
        for (int x : a) {
            auto it = freq.find(tot - x);
            if (it != freq.end()) answer += it->second;
        }
        return answer;
    }
};
