Bitwise ORs of Subarrays —— 先亲手观察“以当前位置结尾”的结果集合如何演化，再决定是否展开完整题解。

位运算数组动态规划非付费题

题目

给定整数数组 arr，统计它的所有连续、非空子数组分别进行按位或（OR）后，能得到多少个不同的结果。单元素子数组的结果就是元素本身。

函数签名：subarrayBitwiseORs(arr: integer[]) → integer

约束

  • 1 ≤ arr.length ≤ 5 × 10⁴
  • 0 ≤ arr[i] ≤ 10⁹

答案关注不同的 OR 值，而不是子数组个数。

官方示例

示例 1 输入：arr = [0] 输出：1 解释：唯一可能的结果是 0。

示例 2 输入：arr = [1,1,2] 输出：3 解释：子数组 [1]、[1]、[2]、[1,1]、[1,2]、[1,1,2] 的 OR 依次为 1、1、2、1、3、3；不同值有 1、2、3。

示例 3 输入：arr = [1,2,4] 输出：6 解释：不同结果是 1、2、3、4、6、7。

完整题解

滚动集合动态规划

核心洞察

设 Eᵢ 为所有以 i 结尾的非空子数组 OR 值集合。新元素 x = arr[i] 单独构成子数组，也能接在上一位置的每个子数组后：

Eᵢ = {x} ∪ {v | x : v ∈ Eᵢ₋₁}

把每轮 Eᵢ 合并进全局集合，最终大小就是答案。OR 只能把二进制位从 0 变 1；沿着固定结尾向左扩展时，每次产生新值至少多置一位。因此一轮的不同值数量至多约为整数位数（这里不超过 30 个），不会增长到 O(n)。

完整过程

初始化当前集合 E = ∅、全局集合 A = ∅。

依次读取 x，创建 N = {x}；对旧 E 中每个 v，加入 v | x。

用 N 替换 E，并把其中每个值加入 A。

遍历结束，返回 |A|。

正确性证明

引理：第 i 轮得到的集合恰好包含全部以 i 结尾的非空子数组 OR。长度为 1 的子数组贡献 arr[i]；其余子数组删掉末尾后必是以 i−1 结尾的子数组，结果为其 OR 再与 arr[i]。反向看，转移生成的每一项也都对应一个合法子数组，故无遗漏、无多余。

定理：每个非空子数组都有唯一的末尾 i，因此其 OR 会在对应 Eᵢ 中出现；全局集合合并所有 Eᵢ，恰好是题目要求的所有不同结果。返回其大小正确。

复杂度与边界

设数值有效位数为 W（本题 W ≤ 30）。时间复杂度 O(nW)，额外空间 O(nW) 用于全局不同结果，滚动集合为 O(W)。单元素、全 0、重复值以及 OR 很快饱和为同一值时，去重集合都能自然处理。

替代方案

枚举所有起点与终点需要 O(n²)，即使增量维护 OR 也无法通过 5×10⁴ 的规模。也可用数组排序去重替代哈希集合，但实现更繁琐；滚动 Set 最贴合状态定义。

四语言完整代码

Java

class Solution {
    public int subarrayBitwiseORs(int[] arr) {
        java.util.Set<Integer> all = new java.util.HashSet<>();
        java.util.Set<Integer> ending = new java.util.HashSet<>();
        for (int x : arr) {
            java.util.Set<Integer> next = new java.util.HashSet<>();
            next.add(x);
            for (int v : ending) next.add(v | x);
            ending = next;
            all.addAll(ending);
        }
        return all.size();
    }
}

/**

var subarrayBitwiseORs = function(arr) {
    const all = new Set();
    let ending = new Set();
    for (const x of arr) {
        const next = new Set([x]);
        for (const v of ending) next.add(v | x);
        ending = next;
        for (const v of ending) all.add(v);
    }
    return all.size;
};

Python

from typing import List

class Solution:
    def subarrayBitwiseORs(self, arr: List[int]) -> int:
        all_values = set()
        ending = set()
        for x in arr:
            ending = {x} | {v | x for v in ending}
            all_values |= ending
        return len(all_values)

C++

class Solution {
public:
    int subarrayBitwiseORs(vector<int>& arr) {
        unordered_set<int> all, ending;
        for (int x : arr) {
            unordered_set<int> next{x};
            for (int v : ending) next.insert(v | x);
            ending = move(next);
            all.insert(ending.begin(), ending.end());
        }
        return static_cast<int>(all.size());
    }
};

常见错误

  • 维护任意子数组的集合，却忘了转移时只应使用“以上一位置结尾”的集合。
  • 原地修改正在遍历的集合，导致同一轮重复扩展；应创建新集合。
  • 把 JavaScript 的 OR 当成任意精度运算；本题数值小于 2³⁰，32 位按位运算安全。
  • 累计集合时统计出现次数，而题目要求不同值数量。

面试追问

为何集合小？ 对固定结尾向左扩展，OR 值只会增加置位；每次严格变化至少新增一个 1。若改成 AND？ 同样可滚动维护，因为位只会从 1 变 0。若问异或 XOR？ 不再有单调置位性质，集合可能线性增长，需要重新分析。
