Premium

Number of Connected Components in an Undirected Graph

无向图中
连通分量的数目

给定一张无向图，辨认其中彼此可达的独立“群落”。先读题、观察连边，再决定怎样把重复工作压到最低。

函数

countComponents(n, edges)

输入

节点数 + 无向边列表

输出

连通分量数量

Problem

题意

有 n 个节点，编号为 0 到 n - 1。二维数组 edges 中的每个二元组 [a, b] 表示节点 a 与 b 之间存在一条无向边。

如果两个节点之间存在一条由若干条边组成的路径，它们就属于同一个连通分量。请返回整张图的连通分量数目；没有出现在任何边中的孤立节点也单独构成一个连通分量。

示例 1

输入：n = 5, edges = [[0,1],[1,2],[3,4]]
输出：2
解释：节点 {0,1,2} 彼此连通，节点 {3,4} 彼此连通，因此共有 2 个连通分量。

示例 2

输入：n = 5, edges = [[0,1],[1,2],[2,3],[3,4]]
输出：1
解释：所有节点都能沿边互相到达，因此整张图只有 1 个连通分量。

约束

  • 1 <= n <= 2000
  • 0 <= edges.length <= 5000
  • edges[i].length == 2
  • 0 <= edges[i][0], edges[i][1] < n，且一条边的两个端点不同。
  • 图中不含重复边；每条边均视为无向边。

Solution

准备好核对思路了吗？

题解默认收起，先独立思考会更有收获。

Union–Find

并查集：从 n 个集合开始合并

核心洞察

开始时没有处理任何边，每个节点各自构成一个连通分量，所以答案暂为 n。每读到一条边，如果两个端点当前属于不同集合，就合并它们并把分量数减一；如果已经属于同一集合，这条边只是在现有分量内部形成另一条路径，数量不变。

完整过程

01

初始化

令每个节点的父节点为自身，记录每棵树的大小或秩，并令 components = n。

02

寻找代表元

对边 [a,b] 分别执行 find(a) 与 find(b)。路径压缩会把查询路径上的节点直接挂到根附近。

03

按大小合并

若根不同，把较小的树接到较大的树下，并将 components 减一；根相同时跳过。

04

返回计数

处理完全部边后，并查集中的集合与原图的连通分量一一对应。

正确性证明

不变量：处理完前 k 条边后，并查集中的每个集合，恰好对应只使用这 k 条边时图中的一个连通分量。

初始：k = 0 时没有边，每个节点只与自身连通；并查集也恰有 n 个单节点集合，不变量成立。

保持：处理边 [a,b] 时，若两端属于不同集合，这条边使两个原本独立的连通分量成为一个，合并两个集合完全复现该变化；若两端已在同一集合，它们本来就存在路径，新边不改变连通分量，并查集也不合并。故不变量继续成立。

终止：所有边处理完毕，不变量说明并查集的集合数就是原图的连通分量数，返回值正确。

复杂度

时间：O((n + E) α(n))，其中 E = edges.length，α 为反阿克曼函数，在实际规模中近似常数。

空间：O(n)，用于父节点与集合大小数组。

边界情况

  • edges 为空：答案就是 n。
  • 只有一个节点：答案为 1。
  • 图已完全连通：再多的内部边也不会继续减少计数。
  • 包含孤立节点：它们未参与合并，仍各自贡献一个分量。

四语言完整代码

四份实现均使用路径压缩与按大小合并。

class Solution {
    public int countComponents(int n, int[][] edges) {
        UnionFind uf = new UnionFind(n);

        for (int[] edge : edges) {
            uf.union(edge[0], edge[1]);
        }

        return uf.components;
    }

    private static class UnionFind {
        private final int[] parent;
        private final int[] size;
        private int components;

        UnionFind(int n) {
            parent = new int[n];
            size = new int[n];
            components = n;
            for (int i = 0; i < n; i++) {
                parent[i] = i;
                size[i] = 1;
            }
        }

        int find(int x) {
            while (x != parent[x]) {
                parent[x] = parent[parent[x]];
                x = parent[x];
            }
            return x;
        }

        boolean union(int a, int b) {
            int rootA = find(a);
            int rootB = find(b);
            if (rootA == rootB) return false;

            if (size[rootA] < size[rootB]) {
                int temp = rootA;
                rootA = rootB;
                rootB = temp;
            }
            parent[rootB] = rootA;
            size[rootA] += size[rootB];
            components--;
            return true;
        }
    }
}

var countComponents = function(n, edges) {
    const parent = Array.from({ length: n }, (_, i) => i);
    const size = new Array(n).fill(1);
    let components = n;

    const find = (x) => {
        while (x !== parent[x]) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    };

    const union = (a, b) => {
        let rootA = find(a);
        let rootB = find(b);
        if (rootA === rootB) return false;

        if (size[rootA] < size[rootB]) {
            [rootA, rootB] = [rootB, rootA];
        }
        parent[rootB] = rootA;
        size[rootA] += size[rootB];
        components--;
        return true;
    };

    for (const [a, b] of edges) {
        union(a, b);
    }
    return components;
};

class Solution:
    def countComponents(self, n: int, edges: List[List[int]]) -> int:
        parent = list(range(n))
        size = [1] * n
        components = n

        def find(x: int) -> int:
            while x != parent[x]:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        def union(a: int, b: int) -> bool:
            nonlocal components
            root_a = find(a)
            root_b = find(b)
            if root_a == root_b:
                return False

            if size[root_a] < size[root_b]:
                root_a, root_b = root_b, root_a
            parent[root_b] = root_a
            size[root_a] += size[root_b]
            components -= 1
            return True

        for a, b in edges:
            union(a, b)

        return components
class Solution {
public:
    int countComponents(int n, vector<vector<int>>& edges) {
        vector<int> parent(n);
        vector<int> size(n, 1);
        iota(parent.begin(), parent.end(), 0);
        int components = n;

        function<int(int)> find = [&](int x) {
            while (x != parent[x]) {
                parent[x] = parent[parent[x]];
                x = parent[x];
            }
            return x;
        };

        for (const auto& edge : edges) {
            int rootA = find(edge[0]);
            int rootB = find(edge[1]);
            if (rootA == rootB) continue;

            if (size[rootA] < size[rootB]) swap(rootA, rootB);
            parent[rootB] = rootA;
            size[rootA] += size[rootB];
            --components;
        }

        return components;
    }
};

替代方案：DFS / BFS

先用邻接表建图，再从每个尚未访问的节点启动一次 DFS 或 BFS；每启动一次搜索，答案加一。该方法同样是 O(n + E) 时间与 O(n + E) 空间，直观且便于输出每个分量的具体节点。并查集更适合边逐条到来、只关心连通关系的场景。

常见错误

  • 把边数或“没有边的节点数”直接当成答案。
  • 每次看到边都将计数减一，忽略两端可能已经连通。
  • 只统计在 edges 中出现的节点，漏掉孤立节点。
  • 并查集合并根节点时忘记先调用 find。
  • DFS 递归深度过大时未考虑语言栈限制。

面试追问

边在线加入怎么办？

保留并查集，每次加入新边时执行一次 union；组件数可实时维护。

需要列出每个分量？

对所有节点求根，再按根分组；或者直接选择 DFS/BFS 收集节点。

如果边会删除？

普通并查集不支持撤销。离线可考虑回滚并查集配合分治；在线动态连通需要更复杂的数据结构。
