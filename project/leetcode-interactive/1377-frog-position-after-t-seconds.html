Problem

题目描述

给定一棵含 n 个顶点、编号为 1 到 n 的无向树。青蛙从顶点 1 出发；每一秒，它只能跳到一个与当前顶点直接相连且从未访问过的顶点。

如果有多个可选顶点，青蛙等概率选择其中一个；如果没有未访问的相邻顶点，它会一直停留在当前位置。给定边集 edges、时间 t 和目标 target，返回恰好 t 秒后青蛙位于目标顶点的概率。误差不超过 10⁻⁵ 的答案均可接受。

关键规则：“不能回到已访问顶点”让树天然从顶点 1 定向为父子关系；叶子节点吸收后续全部概率。

Examples

官方示例

示例 1

输入：n = 7, edges = [[1,2],[1,3],[1,7],[2,4],[2,6],[3,5]], t = 2, target = 4
输出：0.16666666666666666
解释：第 1 秒从 1 跳到 2 的概率为 1/3；第 2 秒从 2 跳到 4 的概率为 1/2，故结果为 1/3 × 1/2 = 1/6。

示例 2

输入：n = 7, edges = [[1,2],[1,3],[1,7],[2,4],[2,6],[3,5]], t = 1, target = 7
输出：0.3333333333333333
解释：顶点 1 有三个可选邻点，因此第 1 秒跳到顶点 7 的概率为 1/3。

约束

  • 1 <= n <= 100
  • edges.length == n - 1
  • edges[i].length == 2
  • 1 <= aᵢ, bᵢ <= n
  • 1 <= t <= 50
  • 1 <= target <= n

先尝试回答：到达目标后，什么情况下概率能够保留到第 t 秒？

Complete solution

分层传播概率

核心洞察

把顶点 1 当作根。由于不能访问已经走过的顶点，青蛙在任意顶点只能走向“孩子”（除父节点外的邻点）。当前概率要么被孩子数等分，要么在没有孩子时原地保留。因此可以逐秒做 BFS 概率转移。

最容易漏掉的点：青蛙提前到达 target 并不代表第 t 秒仍在那里；只有 target 没有未访问孩子时，它才会一直停留。

完整过程

  1. 建立无向邻接表，将状态初始化为 (node=1, parent=0, probability=1)。
  2. 重复 t 次：对每个状态统计除父节点外的孩子数量。
  3. 若没有孩子，将同一状态及其全部概率送入下一秒；否则把概率平均分给每个孩子。
  4. 完成 t 轮后，返回节点等于 target 的状态概率；若不存在则返回 0。

正确性证明

引理 1：在以 1 为根的树中，青蛙从非根节点出发时，可访问的相邻顶点恰好是它的孩子。因为到达它的唯一前驱是父节点，父节点已经访问；树又不存在环。

引理 2：每轮转移后，算法记录的每个节点概率等于该秒青蛙位于该节点的真实概率。归纳基础是 0 秒时节点 1 的概率为 1。归纳步骤中，有孩子的状态按题意等分给全部孩子；无孩子的状态按题意保留，恰好覆盖所有互斥结果。

定理：完成 t 轮后，算法返回青蛙在 t 秒时位于 target 的概率。由引理 2，此时所有状态分布与真实过程一致，读取 target 的概率即为所求。

边界情况

  • n = 1：起点也是叶子，任意 t 后概率仍为 1。
  • 目标深度大于 t：无法及时到达，概率为 0。
  • 目标在 t 前到达但还有孩子：下一秒必然离开，最终概率为 0。
  • 目标是叶子且提前到达：剩余时间始终停留，概率不变。

复杂度

建图和遍历均为 O(n) 时间；邻接表与队列占 O(n) 空间。即使 t 较大，叶子状态只会逐轮保留，单轮活跃状态总数不超过 n。

替代方案

也可以用 DFS 沿根到 target 的唯一路径计算分支数乘积，并额外检查“到达时间”和“target 是否还有孩子”。它更短，但边界判断更集中；逐秒 BFS 与题意一一对应，通常更不易出错。

面试追问

  • 若图不再是树，怎样在状态中表示已访问集合？状态规模会如何增长？
  • 若每条边有不同选择权重，如何把等分改成归一化概率？
  • 若询问多个 target 或多个 t，如何复用一次概率传播结果？

常见错误

  • 把父节点也计入可选邻点，导致分母多 1。
  • 到叶子后把概率丢弃，而不是保留在原地。
  • 找到 target 就立刻返回，没有判断剩余时间能否停留。
  • 使用整数除法，使概率被截断为 0。

import java.util.*;

class Solution {
    static class State {
        int node, parent;
        double probability;

        State(int node, int parent, double probability) {
            this.node = node;
            this.parent = parent;
            this.probability = probability;
        }
    }

    public double frogPosition(int n, int[][] edges, int t, int target) {
        List<Integer>[] graph = new ArrayList[n + 1];
        for (int i = 1; i <= n; i++) graph[i] = new ArrayList<>();
        for (int[] edge : edges) {
            graph[edge[0]].add(edge[1]);
            graph[edge[1]].add(edge[0]);
        }

        List<State> current = new ArrayList<>();
        current.add(new State(1, 0, 1.0));

        for (int second = 0; second < t; second++) {
            List<State> next = new ArrayList<>();
            for (State state : current) {
                int children = 0;
                for (int neighbor : graph[state.node]) {
                    if (neighbor != state.parent) children++;
                }
                if (children == 0) {
                    next.add(state);
                } else {
                    double share = state.probability / children;
                    for (int neighbor : graph[state.node]) {
                        if (neighbor != state.parent) {
                            next.add(new State(neighbor, state.node, share));
                        }
                    }
                }
            }
            current = next;
        }

        for (State state : current) {
            if (state.node == target) return state.probability;
        }
        return 0.0;
    }
}
/**
 * @param {number} n
 * @param {number[][]} edges
 * @param {number} t
 * @param {number} target
 * @return {number}
 */
var frogPosition = function(n, edges, t, target) {
    const graph = Array.from({ length: n + 1 }, () => []);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
    }

    let current = [[1, 0, 1.0]]; // node, parent, probability
    for (let second = 0; second < t; second++) {
        const next = [];
        for (const [node, parent, probability] of current) {
            const children = graph[node].filter(neighbor => neighbor !== parent);
            if (children.length === 0) {
                next.push([node, parent, probability]);
            } else {
                const share = probability / children.length;
                for (const child of children) next.push([child, node, share]);
            }
        }
        current = next;
    }

    const state = current.find(([node]) => node === target);
    return state ? state[2] : 0.0;
};

class Solution:
    def frogPosition(
        self, n: int, edges: List[List[int]], t: int, target: int
    ) -> float:
        graph = [[] for _ in range(n + 1)]
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)

        current = [(1, 0, 1.0)]  # node, parent, probability
        for _ in range(t):
            next_states = []
            for node, parent, probability in current:
                children = [v for v in graph[node] if v != parent]
                if not children:
                    next_states.append((node, parent, probability))
                else:
                    share = probability / len(children)
                    for child in children:
                        next_states.append((child, node, share))
            current = next_states

        for node, _, probability in current:
            if node == target:
                return probability
        return 0.0

        vector<tuple<int, int, double>> current = {{1, 0, 1.0}};
        for (int second = 0; second < t; ++second) {
            vector<tuple<int, int, double>> next;
            for (auto [node, parent, probability] : current) {
                int children = 0;

                    if (neighbor != parent) ++children;

                    next.push_back({node, parent, probability});
