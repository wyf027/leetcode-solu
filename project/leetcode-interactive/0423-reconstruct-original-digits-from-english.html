从英文中
重建数字

字母顺序已被彻底打乱。你的任务不是猜单词，而是还原其中隐藏的数字，并按升序交付结果。

难度：中等 Reconstruct Original Digits from English 非付费题
01 / Case brief

题目档案

先理解输入与输出。这里不提前展示解法，建议先想一想：乱序之后，还有什么信息没有丢失？

题意

给定字符串 s，它由若干个英文数字单词（zero 到 nine）的全部字母打乱后组成。返回这些原始数字按升序拼接成的字符串。

函数形式：originalDigits(s: string) -> string

关键语义

输入保证有效，因此一定存在一组数字单词，恰好用完 s 中的所有字母。

官方示例

Example 1
输入：s = "owoztneoer"
输出："012"
Example 2
输入：s = "fviefuro"
输出："45"

约束

  • 1 <= s.length <= 105
  • s[i] 是 ["e","g","f","i","h","o","n","s","r","u","t","w","v","x","z"] 中的字符之一。
  • s 保证符合题意。

    03 / Sealed solution

    准备好核对思路了吗？

    题解保持封存，点击后才会展示算法、证明与四种语言实现。

    Core insight

    独特字母 + 分层消元

    乱序只破坏了位置，没有破坏字母频次。某些字母只属于一个数字单词：例如 z 只出现在 zero。先确定这些数字，再从剩余频次中逐层确定其他数字。

    核心洞察

    第一层具有全局独特字母：z→0、w→2、u→4、x→6、g→8。

    扣除第一层后，第二层也出现“剩余唯一”关系：h→3、f→5、s→7。最后用 o→1 与 i→9 收尾。

    计数关系

    cnt[0] = f['z']
    cnt[2] = f['w']
    cnt[4] = f['u']
    cnt[6] = f['x']
    cnt[8] = f['g']
    cnt[3] = f['h'] - cnt[8]
    cnt[5] = f['f'] - cnt[4]
    cnt[7] = f['s'] - cnt[6]
    cnt[1] = f['o'] - cnt[0] - cnt[2] - cnt[4]
    cnt[9] = f['i'] - cnt[5] - cnt[6] - cnt[8]

    完整过程

    1

    清点

    扫描 s，统计 26 个小写字母的出现次数。

    2

    确定偶数层

    依次由 z、w、u、x、g 得到 0、2、4、6、8 的数量。

    3

    消除依赖

    利用已经确定的数量，从 h、f、s、o、i 的频次中扣除共享来源。

    4

    升序组装

    从 0 到 9，将每个数字重复对应次数后拼接。

    正确性证明

    1. 第一层正确。 在十个英文数字单词中，z、w、u、x、g 分别只出现在 zero、two、four、six、eight，因此对应字母的频次恰好等于 0、2、4、6、8 的数量。
    2. 第二层正确。 h 只可能来自 three 与已确定的 eight；扣掉 8 后，剩余 h 数即 3 的数量。f 与 s 同理，分别在扣掉 four 与 six 后唯一对应 five 与 seven。
    3. 末层正确。 o 的来源只有 zero、one、two、four，扣掉已知的 0、2、4 后得到 1；i 的来源只有 five、six、eight、nine，扣掉已知的 5、6、8 后得到 9。
    4. 输出正确。 上述步骤唯一确定全部数字数量；按 0 到 9 的次序重复拼接，得到的正是升序原始数字串。

    复杂度

    时间：O(n)，扫描字符串一次，输出长度也至多与输入同阶。

    空间：O(1)，字母表与数字表大小固定；若计入返回字符串则为 O(n)。

    边界情况

    • 只有一种数字，如 nnei → 9。
    • 同一数字重复多次，如 zerozero → 00。
    • 输入长达 10^5，应避免排列、回溯或反复全串替换。

    替代方案与取舍

    逐词回溯：每次尝试从字母库存中扣除一个数字单词，理论上可行，但分支数随输入增长，无法应对 10^5。通用线性方程：可把十个单词的字母贡献写成方程组求解，但实现复杂，且没有利用本题精心设计的唯一字母结构。分层消元本质上是对这组方程的手工拓扑化，最简洁也最稳定。

    Java · LeetCode submission
    class Solution {
    public String originalDigits(String s) {
        int[] freq = new int[26];
        for (char c : s.toCharArray()) {
            freq[c - 'a']++;
        }

        int[] count = new int[10];
        count[0] = freq['z' - 'a'];
        count[2] = freq['w' - 'a'];
        count[4] = freq['u' - 'a'];
        count[6] = freq['x' - 'a'];
        count[8] = freq['g' - 'a'];
        count[3] = freq['h' - 'a'] - count[8];
        count[5] = freq['f' - 'a'] - count[4];
        count[7] = freq['s' - 'a'] - count[6];
        count[1] = freq['o' - 'a']
                 - count[0] - count[2] - count[4];
        count[9] = freq['i' - 'a']
                 - count[5] - count[6] - count[8];

        StringBuilder answer = new StringBuilder();
        for (int digit = 0; digit <= 9; digit++) {
            answer.append(String.valueOf(digit).repeat(count[digit]));
        }
        return answer.toString();
    }
}
    JavaScript · LeetCode submission
    /**
 * @param {string} s
 * @return {string}
 */
var originalDigits = function(s) {
    const freq = new Array(26).fill(0);
    for (const ch of s) {
        freq[ch.charCodeAt(0) - 97]++;
    }

    const count = new Array(10).fill(0);
    const at = (ch) => freq[ch.charCodeAt(0) - 97];
    count[0] = at('z');
    count[2] = at('w');
    count[4] = at('u');
    count[6] = at('x');
    count[8] = at('g');
    count[3] = at('h') - count[8];
    count[5] = at('f') - count[4];
    count[7] = at('s') - count[6];
    count[1] = at('o') - count[0] - count[2] - count[4];
    count[9] = at('i') - count[5] - count[6] - count[8];

    let answer = '';
    for (let digit = 0; digit <= 9; digit++) {
        answer += String(digit).repeat(count[digit]);
    }
    return answer;
};

    class Solution:
    def originalDigits(self, s: str) -> str:
        freq = [0] * 26
        for ch in s:
            freq[ord(ch) - ord('a')] += 1

        count = [0] * 10
        at = lambda ch: freq[ord(ch) - ord('a')]
        count[0] = at('z')
        count[2] = at('w')
        count[4] = at('u')
        count[6] = at('x')
        count[8] = at('g')
        count[3] = at('h') - count[8]
        count[5] = at('f') - count[4]
        count[7] = at('s') - count[6]
        count[1] = at('o') - count[0] - count[2] - count[4]
        count[9] = at('i') - count[5] - count[6] - count[8]

        return ''.join(str(digit) * count[digit]
                       for digit in range(10))
    C++ · LeetCode submission
    class Solution {
public:
    string originalDigits(string s) {
        array<int, 26> freq{};
        for (char ch : s) {
            ++freq[ch - 'a'];
        }

        array<int, 10> count{};
        count[0] = freq['z' - 'a'];
        count[2] = freq['w' - 'a'];
        count[4] = freq['u' - 'a'];
        count[6] = freq['x' - 'a'];
        count[8] = freq['g' - 'a'];
        count[3] = freq['h' - 'a'] - count[8];
        count[5] = freq['f' - 'a'] - count[4];
        count[7] = freq['s' - 'a'] - count[6];
        count[1] = freq['o' - 'a']
                 - count[0] - count[2] - count[4];
        count[9] = freq['i' - 'a']
                 - count[5] - count[6] - count[8];

        string answer;
        for (int digit = 0; digit <= 9; ++digit) {
            answer.append(count[digit], static_cast<char>('0' + digit));
        }
        return answer;
    }
};

    常见错误

    • 按输入中单词出现顺序输出，而没有按数字升序组装。
    • 直接把 h/f/s/o/i 当作全局唯一字母，忘记扣除先前数字的贡献。
    • 用字符串反复替换单词，造成高常数甚至接近平方级开销。
    • 计算正确却直接遍历计数映射，导致输出顺序不稳定。

    面试追问

    • 如果单词表不是 zero 到 nine，怎样自动寻找可消元的字母顺序？
    • 若输入不保证有效，如何检测负计数或剩余字母并拒绝？
    • 能否流式读取超长输入？哪些状态必须保留？
    • 为何辅助空间可写作 O(1)，输出空间又该怎样单独说明？
