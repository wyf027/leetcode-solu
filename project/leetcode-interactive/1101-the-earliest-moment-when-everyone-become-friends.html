彼此熟识的最早时间

The Earliest Moment When Everyone Become Friends · 并查集 / 排序 / 数组

题目

有 n 个人，编号为 0 到 n-1。日志 logs[i] = [timestamp, x, y] 表示在该时刻 x 与 y 成为朋友。朋友关系可传递：若 a 认识 b、b 认识 c，则 a 与 c 也彼此熟识。返回所有人都处于同一熟人网络的最早时间；若始终无法做到，返回 -1。

函数：int earliestAcq(int[][] logs, int n)

示例 1

输入：logs = [[20190101,0,1],[20190104,3,4],[20190107,2,3],[20190211,1,5],
              [20190224,2,4],[20190301,0,3],[20190312,1,2],[20190322,4,5]], n = 6
输出：20190301

示例 2

输入：logs = [[0,2,0],[1,0,1],[3,0,3],[4,1,2],[7,3,1]], n = 4
输出：3

约束

  • 2 ≤ n ≤ 100
  • 1 ≤ logs.length ≤ 10⁴
  • logs[i].length = 3，且 0 ≤ x, y < n、x ≠ y
  • 时间戳为正整数且互不相同。

题解：按时间建立连通关系

核心洞察：按时间排序后逐条合并两个人所在集合；有效合并使连通分量减一，首次只剩一个分量的时间就是答案。

完整过程

  1. 按时间戳升序排列日志。
  2. 初始化并查集，每个人各自为一个连通分量，共 n 个。
  3. 遇到一条日志时合并两端；若原本属于不同集合，分量数减一。
  4. 分量数变为 1 时立即返回当前时间；遍历结束仍大于 1 则返回 -1。

正确性

排序保证处理完某条日志时，并查集恰好表示截至该时间产生的全部熟识关系。并查集合并与朋友关系的传递闭包等价，因此分量数为 1 当且仅当所有人彼此熟识。算法在首次出现该状态时返回，故返回时间最早；若从未出现，则 -1 正确。

边界与复杂度

n=2、重复连接、跨多个分量的连接及最终不连通都由同一流程覆盖。设日志数为 m：排序为 O(m log m)，并查集合并近似 O(m α(n))，空间 O(n)（若排序实现需额外空间则另计）。

替代方案

每加入一条边后用 DFS/BFS 检查连通性也可行，但可能达到 O(m(n+m))；并查集更直接。若日志天然有序，可省去排序。

面试追问

  • 如何支持动态查询某两人是否熟识？直接查询并查集根。
  • 如何回答任意两人最早连通时间？可考虑离线并查集、重构树或按答案二分。
  • 日志流已按时间到达怎么办？在线合并并在分量数为 1 时输出。

常见错误

  • 忘记先按时间排序。
  • 重复边也错误地减少分量数。
  • 只判断直接朋友，而忽略关系传递。
  • 遍历后未连通却返回最后一个时间戳。

完整代码

class Solution {
    private int[] parent, size;
    public int earliestAcq(int[][] logs, int n) {
        java.util.Arrays.sort(logs, (a, b) -> Integer.compare(a[0], b[0]));
        parent = new int[n]; size = new int[n];
        for (int i = 0; i < n; i++) { parent[i] = i; size[i] = 1; }
        int groups = n;
        for (int[] log : logs)
            if (union(log[1], log[2]) && --groups == 1) return log[0];
        return -1;
    }
    private int find(int x) { return parent[x] == x ? x : (parent[x] = find(parent[x])); }
    private boolean union(int a, int b) {
        a = find(a); b = find(b); if (a == b) return false;
        if (size[a] < size[b]) { int t = a; a = b; b = t; }
        parent[b] = a; size[a] += size[b]; return true;
    }
}
var earliestAcq = function(logs, n) {
  logs.sort((a, b) => a[0] - b[0]);
  const parent = Array.from({length: n}, (_, i) => i), size = Array(n).fill(1);
  const find = x => parent[x] === x ? x : (parent[x] = find(parent[x]));
  let groups = n;
  for (const [time, x, y] of logs) {
    let a = find(x), b = find(y);
    if (a === b) continue;
    if (size[a] < size[b]) [a, b] = [b, a];
    parent[b] = a; size[a] += size[b];
    if (--groups === 1) return time;
  }
  return -1;
};
class Solution:
    def earliestAcq(self, logs: list[list[int]], n: int) -> int:
        parent, size = list(range(n)), [1] * n
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x
        groups = n
        for time, x, y in sorted(logs):
            a, b = find(x), find(y)
            if a == b: continue
            if size[a] < size[b]: a, b = b, a
            parent[b] = a
            size[a] += size[b]
            groups -= 1
            if groups == 1: return time
        return -1
class Solution {
    vector<int> parent, sz;
    int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }
public:
    int earliestAcq(vector<vector<int>>& logs, int n) {
        sort(logs.begin(), logs.end()); parent.resize(n); sz.assign(n, 1);
        iota(parent.begin(), parent.end(), 0); int groups = n;
        for (auto& e : logs) {
            int a = find(e[1]), b = find(e[2]); if (a == b) continue;
            if (sz[a] < sz[b]) swap(a, b);
            parent[b] = a; sz[a] += sz[b];
            if (--groups == 1) return e[0];
        }
        return -1;
    }
