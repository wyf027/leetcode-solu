Core insight

核心洞察：找分界线，不找某个点

把一次二分定义成 lowerBound(value)：返回第一个满足 nums[i] ≥ value 的下标。于是：

  • first = lowerBound(target)
  • last = lowerBound(target + 1) - 1
  • 若 first 越界或 nums[first] ≠ target，目标不存在。
Invariant

半开区间不变量

  1. 01搜索空间始终是 [left, right)。
  2. 02nums[mid] < value，mid 一定不是答案，令 left = mid + 1。
  3. 03否则 mid 可能是最左答案，保留它：right = mid。
  4. 04left === right 时，它就是第一个 ≥ value 的位置。

边界情况

  • 空数组：first 等于 0 但已越界。
  • 单元素：同时是 first 与 last。
  • 目标全数组重复：答案 [0, n - 1]。
  • 目标小于最小值或大于最大值。
  • target + 1 用更宽类型，规避泛化后的溢出风险。

复杂度

TIMEO(log n)
SPACEO(1)

两次二分是 2 · O(log n)，常数不改变渐进复杂度。

替代方案取舍

命中后向两侧扩展：直观，但全是 target 时退化为 O(n)。

分别写 first / last 二分：同样 O(log n)，但重复逻辑更多；面试更推荐复用 lowerBound。

面试高频追问

为什么不是找到 target 就返回？
重复元素中任意命中不能保证边界，必须继续向左或向右收缩。
为什么 right = mid 而不是 mid - 1？
当前使用半开区间且 mid 仍可能是第一个合格位置，不能丢掉。
能否只做一次二分？
找到一个点后仍需确定两端；在最坏情况下仍需要额外搜索。两次边界二分最清晰稳定。

常见错误

  • 混用闭区间和半开区间，导致死循环或漏掉端点。
  • 第二次 lowerBound 忘记减 1。
  • 只检查 first < n，却没检查 nums[first] === target。
  • 直接用 target + 1，却忽略更宽输入范围下的整数溢出。
  • 把“已排序”误读为严格递增，忽略重复元素。

class Solution {
    public int[] searchRange(int[] nums, int target) {
        int first = lowerBound(nums, target);
        if (first == nums.length || nums[first] != target) {
            return new int[] {-1, -1};
        }

        int last = lowerBound(nums, (long) target + 1) - 1;
        return new int[] {first, last};
    }

    private int lowerBound(int[] nums, long value) {
        int left = 0;
        int right = nums.length;

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < value) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }
}

function lowerBound(nums, value) {
    let left = 0;
    let right = nums.length;

    while (left < right) {
        const mid = left + Math.floor((right - left) / 2);
        if (nums[mid] < value) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }
    return left;
}
from typing import List


class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        first = self.lower_bound(nums, target)
        if first == len(nums) or nums[first] != target:
            return [-1, -1]

        last = self.lower_bound(nums, target + 1) - 1
        return [first, last]

    def lower_bound(self, nums: List[int], value: int) -> int:
        left, right = 0, len(nums)

        while left < right:
            mid = left + (right - left) // 2
            if nums[mid] < value:
                left = mid + 1
            else:
                right = mid
        return left
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int first = lowerBound(nums, target);
        if (first == nums.size() || nums[first] != target) {
            return {-1, -1};
        }

        int last = lowerBound(nums, static_cast<long long>(target) + 1) - 1;
        return {first, last};
    }

private:
    int lowerBound(const vector<int>& nums, long long value) {
        int left = 0;
        int right = nums.size();

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] < value) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return left;
    }
};
