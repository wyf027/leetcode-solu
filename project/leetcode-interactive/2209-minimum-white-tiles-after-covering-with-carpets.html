用地毯覆盖后的
最少白色砖块

Minimum White Tiles After Covering With Carpets

有限的地毯，相同的长度。如何安排，才能让露出的白砖尽可能少？

01 / 问题与规则

二进制字符串 floor 表示一排地砖，下标从 0 开始。'0' 是黑砖，'1' 是白砖。你有 numCarpets 条黑色地毯，每条连续覆盖 carpetLen 块砖。地毯之间允许重叠。返回铺设之后仍然可见的白砖数量的最小值。

minimumWhiteTiles(floor, numCarpets, carpetLen) → integer

  • 1 ≤ carpetLen ≤ floor.length ≤ 1000
  • floor[i] 只能是 '0' 或 '1'
  • 1 ≤ numCarpets ≤ 1000

03 / 两种选择，逐步铺开

记录“前 i 块砖，在最多 k 条地毯下，还会露出多少白砖”，用更小的问题决定当前选择。

核心洞察与完整过程

定义 dp[k][i] 为前 i 块砖使用至多 k 条地毯时的最少可见白砖数。这里 i 是前缀长度，最后一块砖的下标为 i−1。

dp[0][i] = 前 i 块砖的白砖数量
dp[k][0] = 0

留出最后一砖：a = dp[k][i-1] + int(floor[i-1])
在末尾铺地毯：b = dp[k-1][max(0, i-carpetLen)]
dp[k][i] = min(a, b)

先初始化没有地毯的一行，再从 k=1 到 K 逐行计算，每行从 i=1 到 n 向右推进。留砖依赖当前行左侧，铺毯依赖上一行向左跳 L 的位置。只保存上一行和当前行，最后返回 dp[K][n]。

若 K×L ≥ n，直接返回 0。使用“至多 K 条”不会改变答案，因为额外地毯可以重叠铺放，不会增加白砖数。

前缀织毯机 · 逐格追踪依赖

橙色条纹是当前“铺毯”分支的候选范围，并非最终方案。青色表格单元是留砖依赖，橙色单元是铺毯依赖，深绿单元是当前结果。

正确性说明

空前缀答案为 0；没有地毯时，所有白砖都可见，所以初始化正确。

对任意最优方案，若最后一块砖未被覆盖，前 i−1 块砖至少产生 dp[k][i−1] 的代价，加上最后一砖的颜色即为留砖分支。若最后一砖被覆盖，可将覆盖它的一条地毯向左平移，使其右端对齐前缀末尾；前缀内原有覆盖不会减少。这条毯遮住最后 L 块砖，剩余较短前缀只能使用至多 k−1 条毯，对应铺毯分支。

两个分支都能通过子问题方案构造出来，因此最小值既可实现，也不超过任意最优方案的代价。按 k、i 的计算顺序归纳，所有状态以及 dp[K][n] 都正确。

i<L 时，max(0,i−L) 将剩余前缀截断为空。物理铺设时可把这条毯放在地板起始位置并延伸到右侧；由于 n≥L，位置合法，额外覆盖不会增加代价。这也解释了重叠不会妨碍递推。

边界与复杂度

  • 全黑答案为 0；全白答案为 max(0,n−K×L)。
  • L=1 时，每条地毯最多遮住一块白砖；L=n 时一条地毯就够。
  • 铺毯后剩余长度必须钳制为 0，不能访问负下标。
  • 时间 O(nK)，滚动数组额外空间 O(n)。提前返回为 O(1)。交互演示保存完整历史，空间 O(nK)。

替代方案

用后缀状态和记忆化搜索也可以：跳过当前砖，或用一条毯并向右跳 L。时间仍为 O(nK)，需要二维缓存和递归栈，Python 还需注意递归深度。二维表方便回溯实际铺法。前缀和能快速计算区间白砖数，但不能独立解决多条地毯的全局选择。

常见错误

  • 反复贪心选白砖最多的区间，忽略它对剩余地毯的影响。
  • 铺毯分支读取当前行，而非上一行，误变成无限条地毯。
  • 仅计算 n−K×L，忽略黑白砖的位置分布。
  • 禁止重叠，或强制每条毯都贡献新覆盖。
  • JavaScript 把字符 '0' 当布尔值；非空字符串是真值，应显式转数字。

面试追问

如何输出具体方案？保存每格选择，从 (K,n) 回溯。地毯长度不同时呢？仅记录数量不够，需跟踪剩余地毯种类或集合。能否原地更新一个数组？覆盖可能破坏上一行依赖，两个数组更直观，且已是 O(n) 空间。

Java · 完整提交代码

class Solution {
    public int minimumWhiteTiles(String floor, int numCarpets, int carpetLen) {
        int n = floor.length();
        if (numCarpets * carpetLen >= n) return 0;
        int[] prev = new int[n + 1];
        for (int i = 1; i <= n; i++)
            prev[i] = prev[i - 1] + (floor.charAt(i - 1) - '0');
        for (int k = 1; k <= numCarpets; k++) {
            int[] curr = new int[n + 1];
            for (int i = 1; i <= n; i++) {
                int leave = curr[i - 1] + (floor.charAt(i - 1) - '0');
                int cover = prev[Math.max(0, i - carpetLen)];
                curr[i] = Math.min(leave, cover);
            }
            prev = curr;
        }
        return prev[n];
    }
}

C++ · 完整提交代码

#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int minimumWhiteTiles(string floor, int numCarpets, int carpetLen) {
        int n = static_cast<int>(floor.size());
        if (numCarpets * carpetLen >= n) return 0;
        vector<int> prev(n + 1, 0);
        for (int i = 1; i <= n; ++i)
            prev[i] = prev[i - 1] + (floor[i - 1] - '0');
        for (int k = 1; k <= numCarpets; ++k) {
            vector<int> curr(n + 1, 0);
            for (int i = 1; i <= n; ++i) {
                int leave = curr[i - 1] + (floor[i - 1] - '0');
                int cover = prev[max(0, i - carpetLen)];
                curr[i] = min(leave, cover);
            }
            prev.swap(curr);
        }
        return prev[n];
    }
};
