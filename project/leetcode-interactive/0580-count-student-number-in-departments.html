给定专业表 Department 和学生表 Student，统计每一个专业当前拥有的学生人数。

  • 输出列为 dept_name 与 student_number。
  • 即使某个专业没有任何学生，也必须输出该专业，人数为 0。
  • 先按学生人数降序；人数相同时，再按专业名升序。
观察目标：结果的“行全集”来自专业表，而不是学生表。

先自己想一想：为什么 COUNT(*) 会让没有学生的专业得到错误结果？准备好后再展开完整题解。

Solution

从 LEFT JOIN 到正确计数

关键不是“怎么数”，而是先确保所有专业都出现在分组输入中，再只统计真实匹配到的学生。

INSIGHT 01

全集在左边

以 Department 为驱动表做左连接，保证没有学生的专业仍产生一行。

INSIGHT 02

数非空主键

COUNT(s.student_id) 忽略左连接补出的 NULL，空专业自然得到零。

INSIGHT 03

稳定排序

先按计数降序，再按专业名升序，明确处理并列人数。

完整过程

1

从 Department d 开始，确定结果必须包含的每个专业。

2

用 d.dept_id = s.dept_id 左连接 Student s。有学生的专业展开成多行；无学生的专业保留一行，学生列为 NULL。

3

按专业主键和名称分组。统计 s.student_id 的非空值数量，而不是统计连接结果的行数。

4

将聚合值命名为 student_number，按它降序、再按 dept_name 升序输出。

官方可提交语言：MySQL

MySQL主答案 · 数据库提交
SELECT
    d.dept_name,
    COUNT(s.student_id) AS student_number
FROM Department AS d
LEFT JOIN Student AS s
    ON d.dept_id = s.dept_id
GROUP BY d.dept_id, d.dept_name
ORDER BY student_number DESC, d.dept_name ASC;

正确性说明

覆盖所有专业

左连接对每条 Department 记录至少保留一条连接结果。因此，每个专业都会进入某个分组并最终输出，包含没有匹配学生的专业。

计数恰好等于学生数

对于任意专业，每名属于它的学生贡献一个非空且唯一的 student_id；补齐行贡献的是 NULL，不会被 COUNT(column) 统计，所以聚合值恰好等于真实学生人数。

边界与复杂度

需要留意的边界

  • 某专业没有学生：必须输出零。
  • 所有专业都没有学生：仍输出全部专业。
  • 多个专业人数相同：按专业名升序。
  • 专业名理论上可能重复：按 dept_id 一同分组可避免误合并。

复杂度视角

设专业数为 D、学生数为 S。实际代价由数据库执行计划、索引和排序实现决定；概念上需要扫描关联数据并对 D 个聚合结果排序。

关联/聚合：约 O(D + S) 结果排序：O(D log D)

import java.util.*;
import java.util.stream.*;

public class Main {
    record Student(int studentId, String name, String gender, int deptId) {}
    record Department(int deptId, String deptName) {}
    record Result(String deptName, long studentNumber) {}

    static List<Result> countStudents(
            List<Student> students,
            List<Department> departments) {
        Map<Integer, Long> counts = students.stream()
                .collect(Collectors.groupingBy(
                        Student::deptId,
                        Collectors.counting()
                ));

        return departments.stream()
                .map(dept -> new Result(
                        dept.deptName(),
                        counts.getOrDefault(dept.deptId(), 0L)
                ))
                .sorted(Comparator
                        .comparingLong(Result::studentNumber)
                        .reversed()
                        .thenComparing(Result::deptName))
                .toList();
    }

    public static void main(String[] args) {
        List<Student> students = List.of(
                new Student(1, "Jack", "M", 1),
                new Student(2, "Jane", "F", 1),
                new Student(3, "Mark", "M", 2)
        );
        List<Department> departments = List.of(
                new Department(1, "Engineering"),
                new Department(2, "Science"),
                new Department(3, "Law")
        );

        countStudents(students, departments).forEach(System.out::println);
    }
}

function countStudents(students, departments) {
  const counts = new Map();

  for (const student of students) {
    counts.set(student.deptId, (counts.get(student.deptId) ?? 0) + 1);
  }

  return departments
    .map((department) => ({
      deptName: department.deptName,
      studentNumber: counts.get(department.deptId) ?? 0,
    }))
    .sort((a, b) =>
      b.studentNumber - a.studentNumber ||
      a.deptName.localeCompare(b.deptName)
    );
}

from collections import Counter
from dataclasses import dataclass


@dataclass(frozen=True)
class Student:
    student_id: int
    name: str
    gender: str
    dept_id: int


@dataclass(frozen=True)
class Department:
    dept_id: int
    dept_name: str


def count_students(students: list[Student],
                   departments: list[Department]) -> list[tuple[str, int]]:
    counts = Counter(student.dept_id for student in students)
    result = [
        (department.dept_name, counts[department.dept_id])
        for department in departments
    ]
    return sorted(result, key=lambda row: (-row[1], row[0]))


students = [
    Student(1, "Jack", "M", 1),
    Student(2, "Jane", "F", 1),
    Student(3, "Mark", "M", 2),
]
departments = [
    Department(1, "Engineering"),
    Department(2, "Science"),
    Department(3, "Law"),
]

for dept_name, student_number in count_students(students, departments):
    print(dept_name, student_number)
C++17本地语义参考 · 未执行
#include <algorithm>
#include <iostream>
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>

using namespace std;

struct Student {
    int studentId;
    string name;
    string gender;
    int deptId;
};

struct Department {
    int deptId;
    string deptName;
};

vector<pair<string, int>> countStudents(
        const vector<Student>& students,
        const vector<Department>& departments) {
    unordered_map<int, int> counts;
    for (const Student& student : students) {
        ++counts[student.deptId];
    }

    vector<pair<string, int>> result;
    result.reserve(departments.size());
    for (const Department& department : departments) {
        result.push_back({department.deptName, counts[department.deptId]});
    }

    sort(result.begin(), result.end(), [](const auto& a, const auto& b) {
        if (a.second != b.second) return a.second > b.second;
        return a.first < b.first;
    });
    return result;
}

int main() {
    vector<Student> students = {
        {1, "Jack", "M", 1},
        {2, "Jane", "F", 1},
        {3, "Mark", "M", 2},
    };
    vector<Department> departments = {
        {1, "Engineering"},
        {2, "Science"},
        {3, "Law"},
    };

    for (const auto& [name, count] : countStudents(students, departments)) {
        cout << name << " " << count << '\n';
    }
}

替代方案、面试追问与常见错误

替代方案：相关子查询

可以为每个专业执行一个相关子查询来统计学生。写法直观，但优化器之外的直觉成本通常高于一次连接聚合；本题更适合展示左连接语义。

追问：为什么不能 COUNT(*)？

左连接会为无学生的专业保留一条补齐行。COUNT(*) 会把这条行也计为 1；COUNT(s.student_id) 只统计非空学生主键，因此得到 0。

追问：索引如何设计？

Department.dept_id 应为主键，Student.dept_id 上的索引有助于关联；是否使用索引仍由数据规模和优化器计划决定。

常见错误清单
  • 从 Student 出发，直接丢失空专业。
  • 把 LEFT JOIN 写成 INNER JOIN。
  • 使用 COUNT(*)，空专业被算成 1。
  • 遗漏第二排序键 dept_name。
  • 只按可能重复的 dept_name 分组。
