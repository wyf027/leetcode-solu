Problem

题意

给定一棵允许出现重复值的二叉搜索树，其根节点为 root。请返回树中出现频率最高的全部元素，也就是所有众数。如果众数不止一个，可以按任意顺序返回。

这里的 BST 满足：左子树中的值均小于等于当前节点值，右子树中的值均大于等于当前节点值，并且左右子树也都是二叉搜索树。

进阶：能否不使用额外空间？题目约定递归带来的隐式调用栈不计入额外空间。

示例 1

重复值 
输入：root = [1,null,2,2]
输出：[2]

值 2 出现两次，次数高于其他元素。

示例 2

单节点 
输入：root = [0]
输出：[0]

只有一个元素时，它自然就是唯一的众数。

约束

  • 树中节点数在 [1, 10⁴] 范围内。
  • -10⁵ ≤ Node.val ≤ 10⁵。
  • 返回值类型为整数数组：findMode(root: TreeNode) → integer[]。

Solution

中序遍历 + 连续段计数

核心洞察

BST 的中序遍历结果是非递减序列，因此相同的值一定连续出现。问题就从“统计整棵树的频次”转化为“扫描有序序列中的连续段”：只需记住前一个值、当前连续次数、全局最高频次以及答案集合。

更新规则：当前次数超过最高频次时清空答案并加入当前值；等于最高频次时，把当前值追加到答案；更小时不改变答案。

1 · 中序访问

按“左子树 → 当前节点 → 右子树”遍历，让相同值自然相邻。

2 · 维护连续次数

若当前值等于前一个值，计数加一；否则开启长度为 1 的新连续段。

3 · 更新最高频次

更大的连续次数会产生新的最高频次，并使旧答案全部失效。

4 · 收集并列众数

连续次数与当前最高频次相等时，保留当前值作为并列答案。

完整过程

  1. 初始化 prev、count = 0、maxCount = 0 和空答案数组。
  2. 递归遍历左子树。
  3. 访问当前节点：比较它与 prev，更新当前连续次数。
  4. 将当前连续次数与 maxCount 比较，按“替换 / 追加 / 不变”更新答案。
  5. 将当前值保存为 prev，再递归遍历右子树。

正确性证明

  1. 相邻性：BST 的中序序列非递减，所以每个值的全部出现构成一个连续段，连续段长度正是该值的总频次。
  2. 计数正确：扫描时，相同值使 count 加一，不同值使其重置为 1，因此访问每个节点后，count 等于当前值已扫描连续段的长度。
  3. 答案不变式：每次访问后，maxCount 是已完成或正在扫描的连续段中的最大长度，答案恰好包含达到该长度的所有值。更大值替换答案，相等值追加答案，都会维持该不变式。
  4. 结论：遍历结束时所有节点均被扫描，每个值的完整频次均已参与比较，因此答案恰好是整棵树的全部众数。

复杂度

时间复杂度 O(n)，每个节点访问一次。递归调用栈为 O(h)，其中 h 是树高；除输出数组与递归栈外，只使用 O(1) 状态。

边界情况

单节点；全部值相同；所有值互不相同（此时全部都是众数）；存在多个并列众数；树退化为链；节点值为负数或边界值。

替代方案

哈希表计数适用于任意二叉树，但需要 O(n) 额外空间。Morris 中序遍历可把遍历辅助空间降到 O(1)，代价是临时修改指针且实现更复杂。

常见错误

新最高频次出现时忘记清空答案；初始化前驱值时与合法节点值冲突；在遍历左右子树之间更新顺序错误；只返回一个众数；误以为重复值只能出现在固定一侧。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private Integer previous = null;
    private int count = 0;
    private int maxCount = 0;
    private final List<Integer> modes = new ArrayList<>();

    public int[] findMode(TreeNode root) {
        inorder(root);
        int[] answer = new int[modes.size()];
        for (int i = 0; i < modes.size(); i++) {
            answer[i] = modes.get(i);
        }
        return answer;
    }

    private void inorder(TreeNode node) {
        if (node == null) {
            return;
        }

        inorder(node.left);

        if (previous != null && previous == node.val) {
            count++;
        } else {
            count = 1;
        }

        if (count > maxCount) {
            maxCount = count;
            modes.clear();
            modes.add(node.val);
        } else if (count == maxCount) {
            modes.add(node.val);
        }

        previous = node.val;
        inorder(node.right);
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {number[]}
 */
var findMode = function(root) {
    let previous = null;
    let count = 0;
    let maxCount = 0;
    let modes = [];

    const inorder = (node) => {
        if (node === null) {
            return;
        }

        inorder(node.left);

        if (previous !== null && previous === node.val) {
            count++;
        } else {
            count = 1;
        }

        if (count > maxCount) {
            maxCount = count;
            modes = [node.val];
        } else if (count === maxCount) {
            modes.push(node.val);
        }

        previous = node.val;
        inorder(node.right);
    };

    inorder(root);
    return modes;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def findMode(self, root: Optional[TreeNode]) -> List[int]:
        previous = None
        count = 0
        max_count = 0
        modes = []

        def inorder(node: Optional[TreeNode]) -> None:
            nonlocal previous, count, max_count, modes
            if node is None:
                return

            inorder(node.left)

            if previous is not None and previous == node.val:
                count += 1
            else:
                count = 1

            if count > max_count:
                max_count = count
                modes = [node.val]
            elif count == max_count:
                modes.append(node.val)

            previous = node.val
            inorder(node.right)

        inorder(root)
        return modes
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    bool hasPrevious = false;
    int previous = 0;
    int count = 0;
    int maxCount = 0;
    vector<int> modes;

    void inorder(TreeNode* node) {
        if (node == nullptr) {
            return;
        }

        inorder(node->left);

        if (hasPrevious && previous == node->val) {
            ++count;
        } else {
            count = 1;
        }

        if (count > maxCount) {
            maxCount = count;
            modes.clear();
            modes.push_back(node->val);
        } else if (count == maxCount) {
            modes.push_back(node->val);
        }

        hasPrevious = true;
        previous = node->val;
        inorder(node->right);
    }

public:
    vector<int> findMode(TreeNode* root) {
        inorder(root);
        return modes;
    }
};

面试追问

  • 如果输入只是普通二叉树？ 无法利用中序有序性，通常需要哈希表统计频次。
  • 如何真正做到常数级遍历辅助空间？ 使用 Morris 中序遍历，以临时线索指针替代显式栈与递归。
  • 能否分两遍遍历？ 可以。第一遍求最大频次，第二遍收集达到该频次的值，可避免答案清空，但会访问两次树。
  • 为什么不能把前驱初始为某个哨兵整数？ 合法值覆盖一段整数范围，硬编码哨兵容易与真实节点值冲突；应额外记录是否已有前驱，或使用可空类型。
