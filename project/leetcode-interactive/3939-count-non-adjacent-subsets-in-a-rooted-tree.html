LEETCODE 3939 · HARD

统计有根树中不相邻子集的数目

把“选或不选当前节点”的约束拆成两条模数分布：选父节点时孩子只能不选；不选父节点时孩子可自由选择。

树形 DP 独立集 模数卷积

题意

给定根为 0 的树：parent[i] 是节点 i 的父节点，nums[i] 是节点权值。统计非空节点子集：任意父子不能同时被选，且权值和能被 k 整除。答案对 1_000_000_007 取模。

示例 1

parent = [-1, 0, 1]
nums = [1, 2, 3]
k = 3

输出 1：只有 {2} 的和为 3，且没有相邻节点。

示例 2

parent = [-1, 0, 0, 0]
nums = [2, 1, 2, 1]
k = 3

输出 2：{1, 2} 与 {2, 3} 都满足条件。

约束：1 ≤ n ≤ 1000，1 ≤ k ≤ 100，且 parent[i] < i。这个顺序让我们可以从 n - 1 向 0 自底向上处理。

题解

先自己想一想状态定义，再按需展开。

核心洞察：边约束只跨父子

对于节点 u，子树内部的选择只会通过“u 是否被选”影响其父亲：若选择 u，每个孩子都必须处于不选状态；若不选择 u，孩子可以选或不选。模数 r 是第二个维度，因此每个状态保存长度 k 的计数数组。

状态

  • dp0[u][r]：u 的子树中，u 不选、和值模 k 为 r 的方案数。
  • dp1[u][r]：u 的子树中，u 被选、和值模 k 为 r 的方案数。
  • 初始：dp0[u][0]=1；dp1[u][nums[u]%k]=1。

合并一个孩子 v

  • 父不选：孩子可选可不选，使用 dp0[v][b]+dp1[v][b]。
  • 父选：孩子只能不选，使用 dp0[v][b]。
  • 余数相加：新下标为 (a+b)%k。

完整过程与答案

  1. 根据 parent 建孩子表；因为 parent[i] < i，从后向前枚举节点即可保证孩子已经完成。
  2. 为当前节点建立两条长度 k 的分布；逐个卷入孩子的两条分布。
  3. 根节点的余数 0 同时可来自选根或不选根；减去唯一的空集合。

ans = (dp0[0][0] + dp1[0][0] - 1 + MOD) % MOD

边界

  • n=1 时仅有“空集”与“选根”两种结构，最后必须去掉空集。
  • 值很大时先取模，避免把数值和直接累加。
  • 每次卷积要使用临时数组，不能原地复用正在读的分布。

复杂度与替代方案

每条父子边进行两次 k×k 合并，时间 O(n·k²)，空间 O(n·k)。若 k 极大，需要用多项式优化；本题 k≤100，朴素模数卷积更直接可靠。

面试追问与常见错误

追问：若限制变成“距离不超过 2 的节点不能同时选”？答案是把状态扩展为记录父与祖父是否被选。
错误：把父不选也错误地限制孩子不选；或忘记从余数 0 的总计数中扣除空集合。
