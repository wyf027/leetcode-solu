Solution unlocked

左到右累积位权

不是普通 0–25：Excel 字母位从 A=1 到 Z=26，没有表示零的字符。

核心公式

从左到右读取。每读一位，已有结果整体左移一个 26 进制位，再加当前字母值：

result = result × 26 + (ch − 'A' + 1)

例如 "AB"：先得到 1，再计算 1 × 26 + 2 = 28。

完整过程与正确性

  1. 初始化 result = 0。
  2. 逐字符映射为 1…26。
  3. 用霍纳法更新 result = result × 26 + digit。
  4. 循环结束即得到所有位权之和。霍纳展开等价于 d₀×26ᵏ + … + dₖ，因此结果正确。

与第 168 题互逆

168 将编号转列标题：每轮先减一，把 1–26 偏移回 0–25，再取模与整除。171 则按相反方向，把每个 1–26 数位重新乘 26 累加。

可用性质测试验证：对任意合法编号 n，应满足 titleToNumber(convertToTitle(n)) == n。

边界与复杂度

时间 O(L)

L 为字符串长度，最多 7。

空间 O(1)

只保存累积结果与当前数位。

最小值

"A" = 1。

最大值

"FXSHRXW" = 2³¹−1。

替代与追问

  • 从右到左显式维护 power *= 26，同为 O(L)，但状态更多。
  • 若允许超出 32 位，Java/C++ 应改用 64 位或大整数。
  • 如何实现第 168 题并证明互逆？
  • 若输入包含小写或非法字符，如何定义校验策略？

常见错误

  • 使用 A=0，把 Excel 编码误当普通 26 进制。
  • 漏掉每轮的 result × 26。
  • 把字符编码值直接加入结果。
  • 处理更宽输入时仍使用 32 位整数导致溢出。

class Solution {
    public int titleToNumber(String columnTitle) {
        int result = 0;
        for (char ch : columnTitle.toCharArray()) {
            result = result * 26 + (ch - 'A' + 1);
        }
        return result;
    }
}

var titleToNumber = function (columnTitle) {

        result = result * 26 + digit;
