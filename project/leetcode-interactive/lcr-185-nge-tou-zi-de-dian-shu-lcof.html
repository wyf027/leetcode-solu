04 · COMPLETE SOLUTION

完整题解与可提交代码

核心洞察

面试推荐一维动态规划：同一个点数和可能由多条投掷路径产生，只需统计路径数，无需枚举具体序列。最后统一除以 6num 得到概率。

完整过程

  1. 一枚骰子时，点数和 1 至 6 的组合数均为 1。
  2. 加入新骰子，把上一层每个组合数分别累加到后续 6 个位置。
  3. 滚动数组只保留上一层与当前层，直到合并 num 枚骰子。
  4. 将最终组合数逐项除以总组合数，顺序返回。

边界

num = 1 时返回 6 个相同概率；num = 11 时数组长度为 56。分布左右对称，所有概率之和应接近 1；浮点误差不能用严格相等判断。

复杂度

第 k 层有 5k + 1 个状态，每个状态扩散到 6 个面值，因此时间 O(num²)、空间 O(num)。

替代方案与追问

可使用二维 DP 保留每一层分布，便于解释但空间为 O(num²)；也可做生成函数多项式乘法。面试可追问：若骰子面数不同、各面概率不均或需要精确分数，状态与归一化应如何修改？

常见错误

混淆数组下标与实际点数和；原地正序更新导致同一枚骰子被重复使用；数组长度写成 6 × num；忘记除以总组合数；用严格相等校验概率和。

var statisticsProbability = function(num) {
  let dp = Array(6).fill(1);
  for (let dice = 2; dice <= num; dice++) {
    const next = Array(5 * dice + 1).fill(0);
    for (let i = 0; i < dp.length; i++) for (let face = 1; face <= 6; face++) next[i + face - 1] += dp[i];
    dp = next;
  }
  return dp.map((ways) => ways / 6 ** num);
};
class Solution {
    public double[] statisticsProbability(int num) {
        double[] dp = new double[6];
        java.util.Arrays.fill(dp, 1.0 / 6);
        for (int dice = 2; dice <= num; dice++) { double[] next = new double[5 * dice + 1]; for (int i = 0; i < dp.length; i++) for (int face = 0; face < 6; face++) next[i + face] += dp[i] / 6; dp = next; }
        return dp;
    }
}
from typing import List
class Solution:
    def statisticsProbability(self, num: int) -> List[float]:
        dp = [1 / 6] * 6
        for dice in range(2, num + 1):
            nxt = [0.0] * (5 * dice + 1)
            for i, probability in enumerate(dp):
                for face in range(6): nxt[i + face] += probability / 6
            dp = nxt
        return dp
