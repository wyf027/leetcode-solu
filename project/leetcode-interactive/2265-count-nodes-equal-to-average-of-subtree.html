统计值等于
子树平均值的节点数

Count Nodes Equal to Average of Subtree

从一个节点出发，观察它与所有后代：它的值，恰好等于这片子树的整数平均值吗？

01 / 题目

输入二叉树根节点 root，返回满足以下条件的节点数量：该节点的值等于其子树全部节点值的平均数向下取整后的结果。

  • 子树包括当前节点自己，以及它的所有后代。
  • 平均值为 ⌊节点值总和 / 节点数⌋，例如 ⌊11 / 2⌋ = 5。
  • 参数：root: TreeNode；返回：integer。下方数组用层序表示二叉树，null 表示空位置。

约束

  • 树中有 1 至 1000 个节点。
  • 0 ≤ Node.val ≤ 1000。

示例 1

输入：root = [4,8,5,0,1,null,6]
输出：5

值为 4、5、0、1、6 的节点符合条件。根节点的平均值为 24 / 6 = 4；值为 5 的节点所在子树为 ⌊11 / 2⌋ = 5；三个叶子分别等于自身平均值。值为 8 的节点对应 ⌊9 / 3⌋ = 3，不符合条件。

示例 2

输入：root = [1]
输出：1

只有根节点，子树平均值为 1 / 1 = 1，因此答案为 1。

04 / 独立题解

核心洞察：向上递交两项统计

每个子树只需返回 (sum, count)：节点值总和与节点数量。先处理左右孩子，再处理父节点，即后序遍历。合并时把当前节点也加入，再做一次取整比较。

空子树 → (0, 0)
sum   = left.sum + right.sum + node.val
count = left.count + right.count + 1
若 floor(sum / count) == node.val：答案加 1
向父节点返回 (sum, count)

完整过程

  1. 进入节点后，先得到左子树的统计，再得到右子树的统计。
  2. 0 与 1 都是叶子，分别返回 (0,1)、(1,1)，各命中一次。
  3. 节点 8 合并得到 (9,3)，平均值 3，与 8 不等。
  4. 节点 6 返回 (6,1) 并命中；节点 5 得到 (11,2)，取整后为 5，也命中。
  5. 根节点合并得到 (24,6)，平均值 4，命中。总计 5 个节点。

正确性证明

对子树大小归纳。空子树返回 (0,0)，统计正确。假设左右子树的返回值正确，它们与当前节点互不重叠，且恰好覆盖当前整棵子树，所以相加后的 sum 和 count 正确。根据题目定义，比较 ⌊sum/count⌋ 与当前值，恰好判断其是否满足条件。每个非空节点只被判断一次，累加结果正是所求数量。

复杂度与边界

时间 O(n)，每个节点只合并一次；递归辅助空间 O(h)，h 为树高，最坏斜树为 O(n)，平衡树为 O(log n)。单节点和所有叶子必然命中；空孩子只返回统计，不参与除法。最大 sum 为 1,000,000，32 位整数足够。Python 代码采用显式栈避免 1000 层斜树触及默认递归深度限制。

四语言实现

沿用官方 averageOfSubtree 签名；TreeNode 由 LeetCode 提供，无需重复定义。以下是完整提交解法，尚未执行。

Java

class Solution {
    private int answer;

    public int averageOfSubtree(TreeNode root) {
        answer = 0;
        dfs(root);
        return answer;
    }

    private int[] dfs(TreeNode node) {
        if (node == null) return new int[]{0, 0};
        int[] left = dfs(node.left);
        int[] right = dfs(node.right);
        int sum = left[0] + right[0] + node.val;
        int count = left[1] + right[1] + 1;
        if (sum / count == node.val) answer++;
        return new int[]{sum, count};
    }
}

JavaScript

/**
 * @param {TreeNode} root
 * @return {number}
 */
var averageOfSubtree = function(root) {
    let answer = 0;
    function dfs(node) {
        if (node === null) return [0, 0];
        const [ls, lc] = dfs(node.left);
        const [rs, rc] = dfs(node.right);
        const sum = ls + rs + node.val;
        const count = lc + rc + 1;
        if (Math.floor(sum / count) === node.val) answer++;
        return [sum, count];
    }
    dfs(root);
    return answer;
};

Python 3 · 显式后序栈

class Solution:
    def averageOfSubtree(self, root: TreeNode) -> int:
        if root is None:
            return 0
        # 帧：[节点, 阶段, 已累计总和, 已累计数量]
        stack = [[root, 0, root.val, 1]]
        answer = 0
        while stack:
            frame = stack[-1]
            node, phase = frame[0], frame[1]
            if phase == 0:
                frame[1] = 1
                if node.left is not None:
                    stack.append([node.left, 0, node.left.val, 1])
            elif phase == 1:
                frame[1] = 2
                if node.right is not None:
                    stack.append([node.right, 0, node.right.val, 1])
            else:
                _, _, total, count = stack.pop()
                if total // count == node.val:
                    answer += 1
                if stack:
                    stack[-1][2] += total
                    stack[-1][3] += count
        return answer

阶段 0 处理左孩子，阶段 1 处理右孩子，阶段 2 结算并回传。只保留路径上的帧，时间 O(n)、空间 O(h)。

C++

#include <utility>
using std::pair;

class Solution {
    int answer = 0;

    pair<int, int> dfs(TreeNode* node) {
        if (node == nullptr) return {0, 0};
        auto left = dfs(node->left);
        auto right = dfs(node->right);
        int sum = left.first + right.first + node->val;
        int count = left.second + right.second + 1;
        if (sum / count == node->val) ++answer;
        return {sum, count};
    }

public:
    int averageOfSubtree(TreeNode* root) {
        answer = 0;
        dfs(root);
        return answer;
    }
};

替代方案与常见错误

  • 逐节点重扫子树：逻辑直观，最坏斜树耗时 O(n²)，不如复用子树统计。
  • 显式栈：模拟后序回传，避免运行时递归栈限制；Python 版本展示了 O(h) 帧栈方案。若用映射保存所有节点统计，额外空间变成 O(n)。
  • 平均数不能直接平均：左右子树节点数可能不同，应合并总和与数量，不能平均两边的平均数。
  • 别忘了自己：sum 要加 node.val，count 要加 1。
  • 必须取整：11/2 对应 5；不能用浮点结果直接和节点值比较。
  • 不能换成 sum == val × count：这个等式忽略向下取整，例如节点 5 与孩子 6 也应命中。
  • 遍历顺序：父节点结算之前，两个孩子的统计必须已经完成。重复调用时，要重新初始化答案。

面试追问

不用除法怎么判断？由于 count > 0，可以用 val × count ≤ sum < (val + 1) × count。更大约束下乘法需注意溢出。

如果允许负数？仍需向下取整；Java/C++ 的整数除法朝零截断，不能直接沿用，需修正商。当前题目值均非负。

如果节点值频繁修改？一次修改会影响全部祖先的子树统计；当前解法适用于一次静态查询，动态版本需根据树高和修改频率另行设计。
