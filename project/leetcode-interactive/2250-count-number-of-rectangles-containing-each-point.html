Count Number of Rectangles Containing Each Point

同一个原点，不同的右上角。对于每个点，有多少个矩形把它圈在里面？

01 / 题目说明

给定二维整数数组 rectangles 和 points。rectangles[i] = [lᵢ, hᵢ] 表示长为 lᵢ、高为 hᵢ 的矩形；points[j] = [xⱼ, yⱼ] 表示一个点。

每个矩形的左下角都在 (0,0)，右上角在 (lᵢ,hᵢ)。返回长度等于 points.length 的整数数组 count，count[j] 表示包含第 j 个点的矩形个数，顺序与输入点一致。

包含条件：0 ≤ xⱼ ≤ lᵢ 且 0 ≤ yⱼ ≤ hᵢ。边上与角上的点同样计入。

示例 1

rectangles = [[1,2],[2,3],[2,5]]
points = [[2,1],[1,4]]
输出：[2,1]

[1,2] 不包含这两个点；[2,3] 只包含 (2,1)；[2,5] 包含 (2,1) 与 (1,4)。两个点分别被 2、1 个矩形包含。

示例 2

rectangles = [[1,1],[2,2],[3,3]]
points = [[1,3],[1,1]]
输出：[1,3]

(1,3) 仅被 [3,3] 包含；(1,1) 被三个矩形全部包含，其中它正好位于 [1,1] 的右上角。

02 / 约束与思考

  • 1 ≤ rectangles.length, points.length ≤ 5 × 10⁴
  • rectangles[i].length == points[j].length == 2
  • 1 ≤ lᵢ, xⱼ ≤ 10⁹
  • 1 ≤ hᵢ, yⱼ ≤ 100
  • 所有矩形互不相同；所有点互不相同。

04 / 独立题解

展开后查看算法、交互实验与代码。

核心洞察：高度分桶，长度二分

矩形共享原点，判断只需 l ≥ x 与 h ≥ y。高度最多为 100，把矩形按精确高度分为 101 个桶（0 号不用），每个桶仅保存长度，并升序排序。

对于点 (x,y)，枚举高度 y..100。每个桶里二分找到第一个 ≥ x 的位置 k，该桶贡献就是 桶大小 − k。所有桶贡献之和即为答案。

交互实验 / 追踪二分的切分位置

青色单元格表示候选区间 [L,R)，橙色标记 mid。二分结束后青色显示命中后缀。演示跳过空高度桶，它们的贡献均为 0。



青色边框：包含当前点；灰色虚线：不包含。橙色点：当前查询。横纵轴分别缩放。


Tab 切换焦点，Enter / 空格激活按钮；聚焦本演示区域时按 ← / → 单步。支持减少动态效果偏好，不使用移动动画。


完整过程
  1. 建立 101 个互相独立的桶，将每个矩形长度 l 放入 buckets[h]。
  2. 分别对每个桶中的长度进行数值升序排序。
  3. 按输入顺序查询每个点，计数从 0 开始。
  4. 对 h=y..100 的桶，初始化半开区间 [L,R)=[0,n)。若 a[mid] < x，令 L=mid+1，否则 R=mid。
  5. 当 L=R 时，下界 k=L，累加 n−k。处理完所有合法高度后记录结果。
示例 1 的 (2,1)：高度 2 桶 [1] 贡献 0；高度 3 桶 [2] 贡献 1；高度 5 桶 [2] 贡献 1，总计 2。点 (1,4) 只从高度 5 桶得到 1。


正确性证明
高度筛选：h < y 时必不包含点；h ≥ y 的所有矩形都在枚举桶中，且每个矩形只属于一个精确高度桶。
二分不变量：L 左侧的长度全部小于 x，R 及右侧的长度全部大于等于 x。根据 mid 比较结果移动 L 或 R，保持这两个条件。终止于 L=R=k 时，k 就是第一个 ≥ x 的位置，也可能等于 n。
合并计数：每个桶后缀 [k,n) 中的矩形恰好同时满足 l ≥ x、h ≥ y。桶之间不重叠，因此将 n−k 相加无遗漏也无重复。逐点按原顺序写入，得到题目要求的数组。


边界与常见错误
  • 边界相等也包含，必须找第一个 ≥ x，而不是第一个 > x。
  • 空桶直接贡献 0；长度全部不足时 k=n。
  • y=100 时仍要查询高度 100，循环上界是包含式。
  • JavaScript 必须使用数值比较器排序，不能使用默认字典序。
  • 不要让多个桶共享同一个可变数组。
  • 无需计算面积。长度可达 10⁹，单点计数最多 5×10⁴。
复杂度
设 N 为矩形数、M 为点数、H=100。建桶 O(N+H)，各桶排序总时间上界 O(N log N)。
每点查询最多 H 个桶，总时间 O(N log N + MH log(N+1) + H)，包含空桶扫描的常数工作。
桶存储 O(N+H)，输出 O(M)，连同输出的总辅助空间为 O(N+M+H)。各语言排序所用栈或临时空间不超过该总体上界。


替代方案
  • 暴力：每个点遍历所有矩形，O(NM) 时间，除输出外 O(1) 空间。最大输入下不合适。
  • 按 x 降序离线：矩形按长度降序、点按 x 降序。处理点前加入所有 l ≥ x 的矩形，用高度频次数组累加 y..100。耗时 O(N log N + M log M + MH)，要记录点的原索引。
  • 离线加树状数组：对已加入矩形做高度单点更新，查询“已加入总数 − 前缀和(y−1)”。耗时 O(N log N + M log M + (N+M) log H)。
面试追问
  • 高度没有 100 的限制怎么办？可离线扫描 x，再离散化高度并用树状数组计数，避免枚举整个高度范围。
  • 矩形左下角不固定怎么办？只检查右上角已不充分，需要处理左右、上下四个边界，考虑扫描线与多维范围计数。
  • 支持矩形动态增删吗？静态排序桶不便更新，应明确是否在线，再考虑动态有序结构或离散化后的计数结构。

Java
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public int[] countRectangles(int[][] rectangles, int[][] points) {
        List<List<Integer>> buckets = new ArrayList<>();
        for (int h = 0; h <= 100; h++) {
            buckets.add(new ArrayList<>());
        }
        for (int[] rect : rectangles) {
            buckets.get(rect[1]).add(rect[0]);
        }
        for (List<Integer> bucket : buckets) Collections.sort(bucket);
        int[] answer = new int[points.length];
        for (int i = 0; i < points.length; i++) {
            int x = points[i][0], y = points[i][1];
            for (int h = y; h <= 100; h++) {
                List<Integer> bucket = buckets.get(h);
                int left = 0, right = bucket.size();
                while (left < right) {
                    int mid = left + (right - left) / 2;
                    if (bucket.get(mid) < x) left = mid + 1;
                    else right = mid;
                }
                answer[i] += bucket.size() - left;
            }
        }
        return answer;
    }
}

var countRectangles = function(rectangles, points) {
    const buckets = Array.from({ length: 101 }, () => []);
    for (const [length, height] of rectangles) {
        buckets[height].push(length);
    }
    for (const bucket of buckets) bucket.sort((a, b) => a - b);
    return points.map(([x, y]) => {
        let count = 0;
        for (let h = y; h <= 100; h++) {
            const bucket = buckets[h];
            let left = 0, right = bucket.length;
            while (left < right) {
                const mid = left + Math.floor((right - left) / 2);
                if (bucket[mid] < x) left = mid + 1;
                else right = mid;
            }
            count += bucket.length - left;
        }
        return count;
    });
};


Python 3
from bisect import bisect_left
from typing import List

class Solution:
    def countRectangles(self, rectangles: List[List[int]],
                        points: List[List[int]]) -> List[int]:
        buckets = [[] for _ in range(101)]
        for length, height in rectangles:
            buckets[height].append(length)
        for bucket in buckets:
            bucket.sort()
        answer = []
        for x, y in points:
            count = 0
            for h in range(y, 101):
                bucket = buckets[h]
                count += len(bucket) - bisect_left(bucket, x)
            answer.append(count)
        return answer


C++
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> countRectangles(vector<vector<int>>& rectangles,
                                vector<vector<int>>& points) {
        vector<vector<int>> buckets(101);
        for (const auto& rect : rectangles) {
            buckets[rect[1]].push_back(rect[0]);
        }
        for (auto& bucket : buckets) {
            sort(bucket.begin(), bucket.end());
        }
        vector<int> answer;
        answer.reserve(points.size());
        for (const auto& point : points) {
            int count = 0;
            for (int h = point[1]; h <= 100; ++h) {
                const auto& bucket = buckets[h];
                auto it = lower_bound(bucket.begin(), bucket.end(), point[0]);
                count += static_cast<int>(bucket.end() - it);
            }
            answer.push_back(count);
        }
        return answer;
    }
};
