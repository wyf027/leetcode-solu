二维网格迁移

Shift 2D Grid — 看清一个二维网格如何沿着行优先顺序首尾相接地移动。

任务

给定 m × n 网格与整数 k，返回连续迁移 k 次后的二维网格。

1260

01 / Problem

题目描述

给你一个 m 行 n 列的二维网格 grid 和一个整数 k。每次迁移时：

  • 非末列元素 grid[i][j] 移到同一行的 grid[i][j + 1]；
  • 每行末尾的 grid[i][n - 1] 移到下一行开头 grid[i + 1][0]；
  • 右下角 grid[m - 1][n - 1] 回到左上角 grid[0][0]。

返回执行恰好 k 次迁移后的二维网格。

示例 1

输入：grid = [[1,2,3],
              [4,5,6],
              [7,8,9]], k = 1
输出：[[9,1,2],
      [3,4,5],
      [6,7,8]]

示例 2

输入：grid = [[3,8,1,9],
              [19,7,2,5],
              [4,6,11,10],
              [12,0,21,13]], k = 4
输出：[[12,0,21,13],
      [3,8,1,9],
      [19,7,2,5],
      [4,6,11,10]]

示例 3

输入：grid = [[1,2,3],
              [4,5,6],
              [7,8,9]], k = 9
输出：[[1,2,3],
      [4,5,6],
      [7,8,9]]

约束

  • m == grid.length
  • n == grid[i].length
  • 1 <= m <= 50
  • 1 <= n <= 50
  • -1000 <= grid[i][j] <= 1000
  • 0 <= k <= 100

04 / Solution

题解：把二维移动变成一维旋转

核心洞察

按行优先顺序为每个格子编号：index = i × n + j。一次迁移等价于所有一维下标向右移动一格，并在长度 m × n 的环上取模。

newIndex = (oldIndex + k) % (m × n)

完整过程

  1. 取得行数 m、列数 n 与总格数 total。
  2. 令 k %= total，去掉完整绕圈产生的无效移动。
  3. 遍历旧位置，将它的一维编号加 k 后取模。
  4. 用整除与取余把新编号还原成行列：row = index / n，col = index % n。

正确性证明

引理：每次迁移会把行优先下标 x 变为 (x + 1) mod total。非末列元素直接进入下一下标；行末进入下一行首，也正是下一下标；右下角下标 total - 1 进入下标 0，与取模结果一致。

归纳：迁移 0 次时元素仍在下标 x。若迁移 t 次后位于 (x + t) mod total，再迁移一次便位于 (x + t + 1) mod total。所以迁移 k 次后位于 (x + k) mod total。

结论：算法把每个旧元素放到上述唯一目标位置，覆盖全部格子且没有冲突，因此返回的网格恰为执行 k 次迁移后的结果。

边界情况

  • k = 0：每个元素留在原位。
  • 单行或单列：公式仍等价于普通数组旋转。
  • k 是总格数倍数：取模后为 0，网格不变。
  • 负数和重复值：算法只搬运位置，不依赖数值。

复杂度

时间：O(mn)，每个元素访问一次。

额外空间：O(mn)，用于构造返回网格；返回值本身也需要相同规模。

替代方案

可先把网格展平成列表，切分最后 k 个元素并拼到开头，再按每 n 个元素重建行。思路直观，但会产生中间数组或切片；直接下标映射更统一。

也可真实模拟 k 轮，每轮移动全部元素，时间为 O(kmn)，在约束内可能可用，但没有利用周期性。

面试追问

  • 若必须原地修改，如何用环置换或三次反转完成？
  • 如何把公式改成向左迁移，并避免负数取模问题？
  • 如果网格按列优先展开，下标换算怎样变化？

常见错误

  • 忘记对 k 取模，做了大量完整绕圈的重复工作。
  • 新行号误除以 m；行优先展开时必须除以列数 n。
  • 原地从前向后覆盖，导致尚未搬运的旧值丢失。
  • 只处理普通行末，却漏掉右下角回到左上角的环形边界。

四语言完整代码

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> shiftGrid(int[][] grid, int k) {
        int m = grid.length;
        int n = grid[0].length;
        int total = m * n;
        k %= total;

        int[][] shifted = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int oldIndex = i * n + j;
                int newIndex = (oldIndex + k) % total;
                shifted[newIndex / n][newIndex % n] = grid[i][j];
            }
        }

        List<List<Integer>> answer = new ArrayList<>();
        for (int[] row : shifted) {
            List<Integer> list = new ArrayList<>();
            for (int value : row) list.add(value);
            answer.add(list);
        }
        return answer;
    }
}
/**
 * @param {number[][]} grid
 * @param {number} k
 * @return {number[][]}
 */
var shiftGrid = function(grid, k) {
    const m = grid.length;
    const n = grid[0].length;
    const total = m * n;
    k %= total;

    const answer = Array.from({ length: m }, () => Array(n));
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < n; j++) {
            const newIndex = (i * n + j + k) % total;
            answer[Math.floor(newIndex / n)][newIndex % n] = grid[i][j];
        }
    }
    return answer;
};

class Solution:
    def shiftGrid(self, grid: List[List[int]], k: int) -> List[List[int]]:
        m, n = len(grid), len(grid[0])
        total = m * n
        k %= total

        answer = [[0] * n for _ in range(m)]
        for i in range(m):

                new_index = (i * n + j + k) % total
                answer[new_index // n][new_index % n] = grid[i][j]
        return answer
