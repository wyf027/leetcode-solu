4024. 最近的可用无人机

先检查能否到达，再在可达者中找最小曼哈顿距离。平局不更新，天然保留更小下标。

线性扫描 · O(n) 时间 · O(1) 空间

题意：谁能接到目标？

drones[i] = [x, y, range] 表示第 i 架无人机的位置与续航。目标为 target = [tx, ty]。距离 |x-tx| + |y-ty| 不超过 range 才可达；返回可达且距离最小的下标，距离相同取更小下标，没有则 -1。

曼哈顿距离是横向位移加纵向位移，不是欧氏直线距离；题目的飞行范围正是以此衡量。

核心洞察

  1. 每架无人机的“资格”只取决于 distance ≤ range。
  2. 扫描中维护 bestDistance 与 answer。
  3. 仅当 distance < bestDistance 才更新；等号不更新正好实现平局时小下标优先。

边界与常见错误

  • 距离恰好等于范围时可达，比较符号必须是 ≤。
  • 平局不能写 ≤ bestDistance，否则后面的较大下标会覆盖答案。
  • 先取绝对值再相加；不要误用平方距离或开方。
  • 初始答案 -1、最优距离 ∞，可自然处理“无可达无人机”。

默认隐藏的题解与四语言实现

遍历 drones，计算距离。只有可达并且严格更近时，记录它的下标。因为从左到右扫描，距离相等时保留先出现的下标。

面试追问

          

            若目标不断变化怎么办？
            

              单次查询仍可线性扫描；查询极多且规则固定时，可按距离度量与范围设计空间索引，但这已超出本题约束。
            

          

          

            若要求返回全部最优无人机？
            

              相同扫描即可：遇到严格更小距离清空列表，遇到相等距离追加下标。
