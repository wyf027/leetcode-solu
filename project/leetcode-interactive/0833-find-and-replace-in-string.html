字符串中的查找与替换

把每个替换请求钉在原字符串坐标上，再从左向右收卷。先理解“同时发生”，暂不展开实现答案。

MEDIUM 数组 哈希表 字符串 排序 非付费题
Problem brief

题意与输入约定

findReplaceString(s, indices, sources, targets)

给定下标从 0 开始的字符串 s，以及三个长度均为 k 的并行数组 indices、sources 和 targets。

  1. 第 i 个操作只检查原字符串：sources[i] 是否恰好从 indices[i] 开始。
  2. 若匹配，则用 targets[i] 替换该段；否则忽略这个操作。
  3. 所有有效替换视为同时发生，彼此不会因为字符串变长或变短而改变坐标。
返回：执行全部有效替换后的字符串

关键语义：原坐标不动

不能先改字符串、再用修改后的下标处理下一个操作。题目保证测试中的替换区间不会重叠。

子字符串指字符串中连续的一段字符。

示例 1 · 两次都匹配

输入：s = "abcd"
indices = [0, 2]
sources = ["a", "cd"]
targets = ["eee", "ffff"]
输出："eeebffff"

索引 0 的 "a" 与索引 2 的 "cd" 都在原串中匹配，因此分别替换。

示例 2 · 一次匹配、一次跳过

输入：s = "abcd"
indices = [0, 2]
sources = ["ab", "ec"]
targets = ["eee", "ffff"]
输出："eeecd"

"ab" 在索引 0 匹配；原串索引 2 开始是 "cd"，不是 "ec"，所以第二次操作无效。

约束

  • 1 ≤ s.length ≤ 1000
  • k == indices.length == sources.length == targets.length，且 1 ≤ k ≤ 100
  • 0 ≤ indices[i] < s.length
  • 1 ≤ sources[i].length, targets[i].length ≤ 50
  • s、sources[i] 和 targets[i] 仅由小写英文字母组成
  • 题目保证替换区间不会重叠

Solution

一次预检，一次扫描

original-index map + builder
01

核心洞察

先在原串上验证每个操作，把有效操作记录到“起点 → 操作编号”的映射中。随后扫描原串，不需要修改原串本身。

02

构造规则

扫描到有效操作起点时，追加目标串，并一次跳过源串长度；否则只追加当前原字符，再前进一步。

03

为什么自然满足“同时”

所有匹配判断和扫描坐标都来自未修改的 s，目标串长度不会反过来影响任何操作的起点。

完整过程

  1. 遍历全部操作，用 startsWith / 子串比较确认 sources[j] 是否从 indices[j] 开始。
  2. 把匹配成功的操作编号记到其原始起点。
  3. 令指针 i = 0，创建输出构造器。
  4. 若 i 是有效操作起点，追加对应 target，并令 i += source.length。
  5. 否则追加 s[i]，令 i += 1；直到扫描结束。

正确性证明

  • 有效性：映射只记录在原字符串指定位置确实匹配的操作，因此不会执行无效替换。
  • 完整性：扫描指针会到达每个尚未被前一有效区间覆盖的位置；由于区间不重叠，每个有效替换起点都恰好处理一次。
  • 顺序性：扫描按原坐标从左到右追加目标串或原字符，所以输出片段与原串中的相对顺序一致。
  • 结论：算法执行且仅执行全部有效替换，并保留其余字符，所得字符串正是同时替换的结果。

复杂度与边界

设 n = s.length，所有源串总长度为 S，最终输出长度为 R。

  • 时间：O(n + S + R)
  • 辅助空间：O(k + R)（包含返回值构造器）
  • 失配操作不会消耗原字符；边界索引附近的比较必须避免越界。
  • 目标串可比源串更长或更短，但不影响原坐标。
  • 若没有任何操作匹配，结果就是原串。

替代方案、面试追问与常见错误

替代方案

可将操作编号按 indices 排序，再用“复制间隙 + 替换”的方式构造答案，复杂度多出 O(k log k) 排序；也可从右向左在可变字符串上替换，但不同语言中的插入删除成本和下标细节更易出错。

面试追问

若允许重叠，需先定义冲突优先级；若操作流很大，可按索引排序后流式合并；若字符串是 Unicode，要明确索引按字节、码点还是字素簇计算。

常见错误

在已经修改的字符串上继续使用原下标；匹配失败后仍跳过 source.length；扫描到有效替换后只前进 1；把 target 长度误当作应跳过的长度。

实现提醒

不要依赖操作输入顺序；映射的键必须是原始起点；比较必须严格从指定位置开始，不能用“字符串中任意位置包含 source”。

四语言完整实现

JavaHashMap + StringBuilder
import java.util.HashMap;
import java.util.Map;

class Solution {
    public String findReplaceString(
        String s,
        int[] indices,
        String[] sources,
        String[] targets
    ) {
        Map<Integer, Integer> valid = new HashMap<>();

        for (int j = 0; j < indices.length; j++) {
            int start = indices[j];
            if (s.startsWith(sources[j], start)) {
                valid.put(start, j);
            }
        }

        StringBuilder answer = new StringBuilder();
        int i = 0;

        while (i < s.length()) {
            Integer operation = valid.get(i);
            if (operation != null) {
                answer.append(targets[operation]);
                i += sources[operation].length();
            } else {
                answer.append(s.charAt(i));
                i++;
            }
        }

        return answer.toString();
    }
}

/**

var findReplaceString = function (
    s,
    indices,
    sources,
    targets
) {
    const valid = new Map();

    for (let j = 0; j < indices.length; j++) {
        const start = indices[j];
        if (s.startsWith(sources[j], start)) {
            valid.set(start, j);
        }
    }

    const answer = [];
    let i = 0;

    while (i < s.length) {
        if (valid.has(i)) {
            const operation = valid.get(i);
            answer.push(targets[operation]);
            i += sources[operation].length;
        } else {
            answer.push(s[i]);
            i++;
        }
    }

    return answer.join("");
};
Pythondict + list join
from typing import List


class Solution:
    def findReplaceString(
        self,
        s: str,
        indices: List[int],
        sources: List[str],
        targets: List[str],
    ) -> str:
        valid = {}

        for operation, start in enumerate(indices):
            if s.startswith(sources[operation], start):
                valid[start] = operation

        answer = []
        i = 0

        while i < len(s):
            if i in valid:
                operation = valid[i]
                answer.append(targets[operation])
                i += len(sources[operation])
            else:
                answer.append(s[i])
                i += 1

        return "".join(answer)
C++unordered_map + string
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    string findReplaceString(
        string s,
        vector<int>& indices,
        vector<string>& sources,
        vector<string>& targets
    ) {
        unordered_map<int, int> valid;

        for (int j = 0; j < indices.size(); j++) {
            int start = indices[j];
            if (s.compare(start, sources[j].size(), sources[j]) == 0) {
                valid[start] = j;
            }
        }

        string answer;
        int i = 0;

        while (i < s.size()) {
            auto it = valid.find(i);
            if (it != valid.end()) {
                int operation = it->second;
                answer += targets[operation];
                i += sources[operation].size();
            } else {
                answer += s[i];
                i++;
            }
        }

        return answer;
    }
};
