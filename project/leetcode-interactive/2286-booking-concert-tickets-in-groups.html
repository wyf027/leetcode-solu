01 / 规则与接口

音乐厅有 n 排，每排 m 个座位。排号为 0…n−1，座位号为 0…m−1。每次请求的所有人必须坐在 0…maxRow 内。始终优先较小排号，同排优先较小座位号。

  • BookMyShow(int n, int m)：初始化空音乐厅。
  • int[] gather(int k, int maxRow)：把 k 人安排在同一排的连续空座，返回最小可能起点 [排号, 座位号]；不能安排则返回 []。
  • boolean scatter(int k, int maxRow)：允许跨排和分开坐，按排号、座位号从小到大分配；能容纳全组返回 true，否则返回 false。

请求失败时不能占用部分座位。这里只订票，没有退票操作。

输入边界

  • 1 ≤ n ≤ 5 × 10⁴
  • 1 ≤ m, k ≤ 10⁹
  • 0 ≤ maxRow ≤ n − 1
  • gather 与 scatter 合计调用 ≤ 5 × 10⁴ 次

思考提示：“同排连续”和“总人数足够”是不同条件。

05 / 准备好深入实现了吗？

核心洞察、证明与四语言实现均在下方折叠区域。

题解：每排一个余量，区间保存两种信息

核心洞察

每次都从一排中最左边的空座开始订，因此每排已订座始终是前缀，空座始终是连续后缀。用 free[r] 表示第 r 排剩余座位即可；下一个空座号是 m − free[r]，无需创建 n × m 个座位对象。

线段树节点维护区间剩余座位之和 sum 与单排最大余量 mx。gather 用 mx 找出第一个足够大的排；scatter 先用 sum 判断前缀总容量，再从左到右扣减。

与上方回放同步的区间摘要

两排音乐厅对应一个根节点和两个叶子。判定帧显示提交前容量，提交帧显示更新后容量。

完整过程

  1. 初始化每排余量为 m，建树：叶子 sum = mx = m；父节点 sum 相加，mx 取最大。
  2. gather：区间左端超过 maxRow 或 mx < k 就剪枝。先查左子树，找不到再查右子树。拿到排号 r 后记录 c = m − free[r]，扣掉 k，单点更新树，返回 [r, c]。
  3. scatter：先求 [0, maxRow] 的 sum。若小于 k 立即返回 false，不修改任何状态。
  4. 容量足够时，从指针 ptr 开始跳过满排，在当前非空排取 min(k, free[ptr]) 座，扣减需求并单点更新；直到 k = 0。ptr 只向右移动。

ptr 是“它之前的排一定已满”的下界，不要求随 gather 立即移动。gather 填满它所在的排后，下次 scatter 会跳过这些排。前缀容量已确认足够，所以成功分配不会走到 maxRow 之外。

正确性证明

  1. 余量表示：初始空座为整排。两种操作只取空座后缀的最左部分，剩余空座仍为后缀。归纳得 free 足以准确表示状态。
  2. gather 最优：mx < k 的区间没有可用排；边界之外的区间不合法。先左后右找到的第一片叶子是最小合法排号，从 m − free[r] 开始则是该排的最小合法座位号。
  3. scatter 可行：前缀总余量不足 k 时必然失败；足够时按排从左到右取座必能容纳 k 人，并满足排号、座位号优先顺序。
  4. 状态维护：成功扣减后向上重算 sum、mx；失败无写入。ptr 只跨过余量为 0 的排，后续调用继续满足不变式。

复杂度：单次与总体

令 q 为总操作数，L = log₂(n + 1)。建树时间 O(n)，gather 与前缀容量查询时间 O(L)。单次 scatter 若触及 t 个非空排并跳过 s 个满排，耗时 O(L + tL + s)，最坏 O(nL)，不能声称每次都是 O(log n)。

每次 scatter 至多有一个未填满的尾排，其余触及排都会永久填满；整段调用序列中这样的排最多 n 个，ptr 总前进次数也不超过 n。所以初始化及 q 次操作的总时间为 O(n + (n + q)L)，总空间 O(n)，递归栈 O(L)。

边界与数值

  • k > m 时 gather 失败，scatter 仍可能成功；maxRow 包含端点。
  • n = 1、全满、恰好订完、失败后继续请求都沿用相同逻辑。
  • 总容量最多 5 × 10¹³。Java 用 long，C++ 用 long long，乘法前先提升类型；Python 整数无需额外处理。
  • JavaScript Number 的精确整数范围足够覆盖 5 × 10¹³。sum 使用 Float64Array，不能用 Int32Array 或位运算存容量。

替代方案

逐排扫描简单，但 q 次请求最坏 O(nq)。树状数组能维护容量和与单点更新，却不能单独找出“第一排余量 ≥ k”，还需最大值结构。若必须保证每次 scatter 最坏 O(log n)，可用支持区间清零懒标记的线段树：定位第 k 个空座所在排，清零它前面的排，再扣减尾排；实现更复杂。

常见错误

  • 把跨排总余量当成连续座位数。
  • scatter 边扣边判断，失败后留下部分订票。
  • 返回扣减后的起点；应先保存 m − free[r]。
  • 只维护 sum，遗漏 mx；或搜索遗漏 maxRow。
  • 把 scatter 的单次最坏复杂度和整段调用的摊还分析混为一谈。

面试追问

  • 支持退票？空座可能不再是后缀，需要空闲区间与最长连续空段信息；ptr 单调性失效。
  • 要求每次延迟有上界？用前缀选择、区间清零和懒标记，将跨排扣减合并成区间操作。
  • 并发订票？容量判断和扣减必须原子化，避免重复分配；本题只讨论顺序调用。

class BookMyShow {
    private final int n, m;
    private int ptr = 0;
    private final int[] free, mx;
    private final long[] sum;
    public BookMyShow(int n, int m) {
        this.n = n; this.m = m;
        free = new int[n];
        java.util.Arrays.fill(free, m);
        mx = new int[4*n]; sum = new long[4*n];
        build(1, 0, n-1);
    }
    private void build(int v, int l, int r) {
        sum[v] = (long)(r-l+1)*m; mx[v] = m;
        if (l == r) return;
        int mid = (l+r)/2;
        build(v*2,l,mid); build(v*2+1,mid+1,r);
    }
    private void update(int v, int l, int r, int row) {
        if (l == r) { sum[v] = mx[v] = free[row]; return; }
        int mid = (l+r)/2;
        if (row <= mid) update(v*2,l,mid,row);
        else update(v*2+1,mid+1,r,row);
        sum[v] = sum[v*2]+sum[v*2+1];
        mx[v] = Math.max(mx[v*2],mx[v*2+1]);
    }
    private long prefix(int v, int l, int r, int end) {
        if (l > end) return 0;
        if (r <= end) return sum[v];
        int mid = (l+r)/2;
        return prefix(v*2,l,mid,end)+prefix(v*2+1,mid+1,r,end);
    }
    private int first(int v, int l, int r, int k, int end) {
        if (l > end || mx[v] < k) return -1;
        if (l == r) return l;
        int mid = (l+r)/2;
        int row = first(v*2,l,mid,k,end);
        return row != -1 ? row : first(v*2+1,mid+1,r,k,end);
    }
    public int[] gather(int k, int maxRow) {
        int row = first(1,0,n-1,k,maxRow);
        if (row == -1) return new int[0];
        int seat = m-free[row];
        free[row] -= k; update(1,0,n-1,row);
        return new int[]{row,seat};
    }
    public boolean scatter(int k, int maxRow) {
        if (prefix(1,0,n-1,maxRow) < k) return false;
        while (k > 0) {
            while (free[ptr] == 0) ptr++;
            int take = Math.min(k,free[ptr]);
            free[ptr] -= take; k -= take;
            update(1,0,n-1,ptr);
        }
        return true;
    }
}

class BookMyShow {
  constructor(n, m) {
    this.n = n; this.m = m; this.ptr = 0;
    this.free = Array(n).fill(m);
    this.sum = new Float64Array(4*n);
    this.mx = new Float64Array(4*n);
    this.build(1, 0, n-1);
  }
  build(v, l, r) {
    this.sum[v] = (r-l+1)*this.m; this.mx[v] = this.m;
    if (l === r) return;
    const mid = Math.floor((l+r)/2);
    this.build(v*2, l, mid); this.build(v*2+1, mid+1, r);
  }
  update(v, l, r, row) {
    if (l === r) { this.sum[v] = this.mx[v] = this.free[row]; return; }
    const mid = Math.floor((l+r)/2);
    if (row <= mid) this.update(v*2, l, mid, row);
    else this.update(v*2+1, mid+1, r, row);
    this.sum[v] = this.sum[v*2]+this.sum[v*2+1];
    this.mx[v] = Math.max(this.mx[v*2], this.mx[v*2+1]);
  }
  prefix(v, l, r, end) {
    if (l > end) return 0;
    if (r <= end) return this.sum[v];
    const mid = Math.floor((l+r)/2);
    return this.prefix(v*2,l,mid,end)+this.prefix(v*2+1,mid+1,r,end);
  }
  first(v, l, r, k, end) {
    if (l > end || this.mx[v] < k) return -1;
    if (l === r) return l;
    const mid = Math.floor((l+r)/2);
    const row = this.first(v*2,l,mid,k,end);
    return row !== -1 ? row : this.first(v*2+1,mid+1,r,k,end);
  }
  gather(k, maxRow) {
    const row = this.first(1,0,this.n-1,k,maxRow);
    if (row === -1) return [];
    const seat = this.m-this.free[row];
    this.free[row] -= k;
    this.update(1,0,this.n-1,row);
    return [row,seat];
  }
  scatter(k, maxRow) {
    if (this.prefix(1,0,this.n-1,maxRow) < k) return false;
    while (k > 0) {
      while (this.free[this.ptr] === 0) this.ptr++;
      const take = Math.min(k,this.free[this.ptr]);
      this.free[this.ptr] -= take; k -= take;
      this.update(1,0,this.n-1,this.ptr);
    }
    return true;
  }
}

from typing import List

class BookMyShow:
    def __init__(self, n: int, m: int):
        self.n, self.m, self.ptr = n, m, 0
        self.free = [m] * n
        self.total = [0] * (4*n)
        self.mx = [0] * (4*n)
        self._build(1, 0, n-1)

    def _build(self, v, l, r):
        self.total[v] = (r-l+1)*self.m
        self.mx[v] = self.m
        if l == r:
            return
        mid = (l+r)//2
        self._build(v*2, l, mid)
        self._build(v*2+1, mid+1, r)

    def _update(self, v, l, r, row):
        if l == r:
            self.total[v] = self.mx[v] = self.free[row]
            return
        mid = (l+r)//2
        if row <= mid:
            self._update(v*2, l, mid, row)
        else:
            self._update(v*2+1, mid+1, r, row)
        self.total[v] = self.total[v*2] + self.total[v*2+1]
        self.mx[v] = max(self.mx[v*2], self.mx[v*2+1])

    def _prefix(self, v, l, r, end):
        if l > end:
            return 0
        if r <= end:
            return self.total[v]
        mid = (l+r)//2
        return (self._prefix(v*2, l, mid, end) +
                self._prefix(v*2+1, mid+1, r, end))

    def _first(self, v, l, r, k, end):
        if l > end or self.mx[v] < k:
            return -1
        if l == r:
            return l
        mid = (l+r)//2
        row = self._first(v*2, l, mid, k, end)
        if row != -1:
            return row
        return self._first(v*2+1, mid+1, r, k, end)

    def gather(self, k: int, maxRow: int) -> List[int]:
        row = self._first(1, 0, self.n-1, k, maxRow)
        if row == -1:
            return []
        seat = self.m-self.free[row]
        self.free[row] -= k
        self._update(1, 0, self.n-1, row)
        return [row, seat]

    def scatter(self, k: int, maxRow: int) -> bool:
        if self._prefix(1, 0, self.n-1, maxRow) < k:
            return False
        while k > 0:
            while self.free[self.ptr] == 0:
                self.ptr += 1
            take = min(k, self.free[self.ptr])
            self.free[self.ptr] -= take
            k -= take
            self._update(1, 0, self.n-1, self.ptr)
        return True
