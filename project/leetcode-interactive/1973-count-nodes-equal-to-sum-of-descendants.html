MEDIUM会员题二叉树

值等于子节点值之和的
节点数量

Count Nodes Equal to Sum of Descendants

给定二叉树根节点 root，统计有多少节点的值恰好等于它所有后代节点的值之和，返回这个数量。

先分清“后代”

包括孩子、孙子等所有向下可达的节点，不包含当前节点自身。没有后代时，后代值之和为 0。中文标题中的“子节点”在这里应理解为所有后代。

输入约定

equalToDescendants(root: TreeNode) → integer

示例用层序数组表示 root；null 表示缺失的孩子。实际函数接收树节点对象，不是数组。

  • 节点数：1 ≤ n ≤ 105
  • 节点值：0 ≤ Node.val ≤ 105
  • 返回满足条件的节点数量。
01 / READ THE TREE

官方示例

示例 1

输入：root = [10,3,4,2,1]
输出：2

值为 10 的节点：后代和为 3 + 4 + 2 + 1 = 10；值为 3 的节点：后代和为 2 + 1 = 3。

示例 2

输入：root = [2,3,null,2,null]
输出：0

三个节点自上而下的后代和分别为 5、2、0，均不等于对应节点值。

示例 3

输入：root = [0]
输出：1

唯一节点没有后代，后代和为 0，因此计入答案。

04 / GO DEEPER

完成思考后，再打开题解

核心洞察、正确性与四种语言实现。

后代的答案，从子树返回

核心洞察

令 S(x) 表示以 x 为根的整棵子树的值之和，包含 x 自己。空树的 S 为 0。节点 x 的后代和 D(x) = S(x.left) + S(x.right)。若 D(x) = x.val，计数加一；随后记录 S(x) = D(x) + x.val，供父节点使用。

完整过程：用逆序遍历得到后序

  1. 把根放入显式栈；弹出节点后加入 order，再先压左孩子、后压右孩子。由于后进先出，order 是“根 → 右 → 左”顺序。
  2. 逆序处理 order，得到“左 → 右 → 根”的后序。每个父节点被处理时，它的孩子已完成汇总。
  3. 从映射中取左右子树总和（空孩子取 0），计算 D。只比较 D 与节点值，不把当前节点加进去比较。
  4. 命中则 answer 加一，映射存下 D + node.val。所有节点处理完，返回 answer。

示例 1 的后序节点值为 2、1、3、4、10。依次返回的子树总和为 2、1、6、4、20；节点 3 比较 2 + 1，节点 10 比较 6 + 4，最终命中两次。

正确性证明

对逆序处理的节点归纳。叶子的两个孩子为空，D = 0，比较符合题意，存储的 S 等于叶子自身值。假设孩子的 S 已正确，那么它们的子树互不相交，且恰好覆盖当前节点的全部后代；二者之和就是正确的 D。比较恰好判断当前节点是否合格，加上自身值又得到正确的 S。后序保证归纳前提成立，每个节点仅被判断一次，因此最终计数无遗漏、无重复。

边界与数值范围

  • 零值叶子必须计数；非零叶子不计数。全零树的答案是 n。
  • 单边链同样成立；n 可达 100000，四份实现都使用显式栈，避免依赖语言递归深度。
  • 树总和最多 1010，Java 用 long，C++ 用 long long；JavaScript Number 可精确表示这个范围的整数，Python int 无此溢出问题。
  • 映射的键必须是节点身份，不能是节点值。值相同的两个节点可能有不同子树。代码不修改树。
  • 题目保证非空树；代码额外将空根处理为 0。每次调用的计数和映射都重新创建。

复杂度

每个节点入栈、出栈、入序列与汇总各一次；在映射操作均摊 O(1) 的常用模型下，时间 O(n)，额外空间 O(n)，包括遍历序列、栈和子树和映射。哈希表的极端碰撞可能使时间退化，C++ unordered_map 不承诺单次操作最坏 O(1)。

替代方案

  • 递归后序：每次调用返回子树总和，时间 O(n)、调用栈 O(h)。写法短，但深链树可能造成栈溢出，不能仅依赖提高递归限制。
  • 显式栈帧：在帧内保留阶段和左右子树汇总，完成后传给父帧，可做到 O(n) 时间、O(h) 空间，避免全量映射，状态管理更复杂。
  • 逐节点重算后代：每次从该节点向下求和；链状树上重复访问大量节点，最坏 O(n²)。

常见错误

  • 只加两个直接孩子的值，遗漏孙辈；例如 [3,1,2,1] 的根后代和为 4，不是 3。
  • 拿 S(x) 与 x.val 比较，误把自身算入后代；正确比较对象是 D(x)。
  • 向父节点返回 D(x)，漏掉当前节点自身值。
  • 提前处理父节点，孩子总和尚未可用；或用 32 位整数存储 1010 级别的总和。

面试追问

  • 允许负数呢？等式与后序算法不变，但不能使用“和超过节点值即可停止”的剪枝。
  • 改成多叉树呢？将所有孩子的子树总和相加，再比较，仍是一次后序遍历。
  • 要求输出节点呢？命中时收集节点引用或稳定编号，不能只保存值来区分重复节点。
  • 节点值会动态更新呢？一次改动会影响祖先链上的后代和与更新节点自身的比较；可沿父指针更新，单次 O(h)，频繁更新需要另行设计数据结构。

Java

import java.util.*;

// TreeNode 由 LeetCode 提供，包含 int val、left、right。
class Solution {
    public int equalToDescendants(TreeNode root) {
        if (root == null) return 0;
        List<TreeNode> order = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            order.add(node);
            if (node.left != null) stack.push(node.left);
            if (node.right != null) stack.push(node.right);
        }
        Map<TreeNode, Long> sum = new IdentityHashMap<>();
        int answer = 0;
        for (int i = order.size() - 1; i >= 0; --i) {
            TreeNode node = order.get(i);
            long descendants = sum.getOrDefault(node.left, 0L)
                             + sum.getOrDefault(node.right, 0L);
            if (descendants == node.val) ++answer;
            sum.put(node, descendants + node.val);
        }
        return answer;
    }
}

var equalToDescendants = function(root) {
    if (root === null) return 0;
    const stack = [root], order = [], sum = new Map();
    while (stack.length) {
        const node = stack.pop();
        order.push(node);
        if (node.left !== null) stack.push(node.left);
        if (node.right !== null) stack.push(node.right);
    }
    let answer = 0;
    for (let i = order.length - 1; i >= 0; --i) {
        const node = order[i];
        const descendants = (sum.get(node.left) ?? 0)
                          + (sum.get(node.right) ?? 0);
        if (descendants === node.val) ++answer;
        sum.set(node, descendants + node.val);
    }
    return answer;
};

class Solution:
    def equalToDescendants(self, root: Optional["TreeNode"]) -> int:
        if root is None:
            return 0
        stack, order = [root], []
        while stack:
            node = stack.pop()
            order.append(node)
            if node.left is not None:
                stack.append(node.left)
            if node.right is not None:
                stack.append(node.right)
        sums = {}
        answer = 0
        for node in reversed(order):
            descendants = (sums.get(id(node.left), 0)
                           + sums.get(id(node.right), 0))
            if descendants == node.val:
                answer += 1
            sums[id(node)] = descendants + node.val
        return answer

C++

#include <vector>
#include <unordered_map>
using namespace std;

// TreeNode 由 LeetCode 提供：int val; TreeNode *left, *right;
class Solution {
public:
    int equalToDescendants(TreeNode* root) {
        if (!root) return 0;
        vector<TreeNode*> stack{root}, order;
        while (!stack.empty()) {
            TreeNode* node = stack.back();
            stack.pop_back();
            order.push_back(node);
            if (node->left) stack.push_back(node->left);
            if (node->right) stack.push_back(node->right);
        }
        unordered_map<TreeNode*, long long> sums;
        int answer = 0;
        for (auto it = order.rbegin(); it != order.rend(); ++it) {
            TreeNode* node = *it;
            long long descendants = (node->left ? sums.at(node->left) : 0LL)
                                  + (node->right ? sums.at(node->right) : 0LL);
            if (descendants == node->val) ++answer;
            sums[node] = descendants + node->val;
        }
        return answer;
    }
};
