蜗牛排序

Snail Traversal

让一维数组沿列上下交替地“爬”进二维矩阵。先读懂路径，再通过交互演示观察每个元素的落点。

题目描述

为所有数组实现 snail(rowsCount, colsCount) 方法，把当前一维数组转换为一个 rowsCount × colsCount 的二维数组。

填充从左上角开始：第一列自上而下，第二列自下而上，之后每列交替方向，直至用完原数组中的全部元素。如果 rowsCount * colsCount !== nums.length，输入无效，返回空数组。

示例 1

输入：
nums = [19, 10, 3, 7, 9, 8, 5, 2, 1, 17,
        16, 14, 12, 18, 6, 13, 11, 20, 4, 15]
rowsCount = 5
colsCount = 4

输出：
[
  [19,17,16,15],
  [10, 1,14, 4],
  [ 3, 2,12,20],
  [ 7, 5,18,11],
  [ 9, 8, 6,13]
]

示例 2

输入：
nums = [1,2,3,4]
rowsCount = 1
colsCount = 4

输出： [[1,2,3,4]]

示例 3

输入：
nums = [1,3]
rowsCount = 2
colsCount = 2

输出： []

因为 2 × 2 = 4，与数组长度 2 不相等。

约束

  • 0 <= nums.length <= 250
  • 1 <= nums[i] <= 1000
  • 1 <= rowsCount <= 250
  • 1 <= colsCount <= 250

完整题解

准备好后再展开，避免提前看到核心映射。

题解：用下标直接定位

核心洞察

每连续 rowsCount 个元素恰好填满一列。因此，原数组下标 i 可以直接给出目标列和列内偏移，无需维护移动方向或模拟碰壁。

col = floor(i / rowsCount), offset = i % rowsCount, row = col 为偶数 ? offset : rowsCount - 1 - offset

完整过程

  1. 先判断 rowsCount * colsCount 是否等于数组长度；不等则返回 []。
  2. 创建指定行列数的结果矩阵。
  3. 依次扫描原数组。用整数除法确定列，用取模得到该列内的顺序偏移。
  4. 偶数列向下，行号就是偏移；奇数列向上，行号是镜像后的偏移。
  5. 把当前元素写入计算出的单元格。

正确性说明

对任意下标 i，floor(i / rowsCount) 唯一确定它属于哪一列，i % rowsCount 唯一确定它是该列接收的第几个元素。偶数列保持偏移顺序，正好从上到下；奇数列将偏移镜像，正好从下到上。因此每个元素都被放到蜗牛路径对应的唯一单元格。

当长度校验通过时，元素数与矩阵单元格数相同；上述映射在每一列内互不重复，各列也互不重叠，所以所有单元格被恰好填充一次。

边界情况长度不匹配返回空数组；单行时结果保持原顺序；单列时自上而下；空数组在题目给定的正行列数下必然长度不匹配。
复杂度时间 O(n)，其中 n 是数组长度；结果矩阵占 O(n) 空间，除返回值外额外空间 O(1)。
替代方案也可保存当前位置和方向，遇到列边界就换列并反向。它同样是 O(n)，但状态更多，更容易出现边界错误。
常见错误按行交替而非按列；奇数列忘记镜像行号；先分配矩阵却漏掉长度校验；把偶数列和奇数列方向写反。

面试追问

  • 如果路径改为按行左右交替，下标公式如何变化？
  • 能否从矩阵恢复原数组？答案是按相同列方向依次读取即可。
  • 为何数学映射比方向模拟更容易证明正确？
  • 若输入来自数据流且不能一次保存在内存中，应如何逐列输出？

四语言实现

JavaScript 是本题官方可提交形式；Java、Python、C++ 仅为本地语义参考，因为官方元数据只提供 JavaScript / TypeScript 签名。

JavaScript · 官方提交形式Array.prototype.snail
/**
 * @param {number} rowsCount
 * @param {number} colsCount
 * @return {Array<Array<number>>}
 */
Array.prototype.snail = function(rowsCount, colsCount) {
  if (rowsCount * colsCount !== this.length) return [];

  const result = Array.from(
    { length: rowsCount },
    () => Array(colsCount)
  );

  this.forEach((value, i) => {
    const col = Math.floor(i / rowsCount);
    const offset = i % rowsCount;
    const row = col % 2 === 0
      ? offset
      : rowsCount - 1 - offset;
    result[row][col] = value;
  });

  return result;
};
Java · 本地语义参考静态方法
class Solution {
  public int[][] snail(int[] nums, int rowsCount, int colsCount) {
    if (rowsCount * colsCount != nums.length) return new int[0][0];

    int[][] result = new int[rowsCount][colsCount];
    for (int i = 0; i < nums.length; i++) {
      int col = i / rowsCount;
      int offset = i % rowsCount;
      int row = col % 2 == 0
          ? offset
          : rowsCount - 1 - offset;
      result[row][col] = nums[i];
    }
    return result;
  }
}
Python · 本地语义参考函数
def snail(nums: list[int], rows_count: int, cols_count: int) -> list[list[int]]:
    if rows_count * cols_count != len(nums):
        return []

    result = [[0] * cols_count for _ in range(rows_count)]
    for i, value in enumerate(nums):
        col, offset = divmod(i, rows_count)
        row = offset if col % 2 == 0 else rows_count - 1 - offset
        result[row][col] = value
    return result
C++ · 本地语义参考函数
#include <vector>
using namespace std;

vector<vector<int>> snail(
    const vector<int>& nums,
    int rowsCount,
    int colsCount
) {
  if (rowsCount * colsCount != static_cast<int>(nums.size())) return {};

  vector<vector<int>> result(rowsCount, vector<int>(colsCount));
  for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
    int col = i / rowsCount;
    int offset = i % rowsCount;
    int row = col % 2 == 0
        ? offset
        : rowsCount - 1 - offset;
    result[row][col] = nums[i];
  }
  return result;
}
