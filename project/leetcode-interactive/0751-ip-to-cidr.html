IP 到 CIDR

把一段连续的 IPv4 地址，压缩成尽可能少的 CIDR 地址块。先理解任务，再动手观察地址边界如何改变可选块的大小。

中等 位运算 字符串 IP to CIDR
官方函数形式 ipToCIDR(ip: string, n: integer) → list<string>

输入起始地址与连续地址数量，返回 CIDR 字符串列表。

Problem

题目转述

给定一个合法 IPv4 地址 ip 作为起点，以及正整数 n。从起点开始，一共有 n 个连续的 IPv4 地址需要被覆盖。

CIDR 块写作 a.b.c.d/p：前 p 位固定，其余位可变化，因此一个块包含 2^(32-p) 个地址。块的起点必须与块大小对齐。

请返回一组 CIDR 块，要求它们恰好覆盖这 n 个地址，既不遗漏也不越界，并让使用的块数尽可能少。答案按地址从小到大排列。

Full solution

贪心：每次拿下当前能放的最大对齐块

核心洞察

1. 地址变整数

把 IPv4 的四段看成一个 32 位无符号整数，连续地址就变成连续整数。

2. 对齐限制

起点末尾有多少个二进制 0，就最多允许多大的、从该起点开始的 CIDR 块。

3. 数量限制

块不能覆盖到目标区间之外，因此还要受“不超过剩余数量的最大 2 次幂”限制。

blockSize = min(lowbit(start), highestPowerOfTwo(remaining))
prefix = 32 - log₂(blockSize)

完整过程

  1. 解析四个十进制段，将起始 IP 转成 0 到 2³²-1 的整数 start。
  2. 当 n > 0 时，求 start 的最低有效 1 位所代表的数值，即 lowbit(start)。它是当前位置满足对齐条件的最大块。特殊地，start = 0 时可视为能与 2³² 对齐。
  3. 求不超过剩余 n 的最大 2 次幂，避免块越过目标区间。
  4. 取两种上限中的较小值作为本轮块大小，并换算为前缀长度。
  5. 输出当前 CIDR；令 start += blockSize、n -= blockSize，继续处理后缀区间。

正确性证明

合法性。本轮块大小不超过 lowbit(start)，所以起点满足该 2 次幂块的 CIDR 对齐要求；它也不超过剩余数量，所以不会越界。
覆盖不重不漏。每轮块从当前最小未覆盖地址开始，随后起点恰好移动到该块之后。各块首尾相接，最终剩余数量变为 0，因此恰好覆盖目标区间。
局部最优。任意从当前起点开始的合法 CIDR 块，同时受对齐上限和剩余数量上限约束，所以不可能比贪心所选块更大。
全局最优。最优方案的第一个块也不可能大于贪心块；若更小，可将它及随后紧邻的覆盖合并/替换为贪心块而不增加块数。移除相同前缀后，对剩余区间重复论证，得到贪心方案块数最少。

复杂度

  • 时间：O(k)，其中 k 是输出 CIDR 块数
  • 额外空间：除返回结果外为 O(1)

边界处理

  • start = 0 时避免 lowbit(0) = 0 卡住循环
  • Java / C++ 用 64 位整数承载 2³²
  • JavaScript 避免对完整地址直接做有符号 32 位位运算
  • n = 1 必然生成一个 /32

import java.util.*;

class Solution {
    public List<String> ipToCIDR(String ip, int n) {
        List<String> answer = new ArrayList<>();
        long start = ipToLong(ip);

        while (n > 0) {
            long alignment = (start == 0) ? (1L << 32) : (start & -start);
            long countLimit = Long.highestOneBit(n);
            long size = Math.min(alignment, countLimit);
            int prefix = 32 - Long.numberOfTrailingZeros(size);

            answer.add(longToIp(start) + "/" + prefix);
            start += size;
            n -= (int) size;
        }
        return answer;
    }

    private long ipToLong(String ip) {
        long value = 0;
        for (String part : ip.split("\\.")) {
            value = value * 256 + Integer.parseInt(part);
        }
        return value;
    }

    private String longToIp(long value) {
        return ((value >> 24) & 255) + "." +
               ((value >> 16) & 255) + "." +
               ((value >> 8) & 255) + "." +
               (value & 255);
    }
}

var ipToCIDR = function(ip, n) {
    let start = ipToNumber(ip);
    const answer = [];

    while (n > 0) {
        const alignment = alignmentSize(start);
        const countLimit = 2 ** Math.floor(Math.log2(n));
        const size = Math.min(alignment, countLimit);
        const prefix = 32 - Math.log2(size);

        answer.push(numberToIp(start) + "/" + prefix);
        start += size;
        n -= size;
    }
    return answer;
};

function ipToNumber(ip) {
    return ip.split(".").reduce((value, part) =>
        value * 256 + Number(part), 0);
}

function numberToIp(value) {
    return [24, 16, 8, 0]
        .map(shift => Math.floor(value / (2 ** shift)) % 256)
        .join(".");
}

function alignmentSize(value) {
    if (value === 0) return 2 ** 32;
    let size = 1;
    while (value % (size * 2) === 0) size *= 2;
    return size;
}
from typing import List


class Solution:
    def ipToCIDR(self, ip: str, n: int) -> List[str]:
        start = self.ip_to_int(ip)
        answer = []

        while n > 0:
            alignment = (1 << 32) if start == 0 else start & -start
            count_limit = 1 << (n.bit_length() - 1)
            size = min(alignment, count_limit)
            prefix = 32 - (size.bit_length() - 1)

            answer.append(f"{self.int_to_ip(start)}/{prefix}")
            start += size
            n -= size

        return answer

    def ip_to_int(self, ip: str) -> int:
        value = 0
        for part in ip.split('.'):
            value = value * 256 + int(part)
        return value

    def int_to_ip(self, value: int) -> str:
        return '.'.join(str((value >> shift) & 255)
                        for shift in (24, 16, 8, 0))
#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<string> ipToCIDR(string ip, int n) {
        uint64_t start = ipToInt(ip);
        vector<string> answer;

        while (n > 0) {
            uint64_t alignment = (start == 0)
                ? (1ULL << 32)
                : (start & (~start + 1));
            uint64_t countLimit = 1ULL << (63 - __builtin_clzll(n));
            uint64_t size = min(alignment, countLimit);
            int prefix = 32 - __builtin_ctzll(size);

            answer.push_back(intToIp(start) + "/" + to_string(prefix));
            start += size;
            n -= static_cast<int>(size);
        }
        return answer;
    }

private:
    uint64_t ipToInt(const string& ip) {
        uint64_t value = 0;
        string part;
        stringstream input(ip);
        while (getline(input, part, '.')) {
            value = value * 256 + stoull(part);
        }
        return value;
    }

    string intToIp(uint64_t value) {
        return to_string((value >> 24) & 255) + "." +
               to_string((value >> 16) & 255) + "." +
               to_string((value >> 8) & 255) + "." +
               to_string(value & 255);
    }
};

替代方案

区间递归分解：把目标区间放进二进制前缀树，自顶向下收集完全落在区间内的最大节点。它同样正确，但实现更长，还要处理左右边界。

逐地址合并：先生成所有 /32 再反复合并兄弟块，直观但会产生 O(n) 中间数据。

常见错误

  • 只看剩余数量，忽略起点必须对齐
  • 把前缀长度误写成 log₂(size)
  • 在 JavaScript 中用 x & -x 处理大于 2³¹-1 的地址
  • 未特殊处理全零地址导致块大小为 0
  • IP 转整数时使用了有符号 32 位类型

面试追问

为什么贪心不会错？

重点说明任何合法首块都不能超过“对齐”和“剩余数量”两种上限，而贪心恰好达到共同上限。

如果输入是任意起止 IP 呢？

先用 end - start + 1 得到数量，再复用相同分解；需要防止跨越 IPv4 上界。

如何扩展到 IPv6？

算法不变，但整数宽度变为 128 位；选择支持大整数的类型，并把前缀基数从 32 改为 128。

输出块数有多大？

每轮消去一个由边界或数量决定的最大 2 次幂块；在本题小范围约束下输出很短。
