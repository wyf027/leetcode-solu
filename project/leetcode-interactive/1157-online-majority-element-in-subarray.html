题目要求

设计 MajorityChecker

给定整数数组 arr，建立一个能高效查询子数组多数元素的数据结构。这里的“多数元素”是指在指定子数组中出现至少 threshold 次的元素。

构造器 MajorityChecker(int[] arr)

使用完整数组 arr 初始化实例。

查询方法 int query(int left, int right, int threshold)

返回 arr[left...right] 中出现至少 threshold 次的元素；若不存在，返回 -1。

MajorityChecker([1, 1, 2, 2, 1, 1])
query(0, 5, 4)  →  1

约束

  • 1 ≤ arr.length ≤ 2 × 10⁴
  • 1 ≤ arr[i] ≤ 2 × 10⁴
  • 0 ≤ left ≤ right < arr.length
  • threshold ≤ right - left + 1
  • 2 × threshold > right - left + 1
  • query 最多调用 10⁴ 次

线段树候选 + 位置表验证

洞察一：答案若存在，候选唯一

题目保证 2 × threshold > 区间长度。因此不可能有两个不同值都达到阈值。只需找出一个可能的严格多数候选。

洞察二：Boyer–Moore 摘要可以合并

把一段区间压缩为 (candidate, balance)。相同候选的票数相加，不同候选互相抵消。这个合并规则允许在线段树上求任意区间的候选。

洞察三：候选必须复核

投票只保证“若严格多数存在，它一定成为候选”，并不保证候选达到给定阈值。为每个值保存有序下标列表，用两次二分计算它在查询区间内的真实出现次数。

洞察四：查询保持对数级

线段树查询访问 O(log n) 个节点；在候选的位置列表中做左右边界二分也是 O(log n)。

完整过程

  1. 记录位置：扫描数组，为每个数建立递增下标列表 positions[value]。
  2. 建树：叶节点保存 (arr[i], 1)；父节点由两个子节点按投票抵消规则合并。
  3. 取候选：查询 [left, right]，把被完整覆盖的节点摘要依序合并，得到候选 x。
  4. 数频次：在 positions[x] 中，以 lower bound 找到第一个 ≥ left 的位置，以 upper bound 找到第一个 > right 的位置；两者下标差就是频次。
  5. 作结论：频次不少于 threshold 时返回 x，否则返回 -1。

正确性证明

引理 1：对任意序列执行成对抵消后，如果某元素出现次数超过序列长度的一半，它不可能被全部抵消，最终候选必为该元素。

引理 2：两个区间的投票摘要按“同值相加、异值抵消”合并，等价于对拼接后的区间继续抵消。因此线段树返回的摘要与对整个查询区间投票所得摘要一致。

定理：若查询答案存在，由阈值条件可知它是查询区间的严格多数。依据引理 1、2，它必为树查询得到的候选。位置表二分精确计算其频次，算法会返回它；若候选频次不足，区间不存在达到阈值的其他元素，返回 -1 正确。

边界处理

  • 单元素区间：候选就是该元素，频次为 1。
  • 候选净票数很小：不能据此拒绝，仍须按位置表统计。
  • 候选未达阈值：必须返回 -1。
  • 二分右边界使用第一个 > right 的位置，避免漏计 right。
  • 查询拼接顺序对候选正确性无害，但实现应保持统一合并函数。
O(n)预处理时间：建树与位置表
O(log n)单次 query 时间
O(n)额外空间

import java.util.*;

class MajorityChecker {
    private final int n;
    private final int[] candidate;
    private final int[] balance;
    private final Map<Integer, List<Integer>> positions = new HashMap<>();

    public MajorityChecker(int[] arr) {
        n = arr.length;
        candidate = new int[n * 4];
        balance = new int[n * 4];
        for (int i = 0; i < n; i++) {
            positions.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);
        }
        build(1, 0, n - 1, arr);
    }

    private void build(int node, int lo, int hi, int[] arr) {
        if (lo == hi) {
            candidate[node] = arr[lo];
            balance[node] = 1;
            return;
        }
        int mid = lo + (hi - lo) / 2;
        build(node * 2, lo, mid, arr);
        build(node * 2 + 1, mid + 1, hi, arr);
        int[] merged = merge(
            new int[]{candidate[node * 2], balance[node * 2]},
            new int[]{candidate[node * 2 + 1], balance[node * 2 + 1]}
        );
        candidate[node] = merged[0];
        balance[node] = merged[1];
    }

    private int[] merge(int[] a, int[] b) {
        if (a[1] == 0) return b;
        if (b[1] == 0) return a;
        if (a[0] == b[0]) return new int[]{a[0], a[1] + b[1]};
        if (a[1] >= b[1]) return new int[]{a[0], a[1] - b[1]};
        return new int[]{b[0], b[1] - a[1]};
    }

    private int[] rangeCandidate(int node, int lo, int hi, int left, int right) {
        if (right < lo || hi < left) return new int[]{0, 0};
        if (left <= lo && hi <= right) {
            return new int[]{candidate[node], balance[node]};
        }
        int mid = lo + (hi - lo) / 2;
        return merge(
            rangeCandidate(node * 2, lo, mid, left, right),
            rangeCandidate(node * 2 + 1, mid + 1, hi, left, right)
        );
    }

    private int lowerBound(List<Integer> list, int target) {
        int lo = 0, hi = list.size();
        while (lo < hi) {
            int mid = lo + (hi - lo) / 2;
            if (list.get(mid) < target) lo = mid + 1;
            else hi = mid;
        }
        return lo;
    }

    public int query(int left, int right, int threshold) {
        int value = rangeCandidate(1, 0, n - 1, left, right)[0];
        List<Integer> list = positions.get(value);
        int count = lowerBound(list, right + 1) - lowerBound(list, left);
        return count >= threshold ? value : -1;
    }
}

var MajorityChecker = function(arr) {
    this.n = arr.length;
    this.candidate = new Int32Array(this.n * 4);
    this.balance = new Int32Array(this.n * 4);
    this.positions = new Map();

    for (let i = 0; i < this.n; i++) {
        if (!this.positions.has(arr[i])) this.positions.set(arr[i], []);
        this.positions.get(arr[i]).push(i);
    }

    const build = (node, lo, hi) => {
        if (lo === hi) {
            this.candidate[node] = arr[lo];
            this.balance[node] = 1;
            return;
        }
        const mid = lo + Math.floor((hi - lo) / 2);
        build(node * 2, lo, mid);
        build(node * 2 + 1, mid + 1, hi);
        const merged = this.merge(
            [this.candidate[node * 2], this.balance[node * 2]],
            [this.candidate[node * 2 + 1], this.balance[node * 2 + 1]]
        );
        this.candidate[node] = merged[0];
        this.balance[node] = merged[1];
    };
    build(1, 0, this.n - 1);
};

    if (a[1] >= b[1]) return [a[0], a[1] - b[1]];

};

from bisect import bisect_left, bisect_right
from collections import defaultdict
from typing import List, Tuple


class MajorityChecker:
    def __init__(self, arr: List[int]):
        self.n = len(arr)
        self.candidate = [0] * (self.n * 4)
        self.balance = [0] * (self.n * 4)
        self.positions = defaultdict(list)

        for index, value in enumerate(arr):
            self.positions[value].append(index)

        def build(node: int, lo: int, hi: int) -> None:
            if lo == hi:
                self.candidate[node] = arr[lo]
                self.balance[node] = 1
                return
            mid = lo + (hi - lo) // 2
            build(node * 2, lo, mid)
            build(node * 2 + 1, mid + 1, hi)
            value, votes = self._merge(
                (self.candidate[node * 2], self.balance[node * 2]),
                (self.candidate[node * 2 + 1], self.balance[node * 2 + 1]),
            )
            self.candidate[node] = value
            self.balance[node] = votes

        build(1, 0, self.n - 1)

    @staticmethod
    def _merge(a: Tuple[int, int], b: Tuple[int, int]) -> Tuple[int, int]:
        if a[1] == 0:
            return b
        if b[1] == 0:
            return a
        if a[0] == b[0]:
            return a[0], a[1] + b[1]
        if a[1] >= b[1]:
            return a[0], a[1] - b[1]
        return b[0], b[1] - a[1]

    def _range_candidate(
        self, node: int, lo: int, hi: int, left: int, right: int
    ) -> Tuple[int, int]:
        if right < lo or hi < left:
            return 0, 0
        if left <= lo and hi <= right:
            return self.candidate[node], self.balance[node]
        mid = lo + (hi - lo) // 2
        return self._merge(
            self._range_candidate(node * 2, lo, mid, left, right),
            self._range_candidate(node * 2 + 1, mid + 1, hi, left, right),
        )

    def query(self, left: int, right: int, threshold: int) -> int:
        value, _ = self._range_candidate(1, 0, self.n - 1, left, right)
        indexes = self.positions[value]
        count = bisect_right(indexes, right) - bisect_left(indexes, left)
        return value if count >= threshold else -1
class MajorityChecker {
    struct Vote {
        int candidate;
        int balance;
    };

    int n;
    vector<Vote> tree;
    unordered_map<int, vector<int>> positions;

    static Vote mergeVotes(Vote a, Vote b) {
        if (a.balance == 0) return b;
        if (b.balance == 0) return a;
        if (a.candidate == b.candidate) {
            return {a.candidate, a.balance + b.balance};
        }
        if (a.balance >= b.balance) {
            return {a.candidate, a.balance - b.balance};
        }
        return {b.candidate, b.balance - a.balance};
    }

    void build(int node, int lo, int hi, const vector<int>& arr) {
        if (lo == hi) {
            tree[node] = {arr[lo], 1};
            return;
        }
        int mid = lo + (hi - lo) / 2;
        build(node * 2, lo, mid, arr);
        build(node * 2 + 1, mid + 1, hi, arr);
        tree[node] = mergeVotes(tree[node * 2], tree[node * 2 + 1]);
    }

    Vote rangeCandidate(int node, int lo, int hi, int left, int right) const {
        if (right < lo || hi < left) return {0, 0};
        if (left <= lo && hi <= right) return tree[node];
        int mid = lo + (hi - lo) / 2;
        return mergeVotes(
            rangeCandidate(node * 2, lo, mid, left, right),
            rangeCandidate(node * 2 + 1, mid + 1, hi, left, right)
        );
    }

public:
    MajorityChecker(vector<int>& arr) {
        n = static_cast<int>(arr.size());
        tree.resize(n * 4);
        for (int i = 0; i < n; ++i) positions[arr[i]].push_back(i);
        build(1, 0, n - 1, arr);
    }

    int query(int left, int right, int threshold) {
        int value = rangeCandidate(1, 0, n - 1, left, right).candidate;
        const vector<int>& indexes = positions[value];
        int count = static_cast<int>(
            upper_bound(indexes.begin(), indexes.end(), right) -
            lower_bound(indexes.begin(), indexes.end(), left)
        );
        return count >= threshold ? value : -1;
    }
};

替代方案

随机采样：从查询区间随机取若干下标，把其值作为候选，再用位置表验证。由于答案若存在占比超过一半，多次未抽中的概率指数下降。代码短、期望性能好，但不是确定性保证。

分块：预处理块级众数或候选，查询时组合完整块并扫描边缘。实现可控，但参数调优与最坏复杂度通常不如本解简洁。

每次直接投票：时间为 O(right-left+1)，在最多一万次查询下可能过慢。

常见错误

  • 把线段树候选直接当答案，忘记按 threshold 验证。
  • 父节点只保存“区间出现最多的数”，却没有足够信息正确合并。
  • 二分使用两个 lower bound 时忘记将右目标写成 right + 1。
  • 误认为净票数等于候选的真实出现次数。
  • 查询无覆盖区间返回普通候选而不是零票的单位元。

面试追问

为什么阈值条件如此关键？

它保证合法答案一定是严格多数且至多一个，于是 Boyer–Moore 候选足以覆盖所有可能答案。如果允许较小阈值，一个区间可能有多个达标值，单候选摘要会丢失信息。

如果数组支持单点修改怎么办？

线段树候选可在 O(log n) 更新；但位置表也要动态维护。可以为每个值维护有序集合，或改用支持秩查询的数据结构。整体设计会更复杂。

能否只保存线段树，不保存位置表？

不能可靠判断候选是否达到任意 threshold，因为摘要中的 balance 是抵消后的净票数，不是真实频次。还需要可做区间计数的结构。
