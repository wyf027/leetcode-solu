Process Restricted Friend Requests

一条新连接，会让谁成为间接朋友？
按请求顺序作出决定，同时守住不能跨越的关系边界。

官方题目 ↗

01 / PROBLEM

题目与规则

有 n 个用户，编号为 0…n−1，开始时互不认识。restrictions[i] = [xᵢ, yᵢ] 表示这两人既不能直接成为朋友，也不能通过任意其他人形成朋友链。

按下标从 0 开始的顺序处理 requests[j] = [uⱼ, vⱼ]。如果添加这条好友关系后仍满足全部限制，就接受请求，关系持续生效；否则拒绝且不建立关系。返回布尔数组 result，第 j 项表示第 j 条请求是否被接受。

请求不可重新排序。已经是直接朋友的两人再次请求，仍应返回 true。

函数参数

friendRequests(n: integer, restrictions: integer[][], requests: integer[][]) → boolean[]

完整约束

  • 2 ≤ n ≤ 1000
  • 0 ≤ restrictions.length ≤ 1000
  • restrictions[i].length == 2
  • 0 ≤ xᵢ, yᵢ ≤ n − 1，且 xᵢ ≠ yᵢ
  • 1 ≤ requests.length ≤ 1000
  • requests[j].length == 2
  • 0 ≤ uⱼ, vⱼ ≤ n − 1，且 uⱼ ≠ vⱼ

02 / EXAMPLES

官方示例

示例 1

n = 3, restrictions = [[0,1]], requests = [[0,2],[2,1]]

输出：[true,false]

先接受 0—2；再连 2—1 会产生 0—2—1，触犯限制 [0,1]。

示例 2

n = 3, restrictions = [[0,1]], requests = [[1,2],[0,2]]

输出：[true,false]

先接受 1—2；再连 0—2 会使 0 和 1 通过用户 2 间接相连。

示例 3

n = 5, restrictions = [[0,1],[1,2],[2,3]], requests = [[0,4],[1,2],[3,1],[3,4]]

输出：[true,false,true,false]

接受 0—4；拒绝直接受限的 1—2；接受 3—1；最后的 3—4 会产生 0—4—3—1，必须拒绝。

05 / SOLUTION · OPTIONAL
留一点空间，先自己想想
仅检查请求双方是否直接出现在限制列表中，够不够？
并查集：合并前检查两圈之间的限制
核心洞察
朋友链只关乎连通性。用并查集表示每个好友圈；新请求最多合并两个集合 A、B。危险的情况恰好是某条限制两端分别落在 A、B 中。限制针对用户，但检查必须使用他们当前的集合代表。
a = find(u), b = find(v)
x = find(restriction[0]), y = find(restriction[1])
冲突 ⇔ (x == a 且 y == b) 或 (x == b 且 y == a)


完整过程
  1. 初始化每人一个集合，维护 parent 和 size。
  2. 查找请求双方的根 a、b；如果相同，直接接受，不改变连通性。
  3. 根不同时，扫描所有限制，重新查找每条限制端点的根。
  4. 发现跨越 a、b 的限制就拒绝；不合并，集合成员关系不变。
  5. 全部检查无冲突后，把较小集合挂到较大集合，记录 true。
  6. 按原顺序重复，返回结果数组。
查根采用路径折半压缩，合并采用按大小合并。检查期间的路径压缩只改变树形，不改变连通性，因而不会污染拒绝后的状态。


示例 3 的关键转折
接受 [0,4] 后有 {0,4}；拒绝 [1,2] 后集合不变；接受 [3,1] 后有 {1,3}。请求 [3,4] 不在直接限制列表里，却要合并 {1,3} 与 {0,4}；限制 [0,1] 横跨两圈，因此拒绝。


正确性证明
不变式：处理任意请求前缀后，并查集恰好表示已接受请求的连通分量，所有限制两端仍处于不同分量。初始各人独立，不变式成立。
同圈：添加圈内关系不改变分量，因此保持合法。
异圈：新关系只会合并 A、B。已有分量内部不存在限制，其他分量不受影响，所以新违规出现当且仅当限制原先横跨 A、B。双向根比较精确识别这一条件。发现则拒绝，未发现则合并，两种情况下不变式均保持。
由归纳法，每一步的决定都与题目规则一致，因此整个布尔数组正确。


边界与常见错误
  • 没有限制：全部接受；不能把 R=0 误写成没有工作量。
  • 同圈、重复、反向请求：仍然接受，只要没有改变合法连通状态。
  • 只检查 (u,v) 是否直接受限会漏掉间接关系。
  • 缓存限制端点的初始根会失效；每次应重新 find。
  • 限制是无向的，需检查两种朝向。
  • 不要先 union 再回滚，普通路径压缩并查集不支持简单撤销。
  • 拒绝不能改变集合划分，必须先完整检查再合并。


复杂度
设 R 为限制条数，Q 为请求条数。初始化 O(n)，每条请求最多 O(R+1) 次查根。路径压缩与按大小合并使总时间为 O(n + Q(R+1) α(n))，α 为反阿克曼函数。辅助空间 O(n)，计入返回数组为 O(n+Q)。


替代方案
每次使用 BFS/DFS 重新计算分量也可以，但会反复遍历图。直接维护每个人的集合标签，合并时遍历全部用户重新标记，可得到 O(Q(R+n)) 的简单版本。更大规模时可以维护分量之间的禁止集合，用小并大合并，但必须处理双向关系、去重和根更新，工程复杂度更高。本题各规模不超过 1000，逐请求扫描限制已经合适。


面试追问
  • 必须存全部好友边吗？只求布尔结果无需存边；若要展示违规的具体朋友链，需要额外保留图并搜索路径。
  • 可以重排请求吗？不可以，顺序会影响后续连通状态。
  • 支持删除关系怎么办？普通并查集不能拆分；可视场景考虑离线时间分治和可回滚并查集，或动态连通性结构。
  • 为什么同时按大小合并和路径压缩？前者控制树高，后者加速重复查根，组合得到近常数摊还复杂度。

class Solution {
    private int[] parent, size;
    private int find(int x) {
        while (x != parent[x]) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    public boolean[] friendRequests(int n, int[][] restrictions, int[][] requests) {
        parent = new int[n];
        size = new int[n];
        for (int i = 0; i < n; i++) { parent[i] = i; size[i] = 1; }
        boolean[] result = new boolean[requests.length];
        for (int i = 0; i < requests.length; i++) {
            int a = find(requests[i][0]), b = find(requests[i][1]);
            boolean ok = true;
            if (a != b) {
                for (int[] pair : restrictions) {
                    int x = find(pair[0]), y = find(pair[1]);
                    if ((x == a && y == b) || (x == b && y == a)) {
                        ok = false;
                        break;
                    }
                }
                if (ok) {
                    if (size[a] < size[b]) { int t = a; a = b; b = t; }
                    parent[b] = a;
                    size[a] += size[b];
                }
            }
            result[i] = ok;
        }
        return result;
    }
}

/**
 * @param {number} n
 * @param {number[][]} restrictions
 * @param {number[][]} requests
 * @return {boolean[]}
 */
var friendRequests = function(n, restrictions, requests) {
    const parent = Array.from({length: n}, (_, i) => i);
    const size = Array(n).fill(1);
    function find(x) {
        while (x !== parent[x]) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
    const result = [];
    for (const [u, v] of requests) {
        let a = find(u), b = find(v), ok = true;
        if (a !== b) {
            for (const [x, y] of restrictions) {
                const rx = find(x), ry = find(y);
                if ((rx === a && ry === b) || (rx === b && ry === a)) {
                    ok = false;
                    break;
                }
            }
            if (ok) {
                if (size[a] < size[b]) [a, b] = [b, a];
                parent[b] = a;
                size[a] += size[b];
            }
        }
        result.push(ok);
    }
    return result;
};

from typing import List

class Solution:
    def friendRequests(self, n: int, restrictions: List[List[int]],
                       requests: List[List[int]]) -> List[bool]:
        parent = list(range(n))
        size = [1] * n

        def find(x):
            while x != parent[x]:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x

        result = []
        for u, v in requests:
            a, b = find(u), find(v)
            ok = True
            if a != b:
                for x, y in restrictions:
                    rx, ry = find(x), find(y)
                    if (rx == a and ry == b) or (rx == b and ry == a):
                        ok = False
                        break
                if ok:
                    if size[a] < size[b]:
                        a, b = b, a
                    parent[b] = a
                    size[a] += size[b]
            result.append(ok)
        return result


C++
#include <vector>
#include <numeric>
#include <utility>
using namespace std;

class Solution {
    vector<int> parent, size;
    int find(int x) {
        while (x != parent[x]) {
            parent[x] = parent[parent[x]];
            x = parent[x];
        }
        return x;
    }
public:
    vector<bool> friendRequests(int n, vector<vector<int>>& restrictions,
                               vector<vector<int>>& requests) {
        parent.resize(n);
        iota(parent.begin(), parent.end(), 0);
        size.assign(n, 1);
        vector<bool> result;
        for (const auto& req : requests) {
            int a = find(req[0]), b = find(req[1]);
            bool ok = true;
            if (a != b) {
                for (const auto& pair : restrictions) {
                    int x = find(pair[0]), y = find(pair[1]);
                    if ((x == a && y == b) || (x == b && y == a)) {
                        ok = false;
                        break;
                    }
                }
                if (ok) {
                    if (size[a] < size[b]) swap(a, b);
                    parent[b] = a;
                    size[a] += size[b];
                }
            }
            result.push_back(ok);
        }
        return result;
    }
};
