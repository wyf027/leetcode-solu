01 / THE CHALLENGE

题目：按出现顺序，找第二个

给定下标从 0 开始的非负整数数组 nums。对于每个下标 i，从它的右侧向右扫描，在所有严格大于 nums[i] 的元素中，取第二个遇到的元素值；不足两个时返回 -1。返回与原数组等长的数组 answer。

这里的“第二大”指第二次出现的更大值，不是按数值排序后的第二大，也不是“第一个更大元素的下一个更大元素”。

形式化地，答案来自 j > i，且 nums[j] > nums[i]；在 i < k < j 之间，恰好有一个下标 k 满足 nums[k] > nums[i]。

参数与返回值

secondGreaterElement(nums: integer[]) → integer[]

约束

1 ≤ nums.length ≤ 10⁵
0 ≤ nums[i] ≤ 10⁹

EXAMPLE 01

不同位置，各自计数

输入：nums = [2,4,0,9,6]
输出：[9,6,6,-1,-1]

2 右侧先遇到 4，再遇到 9；4 右侧先遇到 9，再遇到 6；0 右侧先遇到 9，再遇到 6。9 与末尾的 6 都找不到两个更大值。

EXAMPLE 02

相等，不计入更大

输入：nums = [3,3]
输出：[-1,-1]

两个 3 相等，不满足严格大于。两处位置的答案都是 -1。

INSIGHT / TWO WAITING ROOMS

两个等待区，一次从左到右

每个位置只需要经历三种状态：还没遇到更大值、已经遇到一个更大值、答案确定。用 s1 保存“等第一个”的下标，用 s2 保存“等第二个”的下标。两栈的对应数值从栈底到栈顶均为非递增。

  1. 处理当前值 x 时，先从 s2 弹出所有值小于 x 的栈顶，它们的答案就是 x。
  2. 再从 s1 弹出所有值小于 x 的栈顶，临时放进 temp；这些位置刚找到第一个更大值。
  3. 从 temp 逐个弹出并压入 s2，恢复原顺序。直接转移会破坏 s2 的单调性。
  4. 把当前下标压入 s1，等待后面的值。最后仍在等待区的位置保留 -1。

必须先处理 s2，再迁移 s1。否则同一个 x 可能同时被当作某位置的第一个和第二个更大值。

完整过程与正确性

沿官方示例走一遍

读到 2：进入 s1。读到 4：2 转入 s2，4 进入 s1。读到 0：0 进入 s1。读到 9：s2 中的 2 得到答案 9；s1 中的 0、4 依次弹出，再以 4、0 的顺序进入 s2；9 进入 s1。读到 6：s2 中的 0、4 都得到答案 6；6 进入 s1。结束后得到 [9,6,6,-1,-1]。

不变量与归纳

  1. 状态准确：每轮开始前，s1 中的位置在已扫描后缀里恰好遇到零个更大值，s2 中的位置恰好遇到一个；完成的位置已经遇到第二个。
  2. 栈顶能代表可处理集合：两栈数值非递增，所以小于 x 的位置构成栈顶连续一段。弹到栈顶不小于 x 即可停止，不会遗漏栈底的可处理位置。
  3. 迁移保持单调：s1 弹出的数值非递减，借 temp 再弹出得到非递增序列；处理 s2 后，其剩余栈顶不小于 x，而迁入的数值都小于 x，因此拼接后仍非递增。s1 剩余栈顶也不小于 x，可以压入当前值。
  4. 答案恰是第二次：s2 中某位置被 x 弹出前只有一个更大值；x 是下一次严格更大的值，恰好成为第二个。先结算再迁移确保不会重复计算当前值。按从左到右的扫描顺序，得到的 j 也是符合定义的那个位置。

初始两栈为空，不变量成立；每轮保持上述性质。扫描结束后，等待区内的位置不足两次更大值，答案保留 -1，因而所有位置均符合定义。

边界与复杂度

相等值不弹栈；但两个相同的、更大的值可以分别算第一次和第二次。单元素、全相等、递减数组均返回全 -1。答案保存数值而非下标。10⁹ 不超出四语言实现使用的数值范围。

时间 O(n)，额外空间 O(n)。每个下标在 s1、temp、s2 中至多各入栈出栈一次，嵌套 while 的总操作次数仍为线性。演示为支持回退保存了逐步快照，只用于最多 24 个元素；四份提交代码不保存快照。

JavaScript

/**
 * @param {number[]} nums
 * @return {number[]}
 */
var secondGreaterElement = function(nums) {
    const answer = Array(nums.length).fill(-1);
    const s1 = [], s2 = [], temp = [];
    for (let i = 0; i < nums.length; i++) {
        const x = nums[i];
        while (s2.length && nums[s2[s2.length - 1]] < x) {
            answer[s2.pop()] = x;
        }
        while (s1.length && nums[s1[s1.length - 1]] < x) {
            temp.push(s1.pop());
        }
        while (temp.length) s2.push(temp.pop());
        s1.push(i);
    }
    return answer;
};

Java

import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Deque;

class Solution {
    public int[] secondGreaterElement(int[] nums) {
        int[] answer = new int[nums.length];
        Arrays.fill(answer, -1);
        Deque<Integer> s1 = new ArrayDeque<>();
        Deque<Integer> s2 = new ArrayDeque<>();
        Deque<Integer> temp = new ArrayDeque<>();
        for (int i = 0; i < nums.length; i++) {
            int x = nums[i];
            while (!s2.isEmpty() && nums[s2.peek()] < x) {
                answer[s2.pop()] = x;
            }
            while (!s1.isEmpty() && nums[s1.peek()] < x) {
                temp.push(s1.pop());
            }
            while (!temp.isEmpty()) s2.push(temp.pop());
            s1.push(i);
        }
        return answer;
    }
}

Python 3

from typing import List

class Solution:
    def secondGreaterElement(self, nums: List[int]) -> List[int]:
        answer = [-1] * len(nums)
        s1, s2, temp = [], [], []
        for i, x in enumerate(nums):
            while s2 and nums[s2[-1]] < x:
                answer[s2.pop()] = x
            while s1 and nums[s1[-1]] < x:
                temp.append(s1.pop())
            while temp:
                s2.append(temp.pop())
            s1.append(i)
        return answer

C++

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> secondGreaterElement(vector<int>& nums) {
        vector<int> answer(nums.size(), -1);
        vector<int> s1, s2, temp;
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            int x = nums[i];
            while (!s2.empty() && nums[s2.back()] < x) {
                answer[s2.back()] = x;
                s2.pop_back();
            }
            while (!s1.empty() && nums[s1.back()] < x) {
                temp.push_back(s1.back());
                s1.pop_back();
            }
            while (!temp.empty()) {
                s2.push_back(temp.back());
                temp.pop_back();
            }
            s1.push_back(i);
        }
        return answer;
    }
};

替代方案与面试追问

还有哪些路径？

逐位置向右扫描：计数到两次即停止，逻辑直接；最坏 O(n²) 时间，额外空间 O(1)（不含答案），不适合 10⁵ 规模。

单调栈 + 最小堆：s1 等第一次，更大值出现后把位置放入按原数值排序的最小堆。每轮先弹出堆里小于 x 的值并赋答案，再迁移 s1。时间 O(n log n)，空间 O(n)，不需要维护第二个栈的顺序。

面试追问

  • 为什么不是 nextGreater(nextGreater(i))？第二次只要求大于原来的 nums[i]，例如 [1,5,2]，1 的答案是 2。
  • 推广到第 k 个更大值？固定较小 k 可用 k 个等待栈，从高阶段向低阶段处理并反转迁移，约 O(kn) 时间；k 很大时应重新评估有序数据结构方案。
  • 如果要返回下标？在 s2 出栈时记录当前 i，而非 nums[i]；不存在仍使用 -1。
  • 可以在线处理吗？可以边读边确定旧位置的答案；尚未满足条件的位置需要持续保存，到流结束才能判定 -1。

常见错误

  • 使用 ≤ 弹栈，把相等误当严格更大。
  • 先迁移 s1 再结算 s2，让同一位置在同一轮被推进两次。
  • 直接将 s1 弹出的下标压到 s2，不反转，导致小值被大值挡住。
  • 存数值而不存下标，遇到重复值时无法把答案写回原位置。
  • 将 -1 当作演示中的“已完成”；未处理位置和最终无解位置需要通过扫描状态区分。
