从左上到右下，每步仅能向右或向下；负数伤害、零为空房、正数治疗。

生命规则

进入任何房间后生命必须至少为 1。入口和公主所在出口也可能有伤害或增益。

约束

  • 1 ≤ m,n ≤ 200
  • -1000 ≤ dungeon[i][j] ≤ 1000
  • m = dungeon.length
  • 所有行长度均为 n

Solution unlocked

从终点逆向 DP

定义 need[i][j]：进入该格前、并能最终救出公主所需的最小生命。

核心洞察与转移

need = max(1, min(right, down) - cell)

先选择右方和下方中要求更低的出口；当前房间的增益会降低进入需求，伤害会提高需求。max(1,...) 保证进入后始终活着。右下角可视为出口需求 1。

为何正向血量不足

同一格“当前血量更高”不一定代表“所需初始血量更小”，因为路径的最低前缀血量也影响可行性；只记当前累计和会丢失历史最低点。逆向状态直接回答未来最低需求，具有无后效性。

完整过程与空间优化

二维表为 O(mn) 时间、O(mn) 空间。按从下到上、从右到左更新时，dp[j] 表示下方，dp[j+1] 表示右方，可压缩到 O(n) 空间。入口、出口、单格、大负值均由同一公式处理。

时间 O(mn)

每格一次。

空间 O(n)

一维优化；可取较短维进一步优化。

边界与不变量

  • 单格地牢也先承受该格效果，答案是 max(1, 1 - cell)。
  • 每轮开始时，dp[j] 是下方需求，dp[j+1] 是右方需求。
  • 不可达方向保持无穷大；右下角外侧只放一个需求为 1 的出口哨兵。
  • 所有增益格仍需至少 1 点生命进入，不能让需求降到 0。

替代方案与面试追问

  • 暴力枚举所有路径，指数级，仅适合作为小矩阵参考。
  • 二分初始生命 + 可达性检查更复杂，通常不如逆向 DP。
  • 若允许四方向移动，状态图可能有环，需重新建模。

常见错误

  • 漏掉 max(1,...)。
  • 边界哨兵放错，导致不存在的方向被选择。
  • 正向只记累计生命，忽略最低前缀。
  • 把入口或出口特殊处理错，忘记它们也有格子值。

Java

class Solution {
    public int calculateMinimumHP(int[][] dungeon) {
        int m = dungeon.length, n = dungeon[0].length;
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[n - 1] = 1;
        for (int i = m - 1; i >= 0; i--) {
            for (int j = n - 1; j >= 0; j--) {
                int next = Math.min(dp[j], dp[j + 1]);
                dp[j] = Math.max(1, next - dungeon[i][j]);
            }
        }
        return dp[0];
    }
}

class Solution:
    def calculateMinimumHP(self, dungeon: List[List[int]]) -> int:
        m, n = len(dungeon), len(dungeon[0])
        dp = [float("inf")] * (n + 1)
        dp[n - 1] = 1
        for i in range(m - 1, -1, -1):
            for j in range(n - 1, -1, -1):
                next_need = min(dp[j], dp[j + 1])
                dp[j] = max(1, next_need - dungeon[i][j])
        return dp[0]

class Solution {
public:
    int calculateMinimumHP(vector<vector<int>>& dungeon) {
        int m = dungeon.size(), n = dungeon[0].size();
        vector<int> dp(n + 1, INT_MAX);
        dp[n - 1] = 1;
        for (int i = m - 1; i >= 0; --i) {
            for (int j = n - 1; j >= 0; --j) {
                int next = min(dp[j], dp[j + 1]);
                dp[j] = max(1, next - dungeon[i][j]);
            }
        }
        return dp[0];
    }
};
