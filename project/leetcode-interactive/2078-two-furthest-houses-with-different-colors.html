01 / THE PROBLEM

题目与输入约定

街道上等间距排列着 n 栋房子。整数数组 colors 使用从 0 开始的下标，colors[i] 是第 i 栋房子的颜色编号。选取颜色不同的两栋房子，返回它们能达到的最大下标距离 |i − j|。

输入：colors: integer[]。输出：一个整数。颜色数值只代表类别，颜色编号之差不是房子的距离。

  • n == colors.length
  • 2 ≤ n ≤ 100
  • 0 ≤ colors[i] ≤ 100
  • 题目保证至少存在两栋颜色不同的房子。

colors = [1,1,1,6,1,1,1]

示例 2

colors = [1,8,3,8,3]

示例 3

colors = [0,1]
输出：1

仅有两栋房子，颜色不同，距离为 1。

04 / EDITORIAL

想好之后，再看题解

推导、正确性与四语言实现默认收起。

只比较街道两端，就足够了

核心洞察

至少存在一组最优解包含下标 0 或下标 n−1。因此遍历每个下标 i，分别尝试与左端和右端配对，无需枚举所有房子对。

完整过程

  1. 令 ans = 0，从左到右遍历 i = 0…n−1。
  2. 若 colors[i] != colors[0]，用距离 i 更新答案。
  3. 若 colors[i] != colors[n−1]，用距离 n−1−i 更新答案。两个判断分别执行。
  4. 返回所有有效候选距离的最大值。

示例 1 中，只有下标 3 的颜色与两个端点不同。比较 (0, 3) 得到 3，比较 (3, 6) 也得到 3。实验室将每次遍历拆成“比较左端”和“比较右端”两个画面，高亮被比较的房子并维护当前最大值。

正确性证明

任取一对不同色房子 i < j。如果 colors[0] != colors[j]，那么 (0, j) 有效，且距离 j ≥ j−i。否则 colors[0] = colors[j]，因为 i、j 不同色，所以 colors[i] != colors[0]。此时若 colors[i] != colors[n−1]，则 (i, n−1) 有效，且距离 n−1−i ≥ j−i；否则右端与 i 同色，从而左右端不同色，(0, n−1) 有效且距离最大。

因此任何有效房子对都能被一组包含端点的有效配对替代，且距离不减。算法覆盖所有与端点配对的候选，只对不同色候选取最大值，所以返回值就是全局最优距离。遍历过程中，ans 始终等于已经检查的有效候选的最大距离。

边界与复杂度

  • n = 2：合法输入必然不同色，返回 1。
  • 首尾不同：答案一定是 n−1；当前实现仍完整遍历以保持过程统一。
  • 首尾相同：必须考虑两个方向，内部异色房子可能更靠近某一端。
  • 全同色不满足题意保证；演示入口会拒绝此输入。
  • 颜色可以是 0，也可以是 100；只做相等性比较，不参与距离计算。
  • 时间 O(n)，额外空间 O(1)。演示为支持回退保存 O(n) 帧，与提交算法的空间复杂度不同。

替代方案

暴力枚举所有 i < j，异色时更新最大距离：时间 O(n²)、空间 O(1)，在 n ≤ 100 时可行。另一个 O(n) / O(1) 写法：从右向左找第一个不同于左端的颜色，再从左向右找第一个不同于右端的颜色，对两种距离取最大值。当前版本使用一次遍历和两个独立判断，便于解释与演示。

Java

class Solution {
    public int maxDistance(int[] colors) {
        int n = colors.length;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (colors[i] != colors[0]) {
                ans = Math.max(ans, i);
            }
            if (colors[i] != colors[n - 1]) {
                ans = Math.max(ans, n - 1 - i);
            }
        }
        return ans;
    }
}

常见错误

  • 返回颜色编号的差：需要算下标差。
  • 只检查左端：例如 [1,2,1,1,1] 会漏掉距离 3。
  • 用 else if 连接两次判断：一个内部房子可能同时不同于两端，必须分别考虑两个距离。
  • 把 n−1−i 写成 n−i：房子的数量与下标跨度相差 1。
  • 排序数组：会破坏街道上的原始位置。

面试追问

如何同时返回房子下标？ 更新答案时记录对应的 (0, i) 或 (i, n−1)，只多用常数空间。若要返回所有并列最优对，需要另行枚举并明确去重规则。

如果房子不是等间距的呢？ 若给出按位置递增的坐标，端点替代证明仍成立，将下标差替换为坐标差即可。

如果允许全同色输入呢？ 先明确无解返回值（如 −1），再修改初始值和接口约定；不要把此题的合法输入保证无声删掉。
