打家劫舍
House Robber

把一排互相相邻会触发警报的房屋，变成一条可交互追踪的「选或不选」状态链。

题意

数组 nums 给出每间房屋可取得的金额。不能在同一晚选择两间相邻房屋；返回能取得的最大金额。

约束
房屋数为 1 到 100；每个金额为 0 到 400。

官方样例（转述）

输入nums = [1, 2, 3, 1]
输出4
输入nums = [2, 7, 9, 3, 1]
输出12

题解：相邻约束只需要记住前两次最优值

状态：处理到当前金额 x 时，只有两种选择：跳过它，保留 prev1；或选择它，加上前前间的最优值 prev2 + x。取二者较大。

  1. 初始化 prev2 = 0、prev1 = 0。
  2. 每个 x 计算 current = max(prev1, prev2 + x)。
  3. 窗口右移：prev2 = prev1，prev1 = current。
为什么够用？当前决定只会引用「上一间不能选」的答案和「上上间可以累加」的答案；更早的信息已经压缩进它们。

边界与复杂度

[0] 返回 0；单间房可直接选；相同金额、多个 0 也不会破坏转移。时间 O(n)，额外空间 O(1)。

替代方案与取舍

完整 DP 数组更利于回溯选择了哪些房屋，但占 O(n) 空间；这里仅需最大金额，两个变量更适合面试主线。

面试追问

若房屋首尾相连（House Robber II），分别求「不含首间」与「不含末间」两段，取较大值。若要恢复路径，则保留 DP 数组并倒推。

常见错误

  • 选择当前房屋时错误地加上 prev1，这会偷到相邻房屋。
  • 更新变量时覆盖旧 prev1；先用临时变量保存 current。
  • 把数组为空当作题目约束；本题至少一间，但实现可自然兼容空数组。
