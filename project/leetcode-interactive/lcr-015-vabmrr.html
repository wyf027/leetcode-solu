找到字符串中所有字母异位词

固定长度的滑动窗口配合 26 个字母的频次数组：窗口的每次右移只增减两个字符，却能在线判断它是否恰好是目标串的异位词。

题意

给定字符串 s 与 p，找出 s 中所有 p 的字母异位词子串，返回其起始下标。字符均为小写英文字母。

示例

s = "cbaebabacd", p = "abc"

output = [0, 6]

异位词的顺序可以不同，但每个字母出现次数必须完全相同。因此每个长度为 p.length 的窗口都可用频次数组比较。

约束

1 ≤ s.length, p.length ≤ 3 × 104，s 与 p 只含小写字母。

    核心洞察

    维护 need（p 的 26 个字符频次）和窗口 count。窗口首次达到长度 m 后，每向右移动一格，只需加入右字符、移出左字符；当两个频次数组相同，当前左端就是答案。

    完整过程

    1. 统计 p 中每个字母的出现次数。
    2. 右指针遍历 s，并把字符计入窗口。
    3. 窗口超过 p 长度时，移出左端字符并右移左指针。
    4. 窗口长度相等且频次一致时，记录左指针。

    边界与常见错误

    • p.length > s.length 时直接返回空数组。
    • 窗口必须保持固定长度，不能只比较“包含关系”。
    • 结果可以重叠，例如 "abab" 中 "ab" 命中 0、1、2。

    复杂度：每个字符至多进出窗口一次，时间 O(n)，频次数组为 O(1) 空间（26 个小写字母）。

    可提交代码

    Java

    class Solution {
  public List<Integer> findAnagrams(String s, String p) {
    List<Integer> ans = new ArrayList<>(); int[] need = new int[26], win = new int[26];
    for (char c : p.toCharArray()) need[c - 'a']++;
    for (int r = 0; r < s.length(); r++) { win[s.charAt(r) - 'a']++; if (r >= p.length()) win[s.charAt(r - p.length()) - 'a']--; if (r + 1 >= p.length() && Arrays.equals(need, win)) ans.add(r - p.length() + 1); }
    return ans;
  }
}

    JavaScript

    var findAnagrams = function (s, p) {
  const need = Array(26).fill(0), win = Array(26).fill(0), ans = [];
  for (const c of p) need[c.charCodeAt() - 97]++;
  for (let r = 0; r < s.length; r++) { win[s.charCodeAt(r) - 97]++; if (r >= p.length) win[s.charCodeAt(r - p.length) - 97]--; if (r + 1 >= p.length && need.every((v, i) => v === win[i])) ans.push(r - p.length + 1); }
  return ans;
};

    Python

    class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        need, win, ans = [0] * 26, [0] * 26, []
        for ch in p: need[ord(ch) - 97] += 1
        for r, ch in enumerate(s):
            win[ord(ch) - 97] += 1
            if r >= len(p): win[ord(s[r - len(p)]) - 97] -= 1
            if r + 1 >= len(p) and win == need: ans.append(r - len(p) + 1)
        return ans

    C++

    class Solution {
public:
  vector<int> findAnagrams(string s, string p) {
    vector<int> need(26), win(26), ans; for (char c : p) need[c - 'a']++;
    for (int r = 0; r < s.size(); ++r) { win[s[r] - 'a']++; if (r >= p.size()) win[s[r - p.size()] - 'a']--; if (r + 1 >= p.size() && win == need) ans.push_back(r - p.size() + 1); }
    return ans;
  }
};
