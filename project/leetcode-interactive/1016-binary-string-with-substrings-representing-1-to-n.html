子串能表示从 1 到 N 数字的二进制串

Binary String With Substrings Representing 1 To N

给定二进制字符串 s 和正整数 n。如果区间 [1,n] 中每个整数的标准二进制表示都作为连续子字符串出现在 s 中，返回 true；否则返回 false。子字符串必须连续。

示例与约束

示例 1
输入：s = "0110", n = 3
输出：true

示例 2
输入：s = "0110", n = 4
输出：false

约束

  • 1 <= s.length <= 1000
  • s[i] 是 '0' 或 '1'
  • 1 <= n <= 10⁹

题解

核心洞察

只需检查 ⌊n/2⌋+1..n。任意较小的 x≤n/2 反复乘 2，最终会落进后半区；乘 2 只是在其二进制末尾追加 0，所以后半区对应的字符串出现时，较小的表示也随之出现。

完整过程

  1. 从 n 递减至 ⌊n/2⌋+1。
  2. 把当前数转换为无前导零的二进制字符串。
  3. 在 s 中查找；任一目标缺失立即返回 false。
  4. 全部命中则返回 true。

正确性

必要性：全集出现时，后半区作为子集必然出现。充分性：任取 x≤n/2，反复令其翻倍，必能得到 y=x·2ᵏ∈(n/2,n]。y 的二进制是 x 后追加若干个零；既然 y 出现在 s 中，x 也作为它的前缀子串出现。后半区直接检查，因此覆盖全部 1..n。

边界与复杂度

  • n=1 时仅检查 "1"；子串可重叠；标准表示没有前导零。
  • 检查约 n/2 个目标，目标长度 O(log n)；按朴素查找上界计为 O(n·|s|·log n)，额外空间 O(log n)。

替代方案

枚举 s 中每个以 1 开头、长度不超过 30 的子串，边扩展边转整数并存入集合，再判断覆盖。该方案更贴近 |s|，但实现更复杂。

面试追问

  • 为何至多 30 位？因为 n≤10⁹<2³⁰。
  • 如何避免溢出？枚举子串时数值超过 n 即停止扩展。
  • 多次查询如何优化？预处理所有至多 30 位子串对应的整数集合。

常见错误

  • 把子序列当成连续子字符串。
  • 忽略后半区推论，从 1 暴力检查到 n。
  • 保留前导零，改变表示语义。
  • 在 JavaScript 中误用 32 位有符号位运算。
