最小和分割

把一个整数的全部数位重新安排进两个非负整数，让它们的和尽可能小。先理解规则，再亲手推进数位实验；完整解法默认收起。

Problem

题意

给定正整数 num，使用它的每一个数位且恰好使用一次，组成两个非负整数 num1 与 num2。

两个数中的数位总出现次数必须与 num 完全一致；数位可以重新排序，也允许出现前导零。返回 num1 + num2 的最小可能值。

函数签名

splitNum(num: integer) → integer

约束

  • 10 ≤ num ≤ 10⁹
  • num 本身没有前导零。
  • num1、num2 可以包含前导零。
  • 组成后的数位顺序可以不同于原数。

Examples

官方示例

示例 1

输入：num = 4325
输出：59
解释：可组成 num1 = 24、num2 = 35，
因此最小和为 24 + 35 = 59。

示例 2

输入：num = 687
输出：75
解释：可组成 num1 = 68、num2 = 7，
因此最小和为 68 + 7 = 75。

Solution

准备好看完整题解了吗？

下方内容包含核心洞察、证明、复杂度、四语言代码与面试追问。

Greedy Solution

排序后交替放置

核心洞察

一个数位对结果的贡献等于“数位值 × 所在十进制位权”。越小的数位越应该占据越高位。先将全部数位升序排列，再依次交替追加到两个数末尾，就能同时做到两件事：

  1. 较小数位优先获得高位权；
  2. 两个数的长度尽量平衡，避免某个数额外出现更高位权。

以 4325 为例

升序数位为 2, 3, 4, 5，交替追加：

num1 = 24，num2 = 35

最小和：24 + 35 = 59

完整过程

拆分

将 num 转为字符数组，得到所有数位。

排序

按数位从小到大排序，使小数位先被处理。

交替追加

偶数下标追加给第一个数，奇数下标追加给第二个数。

求和

把两个字符串转为整数后相加；前导零会自然消失。

正确性证明

引理 1：对任意两个数位 a ≤ b 和两个位权 x ≥ y，有 a·x + b·y ≤ a·y + b·x，因为两边之差为 (b-a)(x-y) ≥ 0。因此较小数位放在较高位不会使总和变大。

引理 2：两个数的长度差至多为 1 时，所有数位占用的十进制位权集合最小；若长度差至少为 2，把较长数的一位移到较短数会消除一个不必要的更高位权。

结论：升序处理保证小数位优先匹配高位权，交替追加保证长度平衡。由两个引理，该构造在所有合法分割中取得最小和。

时间复杂度O(d log d)

其中 d 是 num 的数位个数，开销来自排序。

空间复杂度O(d)

保存数位数组以及两个结果字符串。

边界情况

  • 包含 0：零会排在最前并作为前导零，不增加数值，例如 1002 → 1 + 2 = 3。
  • 奇数位数：一个结果会多一位，交替放置仍保证长度差为 1。
  • 重复数位：排序与交替分配不依赖数位唯一性。
  • 两位数：每个数各取一位，结果就是两个数位之和。

替代方案

计数排序

数位只有 0～9，可用长度为 10 的计数数组按序取出，时间降为 O(d)。本题最多 10 位，普通排序更直接。

枚举所有分割

排列数位并枚举归属可以得到答案，但状态数量呈指数或阶乘增长，只适合作为小规模对照思路。

四语言完整代码

Java

import java.util.Arrays;

class Solution {
    public int splitNum(int num) {
        char[] digits = String.valueOf(num).toCharArray();
        Arrays.sort(digits);

        StringBuilder a = new StringBuilder();
        StringBuilder b = new StringBuilder();
        for (int i = 0; i < digits.length; i++) {
            (i % 2 == 0 ? a : b).append(digits[i]);
        }
        return Integer.parseInt(a.toString())
             + Integer.parseInt(b.toString());
    }
}

JavaScript

/**
 * @param {number} num
 * @return {number}
 */
var splitNum = function(num) {
    const digits = String(num).split('').sort();
    let a = '';
    let b = '';

    digits.forEach((digit, index) => {
        if (index % 2 === 0) a += digit;
        else b += digit;
    });

    return Number(a) + Number(b);
};

Python

class Solution:
    def splitNum(self, num: int) -> int:
        digits = sorted(str(num))
        a = ''.join(digits[::2])
        b = ''.join(digits[1::2])
        return int(a) + int(b)

C++

#include <algorithm>
#include <string>
using namespace std;

class Solution {
public:
    int splitNum(int num) {
        string digits = to_string(num);
        sort(digits.begin(), digits.end());

        string a, b;
        for (int i = 0; i < digits.size(); ++i) {
            (i % 2 == 0 ? a : b) += digits[i];
        }
        return stoi(a) + stoi(b);
    }
};

面试追问

为什么一定要让两个数的长度平衡？

因为额外的长度会产生更高的十进制位权。长度差超过 1 时，总能把较长数中的一个数位移给较短数，从而去掉一个不必要的高位。

能否做到线性时间？

可以。统计 0 到 9 各出现多少次，再从 0 到 9 依次交替放置，时间为 O(d)，额外空间为 O(1)。

如果输入有上百万位怎么办？

不能再转换成普通整数；应使用计数排序构造两个大整数字符串，再执行字符串加法。

常见错误

  • 排序后把前半段与后半段分别组成两个数，导致大数位集中。
  • 按数位值求和，忽略数位所在位置的十进制位权。
  • 先去掉 0；零也必须被使用，只是可作为前导零。
  • 两个结果不平衡，让其中一个数比另一个多出两位以上。
  • 把字符串按字典序之外的错误比较器排序。
