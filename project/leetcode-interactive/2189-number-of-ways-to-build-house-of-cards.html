01 / 题目

恰好用完 n 张纸牌

输入整数 n，返回满足以下搭建规则的纸牌屋数量。纸牌屋至少有一层；只要某一层的纸牌数量不同，就视为不同的方案。

  • 两张斜靠的纸牌组成一个三角形。
  • 同层每对相邻三角形之间，都必须连接一张水平纸牌。
  • 除底层外，每个三角形都要落在下一层的一张水平牌上。
  • 每层总是优先使用最左侧的可用位置；位置偏移不额外计数。
  • 必须用完所有纸牌，不能留下余牌。
接口：houseOfCards(n: integer) → integer
约束：1 ≤ n ≤ 500

官方示例（参数完整列出）

EXAMPLE 01

输入：n = 16
输出：2

存在两种合法搭建。没有水平牌承托的上层三角形不合法。

EXAMPLE 02

输入：n = 2
输出：1

两张牌只能搭成一个三角形。

EXAMPLE 03

输入：n = 4
输出：0

两个并排三角形缺少连接牌；一个三角形又有余牌，因此没有合法方案。

02 / 从支撑关系到计数

每种层宽最多选一次

一层有 k 个三角形时，斜牌用掉 2k 张，连接牌有 k − 1 张，总成本是 3k − 1。可用层成本依次为 2、5、8、11、14……。

下层有 k 个三角形，就只有 k − 1 个承托位置，因此上层宽度必须严格小于 k。反过来，任意严格递减的正整数层宽序列，都能按最左规则搭成唯一纸牌屋。

选择若干互不相同的层成本，使总和等于 n。选完按宽度从大到小搭建即可，无需计算排列。问题转化为 0/1 背包计数。

完整过程

  1. dp[s] 表示只用已处理层成本，恰好用 s 张牌的方案数。
  2. 设置 dp[0] = 1，代表什么都不选的起点；其余位置为 0。
  3. 从小到大处理成本 c = 2, 5, 8, … ≤ n。
  4. 对每个 c，从 s = n 倒序走到 c，累加 dp[s] += dp[s - c]。
  5. 所有成本处理后返回 dp[n]。n 是正数，空选方案不会计入答案。

为什么倒序？读取的 dp[s-c] 尚未用过本轮成本 c，保证每种宽度只选一次。正序会重复选同宽层，使上层失去足够的承托位置。

03 / 交互实验

层成本 × 倒序计数带

每一步处理一个目标格：金色是来源，绿色是目标。上方画出本轮候选层，斜牌与连接牌分别着色。演示为便于阅读限制 n ≤ 40；提交代码支持 n ≤ 500。

支持 Tab、Enter / 空格操作；焦点在计数带时可用 ← / → 单步。减少动态效果偏好下不启用自动播放。

把 16 张牌的两种方案还原出来

层宽：5 → 1

底层 14 张，上层 2 张。总和 14 + 2 = 16；1 ≤ 5 − 1，承托充分。

层宽：4 → 2

底层 11 张，上层 5 张。总和 11 + 5 = 16；2 ≤ 4 − 1，承托充分。

不能使用 8 + 8：两层各有 3 个三角形，但下层只有 2 张水平牌。倒序更新恰好排除了这种重复层宽。

正确性

一一对应：合法纸牌屋的层宽严格递减，得到一组互不相同的层成本；反过来，每组不同层成本按降序排列后，上层宽度至多是下层宽度减一，且左对齐使布局唯一。两种转换互为逆操作。

状态归纳：未处理成本时只有空集能组成 0。处理 c 时，组成 s 的集合分为不含 c 与含 c 两类：前者已有 dp[s] 种，后者删除 c 后对应旧状态 dp[s-c] 种，两类互斥且穷尽。倒序读取保证来源为旧状态。因此最终 dp[n] 正好数出所有合法纸牌屋。

边界与复杂度

  • n = 1 无法形成三角形；n = 2 恰好一种；n = 4 不能复用成本 2。
  • 不要求每次层宽恰好减少 1，跨过某些宽度也合法。
  • 共有 m = ⌊(n + 1) / 3⌋ 种候选成本，时间 O(nm) = O(n²)，空间 O(n)。层数是 O(√n) 并不意味着候选宽度只有 O(√n)。
  • 题目返回整数，不取模；四语言使用对应整数表示（JavaScript 使用 Number）。

替代方案

记忆化搜索 F(i, r)：对第 i 种成本选择跳过，或在 r 足够时选择一次并进入 i + 1。r = 0 返回 1，成本耗尽且 r > 0 返回 0。时间与空间均为 O(n²)，递归栈 O(n)，相比一维背包更直观但更占空间。

常见错误

  • 漏算水平连接牌，把层成本写成 2k。
  • 把背包容量正序遍历，错误允许同层宽重复出现。
  • 按所有层排列重复计数，或只枚举宽度连续的完整金字塔。
  • 把“最多 n 张”当成“恰好 n 张”，返回所有 dp 项之和。
  • 忘记 dp[0] = 1，所有转移都会保持为 0。

面试追问

如何输出一个方案？保留二维可达表和选取记录，从 (m, n) 回溯，再按成本降序还原层宽。要求恰好 h 层呢？增加计数维度 dp[s][t]，同时倒序更新容量与层数。允许水平位置自由选择呢？集合与布局的一一对应被打破，需要按相邻层的可用位置数计算摆放组合，不能直接沿用本题答案。

四种语言，同一个状态转移

采用官方方法名 houseOfCards；以下代码仅生成，尚未执行或提交。

Java

class Solution {
    public int houseOfCards(int n) {
        int[] dp = new int[n + 1];
        dp[0] = 1;
        for (int c = 2; c <= n; c += 3) {
            for (int s = n; s >= c; s--) {
                dp[s] += dp[s - c];
            }
        }
        return dp[n];
    }
}

Python

class Solution:
    def houseOfCards(self, n: int) -> int:
        dp = [0] * (n + 1)
        dp[0] = 1
        for c in range(2, n + 1, 3):
            for s in range(n, c - 1, -1):
                dp[s] += dp[s - c]
        return dp[n]
