k 镜像数字的和

Sum of k-Mirror Numbers · 数学 / 枚举

一个整数，两种进制，同样的对称。

先理解“镜像”的定义，再思考如何找出最小的 n 个。算法与交互实验都在页面底部，按需展开。

题目

如果一个正整数在十进制与 k 进制下的标准表示都左右对称，就称它为 k 镜像数字。两种表示都不能添加前导零。给定进制 k 和数量 n，返回最小的 n 个不同 k 镜像数字的总和。

9 是 2 镜像数字

9₁₀ = 1001₂，两边都为回文。

4 不是 2 镜像数字

4₁₀ = 100₂，二进制表示不对称。

参数：k: integer，n: integer；返回整数和（long）。

约束：2 ≤ k ≤ 9；1 ≤ n ≤ 30。

题解 · 先构造，再筛选

核心洞察

逐个检查所有整数浪费了大量工作：大多数数连十进制回文都不是。一个回文由它的前半部分唯一决定，因此先按递增顺序生成十进制回文，再检查 k 进制表示。

half = 12 时，奇数长度将 1 反转接到后面，得到 121；偶数长度将整个 12 反转接到后面，得到 1221。奇数长度的中心位只能出现一次。

完整过程

  1. 从一位前缀开始。前缀位数为 d 时，范围是 [10^(d−1), 10^d)。
  2. 先递增枚举全部前缀，构造长度 2d−1 的回文；再重新枚举全部前缀，构造长度 2d 的回文。
  3. 对每个候选反复除以 k 取余，得到各位，用首尾双指针比较。余数顺序反向保存也不影响回文判定。
  4. 匹配则累加，并减少剩余数量。收集到 n 个立即返回；否则增加前缀位数。

正确性

合法性：前缀从非零位开始，镜像构造保证十进制回文且没有前导零。只有 k 进制各对称位相等的候选才被收录，因此收录的每个数都满足定义。

完备性：任意正十进制回文的前 ⌈L/2⌉ 位都唯一决定整个数。算法覆盖所有前缀与两种长度，因此不会遗漏或重复任何可能的答案。

最小性：先短位数再长位数；同一长度内，前缀递增使整个回文递增。筛选不改变顺序。循环过程中，已收录集合始终是已枚举范围内所有合法数；第 n 次收录后，恰好得到最小的 n 个，返回其和正确。

边界与数值类型

  • 0 不参与枚举；一位正数本身是十进制回文，奇数构造的 tail 可以为 0。
  • n = 1 时第一个合法数就是 1；k = 2 或 9 使用同一个转换逻辑。
  • 答案可能超过 32 位整数：Java 用 long，C++ 用 long long；Python 使用整数。
  • JavaScript 内部使用 BigInt，末尾按官方 number 签名返回并检查安全整数范围。不可混用 BigInt 与 Number 运算，也不要用位运算做大整数除法。

复杂度

设第 n 个答案为 M，实际枚举了 P 个十进制回文。每个候选构造花 O(log₁₀ M)，转换与判定花 O(logₖ M)，总时间为 O(P(log₁₀ M + logₖ M))；P = O(√M)，可写作 O(√M · logₖ M)。保存进制位串的额外空间为 O(logₖ M)，无需保存全部答案。M = 1 时按常数处理。

这是固定宽度整数的常用分析。Python / BigInt 的算术成本还取决于整数位长；n 很小不代表枚举时间为 O(n)。

替代方案

逐个整数检查两种回文最易理解，但时间达到 O(M · logₖ M)。也可构造 k 进制回文，再检查十进制；同样必须按长度与前缀排序，构造时的乘数改为 k。预存每个 k 的前 30 项可用于重复查询，但需要可信的生成与验证过程。

常见错误

  • 对每个前缀交替生成奇数、偶数回文：例如 1、11、2、22，并非递增序列，会提前选中较大的数。
  • 奇数回文复制整个前缀，重复了中心位。
  • 只检查十进制回文，或在 k 进制表示前补零。
  • 找到答案后仍继续当前批次，收录数量超过 n。
  • 用 32 位求和，或把 JavaScript 的 x / 10 当作整数除法。

面试追问

为什么不能直接反转整个数比较？可行，但反转过程也有溢出风险；位数组或字符串更直观。

如何处理多个相同 k 的查询？一次生成最大所需数量并构造前缀和，每次读取第 n 项即可。

如何证明前缀递增意味着结果递增？同长度回文比较时，首次不同位必在前半部分，后半部分无法改变大小关系。

Java

class Solution {
    private boolean palindrome(long x, int k) {
        String s = Long.toString(x, k);
        int l = 0, r = s.length() - 1;
        while (l < r) {
            if (s.charAt(l++) != s.charAt(r--)) return false;
        }
        return true;
    }

    public long kMirror(int k, int n) {
        long sum = 0;
        for (long start = 1; ; start *= 10) {
            for (int odd = 1; odd >= 0; odd--) {
                for (long half = start; half < start * 10; half++) {
                    long x = half, tail = odd == 1 ? half / 10 : half;
                    while (tail > 0) {
                        x = x * 10 + tail % 10;
                        tail /= 10;
                    }
                    if (palindrome(x, k)) {
                        sum += x;
                        if (--n == 0) return sum;
                    }
                }
            }
        }
    }
}

    let sum = 0n;
    const palindrome = x => {
        const s = x.toString(k);
        let l = 0, r = s.length - 1;
        while (l < r) {
            if (s[l++] !== s[r--]) return false;
        }
        return true;

    for (let start = 1n; ; start *= 10n) {

Python

class Solution:
    def kMirror(self, k: int, n: int) -> int:
        def palindrome(x):
            digits = []
            while x:
                digits.append(x % k)
                x //= k
            return digits == digits[::-1]

        total, start = 0, 1
        while True:
            for odd in (True, False):
                for half in range(start, start * 10):
                    x = half
                    tail = half // 10 if odd else half
                    while tail:
                        x = x * 10 + tail % 10
                        tail //= 10
                    if palindrome(x):
                        total += x
                        n -= 1
                        if n == 0:
                            return total
            start *= 10

#include <vector>
using namespace std;

class Solution {
    bool palindrome(long long x, int k) {
        vector<int> digits;
        while (x > 0) {
            digits.push_back(x % k);
            x /= k;
        }
        int l = 0, r = static_cast<int>(digits.size()) - 1;
        while (l < r) {
            if (digits[l++] != digits[r--]) return false;
        }
        return true;
    }
public:
    long long kMirror(int k, int n) {
        long long sum = 0;
        for (long long start = 1; ; start *= 10) {
            for (int odd = 1; odd >= 0; --odd) {
                for (long long half = start; half < start * 10; ++half) {
                    long long x = half, tail = odd ? half / 10 : half;
                    while (tail > 0) {
                        x = x * 10 + tail % 10;
                        tail /= 10;
                    }
                    if (palindrome(x, k)) {
                        sum += x;
                        if (--n == 0) return sum;
                    }
                }
            }
        }
    }
};
