装饰树

把每一条原始父子边“拆开”：在中间放入值为 -1 的灯饰节点。关键是先保存旧孩子，再改写当前指针。

中等O(n) 时间O(h) 递归栈

题意

给定二叉树 root。根节点值保持不变；每个原始父子关系之间插入一个值为 -1 的节点。左边插入节点仍作为左孩子，右边插入节点仍作为右孩子。

示例

root = [7, 5, 6]

result = [7, -1, -1, 5, null, null, 6]

树最多 105 个节点；每条原始边只处理一次。

快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

一条边的改写规则

  1. 1.保存 left 与 right。
  2. 2.先递归处理保存下来的原孩子。
  3. 3.若左孩子存在：root.left = new TreeNode(-1, left, null)。
  4. 4.右侧完全对称。

题解：后序式 DFS，先存后改

核心洞察

不能直接把 root.left 改为灯饰后再递归，否则递归会走进新建节点并反复插入。先把旧引用存入局部变量，递归旧子树，最后把灯饰节点挂回当前节点。

完整过程与边界

空节点直接返回；叶子没有边，保持不变。每个原始节点访问一次，每条原始边只新建一个节点。深树可能使递归栈达到 O(h)。

替代方案与面试追问

也可迭代 DFS：栈中仅压入原孩子，再插入灯饰，避免语言递归深度限制。追问：若要不修改原树，需要复制原节点并在复制过程中连接灯饰，空间变为 O(n)。

常见错误

  • 改指针后才保存孩子，导致原子树丢失。
  • 递归进入新建的 -1 节点，造成无限扩张。
  • 右孩子误挂到灯饰节点的左侧。

复杂度

时间 O(n)；除递归栈外，新增 n − 1 个灯饰节点，递归辅助空间 O(h)。
