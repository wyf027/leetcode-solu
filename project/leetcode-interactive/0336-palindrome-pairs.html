Problem

题目要求

给定一个由互不相同字符串组成的 0 索引数组 words。若下标对 (i, j) 满足 i ≠ j，并且拼接串 words[i] + words[j] 是回文串，那么它就是一个回文对。返回所有这样的下标对，答案顺序不限。

目标复杂度：设所有字符串的字符总数为 S，答案对数为 P，目标是做到 O(S + P)；输出答案本身至少需要 O(P)。

函数签名与约束

palindromePairs(words: string[]) -> list<list<integer>>
  • 1 <= words.length <= 5000
  • 0 <= words[i].length <= 300
  • words[i] 只包含小写英文字母，数组中的字符串互不相同。
  • 空字符串合法；它可以与任意非空回文串组成两个方向的回文对。

反向字典树 + Manacher 边界标记

难点不是判断一个给定字符串是否回文，而是在线性总字符量内找到所有可能的另一半。把所有单词反向插入字典树，就能把“寻找反串”变成沿当前单词向前走；Manacher 则让每个剩余片段是否回文都能在 O(1) 时间读取。

核心洞察

若 A + B 是回文，沿 A 与 reverse(B) 同步匹配时，较短一方匹配完后，较长一方剩余的那一段必须自身为回文。

节点信息

wordIndex 记录在此结束的单词；palList 记录“走到此处后，原单词未插入前缀是回文”的所有下标。

线性边界

对每个字符串运行 Manacher，标记所有回文前缀终点 prefixPal 与回文后缀起点 suffixPal，总预处理为 O(S)。

完整过程

  1. 预处理。 对每个单词计算奇数、偶数回文半径。回文区间左端为 0 时标记其右端为回文前缀；右端为 n-1 时标记其左端为回文后缀。
  2. 反向插入。 从单词末尾向开头走。下降到下一字符之前，如果尚未插入的前缀是回文，就把下标加入当前节点的 palList；终点同时写入 wordIndex 和 palList。
  3. 树中单词先结束。 正向查询 A 时，若当前节点是另一单词 B 的终点，且 A 尚未扫描的后缀为回文，就得到 (A,B)。
  4. 当前单词先结束。 若 A 的全部字符都能沿树走完，则当前节点 palList 中的每个不同下标 B 都能接在 A 后面。
  5. 排除自身。 两处分支都检查下标不同。输入字符串互不相同，因此不会为同一有序对产生重复答案。

正确性证明

充分性：查询产生答案时，已匹配部分按构造分别是另一单词的反向字符；未匹配部分又被边界标记证明为回文，因此整体拼接左右对称。

必要性：设 A+B 为回文。比较 A 与 reverse(B)：若 B 先结束，A 的剩余后缀必为回文，命中终点分支；若 A 先结束，B 的剩余前缀必为回文，其下标必在当前节点的 palList。两种情况覆盖全部可能，故不漏解。

边界处理

  • 空串：根节点是它的终点；所有回文单词在根的 palList 中。
  • 长度 1：本身同时是回文前缀与后缀。
  • 同一单词：即使自身回文也不能与自身配对。
  • 有序对：(i,j) 与 (j,i) 是不同答案，不能合并。

复杂度

阶段时间额外空间说明
Manacher 标记O(S)O(S)每字符只参与常数次半径处理。
建树O(S)O(S)节点和全部 palList 条目均为线性。
查询O(S + P)O(P)除输出外，每个输入字符沿树走一次。
总计O(S + P)O(S + P)不计返回值时辅助空间为 O(S)。

class Solution {
    private static class Node {
        Node[] next = new Node[26];
        int wordIndex = -1;
        List<Integer> palList = new ArrayList<>();
    }

    public List<List<Integer>> palindromePairs(String[] words) {
        int n = words.length;
        boolean[][] prefix = new boolean[n][];
        boolean[][] suffix = new boolean[n][];
        for (int i = 0; i < n; i++) {
            boolean[][] b = palindromeBounds(words[i]);
            prefix[i] = b[0];
            suffix[i] = b[1];
        }

        Node root = new Node();
        for (int index = 0; index < n; index++) {
            String word = words[index];
            Node node = root;
            for (int i = word.length() - 1; i >= 0; i--) {
                if (prefix[index][i]) node.palList.add(index);
                int c = word.charAt(i) - 'a';
                if (node.next[c] == null) node.next[c] = new Node();
                node = node.next[c];
            }
            node.wordIndex = index;
            node.palList.add(index);
        }

        List<List<Integer>> answer = new ArrayList<>();
        for (int index = 0; index < n; index++) {
            String word = words[index];
            Node node = root;
            int i = 0;
            for (; i < word.length(); i++) {
                if (node.wordIndex >= 0 && node.wordIndex != index
                        && suffix[index][i]) {
                    answer.add(Arrays.asList(index, node.wordIndex));
                }
                node = node.next[word.charAt(i) - 'a'];
                if (node == null) break;
            }
            if (node != null && i == word.length()) {
                for (int other : node.palList) {
                    if (other != index) answer.add(Arrays.asList(index, other));
                }
            }
        }
        return answer;
    }

    private boolean[][] palindromeBounds(String s) {
        int n = s.length();
        boolean[] prefix = new boolean[n], suffix = new boolean[n];
        int[] odd = new int[n];
        int left = 0, right = -1;
        for (int i = 0; i < n; i++) {
            int k = i > right ? 1
                    : Math.min(odd[left + right - i], right - i + 1);
            while (i - k >= 0 && i + k < n
                    && s.charAt(i - k) == s.charAt(i + k)) k++;
            odd[i] = k;
            int lo = i - k + 1, hi = i + k - 1;
            if (lo == 0) prefix[hi] = true;
            if (hi == n - 1) suffix[lo] = true;
            if (hi > right) {
                left = lo;
                right = hi;
            }
        }

        int[] even = new int[n];
        left = 0;
        right = -1;
        for (int i = 0; i < n; i++) {
            int k = i > right ? 0
                    : Math.min(even[left + right - i + 1], right - i + 1);
            while (i - k - 1 >= 0 && i + k < n
                    && s.charAt(i - k - 1) == s.charAt(i + k)) k++;
            even[i] = k;
            if (k > 0) {
                int lo = i - k, hi = i + k - 1;
                if (lo == 0) prefix[hi] = true;
                if (hi == n - 1) suffix[lo] = true;
            }
            if (i + k - 1 > right) {
                left = i - k;
                right = i + k - 1;
            }
        }
        return new boolean[][] {prefix, suffix};
    }
}

var palindromePairs = function(words) {
    class TrieNode {
        constructor() {
            this.next = new Map();
            this.wordIndex = -1;
            this.palList = [];
        }
    }

    const bounds = words.map(palindromeBounds);
    const root = new TrieNode();

    for (let index = 0; index < words.length; index++) {
        const word = words[index];
        let node = root;
        for (let i = word.length - 1; i >= 0; i--) {
            if (bounds[index].prefix[i]) node.palList.push(index);
            const ch = word[i];
            if (!node.next.has(ch)) node.next.set(ch, new TrieNode());
            node = node.next.get(ch);
        }
        node.wordIndex = index;
        node.palList.push(index);
    }

    const answer = [];
    for (let index = 0; index < words.length; index++) {
        const word = words[index];
        let node = root;
        let i = 0;
        for (; i < word.length; i++) {
            if (node.wordIndex >= 0 && node.wordIndex !== index
                    && bounds[index].suffix[i]) {
                answer.push([index, node.wordIndex]);
            }
            node = node.next.get(word[i]);
            if (node === undefined) break;
        }
        if (node !== undefined && i === word.length) {
            for (const other of node.palList) {
                if (other !== index) answer.push([index, other]);
            }
        }
    }
    return answer;
};

function palindromeBounds(s) {
    const n = s.length;
    const prefix = Array(n).fill(false);
    const suffix = Array(n).fill(false);
    const odd = Array(n).fill(0);
    let left = 0, right = -1;

    for (let i = 0; i < n; i++) {
        let k = i > right ? 1
                : Math.min(odd[left + right - i], right - i + 1);
        while (i - k >= 0 && i + k < n
                && s[i - k] === s[i + k]) k++;
        odd[i] = k;
        const lo = i - k + 1, hi = i + k - 1;
        if (lo === 0) prefix[hi] = true;
        if (hi === n - 1) suffix[lo] = true;
        if (hi > right) {
            left = lo;
            right = hi;
        }
    }

    const even = Array(n).fill(0);
    left = 0;
    right = -1;
    for (let i = 0; i < n; i++) {
        let k = i > right ? 0
                : Math.min(even[left + right - i + 1], right - i + 1);
        while (i - k - 1 >= 0 && i + k < n
                && s[i - k - 1] === s[i + k]) k++;
        even[i] = k;
        if (k > 0) {
            const lo = i - k, hi = i + k - 1;
            if (lo === 0) prefix[hi] = true;
            if (hi === n - 1) suffix[lo] = true;
        }
        if (i + k - 1 > right) {
            left = i - k;
            right = i + k - 1;
        }
    }
    return {prefix, suffix};
}
from typing import List


class TrieNode:
    __slots__ = ("children", "word_index", "pal_list")

    def __init__(self):
        self.children = {}
        self.word_index = -1
        self.pal_list = []


class Solution:
    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        bounds = [self._palindrome_bounds(word) for word in words]
        root = TrieNode()

        for index, word in enumerate(words):
            node = root
            prefix = bounds[index][0]
            for i in range(len(word) - 1, -1, -1):
                if prefix[i]:
                    node.pal_list.append(index)
                node = node.children.setdefault(word[i], TrieNode())
            node.word_index = index
            node.pal_list.append(index)

        answer = []
        for index, word in enumerate(words):
            node = root
            suffix = bounds[index][1]
            i = 0
            while i < len(word):
                if (node.word_index >= 0 and node.word_index != index
                        and suffix[i]):
                    answer.append([index, node.word_index])
                node = node.children.get(word[i])
                if node is None:
                    break
                i += 1

            if node is not None and i == len(word):
                for other in node.pal_list:
                    if other != index:
                        answer.append([index, other])
        return answer

    def _palindrome_bounds(self, s: str):
        n = len(s)
        prefix = [False] * n
        suffix = [False] * n

        odd = [0] * n
        left, right = 0, -1
        for i in range(n):
            k = 1 if i > right else min(
                odd[left + right - i], right - i + 1
            )
            while i - k >= 0 and i + k < n and s[i - k] == s[i + k]:
                k += 1
            odd[i] = k
            lo, hi = i - k + 1, i + k - 1
            if lo == 0:
                prefix[hi] = True
            if hi == n - 1:
                suffix[lo] = True
            if hi > right:
                left, right = lo, hi

        even = [0] * n
        left, right = 0, -1
        for i in range(n):
            k = 0 if i > right else min(
                even[left + right - i + 1], right - i + 1
            )
            while (i - k - 1 >= 0 and i + k < n
                   and s[i - k - 1] == s[i + k]):
                k += 1
            even[i] = k
            if k > 0:
                lo, hi = i - k, i + k - 1
                if lo == 0:
                    prefix[hi] = True
                if hi == n - 1:
                    suffix[lo] = True
            if i + k - 1 > right:
                left, right = i - k, i + k - 1

        return prefix, suffix
class Solution {
    struct Node {
        array<unique_ptr<Node>, 26> next{};
        int wordIndex = -1;
        vector<int> palList;
    };

    pair<vector<char>, vector<char>> palindromeBounds(const string& s) {
        int n = static_cast<int>(s.size());
        vector<char> prefix(n, false), suffix(n, false);
        vector<int> odd(n);
        int left = 0, right = -1;

        for (int i = 0; i < n; ++i) {
            int k = i > right ? 1
                    : min(odd[left + right - i], right - i + 1);
            while (i - k >= 0 && i + k < n
                    && s[i - k] == s[i + k]) ++k;
            odd[i] = k;
            int lo = i - k + 1, hi = i + k - 1;
            if (lo == 0) prefix[hi] = true;
            if (hi == n - 1) suffix[lo] = true;
            if (hi > right) {
                left = lo;
                right = hi;
            }
        }

        vector<int> even(n);
        left = 0;
        right = -1;
        for (int i = 0; i < n; ++i) {
            int k = i > right ? 0
                    : min(even[left + right - i + 1], right - i + 1);
            while (i - k - 1 >= 0 && i + k < n
                    && s[i - k - 1] == s[i + k]) ++k;
            even[i] = k;
            if (k > 0) {
                int lo = i - k, hi = i + k - 1;
                if (lo == 0) prefix[hi] = true;
                if (hi == n - 1) suffix[lo] = true;
            }
            if (i + k - 1 > right) {
                left = i - k;
                right = i + k - 1;
            }
        }
        return {move(prefix), move(suffix)};
    }

public:
    vector<vector<int>> palindromePairs(vector<string>& words) {
        int n = static_cast<int>(words.size());
        vector<vector<char>> prefix(n), suffix(n);
        for (int i = 0; i < n; ++i) {
            auto bounds = palindromeBounds(words[i]);
            prefix[i] = move(bounds.first);
            suffix[i] = move(bounds.second);
        }

        Node root;
        for (int index = 0; index < n; ++index) {
            Node* node = &root;
            for (int i = static_cast<int>(words[index].size()) - 1;
                    i >= 0; --i) {
                if (prefix[index][i]) node->palList.push_back(index);
                int c = words[index][i] - 'a';
                if (!node->next[c]) {
                    node->next[c] = make_unique<Node>();
                }
                node = node->next[c].get();
            }
            node->wordIndex = index;
            node->palList.push_back(index);
        }

        vector<vector<int>> answer;
        for (int index = 0; index < n; ++index) {
            Node* node = &root;
            int i = 0;
            for (; i < static_cast<int>(words[index].size()); ++i) {
                if (node->wordIndex >= 0 && node->wordIndex != index
                        && suffix[index][i]) {
                    answer.push_back({index, node->wordIndex});
                }
                int c = words[index][i] - 'a';
                if (!node->next[c]) {
                    node = nullptr;
                    break;
                }
                node = node->next[c].get();
            }
            if (node != nullptr
                    && i == static_cast<int>(words[index].size())) {
                for (int other : node->palList) {
                    if (other != index) answer.push_back({index, other});
                }
            }
        }
        return answer;
    }
};

替代方案

方案特点取舍
枚举两两拼接直接检查每个有序对O(n²k)，会超时。
哈希表 + 枚举切分代码较短，按回文前后缀查反串切片、反转、重新判断回文会退化到 O(Sk)；滚动哈希还要处理碰撞。
反向字典树 + Manacher确定性地达到 O(S+P)实现较长，节点附加信息必须准确。

常见错误

  • 只查完整反串，漏掉 "lls" + "sssll" 这种长度不同的情况。
  • 把回文前缀与回文后缀用反，导致配对方向颠倒。
  • 未把终点加入 palList，漏掉长度相等的完整反串。
  • 忘记排除 i == j，让回文单词与自身配对。
  • 忽略偶数长度回文，Manacher 只计算了奇数半径。
  • 宣称线性，却在每个切分点重新切片或扫描判断回文。

面试追问

为什么复杂度要写 O(S + P)，不能只写 O(S)？

当答案很多时，创建并返回 P 个下标对就需要 Ω(P) 时间和返回空间；输出敏感复杂度更准确。

如果 words 中允许重复字符串怎么办？

节点的 wordIndex 要改成终点下标列表；查询终点分支遍历全部不同下标，并继续按原数组位置区分。

如果字符集不再只是 26 个小写字母？

Java/C++ 节点可将定长数组换成映射；JavaScript/Python 已使用映射。Unicode 还要明确按码点还是 UTF-16 代码单元定义“字符”。

为什么 palList 的总大小仍是 O(S)？

每个单词在沿反向路径的每个节点至多加入一次，加上终点一次，因此贡献不超过长度加一；全部求和仍为线性。
