Count Pairs of Equal Substrings With Minimum Difference

两个字符串，四个端点。先分清“距离”的定义，再寻找所有并列最优的组合。

阅读题目 ↓

01 / 题目与输入

给定下标从 0 开始的字符串 firstString 与 secondString，统计四元组 (i, j, a, b)：两段闭区间子串 firstString[i..j] 和 secondString[a..b] 必须相同，且 j - a 必须达到全部合法组合中的最小值。返回达到这个最小值的四元组数量；没有相等子串时返回 0。

  • 0 ≤ i ≤ j < firstString.length，0 ≤ a ≤ b < secondString.length。
  • 两串长度均为 1 … 2 × 10⁵，字符仅为小写英文字母。
  • 这里的差值可以为负数，不取绝对值；返回的是个数，不是差值。

countQuadruples(firstString: string, secondString: string) → integer

官方示例 1

firstString = "abcd"
secondString = "bccda"
输出：1

唯一最优四元组为 (0, 0, 4, 4)，两段均为 “a”，差值为 −4。

官方示例 2

firstString = "ab"
secondString = "cd"
输出：0

两串没有共同字符，因此没有合法组合。

核心洞察与完整过程

  1. 设长度 L > 1。只留下两段的首字符，得到 (i, i, a, a)。新差值 i − a 比原来的 j − a 小 L − 1，因此长子串不可能全局最优。
  2. 长度为 1 时 i = j、a = b。固定字母 c，记第一串最早位置 F[c]，第二串最晚位置 R[c]，它的最佳差值就是 F[c] − R[c]。
  3. 扫描第一串，只在该字母尚未记录时写入位置；扫描第二串，每次覆盖位置。缺失标记为 −1。
  4. 枚举 26 个字母，跳过任一串缺失者。遇到更小差值：更新 best，计数重置为 1；遇到相等差值：计数加 1。最终返回计数。

正确性

缩短论证排除了所有长度大于 1 的最优解。对固定字母，任意匹配位置 j、a 满足 j ≥ F[c] 且 a ≤ R[c]，所以 j − a ≥ F[c] − R[c]。等号成立需要 j = F[c] 且 a = R[c]，故每个字母至多贡献一个最优四元组。枚举所有共同字母覆盖了所有可能最优解；更小值重置计数、相等值累加恰好保留已处理候选中的全部最优者。

边界与复杂度

无共同字母时计数保留 0；单字母相同得到 1。重复字母只取两端，不按出现次数相乘。多个字母可能并列，因此答案范围为 0 … 26。差值范围为 −(m−1) … n−1，32 位有符号整数足够。

时间 O(n + m + 26)，额外空间 O(26)，固定小写字母表下即 O(1)。下面 C++ 签名按值接收字符串；若计入参数复制，调用时还可能占用 O(n + m) 空间。

替代方案

也可只记录第二串每个字母的最后位置，再逐字符扫描第一串并比较差值，仍为 O(n+m) 时间。枚举所有单字符匹配需 O(nm)，可用于小输入推导但不适合上限。无需构造全部子串、动态规划或后缀结构。

常见错误

  • 写成 |j−a|：会改变优化目标；示例 1 的最优差值是 −4。
  • 记录第一串最后位置、第二串最早位置：方向恰好相反。
  • 更小值只更新 best，不把计数重置为 1：会留下过时候选。
  • 把缺失下标 −1 当成真实位置，或把同一字母的出现次数相乘。

面试追问

若必须长度至少 K？任何长于 K 的匹配可截为 K；接着要按长度 K 的内容分组，再选择最早与最晚起点，需高效且可靠的子串比较。若改为绝对差值？两端选择不再成立，应研究相同字符的位置序列中的最近位置。若字符集扩大？用映射替代 26 槽数组，空间随不同字符数增长。

Java

import java.util.Arrays;

class Solution {
    public int countQuadruples(String firstString, String secondString) {
        int[] first = new int[26], last = new int[26];
        Arrays.fill(first, -1);
        Arrays.fill(last, -1);
        for (int i = 0; i < firstString.length(); i++) {
            int c = firstString.charAt(i) - 'a';
            if (first[c] == -1) first[c] = i;
        }
        for (int a = 0; a < secondString.length(); a++)
            last[secondString.charAt(a) - 'a'] = a;
        int best = Integer.MAX_VALUE, ans = 0;
        for (int c = 0; c < 26; c++) {
            if (first[c] == -1 || last[c] == -1) continue;
            int d = first[c] - last[c];
            if (d < best) { best = d; ans = 1; }
            else if (d == best) ans++;
        }
        return ans;
    }
}

Python

class Solution:
    def countQuadruples(self, firstString: str, secondString: str) -> int:
        first, last = [-1] * 26, [-1] * 26
        for i, ch in enumerate(firstString):
            c = ord(ch) - ord('a')
            if first[c] == -1:
                first[c] = i
        for a, ch in enumerate(secondString):
            last[ord(ch) - ord('a')] = a
        best, ans = float('inf'), 0
        for c in range(26):
            if first[c] == -1 or last[c] == -1:
                continue
            d = first[c] - last[c]
            if d < best:
                best, ans = d, 1
            elif d == best:
                ans += 1
        return ans

};
