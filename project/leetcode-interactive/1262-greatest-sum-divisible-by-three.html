可被三整除的
最大和

Greatest Sum Divisible by Three

从数组中选择任意一些元素，使它们的总和能被 3 整除；返回所有可行选择中的最大总和。允许一个元素都不选，因此答案至少为 0。

难度：中等非付费题函数：maxSumDivThree(nums)
阅读题目 ↓
Problem

题目描述

你可以自由决定每个数字是否加入总和，但最终总和必须是 3 的倍数。

任务

给定一个整数数组 nums，返回从中选取若干元素所能得到的、可被 3 整除的最大元素和。

maxSumDivThree(nums: integer[]) → integer

空选择的和为 0，所以当没有正数选择满足条件时返回 0。

约束

  • 1 ≤ nums.length ≤ 4 × 10⁴
  • 1 ≤ nums[i] ≤ 10⁴
Examples

官方示例

每个示例都保留完整参数形式。

EXAMPLE 01
输入nums = [3,6,5,1,8]
输出18

EXAMPLE 02

EXAMPLE 03

输出12

Deep Dive

动态规划：只记三种余数

完整总和有很多，但对后续决策而言，当前总和除以 3 的余数只有三种。

核心洞察

令 dp[r] 表示已经处理的元素中，模 3 余数为 r 的最大可达总和。初始化只有空集可达：dp = [0, -∞, -∞]。

next[(r + x) % 3] = max(next[(r + x) % 3], dp[r] + x)

每轮先复制 dp 到 next，代表不选 x；随后从旧状态转移，代表选择 x。必须从快照更新，避免同一数字在一轮中被重复使用。

完整过程

  1. 建立三个状态，分别保存余数 0、1、2 的最大和。
  2. 逐个扫描 nums，复制当前状态。
  3. 对每个可达旧状态，尝试加入当前数字。
  4. 用更大值更新对应的新余数槽位。
  5. 扫描结束后，dp[0] 就是答案。

正确性证明

不变式

处理前 i 个元素后，dp[r] 等于这些元素所有子集里余数为 r 的最大总和。

保持

任一使用前 i+1 个元素的子集，要么不含新元素，要么由一个旧子集加上新元素得到；两类候选都被转移枚举并取最大。

终止

所有元素处理完后，不变式覆盖全部子集；余数 0 槽位因此是所有可被 3 整除子集和的最大值。

边界与复杂度

  • 只有空集满足时，dp[0] = 0。
  • 数字全为正数，但仍需保留“跳过当前数字”的分支。
  • 不可达状态不能写成 0，否则会伪造余数 1 或 2 的候选。
  • 时间复杂度：O(n × 3) = O(n)。
  • 额外空间复杂度：O(3) = O(1)。

替代方案

也可先求数组总和，再按总和余数删除代价最小的一个或两个元素；需要维护余数 1、2 的最小元素。它同样是线性的，但分类边界更多，三状态 DP 更容易推广到“被 k 整除”。

四语言完整实现

Java · 官方签名
class Solution {
    public int maxSumDivThree(int[] nums) {
        final int NEG = Integer.MIN_VALUE / 2;
        int[] dp = {0, NEG, NEG};
        for (int x : nums) {
            int[] next = dp.clone();
            for (int r = 0; r < 3; r++) {
                if (dp[r] == NEG) continue;
                int candidate = dp[r] + x;
                int nr = candidate % 3;
                next[nr] = Math.max(next[nr], candidate);
            }
            dp = next;
        }
        return dp[0];
    }
}

        dp = next;
    }
    return dp[0];
};
Python 3 · 官方签名
from typing import List

class Solution:
    def maxSumDivThree(self, nums: List[int]) -> int:
        dp = [0, float("-inf"), float("-inf")]
        for x in nums:
            nxt = dp[:]
            for value in dp:
                if value == float("-inf"):
                    continue
                candidate = value + x
                remainder = candidate % 3
                nxt[remainder] = max(nxt[remainder], candidate)
            dp = nxt
        return dp[0]
C++ · 官方签名
class Solution {
public:
    int maxSumDivThree(vector<int>& nums) {
        const int NEG = numeric_limits<int>::min() / 2;
        array<int, 3> dp{0, NEG, NEG};
        for (int x : nums) {
            auto next = dp;
            for (int r = 0; r < 3; ++r) {
                if (dp[r] == NEG) continue;
                int candidate = dp[r] + x;
                int nr = candidate % 3;
                next[nr] = max(next[nr], candidate);
            }
            dp = next;
        }
        return dp[0];
    }
};

常见错误

  • 原地更新 dp，导致同一个数字在本轮被使用多次。
  • 把三个状态都初始化成 0，混淆“不可达”与“和为 0”。
  • 只记录余数是否可达，没有保留每个余数的最大和。
  • 返回全部数字之和，而没有读取余数 0 的状态。

面试追问

  • 若要求总和被任意正整数 k 整除，如何修改？使用长度为 k 的状态数组，复杂度为 O(nk)。
  • 若数组允许负数呢？转移不变，但不可达哨兵必须安全，且空集是否允许会影响初始化。
  • 能否还原所选元素？为每轮、每个余数记录前驱状态与是否选择当前元素。
