连接后等于目标字符串的字符串对

Number of Pairs of Strings With Concatenation Equal to Target

MEDIUM 259 / 300 · 独立学习页

题目

给定数字字符串数组 nums 和数字字符串 target，统计满足 i ≠ j 且 nums[i] + nums[j] === target 的下标对 (i, j) 数量。这里的加号表示按顺序连接字符串。

两个相同字符串可以来自不同下标；同一个下标不能使用两次。顺序不同的下标对分别计数。

先阅读示例并思考。完整算法与代码默认折叠在页面底部。

官方示例

示例 1

nums = ["777", "7", "77", "77"], target = "7777"
输出：4

有效下标对：(0,1)、(1,0)、(2,3)、(3,2)。

示例 2

nums = ["123", "4", "12", "34"], target = "1234"
输出：2

有效下标对：(0,1)、(2,3)。

示例 3

nums = ["1", "1", "1"], target = "11"
输出：6

有效下标对：(0,1)、(1,0)、(0,2)、(2,0)、(1,2)、(2,1)。

约束

  • 2 ≤ nums.length ≤ 100
  • 1 ≤ nums[i].length ≤ 100
  • 2 ≤ target.length ≤ 100
  • nums[i] 和 target 只包含数字，且没有前导 0。

题解 · 枚举所有有序对
核心洞察
数组最多只有 100 个元素，至多存在 9,900 个合法候选下标对。直接枚举有序对，连接并比较即可；不需要将字符串转为数字。
完整过程
  1. 初始化答案为 0。
  2. 外层遍历 i，内层遍历全部 j，包含小于 i 的 j。
  3. 若 i 等于 j 则跳过，否则比较 nums[i] + nums[j] 与 target。
  4. 相等就累加 1，全部遍历后返回答案。
示例 1 的第 0 行命中 (0,1)，第 1 行命中 (1,0)，第 2、3 行分别命中 (2,3)、(3,2)，总计 4。矩阵与双重循环一一对应。
正确性
外层与内层循环恰好访问每个有序下标对一次。跳过对角线后，留下的恰好是所有 i ≠ j 的候选。只有连接结果等于 target 时才累加，所以每个被计数的对都合法；每个合法对也一定会被访问并计数一次。因此返回值准确且无遗漏、无重复。
边界与复杂度
重复值不去重，因为统计的是下标；n 个相同字符串在恰好能连接成目标时有 n(n−1) 对。若字符串比目标还长则不可能命中。最大答案 9,900，可用普通整数。
令 n 为数组长度，L 为输入字符串与目标字符串的最大长度。连接与比较每次 O(L)，总时间 O(n²L)；临时连接串使用 O(L) 额外空间，不计输入。
替代方案
用哈希表统计每个字符串频次，再枚举 target 的每个非空切分：前缀 a、后缀 b。若 a ≠ b，贡献 freq[a] × freq[b]；若 a = b，贡献 freq[a] × (freq[a]−1)。每个合法对的第一段长度唯一确定切分点，因此不重不漏。考虑字符串切片和哈希的字符成本，令 m=target.length、S 为 nums 总字符数，期望时间 O(S+m²)，额外空间上界 O(S+m)。
常见错误
  • 只枚举 j > i：丢失反向有序对。
  • 按字符串值去重：丢失不同下标产生的组合。
  • 相同值直接计算频次平方：把同一元素与自己配对。
  • 转成数字相加：破坏字符串连接含义，还可能超出数值范围。
面试追问
数据扩大怎么办？采用频次与切分法。如何避免连接分配？先检查长度和，再逐字符比较两段。若允许空字符串怎么办？需要额外考虑两端切分点，当前题目不允许空串。
Java
class Solution {
    public int numOfPairs(String[] nums, String target) {
        int ans = 0;
        for (int i = 0; i < nums.length; i++) {
            for (int j = 0; j < nums.length; j++) {
                if (i != j && (nums[i] + nums[j]).equals(target)) {
                    ans++;
                }
            }
        }
        return ans;
    }
}

class Solution:
    def numOfPairs(self, nums: List[str], target: str) -> int:
        ans = 0
        for i in range(len(nums)):
            for j in range(len(nums)):
                if i != j and nums[i] + nums[j] == target:
                    ans += 1
        return ans

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int numOfPairs(vector<string>& nums, string target) {
        int ans = 0;
        for (int i = 0; i < (int)nums.size(); ++i) {
            for (int j = 0; j < (int)nums.size(); ++j) {
                if (i != j && nums[i] + nums[j] == target) ++ans;
            }
        }
        return ans;
    }
};
