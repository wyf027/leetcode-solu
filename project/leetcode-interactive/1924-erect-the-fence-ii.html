Erect the Fence II · 一条圆形绳索，围住整片树林。

先理解目标，再观察几何状态。推导与代码位于底部，默认收起。

题意与接口

给定整数二维数组 trees，其中 trees[i] = [xᵢ, yᵢ] 表示一棵树。用一个圆覆盖全部树，允许树在圆周上。要求圆的半径最小，返回长度为 3 的数组 [x, y, r]，依次表示圆心横坐标、纵坐标与半径。答案与真实结果的误差在 10⁻⁵ 内可接受。

outerTrees(trees: integer[][]) → double[]

约束

  • 1 ≤ trees.length ≤ 3000
  • trees[i].length = 2
  • 0 ≤ xᵢ, yᵢ ≤ 3000

输出：[2.00000,2.00000,2.00000]

题解 · 随机增量最小圆覆盖
核心洞察
最小圆由至多三个支撑点确定：一个点对应零半径，两个点可作为直径端点，三个非共线边界点确定外接圆。新点在当前圆内，无需更新；新点在圆外，它必在更新后的最优圆边界上。
完整过程
  1. 复制输入，随机打乱点的顺序。
  2. 外层加入点 i。若它在圆外，将圆重置为以 i 为圆心的零半径圆，重扫之前的点。
  3. 发现圆外点 j，以 i、j 的直径圆重建，再扫描 j 之前的点。
  4. 发现仍在圆外的点 k，使用 i、j、k 的外接圆修复当前边界约束；结束内层扫描后继续向前。
令 u=b−a、v=c−a，圆心为 a+w。等距条件给出 2w·u=|u|²、2w·v=|v|²。解二元一次方程得到 w，半径为 |w|。代码在局部坐标中计算，避免直接相减较大的坐标平方。
正确性
对处理前缀归纳。新点在圆内时，旧最优圆仍可行；旧前缀的最优半径也是新问题的下界，因此它仍最优。若新点在圆外，则新最优圆必须让它位于边界，否则可向旧圆方向调整并缩小而保持覆盖，产生矛盾。固定 i 的重扫同理引入第二个边界点 j；固定 i、j 后遇到违规点 k，则三个边界约束确定唯一外接圆。各层扫描保持对应前缀在固定边界条件下的最小圆，因此完成外层后得到全部点的最小覆盖圆。
边界与数值
  • 单点或重合点：半径为 0。
  • 共线点：最远两点的直径圆覆盖全部点。共线三点不应直接除以行列式，退化分支取三条直径中最大的圆。
  • 精确运算的内层不变量下，共线三点不会产生新的有效三边界约束；仍保留退化分支防止除零。
  • 使用 double / 浮点数计算中点；整数坐标范围内叉积为零可直接判定。包含比较使用 r+10⁻⁹ 容差，不提前四舍五入。
复杂度
均匀随机排列下期望时间 O(n)，最坏 O(n³)。随机逆向分析中，第 i 个点成为至多三个支撑点之一的概率不超过 3/i；结合固定边界的递归分析得到线性期望。复制输入占 O(n) 空间，其余工作空间 O(1)，没有递归栈。
替代方案
递归 Welzl 更贴近数学定义，但 Python 需要注意递归深度。枚举所有二点和三点候选圆，再检查全部点，最坏 O(n⁴)，仅适合小数据参考。数值优化圆心需要额外的收敛与误差控制。
常见错误
  • 把本题误当成凸包题，返回边界树而非 [x,y,r]。
  • 只用最远点对：锐角三角形可能由三点支撑。
  • 在固定边界的内层擅自改用三点的无约束最小圆，破坏不变量。
  • 不随机化却声称期望线性；或把最坏复杂度说成线性。
  • 中点使用整数除法、共线时除零、无容差判断边界点。
面试追问
为什么三个支撑点足够？最优圆心必须落在边界点凸包中，二维下至多三个点即可支撑。如何解释随机化？使用逆向分析。如何支持删除？删除支撑点可能需要重建，当前增量过程不能直接处理。

import java.util.*;
class Solution {
    boolean inside(double[] c, int[] p) {
        return Math.hypot(p[0]-c[0],p[1]-c[1]) <= c[2]+1e-9;
    }
    double[] diameter(int[] a,int[] b) {
        return new double[]{(a[0]+b[0])/2.0,(a[1]+b[1])/2.0,
            Math.hypot(a[0]-b[0],a[1]-b[1])/2};
    }
    double[] triple(int[] a,int[] b,int[] c) {
        double u=b[0]-a[0],v=b[1]-a[1],s=c[0]-a[0],t=c[1]-a[1];
        double d=2*(u*t-v*s);
        if(d==0) {
            double[] z=diameter(a,b),ac=diameter(a,c),bc=diameter(b,c);
            if(ac[2]>z[2]) z=ac;
            if(bc[2]>z[2]) z=bc;
            return z;
        }
        double h=u*u+v*v,g=s*s+t*t,x=(t*h-v*g)/d,y=(u*g-s*h)/d;
        return new double[]{a[0]+x,a[1]+y,Math.hypot(x,y)};
    }
    public double[] outerTrees(int[][] trees) {
        int[][] p=trees.clone();
        Random rng=new Random();
        for(int i=p.length-1;i>0;i--) {
            int j=rng.nextInt(i+1);
            int[] tmp=p[i]; p[i]=p[j]; p[j]=tmp;
        }
        double[] c={0,0,-1};
        for(int i=0;i<p.length;i++) if(!inside(c,p[i])) {
            c=new double[]{p[i][0],p[i][1],0};
            for(int j=0;j<i;j++) if(!inside(c,p[j])) {
                c=diameter(p[i],p[j]);
                for(int k=0;k<j;k++) if(!inside(c,p[k]))
                    c=triple(p[i],p[j],p[k]);
            }
        }
        return c;
    }
}

var outerTrees = function(trees) {
  const p=trees.map(a=>a.slice());
  for(let i=p.length-1;i>0;i--) {
    const j=Math.floor(Math.random()*(i+1));
    [p[i],p[j]]=[p[j],p[i]];
  }
  const inside=(c,a)=>Math.hypot(a[0]-c[0],a[1]-c[1])<=c[2]+1e-9;
  const diameter=(a,b)=>[(a[0]+b[0])/2,(a[1]+b[1])/2,
    Math.hypot(a[0]-b[0],a[1]-b[1])/2];
  function triple(a,b,c) {
    const u=b[0]-a[0],v=b[1]-a[1],s=c[0]-a[0],t=c[1]-a[1];
    const d=2*(u*t-v*s);
    if(d===0) return [diameter(a,b),diameter(a,c),diameter(b,c)]
      .sort((x,y)=>y[2]-x[2])[0];
    const h=u*u+v*v,g=s*s+t*t,x=(t*h-v*g)/d,y=(u*g-s*h)/d;
    return [a[0]+x,a[1]+y,Math.hypot(x,y)];

  for(let i=0;i<p.length;i++) if(!inside(c,p[i])) {

      for(let k=0;k<j;k++) if(!inside(c,p[k]))

  }

Python
from typing import List
import math
import random

class Solution:
    def outerTrees(self, trees: List[List[int]]) -> List[float]:
        p = trees[:]
        random.shuffle(p)
        def inside(c, a):
            return math.hypot(a[0]-c[0], a[1]-c[1]) <= c[2]+1e-9
        def diameter(a, b):
            return [(a[0]+b[0])/2, (a[1]+b[1])/2,
                    math.hypot(a[0]-b[0], a[1]-b[1])/2]
        def triple(a, b, c):
            u, v = b[0]-a[0], b[1]-a[1]
            s, t = c[0]-a[0], c[1]-a[1]
            d = 2*(u*t-v*s)
            if d == 0:
                return max([diameter(a,b),diameter(a,c),diameter(b,c)],
                           key=lambda z: z[2])
            h, g = u*u+v*v, s*s+t*t
            x, y = (t*h-v*g)/d, (u*g-s*h)/d
            return [a[0]+x, a[1]+y, math.hypot(x,y)]
        c = [0.0, 0.0, -1.0]
        for i in range(len(p)):
            if inside(c,p[i]): continue
            c = [float(p[i][0]),float(p[i][1]),0.0]
            for j in range(i):
                if inside(c,p[j]): continue
                c = diameter(p[i],p[j])
                for k in range(j):
                    if not inside(c,p[k]):
                        c = triple(p[i],p[j],p[k])
        return c

#include <vector>
#include <array>
#include <algorithm>
#include <random>
#include <cmath>
using namespace std;
class Solution {
    using Circle = array<double,3>;
    bool inside(const Circle& c,const vector<int>& p) {
        return hypot(p[0]-c[0],p[1]-c[1])<=c[2]+1e-9;
    }
    Circle diameter(const vector<int>& a,const vector<int>& b) {
        return {(a[0]+b[0])/2.0,(a[1]+b[1])/2.0,
                hypot(a[0]-b[0],a[1]-b[1])/2};
    }
    Circle triple(const vector<int>& a,const vector<int>& b,
                  const vector<int>& c) {
        double u=b[0]-a[0],v=b[1]-a[1],s=c[0]-a[0],t=c[1]-a[1];
        double d=2*(u*t-v*s);
        if(d==0) {
            Circle z=diameter(a,b),ac=diameter(a,c),bc=diameter(b,c);
            if(ac[2]>z[2]) z=ac;
            if(bc[2]>z[2]) z=bc;
            return z;
        }
        double h=u*u+v*v,g=s*s+t*t,x=(t*h-v*g)/d,y=(u*g-s*h)/d;
        return {a[0]+x,a[1]+y,hypot(x,y)};
    }
public:
    vector<double> outerTrees(vector<vector<int>>& trees) {
        auto p=trees;
        mt19937 rng(random_device{}());
        shuffle(p.begin(),p.end(),rng);
        Circle c={0,0,-1};
        for(int i=0;i<(int)p.size();i++) if(!inside(c,p[i])) {
            c={double(p[i][0]),double(p[i][1]),0};
            for(int j=0;j<i;j++) if(!inside(c,p[j])) {
                c=diameter(p[i],p[j]);
                for(int k=0;k<j;k++) if(!inside(c,p[k]))
                    c=triple(p[i],p[j],p[k]);
            }
        }
        return {c[0],c[1],c[2]};
    }
};
