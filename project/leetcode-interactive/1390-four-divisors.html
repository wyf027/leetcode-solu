四因数

从一组整数中，找出恰好拥有四个正因数的数，并返回这些因数的总和。

中等 Four Divisors 非付费题 函数：sumFourDivisors(nums)

题目要求

给定整数数组 nums。对数组中的每个整数，判断它是否恰有四个正因数；只有满足条件的整数才贡献其全部因数之和。返回所有这些贡献的总和，如果没有任何数满足条件则返回 0。

Input → Output integer[] → integer

数组中的重复数字需要分别计算并累加。

先想一想，再看完整题解

你能否只检查到平方根，就准确识别“四个因数”并得到它们的和？

核心洞察

因数总是成对出现

若 i 整除 n，则 n / i 也是因数。只需枚举到 √n，同时统计数量与和。

完整过程

  1. 对数组中的每个 n，初始化 count = 0 与 sum = 0。
  2. 枚举 i，满足 i × i ≤ n。若 n % i == 0，得到配对因数 i 与 n / i。
  3. 两者不相等时，因数数量增加 2、因数和增加两者之和；相等时只增加 1 次。
  4. 一旦数量超过 4，可以提前停止；最终仅在数量等于 4 时把局部因数和计入答案。

正确性说明

完整性：任意因数 d 都与 n / d 配对，配对中至少有一个不超过 √n，所以枚举区间不会漏掉任何因数。

不重复：每个较小因数只被枚举一次；平方数在 i = n / i 时只计一次。

结论：count 恰等于正因数总数，sum 恰等于其和。因此算法只会累加、也一定会累加所有恰有四个因数的数字。

边界与复杂度

  • n = 1：只有一个因数，不贡献答案。
  • 完全平方数：平方根只能统计一次。
  • 重复元素：按数组位置分别贡献，例如两个 21。
  • 时间复杂度：O(nums.length × √M)，M = max(nums)。
  • 额外空间复杂度：O(1)。

替代方案与取舍

恰有四个因数的数只可能是 p³（p 为质数）或 p × q（两个不同质数）。可以通过质因数分解或最小质因子筛来判断，在大量查询或更大数值范围时更有价值；但本题上界为 10⁵，逐数枚举到平方根更直接，代码也更不容易出错。

Implementation

四种语言完整代码

JavaLeetCode 可提交
class Solution {
    public int sumFourDivisors(int[] nums) {
        int answer = 0;
        for (int n : nums) {
            int count = 0;
            int sum = 0;
            for (int i = 1; i * i <= n; i++) {
                if (n % i != 0) continue;
                int pair = n / i;
                if (i == pair) {
                    count++;
                    sum += i;
                } else {
                    count += 2;
                    sum += i + pair;
                }
                if (count > 4) break;
            }
            if (count == 4) answer += sum;
        }
        return answer;
    }
}

PythonLeetCode 可提交
from typing import List

class Solution:
    def sumFourDivisors(self, nums: List[int]) -> int:
        answer = 0
        for n in nums:
            count = 0
            divisor_sum = 0
            i = 1
            while i * i <= n:
                if n % i == 0:
                    pair = n // i
                    if i == pair:
                        count += 1
                        divisor_sum += i
                    else:
                        count += 2
                        divisor_sum += i + pair
                    if count > 4:
                        break
                i += 1
            if count == 4:
                answer += divisor_sum
        return answer

面试追问

  • 为什么只枚举到平方根？ 因数成对出现，每对至少有一个不大于平方根。
  • 如何进一步优化批量查询？ 预处理最小质因子，或用筛法累计每个数的因数个数与因数和。
  • 若目标改成恰有 k 个因数？ 通用枚举仍适用；大范围场景可由质因数分解公式计算因数个数。
  • 为什么可以在 count > 4 时停止？ 后续扫描只可能发现更多因数，不可能把数量降回 4。

常见错误

  • 把平方根当作两个不同因数，导致完全平方数的计数和求和都重复。
  • 找到两对因数后立刻认定结果，却没有确认后面不存在第五个因数。
  • 只累加符合条件的原数，而题目要求累加这些数的全部因数之和。
  • 用集合保存全部因数虽可行，但引入了不必要的额外空间。
