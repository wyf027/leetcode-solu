Service brief

题意

给定二叉树根节点 root 和整数 targetSum。如果存在一条从根节点到叶子节点的路径，使沿途节点值之和等于目标值，返回 true；否则返回 false。

验票条件

路径必须从根开始、沿父子边前进并停在叶子。不能从中间节点出发，也不能在尚有孩子的节点提前结束。

叶子站

叶子节点必须同时没有左孩子和右孩子。即使某个中间节点的累计和已经等于 targetSum，只要它不是叶子，就不能验票成功。

输入 root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22

样例二

样例三

输出 false

Route protocol

题解：显式栈 DFS

栈中保存“待访问节点 + 到达它之前的剩余目标值”。弹出节点后扣除节点值；只有当前节点是叶子且余额变成 0，才返回 true。

01

把累计加法改写为剩余扣减

从 targetSum 开始，每经过一个节点就减去 node.val。这样每个栈状态只需携带一个局部余额。

02

余额为 0 还不够

必须同时到达叶子。若中间站余额已经归零，仍要继续沿孩子搜索；这正是本题最常见的边界错误。

Complete process

完整过程

  1. 01若 root == null，不存在根到叶路径，直接返回 false。
  2. 02把 (root, targetSum) 压入栈；第二个值表示进入该节点前的剩余目标。
  3. 03弹出状态并计算 remaining = before - node.val。
  4. 04若节点是叶子且 remaining == 0，立即返回 true。
  5. 05把存在的右孩子、左孩子依次压栈，携带新的 remaining；后压入的左孩子先访问。
  6. 06栈清空仍未命中合法叶子，则返回 false。

Edges & trade-offs

边界、复杂度与替代方案

关键边界

  • 空树即使 targetSum = 0 也返回 false。
  • 单节点树只有在根值等于目标时返回 true。
  • 节点值可为负数，不能在 remaining < 0 时剪枝。
  • 累计值中途命中目标但节点不是叶子，不能提前成功。

为什么使用显式栈

递归状态转移最短，但题目允许 5,000 个节点的深链，部分语言可能出现调用栈溢出。显式栈保留 DFS 的面试思路，也让四语言提交更稳健。

方案 时间 额外空间 取舍
显式栈 DFS（主线） O(n) O(h) 避免递归深度风险，状态稍多。
递归 DFS O(n) O(h) 调用栈 表达最简洁，但深链可能栈溢出。
BFS O(n) O(w) 同样正确，宽树队列可能更大。

Interview follow-up

面试追问与常见错误

面试追问

  • 如何返回那条路径？——栈状态再携带路径，或保存父指针后回溯。
  • 如何统计满足条件的路径数量？——命中叶子时累加，不能提前返回。
  • 若路径可在任意节点起止？——这已变成不同问题，需要前缀和等方法。

常见错误

  • 只判断累计和，不判断当前节点是否为叶子。
  • 空树且目标为 0 时错误返回 true。
  • 因余额为负就剪枝，忽略后续负数节点可以把余额拉回 0。
  • 左右孩子携带不同或未更新的 remaining。

Submission-ready code

四语言可提交代码

四份实现都使用显式栈，状态为节点与进入该节点前的剩余目标。 

class Solution {
    private static class State {
        TreeNode node;
        int before;

        State(TreeNode node, int before) {
            this.node = node;
            this.before = before;
        }
    }

    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) {
            return false;
        }

        Deque<State> stack = new ArrayDeque<>();
        stack.push(new State(root, targetSum));

        while (!stack.isEmpty()) {
            State state = stack.pop();
            TreeNode node = state.node;
            int remaining = state.before - node.val;

            if (node.left == null && node.right == null && remaining == 0) {
                return true;
            }
            if (node.right != null) {
                stack.push(new State(node.right, remaining));
            }
            if (node.left != null) {
                stack.push(new State(node.left, remaining));
            }
        }

        return false;
    }
}

        stack<pair<TreeNode*, int>> states;
