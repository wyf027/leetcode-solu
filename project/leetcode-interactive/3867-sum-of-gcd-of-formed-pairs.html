数对的最大公约数之和

先把每个位置变成「当前元素与此前最大值的 GCD」，再排序。题目规定最小未配对值要和最大未配对值配成一对，因此两端同时收缩即可。

推荐主线：前缀最大值 + gcd + 排序 + 首尾双指针

题意，先看规则

给定 nums，令 mx[i] 是 nums[0..i] 的最大值，构造 prefixGcd[i] = gcd(nums[i], mx[i])。将该数组升序排序后，反复取最小和最大未配对元素，累加每对的 GCD；奇数长度时正中元素不配对。

示例

nums = [3, 6, 2, 8]：得到 prefixGcd = [3, 6, 2, 8]，排序为 [2, 3, 6, 8]，配对 (2, 8) 与 (3, 6)，答案为 2 + 3 = 5。

约束：1 ≤ nums.length ≤ 10^5，1 ≤ nums[i] ≤ 10^9。无需寻找“更优配对”，配对规则已经由题目固定。

题解：把“构造”与“配对”分离

  1. 从左到右维护 mx，填入 g[i] = gcd(nums[i], mx)。
  2. 升序排序 g；题意强制每轮取最小与最大，故第 i 对就是 g[i] 与 g[n - 1 - i]。
  3. 枚举 i < n / 2，求每对 GCD 并累计。奇数时中间下标不会访问。

复杂度与边界

构造和配对为 O(n log V)，排序为 O(n log n)，总空间 O(n)。单元素答案为 0；全相同数组每对都贡献该值；答案用 long/long long 保存。

替代方案、面试追问与常见错误

不能跳过排序，也不能把相邻元素配对；题目不是优化匹配。若追问流式输入，前缀构造可流式完成，但最终首尾规则仍需保留并排序全部 g。常见错误是把 gcd(nums[i], mx) 写成前缀所有值的累计 GCD，或在奇数长度时误把中位数加入答案。 

class Solution {
    public long gcdSum(int[] nums) {
        int n = nums.length, mx = 0;
        int[] g = new int[n];
        for (int i = 0; i < n; i++) { mx = Math.max(mx, nums[i]); g[i] = gcd(nums[i], mx); }
        Arrays.sort(g); long ans = 0;
        for (int i = 0; i < n / 2; i++) ans += gcd(g[i], g[n - 1 - i]);
        return ans;
    }
    private int gcd(int a, int b) { while (b != 0) { int t = a % b; a = b; b = t; } return a; }
}
var gcdSum = function(nums) {
  const gcd = (a, b) => { while (b) [a, b] = [b, a % b]; return a; };
  let mx = 0;
  const g = nums.map(x => { mx = Math.max(mx, x); return gcd(x, mx); }).sort((a, b) => a - b);
  let ans = 0;
  for (let i = 0; i < Math.floor(g.length / 2); i++) ans += gcd(g[i], g[g.length - 1 - i]);
  return ans;
};
from math import gcd
from typing import List

class Solution:
    def gcdSum(self, nums: List[int]) -> int:
        mx = 0
        g = []
        for x in nums:
            mx = max(mx, x)
            g.append(gcd(x, mx))
        g.sort()
        return sum(gcd(g[i], g[-1 - i]) for i in range(len(g) // 2))
