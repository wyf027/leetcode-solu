01
Problem

任务是什么

给定一个按非递减顺序排列的整数数组 nums。请判断能否把其中的每个元素恰好使用一次，分到一个或多个子序列中，并同时满足：

  • 每个子序列都连续递增，相邻两个数之差恰好为 1；
  • 每个子序列的长度都至少为 3。

可以完成分割时返回 true，否则返回 false。子序列允许删除原数组中的其他元素，但必须保持被选元素的相对顺序。

函数形式

isPossible(nums: integer[]) → boolean

注意：这里要求“分完所有元素”，并不是只需找出一条合格子序列。

示例 1

输入nums = [1,2,3,3,4,5]
输出true
解释可以分为 [1,2,3] 与 [3,4,5]。

示例 2

输入nums = [1,2,3,3,4,4,5,5]
输出true
解释可以分为 [1,2,3,4,5] 与 [3,4,5]。

示例 3

输入nums = [1,2,3,4,4,5]
输出false
解释无法把全部数字分成长度至少为 3 的连续递增子序列。

约束

  • 1 ≤ nums.length ≤ 104
  • −1000 ≤ nums[i] ≤ 1000
  • nums 按非递减顺序排列

04
Solution

贪心：先救旧轨道，再开新轨道

核心洞察

从小到大处理每个尚未使用的数字 x。它只有两个合理去处：

  1. 若存在以 x−1 结尾的旧序列，优先把 x 接上去；
  2. 否则，必须用 x, x+1, x+2 立即开一条长度为 3 的新序列。

两者都做不到就返回 false。

两张表
count[v]：数字 v 还剩多少个。
end[v]：有多少条序列当前以 v 结尾。

完整过程

  1. 统计所有数字的剩余次数到 count。
  2. 按原数组顺序扫描 x；若它已被提前用于创建序列，即 count[x] = 0，直接跳过。
  3. 如果 end[x−1] > 0，消耗一个 x，把某条以 x−1 结尾的序列延长到 x。
  4. 否则检查 x+1 与 x+2 是否仍有库存；若都有，则一次消耗 x、x+1、x+2，并登记一条以 x+2 结尾的新序列。
  5. 若既不能延长也不能新建，立即返回 false；扫描结束后返回 true。

正确性说明

引理 1：若没有轨道等待 x，因为 x 是最小的未使用数字，它不可能接在更小的未处理数字后面，只能成为新序列的起点。因此 x+1、x+2 必须存在。

引理 2：若有轨道以 x−1 结尾，把 x 接上是安全的。任何可行分割里，若 x 原本启动另一条序列，可把那条从 x 开始的整段拼到该旧轨道后；连续性和长度要求都不被破坏。

归纳：每一步都选择了必要或可交换成的安全动作，并保持已消费元素组成合法连续序列。若某步无动作，则由引理 1 不存在可行分割；若扫描完成，所有元素都已被纳入长度至少 3 的序列。

为什么新轨道一口气取 3 个数

题目不接受长度 1 或 2 的序列。只有在 x+1 和 x+2 都存在时才开轨，能立刻保证这条序列已经合法；以后即使不再延长，也不会留下“半成品”。

复杂度

时间：O(n)，计数与扫描各一次，哈希表操作均摊 O(1)。

空间：O(n)，两张哈希表最多记录 O(n) 个不同键。

边界情况

  • 不足 3 个元素必然失败；
  • 负数不影响哈希计数；
  • 重复值可能开启多条轨道；
  • 数值断层会让某些起点无法凑齐三个数。

替代方案

也可按数值维护“以该值结尾的序列长度”最小堆，总把新数字接到最短序列。更直观但通常需要 O(n log n) 时间。

常见错误

  • 先开新序列，饿死等待当前数字的旧序列；
  • 只检查 x+1，忘记长度下限为 3；
  • 提前取走 x+1、x+2 后未跳过其零库存项；
  • 把子序列误解为连续子数组。

面试追问

  • 如果数组未排序？ 先排序会变为 O(n log n)；若值域很小，也可按键有序遍历计数。
  • 最短长度从 3 改为 k？ 新建序列时检查并消耗 x 到 x+k−1，延长优先级不变；直接检查会带来 O(nk)，可继续讨论如何利用区间计数优化。
  • 如何返回实际分组？ 将 end[v] 从数量改为存放轨道对象的容器，每次取一条以 v 结尾的轨道追加元素。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isPossible(int[] nums) {
        Map<Integer, Integer> count = new HashMap<>();
        Map<Integer, Integer> end = new HashMap<>();

        for (int x : nums) {
            count.put(x, count.getOrDefault(x, 0) + 1);
        }

        for (int x : nums) {
            if (count.getOrDefault(x, 0) == 0) {
                continue;
            }

            if (end.getOrDefault(x - 1, 0) > 0) {
                count.put(x, count.get(x) - 1);
                end.put(x - 1, end.get(x - 1) - 1);
                end.put(x, end.getOrDefault(x, 0) + 1);
            } else if (count.getOrDefault(x + 1, 0) > 0
                    && count.getOrDefault(x + 2, 0) > 0) {
                count.put(x, count.get(x) - 1);
                count.put(x + 1, count.get(x + 1) - 1);
                count.put(x + 2, count.get(x + 2) - 1);
                end.put(x + 2, end.getOrDefault(x + 2, 0) + 1);
            } else {
                return false;
            }
        }

        return true;
    }
}

var isPossible = function(nums) {
    const count = new Map();
    const end = new Map();
    const get = (map, key) => map.get(key) || 0;

    for (const x of nums) {
        count.set(x, get(count, x) + 1);
    }

    for (const x of nums) {
        if (get(count, x) === 0) continue;

        if (get(end, x - 1) > 0) {
            count.set(x, get(count, x) - 1);
            end.set(x - 1, get(end, x - 1) - 1);
            end.set(x, get(end, x) + 1);
        } else if (get(count, x + 1) > 0 && get(count, x + 2) > 0) {
            count.set(x, get(count, x) - 1);
            count.set(x + 1, get(count, x + 1) - 1);
            count.set(x + 2, get(count, x + 2) - 1);
            end.set(x + 2, get(end, x + 2) + 1);
        } else {
            return false;
        }
    }

    return true;
};
from collections import Counter
from typing import List


class Solution:
    def isPossible(self, nums: List[int]) -> bool:
        count = Counter(nums)
        end = Counter()

        for x in nums:
            if count[x] == 0:
                continue

            if end[x - 1] > 0:
                count[x] -= 1
                end[x - 1] -= 1
                end[x] += 1
            elif count[x + 1] > 0 and count[x + 2] > 0:
                count[x] -= 1
                count[x + 1] -= 1
                count[x + 2] -= 1
                end[x + 2] += 1
            else:
                return False

        return True
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    bool isPossible(vector<int>& nums) {
        unordered_map<int, int> count;
        unordered_map<int, int> end;

        for (int x : nums) {
            ++count[x];
        }

        for (int x : nums) {
            if (count[x] == 0) {
                continue;
            }

            if (end[x - 1] > 0) {
                --count[x];
                --end[x - 1];
                ++end[x];
            } else if (count[x + 1] > 0 && count[x + 2] > 0) {
                --count[x];
                --count[x + 1];
                --count[x + 2];
                ++end[x + 2];
            } else {
                return false;
            }
        }

        return true;
    }
};
