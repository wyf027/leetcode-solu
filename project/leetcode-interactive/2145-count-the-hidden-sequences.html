2145. 统计隐藏数组数目

Count the Hidden Sequences

你知道每一步的变化，却看不到原始数组。给定上下边界，有多少种隐藏数组能同时满足所有条件？

中等免费题先思考，再揭晓

01 / 题目说明

给定长度为 n 的整数数组 differences。需要寻找长度为 n + 1 的整数数组 hidden，使每对相邻元素满足 hidden[i + 1] - hidden[i] = differences[i]，并且每个元素都位于闭区间 [lower, upper] 内。

返回不同的合法隐藏数组的数量；无解时返回 0。区间端点也允许使用。

先想一想：如果只改变第一个数，后面的数会怎样变化？

参数与约束

  • n == differences.length，1 ≤ n ≤ 10⁵。
  • -10⁵ ≤ differences[i] ≤ 10⁵。
  • -10⁵ ≤ lower ≤ upper ≤ 10⁵。
  • 签名：numberOfArrays(differences, lower, upper) → integer。

02 / 官方示例

示例 1

输入：differences = [1,-3,4], lower = 1, upper = 6
输出：2

合法数组为 [3,4,1,5] 和 [4,5,2,6]。[5,6,3,7] 含越界元素；[1,2,3,4] 的差值不符。

示例 2

输入：differences = [3,-4,5,1,-2], lower = -4, upper = 5
输出：4

合法数组为 [-3,0,-4,1,2,0]、[-2,1,-3,2,3,1]、[-1,2,-2,3,4,2] 和 [0,3,-1,4,5,3]。

示例 3

输入：differences = [4,-7,2], lower = 3, upper = 6
输出：0

不存在满足全部差值且所有元素都在区间内的数组。

05 / 独立题解
准备好后，展开推导与四语言代码。


核心洞察：固定形状，只能整体平移


令第一个数为 x，定义 p[0] = 0，p[i + 1] = p[i] + differences[i]。那么 hidden[i] = x + p[i]。差值决定形状，起点决定竖直位置。


记所有前缀值（含 0）的最小值为 mn，最大值为 mx。全部元素合法，等价于 x + mn ≥ lower 且 x + mx ≤ upper。


合法起点区间：[lower - mn, upper - mx]
答案：max(0, upper - lower - (mx - mn) + 1)


完整过程
  1. 初始化 sum = mn = mx = 0，把 hidden[0] 对应的零前缀纳入统计。
  2. 依次累加每个差值，并更新前缀最小值、最大值。
  3. 计算折线跨度 mx - mn。用边界宽度减去跨度，再加 1，得到整数平移位置的数量。
  4. 若计算结果为负，返回 0。


示例 1：differences = [1,-3,4], lower = 1, upper = 6
位置 i       0    1    2    3
前缀 p[i]    0    1   -2    2
mn = -2，mx = 2，跨度 = 4
x ∈ [1 - (-2), 6 - 2] = [3,4]
答案 = 4 - 3 + 1 = 2


正确性证明
唯一性：给定起点 x，差值递推唯一确定后续元素；不同起点生成不同数组，因此只需计数起点。
必要性：如果数组合法，它的最小值 x + mn 不小于 lower，最大值 x + mx 不大于 upper，所以 x 必须处于推导的区间。
充分性：如果 x 在该区间，对任意 i 都有 mn ≤ p[i] ≤ mx，故 lower ≤ x + p[i] ≤ upper；递推同时保证所有差值正确。于是合法数组与该闭区间中的整数一一对应，计数公式成立。


边界与复杂度
  • 跨度等于边界宽度：恰好 1 个位置；更大时无解。
  • 全部差值为 0：答案为 upper - lower + 1。
  • lower = upper：仅全部差值为 0 时有 1 个解。
  • 前缀和绝对值可达 10¹⁰。Java 使用 long，C++ 使用 long long；Python 整数足够，JavaScript Number 在本题范围内可精确表示整数。答案最大为 200001，可返回 int。
  • 时间 O(n)，辅助空间 O(1)，不需要保存前缀数组。交互图为教学保存路径，其空间开销不代表提交算法。


替代方案
可以逐项求约束 x ∈ [lower - p[i], upper - p[i]] 并维护交集，仍是 O(n) 时间、O(1) 空间。枚举 [lower, upper] 中每个起点并生成数组，则需 O(n × (upper - lower + 1)) 时间，最坏情况开销过大。


常见错误
  • 把差值写成 hidden[i] - hidden[i + 1]，导致方向颠倒。
  • 漏掉前缀 0，忽略了起点本身也必须满足边界。
  • 只看总和或单个差值的极值，没有统计沿途前缀极值。
  • 闭区间计数漏加 1，或无解时返回负数。
  • 用 32 位整数保存累加值，导致溢出。


面试追问
能提前返回吗？可以；遍历中一旦 mx - mn > upper - lower，后续跨度不会缩小，必然无解。
如何构造一个合法数组？若区间非空，取 x = lower - mn，再按差值递推。输出数组需要 O(n) 空间。
若每个位置有不同边界？维护所有区间 [lower[i] - p[i], upper[i] - p[i]] 的交集；不能再仅用一组全局前缀极值套同一边界公式。


Java
class Solution {
    public int numberOfArrays(int[] differences, int lower, int upper) {
        long sum = 0, mn = 0, mx = 0;
        for (int d : differences) {
            sum += d;
            mn = Math.min(mn, sum);
            mx = Math.max(mx, sum);
        }
        return (int) Math.max(0L, (long) upper - lower - (mx - mn) + 1);
    }
}
