Problem

题目要求

返回 integer

给定一个由互不相同的小写字母组成的字符串 allowed，以及字符串数组 words。如果某个单词中的每一个字符都出现在 allowed 中，就称它为“一致字符串”。

请返回 words 中一致字符串的总数。

!
判断标准只有一个：单词中不能出现名单外字符。字符可以重复，出现顺序也不重要。

Solution

完整题解

哈希集合
1

核心洞察

“一致”是一个全称条件：单词的每个字符都必须属于许可集合。把 allowed 放进哈希集合后，每次成员查询都是均摊 O(1)。一旦发现非法字符即可提前结束当前单词。

2

为什么能提前停止

一个单词只需一个反例就能判定不一致。已经读到名单外字符后，剩余字符无论是什么，都无法让这个单词重新变得一致。

完整过程

  1. 建立许可集合。遍历 allowed，将每个字母加入集合。
  2. 逐个检查单词。先假设当前单词一致，然后从左到右读取字符。
  3. 遇到非法字符就拦截。若字符不在集合中，标记当前单词不一致并立即跳出内层循环。
  4. 累计通过数。若整个单词扫描完仍未发现非法字符，答案加一。

正确性证明

引理：算法把单词判为一致，当且仅当该单词的每个字符都在 allowed 中。

证明：若算法判为一致，扫描期间没有任何字符触发“不在集合中”的条件，因此所有字符都属于 allowed。反过来，若单词所有字符都属于 allowed，每次集合查询都成功，算法不会提前退出，最终必然判为一致。

结论：算法对每个单词的判断都准确，并且只对一致单词累加一次，所以最终计数恰好等于一致字符串的数目。

边界情况

  • allowed 只有一个字母：重复该字母的单词仍然一致。
  • 所有单词都含非法字符：答案为 0。
  • 所有单词都合法：答案等于 words.length。
  • 非法字符出现在开头时可最快提前停止；出现在末尾时仍需扫描整个单词。

复杂度

设所有单词的字符总数为 S，建立集合需要 O(|allowed|)，扫描至多检查 S 个字符。

时间：O(|allowed| + S)
空间：O(|allowed|)，且字母表固定时可视为 O(1)。

替代方案

推荐

哈希集合

表达直接，四种语言都清晰。成员查询均摊 O(1)。

26 位掩码

把字母映射到二进制位；若单词掩码包含许可掩码之外的位，则不一致。常数小，但可读性稍弱。

字符串查找

对每个字符调用 allowed.includes。由于最多 26 个字母也能通过，但理论上单次查询不是 O(1)。

四语言完整代码

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int countConsistentStrings(String allowed, String[] words) {
        Set<Character> permitted = new HashSet<>();
        for (char c : allowed.toCharArray()) {
            permitted.add(c);
        }

        int answer = 0;
        for (String word : words) {
            boolean consistent = true;
            for (char c : word.toCharArray()) {
                if (!permitted.contains(c)) {
                    consistent = false;
                    break;
                }
            }
            if (consistent) answer++;
        }
        return answer;
    }
}
/**
 * @param {string} allowed
 * @param {string[]} words
 * @return {number}
 */
var countConsistentStrings = function(allowed, words) {
    const permitted = new Set(allowed);
    let answer = 0;

    for (const word of words) {
        let consistent = true;
        for (const char of word) {
            if (!permitted.has(char)) {
                consistent = false;
                break;
            }
        }
        if (consistent) answer++;
    }

    return answer;
};
from typing import List

class Solution:
    def countConsistentStrings(
        self, allowed: str, words: List[str]
    ) -> int:
        permitted = set(allowed)
        answer = 0

        for word in words:
            consistent = True
            for char in word:
                if char not in permitted:
                    consistent = False
                    break
            if consistent:
                answer += 1

        return answer

面试追问

Q：能否不用额外集合？

可以。直接在 allowed 中查找，或用 26 位整数掩码。固定字母表下，位掩码最节省常数空间。

Q：如何用位运算判断？

构造许可掩码 A 和单词掩码 W；当 (W & ~A) == 0 时，W 没有任何越界位。

Q：字符集扩展到 Unicode 呢？

继续使用按字符存储的哈希集合更合适；26 位掩码只适用于已知且很小的字母表。

Q：为什么不能只比较不同字符的数量？

数量相同不代表集合相同。例如许可为 {a,b}，单词含 {a,c}，大小相同但 c 非法。

常见错误

  • 把“每个字符都允许”误写成“至少一个字符允许”。
  • 发现非法字符后仍继续扫描，虽然不影响答案，却失去提前停止的优势。
  • 忘记为每个新单词重置 consistent 标记。
  • 按字符出现次数比较；本题只关心字符是否属于许可集合，不限制重复次数。
