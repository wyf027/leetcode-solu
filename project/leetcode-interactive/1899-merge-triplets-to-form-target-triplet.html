LeetCode 1899 / Merge Triplets to Form Target Triplet

合并若干三元组
以形成目标三元组

三个坐标，一种合并操作。先读题思考，再展开下面的交互推演。

01 / PROBLEM

题目描述

给定二维整数数组 triplets，每个元素 triplets[i] = [aᵢ, bᵢ, cᵢ] 都含三个整数；另给定目标 target = [x, y, z]。

一次操作可以选择两个不同的下标 i、j，把 triplets[j] 更新为两个三元组对应位置的最大值，triplets[i] 保持不变：

triplets[j] = [max(aᵢ, aⱼ), max(bᵢ, bⱼ), max(cᵢ, cⱼ)]

允许执行任意次操作，也允许零次。如果最终能让 target 成为数组中的一个元素，返回 true；否则返回 false。下标从 0 开始。

约束

  • 1 ≤ triplets.length ≤ 10⁵
  • triplets[i].length == target.length == 3
  • 1 ≤ aᵢ, bᵢ, cᵢ, x, y, z ≤ 1000

03 / SOLUTION

核心洞察：先排除越界，再取最大值

逐坐标取 max 只会让数值变大。如果一个三元组的任何坐标超过目标，它一旦参与某个结果的构造，这个越界值就无法被消除。因此，构造目标时只能使用每个坐标都不超过目标的三元组，称它们为“安全三元组”。

把所有安全三元组逐坐标取最大值。若三个最大值恰好等于目标，就能构造成功；否则，某个目标坐标没有可用来源，必然失败。

完整过程

  1. 令汇总值 best = [0,0,0]。输入值均为正数，所以 0 可以表示尚无贡献。
  2. 遍历每个三元组 t：只要存在 t[k] > target[k]，跳过整个 t。
  3. 否则，对三个坐标分别执行 best[k] = max(best[k], t[k])。
  4. 遍历结束，比较 best 和 target 的三个坐标是否全部相等。

best 是算法的汇总变量，并不是额外放入数组中的三元组。真正构造时选择一个安全三元组作为接收者，把其余安全三元组合并进去即可。

正确性说明
1. 必要性：越界无法撤销
任意操作得到的三元组，都是某个非空原始三元组集合的逐坐标最大值。这可由操作次数归纳：初始是单元素集合，合并对应两个来源集合取并集。若来源中有任意一个坐标超过 target，结果该坐标也超过 target，因此成功结果的所有来源必须安全。
2. 循环不变式
扫描前 i 个三元组后，best[k] 是这些三元组中所有安全来源的第 k 个坐标的最大值；没有安全来源时为 0。跳过越界项不改变集合；合并安全项正好更新最大值，因此不变式持续成立。
3. 充分性与失败判定
如果扫描后 best = target，因为 target 为正数，安全集合非空。选其中一个下标作为接收者，依次与其余安全下标合并，就能得到 best；不同来源的下标与接收者不同，符合 i ≠ j。若只有一个来源，则零次操作即可。反之，若某个 best[k] < target[k]，任意安全子集的该坐标最大值都不会更大；不安全来源又不能使用，因此不可能得到目标。
边界情况
  • 数组只有一个三元组：当且仅当它等于目标时成功。
  • 没有安全三元组：best 保持 [0,0,0]，返回 false。
  • 目标已存在：允许零次操作，返回 true。
  • 重复三元组和输入顺序不影响最大值；每个坐标可以由不同三元组提供。
  • 安全三元组不一定贡献新最大值，保留或忽略它都不影响结果。
复杂度
n 为三元组数量。每个元素只检查和更新固定三个坐标：时间 O(n)，额外空间 O(1)，不修改输入。演示界面的历史列表占 O(n) 空间，与提交算法的空间复杂度不同。
替代方案
可以用三个布尔标记或三位掩码记录：是否有安全三元组在对应坐标等于目标。三个标记齐全即成功；仍是 O(n) 时间、O(1) 空间。枚举子集要 O(2ⁿ)，模拟所有成对合并还会重复探索状态，没有必要。
常见错误
  • 看到某坐标等于目标就直接记为可用，却没有检查该三元组的其他坐标是否越界。
  • 要求一个三元组同时匹配所有坐标，漏掉由多个来源协作的情况。
  • 以为可以对三个坐标分别挑选后丢弃原三元组中的越界值；实际每次合并都作用于整个三元组。
  • 对所有三元组直接取最大值，误把本可跳过的越界来源合并进去。
  • 误以为必须至少执行一次操作，或必须使用所有原始三元组。
面试追问
  • 如何返回具体操作？记录每个坐标的一个安全见证下标，去重后最多三个。以其中一个为接收者，合并其余见证，最多两次操作即可构造目标。
  • 最多两次是否就是最少？不一定。已有目标需零次；能找到一对合成目标则一次；否则成功实例最多两次。求最少次数可统计安全三元组的三位匹配掩码并枚举掩码对。
  • 扩展到 d 个坐标？相同判定适用，时间 O(nd)，空间 O(d)，最多需要 d 个见证。
  • 允许负数时？不能再用 0 表示空最大值，应使用负无穷并跟踪是否至少选中一个来源，或直接使用布尔覆盖法。

Java
class Solution {
    public boolean mergeTriplets(int[][] triplets, int[] target) {
        int[] best = new int[3];
        for (int[] t : triplets) {
            if (t[0] > target[0] || t[1] > target[1] || t[2] > target[2]) {
                continue;
            }
            for (int k = 0; k < 3; k++) {
                best[k] = Math.max(best[k], t[k]);
            }
        }
        return best[0] == target[0]
            && best[1] == target[1]
            && best[2] == target[2];
    }
}

var mergeTriplets = function(triplets, target) {
    const best = [0, 0, 0];
    for (const t of triplets) {
        if (t[0] > target[0] || t[1] > target[1] || t[2] > target[2]) {
            continue;
        }
        for (let k = 0; k < 3; k++) {
            best[k] = Math.max(best[k], t[k]);
        }
    }
    return best.every((value, k) => value === target[k]);
};

from typing import List

class Solution:
    def mergeTriplets(self, triplets: List[List[int]], target: List[int]) -> bool:
        best = [0, 0, 0]
        for t in triplets:
            if any(t[k] > target[k] for k in range(3)):
                continue
            for k in range(3):
                best[k] = max(best[k], t[k])
        return best == target
