放置盒子 Building Boxes

困难 HARD非付费题交互拆层离线单文件

盒子不只是向上叠高：每一个离开地面的单位立方体，都要求下方盒子的四个竖直侧面获得墙面或其他盒子的支撑。目标是在放下恰好 n 个盒子时，让触地盒子尽可能少。

Problem

题意

在一个边长均为 n 的立方体房间中，放置 n 个边长为 1 的立方体盒子。盒子可以放在地板任意位置，但叠放时必须遵守：

  • 如果盒子 x 放在盒子 y 上方，那么 y 的四个竖直侧面都必须与另一个盒子或房间墙壁相邻。
  • 返回所有合法摆法中，直接接触地板的盒子数的最小值。
函数签名

minimumBoxes(n: integer) → integer

约束

1 ≤ n ≤ 109

房间尺寸足以容纳所有盒子；只需计算最少触地数量。

Solution

把三维堆叠压缩成两个三角数

1. 完整阶梯

角落里高度为 k 的完整阶梯共有 T(k)=k(k+1)(k+2)/6 个盒子，地板占用 F(k)=k(k+1)/2 个。

2. 装入最大整层

不断加入完整阶梯，直到下一个四面体数会超过 n。这样得到最大的 k 与剩余盒子 r=n-T(k)。

3. 剩余沿边增长

额外增加的第 x 个触地盒子可让这条斜坡累计容纳 1+2+…+x=x(x+1)/2 个盒子。取首次覆盖 r 的 x。

完整过程

  1. 令 k=0，反复尝试加入规模依次为 1, 3, 6, … 的新底层；这些增量是三角数。
  2. 当完整阶梯盒子数加上下一个三角数将超过 n 时停止。此时答案已有的触地盒子数就是最后一个三角数 F(k)。
  3. 对剩余 r 个盒子，从角落底层向外延伸一条递增斜坡。第 1、2、3… 个新底座分别让累计容量增加 1、2、3…。
  4. 逐个加入底座，直到累计额外容量不少于 r；最终答案为 F(k)+x。

正确性证明

引理 1：若最高层数为 k，在角落中逐层铺成边长从 1 到 k 的三角形，恰好使用 T(k) 个盒子、占用 F(k) 个地板位置；墙面与同层相邻盒子为每个上层盒子的下方盒子提供所需的四侧支撑。

引理 2：在最大完整阶梯外再增加 x 个触地盒子，最多可合法承载 1+2+…+x 个额外盒子。沿阶梯边缘依次放置高度 1,2,…,x 的列可以达到该上界；若少一个底座，则最高只能得到前一个三角数。

定理：算法先选最大可容纳的完整阶梯，因此剩余部分无法再组成更大完整阶梯。随后选取满足 x(x+1)/2 ≥ r 的最小 x。由引理 2，x 个新增底座足够，而 x-1 个一定不足，所以 F(k)+x 可行且最小。

边界与复杂度

  • n=1：得到一个完整的一层阶梯，答案为 1。
  • n=T(k)：没有剩余盒子，无需额外底座。
  • 即使 n=10⁹，循环次数也只有 O(∛n) 量级。
  • 时间复杂度 O(∛n)，空间复杂度 O(1)。

替代方案

可以分别二分最大的 k 与最小的 x，把时间写成 O(log n)。但在本题约束下，最多约千级循环的增量写法更短、更不容易出现边界错误。

class Solution {
    public int minimumBoxes(int n) {
        long used = 0;
        long floor = 0;
        long side = 1;
        while (used + side * (side + 1) / 2 <= n) {
            long layer = side * (side + 1) / 2;
            used += layer;
            floor = layer;
            side++;
        }

        long extra = 0;
        long capacity = 0;
        while (used + capacity < n) {
            extra++;
            capacity += extra;
        }
        return (int) (floor + extra);
    }
}

面试追问与常见错误

为什么优先靠墙角，而不是放在房间中央？

角落天然提供两面竖直墙，减少支撑上层盒子时所需的同层邻居数量，因此同样的地板占用能承载更多盒子。

如何改成二分查找？

先对 T(k) ≤ n 二分最大 k，再对 x(x+1)/2 ≥ n-T(k) 二分最小 x，答案仍是 F(k)+x。

常见错误：把剩余盒子数直接加到答案

新增一个触地盒子可能支撑一整列，因此剩余 r 对应的是最小三角数覆盖，而不是简单增加 r 个底座。

常见错误：整数溢出或层数差一

Java/C++ 的乘法中间量使用 64 位整数；完整层循环必须在“加入下一层后仍不超过 n”时才推进。
