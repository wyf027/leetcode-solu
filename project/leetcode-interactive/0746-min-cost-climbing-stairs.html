Problem

先把“顶部”画出来

数组下标是实际台阶；顶部位于下标 cost.length，它本身不收费。你可以从下标 0 或 1 开始。

题意

给定整数数组 cost，cost[i] 表示从第 i 个台阶继续向上时要支付的费用。付费后，可以向上走一阶或两阶。

允许直接选择下标 0 或下标 1 作为起点。请返回抵达楼梯顶部的最低总花费。

函数参数

minCostClimbingStairs(cost: integer[]) → integer

约束

  • 2 <= cost.length <= 1000
  • 0 <= cost[i] <= 999

示例 1

输入：cost = [10, 15, 20]
输出：15
解释：从下标 1 开始，支付 15，
再向上跨两阶到达顶部，总花费为 15。

示例 2

输入：cost = [1, 100, 1, 1, 1, 100, 1, 1, 100, 1]
输出：6
解释：选择下标 0、2、4、6、7、9，
对应费用均为 1，最终总花费为 6。

Complete solution

把“到达”作为状态

空间优化后的动态规划：时间复杂度 O(n)，额外空间复杂度 O(1)。

核心洞察

把 dp[i] 定义为到达位置 i、尚未支付位置 i 费用时的最低总花费。由于起点可以是 0 或 1，所以 dp[0] = dp[1] = 0。

抵达 i 的最后一步只可能来自 i−1 或 i−2。离开来源台阶时才付费，因此：

dp[i] = min(dp[i−1] + cost[i−1], dp[i−2] + cost[i−2])

顶部就是位置 n，答案为 dp[n]。

完整过程

  1. 令 prev2 = dp[0] = 0，prev1 = dp[1] = 0。
  2. 从 i = 2 遍历到 i = n。
  3. 计算两个候选值：从前一阶来与从前两阶来。
  4. 取较小者作为 dp[i]，再滚动更新两个变量。
  5. 循环结束后，prev1 即到达顶部的最低花费。

正确性证明

基础：从位置 0 或 1 开始不需要先支付费用，所以 dp[0] = dp[1] = 0 正确。

归纳：假设 dp[i−1] 与 dp[i−2] 已分别是抵达对应位置的最低花费。抵达 i 的最后一步只能来自这两个位置；两条完整路线的花费分别是 dp[i−1]+cost[i−1] 与 dp[i−2]+cost[i−2]。取二者最小值，就覆盖了所有可能的最后一步，并得到抵达 i 的最低花费。

结论：归纳至 i=n，得到的 dp[n] 就是抵达顶部的最低总花费。

边界与复杂度

  • cost.length = 2：只计算一次顶部状态，答案是两项费用的较小值。
  • 费用允许为 0：转移公式无需特殊处理。
  • 全为相同费用：仍会自动选择更少的付费台阶。
  • 时间复杂度：O(n)，每个位置只处理一次。
  • 额外空间复杂度：O(1)，仅保留两个历史状态。

class Solution {
    public int minCostClimbingStairs(int[] cost) {
        int prev2 = 0; // dp[0]
        int prev1 = 0; // dp[1]

        for (int i = 2; i <= cost.length; i++) {
            int current = Math.min(
                prev1 + cost[i - 1],
                prev2 + cost[i - 2]
            );
            prev2 = prev1;
            prev1 = current;
        }

        return prev1;
    }
}

替代方案

  • 完整一维 DP：保存长度 n+1 的数组，更直观，也方便回溯具体路径；额外空间为 O(n)。
  • 从后向前：令状态表示“从第 i 阶出发到顶部的最低花费”，最后取起点 0 与 1 的较小值。
  • 记忆化搜索：递归表达自然，但需要递归栈和缓存；本题线性依赖下迭代更简洁。

面试追问

  • 如果每次能走 1 到 k 阶，转移式如何变化？

  • 如果费用可能为负数，当前迭代是否仍然成立？为什么？
  • 为什么贪心地选择眼前费用更低的台阶不可靠？

常见错误

  • 把“到达台阶”与“离开台阶时付费”混在一起，导致费用重复或漏算。
  • 忘记可以从下标 1 起步，把初始状态错误地设为 dp[1]=cost[0]。
  • 只计算到 n−1，却没有把虚拟顶部 n 纳入状态。
  • 滚动变量更新顺序错误，覆盖了仍要使用的旧状态。

一分钟复盘

状态选“到达位置的最低花费”，最后一步只有两个来源，顶部看作位置 n。由于每次只依赖前两个状态，完整 DP 数组可以压缩成两个变量。
