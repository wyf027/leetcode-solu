LeetCode 2272 · Substring With Largest Variance

最大波动的子字符串

从一段连续字符中，寻找出现次数的最大落差。

字符串动态规划枚举

01 / 题目

给定只含小写英文字母的字符串 s。对任意非空连续子字符串，只统计在其中实际出现的字符，将最多出现次数减去最少出现次数，得到它的“波动”。返回所有子字符串中最大的波动值。

两个被比较的字符允许相同，因此只有一种字符的子字符串波动为 0。不存在的字符不能作为出现 0 次的最少字符。

官方示例 1

输入：s = "aababbb"
输出：3

选择连续片段 "babbb"：b 出现 4 次，a 出现 1 次，波动为 4 − 1 = 3，没有更大的值。

官方示例 2

输入：s = "abcde"
输出：0

每个字符最多出现一次，任意子字符串内已出现字符的次数相等。

参数与约束

  • largestVariance(s) → integer，唯一参数 s 为字符串。
  • 1 ≤ s.length ≤ 10⁴。
  • s 仅包含小写英文字母 a–z。

04 / 独立题解

包含核心思路、双状态演示、证明与可提交代码。

核心洞察：固定一个有序字符对

枚举不同字符 (a, b)，令 a 贡献 +1，b 贡献 −1，其余字符贡献 0。目标成为：求一个至少包含一次 b的连续片段的最大权重和。这里的 a、b 是角色名，可以分别选择任意字母。

不能直接使用普通最大子段和：它可能选出只有 a 的片段，遗漏“减数也必须出现”的限制。维护两条状态轨道即可保留该限制。

  • free：当前前缀的最大后缀权重和，允许空后缀，初始为 0。
  • valid：当前前缀中至少含一个 b 的非空后缀的最大权重和，初始为 −∞。

valid 允许暂时为负数，例如扫描开头的 b 时为 −1。必须保留它，后续连续的 a 可以将它变成最优解。答案从 0 开始，因而仅含 b 的负值不会被当作答案。

完整过程与状态转移

  1. 收集 s 中出现过的字符，枚举所有不同的有序对 (a,b)。顺序必须区分。
  2. 每一对从 free = 0, valid = −∞ 开始，自左向右扫描原字符串。
  3. 遇到 a：free += 1; valid += 1。−∞ 加一仍视为不可达。
  4. 遇到 b：先用旧 free 算 valid = max(valid − 1, free − 1)，再算 free = max(0, free − 1)。
  5. 遇到其他字符：两个状态不变；该字符仍可在连续片段内部，并没有改变原字符串的连续性。
  6. 每一步以 valid 更新全局答案；枚举结束返回答案。

示例取 a=b（字母 b 扮演 +1）、b=a（字母 a 扮演 −1）：权重序列为 −1, −1, +1, −1, +1, +1, +1。valid 依次为 −1, −1, 0, 0, 1, 2, 3，最终由片段 "babbb" 得到 3。

为什么正确

状态归纳。free 可以扩展旧的最优后缀，也可以从空后缀重新开始。遇到 +1 时扩展一定不差；遇到 −1 时与 0 取最大。valid 在遇到 a 或中立字符时只能扩展已有合法后缀；遇到 b 时，既可扩展旧 valid，也可给旧 free 接上当前 b。后者包含“从当前 b 开始”，因为 free 允许空后缀。这穷尽所有后缀，因此两状态始终保持定义。

从后缀到任意片段。任意连续片段都是某个前缀的后缀。逐位置取 valid 的最大值，即得到该字符对所有含 b 片段的最佳分数。分数大于 0 时必然同时含 a 与 b；非正分数由初始答案 0 覆盖。

从字符对到波动。任意片段的最高频与最低频字符都在枚举范围内，该有序对的次数差恰为片段波动。反过来，任意合法字符对的次数差不会超过该片段的波动。因此枚举最大值恰为题目答案。

边界与复杂度

  • 只有一种字符或长度为 1：没有不同字符对，返回 0。
  • 减数字符只在开头出现：保留负 valid，不能随意清零。
  • 减数字符只在末尾出现：free 积累此前所有正贡献，遇到 b 再转为合法状态。
  • 所有字符各出现一次：答案为 0。

令 n 为长度，k 为不同字符数。时间 O(n + k(k−1)n)，最坏为 O(26²n)；额外空间 O(k)，固定字母表下为 O(1)。交互演示保存逐步记录，其空间为 O(n)，不属于提交算法。

替代方案

计数版 Kadane：对每个字符对维护两类计数及剩余减数字符数。差值为负且后面还有减数时才重置，否则可能丢失唯一的减数。复杂度相同，但重置条件更易出错。

枚举全部子字符串：增量维护 26 个字符频次，逐片段计算最大与最小非零频次，时间 O(26n²)。思路直观，无法适应长度 10⁴。

常见错误

  • 把未出现的字母按 0 次参与比较，误把纯重复字符串的长度当作波动。
  • 只枚举无序对，漏掉另一种“谁加谁减”的方向。
  • 将 valid 初始化为 0，导致没有 b 的片段被误判为合法。
  • 先更新 free 再更新 valid，在 b 处错误地使用新状态。
  • 跳过其他字符后，把过滤序列的下标直接当作原字符串边界。
  • 因为 valid 是负数就丢弃：例如 "baaaa" 会丢失必要的首个 b。

面试追问

怎样返回片段本身？为 free、valid 同步维护起点，选择继承分支时同步继承起点，更新全局答案时记录起止下标。

若字符集很大？k² 枚举将成为瓶颈；先限制为实际出现的字符，再讨论频次剪枝与输入分布，不能继续把字母表视为常数。

为什么不用固定滑动窗口？增加或删除字符都可能提高或降低次数差，且必须保留减数字符，没有直接支持单调收缩的判定条件。

四语言完整实现

Java

class Solution {
    public int largestVariance(String s) {
        int n = s.length(), ans = 0;
        boolean[] seen = new boolean[26];
        for (int i = 0; i < n; i++) seen[s.charAt(i) - 'a'] = true;
        for (int a = 0; a < 26; a++) {
            if (!seen[a]) continue;
            for (int b = 0; b < 26; b++) {
                if (a == b || !seen[b]) continue;
                int free = 0, valid = -n;
                for (int i = 0; i < n; i++) {
                    int c = s.charAt(i) - 'a';
                    if (c == a) {
                        free++;
                        valid++;
                    } else if (c == b) {
                        valid = Math.max(valid - 1, free - 1);
                        free = Math.max(0, free - 1);
                    }
                    ans = Math.max(ans, valid);
                }
            }
        }
        return ans;
    }
}

                        valid = max(valid - 1, free - 1);
                        free = max(0, free - 1);
                    }
                    ans = max(ans, valid);
                }
            }
        }
        return ans;
    }
};
