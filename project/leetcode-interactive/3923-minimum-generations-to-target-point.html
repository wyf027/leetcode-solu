得到目标点的最少代数

把三维点看成一个很小的“可达状态宇宙”：每一代用所有已出现的不同点两两取坐标向下取整的中点。目标第一次出现的代数，就是答案。

题意

从已有点不断生成新点

第 0 代是 points。对每个后续代数，取此前所有代已经出现的两个不同点 a、b，生成 floor((a + b) / 2)（三个坐标分别计算）。返回 target 最早出现的代数；永远无法出现则返回 -1。

约束很小：初始点最多 20 个，坐标和目标坐标都在 0 到 6。因此整个状态空间至多 7³ = 343 个点。

题解

有限状态上的最短“代数”松弛

核心洞察：若点 p 最早在 dp 代出现、q 最早在 dq 代出现，那么中点最早可在 max(dp,dq)+1 代出现。维护每个点的最早代数，反复枚举当前可达点对并松弛即可。只有 343 个状态，稳定时答案就是 target 的最早代数。

完整过程

  1. 把初始点的距离设为 0。
  2. 枚举任意两个不同的已知点。
  3. 计算三个坐标的整数中点，尝试用 max + 1 更新。
  4. 没有更新后停止；查询目标。

边界与复杂度

  • 目标在初始集合中：0。
  • 只有一个点或稳定后仍不可达：-1。
  • 状态至多 V=343，朴素松弛约 O(V³)，空间 O(V)。

替代方案与面试追问

也可按真实代数做集合模拟，表达直观但会重复扫描更多点。追问若坐标范围扩大，可用优先队列按最早代数扩展，并对点编码去重。

常见错误

  • 把“本代新增点”提前用于本代组合；题目要求同一代同步产生。
  • 允许一个点和自己配对；题目要求两个不同点。
  • 对负坐标误用语言的截断除法；本题坐标非负，因此整数除法等价于 floor。
