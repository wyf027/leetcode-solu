Problem brief

先读任务，不展开题解

连接只允许上下左右。需要直接修改原矩阵，不返回新矩阵；边界上的 O 及与它连通的 O 不能被捕获。

题意转述

给定 m × n 字符矩阵 board。如果一个由 O 组成的连通区域没有任何格子落在矩阵边界上，它就被 X 完全围住，应把该区域内所有 O 原地改成 X。

  • 01 连接：只看上、下、左、右，不包含对角线。
  • 02 保留：边界 O 以及能走到边界 O 的整个区域。
  • 03 捕获：其余 O 全部原地改为 X。

可见空格约定：字符串中的普通空格统一显示为 “␠”；本题字符仅为成对直引号包裹的 “X” 和 “O”，输入中没有普通空格字符。

解释

    多源 BFS：从边界反向标记不会被捕获的 O

    核心洞察

    直接判断每个 O 区域是否封闭，需要反复搜索。反过来更简单：所有“不应被捕获”的 O，必然与某个边界 O 连通。把四条边界上的 O 同时放入队列，BFS 标成临时字符 S；扫描结束后，剩余 O 就一定被围住。

    为什么主线选 BFS

    BFS 与 DFS 的渐进复杂度相同，但本题最多有 40,000 个格子；递归 DFS 在部分语言中可能触发调用栈上限。显式队列的多源 BFS 更稳健，也更容易解释“从所有边界同时扩散”。

    完整过程

    1. 枚举首尾两行、首尾两列；遇到 O 立刻改成 S，并入队。
    2. 不断弹出队首，检查上下左右；相邻 O 改成 S 后入队。入队时标记可避免重复。
    3. 遍历整个矩阵：仍为 O 的格子无法到达边界，改成 X。
    4. 把临时标记 S 还原为 O，完成原地修改。

    边界情况

    • 只有一行或一列：所有 O 都在边界，全部保留。
    • 全是 X：队列始终为空，矩阵不变。
    • 全是 O：所有格子都与边界连通，全部保留。
    • 对角相邻不算连通；只有上下左右能传播安全标记。
    • 首尾行列的四个角可能重复枚举，入队即标记可自然去重。

    复杂度

    时间 O(m × n) 每个格子最多入队和扫描常数次。
    空间 O(m × n) 最坏情况下队列容纳大量边界连通 O。

    替代方案取舍

    • 递归 DFS：代码短，但深链可能栈溢出。
    • 显式栈 DFS：同样稳健，顺序不同，思路完全等价。
    • 并查集：可连接虚拟边界节点，但代码和额外空间更大，本题一次性处理不划算。
    • 逐区域搜索：若不缓存访问结果，容易退化并重复工作。

    面试追问

    • 如果对角线也算连通，只需把方向数组扩展为八个方向。
    • 如果不能修改输入，可额外维护 visited 布尔矩阵。
    • 如果要返回捕获数量，在最终扫描 O → X 时计数。
    • 若矩阵极大且无法整体载入，需要外存/分块连通性方案，普通 BFS 不再足够。

    常见错误

    • 从内部 O 出发判断，遗漏区域共享结果并造成重复搜索。
    • 出队时才标记，导致同一 O 被多个邻居重复入队。
    • 只扫描四个角，漏掉边界其余 O。
    • 把对角线 O 当作连通。
    • 最终只做 O → X，却忘记把 S 还原为 O。

    import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    private static final int[][] DIRECTIONS = {
        {1, 0}, {-1, 0}, {0, 1}, {0, -1}
    };

    public void solve(char[][] board) {
        int rows = board.length;
        int cols = board[0].length;
        Queue<int[]> queue = new ArrayDeque<>();

        for (int row = 0; row < rows; row++) {
            enqueue(board, row, 0, queue);
            enqueue(board, row, cols - 1, queue);
        }
        for (int col = 0; col < cols; col++) {
            enqueue(board, 0, col, queue);
            enqueue(board, rows - 1, col, queue);
        }

        while (!queue.isEmpty()) {
            int[] cell = queue.remove();
            for (int[] direction : DIRECTIONS) {
                int nextRow = cell[0] + direction[0];
                int nextCol = cell[1] + direction[1];
                enqueue(board, nextRow, nextCol, queue);
            }
        }

        for (int row = 0; row < rows; row++) {
            for (int col = 0; col < cols; col++) {
                if (board[row][col] == 'O') {
                    board[row][col] = 'X';
                } else if (board[row][col] == '#') {
                    board[row][col] = 'O';
                }
            }
        }
    }

    private void enqueue(
        char[][] board,
        int row,
        int col,
        Queue<int[]> queue
    ) {
        if (
            row < 0 || row >= board.length ||
            col < 0 || col >= board[0].length ||
            board[row][col] != 'O'
        ) {
            return;
        }
        board[row][col] = '#';
        queue.offer(new int[] {row, col});
    }
}

    from collections import deque
from typing import List


class Solution:
    def solve(self, board: List[List[str]]) -> None:
        rows, cols = len(board), len(board[0])
        queue = deque()

        def enqueue(row: int, col: int) -> None:
            if (
                row < 0
                or row >= rows
                or col < 0
                or col >= cols
                or board[row][col] != "O"
            ):
                return
            board[row][col] = "#"
            queue.append((row, col))

        for row in range(rows):
            enqueue(row, 0)
            enqueue(row, cols - 1)
        for col in range(cols):
            enqueue(0, col)
            enqueue(rows - 1, col)

        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
        while queue:
            row, col = queue.popleft()
            for dr, dc in directions:
                enqueue(row + dr, col + dc)

        for row in range(rows):
            for col in range(cols):
                if board[row][col] == "O":
                    board[row][col] = "X"
                elif board[row][col] == "#":
                    board[row][col] = "O"
