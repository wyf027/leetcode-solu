递增顺序搜索树

将二叉搜索树原地重排为只有右孩子的递增链：节点仍是原节点，中序遍历的顺序就是链表顺序。

题意

给定一棵二叉搜索树 root，按递增顺序重新排列。结果中每个节点都没有左孩子，并且每个节点的右孩子是下一个更大的节点。

示例

输入层序：5,3,6,2,4,null,8,1,null,null,null,7,9

输出链：1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9

约束

节点数范围为 1 到 100；节点值互不相同，且二叉搜索树的中序遍历严格递增。

交互实验室

用层序输入一棵 BST，逐步观察中序遍历如何把节点接到右侧链上。空节点使用 null。

载入示例后开始观察。

    测试与验证

    快速生成模式：UI、算法对拍、四语言编译和交互验收待补。

    核心洞察

    二叉搜索树的中序遍历会按从小到大的顺序访问节点。用一个哑节点 dummy 作为新链的起点；每访问一个节点，就清空它的左指针并接到 tail.right，随后让 tail 前进。

    完整过程

    1. 从根开始，反复沿左边界入栈。
    2. 弹出栈顶：它是当前最小的未处理节点。
    3. 令 tail.right = node、node.left = null，再把 tail 移到该节点。
    4. 转向弹出节点的右子树，重复以上过程，最后返回 dummy.right。

    边界与常见错误

    • 必须清空每个节点的左孩子，否则结果不是纯右链。
    • 用哑节点避免“第一个节点该如何初始化尾指针”的特殊分支。
    • 不要新建值相同的节点；题目要求重用原节点。

    复杂度：每个节点入栈、出栈各一次，时间 O(n)，显式栈空间 O(h)，h 为树高。若使用递归，同样的调用栈深度为 O(h)。

    替代方案：递归中序遍历也能完成重连，代码更短，但极度倾斜的树会让递归调用变深；显式栈则避免了语言递归深度限制。面试追问：若不能修改原树，可新建节点形成链，但空间会从 O(h) 增至 O(n)。

    可提交代码

    Java

    class Solution {
    public TreeNode increasingBST(TreeNode root) {
        TreeNode dummy = new TreeNode(0), tail = dummy;
        Deque<TreeNode> stack = new ArrayDeque<>();
        while (root != null || !stack.isEmpty()) {
            while (root != null) { stack.push(root); root = root.left; }
            root = stack.pop();
            tail.right = root; root.left = null; tail = root;
            root = root.right;
        }
        return dummy.right;
    }
}

    class Solution:
    def increasingBST(self, root: TreeNode) -> TreeNode:
        dummy = tail = TreeNode(0)
        stack = []
        while root or stack:
            while root:
                stack.append(root)
                root = root.left
            root = stack.pop()
            tail.right = root
            root.left = None
            tail = root
            root = root.right
        return dummy.right

    C++

    class Solution {
public:
    TreeNode* increasingBST(TreeNode* root) {
        TreeNode dummy(0), *tail = &dummy;
        stack<TreeNode*> st;
        while (root || !st.empty()) {
            while (root) { st.push(root); root = root->left; }
            root = st.top(); st.pop();
            tail->right = root; root->left = nullptr; tail = root;
            root = root->right;
        }
        return dummy.right;
    }
};
