移除子数组元素后第 K 小偶数

把无限偶数序列的“删除”转化为：有序删除编号中，有多少个值会把第 k 个保留位置向右推。

题意

给定严格递增数组 nums。每个查询 queries[i] = [l, r, k] 会从正偶数序列 2, 4, 6, ... 中删除 nums[l..r] 里出现的偶数；返回删除后的第 k 小偶数。

示例：nums = [2,5,8]，l = 0, r = 1, k = 2。删除 2 后，保留序列为 4, 6, 8, ...，答案为 6。

交互：删除如何推移排名

演示固定查询 [l=0, r=1, k=2]

第 1 步：标记子数组中需要删除的偶数。

题解：删除编号的 rank 补偿

只保留 nums 中的偶数，并除以 2，得到被删除的正整数编号 removed。对某个查询，二分找到该子数组对应的连续段 removed[a..b)。

关键判定：如果该段第 p 个删除编号为 v（段内从 1 开始），则它在删除前有 v - p 个未删除编号。它应计入对第 k 个保留数的右移，当且仅当 v - p < k。二分最大的满足位置，答案编号为 k + p，最终偶数为 2 * (k + p)。

完整过程

  1. 预处理偶数的原数组位置 pos 与半值 val = nums[i] / 2。
  2. 对 [l,r,k]，在 pos 二分出 [a,b)。
  3. 在该段内二分最大 mid，满足 val[mid] - (mid-a+1) < k。
  4. 返回 2 * (k + (mid-a+1))；没有满足项时直接返回 2*k。

边界与复杂度

子数组可能没有偶数；k 可达 1e9，使用 64 位整数。每次查询三次二分，时间 O(log n)，预处理 O(n)，空间 O(n)。

替代方案 / 面试追问 / 常见错误

可对答案值二分并做区间计数，但会多一层 log。追问：若 nums 不再有序，可离线排序并处理原索引。常见错误：删除奇数、把 < k 写成 <= k、以及用 32 位整数计算最终答案。

class Solution {
  public long[] kthSmallest(int[] nums, int[][] queries) {
    int n = nums.length, m = 0; for (int x : nums) if ((x & 1) == 0) m++;
    int[] pos = new int[m]; long[] val = new long[m];
    for (int i=0,j=0;i<n;i++) if ((nums[i]&1)==0) { pos[j]=i; val[j++]=nums[i]/2L; }
    long[] ans = new long[queries.length];
    for (int qi=0;qi<queries.length;qi++) { int l=queries[qi][0],r=queries[qi][1]; long k=queries[qi][2];
      int a=lower(pos,l), b=upper(pos,r), lo=a, hi=b-1, best=a-1;
      while(lo<=hi){int mid=(lo+hi)>>>1; if(val[mid]-(mid-a+1)<k){best=mid;lo=mid+1;}else hi=mid-1;}
      ans[qi]=2L*(k+best-a+1);
    } return ans;
  }
  int lower(int[] a,int x){int l=0,r=a.length;while(l<r){int m=(l+r)>>>1;if(a[m]<x)l=m+1;else r=m;}return l;}
  int upper(int[] a,int x){int l=0,r=a.length;while(l<r){int m=(l+r)>>>1;if(a[m]<=x)l=m+1;else r=m;}return l;}
}

class Solution:
    def kthSmallest(self, nums: list[int], queries: list[list[int]]) -> list[int]:
        pos = [i for i,x in enumerate(nums) if x % 2 == 0]
        val = [nums[i] // 2 for i in pos]
        ans = []
        for l,r,k in queries:
            a,b = bisect_left(pos,l),bisect_right(pos,r)
            lo,hi,best = a,b-1,a-1
            while lo <= hi:
                mid=(lo+hi)//2
                if val[mid]-(mid-a+1) < k: best,lo=mid,mid+1
                else: hi=mid-1
            ans.append(2*(k+best-a+1))
        return ans
