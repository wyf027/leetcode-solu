强整数

Powerful Integers — 在有限边界内，让两条指数序列相遇。先读题并亲手观察枚举过程，再决定是否展开完整题解。

题目

给定整数 x、y 和 bound。找出所有不超过 bound、且可写成 xⁱ + yʲ 的整数，其中 i ≥ 0、j ≥ 0。结果顺序任意，但每个数最多出现一次。

函数签名

powerfulIntegers(x: integer, y: integer, bound: integer) → list<integer>

示例 1

输入：x = 2, y = 3, bound = 10
输出：[2,3,4,5,7,9,10]
解释：2=2⁰+3⁰，3=2¹+3⁰，4=2⁰+3¹，5=2¹+3¹，7=2²+3¹，9=2³+3⁰，10=2⁰+3²。

示例 2

输入：x = 3, y = 5, bound = 15
输出：[2,4,6,8,10,14]

约束

  • 1 ≤ x, y ≤ 100
  • 0 ≤ bound ≤ 10⁶

完整题解

核心洞察

底数大于 1 时，幂值按指数快速增长，不超过 bound 的幂只有对数级个；底数等于 1 时所有幂恒为 1，必须只枚举一次。枚举两组幂的笛卡尔积，用集合自然去重。

完整过程

  1. 从 a=1=x⁰ 开始枚举 x 的幂。
  2. 对每个 a，从 b=1=y⁰ 开始枚举 y 的幂。
  3. 若 a+b ≤ bound，放入集合；否则内层停止。
  4. 底数为 1 时立刻停止该维，否则继续乘底数；最后返回集合。

正确性

完备性：循环访问所有可能产生有效和的幂对，因此每个不超过边界的强整数都会被加入。可靠性：只有形如 xⁱ+yʲ 且不超过边界的值才会加入。集合又保证每个值至多出现一次，所以结果恰好满足题意。

边界

  • bound < 2 时为空，因为两个零次幂之和至少是 2。
  • x=1 或 y=1 时必须终止对应维，避免无限循环。
  • 不同指数对可能产生相同的和，必须按结果去重。

复杂度

令 A 为不超过边界的 x 幂数量（x=1 时为 1），B 同理。时间 O(A·B)，集合空间 O(A·B)；当底数大于 1 时，A、B 分别为对数级。

替代方案

可以先生成两张幂数组再组合，可读性更强但额外使用 O(A+B) 空间；也可以收集后排序去重，但哈希集合更直接。双指针无法代替完整的二维组合枚举。

面试追问

  • 为何和超界后能停止内层？因为幂序列单调不减。
  • 如何避免乘法溢出？乘前判断当前值是否大于 bound/base，或使用更宽整数。
  • 若要求升序？把集合转为数组后排序。

常见错误

  • 指数从 1 开始，漏掉零次幂。
  • 忘记底数 1 的特判，造成死循环。
  • 没有对最终的整数值去重。
  • 使用未经证明的固定指数上限。

import java.util.*;

class Solution {
    public List<Integer> powerfulIntegers(int x, int y, int bound) {
        Set<Integer> values = new HashSet<>();
        for (long a = 1; a <= bound; a *= x) {
            for (long b = 1; a + b <= bound; b *= y) {
                values.add((int) (a + b));
                if (y == 1) break;
            }
            if (x == 1) break;
        }
        return new ArrayList<>(values);
    }
}
