驼峰式匹配

Camelcase Matching：判断一个查询词，能否仅通过向模式串插入小写英文字母得到。先亲手观察字符流，再决定是否展开题解。

题目

给定字符串数组 queries 和模式串 pattern，返回布尔数组 answer。当且仅当可以在 pattern 的任意位置插入零个或多个小写英文字母，使其变成 queries[i] 时，对应答案为 true。

关键限制：允许多出来的小写字母，但任何无法与模式对应的额外大写字母都会让匹配失败。

函数形式

camelMatch(queries: string[], pattern: string) → boolean[]

约束

  • 1 ≤ pattern.length, queries.length ≤ 100
  • 1 ≤ queries[i].length ≤ 100
  • 所有字符串只含英文字母。

官方示例

示例 1 输入：queries = ["FooBar","FooBarTest","FootBall","FrameBuffer","ForceFeedBack"], pattern = "FB" 输出：[true,false,true,true,false] 说明：如 "FooBar" = "F" + "oo" + "B" + "ar"，插入部分均为小写。
示例 2 输入：queries = ["FooBar","FooBarTest","FootBall","FrameBuffer","ForceFeedBack"], pattern = "FoBa" 输出：[true,false,true,false,false] 说明："FooBar" 与 "FootBall" 均可由模式插入小写字母得到。
示例 3 输入：queries = ["FooBar","FooBarTest","FootBall","FrameBuffer","ForceFeedBack"], pattern = "FoBaT" 输出：[false,true,false,false,false] 说明：只有 "FooBarTest" 能按顺序保留模式字符，且其余字符均为小写。

题解：双指针扫描

核心洞察

模式字符必须按原顺序全部出现在查询词中。扫描查询词时，当前字符若等于下一个模式字符就消耗它；否则，这个字符只有是小写时才可视作“插入字符”跳过。多余大写字母无法由题目允许的操作产生，因此立即失败。

完整过程

为每个查询词设置模式指针 j = 0。
从左到右读取查询字符 c。若 j < pattern.length 且 c == pattern[j]，令 j++。
否则若 c 是大写字母，立即判定该查询不匹配；若为小写则直接略过。
查询扫描完后，仅当未失败且 j == pattern.length 时匹配成功。

正确性说明

必要性

合法插入只新增小写字母，所以查询中的每个未与模式对齐的大写字符都不可能出现。

顺序性

双指针只向右移动，匹配到的模式字符顺序与模式完全一致。

充分性

若模式全部被消耗且其余字符都是小写，那么这些其余字符正可依次插入模式得到查询词。

边界情况

  • 模式字符尚未全部匹配，查询词却已结束：失败。
  • 模式匹配完后还有小写字母：允许；还有大写字母：失败。
  • 大小写敏感，a 与 A 不相等。
  • 查询与模式完全相同：成功。

复杂度

设所有查询词的总字符数为 S。时间复杂度 O(S)；除输出外，额外空间复杂度 O(1)。

替代方案

可用动态规划定义“查询前缀能否匹配模式前缀”，复杂度通常为 O(nm)；也可先提取大写骨架辅助判断，但仍需验证全部模式字符的顺序。双指针最直接且空间更小。

面试追问

  • 如果允许插入任意字符而不只是小写，规则会退化为普通子序列判断。
  • 若同一模式要匹配海量查询，可并行扫描查询；若模式集合也很大，可讨论自动机或 Trie。
  • 若输入包含 Unicode，语言自带的大小写判断与按码点迭代需要谨慎处理。

常见错误

  • 只判断模式是不是查询词的子序列，漏掉额外大写字母。
  • 模式已经匹配完就直接返回 true，没扫描查询词剩余部分。
  • 用宽泛的字母判断处理题目限定的 ASCII 英文字母，造成不必要差异。

class Solution {
    public List<Boolean> camelMatch(String[] queries, String pattern) {
        List<Boolean> answer = new ArrayList<>();
        for (String query : queries) answer.add(matches(query, pattern));
        return answer;
    }

    private boolean matches(String query, String pattern) {
        int j = 0;
        for (int i = 0; i < query.length(); i++) {
            char c = query.charAt(i);
            if (j < pattern.length() && c == pattern.charAt(j)) {
                j++;
            } else if (c >= 'A' && c <= 'Z') {
                return false;
            }
        }
        return j == pattern.length();
    }
}

var camelMatch = function(queries, pattern) {
    const matches = (query) => {
        let j = 0;
        for (const c of query) {
            if (j < pattern.length && c === pattern[j]) {
                j++;
            } else if (c >= 'A' && c <= 'Z') {
                return false;
            }
        }
        return j === pattern.length;
    };
    return queries.map(matches);
};
from typing import List

class Solution:
    def camelMatch(self, queries: List[str], pattern: str) -> List[bool]:
        def matches(query: str) -> bool:
            j = 0
            for char in query:
                if j < len(pattern) and char == pattern[j]:
                    j += 1
                elif 'A' <= char <= 'Z':
                    return False
            return j == len(pattern)

        return [matches(query) for query in queries]
class Solution {
public:
    vector<bool> camelMatch(vector<string>& queries, string pattern) {
        vector<bool> answer;
        for (const string& query : queries) {
            int j = 0;
            bool ok = true;
            for (char c : query) {
                if (j < pattern.size() && c == pattern[j]) {
                    ++j;
                } else if (c >= 'A' && c <= 'Z') {
                    ok = false;
                    break;
                }
            }
            answer.push_back(ok && j == pattern.size());
        }
        return answer;
    }
};
