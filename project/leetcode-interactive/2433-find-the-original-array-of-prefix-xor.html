找出前缀异或的
原始数组

Find The Original Array of Prefix Xor

一串累计后的数值，能否唯一还原它的起点与每一步？

01问题描述

给定整数数组 pref，长度为 n。请返回同样长度的整数数组 arr，使 pref 的第 i 个元素等于 arr 从下标 0 到下标 i 的所有元素按位异或的结果。

pref[i] = arr[0] ^ arr[1] ^ ... ^ arr[i]

^ 表示按位异或：每个二进制位相同为 0，不同为 1。题目保证满足条件的原始数组是唯一的。

参数与返回值

findArray(pref: integer[]) → integer[]

数组使用从 0 开始的下标。

官方约束

  • 1 ≤ pref.length ≤ 105
  • 0 ≤ pref[i] ≤ 106

02官方示例

示例 1 · 多个前缀

输入：pref = [5,2,0,3,1]
输出：[5,7,2,3,2]

用返回的数组重新累计异或，即可得到输入：

pref[0] = 5
pref[1] = 5 ^ 7 = 2
pref[2] = 5 ^ 7 ^ 2 = 0
pref[3] = 5 ^ 7 ^ 2 ^ 3 = 3
pref[4] = 5 ^ 7 ^ 2 ^ 3 ^ 2 = 1

示例 2 · 只有一个数

输入：pref = [13]
输出：[13]

唯一的前缀只包含一个元素，所以 pref[0] = arr[0] = 13。

先想一想：当一位的输入与累计结果已知时，另一位是否也被确定？

04独立题解

准备好后，展开推导、交互演示与四语言实现。

相邻前缀，消去重复部分

核心洞察

异或满足交换律、结合律，并且 x ^ x = 0、x ^ 0 = x。相邻两个前缀有同一段开头，把它们异或后，这段开头每个元素都出现两次并抵消，只剩下新加入的元素。

arr[0] = pref[0]
arr[i] = pref[i - 1] ^ pref[i]    (i ≥ 1)

例：arr[1] = pref[0] ^ pref[1]
           = arr[0] ^ (arr[0] ^ arr[1])
           = 0 ^ arr[1]

位轨道 · 前缀解码器

每一步还原一个元素

每个元素为 0 至 1000000 的整数。演示长度限制仅用于阅读，算法支持题目完整约束。

完整过程

  1. 创建长度为 n 的答案数组，把 pref[0] 放入 arr[0]。
  2. 从 i = 1 遍历到 n - 1，计算原输入中相邻两项的异或。
  3. 每次写入一个答案元素，最后返回 arr。整个过程不修改 pref。
pref = [5, 2, 0, 3, 1]
i = 0：直接取 5       → [5]
i = 1：5 ^ 2 = 7     → [5,7]
i = 2：2 ^ 0 = 2     → [5,7,2]
i = 3：0 ^ 3 = 3     → [5,7,2,3]
i = 4：3 ^ 1 = 2     → [5,7,2,3,2]

正确性与唯一性

记构造结果的累计异或为 S[i]。基础情形：S[0] = arr[0] = pref[0]。假设 S[i-1] = pref[i-1]，则 S[i] = S[i-1] ^ arr[i] = pref[i-1] ^ (pref[i-1] ^ pref[i]) = pref[i]。归纳可得所有前缀都满足定义。

另一方面，任何合法答案的首项必须是 pref[0]，后续每项必须由等式 pref[i-1] ^ arr[i] = pref[i] 唯一解出。因此构造结果既存在又唯一。

边界与数值范围

  • n = 1 时直接返回首项，没有相邻元素可处理。
  • 相邻前缀相等时，对应原元素为 0。
  • 0 参与异或保留另一操作数，不需要特殊分支。
  • 输入小于 2²⁰，结果最多为 2²⁰ − 1；结果不必满足 pref 的 10⁶ 上界。
  • JavaScript 的按位运算使用 32 位有符号整数，本题范围可安全表示。

复杂度

时间 O(n)：每个元素处理一次。

空间 O(n)：新建返回数组；除返回数组外，辅助空间 O(1)。

替代方案

如果允许修改 pref，可从右向左执行 pref[i] ^= pref[i-1]，返回同一个数组，额外空间 O(1)。必须倒序，以免读取已被覆盖的前缀。也可正序遍历并额外保存修改前的前一项。

四语言完整实现

均采用保留输入的新数组方案，使用官方 findArray 签名。代码尚未执行验证。

Java

class Solution {
    public int[] findArray(int[] pref) {
        int n = pref.length;
        int[] arr = new int[n];
        arr[0] = pref[0];
        for (int i = 1; i < n; i++) {
            arr[i] = pref[i - 1] ^ pref[i];
        }
        return arr;
    }
}

        vector<int> arr(n);

常见错误

  • 把 ^ 当成乘方或普通加减法；这里是逐位异或。
  • 误写 arr[i-1] ^ pref[i]：需要的是前一个完整前缀，而非前一个原元素。
  • 新数组法从 i = 0 套用通式，访问不存在的 pref[-1]；首项单独赋值。
  • 原地正序覆盖后继续读 pref[i-1]，破坏了前缀信息。
  • 将新建答案数组的总空间复杂度写成 O(1)；应明确是否排除输出空间。

面试追问

  • 能处理流式输入吗？能。仅保存前一个 pref 值，新前缀到达即可输出对应 arr 值，首项直接输出。
  • 能推导区间异或吗？能。arr[l..r] 的异或等于 pref[r] ^ pref[l-1]；l = 0 时直接取 pref[r]。
  • 前缀 AND/OR 也能唯一逆推吗？通常不能，它们丢失信息，例如前缀 OR 为 [1,1]，原数组可以是 [1,0] 或 [1,1]。
  • 数字扩展到超过 32 位时呢？JavaScript 应使用 BigInt 并保持操作数类型一致；其他语言也要选择足够宽的整数类型。
