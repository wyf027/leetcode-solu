设计一个支持增量操作的栈

Design a Stack With Increment Operation

先理解四种操作的外部行为，再用交互时间轴观察容量限制、栈底批量增加与空栈返回值。完整实现放在页面底部，默认收起。

题目说明

设计 CustomStack 类，维护一个最多容纳 maxSize 个整数的栈，并支持以下操作：

  • CustomStack(int maxSize)：以最大容量 maxSize 初始化栈。
  • void push(int x)：栈未满时把 x 压入栈顶；栈满时忽略本次操作。
  • int pop()：弹出并返回栈顶元素；空栈返回 -1。
  • void increment(int k, int val)：让栈底最多 k 个元素各增加 val；若元素不足 k 个，则全部增加。

官方示例：输入

["CustomStack","push","push","pop","push","push","push","increment","increment","pop","pop","pop","pop"]
[[3],[1],[2],[],[2],[3],[4],[5,100],[2,100],[],[],[],[]]

官方示例：输出

[null,null,null,2,null,null,null,null,null,103,202,201,-1]

容量为 3，故 push(4) 被忽略；两次 increment 分别作用于全部 3 个、栈底 2 个元素。

约束

  • 1 <= maxSize, x, k <= 1000
  • 0 <= val <= 100
  • increment、push、pop 每种方法分别最多调用 1000 次。

完整题解

包含懒增量机制、证明、复杂度与四语言实现。

核心洞察：把批量增加延迟到弹出时

直接修改栈底 k 个元素需要 O(k)。可以额外维护数组 add：add[i] 表示一笔“作用到下标 0..i”的待结算增量。执行 increment(k, val) 时，只需把 val 记在当前受影响区间的最高位置 min(k, size)-1。

弹出下标 i 的元素时，返回 stack[i] + add[i]。若下方还有元素，就把 add[i] 传给 add[i-1]；这使同一批增量随着栈顶逐个弹出，最终准确覆盖原本的整段栈底元素。

完整过程

  1. 构造时保存容量，并创建值数组与懒增量数组。
  2. push(x)：未满则压入 x，其新位置的懒增量初始化为 0。
  3. increment(k, val)：若非空，在 min(k, size)-1 处累加 val。
  4. pop()：空栈返回 -1；否则取出顶层值和其懒增量，把增量向下一层传播，再返回两者之和。

正确性证明

不变量：对任一下标 j，该元素尚未结算的总增量，等于从 add[j] 到当前栈顶所有懒标记之和。

increment 保持不变量：在受影响区间最高下标 i 增加 val，恰好使所有 j <= i 的后缀和增加 val，而更高元素不受影响。

pop 保持不变量：栈顶下标 i 的全部未结算增量就是 add[i]，所以返回值正确；把它合并到 add[i-1] 后，下方每个元素对应的总增量不变。由归纳法，所有操作结果均正确。

边界情况

  • 空栈 pop 返回 -1，空栈 increment 不做事。
  • 满栈 push 必须被忽略。
  • k 大于栈大小时，标记落在当前栈顶，表示所有元素都增加。
  • val = 0 时结构仍保持正确。
  • 最后一个元素弹出时没有下层，不传播标记。

复杂度

push、pop、increment 的时间复杂度均为 O(1)；空间复杂度为 O(maxSize)。

替代方案

最直观的数组模拟法在 increment 时循环修改前 min(k, size) 个元素，代码更短，且在本题约束下足够通过，但单次 increment 为 O(k)。懒标记方案在操作次数或容量更大时更稳定。

面试追问

  • 为什么懒标记必须向下传播，而不是向上传播？
  • 如果增加 incrementRange(left, right, val)，如何改成差分结构？
  • 若需要线程安全，哪些操作必须处于同一个临界区？
  • 如果 maxSize 极大但实际元素很少，当前空间分配策略是否合适？

常见错误

  • 用 k-1 直接索引，忘记取 min(k, size)-1。
  • pop 时先删标记，导致无法向下一层传播。
  • 复用数组槽位时没有把懒标记清零。
  • 栈满时仍写入，破坏 maxSize 约束。
  • 返回原值却漏加当前顶层懒标记。

四语言完整实现

class CustomStack {
    private final int maxSize;
    private final int[] stack;
    private final int[] add;
    private int size;

    public CustomStack(int maxSize) {
        this.maxSize = maxSize;
        this.stack = new int[maxSize];
        this.add = new int[maxSize];
        this.size = 0;
    }

    public void push(int x) {
        if (size == maxSize) return;
        stack[size] = x;
        add[size] = 0;
        size++;
    }

    public int pop() {
        if (size == 0) return -1;
        int i = --size;
        int increment = add[i];
        if (i > 0) add[i - 1] += increment;
        add[i] = 0;
        return stack[i] + increment;
    }

    public void increment(int k, int val) {
        int i = Math.min(k, size) - 1;
        if (i >= 0) add[i] += val;
    }
}

var CustomStack = function(maxSize) {

/** @param {number} x @return {void} */
CustomStack.prototype.push = function(x) {
    if (this.stack.length === this.maxSize) return;
    this.stack.push(x);
    this.add.push(0);
};

/** @return {number} */
CustomStack.prototype.pop = function() {
    const i = this.stack.length - 1;
    if (i < 0) return -1;
    const increment = this.add[i];
    if (i > 0) this.add[i - 1] += increment;
    this.add.pop();
    return this.stack.pop() + increment;
};

class CustomStack:
    def __init__(self, maxSize: int):
        self.max_size = maxSize
        self.stack = []
        self.add = []

    def push(self, x: int) -> None:
        if len(self.stack) == self.max_size:
            return
        self.stack.append(x)
        self.add.append(0)

    def pop(self) -> int:
        if not self.stack:
            return -1
        i = len(self.stack) - 1
        increment = self.add[i]
        if i > 0:
            self.add[i - 1] += increment
        self.add.pop()
        return self.stack.pop() + increment

    def increment(self, k: int, val: int) -> None:
        i = min(k, len(self.stack)) - 1
        if i >= 0:
            self.add[i] += val
class CustomStack {
private:
    int maxSize;
    vector<int> stack;
    vector<int> add;

public:
    CustomStack(int maxSize) : maxSize(maxSize) {}

    void push(int x) {
        if (stack.size() == static_cast<size_t>(maxSize)) return;
        stack.push_back(x);
        add.push_back(0);
    }

    int pop() {
        if (stack.empty()) return -1;
        int i = static_cast<int>(stack.size()) - 1;
        int increment = add[i];
        if (i > 0) add[i - 1] += increment;
        int answer = stack.back() + increment;
        stack.pop_back();
        add.pop_back();
        return answer;
    }

    void increment(int k, int val) {
        int i = min(k, static_cast<int>(stack.size())) - 1;
        if (i >= 0) add[i] += val;
    }
};
