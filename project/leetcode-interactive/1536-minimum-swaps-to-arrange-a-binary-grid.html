题目

给定一个 n × n 的二进制网格。每次操作可以交换两条相邻行。

若主对角线以上的所有格子都是 0，网格即为有效。返回把网格变为有效网格所需的最少操作次数；若无法做到，返回 -1。

主对角线从 (1, 1) 延伸至 (n, n)。

目标形态
j > i
grid[i][j] = 0

只能整行交换，且一次只能跨过一条相邻行。

题解：把二维条件压缩成一列数字

对第 i 行（0-based），列 i+1 ... n-1 必须全为 0，因此它至少需要 n-1-i 个末尾连续 0。

核心洞察

一行能否放到某个位置，只取决于末尾连续 0 的数量。
把网格压缩成 trailingZeros[]，从上到下填位置；每次找下方第一条满足要求的行，再用相邻交换将其上移。

将当前第 j 行移动到第 i 行恰好要 j-i 次交换。选择最近的可用行成本最低，并保持其余行的相对顺序。

完整过程

  1. 从右往左扫描每一行，统计末尾连续 0 的数量。
  2. 处理目标位置 i，它需要至少 n-1-i 个末尾 0。
  3. 从 i 向下寻找第一条满足要求的行 j；找不到就返回 -1。
  4. 把该行逐次与上一行交换到位置 i，答案增加 j-i。
  5. 处理完所有位置，返回累计交换次数。

示例 1 的末尾 0 数为 [0,1,2]。第三行先上移两次占据位置 0，原第二行再上移一次占据位置 1，总计 3 次。

正确性证明

条件等价

一行位于 i 时，对角线上方恰好对应其最后 n-1-i 个元素，所以合法当且仅当末尾连续 0 不少于该数。

贪心选择安全

任何合法方案都要从剩余行中选一条满足当前阈值的行。若它位于 k，至少需要 k-i 次相邻交换；算法选最靠上的可行行 j，故当前成本不会更高。上移只让跨过的行整体下移且保持相对顺序，剩余部分仍是同类子问题。逐位置归纳，所得总成本最小。

无解判断

若剩余行没有一条满足当前阈值，根据条件等价性，任何排列都无法填好该位置，因此返回 -1 正确。

边界情况

  • n = 1：对角线上方为空，答案为 0。
  • 初始已有效或全 0：无需交换。
  • 某位置下方没有足够末尾 0 的行：立即返回 -1。
  • 多条相同行：选择最近可行行，不要求行唯一。

复杂度

时间复杂度O(n²)统计、搜索和移动都在二次范围内
空间复杂度O(n)保存各行末尾 0 数量

class Solution {
    public int minSwaps(int[][] grid) {
        int n = grid.length;
        int[] zeros = new int[n];
        for (int i = 0; i < n; i++) {
            for (int j = n - 1; j >= 0 && grid[i][j] == 0; j--) {
                zeros[i]++;
            }
        }
        int answer = 0;
        for (int i = 0; i < n; i++) {
            int need = n - 1 - i;
            int j = i;
            while (j < n && zeros[j] < need) j++;
            if (j == n) return -1;
            answer += j - i;
            while (j > i) {
                zeros[j] = zeros[j - 1];
                j--;
            }
        }
        return answer;
    }
}

class Solution:

        zeros = []
        for row in grid:
            count = 0
            for value in reversed(row):
                if value != 0:
                    break
                count += 1
            zeros.append(count)
        answer = 0
        for i in range(n):

                j += 1
            if j == n:
                return -1

        return answer

替代方案

记录每行最右侧的 1：若最右 1 的下标不大于目标行下标，该行即可放入目标位置，与统计末尾 0 完全等价。

枚举排列或 BFS：行排列有 n! 种状态，只适合极小规模。树状数组：确定选择顺序后可统计逆序型移动成本，但实现更复杂，本题 O(n²) 已足够。

面试追问

为何不用真的交换整行？

后续只依赖末尾 0 数，移动这个一维数组与整行交换等价。

为何选最近可行行？

它跨越的相邻边最少，当前交换成本最低。

若允许任意两行交换？

成本模型改变，一次远距离交换不再等于移动距离，需要重新设计。

如何提前判定无解？

可将末尾 0 数排序，逐位置检查是否存在达到阈值的行。

常见错误

  • 把需求写成 n-i；正确值是 n-1-i。
  • 统计整行 0 总数，而非末尾连续 0。
  • 只累加距离却不更新行顺序。
  • 把远距离行交换计作一次；题目只允许相邻交换。
  • 找不到可行行后没有立即返回 -1。
