删除最短的子数组
使剩余数组有序

Shortest Subarray to be Removed to Make Array Sorted

数组双指针二分查找

Problem

题意

给定整数数组 arr，删除其中一个连续子数组（允许为空），让余下元素按原相对顺序组成非递减数组。返回需要删除的最短长度。

函数签名：findLengthOfShortestSubarray(arr)，参数是整数数组，返回一个整数。

数组长度
1 ≤ arr.length ≤ 10⁵
元素范围
0 ≤ arr[i] ≤ 10⁹
目标顺序
非递减（允许相等）

官方示例

示例 1
输入：arr = [1,2,3,10,4,2,3,5]
输出：3
解释：删除 [10,4,2] 后得到
      [1,2,3,3,5]。
示例 2
输入：arr = [5,4,3,2,1]
输出：4
解释：严格递减，只能保留一个元素。
示例 3
输入：arr = [1,2,3]
输出：0
解释：数组已经非递减，无需删除。
示例 4
输入：arr = [1]
输出：0

双指针：保留两个有序端点

核心洞察

删除一段连续区间后，保留下来的只可能是“原数组的一个前缀 + 一个后缀”。因此先找最长非递减前缀与后缀，再尝试让二者在边界处合法拼接。

为什么能用双指针

前缀和后缀各自已经有序。若 arr[i] ≤ arr[j]，当前可删除 (i, j)，并右移 i争取缩短；否则必须右移 j寻找更大的后缀首元素。

完整过程

  1. 从右向左找到最早的下标 right，使 arr[right..n-1] 非递减。若 right = 0，答案是 0。
  2. 从左向右找到最晚的下标 left，使 arr[0..left] 非递减。
  3. 先考虑只保留一端：删前面得到长度 right；删后面得到长度 n-left-1。
  4. 令 i = 0、j = right。当两指针均有效时比较端点，更新可拼接时的删除长度 j-i-1。
answer = min(right, n - left - 1, 所有满足 arr[i] ≤ arr[j] 的 j - i - 1)

正确性说明

充分性：当 arr[i] ≤ arr[j] 时，前缀 arr[0..i]、后缀 arr[j..n-1] 各自非递减，且连接处也非递减，所以删除中间 arr[i+1..j-1] 一定可行。

完备性：任一合法删除方案保留的都必然是某个前缀和某个后缀；它们必须落在已找到的最长有序前缀、后缀范围内，并满足连接端点大小关系。双指针按单调顺序枚举了每个前缀端点所能连接的最早后缀端点，因此不会漏掉更短方案。

最优性：对固定 i，最早可连接的 j 给出最短删除区间；算法比较所有这类候选及仅保留一端的候选，所得最小值即全局最优。

复杂度

三个指针都只单向移动，总时间 O(n)；只使用常数个变量，额外空间 O(1)。

边界情况

单元素或已排序数组返回 0；严格递减数组返回 n−1；重复值允许连接，因为目标是非递减，比较必须使用 ≤。

替代方案

对有序前缀中的每个元素，在有序后缀内二分第一个不小于它的位置，时间 O(n log n)。思路直观，但不如双指针最优。

面试追问

若要求严格递增，应把连接和扫描条件改成严格小于；若允许删除两段，保留结构不再只是一个前缀与一个后缀，需要重新建模。

常见错误

  • 只比较“删前缀”与“删后缀”，遗漏保留两端的更优拼接。
  • 把非递减误写成严格递增，错误使用 < 而非 ≤。
  • 候选长度写成 j-i；真正删除的是开区间两端之间，共 j-i-1 个。
  • 没有提前处理已经有序的数组，导致指针越界或答案错误。

完整代码

Java 
class Solution {
    public int findLengthOfShortestSubarray(int[] arr) {
        int n = arr.length;
        int right = n - 1;
        while (right > 0 && arr[right - 1] <= arr[right]) {
            right--;
        }
        if (right == 0) return 0;

        int left = 0;
        while (left + 1 < n && arr[left] <= arr[left + 1]) {
            left++;
        }

        int answer = Math.min(right, n - left - 1);
        int i = 0, j = right;
        while (i <= left && j < n) {
            if (arr[i] <= arr[j]) {
                answer = Math.min(answer, j - i - 1);
                i++;
            } else {
                j++;
            }
        }
        return answer;
    }
}

class Solution:
    def findLengthOfShortestSubarray(self, arr: List[int]) -> int:
        n = len(arr)
        right = n - 1
        while right > 0 and arr[right - 1] <= arr[right]:
            right -= 1
        if right == 0:
            return 0

        left = 0
        while left + 1 < n and arr[left] <= arr[left + 1]:
            left += 1

        answer = min(right, n - left - 1)
        i, j = 0, right
        while i <= left and j < n:
            if arr[i] <= arr[j]:
                answer = min(answer, j - i - 1)
                i += 1
            else:
                j += 1
        return answer

                ++j;
