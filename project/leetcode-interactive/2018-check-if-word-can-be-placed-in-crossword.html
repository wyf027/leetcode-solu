Check if Word Can Be Placed In Crossword

一个单词，四种方向。观察字母与边界，判断它是否恰好放得下。

01 / 题目

给定 m × n 字符矩阵 board 与字符串 word，判断能否把单词沿一条水平或竖直直线放入棋盘，返回 true 或 false。允许从左向右、从右向左、从上向下、从下向上。

  • '#' 是障碍，不能占用；' ' 是一个空格，可填任意字母。
  • 已有小写字母必须与放入的对应字母一致。
  • 沿放置方向，单词两端外紧邻的位置必须为障碍或棋盘外，不能留下相邻的空格或小写字母。
  • 垂直于放置方向的邻格没有额外限制。

参数与约束

placeWordInCrossword(board, word) → boolean

  • m == board.length；n == board[i].length。
  • 1 ≤ m × n ≤ 2 × 10⁵。
  • board[i][j] 为 ' '、'#' 或小写英文字母。
  • 1 ≤ word.length ≤ max(m, n)。
  • word 只含小写英文字母。

02 / 官方示例

示例 1

board = [["#"," ","#"],[" "," ","#"],["#","c"," "]]
word = "abc"
输出：true

在第 2 列从上向下放置 abc，末尾的 c 与已有字母匹配。

示例 2

board = [[" ","#","a"],[" ","#","c"],[" ","#","a"]]
word = "ac"
输出：false

竖直放置两个字母会留下沿方向紧邻的空格或字母；水平方向也放不下。

示例 3

board = [["#"," ","#"],[" "," ","#"],["#"," ","c"]]
word = "ca"
输出：true

在最后一行从右向左放置 ca。

05 / 题解：整段双向匹配

核心洞察

障碍和边缘将每行、每列分成极大非障碍区间。一个合法单词必须恰好填满某个完整区间，长度相等后，再检查正序与逆序是否兼容。

完整过程

  1. 扫描所有行，再扫描所有列，用 axis 统一坐标读取。
  2. 跳过障碍，记录 start，走到下一个障碍或边缘，得到 [start, p)。
  3. 区间长度不等于单词长度 k，跳过。
  4. 同时维护正向 f 与反向 r。位置 t 分别对照 word[t]、word[k−1−t]，非空格且不同就使对应标志失效。
  5. 任一标志保持成立即可返回 true；全部区间失败则返回 false。

正确性

必要性：合法单词不能占用 #，两端又必须封闭，所以它一定覆盖一个完整极大区间，并且长度相同。每个非空字符必须对应相等。

充分性：算法接受的区间内部无障碍，两端封闭，长度相等，而且至少一个方向逐字兼容，因此可以合法放入。

完备性：枚举所有行列区间，再比较正反两向，涵盖所有四种合法方向，不会遗漏任何合法放置。

边界与常见错误

  • 长区间不能截取一段使用；仅比较字符会误判示例 2。
  • 全障碍返回 false；连续障碍逐个跳过。
  • 单行、单列、长度为 1 均可直接处理；只沿选定方向要求两端封闭。
  • 反向索引为 k−1−t；空格是单个字符，不要 trim。
  • 不能覆盖冲突的已有字母，也无需修改棋盘或回溯。

复杂度

时间 O(mn)：扫描行列各一次，同轴区间不重叠，所有等长区间的逐格比对总量也是 O(mn)。额外空间 O(1)：不复制矩阵、行列或反转字符串，不计输入。交互页面保存回放帧，空间与提交算法不同。

替代方案

逐格枚举起点与四个方向，直接检查 k 格及两端，朴素上界 O(mnk)。按 # 分割行列字符串可缩短代码，但增加副本空间。

面试追问

  • 返回位置：记录区间起点、轴与方向，逆向起点取末格。
  • 统计方案数：累计正反匹配，长度 1 时按题目定义去重。
  • 多次查询单词：预先按长度分组棋盘区间，再考虑字母位置索引。

Java

class Solution {
    public boolean placeWordInCrossword(char[][] board, String word) {
        int m = board.length, n = board[0].length, k = word.length();
        for (int axis = 0; axis < 2; axis++) {
            int lines = axis == 0 ? m : n, size = axis == 0 ? n : m;
            for (int line = 0; line < lines; line++) {
                int p = 0;
                while (p < size) {
                    if (at(board, axis, line, p) == '#') { p++; continue; }
                    int start = p;
                    while (p < size && at(board, axis, line, p) != '#') p++;
                    if (p - start != k) continue;
                    boolean f = true, r = true;
                    for (int t = 0; t < k; t++) {
                        char c = at(board, axis, line, start + t);
                        if (c != ' ' && c != word.charAt(t)) f = false;
                        if (c != ' ' && c != word.charAt(k - 1 - t)) r = false;
                    }
                    if (f || r) return true;
                }
            }
        }
        return false;
    }
    private char at(char[][] b, int axis, int line, int p) {
        return axis == 0 ? b[line][p] : b[p][line];
    }
}

from typing import List

class Solution:
    def placeWordInCrossword(self, board: List[List[str]], word: str) -> bool:
        m, n, k = len(board), len(board[0]), len(word)
        for axis in range(2):
            lines, size = (m, n) if axis == 0 else (n, m)
            for line in range(lines):
                def at(p):
                    return board[line][p] if axis == 0 else board[p][line]
                p = 0
                while p < size:
                    if at(p) == '#':
                        p += 1
                        continue
                    start = p
                    while p < size and at(p) != '#':
                        p += 1
                    if p - start != k:
                        continue
                    f = r = True
                    for t in range(k):
                        c = at(start + t)
                        if c != ' ' and c != word[t]:
                            f = False
                        if c != ' ' and c != word[k - 1 - t]:
                            r = False
                    if f or r:
                        return True
        return False

public:
    bool placeWordInCrossword(vector<vector<char>>& board, string word) {
        int m = board.size(), n = board[0].size(), k = word.size();
        for (int axis = 0; axis < 2; ++axis) {
            int lines = axis == 0 ? m : n, size = axis == 0 ? n : m;
            for (int line = 0; line < lines; ++line) {

                        char c = at(start + t);
                        if (c != ' ' && c != word[t]) f = false;
                        if (c != ' ' && c != word[k - 1 - t]) r = false;
                    }
                    if (f || r) return true;
                }
            }
        }
        return false;
    }
