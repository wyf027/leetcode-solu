不邻接植花

Flower Planting With No Adjacent

四种花，最多三个邻居。先观察花园网络，再亲手推进一次“总能选到颜色”的贪心过程。

题目

有 n 个编号为 1 到 n 的花园，paths[i] = [xᵢ, yᵢ] 表示两座花园间的一条双向路径。给每座花园种 1、2、3、4 四种花之一，使任意由路径直接相连的两座花园花种不同。返回任意一个可行数组 answer，其中 answer[i] 是花园 i+1 的花种。每座花园的度数至多为 3，并保证答案存在。

官方示例

输入：n = 3, paths = [[1,2],[2,3],[3,1]]
输出：[1,2,3]
解释：三对相邻花园的花种均不同；
[1,2,4]、[1,4,2] 等也同样有效。
输入：n = 4, paths = [[1,2],[3,4]]
输出：[1,2,1,2]
输入：n = 4,
paths = [[1,2],[2,3],[3,4],[4,1],[1,3],[2,4]]
输出：[1,2,3,4]

约束

  • 1 ≤ n ≤ 10⁴
  • 0 ≤ paths.length ≤ 2 × 10⁴
  • paths[i].length == 2
  • 1 ≤ xᵢ, yᵢ ≤ n
  • xᵢ != yᵢ
  • 每座花园最多连接 3 条路径

当前决策

准备揭晓？

先问自己：为什么按任意顺序处理，都不需要回溯？

题解：度数上限带来的贪心着色

核心洞察

处理某座花园时，它至多有 3 个邻居，因此已经被邻居占用的花种至多 3 种；候选却有 4 种，至少剩下一种可选。无需改动之前的选择。

完整过程

  1. 根据 paths 建立无向邻接表，题目编号减一转成数组下标。
  2. 按 0 到 n−1 依次处理花园。
  3. 扫描它的邻居，把邻居已选择的花种标记为不可用；未处理邻居的值为 0，可忽略。
  4. 从 1 到 4 选择首个未被占用的花种。
  5. 全部处理后返回结果。

正确性证明

不变量：每次为花园 i 赋值后，所有两端都已赋值的路径均连接不同花种。处理 i 时，算法排除了所有已赋值邻居的花种，故连接 i 与这些邻居的路径满足要求；其他旧路径不受影响。又因 i 至多有 3 个邻居，四种花中必有一种未被排除，所以步骤总能完成。归纳至所有花园处理完毕，每条路径两端均已赋值且花种不同，因此返回方案正确。

边界情况

  • 没有路径：每座花园都可选择花种 1。
  • 孤立点与多个连通分量：顺序贪心无需特殊处理。
  • 三名邻居恰好用了三种不同花：唯一剩余花种仍可选。
  • 返回值不唯一；只需满足相邻不同。

复杂度

建图和扫描邻接表均为 O(n + paths.length) 时间；邻接表与答案占 O(n + paths.length) 空间。检查四种花是常数开销。

替代方案

DFS/BFS 也能决定处理顺序，但着色规则仍相同。通用图着色回溯会显著更复杂；本题的“最大度数 3、颜色数 4”已经保证简单贪心必定成功。

面试追问

  • 若最大度数为 d，需要 d+1 种颜色即可沿任意顺序使用同一证明。
  • 只有 3 种花时不再保证存在答案，例如示例 3 的 K₄ 需要 4 色。
  • 能否原地省空间？仍需某种方式获得每个点的邻居，通常邻接表最直接。

常见错误

  • 忘记把 1-based 花园编号转换为 0-based 下标。
  • 只避开前一个花园，而不是所有已着色邻居。
  • 误以为必须最小化花种数量，加入不必要的回溯。
  • 把未着色标记 0 当成合法花种。

四语言完整实现

import java.util.*;

class Solution {
    public int[] gardenNoAdj(int n, int[][] paths) {
        List<Integer>[] graph = new ArrayList[n];
        for (int i = 0; i < n; i++) graph[i] = new ArrayList<>();
        for (int[] path : paths) {
            int a = path[0] - 1, b = path[1] - 1;
            graph[a].add(b);
            graph[b].add(a);
        }
        int[] answer = new int[n];
        for (int garden = 0; garden < n; garden++) {
            boolean[] used = new boolean[5];
            for (int neighbor : graph[garden])
                used[answer[neighbor]] = true;
            for (int flower = 1; flower <= 4; flower++)
                if (!used[flower]) { answer[garden] = flower; break; }
        }
        return answer;
    }
}
/**
 * @param {number} n
 * @param {number[][]} paths
 * @return {number[]}
 */
var gardenNoAdj = function(n, paths) {
    const graph = Array.from({ length: n }, () => []);
    for (const [x, y] of paths) {
        graph[x - 1].push(y - 1);
        graph[y - 1].push(x - 1);
    }
    const answer = new Array(n).fill(0);
    for (let garden = 0; garden < n; garden++) {
        const used = new Set(graph[garden].map(next => answer[next]));
        for (let flower = 1; flower <= 4; flower++) {
            if (!used.has(flower)) { answer[garden] = flower; break; }
        }
    }
    return answer;
};
from typing import List

class Solution:
    def gardenNoAdj(self, n: int, paths: List[List[int]]) -> List[int]:
        graph = [[] for _ in range(n)]
        for x, y in paths:
            graph[x - 1].append(y - 1)
            graph[y - 1].append(x - 1)

        answer = [0] * n
        for garden in range(n):
            used = {answer[neighbor] for neighbor in graph[garden]}
            for flower in range(1, 5):
                if flower not in used:
                    answer[garden] = flower
                    break
        return answer
