卡车上的最大单元数

容量有限，箱子却各有价值。先读清输入和目标，再进入装载实验室亲手推进每一步；完整思路被留在页面底部，不会在首屏剧透。

输入箱子类型 + 卡车容量
输出最多可装单元数
限制最多 1000 种类型
01 / PROBLEM

题目说明

一辆车按“箱子个数”计容量；不同类型的每个箱子所含单元数不同。

给定二维数组 boxTypes，其中 boxTypes[i] = [numberOfBoxesᵢ, numberOfUnitsPerBoxᵢ]。前者表示第 i 类箱子的数量，后者表示该类型每个箱子包含的单元数。

整数 truckSize 是卡车最多能装载的箱子数量。你可以选择任意箱子，只要总箱数不超过容量。请返回卡车能够装载的最大单元总数。

boxTypes: integer[][]每项是［该类箱数, 每箱单元数］。
truckSize: integer卡车可容纳的最大箱子数，而不是单元数。
02 / EXAMPLES

官方示例

EXAMPLE 01
输入：boxTypes = [[1,3],[2,2],[3,1]], truckSize = 4
输出：8

装入第一类的 1 箱、第二类的 2 箱和第三类的 1 箱，共装 4 箱；单元数为 1×3 + 2×2 + 1×1 = 8。

EXAMPLE 02
输入：boxTypes = [[5,10],[2,5],[4,7],[3,9]], truckSize = 10
输出：91

返回最多能装入卡车的单元总数。

约束

  • 1 ≤ boxTypes.length ≤ 1000
  • 1 ≤ numberOfBoxesᵢ, numberOfUnitsPerBoxᵢ ≤ 1000
  • 1 ≤ truckSize ≤ 10⁶

04 / SOLUTION

准备好核对思路了吗？

题解包含完整推导、正确性证明、复杂度、多语言代码和面试追问。

CORE INSIGHT

核心洞察：单位车位价值优先

局部选择：每个箱子占用的车位完全相同，都是 1；因此，在还有空位时，应优先选择“每箱单元数”最大的类型。

完整过程

  1. 按每箱单元数从高到低排序所有箱子类型。
  2. 依次访问排序后的类型，装入 min(该类箱数, 剩余车位) 个箱子。
  3. 把“装入箱数 × 每箱单元数”加入答案，并减少剩余车位。
  4. 车位耗尽时立即结束；否则继续处理下一类型。

边界处理

  • 卡车容量小于最高价值类型的箱数：只取能放下的部分。
  • 总箱数少于卡车容量：所有箱子都装入，剩余车位不影响答案。
  • 多个类型的每箱单元数相同：它们之间的先后次序不影响最优值。
  • 单一箱子类型：直接取箱数与容量的较小值。
CORRECTNESS

正确性证明

交换论证：设某个可行装载方案在车上放了一个每箱含 b 个单元的箱子，却没有放入仍可选择、每箱含 a 个单元的箱子，其中 a > b。用后者替换前者，箱子总数不变，因此方案仍可行；单元总数增加 a - b。

不断进行这样的交换后，必然得到按每箱单元数从高到低选取的方案，且答案不会变差。算法恰好构造这一方案：对每个当前价值最高的类型，尽可能装入，直到卡车装满。因此算法返回的单元总数是最大值。

O(n log n)时间复杂度，排序占主导。
O(log n)额外空间，按常见原地排序栈空间计；语言实现可能为 O(n)。
n ≤ 1000直接排序清晰且足够高效。
ALTERNATIVES

替代方案

由于每箱单元数被约束在 1..1000，可以建立长度 1001 的计数数组，汇总每个单元值对应的箱数，再从 1000 向 1 扫描。这样时间复杂度为 O(n + U)，其中 U = 1000；额外空间为 O(U)。不过通用排序方案更直观，也不依赖数值上界。

IMPLEMENTATIONS

四种语言完整代码

均遵循官方函数签名；代码容器可独立横向滚动。

JavaSolution.maximumUnits
import java.util.Arrays;

class Solution {
    public int maximumUnits(int[][] boxTypes, int truckSize) {
        Arrays.sort(boxTypes, (a, b) -> Integer.compare(b[1], a[1]));
        int totalUnits = 0;

        for (int[] type : boxTypes) {
            if (truckSize == 0) break;
            int take = Math.min(type[0], truckSize);
            totalUnits += take * type[1];
            truckSize -= take;
        }
        return totalUnits;
    }
}

        truckSize -= take;
    }
    return totalUnits;

class Solution {
public:
    int maximumUnits(vector<vector<int>>& boxTypes,
                     int truckSize) {
        sort(boxTypes.begin(), boxTypes.end(),
             [](const auto& a, const auto& b) {
                 return a[1] > b[1];
             });

        int totalUnits = 0;
        for (const auto& type : boxTypes) {
            if (truckSize == 0) break;
            int take = min(type[0], truckSize);
            totalUnits += take * type[1];
            truckSize -= take;
        }
        return totalUnits;
    }
};
INTERVIEW FOLLOW-UPS

面试追问

如果每类箱子的体积不同呢？

此时每个选择不再等价占用一个车位，简单按单位数排序可能失效，问题会接近 0/1 或多重背包。

能否不修改输入数组？

先复制一份二维数组再排序；JavaScript 可用 boxTypes.slice()，Java/C++ 则复制容器。

何时计数排序更合适？

当每箱单元数上界很小且稳定、数据规模更大时，按值计数能省去比较排序。

COMMON MISTAKES

常见错误

  • 按箱子数量排序，而不是按“每箱单元数”排序。
  • 把 truckSize 误解成可装单元数。
  • 直接装完整个类型，没有对剩余容量取最小值。
  • 装满后不提前停止，导致剩余容量出现负数。
  • 比较器方向写反，变成从低价值到高价值装载。
