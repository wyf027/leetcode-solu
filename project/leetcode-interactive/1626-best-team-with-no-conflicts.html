无矛盾的
最佳球队

从一组年龄与得分各异的球员中，组建总得分最高、且不会出现“年轻球员得分严格高于年长球员”的球队。

难度：中等非付费题bestTeamScore(scores, ages)
16

The brief / 题目

组队规则

你是篮球队经理，要从若干球员中挑选一支球队。球队总得分等于所有入选球员分数之和；可以选择任意非空子集。

若球队中存在一名更年轻的球员，其得分又严格高于一名更年长的球员，就产生矛盾。同龄球员之间无论得分如何都不算矛盾。

给定长度相同的数组 scores 与 ages，其中第 i 个位置共同描述一名球员，返回所有无矛盾球队能取得的最高总分。

一句话判定冲突

只要年龄更小的一方得分严格更高，这一对球员就冲突。

age[a] < age[b] 且 score[a] > score[b]

注意：同龄时不会冲突；得分相等也不会因这一对产生冲突。

官方示例

01
scores = [1,3,5,10,15]
ages = [1,2,3,4,5]

输出：34
所有球员都可入选。

02
scores = [4,5,6,5]
ages = [2,1,2,1]

输出：16
选择后 3 名球员；同龄可同时入选。

03
scores = [1,2,3,5]
ages = [8,9,10,1]

输出：6
选择前 3 名球员。

约束

  • 1 <= scores.length, ages.length <= 1000
  • scores.length == ages.length
  • 1 <= scores[i] <= 10^6
  • 1 <= ages[i] <= 1000

The playbook / 完整题解

排序后做“最高和”的非递减子序列

核心洞察

先将每名球员表示为 (age, score)，按年龄升序、同龄按得分升序排序。这样从左向右选择时，年龄天然不会下降；为了避免年轻球员分数高于后面的年长球员，只需让所选得分保持非递减。

状态：dp[i] 表示必须选择排序后第 i 名球员且以他结尾时，能得到的最大总分。

完整过程

  1. 组合年龄和得分，并按 (age 升序, score 升序) 排序。
  2. 令 dp[i] = score[i]，表示只选自己。
  3. 枚举所有 j < i；若 score[j] <= score[i]，可转移：dp[i] = max(dp[i], dp[j] + score[i])。
  4. 答案是所有 dp[i] 的最大值。

为什么同龄要按得分升序？

同龄球员彼此不冲突，因此应该允许他们共同出现在非递减得分序列中。升序排列恰好保留这种可能性。若同龄按降序排，分数较高者会挡住同龄的较低分球员，错误地漏掉合法组合。

复杂度：排序 O(n log n)，两层转移 O(n²)，空间 O(n)。

正确性证明

1
排序不丢解。年龄升序给任何球队一个固定考察顺序；同龄按得分升序不会引入冲突，因为同龄之间本就无冲突。
2
转移合法。当 j < i 且 score[j] <= score[i] 时，以 j 结尾的无矛盾球队加入球员 i 后，年龄和得分都不下降，所以新球队仍无矛盾。
3
转移完备。任意以 i 结尾、人数至少为 2 的最优合法球队，去掉 i 后必以某个 j < i 结尾，且有 score[j] <= score[i]；枚举会覆盖这个前驱。
4
得到全局最优。每个非空球队都有最后一名球员，取所有 dp[i] 的最大值便覆盖所有可能的最优球队。

边界情况

  • 只有一名球员：答案就是他的得分。
  • 所有球员同龄：全部可选，答案为总和。
  • 年龄增长但得分严格下降：最多选择一个球员，取最高得分。
  • 得分相同：可以共同入选，因为冲突要求“严格更高”。
  • 最大答案可达 10^9；题目语言中的 32 位有符号整数仍可容纳。

替代方案

可对得分离散化后，用树状数组或线段树维护“得分不超过当前值的最大总分”，把转移优化到 O(n log n)。由于 n <= 1000，经典 O(n²) DP 更直接、也足够快。

也可以改为按 (score, age) 升序排序，再在年龄上做同样的最大和非递减子序列。

Implementations

四种语言完整代码

Java

O(n²)
import java.util.Arrays;

class Solution {
    public int bestTeamScore(int[] scores, int[] ages) {
        int n = scores.length;
        int[][] players = new int[n][2];

        for (int i = 0; i < n; i++) {
            players[i][0] = ages[i];
            players[i][1] = scores[i];
        }

        Arrays.sort(players, (a, b) -> {
            if (a[0] != b[0]) return a[0] - b[0];
            return a[1] - b[1];
        });

        int[] dp = new int[n];
        int answer = 0;
        for (int i = 0; i < n; i++) {
            dp[i] = players[i][1];
            for (int j = 0; j < i; j++) {
                if (players[j][1] <= players[i][1]) {
                    dp[i] = Math.max(dp[i],
                        dp[j] + players[i][1]);
                }
            }
            answer = Math.max(answer, dp[i]);
        }
        return answer;
    }
}

JavaScript

O(n²)
/**
 * @param {number[]} scores
 * @param {number[]} ages
 * @return {number}
 */
var bestTeamScore = function(scores, ages) {
    const players = scores.map((score, i) => [ages[i], score]);
    players.sort((a, b) => a[0] - b[0] || a[1] - b[1]);

    const dp = new Array(players.length).fill(0);
    let answer = 0;

    for (let i = 0; i < players.length; i++) {
        const currentScore = players[i][1];
        dp[i] = currentScore;

        for (let j = 0; j < i; j++) {
            if (players[j][1] <= currentScore) {
                dp[i] = Math.max(dp[i], dp[j] + currentScore);
            }
        }
        answer = Math.max(answer, dp[i]);
    }
    return answer;
};

Python

O(n²)
from typing import List

class Solution:
    def bestTeamScore(
        self, scores: List[int], ages: List[int]
    ) -> int:
        players = sorted(zip(ages, scores))
        dp = [0] * len(players)
        answer = 0

        for i, (_, current_score) in enumerate(players):
            dp[i] = current_score
            for j in range(i):
                if players[j][1] <= current_score:
                    dp[i] = max(
                        dp[i], dp[j] + current_score
                    )
            answer = max(answer, dp[i])

        return answer

C++

O(n²)
#include <algorithm>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int bestTeamScore(vector<int>& scores,
                      vector<int>& ages) {
        int n = scores.size();
        vector<pair<int, int>> players;
        players.reserve(n);

        for (int i = 0; i < n; ++i) {
            players.push_back({ages[i], scores[i]});
        }
        sort(players.begin(), players.end());

        vector<int> dp(n);
        int answer = 0;
        for (int i = 0; i < n; ++i) {
            dp[i] = players[i].second;
            for (int j = 0; j < i; ++j) {
                if (players[j].second <= players[i].second) {
                    dp[i] = max(dp[i],
                        dp[j] + players[i].second);
                }
            }
            answer = max(answer, dp[i]);
        }
        return answer;
    }
};

Interview follow-ups

面试追问

如何优化到 O(n log n)？

将得分离散化，用树状数组查询前缀最大值，再以当前总分更新当前得分位置。树状数组保存的是最大值而不是求和。

排序时交换主次键可以吗？

可以。按得分升序、同分按年龄升序后，在年龄维度做最大和非递减子序列，逻辑对称。

为什么允许“等于”？

题目只有年轻球员得分严格高于年长球员才冲突，所以相同得分可以安全衔接。

如果同龄也可能冲突呢？

排序的同龄处理和转移条件都要随新规则调整；不能直接沿用当前的同龄升序策略。

常见错误

  • 只按年龄排序，却忘记同龄按得分升序，导致合法的同龄组合被漏掉。
  • 转移写成 score[j] < score[i]，错误排除相同得分。
  • 把 dp[i] 理解成前 i 人的全局答案，随后又使用“以 i 结尾”的转移，造成状态语义混乱。
  • 返回 dp[n - 1]；最优球队不一定以排序后的最后一人结尾，应返回整个数组最大值。
