Problem

题目说明

给定一个 m × n 的二进制矩阵 grid。值为 1 的格子表示陆地，值为 0 的格子表示水域。只有在水平或竖直方向相邻的陆地才属于同一座岛屿；对角相邻不算连通。可以认为矩阵四周都是水。

岛屿面积等于该岛屿包含的陆地格子数。请返回所有岛屿中的最大面积；如果矩阵里没有陆地，返回 0。

Complete solution

完整题解

核心洞察

一次搜索，恰好吃掉一座岛

从任意尚未访问的陆地出发，沿四个方向持续搜索，所能到达的格子恰好构成一座完整岛屿。搜索时立即把陆地标记为已访问，累加本次面积，再用全局最大值更新答案。

状态设计

原地把 1 改成 0

把已发现的陆地直接改成水，可以避免额外的 visited 矩阵，也能保证同一格最多入栈一次。代价是输入矩阵会被修改；若调用方要求保留输入，应改用同尺寸布尔数组。

完整过程

  1. 令 best = 0，按行扫描矩阵中的每一个格子。
  2. 遇到水或已经被清零的陆地时跳过；遇到值为 1 的格子时，开始一次新的迭代式深度优先搜索。
  3. 起点入栈前立刻改成 0。每弹出一个坐标，本岛面积加一；检查上下左右，把尚未访问的陆地清零后压栈。
  4. 栈为空时，本次搜索覆盖了整座岛屿。用它的面积更新 best，继续扫描。
  5. 扫描结束，best 就是最大岛屿面积；没有陆地时它自然保持为 0。

正确性证明

覆盖完整、不重不漏

  1. 单次搜索完整：搜索从起点沿所有四向陆地边扩展，因此起点所在岛屿中任何可达格子最终都会被发现。
  2. 单次搜索不越界：只有边界内且值为 1 的四向邻格才能入栈，所以不会进入水域、矩阵外部或另一座不连通岛屿。
  3. 全局不重复：格子入栈时立即被置 0，此后不能再次入栈。每个陆地格最多计数一次。
  4. 结论：每次搜索所得面积恰好是一座岛的面积；逐岛取最大值，返回值就是所有岛屿面积的最大值。

复杂度与边界

每个格子至多处理一次

时间复杂度：O(mn)。扫描和搜索合计只会处理每个格子常数次。

空间复杂度：O(mn)。最坏情况下整张矩阵都是陆地，显式栈可容纳线性数量的坐标；不计栈时原地标记为 O(1) 额外标记空间。

关键边界：全水返回 0；单格陆地返回 1；对角陆地分属不同岛；狭长岛屿也应完整统计。

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public int maxAreaOfIsland(int[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;
        int best = 0;
        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        for (int row = 0; row < rows; row++) {
            for (int col = 0; col < cols; col++) {
                if (grid[row][col] == 0) {
                    continue;
                }

                int area = 0;
                Deque<int[]> stack = new ArrayDeque<>();
                stack.push(new int[]{row, col});
                grid[row][col] = 0;

                while (!stack.isEmpty()) {
                    int[] cell = stack.pop();
                    area++;

                    for (int[] direction : directions) {
                        int nextRow = cell[0] + direction[0];
                        int nextCol = cell[1] + direction[1];
                        if (nextRow >= 0 && nextRow < rows
                                && nextCol >= 0 && nextCol < cols
                                && grid[nextRow][nextCol] == 1) {
                            grid[nextRow][nextCol] = 0;
                            stack.push(new int[]{nextRow, nextCol});
                        }
                    }
                }

                best = Math.max(best, area);
            }
        }

        return best;
    }
}

    const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];

                        stack.push([nextRow, nextCol]);

                }
            }

        }

class Solution {
public:
    int maxAreaOfIsland(vector<vector<int>>& grid) {
        const int rows = static_cast<int>(grid.size());
        const int cols = static_cast<int>(grid[0].size());
        const int directions[4][2] = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        int best = 0;

        for (int row = 0; row < rows; ++row) {
            for (int col = 0; col < cols; ++col) {
                if (grid[row][col] == 0) {
                    continue;
                }

                int area = 0;
                stack<pair<int, int>> cells;
                cells.push({row, col});
                grid[row][col] = 0;

                while (!cells.empty()) {
                    auto [currentRow, currentCol] = cells.top();
                    cells.pop();
                    ++area;

                    for (const auto& direction : directions) {
                        int nextRow = currentRow + direction[0];
                        int nextCol = currentCol + direction[1];
                        if (nextRow >= 0 && nextRow < rows
                                && nextCol >= 0 && nextCol < cols
                                && grid[nextRow][nextCol] == 1) {
                            grid[nextRow][nextCol] = 0;
                            cells.push({nextRow, nextCol});
                        }
                    }
                }

                best = max(best, area);
            }
        }

        return best;
    }

替代方案

BFS、递归 DFS 与并查集

广度优先搜索：把栈换成队列即可，复杂度相同，适合偏好按层扩展的实现。

递归 DFS：代码更短，但最坏递归深度可达 mn；Python 等语言可能碰到递归深度限制。

并查集：可先合并相邻陆地并维护连通块大小，但静态矩阵上代码与常数开销更大；当题目改成动态加陆地时更有价值。

常见错误

  • 把八个方向都当作相邻，错误连接对角线上的陆地。
  • 在出栈而不是入栈时标记访问，导致同一格被多个邻居重复压栈。
  • 忘记每次发现新岛屿时把局部面积清零。
  • 把所有陆地总数当成答案，没有按连通块分别统计。
  • 使用原地标记后仍假设调用结束时输入矩阵不变。

Interview follow-ups

面试追问

如果不能修改输入矩阵怎么办？

创建 m × n 的布尔访问数组，发现陆地时设置为已访问。时间复杂度仍为 O(mn)，额外空间显式增加到 O(mn)。

如果允许八方向连通，需要改哪里？

在方向数组中加入四个对角方向即可。其余搜索框架和复杂度不变，但岛屿定义与答案可能改变。

如果陆地会不断在线加入，怎么维护最大面积？

可用并查集：每次新增格子后与四邻陆地合并，在根节点维护连通块大小，并实时更新全局最大值。

为什么选择迭代 DFS 而不是递归？

二者的搜索含义相同。迭代版使用显式栈，不依赖语言调用栈上限，更稳妥地处理最坏情况下的长链或整片陆地。
