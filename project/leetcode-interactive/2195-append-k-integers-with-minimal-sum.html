向数组中追加 K 个整数

Append K Integers With Minimal Sum

从正整数中选出新成员，让追加部分的总和尽可能小。

题目

给定整数数组 nums 和整数 k，追加恰好 k 个正整数。新追加的数必须互不相同，且任何一个都不能已经出现在 nums 中。要求追加后整个数组的元素和最小。

返回这 k 个新整数的和。原数组的元素不计入返回值。

官方示例 1

输入：nums = [1,4,25,10,25], k = 2
输出：5

追加 2、3，追加部分之和为 5；整个数组的和为 70。原数组中的两个 25 可以同时存在。

官方示例 2

输入：nums = [5,6], k = 6
输出：25

追加 1、2、3、4、7、8，共六个数，其和为 25；整个数组的和为 36。

约束与参数

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁹
  • 1 ≤ k ≤ 10⁸（元数据英文题面）

题解 · 把缺失数字按段领取

核心洞察

原数组的和固定，因此只需让新增部分最小。最优选择就是最小的 k 个缺失正整数。排序后，相邻已有数字之间构成连续的空档，可以用等差数列公式一次领取整段，无需执行 k 次。

空档扫描器

每一步处理一个已排序的障碍值，或领取末尾区间。绿色表示已领取，带删除线表示原数组占用；只展示数轴前 40 格，完整区间以文字表示。

交互上限为 100 个数组元素，数值 1～10⁹，k 为 1～10⁸；提交代码支持完整数组规模。

完整过程

  1. 按升序排列 nums，设置 cur = 1、left = k、ans = 0。
  2. 扫描已有数字 x。若 x < cur，说明是已经越过的重复值，跳过。
  3. 区间 [cur, x − 1] 中没有已有数，长度为 x − cur。取 t = min(left, x − cur) 个。
  4. 把 t × (2 × cur + t − 1) / 2 加到答案中，令 left 减少 t。若 left 为零，立即返回。
  5. 越过已有数 x，令 cur = x + 1。扫描结束仍有剩余，就从 cur 开始取 left 个并用同一公式求和。

以 nums = [5,6]、k = 6 为例：先领取 [1,4]，和为 10，剩 2；越过 5、6，再领取 [7,8]，增加 15，最终得到 25。

正确性

交换论证：若一个合法方案选择了 b，却遗漏更小的可用正整数 a，则用 a 替换 b 不会碰到已有值，也不会引入重复，而且使和严格减小。因此最优解必须包含最小的 k 个缺失正整数。

扫描不变式：处理 x 之前，cur 以下的数已被确定为占用或已领取，已领取部分是全局最小的若干缺失数。排序保证 [cur, x−1] 内没有占用值，按升序取其前 t 个维持不变式。之后跳过 x 合法；重复值不会倒退 cur。需求耗尽或领取末尾段后，恰好得到最小的 k 个缺失数，依据交换论证，答案最优。

边界与数值

  • 原数组允许重复，但每个数只构成一次占用。用 x < cur 直接跳过重复项。
  • 第一个数大于 1 时，先处理从 1 开始的空档；若空档已足够，及时返回。
  • 所有已有数连续时，空档长度为 0；最后一个已有数之后仍有无限多个合法值。
  • Java / C++ 在乘法前使用 64 位整数。Python 整数自动扩展。
  • 英文约束下，最大被选值不超过 k + n ≤ 100100000，答案小于 5.01 × 10¹⁵，处于 Number 安全整数范围内。JavaScript 用 BigInt 避免公式中间乘积越过安全整数范围，最后再转 Number。

复杂度

排序 O(n log n)，扫描 O(n)，与 k 的大小无关。以下 Python / JavaScript 使用排序副本，额外空间 O(n)；Java / C++ 原地排序，扫描部分 O(1)，排序栈通常为 O(log n)，具体辅助空间由语言排序实现决定。

替代方案

把候选上界先设为 k，初始和为 k(k+1)/2，按升序遍历去重后的已有值；遇到不超过当前上界的值，就扣掉它，并把上界加一，把新上界加入总和。这相当于不断补偿被占用的位置，时间仍为 O(n log n)。另一种集合逐数枚举方案约 O(n+k)，k 很大时不合适。也可二分最小边界 m，使 m 减去不大于 m 的不同已有值数量达到 k，再用三角和扣除占用值。

常见错误

  • 返回整个数组总和，而不是新增部分总和。
  • 从 0 开始选数，或把数组重复次数当成多个占用位置。
  • 把空档长度写为 x − cur + 1，错误地包含已有数 x。
  • 只处理相邻已有值之间的空档，忘记数组末尾的剩余需求。
  • 用 32 位整数求和，或在乘法完成后才转成 long。
  • JavaScript 默认 sort 按字符串排序，必须提供数值比较函数。

四语言完整实现

均对应官方 minimalKSum 签名。Java / C++ 会改变 nums 顺序。以下代码尚未执行验证。

Java

import java.util.Arrays;

class Solution {
    public long minimalKSum(int[] nums, int k) {
        Arrays.sort(nums);
        long cur = 1, left = k, ans = 0;
        for (int x : nums) {
            if (x < cur) continue;
            long take = Math.min(left, (long) x - cur);
            ans += take * (2 * cur + take - 1) / 2;
            left -= take;
            if (left == 0) return ans;
            cur = (long) x + 1;
        }
        return ans + left * (2 * cur + left - 1) / 2;
    }
}

JavaScript

/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var minimalKSum = function(nums, k) {
    const sorted = [...nums].sort((a, b) => a - b);
    let cur = 1n, left = BigInt(k), ans = 0n;
    for (const value of sorted) {
        const x = BigInt(value);
        if (x < cur) continue;
        const gap = x - cur;
        const take = left < gap ? left : gap;
        ans += take * (2n * cur + take - 1n) / 2n;
        left -= take;
        if (left === 0n) return Number(ans);
        cur = x + 1n;
    }
    return Number(ans + left * (2n * cur + left - 1n) / 2n);
};

class Solution {

    long long minimalKSum(vector<int>& nums, int k) {
        sort(nums.begin(), nums.end());
        long long cur = 1, left = k, ans = 0;

            left -= take;
            if (left == 0) return ans;
            cur = (long long)x + 1;

    }
};

面试追问

  • 为什么不能 O(k) 地生成答案？ k 可达一亿；只返回和时，用区间公式压缩重复工作。
  • 如果要求返回每个新增元素呢？ 输出本身就需 Ω(k) 时间和输出空间，无法再把它压缩成一个数。
  • 不能修改原数组怎么办？ 复制后排序，或建立去重有序结构；接受相应额外空间。
  • 大量不同 k 的查询怎么办？ 对空档预计算累计缺失个数和累计和，再二分查询所在空档并补一段等差和。
