01 / 读懂题目

不是元素在区间内，而是子数组最大值在区间内

题意

给定整数数组 nums，以及整数 left 和 right。统计所有连续、非空的子数组，其中的最大元素必须位于闭区间 [left, right] 内。

函数参数形式：

numSubarrayBoundedMax(nums, left, right) → integer

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁹
  • 0 ≤ left ≤ right ≤ 10⁹
  • 测试数据保证最终答案在 32-bit 整数范围内。

示例 1

输入：nums = [2,1,4,3], left = 2, right = 3
输出：3
解释：满足条件的三个子数组是 [2]、[2,1]、[3]。

示例 2

输入：nums = [2,9,2,5,6], left = 2, right = 8
输出：7

04 / 独立题解

准备好看线性解法了吗？

题解默认收起。展开后会看到核心公式、证明、边界、替代方案与四种语言实现。

Core insight

把“最大值在区间”拆成两个“最大值不超过”

令 F(x) 表示最大值不超过 x 的非空连续子数组数量。那么最大值落在 [left, right] 的子数组，恰好是上界集合去掉最大值小于 left 的集合。

答案 = F(right) − F(left − 1)

完整过程

  1. 写辅助函数 countAtMost(bound)。
  2. 从左到右扫描，维护以当前位置结尾、且所有元素不超过 bound 的最长连续后缀长度 streak。
  3. 当前值不超过阈值时令 streak += 1；否则重置为 0。
  4. 每步把 streak 加入累计值，因为它正好等于以当前位置结尾的合法子数组数。
  5. 计算 F(right) 与 F(left − 1)，相减。

复杂度

时间：O(n)。两次线性扫描。

空间：O(1)。只维护后缀长度与累计值。

建议使用 64 位中间量：即使最终差值保证在 32-bit 范围，两个累计量各自仍可能更大。

正确性证明

局部计数正确。 扫描到位置 i 时，streak 是以 i 结尾且所有元素不超过阈值的最长后缀长度。后缀内每个起点产生一个合法子数组，共 streak 个；更早起点会包含超阈值元素。
没有重计或漏计。 每个非空子数组都有唯一结束位置，所以只在结束位置那一步被计入一次。累加所有位置即得到 F(x)。
差集就是目标。 最大值不超过 right 的子数组中，删除最大值小于 left 的部分，也就是删除 F(left − 1)，剩余最大值正好位于闭区间内。
结论。 算法返回 F(right) − F(left − 1)，与题意一致。

边界情况

  • 单元素：由它是否落在区间决定答案为 0 或 1。
  • left = right：只统计最大值恰好等于该值的子数组。
  • 所有元素都小于下界：两个累计量相等，答案为 0。
  • 元素大于上界：会同时切断两条后缀链。
  • left = 0：下方阈值为 −1，因数组非负，F(−1) = 0。

常见错误

  • 误以为每个元素都必须位于 [left, right]；实际只约束最大值。
  • 用 F(left) 做减数，错误删除最大值等于 left 的子数组。
  • 遇到超阈值元素没有把 streak 清零。
  • Java/C++ 使用 32 位中间累计值，可能在相减前溢出。

替代方案：记录关键下标

一次扫描维护最近一个 nums[i] > right 的位置 lastTooLarge，以及最近一个 left ≤ nums[i] ≤ right 的位置 lastInRange。以当前位置结尾的新答案数为 max(0, lastInRange − lastTooLarge)。

它同样是 O(n) 时间、O(1) 空间且只扫描一次；差分写法通常更易推导和复用。

面试追问

  • 为什么不是直接滑动窗口？ “最大值恰在区间”不好直接收缩，转换为“最大值至多为 x”后性质更单调。
  • 最大值恰好等于 k 怎么做？ 使用 F(k) − F(k − 1)。
  • 如果数据持续到来？ 固定 left/right 时，只需保留两条 streak 与累计量，可在线 O(1) 更新。
  • 两次扫描为什么仍是 O(n)？ 常数 2 不影响渐进复杂度。

四语言完整实现

class Solution {
    public int numSubarrayBoundedMax(int[] nums, int left, int right) {
        long answer = countAtMost(nums, right)
                    - countAtMost(nums, left - 1);
        return (int) answer;
    }

    private long countAtMost(int[] nums, int bound) {
        long total = 0;
        long streak = 0;
        for (int value : nums) {
            if (value <= bound) {
                streak++;
            } else {
                streak = 0;
            }
            total += streak;
        }
        return total;
    }
}

                streak += 1;

public:
    int numSubarrayBoundedMax(
        vector<int>& nums, int left, int right
