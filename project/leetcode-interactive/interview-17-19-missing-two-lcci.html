题解

01 · CORE INSIGHT

核心洞察：先得到二人合成指纹，再找分歧位

把完整序列 1…N 与 nums 中的所有数一起异或。现存数字各出现两次，满足 x ⊕ x = 0，最终只留下两个缺失值 a ⊕ b。

因为 a ≠ b，所以 a ⊕ b 至少有一个二进制位为 1。 取最低的这一位 lowbit = xor & -xor，它在 a、b 中必定一个为 1、一个为 0。

按这位把全集和 nums 同时分组，每组内部再异或；成对数字仍会消失，而 a、b 被隔离在不同组，分别留下。

02 · WALKTHROUGH

完整过程：nums = [2,3]

  1. 1N = 2 + 2 = 4，完整序列为 [1,2,3,4]。
  2. 21 ⊕ 2 ⊕ 3 ⊕ 4 ⊕ 2 ⊕ 3 = 1 ⊕ 4 = 5。
  3. 3lowbit = 5 & -5 = 1，选择最低位分组。
  4. 4最低位为 1 的通道收到 1,3,3，异或后得到 1。
  5. 5最低位为 0 的通道收到 2,4,2，异或后得到 4。
  6. 6返回 [1,4]；题目允许任意顺序。

03 · BOUNDARIES

边界情况

  • • nums = [] 时 N = 2，答案就是 1 和 2。
  • • 两个缺失值可能相邻，也可能分别位于 1 与 N。
  • • nums 的排列任意；异或满足交换律与结合律。
  • • xor ≠ 0，因为两个缺失数字互不相同。
  • • 约束最大只到 30002，四种语言的位运算整数范围都安全。

04 · COMPLEXITY

复杂度

时间
O(N)

O(1)
两轮线性异或；仅保存 N、签名、lowbit 与两个分组累加器。

05 · COMMON ERRORS

常见错误

  • • 把 N 写成 nums.length，漏掉补回的 2。
  • • 只给 nums 分组，却忘记把完整的 1…N 也送入两条通道。
  • • 用 xor & 1 固定最低位；该位可能并不不同。
  • • 把 lowbit 当成缺失值；它只是一枚分组掩码。
  • • 测试时强制期待题目未承诺的返回顺序；可排序后再比较。

06 · TRADE-OFFS

替代方案取舍

总和 + 分界点

先算缺失值之和 S，至少一个缺失值不大于 ⌊S/2⌋，再分别统计两段差值。仍是 O(N)/O(1)，思路直观，但需留心累加溢出；使用 64 位整数即可。

哈希集合

实现最直接，扫描 1…N 查询缺失值，但额外空间是 O(N)，不满足题目要求。

原地放置

扩展两个哨兵位后把值交换到对应下标，理论上 O(N)/O(1)，但会修改输入且交换逻辑更易出错。

面试推荐：异或分组不修改输入、无求和溢出，并直接展示位运算基本功。

07 · INTERVIEW FOLLOW-UPS

面试追问

为什么 lowbit 一定能把两数分开？

lowbit 对应 a ⊕ b 中某个为 1 的位。异或该位为 1，只可能说明 a、b 在这一位不同，因此两者必进不同组。

如果只缺一个数字呢？

直接把 nums 与完整 1…N 全部异或，成对值消失，余下值就是答案，不需要分组。

如果缺失数字超过两个呢？

单个 XOR 签名信息不足，不能唯一还原任意多个值；需要更多独立统计量、哈希空间，或利用额外结构约束。

lowbit 在补码里为什么写成 x & -x？

-x 是按位取反后加 1，最低的 1 及其右侧结构使得按位与后仅保留 x 的最低置位。

class Solution {
    public int[] missingTwo(int[] nums) {
        int n = nums.length + 2;
        int xor = 0;

        for (int value = 1; value <= n; value++) {
            xor ^= value;
        }
        for (int value : nums) {
            xor ^= value;
        }

        int lowbit = xor & -xor;
        int first = 0;
        int second = 0;

        for (int value = 1; value <= n; value++) {
            if ((value & lowbit) == 0) {
                first ^= value;
            } else {
                second ^= value;
            }
        }
        for (int value : nums) {
            if ((value & lowbit) == 0) {
                first ^= value;
            } else {
                second ^= value;
            }
        }

        return first < second
            ? new int[] {first, second}
            : new int[] {second, first};
    }
}

        xor_value = 0

        for value in range(1, n + 1):
            xor_value ^= value

            xor_value ^= value

        lowbit = xor_value & -xor_value
        first = 0

                second ^= value

#include <vector>
using namespace std;

class Solution {
public:
    vector<int> missingTwo(vector<int>& nums) {
        int n = static_cast<int>(nums.size()) + 2;
        int xorValue = 0;

        for (int value = 1; value <= n; ++value) {
            xorValue ^= value;
        }
        for (int value : nums) {
            xorValue ^= value;
        }

        int lowbit = xorValue & -xorValue;
        int first = 0;
        int second = 0;

        for (int value = 1; value <= n; ++value) {
            if ((value & lowbit) == 0) {
                first ^= value;
            } else {
                second ^= value;
            }
        }
        for (int value : nums) {
            if ((value & lowbit) == 0) {
                first ^= value;
            } else {
                second ^= value;
            }
        }

        if (first > second) {
            swap(first, second);
        }
        return {first, second};
    }
};
