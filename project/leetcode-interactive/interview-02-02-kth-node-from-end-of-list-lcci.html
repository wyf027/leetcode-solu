把距离固定为 k

倒数第 k 个看似要求“从尾部往回数”，但单链表不能回头。先让快指针领跑 k 步，再让两枚指针同步前进：终点会自动把答案对齐到慢指针。

面试题 02.02 简单 双指针 · O(1) 空间

题意：从单向链表尾部量回 k 格

给定单链表头节点 head 和有效整数 k，返回倒数第 k 个节点的值。

官方示例

输入 head = [1, 2, 3, 4, 5], k = 2
输出 4
解释 从尾部数，第 1 个是 5，第 2 个是 4。

输入契约

官方保证 k 有效，因此 1 ≤ k ≤ 链表长度。提交函数名为 kthToLast，返回的是节点值，不是节点对象。

可见字符约定：若文本参数含空格，本页用 ␠ 表示；本题输入只有链表和整数，不含字符串。

固定间距实验台

先拉开 k 格，再同步滑动。用按钮或键盘逐帧观察不变量。

步骤 1 / 6
慢指针 slow 索引 0 · 值 1
快指针 fast 索引 0 · 值 1
固定间距 0 / 2
初始化：两枚指针都站在表头

先保持 slow 不动，只移动 fast，直到两者之间恰好相隔 k 个 next。

键盘：← 上一步，→ 下一步，空格播放 / 暂停，Home 重置。

题解保险柜

核心洞察、证明、复杂度与四语言代码默认隐藏，准备好后再展开。

核心洞察

让 fast 比 slow 先走 k 步。之后两者速度相同，所以间距始终保持 k。当 fast 走出链表时，slow 后面恰好还有 k - 1 个节点，它就是倒数第 k 个节点。

fast 走过 n 步到 null
slow 同步阶段走 n - k 步
slow 索引 = n - k = 倒数第 k 个

完整过程

  1. 令 slow = head、fast = head。
  2. 只移动 fast 共 k 次，建立固定间距。
  3. 当 fast 非空时，同时移动 slow 与 fast 一次。
  4. fast 变为 null 时，返回 slow.val。

边界

  • k = 1：slow 最终落在尾节点。
  • k = n：fast 预走后直接为 null，slow 仍在表头。
  • 单节点时只能有 k = 1，直接返回该值。
  • 官方保证 k 有效；若扩展为不可信输入，应检查空链表和越界。

复杂度

时间复杂度 O(n)：每个指针至多走完整条链表。空间复杂度 O(1)：只使用两个节点引用。

替代方案

两次遍历可先统计长度 n，再从表头走 n - k 步；同样是 O(n) / O(1)，但多一次完整扫描。递归回溯能从尾部计数，却需要 O(n) 调用栈，长链表有栈溢出风险。

面试追问

  • 若 k 可能越界，怎样在不额外遍历的前提下返回错误？
  • 若要求返回节点而非节点值，需要改动哪一行？
  • 如果链表含环，这个算法为什么不会终止，应如何先处理？

常见错误

  • fast 只预走 k - 1 步，导致结果偏后一个节点。
  • 同步循环写成 while (fast.next != null)，把 k = 1 的答案算错。
  • 返回 slow 节点，但题目接口要求返回整数值 slow.val。
  • 先把所有值放进数组，虽然正确，却把额外空间从 O(1) 提升到 O(n)。

四语言可提交代码

class Solution {
    public int kthToLast(ListNode head, int k) {
        ListNode slow = head;
        ListNode fast = head;

        for (int i = 0; i < k; i++) {
            fast = fast.next;
        }

        while (fast != null) {
            slow = slow.next;
            fast = fast.next;
        }
        return slow.val;
    }
}
