千位分隔数

Thousand Separator

给定一个整数 n，每隔三位数字插入一个点号 . 作为千位分隔符，并以字符串形式返回结果。

完整题解

Solution

从右向左，三位成组

核心洞察

分隔点的位置由数字到字符串右端的距离决定：每取满 3 位，若左侧仍有数字，就插入一个点。由右向左处理可以让这个判断保持固定。

完整过程

  1. 把 n 转成十进制字符串 s。
  2. 从末尾向开头遍历，把当前字符加入结果。
  3. 已处理位数是 3 的倍数且左侧仍有字符时，加入 .。
  4. 反转临时结果，得到最终字符串。

正确性说明

从右端起，第 3、6、9……位之后正是十进制数的千位分组边界。算法仅在边界左侧仍有数字时插点，因此不会产生前导点；每个原数字恰好复制一次且顺序经最终反转后保持不变，所以结果正确。

边界情况

  • n = 0：字符串只有一位，直接得到 "0"。
  • 少于四位：不会插入分隔点。
  • 位数恰为 3 的倍数：最左侧分组前不能多插点。
  • 最大值 2147483647：结果为 "2.147.483.647"。

复杂度

设十进制位数为 d。时间复杂度 O(d)，构造返回字符串所需额外空间为 O(d)。

替代方案

也可从左向右遍历，依据“剩余位数是否为 3 的倍数”决定插点；或者切分第一个较短分组，再连续追加三位分组。面试中不建议直接依赖本地化格式 API，因为分隔符可能受语言环境影响。

面试追问

  • 若允许负数，如何跳过负号并保持分组正确？
  • 如何把分组宽度和分隔符变成可配置参数？
  • 如果输入是无法装入整数类型的超长数字字符串，方案是否仍成立？

常见错误

  • 每三位无条件插点，导致最左侧出现多余的 .。
  • 忘记处理 0。
  • 从右向左追加后忘记反转结果。
  • JavaScript 使用区域格式化 API，产生逗号或受环境影响。

Java
class Solution {
    public String thousandSeparator(int n) {
        String s = String.valueOf(n);
        StringBuilder reversed = new StringBuilder();

        for (int i = s.length() - 1, count = 0; i >= 0; i--) {
            if (count > 0 && count % 3 == 0) {
                reversed.append('.');
            }
            reversed.append(s.charAt(i));
            count++;
        }
        return reversed.reverse().toString();
    }
}

var thousandSeparator = function(n) {
    const s = String(n);
    const reversed = [];

    for (let i = s.length - 1, count = 0; i >= 0; i--, count++) {
        if (count > 0 && count % 3 === 0) {
            reversed.push('.');
        }
        reversed.push(s[i]);
    }
    return reversed.reverse().join('');
};
Python 3
class Solution:
    def thousandSeparator(self, n: int) -> str:
        s = str(n)
        reversed_chars = []

        for count, digit in enumerate(reversed(s)):
            if count > 0 and count % 3 == 0:
                reversed_chars.append('.')
            reversed_chars.append(digit)

        return ''.join(reversed(reversed_chars))
C++
class Solution {
public:
    string thousandSeparator(int n) {
        string s = to_string(n);
        string reversed;

        for (int i = static_cast<int>(s.size()) - 1, count = 0;
             i >= 0; --i, ++count) {
            if (count > 0 && count % 3 == 0) {
                reversed.push_back('.');
            }
            reversed.push_back(s[i]);
        }
        reverse(reversed.begin(), reversed.end());
        return reversed;
    }
};
