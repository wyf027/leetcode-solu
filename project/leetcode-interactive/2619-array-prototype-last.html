数组原型对象的
最后一个元素

Array Prototype Last

为所有数组增加可调用的 last() 方法。它应返回数组最后一个元素；当数组为空时返回 -1。可以假设输入数组来自 JSON.parse。

04 / Solution

准备好再看题解

先自己想一想：如何同时区分空数组与“最后一项恰好是假值”的数组？

Solution Unlocked

用长度守住边界，用索引直达末尾

核心洞察

方法挂在 Array.prototype 上，普通函数被数组调用时，函数体里的 this 就是该数组。先用 this.length === 0 精确判断空数组；否则最后一个合法索引必然是 this.length - 1。

不能按元素真假判断：0、false、空字符串和 null 都可能是合法的最后一项。

完整过程

Step 01

取得调用者

由 nums.last() 的调用形式得到 this === nums。

Step 02

判断长度

若 this.length === 0，直接返回题目规定的 -1。

Step 03

读取末项

非空时读取 this[this.length - 1]，不修改原数组。

正确性说明

  1. 若数组长度为 0，数组没有最后一个元素，算法返回题目要求的 -1。
  2. 若数组长度为 n > 0，它的合法索引为 0 到 n - 1，因此 n - 1 正是最后一个索引。
  3. 算法返回该索引处的原值，所以无论该值是否为假值，结果都准确且数组保持不变。

边界与复杂度

  • 空数组：返回 -1。
  • 单元素数组：返回索引 0 的元素。
  • 最后一项为 null、false、0 或 ""：原样返回。
  • 时间复杂度：O(1)。
  • 额外空间复杂度：O(1)。

四种语言实现

本题官方可提交语言为 JavaScript / TypeScript。Java、Python 与 C++ 不支持用同样方式修改 JavaScript 的 Array.prototype，因此以下三份代码仅是“取末项，否则返回 -1”的本地语义参考，不能直接提交到本题。

JavaScript官方可提交
/**
 * @return {null|boolean|number|string|Array|Object}
 */
Array.prototype.last = function () {
  return this.length === 0 ? -1 : this[this.length - 1];
};

/**
 * const arr = [1, 2, 3];
 * arr.last(); // 3
 */
Java本地语义参考
import java.util.List;

class Solution {
    public static Object last(List<?> array) {
        return array.isEmpty()
            ? -1
            : array.get(array.size() - 1);
    }
}
Python本地语义参考
from typing import Any


def last(array: list[Any]) -> Any:
    return -1 if not array else array[-1]
C++本地语义参考
#include <variant>
#include <vector>

template <typename T>
std::variant<int, T> last(const std::vector<T>& array) {
    if (array.empty()) return -1;
    return array.back();
}

替代方案

写法是否可用说明
this.at(-1)需搭配长度判断负索引可读性好，但空数组会得到 undefined，仍须单独返回 -1。
this.slice(-1)[0]可用但多余会创建临时数组，空间不再是严格的 O(1)。
this.pop()不应使用会删除末项并改变原数组，副作用不符合只读取末项的语义。

面试追问

为什么不能写成箭头函数？

箭头函数没有自己的 this，无法通过 nums.last() 的调用方式取得数组接收者。

如何避免覆盖已有的原型方法？

生产代码可先检查属性，或用 Object.defineProperty 明确配置；在线题按指定签名直接赋值即可。

为什么题目强调 JSON.parse？

它限定了元素为 JSON 值，也排除了稀疏数组、函数、undefined 等额外情况。

常见错误

  • 访问 this[this.length]，产生一位偏移错误。
  • 使用 this[this.length - 1] || -1，错误吞掉 0、false、"" 和 null。
  • 用 pop() 获取末项，意外修改输入数组。
  • 把原型方法写成箭头函数，导致 this 不是调用数组。
