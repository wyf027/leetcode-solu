Check if One String Swap Can Make Strings Equal

在两个等长字符串之间，判断是否能选择其中一个字符串，最多交换一对位置，使它们完全相同。

01 · Problem

题目描述

给定长度相等的字符串 s1 与 s2。一次交换可以在同一个字符串中选择两个下标（允许相同），交换对应字符。

如果只对其中一个字符串执行最多一次交换，就能让两者相等，返回 true；否则返回 false。

函数形式： areAlmostEqual(s1: string, s2: string): boolean

示例 1

输入：s1 = "bank", s2 = "kanb"
输出：true
解释：交换 s2 的下标 0 与 3，可得到 "bank"。

示例 2

输入：s1 = "attack", s2 = "defend"
输出：false
解释：一次交换无法让两个字符串相等。

示例 3

输入：s1 = "kelb", s2 = "kelb"
输出：true
解释：两者已经相等，无需交换。

示例 4

输入：s1 = "abcd", s2 = "dcba"
输出：false

约束

  • 1 <= s1.length, s2.length <= 100
  • s1.length == s2.length
  • s1 和 s2 只包含小写英文字母。

04 · Solution

准备好再揭晓

题解包含判断规律、正确性证明、复杂度与四种语言的完整实现。

题解：只记录错位位置

核心洞察

一次交换只会影响两个位置。因此两个字符串的错位数量必须是 0 或 2：0 表示已经相等；2 表示这两个位置上的字符必须刚好交叉相等。

s1[i] == s2[j] && s1[j] == s2[i]

完整过程

  1. 从左到右比较同一下标的字符。
  2. 记录所有 s1[i] != s2[i] 的下标；超过 2 个可立即返回 false。
  3. 扫描结束后，0 个错位返回 true；不是 2 个返回 false。
  4. 恰好 2 个错位时检查交叉相等。

正确性

  1. 若没有错位，两字符串已经相等，满足“最多一次交换”。
  2. 若恰有两个错位 i,j 且字符交叉相等，交换一个字符串的 i,j 后，这两处以及其他原本相同的位置都相等。
  3. 反之，一次交换最多改变两个位置；若能成功，原字符串只能有 0 或 2 个错位，且两个被交换字符必然交叉对应。因此算法返回 true 当且仅当题目条件成立。

边界与复杂度

  • 长度为 1 且相同：直接为 true。
  • 只有 1 个错位：交换会同时影响两个位置，无法修复，返回 false。
  • 相同字符可选择相同下标交换，仍视为满足最多一次。
  • 时间复杂度 O(n)，额外空间 O(1)（只保存两个下标）。

替代方案

可以收集全部错位下标后统一判断，写法直观，但最坏会使用 O(n) 空间。也可以先统计字符频率，但频率相同并不足以证明一次交换可达，仍需检查错位数量与交叉关系。

面试追问

  • 若允许至多 k 次交换，如何判断？可把位置映射看作置换环，并计算修复所需交换数。
  • 若只能交换相邻字符，条件会如何变化？需要考察逆序或最小相邻交换距离。
  • 如果字符串很长且流式到达？可在线保存前两个错位，并在第三个错位时提前失败。

常见错误

  • 只判断两个字符串字符频率相同，忽略可能有四个或更多错位。
  • 错位数为 2 时，只比较一侧字符，没有做双向交叉检查。
  • 把已经相等误判为 false；题目允许“最多一次”，所以可以不交换。
  • 把“在一个字符串内交换”误写成跨字符串交换。
Java官方签名
class Solution {
    public boolean areAlmostEqual(String s1, String s2) {
        int first = -1;
        int second = -1;

        for (int i = 0; i < s1.length(); i++) {
            if (s1.charAt(i) == s2.charAt(i)) continue;
            if (first == -1) first = i;
            else if (second == -1) second = i;
            else return false;
        }

        if (first == -1) return true;
        if (second == -1) return false;
        return s1.charAt(first) == s2.charAt(second)
            && s1.charAt(second) == s2.charAt(first);
    }
}

var areAlmostEqual = function(s1, s2) {
    let first = -1;
    let second = -1;

    for (let i = 0; i < s1.length; i++) {
        if (s1[i] === s2[i]) continue;
        if (first === -1) first = i;
        else if (second === -1) second = i;
        else return false;
    }

    if (first === -1) return true;
    if (second === -1) return false;
    return s1[first] === s2[second]
        && s1[second] === s2[first];
};
Python 3官方签名
class Solution:
    def areAlmostEqual(self, s1: str, s2: str) -> bool:
        mismatch = []

        for i, (a, b) in enumerate(zip(s1, s2)):
            if a != b:
                mismatch.append(i)
                if len(mismatch) > 2:
                    return False

        if not mismatch:
            return True
        if len(mismatch) != 2:
            return False

        i, j = mismatch
        return s1[i] == s2[j] and s1[j] == s2[i]

class Solution {
public:
    bool areAlmostEqual(string s1, string s2) {
        int first = -1;
        int second = -1;

        for (int i = 0; i < static_cast<int>(s1.size()); ++i) {
            if (s1[i] == s2[i]) continue;
            if (first == -1) first = i;
            else if (second == -1) second = i;
            else return false;
        }

        if (first == -1) return true;
        if (second == -1) return false;
        return s1[first] == s2[second]
            && s1[second] == s2[first];
    }
};
