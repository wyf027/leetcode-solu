获取单值网格的最小操作数

Minimum Operations to Make a Uni-Value Grid

每次走固定的一步，所有格子能否相遇？

官方题目 ↗

01 / 题目与示例

给定 m × n 的整数网格 grid 和正整数 x。每次选一个元素，将它增加 x 或减少 x。返回使全部元素相等所需的最少操作次数；无法实现时返回 -1。

参数形式：minOperations(grid, x) → integer

官方示例 1

输入：grid = [[2,4],[6,8]], x = 2
输出：4

把 2 增加一次，6 减少一次，8 减少两次，全部变成 4，共 4 次。

官方示例 2

输入：grid = [[1,5],[2,3]], x = 1
输出：5

全部变成 3，总共需要 5 次操作。

官方示例 3

输入：grid = [[1,2],[3,4]], x = 2
输出：-1

无法使所有元素相等。

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 10⁵
  • 1 ≤ m × n ≤ 10⁵
  • 1 ≤ x, grid[i][j] ≤ 10⁴

04 / 推导与实现

核心洞察

加减 x 保持模 x 的余数不变。全部元素同余才可统一。可行时，目标 t 的代价为 Σ|aᵢ−t|/x，选择中位数可以最小化绝对距离之和。

完整过程

  1. 展开网格为 N=m×n 个数，比较各自模 x 的余数，不一致返回 -1。
  2. 升序排序，选择下标 ⌊N/2⌋ 的元素作为目标。
  3. 对每个数累加绝对差除以 x，返回总操作数。

示例 1 排序得到 [2,4,6,8]，代码选 6，代价为 2+1+0+1=4。官方选 4，两者都是最优目标。

正确性

必要性：一次操作不改变余数，因此不同余数无法相遇。充分性：同余时两数之差可整除 x，选择数组中的任意数都能让其他数有限步抵达。

将排序后的两端配对。对 u≤v，|u−t|+|v−t|≥v−u，且 t∈[u,v] 时等号成立。所有配对区间都包含中位数；奇数长度未配对的中间数也在中位数处取得零距离。因此中位数使总距离最小。它来自原数组，保证可达；单格至少需要 |aᵢ−t|/x 次，逐格沿正确方向操作恰好达到此下界，因此总和最优。

边界与复杂度

  • 单个元素或全部相同：0 次。x=1 时始终可行。
  • 偶数长度：两个中间数之间所有同余目标都最优，选择其中一个即可。
  • 时间 O(N log N)，额外空间 O(N)。
  • 当前约束下粗略总和上界为 999900000，32 位有符号整数足够；放宽数值约束则使用 64 位累计。

替代方案

快速选择可用平均 O(N) 时间求中位数，普通实现最坏 O(N²)。利用数值上界 V=10⁴，可用频次数组在 O(N+V) 时间、O(V) 空间求解。排序更直接。

常见错误

  • 选平均数：它不保证绝对距离之和最小，也可能不可达。
  • 未检查同余便整除：会把不可达差值截断。
  • 忘记除以步长 x。
  • JavaScript 使用默认字符串排序，而不是数值比较器。

面试追问

每格操作成本不同怎么办？使用加权中位数。每格步长不同怎么办？需要重新分析同余可行性与目标优化，不能直接套用普通中位数。如何保护输入？使用新的展开数组，下方代码均不改动原网格。

Java

import java.util.Arrays;
class Solution {
    public int minOperations(int[][] grid, int x) {
        int[] a = new int[grid.length * grid[0].length];
        int k = 0, r = grid[0][0] % x;
        for (int[] row : grid) for (int v : row) {
            if (v % x != r) return -1;
            a[k++] = v;
        }
        Arrays.sort(a);
        int target = a[a.length / 2], ans = 0;
        for (int v : a) ans += Math.abs(v - target) / x;
        return ans;
    }
}

JavaScript

/** @param {number[][]} grid @param {number} x @return {number} */
var minOperations = function(grid, x) {
    const a = grid.flat();
    if (a.some(v => v % x !== a[0] % x)) return -1;
    a.sort((a, b) => a - b);
    const target = a[Math.floor(a.length / 2)];
    return a.reduce((sum, v) => sum + Math.abs(v - target) / x, 0);
};

Python

from typing import List
class Solution:
    def minOperations(self, grid: List[List[int]], x: int) -> int:
        a = [v for row in grid for v in row]
        if any(v % x != a[0] % x for v in a):
            return -1
        a.sort()
        target = a[len(a) // 2]
        return sum(abs(v - target) // x for v in a)

C++

#include <vector>
#include <algorithm>
#include <cstdlib>
using namespace std;
class Solution {
public:
    int minOperations(vector<vector<int>>& grid, int x) {
        vector<int> a;
        int r = grid[0][0] % x;
        for (const auto& row : grid) for (int v : row) {
            if (v % x != r) return -1;
            a.push_back(v);
        }
        sort(a.begin(), a.end());
        int target = a[a.size() / 2], ans = 0;
        for (int v : a) ans += abs(v - target) / x;
        return ans;
    }
};
