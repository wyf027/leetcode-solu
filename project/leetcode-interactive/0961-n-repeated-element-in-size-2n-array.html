N-Repeated Element in Size 2N Array

在长度 2N 的数组中
找出重复 N 次的元素

一个长度为 2n 的数组里，有 n + 1 个不同的值：其中 n 个只出现一次，另一个恰好出现 n 次。请返回这个特殊的值。

先读题、观察示例并亲手探索。完整解法藏在页面底部。

示例与约束

示例 1
输入：nums = [1,2,3,3]
输出：3
示例 2
输入：nums = [2,1,2,5,3,2]
输出：2
示例 3
输入：nums = [5,1,5,2,5,3,5,4]
输出：5
  • 2 ≤ n ≤ 5000
  • nums.length == 2 * n
  • 0 ≤ nums[i] ≤ 10⁴
  • 共有 n + 1 个不同元素，且唯一一个元素出现恰好 n 次。

Solution

哈希集合：第一次重逢就是答案

核心洞察

从左到右扫描，把尚未出现的值放进集合。某个值第一次已经存在于集合时，它就是重复元素。因为题目保证除目标外所有值都只出现一次，所以不存在误判。

完整过程

  1. 创建空哈希集合 seen。
  2. 依次访问 nums 中的每个元素 x。
  3. 若 x 已在 seen 中，立即返回 x；否则加入集合。

正确性证明

算法只会在某个值第二次出现时返回它。题设中，恰有目标值出现多次，其余每个值都恰好出现一次；因此被第二次遇见的值必然是目标。目标出现 n ≥ 2 次，所以扫描结束前一定能遇到它的第二次出现并返回。故算法正确。

边界

  • 重复值可位于数组开头或末尾。
  • 重复值可以是 0。
  • 最小规模 n = 2 同样适用。

复杂度

时间 O(n)，最多扫描 2n 个元素；空间 O(n)，集合最多保存 n + 1 个值。

替代方案

利用高频元素在长度 2n 数组中的间距性质，只检查相距 1、2 或 3 的元素即可做到 O(n) 时间、O(1) 空间；也可排序后查相邻重复，但时间为 O(n log n) 且可能修改输入。集合方案最直接、最不易出错。

四语言实现

import java.util.HashSet;
import java.util.Set;

class Solution {
    public int repeatedNTimes(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int value : nums) {
            if (!seen.add(value)) return value;
        }
        throw new IllegalArgumentException("Invalid input");
    }
}
/**
 * @param {number[]} nums
 * @return {number}
 */
var repeatedNTimes = function(nums) {
    const seen = new Set();
    for (const value of nums) {
        if (seen.has(value)) return value;
        seen.add(value);
    }
    throw new Error("Invalid input");
};
from typing import List

class Solution:
    def repeatedNTimes(self, nums: List[int]) -> int:
        seen = set()
        for value in nums:
            if value in seen:
                return value
            seen.add(value)
        raise ValueError("Invalid input")
#include <stdexcept>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    int repeatedNTimes(vector<int>& nums) {
        unordered_set<int> seen;
        for (int value : nums) {
            if (!seen.insert(value).second) return value;
        }
        throw invalid_argument("Invalid input");
    }
};

面试追问

  • 能否做到常数空间？ 可以利用重复元素必在相距不超过 3 的位置形成一对这一性质。
  • 若题目不保证只有一个重复值？ 集合方法只能返回第一个再次遇到的值，需要重新定义返回目标。
  • 为什么无需统计到 n 次？ 唯一性保证第二次出现已经足以确认身份。

常见错误

  • 把“出现 n 次”误写为数值等于 n。
  • 先完整计数再遍历，虽正确但增加了不必要步骤。
  • 使用固定大小数组计数，却忽略值域或通用性。
  • 在无法到达的结尾随意返回 0，掩盖非法输入。
