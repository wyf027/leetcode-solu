交换链表中的节点

Swapping Nodes in a Linked List · 先观察问题与指针移动，再决定是否展开完整题解。

官方参数形式
swapNodes(head: ListNode, k: integer) → ListNode

Problem

题意

给定单链表头节点 head 和整数 k。交换链表中从开头数第 k 个节点与从末尾数第 k 个节点的值，返回链表头节点。节点位置从 1 开始计数。

示例 1
输入：head = [1,2,3,4,5], k = 2 输出：[1,4,3,2,5]
示例 2
输入：head = [7,9,6,6,7,8,3,0,9,5], k = 5 输出：[7,9,6,6,8,7,3,0,9,5]
示例 3
输入：head = [1], k = 1 输出：[1]
示例 4
输入：head = [1,2], k = 1 输出：[2,1]
示例 5
输入：head = [1,2,3], k = 2 输出：[1,2,3]

约束

  • 链表节点数为 n
  • 1 ≤ k ≤ n ≤ 10⁵
  • 0 ≤ Node.val ≤ 100

Full Solution

一次遍历的双指针距离同步

核心洞察：先让 first 落在正数第 k 个节点；再令 fast = first、second = head。二者同步前进到 fast 抵达尾部时，second 恰好位于倒数第 k 个节点。

完整过程

  1. 从头节点出发，将 first 向后移动 k - 1 次，定位正数第 k 个节点。
  2. 令 fast = first，并令 second = head。
  3. 只要 fast.next 存在，就让 fast 与 second 同时后移一格。
  4. fast 到达末节点时，second 就是倒数第 k 个节点。交换 first.val 与 second.val，返回 head。

正确性证明

first 是正数第 k 个节点，因此从 first 到链表末节点一共还需要移动 n - k 次。fast 从 first 出发、second 从 head 出发，两者每轮各移动一次；当 fast 移动 n - k 次到达末节点时，second 也从第 1 个节点移动到第 n - k + 1 个节点。该位置距末尾正好为 k，即倒数第 k 个节点。因此交换两者的值后，所得链表满足题意。

复杂度与边界

时间复杂度 O(n)指针总移动次数与节点数线性相关。
空间复杂度 O(1)只使用固定数量的指针与临时值。
同一节点当 2k = n + 1 时，两指针指向中间节点，自交换不改变链表。
边界位置k = 1 时交换首尾值；单节点链表保持不变。

替代方案

可以遍历链表，把每个节点引用存入数组，再按下标交换第 k - 1 与第 n - k 个节点的值。它同样是 O(n) 时间，但需要 O(n) 额外空间。也可以先遍历计算 n，再第二次遍历定位两个位置；空间仍为 O(1)，但需要两趟链表。

四语言完整代码

JavaO(n) · O(1)
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode swapNodes(ListNode head, int k) {
        ListNode first = head;
        for (int i = 1; i < k; i++) {
            first = first.next;
        }

        ListNode fast = first;
        ListNode second = head;
        while (fast.next != null) {
            fast = fast.next;
            second = second.next;
        }

        int temp = first.val;
        first.val = second.val;
        second.val = temp;
        return head;
    }
}

/**
 * Definition for singly-linked list.
 * function ListNode(val, next) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.next = (next === undefined ? null : next);
 * }
 */
/**
 * @param {ListNode} head
 * @param {number} k
 * @return {ListNode}
 */
var swapNodes = function(head, k) {
    let first = head;
    for (let i = 1; i < k; i++) {
        first = first.next;
    }

    let fast = first;
    let second = head;
    while (fast.next !== null) {
        fast = fast.next;
        second = second.next;
    }

    [first.val, second.val] = [second.val, first.val];
    return head;
};

C++O(n) · O(1)
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* swapNodes(ListNode* head, int k) {
        ListNode* first = head;
        for (int i = 1; i < k; ++i) {
            first = first->next;
        }

        ListNode* fast = first;
        ListNode* second = head;
        while (fast->next != nullptr) {
            fast = fast->next;
            second = second->next;
        }

        std::swap(first->val, second->val);
        return head;
    }
};

面试追问

为什么选择交换值？题目明确要求交换节点的值。若交换节点本身，还要维护前驱、相邻与首尾等更多边界。
能否一趟遍历？可以。first 定位后，fast 与 second 同步移动；整个过程中每条边最多被常数次访问。
如果要求交换节点而不是值？需要额外记录两个节点的前驱，并分别处理同一节点、相邻节点以及涉及头节点的情况。
如果 k 非法怎么办？本题约束保证 k 有效；工程代码中应在解引用前做空指针和范围校验。

常见错误

  • 把倒数第 k 个位置写成数组下标 n - k + 1，忘记数组通常从 0 开始。
  • fast 多走或少走一步，导致 second 停在倒数第 k ± 1 个节点。
  • 错误地重连节点 next，而题目只要求交换值，徒增链表断裂风险。
  • 忽略两个目标位置可能是同一个节点；正确的值交换无需特殊分支。
