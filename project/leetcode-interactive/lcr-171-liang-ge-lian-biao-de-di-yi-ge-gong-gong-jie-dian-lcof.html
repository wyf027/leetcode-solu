训练计划 V

两套训练计划各自有一段前缀，随后可能汇入同一条共享路线。返回它们同一个节点对象首次相遇的位置；节点值相同并不表示相交。

题意与官方示例

给定两个单链表的头节点 headA、headB，找到并返回第一个公共节点；没有交点则返回 null。链表无环，且不得改动原链表。

目标：O(m + n) 时间、O(1) 额外空间。

intersectVal = 8, listA = [4,1,8,4,5], listB = [5,0,1,8,4,5], skipA = 2, skipB = 3

输出：Intersected at '8'。注意交点是同一节点 c1，不是两个值同为 8 的独立节点。

约束：0 ≤ m, n ≤ 3 × 10⁴；1 ≤ Node.val ≤ 10⁵。

交互实验室：两条指针的“换轨”

输入各自前缀和共享尾部（英文逗号分隔）。每一步两指针各走一格；走到 null 时切换到另一链表头部。

示例中的空格只是排版；这里的逗号分隔值会建立节点身份。留空共享尾部即可测试不相交。

题解：路径长度抵消，而不是比较值

令 A 前缀长为 a、B 前缀长为 b、共享尾部为 c。指针 pA 走完 A 后改走 B，pB 走完 B 后改走 A；它们都恰好走过 a + b + c 条边，因此会在公共节点相遇。没有公共节点时，它们会同时成为 null。

  1. 初始化 pA = headA、pB = headB。
  2. 当两者不是同一个节点时，各前进一步；空指针改到对方头部。
  3. 相等时直接返回：可能是首个公共节点，也可能同为 null。

边界与常见错误

  • 用 === / 指针身份判断，不能比较 val。
  • 共享尾部为空时最终两指针一起变成 null。
  • 不要改写 next；题面要求保留结构。
  • 先算长度也可行，但双指针换轨更短且不易出错。

复杂度与追问

O(m+n) 时间，O(1) 额外空间。

追问：若链表允许成环，先用 Floyd 判环，再分情况讨论入环点；本题明确无环，因此不需要这一分支。

替代方案：哈希集合记录 A 的全部节点，再遍历 B；易理解但用掉 O(m) 空间。 

var getIntersectionNode = function(headA, headB) {
  let a = headA, b = headB;
  while (a !== b) {
    a = a === null ? headB : a.next;
    b = b === null ? headA : b.next;
  }
  return a;
};
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        ListNode a = headA, b = headB;
        while (a != b) {
            a = (a == null) ? headB : a.next;
            b = (b == null) ? headA : b.next;
        }
        return a;
    }
}
class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> ListNode:

public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        ListNode *a = headA, *b = headB;
        while (a != b) {
            a = a ? a->next : headB;
            b = b ? b->next : headA;
