LeetCode 100 Easy Binary Tree Paired DFS

相同的树，同步扫描

把两棵树放进同一台比较仪：结构与节点值必须在每一个对应位置同时通过，才算真正相同。

开始扫描
01 / PROBLEM

题意

给定两棵二叉树的根节点，判断它们是否完全相同。

判断标准

输入根节点 p 和 q。当且仅当两棵树在每个对应位置上都拥有相同的结构，并且对应节点值也相等时，返回 true；否则返回 false。

“相同”包含两个条件：空节点的位置一致，非空节点的值一致。

约束

  • 两棵树的节点总数均在 [0, 100] 范围内。
  • -104 ≤ Node.val ≤ 104。
  • 空树也要参与比较：两棵空树相同。
样例 1 · 完全相同
输入 p = [1,2,3],␠q = [1,2,3] 输出 true
样例 2 · 结构不同
输入 p = [1,2],␠q = [1,null,2] 输出 false
样例 3 · 节点值不同
输入 p = [1,2,1],␠q = [1,1,2] 输出 false

输入中的 ␠ 是可见空格标记，仅用于帮助辨认参数之间的空格；提交代码时不需要输入该符号。

04 / SOLUTION VAULT

题解

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误与四语言代码默认收起。

核心洞察 · 成对递归

不要分别遍历两棵树再比较结果；直接把 (p, q) 当成一个递归状态。每次先处理空节点，再比较值，最后同步进入左右子树。 

same(p, q) =
  true                         两者都为空
  false                        仅一者为空
  false                        p.val ≠ q.val
  same(p.left, q.left)
    AND same(p.right, q.right) 其余情况

完整过程

  1. 若 p 与 q 都为空，当前位置相同，返回 true。
  2. 若只有一侧为空，结构不同，立即返回 false。
  3. 若两侧节点值不同，立即返回 false。
  4. 递归比较左子树对与右子树对；两者都为真时才返回真。

边界与短路

  • 两棵空树：第一条规则直接返回 true。
  • 一个为空、一个非空：必须在读取 val 前返回。
  • 值相同但子节点方向不同：空节点位置会揭示结构差异。
  • && / and 会短路；左侧失败后无需继续扫描右侧。

复杂度

O(n) 最坏访问两棵树中所有对应节点，n 为较小遍历边界内实际检查的节点数。
O(h) 递归栈深度等于树高；平衡树为 O(log n)，链状树为 O(n)。

替代方案取舍

  • 成对 BFS：显式队列可避免深递归，但代码更长，额外空间仍为 O(w)。
  • 序列化后比较：必须保留空节点标记，否则不同结构可能得到相同序列；还会创建额外字符串。
  • 面试推荐：成对 DFS 直接对应定义，证明短、实现小、最不易遗漏结构条件。

面试追问

  • 如果树可能有十万层，如何规避递归栈溢出？改用显式栈或成对 BFS。
  • 为什么只比较前序遍历值不够？未记录空位置时无法唯一确定结构。
  • 如何判断两棵树镜像相同？把递归配对改为左—右、右—左。
  • 能否复用同一对象引用？可以先判断 p == q 快速返回，但不是必要条件。

常见错误

  • 先读取 p.val，再判断空节点，导致空指针异常。
  • 只比较值集合或遍历值，漏掉左右结构。
  • 把左子树与对方右子树配对，写成了镜像判断。
  • 左右结果使用“或”，只要一个分支相同就错误返回真。

正确性说明

递归基例精确覆盖空节点结构。对任意非空节点对，算法先确保当前值相等，再要求左右对应子树都相同。根据树高归纳，这与“结构相同且对应值相等”的定义等价。

class Solution {
    public boolean isSameTree(TreeNode p, TreeNode q) {
        if (p == null && q == null) {
            return true;
        }
        if (p == null || q == null) {
            return false;
        }
        if (p.val != q.val) {
            return false;
        }

        return isSameTree(p.left, q.left)
                && isSameTree(p.right, q.right);
    }
}
