01 · Problem brief

题意与数据结构

给定 Views 表，找出至少浏览过一篇自己文章的作者。输出列名为 id，每位作者只出现一次，最后按 id 升序排列。

Views 表

article_idINT · 文章编号
author_idINT · 作者编号
viewer_idINT · 浏览者编号
view_dateDATE · 浏览日期

数据含义

每一行表示某位浏览者在某天看过某位作者的一篇文章。若 author_id 与 viewer_id 相同，两者就是同一个人。

约束与特征

  • 表没有主键，因此可能包含完全重复的行。
  • 四个字段类型依次为 INT、INT、INT、DATE。
  • 结果需要去重，并按作者 id 升序返回。

04 · Complete solution

完整题解

核心洞察

“作者浏览自己的文章”在一行数据中就等价于 author_id = viewer_id。筛选后只保留作者编号；由于原表允许重复，必须去重；最后按编号升序排列。

完整过程

  1. 用 WHERE 保留作者与浏览者相同的行。
  2. 用 DISTINCT 消除同一作者的重复命中。
  3. 将 author_id 别名设为题目要求的 id。
  4. 用 ORDER BY id 生成升序结果。

正确性说明

  1. 不会漏：任何浏览过自己文章的作者，都至少存在一行满足 author_id = viewer_id，因此筛选必然保留该行并输出其编号。
  2. 不会多：任何被筛选保留的行都满足作者编号等于浏览者编号，所以输出的作者确实浏览过自己的文章。
  3. 结果形式正确：DISTINCT 保证每位作者只出现一次，ORDER BY 保证编号升序。因此结果恰好是题目要求的作者集合。

边界情况

  • 没有任何本人浏览记录时，返回空结果。
  • 同一行重复多次时，作者仍只输出一次。
  • 同一作者浏览自己的多篇文章时，仍只输出一次。
  • 输入顺序任意时，最终仍需按 id 升序。

复杂度

从关系数据库执行视角看，需要扫描候选行，时间通常记为 O(n) 加上去重与排序开销；若有 k 个唯一命中作者，排序为 O(k log k)。额外空间取决于数据库执行计划，去重通常需要 O(k) 级别。

替代方案

可以使用 GROUP BY author_id 代替 DISTINCT。本题没有聚合计算，DISTINCT 更直接地表达“唯一作者”。也可先写子查询再排序，但会增加不必要的层级。

常见错误

  • 把两个字段写成不等于，筛到了他人浏览。
  • 忘记去重，重复行导致重复作者。
  • 忘记将输出列别名设置为 id。
  • 省略显式排序，误以为数据库天然有序。

面试追问

  • 如果要统计每位作者看自己文章的次数？ 需要明确是按浏览记录计数，还是按文章/日期去重后计数，再选择相应的 COUNT 表达式。
  • 为什么必须写 ORDER BY？ SQL 结果集在没有显式排序时不保证顺序，执行计划变化也可能改变返回次序。
  • DISTINCT 与 GROUP BY 怎么选？ 只去重时优先选择意图更直接的 DISTINCT；需要聚合时再使用 GROUP BY。
  • 什么索引可能有帮助？ 需结合数据库与数据规模评估；跨两列的相等条件不一定能直接受益于普通单列索引，不能脱离执行计划武断下结论。

Java 17仅本地语义参考
import java.util.ArrayList;
import java.util.List;
import java.util.Set;
import java.util.TreeSet;

class Solution {
    // row: [article_id, author_id, viewer_id]
    public List<Integer> articleViews(int[][] views) {
        Set<Integer> authorIds = new TreeSet<>();

        for (int[] row : views) {
            int authorId = row[1];
            int viewerId = row[2];
            if (authorId == viewerId) {
                authorIds.add(authorId);
            }
        }

        return new ArrayList<>(authorIds);
    }
}

function articleViews(views) {
  const authorIds = new Set();

  for (const [, authorId, viewerId] of views) {
    if (authorId === viewerId) {
      authorIds.add(authorId);
    }
  }

  return Array.from(authorIds)
    .sort((a, b) => a - b)
    .map((id) => ({ id }));
}
Python 3仅本地语义参考
from typing import Iterable, List, Tuple, TypedDict


class ResultRow(TypedDict):
    id: int


ViewRow = Tuple[int, int, int, str]


def article_views(views: Iterable[ViewRow]) -> List[ResultRow]:
    author_ids = {
        author_id
        for _, author_id, viewer_id, _ in views
        if author_id == viewer_id
    }
    return [{"id": author_id} for author_id in sorted(author_ids)]

#include <array>
#include <set>
#include <vector>
using namespace std;

class Solution {
public:
    // row: {article_id, author_id, viewer_id}
    vector<int> articleViews(const vector<array<int, 3>>& views) {
        set<int> authorIds;

        for (const auto& row : views) {
            if (row[1] == row[2]) {
                authorIds.insert(row[1]);
            }
        }

        return vector<int>(authorIds.begin(), authorIds.end());
    }
};
