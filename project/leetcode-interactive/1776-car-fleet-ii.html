Problem

题意

一条单车道上有 n 辆车同向行驶。cars[i] = [positionᵢ, speedᵢ] 表示第 i 辆车的初始位置（米）与初始速度（米/秒），并且所有位置严格递增。

车辆视为数轴上的点。两车到达同一位置时会合并为车队；合并后的车队速度等于队内最慢车辆的初始速度。返回 answer，其中 answer[i] 是第 i 辆车第一次与它前面的车相撞所需的秒数；永不相撞则为 -1。允许绝对或相对误差在 10⁻⁵ 内。

函数签名： getCollisionTimes(cars: integer[][]) → double[]

示例 1

输入cars = [[1,2],[2,1],[4,3],[7,2]] 输出[1.00000,-1.00000,3.00000,-1.00000]

1 秒时，第 0 辆车追上第 1 辆车并以 1 m/s 行驶；3 秒时，第 2 辆车追上第 3 辆车并以 2 m/s 行驶。

示例 2

输入cars = [[3,4],[5,4],[6,3],[9,1]] 输出[2.00000,1.00000,1.50000,-1.00000]

这组数据会用于下方交互演示；每一步都可手动前进或回退。

约束

  • 1 ≤ cars.length ≤ 10⁵
  • 1 ≤ positionᵢ, speedᵢ ≤ 10⁶
  • positionᵢ < positionᵢ₊₁

Monotonic stack

单调候选栈：跳过注定先合并的车

核心洞察

从右向左处理。栈只保存“仍可能成为左侧车辆首次碰撞对象”的车辆下标。设当前车为 i，栈顶为 j：

  1. 若 speed[i] ≤ speed[j]，当前车永远追不上 j，弹出 j。
  2. 否则计算直接追上时间 t = (position[j] - position[i]) / (speed[i] - speed[j])。
  3. 若 j 永不碰撞，或 t ≤ answer[j]，说明当前车能在 j 改变速度前追上它，t 就是答案。
  4. 若 t > answer[j]，则 j 会先并入前方车队；对当前车而言，j 不可能成为首次碰撞对象，弹出后继续看更前方的候选。

完整过程

初始化全部答案为 -1，栈为空。依次令 i = n-1 ... 0，按照上面的两类淘汰规则清理栈顶。若最终还有候选，就计算并记录碰撞时间；随后将 i 入栈，供更左侧车辆使用。

为何等号可接受？ 当 t == answer[j] 时，当前车恰在 j 与前车合并的同一时刻到达同一点，仍算第一次碰撞，因此条件是 t ≤ answer[j]。

正确性证明

引理 1：速度不快于栈顶时，栈顶不可能被当前车直接追上。

当前车在栈顶候选之后且速度不大于它，两车距离不会缩短。若栈顶以后减速，它必先与更前方车辆碰撞；因此当前车的有效首次目标应继续向前寻找，弹出该候选安全。

引理 2：若直接追上时间晚于栈顶自己的碰撞时间，栈顶不可能成为当前车的首次碰撞对象。

在当前车到达之前，栈顶已经与前方车队合并并改变速度。当前车若发生碰撞，实际接触的是合并后的车队；更前方保留的候选完整代表这个未来车队，所以弹出栈顶不丢失答案。

引理 3：清理后剩余的栈顶给出当前车的首次碰撞时间。

此时当前车更快，且能在栈顶改变速度之前（或栈顶永不改变速度）追上它。两者之间所有无法成为首次目标的车辆均已由引理 1、2 排除，因此该碰撞最先发生。

定理

从右向左归纳：右侧车辆的答案已正确，清理规则不删除任何可能的首次目标，剩余栈顶由引理 3 给出唯一正确答案；无剩余候选时答案为 -1。故算法对所有车辆都正确。

复杂度

每辆车最多入栈一次、出栈一次，时间复杂度 O(n)；答案与栈占用 O(n) 空间。

边界情况

  • 只有一辆车：答案为 [-1]。
  • 速度非递减：后车追不上前车，均为 -1。
  • 多车同一时刻相撞：使用 ≤ 保留合法碰撞。
  • 位置、速度较大：时间计算必须使用浮点数。

替代方案

可以用事件驱动的最小堆持续取出最早相撞事件，并用链表维护尚存车队；但要处理失效事件与邻接更新，复杂度通常为 O(n log n)，实现也更繁琐。单调栈利用“只关心右侧首次有效目标”的结构，将其降到线性时间。

面试追问

  • 为什么从右向左？ 当前车的判定依赖右侧车辆何时碰撞，右到左能保证依赖已经求出。
  • 栈是按什么单调？ 重点不是某个数值严格单调，而是候选的可见性与碰撞时间形成可弹出的单调结构。
  • 能否用整数避免精度误差？ 比较两个时间时可交叉相乘，但最终仍需返回浮点数；注意乘法溢出。
  • 若合并速度改为平均速度？ 当前证明失效，因为车队速度不再由前方慢车稳定决定，需要新的事件模拟结构。

常见错误

  • 只弹出速度更快的车，却没有判断候选是否会先碰撞。
  • 将 t ≤ answer[j] 错写成严格小于，漏掉同时碰撞。
  • 使用整数除法导致小数时间被截断。
  • 把“下一辆车”理解为永远固定的原始相邻下标，忽略车队合并。

class Solution {
    public double[] getCollisionTimes(int[][] cars) {
        int n = cars.length;
        double[] answer = new double[n];
        java.util.Arrays.fill(answer, -1.0);
        int[] stack = new int[n];
        int top = -1;

        for (int i = n - 1; i >= 0; --i) {
            while (top >= 0) {
                int j = stack[top];
                if (cars[i][1] <= cars[j][1]) {
                    --top;
                    continue;
                }
                double time = (double) (cars[j][0] - cars[i][0])
                        / (cars[i][1] - cars[j][1]);
                if (answer[j] < 0 || time <= answer[j]) {
                    answer[i] = time;
                    break;
                }
                --top;
            }
            stack[++top] = i;
        }
        return answer;
    }
}

    def getCollisionTimes(self, cars: List[List[int]]) -> List[float]:
        n = len(cars)
        answer = [-1.0] * n
        stack = []

        for i in range(n - 1, -1, -1):

class Solution {
public:
    vector<double> getCollisionTimes(vector<vector<int>>& cars) {
        int n = static_cast<int>(cars.size());
        vector<double> answer(n, -1.0);
        vector<int> stack;

        for (int i = n - 1; i >= 0; --i) {
            while (!stack.empty()) {
                int j = stack.back();
                if (cars[i][1] <= cars[j][1]) {
                    stack.pop_back();
                    continue;

                double time = static_cast<double>(cars[j][0] - cars[i][0]) /
                              (cars[i][1] - cars[j][1]);
                if (answer[j] < 0 || time <= answer[j]) {
                    answer[i] = time;
                    break;
                }
                stack.pop_back();
            }
            stack.push_back(i);
        }
        return answer;
    }
};
