交错字符串

按各自原有顺序，从两个字符串轮流取字符，能否刚好拼出第三个字符串？

题意

给定字符串 s1、s2、s3，判断 s3 是否可由 s1 与 s2 交错组成。每个源串的字符相对顺序必须不变。

示例

s1 = "aabcc", s2 = "dbbca"

s3 = "aadbbcbcac"

输出：true

约束

  • 0 <= s1.length, s2.length <= 100
  • 0 <= s3.length <= 200
  • 字符串只含小写英文字母。

先记住一个关键事实：取了 i 个 s1 字符和 j 个 s2 字符时，s3 已经消费 i+j 个字符。题解默认隐藏。

题解工作台

默认隐藏，避免首屏泄露。

核心洞察

状态 dp[i][j] 表示 s1 前 i 个与 s2 前 j 个，能否组成 s3 前 i+j 个。最后一个字符只能来自两个源串中的一个。

过程

  1. 先检查总长度是否相等。
  2. 初始化空前缀的首行和首列。
  3. 若 s1 或 s2 的上一个字符匹配目标字符，且前一状态为真，则当前状态为真。

边界

长度不等必为 false；任意一个源串为空时，结果只取决于另一个源串是否等于 s3。

复杂度

二维 DP 时间 O(m×n)。可滚动压缩为一维数组，使额外空间降为 O(n)。

替代方案

带记忆的递归也能表达“下一步从哪个源串取”，但迭代 DP 避免递归栈并更容易压缩空间。

常见错误

  • 忘记先判断三者长度关系。
  • 目标下标错写为 i+j 而非 i+j-1。
  • 只选择一个来源，没有用“或”保留两条可行路径。

参考实现

Java

class Solution {
    public boolean isInterleave(String s1, String s2, String s3) {
        if (s1.length() + s2.length() != s3.length()) return false;
        boolean[] dp = new boolean[s2.length() + 1]; dp[0] = true;
        for (int i = 0; i <= s1.length(); i++)
            for (int j = 0; j <= s2.length(); j++) {
                if (i > 0) dp[j] &= s1.charAt(i - 1) == s3.charAt(i + j - 1);
                if (j > 0) dp[j] |= dp[j - 1] && s2.charAt(j - 1) == s3.charAt(i + j - 1);
            }
        return dp[s2.length()];
    }
}

JavaScript

var isInterleave = function(s1, s2, s3) {
  if (s1.length + s2.length !== s3.length) return false;
  const dp = Array(s2.length + 1).fill(false); dp[0] = true;
  for (let i = 0; i <= s1.length; i++) {
    for (let j = 0; j <= s2.length; j++) {
      if (i > 0) dp[j] &= s1[i - 1] === s3[i + j - 1];
      if (j > 0) dp[j] ||= dp[j - 1] && s2[j - 1] === s3[i + j - 1];
    }
  }
  return dp[s2.length];
};

class Solution:
    def isInterleave(self, s1: str, s2: str, s3: str) -> bool:
        if len(s1) + len(s2) != len(s3): return False
        dp = [False] * (len(s2) + 1); dp[0] = True
        for i in range(len(s1) + 1):
            for j in range(len(s2) + 1):
                if i: dp[j] &= s1[i - 1] == s3[i + j - 1]
                if j: dp[j] |= dp[j - 1] and s2[j - 1] == s3[i + j - 1]
        return dp[-1]

C++

class Solution {
public:
    bool isInterleave(string s1, string s2, string s3) {
        if (s1.size() + s2.size() != s3.size()) return false;
        vector<bool> dp(s2.size() + 1); dp[0] = true;
        for (int i = 0; i <= s1.size(); ++i)
            for (int j = 0; j <= s2.size(); ++j) {
                if (i) dp[j] = dp[j] && s1[i - 1] == s3[i + j - 1];
                if (j) dp[j] = dp[j] || (dp[j - 1] && s2[j - 1] == s3[i + j - 1]);
            }
        return dp.back();
    }
};
