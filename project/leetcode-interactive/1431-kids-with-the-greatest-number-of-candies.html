Problem 1431

拥有最多糖果的孩子

Kids With the Greatest Number of Candies

有 n 个孩子，candies[i] 表示第 i 个孩子当前拥有的糖果数。你有 extraCandies 颗额外糖果；依次设想把它们全部给某一个孩子，判断该孩子此时能否达到所有孩子中的最多糖果数。

返回长度为 n 的布尔数组。并列最多也算满足条件，因此可能有多个位置为 true。

输入约束

  • n == candies.length
  • 2 <= n <= 100

返回形式

kidsWithCandies(candies, extraCandies) 返回 List<Boolean> / boolean[]。每一项对应一个孩子，允许多人并列第一。

完整题解

准备好后再打开，避免首屏直接泄露思路。

核心洞察

先找出原数组中的最大糖果数 maxCandies。对于每个孩子，只需检查 candies[i] + extraCandies >= maxCandies。这里必须使用“大于等于”，因为题目允许并列最多。

完整过程

  1. 扫描 candies，记录原始最大值。
  2. 再次扫描数组，计算每个孩子加糖后的数量。
  3. 与原始最大值比较，将布尔结果依次加入答案。
  4. 返回与输入等长的布尔数组。

正确性说明

设原数组最大值为 M。把全部额外糖果给孩子 i 后，该孩子有 candies[i] + extraCandies 颗；其他孩子的数量都不变，且均不超过 M。若这个新数量至少为 M，孩子 i 不少于任何其他孩子，结果应为 true；若小于 M，至少原先达到 M 的孩子仍比他多，结果应为 false。因此该判断对每个位置都正确。

复杂度

两次线性扫描，时间复杂度 O(n)；除返回数组外，额外空间复杂度 O(1)。

边界情况

多个原始最大值；最小长度 2；所有孩子糖果数相同；额外糖果刚好补齐差值；额外糖果仍不足。

替代方案

也可对每个孩子重新扫描数组判断是否最大，但会变成 O(n²)，没有必要。排序会丢失位置关系且为 O(n log n)。

面试追问

  • 为什么比较的是原数组最大值，而不是逐次修改后的最大值？
  • 若额外糖果可以拆分给多个孩子，问题会如何变化？
  • 若数据以流式输入，怎样维护当前最大值？
  • 能否原地复用输入空间？这会带来什么接口副作用？

常见错误

  • 使用 >，错误排除并列最多的孩子。
  • 每处理一个孩子就修改原数组，污染后续比较。
  • 把额外糖果分给所有孩子，而题意是每次设想全部给一个孩子。
  • 排序后直接输出，导致答案顺序不再对应原孩子。

class Solution {
    public List<Boolean> kidsWithCandies(int[] candies, int extraCandies) {
        int maxCandies = 0;
        for (int candy : candies) {
            maxCandies = Math.max(maxCandies, candy);
        }

        List<Boolean> result = new ArrayList<>(candies.length);
        for (int candy : candies) {
            result.add(candy + extraCandies >= maxCandies);
        }
        return result;
    }
}
