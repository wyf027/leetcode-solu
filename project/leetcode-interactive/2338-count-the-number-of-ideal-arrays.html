统计理想数组的数目

Count the Number of Ideal Arrays

相邻元素之间只有一条规则：后一个数必须是前一个数的倍数。
当长度和取值上界都达到一万，如何数清所有可能？

01 / 题目

给定整数 n 和 maxValue。统计长度恰好为 n 的不同整数数组 arr，要求每项都在闭区间 [1, maxValue] 内，且对每个 1 ≤ i < n，都有 arr[i] % arr[i - 1] = 0。返回计数对 1,000,000,007 取模的结果。

数组按每个位置的数值区分；允许重复元素。整除方向不能反过来，例如 [2, 4, 4] 合法，[4, 2, 4] 不合法。

约束
  • 2 ≤ n ≤ 10⁴
  • 1 ≤ maxValue ≤ 10⁴

题解 / 固定末项，拆开指数

核心洞察

先固定最后一项为 x。此前的每项都整除 x，所以自动不超过 maxValue。若 x = ∏ pᵉ，每个质数 p 在数组中的指数必须单调不减，最终达到 e。

把初始指数看作 0，用 d₁, d₂, …, dₙ 表示每个位置新加入的指数。于是 dᵢ ≥ 0 且 Σdᵢ = e。这是把 e 个相同单位放入 n 个有序盒子的计数：C(n + e − 1, e)。

ways(x) = ∏ C(n + e − 1, e)
answer = Σ ways(x)，其中 1 ≤ x ≤ maxValue

不同质数的指数可以独立选择，所以相乘；不同末项对应互不相交的数组集合，所以相加。x = 1 的空乘积为 1。

指数分配实验室

固定末项的每一种数组

每一步更换一组“新增指数”。观察每个质数的指数如何累积，再合成数组。这里只枚举一个末项 x 的贡献，不是整道题的总答案。

演示范围：2 ≤ n ≤ 5，1 ≤ x ≤ 24；用于观察组合机制。x 可视为某个 maxValue ≥ x 的末项。

逐位合成的数组

可用 Tab 切换控件、Enter / 空格操作按钮。自动播放每 1.2 秒一步，到末尾停止。

完整过程：用加法预计算组合数

  1. 设 M = maxValue，E = ⌊log₂ M⌋。任何 x ≤ M 的单个质因子指数都不会超过 E；本题 E ≤ 13。
  2. 用最小质因子筛得到 spf，快速分解每个末项。
  3. 令 c[e] 为当前盒子数量下，分配 e 个指数单位的方案数。只有 1 个盒子时，所有 c[e] = 1。每增加一个盒子，按 e 从小到大更新 c[e] = (c[e] + c[e − 1]) % MOD。重复 n − 1 轮，得到 C(n + e − 1, e)。
  4. 枚举 x = 1…M，分解出各质因子的指数 e，计算 c[e] 的乘积并累加；每次加乘均取模。

例：n = 3，末项 x = 12 = 2² × 3¹。指数 2 的分配有 C(4,2) = 6 种，指数 1 的分配有 C(3,1) = 3 种，共 18 种。它是 maxValue ≥ 12 时总答案中的一项。

正确性

一一对应：合法数组的每个质数指数序列单调不减，差分得到唯一的非负分配；反过来，累加任意非负分配，再将各质数幂相乘，就得到相邻整除且末项为 x 的唯一数组。这两个操作互为逆操作。

计数递推：F(k,e) 表示 k 个盒子分配 e 个单位。末盒为空时有 F(k−1,e) 种；末盒非空时移去其中一个单位，有 F(k,e−1) 种。因此 F(k,e) = F(k−1,e) + F(k,e−1)。正序更新保留上一行 c[e]，使用本行 c[e−1]，恰好实现递推。

汇总：质因数分解唯一，各质数分配独立；末项又唯一划分全部合法数组。因此乘积不漏不重，求和得到答案。

边界与复杂度

  • M = 1 时 E = 0，只有全 1 数组，返回 1。
  • 重复值对应所有质数在该位置的增量为 0，不能排除。
  • 令 E = ⌊log₂ M⌋。筛耗时 O(M log log M)，组合数 O(nE)，全部分解的保守上界 O(ME)。总时间可写为 O((n + M) log(M + 1))，空间 O(M + E)。
  • Java / C++ 用 64 位整数承接模乘；JavaScript 用 BigInt 做乘法，避免 Number 超出安全整数范围。

替代方案

可以先用 DP 统计长度 k 的严格递增整除链，再乘 C(n − 1, k − 1)：把链上每个值重复正整数次填满 n 个位置。严格增长至少翻倍，所以 k ≤ E + 1；按倍数转移的时间约 O(E M log M)，空间滚动后 O(M)。指数法不需要枚举链。

组合数也可用模逆元递推 C(n+e−1,e) = C(n+e−2,e−1) × (n+e−1) / e，将预计算降到 O(E)（线性逆元）。本页使用加法 DP，E ≤ 13 时足够小，且四语言容易保持一致。

常见错误

  • 只检查非递减，遗漏真正的整除条件，例如 [2,3]。
  • 误用 C(n,e)，指数允许在同一位置多次增加。
  • 把各质数的方案数相加；同一末项应相乘。
  • c 的更新从大到小，错误地使用上一行 c[e−1]。
  • 用浮点数乘两个模值，或取模后直接做普通整数除法。

面试追问

若固定末项？只需该末项对应的乘积。若允许 n = 1？所有 c[e] = 1，答案为 M。若要求严格递增？改用严格整除链 DP；质数指数独立计数会允许所有质数同时不变，无法直接沿用。n 极大怎么办？使用小指数的乘积公式与模逆元，不再执行 n 轮 DP。

Java
class Solution {
    public int idealArrays(int n, int maxValue) {
        final long MOD = 1_000_000_007L;
        int E = 0;
        for (int v = maxValue; v > 1; v /= 2) E++;
        long[] c = new long[E + 1];
        java.util.Arrays.fill(c, 1L);
        for (int k = 2; k <= n; k++)
            for (int e = 1; e <= E; e++)
                c[e] = (c[e] + c[e - 1]) % MOD;

        int[] spf = new int[maxValue + 1];
        for (int p = 2; p <= maxValue; p++) {
            if (spf[p] != 0) continue;
            for (int v = p; v <= maxValue; v += p)
                if (spf[v] == 0) spf[v] = p;
        }
        long answer = 0;
        for (int x = 1; x <= maxValue; x++) {
            int v = x;
            long ways = 1;
            while (v > 1) {
                int p = spf[v], e = 0;
                while (v % p == 0) {
                    v /= p;
                    e++;
                }
                ways = ways * c[e] % MOD;
            }
            answer = (answer + ways) % MOD;
        }
        return (int) answer;
    }
}

var idealArrays = function(n, maxValue) {
    const MOD = 1000000007;
    let E = 0;
    for (let v = maxValue; v > 1; v = Math.floor(v / 2)) E++;
    const c = Array(E + 1).fill(1);
    for (let k = 2; k <= n; k++)
        for (let e = 1; e <= E; e++)
            c[e] = (c[e] + c[e - 1]) % MOD;
    const bigC = c.map(value => BigInt(value));
    const bigMOD = 1000000007n;
    const spf = new Int32Array(maxValue + 1);
    for (let p = 2; p <= maxValue; p++) {
        if (spf[p] !== 0) continue;
        for (let v = p; v <= maxValue; v += p)
            if (spf[v] === 0) spf[v] = p;
    }
    let answer = 0n;
    for (let x = 1; x <= maxValue; x++) {
        let v = x, ways = 1n;
        while (v > 1) {
            const p = spf[v];
            let e = 0;
            while (v % p === 0) {
                v /= p;
                e++;

            ways = ways * bigC[e] % bigMOD;
        }
        answer = (answer + ways) % bigMOD;
    }
    return Number(answer);

class Solution:
    def idealArrays(self, n: int, maxValue: int) -> int:
        mod = 1_000_000_007
        E = maxValue.bit_length() - 1
        c = [1] * (E + 1)
        for _ in range(n - 1):
            for e in range(1, E + 1):
                c[e] = (c[e] + c[e - 1]) % mod

        spf = [0] * (maxValue + 1)
        for p in range(2, maxValue + 1):
            if spf[p]:
                continue
            for v in range(p, maxValue + 1, p):
                if spf[v] == 0:
                    spf[v] = p

        answer = 0
        for x in range(1, maxValue + 1):
            v, ways = x, 1
            while v > 1:
                p, e = spf[v], 0
                while v % p == 0:
                    v //= p
                    e += 1
                ways = ways * c[e] % mod
            answer = (answer + ways) % mod
        return answer
C++
#include <vector>
using namespace std;

class Solution {
public:
    int idealArrays(int n, int maxValue) {
        const long long MOD = 1000000007LL;
        int E = 0;
        for (int v = maxValue; v > 1; v /= 2) ++E;
        vector<long long> c(E + 1, 1);
        for (int k = 2; k <= n; ++k)
            for (int e = 1; e <= E; ++e)
                c[e] = (c[e] + c[e - 1]) % MOD;

        vector<int> spf(maxValue + 1, 0);
        for (int p = 2; p <= maxValue; ++p) {
            if (spf[p]) continue;
            for (int v = p; v <= maxValue; v += p)
                if (!spf[v]) spf[v] = p;
        }
        long long answer = 0;
        for (int x = 1; x <= maxValue; ++x) {
            int v = x;
            long long ways = 1;
            while (v > 1) {
                int p = spf[v], e = 0;
                while (v % p == 0) {
                    v /= p;
                    ++e;
                }
                ways = ways * c[e] % MOD;
            }
            answer = (answer + ways) % MOD;
        }
        return static_cast<int>(answer);
    }
};
