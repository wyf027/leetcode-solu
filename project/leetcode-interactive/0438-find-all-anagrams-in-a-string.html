Problem

题目描述

给定两个仅由小写英文字母组成的字符串 s 和 p。请找出 s 中所有与 p 互为字母异位词的连续子串，并返回这些子串的起始索引；索引顺序不限。

字母异位词包含完全相同的字符及出现次数，只是排列顺序可能不同。

FUNCTION

findAnagrams(s, p) → integer[]

1 ≤ s.length, p.length ≤ 3 × 10⁴

s、p 仅含 a-z

示例 1

输入：s = "cbaebabacd", p = "abc"

输出：[0, 6]

索引 0 的 “cba” 与索引 6 的 “bac” 都与 “abc” 字母组成相同。

示例 2

输入：s = "abab", p = "ab"

输出：[0, 1, 2]

长度为 2 的三个窗口 “ab”、“ba”、“ab” 全部匹配。

Solution

题解：固定窗口 + 字符频次

核心洞察

异位词只关心字符出现次数，不关心排列。候选子串长度必定等于 p.length，因此维护一个固定长度窗口即可。用长度 26 的数组记录 p 与当前窗口的频次差；窗口每右移一次，只需撤销左端字符并加入右端字符。

完整过程

  1. 若 p 比 s 长，直接返回空数组。
  2. 统计 p 与 s 的首个等长窗口。这里采用差值数组：加入 p[i] 时加一，加入窗口字符 s[i] 时减一。
  3. 若 26 个差值全为零，记录首窗口起点 0。
  4. 令右端逐步进入新字符：离开的左端字符使对应差值加一，新进入的右端字符使对应差值减一。
  5. 每次移动后检查差值数组；全零则记录新的窗口起点。

正确性说明

不变量：每次检查窗口时，差值数组的第 k 项恒等于字符 k 在 p 中的次数减去它在当前窗口中的次数。初始化直接建立该不变量；滑动时，移出的字符在窗口中少一次，所以差值加一，移入的字符在窗口中多一次，所以差值减一，其余项不变，因此不变量保持。

当前窗口与 p 是异位词，当且仅当二者对每个小写字母的出现次数都相等，也就是差值数组全部为零。因此算法记录且只记录所有正确起点。

边界情况

  • p.length > s.length：不存在等长窗口。
  • 两串都只有一个字符：相同则返回 [0]，否则为空。
  • 字符大量重复，例如 s="aaaa", p="aa"：重叠窗口都应被记录。
  • s.length == p.length：只检查唯一窗口。

复杂度

设 n = s.length。每个字符至多进出窗口一次；逐窗检查固定 26 项，因此时间复杂度为 O(26n) = O(n)，额外空间复杂度为 O(26) = O(1)。

替代方案

可以给每个窗口排序后与排序后的 p 比较，但会反复排序，通常达到 O(n · m log m)。也可以维护“非零差值项数量”，把每次匹配判断从扫描 26 项优化成常数次更新；在固定小写字母表下，两种滑窗实现都为线性复杂度，扫描 26 项的版本更直观、也更不易写错。

面试追问

  • 若字符集是 Unicode，如何把固定数组改成哈希表，并高效维护非零项数量？
  • 如何把算法改造成流式处理，使 s 无需一次性全部加载？
  • 为什么不能只比较窗口字符之和或哈希值？怎样分析碰撞风险？
  • 怎样输出匹配子串本身，同时避免不必要的字符串复制？

常见错误

  • 窗口移动后忘记恢复离开字符的计数，导致账本逐步失真。
  • 窗口边界混用闭区间与左闭右开区间，出现少检查或越界。
  • 只比较窗口中不同字符的种类数，忽略同一字符的重复次数。
  • 用 substring + sort 让代码看似简短，却无法满足大输入下的线性性能目标。

JavaLeetCode 可提交
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> ans = new ArrayList<>();
        int n = s.length(), m = p.length();
        if (m > n) return ans;

        int[] diff = new int[26];
        for (int i = 0; i < m; i++) {
            diff[p.charAt(i) - 'a']++;
            diff[s.charAt(i) - 'a']--;
        }
        if (allZero(diff)) ans.add(0);

        for (int right = m; right < n; right++) {
            diff[s.charAt(right - m) - 'a']++;
            diff[s.charAt(right) - 'a']--;
            if (allZero(diff)) ans.add(right - m + 1);
        }
        return ans;
    }

    private boolean allZero(int[] diff) {
        for (int value : diff) {
            if (value != 0) return false;
        }
        return true;
    }
}

/**
 * @param {string} s
 * @param {string} p
 * @return {number[]}

var findAnagrams = function(s, p) {
    const n = s.length;
    const m = p.length;
    const answer = [];
    if (m > n) return answer;

    const diff = new Array(26).fill(0);
    const index = (char) => char.charCodeAt(0) - 97;

    for (let i = 0; i < m; i++) {
        diff[index(p[i])]++;
        diff[index(s[i])]--;
    }
    if (diff.every((value) => value === 0)) answer.push(0);

    for (let right = m; right < n; right++) {
        diff[index(s[right - m])]++;
        diff[index(s[right])]--;
        if (diff.every((value) => value === 0)) {
            answer.push(right - m + 1);
        }
    }
    return answer;
};

from typing import List


class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        n, m = len(s), len(p)
        if m > n:
            return []

        diff = [0] * 26
        for i in range(m):
            diff[ord(p[i]) - ord("a")] += 1
            diff[ord(s[i]) - ord("a")] -= 1

        answer = [0] if all(value == 0 for value in diff) else []
        for right in range(m, n):
            diff[ord(s[right - m]) - ord("a")] += 1
            diff[ord(s[right]) - ord("a")] -= 1
            if all(value == 0 for value in diff):
                answer.append(right - m + 1)
        return answer
C++LeetCode 可提交
#include <array>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> answer;
        int n = static_cast<int>(s.size());
        int m = static_cast<int>(p.size());
        if (m > n) return answer;

        array<int, 26> diff{};
        for (int i = 0; i < m; ++i) {
            ++diff[p[i] - 'a'];
            --diff[s[i] - 'a'];
        }
        if (isZero(diff)) answer.push_back(0);

        for (int right = m; right < n; ++right) {
            ++diff[s[right - m] - 'a'];
            --diff[s[right] - 'a'];
            if (isZero(diff)) answer.push_back(right - m + 1);
        }
        return answer;
    }

private:
    bool isZero(const array<int, 26>& diff) {
        for (int value : diff) {
            if (value != 0) return false;
        }
        return true;
    }
};
