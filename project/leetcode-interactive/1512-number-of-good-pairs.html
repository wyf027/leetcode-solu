好数对的数目Number of Good Pairs

在一个小数组里，寻找“值相等、左下标更小”的二元关系。先读懂规则，再用下方实验台观察每个元素如何改变答案。

非付费题哈希表数学计数
01

题目说明

先明确什么是“好数对”。

给定整数数组 nums，请返回其中好数对的数量。若一对下标 (i, j) 同时满足 nums[i] == nums[j] 与 i < j，它就是一组好数对。

Example 01
输入：nums = [1,2,3,1,1,3]
输出：4
解释：(0,3)、(0,4)、(3,4)、(2,5)
Example 02
输入：nums = [1,1,1,1]
输出：6
解释：任取两个不同下标都能组成好数对
Example 03
输入：nums = [1,2,3]
输出：0
约束
  • 1 <= nums.length <= 100
  • 1 <= nums[i] <= 100

04

完整题解

一次扫描，在遇见相同值的那一刻计算新增数对。

核心洞察

当扫描到值 x 时，若它此前已出现 k 次，那么当前下标能与这 k 个旧下标分别组成一个新数对。因此先把答案增加 k，再把 x 的出现次数加一。

完整过程

  1. 创建计数表 count，答案 ans = 0。
  2. 依次读取每个元素 x。
  3. 令 ans += count[x]，再执行 count[x]++。
  4. 扫描结束后返回 ans。

正确性说明

处理下标 j 时，计数表只记录下标小于 j 的元素。表中 count[nums[j]] 恰好等于满足 i < j 且 nums[i] = nums[j] 的下标 i 数量，所以本步加入的数对完整且没有误计。

每个好数对只会在其右端点 j 被处理时计入一次，因此扫描结束后，答案恰好等于全部好数对数量。

复杂度

时间复杂度 O(n)；哈希计数的空间复杂度 O(m)，其中 m 是不同数字的个数，最坏为 O(n)。

边界情况

  • 数组只有一个元素：无法选择两个下标，答案为 0。
  • 所有元素互不相同：每次此前出现次数都是 0。
  • 所有元素相同：答案为 n × (n - 1) / 2。
  • 重复值分散在数组中：计数表仍只依赖已扫描前缀，不受距离影响。

常见错误

  • 先递增计数再累加，会把当前元素与自己配成一对。
  • 把条件写成 i <= j，错误包含同一下标。
  • 对所有元素频次直接求平方，没有排除顺序与自配对。
  • 双重循环时重复计算 (i,j) 与 (j,i)。

替代方案

双重循环：枚举所有 i < j 并比较数值，时间 O(n²)、额外空间 O(1)，直观但没有利用计数。

频次组合：先统计每个值的总频次 f，再累加 f × (f - 1) / 2。同样是 O(n)，但无法像实验台那样实时展示答案的增长过程。

面试追问

  • 如果数组以数据流到达，怎样随到随报答案？当前单次扫描法可直接使用。
  • 若值域固定为 1 到 100，能否用长度 101 的数组替代哈希表？可以，常数更小。
  • 若要求返回所有数对而非数量，空间复杂度如何变化？至少与输出规模成正比。
05

四语言实现

均保持“先累加旧次数，再更新计数”的顺序。

JAVAO(n) · O(m)
class Solution {
    public int numIdenticalPairs(int[] nums) {
        int[] count = new int[101];
        int answer = 0;

        for (int value : nums) {
            answer += count[value];
            count[value]++;
        }
        return answer;
    }
}
JAVASCRIPTO(n) · O(m)
/**
 * @param {number[]} nums
 * @return {number}
 */
var numIdenticalPairs = function(nums) {
    const count = new Map();
    let answer = 0;

    for (const value of nums) {
        const seen = count.get(value) ?? 0;
        answer += seen;
        count.set(value, seen + 1);
    }
    return answer;
};
PYTHON 3O(n) · O(m)
from typing import List


class Solution:
    def numIdenticalPairs(self, nums: List[int]) -> int:
        count = {}
        answer = 0

        for value in nums:
            seen = count.get(value, 0)
            answer += seen
            count[value] = seen + 1

        return answer
