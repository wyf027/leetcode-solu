01 / 题目

给定 n 个节点（编号 0…n−1）组成的带权有向图。每个 edges[i] = [fromᵢ, toᵢ, weightᵢ] 表示一条从 fromᵢ 指向 toᵢ、权重为 weightᵢ 的边。

另给出互不相同的 src1、src2、dest。选择原图中的一部分节点和边，使两个起点都可以到达终点；返回所选子图的边权总和的最小值。不存在可行子图时返回 -1。同一条边被两条路线经过时，只计入子图一次。

参数：minimumWeight(n, edges, src1, src2, dest) → 整数（可能超出 32 位）。允许平行边。

官方示例 1

n = 6
edges = [[0,2,2],[0,5,6],[1,0,3],[1,4,5],[2,1,1],
         [2,3,3],[2,3,4],[3,4,2],[4,5,1]]
src1 = 0, src2 = 1, dest = 5
输出：9

选择 [[1,0,3],[0,5,6]]：0 直接到 5，1 经 0 到 5，子图边权和为 9。最优子图不唯一。

官方示例 2

n = 3
edges = [[0,1,1],[2,1,1]]
src1 = 0, src2 = 1, dest = 2
输出：-1

节点 1 无法到达节点 2，因此不存在满足要求的子图。边的方向不能反过来走。

全部约束

  • 3 ≤ n ≤ 10⁵；0 ≤ edges.length ≤ 10⁵。
  • edges[i].length = 3；1 ≤ weightᵢ ≤ 10⁵。
  • 0 ≤ fromᵢ, toᵢ, src1, src2, dest ≤ n−1。
  • fromᵢ ≠ toᵢ；src1、src2、dest 两两不同。

03 / 题解 · 找到汇合点

枚举汇合点 v：
答案 = minᵥ { d₁[v] + d₂[v] + dₜ[v] }
d₁、d₂：两个起点到 v 的最短距离；dₜ：v 到终点的最短距离。

核心洞察

可以选择一个最优子图，使两条路线在某个节点首次汇合后，共用一段通向终点的后缀。只需找到这个汇合点。它可以是某个起点或终点，允许某一段路径长度为 0。

完整过程

  1. 建立正向邻接表 G，以及把每条边 u → v 反成 v → u 的反向图 R，边权不变。
  2. 在 G 上从 src1、src2 分别运行 Dijkstra，得到 d₁、d₂。
  3. 在 R 上从 dest 运行一次 Dijkstra，得到原图中每个点到 dest 的距离 dₜ。
  4. 遍历全部节点。仅当三个距离均有限时计算三项之和，取最小值；若没有有效节点返回 −1。
  5. Dijkstra 使用最小堆。堆中允许存在旧记录；弹出时用 du != dist[u] 跳过失效条目。

05 / 为什么成立

最优子图可以整理成“汇合后共享后缀”

在最优可行子图 H 内，计算各节点到 dest 的最短距离。对每个能到达 dest 的非终点节点，仅保留一条满足最短路等式的出边。由于边权严格为正，沿保留边到 dest 的距离严格下降，不会成环。两个起点仍能到达终点，删除边不会增加成本。此时每个节点至多有一个后继，两条路线一旦相遇就不会分开。

用两个方向夹住最优值

设这两条路线首次相遇于 v。两段前缀和共享后缀的边互不重叠，总长度等于路线并集的权重。全图中的三段最短距离分别不大于这些路径长度，因此枚举公式的最小值 F ≤ OPT。

反过来，对任意三项距离都有限的 v，取对应三条最短路的边并集，它一定使两个起点都能到达 dest。重叠边仅计一次，故并集权重 ≤ 三项距离之和。选择公式的最小候选得到 OPT ≤ F。两者结合，F = OPT。

无需假设每个候选 v 的三条最短路都互不重叠；某个候选的三项和可以大于其边并集权重，上下界仍保证全局最小值正确。

边界与数值

  • 空边集、孤立节点、任一起点无法到 dest：返回 −1。起点到自身距离初始化为 0。
  • 平行边可直接保留；松弛自然会选择更优边。正权环不能降低路径成本。
  • Java 用 long，C++ 用 long long。Python 整数足够。JavaScript Number 足够精确：单条简单路径 ≤ (n−1) × 10⁵，三项和 < 3 × 10¹⁰ < 2⁵³。
  • 使用有限 INF 哨兵时先判断可达，再相加，并预留溢出空间。Java/C++ 示例使用最大整数的四分之一。

复杂度

记边数为 m。以下惰性删除二叉堆实现为 O(n + m log(m+1)) 时间，O(n+m) 空间，三次运行只增加常数。堆可能存放 O(m) 个记录，平行边也会产生旧记录。若压缩平行边或使用支持 decrease-key 的索引堆，可以写成常见的 O((n+m) log n) 时间界。

替代方案

逐个节点运行到 dest 的最短路能算出同一公式，但要重复 n 次，不能应对本题规模。Floyd–Warshall 是 O(n³) 时间、O(n²) 空间，仅适合小图。分别选两条起点到终点的最短路再取并集，可能错过有利的共享后缀，不能代替汇合点枚举。

常见错误

  • 直接相加两条起点到终点的最短距离，重复计算共享边。
  • 将有向图当作无向图，或在正向图从 dest 出发求 dₜ。
  • 排除起点或终点作为候选，漏掉零长度前缀或后缀。
  • 节点第一次入堆就认定距离最短；应等弹出当前最小有效记录。
  • 距离使用 32 位整数，或把不可达哨兵直接相加导致溢出。

面试追问

如何输出子图？ 三轮最短路记录前驱（反向图记录原图后继）及原始边编号，从最佳 v 恢复三段路径，再按边编号去重。

更多起点怎么办？ 三个及以上起点可能分层汇合，单一汇合点公式一般失效；少量起点可考虑子集动态规划结合最短路。

能允许负权吗？ Dijkstra 不再适用，负环还会改变路径距离与最优子图结构的意义，不能简单更换最短路函数后照搬全部证明。

06 / 四语言完整实现

对应官方参数顺序；以下均为可提交语言实现，尚未执行验证。

Java

import java.util.*;

class Solution {
    private static final long INF = Long.MAX_VALUE / 4;

    private long[] dijkstra(List<int[]>[] g, int source) {
        long[] d = new long[g.length];
        Arrays.fill(d, INF);
        d[source] = 0;
        PriorityQueue<long[]> pq = new PriorityQueue<>(
            Comparator.comparingLong(x -> x[0]));
        pq.offer(new long[]{0, source});
        while (!pq.isEmpty()) {
            long[] cur = pq.poll();
            long du = cur[0];
            int u = (int) cur[1];
            if (du != d[u]) continue;
            for (int[] e : g[u]) {
                int v = e[0], w = e[1];
                if (du + w < d[v]) {
                    d[v] = du + w;
                    pq.offer(new long[]{d[v], v});
                }
            }
        }
        return d;
    }

    public long minimumWeight(int n, int[][] edges, int src1, int src2, int dest) {
        @SuppressWarnings("unchecked")
        List<int[]>[] g = new List[n], r = new List[n];
        for (int i = 0; i < n; i++) {
            g[i] = new ArrayList<>(); r[i] = new ArrayList<>();
        }
        for (int[] e : edges) {
            g[e[0]].add(new int[]{e[1], e[2]});
            r[e[1]].add(new int[]{e[0], e[2]});
        }
        long[] a = dijkstra(g, src1), b = dijkstra(g, src2), c = dijkstra(r, dest);
        long ans = INF;
        for (int v = 0; v < n; v++) {
            if (a[v] == INF || b[v] == INF || c[v] == INF) continue;
            ans = Math.min(ans, a[v] + b[v] + c[v]);
        }
        return ans == INF ? -1 : ans;
    }
}

原生二叉堆，无平台专属依赖；可选 onStep 回调供本页演示使用，不传即为普通最短路计算。

Python

from typing import List
from heapq import heappush, heappop
from math import inf

class Solution:
    def minimumWeight(self, n: int, edges: List[List[int]], src1: int, src2: int, dest: int) -> int:
        g, reverse = [[] for _ in range(n)], [[] for _ in range(n)]
        for u, v, w in edges:
            g[u].append((v, w))
            reverse[v].append((u, w))

        def dijkstra(graph, source):
            dist = [inf] * n
            dist[source] = 0
            heap = [(0, source)]
            while heap:
                du, u = heappop(heap)
                if du != dist[u]:
                    continue
                for v, w in graph[u]:
                    nd = du + w
                    if nd < dist[v]:
                        dist[v] = nd
                        heappush(heap, (nd, v))
            return dist

        a = dijkstra(g, src1)
        b = dijkstra(g, src2)
        c = dijkstra(reverse, dest)
        ans = min(a[v] + b[v] + c[v] for v in range(n))
        return -1 if ans == inf else ans

C++

#include <vector>
#include <queue>
#include <functional>
#include <limits>
#include <algorithm>
#include <utility>
using namespace std;

class Solution {
    using ll = long long;
    using Graph = vector<vector<pair<int, int>>>;
    static constexpr ll INF = numeric_limits<ll>::max() / 4;
    vector<ll> dijkstra(const Graph& g, int source) {
        vector<ll> d(g.size(), INF);
        priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> pq;
        d[source] = 0;
        pq.push({0, source});
        while (!pq.empty()) {
            auto [du, u] = pq.top(); pq.pop();
            if (du != d[u]) continue;
            for (auto [v, w] : g[u]) {
                if (du + w < d[v]) {
                    d[v] = du + w;
                    pq.push({d[v], v});
                }
            }
        }
        return d;
    }
public:
    long long minimumWeight(int n, vector<vector<int>>& edges, int src1, int src2, int dest) {
        Graph g(n), r(n);
        for (const auto& e : edges) {
            g[e[0]].push_back({e[1], e[2]});
            r[e[1]].push_back({e[0], e[2]});
        }
        auto a = dijkstra(g, src1), b = dijkstra(g, src2), c = dijkstra(r, dest);
        ll ans = INF;
        for (int v = 0; v < n; ++v) {
            if (a[v] == INF || b[v] == INF || c[v] == INF) continue;
            ans = min(ans, a[v] + b[v] + c[v]);
        }
        return ans == INF ? -1 : ans;
    }
};
