01 / PROBLEM

题目不是从根开始

输入是同一棵 N 叉树的全部节点对象，顺序任意。节点之间原有的 children 引用仍然保留。

题意转述

给你一个数组 tree，其中恰好包含某棵 N 叉树的所有 Node 对象。每个节点的值唯一；除根节点外，每个节点都作为某个节点的直接孩子出现一次。请从这些对象中找到并返回根节点。

评测输入展示的是树的层序序列化：每组孩子之间以 null 分隔。评测器会先建树，再将全部节点打乱后传给 findRoot；返回节点会被重新序列化并与输入树比较。

进阶：能否只使用 O(1) 额外空间？

节点与参数形式

class Node {
  int val;
  List<Node> children;
}

Node findRoot(Node[] tree)

不同语言的容器类型略有差异，但传入的始终是 Node 对象集合，不是整数数组。

约束

  • 节点总数满足 1 ≤ tree.length ≤ 5 × 10⁴。
  • 每个节点的 val 唯一。
  • 输入包含同一棵合法 N 叉树中的全部 Node 对象，节点顺序任意。
  • 层序序列化中的 null 只用于分隔不同父节点的孩子组。

04 / SOLUTION

唯一没有父节点的对象

主解使用对象集合记录“出现为孩子”的节点，避免依赖节点值范围，逻辑直接且稳健。

CORE
INSIGHT

一棵合法树中，除根节点外，每个节点恰好有一个父节点。因此，遍历所有 children 后，唯一从未以孩子身份出现的 Node 就是根。

完整过程

  1. 创建集合 children。
  2. 遍历 tree 中每个节点，再遍历它的 children，把每个孩子对象加入集合。
  3. 再次遍历 tree；首个不在集合中的节点就是根，立即返回。

边界处理

  • 只有一个节点：集合为空，唯一节点直接返回。
  • 输入顺序任意：算法只看引用关系，与数组顺序无关。
  • 叶子节点：children 为空，不影响登记结果。
  • 节点值唯一：主解直接存 Node 对象，不必把值映射回对象。

正确性证明

引理：集合 children 最终恰好包含全部非根节点。任取非根节点 v，树的定义保证它有且仅有一个父节点；扫描该父节点的 children 时，v 被加入集合。反之，根节点没有父节点，所以不会出现在任何节点的 children 中，也就不会进入集合。

结论：第二次扫描时，根是唯一不在集合中的节点，算法返回的节点必然且只能是根。

时间O(n)共 n−1 条父子边
额外空间O(n)最多登记 n−1 个孩子
递归深度O(1)实现不做 DFS

替代方案

  • 值求和抵消：所有节点值之和减去所有孩子值之和，剩下根值；再找回对应 Node。额外空间 O(1)，但固定宽度整数可能溢出。
  • 按位异或：异或全部节点值与全部孩子值，成对值抵消，留下根值；不溢出，要求值唯一且语言的位运算能完整表示题目值域。
  • 入度表：显式统计每个节点入度，取入度 0；信息更完整，但本题只需布尔“出现过”。

面试追问

  • 如果 val 不唯一，O(1) 抵消法为什么失效？
  • 如果输入可能是森林，会返回多少个候选根？
  • 如果图中可能有环或节点缺失，如何验证输入合法性？
  • 流式输入、无法二次遍历时，该怎样保留根对象？

常见错误

  • 误把数组第一个节点当成根，忽略输入顺序已打乱。
  • 从每个节点做 DFS，造成重复遍历甚至 O(n²)。
  • 集合里存值后直接返回值，而函数要求返回 Node 对象。
  • 使用求和法却没有考虑整型溢出。

为什么不需要 DFS

寻找根只依赖“有没有父节点”这一局部结构，不依赖深度、路径或子树内容。把每条父子边读一遍，就已经收集了足够信息。

四语言完整实现

均采用对象集合主解；平台已提供 Node 定义，提交时只需 Solution 部分。

class Node {
    public int val;

class Solution {
    public Node findRoot(List<Node> tree) {
        Set<Node> children = new HashSet<>();

        for (Node node : tree) {
            for (Node child : node.children) {
                children.add(child);
            }
        }

        for (Node node : tree) {
            if (!children.contains(node)) {
                return node;
            }
        }

        return null; // 合法输入不会到达这里
    }
}

        children = set()

        for node in tree:

/*
// Definition for a Node.
class Node {
public:
    int val;
    vector<Node*> children;
    Node() {}
    Node(int _val) : val(_val) {}
    Node(int _val, vector<Node*> _children)
        : val(_val), children(_children) {}
};
*/

class Solution {
public:
    Node* findRoot(vector<Node*> tree) {
        unordered_set<Node*> children;

        for (Node* node : tree) {
            for (Node* child : node->children) {
                children.insert(child);
            }
        }

        for (Node* node : tree) {
            if (children.find(node) == children.end()) {
                return node;
            }
        }

        return nullptr; // 合法输入不会到达这里
    }
};
