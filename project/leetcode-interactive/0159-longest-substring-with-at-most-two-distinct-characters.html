  • · “至多两种”包含只有一种字符的窗口。
  • · 子串必须连续，不能跳过中间字符。
  • · 答案只要求长度，不要求返回子串。

04 / 题解区域

先操作双闸，再展开调度规则

核心洞察、完整过程、边界、复杂度、替代方案、面试追问、常见错误和四语言代码默认隐藏。

核心洞察

维护窗口 [left, right] 的字符频次。右界每轮纳入一个字符；若种类超过 2，左界持续移除字符，频次归零才从哈希表删除。窗口恢复合法后再更新答案。

完整过程

  1. 1. left = 0，答案为 0。
  2. 2. right 从左到右扫描并增加频次。
  3. 3. 种类数大于 2 时，循环收缩左界。
  4. 4. 当前窗口合法后，用长度刷新答案。

边界与错误

  • · 单字符或全同字符：答案等于长度。
  • · 不要把“至多两种”误写成“恰好两种”。
  • · 频次归零必须删除键，否则种类数不会下降。
  • · 收缩必须使用 while，而不是只移动一次。

复杂度与替代方案

时间 O(n)：左右边界都只前进。空间 O(1)：英文字母字符集固定；若按一般字符集表述则为 O(字符集大小)。暴力枚举所有起点最坏 O(n²)，不适合 10⁵。

面试追问

  • · 如何推广到至多 K 种字符？把常量 2 替换为 K。
  • · 为什么每个字符最多被左右边界处理两次？
  • · 如果要返回子串本身，需要额外保存什么？保存最优起点和长度。
  • · Unicode 字符如何处理？语言层面按 code point 迭代并使用哈希表。

推荐取舍

面试主线推荐“频次哈希 + 可变滑动窗口”，语义直观且可直接推广到 K distinct。也可记录最近出现位置并淘汰最旧字符，但证明与实现更绕，不如频次窗口稳健。 

class Solution {
    public int lengthOfLongestSubstringTwoDistinct(String s) {
        Map<Character, Integer> count = new HashMap<>();
        int left = 0;
        int answer = 0;

        for (int right = 0; right < s.length(); right++) {
            char added = s.charAt(right);
            count.put(added, count.getOrDefault(added, 0) + 1);

            while (count.size() > 2) {
                char removed = s.charAt(left++);
                count.put(removed, count.get(removed) - 1);
                if (count.get(removed) == 0) {
                    count.remove(removed);
                }
            }

            answer = Math.max(answer, right - left + 1);
        }
        return answer;
    }
}
