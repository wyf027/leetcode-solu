01 · Problem brief

题目要求

给定两个非负整数数组 rowSum 和 colSum。前者给出矩阵每一行的和，后者给出每一列的和。

准确转述

构造一个大小为 rowSum.length × colSum.length 的非负整数矩阵，使第 i 行元素之和等于 rowSum[i]，第 j 列元素之和等于 colSum[j]。

只需返回任意一个满足要求的二维数组；不要求字典序、唯一性或最小化某个值。题目保证至少存在一个可行矩阵。

关键输入条件：sum(rowSum) == sum(colSum)，总供给与总需求相等。

函数形式

restoreMatrix(
  rowSum: integer[],
  colSum: integer[]
) → integer[][]

约束

  • 1 ≤ rowSum.length, colSum.length ≤ 500
  • 0 ≤ rowSum[i], colSum[j] ≤ 10⁸
  • sum(rowSum) == sum(colSum)

示例 1 2 × 2

输入：rowSum = [3,8], colSum = [4,7]
输出：[[3,0],[1,7]]
解释：两行之和为 3、8；两列之和为 4、7。
      所有元素非负。[[1,2],[3,5]] 也可行。

示例 2 3 × 3

输入：rowSum = [5,7,10], colSum = [8,6,8]
输出：[[0,5,0],[6,1,0],[2,0,8]]

示例 3 2 × 3

输入：rowSum = [14,9], colSum = [6,9,8]
输出：[[0,9,5],[6,0,3]]

示例 4 2 × 1

输入：rowSum = [1,0], colSum = [1]
输出：[[1],[0]]

示例 5 1 × 1

输入：rowSum = [0], colSum = [0]
输出：[[0]]

贪心：每次结清一行或一列

题解目录 核心洞察完整过程正确性证明边界情况复杂度替代方案四语言代码面试追问常见错误测试与验证

核心洞察

在当前格 (i, j) 放入 min(rowSum[i], colSum[j])。
这个值不会让当前行或当前列超额，并且必然至少把其中一方的剩余配额降到 0，于是可以安全地向下一行或下一列推进。

把问题看成“行提供供给，列提出需求”。一次分配同时减少一份行供给和一份列需求；由于两边总量相等，最终所有配额都会恰好用完。

完整过程

  1. 创建 m × n 的全零矩阵，令指针 i = 0、j = 0。
  2. 令 x = min(rowSum[i], colSum[j])，把 x 写入 ans[i][j]。
  3. 分别执行 rowSum[i] -= x 与 colSum[j] -= x。
  4. 若当前行剩余为 0，则 i++；若当前列剩余为 0，则 j++。两者同时为 0 时可同时推进。
  5. 当任一指针越界时，全部总量已被分配，返回矩阵。

正确性证明

1
不超额。

每次写入的是当前行剩余量与当前列剩余量的较小值，因此更新后两者都不会变成负数，矩阵元素也始终非负。

2
安全推进。

写入后至少有一方剩余量归零。若某行归零，该行已经精确达到原始行和，之后无需再写；列同理。

3
最终完备。

初始行总量等于列总量，每次又从两边减去相同的 x，所以剩余总量始终相等。指针单调前进且每步至少结清一行或一列；结束时一侧全部结清，另一侧剩余总量只能也是 0。因此所有行和与列和都满足。

边界情况

  • 配额为 0：写入 0 后相应指针仍可推进，不会死循环。
  • 单行或单列：直接把另一数组的各项依次放入矩阵即可，通用贪心自然覆盖。
  • 两者同时归零：行列指针都推进是安全的；交叉格之后无需再分配。
  • 大数：单项至多 10⁸，题目环境中的四种语言整数类型均可容纳单格值；实现只做减法和比较。

复杂度

O(mn)时间复杂度

初始化返回矩阵本身需要写入 m × n 个位置；有效分配步骤至多 m+n-1。

O(1)额外空间

不计必须返回的答案矩阵，只使用指针与临时变量。

替代方案

网络流

可把每一行连接到每一列，行容量表示供给，列容量表示需求，再求最大流。它能表达更复杂的单格上下界或禁配约束，但本题完全图上的流模型成本远高于必要程度。

反复寻找最小剩余量

每轮全局搜索最小的行或列也可以构造，但会增加扫描开销。双指针按顺序结清配额更直接。

四语言完整代码

JavaLeetCode 可提交
class Solution {
    public int[][] restoreMatrix(int[] rowSum, int[] colSum) {
        int m = rowSum.length;
        int n = colSum.length;
        int[][] answer = new int[m][n];
        int i = 0, j = 0;

        while (i < m && j < n) {
            int value = Math.min(rowSum[i], colSum[j]);
            answer[i][j] = value;
            rowSum[i] -= value;
            colSum[j] -= value;

            if (rowSum[i] == 0) i++;
            if (colSum[j] == 0) j++;
        }
        return answer;
    }
}

var restoreMatrix = function(rowSum, colSum) {
    const m = rowSum.length;
    const n = colSum.length;
    const answer = Array.from({ length: m }, () => Array(n).fill(0));
    let i = 0;
    let j = 0;

    while (i < m && j < n) {
        const value = Math.min(rowSum[i], colSum[j]);
        answer[i][j] = value;
        rowSum[i] -= value;
        colSum[j] -= value;

        if (rowSum[i] === 0) i++;
        if (colSum[j] === 0) j++;
    }
    return answer;
};

from typing import List


class Solution:
    def restoreMatrix(
        self, rowSum: List[int], colSum: List[int]
    ) -> List[List[int]]:
        m, n = len(rowSum), len(colSum)
        answer = [[0] * n for _ in range(m)]
        i = j = 0

        while i < m and j < n:
            value = min(rowSum[i], colSum[j])
            answer[i][j] = value
            rowSum[i] -= value
            colSum[j] -= value

            if rowSum[i] == 0:
                i += 1
            if colSum[j] == 0:
                j += 1

        return answer
C++LeetCode 可提交 · C++17
class Solution {
public:
    vector<vector<int>> restoreMatrix(
        vector<int>& rowSum,
        vector<int>& colSum
    ) {
        int m = rowSum.size();
        int n = colSum.size();
        vector<vector<int>> answer(m, vector<int>(n, 0));
        int i = 0, j = 0;

        while (i < m && j < n) {
            int value = min(rowSum[i], colSum[j]);
            answer[i][j] = value;
            rowSum[i] -= value;
            colSum[j] -= value;

            if (rowSum[i] == 0) ++i;
            if (colSum[j] == 0) ++j;
        }
        return answer;
    }
};

面试追问

  • 为什么不需要回溯？ 每步都只消耗双方当前仍可用的量，不会破坏剩余总量相等的不变量。
  • 如果某些格子禁止填数呢？ 简单贪心不再保证可行，适合改成带容量的网络流。
  • 如何不修改输入数组？ 先复制：JavaScript 用 rowSum.slice()；Python 用 rowSum[:]。
  • 最多有多少个非零格？ 该构造每步至少结清一行或一列，因此非零格至多 m+n-1。

常见错误

  • 把当前格填成较大值，导致某行或某列超额。
  • 只推进一个指针；当行、列同时归零时虽然可能仍能继续，但容易对 0 配额处理失误。
  • 用 while (i < m || j < n)，随后访问已经越界的一侧。
  • 误以为必须复现示例输出。题目接受任意满足行和、列和的矩阵。
  • 忽略实现会原地修改 rowSum 与 colSum；若调用方还需原数组，应先复制。
