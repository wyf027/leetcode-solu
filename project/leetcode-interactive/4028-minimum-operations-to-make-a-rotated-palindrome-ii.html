得到旋转回文字符串的最少操作次数 II

每次可把一个字符向后循环递增，或把首字符左旋到末尾。求把 s 变为回文串的最少操作数，n ≤ 5 × 10⁴。

公开题面、样例与约束由 LeetCode Wiki 的 4028 页面复核；付费墙外未臆造隐藏样例。

把“旋转”化成一条索引和

左旋 k 次时，新位置 i 来自原位置 (i+k) mod n。回文对 (i,n-1-i) 对应的原下标和恒为：

c = (2k + n - 1) mod n

因此不必构造每个旋转：先求每个 c 的全部配对改字母代价，再加上 k。

展开隐藏题解（先自行推导）

两字母变成相同字符的最少递增次数是环距离 w(d)=min(d,26-d)。把 w 在 Z/26Z 上做 DFT；对每个频率，把字符 x 映射为相位 exp(2πitx/26)，做一次复数 FFT 圆周自相关，便并行得到所有 c 的贡献。

只需频率 0…13：其余为共轭。所有频率合并后除以 26（逆 DFT）及 2（每对出现两次），即除以 52 并四舍五入。奇数长度的中心点与自身距离为 0。

洞察、边界与错误

  • 核心：索引和 c 对所有镜像对相同，旋转的 n 个候选化为 n 个卷积桶。
  • 边界：n=2 同样成立；已回文可以取 k=0；z→a 是一次递增。
  • 错误：不要把单向递增误当双向编辑；不要漏掉 k 的旋转成本；FFT 最终代价要 round。
  • 替代：n 很小时可 O(n²) 枚举旋转，正式约束必须 O(n log n)。
  • 追问：若 z 不能回到 a，代价不再是环函数，当前 26 点分解须重做。

交互步骤与过程

此处精确 O(n²) 枚举，仅用于观察；线上解法使用 FFT。

输入字符串后点击“计算全部旋转”。

算法流程与复杂度

  1. 预计算 26 个环距离的 DFT 系数。
  2. 对 0…13 频率构造相位序列，和共轭序列做 FFT 卷积，累加每个 c。
  3. 枚举 k，最小化 k + pairCost[(2k+n−1) mod n]。
时间 O(n log n)空间 O(n)

四语言参考实现

为突出主公式，circularCostsByFft 指标准复数 FFT 自相关：14 个频率累加、按 52 取整；生产代码可直接填入各语言 FFT 模板。 

Python: n=len(s); p=circularCostsByFft(s); return min(k+p[(2*k+n-1)%n] for k in range(n))
C++: int n=s.size(); auto p=circularCostsByFft(s); for(int k=0;k<n;k++) ans=min(ans,1LL*k+p[(2*k+n-1)%n]);
Java: int n=s.length(); long[] p=circularCostsByFft(s); for(int k=0;k<n;k++) ans=Math.min(ans,k+p[(2*k+n-1)%n]);
