01 · 题目

设计一个随机集合

实现 RandomizedSet 类。它要支持插入、删除与随机取值；随机取值时，当前集合里的每个元素都必须以相同概率被返回。三个接口都需要达到平均 O(1) 时间。

insert(int val) → bool

当 val 不存在时插入并返回 true；已经存在则保持集合不变并返回 false。

remove(int val) → bool

当 val 存在时删除并返回 true；不存在则保持集合不变并返回 false。

getRandom() → int

从当前集合等概率返回一个元素。题目保证调用时集合非空。

完整官方示例

Input / Output
输入
["RandomizedSet", "insert", "remove", "insert", "getRandom", "remove", "insert", "getRandom"]
[[], [1], [2], [2], [], [1], [2], []]

输出
[null, true, false, true, 2, true, false, 2]

解释：依次初始化；插入 1；删除不存在的 2；插入 2；从 {1,2} 中等概率取值（示例取到 2）；删除 1；再次插入已存在的 2；最后只能取到 2。

约束

  • −2³¹ ≤ val ≤ 2³¹ − 1
  • 对 insert、remove 与 getRandom 的调用总数最多为 2 × 10⁵。
  • 调用 getRandom 时，数据结构中至少有一个元素。
  • 每个接口要求平均时间复杂度为 O(1)。
随机输出说明：示例给出的 2 是一次合法结果；当集合为 {1,2} 时，1 与 2 都应以 1/2 概率出现。

数组 + 哈希表：各取所长

核心洞察

数组负责随机

元素紧密放在下标 0…n−1。均匀随机选一个下标，就等价于均匀随机选一个元素。

哈希表负责定位

维护 value → index，平均 O(1) 判断元素是否存在，并找到它在数组中的位置。

删除靠末尾换位

不移动删除位置之后的所有元素，而是把数组末尾元素搬到空位，再弹出末尾。

始终维护不变量

数组恰好保存集合中全部元素，且映射记录的下标始终指向该值在数组中的当前位置。

完整过程

  1. 初始化：建立动态数组 values 和哈希映射 index。
  2. 插入 val：若映射已含 val，返回 false；否则记录 index[val] = values.size，再把 val 追加到数组末尾，返回 true。
  3. 删除 val：若映射不含 val，返回 false。设待删位置为 i、末尾值为 last；当 i 不是末尾时，把 last 写入 i 并更新 index[last] = i。最后弹出数组末尾并删除 val 的映射，返回 true。
  4. 随机取值：在 [0, values.size−1] 上均匀生成整数下标，返回对应数组元素。
更新顺序的关键点：先读取末尾值与待删下标，再完成必要换位和映射修正，最后才移除末尾与旧映射。

正确性证明

1

不变量成立：初始化时数组和映射都为空。成功插入时，新值追加到唯一新下标，并建立准确映射；已有值不会重复插入。

2

删除保持不变量：若删除中间元素，末尾值填入空位且映射同步改为新下标；随后移除原末尾与 val 的映射。其余元素及下标均未改变。若删除的本来就是末尾，则直接弹出即可。

3

随机性正确：数组内每个集合元素只出现一次，并分别占据 n 个下标之一。均匀选择下标时，每个元素被返回的概率都是 1/n。

4

因此，三个操作之后数据结构均正确表示集合，且 getRandom 满足等概率要求。

边界与复杂度

  • 插入重复元素和删除不存在元素都必须返回 false，且不能改变内部状态。
  • 删除数组最后一个元素时，不需要换位；代码应避免无意义更新带来的理解成本。
  • 集合只有一个元素时，随机结果必然是该元素；删除后可变为空，但题目不会在空集合上调用 getRandom。
  • val 可以是负数、0 或 32 位有符号整数边界值，不能拿特殊整数充当“空”标记。
insert平均 O(1)哈希查询 + 尾部追加
remove平均 O(1)哈希定位 + 常数次换位
getRandomO(1)均匀下标 + 数组访问

空间复杂度为 O(n)。哈希表在极端冲突下可能退化，因此题目强调的是平均 O(1)。

替代方案为何不够

  • 只用哈希集合：插入和删除平均 O(1)，但不能 O(1) 均匀定位“第 k 个元素”；遍历到随机位置需要 O(n)。
  • 只用动态数组：随机访问 O(1)，但查找值与删除中间元素通常需要 O(n)。
  • 平衡树：可实现 O(log n) 插入删除；若维护子树大小还能按秩随机，但仍达不到平均 O(1)。
  • 链表 + 哈希：能快速删除节点，却不能 O(1) 均匀随机访问任一节点。

面试追问

  • 如果允许重复元素？映射需从值指向“所有下标的集合”；删除换位时同步替换末尾值对应的那个下标，即 LeetCode 381 的方向。
  • 如何支持带权随机？普通等概率下标不再适用，可考虑前缀和 + 二分、Fenwick 树，或权重静态时的 Alias Method。
  • 如何做到线程安全？组合操作必须原子地同步数组和映射；可用互斥锁保护整个状态，读写锁是否收益明显取决于写比例与随机数发生器。
  • 随机数质量重要吗？需要均匀整数分布；避免简单取模在随机源范围不能整除 n 时产生偏差。安全场景还需密码学安全随机源，但本题无需。

常见错误

  • 删除时只改数组、不更新被搬动末尾值的映射，导致后续定位错误。
  • 先 pop 再读取末尾值，丢失换位所需信息。
  • 用数组的值域随机数不断重试，无法保证 O(1)，且稀疏值域下可能极慢。
  • 允许重复插入，破坏“每个值唯一对应一个下标”的不变量。
  • 把示例中某次 getRandom() 的结果 2 误解为固定输出。

四语言完整代码

Java · ArrayList + HashMap + Random
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Random;

class RandomizedSet {
    private final List<Integer> values;
    private final Map<Integer, Integer> index;
    private final Random random;

    public RandomizedSet() {
        values = new ArrayList<>();
        index = new HashMap<>();
        random = new Random();
    }

    public boolean insert(int val) {
        if (index.containsKey(val)) {
            return false;
        }
        index.put(val, values.size());
        values.add(val);
        return true;
    }

    public boolean remove(int val) {
        Integer removeIndex = index.get(val);
        if (removeIndex == null) {
            return false;
        }

        int lastIndex = values.size() - 1;
        int lastValue = values.get(lastIndex);
        if (removeIndex != lastIndex) {
            values.set(removeIndex, lastValue);
            index.put(lastValue, removeIndex);
        }
        values.remove(lastIndex);
        index.remove(val);
        return true;
    }

    public int getRandom() {
        return values.get(random.nextInt(values.size()));
    }
}
JavaScript · Array + Map
var RandomizedSet = function() {
    this.values = [];
    this.index = new Map();
};

/** @param {number} val @return {boolean} */
RandomizedSet.prototype.insert = function(val) {
    if (this.index.has(val)) {
        return false;
    }
    this.index.set(val, this.values.length);
    this.values.push(val);
    return true;
};

/** @param {number} val @return {boolean} */
RandomizedSet.prototype.remove = function(val) {
    if (!this.index.has(val)) {
        return false;
    }

    const removeIndex = this.index.get(val);
    const lastIndex = this.values.length - 1;
    const lastValue = this.values[lastIndex];

    if (removeIndex !== lastIndex) {
        this.values[removeIndex] = lastValue;
        this.index.set(lastValue, removeIndex);
    }
    this.values.pop();
    this.index.delete(val);
    return true;
};

/** @return {number} */
RandomizedSet.prototype.getRandom = function() {
    const randomIndex = Math.floor(Math.random() * this.values.length);
    return this.values[randomIndex];
};
Python 3 · list + dict
import random


class RandomizedSet:
    def __init__(self):
        self.values = []
        self.index = {}

    def insert(self, val: int) -> bool:
        if val in self.index:
            return False
        self.index[val] = len(self.values)
        self.values.append(val)
        return True

    def remove(self, val: int) -> bool:
        if val not in self.index:
            return False

        remove_index = self.index[val]
        last_index = len(self.values) - 1
        last_value = self.values[last_index]

        if remove_index != last_index:
            self.values[remove_index] = last_value
            self.index[last_value] = remove_index

        self.values.pop()
        del self.index[val]
        return True

    def getRandom(self) -> int:
        return random.choice(self.values)
C++ · vector + unordered_map + uniform_int_distribution
#include <random>
#include <unordered_map>
#include <vector>
using namespace std;

class RandomizedSet {
private:
    vector<int> values;
    unordered_map<int, int> index;
    mt19937 generator;

public:
    RandomizedSet() : generator(random_device{}()) {}

    bool insert(int val) {
        if (index.count(val)) {
            return false;
        }
        index[val] = static_cast<int>(values.size());
        values.push_back(val);
        return true;
    }

    bool remove(int val) {
        auto it = index.find(val);
        if (it == index.end()) {
            return false;
        }

        int removeIndex = it->second;
        int lastIndex = static_cast<int>(values.size()) - 1;
        int lastValue = values[lastIndex];

        if (removeIndex != lastIndex) {
            values[removeIndex] = lastValue;
            index[lastValue] = removeIndex;
        }
        values.pop_back();
        index.erase(it);
        return true;
    }

    int getRandom() {
        uniform_int_distribution<int> distribution(
            0, static_cast<int>(values.size()) - 1
        );
        return values[distribution(generator)];
    }
};
