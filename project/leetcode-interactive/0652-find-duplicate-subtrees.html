652. 寻找重复的子树

Find Duplicate Subtrees — 在结构与数值都相同的子树之间，寻找那枚重复出现的“结构指纹”。

MEDIUM #652
⌘↳

同值不一定同构；同构也必须同值。每种重复形态只收录一棵代表树。

Problem brief

题目要求

findDuplicateSubtrees(root)

给定一棵二叉树的根节点 root，找出树中所有重复的子树。对于每一种重复子树，只需返回其中任意一棵的根节点。

两棵子树只有在结构完全相同且对应位置的节点值完全相同时，才被视为重复。答案中不同类型的排列顺序不作要求。

任务的关键不是寻找“相同数值”，而是判断以不同节点为根的整棵子树是否拥有相同的结构与逐点数值。

输入参数

root: TreeNode

返回类型

List<TreeNode>

题目标签

树 深度优先搜索 哈希表 二叉树

Official examples

官方示例

Complete solution

题解：后序编号 + 哈希计数

Expected O(n)

核心洞察

一棵子树可以由三元组 (节点值, 左子树 ID, 右子树 ID) 唯一描述。

空树固定使用 ID 0。后序遍历先得到左右子树的 ID，再给当前三元组分配唯一 ID；相同三元组必然复用相同 ID。某个 ID 的计数从 1 变成 2 时，把当前节点加入答案，之后即使继续出现也不再重复加入。

完整过程

  1. 建立“结构三元组 → 唯一 ID”的哈希表，以及“ID → 出现次数”的计数表。
  2. 对树执行后序 DFS；空节点返回 0，非空节点先递归处理左右孩子。
  3. 用当前值、左 ID、右 ID 组成三元组；若首次出现则分配新 ID，否则取出已有 ID。
  4. 将这个 ID 的计数加一。仅当新计数恰好为 2 时，将当前根节点加入答案。
  5. 把当前子树的 ID 返回给父节点。整棵树处理结束后返回答案。

正确性证明

1

子树身份正确。 用结构归纳：空树统一为 ID 0；若两棵非空子树的根值、左子树 ID、右子树 ID 都相同，根据归纳假设，它们的左右结构和值分别相同，因此整棵子树相同。反过来，相同子树的三个分量必然一致，所以取得同一 ID。

2

不会漏报。 任意重复类型至少出现两次。后序遍历会访问每个根节点；访问到该类型第二个根时，其 ID 计数变为 2，于是该节点被加入答案。

3

不会多报或重复报。 只有同一 ID 的计数到达 2 才加入，而同一 ID 精确对应同一种子树；计数为 3、4……时不再加入，所以每种重复类型恰好保留一个代表。

替代方案：完整字符串序列化

也可以把空节点写成特殊符号，并把每棵子树序列化为类似 value,left,right 的完整字符串，再直接统计字符串。思路更直观，但在退化树上，大量长字符串被反复拼接和哈希，最坏可能达到 O(n²) 的字符处理量。ID 化把每个结构压缩为三个整数，更适合本题的 5000 个节点规模。

复杂度

O(n) 期望时间；每个节点一次，哈希操作均摊常数。
O(n) 哈希表、计数表、答案与递归栈合计空间。

边界情况

  • 只有一个节点：不存在重复子树。
  • 多个相同叶子：属于同一种重复类型，只加入一次。
  • 节点值相同但左右结构不同：三元组不同，不可合并。
  • 同一类型出现三次以上：只在计数等于 2 时加入。
  • 负数节点值不会影响三元组的唯一性。
  • 高度接近 5000 的退化树可能触及语言递归深度；工程环境可改为显式栈后序遍历。

常见错误

  • 只比较根值，忽略左右子树结构。
  • 序列化时不记录空节点，导致不同结构产生同一字符串。
  • 计数大于等于 2 就加入答案，造成同一类型重复出现。
  • 在父节点之前处理当前节点，尚未获得左右子树身份。
  • 用对象引用作为结构键；引用相同不等于结构相同。

面试追问

  • 如何写成迭代后序，避免深树递归栈问题？
  • 为什么加入答案的条件必须是 count == 2？
  • 完整字符串序列化为何可能退化到二次复杂度？
  • 如果需要返回每种重复子树的全部根节点，数据结构如何调整？
  • 若树节点可变，结构 ID 能否跨查询缓存？缓存何时失效？

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private final Map<String, Integer> ids = new HashMap<>();
    private final Map<Integer, Integer> counts = new HashMap<>();
    private final List<TreeNode> answer = new ArrayList<>();
    private int nextId = 1;

    public List<TreeNode> findDuplicateSubtrees(TreeNode root) {
        dfs(root);
        return answer;
    }

    private int dfs(TreeNode node) {
        if (node == null) {
            return 0;
        }

        int leftId = dfs(node.left);
        int rightId = dfs(node.right);
        String key = node.val + "," + leftId + "," + rightId;
        int id = ids.computeIfAbsent(key, unused -> nextId++);

        int newCount = counts.getOrDefault(id, 0) + 1;
        counts.put(id, newCount);
        if (newCount == 2) {
            answer.add(node);
        }
        return id;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {TreeNode} root
 * @return {TreeNode[]}
 */
var findDuplicateSubtrees = function (root) {
    const ids = new Map();
    const counts = new Map();
    const answer = [];
    let nextId = 1;

    function dfs(node) {
        if (node === null) {
            return 0;
        }

        const leftId = dfs(node.left);
        const rightId = dfs(node.right);
        const key = `${node.val},${leftId},${rightId}`;

        if (!ids.has(key)) {
            ids.set(key, nextId++);
        }
        const id = ids.get(key);
        const newCount = (counts.get(id) || 0) + 1;
        counts.set(id, newCount);

        if (newCount === 2) {
            answer.push(node);
        }
        return id;
    }

    dfs(root);
    return answer;
};
from typing import Dict, List, Optional, Tuple
import sys

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def findDuplicateSubtrees(
        self, root: Optional[TreeNode]
    ) -> List[Optional[TreeNode]]:
        sys.setrecursionlimit(10000)
        ids: Dict[Tuple[int, int, int], int] = {}
        counts: Dict[int, int] = {}
        answer: List[Optional[TreeNode]] = []
        next_id = 1

        def dfs(node: Optional[TreeNode]) -> int:
            nonlocal next_id
            if node is None:
                return 0

            left_id = dfs(node.left)
            right_id = dfs(node.right)
            key = (node.val, left_id, right_id)

            if key not in ids:
                ids[key] = next_id
                next_id += 1
            subtree_id = ids[key]

            counts[subtree_id] = counts.get(subtree_id, 0) + 1
            if counts[subtree_id] == 2:
                answer.append(node)
            return subtree_id

        dfs(root)
        return answer
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    unordered_map<string, int> ids;
    unordered_map<int, int> counts;
    vector<TreeNode*> answer;
    int nextId = 1;

    int dfs(TreeNode* node) {
        if (node == nullptr) {
            return 0;
        }

        int leftId = dfs(node->left);
        int rightId = dfs(node->right);
        string key = to_string(node->val) + "," +
                     to_string(leftId) + "," +
                     to_string(rightId);

        if (!ids.count(key)) {
            ids[key] = nextId++;
        }
        int id = ids[key];
        if (++counts[id] == 2) {
            answer.push_back(node);
        }
        return id;
    }

public:
    vector<TreeNode*> findDuplicateSubtrees(TreeNode* root) {
        dfs(root);
        return answer;
    }
};
