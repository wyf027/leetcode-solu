使数组奇偶交替的最少操作

把每一个位置放进“偶、奇、偶……”或“奇、偶、奇……”两条轨道之一；先最小化必须翻转奇偶性的元素数，再在并列方案中收紧最终值域。

贪心 · 枚举两种模式O(n) 时间 · O(1) 额外空间

题意

给定整数数组 nums。相邻元素一奇一偶时数组满足“奇偶交替”。一次操作可让任意一个元素加 1 或减 1。返回 [最少操作数, 在最少操作数下可得到的最小 max−min]。

示例：
nums = [-2, -3, 1, 4]
输出 = [2, 6]
将 1→2、4→3 后得到 [-2,-3,2,3]。

约束：1 ≤ nums.length ≤ 10⁵，-10⁹ ≤ nums[i] ≤ 10⁹。单元素数组天然合法。

题解：枚举起点奇偶性

核心洞察

合法模式只有两种。某元素的目标奇偶性不同时，改变 ±1 就足够且必要，因此一条模式的操作数就是不匹配位置数。

值域并列规则

对每条模式，若要修改的元素正好是全局最小值，优先加 1；若是全局最大值，优先减 1；其余同奇偶转换可任选。最后用字典序比较 [操作数, 值域]。

完整过程与边界

  1. 扫描得到原数组最小值 mn 与最大值 mx。
  2. 分别尝试偶数放在偶下标、奇数放在偶下标。
  3. 不匹配则计数，并按端点规则选择 ±1 以压缩值域。
  4. 长度为 1 时直接返回 [0,0]；其他长度的值域至少为 1。

复杂度：O(n) 时间，O(1) 额外空间。

替代方案：可直接构造两份调整后的数组，逻辑更直观但需 O(n) 空间。

面试追问：若一次操作允许任意加减 k，如何改写？答案是按模 k 枚举目标余数模式。

常见错误：只比较操作数而忽略并列时的值域；或把负数的奇偶判断写成 x % 2 == 1。

Java 

class Solution {
    public int[] makeParityAlternating(int[] nums) {
        if (nums.length == 1) return new int[]{0, 0};
        int mn = Integer.MAX_VALUE, mx = Integer.MIN_VALUE;
        for (int x : nums) { mn = Math.min(mn, x); mx = Math.max(mx, x); }
        int[] a = solve(nums, mn, mx, 0), b = solve(nums, mn, mx, 1);
        return a[0] != b[0] ? (a[0] < b[0] ? a : b) : (a[1] <= b[1] ? a : b);
    }
    private int[] solve(int[] nums, int mn, int mx, int start) {
        int cnt = 0, lo = Integer.MAX_VALUE, hi = Integer.MIN_VALUE;
        for (int i = 0; i < nums.length; i++) { int x = nums[i];
            if (((x - i) & 1) != start) { cnt++; if (x == mn) x++; else if (x == mx) x--; }
            lo = Math.min(lo, x); hi = Math.max(hi, x);
        }
        return new int[]{cnt, Math.max(1, hi - lo)};
    }
}

Python 

class Solution:
    def makeParityAlternating(self, nums: List[int]) -> List[int]:
        if len(nums) == 1: return [0, 0]
        mn, mx = min(nums), max(nums)
        def solve(start):
            cnt, lo, hi = 0, float('inf'), float('-inf')
            for i, x in enumerate(nums):
                if (x - i) & 1 != start:
                    cnt += 1
                    if x == mn: x += 1
                    elif x == mx: x -= 1
                lo, hi = min(lo, x), max(hi, x)
            return [cnt, max(1, hi - lo)]
        return min(solve(0), solve(1))
