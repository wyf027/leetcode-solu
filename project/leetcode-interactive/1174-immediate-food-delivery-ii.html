即时食物配送 II

Immediate Food Delivery II — 从每位顾客的订单历史中识别首次订单，并统计其中即时订单所占的百分比。

Problem brief

题意与数据契约

任务

Delivery 表记录订单日期与顾客期望配送日期。两者相同的订单称为即时订单，否则为计划订单。

每位顾客最早下单的那一笔是其首次订单；题目保证每位顾客恰好有一笔首次订单。请计算：所有顾客的首次订单中，即时订单所占百分比，并将结果四舍五入到小数点后两位。

输出字段： immediate_percentage

Delivery 表结构

字段类型说明
delivery_idint唯一值
customer_idint顾客编号
order_datedate下单日期
customer_pref_delivery_datedate期望配送日期

约束与保证

  • delivery_id 在表中唯一。
  • 期望配送日期等于或晚于下单日期。
  • 每位顾客恰好存在一笔日期最早的订单。
  • 结果按百分数表示，并保留两位小数。

Solution vault

Core insight

先把范围缩到“每人最早的一行”

核心洞察

题目统计的分母不是订单总数，而是顾客总数。因此第一步必须先为每位顾客找到最小 order_date，只保留这些首次订单；第二步才判断 order_date = customer_pref_delivery_date。

一句话：先按顾客过滤首次订单，再对布尔条件求平均并乘 100。

完整过程

  1. 对每个 customer_id 求最早的 order_date。
  2. 将原表限制到这些“顾客 + 最早日期”对应的行。
  3. 把日期相等记为 1，不相等记为 0。
  4. 对 0/1 求平均，乘以 100，再四舍五入两位。

Why it works

正确性说明

1 · 完备性按每位顾客的最小下单日期筛选。题目保证首次订单唯一，所以每位顾客恰好贡献一行，没有遗漏。
2 · 准确性保留下来的每行都满足其日期等于该顾客的最小日期，因此这些行且仅这些行是首次订单。
3 · 分类正确日期相等条件与“即时订单”的定义完全一致，条件真记 1，假记 0。
4 · 比例正确这些 0/1 的平均值等于即时首次订单数除以首次订单总数；乘 100 后即为百分比。

边界情况

  • 只有一位顾客时，结果只能是 0.00 或 100.00。
  • 同一顾客可以有多笔后续订单，它们都不能进入统计。
  • 所有首次订单均即时或均计划时，平均值仍可正确表达极值。
  • 题目保证首次订单唯一，因此无需处理同一顾客最早日期并列。

复杂度

SQL：设订单数为 n、顾客数为 c。聚合通常为 O(n)，连接/过滤通常为 O(n)；实际代价取决于执行计划和索引。中间结果规模 O(c)。

本地参考：哈希表单次扫描为 O(n) 时间、O(c) 空间。

Alternatives

替代方案

  • 窗口函数：用 ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY order_date) 标记首行，表达直观，但代码更长。
  • 相关子查询：逐行比较该顾客最小日期，简洁但可能产生重复相关计算。
  • 元组 IN：写法短，但不同数据库对行值比较的支持和优化存在差异。

Interview follow-ups

面试追问

  • 哪些复合索引有助于“按顾客找最早日期”？
  • 不同数据库中布尔表达式能否直接参与 AVG？
常见错误：直接统计所有订单、用全表最早日期、先判断即时订单再找首次订单、整数除法丢失小数、忘记乘以 100，或没有按要求保留两位小数。

Complete implementations

代码

MySQL 是本题官方可提交语言。Java、JavaScript、Python、C++ 版本均为对等的本地语义参考：接收订单数组并返回百分比，不可直接提交到数据库题判题器。

SELECT ROUND(AVG(d.order_date = d.customer_pref_delivery_date) * 100, 2)
       AS immediate_percentage
FROM Delivery AS d
JOIN (
    SELECT customer_id, MIN(order_date) AS first_order_date
    FROM Delivery
    GROUP BY customer_id
) AS first_orders
  ON d.customer_id = first_orders.customer_id
 AND d.order_date = first_orders.first_order_date;
import java.time.LocalDate;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class ImmediateFoodDeliveryII {
    public record Delivery(
        int deliveryId,
        int customerId,
        LocalDate orderDate,
        LocalDate preferredDate
    ) {}

    public static double immediatePercentage(List<Delivery> deliveries) {
        Map<Integer, Delivery> firstByCustomer = new HashMap<>();

        for (Delivery delivery : deliveries) {
            firstByCustomer.merge(
                delivery.customerId(),
                delivery,
                (current, candidate) ->
                    candidate.orderDate().isBefore(current.orderDate())
                        ? candidate : current
            );
        }

        if (firstByCustomer.isEmpty()) return 0.0;

        long immediate = firstByCustomer.values().stream()
            .filter(d -> d.orderDate().equals(d.preferredDate()))
            .count();

        return Math.round(immediate * 10000.0 / firstByCustomer.size()) / 100.0;
    }
}
/**
 * @param {Array<{
 *   deliveryId: number,
 *   customerId: number,
 *   orderDate: string,
 *   preferredDate: string
 * }>} deliveries
 * @returns {number}
 */
function immediatePercentage(deliveries) {
  const firstByCustomer = new Map();

  for (const delivery of deliveries) {
    const current = firstByCustomer.get(delivery.customerId);
    if (!current || delivery.orderDate < current.orderDate) {
      firstByCustomer.set(delivery.customerId, delivery);
    }
  }

  if (firstByCustomer.size === 0) return 0;

  let immediate = 0;
  for (const delivery of firstByCustomer.values()) {
    if (delivery.orderDate === delivery.preferredDate) immediate += 1;
  }

  return Math.round((immediate * 10000) / firstByCustomer.size) / 100;
}
from dataclasses import dataclass
from datetime import date
from typing import Iterable


@dataclass(frozen=True)
class Delivery:
    delivery_id: int
    customer_id: int
    order_date: date
    preferred_date: date


def immediate_percentage(deliveries: Iterable[Delivery]) -> float:
    first_by_customer: dict[int, Delivery] = {}

    for delivery in deliveries:
        current = first_by_customer.get(delivery.customer_id)
        if current is None or delivery.order_date < current.order_date:
            first_by_customer[delivery.customer_id] = delivery

    if not first_by_customer:
        return 0.0

    immediate = sum(
        delivery.order_date == delivery.preferred_date
        for delivery in first_by_customer.values()
    )
    return round(immediate * 100 / len(first_by_customer), 2)
#include <cmath>
#include <string>
#include <unordered_map>
#include <vector>

struct Delivery {
    int deliveryId;
    int customerId;
    std::string orderDate;     // YYYY-MM-DD
    std::string preferredDate; // YYYY-MM-DD
};

double immediatePercentage(const std::vector<Delivery>& deliveries) {
    std::unordered_map<int, Delivery> firstByCustomer;

    for (const Delivery& delivery : deliveries) {
        auto it = firstByCustomer.find(delivery.customerId);
        if (it == firstByCustomer.end() ||
            delivery.orderDate < it->second.orderDate) {
            firstByCustomer.insert_or_assign(delivery.customerId, delivery);
        }
    }

    if (firstByCustomer.empty()) return 0.0;

    int immediate = 0;
    for (const auto& [customerId, delivery] : firstByCustomer) {
        (void)customerId;
        if (delivery.orderDate == delivery.preferredDate) ++immediate;
    }

    double percentage = immediate * 100.0 / firstByCustomer.size();
    return std::round(percentage * 100.0) / 100.0;
}
