子字符串突变后可能得到的最大整数

Largest Number After Mutating Substring

一张数字映射表，一次连续区间替换。你会选择哪一段？

题目

给定表示大整数的数字字符串 num，以及长度为 10 的整数数组 change。数字 d 的替换结果为 change[d]。

你可以选择至多一个连续子字符串，将其中每一位按映射替换一次，也可以完全不替换。返回能得到的最大整数的字符串表示。映射基于该位原来的数字，不对替换结果反复映射。

函数：maximumNumber(num: string, change: integer[10]) → string。输入允许前导零，请始终按字符串处理。

约束

  • 1 ≤ num.length ≤ 10⁵
  • num 仅包含数字 0–9。
  • change.length = 10
  • 对所有 d ∈ [0,9]，0 ≤ change[d] ≤ 9。

5 会变为 2；保持原字符串得到最大值 "5"。

题解 · 一段连续的增益

核心洞察

同长度数字串的大小由最左侧第一个不同的位置决定。最早能增大的位必须利用；开始之后，映射相等的位可以连接后续增益，映射变小的位则必须停在它之前。

尚未开始：跳过映射不变或变小的位，遇到严格变大才开始。
正在替换：变大或相等都继续，第一次变小就永久结束。

完整过程

  1. 将字符串转换为可修改的字符数组，令 started = false。
  2. 从左向右取原数字 d，查询 mapped = change[d]。
  3. 若 mapped > d，替换当前位，并标记已经开始。
  4. 若相等，继续扫描；开始前无需开启区间，开始后可将该位包含在同一区间中。
  5. 若 mapped < d，开始前跳过，开始后立即退出扫描。
  6. 将字符数组拼接为结果。未遇到严格增大时，返回原字符串。

例如 12342 在演示映射中：1 → 9 开始；2 → 2 连接；3 → 8 继续；4 → 0 时停止，保留剩余后缀，得到 92842。

正确性论证

起点最优。设 p 是第一个映射严格增大的位置。p 前的位只能不变或变小：包含变小位会导致更差的高位；只包含相等位不影响结果。因此可以将最优区间起点选为 p。若跳过 p，后面再多增益也无法弥补该位落后。

延伸最优。开始后，严格增大的位应包含，否则结果在该位落后。相等位无代价地连接后续位置，跨过它不会损害答案。可以一直延伸至第一个下降位之前。

停止最优。若跨入一个映射变小的位，与立刻停止相比，它是第一个变差的位置，之后的增益无法抵消。又因只能操作一个连续区间，不能跳过下降位后重新开始。因此上述扫描得到全局最优结果。若 p 不存在，不操作即最优。

边界与复杂度

  • 长度为 1：仅比较该数字与映射；全不增大：原样返回。
  • 相等位：开始前可跳过，开始后不能误当停止条件。
  • 前导零合法，原字符串长度必须保留；不能转换为普通整数。
  • 映射一次即可，例如 1 → 2 且 2 → 9 时，原数字 1 只变成 2。
  • 时间 O(n)。Java、JavaScript、Python 的字符数组和返回字符串使用 O(n) 空间；C++ 在参数字符串上修改，扫描辅助空间 O(1)，按值参数及返回存储为 O(n)。

四语言实现

采用官方函数签名；代码仅生成，尚未编译或执行。横向滚动各代码容器可查看长行。

Java

class Solution {
    public String maximumNumber(String num, int[] change) {
        char[] digits = num.toCharArray();
        boolean started = false;
        for (int i = 0; i < digits.length; i++) {
            int d = digits[i] - '0';
            if (change[d] > d) {
                digits[i] = (char) ('0' + change[d]);
                started = true;
            } else if (started && change[d] < d) {
                break;
            }
        }
        return new String(digits);
    }
}

var maximumNumber = function(num, change) {
    const digits = num.split('');
    let started = false;
    for (let i = 0; i < digits.length; i++) {
        const d = Number(digits[i]);
        if (change[d] > d) {
            digits[i] = String(change[d]);
            started = true;
        } else if (started && change[d] < d) {
            break;
        }
    }
    return digits.join('');
};

Python

from typing import List

class Solution:
    def maximumNumber(self, num: str, change: List[int]) -> str:
        digits = list(num)
        started = False
        for i, char in enumerate(digits):
            d = int(char)
            if change[d] > d:
                digits[i] = str(change[d])
                started = True
            elif started and change[d] < d:
                break
        return ''.join(digits)

C++

#include <string>

class Solution {

    string maximumNumber(string num, vector<int>& change) {
        bool started = false;
        for (int i = 0; i < static_cast<int>(num.size()); ++i) {

                num[i] = static_cast<char>('0' + change[d]);
                started = true;
            } else if (started && change[d] < d) {
                break;
            }
        }
        return num;
    }
};

替代方案

枚举不操作以及所有 O(n²) 个区间，每次构造并比较长度 n 的字符串，直接实现为 O(n³) 时间、O(n) 工作空间，只适合很小输入的参考推导。也可用“未开始 / 区间内 / 已结束”三状态动态规划，但维护候选字符串容易引入额外开销；本题的高位优先性质让单次扫描更直接。

面试追问

  • 为什么不能逐位取最大？这会选择多个不连续区间；例如官方示例 1 中把最后的 2 也变成 5 会得到不可达的 835。
  • 能否返回替换区间？记录第一次严格增大的索引与最后包含的位置；没有增益则返回空区间。尾部相等位是否包含不影响最大值。
  • 如果允许两个区间呢？停止后还有机会开始第二段，原有永久停止条件失效，需要显式跟踪剩余操作次数并重新论证。
  • 为何前导零不影响比较？候选串长度一致，按首个不同数字比较仍与整数大小一致。

常见错误

  • 尚未开始就因下降而退出，错过后面的第一个增益。
  • 开始后遇到相等就停止，漏掉相等位之后的增益。
  • 遇到下降后重新开启第二段，违反单个连续子字符串限制。
  • 将整个 num 转成 Number / int，丢失长度、前导零或精度。
  • 对同一位重复查表，错误地把一次映射变成多次映射。
