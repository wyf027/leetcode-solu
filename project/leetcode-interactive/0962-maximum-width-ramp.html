MAXIMUM WIDTH RAMP

最大宽度坡把最早的低点，交给最晚的高点

先理解坡，再用交互演示观察严格递减的候选左端点栈。完整题解默认隐藏。

题号 962中等非付费题

题目

左侧数值不大于右侧数值，就形成一个坡。

题意转述

给定整数数组 nums。若 i < j 且 nums[i] <= nums[j]，下标对 (i,j) 就是坡，宽度为 j-i。返回最大宽度；若不存在则返回 0。

maxWidthRamp(nums: integer[]) -> integer

约束

  • 2 <= nums.length <= 5 * 10^4
  • 0 <= nums[i] <= 5 * 10^4

示例 1

输入：nums = [6,0,8,2,1,5]
输出：4
解释：(1,5) 合法，宽度 5-1=4。

示例 2

输入：nums = [9,8,1,0,1,9,4,0,4,1]
输出：7
解释：(2,9) 合法，宽度 9-2=7。

核心洞察与过程

只有比此前所有值都小的位置值得成为新左端点；否则更早且不更大的位置一定更优。先将这些前缀新低点的下标入栈，对应值严格递减。

  1. 从左向右构建候选栈。
  2. 从右向左枚举 j。
  3. 当栈顶 i 满足 nums[i]<=nums[j] 时，更新 j-i 并弹栈。
  4. 返回最大值。

正确性

候选完备：非前缀最小位置 i 的左侧存在更早且不更大的 k；任何与 i 合法的右端点也与 k 合法，宽度更大。

弹栈安全：右端点从右向左扫描，首次匹配栈顶时，当前 j 已是该左端点最右的合法搭档。因此最优坡必被计算。

边界与复杂度

  • 严格递减数组返回 0。
  • 相等元素合法，判断使用 <=。
  • 每个下标至多入栈、出栈一次。

时间 O(n)，空间 O(n)。

替代方案

排序下标并维护最小下标：O(n log n)。前缀最小值 + 后缀最大值 + 双指针：O(n) 时间、O(n) 空间。

面试追问

  • 为何入栈严格小于、匹配小于等于？
  • 如何返回具体下标对？
  • 如何改写为双指针法？

常见错误

  • 遗漏相等元素；栈存值而非下标。
  • 正向扫描右端点；用 if 代替 while。

class Solution {
 public int maxWidthRamp(int[] nums) {
  int[] st=new int[nums.length]; int top=0, ans=0;
  for(int i=0;i<nums.length;i++) if(top==0||nums[i]<nums[st[top-1]]) st[top++]=i;
  for(int j=nums.length-1;j>=0&&top>0;j--)
   while(top>0&&nums[st[top-1]]<=nums[j]) ans=Math.max(ans,j-st[--top]);
  return ans;
 }
}

from typing import List
class Solution:
 def maxWidthRamp(self, nums: List[int]) -> int:
  st, ans = [], 0
  for i, x in enumerate(nums):
   if not st or x < nums[st[-1]]: st.append(i)
  for j in range(len(nums)-1, -1, -1):
   while st and nums[st[-1]] <= nums[j]:
    ans = max(ans, j-st.pop())
  return ans
