网格游戏

两行网格，两位对手。你留下的道路，决定对手能拿走多少。

01 / 游戏规则

给定一个下标从 0 开始的 2 × n 整数矩阵 grid，grid[r][c] 是该格的点数。两个机器人均从 (0, 0) 出发，到达 (1, n−1)，每一步只能向右或向下。

机器人一先走，收走沿途的全部点数，并把经过的格子置为 0。机器人二随后在剩余网格中行走、收集点数；两条路径可以相交。

机器人一的目标是让机器人二得分尽可能低；机器人二的目标是让自己的得分尽可能高。双方都采取最优策略时，返回机器人二的得分。

参数与返回值

gridGame(grid)：输入二维整数数组，返回第二位机器人的最优博弈得分。

  • grid.length == 2
  • n == grid[r].length，两行长度相同
  • 1 ≤ n ≤ 5 × 10⁴
  • 1 ≤ grid[r][c] ≤ 10⁵

05 / 解题手记

准备好后，再展开策略、证明与代码。

核心洞察：一个转弯点，两个剩余区域

两行网格中，每条合法路径恰好向下一次。设机器人一在第 j 列向下，它清空上行 [0,j] 与下行 [j,n−1]。剩下的只有上行右侧与下行左侧。

T(j) = sum(grid[0][j+1 .. n-1])
B(j) = sum(grid[1][0 .. j-1])
score(j) = max(T(j), B(j))
answer = min over j of score(j)

完整过程

  1. 先求上行总和 top，下行已过前缀 bottom = 0。
  2. 遍历转弯列 j，先减去 grid[0][j]，此时 top 不包含当前列。
  3. 本轮对手得分为 max(top, bottom)，更新所有回合的最小值。
  4. 再把 grid[1][j] 加到 bottom，供下一轮使用。

示例 1：j=0 时两块为 (9,0)，对手得 9；j=1 时为 (4,1)，对手得 4；j=2 时为 (0,6)，对手得 6。取最小值 4。

正确性证明

固定机器人一的转弯列 j。若机器人二在 k ≤ j 列向下，上行部分已清空，它只能收集下行左段的一部分，得分不超过 B(j)；在第 0 列向下能取得整个 B(j)。若 k > j，它只能收集上行右段的一部分，得分不超过 T(j)；在最后一列向下能取得整个 T(j)。所有点数非负，收集整段不会比子段更差。因此最佳回应恰为两段之和的较大者。

机器人一的每条路径都唯一对应某个 j，遍历所有 j 没有遗漏。对每个 j 计算对手的最佳回应，再取最小值，正好符合双方的最优目标。

边界与复杂度

  • n = 1：两格必被清空，两段和都为 0。
  • j = 0 的下行前缀为空，j = n−1 的上行后缀为空，空和记 0。
  • 和可能达到 5 × 10⁹；Java 用 long，C++ 用 long long。JavaScript Number 在本题范围内可精确表示整数，不能使用会截成 32 位的位运算。
  • 时间 O(n)，额外空间 O(1)，不修改输入。演示界面保存轮次并渲染网格，其开销与提交代码不同。

替代方案

显式构建上行后缀和、下行前缀和数组，同样 O(n) 时间，但需 O(n) 空间，便于多次查询。逐个转弯点重新累加两段需 O(n²) 时间。使用通用网格动态规划会掩盖“两行只转弯一次”的结构。

常见错误

  • 最大化机器人一的得分：本题目标是压低机器人二的最优得分，两者不等价。
  • 把两块剩余点数相加：机器人二不能先吃到上行右段，再回到下行左段。
  • 先给 bottom 加当前格再比较：把已经清空的转弯格算进了剩余区域。
  • 求两段的 min：固定第一条路径后，机器人二会主动选择更大的一段。
  • 用 32 位整数累加，或复制并逐条清零网格，导致溢出或超时。

面试追问

如何返回路径？ 更新答案时记录 j；若 T ≥ B，机器人二在最后一列向下，否则在第 0 列向下。相等时任选。

若允许负数？ 整段不一定优于子段，max(T,B) 的证明不再成立，需要重新计算可选择子段的最佳收益。

若有三行？ 路径包含两个转弯，剩余区域不再分成这两块，当前公式不能直接推广。

Java

class Solution {
    public long gridGame(int[][] grid) {
        long top = 0, bottom = 0, answer = Long.MAX_VALUE;
        for (int value : grid[0]) top += value;
        for (int j = 0; j < grid[0].length; j++) {
            top -= grid[0][j];
            answer = Math.min(answer, Math.max(top, bottom));
            bottom += grid[1][j];
        }
        return answer;
    }
}

var gridGame = function(grid) {
    let top = grid[0].reduce((sum, value) => sum + value, 0);
    let bottom = 0, answer = Infinity;
    for (let j = 0; j < grid[0].length; j++) {
        top -= grid[0][j];
        answer = Math.min(answer, Math.max(top, bottom));
        bottom += grid[1][j];
    }
    return answer;
};

Python

from typing import List

class Solution:
    def gridGame(self, grid: List[List[int]]) -> int:
        top = sum(grid[0])
        bottom = 0
        answer = top
        for j in range(len(grid[0])):
            top -= grid[0][j]
            answer = min(answer, max(top, bottom))
            bottom += grid[1][j]
        return answer
