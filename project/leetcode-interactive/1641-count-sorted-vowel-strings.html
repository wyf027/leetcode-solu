统计字典序元音字符串的数目

Count Sorted Vowel Strings

五个元音，从左到右只能保持或变大。给定长度 n，数出所有满足条件的字符串。

输入整数 n
输出字符串数量
范围1 ≤ n ≤ 50
元音顺序a ≤ e ≤ i ≤ o ≤ u

Problem

题意

给你一个整数 n，返回所有长度为 n、只含 a、e、i、o、u，并且按字典序非递减排列的字符串数量。

“非递减”表示相邻字符满足 s[i] ≤ s[i + 1]；字符可以重复。例如 aeu 合法，而 eau 不合法。

函数形式： countVowelStrings(n: integer) → integer

官方示例

示例 1
输入：n = 1
输出：5
解释：["a","e","i","o","u"]
示例 2
输入：n = 2
输出：15
解释：["aa","ae","ai","ao","au",
"ee","ei","eo","eu","ii","io",
"iu","oo","ou","uu"]
“ea” 不合法，因为 e > a。
示例 3
输入：n = 33
输出：66045
约束
  • 1 ≤ n ≤ 50

Solution

把“字符串”换成“五种字符的用量”

核心洞察

字符串已经按 a ≤ e ≤ i ≤ o ≤ u 排好序，因此只要知道五个元音各出现多少次，字符串就被唯一确定。设五种元音的出现次数为非负整数 x₁…x₅，它们满足：

x₁ + x₂ + x₃ + x₄ + x₅ = n

这就是把 n 个相同元素分配到 5 个盒子的“隔板法”：在 n 个字符中放入 4 块隔板，共有 n + 4 个位置，从中选 4 个。

答案 = C(n + 4, 4) = (n+1)(n+2)(n+3)(n+4) / 24

完整过程

  1. 忽略具体排列，只记录 a、e、i、o、u 的数量。
  2. 由于字符串必须有序，同一组数量只能对应一个字符串，例如 (2,1,0,1,0) 唯一对应 aaeo。
  3. 于是问题等价于求五个非负整数之和为 n 的解数。
  4. 用隔板法得到 C(n+4,4)。为避免阶乘，直接计算连续四项再除以 24。

正确性证明

引理 1：每个合法字符串都唯一对应一个五元组 (x₁,x₂,x₃,x₄,x₅)，其中各项是对应元音的出现次数，且总和为 n。

引理 2：每个总和为 n 的非负整数五元组，都唯一生成一个合法字符串：依次写出 x₁ 个 a、x₂ 个 e、x₃ 个 i、x₄ 个 o、x₅ 个 u。

结论：两者构成双射，所以合法字符串数等于这些五元组的数量。隔板法计算该数量为 C(n+4,4)，算法返回的正是正确答案。

边界与复杂度

  • n = 1 时答案为 5。
  • n = 50 时结果仍在 32 位有符号整数范围内。
  • 时间复杂度：O(1)。
  • 空间复杂度：O(1)。

替代方案

也可以使用一维动态规划：五个位置分别记录以某元音开头（或结尾）的数量，每增加一位就做前缀和/后缀和。时间复杂度 O(5n)，空间复杂度 O(5)。它更容易推广到字符种类变化或附加限制的情形。

四语言完整代码

class Solution {
    public int countVowelStrings(int n) {
        long a = n + 1L;
        long b = n + 2L;
        long c = n + 3L;
        long d = n + 4L;
        return (int) (a * b * c * d / 24L);
    }
}

常见错误

  • 把“字典序非递减”误解为字符不能重复。
  • 计算成 5ⁿ，这包含了所有无序字符串。
  • 隔板数写成 5，正确是 4 块隔板。
  • 先用 32 位整数连乘，可能在更大扩展输入下溢出。
  • DP 更新方向错误，导致读取本轮刚更新的数据。
