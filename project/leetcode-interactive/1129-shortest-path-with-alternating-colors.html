颜色交替的
最短路径

Shortest Path with Alternating Colors

普通最短路只关心“走到哪里”；这道题还要求记住“刚才用了什么颜色”。先理解规则，再亲手推动图上的搜索。

Problem

题目描述

非付费题

给定一个包含 n 个节点的有向图，节点编号为 0 到 n - 1。每条边是红色或蓝色，图中允许出现自环和平行边。

红色边
redEdges[i] = [aᵢ, bᵢ] 表示一条从 aᵢ 指向 bᵢ 的红色边。
蓝色边
blueEdges[j] = [uⱼ, vⱼ] 表示一条从 uⱼ 指向 vⱼ 的蓝色边。

返回长度为 n 的数组 answer。其中 answer[x] 是从节点 0 到节点 x、且相邻边颜色始终交替的最短路径长度；若不存在这样的路径，则为 -1。节点 0 到自身的路径长度为 0。

示例 1

输入：n = 3, redEdges = [[0,1],[1,2]], blueEdges = []
输出：[0,1,-1]

可以沿红边到达节点 1；继续走红边不满足颜色交替，因此节点 2 不可达。

示例 2

输入：n = 3, redEdges = [[0,1]], blueEdges = [[2,1]]
输出：[0,1,-1]

红边可从 0 到 1，但没有从 0 出发并通向节点 2 的合法路径。

约束

  • 1 ≤ n ≤ 100
  • 0 ≤ redEdges.length, blueEdges.length ≤ 400
  • redEdges[i].length = blueEdges[j].length = 2
  • 所有边端点均满足 0 ≤ 端点 < n

Solution

把节点扩展成双色状态

最短路仍然是 BFS；变化在于，同一节点需要区分“最后通过红边到达”和“最后通过蓝边到达”。

核心洞察

只记录 visited[node] 会错误剪枝。到达同一节点时，上一条边颜色不同，下一步可走的边集合也不同。因此搜索状态应为 (node, lastColor)。

起点如何处理

把 (0, RED) 和 (0, BLUE) 都以距离 0 放入队列。这样下一步分别允许走蓝边和红边，相当于第一条边可任选颜色。

状态转移

(u, RED)— 只能走蓝边 →(v, BLUE)— 只能走红边 →(w, RED)

完整过程

  1. 按颜色建邻接表。分别保存每个节点出发的红边终点和蓝边终点。
  2. 初始化二维距离。dist[node][color] 表示最后通过该颜色边到达节点的最短距离；全部设为无穷，起点两种颜色状态设为 0。
  3. 执行 BFS。弹出 (u, lastColor)，只查看颜色为 1 - lastColor 的出边。
  4. 首次发现即入队。若 (v, nextColor) 尚未访问，则距离加一并入队。每个双色状态只会入队一次。
  5. 合并答案。每个节点取两种颜色状态距离的较小值；两者都不可达时填 -1。

正确性证明

引理 1：扩展图中的每个状态 (v, c) 与原图中一条到达 v 且最后一条边颜色为 c 的交替路径对应。转移只允许走相反颜色，因此搜索产生的路径都合法；任意合法交替路径也会逐边产生对应状态转移。

引理 2：BFS 首次到达任一状态 (v, c) 时取得其最短距离。扩展图中每次转移代价都是 1，BFS 按非递减距离处理状态，这是无权图 BFS 的标准性质。

结论：到节点 v 的合法路径必然以红边或蓝边结束。取 dist[v][RED] 与 dist[v][BLUE] 的最小值，就是所有颜色交替路径中的最短长度；若两者均不可达，答案为 -1。

边界情况

  • n = 1 时答案是 [0]。
  • 允许自环和平行边，二维访问状态会自然避免死循环。
  • 某一种颜色没有边时，最多走一条另一颜色的边。
  • 节点可被两种“上一条边颜色”分别访问。

复杂度

时间O(n + r + b)
空间O(n + r + b)

r、b 分别是红边和蓝边数量；最多处理 2n 个状态。

替代方案

Dijkstra 也可在扩展状态图上求解，但所有边权都是 1，优先队列只会增加复杂度。也能以“下一条应走的颜色”定义状态，本质等价。单纯 DFS 不保证先找到最短路径。

常见错误

  • 只用一维 visited[node]。
  • 起点只初始化一种颜色，漏掉另一种起始边。
  • 出队后继续走同色边。
  • 把不可达的无穷值直接放进答案。

面试追问

如果有 k 种颜色且要求相邻颜色不同？状态仍为 (node, lastColor)，从当前节点枚举除 lastColor 外的边色。若颜色必须按固定周期出现，可把“周期位置”放入状态。若边有非负权重，则在同一状态图上改用 Dijkstra。

四语言完整实现

Java
import java.util.*;

class Solution {
    public int[] shortestAlternatingPaths(int n, int[][] redEdges, int[][] blueEdges) {
        List<Integer>[][] graph = new ArrayList[2][n];
        for (int color = 0; color < 2; color++) {
            for (int node = 0; node < n; node++) {
                graph[color][node] = new ArrayList<>();
            }
        }
        for (int[] edge : redEdges) graph[0][edge[0]].add(edge[1]);
        for (int[] edge : blueEdges) graph[1][edge[0]].add(edge[1]);

        int inf = Integer.MAX_VALUE;
        int[][] dist = new int[n][2];
        for (int[] row : dist) Arrays.fill(row, inf);
        dist[0][0] = dist[0][1] = 0;

        Deque<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{0, 0});
        queue.offer(new int[]{0, 1});

        while (!queue.isEmpty()) {
            int[] state = queue.poll();
            int node = state[0];
            int lastColor = state[1];
            int nextColor = 1 - lastColor;

            for (int next : graph[nextColor][node]) {
                if (dist[next][nextColor] != inf) continue;
                dist[next][nextColor] = dist[node][lastColor] + 1;
                queue.offer(new int[]{next, nextColor});
            }
        }

        int[] answer = new int[n];
        for (int node = 0; node < n; node++) {
            int best = Math.min(dist[node][0], dist[node][1]);
            answer[node] = best == inf ? -1 : best;
        }
        return answer;
    }
}

/**
 * @param {number} n
 * @param {number[][]} redEdges
 * @param {number[][]} blueEdges
 * @return {number[]}
 */
var shortestAlternatingPaths = function(n, redEdges, blueEdges) {
    const RED = 0;
    const BLUE = 1;
    const graph = Array.from({ length: 2 }, () =>
        Array.from({ length: n }, () => [])
    );

    for (const [from, to] of redEdges) graph[RED][from].push(to);
    for (const [from, to] of blueEdges) graph[BLUE][from].push(to);

    const dist = Array.from({ length: n }, () => [Infinity, Infinity]);
    dist[0][RED] = 0;
    dist[0][BLUE] = 0;

    const queue = [[0, RED], [0, BLUE]];
    let head = 0;

    while (head < queue.length) {
        const [node, lastColor] = queue[head++];
        const nextColor = 1 - lastColor;

        for (const next of graph[nextColor][node]) {
            if (dist[next][nextColor] !== Infinity) continue;
            dist[next][nextColor] = dist[node][lastColor] + 1;
            queue.push([next, nextColor]);
        }
    }

    return dist.map(([red, blue]) => {
        const best = Math.min(red, blue);
        return best === Infinity ? -1 : best;
    });
};
Python
from collections import deque
from typing import List


class Solution:
    def shortestAlternatingPaths(
        self,
        n: int,
        redEdges: List[List[int]],
        blueEdges: List[List[int]],
    ) -> List[int]:
        RED, BLUE = 0, 1
        graph = [[[] for _ in range(n)] for _ in range(2)]

        for start, end in redEdges:
            graph[RED][start].append(end)
        for start, end in blueEdges:
            graph[BLUE][start].append(end)

        inf = float("inf")
        dist = [[inf, inf] for _ in range(n)]
        dist[0][RED] = dist[0][BLUE] = 0

        queue = deque([(0, RED), (0, BLUE)])
        while queue:
            node, last_color = queue.popleft()
            next_color = 1 - last_color

            for nxt in graph[next_color][node]:
                if dist[nxt][next_color] != inf:
                    continue
                dist[nxt][next_color] = dist[node][last_color] + 1
                queue.append((nxt, next_color))

        answer = []
        for red_dist, blue_dist in dist:
            best = min(red_dist, blue_dist)
            answer.append(-1 if best == inf else best)
        return answer
C++
#include <algorithm>
#include <array>
#include <limits>
#include <queue>
#include <utility>
#include <vector>

using namespace std;

class Solution {
public:
    vector<int> shortestAlternatingPaths(
        int n,
        vector<vector<int>>& redEdges,
        vector<vector<int>>& blueEdges
    ) {
        const int RED = 0;
        const int BLUE = 1;
        vector<vector<int>> graph[2] = {
            vector<vector<int>>(n),
            vector<vector<int>>(n)
        };

        for (const auto& edge : redEdges) graph[RED][edge[0]].push_back(edge[1]);
        for (const auto& edge : blueEdges) graph[BLUE][edge[0]].push_back(edge[1]);

        const int INF = numeric_limits<int>::max();
        vector<array<int, 2>> dist(n, {INF, INF});
        dist[0][RED] = dist[0][BLUE] = 0;

        queue<pair<int, int>> q;
        q.push({0, RED});
        q.push({0, BLUE});

        while (!q.empty()) {
            auto [node, lastColor] = q.front();
            q.pop();
            int nextColor = 1 - lastColor;

            for (int next : graph[nextColor][node]) {
                if (dist[next][nextColor] != INF) continue;
                dist[next][nextColor] = dist[node][lastColor] + 1;
                q.push({next, nextColor});
            }
        }

        vector<int> answer(n);
        for (int node = 0; node < n; node++) {
            int best = min(dist[node][RED], dist[node][BLUE]);
            answer[node] = best == INF ? -1 : best;
        }
        return answer;
    }
};
