Problem

任务与数据结构

题意转述

给定 Activities 表，每行表示某个产品在某天售出。表没有主键，所以完全相同的记录可能重复。请对每个日期统计售出的不同产品数，并将不同产品按词典序排列后用英文逗号连接。最终结果按销售日期升序返回。

要特别留意：重复销售记录不能让数量增加，也不能在产品列表中重复出现。

Activities 表

sell_date

product
varchar(20)

  • 表内可能存在重复行。
  • 每行记录产品名称与销售日期。
  • 官方元数据未提供额外的数据量范围。

Solution

把四件事交给一次聚合

核心洞察

日期决定结果的分组粒度。计数和字符串聚合都作用于不同产品，因此两处都需要 DISTINCT；字符串聚合内部负责产品排序，查询最外层负责日期排序。

GROUP BY 日期 → DISTINCT 产品 → 产品内排序 → 逗号拼接 → 日期外排序

完整过程

  1. GROUP BY sell_date 将同一天的行归为一组。
  2. COUNT(DISTINCT product) 得到不同产品数量。
  3. GROUP_CONCAT(DISTINCT product ORDER BY product SEPARATOR ',') 去重、排序并连接名称。
  4. ORDER BY sell_date 让最终结果按日期升序排列。

MySQL官方可提交语言
SELECT
    sell_date,
    COUNT(DISTINCT product) AS num_sold,
    GROUP_CONCAT(
        DISTINCT product
        ORDER BY product
        SEPARATOR ','
    ) AS products
FROM Activities
GROUP BY sell_date
ORDER BY sell_date;
Java本地语义参考，不能提交到数据库判题
import java.time.LocalDate;
import java.util.*;

public class Solution {
    record Activity(LocalDate sellDate, String product) {}
    record Result(LocalDate sellDate, int numSold, String products) {}

    public List<Result> categorizeProducts(List<Activity> activities) {
        Map<LocalDate, SortedSet<String>> groups = new TreeMap<>();
        for (Activity activity : activities) {
            groups.computeIfAbsent(
                activity.sellDate(), date -> new TreeSet<>()
            ).add(activity.product());
        }
        List<Result> answer = new ArrayList<>();
        for (var entry : groups.entrySet()) {
            SortedSet<String> products = entry.getValue();
            answer.add(new Result(
                entry.getKey(), products.size(), String.join(",", products)
            ));
        }
        return answer;
    }
}
JavaScript本地语义参考，不能提交到数据库判题
function categorizeProducts(activities) {
  const groups = new Map();

  for (const { sell_date, product } of activities) {
    if (!groups.has(sell_date)) groups.set(sell_date, new Set());
    groups.get(sell_date).add(product);
  }

  return [...groups.keys()]
    .sort((a, b) => a.localeCompare(b))
    .map((sell_date) => {
      const products = [...groups.get(sell_date)]
        .sort((a, b) => a.localeCompare(b));
      return {
        sell_date,
        num_sold: products.length,
        products: products.join(","),
      };
    });
}
Python本地语义参考；Pandas 是官方另一提交入口
from collections import defaultdict
from dataclasses import dataclass
from datetime import date

@dataclass(frozen=True)
class Activity:
    sell_date: date
    product: str

def categorize_products(activities: list[Activity]) -> list[dict]:
    groups: dict[date, set[str]] = defaultdict(set)

    for activity in activities:
        groups[activity.sell_date].add(activity.product)

    answer = []
    for sell_date in sorted(groups):
        products = sorted(groups[sell_date])
        answer.append({
            "sell_date": sell_date,
            "num_sold": len(products),
            "products": ",".join(products),
        })
    return answer
C++本地语义参考，不能提交到数据库判题
#include <map>
#include <set>
#include <string>
#include <vector>
using namespace std;

struct Activity {
    string sellDate;
    string product;
};
struct Result {
    string sellDate;
    int numSold;
    string products;
};

vector<Result> categorizeProducts(const vector<Activity>& activities) {
    map<string, set<string>> groups;
    for (const auto& activity : activities) {
        groups[activity.sellDate].insert(activity.product);
    }

    vector<Result> answer;
    for (const auto& [sellDate, productSet] : groups) {
        string joined;
        for (const string& product : productSet) {
            if (!joined.empty()) joined += ',';
            joined += product;
        }
        answer.push_back({
            sellDate, static_cast<int>(productSet.size()), joined
        });
    }
    return answer;
}

正确性说明

分组完整。

每条记录只进入其销售日期对应的组，所以每个日期恰好产生一行。

计数准确。

不同产品集合忽略重复行，其大小就是正确数量。

列表准确。

字符串聚合恰好保留每个名称一次，内部排序和分隔符保证格式。

整体有序。

最外层按日期排序。因此查询返回且仅返回题目要求的结果。

复杂度与边界

设总行数为 N，某天不同产品数为 Kᵢ。执行计划依赖数据库实现；概念上扫描约为 O(N)，各组排序合计约为 Σ O(Kᵢ log Kᵢ)，聚合空间约为不同“日期—产品”对的总数。

  • 重复行：两处 DISTINCT 都不能遗漏。
  • 单一产品：结果没有多余逗号。
  • 同日多产品：排序位于字符串聚合内部。
  • 大小写：词典序受数据库字符集与排序规则影响。

替代方案

可先在子查询中执行 SELECT DISTINCT sell_date, product，再计数与拼接。它更直观，但多一层查询。PostgreSQL 可用 STRING_AGG(DISTINCT product, ',' ORDER BY product)；SQL Server 的写法取决于版本。

常见错误

只写 COUNT(product)

重复记录会被重复计数。

拼接漏掉 DISTINCT

数量可能正确，字符串仍会重复。

把产品排序写在最外层

外层排序不能控制组内拼接顺序。

漏写日期排序

SQL 不保证无 ORDER BY 时的行序。
