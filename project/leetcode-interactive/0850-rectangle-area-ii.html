矩形面积 IIRectangle Area II

多个轴对齐矩形可能彼此覆盖。你的任务不是把面积简单相加，而是精确测量它们在平面上的并集面积，并对 10⁹ + 7 取模。

非会员题数组有序集合扫描线线段树

Problem

题目要求

重叠区域只能计算一次

准确转述

给定二维数组 rectangles，其中 rectangles[i] = [x1, y1, x2, y2] 表示一个边与坐标轴平行、左下角为 (x1,y1)、右上角为 (x2,y2) 的矩形。

返回所有矩形覆盖区域的总面积。被多个矩形重复覆盖的部分只计一次；结果对 1,000,000,007 取模。

函数签名
输入rectangles: integer[][]
返回integer

约束

  • 1 ≤ rectangles.length ≤ 200
  • rectangles[i].length = 4
  • 0 ≤ x1, y1, x2, y2 ≤ 10⁹
  • x1 ≤ x2
  • y1 ≤ y2
  • 每个矩形面积均非零，因此实际有 x1 < x2 且 y1 < y2。

Examples

官方示例

示例 1
输入：rectangles = [[0,0,2,2],
                    [1,0,2,3],
                    [1,0,3,1]]
输出：6
解释：三个矩形的并集覆盖面积为 6；
重叠部分不重复计数。
示例 2
输入：rectangles = [[0,0,1000000000,
                     1000000000]]
输出：49
解释：面积是 10¹⁸，
对 10⁹ + 7 取模得到 49。

观察提示

  1. 扫描线只在遇到矩形的左边界或右边界时改变状态。
  2. 在两个相邻事件之间，活跃矩形集合不变，因此被覆盖的 y 总长度也不变。
  3. 每个竖直条带的贡献等于“横向宽度 × y 方向并集长度”。

Solution

扫描线 + 活跃区间合并

核心洞察

把每个矩形拆成两个 x 事件：在左边界加入它的 y 区间，在右边界移除。事件按 x 排序。处理当前 x 的事件之前，活跃集合描述了从上一个 x 到当前 x 之间的覆盖情况。将活跃 y 区间排序并合并，就能得到该条带的真实高度。

完整过程

为每个 [x1,y1,x2,y2] 建立 (x1,+1,y1,y2) 与 (x2,-1,y1,y2) 两个事件，并按 x 排序。
来到事件坐标 x 时，先合并当前活跃的所有 y 区间，求并集长度 coveredY。
把 (x - prevX) × coveredY 加到答案中，再一次性处理该 x 上的全部加入、删除事件。
令 prevX = x，继续下一个不同的 x；每次累加都对模数取模。

正确性证明

引理 1：在任意两个相邻事件坐标 prevX 与 x 之间，没有矩形开始或结束，因此活跃矩形集合保持不变。

引理 2：合并所有活跃矩形的 y 区间得到的长度，恰好等于该开区间内任意竖线被矩形并集覆盖的总长度；合并操作保证重叠部分仅计一次。

定理：依据两个引理，算法为每个条带加入“宽 × 覆盖高度”，这正是该条带内矩形并集的面积。相邻条带内部不重叠且覆盖全部可能区域，故所有条带面积之和等于所有矩形的并集面积。

边界情况

  • 多个事件拥有相同 x：先结算前一条带，再成组更新，零宽条带不会贡献面积。
  • y 区间相接：合并或不合并都不改变总长度。
  • 完全重叠或被包含：区间合并避免重复计数。
  • 坐标与面积很大：Java/C++ 使用 64 位整数；JavaScript 使用 BigInt；Python 整数无固定宽度。

复杂度

时间
O(n² log n)

至多 2n 组事件，每组重新排序、合并至多 n 个活跃区间。

空间
O(n)

存储事件与活跃区间。n ≤ 200 时足够稳妥。

替代方案

可以离散化所有 y 坐标，并用覆盖计数线段树动态维护 y 并集长度，使整体复杂度降为 O(n log n)。实现更长，适合 n 更大的扩展题；本题 n 仅为 200，活跃区间直接合并更清晰。

import java.util.*;

class Solution {
    private static final long MOD = 1_000_000_007L;

    public int rectangleArea(int[][] rectangles) {
        List<long[]> events = new ArrayList<>();
        for (int[] r : rectangles) {
            events.add(new long[]{r[0], 1, r[1], r[3]});
            events.add(new long[]{r[2], -1, r[1], r[3]});
        }
        events.sort(Comparator.comparingLong(a -> a[0]));
        List<long[]> active = new ArrayList<>();
        long answer = 0, prevX = events.get(0)[0];
        int i = 0;
        while (i < events.size()) {
            long x = events.get(i)[0];
            answer = (answer + (x - prevX) % MOD * unionLength(active)) % MOD;
            while (i < events.size() && events.get(i)[0] == x) {
                long[] e = events.get(i++);
                if (e[1] == 1) active.add(new long[]{e[2], e[3]});
                else removeOne(active, e[2], e[3]);
            }
            prevX = x;
        }
        return (int) answer;
    }

    private long unionLength(List<long[]> active) {
        if (active.isEmpty()) return 0;
        List<long[]> sorted = new ArrayList<>(active);
        sorted.sort(Comparator.comparingLong(a -> a[0]));
        long total = 0, left = sorted.get(0)[0], right = sorted.get(0)[1];
        for (int i = 1; i < sorted.size(); i++) {
            long[] cur = sorted.get(i);
            if (cur[0] > right) {
                total += right - left;
                left = cur[0]; right = cur[1];
            } else right = Math.max(right, cur[1]);
        }
        return (total + right - left) % MOD;
    }

    private void removeOne(List<long[]> active, long y1, long y2) {
        for (int i = 0; i < active.size(); i++)
            if (active.get(i)[0] == y1 && active.get(i)[1] == y2) {
                active.remove(i); return;
            }
    }
}

var rectangleArea = function(rectangles) {
    const MOD = 1000000007n;
    const events = [];
    for (const [x1, y1, x2, y2] of rectangles) {
        events.push([x1, 1, y1, y2], [x2, -1, y1, y2]);
    }
    events.sort((a, b) => a[0] - b[0]);
    const active = [];
    let answer = 0n, prevX = events[0][0], i = 0;

    const unionLength = () => {
        if (active.length === 0) return 0;
        const sorted = active.slice().sort((a, b) => a[0] - b[0]);
        let total = 0, [left, right] = sorted[0];
        for (let j = 1; j < sorted.length; j++) {
            const [a, b] = sorted[j];
            if (a > right) { total += right - left; left = a; right = b; }
            else right = Math.max(right, b);
        }
        return total + right - left;
    };

    while (i < events.length) {
        const x = events[i][0];
        answer = (answer + BigInt(x - prevX) * BigInt(unionLength())) % MOD;
        while (i < events.length && events[i][0] === x) {
            const [, type, y1, y2] = events[i++];
            if (type === 1) active.push([y1, y2]);
            else {
                const index = active.findIndex(([a, b]) => a === y1 && b === y2);
                active.splice(index, 1);
            }
        }
        prevX = x;
    }
    return Number(answer);
};

public:
    int rectangleArea(vector<vector<int>>& rectangles) {

        vector<array<long long, 4>> events;
        for (const auto& r : rectangles) {

            events.push_back({r[2], -1, r[1], r[3]});
        }
        sort(events.begin(), events.end());
        vector<pair<long long, long long>> active;
        long long answer = 0, prevX = events[0][0];

        auto unionLength = [&]() {
            if (active.empty()) return 0LL;
            auto intervals = active;
            sort(intervals.begin(), intervals.end());
            long long total = 0;
            auto [left, right] = intervals[0];
            for (int j = 1; j < (int)intervals.size(); ++j) {
                auto [a, b] = intervals[j];
                if (a > right) {
                    total += right - left;
                    left = a; right = b;
                } else right = max(right, b);
            }
            return total + right - left;
        };

        for (int i = 0; i < (int)events.size();) {
            long long x = events[i][0];
            answer = (answer + (x - prevX) % MOD * (unionLength() % MOD)) % MOD;
            while (i < (int)events.size() && events[i][0] == x) {
                auto [_, kind, y1, y2] = events[i++];
                if (kind == 1) active.push_back({y1, y2});
                else {
                    auto it = find(active.begin(), active.end(), make_pair(y1, y2));

面试追问

为什么同一 x 的事件要成组处理？

它们之间的宽度为 0，不会产生面积。成组更新能让每个正宽条带只对应一个确定的活跃集合。

如何优化到 O(n log n)？

离散化 y 坐标，用带覆盖计数的线段树维护根节点覆盖长度。每次 x 事件更新一个 y 区间。

为什么 JavaScript 要用 BigInt？

面积中间值可能达到 10¹⁸，超过 Number 的安全整数上限；先用 BigInt 精确运算并取模，最后再转 Number。

常见错误

直接求面积和

会把重叠区域重复计算。

先更新再结算

会用当前 x 之后的集合计算前一条带。

删除所有相同区间

不同矩形可能拥有相同 y 区间，只应删除一个实例。

使用 32 位乘法

宽与高度相乘会溢出，取模前也必须使用足够宽的类型。
