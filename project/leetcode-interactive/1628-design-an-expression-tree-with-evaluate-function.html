#1628 MEDIUM 会员题
Stack · Tree · Design

把一串后缀记号，长成一棵会计算的树。

设计一个表达式树接口：它既能保存算式的结构，也能通过 evaluate() 递归算出结果。先理解任务，再用交互沙盘观察记号如何改变结构。

官方函数 buildTree(s)

输入 string[] 后缀表达式，返回实现了 Node 接口的根节点。

Problem

题意

给定一个算术表达式的后缀记号数组 s，请构建并返回表示该表达式的二叉表达式树。返回树会通过节点接口的 evaluate() 方法接受评测。

叶子节点表示整数；每个内部节点表示 +、-、* 或 /，并且恰有两个孩子。除法按整数规则向零截断。

后缀表达式 把运算符写在两个操作数之后，因此无需括号或优先级表。例如 4 5 2 7 + - * 表示 4 × (5 - (2 + 7))。

官方接口语义

保留抽象节点 Node，让返回的根节点支持 evaluate()；可以自行定义数值节点、运算节点或其他实现类。进阶目标是：添加新运算符时，不必修改既有节点的求值流程。

完整示例

示例 1
输入
s = ["3","4","+","2","*","7","/"]
输出
2
解释
((3 + 4) × 2) / 7 = 2
示例 2
输入
s = ["4","5","2","7","+","-","*"]
输出
-16
解释
4 × (5 - (2 + 7)) = -16

约束

  • 1 ≤ s.length < 100，且 s.length 为奇数。
  • s 只包含十进制整数以及 +、-、*、/。
  • 若 s[i] 是数字，其整数值不超过 105。
  • s 一定构成有效表达式，不会出现除以零。
  • 最终结果及所有中间结果的绝对值均不超过 109。

Solution

栈构树 + 多态求值

后缀序列的顺序已经替我们消除了括号与优先级：扫描时只需要维护“已完成子树”的栈。

数字就是叶子

读到整数，创建数值节点并压栈。它的 evaluate() 直接返回自身值。

运算符合并两棵树

先弹出的节点是右操作数，后弹出的是左操作数；创建运算节点，再把新树压栈。

栈底最终成为根

有效后缀式扫描结束后恰剩一棵树。根节点递归求左右值，再应用自身运算。

完整过程

  1. 建立空栈，栈内元素的类型为 Node。准备“运算符 → 二元函数”的映射，使运算逻辑与树结构解耦。
  2. 从左到右扫描 s。若当前记号是整数，构造 NumericNode 并压栈。
  3. 若当前记号是运算符，依次弹出 right 和 left，以二者及相应运算函数构造 OperatorNode，再压回栈中。
  4. 扫描结束，栈中唯一节点就是根。调用根的 evaluate()：叶子返回值，内部节点递归取得左右结果并调用保存的运算函数。

正确性证明

循环不变式：扫描完前 i 个记号后，栈从底到顶保存了该前缀中尚未被更后运算符合并的全部完整子表达式树，并且每棵树准确表示对应子表达式。

初始化：尚未扫描时栈为空，不变式成立。

保持：数字形成准确的单节点子树；运算符取出最近完成的右、左子表达式，并以当前运算符连接它们，所得新树准确表示两者合成的表达式。因此不变式继续成立。

终止：输入保证有效，全部记号处理完后栈中恰有一棵树，它表示完整表达式。对其结构归纳可知，evaluate() 对叶子返回正确数字，对内部节点组合两个正确子结果，故返回完整表达式的正确值。

复杂度与边界

构建：每个记号只进出栈常数次，时间 O(n)；树和栈共占 O(n) 空间。

求值：每个节点访问一次，时间 O(n)；递归栈为 O(h)，最坏退化为 O(n)。

关键边界：单个数字直接成为根；减法与除法必须保持左右顺序；负数除法按向零截断；有效性及非零除数由题目保证。

import java.util.*;
import java.util.function.IntBinaryOperator;

abstract class Node {
    public abstract int evaluate();
}

class NumericNode extends Node {
    private final int value;

    NumericNode(int value) {
        this.value = value;
    }

    @Override
    public int evaluate() {
        return value;
    }
}

class OperatorNode extends Node {
    private final Node left;
    private final Node right;
    private final IntBinaryOperator operation;

    OperatorNode(Node left, Node right, IntBinaryOperator operation) {
        this.left = left;
        this.right = right;
        this.operation = operation;
    }

    @Override
    public int evaluate() {
        return operation.applyAsInt(left.evaluate(), right.evaluate());
    }
}

class TreeBuilder {
    private static final Map<String, IntBinaryOperator> OPERATIONS = Map.of(
        "+", (a, b) -> a + b,
        "-", (a, b) -> a - b,
        "*", (a, b) -> a * b,
        "/", (a, b) -> a / b
    );

    Node buildTree(String[] s) {
        Deque<Node> stack = new ArrayDeque<>();

        for (String token : s) {
            IntBinaryOperator operation = OPERATIONS.get(token);
            if (operation == null) {
                stack.push(new NumericNode(Integer.parseInt(token)));
                continue;
            }

            Node right = stack.pop();
            Node left = stack.pop();
            stack.push(new OperatorNode(left, right, operation));
        }
        return stack.pop();
    }
}

from abc import ABC, abstractmethod
from typing import Callable, Dict, List


class Node(ABC):
    @abstractmethod
    def evaluate(self) -> int:
        pass


class NumericNode(Node):
    def __init__(self, value: int):
        self.value = value

    def evaluate(self) -> int:
        return self.value


class OperatorNode(Node):
    def __init__(
        self,
        left: Node,
        right: Node,
        operation: Callable[[int, int], int],
    ):
        self.left = left
        self.right = right
        self.operation = operation

    def evaluate(self) -> int:
        return self.operation(self.left.evaluate(), self.right.evaluate())


def truncate_division(a: int, b: int) -> int:
    quotient = abs(a) // abs(b)
    return quotient if (a >= 0) == (b >= 0) else -quotient


class TreeBuilder:
    OPERATIONS: Dict[str, Callable[[int, int], int]] = {
        "+": lambda a, b: a + b,
        "-": lambda a, b: a - b,
        "*": lambda a, b: a * b,
        "/": truncate_division,
    }

    def buildTree(self, s: List[str]) -> Node:
        stack: List[Node] = []

        for token in s:
            operation = self.OPERATIONS.get(token)
            if operation is None:
                stack.append(NumericNode(int(token)))
                continue

            right = stack.pop()
            left = stack.pop()
            stack.append(OperatorNode(left, right, operation))

        return stack.pop()
#include <functional>
#include <stack>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

class Node {
public:
    virtual ~Node() = default;
    virtual int evaluate() const = 0;
};

class NumericNode final : public Node {
private:
    int value;

public:
    explicit NumericNode(int value) : value(value) {}

    int evaluate() const override {
        return value;
    }
};

class OperatorNode final : public Node {
private:
    Node* left;
    Node* right;
    function<int(int, int)> operation;

public:
    OperatorNode(Node* left, Node* right, function<int(int, int)> operation)
        : left(left), right(right), operation(std::move(operation)) {}

    ~OperatorNode() override {
        delete left;
        delete right;
    }

    int evaluate() const override {
        return operation(left->evaluate(), right->evaluate());
    }
};

class TreeBuilder {
private:
    const unordered_map<string, function<int(int, int)>> operations = {
        {"+", [](int a, int b) { return a + b; }},
        {"-", [](int a, int b) { return a - b; }},
        {"*", [](int a, int b) { return a * b; }},
        {"/", [](int a, int b) { return a / b; }}
    };

public:
    Node* buildTree(vector<string>& s) {
        stack<Node*> nodes;

        for (const string& token : s) {
            auto it = operations.find(token);
            if (it == operations.end()) {
                nodes.push(new NumericNode(stoi(token)));
                continue;
            }

            Node* right = nodes.top();
            nodes.pop();
            Node* left = nodes.top();
            nodes.pop();
            nodes.push(new OperatorNode(left, right, it->second));
        }
        return nodes.top();
    }
};

替代方案

直接用栈计算 RPN：同样是 O(n)，而且常数更小；但它只给出数值，无法满足“返回可求值树”的接口，也不保留可复用结构。

节点内写运算符分支：实现更短，但每新增运算符都要修改 evaluate()。运算函数映射更符合开闭原则，也更贴合进阶要求。

面试追问

  • 如何加入一元运算符？让运算描述携带元数，并按元数弹栈。
  • 如何避免极深树的递归风险？用显式栈做后序遍历求值。
  • 如何支持变量？新增变量叶子，并让 evaluate 接收环境映射。
  • 如何序列化？后序遍历天然恢复为后缀表达式。

常见错误

  • 把第一次弹出的节点当作左孩子：对减法、除法会直接得到错误答案。
  • 在 JavaScript 使用 Math.floor(a / b)：负数会向负无穷取整；应使用 Math.trunc。
  • 只构造树却忘记实现节点的动态派发，导致所有运算集中在一个难扩展的条件链中。
  • C++ 未明确节点所有权而泄漏内存；示例让父运算节点析构时递归释放孩子。
  • 把输入当作中缀表达式处理，徒增优先级和括号逻辑。
