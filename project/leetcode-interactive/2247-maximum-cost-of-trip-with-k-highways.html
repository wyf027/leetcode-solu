01 / 问题

旅行规则

有 n 座城市，编号为 0 … n−1。每个 highways[i] = [city1, city2, toll] 表示一条连接两座城市的双向公路，经过它需要支付 toll。

你可以从任意城市出发，每座城市至多访问一次，连续经过恰好 k 条公路。返回符合要求的旅行的最大费用和；不存在这样的旅行时返回 -1。

maximumCost(n: integer, highways: integer[][], k: integer) → integer

约束

  • 2 ≤ n ≤ 15。
  • 1 ≤ highways.length ≤ 50，highways[i].length = 3。
  • 0 ≤ city1, city2 ≤ n−1，且 city1 ≠ city2。
  • 0 ≤ toll ≤ 100。
  • 1 ≤ k ≤ 50。
  • 不存在重复高速公路。

状态演示、证明、边界与四语言代码。

题解 · 访问集合与当前终点

核心洞察

接下来可以去哪，只取决于已访问的城市集合和当前终点。两条路线如果集合和终点相同，之后可选择的路线完全相同，所以只需保留费用更高的那条历史。

n≤15，可以用整数 mask 的二进制位记录集合。第 v 位为 1 表示城市 v 已访问。恰好 k 条公路对应 k+1 个不同城市，因此步数由集合大小直接确定。

dp[mask][u]：恰好访问 mask 中的城市并在 u 结束的合法路线的最大费用。不可达记为 −1。

完整过程

  1. 若 k≥n，城市数量不足，直接返回 −1。
  2. 建立无向邻接表。将所有 dp[1 << u][u] 初始化为 0，其余为 −1，覆盖任意起点。
  3. 按 mask 数值从小到大遍历。添加一个未访问城市总会增大 mask，前驱一定先于后继处理。
  4. 对可达状态和邻边 (u,v,w)，若 v 未访问，更新新状态。目标状态只保留最大费用。
  5. 当集合大小达到 k+1，将其费用纳入答案并停止扩展。从所有终点取最大值；全部不可达则返回 −1。
next = mask | (1 << v)
dp[next][v] = max(dp[next][v], dp[mask][u] + w)

    正确性证明

    基础：单个城市的路线费用为 0，初始化覆盖所有合法起点。

    归纳：任一以 v 结尾的合法路线，去掉最后一条 u→v 后，得到访问较小集合且终点为 u 的合法前缀。归纳假设保证该前缀状态存有最大费用。加上 w 不会比原路线差；因为 v 未访问，扩展仍合法。枚举全部前驱覆盖所有合法路线，而取最大值保留最优者。

    终止：恰有 k+1 个城市的路线恰经过 k 条公路，故这些终态的最大值就是答案；不存在终态时返回 −1。

    复杂度与边界

    令 m 为公路数。每个 mask 扫描 n 个终点及至多 2m 条邻接边，时间为 O(2ⁿ(n+m))；稠密图下可写为 O(2ⁿn²)。DP 空间为 O(2ⁿn)，邻接表占 O(n+m)。

    • k≥n：直接无解，无需分配 DP。
    • 零边权：0 是可达费用，不能作为无解哨兵。
    • 不连通图：不同分量的路线不能拼接。
    • 最大费用 ≤100(n−1)≤1400，整型足够。
    • k=1 时答案就是最大边权。

    替代方案

    • 记忆化 DFS：用 (mask,u) 缓存最优剩余收益，访问满 k+1 个城市时返回 0。状态规模相同，另有 O(n) 递归栈；无解后缀不能直接加边权。
    • 回溯：k 很小时直观，但稠密图最坏会枚举阶乘级城市排列。集合 DP 合并具有相同后续选择的历史。
    • 按集合大小分层：可以用稀疏表只存相邻两层，减少某些图上的存储，但哈希管理更复杂。本题直接数组足够。

    常见错误

    • 仅存“终点+步数”，丢失已访问集合，允许非法重复城市。
    • 只从城市 0 出发，遗漏其他起点。
    • 把“恰好 k”写成“最多 k”，将短路线计入答案。
    • 无向边只添加一个方向；或忘记判断下一城市是否已访问。
    • 全部状态初始化为 0，凭空制造不存在的路径。
    • 贪心挑最贵的邻边，可能走入死路而无法完成 k 条公路。

    面试追问

    如何还原路线？ 每次改善保存前驱 (mask,u)，从最优终态回溯。演示为方便展示直接存短路线，下面提交代码仅存费用。

    允许重复城市呢？ 集合不再必要，可以用“步数×终点”DP，在 O(km) 时间计算恰好 k 步的最大费用。

    允许负费用呢？ 不可达值应改为负无穷或使用独立标记；−1 可能成为合法费用，答案仍只统计恰好 k 条。

    Java

    import java.util.*;

class Solution {
    public int maximumCost(int n, int[][] highways, int k) {
        if (k >= n) return -1;
        List<int[]>[] graph = new ArrayList[n];
        for (int u = 0; u < n; u++) graph[u] = new ArrayList<>();
        for (int[] e : highways) {
            graph[e[0]].add(new int[]{e[1], e[2]});
            graph[e[1]].add(new int[]{e[0], e[2]});
        }
        int size = 1 << n, answer = -1;
        int[][] dp = new int[size][n];
        for (int[] row : dp) Arrays.fill(row, -1);
        for (int u = 0; u < n; u++) dp[1 << u][u] = 0;
        for (int mask = 1; mask < size; mask++) {
            int count = Integer.bitCount(mask);
            if (count > k + 1) continue;
            for (int u = 0; u < n; u++) {
                if (dp[mask][u] < 0) continue;
                if (count == k + 1) {
                    answer = Math.max(answer, dp[mask][u]);
                    continue;
                }
                for (int[] e : graph[u]) {
                    int v = e[0], w = e[1];
                    if ((mask & (1 << v)) != 0) continue;
                    int next = mask | (1 << v);
                    dp[next][v] = Math.max(dp[next][v], dp[mask][u] + w);
                }
            }
        }
        return answer;
    }
}

    /**
 * @param {number} n
 * @param {number[][]} highways
 * @param {number} k
 * @return {number}

var maximumCost = function(n, highways, k) {
    if (k >= n) return -1;
    const graph = Array.from({length: n}, () => []);
    for (const [u, v, w] of highways) {
        graph[u].push([v, w]);
        graph[v].push([u, w]);
    }
    const size = 1 << n;
    const dp = Array.from({length: size}, () => new Int32Array(n).fill(-1));
    const bits = new Uint8Array(size);
    for (let mask = 1; mask < size; mask++)
        bits[mask] = bits[mask >> 1] + (mask & 1);
    for (let u = 0; u < n; u++) dp[1 << u][u] = 0;
    let answer = -1;
    for (let mask = 1; mask < size; mask++) {
        if (bits[mask] > k + 1) continue;
        for (let u = 0; u < n; u++) {
            if (dp[mask][u] < 0) continue;
            if (bits[mask] === k + 1) {
                answer = Math.max(answer, dp[mask][u]);
                continue;
            }
            for (const [v, w] of graph[u]) {
                if (mask & (1 << v)) continue;
                const next = mask | (1 << v);
                dp[next][v] = Math.max(dp[next][v], dp[mask][u] + w);
            }
        }
    }
    return answer;
};

    from typing import List

class Solution:
    def maximumCost(self, n: int, highways: List[List[int]], k: int) -> int:
        if k >= n:
            return -1
        graph = [[] for _ in range(n)]
        for u, v, w in highways:
            graph[u].append((v, w))
            graph[v].append((u, w))
        size = 1 << n
        dp = [[-1] * n for _ in range(size)]
        for u in range(n):
            dp[1 << u][u] = 0
        answer = -1
        for mask in range(1, size):
            count = mask.bit_count()
            if count > k + 1:
                continue
            for u in range(n):
                if dp[mask][u] < 0:
                    continue
                if count == k + 1:
                    answer = max(answer, dp[mask][u])
                    continue
                for v, w in graph[u]:
                    if mask & (1 << v):
                        continue
                    nxt = mask | (1 << v)

        return answer

class Solution {
public:
    int maximumCost(int n, vector<vector<int>>& highways, int k) {
        if (k >= n) return -1;
        vector<vector<pair<int, int>>> graph(n);
        for (const auto& e : highways) {
            graph[e[0]].push_back({e[1], e[2]});
            graph[e[1]].push_back({e[0], e[2]});
        }
        int size = 1 << n, answer = -1;
        vector<vector<int>> dp(size, vector<int>(n, -1));
        for (int u = 0; u < n; ++u) dp[1 << u][u] = 0;
        for (int mask = 1; mask < size; ++mask) {
            int count = __builtin_popcount(static_cast<unsigned>(mask));
            if (count > k + 1) continue;

                if (dp[mask][u] < 0) continue;

                    answer = max(answer, dp[mask][u]);
                    continue;
                }

                    if (mask & (1 << v)) continue;
                    int next = mask | (1 << v);
                    dp[next][v] = max(dp[next][v], dp[mask][u] + w);
                }
            }
        }
        return answer;
    }
};
