生成发票

Generate the Invoice

一张发票，多行商品。找出总金额最高的那张，返回它的完整明细。

阅读题目 ↓先独立思考，再展开底部题解

01题目与数据契约

商品表 Products(product_id int, price int) 保存商品单价；采购表 Purchases(invoice_id int, product_id int, quantity int) 保存一张发票购买某种商品的数量。

选择商品金额总和最大的发票。若多张发票同额，选 invoice_id 最小者。返回它的全部商品行，列为 product_id, quantity, price，行顺序任意。

输出 price 是每行的购买金额（数量 × 单价），Products.price 才是单价。结果不包含 invoice_id。

约束

  • Products.product_id 唯一；Purchases 的联合主键为 (invoice_id, product_id)。同一商品可出现在不同发票中。
  • 所有列均为 int。公开题面没有提供行数、金额或数量的具体上下限，也没有另列非空、外键约束；此处不补造数值范围。
  • 本页按关联到商品价格的采购行计算，即 INNER JOIN 语义。空输入另作为扩展边界。

本轮官方元数据提供表结构和示例，题面与代码模板为空。题意、唯一性与输出规则参考 LeetCode Wiki 公开记录，以自己的语言转述。官方题目入口。

05独立题解

准备好后，展开推导和完整代码。

核心洞察：选发票，再取明细

汇总层负责确定唯一赢家；明细层保留每种商品的数量与金额。分组会压缩多行商品，所以选出发票编号后，要回到明细层取该编号的所有行。

完整过程

  1. 按 product_id 关联采购表与商品表，计算 line_price = quantity × 单价。
  2. 按 invoice_id 分组，求 SUM(line_price)。
  3. 总额降序、invoice_id 升序排序，取第一张发票。
  4. 用选中的编号关联回商品明细，输出 product_id、quantity、line_price AS price。

正确性

金额：商品键唯一，每条匹配的采购行恰好获得一个单价，故行金额正确；按发票分组恰好汇总该发票的所有行，故总额正确。

选择：总额降序使最大总额排在首位；编号升序使同额发票中最小编号排在首位。取一行得到的编号符合全部选择条件。

输出：回联只保留赢家编号的行，既不会混入其他发票，也不丢弃赢家的任何商品；列投影与行金额别名符合输出要求。空赢家集合对应空结果。

边界与数值

  • 单张发票也要输出所有商品；无采购记录时返回空结果。
  • 同额时比较发票编号，而非商品编号；不可依赖输入顺序。
  • 未匹配商品价格的行按 INNER JOIN 语义排除；本题未要求补零。真实业务应另行处理缺失价格。
  • SQL 在乘法前扩展到 DECIMAL；Java 使用 BigInteger，Python 使用任意精度整数，JavaScript 金额使用 BigInt；C++ 使用 long long 并检查累计溢出。
  • 本地参考输入为无 NULL 且满足主键唯一性的表行，不模拟 SQL 的全部 NULL 传播规则。JavaScript 大整数请直接传 BigInt 或整数字符串，避免先经 Number 丢精度。

复杂度

P 为商品数、N 为采购行数、I 为发票数、K 为输出行数。在哈希关联与聚合模型下，SQL 完整排序约需 O(P + N + I log I + K) 时间，工作数据约 O(P + N + I) 空间；实际成本受索引、CTE 物化和 Top-1 优化影响，以执行计划为准。四份本地参考以哈希表和线性选最大值实现，期望 O(P + N + I) 时间、O(P + I) 辅助空间，另有 O(K) 输出空间。复杂度按整数运算为常数计；大整数位数增加时另有算术成本。

替代方案

窗口 SUM(...) OVER (PARTITION BY invoice_id) 可保留明细并附上总额，再在外层按 (总额 DESC, invoice_id ASC) 做 DENSE_RANK，取排名 1。包含 invoice_id 后，只有唯一赢家发票的所有商品行共享第一名。直接对明细使用 ROW_NUMBER 并仅取第一行，会错误丢失其他商品。

面试追问

  • 返回所有最高金额发票？取消编号决胜，按最大总额过滤，或仅按总额做 DENSE_RANK。
  • 大表优化？检查 Products 的商品键索引与 Purchases 的关联访问路径，结合 EXPLAIN 判断，避免盲目添加索引。
  • 单价以后变动怎么办？业务发票应保存购买时的单价快照；本题使用给定 Products.price。

常见错误

  • 选择最大单行金额，忘记汇总整张发票。
  • 输出商品单价或整张发票总额，而不是行金额。
  • GROUP BY 后随意选择未聚合的商品列，破坏分组语义。
  • 遗漏 invoice_id ASC，或在最终明细层 LIMIT 1 导致漏行。

MySQL 8+ · 官方数据库语言

WITH lines AS (
    SELECT pu.invoice_id, pu.product_id, pu.quantity,
           CAST(pr.price AS DECIMAL(38, 0)) * pu.quantity AS line_price
    FROM Purchases AS pu
    JOIN Products AS pr ON pr.product_id = pu.product_id
), winner AS (
    SELECT invoice_id
    FROM lines
    GROUP BY invoice_id
    ORDER BY SUM(line_price) DESC, invoice_id ASC
    LIMIT 1
)
SELECT l.product_id, l.quantity, l.line_price AS price
FROM lines AS l
JOIN winner AS w ON w.invoice_id = l.invoice_id;

Java · 本地语义参考

import java.util.*;
import java.math.BigInteger;

// Products: [product_id, price]
// Purchases: [invoice_id, product_id, quantity]
// 返回行: [product_id, quantity, price]
public class Solution {
    public static List<BigInteger[]> generateInvoice(
            long[][] products, long[][] purchases) {
        Map<Long, BigInteger> prices = new HashMap<>();
        Map<Long, BigInteger> totals = new HashMap<>();
        for (long[] p : products)
            prices.put(p[0], BigInteger.valueOf(p[1]));
        for (long[] r : purchases) {
            if (!prices.containsKey(r[1])) continue;
            BigInteger amount = prices.get(r[1])
                .multiply(BigInteger.valueOf(r[2]));
            totals.merge(r[0], amount, BigInteger::add);
        }
        Long best = null;
        for (long id : totals.keySet()) {
            if (best == null || totals.get(id).compareTo(totals.get(best)) > 0 ||
                (totals.get(id).equals(totals.get(best)) && id < best))
                best = id;
        }
        List<BigInteger[]> result = new ArrayList<>();
        if (best == null) return result;
        for (long[] r : purchases) {
            if (r[0] == best && prices.containsKey(r[1]))
                result.add(new BigInteger[]{BigInteger.valueOf(r[1]),
                    BigInteger.valueOf(r[2]),
                    prices.get(r[1]).multiply(BigInteger.valueOf(r[2]))});
        }
        return result;
    }
}

JavaScript · 本地语义参考

// 二维数组参数；ID 为安全整数；金额结果为 BigInt。
// 价格/数量可传 BigInt 或整数字符串。
function generateInvoice(products, purchases) {
    const prices = new Map(products.map(([id, price]) => [id, BigInt(price)]));
    const totals = new Map();
    for (const [id, product, quantity] of purchases) {
        if (!prices.has(product)) continue;
        totals.set(id, (totals.get(id) ?? 0n) + prices.get(product) * BigInt(quantity));
    }
    let best = null;
    for (const [id, total] of totals) {
        if (best === null || total > totals.get(best) ||
            (total === totals.get(best) && id < best)) best = id;
    }
    if (best === null) return [];
    return purchases
        .filter(([id, product]) => id === best && prices.has(product))
        .map(([, product, quantity]) =>
            [product, quantity, prices.get(product) * BigInt(quantity)]);
}

# products: [[product_id, price], ...]
# purchases: [[invoice_id, product_id, quantity], ...]
# 返回 [[product_id, quantity, price], ...]
def generate_invoice(products, purchases):
    prices = dict(products)
    totals = {}
    for invoice, product, quantity in purchases:
        if product not in prices:
            continue
        totals[invoice] = totals.get(invoice, 0) + prices[product] * quantity
    if not totals:
        return []
    best = min(totals, key=lambda invoice: (-totals[invoice], invoice))
    return [[product, quantity, prices[product] * quantity]
            for invoice, product, quantity in purchases
            if invoice == best and product in prices]

C++ · 本地语义参考

#include <array>
#include <vector>
#include <unordered_map>
#include <limits>
#include <stdexcept>
using namespace std;

// 输入各列为 int，输出为 [product_id, quantity, price]。
// 金额使用 long long；超出范围时抛错，更大金额需多精度整数。
class Solution {
public:
    vector<array<long long, 3>> generateInvoice(
        const vector<array<int, 2>>& products,
        const vector<array<int, 3>>& purchases) {
        unordered_map<int, long long> prices, totals;
        for (const auto& p : products) prices[p[0]] = p[1];
        for (const auto& r : purchases) {
            if (!prices.count(r[1])) continue;
            long long amount = prices.at(r[1]) * r[2];
            long long old = totals[r[0]];
            if ((amount > 0 && old > numeric_limits<long long>::max() - amount) ||
                (amount < 0 && old < numeric_limits<long long>::min() - amount))
                throw overflow_error("invoice total exceeds long long");
            totals[r[0]] = old + amount;
        }
        if (totals.empty()) return {};
        int best = totals.begin()->first;
        for (const auto& entry : totals) {
            int id = entry.first;
            if (entry.second > totals.at(best) ||
                (entry.second == totals.at(best) && id < best)) best = id;
        }
        vector<array<long long, 3>> result;
        for (const auto& r : purchases)
            if (r[0] == best && prices.count(r[1]))
                result.push_back({r[1], r[2], prices.at(r[1]) * r[2]});
        return result;
    }
};
