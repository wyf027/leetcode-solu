任务完成时间 I

给定一棵以任务 0 为根的有向树。叶子任务的完成时间就是 baseTime[i]；非叶子任务先取得所有子任务完成时间的最小值 earliest 与最大值 latest，再得到 latest + (latest - earliest) + baseTime[i]。返回根任务的完成时间。

输入方向
[u, v] 表示 u 是 v 的父任务。
约束
1 ≤ n ≤ 10⁵，结果小于 2⁵³。
首选方法
自底向上的后序 DFS，每条边仅访问一次。

题解与四语言实现

默认收起；先在实验台观察子任务回传的最小与最大时间。

核心洞察

父任务只依赖孩子完成时间的最小值与最大值。先计算所有孩子，父任务就能立即套用题给公式。因此递归返回“该子树根任务的完成时间”即可。

完整过程

  1. 按边建立父到子的邻接表。
  2. 后序 DFS：叶子直接返回 baseTime。
  3. 非叶子聚合各子返回值的 min/max。
  4. 返回 2 × max − min + baseTime[u]。

边界与复杂度

n = 1 时根也是叶子，直接返回 baseTime[0]。链很深时 Java/C++/Python 可改为显式栈以规避递归深度；本题 I 的常规 DFS 思路时间 O(n)、空间 O(n)。

替代方案 / 面试追问

可用显式后序栈和 children-count 自底向上求值，避免递归栈。若任务图不再是树，要先处理共享依赖和环；若要求每个任务完成时间，则保留 DFS 的结果数组。

常见错误

  • 误将 [u,v] 当成 v 的父节点，导致树方向反转。
  • 只取 latest 而漏掉 latest - earliest 的跨度。
  • 把非叶子任务的 baseTime 与 latest 相加两次，或没有使用 64 位结果类型。 
function finishTime(n, edges, baseTime) {
  const children = Array.from({ length: n }, () => []);
  for (const [parent, child] of edges) children[parent].push(child);
  const torqavemi = [n, edges, baseTime];
  function dfs(node) {
    if (children[node].length === 0) return baseTime[node];
    let earliest = Infinity, latest = -Infinity;
    for (const child of children[node]) {
      const time = dfs(child);
      earliest = Math.min(earliest, time);
      latest = Math.max(latest, time);
    }
    return latest + (latest - earliest) + baseTime[node];
  }
  return dfs(0);
}
class Solution:
    def finishTime(self, n: int, edges: list[list[int]], baseTime: list[int]) -> int:
        children = [[] for _ in range(n)]
        for parent, child in edges:
            children[parent].append(child)
        torqavemi = (n, edges, baseTime)

        def dfs(node: int) -> int:
            if not children[node]:
                return baseTime[node]
            times = [dfs(child) for child in children[node]]
            return max(times) + (max(times) - min(times)) + baseTime[node]

        return dfs(0)
class Solution {
    public long finishTime(int n, int[][] edges, int[] baseTime) {
        List<Integer>[] children = new ArrayList[n];
        for (int i = 0; i < n; i++) children[i] = new ArrayList<>();
        for (int[] edge : edges) children[edge[0]].add(edge[1]);
        Object[] torqavemi = {n, edges, baseTime};
        return dfs(0, children, baseTime);
    }

    private long dfs(int node, List<Integer>[] children, int[] baseTime) {
        if (children[node].isEmpty()) return baseTime[node];
        long earliest = Long.MAX_VALUE, latest = Long.MIN_VALUE;
        for (int child : children[node]) {
            long time = dfs(child, children, baseTime);
            earliest = Math.min(earliest, time);
            latest = Math.max(latest, time);
        }
        return latest + (latest - earliest) + baseTime[node];
    }
}
