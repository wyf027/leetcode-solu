子数组最大平均数 II

Maximum Average Subarray II

在所有长度至少为 k 的连续子数组中，找到能达到的最大平均值。先读懂目标，再进入下方实验室观察“候选平均值”如何被逐轮逼近。

Problem

题意转述

给定一个整数数组 nums 和整数 k。请选择一个连续、非空且长度不少于 k 的子数组，使其算术平均值尽可能大，并返回这个最大平均值。

结果是浮点数；与正确答案的绝对误差或相对误差不超过 10-5 时可接受。
double findMaxAverage(int[] nums, int k)

约束

  • 1 ≤ k ≤ nums.length ≤ 104
  • -104 ≤ nums[i] ≤ 104
  • 答案按浮点误差标准判定。

Complete Solution

二分答案 + 前缀最小值判定

核心洞察

直接枚举所有连续子数组需要二次方时间。换一个问题：给定候选平均值 x，是否存在长度至少为 k 的子数组，其平均值不小于 x？

把每个元素都减去 x。对任意子数组，平均值不小于 x，等价于变换后该子数组的和不小于零：

sum(nums[l..r]) / (r-l+1) ≥ x ⇔ sum(nums[i] − x, i=l..r) ≥ 0

于是“平均值问题”变成“是否存在长度至少为 k、和非负的子数组”。若 x 可行，所有更小的候选值也可行，形成单调性，因此可在 [min(nums), max(nums)] 上二分。

完整过程

  1. 令 low = min(nums)，high = max(nums)。
  2. 取 mid = (low + high) / 2，将每项视作 nums[i] - mid。
  3. 先累计前 k 项。如果和非负，长度为 k 的前缀已经证明 mid 可行。
  4. 继续向右扩展。维护完整前缀和 sum、落后 k 位的前缀和 prevSum，以及截至当前位置可被减去的最小前缀 minPrev。
  5. 若 sum - minPrev ≥ 0，就找到了长度至少为 k 的非负和子数组，候选值可行；扫描结束仍未找到则不可行。
  6. 可行则令 low = mid，不可行则令 high = mid；重复到区间宽度不超过 10-5，返回 low。

正确性

等价变换
固定 x 后，子数组平均值 ≥ x 与变换后子数组和 ≥ 0 完全等价。
覆盖所有长度
扫描到右端点 r 时，只减去位置不晚于 r-k 的前缀，因此所得子数组长度至少为 k。
最优前缀
固定右端点时，减去允许范围内最小的前缀会得到最大区间和；若它仍为负，其他合法左端点也不会成功。

引理 1：check(x) 为真，当且仅当存在平均值至少为 x 的合法子数组。

目标条件等价于存在长度至少为 k 的变换后非负和子数组。扫描对每个右端点维护全部合法左边界之前的最小前缀；它成功时得到的区间合法且和非负。反过来，若某个合法区间存在，扫描到其右端点时，维护的最小前缀不大于该区间左边界之前的前缀，所以必能报告成功。

引理 2：可行性关于候选值单调。

若 x 可行，同一子数组对任意 y ≤ x 仍满足平均值至少为 y，所以所有更小值也可行。

定理：算法返回允许误差内的最大平均值。

初始区间包含最优值。依据两个引理，每轮二分都保留包含可行临界值的半区间。停止时区间宽度不超过 10-5，可行下界与真实最优值的差也不超过该宽度，故返回值满足精度要求。

边界情况

  • k = 1：答案是最大元素，通用算法仍成立。
  • k = nums.length：只有整个数组可选。
  • 全为负数：不要错误地把下界设为零。
  • 所有元素相等：初始区间宽度为零，可直接返回该值。
  • 使用双精度累计；判定时比较零，不在中途四舍五入。

复杂度

每次判定为 O(n)。二分轮数为 O(log((max-min)/ε))，总时间为 O(n log((max-min)/ε))；额外空间为 O(1)。

替代方案

可基于前缀和，把问题转化为满足横坐标距离至少为 k 的最大斜率，并用凸包维护候选点。它能达到 O(n) 或 O(n log n) 的结构化解法，但实现和边界更复杂；本题允许误差时，二分答案通常更稳健。

Java 
class Solution {
    public double findMaxAverage(int[] nums, int k) {
        double low = nums[0], high = nums[0];
        for (int num : nums) {
            low = Math.min(low, num);
            high = Math.max(high, num);
        }

        while (high - low > 1e-5) {
            double mid = low + (high - low) / 2.0;
            if (canReach(nums, k, mid)) low = mid;
            else high = mid;
        }
        return low;
    }

    private boolean canReach(int[] nums, int k, double target) {
        double sum = 0.0;
        for (int i = 0; i < k; i++) sum += nums[i] - target;
        if (sum >= 0.0) return true;

        double prevSum = 0.0, minPrev = 0.0;
        for (int i = k; i < nums.length; i++) {
            sum += nums[i] - target;
            prevSum += nums[i - k] - target;
            minPrev = Math.min(minPrev, prevSum);
            if (sum - minPrev >= 0.0) return true;
        }
        return false;
    }
}

var findMaxAverage = function(nums, k) {
    let low = Math.min(...nums);
    let high = Math.max(...nums);

    const canReach = (target) => {
        let sum = 0;
        for (let i = 0; i < k; i++) sum += nums[i] - target;
        if (sum >= 0) return true;

        let prevSum = 0;
        let minPrev = 0;
        for (let i = k; i < nums.length; i++) {
            sum += nums[i] - target;
            prevSum += nums[i - k] - target;
            minPrev = Math.min(minPrev, prevSum);
            if (sum - minPrev >= 0) return true;
        }
        return false;
    };

    while (high - low > 1e-5) {
        const mid = low + (high - low) / 2;
        if (canReach(mid)) low = mid;
        else high = mid;
    }
    return low;
};

from typing import List


class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        low = float(min(nums))
        high = float(max(nums))

        def can_reach(target: float) -> bool:
            total = sum(nums[i] - target for i in range(k))
            if total >= 0.0:
                return True

            previous = 0.0
            min_previous = 0.0
            for i in range(k, len(nums)):
                total += nums[i] - target
                previous += nums[i - k] - target
                min_previous = min(min_previous, previous)
                if total - min_previous >= 0.0:
                    return True
            return False

        while high - low > 1e-5:
            mid = low + (high - low) / 2.0
            if can_reach(mid):
                low = mid
            else:
                high = mid
        return low

class Solution {
public:
    double findMaxAverage(vector<int>& nums, int k) {
        double low = *min_element(nums.begin(), nums.end());
        double high = *max_element(nums.begin(), nums.end());

        auto canReach = [&](double target) {
            double sum = 0.0;
            for (int i = 0; i < k; ++i) sum += nums[i] - target;
            if (sum >= 0.0) return true;

            double previous = 0.0;
            double minPrevious = 0.0;
            for (int i = k; i < static_cast<int>(nums.size()); ++i) {
                sum += nums[i] - target;
                previous += nums[i - k] - target;
                minPrevious = min(minPrevious, previous);
                if (sum - minPrevious >= 0.0) return true;
            }
            return false;
        };

        while (high - low > 1e-5) {
            double mid = low + (high - low) / 2.0;
            if (canReach(mid)) low = mid;
            else high = mid;
        }
        return low;
    }
};

面试追问

  • 为什么边界是最小值和最大值？ 任意子数组平均值不可能超出其中元素的最小、最大值。
  • 为什么只保存最小前缀？ 固定右端点时，要使区间和最大，应减去允许范围内最小的左侧前缀。
  • 固定二分 60 次可以吗？ 可以。当前值域下 60 次远超 10-5 的精度需求。
  • 如何返回具体子数组？ 在最终判定中同步记录最小前缀的位置，并在成功时保存左右端点。

常见错误

  • 只检查长度恰好为 k 的窗口，漏掉更长子数组。
  • 更新 minPrev 的时机错一位，使实际长度小于 k。
  • 全负数时把 low 初始化为零。
  • 在判定中反复除以长度，既多余又更易引入误差。
  • 混淆可行下界与不可行上界的语义。
