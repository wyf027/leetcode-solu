在网格图中访问一个格子的最少时间

格子有开放时间，你却不能原地等待。每一步都必须移动——那么最早何时能抵达右下角？

HARD 免费题 矩阵图最短路
↓先读规则，不急着看答案
The rules of time
  • 01从 (0, 0) 出发，初始时刻为 0。
  • 02每秒必须向上下左右移动一步，不能停留。
  • 03进入格子时，当前时间必须不小于它的开放时间。
01 / 题目

带着时间门槛穿过网格

函数签名：minimumTime(grid: integer[][]) → integer

准确转述

给定一个 m × n 非负整数矩阵。grid[r][c] 是进入格子 (r,c) 的最早时刻。你在时刻 0 位于左上角；每秒必须向四邻格移动，且不能原地等待。

返回最早到达右下角的时刻；若第一步就无处可去，返回 -1。

别忽略“必须移动”

时间门还没开时，你不能站着等。若已经拥有一条可来回走的边，可以用两步往返消耗时间；这会让可达时刻带有奇偶性。

示例 1

输入：grid = [[0,1,3,2],
        [5,1,2,5],
        [4,3,8,6]]
输出：7
解释：可在 0→1→2→3→4→5→6→7 的
每个时刻持续移动，并于时刻 7 到达 (2,3)。

示例 2

输入：grid = [[0,2,4],
        [3,2,1],
        [1,0,4]]
输出：-1
解释：时刻 1 时，起点的两个相邻格都未开放，
又不能原地等待，因此无法出发。

约束

  • m == grid.length，n == grid[i].length
  • 2 ≤ m, n ≤ 1000
  • 4 ≤ m × n ≤ 10⁵
  • 0 ≤ grid[i][j] ≤ 10⁵
  • grid[0][0] == 0

03 / 解锁答案

准备好把直觉变成算法了吗？

题解默认收起。建议先在上面的时间网格里走几步，再展开完整推导。

Dijkstra + 奇偶时间修正

把每个格子看作图节点，每次移动是一条耗时 1 的边。由于进入时间还受格子的开放门槛限制，边的实际到达时间依赖当前时刻；但“越早到达不会更差”，因此仍可按最早到达时间使用 Dijkstra。

01

先判第一步

若 grid[0][1] > 1 且 grid[1][0] > 1，时刻 1 无处可走，直接返回 -1。

02

用往返等待

离开起点后，总能沿已走过的边往返两步。因此可等待的增量只能是偶数。

03

按最早时间扩展

优先队列每次取出最早可达格子，修正邻格时间并松弛，直到弹出终点。

核心公式

当前格子的最早时刻是 t，直接走到邻格的候选是 next = t + 1，邻格开放时间是 g。

  • 若 next ≥ g：直接在 next 到达。
  • 若 next < g：最小合法时刻必须不小于 g，并与 next 奇偶性相同，所以
    next = g + ((g - next) mod 2)。

完整过程

  1. 检查起点的两个邻格；若时刻 1 都不能进入，返回 -1。
  2. 建立距离矩阵 dist，起点为 0，其余为无穷大。
  3. 将 (0,0,0) 放入最小堆。
  4. 弹出最早状态；过期状态跳过，终点状态直接返回。
  5. 遍历四邻格，用奇偶公式算候选时刻，若更小则更新并入堆。

边界

  • 矩阵至少为 2 × 2，因此起点的右、下邻格都存在。
  • 第一步是唯一不能借助“已走过边”往返等待的时刻。
  • 门槛为 0 或已开放时，无需奇偶修正。
  • 堆中可能存在旧状态，必须用 time != dist[r][c] 丢弃。

正确性证明

  1. 奇偶修正给出最早合法到达时刻。 从当前格出发的第一次尝试发生在 t+1。每次沿已走过的边往返增加 2 秒，因此所有可选到达时刻与 t+1 同奇偶。公式恰好选出不小于门槛的最小同奇偶时刻。
  2. 松弛不会遗漏更优路径。 对任一已知最早到达时刻，步骤一计算每个邻格经该节点可得到的最早时刻；所有路径的最后一步都属于某次这样的松弛。
  3. 弹出节点时其距离已最优。 转移后的到达时刻严格大于当前时刻，满足非负、时间单调的最短路条件。Dijkstra 每次弹出的未过期最小距离不可能再被未处理路径改小。
  4. 终点答案正确。 因此终点第一次以未过期状态弹出时，其时刻是所有合法路径中的最小值；若无法出发则前置判断返回 -1。

复杂度

时间：O(mn log(mn))，每个格子至多被有效确认一次，堆操作为对数级。

空间：O(mn)，用于距离矩阵与优先队列。

替代方案与取舍

  • 普通 BFS：不适用。每次移动虽耗时 1，但等待门槛让到达时间不再只由步数决定。
  • SPFA：可以表达松弛，但缺乏本题所需的稳定复杂度保证，最坏情况明显更差。
  • 二分答案 + 可达性：奇偶与“不能停留”会让判定复杂化，而且通常不比一次 Dijkstra 更简洁。

Java PriorityQueue 
import java.util.*;

class Solution {
    public int minimumTime(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        if (grid[0][1] > 1 && grid[1][0] > 1) return -1;

        int[][] dist = new int[m][n];
        for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
        dist[0][0] = 0;

        PriorityQueue<int[]> pq =
            new PriorityQueue<>(Comparator.comparingInt(a -> a[0]));
        pq.offer(new int[]{0, 0, 0});
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        while (!pq.isEmpty()) {
            int[] cur = pq.poll();
            int time = cur[0], r = cur[1], c = cur[2];
            if (time != dist[r][c]) continue;
            if (r == m - 1 && c == n - 1) return time;

            for (int[] d : dirs) {
                int nr = r + d[0], nc = c + d[1];
                if (nr < 0 || nr == m || nc < 0 || nc == n) continue;

                int next = time + 1;
                int gate = grid[nr][nc];
                if (next < gate) next = gate + (gate - next) % 2;

                if (next < dist[nr][nc]) {
                    dist[nr][nc] = next;
                    pq.offer(new int[]{next, nr, nc});
                }
            }
        }
        return -1;
    }
}
JavaScript 原生最小堆 
class MinHeap {
    constructor() { this.a = []; }
    push(x) {
        const a = this.a;
        a.push(x);
        let i = a.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (a[p][0] <= x[0]) break;
            a[i] = a[p];
            i = p;
        }
        a[i] = x;
    }
    pop() {
        const a = this.a, root = a[0], last = a.pop();
        if (a.length) {
            let i = 0;
            while (true) {
                let child = i * 2 + 1;
                if (child >= a.length) break;
                if (child + 1 < a.length && a[child + 1][0] < a[child][0]) child++;
                if (a[child][0] >= last[0]) break;
                a[i] = a[child];
                i = child;
            }
            a[i] = last;
        }
        return root;
    }
    get size() { return this.a.length; }
}

 * @param {number[][]} grid

var minimumTime = function(grid) {
    const m = grid.length, n = grid[0].length;
    if (grid[0][1] > 1 && grid[1][0] > 1) return -1;

    const dist = Array.from({ length: m }, () => Array(n).fill(Infinity));
    dist[0][0] = 0;
    const heap = new MinHeap();
    heap.push([0, 0, 0]);
    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];

    while (heap.size) {
        const [time, r, c] = heap.pop();
        if (time !== dist[r][c]) continue;
        if (r === m - 1 && c === n - 1) return time;

        for (const [dr, dc] of dirs) {
            const nr = r + dr, nc = c + dc;
            if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;

            let next = time + 1;
            const gate = grid[nr][nc];
            if (next < gate) next = gate + (gate - next) % 2;

            if (next < dist[nr][nc]) {
                dist[nr][nc] = next;
                heap.push([next, nr, nc]);
            }
        }
    }
    return -1;
};
Python heapq 
from heapq import heappop, heappush
from math import inf
from typing import List


class Solution:
    def minimumTime(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        if grid[0][1] > 1 and grid[1][0] > 1:
            return -1

        dist = [[inf] * n for _ in range(m)]
        dist[0][0] = 0
        heap = [(0, 0, 0)]
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

        while heap:
            time, r, c = heappop(heap)
            if time != dist[r][c]:
                continue
            if r == m - 1 and c == n - 1:
                return time

            for dr, dc in directions:
                nr, nc = r + dr, c + dc
                if not (0 <= nr < m and 0 <= nc < n):
                    continue

                nxt = time + 1
                gate = grid[nr][nc]
                if nxt < gate:
                    nxt = gate + (gate - nxt) % 2

                if nxt < dist[nr][nc]:
                    dist[nr][nc] = nxt
                    heappush(heap, (nxt, nr, nc))

        return -1
C++ priority_queue 
class Solution {
public:
    int minimumTime(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        if (grid[0][1] > 1 && grid[1][0] > 1) return -1;

        const int INF = numeric_limits<int>::max();
        vector<vector<int>> dist(m, vector<int>(n, INF));
        dist[0][0] = 0;

        using State = array<int, 3>;
        priority_queue<State, vector<State>, greater<State>> pq;
        pq.push({0, 0, 0});
        int dirs[5] = {1, 0, -1, 0, 1};

        while (!pq.empty()) {
            auto [time, r, c] = pq.top();
            pq.pop();
            if (time != dist[r][c]) continue;
            if (r == m - 1 && c == n - 1) return time;

            for (int i = 0; i < 4; ++i) {
                int nr = r + dirs[i], nc = c + dirs[i + 1];
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;

                int next = time + 1;
                int gate = grid[nr][nc];
                if (next < gate) next = gate + (gate - next) % 2;

                if (next < dist[nr][nc]) {
                    dist[nr][nc] = next;
                    pq.push({next, nr, nc});
                }
            }
        }
        return -1;
    }
};

面试追问

  • 为什么只需特判起点？ 一旦成功走出第一步，就已经拥有一条可沿原路往返的边。
  • 为什么门槛越大不一定恰好在门槛时刻进入？ 可达时刻的奇偶性由下一步时刻决定，必要时要再多等 1 秒。
  • 若允许原地等待呢？ 去掉起点特判，转移直接取 max(t+1, g)。
  • 能否提前结束？ 终点从最小堆以未过期状态弹出时即可返回。

常见错误

  • 把等待写成 max(t+1, g)，忽略不能原地停留。
  • 奇偶公式写反，错误地检查 g - t 而不是 g - (t+1)。
  • 漏掉第一步不可达判断，凭空假设起点也能往返。
  • 使用普通队列，无法保证按最早到达时刻扩展。
  • 不跳过堆中的过期状态，导致重复工作。
