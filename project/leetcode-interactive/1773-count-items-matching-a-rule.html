Lookup rule / 检索规则

统计匹配检索规则的
物品数量

每件物品都有类型、颜色和名称。给定一个检索字段与目标值，数一数究竟有多少件物品满足这条规则。

Problem

题目描述

countMatches(items, ruleKey, ruleValue)

给定数组 items，其中 items[i] = [typeᵢ, colorᵢ, nameᵢ]，依次表示第 i 件物品的类型、颜色与名称。另给出字符串 ruleKey 和 ruleValue 表示一条检索规则。

当一件物品在规则指定的字段上等于 ruleValue 时，它与规则匹配：

  • ruleKey == "type" 且 typeᵢ == ruleValue；
  • ruleKey == "color" 且 colorᵢ == ruleValue；
  • ruleKey == "name" 且 nameᵢ == ruleValue。

返回：与给定检索规则匹配的物品数量。

Examples

官方示例

完整参数形式

Example 01 · 按颜色检索

输入：
items = [["phone","blue","pixel"],
         ["computer","silver","lenovo"],
         ["phone","gold","iphone"]],
ruleKey = "color",
ruleValue = "silver"

输出：1

只有 ["computer","silver","lenovo"] 的颜色为 silver。

Example 02 · 按类型检索

输入：
items = [["phone","blue","pixel"],
         ["computer","silver","phone"],
         ["phone","gold","iphone"]],
ruleKey = "type",
ruleValue = "phone"

输出：2

第一件与第三件的类型是 phone；第二件的名称虽然是 phone，但类型不是。

Constraints

约束

1 <= items.length <= 10⁴
1 <= typeᵢ.length, colorᵢ.length, nameᵢ.length, ruleValue.length <= 10
ruleKey 只可能是 "type"、"color" 或 "name"
所有字符串仅由小写英文字母组成

题解

Solution

题解：把规则字段映射为下标

一次遍历

核心洞察

每件物品的三个字段顺序固定：type → 0、color → 1、name → 2。先把 ruleKey 转为一个下标 index，后续所有物品都只需比较 item[index] 与 ruleValue。

完整过程

  1. 根据 ruleKey 确定目标列下标。
  2. 初始化计数器 count = 0。
  3. 依次访问每件物品；若目标列的值等于 ruleValue，计数加一。
  4. 遍历结束后返回 count。

正确性说明

字段映射保证 item[index] 恰好是规则指定的属性。遍历处理完前 k 件物品后，count 等于其中匹配规则的物品数：初始时结论显然成立；处理下一件时，仅当它匹配才加一，因此结论继续成立。处理完全部物品后，count 就是所有匹配物品的数量。

边界情况

  • 只有一件物品：直接得到 0 或 1。
  • 所有物品都匹配：结果等于 items.length。
  • 没有物品匹配：保持为 0。
  • 相同文本出现在非规则字段：不能计入，例如按 type 检索时不看 name。

复杂度

设物品数量为 n。每件物品只做一次目标字段比较，因此时间复杂度为 O(n)；只维护下标和计数器，额外空间复杂度为 O(1)。

替代方案

可以直接按 ruleKey 写三段条件，或使用 filter/count 进行函数式计数。它们同样是 O(n)，但映射下标能把“选字段”与“做比较”分开，重复逻辑更少。创建过滤后的新数组可能需要 O(n) 额外空间。

面试追问

  • 为什么不能更快？ 未预处理的数据可能在最后一项才出现匹配，最坏情况必须查看所有物品。
  • 大量查询怎么办？ 可按三个字段分别建立“值 → 数量”的哈希索引，以额外空间换取近似 O(1) 查询。
  • 规则扩展为多个条件？ 将多个字段下标与目标值组成条件列表，对每件物品执行 AND/OR 判断。

常见错误

  • 把三个字段都与 ruleValue 比较，忽略了 ruleKey。
  • 误写字段顺序，例如把 color 映射到下标 2。
  • 用包含关系代替严格相等。
  • 返回匹配数组而不是匹配数量。
Java
class Solution {
    public int countMatches(List<List<String>> items,
                            String ruleKey,
                            String ruleValue) {
        int index;
        if (ruleKey.equals("type")) {
            index = 0;
        } else if (ruleKey.equals("color")) {
            index = 1;
        } else {
            index = 2;
        }

        int count = 0;
        for (List<String> item : items) {
            if (item.get(index).equals(ruleValue)) {
                count++;
            }
        }
        return count;
    }
}

var countMatches = function(items, ruleKey, ruleValue) {
    const index = {
        type: 0,
        color: 1,
        name: 2
    }[ruleKey];

    let count = 0;
    for (const item of items) {
        if (item[index] === ruleValue) {
            count++;
        }
    }
    return count;
};
