题号 1277非会员题函数 countSquares(matrix)
01 / Problem

先把问题说准确

给定一个由 0 和 1 组成的 m × n 矩阵 matrix，返回其中元素全部为 1 的正方形子矩阵总数。不同位置、不同边长的正方形分别计数。

函数参数

countSquares(matrix: integer[][]): integer
  • 1 ≤ matrix.length ≤ 300
  • 1 ≤ matrix[0].length ≤ 300
  • matrix[i][j] 只可能是 0 或 1
阅读提示

“总数”不等于最大面积

一个边长为 3 的全 1 正方形内部，同时还包含多个边长为 1 和 2 的正方形；题目要求把它们全部计入。

先尝试观察：当右下角落在某个格子时，最多能形成多大的正方形？

边长 1、2、3 的正方形分别有 10、4、1 个，总计 15。

Dynamic Programming

动态规划：让每个格子报告自己的贡献

核心洞察

设 dp[i][j] 为“以 (i,j) 为右下角的全 1 正方形的最大边长”。这个最大边长同时也是该格贡献的正方形个数：若最大边长为 3，它就对应边长 1、2、3 各一个。

状态转移

matrix[i][j] == 0 → dp[i][j] = 0 matrix[i][j] == 1 → dp[i][j] = 1 + min( dp[i-1][j], dp[i][j-1], dp[i-1][j-1] )

第一行或第一列若为 1，只能形成边长 1 的正方形。最终答案是所有 dp[i][j] 之和。

完整过程

  1. 1
    按行扫描
    从左上到右下遍历矩阵。
  2. 2
    跳过 0
    当前值为 0 时，任何以它为右下角的全 1 正方形都不存在。
  3. 3
    查看三个邻居
    上、左、左上能共同支撑的尺寸，由三者最小值决定。
  4. 4
    累加贡献
    把当前 dp 值加入答案；扫描结束即得到总数。

正确性证明

归纳说明。 对第一行和第一列，状态显然正确。假设当前格之前的状态均正确：若当前格为 0，贡献必为 0；若为 1，想扩展出边长大于 1 的正方形，上、左、左上三个方向必须都能覆盖少一层的正方形，因此最大可扩展边长恰好是三者最小值加 1。于是 dp[i][j] 准确计数所有以当前格为右下角的正方形。每个正方形有唯一右下角，对全部状态求和既无遗漏也无重复。

边界情况

  • 只有一个格子：直接返回该格的 0 或 1。
  • 全为 0：所有状态均为 0。
  • 全为 1：会同时计入所有位置与尺寸。
  • 单行或单列：答案等于其中 1 的个数。
  • 矩阵最大为 300 × 300，答案使用 32 位整数仍足够。
时间复杂度
O(mn)
每个格子只处理一次
额外空间
O(n)
使用一维滚动数组

class Solution {
    public int countSquares(int[][] matrix) {
        int rows = matrix.length;
        int cols = matrix[0].length;
        int[] dp = new int[cols + 1];
        int answer = 0;

        for (int i = 1; i <= rows; i++) {
            int diagonal = 0;
            for (int j = 1; j <= cols; j++) {
                int top = dp[j];
                if (matrix[i - 1][j - 1] == 1) {
                    dp[j] = 1 + Math.min(diagonal,
                        Math.min(dp[j], dp[j - 1]));
                    answer += dp[j];
                } else {
                    dp[j] = 0;
                }
                diagonal = top;
            }
        }
        return answer;
    }
}

替代方案与面试追问

先计算二维前缀和，再枚举每个左上角与边长，以 O(1) 判断区域和是否等于面积。实现直观，但枚举所有正方形需要 O(mn · min(m,n)) 时间，慢于动态规划。
每个状态只依赖当前行左侧、上一行同列与上一行左上。用一维数组保存“上一行/当前行”的复用值，再用单独变量保存被覆盖前的左上值即可。
正方形的三邻居最小值转移不再适用。常见做法是逐行维护柱状图高度，并用单调栈统计以每行为底的全 1 子矩形。

常见错误

  • 只返回最大的边长或最大面积，而不是所有正方形数量。
  • 当前格为 1 时只加 1，遗漏以该格为右下角的更大正方形。
  • 滚动数组更新后丢失左上角旧值；必须先保存 top，再在循环末更新 diagonal。
  • 遇到 0 时没有把复用的 dp[j] 清零，导致上一行状态泄漏。
  • 把三个邻居取最大值；任何一个方向不足都会阻止正方形扩展，所以必须取最小值。
