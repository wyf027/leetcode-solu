使数组和能被 P 整除

先理解“该删掉哪一种余数”，再用前缀和与哈希表把寻找最短连续子数组压缩到一次扫描。

中等数组哈希表前缀和非付费题

题目说明

给定一个正整数数组 nums 和正整数 p。请移除一个最短的连续子数组（允许为空），使剩余元素之和能被 p 整除。不能移除整个数组。

返回值：满足条件的最短移除长度；如果不存在合法方案，返回 -1。

函数参数：minSubarray(nums: integer[], p: integer) → integer

官方示例

示例 1

输入：nums = [3,1,4,2], p = 6
输出：1

总和为 10。移除 [4] 后剩余和为 6。

示例 2

输入：nums = [6,3,5,2], p = 9
输出：2

无法只移除一个元素；移除 [5,2] 后剩下 [6,3]，和为 9。

示例 3

输入：nums = [1,2,3], p = 3
输出：0

数组和为 6，已经能被 3 整除，无需移除。

示例 4

输入：nums = [1,2,3], p = 7
输出：-1

唯一能删去的目标是整个数组，但题目禁止这样做，因此无解。

示例 5

输入：nums = [1000000000,1000000000,1000000000], p = 3
输出：0

总和本身可以被 3 整除。

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁹
  • 1 ≤ p ≤ 10⁹

题解：前缀余数 + 最新下标

01 · 转换目标

删去的和应该“带走”总余数

设总和对 p 的余数为 need。剩余和要被整除，删去子数组的和对 p 的余数必须同样是 need。

02 · 用两个前缀表示区间

区间和来自前缀差

扫描到右端点 i，当前前缀余数是 cur。若旧前缀余数为 target，就需要 (cur - target + p) % p = need。

03 · 反推要找什么

target = (cur - need + p) % p

只要哈希表中存在这个余数，其记录下标之后到 i 之间就是合法删除区间。

04 · 为什么存最新下标

同余数越靠右，区间越短

固定右端点 i 时，要让 i - j 最小，就应使用最大的旧下标 j，因此每次覆盖为当前最新下标。

完整过程

  1. 计算 need = sum(nums) % p。若 need == 0，无需删除，直接返回 0。
  2. 初始化映射 last = {0: -1}。它表示扫描前的空前缀余数为 0，下标为 -1。
  3. 从左到右维护当前前缀余数 cur，计算 target = (cur - need + p) % p。
  4. 若 target 已出现，用 i - last[target] 更新最短长度。
  5. 把 last[cur] 更新为 i，确保后续获得同余数的最近位置。
  6. 扫描结束后，如果最短长度仍等于数组长度，说明唯一候选是删除整个数组，返回 -1；否则返回最短长度。
(prefix[i] − prefix[j]) mod p = need　⇒　prefix[j] mod p = (cur − need + p) mod p

正确性证明

  1. 必要性：设总和为 S，删去区间和为 X。若剩余和可被 p 整除，则 (S-X) mod p = 0，所以 X mod p = S mod p = need。
  2. 候选完备：任意以 i 结尾且余数为 need 的区间，都对应一个余数为 target 的旧前缀。扫描到 i 时，映射会提供该余数的某个下标，因此算法不会漏掉可行的右端点。
  3. 局部最优：对固定的 i，映射保留目标余数的最大下标 j，所得 i-j 是以 i 结尾的最短合法区间。
  4. 全局最优：算法检查所有右端点并取局部最优中的最小值，因此得到全局最短合法区间；最终排除长度为 n 的非法整数组删除。

边界情况

  • 总和已经能被 p 整除：返回 0。
  • 只有删除整个数组才能满足：返回 -1。
  • p = 1：任何整数都能被 1 整除，返回 0。
  • 元素和可能远超 32 位：Java 使用 long 求总余数；JavaScript 的最大总和不超过 10¹⁴，仍在安全整数范围内；C++ 使用 long long。
  • 减法取模可能为负：统一写成 (cur - need + p) % p。

复杂度

时间复杂度：O(n)，两次线性扫描（求总余数与寻找区间）。空间复杂度：O(min(n, p))，哈希表最多保存出现过的不同前缀余数。

四种语言完整代码

Java官方签名 · 可提交
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int minSubarray(int[] nums, int p) {
        long total = 0;
        for (int num : nums) {
            total += num;
        }

        int need = (int) (total % p);
        if (need == 0) return 0;

        Map<Integer, Integer> last = new HashMap<>();
        last.put(0, -1);
        int prefix = 0;
        int answer = nums.length;

        for (int i = 0; i < nums.length; i++) {
            prefix = (int) (((long) prefix + nums[i]) % p);
            int target = (prefix - need + p) % p;
            if (last.containsKey(target)) {
                answer = Math.min(answer, i - last.get(target));
            }
            last.put(prefix, i);
        }

        return answer == nums.length ? -1 : answer;
    }
}

/**
 * @param {number[]} nums
 * @param {number} p
 * @return {number}
 */
var minSubarray = function(nums, p) {
    let totalMod = 0;
    for (const num of nums) {
        totalMod = (totalMod + num) % p;
    }

    const need = totalMod;
    if (need === 0) return 0;

    const last = new Map([[0, -1]]);
    let prefix = 0;
    let answer = nums.length;

    for (let i = 0; i < nums.length; i++) {
        prefix = (prefix + nums[i]) % p;
        const target = (prefix - need + p) % p;
        if (last.has(target)) {
            answer = Math.min(answer, i - last.get(target));
        }
        last.set(prefix, i);
    }

    return answer === nums.length ? -1 : answer;
};
Python 3官方签名 · 可提交
from typing import List


class Solution:
    def minSubarray(self, nums: List[int], p: int) -> int:
        need = sum(nums) % p
        if need == 0:
            return 0

        last = {0: -1}
        prefix = 0
        answer = len(nums)

        for i, num in enumerate(nums):
            prefix = (prefix + num) % p
            target = (prefix - need) % p
            if target in last:
                answer = min(answer, i - last[target])
            last[prefix] = i

        return -1 if answer == len(nums) else answer
C++官方签名 · 可提交
#include <algorithm>
#include <unordered_map>
#include <vector>
using namespace std;

class Solution {
public:
    int minSubarray(vector<int>& nums, int p) {
        long long total = 0;
        for (int num : nums) {
            total += num;
        }

        int need = static_cast<int>(total % p);
        if (need == 0) return 0;

        unordered_map<int, int> last;
        last[0] = -1;
        int prefix = 0;
        int answer = nums.size();

        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            prefix = static_cast<int>((static_cast<long long>(prefix) + nums[i]) % p);
            int target = (prefix - need + p) % p;
            auto it = last.find(target);
            if (it != last.end()) {
                answer = min(answer, i - it->second);
            }
            last[prefix] = i;
        }

        return answer == static_cast<int>(nums.size()) ? -1 : answer;
    }
};

替代方案

方案时间评价
枚举所有子数组O(n²)直观但无法应对 10⁵ 数据规模。
前缀余数分组后搜索通常 O(n log n)可为每种余数保存有序下标，但结构更复杂。
前缀余数 + 最新下标O(n)一次扫描直接取得每个右端点的最短候选，是本题最佳实践。

面试追问

  • 为什么不是保存最早下标？ 本题求最短区间；固定右端点时，旧下标越晚，区间越短。若改求最长，才保存最早下标。
  • 为什么先查询再更新？ 可以避免当前下标覆盖旧信息；本题 need != 0 时不会误得长度 0，但“查询后更新”更直接表达区间左前缀必须早于右端点。
  • 若数组允许负数呢？ 思路不变，但多种语言的负数取模规则不同，需规范化为 ((x % p) + p) % p。
  • 能否返回区间端点？ 更新答案时同时保存 last[target] + 1 与 i 即可。

常见错误

  • 把目标余数写成 need - cur；正确反推是 cur - need。
  • 没有初始化 {0: -1}，从而漏掉从下标 0 开始的删除区间。
  • 保存余数的最早下标，得到的反而是更长区间。
  • 允许答案等于 nums.length，违反“不能删除整个数组”。
  • Java/C++ 直接用 32 位整数累加总和导致溢出。
