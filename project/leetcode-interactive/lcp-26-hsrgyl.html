导航装置

导航装置集合为每个节点生成“距离指纹”。把二叉树视为最大度数 3 的无根树后，关键在分叉：若多个尚未被装置覆盖的分支在同一点汇合，必须在其中若干分支补装置。

题意

在若干景点放置装置。每个景点收到的列表是它到所有装置的距离；要求任意两个景点的列表不同，求最少装置数。树有 2..50000 个节点，节点编号互异。

root=[1,2,null,3,4]
输出：2；可在 1、3 或 1、4 或 3、4 放置。

INTERACTIVE / 分叉覆盖

从任意三度节点做后序贪心

后序状态 has

表示该方向的后代中，已经存在能够参与区分的导航装置。叶子返回 false；单链原样上传；分叉节点处理后返回 true。

SOLUTION / 默认隐藏

无根树后序贪心

核心性质

树外装置对同一子树内节点的距离都多出相同常数，可等价投影到子树入口。单链只需延续状态；真正产生歧义的是分叉。

贪心

在分叉节点统计没有装置的子分支数 no。至多允许一个空分支，其余 no-1 个各补一个装置。若整棵无根树没有度数 3 的节点，它就是一条路径，只需 1 个装置。

构图和后序遍历均为 O(n) 时间、O(n) 空间。使用显式栈，避免 50000 深度的递归栈风险。 

import java.util.*;
class Solution {
 public int navigation(TreeNode root) {
  Map<TreeNode,List<TreeNode>> g=new HashMap<>();ArrayDeque<TreeNode> build=new ArrayDeque<>();build.push(root);
  while(!build.isEmpty()){TreeNode x=build.pop();g.computeIfAbsent(x,k->new ArrayList<>());if(x.left!=null){g.get(x).add(x.left);g.computeIfAbsent(x.left,k->new ArrayList<>()).add(x);build.push(x.left);}if(x.right!=null){g.get(x).add(x.right);g.computeIfAbsent(x.right,k->new ArrayList<>()).add(x);build.push(x.right);}}
  TreeNode start=null;for(TreeNode x:g.keySet())if(g.get(x).size()==3){start=x;break;}if(start==null)return 1;
  Map<TreeNode,TreeNode> parent=new HashMap<>();List<TreeNode> order=new ArrayList<>();ArrayDeque<TreeNode> st=new ArrayDeque<>();st.push(start);parent.put(start,null);
  while(!st.isEmpty()){TreeNode x=st.pop();order.add(x);for(TreeNode y:g.get(x))if(y!=parent.get(x)){parent.put(y,x);st.push(y);}}
  Map<TreeNode,Boolean> has=new HashMap<>();int ans=0;for(int i=order.size()-1;i>=0;i--){TreeNode x=order.get(i);int children=0,empty=0;boolean any=false;for(TreeNode y:g.get(x))if(y!=parent.get(x)){children++;boolean h=has.get(y);any|=h;if(!h)empty++;}if(children==0)has.put(x,false);else if(children==1)has.put(x,any);else{ans+=Math.max(0,empty-1);has.put(x,true);}}return ans;
 }
}

class Solution:
 def navigation(self, root):
  g={};stack=[root]
  while stack:
   x=stack.pop();g.setdefault(x,[])
   for y in (x.left,x.right):
    if y:g[x].append(y);g.setdefault(y,[]).append(x);stack.append(y)
  start=next((x for x in g if len(g[x])==3),None)
  if start is None:return 1
  parent={start:None};order=[];stack=[start]
  while stack:
   x=stack.pop();order.append(x)
   for y in g[x]:
    if y is not parent[x]:parent[y]=x;stack.append(y)
  has={};ans=0
  for x in reversed(order):
   states=[has[y] for y in g[x] if y is not parent[x]]
   if not states:has[x]=False
   elif len(states)==1:has[x]=states[0]
   else:ans+=max(0,states.count(False)-1);has[x]=True
  return ans
