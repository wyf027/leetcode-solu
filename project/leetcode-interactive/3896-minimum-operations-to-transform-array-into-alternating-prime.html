3896. 将数组转换为交替质数数组的最少操作次数

偶数下标需要质数，奇数下标需要非质数。每次只能把一个数加一：把每个位置独立修到它所属的合法集合即可。

题意

给定 nums。下标从 0 开始：偶数下标放质数、奇数下标放非质数。一次操作让任意元素 +1，求最少操作数。

示例：nums = [1, 2, 3, 4]，答案 3。约束：1 ≤ nums.length ≤ 10⁵，1 ≤ nums[i] ≤ 10⁵。

规则速览

偶数下标找不小于当前值的下一个质数
奇数下标若当前是质数，继续加到非质数

2 的下一个数 3 仍是质数，所以奇数位的 2 需要加 2；其他质数加 1 即可。

题解

核心洞察

一次增加只影响当前元素；目标类型由下标确定，位置没有耦合。答案是每个位置最小修复成本的和。预处理每个数字右边最近的质数即可。

完整过程

  1. 埃氏筛标记质数。
  2. 从大到小记录每个数右边最近的质数。
  3. 偶数位加 nextPrime[x] - x；奇数位若 x 非质数为 0，若 x 为 2 为 2，否则为 1。

边界

1 不是质数；2 是奇数位的特殊点。筛上界留出质数间隔余量。

复杂度

筛表 O(M log log M)，空间 O(M)，遍历数组 O(n)。

替代方案

逐元素试除实现短，但重复搜索不如统一预处理稳定。

面试追问

若允许减一，取两侧合法数的最近距离；若规则改为其他周期，只替换每个位置的合法集合。

常见错误

  • 把 1 当成质数。
  • 遗漏奇数位中 2 的特殊性。
  • 筛表没有给上界后的质数留余量。

class Solution {
    public int minOperations(int[] nums) {
        int M = 200010; boolean[] prime = new boolean[M + 1];
        java.util.Arrays.fill(prime, true); prime[0] = prime[1] = false;
        for (int p = 2; p * p &lt;= M; p++) if (prime[p])
            for (int q = p * p; q &lt;= M; q += p) prime[q] = false;
        int[] next = new int[M + 2]; int seen = M;
        for (int x = M; x >= 0; x--) { if (prime[x]) seen = x; next[x] = seen; }
        int ans = 0;
        for (int i = 0; i < nums.length; i++) {
            int x = nums[i];
            if ((i & 1) == 0) ans += next[x] - x;
            else if (prime[x]) ans += x == 2 ? 2 : 1;
        }
        return ans;
    }
}

            if prime[x]: seen = x
            nxt[x] = seen
