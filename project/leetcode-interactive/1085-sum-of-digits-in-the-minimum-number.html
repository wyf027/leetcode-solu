最小元素各数位之和

Sum of Digits in the Minimum Number

先观察规律，再展开题解

题目

给定一个正整数数组 nums，找出其中的最小元素，计算它的十进制各位数字之和。如果这个和是偶数则返回 1，否则返回 0。

函数签名： sumOfDigits(nums: integer[]): integer

示例 1

输入：nums = [34,23,1,24,75,33,54,8]

输出：0

最小值是 1，数位和为 1，是奇数。

示例 2

输入：nums = [99,77,33,66,55]

输出：1

最小值是 33，数位和为 3 + 3 = 6，是偶数。

约束

  • 1 ≤ nums.length ≤ 100
  • 1 ≤ nums[i] ≤ 100

完整题解

核心洞察

结果只由数组最小值决定。一次线性扫描找到最小值，再用取模 % 10 取得末位、用整数除法去掉末位。最后判断数位和的奇偶性。

完整过程

  1. 令 minimum 为数组首元素。
  2. 遍历数组，用更小的元素更新 minimum。
  3. 循环处理 minimum：把末位加入 sum，再去掉末位。
  4. 若 sum % 2 === 0，返回 1；否则返回 0。

正确性说明

扫描结束后，候选值不大于任何已访问元素；遍历覆盖全部元素，因此它就是全局最小值。拆位循环恰好把最小值的每个十进制位加入一次且仅一次，所以 sum 等于其数位和。返回表达式严格按照数位和的奇偶性给出 1 或 0，故算法正确。

边界

  • 数组只有一个元素时，该元素就是最小值。
  • 最小值为一位数时，数位和就是自身。
  • 最小值为 100 时，数位和为 1。
  • 重复最小值不影响答案。

复杂度

设数组长度为 n，最小值有 d 位。时间复杂度 O(n + d)，在本题约束下通常写作 O(n)；额外空间 O(1)。

替代方案

也可把最小值转为字符串并逐字符求和，可读性直观，但会创建字符串；数学拆位保持常数额外空间。

代码实现

class Solution {
    public int sumOfDigits(int[] nums) {
        int minimum = nums[0];
        for (int num : nums) {
            minimum = Math.min(minimum, num);
        }
        int sum = 0;
        while (minimum > 0) {
            sum += minimum % 10;
            minimum /= 10;
        }
        return sum % 2 == 0 ? 1 : 0;
    }
}

var sumOfDigits = function(nums) {
    let minimum = Math.min(...nums);
    let sum = 0;
    while (minimum > 0) {
        sum += minimum % 10;
        minimum = Math.floor(minimum / 10);
    }
    return sum % 2 === 0 ? 1 : 0;
};

面试追问

  • 能否少一次遍历？ 找最小值必须检查每个元素；拆位只处理最终最小值，已经很紧凑。
  • 若允许负数？ 应先明确“数位”是否忽略符号；通常对绝对值拆位。
  • 若数值非常大？ 可用字符串避免整数精度或溢出问题。

常见错误

  • 对数组所有元素求数位和，而不是只处理最小元素。
  • 把返回规则写反：偶数返回 1，奇数返回 0。
  • 拆位时忘记整数除法，导致死循环或小数。
  • 直接修改后还需要使用的最小值，却没有先保存副本。
