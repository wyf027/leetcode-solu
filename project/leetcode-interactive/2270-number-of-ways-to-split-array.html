Number of Ways to Split Array

一条分割线，两段非空数组。
有多少个位置，能让左侧的总和至少与右侧一样大？

01 / 题目

判断每一个合法的切口

给定从下标 0 开始的整数数组 nums，长度为 n。在下标 i 后切开，左段是 nums[0…i]，右段是 nums[i+1…n-1]。如果左段元素之和大于等于右段元素之和，这个分割就有效。

两段都必须非空，因此只能选择 0 ≤ i < n − 1。返回有效分割的个数，返回值为整数。

约束
  • 2 ≤ nums.length ≤ 105
  • −105 ≤ nums[i] ≤ 105

元素可以为负数；相等也算有效分割。

05 / 独立题解

准备好对照思路了吗？

展开后阅读推导、证明和四种语言实现。

核心洞察：总和固定，左和逐项更新

设数组总和为 S。切口在 i 后时，左和 L 是前 i+1 个元素之和，右和直接得到 R = S − L。每向右移动一个切口，只需把新经过的元素加入 L，不必重新求两段的和。

有效条件：L ≥ S − L

切口只走到 n − 2。负数会使左和下降，因此某个切口有效，不代表后面的切口都有效。

完整过程

  1. 遍历整个数组，计算总和 S。
  2. 令 L = 0，答案 ans = 0。
  3. 依次枚举 i = 0…n−2：先执行 L += nums[i]，使左段包含当前元素。
  4. 计算 R = S − L。若 L ≥ R，答案加一。
  5. 处理完全部 n−1 个切口，返回答案。

例如 [10,4,-8,7] 的总和是 13：左和依次变为 10、14、6，右和为 3、−1、7；判断依次为有效、有效、无效，答案为 2。分割线移动时，元素同时从右段转入左段，总和保持不变。

正确性证明

不变式：处理下标 i 的比较之前，L 等于 nums[0…i] 的和。初始从 0 加入 nums[0]，命题成立；下一轮仅加入 nums[i+1]，命题继续成立。左右两段互不相交且覆盖整个数组，所以 S−L 恰为右段之和。

计数正确：每轮仅当 L ≥ S−L 时计数，与题目的合法条件完全一致。循环对所有允许的切口各访问一次，并且不访问末元素之后的位置，因此没有遗漏、重复或空右段，最终计数就是所求答案。

边界与数值类型

  • 长度为 2 时只有一个切口；全为 0 时全部 n−1 个切口有效。
  • 比较必须使用 ≥；即使两侧和都是负数，也按普通数值大小判断。
  • 总和绝对值可达 1010。Java 使用 long，C++ 使用 long long；答案最多 99999，可用 int。
  • JavaScript 的 Number 在此范围内可精确表示整数；Python 整数可直接累计。

复杂度

一次求总和，一次枚举切口，时间 O(n)；仅保存总和、左和及计数，额外空间 O(1)。下方 Python 代码按下标访问，不使用会复制数组的切片。

替代方案

  • 前缀和数组：保存每个前缀的和，用前缀值与总和比较，时间 O(n)、空间 O(n)。适合还需要多次区间和查询的扩展题，本题不需要保存全部前缀。
  • 左右和迁移：初始右和为总和，每轮左和加上当前元素、右和减去同一元素。时间 O(n)、额外空间 O(1)，与总和减左和等价。
  • 逐切口重新求和：实现直观，但总时间 O(n²)，不适合 n 达到 100000 的约束。

常见错误

  • 循环到 n−1，误把空右段当作合法分割。
  • 先比较后累加，比较的左段没有包含当前元素。
  • 写成严格大于，漏掉相等的情况。
  • 在 Java / C++ 中用 32 位整数累计，或 C++ 的 accumulate 初值写成 0。
  • 遇到无效切口就提前退出，或用二分寻找临界点；负数使有效性不具备单调性。

面试追问

若全部元素非负，可以二分吗？前缀和不减，合法切口形成后缀；已有前缀数组时可以二分。但建立前缀仍需 O(n)，只查询一次时直接扫描更简单。

能在总和未知时直接计数吗？单个切口是否有效依赖后续元素。可重读输入时先求总和再扫描；不可重读的数据流需要保存足够的前缀信息或增加问题约束。

若还要返回切口位置？在判断成功时保存 i，遍历不变；存储输出的位置需要 O(k) 空间，k 为合法切口数。

Java

class Solution {
    public int waysToSplitArray(int[] nums) {
        long total = 0;
        for (int x : nums) total += x;
        long left = 0;
        int answer = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            left += nums[i];
            if (left >= total - left) answer++;
        }
        return answer;
    }
}

from typing import List

class Solution:
    def waysToSplitArray(self, nums: List[int]) -> int:
        total = sum(nums)
        left = 0
        answer = 0
        for i in range(len(nums) - 1):
            left += nums[i]
            if left >= total - left:
                answer += 1
        return answer

#include <vector>

class Solution {

    int waysToSplitArray(vector<int>& nums) {
        long long total = 0;
        for (int x : nums) total += x;
        long long left = 0;
        int answer = 0;
        for (int i = 0; i < static_cast<int>(nums.size()) - 1; ++i) {
            left += nums[i];
            if (left >= total - left) ++answer;
        }
        return answer;
    }
};
