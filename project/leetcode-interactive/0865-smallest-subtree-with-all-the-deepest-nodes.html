Problem

题目理解

函数：subtreeWithAllDeepest(root)

给定一棵以 root 为根的二叉树，节点深度定义为它到根节点的最短距离。请返回一棵最小子树的根节点，使该子树包含原树中的全部最深节点。

“最深节点”指全树深度达到最大值的节点；某节点的子树由该节点与它的全部后代组成。若只有一个最深节点，答案就是该节点自身。

示例 1
输入：root = [3,5,1,6,2,0,8,null,null,7,4]输出：[2,7,4]

最深节点为 7、4，包含二者的最小子树以 2 为根。

示例 2
输入：root = [1]输出：[1]

根节点本身就是唯一的最深节点。

示例 3
输入：root = [0,1,3,null,2]输出：[2]

唯一最深节点为 2，最小子树就是它自己。

约束

  • 树中节点数在 [1, 500] 内。
  • 0 <= Node.val <= 500。
  • 每个节点的值互不相同。

Core insight

高度相等处，就是汇合点

每个节点只需要向父节点返回两件事：当前子树的最大高度，以及这棵子树中包含全部最深节点的最小子树根。

对节点 node 递归得到左右结果。若左侧更深，所有最深节点都在左子树，沿用左侧答案；右侧更深则对称处理；若两侧一样深，说明全体最深节点分布在两边（或两边都空），只有当前节点能同时覆盖，因此答案是当前节点。

  1. 后序计算左右子树
    先得到 (leftDepth, leftAnswer) 与 (rightDepth, rightAnswer)。
  2. 选择更深的一侧
    若深度不等，较浅侧不可能含有全树最深节点，答案直接继承较深侧。
  3. 在高度相等处合并
    左右同高时，当前节点是两侧最深节点的最低公共祖先，也是所求最小子树根。
  4. 向上增加一层
    当前高度为 max(leftDepth, rightDepth) + 1。

正确性证明

归纳假设：左右递归都正确返回各自子树的最大高度及最小覆盖根。

归纳步骤：左深则当前子树的最深节点全在左侧，继承左答案正确；右深同理；等深时两侧都含当前子树的最深节点，任何真子树都无法同时覆盖两侧，所以当前节点是唯一最小覆盖根。由结构归纳，根节点返回值即全树答案。

边界与复杂度

  • 空节点返回高度 0、答案 null。
  • 叶子两侧同高，返回叶子自身。
  • 退化链中，答案是唯一最深叶子。
  • 时间复杂度 O(n)：每个节点访问一次。
  • 空间复杂度 O(h)：递归栈高度；最坏 O(n)。

替代方案

可以先 DFS 记录父指针与每个节点深度，再把所有最深节点不断向父级提升直到汇合；也可先求最大深度，再做一次 LCA 搜索。它们都可做到 O(n)，但通常需要两遍遍历或额外哈希表，一次树形 DP 更紧凑。

常见错误

  • 返回“最深节点”，忘记可能有多个。
  • 比较左右答案节点的值，而不是子树高度。
  • 高度相等时错误地任选一侧；此时必须返回当前节点。
  • 把答案误当成序列化数组；函数实际返回 TreeNode。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left, right;
 *     TreeNode(int x) { val = x; }
 * }
 */
class Solution {
    private static class Result {
        int depth;
        TreeNode node;
        Result(int depth, TreeNode node) {
            this.depth = depth;
            this.node = node;
        }
    }

    public TreeNode subtreeWithAllDeepest(TreeNode root) {
        return dfs(root).node;
    }

    private Result dfs(TreeNode node) {
        if (node == null) return new Result(0, null);
        Result left = dfs(node.left);
        Result right = dfs(node.right);
        if (left.depth > right.depth) {
            return new Result(left.depth + 1, left.node);
        }
        if (right.depth > left.depth) {
            return new Result(right.depth + 1, right.node);
        }
        return new Result(left.depth + 1, node);
    }
}
/**
 * @param {TreeNode} root
 * @return {TreeNode}
 */
var subtreeWithAllDeepest = function(root) {
    const dfs = (node) => {
        if (node === null) return { depth: 0, answer: null };

        const left = dfs(node.left);
        const right = dfs(node.right);

        if (left.depth > right.depth) {
            return { depth: left.depth + 1, answer: left.answer };
        }
        if (right.depth > left.depth) {
            return { depth: right.depth + 1, answer: right.answer };
        }
        return { depth: left.depth + 1, answer: node };
    };

    return dfs(root).answer;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from typing import Optional, Tuple

class Solution:
    def subtreeWithAllDeepest(
        self, root: Optional[TreeNode]
    ) -> Optional[TreeNode]:
        def dfs(node: Optional[TreeNode]) -> Tuple[int, Optional[TreeNode]]:
            if node is None:
                return 0, None

            left_depth, left_answer = dfs(node.left)
            right_depth, right_answer = dfs(node.right)

            if left_depth > right_depth:
                return left_depth + 1, left_answer
            if right_depth > left_depth:
                return right_depth + 1, right_answer
            return left_depth + 1, node

        return dfs(root)[1]
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 * };
 */
class Solution {
    pair<int, TreeNode*> dfs(TreeNode* node) {
        if (node == nullptr) return {0, nullptr};

        auto [leftDepth, leftAnswer] = dfs(node->left);
        auto [rightDepth, rightAnswer] = dfs(node->right);

        if (leftDepth > rightDepth) {
            return {leftDepth + 1, leftAnswer};
        }
        if (rightDepth > leftDepth) {
            return {rightDepth + 1, rightAnswer};
        }
        return {leftDepth + 1, node};
    }

public:
    TreeNode* subtreeWithAllDeepest(TreeNode* root) {
        return dfs(root).second;
    }
};

面试追问

为什么这是最低公共祖先？

答案必须是所有最深节点的共同祖先；为了让子树最小，应选择距离它们最近、深度最大的那个共同祖先，也就是 LCA。

能否改成迭代？

可以。用栈模拟后序遍历，并用哈希表记录每个节点的高度和答案，代价是代码更长且需 O(n) 显式存储。

节点值不唯一会怎样？

算法只依赖节点引用与树结构，不比较节点值，因此仍然正确；值唯一只是题目给出的额外约束。

如何避免深链递归溢出？

在递归深度限制较严格的环境中，改用显式栈完成后序遍历。当前约束最多 500 个节点，主流提交语言通常可承受。
