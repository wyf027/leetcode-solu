能看到海景的建筑物

一排建筑沿街排列，海洋位于最右侧。判断哪些建筑的视线不会被右侧更高的建筑遮住，并按索引递增返回它们。

MEDIUM #1762 数组 栈 单调栈 付费题
01 · Problem

先把规则说清楚

建筑高度由整数数组给出。对索引 i，只有当右侧所有建筑都比它矮时，它才能看到海景。

题意转述

给定长度为 n 的数组 heights，其中 heights[i] 是第 i 栋建筑的高度。建筑按索引从左到右排列，海洋在最右侧。

若对每个 j > i 都有 heights[i] > heights[j]，则建筑 i 能看到海景。返回所有满足条件的建筑索引，并按递增顺序排列。

最右侧建筑的右边没有其他建筑，因此它一定能看到海景。
  • 函数findBuildings(heights)
  • 参数heights: integer[]
  • 返回integer[]
  • 海洋方向数组右侧 →

示例 1

输入
heights = [4,2,3,1]
输出
[0,2,3]

索引 1 被索引 2 的建筑挡住；其余建筑右侧都没有更高建筑。

示例 2

输入
heights = [4,3,2,1]
输出
[0,1,2,3]

高度从左到右严格下降，每栋建筑都高于它右侧的全部建筑。

示例 3

输入
heights = [1,3,2,4]
输出
[3]

最右侧高度 4 挡住了它左边的所有建筑。

04 · Solution

从右向左维护最高线

海洋在右侧，所以从右往左扫描时，已经见过的恰好是当前建筑右侧的全部建筑。

核心洞察

用 maxRight 记录当前建筑右侧的最大高度。若 heights[i] > maxRight，右侧所有建筑都比它矮，因此它能看到海景；随后更新最高线。

扫描得到的索引是从右到左的降序，最终反转一次即可满足递增顺序。

完整过程

  1. 令 maxRight = -1，结果数组 answer = []。
  2. 令 i 从 n - 1 递减到 0。
  3. 若 heights[i] > maxRight，把 i 加入结果。
  4. 更新 maxRight = max(maxRight, heights[i])。
  5. 反转结果并返回。

正确性证明

  1. 循环不变量：处理索引 i 前，maxRight 等于所有 j > i 的 heights[j] 最大值。
  2. 判定充分必要：建筑 i 能看到海景，当且仅当它高于右侧每栋建筑，也就是 heights[i] > maxRight。
  3. 不变量保持：判定后把当前高度并入最大值，下一轮的 maxRight 正好覆盖下一栋建筑右侧的全部元素。
  4. 结论：每个索引都被准确判定一次；反转只改变顺序，不改变集合，所以返回结果完整且正确。

复杂度与边界

时间复杂度：O(n)，每栋建筑访问一次，反转也是线性时间。

额外空间：O(1)（不计返回数组）；若计入答案则为 O(n)。

  • 只有一栋建筑：返回 [0]。
  • 严格递减：所有索引都入选。
  • 严格递增：只有最右索引入选。
  • 高度可达 109，四种语言的整数类型均可安全容纳。

四语言完整实现

均遵循官方函数名 findBuildings 与参数 heights。

JavaO(n) / O(1) extra
class Solution {
    public int[] findBuildings(int[] heights) {
        int n = heights.length;
        int[] reversed = new int[n];
        int size = 0;
        int maxRight = -1;

        for (int i = n - 1; i >= 0; i--) {
            if (heights[i] > maxRight) {
                reversed[size++] = i;
                maxRight = heights[i];
            }
        }

        int[] answer = new int[size];
        for (int i = 0; i < size; i++) {
            answer[i] = reversed[size - 1 - i];
        }
        return answer;
    }
}
JavaScriptO(n) / O(1) extra
/**
 * @param {number[]} heights
 * @return {number[]}
 */
var findBuildings = function(heights) {
    const answer = [];
    let maxRight = -1;

    for (let i = heights.length - 1; i >= 0; i--) {
        if (heights[i] > maxRight) {
            answer.push(i);
            maxRight = heights[i];
        }
    }

    answer.reverse();
    return answer;
};

from typing import List


class Solution:
    def findBuildings(self, heights: List[int]) -> List[int]:
        answer = []
        max_right = -1

        for i in range(len(heights) - 1, -1, -1):
            if heights[i] > max_right:
                answer.append(i)
                max_right = heights[i]

        answer.reverse()
        return answer
C++O(n) / O(1) extra
class Solution {
public:
    vector<int> findBuildings(vector<int>& heights) {
        vector<int> answer;
        int maxRight = -1;

        for (int i = static_cast<int>(heights.size()) - 1;
             i >= 0;
             --i) {
            if (heights[i] > maxRight) {
                answer.push_back(i);
                maxRight = heights[i];
            }
        }

        reverse(answer.begin(), answer.end());
        return answer;
    }
};

替代方案：单调栈

从左到右维护一个“仍可能看到海景”的索引栈。遇到更高建筑时，持续弹出栈顶较矮建筑，再压入当前索引。栈中最终保留答案，且天然递增。

它同样是摊还 O(n) 时间，但需要 O(n) 额外空间。若只求最终答案，反向维护最大值更直接；若题目扩展为动态消除遮挡关系，单调栈思维更容易迁移。

常见错误

  • 只与右邻建筑比较，而没有比较右侧最高建筑。
  • 从右向左收集后忘记反转，导致返回顺序错误。
  • 把条件写成 >=；本题高度互异，虽不影响官方数据，但会掩盖对“严格更高”的理解。
  • 每个位置再扫描整个右侧，退化为 O(n²) 并在 105 规模超时。

面试追问

  • 如果建筑高度允许相同，判定条件是否仍为严格大于？
  • 如果海洋在左侧，扫描方向与输出顺序怎样变化？
  • 如果海洋在两侧，如何分别求出两组可见建筑？
  • 若高度会在线更新并频繁查询，可考虑怎样的数据结构？
