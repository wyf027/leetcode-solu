Problem Brief

题意

给定含 n 个节点的有向图边列表 graph，判断从 start 到 target 是否存在一条有向路径。

约束与边界

  • 0 ≤ n ≤ 10^5
  • 节点编号满足 0 ≤ node < n
  • 图中可能有自环和平行边
  • 方向不可逆；u → v 不代表 v → u

Sealed Flight Plan

题解

核心洞察、完整过程、边界、复杂度、替代方案、追问、错误与四语言代码默认隐藏。

Core Insight

入队时标记，保证每个节点最多进队一次

先把边列表转换成邻接表。队列保存“下一批待扩散节点”，visited 保存已经登记的节点。检查 u → v 时，如果 v 未访问，就在入队的同一刻标记它；这样自环、环和平行边都不会造成重复搜索。

Complete Process

  1. 创建 n 个邻接列表，按有向边填入。
  2. 起点入队并标记。
  3. 循环取队首；若等于目标，返回 true。
  4. 遍历所有出边，未访问邻居立刻标记并入队。
  5. 队列清空仍未命中，返回 false。

Boundaries & Complexity

  • 时间：O(n + m)
  • 空间：O(n + m)（邻接表、队列、访问数组）
  • 起终点相同：零条边路径也可达。
  • 自环/平行边：visited 自动去重。

Alternatives

DFS 也能在 O(n + m) 内完成；递归版更短，但当 n = 10^5 且图退化成长链时可能栈溢出。迭代 DFS 可规避栈风险。并查集忽略方向，不能用于本题。

Interview Follow-ups

  • 为什么在入队而不是出队时标记？避免多个前驱重复入队。
  • 只问一次与问很多次有何区别？多次查询可考虑传递闭包或按起点缓存，需结合图规模。
  • 如何输出具体路径？维护 parent，命中后反向还原。

Common Mistakes

  • 把有向边当成无向边双向加入。
  • 不设 visited，遇到环永不结束。
  • 出队才标记，平行边导致大量重复节点。
  • 扫描边列表找邻居，使复杂度退化到 O(nm)。

Edge Cases

  • start === target 直接可达。
  • 目标没有入边或起点没有出边时快速失败。
  • n = 0 时题目不会给合法节点编号；实现按约束处理有效起终点。

class Solution {
    public boolean findWhetherExistsPath(int n, int[][] graph, int start, int target) {
        List<Integer>[] adjacency = new List[n];
        for (int i = 0; i < n; i++) adjacency[i] = new ArrayList<>();
        for (int[] edge : graph) adjacency[edge[0]].add(edge[1]);

        boolean[] visited = new boolean[n];
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(start);
        visited[start] = true;

        while (!queue.isEmpty()) {
            int current = queue.poll();
            if (current == target) return true;
            for (int next : adjacency[current]) {
                if (!visited[next]) {
                    visited[next] = true;
                    queue.offer(next);
                }
            }
        }
        return false;
    }
}
var findWhetherExistsPath = function (n, graph, start, target) {
  const adjacency = Array.from({ length: n }, () => []);
  for (const [from, to] of graph) adjacency[from].push(to);

  const visited = Array(n).fill(false);
  const queue = [start];
  visited[start] = true;

  for (let head = 0; head < queue.length; head += 1) {
    const current = queue[head];
    if (current === target) return true;
    for (const next of adjacency[current]) {
      if (!visited[next]) {
        visited[next] = true;
        queue.push(next);
      }
    }
  }
  return false;
};
