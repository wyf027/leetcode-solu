01 / 题目与输入约定

一个句子由若干仅含大小写英文字母的单词组成，相邻单词用一个空格分隔，首尾没有空格。现在给每个单词末尾附上它在原句中从 1 开始的位置编号，然后打乱这些带编号单词的顺序。给定结果字符串 s，请返回去掉编号、恢复原顺序的句子。单词不超过 9 个。

官方示例 1

输入：s = "is2 sentence4 This1 a3"
输出："This is a sentence"

原句依次是 This、is、a、sentence。

官方示例 2

输入：s = "Myself2 Me1 I4 and3"
输出："Me Myself and I"

原句依次是 Me、Myself、and、I。

约束

  • 2 ≤ s.length ≤ 200。
  • s 仅含大小写英文字母、空格和数字 1 到 9。
  • 单词数量在 1 到 9 之间，单词之间恰有一个空格。
  • s 没有前导或尾随空格。
  • 根据题意，输入来自合法句子的打乱结果：末尾编号是 1…n 的一个排列。

参数：s: string　返回：string　入口：sortSentence(s)

04 / 思路与四语言题解

先形成自己的想法，再展开对照。

核心洞察：编号已经告诉我们最终位置

这道题无需比较单词，也无需按字典序排序。每个词的最后一位数字就是它在原句中的位置。创建长度为 n 的数组，直接把去掉数字的词写入 编号 − 1 处，最后用单个空格连接即可。

完整过程

  1. 按单个空格拆分字符串，得到 n 个带编号单词。
  2. 建立 n 个空槽，遍历输入单词。
  3. 读取末尾数字 p，去掉末尾数字，写入 ans[p - 1]。
  4. 所有槽位写入后，以单个空格连接数组并返回。
is2       → ans[1] = "is"
sentence4 → ans[3] = "sentence"
This1     → ans[0] = "This"
a3        → ans[2] = "a"
ans = ["This", "is", "a", "sentence"]
返回 "This is a sentence"

正确性说明

循环不变式：处理完前 k 个输入单词后，每个已处理单词都存放在其原句位置对应的数组下标处，其余槽位尚未填写。初始 k = 0 时成立。处理下一个末尾编号为 p 的单词时，将词干写入 p − 1，正好对应原句第 p 个位置；合法输入的编号互不重复，因此不会覆盖其他已归位单词。遍历结束时，编号 1 到 n 全部出现，数组完整且顺序正确。以一个空格连接并去掉编号，恰好恢复题目定义的原句。

边界与复杂度

一个单词时只需去掉末位数字。已经有序或完全逆序都按相同步骤处理。重复单词不影响结果，因为定位依据是编号；大小写必须原样保留。最多 9 个单词，编号始终是一位，所以可以只取最后一个字符。题目保证输入合法，提交代码无需额外校验。

令 L 为输入字符串长度，n 为单词数。拆分、切片和拼接总计扫描或复制 O(L) 个字符，因此时间复杂度为 O(L)。下面实现保存拆分单词、词干与结果，额外空间为 O(L)；仅槽位引用占 O(n)。不能把包含字符串复制的总体成本仅写作 O(n)。

替代方案

也可以按末尾数字比较排序，再去掉数字并拼接，时间 O(L + n log n)、空间 O(L)（具体排序辅助空间取决于语言实现）。本题编号连续且唯一，直接放置更直观。若编号稀疏且跨度很大，排序或映射后排序就比按最大编号开数组合适。

常见错误

  • 按整个单词字典序排序：字母大小与原位置没有关系。
  • 把编号 p 直接当数组下标：忘记从 1 起算与从 0 起算的差异。
  • 拼接前未移除编号，或通过手动加空格产生尾随空格。
  • 用单词作为映射键：重复词可能丢失，应按位置定位。
  • 推广到多位编号后仍只取末位：需要解析末尾连续数字。

面试追问

如果超过 9 个词？ 从字符串末尾向前扫描连续数字，再将整个数字后缀转为整数。

如果输入不再保证合法？ 检查词干、编号范围、重复与缺号，并明确错误返回策略。工作台对编辑输入做了这些格式检查，提交版本依赖官方约束。

能否做到原地处理？ 对可修改的单词数组可按编号进行循环交换，减少额外槽位；但这些语言中的拆分和结果拼接仍占空间，不能据此宣称总体 O(1)。

Java

class Solution {
    public String sortSentence(String s) {
        String[] words = s.split(" ");
        String[] answer = new String[words.length];
        for (String word : words) {
            int last = word.length() - 1;
            int index = word.charAt(last) - '1';
            answer[index] = word.substring(0, last);
        }
        return String.join(" ", answer);
    }
}

/**

var sortSentence = function(s) {
    const words = s.split(' ');
    const answer = new Array(words.length);
    for (const word of words) {
        const index = Number(word[word.length - 1]) - 1;
        answer[index] = word.slice(0, -1);
    }
    return answer.join(' ');
};

Python 3

class Solution:
    def sortSentence(self, s: str) -> str:
        words = s.split(" ")
        answer = [""] * len(words)
        for word in words:
            index = int(word[-1]) - 1
            answer[index] = word[:-1]
        return " ".join(answer)

C++

#include <string>
#include <vector>
#include <sstream>
using namespace std;

class Solution {
public:
    string sortSentence(string s) {
        istringstream input(s);
        vector<string> words;
        string word;
        while (input >> word) {
            words.push_back(word);
        }
        vector<string> answer(words.size());
        for (const string& token : words) {
            int index = token.back() - '1';
            answer[index] = token.substr(0, token.size() - 1);
        }
        string result;
        result.reserve(s.size());
        for (size_t i = 0; i < answer.size(); ++i) {
            if (i != 0) result += ' ';
            result += answer[i];
        }
        return result;
    }
};
