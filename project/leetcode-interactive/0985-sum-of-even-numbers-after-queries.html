查询后的偶数和

Sum of Even Numbers After Queries

维护一个会被查询永久修改的数组，并在每次修改后返回所有偶数元素之和。先尝试从“每轮重新求和”里找到可以复用的状态，再展开题解。

01题目

给定整数数组 nums 和查询数组 queries，其中 queries[i] = [valᵢ, indexᵢ]。对每次查询，执行 nums[indexᵢ] += valᵢ；修改会保留到后续查询。返回数组 answer，其中 answer[i] 是第 i 次修改后 nums 中所有偶数值的和。

示例 1

输入：nums = [1,2,3,4], queries = [[1,0],[-3,1],[-4,0],[2,3]]
输出：[8,6,2,4]
解释：[2,2,3,4] → 8
      [2,-1,3,4] → 6
      [-2,-1,3,4] → 2
      [-2,-1,3,6] → 4

示例 2

输入：nums = [1], queries = [[4,0]]
输出：[0]

1 + 4 = 5，数组中没有偶数，所以答案为 0。

约束

  • 1 ≤ nums.length ≤ 10⁴
  • -10⁴ ≤ nums[i] ≤ 10⁴
  • 1 ≤ queries.length ≤ 10⁴
  • -10⁴ ≤ valᵢ ≤ 10⁴
  • 0 ≤ indexᵢ < nums.length

03动手前想一想

关键问题

一次查询只改变一个数。旧值和新值分别是奇数或偶数时，偶数和应该怎样增减？

复杂度目标

若每次都遍历整个数组，总成本是 O(nq)。能否将每条查询压缩到 O(1)？

04完整题解

建议先完成上面的推导，再检查答案。

核心洞察

先求出当前偶数和 sum。每次查询只需移除旧值的贡献、修改该值，再加入新值的贡献：

若 old 为偶数：sum -= old
nums[index] += val
若 new 为偶数：sum += new

完整过程

  1. 遍历 nums，初始化所有偶数之和。
  2. 逐条读取 [val, index]。
  3. 旧值若为偶数，从和中减去。
  4. 更新数组元素。
  5. 新值若为偶数，加进和并记录答案。

正确性证明

1

不变式：处理每条查询前，sum 等于当前数组全部偶数元素之和。

2

保持：查询仅修改一个位置。先去掉该位置旧偶数贡献，更新后再加入新偶数贡献；其他位置不变，因此 sum 仍准确。

3

结论：初始化时不变式成立，且每轮保持，所以每个记录值都是该次查询后的正确偶数和。

边界与复杂度

  • 奇→奇：和不变；奇→偶：加入新值。
  • 偶→奇：移除旧值；偶→偶：等价于和增加 val。
  • 0 和负偶数都属于偶数。
  • 时间 O(n + q)，额外空间 O(q)（返回结果不计则 O(1)）。

替代方案

直接模拟后每次重扫数组，逻辑直观但耗时 O(nq)。也可以用树状数组维护“偶数贡献”，实现 O((n+q)log n)，但本题只有全局求和，不需要区间能力，属于过度设计。

面试追问

  • 若查询要求区间偶数和，如何改成树状数组或线段树？
  • 若要同时维护偶数个数、和与最大值，状态应怎样组织？
  • 语言中负数取模的行为是否影响奇偶判断？使用 x % 2 === 0 最稳妥。
常见错误：更新后才尝试删除旧贡献；忘记查询会永久修改数组；把 0 当作非偶数；每次重新遍历；在 JavaScript 中用位运算时忽略 32 位转换。

class Solution {
    public int[] sumEvenAfterQueries(int[] nums, int[][] queries) {
        int sum = 0;
        for (int x : nums) if (x % 2 == 0) sum += x;
        int[] answer = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int val = queries[i][0], index = queries[i][1];
            if (nums[index] % 2 == 0) sum -= nums[index];
            nums[index] += val;
            if (nums[index] % 2 == 0) sum += nums[index];
            answer[i] = sum;
        }
        return answer;
    }
}

from typing import List

class Solution:
    def sumEvenAfterQueries(
        self, nums: List[int], queries: List[List[int]]
    ) -> List[int]:
        even_sum = sum(x for x in nums if x % 2 == 0)
        answer = []
        for val, index in queries:
            if nums[index] % 2 == 0:
                even_sum -= nums[index]
            nums[index] += val
            if nums[index] % 2 == 0:
                even_sum += nums[index]
            answer.append(even_sum)
        return answer
