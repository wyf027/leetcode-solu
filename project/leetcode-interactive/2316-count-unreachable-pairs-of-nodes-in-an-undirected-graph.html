Count Unreachable Pairs of Nodes in an Undirected Graph

两点之间没有直接边，是否就一定无法到达？
先理清“路径”与“点对”，再开始推导。

官方题目 ↗无序点对 · 不同节点 · 无向图

01 / 题目

给定整数 n 和二维整数数组 edges。图中共有 n 个节点，编号从 0 到 n - 1；每个 edges[i] = [aᵢ, bᵢ] 表示一条连接两端的无向边。

返回无法通过任何路径相互到达的不同节点点对数量。每个点对只统计一次，即 (u, v) 与 (v, u) 是同一对，不统计节点与自身。

官方示例 1

输入：n = 3, edges = [[0,1],[0,2],[1,2]]
输出：0

任意两个不同节点之间都能到达，因此答案为 0。

官方示例 2

输入：n = 7, edges = [[0,2],[0,5],[2,4],[1,6],[5,4]]
输出：14

以下 14 个无序点对之间没有路径：

[[0,1],[0,3],[0,6],[1,2],[1,3],[1,4],[1,5],
 [2,3],[2,6],[3,4],[3,5],[3,6],[4,6],[5,6]]

约束

  • 1 ≤ n ≤ 10⁵
  • 0 ≤ edges.length ≤ 2 × 10⁵
  • edges[i].length == 2
  • 0 ≤ aᵢ, bᵢ < n，且 aᵢ ≠ bᵢ
  • 没有重复边。

04 / 独立题解

包含交互演示、推导与四语言实现

核心洞察：先分组，再数跨组配对

一个连通分量中的节点彼此可达；不同连通分量之间没有路径。用迭代 DFS 找到各分量的大小，就把图问题变成了组合计数。

当前分量大小为 s，此前已处理节点共 seen 个：新增加 s × seen 个不可达点对，然后令 seen += s。

示例 2 的分量依次为 {0,2,4,5}、{1,6}、{3}，大小为 4、2、1。新增点对依次为 4×0、2×4、1×6，总数为 14。

完整过程
  1. 建立邻接表，每条无向边都写入两个方向。
  2. 从编号 0 到 n−1 扫描节点。已访问的节点跳过，否则开启一个新分量。
  3. 将起点标记并入栈。每次出栈一个节点，让分量大小加一；把它未访问的邻居标记后入栈，直到栈为空。
  4. 将当前大小乘以此前已结算的节点数，累加到答案，再更新已结算节点数。
  5. 所有节点扫描完成后返回答案。孤立节点会自然成为大小为 1 的分量。


为什么正确
遍历完整：DFS 只沿图中的边扩展，因此不会走出当前连通分量；分量内任意节点都存在一条从起点出发的路径，沿路径扩展最终会访问它。入栈前标记确保每个节点只入栈一次，得到准确分量大小。
计数不重不漏：处理当前分量前，维护不变量：seen 是此前所有分量的节点数，ans 已包含这些分量之间的全部不可达点对。当前 s 个节点与此前 seen 个节点任意组合均不可达，共 s×seen 对。它们此前未被统计；同分量内部不计数。更新后不变量继续成立。每一对不同分量中的节点恰在较晚分量被处理时计入一次，最终答案正确。


边界与复杂度
  • 只有一个分量：各次贡献均为 0。
  • 没有边：答案为 n(n−1)/2。
  • 环：入栈即标记，避免重复计数。
  • 时间 O(n + m)，空间 O(n + m)，m 为边数；邻接表存储 2m 条邻接关系。
  • 最坏答案 4,999,950,000。Java 用 long，C++ 用 long long，且乘法前就提升类型；Python 整数自动扩展，JavaScript Number 在本题范围内可精确表示。
替代方案
  • BFS：用队列代替栈，同样统计分量，复杂度不变。JavaScript 可用下标推进队头，避免反复 shift。
  • 并查集：按边合并，再数各根的大小；路径压缩和按大小合并后时间 O(n + m α(n))，辅助空间 O(n)。
  • 补集计数：从 n(n−1)/2 中减去每个分量的 s(s−1)/2。也可以累加 s(n−s) 后除以 2。


四语言代码 · 迭代 DFS
使用官方方法签名；以下代码待补验证。显式栈避免长链造成递归栈溢出。


Java
import java.util.*;

class Solution {
    public long countPairs(int n, int[][] edges) {
        List<List<Integer>> graph = new ArrayList<>();
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] e : edges) {
            graph.get(e[0]).add(e[1]);
            graph.get(e[1]).add(e[0]);
        }
        boolean[] visited = new boolean[n];
        Deque<Integer> stack = new ArrayDeque<>();
        long seen = 0, answer = 0;
        for (int start = 0; start < n; start++) {
            if (visited[start]) continue;
            visited[start] = true;
            stack.push(start);
            long size = 0;
            while (!stack.isEmpty()) {
                int u = stack.pop();
                size++;
                for (int v : graph.get(u)) {
                    if (!visited[v]) {
                        visited[v] = true;
                        stack.push(v);
                    }
                }
            }
            answer += size * seen;
            seen += size;
        }
        return answer;
    }
}

var countPairs = function(n, edges) {
    const graph = Array.from({ length: n }, () => []);
    for (const [a, b] of edges) {
        graph[a].push(b);
        graph[b].push(a);
    }
    const visited = new Uint8Array(n);
    let seen = 0, answer = 0;
    for (let start = 0; start < n; start++) {
        if (visited[start]) continue;
        visited[start] = 1;
        const stack = [start];
        let size = 0;
        while (stack.length) {
            const u = stack.pop();
            size++;
            for (const v of graph[u]) {
                if (!visited[v]) {
                    visited[v] = 1;
                    stack.push(v);
                }
            }
        }
        answer += size * seen;
        seen += size;
    }
    return answer;
};


Python 3
from typing import List

class Solution:
    def countPairs(self, n: int, edges: List[List[int]]) -> int:
        graph = [[] for _ in range(n)]
        for a, b in edges:
            graph[a].append(b)
            graph[b].append(a)
        visited = [False] * n
        seen = answer = 0
        for start in range(n):
            if visited[start]:
                continue
            visited[start] = True
            stack = [start]
            size = 0
            while stack:
                u = stack.pop()
                size += 1
                for v in graph[u]:
                    if not visited[v]:
                        visited[v] = True
                        stack.append(v)
            answer += size * seen
            seen += size
        return answer


C++
#include <vector>
using namespace std;

class Solution {
public:
    long long countPairs(int n, vector<vector<int>>& edges) {
        vector<vector<int>> graph(n);
        for (const auto& e : edges) {
            graph[e[0]].push_back(e[1]);
            graph[e[1]].push_back(e[0]);
        }
        vector<bool> visited(n, false);
        long long seen = 0, answer = 0;
        for (int start = 0; start < n; ++start) {
            if (visited[start]) continue;
            visited[start] = true;
            vector<int> stack{start};
            long long size = 0;
            while (!stack.empty()) {
                int u = stack.back();
                stack.pop_back();
                ++size;
                for (int v : graph[u]) {
                    if (!visited[v]) {
                        visited[v] = true;
                        stack.push_back(v);
                    }
                }
            }
            answer += size * seen;
            seen += size;
        }
        return answer;
    }
};




常见错误
  • 只检查直接边：路径可以经过多个节点。
  • 只从节点 0 出发：会遗漏其他分量和孤立节点。
  • 先更新 seen 再算 s×seen：会把本分量节点算进去。
  • 累加 s(n−s) 却不除以 2：每一对被计两次。
  • Java / C++ 先用 int 相乘再赋给长整数：乘法已经溢出。
  • JavaScript 用位运算截断答案：会转为 32 位整数。
面试追问
  • 边逐条加入怎么办？初始 n(n−1)/2；并查集合并大小 a、b 的不同分量时，答案减去 a×b。同根边不改变答案。
  • 要输出所有点对？枚举不同分量的笛卡尔积，但输出量本身可能是 Θ(n²)。
  • 改为有向图？当前分量判定不再足够；需先明确单向可达还是双向可达，双向可达可按强连通分量处理。
