Count Common Words With One Occurrence

两个字符串数组。找出在每个数组中都只出现一次的字符串，返回这样的不同字符串的数量。

官方题目 ↗

01 / 题目规格

“都恰好一次”是两个独立条件

输入 words1: string[] 和 words2: string[]。对一个字符串，要求它在 words1 中出现 1 次，并且在 words2 中也出现 1 次。只在一个数组出现，或任意一侧重复出现，都不计入。返回整数，函数名为 countWords。

  • 1 ≤ words1.length, words2.length ≤ 1000
  • 1 ≤ words1[i].length, words2[j].length ≤ 30
  • 所有字符串均仅由小写英文字母组成。

官方示例

示例 1

words1 = ["leetcode","is","amazing","as","is"]
words2 = ["amazing","leetcode","is"]
输出：2

示例 2

words1 = ["b","bb","bbb"]
words2 = ["a","aa","aaa"]
输出：0

两个数组没有公共字符串。

示例 3

words1 = ["a","ab"]
words2 = ["a","a","a","ab"]
输出：1

只有 ab 满足条件；a 在第二个数组中重复。

04 / 按需揭晓

题解与实现

核心洞察：保留每一侧的次数

对任意词 w，设 c1[w]、c2[w] 为它在两个数组中的出现次数。唯一判定条件是 c1[w] === 1 && c2[w] === 1。使用两个哈希表独立计数，然后枚举第一张表的键，每个合格词只累加一次。

完整过程

  1. 扫描 words1，遇到一个词就给 c1 对应计数加一。
  2. 扫描 words2，以相同方式填充 c2。
  3. 枚举 c1 的每个词。左侧计数为 1，且右侧计数也为 1 时，答案加一；不存在的键按 0 处理。
  4. 返回答案。示例 1 的最终频次对为：leetcode=(1,1)、is=(2,1)、amazing=(1,1)、as=(1,0)，所以结果为 2。

正确性

计数不变式：扫描任意前缀后，表中每个词的值等于它在该前缀的出现次数。初始前缀为空，计数为 0；每次只增加当前词的一次出现，因此不变式持续成立，扫描完毕即得到真实总频次。

可靠性：被计入的词同时满足两侧计数为 1，所以一定符合题意。完整性：任意符合题意的词都存在于第一张表，遍历时两项条件必然成立，因此不会漏掉。哈希表的键不重复，所以每个合格词恰好计入一次。

边界与常见错误

  • 只有一个元素且两侧相同，结果为 1；完全无交集时为 0。
  • 任何一侧重复都要排除；单侧缺失也是不合格，不要把“出现过”当成“恰好一次”。
  • 仅取两个 Set 的交集会丢失重复次数。
  • 合并数组后频次为 2 可能是 (2,0)，不能替代 (1,1)。
  • 未扫描完就根据临时频次累计，后续重复可能让已计入的词失效。
  • 题目不允许空数组、空字符串或大写字母。交互输入会按官方范围进行限制。

复杂度

设数组长度分别为 n、m，不同词数量分别为 u₁、u₂，最大词长为 L。通常在哈希操作均摊常数、词长有界的模型下，时间为 O(n + m)，额外空间为 O(u₁ + u₂)。计入字符串哈希成本后，期望时间为 O((n + m)L)；若键需要复制，字符存储空间上界为 O((u₁ + u₂)L)。本题 L ≤ 30。哈希表极端碰撞不属于常数时间保证。

替代方案

可分别排序两个数组，按相同词分组，再用双指针合并两个分组序列，仅计入两边组大小均为 1 的词。通常需 O(n log n + m log m) 次字符串比较，并可能修改输入；若需保留输入，应先复制。也可用一张表给每个词存储两个计数，逻辑相同但实现未必更短。

面试追问

  • 恰好 k 次怎么办？将两个比较条件的 1 改为 k；对 k ≥ 1 仍可只枚举第一张表。
  • 要返回字符串本身？将合格键加入结果列表，需要固定顺序时再排序。
  • 数据流中怎样增量维护答案？每次更新前减去该词旧状态的贡献，更新后加上新状态贡献。
  • 内存受限怎么办？若允许外部排序，可按词聚合后合并两个有序频次流。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int countWords(String[] words1, String[] words2) {
        Map<String, Integer> c1 = new HashMap<>();
        Map<String, Integer> c2 = new HashMap<>();
        for (String word : words1) {
            c1.put(word, c1.getOrDefault(word, 0) + 1);
        }
        for (String word : words2) {
            c2.put(word, c2.getOrDefault(word, 0) + 1);
        }
        int answer = 0;
        for (Map.Entry<String, Integer> entry : c1.entrySet()) {
            if (entry.getValue() == 1
                    && c2.getOrDefault(entry.getKey(), 0) == 1) {
                answer++;
            }
        }
        return answer;
    }
}

var countWords = function(words1, words2) {
    const c1 = new Map();
    const c2 = new Map();
    for (const word of words1) {
        c1.set(word, (c1.get(word) || 0) + 1);
    }
    for (const word of words2) {
        c2.set(word, (c2.get(word) || 0) + 1);
    }
    let answer = 0;
    for (const [word, count] of c1) {
        if (count === 1 && c2.get(word) === 1) answer++;
    }
    return answer;
};

Python 3

from collections import Counter
from typing import List

class Solution:
    def countWords(self, words1: List[str], words2: List[str]) -> int:
        c1 = Counter(words1)
        c2 = Counter(words2)
        return sum(count == 1 and c2[word] == 1
                   for word, count in c1.items())

C++

#include <string>
#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int countWords(vector<string>& words1, vector<string>& words2) {
        unordered_map<string, int> c1, c2;
        for (const auto& word : words1) ++c1[word];
        for (const auto& word : words2) ++c2[word];
        int answer = 0;
        for (const auto& entry : c1) {
            auto it = c2.find(entry.first);
            if (entry.second == 1 && it != c2.end() && it->second == 1) {
                ++answer;
            }
        }
        return answer;
    }
};
