小数字，能否穿过前方的阻挡？

检查字符串是否可以通过排序子字符串得到另一个字符串

Check If String Is Transformable With Substring Sort Operations

先别急着看题解。 先在下方实验：当目标数字想提前时，观察它左边尚未使用的更小数字会发生什么。

Problem

题意

给定两个等长、仅由数字组成的字符串 s 和 t。你可以操作任意次：选择 s 的一个非空连续子字符串，将其中字符就地按升序排列。

判断能否通过这些操作把 s 变成 t。例如，把 "14234" 中的 "4234" 排序，可得到 "12344"。

函数形式：isTransformable(s: string, t: string): boolean

Constraints

约束

  • s.length == t.length
  • 1 <= s.length <= 105
  • s 和 t 仅包含 '0' 到 '9'
连续子串升序排序允许零次操作

题解会解释为什么“更小数字的位置队首”就是全部关键。

Solution

位置队列 + 贪心扫描

核心洞察

升序排序能让较小数字越过较大的数字向左移动，却不能让较大数字越过较小数字向左移动。准备生成目标数字 d 时，应取原串中最靠左、尚未使用的 d。若它前面还有任意更小数字未使用，那么这个更小数字永远无法被 d 跨过，转换失败。

数据结构

为数字 0..9 各建一个位置队列，按从左到右记录它在 s 中的下标。扫描 t；只需比较至多 9 个更小数字的队首。

完整过程

  1. 遍历 s，把每个下标加入对应数字的队列。
  2. 从左到右扫描 t。设当前数字为 d。
  3. 若 d 的队列已空，说明计数不匹配，返回 false。
  4. 设其队首原下标为 p。检查所有 x < d：若某个 x 的未用队首下标小于 p，它挡住了 d，返回 false。
  5. 否则消费该队首；扫描完成则返回 true。

正确性证明

必要性：若未使用的较小数字 x 位于候选 d 左侧，任何升序子串操作都不会颠倒这对字符为 d,x；所以 d 不可能先出现在目标当前位置。

充分性：若候选 d 前方没有更小的未用数字，则它前面的未用字符都不小于 d。对覆盖这些字符与 d 的区间升序排序，可把 d 移到它们之前而不破坏已确定前缀。

贪心每一步都满足必要且可实现的条件，归纳可得：扫描全部成功当且仅当转换可行。

复杂度

建队列 O(n)；每个目标字符检查 10 种数字，故为 O(10n)=O(n)。位置队列占 O(n) 空间。

边界情况

  • 长度 1 与完全相同的字符串
  • 字符计数不同，目标队列会提前耗尽
  • 大量重复数字，必须消费最左未用位置
  • 已经升序的原串不能制造逆序

替代方案

可用 Fenwick 树维护未删除位置并查询前缀最小值类别，但数字域只有 10，十个队列更直接。真实模拟子串排序或冒泡交换会达到二次复杂度。

四语言完整代码

Java

import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    public boolean isTransformable(String s, String t) {
        @SuppressWarnings("unchecked")
        Deque<Integer>[] pos = new ArrayDeque[10];
        for (int d = 0; d < 10; d++) pos[d] = new ArrayDeque<>();
        for (int i = 0; i < s.length(); i++) {
            pos[s.charAt(i) - '0'].offerLast(i);
        }

        for (int i = 0; i < t.length(); i++) {
            int d = t.charAt(i) - '0';
            if (pos[d].isEmpty()) return false;
            int index = pos[d].peekFirst();
            for (int smaller = 0; smaller < d; smaller++) {
                if (!pos[smaller].isEmpty()
                        && pos[smaller].peekFirst() < index) {
                    return false;
                }
            }
            pos[d].pollFirst();
        }
        return true;
    }
}

JavaScript

/**
 * @param {string} s
 * @param {string} t
 * @return {boolean}
 */
var isTransformable = function(s, t) {
    const positions = Array.from({ length: 10 }, () => []);
    const head = Array(10).fill(0);

    for (let i = 0; i < s.length; i++) {
        positions[Number(s[i])].push(i);
    }

    for (const char of t) {
        const digit = Number(char);
        if (head[digit] === positions[digit].length) return false;

        const index = positions[digit][head[digit]];
        for (let smaller = 0; smaller < digit; smaller++) {
            if (head[smaller] < positions[smaller].length &&
                positions[smaller][head[smaller]] < index) {
                return false;
            }
        }
        head[digit]++;
    }
    return true;
};

Python

from collections import deque


class Solution:
    def isTransformable(self, s: str, t: str) -> bool:
        positions = [deque() for _ in range(10)]
        for index, char in enumerate(s):
            positions[int(char)].append(index)

        for char in t:
            digit = int(char)
            if not positions[digit]:
                return False

            index = positions[digit][0]
            for smaller in range(digit):
                if positions[smaller] and positions[smaller][0] < index:
                    return False
            positions[digit].popleft()

        return True

C++

#include <array>
#include <queue>
#include <string>
using namespace std;

class Solution {
public:
    bool isTransformable(string s, string t) {
        array<queue<int>, 10> positions;
        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            positions[s[i] - '0'].push(i);
        }

        for (char ch : t) {
            int digit = ch - '0';
            if (positions[digit].empty()) return false;

            int index = positions[digit].front();
            for (int smaller = 0; smaller < digit; ++smaller) {
                if (!positions[smaller].empty() &&
                    positions[smaller].front() < index) {
                    return false;
                }
            }
            positions[digit].pop();
        }
        return true;
    }
};

常见错误

  • 只比较两串数字计数；计数相同并不代表相对顺序可达。
  • 检查所有更小数字是否出现过，而不是检查它们“当前未用的队首位置”。
  • 从某个数字队列中随便取位置；必须取最左未用位置。
  • 误以为一次排序允许任意排列；操作结果只能是升序。
  • 真的反复排序字符串，无法承受 105 的规模。

面试追问

  • 为什么只检查比当前数字小的队列，而不用检查更大的？
  • 若字符集从 10 个数字扩展到十万种字符，如何优化“检查所有更小字符”？
  • 如果操作改为降序排序，阻挡条件应如何反转？
  • 能否构造具体操作序列，而不只是判断可行性？
  • 位置队列方案与相邻交换视角之间有什么等价关系？
