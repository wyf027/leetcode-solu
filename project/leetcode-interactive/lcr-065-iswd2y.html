Core insight

从末尾向前共享路径

将每个单词倒序插入一棵前缀树。一个单词若插入后没有创建任何新节点，说明它的全部字符路径已经存在，恰好是某个更长单词的后缀；它不需要独立编码。否则答案增加单词长度加一个分隔符。

Complexity

每个字符至多走一次

时间 O(S)，其中 S 是所有单词字符总数；空间 O(S)，用于倒序树的节点。

完整过程

  1. 1. 倒序读取

    从词尾向词首走，令相同后缀成为同一条树路径。

  2. 2. 标记新节点

    插入途中若创建节点，记录该词提供了新的编码信息。

  3. 3. 累加长度

    仅为创建过节点的单词累加 word.length + 1。

边界与常见错误

  • • 单个单词仍要计入末尾的 #。
  • • 必须倒序建树；正向建树共享的是前缀，不符合题意。
  • • 不能只用集合检查任意子串，判断的是完整后缀关系。
  • • 题目保证单词互不相同，重复词不是额外编码段。

替代方案与追问

替代方案：排序后检查
按倒序字符串排序，只需比较相邻词的前缀关系；实现紧凑，但不如树结构直观地表达共享后缀。
为什么可以按任意顺序插入？
无论短词先到还是长词先到，只有创建新节点的词才会被计数；共享路径不会重复计入。

class Solution {
    static class Node {
        Node[] next = new Node[26];
    }

    public int minimumLengthEncoding(String[] words) {
        Node root = new Node();
        int answer = 0;
        for (String word : words) {
            Node node = root;
            boolean created = false;
            for (int i = word.length() - 1; i >= 0; i--) {
                int index = word.charAt(i) - 'a';
                if (node.next[index] == null) {
                    node.next[index] = new Node();
                    created = true;
                }
                node = node.next[index];
            }
            if (created) answer += word.length() + 1;
        }
        return answer;
    }
}

class Solution:
    def minimumLengthEncoding(self, words: List[str]) -> int:
        root = {}
        answer = 0
        for word in words:
            node = root
            created = False
            for ch in reversed(word):
                if ch not in node:
                    node[ch] = {}
                    created = True
                node = node[ch]
            if created:
                answer += len(word) + 1
        return answer
