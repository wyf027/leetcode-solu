滑动谜题 Sliding Puzzle

六个位置、五块数字砖与一个空格。你每次只能把空格与上下左右相邻的数字交换；任务是判断能否到达目标布局，并返回所需的最少移动次数。

123 450
唯一目标状态
[[1,2,3],[4,5,0]]

Problem

题意与规则

先把状态、合法移动与返回值说清楚；本区域不展开求解算法。

给定一个 2 × 3 的二维数组 board。棋盘上恰好有数字 0 到 5，其中 1 到 5 表示五块砖，0 表示空格。

一次移动可以选择空格，并将它与四方向（上、下、左、右）相邻的一块数字砖交换。只有当棋盘变成 [[1,2,3],[4,5,0]] 时，谜题才算完成。

函数 slidingPuzzle(board) 返回从初始棋盘到目标棋盘所需的最少移动次数；如果无论如何都不能完成，则返回 -1。

规则速览

  • 棋盘固定为 2 行 3 列。
  • 每次只交换空格与一个四方向邻居。
  • 不能斜向交换，也不能一次跨过多格。
  • 答案要求最少步数，不是任意可行步数。
  • 无解时返回 -1。
函数形式
输入：board: integer[][]
输出：integer

Solution

广度优先搜索最短路

把每一种棋盘排列视为图上的节点，把一次合法交换视为一条长度为 1 的边。

核心洞察

题目求“最少移动次数”，而每次移动的代价都相同。把状态空间建成无权图后，从起点做 BFS，第一次访问目标状态时所在的层数就是最短距离。

为了方便判重，把二维棋盘压平成长度为 6 的字符串，例如目标状态编码为 "123450"。

位置邻接表

压平后的下标排列如下：

0 1 2
3 4 5

空格下标可交换的位置依次是：0→1,3、1→0,2,4、2→1,5、3→0,4、4→1,3,5、5→2,4。

完整过程

  1. 将 board 按行压平为起点字符串 start，目标固定为 "123450"。
  2. 如果 start 已经等于目标，直接返回 0。
  3. 把起点加入队列和访问集合。变量 steps 表示当前 BFS 层到起点的距离。
  4. 逐层取出状态，找到字符 '0' 的下标，并根据邻接表枚举所有合法交换。
  5. 每个未访问的新状态只入队一次；生成目标状态时返回 steps + 1。
  6. 如果队列耗尽仍未见目标，说明起点与目标不连通，返回 -1。

正确性证明

  1. 转移完整：邻接表恰好列出每个位置在 2 × 3 棋盘上的所有四方向邻居，因此算法生成且仅生成合法的一步移动。
  2. 层数含义：起点位于第 0 层。若某状态位于第 d 层，它的所有新邻居都通过一次移动进入第 d + 1 层。
  3. 最短性：BFS 按距离从小到大处理状态。所以第一次到达目标时，不可能还存在步数更少但尚未处理的路径。
  4. 无解判定：队列耗尽意味着起点所在连通分量内的所有可达状态都已访问；若其中没有目标，则目标不可达。

因此算法返回的正整数一定是最少移动次数；不可达时正确返回 -1。

边界情况

  • 初始状态就是 [[1,2,3],[4,5,0]]：答案为 0。
  • 空格位于角落：只有 2 个合法邻居。
  • 空格位于上排或下排中间：有 3 个合法邻居。
  • 状态无解：访问集合阻止环路，最终队列会正常耗尽。
  • 交换后又立刻换回：旧状态已被访问，不会重复入队。

复杂度

时间 O(6! × 6)最多 720 种排列；复制或编码单个状态需要 O(6)。
空间 O(6! × 6)队列与访问集合最多保存全部状态及其长度 6 的编码。

由于棋盘大小固定，也可以把两者视为常数；写成阶乘形式更能说明状态空间来源。

替代方案

  • 双向 BFS：同时从起点与目标扩展，理论上能减少搜索前沿；本题状态仅 720 个，普通 BFS 更直接。
  • A*：用曼哈顿距离等启发式引导搜索，适合更大的滑块拼图；这里实现成本高于收益。
  • 预处理：从目标反向 BFS，预先记录全部可达状态的距离。大量查询同一尺寸棋盘时很合适。
  • 逆序奇偶性：可先判断可解性，但即使判定可解，仍需搜索最少步数。

四语言完整代码

以下实现均使用相同的压平编码、位置邻接表与逐层 BFS。

Java 
import java.util.*;

class Solution {
    public int slidingPuzzle(int[][] board) {
        StringBuilder builder = new StringBuilder();
        for (int[] row : board) {
            for (int value : row) {
                builder.append(value);
            }
        }

        String start = builder.toString();
        String target = "123450";
        if (start.equals(target)) {
            return 0;
        }

        int[][] neighbors = {
            {1, 3},
            {0, 2, 4},
            {1, 5},
            {0, 4},
            {1, 3, 5},
            {2, 4}
        };

        Queue<String> queue = new ArrayDeque<>();
        Set<String> visited = new HashSet<>();
        queue.offer(start);
        visited.add(start);

        int steps = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) {
                String current = queue.poll();
                if (current.equals(target)) {
                    return steps;
                }

                int zero = current.indexOf('0');
                for (int next : neighbors[zero]) {
                    char[] chars = current.toCharArray();
                    char temp = chars[zero];
                    chars[zero] = chars[next];
                    chars[next] = temp;
                    String candidate = new String(chars);

                    if (visited.add(candidate)) {
                        queue.offer(candidate);
                    }
                }
            }
            steps++;
        }

        return -1;
    }
}
JavaScript 
/**
 * @param {number[][]} board
 * @return {number}
 */
var slidingPuzzle = function(board) {
    const start = board.flat().join("");
    const target = "123450";

    if (start === target) {
        return 0;
    }

    const neighbors = [
        [1, 3],
        [0, 2, 4],
        [1, 5],
        [0, 4],
        [1, 3, 5],
        [2, 4]
    ];

    const queue = [start];
    const visited = new Set([start]);
    let head = 0;
    let steps = 0;

    while (head < queue.length) {
        const levelEnd = queue.length;

        while (head < levelEnd) {
            const current = queue[head++];
            if (current === target) {
                return steps;
            }

            const zero = current.indexOf("0");
            for (const next of neighbors[zero]) {
                const chars = current.split("");
                [chars[zero], chars[next]] = [chars[next], chars[zero]];
                const candidate = chars.join("");

                if (!visited.has(candidate)) {
                    visited.add(candidate);
                    queue.push(candidate);
                }
            }
        }

        steps++;
    }

    return -1;
};
Python 3 
from collections import deque
from typing import List


class Solution:
    def slidingPuzzle(self, board: List[List[int]]) -> int:
        start = "".join(str(value) for row in board for value in row)
        target = "123450"

        if start == target:
            return 0

        neighbors = (
            (1, 3),
            (0, 2, 4),
            (1, 5),
            (0, 4),
            (1, 3, 5),
            (2, 4),
        )

        queue = deque([start])
        visited = {start}
        steps = 0

        while queue:
            for _ in range(len(queue)):
                current = queue.popleft()
                if current == target:
                    return steps

                zero = current.index("0")
                for nxt in neighbors[zero]:
                    chars = list(current)
                    chars[zero], chars[nxt] = chars[nxt], chars[zero]
                    candidate = "".join(chars)

                    if candidate not in visited:
                        visited.add(candidate)
                        queue.append(candidate)

            steps += 1

        return -1
C++ 
#include <array>
#include <queue>
#include <string>
#include <unordered_set>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    int slidingPuzzle(vector<vector<int>>& board) {
        string start;
        for (const auto& row : board) {
            for (int value : row) {
                start.push_back(static_cast<char>('0' + value));
            }
        }

        const string target = "123450";
        if (start == target) {
            return 0;
        }

        const array<vector<int>, 6> neighbors = {{
            {1, 3},
            {0, 2, 4},
            {1, 5},
            {0, 4},
            {1, 3, 5},
            {2, 4}
        }};

        queue<string> states;
        unordered_set<string> visited;
        states.push(start);
        visited.insert(start);

        int steps = 0;
        while (!states.empty()) {
            int levelSize = static_cast<int>(states.size());

            while (levelSize-- > 0) {
                string current = states.front();
                states.pop();

                if (current == target) {
                    return steps;
                }

                int zero = static_cast<int>(current.find('0'));
                for (int next : neighbors[zero]) {
                    string candidate = current;
                    swap(candidate[zero], candidate[next]);

                    if (visited.insert(candidate).second) {
                        states.push(candidate);
                    }
                }
            }

            ++steps;
        }

        return -1;
    }
};

面试追问

  • 为什么 DFS 不能自然保证最短步数？
  • 如果棋盘扩大到 3 × 3，状态数量和搜索成本如何变化？
  • 双向 BFS 的两个访问集合如何判断相遇？
  • A* 中曼哈顿距离为什么可以作为可采纳启发式？
  • 如何把状态编码成一个整数，减少字符串开销？
  • 如果需要回答十万次查询，如何利用从目标出发的预处理？

常见错误

  • 把同一行末尾与下一行开头误判为左右相邻，例如下标 2 与 3。
  • 入队时不立刻标记访问，导致同一状态被多次加入队列。
  • 逐个节点递增步数，而不是处理完一整层再加 1。
  • 原地交换后忘记复原，污染后续邻居的生成。
  • 使用数组对象本身判重，却没有稳定的值编码。
  • 只判断能否到达，忘记题目要求的是最少移动次数。
