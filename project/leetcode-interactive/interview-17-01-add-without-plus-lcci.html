Problem brief

题意

设计函数计算两个整数 a 与 b 的和，但不能使用 + 或其他算术运算符。

官方约束
  • a、b 都可能为负数或 0。
  • 最终结果保证不会溢出 32 位有符号整数。

页面中的二进制轨道显示 32 位运算的低 8 位观察窗；负数按二进制补码处理，实际算法仍在完整 32 位上运行。

Interview solution

题解

核心洞察

a ^ b 等价于逐位相加但忽略进位；(a & b) << 1 恰好得到所有进位。把前者作为新的 a、后者作为新的 b，重复到 b == 0，此时 a 就是答案。

完整过程

  1. 计算 sum = a ^ b，得到不进位和。
  2. 计算 carry = (a & b) << 1，得到下一轮进位。
  3. 令 a = sum、b = carry。
  4. 当进位为 0 时返回 a。

边界与复杂度

  • 0 与任意数：首轮进位就是 0，直接得到另一操作数。
  • 负数：32 位补码让 XOR、AND 与左移仍保持同一加法规律。
  • 连续进位：例如 15 + 17 会多轮传播，但最多 32 轮。
  • 时间复杂度 O(1)，因为最多处理固定 32 位；额外空间 O(1)。

替代方案取舍

可以递归调用 add(a ^ b, (a & b) << 1)，表达更短，但面试中迭代版更容易说明终止条件，也避免递归栈。逐位模拟全加器更接近硬件，却需要更多位级状态，不是本题首选。

面试追问

  • 为什么 XOR 是“不进位和”，AND 左移是进位？
  • 为什么负数补码也能沿用同一循环？
  • Python 的整数没有固定位宽，为什么必须加 32 位掩码？
  • 若结果可能溢出 32 位，接口应该怎样定义？

常见错误

  • 先更新 a，再用新 a 计算 carry，破坏同轮输入。
  • 忘记把 a & b 左移一位。
  • Python 不加掩码，负数的无限符号扩展导致循环不终止。
  • C++ 直接左移负的有符号整数，触发未定义行为。

四语言可提交代码

class Solution {
    public int add(int a, int b) {
        while (b != 0) {
            int sum = a ^ b;
            int carry = (a & b) << 1;
            a = sum;
            b = carry;
        }
        return a;
    }
}
/**
 * @param {number} a
 * @param {number} b
 * @return {number}
 */
var add = function (a, b) {
    a |= 0;
    b |= 0;

    while (b !== 0) {
        const sum = (a ^ b) | 0;
        const carry = ((a & b) << 1) | 0;
        a = sum;
        b = carry;
    }
    return a;
};
class Solution:
    def add(self, a: int, b: int) -> int:
        mask = 0xFFFFFFFF
        max_int = 0x7FFFFFFF
        a &= mask
        b &= mask

        while b:
            value = (a ^ b) & mask
            carry = ((a & b) << 1) & mask
            a, b = value, carry

        return a if a <= max_int else ~(a ^ mask)
class Solution {
public:
    int add(int a, int b) {
        unsigned int x = static_cast<unsigned int>(a);
        unsigned int y = static_cast<unsigned int>(b);

        while (y != 0U) {
            unsigned int sum = x ^ y;
            unsigned int carry = (x & y) << 1U;
            x = sum;
            y = carry;
        }
        return static_cast<int>(x);
    }
};
