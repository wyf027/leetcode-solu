    SOLUTION VAULT

    题解已锁定

    枚举翻倍次数

    核心洞察

    如果先翻倍 x 次，之后带宽就是 2ˣ。再下载 ⌈n / 2ˣ⌉ 分钟，总时间为 x + ⌈n / 2ˣ⌉。因为 n ≤ 10⁵，所以只需枚举至多 17 个 x；这个范围足够小，也避免把并非总成立的简化公式当成答案。

    完整过程

    1. 从带宽 1 开始枚举翻倍次数。
    2. 计算剩余下载分钟数的向上取整。
    3. 记录最小总分钟数和对应策略。

    边界

    n=1 时无需翻倍，直接下载 1 分钟。下载允许超额，所以不需要凑出精确数量。

    复杂度

    枚举写法时间 O(log n)，空间 O(1)。

    替代方案

    也可用公式直接求位数；枚举法更直观，并自然产出可演示的策略。

    面试追问

    若每次翻倍需要不同成本，公式不再成立，但枚举每个候选带宽仍是起点。

    常见错误

    误以为必须恰好下载 n 个，或把翻倍当作即时下载一次。翻倍分钟只改变后续带宽。

    int answer = n;

      answer = Math.min(answer, doubled + (n + bw - 1) / bw);
    }
    return answer;
  }
}
