KMP 回文前缀拼图

只能把字符加在前面。于是问题变成：原串开头已经有多长的回文？把其余后缀反转并贴到左边即可。KMP 能在线性时间找到这个最长前缀。

题意

给定字符串 s。你只能在它前面添加字符，使其变为回文串；返回能得到的最短回文串。

官方样例 1
s = "aacecaaa"
输出："aaacecaaa"
官方样例 2
s = "abcd"
输出："dcbabcd"

约束：s.length ≤ 5 × 10⁴，仅含小写英文字母；空串也合法。

interview answer

题解：KMP 的前缀函数

O(n)

核心洞察

令 r = reverse(s)，构造 t = s + "#" + r。t 的最后一个前缀函数值 L 同时是 s 的前缀、r 的后缀；后者反转回来正是 s 的回文前缀。因此 L 就是最长回文前缀长度。

完整过程

  1. 反转 s 并用不会出现的分隔符拼接。
  2. 线性计算 t 的 KMP 前缀函数 pi。
  3. L = pi[t.length - 1]。
  4. 把 s.substring(L) 反转，拼在 s 前面。

边界与复杂度

空串直接返回空串；长度一已是回文。分隔符必须不在字母表中，否则可能产生越界匹配。

时间：O(n)
空间：O(n)

替代方案取舍

从最长前缀开始逐段判回文，最坏 O(n²)，5×10⁴ 会超时。Manacher 也可在线性时间得到最长回文前缀，但 KMP 的构造更短、更贴合“前缀与反串后缀相同”。

常见错误

  • 把最长回文子串当成答案；只能保留原串的前缀。
  • 漏掉分隔符，导致匹配可以跨越 s 与 reverse(s) 的边界。
  • 把后缀直接拼前面而没有反转。
  • 空串时访问 pi 的最后一项。

面试追问

为什么 L 对应回文？ 它既是 s 的前缀，也等于 reverse(s) 的后缀；反转第二个等式，便得到该前缀等于自身反转。
能用滚动哈希吗？ 可以二分前缀长度并比哈希，但存在碰撞或需要双哈希；KMP 是确定性解法。

class Solution {
    public String shortestPalindrome(String s) {
        String reversed = new StringBuilder(s).reverse().toString();
        String combined = s + "#" + reversed;
        int[] pi = new int[combined.length()];
        for (int i = 1; i < combined.length(); i++) {
            int j = pi[i - 1];
            while (j > 0 && combined.charAt(i) != combined.charAt(j)) j = pi[j - 1];
            if (combined.charAt(i) == combined.charAt(j)) j++;
            pi[i] = j;
        }
        return new StringBuilder(s.substring(pi[combined.length() - 1])).reverse() + s;
    }
}

var shortestPalindrome = function (s) {
  const reversed = [...s].reverse().join('');
  const t = s + '#' + reversed, pi = Array(t.length).fill(0);
  for (let i = 1; i < t.length; i++) {
    let j = pi[i - 1];
    while (j > 0 && t[i] !== t[j]) j = pi[j - 1];
    if (t[i] === t[j]) j++;
    pi[i] = j;
  }
  return [...s.slice(pi.at(-1))].reverse().join('') + s;
};
class Solution:
    def shortestPalindrome(self, s: str) -> str:
        t = s + '#' + s[::-1]
        pi = [0] * len(t)
        for i in range(1, len(t)):
            j = pi[i - 1]
            while j and t[i] != t[j]:
                j = pi[j - 1]
            if t[i] == t[j]:
                j += 1
            pi[i] = j
        return s[pi[-1]:][::-1] + s
class Solution {
public:
    std::string shortestPalindrome(std::string s) {
        std::string reversed = s;
        std::reverse(reversed.begin(), reversed.end());
        std::string t = s + "#" + reversed;
        std::vector<int> pi(t.size());
        for (int i = 1; i < (int)t.size(); ++i) {
            int j = pi[i - 1];
            while (j > 0 && t[i] != t[j]) j = pi[j - 1];
            if (t[i] == t[j]) ++j;
            pi[i] = j;
        }
        std::string add = s.substr(pi.back());
        std::reverse(add.begin(), add.end());
        return add + s;
    }
};
