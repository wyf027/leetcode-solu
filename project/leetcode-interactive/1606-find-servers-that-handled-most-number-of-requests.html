01题目

有 k 台编号为 0 到 k - 1 的服务器。每台服务器同一时刻最多处理一个请求。第 i 个请求在 arrival[i] 到达，需要连续处理 load[i] 个时间单位。

请求优先寻找编号 i % k 的服务器；若它正忙，就沿编号递增方向寻找下一台空闲服务器，越过 k - 1 后回到 0。若全部服务器都忙，请求被丢弃。返回成功处理请求数最多的全部服务器编号，顺序任意。

函数签名
busiestServers(k, arrival, load)
输入
整数 + 两个等长数组
输出
最忙服务器 ID 列表

约束

  • 1 ≤ k ≤ 10⁵
  • 1 ≤ arrival.length = load.length ≤ 10⁵
  • 1 ≤ arrival[i], load[i] ≤ 10⁹
  • arrival 严格递增。

06题解：释放繁忙服务器，再找环上后继

核心洞察：每个请求只需要两类查询：哪些繁忙服务器已经完成，以及从 i % k 开始的第一台空闲服务器是谁。分别用按完成时间排序的最小堆和支持后继查询的有序集合完成。

完整过程

  1. 将全部服务器放入有序集合 available。最小堆 busy 保存 (finishTime, serverId)，计数数组初始为 0。
  2. 处理请求 i 前，释放所有 finishTime ≤ arrival[i] 的服务器。
  3. 若集合为空则丢弃；否则查找第一项 ≥ i % k，若不存在则回绕到集合最小项。
  4. 删除被选服务器，压入新完成时间，并增加处理计数。
  5. 扫描计数，返回等于最大值的所有服务器。

正确性

不变式一 · 空闲集合准确

释放所有完成时间不晚于当前到达时刻的堆元素后，堆中服务器仍忙，集合中的服务器恰好空闲。

不变式二 · 环形选择准确

集合中第一项 ≥ i % k 是向后遇到的第一台空闲服务器；不存在时取最小项，正好对应回绕。

因此每一步要么在无空闲服务器时正确丢弃，要么分配给规则指定的服务器。归纳可知模拟完全符合题意；最终最大计数对应的全部服务器就是答案。

边界

  • finishTime == arrival[i] 时服务器已可用，释放条件必须是 ≤。
  • 后继不存在时必须回绕取空闲集合首项。
  • 完成时间最大约 2 × 10⁹；Java 使用 long 更稳妥。
  • k = 1、大量丢弃和多个并列答案均无需额外特判。

复杂度

设请求数为 n。每个请求至多入堆、出堆各一次，集合操作为 O(log k)，总时间 O(n log k)，空间 O(k)。

替代方案

线性扫描不可行：每个请求最多检查 k 台服务器会退化至 O(nk)。树状数组维护空闲标记也能达到 O(n log k)，适合缺少有序集合的语言。

四语言完整代码

JavaTreeSet + PriorityQueue
import java.util.*;

class Solution {
    public List<Integer> busiestServers(int k, int[] arrival, int[] load) {
        TreeSet<Integer> free = new TreeSet<>();
        for (int s = 0; s < k; s++) free.add(s);
        PriorityQueue<long[]> busy =
            new PriorityQueue<>(Comparator.comparingLong(x -> x[0]));
        int[] count = new int[k];

        for (int i = 0; i < arrival.length; i++) {
            while (!busy.isEmpty() && busy.peek()[0] <= arrival[i]) {
                free.add((int) busy.poll()[1]);
            }
            if (free.isEmpty()) continue;
            Integer server = free.ceiling(i % k);
            if (server == null) server = free.first();
            free.remove(server);
            count[server]++;
            busy.offer(new long[]{(long) arrival[i] + load[i], server});
        }

        int best = 0;
        for (int value : count) best = Math.max(best, value);
        List<Integer> answer = new ArrayList<>();
        for (int s = 0; s < k; s++) if (count[s] == best) answer.add(s);
        return answer;
    }
}
JavaScriptFenwick + MinHeap
class MinHeap {
  constructor() { this.a = []; }
  get size() { return this.a.length; }
  peek() { return this.a[0]; }
  push(x) {
    const a = this.a; a.push(x);
    let i = a.length - 1;
    while (i) {
      const p = (i - 1) >> 1;
      if (a[p][0] <= x[0]) break;
      a[i] = a[p]; i = p;
    }
    a[i] = x;
  }
  pop() {
    const a = this.a, root = a[0], last = a.pop();
    if (a.length) {
      let i = 0;
      while (i * 2 + 1 < a.length) {
        let c = i * 2 + 1;
        if (c + 1 < a.length && a[c + 1][0] < a[c][0]) c++;
        if (a[c][0] >= last[0]) break;
        a[i] = a[c]; i = c;
      }
      a[i] = last;
    }
    return root;
  }
}
class Fenwick {
  constructor(n) { this.n = n; this.t = Array(n + 1).fill(0); }
  add(i, delta) { for (i++; i <= this.n; i += i & -i) this.t[i] += delta; }
  sum(i) {
    let value = 0;
    for (i++; i > 0; i -= i & -i) value += this.t[i];
    return value;
  }
  lowerBound(target) {
    let index = 0, step = 1;
    while ((step << 1) <= this.n) step <<= 1;
    for (; step; step >>= 1) {
      const next = index + step;
      if (next <= this.n && this.t[next] < target) {
        index = next; target -= this.t[next];
      }
    }
    return index;
  }
}
var busiestServers = function(k, arrival, load) {
  const free = new Fenwick(k), busy = new MinHeap();
  const count = Array(k).fill(0);
  for (let s = 0; s < k; s++) free.add(s, 1);

  for (let i = 0; i < arrival.length; i++) {
    while (busy.size && busy.peek()[0] <= arrival[i]) {
      free.add(busy.pop()[1], 1);
    }
    const total = free.sum(k - 1);
    if (!total) continue;
    const preferred = i % k;
    const before = preferred ? free.sum(preferred - 1) : 0;
    const rank = before < total ? before + 1 : 1;
    const server = free.lowerBound(rank);
    free.add(server, -1);
    count[server]++;
    busy.push([arrival[i] + load[i], server]);
  }

  const best = Math.max(...count), answer = [];
  count.forEach((value, server) => {
    if (value === best) answer.push(server);
  });
  return answer;
};
Python 3Fenwick + heapq
from typing import List
import heapq

class Fenwick:
    def __init__(self, n: int):
        self.n, self.tree = n, [0] * (n + 1)

    def add(self, index: int, delta: int) -> None:
        index += 1
        while index <= self.n:
            self.tree[index] += delta
            index += index & -index

    def prefix(self, index: int) -> int:
        total, index = 0, index + 1
        while index:
            total += self.tree[index]
            index -= index & -index
        return total

    def lower_bound(self, target: int) -> int:
        index = 0
        step = 1 << (self.n.bit_length() - 1)
        while step:
            nxt = index + step
            if nxt <= self.n and self.tree[nxt] < target:
                index, target = nxt, target - self.tree[nxt]
            step >>= 1
        return index

class Solution:
    def busiestServers(
        self, k: int, arrival: List[int], load: List[int]
    ) -> List[int]:
        free, busy = Fenwick(k), []
        count = [0] * k
        for server in range(k):
            free.add(server, 1)

        for i, start in enumerate(arrival):
            while busy and busy[0][0] <= start:
                _, server = heapq.heappop(busy)
                free.add(server, 1)
            total = free.prefix(k - 1)
            if total == 0:
                continue
            preferred = i % k
            before = free.prefix(preferred - 1) if preferred else 0
            rank = before + 1 if before < total else 1
            server = free.lower_bound(rank)
            free.add(server, -1)
            count[server] += 1
            heapq.heappush(busy, (start + load[i], server))

        best = max(count)
        return [i for i, value in enumerate(count) if value == best]
C++set + priority_queue
#include <algorithm>
#include <functional>
#include <queue>
#include <set>
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> busiestServers(
        int k, vector<int>& arrival, vector<int>& load
    ) {
        set<int> free;
        for (int s = 0; s < k; ++s) free.insert(s);
        using Job = pair<long long, int>;
        priority_queue<Job, vector<Job>, greater<Job>> busy;
        vector<int> count(k);

        for (int i = 0; i < (int) arrival.size(); ++i) {
            while (!busy.empty() && busy.top().first <= arrival[i]) {
                free.insert(busy.top().second);
                busy.pop();
            }
            if (free.empty()) continue;
            auto it = free.lower_bound(i % k);
            if (it == free.end()) it = free.begin();
            int server = *it;
            free.erase(it);
            ++count[server];
            busy.push({(long long) arrival[i] + load[i], server});
        }

        int best = *max_element(count.begin(), count.end());
        vector<int> answer;
        for (int s = 0; s < k; ++s)
            if (count[s] == best) answer.push_back(s);
        return answer;
    }
};

常见错误

  • 只检查 i % k，忘记继续向后搜索或回绕。
  • 释放条件写成严格小于，漏掉恰好完成的服务器。
  • 服务器空闲时重复加入结构，导致同一服务器被同时分配。
  • 堆按服务器编号而非完成时间排序。
  • 只返回一个最大值服务器，遗漏并列答案。

面试追问

为什么需要两种数据结构？

“谁先结束”按时间排序，“从某编号开始谁先空闲”按服务器编号排序，是两个不同的序。

能否只维护结束时间？

能判断单台是否空闲，但寻找环上第一台空闲服务器仍可能退化为线性扫描。

如果服务器容量不同呢？

需要重新定义可用状态和选择优先级；时间事件与选择顺序仍应分别维护。
