3931. 检查相邻数字差

给定只由数字组成的字符串 s。只要每一对相邻数字的绝对差都不超过 2，就返回 true；一旦发现差值大于 2，立即返回 false。

逐对检查

准备检查

按 Enter 或点击“开始”重置。空格会被忽略；题目约束是长度至少为 2。

尚未开始。

键盘：← / → 前后步，空格自动播放，Esc 停止。

题意与示例

差值阈值 = 2

示例一
s = "132"：|1−3| = 2、|3−2| = 1，因此输出 true。
示例二
s = "129"：第二对 |2−9| = 7，超过 2，因此输出 false。
约束
2 ≤ s.length ≤ 100，且 s 只含数字。

Solution

一次线性扫描

核心洞察

字符 s[i] 与 s[i-1] 的码点差等于数字差；转换成数字后取绝对值。所有相邻对互不依赖，所以找到第一对非法差值就能提前结束。

完整过程

  1. 从下标 1 开始遍历。
  2. 计算 |(s[i]-'0')-(s[i-1]-'0')|。
  3. 若结果大于 2，返回 false；循环结束后返回 true。

边界与复杂度

长度正好为 2 时只检查一对；差值正好为 2 合法。时间 O(n)，额外空间 O(1)。

替代方案与追问

可用相邻 zip / 流式 API 表达同一逻辑，但不比循环更省空间。追问：若阈值改为 k，只需将常数 2 改成 k。

常见错误

  • 比较字符的字典序，而非差值。
  • 漏掉绝对值，导致递减数字被误判。
  • 把“至多 2”错写为严格小于 2。
