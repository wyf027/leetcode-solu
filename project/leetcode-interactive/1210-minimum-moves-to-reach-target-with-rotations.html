穿过迷宫的
最少移动次数

一条长度固定为 2 的蛇，要在障碍网格里平移、旋转，并以水平姿态抵达右下角。先理解规则，再亲手重放一条合法路线。

Minimum Moves to Reach Target with Rotations非付费题n ≤ 100
Problem

题意与移动规则

给定一个 n × n 的二进制网格 grid：0 表示空格，1 表示障碍。蛇占据相邻的两个格子，初始水平位于 (0,0) 与 (0,1)，目标是水平占据 (n-1,n-2) 与 (n-1,n-1)。

每次操作计作一步；若无法到达目标，返回 -1。

向右：保持当前朝向，蛇整体右移一格；新占据的格子必须为空。
向下：保持当前朝向，蛇整体下移一格；新占据的格子必须为空。
顺时针旋转：蛇水平时，若正下方两个格子都为空，则绕左端点转为竖直。
逆时针旋转：蛇竖直时，若正右方两个格子都为空，则绕上端点转为水平。

Solution

把蛇压缩成一个状态

核心洞察

蛇长度恒为 2，所以不必保存两个任意坐标。用左端点（水平）或上端点（竖直）作为锚点，再加一个朝向即可唯一描述状态：

(r, c, 0) 表示水平占据 (r,c)、(r,c+1)；(r, c, 1) 表示竖直占据 (r,c)、(r+1,c)。

每种合法操作的代价都为 1，因此从起点逐层扩展，第一次到达目标时的层数就是最少移动次数。

状态与目标

  • 起点：(0, 0, 0)
  • 终点：(n-1, n-2, 0)
  • 状态总数最多：2n²
  • 访问标记：visited[r][c][orientation]

关键不是“蛇头走到哪里”，而是两个格子的整体姿态是否首次出现。

Process

完整过程

初始化队列。
将起点 (0,0,0) 入队并标记访问，距离为 0。
取出一个状态。
若它等于目标状态，立即返回当前距离。
按朝向生成平移。
水平蛇可检查右侧一个新格与下方两个格；竖直蛇可检查下方一个新格与右侧两个格。
复用 2×2 空区检查旋转。
水平蛇下方两格为空即可顺时针转为竖直；竖直蛇右侧两格为空即可逆时针转为水平。
只入队新状态。
每个合法且未访问的状态以距离加一入队；队列耗尽仍未到达则返回 -1。
Transitions

转移条件速查

当前朝向动作必须为空新状态
水平 0向右(r,c+2)(r,c+1,0)
水平 0向下(r+1,c)、(r+1,c+1)(r+1,c,0)
水平 0顺时针旋转(r+1,c)、(r+1,c+1)(r,c,1)
竖直 1向下(r+2,c)(r+1,c,1)
竖直 1向右(r,c+1)、(r+1,c+1)(r,c+1,1)
竖直 1逆时针旋转(r,c+1)、(r+1,c+1)(r,c,0)
Correctness

正确性证明

引理 1：算法从任一已到达状态生成的，恰好是题目规则允许的一步后继。因为每个分支都同时检查边界、动作扫过的全部格子与对应朝向；反之，四类合法动作都被水平或竖直分支覆盖。

引理 2：队列中某状态第一次出队时，其记录距离是从起点到该状态的最短距离。初始状态距离为 0；按先进先出顺序，距离为 d 的状态总在距离为 d+1 的状态之前扩展，且已访问状态不会被更长路线覆盖。

定理：若算法返回某个距离，它是到目标的最少移动次数。由引理 1，该路线合法；由引理 2，首次到达目标的距离最短。若队列耗尽，则所有从起点可达的状态均已探索而目标不在其中，因此返回 -1 正确。

Edges & Complexity

边界与复杂度

边界情况

  • n = 2 时，若底行为空，只需向下一步。
  • 目标两格可为空但仍可能被障碍完全隔断，此时返回 -1。
  • 旋转必须检查完整的 2×2 区域，不能只检查旋转后的新尾格。
  • 访问标记必须包含朝向；同一锚点的水平与竖直是两个不同状态。

复杂度

至多有 2n² 个状态，每个状态检查常数个转移：

  • 时间复杂度：O(n²)
  • 空间复杂度：O(n²)

import java.util.*;

class Solution {
    public int minimumMoves(int[][] grid) {
        int n = grid.length;
        boolean[][][] seen = new boolean[n][n][2];
        Deque<int[]> queue = new ArrayDeque<>();
        queue.offer(new int[]{0, 0, 0, 0});
        seen[0][0][0] = true;

        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int r = cur[0], c = cur[1], dir = cur[2], dist = cur[3];
            if (r == n - 1 && c == n - 2 && dir == 0) return dist;

            if (dir == 0) {
                if (c + 2 < n && grid[r][c + 2] == 0)
                    add(queue, seen, r, c + 1, 0, dist + 1);
                if (r + 1 < n && grid[r + 1][c] == 0 && grid[r + 1][c + 1] == 0) {
                    add(queue, seen, r + 1, c, 0, dist + 1);
                    add(queue, seen, r, c, 1, dist + 1);
                }
            } else {
                if (r + 2 < n && grid[r + 2][c] == 0)
                    add(queue, seen, r + 1, c, 1, dist + 1);
                if (c + 1 < n && grid[r][c + 1] == 0 && grid[r + 1][c + 1] == 0) {
                    add(queue, seen, r, c + 1, 1, dist + 1);
                    add(queue, seen, r, c, 0, dist + 1);
                }
            }
        }
        return -1;
    }

    private void add(Deque<int[]> queue, boolean[][][] seen,
                     int r, int c, int dir, int dist) {
        if (!seen[r][c][dir]) {
            seen[r][c][dir] = true;
            queue.offer(new int[]{r, c, dir, dist});
        }
    }
}

from collections import deque

class Solution:
    def minimumMoves(self, grid: List[List[int]]) -> int:
        n = len(grid)
        seen = [[[False, False] for _ in range(n)] for _ in range(n)]
        queue = deque([(0, 0, 0, 0)])
        seen[0][0][0] = True

        def add(r: int, c: int, direction: int, distance: int) -> None:
            if not seen[r][c][direction]:
                seen[r][c][direction] = True
                queue.append((r, c, direction, distance))

        while queue:
            r, c, direction, distance = queue.popleft()
            if (r, c, direction) == (n - 1, n - 2, 0):
                return distance

            if direction == 0:
                if c + 2 < n and grid[r][c + 2] == 0:
                    add(r, c + 1, 0, distance + 1)
                if (r + 1 < n and grid[r + 1][c] == 0
                        and grid[r + 1][c + 1] == 0):
                    add(r + 1, c, 0, distance + 1)
                    add(r, c, 1, distance + 1)
            else:
                if r + 2 < n and grid[r + 2][c] == 0:
                    add(r + 1, c, 1, distance + 1)
                if (c + 1 < n and grid[r][c + 1] == 0
                        and grid[r + 1][c + 1] == 0):
                    add(r, c + 1, 1, distance + 1)
                    add(r, c, 0, distance + 1)

        return -1

Trade-offs

替代方案与常见错误

替代方案

  • DFS / 回溯：能判断可达性，但需要枚举大量路线，且不能自然保证最短。
  • Dijkstra：可以求最短路，但本题边权全为 1，优先队列是多余开销。
  • A*：可设计启发函数减少探索，但正确实现更复杂，n ≤ 100 时普通 BFS 已足够。

常见错误

  • 把蛇头坐标当成完整状态，丢失尾部与朝向。
  • 右移或下移时只检查一个格子，却忽略竖直/水平姿态需要的两个新位置。
  • 旋转只检查落点，未检查旋转扫过的完整 2×2 区域。
  • 入队后才延迟标记访问，导致同一状态被重复入队。
  • 把目标误写成竖直状态或锚点 (n-1,n-1)。
Interview Follow-ups

面试追问

如何返回一条具体的最短操作序列？

为每个首次访问的状态记录父状态与动作。到达终点后沿父指针反向回溯，再翻转动作列表。

如果旋转代价为 2、平移代价为 1 呢？

边权不再统一，应改用 Dijkstra；若边权只可能为 0 或 1，则可用 0-1 BFS。

如何统计最短路径条数？

同时维护每个状态的最短距离与方案数。发现更短距离时覆盖并继承方案数；发现相同最短距离时累加。

网格中的障碍会随时间变化怎么办？

把时间或障碍阶段纳入状态；若变化有周期，可只记录时间对周期取模，从而保持有限状态空间。
