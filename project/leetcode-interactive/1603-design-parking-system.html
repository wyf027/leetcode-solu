Problem

题意

停车场只有三类车位：大、中、小，每类在初始化时拥有固定数量的空位。现在要实现一个 ParkingSystem 类，逐次接收想进入停车场的车辆。

车辆类型 1、2、3 分别代表大车、中车、小车。每辆车只能停进与自身类型完全对应的车位：若仍有空位，就占用一个并返回 true；否则不改变停车场状态并返回 false。

构造器ParkingSystem(int big, int medium, int small) 方法bool addCar(int carType)
唯一匹配规则：大车不能占中、小车位；即使其他尺寸还有空位，也不能借用。

Solution

题解：用三个计数器保存状态

核心洞察

1
无需模拟具体车位，只需记录每类剩余数量。

请求类型已经确定唯一对应的计数器。查看该值是否大于 0，就能同时回答“能不能停”以及“成功后该更新哪里”。

完整过程

  1. 构造时把 big、medium、small 存入长度为 3（或为方便下标映射而长度为 4）的数组。
  2. 收到 carType 后定位对应的剩余计数。
  3. 若计数为 0，直接返回 false，状态不变。
  4. 否则将计数减 1，并返回 true。

正确性证明

不变式：在任意一次 addCar 调用前，数组中每个位置都等于对应车型尚未被占用的车位数。

初始化：构造器直接保存三类初始车位数，因此第一次调用前不变式成立。

保持：若目标计数为 0，算法拒绝车辆且不修改状态，剩余数量仍准确；若大于 0，车辆恰好占用一个同类型车位，算法也恰好把该计数减 1，其他类型不变，所以不变式继续成立。

结论：算法仅在对应类型确有空位时返回 true，并准确记录占用；因此每次返回值和停车状态都正确。

边界情况

  • 某类初始容量为 0：该类型的所有请求都立即失败。
  • 某类最后一个空位：本次成功并把计数变为 0，下一次同类请求失败。
  • 其他类型有空位：不能替代当前车型的目标车位。
  • 三类容量都达到 1000、调用也达到 1000：计数仍在普通整数安全范围内。

复杂度

每次 addCarO(1)一次索引、判断与可能的减法
额外空间O(1)固定保存三个整数

四种语言完整代码

class ParkingSystem {
    private final int[] spaces;

    public ParkingSystem(int big, int medium, int small) {
        spaces = new int[] {big, medium, small};
    }

    public boolean addCar(int carType) {
        int index = carType - 1;
        if (spaces[index] == 0) {
            return false;
        }
        spaces[index]--;
        return true;
    }
}
/**
 * @param {number} big
 * @param {number} medium
 * @param {number} small
 */
var ParkingSystem = function(big, medium, small) {
    this.spaces = [big, medium, small];
};

/**
 * @param {number} carType
 * @return {boolean}
 */
ParkingSystem.prototype.addCar = function(carType) {
    const index = carType - 1;
    if (this.spaces[index] === 0) {
        return false;
    }
    this.spaces[index]--;
    return true;
};
class ParkingSystem:
    def __init__(self, big: int, medium: int, small: int):
        self.spaces = [big, medium, small]

    def addCar(self, carType: int) -> bool:
        index = carType - 1
        if self.spaces[index] == 0:
            return False

        self.spaces[index] -= 1
        return True
class ParkingSystem {
private:
    int spaces[3];

public:
    ParkingSystem(int big, int medium, int small) {
        spaces[0] = big;
        spaces[1] = medium;
        spaces[2] = small;
    }

    bool addCar(int carType) {
        int index = carType - 1;
        if (spaces[index] == 0) {
            return false;
        }
        --spaces[index];
        return true;
    }
};

替代方案

可以保存“总容量”和“已使用数量”两组变量，再比较二者；也可以分别维护 big、medium、small 三个字段并用分支选择。它们同样是 O(1)，但数组把车型编号到存储位置的映射写得更直接，重复代码也更少。

面试追问

如果车型种类动态增加？

改用哈希表或按车型编号扩展的数组，键对应车型，值保存剩余数量。

如果允许大车位停小车？

问题会变成带优先级的资源分配；需要先定义策略，例如优先使用尺寸刚好匹配的最小车位。

如果多线程同时入场？

“检查后减一”必须成为原子操作，可使用锁或原子计数器，避免两个请求抢到最后一个车位。

如何支持车辆离场？

增加 removeCar(carType) 并把对应计数加一，同时防止超过初始容量。

常见错误

  • 忘记把 carType 从 1 起始转换为数组的 0 起始下标。
  • 先减再判断，导致无车位时出现负数。
  • 成功后没有持久更新成员变量，只修改了局部副本。
  • 错误地允许车辆使用其他尺寸仍空闲的车位。
