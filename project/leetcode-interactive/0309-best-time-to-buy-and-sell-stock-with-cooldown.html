Problem

题意

给定整数数组 prices，其中 prices[i] 表示第 i 天一支股票的价格。请计算能够获得的最大利润。

你可以完成任意多次买卖，但任何时刻最多持有一股；再次买入之前必须先卖出。每次卖出后的第二天不能买入，这一天是 1 天冷冻期。你可以选择不进行任何交易，因此答案不会小于 0。

示例 1

完整参数
输入：prices = [1,2,3,0,2]
输出：3
解释：[买入, 卖出, 冷冻, 买入, 卖出]
利润为 (2 - 1) + (2 - 0) = 3。

示例 2

最小规模
输入：prices = [1]
输出：0
解释：只有一天，无法完成一次买入与卖出。

约束

  • 1 <= prices.length <= 5000
  • 0 <= prices[i] <= 1000

Solution

动态规划：把冷冻期藏进状态转移

核心洞察

每天结束时，不必记住所有交易历史，只需知道当前属于哪一种互斥状态：hold（持股）、sold（今天刚卖出）、rest（空仓且今天没有卖出）。买入只能从前一天的 rest 发生，不能从 sold 发生；冷冻期因此自动得到保证。

hold

当天结束后仍持有一股。来源是继续持有，或从昨天 rest 买入。

sold

当天完成卖出。唯一来源是昨天 hold 加上今天价格。

rest

当天空仓且没有卖出。来源是继续休息，或承接昨天 sold 的冷冻。

完整过程

  1. 初始化：处理第 0 天前，hold = −∞、sold = −∞、rest = 0。两个负无穷表示尚不可达。
  2. 读取当天价格 p：newHold = max(hold, rest - p)，对应继续持有或合法买入。
  3. 计算卖出：newSold = hold + p。必须用更新前的 hold，避免同一天买入又卖出。
  4. 计算休息：newRest = max(rest, sold)。昨天刚卖出的人今天进入冷冻后的空仓状态。
  5. 滚动更新：用三个新值整体替换旧值。处理完所有天后，持股不是已实现利润，答案为 max(sold, rest)。
newHold = max(hold, rest - price)
newSold = hold + price
newRest = max(rest, sold)
answer  = max(sold, rest)

正确性证明

不变式：处理完第 i 天后，hold、sold、rest 分别是在各自状态约束下能够获得的最大利润。

基础情况：在任何交易日之前，空仓休息的利润为 0；持股和刚卖出都不可达，故初始化成立。

归纳步骤：假设第 i-1 天后不变式成立。第 i 天结束时，持股的所有合法方案只能是昨天已持股后不动，或昨天处于 rest 后今天买入；转移取二者最大值。今天刚卖出的所有合法方案必定由昨天持股并今天卖出得到。今天 rest 的所有合法方案只能来自昨天继续 rest，或昨天 sold 后今天不买入。三条转移完整且互斥地覆盖所有合法方案，所以各状态仍为最优。

终止：最终仍持股不算完成利润；所有合法空仓方案必在 sold 或 rest 中，因此 max(sold, rest) 就是全局最大利润。

复杂度与边界

时间复杂度

O(n)

每个价格只处理一次。

额外空间

O(1)

滚动保存三个状态。

  • 只有一天时无法完成交易，返回 0。
  • 价格持续下降时始终不交易，返回 0。
  • 价格可以为 0，买入不会产生负成本之外的特殊情况。
  • 实现负无穷哨兵时要避免再做可能溢出的算术；按官方约束也可从第 0 天状态开始初始化。

四种语言完整代码

均沿用同一套三状态滚动动态规划，签名与官方提交格式一致。

Java

LeetCode
class Solution {
    public int maxProfit(int[] prices) {
        int hold = -prices[0];
        int sold = Integer.MIN_VALUE / 2;
        int rest = 0;

        for (int i = 1; i < prices.length; i++) {
            int price = prices[i];
            int nextHold = Math.max(hold, rest - price);
            int nextSold = hold + price;
            int nextRest = Math.max(rest, sold);
            hold = nextHold;
            sold = nextSold;
            rest = nextRest;
        }

        return Math.max(sold, rest);
    }
}

class Solution:

            next_hold = max(hold, rest - price)

替代方案

二维 DP 数组

为每天保存三种状态，转移更直观，也方便回溯具体交易路径；时间仍为 O(n)，空间变为 O(n)。

两状态 + 隔日引用

hold[i] = max(hold[i-1], free[i-2] - price[i])，用 i-2 显式跳过冷冻日；状态更少，但边界下标更易写错。

常见错误

允许 sold → hold

这等于卖出后的第二天立即买入，直接违反冷冻期。

原地更新状态

后面的转移读到当天新值，可能制造同一天的非法连续操作。应先计算全部 next 状态。

最终返回 hold

持股只表示账面状态，尚未卖出，不能计入已实现答案。

把贪心套在相邻涨幅

一次卖出会封锁下一天买入，局部收割每段涨幅不一定全局最优。
