538. 把二叉搜索树
转换为累加树

先读题目

题目

给定一棵节点值互不相同的二叉搜索树 root。请原地修改这棵树：每个节点的新值，等于它的原值加上原树中所有严格大于它的节点值之和，并返回根节点。

二叉搜索树中，左子树的值更小、右子树的值更大，左右子树本身也满足这一性质。

函数签名

TreeNode convertBST(TreeNode root)

官方示例

示例 1
输入：root = [4,1,6,0,2,5,7,null,null,null,3,null,null,null,8]
输出：[30,36,21,36,35,26,15,null,null,null,33,null,null,null,8]
示例 2
输入：root = [0,null,1]
输出：[1,null,1]
示例 3
输入：root = [1,0,2]
输出：[3,3,2]
示例 4
输入：root = [3,2,4,1]
输出：[7,9,4,10]

约束

  • 节点数为 [0, 10⁴]。
  • -10⁴ ≤ Node.val ≤ 10⁴。
  • 所有节点值互不相同。
  • root 是合法二叉搜索树。

题解：反向中序 + 前缀累加

核心洞察

二叉搜索树按“右 → 根 → 左”遍历时，节点值从大到小出现。维护累加和 sum：访问节点时先把原值加入 sum，再用 sum 覆盖节点值。此刻累加和恰好包含当前值以及所有更大值。

完整过程

  1. 初始化 sum = 0。
  2. 递归处理右子树。
  3. 执行 sum += node.val，然后令 node.val = sum。
  4. 递归处理左子树，最终返回原根节点。

正确性说明

反向中序访问当前节点时，所有严格大于当前值的节点都已访问并计入 sum，所有更小节点都还未访问。加入当前原值后，sum 正好等于题目要求的新值。对每个节点重复该过程，因此整棵树均被正确转换。

边界与复杂度

  • 空树直接返回 null；单节点值保持不变；负数同样适用。
  • 时间复杂度 O(n)，每个节点访问一次。
  • 递归空间 O(h)，其中 h 是树高；最坏退化为 O(n)。

替代方案

可用显式栈迭代执行反向中序，避免语言调用栈溢出；也可用反向 Morris 遍历把额外空间降为 O(1)，但临时改线更难实现和解释。

Java

class Solution {
    private int sum = 0;
    public TreeNode convertBST(TreeNode root) {
        traverse(root);
        return root;
    }
    private void traverse(TreeNode node) {
        if (node == null) return;
        traverse(node.right);
        sum += node.val;
        node.val = sum;
        traverse(node.left);
    }
}

Python

class Solution:
    def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        total = 0
        def traverse(node):
            nonlocal total
            if node is None:
                return
            traverse(node.right)
            total += node.val
            node.val = total
            traverse(node.left)
        traverse(root)
        return root

C++

class Solution {
    int sum = 0;
    void traverse(TreeNode* node) {
        if (node == nullptr) return;
        traverse(node->right);
        sum += node->val;
        node->val = sum;
        traverse(node->left);
    }
public:
    TreeNode* convertBST(TreeNode* root) {
        traverse(root);
        return root;
    }
};

面试追问

  • 如何改成显式栈迭代？保持指针一路向右入栈，弹出后转向左子树。
  • 如何做到常数额外空间？使用反向 Morris 遍历，并在访问后恢复临时连接。
  • 递归实现有什么工程风险？高度接近 10⁴ 的退化树可能导致调用栈溢出。

常见错误

  • 按“左 → 根 → 右”遍历，得到的是较小值累加。
  • 先覆盖节点再把值加入总和，丢失原值。
  • 在每次递归调用中重新初始化累加和。
  • 误以为新树仍满足原 BST 的大小关系；题目只要求原树是 BST。
