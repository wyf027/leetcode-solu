Problem

先把规则钉牢

给定整数数组 matchsticks，其中第 i 个元素表示第 i 根火柴的长度。请使用全部火柴拼成一个正方形：火柴不能折断，可以首尾相接，并且每根必须恰好使用一次。

若能够拼成正方形，返回 true；否则返回 false。

函数形式
boolean makesquare(int[] matchsticks)
其他语言保持同样的单数组参数与布尔返回值。

约束

  • 1 <= matchsticks.length <= 15
  • 1 <= matchsticks[i] <= 108
  • 所有火柴必须被使用，且不能折断。
示例 1

输入：matchsticks = [1,1,2,2,2]

输出：true

解释：可拼成边长为 2 的正方形，其中一条边由两根长度为 1 的火柴组成。

示例 2

输入：matchsticks = [3,3,3,3,4]

输出：false

解释：不存在使用全部火柴组成四条等长边的方案。

Full Solution

降序回溯 + 对称剪枝

核心洞察：正方形等价于把所有火柴分配到 4 个容量均为 sum / 4 的桶中。每次处理一根火柴，状态只需记录四条边的当前长度。

完整过程

  1. 求总长度。若不能被 4 整除，立即返回 false。
  2. 将火柴按长度降序排序。若最长火柴超过目标边长，也立即失败。
  3. 从最长火柴开始，尝试把当前火柴放入任意一条不超容量的边。
  4. 递归处理下一根；若后续失败，就撤销本次放置。
  5. 若同一层的两条边当前长度相同，只尝试第一条，因为交换它们不会产生新方案。
  6. 当全部火柴都放完时，前三条边都达到目标即可；总和守恒保证第四条边也相等。

为什么先放长火柴

长火柴最难安置。优先处理它们能更早触发“超过目标边长”的剪枝，通常会显著缩小搜索树，但不改变可行解集合。

边界处理

  • 总和不能被 4 整除。
  • 最大值大于目标边长。
  • 大量重复长度：必须跳过同层等价边。
  • 所有数均为正数，因此无需处理零或负数。

正确性证明

1
搜索完备性。对每根火柴，算法依次考虑放入四条边的所有不超容量选择，因此任何合法分配都对应搜索树中的一条路径。
2
剪枝安全性。容量剪枝只排除边长超过目标的状态，它不可能扩展成合法正方形；同长度边剪枝只删除通过交换等价边得到的重复状态，至少保留一个代表。
3
成功条件充分。递归结束意味着每根火柴恰好使用一次；每条边从未超过目标，而总长度恰为四倍目标，所以四条边只能全部等于目标。
4
结论。算法返回 true 当且仅当存在一个使用所有火柴的正方形分配。
时间复杂度（最坏）
O(4n)

排序另需 O(n log n)，实际搜索受剪枝影响。

空间复杂度
O(n)

递归栈深度至多 n；四条边为常数空间。

import java.util.Arrays;

class Solution {
    public boolean makesquare(int[] matchsticks) {
        int sum = 0;
        for (int length : matchsticks) sum += length;
        if (sum % 4 != 0) return false;

        Arrays.sort(matchsticks);
        reverse(matchsticks);
        int target = sum / 4;
        if (matchsticks[0] > target) return false;

        return dfs(matchsticks, 0, new int[4], target);
    }

    private boolean dfs(int[] sticks, int index, int[] sides, int target) {
        if (index == sticks.length) {
            return sides[0] == target && sides[1] == target
                    && sides[2] == target && sides[3] == target;
        }

        int length = sticks[index];
        for (int side = 0; side < 4; side++) {
            if (sides[side] + length > target) continue;
            boolean duplicate = false;
            for (int previous = 0; previous < side; previous++) {
                if (sides[previous] == sides[side]) {
                    duplicate = true;
                    break;
                }
            }
            if (duplicate) continue;

            sides[side] += length;
            if (dfs(sticks, index + 1, sides, target)) return true;
            sides[side] -= length;
        }
        return false;
    }

    private void reverse(int[] values) {
        for (int left = 0, right = values.length - 1; left < right; left++, right--) {
            int temp = values[left];
            values[left] = values[right];
            values[right] = temp;
        }
    }
}

var makesquare = function (matchsticks) {
    const sum = matchsticks.reduce((total, length) => total + length, 0);
    if (sum % 4 !== 0) return false;

    matchsticks.sort((a, b) => b - a);
    const target = sum / 4;
    if (matchsticks[0] > target) return false;

    const sides = [0, 0, 0, 0];
    const dfs = (index) => {
        if (index === matchsticks.length) return true;

        const length = matchsticks[index];
        const seenLengths = new Set();
        for (let side = 0; side < 4; side++) {
            if (sides[side] + length > target) continue;
            if (seenLengths.has(sides[side])) continue;
            seenLengths.add(sides[side]);

            sides[side] += length;
            if (dfs(index + 1)) return true;
            sides[side] -= length;
        }
        return false;
    };

    return dfs(0);
};

替代方案：状态压缩 DP

用位掩码表示已经使用的火柴，记录当前一条边累计到的位置。状态数为 2^n，转移枚举下一根火柴，时间约为 O(n · 2^n)，空间为 O(2^n)。当需要稳定的理论上界时很合适；本题的降序回溯通常更直观。

常见错误

  • 只判断总和能否被 4 整除，却没有实际分组。
  • 没有使用全部火柴，或误以为火柴可以折断。
  • 不降序排序，导致失败分支很晚才暴露。
  • 跳过所有空边却没有保留第一个空边，造成漏解。
  • 回溯返回前忘记撤销边长。

面试追问

  • 为什么同边长状态可以跳过？ 四条边没有身份，当前长度相同的两条边交换后得到同构状态。
  • 能否只检查前三条边？ 可以。总和固定，前三条达到目标且所有火柴已使用时，第四条必然达到目标。
  • 若要拼成 k 边等长图形呢？ 将四个桶推广为 k 个桶；回溯结构不变，但分支数与对称性都增加。
  • 何时更偏向位掩码 DP？ 当 n 较小、需要可预测的状态上界或希望缓存大量重复子问题时。
