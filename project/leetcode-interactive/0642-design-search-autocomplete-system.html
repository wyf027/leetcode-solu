自动补全系统Design Search Autocomplete System

让每次按键都立即返回最热门的三个候选句，并在用户输入 # 后把新句子记入历史。先理解它必须表现成什么样，再决定内部如何组织数据。

行为契约

  1. 01接收一个字符，累积当前搜索句。
  2. 02按热度降序、字典序升序返回至多 3 条。
  3. 03遇到 #，保存整句并开启下一轮输入。

01 / Problem

题意与接口

这是一个有状态的设计题：构造器载入历史搜索及次数，之后连续的 input 调用共同组成一条句子。

准确转述

实现 AutocompleteSystem。系统保存若干历史句子及其被输入的次数。每输入一个普通字符，就筛出以“本轮累计文本”为前缀的历史句子，返回热度最高的至多三条。

热度更高者优先；热度相同时，按 ASCII 字典序较小者优先。字符 # 表示当前句子结束：该句热度增加 1，本次返回空列表，然后清空本轮文本。

AutocompleteSystem(String[] sentences, int[] times) List<String> input(char c)

排序规则

主键：累计次数降序。
次键：句子字典序升序。
截断：只保留前三名。

空格也是句子中的普通字符；只有 # 是结束标志，它不会成为句子内容的一部分。

03 / Limits

约束

官方元数据未包含付费题正文；这里依据标准公开接口整理必要约束，不复制完整题面。

初始化规模

  • 1 ≤ sentences.length ≤ 100
  • times.length = sentences.length
  • 所有初始句子互不相同。

句子与热度

  • 1 ≤ sentences[i].length ≤ 100
  • 1 ≤ times[i] ≤ 50
  • 句子由小写字母与空格组成，以字母开头且不以空格结尾。

输入流

  • c 是小写字母、空格或 #。
  • # 只用于结束当前句子。
  • input 最多被调用 5000 次。

Solution / Spoilers

字典树节点缓存 Top 3

查询必须快，而每个字符只会让前缀沿一条路径前进。把“这个前缀目前最好的三条句子”直接缓存到对应节点，就能把复杂排序从查询时移到初始化与提交时。

PATH字典树用输入字符定位当前前缀节点。
CACHE每个节点只保留按规则排序的前三句。
LEARN# 只更新新句子经过的那条路径。

核心洞察

朴素做法会在每次按键后扫描全部句子，再排序选前三。最多 5000 次输入时，这些重复工作没有必要。字典树天然表示所有前缀；而答案上限恒为 3，因此节点缓存可以保持为常数大小。

另外维护全局 hot[sentence]。某句热度变化时，对它路径上的每个节点，把该句与原来的 Top 3 合并、按“热度降序 + 字典序升序”排序，再截取前三即可。因为只有这一句的排名发生变化，不需要找回其他被淘汰句子。

完整过程

  1. 建立全局热度表。构造时把每条句子的次数记入 hot。
  2. 插入字典树。逐字符创建节点；在每个经过的节点刷新该句对应的 Top 3。
  3. 维护会话状态。保存当前累计字符串与当前字典树节点。普通字符到来时向下一层移动。
  4. 直接回答。节点存在就复制其 Top 3；路径一旦不存在，本轮后续普通字符都返回空列表。
  5. 提交并复位。遇到 #，整句热度加 1 并刷新其路径，然后把累计字符串清空、游标放回根节点。

正确性证明

引理 1：每个节点的缓存始终是其前缀下的正确 Top 3。
初始化插入一句时，它只可能影响自身路径上的节点。刷新时将它与旧 Top 3 一起排序截断：路径外节点不受影响；路径内除该句外，所有句子的热度不变，旧 Top 3 已支配其余句子。因此新前三必然包含在“旧 Top 3 + 该句”中。逐句插入后不变式成立。提交句子时同理。
引理 2：普通输入后，游标对应且仅对应当前累计前缀。
初始游标在根节点，对应空前缀。每读入一个普通字符就沿对应边前进；若边不存在，则没有任何历史句子拥有该前缀。由归纳法结论成立。
定理：每次 input 的返回值都符合题意。
普通字符时，由引理 2 找到当前前缀节点，再由引理 1 直接得到符合热度和字典序规则的至多三条句子。输入 # 时，算法按规则增加整句热度并返回空列表，同时恢复初始会话状态。因此所有调用均正确。

复杂度

构造 O(S · k log k)S 为初始句子总字符数，k = 3。
普通输入 O(k)沿一条边并复制至多 3 个答案，可视为 O(1)。
提交 O(L · k log k)L 为本轮句长；空间 O(S)。

若把字符串比较的字符成本展开，排序中的比较还要乘上对应公共前缀长度；由于 k 恒为 3，主导项仍是路径长度。

边界处理

路径已经断开

游标置空，但继续累积字符；直到 # 才把完整新句插入并复位。

热度相同

绝不能依赖哈希表遍历顺序，必须显式比较句子字典序。

已有句子再次提交

只增加原句热度，不创建逻辑重复项；沿原路径刷新缓存。

空格字符

它属于字典树的一条普通边；只有 # 具有控制语义。

Java
import java.util.*;

class AutocompleteSystem {
    private static class TrieNode {
        Map<Character, TrieNode> children = new HashMap<>();
        List<String> top = new ArrayList<>();
    }

    private final TrieNode root = new TrieNode();
    private final Map<String, Integer> hot = new HashMap<>();
    private final StringBuilder current = new StringBuilder();
    private TrieNode cursor = root;

    public AutocompleteSystem(String[] sentences, int[] times) {
        for (int i = 0; i < sentences.length; i++) {
            add(sentences[i], times[i]);
        }
    }

    public List<String> input(char c) {
        if (c == '#') {
            add(current.toString(), 1);
            current.setLength(0);
            cursor = root;
            return new ArrayList<>();
        }

        current.append(c);
        if (cursor == null) {
            return new ArrayList<>();
        }
        cursor = cursor.children.get(c);
        if (cursor == null) {
            return new ArrayList<>();
        }
        return new ArrayList<>(cursor.top);
    }

    private void add(String sentence, int delta) {
        hot.put(sentence, hot.getOrDefault(sentence, 0) + delta);
        TrieNode node = root;
        for (char ch : sentence.toCharArray()) {
            node.children.putIfAbsent(ch, new TrieNode());
            node = node.children.get(ch);
            refresh(node, sentence);
        }
    }

    private void refresh(TrieNode node, String sentence) {
        List<String> candidates = new ArrayList<>(node.top);
        if (!candidates.contains(sentence)) {
            candidates.add(sentence);
        }
        candidates.sort((a, b) -> {
            int byHotness = Integer.compare(hot.get(b), hot.get(a));
            return byHotness != 0 ? byHotness : a.compareTo(b);
        });
        node.top = new ArrayList<>(
            candidates.subList(0, Math.min(3, candidates.size()))
        );
    }
}
JavaScript
class TrieNode {
    constructor() {
        this.children = new Map();
        this.top = [];
    }
}

class AutocompleteSystem {
    /**
     * @param {string[]} sentences
     * @param {number[]} times
     */
    constructor(sentences, times) {
        this.root = new TrieNode();
        this.hot = new Map();
        this.current = "";
        this.cursor = this.root;

        for (let i = 0; i < sentences.length; i++) {
            this.add(sentences[i], times[i]);
        }
    }

    /**
     * @param {character} c
     * @return {string[]}
     */
    input(c) {
        if (c === "#") {
            this.add(this.current, 1);
            this.current = "";
            this.cursor = this.root;
            return [];
        }

        this.current += c;
        if (this.cursor === null) return [];

        this.cursor = this.cursor.children.get(c) ?? null;
        return this.cursor === null ? [] : this.cursor.top.slice();
    }

    add(sentence, delta) {
        this.hot.set(sentence, (this.hot.get(sentence) ?? 0) + delta);
        let node = this.root;

        for (const ch of sentence) {
            if (!node.children.has(ch)) {
                node.children.set(ch, new TrieNode());
            }
            node = node.children.get(ch);
            this.refresh(node, sentence);
        }
    }

    refresh(node, sentence) {
        const candidates = node.top.slice();
        if (!candidates.includes(sentence)) candidates.push(sentence);

        candidates.sort((a, b) => {
            const hotnessDiff = this.hot.get(b) - this.hot.get(a);
            if (hotnessDiff !== 0) return hotnessDiff;
            return a < b ? -1 : a > b ? 1 : 0;
        });
        node.top = candidates.slice(0, 3);
    }
}
Python
from typing import List, Dict


class TrieNode:
    def __init__(self) -> None:
        self.children: Dict[str, "TrieNode"] = {}
        self.top: List[str] = []


class AutocompleteSystem:
    def __init__(self, sentences: List[str], times: List[int]):
        self.root = TrieNode()
        self.hot: Dict[str, int] = {}
        self.current = ""
        self.cursor = self.root

        for sentence, count in zip(sentences, times):
            self._add(sentence, count)

    def input(self, c: str) -> List[str]:
        if c == "#":
            self._add(self.current, 1)
            self.current = ""
            self.cursor = self.root
            return []

        self.current += c
        if self.cursor is None:
            return []

        self.cursor = self.cursor.children.get(c)
        return [] if self.cursor is None else self.cursor.top[:]

    def _add(self, sentence: str, delta: int) -> None:
        self.hot[sentence] = self.hot.get(sentence, 0) + delta
        node = self.root

        for ch in sentence:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
            self._refresh(node, sentence)

    def _refresh(self, node: TrieNode, sentence: str) -> None:
        candidates = node.top[:]
        if sentence not in candidates:
            candidates.append(sentence)
        candidates.sort(key=lambda item: (-self.hot[item], item))
        node.top = candidates[:3]
C++
#include <bits/stdc++.h>
using namespace std;

class AutocompleteSystem {
    struct TrieNode {
        unordered_map<char, unique_ptr<TrieNode>> children;
        vector<string> top;
    };

    unique_ptr<TrieNode> root;
    TrieNode* cursor;
    unordered_map<string, int> hot;
    string current;

    void refresh(TrieNode* node, const string& sentence) {
        vector<string> candidates = node->top;
        if (find(candidates.begin(), candidates.end(), sentence)
                == candidates.end()) {
            candidates.push_back(sentence);
        }

        sort(candidates.begin(), candidates.end(),
             [this](const string& a, const string& b) {
                 if (hot[a] != hot[b]) return hot[a] > hot[b];
                 return a < b;
             });
        if (candidates.size() > 3) candidates.resize(3);
        node->top = move(candidates);
    }

    void add(const string& sentence, int delta) {
        hot[sentence] += delta;
        TrieNode* node = root.get();

        for (char ch : sentence) {
            auto& child = node->children[ch];
            if (!child) child = make_unique<TrieNode>();
            node = child.get();
            refresh(node, sentence);
        }
    }

public:
    AutocompleteSystem(vector<string>& sentences, vector<int>& times)
        : root(make_unique<TrieNode>()) {
        cursor = root.get();
        for (int i = 0; i < static_cast<int>(sentences.size()); ++i) {
            add(sentences[i], times[i]);
        }
    }

    vector<string> input(char c) {
        if (c == '#') {
            add(current, 1);
            current.clear();
            cursor = root.get();
            return {};
        }

        current.push_back(c);
        if (cursor == nullptr) return {};

        auto it = cursor->children.find(c);
        if (it == cursor->children.end()) {
            cursor = nullptr;
            return {};
        }
        cursor = it->second.get();
        return cursor->top;
    }
};

替代方案与取舍

每次扫描全部句子

实现最直接：筛前缀后用大小为 3 的堆。但每个字符都重复扫描，查询成本高，适合数据很小的基线版本。

字典树 + DFS 收集

先快速定位前缀，再遍历整棵子树找候选。热门前缀的子树可能很大，最坏查询仍然昂贵。

节点保存全部句子

查询方便，但同一句会出现在它的所有前缀节点中；若每次还全量排序，更新与内存都更重。

节点缓存 Top K

本题 K=3，缓存常数级。若 K 可配置且很大，可改用有序集合或可更新堆结构。

常见错误

  • 把 # 拼入句子，导致下次无法按正常前缀匹配。
  • 路径不存在后丢掉已输入文本，提交时保存了不完整句子。
  • 热度相同时写成降序字典序，或使用区域化比较导致顺序偏离题目。
  • 返回节点内部的可变列表引用，让外部修改破坏缓存。
  • 已有句子热度增加后只更新全局表，没有刷新经过节点的 Top 3。

面试追问

  • 如果要支持删除历史句子？
    仅凭旧 Top 3 无法知道被删除后应补入谁；节点需要保存更多候选、有序集合，或在删除时重新遍历对应子树。
  • 如果热度随时间衰减？
    静态缓存会过期。可按时间窗口分桶、使用惰性重算，或在候选召回后应用实时打分层。
  • 如果数据分布在多台机器？
    把前缀按前若干字符分片；热点短前缀可复制缓存，并通过事件流异步合并热度更新。
  • 如何加入个性化？
    全局 Top 3 只负责召回，再融合用户历史、语言与场景打分；需要明确稳定的最终排序和隐私边界。
