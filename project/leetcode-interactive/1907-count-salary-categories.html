1907. 按分类统计薪水

Count Salary Categories

三个薪水区间，一张完整的分类统计表。先理解边界，再探索数据流。

官方题目 ↗

题意与数据契约

输入表 Accounts(account_id INT, income INT)，每行表示一个银行账户的月收入，account_id 是主键。计算每个薪水类别的账户数，输出列为 category 和 accounts_count。

  • Low Salary：income < 20000。
  • Average Salary：20000 ≤ income ≤ 50000，包含两个端点。
  • High Salary：income > 50000。

结果必须包含全部三类；没有账户的类别也要输出 0。结果顺序不限。

官方约束仅给出表结构、主键和分类规则，未给出行数或 income 的数值范围，也未单独说明 NULL 的业务含义。本页交互使用整数收入；SQL 中 NULL 不满足上述任一比较条件。

独立题解

准备好后再展开实现与证明。

核心洞察 · 先保证三行，再统计

直接按 CASE 结果 GROUP BY 只会产生出现过的类别。用三个不带 GROUP BY 的 COUNT(*) 聚合，每个分支始终产生一行，包括匹配记录数为零的情况，再用 UNION ALL 拼接。

正式提交 · SQL

以下查询使用 MySQL、PostgreSQL、SQL Server 与 Oracle 支持的基础语法。

SELECT 'Low Salary' AS category, COUNT(*) AS accounts_count
FROM Accounts
WHERE income < 20000
UNION ALL
SELECT 'Average Salary' AS category, COUNT(*) AS accounts_count
FROM Accounts
WHERE income BETWEEN 20000 AND 50000
UNION ALL
SELECT 'High Salary' AS category, COUNT(*) AS accounts_count
FROM Accounts
WHERE income > 50000;

完整过程

  1. 低薪分支筛选 income < 20000，示例仅账户 2，返回 1。
  2. 中薪分支筛选闭区间 [20000,50000]，示例无匹配，COUNT(*) 返回 0。
  3. 高薪分支筛选 income > 50000，示例有 3 个账户。
  4. UNION ALL 保留三条汇总记录，列名由第一条 SELECT 确定。

正确性

对任一非 NULL 整数收入，三个谓词互斥且覆盖所有可能值，因此每个账户恰好被一个分支计数。各分支的 COUNT(*) 正好统计其类别的账户行数。无 GROUP BY 的整体聚合即使面对空输入也返回一行且 COUNT 为 0，所以最终始终包含三个指定类别，满足输出要求。

边界与复杂度

20000 和 50000 都计入中薪。重复收入是不同账户，不能用 COUNT(DISTINCT income)。空表输出三行 0。NULL 在 SQL 比较中为未知，不归入任何类别；若业务要求对 NULL 分类，应先明确额外规则。

设 n 为账户数，无索引的直接执行最多扫描表三次，时间 O(n)，聚合计数的额外空间 O(1)，输出固定三行。实际数据库可能使用索引和不同执行计划，此处未测量性能。

替代方案

构造包含三类的常量表，再 LEFT JOIN 已分组的账户数据并 COALESCE 为 0；表达更通用但更长。也可一次扫描做条件聚合，再转为三行；需要注意 SUM 在空表上可能为 NULL，且转行语法因数据库而异。UNION 可用但会引入不必要的去重语义。

常见错误

  • 只 GROUP BY CASE，遗漏人数为 0 的类别。
  • 把边界写成严格不等式，漏掉 20000 或 50000。
  • COUNT(income < 20000) 统计的是非 NULL 表达式，不是条件为真的行。
  • 将账户数误写成不同薪水的数量。

面试追问

类别区间经常变化怎么办？使用规则表并约束区间不重叠。需要按月份统计且每月都显示三类怎么办？先建立月份与类别的组合，再左连接聚合结果。如何优化大表？结合实际执行计划比较索引范围计数与单次条件聚合，不能仅凭 SQL 长短判断。

Java · 本地语义参考（非本题提交语言）

四份参考代码均接收账户二元组并返回三类计数；收入使用整数，未实现 SQL NULL 语义。

import java.util.*;
class Solution {
    public static Map<String, Long> countSalaryCategories(long[][] accounts) {
        long[] counts = new long[3];
        for (long[] row : accounts) {
            long income = row[1];
            counts[income < 20000 ? 0 : income <= 50000 ? 1 : 2]++;
        }
        Map<String, Long> result = new LinkedHashMap<>();
        result.put("Low Salary", counts[0]);
        result.put("Average Salary", counts[1]);
        result.put("High Salary", counts[2]);
        return result;
    }
}

JavaScript · 本地语义参考（非本题提交语言）

function countSalaryCategories(accounts) {
    const names = ["Low Salary", "Average Salary", "High Salary"];
    const counts = [0, 0, 0];
    for (const [, income] of accounts) {
        counts[income < 20000 ? 0 : income <= 50000 ? 1 : 2]++;
    }
    return names.map((category, i) => ({
        category, accounts_count: counts[i]
    }));
}

Python · 本地语义参考（非官方 Pandas 签名）

def count_salary_categories(accounts):
    names = ["Low Salary", "Average Salary", "High Salary"]
    counts = [0, 0, 0]
    for account_id, income in accounts:
        index = 0 if income < 20000 else 1 if income <= 50000 else 2
        counts[index] += 1
    return [
        {"category": name, "accounts_count": count}
        for name, count in zip(names, counts)
    ]

vector<pair<string, long long>> countSalaryCategories(
    const vector<array<long long, 2>>& accounts) {
    array<long long, 3> counts{};
    for (const auto& row : accounts) {
        long long income = row[1];
        ++counts[income < 20000 ? 0 : income <= 50000 ? 1 : 2];
    }
    return {{"Low Salary", counts[0]},
            {"Average Salary", counts[1]},
