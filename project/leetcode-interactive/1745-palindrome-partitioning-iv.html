分割回文串 IV

一条字符串，两刀，三个非空片段。先亲手移动切分点，观察哪些组合能让三个片段同时“镜像闭合”。题解暂时藏在页面底部。

Problem

题目描述

非付费题

给定字符串 s，判断能否用两个切分点把它分成三个非空子字符串，并且这三个子字符串都为回文串。若存在这样的切分，返回 true；否则返回 false。

回文串正向读取与反向读取完全相同。切分必须覆盖整个原字符串，不能漏掉字符，也不能产生空片段。

约束

  • 3 <= s.length <= 2000
  • s 只包含小写英文字母。
示例 1 
输入：s = "abcbdd"
输出：true
解释："abcbdd" = "a" + "bcb" + "dd"，三个片段均为回文串。
示例 2 
输入：s = "bcbddxy"
输出：false
解释：不存在恰好分成三个回文子串的切法。

Complete Solution

动态规划预处理 + 枚举两刀

O(n²) 时间 · O(n²) 空间

核心洞察

如果能在常数时间判断任意子串是否为回文，那么只需枚举两处切分位置。设第一段结尾为 i，第二段结尾为 j，检查三个区间 [0,i]、[i+1,j]、[j+1,n-1] 即可。

pal[l][r] = (s[l] == s[r]) && (r - l <= 2 || pal[l+1][r-1])

完整过程

  1. 创建二维状态 pal，其中 pal[l][r] 表示闭区间 s[l..r] 是否为回文。
  2. 让 l 从右向左遍历，r 从 l 向右遍历，保证内部区间已计算。
  3. 枚举 i = 0..n-3，再枚举 j = i+1..n-2，这两个范围天然保证三段非空。
  4. 三个回文状态同时为真时立即返回 true；所有切法均失败后返回 false。

正确性说明

引理：递推式能准确判断任意 s[l..r]。长度不超过 3 时，只要首尾相等，内部为空或单字符，必为回文；更长区间则当且仅当首尾相等且内部区间为回文。

完备性：两层循环枚举了所有满足 0 ≤ i < j < n-1 的切分点，因此任何合法三段切分都不会遗漏。

可靠性：算法只在三个对应区间的 pal 状态均为真时返回真，所以返回的切分一定由三个非空回文串组成。

边界处理

  • n = 3 时只有一种切法，三个单字符都为回文，因此结果一定为真。
  • 单字符与双字符区间要由短区间基础条件处理，避免读取越界状态。
  • 切分位置不能到达末尾；否则第三段为空。
  • 重复字符很多时会产生大量回文区间，但复杂度仍保持平方级。

复杂度

回文预处理需要 O(n²) 时间和 O(n²) 空间；枚举两刀最坏也是 O(n²)。总时间 O(n²)，额外空间 O(n²)。

替代方案

可用“中心扩展”记录所有回文区间，渐进复杂度仍为 O(n²)。逐次双指针检查每段虽然仅用 O(1) 额外空间，但两刀有平方种组合、每次检查又可能线性，最坏会退化到 O(n³)。

面试追问

  • 若要求分成恰好 k 个回文串，如何增加“已用段数”这一维状态？
  • 若要输出一种具体切分，如何保存并恢复两个切分点？
  • 能否用 Manacher 算法提供回文查询，再讨论实现复杂度与收益？

常见错误

  • 使用错误的遍历顺序，导致 pal[l+1][r-1] 尚未计算。
  • 枚举到 j = n-1，意外允许空的第三段。
  • 只枚举相同长度的三段；题目不要求长度相等。
  • 把“分成最多三段”误读为“恰好三个非空片段”。

class Solution {
    public boolean checkPartitioning(String s) {
        int n = s.length();
        boolean[][] pal = new boolean[n][n];

        for (int left = n - 1; left >= 0; left--) {
            for (int right = left; right < n; right++) {
                pal[left][right] = s.charAt(left) == s.charAt(right)
                    && (right - left <= 2 || pal[left + 1][right - 1]);
            }
        }

        for (int i = 0; i < n - 2; i++) {
            if (!pal[0][i]) continue;
            for (int j = i + 1; j < n - 1; j++) {
                if (pal[i + 1][j] && pal[j + 1][n - 1]) {
                    return true;
                }
            }
        }
        return false;
    }
}

var checkPartitioning = function(s) {
    const n = s.length;
    const pal = Array.from({ length: n }, () => new Uint8Array(n));

    for (let left = n - 1; left >= 0; left--) {
        for (let right = left; right < n; right++) {
            if (
                s[left] === s[right] &&
                (right - left <= 2 || pal[left + 1][right - 1] === 1)
            ) {
                pal[left][right] = 1;
            }
        }
    }

    for (let i = 0; i < n - 2; i++) {
        if (pal[0][i] === 0) continue;
        for (let j = i + 1; j < n - 1; j++) {
            if (pal[i + 1][j] === 1 && pal[j + 1][n - 1] === 1) {
                return true;
            }
        }
    }
    return false;
};

class Solution:
    def checkPartitioning(self, s: str) -> bool:

        for left in range(n - 1, -1, -1):
            for right in range(left, n):
                if (
                    s[left] == s[right]
                    and (right - left <= 2 or pal[left + 1][right - 1])
                ):
                    pal[left][right] = 1

        for i in range(n - 2):
            if not pal[0][i]:
                continue
            for j in range(i + 1, n - 1):
                if pal[i + 1][j] and pal[j + 1][n - 1]:

class Solution {

    bool checkPartitioning(string s) {
        int n = static_cast<int>(s.size());
        vector<vector<char>> pal(n, vector<char>(n, 0));

        for (int left = n - 1; left >= 0; --left) {
            for (int right = left; right < n; ++right) {
                pal[left][right] = s[left] == s[right]
                    && (right - left <= 2 || pal[left + 1][right - 1]);
            }
        }

        for (int i = 0; i < n - 2; ++i) {
            if (!pal[0][i]) continue;
            for (int j = i + 1; j < n - 1; ++j) {
                if (pal[i + 1][j] && pal[j + 1][n - 1]) {
                    return true;
                }
            }
        }
        return false;
    }
};
