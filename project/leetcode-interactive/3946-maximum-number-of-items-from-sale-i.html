3946. 购买最多物品数目 I

把“第一次购买”当作有额外赠品的 0/1 选择，再把重复购买当作普通完全背包。

打开题目

题意

每种物品 items[i] = [factorᵢ, priceᵢ] 都能无限购买，花费不能超过 budget。某一种物品第一次被购买时，除自身购买份数外，还会按整除关系各送出一份其他物品；同种物品后续购买不再触发赠送。

目标是最大化购买份数与免费份数之和。字符串、空格等输入在本题不存在；表中的数组均完整显示参数名、等号和值。

示例 1

输入 items = [[6, 2], [2, 6], [3, 4]]
budget = 9
输出 4
选择 买 2 份物品 0 与 1 份物品 2，花费 8；物品 2 的因子 3 整除物品 0 的因子 6，因此额外送 1 份物品 0。

题解

默认收起，避免首屏直接泄露解法。

核心洞察

预先计算 gift[i]：因子 factorᵢ 能整除的其他物品种类数。物品 i 的第一份购买同时贡献 1 + gift[i] 个总副本，价格是 priceᵢ；随后每多买一份只贡献 1。

逐个枚举类型，并维持“此前类型已经决定”的 DP。对当前类型单独使用 chosen 数组，先放入第一份增强购买，再从小预算到大预算追加普通副本，最后和不选它的旧层取最大值。

完整过程

  1. 双重循环求每个 gift[i]。
  2. dp[b] 表示处理完若干种类且花费至多 b 时的最多副本。
  3. 令 chosen[b] = dp[b-price[i]] + 1 + gift[i]，代表第一次购买 i。
  4. 正向转移 chosen[b] = max(chosen[b], chosen[b-price[i]] + 1)，代表追加同类副本。
  5. 将 max(dp[b], chosen[b]) 写进下一层。

边界

预算不足以购买当前类型时不能进入 chosen。所有价格都正，因此正向循环不会无限循环。

复杂度

赠品关系 O(n²)；背包 O(n × budget)，额外空间 O(budget)。

替代方案

直接枚举每种购买数量会多一维且很慢；把首份与后续份分离，才可把数量枚举压成线性预算转移。

面试追问

若同一来源可按购买数量重复赠送，转移会变成普通完全背包的增益；若赠送规则依赖已选集合，则需额外状态表示集合，当前的逐类型压缩不再适用。

常见错误

  • 让普通副本从旧 dp 转移，会允许“未触发第一次购买”就追加。
  • 把 j == i 也计入赠品。
  • 把不同来源送到同一物品的副本错误去重。
