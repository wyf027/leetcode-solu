01 · Problem

题目说明

函数 minInsertions(s) 接收一个仅含小写英文字母的字符串，返回所需插入操作的最小次数。

给定字符串 s。一次操作中，可以在字符串的任意位置插入任意字符。请返回使 s 变为回文串所需的最少操作次数。

回文串正向读取与反向读取完全相同；只能插入，不能删除、替换或交换原字符。

Constraints

  • 1 <= s.length <= 500
  • s 仅由小写英文字母组成。

Example 01

输入：s = "zzazz"
输出：0
解释："zzazz" 已经是回文串，
      无需插入。

Example 02

输入：s = "mbadm"
输出：2
解释：可变为 "mbdadbm"，
      也可变为 "mdbabdm"。

Example 03

输入：s = "leetcode"
输出：5
解释：插入 5 个字符后可变为
      "leetcodocteel"。

03 · Solution

区间动态规划

把“大串怎样变成回文”拆成“每个连续区间还差几次插入”。

核心洞察

令 dp[i][j] 表示子串 s[i..j] 变成回文串的最少插入次数。若两端相同，它们可以直接配对；否则必须在左端外侧补一个与右端相同的字符，或在右端外侧补一个与左端相同的字符，选择代价更小的一边。

状态转移

i == j 时 dp[i][i] = 0。

s[i] == s[j]：dp[i][j] = dp[i+1][j-1]。

s[i] != s[j]：dp[i][j] = 1 + min(dp[i+1][j], dp[i][j-1])。

Process

完整过程

定义边界。

单个字符本身就是回文，因此主对角线全部为 0；空区间在“两端相同且长度为 2”时也等价于 0。

按区间长度递增。

从长度 2 一直计算到长度 n。每个状态只依赖长度更短的区间，所以依赖项一定已经完成。

比较两端。

相同时收缩两端；不同时分别尝试保留左端或保留右端，各插入一次，取较小结果。

读取答案。

dp[0][n-1] 覆盖整个原字符串，即全局最少插入次数。

正确性证明

归纳基础：长度 1 的子串已经是回文，dp[i][i]=0 正确。

归纳假设：所有长度小于 L 的区间都已取得最优值。

归纳步骤：对长度 L 的 s[i..j]，若端点相同，最优方案无需为它们插入字符，问题完全缩为内部区间。若端点不同，最终回文中至少要新增一个字符与其中一个端点配对；这两类方案分别留下 s[i+1..j] 与 s[i..j-1]，转移枚举了全部可能且取最小值。由归纳假设，子问题均最优，因此当前状态也最优。

结论：dp[0][n-1] 是整串的最少插入次数。

边界与复杂度

  • 长度为 1：答案为 0。
  • 已经是回文：状态最终传播为 0。
  • 所有字符不同：答案为 n - 1。
  • 时间复杂度：O(n²)。
  • 空间复杂度：二维写法 O(n²)；可优化为 O(n)。

Alternatives

替代方案：最长回文子序列

最少插入次数也等于 n - LPS(s)，其中 LPS 是最长回文子序列长度；而 LPS(s) 又可转化为 s 与其反转串的最长公共子序列。这个视角很适合解释答案，但二维区间 DP 更直接贴合“从两端补字符”的操作过程。

Implementations

四语言完整代码

均使用相同的二维区间 DP，便于逐行对照。

JavaO(n²) / O(n²)
class Solution {
    public int minInsertions(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];

        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len <= n; i++) {
                int j = i + len - 1;
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = len == 2 ? 0 : dp[i + 1][j - 1];
                } else {
                    dp[i][j] = 1 + Math.min(dp[i + 1][j],
                                             dp[i][j - 1]);
                }
            }
        }
        return dp[0][n - 1];
    }
}
JavaScriptO(n²) / O(n²)
/**
 * @param {string} s
 * @return {number}
 */
var minInsertions = function(s) {
    const n = s.length;
    const dp = Array.from(
        { length: n },
        () => Array(n).fill(0)
    );

    for (let len = 2; len <= n; len++) {
        for (let i = 0; i + len <= n; i++) {
            const j = i + len - 1;
            if (s[i] === s[j]) {
                dp[i][j] = len === 2 ? 0 : dp[i + 1][j - 1];
            } else {
                dp[i][j] = 1 + Math.min(dp[i + 1][j],
                                        dp[i][j - 1]);
            }
        }
    }
    return dp[0][n - 1];
};
Python 3O(n²) / O(n²)
class Solution:
    def minInsertions(self, s: str) -> int:
        n = len(s)
        dp = [[0] * n for _ in range(n)]

        for length in range(2, n + 1):
            for i in range(n - length + 1):
                j = i + length - 1
                if s[i] == s[j]:
                    dp[i][j] = 0 if length == 2 else dp[i + 1][j - 1]
                else:
                    dp[i][j] = 1 + min(dp[i + 1][j],
                                       dp[i][j - 1])

        return dp[0][n - 1]
C++O(n²) / O(n²)
class Solution {
public:
    int minInsertions(string s) {
        int n = static_cast<int>(s.size());
        vector<vector<int>> dp(n, vector<int>(n, 0));

        for (int len = 2; len <= n; ++len) {
            for (int i = 0; i + len <= n; ++i) {
                int j = i + len - 1;
                if (s[i] == s[j]) {
                    dp[i][j] = (len == 2) ? 0 : dp[i + 1][j - 1];
                } else {
                    dp[i][j] = 1 + min(dp[i + 1][j],
                                       dp[i][j - 1]);
                }
            }
        }
        return dp[0][n - 1];
    }
};

面试追问

  • 如何把空间压缩到 O(n)？更新顺序为什么必须谨慎？
  • 如果要输出一个实际构造出的最短回文串，需要额外保存什么？
  • 为什么答案等于 n - 最长回文子序列长度？
  • 若允许删除字符，最少删除次数与本题有何关系？

常见错误

  • 把“子序列”误写成“子串”，丢失不连续选择。
  • 按错误顺序填表，读取了尚未计算的长区间。
  • 端点相同时仍然额外加 1。
  • 长度为 2 且端点相同时访问越界的内部区间。
  • 用贪心固定补某一端，无法保证全局最优。
