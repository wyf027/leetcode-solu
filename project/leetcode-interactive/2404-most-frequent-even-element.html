Most Frequent Even Element

在出现次数相同的候选中，记得选择更小的数字。

01 / THE QUESTION

题目与规则

给定整数数组 nums，找出其中出现次数最多的偶数并返回它。若多个偶数出现次数并列最多，返回数值最小的那个；如果数组里没有偶数，返回 -1。

参数：nums: integer[]　返回：integer

约束：1 ≤ nums.length ≤ 2000；0 ≤ nums[i] ≤ 10⁵。

思考：偶数 0 是否参与比较？出现次数相同的两个数，应该依据什么做决定？

04 / SOLUTION NOTES

独立题解

准备好后再展开完整思路与四语言代码。

核心洞察：偶数计数 + 两级比较

只统计偶数。用哈希表记录每个偶数的出现次数，并维护 ans（当前最佳数字）与 best（最高频次）。比较优先级为：频次越高越好；频次相同时，数字越小越好。

完整过程

  1. 初始化空计数表，ans = -1、best = 0。
  2. 从左到右读取 x。若是奇数，直接跳过。
  3. 若是偶数，令 c = count[x] + 1，存回计数表。
  4. 如果 c > best，或者 c == best 且 x < ans，同时更新 ans = x 和 best = c。
  5. 遍历结束，返回 ans。没有偶数时它一直保持 -1。

例如 [4,4,2,2]：读完前两个数后，4 以两票领先；第一个 2 仅一票，不替换；第二个 2 使双方同为两票，2 更小，因此替换为 2。

正确性：维护前缀最优者

不变量：处理任意前缀后，表中记录该前缀所有偶数的准确次数，ans 是其中按“频次降序、数值升序”规则选出的最优者；若没有偶数，ans = -1。

初始前缀为空，不变量成立。遇到奇数，偶数频次不变。遇到偶数 x 时，只有 x 的次数增加：其余数字之间的优劣关系不变，只需比较更新后的 x 与原来的最优者。若 x 就是原最优者，它的次数增加后会刷新 best；否则按两级条件决定是否替换。因此每步仍满足不变量。最后前缀覆盖整个数组，返回值满足题意。

复杂度

设 n 为数组长度，k 为不同偶数的数量。哈希表单次操作平均 O(1)，算法平均时间 O(n)，额外空间 O(k)，且 k ≤ min(n, 50001)。哈希冲突极端情况下时间可能退化。

教学界面为回退而重算前缀并排序票数榜，其开销与提交算法不同。

边界

  • 0 是偶数，不能用真假值判断候选是否存在。
  • 全奇数返回 -1；单个偶数返回自身。
  • 所有偶数次数相同，选择数值最小者。
  • 首个偶数计数为 1，大于 best 的 0，因此不会受 ans = -1 的大小影响。
  • 空数组不在官方输入范围。

四种可提交实现

以下遵循官方函数签名；Python 使用 Python 3。代码均待补执行验证。

Java

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int mostFrequentEven(int[] nums) {
        Map<Integer, Integer> count = new HashMap<>();
        int ans = -1, best = 0;
        for (int x : nums) {
            if (x % 2 != 0) continue;
            int c = count.getOrDefault(x, 0) + 1;
            count.put(x, c);
            if (c > best || (c == best && x < ans)) {
                ans = x;
                best = c;
            }
        }
        return ans;
    }
}

/**
 * @param {number[]} nums
 * @return {number}

var mostFrequentEven = function(nums) {
    const count = new Map();
    let ans = -1, best = 0;
    for (const x of nums) {
        if (x % 2 !== 0) continue;
        const c = (count.get(x) ?? 0) + 1;
        count.set(x, c);
        if (c > best || (c === best && x < ans)) {
            ans = x;
            best = c;
        }
    }
    return ans;
};

C++

#include <vector>
#include <unordered_map>
using namespace std;

class Solution {
public:
    int mostFrequentEven(vector<int>& nums) {
        unordered_map<int, int> count;
        int ans = -1, best = 0;
        for (int x : nums) {
            if (x % 2 != 0) continue;
            int c = ++count[x];
            if (c > best || (c == best && x < ans)) {
                ans = x;
                best = c;
            }
        }
        return ans;
    }
};

替代方案

  • 两遍哈希：先统计，再扫描不同偶数并比较，更容易拆开理解；平均 O(n + k) 时间、O(k) 空间。
  • 固定计数数组：用长度 100001 的数组统计；O(n + U) 时间、O(U) 空间，U = 100001。可用 x / 2 压缩偶数下标。值域较小且已知时适合。
  • 排序后统计连续段：数字升序排列，比较各偶数段长度，等长时保留先出现的小数；时间 O(n log n)，额外空间取决于排序实现与是否复制输入。

面试追问

  • 流式输入还能做吗？可以，每来一个数字更新计数和候选，无需保存原数组。
  • 允许删除数字呢？简单的 ans/best 更新不足以找回次优候选，需要重新扫描计数表，或使用有序结构维护排名。
  • 若输入含负数？判断奇数仍使用 x % 2 != 0；首个偶数凭更高频次进入候选。若需要区分无答案与合法值，使用独立存在标记。
  • 多分片如何合并？必须合并每个偶数的计数后再选最优；只合并各片冠军会遗漏全局冠军。

常见错误

  • 把次数最多的奇数也纳入候选。
  • 仅用 c >= best 替换，导致并列时保留最后遇到的数。
  • 先按数值大小选答案，忽略频次才是第一优先级。
  • 依赖 Map 的迭代顺序决定平局，而未显式比较数值。
  • 答案初始化为 0，导致全奇数错误返回 0。
  • 候选改变时忘记更新 best，后续比较失去依据。
