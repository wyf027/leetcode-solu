翻转矩阵后的得分Score After Flipping Matrix

一次翻转，整行或整列的 0 与 1 互换。你能把每一行组成的二进制数之和推到多高？先读题，再亲手观察矩阵如何变化。

01 · Problem

先把规则说清楚

题意

给定一个 m × n 的二进制矩阵 grid。一次移动可以选择任意一行或一列，把其中每个值翻转：0 变成 1，1 变成 0。

把每一行看作一个二进制数，矩阵得分是所有行所表示数值的总和。可以执行任意次移动（也可以一次不做），返回能得到的最高分。

参数与返回值

matrixScore(grid) grid: integer[][] return: integer

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 20
  • grid[i][j] 只能是 0 或 1
示例 1 完整参数形式
输入：grid = [[0,0,1,1],[1,0,1,0],[1,1,0,0]]
输出：39
解释：0b1111 + 0b1001 + 0b1111
     = 15 + 9 + 15 = 39
示例 2 最小边界
输入：grid = [[0]]
输出：1

03 · Solution

把高位价值放在第一位

核心洞察

每行最高位的权重是其余所有位权重之和再加一。因此，最优结果里每一行的首位必定为 1：首位为 0 时翻转整行一定更优。

在首列全为 1 之后，各列可以独立决策。对第 j 列，保留较多的 1；若 0 更多，就翻转该列。

无需真的修改矩阵

若某行原首位为 0，就把这一行视为已经翻转。此时位置 (i,j) 的有效值为 1，恰好等价于：

grid[i][j] == grid[i][0]

设该列有效的 1 有 ones 个，最终贡献取 max(ones, m - ones) × 2^(n-1-j)。

完整过程

  1. 遍历每一列，从最高位到最低位计算它的二进制权重。
  2. 遍历所有行，用“当前位是否与该行首位相同”计算虚拟行翻转后的 1 数量。
  3. 比较该列的 1 与 0 数量，选择较大者作为最终的 1 数量。
  4. 把这一列的最大贡献累加到答案，处理完全部列后返回。

正确性证明

  1. 首列最优：一行最高位为 0 时，翻转该行使最高位增加 2^(n-1)，而其他位最多损失 2^(n-1)-1，所以总分严格增加。
  2. 其余列最优：行翻转确定后，每列翻转只影响本列。取 ones 与 m-ones 较大者，正是该列可达到的最大 1 数。
  3. 全局最优：首列决策必然最优，之后各列互不影响且逐列最优，贡献相加即为全局最高分。

边界与复杂度

  • 单元素：[[0]] 可翻成 [[1]]。
  • 单行：所有列都能各自翻成 1。
  • 单列：每一行首位最终都为 1。
  • 时间：O(mn)；额外空间：O(1)。

替代方案

也可以先原地翻转所有首位为 0 的行，再统计并按需翻转各列。思路直观，但会修改输入。枚举所有行列翻转组合需要指数级时间，不适合 m,n ≤ 20。

面试追问

  • 为什么最高位的收益一定压过低位总损失？
  • 如果每次翻转有不同成本，贪心还成立吗？
  • 如何返回具体需要翻转的行、列集合？

常见错误

  • 按原矩阵直接统计各列，忘记先纳入虚拟行翻转。
  • 二进制权重方向写反；第 j 列权重应为 2^(n-1-j)。
  • 只翻一次行或列，误解“任意次数”的含义。
  • 用字符串拼二进制数，增加不必要的时间与空间。

四语言完整代码

Java · 官方可提交签名

class Solution {
    public int matrixScore(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        int score = 0;

        for (int col = 0; col < n; col++) {
            int ones = 0;
            for (int row = 0; row < m; row++) {
                if (grid[row][col] == grid[row][0]) {
                    ones++;
                }
            }
            int bestOnes = Math.max(ones, m - ones);
            score += bestOnes * (1 << (n - 1 - col));
        }
        return score;
    }
}

Python 3 · 官方可提交签名

from typing import List

class Solution:
    def matrixScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        score = 0

        for col in range(n):
            ones = sum(
                grid[row][col] == grid[row][0]
                for row in range(m)
            )
            best_ones = max(ones, m - ones)
            score += best_ones * (1 << (n - 1 - col))

        return score
