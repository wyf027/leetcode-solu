Beautiful Arrangement II

用 1 到 n 的每个整数恰好一次构造数组，使相邻元素的绝对差一共出现恰好 k 种不同的值。若答案不唯一，返回任意一种。

中等 数组 数学 非付费题
目标 / Objective

若答案为 [a₁, a₂, …, aₙ]，观察相邻位置产生的绝对差：

[ |a₁-a₂|, |a₂-a₃|, …, |aₙ₋₁-aₙ| ]

这个差值列表中，必须有且仅有 k 个不同整数。先理解目标，再进入下方实验室。

01 / 题面

从输入输出开始

参数 n 决定排列长度，参数 k 决定不同相邻差值的目标数量。

示例 1

输入：n = 3, k = 1
输出：[1, 2, 3]

相邻差值为 [1, 1]，不同差值只有 1，数量恰好为 1。

示例 2

输入：n = 3, k = 2
输出：[1, 3, 2]

相邻差值为 [2, 1]，不同差值是 1、2，数量恰好为 2。

约束： 1 <= k < n <= 10⁴

04 / 题解

准备好看构造规律了吗？

题解默认收起。展开后会看到核心洞察、证明、复杂度、替代思路、面试追问与四种语言实现。

核心洞察

让差值按 k, k−1, …, 1 降落

只要前 k + 1 个位置精确制造出 1..k，剩余数字再递增追加，就不会引入新的差值种类。

完整过程

  1. 令双指针 left = 1、right = k + 1。
  2. 在闭区间 [1, k+1] 内依次取左端、右端、左端、右端……直到用完。
  3. 这样相邻差值依次为 k, k−1, …, 1。
  4. 最后把 k+2 到 n 递增追加。

例：n = 7, k = 4

先在 [1,5] 两端交替取数：

1, 5, 2, 4, 3

此时差值为 4, 3, 2, 1。再追加 6, 7，新增差值只是已经出现过的 3, 1。

边界情况

  • k = 1：开头是 [1,2]，之后自然递增，始终只有差值 1。
  • k = n−1：整个数组都采用两端交替，得到全部差值 1..n−1。
  • n = 2 时只能有 k = 1，构造仍成立。

常见错误

  • 把目标误读为“差值之和为 k”，而不是“不同差值的数量为 k”。
  • 交替区间使用 [1,k]，少放一个数，只能产生至多 k−1 种差值。
  • 追加剩余数字时换用不连续顺序，意外制造大于 k 的新差值。
  • 忘记答案必须是 1..n 的一个排列，出现重复或遗漏。

正确性证明

  1. 答案是合法排列。前半段恰好使用 1..k+1，后半段恰好使用 k+2..n；两段无重复、无遗漏，因此整体是 1..n 的排列。
  2. 至少有 k 种差值。在前 k+1 个元素中，两端交替取数令相邻差值依次为 k, k−1, …, 1，所以差值 1..k 全部出现。
  3. 至多有 k 种差值。交替段与递增尾部连接处的差值位于 1..k；尾部内部差值恒为 1。因此后续不会产生集合 1..k 以外的值。

结论：相邻差值集合恰好是 {1,2,…,k}，构造满足要求。

时间复杂度O(n)必须生成 n 个元素
额外空间O(1)不计返回数组

四语言完整代码

Java · LeetCode signature
class Solution {
    public int[] constructArray(int n, int k) {
        int[] answer = new int[n];
        int index = 0;
        int left = 1;
        int right = k + 1;

        while (left <= right) {
            if (index % 2 == 0) {
                answer[index++] = left++;
            } else {
                answer[index++] = right--;
            }
        }

        for (int value = k + 2; value <= n; value++) {
            answer[index++] = value;
        }
        return answer;
    }
}

from typing import List


class Solution:
    def constructArray(self, n: int, k: int) -> List[int]:
        answer: List[int] = []
        left, right = 1, k + 1

        while left <= right:
            if len(answer) % 2 == 0:
                answer.append(left)
                left += 1
            else:
                answer.append(right)
                right -= 1

        answer.extend(range(k + 2, n + 1))
        return answer
C++ · LeetCode signature
class Solution {
public:
    vector<int> constructArray(int n, int k) {
        vector<int> answer;
        answer.reserve(n);
        int left = 1;
        int right = k + 1;

        while (left <= right) {
            if (answer.size() % 2 == 0) {
                answer.push_back(left++);
            } else {
                answer.push_back(right--);
            }
        }

        for (int value = k + 2; value <= n; ++value) {
            answer.push_back(value);
        }
        return answer;
    }
};

替代方案

也可以先递增放置 1..n−k−1，再在区间 [n−k,n] 内两端交替取数。它同样先保留差值 1，再制造 k..1，本质是把“摆动段”移到数组尾部。

面试追问

  • 为什么产生 k 种差值至少需要 k+1 个位置？
  • 能否把目标差值集合换成任意给定集合？需要哪些条件？
  • 若要求字典序最小的合法答案，当前构造是否仍然最优？
  • 空间复杂度为何写 O(1) 而不是 O(n)？返回数组是否计入？
