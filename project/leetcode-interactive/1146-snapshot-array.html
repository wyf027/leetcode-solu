Snapshot Array · 时间切片实验室

快照数组
让过去保持不变

设计一种类数组结构：它能持续接收修改，也能把某一刻编号保存下来。之后，即使当前值继续变化，仍可按快照编号读取当时的值。

非付费题 最多 50,000 次调用 四语言实现
当前数组[6, 0, 0]
快照 #0[5, 0, 0]
读取过去5

Problem brief

题意与接口

下面是官方题意的准确转述。初始数组所有位置均为 0。

需要实现的四个操作

  • SnapshotArray(int length)创建指定长度的结构，所有元素初始为 0。
  • void set(int index, int val)把当前位置 index 的值更新为 val。
  • int snap()保存当前状态，返回本次快照编号；编号等于此前调用 snap() 的次数。
  • int get(int index, int snap_id)返回编号为 snap_id 的快照中，索引 index 的值。

官方示例

输入：
["SnapshotArray","set","snap","set","get"]
[[3],[0,5],[],[0,6],[0,0]]

输出：
[null,null,0,null,5]

解释：
SnapshotArray snapshotArr = new SnapshotArray(3);
snapshotArr.set(0, 5);
snapshotArr.snap();       // 返回 snap_id = 0
snapshotArr.set(0, 6);
snapshotArr.get(0, 0);    // 返回 5

约束

  • 1 <= length <= 50,000
  • 0 <= index < length
  • 0 <= val <= 109
  • 0 <= snap_id < snap() 的总调用次数
  • set、snap、get 合计最多调用 50,000 次

Solution

只记录变化，用二分回到过去

关键不是复制整个数组，而是让每个索引只保存自己的变更历史：(snap_id, value)。查询某个快照时，在该索引的历史中寻找不晚于目标快照的最后一条记录。

01 · 稀疏记录

每个位置从 (0, 0) 开始。只有执行 set 时才留下记录，未变化的位置不复制。

02 · 同快照覆盖

若同一索引在下次 snap 前被多次设置，只更新该快照编号下的最后一条记录。

03 · 上界二分

get 找到第一个快照编号大于目标值的位置，向前一步就是应返回的版本。

完整过程

  1. 初始化：创建长度为 length 的历史数组，每个索引放入哨兵记录 (0, 0)；当前快照编号设为 0。
  2. set：查看该索引最后一条记录。若其快照编号等于当前编号，直接改值；否则追加 (currentSnapId, val)。
  3. snap：返回当前编号，再将当前编号加一。历史记录本身无需复制或移动。
  4. get：在指定索引的有序历史中，二分寻找最后一个 record.snapId <= snap_id 的记录并返回其值。

为什么正确

不变式：对任意索引，其历史按快照编号严格递增；每条记录保存该值从该快照开始生效的最新值。

初始化记录保证任何合法查询都有前驱。set 在当前编号内覆盖或追加，因此既保留最新值，也不破坏顺序。snap 只推进编号，所以过去记录不会改变。查询时，目标编号之前的最后一条记录恰好是当时仍生效的值。因此 get 返回正确结果。

复杂度

初始化O(n) 时间，建立每个索引的初始记录
set均摊 O(1)
snapO(1)
getO(log k)，k 为该索引的历史记录数
空间O(n + u)，u 为实际保留的有效更新数

import java.util.ArrayList;
import java.util.List;

class SnapshotArray {
    private final List<int[]>[] history;
    private int currentSnapId;

    @SuppressWarnings("unchecked")
    public SnapshotArray(int length) {
        history = new ArrayList[length];
        for (int i = 0; i < length; i++) {
            history[i] = new ArrayList<>();
            history[i].add(new int[]{0, 0});
        }
        currentSnapId = 0;
    }

    public void set(int index, int val) {
        List<int[]> records = history[index];
        int[] last = records.get(records.size() - 1);
        if (last[0] == currentSnapId) {
            last[1] = val;
        } else {
            records.add(new int[]{currentSnapId, val});
        }
    }

    public int snap() {
        return currentSnapId++;
    }

    public int get(int index, int snap_id) {
        List<int[]> records = history[index];
        int left = 0, right = records.size();

        while (left < right) {
            int mid = left + (right - left) / 2;
            if (records.get(mid)[0] <= snap_id) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return records.get(left - 1)[1];
    }
}

/**
 * @param {number} index
 * @param {number} val
 * @return {void}
 */
SnapshotArray.prototype.set = function(index, val) {
    const records = this.history[index];
    const last = records[records.length - 1];

    if (last[0] === this.currentSnapId) {
        last[1] = val;
    } else {
        records.push([this.currentSnapId, val]);
    }
};

from typing import List


class SnapshotArray:
    def __init__(self, length: int):
        self.current_snap_id = 0
        self.history: List[List[List[int]]] = [
            [[0, 0]] for _ in range(length)
        ]

    def set(self, index: int, val: int) -> None:
        records = self.history[index]
        if records[-1][0] == self.current_snap_id:
            records[-1][1] = val
        else:
            records.append([self.current_snap_id, val])

    def snap(self) -> int:
        snap_id = self.current_snap_id
        self.current_snap_id += 1
        return snap_id

    def get(self, index: int, snap_id: int) -> int:
        records = self.history[index]
        left, right = 0, len(records)

        while left < right:
            mid = left + (right - left) // 2
            if records[mid][0] <= snap_id:
                left = mid + 1
            else:
                right = mid

        return records[left - 1][1]
#include <climits>
#include <utility>
#include <vector>
using namespace std;

class SnapshotArray {
private:
    vector<vector<pair<int, int>>> history;
    int currentSnapId = 0;

public:
    SnapshotArray(int length) : history(length) {
        for (auto& records : history) {
            records.push_back({0, 0});
        }
    }

    void set(int index, int val) {
        auto& records = history[index];
        if (records.back().first == currentSnapId) {
            records.back().second = val;
        } else {
            records.push_back({currentSnapId, val});
        }
    }

    int snap() {
        return currentSnapId++;
    }

    int get(int index, int snap_id) {
        const auto& records = history[index];
        auto it = upper_bound(
            records.begin(),
            records.end(),
            make_pair(snap_id, INT_MAX)
        );
        return prev(it)->second;
    }
};

边界情况

  • 某个索引从未被设置：初始记录保证查询结果为 0。
  • 同一次快照前连续多次设置同一索引：只保留最后一个值。
  • 连续调用 snap() 而没有更新：不同快照读取到同一有效历史值。
  • 查询最早或最新的合法快照：上界二分都能定位正确前驱。
  • val = 0 是合法更新，不能把它误认为“没有记录”。

常见错误

  • 每次 snap 复制完整数组，导致最坏情况下时间与空间接近 O(n · s)。
  • 二分得到第一个大于目标的位置后，忘记向前移动一位。
  • 同一快照编号内重复追加记录，使空间无谓增长。
  • 先递增编号再返回，导致首个 snap_id 错成 1。
  • 没有初始哨兵，查询尚未修改的位置时出现越界。

替代方案

完整拷贝：实现直观，但每次快照要 O(n) 时间和空间，不适合 50,000 规模。

每个快照保存改动表并向前追溯：保存很快，但大量连续空快照会令查询变慢。

可持久化线段树：更新和查询均可做到 O(log n)，适合更复杂的区间能力；本题仅做单点读写时实现成本偏高。
