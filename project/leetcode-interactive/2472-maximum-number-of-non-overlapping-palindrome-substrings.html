2472. 不重叠回文子字符串的最大数目

Maximum Number of Non-overlapping Palindrome Substrings

一条字符串，若干回文片段。每个片段都要足够长，每个位置最多使用一次。

打开 LeetCode 原题 ↗

题目说明

给定字符串 s 和正整数 k。从 s 中选择一些连续子字符串，要求每一个都是回文，长度不小于 k，且任意两个所选子字符串没有公共下标。返回最多能选出的子字符串数量；没有可选片段时返回 0。

回文：从左到右、从右到左读相同。子字符串必须连续，允许相邻，也允许中间留下未使用字符。目标是数量最多，不是覆盖字符最多。

参数：s: string, k: integer
返回：integer
1 ≤ k ≤ s.length ≤ 2000
s 只包含小写英文字母

示例 1

输入：s = "abaccdbbd", k = 3
输出：2

可选 aba（下标 0–2）与 dbbd（下标 5–8）。它们都足够长且没有交叠；最多只能选两个。

示例 2

输入：s = "adbcda", k = 2
输出：0

不存在长度至少为 2 的回文子字符串。

独立题解

核心推导 · 区间演示 · 四语言实现

短回文归约 + 最早结束贪心

01 / 核心洞察

任何长度至少为 k 的回文，都可以不断删除首尾两个字符，保留一个长度恰为 k 或 k + 1 的回文。删除不改变回文性质，且不会与别的片段产生新交叠。因此，只考虑这两种长度，就足以达到最优数量。

接着把候选看作闭区间。按右端点从小到大扫描，遇到与已选片段不重叠的回文就选中：它最早结束，给后续留下的空间最多。

02 / 完整过程

  1. 设 start = 0，表示下一段允许使用的最小下标；答案为 0。
  2. 枚举右端点 r = k - 1 … n - 1。
  3. 依次尝试长度 k、k + 1，左端点为 l = r - len + 1。若 l < start，跳过。
  4. 用双指针从两端向中间比较字符，判定 s[l…r] 是否回文。
  5. 若是回文，答案加 1，令 start = r + 1，结束当前右端点的尝试，继续扫描。

长度顺序只是同一右端点的平局处理。两个候选若都合法，它们都在 r 结束，对未来可用空间的影响相同。

04 / 正确性证明
归约保持最优值。 将任意最优方案中的每个回文向中心缩短到 k 或 k + 1，得到同样数量且仍不重叠的合法片段。因此受限候选的最优值至少等于原问题最优值；它们本身也是原问题合法候选，反向不等式亦成立。
贪心交换。 在当前可用后缀上，令 G 是扫描找到的最早结束候选，O 是某个最优方案的第一个候选。因为 G 的右端点不晚于 O，用 G 替换 O 后，原方案的后续片段仍都在 G 之后，数量保持不变。因此存在以 G 开始的最优方案。
归纳推进。 选 G 后，同样的问题缩小到 G 右侧的后缀，重复交换论证即可。没有合法候选时停止；得到的数量最优。代码按 r 递增扫描且检查两种长度，确实实现最早结束选择。


05 / 边界与复杂度
  • k = 1：每个单字符都被选中，答案为 n。
  • k = n：仅整个字符串可能合法，答案为 0 或 1。
  • 长度 k 没有回文时仍需检查 k + 1，例如 s = "abba", k = 3。
  • 相邻区间合法：选到 r 后，下一个左端点可以等于 r + 1。
  • 没有合法片段时返回 0；全相同字符时答案为 ⌊n / k⌋。
时间 O(nk)，额外空间 O(1)。 每个右端点最多检查两个候选，每次双指针比较 O(k)，只保存常数个变量。在 n ≤ 2000 时，最坏界为 O(n²)。可视化为回放保存历史状态，空间消耗不属于提交解法。

Java
class Solution {
    public int maxPalindromes(String s, int k) {
        int answer = 0, start = 0;
        for (int r = k - 1; r < s.length(); r++) {
            for (int len = k; len <= k + 1; len++) {
                int l = r - len + 1;
                if (l < start) continue;
                if (isPalindrome(s, l, r)) {
                    answer++;
                    start = r + 1;
                    break;
                }
            }
        }
        return answer;
    }

    private boolean isPalindrome(String s, int l, int r) {
        while (l < r) {
            if (s.charAt(l) != s.charAt(r)) return false;
            l++;
            r--;
        }
        return true;
    }
}

class Solution:
    def maxPalindromes(self, s: str, k: int) -> int:
        def is_palindrome(l: int, r: int) -> bool:
            while l < r:
                if s[l] != s[r]:
                    return False
                l += 1
                r -= 1
            return True

        answer = 0
        start = 0
        for r in range(k - 1, len(s)):
            for length in (k, k + 1):
                l = r - length + 1
                if l < start:
                    continue
                if is_palindrome(l, r):
                    answer += 1
                    start = r + 1
                    break
        return answer

#include <string>
using namespace std;

class Solution {
    bool isPalindrome(const string& s, int l, int r) {
        while (l < r) {
            if (s[l] != s[r]) return false;
            ++l;
            --r;
        }
        return true;
    }
public:
    int maxPalindromes(string s, int k) {
        int answer = 0, start = 0;
        for (int r = k - 1; r < static_cast<int>(s.size()); ++r) {
            for (int len = k; len <= k + 1; ++len) {
                int l = r - len + 1;
                if (l < start) continue;
                if (isPalindrome(s, l, r)) {
                    ++answer;
                    start = r + 1;
                    break;
                }
            }
        }
        return answer;
    }
};




07 / 替代方案
回文表 + 前缀 DP： 先计算 pal[l][r] = s[l] == s[r] && (r - l < 2 || pal[l+1][r-1])，按区间长度从短到长填表。令 dp[i] 表示前 i 个字符的最大数量，初值 dp[0] = 0。先令 dp[i] = dp[i-1]，再枚举 0 ≤ l ≤ i-k；若 pal[l][i-1] 为真，则用 dp[l] + 1 更新 dp[i]。时间 O(n²)，空间 O(n²)。它无需短回文归约，但更占内存。
更大规模： Manacher 预处理奇偶回文半径后，可 O(1) 判定每个长度 k / k+1 候选，再用相同贪心，总时间 O(n)、空间 O(n)。本题范围内双指针实现更直接。


08 / 常见错误
  • 只检查长度 k，遗漏另一种奇偶性。
  • 先选最长回文：s = "aaaaaa", k = 2 中，选整串只得 1，选三个 aa 得 3。
  • 混淆最早开始和最早结束；交换证明依赖右端点顺序。
  • 把回文子序列当作子字符串，允许跳过字符。
  • 选中后没有跳出长度循环，或把 start 设为 r，可能重复使用同一位置。
  • 认为缩短只能得到 k：长度每次减 2，必须保留 k 与 k+1 两种长度。


09 / 面试追问
  • 如果最大化所选总长度？ 缩短归约不再保持目标值，最早结束贪心也不保证最优；可对回文区间使用带权区间 DP。
  • 如何返回具体区间？ 每次贪心选中时记录 [l, r]，输出区间列表；额外空间 O(答案数量)。
  • 为何同一 r 先查 k？ 两种长度结束位置相同，只要不重叠，任选其一都保留同样的后缀。
  • 如果字符串达到百万长度？ 双指针重复比较可能太慢，使用回文半径加速候选判定。
