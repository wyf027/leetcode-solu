准备好再看题解

先自己判断每一对数字能否合并；完整状态转移默认隐藏。

题解：合法双位数才多一条路

核心洞察

设 dp[i] 为前 i 位的解密方案数。最后一位必可单独翻译，继承 dp[i-1]；若最后两位组成的数在 10–25，还可把它们合并，额外加上 dp[i-2]。只需保存前两项。

完整过程

  1. 把整数转字符串；初始前两项都为 1。
  2. 从第二位开始，默认 current = prev。
  3. 双位数在 10 到 25 时，令 current += prevPrev；滚动更新。

边界与复杂度

0 只有一种翻译；10、25 可合并，06 不可合并。时间 O(n)，滚动变量 O(1) 空间。

替代方案、追问与常见错误

完整 DP 数组更易展示每步值，但不必保留全部。追问：若允许任意编码表，可改为 trie/词典 DP。常见错误：把 0–9 的两位写法也合并，或把 26 错当合法。

class Solution {
    public int crackNumber(int ciphertext) {
        String s = String.valueOf(ciphertext);
        int prevPrev = 1, prev = 1;
        for (int i = 1; i < s.length(); i++) {
            int current = prev, pair = (s.charAt(i - 1) - '0') * 10 + s.charAt(i) - '0';
            if (pair >= 10 && pair <= 25) current += prevPrev;
            prevPrev = prev; prev = current;
        }
        return prev;
    }
}
