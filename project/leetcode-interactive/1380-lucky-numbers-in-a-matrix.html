EASY数组矩阵Lucky Numbers in a Matrix

题目

给定一个 m × n 的整数矩阵 matrix，其中所有数字互不相同。返回矩阵中的所有幸运数，顺序不限。

一个元素是幸运数，当且仅当它既是所在行的最小值，又是所在列的最大值。

官方示例

示例 1

输入：matrix =
[[3,7,8],
 [9,11,13],
 [15,16,17]]
输出：[15]
解释：15 是本行最小值，
也是本列最大值。

示例 2

输入：matrix =
[[1,10,4,2],
 [9,3,8,7],
 [15,16,17,12]]
输出：[12]
解释：12 同时满足两项条件。

示例 3

输入：matrix =
[[7,8],
 [1,2]]
输出：[7]
解释：7 是第一行最小值，
也是第一列最大值。

约束

  • m == matrix.length
  • n == matrix[i].length
  • 1 ≤ m, n ≤ 50
  • 1 ≤ matrix[i][j] ≤ 10⁵
  • 矩阵中的所有元素互不相同
  • 返回所有答案，顺序不限

Solution

题解：预处理行最小值与列最大值

核心洞察

条件是两个集合的交集：候选元素必须属于“每行最小值集合”，同时属于“每列最大值集合”。先算出每行最小值、每列最大值，再逐格检查。元素互不相同保证极值位置唯一，但算法本身也能处理重复值。

完整过程

1
计算行最小值。第 i 行的结果记为 rowMin[i]。
2
计算列最大值。第 j 列的结果记为 colMax[j]。
3
检查所有坐标。若 matrix[i][j] == rowMin[i] 且 matrix[i][j] == colMax[j]，加入答案。

正确性证明

充分性：算法加入 matrix[i][j] 时，它等于本行最小值与本列最大值，所以按定义是幸运数。

必要性：任意幸运数必等于对应的 rowMin[i] 和 colMax[j]；扫描该坐标时一定被加入。因此返回结果不多不少。

复杂度

时间复杂度 O(mn)；两个辅助数组占用 O(m+n) 空间。只保存列最大值、逐行现场求最小时可降到 O(n)。

边界情况

  • 单行：该行最小值也是所在列唯一元素。
  • 单列：整列最大值也是所在行唯一元素。
  • 最大 50 × 50：线性扫描足够。

替代方案

可把所有行最小值放入集合，再逐列求最大值并检查集合，时间仍为 O(mn)，空间为 O(m)。逐元素重扫整行整列则需 O(mn(m+n))，不推荐。

四种语言完整代码

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<Integer> luckyNumbers(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int[] rowMin = new int[m], colMax = new int[n];
        Arrays.fill(rowMin, Integer.MAX_VALUE);
        Arrays.fill(colMax, Integer.MIN_VALUE);

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                rowMin[i] = Math.min(rowMin[i], matrix[i][j]);
                colMax[j] = Math.max(colMax[j], matrix[i][j]);
            }
        }
        List<Integer> answer = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (matrix[i][j] == rowMin[i]
                        && matrix[i][j] == colMax[j]) {
                    answer.add(matrix[i][j]);
                }
            }
        }
        return answer;
    }
}

class Solution:

        row_min = [float("inf")] * m
        col_max = [float("-inf")] * n

        for i in range(m):
            for j in range(n):
                row_min[i] = min(row_min[i], matrix[i][j])
                col_max[j] = max(col_max[j], matrix[i][j])

        for i in range(m):
            for j in range(n):
                if (matrix[i][j] == row_min[i]
                        and matrix[i][j] == col_max[j]):
                    answer.append(matrix[i][j])
        return answer

面试追问

  • 能否只扫描两遍？可以，第一遍同时维护行最小与列最大，第二遍收集答案。
  • 如何降空间？只保留列最大数组，第二遍逐行现场求最小值，辅助空间 O(n)。
  • 允许重复值怎么办？按“最小/最大”的定义，代码不必修改，但可能有多个位置满足条件。
  • 一定存在幸运数吗？取所有行最小值中最大的那个，它不会小于同列其他行的行最小值；结合其为所在行最小值可推出它是该列最大值，因此至少存在一个。

常见错误

  • 把条件方向写反成“行最大、列最小”。
  • 列循环边界误用 matrix.length，非方阵会漏算或越界。
  • 只判断一种极值条件，或使用了错误的行列索引。
  • 把列最大初值写死为 0；本题虽为正数，使用负无穷更通用。
