Problem

先理解“唯一”究竟要求什么

这一部分只陈述问题和样例，不直接给出解法。你可以先在脑中判断：哪些局部关系足以锁定全局顺序？

题意转述

给定整数数组 nums，它由 1..n 的每个数字恰好一次组成；再给定二维数组 sequences，其中每个子数组都描述了若干数字必须保持的相对顺序。

若一个序列能把 sequences 中的每个子数组都作为子序列容纳，它就是这些子数组的公共超序列。请判断 nums 是否恰好是唯一的最短公共超序列。换句话说，所有局部顺序是否既覆盖了目标中的每个数，又只允许得到 nums 这一种最短全局顺序。

官方参数形式： sequenceReconstruction(nums: integer[], sequences: list<list<integer>>): boolean

约束

  • n == nums.length
  • 1 ≤ n ≤ 10⁴
  • nums 是 [1, n] 的一个排列
  • 1 ≤ sequences.length ≤ 10⁴
  • 1 ≤ sequences[i].length ≤ 10⁴
  • 所有子数组的长度总和不超过 10⁵
  • 1 ≤ sequences[i][j] ≤ n，每个子数组内元素互异
  • 每个 sequences[i] 都是 nums 的子序列

示例 1

false 
输入：nums = [1,2,3]
sequences = [[1,2],[1,3]]
输出：false

关系只规定 1 在 2、3 前；[1,2,3] 与 [1,3,2] 都同样短。

Full Solution

唯一拓扑序：把“恰好一个选择”变成不变量

核心洞察

每个子序列中的相邻数字 a, b 都意味着一条边 a → b。所有边共同构成一个偏序。问题于是变成：

nums 是图的唯一拓扑序 ⇔ Kahn 每一轮都恰好只有一个零入度节点，且它等于 nums[i]

若候选为 0，图中出现矛盾或环；若候选大于 1，可以交换至少两个当前候选的先后位置，拓扑序不唯一；若唯一候选不是目标当前位置，目标顺序不匹配。

为什么还要检查覆盖

仅凭边不能证明 sequences 真正要求目标中的每个数字出现。比如 [[1,2]] 根本没有约束数字 3，而最短公共超序列无需包含它。

因此建图时记录所有在输入子序列里出现过的点；覆盖数不是 n 时立即返回 false。实现仍预先为 nums 的每个点建邻接表，便于统一处理。

完整过程

  1. 初始化图与入度为 nums 中每个数字建立邻接集合；集合可以阻止重复边被重复计数。
  2. 扫描局部序列标记出现过的数字，并把每对相邻元素变成一条有向边。只有新边才增加终点入度。
  3. 拒绝不完整覆盖若出现过的不同数字少于 n，nums 不可能是给定子序列的唯一最短公共超序列。
  4. 启动 Kahn 拓扑排序把所有入度为 0 的节点放入队列。
  5. 每轮执行两道门禁队列大小必须是 1；唯一候选还必须等于 nums 当前元素。任一条件失败即返回 false。
  6. 删除唯一候选降低它所有后继的入度，新入度为 0 的后继进入队列，然后检查下一位置。
  7. 确认完整消费最终匹配位置必须恰好到达 n，才返回 true。

正确性证明

引理 1：Kahn 队列中的节点，恰好是尚未输出且其所有前驱均已输出的节点，因此它们都是当前合法的下一元素。

引理 2：若任一步队列含至少两个节点，则选择其中任意一个都不违反已知边；至少存在两个不同的拓扑序，所以 nums 不唯一。

引理 3：若每一步队列恰有一个节点，则所有合法拓扑序在该位置都只能选择此节点。归纳可知整个拓扑序唯一。

结论：算法还逐位要求该唯一节点等于 nums，并确认所有目标节点均被 sequences 覆盖、最终全部处理。因此返回 true 当且仅当 nums 是唯一的最短公共超序列。

复杂度与边界

设 n = nums.length，所有子序列元素总数为 L，去重后的边数为 E。

  • 时间：O(n + L + E)，且 E ≤ L。
  • 空间：O(n + E)。
  • n = 1 时仍需确认数字 1 被输入覆盖。
  • 重复边必须去重，否则入度会被多加却无法正确归零。
  • 稳健实现可拒绝不属于 nums 的数字，即使正式约束通常保证输入合法。

class Solution {
    public boolean sequenceReconstruction(int[] nums, List<List<Integer>> sequences) {
        int n = nums.length;
        Map<Integer, Set<Integer>> graph = new HashMap<>();
        Map<Integer, Integer> indegree = new HashMap<>();
        Set<Integer> valid = new HashSet<>();

        for (int value : nums) {
            graph.put(value, new HashSet<>());
            indegree.put(value, 0);
            valid.add(value);
        }

        Set<Integer> seen = new HashSet<>();
        for (List<Integer> sequence : sequences) {
            for (int i = 0; i < sequence.size(); i++) {
                int value = sequence.get(i);
                if (!valid.contains(value)) return false;
                seen.add(value);

                if (i > 0) {
                    int from = sequence.get(i - 1);
                    int to = value;
                    if (graph.get(from).add(to)) {
                        indegree.put(to, indegree.get(to) + 1);
                    }
                }
            }
        }

        if (seen.size() != n) return false;

        Deque<Integer> queue = new ArrayDeque<>();
        for (int value : nums) {
            if (indegree.get(value) == 0) queue.offer(value);
        }

        int index = 0;
        while (!queue.isEmpty()) {
            if (queue.size() != 1) return false;

            int current = queue.poll();
            if (index == n || nums[index] != current) return false;
            index++;

            for (int next : graph.get(current)) {
                int nextDegree = indegree.get(next) - 1;
                indegree.put(next, nextDegree);
                if (nextDegree == 0) queue.offer(next);
            }
        }

        return index == n;
    }
}

var sequenceReconstruction = function(nums, sequences) {
    const n = nums.length;
    const valid = new Set(nums);
    const graph = new Map();
    const indegree = new Map();

    for (const value of nums) {
        graph.set(value, new Set());
        indegree.set(value, 0);
    }

    const seen = new Set();
    for (const sequence of sequences) {
        for (let i = 0; i < sequence.length; i++) {
            const value = sequence[i];
            if (!valid.has(value)) return false;
            seen.add(value);

            if (i > 0) {
                const from = sequence[i - 1];
                const to = value;
                if (!graph.get(from).has(to)) {
                    graph.get(from).add(to);
                    indegree.set(to, indegree.get(to) + 1);
                }
            }
        }
    }

    if (seen.size !== n) return false;

    const queue = [];
    let head = 0;
    for (const value of nums) {
        if (indegree.get(value) === 0) queue.push(value);
    }

    let index = 0;
    while (head < queue.length) {
        if (queue.length - head !== 1) return false;

        const current = queue[head++];
        if (index === n || nums[index] !== current) return false;
        index++;

        for (const next of graph.get(current)) {
            indegree.set(next, indegree.get(next) - 1);
            if (indegree.get(next) === 0) queue.push(next);
        }
    }

    return index === n;
};
from collections import deque
from typing import List


class Solution:
    def sequenceReconstruction(
        self, nums: List[int], sequences: List[List[int]]
    ) -> bool:
        n = len(nums)
        valid = set(nums)
        graph = {value: set() for value in nums}
        indegree = {value: 0 for value in nums}
        seen = set()

        for sequence in sequences:
            for i, value in enumerate(sequence):
                if value not in valid:
                    return False
                seen.add(value)

                if i > 0:
                    previous = sequence[i - 1]
                    if value not in graph[previous]:
                        graph[previous].add(value)
                        indegree[value] += 1

        if len(seen) != n:
            return False

        queue = deque(value for value in nums if indegree[value] == 0)
        index = 0

        while queue:
            if len(queue) != 1:
                return False

            current = queue.popleft()
            if index == n or nums[index] != current:
                return False
            index += 1

            for next_value in graph[current]:
                indegree[next_value] -= 1
                if indegree[next_value] == 0:
                    queue.append(next_value)

        return index == n
class Solution {
public:
    bool sequenceReconstruction(
        vector<int>& nums,
        vector<vector<int>>& sequences
    ) {
        const int n = static_cast<int>(nums.size());
        vector<unordered_set<int>> graph(n + 1);
        vector<int> indegree(n + 1, 0);
        vector<bool> valid(n + 1, false);
        vector<bool> seen(n + 1, false);

        for (int value : nums) valid[value] = true;

        int covered = 0;
        for (const auto& sequence : sequences) {
            for (int i = 0; i < static_cast<int>(sequence.size()); ++i) {
                int value = sequence[i];
                if (value < 1 || value > n || !valid[value]) return false;
                if (!seen[value]) {
                    seen[value] = true;
                    ++covered;
                }

                if (i > 0) {
                    int from = sequence[i - 1];
                    if (graph[from].insert(value).second) {
                        ++indegree[value];
                    }
                }
            }
        }

        if (covered != n) return false;

        queue<int> candidates;
        for (int value : nums) {
            if (indegree[value] == 0) candidates.push(value);
        }

        int index = 0;
        while (!candidates.empty()) {
            if (candidates.size() != 1) return false;

            int current = candidates.front();
            candidates.pop();
            if (index == n || nums[index] != current) return false;
            ++index;

            for (int next : graph[current]) {
                if (--indegree[next] == 0) candidates.push(next);
            }
        }

        return index == n;
    }
};

替代方案

在本题保证所有局部序列都是 nums 子序列时，还可以检查 nums 中每对相邻元素是否至少被某个局部序列直接约束。它更短，但唯一拓扑排序法语义更通用，也能自然处理非法顺序与环。

常见错误

  • 只验证 nums 是某个拓扑序，忘记验证“唯一”。
  • 用列表保存边，重复关系导致入度重复累计。
  • 忘记覆盖检查，把缺失数字也当成必须出现。
  • 只在最后比较拓扑序，没有在每轮检查候选数。
