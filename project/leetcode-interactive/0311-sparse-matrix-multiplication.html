311. 稀疏矩阵的乘法

把两个矩阵相乘，但别让大片的零拖慢思考。先理解输入、输出与乘法规则，再进入逐步实验室观察数值如何汇入结果矩阵。

先读题目 ↓
Problem

题目转述

函数签名：multiply(mat1, mat2)。输入保证尺寸相容，可以完成矩阵乘法。

给定两个稀疏整数矩阵 mat1 和 mat2：mat1 的尺寸为 m × k，mat2 的尺寸为 k × n。

返回它们的矩阵乘积 mat1 × mat2。结果是一个 m × n 矩阵，其中第 i 行、第 j 列的元素等于 mat1 第 i 行与 mat2 第 j 列的点积。

“稀疏”表示多数元素为零；答案数值与普通矩阵乘法完全相同，优化空间来自避免无意义的零乘法。

C[i][j] = Σ mat1[i][t] × mat2[t][j]
示例 1 · 完整参数形式
输入：mat1 = [[1,0,0],[-1,0,3]], mat2 = [[7,0,0],[0,0,0],[0,0,1]] 输出：[[7,0,0],[-7,0,3]]

第一行只产生 1 × 7；第二行的两个非零值分别贡献 -1 × 7 与 3 × 1。

示例 2 · 完整参数形式
输入：mat1 = [[0]], mat2 = [[0]] 输出：[[0]]
约束
m == mat1.length
k == mat1[i].length == mat2.length
n == mat2[i].length
1 ≤ m, k, n ≤ 100
-100 ≤ mat1[i][j] ≤ 100
-100 ≤ mat2[i][j] ≤ 100

Solution

把非零值当作“贡献源”

核心洞察

若 mat1[i][t] = 0，它对结果第 i 行没有任何贡献，可以直接跳过。若它非零，只需访问 mat2 第 t 行中的非零项 (j, value)，执行：

result[i][j] += mat1[i][t] × value

完整过程

  1. 扫描 mat2，把每一行压缩成“列下标 + 非零值”列表。
  2. 创建全零的 m × n 结果矩阵。
  3. 按行扫描 mat1；跳过零，只展开非零值对应的 mat2 压缩行。
  4. 将每个乘积累加到正确的结果格。

边界情况

  • 任一输入是全零矩阵：结果保持全零。
  • 负数贡献可能互相抵消，不能把“非零贡献”误认为“非零结果”。
  • 矩阵可以是长方形；只依赖共享维度 k 相等。
  • 单行、单列和 1 × 1 无需特殊分支。

复杂度

令 S = Σ nnz(mat2[t])，求和范围是所有满足 mat1[i][t] ≠ 0 的位置。

时间：O(k·n + m·k + S)。空间：压缩列表 O(nnz(mat2))，另加必须返回的 O(m·n) 结果。

正确性证明

初始化：结果矩阵全为零，等于尚未处理任何共享维度贡献时的部分和。
保持：处理某个非零 mat1[i][t] 时，算法遍历 mat2[t] 的每个非零 mat2[t][j]，恰好把乘积加入 result[i][j]。mat2[t][j] = 0 的项贡献为零，省略不改变部分和；mat1[i][t] = 0 时整行贡献也为零。
终止：所有 (i,t) 都被处理或因零值安全跳过。于是每个 result[i][j] 都包含且只包含所有 t 的 mat1[i][t] × mat2[t][j]，正是矩阵乘积定义。

替代方案

  • 朴素三重循环：O(mkn)，最直观但没有利用稀疏性。
  • 转置 mat2 后做点积：缓存友好，但若仍逐格扫描，稀疏收益有限。
  • 两边都压缩为哈希映射：极稀疏时合适，但对象与哈希常数更大。
  • CSR / CSC：工程级稀疏矩阵库常用，适合规模更大且多次运算的场景。

面试追问

  • 如果同一份 mat2 要被重复使用，如何缓存压缩表示？
  • 如果输出本身也极稀疏，怎样避免分配完整 m × n 数组？
  • 怎样选择“压缩 A 的行”或“压缩 B 的行/列”？
  • 并行化时如何避免多个线程竞争写同一个结果格？

常见错误

  • 把 mat2 的“第 t 行”写成“第 t 列”，导致索引关系错误。
  • 直接赋值 result[i][j] = product，忘记不同 t 的贡献需要累加。
  • 错误地假设非零乘积不会抵消；整数负值可能让结果重新变为零。
  • 用字符串键保存坐标却解析错误，或在 JavaScript 中复用同一个结果行数组。
  • 复杂度只写 O(nnz(A)+nnz(B))；一个 A 的非零值可能展开 B 对应行的多个非零项。
Implementations

四语言完整代码

四份实现使用同一策略：先压缩 mat2 的每一行，再传播 mat1 的非零贡献。

JavaLeetCode 提交形式
import java.util.ArrayList;
import java.util.List;

class Solution {
    public int[][] multiply(int[][] mat1, int[][] mat2) {
        int m = mat1.length;
        int k = mat1[0].length;
        int n = mat2[0].length;

        @SuppressWarnings("unchecked")
        List<int[]>[] nonZeroByRow = new ArrayList[k];
        for (int row = 0; row < k; row++) {
            nonZeroByRow[row] = new ArrayList<>();
            for (int col = 0; col < n; col++) {
                if (mat2[row][col] != 0) {
                    nonZeroByRow[row].add(new int[] {col, mat2[row][col]});
                }
            }
        }

        int[][] result = new int[m][n];
        for (int row = 0; row < m; row++) {
            for (int shared = 0; shared < k; shared++) {
                int left = mat1[row][shared];
                if (left == 0) {
                    continue;
                }
                for (int[] entry : nonZeroByRow[shared]) {
                    int col = entry[0];
                    int right = entry[1];
                    result[row][col] += left * right;
                }
            }
        }
        return result;
    }
}
JavaScriptLeetCode 提交形式
/**
 * @param {number[][]} mat1
 * @param {number[][]} mat2
 * @return {number[][]}
 */
var multiply = function(mat1, mat2) {
    const m = mat1.length;
    const k = mat1[0].length;
    const n = mat2[0].length;

    const nonZeroByRow = Array.from({ length: k }, () => []);
    for (let row = 0; row < k; row++) {
        for (let col = 0; col < n; col++) {
            if (mat2[row][col] !== 0) {
                nonZeroByRow[row].push([col, mat2[row][col]]);
            }
        }
    }

    const result = Array.from({ length: m }, () => Array(n).fill(0));
    for (let row = 0; row < m; row++) {
        for (let shared = 0; shared < k; shared++) {
            const left = mat1[row][shared];
            if (left === 0) continue;

            for (const [col, right] of nonZeroByRow[shared]) {
                result[row][col] += left * right;
            }
        }
    }
    return result;
};
PythonLeetCode 提交形式
from typing import List


class Solution:
    def multiply(
        self, mat1: List[List[int]], mat2: List[List[int]]
    ) -> List[List[int]]:
        m, k, n = len(mat1), len(mat1[0]), len(mat2[0])

        non_zero_by_row = [[] for _ in range(k)]
        for row in range(k):
            for col in range(n):
                if mat2[row][col] != 0:
                    non_zero_by_row[row].append((col, mat2[row][col]))

        result = [[0] * n for _ in range(m)]
        for row in range(m):
            for shared in range(k):
                left = mat1[row][shared]
                if left == 0:
                    continue
                for col, right in non_zero_by_row[shared]:
                    result[row][col] += left * right

        return result
C++LeetCode 提交形式
#include <utility>
#include <vector>
using namespace std;

class Solution {
public:
    vector<vector<int>> multiply(
        vector<vector<int>>& mat1,
        vector<vector<int>>& mat2
    ) {
        const int m = static_cast<int>(mat1.size());
        const int k = static_cast<int>(mat1[0].size());
        const int n = static_cast<int>(mat2[0].size());

        vector<vector<pair<int, int>>> nonZeroByRow(k);
        for (int row = 0; row < k; ++row) {
            for (int col = 0; col < n; ++col) {
                if (mat2[row][col] != 0) {
                    nonZeroByRow[row].push_back({col, mat2[row][col]});
                }
            }
        }

        vector<vector<int>> result(m, vector<int>(n, 0));
        for (int row = 0; row < m; ++row) {
            for (int shared = 0; shared < k; ++shared) {
                const int left = mat1[row][shared];
                if (left == 0) {
                    continue;
                }
                for (const auto& [col, right] : nonZeroByRow[shared]) {
                    result[row][col] += left * right;
                }
            }
        }
        return result;
    }
};
