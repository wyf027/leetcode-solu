Graph Valid Tree

一张有 n 个节点的无向图是树，当且仅当它有 n − 1 条边且不成环。先用边数快速剪枝，再用并查集尝试合并每一条边：连接已属于同一集合的端点就是环。

🌿 并查集 · 无环 + n−1 条边

题意

给定 n 个编号 0 到 n−1 的节点，以及无向边数组 edges。判断这些边能否构成一棵有效树。

官方样例 1n = 5 edges = [[0, 1], [0, 2], [0, 3], [1, 4]]

5 个节点、4 条边且无环，期望：true。

官方样例 2n = 5 edges = [[0, 1], [1, 2], [2, 3], [1, 3], [1, 4]]

1→2→3→1 构成环，期望：false。

约束：公开题目版本中 1 ≤ n ≤ 2000、0 ≤ edges.length ≤ 5000，节点编号合法。本题为 LeetCode Premium，未跳过。

题解：边数门槛与并查集

核心洞察

一棵 n 节点树恰有 n−1 边。满足此边数时，只要无环就必连通；反之，不连通的 n−1 边图必有另一个分量内部存在环。并查集正好能在线报告“这条边是否把同一分量再次相连”。

完整过程

  1. 若 edges.length != n - 1，直接返回 false。
  2. 初始化每个节点的父节点为自己。
  3. 对每条边求两个根；根相同则发现环，返回 false。
  4. 否则合并两个根；全部边处理完即 true。

边界

n=1 且无边是树；边数不足必不连通；边数过多必有环；自环和重复边在合并时都会被识别为环（题目通常给出简单图）。

复杂度与替代方案

并查集时间 O(E·α(n))，空间 O(n)。替代方案：先确认 n−1 条边，再从任意节点 BFS/DFS，若访问数为 n 即树；它也为 O(n+E)。

面试追问

若边流持续加入，可在维护组件数与是否成环的同时实时判断；若要找冗余边，返回首次 union 失败的边；有向图是否为树则要检查入度与可达性。

常见错误

只判断无环而忘了连通性；没有先检查 n−1 条边；把无向边建成单向；union 时比较节点本身而非根；未路径压缩导致退化。

class Solution {
    public boolean validTree(int n, int[][] edges) {
        if (edges.length != n - 1) return false;
        int[] parent = new int[n]; for (int i = 0; i < n; i++) parent[i] = i;
        for (int[] edge : edges) { int a = find(parent, edge[0]), b = find(parent, edge[1]); if (a == b) return false; parent[a] = b; }
        return true;
    }
    private int find(int[] parent, int x) { return parent[x] == x ? x : (parent[x] = find(parent, parent[x])); }
}
