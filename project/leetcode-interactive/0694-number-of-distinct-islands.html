694. 不同岛屿的数量 Number of Distinct Islands

一张只由海水与陆地构成的网格。你的任务不是数出所有岛屿，而是判断其中出现了多少种只考虑平移的不同轮廓。

中等 会员题 函数：numDistinctIslands(grid) 返回：integer

01 · Brief

题目说明

给定一个由 0 和 1 组成的二维整数数组 grid，其中 0 表示水域，1 表示陆地。上下左右相邻的陆地连成一座岛屿；网格四周视为水域。

如果一座岛屿可以仅通过平移与另一座岛屿完全重合，那么两者形状相同。旋转与翻转都不算作平移，因此不会让两个原本不同的轮廓变成同一种形状。

返回网格中不同岛屿形状的数量。

比较的是相对轮廓，而不是岛屿在网格中的绝对坐标。题目保证输入是规则矩阵。

约束

  • m == grid.length
  • n == grid[i].length
  • 1 <= m, n <= 50
  • grid[i][j] ∈ {0, 1}
深度优先搜索广度优先搜索并查集数组哈希表矩阵排序哈希函数

05 · Solution Vault

建议先亲手写出“如何让同一形状在不同位置得到相同表示”，再打开完整题解。

Canonical Shape

题解：给每座岛屿制作坐标指纹

下面采用迭代 DFS 收集坐标、平移归一化、排序后放入哈希集合。四份代码都会原地把访问过的陆地改为 0。

核心洞察

绝对坐标会随岛屿位置变化，但岛内每个格子相对同一个锚点的偏移不会。扫描遇到一座新岛时，以它的第一个格子 (baseRow, baseCol) 为锚点，将每个陆地格记录为 (row - baseRow, col - baseCol)。

把所有偏移按“行优先、列其次”排序并序列化，就是只与形状有关的规范签名。哈希集合最终保存多少个签名，就有多少种形状。

完整过程

  1. 按行扫描网格；遇到值为 1 的格子，开始处理一座尚未访问的岛屿。
  2. 以当前格为锚点，用栈沿四个方向遍历整座岛；格子入栈时立即改为 0，防止重复入栈。
  3. 收集每个格子相对锚点的坐标，遍历结束后排序。
  4. 将排序后的坐标序列作为签名放入集合；重复签名不会增加集合大小。
  5. 扫描结束，返回集合大小。

正确性说明

  1. 遍历完整性：四方向 DFS 从任意岛内格出发，会访问且只访问同一座岛上的所有格子。
  2. 平移不变性：若岛屿整体平移 (Δr, Δc)，格子和锚点都增加同一偏移；两者相减后，相对坐标不变。
  3. 可区分性：若两个排序后的相对坐标集合相同，将锚点对齐后，它们的每个陆地位置一一对应，因此两岛仅相差平移；反之，不同集合不可能仅靠平移重合。
  4. 结论：集合中的每个签名恰好对应一种平移意义下的岛屿形状，所以集合大小就是答案。

复杂度

设网格共有 M = m × n 个格子、陆地格总数为 K。每格至多进栈一次；若各岛大小为 kᵢ，排序总成本为 Σ kᵢ log kᵢ ≤ K log K。

时间O(M + K log K)
额外空间O(K)

最坏情况下可写为时间 O(mn log(mn))、空间 O(mn)。修改输入网格不计入额外空间。

边界情况

  • 全是水：集合保持为空，返回 0。
  • 全是陆地：只有一座岛，也只有一种形状。
  • 多个单格岛：坐标签名都为 0:0，只计一种。
  • 细长或蛇形大岛：迭代遍历避免深递归带来的调用栈风险。
  • 旋转或镜像：相对坐标集合不同，应当计为不同形状。

替代方案与面试追问

  • 路径编码：固定方向顺序，记录进入方向与回退标记，可在线性时间得到签名；漏掉回退标记容易发生碰撞。
  • BFS：同样收集相对坐标，结论不变。
  • 并查集：可以先分组，但仍要为每个连通块构造规范形状，通常更繁琐。
  • 追问：若旋转与翻转也视为相同，应生成一个形状的 8 种变换，各自平移归一化，取字典序最小者作为签名。

常见错误

  • 直接把绝对坐标放入集合，同一形状换个位置就会被误判为不同。
  • 相对坐标未排序；栈或队列的访问顺序变化时，相同形状可能产生不同序列。
  • 把对角线当成相邻；本题只有上、下、左、右四个方向。
  • 无意中把旋转或翻转归一化；本题只允许平移。
  • 出栈后才标记访问，导致同一格被多个邻居重复压栈。
  • 忘记算法会修改 grid；如果调用方还要使用原网格，应先复制。

import java.util.*;

class Solution {
    public int numDistinctIslands(int[][] grid) {
        int rows = grid.length;
        int cols = grid[0].length;
        int[][] directions = {{-1, 0}, {0, 1}, {1, 0}, {0, -1}};
        Set<String> shapes = new HashSet<>();

        for (int row = 0; row < rows; row++) {
            for (int col = 0; col < cols; col++) {
                if (grid[row][col] == 0) {
                    continue;
                }

                int baseRow = row;
                int baseCol = col;
                List<int[]> cells = new ArrayList<>();
                Deque<int[]> stack = new ArrayDeque<>();
                stack.push(new int[]{row, col});
                grid[row][col] = 0;

                while (!stack.isEmpty()) {
                    int[] current = stack.pop();
                    int currentRow = current[0];
                    int currentCol = current[1];
                    cells.add(new int[]{
                        currentRow - baseRow,
                        currentCol - baseCol
                    });

                    for (int[] direction : directions) {
                        int nextRow = currentRow + direction[0];
                        int nextCol = currentCol + direction[1];
                        if (nextRow >= 0 && nextRow < rows
                                && nextCol >= 0 && nextCol < cols
                                && grid[nextRow][nextCol] == 1) {
                            grid[nextRow][nextCol] = 0;
                            stack.push(new int[]{nextRow, nextCol});
                        }
                    }
                }

                cells.sort((a, b) -> a[0] != b[0]
                    ? Integer.compare(a[0], b[0])
                    : Integer.compare(a[1], b[1]));
                StringBuilder signature = new StringBuilder();
                for (int[] cell : cells) {
                    signature.append(cell[0]).append(':')
                             .append(cell[1]).append('|');
                }
                shapes.add(signature.toString());
            }
        }

        return shapes.size();
    }
}

var numDistinctIslands = function(grid) {
  const rows = grid.length;
  const cols = grid[0].length;
  const directions = [[-1, 0], [0, 1], [1, 0], [0, -1]];
  const shapes = new Set();

  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < cols; col++) {
      if (grid[row][col] === 0) continue;

      const baseRow = row;
      const baseCol = col;
      const cells = [];
      const stack = [[row, col]];
      grid[row][col] = 0;

      while (stack.length > 0) {
        const [currentRow, currentCol] = stack.pop();
        cells.push([currentRow - baseRow, currentCol - baseCol]);

        for (const [rowDelta, colDelta] of directions) {
          const nextRow = currentRow + rowDelta;
          const nextCol = currentCol + colDelta;
          if (
            nextRow >= 0 && nextRow < rows &&
            nextCol >= 0 && nextCol < cols &&
            grid[nextRow][nextCol] === 1
          ) {
            grid[nextRow][nextCol] = 0;
            stack.push([nextRow, nextCol]);
          }
        }
      }

      cells.sort((a, b) => a[0] - b[0] || a[1] - b[1]);
      const signature = cells
        .map(([relativeRow, relativeCol]) => `${relativeRow}:${relativeCol}`)
        .join('|');
      shapes.add(signature);
    }
  }

  return shapes.size;
};

from typing import List


class Solution:
    def numDistinctIslands(self, grid: List[List[int]]) -> int:
        rows = len(grid)
        cols = len(grid[0])
        directions = ((-1, 0), (0, 1), (1, 0), (0, -1))
        shapes = set()

        for row in range(rows):
            for col in range(cols):
                if grid[row][col] == 0:
                    continue

                base_row, base_col = row, col
                cells = []
                stack = [(row, col)]
                grid[row][col] = 0

                while stack:
                    current_row, current_col = stack.pop()
                    cells.append((
                        current_row - base_row,
                        current_col - base_col,
                    ))

                    for row_delta, col_delta in directions:
                        next_row = current_row + row_delta
                        next_col = current_col + col_delta
                        if (
                            0 <= next_row < rows
                            and 0 <= next_col < cols
                            and grid[next_row][next_col] == 1
                        ):
                            grid[next_row][next_col] = 0
                            stack.append((next_row, next_col))

                cells.sort()
                shapes.add(tuple(cells))

        return len(shapes)

#include <algorithm>
#include <set>
#include <stack>
#include <utility>
#include <vector>

using namespace std;

class Solution {
public:
    int numDistinctIslands(vector<vector<int>>& grid) {
        const int rows = grid.size();
        const int cols = grid[0].size();
        const int directions[4][2] = {
            {-1, 0}, {0, 1}, {1, 0}, {0, -1}
        };
        set<vector<pair<int, int>>> shapes;

        for (int row = 0; row < rows; ++row) {
            for (int col = 0; col < cols; ++col) {
                if (grid[row][col] == 0) {
                    continue;
                }

                const int baseRow = row;
                const int baseCol = col;
                vector<pair<int, int>> cells;
                stack<pair<int, int>> pending;
                pending.push({row, col});
                grid[row][col] = 0;

                while (!pending.empty()) {
                    auto [currentRow, currentCol] = pending.top();
                    pending.pop();
                    cells.push_back({
                        currentRow - baseRow,
                        currentCol - baseCol
                    });

                    for (const auto& direction : directions) {
                        int nextRow = currentRow + direction[0];
                        int nextCol = currentCol + direction[1];
                        if (nextRow >= 0 && nextRow < rows
                                && nextCol >= 0 && nextCol < cols
                                && grid[nextRow][nextCol] == 1) {
                            grid[nextRow][nextCol] = 0;
                            pending.push({nextRow, nextCol});
                        }
                    }
                }

                sort(cells.begin(), cells.end());
                shapes.insert(cells);
            }
        }

        return static_cast<int>(shapes.size());
    }
};
