准确转述

给定一个按升序排列的循环单链表中的任意节点 head，以及整数 insertVal。请创建一个值为 insertVal 的节点并插入链表，使整个环仍按升序循环排列。

head 不保证指向最小值。若有多个合法插入位置，可任选其一；若链表为空， 创建一个自环节点并返回。非空时返回原来的 head 引用。

函数形式： insert(head: Node | null, insertVal: int) -> Node

约束

  • 0 <= 链表节点数 <= 5 × 10⁴
  • -10⁶ <= Node.val <= 10⁶
  • -10⁶ <= insertVal <= 10⁶
  • 输入链表已满足循环升序结构。
示例 1常规插入
输入：head = [3,4,1], insertVal = 2 输出：[3,4,1,2] 说明：从返回的 head=3 出发，2 被放在 1 与 3 之间。
示例 2空链表
输入：head = [], insertVal = 1 输出：[1] 说明：新节点的 next 指向自身，形成单节点环。
示例 3单节点
输入：head = [1], insertVal = 0 输出：[1,0] 说明：返回原 head；沿 next 可依次访问 1、0，再回到 1。

Complete Solution

一次遍历，覆盖三种落点

NORMAL

普通升序区间

cur.val ≤ x ≤ next.val 时，x 可以放在两者之间。

PIVOT

最大值到最小值

若 cur.val > next.val，此处跨越环的断点；x 足够大或足够小时都应放在这里。

FULL LOOP

绕行一整圈

若回到 head 仍未命中，链表通常全值相同；任意边都合法。

核心洞察

循环升序链表没有全局固定起点，但沿 next 前进时，除至多一个“最大值 → 最小值”的断点外， 其余边都满足非递减。于是每条边只需判定自己属于普通区间还是断点。

完整过程

  1. 空链表：创建节点，让 node.next = node，直接返回。
  2. 令 cur = head，每轮令 next = cur.next。
  3. 若 x 落在普通升序区间，选中当前边。
  4. 否则若当前边是断点，且 x 不小于当前最大值或不大于下一最小值，选中当前边。
  5. 若移动后回到 head，停止搜索并使用当前边作为兜底。
  6. 令 cur.next = new Node(x, next)，返回原 head。

正确性说明

普通区间条件成立时，插入后两条新边仍分别满足 cur.val ≤ x 与 x ≤ next.val，所以非递减关系不变。

断点条件成立时，x 若大于等于当前最大侧，或小于等于下一最小侧，新的唯一降序跨越仍只发生在环首尾， 因而循环升序性质保持。若一整圈都未匹配，则所有可见边都无法区分出严格区间，典型情形是节点值全相等； 插入到任意边都能形成合法循环序列。三种情况覆盖所有输入，因此算法正确。

边界

  • 空链表必须显式建立自环。
  • 单节点会在一轮内回到 head，兜底插入有效。
  • 重复值允许等号，避免遗漏边界相等的插入。
  • head 可以在环的任意位置，不能假设它是最小节点。

复杂度

n 为插入前链表节点数。

时间O(n)最坏绕环一次
额外空间O(1)仅新节点与指针

// Definition for a Node.
class Node {
    public int val;
    public Node next;

    public Node() {}
    public Node(int _val) { val = _val; }
    public Node(int _val, Node _next) {
        val = _val;
        next = _next;
    }

class Solution {
    public Node insert(Node head, int insertVal) {
        if (head == null) {
            Node node = new Node(insertVal);
            node.next = node;
            return node;
        }

        Node cur = head;
        while (true) {
            Node next = cur.next;

            boolean inNormalRange =
                cur.val <= insertVal && insertVal <= next.val;
            boolean atPivot = cur.val > next.val;
            boolean beyondEnds =
                insertVal >= cur.val || insertVal <= next.val;

            if (inNormalRange || (atPivot && beyondEnds)) {
                cur.next = new Node(insertVal, next);
                return head;
            }

            cur = next;
            if (cur == head) {
                cur.next = new Node(insertVal, cur.next);
                return head;
            }
        }
    }
}

替代方案

可以先遍历一圈找出最小节点或断点，再从最小节点寻找区间。它同样是 O(n)，但需要分成两段逻辑， 对“全值相等”和 head 任意指向的处理更冗长。直接逐边分类更紧凑。

也可以收集所有值、加入 insertVal 后排序，再重建环，但会破坏原节点连接，额外占用 O(n) 空间， 不符合原地插入的本意。

面试追问

  • 为什么一个合法环中至多存在一条严格下降边？
  • 如果链表允许多个局部降序断点，现有判定为何失效？
  • 如何证明全值相等时兜底插到任意位置都正确？
  • 若要求返回新插入节点而非原 head，需要改动哪里？

常见错误

  • 假设 head 一定是最小值，导致从中间节点开始时误判。
  • 只检查普通升序区间，遗漏最大值到最小值的断点。
  • 使用严格不等号，重复值场景无法及时命中。
  • 没有“回到 head”的停止条件，全部相等时死循环。
  • 空链表只创建节点，却忘记让 next 指回自己。

手算检查清单

  • x 位于两个普通相邻值之间。
  • x 比现有最大值更大，或比现有最小值更小。
  • x 与某个节点值相等。
  • 空环、单节点环、全相等环。
