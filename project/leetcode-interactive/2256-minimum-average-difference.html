最小平均差

Minimum Average Difference

把数组从某个位置分成左右两部分。两边各自取整后的平均值，在哪一个位置最接近？

前往 LeetCode 原题 ↗

01 / 题目

找到最早的最优分界

给定下标从 0 开始的整数数组 nums，长度为 n。对每个下标 i，左段包含 nums[0…i]，右段包含 nums[i+1…n−1]。先分别将两段平均值向下取整，再求它们差的绝对值，这就是该下标的平均差。

返回平均差最小的下标。若有多个位置并列，返回其中最小的下标。

空段的平均值规定为 0。因此，下标 n−1 也必须参与比较；此时右段为空。

参数与返回值

minimumAverageDifference(nums: integer[]) → integer

约束

  • 1 ≤ nums.length ≤ 10⁵
  • 0 ≤ nums[i] ≤ 10⁵

02 / 官方示例

从输入理解规则

示例 1

输入：nums = [2,5,3,9,5,3]
输出：3

各下标的平均差依次为 [3,2,2,0,1,4]。下标 3 的左段平均值为 ⌊19/4⌋ = 4，右段为 ⌊8/2⌋ = 4，平均差为 0，因此返回 3。

示例 2

输入：nums = [0]
输出：0

唯一位置为下标 0。左段平均值为 0，右段为空、平均值也为 0，因此平均差为 0，返回 0。

05 / 独立题解

准备好之后，再看解法

展开后包含推导、正确性、边界讨论与四种语言的完整实现。

总和 + 滚动前缀和

核心洞察

分界每向右移动一步，左段只多一个元素。先计算总和 total，再用 prefix 累加左段；右段和始终是 total − prefix。每个候选下标都能在常数时间计算，无须重复扫描，也无须额外的前缀和数组。

完整过程

  1. 遍历一次求 total。设左段和为 0，最小差为无穷大，答案下标为 0。
  2. 按 i = 0…n−1 遍历；先执行 prefix += nums[i]，确保当前元素归左段。
  3. 左均值为 floor(prefix / (i+1))；若右段非空，右均值为 floor((total-prefix) / (n-i-1))，否则为 0。
  4. 计算两均值的绝对差。只有差严格小于历史最小值时，才更新差与答案下标。
  5. 遍历结束返回答案下标。

示例 1 的滚动过程

总和 27。前缀和依次为 2、7、10、19、24、27；对应左右均值为 (2,5)、(3,5)、(3,5)、(4,4)、(4,3)、(4,0)。最小差记录依次为 3、2、2、0、0、0，答案下标依次为 0、1、1、3、3、3。下标 2 的差与下标 1 相同，所以保留更早的下标 1。

正确性：两个不变式

区间和不变式：处理下标 i 时，累加后的 prefix 恰好是 nums[0…i] 的和。初始为 0，每轮加入当前元素，因此归纳成立。总和减去它就是剩余右段的和，配合各段长度和空段规则，得到的平均差与定义一致。

最优记录不变式：处理完 i 后，best 是下标 0…i 中最小的平均差，answer 是达到该差的最小下标。首次候选必定更新；以后只在严格更小时更新，等值时保留较早下标。遍历覆盖全部合法位置，故结束时 answer 正是题目要求。

复杂度

时间 O(n)：求总和一次、枚举一次。额外空间 O(1)：仅保存总和、前缀和、最小差与下标。交互演示为支持回退保存了历史，不属于提交算法的空间复杂度。

边界与数值范围

单元素仍需参与比较；右段为空设为 0；全零或重复值要保留最早解。总和最大为 10¹⁰，Java 用 long，C++ 用 long long；Python 整数自动扩展，JavaScript Number 在此整数范围内精确。

替代方案

  • 暴力枚举：每个下标重新求两侧和，时间 O(n²)、额外空间 O(1)，无法适应 10⁵ 的长度。
  • 前缀和数组：保存每个前缀的和，时间 O(n)、空间 O(n)，便于额外区间查询；本题只按顺序扫描，滚动一个和就足够。

常见错误

  • 先求两个精确平均值之差再取整：题目要求分别向下取整，运算顺序不可交换。
  • 右段长度是 n−i−1，不是 n−i；且不能除以 0。
  • 用 <= 更新记录会覆盖更早的并列答案。
  • 在加入当前元素前计算，会把 nums[i] 错分到右段。
  • Java/C++ 用 32 位整型求总和会溢出；JavaScript 的位运算取整会强制转换为 32 位整数，应使用 Math.floor。
  • 返回最小差值而非下标；或者遗漏最后一个位置。

面试追问

  • 遇到平均差 0 可以提前返回吗？可以。差非负，且下标递增，第一次遇到 0 就是最早的全局最优；下面代码保留完整扫描，便于统一过程。
  • 若允许负数？仍可用相同区间和思路，但 Java/C++ 整数除法向零截断，需要显式向下取整；当前非负约束下两者相同。
  • 数组是无法重读的数据流？当前算法需要先获知总和；若总和未知且不能重读，就不能直接按此方式以 O(1) 存储完成，需要缓存数据或额外提供总和。

Java

class Solution {
    public int minimumAverageDifference(int[] nums) {
        long total = 0;
        for (int num : nums) total += num;
        long prefix = 0, best = Long.MAX_VALUE;
        int answer = 0, n = nums.length;
        for (int i = 0; i < n; i++) {
            prefix += nums[i];
            long left = prefix / (i + 1);
            long right = i == n - 1 ? 0
                : (total - prefix) / (n - i - 1);
            long diff = Math.abs(left - right);
            if (diff < best) {
                best = diff;
                answer = i;
            }
        }
        return answer;
    }
}

/**
 * @param {number[]} nums
 * @return {number}

var minimumAverageDifference = function(nums) {
    const n = nums.length;
    let total = 0;
    for (const num of nums) total += num;
    let prefix = 0, best = Infinity, answer = 0;
    for (let i = 0; i < n; i++) {
        prefix += nums[i];
        const left = Math.floor(prefix / (i + 1));
        const right = i === n - 1 ? 0
            : Math.floor((total - prefix) / (n - i - 1));
        const diff = Math.abs(left - right);
        if (diff < best) {
            best = diff;
            answer = i;
        }
    }
    return answer;
};

        prefix = 0
        best = float("inf")
        answer = 0
        n = len(nums)
        for i, num in enumerate(nums):
            prefix += num
