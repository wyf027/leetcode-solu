重构一棵树的方案数

只知道“哪些节点存在祖先关系”，能否倒推出整棵树？这道题的难点不在造树，而在从每个节点的邻接集合里辨认父子层级。

英文名：Number Of Ways To Reconstruct A Tree 函数：checkWays(pairs) 返回：0 / 1 / 2 非付费题
Problem

题意转述

给定互不重复的数对 pairs[i] = [xᵢ, yᵢ]，且 xᵢ < yᵢ。树中的节点恰好是这些数对出现过的值。对于任意两个节点，它们的数对出现在 pairs 中，当且仅当其中一个是另一个的祖先。

需要判断符合条件的有根树有多少种。若没有，返回 0；若唯一，返回 1；若多于一种，只返回 2。树不要求是二叉树；只要至少一个节点的父节点不同，就算不同方案。

关键语义：数对表示的是“祖先—后代可比较”，不是一条直接父子边。输入因此更像一张祖先关系的无向投影图。

参数与约束

checkWays(pairs: integer[][]): integer

  • 1 ≤ pairs.length ≤ 10⁵
  • 1 ≤ xᵢ < yᵢ ≤ 500
  • 所有数对互不相同
  • 祖先不包含节点自身
  • 根节点没有祖先

Solution

用度数顺序恢复父子包含关系

把每个数对当成无向边。若 p 是 x 的父节点，那么与 x 可比较的节点，除了 p 自己，都必须也与 p 可比较。

核心洞察

根必须连接所有点。
根是所有其他节点的祖先，因此度数必须是 n - 1；不存在这种点就直接返回 0。
父节点的度数不会更小。
对非根节点 x，在其邻居中选择度数不小于 deg(x) 且最小的节点作为父候选。
邻接集合必须向上包含。
验证 N(x) \ {parent} ⊆ N(parent)。任何缺失都说明祖先关系彼此矛盾。
相同度数意味着不唯一。
若 deg(parent) = deg(x)，两者在层级上可交换而不改变输入关系，因此答案至少为 2。

完整过程

  1. 从 pairs 收集全部节点，并为每个节点建立邻接集合。
  2. 找到度数等于 n - 1 的根候选；找不到则返回 0。
  3. 遍历每个非根节点 x，从 N(x) 中选出度数不小于 deg(x) 的最小度数节点 p。
  4. 若不存在 p，或 N(x) 除 p 外有元素不在 N(p) 中，返回 0。
  5. 若出现 deg(x) = deg(p)，把结果标记为 2；否则保持 1。
  6. 全部验证通过后返回标记值。
实现细节：若有多个全连接节点，任选一个当根即可；其他全连接节点会在遍历时与根度数相同，从而把答案标记为 2。

正确性说明

必要性。根必须与所有节点可比较。若 p 是 x 的父节点，所有与 x 可比较的祖先或后代（除 p）也必须与 p 可比较，所以集合包含与度数条件必然成立。
局部选择有效。满足度数不小于 x 的最近祖先拥有最小度数；选择最小度数父候选，避免跨过更近的一层。包含检查保证它能承接 x 的全部可比关系。
充分性。根存在且每个非根节点都能接到一个通过包含检查的父候选时，度数方向给出不向下回绕的层级；沿父指针最终到达根，且生成树的祖先可比关系恰好与输入一致。
方案数。严格度数增长时，父层级被唯一确定；若相邻层出现相同度数，其邻接关系等价，可交换父子位置，产生多解。故标记 1 或 2 正确。

复杂度与边界

时间：O(n² + m)。建图为 O(m)，逐节点扫描邻居并验证集合；由于节点值最多 500，总体可按 O(n²) 估算。

空间：O(n²) 最坏用于邻接集合，实际为 O(n + m)。

  • 只有一条数对时，两点都可作根，答案是 2。
  • 根候选可以不唯一；这本身就是多解信号。
  • 节点编号不连续，不能用 pairs.length 推导节点数量。
  • 输入边是祖先关系闭包，不能直接判成树边。

四语言完整实现

JavaHashMap + HashSet
class Solution {
    public int checkWays(int[][] pairs) {
        Map<Integer, Set<Integer>> graph = new HashMap<>();
        for (int[] pair : pairs) {
            graph.computeIfAbsent(pair[0], k -> new HashSet<>())
                 .add(pair[1]);
            graph.computeIfAbsent(pair[1], k -> new HashSet<>())
                 .add(pair[0]);
        }

        int n = graph.size();
        int root = -1;
        for (int node : graph.keySet()) {
            if (graph.get(node).size() == n - 1) {
                root = node;
                break;
            }
        }
        if (root == -1) return 0;

        int answer = 1;
        for (int node : graph.keySet()) {
            if (node == root) continue;

            int degree = graph.get(node).size();
            int parent = -1;
            int parentDegree = Integer.MAX_VALUE;

            for (int neighbor : graph.get(node)) {
                int neighborDegree = graph.get(neighbor).size();
                if (neighborDegree >= degree
                        && neighborDegree < parentDegree) {
                    parent = neighbor;
                    parentDegree = neighborDegree;
                }
            }
            if (parent == -1) return 0;

            for (int neighbor : graph.get(node)) {
                if (neighbor != parent
                        && !graph.get(parent).contains(neighbor)) {
                    return 0;
                }
            }
            if (parentDegree == degree) answer = 2;
        }
        return answer;
    }
}

/**
 * @param {number[][]} pairs
 * @return {number}

var checkWays = function (pairs) {
    const graph = new Map();

    const addEdge = (from, to) => {
        if (!graph.has(from)) graph.set(from, new Set());
        graph.get(from).add(to);
    };

    for (const [x, y] of pairs) {
        addEdge(x, y);
        addEdge(y, x);
    }

    const n = graph.size;
    let root = -1;
    for (const [node, neighbors] of graph) {
        if (neighbors.size === n - 1) {
            root = node;
            break;
        }
    }
    if (root === -1) return 0;

    let answer = 1;
    for (const [node, neighbors] of graph) {
        if (node === root) continue;

        const degree = neighbors.size;
        let parent = -1;
        let parentDegree = Infinity;

        for (const neighbor of neighbors) {
            const neighborDegree = graph.get(neighbor).size;
            if (neighborDegree >= degree &&
                neighborDegree < parentDegree) {
                parent = neighbor;
                parentDegree = neighborDegree;
            }
        }
        if (parent === -1) return 0;

        for (const neighbor of neighbors) {
            if (neighbor !== parent &&
                !graph.get(parent).has(neighbor)) {
                return 0;
            }
        }
        if (parentDegree === degree) answer = 2;
    }
    return answer;
};
Python 3defaultdict + set
from collections import defaultdict
from typing import List


class Solution:
    def checkWays(self, pairs: List[List[int]]) -> int:
        graph = defaultdict(set)
        for x, y in pairs:
            graph[x].add(y)
            graph[y].add(x)

        n = len(graph)
        root = next(
            (node for node in graph
             if len(graph[node]) == n - 1),
            None,
        )
        if root is None:
            return 0

        answer = 1
        for node, neighbors in graph.items():
            if node == root:
                continue

            degree = len(neighbors)
            parent = None
            parent_degree = float("inf")

            for neighbor in neighbors:
                neighbor_degree = len(graph[neighbor])
                if degree <= neighbor_degree < parent_degree:
                    parent = neighbor
                    parent_degree = neighbor_degree

            if parent is None:
                return 0

            for neighbor in neighbors:
                if neighbor != parent and \
                        neighbor not in graph[parent]:
                    return 0

            if parent_degree == degree:
                answer = 2

        return answer
C++unordered_map + unordered_set
class Solution {
public:
    int checkWays(vector<vector<int>>& pairs) {
        unordered_map<int, unordered_set<int>> graph;
        for (const auto& pair : pairs) {
            graph[pair[0]].insert(pair[1]);
            graph[pair[1]].insert(pair[0]);
        }

        const int n = graph.size();
        int root = -1;
        for (const auto& [node, neighbors] : graph) {
            if (static_cast<int>(neighbors.size()) == n - 1) {
                root = node;
                break;
            }
        }
        if (root == -1) return 0;

        int answer = 1;
        for (const auto& [node, neighbors] : graph) {
            if (node == root) continue;

            const int degree = neighbors.size();
            int parent = -1;
            int parentDegree = INT_MAX;

            for (int neighbor : neighbors) {
                int neighborDegree = graph[neighbor].size();
                if (neighborDegree >= degree &&
                    neighborDegree < parentDegree) {
                    parent = neighbor;
                    parentDegree = neighborDegree;
                }
            }
            if (parent == -1) return 0;

            for (int neighbor : neighbors) {
                if (neighbor != parent &&
                    !graph[parent].count(neighbor)) {
                    return 0;
                }
            }
            if (parentDegree == degree) answer = 2;
        }
        return answer;
    }
};

替代方案

可以按度数降序递归划分节点集合：每层取与当前集合其他节点都相连的节点作为根，再根据关系拆分子树。这个视角更贴近“真正重建”，但分组与去重更复杂，代码也更长。

也可以使用 501 × 501 布尔邻接矩阵，把包含检查写成定长扫描。节点值上限只有 500，常数稳定，但空间始终占满；哈希集合更直接表达关系。

面试追问

  • 为什么父候选要取“度数不小于当前节点中的最小值”？
  • 若返回精确方案数，而不是把多解压成 2，应如何计数？
  • 节点值范围扩大到 10⁹ 时，矩阵与哈希集合如何选择？
  • 如果输入允许缺失部分祖先数对，这套判定哪里会失效？

常见错误

  • 把 pairs 当作直接边，然后用“边数等于节点数减一”判断。
  • 只找根，不验证每个节点的邻接集合包含关系。
  • 父候选取最大度数，导致跳过真正的最近祖先。
  • 要求根唯一，从而把多根候选误判为无解。
  • 发现等度数后立刻返回 2，漏掉后续可能出现的矛盾。
  • 验证集合时忘记排除父节点自身。
