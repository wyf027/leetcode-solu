01 · Problem brief

题意，不提前揭晓解法

对任意非空字符串 s，定义 f(s) 为：字典序最小字母在字符串中出现的次数。

给定查询数组 queries 与词表 words。对每个 queries[i]，统计词表中满足 f(queries[i]) < f(W) 的字符串 W 数量。

返回整数数组 answer，其中 answer[i] 对应第 i 次查询。

f("dcce") = 2

最小字母是 c，它出现两次。注意：不是统计第一个字符，也不是统计全局最常见字符。

官方示例 1单次查询
输入：queries = ["cbd"], words = ["zaaaz"]
输出：[1]

f("cbd") = 1，f("zaaaz") = 3，严格小于关系成立，所以答案为 1。

官方示例 2多次查询
输入：queries = ["bbb","cc"],
      words = ["a","aa","aaa","aaaa"]
输出：[1,2]

f("bbb") = 3，只有频次 4 更大；f("cc") = 2，频次 3、4 都更大。

约束
  • 1 <= queries.length <= 2000
  • 1 <= words.length <= 2000
  • 1 <= queries[i].length, words[i].length <= 10
  • 所有字符串均只含小写英文字母。

排序后，找第一个更大的频次

核心洞察

字符串的具体内容不再重要。 对每个字符串求出 f(s) 后，问题变成：对每个查询值 x，在词表频次数组中统计多少个数严格大于 x。

先把所有 words 的频次排序。对查询频次 x 使用“上界”二分，找到第一个 > x 的位置 left；答案就是 words.length - left。

完整过程

计算单串频次
线性扫描字符；维护当前最小字母及其次数。遇到更小字母时更新最小字母并把计数重置为 1，遇到相同字母时计数加 1。
预处理词表
对每个 word 计算 f(word)，得到整数数组并按升序排序。
处理查询
求出 x = f(query)，在已排序数组中二分查找第一个严格大于 x 的元素。
换算答案
边界位置右侧（包含边界）都满足条件，因此用总数减去边界下标。

正确性证明

引理 1：单串扫描得到正确的 f(s)

扫描到任意位置时，维护量 minChar 是前缀中的最小字母，count 是该字母在前缀中的出现次数。新字符更小时，原最小字母不再可能成为整体最小值，因此重置；相等时增加计数；更大时不影响。由循环不变式，扫描结束后计数即为 f(s)。

引理 2：上界位置正确划分词表频次

二分始终保持：答案位置位于半开区间 [left, right)。若中点值 <= x，它以及左侧元素都不可能严格大于 x，故令 left = mid + 1；否则中点可能是首个合法位置，令 right = mid。终止时 left == right，正是首个 > x 的下标。

定理

根据引理 1，每个频次计算正确；根据引理 2，排序数组中从 left 到末尾且仅有这些元素严格大于查询频次，共 n - left 个。因此算法对每个查询都返回正确答案。

边界情况

  • 字符串只有一个字符：最小字母频次为 1。
  • 字符串全部相同：频次等于字符串长度。
  • 查询频次不小于所有词表频次：边界为数组末尾，答案为 0。
  • 查询频次小于所有词表频次：边界为 0，答案为词表长度。
  • 有多个词表频次等于查询频次：它们不能计入，因为条件是严格大于。

复杂度

时间O(C + W log W + Q log W)C 是所有字符串的字符总数；W 为词表数，Q 为查询数。
空间O(W)保存词表频次数组；不计返回值。

替代方案

计数桶 / 后缀和：题目保证字符串长度最多为 10，所以 f(s) 只可能是 1 到 10。统计每个词表频次的数量，再构造“频次严格大于 k 的词数”后缀表。这样每次查询可 O(1) 回答，总时间为 O(C + W + Q + 10)。它利用了本题的小范围约束，但二分方案更通用。

逐查询遍历：对每个查询与所有词比较，容易实现，但要做 Q × W 次比较，规模上限时没有必要。

class Solution {
    public int[] numSmallerByFrequency(String[] queries, String[] words) {
        int[] frequencies = new int[words.length];
        for (int i = 0; i < words.length; i++) {
            frequencies[i] = frequency(words[i]);
        }
        java.util.Arrays.sort(frequencies);

        int[] answer = new int[queries.length];
        for (int i = 0; i < queries.length; i++) {
            int value = frequency(queries[i]);
            int left = 0, right = frequencies.length;
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (frequencies[mid] <= value) left = mid + 1;
                else right = mid;
            }
            answer[i] = frequencies.length - left;
        }
        return answer;
    }

    private int frequency(String s) {
        char smallest = '{';
        int count = 0;
        for (char ch : s.toCharArray()) {
            if (ch < smallest) {
                smallest = ch;
                count = 1;
            } else if (ch == smallest) {
                count++;
            }
        }
        return count;
    }
}

var numSmallerByFrequency = function(queries, words) {
    const frequency = (s) => {
        let smallest = '{';
        let count = 0;
        for (const ch of s) {
            if (ch < smallest) {
                smallest = ch;
                count = 1;
            } else if (ch === smallest) {
                count++;
            }
        }
        return count;
    };

    const values = words.map(frequency).sort((a, b) => a - b);
    return queries.map((query) => {
        const value = frequency(query);
        let left = 0;
        let right = values.length;
        while (left < right) {
            const mid = left + Math.floor((right - left) / 2);
            if (values[mid] <= value) left = mid + 1;
            else right = mid;
        }
        return values.length - left;
    });
};

class Solution {
public:
    vector<int> numSmallerByFrequency(
        vector<string>& queries, vector<string>& words
    ) {
        vector<int> values;
        values.reserve(words.size());
        for (const string& word : words) {
            values.push_back(frequency(word));
        }
        sort(values.begin(), values.end());

        vector<int> answer;
        answer.reserve(queries.size());
        for (const string& query : queries) {
            int value = frequency(query);
            auto firstGreater = upper_bound(
                values.begin(), values.end(), value
            );
            answer.push_back(values.end() - firstGreater);
        }
        return answer;
    }

private:

                smallest = ch;
                count = 1;
            } else if (ch == smallest) {
                count++;
            }
        }
        return count;
    }

面试追问

为什么查的是 upper bound，而不是 lower bound？

lower_bound(x) 找第一个 >= x，会把等于查询频次的词错误计入；本题条件是严格大于，所以要找第一个 > x。

如果字符串长度上限从 10 变成很大，选哪种方案？

排序 + 二分仍然适用，且不依赖频次值域；固定大小的计数桶不再合适，除非动态建立足够大的统计结构。

能否不排序？

可以为每个查询遍历所有词表频次，但复杂度为 O(QW)；或者利用当前长度上限建立 1..10 的频次桶与后缀和。

如何用库函数替换手写二分？

C++ 使用 upper_bound，Python 使用 bisect_right。Java 与 JavaScript 可手写上界函数，避免普通二分返回任意相等位置。

常见错误

把“最小字母”当成首字母
字符串不保证有序，必须扫描完整字符串。
找到大于等于
相等频次不满足条件，二分分支必须使用 <= 排除相等值。
计数未在遇到更小字母时重置
新最小字母第一次出现时，计数应重新设为 1。
每个查询都重新排序或扫描词表
词表固定，应只预处理一次。
