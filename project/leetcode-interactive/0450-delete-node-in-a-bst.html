450. 删除二叉搜索树中的节点

Delete Node in a BST · 在保持二叉搜索树有序性的前提下，删除指定键并返回可能变化的根节点。

MEDIUM 非付费题 树 二叉搜索树 目标复杂度 O(h)
Problem

题目要求

给定二叉搜索树的根节点 root 与整数 key，删除值等于 key 的节点，并保证结果仍然满足二叉搜索树性质。返回删除后树的根节点引用；根节点可能因此发生变化。

删除过程可拆成两件事：先利用 BST 的有序性定位目标；若目标存在，再按它拥有 0、1 或 2 个子节点的情况完成结构调整。
Examples

官方示例

删除内部节点01
输入root = [5,3,6,2,4,null,7], key = 3
输出[5,4,6,2,null,null,7]

值 3 有两个孩子。用右子树中的后继 4 接替它是一种合法结果；使用前驱 2 得到的另一棵合法 BST 也会被接受。

目标不存在02
输入root = [5,3,6,2,4,null,7], key = 0
输出[5,3,6,2,4,null,7]

搜索路径到达空节点，原树保持不变。

空树03
输入root = [], key = 0
输出[]

空树没有可删除节点，直接返回空引用。

Constraints

约束与进阶

  • 树中节点数为 [0, 10⁴]
  • -10⁵ ≤ Node.val ≤ 10⁵
  • 每个节点的值互不相同
  • root 是合法二叉搜索树
  • -10⁵ ≤ key ≤ 10⁵
  • 进阶：时间复杂度达到 O(h)

先自己想一想：拥有两个孩子的节点，为什么不能直接移除？

Solution

递归删除：让子树自己返回新根

核心洞察

递归函数的返回值不是“是否删除成功”，而是删除后这棵子树的新根。当 key 更小或更大时，把递归结果重新接回左/右指针；命中目标时，直接构造该局部子树的新根。

三种命中情况

  1. 没有左孩子：返回右孩子。
  2. 没有右孩子：返回左孩子。
  3. 两个孩子都存在：找到右子树最小节点（中序后继），复制其值，再从右子树删除这个后继值。

完整过程

  1. 空节点直接返回空。
  2. key < root.val：递归更新 root.left。
  3. key > root.val：递归更新 root.right。
  4. 值相等时按 0/1/2 个孩子处理，最后返回当前子树的新根。

为什么选择中序后继

右子树最小值大于左子树所有值，同时又不大于右子树中的其他值。把它放到目标位置后，左右两侧的大小关系不变；而这个最小节点没有左孩子，第二次删除会退化为更简单的 0/1 孩子情况。

正确性证明

  1. 搜索分支正确：BST 中左子树值更小、右子树值更大。比较后只递归进入可能包含 key 的一侧，不会漏掉目标；另一侧保持不变。
  2. 0/1 孩子情况正确：用唯一孩子（或空）替代目标，只是把原本已经合法的子树整体上移，不会改变其中的相对次序，也仍满足父节点一侧的取值范围。
  3. 2 孩子情况正确：中序后继是右子树最小值，因此它大于所有左子树节点且不大于其余右子树节点。复制后再递归删除后继的原位置，既避免重复值，又保持 BST 性质。
  4. 归纳结论：假设递归调用能返回删除后仍合法的子树新根，则重新接回该子树后当前树仍合法。结合空树基例，算法对任意树高都正确。

边界情况

  • 空树或目标不存在：结构不变。
  • 删除叶子：父指针接到空。
  • 删除只有一个孩子的节点：孩子直接上移。
  • 删除根节点：返回值就是新的整棵树根。
  • 后继恰好是右孩子：仍可由同一递归逻辑处理。

复杂度

时间 O(h)搜索目标与定位/删除后继都沿树高方向进行，总路径长度仍为 O(h)。
空间 O(h)递归调用栈深度等于树高；平衡树为 O(log n)，退化树为 O(n)。

替代方案

可以对称地选择左子树最大节点（中序前驱）；也可使用迭代搜索并记录父节点，把额外空间降到 O(1)。若树会频繁退化，可换用 AVL 树、红黑树或随机化 Treap 保持高度。

常见错误

  • 递归后忘记写回 root.left 或 root.right。
  • 复制后继值后，没有删除后继原节点，产生重复值。
  • 删除根节点却仍返回旧根引用。
  • 误写成遍历整棵树，丢掉 BST 的有序性优势。

面试追问

  • 为什么时间不是 O(n)？因为搜索、找后继和删除后继都只沿有限的根到叶路径，总计受树高 h 限制。
  • 如何做到 O(1) 额外空间？改写为迭代，记录目标父节点与后继父节点，再直接重连指针。
  • 如何处理重复值？题目保证唯一；若允许重复，需要先规定等值节点固定放左/右，或在节点中维护计数。
  • 为什么后继没有左孩子？它已是右子树最小节点；若仍有左孩子，就还能继续向左找到更小值，产生矛盾。

四语言完整实现

Java · LeetCode 可提交 
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode deleteNode(TreeNode root, int key) {
        if (root == null) {
            return null;
        }

        if (key < root.val) {
            root.left = deleteNode(root.left, key);
        } else if (key > root.val) {
            root.right = deleteNode(root.right, key);
        } else {
            if (root.left == null) {
                return root.right;
            }
            if (root.right == null) {
                return root.left;
            }

            TreeNode successor = root.right;
            while (successor.left != null) {
                successor = successor.left;
            }
            root.val = successor.val;
            root.right = deleteNode(root.right, successor.val);
        }
        return root;
    }
}

 * @param {TreeNode} root

 * @return {TreeNode}

    if (root === null) {
        return null;
    }

    if (key < root.val) {
        root.left = deleteNode(root.left, key);
    } else if (key > root.val) {
        root.right = deleteNode(root.right, key);

        if (root.left === null) {
            return root.right;
        }
        if (root.right === null) {
            return root.left;

        root.val = successor.val;
        root.right = deleteNode(root.right, successor.val);
    }
    return root;
};

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* deleteNode(TreeNode* root, int key) {
        if (root == nullptr) {
            return nullptr;
        }

        if (key < root->val) {
            root->left = deleteNode(root->left, key);
        } else if (key > root->val) {
            root->right = deleteNode(root->right, key);
        } else {
            if (root->left == nullptr) {
                return root->right;
            }
            if (root->right == nullptr) {
                return root->left;
            }

            TreeNode* successor = root->right;
            while (successor->left != nullptr) {
                successor = successor->left;
            }
            root->val = successor->val;
            root->right = deleteNode(root->right, successor->val);
        }
        return root;
    }
};
