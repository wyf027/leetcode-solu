删除子字符串的
最大得分

在字符不断消失、重新相邻的过程中，怎样安排删除顺序才能把得分推到最高？先别急着看答案，跟着演示亲手走几步。

1717MEDIUM栈贪心字符串

函数签名

maximumGain(s, x, y)

输入一个小写字符串与两种删除操作的分值，返回可获得的最大总分。

01 · Problem

题目说明

Maximum Score From Removing Substrings

给定字符串 s 和整数 x、y。你可以执行任意多次以下操作：

  • 删除一个连续子字符串 "ab"，获得 x 分；
  • 删除一个连续子字符串 "ba"，获得 y 分。

每次删除后，剩余字符会重新拼接，可能形成新的可删除对子。请返回经过若干次操作后能够取得的最大总分。

02 · Examples

官方示例

示例 1

输入：s = "cdbcbbaaabab", x = 4, y = 5
输出：19

一种最优操作可获得 5 + 4 + 5 + 5 = 19 分。下方演示会用另一种同样最优的删除次序展示过程。

示例 2

输入：s = "aabbaaxybbaabb", x = 5, y = 4
输出：20

非 a/b 字符会把字符串自然分成互不影响的片段。

约束

  • 1 ≤ s.length ≤ 10⁵
  • 1 ≤ x, y ≤ 10⁴
  • s 仅包含小写英文字母。

操作规则

只能删除当前相邻的两个字符。删除后两侧字符会靠拢，因此一次操作可能为下一次操作创造新的相邻对子。

04 · Solution

准备好揭晓最优策略了吗？

下面的内容包含核心贪心结论、证明、复杂度和完整代码。它默认收起，不会在首屏直接泄露思路。

Deep Dive

贪心 + 栈：先拿更贵的对子

核心洞察

若 x ≥ y，就先尽可能删除 "ab"；否则先尽可能删除 "ba"。完成第一轮后，再从剩余字符串删除另一种对子。每轮都可用栈在线完成。

冲突只会发生在长度为 3 的局部结构中："aba" 同时包含 "ab" 与 "ba"，"bab" 亦然。无论先删哪一边，最终都只能删一次，所以应把这次机会留给分值更高的操作。

完整过程

1
决定优先级
比较 x 与 y，把高分模式记为 first，低分模式记为 second。
2
第一轮消除
从左到右扫描；若栈顶与当前字符组成 first，弹栈并加分，否则入栈。
3
保留剩余串
第一轮的栈即为删除所有高分模式后的剩余字符，顺序保持不变。
4
第二轮消除
对剩余串用同样方法删除 second，累加低分操作的收益。

正确性说明

引理 1：高分模式可以优先删除。
两种模式若互不重叠，交换操作顺序不会影响结果。若重叠，只可能形成 aba 或 bab；两种选择都会留下一个相同字符，且最多完成一次删除。选择高分模式不劣于选择低分模式。
引理 2：一轮栈扫描会删除指定模式的最大数量。
遇到可配对的栈顶与当前字符时立即删除，不会损失其他同模式配对；否则当前字符必须保留，等待后续字符。扫描结束后不存在该模式，得到最大可删除次数。
定理：算法得到最大总分。
由引理 1，存在一个最优解会先完成所有高分模式删除；由引理 2，第一轮恰好实现这一目标。对剩余串再最大化低分模式数量，因此两轮总收益就是全局最优值。

复杂度

时间：O(n)，两次线性扫描。

空间：O(n)，栈保存尚未消除的字符。

边界情况

  • x = y：任意一种先删都正确。
  • 没有 a 或 b：答案为 0。
  • 其他字符充当天然分隔符。
  • 全部由 a/b 构成时仍只需两轮。

四语言完整代码

class Solution {
    public int maximumGain(String s, int x, int y) {
        char firstA = 'a', firstB = 'b';
        int firstScore = x, secondScore = y;

        if (y > x) {
            firstA = 'b';
            firstB = 'a';
            firstScore = y;
            secondScore = x;
        }

        PassResult first = remove(s, firstA, firstB, firstScore);
        PassResult second = remove(first.remaining, firstB, firstA, secondScore);
        return first.score + second.score;
    }

    private PassResult remove(String s, char left, char right, int value) {
        StringBuilder stack = new StringBuilder();
        int score = 0;
        for (char c : s.toCharArray()) {
            int size = stack.length();
            if (c == right && size > 0 && stack.charAt(size - 1) == left) {
                stack.deleteCharAt(size - 1);
                score += value;
            } else {
                stack.append(c);
            }
        }
        return new PassResult(stack.toString(), score);
    }

    private static class PassResult {
        String remaining;
        int score;
        PassResult(String remaining, int score) {
            this.remaining = remaining;
            this.score = score;
        }
    }
}
/**
 * @param {string} s
 * @param {number} x
 * @param {number} y
 * @return {number}
 */
var maximumGain = function(s, x, y) {
    let first = "ab", second = "ba";
    let firstScore = x, secondScore = y;

    if (y > x) {
        [first, second] = [second, first];
        [firstScore, secondScore] = [secondScore, firstScore];
    }

    const remove = (text, pattern, value) => {
        const stack = [];
        let score = 0;
        for (const char of text) {
            if (char === pattern[1] && stack.at(-1) === pattern[0]) {
                stack.pop();
                score += value;
            } else {
                stack.push(char);
            }
        }
        return [stack.join(""), score];
    };

    const [remaining, highScore] = remove(s, first, firstScore);
    const [, lowScore] = remove(remaining, second, secondScore);
    return highScore + lowScore;
};
class Solution:
    def maximumGain(self, s: str, x: int, y: int) -> int:
        first, second = "ab", "ba"
        first_score, second_score = x, y

        if y > x:
            first, second = second, first
            first_score, second_score = second_score, first_score

        def remove(text: str, pattern: str, value: int) -> tuple[str, int]:
            stack = []
            score = 0
            for char in text:
                if char == pattern[1] and stack and stack[-1] == pattern[0]:
                    stack.pop()
                    score += value
                else:
                    stack.append(char)
            return "".join(stack), score

        remaining, high_score = remove(s, first, first_score)
        _, low_score = remove(remaining, second, second_score)
        return high_score + low_score
class Solution {
    pair<string, int> removePattern(
        const string& s, char left, char right, int value
    ) {
        string stack;
        int score = 0;
        for (char c : s) {
            if (c == right && !stack.empty() && stack.back() == left) {
                stack.pop_back();
                score += value;
            } else {
                stack.push_back(c);
            }
        }
        return {stack, score};
    }

public:
    int maximumGain(string s, int x, int y) {
        char firstLeft = 'a', firstRight = 'b';
        int firstScore = x, secondScore = y;
        if (y > x) {
            firstLeft = 'b';
            firstRight = 'a';
            firstScore = y;
            secondScore = x;
        }

        auto [remaining, highScore] =
            removePattern(s, firstLeft, firstRight, firstScore);
        auto [unused, lowScore] =
            removePattern(remaining, firstRight, firstLeft, secondScore);
        return highScore + lowScore;
    }
};

替代方案

可以反复在字符串中查找并删除目标子串，但中间删除通常会触发大量字符移动，最坏可能退化到 O(n²)。也可以按非 a/b 字符分段后统计，但仍要处理段内相邻顺序；两轮栈更直接，也更容易证明。

面试追问

  • 为什么局部交换足以证明“高分优先”？
  • 能否复用一个字符数组，把额外分配降到更低？
  • 若可删除模式扩展到三种，当前贪心还成立吗？
  • 如果每种操作的收益会随次数变化，应怎样建模？

常见错误

  • 固定先删 ab，忘记比较 x 与 y。
  • 第一轮后仍对原字符串做第二轮。
  • 只统计原始相邻对子，忽略删除后产生的新相邻关系。
  • 用全局替换导致重叠处理不正确或复杂度过高。
