二叉树的垂直遍历

Binary Tree Vertical Order Traversal

给二叉树中的每个节点标记“列”，再从最左列到最右列收集节点。真正需要守住的细节，是同列节点的先后次序。

树广度优先搜索哈希表二叉树排序

Problem

题意转述

给定一棵二叉树的根节点 root。把根节点放在第 0 列；任一节点位于第 col 列时，它的左孩子位于 col - 1，右孩子位于 col + 1。

按列从左到右返回节点值。每一列内部按从上到下的顺序排列；若两个节点处在同一行、同一列，则保留它们在树中从左到右的顺序。

函数签名： verticalOrder(root: TreeNode) → List<List<Integer>>

横向规则

左孩子 −1，右孩子 +1

列内规则

从上到下，同层从左到右

空树

返回空列表 []

示例

示例 1

输入：verticalOrder(root = [3,9,20,null,null,15,7]) 输出：[[9],[3,15],[20],[7]]

节点 3 与 15 同在第 0 列，按深度依次出现。

示例 2

输入：verticalOrder(root = [3,9,8,4,0,1,7]) 输出：[[4],[9],[3,0,1],[8],[7]]

0 与 1 同行同列，保留从左到右的顺序。

示例 3

输入：verticalOrder(root = [1,2,3,4,10,9,11,null,5,null,null,null,null,null,null,null,6]) 输出：[[4],[2,5],[1,10,9,6],[3],[11]]

同列中的值按照 BFS 发现顺序进入结果。

空树

输入：verticalOrder(root = []) 输出：[]

根节点为空时无需建立列。

约束

  • 树中节点数在 [0, 100] 范围内。
  • -100 ≤ Node.val ≤ 100。
  • 输入 root 是二叉树根节点或 null。

Canonical approach

BFS + 列坐标哈希表

核心洞察

队列不只保存节点，还保存它所在的列。BFS 按层推进，同一层又按从左到右出队，因此把节点值直接追加到对应列，就自然得到题目要求的列内顺序，不需要再按行排序。

状态设计

  • 队列元素：(node, col)
  • 哈希表：col → 当前列的节点值列表
  • minCol / maxCol：避免最后对列键排序

完整过程

  1. 若 root 为空，返回空列表。
  2. 令根节点列号为 0，把 (root, 0) 入队。
  3. 每次取出队首，将节点值追加到 columns[col]。
  4. 左孩子携带 col - 1 入队，右孩子携带 col + 1 入队，同时维护最小、最大列号。
  5. 队列清空后，从 minCol 到 maxCol 依次取出每列列表。

正确性证明

列归属正确：根节点列号为 0。若某节点列号正确，则按定义，其左、右孩子分别分配 col - 1 与 col + 1，所以由归纳法，每个节点都进入正确的列。

列内顺序正确：BFS 保证较浅节点先出队；在相同深度，队列按父节点从左到右处理，并按左孩子、右孩子顺序入队，因此同行节点也从左到右出队。追加顺序恰好就是题目要求的顺序。

列间顺序正确：最终严格按照 minCol ... maxCol 读取哈希表，因此结果从最左列到最右列。综上，算法返回正确的垂直遍历。

复杂度

  • 时间：O(n)，每个节点恰好入队、出队一次。
  • 空间：O(n)，结果、哈希表与队列总计线性空间。

边界情况

  • 空树直接返回 []。
  • 单节点返回 [[root.val]]。
  • 完全偏斜树会产生连续的负列或正列。
  • 节点值可重复，不能用值标识节点。

四语言完整实现

import java.util.*;

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private static class State {
        TreeNode node;
        int col;

        State(TreeNode node, int col) {
            this.node = node;
            this.col = col;
        }
    }

    public List<List<Integer>> verticalOrder(TreeNode root) {
        List<List<Integer>> answer = new ArrayList<>();
        if (root == null) return answer;

        Map<Integer, List<Integer>> columns = new HashMap<>();
        Queue<State> queue = new ArrayDeque<>();
        queue.offer(new State(root, 0));
        int minCol = 0;
        int maxCol = 0;

        while (!queue.isEmpty()) {
            State state = queue.poll();
            TreeNode node = state.node;
            int col = state.col;

            columns.computeIfAbsent(col, key -> new ArrayList<>())
                   .add(node.val);

            if (node.left != null) {
                queue.offer(new State(node.left, col - 1));
                minCol = Math.min(minCol, col - 1);
            }
            if (node.right != null) {
                queue.offer(new State(node.right, col + 1));
                maxCol = Math.max(maxCol, col + 1);
            }
        }

        for (int col = minCol; col <= maxCol; col++) {
            answer.add(columns.get(col));
        }
        return answer;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 *
 * @param {TreeNode} root
 * @return {number[][]}
 */
var verticalOrder = function(root) {
    if (root === null) return [];

    const columns = new Map();
    const queue = [[root, 0]];
    let head = 0;
    let minCol = 0;
    let maxCol = 0;

    while (head < queue.length) {
        const [node, col] = queue[head++];

        if (!columns.has(col)) columns.set(col, []);
        columns.get(col).push(node.val);

        if (node.left !== null) {
            queue.push([node.left, col - 1]);
            minCol = Math.min(minCol, col - 1);
        }
        if (node.right !== null) {
            queue.push([node.right, col + 1]);
            maxCol = Math.max(maxCol, col + 1);
        }
    }

    const answer = [];
    for (let col = minCol; col <= maxCol; col++) {
        answer.push(columns.get(col));
    }
    return answer;
};
from collections import defaultdict, deque
from typing import List, Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def verticalOrder(
        self, root: Optional[TreeNode]
    ) -> List[List[int]]:
        if root is None:
            return []

        columns = defaultdict(list)
        queue = deque([(root, 0)])
        min_col = max_col = 0

        while queue:
            node, col = queue.popleft()
            columns[col].append(node.val)

            if node.left is not None:
                queue.append((node.left, col - 1))
                min_col = min(min_col, col - 1)
            if node.right is not None:
                queue.append((node.right, col + 1))
                max_col = max(max_col, col + 1)

        return [columns[col] for col in range(min_col, max_col + 1)]
#include <algorithm>
#include <queue>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<vector<int>> verticalOrder(TreeNode* root) {
        if (root == nullptr) return {};

        unordered_map<int, vector<int>> columns;
        queue<pair<TreeNode*, int>> nodes;
        nodes.push({root, 0});
        int minCol = 0;
        int maxCol = 0;

        while (!nodes.empty()) {
            auto [node, col] = nodes.front();
            nodes.pop();
            columns[col].push_back(node->val);

            if (node->left != nullptr) {
                nodes.push({node->left, col - 1});
                minCol = min(minCol, col - 1);
            }
            if (node->right != nullptr) {
                nodes.push({node->right, col + 1});
                maxCol = max(maxCol, col + 1);
            }
        }

        vector<vector<int>> answer;
        answer.reserve(maxCol - minCol + 1);
        for (int col = minCol; col <= maxCol; ++col) {
            answer.push_back(columns[col]);
        }
        return answer;
    }
};

替代方案

可以 DFS 记录三元组 (col, row, order)，最后整体排序；其中 order 必须能表达同行同列时的从左到右顺序。该方案通常为 O(n log n)，实现与证明都比 BFS 更绕。也可使用有序映射代替最小/最大列号，代价是每次映射操作为 O(log k)。

常见错误

  • 只存节点、不存列号，之后无法判断归属。
  • 用 DFS 直接追加，却忽略同列的深度顺序。
  • 哈希表遍历顺序不等于从最左列到最右列。
  • 先入右孩子再入左孩子，破坏同行同列的左右顺序。
  • 忘记处理 root == null。

面试追问

为什么 BFS 不需要记录 row？

因为 FIFO 队列已经隐式保证深度递增，并保证同层从左到右；row 信息包含在遍历顺序里。

为什么可以从 minCol 连续扫到 maxCol？

从根的第 0 列出发，每条边只改变 1 列；到达极值列的路径会覆盖中间列，所以有效列不会有空洞。

与 987. 垂序遍历有什么区别？

本题同行同列按从左到右；987 在同行同列时按节点值升序，因此 987 需要显式排序。

如何流式输出？

一般仍需等遍历完成，才能确认不会出现更左的列；若树的结构或列范围预先已知，才可能安全提前输出。
