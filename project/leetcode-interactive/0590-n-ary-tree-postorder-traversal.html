N 叉树的后序遍历

N-ary Tree Postorder Traversal

给定一棵 N 叉树的根节点 root，返回所有节点值的后序遍历序列。输入使用层序序列化表示，每一组子节点之间由 null 分隔。

题目说明

函数：postorder(root)

后序遍历要求先依次处理当前节点的全部子树，最后才处理当前节点本身。N 叉树的每个节点可以拥有零个或多个有序子节点，因此遍历时必须保持 children 中原有的从左到右顺序。

示例 1

输入：root = [1,null,3,2,4,null,5,6]
输出：[5,6,3,2,4,1]

示例 2

输入：root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
输出：[2,6,14,11,7,3,12,8,4,13,9,10,5,1]
序列化提示：null 只用于分隔不同父节点的子节点组，不是树中的真实节点。

约束

  • 树中节点总数在 [0, 104] 范围内。
  • 0 <= Node.val <= 104。
  • N 叉树高度不超过 1000。

ITERATIVE FRAME STACK

题解：显式模拟递归栈帧

核心洞察

先记住“回到哪里”

栈帧同时保存节点和下一个待访问孩子的下标，才能在子树返回后继续。

写入时机

孩子全部完成再输出

当下标等于孩子数量，说明所有子树已按顺序处理，此时弹栈并记录节点值。

空间边界

栈只沿当前路径增长

栈深由树高决定，不会同时保存整棵树的所有节点。

完整过程

  1. 如果 root 为空，直接返回空数组。
  2. 把帧 (root, 0) 压栈；第二个字段表示下一个待访问孩子的下标。
  3. 查看栈顶。若仍有未访问孩子，先递增当前帧的下标，再把该孩子的新帧压栈。
  4. 若栈顶节点的孩子已全部处理，把节点值加入答案并弹出该帧。
  5. 重复直到栈空，答案就是后序遍历。

为什么正确

1

栈帧不变式：每个栈帧中，下标之前的孩子都已完成后序遍历，下标及之后的孩子尚未开始；栈从底到顶始终是一条根到当前节点的路径。

2

保持：进入下一个孩子前先递增父帧下标，再压入孩子帧。孩子弹栈返回后，父帧恰好指向再下一个孩子，因此不重复也不遗漏，并保持从左到右顺序。

3

输出正确：只有当一个节点的全部孩子都已完成时才输出该节点，所以每棵子树都满足“所有孩子在前、根在后”。栈最终为空时，每个节点恰好被输出一次，所得序列即整棵树的后序遍历。

复杂度

时间：O(n)，每个节点入栈、出栈各一次。
额外空间：O(h)，其中 h 是树高；返回数组占 O(n)。

边界情况

空树、单节点、退化成高度 1000 的链、一个节点拥有大量孩子、节点值为 0 或 104。

替代方案

递归 DFS 更短但使用系统调用栈；也可做“根→孩子逆序”的变体再反转答案，代码短但不直接模拟后序时机。

四语言完整代码

下列实现都采用同一套显式栈帧机制，保持孩子从左到右的顺序。

/*
// Definition for a Node.
class Node {
    public int val;
    public List<Node> children;
    public Node() {}
    public Node(int _val) { val = _val; }
    public Node(int _val, List<Node> _children) {
        val = _val;
        children = _children;
    }
}
*/
class Solution {
    private static class Frame {
        Node node;
        int nextChild;

        Frame(Node node) {
            this.node = node;
            this.nextChild = 0;
        }
    }

    public List<Integer> postorder(Node root) {
        List<Integer> answer = new ArrayList<>();
        if (root == null) return answer;

        Deque<Frame> stack = new ArrayDeque<>();
        stack.push(new Frame(root));

        while (!stack.isEmpty()) {
            Frame frame = stack.peek();
            List<Node> children = frame.node.children;
            int size = children == null ? 0 : children.size();

            if (frame.nextChild < size) {
                Node child = children.get(frame.nextChild++);
                if (child != null) stack.push(new Frame(child));
            } else {
                answer.add(frame.node.val);
                stack.pop();
            }
        }
        return answer;
    }
}
/**
 * // Definition for a _Node.
 * function _Node(val, children) {
 *   this.val = val;
 *   this.children = children;
 * }
 */

/**
 * @param {_Node|null} root
 * @return {number[]}
 */
var postorder = function(root) {
    const answer = [];
    if (root === null) return answer;

    const stack = [{ node: root, nextChild: 0 }];

    while (stack.length > 0) {
        const frame = stack[stack.length - 1];
        const children = frame.node.children || [];

        if (frame.nextChild < children.length) {
            const child = children[frame.nextChild];
            frame.nextChild += 1;
            if (child !== null) {
                stack.push({ node: child, nextChild: 0 });
            }
        } else {
            answer.push(frame.node.val);
            stack.pop();
        }
    }
    return answer;
};
"""
# Definition for a Node.
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children if children is not None else []
"""

class Solution:
    def postorder(self, root: 'Node') -> List[int]:
        answer = []
        if root is None:
            return answer

        # 每个帧是可变列表：[节点, 下一个孩子下标]
        stack = [[root, 0]]

        while stack:
            node, next_child = stack[-1]
            children = node.children or []

            if next_child < len(children):
                child = children[next_child]
                stack[-1][1] += 1
                if child is not None:
                    stack.append([child, 0])
            else:
                answer.append(node.val)
                stack.pop()

        return answer
/*
// Definition for a Node.
class Node {
public:
    int val;
    vector<Node*> children;
    Node() {}
    Node(int _val) : val(_val) {}
    Node(int _val, vector<Node*> _children)
        : val(_val), children(_children) {}
};
*/
class Solution {
public:
    vector<int> postorder(Node* root) {
        vector<int> answer;
        if (root == nullptr) return answer;

        // pair：节点、下一个待访问孩子的下标
        vector<pair<Node*, size_t>> stack;
        stack.push_back({root, 0});

        while (!stack.empty()) {
            auto& [node, nextChild] = stack.back();

            if (nextChild < node->children.size()) {
                Node* child = node->children[nextChild++];
                if (child != nullptr) stack.push_back({child, 0});
            } else {
                answer.push_back(node->val);
                stack.pop_back();
            }
        }
        return answer;
    }
};

面试追问

  • 如何改成前序遍历或层序遍历？
  • 若不能修改节点，如何只用一个栈实现？
  • 为什么反转“根—右到左”的序列也能得到后序？
  • 树高接近 1000 时，递归与迭代的工程风险有何不同？

常见错误

  • 节点刚入栈就写答案，错误地得到前序结果。
  • 忘记先推进父帧下标，返回后重复访问同一个孩子。
  • 反向压栈与最终反转同时用错，破坏左右顺序。
  • 没有处理空根节点，直接读取 root.children。
