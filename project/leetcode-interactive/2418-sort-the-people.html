2418. 按身高排序

Sort the People

一份名单，两组对应的数据。请把大家按身高从高到低排好队。

官方题目 ↗先思考 · 再观察 · 最后读代码

01 / 题目

给定等长数组 names 与 heights。同一下标的姓名和身高属于同一个人。所有身高都是互不相同的正整数。返回按身高降序排列后的姓名数组。

名字可以重复。即使两个人都叫 Bob，也要按照他们各自的身高安排位置。

官方示例 1

输入：names = ["Mary","John","Emma"]
      heights = [180,165,170]
输出：["Mary","Emma","John"]

Mary 最高，Emma 其次，John 最后。

官方示例 2

输入：names = ["Alice","Bob","Bob"]
      heights = [155,185,150]
输出：["Bob","Alice","Bob"]

身高 185 的 Bob 在最前，身高 150 的 Bob 在最后。

完整约束

  • n == names.length == heights.length
  • 1 ≤ n ≤ 1000
  • 1 ≤ names[i].length ≤ 20
  • 1 ≤ heights[i] ≤ 100000
  • names[i] 仅由大小写英文字母组成。
  • heights 中所有值互不相同。

03 / 独立题解

准备好后，展开索引实验与四语言实现。

核心洞察：排序的是人的索引

姓名和身高通过下标关联。创建 [0, 1, …, n−1]，按这些索引对应的身高降序排序，再用排好的索引读取姓名。这样两个原数组都不需要改动，也不会混淆重名的人。

索引传送带

人物卡保持原位；索引票据重新排队，再沿票据读取姓名。排序阶段作为一次标准库操作展示，不模拟库内部比较。

完整过程

  1. 建立索引数组 order = [0, 1, 2]。
  2. 比较索引对应的身高。示例 1 中，180 > 170 > 165，所以索引变成 [0, 2, 1]。
  3. 依次读取 names[0]、names[2]、names[1]，得到 ["Mary","Emma","John"]。

正确性

初始索引数组恰好包含每个人一次。排序只改变索引位置，因此没有人丢失或重复。比较器保证任意相邻结果索引 order[k] 和 order[k+1] 对应的身高从大到小排列。输出第 k 项取自 names[order[k]]，始终属于该身高对应的人。因此输出完整且满足身高降序要求。

边界与复杂度

n = 1 时直接保留唯一姓名；已经降序的输入顺序不变；重复姓名不影响索引的唯一性。题目不包含空数组或重复身高。

建立索引和映射各需 O(n) 时间，比较排序通常需 O(n log n) 时间；索引和返回数组使用 O(n) 空间。Java、Python、C++ 这里采用的标准排序具有 O(n log n) 的最坏时间界；JavaScript 的具体排序算法和复杂度由引擎实现决定，ECMAScript 不规定复杂度。

四语言完整实现

均采用官方函数签名及相同的索引排序机制；代码尚未编译或执行。

Java

import java.util.Arrays;

class Solution {
    public String[] sortPeople(String[] names, int[] heights) {
        int n = names.length;
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (a, b) ->
            Integer.compare(heights[b], heights[a]));
        String[] result = new String[n];
        for (int i = 0; i < n; i++) result[i] = names[order[i]];
        return result;
    }
}

JavaScript

/**
 * @param {string[]} names
 * @param {number[]} heights
 * @return {string[]}
 */
var sortPeople = function(names, heights) {
    const order = names.map((_, i) => i);
    order.sort((a, b) => heights[b] - heights[a]);
    return order.map(i => names[i]);
};

Python 3

from typing import List

class Solution:
    def sortPeople(self, names: List[str], heights: List[int]) -> List[str]:
        order = sorted(range(len(names)),
                       key=lambda i: heights[i], reverse=True)
        return [names[i] for i in order]

C++

#include <algorithm>
#include <numeric>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> sortPeople(vector<string>& names, vector<int>& heights) {
        vector<int> order(names.size());
        iota(order.begin(), order.end(), 0);
        sort(order.begin(), order.end(), [&](int a, int b) {
            return heights[a] > heights[b];
        });
        vector<string> result;
        result.reserve(names.size());
        for (int i : order) result.push_back(names[i]);
        return result;
    }
};

替代方案

把身高与姓名打包成二元组再按身高排序，同样可行，通常为 O(n log n) 时间和 O(n) 空间。也可同时交换两个原数组做选择排序，额外存储少，但时间为 O(n²)，且会修改输入。利用身高上界建立桶需 O(n + H) 时间和 O(H) 空间，H = 100000，对最多 1000 人未必划算。

常见错误

  • 只对 heights 排序，丢失与姓名的对应关系。
  • 把姓名作为字典键，覆盖重复的 Bob。
  • JavaScript 忘记数值比较器，或符号写反得到升序。
  • C++ 比较器使用 >=，违反严格弱序要求；应使用 >。
  • Java 对 int[] 传入对象比较器；此处使用 Integer[]。

面试追问

若允许相同身高呢？ 先明确并列顺序；若要保留原顺序，可以让身高相同时按原下标升序比较，避免依赖排序稳定性。

只要最高的 k 个人呢？ 可用容量 k 的最小堆，扫描 O(n log k)，最后再对堆中 k 人降序排序。

能不修改输入吗？ 上述四份代码都只排序新建的索引数组，并建立新结果数组。
