Maximum XOR of Two Non-Overlapping Subtrees

在同一棵树中选出两片互不相交的子树。分别求和，再进行异或。
先厘清“整棵子树”的范围，再思考如何高效选择。

01 / 题目

给定以节点 0 为根的无向树，共 n 个节点，编号为 0…n−1。edges[i] = [aᵢ, bᵢ] 描述一条边，values[i] 是节点权值。某个节点的子树包含它自己及其全部后代。

选择两棵没有公共节点的子树，分别计算其中所有节点权值的和，再对两个和做按位异或。返回最大得分；不存在合法的两棵子树时返回 0。子树不能任意删去后代；本题先求和，再异或。

maxXor(n: integer, edges: integer[][], values: integer[]) → long

约束

  • 2 ≤ n ≤ 5 × 10⁴
  • edges.length = n − 1；每条边包含两个编号，0 ≤ aᵢ, bᵢ < n
  • values.length = n，1 ≤ values[i] ≤ 10⁹
  • 保证 edges 构成有效的树。

04 / 题解 · 用遍历时机排除重叠

核心洞察

两棵子树相交，当且仅当一个根是另一个根的祖先。先计算所有子树和 S[u]，再执行 DFS：进入 u 时查询最大异或；离开 u 时才插入 S[u]。

进入 u 时，Trie 中只有已完整遍历结束的子树。祖先还在 DFS 路径上，后代尚未进入，因此都没有插入。Trie 内的子树彼此可以重叠，但它们每一棵都与当前 u 的子树不重叠。

完整过程

  1. 建立邻接表、父节点数组及父先于子的顺序。
  2. 逆序把每个节点的和加到父节点，得到 S[u]。
  3. 显式栈执行 DFS：非负编号为入场，~u 为退场。
  4. 入场时先查询 Trie，然后压入退场事件，再压入子节点入场事件。
  5. 退场时才插入 S[u]。每个节点查询、插入各一次。
  6. Trie 从第 45 位到第 0 位贪心选择相反分支；没有相反位时走相同位。空 Trie 跳过查询，初始答案为 0。

算法机制参考：walkccc 入场查询与退场插入。下方代码以显式栈实现，避免深链递归栈问题。

正确性证明

  1. 子树和：逆序累加时，孩子的和已计算完成。每个孩子的整棵子树仅加到父亲一次，故 S[u] 正确。
  2. 合法性：u 入场时，已退场的节点既不是仍在路径上的祖先，也不是尚未访问的后代；它们的子树都与 u 不相交。
  3. 完整性：任取一对不相交子树，其 DFS 区间不相交。较早的子树已退场插入，较晚的子树入场查询时一定能考虑前者。
  4. 贪心最优：已有高位相同的情况下，当前异或位取 1 带来的收益，大于所有低位的最大收益之和。相反分支存在时必须优先走它。
  5. 结论：每次查询求得当前根的最佳合法得分，所有合法对均被覆盖，维护最大值即得到全局答案。

边界与复杂度

  • 链形树：入场查询均为空，无合法对，返回 0。
  • 根 0：首次查询为空，最后才插入，不参与后续配对。
  • 相同和值：共享 Trie 路径即可，无需计数。
  • 总和至多 5 × 10¹³ < 2⁴⁶，因此处理 46 位。
  • Java 用 long，C++ 用 long long；JS 用 BigInt 做位运算，最终值小于 2⁴⁶，可安全转 Number。

时间 O(nB)，空间 O(nB)，B = 46。图、顺序及栈为 O(n)，Trie 至多 1 + nB 个节点。固定 B 时可写作 O(n)。

替代方案与常见错误

小规模可枚举每对节点，通过 DFS 入退时间判断祖先关系，合法时求异或。时间 O(n²)、额外空间 O(n)，不适用于 5 万节点。

也可使用 DFS 序区间和离线扫描，将结束位置早于当前起点的子树和加入 Trie，仍为 O(nB)，但需额外维护区间事件。

  • 一次插入所有和值：会错误配对祖先与后代。
  • 入场插入：后代查询将看到祖先。
  • 退场查询：会查询到自己的后代。
  • 只比较兄弟根：漏掉不同分支的内部节点。
  • 只处理 30 / 32 位：忽略子树和的高位。
  • JS 用 Number 的 ^：被截为 32 位。

面试追问

  • 返回两个根？Trie 叶子保存一个节点编号，查询返回伙伴编号，更新最大值时一起记录。
  • 为何不删除退场节点？它们与后续未访问分支不相交；祖先的查询已在更早的入场完成，不会再次查询。
  • 子节点顺序改变？只改变某一合法对被考虑的方向，不影响完整性。
  • 允许负权值？先定义固定位宽及有符号比较语义；本页的无符号高位优先贪心不能直接作为有符号最大值算法。

Java

import java.util.*;

class Solution {
    public long maxXor(int n, int[][] edges, int[] values) {
        List<List<Integer>> g = new ArrayList<>();
        for (int i = 0; i < n; i++) g.add(new ArrayList<>());
        for (int[] e : edges) {
            g.get(e[0]).add(e[1]);
            g.get(e[1]).add(e[0]);
        }
        int[] parent = new int[n], order = new int[n];
        parent[0] = -1;
        int count = 1;
        for (int i = 0; i < n; i++) {
            int u = order[i];
            for (int v : g.get(u)) if (v != parent[u]) {
                parent[v] = u;
                order[count++] = v;
            }
        }
        long[] sum = new long[n];
        for (int i = 0; i < n; i++) sum[i] = values[i];
        for (int i = n - 1; i > 0; i--) {
            int u = order[i];
            sum[parent[u]] += sum[u];
        }
        int[] zero = new int[46 * n + 1];
        int[] one = new int[46 * n + 1];
        int size = 1;
        long answer = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);
        while (!stack.isEmpty()) {
            int event = stack.pop();
            if (event < 0) { // Exit: insert.
                int u = ~event, at = 0;
                for (int b = 45; b >= 0; b--) {
                    int[] child = ((sum[u] >>> b) & 1) == 0 ? zero : one;
                    if (child[at] == 0) child[at] = size++;
                    at = child[at];
                }
            } else { // Enter: query before visiting children.
                int u = event, at = 0;
                long score = 0;
                if (size > 1) {
                    for (int b = 45; b >= 0; b--) {
                        boolean bit = ((sum[u] >>> b) & 1) != 0;
                        int opposite = bit ? zero[at] : one[at];
                        if (opposite != 0) {
                            score |= 1L << b;
                            at = opposite;
                        } else at = bit ? one[at] : zero[at];
                    }
                    answer = Math.max(answer, score);
                }
                stack.push(~u);
                for (int v : g.get(u)) if (v != parent[u]) stack.push(v);
            }
        }
        return answer;
    }
}

/**
 * @param {number} n
 * @param {number[][]} edges
 * @param {number[]} values
 * @return {number}
 */
var maxXor = function(n, edges, values) {
    const g = Array.from({length: n}, () => []);
    for (const [u, v] of edges) {
        g[u].push(v);
        g[v].push(u);
    }
    const parent = new Int32Array(n);
    parent[0] = -1;
    const order = [0];
    for (let i = 0; i < n; i++) {
        const u = order[i];
        for (const v of g[u]) if (v !== parent[u]) {
            parent[v] = u;
            order.push(v);
        }
    }
    const sum = values.map(x => BigInt(x));
    for (let i = n - 1; i > 0; i--) {
        const u = order[i];
        sum[parent[u]] += sum[u];
    }
    const child = [new Int32Array(46 * n + 1),
                   new Int32Array(46 * n + 1)];
    let size = 1, answer = 0n;
    const stack = [0];
    while (stack.length) {
        const event = stack.pop();
        if (event < 0) {
            const u = ~event;
            let at = 0;
            for (let b = 45n; b >= 0n; b--) {
                const bit = Number((sum[u] >> b) & 1n);
                if (child[bit][at] === 0) child[bit][at] = size++;
                at = child[bit][at];
            }
        } else {
            const u = event;
            let at = 0, score = 0n;
            if (size > 1) {
                for (let b = 45n; b >= 0n; b--) {
                    const bit = Number((sum[u] >> b) & 1n);
                    const opposite = child[bit ^ 1][at];
                    if (opposite !== 0) {
                        score |= 1n << b;
                        at = opposite;
                    } else at = child[bit][at];
                }
                if (score > answer) answer = score;
            }
            stack.push(~u);
            for (const v of g[u]) if (v !== parent[u]) stack.push(v);
        }
    }
    // The answer is below 2^46, hence exactly representable as Number.
    return Number(answer);
};

Python

from typing import List
from array import array

class Solution:
    def maxXor(self, n: int, edges: List[List[int]],
               values: List[int]) -> int:
        g = [[] for _ in range(n)]
        for u, v in edges:
            g[u].append(v)
            g[v].append(u)
        parent = [-1] * n
        order = [0]
        for u in order:
            for v in g[u]:
                if v != parent[u]:
                    parent[v] = u
                    order.append(v)
        sums = values[:]
        for u in reversed(order[1:]):
            sums[parent[u]] += sums[u]
        child = [array('i', [0]), array('i', [0])]
        answer = 0
        stack = [0]
        while stack:
            event = stack.pop()
            if event < 0:
                u, at = ~event, 0
                for b in range(45, -1, -1):
                    bit = (sums[u] >> b) & 1
                    if child[bit][at] == 0:
                        child[bit][at] = len(child[0])
                        child[0].append(0)
                        child[1].append(0)
                    at = child[bit][at]
            else:
                u, at, score = event, 0, 0
                if len(child[0]) > 1:
                    for b in range(45, -1, -1):
                        bit = (sums[u] >> b) & 1
                        opposite = child[bit ^ 1][at]
                        if opposite:
                            score |= 1 << b
                            at = opposite
                        else:
                            at = child[bit][at]
                    answer = max(answer, score)
                stack.append(~u)
                for v in g[u]:
                    if v != parent[u]:
                        stack.append(v)
        return answer

C++

#include <algorithm>
#include <array>
#include <vector>
using namespace std;

class Solution {
public:
    long long maxXor(int n, vector<vector<int>>& edges,
                     vector<int>& values) {
        vector<vector<int>> g(n);
        for (const auto& e : edges) {
            g[e[0]].push_back(e[1]);
            g[e[1]].push_back(e[0]);
        }
        vector<int> parent(n, -1), order{0};
        for (int i = 0; i < n; ++i) {
            int u = order[i];
            for (int v : g[u]) if (v != parent[u]) {
                parent[v] = u;
                order.push_back(v);
            }
        }
        vector<long long> sums(values.begin(), values.end());
        for (int i = n - 1; i > 0; --i) {
            int u = order[i];
            sums[parent[u]] += sums[u];
        }
        vector<array<int, 2>> trie(1, array<int, 2>{0, 0});
        trie.reserve(46 * n + 1);
        vector<int> stack{0};
        long long answer = 0;
        while (!stack.empty()) {
            int event = stack.back();
            stack.pop_back();
            if (event < 0) {
                int u = ~event, at = 0;
                for (int b = 45; b >= 0; --b) {
                    int bit = (sums[u] >> b) & 1;
                    if (trie[at][bit] == 0) {
                        trie[at][bit] = static_cast<int>(trie.size());
                        trie.push_back({0, 0});
                    }
                    at = trie[at][bit];
                }
            } else {
                int u = event, at = 0;
                long long score = 0;
                if (trie.size() > 1) {
                    for (int b = 45; b >= 0; --b) {
                        int bit = (sums[u] >> b) & 1;
                        int opposite = trie[at][bit ^ 1];
                        if (opposite) {
                            score |= 1LL << b;
                            at = opposite;
                        } else at = trie[at][bit];
                    }
                    answer = max(answer, score);
                }
                stack.push_back(~u);
                for (int v : g[u]) if (v != parent[u]) stack.push_back(v);
            }
        }
        return answer;
    }
};
