LEETCODE 3977 · STATE DIJKSTRA

有限电量到达目标节点的最少时间

在有向带权图中，转发一次会消耗当前节点成本。先最小化到达时间；同一最短时间下，保留最多电量。

Dijkstra状态图

题意

给定 n、有向边 edges=[u,v,t]、初始电量 power、离开节点成本 cost、source 和 target。仅当剩余电量至少为 cost[u] 时才能从 u 出边，随后电量减少 cost[u]。返回 [最短时间, 该时间下最大剩余电量]，不可达返回 [-1,-1]。

约束：n, edges.length ≤ 1000、power ≤ 1000、边时间 ≤ 10^9，时间用 64 位整数。

核心洞察

节点编号不足以描述状态：到同一节点而剩余电量不同，后续可走边不同。扩展为 (node, remainingPower) 后，所有边权仍非负，可以运行 Dijkstra。

优先队列按时间升序、同时间电量降序；第一次弹出目标，就是字典序最优答案。

题解与完整代码

过程、边界、复杂度

  1. 建邻接表；dist[u][p] 是到达 u 且余量为 p 的最短时间。
  2. 若 p ≥ cost[u]，每条 u→v 产生 (v,p-cost[u])。
  3. 键为 (time,-power)；第一次弹出 target 即是最短时间且剩余电量最大。

边界：起点等于目标返回 [0,power]；所有状态耗尽则 [-1,-1]。时间 O((n·power+edges·power)log(n·power))，空间 O(n·power+edges)。
