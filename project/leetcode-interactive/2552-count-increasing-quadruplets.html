Count Increasing Quadruplets

2552 / HARD统计上升四元组

四个位置按顺序向右，数值却要走出一次“低—高—中—更高”的折线。先读题，再亲手推动扫描器；完整题解留在页面底部。

困难 数组 动态规划 枚举 前缀计数

Problem

题目描述

给定一个长度为 n 的、下标从 0 开始的整数数组 nums。数组恰好是 1..n 的一个排列，请统计满足指定次序与大小关系的四元组数量。

四元组 (i, j, k, l) 被称为“上升四元组”，当且仅当：

0 ≤ i < j < k < l < n　且　nums[i] < nums[k] < nums[j] < nums[l]

返回所有符合条件的四元组数量。注意数值顺序中的 nums[k] 与 nums[j] 和位置顺序相反，这是本题的关键形状。

示例 1

调用
countQuadruplets(nums = [1,3,2,4,5])
返回
2
解释
有效下标为 (0,1,2,3) 与 (0,1,2,4)。

示例 2

调用
countQuadruplets(nums = [1,2,3,4])
返回
0
解释
唯一的四个位置满足 nums[j] < nums[k]，不符合目标大小关系。

约束

  • 4 ≤ nums.length ≤ 4000
  • 1 ≤ nums[i] ≤ nums.length
  • nums 中的整数互不相同，且 nums 是一个排列。

Solution

一次扫描，保存可闭合的三元组

枚举最右端点 right，再从左到右枚举中间位置 mid。一个一维计数数组就足以把四层枚举压缩到两层。

核心洞察

为每个位置 mid 维护 triples[mid]：在当前 right 之前，满足 i < mid < k < right 且 nums[i] < nums[k] < nums[mid] 的三元组数量。

扫描固定的 right 时，额外维护 smaller，表示已经越过的下标 i < mid 中，有多少个满足 nums[i] < nums[right]。

nums[mid] < nums[right] 时，储备的每个三元组都能接上当前右端点；反之，当前 right 可充当未来三元组里的 k，把 smaller 加入储备。

完整过程

  1. 初始化：triples 全为 0，答案 answer = 0。
  2. 枚举右端：让 right 从左到右移动，每轮把 smaller 置 0。
  3. 扫描中间位：对所有 mid < right：
    • 若 nums[mid] < nums[right]，执行 answer += triples[mid]，随后 smaller++。
    • 若 nums[mid] > nums[right]，执行 triples[mid] += smaller。
  4. 返回：所有右端点处理完后返回 answer。

为什么正确

不变式：处理一对 (mid, right) 前，smaller 精确等于满足 i < mid 且 nums[i] < nums[right] 的位置数；triples[mid] 精确记录此前形成的所有合法三元组 (i, mid, k)。

当 nums[mid] > nums[right] 时，当前 right 充当 k，每个被 smaller 计数的 i 都形成且仅形成一个 nums[i] < nums[k] < nums[mid] 的新三元组。当 nums[mid] < nums[right] 时，当前 right 充当 l，每个已储存三元组都恰好闭合为一个目标四元组。

每个目标四元组由唯一的 (mid, right) = (j, l) 在右端点到达 l 时计入一次，因此既不遗漏，也不重复。

边界情况

  • 完全递增排列没有 nums[k] < nums[j]，答案为 0。
  • 完全递减排列无法满足首尾的递增关系，答案也为 0。
  • 最短长度 n = 4 时，算法仍按同一不变式工作。
  • 答案可能超过 32 位整数；Java 使用 long，C++ 使用 long long。

复杂度

双层扫描的时间复杂度为 O(n²)；计数数组的空间复杂度为 O(n)。

替代方案

  • 暴力四枚举：O(n⁴)，只适合解释定义。
  • 前后二维计数：预计算左右可选数量后枚举 (j,k)，时间 O(n²)，但空间可达 O(n²)。
  • 树状数组：可做区间计数，但在本题排列约束下实现更重，且不优于这里的 O(n²) 主复杂度。

面试追问

  • 为什么 smaller 必须在每个 right 开始时清零？
  • 若数组允许重复值，比较符号和计数逻辑需要怎样保持严格不等？
  • 为什么 JavaScript 的 Number 在本题最大规模仍可精确表示答案？
  • 能否写出 O(n²) 时间、O(n²) 空间的前后计数解，并比较可读性？

常见错误

  • 把目标关系误读成 nums[i] < nums[j] < nums[k] < nums[l]。
  • 先增加 smaller 再处理当前 mid，从而让下标不再严格小于。
  • 把 triples 每轮清零，丢失此前右端点作为 k 形成的储备。
  • 使用 32 位答案类型导致溢出。
Javalong · O(n²)
class Solution {
    public long countQuadruplets(int[] nums) {
        int n = nums.length;
        long[] triples = new long[n];
        long answer = 0;

        for (int right = 0; right < n; right++) {
            int smaller = 0;
            for (int mid = 0; mid < right; mid++) {
                if (nums[mid] < nums[right]) {
                    answer += triples[mid];
                    smaller++;
                } else {
                    triples[mid] += smaller;
                }
            }
        }
        return answer;
    }
}

from typing import List


class Solution:
    def countQuadruplets(self, nums: List[int]) -> int:
        triples = [0] * len(nums)
        answer = 0

        for right in range(len(nums)):
            smaller = 0
            for mid in range(right):
                if nums[mid] < nums[right]:
                    answer += triples[mid]
                    smaller += 1
                else:
                    triples[mid] += smaller

        return answer
