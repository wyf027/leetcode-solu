Longest Continuous Increasing Subsequence

在相邻元素之间寻找持续上升的片段。先读懂“连续”和“严格递增”两个关键词，再用下方的扫描台观察每一次相邻比较如何改变当前片段。

Problem

题意

给定一个未经排序的整数数组 nums，返回其中最长的连续、严格递增子数组的长度。

连续递增片段可由下标 l 与 r 确定。片段为 [nums[l], nums[l+1], …, nums[r]]，并且对每个 l ≤ i < r，都有 nums[i] < nums[i+1]。

函数形式：findLengthOfLCIS(nums: integer[]) → integer

约束

  • 1 ≤ nums.length ≤ 104
  • −109 ≤ nums[i] ≤ 109

示例 1

出现断点 
输入：findLengthOfLCIS(nums = [1,3,5,4,7])
输出：3
解释：最长连续递增片段为 [1,3,5]，长度为 3。
[1,3,5,7] 虽然递增，但 5 与 7 在原数组中
被 4 隔开，因此不连续。

示例 2

严格递增 
输入：findLengthOfLCIS(nums = [2,2,2,2,2])
输出：1
解释：相等不满足严格递增，所以每个单元素片段
的长度都是 1，最长长度为 1。

Solution

准备好后再展开完整思路、证明与代码。

One Pass · Constant Space

一次扫描：只记住两段长度

连续性让状态变得很轻：新元素只能接在前一个元素后面，不能跨过中间位置。

核心洞察：扫描到 nums[i] 时，只需比较它与 nums[i−1]。若严格变大，当前连续递增长度加一；否则当前片段在这里断开，长度重置为 1。每一步再更新全局最大值。

完整过程

  1. 令 current = 1、best = 1。
  2. 从下标 1 开始扫描。若 nums[i] > nums[i−1]，令 current += 1。
  3. 否则相邻严格递增关系被破坏，令 current = 1。
  4. 每轮令 best = max(best, current)，最后返回 best。

正确性证明

不变式：处理完下标 i 后，current 等于以 i 结尾的最长连续递增片段长度；best 等于区间 [0, i] 内的最优长度。
保持：若当前值大于前值，以 i−1 结尾的片段可且只能向右延长一位；否则任何包含这对相邻元素的严格递增片段都不成立，只能从当前元素重新开始。
终止：扫描结束时，所有可能的连续递增片段末端都已被处理，因此 best 就是全局答案。

边界情况

  • 单元素数组：没有相邻比较，答案为 1。
  • 全相等或严格递减：每一步都会重置，答案为 1。
  • 全程严格递增：current 最终等于数组长度。
  • 负数和极大值不影响逻辑，因为只进行大小比较。
  • 官方约束保证非空；代码仍对空数组做防御性处理并返回 0。

复杂度

时间复杂度：O(n)，每个元素只处理一次。

空间复杂度：O(1)，除输入外只使用常数个变量。

替代方案

可以用动态规划数组记录每个位置结尾的长度，但需要 O(n) 额外空间；也可以维护当前片段左端点，用 i − left + 1 计算长度。两者本质上都利用同一个相邻关系。

class Solution {
    public int findLengthOfLCIS(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }

        int current = 1;
        int best = 1;

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] > nums[i - 1]) {
                current++;
            } else {
                current = 1;
            }
            best = Math.max(best, current);
        }

        return best;
    }
}

常见错误

  • 把“连续子数组”误当成可跳过元素的普通子序列。
  • 用 ≥ 判断递增，错误地把相等元素接入片段。
  • 断开时把 current 重置为 0；当前元素本身已经是长度 1 的新片段。
  • 只在断点更新答案，遗漏数组末尾就是最佳片段的情况。
  • 默认答案为 0，导致非空且无递增相邻对的数组返回错误。
