统计染色格子数Count Total Number of Colored Cells

从一个蓝色格子开始，观察颜色如何沿曼哈顿距离一圈圈扩散。先用交互演示建立直觉，再按需展开完整题解。

中等 非会员题 数学 函数：coloredCells(n)

Problem

题目描述

1 ≤ n ≤ 105

在一个无限大的二维单位方格网中，所有格子起初都没有颜色。给定正整数 n，连续进行 n 分钟的染色：

第一分钟任选一个格子染成蓝色；之后每一分钟，把所有与蓝色格子共边相邻、且尚未染色的格子同时染成蓝色。

返回第 n 分钟结束时，蓝色格子的总数。

1

选起点
任意一个单位格子变为蓝色。

2+

同步扩散
每个蓝色格子的上、下、左、右相邻格子被染色。

示例 1
输入：n = 1
输出：1

第 1 分钟只有起始格子为蓝色，因此返回 1。

示例 2
输入：n = 2
输出：5

第 2 分钟时，中心格子加上边界的 4 个格子，共 5 个。

约束：1 <= n <= 100000

Solution

数学规律：按距离分层计数

O(1) 时间 · O(1) 空间
核心洞察答案 = 1 + 4 × (1 + 2 + ⋯ + n − 1) = 1 + 2n(n − 1)

第 1 分钟只有中心。第 k 分钟新增的格子恰好位于距中心曼哈顿距离 k − 1 的菱形边界上，共 4(k − 1) 个。

完整过程

  1. 把第一分钟染色的格子视作中心。
  2. 第 2 到第 n 分钟依次增加第 1 到第 n−1 圈。
  3. 距离为 d 的菱形边界含 4d 个格子。
  4. 累加并使用等差数列求和，得到 1 + 2n(n−1)。

正确性证明

  1. 染色每分钟只沿共边移动一步，所以第 k 分钟结束时，恰有曼哈顿距离不超过 k−1 的格子被染色。
  2. 距离恰为 d>0 的格子组成菱形边界；四条边各贡献 d 个不重复格子，因此共有 4d 个。
  3. 中心贡献 1，其余各层贡献之和为 Σ(4d)，其中 d=1..n−1。故算法返回全部且仅有的染色格子数。

边界与类型

  • n = 1 时求和为空，答案为 1。
  • n = 100000 时答案为 19,999,800,001，超过 32 位有符号整数。
  • Java 与 C++ 必须使用 64 位整数；乘法前就要提升类型。
  • JavaScript 的该范围结果小于 Number.MAX_SAFE_INTEGER。

复杂度与替代方案

  • 公式法：时间 O(1)，空间 O(1)。
  • 逐层累加：从第 2 分钟起累加 4(k−1)，时间 O(n)；直观但没有必要。
  • 网格模拟：至少触达每个染色格子，既耗时又耗内存，只适合演示。

常见错误

  • 把“相邻”误解为包含对角线，实际只有上下左右共边相邻。
  • 把第 n 分钟的最外层距离写成 n，产生偏一错误；应为 n−1。
  • Java/C++ 先用 32 位整数完成乘法，再赋给 64 位变量，溢出已发生。
  • 真的维护无限网格，忽略了扩散图形的规律。
