连续天数的最高销售额

从每日销售额中选出一段连续且非空的区间，使区间总销售额最大。

连续一或多天返回最大总和最多 10⁵ 天

题意与示例

整数数组 sales 记录每日销售额，返回任意连续一或多天销售额之和的最大值，要求 O(n)。 

sales = [-2,1,-3,4,-1,2,1,-5,4]
输出 = 6
sales = [5,4,-1,7,8]
输出 = 23

约束：1 <= sales.length <= 10⁵，-100 <= sales[i] <= 100。

题解：Kadane 的两种选择

核心洞察

以 i 结尾的最大连续和，要么是前一天最大段加上 sales[i]，要么干脆从 sales[i] 单独开始：current=max(sales[i], current+sales[i])。每轮用 current 更新全局 best。

完整过程

  1. 以第一个数初始化 current 和 best。
  2. 依次扫描后续元素，比较接续与重开。
  3. best 记录任何时刻的最大 current。

边界与复杂度

全负数组必须返回最大的那个元素，不能返回 0；单元素直接返回自身。时间 O(n)，只用 O(1) 变量。

替代方案、面试追问与常见错误

  • 替代方案：分治法合并左侧、右侧和跨中点答案，复杂度 O(n log n)，实现更复杂。
  • 面试追问：若要返回区间端点，在重开当前段和刷新 best 时同步记录下标。
  • 常见错误：把 current 或 best 初始化为 0，导致全负数组错误返回 0。

可提交代码

class Solution {
    public int maxSales(int[] sales) {
        int current = sales[0], best = sales[0];
        for (int i = 1; i < sales.length; i++) {
            current = Math.max(sales[i], current + sales[i]);
            best = Math.max(best, current);
        }
        return best;
    }
}
