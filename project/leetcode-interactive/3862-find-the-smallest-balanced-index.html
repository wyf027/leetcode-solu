找出最小平衡下标

左侧做求和，右侧做连乘。从右向左维护两个量，利用正整数带来的单调性，在线性时间内找到唯一可能的平衡点。

题意

给定整数数组 nums。若下标 i 左侧元素之和，恰好等于右侧元素之积，则 i 是平衡下标。返回最小的平衡下标；不存在则返回 -1。

示例 1

nums = [2, 1, 2]

输出 1：左和 2，右积 2。

示例 2

nums = [2, 8, 2, 2, 5]

输出 2：左和 10，右积 10。

边界

nums = [1]

输出 -1：空左侧为 0，空右侧为 1。

约束：1 ≤ nums.length ≤ 10⁵，1 ≤ nums[i] ≤ 10⁹。数组元素均为正数。

从右向左的状态机

当前候选下标的左侧和是 sum；右侧积是 product。每一步先移走当前数，再比较。

题解：右扫 + 单调剪枝

核心洞察

  1. 先令 sum = Σ nums，product = 1（空右侧的积）。
  2. 从右向左枚举 i：先做 sum -= nums[i]，此时它正是 i 左侧的元素和。
  3. 如果 sum == product，该位置平衡。正数条件下等式至多出现一次；继续左移时左和变小、右积变大。
  4. 比较后把 nums[i] 乘入 product。若新积已经大于左和，以后差距只会扩大，直接结束。

完整过程（[2, 8, 2, 2, 5]）

i=4：左和 14，右积 1；乘入 5 后右积为 5。

i=3：左和 12，右积 5；乘入 2 后右积为 10。

i=2：左和 10，右积 10，返回 2。

复杂度

O(n) 时间，O(1) 额外空间。

边界

空左侧是 0，空右侧是 1；单元素数组通常无解。用 64 位整数承接和与受控积。

常见错误

把当前元素算进任一侧；先乘再比较；不利用正数单调性导致乘积溢出。

替代方案与面试追问

可构建后缀积再从左扫描，但会占用 O(n) 空间且积可能快速溢出。若数组允许 0 或负数，单调剪枝失效，需要重新设计状态或采用高精度/因数分解策略。面试可追问：如何安全判断乘法是否越界？答案是在乘前比较 product > sum / nums[i]。
