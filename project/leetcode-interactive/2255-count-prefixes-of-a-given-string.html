Count Prefixes of a Given String

从字符串的起点出发，哪些单词能与它的开头完整重合？

前往 LeetCode 官方题目 ↗
01 / 读题

找的是前缀，统计的是出现次数

给定字符串数组 words 和字符串 s，返回数组中有多少个字符串是 s 的前缀。前缀必须从 s 的第一个字符开始，且连续覆盖整个待判断的字符串。字符串本身也属于自己的前缀；数组中的重复项各自计数。

参数与返回值

countPrefixes(words: string[], s: string) → integer

官方约束

  • 1 ≤ words.length ≤ 1000
  • 1 ≤ words[i].length, s.length ≤ 10
  • 所有字符串仅含小写英文字母。
EXAMPLE 01
words = ["a","b","c","ab","bc","abc"]
s = "abc"
输出：3

“a”、“ab” 和 “abc” 是前缀，共 3 个。“bc” 出现在中间，不能计入。

EXAMPLE 02
words = ["a","a"]
s = "aa"
输出：2

两个 “a” 都是前缀。即使内容相同，也要分别计入。

04 / 独立题解

想清楚后，再揭开答案

核心洞察

对每个单词 w，只需判断 s 是否以 w 开头。各数组项之间互不影响，因此逐项判断并累加即可，无需排序或去重。

完整过程

  1. 初始化计数器 answer = 0。
  2. 遍历每一个 w。若它比 s 长，直接跳过。
  3. 从下标 0 开始比较字符，任一字符不同就判定失败；全部字符相同则计数加 1。
  4. 遍历结束返回计数。标准库的前缀方法封装了这项判断。

例如 w = "ab", s = "abc"：下标 0 的 a 相同，下标 1 的 b 相同；w 已完整匹配，所以计入。无需匹配 s 剩下的 c。

正确性

循环不变式：处理完前 k 个数组项后，计数等于这些项中前缀的数量。开始时 k = 0，计数为 0，成立。下一项只有在长度允许且每个字符与 s 的相同下标字符一致时才加 1，这恰好等价于前缀定义；否则不改变计数。故不变式保持。处理完全部 n 项后，计数就是要求的答案，重复项也各被处理一次。

边界与复杂度

完整相等也算前缀；过长单词失败；首字符或中间字符不同均失败；重复项分别计数。题目不包含空字符串。设 n 为 words 的数量、L 为最大单词长度，最坏时间为 O(nL)，额外空间 O(1)，不含输入和教学演示帧。这里 L ≤ 10。

替代方案

手动逐字符比较与标准库前缀判断等价。也可以枚举 s 的所有前缀放入集合，再逐项查询 words；在通常复制与哈希字符串的实现下，构造前缀会累计花费 O(|s|²) 字符工作与存储，本题无需这些额外开销。只有大量字符串查询时才值得讨论 Trie 等结构。

常见错误

  • 用 contains / includes：会把 “bc” 这样的中间子串误算为前缀。
  • 写反方向：应判断 s 是否以 w 开头，而不是 w 是否以 s 开头。
  • 先对 words 去重：会丢失官方示例 2 的重复计数。
  • 手动比较不检查长度：可能访问 s 的越界位置。

面试追问

如果允许空字符串？空串是任意字符串的前缀，应计入。若 words 固定而 s 被查询很多次？可构造 Trie，并在终止节点保存重复次数，每次沿 s 走时累加。若字符包含 Unicode？先明确按编码单元、码点还是用户感知字符比较；本题仅有小写英文字母，不涉及这一区别。

Java

class Solution {
    public int countPrefixes(String[] words, String s) {
        int answer = 0;
        for (String word : words) {
            if (s.startsWith(word)) {
                answer++;
            }
        }
        return answer;
    }
}

Python 3

from typing import List

class Solution:
    def countPrefixes(self, words: List[str], s: str) -> int:
        answer = 0
        for word in words:
            if s.startswith(word):
                answer += 1
        return answer

C++

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int countPrefixes(vector<string>& words, string s) {
        int answer = 0;
        for (const string& word : words) {
            if (s.size() >= word.size() &&
                s.compare(0, word.size(), word) == 0) {
                ++answer;
            }
        }
        return answer;
    }
};
