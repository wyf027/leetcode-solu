01 / Problem

把图像当作透明胶片

给定两个大小相同的二进制正方形矩阵 img1 与 img2。将其中一张整体向上、下、左、右平移任意整数单位，再覆盖到另一张上。

题意转述

每个矩阵元素只可能是 0 或 1。一次平移会让图像中的所有 1 保持相对位置不变并一起移动；移出边界的 1 被丢弃。平移不允许旋转或翻转。

覆盖后，如果同一个坐标在两张图像中都为 1，就贡献一次重叠。请返回所有可能平移中最大的重叠数量。

官方函数形式：largestOverlap(img1, img2) → integer。

约束

  • n == img1.length == img1[i].length
  • n == img2.length == img2[i].length
  • 1 ≤ n ≤ 30
  • img1[i][j] 为 0 或 1
  • img2[i][j] 为 0 或 1

示例 1

输入 
img1 = [[1,1,0],[0,1,0],[0,1,0]],
img2 = [[0,0,0],[0,1,1],[0,0,1]]
输出3
解释

将 img1 向右 1 格、向下 1 格，可得到 3 个重叠的 1。

示例 2

输入 
img1 = [[1]], img2 = [[1]]
输出1

示例 3

输入 
img1 = [[0]], img2 = [[0]]
输出0

03 / Solution

准备好再揭开机制

题解与完整代码独立收纳在下方。展开前，可以先在平移台里猜一猜：怎样避免检查大量无意义的 0？

Decoded

让每对 1 为平移量投票

只保留两张图中值为 1 的坐标。若 img1 的一个 1 要与 img2 的一个 1 重合，它们唯一确定一个平移向量。

核心洞察：相同向量的票数，就是对应平移下的重叠数

(dr, dc) = (r₂ − r₁, c₂ − c₁)

枚举 img1 中的每个 1 与 img2 中的每个 1，计算把前者移动到后者所需的向量，并在哈希表中计数。出现次数最多的向量就是答案。

完整过程

  1. 扫描两个矩阵，分别收集所有值为 1 的坐标。
  2. 两层循环枚举坐标对 (p1, p2)。
  3. 计算 p2 - p1 得到平移向量，并把该向量的计数加一。
  4. 持续维护最大计数；若任意一张图没有 1，计数表为空，返回 0。

正确性证明

1

每张票都有效。 对任意坐标对 p1 与 p2，向量 p2-p1 恰好把 p1 移到 p2，因此这两个 1 会在该平移下重叠。

2

每个重叠都被计入。 固定任意平移向量 v，平移后每个重叠位置都对应唯一一对满足 p2-p1=v 的 1，因此它为 v 恰好贡献一票。

3

计数等价。 由前两点，向量 v 的票数与采用 v 平移时的重叠数一一对应，所以所有向量中的最大票数就是最大可能重叠。

复杂度与边界

设两张图中 1 的数量分别为 k₁、k₂。

  • 收集坐标：时间 O(n²)，空间 O(k₁ + k₂)。
  • 向量投票：时间 O(k₁k₂)。
  • 不同向量至多 (2n−1)² 个，因此哈希计数空间可记为 O(n²)。
  • 任一图全为 0 时没有坐标对，答案为 0。
  • n=1 时仍适用：两个元素都为 1 才有一票。
  • 负平移量必须作为合法键保存，不能丢弃。

替代方案

  • 枚举全部平移： 枚举 dr, dc，每次扫描矩阵计数，时间 O(n⁴)；直观但没有利用稀疏性。
  • 二维卷积： 翻转一张图后做卷积，卷积峰值就是最大重叠；可用 FFT 加速，但实现复杂且有浮点误差处理。
  • 位集： 把每行压成整数，按水平位移做位运算，再统计 1；在 n≤30 时很实用，但跨语言写法差异较大。

面试追问

  • 若矩阵非常稠密，坐标投票与枚举平移哪个更合适？如何动态选择？
  • 若允许旋转 90°，如何复用同一计数过程？
  • 若两张图尺寸不同，平移向量的范围与编码方式怎样调整？
  • 怎样用卷积解释“相关性”，并避免 FFT 舍入导致的误差？

常见错误

  • 把向量方向写反并在代码其他位置混用；统一采用 img2 坐标 − img1 坐标。
  • 只按距离计数，忽略方向；(1, 0) 与 (−1, 0) 是不同平移。
  • 用不安全的整数编码导致不同向量碰撞；基数必须严格大于列偏移的完整取值跨度。
  • 误以为移出边界的 1 需要单独处理；坐标配对只统计仍与另一个 1 重合的点，越界点自然不贡献票。
  • 在空计数表上直接求最大值；应让答案初始为 0。

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int largestOverlap(int[][] img1, int[][] img2) {
        int n = img1.length;
        Map<Integer, Integer> votes = new HashMap<>();
        int answer = 0;
        int base = 2 * n + 1;

        for (int r1 = 0; r1 < n; r1++) {
            for (int c1 = 0; c1 < n; c1++) {
                if (img1[r1][c1] == 0) continue;

                for (int r2 = 0; r2 < n; r2++) {
                    for (int c2 = 0; c2 < n; c2++) {
                        if (img2[r2][c2] == 0) continue;

                        int dr = r2 - r1;
                        int dc = c2 - c1;
                        int key = (dr + n) * base + (dc + n);
                        int count = votes.getOrDefault(key, 0) + 1;
                        votes.put(key, count);
                        answer = Math.max(answer, count);
                    }
                }
            }
        }

        return answer;
    }
}

var largestOverlap = function (img1, img2) {
    const ones1 = [];
    const ones2 = [];
    const n = img1.length;

    for (let r = 0; r < n; r++) {
        for (let c = 0; c < n; c++) {
            if (img1[r][c] === 1) ones1.push([r, c]);
            if (img2[r][c] === 1) ones2.push([r, c]);
        }
    }

    const votes = new Map();
    let answer = 0;

    for (const [r1, c1] of ones1) {
        for (const [r2, c2] of ones2) {
            const key = `${r2 - r1},${c2 - c1}`;
            const count = (votes.get(key) || 0) + 1;
            votes.set(key, count);
            answer = Math.max(answer, count);
        }
    }

    return answer;
};
from collections import Counter
from typing import List


class Solution:
    def largestOverlap(
        self, img1: List[List[int]], img2: List[List[int]]
    ) -> int:
        ones1 = [
            (r, c)
            for r, row in enumerate(img1)
            for c, value in enumerate(row)
            if value == 1
        ]
        ones2 = [
            (r, c)
            for r, row in enumerate(img2)
            for c, value in enumerate(row)
            if value == 1
        ]

        votes = Counter(
            (r2 - r1, c2 - c1)
            for r1, c1 in ones1
            for r2, c2 in ones2
        )
        return max(votes.values(), default=0)
#include <algorithm>
#include <unordered_map>
#include <utility>
#include <vector>

using namespace std;

class Solution {
public:
    int largestOverlap(vector<vector<int>>& img1,
                       vector<vector<int>>& img2) {
        vector<pair<int, int>> ones1;
        vector<pair<int, int>> ones2;
        int n = static_cast<int>(img1.size());

        for (int r = 0; r < n; ++r) {
            for (int c = 0; c < n; ++c) {
                if (img1[r][c] == 1) ones1.push_back({r, c});
                if (img2[r][c] == 1) ones2.push_back({r, c});
            }
        }

        unordered_map<int, int> votes;
        int answer = 0;
        int base = 2 * n + 1;

        for (const auto& [r1, c1] : ones1) {
            for (const auto& [r2, c2] : ones2) {
                int dr = r2 - r1;
                int dc = c2 - c1;
                int key = (dr + n) * base + (dc + n);
                answer = max(answer, ++votes[key]);
            }
        }

        return answer;
    }
};
