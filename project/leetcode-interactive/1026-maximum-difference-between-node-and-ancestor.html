节点与其祖先之间的最大差值

Maximum Difference Between Node and Ancestor

MEDIUM深度优先搜索二叉树非付费题

题目

给定一棵二叉树的根节点 root。请在所有不同节点 A、B 中，找到满足 A 是 B 的祖先时 |A.val - B.val| 的最大值。祖先可以是父节点，也可以位于更高层。

示例 1

输入：root = [8,3,10,1,6,null,14,null,null,4,7,13] 输出：7 解释：祖先 8 与后代 1 的差为 |8 - 1| = 7，这是最大值。

示例 2

输入：root = [1,null,2,null,0,3] 输出：3

约束

  • 树中节点数位于 [2, 5000]。
  • 0 <= Node.val <= 10^5。

Solution

题解：DFS 维护路径值域

核心洞察

对当前节点而言，合法的 A 必须出现在根到它的路径上。因此无需保存整条路径，只需保存其中的最小值 lo 与最大值 hi；当前路径能产生的最大差就是 hi - lo。

完整过程

  1. 以根值初始化 lo、hi。
  2. 访问节点时，用节点值更新二者。
  3. 用更新后的 hi - lo 更新答案。
  4. 将这两个路径状态分别传给左右子树。不同分支使用自己的数值副本。

正确性

不变式：进入任一节点后，lo 与 hi 分别等于根到该节点路径上的最小值和最大值。根节点显然成立；从父节点走到子节点时加入且只加入子节点值，更新后仍成立。路径中任意两值的最大绝对差一定由最小值和最大值构成，而路径上的较高节点正是较低节点的祖先。因此遍历所有节点后，取到的最大 hi - lo 恰为题目所求。

边界与复杂度

  • 所有值相同，答案为 0。
  • 单链树仍按同一逻辑处理；递归深度可能达到节点数。
  • 时间复杂度 O(n)；递归栈空间 O(h)，h 为树高。

替代方案

也可让每个子树向上返回其最小值与最大值，并在父节点计算差值。这是后序 DFS，同样为 O(n)，但路径状态的前序写法通常更直接。若担心极深树导致递归栈溢出，可显式使用栈保存 (node, lo, hi)。

面试追问

  • 若要求返回构成答案的两个节点，应额外携带路径最小/最大节点引用。
  • 若祖先必须是严格祖先，为什么当前写法仍正确？单个节点使差值为 0，不会制造错误的正答案；树至少有两个节点。
  • 如何改成迭代？把递归参数装入栈即可。

常见错误

  • 只比较当前节点与父节点，遗漏跨多层祖先。
  • 为左右分支共享并修改可变的 lo/hi 状态，造成分支污染。
  • 只用根值与当前值比较，遗漏路径中间节点产生的极值。

四语言完整实现

Java

class Solution {
    public int maxAncestorDiff(TreeNode root) {
        return dfs(root, root.val, root.val);
    }
    private int dfs(TreeNode node, int lo, int hi) {
        if (node == null) return hi - lo;
        lo = Math.min(lo, node.val);
        hi = Math.max(hi, node.val);
        return Math.max(dfs(node.left, lo, hi),
                        dfs(node.right, lo, hi));
    }
}

JavaScript

var maxAncestorDiff = function(root) {
  const dfs = (node, lo, hi) => {
    if (node === null) return hi - lo;
    lo = Math.min(lo, node.val);
    hi = Math.max(hi, node.val);
    return Math.max(
      dfs(node.left, lo, hi),
      dfs(node.right, lo, hi)
    );
  };
  return dfs(root, root.val, root.val);
};

Python

class Solution:
    def maxAncestorDiff(self, root: Optional[TreeNode]) -> int:
        def dfs(node, lo, hi):
            if node is None:
                return hi - lo
            lo = min(lo, node.val)
            hi = max(hi, node.val)
            return max(dfs(node.left, lo, hi),
                       dfs(node.right, lo, hi))

        return dfs(root, root.val, root.val)

C++

class Solution {
public:
    int maxAncestorDiff(TreeNode* root) {
        return dfs(root, root->val, root->val);
    }
private:
    int dfs(TreeNode* node, int lo, int hi) {
        if (node == nullptr) return hi - lo;
        lo = min(lo, node->val);
        hi = max(hi, node->val);
        return max(dfs(node->left, lo, hi),
                   dfs(node->right, lo, hi));
    }
};
