删除子文件夹

给定一组绝对文件夹路径，移除所有位于另一条路径之下的子文件夹，返回剩余路径。答案顺序不限。

深度优先搜索字典树数组字符串
Problem

题意

函数接收字符串数组 folder。如果某个路径位于列表中另一文件夹的内部，就将它删除；最后返回所有不是其他路径子文件夹的路径。

判断边界：路径 child 是 parent 的子文件夹，当且仅当它以 parent + "/" 开头。斜杠不可省略，因此 /a/bc 不是 /a/b 的子文件夹。

合法路径由一个或多个“斜杠 + 小写字母段”串联而成，例如 /leetcode 与 /leetcode/problems。

约束

  • 1 ≤ folder.length ≤ 4 × 10⁴
  • 2 ≤ folder[i].length ≤ 100
  • 路径只包含小写字母和 /
  • 每条路径都以 / 开头
  • 所有路径互不相同
Examples

官方示例

Example 01
输入：folder = ["/a","/a/b","/c/d","/c/d/e","/c/f"]
输出：["/a","/c/d","/c/f"]

/a/b 位于 /a 下，/c/d/e 位于 /c/d 下。

Example 02
输入：folder = ["/a","/a/b/c","/a/b/d"]
输出：["/a"]

后两条路径都是 /a 的子文件夹，因此只留下根路径。

Example 03
输入：folder = ["/a/b/c","/a/b/ca","/a/b/d"]
输出：["/a/b/c","/a/b/ca","/a/b/d"]

相似前缀不等于父子关系；路径段边界必须是斜杠。

Solution

排序 + 线性扫描

核心洞察

先将路径按字典序排序。任何父文件夹都会排在它的子文件夹之前，而且同一父目录下的子路径会连续出现。扫描时只需比较当前路径与最近保留的路径：

current.startsWith(lastKept + "/") 为真时，当前路径就是子文件夹；否则保留它。

拼上 / 是关键。例如 /a/bc 以 /a/b 开头，但不以 /a/b/ 开头。

完整过程

  1. 排序
    将所有路径按字典序升序排列。
  2. 建立保留区
    结果为空时，第一条路径必然保留。
  3. 检查边界前缀
    比较当前路径与最后一条保留路径加斜杠后的字符串。
  4. 保留或跳过
    匹配则跳过，不匹配则加入结果并成为新的比较基准。

为什么正确

性质 1 · 排序聚集若 p 是 x 的父路径，则 p 在字典序中先于 x，且所有以 p + "/" 开头的路径形成连续区间。
性质 2 · 最近保留者足够处理 x 时，若它属于某个已保留父路径，该父路径覆盖的连续区间尚未结束，因此最后保留路径就是能覆盖它的祖先。
结论前缀匹配时跳过的恰好是子文件夹；不匹配时，已不存在能覆盖当前路径的已保留祖先，所以保留它是正确的。

用循环不变式表达：扫描完前 i 条排序路径后，结果恰好包含其中所有顶层文件夹，并且最后一项是最靠近下一扫描位置的顶层文件夹。上述两种分支都保持该不变式，扫描结束即得到完整答案。

复杂度

时间O(n log n · L)字符串排序主导；L 为最大路径长度。
额外空间O(n)结果数组与排序所需空间；具体排序栈依语言实现。

边界情况

  • 只有一条路径：直接保留。
  • 所有路径都在同一根路径下：只保留最短的祖先。
  • 所有路径互不包含：全部保留。
  • /a/b 与 /a/bc：两者都应保留。
  • 父子路径在输入中逆序：排序后仍能正确处理。

替代方案

哈希集合 + 枚举祖先

将所有路径放入集合，对每条路径依次截取每个斜杠之前的前缀，若某个祖先在集合中则删除。思路直接，平均时间约为字符总量，但频繁截取字符串可能产生额外开销。

字典树

按路径段插入 Trie；一旦途中遇到终止标记，后续节点都属于子文件夹。适合流式插入或需要复用目录结构的场景，但节点结构与实现复杂度更高。

四语言完整实现

import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<String> removeSubfolders(String[] folder) {
        Arrays.sort(folder);
        List<String> answer = new ArrayList<>();

        for (String path : folder) {
            if (answer.isEmpty()) {
                answer.add(path);
                continue;
            }

            String parentPrefix = answer.get(answer.size() - 1) + "/";
            if (!path.startsWith(parentPrefix)) {
                answer.add(path);
            }
        }
        return answer;
    }
}

from typing import List


class Solution:
    def removeSubfolders(self, folder: List[str]) -> List[str]:
        folder.sort()
        answer: List[str] = []

        for path in folder:
            if not answer or not path.startswith(answer[-1] + "/"):
                answer.append(path)

        return answer
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    vector<string> removeSubfolders(vector<string>& folder) {
        sort(folder.begin(), folder.end());
        vector<string> answer;

        for (const string& path : folder) {
            if (answer.empty()) {
                answer.push_back(path);
                continue;
            }

            const string parentPrefix = answer.back() + "/";
            if (path.compare(0, parentPrefix.size(), parentPrefix) != 0) {
                answer.push_back(path);
            }
        }
        return answer;
    }
};

常见错误

  • 只检查普通字符串前缀，误删 /a/bc。
  • 未先排序，却只与上一条输入路径比较。
  • 与“上一条扫描路径”比较；应与“最后保留路径”比较。
  • 遍历中直接删除数组元素，导致下标错位或额外的线性搬移。
  • 忘记答案允许任意顺序，却为恢复原顺序增加无用逻辑。

面试追问

  • 如果路径流式到达，不能一次排序？ 使用按目录段构建的 Trie，或维护支持前缀查询的有序集合。
  • 如果允许重复路径？ 先明确重复项是否应去重；本题官方约束保证唯一。
  • 为何比较最后一个答案就够？ 因为字典序让某父路径覆盖的所有子路径连续出现。
  • 系统路径包含大小写或 ..？ 需先根据目标文件系统规则做规范化；本题输入已规范化。
