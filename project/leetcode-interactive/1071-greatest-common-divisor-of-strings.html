字符串的最大公因子

Greatest Common Divisor of Strings——从“两个拼接顺序是否相同”出发，找到两个字符串共享的最长重复基元。

EASY欧几里得算法字符串非付费题

题目

若字符串 s 能由非空字符串 t 重复拼接一次或多次得到，就称 t 能除尽 s。给定 str1 与 str2，返回能同时除尽二者的最长字符串；若不存在则返回空字符串。

输入：str1 = "ABCABC", str2 = "ABC"\n输出："ABC"
输入：str1 = "ABABAB", str2 = "ABAB"\n输出："AB"
输入：str1 = "LEET", str2 = "CODE"\n输出：""
输入：str1 = "AAAAAB", str2 = "AAA"\n输出：""

约束

  • 1 <= str1.length, str2.length <= 1000
  • 两个字符串仅包含大写英文字母。

重复节拍实验室

先观察拼接顺序，再用长度的最大公约数切出候选前缀。你可以修改输入；内容会以安全文本节点呈现。

题解

核心洞察：若两字符串由同一基元重复而成，那么 str1 + str2 === str2 + str1。通过这道兼容性门槛后，答案长度就是 gcd(str1.length, str2.length)。

完整过程

  1. 比较两种拼接顺序。若不相等，说明不存在共同重复基元，立即返回空串。
  2. 用欧几里得算法计算两个长度的最大公约数 g。
  3. 返回 str1 的前 g 个字符。兼容性已经保证它能重复铺满两个字符串。

正确性证明

若存在公共除数字符串 x，则两串都是 x 的若干次重复，所以交换拼接顺序不改变字符序列。反之，当两种拼接相同，两串具有相同的周期基元；所有公共除数字符串的长度必须同时整除两串长度，因此最长可能长度为两长度的最大公约数 g。取任一字符串长为 g 的前缀，恰能重复组成两串，故它既可行又最长。

边界

  • 字符串相同：返回自身。
  • 长度互质且兼容：答案是单个字符。
  • 首字符或内部节拍不同：拼接检查直接失败。
  • 题设保证输入非空。

复杂度

拼接比较需要 O(m+n) 时间与（按通常字符串实现）O(m+n) 临时空间；欧几里得算法为 O(log min(m,n))。结果切片空间不计输出时，其余为常数级。

四种语言

class Solution {
    public String gcdOfStrings(String str1, String str2) {
        if (!(str1 + str2).equals(str2 + str1)) return "";
        return str1.substring(0, gcd(str1.length(), str2.length()));
    }

    private int gcd(int a, int b) {
        while (b != 0) {
            int temp = a % b;
            a = b;
            b = temp;
        }
        return a;
    }
}

var gcdOfStrings = function(str1, str2) {
    if (str1 + str2 !== str2 + str1) return "";
    const gcd = (a, b) => {
        while (b !== 0) [a, b] = [b, a % b];
        return a;
    };
    return str1.slice(0, gcd(str1.length, str2.length));
};

替代方案

可从较短字符串的每个前缀开始枚举，并检查它能否铺满两串；直观但最坏会反复扫描，复杂度更高。也可逐字符寻找最小周期，再校验两串，代码通常更长。

面试追问

  • 为什么只检查长度最大公约数的前缀就够？
  • 不创建两个拼接字符串，如何用下标完成兼容性检查？
  • 若字符串允许 Unicode 组合字符，“字符长度”应如何定义？

常见错误

  • 只计算长度最大公约数，却漏掉拼接兼容性检查。
  • 仅验证候选是两串前缀，没有验证可完整重复。
  • 暴力枚举时忘记候选长度必须整除两串长度。
