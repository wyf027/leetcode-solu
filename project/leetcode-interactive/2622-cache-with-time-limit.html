01 · Problem

有时间限制的缓存

实现 TimeLimitedCache 类，用于保存整数键值对；每个键都带有以毫秒计的有效期。到期后，该键必须变为不可访问。

set(key, value, duration)

写入并从当前时刻重新计时。若同一键在调用时仍未过期则返回 true，否则返回 false；原值和有效期都被覆盖。

get(key)

键仍有效时返回其值；键不存在或已经过期时返回 -1。

count()

返回当前尚未过期的键的数量。

示例 1

EXPIRES
输入
actions = ["TimeLimitedCache", "set", "get", "count", "get"]
values = [[], [1, 42, 100], [1], [], [1]]
timeDelays = [0, 0, 50, 50, 150]

输出
[null, false, 42, 1, -1]

t=0 写入的 key=1 在 t=100 到期，所以 t=50 可读，t=150 不可读。

示例 2

OVERWRITE
输入
actions = ["TimeLimitedCache", "set", "set", "get", "get", "get", "count"]
values = [[], [1, 42, 50], [1, 50, 100], [1], [1], [1], []]
timeDelays = [0, 0, 40, 50, 120, 200, 250]

输出
[null, false, true, 50, 50, -1, 0]

t=40 覆盖旧值并重新计时，新的到期时刻为 t=140。

约束

0 ≤ key, value ≤ 10⁹
0 ≤ duration ≤ 1000
1 ≤ actions.length ≤ 100
actions.length === values.length
actions.length === timeDelays.length
0 ≤ timeDelays[i] ≤ 1450
actions[i] 为 TimeLimitedCache、set、get 或 count
首个操作一定是延迟为 0ms 的 TimeLimitedCache

04 · Spoiler gate

准备好看实现了吗？

先形成自己的数据结构选择，再展开完整题解。

Solution

一个 Map，两个时间机制

核心洞察

JavaScript 版本让 setTimeout 负责到点删除，因此 count() 可以直接读取 Map.size。每次覆盖都先取消旧定时器，避免旧回调误删新值。

其余三种语言是本地语义参考：用截止时间惰性判断，get 与 count 会清理已过期项，不依赖常驻事件循环。

完整过程

  1. 写入：判断旧项此刻是否有效，随后覆盖值与截止信息。
  2. 续期：JavaScript 清除旧定时器，并为新持续时间创建新定时器。
  3. 读取：有效则返回值；不存在或到期则返回 -1。
  4. 计数：返回全部有效键的数量。

正确性

set 后映射中保存最新值；旧删除任务已取消，新删除任务恰在新有效期结束时移除该键。因此任意时刻，映射中的键恰好是未过期键，get 与 count 的返回值符合定义。

边界

duration = 0 时键应立即失效；同键反复覆盖必须取消旧任务；值可以是 0，不能用真值判断键是否存在。

复杂度

JavaScript 的 set/get/count 平均均为 O(1)，空间 O(n)。惰性参考实现中 count 为 O(n)，其余平均 O(1)。

替代方案

可以只存 expiresAt 并在每次访问时惰性清理，省去每键一个定时器，但 count() 需要扫描；也可以维护最小堆批量回收，适合大量键，不过本题至多 100 次操作，没有必要引入这份复杂度。

JavaScript

官方可提交
var TimeLimitedCache = function() {
  this.cache = new Map();
};

TimeLimitedCache.prototype.set = function(key, value, duration) {
  const existed = this.cache.has(key);
  if (existed) clearTimeout(this.cache.get(key).timer);

  const timer = setTimeout(() => this.cache.delete(key), duration);
  this.cache.set(key, { value, timer });
  return existed;
};

TimeLimitedCache.prototype.get = function(key) {
  return this.cache.has(key) ? this.cache.get(key).value : -1;
};

TimeLimitedCache.prototype.count = function() {
  return this.cache.size;
};

Java

本地语义参考
import java.util.HashMap;
import java.util.Iterator;
import java.util.Map;

class TimeLimitedCache {
    private static class Entry {
        int value;
        long expiresAt;

        Entry(int value, long expiresAt) {
            this.value = value;
            this.expiresAt = expiresAt;
        }
    }

    private final Map<Integer, Entry> cache = new HashMap<>();

    public boolean set(int key, int value, int duration) {
        long now = System.currentTimeMillis();
        Entry old = cache.get(key);
        boolean existed = old != null && old.expiresAt > now;
        cache.put(key, new Entry(value, now + duration));
        return existed;
    }

    public int get(int key) {
        Entry entry = cache.get(key);
        if (entry == null || entry.expiresAt <= System.currentTimeMillis()) {
            cache.remove(key);
            return -1;
        }
        return entry.value;
    }

    public int count() {
        long now = System.currentTimeMillis();
        Iterator<Entry> it = cache.values().iterator();
        while (it.hasNext()) {
            if (it.next().expiresAt <= now) it.remove();
        }
        return cache.size();
    }
}

Python

本地语义参考
from time import monotonic


class TimeLimitedCache:
    def __init__(self):
        self.cache = {}

    def set(self, key: int, value: int, duration: int) -> bool:
        now = monotonic()
        old = self.cache.get(key)
        existed = old is not None and old[1] > now
        self.cache[key] = (value, now + duration / 1000)
        return existed

    def get(self, key: int) -> int:
        entry = self.cache.get(key)
        if entry is None or entry[1] <= monotonic():
            self.cache.pop(key, None)
            return -1
        return entry[0]

    def count(self) -> int:
        now = monotonic()
        self.cache = {
            key: entry
            for key, entry in self.cache.items()
            if entry[1] > now
        }
        return len(self.cache)

C++

本地语义参考
#include <chrono>
#include <unordered_map>

class TimeLimitedCache {
    using Clock = std::chrono::steady_clock;

    struct Entry {
        int value;
        Clock::time_point expiresAt;
    };

    std::unordered_map<int, Entry> cache;

public:
    bool set(int key, int value, int duration) {
        auto now = Clock::now();
        auto it = cache.find(key);
        bool existed = it != cache.end() && it->second.expiresAt > now;
        cache[key] = {value, now + std::chrono::milliseconds(duration)};
        return existed;
    }

    int get(int key) {
        auto it = cache.find(key);
        if (it == cache.end() || it->second.expiresAt <= Clock::now()) {
            if (it != cache.end()) cache.erase(it);
            return -1;
        }
        return it->second.value;
    }

    int count() {
        auto now = Clock::now();
        for (auto it = cache.begin(); it != cache.end(); ) {
            if (it->second.expiresAt <= now) it = cache.erase(it);
            else ++it;
        }
        return static_cast<int>(cache.size());
    }
};

  • 如何支持滑动过期，即每次读取都续期？
  • 多线程环境中如何保证覆盖与旧任务删除的原子性？
  • 系统时间回拨时，为什么单调时钟更安全？

常见错误

  • 覆盖时未取消旧定时器，旧回调提前删除新值。
  • 用 if (value) 判断存在性，错误处理值为 0 的键。
  • 把过期边界写成 < 而不是 <=。
  • 惰性方案的 count() 未清理过期项。
