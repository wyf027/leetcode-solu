兰顿蚂蚁

一只蚂蚁，一张无限棋盘，两条局部规则。让每一次转向、翻色与移动都在坐标纸上留下可追踪的证据。

  • 01 / TURN 按脚下颜色转向 白格右转，黑格左转
  • 02 / FLIP 翻转当前格颜色 白变黑，黑变白
  • 03 / MOVE 沿新方向前进一格 并扩张历史访问边界
→
ORIGIN 0,0 HEADING R INK 0
Problem brief

题意

无限网格初始全白，蚂蚁位于原点并朝右。执行前 K 次动作后，返回能覆盖蚂蚁走过的全部方格的最小矩形。

  • 白格：翻成黑色，顺时针右转 90°，再前进一步。
  • 黑格：翻成白色，逆时针左转 90°，再前进一步。
  • 输出以 "X" 表示黑格、"_" 表示白格，蚂蚁以 "L"、"U"、"R"、"D" 表示朝向。
边界： K <= 100000。输出矩形覆盖的是历史走过区域，不是只覆盖最终黑格。

Core insight

核心洞察：稀疏集合 + 历史边界

无限网格不能开二维数组，但最多只执行 K 步。用哈希集合只记录黑格；集合中存在代表黑色，不存在代表白色。每步读取当前格、翻转集合成员关系、更新方向，再移动。

裁剪范围必须覆盖所有走过的格子。因此每次移动后更新 minRow、maxRow、minCol、maxCol，不能在结尾只扫描黑格。

State machine

完整过程

  1. 1. 初始化坐标 (0, 0)、方向 R、空黑格集合与全零边界。
  2. 2. 若当前位置在集合中，删除并左转；否则加入并右转。
  3. 3. 按新方向移动一格，并把新坐标纳入历史边界。
  4. 4. 重复 K 次，逐行扫描历史矩形；蚂蚁字符优先覆盖格子颜色。

边界处理

  • K = 0：只返回 ["R"]。
  • 坐标可为负，键编码不能发生碰撞。
  • 蚂蚁落在黑格上时，输出方向字符而非 X。
  • 曾访问但最终为白色的边界格仍必须保留。

复杂度

时间
O(K + H × W)，模拟 K 步并生成 H×W 输出。
空间
O(B + H × W)，B 为最终黑格数，输出本身占 H×W。

替代方案取舍

动态扩张二维数组直观，却需要在越界时搬移或补行补列，坐标与输出偏移容易出错。哈希集合天然表达无限稀疏网格，是面试主线；平衡树也能做，但单步从均摊 O(1) 退化为 O(log K)。

面试追问

如果 K 极大，如何减少内存？

仍只存黑格；若只查询最终位置可不保留历史边界与输出，但本题必须构造矩形，输出尺寸是不可绕过的下界。

为什么方向编码适合模运算？

按 U、R、D、L 顺时针排列后，右转是 (d + 1) % 4，左转是 (d + 3) % 4。

能否只记录访问过的格子？

不能。颜色会反复翻转；需要记录“当前为黑”的奇数翻转格，同时边界单独记录所有历史访问。

常见错误

  • 先移动再翻色，打乱题面规定的状态机顺序。
  • 按旧方向移动，忘记转向立即生效。
  • 仅按最终黑格求边界，裁掉已经走过但后来变白的格子。
  • 拼接坐标时没有分隔符，导致 1,23 与 12,3 冲突。
  • 渲染时先写黑格，覆盖了蚂蚁方向字符。

import java.util.*;

class Solution {
    public List<String> printKMoves(int K) {
        Set<Long> black = new HashSet<>();
        int[] dr = {-1, 0, 1, 0};
        int[] dc = {0, 1, 0, -1};
        char[] direction = {'U', 'R', 'D', 'L'};
        int row = 0, col = 0, dir = 1;
        int minRow = 0, maxRow = 0, minCol = 0, maxCol = 0;

        for (int step = 0; step < K; step++) {
            long current = key(row, col);
            if (black.remove(current)) {
                dir = (dir + 3) % 4;
            } else {
                black.add(current);
                dir = (dir + 1) % 4;
            }
            row += dr[dir];
            col += dc[dir];
            minRow = Math.min(minRow, row);
            maxRow = Math.max(maxRow, row);
            minCol = Math.min(minCol, col);
            maxCol = Math.max(maxCol, col);
        }

        List<String> answer = new ArrayList<>();
        for (int r = minRow; r <= maxRow; r++) {
            StringBuilder line = new StringBuilder();
            for (int c = minCol; c <= maxCol; c++) {
                if (r == row && c == col) {
                    line.append(direction[dir]);
                } else {
                    line.append(black.contains(key(r, c)) ? 'X' : '_');
                }
            }
            answer.add(line.toString());
        }
        return answer;
    }

    private long key(int row, int col) {
        return ((long) row << 32) ^ (col & 0xffffffffL);
    }
}

    const dc = [0, 1, 0, -1];

    let row = 0;
    let col = 0;

            black.delete(current);
            dir = (dir + 3) % 4;
        } else {
            black.add(current);
            dir = (dir + 1) % 4;

        row += dr[dir];
        col += dc[dir];
        minRow = Math.min(minRow, row);
        maxRow = Math.max(maxRow, row);
        minCol = Math.min(minCol, col);
        maxCol = Math.max(maxCol, col);

    for (let r = minRow; r <= maxRow; r++) {
        let line = "";

                line += direction[dir];

from typing import List


class Solution:
    def printKMoves(self, K: int) -> List[str]:
        black = set()
        dr = (-1, 0, 1, 0)
        dc = (0, 1, 0, -1)
        direction = "URDL"
        row = col = 0
        current_dir = 1
        min_row = max_row = min_col = max_col = 0

        for _ in range(K):
            current = (row, col)
            if current in black:
                black.remove(current)
                current_dir = (current_dir + 3) % 4
            else:
                black.add(current)
                current_dir = (current_dir + 1) % 4
            row += dr[current_dir]
            col += dc[current_dir]
            min_row = min(min_row, row)
            max_row = max(max_row, row)
            min_col = min(min_col, col)
            max_col = max(max_col, col)

        answer = []
        for r in range(min_row, max_row + 1):
            line = []
            for c in range(min_col, max_col + 1):
                if (r, c) == (row, col):
                    line.append(direction[current_dir])
                else:
                    line.append("X" if (r, c) in black else "_")
            answer.append("".join(line))
        return answer
class Solution {
public:
    vector<string> printKMoves(int K) {
        unordered_set<uint64_t> black;
        const int dr[4] = {-1, 0, 1, 0};
        const int dc[4] = {0, 1, 0, -1};
        const char direction[4] = {'U', 'R', 'D', 'L'};
        int row = 0, col = 0, dir = 1;
        int minRow = 0, maxRow = 0, minCol = 0, maxCol = 0;

        for (int step = 0; step < K; ++step) {
            uint64_t current = key(row, col);
            auto it = black.find(current);
            if (it != black.end()) {
                black.erase(it);
                dir = (dir + 3) % 4;
            } else {
                black.insert(current);
                dir = (dir + 1) % 4;
            }
            row += dr[dir];
            col += dc[dir];
            minRow = min(minRow, row);
            maxRow = max(maxRow, row);
            minCol = min(minCol, col);
            maxCol = max(maxCol, col);
        }

        vector<string> answer;
        for (int r = minRow; r <= maxRow; ++r) {
            string line;
            for (int c = minCol; c <= maxCol; ++c) {
                if (r == row && c == col) {
                    line.push_back(direction[dir]);
                } else {
                    line.push_back(black.count(key(r, c)) ? 'X' : '_');
                }
            }
            answer.push_back(line);
        }
        return answer;
    }

private:
    uint64_t key(int row, int col) {
        return (uint64_t(uint32_t(row)) << 32) | uint32_t(col);
    }
};
