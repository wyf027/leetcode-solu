叶子相似的树

Leaf-Similar Trees

两棵树可以长得完全不同，却拥有同一条“叶脉”。你的任务不是比较整棵树，而是判断它们从左到右抵达的叶子是否一致。

难度：简单非付费题函数：leafSimilar(root1, root2)
Problem

题目说明

一棵二叉树的所有叶子结点，按照从左到右的顺序排列，会形成它的叶值序列。如果两棵二叉树的叶值序列完全相同，就称它们为“叶相似”。

给定根结点 root1 与 root2，仅当两棵树叶相似时返回 true，否则返回 false。

叶子结点：没有左孩子且没有右孩子的结点。左右顺序不可交换。

约束

  • 每棵树的结点数在 [1, 200] 内。
  • 每个结点的值在 [0, 200] 内。
  • root1、root2 均为二叉树根结点。
  • 返回值类型为 boolean。
示例 1 
输入：root1 = [3,5,1,6,2,9,8,null,null,7,4]
      root2 = [3,5,1,6,7,4,2,null,null,null,null,null,null,9,8]
输出：true
示例 2 
输入：root1 = [1,2,3]
      root2 = [1,3,2]
输出：false

Solution

把形状丢掉，只留下叶子的顺序

核心洞察

判断标准只与两棵树从左到右的叶值序列有关。分别以“左子树优先”的深度优先搜索收集叶子，然后比较两个数组即可；树的内部结构无需相同。

完整过程

  1. 定义收集函数。 若当前结点为空则返回；若左右孩子都为空，将值加入序列。
  2. 保持左右顺序。 先递归左子树，再递归右子树，得到从左到右的叶值。
  3. 独立采集。 对 root1、root2 分别得到两个序列。
  4. 整体比较。 长度和对应位置的值全部相同才返回 true。

正确性证明

引理：对任意二叉树，按“当前结点若为叶子则记录，否则先左后右递归”的 DFS，所得序列恰为该树从左到右的叶值序列。

证明：任意结点的左子树中所有叶子在位置上都先于右子树中的所有叶子。DFS 先完整访问左子树，再访问右子树，并且只记录叶子，因此既不遗漏也不重复，且顺序正好从左到右。

定理：算法返回 true 当且仅当两棵树叶相似。由引理，两个数组分别等于两棵树的叶值序列；数组相等恰好等价于叶值序列相同，故结论成立。

复杂度

时间：O(n + m)，每个结点访问一次。

空间：O(n + m) 保存叶序列；递归栈额外为 O(h1 + h2)。

边界情况

  • 单结点树：根本身就是叶子。
  • 叶子数量不同，可立即判为不同。
  • 值重复时仍需逐位置比较。
  • 极度倾斜的树要注意递归深度。

替代方案

可用两个“下一个叶子”迭代器同步比较，发现首个不同便结束，避免保存完整序列；实现更复杂，但辅助空间可降至两棵树的栈高度。

/** Definition for a binary tree node.
 * public class TreeNode {
 *   int val; TreeNode left; TreeNode right;
 * }
 */
class Solution {
    public boolean leafSimilar(TreeNode root1, TreeNode root2) {
        List<Integer> first = new ArrayList<>();
        List<Integer> second = new ArrayList<>();
        collect(root1, first);
        collect(root2, second);
        return first.equals(second);
    }

    private void collect(TreeNode node, List<Integer> leaves) {
        if (node == null) return;
        if (node.left == null && node.right == null) {
            leaves.add(node.val);
            return;
        }
        collect(node.left, leaves);
        collect(node.right, leaves);
    }
}
/**
 * @param {TreeNode} root1
 * @param {TreeNode} root2
 * @return {boolean}
 */
var leafSimilar = function(root1, root2) {
    const collect = (node, leaves) => {
        if (node === null) return;
        if (node.left === null && node.right === null) {
            leaves.push(node.val);
            return;
        }
        collect(node.left, leaves);
        collect(node.right, leaves);
    };

    const first = [];
    const second = [];
    collect(root1, first);
    collect(root2, second);
    return first.length === second.length &&
        first.every((value, index) => value === second[index]);
};

        self,

                return

面试追问

  • 能否不保存两个完整数组？ 可以，为每棵树维护显式栈，每次取出下一个叶子同步比较。
  • 为什么必须左子树优先？ 题目定义的是空间上的从左到右顺序；交换访问顺序会生成反向或错乱序列。
  • 如果树非常深？ 使用迭代 DFS，避免语言递归栈溢出。
  • 能否提前结束？ 迭代器方案能在首个不同叶子处结束；收集数组方案通常先遍历完。

常见错误

  • 把“只有一个孩子”的结点误判成叶子。
  • 比较集合或排序后比较，丢失顺序与重复次数。
  • 递归时先右后左，得到错误次序。
  • 用字符串拼接但没有分隔符，如 [1, 23] 与 [12, 3] 发生歧义。
