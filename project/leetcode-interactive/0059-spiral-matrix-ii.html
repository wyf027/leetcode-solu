01 / Brief

题意

给定一个正整数 n，生成一个 n × n 方阵。将整数 1 到 n² 按顺时针螺旋顺序写入矩阵，并返回这个矩阵。

官方样例 1

输入n = 3
输出 [[1,2,3],[8,9,4],[7,6,5]]

官方样例 2

输入n = 1
输出[[1]]
约束：1 <= n <= 20

04 / Make-ready notes

题解

Core insight

核心洞察：填满一条边，再收紧夹具

用 top、bottom、left、right 表示尚未填充区域的四条边界。每轮依次填上边、右边、下边、左边；每完成一条边，立刻把对应边界向内移动。数字本身只递增，不需要额外记录访问状态。

Invariant

循环不变量

每次进入循环时，边界外的格子已经按顺时针顺序写好；边界内的格子仍为空；下一待写数字恰好等于已写格子数加一。四段填充保持这个不变量，直至边界交错。

Full process

完整过程

  1. 01

    从 left 到 right 填写第 top 行，然后 top++。

  2. 02

    从 top 到 bottom 填写第 right 列，然后 right--。

  3. 03

    若仍有行，从 right 到 left 填写第 bottom 行，然后 bottom--。

  4. 04

    若仍有列，从 bottom 到 top 填写第 left 列，然后 left++。

Boundaries

边界情况

  • n = 1：第一段就填完唯一格子。
  • 奇数阶：最后剩一个中心格。
  • 偶数阶：最后剩一个 2 × 2 环。
  • 写下边和左边前必须重新确认边界仍有效，避免覆盖。

Complexity

复杂度

时间：O(n²)，每个格子恰好写一次。

额外空间：O(1)，不计必须返回的 n × n 矩阵。

Alternatives

替代方案取舍

也可用方向数组与“越界或下一格已写”来转向，代码统一但依赖矩阵中的 0 充当未访问标记。面试更推荐四边界：状态含义直接，也更容易证明每格只访问一次。

Interview follow-ups

面试追问

为什么下边和左边需要条件判断？

上边、右边写完后，剩余区域可能已经没有行或列。若仍无条件反向写入，会覆盖刚填好的单行或单列。

如何改成逆时针或指定起点？

调整四段遍历顺序和每段的索引方向即可；关键仍是每完成一条边后收缩对应边界。

能否做到比 O(n²) 更快？

不能。输出本身包含 n² 个元素，任何正确算法至少要写入这些格子，因此下界就是 Ω(n²)。

Misprints

常见错误

  • 边界移动时机错误：完成一整条边后再移动，而不是每写一个元素就移动。
  • 遗漏二次判断：上边和右边会改变可用区域，反向遍历前要重新检查。
  • 数字重复或跳号：统一使用 value++，每次赋值后只递增一次。
  • 把结果空间算作额外空间：面试中应明确说明返回矩阵不计入辅助空间。

class Solution {
    public int[][] generateMatrix(int n) {
        int[][] matrix = new int[n][n];
        int top = 0, bottom = n - 1;
        int left = 0, right = n - 1;
        int value = 1;

        while (top <= bottom && left <= right) {
            for (int col = left; col <= right; col++) {
                matrix[top][col] = value++;
            }
            top++;

            for (int row = top; row <= bottom; row++) {
                matrix[row][right] = value++;
            }
            right--;

            if (top <= bottom) {
                for (int col = right; col >= left; col--) {
                    matrix[bottom][col] = value++;
                }
                bottom--;
            }

            if (left <= right) {
                for (int row = bottom; row >= top; row--) {
                    matrix[row][left] = value++;
                }
                left++;
            }
        }

        return matrix;
    }
}

from typing import List


class Solution:
    def generateMatrix(self, n: int) -> List[List[int]]:
        matrix = [[0] * n for _ in range(n)]
        top, bottom = 0, n - 1
        left, right = 0, n - 1
        value = 1

        while top <= bottom and left <= right:
            for col in range(left, right + 1):
                matrix[top][col] = value
                value += 1
            top += 1

            for row in range(top, bottom + 1):
                matrix[row][right] = value
                value += 1
            right -= 1

            if top <= bottom:
                for col in range(right, left - 1, -1):
                    matrix[bottom][col] = value
                    value += 1
                bottom -= 1

            if left <= right:
                for row in range(bottom, top - 1, -1):
                    matrix[row][left] = value
                    value += 1
                left += 1

        return matrix
