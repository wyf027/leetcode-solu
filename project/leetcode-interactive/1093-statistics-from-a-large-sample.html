大样本统计Statistics from a Large Sample

不用展开十亿个样本。沿着 256 个频数桶走一遍，就能从压缩分布中读出五个统计量。

题目

一个只含 0…255 整数的大样本被压缩成长度为 256 的数组 count，其中 count[k] 表示数值 k 出现的次数。

计算并按浮点数组 [minimum, maximum, mean, median, mode] 返回最小值、最大值、均值、中位数和众数。样本量为奇数时，中位数是排序后的中间元素；为偶数时，是中间两个元素的平均值。众数保证唯一，误差不超过 10⁻⁵ 即可。

函数签名

sampleStats(count: integer[256]) → double[5]

约束

  • count.length == 256
  • 0 <= count[i] <= 10⁹
  • 1 <= sum(count) <= 10⁹
  • 样本的众数唯一

关键暗示：频数数组已经按“值”排序。累计频数跨过目标秩时，当前下标就是对应的顺序统计量。

官方示例

示例 1
展开后为 [1,2,2,2,3,3,3,3]；均值为 19/8，偶数样本的两个中间值是 2 和 3。

题解：一次频数扫描
统计量是可累积的
总数累加 count[i]，总和累加 i × count[i]。
顺序来自下标
第一个和最后一个非零桶给出极值；最大频数桶给出众数。
中位数是两个秩
统一找第 (n+1)/2 与第 (n+2)/2 个元素，再取平均。

        
完整过程
  1. 遍历 0 到 255，累积样本量 n 与加权和 sum。
  2. 第一次遇到非零桶记录最小值，每次非零都更新最大值；频数更大时更新众数。
  3. 再次累计频数，分别找到累计值首次达到两个中位秩时的下标。
  4. 用 sum / n 求均值，两中位值的平均数即中位数。

        
正确性证明
对任意下标 i，累计频数等于样本中所有不大于 i 的元素数量。因此累计频数第一次达到秩 k 时，排序后第 k 个元素必为 i。
首末非零下标分别是样本可取的最小与最大值；i × count[i] 汇总了值 i 对总和的全部贡献；最大频数下标按定义是唯一众数。故返回的五项均正确。

        
边界与复杂度
  • 只有一个元素：两个中位秩相同。
  • 只有一个非零桶：五个统计量都等于该下标。
  • 偶数样本：两个中位值可能落在不同桶。
  • 加权和在 Java/C++ 中必须用 64 位整数。
时间：O(256)（一般写作 O(K)）
额外空间：O(1)

        
替代方案
可以写一个 kth(k) 辅助函数，扫描频数并返回第 k 个元素，分别调用两次求中位数。表达直观，但会多做一次扫描。
真正展开样本再排序需要最多十亿个元素，不现实；二分值域也能找秩，但固定 256 桶下线性扫描更简单。

        
面试追问
  • 若值域不是 0…255，而是稀疏且很大？可用有序映射存频数。
  • 若数据流持续到达？均值、极值、众数可在线维护，中位数可用双堆或树状结构。
  • 为什么两个中位秩公式能统一奇偶？奇数时两者相同，偶数时恰为中间两个位置。

        
四语言完整代码

          
class Solution {
    public double[] sampleStats(int[] count) {
        long total = 0, sum = 0;
        int minimum = -1, maximum = -1, mode = 0;
        for (int i = 0; i < 256; i++) {
            if (count[i] > 0) {
                if (minimum == -1) minimum = i;
                maximum = i;
                total += count[i];
                sum += (long) i * count[i];
                if (count[i] > count[mode]) mode = i;
            }
        }
        long leftRank = (total + 1) / 2;
        long rightRank = (total + 2) / 2;
        long prefix = 0;
        int left = -1, right = -1;
        for (int i = 0; i < 256; i++) {
            prefix += count[i];
            if (left == -1 && prefix >= leftRank) left = i;
            if (prefix >= rightRank) { right = i; break; }
        }
        return new double[]{minimum, maximum, (double) sum / total,
                            (left + right) / 2.0, mode};
    }
}

                maximum = value

常见错误
  • 把 count[i] 当成样本值，而不是频数。
  • 用 32 位整数保存 i × count[i] 的累加和。
  • 偶数样本只取第 n/2 个元素，忘记与第 n/2+1 个求平均。
  • 用 > 判断是否跨过中位秩；目标是“累计频数大于等于秩”。
  • 真的构造或排序原始大样本，造成内存爆炸。
