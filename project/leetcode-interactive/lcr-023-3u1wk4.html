LCR 023 · EASY · 链表 / 双指针

相交链表

两条单链表在某个节点开始共享尾部。无需额外集合，也不必预先知道长度：让两个指针各自走完两条路。

关键不变量

len(A) + len(B)
两指针总路程相同

题目要求

给你两个单链表的头节点 headA 和 headB，找到并返回它们相交的起始节点；若不相交，返回 null。

“相交”指的是节点对象相同，不是节点值相等。题目保证链表结构无环。

示意

A: 4 → 1 ↘ 8 → 4 → 5
B: 5 → 6 → 1 ↗

两条路径在值为 8 的同一个节点汇合。

当前动作

走到空节点并不结束：指针切换到另一条链的头部。因此两人都会额外补上对方独有的前缀。

为什么一定同步？

A 的路程是 A 独有前缀 + 公共尾部 + B 独有前缀 + 公共尾部；B 的路程正好交换前两段，合计完全相同。若有相交节点，它们会在那里相遇；若没有，两者会同时为 null。

01 / 初始化

各从自己的头部出发

指针 a 指向 headA，b 指向 headB。不要比较 value，要比较节点引用。

02 / 走到尾部

为空时换到另一头

a 到尾部后改指向 headB；b 到尾部后改指向 headA。二者路径长度被拉平。

03 / 退出循环

相同引用即答案

当 a === b 时停止：可能是公共节点，也可能是两个 null。无需额外特判。

复杂度

时间：O(m + n)

每个指针最多走两条链各一次；m、n 分别为两条链的长度。

空间：O(1)

只维护两个指针。相比用 Set 记录节点的解法，空间更优。

四语言提交版

循环条件直接比较两个节点引用。

  1. 用两个临时指针保存当前节点，不修改输入链表。
  2. 不相等时同步前进；遇到 null 就转去对方的 head。
  3. 两者相等时返回该引用，天然覆盖不相交场景。

提交前检查

  • ✓ 相交发生在中间节点
  • ✓ 两条链完全相同
  • ✓ 一条链为空
  • ✓ 不相交时返回 null
