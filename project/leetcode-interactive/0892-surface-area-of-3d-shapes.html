三维形体的表面积

不要真的搭出所有小方块。沿网格逐座检查塔柱：上下两面固定贡献，四周只计算高出相邻塔柱的部分。

题号 892难度：简单时间 O(n²)空间 O(1)
Problem

从高度网格到立体外壳

给定一个 n × n 整数网格。grid[i][j] = v 表示在位置 (i,j) 上竖直叠放了 v 个单位正方体；直接相邻的方块会粘合。返回最终所有形体的总表面积。

注意：底面也算表面积；粘合在一起的两个面不再暴露。

示例 1
输入：grid = [[1,2],[3,4]]
输出：34
示例 2
输入：grid = [[1,1,1],
              [1,0,1],
              [1,1,1]]
输出：32
示例 3
输入：grid = [[2,2,2],
              [2,1,2],
              [2,2,2]]
输出：46

约束

  • n == grid.length == grid[i].length
  • 1 <= n <= 50
  • 0 <= grid[i][j] <= 50
  • 返回值类型：integer

Solution

把立体问题投影回二维

核心洞察

高度为 h 的非空塔固定贡献顶部和底部 2 个面。朝某方向若邻居高度为 q，只有超出邻居的部分可见，贡献 max(h - q, 0)。把网格之外看成高度 0，四个方向可用同一条公式。

01

选择一塔

读取当前位置高度 h；若 h=0，这格贡献 0。

02

数上下表面

非空塔先加 2，分别对应顶部与底部。

03

比较四邻

累加四个方向的 max(h-neighbor,0)。

正确性证明

对任意非空塔，其顶部与底部各恰有一个暴露面，算法加入 2。对塔的任一侧面方向，邻塔会遮挡从地面起的 min(h,q) 个单位面，因此恰有 h-min(h,q)=max(h-q,0) 个面暴露，算法加入的数量完全一致。

每个外露面只属于一座塔及一个确定方向，所以不会重复；所有可能方向（上、下、四侧）均被枚举，所以不会遗漏。对全部格求和即为总表面积。

边界与复杂度

  • 空格 h=0 不贡献顶部或底部。
  • 网格边界外按高度 0 处理，自然计入外侧面。
  • 凹槽不会特殊处理：高度差已经精确描述暴露部分。
  • 时间复杂度 O(n²)，每格只看 4 个方向。
  • 额外空间复杂度 O(1)，不计输入。

四语言完整实现

class Solution {
    public int surfaceArea(int[][] grid) {
        int n = grid.length;
        int area = 0;
        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        for (int row = 0; row < n; row++) {
            for (int col = 0; col < n; col++) {
                int height = grid[row][col];
                if (height == 0) continue;
                area += 2;
                for (int[] direction : directions) {
                    int nr = row + direction[0];
                    int nc = col + direction[1];
                    int neighbor = (nr >= 0 && nr < n && nc >= 0 && nc < n)
                            ? grid[nr][nc] : 0;
                    area += Math.max(height - neighbor, 0);
                }
            }
        }
        return area;
    }
}

替代方案

也可把每座高度 h 的塔先看成贡献 4h+2，然后对每对相邻塔减去 2×min(a,b)。它同样是 O(n²)，但“四方向高度差”更统一，也更容易处理边界。

面试追问

  • 若网格不是方阵，循环和边界判断如何调整？
  • 若只加入一座塔，怎样在 O(1) 更新面积？
  • 如何扩展到可动态修改高度的查询？

常见错误

  • 把 h=0 的空格也加上顶部和底部。
  • 相邻塔同时减重合面时只减一次。
  • 忘记边缘外侧面，或忘记底面。
  • 使用绝对高度差，导致矮塔一侧重复计数。

记忆钩子

“上下二，四边差。”
非空塔先加 2；四个方向只取正高度差。网格之外就是 0。
