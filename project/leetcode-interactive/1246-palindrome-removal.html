删除回文
子数组

把一个数组当作可不断收拢的纸带：每次剪掉一段回文，左右残片随即拼接。你需要求出清空整条纸带的最少剪切次数。

HARD付费题数组动态规划
01 / Problem

题目要求

给定整数数组 arr。一次操作可以选择当前数组中任意一个连续且正读、反读相同的子数组，将它删除；删除后两侧剩余元素会立即连接。返回删除全部元素所需的最少操作次数。

函数签名
minimumMoves(arr: integer[]) → integer
1

两个不同元素

输入：minimumMoves(arr = [1, 2])
输出：2

没有长度为 2 的回文段，只能分别删除 [1] 和 [2]。

2

删除后形成新回文

输入：minimumMoves(arr = [1, 3, 4, 1, 5])
输出：3

可先删 [4]，此时形成 [1,3,1]；再删这段回文，最后删 [5]。

约束

  • 1 ≤ arr.length ≤ 100
  • 1 ≤ arr[i] ≤ 20

真正的难点

删除会改变相邻关系。原本不连续的两个相等元素，可能在中间部分消失后合并进同一次回文删除中。

Core insight

区间 DP：让相等端点共享一次删除

状态

dp[i][j] 表示清空原数组闭区间 arr[i..j] 的最少操作数。空区间贡献 0，单元素区间为 1。

关键合并

若 arr[i] == arr[k]，先清掉两者之间的元素，arr[i] 就能搭上删除 arr[k] 的那一次操作，不必独立删除。

完整转移过程

  1. 先独立删除左端。总能先删 arr[i]，所以基线是 1 + dp[i+1][j]。
  2. 处理紧邻的相同元素。若 arr[i] == arr[i+1]，两者可一次删掉，候选值为 1 + dp[i+2][j]。
  3. 寻找更远的相同元素。对每个 k ≥ i+2 且 arr[i] == arr[k]，先清空 (i,k)；左端可并入删除第 k 项的操作，再清空右侧。
  4. 按依赖顺序填表。让 i 从右向左、j 从左向右枚举，所需的更短区间都已计算。
dp[i][j] = 1 + dp[i+1][j] if arr[i] == arr[i+1]: dp[i][j] = min(dp[i][j], 1 + dp[i+2][j]) for k = i+2 ... j, when arr[i] == arr[k]: dp[i][j] = min(dp[i][j], dp[i+1][k-1] + dp[k+1][j])

正确性证明

归纳基础：长度为 1 的区间只需一次删除，状态正确。

归纳假设：所有长度小于当前区间的状态均为最优。

归纳步骤：考虑清空 [i,j] 的最优方案中 arr[i] 被删除的那次操作。若它单独删除，代价由基线覆盖；若它与紧邻的相同元素一起删除，由第二种转移覆盖；若它与某个更远的相同元素 arr[k] 同次删除，则中间区间必须先被清空，之后 arr[i] 可并入删除 arr[k] 的操作，代价恰由第三种转移覆盖。转移枚举了所有可能，而各子区间按归纳假设最优，因此取最小值得到全局最优。

时间复杂度

O(n³)：共有 O(n²) 个区间，每个区间最多枚举 O(n) 个匹配位置。

空间复杂度

O(n²)：保存所有区间状态。

边界处理

访问空的右侧区间时按 0 处理；相邻相等元素必须单独特判为一次删除。

四语言完整实现

JavaLeetCode 提交格式
class Solution {
    public int minimumMoves(int[] arr) {
        int n = arr.length;
        int[][] dp = new int[n][n];

        for (int i = n - 1; i >= 0; i--) {
            dp[i][i] = 1;
            for (int j = i + 1; j < n; j++) {
                dp[i][j] = 1 + dp[i + 1][j];

                if (arr[i] == arr[i + 1]) {
                    int right = i + 2 <= j ? dp[i + 2][j] : 0;
                    dp[i][j] = Math.min(dp[i][j], 1 + right);
                }

                for (int k = i + 2; k <= j; k++) {
                    if (arr[i] == arr[k]) {
                        int right = k + 1 <= j ? dp[k + 1][j] : 0;
                        dp[i][j] = Math.min(
                            dp[i][j],
                            dp[i + 1][k - 1] + right
                        );
                    }
                }
            }
        }
        return dp[0][n - 1];
    }
}

var minimumMoves = function(arr) {
    const n = arr.length;
    const dp = Array.from(
        { length: n },
        () => Array(n).fill(0)
    );

    for (let i = n - 1; i >= 0; i--) {
        dp[i][i] = 1;
        for (let j = i + 1; j < n; j++) {
            dp[i][j] = 1 + dp[i + 1][j];

            if (arr[i] === arr[i + 1]) {
                const right = i + 2 <= j ? dp[i + 2][j] : 0;
                dp[i][j] = Math.min(dp[i][j], 1 + right);
            }

            for (let k = i + 2; k <= j; k++) {
                if (arr[i] === arr[k]) {
                    const right = k + 1 <= j ? dp[k + 1][j] : 0;
                    dp[i][j] = Math.min(
                        dp[i][j],
                        dp[i + 1][k - 1] + right
                    );
                }
            }
        }
    }
    return dp[0][n - 1];
};
PythonLeetCode 提交格式
from typing import List


class Solution:
    def minimumMoves(self, arr: List[int]) -> int:
        n = len(arr)
        dp = [[0] * n for _ in range(n)]

        for i in range(n - 1, -1, -1):
            dp[i][i] = 1
            for j in range(i + 1, n):
                dp[i][j] = 1 + dp[i + 1][j]

                if arr[i] == arr[i + 1]:
                    right = dp[i + 2][j] if i + 2 <= j else 0
                    dp[i][j] = min(dp[i][j], 1 + right)

                for k in range(i + 2, j + 1):
                    if arr[i] == arr[k]:
                        right = dp[k + 1][j] if k + 1 <= j else 0
                        dp[i][j] = min(
                            dp[i][j],
                            dp[i + 1][k - 1] + right,
                        )

        return dp[0][n - 1]

替代方案

按分割点做区间 DP：可以先枚举最后一次组合或所有切分点，再额外处理相等端点。思路等价，但边界更容易写错。

记忆化搜索：状态和复杂度相同，代码更贴近递归定义；最坏情况下递归深度为 O(n)。

面试追问

  • 为什么删除会让普通的一维 DP 失效？
  • 怎样从“左端元素在哪次被删除”推导完整转移？
  • 若要求输出具体删除方案，需要为每个状态额外记录什么？
  • 值域只有 20，能否实际减少匹配位置的枚举？

常见错误

  • 误把“回文子数组”当成原数组中的固定连续片段，忽略删除后的重新拼接。
  • 对相邻相等元素套用空区间公式得到 0；它们仍然需要一次操作。
  • 只在当前区间两端相等时合并，漏掉左端与内部某个位置合并的情况。
  • 填表顺序不满足依赖关系，读取到尚未计算的状态。
