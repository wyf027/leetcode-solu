查找两棵二叉搜索树之和

Two Sum BSTs — 在两棵彼此独立的二叉搜索树中，各选一个节点，让它们的值恰好组成目标和。

题号 1214MEDIUM付费题栈 · 树 · 双指针

Problem

先把问题说清楚

本页依据官方元数据中的题名、签名、样例与提示进行简明转述，不复刻付费题面。

给定两棵二叉搜索树 root1、root2 和整数 target。判断能否从第一棵树与第二棵树中各取一个节点，使两个节点值之和等于 target。

存在这样的组合时返回 true，否则返回 false。两个节点必须分别来自不同的树。

twoSumBSTs(root1, root2, target)root1: TreeNoderoot2: TreeNodetarget: integerreturn: boolean
读题锚点
  • 来源约束每棵树各取一个节点
  • 结构保证输入的两棵树都是 BST
  • 目标只需判断是否存在，无需返回节点

示例 1 · 找得到

输入root1 = [2,1,4], root2 = [1,0,3], target = 5
输出true

例如从第一棵树取 2，从第二棵树取 3，二者之和为 5。

示例 2 · 找不到

输入root1 = [0,-10,10], root2 = [5,1,7,0,2], target = 18
输出false

跨两棵树检查所有可能方向后，没有任何一对节点值之和等于 18。

约束

  • 每棵树的节点数均在 [1, 5000] 范围内。
  • -10⁹ ≤ Node.val, target ≤ 10⁹。
  • root1 与 root2 均为合法二叉搜索树。

Solution

把两棵 BST 当作两条有序流

不必把两棵树完整摊平成数组：用两个栈模拟升序与降序迭代器即可。

01

核心洞察

BST 的中序遍历是升序。让 A 产生当前最小值，让 B 产生当前最大值，就能像经典“两数之和”的双指针一样，根据当前和只移动一侧。

  1. 给 A 建立升序迭代器：持续压入左链，弹出栈顶后再压入其右子树的左链。
  2. 给 B 建立降序迭代器：对称地持续压入右链，弹出后再压入其左子树的右链。
  3. 若两端当前值之和等于目标，立即返回 true。
  4. 和偏小则推进 A；和偏大则推进 B。任一迭代器耗尽时返回 false。

正确性证明

  • 有序性：A 迭代器按非递减次序产生第一棵树的值；B 迭代器按非递增次序产生第二棵树的值。
  • 安全消去：若 a + b < target，在当前最大值 b 下，当前 a 不可能与 B 中任何未访问值组成目标和，因此可安全丢弃 a。和偏大时对 b 的论证对称。
  • 完备性：每一步要么找到答案，要么只消去不可能参与答案的一端；所以若答案存在，必会到达该组合。若一端耗尽仍未命中，则不存在可行组合。

复杂度与边界

时间O(n₁+n₂)每个节点至多进出栈一次
空间O(h₁+h₂)只保存两棵树的搜索路径
  • 单节点树与负数无需特殊分支。
  • 节点值可重复；两节点来自不同树，因此相等值也可配对。
  • 求和时在 Java / C++ 中使用 64 位整数，避免极端值扩展时溢出。
  • 任意一棵树为空时直接返回 false，实现更健壮。

class Solution {
    private static class Iterator {
        private final java.util.Deque<TreeNode> stack = new java.util.ArrayDeque<>();
        private final boolean ascending;

        Iterator(TreeNode root, boolean ascending) {
            this.ascending = ascending;
            pushPath(root);
        }

        private void pushPath(TreeNode node) {
            while (node != null) {
                stack.push(node);
                node = ascending ? node.left : node.right;
            }
        }

        boolean hasNext() {
            return !stack.isEmpty();
        }

        int next() {
            TreeNode node = stack.pop();
            pushPath(ascending ? node.right : node.left);
            return node.val;
        }
    }

    public boolean twoSumBSTs(TreeNode root1, TreeNode root2, int target) {
        if (root1 == null || root2 == null) return false;
        Iterator left = new Iterator(root1, true);
        Iterator right = new Iterator(root2, false);
        int a = left.next();
        int b = right.next();

        while (true) {
            long sum = (long) a + b;
            if (sum == target) return true;
            if (sum < target) {
                if (!left.hasNext()) return false;
                a = left.next();
            } else {
                if (!right.hasNext()) return false;
                b = right.next();
            }
        }
    }
}

                node = self.stack.pop()

class Solution {
    class BSTIterator {
        std::stack<TreeNode*> nodes;
        bool ascending;

        void pushPath(TreeNode* node) {
            while (node != nullptr) {
                nodes.push(node);
                node = ascending ? node->left : node->right;
            }
        }

    public:
        BSTIterator(TreeNode* root, bool ascending)
            : ascending(ascending) {
            pushPath(root);
        }

        bool hasNext() const {
            return !nodes.empty();
        }

        int next() {
            TreeNode* node = nodes.top();
            nodes.pop();
            pushPath(ascending ? node->right : node->left);
            return node->val;
        }
    };

public:
    bool twoSumBSTs(TreeNode* root1, TreeNode* root2, int target) {
        if (root1 == nullptr || root2 == nullptr) return false;
        BSTIterator left(root1, true);
        BSTIterator right(root2, false);
        int a = left.next();
        int b = right.next();

            long long sum = static_cast<long long>(a) + b;
            if (sum == target) return true;
            if (sum < target) {
                if (!left.hasNext()) return false;
                a = left.next();
            } else {
                if (!right.hasNext()) return false;
                b = right.next();
            }
        }
    }

替代方案

方案 A：两次中序遍历 + 双指针。先得到两个有序数组，再左右逼近。时间同为 O(n₁+n₂)，空间变为 O(n₁+n₂)；最直观，适合先讲清楚。

方案 B：遍历 A + 搜索 B。对 A 的每个值，在 B 中查找 target - value。平均平衡树上较快，但最坏退化为 O(n₁n₂)。

方案 C：哈希集合。记录一棵树全部值，再遍历另一棵树查补数；时间线性，额外空间线性。

常见错误

  • 把问题误解成在同一棵树中取两个节点。
  • 两个迭代器都按升序，导致无法依据和的大小单调移动。
  • 弹出节点后忘记把对侧子树的新路径压栈。
  • 先完整展开数组，却仍声称空间复杂度是 O(h)。
  • 未处理空树，初始化时直接对空栈执行 pop。
