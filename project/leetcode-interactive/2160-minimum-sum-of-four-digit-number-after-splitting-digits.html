四位数字的最小和

Minimum Sum of Four Digit Number After Splitting Digits

四枚数字，两组新数。你会怎样重新安排它们？

01 / 题目

给定一个恰好四位的正整数 num，将它的四个数位重新分成两个整数 new1 和 new2。每个数位必须恰好使用一次；重复出现的数字按各自次数使用。每组至少使用一个数位，可以重新排序，也允许前导零。返回两数之和的最小值。

例如 2932 中有两个 2、一个 9、一个 3；可以组成 [22, 93]、[23, 92]、[223, 9] 或 [2, 329]。这不是按原顺序截断整数。

官方示例 1

输入：num = 2932
输出：52

取 new1 = 29、new2 = 23，和为 52，是可取得的最小和。

官方示例 2

输入：num = 4009
输出：13

将数位组成 04 和 09，按整数读作 4 和 9，和为 13；两个 0 都已使用。

约束：1000 ≤ num ≤ 9999。

接口：minimumSum(num: integer) → integer

包含逐步演示、证明与四语言实现

核心洞察：把小数字放在更贵的位置

十位上的数字会被乘以 10，个位只乘以 1。把四个数位升序排列为 a ≤ b ≤ c ≤ d，让 a、b 分别占据两个十位，c、d 占据两个个位。可以组成 10a + c 与 10b + d，最小和就是 10(a + b) + c + d。

完整过程

  1. 拆出 num 的全部四个数位，保留 0 与重复值。
  2. 从小到大排序，得到 a、b、c、d。
  3. 用 a、b 作两个十位，c、d 作两个个位。
  4. 返回 10(a + b) + c + d，无需实际拼接字符串。

2932 → [2, 2, 3, 9] → 23 与 29 → 52。4009 → [0, 0, 4, 9] → 04 与 09 → 13。

正确性：先选择长度，再安排数字

交换论证。若较大的 x 放在权重 w 上，较小的 y 放在权重 v 上，且 w > v，交换会使总和减少 (w − v)(x − y) ≥ 0。因此较大的权重应匹配较小的数字。

覆盖所有长度。四个数位分成两组，每组非空，只有 2+2 和 3+1 两种长度类型。对排好序的 a、b、c、d，2+2 的权重为 [10,10,1,1]，最小和为 10a + 10b + c + d；3+1 的权重为 [100,10,1,1]，最小和为 100a + 10b + c + d。后者比前者多 90a ≥ 0，所以总能选 2+2 达到最优。

可行且最优。构造 10a+c 和 10b+d 恰好使用每个数位一次，前导零合法；其和达到上述所有分组的下界。因此返回值就是全局最小和。a=0 时，3+1 也可能并列最优，2+2 并非唯一最优形式。

边界与复杂度

1000 可组成 00 与 01，答案 1；9999 得到 99+99=198。0 不能丢弃，重复值不能去重。官方输入总是四位，提交函数不必处理负数或非四位整数。

固定 4 位：时间 O(1)，额外空间 O(1)。如果把位数记为 k，这一步排序的常规分析为 O(k log k)，数位数组为 O(k)；当前公式只针对四位。

替代方案

可以枚举四个数位的全部排列，再枚举 3 个切分点，比较两数之和，至多 24×3 次候选计算；易理解但比排序冗长。也可用 10 个计数桶代替排序；本题规模固定，没有必要为此增加实现复杂度。

四语言完整代码

按官方 minimumSum 接口编写，均为待验证实现。

Java

import java.util.Arrays;

class Solution {
    public int minimumSum(int num) {
        int[] digits = new int[4];
        for (int i = 0; i < 4; i++) {
            digits[i] = num % 10;
            num /= 10;
        }
        Arrays.sort(digits);
        return 10 * (digits[0] + digits[1]) + digits[2] + digits[3];
    }
}

};

常见错误

  • 把原数直接切成左右两半：题目允许重排，必须考虑数位的重新分配。
  • 丢掉零或用集合去重：四个数位必须完整使用。
  • 把最小两位放到同一个数里：应让它们分别承担十位权重。
  • 字符串相加：JavaScript 要先转为数值，否则 + 可能变成拼接。
  • 只说“均分最好”却不给证明：需要比较 2+2 与 3+1 的最小可能值。

面试追问

个位互换会怎样？c、d 互换不改变总和，因为权重相同。

最优拆分唯一吗？不唯一；两个整数可交换，个位可交换，有零时不同长度也可能打平。

推广到更多数位呢？允许前导零时，可先平衡两组数位数，再把较小数字安排到较高权重；需要重新说明长度选择和整数溢出，不能直接套用四位公式。

如果不允许前导零呢？最高位还需满足非零约束；本题的直接分配可能失效，应单独选择合法首位并重新论证。
