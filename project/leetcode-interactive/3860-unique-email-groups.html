不同邮件组

把看似不同的地址压缩成同一个规范身份：本地名截断加号、移除圆点并统一小写；域名只需统一小写。

哈希集合字符串O(总字符数)

题意

给定若干合法邮件地址。两个地址的规范化本地名和规范化域名都相同，便属于同一组；返回不同组的数量。

  • 本地名（@ 前）：忽略第一个 + 后的内容，移除全部 .，转为小写。
  • 域名（@ 后）：仅转为小写。
  • 约束：1 ≤ emails.length ≤ 1000，每个地址长度至多 100，每项恰有一个 @。
示例：emails = ["test.email+alex@leetcode.com", "test.e.mail+bob.cathy@leetcode.com", "testemail+david@lee.tcode.com"]，答案为 2。

规范化流水线

  1. 1按 @ 拆成本地名与域名。
  2. 2本地名在第一个 + 截断，删掉圆点并小写化。
  3. 3域名小写化；拼成规范地址并放入 Set。

题解：规范键 + Hash Set

核心洞察

分组关系只依赖规范后的完整地址；每封邮件映射为唯一的键，集合大小就是答案。

复杂度

设所有字符串总长度为 L：时间 O(L)，集合最坏额外空间 O(L)。

完整过程

逐项拆分；本地名截断、去点、小写化；域名小写化；插入集合。

边界

只认第一个 +；域名中的圆点不能删除；两侧都需统一大小写。

替代方案

排序所有规范键后计相邻变化也可行，但会增加 O(n log n)。

常见错误与面试追问

  • 把域名圆点也删掉，或忘记域名小写化。
  • 不能将加号后内容带进规范键。
  • 追问：若规则因域名而异，应将规范器策略化。
