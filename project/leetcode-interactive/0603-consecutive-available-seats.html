Consecutive Available Seats

一张影院座位表里，哪些空余座位至少紧挨着另一张空余座位？先读清输入与输出，再用一排可点击的座位亲手观察结果如何形成。

01

题意与数据契约

这是数据库题，没有函数参数；输入是一张表，输出是一列按升序排列的座位编号。

准确转述

表 Cinema 记录影院座位。seat_id 是座位编号，free 表示该座位是否空余：值为 1 时空余，值为 0 时已占用。

返回所有“连续空余座位”的编号。如果一张空余座位的左邻座位（编号减一）或右邻座位（编号加一）也是空余的，那么它属于答案。结果按 seat_id 升序排列。

连续的含义：座位编号之差必须恰好为 1；单独空余、但两侧都没有空余邻座的座位不返回。

表结构与输出

输入Cinema(seat_id INT, free BOOLEAN)
键seat_id：自增主键
取值free ∈ {0, 1}
输出Result(seat_id INT)
排序ORDER BY seat_id ASC

约束说明

  • seat_id 唯一，官方建表元数据将其定义为自增主键。
  • free 是布尔标记，仅用 0 与 1 表达占用状态。
  • 官方元数据未给出行数或编号的数值范围；本页不虚构额外上限。

把“连续”改写成邻居存在性

不用识别整段区间。对每张空余座位，只要确认编号减一或加一的位置存在另一张空余座位，它就应该出现在结果里。

过滤自己当前座位必须满足 free = 1。
寻找邻居检查 seat_id − 1 与 seat_id + 1。
自然去重EXISTS 只判断存在，不复制结果行。

完整过程

  1. 从 Cinema 逐行考虑当前座位 c。
  2. 先用 c.free = 1 排除已占用座位。
  3. 分别查询 c.seat_id - 1 和 c.seat_id + 1 是否为空余座位。
  4. 任一邻居存在时保留当前编号，最后按编号升序输出。

正确性说明

  • 不会漏：若座位属于某段连续空余座位，它必为空余，且至少有一个编号相差 1 的空余邻座，因此查询会选中它。
  • 不会多：若查询选中某座位，则它自身空余，并存在编号相差 1 的空余邻座；这正是连续空余座位的定义。
  • 顺序正确：ORDER BY seat_id 明确保证升序，不依赖数据库默认返回顺序。

代码实现

MySQL 是本题可提交解法；Java、JavaScript、Python、C++ 仅用于本地复现相同语义，不是本题 LeetCode 提交语言。

官方可提交语言：MySQL。用两个相关子查询判断左右邻座是否存在。

SELECT c.seat_id
FROM Cinema AS c
WHERE c.free = 1
  AND (
    EXISTS (
      SELECT 1
      FROM Cinema AS left_seat
      WHERE left_seat.seat_id = c.seat_id - 1
        AND left_seat.free = 1
    )
    OR EXISTS (
      SELECT 1
      FROM Cinema AS right_seat
      WHERE right_seat.seat_id = c.seat_id + 1
        AND right_seat.free = 1
    )
  )
ORDER BY c.seat_id;

本地语义参考：输入每行是 {seat_id, free}，返回符合条件的 seat_id；不是本题 LeetCode 提交代码。

import java.util.ArrayList;
import java.util.Collections;
import java.util.HashSet;
import java.util.List;
import java.util.Set;

public class ConsecutiveAvailableSeats {
    public static List<Integer> findSeats(int[][] cinema) {
        Set<Integer> freeSeats = new HashSet<>();

        for (int[] row : cinema) {
            int seatId = row[0];
            int free = row[1];
            if (free == 1) {
                freeSeats.add(seatId);
            }
        }

        List<Integer> answer = new ArrayList<>();
        for (int seatId : freeSeats) {
            if (freeSeats.contains(seatId - 1)
                    || freeSeats.contains(seatId + 1)) {
                answer.add(seatId);
            }
        }

        Collections.sort(answer);
        return answer;
    }

    public static void main(String[] args) {
        int[][] cinema = {
            {1, 1}, {2, 0}, {3, 1}, {4, 1}, {5, 1}
        };
        System.out.println(findSeats(cinema));
    }
}

/**
 * @param {Array<[number, number]>} cinema
 * @returns {number[]}
 */
function findConsecutiveAvailableSeats(cinema) {
  const freeSeats = new Set(
    cinema
      .filter(([, free]) => free === 1)
      .map(([seatId]) => seatId)
  );

  return [...freeSeats]
    .filter(
      (seatId) =>
        freeSeats.has(seatId - 1) || freeSeats.has(seatId + 1)
    )
    .sort((a, b) => a - b);
}

from typing import Iterable, List, Tuple


def find_consecutive_available_seats(
    cinema: Iterable[Tuple[int, int]],
) -> List[int]:
    free_seats = {
        seat_id
        for seat_id, free in cinema
        if free == 1
    }

    answer = [
        seat_id
        for seat_id in free_seats
        if seat_id - 1 in free_seats
        or seat_id + 1 in free_seats
    ]
    return sorted(answer)

本地语义参考：vector<pair<int,int>> 模拟表行；不是本题 LeetCode 提交代码。

#include <algorithm>
#include <iostream>
#include <unordered_set>
#include <utility>
#include <vector>

std::vector<int> findConsecutiveAvailableSeats(
    const std::vector<std::pair<int, int>>& cinema
) {
    std::unordered_set<int> freeSeats;
    for (const auto& [seatId, free] : cinema) {
        if (free == 1) {
            freeSeats.insert(seatId);
        }
    }

    std::vector<int> answer;
    for (int seatId : freeSeats) {
        if (freeSeats.count(seatId - 1)
                || freeSeats.count(seatId + 1)) {
            answer.push_back(seatId);
        }
    }

    std::sort(answer.begin(), answer.end());
    return answer;
}

int main() {
    std::vector<std::pair<int, int>> cinema = {
        {1, 1}, {2, 0}, {3, 1}, {4, 1}, {5, 1}
    };

    for (int seatId : findConsecutiveAvailableSeats(cinema)) {
        std::cout << seatId << ' ';
    }
    std::cout << '\n';
    return 0;
}

复杂度

SQL 查找主键索引下，每个邻居定位约为 O(log n)。
整体时间通常 O(n log n)，最终排序也计入。
额外空间查询逻辑本身 O(1)，不计数据库执行计划。

数据库实际代价取决于优化器、索引和数据分布；复杂度表述是基于 seat_id 主键索引的算法级估计。

边界情况

  • 只有一张空余座位：没有邻居，结果为空。
  • 所有座位占用：第一层 free = 1 即全部过滤。
  • 整排都空余：每张座位至少有一侧空余邻居，全部返回。
  • 存在编号缺口：只有差值恰好为 1 才算相邻。
  • 连续三张或更多：中间座位有两个空余邻居，但仍只返回一次。

替代方案

自连接：把 Cinema 与自身按编号差 1 连接，再用 DISTINCT 去重。写法直观，但连续三张以上时同一座位可能参与多对连接。

窗口函数：使用 LAG/LEAD 同时读取前后行的编号与状态。适合继续分析连续区段，但必须同时校验编号差，不能把有缺口的相邻行误判成相邻座位。

并集：分别查询“右邻为空余”和“左邻为空余”，用 UNION 去重。语义清楚，但要扫描或组合两份结果。

常见错误

  • 只返回相邻对中的一侧，漏掉另一张同样合格的座位。
  • 自连接后忘记 DISTINCT，让连续区段的中间座位重复出现。
  • 只看上一行或下一行，却没有核对 seat_id 的差值是否为 1。
  • 遗漏当前座位自身的 free = 1 条件。
  • 依赖数据库默认顺序，没有写 ORDER BY。

面试追问

如果要返回连续空余区段的起点、终点和长度呢？

可以用“座位编号减去行号”的 gaps-and-islands 分组法；先筛选空余座位，再对连续编号形成的分组做聚合。

为什么这里选择 EXISTS 而不是 JOIN？

本题只关心邻居是否存在，不需要邻居行的列。EXISTS 直接表达存在性，并天然避免一个座位因两个邻居而复制成多行。

如果座位按影厅和排号划分，查询怎样变化？

把影厅号、排号加入相关子查询的等值条件，使邻居查找只能发生在同一影厅、同一排内，并为这些列与 seat_id 建合适的联合索引。

怎样支持一次预订 k 张连续座位？

问题从“存在一个邻居”升级为“寻找长度至少为 k 的连续区段”。可用窗口函数分组连续编号，再按组计数并筛选长度。
