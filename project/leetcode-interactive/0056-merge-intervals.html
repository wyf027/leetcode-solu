题意与样例

给定区间数组 intervals，每个元素为 [startᵢ, endᵢ]。合并所有重叠区间，返回恰好覆盖原有范围、且互不重叠的区间数组。端点相接也视为重叠。

Official sample 01

输入
intervals = [[1,3],[2,6],[8,10],[15,18]]
输出
[[1,6],[8,10],[15,18]]

Official sample 02

输入
intervals = [[1,4],[4,5]]
输出
[[1,5]]

约束：1 ≤ intervals.length ≤ 10⁴；每个区间恰有两个端点； 0 ≤ startᵢ ≤ endᵢ ≤ 10⁴。

Core insight

排序把“任意重叠”变成“只看最后一段”

按起点升序排列后，如果新区间能和任何已合并区间重叠，它一定先与结果数组的最后一个区间相遇。因此只需判断 start ≤ lastEnd：成立就扩展终点，否则把新区间追加到结果。

Full process

完整过程

  1. 1. 按每个区间的起点升序排序。
  2. 2. 结果为空时，直接放入第一段。
  3. 3. 若当前起点不大于结果末段终点，更新末段终点为两者最大值。
  4. 4. 否则说明出现空隙，把当前区间作为新段追加。

Boundaries

边界与不变量

  • 端点相等仍重叠，所以条件是 ≤，不是 <。
  • 完全包含时终点可能不变，必须取 max(lastEnd, end)。
  • 相同起点的先后不影响正确性；按终点再排序便于稳定展示。
  • 单个区间、零长度区间 [x,x] 都可由同一逻辑处理。

Complexity

复杂度

排序 O(n log n)，扫描 O(n)。除排序与返回结果外，额外空间取决于语言排序实现，通常记作 O(log n) 或 O(n)。

Trade-offs

替代方案

当端点范围很小时可做扫描线或计数映射，但依赖值域且更难处理闭区间边界。面试中“排序 + 一次扫描”更通用、证明更直接。

Common mistakes

常见错误

忘记排序；用严格小于导致 [1,4] 与 [4,5] 未合并；直接覆盖终点而不是取最大值；边遍历边修改原数组导致索引混乱。

Interview follow-up

面试追问

如果输入已经按起点排序？

跳过排序，整体时间降为 O(n)。

如果区间是开区间？

端点相等不一定重叠，比较条件要根据开闭规则调整。

如何支持持续到来的新区间？

若到达顺序仍按起点递增，可在线维护末段；否则需要有序结构并处理相邻区间。

如何证明只比较最后一段？

结果区间按起点有序且互不重叠；若当前起点已越过最后终点，也必然越过更早区间的终点。

class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
        List<int[]> merged = new ArrayList<>();

        for (int[] interval : intervals) {
            if (merged.isEmpty()
                    || interval[0] > merged.get(merged.size() - 1)[1]) {
                merged.add(new int[] {interval[0], interval[1]});
            } else {
                int[] last = merged.get(merged.size() - 1);
                last[1] = Math.max(last[1], interval[1]);
            }
        }

        return merged.toArray(new int[merged.size()][]);
    }
}

var merge = function (intervals) {
  intervals.sort((a, b) => a[0] - b[0]);
  const merged = [];

  for (const [start, end] of intervals) {
    const last = merged[merged.length - 1];
    if (!last || start > last[1]) {
      merged.push([start, end]);
    } else {
      last[1] = Math.max(last[1], end);
    }
  }

  return merged;
};

class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        vector<vector<int>> merged;

        for (const auto& interval : intervals) {
            if (merged.empty() || interval[0] > merged.back()[1]) {
                merged.push_back(interval);

                merged.back()[1] = max(merged.back()[1], interval[1]);
