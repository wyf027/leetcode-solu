数据流中的移动平均值

设计一个能够返回数据流最近 size 个元素平均值的数据结构。用队列保存窗口，用滚动和避免重复求和。

    核心思路

    入队：将新数字加入队尾，同时加入滚动和。

    出队：若队列超过 size，弹出队首并从滚动和减去它。

    返回：sum / queue.length。每次操作仅访问常数个元素。

    时间
    O(1)
    空间
    O(size)
    常见错误：每次 next 都遍历窗口重新求和，会把单次时间从 O(1) 退化为 O(size)。

    为什么它是移动平均？

    窗口像一段固定长度的传送带：新数据上带，最旧数据下带。滚动和始终等于带上所有数字之和，所以平均值可立即得到。
