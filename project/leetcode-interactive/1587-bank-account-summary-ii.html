银行账户概要 II

Bank Account Summary II · 把每一笔交易汇成账户余额，再找出真正超过门槛的用户。

先读题 打开聚合实验室
Problem

题意

给定用户表 Users 与交易表 Transactions。每个账户初始余额为 0；收入是正数，转出是负数。账户余额等于该账户全部交易金额之和。

请返回余额严格高于 10000 的用户姓名与余额，结果顺序不限。注意：等于 10000 不符合条件。

参数一：Users

每行描述一个银行用户。

列名类型含义
accountint主键，账户号
namevarchar用户姓名，互不重复

参数二：Transactions

每行是一笔账户金额变化。

列名类型含义
trans_idint主键，交易编号
accountint交易所属账户
amountint正为收入，负为转出
transacted_ondate交易日期

约束与关系事实

Users.account 与 Transactions.trans_id 均为唯一主键；Users 中姓名互不重复；所有账户从 0 开始；amount 的正负表示资金流向。输出只要求 name 与聚合后的 balance，顺序任意。

准备好看题解了吗？

先动手想一想：为什么余额条件不能直接写在 WHERE 中？

Solution

题解：先连接，再按账户聚合

核心洞察：余额不是某一行的字段，而是一组交易的总和。先用 account 连接用户与交易，再按账户分组求和，最后用 HAVING 过滤聚合结果。

完整过程

1
连接身份与流水

Users JOIN Transactions USING(account)，让每笔交易带上用户姓名。

2
按账户分组

以 account、name 为组键，确保每个账户形成一个交易集合。

3
求和并筛选

SUM(amount) 得到余额；HAVING 保留余额严格大于 10000 的组。

4
投影结果列

仅输出 name 与 SUM(amount) AS balance。

正确性说明

连接后，每笔 Transactions 记录恰好归入其 account 对应的用户组。对该组全部 amount 求和，按照题目对余额的定义，所得值正是该账户最终余额。

HAVING 只保留聚合值大于 10000 的组，因此输出中的每位用户都满足条件；任何满足条件的账户组也都会被保留，所以结果既无误收也无漏收。

复杂度

设交易数为 T、用户数为 U。典型哈希连接与哈希聚合的期望时间为 O(U + T)，额外空间为 O(U)；数据库实际计划取决于索引、统计信息和执行器。

边界情况

  • 余额恰好等于 10000：不返回。
  • 多笔正负交易互相抵消：必须对全部流水求和。
  • 余额为负数或 0：不返回。
  • 只有一笔大额收入：同样通过分组求和判断。
  • 没有满足条件的账户：结果为空表。

替代方案

先聚合 Transactions 再连接 Users：子查询先按 account 求余额并过滤，再连接姓名，语义同样清晰，在部分执行计划下可减少中间行。

窗口函数：可以计算分区总和，但还需去重，表达更复杂，不是本题首选。

面试追问

  • WHERE 与 HAVING 的执行对象有什么不同？
  • 若还要返回零交易用户，INNER JOIN 应如何改变？
  • 若只统计某个日期范围，应把日期条件放在哪里？
  • account 已唯一时，为什么仍建议把 name 一起写入 GROUP BY？

常见错误

  • 在 WHERE 中直接使用 SUM(amount)。
  • 误写成 >= 10000。
  • 按 trans_id 分组，导致每笔交易独立成组。
  • 忽略负数交易，只累加收入。
  • 输出 account，却漏掉题目要求的 name。

MySQL · 官方可提交语言

推荐
SELECT
    u.name,
    SUM(t.amount) AS balance
FROM Users AS u
JOIN Transactions AS t
    ON u.account = t.account
GROUP BY u.account, u.name
HAVING SUM(t.amount) > 10000;

Java

本地语义参考
import java.time.LocalDate;
import java.util.*;

public class BankAccountSummaryII {
    record User(int account, String name) {}
    record Transaction(int id, int account, int amount,
                       LocalDate transactedOn) {}
    record Result(String name, long balance) {}

    public static List<Result> accountSummary(
            List<User> users,
            List<Transaction> transactions,
            long threshold) {
        Map<Integer, Long> balances = new HashMap<>();
        for (Transaction transaction : transactions) {
            balances.merge(transaction.account(),
                           (long) transaction.amount(),
                           Long::sum);
        }

        List<Result> result = new ArrayList<>();
        for (User user : users) {
            long balance = balances.getOrDefault(user.account(), 0L);
            if (balance > threshold) {
                result.add(new Result(user.name(), balance));
            }
        }
        return result;
    }
}

JavaScript

本地语义参考
/**
 * @param {{account:number,name:string}[]} users
 * @param {{trans_id:number,account:number,
 *          amount:number,transacted_on:string}[]} transactions
 * @param {number} threshold
 * @return {{name:string,balance:number}[]}
 */
function accountSummary(users, transactions, threshold = 10000) {
  const balances = new Map();

  for (const transaction of transactions) {
    const oldBalance = balances.get(transaction.account) ?? 0;
    balances.set(
      transaction.account,
      oldBalance + transaction.amount
    );
  }

  return users
    .map((user) => ({
      name: user.name,
      balance: balances.get(user.account) ?? 0,
    }))
    .filter((row) => row.balance > threshold);
}

Python

本地语义参考
from collections import defaultdict
from dataclasses import dataclass
from datetime import date

@dataclass(frozen=True)
class User:
    account: int
    name: str

@dataclass(frozen=True)
class Transaction:
    trans_id: int
    account: int
    amount: int
    transacted_on: date

def account_summary(users, transactions, threshold=10_000):
    balances = defaultdict(int)
    for transaction in transactions:
        balances[transaction.account] += transaction.amount

    return [
        {"name": user.name, "balance": balances[user.account]}
        for user in users
        if balances[user.account] > threshold
    ]

C++

本地语义参考
#include <cstdint>
#include <string>
#include <unordered_map>
#include <vector>

struct User {
    int account;
    std::string name;
};

struct Transaction {
    int transId;
    int account;
    int amount;
    std::string transactedOn;
};

struct Result {
    std::string name;
    std::int64_t balance;
};

std::vector<Result> accountSummary(
    const std::vector<User>& users,
    const std::vector<Transaction>& transactions,
    std::int64_t threshold = 10000) {
    std::unordered_map<int, std::int64_t> balances;
    for (const auto& transaction : transactions) {
        balances[transaction.account] += transaction.amount;
    }

    std::vector<Result> result;
    for (const auto& user : users) {
        const std::int64_t balance = balances[user.account];
        if (balance > threshold) {
            result.push_back({user.name, balance});
        }
    }
    return result;
}
