最小分割分数 II

把正整数数组切成恰好 k 段。段和越集中，三角形代价增长越快；本页用“惩罚段数 + 单调凸包”把看似二次的分段 DP 压到可处理的规模。

题意

给定正整数数组 nums 与整数 k，将数组切成恰好 k 个连续、非空子数组。每段的元素和为 s 时，其值为 s × (s + 1) / 2；分割分数是所有段值之和。返回最小分数。

示例 1

nums = [5, 1, 2, 1]
k = 2

输出 25：[5] | [1,2,1]，段和为 5、4，代价 15 + 10。

示例 2

nums = [1, 2, 3, 4]
k = 1

输出 55：只能保留整段，段和为 10。

示例 3

nums = [1, 1, 1]
k = 3

输出 3：每段一个 1，每段代价均为 1。

约束（II）：1 ≤ nums.length ≤ 5 × 10⁴，1 ≤ nums[i] ≤ 10³，1 ≤ k ≤ nums.length。所有数为正，因此前缀和单调递增。

题解

默认收起，避免在首屏直接给出答案。

核心洞察：把段数变成价格

  1. 设 P[i] 是前 i 个数的前缀和，朴素转移是 dp[t][i] = min(dp[t-1][j] + F(P[i]-P[j]))。
  2. F(x)=x(x+1)/2 展开后，关于 P[i] 的部分是常数，候选 j 变成一条斜率为 -P[j] 的直线。
  3. 给每段加惩罚 λ，一次 DP 同时得到“最小（原分数 + λ×段数）”和使用的段数。增大 λ 会让段数单调减少。
  4. 二分 λ，寻找恰好跨过 k 的位置；最后从带惩罚的值中减去 λ × k。这就是 WQS/Aliens trick。

完整过程

line(j): y = -P[j] · x + dp[j] + (P[j]² - P[j]) / 2
dp[i] = F(P[i]) + λ + min_j line(j)(P[i])

P[i] 单调递增，加入直线的斜率 -P[j] 单调递减，查询 x=P[i] 单调递增。
所以维护一个双端队列：队首淘汰、队尾维护下凸壳，每次 DP 线性完成。

边界

  • k=1：整数组成一段。
  • k=n：每个元素单独成段。
  • 前缀和与分数必须使用 64 位；比较两条线的交点时使用更宽整数（C++ 的 __int128 / Java BigInteger）。
  • 正数条件保证前缀和、斜率、查询坐标的单调性。

复杂度

一次带惩罚 DP 为 O(n)；二分惩罚约 O(log S²) 次，整体 O(n log S)，额外空间 O(n)。

替代方案

当 n、k 很小时可用 O(kn²) DP 作对拍；分治 DP 优化可到 O(kn log n)，但这里 k 也可能很大，WQS 更合适。

面试追问与常见错误

追问

  • 若 nums 可为负数，单调 CHT 为什么失效？
  • 如何把队列 CHT 换成 Li Chao tree？
  • 怎样用小数据的三重循环 DP 验证 WQS？

常见错误

  • 把段数惩罚加在元素上，而不是每段一次。
  • 只比较带惩罚的分数，不携带段数做平局处理。
  • 交点判定相乘溢出，破坏凸包。
