寻找峰值 II

Find a Peak Element II

找到一个局部高点。先独立思考，再展开搜索过程。

题意与约束

给定从 0 开始编号的 m × n 整数矩阵 mat，任意上下、左右相邻的元素都不相等。寻找任意一个严格大于上、下、左、右邻居的元素，返回长度为 2 的坐标数组 [行, 列]。不比较对角线。矩阵外圈视为 −1。

必须达到 O(m log n) 或 O(n log m) 时间复杂度。

  • m == mat.length，n == mat[i].length。
  • 1 ≤ m, n ≤ 500。
  • 1 ≤ mat[i][j] ≤ 100000。
  • 任意两个相邻元素均不相等。
官方题目

官方示例 1

输入：mat = [[1,4],[3,2]]
输出：[0,1]

4 与 3 都是峰值，[0,1] 和 [1,0] 均可。

官方示例 2

输入：mat = [[10,20,15],[21,30,14],[7,16,32]]
输出：[1,1]

30 与 32 都是峰值，[1,1] 和 [2,2] 均可。

思考起点

一个元素比右侧小，是否就能放心丢弃左半矩阵？二维问题还需要怎样的保证？题解与交互演示位于页面底部。

题解：中间列最大值

核心洞察

扫描中间列，取全列最大值。因为相邻不等，它严格大于上下邻居。只需比较左右；如果某侧更大，就向那一侧缩小列区间，否则找到峰值。

交互：列切片搜索

蓝色为中间列，金色为当前候选，绿色为峰值，淡色为排除列。每扫描一行前进一步。

完整过程

  1. 初始化闭区间 [lo,hi] = [0,n−1]。
  2. 取中间列 c，扫描全部 m 行，找到列最大值所在行 r。
  3. 读取原矩阵左右邻居，只有越出原矩阵才使用 −1。
  4. 候选大于左右则返回 [r,c]；左侧更大则 hi=c−1，否则 lo=c+1。
  5. 重复，区间每轮至少减半。

正确性证明

令 f(c) 是第 c 列最大值，外部列值为 −1。维护边界关系 f(lo) > f(lo−1) 与 f(hi) > f(hi+1)。初始成立；向左时左邻居大于中间列最大值，因此 f(c−1) > f(c)，新右边界合法；向右时同理。

在保留区间中取全局最大元素，它不小于所有区间内部邻居，相邻不等使比较严格。如果位于区间边缘，边界关系保证它也大于区间外的邻居。因此保留区间始终存在原矩阵的峰值。当前候选已大于上下，若也大于左右即正确返回；否则区间严格缩短且不丢失峰值，故算法终止并返回正确结果。

边界与复杂度

单列扫描一次；单行退化为一维；单元素直接是峰值。同列不相邻的最大值可以相等，任选一个即可。每轮 O(m)，总时间 O(m log(n+1))，通常记作 O(m log n)；额外空间 O(1)。演示保存历史的空间不计入提交算法。

替代方案

对行二分、扫描行最大值可得 O(n log(m+1)) 时间与 O(1) 空间。逐格检查是 O(mn)，不符合目标复杂度。沿更大邻居爬坡可以终止，但最坏仍可能经过 O(mn) 个位置。

常见错误

  • 随意取中间列元素，无法保证上下关系。
  • 把被排除列当成 −1，应比较真实矩阵邻居。
  • 误把对角线算作邻居，或要求唯一答案。
  • 认为列最大值序列必须有序：二分依赖存在性不变量。
  • 认为不同列最大值必不相等：它们可能来自不同行。

面试追问

两侧都更大？任选一侧都保留峰值，代码优先左侧。允许相邻相等？严格峰值可能不存在，例如全等矩阵。如何选扫描方向？比较 m log(n+1) 与 n log(m+1) 的代价。

/** @param {number[][]} mat @return {number[]} */
var findPeakGrid = function(mat) {
    const m = mat.length, n = mat[0].length;
    let lo = 0, hi = n - 1;
    while (lo <= hi) {
        const c = Math.floor((lo + hi) / 2);
        let r = 0;
        for (let i = 1; i < m; i++)
            if (mat[i][c] > mat[r][c]) r = i;
        const left = c > 0 ? mat[r][c - 1] : -1;
        const right = c + 1 < n ? mat[r][c + 1] : -1;
        if (mat[r][c] > left && mat[r][c] > right) return [r, c];
        if (left > mat[r][c]) hi = c - 1;
        else lo = c + 1;
    }
    return [-1, -1];
};

    public int[] findPeakGrid(int[][] mat) {
        int m = mat.length, n = mat[0].length;
        int lo = 0, hi = n - 1;
        while (lo <= hi) {
            int c = lo + (hi - lo) / 2, r = 0;
            for (int i = 1; i < m; i++)

            int left = c > 0 ? mat[r][c - 1] : -1;

                return new int[]{r, c};
            if (left > mat[r][c]) hi = c - 1;
            else lo = c + 1;
        }
        return new int[]{-1, -1};
    }
}

Python

from typing import List

class Solution:
    def findPeakGrid(self, mat: List[List[int]]) -> List[int]:
        m, n = len(mat), len(mat[0])
        lo, hi = 0, n - 1
        while lo <= hi:
            c = (lo + hi) // 2
            r = max(range(m), key=lambda i: mat[i][c])
            left = mat[r][c - 1] if c > 0 else -1
            right = mat[r][c + 1] if c + 1 < n else -1
            if mat[r][c] > left and mat[r][c] > right:
                return [r, c]
            if left > mat[r][c]:
                hi = c - 1
            else:
                lo = c + 1
        return [-1, -1]
