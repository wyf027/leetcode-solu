由单个字符重复的
最长子字符串

Longest Substring of One Repeating Character

一个字符的改变，如何拆开一段连续字符，又把相邻的片段连起来？

查看官方题目 ↗

01 / 题目

给定字符串 s、字符串 queryCharacters 和整数数组 queryIndices。后两者长度均为 k。按顺序执行第 i 次操作：把 s[queryIndices[i]] 替换为 queryCharacters[i]。

每次修改之后，记录当前字符串中由同一个字符连续组成的最长子字符串长度，返回这 k 个长度。所有下标从 0 开始；修改会保留到下一次操作，子字符串必须连续。

官方示例 1

s = "babacc"
queryCharacters = "bcb"
queryIndices = [1,3,3]
输出：[3,3,4]

依次变成 bbbacc、bbbccc、bbbbcc；最长段依次为 bbb、bbb 或 ccc、bbbb。

官方示例 2

s = "abyzz"
queryCharacters = "aa"
queryIndices = [2,1]
输出：[2,3]

依次变成 abazz、aaazz；最长段依次为 zz、aaa。

约束

  • 1 ≤ s.length ≤ 10⁵
  • k == queryCharacters.length == queryIndices.length
  • 1 ≤ k ≤ 10⁵
  • s 和 queryCharacters 仅含小写英文字母。
  • 0 ≤ queryIndices[i] < s.length

04 / 推导与实现
准备好后再展开，查看区间摘要如何在一次修改后恢复。


线段树：合并边界上的连续段


核心洞察
一次单点修改可能让整条字符串的最长段增长或断开。每次从头扫描会达到 O(nk)。将区间一分为二后，最长段只有三种位置：完全在左边、完全在右边、横跨两边。
为每个区间维护 pre（同字符最长前缀）、suf（同字符最长后缀）、best（区间内最长段）。长度由区间边界获得；边界字符直接从可变字符数组读取，因此代码无需在节点里另存首尾字符。


合并公式与完整过程
  1. 叶子只有一个字符，pre = suf = best = 1。递归建树并向上合并。
  2. 设左右子区间为 L、R，先令 pre = L.pre、suf = R.suf、best = max(L.best, R.best)。
  3. 只有 a[mid] == a[mid+1] 时才能跨边界：用 L.suf + R.pre 更新 best。若左区间全部同字符，前缀延伸到右前缀；若右区间全部同字符，后缀延伸到左后缀。
  4. 每次更新沿树下降到目标叶子，修改字符数组。叶子三项长度仍为 1；回溯时逐层重新合并。其他子树不变。
  5. 根节点覆盖整个字符串，读取根的 best 加入结果；结果不包含初始状态。


若边界字符相等：
best = max(L.best, R.best, L.suf + R.pre)
pre  = L.pre + (L.pre == len(L) ? R.pre : 0)
suf  = R.suf + (R.suf == len(R) ? L.suf : 0)
若边界字符不等：
best = max(L.best, R.best), pre = L.pre, suf = R.suf


同步区间树
随实验室的步骤同步更新。每层从左到右对应连续区间；父区间由下一层中覆盖它的两个子区间组成。橙色节点为本次修改的叶子及其祖先，显示更新后的摘要。初始状态没有更新路径。


示例中的跨界连接
示例 1 的根分为 [0,2] 与 [3,5]。第一次更新后为 bbb | acc，边界 b ≠ a，答案 3。第二次为 bbb | ccc，边界仍不同，答案 3。第三次为 bbb | bcc，左后缀 3 加右前缀 1，得到答案 4。


正确性
区间不变式：每个节点的三项摘要精确描述它覆盖的当前字符串片段。叶子显然满足。假设两个子节点满足，任何连续同字符子串要么完全在一个子区间内，要么跨越唯一的分界线。前两类被子节点 best 覆盖；第三类存在的充要条件是边界字符相等，最长长度恰为左后缀加右前缀。前后缀只有在靠外的整个子区间同字符时才能延伸，所以合并公式精确且不会越过异字符。归纳可知建树正确。
单点更新只影响包含该位置的区间。更新叶子后沿祖先链重算，其他区间仍满足不变式，因此整棵树恢复正确。根覆盖全部字符串，其 best 就是此次查询后要求的值。按序处理确保所有修改累计生效。


边界与常见错误
  • 长度为 1：答案始终为 1；相同字符覆盖无需改变叶子的摘要。
  • 重复修改同一下标：必须使用当前字符数组，不能每轮恢复初始字符串。
  • 全相同或修改首尾字符：统一合并规则即可处理，不需额外分支。
  • 边界不同不能拼接；即使边界相同，也不能无条件把两边的 pre 或 suf 相加。
  • 每次 pull 必须先重置三项摘要，再做延伸；否则旧的长段可能残留。
  • 答案可能下降，不能把历次答案的最大值当作当前答案；也不能统计整个字符串中某字符的总出现次数。


复杂度
令 n = s.length，k 为查询数。建树 O(n)，每次修改 O(log n)，根部读取 O(1)，总时间 O(n + k log n)。树和字符数组 O(n)，递归栈 O(log n)，输出 O(k)；含输出总空间 O(n + k)。


替代方案
逐次扫描易写，但最坏 O(nk)，只适合小数据。也可用有序集合维护最大同字符区间，更新时拆分/合并相邻段，配合长度多重集合维护最大值，可达到 O((n+k) log n)，但删除重复长度、定位相邻段更易出错。普通树状数组无法直接用加减维护此类边界相关摘要；线段树更自然。


面试追问
  • 若查询任意子区间？按从左到右的顺序合并覆盖该范围的节点；摘要额外携带长度和首尾字符，可处理截断区间。
  • 若将整段赋值为同一字符？增加懒标记，覆盖节点的 pre、suf、best 均变为区间长度，首尾字符一致，向下访问前下推。
  • 为什么只存 best 不够？左右相同的 best 可能对应不同边界字符或不同边界连续段，无法判断跨界长度。

/**
 * @param {string} s
 * @param {string} queryCharacters
 * @param {number[]} queryIndices
 * @return {number[]}
 */
var longestRepeating = function(s, queryCharacters, queryIndices) {
    const a = s.split(''), n = a.length;
    const pre = new Int32Array(4 * n);
    const suf = new Int32Array(4 * n);
    const best = new Int32Array(4 * n);
    function pull(v, l, r) {
        const m = (l + r) >> 1, x = v * 2, y = x + 1;
        pre[v] = pre[x]; suf[v] = suf[y];
        best[v] = Math.max(best[x], best[y]);
        if (a[m] === a[m + 1]) {
            best[v] = Math.max(best[v], suf[x] + pre[y]);
            if (pre[x] === m - l + 1) pre[v] += pre[y];
            if (suf[y] === r - m) suf[v] += suf[x];
        }
    }
    function build(v, l, r) {
        if (l === r) { pre[v] = suf[v] = best[v] = 1; return; }
        const m = (l + r) >> 1;
        build(v * 2, l, m); build(v * 2 + 1, m + 1, r);
        pull(v, l, r);
    }
    function update(v, l, r, i, c) {
        if (l === r) { a[i] = c; return; }
        const m = (l + r) >> 1;
        if (i <= m) update(v * 2, l, m, i, c);
        else update(v * 2 + 1, m + 1, r, i, c);
        pull(v, l, r);
    }
    build(1, 0, n - 1);
    const ans = [];
    for (let j = 0; j < queryIndices.length; j++) {
        update(1, 0, n - 1, queryIndices[j], queryCharacters[j]);
        ans.push(best[1]);
    }
    return ans;
};

Python
from typing import List

class Solution:
    def longestRepeating(self, s: str, queryCharacters: str,
                         queryIndices: List[int]) -> List[int]:
        a = list(s)
        n = len(a)
        pre, suf, best = [0] * (4 * n), [0] * (4 * n), [0] * (4 * n)

        def pull(v, l, r):
            m = (l + r) // 2
            x, y = v * 2, v * 2 + 1
            pre[v], suf[v] = pre[x], suf[y]
            best[v] = max(best[x], best[y])
            if a[m] == a[m + 1]:
                best[v] = max(best[v], suf[x] + pre[y])
                if pre[x] == m - l + 1:
                    pre[v] += pre[y]
                if suf[y] == r - m:
                    suf[v] += suf[x]

        def build(v, l, r):
            if l == r:
                pre[v] = suf[v] = best[v] = 1
                return
            m = (l + r) // 2
            build(v * 2, l, m)
            build(v * 2 + 1, m + 1, r)
            pull(v, l, r)

        def update(v, l, r, i, c):
            if l == r:
                a[i] = c
                return
            m = (l + r) // 2
            if i <= m:
                update(v * 2, l, m, i, c)
            else:
                update(v * 2 + 1, m + 1, r, i, c)
            pull(v, l, r)

        build(1, 0, n - 1)
        ans = []
        for i, c in zip(queryIndices, queryCharacters):
            update(1, 0, n - 1, i, c)
            ans.append(best[1])
        return ans

    vector<int> longestRepeating(string s, string queryCharacters,
                                vector<int>& queryIndices) {
