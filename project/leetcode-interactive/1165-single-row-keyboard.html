单行键盘

Single-Row Keyboard

把每个字母的位置先记下来，再让手指沿着单行键盘逐字移动。页面先让你观察路径；完整解法收在底部，不会在首屏剧透。

Problem

题意

函数：calculateTime(keyboard, word) → integer

给定长度为 26 的字符串 keyboard，它描述了一排键盘中字母从左到右的排列。手指初始停在下标 0。输入字符串 word 时，每次从下标 i 移动到 j 要花费 |i - j| 秒；按键本身不耗时。返回输入完整单词的总时间。

关键观察：每个字母只出现一次，因此每次移动的起点和终点都是确定的；总时间就是所有移动距离之和。

示例 1

输入
keyboard = "abcdefghijklmnopqrstuvwxyz"
word = "cba"
输出
4
解释
从 0 到 2 花 2 秒，再到 1 花 1 秒，最后到 0 花 1 秒，共 4 秒。

示例 2

输入
keyboard = "pqrstuvwxyzabcdefghijklmno"
word = "leetcode"
输出
73
说明
仍从下标 0 开始，依次累加到 l,e,e,t,c,o,d,e 的移动距离。

约束

  • keyboard.length == 26
  • keyboard 恰好包含每个小写英文字母一次
  • 1 <= word.length <= 10⁴
  • word[i] 是小写英文字母

Full solution

一次建表，一次扫描

O(26 + n) time · O(26) space

把“找字母”从每次线性搜索，变成一次建表后的 O(1) 查询。

完整过程

建立位置表。

扫描 keyboard，记录每个字母对应的下标。

维护当前位置。

令 current = 0，因为手指一开始位于键盘最左边。

逐字累加。

对 word 中每个字符，取得目标下标，累加与当前位置的绝对差，再更新当前位置。

返回总和。

扫描结束时，累积值就是输入整个单词的时间。

正确性

不变式：处理完 word[0..k-1] 后，current 等于最后处理字符的位置，total 等于输入该前缀的准确时间。

初始时前缀为空且手指在 0，结论成立。处理下一字符时，唯一移动的代价恰为当前位置与目标位置的绝对差；累加并更新后不变式继续成立。处理完所有字符，total 即完整答案。

边界：连续相同字符的本步耗时为 0；目标在下标 0 时无需移动；长度为 1 的单词仍适用同一逻辑。

复杂度

建表固定扫描 26 个字符，再扫描长度为 n 的单词：时间复杂度 O(26 + n)，通常简写为 O(n)；位置表占 26 个条目，空间复杂度 O(26)，字母表固定时也可视为 O(1)。

四语言完整代码

切换标签不会执行代码。

class Solution {
    public int calculateTime(String keyboard, String word) {
        int[] position = new int[26];
        for (int i = 0; i < keyboard.length(); i++) {
            position[keyboard.charAt(i) - 'a'] = i;
        }

        int total = 0;
        int current = 0;
        for (int i = 0; i < word.length(); i++) {
            int target = position[word.charAt(i) - 'a'];
            total += Math.abs(target - current);
            current = target;
        }
        return total;
    }
}

var calculateTime = function(keyboard, word) {
    const position = new Array(26);
    for (let i = 0; i < keyboard.length; i++) {
        position[keyboard.charCodeAt(i) - 97] = i;
    }

    let total = 0;
    let current = 0;
    for (const character of word) {
        const target = position[character.charCodeAt(0) - 97];
        total += Math.abs(target - current);
        current = target;
    }
    return total;
};
class Solution:
    def calculateTime(self, keyboard: str, word: str) -> int:
        position = [0] * 26
        for index, character in enumerate(keyboard):
            position[ord(character) - ord('a')] = index

        total = 0
        current = 0
        for character in word:
            target = position[ord(character) - ord('a')]
            total += abs(target - current)
            current = target
        return total

替代方案

可对每个字符调用 keyboard.indexOf(...)。代码更短，但每次最多扫描 26 个位置。因字母表固定仍能通过；位置表更能表达“预处理后常数时间查询”的通用技巧。

面试追问

  • 键盘不止 26 个字符时复杂度如何变化？
  • 允许两根手指时，状态应包含什么？
  • 相邻键移动耗时不同，能否转化成图上的最短路？
常见错误：忘记手指从下标 0 开始；把字符编码差当成键盘距离；累计后未更新当前位置；误把按键动作也计为 1 秒。
