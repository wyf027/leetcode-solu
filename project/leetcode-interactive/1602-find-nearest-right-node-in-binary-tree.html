最近的右侧节点

Find Nearest Right Node in Binary Tree — 不跨层，只寻找同一层里紧挨在目标节点右边的那一个节点。

树广度优先搜索二叉树

Problem

题目描述

给定一棵二叉树的根节点 root 和树中的一个节点引用 u，返回与 u 位于同一层、且在它右侧最近的节点；若 u 已是该层最右节点，则返回 null。

示例 1
输入：root = [1,2,3,null,4,5,6], u = 4 输出：5

节点 4 所在层从左到右为 [4,5,6]，紧邻其右的是节点 5。

示例 2
输入：root = [3,null,4,2], u = 2 输出：null

节点 2 是自己所在层的最右节点，因此没有答案。

注意“节点”不是“节点值”

参数 u 是树中实际节点的引用；题目保证所有节点值互不相同，但判断目标时仍应按节点身份比较。

约束

  • 树中节点数为 [1, 10⁵]
  • 1 ≤ Node.val ≤ 10⁵
  • 树中所有节点值互不相同
  • u 一定属于以 root 为根的树
函数形式findNearestRightNode(root, u) → TreeNode | null

Solution

先想清楚，再揭晓

如果目标出现在队列中，下一个队首一定是答案吗？还有一个必须先确认的条件。

Core Insight

队列知道左右顺序，层长守住边界

按层从左到右 BFS。处理每一层之前记下该层节点数；找到 u 时，若本层仍有未处理节点，当前队首就是最近右侧节点，否则答案为 null。

1

冻结层长

进入一层时记录 levelSize = queue.size。处理期间加入的孩子属于下一层，不计入当前层。

2

从左到右出队

孩子始终先左后右入队，因此队列保留同一层的天然从左到右顺序。

3

看本层余量

命中 u 且循环中仍有节点时，队首就是答案；余量为 0 时不能读取下一层。

关键判定

命中目标时，必须同时满足“当前层还有至少一个未处理节点”。只判断队列非空，会把下一层最左节点误当成答案。

Walkthrough

完整过程

  1. 初始化。 将 root 入队。只要队列不空，就开始处理新的一层。
  2. 固定边界。 读取这一刻的队列长度为 levelSize，随后恰好循环这么多次。
  3. 检查当前节点。 每次从队首取出节点。若它就是 u，根据当前层是否还有剩余项立即返回队首或 null。
  4. 扩展下一层。 若未命中目标，将非空左孩子、右孩子依次入队。
  5. 结束。 题目保证 u 在树中，因此循环会在命中时返回；末尾的 null 是完整性保护。

Correctness

正确性说明

引理 1：每层节点按从左到右顺序出队。根层显然成立；若某层有序，按该顺序访问父节点并先左后右加入孩子，则下一层也有序。

引理 2：固定的 levelSize 精确标识当前层边界。循环开始时队列只含当前层节点；循环中新加入的孩子位于队尾且属于下一层。

结论：当取出 u 时，若当前层仍有未处理节点，队首是同层第一个位于其右侧的节点，因而最近；若没有，则 u 为该层最右节点，返回 null。算法正确。

Boundaries

边界情况

  • 树只有根节点，且 u = root。
  • u 是任意一层的最右节点。
  • 树严重偏斜，每层只有一个节点。
  • 答案与 u 的父节点不同，不能只看兄弟节点。
  • 节点总数达到 10⁵，递归 DFS 可能触发栈深问题。
时间复杂度
O(n)

最坏情况下访问所有 n 个节点；命中后会提前返回。

空间复杂度
O(w)

w 为二叉树最大层宽，最坏为 O(n)。

Implementations

四语言完整代码

均采用显式层长的 BFS；切换标签只改变代码展示。

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) { val = x; }
 * }
 */
class Solution {
    public TreeNode findNearestRightNode(TreeNode root, TreeNode u) {
        Queue<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size();
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                if (node == u) {
                    return i + 1 < levelSize ? queue.peek() : null;
                }
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        return null;
    }
}
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *   this.val = (val === undefined ? 0 : val);
 *   this.left = (left === undefined ? null : left);
 *   this.right = (right === undefined ? null : right);
 * }
 * @param {TreeNode} root
 * @param {TreeNode} u
 * @return {TreeNode}
 */
var findNearestRightNode = function(root, u) {
    const queue = [root];
    let head = 0;

    while (head < queue.length) {
        const levelSize = queue.length - head;
        for (let i = 0; i < levelSize; i++) {
            const node = queue[head++];
            if (node === u) {
                return i + 1 < levelSize ? queue[head] : null;
            }
            if (node.left) queue.push(node.left);
            if (node.right) queue.push(node.right);
        }
    }
    return null;
};
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
from collections import deque
from typing import Optional

class Solution:
    def findNearestRightNode(
        self, root: 'TreeNode', u: 'TreeNode'
    ) -> Optional['TreeNode']:
        queue = deque([root])

        while queue:
            level_size = len(queue)
            for i in range(level_size):
                node = queue.popleft()
                if node is u:
                    return queue[0] if i + 1 < level_size else None
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)

        return None
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 * };
 */
class Solution {
public:
    TreeNode* findNearestRightNode(TreeNode* root, TreeNode* u) {
        queue<TreeNode*> nodes;
        nodes.push(root);

        while (!nodes.empty()) {
            int levelSize = nodes.size();
            for (int i = 0; i < levelSize; ++i) {
                TreeNode* node = nodes.front();
                nodes.pop();
                if (node == u) {
                    return i + 1 < levelSize ? nodes.front() : nullptr;
                }
                if (node->left) nodes.push(node->left);
                if (node->right) nodes.push(node->right);
            }
        }
        return nullptr;
    }
};

Alternative

替代方案：带深度的 DFS

先序遍历时记录目标深度。遇到 u 后，遍历顺序中下一个处于相同深度的节点就是答案。它仍是 O(n) 时间，但需要谨慎维护“已命中目标”和深度状态；在高度可能达到 10⁵ 的偏斜树上，递归栈也不够稳妥。

选择建议：这道题的关键词是“同一层”和“右侧最近”，层序 BFS 更直接，也更容易证明层边界。

Common Mistakes

常见错误

  • 命中 u 后无条件返回队首，误跨到下一层。
  • 把右侧节点理解成 u.right 或同父兄弟。
  • 先右后左入队，破坏从左到右的层序。
  • JavaScript 使用频繁 shift()，大数据下可能产生数组搬移成本。
  • 通过节点值而非节点引用判断 u。

Interview Follow-ups

面试追问

一次 BFS 为同层相邻节点建立映射 nextRight[node] = nextNode，预处理 O(n)，之后每次查询可在 O(1) 时间回答，并使用 O(n) 额外空间。

普通二叉树没有父指针或 next 指针时，很难在不修改树的前提下同时保留完整层序信息。若树节点已有同层 next 指针，或允许先构造这些指针，查询才可沿 next 直接完成。

队列同时保存的主要是某一层以及下一层的一部分，规模由最大层宽 w 控制。因为 w ≤ n，最坏界仍是 O(n)，但 O(w) 更精确。
