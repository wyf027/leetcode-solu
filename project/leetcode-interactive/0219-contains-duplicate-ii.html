展开后查看窗口不变式、证明、边界、替代方案与四语言代码。

Sliding hash set

集合只代表当前下标之前的最近 k 位

检查 nums[i] 时，只关心下标区间 [i-k, i-1]。集合包含这段窗口的值；若当前值已存在，距离条件自动成立。

完整过程与窗口不变式

  1. 初始化空哈希集合 window。
  2. 到达 i 时，集合包含前面至多 k 个值。
  3. 若 window 已有 nums[i]，立刻返回 true。
  4. 否则加入 nums[i]；若集合尺寸超过 k，删除 nums[i-k]，为下一轮恢复窗口。
  5. 扫描结束未命中，返回 false。

在每轮检查开始前，window 恰对应下标 max(0,i-k)..i-1。因此命中等价于存在 j 且 i-k ≤ j < i，即不同下标、值相等、距离不超过 k。

复杂度、边界与替代方案

主线

  • 哈希操作均摊 O(1)，总时间 O(n)。
  • 集合最多保存 min(n,k) 个值，空间 O(min(n,k))。
  • k=0 时每轮加入后立即删除，不可能匹配不同下标。
  • k ≥ n-1 时等价于判断数组是否存在任意重复。

替代

  • 哈希表记录每个值最后下标，同为 O(n)，空间可能 O(n)，也很常用。
  • 平衡树维护窗口为 O(n log k)，可扩展到范围查询。
  • 两层循环检查最近 k 项，时间 O(nk)，只适合极小输入。
  • 排序会破坏原下标邻近关系，必须携带下标且并不简化主线。

import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean containsNearbyDuplicate(int[] nums, int k) {
        Set<Integer> window = new HashSet<>();
        for (int i = 0; i < nums.length; i++) {
            if (!window.add(nums[i])) {
                return true;
            }
            if (window.size() > k) {
                window.remove(nums[i - k]);
            }
        }
        return false;
    }
}

class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
        window = set()
        for i, value in enumerate(nums):
            if value in window:
                return True
            window.add(value)
            if len(window) > k:
                window.remove(nums[i - k])
        return False
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    bool containsNearbyDuplicate(vector<int>& nums, int k) {
        unordered_set<int> window;
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            if (window.count(nums[i])) return true;
            window.insert(nums[i]);
            if (static_cast<int>(window.size()) > k) {
                window.erase(nums[i - k]);
            }
        }
        return false;
    }
};

常见错误

  • 只判断重复，忘记距离 k。
  • 把条件写成距离严格小于 k。
  • 先删除再检查时下标 off-by-one。
  • 集合无限增长，空间退化为 O(n)。
  • k=0 时错误地让元素与自身匹配。
