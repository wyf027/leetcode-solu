回文链表

把后半段链表原地反转，再让两支指针从两端向中间比对。没有数组副本，也不需要额外栈。

LCR 027链表O(n) 时间 · O(1) 额外空间

题意

判断单链表是否正着、倒着都一样

给定头节点 head，若节点值序列从左到右与从右到左相同，返回 true。例如 [1,2,2,1] 是回文，[1,2] 不是。

输入

head = [1,2,2,1]

输出

true

核心不变量

  1. 1. 快指针每次两步、慢指针每次一步，慢指针停在后半段起点。
  2. 2. 反转从慢指针开始的后半段，让它能从右向左读取。
  3. 3. 前半段和反转后的后半段逐值相等，链表就是回文。

为何可行

中点把“从尾部读取”变成“从反转链读取”

单链表不能往回走。先用快慢指针定位中点，再原地翻转后半段，就得到了两个同步前进、分别代表左半和右半的游标。奇数长度时中间元素没有配对对象；让它留在任一半都不影响比较次数。

实现分三段：快慢指针找中点；迭代反转从慢指针开始的链；两支指针逐值比较。题目不要求恢复链表；若调用方需要保持原状，可再次反转后半段。

Java

class Solution {
    public boolean isPalindrome(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; }
        ListNode prev = null;
        while (slow != null) { ListNode next = slow.next; slow.next = prev; prev = slow; slow = next; }
        while (prev != null) { if (head.val != prev.val) return false; head = head.next; prev = prev.next; }
        return true;
    }
}

Python

class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        slow = fast = head
        while fast and fast.next:
            slow, fast = slow.next, fast.next.next
        prev = None
        while slow:
            slow.next, prev, slow = prev, slow, slow.next
        while prev:
            if head.val != prev.val: return False
            head, prev = head.next, prev.next
        return True

class Solution {
public:
    bool isPalindrome(ListNode* head) {
        ListNode *slow = head, *fast = head;
        while (fast && fast->next) { slow = slow->next; fast = fast->next->next; }
        ListNode* prev = nullptr;
        while (slow) { auto next = slow->next; slow->next = prev; prev = slow; slow = next; }
        while (prev) { if (head->val != prev->val) return false; head = head->next; prev = prev->next; }
        return true;
    }
};
