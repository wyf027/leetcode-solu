验证 IP 地址

Validate IP Address

把一串看似普通的字符拆成段，逐项核对数量、长度、字符集与数值范围。先自己观察规则，再按需展开完整题解。

Problem

题目

给定字符串 queryIP，判断它是合法 IPv4、合法 IPv6，还是两者都不是。

IPv4

点分十进制

x1.x2.x3.x4，恰好四段。

  • 每段只含十进制数字，且数值在 0..255。
  • 除单个字符 0 外，段首不能是 0。
  • 空段、符号、字母或多余分隔符都不合法。

IPv6

冒号分组十六进制

x1:x2:x3:x4:x5:x6:x7:x8，恰好八组。

  • 每组长度为 1..4。
  • 字符只能是 0-9、a-f 或 A-F。
  • 允许前导零；本题不接受 :: 压缩写法。

Solution

完整题解

核心洞察：先定候选类型，再做局部白名单验证

不要把整个地址交给宽松的系统 IP 解析器，也不必写一个难以审查的巨型正则。分隔符已经给出候选类型：含点号则只可能尝试 IPv4，含冒号则只可能尝试 IPv6；随后对固定数量的段逐项检查。

完整过程

1. 路由

点号 → IPv4；冒号 → IPv6；混用或无分隔符 → Neither。

2. 切分

保留空段，核对必须恰好为 4 段或 8 组。

3. 白名单

逐段检查长度、字符集，以及 IPv4 的前导零与数值范围。

IPv4 检查

  1. 按 . 切分并保留空段，段数必须为 4。
  2. 每段非空、长度不超过 3，且只含 0-9。
  3. 长度大于 1 时首字符不能为 0。
  4. 转为十进制整数后必须不超过 255。

IPv6 检查

  1. 按 : 切分并保留空组，组数必须为 8。
  2. 每组长度必须位于 1..4。
  3. 每个字符必须属于十六进制白名单。
  4. 无需解析数值，也无需排除前导零。

正确性证明

IPv4 的充分必要性

算法要求恰好四段，并逐段强制十进制字符、无非法前导零且数值在 0 到 255，正好覆盖定义中的全部条件。因此通过时一定合法；任一合法 IPv4 也不会被这些条件拒绝。

IPv6 的充分必要性

算法要求恰好八组，每组长度 1 到 4 且所有字符均为十六进制字符，这与题目定义完全一致。因此通过当且仅当它是合法 IPv6。

最终分类

点号与冒号通道互斥；任一合法地址会进入对应通道并通过，而其他字符串会在路由、段数或局部规则处被拒绝，所以最终返回值正确。

边界清单

  • 1.1.1.1.：末尾产生空段，拒绝。
  • 01.0.0.1：IPv4 前导零，拒绝。
  • 0.0.0.0：单字符零合法。
  • 255.255.255.255：上界合法；256 非法。
  • 2001:db8::1：出现空组，本题不接受压缩。
  • FFFF:0:0:0:0:0:0:abcd：大小写十六进制均合法。
  • 同时出现 . 与 :：直接返回 Neither。

复杂度

设输入长度为 n。切分和逐字符检查都只扫描常数次，因此时间复杂度为 O(n)；保存切分结果需要 O(n) 额外空间。若手写索引扫描，可把额外空间降为 O(1)。

替代方案

  • 正则表达式：可以一次匹配，但表达式较长、可读性和可维护性较弱。
  • 系统网络库：可能接受 ::、IPv4 映射 IPv6 或其他标准扩展，与本题的严格语法不一定一致。
  • 单次索引扫描：空间更省，但分支更多；面试中先写清晰的分段校验通常更稳。

Java · 官方签名class Solution
class Solution {
    public String validIPAddress(String queryIP) {
        if (queryIP.indexOf('.') >= 0 && queryIP.indexOf(':') < 0) {
            return isIPv4(queryIP) ? "IPv4" : "Neither";
        }
        if (queryIP.indexOf(':') >= 0 && queryIP.indexOf('.') < 0) {
            return isIPv6(queryIP) ? "IPv6" : "Neither";
        }
        return "Neither";
    }

    private boolean isIPv4(String s) {
        String[] parts = s.split("\\.", -1); // -1 保留末尾空段
        if (parts.length != 4) return false;

        for (String part : parts) {
            if (part.length() == 0 || part.length() > 3) return false;
            if (part.length() > 1 && part.charAt(0) == '0') return false;

            int value = 0;
            for (char ch : part.toCharArray()) {
                if (ch < '0' || ch > '9') return false;
                value = value * 10 + (ch - '0');
            }
            if (value > 255) return false;
        }
        return true;
    }

    private boolean isIPv6(String s) {
        String[] parts = s.split(":", -1); // -1 保留末尾空组
        if (parts.length != 8) return false;

        for (String part : parts) {
            if (part.length() == 0 || part.length() > 4) return false;
            for (char ch : part.toCharArray()) {
                boolean digit = ch >= '0' && ch <= '9';
                boolean lower = ch >= 'a' && ch <= 'f';
                boolean upper = ch >= 'A' && ch <= 'F';
                if (!digit && !lower && !upper) return false;
            }
        }
        return true;
    }
}

/**

var validIPAddress = function(queryIP) {
    const hasDot = queryIP.includes('.');
    const hasColon = queryIP.includes(':');

    if (hasDot && !hasColon) {
        return isIPv4(queryIP) ? 'IPv4' : 'Neither';
    }
    if (hasColon && !hasDot) {
        return isIPv6(queryIP) ? 'IPv6' : 'Neither';
    }
    return 'Neither';
};

function isIPv4(s) {
    const parts = s.split('.');
    if (parts.length !== 4) return false;

    return parts.every((part) => {
        if (part.length === 0 || part.length > 3) return false;
        if (part.length > 1 && part[0] === '0') return false;

        let value = 0;
        for (const ch of part) {
            if (ch < '0' || ch > '9') return false;
            value = value * 10 + (ch.charCodeAt(0) - 48);
        }
        return value <= 255;
    });
}

function isIPv6(s) {
    const parts = s.split(':');
    if (parts.length !== 8) return false;

    return parts.every((part) => {
        if (part.length === 0 || part.length > 4) return false;
        for (const ch of part) {
            const digit = ch >= '0' && ch <= '9';
            const lower = ch >= 'a' && ch <= 'f';
            const upper = ch >= 'A' && ch <= 'F';
            if (!digit && !lower && !upper) return false;
        }
        return true;
    });
}
Python 3 · 官方签名class Solution
class Solution:
    def validIPAddress(self, queryIP: str) -> str:
        has_dot = "." in queryIP
        has_colon = ":" in queryIP

        if has_dot and not has_colon:
            return "IPv4" if self._is_ipv4(queryIP) else "Neither"
        if has_colon and not has_dot:
            return "IPv6" if self._is_ipv6(queryIP) else "Neither"
        return "Neither"

    def _is_ipv4(self, s: str) -> bool:
        parts = s.split(".")
        if len(parts) != 4:
            return False

        for part in parts:
            if not 1 <= len(part) <= 3:
                return False
            if len(part) > 1 and part[0] == "0":
                return False
            if any(ch < "0" or ch > "9" for ch in part):
                return False
            if int(part) > 255:
                return False
        return True

    def _is_ipv6(self, s: str) -> bool:
        parts = s.split(":")
        if len(parts) != 8:
            return False

        allowed = set("0123456789abcdefABCDEF")
        return all(
            1 <= len(part) <= 4 and all(ch in allowed for ch in part)
            for part in parts
        )
C++ · 官方签名class Solution
class Solution {
public:
    string validIPAddress(string queryIP) {
        bool hasDot = queryIP.find('.') != string::npos;
        bool hasColon = queryIP.find(':') != string::npos;

        if (hasDot && !hasColon) {
            return isIPv4(queryIP) ? "IPv4" : "Neither";
        }
        if (hasColon && !hasDot) {
            return isIPv6(queryIP) ? "IPv6" : "Neither";
        }
        return "Neither";
    }

private:
    vector<string> splitPreserveEmpty(const string& s, char delimiter) {
        vector<string> parts;
        size_t start = 0;
        for (size_t i = 0; i <= s.size(); ++i) {
            if (i == s.size() || s[i] == delimiter) {
                parts.push_back(s.substr(start, i - start));
                start = i + 1;
            }
        }
        return parts;
    }

    bool isIPv4(const string& s) {
        vector<string> parts = splitPreserveEmpty(s, '.');
        if (parts.size() != 4) return false;

        for (const string& part : parts) {
            if (part.empty() || part.size() > 3) return false;
            if (part.size() > 1 && part[0] == '0') return false;

            int value = 0;
            for (char ch : part) {
                if (ch < '0' || ch > '9') return false;
                value = value * 10 + (ch - '0');
            }
            if (value > 255) return false;
        }
        return true;
    }

    bool isIPv6(const string& s) {
        vector<string> parts = splitPreserveEmpty(s, ':');
        if (parts.size() != 8) return false;

        for (const string& part : parts) {
            if (part.empty() || part.size() > 4) return false;
            for (char ch : part) {
                bool digit = ch >= '0' && ch <= '9';
                bool lower = ch >= 'a' && ch <= 'f';
                bool upper = ch >= 'A' && ch <= 'F';
                if (!digit && !lower && !upper) return false;
            }
        }
        return true;
    }
};

  • 若允许 IPv4 映射 IPv6，例如 ::ffff:192.0.2.1，如何扩展状态机？
  • 如何设计性质测试，覆盖空段、边界值与非法字符？

常见错误

  • 直接 parseInt，导致 1e2、+1 或前导零被宽松接受。
  • 切分时丢掉尾部空段，误判以分隔符结尾的输入。
  • IPv4 只检查小于 256，却忘记禁止前导零。
  • IPv6 使用“字母或数字”判断，错误接受 g-z。
  • 沿用完整互联网标准，错误接受题目未允许的 :: 压缩。
