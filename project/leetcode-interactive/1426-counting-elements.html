数元素

Counting Elements — 在数组里寻找能够把数值“接力”给下一位的元素。

难度EASY
题目权限会员题
函数countElements(arr)

Problem

题目描述

给你一个整数数组 arr。对于数组中的每个元素 x，如果数组中也存在 x + 1，那么这一次出现的 x 应被计数。返回满足条件的元素出现次数。

重复值按出现次数计算：只要某个值的后继存在，该值的每一次出现都贡献 1。

示例 1

输入：arr = [1, 2, 3]
输出：2
解释：1 的后继 2 存在，2 的后继 3 也存在；3 不计数。

示例 2

输入：arr = [1, 1, 3, 3, 5, 5, 7, 7]
输出：0
解释：数组里没有任一元素的下一整数。

示例 3

输入：arr = [1, 3, 2, 3, 5, 0]
输出：3
解释：满足条件的是 1、2 和 0。

示例 4

输入：arr = [1, 1, 2, 2]
输出：2
解释：两个 1 都应计数。

约束

  • 1 ≤ arr.length ≤ 1000
  • 0 ≤ arr[i] ≤ 1000

Solution

想好以后，再打开题解

先试着回答：判断某个整数是否存在，什么数据结构能把查询降到近似常数时间？

Editorial

哈希集合：先记住，再逐个询问

O(n) 时间 · O(n) 空间

核心洞察

题目不要求寻找位置，也不要求配对后消耗元素。对每个 x，我们只关心一个布尔问题：x + 1 是否至少出现过一次。因此可先把所有值放入哈希集合，再遍历原数组计数。

为什么仍遍历原数组？

集合会去重，而答案按元素出现次数计算。集合只承担“存在性查询”，计数必须遍历原数组。例如 [1,1,2] 中两个 1 都应贡献答案。

完整过程

  1. 建立集合：把 arr 中所有整数加入哈希集合 values。
  2. 扫描原数组：依次取出每个出现位置上的元素 x。
  3. 查询后继：若 values 包含 x + 1，答案加一。
  4. 返回计数：扫描结束后，答案恰好包含每个满足条件的出现位置。

正确性证明

充分性：算法只在集合含有 x + 1 时为当前元素 x 加一。集合由数组全部元素构成，所以被计数的元素一定满足题意。

必要性：若数组中某次出现的 x 满足题意，则 x + 1 必然属于数组，也必然在集合中。当扫描到该次出现时，算法一定将其计数。

结论：算法不多计也不漏计，返回值正确。

边界情况

  • 只有一个元素：不存在后继，答案为 0。
  • 全部相同：除非下一整数也出现，否则答案为 0。
  • 重复元素：每次出现独立计数。
  • 无序数组：集合查询与顺序无关。
  • 值为 1000：查询 1001 合法，只是集合中不存在。

复杂度

时间：期望 O(n)。建集合和扫描数组各一次，哈希查询平均为 O(1)。

空间：O(n)，集合最多保存数组中全部不同元素。

四种语言实现

JavaHashSet
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int countElements(int[] arr) {
        Set<Integer> values = new HashSet<>();
        for (int value : arr) {
            values.add(value);
        }

        int count = 0;
        for (int value : arr) {
            if (values.contains(value + 1)) {
                count++;
            }
        }
        return count;
    }
}
JavaScriptSet
/**
 * @param {number[]} arr
 * @return {number}
 */
var countElements = function(arr) {
    const values = new Set(arr);
    let count = 0;

    for (const value of arr) {
        if (values.has(value + 1)) {
            count++;
        }
    }

    return count;
};
Pythonset
from typing import List


class Solution:
    def countElements(self, arr: List[int]) -> int:
        values = set(arr)
        count = 0

        for value in arr:
            if value + 1 in values:
                count += 1

        return count
C++unordered_set
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    int countElements(vector<int>& arr) {
        unordered_set<int> values(
            arr.begin(), arr.end()
        );
        int count = 0;

        for (int value : arr) {
            if (values.count(value + 1) > 0) {
                ++count;
            }
        }

        return count;
    }
};

替代方案对比

方案时间额外空间取舍
哈希集合期望 O(n)O(n)直观、无需修改数组，是推荐方案。
排序 + 二分查找O(n log n)视排序实现而定可行，但要谨慎保留重复出现次数。
固定范围布尔表O(n + U)O(U)利用本题值域 0～1000；通用性较弱。
双重循环O(n²)O(1)能得到正确答案，但没有利用存在性查询结构。

面试追问

  • 如果内存严格受限，如何用排序降低额外空间？
  • 如果要统计 x + k，代码需要改哪里？
  • 如果数据以流的形式到达，能否一次遍历完成？需要记录哪些频次？
  • 哈希表最坏复杂度与平均复杂度有什么区别？

常见错误

  • 遍历集合而不是原数组，导致重复值少计。
  • 查找 x - 1，把方向写反。
  • 找到一个后继就从集合删除；题意不要求配对消耗。
  • 把“有多少种值满足条件”误当成“有多少个元素满足条件”。
