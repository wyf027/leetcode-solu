需要教语言的最少人数

有些好友正因语言不通而失联。你只能选定一门语言进行教学——需要教给多少人，才能让每一对好友都重新沟通？

中等贪心数组哈希表非付费题
↓ 先理解规则，再亲手推进演示
Problem

题目描述

一个社交网络中有 m 名用户及若干好友关系。只有当一对好友掌握至少一门共同语言时，他们才能沟通。

给定语言总数 n、二维数组 languages 和二维数组 friendships：语言编号为 1..n；languages[i] 表示用户 i + 1 掌握的语言；friendships[j] = [u, v] 表示用户 u 与 v 是好友。

你可以选择一门语言，教给若干用户，使所有给定的好友对都能沟通。返回需要教学的最少用户数。好友关系不具传递性。

约束

  • 2 <= n <= 500
  • languages.length == m，且 1 <= m <= 500
  • 1 <= languages[i].length <= n，其中语言编号在 [1, n] 内且互不相同
  • 1 <= friendships.length <= 500
  • 每对关系满足 1 <= u < v <= m，且所有好友关系唯一
Examples

官方示例

示例 1

输入：n = 2
languages = [[1],[2],[1,2]]
friendships = [[1,2],[1,3],[2,3]]
输出：1
解释：可教用户 1 语言 2，或教用户 2 语言 1。

示例 2

输入：n = 3
languages = [[2],[1,3],[1,2],[3]]
friendships = [[1,4],[1,2],[3,4],[2,3]]
输出：2
解释：把语言 3 教给用户 1 和用户 3。

Solution

题解：只统计失联关系涉及的人

核心洞察

已经拥有共同语言的好友无需处理。只有“没有任何共同语言”的好友对会限制选择；把这些关系的全部端点去重，得到必须关注的用户集合。选定语言 L 后，集合中不会 L 的人都必须学习它，因此枚举语言并取最小值即可。

完整过程

  1. 把每个用户会的语言放进集合，便于判断交集。
  2. 遍历好友关系；若两端没有共同语言，把两名用户加入 affected。
  3. 对每门语言 1..n，统计 affected 中已经会它的人数 known。
  4. 教学人数为 |affected| - known，取所有语言中的最小值。

正确性证明

对任意选定语言 L：每个失联好友对的两端都属于 affected。把 L 教给其中所有原本不会 L 的用户后，每个端点都会 L，所以所有失联关系都能沟通；原本互通的关系仍然互通，方案充分。

反之，若 affected 中某个不会 L 的用户未被教学，他至少属于一条原本失联的关系，而题目只允许教学 L；无法保证该关系通过 L 沟通。因此固定 L 时至少要教这些人。枚举所有 L 取最小值即为全局最优。

边界情况

  • 所有好友本来就能沟通：affected 为空，答案是 0。
  • 同一用户出现在多条失联关系中：必须用集合去重，只教学一次。
  • 某门语言无人掌握：该候选方案需要教给全部受影响用户。
  • 多个语言达到相同最优值：题目只返回人数，无需返回语言编号。

复杂度

令 m 为用户数，F 为好友关系数，S 为所有用户掌握语言数量总和。用布尔表或哈希集合检查语言时，筛选失联关系最坏为 O(F · n)；统计各语言为 O(S) 或 O(n · |affected|)。空间复杂度为 O(S + m)。

替代方案

可以直接对每门语言扫描所有失联关系并收集需教学端点，但会反复去重，逻辑更绕。也可用长度 n + 1 的布尔数组代替哈希集合；在 n <= 500 时，它通常更直接、更稳定。

面试追问

  • 若允许选择两门语言，状态和搜索空间如何变化？
  • 若教学每个用户的成本不同，应如何把计数改成成本求和？
  • 若好友关系动态增加，如何维护失联端点与语言频次？

常见错误

  • 把好友关系误当作可传递关系，按连通分量处理。
  • 统计所有用户而非仅统计失联好友涉及的用户。
  • 同一用户因多条失联关系被重复计数。
  • 固定某一门看似常见的语言而没有枚举全部 1..n。

import java.util.*;

class Solution {
    public int minimumTeachings(int n, int[][] languages, int[][] friendships) {
        int m = languages.length;
        boolean[][] knows = new boolean[m][n + 1];
        for (int user = 0; user < m; user++) {
            for (int language : languages[user]) {
                knows[user][language] = true;
            }
        }

        Set<Integer> affected = new HashSet<>();
        for (int[] friendship : friendships) {
            int u = friendship[0] - 1;
            int v = friendship[1] - 1;
            boolean canCommunicate = false;
            for (int language : languages[u]) {
                if (knows[v][language]) {
                    canCommunicate = true;
                    break;
                }
            }
            if (!canCommunicate) {
                affected.add(u);
                affected.add(v);
            }
        }

        int answer = affected.size();
        for (int language = 1; language <= n; language++) {
            int needTeaching = 0;
            for (int user : affected) {
                if (!knows[user][language]) needTeaching++;
            }
            answer = Math.min(answer, needTeaching);
        }
        return answer;
    }
}

var minimumTeachings = function(n, languages, friendships) {
    const known = languages.map(list => new Set(list));
    const affected = new Set();

    for (const [rawU, rawV] of friendships) {
        const u = rawU - 1;
        const v = rawV - 1;
        let canCommunicate = false;
        for (const language of known[u]) {
            if (known[v].has(language)) {
                canCommunicate = true;
                break;
            }
        }
        if (!canCommunicate) {
            affected.add(u);
            affected.add(v);
        }
    }

    let answer = affected.size;
    for (let language = 1; language <= n; language++) {
        let needTeaching = 0;
        for (const user of affected) {
            if (!known[user].has(language)) needTeaching++;
        }
        answer = Math.min(answer, needTeaching);
    }
    return answer;
};
from typing import List


class Solution:
    def minimumTeachings(
        self,
        n: int,
        languages: List[List[int]],
        friendships: List[List[int]],
    ) -> int:
        known = [set(items) for items in languages]
        affected = set()

        for raw_u, raw_v in friendships:
            u, v = raw_u - 1, raw_v - 1
            if known[u].isdisjoint(known[v]):
                affected.add(u)
                affected.add(v)

        answer = len(affected)
        for language in range(1, n + 1):
            need_teaching = sum(
                language not in known[user]
                for user in affected
            )
            answer = min(answer, need_teaching)

        return answer

class Solution {
public:
    int minimumTeachings(
        int n,
        vector<vector<int>>& languages,
        vector<vector<int>>& friendships
    ) {
        int m = static_cast<int>(languages.size());
        vector<vector<bool>> knows(m, vector<bool>(n + 1, false));
        for (int user = 0; user < m; ++user) {
            for (int language : languages[user]) {
                knows[user][language] = true;
            }
        }

        unordered_set<int> affected;
        for (const auto& friendship : friendships) {
            int u = friendship[0] - 1;
            int v = friendship[1] - 1;
            bool canCommunicate = false;
            for (int language : languages[u]) {
                if (knows[v][language]) {
                    canCommunicate = true;
                    break;
                }
            }
            if (!canCommunicate) {
                affected.insert(u);
                affected.insert(v);
            }
        }

        int answer = static_cast<int>(affected.size());
        for (int language = 1; language <= n; ++language) {
            int needTeaching = 0;
            for (int user : affected) {
                if (!knows[user][language]) ++needTeaching;
            }
            answer = min(answer, needTeaching);
        }
        return answer;
    }
