Problem brief

题意转述

给定一个按非递减顺序排列的整数数组 nums，在原数组中把每种数字只保留一次，且保持相对顺序。返回唯一元素数量 k，并保证 nums[0..k-1] 正好是去重后的结果；后面的槽位内容可以忽略。

官方样例 1

输入：nums = [1,1,2]

输出：k = 2, nums = [1,2,_]

官方样例 2

输入：nums = [0,0,1,1,1,2,2,3,3,4]

输出：k = 5, nums = [0,1,2,3,4,_,_,_,_,_]

约束：1 ≤ nums.length ≤ 3 × 10⁴；-100 ≤ nums[i] ≤ 100；nums 按非递减顺序排列。下划线表示该位置无需关心，不是实际字符串。

Core insight

有序性让重复值必然相邻

write 表示“下一个唯一值应该写入的位置”，所以 nums[0..write-1] 始终是已经确认的唯一前缀。read 扫到的值只需与前缀最后一项 nums[write-1] 比较：相同就跳过，不同就写入 nums[write] 并让 write 加一。

Invariant

nums[0..write-1] 始终有序且无重复。

Duplicate

相等时只移动 read，write 原地等待。

New value

不同就覆盖 nums[write]，再扩大前缀。

Complete process

完整解题过程

  1. 1. 数组非空，nums[0] 直接成为第一个唯一值，令 write = 1。
  2. 2. read 从 1 扫到 n - 1。
  3. 3. 比较 nums[read] 与 nums[write - 1]。
  4. 4. 若不同，将 nums[read] 写到 nums[write]，然后 write++。
  5. 5. 若相同，不写入，只继续移动 read。
  6. 6. 扫描结束后返回 write，它就是 k。

Boundary & complexity

边界与复杂度

  • 单元素：循环不执行，直接返回 1。
  • 全部相同：write 始终为 1。
  • 完全不同：每次写回同一位置，返回 n。
  • 负数：比较逻辑不受符号影响。
  • 时间：O(n)，read 单向扫描一次。
  • 额外空间：O(1)，原地覆盖。

Alternative

Set / 新数组

去重集合写起来简单，却需要 O(n) 额外空间，而且没有利用有序性，不符合原地修改要求。

Common mistakes

常见错误

  • 返回数组或新数组长度，而不是修改 nums 后返回 k。
  • 与 nums[read - 1] 比较，却没有维护有效前缀语义。
  • write 从 0 开始，覆盖或漏掉第一个元素。
  • 纠结 k 之后的内容，做了无意义清理。

Interview follow-up

高频追问

  • 为什么只比较前缀最后一个值就够？
  • 如何证明覆盖不会破坏尚未读取的数据？
  • 若每个值最多保留两次，条件如何改？
  • 如果数组未排序，这个方法还能用吗？

class Solution {
    public int removeDuplicates(int[] nums) {
        int write = 1;

        for (int read = 1; read < nums.length; read++) {
            if (nums[read] != nums[write - 1]) {
                nums[write] = nums[read];
                write++;
            }
        }
        return write;
    }
}
