分割连接字符串
Split Concatenated Strings

为每段选择方向，再寻找字典序最大的环形切口。

Problem

题意

给定字符串数组 strs。每个字符串可保持原样或反转；按数组顺序将它们首尾连接成环，再在任意字符之前切开。返回所有可能的线性字符串中字典序最大的一个。各段在环上的相对次序不可改变。

官方函数签名：String splitLoopedString(String[] strs)

官方示例 1

输入：strs = ["abc", "xyz"]
输出："zyxcba"
解释：选择 "cba" 和 "zyx" 构成环，从 z 前切开。

官方示例 2

输入：strs = ["abc"]
输出："cba"

约束

  • 1 <= strs.length <= 1000
  • 1 <= strs[i].length <= 1000
  • 全部字符串总长度不超过 1000
  • 字符串仅含小写英文字母

Solution

先思考，再揭晓

如果切口落在第 i 段，其他完整段还有理由选择字典序更小的方向吗？

Deep Dive

贪心定向 + 枚举断点

核心洞察

固定切口所在段后，其他段都完整出现，可独立取 max(s, reverse(s))。切口段被拆为后缀和前缀，必须枚举原向、反向以及每个字符位置。

完整过程

  1. 把每个字符串规范为原串与反串中字典序较大者。
  2. 枚举切口段 i。
  3. 枚举该段的原向/反向与切口 k。
  4. 构造：当前段后缀 + 后续规范段 + 前序规范段 + 当前段前缀。
  5. 保留字典序最大候选。

正确性

每个合法结果都对应某个切口段、方向和位置，枚举不会遗漏。固定三者时，其余段连续完整出现；把任一完整段换成两方向中字典序较大者，只会让第一个差异位置更大，不会使整体变小。因此规范化给出该固定切口下的最优结果，所有候选取最大即为全局最优。

边界与复杂度

单段、回文、重复字符无需特判。总长度为 N，共有 O(N) 个方向/切口组合，每次构造比较 O(N)，时间 O(N²)，额外空间 O(N)。

替代方案与追问

后缀数组或哈希/LCP 可尝试加速比较，但切口段的双方向仍需处理，在本题约束下不如直接枚举清晰。可追问：允许重排段时如何变化？怎样减少候选复制？为何切口段不能直接规范化？

常见错误

  • 只尝试切口段的较大方向。
  • 只在段边界切开。
  • 拼接时漏掉回绕后的前序段或当前段前缀。

class Solution {
  public String splitLoopedString(String[] strs) {
    int n = strs.length; String[] best = new String[n];
    for (int i=0;i<n;i++) {
      String r=new StringBuilder(strs[i]).reverse().toString();
      best[i]=strs[i].compareTo(r)>=0?strs[i]:r;
    }
    String ans="";
    for(int i=0;i<n;i++){
      String r=new StringBuilder(strs[i]).reverse().toString();
      for(String cur:new String[]{strs[i],r}) for(int k=0;k<cur.length();k++){
        StringBuilder c=new StringBuilder(cur.substring(k));
        for(int j=i+1;j<n;j++) c.append(best[j]);
        for(int j=0;j<i;j++) c.append(best[j]);
        c.append(cur,0,k);
        if(c.toString().compareTo(ans)>0) ans=c.toString();
      }
    }
    return ans;
  }
}
var splitLoopedString = function(strs) {
  const rev = s => [...s].reverse().join('');
  const best = strs.map(s => s > rev(s) ? s : rev(s));
  let ans = '';
  for (let i=0; i<strs.length; i++) {
    for (const cur of [strs[i], rev(strs[i])]) {
      for (let k=0; k<cur.length; k++) {
        const c = cur.slice(k) + best.slice(i+1).join('') +
          best.slice(0,i).join('') + cur.slice(0,k);
        if (c > ans) ans = c;
      }
    }
  }
  return ans;
};
class Solution:
    def splitLoopedString(self, strs: list[str]) -> str:
        best = [max(s, s[::-1]) for s in strs]
        ans = ""
        for i, original in enumerate(strs):
            for cur in (original, original[::-1]):
                for k in range(len(cur)):
                    cand = (cur[k:] + "".join(best[i+1:]) +
                            "".join(best[:i]) + cur[:k])
                    ans = max(ans, cand)
        return ans
