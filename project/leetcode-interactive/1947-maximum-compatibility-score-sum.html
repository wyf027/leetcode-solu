最大兼容性评分和

Maximum Compatibility Score Sum

答案相同，默契加一。怎样安排一对一配对，让整体的默契最高？

先理解问题，再展开下方题解。题解与算法演示默认收起。

01 / PROBLEM

题目说明

有 m 名学生和 m 名导师，每个人都回答了同一份含 n 个问题的问卷，答案只能为 0 或 1。二维数组 students[i] 和 mentors[j] 分别记录学生 i 与导师 j 的回答，编号均从 0 开始。

你需要让每名学生恰好对应一名导师，每名导师也只能对应一名学生。一对学生与导师的兼容性评分，是他们在相同问题上给出相同答案的位置数。返回所有合法配对方案中，兼容性评分总和的最大值。

计分示意：[1, 0, 1] 与 [0, 0, 1] 在第 2、3 个问题上相同，得 2 分。题目返回一个整数，无须返回具体配对。

输入与约束

  • m == students.length == mentors.length
  • n == students[i].length == mentors[j].length
  • 1 ≤ m, n ≤ 8
  • students[i][k] 和 mentors[j][k] 均为 0 或 1。

参数：students、mentors，均为 m × n 的二维整数数组。返回值：最大兼容性评分和（整数）。

02 / EXAMPLES

官方示例

示例 1

students = [[1,1,0],[1,0,1],[0,0,1]]
mentors = [[1,0,0],[0,0,1],[1,1,0]]

输出：8

学生 0 → 导师 2，得 3 分；学生 1 → 导师 0，得 2 分；学生 2 → 导师 1，得 3 分。总分为 3 + 2 + 3 = 8。

示例 2

students = [[0,0],[0,0],[0,0]]
mentors = [[1,1],[1,1],[1,1]]

输出：0

任意学生与任意导师在每个问题上都不相同，因此所有配对方案均为 0 分。

题解 · 用导师集合压缩配对历史

核心洞察

学生按 0、1、2… 的固定顺序分配。若已使用导师集合为 mask，则已经安排的学生数必然等于 mask 中 1 的数量，下一个学生就是 i = popcount(mask)。以后能选哪些导师，只取决于这个集合；到达同一集合的不同历史，只需保留最高得分。

先预计算 score[i][j]：学生 i 与导师 j 回答相同的位置数。定义 dp[mask] 为前 popcount(mask) 名学生恰好使用 mask 中导师的最大总分。

dp[0] = 0，其余状态 = -1（尚不可达）
i = popcount(mask)
对每个尚未使用的导师 j：
    next = mask | (1 << j)
    dp[next] = max(dp[next], dp[mask] + score[i][j])
答案 = dp[(1 << m) - 1]

完整过程

  1. 用三重循环构建 m × m 的评分矩阵，每对逐题比较。
  2. 创建长度 2ᵐ 的 dp 数组，只有空集合初始得分为 0。
  3. 按 mask 从小到大遍历非满集合，计算下一个学生编号 i。
  4. 枚举未被 mask 占用的导师 j，尝试向更大的集合 next 转移。
  5. 保留较大的候选分数；全体导师均已使用时得到答案。因为设置一个原本为 0 的位必然让 mask 变大，此遍历顺序满足依赖顺序。

为什么正确？
状态不变量：dp[mask] 是前 popcount(mask) 名学生使用恰好这组导师的最优得分。空集合时没有配对，最优分为 0，成立。
合法性：每次只给下一个学生选择一个未使用导师，因此没有重复使用导师，也不会漏掉或重复学生。
完备性：任意非空集合的合法方案中，最后一个学生必定对应集合内某个导师 j。移除这对配对后，剩下的方案恰好对应去掉 j 的前驱集合。算法枚举了所有这种前驱与最后配对，并取最大值，因此不会漏掉最优方案。
归纳结论：所有前驱都先被处理；由较小集合正确可得当前集合正确。满集合覆盖全部 m 名学生与导师，其最优分就是所求。


边界与复杂度
  • m = 1 时只比较唯一的一对；n = 1 时每对得分为 0 或 1。
  • 全为 0 分也是合法答案，所以用 -1 标记不可达，不能把 0 当作“尚未计算”。
  • 重复问卷仍属于不同的人，必须保留不同导师的位编号；多种最优方案只需返回同一最大分。
  • 评分范围为 0 到 mn，最大 64；四种语言中的整数范围均足够。
  • 预计算时间 O(m²n)，DP 时间 O(m · 2ᵐ)，合计 O(m²n + m · 2ᵐ)。JavaScript / Python 计算位数的额外 O(m · 2ᵐ) 不改变这个界。
  • 辅助空间 O(m² + 2ᵐ)。这里不包含页面为逐步回放而保存的快照，提交代码只保留评分矩阵和 dp。


替代方案
预计算评分后，回溯枚举导师的全部排列，时间可用 O(m · m!) 上界估计，额外递归空间 O(m)。m ≤ 8 时可行，逻辑直观。记忆化搜索以已用导师 mask 为键，可得到同样的状态压缩 DP 复杂度。规模明显增大时，可将问题建模为最大权完美二分图匹配，使用 O(m³) 的加权匈牙利算法，但实现更复杂。


常见错误
  • 逐个学生贪心选择最高分导师，可能占用后来学生唯一的高分选择。用例 05 中，学生 0 的两个选择都得 1 分，若先占导师 0，总分只有 1；选导师 1 则可得 1 + 2 = 3。
  • 把掩码的值当作学生编号；正确编号是掩码中 1 的个数。
  • 在满集合继续计算 score[m][j]，导致越界；循环在满集合前停止。
  • 混淆 m（人数）与 n（问题数）；状态位数是 m，评分比较次数是 n。
  • 用按位异或“添加”一个已使用的导师，反而会删除该位；先判断未使用，再使用按位或。


面试追问
  • 如何输出配对？更新最优值时记录前驱 mask 和导师 j，从满集合逆推，每次恢复学生 popcount(mask) − 1 的导师。
  • 问题有不同权重？相同答案累加问题权重即可，评分矩阵与转移结构不变；若允许负权，初始化不可达值应改为负无穷。
  • 导师数量更多？掩码改用导师总数作为位数，只扩展到已安排 m 名学生，取所有大小为 m 的集合中的最大值；状态规模也随导师数增长。
  • 能否用位运算加速评分？将问卷编码为 n 位整数，评分为 n − popcount(studentBits XOR mentorBits)。状态 DP 仍保持不变。

Java
import java.util.Arrays;

class Solution {
    public int maxCompatibilitySum(int[][] students, int[][] mentors) {
        int m = students.length, n = students[0].length;
        int[][] score = new int[m][m];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < m; j++) {
                for (int k = 0; k < n; k++) {
                    if (students[i][k] == mentors[j][k]) score[i][j]++;
                }
            }
        }
        int size = 1 << m;
        int[] dp = new int[size];
        Arrays.fill(dp, -1);
        dp[0] = 0;
        for (int mask = 0; mask < size - 1; mask++) {
            if (dp[mask] < 0) continue;
            int i = Integer.bitCount(mask);
            for (int j = 0; j < m; j++) {
                if ((mask & (1 << j)) != 0) continue;
                int next = mask | (1 << j);
                dp[next] = Math.max(dp[next], dp[mask] + score[i][j]);
            }
        }
        return dp[size - 1];
    }
}

/**

 * @param {number[][]} mentors
 * @return {number}

var maxCompatibilitySum = function(students, mentors) {
    const m = students.length, n = students[0].length;
    const score = Array.from({ length: m }, () => Array(m).fill(0));
    for (let i = 0; i < m; i++) {
        for (let j = 0; j < m; j++) {
            for (let k = 0; k < n; k++) {
                if (students[i][k] === mentors[j][k]) score[i][j]++;
            }
        }
    }
    const size = 1 << m;
    const dp = Array(size).fill(-1);
    dp[0] = 0;
    for (let mask = 0; mask < size - 1; mask++) {
        if (dp[mask] < 0) continue;
        let i = 0;
        for (let bits = mask; bits; bits &= bits - 1) i++;
        for (let j = 0; j < m; j++) {
            if (mask & (1 << j)) continue;
            const next = mask | (1 << j);
            dp[next] = Math.max(dp[next], dp[mask] + score[i][j]);
        }
    }
    return dp[size - 1];
};


Python 3
from typing import List

class Solution:
    def maxCompatibilitySum(self, students: List[List[int]],
                            mentors: List[List[int]]) -> int:
        m = len(students)
        score = [[sum(a == b for a, b in zip(student, mentor))
                  for mentor in mentors] for student in students]
        size = 1 << m
        dp = [-1] * size
        dp[0] = 0
        for mask in range(size - 1):
            if dp[mask] < 0:
                continue
            i = bin(mask).count("1")
            for j in range(m):
                if mask & (1 << j):
                    continue
                nxt = mask | (1 << j)
                dp[nxt] = max(dp[nxt], dp[mask] + score[i][j])
        return dp[-1]


C++
#include <algorithm>
#include <vector>
using namespace std;

class Solution {
public:
    int maxCompatibilitySum(vector<vector<int>>& students,
                            vector<vector<int>>& mentors) {
        int m = students.size(), n = students[0].size();
        vector<vector<int>> score(m, vector<int>(m));
        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < m; ++j) {
                for (int k = 0; k < n; ++k) {
                    score[i][j] += students[i][k] == mentors[j][k];
                }
            }
        }
        int size = 1 << m;
        vector<int> dp(size, -1);
        dp[0] = 0;
        for (int mask = 0; mask < size - 1; ++mask) {
            if (dp[mask] < 0) continue;
            int i = __builtin_popcount(static_cast<unsigned>(mask));
            for (int j = 0; j < m; ++j) {
                if (mask & (1 << j)) continue;
                int next = mask | (1 << j);
                dp[next] = max(dp[next], dp[mask] + score[i][j]);
            }
        }
        return dp.back();
    }
};
