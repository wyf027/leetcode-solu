同一天的第一个电话
和最后一个电话

First and Last Call On the Same Day

一天从谁的声音开始，又以谁的声音结束？
找到至少有一天，首通与末通电话对象相同的用户。

先独立思考；交互演示、推导与代码在底部题解中，默认收起。

01 / 题意

输入通话记录，输出用户 ID

给定表 Calls(caller_id, recipient_id, call_time)。每行表示拨出方与接听方在指定时刻发生的一次通话。

对每名用户，拨出和接听都算作通话。若他在至少一个自然日的最早和最晚通话对象相同，就将其 ID 放入结果的 user_id 列。结果去重，顺序不限。

当天只有一通电话时，它同时是第一通和最后一通。

输入结构 / 约束
字段类型
caller_idint
recipient_idint
call_timedatetime
  • 三个字段共同组成复合主键。
  • 每行描述一次双方通话。
  • 公开题面没有给出行数、ID 数值范围或同一用户时间戳唯一性的额外保证，这里不补造限制。

准备好拆解了吗？

按用户观察时间线，再阅读 SQL 与语义参考。

核心洞察：每个人都有自己的“当天”

把通话转换成双方各自的视角，按用户与日期分组，只检查当天的时间边界。中间与谁通话不影响结果。任意一个日期组满足，便可输出这个用户。

交互 / 双向通话时间线

原始方向 → 用户视角 → 时间边界

Tab 移动焦点，Enter / 空格操作按钮。自动播放每 1.8 秒推进。减少动态效果偏好下采用手动步骤。此处为教学模型，不执行数据库查询，不生成验证结论。

完整过程

  1. 使用 UNION ALL 合并拨出与接听视角，构造 user_id、peer_id、call_time。
  2. 按 user_id 与 DATE(call_time) 分区，分别求最早和最晚时间。
  3. 筛出位于首尾时刻的记录，中间记录不参与后续统计。
  4. 每个用户日期组要求 COUNT(DISTINCT peer_id) = 1。
  5. 最终 DISTINCT user_id，实现“至少一天满足”与跨天去重。

正确性

双向展开完整收集每个用户参与的所有通话。用户日期分区既不混入他人的通话，也不混入其他日期。MIN 与 MAX 恰好定位时间边界，筛选后保留且仅保留首尾时刻记录。边界对象集合大小为 1 当且仅当所有边界记录指向同一人，因此保留的日期组满足要求。对这些组的用户 ID 去重，恰好得到至少一天符合条件的用户集合。

边界与并列时间

  • 单通电话同时位于两个边界，只有一个对象，符合条件。
  • 某一天不符合不会抵消另一天符合；多个符合日期只贡献一个 ID。
  • 复合主键不能保证一个用户同一时间只有一通电话。公开题面未进一步定义并列语义。本页明确采用保守解释：保留所有首尾时刻记录，要求其对象一致。若业务指定其他并列策略，应先澄清。
  • 四种参考函数假定时间为统一的 YYYY-MM-DD HH:mm:ss 字符串，按同一时区自然日分组；不自行转换时区。

复杂度

n 条通话展开为 2n 条视角记录。常见窗口排序执行计划需要 O(n log n) 时间、O(n) 中间空间，实际开销取决于数据库计划。四语言参考均为分组排序，整体 O(n log n) 时间、O(n) 空间；哈希容器按期望复杂度计算，C++ 有序 map / set 和 Java TreeSet 的对数成本不改变该上界。

替代方案

双向 RANK 分别按时间升序、降序排名，保留任一排名为 1 的行，再统计对象。也可以先聚合最早与最晚时间，再连接回明细。内存版本可只维护每组的两个边界及其对象集合，省掉排序，在哈希模型下达到期望 O(n)。

常见错误

  • 只统计拨出方，漏掉接听方。
  • 分组遗漏日期，或遗漏用户。
  • 对全天对象去重，错误排除中间对象不同的情况。
  • 比较最小与最大对象 ID，忽视通话时间。
  • LAST_VALUE 未设置完整窗口帧，误把当前行当成末行；ROW_NUMBER 任意裁掉并列边界。
  • 忘记最终去重，或者要求用户每天都符合。

面试追问

若改成“所有有通话的日期都符合”，应按用户比较符合天数与总天数。若输入乱序且持续到来，可以维护用户日期的最早与最晚状态；迟到数据仍可更新。真实业务中的“同一天”需要先确定时区。优化数据库时应结合执行计划评估日期表达式、双向展开与索引成本。

MySQL 8 · 提交主体

WITH directed AS (
    SELECT caller_id AS user_id, recipient_id AS peer_id, call_time
    FROM Calls
    UNION ALL
    SELECT recipient_id, caller_id, call_time FROM Calls
), bounds AS (
    SELECT user_id, peer_id, call_time, DATE(call_time) AS day,
           MIN(call_time) OVER (
               PARTITION BY user_id, DATE(call_time)
           ) AS first_time,
           MAX(call_time) OVER (
               PARTITION BY user_id, DATE(call_time)
           ) AS last_time
    FROM directed
)
SELECT DISTINCT user_id
FROM bounds
WHERE call_time = first_time OR call_time = last_time
GROUP BY user_id, day
HAVING COUNT(DISTINCT peer_id) = 1;

JavaScript · 本地语义参考

// calls: Array<[number, number, string]>
function sameDayCalls(calls) {
  const groups = new Map();
  for (const [a, b, time] of calls) {
    for (const [user, peer] of [[a, b], [b, a]]) {
      const key = user + '|' + time.slice(0, 10);
      if (!groups.has(key)) groups.set(key, { user, events: [] });
      groups.get(key).events.push([time, peer]);
    }
  }
  const answer = new Set();
  for (const { user, events } of groups.values()) {
    events.sort((a, b) => a[0].localeCompare(b[0]));
    const first = events[0][0], last = events[events.length - 1][0];
    const peers = new Set(events
      .filter(([t]) => t === first || t === last)
      .map(([, peer]) => peer));
    if (peers.size === 1) answer.add(user);
  }
  return [...answer].sort((a, b) => a - b);
}

from collections import defaultdict
from typing import List, Tuple

def same_day_calls(calls: List[Tuple[int, int, str]]) -> List[int]:
    groups = defaultdict(list)
    for a, b, time in calls:
        groups[(a, time[:10])].append((time, b))
        groups[(b, time[:10])].append((time, a))
    answer = set()
    for (user, day), events in groups.items():
        events.sort()
        first, last = events[0][0], events[-1][0]
        peers = {peer for time, peer in events
                 if time == first or time == last}
        if len(peers) == 1:
            answer.add(user)
    return sorted(answer)

Java 17 · 本地语义参考

import java.util.*;

public class Solution {
    public record Call(int callerId, int recipientId, String callTime) {}
    private record Key(int user, String day) {}
    private record Event(String time, int peer) {}

    public List<Integer> sameDayCalls(List<Call> calls) {
        Map<Key, List<Event>> groups = new HashMap<>();
        for (Call c : calls) {
            add(groups, c.callerId(), c.recipientId(), c.callTime());
            add(groups, c.recipientId(), c.callerId(), c.callTime());
        }
        Set<Integer> answer = new TreeSet<>();
        for (var entry : groups.entrySet()) {
            List<Event> events = entry.getValue();
            events.sort(Comparator.comparing(Event::time));
            String first = events.get(0).time();
            String last = events.get(events.size() - 1).time();
            Set<Integer> peers = new HashSet<>();
            for (Event e : events) {
                if (e.time().equals(first) || e.time().equals(last))
                    peers.add(e.peer());
            }
            if (peers.size() == 1) answer.add(entry.getKey().user());
        }
        return new ArrayList<>(answer);
    }
    private void add(Map<Key, List<Event>> groups,
                     int user, int peer, String time) {
        Key key = new Key(user, time.substring(0, 10));
        groups.computeIfAbsent(key, k -> new ArrayList<>())
              .add(new Event(time, peer));
    }
}

#include <algorithm>
#include <map>
#include <set>
#include <string>
#include <utility>
#include <vector>
using namespace std;

struct Call { int caller_id, recipient_id; string call_time; };
class Solution {
public:
    vector<int> sameDayCalls(const vector<Call>& calls) {
        map<pair<int, string>, vector<pair<string, int>>> groups;
        for (const auto& c : calls) {
            string day = c.call_time.substr(0, 10);
            groups[{c.caller_id, day}].push_back({c.call_time, c.recipient_id});
            groups[{c.recipient_id, day}].push_back({c.call_time, c.caller_id});
        }
        set<int> answer;
        for (auto& [key, events] : groups) {
            sort(events.begin(), events.end());
            const string first = events.front().first;
            const string last = events.back().first;
            set<int> peers;
            for (const auto& [time, peer] : events)
                if (time == first || time == last) peers.insert(peer);
            if (peers.size() == 1) answer.insert(key.first);
        }
        return vector<int>(answer.begin(), answer.end());
    }
};
