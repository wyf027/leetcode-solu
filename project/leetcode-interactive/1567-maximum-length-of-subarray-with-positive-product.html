Problem 1567 · Maximum Length of Subarray With Positive Product

乘积为正数的
最长子数组长度

给定整数数组 nums，找出一个连续子数组，使其中所有元素的乘积为正，并返回它能够达到的最大长度。

阅读题目 打开符号实验室
目标 max len
1−2−34

不要急着计算巨大乘积。先观察正、负、零如何改变“符号”。往下动手试一试，再决定是否查看题解。

题目说明

只问长度，不问乘积值

子数组必须连续。空序列不产生正乘积；包含 0 的子数组乘积为 0，也不符合要求。

函数签名

getMaxLen(nums: integer[]) → integer

约束

  • 1 ≤ nums.length ≤ 10⁵
  • −10⁹ ≤ nums[i] ≤ 10⁹

示例 1

输入：nums = [1,-2,-3,4]
输出：4
解释：整个数组的乘积为 24，是正数。

示例 2

输入：nums = [0,1,-2,-3,-4]
输出：3
解释：[1,-2,-3] 的乘积为 6；0 不能包含在内。

示例 3

输入：nums = [-1,-2,-3,0,1]
输出：2
解释：[-1,-2] 或 [-2,-3] 的乘积为正。

独立题解

准备好看方法了吗？

建议先在上方推进几个步骤，猜出状态变化规则。下面的内容默认收起，展开后包含证明、复杂度与四种语言实现。

Solution

用两个长度保存符号历史

01

状态

pos 与 neg 分别表示以当前位置结尾、乘积为正或负的最长非空子数组长度。

02

翻转

乘以正数，符号不变；乘以负数，正负角色互换；遇到零，两个状态同时清空。

03

答案

每一步用 pos 更新全局最大值。只记录长度，完全避免整数乘积溢出。

核心洞察

在扫描到 nums[i] 时，我们并不关心乘积的具体数值，只关心它的符号。所有以 i 结尾的候选子数组中，对未来有用的只有两种代表：正乘积的最长长度和负乘积的最长长度。

完整过程

  1. 初始化 pos = 0、neg = 0、ans = 0。
  2. 若当前数大于 0：正状态直接延长；负状态只有原本存在时才能延长。
  3. 若当前数小于 0：旧负状态乘负数变正，旧正状态乘负数变负；单独的当前负数也构成长度为 1 的负状态。更新时必须使用旧值或先交换。
  4. 若当前数等于 0：任何包含它的乘积都不是正数，令两个状态归零。
  5. 用当前 pos 更新 ans，扫描结束后返回 ans。

正确性证明

循环不变式：处理完下标 i 后，pos 是以 i 结尾且乘积为正的最长非空子数组长度（不存在则为 0）；neg 对负乘积同理；ans 是区间 [0, i] 内所有正乘积子数组的最大长度。

初始化：扫描前没有任何非空子数组，三个值均为 0，命题成立。

保持：正数不改变已有乘积符号，负数使正负互换，零截断所有候选。转移恰好枚举了“延长旧候选”和“从当前元素开始”两种可能，并保留各符号的最长者，因此 pos、neg 的定义继续成立。随后取 ans = max(ans, pos)，全局命题也成立。

终止：最后一个元素处理后，ans 覆盖整个数组，故它就是所求最大长度。

边界情况

  • 全为 0：状态反复清零，答案为 0。
  • 只有一个负数：只有负状态，答案仍为 0。
  • 连续段内有偶数个负数：整个非零段可能都是答案。
  • 连续段内有奇数个负数：答案会舍弃第一个负数及其左侧，或最后一个负数及其右侧。
  • 元素绝对值很大：算法从不计算乘积，因此没有乘法溢出问题。

复杂度

时间 O(n)额外空间 O(1)

替代方案

也可以先按 0 切分非零段，统计每段负数数量：若为偶数，整段有效；若为奇数，分别移除到第一个负数的前缀或从最后一个负数开始的后缀，取较长者。它同样是 O(n)，但需要维护段边界与首尾负数位置；双状态动态规划更适合一次流式扫描。

面试追问

为什么负状态也必须保存？

负乘积当前不是答案，但它遇到下一个负数就会翻成正数，可能立刻产生最长候选。

为什么只保留最长状态？

对同一结尾与同一符号，未来乘上相同后缀时符号变化一致；较长候选永远不会劣于较短候选。

能否返回具体子数组？

可以。状态除长度外再记录起点，每次更新答案时保存最佳左右边界即可，渐进复杂度不变。

如果要求乘积为负呢？

扫描逻辑无需改变，改为用每一步的 neg 更新答案。

常见错误

  • 直接累计乘积，导致溢出且难以在符号失效时选择新起点。
  • 处理负数时先覆盖 pos，随后错误地用新值计算 neg。
  • 将乘积为 0 误认为正数，或遇到 0 后没有同时清空两个状态。
  • 把状态定义成“到当前位置为止”而非“必须以当前位置结尾”，导致无法正确转移。

四语言完整代码

JavaLeetCode 可提交
class Solution {
    public int getMaxLen(int[] nums) {
        int pos = 0, neg = 0, ans = 0;

        for (int x : nums) {
            if (x > 0) {
                pos = pos + 1;
                neg = neg == 0 ? 0 : neg + 1;
            } else if (x < 0) {
                int oldPos = pos;
                int oldNeg = neg;
                pos = oldNeg == 0 ? 0 : oldNeg + 1;
                neg = oldPos + 1;
            } else {
                pos = 0;
                neg = 0;
            }
            ans = Math.max(ans, pos);
        }
        return ans;
    }
}
