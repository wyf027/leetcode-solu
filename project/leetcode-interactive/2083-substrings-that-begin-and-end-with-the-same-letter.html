Substrings That Begin and End With the Same Letter

在一串字母里，寻找首尾呼应的连续片段。先理解哪些片段符合条件，再观察计数如何随右端点推进。

01 / 读懂题目

只看首尾，但片段必须连续

给定下标从 0 开始、仅包含小写英文字母的字符串 s，返回首字符与尾字符相等的非空连续子串数量。子串按起止位置计数；即使内容相同，出现在不同位置也分别计算。单个字符的首尾是它自己。

例如 "abca" 的整个字符串满足条件；中间字符不需要对称。

示例 1

输入：s = "abcba"
输出：7

5 个单字符子串，加上 "bcb" 和 "abcba"。

示例 2

输入：s = "abacad"
输出：9

6 个单字符子串，加上 "aba"、"aca"、"abaca"。

示例 3

输入：s = "a"
输出：1

只有单字符子串 "a"。

约束：1 ≤ s.length ≤ 10⁵；s 只含 a–z。接口：numberOfSubstrings(s: string) → long。

04 / 独立题解

准备好解释你的思路了吗？

展开后查看推导、正确性与四语言实现。

固定右端点，累计同字母起点

核心洞察

若当前位置字符为 c，之前已有 k 个 c，那么以当前位置结尾的合法子串恰有 k + 1 个：每个此前的同字母位置各贡献一个，当前位置自己再贡献一个。中间是什么字符完全不影响资格。

完整过程

  1. 用长度 26 的数组 freq 存储已扫描前缀内各字母出现次数，答案 answer = 0。
  2. 从左到右扫描 s，把当前字母映射到 0…25。
  3. 先执行 freq[index] += 1，把当前位置也作为合法起点；再执行 answer += freq[index]。
  4. 扫描结束后返回答案。不必创建任何子串。

正确性：按右端点划分，既不遗漏也不重复

循环不变式：处理完下标 r 后，freq 等于前缀 s[0…r] 中的字母频数，answer 等于右端点不超过 r 的合法子串数。初始前缀为空，频数和答案均为 0，不变式成立。

处理 r 时，每个满足 0 ≤ l ≤ r 且 s[l] = s[r] 的位置与一个合法区间 [l,r] 一一对应，共有更新后的 freq[s[r]] 个。此前统计的区间右端点更小，因此新增项与旧项不重叠；所有以 r 结尾的合法区间都被包含。故不变式保持。最后 r = n−1，覆盖全部右端点，得到完整答案。

边界与数值范围

  • 长度 1：贡献 1；不同位置的相同单字符都应计数。
  • 所有字母不同：答案为 n；全相同：答案为 n(n+1)/2。
  • 最大答案为 100000 × 100001 / 2 = 5,000,050,000，超出 32 位有符号整数。Java 用 long，C++ 用 long long，Python 整数自动扩展；JavaScript 的 Number 在本题上限内可精确表示整数。
  • 空串和非小写字符不属于官方输入范围；演示输入会单独限制字符与长度。

复杂度

时间 O(n)，每个字符只处理一次；额外空间 O(26) = O(1)。演示为显示具体区间会额外扫描前缀、切分短字符串，不属于提交算法的复杂度。

替代方案

先统计每个字符总频次 f，再求和 f(f+1)/2。这是 f 个单字符区间加上 C(f,2) 个不同端点组合，仍是 O(n) 时间、O(1) 空间。Java / C++ 乘法必须先提升到 64 位。另一种直接枚举所有 l ≤ r 并比较首尾的方法需要 O(n²) 时间，在最大规模下不合适。

常见错误

  • 把首尾相等当成回文条件，错误排除 "abca"。
  • 先累加旧频次却忘记加 1，漏掉每个单字符子串。
  • 用集合按字符串内容去重，丢掉不同位置的合法区间。
  • 实际构造每个子串，浪费时间和空间；只比较端点即可计数。
  • 使用 32 位答案或让公式乘法先以 32 位计算，产生溢出。

面试追问

  • 流式输入？保留频数和答案，每到一个字符 O(1) 更新。
  • 只统计长度至少 2？累加更新前的频数，或从最终结果减去 n。
  • 查询某个区间内的答案？为 26 个字符建立前缀频数，每次求区间各字符频数，再累加组合公式；预处理 O(26n)、查询 O(26)。
  • 字符集扩大？用哈希表，空间 O(不同字符数)；同时明确 Unicode 码点与用户感知字符的区别。

四语言完整提交代码

遵循官方元数据的方法名与参数。以下实现尚未执行或提交验证。

Java

class Solution {
    public long numberOfSubstrings(String s) {
        int[] freq = new int[26];
        long answer = 0L;
        for (int r = 0; r < s.length(); r++) {
            int index = s.charAt(r) - 'a';
            freq[index]++;
            answer += freq[index];
        }
        return answer;
    }
}

    }
    return answer;
};

Python

class Solution:
    def numberOfSubstrings(self, s: str) -> int:
        freq = [0] * 26
        answer = 0
        for ch in s:
            index = ord(ch) - ord('a')
            freq[index] += 1
            answer += freq[index]
        return answer
