01 · 案情陈述

任务是什么

给定长度为 n 的整数数组 nums。数组中的每个整数都在 [1, n] 内，并且每个整数只出现一次或两次。

返回所有恰好出现两次的整数。答案顺序不限。

目标限制

算法应在 O(n) 时间内完成，并仅使用常量级辅助空间；返回结果本身占用的空间不计。

约束

  • n == nums.length
  • 1 <= n <= 105
  • 1 <= nums[i] <= n
  • nums 中每个元素出现一次或两次

输出：[2,3]
示例 2

输出：[1]
示例 3
输入：nums = [1]
输出：[]

03 · 观察记录

实验中值得留意的三件事

范围就是地址

值在 1 到 n 内，因此每个值都能稳定映射到数组中的一个下标。

正负号是状态

不改变绝对值，就能借用符号记录某个映射位置是否已经被访问。

再次命中是证据

若指向的位置早已是负数，说明同一个原值此前已经出现过。

05 · 解密档案

原地负号标记

核心洞察

对当前值 x = abs(nums[i])，把下标 x - 1 当作它专属的“访问位”。首次遇到 x 时将该位置变为负数；再次遇到 x 时会发现它已经是负数，于是 x 就是重复值。

完整过程

  1. 从左到右遍历数组，读取当前元素绝对值 x。
  2. 计算它的映射下标 index = x - 1。
  3. 若 nums[index] 大于 0，将它取负，代表 x 已出现。
  4. 若 nums[index] 小于 0，把 x 加入答案；无需再次翻转。

为什么必须取绝对值

某个数组位置可能已被先前的值改成负数。遍历后来到这个位置时，负号只是标记，不属于原始值；用绝对值才能恢复真正要映射的 x。

复杂度

O(n)时间：只遍历一次
O(1)辅助空间：答案不计

正确性证明

标记含义：对任意值 x，位置 x - 1 为负，当且仅当遍历过的前缀中已经出现过 x。

首次出现：其映射位置尚为正，算法将其取负，建立上述标记，且不会误加入答案。

第二次出现：映射位置已为负，算法识别到先前出现并将 x 加入答案。题设保证每个值最多出现两次，所以每个重复值只会加入一次。

结论：遍历结束时，答案恰好包含全部且仅包含出现两次的值。

边界情况

  • 数组仅含一个元素：只做一次标记，答案为空。
  • 没有重复值：所有映射位置都只被首次命中。
  • 重复值相邻：第二个元素会立即命中负数标记。
  • 映射位置恰好是当前下标：先读取绝对值再修改，过程仍成立。
  • 算法会改变输入数组的符号；若调用方要求保留原数组，需要结束后恢复或改用其他方案。

四种语言完整代码

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> findDuplicates(int[] nums) {
        List<Integer> answer = new ArrayList<>();

        for (int i = 0; i < nums.length; i++) {
            int value = Math.abs(nums[i]);
            int index = value - 1;

            if (nums[index] < 0) {
                answer.add(value);
            } else {
                nums[index] = -nums[index];
            }
        }
        return answer;
    }
}

替代方案

  • 哈希集合：直观且不修改输入，但需要 O(n) 额外空间。
  • 排序后扫描：可用 O(1) 额外空间（原地排序），但时间为 O(n log n)，也会改变数组顺序。
  • 循环置换：把值 x 尽量放到 x - 1 处，再扫描错位元素；同为 O(n) 时间、O(1) 辅助空间，但交换逻辑更复杂。

常见错误

  • 直接用 nums[i] - 1 作下标，忘记该值可能已经是负数。
  • 把映射下标写成 x，造成越界；值域 1..n 对应下标 0..n-1。
  • 第二次命中时再次翻转为正，破坏“已经出现”的状态。
  • 声称 O(1) 空间，却额外使用了长度为 n 的计数数组或集合。

面试追问

如果不能修改输入数组？

通常需要放宽空间或时间限制，例如使用哈希集合获得 O(n) 时间、O(n) 空间；也可先澄清是否允许排序副本。

如果元素可能出现三次以上？

当前逻辑会把同一值多次加入答案。可按题意改为计数、恢复标记或采用其他编码；先确认要返回一次还是统计次数。

如何恢复输入数组？

算法结束后再遍历一次，把所有元素替换为绝对值，总时间仍为 O(n)。

为什么输出空间不计入 O(1)？

答案规模由问题本身决定，复杂度约束通常只衡量算法为工作过程额外申请的辅助存储。
