反转链表

将单链表的节点顺序原地反转，并返回新的头节点。关键不在值，而在每一次安全地重连 next 指针。

题目

输入链表 1 → 2 → 3 → 4 → 5，输出 5 → 4 → 3 → 2 → 1。节点数可为零；不能丢失仍未处理的后半段链表。

真正要守住的状态

prev：已反转部分的头；curr：尚未处理部分的头；next：临时保存的后继。

核心洞察

每轮只翻转一条边：先保存 curr.next，再令它指向 prev，最后整体向前推进。保存后继是避免断链的唯一前提。

迭代过程

  1. 1. 初始化 prev = null，curr = head。
  2. 2. 保存 next = curr.next，防止后段丢失。
  3. 3. 令 curr.next = prev，完成这一条边的反向。
  4. 4. prev = curr、curr = next，直到 curr 为空。

边界、复杂度与替代

  • 空链表：直接返回 null。
  • 一个节点：循环不破坏其 next，原样返回。
  • 复杂度：每个节点访问一次，时间 O(n)，额外空间 O(1)。
  • 替代方案：递归写法更短，但会消耗 O(n) 调用栈，超长链表优先迭代。

四语言实现

所有版本都保留 next，再修改指针。

面试追问与常见错误

面试追问

  • 如何反转指定区间？
  • 如何每 k 个节点反转一次？
  • 怎样判断链表是否有环，且不破坏链表？

常见错误

  • 未保存后继就覆盖 curr.next。
  • 推进顺序错误，导致重复节点或死循环。
  • 递归基例遗漏 null。

while curr != null: next = curr.next; curr.next = prev; prev = curr; curr = next。循环结束时 prev 正是新头节点。
