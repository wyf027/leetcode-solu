01 / 理解问题

只问能否到达

给定一个有 n 个顶点的无向图，顶点编号为 0 到 n - 1。数组 edges 中的每项 [u, v] 表示可以沿这条边从 u 到 v，也可以从 v 到 u。图中没有重复边，也没有连接顶点自身的边。

判断从 source 到 destination 是否存在路径，存在返回 true，否则返回 false。无需返回具体路线。

validPath(n, edges, source, destination) → boolean

官方示例 1 · 连通

n = 3
edges = [[0,1],[1,2],[2,0]]
source = 0
destination = 2

输出：true

可以直接走 0 → 2，也可以走 0 → 1 → 2。

官方示例 2 · 分离

n = 6
edges = [[0,1],[0,2],[3,5],[5,4],[4,3]]
source = 0
destination = 5

输出：false

0 所在的区域与 5 所在的区域之间没有连接。

约束

  • 1 ≤ n ≤ 2 × 10⁵
  • 0 ≤ edges.length ≤ 2 × 10⁵；每个 edges[i].length = 2。
  • 0 ≤ uᵢ, vᵢ ≤ n - 1，且 uᵢ ≠ vᵢ。
  • 0 ≤ source, destination ≤ n - 1。
  • 没有重复边，没有自环；图不一定连通。

用 BFS 扩展起点的可达区域

核心洞察：只要不断沿边扩展，最终发现的顶点恰好就是起点所在的连通分量。用队列保存待处理顶点，在入队时标记已发现，避免环导致反复入队。

完整过程
  1. 建立邻接表。对于每条 [u, v]，同时添加 u → v 和 v → u。
  2. 把 source 入队，并将其标记为已发现。
  3. 队列非空时弹出队首 u。如果 u 就是 destination，返回 true。
  4. 遍历 u 的所有邻居，将未发现的邻居标记后入队。
  5. 队列耗尽仍未找到目标，返回 false。
示例 2 的邻接顺序下，依次处理 0、1、2，队列随后耗尽。3、4、5 没有被发现。
为什么正确
可靠性：起点显然可达；每个新入队的点，都通过一条边连接到已可达的点。因此所有入队顶点都可从起点到达，取出目标时返回 true 是正确的。
完整性：假设一个可达点没有被发现，取一条从起点到它的路径。路径上第一个未发现点的前驱必然已发现；前驱被取出时就会发现这个点，产生矛盾。
终止性：每个顶点至多入队一次，有限个顶点处理完成后必然结束。因此队列耗尽意味着目标不可达。


复杂度
令 V = n，E = edges.length。
时间 O(V + E)：初始化邻接表，记录双向边，每个顶点至多处理一次，每条边至多扫描两次。
空间 O(V + E)：邻接表、访问标记、队列。提前找到目标也不改变最坏界限。
边界与错误
  • source = destination 时，零条边的路径也有效。
  • 没有边且起终点不同，返回 false。
  • 只添加单向边会漏掉合法路线。
  • 入队时标记，不能无限重复访问环。
  • JS 用头索引，避免反复 shift 的搬移成本。
  • 20 万节点链不宜递归遍历，以免栈溢出。
替代方案与追问
迭代 DFS：队列换栈，仍为 O(V + E)，同样能判断可达性。
并查集：合并边两端，再比较根。按大小合并与路径压缩的时间为 O(V + E α(V))，空间 O(V)。
需要最短路径？BFS 保存 parent，沿父链逆推；无权图首次发现时距离最短。多次查询？预先标记连通分量，每次 O(1)；动态删边不能直接靠普通并查集解决。

Java
import java.util.*;

class Solution {
    public boolean validPath(int n, int[][] edges, int source, int destination) {
        List<List<Integer>> graph = new ArrayList<>(n);
        for (int i = 0; i < n; i++) graph.add(new ArrayList<>());
        for (int[] edge : edges) {
            graph.get(edge[0]).add(edge[1]);
            graph.get(edge[1]).add(edge[0]);
        }
        boolean[] seen = new boolean[n];
        ArrayDeque<Integer> queue = new ArrayDeque<>();
        queue.addLast(source);
        seen[source] = true;
        while (!queue.isEmpty()) {
            int u = queue.removeFirst();
            if (u == destination) return true;
            for (int v : graph.get(u)) {
                if (!seen[v]) {
                    seen[v] = true;
                    queue.addLast(v);
                }
            }
        }
        return false;
    }
}

/**
 * @param {number} n
 * @param {number[][]} edges
 * @param {number} source
 * @param {number} destination
 * @return {boolean}

var validPath = function(n, edges, source, destination) {
    const graph = Array.from({ length: n }, () => []);
    for (const [u, v] of edges) {
        graph[u].push(v);
        graph[v].push(u);
    }
    const seen = new Uint8Array(n);
    const queue = [source];
    seen[source] = 1;
    for (let head = 0; head < queue.length; head++) {
        const u = queue[head];
        if (u === destination) return true;
        for (const v of graph[u]) {
            if (!seen[v]) {
                seen[v] = 1;
                queue.push(v);
            }
        }
    }
    return false;
};


Python 3
from collections import deque
from typing import List

class Solution:
    def validPath(self, n: int, edges: List[List[int]],
                  source: int, destination: int) -> bool:
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)
        seen = [False] * n
        seen[source] = True
        queue = deque([source])
        while queue:
            u = queue.popleft()
            if u == destination:
                return True
            for v in graph[u]:
                if not seen[v]:
                    seen[v] = True
                    queue.append(v)
        return False


C++
#include <vector>
#include <queue>
using namespace std;

class Solution {
public:
    bool validPath(int n, vector<vector<int>>& edges,
                   int source, int destination) {
        vector<vector<int>> graph(n);
        for (const auto& edge : edges) {
            graph[edge[0]].push_back(edge[1]);
            graph[edge[1]].push_back(edge[0]);
        }
        vector<bool> seen(n, false);
        queue<int> q;
        q.push(source);
        seen[source] = true;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            if (u == destination) return true;
            for (int v : graph[u]) {
                if (!seen[v]) {
                    seen[v] = true;
                    q.push(v);
                }
            }
        }
        return false;
    }
};
