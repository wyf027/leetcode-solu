将数组分割成和相等的子数组

Split Array with Equal Sum · 数组 / 哈希表 / 前缀和

题目

给定整数数组 nums，判断能否选出三个下标 i、j、k，满足 0 < i、i + 1 < j、j + 1 < k、k < n - 1，删除这三个位置后，余下的四个非空连续片段具有相同元素和：

sum(0..i-1) = sum(i+1..j-1) = sum(j+1..k-1) = sum(k+1..n-1)

函数：boolean splitArray(int[] nums)

示例 1

输入：nums = [1,2,1,2,1,2,1]
输出：true
解释：取 i=1、j=3、k=5，四段均为 [1]，和为 1。

示例 2

输入：nums = [1,2,1,2,1,2,1,2]
输出：false

约束

  • 7 ≤ nums.length ≤ 2000
  • -10⁶ ≤ nums[i] ≤ 10⁶
  • 数组可含负数，不能依靠单调性或滑动窗口。

交互演示：固定中间切口，左右配对

题解

核心洞察

固定中间删除位置 j。枚举左切口 i，把“第一段和等于第二段和”的目标和放入集合；再枚举右切口 k，若第三、第四段和相等且目标和存在于集合，就找到了答案。

完整过程

  1. 构造前缀和 P，令 P[t] 为前 t 个元素之和。
  2. 枚举 j = 3..n-4。
  3. 枚举 i = 1..j-2；若 P[i] = P[j]-P[i+1]，保存该和。
  4. 枚举 k = j+2..n-2；若 P[k]-P[j+1] = P[n]-P[k+1] 且集合包含该和，返回 true。

正确性

集合恰好记录当前 j 左侧所有合法 i 对应的共同和。右侧检查恰好验证某个 k 的后两段相等；命中集合时四段同和。反之，任何合法三切口在枚举到其 j 时，左侧和必被加入，右侧检查必命中，因此算法不会漏解。

边界与复杂度

长度小于 7 时不可能形成四个非空片段。负数和零均可由前缀和正确处理。时间复杂度 O(n²)，额外空间 O(n)。

替代方案

直接枚举 i,j,k 为 O(n³)；滑动窗口对负数不成立；也可用映射记录更多配对信息，但没有必要。

常见错误

  • 把被删除的 nums[i]、nums[j]、nums[k] 算入片段。
  • 允许相邻切口，产生空片段。
  • 用 32 位前缀和导致溢出（代码中使用 64 位）。
  • 跨不同 j 复用集合，造成错误匹配。

面试追问

  • 若要求返回全部三元组，如何修改数据结构？
  • 若元素都非负，能否利用单调性优化常数？
  • 为什么固定中间切口比固定左切口更自然？
