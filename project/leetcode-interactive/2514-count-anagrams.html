Count Anagrams

字母可以重排，但每个单词都有自己的边界。
当重复字母彼此无法区分时，你能数清所有不同的句子吗？

输入：字符串 s输出：整数模数：1,000,000,007

01 / PROBLEM

题意与规则

给定由一个或多个单词构成的字符串 s，相邻单词之间恰有一个空格。构造字符串 t 时，只能重新排列每个单词内部的字母；第 i 个单词必须保留原来第 i 个单词的字母及其出现次数。

返回不同的 t 的数量，对 109 + 7 取余。相同字母交换位置不会产生新字符串。

"abc def" → "acb dfe" 合法。
"def cab" 交换了单词，不合法；"adc bef" 跨越单词边界移动字母，也不合法。

02 / CONSTRAINTS

输入边界

  • 1 ≤ s.length ≤ 100,000，长度包含空格。
  • s 只含小写英文字母和空格。
  • 相邻单词用单个空格隔开。
  • 字符串由非空单词组成，不含首尾空格。

04 / INSIGHT

先去掉重复，再组合单词

长度为 m 的单词，如果每个字母都带有独立编号，有 m! 种排列。去掉编号后，出现 c 次的同一个字母有 c! 种互换方式，全都对应同一个可见结果，所以要除以每种字母的频次阶乘。

单词方案数 = m! / (cₐ! × cᵦ! × … × c𝓏!)
整句方案数 = 各单词方案数的乘积

将所有单词的分子合并为 N，所有分母合并为 D，最后只需求一次逆元：答案 = N × DP−2 mod P，其中 P = 1,000,000,007。

不必预计算阶乘数组。读取一个字母时，当前词长度由 k−1 变为 k，给 N 乘 k；该字母频次由 c−1 变为 c，给 D 乘 c。依次相乘就自然形成了所需的阶乘。遇到空格只清空当前词长度与频次数组，保留 N 和 D。

完整过程

  1. 初始化 N = D = 1、词长 k = 0、26 个频次为 0。
  2. 遇到字母：k 加 1，N 乘 k；对应频次 c 加 1，D 乘 c。两次乘法均对 P 取模。
  3. 遇到空格：将 k 与所有频次清零。此前累积的 N、D 不变。
  4. 全部字符读完后，用快速幂计算 DP−2 mod P，并乘 N 取模。

too hot：第一词贡献 3!/2! = 3；第二词贡献 3! = 6。整体 N = 6 × 6 = 36、D = 2，得到 18。

为什么能用逆元？

P 是素数，且所有词长和频次至多 105，都小于 P，因此分母的每个因子都不被 P 整除，D 模 P 非零。由费马小定理，DP−2 是 D 的乘法逆元。在模运算里用它代替除法。

正确性证明

  1. 单词计数正确：给重复字母编号后有 m! 种排列；每个可见排列恰好对应 ∏c! 种编号排列，故不同单词数为 m!/∏c!。
  2. 累乘不变量：处理任意前缀后，N 是所有完整单词词长阶乘与当前词前缀词长阶乘之积；D 是这些词各字母频次阶乘之积。新增字母使词长与对应频次各增长一次，分别乘入新的长度和频次即可保持不变量。空格只开启下一个词。
  3. 整句一一对应：从每个位置各选一种合法单词排列，就唯一确定一个结果字符串；不同选择至少在一个位置不同，因此按乘法原理相乘。
  4. 模运算等价：由不变量与乘法原理，最终整数答案为 N/D。分母可逆，故以模逆元替换整数除法可得到该答案对 P 的余数。

边界与复杂度

  • 一个字母：分子和分母均为 1。
  • 全部相同：每一步长度与频次相等，最终相消为 1。
  • 全是单字母词：每词只有一种选择，总数为 1。
  • 最后一个词不需要额外结算；其阶乘因子已随字符加入。
  • 设 n 为字符串长度：时间 O(n + log P)；固定模数下视为 O(n)。频次数组重置最多 26 次赋值/空格。
  • 额外空间 O(26) = O(1)；四份实现都直接扫描输入，不使用分词列表或阶乘表。大整数按固定模数的字长计算成本。

替代方案

  • 阶乘 + 逆阶乘预处理：准备 0 到 n 的表，再逐词查询。时间 O(n + log P)，空间 O(n)，适合大量相关查询复用表。
  • 逐词求逆元：每词独立计算多重集排列数后相乘，易理解；w 个词时多出 O(w log P) 的快速幂开销。
  • 组合数选位置：依次给各类字母选择空位，乘上 C(m,c₁)、C(m−c₁,c₂) 等；与阶乘公式等价。
  • 枚举并去重：最坏阶乘级数量，只适用于极短输入的概念说明，不适合本题上限。

四语言完整实现

均采用官方方法签名，直接扫描字符串，最后仅求一次逆元。以下代码仅生成，所有验证待补。JavaScript 使用 BigInt 防止乘积超过 Number 的安全整数范围。

Java

class Solution {
    private static final long MOD = 1_000_000_007L;

    private long power(long a, long e) {
        long result = 1;
        while (e > 0) {
            if ((e & 1) != 0) result = result * a % MOD;
            a = a * a % MOD;
            e >>= 1;
        }
        return result;
    }

    public int countAnagrams(String s) {
        long numerator = 1, denominator = 1;
        int length = 0;
        int[] counts = new int[26];
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == ' ') {
                length = 0;
                java.util.Arrays.fill(counts, 0);
            } else {
                length++;
                int count = ++counts[ch - 'a'];
                numerator = numerator * length % MOD;
                denominator = denominator * count % MOD;
            }
        }
        return (int) (numerator * power(denominator, MOD - 2) % MOD);
    }
}

/**

var countAnagrams = function(s) {
    const MOD = 1000000007n;
    function power(a, e) {
        let result = 1n;
        while (e > 0n) {
            if (e & 1n) result = result * a % MOD;
            a = a * a % MOD;
            e >>= 1n;
        }
        return result;
    }
    let numerator = 1n, denominator = 1n;
    let length = 0;
    const counts = Array(26).fill(0);
    for (let i = 0; i < s.length; i++) {
        if (s[i] === ' ') {
            length = 0;
            counts.fill(0);
        } else {
            length++;
            const count = ++counts[s.charCodeAt(i) - 97];
            numerator = numerator * BigInt(length) % MOD;
            denominator = denominator * BigInt(count) % MOD;
        }
    }
    return Number(numerator * power(denominator, MOD - 2n) % MOD);
};

常见错误

  • 对整个句子的字母一起计数：错误地允许字母跨词移动。
  • 只计算 m!：重复字母被重复计数。
  • 在取模后直接做普通除法：余数不能这样相除，必须使用逆元。
  • 遇到空格清空累计分子、分母：会丢失前面单词的贡献。只清空当前词状态。
  • Java / C++ 用 32 位整型承接乘积会溢出；应使用 long / long long。
  • JavaScript 用 Number 计算模乘，约 1018 的中间结果会丢精度；BigInt 不能和 Number 混乘，最后取模后再转回 Number。

面试追问

  • 模数是合数怎么办？费马小定理不适用，分母可能不可逆；需针对模数做质因子指数处理，并结合互素部分和中国剩余定理等方法。
  • 词长达到 P 呢？阶乘可能含 P，分母余数为零；当前方法的可逆前提失效，需要单独处理 P 的因子。
  • 很多字符串查询如何优化？在总长度、最大词长与内存预算允许时复用阶乘及逆阶乘表。
  • 为什么只求一次逆元？可逆元素乘积的逆等于逆元的乘积，所以可先把所有分母乘起来。
  • 能流式处理吗？可以，保留两个模累积量、词长和 26 个频次即可，空格处清空词内状态。
