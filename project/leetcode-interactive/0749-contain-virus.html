隔离病毒

Contain Virus

任务简报

01 / BRIEF

世界是一张 m × n 的二进制网格 isInfected：0 表示未感染，1 表示感染。两个四方向相邻单元的共享边上最多可建一面墙。

每晚，未被墙阻挡的病毒会传播到相邻的未感染单元。资源有限：每天只能完整隔离一个连通感染区域，并且必须选择“下一晚会威胁最多未感染单元”的区域；题目保证这个选择唯一。

返回最终建造的墙数。若整个世界最终都会感染，则返回在完全感染前已经使用的墙数。

containVirus(isInfected: integer[][]) → integer

约束

  • m == isInfected.length
  • n == isInfected[i].length
  • 1 ≤ m, n ≤ 50
  • 每个单元只可能是 0 或 1
  • 在题目描述的过程中，威胁最多未感染单元的感染区域始终严格唯一
计数口径
墙建在单元之间的边上；同一个未感染单元若与感染区共享两条边，需要两面墙。

完整题解

04 / SOLUTION

核心洞察

一次遍历感染网格时，要为每个连通区域收集三份数据：

  • 区域单元 cells：若该区域被选中，把这些位置标记为已隔离。
  • 威胁集合 frontier：相邻的未感染坐标，必须去重；选择依据是它的大小。
  • 边界墙数 perimeter：感染单元到未感染单元的相邻边总数，不去重；答案增加的是它。
“威胁单元数”与“墙数”不是同一个量：一个未感染单元可能沿多条边接触同一区域。

完整过程

  1. 扫描所有值为 1 的单元，用 DFS/BFS 找出每个感染连通块。
  2. 对区域的每条四方向边分类：遇到 0，加入威胁集合并把墙数加一；遇到 1，继续遍历。
  3. 选出威胁集合最大的唯一区域，把其墙数累加到答案，并把区域内单元标记为 -1。
  4. 其余区域同时扩散：把各自威胁集合中的所有位置改为 1，随后进入下一天。
  5. 若已不存在可被感染的未感染单元，则结束模拟。

正确性说明

  1. 区域统计准确：连通遍历恰好访问当前所有感染连通块；检查每条邻边，因此 frontier 正好是下一晚可能感染的不同单元，perimeter 正好是阻断该区域所需的墙数。
  2. 每日决策符合规则：题目规定隔离威胁单元最多的区域，且保证唯一；按 frontier 大小取最大值恰好得到该区域。
  3. 状态转移准确：选中区域被标为 -1，之后不再传播；其他区域的 frontier 全部置为感染，等价于同时经历一晚传播。
  4. 归纳结论：初始网格一致；若某天开始时模拟状态正确，上述统计、隔离与传播会得到真实的下一天状态。故终止时累计墙数就是题目要求。

复杂度与边界

令 S = m × n。每一天扫描网格与所有邻边需要 O(S)；天数不超过 O(S)，总时间为 O(S²)，额外空间为 O(S)。

  • 全为 0：没有感染区，返回 0。
  • 全为 1：没有可扩散边界，无需建墙，返回 0。
  • 单个感染区：直接按所有感染—未感染邻边建墙。
  • -1 只是实现中的“已隔离”标记，不属于输入值域。

替代方案

BFS 与 DFS 等价：两者都能枚举连通块；迭代 BFS 可避免深递归。也可以每天为网格建立并查集，但传播会动态新增感染单元，重新维护分组不比直接遍历更简单。若只复制网格做试探性模拟，会产生更多状态与同步成本，并不能绕开每日完整区域统计。

import java.util.*;

class Solution {
    public int containVirus(int[][] isInfected) {
        int m = isInfected.length, n = isInfected[0].length;
        int answer = 0;
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        while (true) {
            boolean[][] seen = new boolean[m][n];
            List<List<int[]>> regions = new ArrayList<>();
            List<Set<Integer>> frontiers = new ArrayList<>();
            List<Integer> perimeters = new ArrayList<>();

            for (int r = 0; r < m; r++) {
                for (int c = 0; c < n; c++) {
                    if (isInfected[r][c] != 1 || seen[r][c]) continue;
                    List<int[]> cells = new ArrayList<>();
                    Set<Integer> frontier = new HashSet<>();
                    int perimeter = 0;
                    Deque<int[]> queue = new ArrayDeque<>();
                    queue.offer(new int[]{r, c});
                    seen[r][c] = true;

                    while (!queue.isEmpty()) {
                        int[] cell = queue.poll();
                        cells.add(cell);
                        for (int[] d : dirs) {
                            int nr = cell[0] + d[0], nc = cell[1] + d[1];
                            if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                            if (isInfected[nr][nc] == 0) {
                                perimeter++;
                                frontier.add(nr * n + nc);
                            } else if (isInfected[nr][nc] == 1 && !seen[nr][nc]) {
                                seen[nr][nc] = true;
                                queue.offer(new int[]{nr, nc});
                            }
                        }
                    }
                    regions.add(cells);
                    frontiers.add(frontier);
                    perimeters.add(perimeter);
                }
            }

            if (regions.isEmpty()) break;
            int target = 0;
            for (int i = 1; i < regions.size(); i++) {
                if (frontiers.get(i).size() > frontiers.get(target).size()) target = i;
            }
            if (frontiers.get(target).isEmpty()) break;

            answer += perimeters.get(target);
            for (int[] cell : regions.get(target)) {
                isInfected[cell[0]][cell[1]] = -1;
            }
            for (int i = 0; i < regions.size(); i++) {
                if (i == target) continue;
                for (int pos : frontiers.get(i)) {
                    isInfected[pos / n][pos % n] = 1;
                }
            }
        }
        return answer;
    }
}

var containVirus = function (isInfected) {
    const m = isInfected.length;
    const n = isInfected[0].length;
    const dirs = [[1, 0], [-1, 0], [0, 1], [0, -1]];
    let answer = 0;

    while (true) {
        const seen = Array.from({ length: m }, () => Array(n).fill(false));
        const regions = [];
        const frontiers = [];
        const perimeters = [];

        for (let r = 0; r < m; r++) {
            for (let c = 0; c < n; c++) {
                if (isInfected[r][c] !== 1 || seen[r][c]) continue;
                const cells = [];
                const frontier = new Set();
                let perimeter = 0;
                const stack = [[r, c]];
                seen[r][c] = true;

                while (stack.length) {
                    const [cr, cc] = stack.pop();
                    cells.push([cr, cc]);
                    for (const [dr, dc] of dirs) {
                        const nr = cr + dr, nc = cc + dc;
                        if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                        if (isInfected[nr][nc] === 0) {
                            perimeter++;
                            frontier.add(nr * n + nc);
                        } else if (isInfected[nr][nc] === 1 && !seen[nr][nc]) {
                            seen[nr][nc] = true;
                            stack.push([nr, nc]);
                        }
                    }
                }
                regions.push(cells);
                frontiers.push(frontier);
                perimeters.push(perimeter);
            }
        }

        if (regions.length === 0) break;
        let target = 0;
        for (let i = 1; i < regions.length; i++) {
            if (frontiers[i].size > frontiers[target].size) target = i;
        }
        if (frontiers[target].size === 0) break;

        answer += perimeters[target];
        for (const [r, c] of regions[target]) isInfected[r][c] = -1;
        for (let i = 0; i < regions.length; i++) {
            if (i === target) continue;
            for (const pos of frontiers[i]) {
                isInfected[Math.floor(pos / n)][pos % n] = 1;
            }
        }
    }
    return answer;
};

from typing import List, Set, Tuple


class Solution:
    def containVirus(self, isInfected: List[List[int]]) -> int:
        m, n = len(isInfected), len(isInfected[0])
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
        answer = 0

        while True:
            seen = [[False] * n for _ in range(m)]
            regions: List[List[Tuple[int, int]]] = []
            frontiers: List[Set[Tuple[int, int]]] = []
            perimeters: List[int] = []

            for r in range(m):
                for c in range(n):
                    if isInfected[r][c] != 1 or seen[r][c]:
                        continue
                    cells: List[Tuple[int, int]] = []
                    frontier: Set[Tuple[int, int]] = set()
                    perimeter = 0
                    stack = [(r, c)]
                    seen[r][c] = True

                    while stack:
                        cr, cc = stack.pop()
                        cells.append((cr, cc))
                        for dr, dc in directions:
                            nr, nc = cr + dr, cc + dc
                            if not (0 <= nr < m and 0 <= nc < n):
                                continue
                            if isInfected[nr][nc] == 0:
                                perimeter += 1
                                frontier.add((nr, nc))
                            elif isInfected[nr][nc] == 1 and not seen[nr][nc]:
                                seen[nr][nc] = True
                                stack.append((nr, nc))

                    regions.append(cells)
                    frontiers.append(frontier)
                    perimeters.append(perimeter)

            if not regions:
                break
            target = max(range(len(regions)), key=lambda i: len(frontiers[i]))
            if not frontiers[target]:
                break

            answer += perimeters[target]
            for r, c in regions[target]:
                isInfected[r][c] = -1
            for i, frontier in enumerate(frontiers):
                if i == target:
                    continue
                for r, c in frontier:
                    isInfected[r][c] = 1

        return answer

#include <array>

using namespace std;

class Solution {
public:
    int containVirus(vector<vector<int>>& isInfected) {
        int m = isInfected.size(), n = isInfected[0].size();
        const array<array<int, 2>, 4> dirs = {{{1, 0}, {-1, 0}, {0, 1}, {0, -1}}};
        int answer = 0;

        while (true) {
            vector<vector<bool>> seen(m, vector<bool>(n, false));
            vector<vector<pair<int, int>>> regions;
            vector<unordered_set<int>> frontiers;
            vector<int> perimeters;

            for (int r = 0; r < m; ++r) {
                for (int c = 0; c < n; ++c) {
                    if (isInfected[r][c] != 1 || seen[r][c]) continue;
                    vector<pair<int, int>> cells;
                    unordered_set<int> frontier;
                    int perimeter = 0;
                    queue<pair<int, int>> q;
                    q.push({r, c});
                    seen[r][c] = true;

                    while (!q.empty()) {
                        auto [cr, cc] = q.front();
                        q.pop();
                        cells.push_back({cr, cc});
                        for (const auto& d : dirs) {
                            int nr = cr + d[0], nc = cc + d[1];
                            if (nr < 0 || nr >= m || nc < 0 || nc >= n) continue;
                            if (isInfected[nr][nc] == 0) {
                                ++perimeter;
                                frontier.insert(nr * n + nc);
                            } else if (isInfected[nr][nc] == 1 && !seen[nr][nc]) {
                                seen[nr][nc] = true;
                                q.push({nr, nc});
                            }
                        }
                    }
                    regions.push_back(move(cells));
                    frontiers.push_back(move(frontier));
                    perimeters.push_back(perimeter);
                }
            }

            if (regions.empty()) break;
            int target = 0;
            for (int i = 1; i < static_cast<int>(regions.size()); ++i) {
                if (frontiers[i].size() > frontiers[target].size()) target = i;
            }
            if (frontiers[target].empty()) break;

            answer += perimeters[target];
            for (auto [r, c] : regions[target]) isInfected[r][c] = -1;
            for (int i = 0; i < static_cast<int>(regions.size()); ++i) {
                if (i == target) continue;
                for (int pos : frontiers[i]) isInfected[pos / n][pos % n] = 1;
            }
        }
        return answer;
    }
};

面试追问

  • 为什么 frontier 要去重，而 perimeter 不能去重？
  • 如果每天允许隔离两个区域，选择局部最大是否仍然正确？
  • 若墙有不同建造成本，状态与选择标准应如何改变？
  • 怎样在不修改输入矩阵的前提下表达已隔离区域？

常见错误

  • 用边界墙数选择区域；题目比较的是不同未感染单元数。
  • 把多个区域共享的传播目标当成冲突；当晚把它置为感染一次即可。
  • 先传播再隔离，导致每日顺序颠倒。
  • 隔离后仍把该区域当作值 1 扫描，造成重复建墙。
  • 按每个感染格新建 visited 集合，导致同一连通块被反复统计。
