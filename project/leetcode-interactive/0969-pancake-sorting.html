Pancake Sorting

煎饼排序

像翻动一摞煎饼那样，每次只能反转数组的一个前缀。你能把最大值逐层送到底部吗？

题目

给定整数数组 arr。一次煎饼翻转选择 1 ≤ k ≤ arr.length，并反转前缀 arr[0...k-1]。返回一组翻转长度 k，使数组升序排列；只要操作有效且不超过 10 × arr.length 次，任意答案均可接受。

321→4123·4

示例 1

输入：arr = [3,2,4,1]
输出：[4,2,4,3]
解释：依次翻转长度 4、2、4、3：
[3,2,4,1] → [1,4,2,3] → [4,1,2,3] → [3,2,1,4] → [1,2,3,4]

示例 2

输入：arr = [1,2,3]
输出：[]
解释：数组已经有序，不需要翻转。（例如 [3,3] 也同样有效。）

约束

  • 1 ≤ arr.length ≤ 100
  • 1 ≤ arr[i] ≤ arr.length
  • arr 中元素互不相同，即它是 1..n 的一个排列。

核心洞察

从数组末端向前固定位置。若当前未排序区间是 [0, size)，先找到其中最大值：它不在末端时，最多用两次翻转——先把它翻到顶部，再把整个未排序前缀翻转，让它落到 size - 1。

完整过程

  1. 令 size = n，在前 size 项找到最大值下标 maxIndex。
  2. 若它已位于 size - 1，直接缩小区间。
  3. 若它不在顶部，先翻转 maxIndex + 1 项。
  4. 翻转前 size 项，将最大值送到当前末端；重复直到 size = 1。

正确性

循环不变量：每轮开始时，区间 [size,n) 已含正确且升序排列的最大元素。当前前缀的最大值经至多两次翻转到达 size-1；翻转不会触及已固定后缀，因此不变量继续成立。最终 size=1，整个数组有序。

边界与复杂度

  • 长度为 1 或已经有序：可以不产生翻转。
  • 最大值已在顶部：只需第二次翻转。
  • 时间复杂度 O(n²)；除返回结果外额外空间 O(1)。
  • 每轮至多 2 次，共不超过 2(n-1) 次，满足 10n 限制。

替代方案

可以用普通排序得到目标位置后模拟寻找，但仍需前缀翻转；本题元素恰为 1..n，也可直接按目标值 size 查找。两者本质仍是选择排序式贪心。若追求最少翻转，则成为更难的状态搜索问题，本题不要求最优序列。

面试追问

  • 为什么固定最大值不会破坏后缀？因为每次翻转长度不超过当前 size。
  • 能否跳过无效操作？可以；最大值已就位时零次，已在顶部时一次。
  • 若元素重复怎么办？选择任一最大值仍能排序，但原题保证互异。

常见错误

  • 把下标 maxIndex 当作翻转长度；正确长度是 maxIndex + 1。
  • 在整个数组寻找最大值，误触已经固定的后缀。
  • 只记录答案却没有同步反转数组，导致后续位置判断错误。

四语言完整代码

Java

class Solution {
    public List<Integer> pancakeSort(int[] arr) {
        List<Integer> ans = new ArrayList<>();
        for (int size = arr.length; size > 1; size--) {
            int maxIndex = 0;
            for (int i = 1; i < size; i++)
                if (arr[i] > arr[maxIndex]) maxIndex = i;
            if (maxIndex == size - 1) continue;
            if (maxIndex > 0) {
                reverse(arr, maxIndex + 1);
                ans.add(maxIndex + 1);
            }
            reverse(arr, size);
            ans.add(size);
        }
        return ans;
    }
    private void reverse(int[] a, int k) {
        for (int l = 0, r = k - 1; l < r; l++, r--) {
            int t = a[l]; a[l] = a[r]; a[r] = t;
        }
    }
}

JavaScript

/** @param {number[]} arr @return {number[]} */
var pancakeSort = function(arr) {
  const ans = [];
  const reverse = k => {
    for (let l = 0, r = k - 1; l < r; l++, r--)
      [arr[l], arr[r]] = [arr[r], arr[l]];
  };
  for (let size = arr.length; size > 1; size--) {
    let maxIndex = 0;
    for (let i = 1; i < size; i++)
      if (arr[i] > arr[maxIndex]) maxIndex = i;
    if (maxIndex === size - 1) continue;
    if (maxIndex > 0) {
      reverse(maxIndex + 1);
      ans.push(maxIndex + 1);
    }
    reverse(size);
    ans.push(size);
  }
  return ans;
};

Python

class Solution:
    def pancakeSort(self, arr: List[int]) -> List[int]:
        ans = []
        for size in range(len(arr), 1, -1):
            max_index = max(range(size), key=arr.__getitem__)
            if max_index == size - 1:
                continue
            if max_index > 0:
                k = max_index + 1
                arr[:k] = reversed(arr[:k])
                ans.append(k)
            arr[:size] = reversed(arr[:size])
            ans.append(size)
        return ans

C++

class Solution {
public:
    vector<int> pancakeSort(vector<int>& arr) {
        vector<int> ans;
        for (int size = arr.size(); size > 1; --size) {
            int idx = max_element(arr.begin(), arr.begin() + size)
                      - arr.begin();
            if (idx == size - 1) continue;
            if (idx > 0) {
                reverse(arr.begin(), arr.begin() + idx + 1);
                ans.push_back(idx + 1);
            }
            reverse(arr.begin(), arr.begin() + size);
            ans.push_back(size);
        }
        return ans;
    }
};
