分割回文串 II

预处理回文区间，再用动态规划求最少切割次数。

题意

给你字符串 s，将它分割成若干回文子串，返回最少分割次数。

示例

s = "aab"
输出：1（"aa" | "b"）

约束

1 ≤ s.length ≤ 2000；s 只含小写英文字母。

洞察与过程

令 pal[l][r] 表示区间是否回文，按右端点递增更新；令 dp[i] 为前 i 个字符的最少切割。若 s[j..i] 回文，则 dp[i]=min(dp[i], dp[j-1]+1)，整个前缀回文时为 0。

边界与复杂度

空前缀、单字符、整串回文均需正确初始化。时间与空间为 O(n²)。

替代与追问

可中心扩展并同步更新 dp 以节省回文表；追问如何恢复具体切分方案。

常见错误

  • 回文表依赖方向错误。
  • 把段数和切割数混淆。
  • 忘记整段回文时切割为 0。

四语言代码

Java

class Solution { public int minCut(String s) { int n=s.length(); boolean[][] p=new boolean[n][n]; int[] d=new int[n]; for(int i=0;i<n;i++){d[i]=i;for(int j=0;j<=i;j++)if(s.charAt(j)==s.charAt(i)&&(i-j<2||p[j+1][i-1])){p[j][i]=true;d[i]=j==0?0:Math.min(d[i],d[j-1]+1);}}return d[n-1];} }

class Solution:
 def minCut(self, s):
  n=len(s); p=[[False]*n for _ in s]; d=list(range(n))
  for i in range(n):
   for j in range(i+1):
    if s[j]==s[i] and (i-j<2 or p[j+1][i-1]): p[j][i]=True; d[i]=0 if j==0 else min(d[i],d[j-1]+1)
  return d[-1]
