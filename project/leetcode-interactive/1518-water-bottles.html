换水问题 Water Bottles

喝完会留下空瓶，空瓶又能换来新的满瓶。你能在这场不断回收的循环中，最多喝到多少瓶水？

题目说明

任务

开始时有 numBottles 瓶装满水的瓶子。每喝完一瓶，就得到一个空瓶；每凑齐 numExchange 个空瓶，可以兑换一瓶新的满水瓶。求最终最多能喝多少瓶水。

函数签名

numWaterBottles(numBottles, numExchange) → integer

参数与约束

  • numBottles：初始满瓶数。
  • numExchange：兑换一瓶水所需的空瓶数。
  • 返回值：整个过程能喝到的最大瓶数。
  • 1 ≤ numBottles ≤ 100
  • 2 ≤ numExchange ≤ 100

示例 1

输入：numBottles = 9, numExchange = 3
输出：13
解释：每 3 个空瓶换 1 瓶水，共可喝 9 + 3 + 1 = 13 瓶。

示例 2

输入：numBottles = 15, numExchange = 4
输出：19
解释：兑换得到的满瓶数量依次为 3、1，共可喝 15 + 3 + 1 = 19 瓶。

Complete solution

完整题解

核心洞察：每一轮只需记录“当前满瓶、空瓶、累计喝过的瓶数”。喝完当前所有满瓶后，把新增空瓶尽可能兑换；当空瓶不足以换出下一瓶时结束。

完整过程

  1. 令 full = numBottles、empty = 0、total = 0。
  2. 只要 full > 0，就喝完这些水：total += full，同时得到等量空瓶。
  3. 用整数除法算出本轮可兑换的满瓶数，用取模保留兑换后剩余的空瓶。
  4. 没有新满瓶时停止，total 即最大可饮用瓶数。

正确性

循环开始时，full 和 empty 精确表示尚未处理的满瓶与可用空瓶，total 精确表示已经喝完的瓶数。每轮先喝完全部满瓶，不会损失任何可饮用水；再用 empty / numExchange 的整数部分做尽可能多的兑换，余数继续保留，因此既不漏换也不多换。

结束时 full = 0 且剩余空瓶不足一次兑换，所以不存在可继续获得的水。由此算法得到的数量就是最大值。

边界情况

  • numBottles < numExchange：只能喝初始的水。
  • numBottles = numExchange：恰好还能兑换一次。
  • numExchange = 2：兑换最频繁，但满瓶数仍会严格减少。
  • 约束保证 numExchange ≥ 2，不会出现无限兑换。

复杂度

时间：O(lognumExchange numBottles) 轮。每轮可兑换出的满瓶数至少按兑换比例缩小。

空间：O(1)，只维护少量整数变量。

替代方案：数学公式

每多喝一瓶兑换水，净消耗 numExchange - 1 个空瓶；为了保证最后一次兑换可发生，初始贡献可整理为：

answer = numBottles + ⌊(numBottles - 1) / (numExchange - 1)⌋

公式是 O(1)，但模拟更直观，也更容易在规则变化时扩展。

面试追问

  • 若每次兑换后所需空瓶数递增，状态和终止条件如何调整？
  • 若允许借一个空瓶再归还，最大值会怎样变化？
  • 能否从守恒关系推导 O(1) 公式，并说明为什么要减 1？

常见错误

  • 只把兑换次数加到答案，却忘记兑换来的水喝完后还会产生新空瓶。
  • 计算余数前覆盖空瓶数量，导致丢失未参与兑换的空瓶。
  • 用浮点除法直接作为新满瓶数，没有向下取整。
  • 循环条件写成 empty > numExchange，漏掉恰好可以兑换一次的情况；应体现“大于等于”。

四语言完整实现

Java官方可提交签名
class Solution {
    public int numWaterBottles(int numBottles, int numExchange) {
        int full = numBottles;
        int empty = 0;
        int total = 0;

        while (full > 0) {
            total += full;
            empty += full;
            full = empty / numExchange;
            empty %= numExchange;
        }

        return total;
    }
}
