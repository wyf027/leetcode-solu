收集垃圾的
最少总时间

Minimum Amount of Time to Collect Garbage

三辆专属垃圾车，一条街道。如何安排，才能尽早收工？

01 / Understand

先读懂规则

garbage[i] 表示第 i 栋房子的垃圾，每个字符是一单位：M 为金属、P 为纸、G 为玻璃。每收集一单位垃圾需要 1 分钟。

travel[i] 是房子 i 到 i + 1 的行驶分钟数。三辆车各负责一种垃圾，均从房子 0 出发，按房子编号顺序行驶，可以提前结束行程。

任意时刻只能有一辆车工作。它行驶或收集时，另两辆车必须等待。求清空所有房子垃圾所需的最少总分钟数；无需返回起点。

函数：garbageCollection(garbage, travel) → integer

查看官方题目 ↗

输入约束

  • 2 ≤ garbage.length ≤ 10⁵
  • 1 ≤ garbage[i].length ≤ 10
  • 每个字符串只含 M、P、G。
  • travel.length = garbage.length - 1
  • 1 ≤ travel[i] ≤ 100

动手前想一想

房子没有某种垃圾时，对应的车可以跳过收集；但如果它还要去更远处，是否能跳过中间路段？

官方示例

示例 1

garbage = ["G","P","GP","GG"]
travel = [2,4,3]
输出 = 21

纸车用时 8 分钟，玻璃车用时 13 分钟，金属车不需要工作。总计 21 分钟。

示例 2

garbage = ["MMM","PGM","GP"]
travel = [3,10]
输出 = 37

金属车用时 7 分钟，纸车与玻璃车分别用时 15 分钟。总计 37 分钟。

03 / Solution

只开到最后一份目标垃圾

收集时间无法减少：每个字符都要处理一次。真正可以节省的是车的行驶距离。某种垃圾最后出现在房子 last，对应车辆只需开到那里。

答案 = 全部垃圾的字符总数 + 三辆车各自最远必要行驶时间之和。
没有出现的类型贡献 0；只在房子 0 出现的类型也无需行驶。

完整过程

  1. 维护累计距离 distance、垃圾总量 pickup，以及 M/P/G 三个最新距离 last，全部初始化为 0。
  2. 扫描房子 i：若 i > 0，先加上 travel[i - 1]，得到起点到当前房子的距离。
  3. 把该房子字符串长度计入收集时间；每遇到类型 c，就覆盖 last[c] = distance。
  4. 扫描结束，三个 last 保存对应类型最后一次出现的距离。将它们加到收集时间上。

为什么一定最优？

下界：设垃圾总量为 S，每单位必须花 1 分钟，所以至少需要 S 分钟。对每种出现的类型 t，车必须到达其最后出现的房子 Lₜ，因此至少要花从 0 到 Lₜ 的路程时间 Dₜ。车辆不能并行，所以下界是 S + ΣDₜ。

可达：让三辆车依次出发，沿街收集自己负责的垃圾，并在最后一份目标垃圾处停下。此方案恰好收集 S 次，且每辆车只走 Dₜ，达到下界。

扫描不变量：处理完房子 i 后，pickup 等于 0…i 的字符总数，distance 等于 0 到 i 的路程，last[t] 等于已处理房子中类型 t 最近一次出现的位置距离；未出现时为 0。逐步覆盖保持该不变量，最终得到所有 Dₜ。

复杂度与边界

  • 设 n 为房子数，S 为字符总数：时间 O(n + S)，约束下 S ≤ 10n，也可写 O(n)。
  • 实现仅保存三个距离：额外空间 O(1)。交互界面为展示保留状态，与提交算法的空间无关。
  • 不存在某种类型：last 保持 0，无需启动那辆车。
  • 同一房子多个同类字符：每个都计入收集时间，覆盖同一个距离不会多算行驶。
  • 没有目标垃圾的中间房子仍需经过；无需回程。
  • 结果不超过 10n + 300(n−1)，n = 10⁵ 时上界 30,999,700，32 位有符号整数足够。

替代方案 · 从路段出发

还可以从右向左扫描，维护右侧已经出现的垃圾类型集合。一段路的贡献等于该路耗时乘以其右侧出现的类型数，再加上所有垃圾的收集时间。例如一段路右侧还有纸和玻璃，这段路就必须分别被两辆车经过。

这个后缀集合方案同样为 O(n + S) 时间、O(1) 额外空间。若使用完整前缀和数组再查询三种类型的末尾位置，表达更直观，但需要 O(n) 额外空间；本题只需累计距离即可。

四种语言 · 可提交实现

统一采用累计距离与最后出现距离。以下代码尚未编译或运行。

Java

class Solution {
    public int garbageCollection(String[] garbage, int[] travel) {
        int pickup = 0, distance = 0;
        int[] last = new int[3];
        for (int i = 0; i < garbage.length; i++) {
            if (i > 0) distance += travel[i - 1];
            pickup += garbage[i].length();
            for (int j = 0; j < garbage[i].length(); j++) {
                char c = garbage[i].charAt(j);
                int k = c == 'M' ? 0 : c == 'P' ? 1 : 2;
                last[k] = distance;
            }
        }
        return pickup + last[0] + last[1] + last[2];
    }
}

var garbageCollection = function(garbage, travel) {
    let pickup = 0, distance = 0;
    const last = { M: 0, P: 0, G: 0 };
    for (let i = 0; i < garbage.length; i++) {
        if (i > 0) distance += travel[i - 1];
        pickup += garbage[i].length;
        for (const c of garbage[i]) last[c] = distance;
    }
    return pickup + last.M + last.P + last.G;
};

Python 3

from typing import List

class Solution:
    def garbageCollection(self, garbage: List[str], travel: List[int]) -> int:
        pickup = distance = 0
        last = {"M": 0, "P": 0, "G": 0}
        for i, house in enumerate(garbage):
            if i > 0:
                distance += travel[i - 1]
            pickup += len(house)
            for c in house:
                last[c] = distance
        return pickup + sum(last.values())

C++

#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    int garbageCollection(vector<string>& garbage, vector<int>& travel) {
        int pickup = 0, distance = 0;
        int last[3] = {0, 0, 0};
        for (int i = 0; i < static_cast<int>(garbage.size()); ++i) {
            if (i > 0) distance += travel[i - 1];
            pickup += static_cast<int>(garbage[i].size());
            for (char c : garbage[i]) {
                int k = c == 'M' ? 0 : c == 'P' ? 1 : 2;
                last[k] = distance;
            }
        }
        return pickup + last[0] + last[1] + last[2];
    }
};

常见错误

  • 取三辆车耗时的最大值：题目禁止并行，应求和。
  • 把每段路固定乘 3：有些车在更早的位置就已经完成任务。
  • 每遇到一份垃圾就累加 distance：同一辆车的共用路段会被重复计费，应该覆盖最后距离。
  • 先处理房子再加到达它的路程：导致 last 错一段；应先加 travel[i−1]。
  • 计算往返时间：题目没有回到起点的要求。

面试追问

  • 如果三辆车可以并行？在互不影响且无共享资源约束时，结果变为各车“收集 + 行驶”耗时的最大值。
  • 如果必须返回起点？假定回程耗时与去程一致，将各车的行驶项乘 2，收集项不变。
  • 如果有 k 种垃圾？用映射保存各类型末尾距离；时间 O(n + S + k)，空间 O(k)。
  • 能否流式读取？可以，按房子和相邻路段顺序输入，只需累计距离、收集总量和类型距离表。
