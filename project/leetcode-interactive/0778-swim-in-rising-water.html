水位上升的泳池中
游泳

在不断上涨的水面下，真正决定何时抵达终点的，不是路线长度，而是沿途必须跨过的最高平台。

HARD 数组矩阵极小化极大堆（优先队列）

01 · Read the terrain

题目要求

先读题，再决定如何穿过水域。

给定一个 n × n 整数矩阵 grid，其中 grid[i][j] 表示坐标 (i, j) 处平台的高度。

时间为 t 时，水位也为 t。只有当当前平台和相邻平台的高度都不超过水位时，才能向上、下、左、右游动；游动本身不耗费时间，且不能离开网格。

从左上角 (0, 0) 出发，返回能够抵达右下角 (n − 1, n − 1) 的最早时间。

swimInWater(grid: integer[][]) → integer

05 · Solution

题解：最短路的“最大值”版本

不是累计每一步的代价，而是让整条路线上的最高平台尽可能低。

◎

核心洞察

经过一条路径所需等待的时间，等于路径上所有平台高度的最大值。因此目标是：在所有起点到终点的路径中，最小化这个最大值。把 Dijkstra 中的“距离相加”改为“取最大值”即可。

完整过程

  1. 令 best[r][c] 表示从起点到该格所需的最低水位，初值为无穷大。
  2. 起点的值为 grid[0][0]，将它压入最小堆。
  3. 每次弹出 best 最小的格子；若它是终点，立即返回。
  4. 转移到邻格时，新代价为 max(当前代价, 邻格高度)。
  5. 若新代价更小，就更新邻格并压入堆。过期堆项在弹出时跳过。

正确性证明

  1. 路径代价正确。每次扩展取当前代价和新平台高度的最大值，恰好等于整条新路径的最高高度。
  2. 弹出值最优。假设最小堆首次弹出格子 u 时仍存在更低代价路径；该路径上第一个未确认点的前驱已确认，它本应以更小代价进入堆，产生矛盾。
  3. 终点答案最优。终点首次弹出时，其值已是所有起点到终点路径代价的最小值，因此就是最早可达时间。

边界与细节

  • n = 1 时，起点就是终点，答案是唯一平台的高度。
  • 起点可能不是最低平台，初始等待时间必须包含 grid[0][0]。
  • 只允许四方向移动，不能斜着游。
  • 重复堆项不影响正确性，但必须跳过过期项以减少无效扩展。

复杂度

共有 n² 个节点、至多约 4n² 条有向邻接关系。

时间 O(n² log n)空间 O(n²)

替代方案

二分答案 + BFS/DFS：二分水位 T，只走高度不超过 T 的格子，检查能否抵达终点。时间 O(n² log n)，思路直接，但会重复扫描网格。

并查集：按高度从低到高激活格子，并与已激活邻格合并；起终点首次连通时的高度即答案。排序后为 O(n² log n)；本题高度恰为唯一的 [0,n²) 值时可省去排序。

面试追问

  • 如果平台高度可重复，算法与证明是否改变？
  • 如果查询很多组起点和终点，能否预处理最小生成树？
  • 如果可以八方向移动，只需改哪里？
  • 为什么普通 BFS 不能直接保证最小等待时间？

常见错误

  • 把代价写成高度之和，误解为传统加权最短路。
  • 只按平台自身高度入堆，却没有携带从起点到这里的路径最大值。
  • 看到终点被加入堆就返回；应在终点成为最小项并被弹出时返回。
  • 用访问标记过早锁死节点，导致后续更优代价无法更新。

Java · LeetCode 可提交PriorityQueue
import java.util.Arrays;
import java.util.PriorityQueue;

class Solution {
    public int swimInWater(int[][] grid) {
        int n = grid.length;
        int[][] best = new int[n][n];
        for (int[] row : best) {
            Arrays.fill(row, Integer.MAX_VALUE);
        }

        // {到达所需最低水位, 行, 列}
        PriorityQueue<int[]> heap =
            new PriorityQueue<>((a, b) -> Integer.compare(a[0], b[0]));
        best[0][0] = grid[0][0];
        heap.offer(new int[]{best[0][0], 0, 0});

        int[][] directions = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        while (!heap.isEmpty()) {
            int[] current = heap.poll();
            int cost = current[0];
            int row = current[1];
            int col = current[2];

            if (cost != best[row][col]) continue;
            if (row == n - 1 && col == n - 1) return cost;

            for (int[] direction : directions) {
                int nextRow = row + direction[0];
                int nextCol = col + direction[1];
                if (nextRow < 0 || nextRow >= n ||
                    nextCol < 0 || nextCol >= n) continue;

                int nextCost = Math.max(cost, grid[nextRow][nextCol]);
                if (nextCost < best[nextRow][nextCol]) {
                    best[nextRow][nextCol] = nextCost;
                    heap.offer(new int[]{nextCost, nextRow, nextCol});
                }
            }
        }
        return -1;
    }
}
JavaScript · LeetCode 可提交Binary Min-Heap
/**
 * @param {number[][]} grid
 * @return {number}
 */
var swimInWater = function(grid) {
    const n = grid.length;
    const best = Array.from({ length: n }, () => Array(n).fill(Infinity));
    const heap = [];

    const push = (item) => {
        heap.push(item);
        let index = heap.length - 1;
        while (index > 0) {
            const parent = (index - 1) >> 1;
            if (heap[parent][0] <= heap[index][0]) break;
            [heap[parent], heap[index]] = [heap[index], heap[parent]];
            index = parent;
        }
    };

    const pop = () => {
        const top = heap[0];
        const last = heap.pop();
        if (heap.length > 0) {
            heap[0] = last;
            let index = 0;
            while (true) {
                let smallest = index;
                const left = index * 2 + 1;
                const right = left + 1;
                if (left < heap.length &&
                    heap[left][0] < heap[smallest][0]) smallest = left;
                if (right < heap.length &&
                    heap[right][0] < heap[smallest][0]) smallest = right;
                if (smallest === index) break;
                [heap[index], heap[smallest]] = [heap[smallest], heap[index]];
                index = smallest;
            }
        }
        return top;
    };

    best[0][0] = grid[0][0];
    push([best[0][0], 0, 0]);
    const directions = [[1, 0], [-1, 0], [0, 1], [0, -1]];

    while (heap.length > 0) {
        const [cost, row, col] = pop();
        if (cost !== best[row][col]) continue;
        if (row === n - 1 && col === n - 1) return cost;

        for (const [dr, dc] of directions) {
            const nextRow = row + dr;
            const nextCol = col + dc;
            if (nextRow < 0 || nextRow >= n ||
                nextCol < 0 || nextCol >= n) continue;

            const nextCost = Math.max(cost, grid[nextRow][nextCol]);
            if (nextCost < best[nextRow][nextCol]) {
                best[nextRow][nextCol] = nextCost;
                push([nextCost, nextRow, nextCol]);
            }
        }
    }
    return -1;
};
Python 3 · LeetCode 可提交heapq
from typing import List
import heapq


class Solution:
    def swimInWater(self, grid: List[List[int]]) -> int:
        n = len(grid)
        best = [[float("inf")] * n for _ in range(n)]
        best[0][0] = grid[0][0]
        heap = [(best[0][0], 0, 0)]
        directions = ((1, 0), (-1, 0), (0, 1), (0, -1))

        while heap:
            cost, row, col = heapq.heappop(heap)
            if cost != best[row][col]:
                continue
            if row == n - 1 and col == n - 1:
                return cost

            for dr, dc in directions:
                next_row = row + dr
                next_col = col + dc
                if not (0 <= next_row < n and 0 <= next_col < n):
                    continue

                next_cost = max(cost, grid[next_row][next_col])
                if next_cost < best[next_row][next_col]:
                    best[next_row][next_col] = next_cost
                    heapq.heappush(heap, (next_cost, next_row, next_col))

        return -1
C++ · LeetCode 可提交priority_queue
class Solution {
public:
    int swimInWater(vector<vector<int>>& grid) {
        int n = grid.size();
        const int INF = numeric_limits<int>::max();
        vector<vector<int>> best(n, vector<int>(n, INF));

        using State = array<int, 3>; // {代价, 行, 列}
        priority_queue<State, vector<State>, greater<State>> heap;
        best[0][0] = grid[0][0];
        heap.push({best[0][0], 0, 0});

        const int directions[4][2] = {
            {1, 0}, {-1, 0}, {0, 1}, {0, -1}
        };

        while (!heap.empty()) {
            auto [cost, row, col] = heap.top();
            heap.pop();
            if (cost != best[row][col]) continue;
            if (row == n - 1 && col == n - 1) return cost;

            for (const auto& direction : directions) {
                int nextRow = row + direction[0];
                int nextCol = col + direction[1];
                if (nextRow < 0 || nextRow >= n ||
                    nextCol < 0 || nextCol >= n) continue;

                int nextCost = max(cost, grid[nextRow][nextCol]);
                if (nextCost < best[nextRow][nextCol]) {
                    best[nextRow][nextCol] = nextCost;
                    heap.push({nextCost, nextRow, nextCol});
                }
            }
        }
        return -1;
    }
};
