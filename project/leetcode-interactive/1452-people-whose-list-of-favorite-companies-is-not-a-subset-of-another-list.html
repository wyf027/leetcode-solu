Problem 1452 · Medium

收藏清单

People Whose List of Favorite Companies Is Not a Subset of Another List

题号#1452
难度MEDIUM
标签数组 · 哈希表 · 字符串
函数peopleIndexes

01 · Understand

题目要求

给定二维字符串数组 favoriteCompanies，其中 favoriteCompanies[i] 表示下标为 i 的用户收藏的公司清单。

找出所有满足下列条件的用户：他的收藏清单不是其他任何一个用户收藏清单的子集。返回这些用户的下标，并按升序排列。

函数参数与返回值：

peopleIndexes(favoriteCompanies: string[][]): number[]

约束

  • 1 ≤ favoriteCompanies.length ≤ 100
  • 1 ≤ favoriteCompanies[i].length ≤ 500
  • 1 ≤ favoriteCompanies[i][j].length ≤ 20
  • 同一清单内的公司名互不相同。
  • 任意两份清单不同（各自排序后仍不相等）。
  • 公司名只含小写英文字母。

04 · Solve

题解：哈希集合判定子集

把每份收藏清单转换成集合，再枚举不同用户的清单，逐项检查子集关系。

核心洞察

用户 i 应被排除，当且仅当存在某个 j ≠ i，使 favoriteCompanies[i] 中的每个公司都能在 favoriteCompanies[j] 中找到。

先用清单长度剪枝：较短清单不可能包含较长清单。随后借助哈希集合，将单次“公司是否存在”的查询降为均摊 O(1)。

完整过程

  1. 把每位用户的公司清单转为哈希集合。
  2. 依次把每个用户 i 当作候选答案。
  3. 枚举另一个用户 j；若 j 的清单更短，直接跳过。
  4. 检查 i 的每家公司是否都在 j 的集合中。
  5. 一旦找到包含者就排除 i；否则把 i 加入答案。

正确性证明

要证：算法返回的下标，恰好是收藏清单不为任何其他清单子集的用户。

充分性：若算法加入下标 i，说明它枚举了每个 j ≠ i，均未发现 favoriteCompanies[i] 的所有元素同时存在于 favoriteCompanies[j]。因此 i 的清单不是任何其他清单的子集，加入答案正确。

必要性：若用户 i 的清单是某个用户 j 清单的子集，则枚举到这对清单时，每个属于 i 的公司都会在 j 的哈希集合中命中，算法会标记并排除 i。因此任何不该返回的下标都不会进入答案。

两方面合并，算法返回结果与题目要求完全一致。外层按下标从小到大遍历，因此答案天然升序。

边界情况

  • 只有一位用户：不存在其他清单，下标 0 必然保留。
  • 全部为互不相同的单元素清单：所有下标保留。
  • 某清单只比另一清单少一个元素：仍是严格子集，应排除。
  • 题目保证同一清单内无重复公司，且任意两份清单不完全相同。

复杂度

设用户数为 n，单份清单最大长度为 m。

时间 O(n² · m)　空间 O(n · m)

长度剪枝不会改变最坏复杂度，但能减少实际比较。集合构建占 O(n · m)。

替代方案

排序 + 双指针：先分别排序每份清单，再用双指针线性判断子集。单次比较也是 O(m)，且额外包含排序成本；优点是访问连续、无需哈希查询。

公司名编号 + 位集：将公司映射为整数，再使用位集做包含判断。公司全集适中时很快，但实现与空间管理更复杂。

面试追问

  • 如果公司名全集很小，如何用位运算加速？
  • 如果允许两份清单相同，答案语义应怎样定义？实现需改哪里？
  • 如果数据持续在线新增，怎样维护“当前不是任何清单子集”的用户？
  • 哈希碰撞与极端长字符串会怎样影响实际性能？

常见错误

  • 把“不是别人的子集”误写成“没有别人是它的子集”。
  • 比较到自己，导致每份清单都被判定为子集。
  • 只比较清单长度，未逐项检查具体公司。
  • 找到包含者后没有及时停止，增加无意义计算。
  • 用对象存公司名时忽略原型键；优先使用语言自带的集合。

import java.util.*;

class Solution {
    public List<Integer> peopleIndexes(List<List<String>> favoriteCompanies) {
        int n = favoriteCompanies.size();
        List<Set<String>> sets = new ArrayList<>(n);
        for (List<String> companies : favoriteCompanies) {
            sets.add(new HashSet<>(companies));
        }

        List<Integer> answer = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            boolean isSubset = false;
            for (int j = 0; j < n && !isSubset; j++) {
                if (i == j || sets.get(j).size() < sets.get(i).size()) {
                    continue;
                }
                if (sets.get(j).containsAll(sets.get(i))) {
                    isSubset = true;
                }
            }
            if (!isSubset) {
                answer.add(i);
            }
        }
        return answer;
    }
}

var peopleIndexes = function(favoriteCompanies) {
    const sets = favoriteCompanies.map(companies => new Set(companies));
    const answer = [];

    for (let i = 0; i < sets.length; i++) {
        let isSubset = false;

        for (let j = 0; j < sets.length && !isSubset; j++) {
            if (i === j || sets[j].size < sets[i].size) continue;

            let allIncluded = true;
            for (const company of sets[i]) {
                if (!sets[j].has(company)) {
                    allIncluded = false;
                    break;
                }
            }
            isSubset = allIncluded;
        }

        if (!isSubset) answer.push(i);
    }
    return answer;
};
from typing import List


class Solution:
    def peopleIndexes(
        self, favoriteCompanies: List[List[str]]
    ) -> List[int]:
        sets = [set(companies) for companies in favoriteCompanies]
        answer: List[int] = []

        for i, current in enumerate(sets):
            is_subset = False
            for j, other in enumerate(sets):
                if i == j or len(other) < len(current):
                    continue
                if current.issubset(other):
                    is_subset = True
                    break

            if not is_subset:
                answer.append(i)

        return answer
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> peopleIndexes(vector<vector<string>>& favoriteCompanies) {
        int n = static_cast<int>(favoriteCompanies.size());
        vector<unordered_set<string>> sets(n);
        for (int i = 0; i < n; ++i) {
            sets[i].insert(favoriteCompanies[i].begin(), favoriteCompanies[i].end());
        }

        vector<int> answer;
        for (int i = 0; i < n; ++i) {
            bool isSubset = false;

            for (int j = 0; j < n && !isSubset; ++j) {
                if (i == j || sets[j].size() < sets[i].size()) continue;

                bool allIncluded = true;
                for (const string& company : sets[i]) {
                    if (sets[j].find(company) == sets[j].end()) {
                        allIncluded = false;
                        break;
                    }
                }
                isSubset = allIncluded;
            }

            if (!isSubset) answer.push_back(i);
        }
        return answer;
    }
};
