满足不等式的数对数目

Number of Pairs Satisfying Inequality

两个数组，一条不等式。找出所有按下标先后排列、满足条件的数对。

打开 LeetCode 原题 ↗

01 / 题目

给定两个长度同为 n 的整数数组 nums1、nums2（下标从 0 开始），以及整数 diff。返回同时满足下面两条条件的数对 (i, j) 的数量：

0 ≤ i < j ≤ n − 1
nums1[i] − nums1[j] ≤ nums2[i] − nums2[j] + diff

约束

  • n == nums1.length == nums2.length
  • 2 ≤ n ≤ 10⁵
  • −10⁴ ≤ nums1[i], nums2[i] ≤ 10⁴
  • −10⁴ ≤ diff ≤ 10⁴

示例 1

nums1 = [3,2,5]
nums2 = [2,2,1]
diff = 1
输出：3

三个数对都成立：(0,1) 对应 1 ≤ 1，(0,2) 对应 −2 ≤ 2，(1,2) 对应 −3 ≤ 2。

示例 2

nums1 = [3,-1]
nums2 = [-2,2]
diff = -1
输出：0

唯一候选数对 (0,1) 要求 4 ≤ −5，不成立，因此答案是 0。

02 / 题解 · 把数对变成前缀计数

核心洞察

将同一下标的量移到一起，定义 a[k] = nums1[k] − nums2[k]。原式等价于 a[i] ≤ a[j] + diff。从左向右处理 j，只需询问：已经见过的值中，有多少个不大于这个阈值？

  1. 计算差值数组 a；排序去重得到坐标 keys，保留原数组的处理顺序。
  2. 树状数组存储每个坐标出现的次数。upper_bound(keys, t) 返回不大于阈值 t 的坐标数量，恰好就是前缀查询的终点。
  3. 先查询 t = a[j] + diff，把结果累加到答案。
  4. 再把当前 a[j] 的频次加一。重复直到处理完所有下标。

必须先查询再插入，树中才只有 i < j。压缩只改变值的表示，不会改变大小关系；重复值仍按出现次数累计。

04 / 为什么正确

循环不变量：开始处理下标 j 时，树状数组准确记录 a[0…j−1] 的频次，答案恰好包含所有右端点小于 j 的合法数对。

初始树为空、答案为零，不变量成立。查询阈值 a[j]+diff 的前缀，恰好统计所有满足原式且 i < j 的左端点。每个频次对应一个不同下标，所以重复值不会漏计。更新只加入当前值，使不变量延续到下一轮。每对数对有唯一的右端点，故不会重复；循环结束后所有合法数对都被统计。

复杂度

排序与去重为 O(n log n)；每轮二分、查询和更新为 O(log n)。总时间 O(n log n)，额外空间 O(n)。

边界与常见错误

  • 阈值小于最小坐标：前缀长度为 0；大于等于最大坐标：查询整个树。阈值不必加入压缩坐标。
  • 条件含等号，应使用 upper_bound / bisect_right，不能漏掉等于阈值的元素。
  • diff 可以为负，不能假设所有相同差值都能配对。
  • 树坐标从 1 开始，不能在位置 0 更新，否则 lowbit 为 0 导致死循环。
  • 不能先全局排序原差值数组再扫描，否则破坏 i < j 的约束。
  • 最大答案为 100000 × 99999 / 2 = 4,999,950,000。Java 用 long，C++ 用 long long；Python 整数与 JavaScript Number 均可精确表示本题答案。

替代方案

归并排序计数：按原下标区间递归，合并前对已排序的左右半区，用单调指针为每个右半区元素统计满足阈值的左半区元素，时间同为 O(n log n)。线段树同样能做前缀频次统计，但常数与实现更大。固定值域也可用偏移树状数组，省去压缩，但查询必须处理阈值超界。

面试追问

  • 如果要求严格小于？改用 lower_bound 查询严格小于阈值的坐标数量。
  • 如果限制 j−i ≤ k？扫描时从树中移除离开窗口的值，再查询并插入。
  • 如果要求输出所有数对？答案本身可能达到平方规模；计数结构不能避开输出规模的下界。
  • 为何无需离散化 a[j]+diff？二分只需知道阈值落在坐标序列的哪个间隙。

JavaScript

/**
 * @param {number[]} nums1
 * @param {number[]} nums2
 * @param {number} diff
 * @return {number}
 */
var numberOfPairs = function(nums1, nums2, diff) {
    const a = nums1.map((x, i) => x - nums2[i]);
    const keys = [...new Set(a)].sort((x, y) => x - y);
    const bit = Array(keys.length + 1).fill(0);
    function upper(x) {
        let l = 0, r = keys.length;
        while (l < r) {
            const m = Math.floor((l + r) / 2);
            if (keys[m] <= x) l = m + 1;
            else r = m;
        }
        return l;
    }
    let answer = 0;
    for (const x of a) {
        for (let p = upper(x + diff); p > 0; p -= p & -p)
            answer += bit[p];
        // x is a key, so upper(x) is its 1-based rank.
        for (let p = upper(x); p < bit.length; p += p & -p)
            bit[p]++;
    }
    return answer;
};

Java

import java.util.Arrays;

class Solution {
    private int upper(int[] keys, int x) {
        int l = 0, r = keys.length;
        while (l < r) {
            int m = l + (r - l) / 2;
            if (keys[m] <= x) l = m + 1;
            else r = m;
        }
        return l;
    }

    public long numberOfPairs(int[] nums1, int[] nums2, int diff) {
        int n = nums1.length;
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = nums1[i] - nums2[i];
        int[] sorted = a.clone();
        Arrays.sort(sorted);
        int size = 0;
        for (int x : sorted)
            if (size == 0 || sorted[size - 1] != x) sorted[size++] = x;
        int[] keys = Arrays.copyOf(sorted, size);
        int[] bit = new int[size + 1];
        long answer = 0;
        for (int x : a) {
            for (int p = upper(keys, x + diff); p > 0; p -= p & -p)
                answer += bit[p];
            for (int p = upper(keys, x); p <= size; p += p & -p)
                bit[p]++;
        }
        return answer;
    }
}

Python

from typing import List
from bisect import bisect_right

class Solution:
    def numberOfPairs(self, nums1: List[int], nums2: List[int], diff: int) -> int:
        a = [x - y for x, y in zip(nums1, nums2)]
        keys = sorted(set(a))
        bit = [0] * (len(keys) + 1)
        answer = 0
        for x in a:
            p = bisect_right(keys, x + diff)
            while p > 0:
                answer += bit[p]
                p -= p & -p
            p = bisect_right(keys, x)
            while p < len(bit):
                bit[p] += 1
                p += p & -p
        return answer

C++

#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    long long numberOfPairs(vector<int>& nums1, vector<int>& nums2, int diff) {
        int n = nums1.size();
        vector<int> a(n);
        for (int i = 0; i < n; ++i) a[i] = nums1[i] - nums2[i];
        vector<int> keys = a;
        sort(keys.begin(), keys.end());
        keys.erase(unique(keys.begin(), keys.end()), keys.end());
        int m = keys.size();
        vector<int> bit(m + 1, 0);
        long long answer = 0;
        for (int x : a) {
            int p = upper_bound(keys.begin(), keys.end(), x + diff) - keys.begin();
            for (; p > 0; p -= p & -p) answer += bit[p];
            p = upper_bound(keys.begin(), keys.end(), x) - keys.begin();
            for (; p <= m; p += p & -p) ++bit[p];
        }
        return answer;
    }
};
