不相交的线Uncrossed Lines

两排数字之间，怎样连出尽可能多的相等数字，又保证连线互不交叉？先从顺序关系出发观察，再决定是否查看完整题解。

MEDIUM数组动态规划最长公共子序列

题目

给定两个整数数组 nums1 和 nums2，把它们按原顺序写在两条水平线上。你可以在值相等的两个元素之间连线；每个元素最多使用一次，任意两条连线也不能交叉（包括不能共享端点）。返回最多能画出的连线数。

函数参数：maxUncrossedLines(nums1, nums2)；返回一个整数。

约束

  • 1 <= nums1.length, nums2.length <= 500
  • 1 <= nums1[i], nums2[j] <= 2000

不交叉意味着：若连接 (i, j) 后，之后选择的端点下标必须同时向右增长。

官方示例

输入：nums1 = [1,4,2], nums2 = [1,2,4]
输出：2
说明：可连接 1 和 1，再连接 2 和 2；若同时连接 4 与 4，连线会交叉。
输入：nums1 = [2,5,1,2,5], nums2 = [10,5,2,1,5,2]
输出：3
输入：nums1 = [1,3,7,1,7,5], nums2 = [1,9,2,5,1]
输出：2

示例固定为 nums1 = [1,4,2]、nums2 = [1,2,4]。格子 dp[i][j] 表示两个前缀最多可连多少条线。

点击“下一步”，从左上角开始填写表格。

Solution

题解：把几何限制翻译成顺序

核心洞察：不交叉的连线，其两端下标顺序必然一致。因此，每组连线对应两个数组的一个公共子序列；反过来，任意公共子序列也能按顺序连成互不交叉的线。问题等价于求最长公共子序列（LCS）长度。

状态与转移

令 dp[i][j] 表示 nums1 前 i 个元素与 nums2 前 j 个元素的答案。

  • 若 nums1[i-1] == nums2[j-1]，连接这两个末尾元素：dp[i][j] = dp[i-1][j-1] + 1。
  • 否则至少舍弃一个末尾元素：dp[i][j] = max(dp[i-1][j], dp[i][j-1])。
  • 空前缀无法连线，所以第 0 行和第 0 列都是 0。

完整过程

  1. 创建长度为 nums2.length + 1 的一维数组 dp，初值为 0。
  2. 逐个扫描 nums1；每轮保存左上角旧值 prev。
  3. 从左到右扫描 nums2。相等时用 prev + 1；否则取当前格上方旧值与左侧新值的较大者。
  4. 更新 prev 为覆盖前的当前值，最终返回 dp[n]。

正确性证明

  1. 对应关系：任意不交叉连线按 nums1 下标递增排列时，其 nums2 下标也严格递增，且端点值相等，因此得到公共子序列；任意公共子序列按顺序连接也不会交叉。
  2. 转移完备：末尾值相等时，可以把它们接在两个更短前缀的最优解之后；末尾值不等时，任何最优解不可能同时使用这两个末尾，必然属于舍弃其中一个后的某个子问题。
  3. 归纳结论：边界空前缀答案为 0；依照上述转移，所有更小前缀正确则当前前缀也正确，所以最终状态就是最多连线数。

边界情况

单元素数组；完全没有相同值；所有值都相同；大量重复值；数组长度不同；顺序完全相反。算法均不依赖值唯一性。

复杂度

设 m = nums1.length，n = nums2.length：时间复杂度 O(mn)，滚动数组空间复杂度 O(n)。

替代方案与面试追问

二维 DP 更直观，空间为 O(mn)，并能通过回溯恢复具体连线。若要让空间变为 O(min(m,n))，可把较短数组放在列方向。若元素保证互异，可把匹配位置映射后转化为 LIS；但本题允许重复，直接套用会错误。追问常见于：如何恢复方案、如何证明一维更新方向、是否可以输出所有最优方案。

常见错误

  • 贪心连接当前最早相等元素，可能阻断后续更优匹配。
  • 一维 DP 中没有保存左上角旧值，导致相等分支引用已更新数据。
  • 把“值相等”当成唯一匹配，忽略重复元素和下标顺序。
  • 把一维数组从右向左更新；LCS 当前行需要左侧新值，应从左向右。
