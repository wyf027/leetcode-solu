叶值的最小
代价生成树

叶子的顺序已经锁定。真正要决定的，是每个较小值应当在什么时候、与哪一侧的邻居合并。

Problem

题意

给定正整数数组 arr。构造所有可能的满二叉树，使 arr 恰好是叶节点的中序遍历序列；每个内部节点的值，等于其左、右子树中最大叶值的乘积。返回所有内部节点值之和的最小值。

  • 每个节点只能有 0 个或 2 个子节点。
  • 叶子相对顺序不能改变。
  • 函数形式：mctFromLeafValues(arr: integer[]) → integer。

约束

  • 2 ≤ arr.length ≤ 40
  • 1 ≤ arr[i] ≤ 15
  • 答案小于 2³¹，可放入 32 位有符号整数。

示例 1

三片叶子
输入：arr = [6,2,4]
输出：32
解释：两种树的内部节点和分别为 36、32，取较小值。

示例 2

最短数组
输入：arr = [4,11]
输出：44

    Monotonic Stack

    题解：让较小值尽早与更小邻居配对

    核心洞察

    任取当前尚未消去的最小叶值 x，它最终一定会与左、右相邻候选中的一个形成内部节点。为了最小化这次不可避免的代价，应让它乘上两侧中更小的值。单调递减栈恰好能在线找到这个时刻。

    完整过程

    1. 栈底先放一个正无穷哨兵，保证读取阶段无需判断空栈。
    2. 从左到右读取 x。只要栈顶 mid ≤ x，就弹出 mid。
    3. mid 的左右候选分别是弹栈后的新栈顶与当前 x；加入 mid × min(left, x)。
    4. 将 x 入栈。扫描结束后，栈仍为递减序列。
    5. 依次弹出栈顶，与新的栈顶相乘并累加，直到只剩哨兵和一个真实值。

    以 [6,2,4] 为例

    1. 读取 6、2，栈为 [∞,6,2]。
    2. 读取 4 时弹出 2：2 × min(6,4) = 8。
    3. 4 入栈，扫描后为 [∞,6,4]。
    4. 清理时弹出 4：4 × 6 = 24。
    5. 总和为 8 + 24 = 32。

    正确性证明

    引理：对当前序列中的最小值 m，存在一个最优方案，使它与相邻值中较小的那个直接合并。因为 m 不能成为任何非平凡子树的最大叶值，它必须在某个内部节点第一次与左邻或右邻相遇；交换合并次序不会影响其余叶子的相对顺序，而将乘数换为两侧较小者不会增大代价。

    栈不变式：扫描过程中，栈内真实值严格递减（相等值也会弹出）。当读到 x 并弹出 mid ≤ x 时，新栈顶是 mid 左侧第一个更大值，x 是右侧第一个不小于它的值，因此算法正按引理选择两邻居中较小者。

    归纳：每次弹栈都安全地确定一个最优合并并消去一个叶值，剩余值仍构成同类子问题。扫描结束的递减栈只能从右向左相邻合并。重复此过程直到只剩一个值，所得总代价即全局最小值。

    复杂度与边界

    • 时间：O(n)，每个元素至多入栈、出栈各一次。
    • 空间：O(n)，最坏为严格递减数组。
    • 长度为 2 时只产生一个乘积。
    • 相等值使用 ≤ 弹栈，任一相同值先消去都不改变最优代价。
    • 官方保证答案在 32 位有符号整数范围内。

    替代方案：区间 DP

    dp[i][j] 表示叶片 i..j 构成树的最小代价。枚举最后一次切分点 k：

    dp[i][j] = min(dp[i][k] + dp[k+1][j] + max(i..k) × max(k+1..j))

    预处理区间最大值后时间为 O(n³)、空间为 O(n²)。它更直观，也能作为推导贪心前的可靠思路。

    class Solution {
    public int mctFromLeafValues(int[] arr) {
        int[] stack = new int[arr.length + 1];
        int top = 0;
        int answer = 0;
        stack[0] = Integer.MAX_VALUE;

        for (int value : arr) {
            while (stack[top] <= value) {
                int middle = stack[top--];
                answer += middle * Math.min(stack[top], value);
            }
            stack[++top] = value;
        }

        while (top > 1) {
            answer += stack[top] * stack[top - 1];
            top--;
        }
        return answer;
    }
}

        stack.push(value);

    return answer;

    常见错误

    • 误以为可以排序；排序会破坏叶子的中序顺序。
    • 弹出 mid 后固定乘左边或右边，而不是取两者最小。
    • 扫描结束忘记清理递减栈，导致缺少内部节点。
    • 清理条件写成只剩哨兵，错误地多算一次。
    • 用栈模拟树形本身；本题只需最小代价，不必真的建树。
