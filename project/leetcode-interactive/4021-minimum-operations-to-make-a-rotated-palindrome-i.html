4021. 得到旋转回文字符串的最少操作次数 I

每次可把任意字符向后循环加一，或把首字符左旋到末尾。目标是在所有操作顺序中，找出得到回文串的最少次数。

关键结论

固定旋转 r 后，镜像对彼此独立；枚举 0…n-1 即可。

O(n²) 时间 O(1) 额外空间

    题意与完整推导

    1. 左旋做 r 次后，新位置 i 取原串 (i+r) mod n。
    2. 回文只约束镜像对 (i, n-1-i)；长度为奇数时中点不用修改。
    3. 两字母差 d=|a-b|。只能前进但可绕过 z，因此总能选择让其中一个追上另一个，最少为 min(d,26-d)。
    4. 这次旋转成本为 r + Σ pairCost，取最小值。

    操作可以交错执行，但先确定总旋转次数不会损失最优性：旋转只改变位置，字符自增只改变值；最终镜像配对确定后可分别补齐。

    洞察、边界与替代方案

    • 已是回文：r=0 的增量和为 0，答案立即是 0。
    • z 与 a：差 25，环距离为 1，不要误写成 25。
    • 长度 2：只一对；例如 yb 需要 min(23,3)=3。
    • 为何不贪心旋转：当前最小配对代价不保证加上 r 后最小，必须比较所有 r。
    • 替代：II 版 n 更大，需要维护所有旋转的配对贡献；本题 n≤2000，O(n²) 更直接可靠。
