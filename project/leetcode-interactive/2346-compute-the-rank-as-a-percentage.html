01 / 题目档案

把名次换成百分比

给定 Students 表，为每名学生输出 student_id、department_id、percentage。排名只在所属院系内计算，按成绩降序，最高分排第 1，同分共享名次。百分比四舍五入到两位小数，结果行的顺序不限。

percentage = (院系内名次 − 1) × 100 / (院系人数 − 1)

04 / 独立题解

准备好后，再展开推导

核心洞察：数一数严格在前面的人

若同院系中有 g 人成绩严格更高，名次就是 g + 1；百分比等于 g × 100 / (n − 1)。同分学生面对相同的高分人数，因此名次和百分比相同。

完整过程

  1. 按 department_id 分区，每个院系统计人数 n。
  2. 按 mark 降序。同分组第一次出现的下标为 i（从 0 开始），组内所有人的名次都是 i + 1。
  3. 90、90、70、60 的名次是 1、1、3、4；两名并列第一占据两个位置，下一名跳到 3。
  4. n > 1 时按公式换算并最后舍入；n = 1 时返回 0。输出每位学生的身份、院系和百分比。

正确性

分区使每个学生只与本院系比较。降序排列后，某同分组之前的所有学生恰好是严格高分学生，因此组起始下标 i 等于 g，赋予 i + 1 正是所需排名。将其代入题意公式即可得到正确百分比。逐行保留输入身份，每名学生恰好产生一条结果，同分行不会合并或丢失。

主解：MySQL 8（官方可提交语言）

PERCENT_RANK() 计算 (rank − 1) / (分区人数 − 1)；乘 100 并舍入即可。RANK() 对同分共享名次并保留空位。参见MySQL 官方窗口函数说明。

SELECT student_id, department_id,
       ROUND(100 * PERCENT_RANK() OVER (
           PARTITION BY department_id
           ORDER BY mark DESC
       ), 2) AS percentage
FROM Students;

SQL：显式展开公式

WITH ranked AS (
    SELECT student_id, department_id,
           RANK() OVER (
               PARTITION BY department_id ORDER BY mark DESC
           ) AS r,
           COUNT(*) OVER (PARTITION BY department_id) AS n
    FROM Students
)
SELECT student_id, department_id,
       ROUND(CASE WHEN n = 1 THEN 0
                  ELSE (r - 1) * 100.0 / (n - 1)
             END, 2) AS percentage
FROM ranked;

Java · 本地语义参考

import java.util.*;
import java.math.*;

public class Main {
    // Rows: [student_id, department_id, mark].
    static List<String> computeRating(int[][] students) {
        Map<Integer, List<int[]>> groups = new TreeMap<>();
        for (int[] s : students)
            groups.computeIfAbsent(s[1], k -> new ArrayList<>()).add(s);
        List<String> out = new ArrayList<>();
        for (List<int[]> group : groups.values()) {
            group.sort((a, b) -> Integer.compare(b[2], a[2]));
            int n = group.size(), rank = 1;
            for (int i = 0; i < n; i++) {
                if (i == 0 || group.get(i)[2] != group.get(i-1)[2])
                    rank = i + 1;
                BigDecimal pct = n == 1 ? new BigDecimal("0.00")
                    : BigDecimal.valueOf((rank - 1) * 100L).divide(
                        BigDecimal.valueOf(n - 1), 2, RoundingMode.HALF_UP);
                int[] s = group.get(i);
                out.add(s[0] + "," + s[1] + "," + pct.toPlainString());
            }
        }
        return out;
    }
    public static void main(String[] args) {
        int[][] students = {{2,2,650},{8,2,650},{7,1,920},{1,1,610},{3,1,530}};
        System.out.println("student_id,department_id,percentage");
        computeRating(students).forEach(System.out::println);
    }
}

JavaScript · 本地语义参考

// Rows: [student_id, department_id, mark].
function computeRating(students) {
  const groups = new Map(), result = [];
  for (const s of students) {
    if (!groups.has(s[1])) groups.set(s[1], []);
    groups.get(s[1]).push(s);
  }
  for (const group of groups.values()) {
    group.sort((a, b) => b[2] - a[2]);
    let rank = 1;
    for (let i = 0; i < group.length; i++) {
      if (i === 0 || group[i][2] !== group[i-1][2]) rank = i + 1;
      // Exact integer half-up rounding to hundredths.
      const d = BigInt(Math.max(1, group.length - 1));
      const a = BigInt(rank - 1) * 10000n;
      const cents = (2n * a + d) / (2n * d);
      result.push({student_id: group[i][0], department_id: group[i][1],
                   percentage: Number(cents) / 100});
    }
  }
  return result;
}

Python 3 · 本地语义参考

from collections import defaultdict
from decimal import Decimal, ROUND_HALF_UP

def compute_rating(students):
    # Rows: [student_id, department_id, mark].
    groups = defaultdict(list)
    for row in students:
        groups[row[1]].append(row)
    result = []
    for group in groups.values():
        group.sort(key=lambda row: -row[2])
        rank, n = 1, len(group)
        for i, (sid, dept, mark) in enumerate(group):
            if i == 0 or mark != group[i - 1][2]:
                rank = i + 1
            pct = Decimal(0) if n == 1 else (
                Decimal((rank - 1) * 100) / Decimal(n - 1))
            result.append((sid, dept, pct.quantize(
                Decimal("0.01"), rounding=ROUND_HALF_UP)))
    return result

#include <algorithm>
#include <array>
#include <iomanip>
#include <iostream>
#include <map>
#include <vector>
using namespace std;
struct Result { int student_id, department_id; long long cents; };
vector<Result> computeRating(const vector<array<int,3>>& students) {
    map<int, vector<array<int,3>>> groups;
    for (auto s : students) groups[s[1]].push_back(s);
    vector<Result> result;
    for (auto& entry : groups) {
        auto& g = entry.second;
        sort(g.begin(), g.end(), [](const auto& a, const auto& b) {
            return a[2] > b[2];
        });
        long long n = g.size(), rank = 1;
        for (long long i = 0; i < n; ++i) {
            if (i == 0 || g[i][2] != g[i-1][2]) rank = i + 1;
            long long d = max(1LL, n - 1), a = (rank - 1) * 10000LL;
            long long cents = (2 * a + d) / (2 * d);
            result.push_back({g[i][0], g[i][1], cents});
        }
    }
    return result;
}

        cout << r.student_id << ',' << r.department_id << ','

边界

  • 单人院系返回 0，避免除零；全部同分也全部为 0。
  • 最低分并列时不保证有人得到 100。例如 90、70、70 得到 0、50、50。
  • 不同院系的人数、名次必须分别计算；空表没有输出行。
  • 本地代码假设输入符合非空整数表结构且学生编号唯一；编辑器拒绝 NULL、非整数和重复编号，不定义额外的 SQL NULL 规则。

复杂度

总人数 N，各院系人数 nᵢ。参考实现分组 O(N)，排序 O(Σ nᵢ log nᵢ)，最坏 O(N log N)；分组与输出占用 O(N) 额外空间。SQL 通常由窗口排序主导，实际内存、磁盘与索引利用由执行计划决定。

替代方案

显式 RANK + COUNT 便于展示单人分支，PERCENT_RANK 更简洁。没有窗口函数时，可用相关子查询统计本院系总人数和严格更高分人数；朴素执行最坏 O(N²)。DENSE_RANK 压缩名次空位，ROW_NUMBER 拆分同分，CUME_DIST 统计含同分的累计占比，都不能直接替换。

常见错误

  • 遗漏 PARTITION BY，将全校混为一个院系。
  • 成绩升序，让最低分排第一。
  • 排名窗口添加 student_id，导致同分被拆开；如需稳定显示，应只在最终结果排序。
  • COUNT 窗口增加 ORDER BY 却未设置完整帧，得到累计人数。
  • 提前整数除法、先舍入后乘 100，导致精度丢失。
  • 用 GROUP BY 合并同分学生，丢失输出行。
  • 把结果误解为超过多少人的比例；本题最高分是 0。

面试追问

为什么分母是 n − 1？从第 1 名的 0 到第 n 名的 100，共有 n − 1 个名次间隔。

大数据如何优化？先查看窗口排序执行计划，评估 (department_id, mark) 索引和排序溢写，避免逐行全表扫描。

最低分必须为 100 怎么办？当前公式在并列时不保证这一点，需要重新明确业务分位定义，不能偷偷改分母。
