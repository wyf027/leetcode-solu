题意转述

输入一个从 0 开始编号的行号，返回杨辉三角对应行。每个内部数字来自上一行正上方相邻两数之和。

任务与约束

给定整数 rowIndex，返回杨辉三角的第 rowIndex 行。第 0 行是 [1]，两端始终为 1。

  • 0 <= rowIndex <= 33
  • 返回长度固定为 rowIndex + 1
  • 进阶要求：只使用 O(rowIndex) 额外空间

题解区域

Interview solution

从右向左，保住上一层

核心洞察

只维护最终要返回的一行。构造第 i 行时，让 j 从 i 递减到 1，执行 row[j] += row[j - 1]。右侧先更新，左侧旧值仍可被下一步读取。

完整过程

  1. 创建长度为 rowIndex + 1 的全零数组。
  2. 设置 row[0] = 1。
  3. 外层从第 1 行走到目标行。
  4. 内层从当前行尾向左更新到下标 1。
  5. 全部完成后直接返回这一个数组。

边界

  • rowIndex = 0：没有内层更新，直接返回 [1]。
  • rowIndex = 1：只更新一次右端，得到 [1,1]。
  • rowIndex = 33：最大值仍在 32 位有符号整数范围内。

复杂度

第 i 行更新 i 次，总时间为 O(rowIndex²)。返回数组占 O(rowIndex)；除此之外只用常数辅助变量。

替代方案取舍

可用组合数递推 C(n,k) = C(n,k-1) × (n-k+1) / k，把时间降至 O(rowIndex)。但跨语言时要谨慎安排乘除顺序和整数宽度。面试主线更推荐原地 DP：直观、稳定，并直接回答空间追问。

常见错误

  • 从左向右更新，导致本行新值覆盖仍需使用的上一行旧值。
  • 循环从 j = i - 1 开始，漏掉右端的 1。
  • 创建每一行的新数组，虽正确但没有回应原地空间优化。
  • 组合数方案先做整数除法，产生不可逆的截断误差。

面试追问

  • 为什么更新方向必须是从右到左？
  • 如何用组合数把时间降到线性？
  • 如果 rowIndex 很大，如何处理溢出？
  • 空间复杂度应否把返回数组计算在内？

推荐回答模板

“我用一个长度为 rowIndex + 1 的数组原地滚动。每层从右向左更新，保证 row[j - 1] 仍是上一层的数据。时间平方级，返回空间线性，额外辅助空间为常数。”

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

class Solution {
    public List<Integer> getRow(int rowIndex) {
        List<Integer> row = new ArrayList<>(
            Collections.nCopies(rowIndex + 1, 0)
        );
        row.set(0, 1);

        for (int i = 1; i <= rowIndex; i++) {
            for (int j = i; j >= 1; j--) {
                row.set(j, row.get(j) + row.get(j - 1));
            }
        }
        return row;
    }
}

var getRow = function (rowIndex) {
    const row = Array(rowIndex + 1).fill(0);
    row[0] = 1;

    for (let i = 1; i <= rowIndex; i++) {
        for (let j = i; j >= 1; j--) {
            row[j] += row[j - 1];
        }
    }
    return row;
};
from typing import List


class Solution:
    def getRow(self, rowIndex: int) -> List[int]:
        row = [0] * (rowIndex + 1)
        row[0] = 1

        for i in range(1, rowIndex + 1):
            for j in range(i, 0, -1):
                row[j] += row[j - 1]
        return row
