路径总和 III

在二叉树中统计和为 targetSum 的向下路径。路径可从任意节点开始、在任意节点结束，但只能沿父到子的方向。

题意

给定二叉树根节点 root 和整数 targetSum，返回树中节点值之和等于 targetSum 的向下路径数量。节点值可以是负数，根到叶并不是唯一合法路径。

示例

root = [10,5,-3,3,2,null,11,3,-2,null,1]
targetSum = 8
输出：3
路径：[5,3]、[5,2,1]、[-3,11]

约束

树中节点数在 [0, 1000]；节点值与 targetSum 均在 -109 到 109 之间。

前缀和实验室

层序数组用逗号分隔，空节点写 null。逐步 DFS 会展示当前根到节点路径、前缀和，以及新发现的合法路径。

    核心洞察：祖先前缀和

    设当前从根走到节点的累积和是 sum。若某个祖先之前的累积和为 sum - targetSum，两者之间那一段的和就恰好是目标值。用哈希表记录当前 DFS 路径上每个前缀和出现次数，即可在到达每个节点时 O(1) 得到以它为终点的路径数量。

    完整过程

    1. 初始化 prefix[0] = 1：这让从根开始、和恰为目标的路径也能被统计。
    2. DFS 到当前节点，令 sum += node.val。
    3. 将 prefix[sum - targetSum] 加入答案。
    4. 记录 prefix[sum]++，递归左右子树。
    5. 离开当前节点时回溯 prefix[sum]--；哈希表只能描述当前分支，不能泄漏到兄弟分支。

    复杂度：每个节点进入、离开各一次，时间 O(n)；递归栈和前缀和表最多 O(n) 空间。常见错误：忘记初始的 0 前缀和、把前缀和累积到兄弟分支、或误把路径限制成“必须从根开始”。

    可提交代码

    Java

    class Solution {
    Map<Long, Integer> prefix = new HashMap<>();
    int target;
    public int pathSum(TreeNode root, int targetSum) {
        target = targetSum; prefix.put(0L, 1);
        return dfs(root, 0L);
    }
    private int dfs(TreeNode node, long sum) {
        if (node == null) return 0;
        sum += node.val;
        int ans = prefix.getOrDefault(sum - target, 0);
        prefix.put(sum, prefix.getOrDefault(sum, 0) + 1);
        ans += dfs(node.left, sum) + dfs(node.right, sum);
        prefix.put(sum, prefix.get(sum) - 1);
        return ans;
    }
}

    var pathSum = function (root, targetSum) {
  const prefix = new Map([[0, 1]]);
  const dfs = (node, sum) => {
    if (!node) return 0;
    sum += node.val;
    let ans = prefix.get(sum - targetSum) || 0;
    prefix.set(sum, (prefix.get(sum) || 0) + 1);
    ans += dfs(node.left, sum) + dfs(node.right, sum);
    prefix.set(sum, prefix.get(sum) - 1);
    return ans;
  };
  return dfs(root, 0);
};

    def pathSum(self, root, targetSum):
        prefix = {0: 1}
        def dfs(node, total):
            if not node: return 0
            total += node.val
            ans = prefix.get(total - targetSum, 0)
            prefix[total] = prefix.get(total, 0) + 1
            ans += dfs(node.left, total) + dfs(node.right, total)
            prefix[total] -= 1

    C++

    class Solution {
    unordered_map<long long, int> prefix;
    int target;
    int dfs(TreeNode* node, long long sum) {
        if (!node) return 0;
        sum += node->val;
        int ans = prefix[sum - target];
        ++prefix[sum];
        ans += dfs(node->left, sum) + dfs(node->right, sum);
        --prefix[sum];
        return ans;
    }
public:
    int pathSum(TreeNode* root, int targetSum) {
        target = targetSum; prefix[0] = 1;
        return dfs(root, 0);
    }
};
