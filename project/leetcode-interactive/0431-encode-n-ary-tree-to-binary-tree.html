将 N 叉树编码为二叉树

Encode N-ary Tree to Binary Tree

设计一对可逆的转换：把任意 N 叉树编码为二叉树，再从该二叉树恢复出结构和值完全一致的 N 叉树。

编码格式没有被限定；只要 decode(encode(root)) 能还原原树即可。你需要实现 Codec 中的 encode 与 decode。

Problem contract

题目要求

N 叉树节点由整数值 val 和按顺序排列的子节点列表 children 组成；二叉树节点由 val、left、right 组成。

实现以下完整参数形式：

TreeNode encode(Node root) Node decode(TreeNode root)

评测器会将输入 N 叉树交给 encode，再把返回的二叉树交给 decode，最终比较恢复树与输入树是否相同。

Constraints

约束

  • 树中节点数在 [0, 104] 范围内。
  • 0 ≤ Node.val ≤ 104。
  • N 叉树的高度不超过 1000。
  • 子节点的相对顺序必须在往返转换后保持不变。
  • 实现应只依赖传入的树，不使用跨调用共享的全局映射。

    Complete solution

    左孩子—右兄弟表示法

    核心洞察

    一个节点虽然可能有很多孩子，但我们只需保存两类关系：它的第一个孩子是谁，以及同一父节点下的下一个兄弟是谁。因此规定：

    binary.left 指向 N 叉节点的第一个孩子；binary.right 指向该 N 叉节点的下一个兄弟。

    这就是经典的左孩子—右兄弟表示法。第一个孩子带我们进入下一层，连续的右指针则按原顺序遍历这一层的所有兄弟，因而信息没有丢失。

    完整过程

    编码 N 叉树 → 二叉树

    1. 空节点直接返回空。
    2. 为当前 N 叉节点创建一个同值二叉节点。
    3. 若存在孩子，递归编码第一个孩子，并把结果接到当前二叉节点的 left。
    4. 依次递归编码其余孩子，把每个结果接到前一个孩子编码节点的 right，形成兄弟链。

    解码 二叉树 → N 叉树

    1. 空节点直接返回空。
    2. 为当前二叉节点创建一个同值 N 叉节点和空的 children 列表。
    3. 从 left 开始；它若存在，就是第一个孩子。
    4. 沿 right 链逐个递归解码，并按顺序追加到 children，直到为空。

    正确性证明

    对 N 叉树的节点数作结构归纳。

    • 基础情形：空树被编码为空，解码空仍为空；叶节点被编码成没有左孩子的同值二叉节点，解码后得到同值且孩子列表为空的叶节点。
    • 归纳假设：假设每棵规模更小的子树经过 decode(encode(subtree)) 都能被完整还原。
    • 归纳步骤：对当前节点，编码保留其值；第一个孩子放在左指针，其余孩子按原顺序串在右兄弟链。解码从左指针开始并严格沿右链依次恢复孩子。由归纳假设，每个孩子的整棵子树都被还原；右链顺序又与原 children 顺序一致。因此当前节点的值、孩子顺序和所有后代均与原树相同。

    所以对任意 N 叉树 root，decode(encode(root)) 与 root 结构和值完全一致。

    边界情况

    • 空树：两个方向都应返回 null/None。
    • 单节点树：编码结果没有左右孩子。
    • 只有一个孩子的长链：主要使用左指针，不应虚构兄弟关系。
    • 根节点有大量孩子：会形成较长的右兄弟链，必须保持顺序。
    • 不同父节点的孩子：右链只连接同一父节点的兄弟，绝不能跨组相连。

    复杂度

    设节点数为 n、N 叉树高度为 h。编码和解码都只访问每个节点一次，时间复杂度为 O(n)；返回结果之外，递归调用栈为 O(h)。编码后的二叉树仍恰好有 n 个节点。

    四语言完整代码

    以下实现使用 LeetCode 提供的 Node 与 TreeNode 定义；只需提交 Codec。选择语言标签查看对应版本。

    import java.util.ArrayList;

class Codec {
    public TreeNode encode(Node root) {
        if (root == null) {
            return null;
        }

        TreeNode binaryRoot = new TreeNode(root.val);
        if (root.children == null || root.children.isEmpty()) {
            return binaryRoot;
        }

        binaryRoot.left = encode(root.children.get(0));
        TreeNode sibling = binaryRoot.left;

        for (int i = 1; i < root.children.size(); i++) {
            sibling.right = encode(root.children.get(i));
            sibling = sibling.right;
        }
        return binaryRoot;
    }

    public Node decode(TreeNode root) {
        if (root == null) {
            return null;
        }

        Node naryRoot = new Node(root.val, new ArrayList<Node>());
        TreeNode child = root.left;

        while (child != null) {
            naryRoot.children.add(decode(child));
            child = child.right;
        }
        return naryRoot;
    }
}
    /**
 * // Definition for an N-ary tree node.
 * function Node(val, children) {
 *   this.val = val;
 *   this.children = children;
 * }
 * // Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *   this.val = val;
 *   this.left = left || null;
 *   this.right = right || null;
 * }
 */

var Codec = function () {};

Codec.prototype.encode = function (root) {
  if (root === null) return null;

  const binaryRoot = new TreeNode(root.val);
  const children = root.children || [];
  if (children.length === 0) return binaryRoot;

  binaryRoot.left = this.encode(children[0]);
  let sibling = binaryRoot.left;

  for (let i = 1; i < children.length; i += 1) {
    sibling.right = this.encode(children[i]);
    sibling = sibling.right;
  }
  return binaryRoot;
};

Codec.prototype.decode = function (root) {
  if (root === null) return null;

  const naryRoot = new Node(root.val, []);
  let child = root.left;

  while (child !== null) {
    naryRoot.children.push(this.decode(child));
    child = child.right;
  }
  return naryRoot;
};
    class Codec:
    def encode(self, root: 'Node') -> 'TreeNode':
        if root is None:
            return None

        binary_root = TreeNode(root.val)
        children = root.children or []
        if not children:
            return binary_root

        binary_root.left = self.encode(children[0])
        sibling = binary_root.left

        for child in children[1:]:
            sibling.right = self.encode(child)
            sibling = sibling.right

        return binary_root

    def decode(self, root: 'TreeNode') -> 'Node':
        if root is None:
            return None

        nary_root = Node(root.val, [])
        child = root.left

        while child is not None:
            nary_root.children.append(self.decode(child))
            child = child.right

        return nary_root

public:
    TreeNode* encode(Node* root) {
        if (root == nullptr) {
            return nullptr;
        }

        TreeNode* binaryRoot = new TreeNode(root->val);
        if (root->children.empty()) {
            return binaryRoot;

        binaryRoot->left = encode(root->children[0]);
        TreeNode* sibling = binaryRoot->left;

        for (int i = 1; i < static_cast<int>(root->children.size()); ++i) {
            sibling->right = encode(root->children[i]);
            sibling = sibling->right;

        if (root == nullptr) {
            return nullptr;

        Node* naryRoot = new Node(root->val);
        TreeNode* child = root->left;

        while (child != nullptr) {

            child = child->right;

    替代方案

    也可以使用队列迭代地完成同一种映射：为每个 N 叉节点创建对应二叉节点，再逐层连接第一个孩子与右兄弟链。这样可避免深树的递归栈，但需要显式队列和成对节点状态，代码更长。另一种思路是先序序列化并记录每个节点的孩子数，再把字节序列塞进二叉树；它能做到可逆，却人为制造了与树结构无关的载体，通常不如左孩子—右兄弟表示法自然。

    面试追问

    • 为什么不能只把所有孩子接成左链？ 因为无法区分“孩子”与“孙子”，层级边界会丢失。
    • 编码是否唯一？ 题目不要求全局唯一；当前规则一旦确定，对给定有序 N 叉树的结果就是确定的。
    • 怎样改成迭代版本？ 队列中保存原节点与目标节点的配对，取出后创建其全部孩子并连接左指针与右链。
    • 极深树有什么风险？ 递归可能溢出调用栈，可用显式栈或队列改写。
    • 能否原地转换？ 两种节点类型和字段语义不同，常规接口要求创建新节点；强行复用会破坏输入且不符合类型约束。

    常见错误

    • 把第二个孩子接到父节点的 right，而不是第一个孩子的 right。
    • 解码时递归整个 root.right 作为当前节点孩子；这个指针表示当前节点自己的兄弟，应由父层循环处理。
    • 遗漏空树，或为叶节点创建虚假的占位孩子。
    • 用栈逆序压入孩子后忘记恢复原有顺序。
    • 使用全局哈希表保存映射，使多次调用互相污染，也没有真正实现结构编码。
