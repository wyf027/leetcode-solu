反转字符串 II

把字符串切成长度为 2k 的节拍：每个节拍只翻转前半拍。先观察规则，再按自己的节奏展开完整题解。

EASY双指针字符串O(n)

题目

给定字符串 s 和整数 k。从字符串开头起，每连续计数 2k 个字符，就反转这一段中的前 k 个字符。

  • 若最后剩余不足 k 个字符，全部反转。
  • 若最后剩余至少 k、但不足 2k 个字符，只反转前 k 个，其余保持原序。
函数形式

reverseStr(s: string, k: integer) → string

约束

  • 1 ≤ s.length ≤ 10⁴
  • s 仅由小写英文字母组成
  • 1 ≤ k ≤ 10⁴

提示：原地交换字符时，思考每轮起点为什么递增 2k。

官方示例

示例 1 输入：s = "abcdefg", k = 2 输出："bacdfeg"
示例 2 输入：s = "abcd", k = 2 输出："bacd"

想清楚每个 2k 窗口的职责了吗？

Solution

题解：以 2k 为步长扫描

核心洞察

题目按固定周期工作。每轮起点为 i = 0, 2k, 4k, …，只需反转闭区间 [i, min(i+k-1, n-1)]。右端点用最小值裁剪，自然覆盖“剩余不足 k”的边界。

完整过程

  1. 将字符串转成可修改的字符数组。
  2. 每次把窗口起点增加 2k。
  3. 用左右指针交换当前窗口前 k 个字符；若不足 k，交换到字符串末尾。
  4. 返回字符数组拼接后的字符串。

正确性

循环不变式：进入起点 i 的一轮前，索引小于 i 的所有完整或残缺窗口都已按规则处理，索引不小于 i 的字符尚未改变。本轮仅反转 [i, min(i+k-1,n-1)]，并不触碰该窗口应保持原序的后半段，因此本轮结束后不变式对下一起点 i+2k 仍成立。循环终止时所有窗口均处理完，所得字符串满足题意。

边界

  • k = 1：每次只反转一个字符，字符串不变。
  • k ≥ n：唯一一轮反转整个字符串。
  • 尾段长度恰为 k 或 2k：裁剪后的右端点仍准确。

复杂度：时间 O(n)；字符数组占 O(n)，若语言支持可变字符串则额外空间可视为 O(1)。

替代方案
也可对每个 2k 分片，通过切片反转并拼接结果；代码直观，但会创建更多临时字符串。双指针版本更贴近原地操作，也更适合面试阐述。
面试追问
  • 若规则改为反转每段后 k 个字符，如何调整区间？
  • 若输入来自字符流，怎样用大小为 2k 的缓冲区在线处理？
  • UTF-16 语言中遇到 emoji 等代理对时，按“字符”反转需要注意什么？
常见错误
  • 循环步长写成 k，误把每一段都反转。
  • 右端点直接写 i+k-1，尾段发生越界。
  • 误将后 k 个字符也反转，或将不足 2k 的尾段全部反转。
