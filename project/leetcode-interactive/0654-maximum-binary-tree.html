最大二叉树

654. Maximum Binary Tree

数组 二叉树 笛卡尔树 单调栈

Problem

题意

给你一个元素互不相同的整数数组 nums。按下面的递归规则构造最大二叉树：

  1. 当前数组中的最大值成为根节点。
  2. 最大值左侧的前缀递归构造左子树。
  3. 最大值右侧的后缀递归构造右子树。
返回值：由 nums 构造出的最大二叉树根节点。数组中的相对顺序不会改变：树的中序遍历仍是原数组。

示例 1

输入：nums = [3,2,1,6,0,5]
输出：[6,3,5,null,2,0,null,null,1]

最大值 6 成为根；左侧 [3,2,1] 构成左子树，右侧 [0,5] 构成右子树，两个部分继续遵循同一规则。

示例 2

输入：nums = [3,2,1]
输出：[3,null,2,null,1]

数组严格递减；每个后来的元素都落在前一个节点的右侧，因此形成一条向右延伸的链。

约束

  • 1 <= nums.length <= 1000
  • 0 <= nums[i] <= 1000
  • nums 中的所有整数互不相同。

Solution

准备好再揭晓题解

先尝试从中序顺序和“谁能成为谁的父节点”出发思考。

Monotonic Stack

O(n) 单调栈构造

中序顺序固定

题目只改变父子关系，不改变元素的左右顺序；最终树的中序遍历必然等于 nums。

更大值接管小值

扫描到新值 x 时，比 x 小且仍在最右路径上的节点，不可能继续位于 x 的上方。

维护递减最右路径

栈从底到顶严格递减。弹出的最后一个节点成为 x.left，未弹出的栈顶（若存在）令其 right = x。

完整过程

  1. 建立空栈。栈中保存已经处理部分的最右路径，栈底是当前根。
  2. 依次读取每个值 x，创建节点 cur。
  3. 当栈顶值小于 x 时持续弹栈；每次都令 cur.left 指向刚弹出的节点。循环结束后，最后弹出的节点正是整个被接管片段的根。
  4. 如果栈仍非空，栈顶是左侧离 x 最近且比它大的节点，令该节点的右孩子为 cur。
  5. 将 cur 入栈。扫描结束后，栈底就是全局最大值节点，也就是答案的根。

正确性证明

循环不变式：处理完前缀 nums[0..i] 后，已连接的节点构成该前缀的最大二叉树；栈从底到顶恰好是这棵树的最右路径，节点值严格递减。

初始化：处理第一个值后，单节点树显然是该前缀的最大二叉树；栈只有该节点，不变式成立。

保持：加入 x 时，所有被弹出的节点都小于 x，且形成最右路径的一段。最后弹出的节点是这段节点中的最大者，按最大二叉树定义应成为 x 的左子树根。若仍有栈顶，它是左侧最近的、更大的祖先，x 应成为它的新右孩子。这样既保留原数组的中序顺序，也让每个区间最大值位于该区间根部。入栈后新的最右路径仍严格递减，因此不变式保持。

终止：所有元素处理完时，已连接的树就是整个数组的最大二叉树。全局最大值从不可能被弹出，位于栈底，所以返回栈底节点正确。

时间复杂度：O(n)

每个节点最多入栈一次、出栈一次；所有 while 循环合计仍是线性次数。

空间复杂度：O(n)

最坏情况下数组单调递减，所有节点同时留在栈中。这里不计返回树本身的存储。

四语言完整代码

Java官方签名
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode constructMaximumBinaryTree(int[] nums) {
        java.util.Deque<TreeNode> stack = new java.util.ArrayDeque<>();

        for (int value : nums) {
            TreeNode current = new TreeNode(value);

            while (!stack.isEmpty() && stack.peek().val < value) {
                current.left = stack.pop();
            }

            if (!stack.isEmpty()) {
                stack.peek().right = current;
            }

            stack.push(current);
        }

        while (stack.size() > 1) {
            stack.pop();
        }
        return stack.peek();
    }
}
JavaScript官方签名
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val === undefined ? 0 : val);
 *     this.left = (left === undefined ? null : left);
 *     this.right = (right === undefined ? null : right);
 * }
 */
/**
 * @param {number[]} nums
 * @return {TreeNode}
 */
var constructMaximumBinaryTree = function(nums) {
    const stack = [];

    for (const value of nums) {
        const current = new TreeNode(value);

        while (stack.length > 0 &&
               stack[stack.length - 1].val < value) {
            current.left = stack.pop();
        }

        if (stack.length > 0) {
            stack[stack.length - 1].right = current;
        }

        stack.push(current);
    }

    return stack[0];
};

C++官方签名
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right)
 *         : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    TreeNode* constructMaximumBinaryTree(vector<int>& nums) {
        vector<TreeNode*> stack;

        for (int value : nums) {
            TreeNode* current = new TreeNode(value);

            while (!stack.empty() &&
                   stack.back()->val < value) {
                current->left = stack.back();
                stack.pop_back();
            }

            if (!stack.empty()) {
                stack.back()->right = current;
            }

            stack.push_back(current);
        }

        return stack.front();
    }
};

边界情况

  • 单元素：该节点同时是根和答案。
  • 严格递增：每次会清空栈，最终形成向左的链。
  • 严格递减：不会弹栈，最终形成向右的链。
  • 值可以是 0；比较的是大小，不要把 0 当成空节点。

常见错误

  • 把“最后弹出的节点”误写为新节点的右孩子。
  • 先入栈再更新旧栈顶的右孩子，导致父节点丢失。
  • 返回栈顶而非栈底；扫描结束时栈顶通常只是最右叶子。
  • 把总弹栈次数误判成 O(n²)；每个节点只会弹出一次。

替代方案

直接递归：每段线性寻找最大值，再递归左右区间。最直观，平均表现取决于数据，但单调数组会退化到 O(n²)，递归深度也可达 O(n)。

RMQ / 线段树：先建立区间最大值查询结构，再递归定位每段最大值，约 O(n log n)。适合把区间查询扩展为其他需求，但本题单次构树不如单调栈简洁。

面试追问

  • 如果数组允许重复值，如何定义稳定的父子归属？比较符号应如何选择？
  • 能否从树恢复原数组？可以，中序遍历即可。
  • 为什么它也是一棵最大笛卡尔树？因为同时满足中序顺序和最大堆性质。
  • 如何在线处理数据流？单调栈可以随输入到达持续更新当前树。
