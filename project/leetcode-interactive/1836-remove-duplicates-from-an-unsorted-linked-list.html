从未排序的链表中
移除重复元素

Remove Duplicates From an Unsorted Linked List

先理解规则，再观察节点之间的连接如何改变。

题意

给定未排序单链表的头节点 head。对于在原链表中出现超过一次的值，删除拥有该值的所有节点。只保留出现一次的值，保持原顺序，返回新链表的头节点。

第一次出现的重复值也要删除，不能留下一个副本。

参数：head: ListNode；返回：ListNode（可能为 null）。官方入口：deleteDuplicatesUnsorted(head)。

官方示例 1

输入：head = [1,2,3,2]
输出：[1,3]

两个值为 2 的节点都被移除。

官方示例 2

输入：head = [2,1,1,2]
输出：[]

1 和 2 都重复，因此没有节点留下。

官方示例 3

输入：head = [3,2,2,1,3,2,4]
输出：[1,4]

移除所有 3 和 2，保留 1、4。

约束

  • 节点数 1 ≤ n ≤ 10⁵。
  • 1 ≤ Node.val ≤ 10⁵。

元数据未包含付费题面，以上为转述。来源：官方题目、公开题面参考（示例与约束）。

先想一想

第一次遇到一个值时，你能立即确定它会保留吗？先手算第三个示例，再展开演示。

题解：先计数，再断链

核心洞察与过程

去留由原链表中的全局频次决定。第一遍统计每个值的出现次数。第二遍引入 dummy 虚拟头节点，令 prev 初始指向 dummy，检查 prev.next：频次大于 1 时令 prev.next = prev.next.next；否则移动 prev。删除时 prev 留在原处，继续检查新的后继。最后返回 dummy.next。

正确性
第一遍遍历每个节点一次，得到准确的原始频次。第二遍维持不变式：已处理部分恰好保留原前缀中全局频次为 1 的节点，顺序不变；prev 指向最后保留节点或 dummy，prev.next 是下一个待处理节点。
频次大于 1 时旁路节点，正好删除不应保留的节点；频次为 1 时保留并移动 prev。不变式在两种情况下都保持。每轮处理一个节点，最终全部节点均被判定，因此 dummy.next 指向正确结果。
边界和常见错误
  • 全部重复时结果为 null；单节点和全部唯一时保留所有节点。
  • 头部重复时 head 可能被移除，必须返回 dummy.next。
  • 连续删除时不能移动 prev，否则跳过下一节点。
  • 链表未排序，仅比较相邻值不能发现所有重复。
  • 用 seen 跳过后续出现，会错误保留第一次出现。
  • 删除时不要递减频次，判断依据始终是原链表。
复杂度
哈希操作均摊 O(1) 时，两遍遍历期望时间 O(n)，额外空间 O(k)，k 是不同值的数量，最坏 O(n)。极端哈希碰撞下不保证严格线性。指针本身占 O(1) 空间。
替代方案
计数数组：值域 U = 100000，可用 U + 1 个槽位，时间 O(n + U)，空间 O(U)。双集合：分别记录已出现与重复的值，再遍历过滤。逐节点扫描完整原链表可用 O(n²) 时间确定频次，但不能边删除边丢失原始重复证据。直接排序会改变顺序，不适合保序要求。
面试追问
  • 为什么两遍？首次出现时无法知道后面是否重复，先收集全局信息可简化删除。
  • 不能修改输入怎么办？计数后创建新的结果节点，增加输出空间。
  • 只读一次的流怎么办？需要缓存或可撤销的输出，首次遇见不能立即确定最终去留。
  • C++ 是否 delete？取决于所有权约定，这里只断链，独立程序由节点所有者负责释放。

Java
import java.util.HashMap;
import java.util.Map;
class Solution {
    public ListNode deleteDuplicatesUnsorted(ListNode head) {
        Map<Integer, Integer> count = new HashMap<>();
        for (ListNode p = head; p != null; p = p.next)
            count.merge(p.val, 1, Integer::sum);
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy;
        while (prev.next != null) {
            if (count.get(prev.next.val) > 1)
                prev.next = prev.next.next;
            else
                prev = prev.next;
        }
        return dummy.next;
    }
}

from typing import Optional
from collections import Counter

class Solution:
    def deleteDuplicatesUnsorted(self, head: Optional[ListNode]) -> Optional[ListNode]:
        count = Counter()
        p = head
        while p is not None:
            count[p.val] += 1
            p = p.next
        dummy = ListNode(0)
        dummy.next = head
        prev = dummy
        while prev.next is not None:
            if count[prev.next.val] > 1:
                prev.next = prev.next.next
            else:
                prev = prev.next
        return dummy.next
C++
#include <unordered_map>
using namespace std;
class Solution {
public:
    ListNode* deleteDuplicatesUnsorted(ListNode* head) {
        unordered_map<int, int> count;
        for (ListNode* p = head; p != nullptr; p = p->next)
            ++count[p->val];
        ListNode dummy(0);
        dummy.next = head;
        ListNode* prev = &dummy;
        while (prev->next != nullptr) {
            if (count[prev->next->val] > 1)
                prev->next = prev->next->next;
            else
                prev = prev->next;
        }
        return dummy.next;
    }
};
