Replace All ?'s to Avoid Consecutive Repeating Characters

输入：string s 输出：string 长度：1…100 目标：相邻字符不同

01 / Mission

题目任务

给定字符串 s，其中只含小写英文字母与字符 '?'。把每一个问号替换成某个小写字母，使最终字符串中不存在两个连续且相同的字符。

原有的非问号字符不能修改。输入保证：除问号外，原字符串本身没有相邻重复字母。若答案不唯一，返回任意一个合法结果即可；在约束范围内答案总是存在。

官方示例 01
输入
s = "?zs"
输出
"azs"

首位不能换成 z，其余 25 个小写字母都能构成合法答案；"azs" 是其中之一。

官方示例 02
输入
s = "ubv?w"
输出
"ubvaw"

问号不能换成相邻的 v 或 w；示例选择 a。

约束

  • 1 <= s.length <= 100
  • s 只由小写英文字母和 '?' 组成。

Solution / Greedy

从左到右，避开左右邻居

核心洞察

处理某个 '?' 时，它最多只需要避开两个字母：已经确定的左邻居和原字符串中的右邻居。从 a、b、c 三个候选中必然至少能找到一个不同于这两个邻居的字母。

完整过程

把字符串转成可修改字符数组

随后从下标 0 扫描到 n − 1，普通字母原样保留。

遇到问号时读取边界

左边界使用已经替换后的字符；右边界若存在，则读取尚未处理的原字符。右边若也是问号，它不会阻止任何候选。

依次尝试 a、b、c

选出第一个既不等于左邻居、也不等于右邻居的候选，立即写回数组。

扫描结束后拼接返回

每个问号都被替换，且每一条相邻边在至少一个端点被处理时已保证不同。

正确性说明

局部可行：一个位置至多禁止左右邻居对应的两个字母，而候选集合有三个不同字母，所以总有候选可选。

整体合法：从左到右处理后，当前位置与左侧已确定字符不同；若右侧是固定字母，也同时与它不同。若右侧是问号，它稍后会避开当前字符。因此最终没有相邻重复。

保持约束：算法只写入问号位置，所有原字母均未改变。

边界与复杂度

  • 首字符没有左邻居，末字符没有右邻居。
  • 字符串可能完全没有问号，直接原样返回。
  • 连续多个问号会使用刚写入的左邻居继续决策。
  • 时间复杂度 O(n)；字符数组占用 O(n)，若语言支持原地修改则额外空间可视为 O(1)。

替代方案

也可以在全部 26 个小写字母中寻找合法字符，正确但没有必要；三个候选已经覆盖“最多禁用两个字符”的情况。回溯同样能解，但会引入无意义的搜索树。

面试追问

  • 为什么两个候选不够？当左右邻居分别占用两个候选时会无解。
  • 若要求字典序最小答案怎么办？按 a 到 z 顺序取首个合法字符。
  • 若禁止距离 2 内重复，需要多少候选？需要统计更大的局部禁用集合。

常见错误

  • 检查左邻居时仍读取原字符串，忘记前一个问号可能已经被替换。
  • 只避开左邻居，导致当前位置与固定的右邻居相同。
  • 访问 i - 1 或 i + 1 前没有判断边界。
  • 误以为必须复现示例输出；本题允许返回任意合法答案。

四语言完整代码

Java
class Solution {
    public String modifyString(String s) {
        char[] chars = s.toCharArray();

        for (int i = 0; i < chars.length; i++) {
            if (chars[i] != '?') continue;

            for (char candidate = 'a'; candidate <= 'c'; candidate++) {
                boolean sameAsLeft = i > 0 && chars[i - 1] == candidate;
                boolean sameAsRight = i + 1 < chars.length
                        && chars[i + 1] == candidate;

                if (!sameAsLeft && !sameAsRight) {
                    chars[i] = candidate;
                    break;
                }
            }
        }

        return new String(chars);
    }
}

/**

var modifyString = function(s) {
    const chars = s.split('');

    for (let i = 0; i < chars.length; i++) {
        if (chars[i] !== '?') continue;

        for (const candidate of ['a', 'b', 'c']) {
            const sameAsLeft = i > 0 && chars[i - 1] === candidate;
            const sameAsRight = i + 1 < chars.length
                && chars[i + 1] === candidate;

            if (!sameAsLeft && !sameAsRight) {
                chars[i] = candidate;
                break;
            }
        }
    }

    return chars.join('');
};
Python
class Solution:
    def modifyString(self, s: str) -> str:
        chars = list(s)

        for i, char in enumerate(chars):
            if char != '?':
                continue

            for candidate in 'abc':
                same_as_left = i > 0 and chars[i - 1] == candidate
                same_as_right = (
                    i + 1 < len(chars)
                    and chars[i + 1] == candidate
                )

                if not same_as_left and not same_as_right:
                    chars[i] = candidate
                    break

        return ''.join(chars)

class Solution {
public:
    string modifyString(string s) {
        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            if (s[i] != '?') continue;

            for (char candidate = 'a'; candidate <= 'c'; ++candidate) {
                bool sameAsLeft = i > 0 && s[i - 1] == candidate;
                bool sameAsRight = i + 1 < static_cast<int>(s.size())
                    && s[i + 1] == candidate;

                if (!sameAsLeft && !sameAsRight) {
                    s[i] = candidate;
                    break;
                }
            }
        }

        return s;
    }
