3972. 求和后首尾数字相同的有效子数组 II

把「和的首位与末位都是 x」拆成有限个十进制区间，再把区间查询交给同余前缀和桶。

题意与示例

给定正整数数组 nums 与数字 x。若连续非空子数组的元素和首位数字、末位数字都等于 x，则它有效；返回有效子数组个数。

示例 1

nums = [1, 100, 1]
x = 1

输出：4。和为 1 或 101 的四个区间都合格。

示例 2

nums = [1]
x = 2

输出：0；唯一和为 1。

约束：1 ≤ nums.length ≤ 10⁵，1 ≤ nums[i] ≤ 10⁹，1 ≤ x ≤ 9。数组元素为正，所以前缀和严格递增。

题解

核心洞察：首位条件变成少量范围，末位条件变成余数

长度为 d 的、首位为 x 的正整数恰在 [x·10^(d-1), (x+1)·10^(d-1)-1]。再限制末位为 x，等价于和 mod 10 = x。令 P[j] 是前 j 项和，子数组和为 P[j]-P[i]。固定右端 P[j] 与 d 后，P[i] 必须落进一个闭区间，且 P[i] mod 10 = (P[j]-x) mod 10。

完整过程

  1. 预先收集所有前缀和，按余数 0..9 分桶并坐标压缩。
  2. 从左到右扫描右端前缀 P[j]；对每个可行十进制长度 d，查询相应余数桶在闭区间内有多少旧前缀。
  3. 把 P[j] 插入自己的余数桶，供后续右端使用。

总和至多约 10¹⁴，所以只需约 15 个 d；每次范围计数由 Fenwick 树完成。

边界、复杂度与替代方案

  • 边界：x 不会为 0；P[0]=0 必须先作为可选左边界插入；范围端点使用 64 位整数。
  • 复杂度：O(n · log n · log₁₀S) 时间，O(n) 空间；S 是总和。
  • 替代方案：n≤1500 的 I 版可 O(n²) 枚举；本题 n=10⁵ 时不可行。平衡树可替代 Fenwick，但常数较大。

面试追问与常见错误

  • 追问：若允许负数，前缀和不再递增，但离线压缩 + Fenwick 的范围计数仍能使用；要重新审视和的符号与首位定义。
  • 错误：只查范围不分余数；把区间右端写成 (x+1)·10^(d-1)（应减一）；先插入 P[j] 导致空子数组被计入。
