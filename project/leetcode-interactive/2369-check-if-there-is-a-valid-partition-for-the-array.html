2369. 检查数组是否
存在有效划分

Check if There is a Valid Partition For The Array

把整个数组切成合法的小段。每一次切分，都必须连续且不留剩余。

01 / PROBLEM

题目要求

给定从下标 0 开始的整数数组 nums，按原有顺序切成一个或多个非空连续子数组。每个元素必须恰好属于一段，每段须满足下面三种规则中的一种。只要存在任意一种这样的划分就返回 true，否则返回 false。

01

两个相等

恰好两个元素，且数值相同。

[2, 2]
02

三个相等

恰好三个元素，且数值相同。

[4, 4, 4]
03

三个连续递增

恰好三个元素，相邻差均为 1。

[3, 4, 5]

不能排序、跳过元素或重新排列；[1,3,5] 不满足连续递增规则。

官方约束

  • 2 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i] ≤ 10⁶

函数：validPartition(nums) → boolean · 官方题目

02 / EXAMPLES

官方示例

示例 1

输入：nums = [4,4,4,5,6]
输出：true

可切成 [4,4] | [4,5,6]：第一段两个相等，第二段三个连续递增。

示例 2

输出：false

04 / SOLUTION

核心洞察：最后一段决定从哪里接上

不要贪心地立即选两个或三个。设 dp[i] 表示前 i 个元素能否全部合法划分。最后一段只能长 2 或 3，因此只要检查两种前缀长度，再判断末段是否合法。

dp[0] = true，dp[1] = false
dp[i] = (dp[i−2] 且末尾两个相等)
　　　　或 (i ≥ 3 且 dp[i−3] 且末尾三个相等或连续递增)

上式最后的“相等或连续递增”整体属于末尾三个元素的合法性判断。空前缀是递推起点，不代表题目允许输入空数组。

完整过程

  1. 创建长度 n+1 的布尔数组，只有 dp[0] 为真。
  2. 从 i=2 到 n 扫描前缀终点。
  3. 若前两个元素之前的前缀可达，且末尾两个相等，将 dp[i] 设为真。
  4. 当 i≥3，再尝试末尾三个；与已有结果取“或”。
  5. 返回 dp[n]。中间某个前缀失败并不能直接判整段失败。

交互：前缀接驳轨道

每一步只确定一个前缀终点。观察来自 i−2 与 i−3 的连接：末段合法、起点也可达，才能接通。初始仅空前缀接通。

正确性

归纳基：空前缀无需分段，成立；一个元素无法组成合法块，不成立。

可靠性：递推判真时，必定有一个可划分的更短前缀，加上一段符合规则的连续末段。拼接覆盖当前前缀，且不重叠。

完备性：若当前前缀存在有效划分，其最后一段一定长 2 或 3，且满足对应规则。移除该段后得到的前缀可划分，按归纳假设已被标为真，因此递推一定发现它。

按前缀长度递增，所有依赖均已确定，故最终 dp[n] 等价于题目所求。

边界与复杂度

  • n=2 只判断两个相等；不访问第三个元素。
  • n=3 可直接从空前缀接三个相等或递增元素。
  • 四个相等元素需要分成两对，不能把长度 4 当作一段。
  • 递减、间隔为 2、单元素均不是合法块。

每个位置做常数次比较：时间 O(n)，布尔数组空间 O(n)。四份实现使用同一递推结构。

替代方案

滚动状态：只保留最近三个前缀状态，空间降至 O(1)。覆盖旧状态前保存 dp[i−3]，以免读取被更新的值。

记忆化搜索：从起点尝试长度 2、3 的块，缓存每个起点的可行性，时间 O(n)、空间 O(n)。长度 10⁵ 时递归深度可能溢出，迭代更稳妥。

位置图：把前缀长度看作顶点，合法块是一条向前的边，本题就是从 0 能否到达 n。

常见错误与面试追问

  • 贪心先取三相等：示例 1 留下 [5,6]，但先取两个即可成功。
  • 只看末段合法，忘记前缀也必须可达。
  • 第二次赋值覆盖第一次结果；应使用逻辑“或”。
  • 把递增理解成大小有序，忘记差必须恰好为 1。
  • 混淆前缀长度 i 与末元素下标 i−1。

如何输出一种划分？每个可达状态记录所选块长，从 n 回溯。

如何数方案？把布尔“或”换为合法前驱的计数求和，按要求取模。

规则可变怎么办？枚举允许的块长及判定条件；复杂度取决于每个终点的候选检查成本。

Java

class Solution {
    public boolean validPartition(int[] nums) {
        int n = nums.length;
        boolean[] dp = new boolean[n + 1];
        dp[0] = true;
        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 2] && nums[i - 2] == nums[i - 1];
            if (i >= 3) {
                int a = nums[i - 3], b = nums[i - 2], c = nums[i - 1];
                boolean triple = (a == b && b == c)
                    || (b == a + 1 && c == b + 1);
                dp[i] = dp[i] || (dp[i - 3] && triple);
            }
        }
        return dp[n];
    }
}
