1751. 最多可以参加的会议数目 II

Maximum Number of Events That Can Be Attended II

HARD

在时间不重叠且最多选择 k 场的限制下，让会议价值总和最大。难点不在“选最高价值”，而在同时处理区间兼容性与选择次数。

数组排序二分查找动态规划

题目描述

给定二维数组 events，其中 events[i] = [startDayᵢ, endDayᵢ, valueᵢ] 表示第 i 场会议的开始日、结束日和参加后获得的价值；另给整数 k，表示最多可参加的会议数。

同一时间只能参加一场会议，且被选中的会议必须从开始到结束全程参加。结束日也属于会议区间，因此一场会议在第 d 天结束时，另一场会议必须在严格晚于第 d 天时才能开始。返回可获得的最大价值总和；不要求恰好参加 k 场。

函数形式： maxValue(events, k) → integer

官方示例

示例 1

输入：events = [[1,2,4],[3,4,3],[2,3,1]], k = 2 输出：7

选择会议 0 和 1，价值为 4 + 3 = 7。

示例 2

输入：events = [[1,2,4],[3,4,3],[2,3,10]], k = 2 输出：10

只选会议 2；它与其余会议重叠，也无需选满 k 场。

示例 3

输入：events = [[1,1,1],[2,2,2],[3,3,3],[4,4,4]], k = 3 输出：9

四场互不重叠，只能选三场，因此取价值 2、3、4。

约束

  • 1 ≤ k ≤ events.length
  • 1 ≤ k × events.length ≤ 10⁶
  • 1 ≤ startDayᵢ ≤ endDayᵢ ≤ 10⁹
  • 1 ≤ valueᵢ ≤ 10⁶

先独立思考状态定义与“下一场兼容会议”的查找方式。

题解：排序 + 二分 + 动态规划

01 · Sort

按开始日排序

统一“从当前位置向后选择”的方向，也让兼容后继可以二分定位。

02 · Search

预处理 next[i]

找第一个 start > end[i] 的下标。必须严格大于，因为结束日包含在会议中。

03 · Decide

选或不选

每个状态比较跳过当前会议，与选择当前会议并跳到 next[i]。

核心洞察

这是“带最多选择次数限制的加权区间调度”。仅按结束时间或价值做贪心都不可靠：一场高价值长会议可能挡住多场总价值更高的短会议。排序后，二分解决区间跳转，DP 负责全局取舍。

完整过程

  1. 按 startDay 升序排序会议，并单独保存开始日数组 starts。
  2. 对每场会议 i，二分查找第一个 starts[j] > endDay[i] 的位置，记为 next[i]；不存在时取 n。
  3. 定义 dp[t][i]：从下标 i 开始，最多参加 t 场可获得的最大价值。
  4. 转移：dp[t][i] = max(dp[t][i+1], value[i] + dp[t-1][next[i]])。
  5. 边界：dp[0][i] = 0，以及所有 dp[t][n] = 0。答案是 dp[k][0]。

正确性说明

状态覆盖：在状态 (t,i) 中，任一合法最优方案对会议 i 只有两种可能：不参加，剩余问题正是 dp[t][i+1]；参加，则获得 value[i]，其余会议必须从第一个严格不重叠的位置 next[i] 开始，且名额减一，对应 dp[t-1][next[i]]。

最优子结构：两种分支的后续部分若不是对应子问题的最优解，都可替换为更优解，从而让原方案更优，产生矛盾。因此取两分支最大值就是该状态最优值。按 i 从后向前、t 从小到大计算时，依赖状态均已求得；结合边界，归纳可得 dp[k][0] 是全局最优答案。

边界处理

  • k = 1：答案就是单场最大价值，统一转移仍成立。
  • 会议首尾同日：只有后一场开始日严格大于前一场结束日才兼容。
  • next[i] = n：后继贡献为 0。
  • 无需选满 k 场；“跳过”分支自然允许少选。
  • 日期可达 10⁹，不要按天建立数组。

复杂度

排序和后继预处理为 O(n log n)；DP 为 O(nk)。二维实现空间为 O(nk)；由于第 t 层只依赖本层右侧和上一层，可滚动压缩到 O(n)。

替代方案

可用记忆化 DFS 表达同一递推，通常更直观，但有递归栈开销；也可按结束时间排序并二分前驱，定义“前 i 场中最多选 t 场”，本质等价。

import java.util.Arrays;

class Solution {
    public int maxValue(int[][] events, int k) {
        Arrays.sort(events, (a, b) -> Integer.compare(a[0], b[0]));
        int n = events.length;
        int[] starts = new int[n];
        int[] next = new int[n];
        for (int i = 0; i < n; i++) starts[i] = events[i][0];

        for (int i = 0; i < n; i++) {
            int left = i + 1, right = n;
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (starts[mid] > events[i][1]) right = mid;
                else left = mid + 1;
            }
            next[i] = left;
        }

        int[] previous = new int[n + 1];
        for (int chosen = 1; chosen <= k; chosen++) {
            int[] current = new int[n + 1];
            for (int i = n - 1; i >= 0; i--) {
                int take = events[i][2] + previous[next[i]];
                current[i] = Math.max(current[i + 1], take);
            }
            previous = current;
        }
        return previous[0];
    }
}

from typing import List


class Solution:
    def maxValue(self, events: List[List[int]], k: int) -> int:
        events.sort(key=lambda event: event[0])
        n = len(events)
        starts = [event[0] for event in events]
        next_index = [
            bisect_right(starts, events[i][1], lo=i + 1)
            for i in range(n)
        ]

        previous = [0] * (n + 1)
        for _ in range(k):
            current = [0] * (n + 1)
            for i in range(n - 1, -1, -1):
                take = events[i][2] + previous[next_index[i]]
                current[i] = max(current[i + 1], take)
            previous = current
        return previous[0]

常见错误

  • 二分条件写成 start ≥ end；正确条件是 start > end。
  • 把“最多 k 场”误写成“恰好 k 场”，导致必须选择低价值或不存在的会议。
  • 二维循环顺序错误，在滚动数组中读到当前层，等价于重复使用会议。
  • 按日期范围做 DP；日期上限为 10⁹，应按会议下标建状态。
  • 只按价值贪心，忽略一个区间对后续可选集合的影响。

面试追问

如果要求恰好参加 k 场？

把不可达状态初始化为负无穷，仅 dp[0][n] = 0 等合法边界为 0，避免少选方案混入。

如何恢复具体选择了哪些会议？

保留二维 DP，并从 (k,0) 比较 take 与 skip；take 更优就记录当前原始编号并跳到 next[i]。

为什么空间能压缩？

当前选择次数层只读取上一层的 take 值，skip 值来自当前层右侧，故保留两个长度 n+1 的数组即可。

若 k 很大，可以先缩小吗？

最多不可能选择超过 n 场；更紧的上界需分析区间结构。题目已保证 n × k ≤ 10⁶，直接 DP 足够。
