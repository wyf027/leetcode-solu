Problem brief

题目要求

给定一个异步函数数组 functions 和并发池上限 n，实现 promisePool。它返回一个 Promise；只有当数组中的所有函数所返回的 Promise 都完成后，这个 Promise 才完成。

任意时刻最多允许 n 个 Promise 处于挂起状态。开始时应立即启动尽可能多的函数；此后每当一个任务完成，就立刻按数组顺序启动下一个尚未执行的函数，而不是等待当前一整批任务全部结束。

题目保证输入函数不会 reject；返回的 Promise 可以 resolve 为任意值。示例输出中的数组描述各任务的完成时刻，最后一个数字表示池整体的完成时刻，并非要求函数返回这些时间数据。

Solution

用固定数量的工人消费共享队列

核心洞察

不必维护复杂的“正在运行 Promise 集合”。只创建至多 n 个工人，每个工人反复领取下一个函数、等待它完成，再继续领取。工人数天然就是并发上限。

完整过程

  1. 设置共享下标 next = 0。
  2. 启动 min(n, functions.length) 个工人。
  3. 每个工人同步领取一个下标，然后 await 对应函数。
  4. 所有工人完成时，所有任务也已完成。

正确性说明

每个任务恰好领取一次。

共享下标只递增；一次领取得到唯一索引，越过数组末尾后不再产生任务。

并发数不会超过 n。

最多只有 min(n, m) 个工人；每个工人等待当前任务完成后才领取下一个任务，因此每个工人最多贡献一个挂起 Promise。

任务按索引顺序启动。

JavaScript 在每次遇到 await 前同步执行领取操作，所以下标 0、1、2……依次被取出并调用。

整体完成等价于全部任务完成。

工人只有在没有剩余任务且自己最后一个任务已完成时才结束；等待全部工人即可覆盖全部任务。

边界情况

  • 空数组：启动零个工人，立即完成。
  • n = 1：退化为串行执行。
  • n ≥ m：全部任务立即启动。
  • 题目保证不 reject；若扩展到会失败的任务，需要先定义快速失败或收集全部错误的语义。

复杂度

设任务数为 m。调度开销是 O(m)，额外空间是 O(min(n, m))。真实墙钟时间由任务耗时及调度分配决定，不能仅用 m 表示。

替代方案

也可以维护运行集合，用 Promise.race 等待最先完成者后补入新任务；它更适合需要取消、动态调并发或逐项收集结果的系统。本题只要求完成信号，固定工人更短也更直接。

常见错误

  • 按大小 n 分批再 Promise.all，会让已空闲槽位等待慢任务。
  • 一开始调用所有函数，再限制 await，此时并发早已失控。
  • 忘记等待全部工人，导致池过早完成。
  • 用结果完成顺序误替代函数启动顺序。

面试追问

  • 若任务会 reject？ 先明确语义：快速失败可直接让工人链 reject；全部收集则在工人内部捕获并记录。
  • 如何保留结果的输入顺序？ 领取时保存索引，把结果写入预分配数组的对应位置。
  • 如何取消？ 将 AbortSignal 传入任务，并在领取新任务前检查取消状态。
  • 为何不用固定批次？ 固定批次必须等批次最慢任务，无法在单个槽位释放时立即补位。

Implementations

四语言完整代码

JavaScript

官方可提交语言
/**
 * @param {Array<() => Promise<any>>} functions
 * @param {number} n
 * @return {Promise<any>}
 */
var promisePool = async function(functions, n) {
  let next = 0;

  async function worker() {
    while (next < functions.length) {
      const fn = functions[next++];
      await fn();
    }
  }

  const workerCount = Math.min(n, functions.length);
  await Promise.all(Array.from({ length: workerCount }, worker));
};

Java

本地语义参考，非本题官方提交语言
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.CompletableFuture;
import java.util.function.Supplier;

class Solution {
    public static CompletableFuture<Void> promisePool(
            List<Supplier<CompletableFuture<Void>>> functions, int n) {
        State state = new State(functions);
        List<CompletableFuture<Void>> workers = new ArrayList<>();
        for (int i = 0; i < Math.min(n, functions.size()); i++) {
            workers.add(worker(state));
        }
        return CompletableFuture.allOf(
                workers.toArray(new CompletableFuture[0]));
    }

    private static CompletableFuture<Void> worker(State state) {
        CompletableFuture<Void> task = state.next();
        return task == null
                ? CompletableFuture.completedFuture(null)
                : task.thenCompose(ignored -> worker(state));
    }

    private static final class State {
        private final List<Supplier<CompletableFuture<Void>>> functions;
        private int next;

        State(List<Supplier<CompletableFuture<Void>>> functions) {
            this.functions = functions;
        }

        synchronized CompletableFuture<Void> next() {
            return next == functions.size() ? null : functions.get(next++).get();
        }
    }
}

Python

本地语义参考，非本题官方提交语言
import asyncio
from collections.abc import Awaitable, Callable, Sequence

AsyncTask = Callable[[], Awaitable[object]]


async def promise_pool(functions: Sequence[AsyncTask], n: int) -> None:
    tasks = iter(functions)

    async def worker() -> None:
        for function in tasks:
            await function()

    worker_count = min(n, len(functions))
    await asyncio.gather(*(worker() for _ in range(worker_count)))

C++17

本地语义参考，非本题官方提交语言
#include <algorithm>
#include <cstddef>
#include <future>
#include <functional>
#include <mutex>
#include <utility>
#include <vector>

using Task = std::function<std::future<void>()>;

std::future<void> promisePool(std::vector<Task> functions,
                              std::size_t n) {
    return std::async(std::launch::async,
        [functions = std::move(functions), n]() mutable {
            std::size_t next = 0;
            std::mutex mutex;
            std::vector<std::future<void>> workers;

            auto worker = [&]() {
                while (true) {
                    std::future<void> task;
                    {
                        std::lock_guard<std::mutex> lock(mutex);
                        if (next == functions.size()) return;
                        task = functions[next++]();
                    }
                    task.get();
                }
            };

            const auto count = std::min(n, functions.size());
            workers.reserve(count);
            for (std::size_t i = 0; i < count; ++i) {
                workers.push_back(std::async(std::launch::async, worker));
            }
            for (auto& future : workers) future.get();
        });
}
