检查操作是否合法

Check if Move is Legal

一次落子，能否成为好线段的端点？先理解规则并判断示例，再展开下方题解，沿着棋盘逐格观察。

阅读题目 ↓

01 / 题目与规则

给定从 0 开始编号的 8 × 8 棋盘 board：'.' 是空格，'W' 是白棋，'B' 是黑棋。选择空格 (rMove, cMove)，把它改成 color。

如果新格子成为至少一条“好线段”的端点，就返回 true；否则返回 false。线段可以水平、竖直或沿对角线，格子必须连续。

  • 好线段至少包含 3 个格子，计入两端。
  • 两个端点颜色相同，中间所有格子都是另一种颜色。
  • 线段不能包含空格；新落子只处于中间位置不算合法。

参数：checkMove(board, rMove, cMove, color) → boolean。只需判断合法性，不要求翻转棋子或更新整个棋盘。

官方约束

  • board.length == board[r].length == 8
  • 0 ≤ rMove, cMove < 8
  • board[rMove][cMove] == '.'
  • color 为 'B' 或 'W'；棋盘格为 '.'、'W' 或 'B'。

04 / 准备好再展开

先自己判断：新棋子的角色是什么？什么情况会让一条候选线段失效？

题解 / 从落点向八个方向扫描

核心洞察：以新棋子为端点的好线段必定形如 己方 → 一个或多个连续对方 → 己方。因此，枚举八条射线，跳过连续异色棋子，再看是否由同色棋子封口即可。

交互 / 射线观察台

逐格高亮当前射线。蓝框是虚拟落子，橙框是当前格，浅黄是当前射线已访问的格子。格内 B / W 表示颜色，左上角为行、列编号。

RAY SCANNER

控件支持 Tab 与 Enter / 空格。焦点在观察台控件时，也可用 ← / → 单步移动。自动播放仅在点击后启动，收起题解时暂停。

完整过程

  1. 枚举 dr, dc ∈ {-1,0,1}，跳过 (0,0)，得到八个方向。
  2. 从落点相邻格开始，令异色计数 count = 0。
  3. 遇到异色就累加计数，并沿方向前进一步。
  4. 遇到空格或越界，当前方向失败；遇到同色，仅在 count > 0 时成功，否则该方向失败。
  5. 任意方向成功立即返回 true；全部失败返回 false。落点颜色用参数表达，无须修改棋盘。

正确性论证

循环不变式：扫描时，落点与当前格之间的所有格子均为连续异色棋子，数量为 count。初始为空，count 为 0；只有异色格才推进，所以不变式保持。

充分性：当当前格同色且 count > 0，落点与当前格为同色端点，中间至少一个异色格，没有空格，长度至少为 3，所以返回 true 必然合法。

必要性：如果存在合法线段，其方向一定在八个方向中。扫描会经过它的所有连续异色中间格，到达同色端点并返回 true。空格、边界或紧邻同色都无法成为有效中间部分，及时停止不会漏解。因此八个方向均失败时返回 false 正确。

边界与常见错误

  • 紧邻同色不合法：两个格子不满足长度至少为 3。
  • 连续异色直到边界仍不合法：缺少远端同色棋子。
  • 不能越过空格，也不能越过先遇到的同色棋子再继续找。
  • 新落子必须是端点；不能把落点两侧拼接后判定。
  • 边角只扫描仍在棋盘内的方向；访问数组前必须判断边界。
  • 每个方向都要重新置零计数；别漏掉四个对角方向，也别扫描零向量。

复杂度

本题固定 8 × 8，最多八条射线、每条最多 7 个格子，时间 O(1)，额外空间 O(1)。若推广为 N × N 棋盘，时间为 O(N)；R × C 棋盘可写作 O(max(R,C))，额外空间仍为 O(1)。演示保存步骤快照的开销不属于提交算法。

替代方案

也可以先确认相邻格为异色，再用 while 跳过整段异色，最后检查同色封口；它与计数方案同阶。枚举远端同色候选格，再逐一检查中间段也可实现，但重复扫描使 N × N 的朴素实现达到 O(N²)。本题不需要 BFS、DFS 或修改棋盘。

面试追问

  • 需要翻转被夹住的棋子怎么办？先记录各方向的候选异色坐标，确认同色封口后再翻转，失败方向不动。
  • 需要返回全部合法方向怎么办？成功时收集方向，继续扫描，而不是立即返回。
  • 如何支持矩形棋盘？分别使用行数和列数进行边界判断，其余机制保持不变。

Java

class Solution {
    public boolean checkMove(char[][] board, int rMove, int cMove, char color) {
        for (int dr = -1; dr <= 1; dr++) {
            for (int dc = -1; dc <= 1; dc++) {
                if (dr == 0 && dc == 0) continue;
                int r = rMove + dr, c = cMove + dc, count = 0;
                while (r >= 0 && r < 8 && c >= 0 && c < 8) {
                    if (board[r][c] == '.') break;
                    if (board[r][c] == color) {
                        if (count > 0) return true;
                        break;
                    }
                    count++;
                    r += dr;
                    c += dc;
                }
            }
        }
        return false;
    }
}

from typing import List

class Solution:
    def checkMove(self, board: List[List[str]], rMove: int,
                  cMove: int, color: str) -> bool:
        for dr in range(-1, 2):
            for dc in range(-1, 2):
                if dr == 0 and dc == 0:
                    continue
                r, c, count = rMove + dr, cMove + dc, 0
                while 0 <= r < 8 and 0 <= c < 8:
                    if board[r][c] == '.':
                        break
                    if board[r][c] == color:
                        if count > 0:
                            return True
                        break
                    count += 1
                    r += dr
                    c += dc
        return False
