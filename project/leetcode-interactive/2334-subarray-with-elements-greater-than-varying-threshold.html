元素值大于变化阈值的子数组

Subarray With Elements Greater Than Varying Threshold

窗口越长，门槛越低。找到一段连续区间，让其中每个元素都越过门槛。

连续非空严格大于任意有效长度

01 / PROBLEM

题目说明

给定整数数组 nums 和整数 threshold。请寻找长度为 k 的连续非空子数组，使其中每个元素都满足 nums[j] > threshold / k。返回任意一个符合要求的长度 k；若没有，返回 -1。

除法表示数学上的比值，条件必须是严格大于。返回长度，不是子数组本身，也不要求最大或最小长度。

参数与返回值

validSubarraySize(nums, threshold) → integer

nums：整数数组；threshold：整数阈值。

完整约束

  • 1 ≤ nums.length ≤ 10⁵
  • 1 ≤ nums[i], threshold ≤ 10⁹

04 / INSIGHT

由最小值决定整个区间

设区间最小值为 m，长度为 k。所有元素都超过门槛，等价于 m > threshold/k，进一步等价于 m × k > threshold。

把数组画成柱形图：最矮柱高 × 区间宽度，就是该区间能支撑的矩形面积。我们只要找到一个面积严格超过阈值的矩形。固定正数高度时，越宽越有利，因此无需枚举该高度下的所有短区间。

用严格递增的单调栈保存下标。扫描到高度小于等于栈顶的 R，弹出下标 i。新栈顶 L（空栈为 -1）是左侧最近严格更小值的位置；R 是右侧第一个小于等于它的位置。结算区间 [L+1,R-1]，宽度为 R-L-1。

相等也弹出意味着边界不对称：左侧 <，右侧 ≤。跨越相等高度的更宽区间由右侧相等元素负责，不能把这里的 R 误称为严格更小边界。

完整过程

  1. 创建存下标的空栈，栈内对应高度严格递增。
  2. 扫描 R=0…n。R=n 时使用虚拟高度 0，负责清空栈；不修改 nums。
  3. 只要栈顶高度大于等于当前高度，就弹出 i，取新栈顶为 L，栈空取 -1。
  4. 令 k=R-L-1。若 nums[i]×k>threshold，立即返回 k；否则继续弹出。
  5. R<n 时将 R 入栈。所有候选都失败则返回 -1。

示例 1 的关键步骤

R=3，高度为 3：先弹出高度 4，宽度 1，面积 4；再弹出下标 1 的高度 3，宽度 2，面积 6，等于阈值仍失败。R=4，高度为 1：弹出下标 3，得到 L=0、R=4、k=3，面积 9>6，返回 3。

正确性证明

区间性质：i 入栈前已弹出左侧所有不小于它的栈顶，下面保留左侧最近严格更小值 L。i 能存活到 R，说明其后尚未出现小于等于它的值。因此 [L+1,R-1] 包含 i，且每个值都至少为 nums[i]。

返回值可靠：宽度为 k 的候选区间最小值就是 nums[i]；若乘积严格大于 threshold，则其每个元素都严格大于 threshold/k，返回 k 合法。

不会漏解：假设 [a,b] 是合法区间，最小值为 m，取该区间最右侧的最小值位置 i。i 左侧严格更小边界一定在 a 之前；右侧第一个小于等于 m 的位置一定在 b 之后。于是 i 弹出时的候选区间覆盖 [a,b]，宽度更大或相等，m 为正，面积仍超过阈值。该候选一定会被检查，除非更早已经找到另一个合法答案。

结束与失败：虚拟高度 0 小于所有实际元素，最终弹出全部下标。如果没有返回，根据覆盖性就不存在合法区间，因此 -1 正确。

边界与常见错误

  • 面积等于 threshold 时不合法；必须写 >，不能写 ≥。
  • 宽度 R-L-1 不包含两个边界。
  • 相等高度也弹出，本实现采用左 <、右 ≤ 的一致规则。
  • 末尾必须清栈，否则会漏掉单调上升序列。
  • 单元素按同样流程处理；不存在答案时返回 -1。
  • 最大乘积为 10¹⁴。Java 使用 long，C++ 使用 long long，乘法前就要提升类型。JavaScript Number 可精确表示该范围整数；Python 整数无需额外处理。
  • 返回任意有效长度即可，不要只和示例的单一数字比较。

复杂度与替代方案

时间 O(n)，空间 O(n)。每个下标最多入栈、出栈各一次。嵌套 while 的总出栈次数仍不超过 n。

  • 左右边界数组：分别计算每个位置两侧最近严格更小值，再检查最大跨度。时间 O(n)、空间 O(n)，实现更直观但多保存两个数组。
  • 并查集：按数值从大到小激活位置，合并相邻已激活段。相同值成组处理后，用当前值乘连通段长度判断。排序后总时间 O(n log n)、空间 O(n)。
  • 枚举所有区间：逐步维护最小值，O(n²) 时间、O(1) 额外空间，仅适用于小规模推导。

面试追问

  • 能对长度二分吗？不能直接二分。nums=[1,10,10,1]、threshold=15 时，仅 k=2 可行，k=1、3、4 都不可行，可行性不单调。
  • 如何同时返回区间？成功弹出时返回 [L+1,R-1]，不必再次搜索。
  • 与柱状图最大矩形有什么关系？候选矩形生成方式相同。本题只需遇到面积超过阈值的候选就结束，无需求全局最大面积。
  • 如果允许负数？固定高度扩大宽度的证明依赖正值约束，虚拟 0 也不能保证清栈，必须重新分析。

Java

class Solution {
    public int validSubarraySize(int[] nums, int threshold) {
        int n = nums.length;
        int[] stack = new int[n];
        int top = -1;
        for (int r = 0; r <= n; r++) {
            int current = r == n ? 0 : nums[r];
            while (top >= 0 && nums[stack[top]] >= current) {
                int i = stack[top--];
                int left = top >= 0 ? stack[top] : -1;
                int width = r - left - 1;
                if ((long) nums[i] * width > threshold) return width;
            }
            if (r < n) stack[++top] = r;
        }
        return -1;
    }
}

/**
 * @param {number[]} nums
 * @param {number} threshold
 * @return {number}

var validSubarraySize = function(nums, threshold) {
    const n = nums.length;
    const stack = [];
    for (let r = 0; r <= n; r++) {
        const current = r === n ? 0 : nums[r];
        while (stack.length && nums[stack[stack.length - 1]] >= current) {
            const i = stack.pop();
            const left = stack.length ? stack[stack.length - 1] : -1;
            const width = r - left - 1;
            if (nums[i] * width > threshold) return width;
        }
        if (r < n) stack.push(r);
    }
    return -1;
};

from typing import List

class Solution:
    def validSubarraySize(self, nums: List[int], threshold: int) -> int:
        n = len(nums)
        stack = []
        for r in range(n + 1):
            current = 0 if r == n else nums[r]
            while stack and nums[stack[-1]] >= current:
                i = stack.pop()
                left = stack[-1] if stack else -1
                width = r - left - 1
                if nums[i] * width > threshold:
                    return width
            if r < n:
                stack.append(r)
        return -1

C++

#include <vector>
using namespace std;

class Solution {
public:
    int validSubarraySize(vector<int>& nums, int threshold) {
        int n = static_cast<int>(nums.size());
        vector<int> stack;
        for (int r = 0; r <= n; ++r) {
            int current = r == n ? 0 : nums[r];
            while (!stack.empty() && nums[stack.back()] >= current) {
                int i = stack.back();
                stack.pop_back();
                int left = stack.empty() ? -1 : stack.back();
                int width = r - left - 1;
                if (1LL * nums[i] * width > threshold) return width;
            }
            if (r < n) stack.push_back(r);
        }
        return -1;
    }
};
