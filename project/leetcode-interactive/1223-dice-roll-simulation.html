Dice Roll Simulation题号 1223非会员题

Problem

题目说明

一个骰子模拟器每次会产生 1 到 6 中的一个点数。对点数 i，它连续出现的次数不能超过 rollMax[i - 1]。

给定投掷次数 n 和长度为 6 的数组 rollMax，计算恰好投掷 n 次时，能够得到多少个不同的合法点数序列。只要至少一个位置不同，两个序列就不同。答案对 10⁹ + 7 取模。

dieSimulator(n: integer, rollMax: integer[]) → integer

约束

  • 1 ≤ n ≤ 5000
  • rollMax.length = 6
  • 1 ≤ rollMax[i] ≤ 15

注意限制的是连续出现次数，而不是某个点数在整个序列中的总次数。

Examples

官方示例

EXAMPLE 01
n = 2 rollMax = [1,1,2,2,2,3]
输出 34

无约束时有 36 种；(1,1) 与 (2,2) 不合法。

EXAMPLE 02
n = 2 rollMax = [1,1,1,1,1,1]
输出 30

任意相邻两次都不能掷出相同点数。

EXAMPLE 03
n = 3 rollMax = [1,1,1,2,2,3]
输出 181

不同点数拥有不同的连续次数上限。

Complete solution

把“连续了几次”放进状态

核心洞察

判断下一次能否继续掷出同一点数，只需要知道两个信息：当前最后一个点数，以及它已经连续出现了几次。因此用 dp[face][streak] 统计当前长度下、末尾为 face 且末尾连续段长度为 streak 的序列数。

状态转移

从每个已有状态出发有两类选择：

  1. 换成其他 5 个点数，新状态的连续长度为 1。
  2. 继续相同点数，但只有 streak < rollMax[face] 时才允许，连续长度加 1。

完整过程

  1. 第一次投掷：六个 dp[face][1] 都设为 1。
  2. 从第 2 次到第 n 次，新建全零数组 next。
  3. 枚举所有非零状态，分别执行“切换”与合法的“延长”。
  4. 每次加法取模，最后汇总所有末尾状态。

转移式

next[g][1] += dp[f][s]，其中 g ≠ f
next[f][s+1] += dp[f][s]，其中 s < rollMax[f]

数组每轮滚动，旧轮状态用完即可丢弃。

正确性说明

不重不漏：任意长度为 k 的合法序列，删除最后一个点数后得到唯一的合法前缀。若末尾点数改变，它唯一来自“切换”；否则唯一来自“延长”。反过来，切换永远合法，延长只在未超过上限时发生。因此每个合法序列被构造恰好一次，非法序列不会进入状态。由长度归纳，最终汇总就是答案。

边界与复杂度

  • n = 1 时答案为 6。
  • 上限为 1 的点数不能连续出现两次。
  • 所有计数均对 1,000,000,007 取模。
  • 设 L = max(rollMax)。时间为 O(n · 6 · L · 6)，因骰子面数固定可写作 O(nL)；空间为 O(6L)。

替代方案

也可以只记录“以某点数结尾”的总量，再用前缀计数减去恰好形成超长连续段的序列，做到 O(n · 6)；但边界和下标更难维护。还可把状态转移写成矩阵，在 n 极大时快速幂。本题 n ≤ 5000，滚动状态更直接。

面试追问

  • 如何把六个点数推广到 m 种符号？
  • 若 n 达到 10¹⁸，怎样构造转移矩阵？
  • 若要求随机等概率采样一个合法序列，怎样利用后缀计数反向选择？

常见错误

  • 把 rollMax 当成整个序列中的出现总次数。
  • 切换点数后忘记把连续长度重置为 1。
  • 使用同一个数组原地转移，导致一轮内重复消费新状态。
  • 只在最终答案处取模，造成整数溢出或精度问题。

class Solution {
    private static final int MOD = 1_000_000_007;

    public int dieSimulator(int n, int[] rollMax) {
        long[][] dp = new long[6][16];
        for (int face = 0; face < 6; face++) {
            dp[face][1] = 1;
        }

        for (int roll = 2; roll <= n; roll++) {
            long[][] next = new long[6][16];
            for (int face = 0; face < 6; face++) {
                for (int streak = 1; streak <= rollMax[face]; streak++) {
                    long ways = dp[face][streak];
                    if (ways == 0) continue;

                    if (streak < rollMax[face]) {
                        next[face][streak + 1] =
                            (next[face][streak + 1] + ways) % MOD;
                    }
                    for (int other = 0; other < 6; other++) {
                        if (other != face) {
                            next[other][1] = (next[other][1] + ways) % MOD;
                        }
                    }
                }
            }
            dp = next;
        }

        long answer = 0;
        for (int face = 0; face < 6; face++) {
            for (int streak = 1; streak <= rollMax[face]; streak++) {
                answer = (answer + dp[face][streak]) % MOD;
            }
        }
        return (int) answer;
    }
}

from typing import List


class Solution:
    def dieSimulator(self, n: int, rollMax: List[int]) -> int:
        mod = 1_000_000_007
        dp = [[0] * 16 for _ in range(6)]
        for face in range(6):
            dp[face][1] = 1

        for _ in range(2, n + 1):
            nxt = [[0] * 16 for _ in range(6)]
            for face in range(6):
                for streak in range(1, rollMax[face] + 1):
                    ways = dp[face][streak]
                    if ways == 0:
                        continue

                    if streak < rollMax[face]:
                        nxt[face][streak + 1] = (
                            nxt[face][streak + 1] + ways
                        ) % mod
                    for other in range(6):
                        if other != face:
                            nxt[other][1] = (nxt[other][1] + ways) % mod
            dp = nxt

        return sum(sum(row) for row in dp) % mod
#include <vector>
using namespace std;

class Solution {
public:
    int dieSimulator(int n, vector<int>& rollMax) {
        const long long MOD = 1'000'000'007LL;
        vector<vector<long long>> dp(6, vector<long long>(16, 0));
        for (int face = 0; face < 6; ++face) dp[face][1] = 1;

        for (int roll = 2; roll <= n; ++roll) {
            vector<vector<long long>> next(6, vector<long long>(16, 0));
            for (int face = 0; face < 6; ++face) {
                for (int streak = 1; streak <= rollMax[face]; ++streak) {
                    long long ways = dp[face][streak];
                    if (ways == 0) continue;

                    if (streak < rollMax[face]) {
                        next[face][streak + 1] =
                            (next[face][streak + 1] + ways) % MOD;
                    }
                    for (int other = 0; other < 6; ++other) {
                        if (other != face) {
                            next[other][1] = (next[other][1] + ways) % MOD;
                        }
                    }
                }
            }
            dp.swap(next);
        }

        long long answer = 0;
        for (int face = 0; face < 6; ++face) {
            for (int streak = 1; streak <= rollMax[face]; ++streak) {
                answer = (answer + dp[face][streak]) % MOD;
            }
        }
        return static_cast<int>(answer);
    }
};
