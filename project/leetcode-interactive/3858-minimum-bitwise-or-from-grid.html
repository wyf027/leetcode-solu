3858. 按位或的最小值

每行选一个数，让最终 OR 尽可能小。

MEDIUM · 位运算

题意

每一行只能留下一张“数字卡”

给定二维数组 grid。必须从每一行恰好选择一个整数，返回所选整数按位或的最小可能值。

示例 1

grid = [[1, 5], [2, 4]]

输出 = 3

示例 2

grid = [[3, 5], [6, 4]]

输出 = 5

范围

m × n ≤ 10⁵
1 ≤ 数值 ≤ 10⁵

数值在 10⁵ 以内，因此只需关注第 16 位到第 0 位。

题解

单调可行性 + 贪心清位

核心洞察

如果目标 OR 为 mask，第 i 行必须存在一个数 x 满足 (x | mask) == mask，即 x 的每个 1 位都已经被 mask 允许。行与行之间的选择互不冲突，所以逐行存在即可。

完整过程

  1. 从全 1 掩码开始（0 到 16 位）。
  2. 由高到低尝试清除当前位，得到 candidate。
  3. 扫描每行是否存在子掩码数；可行就接受 candidate。

复杂度与边界

17 个二进制位；每次最多扫描全部元素。时间 O(17 · m · n)，额外空间 O(1)。单行时会选这一行中的最小值；相同行、只有高位的数都无需特判。

替代方案与追问

可枚举所有候选 OR 再判定，但没有利用位数小。追问：若数值上界变大，可将最高位设为所有数的最高有效位；若每行可选多个且需要记录选择，判定时存下第一个满足条件的位置。

常见错误

  • 把“存在一行的数”误写成所有数都必须是子掩码。
  • 从低位贪心清零，可能错失更小的高位收益。
  • 用 value & mask == value 时忘记括号。
