2198. 单因数三元组

Number of Single Divisor Triplets

三个不同下标，三个整除判断。只有一项成立，才算一次。

先理解规则，再展开底部题解与交互实验。页面为本地学习稿。

题目与接口

给定从 0 开始编号的正整数数组 nums。选出有顺序的下标三元组 (i, j, k)，三个下标必须两两不同。令 s = nums[i] + nums[j] + nums[k]，若三次判断 s % nums[i] == 0、s % nums[j] == 0、s % nums[k] == 0 中恰好一次为真，则该三元组有效。返回有效三元组总数。

下标不同不要求数值不同；判断按三个位置分别计数。交换下标顺序会得到另一个三元组。

singleDivisorTriplet(nums: integer[]) → long
3 ≤ nums.length ≤ 100000
1 ≤ nums[i] ≤ 100

函数名、参数与返回类型来自本地官方元数据。题面字段及代码片段为空；题意按公开存档转述，代码独立编写。

官方示例

示例 1

输入：nums = [4,6,7,3,2]
输出：12

数值组 {4,3,2} 的和为 9，仅 3 整除它；{4,7,3} 的和为 14，仅 7 整除它。每组的三个下标都有 6 种顺序，共 12 个。

示例 2

输入：nums = [1,2,2]
输出：6

总和 5 仅被 1 整除。两个 2 属于不同下标，三个下标的全部 6 种排列都有效。

示例 3

输入：nums = [1,1,1]
输出：0

总和 3 可被每个位置上的 1 整除，命中次数为 3，而非 1。

题解 · 按数值分组，按下标计数

核心洞察

数组长达 10⁵，但数值只有 100 种。整除条件只取决于三个数值，选择下标的数量则由频次决定。先统计 cnt[x]，再枚举有序数值三元组 (a,b,c)。

依次为三个位置选择下标，剩余选择数分别为：

A = cnt[a]
B = cnt[b] - [a == b]
C = cnt[c] - [a == c] - [b == c]
贡献 = A × B × C（仅在 B、C > 0 且恰好一项整除时）

方括号表示条件成立为 1，否则为 0。扣减表示该数值的某个下标已经被前面的位置占用。

交互实验 · 频次抽取与三路整除门

有序值组

每步对应一种有足够不同下标的有序数值三元组。绿色门表示能整除；只有一扇门开启时，贡献才加入累计值。

演示限制仅用于控制步数；下方提交代码支持完整约束。修改后需点击载入。

使用 Tab 切换控件，Enter / 空格操作按钮。重置保留已载入数组；减少动态效果偏好开启时，自动播放使用较慢节奏。

完整过程

  1. 扫描数组建立 101 格频次数组，收集出现过的数值。
  2. 三重循环枚举这些数值，顺序分别对应 i、j、k。
  3. 计算第二、第三位置剩余下标数。不足时跳过该值组。
  4. 求和并分别取模，将三次判断的布尔值转成 0 或 1 后相加。
  5. 命中次数为 1 时累加三项选择数的乘积；所有值组处理后返回总数。

例如 [1,2,2] 的有效值组为 (1,2,2)、(2,1,2)、(2,2,1)，每组对应 2 种下标选择，共 6。已经枚举值的顺序，不能再乘 6。

正确性证明

覆盖：每个有序且下标不同的三元组都唯一映射到它的有序数值组。循环会访问该值组。

计数：固定 (a,b,c) 后，第一位置有 cnt[a] 个选择；第二位置扣除可能被第一位置占用的下标；第三位置扣除前两个可能占用的下标。乘法原理得到恰好所有互不相同下标的选择数。

筛选与唯一性：同一值组的所有下标选择具有相同的和与整除结果，因此条件成立时全计入，否则全排除。不同有序值组对应的下标三元组互不重叠，求和即为答案。

边界与复杂度

  • 全部相等：和为 3a，三处判断都成立，贡献为 0。
  • 重复数值需要不同下标，频次不足必须跳过。
  • 1 总能整除和；若选了至少两个 1，必然不满足恰好一个。
  • 令 U 为不同值个数、M=100。时间 O(n + M + U³)，空间 O(M)。U ≤ 100，枚举至多 10⁶ 组。
  • 答案 ≤ n(n−1)(n−2) < 10¹⁵。Java 用 long、C++ 用 long long；JavaScript Number 在此界内可精确表示整数，Python int 自动扩展。

替代方案与常见错误

  • 直接枚举有序下标：O(n³)，仅适合很小输入。
  • 枚举 a ≤ b ≤ c，再用组合数选下标并乘 6；枚举量较小，但相等情况分支更多。
  • 错误：把“恰好一个”写成“至少一个”。
  • 错误：对数值去重后再数整除次数。重复数值必须按位置计数。
  • 错误：频次直接相乘，允许相同下标被重复使用。
  • 错误：用 32 位数相乘后才赋给 64 位结果；须在乘法开始前提升类型。

面试追问

若只数无序下标集合？这里每组三个不同下标有 6 种排列，整除条件对排列不变，结果除以 6。

值域扩大后怎么办？频次压缩仍把复杂度降到 U³；当 U 也很大时需进一步研究按和、整除关系的约束，不能继续依赖固定值域。

为什么不需要排序 nums？下标的相对大小不参与条件，频次保留了所有计数所需信息。

Java

class Solution {
    public long singleDivisorTriplet(int[] nums) {
        int[] cnt = new int[101];
        for (int x : nums) cnt[x]++;
        long ans = 0;
        for (int a = 1; a <= 100; a++) {
            if (cnt[a] == 0) continue;
            for (int b = 1; b <= 100; b++) {
                int second = cnt[b] - (a == b ? 1 : 0);
                if (second <= 0) continue;
                for (int c = 1; c <= 100; c++) {
                    int third = cnt[c] - (a == c ? 1 : 0)
                                       - (b == c ? 1 : 0);
                    if (third <= 0) continue;
                    int sum = a + b + c;
                    int hits = (sum % a == 0 ? 1 : 0)
                             + (sum % b == 0 ? 1 : 0)
                             + (sum % c == 0 ? 1 : 0);
                    if (hits == 1) ans += 1L * cnt[a] * second * third;
                }
            }
        }
        return ans;
    }
}

var singleDivisorTriplet = function(nums) {
    const cnt = Array(101).fill(0);
    for (const x of nums) cnt[x]++;
    const values = [];
    for (let x = 1; x <= 100; x++) if (cnt[x]) values.push(x);
    let ans = 0;
    for (const a of values) {
        for (const b of values) {
            const second = cnt[b] - Number(a === b);
            if (second <= 0) continue;
            for (const c of values) {
                const third = cnt[c] - Number(a === c) - Number(b === c);
                if (third <= 0) continue;

                const hits = Number(sum % a === 0)
                           + Number(sum % b === 0)
                           + Number(sum % c === 0);
                if (hits === 1) ans += cnt[a] * second * third;
            }
        }
    }
    return ans;
};

Python

from typing import List
from collections import Counter

class Solution:
    def singleDivisorTriplet(self, nums: List[int]) -> int:
        cnt = Counter(nums)
        ans = 0
        for a in cnt:
            for b in cnt:
                second = cnt[b] - (a == b)
                if second <= 0:
                    continue
                for c in cnt:
                    third = cnt[c] - (a == c) - (b == c)
                    if third <= 0:
                        continue
                    total = a + b + c
                    hits = sum(total % x == 0 for x in (a, b, c))
                    if hits == 1:
                        ans += cnt[a] * second * third
        return ans

C++

#include <vector>
using namespace std;

class Solution {
public:
    long long singleDivisorTriplet(vector<int>& nums) {
        int cnt[101] = {};
        for (int x : nums) ++cnt[x];
        vector<int> values;
        for (int x = 1; x <= 100; ++x)
            if (cnt[x]) values.push_back(x);
        long long ans = 0;
        for (int a : values) {
            for (int b : values) {
                int second = cnt[b] - (a == b);
                if (second <= 0) continue;
                for (int c : values) {
                    int third = cnt[c] - (a == c) - (b == c);
                    if (third <= 0) continue;
                    int s = a + b + c;
                    int hits = (s % a == 0) + (s % b == 0) + (s % c == 0);
                    if (hits == 1) ans += 1LL * cnt[a] * second * third;
                }
            }
        }
        return ans;
    }
};
