四个键的键盘

屏幕、剪贴板与有限按键次数组成一场小型资源调度。先理解规则，再亲手推进每一步决策；完整题解不会在首屏提前出现。

函数签名

maxA(n) → integer

给定最多 n 次按键，求屏幕上最多能得到多少个字符 A。

题目说明

先把四个动作的语义钉牢。

准确转述

想象一块初始为空的屏幕和一把只保留四个按键的键盘。在一次按键操作中，你可以选择：

A在屏幕末尾输入一个字符 A。
Ctrl-A选中屏幕上的全部内容。
Ctrl-C把当前选中的内容复制到剪贴板。
Ctrl-V把剪贴板内容追加到屏幕末尾。

给定整数 n，你最多只能按键 n 次。返回操作结束后屏幕上能够得到的 A 的最大数量。

参数与返回值

n：可用的最大按键次数；maxA(n) 返回屏幕上最多的 A 数量。

约束

  • 1 ≤ n ≤ 50
  • n 为整数。
  • 屏幕与剪贴板初始都为空；粘贴不会清空剪贴板。
示例 1
输入
n = 3
输出
3
说明
连续按三次 A，屏幕得到 AAA。
示例 2
输入
n = 7
输出
9
说明
依次按 A, A, A, Ctrl-A, Ctrl-C, Ctrl-V, Ctrl-V，屏幕最终有 9 个 A。

完整题解：枚举最后一次复制

关键不是记录剪贴板里的每一种可能，而是抓住最优序列的最后一段：一旦执行最后一次 Ctrl-A, Ctrl-C，余下操作只需要连续粘贴。

核心洞察

令 dp[i] 表示最多使用 i 次按键后，屏幕上能够得到的最大 A 数量。对于总预算 i，有两类结尾：

  1. 完全不复制：连续输入 i 次 A，得到 i。
  2. 在第 j 次操作后已有 dp[j] 个 A，再用两次操作全选、复制，最后粘贴 i-j-2 次。
dp[i] = max(i, dp[j] × (i - j - 1)), 1 ≤ j ≤ i - 3

乘数中包含复制前屏幕已有的 1 份，以及后续的 i-j-2 份粘贴，总计 i-j-1 份。

完整过程

  1. 建立长度为 n + 1 的数组，dp[0] = 0。
  2. 依次计算 i = 1..n。
  3. 先把 dp[i] 设为 i，对应全部直接输入。
  4. 枚举最后一次复制前的操作数 j。全选和复制至少占 2 次，且至少要留 1 次粘贴，所以 j ≤ i - 3。
  5. 用 dp[j] × (i-j-1) 更新最大值，最终返回 dp[n]。

以 n = 7 为例

取 j = 3：先用 3 次按键得到 AAA，再全选、复制，并粘贴 2 次。最终有 3 × 3 = 9 个 A。

正确性证明

命题：对每个 0 ≤ i ≤ n，算法计算出的 dp[i] 等于最多使用 i 次按键能够得到的最大 A 数量。

基础情形：i = 0 时不能按键，屏幕为空，dp[0] = 0 正确。

归纳步骤：假设所有小于 i 的状态都正确。任取一个使用不超过 i 次按键的最优方案：若它没有有效的复制粘贴阶段，直接输入至多得到 i 个 A，算法已纳入基线；若它有复制阶段，考察最后一次 Ctrl-A, Ctrl-C。设这两次操作之前用了 j 次按键，则依据归纳假设，那时屏幕至多有 dp[j] 个 A。之后剩余 i-j-2 次操作全部粘贴不会劣于插入其他操作，因此最终至多得到 dp[j] × (i-j-1)。算法枚举了所有合法 j，所以不会漏掉最优值；而每个候选都对应一条实际可执行的序列，所以不会高估。故 dp[i] 正确。

由数学归纳法，dp[n] 即所求答案。

边界情况

  • n ≤ 3 时没有空间完成“全选、复制、粘贴”，答案就是 n。
  • n = 4..6 时复制并不会严格优于直接输入，初始化基线即可覆盖。
  • 相同最大值来自多条序列时，只需返回数量，无需保存路径。

复杂度

  • 时间复杂度：O(n²)，每个 i 枚举此前的切分点。
  • 空间复杂度：O(n)，保存一维动态规划数组。
  • 在 n ≤ 50 的范围内十分充足。

常见错误

  • 把倍数写成 i-j-2，漏掉复制前屏幕原有的那一份。
  • 忘记全选和复制合计占用两次按键。
  • 只从原始输入次数出发，忽略 dp[j] 本身也可能由复制得到。

替代方案

记忆化搜索：可把“剩余次数、屏幕数量、剪贴板数量”作为状态，枚举四种按键。它更贴近操作定义，但状态更多，也容易产生无效的全选或复制操作。

分段乘法观察：当 n 很大时，可以进一步分析每轮复制粘贴的最佳分段长度，得到更紧凑的数学策略。不过本题约束很小，二维思考压缩成一维 DP 后更直观、稳健。

面试追问

  • 如果要求返回一条最优按键序列，如何记录前驱和决策？
  • 如果 Ctrl-A 和 Ctrl-C 各自消耗不同成本，转移式如何变化？
  • 如果剪贴板允许追加复制，状态是否还可只用一维数组？
  • 能否从最优分段的结构出发，把大规模输入优化到线性或对数级思考？

四语言完整代码

四份实现使用相同的一维动态规划转移，可直接对应各语言的 LeetCode 提交形式。

Java · O(n²) / O(n)
class Solution {
    public int maxA(int n) {
        int[] dp = new int[n + 1];

        for (int i = 1; i <= n; i++) {
            dp[i] = i;
            for (int j = 1; j <= i - 3; j++) {
                int candidate = dp[j] * (i - j - 1);
                dp[i] = Math.max(dp[i], candidate);
            }
        }

        return dp[n];
    }
}
