LCR 097 · HARD

不同的子序列

给定字符串 s 和 t，计算 s 的子序列中等于 t 的不同方案数。删除不同位置的字符得到的相同子序列，也算不同方案。

题意

从 s 中删除任意字符（但不改变剩余字符顺序），使其成为 t。返回所有可行删除方案的数量。

示例

s = "rabbbit", t = "rabbit" → 3

s = "babgbag", t = "bag" → 5

约束

1 ≤ s.length, t.length ≤ 1000；s 和 t 由英文字母组成。题目保证结果符合 32 位有符号整数范围。

分步交互：一维 DP

从右向左更新 dp，避免同一源字符被重复使用。

准备就绪。

核心洞察

令 dp[j] 表示已处理的 s 前缀中，能形成 t 前 j 个字符的方案数。每个 s 字符都可以跳过；若它等于 t[j-1]，还可用它匹配 t 的第 j 个字符，于是累加旧的 dp[j-1]。

完整过程

  1. 初始化 dp[0]=1：空目标只有一种匹配方法。
  2. 依次扫描 s 的每个字符。
  3. 对 j 从 t.length 递减到 1；字符相等时执行 dp[j]+=dp[j-1]。

边界

  • 空目标永远有 1 种方案。
  • s 比 t 短时答案为 0。
  • 必须逆序更新，否则一个源字符会在同轮匹配多个目标位置。

复杂度

时间 O(|s|·|t|)，通过滚动数组将空间从 O(|s|·|t|) 压缩为 O(|t|)。

替代方案与追问

二维 DP 更易展示状态含义，但占用更多空间。追问：若 t 很短且字符集有限，可预处理 s 中每种字符的位置并用二分/组合思路优化特定场景；若要求列举方案，需保存转移路径而非只保留计数。

常见错误

  • 正序更新一维 dp，重复使用当前字符。
  • 把 dp[0] 初始化成 0。
  • 把“子序列”误当成必须连续的“子串”。

官方签名代码

// Java
class Solution { public int numDistinct(String s, String t) { long[] dp=new long[t.length()+1]; dp[0]=1; for(char c:s.toCharArray())for(int j=t.length();j>0;j--)if(c==t.charAt(j-1))dp[j]+=dp[j-1]; return (int)dp[t.length()]; } }
// JavaScript
var numDistinct = function(s, t) { const dp=Array(t.length+1).fill(0); dp[0]=1; for(const c of s)for(let j=t.length;j>0;j--)if(c===t[j-1])dp[j]+=dp[j-1]; return dp[t.length]; };
# Python
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        dp = [0] * (len(t) + 1)
        dp[0] = 1
        for c in s:
            for j in range(len(t), 0, -1):
                if c == t[j - 1]: dp[j] += dp[j - 1]
        return dp[-1]
// C++
class Solution { public: int numDistinct(string s, string t) { vector<unsigned long long> dp(t.size()+1); dp[0]=1; for(char c:s)for(int j=t.size();j>0;--j)if(c==t[j-1])dp[j]+=dp[j-1]; return dp[t.size()]; } };
