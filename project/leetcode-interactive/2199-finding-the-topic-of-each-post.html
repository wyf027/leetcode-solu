找到每篇文章的主题

Finding the Topic of Each Post

一个词，可能指向多个主题。一次出现，也可能只是另一个词的前缀。

从两张关系表出发，为每篇文章输出准确的主题标签。先理解规则，再打开底部题解。

阅读题目 ↗交互实验 ↗测试与验证 ↗
01 / PROBLEM

输入是两张表，输出是每篇文章的主题

Keywords 中每一行将一个关键词关联到一个主题；Posts 中每一行保存一篇文章。若文章包含某主题的至少一个完整关键词，就给文章赋予该主题，比较时忽略大小写。

Keywords

字段类型
topic_idINT
wordVARCHAR(25)

联合主键为 (topic_id, word)。同主题可有多个词，同词也可对应多个主题。

Posts

字段类型
post_idINT
contentVARCHAR(100)

post_id 为主键。content 只含英文字母与空格。

  • 输出字段为 post_id 与 topic，每篇文章一行，结果行顺序任意。
  • 匹配到的主题 ID 必须去重、按数值升序排列，用英文逗号连接，不加空格。
  • 完全没有匹配时，topic 为字符串 Ambiguous!。多个主题不是歧义。
  • 整词匹配：war 不能匹配 warning；Vaccine 不能匹配 vaccinated。

约束说明：长度来自官方 SQL 建表元数据；公开题面未给出表行数和 ID 数值范围，不自行补造。数据库题没有四种通用语言的官方函数签名。

READY FOR THE REASONING?

从匹配规则走到 SQL

核心洞察、证明与五份代码都在这里。

题解 · 保留文章，再归并主题

核心洞察

这不是机器学习分类，而是词典匹配。将文章与关键词都转成小写，并在两端补一个空格。查找 空格 + keyword + 空格 ，就能同时照顾整词边界、文章开头与结尾。INSTR 检查字面子串，不把关键词中的字符当作 LIKE 通配符。

完整过程

  1. 对每篇文章逐一考虑 Keywords 的所有行，使用补空格后的规范化字符串决定是否连接。
  2. 以 Posts 为左表执行 LEFT JOIN，让没有匹配的文章也保留一行，关键词侧为 NULL。
  3. 按 post_id 分组。GROUP_CONCAT 忽略 NULL，对 topic_id 去重，并在聚合内部按数值排序，用逗号连接。
  4. 若聚合结果为 NULL，用 COALESCE 替换为 Ambiguous!。这也覆盖 Keywords 为空的情况。

演示按单词扫描，SQL 按关键词行匹配；两者在本题以空格分词的输入域上收集同一个主题集合。重复出现一个词、或同主题多个词，不会改变最终集合。

正确性说明

匹配可靠且完整：补空格后，完整单词的左右都有空格，因而真实关键词一定能被查到；反过来，被查到的关键词两侧都是空格，不可能只是 warning 中的 war。LOWER 统一大小写。

聚合恰好得到所有主题：连接行与合法关键词匹配一一对应，所有合法主题都会进入分组。DISTINCT 只删除重复 ID，不丢主题；聚合内排序满足输出顺序。无匹配时左连接仍保留文章，聚合为空，再得到规定字符串。因此每篇文章恰好有一行正确答案。

边界与常见错误

  • 主题 ID 2 与 10 应输出 2,10；不能把 ID 先当字符串排序。
  • 不要写 INNER JOIN，也不要把匹配条件移到 WHERE 后过滤 NULL，这会丢掉无主题文章。
  • 不要只检查子串，或只补文章一侧空格；前者误收前缀，后者漏掉首尾单词。
  • 必须在 GROUP_CONCAT 内写 ORDER BY；外层排序不能保证主题字符串内部顺序。
  • 一个词可对应多个主题，不能用 word → 单个 ID 的字典覆盖其他关联。
  • 生产数据如包含标点、多语言或短语，应先定义分词规则；不能直接扩展本题的空格边界假设。

复杂度

记 P 为文章数、K 为关键词行数、L 为文章最大长度、W 为关键词最大长度（元数据为 25），mᵢ 为文章 i 的匹配关键词行数。朴素子串搜索的保守上界为 O(PKLW + Σ mᵢ log(mᵢ + 1))；将 W 视为固定上限时可写成 O(PKL + Σ mᵢ log(mᵢ + 1))。真实 SQL 计划与字符串搜索实现可能不同。

单篇流式处理需要保存最多 O(K) 个匹配 ID；SQL 若物化连接中间结果，最坏可达 O(PK) 行，并需要排序/聚合缓冲，不能笼统称为 O(1) 空间。输出字符串还需计入结果空间。

四语言参考用分词集合检测关键词：单篇构词集合 O(L)，再扫描 K 行，并对最多 K 个 ID 排序；典型上界 O(P(L + KW + K log(K + 1)))，额外工作空间 O(L + K)，不计全部输出。

替代方案与面试追问

  • 正则边界：可匹配 (^| )keyword( |$)，需显式处理大小写和正则元字符转义，具体语法依数据库而异。
  • 先分词再连接：将文章拆成 (post_id, word)，与规范化关键词等值连接，便于索引；代价是分词步骤与中间行数。
  • 大量文本怎么做？建立 word → 主题集合的倒排映射，逐词查表，避免每篇文章扫描整张词典；数据库端可将分词结果规范化后索引。
  • GROUP_CONCAT 有容量限制怎么办？生产中按需要设置会话 group_concat_max_len 或使用结构化聚合并在应用层编码，防止长结果被截断；本题元数据未提供主题总数上限。
  • 多主题为什么不歧义？规则明确允许多主题；只有命中集合为空才输出 Ambiguous!。

MySQL · 官方可提交语言

SELECT p.post_id,
       COALESCE(
           GROUP_CONCAT(DISTINCT k.topic_id
                        ORDER BY k.topic_id SEPARATOR ','),
           'Ambiguous!'
       ) AS topic
FROM Posts AS p
LEFT JOIN Keywords AS k
  ON INSTR(CONCAT(' ', LOWER(p.content), ' '),
           CONCAT(' ', LOWER(k.word), ' ')) > 0
GROUP BY p.post_id;

Java · 本地语义参考（Java 17）

import java.util.*;
import java.util.stream.Collectors;

public class Main {
    record Keyword(int topicId, String word) {}
    record Post(int postId, String content) {}
    record Result(int postId, String topic) {}

    static List<Result> findTopic(List<Keyword> keywords, List<Post> posts) {
        List<Result> result = new ArrayList<>();
        for (Post p : posts) {
            Set<String> words = new HashSet<>(Arrays.asList(
                p.content().toLowerCase(Locale.ROOT).split(" +")));
            TreeSet<Integer> topics = new TreeSet<>();
            for (Keyword k : keywords) {
                if (words.contains(k.word().toLowerCase(Locale.ROOT))) {
                    topics.add(k.topicId());
                }
            }
            String topic = topics.isEmpty() ? "Ambiguous!" :
                topics.stream().map(String::valueOf)
                    .collect(Collectors.joining(","));
            result.add(new Result(p.postId(), topic));
        }
        return result;
    }

    public static void main(String[] args) {
        var keywords = List.of(new Keyword(1, "handball"),
            new Keyword(1, "football"), new Keyword(3, "WAR"),
            new Keyword(2, "Vaccine"));
        var posts = List.of(new Post(1, "We call it soccer They call it football hahaha"),
            new Post(2, "Americans prefer basketball while Europeans love handball and football"),
            new Post(3, "stop the war and play handball"),
            new Post(4, "warning I planted some flowers this morning and then got vaccinated"));
        findTopic(keywords, posts).forEach(System.out::println);
    }
}

function findTopic(keywords, posts) {
  return posts.map(([postId, content]) => {
    const words = new Set(content.toLowerCase().split(/ +/).filter(Boolean));
    const topics = new Set();
    for (const [topicId, word] of keywords) {
      if (words.has(word.toLowerCase())) topics.add(topicId);
    }
    return [postId, topics.size
      ? [...topics].sort((a, b) => a - b).join(',')
      : 'Ambiguous!'];
  });
}

def find_topic(keywords, posts):
    result = []
    for post_id, content in posts:
        words = set(content.lower().split())
        topics = {topic_id for topic_id, word in keywords
                  if word.lower() in words}
        topic = ','.join(map(str, sorted(topics))) if topics else 'Ambiguous!'
        result.append([post_id, topic])
    return result

#include <algorithm>
#include <cctype>
#include <iostream>
#include <set>
#include <sstream>
#include <string>
#include <unordered_set>
#include <utility>
#include <vector>
using namespace std;

string lower(string s) {
    for (char& c : s) c = static_cast<char>(tolower(static_cast<unsigned char>(c)));
    return s;
}

vector<pair<int, string>> findTopic(
    const vector<pair<int, string>>& keywords,
    const vector<pair<int, string>>& posts) {
    vector<pair<int, string>> result;
    for (const auto& [postId, content] : posts) {
        istringstream input(lower(content));
        unordered_set<string> words;
        string word;
        while (input >> word) words.insert(word);
        set<int> topics;
        for (const auto& [topicId, keyword] : keywords) {
            if (words.count(lower(keyword))) topics.insert(topicId);
        }
        string topic;
        for (int id : topics) {
            if (!topic.empty()) topic += ',';
            topic += to_string(id);
        }
        result.emplace_back(postId, topics.empty() ? "Ambiguous!" : topic);
    }
    return result;
}

int main() {
    vector<pair<int, string>> keywords = {
        {1, "handball"}, {1, "football"}, {3, "WAR"}, {2, "Vaccine"}};
    vector<pair<int, string>> posts = {
        {1, "We call it soccer They call it football hahaha"},
        {2, "Americans prefer basketball while Europeans love handball and football"},
        {3, "stop the war and play handball"},
        {4, "warning I planted some flowers this morning and then got vaccinated"}};
    for (const auto& [postId, topic] : findTopic(keywords, posts))
        cout << postId << " | " << topic << '\n';
}
