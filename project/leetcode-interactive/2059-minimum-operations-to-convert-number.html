转化数字的最小运算数

Minimum Operations to Convert Number

三个运算按钮，一条数值边界。你能用最少几步抵达目标？

官方题目 ↗

01 / 题目与规则

给定元素互不相同的整数数组 nums，以及整数 start 和 goal。令 x = start。只要当前 x 位于闭区间 [0, 1000]，就能任选一个 nums[i]，执行下面三种运算中的一种。

加法 +

x → x + nums[i]

减法 −

x → x - nums[i]

按位异或 ^

x → x ^ nums[i]

每个数组元素都可以重复使用，顺序不限。一次运算可以让结果落在区间外，但此后不能再执行任何运算。求到达 goal 的最少运算次数；无法到达时返回 -1。

函数参数：minimumOperations(nums, start, goal) → integer。^ 表示二进制位的异或，不是乘方。

约束

  • 1 ≤ nums.length ≤ 1000
  • -10⁹ ≤ nums[i], goal ≤ 10⁹
  • 0 ≤ start ≤ 1000
  • start ≠ goal
  • nums 中的整数互不相同。

02 / 官方示例

示例 1

nums = [2,4,12]
start = 2
goal = 12
输出 = 2

可走 2 → 14 → 12：先加 12，再减 2，共 2 次。

示例 2

nums = [3,5,7]
start = 0
goal = -4
输出 = 2

可走 0 → 3 → -4：先加 3，再减 7。最后一步越界仍有效。

示例 3

nums = [2,8,16]
start = 0
goal = 1
输出 = -1

不存在把 0 变为 1 的合法操作序列。

04 / 题解：有限状态上的最短路

核心洞察

把一个数看作一个状态，把一次合法运算看作一条长度为 1 的有向边。所有边代价相同，用广度优先搜索（BFS）逐层寻找最短路。可继续扩展的状态只有 0…1000 这 1001 个数；区间外的结果只能作为终点候选。

先判断是否等于 goal，再判断是否在区间内。如果先丢弃越界结果，就会漏掉 goal = -4 这样的合法终点。

完整过程

  1. 把 start 放入队列，距离设为 0，同时标记已访问。
  2. 按队列顺序取出 x，对每个数组元素 a 计算 x+a、x-a、x^a。
  3. 如果候选值等于目标，立即返回 dist[x]+1。
  4. 否则，只把处于 [0,1000] 且未访问的候选加入队列。入队时标记，防止重复入队。
  5. 队列耗尽仍未命中目标，返回 -1。

为什么正确
状态充分：从当前数出发允许的操作只取决于这个数和 nums，与到达路径无关。因此同一数无需重复扩展。
层序最优：起点距离为 0。FIFO 队列确保距离较小的状态先扩展，从距离 d 的状态产生的候选路径长度为 d+1。首次命中目标时，不可能还有更短但未考察的路径。
范围裁剪安全：题目禁止从区间外继续操作，所以未命中的越界候选永远不能成为有效中间节点。所有区间内未访问后继都会被入队；若搜索耗尽，任何合法路径都无法到达目标。


边界与复杂度
0 和 1000 都可以继续运算；目标可以在区间外。负数元素合法，不能用“只能增大”之类的假设。0 会产生自环，由访问标记消除。约束保证 start ≠ goal，代码仍保留相等时返回 0 的防御分支。
设 n = nums.length、U = 1001。每个区间内状态最多扩展一次，每次枚举 3n 个候选：时间 O(U·n)，额外空间 O(U)。在本题固定范围下，也可记为 O(n) 时间和 O(1) 有界空间，但写出 U 更清楚。
该复杂度对应下方提交代码；可视化另存层记录以支持回退。




替代方案
Dijkstra 能处理此图，但所有边都是单位权，堆会增加开销。DFS 首次到达不保证最短，需要额外剪枝与距离更新。双向 BFS 可以考虑，不过越界目标没有合法出边，反向端必须枚举合法前驱，不能直接复用正向扩展规则，当前只有 1001 个可扩展状态时收益有限。
面试追问
  • 如何输出路径？记录每个新状态的前驱和使用的运算；命中 goal 后逆序回溯。演示中的路径使用这种方式。
  • 如果运算代价不同？非负权用 Dijkstra；若权仅为 0/1，可用 0-1 BFS。
  • 为什么不能按离 goal 的绝对距离贪心？异或并不单调，先远离目标的路径也可能更短。
  • 如果范围扩大？访问数组可能不合适，可改哈希集合，但搜索规模也会增大，需要重新评估策略。
常见错误
  • 先做范围过滤，再判断 goal，漏掉合法越界终点。
  • 把越界结果加入队列并继续扩展，产生题目禁止的路径。
  • 出队时才标记访问，导致重复入队；或者完全不去重，困在自环中。
  • 把 ^ 当成幂运算，或只做加减而漏掉异或。
  • JavaScript 用 shift() 反复移动数组；使用递增队首下标即可。

Java
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.Queue;

class Solution {
    public int minimumOperations(int[] nums, int start, int goal) {
        if (start == goal) return 0;
        int[] dist = new int[1001];
        Arrays.fill(dist, -1);
        Queue<Integer> queue = new ArrayDeque<>();
        queue.offer(start);
        dist[start] = 0;
        while (!queue.isEmpty()) {
            int x = queue.poll();
            for (int a : nums) {
                for (int y : new int[] {x + a, x - a, x ^ a}) {
                    if (y == goal) return dist[x] + 1;
                    if (y >= 0 && y <= 1000 && dist[y] == -1) {
                        dist[y] = dist[x] + 1;
                        queue.offer(y);
                    }
                }
            }
        }
        return -1;
    }
}

var minimumOperations = function(nums, start, goal) {
    if (start === goal) return 0;
    const dist = new Array(1001).fill(-1);
    const queue = [start];
    dist[start] = 0;
    for (let head = 0; head < queue.length; head++) {
        const x = queue[head];
        for (const a of nums) {
            for (const y of [x + a, x - a, x ^ a]) {
                if (y === goal) return dist[x] + 1;
                if (y >= 0 && y <= 1000 && dist[y] === -1) {
                    dist[y] = dist[x] + 1;
                    queue.push(y);
                }
            }
        }
    }
    return -1;
};


Python 3
from collections import deque
from typing import List

class Solution:
    def minimumOperations(self, nums: List[int], start: int, goal: int) -> int:
        if start == goal:
            return 0
        dist = [-1] * 1001
        dist[start] = 0
        queue = deque([start])
        while queue:
            x = queue.popleft()
            for a in nums:
                for y in (x + a, x - a, x ^ a):
                    if y == goal:
                        return dist[x] + 1
                    if 0 <= y <= 1000 and dist[y] == -1:
                        dist[y] = dist[x] + 1
                        queue.append(y)
        return -1

                        q.push(y);
                    }
                }
            }
        }
        return -1;
    }
};
