设计电影租借系统

Design Movie Rental System

一家连锁影碟店，四种操作。你能让库存查询与租借报告始终保持正确的前五名吗？

LeetCode 官方题目 ↗

01 / 任务契约

共有 n 家店。每条 entries[i] = [shop, movie, price] 表示该店的一份电影拷贝及其固定租金；同一家店的同一电影至多一份，初始化时全部可租。

  • MovieRentingSystem(int n, int[][] entries)：初始化。
  • List<Integer> search(int movie)：返回拥有该电影可租拷贝的前 5 家店，按价格、店号依次升序。
  • void rent(int shop, int movie)：借出指定拷贝。
  • void drop(int shop, int movie)：归还指定拷贝。
  • List<List<Integer>> report()：返回已租拷贝前 5 名的 [shop,movie]，按价格、店号、电影号依次升序。

不足 5 项返回全部，零项返回 []。报告可包含相同电影号。题目保证租借和归还操作合法。

约束

  • 1 ≤ n ≤ 3 × 10⁵；1 ≤ entries.length ≤ 10⁵。
  • 0 ≤ shop < n；1 ≤ movie, price ≤ 10⁴。
  • 每家店的每个电影号至多出现一次。
  • search、rent、drop、report 总调用数不超过 10⁵。

输入（方法数组 + 完整参数数组）

["MovieRentingSystem","search","rent","rent","report","drop","search"]
[[3,[[0,1,5],[0,2,6],[0,3,7],[1,1,4],[1,2,7],[2,1,5]]],[1],[0,1],[1,2],[],[1,2],[2]]

输出

[null,[1,0,2],null,null,[[0,1],[1,2]],null,[0,1]]

查询电影 1 时，店 1 价格为 4，店 0 与店 2 都为 5，所以返回 [1,0,2]。借出 (0,1) 与 (1,2) 后，报告按租金 5、7 排列；归还 (1,2) 后，电影 2 的可租商店又恢复为 [0,1]。

先思考：一次租借会影响哪些查询？重复租还后，旧记录应当怎样处理？

03 / 题解：版本票据与惰性删除

核心洞察

为每部电影维护一个可租最小堆，再维护一个全局已租最小堆。哈希表保存每份拷贝的价格、版本号和租借状态。堆里放不可变票据 (price, shop, movie, version)，租还时只更新权威状态、递增版本，并向目标堆加入新票据。旧票据留到查询时再清理。

前三个字段决定业务顺序，版本只在同一拷贝的历史记录间破平局。必须同时核对版本与状态：只核对状态会让一次“租→还”之前的旧票据重新有效，产生重复结果。

交互实验 / 看见旧票据失效

使用官方库存，随后追加一次租还循环。面板按堆的弹出顺序展示票据，不代表堆数组的物理布局。红色标为失效，查询会移除它们；有效前五项暂存后放回。

本步结果与清理



完整过程
  1. 初始化哈希表，版本为 0、状态为可租；将每份票据加入对应电影堆。
  2. rent / drop：修改状态，版本加 1，创建新票据压入已租堆 / 可租堆。
  3. search / report：不断弹出最小票据。版本不匹配或状态不匹配则丢弃，否则加入临时结果。
  4. 取到 5 个有效票据或堆空后停止，将有效票据全部压回原堆。search 取店号；report 取店号与电影号。


正确性论证
覆盖不变量：每份拷贝在当前状态对应的堆中恰有一张当前版本票据。初始化成立；每次租还使旧版本失效，并在新堆加入唯一新版本。查询仅丢弃失效记录，将有效记录放回，故不变量保持。
顺序不变量：堆按 (价格, 店号, 电影号, 版本) 弹出；去除失效票据后，剩余序列仍按题目业务键升序。由覆盖不变量，它恰好包含全部目标拷贝且无重复，取前五项即是要求的结果。


复杂度：不要把摊还写成单次保证
令 E 为 entries 数量，Q 为总调用数，H = E + Q。以下代码逐个入堆，初始化 O(E log(E+1))。单次租还 O(log H)。若查询清理了 S 张失效票据，时间为 O((S+5) log H)，最坏一次可能清理大量历史记录。每张失效票据至多被丢弃一次，所有操作合计 O((E+Q) log H)，空间 O(E+Q)；哈希访问按期望 O(1) 计。不存在电影的空堆条目也至多 O(Q)。


边界与常见错误
  • 空堆、不存在电影、少于五份都要自然结束；无须遍历 n 家商店。
  • 同价时 search 依店号；report 还需按电影号。电影号相同但店不同是不同拷贝。
  • 不能只存 rented 布尔值来判定旧票据，也不能让堆票据引用可变排序字段。
  • 有效票据要在本次收集结束后统一放回；边弹边放会反复取到同一项。
  • Java 组合键先转 long：最大 shop × 10001 会超过 32 位整数。JS 用字符串键避免位运算截断。


替代方案
Java TreeSet / C++ set 可为每部电影与全部已租拷贝维护有序集合，租还直接删除并插入，空间 O(E)，更新最坏 O(log E)，取前五的迭代成本 O(5)（定位开头视容器而定）。Python 与 JavaScript 标准库没有同等有序集合，版本堆能保持四语言一致。每次全量排序实现简单，但 E、Q 都达到 10⁵ 时不可取。


面试追问
  • 如何保证查询延迟上界？采用支持删除的有序树，而非堆积历史票据。
  • 堆空间持续增长怎么办？历史票据过多时按权威状态重建堆，并分析重建摊还成本。
  • 价格可以修改吗？价格变更也必须增加版本并发新票据，不能直接改堆内元素。
  • 并发租同一份拷贝怎么办？实际系统需要原子状态转换；本题是合法的串行调用。

from typing import List
from collections import defaultdict
from heapq import heappush, heappop

class MovieRentingSystem:
    def __init__(self, n: int, entries: List[List[int]]):
        self.state = {}  # (shop, movie) -> [price, version, rented]
        self.available = defaultdict(list)
        self.rented = []
        for s, m, p in entries:
            self.state[s, m] = [p, 0, False]
            heappush(self.available[m], (p, s, m, 0))

    def _take(self, heap, rented):
        keep = []
        while heap and len(keep) < 5:
            ticket = heappop(heap)
            p, s, m, v = ticket
            current = self.state[s, m]
            if current[1] == v and current[2] == rented:
                keep.append(ticket)
        for ticket in keep:
            heappush(heap, ticket)
        return keep

    def search(self, movie: int) -> List[int]:
        return [t[1] for t in self._take(self.available[movie], False)]

    def _move(self, s, m, rented):
        state = self.state[s, m]
        state[1] += 1
        state[2] = rented
        heap = self.rented if rented else self.available[m]
        heappush(heap, (state[0], s, m, state[1]))

    def rent(self, shop: int, movie: int) -> None:
        self._move(shop, movie, True)

    def drop(self, shop: int, movie: int) -> None:
        self._move(shop, movie, False)

    def report(self) -> List[List[int]]:
        return [[t[1], t[2]] for t in self._take(self.rented, True)]

class MinHeap {
    constructor() { this.a = []; }
    less(x, y) {
        for (let i = 0; i < 4; i++) {
            if (x[i] !== y[i]) return x[i] < y[i];
        }
        return false;
    }
    push(x) {
        const a = this.a;
        a.push(x);
        let i = a.length - 1;
        while (i > 0) {
            const p = (i - 1) >> 1;
            if (!this.less(x, a[p])) break;
            a[i] = a[p]; i = p;
        }
        a[i] = x;
    }
    pop() {
        const a = this.a, first = a[0], last = a.pop();
        if (a.length) {
            let i = 0;
            while (i * 2 + 1 < a.length) {
                let c = i * 2 + 1;
                if (c + 1 < a.length && this.less(a[c + 1], a[c])) c++;
                if (!this.less(a[c], last)) break;
                a[i] = a[c]; i = c;
            }
            a[i] = last;
        }
        return first;
    }
}
class MovieRentingSystem {
    constructor(n, entries) {
        this.state = new Map();
        this.available = new Map();
        this.rented = new MinHeap();
        for (const [s, m, p] of entries) {
            this.state.set(`${s},${m}`, {p, v: 0, rented: false});
            if (!this.available.has(m)) this.available.set(m, new MinHeap());
            this.available.get(m).push([p, s, m, 0]);
        }
    }
    take(heap, rented) {
        if (!heap) return [];
        const keep = [];
        while (heap.a.length && keep.length < 5) {
            const t = heap.pop();
            const current = this.state.get(`${t[1]},${t[2]}`);
            if (current.v === t[3] && current.rented === rented) keep.push(t);
        }
        for (const t of keep) heap.push(t);
        return keep;
    }
    search(movie) {
        return this.take(this.available.get(movie), false).map(t => t[1]);
    }
    move(s, m, rented) {
        const c = this.state.get(`${s},${m}`);
        c.v++; c.rented = rented;
        const heap = rented ? this.rented : this.available.get(m);
        heap.push([c.p, s, m, c.v]);
    }
    rent(shop, movie) { this.move(shop, movie, true); }
    drop(shop, movie) { this.move(shop, movie, false); }
    report() { return this.take(this.rented, true).map(t => [t[1], t[2]]); }
}
Java
import java.util.*;

class MovieRentingSystem {
    // Tickets are immutable [price, shop, movie, version].
    private final Comparator<int[]> order = (a, b) -> {
        for (int i = 0; i < 4; i++) {
            int c = Integer.compare(a[i], b[i]);
            if (c != 0) return c;
        }
        return 0;
    };
    private final Map<Long, int[]> state = new HashMap<>();
    private final Map<Integer, PriorityQueue<int[]>> available = new HashMap<>();
    private final PriorityQueue<int[]> rented = new PriorityQueue<>(order);
    private long key(int s, int m) { return (long) s * 10001 + m; }

    public MovieRentingSystem(int n, int[][] entries) {
        for (int[] e : entries) {
            int s = e[0], m = e[1], p = e[2];
            state.put(key(s, m), new int[]{p, 0, 0});
            available.computeIfAbsent(m, k -> new PriorityQueue<>(order))
                .offer(new int[]{p, s, m, 0});
        }
    }
    private List<int[]> take(PriorityQueue<int[]> heap, int wanted) {
        List<int[]> keep = new ArrayList<>();
        if (heap == null) return keep;
        while (!heap.isEmpty() && keep.size() < 5) {
            int[] t = heap.poll(), c = state.get(key(t[1], t[2]));
            if (c[1] == t[3] && c[2] == wanted) keep.add(t);
        }
        heap.addAll(keep);
        return keep;
    }
    public List<Integer> search(int movie) {
        List<Integer> result = new ArrayList<>();
        for (int[] t : take(available.get(movie), 0)) result.add(t[1]);
        return result;
    }
    private void move(int s, int m, int wanted) {
        int[] c = state.get(key(s, m));
        c[1]++; c[2] = wanted;
        (wanted == 1 ? rented : available.get(m))
            .offer(new int[]{c[0], s, m, c[1]});
    }
    public void rent(int shop, int movie) { move(shop, movie, 1); }
    public void drop(int shop, int movie) { move(shop, movie, 0); }
    public List<List<Integer>> report() {
        List<List<Integer>> result = new ArrayList<>();
        for (int[] t : take(rented, 1)) result.add(Arrays.asList(t[1], t[2]));
        return result;
    }
}

#include <vector>
#include <queue>

#include <functional>
using namespace std;

class MovieRentingSystem {
    using Ticket = array<int, 4>;
    using Heap = priority_queue<Ticket, vector<Ticket>, greater<Ticket>>;
    unordered_map<long long, array<int, 3>> state;
    unordered_map<int, Heap> available;
    Heap rented;
    long long key(int s, int m) { return 1LL * s * 10001 + m; }
    vector<Ticket> take(Heap& heap, int wanted) {
        vector<Ticket> keep;
        while (!heap.empty() && keep.size() < 5) {
            auto t = heap.top(); heap.pop();
            auto& c = state.at(key(t[1], t[2]));
            if (c[1] == t[3] && c[2] == wanted) keep.push_back(t);
        }
        for (auto t : keep) heap.push(t);
        return keep;
    }
    void move(int s, int m, int wanted) {
        auto& c = state.at(key(s, m));
        ++c[1]; c[2] = wanted;
        (wanted ? rented : available[m]).push({c[0], s, m, c[1]});
    }
public:
    MovieRentingSystem(int n, vector<vector<int>>& entries) {
        for (auto& e : entries) {
            int s = e[0], m = e[1], p = e[2];
            state[key(s, m)] = {p, 0, 0};
            available[m].push({p, s, m, 0});
        }
    }
    vector<int> search(int movie) {
        vector<int> result;
        for (auto t : take(available[movie], 0)) result.push_back(t[1]);
        return result;
    }
    void rent(int shop, int movie) { move(shop, movie, 1); }
    void drop(int shop, int movie) { move(shop, movie, 0); }
    vector<vector<int>> report() {
        vector<vector<int>> result;
        for (auto t : take(rented, 1)) result.push_back({t[1], t[2]});
        return result;
    }
