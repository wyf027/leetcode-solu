SWEEP LINE · PRIORITY QUEUE

218. 天际线问题 Hard

让扫描线沿 x 轴旅行。每到一个边界，更新“仍覆盖当前位置”的建筑高度；最高的有效高度改变时，才在天际线上留下一个关键点。

?题意

给定建筑数组 buildings，其中 buildings[i] = [left, right, height] 表示一座贴地矩形建筑。返回所有建筑外轮廓组成的天际线关键点 [[x₁,y₁], ...]：按 x 递增，最后一个点高度为 0，且不能连续输出同一高度。

官方样例 1

buildings = [[2,9,10],[3,7,15],[5,12,12],[15,20,10],[19,24,8]]
输出：[[2,10],[3,15],[7,12],[12,0],[15,10],[20,8],[24,0]]

官方样例 2

buildings = [[0,2,3],[2,5,3]]
输出：[[0,3],[5,0]]

约束：1 ≤ buildings.length ≤ 10⁴；0 ≤ left < right ≤ 2³¹−1；1 ≤ height ≤ 2³¹−1；输入按 left 非递减排序。

核心洞察

每座 [L,R,H] 变成开始事件 [L,-H,R]。按 x 扫描时，将已经开始且右端仍在未来的高度放入最大堆；惰性删除堆顶过期建筑。若堆顶高度与上一个输出不同，就记录 [x, heapTop]。

为何负高？同 x 时更高建筑先入堆，保证这一个 x 只取一次正确最高值。

完整过程

  1. 提取所有建筑的左右边界，升序去重。
  2. 走到 x 前，把 left ≤ x 的建筑压入最大堆（堆元素记录高度与 right）。
  3. 弹出所有 right ≤ x 的堆顶过期建筑。
  4. 堆顶即 x 处有效最大高度；改变才追加关键点。

边界与复杂度

  • 接壤等高：[[0,2,3],[2,5,3]] 不能在 x=2 输出重复高度。
  • 完全覆盖：低楼在高楼结束时才重新出现。
  • 大坐标：不能按每个整数 x 遍历。

时间：O(n log n)，空间：O(n)。

替代方案、追问与错误

替代：分治法合并两条天际线也是 O(n log n)，适合解释归并；扫描线更便于实现动态有效高度。
追问：在线新增建筑？需维护区间结构；若输出面积？遍历相邻关键点累加宽 × 高。
错误：逐事件直接输出（同 x 会出假点）；未删过期堆顶；只比较高度却忘记末尾 0。

import java.util.*;
class Solution {
    public List<List<Integer>> getSkyline(int[][] buildings) {
        List<int[]> events = new ArrayList<>();
        for (int[] b : buildings) { events.add(new int[]{b[0], -b[2], b[1]}); events.add(new int[]{b[1], 0, 0}); }
        events.sort((a,b) -> a[0] != b[0] ? Integer.compare(a[0], b[0]) : Integer.compare(a[1], b[1]));
        PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> b[0] - a[0]); pq.offer(new int[]{0, Integer.MAX_VALUE});
        List<List<Integer>> ans = new ArrayList<>();
        int i = 0, prev = 0;
        while (i < events.size()) { int x = events.get(i)[0];
            while (i < events.size() && events.get(i)[0] == x) { int[] e = events.get(i++); if (e[1] != 0) pq.offer(new int[]{-e[1], e[2]}); }
            while (pq.peek()[1] <= x) pq.poll(); int h = pq.peek()[0];
            if (h != prev) { ans.add(Arrays.asList(x, h)); prev = h; }
        } return ans;
    }
}

from heapq import heappush, heappop
class Solution:
    def getSkyline(self, buildings: list[list[int]]) -> list[list[int]]:
        events = sorted({x for left, right, _ in buildings for x in (left, right)})
        heap, ans, i, prev = [(0, float('inf'))], [], 0, 0
        for x in events:
            while i < len(buildings) and buildings[i][0] <= x:
                left, right, height = buildings[i]; heappush(heap, (-height, right)); i += 1
            while heap[0][1] <= x: heappop(heap)
            height = -heap[0][0]
            if height != prev: ans.append([x, height]); prev = height
        return ans
