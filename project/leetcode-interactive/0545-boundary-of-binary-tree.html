二叉树的边界

Boundary of Binary Tree — 从根出发，依次收集左边界、叶子与反向右边界。先观察边界是如何被“缝合”的，再决定是否展开完整题解。

TreeDepth-First SearchBinary Tree返回 list<integer>

题目

给定一棵二叉树的根节点 root，按逆时针顺序返回它的边界节点值。

边界由三部分组成：根节点；从根的左子树向下的左边界（每层优先走左孩子，没有才走右孩子，叶子不在此处重复加入）；全部叶子节点从左到右；以及从根的右子树向下的右边界，以自底向上的顺序加入（同样不包含叶子）。每个节点最多出现一次。

函数签名： boundaryOfBinaryTree(root: TreeNode): List<Integer>

约束

  • 树中节点数在 [1, 10⁴] 范围内。
  • -1000 ≤ Node.val ≤ 1000。

官方示例（完整参数形式）

输入：root = [1,null,2,3,4]
输出：[1,3,4,2]

根为 1；叶子依次是 3、4；右边界逆序补上 2。

输入：root = [1,2,3,4,5,6,null,null,null,7,8,9,10]
输出：[1,2,4,7,8,9,10,6,3]

叶子必须严格从左到右；节点 2、3、6 属于非叶边界。

题解：三段互斥收集

核心洞察

不要试图一次 DFS 判断“几何外轮廓”。把边界拆成三个互斥集合更稳：非叶左边界、所有叶子、非叶右边界。根单独加入；右边界暂存后反转，顺序自然变成自底向上。

完整过程

  1. 若根为空返回空表；先把根加入答案。
  2. 从 root.left 出发：当前节点不是叶子才加入；下一步优先左孩子，否则右孩子。
  3. DFS 整棵树，遇到叶子就从左到右加入；为防止单节点树重复，跳过根本身。
  4. 从 root.right 出发：当前节点不是叶子才加入临时表；下一步优先右孩子，否则左孩子。最后倒序追加临时表。

正确性证明

左边界：每层按“左优先、无左取右”前进，恰好选择该子树最靠左的可达非叶节点，且不加入叶子。

叶子：先左后右的 DFS 恰按从左到右顺序访问全部且仅全部叶子。

右边界：“右优先、无右取左”恰好选择最靠右的非叶节点；将自顶向下的暂存结果反转，即为题目要求的自底向上顺序。

三段排除了叶子重叠，根又被单独处理，因此无重复且没有遗漏；拼接次序正是逆时针边界。

边界情况

  • 只有根：结果仅含根。
  • 退化为单链：左链或右链仍不会重复叶子。
  • 边界节点缺少首选方向孩子：改走另一孩子，仍保持外侧路径。
  • 根的某一侧为空：对应边界扫描自然跳过。

复杂度

每个节点在叶子 DFS 中访问一次，边界扫描至多再走树高：时间 O(n)；递归栈 O(h)，右边界暂存最多 O(h)（返回结果空间不计）。

替代方案

可以用一次 DFS 携带 isLeftBoundary / isRightBoundary 标记，并在前序位置加入左边界、后序位置加入右边界。它同样是 O(n)，但标记传播和去重更容易写错；三段法更适合面试现场说明与验证。

面试追问

  • 如何改为顺时针？交换左右规则与拼接方向。
  • 如何避免递归栈溢出？用显式栈进行叶子遍历。
  • 为什么边界扫描排除叶子？因为叶子阶段统一决定其从左到右的顺序，排除后才能保证互斥。

常见错误

  • 左边界只沿 left、右边界只沿 right，导致缺孩子时漏节点。
  • 叶子被边界扫描和 DFS 各加入一次。
  • 右边界没有反转，得到顺时针的局部顺序。
  • 单节点树把根作为叶子再次加入。

class Solution {
    public List<Integer> boundaryOfBinaryTree(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        if (root == null) return ans;
        ans.add(root.val);
        addLeft(root.left, ans);
        addLeaves(root, root, ans);
        addRight(root.right, ans);
        return ans;
    }
    private boolean leaf(TreeNode n) { return n.left == null && n.right == null; }
    private void addLeft(TreeNode n, List<Integer> ans) {
        while (n != null) {
            if (!leaf(n)) ans.add(n.val);
            n = n.left != null ? n.left : n.right;
        }
    }
    private void addLeaves(TreeNode n, TreeNode root, List<Integer> ans) {
        if (n == null) return;
        if (leaf(n)) { if (n != root) ans.add(n.val); return; }
        addLeaves(n.left, root, ans); addLeaves(n.right, root, ans);
    }
    private void addRight(TreeNode n, List<Integer> ans) {
        List<Integer> tmp = new ArrayList<>();
        while (n != null) {
            if (!leaf(n)) tmp.add(n.val);
            n = n.right != null ? n.right : n.left;
        }
        for (int i = tmp.size() - 1; i >= 0; --i) ans.add(tmp.get(i));
    }
}
var boundaryOfBinaryTree = function(root) {
  if (!root) return [];
  const ans = [root.val];
  const isLeaf = n => !n.left && !n.right;
  let node = root.left;
  while (node) {
    if (!isLeaf(node)) ans.push(node.val);
    node = node.left || node.right;
  }
  const addLeaves = node => {
    if (!node) return;
    if (isLeaf(node)) { if (node !== root) ans.push(node.val); return; }
    addLeaves(node.left); addLeaves(node.right);
  };
  addLeaves(root);
  const right = [];
  node = root.right;
  while (node) {
    if (!isLeaf(node)) right.push(node.val);
    node = node.right || node.left;
  }
  while (right.length) ans.push(right.pop());
  return ans;
};
class Solution:
    def boundaryOfBinaryTree(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        ans = [root.val]
        leaf = lambda n: n.left is None and n.right is None
        node = root.left
        while node:
            if not leaf(node):
                ans.append(node.val)
            node = node.left if node.left else node.right

        def add_leaves(node):
            if not node:
                return
            if leaf(node):
                if node is not root:
                    ans.append(node.val)
                return
            add_leaves(node.left)
            add_leaves(node.right)
        add_leaves(root)

        right = []
        node = root.right
        while node:
            if not leaf(node):
                right.append(node.val)
            node = node.right if node.right else node.left
        ans.extend(reversed(right))
        return ans
class Solution {
    bool leaf(TreeNode* n) { return !n->left && !n->right; }
    void leaves(TreeNode* n, TreeNode* root, vector<int>& ans) {
        if (!n) return;
        if (leaf(n)) { if (n != root) ans.push_back(n->val); return; }
        leaves(n->left, root, ans); leaves(n->right, root, ans);
    }
public:
    vector<int> boundaryOfBinaryTree(TreeNode* root) {
        if (!root) return {};
        vector<int> ans{root->val};
        for (TreeNode* n = root->left; n; n = n->left ? n->left : n->right)
            if (!leaf(n)) ans.push_back(n->val);
        leaves(root, root, ans);
        vector<int> right;
        for (TreeNode* n = root->right; n; n = n->right ? n->right : n->left)
            if (!leaf(n)) right.push_back(n->val);
        for (auto it = right.rbegin(); it != right.rend(); ++it) ans.push_back(*it);
        return ans;
    }
};
