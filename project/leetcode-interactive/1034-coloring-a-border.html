边界着色

Coloring A Border
MEDIUM深度优先搜索广度优先搜索数组矩阵

题目

给定一个 m × n 整数矩阵 grid，以及 row、col、color。上下左右相邻且颜色相同的方格属于同一连通分量。找到包含 grid[row][col] 的分量，只把它的边界方格改成 color，返回最终网格。

边界方格满足至少一项：位于整个网格的外缘；或四邻域中存在一个不属于该连通分量的方格。分量内部方格保持原色。

官方示例

输入：grid = [[1,1],[1,2]], row = 0, col = 0, color = 3
输出：[[3,3],[3,2]]
输入：grid = [[1,2,2],[2,3,2]], row = 0, col = 1, color = 3
输出：[[1,3,3],[2,3,3]]
输入：grid = [[1,1,1],[1,1,1],[1,1,1]], row = 1, col = 1, color = 2
输出：[[2,2,2],[2,1,2],[2,2,2]]

约束

  • m == grid.length
  • n == grid[i].length
  • 1 ≤ m, n ≤ 50
  • 1 ≤ grid[i][j], color ≤ 1000
  • 0 ≤ row < m
  • 0 ≤ col < n

完整题解

核心洞察

先用 DFS/BFS 找出起点所属的完整连通分量，同时根据原始颜色判断每个成员是否为边界。搜索结束后统一着色，避免“边搜边改”破坏后续的同色判断。

完整过程

  1. 记起点颜色为 original，创建 visited。
  2. 从起点开始 BFS，仅将网格内、颜色等于 original、未访问的四邻格加入队列。
  3. 检查当前格四个方向：若有方向越界或邻格颜色不同，则当前格属于边界。
  4. 搜索完成后，将收集到的边界坐标改为 color。

正确性证明

  1. 搜索完整性：BFS 从起点沿同色四邻边扩展，因此能到达该连通分量的每个格；又不会进入不同颜色的格，所以访问集合恰好等于目标分量。
  2. 边界判定正确：对每个分量成员检查四个方向。存在越界方向或不同原色邻格，当且仅当它位于题目定义的边界。
  3. 着色正确：算法只修改被判定为边界的分量成员；分量内部及分量外格子均不变。因此返回矩阵正是所求。

复杂度

设网格大小为 m × n。每格至多访问一次，时间 O(mn)；访问数组、队列和边界列表合计空间 O(mn)。

边界情况

  • 单行或单列：分量内每格都是边界。
  • 新旧颜色相同：结果不变，流程仍正确。
  • 起点孤立：起点自身就是边界。
  • 整个网格同色：只改最外圈。

替代方案

可用递归 DFS 替代 BFS，代码更短，但最坏深度可达 2500；也可先复制结果矩阵，在原矩阵上判断、在副本上写入，从而天然隔离读写。

面试追问

  • 若相邻定义改为八方向，只需扩展方向数组，但边界定义也须同步确认。
  • 若要处理多次查询，可否预处理连通分量？静态网格可标号并保存每个分量边界；着色会改变连通性时则需要更复杂的动态维护。
  • 怎样原地修改且不额外保存边界？可用临时标记编码，但颜色取值与符号约束必须允许，且可读性较弱。

常见错误

  • 边搜索边改成新颜色，导致同色判断失真，尤其当新颜色等于邻近其他分量颜色时。
  • 只把网格外缘当成边界，漏掉与异色格相邻的内部边界。
  • 以“未访问邻格”代替“不在分量的邻格”，会把搜索顺序误当边界条件。

四语言完整代码

import java.util.*;
class Solution {
    public int[][] colorBorder(int[][] grid, int row, int col, int color) {
        int m = grid.length, n = grid[0].length, original = grid[row][col];
        boolean[][] seen = new boolean[m][n];
        List<int[]> border = new ArrayList<>();
        ArrayDeque<int[]> q = new ArrayDeque<>();
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
        q.offer(new int[]{row,col}); seen[row][col] = true;
        while (!q.isEmpty()) {
            int[] p = q.poll(); boolean edge = false;
            for (int[] d : dirs) {
                int x=p[0]+d[0], y=p[1]+d[1];
                if (x<0 || x>=m || y<0 || y>=n || grid[x][y] != original) edge=true;
                else if (!seen[x][y]) { seen[x][y]=true; q.offer(new int[]{x,y}); }
            }
            if (edge) border.add(p);
        }
        for (int[] p : border) grid[p[0]][p[1]] = color;
        return grid;
    }
}
var colorBorder = function(grid, row, col, color) {
  const [m,n,original] = [grid.length,grid[0].length,grid[row][col]];
  const seen = Array.from({length:m}, () => Array(n).fill(false));
  const queue = [[row,col]], border = [], dirs = [[1,0],[-1,0],[0,1],[0,-1]];
  seen[row][col] = true;
  for (let head=0; head<queue.length; head++) {
    const [r,c] = queue[head]; let edge = false;
    for (const [dr,dc] of dirs) {
      const x=r+dr, y=c+dc;
      if (x<0 || x>=m || y<0 || y>=n || grid[x][y] !== original) edge=true;
      else if (!seen[x][y]) { seen[x][y]=true; queue.push([x,y]); }
    }
    if (edge) border.push([r,c]);
  }
  for (const [r,c] of border) grid[r][c] = color;
  return grid;
};
from typing import List
from collections import deque

class Solution:
    def colorBorder(self, grid: List[List[int]], row: int, col: int,
                    color: int) -> List[List[int]]:
        m, n, original = len(grid), len(grid[0]), grid[row][col]
        seen, border = {(row, col)}, []
        q = deque([(row, col)])
        for r, c in iter(q.popleft, None):
            edge = False
            for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
                x, y = r + dr, c + dc
                if not (0 <= x < m and 0 <= y < n) or grid[x][y] != original:
                    edge = True
                elif (x, y) not in seen:
                    seen.add((x, y)); q.append((x, y))
            if edge: border.append((r, c))
            if not q: break
        for r, c in border: grid[r][c] = color
        return grid
class Solution {
public:
    vector<vector<int>> colorBorder(vector<vector<int>>& grid, int row, int col, int color) {
        int m=grid.size(), n=grid[0].size(), original=grid[row][col];
        vector<vector<bool>> seen(m, vector<bool>(n));
        vector<pair<int,int>> border; queue<pair<int,int>> q;
        int dirs[5]={1,0,-1,0,1}; q.push({row,col}); seen[row][col]=true;
        while (!q.empty()) {
            auto [r,c]=q.front(); q.pop(); bool edge=false;
            for (int k=0;k<4;k++) {
                int x=r+dirs[k], y=c+dirs[k+1];
                if (x<0 || x>=m || y<0 || y>=n || grid[x][y]!=original) edge=true;
                else if (!seen[x][y]) { seen[x][y]=true; q.push({x,y}); }
            }
            if (edge) border.push_back({r,c});
        }
        for (auto [r,c]:border) grid[r][c]=color;
        return grid;
    }
};
