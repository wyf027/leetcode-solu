Problem

题意

实现类 MovingAverage，持续接收一个整数数据流，并返回数据流中最近至多 size 个值的平均值。

MovingAverage(int size) 用窗口容量 size 初始化对象；double next(int val) 把 val 加入数据流，再返回当前窗口的移动平均值。数据不足 size 个时，对已经到达的全部数据求平均。

官方参数形式示例

输入
["MovingAverage", "next", "next", "next", "next"]
[[3], [1], [10], [3], [5]]
输出
[null, 1.0, 5.5, 4.66667, 6.0]
调用说明
  1. MovingAverage(3)：窗口容量为 3。
  2. next(1)：窗口 [1]，平均值 1 / 1 = 1.0。
  3. next(10)：窗口 [1, 10]，平均值 11 / 2 = 5.5。
  4. next(3)：窗口 [1, 10, 3]，平均值 14 / 3 ≈ 4.66667。
  5. next(5)：1 被移出，窗口 [10, 3, 5]，平均值 18 / 3 = 6.0。

约束

  • 1 <= size <= 1000
  • -10^5 <= val <= 10^5
  • 最多调用 next 约 10^4 次。

Full solution

队列 + 滚动总和

窗口的关键不是“重新计算”，而是维护前后两次状态的差：加入一个新值；若超出容量，移除最旧值；总和同步加新减旧。

核心洞察

先进先出的队列恰好对应滑动窗口：队首永远是下一次需要淘汰的最旧元素。额外维护 sum，就能以常数时间得到平均值。

完整过程

  1. 将 val 入队并加入 sum。
  2. 若队列长度大于 size，弹出队首并从 sum 中减去。
  3. 返回 sum / queue.length。

正确性说明

不变式：每次 next 结束时，队列按到达顺序保存数据流最后 min(size, t) 个值，并且 sum 等于这些值之和。

初始队列为空，不变式成立。加入新值后，若未超容量，窗口正是全部已到达值；若超容量，只移除唯一的最旧值，留下的正是最后 size 项。加新、减旧同步更新总和，因此不变式继续成立。返回总和除以窗口元素数，必然得到题目要求的移动平均值。

边界与数值

  • size = 1：每次返回当前值。
  • 尚未填满：分母使用当前元素数，不能固定除以 size。
  • 负数和零：加减逻辑不变。
  • 使用浮点除法；Java/C++ 中避免整数除法。
  • 按约束总和绝对值最多约为 10^8，但使用更宽或浮点的累加类型更稳妥。

复杂度

每个元素至多入队、出队各一次。单次 next 时间复杂度为 O(1)，窗口存储的空间复杂度为 O(size)。

替代方案

循环数组：用固定长度数组覆盖最旧位置，同样能做到 O(1) 时间和 O(size) 空间，还避免队列节点开销。JavaScript 版本在下方演示这种写法。

每次遍历：实现直观，但单次需要 O(size)，不适合高频数据流。

面试追问

  • 如果窗口按“最近 5 分钟”而非元素个数定义，如何用时间戳队列淘汰？
  • 如果数据并发到达，怎样保证队列与总和的原子更新？
  • 如何支持动态修改窗口容量？缩小时需要立即淘汰哪些元素？
  • 极大规模浮点数据如何降低累加误差？可讨论补偿求和。

常见错误

  • 先求平均再淘汰，导致窗口多包含一个元素。
  • 忘记从总和中减掉弹出的队首。
  • 窗口未满时仍除以固定容量。
  • 用数组 shift() 并假定所有语言中它都是 O(1)。
  • Java/C++ 使用整数类型相除，截断小数。
一句话记忆：队列决定“谁还在窗口里”，滚动总和负责“立刻算出平均值”。

四种语言完整实现

JavaArrayDeque + double sum
import java.util.ArrayDeque;
import java.util.Queue;

class MovingAverage {
    private final int size;
    private final Queue<Integer> window;
    private double sum;

    public MovingAverage(int size) {
        this.size = size;
        this.window = new ArrayDeque<>();
        this.sum = 0.0;
    }

    public double next(int val) {
        window.offer(val);
        sum += val;

        if (window.size() > size) {
            sum -= window.poll();
        }

        return sum / window.size();
    }
}
JavaScript固定长度循环数组
/**
 * @param {number} size
 */
var MovingAverage = function(size) {
    this.size = size;
    this.buffer = new Array(size).fill(0);
    this.count = 0;
    this.nextIndex = 0;
    this.sum = 0;
};

/**
 * @param {number} val
 * @return {number}
 */
MovingAverage.prototype.next = function(val) {
    if (this.count < this.size) {
        this.count += 1;
    } else {
        this.sum -= this.buffer[this.nextIndex];
    }

    this.buffer[this.nextIndex] = val;
    this.sum += val;
    this.nextIndex = (this.nextIndex + 1) % this.size;

    return this.sum / this.count;
};
Pythoncollections.deque
from collections import deque


class MovingAverage:
    def __init__(self, size: int):
        self.size = size
        self.window = deque()
        self.total = 0

    def next(self, val: int) -> float:
        self.window.append(val)
        self.total += val

        if len(self.window) > self.size:
            self.total -= self.window.popleft()

        return self.total / len(self.window)
C++queue + long long sum
#include <queue>

class MovingAverage {
private:
    int size;
    std::queue<int> window;
    long long sum;

public:
    MovingAverage(int size) : size(size), sum(0) {}

    double next(int val) {
        window.push(val);
        sum += val;

        if (static_cast<int>(window.size()) > size) {
            sum -= window.front();
            window.pop();
        }

        return static_cast<double>(sum) / window.size();
    }
};
