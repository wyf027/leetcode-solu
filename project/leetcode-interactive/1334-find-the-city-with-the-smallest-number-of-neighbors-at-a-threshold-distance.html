城市之间不只看直达，还要看“绕路后的最短距离”

阈值距离内邻居最少的城市

Find the City With the Smallest Number of Neighbors at a Threshold Distance

在一张带权无向图中，为每座城市统计阈值范围内可到达的其他城市数量；选出数量最少者，平局时返回编号最大的城市。

任务

先理解距离、阈值与平局规则。题解默认收起，你可以先用交互图独立推演答案。

Problem

题意

有 n 座城市，编号为 0 到 n - 1。edges[i] = [fromᵢ, toᵢ, weightᵢ] 表示两座城市之间有一条权重为 weightᵢ 的双向边。

一条路径的距离等于沿途边权之和。对每座城市，统计通过某条路径能到达、且最短路径距离不超过 distanceThreshold 的其他城市数量。返回数量最少的城市；若并列，返回编号最大的城市。

示例 1

输入：n = 4 edges = [[0,1,3],[1,2,1],[1,3,4],[2,3,1]] distanceThreshold = 4 输出：3

城市 0 与 3 都有 2 个阈值内邻居；平局选择编号更大的 3。

示例 2

输入：n = 5 edges = [[0,1,2],[0,4,8],[1,2,3], [1,4,2],[2,3,1],[3,4,1]] distanceThreshold = 2 输出：0

城市 0 的阈值内邻居只有城市 1，数量最少。

约束

  • 2 ≤ n ≤ 100
  • 1 ≤ edges.length ≤ n × (n - 1) / 2
  • edges[i].length = 3
  • 0 ≤ fromᵢ < toᵢ < n
  • 1 ≤ weightᵢ, distanceThreshold ≤ 10⁴
  • 所有端点对 (fromᵢ, toᵢ) 互不相同

Solution

题解：Floyd–Warshall 全源最短路

核心洞察

题目询问每一对城市之间的最短距离，且 n ≤ 100。用一个 n × n 矩阵保存距离，再依次允许每个城市作为中转点，正好匹配 Floyd–Warshall。得到全源最短路后，只需逐行统计不超过阈值的非对角元素。

平局技巧：按城市编号从小到大扫描，并在 count ≤ bestCount 时更新答案。相同数量出现时，后来的更大编号会覆盖旧答案。

完整过程

  1. 初始化距离矩阵：dist[i][i] = 0，其余为无穷大。
  2. 把每条无向边的权重同时写入 dist[u][v] 与 dist[v][u]。
  3. 枚举中转点 k，再枚举起点 i 和终点 j，执行 dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])。
  4. 对每个 i，统计所有 j ≠ i 且 dist[i][j] ≤ distanceThreshold 的城市。
  5. 若当前数量小于或等于历史最小值，更新答案为 i。

正确性证明

引理 1：距离矩阵阶段含义

完成中转点 0..k 的处理后，dist[i][j] 等于所有“内部节点只来自 0..k”的 i → j 路径中的最短距离。初始时不允许内部中转点，只可能走直接边；归纳到 k 时，最短路径要么不经过 k，要么可拆成 i → k 与 k → j，转移恰好取两者较小值。

引理 2：统计值准确

所有中转点处理完后，任何路径的内部城市都已被允许，因此 dist[i][j] 是真实最短距离。条件 j ≠ i 且 dist[i][j] ≤ distanceThreshold 与题目对邻居的定义完全一致。

定理：算法返回正确城市

扫描过程中记录迄今最小邻居数；使用“小于等于”更新，使相同计数下编号更大的城市覆盖更小者。因此最终答案同时满足邻居数最少和并列时编号最大。

复杂度

时间复杂度 O(n³)；距离矩阵空间复杂度 O(n²)。

边界情况

  • 没有任何其他城市在阈值内
  • 所有城市邻居数相同
  • 最短路由多条边组成
  • 路径距离恰好等于阈值

替代方案

也可以从每座城市运行一次 Dijkstra。邻接表加二叉堆的典型复杂度约为 O(n · (m + n) log n)，稀疏图上可能更好；还可以在弹出的最短距离超过阈值时提前停止。这里 n ≤ 100，Floyd 写法短、状态直接，尤其适合全源统计。

四语言完整代码

import java.util.Arrays;

class Solution {
    public int findTheCity(int n, int[][] edges, int distanceThreshold) {
        final int INF = 1_000_000_000;
        int[][] dist = new int[n][n];
        for (int i = 0; i < n; i++) {
            Arrays.fill(dist[i], INF);
            dist[i][i] = 0;
        }

        for (int[] edge : edges) {
            int u = edge[0], v = edge[1], w = edge[2];
            dist[u][v] = w;
            dist[v][u] = w;
        }

        for (int k = 0; k < n; k++) {
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
                }
            }
        }

        int answer = -1;
        int bestCount = n;
        for (int i = 0; i < n; i++) {
            int count = 0;
            for (int j = 0; j < n; j++) {
                if (i != j && dist[i][j] <= distanceThreshold) count++;
            }
            if (count <= bestCount) {
                bestCount = count;
                answer = i;
            }
        }
        return answer;
    }
}

    const INF = Number.POSITIVE_INFINITY;
    const dist = Array.from({ length: n }, (_, i) =>
        Array.from({ length: n }, (_, j) => i === j ? 0 : INF)
    );

    for (const [u, v, w] of edges) {
        dist[u][v] = w;
        dist[v][u] = w;
    }

    for (let k = 0; k < n; k++) {
        for (let i = 0; i < n; i++) {
            for (let j = 0; j < n; j++) {
                dist[i][j] = Math.min(dist[i][j], dist[i][k] + dist[k][j]);
            }
        }
    }

    let answer = -1;
    let bestCount = n;

        }

            answer = i;
        }

    return answer;

常见错误

  • 只检查直接边，没有计算可绕行的最短路径。
  • 把城市自己计入邻居，导致统计多 1。
  • 使用严格小于阈值，漏掉距离恰好等于阈值的城市。
  • 平局时使用 count < bestCount，错误保留较小编号。
  • 无穷大设得过小，或加法溢出。这里最大简单路径远低于 10⁹。
