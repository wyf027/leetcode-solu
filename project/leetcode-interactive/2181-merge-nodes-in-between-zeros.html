合并零之间的节点

Merge Nodes in Between Zeros

01题目

给定单链表头节点 head，链表的第一个和最后一个节点值均为 0。零节点将其他节点划分成若干非空区间。

对链表中按顺序相邻的两个零节点，把它们之间的所有节点合并成一个节点，新节点的值等于该区间所有节点值的总和。移除所有零节点，保持各区间原有顺序，返回结果链表的头节点。

这里“相邻的两个零”指零节点序列中相邻的两个边界，并不是说两个零在链表中直接相连。数组仅用于表示链表，函数接收和返回的都是链表节点。

官方示例 1

输入：head = [0,3,1,0,4,5,2,0]
输出：[4,11]

两个区间分别为 [3,1] 和 [4,5,2]，合并后的节点值为 4 和 11。

官方示例 2

输入：head = [0,1,0,3,0,2,2,0]
输出：[1,3,4]

三个区间分别为 [1]、[3] 和 [2,2]，合并后的节点值为 1、3 和 4。

约束

  • 链表节点数 n 满足 3 ≤ n ≤ 2 × 10⁵。
  • 0 ≤ Node.val ≤ 1000。
  • 不存在两个直接相连、值都为 0 的节点。
  • 链表的首节点和尾节点值都为 0。

接口：mergeNodes(head: ListNode) → ListNode。题目及签名依据本地官方元数据转述。查看官方题目 ↗

03准备好看题解了吗？

展开后包含分步演示、推导与四语言实现。

题解 · 把零看作区间结束信号

从首个零的下一个节点开始读取，用 sum 保存当前区间的和。读到非零值就累加；读到零就把当前和追加到结果链表，然后清零。用一个哑节点 dummy 统一处理第一个结果节点。

主解法新建结果节点，输入链表保持不变。这样“读入”和“输出”分开，便于理解；不要求原地修改也能返回题目需要的链表。

交互 · 零边界收集器

金色外框标记刚处理的节点，虚线框表示零边界，绿色表示已经读过。每次跨过一个结束边界，下方结果轨道增加一个节点。

演示限制为 3～40 个节点；值为 0～1000 的整数，首尾为零且不可连续出现零。此长度限制仅用于演示。

完整过程

  1. 建立哑节点 dummy，让尾指针 tail 指向它，设 sum = 0。
  2. 让读取指针从 head.next 出发，跳过最前面的零。
  3. 当前节点非零：把节点值加入 sum，继续前进。
  4. 当前节点为零：建立值为 sum 的节点，接到 tail.next，移动尾指针并令 sum = 0。
  5. 处理完最后一个零后，最后一段已经写入结果。返回 dummy.next。

示例 1：读取 3、1 后 sum = 4；读到零，追加 4 并清零。读取 4、5、2 后 sum = 11；读到末尾零，追加 11 并清零。最终为 4 → 11 → null。

正确性 · 循环不变式

每次读取节点前，结果链表恰好包含此前所有完整区间的和，且顺序一致；sum 恰好等于最近一个已处理零节点之后、当前节点之前的非零值之和。

  • 初始化：跳过起始零后，没有已完成区间，结果为空且 sum 为零，不变式成立。
  • 保持：遇到非零值时只累加，当前区间的和仍正确；遇到零时，sum 正好是刚结束区间的总和，将其追加并清零后，结果和下一段状态都正确。
  • 终止：最后一个节点是零，所以最后一段也被提交，没有遗漏。各段非空且内部值为正，输出节点都非零。返回链表恰好满足要求。

边界与复杂度

最短输入 [0,x,0] 产生单个节点 x；一段或很多短段都由同一循环处理。合法输入不包含相邻零，不需要为“空区间”输出节点。算法按题目保证接收合法非空链表；演示输入另行校验。

设原链表有 n 个节点、非空区间有 k 段。时间复杂度 O(n)；新建结果节点占 O(k) 空间，除输出外辅助空间为 O(1)。最大段和为 (200000 − 2) × 1000 = 199998000，Java / C++ 的 32 位 int 足够，JavaScript Number 也可精确表示。

替代方案 · 原地双指针

读取指针照常遍历；写入指针从原始 head 出发，每遇到结束零，就先把写入指针前进一格，再把段和写入该节点。写指针始终落在已读取的区域，不会破坏未来读取值。遍历完成后令最后写入节点的 next 为 null，返回原始 head.next。

原地方案时间 O(n)、额外空间 O(1)，但会覆盖输入链表，并且必须断开旧尾部。若需要保留输入，使用本页的新建节点方案。递归分段也能实现，但 n 可达 2 × 10⁵，递归深度可能导致栈溢出，不推荐。

常见错误

  • 从 head 开始遇零就输出：会把起始零误当成一个空段结束。
  • 输出段和后忘记清零：后续结果变成累计前缀和。
  • 循环跳过最后一个节点：最后一个零不能漏读，否则末段丢失。
  • 返回 dummy：结果多了一个零；应返回 dummy.next。
  • 原地方案忘记截断尾指针：旧链表节点会留在结果中。

面试追问

  • 如何不申请新节点？使用上述原地读写指针，并说明写指针落后于读指针的不变式。
  • 如果允许负数呢？遇到零仍可作为边界，但段和可能等于零；“结果不含零”就需要重新定义，不能偷偷丢弃零和区间。
  • 如果末尾没有零呢？需要在遍历结束时提交尚未结束的区间，并通过“是否有数据”判断是否提交，不能只判断 sum 是否为零。
  • 流式输入可行吗？可以。只需保留当前和；每遇一个零就发出本段结果，不依赖回看。

四语言实现

均为官方可提交语言，采用相同的新建链表策略。ListNode 由 LeetCode 提供，下方注释列出对应定义；不需要编写 main。代码仅生成，未编译或执行。

Java

/* LeetCode provides:
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) {
        this.val = val;
        this.next = next;
    }
}
*/
class Solution {
    public ListNode mergeNodes(ListNode head) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        int sum = 0;
        for (ListNode p = head.next; p != null; p = p.next) {
            if (p.val == 0) {
                tail.next = new ListNode(sum);
                tail = tail.next;
                sum = 0;
            } else {
                sum += p.val;
            }
        }
        return dummy.next;
    }
}

class Solution:

        dummy = ListNode(0)
        tail = dummy
        total = 0
        p = head.next
        while p is not None:
            if p.val == 0:
                tail.next = ListNode(total)
                tail = tail.next
                total = 0
            else:
                total += p.val
            p = p.next
        return dummy.next

C++

/* LeetCode provides:
struct ListNode {
    int val;
    ListNode *next;
    ListNode() : val(0), next(nullptr) {}
    ListNode(int x) : val(x), next(nullptr) {}
    ListNode(int x, ListNode *next) : val(x), next(next) {}
};
*/
class Solution {
public:
    ListNode* mergeNodes(ListNode* head) {
        ListNode dummy(0);
        ListNode* tail = &dummy;
        int sum = 0;
        for (ListNode* p = head->next; p != nullptr; p = p->next) {
            if (p->val == 0) {
                tail->next = new ListNode(sum);
                tail = tail->next;
                sum = 0;
            } else {
                sum += p->val;
            }
        }
        return dummy.next;
    }
};

C++ 的 dummy 在栈上，返回的是独立分配的结果节点，不是 dummy 的地址。输入链表不释放；独立程序应按所有权约定分别管理输入和输出节点的生命周期。
