# le-e 产品落地页与开源入口同步

## 目标与已确认方向

为终端刷题工具 le-e 制作中文产品落地页与使用说明，发布到用户 Vercel，并更新 GitHub Pages 索引和 GitHub 个人首页开源项目列表。使用 Tailwind CSS，沿用真实 TUI 的深灰与青色风格。页面是产品介绍，不是可在线执行代码的 LeetCode 客户端。

## 页面内容

1. 首屏：le-e 标识、标题“把刷题工作区，留在终端里”、产品摘要、“开始使用”和“GitHub 源码”入口。
2. 实机截图：只采用本次重新截取的终端内容，无浏览器与桌面；保持图片比例，提供原图查看，不伪造产品画面。
3. 功能：中文题库搜索、个人收藏、官方题单、Micro 同屏编辑、语言切换、测试与提交、面板收起和拖拽。
4. 快速开始：先列依赖与完整初始化步骤，再提供已初始化项目内的一行启动命令 `corepack pnpm start`。不把该命令宣传成无需安装的一键运行。
5. 登录：浏览器登录 leetcode.cn，通过开发者工具 Application / Cookies 找到 LEETCODE_SESSION 和 csrftoken；在 TUI 按 c，分别粘贴值，Tab 切换并 Enter 登录。仅说明操作，不展示真实 Cookie，不在落地页接收 Cookie。CookieError 时点击登录异常状态更新。
6. 快捷键：F2 保存、F3 测试、F4 提交、F6 切栏目、F7/F8 切题、/ 搜索、b 收起、g 切语言、c 登录。说明提交会直接发起，避免旧版二次确认文案。
7. 限制与来源：注明基于 clearloop/leetcode-cli，非力扣官方产品；基础补全不是完整语言服务；图片清晰度依赖终端图形协议，数据库与 Shell 的执行能力受上游限制。

## 技术与展示

采用静态 HTML、构建后的 Tailwind CSS 和少量原生 JavaScript，无后端、无登录表单、无追踪器。复制命令按钮失败时显示可手动复制提示。移动端截图可打开原图阅读，代码块局部滚动；键盘焦点可见，图片有替代文本，导航与按钮可通过键盘使用。
